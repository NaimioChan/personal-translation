第 40 章　高斯函数的增量计算

Ken Turkowski
Adobe Systems

我们提出一种增量方法，用于在一系列规则间隔的点上计算高斯函数，每点的代价是一次向量乘法。这种技术可用于实现图像模糊：在运行时生成高斯系数，从而省去对预计算系数表的一次额外纹理查找。

系数计算涉及一些相对昂贵的操作（一次指数运算和一次除法），以及一些较便宜的乘法。昂贵的操作可能主导内层循环的计算时间。有经验的实践者可以把系数计算化简为

coeff = exp(-u * u);

但仍然每个像素都有指数运算。

克服这些昂贵计算的一种做法是预计算系数，再从纹理中查找。不过内层循环里已经另有两次纹理取数，我们更愿意在等待内存请求完成时做一些计算。

示例 40-1.


   uniform sampler2D inImg;  // 源图像
   uniform float     sigma;  // 高斯 sigma
   uniform float     norm;   // 归一化，例如 1/(sqrt(2*PI)*sigma)
   uniform vec2      dir;    // horiz=(1.0, 0.0), vert=(0.0, 1.0)
   uniform int       support; // int(sigma * 3.0) 截断
   void main()
{
  vec2 loc = gl_FragCoord.xy;    // 中心像素坐标
   vec4 acc;                      // 累加器
  acc = texture2D(inImg, loc);   // 累加中心像素
   for (i = 1; i <= support; i++) {
    float coeff = exp(-0.5 * float(i) * float(i) / (sigma * sigma));
    acc += (texture2D(inImg, loc - float(i) * dir)) * coeff; // L
    acc += (texture2D(inImg, loc + float(i) * dir)) * coeff; // R
  }
  acc *= norm;            // 归一化为单位增益
  gl_fragColor = acc;
}

另一种做法是用若干多项式或有理多项式近似之一计算高斯，按自变量的取值范围选用。但在 GPU 上做范围比较效率很低，而且多项式系数表多半需要存进纹理，因此这不如前一种做法。

我们的做法是在运行时计算系数，利用相邻采样之间的连贯性，用少量简单指令增量地完成计算。这种技术与多项式前向差分类似，所以我们先花点时间介绍那一技术。

注意这个方法可用来计算任意函数，而不只是多项式。前向差分在二维和三维图形渲染中尤其有用，用于线段与多边形的扫描转换技术（Foley 等 1990）。自适应前向差分是在一系列论文中发展起来的（Lien 等 1987，Shantz 和 Chang 1988，以及 Chang 等 1989），用于在浮点与定点运算中对三次曲线、NURBS 曲线与曲面求值并着色。Klassen（1991a）用自适应前向差分绘制抗锯齿的三次样条曲线。Turkowski（2002）用分段多项式的自适应前向差分实时渲染三次与球面全景图，这些多项式自适应地逼近超越函数。

我们的初始化方法对应泰勒级数近似。要在目标定义域上得到更精确的近似，可以用其他多项式近似方法，例如拉格朗日插值或切比雪夫近似（Ralston 和 Rabinowitz 1978）。

#ifdef USE_SCALAR_INSTRUCTIONS // suitable for scalar GPUs
float g0, g1, g2;
g0 = 1.0 / (sqrt(2.0 * PI) * sigma);
g1 = exp(-0.5 * delta * delta / (sigma * sigma));
g2 = g1 * g1;
for (i = 0; i < N; i++) {
  MultiplySomethingByTheGaussianCoefficient(g0);
  g0 *= g1;
  g1 *= g2;
}
#else // especially for vector architectures
float3 g;
g.x = 1.0 / (sqrt(2.0 * PI) * sigma);
g.y = exp(-0.5 * delta * delta / (sigma * sigma));
g.z = g.y * g.y;
for (i = 0; i < N; i++) {
  MultiplySomethingByTheGaussianCoefficient(g.x);
  g.xy *= g.yz;
}
#endif // USE_VECTOR_INSTRUCTIONS

高斯系数每个采样只需一次向量乘法即可生成。向量乘法是 GPU 上最快的指令之一。

40.5 性能

过去十年处理器性能大幅提升，算术逻辑单元（ALU）运算的执行速度已经比访问内存快一到三个数量级。因此在现代计算机架构上，用相对简单的计算取代查表往往能让算法受益，表比较大时尤其如此。

在 GPU 和 CPU 上，增量计算算法都明显快于在表中查找系数。GPU 性能高度依赖硬件能力、GPU 厂商、驱动版本和操作系统版本，但我们可以保守地说，这项技术至少带来 15% 的性能提升。

性能的另一个方面是某个模糊滤波能否装进 GPU。增量高斯模糊算法看起来很小，但在某些情况下 GPU 驱动会大幅增加指令数量。特别是有些 GPU 没有任何循环图元，驱动就会自动展开循环。于是最大循环次数（也就是高斯半径）受 ALU 指令或纹理查找指令数量的限制。该算法随后通过减少纹理查找次数来增大最大模糊半径。

图形硬件架构在不断演进。纹理访问相对算术计算较慢，但一些较新的硬件（例如 GeForce 8800 系列）最多集成 16 个 常量缓冲，每个 16K 个浮点数，访问时间与寄存器相同。使用这样的常量缓冲时，增量高斯算法的性能可能不比查表更高，但也可能不更低。增量高斯算法的优势在于它能成功部署在各种各样的平台上。

40.6 结论

我们给出了一种非常简单的技术，用于在等间距点上求高斯函数的值。它不是近似，而且具有多项式前向差分的简洁性，因此在 GPU 上每个点每更新一次系数只需要一条向量指令。

前向商方法能加速任何以多项式为指数的函数计算。现代计算机做乘法与做加法一样快，因此这项技术与前向差分同样强大。这种方法把增量计算扩展到了一类新的函数上。
