非茗的翻译文档库

撰稿人

Thomas Alexander 参与创立了 Exapath，这家初创公司专注于把网络算法映射到 GPGPU 上。此前他在 Juniper Networks 的基础设施产品组工作，参与构建核心路由器。Thomas 在杜克大学获得电气工程博士学位，其间还参与过一台为光线投射定制的并行机。

Kavita Bala 是康奈尔大学计算机科学系与计算机图形学项目的助理教授。Bala 专攻高复杂度光照的可扩展渲染、交互式全局光照、基于感知的渲染，以及基于图像的纹理化。她发表过多篇研究论文，并担任过 SIGGRAPH 等多个会议的程序委员会委员。2005 年，Bala 担任 Eurographics Symposium on Rendering 的共同主席。她参与撰写了研究生教材 Advanced Global Illumination, 2nd ed.（A K Peters，2006）。到康奈尔之前，Bala 在麻省理工学院获得 S.M. 与博士学位，在印度理工学院孟买分校获得 B.Tech. 学位。

Kevin Bjorke 是 NVIDIA 技术推广组的成员，并继续担任前几卷 GPU Gems 的编辑与撰稿人。他在实拍电影与动画电影、电视、广告、主题公园游乐设施、印刷品以及——当然——游戏等领域的制作方面都有广泛背景。自 20 世纪 80 年代中期起，Kevin 常在 SIGGRAPH 和 GDC 等活动上演讲。他目前的工作重点是利用 NVIDIA 的算力与专业能力，帮助开发者实现各自的目标。

Jean-Yves Blanc 于 1991 年在法国格勒诺布尔国立理工学院获得应用数学博士学位。他于 1992 年加入 CGG，在那里引入并开发了用于高性能计算地震应用的并行处理。他现在负责处理与油藏产品线的 IT 战略。

Jim Blinn 于 1968 年在密歇根大学读本科时开始做计算机图形学。1974 年他成为犹他大学的研究生，在那里研究镜面光照模型、凹凸贴图和环境/反射贴图，并于 1977 年获得博士学位。之后他去了 JPL，为飞往木星、土星和天王星的多次太空任务制作计算机图形动画，也为 Carl Sagan 的 PBS 系列片「宇宙」和 Annenberg/CPB 资助的项目「机械宇宙」制作动画——后者是一门 52 集的电视课程，用于教授大学水平的物理。在这些制作中，他又发展出若干技术，包括云模拟、置换贴图，以及一种先后被称为blobbies 或 metaballs 的建模方案。自 1987 年起，他在 IEEE Computer Graphics and Applications 期刊上撰写定期专栏，介绍计算机图形学中使用的数学技术。他刚刚出版了该系列文章结集的第三卷。1995 年他加入微软研究院，任 Graphics Fellow。他是麦克阿瑟奖得主、美国国家工程院院士，拥有 Otis Parsons 设计学院的荣誉美术博士学位，并先后获得 SIGGRAPH 计算机图形学成就奖（1983）和 Steven A. Coons 奖（1999）。

George Borshukov 是 Electronic Arts 的 CG 主管。他在加州大学伯克利分校获得硕士学位，是 The Campanile Movie 及其实时演示（1997）的创作者之一。他担任了 The Matrix（1999）中「子弹时间」段落的技术设计，并因该片使用的基于图像的渲染技术获得美国电影艺术与科学学院科技成就奖。Borshukov 主导了 The Matrix 续集（2003）中照片级真实数字角色的开发，并因在这些影片中设计并应用 Universal Capture 系统而获得视觉效果协会奖。其他电影作品包括 What Dreams May Come（1998）、Mission: Impossible 2（2000）和 Michael Jordan to the Max（2000）。他还是 UV pelting 方法的共同发明人之一，该方法用于多边形或细分曲面的参数化与无缝纹理化。他于 2004 年加入 Electronic Arts，专注于为下一代互动娱乐确立面部捕捉、动画与渲染的新标准。他构思了 Fight Night Round 3 的概念，以及 2005 年和 2006 年索尼 E3 活动上展示的 Tiger Woods 技术演示。

Tamy Boubekeur 是法国波尔多 INRIA 的计算机科学三年级博士生。他于 2004 年在波尔多大学获得计算机科学硕士学位。他目前的研究聚焦三维几何处理与实时渲染。他为三维采集管线开发了新的算法与数据结构，在大型三维物体的高效处理与交互式编辑、层次空间剖分结构、基于点的图形学以及实时表面细化方法等领域发表了多篇科学论文。他还在波尔多大学讲授几何建模与虚拟现实。

Ralph Brunner 毕业于苏黎世瑞士联邦理工学院（ETH），获计算机科学硕士学位。在熊群侵扰使主要城市不宜居住之后，他离开了这个国家，此后一直在加州从事 Mac OS X 图形栈的工作。

Iain 的职业生涯始于飞行模拟，当时每帧 250 个多边形已是最先进水平。随着消费级三维硬件的出现，他转向编写游戏引擎，已发行的作品包括 Machines 和 MotoGP 3。2005 年他转到 NVIDIA 的开发者技术组，这里是把他对游戏与三维图形的热情结合起来的最佳去处。

Ignacio Castaño Aguado 是 NVIDIA 开发者技术组的工程师。不下棋赢同事、或不带儿子穿越圣克鲁斯山徒步的时候，Ignacio 都在解决令他着迷的计算机图形学问题，并帮助开发者利用最新的 GPU 技术。加入 NVIDIA 之前，Ignacio 在多家游戏公司工作，包括 Crytek、Relic Entertainment 和 Oddworld Inhabitants。

Mark Colbert 是中佛罗里达大学的博士生，在媒体融合实验室工作。他于 2004 年和 2006 年在中佛罗里达大学先后获得计算机科学学士与硕士学位。他目前的研究聚焦交互式材质与光照设计的用户界面。

Keenan 最近在伊利诺伊大学厄巴纳-香槟分校完成计算机科学学士学位，其间研究 GPU 算法、网格参数化与动作捕捉。作为 NVIDIA 演示团队的实习生，他参与了「Mad Mod Mike」和「Smoke in a Box」两个演示。他 1991 年在日本东京的西町国际学校首次接触图形编程，在那里研习了 LogoWriter 海龟语言的种种细节。今年夏天他将前往乌干达坎帕拉，通过 Volunteers for Peace 参加一个服务项目。

Eugene d'Eon 自 2000 年作为实习生首次加入团队起，就一直在 NVIDIA 做演示，头三个月为一部只放映过一次的实时演示短片「Luxo Jr.」做建模、绑定和转描。之后他很快转到一个更宽容的编程岗位，此后一直用现有最数学化、最过度精巧的模型，来解决 NVIDIA 实时演示中最简单的着色与仿真问题。他总在写物理正确的着色器和「看起来还行」之间挣扎。Eugene 在滑铁卢大学获得荣誉数学学士学位，应用数学与计算机科学双专业，偶尔以音乐才能（钢琴与 Guitar Hero）和抛接「Eric's Extension」的本领为人所知。研究兴趣包括光传输、散射、反射率模型、皮肤着色、理论物理与数理逻辑。他开车的速度从不超过 c，而且与宇宙中大多数粒子不同，他的位置和动量都无法确切知道。他从不投票给在选择公理上没有明确立场的人。Eugene 使用 Elixir 吉他弦。

Bernard Deschizeaux 于 1988 年获得高能物理硕士学位，1991 年获得粒子物理博士学位。此后他一直在 CGG 工作，这是一家服务石油天然气行业的法国公司，他在那里运用高性能计算技能与物理知识解决地震处理的难题。他在 CGG 担任过从开发到高性能计算与算法研究的多个职位。他现在负责一个 GPGPU 项目，开发基于 GPU 集群的工业级方案。

Franck Diard 是 NVIDIA 的资深软件架构师。他于 1998 年在法国尼斯-索菲亚安提波利斯大学获得计算机科学博士学位。从 20 世纪 80 年代末在 Amiga 上玩矢量球和 copper list 起步，他随后在 UNIX 上编程十年，做过 Reyes 渲染、光线追踪和计算机视觉，之后转到 NVIDIA 做 Windows 内核驱动。他的兴趣始终围绕可扩展性（多核、多 GPU 渲染农场的编程），并将其应用于图像处理与图形渲染。他对 NVIDIA 的主要贡献是 SLI 技术。

在发现写有缺陷的软件比当税务员能让更多人的生活变得悲惨之后，Frank Doepke 决定做一名软件开发人员。意识到写坏代码是不对的，他从德国扬帆前往新大陆，此后一直在 Apple 追寻图形珍宝。

1999 年至 2002 年，Henrik Dohlmann 在哥本哈根大学计算机科学系图像组担任研究助理，后来在该校获得计算机科学 Cand. Scient. 学位。接着他参与了哥本哈根大学牙科学院三维实验室与 Image House 之间的工业合作项目。他于 2005 年转到 3Dfacto R&D，现在在那里做软件工程师。

Bryan 于 1997 年进入游戏行业，先后在西雅图的多家公司工作，包括 Sierra Online 和 Escape Factory。他拥有华盛顿大学的硕士学位。2003 年他加入 NVIDIA，开始教授（并学习）高端实时计算机图形学。自 2000 年起学习日语，Bryan 在 2004 年说服 NVIDIA 把他调到东京，此后一直在那里支持亚太地区的开发者。你要是去东京，不妨给他打个电话。

2001 年，Kenny Erleben 在哥本哈根大学计算机科学系获得计算机科学 Cand. Scient. 学位。之后他在 3Dfacto A/S 做全职研究员，2001 年晚些时候开始攻读博士。2004 年他在爱荷华大学数学系待了三个月。他于 2005 年获得博士学位，不久后被聘为哥本哈根大学计算机科学系助理教授。

Ryan 多年来一直是音乐可视化领域的先驱。在 Nullsoft 工作期间，他为 Winamp 编写了许多插件，其中最著名的是广受欢迎的 MilkDrop 可视化器。更近一些，他在 NVIDIA 演示团队做了几年成员，创作了「GeoForms」和「Cascades」两个演示，并做过其他 GPU 研究项目。

Nolan Goodnight 是 NVIDIA 的软件工程师。他在 CUDA 软件组工作，做应用与驱动开发。加入 NVIDIA 之前，他是弗吉尼亚大学计算机图形组的成员，研究 GPU 算法以及用预计算光传输进行渲染的近似方法。Nolan 对计算机图形学基础的兴起来自他为工业设计做几何建模的工作。他拥有物理学学士学位和计算机科学硕士学位。

Larry Gritz 是 NVIDIA Gelato 软件的总监兼首席架构师，这是一款硬件加速的电影级渲染器。他此前的图形工作包括：BMRT 的作者；Exluna, Inc.（后被 NVIDIA 收购）的联合创始人兼副总裁及其 Entropy 渲染器的主要开发者；Pixar 渲染研究组负责人；PhotoRealistic RenderMan 的主要贡献者；Advanced RenderMan: Creating CGI for Motion Pictures 一书的合著者；并偶尔在多部电影和广告中担任技术指导。Larry 在康奈尔大学获得学士学位，在乔治·华盛顿大学获得硕士与博士学位。

John Hable 是 Electronic Arts 的渲染工程师。他毕业于佐治亚理工学院，获计算机科学学士与硕士学位，其间解决了把三角形网格布尔组合的渲染时间从指数级降到二次方时间的问题。他近期的工作聚焦于在电脑游戏中渲染高质量面部动画所带来的压缩问题。目前他在洛杉矶开发一款 EA 新作。

Earl Hammon, Jr. 是 Infinity Ward 的首席软件工程师，在那里协助一支才华横溢的开发团队打造了多白金销量、广受好评的作品 Call of Duty 2 和 Call of Duty。在成为 Infinity Ward 创始成员之前，他参与过 Medal of Honor: Allied Assault。他毕业于斯坦福大学，获电气工程硕士学位，此前在塔尔萨大学获得电子工程学士学位。他目前的项目是 Call of Duty 4: Modern Warfare。

Takahiro Harada 是东京大学的副教授。他于 2006 年在东京大学获得工程学硕士学位。他目前的研究兴趣包括基于物理的仿真、实时仿真和通用 GPU 计算。

Mark Harris 是 NVIDIA 伦敦开发者技术团队的成员，与全世界的软件开发者合作，推动最新的 GPU 图形与高性能计算技术。他的主要研究兴趣包括并行计算、GPU 通用计算和基于物理的仿真。Mark 于 2003 年在北卡罗来纳大学教堂山分校获得计算机科学博士学位，1998 年在圣母大学获得学士学位。Mark 创办并维护 www.GPGPU.org，这是一个专门讨论 GPU 通用计算的网站。

Evan Hart 是 NVIDIA 开发者技术组的软件工程师。Evan 于 1997 年从可视化仿真入手，开始做实时三维。1998 年从俄亥俄州立大学毕业后，他一直致力于开发与改进实时渲染技术，从游戏到 CAD 程序都有涉猎，还顺带做过一些驱动。Evan 常在 GDC 演讲，并为 Game Programming Gems 和 ShaderX 系列图书撰写过章节。

Miloš Hašan 毕业于斯洛伐克布拉迪斯拉发的夸美纽斯大学，获计算机科学学位。目前他是康奈尔大学计算机科学系的博士生。他的研究兴趣包括全局光照、GPU 渲染和数值计算。

Jared Hoberock 是伊利诺伊大学厄巴纳-香槟分校的研究生。他曾在 NVIDIA 做过两个暑假的实习生，并两次获得 NVIDIA 研究生奖学金。他喜欢花时间写渲染软件。

Lee Howes 于 2005 年毕业于伦敦帝国理工学院，获计算工程硕士学位，目前正在帝国理工攻读博士。Lee 的研究涉及用 FPGA 和 GPU 进行计算，包括 FFT 与金融仿真方面的工作。为了从学业中分心、也为了涉猎现实世界的领域，Lee 曾短期在 Philips 和 NVIDIA 工作。

Yuntao Jia 目前正在伊利诺伊大学厄巴纳-香槟分校攻读计算机科学博士。他对计算机图形学极感兴趣，目前的研究兴趣包括真实感渲染（尤其是在 GPU 上）、视频与图像处理，以及图可视化。

Alexander Keller 于 1988 年至 1993 年在凯撒斯劳滕大学学习计算机科学。之后他加入同一所大学的数值算法组，并于 1997 年 6 月 13 日星期五通过博士论文答辩。1998 年他被聘为 mental images 的科学顾问。2003 年有四个职位向他发出邀请，他选择到德国乌尔姆大学任计算机图形学正教授。他的研究兴趣包括拟蒙特卡洛方法、照片级真实图像合成、光线追踪和科学计算。他 1997 年的 SIGGRAPH 论文「Instant Radiosity」可被视为 GPGPU 计算的源头之一。

Alex 是莫斯科国立大学计算数学与控制论系的本科生。他十岁时对电子游戏产生兴趣，并认定没有别的东西能让他如此着迷。目前他是 NVIDIA 开发者技术团队的成员，为游戏和 GPU 通用计算实现新技术与新效果。

Peter Kipfer 是 Havok 的软件工程师，在 Havok FX 团队工作，该团队在多核 CPU 或 GPU 等高度并行环境中开拓大规模实时物理仿真。他于 2003 年在埃尔朗根-纽伦堡大学获得计算机科学博士学位，论文来自 KONWIHR 超级计算项目。他还曾在慕尼黑工业大学做博士后研究，专注 GPU 上的通用计算与几何处理。

Rusty Koonce 毕业于德克萨斯大学达拉斯分校，获物理学学位。他参与过多个已发行的电子游戏作品，涵盖主机、PC 和 Mac 等多种平台。自他的第一台电脑 TRS-80 起，计算机图形学就一直吸引着他。如今他如今把德克萨斯州奥斯汀当作自己的家，乐于在那里为「Keep Austin Weird」尽一份力。

Kees van Kooten 是 Playlogic Game Factory 的软件开发人员。2006 年他以优异成绩（summa cum laude）在埃因霍温理工大学获得硕士学位。他硕士项目的成果就收录在本书中。他的兴趣与硕士研究的主题密切相关：三维图形与实时仿真。下班之后，Kees 常被看到与「真正的」音乐人一起打鼓。

Jaroslav Křivánek 是布拉格捷克技术大学的助理教授。他于 2005 年在 IRISA/INRIA 雷恩与捷克技术大学获得博士学位（联合学位）。2003 年和 2004 年他是中佛罗里达大学的研究助理。他于 2001 年在布拉格捷克技术大学获得计算机科学硕士学位。

Bunny Laden 于 1989 年在华盛顿大学获得认知科学与音乐方向的特别个人博士（Special Individual Ph.D.）。她于 1997 年加入 Apple，现在为 Quartz、Core Image、Quartz Composer 及其他 Mac OS X 技术撰写文档。她参与撰写了 Programming with Quartz（Morgan Kaufmann，2006）和 Learning Carbon（O'Reilly，2001）。在从前做学者的日子里，她写过关于音乐认知、音乐声学及其他各类主题的文章。

Andrew Lauritzen 最近获得计算机科学数学学士学位，现正在滑铁卢大学完成计算机图形学硕士学位。到目前为止，他在图形学以及理论物理方面完成了多项研究。他目前的研究兴趣包括光照与阴影算法、延迟渲染和图形引擎设计。Andrew 还是 RapidMind 的开发人员，在那里与 GPU 及其他高性能并行计算机打交道。

Scott 是 NVIDIA CUDA 软件团队的资深工程师。他此前的商业项目包括 Atari Jaguar 上的游戏 BattleSphere；Atari ST 上的 Genesis——首个面向家用电脑的分子建模系统；以及 Folderol——首个针对蛋白质折叠问题的分布式计算项目。Scott 自 1971 年在一台大型机上玩到一款星际迷航游戏、并瞬间迷上之后，就一直在写电子游戏。在另一段人生里，他在锡耶纳学院获得生物学学士学位，在宾夕法尼亚州立大学获得生物化学博士学位。此外，他为 ShaderX 写过一章，并参与编辑了一本关于蛋白质结构预测计算方法的书。

Ignacio Llamas 是 NVIDIA 开发者技术组的软件工程师。加入 NVIDIA 之前，Ignacio 是佐治亚理工学院计算学院的博士生，在那里做了计算机图形学多个方向的研究。除了在 NVIDIA 做的令人兴奋的工作，他还喜欢单板滑雪。

Charles Loop 在华盛顿州雷德蒙德的微软研究院工作。他于 1987 年在犹他大学获得数学硕士学位，1992 年在华盛顿大学获得计算机科学博士学位。他的图形研究主要聚焦光滑自由形状的表示与渲染，包括细分曲面、多项式样条与面片，以及代数曲线与曲面。

Charles 还研究交互式建模与计算机视觉技术。近来他的精力投入到用于显示曲面物体的 GPU 算法上。

Tristan Lorach 于 1995 年毕业，获应用于艺术与美学的计算机科学硕士学位，此后他为世界各地的展览与活动开发了一系列三维实时交互装置。从为在虚拟实体中开凿复杂廊道而专门编写引擎，到为公众活动构思新的三维人机界面，Tristan 一直想弥合技术与艺术或人机工程构想之间的差距。他的多数项目（如「L'homme Transformé」和「Le Tunnel sous l'Atlantique」）都在巴黎 Beaubourg 和 Cité des Sciences 等知名展览中心展出。现在 Tristan 在 NVIDIA 的技术开发者关系团队工作，常驻加州圣克拉拉。

David Luebke 是 NVIDIA 的研究科学家。他于 1998 年在北卡罗来纳大学师从 Frederick P. Brooks, Jr. 获得计算机科学硕士与博士学位，此前在科罗拉多学院获得化学学士学位。David 在弗吉尼亚大学任教八年，2006 年离开，参与创办 NVIDIA 研究院。他的研究兴趣包括实时渲染、光照模型和图形体系结构。

Kenny 是 Electronic Arts 英国工作室的首席引擎程序员。他的博士工作引入了在消费级硬件上用实时三维做信息可视化，其中包括一种新颖的递归透视投影技术。过去十年里，他参与发行的游戏采用了体素、PN 面片、置换贴图和 clipmap 等高端图形技术。在为 EA 旗舰哈利·波特系列发行游戏的间隙，他也参与开发新的原创 IP。

Jefferson Montgomery 拥有不列颠哥伦比亚大学的工程物理学士（B.A.Sc.）学位和计算机科学硕士学位。他目前是 Electronic Arts 全球可视化组的成员，任务是把先进技术适配到当前游戏团队面临的资源限制之下，并制作实时演示，例如 2005 年和 2006 年索尼 E3 活动上的那些。

Kevin Myers 在 NVIDIA 开发者技术组工作，帮助游戏开发者充分利用 GPU。他常在 GDC 演讲，并曾在一本 ShaderX 图书中发表文章。他是土生土长的加州人，在圣克拉拉大学获得计算机科学学士学位。他最爱的食物是三明治，尤其是古巴三明治——但得够油才行。

Hubert Nguyen 在 NVIDIA 工作，负责开发者教育项目，帮助开发者推进其应用的图形水平。在此之前，他在 NVIDIA 演示团队工作，寻找能展示最新 GPU 特性的新颖效果。他的作品出现在前几卷 GPU Gems 的封面上。加入 NVIDIA 之前，Hubert 在 3dfx interactive——Voodoo Graphics 的创造者——做开发者技术工程师。他第一次接触 3dfx 是在巴黎一家电子游戏公司 Cryo Interactive 的 R&D 部门做三维引擎的时候。Hubert 于 1991 年开始三维图形编程，当时他参与欧洲 demoscene，他与自己的「Impact Studios」团队在丹麦举办的世界最大 PC 演示竞赛「The Party 1994」上排名第一。

Lars Nyland 是 NVIDIA 的资深架构师，专注于 GPU 体系结构中与计算相关的问题。他在杜克大学获得计算机科学博士与硕士学位（分别为 1991 年和 1983 年）。研究生工作之后，他在北卡罗来纳大学做了 12 年研究，方向是并行计算（语言、编译器、算法与应用）和基于图像的渲染，其间开发了 DeltaSphere 距离扫描仪设备（现由 3rdTech 销售）。2005 年加入 NVIDIA 之前，他是科罗拉多州戈尔登的科罗拉多矿业学院计算机科学副教授。

Oskari Nyman 是赫尔辛基理工大学计算机科学与工程系的本科生。他出身于 mod 圈，十五岁时在那里开始编程。他的兴趣在于实时渲染和一般意义上的游戏编程。

Manuel M. Oliveira 是巴西 UFRGS 的教职人员。他于 2000 年在北卡罗来纳大学教堂山分校获得计算机科学博士学位。加入 UFRGS 之前，他于 2000 年至 2002 年在纽约州立大学石溪分校任助理教授。他的研究兴趣包括实时渲染、表面细节的表示与渲染、表面重建，以及基于图像的渲染。

John D. Owens 是加州大学戴维斯分校电气与计算机工程助理教授，在那里领导图形硬件/软件与 GPGPU 的研究项目。到戴维斯任职之前，John 在斯坦福大学获得电气工程博士（2002）与硕士（1997）学位。在斯坦福，他是 Imagine 流处理器的架构师之一，也是并发 VLSI 体系结构组和计算机图形实验室的成员。John 于 1995 年在加州大学伯克利分校获得电气工程与计算机科学学士学位。

Gustavo Patow 在阿根廷拉普拉塔国立大学获得物理学学位，并在西班牙巴塞罗那加泰罗尼亚理工大学在 Xavier Pueyo 和 Àlvar Vinacua 的指导下获得博士学位。他的论文题目是灯具设计中的反射面逆向设计，目前的研究继续深入逆向渲染这一类问题，以及如何高效利用现代 GPU 实现实时照片级真实渲染。他目前是西班牙赫罗纳大学的副教授。

Fabio Pellacini 是达特茅斯学院计算机科学的助理教授。他的研究聚焦于复杂环境的交互式高质量渲染算法，以及便于美术使用的材质与光照设计算法，以支持更高效的内容创作。进入学术界之前，Pellacini 在 Pixar Animation Studios 研究光照算法，并在多部电影作品中获得署名。Pellacini 在意大利帕尔马大学获得物理学 Laurea 学位，在康奈尔大学获得计算机科学硕士与博士学位。

Fabio Policarpo 是资深软件工程师，正在做 Perpetual Entertainment 的最新项目：Star Trek Online。他毕业于巴西里约的弗鲁米嫩塞联邦大学计算机科学专业，著有几本游戏编程图书，包括 GPU Gems. 中的一章。他的主要研究兴趣与游戏的实时特效相关，包括图形、物理和动画。

Jan Prins 是北卡罗来纳大学教堂山分校计算机科学系的教授兼系主任。他是 Digital Effects Inc. 的共同创始人，并参与过电影 Tron 的制作。Prins 于 1987 年在康奈尔大学获得计算机科学博士学位。自 1987 年起他一直在 UNC 教堂山分校计算机科学系任教，并且是生物信息学与计算生物学项目的成员。

1996 年至 1997 年，他是苏黎世瑞士联邦理工学院理论计算机科学研究所的访问教授，方向是科学计算。他的研究兴趣集中于高性能计算，包括算法设计、并行计算机体系结构、编程语言与应用。

Eric Risser 是哥伦比亚大学计算机科学研究生。此前他就读于中佛罗里达大学，在那里参与实时图形编程与研究近四年。他的专长主要在于以逐像素置换贴图为核心的基于图像的实时渲染技术。他的研究曾在 Symposium on Interactive 3D Graphics and Games、GDC 和 SIGGRAPH 上展示。更多信息请访问 www.ericrisser.com。

Gilberto Rosado 毕业于 DigiPen 理工学院，在那里学习了四年电子游戏编程。在 DigiPen 期间，Gil 担任 2005 年独立游戏节入围作品 Kisses 的图形程序员。Gil 目前在 Rainbow Studios，为精彩的新游戏做图形与技术程序员。他的文章也曾收录在 ShaderX4 一书中。不玩最新游戏的时候，你也许能在健身房看到他在锻炼，或在当地的舞蹈教室练习萨尔萨舞步。

Christophe Schlick 是法国波尔多第二大学计算机科学教授，过去五年一直担任应用数学与计算机科学系主任。他于 1992 年因 BRDF 模型与蒙特卡洛技术方面的研究获得博士学位，其研究兴趣涵盖计算机图形学的许多方面，包括参与介质、过程化纹理、样条与小波曲线曲面、隐式曲面，以及更近期的基于点的建模与渲染。他目前是法国国家计算机科学与控制研究所 INRIA 的高级研究员。

Elizabeth Seamans 于 2005 年在斯坦福大学完成计算机科学博士学业，随后参与创办 Exapath，编写 GPU 加速的扫描库。她现在在 Juniper Networks 做软件工程师，让并行计算资源保持忙碌。

Shubho 是加州大学戴维斯分校计算机科学系的博士生，也是数据分析与可视化研究所的成员。他目前的研究聚焦并行数据结构与算法及其在计算机图形学各领域的应用。Shubho 于 1998 年和 1996 年在印度理工学院克勒格布尔分校先后获得数学硕士与学士学位。

Tiago Sousa 是自学成才的游戏与图形程序员，过去四年在 Crytek 做 R&D 图形程序员。他参与过「Far Cry: The Project」演示，最近参与 Crysis，开发了其中大部分视觉效果，包括水面/水下渲染和所有后期效果，如运动模糊和相机环境效果。加入 Crytek 之前，他在葡萄牙共同创办了一支开拓性的游戏开发团队，并在高等技术学院短暂学习过计算机科学，他希望有一天能完成学业。他把时间大多花在跳出框框思考、发明原创而有创意的技术来做出漂亮画面上。

1998 年 Yury 毕业于乌克兰扎波罗热国立工程学院电子系，专业是微处理器系统。学生时代他就热衷于计算机图形学与底层优化，并决定把这个爱好变成职业。他现在在 NVIDIA 莫斯科办公室工作，参与开发新的图形技术。

Martin Stich 是 mental images 柏林公司的图形软件工程师，为 RealityServer 产品研究渲染算法。他的研究兴趣包括实时渲染、光栅化和光线追踪。2006 年加入公司之前，他为空中交通管制仿真系统开发实时图像生成软件。他拥有乌尔姆大学的计算机科学学位。

Hanqiu Sun 在不列颠哥伦比亚大学获得电气工程硕士学位，在加拿大阿尔伯塔大学获得计算机科学博士学位。她在知名 VR/CG 期刊、图书章节和国际会议上发表了一百多篇经同行评审的技术论文。她曾担任 MIT 的 Presence 和 Journal of Computer Animation and Virtual Worlds 客座编辑、ACM VRST 2002 程序共同主席、Pacific Graphics 2005 与 CGI 2006 组织共同主席、ACM VRCIA 2006 大会主席，以及多个国际程序委员会的成员。她目前的研究兴趣包括虚拟与增强现实、交互式图形/动画、超媒体、计算机辅助手术、基于互联网的导航、远程医疗和真实感触觉仿真。

László Szirmay-Kalos 是布达佩斯技术与经济大学电气工程与信息技术学院计算机图形组的负责人。他于 1992 年获得博士学位，2001 年获得计算机图形学正教授职位。他还曾在赫罗纳大学、维也纳技术大学和明尼苏达大学做客座讲师或研究员。他的研究领域是蒙特卡洛全局光照算法及其 GPU 实现。他就这一主题发表了一百多篇论文、讲义和图书章节。他是 GameTools EU-FP6 项目光照部分的负责人。他是 Eurographics 的成员，曾在执行委员会任职三年。

Sarah 是 NVIDIA 开发者技术团队的软件工程师，主要负责实现利用最新硬件的新渲染与仿真技术，并帮助游戏开发者把这些技术用到自己的游戏中。加入 NVIDIA 之前，Sarah 是佐治亚理工学院的博士生，并在那里获得计算机科学硕士学位。

Diogo Teixeira 是计算机图形学爱好者，对游戏开发尤有兴趣。他对底层二维与三维计算机图形学的兴趣始于高中时期。作为狂热的玩家，他最终在 2000 年初开始游戏开发生涯，加入了一支葡萄牙的先锋团队，制作第三人称动作冒险游戏 Yamabushi。2003 年他担任社区游戏项目 RCmania 的项目负责人，这是一款多平台竞速游戏。2005 年他中断在里斯本大学的学业，加入 Move Interactive，为 PC 和下一代主机开发游戏 Ugo Volt。

Alex Telea 于 2000 年在埃因霍温理工大学获得可视化博士学位，目前在该校任可视化与计算机图形学领域的助理教授。他的主要研究兴趣是数据可视化、基于纹理的渲染方法、图像与数据处理的数值方法、形状简化，以及软件可视化与逆向工程。他在国际出版物上参与发表了 70 多篇论文。

David Thomas 于 2001 年和 2006 年在帝国理工学院先后获得计算机科学硕士与博士学位。他太喜欢帝国理工了，于是留了下来，现在是定制计算组的博士后研究员。研究兴趣包括基于 FPGA 的蒙特卡洛仿真、均匀与非均匀随机数生成的算法与体系结构，以及金融计算。

Ken Turkowski 的职业生涯始于设计用于图形加速的可编程硬件，随后开发能充分发挥该硬件性能的算法。他本质上是一位应用数学家，后来把精力集中于为各种图形应用开发高效软件：纹理映射、抗锯齿、着色、全景图、图像处理、视频变换、相机/镜头建模、碰撞、曲面建模和轮廓字体——先后在 Ampex、Compression Labs、CADLINC、Apple、Media Machines、Fakespace Labs、Adobe 和 Google 等公司工作。他专长于比传统算法更快、更稳健、占用内存更少的算法。他活跃于 SIGGRAPH，是电子剧场的投稿者、论文作者和硅谷分会主席。

Tamás Umenhoffer 是布达佩斯技术与经济大学电气工程与信息技术学院的博士生。他的研究题目是 GPU 上的全局光照效果计算。他的投稿入围了 EG 2006 的 Graphics Meets Games 竞赛。他是 GameTools EU-FP6 项目的活跃成员。

Gino van den Bergen 是 Playlogic Game Factory 的首席程序员。他在埃因霍温理工大学获得计算机图形学博士学位。他是 Collision Detection in Interactive 3D Environments（Morgan Kaufmann）一书的作者。Gino 是碰撞检测软件库 SOLID 的创造者，该库已成功应用于畅销主机游戏和 CAM 应用。

Carsten Wächter 于 1998 年至 2004 年在乌尔姆大学学习计算机科学。之后他在 Alexander Keller 指导下攻读博士，2007 年开始在 mental images 工作。他的研究兴趣包括实时光线追踪、全局光照和拟蒙特卡洛方法。自 1999 年起他一直是欧洲 demo 圈的活跃成员。

Takeshi Yamanouchi 于 1995 年毕业于九州工业大学，获计算机科学硕士学位。同年他加入 SEGA 公司，此后一直在 AM R&D 第 2 部从事街机游戏开发。他最近的工作是 Virtua Fighter 5 的图形、着色器和网络编程。他最新的兴趣是他女儿的脸——她现在一岁了。他想知道自己能否在 60 fps 的实时游戏中实现这种美丽的次表面散射。写这一章时，AMplus R&D 部的 Robert Gould 帮他润色了英文。

Cyril Zeller 在 NVIDIA 开发者技术组工作，探索并推广在现代 GPU 上实现实时图形与仿真的一切新途径，以及 CUDA 开辟的所有新应用领域。加入 NVIDIA 之前，Cyril 在 Electronic Arts 开发游戏。他在法国巴黎综合理工学院获得计算机视觉博士学位。

Fan Zhang 于 2000 年和 2002 年在中国吉林大学先后获得计算数学学士与硕士学位。他目前是香港中文大学计算机科学与工程系的博士研究生。他的主要研究兴趣包括实时阴影渲染和基于 GPU 的渲染技术。

Renaldas Zioma 在 EA/Digital Illusions CE 为即将推出的 Battlefield: Bad Company 研究渲染技术。过去他开发过实时策略游戏、一些上世代主机游戏和无传感器动作识别软件；小时候他甚至用 ZX Spectrum 汇编写过几个小游戏。目前他把业余时间花在自制 PSP 开发套件和 Amiga 1200 上渲染东西，大多与 The Black Lotus demogroup 的人一起。不然他就去徒步了！他此前在 ShaderX2、ShaderX4 和 AI Game Programming Wisdom 3 上发表过文章。
