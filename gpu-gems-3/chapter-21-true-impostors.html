第 21 章　真 impostor

Eric Risser
University of Central Florida

本章介绍真 impostor（true impostors）方法，这是一种把大量简单模型加入任意场景而无需渲染大量多边形的技术。该技术利用现代着色硬件，在纹理定义好的体积内做光线投射。用这种方法，代表非高度场表面数据的多个深度层与四边形关联起来。

与传统 impostor 一样，真 impostor 方法让四边形绕其中心旋转，使其始终面向相机。传统 impostor 技术显示的是静态纹理，而真 impostor 技术不同，它用像素着色器在纹理坐标空间中穿过四边形投射视线，与三维模型求交，并计算交点处的颜色。纹理坐标空间由以四边形中心为原点的坐标系定义。

真 impostor 支持模型上的自阴影、反射与折射，也是一种在体积内求距离的高效方法。

21.1 引言

大多数有意思的环境，无论是自然还是人造的，往往密集分布着大量高度精细的物体。渲染这类环境通常需要庞大的多边形集合，还需要复杂的场景图以及运行它的开销。

作为替代，人们探索了基于图像的技术，为这些局限提供实用的补救。现有的基于图像的技术中，impostor 是一种强大的技术，多年来在图形学界被广泛使用。impostor 是一张二维图像纹理，映射到一块矩形卡片或公告板（billboard）上，制造出高度精细几何体的错觉。impostor 可以即时生成，也可以预计算并存放在内存中。两种情况下，impostor 都只对特定观察方向准确。当视角偏离这一理想条件时，impostor 便失去准确性。同一个 impostor 会被反复使用，直到其视觉误差超过某个给定的任意阈值，才被替换为更准确的 impostor。

真 impostor 方法利用最新图形硬件，实现随任意观察角度逐帧更新的准确几何表示。真 impostor 建立在此前逐像素置换贴图技术的基础之上。它还把「为任意表面添加视觉上准确的次表面特征」这一目标扩展为在公告板上生成完整的三维物体。真 impostor 方法与以往的逐像素置换贴图 impostor 方法的区别在于，它不限制观察，同时还提供性能优化与真正的多次折射。

21.2 算法与实现细节

一张四通道纹理可以存放四个高度场，从而表示许多体积。加入更多纹理数据就能扩展到任意形状。我们生成一块公告板（即始终面向相机的四边形），作为从任意给定方向观察我们高度场的窗口，如图 21-1 所示。

图 21-1b 中的图像展示了公告板纹理坐标在变换成三维平面、并绕位于中心的函数（模型）（以那颗小行星表示）旋转之后的情形。图 21-1a 显示了函数中将会显示在我们公告板上的那个视角，图 21-1c 则显示了表示我们这颗小行星的函数（以位图形式）。

要展开这一概念，见图 21-2。在图 21-2a 中，我们看到该方法在世界空间中处理几何体的部分。相机正在观察一个四边形，该四边形经过旋转，使其法线为相机与四边形中心之间生成的向量。如图所示，纹理坐标被赋给每个顶点。图 21-2b 揭示了纹理空间——传统上是二维空间，我们在此加上第三维 W，并把 UV 坐标偏移 –0.5。在图 21-2c 中，我们只是把纹理坐标的 W 分量设为 1。

要记住，纹理贴图只有 UV 分量，因此被约束在两个维度上，只能在 UV 平面内平移，任何 W 值都引用同一个点。虽然被约束在 UV 平面内，纹理贴图仍可表示体积数据：把构成一个像素的四个变量各自视为 W 轴上的点即可。在图 21-3 中，我们可以看到纹理体积向三维空间的投影。每个顶点的纹理坐标绕原点旋转——与我们原来的四边形绕其原点旋转的方式相同——从而生成公告板。

现在我们把这个概念中的视线引入进来。视线由从相机向每个顶点投射一条光线产生。光栅化过程中，存放在每个顶点中的纹理坐标与视线都会在四边形被片元化的表面上插值。这在概念上类似于光线投射或光线追踪，因为我们现在有了一屏原点，每个点都有一个对应的向量来定义一条光线。还应注意，每条单独的光线在纹理贴图平面上都投影为一条直线，因此会从三维体积中切出一个二维切片，用于求交计算。这在图 21-3 中有详细展示。

此时有两种不同的选择，取决于所需的材质类型。对不透明物体，光线投射是现有最快也最准确的选择。Policarpo 与 Oliveira 2006 给出了这一选择的一种精简做法，使用光线步进后接二分搜索，如图 21-4 所示。图 21-4a 展示了线性搜索的实际运作。视线按固定间隔被测试，看它是否已与某个体积相交。一旦找到第一个交点，就把该点与前一个点用作二分搜索空间的起点与终点。随后反复把这个空间对半分，直到找到进入体积的精确交点。

由于 GPU 设计的特性，从效率角度讲提前跳出循环并不现实；因此无论第一次碰撞在搜索中多早被发现，都必须执行完最大数量的光线步进与纹理读取。与其忽略这些「免费」得到的数据，我们提出一种方法，通过局部近似为半透明材质类型添加渲染支持。我们不在视线方向上做二分搜索，而是用 W 轴上的点为每个高度场定义一个线性方程。然后按与 Tatarchuk 2006 中类似的方式，测试这些线性方程与视线的交点。

如图 21-5 所示，落在上下两个边界点之间的交点被保留为最终交点。由于材质是半透明的，我们为该点检查法线。此外，视线按折射率发生折射，该折射率可以是着色器中的常量，也可以存放在某张纹理贴图的额外颜色通道里。得到新的视线方向后，光线步进继续，对后续穿透的任何表面重复该过程。把穿过各个体积所走的距离累加，我们就能确定穿过模型的总距离，并用它计算该像素的透明度。

21.3 结果

真 impostor 方法的表现与其他逐像素置换贴图技术相当。不过这个方法有一些独有的问题：例如性能依赖于填充率。此外，公告板之间会相互遮挡，所以在 CPU 上做深度排序对避免过度绘制至关重要。

另一方面，由于真 impostor 方法依赖填充率，细节层次是内禀的，这是一大优点。

用真 impostor 方法，你在同一屏上能表示的几何体比标准多边形手段更多。图 21-6 展示了一个 Jupiter 模型，用 25 万颗小行星构成它的环。该技术用 C++ 与 DirectX 9 实现。所有基准测试都在一块 NVIDIA GeForce 6800 Go GPU 以及两块以 SLI 运行的 GeForce 7800 GPU 上取得。

尽管顶点处理器对该方法至关重要，但由此产生的操作并不会使顶点处理单元过载，也不会明显降低性能。该技术的性能主要取决于片元处理单元的速度、屏幕上的像素数、每个像素的搜索步数以及渲染技术的选择。做光线投射时，性能与 Policarpo 与 Oliveira 2006 相当，因为两种方法所用的光线投射技术相似。表 21-1 以「光线投射」一栏给出该技术的性能。

21.4 小结

真 impostor 是在 GPU 上渲染大量动态、不透明、具反射或折射特性物体的一种快速高效方法。它生成的 impostor 渲染误差很小，并自带逐像素的细节层次。把体积数据表示为存放在传统纹理贴图中的多个高度场，就利用了现代 GPU 的向量处理特性，在内存需求很低的情况下获得高帧率。

我们放弃了那些使逐像素置换贴图本质上只能是次表面细节技术的限制，从而得到一种能渲染数量惊人的伪几何体的新方法。我们做到这一点，靠的不是模糊光栅化与光线追踪之间的界线，而是采用一种混合做法，取两者各自的长处。
