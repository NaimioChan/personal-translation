第 13 章　作为后处理的体积光散射

Kenny Mitchell
Electronic Arts

本章介绍一种简单的后处理（post-process）方法，用于产生大气中阴影造成的体积光散射效果。我们改进了一个现有的日光散射解析模型，把体积遮蔽的影响纳入其中，并给出了它在像素着色器中的实现。随书 DVD 中的演示表明，这项技术可以应用于任意场景复杂度、任意动画化的图像。演示的截图见 图 13-1。

13.1 引言

在现实世界中，我们很少在真空中观察事物，即物体与观察者之间空无一物。在实时渲染中，参与介质对光传输的影响常常被简化为低复杂度的均匀假设。这是因为在复杂的交互式动画环境中，要考虑发射、吸收与散射的辐射传输方程（Jensen and Christensen 1998）难以求解。本章我们考虑大气中体积阴影对光散射的影响，并说明如何用一个 GPU 像素着色器后处理，对一个或多个图像光源实时计算这一效果。

13.2 曙暮光条

在合适的条件下，当空间中充满足够稠密的散射介质混合物（例如气体分子和气溶胶）时，遮挡光的物体会投出体积阴影，看上去就像从光源辐射出的光条。这类现象有各种名称：曙暮光条、太阳光束、日冕光、星芒、耶稣光或光轴。在阳光中，这些体积实际上是平行的，但在透视下看起来像从太阳处散开。

渲染曙暮光条最早是在非实时渲染中用改进的阴影体算法解决的（Max 1986），不久之后又发展了针对多光源的方法（Nishita et al. 1987）。这个话题后来在实时渲染中重新被研究，采用了基于切片的体渲染技术（Dobashi et al. 2002），最近又用硬件阴影贴图实现（Mitchell 2004）。不过基于切片的体渲染方法可能出现采样瑕疵、要求高填充率，还需要额外的场景设置。阴影贴图方法虽然提高了效率，但在这里同样有基于切片方法的缺点，并且需要更多显存资源和渲染同步。另一种实时方法基于 Radomir Mech（2001）的工作，使用多边形体积（James 2003），其中重叠的体积用帧缓冲混合配合深度剥离累加。一个类似的方法（James 2004）利用累积的体积厚度，免去了深度剥离的需要。在我们的做法中，我们施加逐像素的后处理操作，不需要预处理或其他场景设置，并且能在任意复杂度的动画场景中生成细致的光轴。

在先前的工作（Hoffman and Preetham 2003）中，实现了一个用于均匀介质光散射的 GPU 着色器。我们在此之上扩展了一个后处理步骤，以计入体积阴影。这个后处理的基本形态可以追溯到一种图像处理操作——径向模糊，它出现在许多 CG 演示作品中（Karras 1997）。虽然这类演示用软件光栅化来施加后处理效果，我们则用硬件加速的着色器后处理，以便基于日光解析模型进行更复杂的采样。

由于采样完全来自源图像，半透明物体无需额外工作就能处理。多个光源可以通过对每个投射光线的光源依次施加加性的屏幕空间渲染遍来实现。虽然这里的解释中我们用的是自己的日光解析模型，但实际上任何图像光源都可以使用。

对于太阳位置 与每个屏幕空间图像位置 ，我们沿射线向量以等间隔从源图像连续采样来实现求和，其中 = (-)/n(density)。这里引入 density 是为了控制采样之间的间距，用于我们想减少总的采样迭代次数、同时保持足够无走样的采样密度的情形。增大密度因子会减小采样间距，结果光轴更亮但覆盖范围更短。

在 图 13-2 中，来自 1 的采样都没有被遮挡，按常规方式求 L(s,) 得到最大的散射照明。在 2 处，射线上有部分采样打到建筑，因此累积到的散射照明较少。通过对图像中每个像素投射的射线求和，我们生成了包含被遮挡光散射的体积。

我们可以对源图像降采样来降低带宽需求。配合滤波，这会减少采样瑕疵，同时因滤波核而通过邻域采样引入一份局部散射贡献。在演示中，一个基本的双线性滤波就足够了。

13.4 后处理像素着色器

这项技术的核心是代码清单 13-1 给出的后处理像素着色器，它实现公式 4 的简单求和。

给定初始图像，沿从像素位置射向屏幕空间光源位置的射线生成采样坐标。[1] 屏幕空间中的光源位置由标准的 world-view-project 变换算出，再经缩放与偏移得到 [-1, 1] 范围内的坐标。公式 4 求和中的连续采样 L(s, , i ) 会同时乘以 weight 常数与指数 decay 衰减系数，以便参数化地控制效果。采样之间的间距，即 density，可以调整；作为最后一项控制因子，合并后的颜色再乘以一个常数衰减系数 exposure。

示例 13-1. 加性采样的后处理着色器实现


float4 main(float2 texCoord : TEXCOORD0) : COLOR0
{
  // 在屏幕空间中计算从像素指向光源的向量。
  half2 deltaTexCoord = (texCoord - ScreenLightPos.xy);
  // 除以采样数，再乘以控制系数。
  deltaTexCoord *= 1.0f / NUM_SAMPLES * Density;
  // 保存初始采样。
  half3 color = tex2D(frameSampler, texCoord);
  // 设置光照衰减因子。
  half illuminationDecay = 1.0f;
  // 按公式 3 做 NUM_SAMPLES 次迭代求和。
  for (int i = 0; i < NUM_SAMPLES; i++)
  {
    // 沿射线推进采样位置。
    texCoord -= deltaTexCoord;
    // 在新位置取出采样值。
    half3 sample = tex2D(frameSampler, texCoord);
    // 应用采样的衰减缩放/衰减因子。
    sample *= illuminationDecay * Weight;
    // 累加合成颜色。
    color += sample;
    // 更新指数衰减因子。
    illuminationDecay *= Decay;
  }
  // 输出最终颜色，再乘上一个控制缩放系数。
  return float4(color * Exposure, 1);
}

13.5 屏幕空间遮蔽方法

如前所述，屏幕空间中的采样并不是纯粹的遮蔽采样。表面纹理的变化可能导致不理想的条纹。所幸我们可以用以下措施来处理这些不良效果。

13.5.1 遮蔽预渲染遍方法

如果我们把遮挡物体以黑色、无纹理的方式渲染进源帧缓冲，那么生成光线条的图像处理就在这张图上进行。之后用常规着色渲染场景中的遮挡物体，再把后处理结果以加性方式混合进场景。这种做法与常见的先渲染一遍无着色深度预渲染遍、以限制完整着色像素的深度复杂度的手法相辅相成。图 13-3 展示了所涉及的步骤。

13.5.2 遮蔽模板方法

在较早的图形硬件上，不用预渲染遍也能达到同样效果：使用模板缓冲或 alpha 缓冲。图像中的主要发光元素（例如天空）照常渲染，同时置一个模板位。然后渲染场景中的遮挡物体，不置模板位。施加后处理时，只有置了模板位的那些采样才参与加性混合。

13.5.3 遮蔽对比度方法

同样地，这个问题也可以通过降低纹理对比度来管理：借助纹理内容、雾、空气透视，或者朝光源方向时效果强度增大所对应的光适应。任何降低遮挡物体照明频率与对比度的做法都会减轻条纹瑕疵。

13.6 注意事项

虽然能取得有说服力的结果，但这个方法并非没有局限。在处理相对较近的光源时，来自背景物体的光轴可能出现在前景物体之前，如 图 13-4 所示。在完整的辐射传输解中，前景物体会正确地遮住背景的光轴。这一现象没有想象中那么显眼，原因之一是它可以被感知为相机镜头效果的表现——光散射发生在场景之前的一层里。存在高频纹理物体时，这个瑕疵也能减轻。

当遮挡物体越过图像边界时，光轴会闪烁，因为它们超出了可见采样的范围。要减轻这个瑕疵，可以在屏幕周围渲染一个扩展区域，以增大可寻址采样的范围。

最后，当视线垂直于光源方向时，光源的屏幕空间位置可能趋于无穷远，从而导致采样间距过大。这可以通过把屏幕空间位置钳制到合适的保护带区域来减轻。另一种做法是让效果随接近垂直而淡出，使用遮蔽方法时还会进一步减弱。

13.8 扩展

可以在较低分辨率上采样，以降低纹理带宽需求。进一步的改进是用随机采样改变采样模式，从而在采样密度降低的地方减少规则图案瑕疵。

我们的方法在一次着色器执行中完成整个后处理。在一项多遍做法中，像素着色器的求和可以在这样的方式下进行：把从光源发出的同心矩形环带的结果累加到相邻的外层环带中，即 L(s, , ) = Li - 1(s, , ) + Li (s, , )。虽然这未必最适合当前的硬件设计，但这样做所需的采样与计算量已经是最低限度。

在光轴强度与避免过饱和之间取得平衡，需要调整衰减系数。一个执行光适应、使图像影调保持一致的解析公式，或许能提供一种自动获得一致观感图像的方法。例如，我们也许可以评估图像整体的平均、最小与最大照明的组合，然后施加一条校正色阶，从而避免图像过度泛光或过于阴郁。

13.9 小结

我们展示了一种简单的后处理方法，用于产生大气中阴影造成的体积光散射效果。我们扩展了一个现有的日光散射解析模型，纳入体积遮蔽的贡献，并描述了它在像素着色器中的实现。演示表明这是一种实用技术，可以应用于任意场景复杂度、任意动画化的图像。
