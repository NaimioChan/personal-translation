25.1 引言

向量表示是一种与分辨率无关的形状描述方式。其优点在于，无论什么比例，内容显示时都不会出现剖分或采样瑕疵。这与由颜色值数组构成的光栅表示形成鲜明对比。光栅图像在缩放或透视映射下很快就会出现瑕疵。本章的目标是给出一套在 GPU 上加速向量表示渲染的方法。

现代图形处理器擅长渲染三角形以及光滑物体的三角形近似。想到同一架构也理想地适合渲染光滑的基于向量的物体，多少有些意外。一个向量物体包含若干层闭合路径与曲线。这些路径与曲线通常是绘图程序输出的二次与三次贝塞尔样条曲线。我们给出直接按样条的数学描述渲染这些曲线的方法，使其与分辨率无关，几何表示也最小。

我们算法的核心概念是隐式化：从参数式 [x(t) y(t)] 变换为隐式平面曲线 f (x, y) = 0。我们把贝塞尔控制点的凸包当作多边形渲染，由像素着色器程序求值曲线的隐式形式，判定像素是否落在曲线内。借助 GPU 的插值功能并选出恰当的隐式形式，这一过程变得非常高效。除了在像素处回答内/外查询，我们还演示了一种用硬件梯度对这些曲线做抗锯齿的机制。本章的大部分工作最初发表于 Loop 与 Blinn 2005。

25.2 二次样条

理解我们算法最好的方式，是用一个简单例子说明它怎么工作。考虑 图 25-1 中的字母「e」。图 25-1a 展示了用于描述这个字体字形的 TrueType 数据。TrueType 结合使用二次 B 样条与线段来指定一条有方向的向量轮廓。按惯例，曲线右侧的区域被视为内部。空心点是定义曲线的 B 样条控制点；实心点是曲线上的点，可以定义尖角这类不连续处。作为预处理，我们在相邻 B 样条控制点的中点处插入新点，把 B 样条表示转换为贝塞尔形式。每个 B 样条控制点将对应一条二次贝塞尔曲线。接着我们把闭合路径的内部三角化，并为每条二次贝塞尔曲线形成一个三角形。三角化之后，我们就有了内部三角形（绿色所示）以及含曲线的边界三角形（红、蓝所示），见 图 25-1b。

内部三角形正常填充渲染。含曲线的三角形则按曲线哪一侧是闭合区域内部而分别为凸或凹。见 图 25-1b 中的红色与蓝色曲线。

我们用一个着色器程序判定像素是在闭合区域的内部还是外部。在进入这个着色器之前，必须给含曲线的三角形的顶点指定 [u v] 坐标。一个例子见 图 25-2。当这些三角形在任意三维投影变换下渲染时，GPU 会对这些坐标做透视校正插值，并把得到的 [uv] 值提供给像素着色器程序。我们不像纹理映射那样查找颜色值，而是用 [u v] 坐标求值一张过程化纹理。像素着色器计算表达式

u 2 - v，

并用结果的符号判定像素是否被包含。对凸曲线，结果为正意味着像素在曲线之外；否则在曲线之内。对凹曲线，这一判定相反。

所得表示的规模与边界曲线描述的规模成正比。生成的图像没有剖分或欠采样造成的任何瑕疵，因为位于曲线区域之下的所有像素中心都被着色，不多不少。

这个算法之所以成立，直觉上的解释如下。过程化纹理坐标 [0 0]、[½ 0] 和 [1 1]（如 图 25-2 所示）本身就是该曲线的贝塞尔控制点

u(t) = t,

v(t) = t 2.

这显然是代数（隐式）曲线 u 2 - v = 0 的一种参数化。设 P 是从 u、v 空间经曲线设计（字形）空间、观察与透视空间到屏幕空间的复合变换。最终它是一个从 2D 到 2D 的投影映射。任何投影到屏幕空间的二次曲线段都会有这样一个 P。GPU 插值纹理坐标时，实际上是在为每个像素计算 P-1 的值。因此，我们可以在隐式方程简单的 u、v 空间中完成内外判定，只需一次乘法和一次加法。

另一种做法是在屏幕空间求出每个曲线段的代数方程。但计算一般的二阶代数曲线系数需要几十次算术运算，在对应的像素着色器中求值也要很多运算。而且这条曲线的系数会随观察变换改变，需要重新计算。我们的方法除了由 GPU 插值 [u v] 过程化纹理坐标之外，不需要任何逐帧处理。

二次曲线其实是一个非常简单的特例。所有（整）二次曲线分配过程化纹理坐标的方式都相同，着色器方程也简单紧凑。不过，产出矢量美术作品的绘图软件往往使用更灵活、更平滑的三次样条。接下来我们把渲染算法扩展到三次曲线。好消息是运行时的着色器方程同样简单紧凑；坏消息是预处理——即分配过程化纹理坐标——并不简单。

25.3 三次样条

我们渲染三次样条曲线的算法在思路上与渲染二次曲线类似。带方向的闭合路径由三次贝塞尔曲线段构成，每段包含四个控制点，见图 图 25-3a。我们约定曲线的右手侧为内部。这些控制点的凸包构成一个由两个三角形组成的四边形，或单个三角形。与之前一样，我们对路径内部做三角剖分，如 图 25-3b 所示。内部三角形正常填充并渲染。有意思的部分在于如何推广我们用于二次曲线的过程化纹理技术。

与参数化二次曲线不同，参数化三次平面曲线并不都射影等价。也就是说，不存在一条所有其他曲线都能由它投影得到的原型曲线。众所周知，所有有理参数平面曲线都有一条同次的代数曲线与之对应。参数三次曲线的代数形式属于三种射影类型之一（Blinn 2003），如 图 25-4 所示。任意三次曲线都可以归类为蛇形线、尖点线或自环线。而且存在一个射影映射，能把任意参数三次曲线变换为这三种曲线之一。把曲线的贝塞尔控制点在该变换下映射，就得到这三种曲线之一某一段的贝塞尔参数化。

关于三次曲线的一个很古老的结果（Salmon 1852）指出，三种类型的三次曲线都有一种可写成如下形式的代数表示

k 3 - lmn = 0,

其中 k、l、m、n 是分别对应直线 k、l、m、n 的线性泛函，如图 图 25-4 所示。（直线 n 为何没有出现在 图 25-4 中，稍后就会清楚。）更具体地说，k = au + bv + cw，其中 [u v w] 是平面中某点的齐次坐标，而 k = [a b c] T 是直线的坐标；l、m、n 同理。直线 k、l、m、n 与曲线 C(s, t) 的关系有重要的几何意义。蛇形线在 k ∩ l、k ∩ m 和 k ∩ n 处有拐点，并分别与直线 l、m、n 相切。自环线在 k ∩ l 和 k ∩ m 处有二重点，并在此点与直线 l 和 m 相切；k ∩ n 对应一个拐点。尖点线在重合的直线 l 与 m 同 k 相交处有尖点，并在此点与直线 l = m 相切；k ∩ n 对应一个拐点。

过程化纹理坐标就是 k、l、m、n 四个泛函在每个三次贝塞尔控制点处的取值。渲染（已三角剖分的）贝塞尔凸包时，GPU 会插值这些坐标，并调用像素着色器程序求值着色器方程 k 3 - lmn。根据结果的符号即可判定像素在曲线内部还是外部。

我们在齐次坐标下工作，平面中的点用三元组 [x y w] 表示，二维笛卡儿坐标为 x/w 和 y/w。我们还使用齐次的曲线参数化，参数值用数对 [s t] 表示，一维标量参数为 s/t。采用齐次表示，是因为射影几何中无穷远点的概念由 w = 0 刻画；同样，参数值无穷大出现在 t = 0 时。

原则上，这样定义的任意平面三次贝塞尔曲线都可以渲染；不过为了简化算法的推导与实现，我们做了一些假设。第一，贝塞尔控制点是仿射的，即 w = 1。这意味着曲线必须是整曲线而不是有理曲线。这不是严重的限制，因为大多数绘图工具只支持整曲线。对于整三次平面曲线，我们仍能渲染出正确的投影图像，但在定义该曲线的平面内它不能是有理曲线。对整曲线而言，直线 n = [0 0 1]，即无穷远直线。图 25-4 中三条三次原型曲线都有整表示，所以直线 n 不出现。对应无穷远直线的线性泛函是 n = 1，于是着色器方程简化为

k 3 - lm.

虽然这只在着色器里省下一次乘法，但它为顶点去掉了整整一个纹理坐标，有可能因此得到更高效的代码。不过，假设曲线是整曲线的主要目的是简化曲线分类。第二个假设是控制点坐标是精确的浮点数。这个假设并非严格必需，但它能让我们避开相等性测试中可能出现的浮点舍入误差。这对应于控制点位于规则网格上的交互式绘图场景。

25.3.3 尖点线

尖点出现在 discr(I) = 0 时。这是蛇形线与自环线两种情况之间的边界。在几何上，直线 l 与 m 重合，因此 [ls lt] = [ms mt]。自环线或蛇形线的流程都可以用，因为纹理坐标矩阵最终会相同。

有一个例外：d 1 = 0 时。在蛇形线和自环线两种情况下，必然有 d 1 ≠ 0；否则 discr(I) = 0，得到的就是尖点线。d 1 = 0 而 d 2 ≠ 0 的情形对应一条在参数值 [1 0]——即齐次意义下的无穷远——处有尖点的三次曲线。此时拐点多项式简化为

I(s, t) = t 2(d 3 t - 3d 2 s),

它在无穷远处有二重根，并在 [ls lt] = [d 3 3d 2] 处有单根。由此得到

25.4 三角剖分

为简明起见，25.2 节和 25.3 节只简要讨论了三角剖分流程。一个此前未提到的重要细节是：贝塞尔凸包不能相互重叠。原因有两个：一是重叠的三角形会给三角剖分代码带来麻烦；二是一个填充区域中不需要的部分可能透到另一个区域里，造成可见瑕疵。把其中一条有问题的曲线剖分，使贝塞尔曲线凸包不再重叠，即可解决该问题，如图 图 25-6 所示。

我们对所有不重叠的贝塞尔凸包做局部三角剖分。对二次曲线，贝塞尔凸包必定是三角形。对三次曲线，贝塞尔凸包可能是四边形或三角形。若是四边形，我们任选一条对角线剖分成三角形。接着对整个边界内部做三角剖分。该流程的细节超出本章范围。任何适用于多轮廓多边形的三角剖分流程都可以用。

最近 Kokojima 等 2006 针对二次样条提出了我们方法的一个变体，用模板缓冲来避免三角剖分。他们的思路是把曲线路径上的所有点连接起来，以三角扇形式用反转算子画进模板缓冲。只有被绘制奇数次的像素非零，从而得到凹处和空洞的正确图像。接着他们绘制曲线段，把它们全部当作凸二次图元。这会为形状加上或挖去一段弯曲部分。然后画一个足以覆盖模板缓冲范围的四边形，带模板测试地写入帧缓冲。结果与我们的相同，但不需要三角剖分或剖分，且只需一种二次曲线方向。此外，去掉三角剖分步骤使动态曲线的高性能渲染成为可能。他们方法的缺点是要对曲线数据做两遍处理。对静态曲线来说，他们是用性能换实现开销。

25.5 抗锯齿

我们给出一种在像素着色器中基于曲线边界的符号距离近似来做抗锯齿的方法。通过降低包含边界的窄带内像素的不透明度，可以近似与滤波核的卷积。不过这只在边界两侧都有像素采样时成立，例如完全位于曲线贝塞尔凸包内部的点。对于靠近三角形边、或三角形边本身就是边界的位置，这套方案就失效了。幸运的是，这种情况恰好由硬件的多重采样抗锯齿（MSAA）处理。MSAA 使用覆盖率掩码，其值由三角形覆盖的采样点百分比（采样图样取决于硬件）给出。只发起一次像素着色器调用，并且可以选择把它放在被覆盖采样点的质心而不是像素中心，以避免在纹理空间中采到三角形图像之外。在我们的情形中，采到色域之外不是问题，因为我们用过程化方式（代数方程）定义纹理。因此不建议使用质心采样。

对贝塞尔凸包内部弯曲边界的抗锯齿，我们需要知道当前像素到边界的屏幕空间符号距离。若该距离在 ±½ 像素以内（这是凭经验确定的取值，也可以更小或更大），就根据像素到弯曲边界的距离改变该像素颜色的不透明度。计算到 d 次多项式曲线的真实距离需要求解一个 2d - 1 次方程。出于性能考虑，这在当今硬件上不现实。

25.6 代码

代码清单 25-1 是我们的二次曲线着色器的 HLSL 代码。三次着色器的代码类似。

示例 25-1. 二次曲线像素着色器


float4 QuadraticPS(float2 p : TEXCOORD0, float4 color : COLOR0) : COLOR
{
  // 梯度
  float2 px = ddx(p);
  float2 py = ddy(p);
  // 链式法则
  float fx = (2 * p.x) * px.x - px.y;
  float fy = (2 * p.x) * py.x - py.y;
  // 有符号距离
  float sd = (p.x * p.x - p.y) / sqrt(fx * fx + fy * fy);
  // 线性 alpha
  float alpha = 0.5 - sd;
  if (alpha > 1)
    // 内部
    color.a = 1;
  else if (alpha < 0)
    // 外部
    clip(-1);
  else
    // 近边界
    color.a = alpha;
  return color;
}

25.7 结论

我们给出了一种渲染矢量美术作品的算法，这些作品由包含二次和三次贝塞尔曲线的闭合路径定义。我们对每个贝塞尔凸包做局部三角剖分，并对每条路径的内部（右手侧）做整体三角剖分。我们为每个贝塞尔凸包的顶点分配过程化纹理坐标。这些坐标编码线性泛函，在光栅化过程中由硬件插值。插值过程把过程化纹理坐标映射到一个空间，在那里曲线的隐式方程具有简单形式：二次曲线为 u 2 - v = 0，三次曲线为 k 3 - lm = 0。像素着色器程序求值该隐式方程。结果的符号决定像素是在内部（负）还是外部（正）。我们用硬件梯度近似到曲线边界的屏幕空间符号距离，并用该符号距离对弯曲边界做抗锯齿。我们可以施加任意投影变换，在 3D 中观察这些平面曲线。结果占用的内存很小且是固定的，得到的图像与分辨率无关。图 25-7 展示了用我们的技术以透视方式渲染的一些文字。

未来我们想把这套渲染范式扩展到 4 次及更高次的曲线。这样就可以对低次形状（例如字体字形）施加自由变形，而得到的高次曲线仍与分辨率无关。Kokojima 等 2006 的工作展示了如何渲染动态二次曲线；我们想进一步把他们的方法扩展到三次曲线。由于过程化纹理坐标分配阶段的存在，这比二次情形复杂得多。不过，借助配备几何着色器的 DirectX 10 级硬件（Blythe 2006），应该可以完全在 GPU 上完成。
