第 17 章　稳健的多次镜面反射与折射

Tamás Umenhoffer
布达佩斯技术与经济大学

Gustavo Patow
赫罗纳大学

László Szirmay-Kalos
布达佩斯技术与经济大学

本章介绍一种在 GPU 上计算单次与多次反射、折射的稳健算法。为了让片元着色器在寻找二次光线命中点时能访问整个场景的几何描述，我们先把场景渲染进一张分层距离贴图。每一层以一张立方体贴图的形式存放在纹理内存中。这些立方体贴图的纹素不仅包含颜色信息，还包含到参考点的距离与表面法线，因此纹素可以看作场景的采样表示。算法在这份表示中搜索以追踪二次光线。搜索过程从光线步进开始，确保不漏掉任何光线与表面的交点，再用割线搜索保证精度。

介绍完追踪二次光线的一般机制之后，我们给出应用，包括曲面上的单次与多次反射和折射。为计算多次反射与折射，程序读取距离贴图中存放的法线向量，用来生成反射/折射光线。这些高阶光线由片元着色器追踪，方式与追踪第一次反射光线类似。反射光线的强度按一个简化的菲涅尔公式计算，该公式对金属同样适用。得到的算法实现简单、可实时运行，精度足以渲染自反射。我们提出的方法在实现上需要动态分支支持。

17.1 引言

图像合成计算通过虚拟相机各像素可见的点的辐亮度。局部光照模型依据位置、法线向量、材质数据等局部属性，再加上全局光源参数来计算辐亮度。每个点独立着色，这为并行计算开启了大量可能。当前 GPU 大量利用这种独立并行的着色思路，其诱人性能正来自局部光照模型所允许的并行架构。不过，对理想反射体与折射体，一个点的辐亮度还取决于其他点的光照，因而点无法独立着色。这意味着，计算一个点的辐亮度会递归地产生新的可见性与颜色计算任务，以确定间接光照的强度。

求解某点在某个方向上的可见性问题，基本操作是投射一条光线。要得到完整的路径，我们应在命中点继续追踪光线，得到第二个点以及更多散射点。GPU 对同源光线的追踪非常高效：从共同的出发点「拍一张照片」，用片元着色器单元计算可见点的辐亮度。这一摄影过程包括把场景几何光栅化，并利用 z 缓冲找出穿过各像素的光线的首次命中。

这种方式对主光线很理想，但对辐亮度中镜面反射与折射项所需的二次光线不适用，因为这些光线并不共享同一出发点。要追踪这些光线，片元着色器必须能访问场景。由于片元着色器可以访问全局（即 uniform）参数与纹理，只要把场景几何存进 uniform 参数或纹理，这一要求就能满足。

场景物体可以编码为表面方程的一组参数，类似经典光线追踪的做法（Havran 2001、Purcell et al. 2002 与 Purcell et al. 2003）。如果场景几何过于复杂，可以用简单的代理几何体，以支持快速的近似求交（Bjorke 2004 与 Popescu et al. 2006）。

另一方面，场景几何也可以按采样形式存放。这一想法最古老的应用是阴影算法所用的深度贴图（Williams 1978），它存放从光源位置透过一扇窗口所看到的几何体部分在光照空间中的 z 坐标。

要考虑所有方向，就应使用立方体贴图而非单张深度图像。若在纹素中存放世界空间的欧氏距离，立方体贴图就变得类似球面贴图（Patow 1995 与 Szirmay-Kalos et al. 2005）。这样，一对方向与距离值就指定了该方向上的可见点，无需知道立方体贴图各面的朝向。这条性质在两个方向之间插值时尤为重要，因为它省去了处理立方体贴图面边界的工作。存放距离值的立方体贴图称为距离贴图。

深度或距离立方体贴图只表示从生成该贴图所用的眼位置直接可见的表面。这个眼位置称为贴图的参考点。为了也包含被参考点遮挡的表面，我们应生成并存放距离贴图的多个层（在纹素中不仅存最近的点，而是存该方向上的所有点）。

本章介绍一种简单而稳健的光线追踪算法，用于计算与存放在分层距离贴图中的几何体求交。注意这张贴图是场景几何的采样表示。因此追踪光线时，求交计算可以使用这些信息而不必用三角网格。片元着色器可以查纹理，却无法直接访问网格，所以这一替换对 GPU 实现至关重要。在我们的方法中，光线追踪可以支持查找路径上的第二、第三次（等等）命中点，而第一个点由光栅化确定。我们的方法可以看作对环境贴图的扩展，因为它把距离信息放进纹素，以获得更准确的光线-环境求交。

这套追踪二次光线的稳健机制可用于实时计算多次反射与折射。

17.2 追踪二次光线

所提出的光线追踪算法处理存放在分层距离贴图中的几何体。分层距离贴图的单层是一张立方体贴图，其中纹素存放该纹素方向上的点的材质属性、距离与法线向量。材质属性对漫反射表面是反射辐亮度，对镜面反射体是垂直入射时的菲涅尔因子。对折射体，折射率也作为材质属性存放。距离从立方体贴图的中心（即参考点）量起。

17.2.1 生成分层距离贴图

计算距离贴图与计算经典环境贴图类似。我们把场景渲染六次，以参考点为眼、以立方体的各面为窗口矩形。不同之处在于，不只是计算并存放颜色到额外的立方体贴图，还要存距离与法线向量。利用多渲染目标特性，我们可以在单个渲染遍中生成存放颜色的纹理，以及编码法线向量与距离的纹理。

一般情形下，表示场景的那组层可以用深度剥离得到（Everitt 2001 与 Liu et al. 2006）。为了控制层数，我们可以限制剥离遍数，这样无论远处的物体是否相互遮挡，它们都被放进同一层，如图 17-1 所示。如果远处物体的距离显著大于反射物体本身的尺寸，这种近似是可以接受的。

对比较简单、且与环境相距不太近的反射物体，层的生成可以进一步简化。把参考点放在反射物体的中心，把反射物体的正面与背面分别渲染进两层。注意这种方法可能填不满某一层的所有纹素，因此有些纹素可能不代表任何可见点。如果渲染前用负距离值清空渲染目标，那么不含可见点的无效纹素之后可以通过检查距离的正负来识别。

场景物体运动时，距离贴图需要更新。

17.2.2 在分层距离贴图中追踪光线

基本思路借助图 17-2 的记号来讨论。点的位置向量用小写字母表示，方向向量用大写字母表示。假定坐标系中心 o 就是参考点，我们关心点 x 从方向 R 受到的光照。

于是发光点位于方程 x + R · d 所表示的射线上，其中 d 是待定的光线参数。我们可以检验 d 的任意近似的准确性：在立方体贴图中按方向 l = x + R · d 读出所存的环境表面距离（|l'|），再与射线上近似点 l 的距离 |l| 比较。若 |l| ≈ |l'|，就找到了交点。若射线上的点在表面前方，即 |l| < |l'|，当前近似是低于的。反之，当点 |l| 位于表面之后（|l| > |l'|），该近似是高于的。

光线参数 d 可用迭代过程求得。过程从光线步进（即线性搜索）开始，再用割线搜索继续。稳健的线性搜索会算出一个粗略的偏高猜测与一个偏低的近似，把光线的第一个交点夹在中间。从这两个近似出发，割线搜索能迅速得到准确的交点。

线性搜索

可能的交点都在射线上。因此，交点可以通过在射线上步进找到（即检查点 r(d) = x + R · d，这些点由递增的正参数序列 d, 生成，并找出第一对相邻点，其中一点偏高、另一点偏低）。真正的交点位于这两个猜测之间，用割线搜索（下一小节讨论）求得。

光线参数 d 的增量定义需要特别考虑，因为现在几何体是采样的，反复检查同一个样本而忽略其他样本并不划算。遗憾的是，在射线上取等长步长并不能保证纹理空间被均匀采样。离参考点越远，射线上单位长度的步长对应纹理空间中越小的步长。要解决这个问题，可以在一段线段上步进，从参考点看去这条线段与射线完全重合，只是两个端点等距。把射线的起点 r(0) 与终点 r(∞) 分别投影到单位球上，就得到这样的线段端点：新起点 s = x/|x| 与终点 e = R/|R|。交点必须位于从 s 到 e 之间方向上所见的纹素处，如图 17-3 所示。

求交算法在 s 与 e 的线段上以等长步长搜索这些纹素：

r'(t) = s · (1 - t) + e · t,

t = 0,t, 2t,..., 1.

片元着色器的实现应接收光线起点 x 与方向 R，以及作为 uniform 参数传入的 samplerCUBE 类型的立方体贴图 map，依次生成光线参数 d 与射线上的点 r，并返回偏低的光线参数 dl 与偏高的光线参数 dp。比值 |l|/|l'| 与 |p| / |p'| 分别用变量 llp 与 ppp 表示。距离值存放在立方体贴图的 alpha 通道中。代码清单 17-1 给出执行线性搜索的片元着色器算法。

该算法在单层中找到相邻的一对偏低点与偏高点，在射线上按纹理空间中的等长步长 Dt 前进。步长 Dt 按 s 与 e 线段长度以及立方体贴图分辨率成比例设置。把纹素步长 Dt 设为大于相邻两个纹素的距离，可以加快算法，但也提高了漏掉薄物体反射的概率。在某个纹素处，距离值从立方体贴图的 alpha 通道取得。注意我们使用函数 texCUBElod()——显式把 mipmap 级别设为 0——而不用 texCUBE()，因为 texCUBE() 与 tex2D() 一样会迫使 DirectX 9 HLSL 编译器展开动态循环（Sander 2005）。

线性搜索应对每一层都执行。光线参数（dp）最小的那一层含有光线的首次命中。

用最小-最大距离值加速

为加快某一层内的求交搜索，我们为每张距离贴图计算一个最小距离值与一个最大距离值。追踪光线时，让光线与以参考点为中心、半径分别等于最小值与最大值的球面求交。这两个交点显著缩小了需要步进的光线区间。这个过程让起点 s 与终点 e 靠得更近，因此更少的步数就能达到同样的精度。见图 17-4。

示例 17-1. 在 HLSL 中执行线性搜索的片元着色器


float a = length(x) / length(R);
bool undershoot = false, overshoot = false;
float dl, llp;
// 最近一次欠冲的光线参数与 |l|/|l'|
float dp, ppp;
// 最近一次过冲的光线参数与 |p|/|p'|
float t = 0.0001f;
while (t < 1 && !(overshoot && undershoot))
{
  // 迭代
  float d = a * t / (1 - t);
  // 对应于 t 的光线参数
  float3 r = x + R * d;
  // r(d)：光线上的点
  float ra = texCUBElod(map, float4(r, 0)).a; // |r'|
  if (ra > 0)
  {
    // 有效纹素，即前方有可见物
    float rrp = length(r) / ra; //|r|/|r'|
    if (rrp < 1)
    {
      // 欠冲
      dl = d;
      // 把最近一次欠冲存入 dl
      llp = rrp;
      undershoot = true;
    }
    else
    {
      // 过冲
      dp = d;
      // 把最近一次过冲存为 dp
      ppp = rrp;
      overshoot = true;
    }
  }
  else
  {
    // 前方没有可见物：重新开始搜索
    undershoot = false;
    overshoot = false;
  }
  t += Dt;
  // 下一个纹素
}

用割线搜索细化

线性搜索给出相邻的一对偏低与偏高样本，真正的交点必在二者之间。我们把偏低与偏高的光线参数分别记为 dp 与 dl 。射线上对应的两点为 p 与 l，表面上对应的两点为 p' 与 l'，如图 17-5 所示。

如果单次割线步不够准确，可以让 dnew 替换掉之前的一个近似 dl 或 dp （始终保留一个偏高、一个偏低的近似），然后继续同样的迭代步。注意割线搜索对平面表面一次迭代就能得到精确结果，对平面网格也只需有限步。代码清单 17-2 给出割线搜索的片元着色器实现。

示例 17-2. HLSL 中割线搜索的片元着色器实现


for (int i = 0; i < NITER; i++)
{
  // 新交点的光线参数
  dnew = dl + (dp - dl) * (1 - llp) / (ppp - llp);
  float3 r = x + R * dnew;
  // 光线上新的点
  float rrp = length(r) / texCUBElod(map, float4(r, 0)).a; // |r|/|r'|
  if (rrp < 0.9999)
  {
    // 欠冲
    llp = rrp;
    // 存为最近一次欠冲
    dl = dnew;
  }
  else if (rrp > 1.0001)
  {
    // 过冲
    ppp = rrp;
    // 存为最近一次过冲
    dp = dnew;
  }
  else
    i = NITER;
}

我们把对每层执行的线性搜索，与处理单层的割线搜索一起放进一个 Hit() 函数。现在我们有了在场景中追踪任意光线的通用工具。该函数找到首次命中 l。在这个方向上读取立方体贴图，就能得到该点对应的材质属性与法线向量。

17.3 反射与折射

先考虑镜面反射。生成分层距离贴图之后，我们渲染反射物体并启用自定义的顶点与片元着色器程序。顶点着色器把反射物体变换到裁剪空间——同时也变换到立方体贴图的坐标系——先施加建模变换，再平移到参考点。视线向量 V 与法线 N 也在该空间中取得。代码清单 17-3 给出反射与折射的顶点着色器。

示例 17-3. HLSL 中反射与折射的顶点着色器


void SpecularReflectionVS(in float4 Pos
                          : POSITION,
                            // 模型空间中的顶点
                            in float3 Norm
                          : NORMAL,
                            // 模型空间中的法线
                            out float4 hPos
                          : POSITION,
                            // 裁剪空间中的顶点
                            out float3 x
                          : TEXCOORD1,
                            // 立方体贴图空间中的顶点
                            out float3 N
                          : TEXCOORD2,
                            // 立方体贴图空间中的法线
                            out float3 V
                          : TEXCOORD3,
                            // 视线方向
                            uniform float4x4 WorldViewProj,
                            // 模型空间到裁剪空间
                            uniform float4x4 World,
                            // 模型空间到世界空间
                            uniform float4x4 WorldIT,
                            // World 的逆转置
                            uniform float3 RefPoint,
                            // 世界空间中的参考点
                            uniform float3 EyePos
                          // 世界空间中的视点
)
{
  hPos = mul(Pos, WorldViewProj);
  float3 wPos = mul(Pos, World).xyz;
  // 世界空间
  N = mul(Norm, WorldIT);
  V = wPos - EyePos;
  x = wPos - RefPoint;
  // 变换到立方体贴图空间
}

片元着色器调用 Hit() 函数，得到首次命中 l 及其辐亮度 Il 与法线向量 Nl。如果表面是理想镜面，入射辐亮度应乘以按表面法线 N 与反射方向 R 之间夹角求值的菲涅尔项。我们使用菲涅尔函数的一种近似（Schlick 1993），它不仅考虑折射率 n，还考虑消光系数 k（这对逼真的金属至关重要）（Bjorke 2004；Lazányi and Szirmay-Kalos 2005）：

F(N,R) = Fp + (1 - F p )·(1 - N · R)5,

其中

是垂直入射时的菲涅尔函数（即光子被反射的概率）。注意 Fp 对给定材质是常数。因此该值可以在 CPU 上由折射率与消光系数算出，再作为全局变量传给 GPU。代码清单 17-4 给出单次反射的片元着色器。

示例 17-4. HLSL 中单次反射的片元着色器


float4 SingleReflectionPS(float3 x
                          : TEXCOORD1,
                            // 立方体贴图空间中的着色点
                            float3 N
                          : TEXCOORD2,
                            // 法线向量
                            float3 V
                          : TEXCOORD3,
                            // 视线方向
                            uniform float3 Fp0
                          // 垂直方向上的菲涅尔
                          )
    : COLOR
{
  V = normalize(V);
  N = normalize(N);
  float3 R = reflect(V, N); // 反射方向
  float3 Nl;
  // 交点处的法线向量
  float3 Il;
  // 交点处的辐亮度
  // 追踪光线 x+R*d，得到交点 l、辐亮度 Il、法线 Nl
  float3 l = Hit(x, R, Il, Nl);
  // 菲涅尔反射
  float3 F = Fp0 + pow(1 - dot(N, -V), 5) * (1 - Fp0);
  return float4(F * Il, 1);
}

单次折射的着色器类似，但方向计算应使用折射定律而非反射定律。换句话说，应把 reflect 操作换成 refract 操作，且入射辐亮度应乘以 1-F 而非 F。

光在到达漫反射表面之前，可能在理想反射体或折射体上被反射或折射多次。如果命中点位于镜面表面上，就需要计算一条反射或折射光线并继续追踪，对二次、三次以及更多次光线重复同一算法。计算反射或折射光线时，我们需要命中表面处的法线向量、菲涅尔函数以及折射率（折射情形）。这些信息可以按每层存进两张立方体贴图。第一张立方体贴图包含材质属性（漫反射表面的反射颜色，或镜面表面的垂直入射菲涅尔项）与折射率。第二张立方体贴图存放法线向量与距离值。

为了区分反射体、折射体与漫反射表面，我们检查折射率的符号。负值、零与正值分别表示反射体、漫反射表面与折射体。代码清单 17-5 给出计算多次镜面反射/折射的代码。

                              float3 V
                            : TEXCOORD3,
                              // 视线方向
                              uniform float3 Fp0,
                              // 垂直方向上的菲涅尔
                              uniform float3 n0
                            // 折射率
                            )
    : COLOR
{
  V = normalize(V);
  N = normalize(N);
  float3 I = float3(1, 1, 1);
  // 该路径的辐亮度
  float3 Fp = Fp0;
  // 首次命中处 90 度的菲涅尔
  float n = n0;
  // 首次命中处的折射率
  int depth = 0;
  // 路径长度
  while (depth < MAXDEPTH)
  {
    float3 R;
    // 反射或折射方向
    float3 F = Fp + pow(1 - abs(dot(N, -V)), 5) * (1 - Fp);
    if (n < = 0)
    {
      R = reflect(V, N);
      // 反射
      I *= F;
      // 菲涅尔反射
    }
    else
    {
      // 折射
      if (dot(V, N) > 0)
      { // 从内部射来
        n = 1 / n;
        N = -N;
      }
      R = refract(V, N, 1 / n);
      if (dot(R, R) == 0)
        // 不存在折射方向
        R = reflect(V, N); // 全反射
      else
        I *= (1 - F);
      // 菲涅尔折射
    }
    float3 Nl;
    // 交点处的法线向量
    float4 Il;
    // 交点处的辐亮度
    // 追踪光线 x+R*d，得到交点 l、辐亮度 Il、法线 Nl
    float3 l = Hit(x, R, Il, Nl);
    n = Il.a;
    if (n != 0)
    {
      // 交点位于镜面反射表面
      Fp = Il.rgb;
      // 90 度的菲涅尔
      depth += 1;
    }
    else
    {
      // 交点位于漫反射表面
      I *= Il.rgb; // 乘以辐亮度
      depth = MAXDEPTH;
      // 终止
    }
    N = Nl;
    V = R;
    x = l; // 交点即为下一个着色点
  }
  return float4(I, 1);
}

17.4 结果

我们的算法在 DirectX 9 HLSL 环境中实现，并在 NVIDIA GeForce 8800 GTX 显卡上测试。为简化实现，我们用两层表示反射物体（分别含正面与背面），并把所有漫反射表面光栅化到第三层。这一简化免去了实现深度剥离过程，并把层数上限设为三层。要处理更复杂的反射物体，需要整合深度剥离算法。

所有图像以 800x600 分辨率渲染。立方体贴图分辨率为 6x512x512，每帧更新。我们应仔细选择线性搜索的步长与割线搜索的迭代次数，因为它们会显著影响图像质量与渲染速度。如果把线性搜索的步长设得大于距离贴图相邻两纹素的距离，就能加快算法，但也会提高漏掉薄物体反射的概率。如果渲染进某一层的几何体是光滑的（即由较大的多边形面片构成），线性搜索可以取较大步长，割线搜索只需少数几次迭代就能找到精确解。然而，当层中距离值变化剧烈时，线性搜索应取细步长，以免漏掉距离贴图中的尖峰——那对应着薄的反射物体。

欠采样瑕疵的另一个来源是层数限制与距离贴图分辨率的限制。反射中我们可能看到场景的某些部分，它们由于遮挡以及相对立方体贴图中心的掠射朝向，在距离贴图中表示得很粗糙或根本没有表示。图 17-6 展示了这些瑕疵，并说明通过适当设置线性搜索步长与割线搜索迭代次数可以把它们减轻到何种程度。

注意阶梯状瑕疵通常可以通过增加割线步来消除。绿色与红色框内放大的薄物体需要细的线性步长，因为一旦漏掉，后面的割线搜索并不总能迅速纠正误差。注意在图 17-6b 中，割线搜索对桌子比对镜框更成功，因为桌子在距离贴图中占据的纹素更多。图 17-6a 与 17-6c 左侧镜子里桌子下方阴影区域反射的走样（在蓝色框中放大），源于距离贴图层数被限制为三层。该区域在层中没有表示，因此连割线搜索也无法算出准确反射（图 17-6b 与 17-6d）。这类问题可以通过增加层数来解决。

图 17-7 展示了盒中一个反射茶壶的图像，分别用所提出的方法和 Maya（作对比）渲染，并把一条路径中的最大反射次数限制为一、二、三。

注意 GPU 渲染与软件渲染的图像高度相似。还值得一提的是，最大反射次数增加时帧率下降很少。这一情形说明最新 NVIDIA 显卡的动态分支性能优异，也说明即使 GPU 方案也能从光线提前终止中获益。

图 17-8 展示了一个更复杂的场景，含一个反射球与一面镜子，此时最大光线深度变量从一递增到八。把所有漫反射表面归入单层，会在出现视线相关遮挡的地方造成轻微模糊瑕疵（例如镜面球上灯把手的反射）。用更多层可以消除这些瑕疵，但代价是实现更复杂、渲染更慢。

图 17-9 展示了一个既反射又折射光的球。最后，图 17-10 包含一段关于复杂环境中反射茶壶的视频截图。该视频在不用最小-最大加速时以 25 fps 渲染。为每层计算一对最小-最大值后，速度提升到 50 fps。最大反射次数设为二。

17.5 结论

本章介绍了一种在以分层距离贴图表示的场景中追踪光线的稳健算法。该方法用于在 GPU 上计算单次与多次反射和折射。在光栅化几何表示中追踪光线，而非直接实现经典光线追踪，一个重要优势是这些方法可以集成进游戏引擎，受益于为游戏开发的可见性算法（Wimmer and Bittner 2005），并充分利用最新显卡的潜力。如果渲染进某一层的几何体是光滑的（即由较大的多边形面片构成），这一方法尤其有效。此时线性搜索可以取较大步长，割线搜索只需少数几次迭代就能找到精确解。然而，当层中距离值变化剧烈时，线性搜索应取细步长，以免漏掉薄的反射物体。注意浮雕贴图中也会出现类似问题，已有多套解法（Donnelly 2005；Policarpo and Oliveira 2007——本书第 18 章）。将来我们会考虑把类似的解法整合进我们的技术。
