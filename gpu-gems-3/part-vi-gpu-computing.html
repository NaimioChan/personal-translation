第六部分：GPU 计算

在 GPU Gems 3 中，我们继续展示把图形硬件用于非图形计算的工作。每一代新产品都带来显著更强的计算能力和可编程性，GPU 因此越来越有吸引力，成为通用计算的目标，也就是通常所说的 GPGPU 或 GPU 计算。于是学术界与工业界的研究者和开发者不断为排序、数据库操作、图像处理和线性代数等任务开发新的 GPU 算法。许多情况下，使用 GPU 的主要动机是以相对低的成本获得高性能的前景。

GPU 编程工具在过去几年里发生了巨大变化。最近 NVIDIA 随 CUDA 技术的推出发布了一套新的 GPU 计算工具。CUDA 提供了灵活的编程模型和类 C 语言，用于在 GPU 上实现数据并行算法。更重要的是，NVIDIA 兼容 CUDA 的 GPU 具备额外硬件特性，专门用于提升性能，并让用户对算法如何映射到 GPU 有更多控制。在许多方面，CUDA 是拓宽可从 GPU 性能中受益的算法领域的重要一步。本书这一部分既有使用 CUDA 的新应用，也有用 Cg 等语言做基于图形的 GPGPU。

我们从 GPU 在网络安全中的角色开始这一部分。对网络病毒检测系统来说，在快速而昂贵、基于专用处理器的方案与基于平价 CPU 的低成本方案之间存在权衡。第 35 章「在 GPU 上快速匹配病毒签名」，Juniper Networks 的 Elizabeth Seamans 与 Polytime 的 Thomas Alexander 给出了一个高性能的、基于 GPU 的病毒扫描库。该系统把 GPU 当作快速过滤器，并行地为成千上万个数据对象快速找出可能的病毒签名。他们这个库的性能表明，GPU 如今已是实现高性价比、高性能网络安全处理的可行平台。

第 36 章「GPU 上的 AES 加密与解密」，SEGA 公司的 Takeshi Yamanouchi 描述了他把加密算法实现在 GPU 上的工作。AES（高级加密标准）是当前分组密码加密的标准，和许多加密算法一样，它大量依赖整数运算。作者描述了如何利用 NVIDIA GeForce 8800 GPU 的整数处理能力来加速 AES 加密与解密。

许多软件系统，包括粒子物理模拟器和随机光线追踪器，都依赖蒙特卡洛方法高效求解涉及复杂多维函数的问题。快速而准确的随机数生成是所有蒙特卡洛仿真的关键组件。第 37 章「用 CUDA 高效生成随机数及其应用」，Lee Howes 与 Imperial College London 的 David Thomas 提出了用 CUDA 生成随机数的方法，以发挥 GPU 的大规模并行与算术性能。他们描述了两种快速生成高斯随机数算法的相对优势——这些技术在为股票期权定价的金融仿真中特别有用。

石油天然气行业的公司依靠精确的地震勘探来识别地下油藏。难点在于大多数地震数据集有数 TB 之大，把原始数据转换成有用的勘探图像需要极大的计算能力。第 38 章「用 CUDA 为地球地下成像」，Bernard Deschizeaux 与 CGGVeritas 的 Jean-Yves Blanc 描述了在其工业地震处理管线中若干时间关键算法的 CUDA 实现。他们的 CUDA 实现相比最新一代 CPU 取得了显著的性能提升，作者还讨论了构建 GPU 集群以加速大型地震处理问题的可能性。

计算机科学中许多常用算法都涉及一个称为全前缀和或扫描的简单操作。对数据数组中的每个值，扫描操作计算它前面所有值的和。第 39 章，「用 CUDA 实现并行前缀和（扫描）」，NVIDIA 的 Mark Harris 与 University of California, Davis 的 Shubhabrata Sengupta 和 John D. Owens 描述了并行扫描算法的高效 CUDA 实现，并给出流压缩和基数排序等应用的结果。这一章也是开发者学习 CUDA 编程与优化策略的好参考。

高斯函数是图像与信号处理中使用最广的滤波核之一。指数项使得动态求值高斯函数的代价很高，因此实践中常预先计算一张系数表。第 40 章「高斯函数的增量计算」，Adobe Systems 的 Ken Turkowski 提出了一种用类似多项式前向差分的技巧快速即席求值高斯函数的方法。通过把差分换成商，这个算法增量地计算高斯系数。对 GPU 实现而言，这种做法省掉了像素着色器中的一次纹理查找，从而可能带来更快的滤波性能。

第 41 章「用几何着色器实现紧凑、可变长度的 GPU 回读」为本部分作结，描述了如何利用符合 DirectX 10 的 GPU 中的新硬件特性，实现无法用像素着色器或顶点着色器高效实现的算法。几何着色器是 GPU 渲染管线中额外的阶段，能够执行输入输出可变、依赖数据的算法。这一能力对分析图像以识别几何形状的计算机视觉应用特别有用。本章中，NVIDIA 的 Franck Diard 给出了若干算法的几何着色器实现，包括直方图构建和角点检测。

本部分只提供了 GPGPU 技术近期工作的一个小样本。即便架构与编程工具（如 NVIDIA 的 CUDA）在迅速演进，GPU 对数据并行计算来说仍相当专门化。不过很明显，科学计算等领域的许多重要算法都有足够的并行性，能从 GPU 性能中获益；随着 GPU 变得更通用、更易编程，很可能会有新算法涌现。正如本部分各章所示，图形处理器的性价比在高性能计算及其他计算行业中都可能是一股颠覆性力量。

Nolan Goodnight, NVIDIA Corporation
