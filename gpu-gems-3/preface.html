前言

从第一本 GPU Gems 问世至今只有三年，实时图形的某些领域却已真正达到超写实水准。第 14 章「面向真实感实时皮肤渲染的高级技术」漂亮地展示了这一演进：它描述的皮肤渲染技术效果极好，以至于在未来几年里，数据采集与动画将成为渲染人物角色最棘手的问题。

所有这些进步都由 GPU 持续不断的创新节奏推动。这些处理器在速度上不断提升，用途也越来越灵活。今天的 GPU 能处理海量数据，不仅用于渲染三维场景，也用于处理图像或执行大规模并行计算，例如金融统计，或为寻找新油田做地形分析。

无论用于计算还是图形，GPU 都需要一个软件接口来驱动，而我们正处在一场重要转变之中。新一代 API 带来了额外的正交性，并暴露出新的能力，例如以编程方式生成几何体。在计算一侧，CUDA 架构让开发者能用类似 C 的语言完成计算任务，而不必被迫使用图形管线。这一架构将让没有图形背景的开发者也能挖掘 GPU 的巨大潜力。

GPU 编程社区提交了两百多章稿件，涵盖从纯三维渲染到非图形应用的广阔范围。每一章都经过 NVIDIA 工程师与外部评审的严格审阅。

我们最终收录了 41 章，每一章又经过一轮审阅，其间编辑与同行评审的反馈常常显著改善了内容。遗憾的是，由于篇幅限制，一些优秀章节无法收录。确定最终目录很不容易，但我们要感谢每一位投稿者。

目标读者

对于与图形相关的章节，我们期望读者熟悉计算机图形学基础，包括 DirectX、OpenGL 等图形 API，以及它们对应的高级编程语言，即 HLSL、GLSL 或 Cg。任何从事交互式三维应用的人，都能在本书中找到适用于今天和明天 GPU 的大量技术。

对计算和 CUDA 感兴趣的读者，最好了解并行计算概念，也需要具备 C 编程知识。
