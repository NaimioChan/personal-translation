Eugene d'Eon

现代 GPU 的着色性能，加上三维扫描技术的进步、次表面散射渲染的研究，以及对皮肤物理构成的细致理解，使得生成极其逼真的人体皮肤与面部实时图像成为可能。图 14-1 展示了一个例子。本章介绍生成这类图像的高级技术。我们始终的目标是采用现有最物理精确、同时又能实时实现的模型。这类基于物理的模型提供了灵活性：它们支持在不同光照场景下做真实感渲染，并且只需最少的调参就能得到很好的结果。

14.1 皮肤的外观

皮肤一直难以渲染：它有许多细微的视觉特征，而人对皮肤、尤其是面部的外观极其敏感。人体皮肤的细节量本身就是一道障碍。真实的皮肤模型必须包含皱纹、毛孔、雀斑、毛囊、疤痕等等。幸运的是，现代三维扫描技术让我们能捕捉到如此极端的细节层次。然而，直接渲染出来的模型看起来不真实、僵硬、发干，如图 14-2a 所示。缺了什么？困难主要来自次表面散射：光进入皮肤表面之下，在其中散射并被部分吸收，然后从别处射出。皮肤其实是微半透明的；这个细微却关键的效果赋予皮肤柔和的外观，对真实感渲染绝对不可或缺，如 图 14-2b 所示。

对大多数材质，光的反射通常分成两个独立处理的成分：（1）表面反射，一般用简单的镜面计算近似；（2）次表面散射，一般用简单的漫反射计算近似。然而，要为皮肤生成真实感图像，这两个成分都需要更高级的模型。即使有现代扫描技术提供的高细节漫反射、镜面与法线贴图，缺少准确的镜面反射与次表面散射，皮肤也不会显得真实。

14.1.1 皮肤表面反射

入射到皮肤表面的光有一小部分（整个光谱上大约 6%（Tuchin 2000））会直接反射，不被染色。这源于与皮肤最外层（粗糙且含油）的菲涅尔相互作用，我们可以用镜面反射函数来建模。我们在图 14-3 中结合一个很适合皮肤渲染的多层皮肤模型（Donner 与 Jensen 2006）展示了这一过程。光直接从油层与表皮反射出去，既不进入，也不被散射或染色。这种反射不是完美的镜面反射，因为皮肤表面有非常细尺度的粗糙度，使单一入射角的光反射到一定范围的出射角。这种粗糙度的效果可以用镜面双向反射分布函数（BRDF）来描述。

简单的经验性镜面计算，例如 OpenGL 与 Direct3D 长期支持的、大家熟悉的 Blinn-Phong 模型，并不能准确近似皮肤的镜面反射。基于物理的镜面模型给出更准确的结果，从而得到更真实的图像。14.3 节我们会探讨这样一个模型（本章所有图像都用它计算），并说明如何在 GPU 上高效实现。

14.1.2 皮肤次表面反射

任何没有在皮肤表面直接反射的光都会进入次表面各层。光在次表面组织层中的散射与吸收，赋予皮肤颜色与柔和的外观。光进入这些层，在其中被部分吸收（从而获得颜色）并多次散射，最后从入射点周围的三维邻域返回并射出表面。有时光会完全穿过耳朵这类薄的区域。真实的皮肤着色器必须建模这一散射过程；图 14-2a 之所以显得僵硬、发干，正是因为忽略了这一过程，光只能从它首次接触表面的位置反射。

使过程更复杂的是，皮肤内部的多层结构对光的吸收与散射方式实际上各不相同，如图 14-4 所示。图形学研究者已经给出了非常精细的模型，用多达五个独立层来描述皮肤中的光学散射（Krishnaswamy 与 Baranoski 2004）。真实的皮肤还要复杂；在医学上，仅表皮就被认为包含五个不同的层（Poirer 2004）。按这种复杂度模拟散射大概过分了，但真实感渲染至少需要在负责镜面反射的油层之下建模两个不同的层。Donner 与 Jensen 2005 证明单层模型不够用，并展示了使用三层模型所获得的改善。我们在 14.4.3 节用能建模这种多层散射的实时系统做了类似对比，见图 14-11。Donner 与 Jensen 2006 后来提出了一个两层模型，效果依然令人信服。

为图像合成的目的模拟这一过程，研究者从物理学界借用（并改进）了散射模型。有一类散射模型在皮肤渲染上被证明非常成功。在皮肤表面之下，入射光很快因散射而变成漫射：光子在组织层中频繁散射，只经过几次散射事件，即使完全相干的光束也会朝各个方向均匀流动。这大大简化了一般的散射问题，由此得到所谓扩散模型。不过扩散模型在数学上仍然相当复杂，相关文献读起来可能吃力。14.5 节我们讨论一些着色操作——其中许多简单到只是对图像做模糊——它们能准确高效地模拟这些模型的核心效果，从而可以写出易于编程、能生成真实感实时图像的 GPU 算法。

14.2 皮肤渲染系统概览

以下几节详细介绍我们的实时皮肤渲染系统，它由镜面反射分量与次表面散射分量相加而成。两个分量的 GPU 实现都做详细描述，包括对漫散射理论的回顾，以及散射剖面的一种新表述。

14.3 节讨论光与皮肤最表层的相互作用，即镜面表面反射，并讨论 Kelemen 与 Szirmay-Kalos 2001 解析 BRDF 的一种高效实现。该模型很接近 Torrance/Sparrow 模型，后者已被证明能生成逼真的面部图像（Donner 与 Jensen 2005、Donner 与 Jensen 2006、Weyrich 等 2006），但求值代价低得多，外观大体相同。Weyrich 等 2006 的实测参数对调节这两个模型以渲染面部都很有用。

14.4 节回顾现有的散射理论，重点是扩散剖面、如何用它们渲染带次表面散射的图像，尤其是它们的精确形状对产生真实感皮肤外观为何重要。我们给出扩散剖面的一种新的高斯和表述，它有许多优点，包括 14.5 节介绍的新渲染算法。这一新表述能很好地近似流行的偶极（Jensen 等 2001）与多极（Donner 与 Jensen 2005）解析扩散剖面，我们还讨论了如何把高斯和准确拟合到已知剖面上（附简要误差分析）。本章所有图像所用三层皮肤模型的高斯和剖面一并给出，供读者作为起点。

14.5 节我们先修改纹理空间扩散（Borshukov 与 Lewis 2003），以利用高斯和扩散剖面，办法是类似 Green 2004 那样对辐照度做可分离的、分层级的卷积。不过我们保留一系列中间的高斯卷积纹理，并在最终渲染遍中把它们组合起来，从而快速准确地近似多层模型所预测的散射。纹理空间中卷积引起的畸变，参照 Gosselin 2004 的做法用一张伸缩纹理来修正，该纹理在局部校正卷积核。不过我们的伸缩校正纹理分别独立地校正 U、V 两个方向的畸变，并用一个简单的片元着色器快速算出（这样网格可以有相当大的形变，也不需要预计算和美术输入）。

耳朵这类薄表面区域的透射，是通过修改半透明阴影贴图（Dachsbacher 与 Stamminger 2004）实现的：计算穿过表面的深度，并把处于阴影中的区域与朝向光源那一面上的位置关联起来，那里可以通过访问为局部散射算好的同一批纹理获得辐照度的多次卷积。我们利用高斯在第三维上的可分离性，在计算所需的三维卷积时复用辐照度的二维卷积。

最后，14.6 节用加速次表面散射的同一套可分离、分层级技术，把宽大的不可分离泛光滤波器近似为两个高斯之和，从而加速二维卷积。

14.3 镜面表面反射

Phong 镜面模型在实时计算机图形学中几乎无处不在，但改用更准确的基于物理的表面反射模型，只需多几条着色器指令就能轻松提升画质。Phong 模型无法表现掠射角下增强的镜面反射，而且在物理上不合理（例如它输出的能量可能多于接收的能量）。图 14-5 展示了 Phong 模型相比基于物理的镜面 BRDF 的局限。

14.3.1 为皮肤实现基于物理的镜面反射模型

计算机图形学文献中有许多基于物理的镜面 BRDF 可用于提升皮肤渲染的真实感。我们先讨论所有 BRDF 模型通用的实现细节，再说明 Kelemen/Szirmay-Kalos 模型的具体做法，我们选它是因为求值高效。

用 BRDF 渲染

大多数镜面 BRDF 模型用解析函数描述反射率，这类函数在片元着色器中求值很直接。这类模型通常是若干项（例如菲涅尔项与几何衰减项）的乘积，并带有若干参数。

这些解析 BRDF 通常有一个常量 rho_s 项用来缩放强度。其他常见输入有表面法线 N、视线向量 V、光线向量 L、折射率 eta（菲涅尔项需要）以及粗糙度参数 m。于是每个光源的总镜面反射为：

specularLight += lightColor[i] * lightShadow[i] * rho_s *
                 specBRDF(N, V, L[i], eta, m) * saturate(dot(N, L[i]));

由于 BRDF 的定义，除了计算 BRDF 本身，还需要 dot(N, L[i]) 项。每个光源还可以加一个距离衰减项，按到光源的距离降低强度。这段代码适用于点光源、平行光或聚光灯，只要能为它们算出 L 向量与阴影项。来自环境贴图光源或面光源、由粗糙表面产生的镜面反射——称为光泽反射——复杂且计算开销很大，我们没有把它们纳入皮肤渲染系统。感兴趣的读者可参阅 Kautz 与 McCool 2000，那里有一种使用预滤波环境贴图的实时技术。

渲染皮肤时的菲涅尔反射

所有基于物理的镜面 BRDF 模型都含有菲涅尔项，而这一项通常没有得到详细解释。它应当是非偏振的介质菲涅尔反射函数，F 0（或 R 0）参数（法向入射时的反射率）取 0.028。这来自比尔定律，并假定皮肤的折射率为 1.4（Donner 与 Jensen 2006）。Pharr 与 Humphreys 2004 对菲涅尔反射与比尔定律做了出色的阐述，我们不再重复公式。为皮肤这类粗糙表面计算菲涅尔项时，所有 项都应从半角向量 H 量起，而不是从 N。Schlick 的菲涅尔近似（Schlick 1993）对皮肤效果良好，如图 14-6 所示。代码清单 14-1 给出了计算 Schlick 菲涅尔反射的函数。

示例 14-1　计算镜面 BRDF 中菲涅尔反射的函数

H 是标准的半角向量。F0 是法向入射时的反射率（皮肤用 0.028）。


float fresnelReflectance(float3 H, float3 V, float F0)
{
  float base = 1.0 - dot(V, H);
  float exponential = pow(base, 5.0);
  return exponential + F0 * (1.0 - exponential);
}

为高效求值而分解 BRDF

Heidrich 与 Seidel 1999 描述了一种有助于高效求值 BRDF 模型的预计算策略，基于把 BRDF 分解到多张预计算的二维纹理中。我们采用类似做法来高效计算 Kelemen/Szirmay-Kalos 镜面 BRDF，但我们只预计算一张纹理（Beckmann 分布函数），并用 Schlick 菲涅尔近似，得到相当高效的镜面反射计算，同时允许粗糙度参数 m 在物体上变化。

我们先用代码清单 14-2 所示的片元着色器渲染一个与屏幕对齐的四边形，预计算出 Beckmann 分布纹理。图 14-7c 展示了得到的纹理。这一步可以在应用启动时做一次，或者干脆存成纹理文件备用。我们用指数缩放并把结果减半，把函数映射到 8 位纹理能存的范围，然后在镜面计算时反演这个映射。（另一种做法是用浮点纹理，以减少计算，代价是纹理带宽。）代码清单 14-3 给出使用该预计算纹理进行渲染的最终镜面函数。图 14-7 在一系列粗糙度值上比较了完整镜面计算与快速版本。图中只显示镜面反射，很难把近似结果与完整 BRDF 求值区分开。

示例 14-2　预计算 Beckmann 纹理的代码


float PHBeckmann(float ndoth, float m)
{
  float alpha = acos(ndoth);
  float ta = tan(alpha);
  float val = 1.0 / (m * m * pow(ndoth, 4.0)) * exp(-(ta * ta) / (m * m));
  return val;
} // 渲染一个屏幕对齐的四边形，预计算 512x512 的纹理。
float KSTextureCompute(float2 tex : TEXCOORD0)
{
  // 把该值缩放到 [0,1] 范围内——查表时再反变换。
  return 0.5 * pow(PHBeckmann(tex.x, tex.y), 0.1);
}

示例 14-3　用预计算的 Beckmann 纹理计算 Kelemen/Szirmay-Kalos 镜面反射


float KS_Skin_Specular(float3 N, // 凹凸后的表面法线
                       float3 L, // 指向光源
                       float3 V, // 指向视点
                       float m,
                       // 粗糙度
                       float rho_s, // 镜面反射亮度
                       uniform texobj2D beckmannTex)
{
  float result = 0.0;
  float ndotl = dot(N, L);
  if (ndotl > 0.0)
  {
    float3 h = L + V; // 未归一化的半程向量
    float3 H = normalize(h);
    float ndoth = dot(N, H);
    float PH = pow(2.0 * f1tex2D(beckmannTex, float2(ndoth, m)), 10.0);
    float F = fresnelReflectance(H, V, 0.028);
    float frSpec = max(PH * F / dot(h, h), 0);
    result = ndotl * rho_s * frSpec; // BRDF * dot(N,L) * rho_s
  }
  return result;
}

皮肤的镜面反射是白色的

皮肤最外层的组织细胞与油脂是介质材料，反射光而不给光染色（而金这类金属会给反射光染色，因为在可见光波段上折射率变化剧烈）。因此，基于物理的皮肤着色器应使用白色镜面颜色。换句话说，白光在皮肤上的镜面反射是白色的，有色光的镜面反射则具有该光本身的颜色——与底下皮肤的颜色无关。渲染皮肤时若没有正确的伽马校正（见本书第 24 章「线性空间的重要性」），一个常见问题是在把白色镜面反射加到漫反射次表面散射项上时颜色过黄。如果所有渲染都在线性色彩空间中完成并正确显示，镜面颜色就不需要调成白色以外的值。

让镜面参数在面部变化

Weyrich 等 2006 给出的一项人脸调研，提供了 Torrance/Sparrow 镜面 BRDF 模型（配 Beckmann 微表面分布函数）的实测参数。他们假定该模型适用于皮肤表面反射，并在 149 张人脸上测量了面部十个区域的粗糙度 m 与强度 rho_s。这些结果见其 SIGGRAPH 2006 论文，为调节用于渲染面部的镜面 BRDF 提供了很好的起点。Kelemen/Szirmay-Kalos 模型很接近 Torrance/Sparrow 模型，实测参数对两者都好用。他们的数据可以很容易地画到脸上——用一张低分辨率双通道贴图为每个面部区域指定 m 与 rho_s。图 14-8 比较了使用 Weyrich 等实测值与整张脸使用常量 m 和 rho_s 的渲染结果。差别细微但看得出来，增添了一些不错的层次（例如让嘴唇与鼻子更亮）。

Ma 等 2007 巧妙地利用光的偏振，快速捕获面部反射率，并把它分离成镜面与漫反射分量。由此可以生成高分辨率的法线、颜色与镜面强度（rho_s）贴图，以及面部的高分辨率几何。得到的数据能产生逼真的渲染（见 d'Eon 等 2007），而且镜面贴图提供的镜面变化分辨率远高于 Weyrich 等的参数（但假定粗糙度固定）。

14.4 散射理论

现在我们从严面表面反射转向漫反射次表面散射。在着手真实感皮肤渲染算法之前，先要引入扩散剖面这个概念。这个概念是次表面散射理论的关键，源自对半透明材料中光的传播与散射所做的一番相当复杂的数学分析，但它本身很直观，也容易解释。

需要说明，本章描述的技术只适用于扩散模型。具体来说，我们不处理单次散射效果，即每条光线在表面下恰好散射一次的情形。渲染皮肤时忽略单次散射一般可以接受（不过见 14.7.1 节），但对某些材料（如大理石、玉、烟），单次散射会显著影响外观。这些材料的真实感渲染必须包含单次散射，所用方法迄今远比我们介绍的技术昂贵或受限（Jensen 等 2001、Wang 等 2005）。幸运的是，只用扩散近似对皮肤效果就很好。

14.4.1 扩散剖面

扩散剖面给出光在高度散射的半透明材料表面之下如何散射的一种近似。具体来说，它描述下面这个简单实验的结果（这个实验有时也用来测量扩散剖面）。设想暗室中有一个平面，一束很细的白色激光照在上面。我们会在激光击中表面的中心点周围看到一圈辉光，因为有些光进入表面之下又从附近返回，如图 14-9a 所示。扩散剖面告诉我们，出射的光量如何随离开激光中心的角度与距离变化。若只考虑均匀材料，各方向散射相同，角度无关紧要。每种颜色都有自己的剖面，可以画成一维曲线，如图 14-9b 所示。 [1]

注意这些剖面强烈依赖颜色：红光比绿光和蓝光散射得远得多。皮肤的吸光特性对频率变化非常敏感；事实上，研究者实现过把散射分到 150 个色带上分别模拟的光谱模型（Donner 与 Jensen 2006），因而要算 150 个扩散剖面！虽然原则上我们可以在 GPU 上实现类似的光谱模型，但由此带来的改善大概不足以抵偿多出来的大量渲染遍与纹理。本章所有图像都用 RGB 光传输渲染。

14.4.2 用扩散剖面渲染

有了合适的扩散剖面，模拟皮肤内的次表面散射就归结为这样一个过程：收集表面上每个位置的全部入射光，然后按剖面的精确形状把它扩散到邻近位置。可以把表面上的每个微小区域看作在重演图 14-9a 所示的激光点实验。一小块很窄的入射光会产生一块更大、带颜色的出射光。表面上的每个区域都要这么做，所有重叠的彩色光斑叠加起来，就呈现出半透明的外观。

由于入射光在皮肤中很快变成漫射，我们可以把表面上每一点的全部入射光加起来而忽略其方向，只需为每个光源保留一个 N · L 项，以及后面（14.5.2 节）讨论的可选菲涅尔透射项。入射光的方向性几乎立刻就丢失了，因此只有总光量重要。这些漫射光随后散射到邻近区域（具体量由扩散剖面决定），并假定从表面射出时朝各方向均匀流动（同样，为了最大真实感，漫射光射出表面时需要菲涅尔透射项）。这就允许使用相当简单的渲染算法，我们马上介绍。但首先需要知道描述皮肤散射的精确扩散剖面。

Jensen 等 2001 被广泛使用的散射模型，基于若干材料属性给出了扩散剖面的解析公式。给定这些属性，剖面用偶极方程算出。后来的一篇论文（Donner 与 Jensen 2005）提出了处理多层材料的多极理论。他们还给出了一个三层皮肤模型，我们的皮肤渲染系统使用该模型预测的剖面。

除了偶极模型，Jensen 等 2001 还给出了一种用扩散剖面渲染曲面的高效技术。思路很简单：用表面上两点之间的空间距离 r 来求扩散剖面的值。这决定了任意两个位置之间的漫散射，而不论它们之间的几何形状如何，如图 14-10 所示。这虽然不物理精确，但皮肤表面上常见的曲率相对散射的有效半径来说相当低，这个近似在实践中效果很好。

14.4.3 扩散剖面的形状

准确渲染需要知道要模拟的材料的扩散剖面的精确形状，偶极（Jensen 等 2001）或多极（Donner 与 Jensen 2005）扩散模型会依据实测散射参数算出这些形状。对许多材料，较简单的偶极模型就够了。要渲染牛奶、大理石或番茄酱，我们可以查出实测散射系数，用偶极模型算出它们的扩散剖面。

然而，对于由若干层构成、每层散射属性不同的材料，剖面的形状会变得比偶极能表示的更复杂。使用更复杂的多极模型可以显著改善皮肤这类多层材料的外观。图 14-11 比较了用单层与三层次表面散射渲染的皮肤。注意各次渲染中的镜面光、法线与漫反射颜色完全相同。关键差别在于所用扩散剖面的形状。偶极为单层无限厚介质中的散射推导而来，其简单的形状导致蜡质感的外观。偶极无法表现薄的、窄散射表皮层叠在宽散射真皮层之上时的合成反射率。

14.5 高级次表面散射

本节详细介绍皮肤渲染系统的次表面散射分量，包括我们对纹理空间扩散与半透明阴影贴图的扩展。我们计算若干张模糊后的辐照度纹理，并在最终渲染遍中把它们全部组合起来。扩散剖面中用到的每个高斯函数对应一张纹理。一张简单的伸缩校正纹理使在扭曲的 UV 纹理空间中做可分离卷积更准确。我们修改半透明阴影贴图技术（Dachsbacher 与 Stamminger 2004），把它与模糊后的辐照度纹理结合，从而让光令人信服地穿过耳朵这类薄区域。

使用六张离屏模糊纹理，可以用 Donner 与 Jensen 2005 所用的三层皮肤模型准确渲染。我们尽可能贴近地复现了他们的一幅渲染结果，实时结果见 图 14-15。肤色不完全一致，因为他们漫反射贴图的平均颜色没有给出，而且他们的阴影边缘因使用面光源而更软。除此之外，实时结果与离线渲染非常相似，而后者需要几分钟才能算完。

14.5.1 纹理空间扩散

Borshukov 与 Lewis 2003 为渲染 The Matrix 续集中的面部而提出的纹理空间扩散技术，可用于准确模拟次表面散射。他们那个简单却有力的洞见是：利用皮肤中散射的局部性，把三维网格按纹理坐标作为渲染坐标展开到二维纹理中，从而高效模拟散射。然后他们对纹理施加卷积操作（模糊）来建模光的散射，这一步可以做得非常高效。所需的模糊形状正是材质的扩散剖面（因此红、绿、蓝需要不同的模糊）。他们使用两个简单解析扩散剖面之和：一个宽基底加一个尖峰（细节见 Borshukov 与 Lewis 2005）。这两项近似了宽散射真皮层之上表皮的窄散射，但引入的参数并非直接来自任何物理模型，其调整留给美术手工完成。我们的高斯和扩散剖面近似能实现更快的渲染并产生更准确的散射，因为它们源自基于物理的模型。

纹理空间扩散可以很好地扩展到 GPU 上，Green 2004 对此作了展示。我们在几方面扩展了 Green 的实现：纳入穿过耳朵这类薄区域的透射（Borshukov 与 Lewis 那里用的是光线追踪），并通过伸缩校正与更好的卷积核提高结果精度。以往纹理空间扩散的实时实现（Green 2004、Gosselin 2004）只用一个高斯核（或泊松盘采样），那只是对真实散射非常粗糙的近似。

14.5.2 改进的纹理空间扩散

我们修改纹理空间扩散，使其更准确地近似次表面散射。新算法每帧执行——图 14-16 展示了它——步骤如下：

  1. 渲染所需的阴影贴图。
  2. 渲染伸缩校正贴图（可选：可以预计算）。
  3. 把辐照度渲染进离屏纹理。
  4. 对漫射剖面近似中使用的每个高斯核：
    1. 在 U 方向做一遍可分离模糊（临时缓冲）。
    2. 在 V 方向做一遍可分离模糊（全部保留，供最终遍使用）。
  5. 在三维中渲染网格：
    1. 取用每张高斯卷积纹理，做线性组合。
    2. 为每个光源加上镜面反射。

高斯和扩散剖面的优点

我们本可以用单遍二维卷积操作，直接用扩散剖面对辐照度纹理做卷积（Borshukov 与 Lewis 2003 就是这么做的）。但那样相当昂贵：在辐照度纹理中我们在脸上平均每毫米存 4 个采样（纹素），而红光的扩散剖面宽度约为 16 mm，即 64 个纹素。因此我们需要一个 64 x 64 或 4,096 抽头的模糊着色器。若扩散剖面可分离，可以降到只有 64 + 64 或 128 抽头。但扩散剖面是径向对称的，因为我们假定材料均匀、各方向散射相同，因此它们不可分离——可分离且径向对称的函数只有高斯，而我们已经看到扩散剖面不是高斯。

不过，每张高斯卷积纹理可以可分离地算出，而且只要我们的拟合准确，这些纹理的加权和就能很好地近似用原来的不可分离函数做的那次冗长二维卷积。这提供了一种加速不可分离函数通用卷积的好办法：用若干个可分离卷积之和来近似一次不可分离卷积。14.6 节我们用同样的思路加速高动态范围（HDR）泛光滤波器。

总结一下，我们做六次七抽头可分离卷积，每个输出纹素总共 6 x 2 x 7 = 84 次纹理访问，而用原扩散剖面一步卷积需要 4,096 次。

校正 UV 畸变

如果表面是平的，而且用来模糊辐照度的卷积核正好是材质的扩散剖面，那么纹理空间扩散非常准确。然而把这套技术用于曲面时会出现一些问题。

在曲面上，由于 UV 畸变，纹理中位置之间的距离并不直接对应网格上的距离。要更准确地处理曲面上的卷积，就得解决 UV 畸变。我们发现，用每帧可快速算出的简单伸缩值，可以在很大程度上校正这一点，结果看起来很好，对面部这类曲率不极端的表面尤其如此。忽略 UV 畸变会在阴影周围造成红色辉光，并在耳朵这类在纹理空间中比其他表面区域更被压缩的地方产生蜡状的扩散。

我们计算一张伸缩校正纹理，用它调制纹理空间中每个位置的卷积抽头间距，如 图 14-20 所示。这样卷积宽度在网格上处处大致相同（因而在纹理的不同区域有所变化）。我们分别计算 U、V 两个纹理空间方向上的伸缩，因为水平与垂直方向的伸缩往往差别很大。

示例 14-4　计算双分量伸缩纹理

伸缩纹理的计算非常高效，可以对高度形变的网格逐帧计算。世界空间坐标的纹理空间导数能准确估计局部伸缩，取倒数后在后面直接乘以模糊宽度。可能需要一个常数把数值缩放到 [0,1] 范围。


float2 computeStretchMap(float3 worldCoord : TEXCOORD0)
{

  float3 derivv = ddy(worldCoord);
  float stretchU = 1.0 / length(derivu);
  float stretchV = 1.0 / length(derivv);
  return float2(stretchU, stretchV); // 一个双分量纹理 }

卷积着色器

可选：多尺度伸缩

伸缩贴图在网格的每个三角形内是常量，因此在某些三角形边缘处不连续。对很小的卷积这应该不成问题，但伸缩值的高频变化可能在非常大的卷积中造成高频瑕疵。用于计算伸缩的导数只考虑两个相邻纹素，因此这些值可能不足以代表比如 64 个纹素宽度上的平均伸缩。

更通用的做法是把用于卷积辐照度的卷积遍复制一份，对伸缩贴图也做卷积。然后用伸缩贴图的第 k 次卷积去卷积第 k 张辐照度纹理。这个思路是：选一张已用你即将使用的同一半径做过局部平均的伸缩贴图，用那个平均值来校正当前对辐照度的卷积。

示例 14-5　可分离卷积着色器（U 纹理方向）

七个抽头的最终间距由伸缩值与所要卷积的高斯的宽度共同决定。


float4 convolveU(float2 texCoord
                 : TEXCOORD0,
                   // Scale —— 用于加宽高斯抽头。
                   // GaussWidth 应为标准差。
                   uniform float GaussWidth,
                   // inputTex —— 被卷积的纹理
                   uniform texobj2D inputTex,
                   // stretchTex —— 双分量拉伸纹理
                   uniform texobj2D stretchTex)
{
  float scaleConv = 1.0 / 1024.0;
  float2 stretch = f2tex2D(stretchTex, texCoord);
  float netFilterWidth = scaleConv * GaussWidth * stretch.x;
  // 高斯曲线 —— 标准差为 1.0
  float curve[7] = {0.006, 0.061, 0.242, 0.383, 0.242, 0.061, 0.006};
  float2 coords = texCoord - float2(netFilterWidth * 3.0, 0.0);
  float4 sum = 0;
  for (int i = 0; i < 7; i++)
  {
    float4 tap = f4tex2D(inputTex, coords);
    sum += curve[i] * tap;
    coords += float2(netFilterWidth, 0.0);
  }
  return sum;
}

把漫反射颜色贴图纳入散射模型有几种可选方式。由于该模型推导时假定材料完全均匀，这些技术没有一种完全基于物理，各自可能适用于不同场景。

散射后贴图

一种选择是先做所有散射计算而不带任何颜色，得到一个处处平均为白色的值，然后乘以漫反射颜色贴图得到所需肤色。用代码清单 14-6 的代码把扩散剖面归一化为白色，即把每个高斯权重除以所有权重之和。辐照度纹理计算中不使用漫反射颜色。这样得到的散射光平均为白色（更确切地说，是入射光的颜色），所有辐照度纹理的最终线性组合看起来如 图 14-22（右上）所示。漫反射颜色纹理在散射之后相乘：结果显示在 图 14-22（右下）（也加了镜面反射）。所有高频纹理细节都保留下来，因为它们没有被卷积遍模糊，但肤色之间不会出现颜色渗溢，这可能让这个选择不合意。不过，如果漫反射贴图来自真实皮肤的照片，自然的颜色渗溢已经发生了，再做额外的模糊可能并不合适，因此这种散射后贴图可能是最好的选择。本章中 XYZ RGB, Inc. 的 Adrian 数据集图像（前面 图 14-15 中展示过）就是用散射后贴图渲染的。

Donner 与 Jensen 2005 建议也用与辐照度卷积完全相同的剖面去卷积漫反射颜色贴图，以获得恰当的颜色渗溢，再把这个卷积后的颜色值乘以卷积后的辐照度（后者是另外卷积的）。这与下一个选项散射前贴图略有不同：一个是乘积的卷积，另一个是卷积的乘积，视所用漫反射贴图而定，两者都可能更好看。

散射前贴图

纳入漫反射颜色变化的另一种方式是散射前贴图。在计算辐照度纹理时把光照乘以漫反射颜色，最终遍中就不再使用颜色。这样漫反射颜色会像光一样被散射，从而变模糊、变柔和，如 图 14-22（左下）所示。

这种方法的潜在缺点是可能损失太多高频细节，例如胡茬，它位于皮肤各层的最上面，在光正要射出时将其吸收。不过，把两种技术结合起来很容易实现，既能带来一定的颜色渗溢，又能保留颜色贴图中的部分高频细节。

结合散射前与散射后贴图

一部分漫反射颜色可以在散射前施加，其余在散射后施加。这样有些颜色细节会因散射而变柔和，同时有一部分仍保持锐利。由于漫反射颜色贴图包含最终想要的肤色，我们不能把 diffuseColor 乘两次。替代做法是，模糊前把光照乘以 pow(diffuseColor, mix)，模糊后把全部模糊纹理组合后的结果乘以 pow(diffuseColor, 1 – mix)。mix 值决定散射前与散射后各施加多少颜色，最终肤色仍是想要的 diffuseColor 值。mix 取 0.5 相当于皮肤表面最顶上有一层无限薄的吸收层，光恰好被吸收两次：进入散射前一次，离开时一次。这大概是这些方法中最物理合理的一种，也是 Weyrich 等 2006 所用的技术。

本章中 Doug Jones 的图像（例如 图 14-1）使用 mix 值 0.5。不过视漫反射颜色纹理及其生成方式而定，其他值可能更好看。当 mix 恰好取 0.5 时，可把 pow(diffuse-Color, 0.5) 指令替换为 sqrt(diffuseColor) 以获得更好的性能。

用同一套法线计算镜面光与漫射光

有一种对次表面散射的近似做法，是为镜面光照与漫射光照使用不同的法线贴图（或凹凸高度/置换贴图），以此模仿漫射光照的柔化（甚至可以像 Ma 等 2007 所述，为红、绿、蓝漫射光照各自用单独的贴图）。镜面光照直接从表面反射，完全不被扩散，因此它体现出皮肤表面最剧烈的高频变化。其余（非镜面）光照经皮肤扩散，使表面细节——凸起、毛孔、皱纹等等——造成的高频光照变化变柔和，其中红光在皮肤次表面层中扩散得最远，柔化得最多。然而，单纯把法线贴图模糊并不能正确扩散肤色或实际光照本身。由于本章介绍的方法直接建模了造成表面细节柔化的次表面散射，镜面与漫射计算都应使用真实的法线信息。

处理接缝

纹理接缝会给纹理空间扩散带来问题，因为网格上相连的区域在纹理空间中是断开的，难以在它们之间扩散光。纹理空间的空白区域会沿每条接缝边缘糊到网格上，在渲染时把卷积后的辐照度纹理贴回网格就会造成瑕疵。

一个简单的解决办法是用一张贴图或 alpha 值来检测辐照度纹理是否在接缝附近的区域（甚至空白区域）被访问。检测到这种情况时，就关闭次表面散射，改用等效的局部光照计算替代漫反射反射率。一次 lerp 在散射的漫反射光与非散射的漫反射光之间混合，使过渡平滑（alpha 贴图会预先模糊，以得到平滑的 lerp 值）。此外，把所有接缝边缘处的拉伸纹理涂成黑色，会使卷积核在这些区域完全不进行模糊，从而缩短必须关闭散射的、距接缝边缘的距离。这个方案会让物体所有存在接缝的地方都出现僵硬、干枯的皮肤，可能很显眼，但它在 NVIDIA 的「Froggy」和「Adrianne」演示中效果良好。本章所示的头部模型，其 UV 映射填满整个纹理空间，因此不需要这些技术。只有在非常特定的光照设置下才会看到令人不适的接缝。

更复杂的方案是为计算辐照度纹理而复制网格中的部分多边形。如果有足够的空间，就把所有贴着接缝边缘的多边形复制一份，放到接缝边缘处空白的纹理空间里。如果光散射的距离永远不超过这些额外多边形的厚度，空白区域就不会扩散到被访问的纹素上，光也能正确地跨接缝边缘散射。这些额外多边形只在辐照度纹理遍中渲染，不参与最终渲染遍。复制的多边形可能需要在纹理中少数几处重叠，但这不应造成明显的瑕疵。我们预期这一技术能适用于许多网格，只是我们尚未亲自尝试。

更通用的方案是找出许多相互重叠的表面参数化，使每一点在至少一张纹理中都距接缝边缘有一段安全距离。辐照度纹理的计算与卷积遍对每个参数化各做一次（也可以把多个参数化存进同一张纹理），再用一组单位分解——对应每个参数化各一个权重——在表面的每一处混合不同的纹理组。这在接缝边缘靠近的位置「关闭」坏纹理坐标，在好的位置「打开」。这些权重在每一处都应求和为 1.0，并在表面上平滑变化。对每个表面位置，所有非零权重都应只对应距接缝边缘安全距离的参数化。计算这类参数化及其相应单位分解的技术可参见 Piponi and Borshukov 2000。给定单位分解后，整个纹理空间扩散算法对每个参数化各跑一遍，再用单位分解的权重混合结果。这需要相当多的额外着色与纹理内存，代价相对高昂，但很可能仍优于其他次表面散射实现。

精确的能量守恒

镜面反射率与漫反射反射率通常被完全独立地处理，不考虑入射与出射角度。这种做法从能量角度忽略了二者之间微妙的相互作用：如果镜面反射（不只是单个视线方向，而是所有可能视线方向的整个半球）消耗掉比如 20% 的入射光，那么留给漫反射的就不超过 80%。这看似没问题，因为着色常被算成 Ks * specular + Kd * diffuse，其中 Ks 与 Kd 是常数。但镜面反射消耗的能量总量高度依赖 N 与 L 之间的夹角，两者的常数混合并不守恒能量。这一课题已在耦合反射模型中处理过，例如 Ashikmin and Shirley 2000 与 Kelemen and Szirmay-Kalos 2001，Donner and Jensen 2005 也针对次表面散射处理过。由此得到的非兰伯特漫反射光照在 GPU 上很容易计算。由于我们渲染的是皮肤，这里只讨论次表面散射的版本。

float computeRhodtTex(float2 tex : TEXCOORD0)
{
  // 在半球上对镜面 BRDF 分量积分
  float costheta = tex.x;
  float pi = 3.14159265358979324;
  float m = tex.y;
  float sum = 0.0;
  // 用更多项可以获得更高精度
  int numterms = 80;
  float3 N = float3(0.0, 0.0, 1.0);
  float3 V = float3(0.0, sqrt(1.0 - costheta * costheta), costheta);
  for (int i = 0; i < numterms; i++)
  {
    float phip = float(i) / float(numterms - 1) * 2.0 * pi;
    float localsum = 0.0f;
    float cosp = cos(phip);
    float sinp = sin(phip);
    for (int j = 0; j < numterms; j++)
    {
      float thetap = float(j) / float(numterms - 1) * pi / 2.0;
      float sint = sin(thetap);
      float cost = cos(thetap);
      float3 L = float3(sinp * sint, cosp * sint, cost);
      localsum += KS_Skin_Specular(V, N, L, m, 0.0277778) * sint;
    }
    sum += localsum * (pi / 2.0) / float(numterms);
  }
  return sum * (2.0 * pi) / (float(numterms));
}

14.5.3 改进的半透明阴影贴图

纹理空间扩散捕捉不到完全穿过耳朵、鼻孔这类薄区域的光——这些地方两个表面位置在三维空间中贴得很近，在纹理空间中却相距很远。我们修改了半透明阴影贴图（TSM）（Dachsbacher and Stamminger 2004），通过复用卷积后的辐照度纹理，非常高效地估计穿过薄区域的扩散。

与传统半透明阴影贴图不同，我们不为最靠近光源的表面上每个点（朝向光源的表面）渲染 z、法线和辐照度，而是渲染 z 与该朝向光源表面的（u, v）坐标。这样阴影中的每个点都能算出一条穿过物体的厚度，并访问表面另一侧卷积后的辐照度纹理，如图 14-25 所示。

我们分析图 14-26 所示的简单场景，看如何计算全局散射。正在渲染的阴影点 C 需要汇总来自物体另一侧点 A 邻域内所有点的散射光。通常的做法是在 A 周围（在二维的朝向光源表面上）采样若干点，计算反射率[3]剖面 R(m)，其中 m 是 C 到 A 附近各点的真实距离。

我们可以用改进的 TSM 和卷积后的辐照度纹理来估计这一全局透射光。在任意阴影位置 C，TSM 给出距离 m 以及朝向光源表面上点 A 的 UV 坐标。我们想估计在 C 处出射的散射光，它是朝向光源的各点与剖面 R 的卷积，其中 C 到每个采样点的距离要各自单独计算。不过，改为在 B 处计算这件事要容易得多；在小角度 下，B 会接近 C。 对于大 ，菲涅尔项与 N · L 项会使贡献变小，从而掩盖大部分误差。在 C 处计算正确值很可能不值得那份可观的代价。

这里我们利用了高斯函数在第三维上的可分离性，把关于 的函数变换成关于 r 的函数。这很方便，因为朝向光源的各点已经用 G(vi , r) 在 A 处卷积过了（这正是我们存在每张卷积辐照度纹理里的内容）。于是，在位置 C 处出射的总漫反射光（实际在 B 处估计）等于 k 次纹理查找之和（使用 TSM 中存的位置 A 的（u, v）），每次用 wi 以及基于 vi 与 d 的指数项加权。这一变换之所以成立，是因为高斯和扩散剖面中的每个高斯都是可分离的。若用扩散剖面 R(r) 对朝向光源的各点做单次二维卷积，就无法用于计算 B 或 C 处的散射（只能用在 A 处）。

阴影贴图算出的深度 m 需用 cos() 修正，因为这里用的是扩散近似，最直接的厚度更为适用。程序比较 A 与 C 处的表面法线，仅当两个法线朝向相反时应用这一修正。当两个法线接近垂直时，一次简单的 lerp 把该修正混合回原始距离 m。虽然在平面情形下推导，这一技术在耳部这样的非平面表面上也相当有效（如图 14-27 所示）。

到目前为止我们只考虑了穿过物体的一条光路，这会带来一些问题。由 TSM 算出的深度若出现高频变化，输出中就会出现高频瑕疵。对高散射的透光材质来说这不可取，因为这类材质会模糊所有透射光，不应有任何锐利特征。一个有用的技巧是把穿过表面的深度存进辐照度纹理的 alpha 通道，并随辐照度一起在表面上模糊。计算全局散射时，每个高斯使用相应的一份模糊后的深度版本。（计算第 i 个高斯时，我们用第 i - 1 张纹理的 alpha 作为深度。）这样穿过物体的每条光线都能考虑若干不同路径的平均，每个高斯也能挑选合适的平均值。为了把距离值塞进 8 位 alpha，我们对某个常数 d 存 exp(-const * d)，在表面上对这一深度的指数做卷积，查表后再取反。见代码清单 14-9。

{

多光源与环境光照

扩展 TSM 技术是在假设单个点光源、单个 TSM 的前提下推导的。使用多个 TSM 时，需要为每盏灯生成卷积辐照度纹理并分别存放。（每个 TSM 都需要一套只属于该光源的卷积辐照度纹理。）这需要很多额外的模糊遍与额外的纹理内存。一种可能的规避办法是用多个 TSM 算出穿过表面的所有深度的最小值，再在表面上对这一最小值做卷积。在最终着色器中可以访问每个 TSM，并用所有算出的厚度中最小的那个所对应的（u, v）做一次 TSM 全局散射计算。这当然是一种近似，但避免了让整个纹理空间扩散算法的开销随点光源数量成倍增长。

总的来说，我们发现改进的半透明阴影贴图在戏剧性光照下效果良好（图 14-27），但在明亮的环境光照下，耳朵仍然显得有些实。这在离线渲染中也是常见现象，Donner and Jensen 2007 已处理过。其解法代价相当高，目前也看不出有什么明显的实时近似。

14.6 快速的泛光滤波器

为加速次表面散射卷积所用的技术，一般也适用于其他不可分离的卷积，例如泛光滤波器。Pharr and Humphreys 2004 建议用 (1 - r/d)4 滤波器为最终渲染图像添加泛光（对 HDR 图像尤其好看）。这个滤波器不可分离，必须在二维上暴力计算。不过它用两个高斯之和就能很好地近似，而用于改进纹理空间扩散的那套可分离、层级式卷积技术（不含拉伸纹理）也能高效地求值它。对 d = 1，(1 - r)4 可用 0.0174 G(0.008, r) + 0.192 G(0.0576, r) 很好地近似。图 14-29 展示了用这个双高斯核计算 HDR 泛光滤波的皮肤渲染图像。

Craig Donner 与 Henrik Wann Jensen 在 2005 年的开创性工作给了我们极大启发。希望读者也像我们一样受到启发，在自己的应用允许的范围内尽可能贴近地近似这些结果乃至未来的结果，做出尽可能逼真的实时角色。

14.7.1 未来工作

本章聚焦实时面部渲染，但许多技术也适用于各种高散射透光材质。我们预期，为高效 GPU 渲染而开发的这些次表面散射算法，在离线渲染管线中也可能有用。

我们介绍的皮肤渲染技术对面部效果极佳，但纹理接缝给一般表面的渲染带来困难，尤其是手和脚。针对接缝讨论的几种解法需要更细致地研究，以确定它们能在多大程度上无需用户干预而自动处理（这或许能让纹理空间扩散的想法更适用于通用渲染），并检验改进后的纹理空间扩散能否用于更一般的透光材质渲染。

按多尺度法线曲率修正纹理空间卷积核，对面部渲染的效果可忽略不计，但这类的改进与多尺度拉伸修正应当继续探究，以确定当表面曲率与散射的有效半径相当时，纹理空间扩散能在多大程度上生成逼真的次表面散射图像。Donner and Jensen 2007 给出了曲面中漫反射散射更准确的解法，改进实时散射技术时应参考他们的结果。

就一般的皮肤渲染而言，Donner and Jensen 2006 的光谱双向表面散射反射率分布函数（BSSRDF）模型与五层 BioSpec 模型（Krishnaswamy and Baranoski 2004）应能给出更准确的图像，但尚未有将这些模型与 Donner and Jensen 2005 的三层皮肤模型作精确对比的工作。这些更符合物理的模型究竟带来多大视觉影响，目前并不清楚。特别是，比较在 3–150 范围内取不同色带数目的光谱皮肤渲染，会很有说明性。把 Donner 与 Jensen 的扩散模型与基于 BioSpec 模型的完整蒙特卡洛真值仿真做尽可能精确的对比，也应能揭示用两三层代替五层所带来的简化影响，以及假定扩散近似究竟丢失了什么。

单次散射在次表面散射仿真中常被忽略，皮肤渲染尤其如此。Hanrahan and Krueger 1993 的方法因粗糙表面层而不能直接套用——这层粗糙表面把单次散射过程变成了三次散射过程。次表面散射中这一方向性成分到底有多重要，可用蒙特卡洛方法研究。若在掠射角下足够显著，可以把次表面辐照度解耦为漫反射与单次散射两部分，从而将这一成分建模为 BRDF 或 BSSRDF。基于stratum corneum（表皮最外层）细胞模型的、针对表皮的、基于物理的双向透射率分布函数（BTDF）（Stam 2001）应能提供最好的数据。

纳入肤色的变化目前仍是一个颇为随意的过程。未来的工作若能以可预期良好结果的方式捕捉、纳入并编辑肤色变化，将非常有益。Weyrich et al. 2006 与 Tariq et al. 2006 指出了各向异性以及面部不同区域散射系数的差异。一套能快速捕捉面部空间变化、具备多层保真度的扩散剖面的系统，也可能改善图像质量。

凹凸散射（asperity scattering）（Koenderink and Pont 2003）尚未被建模，应纳入进来以模拟面部毛发的散射。

Torrance/Sparrow 镜面 BRDF 或许可以通过拟合真实皮肤反射率的实测数据、或基于角质层细胞物理模型的表面散射仿真来改进。BioSpec 中就用了这样一个 BTDF 模型。Debevec et al. 2000 的偏振技术应能直接测量真实皮肤纯镜面部分的精确 BRDF。
