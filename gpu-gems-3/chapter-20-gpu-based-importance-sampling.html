20.1 引言

高动态范围（HDR）基于图像的光照下，表面的高保真实时可视化，为各种计算机图形应用提供了极有价值的资源。材质设计、光照设计、建筑预演以及游戏只是其中几个应用。环境贴图预滤波技术（Kautz 等 2000）——加上用小波（Wang 等 2006）或球谐函数（Ramamoorthi 与 Hanrahan 2002）的其他频域方案——能提供实时可视化。但它们的用法可能过于笨重，因为要为光泽表面反射做大量预计算，或者需要相当规模的代码库。

作为替代，我们给出一项用蒙特卡洛求积对光泽物体做基于图像光照的技术，它只需极少的预计算，并在单个 GPU 着色器内运行，因此能轻松融入几乎所有需要材质或光照实时动态变化的制作管线。图 20-1 给出了我们的结果示例。

20.2 渲染的表述

渲染的目标是：对每个像素，计算给定表面点处周围环境有多少光反射向虚拟相机，如图 20-2 所示。要把来自某一特定方向的入射光 L i (u) 转换为反射向相机方向 v 的光，我们使用材质函数 f，即所谓的双向反射分布函数（BRDF）。一种常见的 BRDF 是经典的 Phong 反射模型。要计算总的反射光 L o (v)，必须把所有入射方向 u 的贡献在半球 H 上求和（在极限意义下即积分）：

公式 1

这个公式称为反射率方程或光照积分。其中 u 是表面法线与入射光方向 u 之间的夹角。

在基于图像的光照中，入射光 L i 用环境贴图近似，其中每个纹素对应一个入射方向 u，且忽略遮蔽。不过即便有这一近似，要为一个像素对光照积分做数值积分，仍需把环境贴图中成千上万个纹素与 BRDF 相乘再求和。对实时渲染而言，这个运算的计算量显然太大。

20.2.1 蒙特卡洛求积

我们无法为所有入射方向计算光照积分，于是随机选取若干方向，在这些方向上计算被积函数 L i (u)f (u, v)cos u ，得到采样，即对积分的估计。这些采样的平均值给出积分的近似，这正是蒙特卡洛求积的精髓。事实上，如果我们有无限多个采样，其平均值就等于积分的真值。但当我们只用有限的、实际可行的采样集时，平均值会偏离真实解，并在图像中引入噪声，如图 20-5b 所示（见 20.4 节）。减少这种噪声的一种办法是挑选最重要的那些采样，使它们最能近似该积分。

20.2.2 重要性采样

如果对被积函数的行为有大致的了解，生成均匀随机方向就不是近似积分的最好方法。例如，若我们要把光泽材质与环境做积分，最合理的做法是在镜面反射方向（也就是镜像反射方向）附近采样，因为大部分反射光都来自这些方向。为了在数学上表达这一点，用概率密度函数（PDF）来定义最优的采样方向。PDF 是一个归一化函数：在整个定义域上的积分为 1，其峰值代表重要的采样区域。

不过当我们使采样方向有偏时，各个积分估计并不等价，因此在求所有采样的平均值时必须相应地加权。例如，PDF 低值区域中的一个采样，代表性相当于均匀采样下的许多个采样。同样，PDF 高值区域中的一个采样，只代表均匀采样下少数几个采样。为补偿这种与 PDF 成比例的采样方式，我们把每个采样乘以 PDF 的倒数。这样就得到使用所有采样加权平均的蒙特卡洛估计量：

20.2.3 对材质函数采样

由于 BRDF 是积分的一部分，它很适合作为引导采样、以产生最接近积分的方向的度量。这里我们用归一化的 BRDF 作为采样的 PDF。要对该 PDF 采样，我们把一对随机数转换为 BRDF 的一个重要方向。例如本节稍后的公式 7 与公式 8 就为 Phong BRDF 的镜面波瓣做了这种转换。如果你对这些采样公式是怎么推导出来的感兴趣，请继续往下读。

我们通过把 PDF 转成累积分布函数（CDF）来求采样方向。直观地看，可以把 CDF 理解为「与 PDF 成比例的分布」与「均匀分布」之间的映射。在只有有限个采样的离散情形，我们可以把各个采样堆叠起来定义 CDF。例如，若把渲染的所有可能采样方向划分为四个离散方向，其中某个采样方向 S2 先验 已知更重要，那么这四个采样的概率可以如图 20-3 所示堆叠在一起。

在这种情况下，如果我们取一个随机数，且 0 到 1 之间任何值被取到的可能性相同，那么会有更多随机数映射到重要的采样 S2，于是我们会更频繁地在该方向上采样。

20.4 经 mipmap 滤波的采样

如图 20-5a 所示，确定性的重要性采样会造成尖锐的走样瑕疵，看起来像重复的镜面反射。在标准蒙特卡洛求积中，对付这个问题的办法是引入随机性，它把走样变成视觉上更可接受的噪声，这一点在图 20-5b 中很明显。不过要把噪声水平压得低，每个像素就需要用到几百乃至几千个采样——这显然不适合在 GPU 上做实时渲染。我们采用另一种做法——用 mipmap 滤波——来减少采样数少所引起的走样，如图 20-5c 所示。

思路如下：如果某个采样方向的 PDF 很小（即该采样不太可能出现），那么在相近方向上生成其他采样的可能性就不大。这种情况下，我们希望该采样带来的是环境贴图在较大区域上的平均值，从而更好地近似整体积分。反过来说，如果一个方向的 PDF 很高，就很可能在相近方向上生成许多采样。于是多个采样会帮助平均掉该区域带来的积分估计误差。这种情况下，该采样只应对环境贴图中很小的一块区域取平均，如图 20-6a 所示。

20.4.1 映射与畸变

环境映射通常使用立方体贴图。不过，立方体贴图虽然畸变很低（这是好事），却有一个严重缺陷——mipmap 是分别对每个面生成的。遗憾的是，我们的滤波操作假定 mipmap 由整张环境贴图的像素取平均生成。因此，我们需要一种办法，把环境贴图尽可能多的周边信息引入单张图像，从而在不改动硬件加速 mipmap 生成的前提下减轻 mipmap 产生的接缝状瑕疵。

于是我们不用立方体贴图，而用双抛物面环境贴图（Heidrich 与 Seidel 1998，Kilgard 1999）。环境存放在两张纹理中：一张表示上半球（z≥ 0）的方向，另一张表示下半球（z < 0）的方向。虽然两张纹理的 mipmap 是分别计算的，渲染出的图像中却很少出现瑕疵。为什么呢？因为对应每个半球的那张纹理都含有来自对面半球的一些信息。

不过渲染图像中仍偶有接缝，可能对应于在图 20-7a 中的圆与纹理边缘相接的位置对环境贴图采样。为改善这种情况，我们在常规抛物面映射上加一个 1.2 的缩放因子 b，以引入更多来自对面半球的信息，如图 20-7b 所示。

如代码清单 20-1 所示，算法的实现直接来自蒙特卡洛估计量（公式 2）与 mipmap 层级的计算（公式 13）。为优化画质与性能，我们用球谐函数表示材质的漫反射分量（Ramamoorthi 2001）。球谐函数很适合低频的漫反射着色，配合我们用于光泽着色的采样方法，构成一个理想的混合方案。

图 20-8a 相对于参考解绘制了近似的误差，表明渲染的保真度直接与所用采样数相关。实践中，几何形状复杂的表面只需 24 个或更少的采样。而像图 20-8b 中的球体那样光滑的表面，往往需要更多采样，但 40 个采样就足以给出视觉上可接受的结果。因此，与基于小波的方法很像，经滤波的重要性采样不需要很多采样就能产生准确的光泽表面反射。此外，图 20-9 表明我们的技术在多种 GPU 上表现良好，且性能几乎随采样数线性变化。

示例 20-1. 我们的采样算法的伪代码

着色器的实际实现与这段伪代码看起来略有不同，但它确实只是一个优化版本。最重要的优化是这几项：(1) 并行生成四个方向。(2) BRDF 不被显式求值，因为它只以「除以 PDF」的形式出现，而这里大部分项都会被约掉。(3) 与用 Hammersley 序列（公式 10）生成采样方向相关的三角函数已预先算好。


float4 GPUImportanceSampling(
  float3 viewing : TEXCOORD1
   uniform sampler2D env) : COLOR
{
  float4 c = 0;
  // 采样循环
   for (int k=0; k < N; k++) {
    float2 xi = hammersley_seq(k);
    float3 u = sample_material(xi);
    float pdf = p(u, viewing);
    float lod = compute_lod(u, pdf);
    float2 texcoord = convert_to_dual_paraboloid(u);
    float3 L = tex2Dlod(env, float4(texcoord, lod.xy));
    c += L*f(u,viewing)/pdf;
  }
  return c/N;
}

20.6 结论

我们基于 GPU 的重要性采样是一种实时渲染算法，适用于由环境贴图照亮的各种参数化材质模型。用基于 mipmap 的滤波执行蒙特卡洛积分，足以把重要性采样的计算复杂度降到能在单个 GPU 着色器内完成的程度。这种组合还表明，非 BRDF 专用的滤波器（例如 mipmap）就足以近似光照积分。因此，BRDF 与环境都可以实时改变。

既然 BRDF 与环境可以完全动态，材质或光照设计这类应用的可视化就变得轻而易举，并能提供全新的用户界面。在图 20-10 中，我们展示了这样一个用于空间变化 BRDF 绘制程序的界面，用户可以选定一种 BRDF 参数化，并实时把它绘制到网格上。总的来说，我们的技术只用一个着色器就能发挥 GPU 的计算能力，因此容易集成进现有的制作管线。
