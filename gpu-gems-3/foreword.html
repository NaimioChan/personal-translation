组合——把基本操作组织成一个并不显而易见的整体——是指令式编程的精髓。微处理器的指令集体系结构（ISA）是一个通用的组合接口，软件渲染器的程序员们曾有效而有创意地利用它来追求图像的真实感。早期图形硬件提升了渲染性能，但往往在可组合性上代价很高，进而牺牲了可编程性与应用创新。具备类微处理器可编程性的硬件确实出现过（例如 Ikonas Graphics System），但图形硬件加速的主流形式一直围绕着固定的渲染操作序列来组织，这个序列常被称为图形管线。这类系统的早期接口——如 CORE 以及后来的 PHIGS——允许程序员指定渲染结果，但它们并不是为组合而设计的。

OpenGL 是我在 20 世纪 90 年代初帮助其从 Silicon Graphics 定义的 IRIS GL 演化而来的，它通过规定一种体系结构（非正式地称为 OpenGL Machine）来满足可组合性的需求，并通过命令式编程接口访问该体系结构。许多特性——例如严格规定的语义；模板与深度缓冲函数这类表驱动操作；作为通用一维、二维、三维查找函数暴露的纹理映射；以及所要求的可重复性——确保程序员能够组合 OpenGL 操作，得到强大而可靠的结果。OpenGL 带来的有用技术包括基于纹理的体积渲染、用模板缓冲实现的阴影体，以及封盖（计算裁剪平面与由多边形定义的实体对象相交处的表面平面）这类构造实体几何算法。最终，Mark Peercy 与 SIGGRAPH 2000 论文「Interactive Multi-Pass Programmable Shading」的合著者们证明，任意的 RenderMan 着色器都可以通过组合 OpenGL 渲染操作来加速。

在这十年间，集成电路技术原始能力的提升使 OpenGL 体系结构（以及后来的 Direct3D）得以扩展，暴露出 ISA 接口。这些扩展以图形管线内可编程顶点着色器与片元着色器的形式出现，如今又随 CUDA 的引入，以数据并行 ISA 的形式出现，能力已接近微处理器的 ISA。尽管通向完全类微处理器通用性的循环尚未走完，图形硬件加速的巨大威力对程序员而言却比以往任何时候都更容易获得。

这是何等的计算能力！在撰写本文时，NVIDIA GeForce 8800 Ultra 每秒执行超过 4000 亿次浮点运算——超过十年前最强的超级计算机，也是当今最强微处理器的五倍。Ultra 支持的数据并行编程模型让这份算力得以发挥，而无需操心使用了多少个处理器。这一点至关重要，因为今天的 Ultra 已包含一百多个处理器，明天的将包含数千个，之后还会更多。集成电路密度逐年倍增（即摩尔定律）看不到尽头，大规模并行系统显然是计算的未来，而图形硬件正走在这条路上。

GPU Gems 3 是一本当前最先进的 GPU 编程实例集。它讲的是如何把数据并行处理用起来。前四部分聚焦 GPU 在几何、光照与阴影、渲染和图像效果方面的图形专用应用。第五、第六部分的主题则拓宽了范围，给出如今可以用数据并行 GPU 技术解决的非图形应用的具体实例。这些应用多种多样，从刚体仿真到流体流动仿真，从病毒特征匹配到加密解密，从随机数生成到高斯函数计算。

这一切通向何方？封面艺术提醒我们，心智仍是所有并行计算系统中最强大的一种。计算机科学的一个长期目标是达到并最终超越人类心智的能力。令人兴奋的是，当我们识别、应对并掌握大规模并行计算的种种挑战时，计算机图形学界正在为这个梦想的实现贡献力量。
