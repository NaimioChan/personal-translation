第五部分：物理仿真

物理仿真具有高度的数据并行性，且计算密集，很适合放到 GPU 上执行。再者，仿真的结果往往还要交给 GPU 做可视化，所以让 GPU 直接把它生成在显存里也是合理的。本节汇集了几个成功的 GPU 实现，涉及物理仿真中使用的多种算法。随着 GPU 变得更多能、更强大，这类实现必然会越来越多。

电子游戏、虚拟现实系统和计算机生成电影大量使用基于物理的仿真来提升其世界的真实感。物理引擎让这些世界中大多数物体动起来所用的第一种基本方法是刚体动力学。在第 29 章「GPU 上的实时刚体仿真」，Takahiro Harada（东京大学）提出一种在 GPU 上实现刚体动力学的方法，把刚体表示为粒子集合。该做法依托 GPU 强大的浮点处理能力，给出一条用精度换速度的直接途径。此外，它还能自然扩展到流体等非刚体，使刚体与非刚体在同一套统一框架中运动和交互。

水、火、烟是另外几个让虚拟世界鲜活起来的关键要素，而流体仿真是高质量实现这些效果的最佳技术。在第 30 章「3D 流体的实时仿真与渲染」，Keenan Crane（伊利诺伊大学厄巴纳-香槟分校）以及 NVIDIA 公司的 Ignacio Llamas 与 Sarah Tariq 表明，体积流体仿真对今天的游戏来说是可行的方案。作者完整描述了从 GPU 仿真到渲染的全过程，说明他们如何在实际游戏中运用这一方法，得到与动态环境融合、交互的动人画面。

当然，物理仿真存在于计算机图形之外的许多领域。尤其是 N 体问题——模拟 N 个物体组成的系统，其中每个物体对其他所有物体施加作用力——出现在天体物理、分子动力学、等离子体物理以及辐射度渲染等差别极大的领域。在第 31 章「用 CUDA 做快速 N 体仿真」，Lars Nyland（NVIDIA）、Mark Harris（NVIDIA）与Jan Prins（北卡罗来纳大学教堂山分校）展示了如何最好地把该问题映射到 CUDA 编程模型。不仅如此，他们解决问题之高效，使其实现的性能数倍于优化过的 CPU 实现。

多数物理仿真中非常耗时的环节是碰撞检测，因此这项任务也是优化的主要目标。本部分的两章承担这一任务，并借助 CUDA 取得显著加速。在第 32 章「用 CUDA 做粗筛阶段碰撞检测」，Scott Le Grand（NVIDIA）聚焦碰撞检测的粗筛阶段，快速剔除不可能相撞的物体对。他给出基于并行空间细分的 CUDA 实现。特别是，Le Grand 说明了如何组合并行归约、前缀和等基本并行编程技术，得出基数排序的 CUDA 实现——这是整个算法的关键一步。接着，在第 33 章「用 CUDA 做碰撞检测的 LCP 算法」，Peter Kipfer（Havok）聚焦碰撞检测的精筛阶段，即对粗筛之后剩下的每一对物体做精确碰撞检测。计算两个凸多面体之间的距离可以转化为线性互补问题，他用并行算法求解，并在 CUDA 中做了恰当的实现。

GPU 也能加速数据预处理，哥本哈根大学的 Kenny Erleben 与 3Dfacto R&D 的 Henrik Dohlmann 在第 34 章「用单遍 GPU 四面体扫描转换生成有符号距离场」中展示了这一点。距离场给出空间中任意点到物体表面的距离，在碰撞检测（尤其是刚体与可变形体之间）中有应用，在建模、光线追踪、路径规划等许多其他领域也有应用。本章中作者描述了一种适合 GPU 实现的距离场计算算法。他们说明如何用任何可编程 GPU 以直接的方式显著加速它。最新一代 GPU 带来了许多新特性，可以把算法的更多部分移植过去。

Cyril Zeller, NVIDIA Corporation
