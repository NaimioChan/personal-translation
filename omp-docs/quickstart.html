快速上手

安装 omp，选择提供商与模型，完成你的第一个编码任务。

omp 在你现有的项目里工作：用自然语言描述一项改动，让代理检查并修改代码，然后审阅结果并继续对话。本指南带你从安装走到第一次可恢复的会话。

1. 安装 omp

在 macOS 或 Linux 上：

curl -fsSL https://omp.sh/install | sh

在 Windows 上，请在 PowerShell 中运行：

irm https://omp.sh/install.ps1 | iex

确认可执行文件已可用：

omp --version

如果你的 shell 找不到 omp，请按照安装器打印的 PATH 提示操作，然后打开新的终端重试。

2. 打开你的项目

切换到你想让 omp 处理的项目。启动 omp 时所在的目录会成为该会话的项目根目录。

cd ~/code/my-project

把 ~/code/my-project 换成你项目的路径。

如果你使用 API 密钥，请在启动前于该终端中导出。例如：

export ANTHROPIC_API_KEY=sk-ant-...

如果你使用带浏览器登录的提供商订阅，可以跳过这条命令；首次运行设置会帮你登录。

现在启动交互式应用：

omp

3. 登录并选择模型

首次启动会打开设置向导。

  1. 在 Set up your providers 界面，保持选中 Sign in 标签页，选择你的提供商，然后按 Enter。完成浏览器登录后回到终端。你可以登录多个提供商。
  2. 如果你改为导出了 API 密钥，它已经对 omp 可用；按 Esc 离开提供商步骤。
  3. 连接完提供商后，按 Esc。
  4. 在 Choose your default model 界面，输入以搜索，高亮你已配置的提供商下的某个模型，然后按 Enter。omp 会为新会话保存这个选择。
  5. 完成其余终端外观相关的提示。它们会在保存前预览每个选择。

之后的启动会直接进入提示词。使用 OAuth 的用户可以用 /login 重新打开登录；使用 /model 更改当前会话的模型。

4. 给 omp 一个编码任务

在提示词处，用日常语言输入一个具体的结果。下面这个示例可以作为对不熟悉项目的首次巡览：

Inspect this project for one small bug or inconsistency that can be verified locally. Explain what you found, make the smallest safe fix, and run the most relevant check.

按 Enter。omp 会检查项目，把它的动作显示为工具卡片，在需要时编辑文件，并流式输出它的回复。按 Ctrl+O 展开或折叠完整的工具输出。

5. 审阅并继续

阅读最后的总结和所报告的检查结果。不必离开会话，就能请求一次聚焦的审查：

Show me the diff and explain each changed file. Do not make more changes.

然后像对待同事一样继续追问：

Looks good. Run the relevant check once more and summarize any remaining risk.

如果代理在某一轮次中走错了方向，按 Esc 打断它，然后澄清你的请求。

6. 退出与恢复

按 Ctrl+D 或输入 /exit 离开。omp 会自动保存会话。

要接着该项目最近一次的会话继续，请回到同一个项目目录并运行：

omp --continue

对话和所选模型会在同一个项目中重新打开，你可以直接发送下一条消息。若想从最近的会话中选择，请改为运行 omp --resume。

可选的后续步骤

你的第一个会话不需要配置文件。当你想自定义 omp 时，继续阅读：

  • 模型提供商：了解 API 密钥、OAuth 提供商与认证故障排查。
  • 自定义模型与提供商：当内置目录不够用时。
  • 设置：了解用户与项目配置。
  • 使用 omp：了解编辑器、消息队列与日常工作流。
  • 会话：了解恢复、分叉与会话历史。
  • 快捷键：了解全部默认控制方式。
