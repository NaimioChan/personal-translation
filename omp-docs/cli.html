命令行参考

用于启动 omp、编写脚本和运行维护命令的完整 shell 界面。

选择命令

单独运行 omp 可进入交互式编码会话。需要非交互式结果或管理任务时，可以添加提示词、通过管道传入文本，或选择专用命令。

目标最简命令
在当前目录打开交互式 TUIomp
带请求启动omp "Fix the failing tests"
将上下文附加到首个请求omp @plan.md @screenshot.png "Implement this"
打印一个回答后退出omp -p "Summarize this project"
将输入通过管道传给一次性运行git diff | omp -p "Review this diff"
继续此目录最近的会话omp -c
选择或命名已保存的会话omp -r 或 omp -r <id>
输出机器可读事件omp -p --mode json "Find every TODO"
启动协议服务器omp --mode rpc 或 omp acp
查找命令或其标志omp --help 或 omp <command> --help

命令行形式

omp [launch flags] [@files...] [messages...]
omp launch [launch flags] [@files...] [messages...]
omp <command> [arguments] [command flags]

launch 是默认命令。如果第一个非标志词不是已注册命令，omp 会把其余词视为初始请求。例如，omp "fix the build" 会启动会话，而 omp models 会列出模型。如果请求以命令名开头，请显式使用 omp launch …。

所有需要值的长选项都接受 --flag value 或 --flag=value。使用 -- 停止解析标志：

omp -- "Explain why --force is dangerous here"

已加载的扩展可以添加启动标志。除了下面列出的内置选项外，omp --help 也会显示这些标志。

启动输入与入口模式

提示词、文件、图片和 stdin

  • 普通位置参数会拼接为初始请求。
  • 在路径前加 @ 可附加该路径。文本会作为上下文纳入；受支持的图片会作为图片输入发送。大小限制和支持的来源见处理文件。
  • 当 stdin 不是 TTY 时，omp 会自动读取。无需使用 - 标记。
  • @file 不存在或不可读时，命令会失败，而不是静默忽略它。
  • rpc 或 rpc-ui 模式不会展开 @file 参数；请改为通过相应协议发送输入。
omp @requirements.md "Implement the first unchecked item"
omp @before.png @after.png "Match the second design"
printf '%s\n' 'Explain packages/core' | omp -p

输出与协议模式

入口行为
omp交互式文本模式：打开 TUI 并保持会话运行。
omp -p、omp --print无头文本模式：处理请求、写出回答，然后退出。
omp -p --mode json输出以换行符分隔的结构化事件流，供自动化使用。
omp --mode rpc通过 stdio 运行 JSON-RPC 服务器。参见 RPC 模式。
omp --mode rpc-ui运行 RPC，并启用 UI 扩展事件。
omp --mode acp、omp acp通过 stdio 运行 Agent Client Protocol 服务器。参见 ACP。

--mode text 是默认模式。--print 控制文本/JSON 运行是否在请求后退出；协议模式则会继续作为服务器运行。

启动标志

本节的标志适用于 omp 和 omp launch。omp acp 也接受相关启动标志，但它会强制使用 ACP 传输。

工作区与配置

标志作用
--cwd <dir>从此目录启动，而不是从 shell 当前目录启动。
--add-dir <dir>添加另一个工作区目录。可重复使用以添加多个目录。
--allow-home允许会话从 ~ 启动；否则 omp 会防止意外地把整个主目录当作项目。
--profile <name>为指定配置文件隔离认证信息、会话、设置和缓存。
--alias <command>为所选 --profile 创建 shell 快捷方式，然后退出。
--config <file>为此进程添加 YAML 设置覆盖文件。可重复使用；后面的文件优先。

配置按以下顺序合并：内置默认值、全局配置、项目配置、PI_CONFIG_FILES 中的文件、重复指定的 --config 文件，最后是启动标志等运行时覆盖项。首个存在的全局文件是 ~/.omp/agent/config.yml 或 ~/.omp/agent/config.yaml；原生项目设置位于 .omp/config.yml。环境变量的优先级由各自的解析器决定，并没有统一规则。参见设置和环境变量。

已保存的会话

标志作用
-c、--continue继续与当前项目关联的最近会话。
-r [id|path]、--resume [id|path]、--session [id|path]按 ID 前缀或 JSONL 路径恢复。未提供值时，打开会话选择器。
--fork <id|path>将已保存的会话分叉为新会话。
--from-claude导入 Claude Code 会话。
--from-codex导入 Codex 会话。
--session-dir <dir>覆盖用于会话存储和查找的目录。
--no-session让本次运行保持临时状态，而不是保存它。
--provider-session-id <id>复用外部签发的提供商会话 ID，以保持连续性并限定缓存范围。
--no-title跳过自动生成会话标题。
--export <session> [output.html]将已保存的 JSONL 会话渲染为 HTML 后退出。若省略输出路径，则根据会话文件生成输出名称。

模型与推理

标志作用
--model <id-or-role>通过模糊 ID、provider/model 或已配置的角色（如 slow 或 @slow）选择模型。
--provider <name>旧式提供商提示。优先使用 --model。
--api-key <key>为本次运行提供所选提供商的凭据；不会持久化。
--smol <id>覆盖快速/轻量模型角色。
--slow <id>覆盖深入推理模型角色。
--plan <id>覆盖计划模型角色。
--models <a,b,…>限制可供 Ctrl+P 切换的模型。模式可以包含 effort，例如 sonnet:high。
--thinking <level>设置为 off、minimal、low、medium、high、xhigh、max 或 auto。
--service-tier <tier>覆盖 OpenAI 系列的服务层级：none、auto、default、flex、scale 或 priority。none 会省略请求字段。
--provider-session-id <id>复用提供商端的会话 ID。
--prompt-cache-key <key>覆盖此会话的提供商提示词缓存键。
--hide-thinking在 TUI 中隐藏思考区块，但不改变模型推理。
--print-thoughts在打印模式的文本输出中包含思考区块。
--external-thinking使用私有草稿区，同时禁用受支持的提供商推理。此请求形式可能触发提供商的滥用控制；使用风险自负。

有关模型和凭据解析，请参见模型提供商；有关角色选择，请参见模型角色。

Prewalk 与计划执行

标志作用
--prewalk计划待办列表生成后，在首次编辑或写入时切换到快速模型。默认关闭。
--no-prewalk即使配置已启用，也禁用 prewalk。
--prewalk-into <id>选择 prewalk 目标；默认是 smol 角色。
--plan-yolo以只读计划模式启动，自动批准第一个已确定的计划，然后执行它。
--plan-yolo-into <id>选择执行 plan-yolo 计划的模型；默认是 smol。

参见Prewalk和计划模式。

能力、审批与运行时

标志作用
--tools <a,b,…>本次运行只提供指定的内置能力。
--no-tools禁用所有内置能力。插件提供的能力仍可能加载。
--no-lsp禁用语言服务器功能、格式化和诊断。
--no-pty禁用由 PTY 支持的交互式 shell 执行。
--approval-mode <mode>为此会话使用 always-ask、write 或 yolo。
--auto-approve、--yolo跳过所有操作的审批提示。
--advisor启用每轮被动审查并注入建议。参见顾问模型。
--max-time <duration>在指定的正秒数或时长（如 5s、10m 或 1h）后停止。

审批快捷方式会削弱交互式安全边界。参见工具审批和安全扫描。

扩展、钩子、技能与规则

标志作用
-e <path>、--extension <path>加载扩展文件。可重复使用。
--hook <path>通过同一加载器加载钩子/扩展文件。可重复使用。
--trusted-extension <absolute-path>从绝对路径加载可信扩展。可重复使用；不能与 -e、--extension 或 --hook 同时使用。
--plugin-dir <dir>将本地插件目录添加到发现范围。可重复使用。
--no-extensions禁用扩展发现。显式指定的 -e 和 --hook 路径仍会加载。
--skills <glob,…>只保留匹配逗号分隔 glob 模式的技能。
--no-skills禁用技能发现和加载。
--no-rules禁用规则发现和加载。

提示词与输出

标志作用
--system-prompt <text-or-file>替换默认系统提示词。如果值指向可读文件，omp 会读取它；否则该值作为文本字面量处理。
--append-system-prompt <text-or-file>把可读文件内容或文本字面量追加到默认提示词。
-p、--print不使用 TUI 处理请求，然后退出。
--mode <mode>选择 text、json、rpc、rpc-ui 或 acp。
--print-thoughts在打印模式的文本中包含推理区块。
--no-title跳过后台标题生成请求。
-h、--help打印帮助并退出。
-v、--version打印已安装的版本并退出。

Shell 补全

补全脚本根据实时命令注册表生成，包括嵌套操作和扩展提供的启动标志。

# zsh: add to ~/.zshrc
eval "$(omp completions zsh)"

# bash: add to ~/.bashrc
eval "$(omp completions bash)"

# fish: install once
omp completions fish > ~/.config/fish/completions/omp.fish

运行 omp completions bash、omp completions zsh 或 omp completions fish 可打印脚本。重启 shell 或加载其启动文件，然后输入 omp 并按 Tab 验证。

子命令参考

会话、协作与本地服务

命令语法、操作与标志
omp acp [launch flags]通过 stdio 启动 ACP。没有 ACP 专属公开标志；请使用适用的启动标志。
omp agents unpack [flags]写出捆绑的代理定义。--user 的目标是 ~/.omp/agent/agents（默认）；--project 的目标是 ./.omp/agents；--dir <path> 会覆盖两者；-f、--force 会覆盖文件；--json 输出 JSON。
omp browser-relay [serve|install] [flags]默认执行 serve。-p、--port <n> 选择端口；--token <value> 要求扩展 token；--dir <path> 选择安装目录；--no-group 不对 Chrome 标签页分组；-v、--verbose 记录流量摘要。参见电脑控制。
omp join <link>加入主持端提供的加密协作链接。没有命令专属标志。
omp ps [action] [name] [flags]list（默认）显示进程；info 显示单个进程；logs 读取输出；stop 请求正常关闭；kill 立即终止；restart 重启进程。-a、--all；-j、--json；--plain；--dir <path>；--global <scope>；-f、--follow；--head；-n、--lines <n>（最多 1000）；--grep <regex>；stop 的 --timeout <seconds>。
omp share <session> [--gist]共享会话 ID 前缀或 JSONL 路径。--gist 使用私密 GitHub gist，而不是共享服务器。
omp shell [flags]打开交互式控制台。-C、--cwd <dir> 选择其目录；-t、--timeout <ms> 设置每条命令的超时；--no-snapshot 跳过用户的 shell 快照。
omp stats [flags]打开用量仪表板。-p、--port <n> 和 --host <host> 绑定服务器；-j、--json 打印 JSON；-s、--summary 打印控制台摘要。
omp worktree [list|clear] [flags]默认执行 list。clear 移除托管条目；-n、--dry-run 预览操作；--all 包含仍在使用的 PR 检出工作树；-j、--json 输出 JSON。wt 是别名。

认证与提供商检查

命令语法、操作与标志
omp auth-broker [action] [source] [flags]serve 启动凭据保险库；token 打印或轮换其 bearer；login [provider]；logout [provider]；list 列出 OAuth 提供商；import <path> 导入凭据；migrate 上传本地凭据；status 检查配置的 broker。标志：--json；-b、--bind <host:port>；--regenerate；--via <user@host>；导入时使用的 --provider <id>；--include-disabled；--from-local；--include-env；--include-oauth；--dry-run。
omp auth-gateway [serve|token|status|check] [flags]serve 启动转发代理；token 打印或轮换其 bearer；status 显示 gateway/broker 配置；check 探测凭据。标志：--json；-b、--bind <host:port>；--regenerate；--no-auth 允许任何本地调用方；--strict 执行实时提供商检查并消耗少量配额。
omp dry-balance [model] [flags]在不运行会话的情况下测试账户选择。--model <selector>；--count <n>；--concurrency <n>；--json；--bench 会为每个 OAuth 账户发送一次实时基准请求。
omp models [action] [pattern] [flags]直接运行或使用 ls 可列出模型；提供商名称会列出该提供商；find <text> 搜索；refresh 刷新目录。标志：--json；可重复的 -e、--extension <path>；--no-extensions；可重复的 --config <file>。
omp token <provider> [flags]打印所选 API key 或 OAuth access token。--raw 避免解包嵌套凭据 JSON；--force-refresh 刷新 OAuth；-l、--list 列出账户；-a、--account <n> 选择从 1 开始编号的账户。请将输出视为密钥。
omp usage [invalidate] [flags]直接运行时显示提供商实时限额；invalidate 清除缓存的报告。-j、--json；-p、--provider <id>；-r、--redact；--history；-d、--days <n>。

插件、插件市场与配置

命令语法、操作与标志

omp install <target…> [flags]安装 npm/git/插件市场目标，或链接本地目录。--json；--force；--dry-run；插件市场安装使用 --scope user|project。
omp update [flags]安装当前发布通道的更新。-f、--force；-c、--check；-l、--plugins；--canary；--stable。

omp commit [flags]生成提交信息、更新变更日志，并提交暂存的 diff。--push；--dry-run；--no-changelog；--legacy；-c、--context <text>；-m、--model <selector>。
omp compress <file-or-glob…> [flags]把文本重写为精简的提示词寄存内容。单文件使用 -o、--out <path>；-i、--inPlace；-r、--rounds <n>；-n、--agents <n>；-m、--model <selector>。
omp gc [flags]除非指定 --apply，否则只试运行存储维护。标志：--apply；--json；--agent-dir <path>；--blobs；--archive；--wal；--cold-archive-after-days <n>；--retain-newest-global <n>；--retain-newest-per-cwd <n>。
omp grievances [list|clean|push] [flags]默认执行 list；clean 删除所选报告；push 提交排队的报告。-n、--limit <n>；-t、--tool <name>；-j、--json；--id <n>；--all。
omp images [status|doctor|probe|purge] [flags]默认执行 status；doctor 诊断；probe 检查外部健康状况；purge 默认只试运行。--json；--apply；--all；--dir <project>；--timeout <seconds>。别名：img。
omp ttsr [test|list|scan] [input] [flags]list 显示规则；test 检查内联片段、路径或 --file；scan [dir] 检查文件。--file <path|->；-r、--rule <file>；--source text|thinking|tool；--tool <name>；-p、--path <path>；-v、--verbose；--json；--no-gitignore；--max-bytes <n>（0 禁用限制）。

独立检查与媒体命令

这些是 shell 命令。其参数遵循普通 CLI 语法，并不是模型函数调用的操作配方。

命令语法与标志
omp gallery [flags]预览渲染器。-t、--tool <name>；可重复的 -s、--state <state>（streaming、progress、success 或 error；也接受显示标签别名）；-w、--width <columns>；-e、--expanded；--plain；--screenshot；-o、--out <path>；--font <family>；--font-size <points>。截图模式需要 vhs。
omp grep [pattern] [path] [flags]使用正则表达式搜索。-g、--glob <pattern>；-l、--limit <n>；-C、--context <n>；-f、--files；-c、--count；--no-gitignore。
omp read <path-or-uri>打印文件、URL、内部 URI、压缩包成员或 SQLite 选择结果。接受 src/a.ts:50-100 和 src/a.ts:raw 等选择器。
omp render [session] [flags]默认渲染当前目录最近的会话。-w、--width <columns>；--height <rows>；-t、--timing；--repaint <n>；--plain；-q、--quiet。
omp say [text] [flags]在本地朗读文本。--voice <id>；--model <key>；-f、--file <path>；-o、--out <wav> 将结果写入文件而不是播放。
omp search [query…] [flags]搜索网页。--provider <name> 接受 auto、perplexity、gemini、anthropic、codex、xai、zai、exa、tinyfish、jina、kagi、tavily、firecrawl、brave、kimi、parallel、synthetic、searxng、startpage、duckduckgo、ecosia、google、mojeek 或 public；--recency day|week|month|year；-l、--limit <n>；--compact。别名：q。

设置、SSH 与本地模型资源

命令语法、操作与标志
omp setup运行交互式引导设置向导，需要 TTY。
omp setup python [--check] [--json]安装或探测 Python 内核依赖。
omp setup speech [--check] [--json]安装或探测语音依赖。
omp ssh add <name> [flags]添加主机。选项：--host <address>、--user <name>、--port <n>、--key <path>、--desc <text>、--compat、--scope project|user、--json。
omp ssh remove <name> [--scope project|user] [--json]移除已保存的主机。
omp ssh list [--json]列出已保存的主机。
omp tiny-models list [--json]列出用于会话标题和记忆的本地 tiny 模型。
omp tiny-models download <model|all> [--json]下载一个模型或所有受支持的 tiny 模型。

实用示例

# Start in another directory with an additional workspace root
omp --cwd apps/web --add-dir packages/ui "Fix the broken component test"

# Resume a session and keep the result as a separate fork
omp --fork 01JZ8Y2A "Try the smaller design"

# Bounded one-shot run for CI
omp -p --mode json --no-session --max-time 10m \
  "Check whether generated files are current" > omp-events.jsonl

# Restrict the session and require approval for writes
omp --tools read,grep,glob --approval-mode write \
  "Audit the migration without changing files"

# Inspect available models, then benchmark two choices
omp models find sonnet
omp bench sonnet gpt-5.6 --runs 3

# Manage a project-scoped marketplace plugin
omp plugin marketplace add https://example.com/marketplace.json
omp plugin install widget@example --scope project
omp plugin list

# Check configuration and storage without applying destructive work
omp config get defaultThinkingLevel
omp gc --json
omp worktree clear --dry-run

如果命令拒绝某项操作或标志，请从已安装的版本运行 omp <command> --help。该输出由当前命令注册表生成，分发和补全也使用同一注册表。
