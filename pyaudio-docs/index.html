简介

PyAudio 为跨平台音频 I/O 库 PortAudio 提供 Python 绑定。借助 PyAudio，你可以轻松地用 Python 在各种平台上播放和录制音频。

示例：阻塞模式音频 I/O

"""PyAudio Example: Play a wave file."""

import wave
import sys

import pyaudio


CHUNK = 1024

if len(sys.argv) < 2:
    print(f'Plays a wave file. Usage: {sys.argv[0]} filename.wav')
    sys.exit(-1)

with wave.open(sys.argv[1], 'rb') as wf:
    # Instantiate PyAudio and initialize PortAudio system resources (1)
    p = pyaudio.PyAudio()

    # Open stream (2)
    stream = p.open(format=p.get_format_from_width(wf.getsampwidth()),
                    channels=wf.getnchannels(),
                    rate=wf.getframerate(),
                    output=True)

    # Play samples from the wave file (3)
    while len(data := wf.readframes(CHUNK)):  # Requires Python 3.8+ for :=
        stream.write(data)

    # Close stream (4)
    stream.close()

    # Release PortAudio system resources (5)
    p.terminate()

要使用 PyAudio，首先用 pyaudio.PyAudio() 实例化 PyAudio（1），它会为 PortAudio 获取系统资源。

要录制或播放音频，用 pyaudio.PyAudio.open()（2）在目标设备上按所需的音频参数打开一个流。它会建立一个 pyaudio.PyAudio.Stream 来播放或录制音频。

用 pyaudio.PyAudio.Stream.write() 向流写入音频数据来播放音频，或用 pyaudio.PyAudio.Stream.read() 从流中读取音频数据。（3）

注意，在“阻塞模式”下，每次 pyaudio.PyAudio.Stream.write() 或 pyaudio.PyAudio.Stream.read() 都会阻塞，直到所有帧播放或录制完毕。另一种方式是下文介绍的“回调模式”，由 PyAudio 调用一个用户定义的函数，用来处理录制到的音频或生成要输出的音频。

用 pyaudio.PyAudio.Stream.close() 关闭流。（4）

最后，用 pyaudio.PyAudio.terminate() 终止 PortAudio 会话并释放系统资源。（5）

示例：回调模式音频 I/O

"""PyAudio Example: Play a wave file (callback version)."""

import wave
import time
import sys

import pyaudio


if len(sys.argv) < 2:
    print(f'Plays a wave file. Usage: {sys.argv[0]} filename.wav')
    sys.exit(-1)

with wave.open(sys.argv[1], 'rb') as wf:
    # Define callback for playback (1)
    def callback(in_data, frame_count, time_info, status):
        data = wf.readframes(frame_count)
        # If len(data) is less than requested frame_count, PyAudio automatically
        # assumes the stream is finished, and the stream stops.
        return (data, pyaudio.paContinue)

    # Instantiate PyAudio and initialize PortAudio system resources (2)
    p = pyaudio.PyAudio()

    # Open stream using callback (3)
    stream = p.open(format=p.get_format_from_width(wf.getsampwidth()),
                    channels=wf.getnchannels(),
                    rate=wf.getframerate(),
                    output=True,
                    stream_callback=callback)

    # Wait for stream to finish (4)
    while stream.is_active():
        time.sleep(0.1)

    # Close the stream (5)
    stream.close()

    # Release PortAudio system resources (6)
    p.terminate()

在回调模式下，每当需要新的音频数据用于播放，或者有新的录制音频数据可用时，PyAudio 都会调用一个用户定义的回调函数（1）。PyAudio 在单独的线程中调用该回调函数。回调函数必须具有如下签名 callback(<input_data>, <frame_count>, <time_info>, <status_flag>)。它必须返回一个元组，其中包含要输出的 frame_count 帧音频数据（用于输出流），以及一个标志，表示是否还有更多预期要播放或录制的帧。（对于仅输入的流，返回值中的音频数据部分会被忽略。）

流一经打开（3），音频流就开始处理，它会反复调用回调函数，直到该函数返回 pyaudio.paComplete 或 pyaudio.paAbort，或者直到调用 pyaudio.PyAudio.Stream.stop 或 pyaudio.PyAudio.Stream.close。注意，如果回调返回的帧数少于 frame_count 参数（2），流会在这些帧播放完毕后自动关闭。

为了让流保持活动，主线程必须保持存活，例如通过休眠（4）来做到。在上面的示例中，整个波形文件读完之后，wf.readframes(frame_count) 最终会返回少于请求数量的帧。流将停止，while 循环（4）随之结束。

__init__(PA_manager, rate, channels, format, input=False, output=False, input_device_index=None, output_device_index=None, frames_per_buffer=0, start=True, input_host_api_specific_stream_info=None, output_host_api_specific_stream_info=None, stream_callback=None)

初始化一个音频流。

不要直接调用。请用 PyAudio.open()。

一个流可以是输入流、输出流，或两者兼具。

参数

  • PA_manager – 对管理它的 PyAudio 实例的引用

  • rate – 采样率

  • channels – 声道数

  • format – 采样大小与格式。见 PortAudio 采样格式。

  • input – 指定这是否是一个输入流。默认值为 False。

  • output – 指定这是否是一个输出流。默认值为 False。

  • input_device_index – 要使用的输入设备索引。不指定（或为 None）时使用默认设备。input 为 False 时忽略。

  • output_device_index – 要使用的输出设备索引。不指定（或为 None）时使用默认设备。output 为 False 时忽略。

  • frames_per_buffer – 指定每个缓冲区中的帧数。

  • start – 立即启动流的运行。默认值为 True。一般来说，没有理由把它设为 False。

  • input_host_api_specific_stream_info – 为输入指定一个宿主 API 专用的流信息数据结构。见 PaMacCoreStreamInfo。

  • output_host_api_specific_stream_info – 为输出指定一个宿主 API 专用的流信息数据结构。见 PaMacCoreStreamInfo。

  • stream_callback – 为非阻塞（回调）操作指定一个回调函数。默认值为 None，表示采用阻塞操作（即 PyAudio.Stream.read() 和 PyAudio.Stream.write()）。要使用非阻塞操作，需要指定符合如下签名的回调：

    callback(in_data,      # input data if input=True; else None
         frame_count,  # number of frames
         time_info,    # dictionary
         status_flags) # PaCallbackFlags

    time_info 是一个字典，包含以下键：input_buffer_adc_time、current_time 和 output_buffer_dac_time；它们的含义见 PortAudio 文档。status_flags 是 PortAudio 回调标志之一。

    回调必须返回一个元组：

    (out_data, flag)

    当 output=True 时，out_data 是一个字节数组，其长度应为（frame_count * channels * bytes-per-channel）；当 output=False 时为 None。flag 必须是 paContinue、paComplete 或 paAbort 之一（属于 PortAudio 回调返回码）。当 output=True 且 out_data 包含的帧数不足 frame_count 时，flag 会被视为 paComplete。

    注意：stream_callback 是在另一个线程（相对于主线程）中调用的。stream_callback 中发生的异常将会：

    1. 在标准错误上打印回溯，便于调试，

    2. 把这个异常加入队列，让它在（某个时刻）于主线程中抛出，并且

    3. 向 PortAudio 返回 paAbort 以停止流。

    注意：使用非阻塞操作时，不要调用 PyAudio.Stream.read() 或 PyAudio.Stream.write()。

    参见：PortAudio 的回调签名，其中有更多细节：http://portaudio.com/docs/v19-doxydocs/portaudio_8h.html#a8a60fb2a5ec9cbade3f54a9c978e2710

ValueError – 输入和输出都没有设为 True。
