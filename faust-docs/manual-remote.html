远程编译

在不同的平台和目标平台（应用程序与插件）上编译同一个 Faust DSP 程序，往往要安装并配置各家 SDK，或者需要做交叉编译，因此是一件繁琐的事。

为简化这一过程，我们开发了远程编译服务。它允许把 DSP 源代码发送到基于云的基础设施上，那里托管了大量目标平台，并且能做交叉编译。该服务可通过以下方式访问：

  • 在 FaustLive、Faust Editor 或 Faust IDE 等若干应用中使用

  • 通过专用 API 使用，详见 faustservice 项目和 FaustWeb 客户端工具

  • 通过 faustremote 脚本使用。

faustremote

faustremote 脚本（随 Faust 发行版提供）让你可以访问远程编译服务并执行编译请求：

  • faustremote [<servurl>] [<platform> <arch> <srcfile>] 会返回各平台的平台与架构列表。未指定 <servurl> 时，使用 GRAME 默认的 Faust URL 服务。之后即可用类似 faustremote osx coreaudio-qt 的命令编译指定的 DSP 文件，并以 ZIP 文件形式返回编译结果。

  • 如果 DSP 程序中需要用到 DSP 库，可以准备一个包含全部所需资源的 ZIP 文件并发送过去。

  • source 和 any 两个参数可用于为任意受支持的后端生成代码。所需的选项要通过 compile_options 元数据指定，例如 declare compile_options -lang c -cn foo -double 表示用 C 后端编译。默认情况下，生成的文件带 .txt 扩展名。
