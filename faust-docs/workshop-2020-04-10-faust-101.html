Faust 简介

  • Faust 是一种用于实时信号处理与合成的领域特定语言（类似 Csound、Max/MSP、SuperCollider、PureData……）。
  • Faust 基于纯函数式的方法。
  • 一个 Faust 程序表示一个信号处理器：一个把输入信号映射为输出信号的函数。
  • 在 Faust 中编程，本质上是用五种组合运算构成的代数来组合信号处理器：<: :> : , ~。
  • Faust 是一种编译型语言，Faust 编译器的职责是综合出最高效的实现。
  • Faust 为最终用户提供了 C/C++ 之外的高层选择，用于为大量平台开发音频应用。

第 1 部分：非常简单的示例

让我们从一些简单的 Faust 程序示例开始。

示例 1：最简单的 Faust 程序

这是能想到的最简单的 Faust 程序。它只包含一行代码，即定义：process = _;。这个程序把音频输入复制到音频输出。

让我们在在线 Faust IDE 中试试这个程序：

process = _;

从这个非常简单的示例中可以得到几点经验：

  • 一个 Faust 程序至少有一个定义，即关键字 process 的定义，它指出程序的入口点。
  • 定义总是以 ; 结尾。一个常见的错误是忘记在定义末尾写分号。
  • _ 符号表示语言的基元之一（基元是语言预定义的函数）。它表示一根音频线，让信号原样通过而不做变换。这就是数学中所说的恒等函数：从左侧进入的信号原样从右侧出来。

示例 2：相加两个信号

在之前的示例中我们看到了基元 _。Faust 有大量基元，包括所有数学运算。

例如 + 基元用于相加两个信号。因此可以用它把立体声信号（两个声道）转换为单声道信号，如下例所示：

process = +;

示例 3：相乘两个信号

例如 * 基元用于相乘两个信号：

process = *;

可以听出，把信号的两个声道相互相乘会相当剧烈地改变声音。

示例 4：并行组合

在 Faust 中编程就是把基元操作组装成或简单或复杂的音频电路。为了实现这些组装，Faust 有 5 种组合运算：~、,、;、<:、:>。

先来看用逗号 , 表示的并行组合：

process = _, _;

我们做了一根立体声线，播放音频文件时，现在两个音箱都能听到。

区分基元（如 _、+ 或 *）与组合运算（如 , 或 :）非常重要。基元表示对音频信号的操作，而组合运算用于把两个音频操作连接起来。换句话说，你可以单独写 + 或 *，因为它们表示有效的音频操作，但你永远不能单独写 , 或 :，因为它们用于连接两个音频操作。你必须写成 A,B 或 A:B。

Faust 的基元分为若干类别。这里有 C 语言的全部数值函数，只是作用于音频信号：

类别基元
算术+, -, *, /, ...
比较<, ==, !=, <=, ...
三角sin, cos, ...
对数及其他log, exp, ...
最小值、最大值min, max, ...
选择器select2, select3, ...
延迟与表@, rdtable, ...
GUIhslider(), button(), ...

下面是五种组合算子的汇总表：

语法优先级结合性说明
A ~ B4左递归组合
A , B3右并行组合
A : B2右顺序组合
A <: B1右拆分组合
A :> B1右合并组合

示例 5：控制音量

看一个把三个基元 _、0.1 和 * 与两个组合算子 , 和 : 结合的例子。

这里的想法是把输入信号的音量降到初始值的十分之一。做法是把输入信号乘以 0.1：

process = (_, 0.1) : *; // 试着把 0.1 换成 0 到 1 之间的其他值

注意，这个示例中我们用了括号来明确标出执行顺序。先把 _ 和 0.1 并行放置，再与 * 顺序组合。

但是，正如 (2*3)+7 中括号其实并不必要，因为乘法优先于加法，也可以直接写 process = _,0.1 : *; 而不加括号，因为并行组合优先于顺序组合。组合算子的优先级见上一张表。

示例 6：用滑块控制音量

与其通过修改代码来控制音量，使用图形滑块要方便得多。为此可以使用 hslider(...)，即水平滑块。它接受五个参数。第一个是名称 "volume"，然后是默认值 0.1、最小值 0、最大值 1，以及步长值 0.1。所以这里的默认值是 0.1：

process = _, hslider("volume", 0.1, 0, 1, 0.01) : *;

示例 7：单声道放大器

到目前为止我们写的都是能放进一行代码的非常简单的程序。现在引入额外的定义。定义应理解为给某个东西起名字的方式，这样就不必每次都重新输入，也让程序更易理解：

monoamp = _, hslider("volume", 0.1, 0, 1, 0.01) : *;
process = monoamp;

示例 8：立体声放大器

沿着同样的思路，我们把立体声放大器定义为两个并行放置的单声道放大器：

monoamp = _, hslider("volume", 0.1, 0, 1, 0.01) : *;
stereoamp = monoamp, monoamp;

process = stereoamp;

注意，即使 hslider 音量在代码中出现多次，用户界面中也只会有一个：

示例 9：垂直滑块

除了水平滑块，也可以使用垂直滑块。只需把 hslider(...) 换成 vslider(...)：

monoamp = _, vslider("volume", 0.1, 0, 1, 0.01) : *;
stereoamp = monoamp, monoamp;

process = stereoamp;

示例 10：用旋钮代替滑块

默认情况下滑块就是……滑块！可以通过元数据机制改变它们的外观。

元数据是放在滑块名称方括号里的信息。例如元数据 "...[style:knob]..." 可以把滑块变成旋钮：

monoamp = _, vslider("volume[style:knob]", 0.1, 0, 1, 0.01) : *;
stereoamp = monoamp, monoamp;

process = stereoamp;

示例 11：语法糖

到目前为止我们用的是 Faust 的核心语法。例如要把输入信号乘以 0.1，我们写成 _,0.1:*。对数值表达式来说，这种写法并不总是最方便，有时我们更愿意使用更传统的中缀写法，写成 _*0.1。也可以使用前缀写法，写成 *(0.1)。

下面用前缀写法重写 monoamp 的定义：

monoamp = *(vslider("volume[style:knob]", 0.1, 0, 1, 0.01));
stereoamp = monoamp, monoamp;

process = stereoamp;

下面是等价写法的表格，同一个表达式用三种语法表示。请记住，中缀和前缀表达式都会被转换为核心语法：

表达式说明
_,0.1:*核心语法
_*0.1中缀写法
*(0.1)前缀写法

这些写法可以自由组合。例如以下表达式都等价：

表达式说明
*(1-m)前缀 + 中缀写法
_*(1-m)仅中缀写法
_,(1,m:-):*核心语法

示例 12：静音按钮

我们希望按一下按钮就能完全静音，而不必改变音量。

给单声道放大器加一个静音级。要静音只需把信号乘以 0。我们使用 checkbox(...)，这个界面控件默认产生 0，被勾选时产生 1。因为希望在复选框被勾选时把信号乘以 0，所以使用 1-checkbox("mute")：

mute = *(1-checkbox("mute"));
monoamp = *(vslider("volume[style:knob]", 0.1, 0, 1, 0.01)) : mute;
stereoamp = monoamp, monoamp;

process = stereoamp;

示例 13：垂直与水平布局

从上一个示例可以看到，元素默认是垂直布局。可以用 hgroup(...) 和 vgroup(...) 改变布局。例如要让布局水平，可以写：

mute = *(1-checkbox("mute"));
monoamp = *(vslider("volume[style:knob]", 0.1, 0, 1, 0.01)) : mute;
stereoamp = hgroup("Marshall", monoamp, monoamp);

process = stereoamp;

示例 14：区分两个声道的音量

为了区分两个声道的音量控制，我们用声道号 c 参数化 monoamp，用它定制每个音量控制的名称。注意参数名 c 必须是单个字母，这样它才能在滑块名称 "volume %c[style:knob]" 中被正确解释：

mute = *(1-checkbox("mute"));
monoamp(c) = *(vslider("volume %c[style:knob]", 0.1, 0, 1, 0.01)) : mute;
stereoamp = hgroup("Marshall", monoamp(0), monoamp(1));

process = stereoamp;

示例 15：拥有多个声道

我们构建了立体声放大器，但假设想把这种构造推广到任意数量的声道。为此引入 par(i, N, ...) 构造，它允许把表达式并行放置若干次。它大致相当于经典编程语言中的 for() 循环。

在我们的情况下，要指明放大器的声道数：

mute = *(1-checkbox("mute"));
monoamp(c) = *(vslider("volume %c[style:knob]", 0.1, 0, 1, 0.01)) : mute;
multiamp(N) = hgroup("Marshall", par(i, N, monoamp(i)));

process = multiamp(2); // 试试 multiamp(4)

第 2 部分：延迟与反馈

本节介绍两个重要概念：用 @ 基元实现的延迟，以及反馈（环路电路），后者需要递归组合 A~B。这个算子把 A 的输出送入 B 的输入，并把 B 的输出送回 A 的输入。

示例 1：1 秒的单声道延迟

从一个非常简单的例子开始：1 秒的单声道延迟，即 44,100 个样本。我们使用前缀写法：

process = @(44100); 

// 等价于核心语法
// process = _, 44100 : @;

示例 2：右声道延迟 0.1 秒

为了更好地听到延迟，只把它加在右声道，左声道保持不变：

process = _, @(4410);

示例 3：声音在墙上的反射

把延迟与衰减结合起来，就可以模拟声音在墙上的反射：

bounce = @(4410) : *(0.75);
process = _, bounce;

示例 4：简单的单声道回声

要模拟回声，只需建立一个反馈环。我们将使用递归组合 A~B：

bounce = @(4410) : *(0.75);
monoecho = +~bounce;
process = _, monoecho;

示例 5：立体声回声

把两个单声道回声并行放置，做一个立体声回声：

bounce = @(44100/4) : *(0.75);
monoecho = +~bounce;
stereoecho = monoecho, monoecho;

process = stereoecho;

示例 6：添加参数

现在用参数来推广回声，以控制其时长与反馈量：

bounce(d,f) = @(d) : *(f);
monoecho(d,f) = +~bounce(d,f);
stereoecho(d,f) = monoecho(d,f), monoecho(d,f);

process = stereoecho(44100/4,0.75);

示例 7：反馈控制的滑块

现在可以加一个滑块来控制反馈量：

bounce(d,f) = @(d) : *(f);
monoecho(d,f) = +~bounce(d,f);
stereoecho(d,f) = monoecho(d,f), monoecho(d,f);

process = stereoecho(44100/4, hslider("feedback", 0, 0, 1, 0.01));

示例 8：冻结效果

现在我们希望避免反馈量设为 1 时音量无限上升。思路是当反馈量超过某个阈值时逐渐关闭输入：

bounce(d,f) = @(d) : *(f);
monoecho(d,f) = *(g) : +~bounce(d,f) with { g = 1 - max(0, f-l)/(1-l); l = 0.95; };
stereoecho(d,f) = monoecho(d,f), monoecho(d,f);

process = stereoecho(44100/4, hslider("feedback", 0, 0, 1, 0.01));

第 3 部分：基本振荡器

按照约定，Faust 中满幅音频信号在 -1 与 +1 之间变化，但我们先从一个 0 到 1 之间的锯齿波信号开始，它将作为相位发生器来产生不同的波形。

相位发生器

第一步是构建一个相位发生器，产生 0 到 1 之间的周期锯齿波信号。下面是我们要生成的信号：

示例 1：斜坡

为此我们产生一个「无限」斜坡，然后通过小数部分运算把它变成周期信号：

斜坡由以下程序产生：

process = 0.125 : + ~ _;

语义

为了理解上面的图，我们用数学语义来标注它：

从图中可以看出，输出信号的公式是：y(t) = y(t-1) + 0.125

可以计算 y(t) 的前几个值：

  • y(t&lt;0)=0.
  • y(0) = y(-1) + 0.125 = 0.125.
  • y(1) = y(0) + 0.125 = 2*0.125 = 0.250
  • y(2) = y(1) + 0.125 = 3*0.125 = 0.375
  • ...
  • y(6) = y(5) + 0.125 = 7*0.125 = 0.875
  • y(7) = y(6) + 0.125 = 8*0.125 = 1,000
  • y(8) = y(7) + 0.125 = 9*0.125 = 1.125
  • ...

示例 2：相位信号

如何把上面的斜坡变成锯齿波信号？去掉样本的整数部分，只保留小数部分：3.14159\rightarrow 0.14159。

定义一个函数来做这件事：

decimalpart(x) = x - int(x);

现在可以用这个函数把斜坡变成锯齿波。于是很自然会写：

process = 0.125 : + ~ _ : decimalpart;

从数学角度看这完全正确，但会累积舍入误差。为了保持完整精度，最好把小数部分运算放在循环内部，像这样：

process = 0.125 : (+ : decimalpart) ~ _;

现在可以试试完整代码（记得把音量调小）：

decimalpart(x) = x-int(x);
phase = 0.125 : (+ : decimalpart) ~ _;
process = phase;

在我们的 phase 定义中，步长值（这里是 0.125）控制生成信号的频率。我们希望根据目标频率计算这个步长值。为了完成转换，需要知道采样率。它在标准库中以 ma.SR 提供，并由底层音频层在启动时设置。要使用这个标准库，在程序中加入以下一行：import("stdfaust.lib");。

假设希望相位信号的频率为 1 Hz，那么步长应该非常小，为 1/ma.SR，这样相位信号从 0 走到 1 需要 ma.SR 个样本（即 1 秒）。

如果希望频率为 440 Hz，就需要大 440 倍的步长，让相位信号从 0 走到 1 快 440 倍：

phase = 440/ma.SR : (+ : decimalpart) ~ _;

把 440 换成参数 f，这个定义就可以推广：

phase(f) = f/ma.SR : (+ : decimalpart) ~ _;

并把目标频率改为 phase：

process = phase(440);

示例 3：锯齿波信号发生器

现在可以用相位发生器产生锯齿波信号：

import("stdfaust.lib");

decimalpart(x) = x-int(x);
phase(f) = f/ma.SR : (+ : decimalpart) ~ _;

sawtooth(f) = phase(f) * 2 - 1;

process = sawtooth(440);

示例 4：方波发生器

也可以用相位发生器产生方波信号：

import("stdfaust.lib");

decimalpart(x) = x-int(x);
phase(f) = f/ma.SR : (+ : decimalpart) ~ _;
squarewave(f) = (phase(f) > 0.5) * 2 - 1;

process = squarewave(440);

第 4 部分：加法合成

示例 1：正弦波发生器

相位发生器也是正弦波发生器的基础：

import("stdfaust.lib");

decimalpart(x) = x-int(x);
phase(f) = f/ma.SR : (+ : decimalpart) ~ _;
osc(f) = sin(phase(f) * 2 * ma.PI);

process = osc(440);

但既然我们已经了解了如何从零构建正弦振荡器，接下来就使用 Faust 标准库中定义的那个：

import("stdfaust.lib");

process = os.osc(440);

示例 2：带音量控制的正弦波

第二个示例中我们用水平滑块 hslider(...) 控制音量：

import("stdfaust.lib");

process = os.osc(440) * hslider("gain", 0.1, 0, 1, 0.01);

第一个参数是指明滑块名称的字符串。后面跟着四个数值参数。第二个参数 0.1 表示滑块的默认值，即程序启动时滑块给出的值。然后是最小值 0、最大值 1 和变化步长 0.01。

示例 3：练习，添加频率控制

作为练习，把上一个示例中的频率 440 换成一个水平滑块，其名称为 freq，默认值 110，最小值 40，最大值 8000，步长 1：

import("stdfaust.lib");

process = os.osc(440 /* 待替换的部分 */) * hslider("gain", 0.1, 0, 1, 0.01);

示例 4：超过 SR/2 的频率混叠现象

数字声音合成领域一个众所周知的问题是频率混叠：任何超过采样率一半的频率都会被折叠到可听频谱中：

import("stdfaust.lib");

// 超过 SR/2 时会出现频率混叠现象

process = os.osc(hslider("freq", 440, 20, 20000, 1)) * hslider("gain", 0.1, 0, 1, 0.01);

示例 5：加法合成

一个加法合成的示例，其中每个分音的电平可以单独设置：

import("stdfaust.lib");

//----------------------------------------------------------------------
// partial(f,n);
// f = 频率，单位为 Hz
// n = 分音序号，从 1 开始
partial(n,f) = os.osc(f*n) * hslider("partial %n", 0.25, 0, 1, 0.01);

process = sum(i, 4, partial(i+1, hslider("freq", 440, 20, 8000, 0.001)));

注意使用了 sum(i, n, foo(i)) 构造，它等价于 foo(0)+foo(1)+...+foo(n-1)。

示例 6：用加法合成近似方波

前面我们看到了如何产生完美的方波信号。这个完美的方波信号包含无穷多个谐波，由于采样，它们会折叠到可听频谱中，导致声音不够准确、带有噪声！方波可以用加法合成来近似，即累加无穷级数的奇次谐波（见 https://en.wikipedia.org/wiki/Square_wave）：

import("stdfaust.lib");

// 用加法合成近似方波

squarewave(f) = 4/ma.PI*sum(k, 4, os.osc((2*k+1)*f)/(2*k+1));

process = squarewave(55);

作为练习，改变谐波数量，看看近似如何改善（但不要超过 SR/2）。

示例 7：用加法合成近似锯齿波

同样，锯齿波也可以用加法合成来近似，即累加无穷级数的谐波（见 https://en.wikipedia.org/wiki/Sawtooth_wave）：

import("stdfaust.lib");

// 用加法合成近似锯齿波

sawtooth(f) = 2/ma.PI*sum(k, 4, (-1)^k * os.osc((k+1)*f)/(k+1));

process = sawtooth(55);

示例 8：带限振荡器

混叠问题可以用 Faust 库中提供的带限振荡器来解决：

import("stdfaust.lib");

decimalpart(x) = x-int(x);
phase(f) = f/ma.SR : (+ : decimalpart) ~ _;
sawtooth(f) = phase(f) * 2 - 1;

// process = sawtooth(440);
process = os.sawN(3,400);

第 5 部分：减法合成

减法合成与加法合成相反。它从丰富的声音（例如白噪声）出发，对其频谱进行雕琢。

示例 1：白噪声

一个白噪声发生器：

import("stdfaust.lib");

process = no.noise * hslider("noise", 0.5, 0, 1, 0.01);

示例 2：低通

这里用低通滤波器对噪声进行滤波，它去除低于所选截止频率的频率：

import("stdfaust.lib");

process = no.noise * hslider("noise", 0.5, 0, 1, 0.01) : fi.lowpass(3, hslider("hifreq", 2000, 20, 20000, 1));

这里使用的 fi.lowpass 滤波器可以通过一个参数配置，以调整衰减斜率。

示例 3：高通

这里用高通滤波器对噪声进行滤波，它去除高于所选截止频率的频率：

import("stdfaust.lib");

process = no.noise * hslider("noise", 0.5, 0, 1, 0.01) : fi.highpass(3, hslider("lowfreq", 400, 20, 20000, 1));

这里使用的 fi.highpass 滤波器可以通过一个参数配置，以调整衰减斜率。

示例 4：带通

把低通和高通滤波器顺序组合，就可以定义带通滤波器，它去除低于所选低截止频率和高于所选高截止频率的频率（使用前面已介绍的 fi.lowpass 和 fi.highpass 滤波器）：

import("stdfaust.lib");

process = no.noise * hslider("noise", 0.5, 0, 1, 0.01) 
: fi.highpass(3, hslider("lowfreq", 400, 20, 20000, 1))
: fi.lowpass(3, hslider("hifreq", 2000, 20, 20000, 1));

示例 5：谐振

谐振滤波器放大选定的频率范围：

import("stdfaust.lib");

process = no.noise * hslider("noise", 0.5, 0, 1, 0.01) 
        : fi.resonlp(hslider("hifreq", 400, 20, 20000, 1),
                    hslider("Q", 1, 1, 100, 0.01),
                    hslider("gain", 1, 0, 2, 0.01));

这里使用的 fi.resonlp 滤波器有一个用于选择目标频率的参数、一个塑造频率范围的 Q 值，以及一个增益系数。

示例 6：fir

这里使用了一个 FIR 滤波器：

import("stdfaust.lib");

// FIR
process = no.noise * hslider("noise", 0.5, 0, 1, 0.01) 
        <: _, transformation :> _;

transformation = @(1) : *(hslider("gain", 0, -1, 1, 0.1));

示例 7：iir

这里使用了一个 IIR 滤波器：

import("stdfaust.lib");

// IIR
process = no.noise * hslider("noise", 0.5, 0, 1, 0.01) :
        + ~ transformation;

transformation = @(0) : *(hslider("gain", 0, -0.95, 0.95, 0.01));

示例 8：梳状滤波器

一个梳状滤波器会衰减一组连续的频带：

import("stdfaust.lib");

示例 9：Karplus-Strong（1/2）

示例 11：Kisana

declare name    "myKisana";
declare author  "Yann Orlarey";

// GRAME 2015 年 7 月修改

/* ========= DESCRIPTION =============

- Kisana：三环弦乐器（基于 Karplus-Strong）
- Head = 静音
- Tilt = 高频
- Front = 高频 + 中频
- Bottom = 高频 + 中频 + 低频
- Left = 最低亮度
- Right = 最高亮度
- Front = 长音
- Back = 短音

*/

import("stdfaust.lib");

KEY = 60; // 基本 MIDI 音符
NCY = 15; // 音符周期长度
CCY = 15; // 控制周期长度
BPS = 360; // 整体速度（ba.beat 每秒）

process = kisana;    

// -------------------------------kisana----------------------------------
// USAGE:  kisana : _,_;
// 三环弦乐器
//-----------------------------------------------------------------------

kisana = vgroup("MyKisana", harpe(C,11,48), harpe(C,11,60), (harpe(C,11,72) : *(1.5), *(1.5)) 
    :> *(l), *(l))
    with {
        l = -20 : ba.db2linear; // hslider("[1]Volume",-20, -60, 0, 0.01) : ba.db2linear;
        C = hslider("[2]Brightness[acc:0 1 -10 0 10]", 0.2, 0, 1, 0.01) : ba.automat(BPS, CCY, 0.0);
    };

// ----------------------------------Harpe--------------------------------
// USAGE:  harpe(C,10,60) : _,_;
// C 为滤波器系数，范围 0..1
// 用五声音阶构建 N（10）根弦的竖琴
// 基于 MIDI 音符 b（60）
// 每根弦由特定
// 的「手」位置触发
//-----------------------------------------------------------------------
harpe(C,N,b) = hand(b) <: par(i, N, position(i+1)
                        : string(C,Penta(b).degree2Hz(i), att, lvl)
                        : pan((i+0.5)/N) )
                        :> _,_
    with {
        att  = hslider("[3]Resonance[acc:2 1 -10 0 12]", 4, 0.1, 10, 0.01); 
        hand(48) = vslider("h:[1]Instrument Hands/1 (Note %b)[unit:pk]", 0, 0, N, 1) : int : ba.automat(120, CCY, 0.0);
        hand(60) = vslider("h:[1]Instrument Hands/2 (Note %b)[unit:pk]", 2, 0, N, 1) : int : ba.automat(240, CCY, 0.0);
        hand(72) = vslider("h:[1]Instrument Hands/3 (Note %b)[unit:pk]", 4, 0, N, 1) : int : ba.automat(480, CCY, 0.0);
        // lvl  = vslider("h:loop/level", 0, 0, 6, 1) : int : ba.automat(BPS, CCY, 0.0) : -(6) : ba.db2linear;
        lvl = 1;
        pan(p) = _ <: *(sqrt(1-p)), *(sqrt(p));
        position(a,x) = abs(x - a) < 0.5;
    };

// ----------------------------------Penta-------------------------------
// 五声音阶，带音级到 MIDI 与音级到 Hz 的转换
// USAGE: Penta(60).degree2midi(3) ==> 67 midikey
// Penta(60).degree2Hz(4)   ==> 440 Hz
//-----------------------------------------------------------------------

Penta(key) = environment {

    A4Hz = 440; 

    degree2midi(0) = key+0;
    degree2midi(1) = key+2;
    degree2midi(2) = key+4;
    degree2midi(3) = key+7;
    degree2midi(4) = key+9;
    degree2midi(d) = degree2midi(d-5)+12;

    degree2Hz(d) = A4Hz*semiton(degree2midi(d)-69) with { semiton(n) = 2.0^(n/12.0); };

}; 

// ----------------------------------String-------------------------------
// 一根 Karplus-Strong 弦。
//
// USAGE: string(440Hz, 4s, 1.0, button("play"))
// or     button("play") : string(440Hz, 4s, 1.0)
//-----------------------------------------------------------------------

string(coef, freq, t60, level, trig) = no.noise*level
                            : *(trig : trigger(freq2samples(freq)))
                            : resonator(freq2samples(freq), att)
    with {
        resonator(d,a)  = (+ : @(d-1)) ~ (average : *(a));
        average(x)      = (x*(1+coef)+x'*(1-coef))/2;
        trigger(n)      = upfront : + ~ decay(n) : >(0.0);
        upfront(x)      = (x-x') > 0.0;
        decay(n,x)      = x - (x>0.0)/n;
        freq2samples(f) = 44100.0/f;
        att             = pow(0.001,1.0/(freq*t60)); // 衰减系数
        random          = +(12345)~*(1103515245);
        noise           = random/2147483647.0;
    };
