Faust 中的 RMS 与求和

本教程介绍在 Faust 中计算 n 个连续样本之和的几种编程技巧。这类求和通常用于计算信号的 RMS 值，因此我们放在 RMS 的语境下讲解。我们不会使用任何预定义函数，只用 Faust 基元，好让你看到所有细节。

本文面向具备一些 Faust 基础知识的初学者。如果你还不具备，请先看看本站上的各种文档。

RMS 值

信号 RMS（Root Mean Square，均方根）值的计算由下面的 Faust 表达式定义：

^(2) : summation : /(n) : sqrt

其中 n 是所考虑的连续样本数。

这个表达式包含几个步骤：

  • 首先对信号取平方：^(2)。这就是 RMS 中的 S。
  • 然后对 n 个连续样本求和：summation，再把这个和除以 n 得到均值：/(n)。这就是 RMS 中的 M。
  • 最后取平方根 sqrt。这就是 RMS 中的 R。

换句话说，在 Faust 中 RMS 写作 S:M:R（暂时不定义 summation 函数）：

RMS(n) = S:M:R with {
    S = ^(2);
    M = summation : /(n);
    R = sqrt;
};

下面几段将介绍编写这个 summation 函数的 4 种不同技巧。我们假定音频样本在 -1 与 1 之间。

滑动求和

先从滑动求和方法开始，这大概是用 n 个连续样本高效求和的最简单方式。先回顾一下，用下面的表达式可以把信号 s 从时刻 0 到当前时刻的所有样本累加起来：s : +~_。

只累加最近 n 个样本的技巧，是从这个和中减去 n 个样本之前的同一个和。例如，要只保留最近 10 个样本的和，只需从所有样本之和 (s:+~_) 中减去 10 个样本之前这个和的值 (s:+~_ : @(10))：

(s:+~_), (s:+~_ : @(10)) : -

这个表达式还可以通过提取 s:+~_ 进一步化简。于是得到：

s : +~_ <: _, @(10) : -

从数学角度看这完全正确，但用浮点数计算时会出问题。与数学中的数不同，浮点数的精度有限（单精度为 23 位）。计算 RMS 值时我们只累加正数，因此和会一直增长。但当和超过 2^{23} 之后，最低有效位就会高于 0 到 1 之间的任何数。此时加上这么小的数就等同于加 0，和再也不会变化。

幸运的是，这个问题很容易解决。只需把积分与差分两部分交换位置：

s <: _, @(10) : - : +~_

从数学角度看，这个新写法与之前完全相同。但现在和始终保持在 -10​ 与 +10 之间，精度问题只出现在最低有效位上。如果把量化引起的舍入误差建模为 -q/2 与 q/2 之间均匀分布的随机数，那么它的方差（均方）为 q^2/12，而在累加和中这个值随时间线性增长（参见「Wiener process」）。因此，累加和式 RMS 计算器的舍入误差预期会按时间的平方根增长。

现在可以补全 RMS 的定义：

RMS(n) = S:M:R with {
    S = ^(2);
    M = summation : /(n);
    R = sqrt;

    summation = _ <: _, @(n) : - : +~_;
};

定点滑动求和

虽然前一种方案在典型信号和实际时间跨度上表现很好，但舍入误差仍会缓慢增长。为避免精度逐渐损失，可以对样本采用定点编码，使延迟后的减法始终精确。假设我们要对 0 与 1 之间的 10 个值做滑动求和，已知这个和不会超过 2^4。因此最多可以用 27 位（31-4）来编码值的小数部分。

转换很直接。把浮点值转成定点可以用：*(2^27):int。从定点转回浮点用相反的表达式：float:/(2^27)。

现在可以补全 RMS 的定义。如下面的求和定义所示，我们先把样本转成定点，在整数上求和，再把结果转回浮点：

RMS(n) = S:M:R with {
    S = ^(2);
    M = summation : /(n);
    R = sqrt;

    summation = float2fix(16) : _ <: _, @(n) : - : +~_ : fix2float(16);
    float2fix(p) = *(2^p) : int;
    fix2float(p) = float : /(2^p);
};

显然，只有在为整数部分留出足够位数时这才是正确的。这里我们有 15 位（31-16），足以支持 n 达到 32000 个样本。

分块求和

滑动求和的行为平滑，因为每个样本都会产生一个更新后的和。但它们需要很长的延迟线（长于 n），而且可能有精度问题。第三种方法采用分块求和：求和是精确的，不需要长延迟线，但每 n 个样本的一块才更新一次。

代码稍微复杂一些。它需要一个相位信号：0,1,2,3,\ldots,n-1,0,1\ldots，以及一个捕获（采样保持）操作。

先从一个由 s:+~_ 导出的简化版本开始。记住 _ 是恒等函数，等价于 *(1)。因此可以把前面的表达式改写为 s:+~*(1)。现在设想把 1 换成一个布尔值 b，写成：s:~*(b)。当 b 为 1 时，输入样本加到之前的和上；而当 b 为 0 时，输入样本加到 0 上，和就被重置为输入样本。

在我们的情形中，希望每 n 个样本一块之后重置和，也就是每次 phase 回到 0 时。可以写成：s:+~*(phase!=0)。

注意不能直接使用这个表达式的输出。它只在 phase==(n-1) 时表示我们要找的和。因此需要一个额外的捕获级，在处理下一块期间把和采样并保持住。假设 b 指示何时捕获输入值，那么 select2(b)~_ 就能完成这件事。当 b 为 0 时它复现反馈信号，当 b 为 1 时它捕获输入信号。

完整实现如下：

RMS(n) = S:M:R with {
    S = ^(2);
    M = summation : /(n);
    R = sqrt;

    summation = + ~ *(phase != 0) : capture(phase==(n-1));
    phase = 1 : (+,n:%)~_;
    capture(b) = select2(b)~_;
};

重叠分块求和

如前所述，分块求和的缺点是一块只产生一个新值。如果块很大，这会成为问题。第四种方法将让产生的值相互重叠。例如，我们想计算最近 1000 个样本的和，但每 250 个样本给出一个新结果（即 75% 的重叠）。

原理是对 250 个样本的小块求和，保留最近四个和，再把它们相加，从而每 250 个样本产生最近 1000 个样本的新和。设 w 为一个小块的长度，c 为 n 个样本的大块中小块的个数（即 n=c*w）。

我们不再像 + ~ *(phase != 0) 那样对 n 个样本求和，而是对 w 个样本求和：+ ~ *(phase%w != 0)。也不再每 n 个样本捕获一次：capture(phase == (n-1))，而是需要在 1*w-1、2*w-1 等位置并行捕获 c 次：par(i,c, capture( phase == (w*(i+1) - 1) ))

完整代码如下：

RMS(n) = S:M:R with {
    S = ^(2);
    M = summation : /(n);
    R = sqrt;

    c = 4; // 重叠次数
    summation = + ~ *(phase%w != 0) 
                 <: par(i, c, capture( phase == (w*(i+1) - 1) )) 
                 :> _
        with { w = n/c; };

    phase = 1 : (+,n:%)~_;
    capture(b) = select2(b)~_;
};

比较所有方案

用 Faust IDE 可以方便地比较这些方案。为了把全部定义封装起来并选择 RMS 的实现，我们使用环境。如果你不熟悉环境这个概念，它是一种把定义分组的办法。

import("stdfaust.lib");

process = testsource <: _, RMS(n).sliding, RMS(n).fixpoint, RMS(n).block, RMS(n).overlap(4)
    with {
        n = 10000;
        testsource = os.osc(40) * lfo(1) * hslider("level", 1, 0, 1, 0.01);
        lfo(f) = os.osc(f)/2+0.5;
    };

RMS(n) = environment {

    // 要测试的 4 种实现
    sliding    = horms(( _ <: _, @(n) : - : +~_ ));
    fixpoint   = horms(( float2fix(16) : _ <: _, @(n) : -: +~_ : fix2float(16) ));
    block      = horms(( + ~ *(phase != 0) : capture(phase == (n-1)) ));
    overlap(c) = horms(( + ~ *(phase%w != 0) <: par(i, c, capture( phase == (w*(i+1) - 1) )) :> _ with { w = n/c; } ));

    // 以 summation 函数为参数的高阶 rms
    horms(summation) = S:M:R with {
        S = ^(2);
        M = summation : /(n);
        R = sqrt;
    };

    // 辅助函数
    float2fix(p) = *(2^p) : int;
    fix2float(p) = float : /(2^p);

    phase = 1 : (+,n:%)~_;
    capture(b) = select2(b)~_;

};
