简介

Faust 是什么？

Faust（Functional Audio Stream）是一门用于声音合成与音频处理的函数式编程语言，尤其侧重合成器、乐器、音频效果器等的设计。Faust 面向各类平台与标准上的高性能信号处理应用和音频插件。它被用于音乐会和艺术制作的现场演出，也用于教育与科研、开源项目以及商业应用。

Faust 的核心组件是它的编译器。它可以把任意 Faust 数字信号处理（DSP）描述「翻译」成多种与领域无关的语言，如 C++、C、JAVA、LLVM IR、WebAssembly 等。从这个角度看，Faust 可以视为 C++ 的替代方案，但学起来简单得多、也直观得多。

借助名为「架构」的封装体系，Faust 生成的代码可以轻松编译成各种各样的对象，从音频插件到独立应用程序，再到智能手机应用和网页应用等等。

本手册通过多个可交互的示例，概述 Faust 编程语言及其各项特性。

Faust 适合做什么？

Faust 的语法让我们能把任何 DSP 算法表达为框图。例如，+ 被视为一个合法的函数（也是框图），它接收两个参数（信号）并返回一个：

process = +;

框图之间可以用 :「连接」组合轻松连起来：

process = + : *(0.5);

在这个例子里，我们把两个信号相加，然后对运算结果做缩放。

因此，Faust 非常适合实现能够方便地表示为框图的时域算法，例如滤波器、波导物理模型、虚拟模拟元件等。

Faust 非常简洁，例如下面是与 y(n) = x(n) + a_{1}y(n-1) 等价的一阶极点滤波器/积分器实现（其中 a_{1} 是极点）：

a1 = 0.9;
process = +~*(a1);

Faust 生成的代码经过高度优化，通常比手写代码更高效（至少对 C 和 C++ 而言）。Faust 编译器会尽量优化算法中的每个环节。例如，你不必操心该用除法还是乘法，编译器会在可能时自动把除法替换为乘法。

Faust 的通用性很强，写出的代码可以运行在几十个平台上。

Faust 不（太）适合做什么？

尽管如此，Faust 确实存在一些局限。例如，它无法高效实现需要多采样率的算法，如 FFT、卷积等。虽然有一些变通办法绕开这个问题，但我们很清楚这是个大问题，正在尽最大努力解决。

Faust 的简洁有时也会成为问题，尤其是对含有大量递归信号的复杂算法。在 Faust 中，通常必须对要实现的算法有「整体心智图景」，而这在某些情况下并不容易。

Faust 编译器虽然相对没有什么缺陷，但仍有局限，在某些极端情况下可能卡住，不过你大概永远不会遇到。如果真遇到了，给我们发封邮件！

设计原则

自 2002 年开始开发以来，Faust 一直遵循若干设计原则：

  • Faust 是一门描述语言。它旨在提供一种恰当的记法，从数学角度描述信号处理器。Faust 尽可能不涉及实现细节。
  • Faust 程序是完全编译的（即不做解释执行）。编译器把 Faust 程序翻译成其他语言中的等价程序（如 JAVA、LLVM IR、WebAssembly 等），并注意生成最高效的代码。生成结果通常能与资深程序员手写的 C++ 代码相媲美，有时甚至更优。
  • 生成的代码在样本级工作，因此适合实现递归滤波器这类底层 DSP 功能。此外，代码可以轻松嵌入。它是自包含的，不依赖任何 DSP 库或运行时系统，行为高度确定，内存占用恒定。
  • Faust 的语义简单且定义清晰。这不只是学术上的趣味，它让 Faust 编译器可以由语义驱动：它编译的不是程序的字面形式，而是程序所表示的数学函数。这一特性有助于在保持最佳性能的同时促进组件复用。
  • Faust 是一门文本语言，但面向框图。它实际上结合了两种方法：函数式编程与代数框图。核心思想是把框图的构造视为函数组合。为此，Faust 依赖由五种组合运算构成的框图代数：: , ~ <: :>（详见框图组合运算一节）。
  • 得益于架构这一概念，Faust 程序可以轻松部署到大量音频平台和插件格式上，而无需改动 Faust 代码。

信号处理器语义

Faust 程序描述的是一个信号处理器。信号处理器的作用是把一组（可能为空的）输入信号变换成一组（可能为空的）输出信号。大多数音频设备都可以建模为信号处理器：它们有音频输入、音频输出，以及与滑块、旋钮、电平表等相接的控制信号。

更准确地说：

  • 信号 s 是时间的离散函数 s:\mathbb{Z}\rightarrow\mathbb{R}。信号 s 在时刻 t 的值写作 s(t)。信号的值通常从时刻 0 开始需要。但为了处理延迟运算，允许出现负时刻，并且负时刻总映射为零。因此，对任意 Faust 信号 s 都有 \forall t&lt;0, s(t)=0。用运算术语来说，这相当于假定所有延迟线都是用 0 初始化的信号。
  • Faust 考虑两类信号：整数信号 s:\mathbb{Z}\rightarrow\mathbb{Z} 和浮点信号 s:\mathbb{Z}\rightarrow\mathbb{Q}。按照约定，与外部世界的交换使用浮点信号进行。完整范围由 -1.0 到 +1.0 之间的样本值表示。
  • 所有可能信号的集合是 \mathbb{S}=\mathbb{Z}\rightarrow\mathbb{R}。
  • 一组 n 个信号（n 元信号组）写作 (s_{1},\ldots,s_{n})\in \mathbb{S}^{n}。空元组是 \mathbb{S}^{0} 的唯一元素，记作 ()。
  • 信号处理器 p 是从 n 元信号组到 m 元信号组的函数 p:\mathbb{S}^{n}\rightarrow\mathbb{S}^{m}。集合 \mathbb{P}=\bigcup_{n,m}\mathbb{S}^{n}\rightarrow\mathbb{S}^{m} 是所有可能信号处理器的集合。

举例来说，我们来表达 Faust 基元 + 的语义。与任何 Faust 表达式一样，它是一个信号处理器，其签名是 \mathbb{S}^{2}\rightarrow\mathbb{S}。它接收两个输入信号 X_0 和 X_1，产生输出信号 Y，满足 Y(t) = X_0(t)+X_1(t)。

数字也是信号处理器。例如，数字 3 的签名是 \mathbb{S}^{0}\rightarrow\mathbb{S}。它不接收输入信号，产生输出信号 Y，满足 Y(t) = 3。
