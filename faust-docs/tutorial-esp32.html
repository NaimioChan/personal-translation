用 Faust 在 ESP32 上做 DSP

ESP32 是一款便宜的微控制器，内置蓝牙与 Wi-Fi 支持，拥有大量 GPIO 与模拟输入等。它极低的价格（几美元）使其非常有吸引力，被越来越多的开发板采用。市面上有大量面向音频应用的「未知/神秘」开发板基于 ESP32，可以在阿里巴巴/速卖通上找到。它们大多面向「智能音箱」（如 Alexa 等）的开发，但搭载了开展实时 DSP 应用所需的全部组件，因此可用于开发数字乐器、效果处理器、合成器硬件等。TTGO T-Audio 与 ESP32 Audio Dev Kit 就是这类开发板的好例子。

TTGO T-Audio（左）与 ESP32 Audio Dev Kit（右）

两者都搭载质量较好的音频编解码器，带立体声输入输出、内置功放、电池电路、外部 RAM 以及多种运动传感器（仅 TTGO T-Audio），价格都不到 15 美元。由于这些开发板不运行任何操作系统，可以达到很低的音频延迟（例如缓冲区为 8 个样本等）。与 Teensy 3.6/4.0 及其各自的音频扩展板相比，这些开发板便宜得多，性能也比 Teensy 3.6 强（双核，主频高得多），而且最重要的是有足够 RAM 运行混响、回声等内存占用大的 DSP 算法（这在 Teensy 3.6 和 4.0 上相对受限）。最后，ESP32 生态完全开源（包括其引导程序）！在很多方面，它们可以与 BELA（<150 美元）等贵得多的专用音频平台竞争。

Faust 发行版现在带有 faust2esp32，这是一个用 Faust 为基于 ESP32 的开发板编程的工具。faust2esp32 仍在开发中，当前版本可以生成 DSP 引擎，用于 ESP32 项目中完成声音合成与处理任务。虽然 ESP32 与音频编解码器之间的通信机制（i2s）在所有开发板上都相同，但 ESP32 开发板所用音频编解码器的品牌和型号差别很大。faust2esp32 支持若干音频编解码器，可以通过运行 faust2esp32 -h 或查看 faust2esp32 文档列出。

faust2esp32 生成的 DSP 引擎同时兼容 ESP32 的 C++ 与 Arduino 开发环境。下面两节分别用这两种方式带你新建 ESP32 项目并为其添加 Faust 音频支持。

使用 ESP32 的 C++ 开发环境

本教程的最终源代码可以在这里找到。

用 ESP32 原生的 C++ 环境编程有很多好处。特别是可以非常精细地控制开发板配置与编译选项。例如，如果你的 DSP 算法内存占用很大，可能别无选择，因为必须启用外部 RAM（见使用 ESP32 的外部 RAM）。

在这个简短的教程中，我们带你从零创建一个支持音频 DSP 的 C++ 项目，目标板为 TTGO T-Audio（类似开发板的流程大致相同）。

新建 ESP32 项目

关于如何配置 ESP32 C++ 开发环境，可以在这个教程中找到（读到第 4 步结束）。

环境就绪后，把 ESP32 hello_world 示例项目复制到系统中某个位置。然后运行 make，它应会自动弹出 ESP32 配置面板。按需做一些修改（例如按 ESP32 入门教程所说明的配置串口烧录器等）。退出菜单后，编译应开始并顺利完成。

由于我们即将用 faust2esp32 生成的 DSP 引擎使用 C++，当前项目的主文件也应改为 C++。为此，只需把 main/hello_world_main.c 重命名为 main/main.cpp（当然也可以取别的名字，只要用 cpp 扩展名）。然后确认程序的基本结构如下：

#include <stdio.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "esp_system.h"
#include "esp_spi_flash.h"

extern "C" {
    void app_main(void);
}

void app_main(void)
{
  while(1) {
    vTaskDelay(1000 / portTICK_PERIOD_MS);
  }
}

这里的无限 while 循环在主线程/任务中运行，每秒更新一次。修改项目根目录的 CMakeLists.txt 以更改项目名（例如 project(FaustTutorial)）。同样，修改 main 中的 CMakeLists.txt，为组件源文件设置正确的文件（例如 set(COMPONENT_SRCS "main.cpp")）。再次运行 make，确认程序仍能编译、没有改坏东西。

制作一个简单的 DSP 引擎

现在写一个简单的 Faust 程序（就是那个老熟人哈哈），实现带平滑控制的带限锯齿波：

import("stdfaust.lib");

freq = nentry("freq",440,20,20000,0.01) : si.smoo;
gain = nentry("gain",1,0,1,0.01) : si.smoo;

process = os.sawtooth(freq)*gain;

把它保存为 FaustSawtooth.dsp（这将决定对应 DSP 引擎的名字），然后用 faust2esp32 运行以下命令编译：

faust2esp32 -lib FaustSawtooth.dsp

-lib 要求生成 C++ DSP 引擎，而不是完整固件。

注意：当前版本的 faust2esp32 只能生成 DSP 引擎（不能生成完整的 ESP32 程序），所以这里 -lib 选项其实并非必需。

另一种做法是在在线 IDE 的 Faust 编译服务中选择 ESP32 目标平台。

两种情况都会返回一个包含若干 C++ 文件的 .zip 包。在当前示例中，FaustSawtooth.[cpp/h] 实现由 FaustSawtooth.dsp 生成的 Faust DSP 对象，WM8978.[cpp/h] 是对应你开发板音频编解码器的对象。

注意：在 faust2esp32 当前版本中，唯一支持的音频编解码器是 WM8978（-WM8978 选项，即 TTGO T-Audio 所用的那颗）和 AC101（-AC101 选项）。

所有这些文件应放到项目的 main 文件夹中。之后按如下方式在 main.cpp 中包含它们：

#include <stdio.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "esp_system.h"
#include "esp_spi_flash.h"

#include "WM8978.h"
#include "FaustSawtooth.h"

extern "C" {
    void app_main(void);
}

配置音频编解码器

接下来，应在 app_main 中实例化并配置 WM8978 对象（它对应音频编解码器，即开发板上的音频接口）：

WM8978 wm8978;
wm8978.init();
wm8978.addaCfg(1,1); 
wm8978.inputCfg(1,0,0);     
wm8978.outputCfg(1,0); 
wm8978.micGain(30);
wm8978.auxGain(0);
wm8978.lineinGain(0);
wm8978.spkVolSet(0);
wm8978.hpVolSet(40,40);
wm8978.i2sCfg(2,0);

同样，faust2esp32 当前版本只支持 TTGO T-Audio 上的 Wolfson WM8978 和 AC101，但我们正在努力加入其他厂商的新编解码器。其他编解码器的流程应该类似。

当前的配置会启用麦克风输入、关闭扬声器功放、把耳机增益设为 40 等。更多信息请参阅 WM8978 对象文档。

注意，这些命令在启动时会「实时」逐条调用，因此音频编解码器的配置是逐步完成的，应在向它发送任何音频缓冲区之前完成。

实例化 Faust DSP 引擎

配置好音频编解码器后，上一步生成并已包含在 main.cpp 中的 Faust DSP 对象也应在 app_main 中实例化：

int SR = 48000;
int BS = 8;
FaustSawtooth faustSawtooth(SR,BS);  
faustSawtooth.start();

FaustSawtooth 的构造函数接受两个参数：采样率（这里是 48kHz）和块大小（这里是 8）。调用构造函数会配置对象、为其分配内存等，但要开始计算，还需要调用 start() 方法。由于 ESP32 固件基于 freertos，音频在其自己的高优先级任务中计算，调用 start() 会启动这个任务。注意，随时调用 stop() 即可移除该任务并停止音频计算。

最后，随时可以调用 FaustSawtooth 对象的 setParamValue 方法，改变 Faust 对象某个参数的值（这里声明了两个参数：freq 与 gain）。例如，在 app_main 底部的 while 循环中调用下面这行，即可每个样本随机改变所生成锯齿波的频率：

faustSawtooth.setParamValue("freq",rand()%(2000-50 + 1) + 50);

到这里，main.cpp 应该如下所示：

#include <stdio.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "esp_system.h"
#include "esp_spi_flash.h"

#include "WM8978.h"
#include "FaustSawtooth.h"

extern "C" {
    void app_main(void);
}

void app_main(void)
{
    WM8978 wm8978;
    wm8978.init();
    wm8978.addaCfg(1,1); 
    wm8978.inputCfg(1,0,0);     
    wm8978.outputCfg(1,0); 
    wm8978.micGain(30);
    wm8978.auxGain(0);
    wm8978.lineinGain(0);
    wm8978.spkVolSet(0);
    wm8978.hpVolSet(40,40);
    wm8978.i2sCfg(2,0);

    int SR = 48000;
    int BS = 8;
    FaustSawtooth faustSawtooth(SR,BS);  
    faustSawtooth.start();

    while(1) {
        faustSawtooth.setParamValue("freq",rand()%(2000-50 + 1) + 50);
        vTaskDelay(1000 / portTICK_PERIOD_MS);
    }
}

试着重新编译固件并上传到开发板。如果接上耳机，你应该能听到频率每秒随机变化的锯齿波。

使用 ESP32 的外部 RAM

某些 DSP 算法可能需要大量内存（例如波表、延迟等）。这种情况下，Faust 生成的对象可能无法放进 ESP32 的内置 RAM，可能需要使用开发板的外部 RAM 模块（SRAM）。

为了测试这一点，我们先要写一个需要大量内存的 Faust 程序。把上一个示例的锯齿波换成正弦波就够了，因为 Faust 默认的正弦振荡器（os.osc）基于大小为 65536 的波表：

import("stdfaust.lib");

freq = nentry("freq",440,20,20000,0.01) : si.smoo;
gain = nentry("gain",1,0,1,0.01) : si.smoo;

process = os.osc(freq)*gain;

然后可以按制作一个简单的 DSP 引擎一节中描述的相同步骤，把这个 Faust 程序集成到你的 C++ ESP32 项目中。

如果再次编译固件（即 make），链接时应会得到如下错误：

[...]/xtensa-esp32-elf/bin/ld: hello-world.elf section `.dram0.bss' will not fit in region `dram0_0_seg'
[...]/xtensa-esp32-elf/bin/ld: DRAM segment data does not fit.
[...]/xtensa-esp32-elf/bin/ld: region `dram0_0_seg' overflowed by 93408 bytes
collect2: error: ld returned 1 exit status

要解决这个问题，可以把外部 RAM 纳入 ESP32 的内存映射。为此，运行 make menuconfig 并进入 Component Config/ESP32-specific。然后高亮 Support for external RAM, SPI-Connected RAM 并按 y 键启用。进入 SPI RAM config/SPI RAM access method 菜单，选择 Integrate RAM into ESP32 memory map。接着选择 Allow .bss segment placed in external memory 并按 y 键启用该功能。最后，打开 FaustSawtooth.cpp（不过我们现在合成的是正弦波，所以你那里这个文件名可能不同），搜索 static float ftbl0mydspSIG0，这就是将被正弦波表填充的静态表。Faust 编译器生成的 C++ 代码中，这一部分总会包含需要大量内存的大表。现在要在表定义旁边加上 EXT_RAM_ATTR 属性：

static float ftbl0mydspSIG0[65536] EXT_RAM_ATTR;

它告诉 C++ 编译器，这个静态表应放在外部内存而不是内置内存中。如果你的 Faust 程序做的不是合成正弦波，可能需要在每个表定义上都加这个属性。

注意：我们正在修改 Faust 编译器，使其在给定特定选项时自动完成这一过程。

最后，试着重新编译固件，现在应该一切正常了！

使用 Arduino 开发环境

本教程的最终源代码可以在这里找到。

Arduino 开发环境也可以用来给 ESP32 编程。在这种情况下使用 Faust 生成的 DSP 引擎，步骤与上一节描述的 C++ 环境非常相似。

首先确认 Arduino 开发板管理器中已安装 esp32 包（Tools/Board/Boards Manager）。接着新建一个空项目并保存。然后按上一教程制作一个简单的 DSP 引擎一节中描述的相同步骤操作；不过应把 FaustSawtooth.[cpp/h] 与 WM8978.[cpp/h] 文件放在与项目 .ino 文件相同的文件夹里。生成的项目文件夹现在应如下所示：

esp32Tuto.ino 
FaustSawtooth.cpp
FaustSawtooth.h
WM8978.cpp
WM8978.h

然后按如下方式编辑 Arduino 程序：

#include "freertos/FreeRTOS.h"
#include "freertos/task.h"

#include "WM8978.h"
#include "FaustSawtooth.h"

FaustSawtooth faustSawtooth(48000,8);

void setup() {
  WM8978 wm8978;
  wm8978.init();
  wm8978.addaCfg(1,1); 
  wm8978.inputCfg(1,0,0);     
  wm8978.outputCfg(1,0); 
  wm8978.micGain(30);
  wm8978.auxGain(0);
  wm8978.lineinGain(0);
  wm8978.spkVolSet(0);
  wm8978.hpVolSet(40,40);
  wm8978.i2sCfg(2,0);

  faustSawtooth.start();
}

void loop() {
  faustSawtooth.setParamValue("freq",rand()%(2000-50 + 1) + 50);
  delay(1000);
}

生成的固件行为应与前面 C++ 教程中的版本相同。关于 WM8978 那几行在做什么等更多信息，可以参考配置音频编解码器一节。
