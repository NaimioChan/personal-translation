使用 box API

box API 在Faust 编译链内部提供了一个中间接入点。本教程通过代码示例介绍它。目标是展示如何在 box API 之上构建新的音频 DSP 语言（文本式或图形式），并利用 Faust 编译器基础设施的一部分。

Faust 编译器结构

Faust 编译器由若干步骤组成：

编译链

从 DSP 源代码出发，语义阶段产生信号，信号在概念上是样本或控制值的无限流。随后在代码生成阶段把这些信号编译为命令式代码（C/C++、LLVM IR、WebAssembly 等）。

语义阶段本身由若干步骤组成：

语义阶段

使用框图代数（BDA）编写的初始 DSP 代码，在求值、lambda 演算步骤中被翻译为范式的扁平电路。

输出信号列表由符号传播步骤产生。每个输出信号随后被简化，并执行一组优化（范式计算与化简、延迟线共享、类型推导等），最终产生范式形式的输出信号列表。

代码生成阶段把信号翻译为名为 FIR（Faust Imperative Representation）的中间表示，再通过一组后端转换为最终目标语言（C/C++、LLVM IR、WebAssembly 等）。

访问 box 阶段

在语义阶段中、求值、lambda 演算步骤之后，新增了一个公开的中间入口点，可以创建 box 表达式，从而利用编译链剩余的所有部分。box API（或 C box API 版本）让开发者能够以编程方式创建 box 表达式，然后编译它，生成可直接使用的 DSP，形式可以是 C++ 类，也可以是 LLVM、Interpreter 或 WebAssembly 工厂，以便与所有现有的架构文件配合使用。信号阶段完成的若干优化，将通过查看生成的 C++ 代码来演示。

注意，signal API 可以访问编译链中的另一个阶段。

编译 box 表达式

使用 box API 需要执行以下步骤：

  • 使用 createLibContext 函数创建全局编译上下文

  • 使用 box API 创建 box 表达式，通过组合更简单的表达式逐步构建更复杂的表达式

  • 使用 createCPPDSPFactoryFromBoxes 函数编译 box 表达式以创建 DSP 工厂（或用 createDSPFactoryFromBoxes 生成 LLVM 嵌入工厂，或用 createInterpreterDSPFactoryFromBoxes 生成 Interpreter 嵌入工厂）

  • 最后使用 destroyLibContext 函数销毁编译上下文

DSP 工厂允许创建 DSP 实例，以便与音频和 UI 架构文件配合使用，在编译过程本身之外。DSP 实例和工厂最终在不再使用时必须释放。

工具

先定义一个 compile 函数，它使用 createCPPDSPFactoryFromBoxes 函数并打印生成的 C++ 类：

static void compile(const string& name, 
                    tvec signals, 
                    int argc = 0, 
                    const char* argv[] = nullptr)
{
    string error_msg;
    dsp_factory_base* factory = createCPPDSPFactoryFromBoxes(name, 
                                                             signals, 
                                                             argc, 
                                                             argv, 
                                                             error_msg);
    if (factory) {
        // 打印 C++ 类
        factory->write(&cout);
        delete(factory);
    } else {
        cerr << error_msg;
    }
}

一个封装所有必要步骤的宏：

#define COMPILER(exp)    \
{                        \
    createLibContext();  \
    exp                  \
    destroyLibContext(); \
}                        \

示例

每个示例都给出等价的 Faust DSP 程序和 SVG 图作为辅助。SVG 图展示编译 propagate 步骤的结果（即在任何信号规范化步骤之前）。所有展示的 C++ 示例（以及一些额外示例）都定义在 box-tester 工具中，可在 tools/benchmark 目录下用 make box-tester 编译。

生成常量信号的表达式

我们来创建一个并行构造 7 和 3.14 两个常量值的程序。以下是 Faust DSP 代码：

process = 7,3.14;

下面的代码创建一个 box 表达式，其中包含 box boxPar(boxInt(7), boxReal(3.14)) 表达式，然后编译它并显示 C++ 类：

static void test1()
{
    COMPILER
    (
        Box box = boxPar(boxInt(7), boxReal(3.14));

        compile("test1", box);
    )
}

compute 方法则是：

virtual void compute(int count, FAUSTFLOAT** inputs, FAUSTFLOAT** outputs) 
{
    FAUSTFLOAT* output0 = outputs[0];
    FAUSTFLOAT* output1 = outputs[1];
    for (int i0 = 0; (i0 < count); i0 = (i0 + 1)) {
        output0[i0] = FAUSTFLOAT(7);
        output1[i0] = FAUSTFLOAT(3.1400001f);
    }
}

对输入信号做一些数学运算

下面是一个对信号输入做数学运算的简单程序：

process = _,3.14 : +;

第一个音频输入用 boxWire() 表达式创建，然后用 boxAdd 和 boxSeq 算子变换，产生一个输出：

static void test2()
{
    COMPILER
    (
        Box box = boxSeq(boxPar(boxWire(), boxReal(3.14)), boxAdd());

        compile("test2", box);
     )
}

compute 方法则是：

virtual void compute(int count, FAUSTFLOAT** inputs, FAUSTFLOAT** outputs) 
{
    FAUSTFLOAT* input0 = inputs[0];
    FAUSTFLOAT* output0 = outputs[0];
    for (int i0 = 0; (i0 < count); i0 = (i0 + 1)) {
        output0[i0] = FAUSTFLOAT((float(input0[i0]) + 3.1400001f));
    }
}

在公开的 API 中，大多数算子都导出为简单的无参数算子，使用语言的 core-syntax。每个相关算子还添加了前缀记法，可与额外的多参数版本一起使用。因此前面的例子可以用下面的代码更简单地写出，生成的 C++ 完全相同：

static void test3()
{
    COMPILER
    (
        Box box = boxAdd(boxWire(), boxReal(3.14));

        compile("test3", box);
     )
}

定义延迟表达式

下面是一个对第一个输入做延迟的简单程序：

process = @(_,7);

前缀记法 boxDelay(x, y) 算子把第一个 boxWire() 参数延迟第二个参数 boxInt(7) 个样本：

static void test6()
{
    COMPILER
    (
        Box box = boxDelay(boxWire(), boxInt(7));

        compile("test6", box);
    )
}

compute 方法则是：

virtual void compute(int count, FAUSTFLOAT** inputs, FAUSTFLOAT** outputs) 
{
    FAUSTFLOAT* input0 = inputs[0];
    FAUSTFLOAT* output0 = outputs[0];
    for (int i0 = 0; (i0 < count); i0 = (i0 + 1)) {
        fVec0[0] = float(input0[i0]);
        output0[i0] = FAUSTFLOAT(fVec0[7]);
        for (int j0 = 7; (j0 > 0); j0 = (j0 - 1)) {
            fVec0[j0] = fVec0[(j0 - 1)];
        }
    }
}

Faust 编译器的若干选项可以控制生成的 C++ 代码。默认情况下在单个循环中逐样本计算。但编译器也可以生成向量化和并行代码。下面的代码展示如何以向量模式编译：

static void test7()
{
    createLibContext();
    Box box = boxDelay(boxWire(), boxInt(7));

    compile("test7", box, 3, (const char* []){ "-vec", "-lv", "1" });
    destroyLibContext();
}

compute 方法则是：

virtual void compute(int count, FAUSTFLOAT** inputs, FAUSTFLOAT** outputs) 
{
    FAUSTFLOAT* input0_ptr = inputs[0];
    FAUSTFLOAT* output0_ptr = outputs[0];
    float fYec0_tmp[40];
    float* fYec0 = &fYec0_tmp[8];
    for (int vindex = 0; (vindex < count); vindex = (vindex + 32)) {
        FAUSTFLOAT* input0 = &input0_ptr[vindex];
        FAUSTFLOAT* output0 = &output0_ptr[vindex];
        int vsize = std::min<int>(32, (count - vindex));
        /* 可向量化循环 0 */
        /* 前置代码 */
        for (int j0 = 0; (j0 < 8); j0 = (j0 + 1)) {
            fYec0_tmp[j0] = fYec0_perm[j0];
        }
        /* 计算代码 */
        for (int i = 0; (i < vsize); i = (i + 1)) {
            fYec0[i] = float(input0[i]);
        }
        /* 后置代码 */
        for (int j1 = 0; (j1 < 8); j1 = (j1 + 1)) {
            fYec0_perm[j1] = fYec0_tmp[(vsize + j1)];
        }
        /* 可向量化循环 1 */
        /* 计算代码 */
        for (int i = 0; (i < vsize); i = (i + 1)) {
            output0[i] = FAUSTFLOAT(fYec0[(i - 7)]);
        }
    }
}

如果 C++ 编译器能自动向量化，可能会更快。

如果延迟算子用在数学运算之前的输入信号上，那么只会创建一条延迟线，取两条延迟线的最大长度：

process = _ <: @(500) + 0.5, @(3000) * 1.5;

并用下面的代码构建：

static void test8()
{
    COMPILER
    (
        Box box = boxSplit(boxWire(), 
                            boxPar(boxAdd(boxDelay(boxWire(), 
                                                    boxReal(500)), boxReal(0.5)),
                                   boxMul(boxDelay(boxWire(), 
                                                    boxReal(3000)), boxReal(1.5))));


        compile("test8", box);
    )
}

在 compute 方法中，单条 fVec0 延迟线在两个不同索引处被读取：

virtual void compute(int count, FAUSTFLOAT** inputs, FAUSTFLOAT** outputs) 
{
    FAUSTFLOAT* input0 = inputs[0];
    FAUSTFLOAT* output0 = outputs[0];
    FAUSTFLOAT* output1 = outputs[1];
    for (int i0 = 0; (i0 < count); i0 = (i0 + 1)) {
        float fTemp0 = float(input0[i0]);
        fVec0[(IOTA & 4095)] = fTemp0;
        output0[i0] = FAUSTFLOAT((fVec0[((IOTA - 500) & 4095)] + 0.5f));
        output1[i0] = FAUSTFLOAT((1.5f * fVec0[((IOTA - 3000) & 4095)]));
        IOTA = (IOTA + 1);
    }
}

等价的 box 表达式

非常重要的一点是，语法等价的 box 表达式会在内部由同一个内存结构表示（使用哈希共享 hash consing），因此在后续编译步骤中以相同方式处理。所以下面的代码中，创建 s1 变量来定义 boxAdd(boxDelay(boxWire(), boxReal(500)), boxReal(0.5)) 表达式，然后在两个输出中使用：

static void equivalent1()
{
    COMPILER
    (
        Box b1 = boxAdd(boxDelay(boxWire(), boxReal(500)), boxReal(0.5));
        Box box = boxPar(b1, b1);

        compile("equivalent1", signals);
    )
}

其行为与下面的代码完全相同，其中 boxAdd(boxDelay(boxWire(), boxReal(500)), boxReal(0.5)) 表达式被使用了两次：

static void equivalent2()
{
    COMPILER
    (
         Box box = boxPar(boxAdd(boxDelay(boxWire(), boxReal(500)), boxReal(0.5)),
                          boxAdd(boxDelay(boxWire(), boxReal(500)), boxReal(0.5)));


        compile("equivalent2", box);
    )
}

在 box API 之上创建 DSL 时，这是值得记住的一个特性。

定义递归信号

递归信号可以用 boxRec 表达式定义。会自动创建一个样本的延迟以产生有效的计算。下面是一个简单例子：

process = + ~ _;

用下面的代码构建：

static void test10()
{
    COMPILER
    (
        Box box = boxRec(boxAdd(), boxWire());

        compile("test10", box);
    )
}

compute 方法显示了保存延迟信号的 fRec0 变量：

virtual void compute(int count, FAUSTFLOAT** inputs, FAUSTFLOAT** outputs) 
{
    FAUSTFLOAT* input0 = inputs[0];
    FAUSTFLOAT* output0 = outputs[0];
    for (int i0 = 0; (i0 < count); i0 = (i0 + 1)) {
        fRec0[0] = (float(input0[i0]) + fRec0[1]);
        output0[i0] = FAUSTFLOAT(fRec0[0]);
        fRec0[1] = fRec0[0];
    }
}

访问全局上下文

在 Faust 中，底层音频引擎的采样率和缓冲区大小通过外部函数与常量机制访问。这些值也可以在 box 语言中用以下辅助函数使用：

// 在 platform.lib 中复现 'SR' 定义
// SR = min(192000.0, max(1.0, fconstant(int fSampleFreq, )));
inline Box SR()
{
    return boxMin(boxReal(192000.0), 
                  boxMax(boxReal(1.0), 
                         boxFConst(SType::kSInt, "fSampleFreq", "<math.h>")));
}

// 在 platform.lib 中复现 'BS' 定义
// BS = fvariable(int count, );
inline Signal BS()
{
    return boxFVar(SType::kSInt, "count", "<math.h>");
}

所以下面的 DSP 程序：

import("stdfaust.lib"); 
process = ma.SR, ma.BS;

可以在 box API 层面写成：

static void test11()
{
    COMPILER
    (
        Box box = boxPar(SR(), BS());

        compile("test11", box);
    )
}

生成的 C++ 类包含：

virtual void instanceConstants(int sample_rate) 
{
    fSampleRate = sample_rate;
    fConst0 = std::min<float>(192000.0f, std::max<float>(1.0f, float(fSampleRate)));
}

以及：

virtual void compute(int count, FAUSTFLOAT** inputs, FAUSTFLOAT** outputs) 
{
    FAUSTFLOAT* output0 = outputs[0];
    FAUSTFLOAT* output1 = outputs[1];
    int iSlow0 = count;
    for (int i0 = 0; (i0 < count); i0 = (i0 + 1)) {
        output0[i0] = FAUSTFLOAT(fConst0);
        output1[i0] = FAUSTFLOAT(iSlow0);
    }
}

创建表

可以创建只读表和读写表。只读表信号用 boxReadOnlyTable 创建，接受：

  • 第一个参数为长度
  • 第二个参数为内容
  • 第三个参数为读取索引（介于 0 与 size-1 之间）

并产生被索引的表内容作为其唯一输出。下面这个简单的 DSP 示例：

process = 10,1,int(_) : rdtable;

可以用以下代码写出：

static void test20()
{
    COMPILER
    (
        Box box = boxReadOnlyTable(boxInt(10), boxInt(1), boxIntCast(boxWire()));

        compile("test20", signals);
    )
}

生成的 C++ 代码包含 itbl0mydspSIG0 静态表定义：

static int itbl0mydspSIG0[10];

将在初始化时调用一次的表填充代码：

void fillmydspSIG0(int count, int* table) 
{
    for (int i1 = 0; (i1 < count); i1 = (i1 + 1)) {
        table[i1] = 1;
    }
}

以及访问 itbl0mydspSIG0 表的 compute 方法：

virtual void compute(int count, FAUSTFLOAT** inputs, FAUSTFLOAT** outputs) 
{
    FAUSTFLOAT* input0 = inputs[0];
    FAUSTFLOAT* output0 = outputs[0];
    for (int i0 = 0; (i0 < count); i0 = (i0 + 1)) {
        output0[i0] = FAUSTFLOAT(itbl0mydspSIG0[int(float(input0[i0]))]);
    }
}

读写表信号用 boxWriteReadTable 创建，接受：

  • 第一个参数为长度
  • 第二个参数为内容
  • 第三个参数为写入索引（介于 0 与 size-1 之间）
  • 第四个参数为表的输入
  • 第五个参数为读取索引（介于 0 与 size-1 之间）

并产生被索引的表内容作为其唯一输出。下面这个 DSP 示例：

process = 10,1,int(_),int(_),int(_) : rwtable;

可以用以下代码写出：

static void test20()
{
    COMPILER
    (
        Box box = boxWriteReadTable(boxInt(10), 
                                    boxInt(1), 
                                    boxIntCast(boxWire()), 
                                    boxIntCast(boxWire()), 
                                    boxIntCast(boxWire()));

        compile("test21", signals);
    )
}

生成的 C++ 代码在 mydsp 类中包含 itbl0 定义作为字段：

int itbl0[10];

将在初始化时调用一次的表填充代码：

创建波形

下面这个定义波形的 DSP 程序：

process = waveform { 0, 100, 200, 300, 400 };

可以用以下代码写出，其中波形的长度是第一个输出，波形内容本身是用 boxWaveform 创建的第二个输出，以遵循波形语义：

static void test12()
{
    COMPILER
    (
        tvec waveform;
        // 填充波形内容向量
        for (int i = 0; i < 5; i++) {
            waveform.push_back(boxReal(100*i));
        }
        Box box = boxWaveform(waveform); // 长度和波形内容

        compile("test12", box);
     )
}

生成的 C++ 代码中，fmydspWave0 波形被定义为静态表：

const static float fmydspWave0[5] = {0.0f,100.0f,200.0f,300.0f,400.0f};

并在下面的 compute 方法中使用：

virtual void compute(int count, FAUSTFLOAT** inputs, FAUSTFLOAT** outputs) 
{
    FAUSTFLOAT* output0 = outputs[0];
    FAUSTFLOAT* output1 = outputs[1];
    for (int i0 = 0; (i0 < count); i0 = (i0 + 1)) {
        output0[i0] = FAUSTFLOAT(5);
        output1[i0] = FAUSTFLOAT(fmydspWave0[fmydspWave0_idx]);
        fmydspWave0_idx = ((1 + fmydspWave0_idx) % 5);

创建声音文件

soundfile 基元可以访问一组外部定义的声音资源，这些资源用其文件名或完整路径的列表描述。它接受：

  • 声音编号（作为 0 到 255 之间的整数，即常量数值表达式）
  • 声音中的读取索引（如果读取索引大于声音长度，将访问声音的最后一个样本）

生成的块具有：

  • 两个固定输出：第一个是当前访问的声音长度（以帧为单位），第二个是当前访问的声音标称采样率
  • 声音声道本身还有若干额外输出，作为常量数值表达式

soundfile 块用 boxSoundfile 创建。因此下面的 DSP 代码：

process = 0,0 : soundfile("sound[url:{'tango.wav'}]", 1);

将用 box API 这样创建：

static void test19()
{
    COMPILER
    (
        Box box = boxSoundfile("sound[url:{'tango.wav'}]", 
                               boxInt(2),  
                               boxInt(0),  
                               boxInt(0));

        compile("test19", box);
    )
}

并生成下面的 compute 方法：

virtual void compute(int count, FAUSTFLOAT** inputs, FAUSTFLOAT** outputs) 
{
    FAUSTFLOAT* output0 = outputs[0];
    FAUSTFLOAT* output1 = outputs[1];
    FAUSTFLOAT* output2 = outputs[2];
    Soundfile* fSoundfile0ca = fSoundfile0;
    int* fSoundfile0ca_le0 = fSoundfile0ca->fLength;
    int iSlow0 = fSoundfile0ca_le0[0];
    int* fSoundfile0ca_ra0 = fSoundfile0ca->fSR;
    int iSlow1 = fSoundfile0ca_ra0[0];
    int iSlow2 = std::max<int>(0, std::min<int>(0, (iSlow0 + -1)));
    int* fSoundfile0ca_of0 = fSoundfile0ca->fOffset;
    float** fSoundfile0ca_bu0 = static_cast<float**>(fSoundfile0ca->fBuffers);
    float* fSoundfile0ca_bu_ch0 = fSoundfile0ca_bu0[0];
    for (int i0 = 0; (i0 < count); i0 = (i0 + 1)) {
        output0[i0] = FAUSTFLOAT(iSlow0);
        output1[i0] = FAUSTFLOAT(iSlow1);
        output2[i0] = FAUSTFLOAT(fSoundfile0ca_bu_ch0[(fSoundfile0ca_of0[0] + iSlow2)]);
    }
    fSoundfile0 = fSoundfile0ca;
}

使用 DSPToBoxes 函数

完整的 DSP 程序可以用 DSPToBoxes 函数编译为 box，该函数接受 DSP 程序字符串，返回输入/输出数量和创建的 box：

static void test25(int argc, char* argv[])
{
    createLibContext();
    {
        int inputs = 0;
        int outputs = 0;
        string error_msg;

        // 创建振荡器
        Box osc = DSPToBoxes("import(\"stdfaust.lib\"); process = os.osc(440);", argc, (const char**)argv, &inputs, &outputs, error_msg);

        // 编译它
        dsp_factory_base* factory = createCPPDSPFactoryFromBoxes("FaustDSP", osc, argc, (const char**)argv, error_msg);
        if (factory) {
            factory->write(&cout);
            delete(factory);
        } else {
            cerr << error_msg;
        }
    }
    destroyLibContext();
}

生成的 box 表达式可以复用在更复杂的构造中，如下例：用 DSPToBoxes 函数创建滤波器，然后用滑块控制其频率，并接入实际输入：

static void test26(int argc, char* argv[])
{
    createLibContext();
    {
        int inputs = 0;
        int outputs = 0;
        string error_msg;

        // 创建无参数滤波器
        Box filter = DSPToBoxes("import(\"stdfaust.lib\"); process = fi.lowpass(5);", argc, (const char**)argv, &inputs, &outputs, error_msg);

        // 创建滤波器参数并连接
        Box cutoff = boxHSlider("cutoff", boxReal(300), boxReal(100), boxReal(2000), boxReal(0.01));
        Box cutoffAndInput = boxPar(cutoff, boxWire());
        Box filteredInput = boxSeq(cutoffAndInput, filter);

        bool res = getBoxType(filteredInput, &inputs, &outputs);
        std::cout << "getBoxType inputs: " << inputs << " outputs: " << outputs << std::endl;

        dsp_factory_base* factory = createCPPDSPFactoryFromBoxes("FaustDSP", filteredInput, argc, (const char**)argv, error_msg);
        if (factory) {
            factory->write(&cout);
            delete(factory);
        } else {
            cerr << error_msg;
        }
    }
    destroyLibContext();
}

注意，getBoxType 函数可用于获取给定 box 的输入和输出数量。

定义更复杂的表达式：相位器与振荡器

可以定义更复杂的信号表达式，用辅助定义创建 box。所以下面的 DSP 程序：

import("stdfaust.lib");
process = phasor(440)
with {
     decimalpart(x) = x-int(x);
     phasor(f) = f/ma.SR : (+ : decimalpart) ~ _;
};

可以用以下辅助函数构建，这里用 C 编写：

static Box decimalpart()
{
    return boxSub(boxWire(), boxIntCast(boxWire()));
}

static Box phasor(Box f)
{
    return boxSeq(boxDiv(f, SR()), 
                  boxRec(boxSplit(boxAdd(), decimalpart()), boxWire()));
}

以及组合它们的主函数：

static void test17()
{
    COMPILER
    (
        Box box = phasor(boxReal(440));

        compile("test17", box);
    )
}

它产生下面的 compute 方法：

virtual void compute(int count, FAUSTFLOAT** inputs, FAUSTFLOAT** outputs) 
{
    FAUSTFLOAT* output0 = outputs[0];
    for (int i0 = 0; (i0 < count); i0 = (i0 + 1)) {
        fRec0[0] = (fConst0 + (fRec0[1] - float(int((fConst0 + fRec0[1])))));
        output0[i0] = FAUSTFLOAT(fRec0[0]);
        fRec0[1] = fRec0[0];
    }
}

现在看下面的振荡器：

 import("stdfaust.lib");
 process = osc(440), osc(440)
 with {
    decimalpart(x) = x-int(x);
    phasor(f) = f/ma.SR : (+ : decimalpart) ~ _;
    osc(f) = sin(2 * ma.PI * phasor(f));
 };

可以用以下代码构建：

static Box osc(Box f)
{
    return boxSin(boxMul(boxMul(boxReal(2.0), boxReal(3.141592653)), phasor(f)));
}

static void test18()
{
    COMPILER
    (
        Box box = boxPar(osc(boxReal(440)), osc(boxReal(440)));

        compile("test18", box);
    )
}

它产生下面的 compute 方法，可以看到，由于两个输出上使用的是同一个振荡器信号，它实际上只计算一次并复制两次：

virtual void compute(int count, FAUSTFLOAT** inputs, FAUSTFLOAT** outputs) 
{
    FAUSTFLOAT* output0 = outputs[0];
    FAUSTFLOAT* output1 = outputs[1];
    for (int i0 = 0; (i0 < count); i0 = (i0 + 1)) {
        fRec0[0] = (fConst0 + (fRec0[1] - float(int((fConst0 + fRec0[1])))));
        float fTemp0 = std::sin((6.28318548f * fRec0[0]));
        output0[i0] = FAUSTFLOAT(fTemp0);
        output1[i0] = FAUSTFLOAT(fTemp0);
        fRec0[1] = fRec0[0];
    }
}

将信号生成为中间步骤

boxesToSignals 函数可以把 box 编译为信号列表，以便与 signal API 一起使用。下面的例子展示两个步骤（box => 信号，然后信号 => DSP 工厂）如何串联，把前面的代码重写为：

// 使用 Interpreter 后端。
static void test23(int argc, char* argv[])
{

复音 MIDI 可控的简单合成器

下面是一个 MIDI 可控的简单合成器，先是 DSP 代码：

import("stdfaust.lib");
process = organ, organ
with {
    decimalpart(x) = x-int(x);
    phasor(f) = f/ma.SR : (+ : decimalpart) ~ _;
    osc(f) = sin(2 * ma.PI * phasor(f));
    freq = nentry("freq", 100, 100, 3000, 0.01);
    gate = button("gate");
    gain = nentry("gain", 0.5, 0, 1, 0.01);
    organ = gate * (osc(freq) * gain + osc(2 * freq) * gain);

};

然后是使用 box API 的 C++ 代码：

// 简单的复音 DSP。
static void test24(int argc, char* argv[])
{
    interpreter_dsp_factory* factory = nullptr;
    string error_msg;

    createLibContext();
    {
        // 遵循 freq/gate/gain 约定，
        // 见：../manual/midi/#standard-polyphony-parameters
        Box freq = boxNumEntry("freq", 
                               boxReal(100), 
                               boxReal(100), 
                               boxReal(3000), 
                               boxReal(0.01));
        Box gate = boxButton("gate");
        Box gain = boxNumEntry("gain",
                               boxReal(0.5), 
                               boxReal(0), 
                               boxReal(1), 
                               boxReal(0.01));
        Box organ = boxMul(gate, boxAdd(boxMul(osc(freq), gain), 
                                        boxMul(osc(boxMul(freq, boxInt(2))), gain)));
        // 立体声
        Box box = boxPar(organ, organ);

        factory = createInterpreterDSPFactoryFromBoxes("FaustDSP", 
                                                        box, 
                                                        0, nullptr, 
                                                        error_msg);
    }
    destroyLibContext();

    // 在 createLibContext/destroyLibContext 作用域之外使用工厂
    if (factory) {
        dsp* dsp = factory->createDSPInstance();
        assert(dsp);

        // 分配复音 DSP
        dsp = new mydsp_poly(dsp, 8, true, true);

        // 分配 MIDI/音频驱动
        jackaudio_midi audio;
        audio.init("Organ", dsp);

        // 创建 GUI
        GTKUI gtk_ui = GTKUI("Organ", &argc, &argv);
        dsp->buildUserInterface(&gtk_ui);

        // 创建 MIDI 控制器
        MidiUI midi_ui = MidiUI(&audio);
        dsp->buildUserInterface(&midi_ui);

        // 启动实时处理
        audio.start();

        // 启动 MIDI
        midi_ui.run();

        // 启动 GUI
        gtk_ui.run();

        // 清理
        audio.stop();
        delete dsp;
        deleteInterpreterDSPFactory(factory);
    } else {
        cerr << error_msg;
    }
}

C API 示例

box API 也以纯 C API 形式提供。下面是前面某个示例用 C API 重写，以创建 box 表达式，其中 LLVM 后端与 C 版本的 createCDSPFactoryFromBoxes 函数一起使用（见 llvm-dsp-c.h）来生成 DSP 工厂，然后生成 DSP 实例：

/*
 import("stdfaust.lib");
 process = phasor(440)
 with {
     decimalpart(x) = x-int(x);
     phasor(f) = f/ma.SR : (+ : decimalpart) ~ _;
 };
 */

static Box decimalpart()
{
    return CboxSubAux(CboxWire(), CboxIntCastAux(CboxWire()));
}

static Box phasor(Box f)
{
    return CboxSeq(CboxDivAux(f, SR()), 
                   CboxRec(CboxSplit(CboxAdd(), decimalpart()), CboxWire()));
}

static void test1()
{
    createLibContext();
    {
        Box box = phasor(CboxReal(2000));

        char error_msg[4096];
        llvm_dsp_factory* factory = createCDSPFactoryFromBoxes("test1", 
                                                               box, 
                                                               0, NULL, 
                                                               "", 
                                                               error_msg, 
                                                               -1);

        if (factory) {

            llvm_dsp* dsp = createCDSPInstance(factory);
            assert(dsp);

            // 渲染音频
            render(dsp);

            // 清理
            deleteCDSPInstance(dsp);
            deleteCDSPFactory(factory);

        } else {
            printf("Cannot create factory : %s\n", error_msg);
        }
    }
    destroyLibContext();
}
