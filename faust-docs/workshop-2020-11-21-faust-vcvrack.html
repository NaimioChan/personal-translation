用 Faust 配合 VCV Rack

VCV Rack 是一个虚拟模块化合成器，允许把成千上万个独立开发的模块在 patch 中连接起来，以合成和处理声音。庞大的开发者社区提供了大量模块，可作为库安装到应用中，其中许多是作为GitHub 上的开源项目开发的。

本教程展示如何用 Faust 语言生成单音或复音模块：

  • 要么使用可编程且支持 Faust 的 VCV Prototype 来编辑、编译和测试 Faust DSP 代码
  • 要么使用 faust2vcvrack 工具，它可以生成独立模块
  • 为了介绍模块开发，我们先快速概览用 C++ 开发模块的过程。

安装

在这里获取适用于你的操作系统的二进制版本。

安装 VCV Rack SDK

参见插件开发教程页面，以及适用于你的操作系统的SDK 本身。

别忘了设置 RACK_DIR 变量：export RACK_DIR=<Rack SDK folder>。

编译 Faust 版的 VCV Prototype 模块

Faust 编译器可以通过 libfaust 嵌入应用或插件，DSP 代码可以即时编辑和 JIT 编译。

你需要克隆并编译这个 GitHub 项目。务必使用 faust 分支，并按照所提供的说明操作。

然后你就可以参加这个工作坊了！

模块化原理

VCV Rack 遵循这篇维基百科文章中所解释的模块化合成器原理：

模块化合成器是由不同功能的独立模块组成的合成器。用户可以用跳线、矩阵接线系统或开关把模块连接起来，形成一个 patch。模块的输出（电压）可以作为（音频）信号、控制电压或逻辑/定时条件。典型的模块有振荡器（作用于频率）、滤波器（频谱）、放大器/门（幅度）和包络发生器（动态控制）。

为此，控制信号（CV）以音频速率运行，因此整个 patch 以只有单个样本的音频缓冲区触发。当被描述为 CV 信号时，参数因此可以由任何模块传来的其他信号实时改变，只需把它们连接起来。所以这个模型中音频信号与控制信号之间存在某种模糊，信号可以在任何地方连接。

由于软件模块模仿真实的物理模块，它们多少遵循相同的约定来表示信号范围，通常是 [-5v...5v] 或 [0v..10v] 的取值，MIDI 信号则用 1V/倍频程。更完整的说明见电压标准页面。

控制参数也可以用开关、旋钮等从模块的 GUI 改变。

模块可以是单音或复音的（最多 16 个声道），此时每根线实际传输若干（通常相关的）信号。复音模型显然用于乐器，但也可以用于效果器。复音模块在 GUI 中显示为更粗的线。

用 C++ 开发模块

在用 Faust 开发模块之前，先看看标准流程。模块通常用 C++ 借助 VCV Rack SDK 创建，SDK 为开发者提供了几个入手工具。按照这里的教程，可以创建一个模板项目：

生成模板

./helper.py createplugin MyPlugin

创建的文件夹包含一个 Makefile，可用于编译模块并安装到你（先前安装的）VCV Rack 应用中：

make && make install

在模块项目中，以下命令会解码 SVG 文件并生成用于创建各种控件的模板 C++ 代码：

../helper.py createmodule MyModule res/MyModule.svg src/MyModule.cpp

添加 DSP 代码

然后添加 C++ 代码，在 process 函数中实现一个简单的振荡器：

 float phase = 0.f;
 float freq = 440.f;

 void process(const ProcessArgs &args) override {
        // 累加相位
        phase += freq * args.sampleTime;
        if (phase >= 0.5f)
            phase -= 1.f;

        // 计算正弦输出
        float sine = std::sin(2.f * M_PI * phase);

        // 音频信号通常为 +/-5V
        outputs[SINE_OUTPUT].setVoltage(5.f * sine);
 }

plugin.cpp 中的以下一行需要取消注释：

p->addModel(modelMyModule);

plugin.hpp 中同样如此：

extern Model* modelMyModule;

然后需要重新编译并安装模块：

make && make install

用支持 Faust 的 VCV Prototype 模块编程

VCV Prototype 模块运行脚本语言，用于原型设计、学习和现场编程。它目前可以用 JavaScript、Lua、Vult 或 PureData 编程。它定义了一个通用 GUI，含 6 个输入/输出（音频或 CV 信号）、6 个旋钮、6 个指示灯（RGB LED）或 6 个开关（带 RGB LED）。

注意，用原型只能编写单音示例。

通过嵌入 Interpreter 后端的 libfaust 加入了对 Faust 的支持。它允许即时编辑/编译/执行 DSP 程序，性能尚可（使用 LLVM JIT 能生成更快的代码，但安装过程会复杂得多）。

编辑/编译/执行 DSP 文件

Faust DSP 文件必须加载到 VCV Prototype 中，并在外部编辑器（Visual Studio Code、Atom……）中编辑。每次保存文件时，它都会被重新编译并执行。为了可能节省编译时间，DSP 机器码会保存在缓存中，下次加载会话时可能被恢复。

6 个音频输入/输出可以在 Faust DSP 中按顺序访问，因此最多可以使用 6 个声道。

6 个开关、旋钮以及指示灯和 switchLights 可以用元数据连接到界面控件：

  • [switch:N]（N 为 1 到 6）必须用在 button 或 checkbox 项中，把它连接到原型界面的第 N 个开关
  • [knob:N]（N 为 1 到 6）必须用在 vslider、hslider 或 nentry 项中，把它连接到原型界面的第 N 个旋钮。旋钮的 [0..1] 范围会映射到滑块/数值输入框的 [min..max] 范围
  • [light_red:N|light_green:N|light_blue:N]（N 为 1 到 6）必须用在 vbargraph 或 hbargraph 项中，把它连接到原型界面的第 N 个指示灯
  • [switchlight_red:N|switchlight_green:N|switchlight_blue:N]（N 为 1 到 6）必须用在 vbargraph 或 hbargraph 中，把它连接到原型界面的第 N 个 switchLight

因此，按钮或复选框界面项可以用 [switch:N] 元数据关联到对应的 GUI 开关，其颜色可以用 switchlight_xx:N 元数据控制。例如：

  • gate = button("gate [switch:1") : hbargraph("[switchlight_red:1]", 0, 1); 描述了一个按下时变红的按钮
  • check = checkbox("check [switch:2]") : vbargraph("[switchlight_red:2]", 0, 1) : vbargraph("[switchlight_green:2]", 0, 1) : vbargraph("[switchlight_blue:2]", 0, 1); 描述了一个被勾选时变白的复选框

其他元数据：

  • [scale:lin|log|exp] 元数据已实现。

rack.lib Faust 库包含用于转换 CV 信号的实用函数，必要时可以扩充。

注意只能描述单音 DSP 程序。

DSP 示例

下面是一个简单示例，展示如何用 GUI 项控制振荡器，并在 DSP 代码中用元数据关联：

import("stdfaust.lib");

// 用元数据连接的界面控件
freq = hslider("freq [knob:1]", 200, 50, 5000, 0.01);
gain = hslider("gain [knob:2]", 0.5, 0, 1, 0.01);
gate = button("gate [switch:1]");

// DSP 处理器
process = os.osc(freq) * gain * 5, os.sawtooth(freq) * gain * gate * 5;

按照 VCV Prototype 模型，注意音频输出会乘以 5，以遵循 [-5v..5v] 范围约定。

移植到 Faust 的 VCV Prototype 标准示例可以在 examples 文件夹中看到：

  • gain.dsp 展示如何用元数据连接开关和旋钮，甚至在被按下或移动时改变颜色：
// 使用所有变量的最简脚本

import("stdfaust.lib");

// 开关按钮，红色高亮
switch(i) = button("switch%i [switch:%i]") : hbargraph("[switchlight_red:%i]", 0, 1);

// 增益滑块，红色高亮
gain(i) = hslider("gain%i [knob:%i]", 0.1, 0, 1, 0.01) : hbargraph("[light_red:%i]", 0, 1);

process = si.bus(6) : par(i, 6, *(gain(i+1)) * (1-switch(i+1)));

  • vco.dsp 展示一个振荡器，其频率由旋钮和 CV 音高信号控制（遵循 1V/倍频程约定）：
// 压控振荡器示例
import("stdfaust.lib");

// 以给定频率创建相位累加器
phasor(freq) = freq/ma.SR : (+ : decimal) ~ _ with { decimal(x) = x-int(x); };

// 音高到频率的转换（也包含在 rack.lib 库中）
cv_pitch2freq(cv_pitch) = 440 * 2 ^ (cv_pitch - 0.75);

gain = hslider("gain [knob:1]", 0.1, 0, 1, 0.01) * 10 - 5;

pitch(x) = x + gain;

process(x) = sin(2 * ma.PI * phasor(cv_pitch2freq(pitch(x)))) * 5;

  • rainbow.dsp

一些附加示例：

  • synth.dsp 演示如何使用 VCV Prototype 的全部界面控件

  • organ.dsp 演示一个可 MIDI 控制的基于加法合成的风琴

  • physicalmodel.dsp 演示一个基于模态合成的钟，连接到混响

使用 faust2vcvrack

faust2vcvrack 工具把一个 Faust DSP 程序编译到一个文件夹中，其中包含 VCV Rack 插件的 C++ 源代码和用于编译它的 Makefile。默认情况下，生成的 C++ 代码会被编译并安装到 VCV Rack 应用中：

faust2vcvrack [-soundfile] [-source] [-nvoices <num>] [additional Faust options (-vec -vs 8...)] <file.dsp>

该工具现在已进入 GitHub 上的 master-dev 分支，也可以在 Faust IDE 中使用，选择相应的导出目标（vcvrack、vcvrack-poly8 或 vcvrack-poly16）。

可用的选项如下：

  • -soundfile when compiling a DSP using the 'soundfile' primitive, add required resources
  • -source to only create the source folder
  • -nvoices <num> to produce a polyphonic self-contained DSP with <num> voices, ready to be used with MIDI

Faust DSP 代码通常产生 [-1..1] 范围的音频信号。由于 VCV 期望 [-5v..5v] 范围的音频信号，它们会在架构文件中自动转换。[0v..10v] 伏范围内的 CV 控制会映射到控制器的 [min..max] 范围。

复音支持

可以用 -nvoices <num> 参数创建最多 16 个声部的复音模块。DSP 代码中可以使用 freq/gate/gain 约定。VCV Rack 对 MIDI 音高值遵循 1V/倍频程约定，因此 MIDI 信号会按此约定自动转换为 freq。增益和门信号（使用 [0v..10v] 范围）会转换为 [0..1] 的取值。

注意，创建复音效果器在 VCV Rack 中同样有意义。例如连接到复音乐器的混响需要是复音的。因此这种情况下也可以使用 -nvoices <num> 参数。

元数据

控件（通常是按钮、滑块、nentry 或 bargraph）会自动转换为 GUI 项（如开关、旋钮或指示灯）。但也可以用元数据把它们连接到 CV 输入/输出：

  • [CV:N] 可以用在输入（通常是滑块或 nentry）或输出（通常是 bargraph）控件中，把它们连接到 CV 而不是常规 GUI 参数。

DSP 示例

下面是一个简单示例，展示如何用界面项控制振荡器。GUI 中会创建一个开关、一个按钮和两个旋钮：

declare options "[midi:on][nvoices:4]";
import("stdfaust.lib");

freq = hslider("freq", 200, 50, 5000, 0.01);
gain = hslider("gain", 0.5, 0, 1, 0.01);
gate = button("gate");
check = checkbox("check");

// DSP 处理器
process = os.osc(freq) * gain * gate, os.sawtooth(freq) * gain * check;

一个复音乐器，其 freq/gate/gain 控件通过 [CV:N] 元数据关联到 VCV 的 MIDI 输入，需用 -nvoices <num> 选项编译：

declare options "[midi:on][nvoices:4]";
import("stdfaust.lib");

// 控制变量
master = hslider("master", 0.3, 0, 2, 0.01);    
pan = hslider("pan", 0.5, 0, 1, 0.01);    

freq = nentry("freq [CV:1]", 440, 20, 20000, 1);    
gate = button("gate [CV:2]");      
gain = nentry("gain [CV:3]", 0.3, 0, 10, 0.01);    

// 各分音的相对幅度
amp(1) = hslider("amp1", 1.0, 0, 3, 0.01);
amp(2) = hslider("amp2", 0.5, 0, 3, 0.01);
amp(3) = hslider("amp3", 0.25, 0, 3, 0.01);

// 声像函数
panner(pan, x) = x*sqrt(1-pan), x*sqrt(pan);

// 加法合成：3 个带 ADSR 包络的正弦振荡器
partial(i) = amp(i+1)*os.osc((i+1)*freq);

process = sum(i, 3, partial(i))
            * (gate : vgroup("1-adsr", en.adsr(0.05, 0.1, 0.1, 0.1)))
            * gain : vgroup("2-master", *(master) : panner(pan));

这个复音乐器随后可以连接到一个复音混响，后者同样要用 -nvoices <num> 选项编译：

import("stdfaust.lib");
process = dm.freeverb_demo;
