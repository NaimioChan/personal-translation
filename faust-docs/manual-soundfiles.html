声音文件支持

声音文件可以通过 soundfile 语言基元使用。声音文件会在初始化时完整加载到内存中，并通过一个输入读取索引来访问。可以获取声音文件的长度和采样率，以实现更复杂的播放方案。soundfile 基元的更完整说明见此。

在 faust2xx 脚本中使用声音文件

由于使用声音文件（实际上是 libsndfile 库能读取的所有格式，若使用 faust2juce 工具则是 JUCE 能读取的格式）时必须把它们嵌入到生成的二进制文件（应用程序或插件）中，一些 faust2xx 脚本里新增了 -soundfile 选项来完成这件事。假设已经写好一个使用 soundfile 基元的 DSP 程序，就可以用下列命令生成二进制文件：

  • faust2caqt -soundfile foo.dsp，在 OSX 上把所需的声音文件嵌入应用程序包

  • faust2max6 -soundfile foo.dsp，在 OSX 上把所需的声音文件嵌入 Max/MSP 外部对象包

查阅 faust2xx 脚本说明页，了解目前哪些脚本支持 -soundfile 选项。

Soundfile 库

soundfiles.lib 库中还有一些额外的函数。目前有三个基本函数有完整文档。库源代码中已写好更多代码，可用不同插值方式读取声音文件。

soundfile 基元也可以在 Web 平台上使用。参见 Faust 网页版 IDE 的相关文档。
