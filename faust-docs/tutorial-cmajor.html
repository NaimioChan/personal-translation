在 Cmajor 中使用 Faust

本教程介绍如何把 Faust 与 Cmajor 配合使用，Cmajor 是一门类似 C 的过程式高性能语言，专为音频处理设计，支持基于 JIT 的动态编译。把 Faust DSP 编译成 Cmajor 代码，可以利用 Faust 库中实现的数百个 DSP 构建模块、开箱即用的示例、Powered By Faust 页面上 200 多个项目中开发的任何 DSP 程序，或网上找到的 Faust DSP 程序。

本教程面向谁？

第一节假定机器上已安装可用的 Faust 编译器，因此更面向常规的 Faust 用户。第二节更适合想了解 Faust 的 Cmajor 用户。

安装所需的包

下载 cmaj 包并安装，使它在 PATH 中可用。

使用命令行工具

生成 Cmajor 代码

假定你已经安装了 faust 编译器，从下面这个 DSP 程序 osc.dsp 出发：

import("stdfaust.lib");

vol = hslider("volume [unit:dB]", 0, -96, 0, 0.1) : ba.db2linear : si.smoo;
freq1 = hslider("freq1 [unit:Hz]", 1000, 20, 3000, 1);
freq2 = hslider("freq2 [unit:Hz]", 200, 20, 3000, 1);

process = vgroup("Oscillator", os.osc(freq1) * vol, os.osc(freq2) * vol);

可以用下面的命令生成 Cmajor 代码：

faust -lang cmajor osc.dsp -o osc.cmajor

这会生成一个 mydsp 处理器，包含在命名空间 faust {...} 中，并附带一组操作它的方法。这个 API 基本上仿照为 C++ 后端定义的那套接口。

查看生成的代码

生成的代码包含针对 DSP 源代码中定义的三个滑块的 input event 定义：

input event float32 eventfHslider1 [[ name: "freq1", group: "/v:Oscillator/freq1", min: 20.0f, max: 3000.0f, init: 1000.0f, step: 1.0f, meta_unit0: "Hz" ]];
input event float32 eventfHslider2 [[ name: "freq2", group: "/v:Oscillator/freq2", min: 20.0f, max: 3000.0f, init: 200.0f, step: 1.0f, meta_unit1: "Hz" ]];
input event float32 eventfHslider0 [[ name: "volume", group: "/v:Oscillator/volume", min: 0.0f, max: 1.0f, init: 0.5f, step: 0.01f ]];

必需的 main 函数执行 DSP 样本生成代码：

void main()
{
    // DSP 循环永远运行……
    loop
    {
        if (fUpdated) { fUpdated = false; control(); }

        // 计算一个样本
        fRec1[0] = fControl[1] + fRec1[1] - floor (fControl[1] + fRec1[1]);
        output0 <- float32 (fControl[0] * ftbl0mydspSIG0.at (int32 (65536.0f * fRec1[0])));
        fRec2[0] = fControl[2] + fRec2[1] - floor (fControl[2] + fRec2[1]);
        output1 <- float32 (fControl[0] * ftbl0mydspSIG0.at (int32 (65536.0f * fRec2[0])));
        fRec1[1] = fRec1[0];
        fRec2[1] = fRec2[0];

        // 把所有流向前推进一个「tick」
        advance();
    }
}

注意生成的代码使用所谓的标量代码生成模型（默认模型），其中编译好的样本生成代码内联在 Cmajor 的 loop 块里。

我们无法直接播放生成的 osc.cmajor 文件，因为 cmaj 程序需要 osc.cmajorpatch 才能执行。一个简单的办法是使用下面的命令：

cmaj create --name=osc osc

创建一个 osc 文件夹，其中含默认的 osc.cmajor 与 osc.cmajorpatch 文件。然后用下面的命令：

faust -lang cmajor osc.dsp -o osc/osc.cmajor

就可以把默认的 osc.cmajor 简单替换为我们自己由 Faust 生成的版本。

现在可以用 cmaj 程序编译并执行这个 patch 文件：

cmaj play osc/osc.cmajorpatch

三个声明的滑块会被自动创建，可用于改变两个声道的频率及其音量。

Cmajor 处理器代码可以直接用于更复杂的 Cmajor 程序，也可以与其他 Faust 生成的或手写的 Cmajor 处理器相连。注意，生成的处理器名字可以直接用 Faust 编译器的 -cn <name> 选项更改，这样多个 Faust 生成的处理器就能靠名字区分开：

faust -lang cmajor -cn osc osc.dsp -o osc/osc.cmajor

使用 faust2cmajor 工具

faust2cmajor 工具可以自动完成用正确选项调用 Faust 编译器并与 cmaj 程序交互的过程：

faust2cmajor -h
Usage: faust2cmajor [options] [Faust options] <file.dsp>
Compiles Faust programs to Cmajor
Options:
-midi : activates MIDI control
-nvoices <num> : produces a polyphonic DSP with <num> voices, ready to be used with MIDI events
-effect <effect.dsp> : generates a polyphonic DSP connected to a global output effect, ready to be used with MIDI or OSC
-effect auto : generates a polyphonic DSP connected to a global output effect defined as 'effect' in <file.dsp>, ready to be used with MIDI or OSC
-juce : to create a JUCE project
-dsp : to create a 'dsp' compatible subclass
-play : to start the 'cmaj' runtime with the generated Cmajor file
Faust options : any option (e.g. -vec -vs 8...). See the Faust compiler documentation.

所以下面的命令：

faust2cmajor -play osc.dsp

会直接编译 osc.dsp 文件，生成 osc.cmajor 与 osc.cmajorpatch 文件：

{
    "CmajorVersion": 1,
    "ID": "grame.cmajor.osc",
    "version": "1.0",
    "name": "osc",
    "description": "Cmajor example",
    "category": "synth",
    "manufacturer": "GRAME",
    "website": "https: // faust.grame.fr",
    "isInstrument": false,
    "source": "osc.cmajor"
}

并启动 cmaj 程序来运行这个处理器。

下面这个支持复音乐器的 DSP 可以转换为 MIDI 就绪的 cmajor 乐器：

declare options "[midi:on][nvoices:8]";
import("stdfaust.lib");
process = organ <: _,_
with {
    decimalpart(x) = x-int(x);
    phasor(f) = f/ma.SR : (+ : decimalpart) ~ _;
    osc(f) = sin(2 * ma.PI * phasor(f));
    freq = nentry("freq", 100, 100, 3000, 0.01);
    gate = button("gate");
    gain = nentry("gain", 0.5, 0, 1, 0.01);
    organ = en.adsr(0.1, 0.1, 0.7, 0.25, gate) * (osc(freq) * gain + osc(2*freq)*0.5 * gain);
};

随后下面的命令会打开 cmaj 程序，可以发送 MDI 事件来控制这个乐器：

faust2cmajor -play -midi -nvoices 16 organ.dsp

注意生成的 GUI 是空的，因为生成的处理器无法自动把它的控件反映到主图里。

下面这个集成了效果的支持复音乐器的 DSP 可以转换为 MIDI 就绪的 cmajor 乐器：

declare options "[midi:on][nvoices:8]";
import("stdfaust.lib");
process = pm.clarinet_ui_MIDI <: _,_;
effect = dm.freeverb_demo;

随后下面的命令会打开 cmaj 程序，可以发送 MIDI 事件来控制这个乐器：

faust2cmajor -play -midi -nvoices 16 -effect auto clarinet.dsp

这里生成的 GUI 同样是空的。

用 faustremote 生成 Cmajor 输出

另一种办法是用 faustremote 脚本，通过下面的命令转换本地的 DSP：

faustremote cmajor cmajor foo.dsp
unzip binary.zip

使用 Faust 网页版 IDE

Faust DSP 程序可以在 Faust 网页版 IDE 中编写、测试，并生成为可嵌入的 Cmajor 代码。

生成 Cmajor 输出

可以直接用 Platform = cmajor 与 Architecture = cmajor 导出选项生成 Cmajor 程序形式的输出。得到的 foo 文件夹是自包含的，包含 foo.cmajor 与 foo.cmajorpatch 文件。可以用 cmaj play foo/foo.cmajorpatch 命令执行这个程序，也可以把它转换为 JUCE 插件。

导出代码

以复音模式生成 Cmajor 输出

遵循复音freq/gate/gain 约定的 DSP 程序可以用 Platform = cmajor 与 Architecture = cmajor-poly 导出选项生成。得到的 foo 文件夹是自包含的，包含 foo.cmajor 与 foo.cmajorpatch 文件。可以用 cmaj play foo/foo.cmajorpatch 命令执行这个乐器，并用 MIDI 设备演奏，也可以把它转换为 JUCE 插件。

以复音模式并带全局效果生成 Cmajor 输出

遵循复音freq/gate/gain 约定、并带集成效果的 DSP 程序可以用 Platform = cmajor 与 Architecture = cmajor-poly-effect 导出选项生成。得到的 foo 文件夹是自包含的，包含 foo.cmajor 与 foo.cmajorpatch 文件。可以用 cmaj play foo/foo.cmajorpatch 命令执行这个乐器，并用 MIDI 设备演奏，也可以把它转换为 JUCE 插件。

从网上找到的 Faust DSP 程序生成 Cmajor 输出

网上找到的 Faust DSP 程序也可以转换：

  • 例如 Powered By Faust 页面上列出的 fverb。用 https://faustide.grame.fr/?code=URL 语法即可加载 DSP 内容，所以用下面这个 URL：https://faustide.grame.fr/?code=https://raw.githubusercontent.com/jpcima/fverb/master/fverb.dsp，在 Faust 网页版 IDE 中测试后，再如前所示转换为 Cmajor 程序

  • 基础示例已编译为 Cmajor 版本，见此处

  • faustplayground 平台的示例可以在此找到并转换。它们已编译为 Cmajor 版本，见此处。

实验性的 Faust in Cmajor 集成

随着 Cmajor 源代码的发布，现在已有与 Faust 的实验性集成，从 Cmajor 1.0.2616 发布版开始。这样可以创建融合 Faust 与 Cmajor 代码的 patch。包含 Faust 到 Cmajor 后端的 libfaust 组件被编译为 WebAssembly，在 Faust DSP 到 Cmajor 的转换过程中动态使用。随后生成的 Cmajor 文件会被 JIT 编译。参见 FaustFM 示例。

已知限制

当 patch 导出为 C++ 或 JavaScript 时，Cmajor 语言会生成一些有用的 API。例如 getInputEndpoints/getOutputEndpoints 与 getEndpointHandle 函数允许外部代码枚举并访问所有端点，从而控制程序或构建 GUI。但遗憾的是，这些函数并不属于语言本身。因此我们不知道有什么办法可以：

  • 编写一个通用的 Cmajor 程序，自动把某些端点（假设它们使用某种 MIDI 描述元数据）连接到 MIDI 消息

  • 编写一个通用的 Cmajor 程序，自动把由 Faust DSP 程序生成的声部包装成复音且支持 MIDI 的程序，并在主图层面上暴露该声部的参数集，以便对所有声部统一控制

我们认为，如果语言具备某种反射性，表达能力会更强。
