数学文档

Faust 编译器提供一种机制，可为 Faust 程序生成自描述的数学语义文档，本质上是一个 pdf 文件。相应选项是 -mdoc（短）或 --mathdoc（长）。

Mathdoc 的目标

Faust 数学文档生成器有四个主要目标，也就是四种用途：

  • 保留 DSP 源代码及其所需的全部库，使 DSP 能用更新版本的编译器编译并产生相同的程序。我们正是以这种方式允许库自身演进（甚至不必保持与旧版本的兼容），同时仍让旧程序能用新版本编译器编译，
  • 以纯数学形式保留信号处理器，独立于任何计算机语言，
  • 通过展示编译阶段之后真正参与计算的公式，为调试任务提供帮助，
  • 提供一种新的教学支持，作为代码与信号处理公式之间的桥梁。

安装要求

  • 当然是 faust！
  • svg2pdf（来自 Cairo 2D 图形库），用于转换框图，因为 Latex 不能直接嵌入 SVG，
  • breqn，一个处理长公式自动断行的 Latex 包，
  • pdflatex，用于编译 Latex 输出文件。

生成 Mathdoc

生成完整数学文档最简单的方式是对 Faust 文件调用 faust2mathdoc 脚本，因为 -mdoc 选项会让文档生成过程停在未完成状态（只生成源代码）。

调用 -mdoc 选项

直接调用 faust -mdoc 只完成工作的第一部分，生成：

  • 一个顶层目录，后缀为 -mdoc，
  • 5 个子目录（cpp/、pdf/、src/、svg/、tex/），
  • 一个包含公式的 Latex 文件，
  • 框图的 SVG 文件。

此阶段：

  • cpp/ 仍为空，
  • pdf/ 仍为空，
  • src/ 包含用到的所有 Faust 源代码（因此含全部所需库，得到自包含的 DSP），
  • svg/ 包含 SVG 框图文件，
  • tex/ 包含生成的 Latex 文件。

调用 faust2mathdoc

faust2mathdoc 脚本先调用 faust --mathdoc，然后完成余下的工作：

  • 把输出的 C++ 文件移到 cpp/，
  • 把所有 SVG 文件转换为 pdf 文件（必须安装 Cairo 2D 图形库的 svg2pdf），
  • 对 Latex 文件运行 pdflatex（必须同时安装 pdflatex 和 breqn 包），
  • 把生成的 pdf 文件移到 pdf/。

自动文档

默认情况下，输入 Faust 文件中找不到 <mdoc> 标签时，-mdoc 选项会自动生成包含四个小节的 Latex 文件：

  • process 的公式，汇集 process 所需的全部公式，
  • process 的框图，显示 process 的顶层框图，
  • 本文档的说明，概述生成过程与约定信息，
  • 输入代码的完整清单，列出所有需要的输入文件（含库）。

手工文档

可以不用自动模式，改用五个类 xml 标签自行指定文档。这样既能修改呈现方式，也能添加自己的注释，不仅可针对 process，也可针对任何你想描述的表达式。注意，一旦在 Faust 文件中声明 <mdoc> 标签，自动模式的默认结构就被忽略，所有 Latex 内容都由你负责！

六个标签

以下是这六个专用标签：

  • <mdoc></mdoc>，用于在 Faust 代码中打开一个文档区，
  • <equation></equation>，用于获取某个 Faust 表达式的公式，
  • <diagram></diagram>，用于获取某个 Faust 表达式的顶层框图，
  • <metadata></metadata>，用于引用 Faust 元数据（参见声明），会调用相应的关键字，
  • <notice />，用于插入所有公式实际打印的「自适应」说明，
  • <listing [attributes] />，用于插入所调用 Faust 文件的清单。

<listing /> 标签最多可有三个布尔属性（默认为 true）：

  • mdoctags 对应 <mdoc> 标签；
  • dependencies 对应其它文件的依赖；
  • distributed 对应交错在 <mdoc> 各节之间的 Faust 代码的分发。

mdoc 顶层标签

<mdoc></mdoc> 标签是 Faust 数学文档各节的顶层定界符。这意味着另外四个文档标签不能在这些标签对之外使用。

除这四个内部标签外，<mdoc></mdoc> 标签还接受自由 Latex 文本，包括其标准宏（如 \section、\emph 等）。这样就能直接在输入 Faust 文件里管理生成的 tex 文件的呈现方式。

Faust 引入的 Latex 包的完整列表见文件 architecture/latexheader.tex。

手工编写 Mathdoc 的示例

<mdoc>
\title{<metadata>name</metadata>}
\author{<metadata>author</metadata>}
\date{\today}
\maketitle

\begin{tabular}{ll}
    \hline
    \textbf{name}       & <metadata>name</metadata> \\
    \textbf{version}    & <metadata>version</metadata> \\
    \textbf{author}     & <metadata>author</metadata> \\
    \textbf{license}    & <metadata>license</metadata> \\
    \textbf{copyright}  & <metadata>copyright</metadata> \\
    \hline
\end{tabular}
\bigskip
</mdoc>

-stripmdoc 选项

输入代码清单包含所有 mathdoc 文本。某些情况下它可能无用，因此我们提供一个选项，可在编译阶段直接剥离 mathdoc 内容：-stripmdoc（短）或 --strip-mdoc-tags（长）。

Mathdoc 文件的本地化

默认情况下文档器使用的文本是英文，但可以用 -mdlang（或 --mathdoc-lang）选项加两字母参数（en、fr、it 等）指定其它语言（目前支持法语、德语和意大利语）。

faust2mathdoc 脚本也支持该选项，并且还有第三种短写法 -l：

faust2mathdoc -l fr myfaustfile.dsp

如果你想为本地化工作出力，欢迎翻译 architecture 目录下任一 mathdoctexts-*.txt 文件中的 mathdoc 文本（mathdoctexts-fr.txt、mathdoctexts-it.txt 等）。这些文件是动态加载的，只要添加一个名字合适的文件就能生效。

Mathdoc 生成步骤小结

  • 首先，要对你的 Faust 文件生成完整的数学文档，调用 faust2mathdoc myfaustfile.dsp。
  • 然后打开 pdf 文件 myfaustfile-mdoc/pdf/myfaustfile.pdf。
  • 大功告成！
