非茗的翻译文档库

快速上手

本节的目标是教你在大约两小时内掌握 Faust 编程语言的基本要素。虽然用 Faust 从零写 DSP 算法很容易，但这里我们只演示如何使用 Faust 库中已有的元件、把它们互相连接，并实现基本的用户界面（UI）来控制它们。

Faust 的优势之一在于它的库实现了数百个函数。所以读完本节之后，仅靠使用现成的东西，你就已经能走很远了。

本教程假设读者已经熟悉计算机音乐和编程的基本概念。

更一般地说，本节结束时：

  • 你的 Faust 开发环境应该已经装好并能运行，
  • 你应该掌握了足够的知识来编写基本的 Faust 程序，
  • 你应该能把它们用到不同的平台上。

本教程设计为在 Faust 在线 IDE中完成（参见其文档）。如果你想在本地做，需要在系统上安装 Faust，但这一步完全不是必须的。

发出声音

在 Faust 在线 IDE 中输入以下代码：

import("stdfaust.lib");
process = no.noise;

然后点击左上角的「运行」按钮。如果你看的是本文档的在线版本，也可以点击上方窗口中的「自己试试」按钮。现在你应该能听到白噪声了，当然…… ；）

stdfaust.lib 通过一系列环境，让你从一处即可访问所有 Faust 库。例如这里我们用的是 no 环境，它代表 noise.lib，以及 noise 函数（Faust 的标准白噪声发生器）。Faust 库文档对这个体系有更详细的说明。

任何 Faust 代码中最基本的元素是 process 行，它给出对目标平台音频输入输出的访问。这个体系是完全动态的：由于 no.noise 只有一个输出、没有输入，相应程序就只有一个输出。

我们只需把 no.noise 的输出乘以一个 0 到 1 之间的数，就能静态地改变它的增益：

process = no.noise*0.5;

可见，标准的数学运算在 Faust 中就像在其他任何语言中一样可用。

接下来我们用 Faust 的顺序组合算子 :，把噪声发生器接到一个谐振低通滤波器（fi.resonlp）上：

import("stdfaust.lib");
ctFreq = 500;
q = 5;
gain = 1;
process = no.noise : fi.resonlp(ctFreq,q,gain);

fi.resonlp 有四个参数（按顺序）：截止频率、q、增益以及它的输入。注意，在在线 IDE 中把鼠标悬停在函数上即可快速查看它的参数。这里我们用固定变量设定前三个参数。变量在 Faust 中没有类型，一切都视为信号。Faust 编译器负责做恰当的优化，决定哪些变量以音频速率运行、它们是什么类型。因此 ctFreq、q 和 gain 也可以由振荡器（即以音频速率运行的信号）来控制。

由于这里没有把滤波器的输入作为参数指定（当然也可以指定），它会自动成为 fi.resonlp 的「隐式」输入/参数。: 顺序组合算子可用于连接两个输出数与输入数相同的元件。由于 no.noise 有一个输出，而 fi.resonlp(ctFreq,q,gain) 有一个隐式输入，我们可以把它们连起来。这实质上等同于写成这样：

import("stdfaust.lib");
ctFreq = 500;
q = 5;
gain = 1;
process = fi.resonlp(ctFreq,q,gain,no.noise);

这样写虽然能用，但有点丑，也不够「Faust 味」，所以我们不这么干…… ；）

到这里，你应该已经能把 Faust 库中的各种元件拿来使用并相互插接了。Faust 库实现了数百个函数，其中一些用途非常专门。好在 Faust 库文档中有一节 Standard Faust Libraries，按类型列出了所有高层的「标准」Faust 函数。我们建议你现在就去看看。看的时候要知道，Faust 中的隐式信号可以用 _ 字符显式表示。所以当你在库文档中看到这样的东西：

_ : aFunction(a,b) : _

它的意思是这个函数有一个隐式输入、一个隐式输出和两个参数（a 和 b）。而另一方面：

anotherFunction(a,b,c) : _,_

是一个有三个参数、没有隐式输入、有两个输出的函数。

就当「玩玩」，试着改写前面在 Faust 在线编辑器中运行的例子，让 process 行写成这样：

import("stdfaust.lib");
ctFreq = 500;
q = 5;
gain = 1;
process = no.noise : _ : fi.resonlp(ctFreq,q,gain) : _;

当然，这不应影响结果。

你大概已经注意到，我们用 , 这个 Faust 组合算子把两个信号并行表达。用它很容易就能把滤波噪声的例子变成立体声对象：

import("stdfaust.lib");
ctFreq = 500;
q = 5;
gain = 1;
process = no.noise : _ <: fi.resonlp(ctFreq,q,gain),fi.resonlp(ctFreq,q,gain);

或者甚至可以写得更干净些：

import("stdfaust.lib");
ctFreq = 500;
q = 5;
gain = 1;
filter = fi.resonlp(ctFreq,q,gain);
process = no.noise <: filter,filter;

注意，这个例子让我们能为每个声道使用各自独立的两个滤波器。由于两个滤波器目前的参数相同，另一种写法可以是：process = no.noise : filter <: _,_;。
你可以把第一种形式理解为同一个噪声信号被拆分后在左右声道分别滤波，第二种形式理解为噪声先被滤波再拆分到左右声道。但编译器明白，两种情况下左右声道产生的都是同一个滤波后的噪声。所以滤波后的噪声信号只需计算一次，就能用在左右声道上。对这两个程序，编译器实际生成的优化代码完全相同！这是其语义驱动编译模型的一个极其强大的特性。

由于这里把 filter,filter 视为一个完整表达式，我们不能用 : 算子把 no.noise 接到并联的两个滤波器上，因为 filter,filter 有两个输入（_,_ : filter,filter : _,_），而 no.noise 只有一个输出。

这里用到的 <: 拆分组合算子接收 n 个信号并把它们拆成 m 个信号。唯一的规则是 m 必须是 n 的整数倍。

合并组合算子 :> 的用法完全一样：

import("stdfaust.lib");
process = no.noise <: filter,filter :> _;

这里我们把 no.noise 的信号拆成两个信号，接到并联的两个滤波器上，最后把滤波器的输出合并成一个信号。注意，上一个表达式也可以这样写：

import("stdfaust.lib");
process = no.noise <: filter+filter;

要记住，拆分信号并不意味着它的能量会分摊到每份副本上。例如在下面这个表达式中：

process = 1 <: _,_;

两个 _ 都包含 1……

好，现在该给我们的 Faust 程序加上基本用户界面，让它可以交互了。

构建简单的用户界面

本节我们给上一节写的代码加一个简单的用户界面：

import("stdfaust.lib");
ctFreq = 500;
q = 5;
gain = 1;
process = no.noise : fi.resonlp(ctFreq,q,gain);

Faust 允许我们声明基本的用户界面（UI）元件来控制 Faust 对象的参数。由于 Faust 可用来制作从独立应用到音频插件再到 API 端点等各种东西，UI 声明的作用随目标平台略有不同。例如在 Faust 在线编辑器中，UI 是一个带有各种控件的窗口（滑块、按钮等）。而如果你用 Faust 借 faust2api 生成音频引擎，那么 Faust 代码中声明的 UI 元件就是对「外部世界」可见、可通过 API 控制的参数。

标准 Faust UI 元件的完整列表见相应章节。请注意，并非每个 Faust 目标平台都支持全部元件。例如使用 Faust Playground 时就无法声明垂直滑块，等等。

在当前这个例子里，我们想用水平滑块控制上一个程序的 ctFreq、q 和 gain 参数。为此可以这样写：

import("stdfaust.lib");
ctFreq = hslider("cutoffFrequency",500,50,10000,0.01);
q = hslider("q",5,1,30,0.1);
gain = hslider("gain",1,0,1,0.01);
process = no.noise : fi.resonlp(ctFreq,q,gain);

hslider 的第一个参数是参数名，它将显示在界面中或被 API 使用（可以与关联该 UI 元件的变量名不同），接下来是默认值，然后是最小值和最大值，最后是步长。概括起来：hslider("paramName",default,min,max,step)。

现在我们加一个「gate」button 来启动和停止声音（其中 gate 只是按钮的名字）：

import("stdfaust.lib");
ctFreq = hslider("[0]cutoffFrequency",500,50,10000,0.01);
q = hslider("[1]q",5,1,30,0.1);
gain = hslider("[2]gain",1,0,1,0.01);
t = button("[3]gate");
process = no.noise : fi.resonlp(ctFreq,q,gain)*t;

注意，我们通过在参数名字段中用方括号编号，实现了界面中参数的排序。

Faust 的 UI 元件以控制速率运行。因此你可能注意到，快速拖动滑块时会产生咔嗒声。只要用 si.smoo 函数对滑块输出做「平滑」，就能轻松解决这个问题：

import("stdfaust.lib");
ctFreq = hslider("[0]cutoffFrequency",500,50,10000,0.01) : si.smoo;
q = hslider("[1]q",5,1,30,0.1) : si.smoo;
gain = hslider("[2]gain",1,0,1,0.01) : si.smoo;
t = button("[3]gate") : si.smoo;
process = no.noise : fi.resonlp(ctFreq,q,gain)*t;

注意，我们也对 gate 按钮的输出用了 si.smoo，以对其信号施加指数包络。

以上是对在 Faust 中制作界面元件的一次很宽泛的介绍。你还能做更多事，比如创建分组、使用旋钮、各种菜单等，但至少到这一步你应该已经能写出可控、好听（或者不好听 ；））的 Faust 程序了。

最后的润色

有些 Faust 函数已内置 UI，拿来即用。这些函数都放在 demo.lib 中，可通过 dm. 环境访问。

举例来说，我们调用 dm.zita_light（基于反馈延迟网络的高质量混响）给前面的代码加上混响。由于这个函数有两个隐式输入，我们还需要拆分滤波器的输出（否则会报错，因为 Faust 不知道该怎么连接）：

import("stdfaust.lib");
ctFreq = hslider("[0]cutoffFrequency",500,50,10000,0.01) : si.smoo;
q = hslider("[1]q",5,1,30,0.1) : si.smoo;
gain = hslider("[2]gain",1,0,1,0.01) : si.smoo;
t = button("[3]gate") : si.smoo;
process = no.noise : fi.resonlp(ctFreq,q,gain)*t <: dm.zita_light;

顺利的话，你应该会在界面中看到多得多的 UI 元件。

就这些了！到这一步，你应该已经会使用Faust 标准函数、把它们连接起来，并在其之上构建简单的 UI。

一些项目点子

本节给出几个你可以试着用Faust 标准函数实现的项目点子。也欢迎看看 Faust 仓库的 /examples 目录。

加法合成器

用 os.osc（正弦波振荡器）做一个加法合成器：

import("stdfaust.lib");
// 频率与增益的定义写在这里
process = 
    os.osc(freq0)*gain0,
    os.osc(freq2)*gain2 
    :> _ // 在这里合并信号
    <: dm.zita_light; // 然后在这里把它们拆成立体声

FM 合成器

用 os.osc（正弦波振荡器）做一个频率调制（FM）合成器：

import("stdfaust.lib");
// 载波频率、调制器频率与调制指数的定义写在这里
process = 
    os.osc(carrierFreq+os.osc(modulatorFreq)*index)
    <: dm.zita_light; // 在这里把信号拆成立体声

吉他效果器链

做一条吉他效果器链：

import("stdfaust.lib");
process = 
    dm.cubicnl_demo : // 失真
    dm.wah4_demo <: // 哇音踏板
    dm.phaser2_demo : // 立体声移相器
    dm.compressor_demo : // 立体声压缩器
    dm.zita_light; // 立体声混响

由于这里只用了 demo.lib 中的函数，而我们调用的函数已内置 UI，所以无需定义任何 UI。注意 dm.wah4_demo 的单声道输出被拆分，以适配 dm.phaser2_demo 的立体声输入。最后三个效果器的输入数与输出数相同（2x2），因此无需拆分或合并。

基于梳状滤波器的弦物理模型

基于反馈梳状滤波器做一个弦物理模型：

import("stdfaust.lib");

// freq、res 与 gate 的定义
freq = hslider("frequency[unit:Hz]", 440, 20, 2000, 1);
res  = hslider("resonance", 0.99, 0, 0.999, 0.001);
gate = button("trigger");

// 弦模型
string(frequency,resonance,trigger) = trigger : ba.impulsify : fi.fb_fcomb(1024,del,1,resonance)
with {
    del = ma.SR/frequency;
};

process = string(freq,res,gate);

采样率在 maths.lib 中定义为 SR。这里我们用它计算梳状滤波器延迟的长度。with{} 是 Faust 的一个基元，用于把局部变量附着到函数上。所以在当前例子中，del 是 string 的局部变量。
