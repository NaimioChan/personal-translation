Faust 生态概览

Faust 以其最基本的形式作为命令行编译器发行，但过去几年围绕它开发了种类繁多的工具。它们的多样性和各自的用途初看可能不易把握。本章概述它们各自扮演的角色，希望能帮你判断哪一种更适合自己的使用场景。

Faust 发行版

Faust 发行版包含 Faust 编译器（命令行版与库版）的源代码、Faust 架构（目标平台）的源代码、各种 Faust 编译脚本、大量 Faust 相关工具、Faust DSP 库（实际上托管在独立的 Git 子模块中）等等。

Faust 发行版的最新稳定版本可在此处找到。对于想从零开始编译 Faust 编译器与 libfaust 的大多数用户，推荐使用该版本。

若要获取最新的稳定开发版本，可以使用托管在 GitHub 上的 Faust git 仓库的 master branch。若想要更前沿的版本（风险自负），可以使用 Faust git 仓库的 master-dev 分支。master-dev 是 master 的开发子分支，Faust 开发者在其上提交改动，可以视为「主开发分支」。这样做的目的是确保 master 始终可用。master-dev 与 master 之间的合并由 GRAME 团队在每次稳定版发布时完成。

另外请注意，Faust 编译器与 libfaust 针对各平台的预编译包可以在 Faust 网站上找到。

Faust 发行版的目录组织如下：

bin/           : contains the compiler and the Faust tools
include/       : contains header files required by the Faust tools
lib/           : contains the Faust libraries
share/         : contains documentation, the Faust libraries and architecture files

注意：你可以把 Faust 发行版安装到任意位置，只要 faust 命令能从 PATH 中找到（若安装位置不在标准路径下，需要更新 .profile）。

下面几小节介绍构建在 Faust 编译器之上、旨在让你省事的主要工具。

Faust IDE

Faust IDE 是一个零配置工具，提供全部编译服务，包括为所有受支持的平台与架构生成二进制文件，还提供各种用于信号处理开发的实用功能。

Faust Editor

Faust Editor 是一个零配置工具，提供全部编译服务，包括为所有受支持的平台与架构生成二进制文件。

Faust Playground

Faust Playground 是一个图形化环境，可以用更高层的方式开发 Faust 程序。它最初是为儿童和教学目的设计的。

Faustgen

Faustgen 是一个 Max/MSP 外部对象，功能与 FaustLive 类似。它是在 Max/MSP 中快速做原型设计的理想工具。Faustgen 属于 Faust 项目，随 Faust 发布版本分发。

FaustLive

FaustLive 是 Faust 语言的高级自包含原型环境，编辑—编译—运行周期极短。得益于完全内嵌的编译链，FaustLive 安装简单，运行时不需要任何外部编译器、开发工具链或 SDK。

FaustLive 是快速做原型设计的理想工具。Faust 程序只需拖放即可即时编译并运行。程序甚至可以在运行中编辑并重新编译，声音不中断。它还支持借助 Faust 在线编译器生成原生应用程序。注意 FaustLive 仍会定期重新编译，但已不再继续开发，因此推荐使用 Faust IDE。
