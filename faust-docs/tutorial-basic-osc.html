从零构建正弦振荡器与加法合成

目标

  • 在 Faust 中从零实现正弦振荡器
  • 理解正弦函数与所生成声音之间的关系
  • 用多个正弦振荡器实现加法合成器
  • 用 SmartKeyboard 制作可控制该合成器的复音移动应用

Faust 中的正弦函数

  • Faust 中的正弦函数与计算器上的用法相同：
process = sin(0);

会输出 0。

要验证这一点，可以点击 Faust 网页版 IDE 中的卡车图标（导出功能），然后选择 misc/csv，得到一张包含程序输出的前 n 个样本的表。

import("stdfaust.lib");
process = sin(ma.PI/2);

会输出 1。

注意，这里导入 stdfaust.lib 是为了使用 ma.pi。

import("stdfaust.lib");
process = sin(2*ma.PI);

会输出 0。

实现相位累加器

  • 要生成完整的正弦波需要什么？
    • -> 我们需要创建一串从 0 到 2pi 的数（向量），换句话说，画一条线。
  • 先在 Faust 里创建一个「计数器」：
process = +(1) ~ _;

别忘了，你随时可以用 Faust 网页版 IDE 中的 misc/csv 选项打印 Faust 程序的输出。

  • 当前的计数器每次加一。而我们希望它增长得更慢，每次加 0.01。
process = +(0.01) ~ _;

  • 现在，我们希望计数器到达 1 时重置回 0。用 ma.frac 函数可以轻松做到：
import("stdfaust.lib");
process = +(0.01) ~ ma.frac;

注意这里在循环中使用了 ma.frac，以避免数值误差。

  • 试着运行程序（编辑器里的播放按钮），它应该会发声！我们生成的是什么？
    • -> 一个锯齿波。
  • 怎样改变锯齿波的音高？
    • -> 让计数器增长得更快或更慢。试试不同的值（例如 0.001、0.1 等）。
  • 我们不想直接控制计数器的增量，而是想控制锯齿波的频率。
  • 为此，需要知道计算机在一秒内处理多少个波形值。这就是所谓的采样率。这个值取决于程序所在的运行环境，因此可以用 ma.SR 获取。
  • 采样率 44100 对应频率 44100 Hz。如果想要 440 的频率，计数器里应该放多大的增量？
    • -> freq/ma.SR
  • 最终得到：
import("stdfaust.lib");
freq = 440;
process = (+(freq/ma.SR) ~ ma.frac);

  • 此时不妨用在线编辑器导出功能里的 misc/csv 画出 Faust 程序的输出。
  • freq 参数可以动态控制：
import("stdfaust.lib");
freq = hslider("freq",440,50,2000,0.01);
process = (+(freq/ma.SR) ~ ma.frac);

  • 把相位累加器放进函数里，代码会更整洁：
import("stdfaust.lib");
f = hslider("freq",440,50,2000,0.01);
phasor(freq) = (+(freq/ma.SR) ~ ma.frac);
process = phasor(f);

生成正弦波

  • 快完成了！现在我们要让相位累加器从 0 走到 2pi，好把它接到 sin 函数上：
import("stdfaust.lib");
f = hslider("freq",440,50,2000,0.01);
phasor(freq) = (+(freq/ma.SR) ~ ma.frac);
osc(freq) = sin(phasor(freq)*2*ma.PI);
process = osc(f);

注意我们创建了 osc 函数，让代码更整洁。

加法合成

  • 正弦波产生的是所谓的纯音。把多个正弦波叠加起来产生谐波，就能得到更复杂的声音。每个谐波的频率与增益决定声音的音色。用这种技术可以「雕刻」声音。
  • 用加法合成可以实现一个简单的管风琴合成器：
import("stdfaust.lib");
f = hslider("freq",440,50,2000,0.01);
phasor(freq) = (+(freq/ma.SR) ~ ma.frac);
osc(freq) = sin(phasor(freq)*2*ma.PI);
organ(freq) = (osc(freq) + osc(freq*2) + osc(freq*3))/3;
process = organ(f);

  • 这就是所谓的谐波列。

制作合成器

  • 要用键盘演奏这个合成器，我们需要能够开关声音，并控制它的音量：
import("stdfaust.lib");
f = hslider("freq",440,50,2000,0.01);
g = hslider("gain",1,0,1,0.01);
t = button("gate");
phasor(freq) = (+(freq/ma.SR) ~ ma.frac);
osc(freq) = sin(phasor(freq)*2*ma.PI);
organ(freq) = (osc(freq) + osc(freq*2) + osc(freq*3))/3;
process = organ(f)*g*t;

  • 可以加入包络，让它听起来更自然：
import("stdfaust.lib");
f = hslider("freq",440,50,2000,0.01);
g = hslider("gain",1,0,1,0.01);
t = si.smoo(button("gate"));
phasor(freq) = (+(freq/ma.SR) ~ ma.frac);
osc(freq) = sin(phasor(freq)*2*ma.PI);
organ(freq) = (osc(freq) + osc(freq*2) + osc(freq*3))/3;
process = organ(f)*g*t;

  • 这个合成器可以用 MIDI 键盘控制。

做成 Android 应用

  • 用 Faust 编辑器的导出功能，选择 android/smartkeyb，把应用装到手机上，然后尽情玩吧！
  • 也可以把它做成一个持续发声、由加速度计控制的应用：
import("stdfaust.lib");
f = hslider("freq[acc: 0 0 -10 0 10]",1000,50,2000,0.01) : si.smoo;
phasor(freq) = (+(freq/ma.SR) ~ ma.frac);
osc(freq) = sin(phasor(freq)*2*ma.PI);
organ(freq) = (osc(freq) + osc(freq*2) + osc(freq*3))/3;
process = organ(f);
  • 这种情况下，用 android/android 导出。
