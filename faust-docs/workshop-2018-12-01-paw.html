构建一个简单的 MIDI 合成器

我们将从零构建一个 MIDI 合成器（不使用 Faust 库）。

相位发生器

第一步是构建一个相位发生器，产生 0 到 1 之间的周期锯齿波信号。下面是我们要生成的信号：

斜坡

为了产生上面的信号，我们必须先生成一个斜坡信号

使用以下 Faust 程序：

process = 0.125 : + ~ _;

你可以把 Faust 程序看作对一个音频电路的描述，其中 0.125、+ 和 _ 是语言的基元（预定义的基本音频组件），另外两个符号：: 和 ~ 用于把这些音频组件连接起来。

语义

为了理解上面的图，我们用它的数学语义来标注它。

从图中可以看出，输出信号的公式是：y(t) = y(t-1) + 0.125

可以计算 y(t) 的前几个值：

  • y(t&lt;0)=0
  • y(0) = y(-1) + 0.125 = 0.125
  • y(1) = y(0) + 0.125 = 2*0.125 = 0.250
  • y(2) = y(1) + 0.125 = 3*0.125 = 0.375
  • ...
  • y(6) = y(5) + 0.125 = 7*0.125 = 0.875
  • y(7) = y(6) + 0.125 = 8*0.125 = 1.000
  • y(8) = y(7) + 0.125 = 9*0.125 = 1.125
  • ...

相位信号

如何把上面的斜坡变成锯齿波信号？去掉样本的整数部分，只保留小数（分数）部分（3.14159 -> 0.14159）。

定义一个函数来做这件事：

decimalpart(x) = x - int(x);

现在可以用这个函数把斜坡变成锯齿波。于是很自然会写：

process = 0.125 : + ~ _ : decimalpart;

从数学角度看这完全正确，但会累积舍入误差。为了保持完整精度，最好把小数部分运算放在循环内部：

process = 0.125 : (+ : decimalpart) ~ _;

现在可以听一下产生的信号。只需把 decimalpart 和 process 的定义复制粘贴到 Faust 网页版 IDE 中。

控制相位信号的频率

先重排一下代码：

decimalpart(x) = x-int(x);
phase = 0.125 : (+ : decimalpart) ~ _;
process = phase;

在我们的 phase 定义中，步长值（这里是 0.125）控制生成信号的频率。我们希望根据目标频率计算这个步长值。为了完成转换，需要知道采样率。它可以从标准库中以 ma.SR 获得。

假设希望相位信号的频率为 1 Hz，那么步长应该非常小，为 1/ma.SR，这样相位信号达到 1 需要 ma.SR 个样本（即 1 秒）。

如果希望频率为 440 Hz，就需要大 440 倍的步长，让相位信号达到 1 快四百四十倍。

phase = 440/ma.SR : (+ : decimalpart) ~ _;

把 440 换成参数 f，这个定义就可以推广：

phase(f) = f/ma.SR : (+ : decimalpart) ~ _;

并在使用 phase 时指明目标频率：

process = phase(440);

创建正弦波振荡器

下一步是把上面的相位发生器变成正弦波发生器。我们将使用 sin 基元，它计算 x 的正弦（以弧度为单位）。因此我们从相位信号出发，把它乘以 2*ma.PI 得到弧度，再计算正弦。完整程序如下：

import("stdfaust.lib");
decimalpart(x) = x-int(x);
phase(f) = f/ma.SR : (+ : decimalpart) ~ _;
osc(f) = phase(f) * 2 * ma.PI : sin;
process = osc(440);

控制振荡器的频率与增益

下一步是为振荡器的频率和增益添加控制。可以把固定频率 440 换成一个界面滑块：

process = osc(hslider("freq", 440, 20, 10000, 1));

并添加一个增益来控制振荡器的输出电平：

process = osc(hslider("freq", 440, 20, 10000, 1)) * hslider("gain", 0.5, 0, 1, 0.01);

添加门按钮

为了准备我们的 MIDI 合成器，需要加一个门按钮，这样只有按下它时才产生声音：

process = osc(hslider("freq", 440, 20, 10000, 1)) * hslider("gain", 0.5, 0, 1, 0.01) * button("gate");

添加包络发生器

最好再加一个包络发生器。这里我们使用 Faust 标准库中预定义的 ADSR。

declare options "[midi:on][nvoices:4]";
import("stdfaust.lib");
decimalpart(x) = x-int(x);
phase(f) = f/ma.SR : (+ : decimalpart) ~ _;
osc(f) = phase(f) * 2 * ma.PI : sin;
process = osc(hslider("freq", 440, 20, 10000, 1)) 
        * hslider("gain", 0.5, 0, 1, 0.01) 
        * (button("gate") : en.adsr(0.1,0.1,0.98,0.1));

改善音色

与其只演奏纯正弦音，不如用简单的加法合成来改善音色：

declare options "[midi:on][nvoices:4]";
import("stdfaust.lib");
decimalpart(x) = x-int(x);
phase(f) = f/ma.SR : (+ : decimalpart) ~ _;
osc(f) = phase(f) * 2 * ma.PI : sin;
timbre(f) = osc(f)*0.5 + osc(f*2)*0.25 + osc(f*3)*0.125;
process = timbre(hslider("freq", 440, 20, 10000, 1)) 
        * hslider("gain", 0.5, 0, 1, 0.01) 
        * (button("gate") : en.adsr(0.1,0.1,0.98,0.1));

作为复音 MIDI 合成器运行

要用 MIDI 控制合成器，需要使用 Chrome。复音 MIDI 模式通过编辑器左侧的下拉菜单 Poly Voices 激活。选择 Computer Keyboard 作为 MIDI 输入，就可以用电脑键盘演奏音符，或者插入 MIDI 键盘。

添加全局效果

为 effect 提供一个定义，就可以添加全局效果。

// 通用效果
effect = dm.zita_light;

declare options "[midi:on][nvoices:4]";
import("stdfaust.lib");
decimalpart(x) = x-int(x);
phase(f) = f/ma.SR : (+ : decimalpart) ~ _;
timbre(f) = phase(f)*0.5 + phase(f*2)*0.25 + phase(f*3)*0.125;

process = timbre(hslider("freq", 440, 20, 10000, 1)) 
* hslider("gain", 0.5, 0, 1, 0.01) 
* (button("gate") : en.adsr(0.1,0.1,0.98,0.1));

effect = dm.zita_light;
