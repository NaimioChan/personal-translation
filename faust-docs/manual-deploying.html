在 Web 上部署 Faust DSP

借助为 Web 所做的工作（WebAssembly 后端以及用 Emscripten 编译成 WebAssembly 的 libfaust 库），可以轻松生成 Faust 的 WebAudio 节点并部署到 Web 上，既可以是静态的，也可以是动态的。

faustwasm 包

FaustWasm 库提供了一套便捷的高层 API，对 Faust 编译器做了封装。该库的接口主要为 TypeScript 使用而设计，同时也为纯 JavaScript 提供 API 描述和文档。Faust 编译器的 WebAssembly 版本使用 Emscripten 3.1.31 编译，兼容 Node.js 与浏览器。

该库提供把 Faust DSP 代码编译成 WebAssembly 的功能，使其能够在标准 WebAudio 节点图中作为 WebAudio 节点使用。此外，它还支持离线渲染场景。还可以使用附加工具从 Faust DSP 程序生成 SVG。

导出到 Web

可通过远程编译服务从 Faust Editor 或 Faust IDE 导出 Web 目标。选择 Platform = web，然后在 Architecture 中选择下列目标之一：

  • wasmjs 可导出可直接使用的 Web 音频节点，供集成到应用中。附带的 HTML 与 JavaScript 示例文件演示了如何加载并激活该节点。

  • wasmjs-poly 可导出可直接使用、支持 MIDI 控制的复音 Web 音频节点，供集成到应用中。附带的 HTML 与 JavaScript 示例文件演示了如何加载并激活该节点。

  • webaudiowasm 可导出带预制图形界面的可直接使用的 Web 音频节点，并可作为渐进式 Web 应用安装。附带的 HTML 与 JavaScript 示例文件演示了如何加载并激活该节点。

  • webaudiowasm-poly 可导出带预制图形界面、可直接使用且支持 MIDI 控制的复音 Web 音频节点，并可作为渐进式 Web 应用安装。附带的 HTML 与 JavaScript 示例文件演示了如何加载并激活该节点。

  • pwa 可导出带预制图形界面的可直接使用的渐进式 Web 应用，可直接在页面中使用，也可通过二维码安装到智能手机或平板电脑上运行。

  • pwa-poly 可导出带预制图形界面、可直接使用且支持 MIDI 控制的复音渐进式 Web 应用，可直接在页面中使用，也可通过二维码安装到智能手机或平板电脑上运行。

faust-web-component 包

faust-web-component 包提供两个 Web 组件，用于在网页中嵌入可交互的 Faust 片段：

  • <faust-editor> 显示一个编辑器（使用 CodeMirror 6），其中是可执行、可编辑的 Faust 代码，旁边的面板里还有一些附加功能（控件、框图、绘图）。这个组件非常适合在页面中演示 Faust 代码，让读者不必离开页面就能自己尝试和调整，可在此测试。

  • <faust-widget> 只显示控件，不允许编辑，因此仅作为嵌入交互式 DSP 的手段，可在此测试。

这些组件构建在 faustwasm 与 faust-ui 包之上，并以 npm 包形式发布。

导出 WAM 2.0 插件

WAM 2.0 插件可通过远程编译服务从 Faust Editor 或 Faust IDE 导出，使用的是 faust2wam 项目构建。完整教程见此。选择 Platform = web，然后在 Architecture 中选择下列目标之一：

  • wam2-ts 可导出可直接使用的 WAM 2.0 插件。

  • wam2-poly-ts 可导出可直接使用、支持 MIDI 控制的复音 WAM 2.0 插件。

  • wam2-fft-ts 可导出可直接使用的 WAM 2.0 插件，使用的是这篇论文中介绍的 FFT 架构。
