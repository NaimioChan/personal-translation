Generate WAMs with FaustIDE

Web Audio Modules（WAM）是 Web Audio 插件与 DAW 的标准。Web Audio Modules 2.0 版于 2021 年由一大群人协作发布，此后已有多个插件和宿主发布，大多为开源和自由软件。

FAUST IDE 是从现有 FAUST 代码生成 WAM 的极流行工具（还有数百个音频效果器、乐器等的源代码示例可用）。你也可以用 faust2wam 脚本从命令行直接生成 WAM。

Creating VSTs and more using FAUST

FAUST 是一门能让我们快速编写跨平台 DSP 代码的编程语言。我们可以轻松制作 VST 插件、Max 外部对象等。它高质量的内置效果器与工具库让我们能快速做出高质量的音频处理设备。本工作坊旨在让新用户入门，说明 FAUST 适合做什么，以及如何有效使用它来快速获得高质量结果。

代码生成器与工具

faust2pdex

Pure Data 的 Faust 封装器生成器。该软件把 Faust 生成的 C++ 代码包装成 Pure Data 的原生外部对象。你得到一份源代码，可以借助 make 配合 pd-lib-builder 生成原生二进制文件。无需任何 C++ 编程知识。

Faust.quark

这个 SuperCollider 包让你可以创建包含 Faust 代码所写插件的 SuperCollider 包（Quark）。这样你就能分发用 Faust 编写的插件，让别人轻松安装、编译或卸载。它还包含一些简单接口，用于背后调用的 faust 和 faust2sc.py 命令。

ode2dsp

ode2dsp 是一个 Python 库，用于在数字信号处理（DSP）语言中生成常微分方程（ODE）求解器。它把为 ODE 建立 DSP 模型时繁琐且易错的符号计算自动化。

特性：

  • 支持线性与非线性 ODE 方程组
  • 支持梯形法与后向欧拉离散时间积分近似
  • 用牛顿法求隐式方程的近似解
  • 把有限差分方程（FDE）渲染为 Faust 代码
  • 计算 ODE 与 FDE 在工作点处的稳定性

circle-faust

该仓库演示了在 pi-zero-2 上使用 circle SDK 并通过外加 DAC 输出 pwm 音频。

vscode-faust-runner

在 VS Code 底部面板（终端 / 调试控制台旁边）内编译、播放并分析 Faust DSP，支持硬件与屏幕 MIDI、可切换的测试信号、触发式示波器，以及带前后叠加和频率响应模式的频谱分析仪。
