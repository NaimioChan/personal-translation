开始使用

安装 plugdata

Windows:

  • 从最新的官方发布版获取安装程序

MacOS:

  • 方案一：从最新的官方发布版下载安装程序
  • 方案二：安装 Homebrew cask。注意：这份 cask 可能无人维护，内容也可能已经过期。

Linux:

  • 方案一：OBS 仓库/软件包
    • 仓库里包含 plugdata、plugdata-vst3 和 plugdata-lv2 的软件包。如果直接下载软件包而不使用仓库，其中会包含独立应用版本。
    • 插件版本：
      • Deb/Ubuntu：plugdata-vst3 和 plugdata-lv2
      • 基于 RPM 的发行版：vst3-plugdata 和 lv2-plugdata
  • 方案二：Arch User Repository（仅限 Arch）。
    • plugdata-bin 对应最新的稳定版本。
    • plugdata-git 对应最新的实验性构建。
  • 方案三：从最新的官方发布版下载二进制文件

你也可以在我们的网站上获取近期的实验性构建。

从源码构建

注意：除非你要为 plugdata 的开发做贡献，否则通常不需要从源码编译。

git clone --recursive https://github.com/plugdata-team/plugdata.git
cd plugdata
mkdir build && cd build
cmake ..  # Specify the generator using -G"Unix Makefiles", -G"XCode" or -G"Visual Studio 16 2019" -A x64
cmake --build .
