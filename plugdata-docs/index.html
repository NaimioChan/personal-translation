概述

plugdata 是为 Miller Puckette 的 Pure Data（Pd）打造的插件封装，界面（GUI）用 JUCE 做了增强，由 Timothy Schoen 主持开发。这个项目仍在开发中，可能还有些 bug。默认情况下，plugdata 附带 cyclone 和 ELSE 两个外部对象与抽象对象合集。此外还包含 pd-lua，作为用 Lua 开发自定义 Pd 对象的脚本扩展。它的主要目标是把 patch 的体验做得更友好，并与各类数字音频工作站（DAW）无缝集成。plugdata 也提供独立可执行版本，可作为 Pd 程序的替代。

plugdata 还集成了 hvcc 编译器，可以从 Pd patch 生成优化过的 C++ 代码。这些 C++ 代码可由 plugdata 编译，既可烧录到 Electro-Smith Daisy 平台，也可转成音频插件（基于 DPF 框架）。相关内容见「编译 patch」一章。

关于开发

作为一个持续演进的项目，plugdata 可能仍有 bug。你的反馈对打磨和提升使用体验很重要。可以在我们的 GitHub 页面上报告 bug。

项目目标

  • 把 patch 带进每一个 DAW：

    • 作为插件无缝集成到各类数字音频工作站（DAW）中

  • 提供现代化的使用体验：

    • 专注于做当代的界面，让新用户和有经验的用户都能顺畅使用

  • 跨平台支持：

    • 确保 plugdata 在 Windows、macOS、Linux、树莓派，以及新推出的 iOS 应用等各类操作系统上都有最佳表现

  • 与 vanilla 兼容：

    • 与 pure-data（pd-vanilla）保持可靠兼容，让用户的技能可以在两套环境之间无缝迁移

项目理念

  • 自由与开源：

    • plugdata 将始终保持自由与开源，营造便于协作的开发和使用环境

  • 友善待人：

    • 我们通过抵制和处理各种形式的歧视（例如恐同、跨性别歧视、种族主义）来维护包容的社区，为所有贡献者和用户提供友好的空间
