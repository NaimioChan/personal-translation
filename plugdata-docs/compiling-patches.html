使用 HVCC 编译器编译与集成

概述

plugdata 额外提供了把 patch 编译到多种目标平台的功能。支持的目标包括：

  • C++ Code: 生成 C/C++ 源代码，供其他 DSP 项目使用。
  • Electro-Smith Daisy: 编译代码并烧录到 Daisy 单片机开发板。
  • DPF Audio Plugin: 生成音频插件，供各类插件宿主使用。
  • Pd External: 把 patch 编译成 Pure Data 外部对象，以优化其性能。

警告：导出代码或插件二进制文件的目标路径中不能包含任何空格。

编译模式

在 plugdata 主菜单里有一个标记为 Compiled Mode 的开关。这个模式会检查 patch 是否符合 plugdata 编译工具的要求。它使用 Heavy hvcc 编译器，该编译器只支持 Pure Data Vanilla 对象集中的一部分对象。

Compiled Mode 会找出 patch 中不受支持的对象，向控制台输出一条消息，并且只为兼容的对象提供自动补全。

下载编译工具链后，由 Wasted Audio 维护的 Heavy hvcc 编译器会被安装，同时还会装上其他编译工具。hvcc 只能为 plugdata 包含的一部分对象生成代码，这些对象是 Pure Data Vanilla 对象集的子集。

Compiled Mode 会向控制台输出一条消息并标出问题对象，以此提示 patch 中是否存在无法用于编译后 patch 的对象。启用该模式时，plugdata 的自动补全也只会给出兼容的对象。

在 plugdata 中编译

选择 Compile... 会打开一个窗口，其中是不同模式的编译选项，每个模式都有通用配置和该模式专属的配置。

通用配置

本节中的通用字段包括：

  • Patch to export: 选择想要导出的 patch。
  • Project Name (Optional): 自动填入 patch 的名称。
  • Project Copyright (Optional): 从常见源代码许可证中选择一项填写。

C++ 代码

在 C++ Code 模式下，plugdata patch 会被转译成通用的 C/C++ 代码。请针对具体应用修改这些原始代码。更多内容见官方文档。

Electro-Smith Daisy

Daisy 模式可以让 patch 运行在基于 STM32 单片机的嵌入式硬件设备上。可选项包括选择目标板、导出类型（源代码、二进制、烧录）、启用 USB MIDI，以及配置 patch 大小。

DPF 音频插件

DPF 模式会以多种格式（VST2、VST3、LV2、CLAP、JACK）导出自包含的 patch。可选择导出类型（源代码、二进制）和插件类型（效果器、乐器、自定义）。在给出的列表中选择插件格式。

Pd 外部对象

把 patch 导出为 Pd 外部对象，以获得更好的性能。可选择导出类型（二进制或源代码），并启用复制到外部对象路径。

每种导出选项的更多细节，请参考官方文档。
