ofSketch 是什么？

ofSketch 是一个专为编写和运行 openFrameworks sketch 而打造的精简开发环境。它是一个安装极简的 openFrameworks 应用，让你能把更多时间花在写代码上，而不是花在配置上。

开发 ofSketch 的主要目标之一是降低 openFrameworks 的入门门槛。因此需要说明，ofSketch 主要面向初学者和新手程序员。

ofSketch 适合做什么？

  • 教授或学习 openFrameworks
  • 完成从 Processing 到 openFrameworks 的跨越
  • 快速做代码原型
  • 创建代码片段、实验和示例
  • 在 Raspberry Pi 上运行 openFrameworks

ofSketch 不适合做什么？

  • 替代 Xcode、QtCreator、Visual Studio 等专业 IDE
  • 构建规模较大的项目或应用

ofSketch 是怎么工作的？

ofSketch 的工作原理是让 ofSketch 应用与浏览器编辑器在内部互相通信。应用负责在你电脑上读写文件、编译并启动项目等等；浏览器编辑器则充当图形用户界面（GUI），你在其中写代码、运行和管理项目。与 ofSketch 交互时，你是在浏览器里操作，但不应忽视应用与浏览器之间的这个区分。更多信息可以看 ofSketch GitHub 仓库里的 ARCHITECTURE.md 文件。

ofSketch 入门

ofSketch 里的代码写起来与你可能习惯的 openFrameworks 略有不同。如果你是 openFrameworks 新手，那太好了！我们认为 ofSketch 的代码比常规的 .h 和 .cpp openFrameworks 代码结构更容易学。

ofSketch 风格的代码

ofSketch 使用“头文件风格”的 C++，也就是把实现代码与声明一起写在头文件里，而不是写在与头文件对应的 .cpp 源文件里。如果这让你摸不着头脑，不用担心。本质上，这让我们能写出简单、易读的代码，非常适合初学者！

项目文件

每个 ofSketch 项目都从一个空的、像这样的项目文件开始：

void setup() {
        // 把 setup 代码放在这里，只运行一次：
        
}
	
void draw() {
        // 把主代码放在这里，每帧运行一次：
        
}

如果你来自 Processing，这应该无比熟悉。要添加全局函数和变量，直接把它们加到项目文件里就行。你不需要给任何标识符（变量、函数等）加上 ofApp 前缀。

// 全局变量写在这上面
std::string text; 

void setup() {
        // 把 setup 代码放在这里，只运行一次：
        text = "Hello World!";
        printHelloWorld(); // 函数调用
}

void draw() {
        // 把主代码放在这里，每帧运行一次：
        
}

// 全局函数写在这下面
void printHelloWorld() {
        cout << text << endl;
}

类

在 ofSketch 里使用类很简单！在 ofSketch 浏览器窗口的标签栏里点击“+”按钮即可添加一个新类。点击后会自动为你生成一个类模板。下面是一个“Particle”类的模板示例：

class Particle{

public:

    Particle(){

    }        
};

这本质上就是一个常规的 .h 文件。生成的模板里显式定义了默认构造函数，而添加类成员很容易。只要记住，你在这个文件里写的所有函数都要既声明又实现。下面是一个基础的“Particle”类示例，可以用在粒子系统里。

class Particle{

public:

    ofVec2f location;
    ofVec2f velocity;
    ofVec2f acceleration;
    
    ofColor color;
    
    float maxSpeed;
    
    int radius;
    
    // 默认构造函数
    Particle() {}; 
    // 重载的构造函数
    Particle(float x, float y) {
        
        acceleration = ofVec2f(0,0);
        velocity = ofVec2f(0, -2);
        location = ofVec2f(x,y);
        color = ofColor(ofRandom(255), 0, 255);
        radius = 6.0;
        
        maxSpeed = 4;
    }
    
    void update() {
        
        velocity += acceleration;
        velocity.limit(maxSpeed);
        location += velocity;
        acceleration *= 0;
    }
    
    void draw() {
        
        ofFill();
        ofSetColor(color);
        ofDrawCircle(location.x, location.y, radius);
    }

// 等等……

};

包含

每个 ofSketch 文件默认都会包含 “ofMain.h”。要包含自定义的类，只需在任何需要用到该类的文件顶部写上 #include "ClassName.h"。下面是在项目文件里包含上面的 Particle 类文件的示例。

#include "Particle.h"

Particle p;

void setup() {
     // 把 setup 代码放在这里，只运行一次：
     // 在中心创建一个粒子
     p = Particle(ofGetWidth()/2, ofGetHeight()/2);    
}

void update() {
    p.update();

}

void draw() {
        // 把主代码放在这里，每帧运行一次：
    p.draw(); 
}

这里我们包含了 “Particle.h” 文件，用它实例化了一个 Particle 对象“p”，然后把它放在屏幕中央。

注意我们还加了一个 update 函数。你可能已经知道，在 openFrameworks 里，习惯上把更新逻辑的操作与渲染图形的操作分开。这是出于性能考虑，但并非必须如此；如果你愿意，放在 void update() 里的所有代码都可以改放在 void draw() 里。

Sketch 格式

如果你看看 Projects 文件夹里的某个应用，会看到一个“sketch”目录。所有 ofSketch 源文件都保存在这里，每个文件的扩展名都是“.sketch”。使用 ofSketch 时，你编辑的就是这个目录里的文件。每当你在 ofSketch 里运行应用，系统都会处理“sketch”目录中的所有文件，在“src”目录里生成源文件。

由于这样的工作流程，很重要的一点是：只能通过 ofSketch 来编辑 ofSketch 项目。如果你用 Xcode 编辑了 ofSketch 项目（修改了“src”目录里的文件），再回到 ofSketch 里打开它、按下播放按钮，就会把我们所有的改动全部覆盖掉，很容易给自己惹麻烦。

ofSketch 很快会加入好用的项目导入导出功能，让你可以把项目导入/导出到你所选的专业 IDE 工程中。在那之前，如果你想用 ofSketch 以外的东西编辑项目，最好直接复制一份。

远程写代码

ofSketch 浏览器编辑器的亮点之一，是可以通过网络连接编辑远程机器上的代码。这在用 Raspberry Pi 写代码、或调整现场装置的代码时特别有用。下图展示了实际做法。

  1. Raspberry Pi 上运行着一个 ofSketch 应用，把一片风景画到连接的电视上
  2. 笔记本电脑上的网页浏览器指向 RPi 的 IP 地址和 7890 端口（例如 http://192.168.0.204:7890）

要远程用 ofSketch 写代码，先在你想运行 openFrameworks 应用的机器上启动 ofSketch 应用。为了从这台机器连上 ofSketch，你需要知道它在网络中的唯一 IP 地址。你可以在设备 2 上用 Bonjour Browser 这类应用来发现设备 1 的 IP 地址。

拿到设备 1 的 IP 地址后，在设备 2 上打开网页浏览器，访问 http://CPU_1_IP_ADDRESS:7890。

现在你就可以用设备 2 创建、编辑和运行项目了。

未来

ofSketch 项目还处在幼年期。事实上，写这一章时，最新的 ofSketch 版本是 v0.3.2。随着我们逐步接近稳定版（v1.0），这个应用无疑会发生变化，但我们尤其对计划中的一些东西感到兴奋。下面是未来一年里值得关注的功能清单。

应用导出

应用导出让用户可以导出可执行文件和资源，复制到其它电脑上运行。导出的项目会以压缩包的形式下载，便于传输。

项目文件导出

项目文件导出会在 ofSketch 应用里使用集成版的 openFrameworks Project Generator，为 Xcode、Code::Blocks 和 Visual Studio 2012 导出项目。这些项目文件可以帮助新用户用上专业 IDE 里更高级的编辑功能。

自定义 .h 与 .cpp 文件

为了帮助用户从 ofSketch 过渡到更高级的 IDE，ofSketch 用户将可以选择创建并使用 .h 和 .cpp 文件。最终，使用这项功能会简化到在创建文件时选择相应的扩展名即可。

Clang 索引自动补全

我们打算利用这些 Clang 资源来为 openFrameworks 核心建立索引，从而在编辑器里更好地提供自动补全和语法高亮。理想情况下，这个系统也会自动为用户代码建立索引。
