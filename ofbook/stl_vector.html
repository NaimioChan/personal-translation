vector 入门

作者：Chris Sugrue

C++ 的 vector 是一种容器（类似数组），可以以能动态增长或收缩的方式存放多个元素（数字、字符串、对象等）。创建之后，可以添加新元素、删除其他元素，也可以对整个 vector 排序或打乱。本教程是对使用 vector 的基础概览，面向可能刚开始用 openFrameworks 或来自其他平台与语言的程序员。它并不是 C++ vector 所有函数的完整指南（下面提供了一些额外资源链接）。

额外资源：

C++ vector 参考文档

快速回顾：

vector<float> nums;  // 创建一个空的 float vector     
nums.push_back(10.5); // 把一个值为 10.5 的 float 添加到 vector 末尾
cout << nums[0] << endl; // 打印位置 0 处元素的值
nums.erase( nums.begin() ); // 删除 vector 中的第一个元素
cout << nums.size() << endl; // 打印 vector 中元素的数量

vector<float>:: iterator it = nums.begin(); // 为 vector 创建一个指向第一个元素的迭代器
cout << *it << endl; // 打印迭代器所指向元素的值

声明一个 vector

vector< 类型 > 名称;

vector<float> measures;       
vector<string> surnames;
vector<Particle> particles;

向 vector 添加元素

push_back

push_back 在 vector 末尾添加一个新元素。

vector<string> names; // 声明一个空 vector

names.push_back("jane"); // 添加一个元素
names.push_back("joe"); // 再添加一个——现在大小为 2，元素是：“jane”、“joe”

push_back 是添加元素的常见方式，适合一次添加一个或只添加少量元素的情况（比如某个事件发生时添加一个对象）。

resize

resize 为 vector 中指定数量的元素分配内存，并相应地调整其大小。

vector<int> nums; // 声明 vector

nums.resize(100); // 在 vector 中为 100 个 int 分配空间

for(int i = 0; i < nums.size(); i++){
  nums[i] = i; // 用下标设置值
}

当需要同时添加很多元素时，使用 resize 可能比 push_back 更快。这是因为当新元素被添加到 vector 末尾时，当前位置的内存可能不够。这种情况下，整个 vector 会被移动，也就是它会被复制，并在别的位置分配新内存。这可能很慢，而且在循环中使用 push_back 时可能发生多次。使用 resize 的话，这种移动只需要进行一次。

关于这方面的更多细节，请参考 Arturo Castro 的教程

assign

assign 可用于创建一个给定大小的 vector 并用统一的值填充，或者复制已有 vector 的一部分。它会重新初始化 vector，删除之前的所有元素。

vector<float> vals; // 声明 vector
vals.assign(100,0.0f); // 添加 100 个值全为 0.0 的 float

vector<Particle> particles;
particles.assign(10,Particle());

vector<Particle> copyParticles;
copyParticles.assign( particles.begin(), particles.begin()+5 );

访问 vector 的元素

operator []

可以像 C 数组那样，用带下标的 [] 运算符访问元素。

cout << names[0] << end; // ！如果元素 0 不存在，就会出现内存访问错误

for( int i = 0; i < names.size(); i++){
  cout << names[i] << endl;
}

at()

vector 有一个函数 at()，它像 [] 运算符一样返回值，但比 [] 稍慢。at() 会检查下标是否在范围内，若不在则抛出异常。这使它在调试时很有用，不过为了清晰和速度，通常更推荐 []。

cout << names.at(0) << endl;

删除 vector 的元素

erase

可以用 erase 从 vector 中移除一个元素。这个函数接受的是指向 vector 中某个位置的迭代器，而不是下标。函数 begin() 返回指向 vector 第一个元素的迭代器，可以在它上面做加法以传入后续位置。注意 erase 不会检查元素是否存在，所以删除时要确定！

particles.erase( particles.begin() ); // 删除第一个元素

particles.erase( particles.begin() + 3 ); // 删除第三个元素

particles.erase( particles.begin(), particles.begin()+2 ); // 删除前 2 个元素

clear

clear 移除 vector 中的所有元素，把大小减到 0。

particles.clear();

迭代器

迭代器是一类对象，用来帮助遍历一串元素（比如 vector）。vector 的迭代器指向 vector 中的某个元素，可以自增以指向下一个。由于有些 vector 函数接受或返回迭代器，理解它们如何工作很有用。

为 vector 声明一个迭代器：

vector< 类型 >::iterator it; // it 是迭代器的名字，但你想叫什么都行

vector<float>::iterator it = nums.begin();
vector<Particle>::iterator itp = partices.begin();

begin() 返回指向 vector 第一个元素的迭代器，end() 返回指向 vector 最后一个元素之后一个位置的迭代器。

要用迭代器访问某个元素的值，我们必须像指针那样对它解引用。迭代器指向数组中的元素，而我们要的是它所指向的那个元素的值。

vector<int> nums;
nums.push_back(10);
vector<int>::iterator it = nums.begin();
cout << *it << endl; // 打印出 10

vector<Particle>::iterator itp = particles.begin(); // 取得指向第一个元素的迭代器
float xpos = (*itp).pos.x; // 用解引用 * 访问元素的值或属性
particle.erase(itp); // 把迭代器传给 vector 函数，例如 erase

用迭代器遍历 vector：

 
vector<float>::iterator it = nums.begin();  // 创建一个指向第一个元素的迭代器

// 循环遍历，递增到下一个元素直到到达末尾

for(; it != nums.end(); ++it){ 
  cout << *it << end; // 用解引用运算符输出值
}


for(vector<Particle>::iterator it = particles.begin(); it != particles.end(); ++it){ 
  cout << (*it).pos.x << end; 
}

注意使用迭代器时，我们要判断迭代器（这里就是 it）是否不等于 end()（it != particles.end()），而不是用 > 比较。end() 表示最后一个元素之后的那一个。这一点很重要，因为迭代器不能自增到 end() 之后，否则可能出乱子。

在 while 循环中，结构会是：

vector<Particle>::iterator it = particles.begin();

while( it != particles.end() ){
 cout << (*it).x << end; 
 ++it;
}

用迭代器删除多个元素时，重要的是让迭代器接收被删除元素的返回值，这样它才不会失效。

vector<float>::iterator it = nums.begin(); // 迭代器指向第一个元素

for(; it != num.end();){
	if( *it > 5.2 ) it = nums.erase(it); // 删除时务必接收返回的迭代器，以免它失效
	else ++it;
}

在 vector 中，迭代器和数组风格的 [] 下标在速度上没有区别。

std::remove_if 与 ofRemove

remove_if 检查布尔函数中定义的条件，以判断 vector 的每个元素是否应被删除。它会把返回 true 的元素都移到 vector 末尾，然后返回指向第一个应被删除元素的迭代器。它本身不删除任何东西，但可以和 erase 一起用来真正删除不需要的元素。当需要检查 vector 中所有元素以确定是否应删除时，这很有用（例如某个粒子是否已移出屏幕，或其生命计时器已归零等等）。

第一步是定义一个返回 bool 的函数，它接收一个参数：对 vector 所含类型元素的引用。

bool checkDead( Particle &p ){
	return p.isDead;
}

然后用 erase 接收从 remove_if 返回的迭代器：

vector<Particle>::iterator it = particles.remove_if(particles.begin(),particles.end(),checkDead);
particles.erase( it, particles.end() );

// 或者全部写在一行里
particles.erase( particles.remove_if(particles.begin(),particles.end(),checkDead), particles.end() );

OpenFrameworks 有一个名为 ofRemove 的函数，作用类似。定义那个函数并把它连同 vector 一起传入，就能同时完成 remove_if 和 erase。

ofRemove(particles,checkDead); //particles 是 vector，checkDead 是那个布尔函数

注意不要把这种写法用在存放对象指针的 vector 上（见下文）。

对 vector 排序与打乱

C++ 有许多 < algorithm > 中的函数可以与 vector 和迭代器配合使用（例如 remove_if 就是其中之一）。两个非常有用的函数是 sort 和 random_shuffle。在 openFrameworks 中，它们被实现为 ofSort 和 ofRandomize。

sort 的用法与 remove_if 类似，它可以接收一个 vector 和一个决定元素如何排序的布尔函数。这个布尔函数有两个参数，都是 vector 类型的元素，根据两者的比较返回 true 或 false。

// 用于 float vector 的比较，从低到高排序
bool my_compare( float a, float b){
    return a < b;
}

然后可以把 vector 的范围和布尔函数传给 sort：

    vector<float>vals;
    vals.push_back(3.0);
    vals.push_back(.1);
    vals.push_back(2.3); // vector 现在的内容是：3.0,.1,2.3
    
    std::sort( vals.begin(), vals.end(), my_compare); // 排序之后：.1, 2.3, 3.0

ofSort 用于对象：

    bool my_compare( Particle &a, Particle &b){
        return a.pos.x < b.pos.x;
    }
    
    ...
    vector<Particle> particles;
    particles.assign(10,Particle());
    
    ofSort(particles,my_compare); // 使用 ofSort 时传入的是整个 vector 而不是一个范围

random_shuffle 和 ofRandomize 只是把 vector 的元素打乱成随机顺序。

    std::random_shuffle(vals.begin(),vals.end());  // 传入要打乱的范围
     
    ofRandomize(vals); // 只传入 vector（全部都会被乱序）

对象的 vector

如上面的例子所示，创建对象的 vector 很常见。

    vector<Particle> particles;

在很多情况下这很好用，也是首选做法。不过，如果类里有成员指针和动态分配的内存，却没有正确的拷贝构造函数，有时就会出问题。可以使用存放对象指针的 vector，不过共享指针大概是最好的选择。若要使用多态／基类，也需要共享指针。

更多内容：vector 与拷贝构造函数。

## 对象指针的 vector

使用存放对象指针的 vector 时，语法类似：

    vector<Particle *> particlePointers;

非常重要的一点：当删除 vector 中指向对象的指针时，既要 delete 它，也要 erase 它！！

    // 用下标 delete 并 erase 单个元素
    delete particlePointers[1];
    particlePointers.erase( particlePointers.begin()+1 );

    // 用循环 delete 并 erase
    vector<Particle>::iterator it = particlePointers.begin();
    for(; it != particlePointers.end();){
    	if( (*it)->isDead ){
    		delete *it;
     		it = particlePointers.erase(it);
    	}else
    		++it;
    }

注意这意味着前面演示的 erase 和 remove_if 并不够用。如果确实需要指针，值得考虑改用共享指针。

## OpenFrameworks 示例

ofApp.h

    #pragma once

    #include "ofMain.h"

    // 为简洁起见，把 particle 类写在头文件里

    class Particle{
    public:
    Particle(){
    		pos.set( 0, 0, 0 );
    		vel.set( ofRandom(-5,5), ofRandom(-4,-8), 0);
    	}
	
    	void update(){
    		pos += vel;
    		vel.y += .1;
    	}
	
    	void draw(){
    		ofDrawEllipse(pos.x,pos.y,10,10);
    	}
	
    	ofPoint pos;
    	ofVec3f vel;
	
    };

    class ofApp : public ofBaseApp{
    public:
    	void setup();
    	void update();
        void draw();
	    
        void keyPressed(int key);
    	void keyReleased(int key);
    	void mouseMoved(int x, int y);
    	void mouseDragged(int x, int y, int button);
    	void mousePressed(int x, int y, int button);
    	void mouseReleased(int x, int y, int button);
    	void windowResized(int w, int h);
    	void dragEvent(ofDragInfo dragInfo);
    	void gotMessage(ofMessage msg);
	
    	// 声明 particle 的 vector
    	vector<Particle> particles;
    };

ofApp.cpp

    #include "ofApp.h"
    
    // 编写我们的布尔删除函数
    bool shouldRemove(Particle &p){
    	if(p.pos.y > ofGetHeight() )return true;
    	else return false;
    }
    
    void ofApp::setup(){
    	ofSetFrameRate(60);
    }
    
    void ofApp::update(){
    	for(int i = 0; i < particles.size(); i++){
    		particles[i].update();
    	}
    	
    	ofRemove(particles,shouldRemove);
    }
    
    void ofApp::draw(){
    	
        ofTranslate( ofGetWidth()/2, ofGetHeight()/2);
        for(int i = 0; i < particles.size(); i++){
    		particles[i].draw();
    	}
    }
    
    void ofApp::keyPressed(int key){
    	particles.push_back( Particle() );
    }
