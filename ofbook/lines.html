绘制线条

*by Davide Prati

介绍……

在本教程中，我们会看看如何用 openFrameworks 绘制线条。本教程中的大部分代码来自这个工作坊，它由 Zach Lieberman 主持。线条大概是最原始的抽象绘图形式。它是孩子最早学会画的东西之一，也是我们在平面上作画时仍在使用的最本能的方式之一。但归根到底，它们不过是一堆连在一起的点；openFramework 提供了一个类来轻松绘制连接各点的线条：ofPolyline。我们先来看看怎么用它！

画一条线

在这个例子里，我们只要在屏幕上拖动鼠标就能画出一条线。为此，我们先创建自己的点容器。用 project generator 新建一个应用，然后把下面这行加到你的 App.h 文件里：

ofPolyline line;

现在按下面的方式改写 setup、draw、mouseDragged 和 mousePressed 方法：

void ofApp::setup(){
    ofBackground(0,0,0);
}

void ofApp::draw(){
    line.draw();
}

void ofApp::mouseDragged(int x, int y, int button){
    ofPoint pt;
    pt.set(x,y);
    line.addVertex(pt);
}

void ofApp::mousePressed(int x, int y, int button){
    line.clear();
}

有意思的事情发生在 mouseDragged 方法里。当我们按下鼠标左键并四处拖动时，坐标对应鼠标位置的点会被加入 ofPolyline 类的实例 line。当我们调用 line.draw() 时，ofPolyline 会自动把点连起来，在屏幕上画出一条线。当我们松开鼠标时，line.clear() 会删掉之前插入的所有点，准备画新的一条线。

一点噪声

一旦 ofPolyline 里有了点，我们就可以在绘制之前于 update 方法中编辑它们。让我们沿 x 和 y 轴把点向上或向下移动一个像素。按下面的方式改写 update 方法：

for (auto &vert : line.getVertices()){
    vert.x += ofRandom(-1,1);
    vert.y += ofRandom(-1,1);
}

你应该会看到类似这样的东西：

注意循环里的 &。如果省略它，我们就无法编辑顶点的位置。& 是在告诉 C++，我们使用的是 ofPolyline 中所含顶点的一个引用，而我们需要引用，因为我们要改变 ofPolyline 里的值。当你只是想读取 ofPolyline 中点的值时，不要用 &。当你想编辑它们时，像本例这样，就用它。

线条之网

我们来试个更复杂的。这个例子里我们要用 ofDrawLine 和 ofPoint 来创建线条。用 project generator 新建一个应用，然后按下面的方式编辑 ofApp.h 文件：

#include "ofMain.h"

class Line {
public:
    ofPoint a;
    ofPoint b;
};

class ofApp : public ofBaseApp{

  public:
    // ...
    //保持原样
    // ...
    vector < ofPoint > drawnPoints;
    vector < Line > lines;
};

在这个头文件里我们定义了一个新类 Line。这个类只由 2 个点 a 和 b 组成，这两个点定义了线条的起点和终点。我们还定义了两个新的 vector，drawnPoints 和 lines。在 App.cpp 文件里我们会看到为什么需要它们：

void ofApp::setup(){
    ofBackground(255,255,255);
}

void ofApp::draw(){
    ofEnableAlphaBlending();
    ofSetColor(30,30,30,30);

    for (auto line : lines) {
        ofDrawLine(line.a, line.b);
    }
}

void ofApp::mouseDragged(int x, int y, int button){
    for (auto point : drawnPoints){
        ofPoint mouse;
        mouse.set(x,y);
        float dist = (mouse - point).length();
        if (dist < 30){
            Line lineTemp;
            lineTemp.a = mouse;
            lineTemp.b = point;
            lines.push_back(lineTemp);
        }
    }
    drawnPoints.push_back(ofPoint(x,y));
}

draw() 方法很简单，我们用头文件里创建的 Line 类取得点 a 和 b 的值，然后用 ofDrawLine 把它们连起来。ofDrawLine 就是从一个点画一条线到另一个点。mouseDragged 方法稍微复杂一些。从最简单的部分开始：drawnPoints.push_back(ofPoint(x,y))。每次拖动鼠标，我们都把鼠标位置存进 drawnPoints vector。这个 vector 就像是鼠标在屏幕上所有移动的历史记录。现在看看以 for (auto point : drawnPoints) 开头的循环。在这个循环里，我们取鼠标的当前位置 ofPoint mouse，把它与所有之前的位置作比较。如果当前位置与某个先前位置的距离小于 30 像素，我们就创建一个 Line lineTemp，把鼠标位置与历史 vector drawnPoints 中距离小于 30px 的那个点连起来。之后我们把这条 Line 推入 lines vector，准备好画到屏幕上。试着到处移动鼠标，你应该能画出类似这样的东西。

在 3D 空间里画一条平滑移动的线

现在我们知道怎么用 ofPolyline 了，可以把它和 ofNode 结合起来，画出一条在屏幕上平滑移动的线。ofNode 是一个定义 3D 空间中点的类，可以与其他节点串成链。如果我们做两个节点 A 和 B，并把节点 A 定义为 B 的父节点，那么移动 A 也会移动节点 B。我们来看看 ofNode 和 ofPolyline 如何配合。首先，按下面的方式编辑 App.h 文件：

ofNode baseNode;
ofNode childNode;
ofNode grandChildNode;
ofPolyline line;
ofEasyCam cam;

EasyCam 类用于在 3D 空间中查看场景。四处拖动鼠标就能让相机在场景中移动。你现在不必操心它如何工作，EasyCam 会处理好一切。现在，按下面的方式编辑 App.cpp 文件：

void ofApp::setup(){
    ofEnableDepthTest();
    baseNode.setPosition(0, 0, 0);
    childNode.setParent(baseNode);
    childNode.setPosition(0, 0, 200);
    grandChildNode.setParent(childNode);
    grandChildNode.setPosition(0,50,0);
}

//--------------------------------------------------------------
void ofApp::update(){
    baseNode.pan(1);
    childNode.tilt(3);

    line.addVertex(grandChildNode.getGlobalPosition());
    if (line.size() > 200){
        line.getVertices().erase(
                                 line.getVertices().begin()
                                 );
    }
}

//--------------------------------------------------------------
void ofApp::draw(){
    cam.begin();
    //取消注释这 3 行，就能看清节点是如何移动的
    //baseNode.draw();
    //childNode.draw();
    //grandChildNode.draw();
    line.draw();
    cam.end();
}

我们来过一遍代码。在 setup 方法里我们创建了一条 3 个节点的链，并给它们指定位置。每个节点通过 setParent 成为前一个节点的子节点。在 update 方法里，我们让 baseNode 绕 y 轴旋转 1 度。这也会对另外 2 个节点产生连带影响。我们还让 childNode 绕 x 轴旋转 3 度。这两次旋转足以让链上最后一个节点 grandChildNode 绕这 2 个节点做出优雅的运动。在接下来的几行里，我们从这个运动中捕获点，并把它们放进 ofPolyline。线条里只保留 200 个点，一旦有新点推入就抹掉旧点。试着把这个值调大，看看线条如何变化。
