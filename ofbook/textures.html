在 3D 图元上使用纹理

作者：Davide Prati 和 Hubris

简介

本章我们会从零开始构建行星地球。有一个球体和一张纹理，这比听起来容易得多。我们会用 ofTexture 类，读完本章你就能把任何纹理应用到 3D 图元上。之后你也就准备好进一步探索着色器与纹理的结合了。

基础：给球体添加纹理

要给球体加纹理，我们需要把想应用的图像保存到 bin/data 文件夹。假设我们已经保存了这张图像，想把它贴到一个球体上。为此，你需要搭好一个基本的 3D 场景，包含一个球体和一个纹理对象。你的 app.h 文件应该像这样：

#pragma once

#include "ofMain.h"

class ofApp : public ofBaseApp{

    public:
        void setup();
        void update();
        void draw();

        void keyPressed(int key);
        void keyReleased(int key);
        void mouseMoved(int x, int y );
        void mouseDragged(int x, int y, int button);
        void mousePressed(int x, int y, int button);
        void mouseReleased(int x, int y, int button);
        void mouseEntered(int x, int y);
        void mouseExited(int x, int y);
        void windowResized(int w, int h);
        void dragEvent(ofDragInfo dragInfo);
        void gotMessage(ofMessage msg);

        ofSpherePrimitive sphere;
        ofLight light;
        ofTexture mTex;
        ofEasyCam cam;
};

你的 App.cpp 文件像这样：

#include "ofApp.h"

//--------------------------------------------------------------
void ofApp::setup(){
    ofDisableAlphaBlending();
    ofEnableDepthTest();
    light.enable();
    light.setPosition(ofVec3f(100,100,200));
    light.lookAt(ofVec3f(0,0,0));
}

//--------------------------------------------------------------
void ofApp::update(){

}

//--------------------------------------------------------------
void ofApp::draw(){
    cam.begin();
    sphere.draw();
    cam.end();
}

运行这个 App，你会看到一个没有任何纹理的球体。要加上纹理，ofTexture 对象必须把 earth.jpg 文件加载到内存中。在 setup 方法里加上这几行：

ofDisableArbTex();
ofLoadImage(mTex,"earth.jpg");

调用 ofDisableArbText() 是出于向后兼容的考虑，如果你想了解其中缘由，可以看看 论坛上的这个帖子。

第二步是告诉 openFrameworks，在我们想画球体时应用这张纹理。按下面的方式修改 draw() 方法：

    cam.begin();
    mTex.bind();
    sphere.draw();
    mTex.unbind();
    cam.end();

瞧，地球就做好了。

Mipmap

mipmap 是个聪明的东西，它让我们的球体从远处看很好，凑近看也很好。基本来说，mipmap 是一张包含我们图像多种分辨率的图像，从图像的高分辨率版本一直到低分辨率版本。当我们从远处看行星地球时，会用那张图像的低分辨率版本来渲染球体；当我们靠近看球体时，则改用高分辨率图像。这个方案避免了抗锯齿效应并提高速度。维基百科上关于 Mipmap 的页面很有意思，想了解更多可以看看。

这是否意味着我们得把地球图像缩放到不同分辨率，再根据情况决定渲染哪一张？不，openFrameworks 用一个简单的方法来帮忙，generateMipmap() 会替我们完成所有这些工作。按下面的方式修改 setup 方法：

ofDisableArbTex();
ofLoadImage(mTex,"earth.jpg");
mTex.generateMipmap();

或者，你也可以在加载纹理之前调用 enableMipmap：

ofDisableArbTex();
mtex.enableMipmap();
ofLoadImage(mTex,"earth.jpg");

现在，OpenGL 内部使用这些不同分辨率图像的方式有好几种。在 openFrameworks 中默认是用 GL_LINEAR 对这些图像做线性插值。要改变默认行为，有一个叫 setTextureMinMagFilter() 的方法。

如果我们在 mTex.generateMipmap() 之后加上这一行

ofTexture.setTextureMinMagFilter(GL_LINEAR_MIPMAP_LINEAR, GL_NEAREST)

纹理重复

有时你需要把一个纹理在整个网格上重复。把行星地球的纹理绕球体重复很奇怪，但把树皮的纹理重复到一棵树上就很合理。我们来看看怎么做，以及纹理重复和 mipmap 如何改变网格的外观。为了清楚起见，我会略去加载树的网格和加载纹理的代码，并且我用了一张红底黑球的图像作为纹理，好让瑕疵更明显。

下面代码里出现的新方法是 setTextureWrap()。它接受两个参数，第一个定义纹理是否在 x 方向重复，第二个定义纹理是否在 y 方向重复。

我们来看看这张包含同一棵树、纹理用法不同的图。

示例 A 由下面的代码生成：

// 假设你在 App.h 中已经声明了
// ofTexture bark
ofLoadImage(bark, "bark.png");

没有设置纹理重复，也没有设置 minMag 过滤。

示例 B 的代码是这样的：

ofLoadImage(bark2, "bark.jpg");
bark2.setTextureWrap(GL_REPEAT, GL_REPEAT);
bark2.setTextureMinMagFilter(GL_NEAREST, GL_NEAREST);

如你所见，纹理正确地重复了，也没有被缩放，但树的末端看起来像素化很严重。我们在示例 C 的代码里解决这个问题

ofLoadImage(bark3,"bark.jpg");
bark3.setTextureWrap(GL_REPEAT, GL_REPEAT);
bark3.generateMipmap();
bark3.setTextureMinMagFilter(GL_LINEAR_MIPMAP_LINEAR, GL_NEAREST);

当然，这棵树看起来更像豹子而不是树，试试不同的纹理以获得更真实的效果。
