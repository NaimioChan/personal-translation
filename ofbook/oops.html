Ooops! = 面向对象编程 + 类

作者：Rui Pereira

概述

本教程是对 openFrameworks 中面向对象编程的快速实用介绍，也是一份如何构建并使用你自己的类的操作指南。读完本章，你应该能理解如何创建自己的对象，并让一大堆小球在你屏幕上弹跳！

什么是面向对象编程

面向对象编程（OOP）是一种基于对象及其相互作用的编程范式。一个常见的类比是把“类”看作一块饼干模具，它能做出很多块饼干，也就是“对象”。下面列出 OOP 中常用的一些术语和定义：

  • 类定义一个事物——也就是对象——的特征及其行为；它不仅定义属性和特性，也定义它能做什么。

  • 对象是类的一个实例。

  • 方法是对象的能力。

如何构建你自己的类（简单的类）

类和对象是面向对象编程的基础。因为烹饪和写代码一样有趣，而我们又总爱在厨房里折腾，所以继续用这个经典的比喻：饼干模具是类，它定义交互方式、能力和可供性；饼干是对象。每个类都有两个文件：头文件，也叫声明文件，后缀是 '.h'；以及实现文件，后缀是 '.cpp'。要轻松理解这两个文件各自做什么，可以把头文件（.h）想成一份食谱，列出你饼干的几样主要原料。实现文件（.cpp）则是我们拿这些原料做什么、怎么混合和加工，把它们做成完美的饼干！那我们来看看它是怎么运作的：

首先，创建两个类文件：Ball.h 和 Ball.cpp，把它们放进项目的 src 文件夹。

如果你用 Xcode 作为 IDE（它代表 Integrated Development Environment，集成开发环境），选中 src 文件夹，左键单击（或 CTRL + 单击），在弹出菜单里选择 'New File'，会出现一个新的窗口菜单，选择你开发所用的平台（OS X 或 iOS），然后选 C++ class，最后起个名字（我们用的是 'Ball'）。你会自动在 src 文件夹里看到这两个文件：Ball.h 和 Ball.cpp。

如果你用别的 IDE，操作应该大同小异。

在头文件（.h）里声明一个类。这里文件名应该是 Ball.h。照着下面的代码敲进你自己的 Ball.h 文件，注意我加进去为你指路的那些注释。

#ifndef _BALL // 如果这个类还没有定义，程序就可以定义它
#define _BALL // 借助这个 if 语句，可以防止该类被多次调用，否则会让编译器困惑
#include "ofMain.h" // 必须包含它，才能引用 openFrameworks 框架
class Ball {

    public: // 在这里放置 public 函数或变量的声明

    // 方法，相当于你的类对象所特有的函数
    void setup();    // setup 方法，用它来设置对象的初始状态
    void update();  // update 方法，用于刷新对象的属性
    void draw();    // draw 方法，在这里完成对象的绘制

    // 变量
    float x;        // 位置
    float y;
    float speedY;   // 速度与方向
    float speedX;
    int dim;        // 尺寸
    ofColor color;  // 颜色，使用 ofColor 类型

    Ball();  // 构造函数——用于初始化对象；如果不传入属性，程序就把它们设为默认值
    private: // 在这里放置 private 函数或变量的声明
}; // 别忘了分号！
#endif

我们已经声明了 Ball 类的头文件（原料清单），现在进入烹饪环节，看看这些原料能做出什么！请注意 '#include' 标签。它是告诉编译器（wikipedia）要在实现文件里包含哪些文件的方式。程序编译时，这些 '#include' 标签会被它们所指的原始文件替换。'if 语句'（#ifndef）是一种防止头文件被重复包含的手段，而重复包含很容易发生。这叫做include guard。使用这个模式能让编译器只包含该文件一次，避免重复。现在不用操心这个，我们后面会讲到！

现在我们来为小球对象创建一个类。这个小球会有颜色、速度和方向这些属性：它会穿过屏幕移动，撞到墙上就反弹。其中一些属性我们会用随机值来生成，但会小心为它的运动行为写好正确的逻辑。

下面这样写类 Ball.cpp，也就是实现文件：

#include "Ball.h"
Ball::Ball(){
}

void Ball::setup(){
    x = ofRandom(0, ofGetWidth());      // 给一个随机的位置
    y = ofRandom(0, ofGetHeight());

    speedX = ofRandom(-1, 1);           // 以及随机的速度和方向
    speedY = ofRandom(-1, 1);

    dim = 20;

    color.set(ofRandom(255),ofRandom(255),ofRandom(255)); // 定义数字颜色的一种方式是分别指定它的 3 个分量（红、绿、蓝），取值 0-255；这个例子里我们把每个分量都设为随机值
}

void Ball::update(){
    if(x < 0 ){
        x = 0;
        speedX *= -1;
    } else if(x > ofGetWidth()){
        x = ofGetWidth();
        speedX *= -1;
    }

    if(y < 0 ){
        y = 0;
        speedY *= -1;
    } else if(y > ofGetHeight()){
        y = ofGetHeight();
        speedY *= -1;
    }

    x+=speedX;
    y+=speedY;
}

void Ball::draw(){
    ofSetColor(color);
    ofDrawCircle(x, y, dim);
}

这个程序很简单，我们本来可以把它直接写在 ofApp（.h 和 .cpp）文件里——如果不想在别处复用这段代码，那样也说得通。面向对象编程的优点之一就是复用。想象一下我们要创建成千上万个这样的小球，不用 OOP，代码很容易变得一团糟。通过创建自己的类，之后可以按需从它再造出任意多个对象，需要时调用相应的方法，让代码保持干净高效。举个更实际的例子：为每个用户界面（UI）元素（button、slider 等）各创建一个类，然后既方便把它们部署到程序里，也方便在以后的项目里包含和复用。

从你的类创建一个对象

类已经建好了，现在来造真正的对象！在 ofApp.h（头文件）里我们要声明一个新对象，但首先得在程序里包含（或给出包含的指令）你的 Ball 类。为此需要写：

#include "Ball.h"

写在 ofApp.h 文件的顶部。然后我们终于可以在程序里声明该类的实例了。在 ofApp 类内部、最后的 "};" 之前加上这一行。

Ball myBall;

现在让小球在屏幕上弹起来！打开项目的 ofApp.cpp（实现）文件。对象已经创建好，我们只需初始化它，然后更新它的数值并通过调用它的方法把它画出来。

在 ofApp.cpp 的 setup() 函数里加上下面的代码：

myBall.setup(); // 调用对象的 setup 方法

在 update() 函数里加上：

myBall.update(); // 调用对象的 update 方法

在 draw() 函数里加上：

myBall.draw(); // 调用 draw 方法绘制对象

编译并运行！这时你应该能看到屏幕上一个弹跳的小球了！很好！

从你的类创建多个对象

到这儿你大概在问自己：为了一个弹跳的小球费这么大劲干什么？不用类你也能做到（说不定已经做过）。其实，用类的好处之一就是能创建多个特性相同的独立对象。那现在就动手！回到 ofApp.h 文件，创建几个新对象：

Ball myBall1;
Ball myBall2;
Ball myBall3;

在实现文件（ofApp.cpp）里，在 ofApp 的 setup() 函数中为每个对象调用对应的方法：

myBall1.setup();
myBall2.setup();
myBall3.setup();

在 ofApp 的 update() 函数里：

myBall1.update();
myBall2.update();
myBall3.update();

还有 draw() 函数里：

myBall1.draw();
myBall2.draw();
myBall3.draw();

从你的类创建更多对象

我们刚创建了 3 个对象，但你已经能看出要创建 10 个、100 个甚至上千个会有多繁琐。一个个手写死会是漫长又痛苦的过程，而只要把对象创建和函数调用自动化就能轻松解决。只用几个 for 循环，就能让这个过程更简单干净。我们不再逐个声明对象列表，而是创建一个 Ball 类型的对象数组。这里还要引入另一个新元素：常量。常量的写法是在所有 #include 之后用 #define 常量名 值。这是一种设定程序中永不改变的数值的方式。在 ofApp 类的头文件里，也就是定义小球对象的地方，顺便把用于对象数量的常量也定义好：

#define NBALLS 10

接下来用常量 NBALLS 的值来定义对象数组的大小：

Ball groupOfBalls[NBALLS];

数组是同类型元素带索引的列表。索引用来访问列表中的某个特定元素。索引通常从 0 开始，所以第一个 Ball（对象）在 groupOfBalls[0]。只有少数几种编程语言的数组索引从 1 开始。如果访问无效索引（大于数组大小或为负数），就会报错。数组的更多信息请看“C++ 基础”一章。在实现文件里，我们创建一个对象数组，并通过 'for' 循环调用它们的方法。

在 setup() 函数里删掉：

myBall1.setup();
myBall2.setup();
myBall3.setup();

换成

for(int i=0; i<NBALLS; i++){
    groupOfBalls[i].setup();
}

代替它。

在 update() 函数里删掉

myBall1.update();
myBall2.update();
myBall3.update();

改成

for(int i=0; i<NBALLS; i++){
    groupOfBalls[i].update();
}

在 draw() 函数里把

myBall1.draw();
myBall2.draw();
myBall3.draw();

换成

for(int i=0; i<NBALLS; i++){
    groupOfBalls[i].draw();
}

借助 for 循环，setup()、update() 和 draw() 方法会对 myBall 数组中的每个 Ball 对象各调用一次，不必再手动碰任何一个对象。

从你的类创建更多对象：属性与构造函数

正如所见，每个对象都有一组由变量定义的属性（位置、速度、方向和尺寸）。面向对象编程的另一个优点是，创建出的对象可以为各自的属性取不同的值。为了更好地控制每个对象，我们可以有一个方法，用来定义这些特性并让我们访问它们。因为想在创建对象之后立刻做这件事，我们就放在 setup() 方法里做。我们会修改它，让它接收对象的一些属性，比如位置和尺寸。先在 Ball 的定义文件（*.h）里改：

void setup(float _x, float _y, int _dim);

还需要更新 Ball 的实现文件（*.cpp）以反映这些改动。

void Ball::setup(float _x, float _y, int _dim){
    x = _x;
    y = _y;
    dim = _dim;

    speedX = ofRandom(-1, 1);
    speedY = ofRandom(-1, 1);
}

到此你的 Ball.cpp 文件应该像这样：

#include "Ball.h"

Ball::Ball(){
};

void Ball::setup(float _x, float _y, int _dim){
    x = _x;
    y = _y;
    dim = _dim;

    speedX = ofRandom(-1, 1);
    speedY = ofRandom(-1, 1);

    color.set(ofRandom(255), ofRandom(255), ofRandom(255));
}

void Ball::update(){
    if(x < 0 ){
        x = 0;
        speedX *= -1;
    } else if(x > ofGetWidth()){
        x = ofGetWidth();
    speedX *= -1;
    }

    if(y < 0 ){
        y = 0;
        speedY *= -1;
    } else if(y > ofGetHeight()){
        y = ofGetHeight();
        speedY *= -1;
    }

    x+=speedX;
    y+=speedY;
}

void Ball::draw(){
    ofSetColor(color);
    ofDrawCircle(x, y, dim);
}

现在在 ofApp.cpp 里，我们需要在应用启动时立刻运行这个新实现的方法，这样每个对象创建时就能体现不同的设置。所以在 ofApp::setup() 里

for(int i=0; i<NBALLS; i++){

    int size = (i+1) * 10; // 根据小球在数组中的位置来定义它的尺寸
    int randomX = ofRandom( 0, ofGetWidth() ); //生成一个大于 0 且小于应用屏幕宽度的随机值
    int randomY = ofRandom( 0, ofGetHeight() ); //生成一个大于 0 且小于应用屏幕高度的随机值

    groupOfBalls[i].setup(randomX, randomY, size);
}

如你所见，现在可以在创建对象时直接控制它的属性。接下来只需用前面的 for 循环遍历这些小球，在各自的函数里更新并绘制它们。

groupOfBalls[i].update();

groupOfBalls[i].draw();

即兴创建对象

很多时候你已经预先知道要创建多少个对象，用数组就是正确选择，但还有其他创建多个对象的方式，各有各的好处：欢迎 vector！vector 非常棒，它允许创建元素数量不预先确定的集合。它相当动态，既能即兴添加对象（比如程序运行期间），也能在不再需要时删除对象。把它想成弹性数组就好。那我们就用起来！注意：这本书里你会遇到两种不同的 vector。请不要把 stl::vector（也就是我们说的这种弹性数组）和数学上的向量（比如力）搞混。

想进一步了解 stl::vector，请看“C++ 基础”一章，或 openFrameworks 网站上的简短在线教程。

回到我们心爱的 ofApp.h 文件，输入下面的内容来定义一个装 Ball 对象的 vector：

vector <Ball> groupOfBalls;

这个表达式里，我们创建了一个类型（vector），它的元素类型是（Ball 指针），并把它命名为 groupOfBalls。现在转去 ofApp.cpp 开始烹饪！先不管 ofApp 里的 setup()、update() 和 draw() 方法，直接跳到 ofApp::mouseDragged(...) 方法。这个方法持续监听鼠标拖拽动作，一旦有变化就把它的数值（位置和按键状态）交给我们。

void ofApp::mouseDragged(int x, int y, int button){
}

在这个方法里，我们监听鼠标的拖拽活动，并用它来制造交互！那就写点代码，在拖动鼠标时创建 Ball 并把它们加进我们的程序。鼠标或触控板的拖拽动作是一种无处不在、简单又极具手势性的数据来源，我们就用它来制造交互！下面加上代码，在拖动鼠标时创建 Ball 并加入程序。

void ofApp::mouseDragged(int x, int y, int button){
    Ball tempBall;                            // 创建小球对象
    tempBall.setup(x,y, ofRandom(10,40));    // 设置它的初始状态
    groupOfBalls.push_back(tempBall);                // 把它加进 vector
}

代码里有几处新东西：我们先声明一个临时对象，可以把它看成真正对象——那个会被放进 vector 的对象——的占位符，然后通过把鼠标拖拽坐标 x 和 y 赋给它的初始化变量来设定初始属性。随后，我们用这个临时对象作为占位符，把 Ball 对象加进 vector。

回到 update 和 draw 方法。我们可以加上所需的 'for 循环'，像处理数组那样遍历 vector 里的对象来更新和绘制它们。不过这次我们没有声明一个保存对象数量上限的变量，而是由 vector 对象提供一个顺手的方法，调用它就能知道元素个数（size()）。update() 的代码见下

for (int i = 0; i<groupOfBalls.size(); i++) {
    groupOfBalls[i].update();
}

以及 draw()：

for (int i = 0 ; i<groupOfBalls.size(); i++) {
    groupOfBalls[i].draw();
}

现在 'for' 循环会遍历 vector 中的所有对象，我们不必事先指定确切的元素数量。多亏了 size()，它会即时调整。

想造就造，想删就删——使用 vector

如果运行前面的代码，你会发现很短时间里就不只创建了大量小球，而且到某个时刻系统可能变得迟钝，因为屏幕上的对象实在太多了。正如刚才提到的，vector 很特别，我们可以动态增删元素。这就是它的魔力：vector 是弹性的！所以我们还得实现一种删除方式，免得小球多到不可收拾。

在 ofApp::MousePressed(...) 里，我们会遍历 vector，检查鼠标坐标与某个 Ball 位置之间的距离。如果这个距离小于 Ball 的半径，就说明我们点中了它，可以把它删掉。因为要用 vector.erase(...) 方法，我们需要一个迭代器（groupOfBalls.begin()）。迭代器指向一个更大容器中的某个元素，并且能够遍历该范围内的元素。可以把它们看作路径或链接。在这个例子里，它们是一种捷径，以 vector 的第一个元素为起点，去访问我们真正想删除的那个元素（i），也就是 groupOfBalls.begin()+i。

for (int i =0; i < groupOfBalls.size(); i++) {
    float distance = ofDist(x,y, groupOfBalls[i].x, groupOfBalls[i].y); // oF 提供的方法，用来检查两个坐标之间的距离

    if (distance < groupOfBalls[i].dim) {
        groupOfBalls.erase(groupOfBalls.begin()+i); // 我们需要用迭代器/引用来指向要删除的 vector 位置
    }
}

但总有时候你只想把它们全部销毁，vector 也有一个非常顺手的方法帮你做到：clear()。尽管自己动手实验，试着用用看！

groupOfBalls.clear();

多态（继承）快速入门

你现在正在体会 OOP 的威力：做一个类，瞬间从它创建任意多个对象，按应用的需要增删。现在，先回到我们的烹饪比喻（真香！）想象一下：你的饼干虽然用的是同一块模具和同一份面团，但每块撒的糖粒不同，好给我们的饼干罐添点想要的花样！这也是 OOP 和继承的威力。它让我们可以使用一个基类并添加一些特定的行为，覆盖类的某些行为，从而创建出行为略有差异的实例/对象子集。最棒的是它的可复用性。我们把父类当作起点，用上它全部的能力，但覆盖它的某个方法，让它更灵活。回到我们 Ball 类的初始版本，我们会基于它的主要特征（运动行为和形状）构建几个子类，但让每个继承来的子类在绘制方法里用不同的颜色以示区别。

你的 Ball 头文件应该像这样：

#ifndef _BALL // 如果这个类还没有定义，程序就可以定义它
#define _BALL // 借助这个 if 语句，可以防止该类被多次调用，否则会让编译器困惑
#include "ofMain.h"


class Ball {
    public: // 在这里放置 public 函数或变量的声明

    void setup();
    void update();
    void draw();

    // 变量
    float x;
    float y;
    float speedY;
    float speedX;
    int dim;

    ofColor color;

    Ball();

    private:
};
#endif

对实现文件做点小改动。把随机尺寸的最小值和最大值调大，并把位置设到屏幕中心。让源码变成这样：

#include "Ball.h"

Ball::Ball(){
}

void Ball::setup(){

    x = ofGetWidth()*.5;
    y = ofGetHeight()*.5;
    dim = ofRandom(200,250);

    speedX = ofRandom(-1, 1);
    speedY = ofRandom(-1, 1);

    color.set(ofRandom(255), ofRandom(255), ofRandom(255));
}

update() 和 draw() 函数可以保持原样，但 ofApp.cpp 里的 mouseDragged(...) 需要配合新的 setup() 函数调整，把三个参数去掉：

void ofApp::mouseDragged(int x, int y, int button){
    Ball tempBall;                // 创建小球对象
    tempBall.setup();            // 设置它的初始状态
    groupOfBalls.push_back(tempBall);    // 把它加进 vector
}

现在开始制作这个父类的子版本。新建一组类文件，命名为 BallBlue。可以直接抄下面的代码。它的 '.h' 应该像这样：

#pragma once                // 另一种更现代的方式，防止编译器重复包含这个文件

#include "ofMain.h"
#include "Ball.h"            // 我们需要包含父类，编译器会包含母类/基类，这样我们才能访问所有继承来的方法

class BallBlue : public Ball {     // 我们让这个类继承自 'Ball'
    public:
        virtual void draw();       // 这是我们唯一希望与父类不同的方法
};

在 '.cpp' 文件里，我们需要指明新的 draw() 方法要怎样表现得和父类中的不同。

#include "BallBlue.h"

void BallBlue::draw(){
    ofSetColor(ofColor::blue);    // 这是纯蓝色的简写方式 ;)
    ofDrawCircle(x, y, dim);
}

现在自己动手创建两个新类：仿照 BallBlue，基于 Ball 类做出 BallRed 和 BallGreen。回到你的 'ofApp.h'，包含刚做好的类并各创建一个实例，然后在你的 'ofApp.cpp' 文件里初始化它们并调用它们的 update() 和 draw() 方法。一个小技巧！在调用 draw() 方法之前，先调用：

ofEnableBlendMode(OF_BLENDMODE_ADD);

这会让你的应用绘制方法使用加色混合模式。更多内容请看“图形”一章。
