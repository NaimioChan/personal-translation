玩转 Map，具体说是 std::map

作者：Joshua Noble

简介：map 是什么？

在上一篇教程中你了解了 std::vector，但那并不是 C++ 为你提供的唯一一种容器。事实上，几乎你能想到的任何一种数据存储方式，都有一种容器可以让你优雅地表达它。在这篇小教程里，我们来看一种在你需要比 vector 更专门的东西时非常好用的容器。map 是按特定顺序存放由键值和映射值组合而成的元素的容器。如果你用过 Javascript、Ruby 或 Python，那你已经很熟悉它们了，每当你想要做类似这样的事时就用过：

images["Portland"].draw();

很漂亮吧？你不需要在 vector 中翻找合适的图像，只需用一个键把它存起来，之后就可以用更适合你的数据的方式查找它。如果你发现自己总是在做这样的事：

int theImageIWant, otherImageIWant;
vector<ofTexture> images;

你也许该考虑用 map，因为你实际在说的是：我需要一种好的方式来存放对象的索引（其实它们就是“键”），好让我以后能取回它们。存放索引最大的问题是，一旦你重排了 vector、在开头插入东西、删除东西，你的索引就失去意义了。如果能写成这样不是更好吗：

string firstImageKey = "Portland", secondImageKey = "Tokyo";
map<string, ofTexture> images;

这有几个好处：“Portland” 和 “Tokyo” 永远指向同样的 ofTexture，无论你对 map 做什么，而且这些名字是人可读的：你直接读就能知道它们是什么。我们来看一个小例子。在我的 ofApp.h 文件里，我加入下面这行：

map<string, ofImage> images;

这表示：我将用字符串作为键来存放图像。在我的 cpp 文件里，我可以这样做：

void ofApp::setup(){
    // 创建要存放的 2 张图像
    ofImage pImage;
    pImage.load("portland.jpg");
    
    ofImage tImage;
    tImage.load("tokyo.jpg");
    
    // 现在用清晰的名字存起来
    images["Portland"] = pImage;
    images["Tokyo"] = tImage;
}

void ofApp::draw(){
    // 现在我可以直接用它们的名字访问：
    images["Portland"].draw(0, 0, 100, 100);
    images["Tokyo"].draw(100, 0, 100, 100);
}

你可以看到，虽然这并不是这方面最有力的例子，但能用某个具体的、无论如何都会保持其“位置”的东西来追踪事物，可能真的很好。所以，一般来说在 map 中，键值通常用来排序并唯一标识元素，而映射值存放与该键关联的内容。你可以用什么作为值？任何东西。真的，任何东西都可以是值。存放指针时你要小心，但与 vector 不同，对象一旦插入 map 就不会移动，即使添加或删除其他元素也一样；不过存放指针是好的，特别是当你处理大量纹理或其他大型数据对象时。只要确保不要让指针失效（也就是不要删除被指向的对象），就没问题了。

向 map 插入值

就添加来说，这样做：

 map[key] = value;

并不是你唯一会看到的向 map 添加对象的方式。map 中的每个元素是一个 pair。pair 由两部分组成：一个键和一个值。pair 的声明看上去就和 map 本身的声明一样：

typedef pair<const Key, T> value_type;

这还没什么特别启发人的，但请稍等。考虑到这一点，往 map 里添加元素就意味着往里添加 pair。在 C++ 中有几种不同的做法。我们先实例化 3 个新城市

ofImage bImage;
bImage.load("Berlin.jpg");

ofImage lImage;
lImage.load("London.jpg");

ofImage pImage;
pImage.load("Paris.jpg");

我们怎么把它们加进 map？最常见的方式之一是使用 insert 方法配合 make_pairs。

images.insert(make_pair("Berlin", bImage));

我们也可以用 insert 和 pair

images.insert(pair<string, ofTexture>("London", lImage));

或者我们可以使用 std::pair 构造

images.insert(map<string, ofTexture>::value_type("Paris", pImage));

从 map 中删除元素

要从 map 中删除元素，我们用 erase

images.erase("London");

要完全清空 map，我们用 clear

images.clear();

遍历 map

那么，我们知道如何把东西放进 map 再取出来，那如何遍历它们呢？你不能像 vector 那样用一个 int 循环遍历它们，所以需要使用迭代器。我们先把 pair 甚至 map 放一边，聊一聊迭代器，因为它们让 map 好用得多：

迭代器是 C++ 标准库版本的指针。你用它指向容器中的某个位置，有点像用 vector 时你可能会保留一个索引，它引用 vector 中你关心的某个位置；迭代器就像那个索引，但更进一步——它就是 vector 中的那个对象。所有容器都有 begin() 函数，返回指向容器开头（第一个元素）的迭代器，以及 end() 函数，返回对应“已到达容器末尾”的迭代器。我们用迭代器写一个 for 循环，看看它们如何工作得更清楚：

map<float,string>::iterator it; // 创建迭代器，说明它要遍历一个 map<float, string>
for ( it = aMap.begin(); // 说明迭代器应指向名为 “aMap” 的 map 的开头
      it != aMap.end();  // 说明到达 aMap 末尾时就停止
      ++it) {            // 递增迭代器
}

ofImage 的 vector 的迭代器看起来像这样：vector<ofImage>::iterator而键为 string、值为 ofMatrix4x4 的 map 的迭代器则是：map<string, ofMatrix4x4>::iterator。你可以用 ++ 把迭代器前移，用 -- 后移。有意思的是：你可以用 advance(it, 2) 把迭代器移动两个位置，或用 advance(it, 20) 移动二十个，不过你大概永远不需要这么做。好，回到 map，我们来遍历我们的 map 把它们画到屏幕上：

void ofApp::draw(){
    int xpos = 0;
    for (map<string, ofTexture>::iterator it=cities.begin(); it!=cities.end(); ++it){
        // it->first 包含键
        cout << " this is the key " << it->first << endl;
        // it->second 包含值
        it->second.draw(xpos, 0, 100, 100);
        xpos+= 100;
    }
}

那么那个迭代器指向什么？一个 pair，这里是 string,ofTexture 的 pair，像这样：

pair<string, ofTexture> p;

C++ 11 引入了一种遍历 map 的简写，auto。我们可以这样用：

for (auto& pic : images )
  cout << pic.first << endl;

请注意我们用的是 pic.first 而不是 pic->first。这是因为 pic 是对 pair 的引用（注意那个 &），而不是上一个例子那样的指针。在这种写法里，我们可以遍历 map 并修改 map 的值。但如果我们只想读取 map 中的值、不修改它们呢？这种情况下，我们使用 constant 关键字。这个关键字确保 map 中没有任何值会被改动

for (const auto& pic : images )
  cout << pic.first << endl;

在 map 中查找元素

在 map 中搜索元素的方法名除了 find 还能是什么呢？

  if (cities.find("Berlin") != cities.end())
    cout << it->first << " found!" <<endl;
  else
    cout << "city not found" << endl;

注意到那里的 end() 调用了吗？那是因为 find() 返回的其实是一个迭代器：如果元素在 map 里，我们得到一个指向它的迭代器；如果不在，我们得到一个指向迭代器末尾的迭代器。map 还提供了其他一些方法，我们稍微简略地列一下：

在 map 中存放对象

map 中可以用什么作为键？嗯，几乎你想要的东西都可以：字符串、浮点数之类的。不过这也有一些限制，你可能会试着这样做：

map<ofVec2f, string> locations;

这会抛出一个相当晦涩的错误，大致像这样：“/usr/include/c++/4.2.1/bits/stl_function.h:227:20: error: invalid operands to binary expression ('const ofVec2f' and 'const ofVec2f')”。这其实合理，因为“小于”的 vector 这个概念有点奇怪。它在数学上有定义，但不太符合常识，而符合常识的那种在数学上又不太说得通，况且那并不是重点。重点是：任何有 “<” 运算符的东西都能用作键。我们来造一个：

class vec2Key
{
    
public:
    
    float x, y;
    
    vec2Key( float xValue, float yValue )
    {
        x = xValue;
        y = yValue;
    }
    
    bool operator < ( const vec2Key& other) const
    {
        if ( x == other.x ) {
            return y < other.y;
        }
        
        return x < other.x;
    }
    
};

注意那个 < 运算符。这很关键，因为它告诉 map 如何组织它包含的所有值，从而让查找所需值相对快速。map 底层通常是一棵红黑树，对想知道那是什么的人，尽管去看吧。好，现在我们有了一个可用的键对象，接下来就用它：

vec2Key k1(100, 200, 1);
vec2Key k2(100, 300, 1);
vec2Key k3(100, 400, 1);

map<vec2Key, string> stringToLocation;

stringToLocation[k1] = "first";
stringToLocation[k2] = "second";
stringToLocation[k3] = "third";

好，我们来测试一下：

cout << stringToLocation[vec2Key(100, 300)] << endl; // 打印 “second”，一切正常

任何知道自己是否大于另一个东西的对象都可以放进去。假设我们想以一种模糊的方式查找，因为我们在做一个奇怪的四叉树实现之类的东西，那我们就可以让那个 < 运算符为我们做很多事。让我们给这个 vector 一个稍微更“流动”的比较运算符：

    bool operator < ( const vec2Key& other) const
    {
        if ( fabs(x - other.x) < 0.1 ) {
              return fabs(y - other.y) > 0.1;
        }
        
        return x < other.x;
    }

现在：

 cout << stringToLocation[vec2Key(100.01, 299.99)] << endl; // 返回 “second”，因为 100,300 两者相距都 < 0.1

什么是 multimap？

在 map 中每个键都是唯一的，这意味着在我们之前的 map map<string, ofTexture> images 中，不可能出现两个城市图像以同一个名字作为键，比如 “London”。在 multimap 中我们没有这条规则，一个 multimap 可以包含键相同的 pair。例如：

  multimap<string, int> coldestCities;
  coldestCities.insert(make_pair("moskow",2015));
  coldestCities.insert(make_pair("chicago",2014));
  coldestCities.insert(make_pair("moskow",2013));
  coldestCities.insert(make_pair("moskow",2012));
  coldestCities.insert(make_pair("helsinki",2011));

  cout "coldest cities in the last 5 years" << endl;
  cout "disclaimer: this data are just an example" << endl;

  for (const auto& cityYear : coldestCities )
    cout << cityYear.first<< "year: "<< cityYear.second << endl;

当我们希望键只出现一次时用 map，当这个细节不重要时用 multimap。

其他有用的方法

empty - 如果容器为空返回 true，否则返回 false

size - 返回 map 中元素的数量

lower_bound - 返回指向第一个不小于给定值的元素的迭代器，所以：upper_bound - 返回指向第一个大于某个值的元素的迭代器

作为这两个方法的例子：

map<float, string> floatToString;

floatToString[3.14] = "PI";
floatToString[2.71] = "E";
floatToString[2.29] = "UPC";
floatToString[0.83] = "Gauss's constant";

cout << floatToString[0.83] << endl;

map<float, string>::iterator lb = floatToString.lower_bound(2.6);
map<float, string>::iterator ub = floatToString.upper_bound(2.8);
