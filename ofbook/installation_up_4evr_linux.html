永久运行的装置 - Linux

作者：Arturo Castro

在 Linux 上你可以装一个极简桌面，这会让装置的配置容易得多，因为除其他好处外，你不必操心关掉烦人的通知。而且关掉屏幕空白这类事可以通过脚本完成，所有东西都能直接复制粘贴，也便于自动化。

  1. 安装你选定的 Linux 发行版。做装置时我通常用 ubuntu，因为显卡驱动是预装的。安装过程中选择自动登录到你的用户，这样以后只要开机就能启动装置。

  2. 把所有软件包更新到最新版本。在 ubuntu 中你可以用 Software Updater 工具，或在命令行执行：

sudo apt-get update
sudo apt-get upgrade

  1. 如果你用的是 nvidia 或 ati 显卡，安装专有驱动。在最新的 ubuntu 版本中，你可以通过 "Software & Updates" 工具的 Additional Drivers 选项卡安装

  2. Ubuntu Unity 这个默认桌面通常塞满了运行装置时用不到的功能。我最近一直在用 Openbox，它还让 OpenGL 稍微快一些，因为桌面不做合成，甚至能解决一些 vsync 的问题：

sudo apt-get install openbox
  1. 你可能还想安装 openssh server，以便远程访问这台机器：
sudo apt-get install openssh-server

  1. 现在通过 install_dependencies.sh 脚本下载并安装 openFrameworks

  2. 注销会话，在登录界面选择 openbox 而不是 unity

  3. 你会看到一个没有任何装饰、面板的灰色屏幕……在桌面任意位置按鼠标右键可以调出上下文菜单，不过我发现此时从笔记本通过 ssh 登录更方便。

  4. 把应用装到机器上之后，你大概希望它在开机时启动。用 Openbox 你只需在 ~/.config/openbox/autostart 里创建一个脚本，在其中加上你的应用二进制的路径：

~/openFrameworks/apps/myapps/myapp/bin/myapp &
don't forget the & at the end so the application is started in the background.
  1. 关掉屏幕空白，在同一个 autostart 文件里加上这几行：
xset s off
xset -dpms

就这样，现在电脑每次启动都会启动你的应用。大多数 PC 的 BIOS 里有一项设置，可以选择断电后自动开机，所以如果装置放在那种晚上直接拉闸的地方，早上他们一通电它就会自动启动。

一些额外的技巧：

  • Linux 可以装到 SD 卡上，这样你可以买一张 16Gb 的 SD 卡代替硬盘来省钱，大多数 SD 卡也相当快，启动时间会很短。从 U 盘或 CD 启动，把 SD 卡插在读卡器里，如果没有硬盘，ubuntu 安装程序就会装到 SD 卡上。装到 SD 卡上也使得复制装置变得非常容易。在 ubuntu 中你可以用 "Disks" 工具创建和恢复备份，或在命令行用：
sudo dd bs=4M if=/dev/sdcardDevice of=sdcardimg.bin
To create the backup where sdcardDevice is the name of the device that you can find out by mounting the device and showing it's properties from nautilus. And then:
sudo dd bs=4M if=sdcardimg.bin of=/dev/sdcardDevice
To restore the backup. If you have 2 sdcard readers you can just copy from one to another using dd
  • 通过 ssh 访问机器时，如果你先设置显示，就能启动有图形输出的应用：
export DISPLAY=:0
also you can tunnel the graphical output to your own computer if you add -X when starting the ssh session
  • 你可以在同一个 autostart 脚本里很轻松地让应用在崩溃后重新启动：
~/openFrameworks/apps/myapps/myapp/bin/myapp.sh &
and now create a myapp.sh script with this contents:
cd ~/openFrameworks/apps/myapps/myapp/bin/
ret=1
while [ $ret -ne 0 ]; do
    ./myapp
    ret=$?
done
that will restart your application in case it crashes and you can still quit it pressing escape (unless your app crashes when exiting)
