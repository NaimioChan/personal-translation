安装与运行

要确认 Rack 能在你的电脑上运行，请参见 Rack 2 系统要求。

安装 Rack

请在 VCV Rack 产品页面下载 Rack。

在 Mac 上安装

双击安装程序，按屏幕上的步骤操作。

从 Applications 文件夹启动 VCV Rack。

在 Windows 上安装

运行安装程序，按屏幕上的步骤操作。

在 Rack Pro 的安装程序中，你可以在安装过程中设置自定义的 VST 路径。

从桌面图标或开始菜单项启动 VCV Rack。

在 Linux 上安装

解压 ZIP 文件。 确认你的系统已安装 zenity。

打开 Rack 的文件夹，双击 Rack 可执行文件。 或者在命令行中 cd 到 Rack 的文件夹并运行 ./Rack。

安装 Rack 插件

插件通过为你的 patch 添加一个或多个模块来扩展 VCV Rack 的功能。 插件通常通过 VCV Library 安装。 请参见 VCV Library 页面底部的 VCV Library Instructions 一节。

如果你的电脑处于离线状态，你可以用另一台电脑下载插件，并把 <Rack user folder>/plugins-<OS>-<CPU>/（参见 “Rack 用户文件夹”在哪里？）传输到离线电脑上。 目前不支持直接从 VCV Library 下载插件。

安装 VCV Library 上没有的插件

请自行承担安装第三方插件的风险。与 VST 插件一样，从不明来源安装插件可能会危及你的电脑和个人信息。

Rack 的插件以 .vcvplugin 文件的形式分发。 从厂商网站下载插件包到 <Rack user folder>/plugins-<OS>-<CPU>/（参见 “Rack 用户文件夹”在哪里？）。 Rack 会在启动时解压并加载该插件。

注意：“major” 版本号（例如 v2.3.4 中的 2）必须与 Rack 的主版本号一致。参见 ABI/API 版本。

命令行用法

要从命令行启动 Rack，先 cd 到 Rack 的文件夹，然后运行 ./Rack，可选地带上以下选项。

  • <patch filename>：加载一个 patch 文件。
  • -s / --system <Rack system folder>：设置 Rack 的系统文件夹，其中包含只读的程序资源。默认为
    • MacOS：<app bundle path>/Contents/Resources
    • Windows：安装位置，例如 C:\Program Files\VCV\Rack
    • Linux：当前工作目录
  • -u / --user <Rack user folder>：设置 Rack 的用户文件夹，其中包含设置、插件和 patch。默认位置参见 “Rack 用户文件夹”在哪里？。
  • -d / --dev：启用开发模式。 这会把系统文件夹和用户文件夹设为当前工作目录，使用终端（stderr）输出日志，并禁用 Rack 的 Library 菜单，以防覆盖插件。
  • -h / --headless：在没有窗口的情况下启动自动保存的 patch。 非常适合博物馆展览中的生成式 patch。 patch 可以用 MIDI 控制。
  • -a / --safe：在没有任何插件和自动保存 patch 的情况下启动 Rack。 用于测试很方便。
  • -t / --screenshot <zoom factor>：为所有已安装的模块截图，并分别保存到 <Rack user folder>/screenshots/<plugin slug>/<module slug>.png。缩放系数为 1 时生成的截图高度为 380px。
  • -v / --version：打印 Rack 版本并退出。

你也可以设置 RACK_SYSTEM_DIR 或 RACK_USER_DIR 环境变量来覆盖这些位置。
