插件许可

VCV Rack 是自由/开源软件，但在发布插件之前，你仍应熟悉 VCV Rack 许可证，以避免知识产权被滥用。如有疑问，请将许可相关问题发送至 support@vcvrack.com。

我希望以 GNU 通用公共许可证 v3.0（或更高版本）自由/开源许可证（GPLv3+）发布插件。

由于 Rack 以 GPLv3+ 许可发布，你也可以同样以 GPLv3+ 许可发布你的插件。

VCV 建议自由/开源软件的支持者将其 Rack 插件以 GPLv3+ 许可发布（SPDX 许可证标识符为 GPL-3.0-or-later）。 该许可证赋予用户自由软件的四项基本自由，并遵循 OSI 的开源定义。

以 GPLv3+ 许可发布你的 Rack 插件，要求衍生作品也须以 GPLv3 作为自由软件进行许可。 这可防止公司在未经你明确许可的情况下，将你的源代码变为专有（非自由）软件。

我希望以其他开源许可证或免费软件的形式发布插件。

Rack 提供了一项 VCV Rack 非商业插件许可例外，允许你以自己的任意条款许可插件，只要它是免费提供的。 你可以选择：

  • 开源。非 GPL 许可证的示例：BSD 三条款、MIT 和 CC0。
  • 闭源免费软件。
  • 捐赠软件，只要使用不以捐赠为前提（否则你需要商业插件许可）。

请注意，如果你将 Rack 代码的重要部分复制到你自己的插件中，则必须对其以 GPLv3 许可。

如果有人对你的非 GPLv3 开源插件制作了分支，而该分支不是 Rack 插件（例如移植到 VST 或数字硬件模块），其源代码便不再链接到 VCV Rack，因而不再是 Rack 的“衍生作品”，所以 Rack 的许可证不适用于他们的源代码。

我希望以非 GPLv3 条款商业销售插件。

VCV 为 Rack 插件提供商业版税许可，可通过发送邮件至 support@vcvrack.com 申请。 该许可还包含使用 Grayscale 的 Component Library 图形的权限，这些图形通常仅限非商业使用。

建议在开发过程中尽早联系 VCV，以确保许可协议在你发布插件之前就已就绪。 在提交许可申请时附上概念图或设计稿，可以加快许可处理速度。

你可能还希望在 VCV Library 上销售你的插件。 在 VCV Library 上分发插件的一些好处：

  • 大多数 Rack 用户已经熟悉 VCV Library 的结账系统。
  • 插件更新会自动同步到用户的电脑。
  • VCV 提供针对 Rack SDK 和 DSP 库的高级技术支持。
  • 你可以向 VCV 提供 Mac/Windows/Linux 的二进制包，或提供源代码包，由我们为你构建。
  • 可访问仪表板来管理客户的购买并查看实时统计。

VCV 插件伦理准则

  • 未经所有者许可，你不得克隆现有硬件或软件产品的品牌名称、型号名称、徽标、面板设计或元件布局（旋钮、接口、开关等），无论这些是否受商标/版权法保护。

建议所有插件都遵循这些准则，但你在法律上并无此义务。 不过，这是以下情形的必要条件：

  • 在 VCV Library 上分发你的插件。
  • 获得商业插件许可。
