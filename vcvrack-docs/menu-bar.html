菜单栏

File

New

清空当前 patch 并加载模板 patch（<Rack user folder>/template.vcv）。

Open/Save/Save as

打开或保存 patch 到 .vcv 文件。

Save template

将当前 patch 保存为 <Rack user folder>/template.vcv，这样之后新建 patch 时就会加载它。

Revert

把 patch 恢复到上次保存的状态。

Quit

自动保存 patch 到 <Rack user folder>/autosave.vcv 并关闭 Rack。 Rack 还会每 15 秒自动保存一次，以免因崩溃、断电等情况丢失工作。

Edit

Undo/Redo

回退并重放所有对 patch 进行编辑的操作。

Clear cables

移除 patch 中的所有线缆。

View

Show tooltips

启用或禁用鼠标悬停在参数（旋钮、滑块、按钮等）、端口和指示灯上时显示的工具提示，其中包含名称、数值和描述等有用信息。

Zoom

调整机架的缩放级别，范围为 25–400%。 双击可重置为 100%。

你也可以用 Ctrl-- 和 Ctrl-=（Mac 上为 Cmd）来缩放，或者 Ctrl-滚轮，或者多键鼠标上的 #4、#5 键。

Cable opacity

设置跳线的透明度。 双击可重置为 50%。

Cable tension

设置跳线的相对长度。 双击可重置为 50%。

Frame rate

设置 Rack 的屏幕刷新频率。 Rack 会在每次显示器垂直同步时重绘屏幕，或者按此设置的倍数每 NN 次垂直同步才重绘一次。 降低帧率会使 Rack 占用的 GPU 资源几乎按比例减少，代价是画面更不流畅。

Fullscreen

让 Rack 扩展至填满屏幕，不显示窗口边框。

Lock module positions

锁定或解锁模块，使其不能被鼠标移动。 可防止误拖动模块。

Engine

Performance meters

启用或禁用对每个模块生成每个采样所耗时间的测量（参见采样率）。 这会在每个模块上显示一个仪表，表示在该模块所分配线程中消耗的时间百分比（参见线程）。

CPU 仪表本身也会消耗引擎的 CPU 时间，因此为了获得最佳性能，建议在不需要时将其关闭。

Sample rate

设置 Rack 引擎的采样率。

Rack 引擎的工作原理是反复以 1 / sampleRate 秒为步长推进每个模块的状态，为每个输出产生 1 个新采样。 采样率越高，时间步长越小，模拟电路建模和数字算法就越精确，而采样率越低，引擎的 CPU 占用越少。 引擎的 CPU 占用几乎与采样率成正比。

Threads

设置 Rack 多线程引擎使用的核心数量。

为了尽量减少功耗、把 CPU 资源留给其他程序，可选择 1 个线程来禁用多线程。 使用更多线程会增加 CPU 占用，但也能提高机架中可使用的模块数量上限。

建议从 1 个线程开始，如果遇到音频卡顿，就尝试把线程数加 1。 持续增加线程，直到不再出现卡顿。 推荐的线程数上限是机器的物理核心数。 例如，四核机器使用 4 个线程通常能让模块数量达到最大。

由于同步多线程（如Intel 超线程）的存在，你也许可以尝试使用最多两倍于物理核心数的线程，但通常这会导致性能更差、功耗更高。

Library

Login

登录你在 vcvrack.com 注册的 VCV 账号。 如需账号帮助，请发邮件至 support@vcvrack.com。

Update all

更新并下载添加到你的 VCV 账号中的所有新插件及插件新版本。 必须重启 Rack 才能加载新的插件更新。

Help

Tips

显示提示窗口，其中有若干条学习 VCV Rack 的实用技巧。

默认情况下，提示窗口会在启动时显示，但取消勾选 “Show tips at startup” 即可禁用它。
