快捷键

本文档中，Mac 上请用 Command (⌘) 代替 Ctrl。

全局命令

已在 Rack 菜单栏中记录的快捷键，此处不再重复。

  • Enter 或 在机架上右键单击：打开模块浏览器，向机架添加模块。
  • F1：在浏览器中打开 Rack 手册。
  • F3：显示或隐藏 CPU 仪表。
  • F11：进入或退出全屏。
  • Ctrl+0：将机架缩放级别设为 100%。
  • Ctrl+-：缩小。
  • Ctrl+=：放大。
  • 滚动：纵向滚动机架。
  • Shift+滚动：横向滚动机架。
  • Ctrl+滚动：放大或缩小。
  • 拖动鼠标中键：平移机架视图。
  • 方向键：平移机架视图。可用 Ctrl、Shift 或 Ctrl+Shift 改变滚动的速度。
  • Ctrl+V：在光标位置粘贴一个新模块，内容来自模块右键菜单的 “Preset > Copy” 或 Ctrl+C。

模块命令

你必须把鼠标悬停在一个模块上，才能对它使用快捷键。 已在模块右键菜单中记录的快捷键，此处不再重复。

  • 在面板上右键单击：打开模块右键菜单。
  • 在面板上单击并拖动：在机架中拖动模块。
  • 在面板上Ctrl+单击并拖动：强制拖动模块。这会移动其他模块，以便为被拖动的模块腾出位置。
  • Backspace 或 Delete：从机架中删除模块。你可以在移动鼠标的同时按住此键，以删除多个模块。

参数命令

参数是指任何用于控制模块状态的旋钮、滑块、按钮、开关或其他自定义组件。

  • 垂直单击并拖动：调整数值。拖动时按住 Ctrl 可缓慢移动旋钮，Ctrl+Shift 可极缓慢移动，或按住 Shift 快速移动。
  • 双击：重置为默认值。
  • 右键单击：打开参数右键菜单。你可以在文本框中输入精确数值，或输入数学表达式。 按下 Enter 后，诸如 2+2、2*2、1/2 和 2^2 这样的常规数学表达式会立即被求值为数值。 你可以使用下列常量与函数，它们不区分大小写。

    • C、A#、Gb 等：以中央 C 为起点的音名所对应的频率，单位为 Hz

    • C4、A#5、Gb0 等：带八度编号的音名所对应的频率，单位为 Hz（C4 = 中央 C）

    • C4v、A#5v、Gb0v 等：音名对应的电压，假设 1V/octave 且 C4v = 0V。Rack 2.6.1 中新增。

    • log2(x)：以 2 为底 x 的对数 示例：log2(8) = 3

    • gaintodb(x)：将增益/幅度系数转换为分贝 (dB) 单位。
      示例：gaintodb(1) = 0、gaintodb(0.5) = -6.0206、gaintodb(0) = -inf

    • dbtogain(x)：将分贝 (dB) 值转换为增益单位。
      示例：dbtogain(20) = 10、dbtogain(0) = 1、dbtogain(-inf) = 0

    • vtof(x)：将以伏特表示的 1V/octave 值转换为以 Hz 表示的频率，以中央 C（261.63 Hz）为基准。
      示例：vtof(0) = 261.63、vtof(-1) = 130.81

    • ftov(x)：将以 Hz 表示的频率值转换为以伏特表示的 1V/octave 值。
      示例：ftov(440) = 0.75、ftov(c#4) == 0.083333
