插件清单

本文档定义位于插件文件夹根目录的 plugin.json 文件。 例如，参见 Fundamental 的 plugin.json 文件。

JSON 路径以“扁平格式”表示，即 jq 所使用的格式。

.slug

字符串。必填。

插件的唯一标识符。 区分大小写。 slug 只能包含字母 a-z 与 A-Z、数字 0-9、连字符 - 以及下划线 _。

插件发布之后，slug 绝不能更改，否则会破坏预设的兼容性。 为保证唯一性，如果可能的话，建议用你的“品牌名”作为 slug 的前缀，例如“MyCompany-MyPlugin”。

“slug”一词源自网络出版，用来表示永不改变的 URL 路径，而这一用法又源自活字排版。

.name

字符串。必填。

插件的人类可读名称。 用于在 VCV Library 中标注你的插件。

与 slug 不同，名称可以随时更改，而不会破坏预设兼容性。

.version

字符串。必填。

插件版本应遵循 MAJOR.MINOR.REVISION 的形式。 不要包含“v”前缀——该前缀会在适当之处自动添加。

MAJOR 版本应与你的插件所针对构建的 Rack 版本一致，例如 2。 你可以自由选择插件版本的 MINOR.REVISION 部分。 例如，MyPlugin 2.4.2 表示你的插件兼容 Rack 2.X。

如果你在 git 仓库中发布源代码，建议用 git tag vX.Y.Z 添加 git 标签，并执行 git push --tags。

.license

字符串。必填。

你的插件的许可证。

对于开源插件，请使用 SPDX 许可证列表中的许可证标识符字符串，例如 "GPL-3.0-or-later"、"GPL-3.0-only"、"MIT"、"BSD-3-Clause"、"CC0-1.0" 等。

对于免费软件插件，请使用 "proprietary"（待办：在可用后改用 "https://vcvrack.com/freeware-eula"），或你自己的免费软件许可证 URL。

对于商业插件，如果在 VCV Library 上销售，请使用 "https://vcvrack.com/eula"，或你自己的商业许可证 URL。

.brand

字符串。可选。

插件中所有模块的前缀字符串。 例如，Fundamental 插件使用品牌“VCV”来生成“VCV VCF”、VCV Unity" 等名称。 若为空或未定义，则使用插件名称。

.description

字符串。可选。

对插件用途的一行摘要。 如果你的插件没有统一的主题，最好省略此项。

.author

字符串。必填。

你的姓名、公司、别名、GitHub 用户名等。

.authorEmail

字符串。可选。

用于支持咨询的电子邮件地址。

.authorUrl

字符串。可选。

你个人或你公司的主页。

.pluginUrl

字符串。可选。

插件本身的主页。

.manualUrl

字符串。可选。

插件的手册网站。 例如 HTML、PDF、GitHub readme、GitHub wiki。

.sourceUrl

字符串。可选。

源代码的主页。 对于 GitHub URL，请使用项目主页，而不是 .git URL。

.donateUrl

字符串。可选。

指向捐赠页面的链接，供希望捐赠的用户使用。 例如 PayPal.Me、Cash App 链接。

.changelogUrl

字符串。可选。

指向插件更新日志的链接。

.minRackVersion

字符串。可选。

从 VCV Library 下载该插件所需的最低 Rack 版本。

需要 VCV Rack 2.4.0+，以防止下载 minRackVersion 不兼容的插件包。 更旧的 Rack 版本不支持此属性，会忽略其值而下载所有插件版本。

.modules[].slug

字符串。必填。

模块的唯一标识符。 适用与 .slug 相似的准则。

.modules[].name

字符串。必填。

模块的人类可读名称。

.modules[].tags

字符串数组。可选。

表示模块功能和/或属性的标签列表。 所有标签都必须匹配以下字符串，不区分大小写。

“Arpeggiator”

将一个和弦拆解为一系列单音。

“Attenuator”

带一个电平旋钮，除此之外几乎没有别的。

“Blank”

没有参数或端口。除了视觉用途外没有其他作用。

“Chorus”
“Clock generator”

已弃用的别名：“Clock”

“Clock modulator”

时钟分频器、倍频器等。

“Compressor”

带阈值、压缩比、拐点等参数。

“Controller”

仅当艺术家用此模块来“演奏”时才使用。仅仅有旋钮是不够的。示例：屏幕键盘、XY 触摸板。

“Delay”
“Digital”
“Distortion”
“Drum”

已弃用的别名：“Drums”、“Percussion”

“Dual”

核心功能乘以二。如果多通道是模块存在的必要条件（环形调制器、混音器等），那它就不是 Dual 模块。

“Dynamics”
“Effect”
“Envelope follower”
“Envelope generator”
“Equalizer”

已弃用的别名：“EQ”

“Expander”

放在“母”模块旁边时扩展其功能。

“External”

与 VCV Rack 之外的硬件或软件交互，例如 MIDI/音频接口、摄像头、DAW、机器狗等。

“Filter”

已弃用的别名：“VCF”、“Voltage controlled filter”

“Flanger”
“Function generator”

通过大量通用参数生成复杂的包络或循环。

“Granular”
“Hardware clone”

已弃用的别名：“Hardware”

复刻市面上硬件模块的功能、面板设计和元件布局。

请记得遵守 VCV 插件伦理准则，并且仅在其所有者许可的情况下复刻硬件。

如果该硬件模块有 ModularGrid 页面，请添加 modularGridUrl 属性。

如果模块名称不包含硬件的名称或品牌，请把该信息添加到模块描述中，以便用户通过硬件的名称搜索到该模块，例如“Based on Mutable Instruments Clouds”。

“Limiter”

限制信号不超过某个阈值，例如通过软削波或动态范围压缩。

“Logic”

用门信号实现二进制逻辑。

“Low-frequency oscillator”

已弃用的别名：“LFO”、“Low frequency oscillator”

“Low-pass gate”

已弃用的别名：“Low pass gate”、“Lowpass gate”

“MIDI”

生成、处理或解析 MIDI 消息，例如用于 MIDI 接口。

“Mixer”

混合/汇总音频，可选带电平调节、声像和/或混音总线。

“Multiple”

将一路输入直接复制到多路输出。 虽然 VCV Rack 支持在输出端口上堆叠线缆，但用户有时更喜欢用 multiples 来整理线缆，便于取用每一根线。

“Noise”

生成音频速率或 CV 速率的随机噪声。

“Oscillator”

已弃用的别名：“VCO”、“Voltage controlled oscillator”

“Panning”

已弃用的别名：“Pan”

“Phaser”
“Physical modeling”

模拟物理系统，例如弦、金属条、声带、混沌系统、天体等。

“Polyphonic”

已弃用的别名：“Poly”

“Quad”

核心功能乘以四。如果多通道是模块存在的必要条件（环形调制器、混音器等），那它就不是 Quad 模块。

“Quantizer”
“Random”
“Recording”
“Reverb”
“Ring modulator”
“Sample and hold”

已弃用的别名：“S&H”、“Sample & hold”

“Sampler”
“Sequencer”
“Slew limiter”
“Speech”
“Switch”
“Synth voice”

合成器声部至少必须内置一个振荡器和一个包络。

“Tuner”
“Utility”

仅提供极其基础的功能，例如反相、最大值、最小值、乘以 2 等。

“Visual”
“Vocoder”
“Voltage-controlled amplifier”

已弃用的别名：“Amplifier”、“VCA”、“Voltage controlled amplifier”

“Waveshaper”

.modules[].description

字符串。可选。

对模块用途的一行摘要。 显示在模块浏览器的工具提示中。

.modules[].keywords

字符串。可选。

描述模块的单词、别名和缩写组成的字符串，用于提升在 VCV Library 和 Rack 模块浏览器中的可搜索性。 不需要照抄 modules[].tags 中的标签。 不向用户显示。

示例："24dB 12dB V2164 LM13700 OTA multi-mode analog"

modules[].manualUrl

字符串。可选。

模块的手册网站。 若省略，则使用插件的手册。

modules[].modularGridUrl

字符串。可选。

如果该模块带有 Hardware clone 标签，则此项为该模块的 ModularGrid 页面 URL。 示例："https://www.modulargrid.net/e/mutable-instruments-clouds"

在与 ModularGrid 的合作中，发布到 VCV Library 的模块将与其 ModularGrid 页面互相链接。 例如，ModularGrid 上的 Mutable Instruments Clouds 有一个“Available for VCV Rack”链接，指向 VCV Library 上的 Audible Instruments Texture Synthesizer。

.modules[].hidden

布尔值。可选。

指定该模块应从 Rack 的模块浏览器和 VCV Library 搜索结果中隐藏。 如果该模块已弃用且存在后继模块，请在描述中添加其名称，例如“Replaced by MyModule 2”。
