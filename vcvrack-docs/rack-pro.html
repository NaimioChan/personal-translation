Rack Pro 功能

VCV Rack Pro 让你可以把 Rack 作为插件在 DAW 中使用，也可以作为独立应用运行。 它还包含一组独有的Pro 模块。 本页记录 Rack Pro 独有的全部功能。

  • 插件格式
  • 音频输入/输出
  • MIDI 输入/输出
  • 参数自动化
  • 离线渲染
  • Pro 模块

插件格式

VCV Rack Pro 支持以下 DAW 插件标准。

  • VST2
  • VST3
  • Audio Unit（仅 macOS）
  • CLAP

我们在以下 DAW 中测试并支持 VCV Rack Pro。

  • Ableton Live
  • Cubase
  • FL Studio
  • Reason
  • Bitwig
  • Reaper
  • Mixbus
  • Studio One
  • Cakewalk
  • Logic Pro
  • GarageBand

其他 DAW 可能也能运行 Rack，但 VCV 不提供支持。

所有 Rack 插件格式都可以作为乐器和效果（FX）插件使用。 乐器插件适合可以用 MIDI 演奏（或自行运行）的 patch，而效果插件则适合处理音频。 不过，只要你的 DAW 允许把音频/MIDI 路由到插件，无论插件是哪种类型，音频和 MIDI 都可以发送给 Rack。

如果你需要在 DAW 工程中更改 VCV Rack 的插件格式，甚至希望在切换 DAW 或工程时保留同一个 VCV Rack patch，请按以下步骤操作。 打开现有的 Rack 插件窗口，选择“File > Save”保存一个 .vcv 文件。替换插件，然后在新窗口中选择“File > Open”加载该 .vcv 文件。

音频输入/输出

所有 Rack 插件格式都包含 16 个音频输入通道（8 个立体声输入）和 16 个音频输出通道（8 个立体声输出）。

当 Rack 作为 DAW 插件使用时，请使用某个 VCV Audio 模块并选择“DAW”驱动，以访问插件的音频输入/输出。 通道 1 和 2 是插件的主左/右音频通道，在 DAW 的通道条内路由，而通道 3–16 可以路由到其他轨道或从其他轨道接收，并通过 VCV Audio 8 或 VCV Audio 16 模块访问。 所有输入/输出通道在乐器插件和效果插件中均可用。

Ableton Live

要把 Ableton Live 轨道中的音频发送到另一条轨道上的 VCV Rack 插件，请在“Audio To”下选择 Rack 的轨道名称以及一对立体声输入。

要把 VCV Rack 插件中的音频接收到另一条轨道，请在“Audio From”下选择 Rack 的轨道名称以及一对立体声输出。 启用输入监听即可听到接收到的音频。 你可以用这条轨道把 Rack 的音频录制到 Live 的 Arrangement View 或 Session View 中。

Logic Pro

如果你希望使用 VCV Rack 乐器插件的多个立体声输出，请使用插件的“Multi-Output (8xStereo)”变体。 打开 Logic 的混音器，按 Rack 轨道底部附近的小“+”按钮，最多可创建 7 条 Aux 轨道，它们会自动从 Rack 的 3–4、5–6、7–8 等输出路由。 这些 Aux 轨道可以路由到 Master 轨道、硬件输出或 Bus，而 Bus 可作为其他音频轨道的输入用于录音。 更多细节请参阅 Logic 手册中的 Use multi-output instruments in Logic Pro for Mac。

Logic Pro 允许 VCV Rack 通过点击 Rack 编辑器窗口中的“Side Chain”下拉菜单，从某条轨道、输入或总线接收额外的一路立体声音频输入。 作为乐器插件时，Rack 在通道 1–2 上接收该侧链输入。 作为效果插件时，Rack 在通道 3–4 上接收。 遗憾的是，Logic 不允许 Audio Unit 插件接收多于一路立体声侧链输入。

MIDI 输入/输出

DAW 的 MIDI 可以发送给 Rack 插件，并由任意 VCV MIDI 输入模块处理。 大多数 DAW 都能向 VCV Rack 发送以下类型的 MIDI 消息。

  • 通道 #1-16 上的数据消息，例如音符、弯音轮、触后和 CC（Control Change）。
  • 来自 DAW 时间线的传输事件，例如开始、停止、继续，以及 24 PPQN（每四分音符脉冲数）时钟。
  • DAW 时间线的歌曲位置。
  • SysEx（System Exclusive）数据。

你也可以把任意 VCV MIDI 输出模块的 MIDI 输出接收到 DAW 轨道中，用于控制另一个插件或外部硬件，或录制成 MIDI 片段。

Ableton Live

要把 Ableton Live 轨道中的 MIDI 发送到另一条轨道上的 VCV Rack 插件，请在“MIDI To”下选择 Rack 的轨道名称以及“VCV Rack”插件。

要把 VCV Rack 插件中的 MIDI 接收到另一条轨道，请在“MIDI From”下选择 Rack 的轨道名称以及“VCV Rack”插件。 启用输入监听即可接收 MIDI。 你可以用这条轨道把 Rack 的 MIDI 录制到 Live 的 Arrangement View 或 Session View 中。

注意：Ableton Live 会把所有 MIDI 数据路由到 MIDI 通道 #1。 这意味着在通道 #2–16 上产生 MIDI 数据的 MIDI 控制器，会显示在 Rack 的 MIDI 输入模块的通道 #1 上。 请参阅 Live 手册中的 “What MIDI channels does Live support?”。

参数自动化

你可以用 DAW 自动化 Rack 模块的任意参数（旋钮、推子、按钮）。 要录制参数自动化，请确保在 DAW 中启用了自动化录制（如果适用），开始录制，然后移动 Rack 窗口中的任意参数。 回放时，模块参数会完全按照录制的方式移动。

许多 DAW 允许你用 MIDI 控制器控制插件参数。 要把某个 MIDI CC 控制或键盘音符映射到模块参数，请启用 DAW 的 MIDI 分配功能，晃动或点击模块的参数，然后晃动或按下物理控制器。

注意：如果你在 Rack 中删除了某个模块，DAW 的自动化片段不会被删除，但会失效。 建议删除已删除模块的自动化片段，因为 Rack 可能会把自动化槽位重新用于新创建模块的参数，这可能导致任意参数被错误地自动化。

Ableton Live

要在 Ableton Live 的 Arrangement View 或 Session View 中录制任意 Rack 模块的参数，请启用 Automation Arm 并录制一个片段。 在 VCV Rack 中调整的所有参数都会记录在轨道中。 更多细节请参阅 Live 手册中的 Automation and Editing Envelopes。

要在 Ableton Live 中把硬件 MIDI 控制（CC）映射到任意 VCV Rack 模块的参数，请启用 MIDI Map Mode（Ctrl-M 或 Cmd-M），移动一个 MIDI 控制，然后移动 Rack 中的参数。 该 MIDI 控制之后就会调整 Rack 中的该参数。 更多细节请参阅 Live 手册中的 Making custom MIDI Mappings。

离线渲染

VCV Rack 可以使用 DAW 的“render”、“bounce”、“bake”、“mixdown”或“export”功能离线渲染音频（快于实时）。 这让你只需几分钟的处理时间，就能渲染数小时的生成式模块音乐。 例如，如果你的 Rack patch 占用约 10% CPU，那么一首 10 分钟的曲子只需 1 分钟即可渲染完成。

Pro 模块

VCV Rack Pro 包含 VCV Pro Modules，这是一组 VCV Rack Free 中没有的高级效果模块。 这是作为你购买 VCV Rack Pro 的一份额外感谢而附赠的。
