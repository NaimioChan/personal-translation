常见问题

“VCV” 代表什么？

“VCV” 这个名字没有官方含义，但一些用户提出过“Virtual Control Voltage”（虚拟控制电压）或“Voltage Controlled Virtualization”（电压控制虚拟化）。 这些都是不错的猜测，但之所以选择 “VCV”，只是因为它容易记忆和输入。

VCV Rack 是我们旗舰软件产品的全名。

“Rack 用户文件夹”在哪里？

Rack 用户文件夹用于存放 Rack 可读写的数据。 你可以在 Rack 的菜单栏中选择 Help > Open user folder 打开它，或导航至

  • MacOS：~/Library/Application Support/Rack2/
  • Windows：C:\Users\<username>\AppData\Local\Rack2\
  • Linux：~/.local/share/Rack2/

以开发模式运行 Rack 时，它则是你当前的工作目录。

VCV Rack 支持触摸屏吗？

支持，请在 Rack 的菜单中禁用 “View > Lock cursor while dragging params”，并可根据喜好将 “Knob mode” 设置为 rotary。

VCV Rack 目前不支持多点触控手势。

什么是 VCV Rack 插件？

插件是一个单一的软件单元，通常由一家公司或个人开发，可以包含多个 VCV Rack 模块。 插件从 <Rack user folder>/plugins-<OS>-<CPU>/ 加载。
