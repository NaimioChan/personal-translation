插件开发教程

前置条件

  • 熟悉 C++，不过创建 Rack 插件也是学习编程和 C++ 的好途径。Rack 插件使用 C++11 编写。
  • 熟悉命令行的基本操作（cd、ls 等）。
  • 熟悉模块化合成器。数字信号处理（DSP）知识仅在创建声音发生器与处理器时才需要。
  • 下载并安装 VCV Rack。
  • 按照步骤为你的操作系统搭建构建环境。 如果使用 Rack SDK，则无需从源码构建 Rack。

在终端中运行

export RACK_DIR=<Rack SDK folder>

以指定解压后的 Rack SDK 的绝对路径。 你可以把这一行加到 ~/.bashrc 或其他 shell 环境配置中，这样每次打开终端时就不必重新定义。

创建模板插件

Rack SDK 中包含的 helper.py 脚本是创建插件模板的简便方式。 不带参数运行它即可显示文档。

为插件选择一个 slug，即一个只含字母、数字、- 或 _ 的唯一字符串。 本教程中我们使用 MyPlugin。 运行

$RACK_DIR/helper.py createplugin MyPlugin

即可在当前目录下创建名为 MyPlugin/ 的文件夹。 示例会话：

之后可以通过编辑 plugin.json 修改该清单。（参见 Manifest）。

要测试构建系统，可以在插件目录中运行 make。 如果成功，会构建出一个不含任何模块的「空」插件。 不过这仍是检查构建环境是否配置正确的好机会。

创建面板

对每个要创建的模块，请按照面板指南设计 SVG 面板图形。

本教程中，我们将创建一个 slug 为 MyModule、面板文件为 MyModule.svg 的模块。 把该文件保存到 res/，然后运行

$RACK_DIR/helper.py createmodule MyModule res/MyModule.svg src/MyModule.cpp

这会根据 SVG 文件中的组件自动生成一个 C++ 文件。 示例会话：

Module name [MyModule]: 
One-line description (optional) []:  Simple sine oscillator
Tags (comma-separated, case-insensitive, see https://vcvrack.com/manual/Manifest#modules-tags for list) []: VCO
Added MyModule to plugin.json
Found 1 params, 3 inputs, 4 outputs, 4 lights, and 0 custom widgets in "components" layer.

To enable the module, add

	extern Model* modelMyModule;

to plugin.hpp, and add

	p->addModel(modelMyModule);

to the init() function in plugin.cpp.
Source file generated at src/MyModule.cpp

按 helper 脚本的提示，把该 Model 添加到 plugin.hpp 和 plugin.cpp 中。

实现 DSP 内核

正如我们在面板指南中看到的，Rack 模块有四个基本组成部分。

  • Param：用 params[...].getValue() 读取
  • Input：用 inputs[...].getVoltage() 读取
  • Output：用 outputs[...].setVoltage(voltage) 写入
  • Light：用 lights[...].setBrightness(brightness) 写入

本教程中，我们将实现一个简单的正弦振荡器，包含 PITCH 参数、1V/oct 的 PITCH 输入、SINE 输出，以及一个以 1 Hz 闪烁的 BLINK 灯。

打开生成的 src/MyModule.cpp 源文件，在 Module 类中添加以下成员变量。

	float phase = 0.f;
	float blinkPhase = 0.f;

这些变量用于保存模块的内部状态。 然后在 process() 函数中添加以下代码，该函数每个音频帧调用一次（例如采样率为 44,100 Hz 时，每秒调用 44,100 次）。

	void process(const ProcessArgs &args) override {
		// 根据音高参数和输入计算频率
		float pitch = params[PITCH_PARAM].getValue();
		pitch += inputs[PITCH_INPUT].getVoltage();
		// 默认频率为 C4 = 261.6256f
		float freq = dsp::FREQ_C4 * std::pow(2.f, pitch);

		// 累加相位
		phase += freq * args.sampleTime;
		if (phase >= 1.f)
			phase -= 1.f;

		// 计算正弦输出
		float sine = std::sin(2.f * M_PI * phase);
		// 音频信号通常为 +/-5V
		// https://vcvrack.com/manual/VoltageStandards
		outputs[SINE_OUTPUT].setVoltage(5.f * sine);

		// 以 1Hz 闪烁指示灯
		blinkPhase += args.sampleTime;
		if (blinkPhase >= 1.f)
			blinkPhase -= 1.f;
		lights[BLINK_LIGHT].setBrightness(blinkPhase < 0.5f ? 1.f : 0.f);
	}

用 make 编译插件。 如果构建成功，可以用 make dist 生成可分发的插件包，它会放在 dist/ 中。

可以用 make install 把插件包自动安装到你的 Rack 用户文件夹。 现在打开 Rack，在 Module Browser（模块浏览器）中选择你的模块，即可测试插件。

如果在 Rack 的 Module Browser 中看不到你的插件，请检查 Rack 用户文件夹中的 log.txt 文件。 该文件记录了加载失败的插件警告，以及插件崩溃时的错误信息。

教程之后

Rack API 非常灵活，可用于创建自定义的 DSP 算法，以及处理键盘、鼠标等多种事件的自定义交互控件。 完整参考请见 Rack API 头文件或 Rack API 文档；如果你更喜欢通过例子学习，也可以研读众多开源插件的源码。

电压标准一文定义了以一致方式处理信号的行为规范。

在 VCV Community 论坛的开发者分类中搜索或新建主题，可以找到大量信息。

发布

最终你可能会想发布自己的成果。

关于如何遵循 Rack 的许可证，请参见插件许可，尤其是在开发商业插件时。 建议在插件根目录添加一个 LICENSE.txt 文件，注明你所选择的许可证（无论开源还是专有）。

检查 plugin.json 清单文件的正确性、拼写和大小写。 最后，把你的插件提交到 VCV Library，以便用户能方便地从其 VCV 账户下载你的插件。
