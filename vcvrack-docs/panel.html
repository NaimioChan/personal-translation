模块面板指南

设置

安装 Inkscape，这是一款跨平台的开源矢量图形编辑器，用于以 SVG 格式为 Rack 模块制作面板。

  • 新建一个文档。
  • 打开 “Document Properties” 面板（Shift+Ctrl+D），确认 “Units” 和 “Display units” 都设置为 “mm”。“px” 不被支持。
  • 将高度设为 128.5 mm，宽度设为 5.08 mm 的任意整数倍（Eurorack 中的 1 HP）。

设计面板

设计面板，或者打开已有的 .pdf、.ai、.svg 等文件，把其中的内容复制粘贴到你的新文档里。

VCV 的设计建议：

  • 把面板当作硬件来设计。
    • 确保旋钮和端口之间留有足够的空间，能把大拇指放进去。
    • 输出端口使用反色的背景（参见上方的 VCV VCO 面板）。
    • 标签应简洁地说明旋钮、开关和端口的用途。
  • 大致遵循 VCV 模块的图形密度和文字大小。
    • 在非高 DPI 显示器上以 100% 缩放时，文字应当清晰可读。

未经许可，不要使用他人的知识产权（IP）。 参见 VCV 插件伦理准则。

需要设计方面的帮助时，尽管去 VCV 社区提问。 你可能会遇到几位正在寻找程序员合作的平面设计师。

SVG 的限制

SVG 标准极其宽泛，很少有（甚至没有）渲染器支持完整标准。 Rack 的 SVG 渲染器不支持以下特性。

  • 文字与字体：所有文字对象都必须转换为路径。在 Inkscape 中可通过 Path > Object to Path 完成。这样做的好处是，可以避免嵌入专有字体带来的许可问题。
  • 复杂渐变：简单的双色线性渐变或许可用。
  • CSS：不过，大多数 fill-* 和 stroke-* 属性在内联 style 属性中是受支持的。

添加部件

部件（component）是可以在 C++ 中操作的图形元素。 一个部件可以是参数（旋钮、开关、按钮、滑块）、输入、输出、灯，或自定义控件（例如用 C++ 程序化绘制的 LED 显示屏）。

部件真正的图形不应画在面板上。 取而代之的是放置占位符，让 helper.py 脚本能够生成 C++ 代码。

  • 打开 “Layers” 面板（Ctrl+Shift+L），创建一个名为 components 的图层。
  • 为每个需要的部件，在 components 图层上创建一个特定的形状。
    • 使用圆形工具（F5）以圆心来定位占位符。 圆的大小无关紧要，只有中心点起作用。 C++ 中会生成一个 create*Centered() 函数调用。
    • 或者使用矩形工具（F4）以左上角来定位占位符。 只有当部件的尺寸需要在面板上定义时才应这么做，例如矩形的 LED 显示屏。 C++ 中会生成一个 create*() 函数调用。
  • 根据部件的类型设置每个形状的颜色。
    • 参数：红色 #ff0000
    • 输入：绿色 #00ff00
    • 输出：蓝色 #0000ff
    • 灯：洋红 #ff00ff
    • 自定义控件：黄色 #ffff00
  • 为了日后少花时间编辑 .cpp 文件，你可以为每个部件命名，让 C++ 中自动生成这些名字。 打开 “Object Properties” 面板（Shift+Ctrl+O），选中一个部件占位符，然后在 “Label” 字段中输入名称。 注意必须按 “Set” 或回车键才能应用新名称。
  • 用 “Layers” 面板中的眼睛图标隐藏 components 图层，然后把文件保存为 res/<module slug>.svg。

运行

<Rack SDK>/helper.py createmodule <module slug> res/<module slug>.svg src/<module slug>.cpp

即可自动把你的面板转换为一个模板 .cpp 源文件。
