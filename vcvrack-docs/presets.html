模块预设

出厂模块预设是教导和启发 Rack 插件用户的绝佳工具。 它们会存储参数值，以及（如果重写的话）来自 Module::dataToJson() 方法的内部数据。 由于预设只是 JSON 文件，它们无法存储模块的 patch 存储文件（Rack 2 引入）。

要将出厂模块预设包含进你的模块，请把模块预设文件（.vcvm）保存到

<your plugin's root dir>/presets/<module slug>/<preset name>.vcvm

并把 presets 目录添加到你的分发文件中。

DISTRIBUTABLES += presets

Rack 会在用户打开预设右键菜单时重新加载预设，因此你无需重启 Rack。

模块预设按文件名以字母顺序排序。 不过（自 Rack 2 起），如果文件名以数字开头并紧跟 _（正则 /^\d+_/），那么该前缀不会显示给用户，因此你可以应用自己的自定义预设排序。

例如，VCV Drum Machine（如图）的预设使用了以下文件名。

/presets/DrumMachine/00_House.vcvm
/presets/DrumMachine/01_House 2.vcvm
/presets/DrumMachine/02_Techno.vcvm
/presets/DrumMachine/03_IDM.vcvm
/presets/DrumMachine/04_Moombah.vcvm
/presets/DrumMachine/05_Lounge.vcvm

可以用文本编辑器编辑预设，以便只更新一部分参数。 例如，要修改 #0 和 #2 号参数而保持 #1 不变，请删除 id 为 1 的 "param" 对象。

  "params": [
    {
      "id": 0,
      "value": 0.5
    },
    {
      "id": 2,
      "value": 1.0
    }
  ]
