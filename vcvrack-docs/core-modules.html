Core（核心）插件内置于 Rack 本身，包含用于在虚拟世界与硬件世界之间进行连接的实用工具与接口。

  • 音频
  • MIDI 输入模块

  • MIDI 输出模块

音频

音频（Audio）模块将虚拟的 Rack 世界与物理硬件世界连接起来。 TO DEVICE 部分把 Rack 信号发送到硬件音频设备进行播放，FROM DEVICE 部分则把硬件信号接收进 Rack。

音频模块目前支持以下驱动。

  • macOS 上的 Core Audio
  • Windows 上的 WASAPI
  • Windows 上的 ASIO
  • Linux 上的 ALSA
  • Linux 上的 JACK

选定驱动之后，还可以为该驱动选择具体的设备。

采样率是音频设备每秒处理的音频采样数。 请注意，这个采样率与 Rack 的引擎采样率不同，后者决定 Rack 模块每秒处理的采样数。 如果两者设置为不同的采样率，就会发生采样率转换，从而导致 CPU 占用略微升高、音频保真度略微下降、延迟略微增加。

块大小决定在把数据发送给音频设备之前，音频缓冲区中存放多少个采样。 块大小越大，延迟越高（blockSize / sampleRate 秒）；块大小越小，操作系统与音频设备通信就越频繁，可能导致音频稳定性变差。 一个较好的平衡点是：不断增大块大小，直到听不到音频“爆音”为止。

注意：使用多个音频模块属于实验性功能，可能导致 Rack 崩溃或产生不稳定的音频。 出于稳定性考虑，大多数 DAW 完全避免了这一功能，只允许使用单个输入设备和单个输出设备；不过，如果你的配置下在 Rack 中使用多个音频设备能正常工作，那就尽管用吧！

MIDI 输入模块

下文介绍的每个 MIDI 输入模块都支持以下驱动。

  • macOS 上的 Core MIDI
  • Windows 上的 Windows MIDI
  • Linux 上的 ALSA
  • Linux 上的 JACK
  • 游戏手柄
  • 电脑键盘

游戏手柄 MIDI 驱动允许把 USB 电子游戏控制器用作 CV 与门信号源，作为 MIDI 控制器的一种廉价替代方案。 手柄按键被映射为 MIDI 音符门限，依次从 C-1、C#-1、D-1 等音开始。 摇杆轴被映射为 MIDI CC 消息，依次从 CC0、CC1、CC2 等开始，并使用一种非标准的 MIDI 扩展，以允许使用负的 CC 值。

电脑键盘 MIDI 驱动在 Rack 窗口处于焦点状态时，于按键按下时生成 MIDI 音符。 这个两行的虚拟 MIDI 键盘使用四行电脑按键，跨度约为两个半八度，可以用 ` 键和 1 键向下、向上移调。

以下是 QWERTY（美式）键盘的布局。

MIDI-CV

  • V/OCT 为最后按住的 MIDI 音符生成 1V/oct 音高信号。
  • GATE 在按住按键时生成 10V。连奏（legato）弹奏音符时不会重新触发。
  • VEL 根据力度生成 0V 到 10V 的 CV 信号
  • AFT 生成触后（aftertouch）CV（即通道压力，而非复音触后）
  • PW 生成弯音轮 CV，范围从 -5V 到 5V
  • MW 生成调制轮 CV。
  • CLK 每收到一个 24-PPQN MIDI 时钟就生成一个时钟。
  • CLK/N 按照在面板上单击右键并选择 CLK/N rate 所设定的分频来生成时钟。
  • RTRG 在按下新音符时生成触发，无论是否连奏。
  • STRT、STOP 和 CONT 在 MIDI 设备发送开始、停止或继续事件时生成触发。

在面板上单击右键可启用复音，并选择复音通道数。

  • Rotate（轮转）：每个按下的音符选择下一个可用通道；若没有可用通道，则选择下一个通道，到达最后一个通道后回绕到第一个通道。
  • Reuse（复用）：如果此前使用过具有相同 MIDI 音符的通道，则复用它；否则采用 Reset 模式的行为。
  • Reset（重置）：每个按下的音符选择编号最低的可用通道。释放音符时，其上方的所有通道依次下移。

多个 MIDI 接口可以同时使用同一个驱动，例如把 MIDI-CV 与 MIDI-CC 的功能结合起来使用。

MIDI-CC

每个输出把 0 到 127 的 MIDI CC（连续控制器）消息映射为 0V 到 10V 的 CV 信号。 某些驱动（例如游戏手柄驱动）会生成 -128 到 127 的非标准 MIDI 值，这些值被映射为 -10V 到 10V。 目前还不支持 14 位 MIDI CC 消息。

点击与输出端口位置对应的数字显示屏，即可为每个输出指定特定的 CC 编号。 端口处于“学习”（learn）模式时会显示 LRN 指示。 输入一个数字，或者拨动控制器，即可设定 CC 编号。

MIDI-Gate

MIDI-Gate 与 MIDI-CC 类似，区别在于：当某个特定音符被按住时，它生成 10V 的门信号。 对于会连续发送即时的音符开/关（note ON/OFF）消息的 MIDI 音序器和鼓机，则会生成 1 ms 的触发。

若要生成与音符力度相对应（而非固定 10V）的 CV 信号，请在面板上单击右键并启用 Velocity（力度）模式。 例如，对于带有力度感应打击垫的 MIDI 控制器，这可以很方便地用来设定打击类音色的幅度。

MIDI-Map

通过硬件 MIDI CC 控制器来控制其他 Rack 模块的参数。

要把一个硬件控件映射到 Rack 参数，请点击 MIDI-Map 显示屏中一个标为“Unmapped”（未映射）的槽位。 其文字会变为“Mapping…”（映射中…）。 然后点击 Rack 中另一个模块的某个参数（旋钮、推子、按钮等）。 接着转动你 MIDI 控制器上的旋钮/推子，或按下某个 CC 按钮。 （这些步骤的先后顺序可以互换。） 该参数现在已被映射，使用 MIDI 控制器时它就会随之变化。

MIDI 输出模块

以下模块向外部硬件发送 MIDI 消息，例如桌面合成器、Eurorack 模块和鼓机。

CV-MIDI

把 Rack 中的 CV 转换为供外部硬件使用的 MIDI。

适合用 Rack 来演奏硬件合成器。

CV-CC

把 Rack 中的 CV 转换为供外部硬件使用的 MIDI CC（连续控制器）命令。

适合用 Rack 来控制硬件合成器的参数。

CV-Gate

把 Rack 中的门信号转换为供外部硬件使用的 MIDI 音符开/关命令。

适合用 Rack 来演奏硬件鼓机。

Blank

适合在机架中为模块之间留出空隙。

你可以水平拖动面板边缘来调整其尺寸，最小为 3HP。

Notes

适合为你的 patch 添加 patch 备注、用于组织的分区标题、说明文字以及作者信息。 你可以用 Ctrl+C 和 Ctrl+V 复制粘贴文本。
