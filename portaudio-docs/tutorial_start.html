PortAudio 教程

本教程通过一个动手示例，带你用 PortAudio 发出声音。如果你想先自顶向下概览 PortAudio API，请看 PortAudio API 概览。

下载

你首先要做的是下载 PortAudio 源代码，既可以从网站下载 tarball，也可以从 Subversion 仓库获取。

编译

下载 PortAudio 之后需要编译它，具体做法取决于你的环境：

  • Windows
    • 在 Windows 上用 Microsoft Visual Studio 构建 PortAudio
    • 在 Windows 上用 MinGW-w64 构建 PortAudio
    • 在 Windows 上用 MinGW 构建 PortAudio
    • 在 Windows 上用 MSVC 构建带 ASIO 支持的 PortAudio
  • Mac OS X
    • 在 Mac OS X 上构建 PortAudio
  • POSIX
    • 在 Linux 上构建 PortAudio

你也可以用 CMake 为 Windows、OS X 或 Linux 上的 PortAudio 生成工程文件，或把 PortAudio 方便地纳入你自己的 CMake 工程。见用 CMake 构建 PortAudio。

许多带 GCC/make 的平台可以用简单的 ./configure && make 组合，然后直接在代码里使用生成的库。

用 PortAudio 编程

以下是使用回调方式编写 PortAudio 应用程序的步骤：

  • 编写一个回调函数，在需要处理音频时由 PortAudio 调用。
  • 初始化 PA 库，并打开一个用于音频 I/O 的流。
  • 启动流。此后 PA 会在后台反复调用你的回调函数。
  • 在回调中，你可以从 inputBuffer 读取音频数据，和/或向 outputBuffer 写入数据。
  • 通过在回调中返回 1 或调用停止函数来停止流。
  • 关闭流并终止库。

除这种“回调”架构外，V19 还支持“阻塞式 I/O”模型，它使用 read 与 write 调用，对非音频领域的程序员可能更熟悉。注意，目前并非所有 API 都支持这一功能。

本教程将展示如何用回调架构播放锯齿波。教程的大部分内容取自文件 paex_saw.c，它是 PortAudio 发行包的一部分。读完本教程，你就掌握了编写音频程序所需的基础知识。如果需要更多示例代码，可以查看 PortAudio 发行包中的 "examples" 和 "test" 目录。另一个很好的信息来源是 portaudio.h 的 Doxygen 页面，其中记录了整个 V19 API。另见 PortAudio wiki 上关于 PortAudio 编程的技巧页面。
