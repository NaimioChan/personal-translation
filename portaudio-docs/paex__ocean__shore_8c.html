详细说明

使用 Gardner 方法生成粉红噪声，并制造“波浪”。演示如何借助 PA ringbuffer 实现的无锁 FIFO，在音频回调与外部之间传递数据。

James McCartney 建议的优化使用一棵树来选择要替换哪个随机值。

x x x x x x x x x x x x x x x x x x x x x x x x x x x x x x x

这棵树通过统计递增索引的尾随零来生成。当索引为 0 时，不选择任何随机数。
