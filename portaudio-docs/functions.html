非茗的翻译文档库

数据成员列表

以下列出所有已文档化的结构体与联合体字段，并附指向各字段所属结构体或联合体文档的链接：

- c -

  • channelCount : PaStreamParameters
  • channelMap : PaMacCoreStreamInfo
  • channelMapSize : PaMacCoreStreamInfo
  • channelMask : PaWasapiStreamInfo, PaWinDirectSoundStreamInfo, PaWinWDMKSInfo
  • channels : PaWDMKSDirectionSpecificStreamInfo
  • currentTime : PaStreamCallbackTimeInfo

- d -

  • defaultHighInputLatency : PaDeviceInfo
  • defaultInputDevice : PaHostApiInfo
  • defaultLowInputLatency : PaDeviceInfo
  • defaultOutputDevice : PaHostApiInfo
  • device : PaStreamParameters
  • deviceCount : PaHostApiInfo
  • deviceProductGuid : PaWinWDMKSDeviceInfo

- e -

  • endpointPinId : PaWDMKSDirectionSpecificStreamInfo
  • errorCode : PaHostErrorInfo
  • errorText : PaHostErrorInfo

- f -

  • filterPath : PaWinWDMKSDeviceInfo
  • flags : PaMacCoreStreamInfo, PaWasapiStreamInfo, PaWinDirectSoundStreamInfo, PaWinWDMKSInfo
  • framesPerBuffer : PaWinDirectSoundStreamInfo
  • framesPerHostBuffer : PaWDMKSDirectionSpecificStreamInfo

- h -

  • hostApi : PaDeviceInfo
  • hostApiSpecificStreamInfo : PaStreamParameters
  • hostApiType : PaAsioStreamInfo, PaHostErrorInfo, PaMacCoreStreamInfo, PaWasapiStreamInfo, PaWinDirectSoundStreamInfo, PaWinMmeStreamInfo, PaWinWDMKSInfo
  • hostProcessorOutput : PaWasapiStreamInfo

- i -

  • inputBufferAdcTime : PaStreamCallbackTimeInfo
  • inputLatency : PaStreamInfo

- m -

  • muxNodeId : PaWDMKSDirectionSpecificStreamInfo

- n -

  • name : PaDeviceInfo, PaHostApiInfo
  • noOfPackets : PaWinWDMKSInfo

- o -

  • outputBufferDacTime : PaStreamCallbackTimeInfo
  • outputLatency : PaStreamInfo

- p -

  • passthrough : PaWasapiStreamInfo

- s -

  • sampleFormat : PaStreamParameters
  • sampleRate : PaStreamInfo
  • size : PaAsioStreamInfo, PaWasapiStreamInfo, PaWinDirectSoundStreamInfo, PaWinMmeStreamInfo, PaWinWDMKSInfo
  • streamCategory : PaWasapiStreamInfo
  • streamingSubType : PaWDMKSDirectionSpecificStreamInfo
  • streamOption : PaWasapiStreamInfo
  • structVersion : PaDeviceInfo, PaHostApiInfo, PaStreamInfo
  • suggestedLatency : PaStreamParameters

- t -

  • threadPriority : PaWasapiStreamInfo
  • topologyPath : PaWinWDMKSDeviceInfo
  • type : PaHostApiInfo

- v -

  • version : PaAsioStreamInfo, PaMacCoreStreamInfo, PaWasapiStreamInfo, PaWinDirectSoundStreamInfo, PaWinMmeStreamInfo, PaWinWDMKSInfo
  • versionControlRevision : PaVersionInfo
  • versionText : PaVersionInfo
