字段说明

channelCount

int PaStreamParameters::channelCount

要传递给流回调、或由 Pa_ReadStream() 或 Pa_WriteStream() 访问的声道数。取值范围为 1 到 device 参数所指定设备在 PaDeviceInfo 记录中的 maxInputChannels 值。

定义于文件 portaudio.h 第 562 行。

device

PaDeviceIndex PaStreamParameters::device

取值范围为 0 到 (Pa_GetDeviceCount()-1) 的有效设备索引，用于指定要使用的设备；也可以是特殊常量 paUseHostApiSpecificDeviceSpecification，表示实际要使用的 设备在 hostApiSpecificStreamInfo 中指定。该字段不得设为 paNoDevice。

定义于文件 portaudio.h 第 555 行。

hostApiSpecificStreamInfo

void* PaStreamParameters::hostApiSpecificStreamInfo

指向宿主 API 专用数据结构的可选指针，其中包含用于设备设置和/或流处理的附加信息。hostApiSpecificStreamInfo 对正确运行从来不是必需的，未使用时应设为 NULL。

定义于文件 portaudio.h 第 587 行。

sampleFormat

PaSampleFormat PaStreamParameters::sampleFormat

提供给流回调、Pa_ReadStream() 或 Pa_WriteStream() 的缓冲区的采样格式。它可以是 PaSampleFormat 枚举所描述的任何格式。

定义于文件 portaudio.h 第 568 行。

suggestedLatency

PaTime PaStreamParameters::suggestedLatency

期望的延迟，以秒为单位。在可行的情况下，实现应依据这些参数配置各自的延迟。实现应把实际延迟向上取整到下一个可行的值，除非建议延迟超过设备的上限。

已打开流的实际延迟值可以用 Pa_GetStreamInfo() 返回的 PaStreamInfo 结构体的 inputLatency 和 outputLatency 字段获取。

另见
PaDeviceInfo 中的 default*Latency，PaStreamInfo 中的 *Latency

定义于文件 portaudio.h 第 580 行。
