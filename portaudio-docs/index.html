PortAudio

概述

PortAudio 是一个跨平台的开源 C 语言库，用于实时音频输入与输出。该库提供的函数让软件能够从计算机的硬件音频接口获取并输出实时音频流。它的设计目标是简化跨平台音频应用的编写，同时通过隐藏直接处理各个原生音频 API 的复杂性，简化音频软件的一般开发工作。PortAudio 用于实现录音、编辑与混音应用、软件合成器、效果处理器、音乐播放器、网络电话应用、软件无线电，等等。支持的平台包括 MS Windows、Mac OS X 和 Linux。第三方语言绑定使得可以从其他编程语言调用 PortAudio，包括 Java、C++、C#、Python、PureBasic、FreePascal 和 Lazarus。
