在 Windows 上用 MinGW 构建 PortAudio

用 MinGW 构建 Windows 版 PortAudio

本文档包含过时或已失效的信息。请参阅我们 Wiki 上新的 MinGW 说明草稿：PortAudio Wiki：用 MinGW 构建 PortAudio 的说明 如果你是 MinGW 新手，可以考虑 MinGW-64：在 Windows 上用 MinGW-w64 构建 PortAudio。它是较新的项目。

= MinGW/MSYS =

摘自 [http://www.mingw.org MinGW 项目页]：

MinGW：一组可自由获取、可自由分发的 Windows 专用头文件和导入库，用于增强 GNU 编译器集合（GCC）及其相关工具（GNU binutils）。MinGW 提供一套完整的开源编程工具集，适合开发不依赖任何第三方 C 运行时 DLL 的原生 Windows 程序。

MSYS：一个提供 POSIX 兼容 Bourne shell 环境的最小系统（Minimal SYStem），附带少量 UNIX 命令行工具。它主要用于执行构建开源软件所需的 configure 脚本和 Makefile，也可作为通用命令行界面替代 Windows cmd.exe。

MinGW 提供编译器/链接器工具链，而实际运行 PortAudio 的 configure 脚本需要 MSYS。

安装好 MinGW 和 MSYS 后（参见 [http://www.mingw.org/MinGWiki MinGW-Wiki]），打开 MSYS shell，运行那个经典的命令：

./configure
make
make install

以上操作应能生成可用的版本，不过你可能想给 configure 加上 '–prefix=<path-to-install-dir>'。

'./configure –help' 说明了可以调整哪些内容。

— Mikael Magnusson
