函数说明

PaWinMME_GetStreamInputHandle()

HWAVEIN PaWinMME_GetStreamInputHandle ( PaStream * stream, int handleIndex )

获取 PortAudio WinMME 流使用的波形输入句柄。

参数
参数说明
stream要查询的流。
handleIndex要获取的波形输入句柄的索引，从 0 开始。取值范围应为 [0, PaWinMME_GetStreamInputHandleCount(stream)-1]。
返回值
有效的波形输入句柄；若出错则为 NULL。

PaWinMME_GetStreamInputHandle

PaWinMME_GetStreamInputHandleCount()

int PaWinMME_GetStreamInputHandleCount ( PaStream * stream)

获取 PortAudio WinMME 流使用的波形输入句柄数量。若流仅用于输出则返回零。

返回值
非负值，表示波形输入句柄的数量；若 PortAudio 未初始化或遇到错误，则为 PaErrorCode（总是负数）。
