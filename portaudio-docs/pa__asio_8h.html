函数说明

PaAsio_GetAvailableBufferSizes()

PaError PaAsio_GetAvailableBufferSizes ( PaDeviceIndex device, long * minBufferSizeFrames, long * maxBufferSizeFrames, long * preferredBufferSizeFrames, long * granularity )

获取指定设备的合法原生缓冲区大小，以采样帧为单位。

参数
参数说明
device所查询设备的全局索引。
minBufferSizeFrames指向用于接收最小缓冲区大小值的位置的指针。
maxBufferSizeFrames指向用于接收最大缓冲区大小值的位置的指针。
preferredBufferSizeFrames指向用于接收首选缓冲区大小值的位置的指针。
granularity指向用于接收“粒度”的位置的指针。该值决定在 minBufferSizeFrames 与 maxBufferSizeFrames 之间计算合法值所用的步长。如果 granularity 为 -1，则可用的缓冲区大小值为 2 的幂。
另见
ASIO SDK 中的 ASIOGetBufferSize。
注意
：该函数以前称为 PaAsio_GetAvailableLatencyValues。为了向后兼容，有一个 #define 把 PaAsio_GetAvailableLatencyValues 映射到本函数。

PaAsio_GetInputChannelName()

PaError PaAsio_GetInputChannelName ( PaDeviceIndex device, int channelIndex, const char ** channelName )

获取指向一个字符串的指针，该字符串包含指定输入声道的名称。该字符串在调用 Pa_Terminate 之前保持有效。

该字符串长度不超过 32 个字符（含结尾的空字符）。

该字符串长度不超过 32 个字符（含结尾的空字符）。

PaAsio_SetStreamSampleRate()

PaError PaAsio_SetStreamSampleRate ( PaStream * stream, double sampleRate )

设置已打开的 paASIO 流的采样率。

参数
参数说明
stream要操作的流。
sampleRate新的采样率。

注意，如果流已经在运行，而 ASIO 驱动不支持切换运行中流的采样率，该函数可能失败。

如果 stream 不是 paASIO 流，则返回 paIncompatibleStreamHostApi。

PaAsio_ShowControlPanel()

PaError PaAsio_ShowControlPanel ( PaDeviceIndex device, void * systemSpecific )

显示指定设备的 ASIO 控制面板。

参数
参数说明
device要显示其控制面板的设备的全局索引。
systemSpecific在 Windows 上为调用应用程序的主窗口句柄，在 Macintosh 上该值应为 0。
