枚举与查询 PortAudio 设备

查询设备

像本教程前面那样使用默认设备通常就够了，但有时你需要从系统中可用设备的列表里明确选择设备。要看一个可运行的示例，请查看 PortAudio 源代码 tests/ 目录中的 pa_devs.c。为此，你需要先初始化 PortAudio 并查询设备数量：

int numDevices;
 
numDevices = Pa_GetDeviceCount();
if( numDevices < 0 )
{
    printf( "ERROR: Pa_CountDevices returned 0x%x\n", numDevices );
    err = numDevices;
    goto error;
}

如果你想获取每个设备的信息，只需像下面这样循环遍历：

const   PaDeviceInfo *deviceInfo;
 
for( i=0; i<numDevices; i++ )
{
    deviceInfo = Pa_GetDeviceInfo( i );
    ...
}

Pa_DeviceInfo 结构体包含大量信息，例如设备名称、与设备关联的默认延迟等等。该结构体具有以下字段：

int     structVersion
const char *    name
PaHostApiIndex  hostApi
int     maxInputChannels
int     maxOutputChannels
PaTime  defaultLowInputLatency
PaTime  defaultLowOutputLatency
PaTime  defaultHighInputLatency
PaTime  defaultHighOutputLatency
double  defaultSampleRate

你可能会注意到，仅凭这些信息无法判断某个采样率是否受支持。这是因为有些设备支持一定范围的采样率，有些设备支持一组采样率，还有一些设备支持某些采样率与声道数的组合而不支持另一些。为解决这个问题，PortAudio 提供了一个函数，用于按给定格式测试某个设备：

const PaStreamParameters *inputParameters;
const PaStreamParameters *outputParameters;
double desiredSampleRate;
...
PaError err;
 
err = Pa_IsFormatSupported( inputParameters, outputParameters, desiredSampleRate );
if( err == paFormatIsSupported )
{
   printf( "Hooray!\n");
}
else
{
   printf("Too Bad.\n");
}

稍后将演示如何填写 inputParameters 和 outputParameters 字段。

当你找到喜欢的配置，或者想直接试一试的配置之后，就可以填写 PaStreamParameters 结构体并调用 Pa_OpenStream 来打开流：

double srate = ... ;
PaStream *stream;
unsigned long framesPerBuffer = ... ; //could be paFramesPerBufferUnspecified, in which case PortAudio will do its best to manage it for you, but, on some platforms, the framesPerBuffer will change in each call to the callback
PaStreamParameters outputParameters;
PaStreamParameters inputParameters;
 
bzero( &inputParameters, sizeof( inputParameters ) ); //not necessary if you are filling in all the fields
inputParameters.channelCount = inChan;
inputParameters.device = inDevNum;
inputParameters.hostApiSpecificStreamInfo = NULL;
inputParameters.sampleFormat = paFloat32;
inputParameters.suggestedLatency = Pa_GetDeviceInfo(inDevNum)->defaultLowInputLatency ;
inputParameters.hostApiSpecificStreamInfo = NULL; //See you specific host's API docs for info on using this field
 
 
bzero( &outputParameters, sizeof( outputParameters ) ); //not necessary if you are filling in all the fields
outputParameters.channelCount = outChan;
outputParameters.device = outDevNum;
outputParameters.hostApiSpecificStreamInfo = NULL;
outputParameters.sampleFormat = paFloat32;
outputParameters.suggestedLatency = Pa_GetDeviceInfo(outDevNum)->defaultLowOutputLatency ;
outputParameters.hostApiSpecificStreamInfo = NULL; //See you specific host's API docs for info on using this field
 
err = Pa_OpenStream(
                &stream,
                &inputParameters,
                &outputParameters,
                srate,
                framesPerBuffer,
                paNoFlag, //flags that can be used to define dither, clip settings and more
                portAudioCallback, //your callback function
                (void *)this ); //data to be passed to callback. In C++, it is frequently (void *)this
//don't forget to check errors!
