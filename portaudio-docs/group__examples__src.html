示例程序

文件

类型成员说明
filepa_devs.c列出可用设备，包括设备信息
filepa_fuzz.c像法兹效果器那样使输入失真
filepaex_mono_asio_channel_select.c在指定的 ASIO 声道上播放单声道正弦波
filepaex_ocean_shore.c使用 Gardner 方法生成粉红噪声并制造“波浪”。演示如何借助 PA ringbuffer 实现的无锁 FIFO 在音频回调中收发数据
filepaex_pink.c使用 Gardner 方法生成粉红噪声
filepaex_read_write_wire.c通过把输入直接接通到输出，测试全双工阻塞式 I/O
filepaex_record.c把输入录制到数组；将数组保存到文件；回放录制的数据
filepaex_record_file.c把输入录制到文件，然后从文件回放录制的数据（目前仅限 Windows）
filepaex_saw.c播放简单的（有混叠的）锯齿波
filepaex_sine.c播放若干秒的正弦波
filepaex_wmme_ac3.c使用 WMME 专用接口把原始 AC3 数据发送到 S/PDIF 输出
filepaex_wmme_surround.c使用 WMME 专用的 channelMask 请求 5.1 环绕声输出
filepaex_write_sine.c使用阻塞式 API（Pa_WriteStream()）播放若干秒的正弦波
filepaex_write_sine_nonint.c使用阻塞式 API（Pa_WriteStream()）播放非交错正弦波
