PaWasapiWinrt_PopulateDeviceList()

PaError PaWasapiWinrt_PopulateDeviceList ( const unsigned short ** pId, const unsigned short ** pName, const PaWasapiDeviceRole * pRole, unsigned int count, int bOutput )

填充设备列表。

默认情况下，实现会把 DEVINTERFACE_AUDIO_RENDER 与 DEVINTERFACE_AUDIO_CAPTURE 作为默认设备。若通过 PaWasapiWinrt_SetDefaultDeviceId() 提供了设备 Id，则这些设备 Id 将作为设备列表的默认且唯一的设备。

通过填充设备列表，可以把系统额外可用的音频设备提供给 PA，这些设备可通过 Windows::Devices::Enumeration::DeviceInformation::FindAllAsync(selector) 获取，其中 selector 可通过 Windows::Media::Devices::MediaDevice::GetAudioRenderSelector() 或 Windows::Media::Devices::MediaDevice::GetAudioCaptureSelector() API 获取。

调用完成后，指针引用的内存即可释放，因为实现会保留自己的副本。

调用此函数后，必须调用 PaWasapi_UpdateDeviceList() 来更新实现的内部设备列表。

示例见重要说明。

注意
仅限 UWP/WinRT 平台。
参数
参数说明
pId设备 Id 数组，指向 16 位 Unicode 字符串（WCHAR）指针数组的指针。若为 NULL 且 count 也为 0，则设备 Id 将重置为默认值。必需。
pName设备名数组，指向 16 位 Unicode 字符串（WCHAR）指针数组的指针。可选。
pRole设备角色数组，详见 PaWasapiDeviceRole 与 PaWasapi_GetDeviceRole()。可选。
count设备数量，即数组元素（pId、pName、pRole）的个数。设备数量上限受 PA_WASAPI_DEVICE_MAX_COUNT 限制。
bOutput输出（渲染）为 TRUE (1)，输入（采集）为 FALSE (0)。
返回值

PaWasapiWinrt_SetDefaultDeviceId()

PaError PaWasapiWinrt_SetDefaultDeviceId ( const unsigned short * pId, int bOutput )

设置默认设备 Id。

若未显式提供设备 Id，实现默认会使用 DEVINTERFACE_AUDIO_RENDER 与 DEVINTERFACE_AUDIO_CAPTURE 的 Id。这些默认 Id 无法在 UWP/WinRT 平台上使用独占模式，因此必须在调用 Pa_OpenStream() 之前通过此 API 显式提供设备 Id。

UWP 平台上的设备 Id 可通过 Windows::Media::Devices::MediaDevice::GetDefaultAudioRenderId() 或 Windows::Media::Devices::MediaDevice::GetDefaultAudioCaptureId() API 获取。

调用完成后，指针引用的内存即可释放，因为实现会保留自己的副本。

请求独占模式时，在调用 Pa_IsFormatSupported() 之前调用此函数。

仅限 UWP/WinRT 平台。
