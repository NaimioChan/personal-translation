工具函数

除了本教程其他部分介绍的函数之外，PortAudio 还提供了一些在各种场合都有用的工具函数。你可以阅读 portaudio.h 参考文档了解完整的 V19 API 细节，但我们会在这里介绍基本内容。

版本信息

PortAudio 提供两个函数来确定 PortAudio 版本。当你把 PortAudio 用作动态库时这些函数最有用，但在其他时候也可能有用。

int             Pa_GetVersion (void)
const char *    Pa_GetVersionText (void)

错误文本

PortAudio 允许你根据错误编号获取错误文本。

const char *    Pa_GetErrorText (PaError errorCode)

流状态

PortAudio 的流存在 3 种状态：活动、已停止和回调已停止。如果流处于回调已停止状态，需要先停止它才能再次启动它。如果需要查询某个 PortAudio 流的状态，有两个函数可用来完成：

PaError     Pa_IsStreamStopped (PaStream *stream)
PaError     Pa_IsStreamActive (PaStream *stream)

流信息

如果需要获取某个流的有关信息，例如延迟和采样率信息，也有对应的函数：

const PaStreamInfo *    Pa_GetStreamInfo (PaStream *stream)

流时间

如果需要让显示刷新或 MIDI 输出等其他活动与 PortAudio 回调同步，你需要知道按流回调时间戳所用的同一时间基准所计的当前时间。

PaTime  Pa_GetStreamTime (PaStream *stream)

用法

要确定回调占用了多少 CPU，请使用：

double  Pa_GetStreamCpuLoad (PaStream *stream)

其他工具

这些函数让你可以根据采样格式确定采样的大小，以及睡眠给定的时长。睡眠函数不应用于精确定时或同步，因为它对所等待的确切时长几乎不做保证。它最常用于测试。

PaError Pa_GetSampleSize (PaSampleFormat format)
void    Pa_Sleep (long msec)
