阻塞读写函数

PortAudio V19 通过一项称为阻塞式 I/O 的特性，比之前的版本向前迈进了一大步。虽然它的性能可能低于本教程前面介绍的回调方式，但阻塞式 I/O 更易于理解，在某些情况下比回调方式更能兼容第三方系统。多数刚开始做音频编程的人也觉得阻塞式 I/O 更容易上手。

阻塞式 I/O 的工作方式与回调方式大体相同，区别在于：你不是提供一个函数来提供（或消费）音频数据，而是必须按固定的时间间隔把数据送入 PortAudio（或从中取出数据），这一般在一个循环里进行。下面的示例摘自 patest_read_write_wire.c，展示了如何打开默认设备，并在设定的一段时间内把数据从它的输入传递到输出。注意，我们使用默认的高延迟值来帮助避免欠载，因为我们通常从优先级相对较低的线程读写音频数据，而且要让阻塞式 I/O 工作，通常需要额外的缓冲。

注意，目前并非所有 API 都实现了阻塞式 I/O，因此为了获得最大的可移植性或性能，你仍然会想使用回调。

/* -- initialize PortAudio -- */
err = Pa_Initialize();
if( err != paNoError ) goto error;
 
/* -- setup input and output -- */
inputParameters.device = Pa_GetDefaultInputDevice(); /* default input device */
inputParameters.channelCount = NUM_CHANNELS;
inputParameters.sampleFormat = PA_SAMPLE_TYPE;
inputParameters.suggestedLatency = Pa_GetDeviceInfo( inputParameters.device )->defaultHighInputLatency ;
inputParameters.hostApiSpecificStreamInfo = NULL;
 
outputParameters.device = Pa_GetDefaultOutputDevice(); /* default output device */
outputParameters.channelCount = NUM_CHANNELS;
outputParameters.sampleFormat = PA_SAMPLE_TYPE;
outputParameters.suggestedLatency = Pa_GetDeviceInfo( outputParameters.device )->defaultHighOutputLatency;
outputParameters.hostApiSpecificStreamInfo = NULL;
 
/* -- setup stream -- */
err = Pa_OpenStream(
          &stream,
          &inputParameters,
          &outputParameters,
          SAMPLE_RATE,
          FRAMES_PER_BUFFER,
          paClipOff,      /* we won't output out of range samples so don't bother clipping them */
          NULL, /* no callback, use blocking API */
          NULL ); /* no callback, so no callback userData */
if( err != paNoError ) goto error;
 
/* -- start stream -- */
err = Pa_StartStream( stream );
if( err != paNoError ) goto error;
printf("Wire on. Will run one minute.\n"); fflush(stdout);
 
/* -- Here's the loop where we pass data from input to output -- */
for( i=0; i<(60*SAMPLE_RATE)/FRAMES_PER_BUFFER; ++i )
{
   err = Pa_WriteStream( stream, sampleBlock, FRAMES_PER_BUFFER );
   if( err ) goto xrun;
   err = Pa_ReadStream( stream, sampleBlock, FRAMES_PER_BUFFER );
   if( err ) goto xrun;
}
/* -- Now we stop the stream -- */
err = Pa_StopStream( stream );
if( err != paNoError ) goto error;
 
/* -- don't forget to cleanup! -- */
err = Pa_CloseStream( stream );
if( err != paNoError ) goto error;
 
Pa_Terminate();
return 0;
