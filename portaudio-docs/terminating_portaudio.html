关闭流并终止 PortAudio

用完一个流之后，应当关闭它以释放资源：

err = Pa_CloseStream( stream );
if( err != paNoError ) goto error;

我们在初始化 PortAudio中已经提到过这一点，但以防你忘了，用完一定要终止 PortAudio：

err = Pa_Terminate( );
if( err != paNoError ) goto error;
