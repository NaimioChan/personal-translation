宏定义说明

paMacCoreChangeDeviceParameters

#define paMacCoreChangeDeviceParameters (0x01)

获取指定设备的音频工作群组。（仅 Mac OS 11 及以上版本）

参数
参数说明
device所查询的 PortAudio 设备的全局索引。
workgroup指向接收工作群组值的位置的指针。
另见
CoreAudio SDK 中的 kAudioDevicePropertyIOThreadOSWorkgroup。标志 以下标志改变 mac 平台上 PA 的行为。它们可以用按位或组合起来。这些标志在打开设备和检查设备时都应有效。允许 PortAudio 更改设备的帧大小等设置，这可以带来低得多的延迟，但如果其他程序正在使用该设备，这样做可能会干扰设备，即使你只是查询设备。

定义于文件 pa_mac_core.h 第 171 行。

paMacCoreConversionQualityMin

#define paMacCoreConversionQualityMin (0x0100)

如果需要，这些标志设置 SR 转换的质量。这种奇怪的顺序使最高质量成为默认值。

定义于文件 pa_mac_core.h 第 180 行。

paMacCoreFailIfConversionRequired

#define paMacCoreFailIfConversionRequired (0x02)

与上述标志组合使用时，除非设备支持精确的采样率，否则会导致打开流失败。

定义于文件 pa_mac_core.h 第 176 行。

paMacCoreMinimizeCPU

#define paMacCoreMinimizeCPU (0x0101)

此设置用于将 CPU 占用降到最低，即便这意味着打断设备。

定义于文件 pa_mac_core.h 第 201 行。

paMacCoreMinimizeCPUButPlayNice

#define paMacCoreMinimizeCPUButPlayNice (0x0100)

此设置用于将 CPU 占用降到最低，同时仍然对设备友好。

定义于文件 pa_mac_core.h 第 199 行。

paMacCorePlayNice

#define paMacCorePlayNice (0x00)

以下是一些（上述）标志的 "预设" 组合，用于得到一些常见配置。这是过度设计，但如果以后增加更多标志就不算多余了。这是默认设置：尽可能多地进行采样率转换，尽可能少地干扰设备。

定义于文件 pa_mac_core.h 第 194 行。

paMacCorePro

#define paMacCorePro (0x01)

此设置针对专业音频应用调优。它允许在输入和输出上进行 SR 转换，但它会尝试在设备上设置合适的 SR。

定义于文件 pa_mac_core.h 第 197 行。
