在 Linux 上构建 PortAudio

注意：本页尚未经过审校，可能存在错误。

安装 ALSA 开发套件

OSS 声音 API 非常老旧，支持也不完善。推荐使用 ALSA 声音 API。PortAudio 的 configure 脚本会查找 ALSA SDK。在 Ubuntu 上可以用下面的命令安装 ALSA SDK：

sudo apt-get install libasound-dev

在你的机器上，你可能需要用 yum 或其他包管理器来代替 apt-get。如果不安装 ALSA，测试时可能会收到提示说没有任何音频设备。

关于 ALSA 的更多信息见：http://www.alsa-project.org/

配置并编译 PortAudio

在 Linux 环境中，你可以用标准的 configure/make 工具构建 PortAudio：

./configure && make

这会按你的系统上实际找到的组合，用 Jack、ALSA 和 OSS 构建 PortAudio。例如，如果你有 Jack 和 OSS 而没有 ALSA，构建时就只用 Jack 和 OSS，不用 ALSA。这一步还会构建若干测试程序，它们位于 PortAudio 的 bin 目录中。运行其中一些测试来确认 PortAudio 工作正常是个好主意。

在项目中使用 PortAudio

要在你的应用中使用 PortAudio，直接安装 .so 文件即可：

sudo make install

这样构建的项目在运行时要求目标系统上安装了 PortAudio。如果你想构建一个更自包含的可执行文件，可以使用 libportaudio.a 文件：

cp lib/.libs/libportaudio.a /YOUR/PROJECT/DIR

在某些系统上，你可能需要用：

cp /usr/local/lib/libportaudio.a /YOUR/PROJECT/DIR

你可能还需要把 PortAudio 的 include/ 目录下的 portaudio.h 复制到你的项目中。注意，你通常需要链接用到的相应库，例如 ALSA 和 JACK，以及 librt 和 libpthread。例如：

gcc main.c libportaudio.a -lrt -lm -lasound -ljack -pthread -o YOUR_BINARY

Linux 扩展

注意，ALSA 的 PortAudio 后端为标准 API 增加了若干你可以利用的扩展。要使用这些函数，务必包含 PortAudio 文件夹中 include 目录下的 pa_linux_alsa.h 文件。该文件包含以下函数的进一步文档：

PaAlsaStreamInfo/PaAlsa_InitializeStreamInfo：!PaAlsaStreamInfo 类型的对象可用于 !PaStreamParameters 对象的 !hostApiSpecificStreamInfo 属性，以便指定要直接打开的 ALSA 设备名。在用 PaAlsa_InitializeStreamInfo 初始化对象之后，通过 !PaAlsaStreamInfo.deviceString 指定设备。

PaAlsa_EnableRealtimeScheduling：PA ALSA 通过扩展 PaAlsa_EnableRealtimeScheduling 支持音频回调线程的实时调度（使用 FIFO pthread 调度策略）。在启动流之前调用它，并把 enableScheduling 参数设为 true 或 false，分别启用或禁用该行为。

PaAlsa_GetStreamInputCard：用此函数获取流的输入设备的 ALSA-lib 声卡索引。

PaAlsa_GetStreamOutputCard：用此函数获取流的输出设备的 ALSA-lib 声卡索引。

特别重要的是 PaAlsa_EnableRealtimeScheduling，它允许 ALSA 以高优先级运行，防止系统上的普通进程抢占音频播放。没有它，低延迟音频播放会不稳定，并频繁出现断续。

Linux 调试

Eliot Blennerhassett 写道：

在 Linux 构建中，可以例如用 "libtool gdb bin/patest_sine8" 调试该程序。这是因为在 Linux 上 bin/patest_sine8 是一个 libtool shell 脚本，它包装了 bin/.libs/patest_sine8，使其能在构建树内找到合适的库。
