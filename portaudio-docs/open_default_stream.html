用默认值打开流

下一步是打开流，这与打开文件类似。你可以指定是否需要音频输入和/或输出、声道数、数据格式、采样率等。打开“默认”流意味着打开默认的输入和输出设备，这样就省去了获取设备列表并从中挑选的麻烦。（稍后我们会看到具体做法。）

#define SAMPLE_RATE (44100)
static paTestData data;
 
.....
 
    PaStream *stream;
    PaError err;
 
    /* Open an audio I/O stream. */
    err = Pa_OpenDefaultStream( &stream,
                                0,          /* no input channels */
                                2,          /* stereo output */
                                paFloat32,  /* 32 bit floating point output */
                                SAMPLE_RATE,
                                256,        /* frames per buffer, i.e. the number
                                                   of sample frames that PortAudio will
                                                   request from the callback. Many apps
                                                   may want to use
                                                   paFramesPerBufferUnspecified, which
                                                   tells PortAudio to pick the best,
                                                   possibly changing, buffer size.*/
                                patestCallback, /* this is your callback function */
                                &data ); /*This is a pointer that will be passed to
                                                   your callback*/
    if( err != paNoError ) goto error;

数据结构与回调在编写回调函数中说明。

上面的示例打开了用于写入的流，这足以进行播放。也可以打开用于读取的流来进行录音，或同时读写，用于同时录音与播放，甚至实时音频处理。如果你打算同时播放和录音，只打开一个输入与输出参数都有效的流。

关于同时读写，有几点需要注意：

  • 某些平台只能使用同一个设备打开读写流。
  • 虽然可以打开多个流，但很难让它们同步。
  • 某些平台不支持在同一设备上打开多个流。
  • 使用多个流可能不如其他功能测试得充分。
  • PortAudio 库调用必须在同一线程中发起，或由用户自行同步。
