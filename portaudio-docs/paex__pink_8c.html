详细说明

使用 Gardner 方法生成粉红噪声。

James McCartney 建议的优化方法使用一棵树来选择要替换哪个随机值。

x x x x x x x x x x x x x x x x x x x x x x x x x x x x x x x

该树通过对递增的索引统计末尾零的个数生成。索引为零时，不会选择任何随机数。

作者
Phil Burk http://www.softsynth.com
