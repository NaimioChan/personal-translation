在 Windows 上用 MSVC 构建带 ASIO 支持的 PortAudio

使用 MSVC 构建 Windows ASIO 版 Portaudio

注意：本页介绍使用 msvc// 目录中旧版 MSVC 工程文件构建 PortAudio 的方法。你也可以使用 CMake 构建系统。

本教程介绍在不具备现成 Visual Studio 工程的情况下，使用 MSVC 从零开始构建带 ASIO 支持的 PortAudio 的方法。若要了解如何使用随附的 Visual Studio 工程文件构建 PortAudio（含 ASIO 支持），请参见 在 Windows 上用 Visual Studio 构建 PortAudio 的编译说明。

ASIO 是 Steinberg 提供的低延迟音频 API。编译 ASIO 应用前，必须先向 Steinberg 下载 ASIO SDK，还需要为音频设备获取 ASIO 驱动。请从 Steinberg 的 http://www.steinberg.net/en/company/developer.html 下载 ASIO SDK。该 SDK 免费，但你需要注册 Steinberg 开发者账号。

本教程假定你把 3 个目录安排在同一层（并列），分别存放 PortAudio、ASIO SDK 和你的 Visual Studio 工程：

/ASIOSDK2 
/portaudio
/DirContainingYourVisualStudioProject  (should directly contain the .sln, .vcproj or .vcprojx etc.)

首先，确认 Steinberg SDK 与 portaudio 文件在同一目录中“并列”存放。

打开 Microsoft Visual C++，在同一目录中新建一个空的控制台 exe 工程/工作区。

例如，这三组文件的路径可能如下：

C:\Program Files\Microsoft Visual Studio\VC98\My Projects\ASIOSDK2
C:\Program Files\Microsoft Visual Studio\VC98\My Projects\portaudio
C:\Program Files\Microsoft Visual Studio\VC98\My Projects\Sawtooth

接下来，把以下 Steinberg ASIO SDK 文件加入工程的 Source Files：

asio.cpp                        (ASIOSDK2\common)
asiodrivers.cpp                 (ASIOSDK2\host)
asiolist.cpp                    (ASIOSDK2\host\pc)

然后，把以下 PortAudio 文件加入工程的 Source Files：

pa_asio.cpp                     (portaudio\src\hostapi\asio)
pa_allocation.c                 (portaudio\src\common)
pa_converters.c                 (portaudio\src\common)
pa_cpuload.c                    (portaudio\src\common)
pa_dither.c                     (portaudio\src\common)
pa_front.c                      (portaudio\src\common)
pa_process.c                    (portaudio\src\common)
pa_ringbuffer.c                 (portaudio\src\common)
pa_stream.c                     (portaudio\src\common)
pa_trace.c                      (portaudio\src\common)
pa_win_hostapis.c               (portaudio\src\os\win)
pa_win_util.c                   (portaudio\src\os\win)
pa_win_version.c                (portaudio\src\os\win)
pa_win_coinitialize.c           (portaudio\src\os\win)
pa_win_waveformat.c             (portaudio\src\os\win)
pa_x86_plain_converters.c       (portaudio\src\os\win)
paex_saw.c                      (portaudio\examples)  (Or another file containing main() 
                                                      for the console exe to be built.)

尽管并非严格必需，你也可以把以下文件加入工程的 Header Files：

portaudio.h                     (portaudio\include)
pa_asio.h                       (portaudio\include)

这些头文件定义了 PortAudio API 的接口。

接下来，依次进入 Project Settings > All Configurations > C/C++ > Preprocessor > Preprocessor Definitions，在可能已有的条目中加入 PA_USE_ASIO=1。

例如：WIN32;_CONSOLE;_MBCS 变为 WIN32;_CONSOLE,_MBCS;PA_USE_ASIO=1

然后，在同一个 Project Settings 选项卡中向下找到 Additional Include Directories（在 VS2010 中该设置位于 C/C++ > General 下），输入以下相对包含路径：

..\portaudio\include;..\portaudio\src\common;..\portaudio\src\os\win;..\asiosdk2\common;..\asiosdk2\host;..\asiosdk2\host\pc

你需要确认相对路径与你所用的目录布局相符。如果采用前面推荐的并列布局，上述设置即可正常工作。

ASIO SDK 中的部分源代码与 Win32 API 的 UNICODE 模式不兼容（ASIO SDK 期望使用非 Unicode 的 Win32 API）。因此需要确保工程未设置为使用 Unicode。做法是把工程的 Character Set 设为 “Use Multi-Byte Character Set”，而不是 “Use Unicode Character Set”。在 VS2010 中，Character Set 选项位于 Configuration Properties > General > Character Set。（除了把工程设为非 Unicode，另一种办法是修改 asiolist.cpp，使其在定义了 UNICODE 时也能工作：在文件开头、包含 windows.h 之前加上 #undef UNICODE。）

注意：Windows 上某些版本的 ASIO SDK 存在数组删除缺陷。要绕过这个问题，需要给 ASIO SDK 打补丁。修复方法请见 src/host/asio/ASIO-README.txt。

现在你应该能够构建 portaudio\examples 目录中的任意测试可执行文件。建议从 paex_saw.c 开始，它是最简单的示例文件之一。

— Chris Share, Tom McCandless, Ross Bencina
