函数说明

PaAlsa_EnableRealtimeScheduling()

void PaAlsa_EnableRealtimeScheduling ( PaStream * s, int enable )

指定在启动音频线程时是否启用实时优先级。

如果在流启动时开启此项，音频回调线程将以 FIFO 调度策略创建，该策略适合实时运行。

PaAlsa_GetStreamInputCard()

PaError PaAlsa_GetStreamInputCard ( PaStream * s, int * card )

获取此流输入设备的 ALSA-lib 声卡索引。

PaAlsa_GetStreamOutputCard()

PaError PaAlsa_GetStreamOutputCard ( PaStream * s, int * card )

获取此流输出设备的 ALSA-lib 声卡索引。

PaAlsa_InitializeStreamInfo()

void PaAlsa_InitializeStreamInfo ( PaAlsaStreamInfo * info)

初始化宿主 API 专用结构体，在设置相关属性之前调用。

PaAlsa_SetLibraryPathName()

void PaAlsa_SetLibraryPathName ( const char * pathName)

如果 PortAudio 配置为动态加载 ALSA 库，则设置 ALSA 库文件的路径与名称（见 PA_ALSA_DYNAMIC）。此设置会覆盖 PA_ALSA_PATHNAME 宏设置的默认名称。

参数
参数说明
pathName含文件名的完整路径。也可以只给文件名，此时 dlopen() 会在默认的可搜索目录（/usr/lib;/usr/local/lib）中查找。

PaAlsa_SetNumPeriods()

PaError PaAlsa_SetNumPeriods ( int numPeriods)

设置用于配置设备的周期数（缓冲区片段数）。

默认周期数为 4，这是在作者的声卡上能正常工作的最低周期数。

参数
参数说明
numPeriods周期数。

PaAlsa_SetRetriesBusy()

PaError PaAlsa_SetRetriesBusy ( int retries)

设置重试打开正被占用设备的最大次数（每次重试之间短暂休眠）。
