初始化 PortAudio

在对 PortAudio 进行任何其他调用之前，你 "必须" 调用 Pa_Initialize()。这会触发对可用设备的扫描，之后可以再查询这些设备。像大多数 PA 函数一样，它会返回 paError 类型的结果。如果结果不是 paNoError，说明发生了错误。

err = Pa_Initialize();
if( err != paNoError ) goto error;

把错误码传给 Pa_GetErrorText( err ) 就能得到解释该错误的文本消息。例如：

printf(  "PortAudio error: %s\n", Pa_GetErrorText( err ) );

同样重要的是，在不再使用 PortAudio 时要终止它：

err = Pa_Terminate();
if( err != paNoError )
   printf(  "PortAudio error: %s\n", Pa_GetErrorText( err ) );
