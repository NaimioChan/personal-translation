Jack 路由（多声道与浏览器音频）

JACK 是一个处理实时、低延迟音频（以及 MIDI）的系统。它运行在 GNU/Linux、Solaris、FreeBSD、Mac OS X 和 Windows 上（也可以移植到其他符合 POSIX 的平台上）。它能把多个不同的应用程序连接到音频设备，也允许它们彼此之间共享音频。它的客户端可以运行在自己的进程里（即作为普通应用程序），也可以运行在 JACK 服务器里（即作为一个「插件」）。JACK 还支持跨网络分发音频处理，既包括快速可靠的 LAN，也包括较慢、可靠性较低的 WAN，因此对于 Pure Data 这类实时编码（live coding）环境来说是个好选择，Pure Data 支持 JACK。

从不同角度理解 JACK

「JACK」这个词并没有非常精确地指代某个东西。JACK 的含义多少取决于你的视角。有几种理解这个词的方式，它们同样都成立：

JACK API

使用 JACK 的程序所用的数据结构、协议和函数的定义。API 的一种实现。

软件（服务器）

一个服务器应用程序，通常叫「jack」，以及一个供客户端使用的库。API 已经有两个实现，叫做「jack1」和「jack2」（以前叫「jackmp」）。不同的实现在（几乎）所有方面都可以互相替换使用。

qjackctl（一个 GUI 控制应用程序）

现有的实现完全不带任何 GUI。为了让大多数用户省事，出现了 GUI 控制程序，可以方便地修改 JACK 的启动参数，并监视正在运行的 JACK 系统的状态。qjackctl 是使用最广泛的 GUI 控制程序。

让 Pure Data 与 JACK 对接

把 Pure Data 和 Jack 配合起来相当容易。

  1. 从 GUI 或命令行运行 jack 来启动它。

  2. 在 Media 标签页里选择 jack。

  3. 在 Media > Audio Settings 里选择你想让 PD 交给 jack 的声道数（输入和输出）。

这里假设你已经安装了 Jack，并且可能为了让性能更好而启用了实时配置。

把浏览器音频路由到 jack（包括 flash 和其他浏览器插件容器）

（来自 Ubuntu Studio 教程，也可以用在其他 Linux 发行版上）

  1. sudo apt-get install pulseaudio-module-jack

jackd 启动之后，在终端里运行：

  1. pacmd load-module module-jack-source channels=2; pacmd load-module module-jack-sink channels=2;

现在进入 ubuntu 的声音选项，把输出（如果你愿意，输入也一样）切换到 pulseaudio，然后就可以享受了。音频都会被路由回 jack。

如果你成功了，它会像下面这样出现在 GUI（qjackctl）里。

整理一下，如果你使用 qjackctl

  1. 启动 qjackctl

  2. 进入 Setup > Options

  3. 把上面的 load-module 命令加到 script to be started after jack is launched 里

  4. 重启 jack。
