在 Linux 上让 Arduino UNO 正常工作

截至目前（2011 年 7 月初），UNO 在 Linux 下是坏的。这块板子出厂的固件使它在 Linux 下几乎无法使用。

症状有：

  • Arduino IDE 无法检测到串口，或者会随机丢失串口，导致上传 sketch 或打开串口监视器非常困难。

  • 无法以可预测的方式在 Pd 内检测到这块板子。[comport] 检测它非常不稳定，尝试打开你的设备时会输出错误，而且对 [open( 或 [close(、甚至 [devices( 的反应通常要等很久。

幸运的是，有解决办法！你需要用更新版本的固件刷新它。这听起来像是一件挺危险的事，但实际上相当安全，也不会有把板子刷坏的风险（据 Arduino 团队的一些人说）。为了刷新固件，你必须把板子置于「固件更新」模式。

如果你持有第一版的 UNO 板（板子背面应该写着「UNO」），可以参考这个教程：

http://arduino.cc/en/Hacking/DFUProgramming8U2

如果你持有「修订版」的 UNO（背面写着「UNO R2」），那么按以下步骤操作：

  1. 从这个页面下载更新后的固件（.hex 文件）：https://github.com/arduino/Arduino/tree/master/hardware/arduino/firmwares/arduino-usbserial

  2. 在终端里粘贴这条命令来安装 dfu-programmer：

    sudo apt-get install dfu-programmer

  3. 把板子连接到电脑上，找到靠近 USB 插头的六个竖排插针（下图中用红圈标出）。

  4. 用一根导线（例如）短暂连接最靠近 USB 插头的两个插针。你应该会看到「L」LED 闪一两次。「Rx」和「Tx」两个 LED 现在应该都熄灭：板子已经准备好进行固件更新了。

  5. 在终端里 cd 到你保存更新后固件的目录，运行以下命令：

    sudo dfu-programmer at90usb82 erase
sudo dfu-programmer at90usb82 flash Arduino-usbserial-uno.hex
sudo dfu-programmer at90usb82 reset

  6. 拔下再重新插上你的 UNO 板。

  7. 打开 Arduino IDE：现在它应该能完美工作。你现在可以把任何 sketch 上传到板子上。而且 Pd 中的 [comport] 现在也能检测到它。

请注意，这个修复据说也适用于 Arduino Mega 板，不过我自己没有 Mega，没有测试过。另外，新出厂的 UNO 预计会带上更新后的固件。我是在 2011 年 4 月买的，所以在那之前买的 UNO 肯定都要刷。之后买的板子情况我不清楚。

现在你的 UNO 在 Linux 下能正常工作了，你可以从 Hans-Christoph Steiner 的网站下载 Pduino。Pduino 需要在板子上上传 firmata。它是在 PD 内控制板子各引脚最灵活、最全面的方式，输入输出都包括。
