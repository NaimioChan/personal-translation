简单的回归测试

有一套简单的回归测试框架，会在部分 PdLab 机器上自动运行。有两个关键细节，其余由你决定：返回值和文件结构。

接下来的计划是写一个脚本，遍历整棵目录树寻找回归测试文件，运行它们，记录结果，并把错误通过邮件发送到 pd-cvs@iem.at。

返回值

SUCCESS

测试成功完成

FAIL

测试失败（可选）

WAIT

测试尚未完成，重置超时计数器（可选）

另外还有一个标准超时。如果一个 patch 在该超时时间内没有发送 SUCCESS、FAIL 或 WAIT，测试 patch 就会被终止。

文件结构

目前 zexy 库拥有最完整的测试基础设施。它的测试都放在一个名为 tests 的文件夹里，其中的子文件夹以被测试的对象类命名。这些子文件夹里就是包含测试的 Pd patch。

另一种想法

首先，文件名必须以 -regression.pd 结尾，就像帮助文件以 -help.pd 结尾一样。其次，如果测试成功，必须向 [print SUCCESS] 发送一个 bang。
