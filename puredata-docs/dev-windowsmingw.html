在 Windows 上用 MinGW 构建 Pd

面向 Pd-0.48-1 或更新版本的构建指南更新版。推荐使用针对 Msys2 的指南。你也可以用 Msys1 编译。

过时的内容已下移。

在 Windows 上用 Msys2 构建

从以下地址下载 64 位安装程序：

https://www.msys2.org/

按照以下地址上的安装说明操作： https://www.msys2.org/wiki/MSYS2-installation/

用 pacman 添加这些软件包：

pacman -S make autoconf automake libtool

然后是 32 位编译器：

pacman -S mingw32/mingw-w64-i686-gcc

以及 64 位编译器：

pacman -S mingw64/mingw-w64-x86_64-gcc

获取 Pd 源代码

从 GIT 下载 Pd 源代码。在 https://github.com/pure-data/pure-data 上有一个写着 "clone or download" 的绿色大按钮

下载 ASIO SDK

按以下步骤安装 ASIO SDK：

  • 1. 下载 ASIO SDK： https://www.steinberg.net/en/company/developer.html

  • 2. 把 asiosdk2.3.zip（或更高版本）解压到你下载的 Pd 源代码的 ASIO 文件夹中

  • 3. 去掉版本号，得到 pure-data/asio/ASIOSDK

为 32 位构建 Pd

打开 MinGW32 shell，执行：

cd full/path/to/your/pd-master-sources

./autogen.sh

./configure

make

make app

为 64 位构建 Pd

打开 MinGW64 shell，执行：

cd full/path/to/your/pd-master-sources

./autogen.sh

./configure

make

make app

使用其他 TCL/TK 的补充说明

参阅 https://github.com/pure-data/pure-data/blob/master/msw/README.txt

在 Windows 上用 Msys1 构建

安装 MinGW。推荐使用的目录是 C:\MinGW

在 MinGW Installer Manager 中，选择 Installation > Update Catalogue

在 'Basic Setup' 中安装：

  • mingw-developer-toolkit / bin

  • mingw32-base / bin

  • mingw32-gcc-g++ / bin

  • msys-base / bin

在 'All Packages > MinGW > MinGW Libraries' 中安装：

  • mingw32-pthread-w32 / dev

'All Packages > MinGW > MinGW Autotools' 里那些旧的 automake 1.4 到 1.8 版本可以移除。

命令行 shell 可以用 C:\MinGW\msys\1.0\msys.bat 启动。在 shell 中，C:\ 对应 /c/。

确保你没有安装 msys-gcc 或 msys-binutils。它们只用于构建 msys，而且用的是更老的版本。

构建 Pd-Vanilla

从 Pd-0.48-1 起，你可以像 Msys2 那样操作，ASIO 文件夹的步骤与上面相同。

cd full/path/to/your/pd-master-sources

./autogen.sh

./configure

make

make app

要用 Msys1 运行你编译好的 Pd，应该把 pthreadGC-3.dll 和 libgcc_s_dw2.dll 从 C:\MinGW\bin 复制到你构建出的 pd/bin

  • MinGW Gcc 编译器需要一个 pd.dll 才能构建。最简单的办法是构建或下载 pd-vanilla，然后把 pd.dll 复制到 pure-data-svn/pd/bin。

MinGW 没有 subversion、git、zip、gpg 这类方便的工具。为此你可以安装 Cygwin 或使用 Windows 工具。

过时内容：

原始页面

在 Microsoft Windows 上用免费工具就能轻松构建 Pd，最近随着 mingw-get 工具的出现，上手容易了许多。虽然你大概也能用下面所有软件包的最新版本，但这里提供的链接是已知可用的版本。

Tortoise SVN

TortoiseSVN 提供原生的 Windows SVN。这个过程最好使用原生 Windows 工具，不过 Cygwin 工具也能用。

  • 下载 TortoiseSVN，32 位或 64 位都可以

  • 在安装中自定义勾选 command line client tools

Git for Windows

有一个基于 MinGW MSYS 的 Git for Windows 构建，但它带有自己的安装程序。这个过程最好用原生 git，不过也可以用 Cygwin 的 git。

  • 下载 Git-1.8.0-preview20121022.exe 并安装。

  • 在安装程序的 Adjusting your PATH environment 这一步选择 Run Git from the Windows Command Prompt

Cygwin

Cygwin 安装起来相对容易，并且为 subversion 这类东西提供了好得多的工作环境。MinGW 对 rsync、git、svn 等部分 GNU 工具的支持不完整，所以要安装 Cygwin 的版本。

  • 下载 setup-x86.exe 或 setup-x86_64.exe 并运行来安装 Cygwin。安装在默认位置。

进入 Select Packages 界面后，点击右上角标着 View 的按钮，把它改成 Full。然后找到 git、make、openssh、patch、rsync、sed、svn、zip 和 unzip，确保它们设为安装。这表现为显示一个将要安装的版本号，而不是 Skip。

如果你想让自动构建脚本正常工作，需要把 Cygwin 加入系统 PATH。

ASIO SDK

首先下载 ASIO SDK。你必须同意 Steinberg 的许可协议，然后提交一个邮箱地址，之后他们会把下载 URL 发到你的邮箱。把 asiosdk2.3.zip 解压到 path/to/pd/asio，使文件位于 path/to/pd/asio/ASIOSDK2.3。

你也可以把 asiosdk2.3.zip 直接留在 MSYS 的主目录里，即在 MSYS/MinGW shell 中是 ~/asiosdk2.3.zip，或 C:\MinGW\msys\1.0\home\%USER%\asiosdk2.3.zip。Pd-extended 构建系统会在那里找它，并自动解压到正确位置。对于 Pd-vanilla，你得手工解压到正确位置。

注意：老版本 Pd 使用的 2.2 版已经不能从 Steinberg 下载了。

MinGW

下载 MinGW 软件包安装程序并运行：

  1. mingw-get-inst-20120426.exe

  2. 接受 GPLv3 并点击 Next

  3. 选择 Use pre-packaged repository catalogues 并点击 Next

  4. 安装到默认位置：C:\MinGW 并点击 Next

  5. 勾选所有组件（MinGW Compiler Suite、MSYS Basic System 和 MinGW Developer Toolkit）。点击 Next

  6. 等安装程序下载并安装完所有内容，现在你就有可用的 MinGW 安装和 MSYS shell 了。

配置 MSYS

接下来的步骤中，你会用到由 MSYS 安装程序装好的 MSYS shell。你可以从桌面快捷方式启动它，也可以走 Start --> Programs --> MinGW --> MinGW Shell。进入 MSYS shell 后，你需要运行以下命令来创建 /usr/local：

mkdir /usr/local

现在用一款好的文本编辑器编辑 C:\MinGW\msys\1.0\etc\fstab（vim 现在已包含在 MinGW 中，Wordpad 可以用，但不要用 Notepad），或者在 MinGW/MSYS shell 里编辑 vim /etc/fstab。在该文件中，确保有以下两行（大小写很重要！）：

c:/MinGW/ /mingw
c:/MinGW/ /usr/local

然后退出所有 MSYS shell，重新启动一个 MSYS shell，用 mount 命令检查上面两个目录是否都已挂载。为此运行 mount。你应该能在其余输出中看到这些行：

...
c:\MinGW on /mingw type user (binmode)
c:\MinGW on /usr/local type user (binmode)
...

你可以把 MinGW 和 MSYS 加入 PATH，让 cmd.exe 这类 Windows 工具能找到它们。关于如何为 MSYS 设置环境变量，参见 Max Berger 的 设置编译器 中的 Figure 10 及之后的内容。

MinGW 附加包

我们还需要一些不在默认安装中、但包含在 MinGW 里的软件包。在 MinGW/MSYS shell 中运行：

mingw-get install automake1.10 automake1.9 bzip2 expat gcc-ada gcc-fortran \
gcc-g++ gcc-objc gendef gettext gmp libasprintf libbz2 libexpat libiconv \
libpthreadgc libtool libz lua mingw-utils pexports pkginfo msys-bash \
msys-bison msys-cygutils msys-dos2unix msys-findutils msys-gawk msys-gmp \
msys-gzip msys-less msys-libgmp msys-libregex msys-make msys-rsync \
msys-texinfo msys-wget msys-unzip msys-zip

出于某些原因，mingw 也会装上一些非常旧的 automake 版本。它们只会碍事并带来麻烦，所以移除它们：

mingw-get remove automake1.4 automake1.5 automake1.6 automake1.7 automake1.8

现在你可以构建 Pd-vanilla 了！

你的环境现在已经可以构建 Pd-vanilla 或 Pd-extended 的核心。本说明余下的部分介绍如何为完整的 Pd-extended 构建环境配置好全部库。

来自 MinGW 和 GTK+ 的二进制文件

GTK+ 项目提供了一些面向 Windows 的二进制文件。我们这里用到其中几个。用 MinGW/MSYS shell 把它们下载并安装到 C:\MinGW。最简单的做法是在 MinGW/MSYS shell 中运行这些命令：

cd /tmp
wget http://prdownloads.sourceforge.net/mingw/mingw-libgnurx-2.5.1-bin.tar.gz
wget http://prdownloads.sourceforge.net/mingw/mingw-libgnurx-2.5.1-dev.tar.gz
tar --directory /mingw -xzf mingw-libgnurx-2.5.1-bin.tar.gz
tar --directory /mingw -xzf mingw-libgnurx-2.5.1-dev.tar.gz
wget --no-check-certificate https://www.tortall.net/projects/yasm/releases/yasm-1.2.0-win32.exe
mv yasm-1.2.0-win32.exe /mingw/bin/yasm.exe
wget http://ftp.gnome.org/pub/gnome/binaries/win32/dependencies/pkg-config_0.25-1_win32.zip
wget http://ftp.gnome.org/pub/gnome/binaries/win32/dependencies/pkg-config-dev_0.25-1_win32.zip
wget http://ftp.gnome.org/pub/gnome/binaries/win32/glib/2.28/glib_2.28.1-1_win32.zip
wget http://ftp.gnome.org/pub/gnome/binaries/win32/glib/2.28/glib-dev_2.28.1-1_win32.zip
wget http://ftp.gnome.org/pub/gnome/binaries/win32/dependencies/gettext-runtime_0.18.1.1-2_win32.zip
unzip pkg-config_0.25-1_win32.zip -d /mingw 
unzip pkg-config-dev_0.25-1_win32.zip -d /mingw 
unzip glib_2.28.1-1_win32.zip -d /mingw 
unzip glib-dev_2.28.1-1_win32.zip -d /mingw
unzip gettext-runtime_0.18.1.1-2_win32.zip -d /mingw

最后一步会提示你替换 /mingw/share/locale/locale.alias，回答 Yes。

为 cc1.exe 复制 libgmp-10.dll

有时你可能会遇到关于 cc1.exe 缺少 libgmp-10.dll 的错误。你可以在 libtheora 里运行 ./configure 来测试这一点。一个临时的解决办法是把这些 DLL 复制到 cc1.exe 旁边。写作本文时，它是这样生效的：

cd /mingw/bin
cp libgmp-10.dll libmpc-2.dll libmpfr-1.dll libintl-8.dll /mingw/libexec/gcc/mingw32/4.7.2/
cp libintl-8.dll libiconv-2.dll /mingw/mingw32/bin

Inno Unpack

对于 Pd-extended 的 zip 发行版，Inno Setup 软件包需要先解包再重新打成 zip。为此我们使用 innounp，这样解包时不需要管理员权限。下载 innounp037.rar 并把它 unrar 到 C:\MinGW\bin

QuickTime SDK

Gem 在 Windows 上使用 QuickTime 读写视频文件。你需要一个 Apple ID 才能登录并下载 quicktimesdk.zip。先点击 这个链接 登录，登录后点击这个链接下载文件： QuickTime 7.3 SDK for Windows。拿到之后解压它，然后双击 QuickTimeSDK.exe 并按全部默认设置安装。

安装 Inno Setup 打包

Inno Setup/ISTool

Inno Setup 是 Windows 上的免费安装程序生成器。 ISTool 是更好用的 Inno 脚本 IDE。它用来组装 Pd-extended 安装程序。

  • ispack-5.5.2-unicode.exe 会为你下载并安装好一切。

从 SVN 的 '/sources' 构建 Windows 的库依赖

构建 Pd 的库时需要用到的很多库，目前还无法通过 mingw-get 或二进制文件获得。目前获取它们最好的方式是从源代码构建。对于 Pd-extended，你可以从 SVN 取得源代码，然后运行这个脚本把全部构建出来：

cd pure-data
svn co https://pure-data.svn.sourceforge.net/svnroot/pure-data/sources
cd sources
./build-libs-on-mingw.sh

这会运行一段时间，如果顺利完成，它就装好了 Pd-extended 所需的全部库。如果中途失败，再次运行 ./build-libs-on-mingw.sh 应该是安全的。

构建 Pd

现在你可以开始构建 Pd 了。首先需要从 GettingPdSource 开始，然后可以接着看 BuildingPd 或 BuildingPdExtended。

更新这一流程

这个构建流程肯定还有可以改进的地方。MinGW 被广泛使用，但它并没有被广泛标准化。所以很多人在 MinGW 上构建常见库的方式各不相同。这个流程是为了把它们统一起来，这方面最近最大的进展是 mingw-get。写作本文时，这个流程可以成功构建带许多编解码器的 ffmpeg。最后一个大的缺口是 gmerlin-avdecoder，[readanysf~] 和 Gem 会用到它。还有一些编解码器尚未纳入这个流程，例如 openjpeg 能构建但似乎不能工作，另外还有 libgsm 以及相当多其他可供 ffmpeg 和 gmerlin-avdecoder 使用的编解码库。你可以通过在 MinGW 上把它们构建起来并跑通，然后把结果发布到 pd-dev 来做出贡献。
