Mac OS X 上的 Fink

这篇 HOWTO 演示如何配置一台 Mac OS X 机器来构建 Pd 和 Pd-extended。

搭建构建环境

Apple 开发者工具

你需要安装 Apple 开发者工具以获得 Apple 的编译器和工具。它随 Mac OS X 光盘提供，你也可以从 Apple 下载。请确认你还安装了 X11User.pkg 和 X11SDK.pkg。

Fink

构建 Pd 所用的大部分外部库都可以很方便地通过 Fink 安装。如果你还没有安装 Fink，这里是下载说明。下面的命令会安装 Pd 各个部分所需的所有库。

为了确保你的 Fink 安装在这之前都是最新的，最好在做其他事情之前先运行这些命令：

fink selfupdate
sudo apt-get update
sudo apt-get -f install
sudo apt-get upgrade
sudo apt-get dist-upgrade

简单方法

构建 Pd-extended 需要很多软件包。你可以试试用新的 “bundle” 包，它会安装所有依赖，不过它很新，可能还不能完全正常工作。每当你想确保自己拿到的是最新的 Pd-extended 构建配置时，就运行这些命令：

fink selfupdate
fink purge pd-extended-dev
fink rebuild pd-extended-dev
fink install pd-extended-dev

如果你在一个全新的 Fink 安装上运行这些，下载并构建这一长串依赖会花很长时间。等它完成后，你应该就可以构建 Pd-extended 了。

并非所有软件包都有二进制格式，所以你必须用 fink 来编译这些。

sudo fink install lua51 lua51-dev imagemagick10-dev \
mysql15-dev postgresql82-dev libcdio-dev

到这一步，把所有已安装的软件包更新到稳定仓库里的最新版本大概是个好主意。不幸的是，这意味着要从源码构建很多东西，可能花很长时间。所以开始这个过程，然后把它忘掉几个小时。虽然这不是必须的，但它会让后面的步骤更顺利。

fink -y update-all &

这些软件包需要从 “unstable” Fink 发行版安装。要使用这些包，你需要把你的 Fink 安装配置为使用 “unstable” 发行版（对我来说它一直相当稳定）。Fink FAQ 第 5.8 问告诉你怎么做。

一个好办法是先从 stable 安装所有依赖，然后切到 unstable 装剩下的。如果某个 unstable 包又带来更多依赖，我就切回 stable 把它们都在那里构建，然后再切回 unstable 把一切做完。听起来可能复杂，其实并不复杂。只是复制粘贴一些软件包名字，再运行几次 fink configure。

sudo fink install coreutils-default svn ffmpeg ffmpeg-dev libavcodec-dev \
libdv4 speex3 lame-dev fftw3 libftgl1 libhid0 libquicktime1 faac-dev \
libfaad1-dev libpostproc1 libpostproc-dev libavutil-dev libavformat-dev \
libswscale-dev libavdevice-dev libgavl1 gmerlin-avdecoder1

这些是目前自动构建并不需要的依赖，但 SVN 里有几个库会用到它们。它们构建起来可能很麻烦，所以是可选的。

sudo fink install flite libflac8-dev ladspa-dev fftw artoolkit

另一种方法

安装所有库的另一种方法见：Alternate MacOSX Fink

Framework

Tcl/Tk

构建 Pd 需要 Tcl/Tk framework。目前 Mac 上的 Tcl/Tk 没有定期的发布版，但从源码构建很容易。要下载 Pd-extended 所用的版本，请用 GettingPdSource。首先 rsync pd-extended，然后把 tcltk_core-8-4-branch rsync 到同一个文件夹，再运行这些命令：

cd tcltk_core-8-5-branch
./tcltk_core-8-5-branch_auto-builder.sh
sudo mv build/tcl/Tcl.framework /Library/Frameworks/
sudo mv build/tk/Tk.framework /Library/Frameworks/

如果你运行的是 Mac OS X 10.4 Tiger 或更新版本，严格来说这并非必需，因为系统自带 Tcl/Tk 8.4.7。但使用更新版本的 Tcl/Tk 有很多好处

Jack OS X

Pd-extended 在 Mac OS X 上也使用 Jack on Mac OS X。除了非常基本的测试之外我没有用过它，但据说它可以工作。它确实能正常编译。我用的是这个版本：http://sourceforge.net/projects/jackosx/files/JackOSX/0.83/JackOSX.0.83_32bits.pkg.zip 它是一个安装程序，下载后直接运行安装程序即可。

构建 Pd 和/或 Pd-extended

在开始构建之前，你当然需要先拿到源代码。获取方式有多种，各种选择参见 GettingPdSource。然后根据你想构建的东西，转到 BuildingPd 或 BuildingPdExtended。
