Mac OS X 64 位构建

Pd 自身从 0.41.4 版起就已经支持 64 位，而 Pd-extended 从 0.42.5 起在 GNU/Linux 上已经是完整的 64 位。Mac OS X 10.6 Snow Leopard 现在也完全是 64 位的，所以现在正是开始制作完整 64 位构建的好时候。

为 Mac OS X 制作完整的 64 位 Pd-extended 构建有一个大问题：Apple 已经废弃了部分 Carbon API，并且只在 32 位模式下支持它们。Gem、hid 和 pidip 都依赖这些 API，所以不做大手术的话它们无法在 64 位下工作。

下面是让 Pd-extended 的 64 位构建跑完的方法：

  • 把一个 Tcl/Tk 8.4 的构建安装到 /Library/Frameworks

  • 在 packages/Makefile 中，从以 all: 开头的行里去掉 gem，从以 externals_install 开头的行里去掉 gem_install

  • 从 Pd-extended 的 32 位构建中复制 libPdTcl.dylib
