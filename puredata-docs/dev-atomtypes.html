Atom 类型

规范的 atom 类型：

  • A_FLOAT (1)

    一个数字，例如 3

  • A_SYMBOL (2)

    一个符号（存放在哈希表里的字符串），例如 foo

  • A_POINTER (3)

    指向某个数据结构的指针

通常不会出现在消息里（只出现在消息框中）的规范 atom 类型：

  • A_SEMI (4)

    一个分号 ;（消息结束）

  • A_COMMA (5)

    一个逗号 ,（消息分隔符）

  • A_DOLLAR (8)

    一个（带编号的）占位符，例如 $2

  • A_DOLLSYM (9)

    一个包含（带编号的）占位符的符号，例如 $0-table

伪 atom 类型（不在 t_atom 中使用）：

  • A_NULL (0)

    类型列表的终止符。不计入类型列表的一部分。

  • A_DEFFLOAT (6)

    默认数字（用于对象参数）

    如果用户没有提供（数字）参数，则假定为 0

  • A_DEFSYM (7)

    默认符号（用于对象参数）

    如果用户没有提供（符号）参数，则假定为 ''（空符号）

  • A_GIMME (10)

    一次表示所有参数的类型列表元素。它应该是唯一的类型列表元素。

  • A_CANT (11)

    「bottom type」。这使得无法用常规方式调用方法：它必须由 getfn 接管。这是给那些必须接受非 atom 参数的方法用的。例如，DSP 参数不是 atom。

用户定义的 atom 类型：

如果你添加自己的 atom 类型，请注明它的数值以及该类型在何处使用

  • A_NULL (0)

    这个伪 atom 类型被 GridFlow 复用为真正的 atom 类型。 当 a_type==A_NULL 时，a_w 会被忽略，其含义相当于其他语言里的「nil」「undef」「none」或「NULL」。

  • A_LIST (13)

    a_w 是一个 t_binbuf *。由 GridFlow 使用，将来也会由 DesireData 使用。

  • A_GRID (14)

    由 GridFlow 保留

  • A_GRIDOUT (15)

    a_w 是一个 GridOutlet *。由 GridFlow 使用

  • A_FTS_OBJECT (77)

    FTM 使用的一种复杂数据结构

    由 IOhannes 保留

  • A_FTS_STRING (78)

    FTM 使用的一种字符串

    由 IOhannes 保留

  • A_EVIL (666)

    evil 数据；将来可能对 evil 处理例程的优化实现有用

    由 Stephen Sinclair 保留

用户定义的伪 atom 类型（不在 t_atom 中使用）：

  • A_ATOM (12)

    由 DesireData 保留……也许不是。（仍在考虑）
