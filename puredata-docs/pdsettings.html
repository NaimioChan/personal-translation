如何保存启动选项，让它们在我每次启动 Pd 时都被加载

你会发现有若干启动选项是你每次启动 pd 时都需要的。 你可以通过 pdsettings 系统保存这些选项，让它们在启动时自动生效（注意：这是从 pd 0.38 开始引入的）

注意：从 pd-extended 0.43 起不支持保存库路径，推荐的引入库的方式是使用 import 对象（已废弃）

pdsettings 可以通过 Pd 的菜单配置。

可惜这些设置分散在几个不同的菜单里：

  • 要更改音频设置（你的音频和 MIDI 硬件设置），进入 Media->Audio Settings...（相应的是 Media->MIDI Settings...），把各项值改成合适的（如果需要改的话）。（要把这些修改保存下来供以后的会话使用，请继续往下读。）
  • 要更改 pd 的搜索路径，进入 File->Path...，每行添加一个额外的搜索路径（或删除不需要的）；在这里你还可以指定是否让 pd 以「verbose」模式启动。 当你点 Save all settings 按钮时，你的修改就会保存到系统里。
  • 要更改启动时加载的库/外部对象，进入 File->Startup...，每行添加一个额外的库/外部对象（或删除不需要的）；在这里你还可以强制 pd 不以实时模式启动（在某些场景下使用实时模式并不完全是个好主意）；此外你还可以指定自定义的启动参数。

当你点 Save all settings 按钮时，你的修改就会保存到系统里。 pdsettings 以平台相关的方式按键/值对保存。

平台

Windows/WIN32

在 Windows 上，偏好设置存放在注册表里。对 Pd-vanilla，它们在 HKEY_LOCAL_MACHINE -> SOFTWARE -> Pd。对 Pd-extended，它们在：HKEY_LOCAL_MACHINE -> SOFTWARE -> Pd-extended

Mac OS X

在 Mac OS X 上，设置通过原生的 defaults 系统保存，它以 plist 文件的形式存放。（即 ~/Library/Preferences/org.puredata.pd.plist）。你可以用命令行工具 defaults 编辑它们，例如 defaults read org.puredata.pd。对 Pd-vanilla，它们存放在 org.puredata.pd。对 Pd-extended，它们存放在 org.puredata.pdextended。

GNU/Linux, Debian, Ubuntu, Fedora, UNIX, ...

在其他类 UNIX 系统（如 GNU/Linux）上，使用主目录里的一个隐藏文件。对 Pd-vanilla，这个文件名为 ~/.pdsettings。对 Pd-extended，这个文件名为 ~/.pdextended
