把你的项目添加到下载页面

现在我们有了一个不错的 Plone 软件下载页面，它正在成为各类 Pd 项目的集中仓库。它对所有与 Pd 相关的项目开放。下面是添加你的项目的方法。

  1. 用你的账号登录

  2. 进入下载页面

  3. 要创建你的项目页面，看左上角，点击

  4. 尽可能把表单填写完整，然后点击页面底部的 。最好再附上一张截图和一个 logo 图片。

  5. 在你新建的项目页面上，Current release 一节里点击 Go to the release folder to add or publish a release

  6. 在 Releases 页面的右上角，点击

  7. 填写表单，然后点击

  8. 在新建的版本页面右上角，点击 来设置这个发布的状态，即 alpha、beta、final 等。

  9. 在右上角点击 add item，然后选择 downloadable file（如果你想把这个发布托管在 puredata.info 上）或 externally hosted file（如果你想提供一个托管在别处的发布链接）。

  11. 填写表单并点击

你的项目及其新版本现在应该会显示在主下载页面上。你随时可以在下载页面 URL 后面加上你的项目名来访问这个页面。
