我听不到任何声音！

我以为 Pd 就是用来做声音的。可我什么都听不到！

首先确认主 PD 窗口里标着 compute audio 的方框已勾选。

然后检查你是否为系统选对了声卡和驱动，以及声卡是否已连接并正常工作。

  • 在 OS X 上，确认 "Audio Settings" 中所选声卡旁边的方框都已勾选。
  • 在使用 Jack 的 Linux 或 OS X 上，确认 Jack 程序正在运行。
  • 在所有平台上，检查操作系统自带的音频控制面板，确认那里启用了正确的输出，并且它的播放音量已经调高。

另外要确认你在 PD 里使用的采样率与声卡的一致。
