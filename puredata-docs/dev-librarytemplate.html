库模板

如果你正准备开始写一个库，或者想把已有的库移植到多个平台上，那么库模板会让你轻松很多。用这种格式的库非常容易安装，并且能和 Pd 紧密结合，提供命名空间支持、供搜索功能使用的元数据、在帮助浏览器中的条目等功能。它处理在所有受支持平台上的构建（目前有 GNU/Linux、GNU/Hurd、GNU/kFreeBSD、Mac OS X/Universal、Windows/MinGW、Windows/Cygwin、Android、Apple iOS）。用了这个模板，把你的库打包给 Debian、Ubuntu、Fedora、Gentoo 等发行版就变得极其容易。

开始使用

下面介绍如何开始在你的项目里使用库模板：

  1. 下载整个模板文件夹，可以下载一个发行版，或者直接用 SVN 检出：

    svn co https://pure-data.svn.sourceforge.net/svnroot/pure-data/trunk/externals/template

  2. 把模板文件夹重命名为你库的名字（例如 mylibrary）

  3. 编辑 Makefile，把库名填入第一个变量（例如 LIBRARY_NAME=mylibrary）

  4. 把 template-meta.pd 重命名，用你刚才给文件夹起的名字替换 'template'（例如 mylibrary-meta.pd）

现在你可以在 meta 文件里设置库的元数据，比如版本、作者等。用 Pd 或一个好用的文本编辑器打开 meta 文件（例如 mylibrary-meta.pd）。

构建方式

  • MakefileTemplate - 可用于 GNU/Linux、MacOSX/Fink、Windows/MinGW。Windows/Cygwin、Android、iPhoneOS

  • DebianTemplate - 为 Debian、Ubuntu 等制作 .deb 包

  • GentooTemplate - 许多库的 ebuild

  • ArchTemplate - 一个 PKGBUILD 脚本的示例文件

  • [[RPMTemplate]] - 你来写！帮我们为 Redhat、Fedora、Mandriva 等制作 .rpm 包

特殊功能

为 GUI 对象提供每个对象一个 Tcl 文件

如果你写了一个 GUI 对象，可以把该 GUI 对象的全部 Tcl 代码放进一个与你的对象同名的 .tcl 文件里（例如 myobject.c 和 myobject.tcl）。这个文件会被构建系统自动处理，但你需要在自己的 setup() 函数里加载它，并包含 Pd 的 m_imp.h 头文件。

你可以在 [cursor] 对象的 cursor.c 和 cursor.tcl 中看到实际用法。下面是一段摘录：

#include "m_imp.h"
...

void cursor_setup(void)
{
...
    sys_vgui("eval [read [open {%s/%s.tcl}]]\n",
        cursor_class->c_externdir->s_name,
        cursor_class->c_name->s_name);
    sys_vgui("::hcs::cursor::setup %s\n", cursor_receive_symbol->s_name);
}

为库制作一个共享库

最近已经可以有共享的二进制库、共享的头文件和共享的 Tcl 库了。如果你的对象共用 C 或 Tcl 代码，就可以把共用的代码放进这些共享库里。只要你遵循文件命名规则，其余部分都会自动处理。对于 C 文件，里面写什么代码都可以，只要文件名是 lib$(LIBRARY_NAME).c，头文件叫 $(LIBRARY_NAME).h。例如，如果你的库叫 foo，你就要把 Makefile 顶部的 LIBRARY_NAME 变量设为 foo，然后把 C 头文件写成 foo.h，共享的 C 代码写成 libfoo.c，共享的 Tcl 代码写成 libfoo.tcl。

把所有对象构建成一个库文件

有些人想把所有对象构建成单个 .pd_linux 库文件。要做到这一点，你只需要加一个与你库同名的 C 文件。那个 $(LIBRARY_NAME).c 文件应当只包含所需的各个 setup 函数。例如，下面是库模板的 template.c：

/* glue code for compiling "template" as a library
 * this calls the setup function of each object
 */
void mycobject_setup(void);

void template_setup(void) {
  mycobject_setup();
}

注意：如果你想这样做又没有创建共享库，那就确保为 lib$(LIBRARY_NAME).c 和 $(LIBRARY_NAME).h 创建占位文件，以免那时还需要改 Makefile。例如，下面是库模板的 libtemplate.c：

/* This is just a dummy file, you don't have to put something inside here */

现在运行 make $(LIBRARY_NAME) 而不是只运行 make，编译器就会输出 $(LIBRARY_NAME).pd_linux（或者 .pd_darwin、.dll 等等……）。

再注意一点：不要把 $(LIBRARY_NAME).c 这个文件放进 SOURCES，但一定要把它放进 EXTRA_DIST。

库模板的许可证

库模板中的所有文件都已释放到公有领域，这样创建库的人可以轻松选择最适合自己的许可证（GPL-3、GPL-2、BSD 等）。当然，我们希望你能选择自由软件许可证。
