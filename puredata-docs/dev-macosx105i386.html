2048 a3:0c:fa:55:77:19:ec:1a:4f:98:0d:d9:09:77:5e:41 /etc/ssh_host_rsa_key.pub (RSA)
1024 88:63:9f:ab:08:08:c2:75:3f:14:f9:58:6a:52:eb:2e /etc/ssh_host_dsa_key.pub (DSA)

使用说明

很多依赖是用 Fink 安装的，它把所有东西装到 /sw 里。这意味着你必须相应地调整 include 和 lib 路径。详见 MacOSXFink。

如果你想使用完整的 Fink 环境，需要用下面的命令为 shell 设置 Fink：

. /sw/bin/init.sh
