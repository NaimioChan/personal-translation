Debian

用 Debian/Ubuntu/Mint 等在 GNU/Linux 上构建

首先你需要确认所有标准开发工具都已经安装。为此，在你的终端里运行这条命令：

sudo apt-get build-dep puredata gem pdp

额外需要的软件包

所有这些软件包都用于在 Debian Sarge/stable 上编译 Pd-extended。除了标出的那些，它们全都来自标准的 Debian 仓库。安装它们最省事的办法，是把软件包列表复制粘贴到以 apt-get install 开头的一行里。

编译 Pd-extended 需要的就这些：

sudo apt-get install fakeroot ttf-dejavu libfftw3-dev libspeex-dev libvorbis-dev libflac-dev libsndfile1-dev libsamplerate0-dev libgavl-dev libmad0-dev dssi-dev liblo-dev flite1-dev libtk-img tcllib swig tcl8.5-dev tk8.5-dev liblua5.1-0-dev subversion git rsync

LAME 是一个提供 mp3 支持的自由库。如果你用的是 Ubuntu 或 Mint，这就是你最后需要安装的一个软件包。可以这样安装它：

sudo apt-get install libmp3lame-dev

libmp3lame-dev 直到 Debian/wheezy 才被加入 Debian。Debian/squeeze 可以从 backports 获取。把 backports 加入你的 /etc/apt/sources.list 之后，就可以这样安装它

sudo apt-get -t squeeze-backports install libmp3lame-dev

如果这样失败了，那你就需要添加一个外部仓库。mp3 格式在美国、德国以及其他一些国家是有专利的（ No Software Patents!），所以 Debian 无法包含 LAME。其中一些专利最近已经过期。你可以从 debian-multimedia .org 仓库获取 LAME 软件包。如果你所在的国家适用这些专利，你需要确认自己拥有该专利软件的许可，或者只把这个软件用于研究目的。你可以用文本编辑器或 synaptics 把下面这行加入 /etc/apt/sources.list。

deb http://www.debian-multimedia.org stable main

注意，不带 mp3 支持来构建 pd 并不容易，所以即使你不打算用它，也建议安装这些软件包。

Gridflow

构建 gridflow 需要：

ruby1.9-dev ruby1.9 libx11-dev libpng12-dev libmpeg3-dev libquicktime-dev libjpeg62-dev xlibs-dev

你应该使用来自 gridflow.ca CVS 仓库的版本。它并不是自包含的，所以要下载到一个新目录里。输入 ./configure; make;。然后你需要手动把这个目录复制到你希望安装它的任何位置。比如说 /usr/local/lib/pd/extra/gridflow。

冲突的软件包

注意，oss4-dev 似乎会破坏 Debian 系统上的构建。你可以用下面的命令卸载它

sudo apt-get remove oss4-dev

构建 Pd 和/或 Pd-extended

在开始构建之前，你当然需要先获取源代码。获取它有很多种方式，具体选项可以看 GettingPdSource。然后根据你想构建的东西，继续看 BuildingPd 或 BuildingPdExtended。

自动构建机

Debian 的自动构建机是自动构建所有 Debian 软件包的服务器。要让这套机制正常工作，Pd 源代码必须被正确配置。
