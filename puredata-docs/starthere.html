Pd 入门

最简单的入手方式是安装 Pd-vanilla。各平台的版本可以在这里下载：

  • 下载 Pd-vanilla

安装 Pd-vanilla 并启动这个应用。你会看到 Pd 主窗口出现。Pd 主窗口会提供有用的反馈，但目前你不需要太在意它。

探索一个 patch

Pure Data 的文件叫做「patch（补丁文件）」。我们来看一个很简单的例子。在 Pd-vanilla 的 Help 菜单中打开 Browser...，点击列表中的第一项 Pure Data/，然后点击 2.control.examples/。打开第一个示例 patch，01.PART1.hello.pd。

在那里你可以点击并测试一个简单的「hello world」patch！（结果在 Pd 主窗口中查看）

有点意思吧？Pd 的 patch 是实时运行的，所以你和代码交互，马上就能得到结果。这非常适合随手实现一些想法，做出能对用户输入作出反应的乐器。不过要做到这些，我们得先知道怎么创建东西、以及能创建什么，对吧？

从零创建一个简单的 patch

说了这些，我们来从零创建一个很简单的 patch，从 pd 里听到一些声音！

打开 File -> New，会出现一个空白窗口（也就是画布）。挺吓人的吧！

在这个新画布里创建任何东西之前，先学一件很重要的事。Pd 的 patch 有两种操作模式，其中一种我们称为 Edit Mode，另一种在软件里没有名字，你可以叫它 Run Mode，或者演奏模式、交互模式（它只是「非 Edit Mode」，比如手册为了说话方便就叫它 Run Mode）。

要切换所处的模式，有两种办法。第一种是打开 Edit 菜单，点击 Edit Mode。不过这不够快，而我们在连线时会频繁切换模式，所以现在正好把编辑模式的快捷键记牢：Ctrl + E （在 mac 上是 command + e）。标题栏和鼠标图标会根据当前所处的模式变化，如下所示：

那我们就来创建点东西！打开 Put 菜单，选择 Object。这样 Pd 会自动切到 Edit Mode，鼠标上会带着一个虚线框。在 patch 里点击一个位置把它放下去，然后输入 "osc~ 440"，之后在 patch 的空白处点击一下让对象实例化。如果一切顺利，你会得到一个像这样的框：

如果你因为某种原因给对象取错了名字（比如漏掉了波浪号），对象就创建不出来，pd 主窗口里会产生一条错误：

但这不是什么大问题，只要点击这个框重新编辑，输入正确的名字，再点击框外，对象就会正确创建（要确认自己在 Edit Mode，否则你没法编辑这个框，想试可以试试）。在 List Of Objects 一节里我们会说明怎么找到所有对象的名字、怎么查看对象的帮助文件，现在先继续。

osc~ 是一个正弦振荡器，也就是用余弦函数产生音频信号的对象。440 是这个对象的第一个参数，在这个例子里把它的频率设为 440 hz。这个参数是可选的，只是设定振荡器的起始频率（稍后我们可以给它的第一个入口发消息来改变频率，这一点会在与对象交互那一节里看到）。

不过如你所见（或所闻），目前还没有声音。要听到声音，还需要三步。首先，为了训练我们「创建对象」的大脑肌肉记忆，创建 *~ 0.2 和 dac~，把对象摆成像图中这样：

*~ 是一个让我们在 Pd 中做信号相乘的对象（ * 在很多编程语言里都是乘法运算符）。0.2 是这个对象的参数，在这个例子里就是用来乘信号的数。这意味着我们把信号增益降到原来的 20%（大约降低 14db）。这会让信号变轻（只是以防万一，我们不想用很大的声音把你的音箱震坏）。

dac~ 是 Pd 里代表你实际音箱的对象，DAC 意为 Digital to Analog Converter，它的作用是把（来自 pd 的）数字信号送到你的音频接口（真正的 dac 在那里，然后把信号送给音箱）。

好，第二步（就快好了，我保证！），我们需要把这些对象连接起来。为此，在 Edit Mode 下（你大概一直都没离开过它吧？）把鼠标悬停在对象底部那块黑色矩形上（我们叫它 outlet），等鼠标图标发生变化后，拖动鼠标到下一个对象顶部的另一块黑色矩形上（我们叫它 inlet）。头几次可能不太好操作，需要练一练才能找准位置。注意连线只能从 outlet 到 inlet，不能反过来：

没有声音……怎么打开 DSP

很好！都连好了，但还是没有声音……我故意这样安排的，抱歉，不过是有原因的。最后一步是告诉 pd，我们想让它处理信号。默认情况下 pd 启动时是「DSP off」，所以任何名字以波浪号（~）结尾的对象，在你打开 DSP 之前都不会产生任何东西（顺便说一下，DSP 意为 Digital Signal Processing）。我们有四种方式打开 DSP：

# 你可以打开 Media 菜单，点击 DSP On，之后点击 DSP Off 把它关掉

# 你可以在 pd window（右上角）上找到 DSP toggle 并点击它。

# 你可以记住 DSP On（ctrl + /）和 DSP Off（ctrl + .）的快捷键 （用 supercollider 的人会认得 ctrl + . 是停止所有声音）

# （现在算进阶内容，但它确实存在，知道有这回事很重要）你可以把消息 "dsp 1" 发给 "s pd"，有些帮助文件就是用这种办法自动打开 dsp 的，所以有时你没有手动改过，dsp 却是开着的。不过现在不用担心这个。

太好了。如果你打开 dsp 并听到了我们的 440 hz 正弦波，那就说明一切都正常！如果没有，可能是音频设置有问题，可以读官方手册这里，看看设置是否正确： Audio and Midi

自动连线

还有另一种创建对象并让它们自动连接的方式，值得学一下，那我们就用自动连线功能稍微改一改我们的 patch！

先来学创建对象的快捷键。它是 Ctrl + 1（mac 上是 command + 1）。

那我们创建一个不同频率的 osc~，osc~ 442，按 Ctrl + 1，在框里输入，然后等一下！

现在的 ~ 窍门 ~ 是：输入对象名字时，我们不点击框外来实例化它，而是再按一次快捷键，这样会在刚创建的对象下面再创建一个新对象，而且它已经和第一个连好了。这个新对象我们再做一次 *~ 0.2，最后点击框外结束这一串，见图：

不错，对象创建好了，那我们现在把这个信号接到 dac~ 的第二个入口上，做出一个漂亮的拍频效果。不过在动手之前，先学怎么删除连线：要删除一条连线，在 Edit Mode 下点击这条连线（或者说 cord，也就是那条黑线），它会变蓝，表示被选中。连线被选中后按 delete，连线就会消失。然后照着图把我们的新对象接上去试试：

这里有个小趣闻：如果你在做自动连线时留意一下，会发现在你按下 ctrl（或 command）并按住时（在按下 1 完成快捷键之前），鼠标图标发生了变化，就像我们切换模式时那样（你可以回看前面的 gif，鼠标在新对象创建之前就变了）。这是另一个功能：在 Edit Mode 下按住 ctrl 可以暂时进入 Run 模式，松开 ctrl 之后又回到 Edit Mode，这在以后可能有用！

不管怎样，我们用 ctrl + 1 和自动连线再多练练新技能，试试做出下面这个 patch，就当玩玩：

这些对象是：

# phasor~ 0.5 ：它产生一个从 0 到 1 的斜坡信号，频率为 0.5（也就是周期 2 秒，周期是频率的倒数）。这个连续的斜坡可以看成一个锯齿波振荡器（但我们更多的是把它当作给表做索引的相位发生器来用……它的名字就是这么来的，有些库里有更适合做音频锯齿波振荡器的对象），不过因为它的频率很低，实际上起到了 LFO（低频振荡器）的作用。

# *~ 12 把信号乘以 12，把它的范围从 0 到 1 变成 0 到 12。

# +~ 60 给信号加上 60，于是它的范围现在是 60 到 72

# mtof~ 把 midi 音符号格式的值（60 是中央 C，每差一步是 1，所以 C# 是 61，D 是 62，以此类推）换算成频率数值，于是它把我们 60 到 72 的信号变成一段频率跨一个八度的斜坡，从中央 C 开始

剩下的我们已经知道了，就是 osc~ -> *~ 0.2 -> dac~ 。注意我们没有给 osc~ 设置任何初始频率，因为在这个例子里那没有用。那个频率参数只是初始化振荡器，一旦它收到别的数字（来自消息）或信号，它的内部频率就会被替换，那个参数也就不起作用了。

太好了！现在正是学习怎么获取每个对象的帮助的好时机，这样你就能自己发现每个对象是做什么的，开始吧！

帮助文件

对每个你想了解更多信息的对象，你都可以查看它的帮助文件！很简单。在对象上右键，会弹出一个小菜单。点击那个菜单里的 Help，瞧，它的帮助文件就打开了。好消息是，因为帮助本身也是一个 patch，你可以和它交互，像普通 patch 一样复制粘贴！

关于外部对象

除了 pd-vanilla 自带的对象，你还可以通过给 pd 添加外部对象来增加功能。这一点尤其重要，因为 Pd-extended（另一个早已停止维护、带有许多附加库的发行版）有大量教程至今还留在网上，但遗憾的是这些教程依赖这些外部对象，你在尝试创建那些对象时，很可能在 pd 主窗口里得到一些「couldn't create...」的错误。

不过用 Deken 工具搜索和安装这些对象和库很容易，可以在 Help -> Find Externals 里找到它。你可以在官方手册里读到更多，这里： Help > Find externals
