面向 Max 用户的 Pd

Pd 和 Max 是非常相似的程序，因此如果你熟悉其中一个而想学习另一个，可以把大量知识和原则迁移到新软件上。本页讨论来自 Max/MSP 的用户改用 Pd 时会遇到的一些差异。为了最轻松地过渡，你大概会想使用 'cyclone' 库，它是一组 Max/MSP 对象的克隆库（'cyclone' 包含在 Pd-extended 中）。

始终使用 [trigger] 对象

在 Max 中，从同一出口出发的（消息）连线按从右到左、从下到上的顺序执行，具体取决于接收对象在画布上的位置。在 Pd 中，这种 ''扇出连线'' 按创建顺序执行。两种方式都有问题：在 Max 中，当你整理 patch、重新排列对象时，可能意外破坏原有逻辑。在 Pd 中，无法通过观察 patch 判断哪条连线是先创建的。对 Max 和 Pd 来说，解决方案都是始终使用 [trigger] 对象，并让每条连线都对应一个出口。这些出口随后从右到左触发。

Pd 没有整数

Pd 中的每个数字都是浮点数。Pd 没有整数。[int] 对象只是在十进制小数点处截断浮点数，但对编程语言来说数据类型保持不变。这通常不是问题，但如果你要移植那些依赖整数与浮点数之别的抽象对象，可以看看 Khz Essl 的 RTC-lib 的 Pd 移植版中的 [int-or-float] 抽象对象。

[gate] 变为 [spigot]

Pd 没有内置的 [gate] 对象。取而代之的是 [spigot]，它像只有一个出口的 gate，但入口顺序相反。（cyclone 提供了与 Max/MSP 兼容的 [gate]）

替代 [cycle~]

在 Pd 中用 [osc~] 代替 [cycle~]。注意 [osc~] 右侧的相位入口只是消息入口，因此不能用它做相位调制。要做相位调制，请组合使用 [phasor~] 和 [cos~]。帮助文件中有一个示例：Pure Data/3.audio.examples/E08.phase.mod.pd。cyclone 外部对象也提供了与 Max/MSP 兼容的 [cycle~]。

[zl] 和列表

Pd 的 [list] 大致相当于 [zl]，不过工作方式不同。它强制所有内容都成为 "list"，也就是说会在经过 [list] 的任何消息前面加上 "list" 这个词。可以用 [list trim] 去掉 "list" 选择器。在 [list] 对象之上构建起来的是 [list]-abs 抽象对象集合（包含在 Pd-extended 和 pure:dyne 中）。[list]-abs 提供多种列表操作。

[prepend]

你可以用 [list prepend] 当作 prepend，但它与 Max/MSP 的 [prepend] 并不完全相同。不过一个重要区别是，[list prepend] 生成的是所谓的 "list 消息"，其内部以符号 "list" 开头。例如 [list prepend set] 收到一个数字时，会生成消息 "list set <number>"，而不是像 Max 的 [prepend] 那样生成 "set <number>" 消息。

如果你只想用 Pd-vanilla，并且想要 Max/MSP 风格的 [prepend]，可以组合使用 [list prepend] 和 [list trim]。把 prepend 和 trim 两个操作放进一个名为 "prepent.pd" 的抽象对象中，"t" 代表 "trim"。（cyclone 提供了与 Max/MSP 兼容的 [prepend]）

Cyclone 库

许多 Max 对象属于一个名为 "cyclone" 的外部对象集合，它也随 Pd-extended 一起提供。Cyclone 还包含另一个 Max/MSP 文件加载器。在 Pd-extended 中，创建一个 [cyclone/maxmode] 对象并单击它，即可打开打开面板。

打开和保存 Max patch

Pd 可以打开和保存扩展名为 .pat 的 Max「文本」patch。Pd-extended 还能打开 Max/MSP 的 .help 和 .mxt 文件。如果你想把 patch 保存为 Max/MSP 的 .pat 文件，请执行 File -> Save As，然后在保存时手动输入 '.pat' 扩展名。

Max 5 引入了基于 JSON 的新文件格式，扩展名为 .maxpat。Max 5 仍能读取 Pd 可以导出的旧 Max 4 格式 .pat 和 .mxt，但 MaxMSP 5 不再能写出 Pd 可直接读取的 .pat 或 .mxt 格式文件。Cyclone 也无法读取新的 .maxpat 文件格式。

Fredrick Olofsson 写了一个 SuperCollider patch，可以把 Max 5 的 .maxpat 文件转换成与 Max 4 兼容的 .pat 文件。转换得到的 .pat 文件随后可以在 Pd 或 Cyclone 中打开。 http://www.fredrikolofsson.com/pages/code-sc.html
