使用说明

它位于 NAT 路由器之后，所以通过 ssh 连接它时需要指定端口号：

ssh -p 2222 pddev@hq.nycresistor.com

很多依赖是用 Fink 安装的，它把所有东西装到 /sw 里。这意味着你必须相应地调整 include 和 lib 路径。

如果你想使用完整的 Fink 环境，需要用下面的命令为 shell 设置 Fink：

. /sw/bin/init.sh

自动重启

这台机器有时不太稳定，所以设置为每天美国东部时间 1:05 重启一次。
