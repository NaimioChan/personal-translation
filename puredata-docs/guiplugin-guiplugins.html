GUI 插件

从 Pd 0.43 起，可以用 Tcl/Tk 插件为 GUI 添加可选功能。使用 GUI 插件，可以同时改变 Pd 用户界面的外观和行为。

安装

GUI 插件放在 Pd 的 标准路径之一中，这些路径取决于你的平台。

命名

每个采用 xyz-plugin.tcl 命名方式、且位于 Pd 对象搜索路径中的文件都会在启动时被执行。更准确地说，是 pd-gui.tcl 里的 pdtk_pd_startup 函数按以下顺序调用启动插件的执行： 

    # [...]
    ::pdwindow::create_window
    ::pd_menus::configure_for_pdwindow
    load_startup_plugins                # 神奇之处就在这里
    open_filestoopen
    set ::done_init 1                   # pdtk_pd_startup 结束

格式

启动插件的格式或结构没有硬性要求。作为例子，下面是一些推荐加入的元素： 

# META NAME My nifty plugin
# META DESCRIPTION Does all kinds of magic that may not be necessary for everyone
# META AUTHOR <John the Developer> johndev@mail.com

package require Tcl 8.5         # 让插件能运行的最低 TCL 版本
package require Ttk             # 如果需要 Tk 或 Ttk
package require pdwindow 0.1    # 需要的任何 Pd GUI 元素
                                # + require 你脚本需要的一切。
                                #   如果缺少某项依赖，
                                #   Pd 会加载，但脚本不会。

覆盖函数

要覆盖已有的 TCL 函数，这样做： 

rename the_function the_function_old   # 这不那么重要

proc the_function {params} {           # 我们只是重新定义这个函数
      # 这里写你的新逻辑
}

# 另一种做法是，试着对这个函数执行一个
# 类似查找替换的 patcher 函数：
proc the_function {params} [my_patcher_func [info body the_function]]

启动插件中可用的 Pd 资源

pd-gui 中有一些代码是专门作为编写插件的 API 的，其中一部分在 GUIPluginsAPI 页面里有文档。要看得更完整，请查看现有插件以及 Pd 源代码。

注意！插件的 API 并不完整，也没有最终定稿。随着 Pd 变化，你的插件可能变得不可用（所以你得持续更新它）。

不过，pd-gui.tcl 里有一些供插件使用的变量： 

# 这些常量会保存实际的版本号
set PD_MAJOR_VERSION 0
set PD_MINOR_VERSION 0
set PD_BUGFIX_VERSION 0
set PD_TEST_VERSION ""
set TCL_MAJOR_VERSION 0
set TCL_MINOR_VERSION 0
set TCL_BUGFIX_VERSION 0

# 有用的变量
# Pd 文件库的根路径，更多信息见 s_main.c
set sys_libdir {}
# pd-gui.tcl 这个 GUI 脚本所在的根路径
set sys_guidir {}
# 用户指定的对象、帮助、字体等搜索路径
set sys_searchpath {}
# 硬编码的对象、帮助、插件等搜索路径
set sys_staticpath {}
# 启动时设置的命令行选项列表
set startup_flags {}
# 启动时加载的库列表
set startup_libraries {}

# 存放菜单栏的变量，以便插件进行配置
set ::pdwindow_menubar ".menubar"
set ::patch_menubar   ".menubar"

要向控制台发送消息，使用： 

::pdwindow::verbose 1 "Hello, World!"
::pdwindow::error "Houston, we have a problem!"
::pdwindow::fatal "See you on the other side."
::pdwindow::post  "This message will self destruct in five seconds."
::pdwindow::debug "Second phase initiated"

要在插件中的任何地方使用已翻译成各语言版本的字符串（如 HowToTranslatePd 所述），请使用 _ 函数。例如： 

toplevel .myplugwindow
wm title .myplugwindow [_ "My Plugin Window Title in Languages"]

画布控件

画布上出现的项（文字字体、消息框、对象框等）是画布控件上的项。以文字为例：

tk -> text widget = 功能强大的多行文本显示，对文字／字体设置有大量控制，可以嵌入图像和其他 tk 控件 tk -> canvas -> text item = 在已有画布内受限的文本显示，对文字／字体的控制有限，不能嵌入

关于修改画布控件上各项的信息可以在这里找到： http://www.tcl.tk/man/tcl8.5/TkCmd/canvas.htm 注意：这些选项并非 Pd 特有。它们是 tk 的设置。

下面演示一个在画布上更改字体的例子： 

$tkcanvas itemconfigure text -fill red -font {Helvetica 16}  ;# 单位是点
$tkcanvas itemconfigure text -fill red -font {Helvetica -16}  ;# 负数表示像素
