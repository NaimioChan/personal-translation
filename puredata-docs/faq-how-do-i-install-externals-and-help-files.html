如何安装外部对象和帮助文件？

关于管理和安装 Pd 外部对象，请在这里查看一份详细教程： 这里。

本条 FAQ 是一份更客观、更简单的指引，在大多数情况下应该够用。

有专门的文件夹用来安装库、外部对象、对象类、抽象对象、GUI 插件和帮助文件。这些文件夹用于存放未包含在 Pd 二进制文件里的内容。关于在 Pd vanilla 及其库管理器 Deken 中使用和安装库的更详细讨论可以在这里找到： 这里。

在所有平台上，都有用户专属的系统文件夹、应用程序专属的文件夹，以及全局系统文件夹。全局系统文件夹影响所有用户的所有 Pure Data 应用程序。要把内容安装进这些文件夹，需要管理员权限。 用户专属的系统文件夹影响该用户的所有 Pure Data 应用程序。 系统文件夹让你可以升级 Pd 而不弄乱其他文件。而且由于系统中可以安装不同版本的 Pd，应用程序专属的文件夹只影响那一个特定的 Pd 应用程序。这不仅是新旧版本之别，还可能是 Mac OS 上同时存在的 32 位和 64 位版本，甚至还有 Pd Extended！

在撰写本文时（2017-07-29），这些目录大多不会自动创建。 创建这些文件夹之后，Pd 就会开始使用它们（这可能需要重启 Pd）。

GNU/Linux

许多外部对象可以通过 Debian/Ubuntu/Mint 的包管理器安装。这些软件包的名称带有 pd-... 前缀。

应用程序专属
通常，如果你通过包管理器（例如 apt）安装 Pd，则为 /usr/lib/pd/extra；如果你自己编译 Pd，则为 /usr/local/lib/pd/extra。
用户专属
~/.local/lib/pd/extra（自 Pd-0.47-1 起，首选）或 ~/pd-externals（已弃用/较旧的 Pd 版本；仍然可用）
全局
/usr/local/lib/pd-externals

Mac OS X

应用程序专属
通常为 /Applications/Pd.app/Contents/Resources/extra（这在 Pd 应用程序内部。首先需要找到 Pd 应用（通常在 /Applications 里），然后右键选择 “Show Package Contents”）。
用户专属
~/Library/Pd
全局
/Library/Pd

Windows

应用程序专属
通常为 %ProgramFiles(x86)%\\Pd\\extra（64 位系统）或 %ProgramFiles%\\Pd\\extra（32 位系统）；这在 Pd 应用程序内部，64 位系统上通常在 C:\\Program Files (x86)。
用户专属
%AppData%\\Pd（自 Pd-0.47 起）
  • %AppData%\\Pd 类似于 C:\\Users\\myusername\\AppData\\Roaming\\pd
  • 在 Win7 之前（例如 Vista、XP、Win2000），这等同于 %UserProfile%\\Application Data\\Pd（Pd-0.47 之前使用的位置）
全局
%CommonProgramFiles%\\Pd
  • 在英文系统上，这通常是 C:\\Program Files\\Common Files\\Pd
  • 西班牙语：\\Archivos de programa\\Archivos comunes\\Pd
  • 德语：\\Programme\\Gemeinsame Dateien\\Pd
  • 这大多等同于 %ProgramFiles%\\Common Files\\Pd（%ProgramFiles% 是你的程序安装位置）

其他版本的 Pd

这一点在 Pd-vanilla 0.43 和 Pd-extended 0.41 中已包含。

讨论（Linux 专有）

以下是一些关于把依赖架构的二进制文件存放在 $HOME 某处的讨论出处。

http://lists.freedesktop.org/archives/xdg/2009-June/010716.html（给架构/操作系统起别称）

http://lists.freedesktop.org/archives/xdg/2008-November/010010.html（.local/share、.local/lib、$HOME/lib，还是别的什么？）

http://lists.freedesktop.org/archives/xdg/2007-November/009029.html（所有二进制文件都应放在 $prefix/bin 或 $prefix/lib{,64} —— 只有这些目录保证以可执行权限挂载，并且不会在不同架构之间共享（/$prefix/share 有时就会共享））

http://lists.freedesktop.org/archives/xdg/2007-November/009030.html（如果插件是 dlopen 的对象，我认为它们就该放在 $prefix/lib{,64} 的子目录里）
