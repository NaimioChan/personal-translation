如何在 MS Windows 平台上获得可接受的性能和延迟？

我在 Windows 上安装了 Pure Data（或 Pd-extended），为了避免音频丢帧（爆音），不得不把缓冲区（延迟）设到 100ms 以上。在 Microsoft Windows 上要怎样才能让 Pd 得到合适的延迟？

确保你的 Windows 系统为音频做好了设置。确保整体系统性能正常，为声卡安装更新的 ASIO 驱动，或者当厂商没有提供 ASIO 时安装 "ASIO4All Drivers"：http://www.asio4all.com/。此外还有 "ASIO driver for WDM kernel-streaming compliant soundcards"：http://www.asio2ks.de/

阅读 Native Instrument 的 "Windows 7 Tuning Tips for Audio Processing"：http://www.native-instruments.com/knowledge/questions/847/Windows+7+Tuning+Tips+for+Audio+Processing

另请阅读 RME 的 "Tuning Tips for Low Latency Operation"：http://www.rme-audio.de/english/techinfo/lola.htm（稍旧，可能已过时）

USB 与持久性

如果你遇到只能把外置声卡插在某一个特定 USB 端口上的问题，可以把系统的 COM 端口分配永久固定到这个设备。做法如下：goto control panel -> device manager -> com ports -> properties -> port settings -> advanced -> comport number，在那里可以为该设备永久设置 COM 端口号。
