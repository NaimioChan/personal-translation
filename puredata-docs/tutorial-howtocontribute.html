如何贡献

你可以怎样把作品贡献到这里

所以你想把自己的作品贡献到这个站点，想得到反馈，或者只是想找个地方存放你那 20 兆字节的 Pd 录音？那你来对地方了！只要按这些步骤做，在这里分享非常容易。但请注意：只上传你自己拥有、并且有权发布的东西。如果你开始把它当成盗版文件服务器来用，账号会被封。

先成为成员并登录

要使用这里的任何功能，你需要先成为成员。注册一下这个站点就可以开始了。

添加你的音乐

登录之后，你可以把音乐、作品、曲子、音轨，或者随便你怎么称呼的东西提交到这个站点。进入你的文件夹（顶部导航栏里叫做 my folder），切换到 contents 视图。然后添加一个叫做 File 的条目。会出现一个小表单，你可以在里面上传一个文件并为它添加描述。描述里应该包含你的名字（用化名也可以）以及关于你这个作品的一些信息。重要的是你文件的 Name 要完整，包括有效的文件后缀，比如 yourtrack.ogg。否则别人不知道怎么打开它。然后 upload and save 你的文件。之后你需要给它一个 Keyword，这样它才能自动出现在社区文件夹 Tracks with Pd 下面（这个名字待改）。进入你刚上传文件的 Properties 标签页，在 Keywords 列表里选择 Track。如果你希望得到反馈，还应该为你的文件 Enable discussion。再次保存。

嗯，差不多就是这样。现在你的作品已经提交，会出现在音轨区域。取决于你在这里的角色，它可能需要先由我们的一位审核者发布，他们会确认你不是在上传受版权保护的 Britney Spears mp3（或者图片）。

添加你的 patch

基本上你需要做 Adding Music 里描述的每一步，只是 Keyword 不一样。patch 使用的 Keyword 是：Patch。当然，你还需要在 Name 字段里给出正确的文件名，包括像 .pd 这样的后缀，这样别人才知道怎么处理它。

添加图片

添加图片可以在你工作区里的任何地方进行。你应该使用 Photo 产品，因为它在服务器上以不同的方案存储，处理起来更优雅。你也可以使用 PhotoAlbum 来创建一个照片集合，并通过 ftp 或 webdav 把照片加载到站点上。

给站点管理员的简短说明（普通用户不需要读这个）

要在 community 下创建更多自动收集的文件夹，你需要给那个文件夹添加一个 "Topic"。然后进入 "criteria" 标签页，制定一条规则："Subject is: some keyword"。
