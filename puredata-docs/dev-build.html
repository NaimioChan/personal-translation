构建

如果你还没有 Pd 源代码，请先阅读 GettingPdSource。rsync 方式是上手最容易的；关于获取源代码还有哪些可选方案，以及如何从零开始把源码拼装起来，详见 WorkingWithPdExtendedSources。

如果你只想构建 Pd，而不带上 Pd-extended 里包含的那些库，请阅读 BuildingPd。在尝试构建之前，你还需要安装所有依赖项。这一点因操作系统而异，见 开发者文档 中「为构建准备你的机器」一节的各操作系统页面。当你拿到全部源码和依赖项之后，就可以开始编译了。

先把整个东西构建一遍，看看能不能用。如果碰上某些自带的库在你的系统上构建不了，可以把它们从构建中移除。在 externals/Makefile 里找到 LIB_TARGETS，删掉你不想构建的库名。

GNU/Linux

在任何 GNU/Linux 发行版上构建，基本命令目前都是一样的。Makefile 会生成一个 tarball，除非它找到 dpkg-dev 工具。如果找到了 dpkg-dev 工具，最终产物就是一个 .deb。

cd pure-data/packages/linux_make
make install && make package

接着它会构建一段时间，然后你会在 pure-data/packages/linux_make/build 里看到一个 .tar.bz2 或 .deb。Makefile 会检查 Debian 工具 dpkg-shlibdeps 来判断该构建 .deb 包还是 tarball。如果你想强制构建 tarball，可以这样运行构建：

cd pure-data/packages/linux_make
make PACKAGE_TYPE=tarbz2 install && make PACKAGE_TYPE=tarbz2 package

Mac OS X

当你拿到全部源码后，就可以开始编译了。先把整个东西构建一遍，看看能不能用：

cd pure-data/packages/darwin_app
make install && make package

接着它会构建一段时间，最后应该在 pure-data/packages/darwin_app/build 里得到一个 Pd-extended.dmg 包。

Windows

当你拿到全部源码后，就可以开始编译了。先把整个东西构建一遍，看看能不能用：

cd pure-data/packages/win32_inno
make install && make package

接着它会构建一段时间，最后应该在 pure-data/packages/win32_inno/Output 里得到一个 Pd-extended.exe 包。

自动构建脚本

你也可以使用 PdLab 构建农场每晚构建 Pd 所用的同一套脚本。

  • 先获取源代码：GettingPdSource

  • 然后运行脚本：AutoBuildScripts

所以在终端里，针对 Pd-extended 做类似这样的事：

mkdir ~/auto-build
cd ~/auto-build
https://pure-data.svn.sourceforge.net/svnroot/pure-data/branches/pd-extended/0.43 pd-extended
~/auto-build/pd-extended/scripts/auto-build/pd-extended-auto-builder.sh
