Pd-Extended 已经死了吗？有什么替代品？

是的，长期受人喜爱的 Pd Extended 已经死了！:(

Pd-extended 最初是 Pd Vanilla 的一个分支，包含一些额外功能和许多随附的外部对象库。它仍然能用，你也仍然可以下载和使用它，但它已经过时、被放弃，而且没有支持！因此，继续依赖它并不是好主意。幸运的是，还有替代品。

Pd-l2ork => http://l2ork.music.vt.edu/main/make-your-own-l2ork/software/

‐ Pd-l2ork 最初是 Pd-Extended 的一个分支。它拥有 Extended 过去所有的一切，而且更多，但它只支持 Linux（Pd-l2ork 链接）

Purr Data => https://git.purrdata.net/jwilkes/purr-data-binaries/tree/master

‐ 这实际上是「Pd-l2ork 2.0」，支持所有平台（mac、windows、linux）。它正在被移植到基于 web 技术的新界面上。虽然首个版本已经可用，但还需要再把一些 GUI 对象移植到新的 web 格式。Purr Data 链接


Pd Vanilla 加上已安装的外部对象库

‐ 你可以直接使用 Pd vanilla —— Pure Data 的主版本 —— 并安装外部对象库。Vanilla 与 Pd-extended 略有不同，但除了外观上的差异，只要装好相应的库，你用 Pd-extended 能做的一切在这里也能做。

Pd Vanilla 与 Pd-extended 的主要区别在于，Pd-Extended 自带了好几个已经安装好的库，并且会自动加载其中许多。如果你需要一份在 Pd Vanilla 里安装库的指南（借助 'deken'），请查看 <https://puredata.info/docs/faq/deken>。

注意，Pd extended 0.43 里可用的那些库，在 'deken' 中以 “v00-extended” 提供
