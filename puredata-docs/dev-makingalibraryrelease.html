制作库发布版本

你在自己的库上已经工作了一段时间，现在准备发布一个版本。做法如下。这些说明假定你的库基于 Library Template，但大体上适用于任何库。

设置版本

版本在 mylib-meta.pd meta 文件中用 VERSION 标签设置。为新版本设置版本号并提交更改。假设旧版本是 0.1，你想发布的新版本是 0.2。

为发布打标签

现在，你应该用自己在使用的源代码管理工具为发布打标签。标签会用到版本号。如果你使用的是 pure-data SVN，可以这样做：

 svn cp https://pure-data.svn.sourceforge.net/svnroot/pure-data/trunk/externals/mylib \
   https://pure-data.svn.sourceforge.net/svnroot/pure-data/tags/externals/mylib/v0.2 \
   -m "tagging release 0.2"

制作源码 tarball

Makefile 模板包含一条便捷命令，用来为发布生成源码 tarball：

  cd mylib
  make dist

这会在你的 mylib/ 文件夹里生成名为 mylib-0.2.tar.gz 的 tarball。现在你可以把 mylib-0.2.tar.gz 发到你自己的网站上，上传到本站的下载页，或者发送到 pd-dev@iem.at，以便发布到SourceForge 下载站点。

创建或更新你的下载页

每个库都可以在 puredata.info 的 Downloads 区拥有自己的页面。它是查找 Pd 的库、发行版、应用、GUI 插件等的中心位置。这里有如何为你的库添加或更新页面的说明。

制作二进制发布版

你也可以制作二进制发布版。为此，你需要在每个想支持的平台上构建。然后你可以把这些文件都上传到你的网站、你库的下载页，或者通过发邮件到 pd-dev@iem.at 提交到SourceForge 下载站点。
