Android 延迟测试

用于以 LibPd 制作的 Android 应用的延迟测试工具。

显示从 Pd 中触发声音到 bonk~ 在麦克风中检测到声音之间的时间；录音延迟大约是这段时间的 1/2。bonk~ 检测器本身似乎会在往返总时间上再加上 5ms 到 15ms。

运行

  1. 把 apk 下载到手机上：PureDataLatencyTester.apk（需要在设备的 Settings >> Applications >> Unknown sources 中启用「允许未知来源」）

  2. 启动应用。

  3. 把音量调到最大，等待 11 声「ponk」，此时应该会出现数字。

  4. 把稳定的中位数值记录到下面的表格里：
