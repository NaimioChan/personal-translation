宏字典

本页是 Pd 的 C 代码中用到的宏的字典。

__APPLE__:: 仅用于 Apple Mac OS X

__gnu_linux__:: 仅用于 GNU/Linux

__linux__:: 仅用于 GNU/Linux

_MSC_VER:: 仅用于 Microsoft 的编译器

MSW:: 用于 Windows，仅 Pd 使用，已废弃，请使用 _WIN32 或 _MSC_VER

NT:: 用于 Windows，仅 Pd 使用，已废弃，请使用 _WIN32 或 _MSC_VER

PD:: 用于在 Pd 和 Max/MSP 的 API 之间选择代码

UNISTD:: 仅 Pd 使用，通常表示类 UNIX 平台（即非 Win32）。已废弃，请使用 #ifndef _WIN32

UNIX:: 仅 Pd 使用，通常指 GNU/Linux，历史上也指 IRIX。已废弃，请用 __linux__、__APPLE__ 或 #ifndef _WIN32 来区分平台。

_WIN32:: 用于 Win32 API（例如 MSVC 和 MinGW，但**不包括** Cygwin）
