Raspberry Pi

  • 据一些人说，如果确保电源提供稳定、滤波良好的电压，并且能达到 2 安培，音频表现会更稳定。

  • 如果你只是想让 Raspberry Pi 做音频，最好以无头（headless）方式运行它。把鼠标、键盘和显示器都断开。用网线接入网络，给 Raspberry Pi 一个固定 IP，然后用另一台电脑通过 SSH 连接来控制它。这样也能避免把 USB 端口降速到 1.1 时出现的键盘问题，因为大多数键盘似乎都不喜欢降速（例外：蓝牙键盘）。

  • 关于 Raspberry Pi 和低延迟音频的一般信息见 LinuxAudio wiki

可用的发行版

  • Pd-extended 包含在 Satellite CCRMA 提供的 Raspberry Pi 镜像中

  • Pd-extended 0.43.4 在 apt.puredata.info 中，或通过 直接下载

  • Pd-L2Ork 的 Debian 包，其中有安装和以无头方式运行 RPi 的说明： 下载与文档链接

  • Vanilla Pd 包含在修改过的 Raspian 镜像中，可从 Pd-LA 网站或 这个 sdsc.edu 地址下载

音频与 Raspberri Pi

设想：在这里写一小段文字，说明 Raspberry Pi 板载音频能力（mini 立体声插孔和 HDMI 音频）存在哪些问题。Raspberry Pi 上没有音频输入，所以输入需要在某个 USB 端口上接一台设备。

可用的声卡

这份清单大致是在重复你已经在 elinux.org wiki 里能找到的内容

  • Native Instruments Komplete Audio 6：至少 4 路模拟输入/输出可用（数字输入/输出未测试）。如果输入听起来像白噪声，说明 Raspberry 的固件太旧，需要用 'sudo rpi-update' 更新

  • Logitech USB To 3.5mm Jack Audio Adapter，ASIN: B0058P0I2C，配合 dwc_otg.speed=1 使用

  • Beringher UCA222，配合 dwc_otg.speed=1 使用

  • Griffin iMic。便宜，3.5mm 插孔，麦克风/线路输入，USB 供电，配合 dwc_otg.speed=1 使用

  • ESI UDJ 6，6 路 24bit 输出 @ 48kHz：4 路线路输出（RCA），2 路耳机输出（6,3mm 插孔），USB 供电，在 Raspbian 上开箱即用（也就是无需把 USB 降速），在 kernel 3.6.11+、以太网连接启用的情况下配合 Pd Vanilla 0.44-2 测试通过，但无法让它只在 2 路输出 @ 96kHz 下工作。

  • ESI UGM6 的输出配合 alsa 驱动、无需把 USB 降速即可工作，但输入与输出、以太网同时使用时不工作（有爆裂声）。禁用以太网后输入和输出似乎可以工作（更多信息见 linuxaudio wiki，链接在本页顶部）。把 USB 降速时这个接口无法被正确识别。

  • ESI GIGAPort AG（旧版本），只有最后 6 路输出可用。输出 1&2 无论是接耳机还是接 RCA 插头都不工作。不知道原因……

  • ESI GIGAPort HD+。配合 alsa 驱动、无需把 USB 降速即可正常工作。注意这是 HD+（HD plus）版本，据报告 HD 无法工作。

  • HY544 USB 3D Sound Adapter。你只需在终端窗口里输入 'amixer -c 1 set Mic 80% cap' 就能启用麦克风。在 Pd 的 preferences 中，把输出选为 'Alsa'，并在 'audio configuration' 中选择 'input Generic AudioUSB Device (hardware) Channels 1' 和 'output Generic USB Audio Device (plug-in) Channels 2'。

*M-Audio MobilePre USB 在 Raspbian 上配合 ALSA 驱动、无需把 USB 降速即可工作，但可能只能在 22,050 Hz 下工作。

不可用的声卡

  • ESI GIGAPort HD。把 USB 降速和不降速都试过。设备完全识别不到。

  • Hercules Muse Pocket LT。不加 dwc_otg.speed=1 时：可以输出 6 通道，但音质很差（爆裂声……）。加 dwc_otg.speed=1 时：2 通道可用（不过能听到一个多余的纯音），超过 2 通道不工作（"ALSA output error (snd_pcm_hw_params): Invalid argument" 或 "read other error -77"）。

  • Terratec Aureon 7.1 USB。3.5mm 插孔。最多只能 2 通道工作。把 USB 降速到 1.1 不行（会产生：schedule_periodic: Insufficient periodic bandwidth for periodic transfer）。

  • RME Fireface UCX（以及 Fireface UC、Babyface 和其他任何 UAC 2 设备）。固件提供的 USB Class Compliant 模式本应让设备在 Linux 下可用，但 ALSA /sound/usb/mixer.c 中的一个 bug 实际上让它无法运行。你要么自己编译内核并打上一个小修补，要么等 3.8 在 Raspberry 上可用（wheezy 是 3.2）。

注意："dwc_otg.speed=1" 是要加到文件 /boot/cmdline.txt 里的一个字符串，它会把所有 USB 设备（包括以太网）都降速到 1.1。出于某种原因，在 USB 降速运行时，USB 键盘（有线的或用无线接收器的）都不工作（插上一个会立刻让 pi 崩溃）。解决办法是改用蓝牙键盘，或者通过 ssh -XY 远程登录。例如参见 http://lists.puredata.info/pipermail/pd-list/2013-01/100545.html。另一方面，至少有一种设备 E-MU 0404 显然可以在 USB 保持较快的默认速率（2.0）下工作： http://lists.puredata.info/pipermail/pd-list/2013-01/100302.html
