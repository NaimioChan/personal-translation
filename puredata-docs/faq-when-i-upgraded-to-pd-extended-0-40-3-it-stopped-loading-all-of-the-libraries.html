升级到 Pd-extended 0.40.3 后，所有库都不再加载。

如果你升级到了 Pd-extended 0.40.3，然后在 Pd 窗口里看到大量这样的消息： 

  cyclone: can't load library

  zexy: can't load library

  cxc: can't load library

  ext13: can't load library

那么你需要更新你的偏好设置。默认偏好设置现在已内嵌在应用中，所以你只要删掉自己的偏好设置文件，Pd-extended 就会使用内嵌的偏好设置。你可以查阅 pdsettings FAQ 条目，了解你的操作系统上偏好设置文件的位置。

如果你想保留自己的偏好设置文件，就需要把 libdir 添加为第一个加载的库。
