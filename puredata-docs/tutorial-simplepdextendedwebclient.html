简易 Pd-extended 网页客户端

背景

你想过在 PD 里从网页或 HTTP 服务器抓取信息吗？用 HTTP 协议的 GET 请求和一个 tcp 网络对象就能轻松做到，这里用的是我们简易网页客户端对象 httpget 里的 mrpeach/tcpclient：

下载

httpget.pd - httpget-help.pd

另外，更新一些的版本可以在 Github 上的 rc-patches 里找到。

操作方法

把你想要获取的 URL 作为消息发给 httpget，它会把页面的原始数据按字节取回，并作为一个 symbol（文本字符串）输出。如果你想把输出按换行（10）、空格（32）、制表符（9）等分隔开来以便解析，就设置 End of String (EOS) 字符。字符编码见 ASCII 表。
