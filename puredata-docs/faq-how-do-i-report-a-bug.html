如何报告 bug？

所有 bug 都应该报告到 SourceForge 上的 pure-data bug 跟踪器。提交报告之前，你应该先搜索已有的报告，确认这个 bug 还没有被报告过。如果已经有报告，请把你的信息补充到那份报告里。

以下是找到 bug 跟踪器的几种途径：

  • SourceForge bug 跟踪器的直接链接
  • 如果你在用 Pd-extended，可以使用 Help 菜单中的 report bug 菜单项。
  • 重定向网址：http://puredata.info/dev/bugtracker

以下是一些应该包含在你的报告里的信息：

  • 确切的操作系统和版本（例如 Debian/stable、Ubuntu Hardy、Windows XP SP2、Mac OS X 10.4.11）
  • 出现该 bug 的确切 Pd 版本（例如 Pd-vanilla 0.41-4、Pd-extended 0.40.3-extended-20080703）
  • 测试过该 bug 的其它 Pd 版本
  • 测试过该 bug 的其它操作系统
  • 如果出现了崩溃，请附上崩溃日志
