Windows XP i386 虚拟机

pdlab1 / 141.54.160.75 是位于魏玛包豪斯大学（Bauhaus-Universität in Weimar）的一台虚拟机。这台机器已经装好 winXP SP3 并正在运行。如果你想帮忙管理这台机器，请联系 uni-weimar.de 域下的 max.neupert

使用说明

当你 ssh 登录到这台 windows 机器时，你处在 Cygwin shell 里。Pd 不能在 Cygwin 里构建。你必须用 MSYS。为了得到完整的 MSYS shell，你需要使用 ssh 端口转发和 rdesktop 访问 Windows GUI，然后从开始菜单启动 MSYS shell。在命令行中：

  • ssh -L3389:localhost:3389 pddev@IP Address

  • rdesktop -u pddev -g 800x600 localhost

同一时间只能有一个人登录 GUI，所以用完请 Log Out...。发邮件到 pd-dev@iem.at 获取 GUI 密码。你需要先用 ssh key 登录，然后才能使用 GUI 密码。

rsync 在 MSYS 下工作得不好，所以有一个单独的脚本 /msys/1.0/home/pd/extra-rsync.bat，它被安排每天运行多次。
