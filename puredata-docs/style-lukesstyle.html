Luke 的样式指南

参数：

  • 如果把 $0 作为参数传给抽象对象，它总是位于参数列表的第一位 [1]
    • 尽可能按数字顺序传递父级参数，例如 [child $0 $1 $2 whale hippopotamus] 等。

Send/Receive/Value 命名约定：

  • Send 和 Receive 用小驼峰（camelCase）书写，配对的 receive 追加 "R"（例如在 GUI 中，send 用 $0mySlider，receive 用 $0mySliderR）
  • 在符号前加上 $0 时，只有需要把它与另一个数字分开才加 "-"，例如 [r $0-1stSend]。否则符号应紧跟在后面，例如 [r $0mySend]。
  • 处理立体声时，左、右声道对分别追加 Le 和 Ri（以便与上面表示 "receive" 的 R 区分）

编程建议：

  • 要取反一个 toggle，使用 [== 0]
  • 用两个抽象对象共同的父级的 loadbang 来初始化两个或更多相互依赖的抽象对象
[1]在我看来，这类似于模拟 Python 中的 "self" 惯例
