什么是 Pd-extended？

Pd-extended 有两个主要目标：提供一套标准的库集合，以及分发对 Pd 核心的修改。提供一个包含众多库的软件包，不只是让这些库易于使用。更重要的是，它意味着你可以制作一个使用这些库的 patch，并指望在任何安装了同一版本 Pd-extended 的电脑上这些库都已经装好。

在对核心的修改方面，Pd-extended 的目标是在 GNOME GNU/Linux、Mac OS X 和 Windows 上都像原生应用一样。它还包含一批社区添加的功能，例如实验性的字符串支持，以及为提升可读性而设计的视觉样式。
