ACADIA 传感器与交互

本工作坊是 ACADIA conference 2010 的一部分。

描述

从传感器与交互开始

使用 Pd 和 Arduino 创造实时交互。传感器与计算机的结合为创造交互提供了大量机会。本工作坊将介绍如何用计算机和传感器，借助光和运动在物理世界中产生实时交互。会介绍 Pd（即 Pure Data）作为一个用于实时交互的简单编程环境。运行 Firmata 软件的 Arduino 将用来连接传感器、电子器件、舵机等。本工作坊由短讲座、动手指导，以及在讲师支持下自由学习和探索的时间组成。Pd 相当容易学，也是为艺术家设计的，但熟悉基本的计算机编程会大有帮助。你可以把本课程学到的概念应用到各种支持 Arduino / Firmata 的编程环境中，包括 Flash、Processing 等。

场地里备有所需的电子工具，但我们鼓励你安排购买下面这套套件： http://www.adafruit.com/index.php?main_page=product_info&cPath=17&products_id=170。也鼓励学生带来他们有兴趣使用的其他硬件和/或工具。带上 DMX 灯具、LED、投影仪等，来实验实时灯光控制。带上舵机或电机控制器来实验运动。带上加速度计、旋转传感器、弯曲传感器等来实验运动感知。带上基本的建筑模型制作材料，做一个模型来配合使用。我们还建议你带上你可能有的任何电子设备，包括烙铁和焊锡、剥线钳、焊接辅助工具、数字万用表等。

工作坊开始之前

参加工作坊的人需要从 NYU's Bookstore 购买一套实体计算套件。或者在线订购：

  • Adafruit ARDX - v1.0 Experimentation Kit for Arduino (Uno) - v1.3

来参加工作坊之前，请下载并安装工作坊所需的软件： Pd-extended 和 Arduino。这两个都是自由软件，可运行在 Mac OS X、Windows 和 GNU/Linux 上。如果你在安装上遇到问题，我们会在工作坊开始时先确保每个人都把一切跑起来。
