使用说明

很多依赖是用 Fink 安装的，它把所有东西装到 /sw 里。这意味着你必须相应地调整 include 和 lib 路径。详见 MacOSXFink。访问这台电脑时请记住它是一台工作站，有可能正在被人使用。使用时请保持尊重并自行斟酌，尤其是摄像头！

如果你想使用完整的 Fink 环境，需要用下面的命令为 shell 设置 Fink：

. /sw/bin/init.sh
