s_stuff.h

  • 轮询文件处理

    • pollfns

      • pollfns 是与文件句柄关联的回调函数。当文件句柄上出现新数据时，就会调用与之关联的 pollfn。在内部，pollfns 只用于处理网络套接字。 'typedef void (*t_fdpollfn)(void *ptr, int fd);' pollfn 的原型。 'void sys_addpollfn(int fd, t_fdpollfn fn, void *ptr);' 把一个 pollfn 与文件句柄关联起来。Pd 会监视该文件句柄，在有新数据时调用 pollfn。 'void sys_rmpollfn(int fd);' 把该文件句柄从 Pd 的监视中移除。

    加载器

    • 'int sys_load_lib(t_canvas *canvas, char *classname)' 尝试找到某个类名对应的文件并加载它。这个函数会遍历加载器函数列表，按顺序调用它们。如果没有当前画布，canvas 可以为 0。 'void sys_register_loader(loader_t loader)' 这个函数通常在某个加载器的 setup 函数中调用，把自己注册到 Pd。 'typedef int (*loader_t)(t_canvas *canvas, char *classname)' 供 sys_register_loader() 使用的加载器函数的原型。

    namelist 与路径

    • namelists 用于存储字符串列表，比如全局路径、画布局部路径或 helppath。 't_namelist' 这个 struct 是 namelist 链表中的一个元素。 't_namelist *namelist_append(t_namelist *listwas, const char *s, int allowdup);' 向 namelist 追加一个字符串。为了新建一个 namelist，t_namelist 指针可以为 NULL。 't_namelist *namelist_append_files(t_namelist *listwas, const char *s);' 把一个以冒号分隔（Windows 上为分号）的字符串列表加入 namelist。 'void namelist_free(t_namelist *listwas)' 释放 namelist 中的每个元素。 'char *namelist_get(t_namelist *namelist, int n)' 获取 namelist 中的第 n 个元素。 'extern t_namelist *sys_externlist' Pd 启动时要加载的库列表。 'extern t_namelist *sys_searchpath' 尝试实例化某个类时搜索的搜索路径。 'extern t_namelist *sys_helppath' 尝试打开帮助文件（helppatch）时搜索的搜索路径。 'extern int sys_usestdpath' 用于启用/禁用标准 "extra" 路径的布尔值。 'void sys_setextrapath(const char *p);' 用于设置 "extra" 文件夹实际路径的函数。

    audioapi

    • audioapi 是 Pd 配置使用的操作系统音频接口。它在 pdextended 配置文件（例如 ~/.pdextended）中指定，例如 jack：audioapi: 5 这个数字代码对应 s_stuff.h 中定义的某个 API，例如（在 Pd 0.43.4-extended 中）：

        #define API_NONE 0
  #define API_ALSA 1
  #define API_OSS 2
  #define API_MMIO 3
  #define API_PORTAUDIO 4
  #define API_JACK 5
  #define API_SGI 6
  #define API_AUDIOUNIT 7
  #define API_ESD 8
  #define API_DUMMY 9
