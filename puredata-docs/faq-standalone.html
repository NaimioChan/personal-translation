如何把 Pd 的 patch 编译成独立应用程序？

目前无法把 patch 编译成二进制程序。Pd 的 patch 文件始终是纯文本，需要 Pd 程序才能运行。

不过，Max/MSP 以及类似软件之所以允许你创建独立应用，主要原因是能在不向分发方支付授权费的情况下分发 patch。由于 Pure Data 是自由软件，你只需把 patch 连同所需的 Pd 二进制文件一起分发即可。

在 Mac OS X 上，Pd-extended 0.41.4 让这种分发变得容易。你可以用 File 菜单里的 "Make app from" 菜单项制作独立的 .app。
