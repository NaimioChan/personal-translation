如何添加 Wiki

本操作指南从 http://plone.org/documentation-old/howto/HowToAddAWiki 复制并简化而来

  1. 为你的 wiki 创建一个 Folder，或者选一个已有的。
  2. 使用 add new item 菜单或文件夹内容视图，添加一个 Wiki Page。
  3. 在 wiki 页面编辑表单中，把页面名改成 ! FrontPage 或你想要的任何名字，然后点击 save。
  4. 你大概会想让这个页面成为该文件夹的默认视图，所以把 ID 用成 FrontPage 或 index_html 这个名字。

    或者也可以进入 display / change content item as default view，选中你想作为默认页面的那一页，然后 save

  5. 现在你看到的是一个只有一页的 wiki。用平常的 wiki 方式编辑、链接和创建新页面。很快你就会养出一个健康的怪物。

更多提示：

你可以在称为 ZMI 的 manage 视图里做这些事。为此，只需在你的文件夹 URL 后面加上 manage 这个词。例如，如果你的文件夹是 http://puredata.info/Members/pdlover/lovefolder，就用 URL http://puredata.info/Members/pdlover/lovefolder/manage

  1. 在 ZMI 里，于该文件夹的 ZMI 安全标签页中配置你想要的 Zwiki 权限；参见 http://zwiki.org/QuickReference#permissions 。
  2. 要启用子主题显示：在该文件夹上设置一个值为 true 的 show_subtopics 属性。在 ZMI 里进入属性标签页，添加一个名为 show_subtopics、类型为 boolean、内容为 True 的属性。
  3. 要启用订阅：在你的 wiki 文件夹上添加一个 mail_replyto 字符串属性。把你的邮箱地址、或 dont_reply@yourdomain、或这个 wiki 的投稿邮件地址填在这里。
  4. 要用一组默认页面快速启动你的 wiki：以 manager 身份登录后访问 !http://.../YourPage/setupPages。
  5. 要在你的 wiki 里设置问题跟踪：以 manager 身份登录后访问 !http://.../YourPage/setupTracker。

提示

  1. 默认情况下，wiki 页面处于可见状态，不参与工作流。
  2. 在创建许多互不相干的小 wiki 之前请三思，少而大一些的 wiki 可能没那么令人困惑。

更多帮助：

http://zwiki.org 上有其余内容。然后可以试试 #zwiki 、 #plone 、 http://zwiki.org/ZwikiAndPloneCMFDiscussion 、 http://zwiki.org/UserDiscussion ， 或者 plone-users 邮件列表。
