PdLab

Pd Lab 是一个协助 Pd 开发的地方。它由若干台构建服务器组成，每晚在各种平台上构建 Pd。

系统的部分服务由 Bauhaus-Universität Weimar 托管（此前由 IDMI/Polytechnic University 托管）。

编译农场

Pd 编译农场是一批机器的集合，它们运行的操作系统在 Pd 用户中很常用。

chroots

所有 Debian 服务器都通过 chroots 运行多个发行版/版本。在一台给定的机器上运行 ls /var/chroot 就能看到有哪些可用的 chroot。如果你想使用其中一个 chroot，运行下面的命令来「登录」：dchroot -d -c chroot-name。例如，在 debian-stable-amd64 上有一个 32 位的 i386 chroot：

pddev@debian-squeeze-amd64:~$ ls /var/chroot/
squeeze
pddev@debian-squeeze-amd64:~$ dchroot -d -c squeeze
(squeeze-i386)pddev@debian-squeeze-amd64:~$

自动构建流程

AutoBuildProcess 在所有这些服务器上运行。以前有一个中心的 rsync 服务器，但现在每台服务器都自给自足，只从 SVN 和 git 获取代码。

获取访问权限

如果你是 Pd 开发者，就可以获得编译农场任意一台机器的 ssh 访问权限。账户名是 pddev，你需要用自己的 ssh 密钥登录。要让你的 ssh 密钥生效，需要在 pd-dev 上申请访问权限，并在邮件里附上公钥（即 ~/.ssh/id_rsa.pub）。下面是登录 debian-stable-amd64 机器的示例：

ssh pddev@debian-stable-amd64.pdlab.puredata.info

加入编译农场！

我们在寻找运行 Fedora、Arch、Mac OS X 10.7 和 10.8 等的机器。我们也可以为其他 Windows 版本（比如 windows 8）搭建更多虚拟机，但需要有人来负责这些机器的安装与维护。

如果你能支配一台具有上表中缺失的 CPU/操作系统组合的计算机，就可以加入编译农场，帮助其他人每天自动构建并上传最新的 Pd 和 Pd-extended。首先你需要确认几件事：

  • 这台计算机需要常连互联网，并且 ssh 可用。有固定 IP 会更好。

  • 你需要是这台计算机的管理员，以便安装必要的软件和依赖，并确保系统不会突然被改动。

  • 这台计算机必须每天开机，时间要足够完成自动构建。

为加入编译农场做准备，请安装所有依赖、获取源代码，并按 AutoBuildProcess 中所述尝试构建一次 pd-extended。需要构建方面的帮助，或想学会设置每日自动构建循环，请在 pd-dev 上做个自我介绍。

为便于访问编译农场的机器，我们给每台主机分配一条 DNS 记录，例如 debian-stable-i386.pdlab.puredata.info。如果你在 PdLab 中增加或移除机器，或者改动它们的 IP 地址或名称，请把信息转告我们的 DNS 管理员。
