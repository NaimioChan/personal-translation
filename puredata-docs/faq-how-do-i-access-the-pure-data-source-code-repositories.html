如何访问 pure-data 源代码仓库？

Pd-vanilla 使用 Sourceforge 上的 GIT 仓库进行开发。

对整个 Pd 社区来说，还有 pure-data 这个托管在 Sourceforge 上的 Subversion (SVN) 仓库，它包含大多数外部对象，……以及 Pd 世界中的开发内容。

此外还有一些相关源代码仓库，可以在这里获取更多信息：GettingPdSource
