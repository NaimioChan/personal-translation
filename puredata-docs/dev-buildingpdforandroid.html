为 Android 构建 Pd

为 Android 构建外部对象

从 Android NDK r5 开始，你可以把 Android 编译器当作一个独立编译器来用。这意味着你可以构建供 Android 上的 Pd 使用的外部对象。你可以构建使用 MakefileTemplate 的库，只要设置 UNAME=ANDROID，它应该能在所有平台上工作：

make NDK_BASE=/path/to/android-ndk-r5 UNAME=ANDROID CFLAGS=-I/path/to/pd/src

把 Pd 嵌入 Android 应用

为 Android 构建 Pd 最常见的方式，是把 libpd 嵌进一个 Android 应用里。这里有 一批自由、开源的应用。你可以在这里了解更多： http://gitorious.org/pdlib/pages/Home

为 Android 构建无 GUI 的 Pd

也可以直接为 Android 构建 Pd，但它只会作为一个无界面的 UNIX 进程运行。Pd 是用 Android NDK（Native Development Kit）为 Android 构建的，NDK 是用于构建 C 和 C++ 代码的 Android 开发环境。下面是一个粗略的构建示例，如果你把它跑通了，请帮忙改进这个 wiki 页面：

./configure --with-androidversion=android-7
make
