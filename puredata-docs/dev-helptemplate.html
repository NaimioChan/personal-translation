帮助模板

使用 PDDP 帮助模板

PDDP 小组提出了一个基本模板，用于任何 Pd 帮助文件。其想法是有一个标准的页面，它足够灵活，能适用于所有 Pd 对象，同时又足够标准，让人们可以快速浏览帮助文件，用最少的气力迅速找到自己需要的信息。

当前这个模板凝聚了大量工作和讨论，但我们并不声称它已经完美或者不可更改。相反，我们正在向使用这个模板的人收集反馈，以便改进它。加入我们：PDDP 工作组

文件

doc/pddp/templates/template-help.pd

这个文件是原始模板，作为编写帮助文件的基础。它只有一页。如果你需要更多页面来放示例或文字，可以在帮助文件的 “more_info” 区段里使用子 patch。

这个首页应当包含关于入口、出口和参数的完整信息。如果这意味着你的内容会比模板更长，那就保持页面同样大小，不做缩放，而是依靠滚动 patch 来查看。所有帮助文件的首页都应当是同样大小。

doc/pddp/templates/template-help_elements.pd

这个文件包含所有标准图形元素，把它们插入 template-help.pd 就能完成你的帮助文件。你可以直接从该文件把它们复制粘贴到你的帮助文件中。

doc/pddp/templates/example-help.pd

这个文件是一个示例文件，它在模板中填入实际内容，用来说明帮助文件最终应当是什么样子。这个例子相当简单，所以在更复杂的帮助文件里情况会有所不同。

标准 receive 符号

  • 模板中所有画布（'cnv'）都有 receive 符号，因此它们的外观可以动态改变。

  • 帮助文件页眉：$0-pddp.cnv.header

  • 帮助文件页脚：$0-pddp.cnv.footer

  • 入口标题：$0-pddp.cnv.inlets

  • 出口标题：$0-pddp.cnv.outlets

  • 参数标题：$0-pddp.cnv.arguments

  • more_info 标题：$0-pddp.cnv.more_info

  • 对象高亮：$0-pddp.cnv.highlight

  • 入口/出口 0：$0-pddp.cnv.let.0

  • 入口/出口 1：$0-pddp.cnv.let.1

  • 入口/出口 2：$0-pddp.cnv.let.2

  • 入口/出口 3：$0-pddp.cnv.let.3

  • 入口/出口 4：$0-pddp.cnv.let.4
