构建你自己的 Debian 包

  1. 从自动构建站点下载两个源码 tarball（挑一个日期）： http://autobuild.puredata.info/auto-build/

  2. 在你的终端里运行这些命令： 

sudo apt-get install dpkg-dev devscripts debhelper
tar xjf Pd-extended_0.43.1~20120928-source.tar.bz2
mv Pd-extended_0.43.1~20120928-source.tar.bz2  pd-extended_0.43.1~20120928.orig.tar.bz2
cd pd-extended
tar xjf ../Pd-extended_0.43.1~20120928-source.debian.tar.bz2
debuild -uc -us

如果你想生成一个用于上传到 Launchpad 或 OpenSUSE Build Service 这类构建服务的源码包，运行 debuild -S -uc -us。这样你就会在你运行命令的那个目录下面——也就是放着这些 tarball 和 pd-extended/ 文件夹的地方——得到一个包含所有所需文件的完整源码包。
