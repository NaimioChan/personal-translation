怎样在 GNU/Linux 上以实时优先级运行 Pd？

在 Linux 上，Pd 可以由 root 用户作为实时进程运行，这样音频中断（咔哒声）会少得多。本质上，操作系统给 Pd 进程更多的工作时间，让它不被其他程序打断。

不过，以 root 身份运行非系统程序被视为安全风险，而且如果用户没有管理员权限，这显然不是一个选项。好在有一个系统配置文件可以接受优先级设置选项。

摘自Ubuntu Studio wiki。

注意：如果你安装了 JACK，可能不必编辑 /etc/security/limits.conf，因为较新版本的 JACK 会把同样的设置加到 /etc/security/limits.d/audio.conf 这个文件里。运行下面的命令检查该文件是否存在。如果看到有内容打印出来，就不需要按下面的步骤做。


cat /etc/security/limits.d/audio.conf

你只需要给你的 "audio" 组访问 rtprio 和 memlock 限制的权限。为此，只要运行下面这几条命令，它们会往 /etc/security/limits.conf 文件里添加几行，并把你的用户加入 audio 用户组：


sudo su -c `echo @audio - rtprio 99 >> /etc/security/limits.conf`

sudo su -c `echo @audio - memlock unlimited >> /etc/security/limits.conf`

sudo adduser username audio

当然，要把 username 换成你实际的用户名。

注意：在 Ubuntu Intrepid 及更高的版本上默认没有 audio 组。你可以运行下面这些命令创建一个 audio 组并把自己加进去：


sudo addgroup audio

sudo addgroup username audio

重启。现在用实时标志 -rt 运行 pd 应该可以工作了，你应该会在 pd 控制台上看到类似 "Realtime Priority Enabled" 的内容。像这样运行它（或者把 -rt 加到启动选项里）：

pd -rt
