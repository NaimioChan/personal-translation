构建 Pd

Windows Msys1 与 Msys2

关于 Pd-0.48-1，读这里 https://puredata.info/docs/developer/WindowsMinGW

2012 年前后的过时内容：

如果你还没有 Pd 源代码，请先阅读 GettingPdSource。等你拿到全部源码、打好补丁之后，就可以开始编译了。先把整个东西构建一遍，看看能不能用。（如果你要构建 Pd-extended，请阅读 BuildingPdExtended。）

GNU/Linux

在任何 GNU/Linux 发行版上构建，基本命令目前都是一样的。Makefile 会生成一个 tarball，除非它找到 dpkg-dev 工具。如果找到了 dpkg-dev 工具，最终产物就是一个 .deb。

cd pure-data/pd/src
./configure && make

或者，如果你的 Pd 核心是从 SVN 拿的，你还需要用 autoconf 生成 configure 脚本 

cd pure-data/pd/src
autoconf
./configure && make

接着它会构建一段时间，然后你会在 pure-data/pd/bin 里看到二进制文件。你可以直接从那里运行，也可以运行 make install 把它安装到 /usr/local。

Mac OS X

当你拿到全部源码后，就可以开始编译了。先把整个东西构建一遍，看看能不能用：

cd pure-data/packages/darwin_app
make darwin_app_core

接着它会构建一段时间，最后应该在 pure-data/packages/darwin_app/build 里得到一个 Pd-extended.app。但这只是 Pd 核心。
