照片与图像怎么处理？

这里说明 Image 与 Photo 的区别，并解释它们在文档中的用法。

Photo 与 Images 的区别？

允许使用两种类型的图片：Images 和 Photos。

Image 对应的是一张普通图片，通常用在某个位置上是合适的，并且大多已经预先处理成正确的大小。

Photo 是一个数字图像文件，上传时就可以同时换算成多种尺寸。据说还能旋转、调亮等等，不过我还没能做到。

预设了以下尺寸： 

       显示名称     期望的宽度 x 高度
       -------------------------------------------
       thumbnail      128  x  128
       xsmall         200  x  200
       small          320  x  320
       medium         480  x  480
       large          768  x  768
       xlarge        1024 x 1024

其中只会使用较大的那一维（高度或宽度）以保持比例正确，但绝不会大于原始尺寸。因此，分辨率应当始终等于或大于要显示的最大尺寸。

怎样在文档中嵌入 Images？

在 structured Text 中，位于 bilder 文件夹里、名为 hallo.png 的 Image 可以写成： 

            "Text bei bilderlosen browsern":img:bilder/hobby.png

或者像在 html 里那样： 

          <img src="bilder/hobby.png">

当然这里允许使用所有 html 标签，比如 width、height 等。

怎样在文档中嵌入 Photos？

和 Images 一样，见上面，不过也可以用 html 标签缩放： 

        <img src="bilder/klangplatten.jpg?size=thumbnail"> thumbnail

        <img src="bilder/klangplatten.jpg?size=xsmall"> xsmall

        <img src="bilder/klangplatten.jpg?size=small"> small

        ...

        <img src="bilder/klangplatten.jpg?size=large"> large

        ...

效果看起来就是这样：

xsmall

small

...

medium

...

thumbnail 拉宽到 480
