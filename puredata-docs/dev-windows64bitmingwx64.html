Windows 64 位/MinGW-x64

从 2018 年（Pd-0.48-1）起，参见： http://puredata.info/docs/developer/WindowsMinGW，其中有使用 Msys2 为 64 位构建 Pd 的指南。

2011 年前后的过时内容：

本页用于记录使用 MinGW 开发 64 位 Windows 构建环境的进展。你可以从 32 位的 MinGW 页面获取一些思路：WindowsMinGW。

以下指南仍不完整

  • 按 WindowsMinGW 中所述安装 32 位工具链（可以跳过安装库的步骤）

  • 从 http://www.drangon.org/mingw/ 获取 mingw basic library 和 mingw multimedia library 的 x64 原生二进制文件，并解压到 C:\mingw_w64。

  • 把 C:\msys\1.0\bin 和 C:\MinGW\bin 从 %PATH% 中移除，并把 C:\mingw_w64\bin 加入 %PATH%

  • 编辑 /etc/fstab（C:\msys\1.0\etc\fstab），把 C:\MinGW 替换为 C:\mingw_w64

  • 现在打开 msys shell 并检查版本：

  $ gcc --version
  gcc.exe (GCC) 4.5.2 20100804 (prerelease)
