Debian 打包策略

在 Debian 中打包时，Pd 带来了一些不寻常的挑战。本页用来记录如何最好地让 Pd 相关的东西符合 Debian Policy。

  • 虽然 .pd 文件是纯文本，但它们最像的其实是脚本，也应该按脚本对待。这意味着它们应该放在 /usr/lib/pd，而不是数据目录 /usr/share/pd

  • 帮助文件（helppatch）本身就是 Pd patch，也就是脚本，所以把它们放进 /usr/lib/pd 也可以。

  • 帮助文件在 Pd 之外读起来没什么用，所以帮助文件不应该放进 `/usr/share/doc'

  • HTML、PDF、.txt 和 README 应该像其他任何软件包一样放进 /usr/share/doc
