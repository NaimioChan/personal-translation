为 Maemo 构建 Pd

  • 确保你有最新版本的 Maemo 5 10.2010.19-1

  • 设备上的 root 权限

  • 安装 tcl8.5_8.5.8-2maemo2_armel.deb、tcl8.5-dev_8.5.8-2maemo2_armel.deb、tk8.5_8.5.8-1maemo1_armel.deb、tk8.5-dev_8.5.8-1maemo1_armel.deb、libasound2-dev

  • ./configure 并 make pd-0.42-5
