运行 Pd 需要什么？

Pd 能在任何可以运行 GNU/Linux、MacOS X、IRIX、BSD 或 Windows 的机器上编译和运行。如果你只是做简单的 MIDI 处理，任何一台老 486 大概就够了。如果你想做实时音频合成或其他花哨的多媒体，就需要一台又大又快的电脑。越大越快，越好。

要做 MIDI 和音频，你需要合适的 MIDI 和音频硬件，以及能让你的操作系统使用这些硬件的相应驱动软件。有些 Pd 扩展可能需要其他特殊硬件，或者靠它们才能发挥得更好。例如，GEM 库需要好的 GL 库和 3D 硬件才值得一用。由于 Pd 主要用于实时演出，你可能也会想用一些特殊的输入设备。游戏摇杆、3D 鼠标以及各种各样的 MIDI 控制器都能让你的 Pd 体验有价值得多。

事先提醒一下，Pd 仍在开发中。在现阶段使用 Pd，你需要一些耐心和一点冒险精神。
