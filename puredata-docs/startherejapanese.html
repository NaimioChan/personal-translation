从这里开始！

如果你正要开始使用 Pd，不妨读一读这一页，它讲的是 Pd 的基础。

开始使用 Pd

起点是安装 Pd-extended。下面可以下载适配各种操作系统的 Pd 版本：

  • 下载 Pd-extended

Pd-extended 是给 Pd 增加了功能的版本。下载之后，先安装再启动它。会显示 Pd 主窗口。Pd 主窗口里会显示程序的各种反馈，比如运行结果和错误信息。目前暂时不用在意它。

探索 patch

Pure Data 的文件被称为「patch」。我们来看一个。点击 Pd-extended 的「帮助」菜单 → 「Pd 帮助浏览器」，打开帮助浏览器。点击最上面的 "Manual"，然后是 "+Start Here/"。再点击 "+ここからスタート.pd"，patch 就会打开。请试着照着这个 patch 里的三个步骤操作。

那我们就继续前进吧

你已经站在用 Pd 编程的路上了。 Pure Data Floss Manual 里有更深入的入门介绍，可以参考。
