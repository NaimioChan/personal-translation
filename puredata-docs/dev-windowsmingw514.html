在 Windows 上用 MinGW 5.1.4 构建 Pd

在 Microsoft Windows 上用免费工具就能轻松构建 Pd。虽然你大概也能用下面所有软件包的最新版本，但这里提供的链接是已知可用的版本。如果你是在这套配置的旧安装基础上升级，那么实际上只需要升级 C:\MinGW 里的文件。最简单的做法是删掉整个 C:\MinGW 文件夹，然后把 MinGW、MinGW 附加包 以及之后的所有步骤重新走一遍。

Cygwin

Cygwin 安装起来相对容易，并且为 subversion 这类东西提供了好得多的工作环境。MinGW 对部分 GNU 工具的支持不完整，所以也要安装 Cygwin 的版本。

  • 下载 setup.exe 并运行来安装 Cygwin。安装在默认位置。

进入 Select Packages 界面后，点击右上角标着 View 的按钮，把它改成 Full。然后找到 make、openssh、patch、sed、svn、zip 和 unzip，确保它们设为安装。这表现为显示一个将要安装的版本号，而不是 Skip。

MinGW

下载 MinGW 软件包安装程序并运行：

  • MinGW-5.1.4.exe

选择 Current 发行版。在标着 Select the type of install: 的下拉菜单中选择 Full。MinGW 站点上有一份站点上的 HOWTO，对了解其他一些细节有帮助。

MSYS

  • 下载这个：https://sourceforge.net/projects/mingw/files/MSYS%20Base%20System/msys-1.0.11/MSYS-1.0.11.exe/download

MSYS 是围绕 MinGW 构建的开发环境。它提供了自由软件开发人员习惯的许多开发工具，比如 autoconf、make 等等。MSYS 安装程序完成后，会弹出一个正在运行脚本的 cmd.exe 窗口。该脚本会问你几个问题：

    This is a post install process that will try to normalize between
    your MinGW install if any as well as your previous MSYS installs
    if any. I don't have any traps as aborts will not hurt anything.
    Do you wish to continue with the post install? [yn ]

这里回答 y。

    Do you have MinGW installed? [yn ]

这里回答 y。

    Please answer following the in the form of c:/foo/bar.
    Where is your MinGW installation?

这里回答 c:/MinGW（注意！是正斜杠，而且区分大小写！）。安装脚本会打印一些文字，最后写出：

    Oh joy, you do not have c:/mingw/bin/make.exe. Keep it that way.

这没关系。安装的第一阶段已经完成。按任意键。接下来是 msysDTK，你只需一路点击安装程序，接受所有默认设置即可。

  • 下载并安装这个： msysDTK-1.0.1.exe

配置 MSYS

关于如何为 MSYS 设置环境变量，参见 Max Berger 的 设置编译器。此外那里还有上面安装 MSYS 过程的截图。接下来的步骤中，你会用到由 MSYS 安装程序装好的 MSYS shell。你可以从桌面快捷方式启动它，也可以走 Start --> Programs --> MinGW --> MSYS --> msys。进入 MSYS shell 后，你需要运行以下命令来创建 /usr/local：

mkdir /usr/local

现在用一款好的文本编辑器编辑 C:\msys\1.0\etc\fstab（Wordpad 可以用，但不要用 Notepad），或者在 MSYS shell 里编辑 /etc/fstab。在该文件中，确保有以下两行（大小写很重要！）：

c:/MinGW /mingw
c:/MinGW /usr/local

然后退出所有 MSYS shell，重新启动一个 MSYS shell，用 mount 命令检查上面两个目录是否都已挂载。为此运行 mount。你应该能在其余输出中看到这些行：

...
c:\MinGW on /mingw type user (binmode)
c:\MinGW on /usr/local type user (binmode)
...

MSYS coreutils

这个包里包含了不少好用的工具。特别是 ffmpeg 构建系统需要 MSYS coreutils 包里的 pr.exe。先把 tar 包下载到 C:\msys\1.0：

  • coreutils-5.97-MSYS-1.0.11-snapshot.tar.bz2

现在用 MSYS shell（Start --> Programs --> MinGW --> MSYS --> msys）把 tar 包解压到 MSYS 的各个文件夹里。不过 tar 包通常会创建一个 'coreutils-5.97' 文件夹，所以我们需要加上 --strip-components 1：

cd /
tar --strip-components 1 -xjf coreutils-5.97-MSYS-1.0.11-snapshot.tar.bz2

7-Zip

7-Zip 是 Windows 上的免费应用程序，可以解压各种各样的压缩包。解压 MinGW 的二进制文件推荐用它。安装时下载 7-Zip，然后一路点击安装程序。之后你可以在开始菜单的「程序」里找到 7-Zip。

在 7-Zip 中选中所有要解压的文件，点击 Extract，保持 Current pathnames 设置，然后选择 C:\MinGW，再点击 OK。最后应该看起来像这样：

MinGW 附加包

接下来下载这些，并把它们保存到 C:\MinGW：

  • mingw-utils-0.3.tar.gz

  • autoconf2.5-2.61-1-bin.tar.bz2

  • autoconf-4-1-bin.tar.bz2

  • automake1.10-1.10-1-bin.tar.bz2

  • automake1.9-1.9.6-2-bin.tar.bz2

  • automake-3-1-bin.tar.bz2

  • gettext-0.16.1-1-bin.tar.bz2

  • gettext-0.16.1-1-dll.tar.bz2

  • libiconv-1.13-mingw32-bin.tar.gz

  • libiconv-1.13-mingw32-dev.tar.gz

  • libiconv-1.13-mingw32-dll-2.tar.gz

  • mingw-libgnurx-2.5.1-bin.tar.gz

  • mingw-libgnurx-2.5.1-dev.tar.gz

你可以用 7-Zip 解压到 C:\MinGW，也可以在 MSYS shell 里做。用 MSYS 的话，从桌面快捷方式或 Start --> Programs --> MinGW --> MSYS --> msys 启动一个 MSYS shell。进入 MSYS shell 后，运行以下命令安装这些 tar 包：

cd /mingw
tar xzf mingw-utils-0.3.tar.gz
tar xjf autoconf2.5-2.61-1-bin.tar.bz2
tar xjf autoconf-4-1-bin.tar.bz2  
tar xjf automake1.10-1.10-1-bin.tar.bz2
tar xjf automake1.9-1.9.6-2-bin.tar.bz2
tar xjf automake-3-1-bin.tar.bz2
tar xzf libiconv-1.13-mingw32-bin.tar.gz
tar xzf libiconv-1.13-mingw32-dev.tar.gz
tar xzf libiconv-1.13-mingw32-dll-2.tar.gz
tar xjf gettext-0.16.1-1-bin.tar.bz2
tar xjf gettext-0.16.1-1-dll.tar.bz2
tar xzf mingw-libgnurx-2.5.1-dev.tar.gz
tar xzf mingw-libgnurx-2.5.1-bin.tar.gz

（注：你也许想把上面这些 autoconf 和 automake 的 tar 包放进 C:\msys\1.0，因为它们看起来更像 MSYS 工具而不是 MinGW 工具）

来自 GTK+ 的二进制文件

GTK+ 项目提供了一些面向 Windows 的二进制文件。我们这里用到其中几个。接下来下载这些，并把它们保存到 C:\MinGW：

  • pkg-config-0.23-2.zip

  • glib_2.20.3-1_win32.zip

  • freetype-2.3.6.zip

  • freetype-dev-2.3.6.zip

接下来你需要把所有这些解压到 C:\MinGW，最简单的做法和上面一样，用 7-Zip。

可选：你也可以在 Cygwin shell 里做这件事，但可能会遇到权限问题。如果你遇到像 bad file number 这样的错误，说明权限不对。给 C:\MinGW 里的每个文件都加上 Full Control 权限就能解决。要通过命令行安装，从桌面快捷方式或 Start --> Programs --> Cygwin --> Cygwin Bash Shell 启动一个 Cygwin shell。进入 Cygwin shell 后，运行以下命令安装这些 tar 包：

cd /cygdrive/c/MinGW
unzip pkg-config-0.23-2.zip
unzip glib_2.20.3-1_win32.zip
unzip freetype-2.3.6.zip
unzip freetype-dev-2.3.6.zip
chmod -R a+rx /cygdrive/c/MinGW

ASIO SDK

首先下载 ASIO SDK。你必须同意 Steinberg 的许可协议，然后提交一个邮箱地址，之后他们会把下载 URL 发到你的邮箱。把 asiosdk2.2.zip 解压到 path/to/pd/asio，使文件位于 path/to/pd/asio/ASIOSDK2。

安装 Inno Setup 打包

Inno Setup/ISTool

Inno Setup 是 Windows 上的免费安装程序生成器。 ISTool 是更好用的 Inno 脚本 IDE。它用来组装 Pd-extended 安装程序。

  • ispack-5.2.3.exe 会为你下载并安装好一切。

从 SVN 的 '/sources' 构建

对于其余的库，你可以从 SVN 取得源代码，然后运行这个脚本把全部构建出来：

cd pure-data
svn co https://pure-data.svn.sourceforge.net/svnroot/pure-data/sources
cd sources
./build-libs-on-mingw.sh

这会运行一段时间，如果顺利完成，它就装好了 Pd-extended 所需的全部库。如果中途失败，再次运行 ./build-libs-on-mingw.sh 应该是安全的。

用 MinGW 构建 Pd-extended

./configure 目前还不能在 MinGW 下工作，所以你必须用这个

svn co https://pure-data.svn.sourceforge.net/svnroot/pure-data/branches/pd-extended/0.41/
cd 0.41/pd/src
make -f makefile.mingw

更新这一流程

这个构建流程肯定还有可以改进的地方。MinGW 被广泛使用，但它并没有被广泛标准化。所以很多人在 MinGW 上构建常见库的方式各不相同。这个流程是为了把它们统一起来。

以下文档看起来包含很有用的信息，但目前还没有被纳入这个流程：

  • zlib、libpng、libjpeg、libtiff 等等

  • libschroedinger

gcc 4.3

MinGW 仍然使用 gcc 3.4.5，Pd-extended 就是用它构建一切。如果你愿意，也可以试用更新的 gcc 版本。外面有一些当前版本 gcc 的测试版，例如 ! The TDM builds 或这个 4.3.0 alpha 构建：

  • gcc-4.3.0-20080502-mingw32-alpha-bin.tar.gz

安装它时，它会替换掉 MinGW 的 gcc 3.4.5。在 MSYS shell 中运行以下命令来安装：

cd /mingw
tar xzf gcc-4.3.0-20080502-mingw32-alpha-bin.tar.gz
