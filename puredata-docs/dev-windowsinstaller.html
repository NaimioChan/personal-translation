Windows 安装程序

更新的信息在这里： https://github.com/pure-data/pure-data/blob/master/msw/build-nsi.sh

在 Windows/Msys2 上你应该安装 Nsis 包：

# 32 位 

pacman -S mingw-w64-i686-nsis

# 64 位 

pacman -S mingw-w64-x86_64-nsis

2011 年前后的过时内容：

  1. 获取 Pd-extended 的 源代码压缩包，或者参见 GettingPdSource 了解自动构建用的源代码（用 rsync 最方便）

  2. 按照这些说明搭建 MinGW 构建环境：WindowsMinGW

  3. 在 pd-extended/packages/win32_inno 中运行：make install

  4. 在 pd-extended/packages/win32_inno 中运行：make package

  5. 如果没有自动启动，双击 packages/win32_inno/pd-inno.iss 启动 Inno Setup。

  6. 用 Inno Setup 中的编译按钮、F9 或菜单选项编译 Pd 安装程序。
