Pd 无法启动。

在 OS X 上，Dock 里的图标一直在弹跳，但随后停住，Pure Data 就是启动不起来。

如果 Pure Data 在你的电脑上启动不了，就检查一下你的 /private/etc/hosts 文件是否配置正确。
你可能会在控制台里看到消息 ERROR: failed to allocate port, exiting!

OS X 下的默认内容看起来是这样：

##
# 主机数据库
#
# localhost 用于配置回环接口，
# 在系统启动时。不要改动这一条。
##
127.0.0.1 localhost

255.255.255.255 broadcasthost
::1 localhost
fe80::1%lo0 localhost

如果你的文件里缺少 localhost，Pd 就无法启动。它会在启动时卡住，然后退出。

关于 hosts 文件的说明，见 wikipedia http://en.wikipedia.org/wiki/Hosts_%28file%29
