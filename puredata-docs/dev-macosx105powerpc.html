2048 f3:62:7a:cd:3c:c2:4c:84:8f:89:ae:4b:b4:5c:96:12 /etc/ssh_host_rsa_key.pub (RSA)
1024 99:e5:7d:6c:fd:f5:cf:f8:6d:be:26:7e:c2:ac:0a:03 /etc/ssh_host_dsa_key.pub (DSA)

使用说明

很多依赖是用 Fink 安装的，它把所有东西装到 /sw 里。这意味着你必须相应地调整 include 和 lib 路径。详见 MacOSXFink。

如果你想使用完整的 Fink 环境，需要用下面的命令为 shell 设置 Fink：

. /sw/bin/init.sh
