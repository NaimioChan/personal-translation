我能用 Pd 运行用 Max/MSP 写的 patch 吗？

如果你把 Max/MSP patch 保存成 pat/mxt 文本格式的「Max patch file」，那么 Pd 能打开这个文件。Pd 不会打开二进制格式的 pat 文件。麻烦的地方在于，所有对象必须名称相同并且相互兼容，patch 才能工作。

你也可以把文件保存成「Max patch file」。在 GNU/Linux 和 Windows 上，可以在保存面板底部选择文件类型。在 Mac OS X 上，只要把文件名末尾的 .pd 改成 .pat，Pd 就会用「Max patch file」文本格式保存。

Krzysztof Czaja 的 Cyclone 项目专门针对 Max 兼容性，包含一个用于二进制和文本 Max patch 的加载器。它包含一个 cyclone 对象，目的是简化转换。要使用它，用「-lib cyclone」把 cyclone 作为库加载，然后创建一个对象「cyclone」，点它，用 File-Open 对话框打开一个 Max patch。

Max 5 引入了新的基于 JSON 的文件格式，扩展名为 .maxpat。Max 5 仍然能读取 Pd 可以导出的较老的 Max 4 格式 .pat 和 .mxt，但 MaxMSP 5 不能再写出 Pd 能直接读取的 .pat 或 .mxt 格式文件。Cyclone 也无法读取新的 .maxpat 文件格式。

Fredrick Olofsson 写了一个 SuperCollider patch，可以把 Max 5 的 .maxpat 文件转换成 Max 4 兼容的 .pat 文件。转换得到的 .pat 文件之后可以在 Pd 或 Cyclone 中打开。 Fredrick Olofsson 的 MaxPat 转换器
