pdlab2 / 141.54.160.76 是魏玛包豪斯大学的一台虚拟机。它运行 Windows 7。如果你想帮忙管理这台机器，请联系域名 uni-weimar.de 下的 max.neupert

使用说明

当你 ssh 登录到这台 Windows 机器时，会进入一个 Cygwin shell。Pd 无法在 Cygwin 中构建，必须使用 MSYS。要获得完整的 MSYS shell，你需要用 ssh 端口转发和 rdesktop 访问 Windows GUI，然后从开始菜单启动 MSYS shell。从命令行：

  • ssh -L3389:localhost:3389 pddev@IP Address

  • rdesktop -u pddev -g 800x600 localhost

同一时间只能有一个人登录 GUI，所以用完请 Log Out...。发邮件到 pd-dev@iem.at 获取 GUI 密码。你需要先用 ssh 密钥登录，然后才能使用 GUI 密码。

rsync 在 MSYS 下工作得不好，所以有一个单独的脚本 /msys/1.0/home/pd/extra-rsync.bat，它被安排每天运行多次。
