  1.   C 编码风格。源代码应当通过 C 编译器的大多数 "warnings"
（例如 linux 上的 -Wall；参见 makefile。）有些写法上的随意是有意为之，
例如函数原型的松散使用（见下文）以及从较长数值格式到较短格式的不加转换的
转换。代码目前还不遵守 "const"。
    2. 

  2. 1.  结构元素中的前缀。结构元素的名称总是带有 K&R 风格的前缀，如 ((t_atom)x)->a_type，
其中 "a_" 前缀表示 "atom"。这样做是为了提高可读性（尽管这一约定源自早期 C 编译器的
一个限制）。常见前缀有 "w_"（word）、"a_"（atom）、"s_"（symbol）、"ob_"（object）、
"te_"（text object）、"g_"（graphical object）和 "gl_"（glist，图形对象列表）。
另外，全局符号有时也带前缀，如 "s_float"（字符串为 "float 的符号）。typedef 以 "t_" 为前缀。
大多数 私有 结构，即定义出现在 ".c" 文件中的结构，以 "x_" 为前缀。
    3. 

  3. 2.   函数参数。许多函数把名为 "x" 的指针作为第一个参数，它是指向函数前缀所暗示的
结构的指针；例如 canvas_dirty(x, n)，其中 "x" 指向一个画布（t_canvas *x）。
    4. 

  4. 3.  函数原型。至少在两个不同文件中使用（除了它们定义所在的文件之外）的函数，
在相应的 include 文件中声明原型。只在一个文件中提供、在另一个文件中使用的函数，
就在使用处声明原型。这只是为了让 ".h" 文件的体积缩小，便于阅读。
    5. 

  5. 4.  古怪的私有术语。有些术语来自其他历史上相关的程序，特别是 "ugen"
（它就是一个波浪号对象；参见 d_ugen.c。）
    6. 

  6. 5.  空格。制表符算 8 个空格；缩进是 4 个空格。缩进的花括号单独占一行，例如：
        if (x)
    {
        x = 0;
    }
    

    7. 




每行不应超过 80 个字符。



    

  1.   最大限度兼容 Max patch 层。提供了 "Import" 和 "Export" 函数，
它们力求与 0.26 版本的 patch（ISPW 版本）严格兼容，但目前还差得远。
在可能的情况下，Mac 上出现的功能将来某天也会在 Pd 中提供；例如 Mac 上的 connect
消息提供分段连线，而在 Pd 中它们会退化成直线。Opcode Max 中许许多多的 UI 对象
不会出现在 Pd 中，至少一开始不会。
    2. 

  2.   与 Max 0.26 "externs"（即源代码级兼容）兼容。Pd 的对象尽可能
贴近 0.26 对象的风格，只在 0.26 模型明显有缺陷的地方破例。这些地方是：
    3. 

  3. 1.  任何涉及 MacIntosh "Handle" 数据类型的地方都改为使用
char  或 void 。
    4. 

  4. 2.  Pd 向方法传递真正的单精度浮点参数；
Max 使用双精度。
提供了这些 typedef：
    t_floatarg、t_intarg 用于通过消息系统传递的参数
    t_float、t_int 用于 "word" 联合体（例如在 atom 中。）
    5. 

  5. 3.  命名糟糕的实体改了名字：
        w_long --> w_int（在 "union word" 结构中）
    

    6. 

  6. 4.  许多库函数被改名，参数也不同；
我希望在编译 Max 外部对象时提供一个 include 文件来给它们起别名。
    7. 

  7.   函数名前缀。
许多函数名带有前缀，表明它们属于哪个 "package"。
例外的是：
    typedmess、vmess、getfn、gensym (m_class.c)
    getbytes、freebytes、resizebytes (m_memory.c)
    post、error、bug (s_print.c)
它们都被频繁调用，难以归入简单的类别。
重要的 package 有：
(pd-gui:)   pdgui -- 全部
(pd:)       pd -- 所有 "pd" 对象通用的函数
            obj -- 所有类似 Max 的 "可 patch" 对象通用的函数
            sys -- "系统" 级函数
            binbuf -- 操作 binbuf 的函数
            class -- 操作类的函数
            (other) -- 以该 Pd 类命名的通用函数
    8.
