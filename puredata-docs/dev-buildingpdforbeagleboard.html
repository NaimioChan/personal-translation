为 Beagleboard 构建 Pd

虽然我在网上能找到的唯一文档是关于让 Pda 在 Beagleboard 上构建的，但把音频弄顺之后，完整的 Pd 工作得很好。

安装设置

我没能让我当时用的 Ångström 发行版上的 Pd 正常工作——声音就是一直不好听。我建议在 Beagleboard 上装 Ubuntu。我用的是 Ubuntu 10.04。完整说明可以在 eLinux.org 的 wiki 上找到： http://elinux.org/BeagleBoardUbuntu 。

确保你有某种声音输出。虽然 ALSA 驱动在被 Pd 使用时似乎有 bug，但用 ALSA 的正常系统声音开箱就应该能用；不过声音输出的混音器音量可能被设成了 0。用 alsamixer 把所有音量都调大吧。我记得我不得不调大 'headset volume' 之类的。你可以用 mpg123 或 aplay 把一些声音输出送给 ALSA 驱动；mpg123 很方便，允许你使用 http:// 地址：

$ mpg123 http://frey.co.nz/content/music/frey-recirculate.mp3

安装 Pd

直接用 apt-get：

$ sudo apt-get install puredata

试着用 ALSA 运行（预计声音是坏的）：

$ pd -alsa

如果它用 ALSA 驱动能工作，那你比我运气好。如果你听到的是这种声音： http://soundcloud.com/damian/pure-data-on-beagleboard-sound-issue 那么你需要按接下来的步骤做。

让声音正常工作

如果你在运行音频测试 patch 时声音听起来像这样： http://soundcloud.com/damian/pure-data-on-beagleboard-sound-issue 那么你需要改用 OSS 驱动，而不是 ALSA。

加载 OSS 驱动的内核模块：

$ sudo modprobe snd-pcm-oss

用 OSS 运行 Pd。你需要把音频块大小设成至少 1024 个采样，否则会听到爆音（不过它们听起来和 ALSA 的爆音不一样）：

$ pd -oss -blocksize 1024

完成

没那么糟，对吧？
