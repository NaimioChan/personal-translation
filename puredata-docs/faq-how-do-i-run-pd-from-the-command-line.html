如何从命令行运行 Pd？

在命令行上启动 Pd 的方式在各个平台（GNU/Linux、Mac OS X 和 Windows）上有所不同。

GNU/Linux
通常你只需在命令行上使用 pd。如果 Pd 安装在非标准位置，比如从源代码构建时，你必须指定二进制的完整路径。例如 ~/trunk/pd/bin/pd。 你也可以先 cd 到 Pd 的 bin 目录，然后启动 ./pd。例如 cd ~/trunk/pd/bin/ && ./pd
Mac OS X
由于 Mac OS X 上的 Pd 有与其他平台不同的启动流程，请启动 GUI 进程：/Applications/Pd-0.41-4.app/Contents/MacOS/Pd 或 /Applications/Pd-extended.app/Contents/MacOS/Pd-extended。要想先运行 pd 进程，你必须把 Tcl/Tk 的 Wish.app 装在电脑上某个能被找到的位置，比如 /Applications。然后运行：/Applications/Pd.app/Contents/Resources/bin/pd。
Windows
如果你用的是 Windows 的 cmd.exe shell，请使用 Windows 路径：C:\Program Files\pd\bin\pd.com。你也可以从 Start -> Run... 运行 C:\Program Files\pd\bin\pd.com，它会启动自己的 cmd.exe。
Windows/Cygwin
使用 Cygwin shell 时，你需要使用 UNIX 风格的路径，并且用 Cygwin 的特殊目录来表示 Windows 盘符：/cygdrive/c/Program\ Files/pd/bin/pd.com
Windows/MinGW/MSYS
使用 MinGW MSYS shell 时，你需要使用 UNIX 风格的路径，并且用 MSYS 的特殊目录来表示 Windows 盘符：/c/Program\ Files/pd/bin/pd.com
