如何在 Mac OSX 上为 Pd 脚本添加别名

我想在 MacOSX 上使用一些我在 Linux 里写的、用到 Pd 的 shell 脚本，但 shell（Terminal）会话不知道如何从 Application Bundle 内部启动二进制文件。

在 Linux 上，我输入 "pd" 再回车就能启动 pd。在 Mac OSX 上，我可以输入 "open -a Pd-extended" 来启动 Pd App……但我更希望直接访问 bundle 里的 pd 二进制文件，这样同一个脚本在 Linux 和 OSX 上都能用。

解决办法很简单：在 shell 会话中为 Pd-extended.app 里的二进制文件添加别名。

把下面内容加到 ~/.bash_profile：


# pd 命令行

alias pd="/Applications/Pd-extended.app/Contents/Resources/bin/pd"

alias pdsend="/Applications/Pd-extended.app/Contents/Resources/bin/pdsend"

alias pdreceive="/Applications/Pd-extended.app/Contents/Resources/bin/pdreceive"

重启 shell 会话，现在 "pd"、"pdsend" 和 "pdreceive" 命令应该就能启动各自对应的程序了。

备注

~/.bash_profile 位于你的主目录，因此任何改动只对你自己的用户账号生效。
