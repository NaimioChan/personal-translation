Debian 打包模板

LibraryTemplate 自带一个 debian 目录，用来为 Debian 以及 Ubuntu、Linux Mint 等任何 Debian 衍生发行版制作 .deb 软件包。它的设计目标是与 Debian pkg-multimedia 团队的工作流程配合，该流程使用 git-buildpackage。

准备文件

一个基本库所需的全部文件都已经包含在 debian 文件夹里了。要把它们用于你自己的库，请把 debian 文件夹中所有文件里的 template 一词替换成你的库名，然后再把 template-meta.pd 里的信息改成你库的信息。

构建软件包

你可以不太费劲地在自己机器上构建一个可安装的 .deb 软件包，下面是做法概览：

  1. sudo apt-get install puredata-dev dpkg-dev devscripts debhelper

  2. cd 进入你的库

  3. make dpkg-source

  4. debuild -uc -us （如果你已经配置好用 gpg 密钥签名，就去掉 -uc -us）

  5. ls -l ../pd-*.deb （现在你能看到你的软件包了！）

为特定的发行版和版本构建

你可以用 Debian 的工具 pbuilder 或 cowbuilder 为任何 Debian、Ubuntu、Mint 等发行版构建软件包。这更复杂一些，下面是简要总结：

  • sudo apt-get install puredata-dev dpkg-dev devscripts debhelper cowbuilder

  • 如果你还没有配置过 cowbuilder，那么执行：sudo cowbuilder --create

  • 在你的库里运行：make dpkg-source

  • .dsc 文件、.orig.tar.gz tarball 和 .debian.tar.gz tarball 就是你的源码包

  • 构建这个软件包：

    • cd ..

    • sudo cowbuilder --update

    • sudo cowbuilder --build pd-template_0.0-0.0.dsc（把 template 和版本号替换成你库里的信息）

上传到 Launchpad

Ubuntu 提供了 https://launchpad.net/，这是一个可免费使用的服务，用来为 Ubuntu 各发行版构建 Debian 软件包。它是测试和分发你的软件包的一个有用途径，而且相当易用。它还会在不同架构上构建，比如 i386、amd64 等。

  • （针对你目标的 ubuntu 发行版编辑 debian/changelog）

  • make distclean

  • make dpkg-source （生成原始源码 tarball）

  • debuild -uc -us （确认你的软件包能构建）

  • debclean （清理掉所有东西）

  • rm ../pd-comport* （删除 debuild 产生的东西）

  • make dpkg-source （生成原始源码 tarball）

  • debuild -S （生成源码包）

  • cd ..

  • dput ppa:eighthave/libdirs pd-comport_0.1-1~maverick_i386.changes

提交到 pkg-multimedia 的 git

下面是具体步骤，这里用 <package> 代表示例库，也就是说，对于库 motex，<libdir> 是 motex，<package> 是 pd-motex，<user> 是你在 alioth.debian.org 上的用户名。

  • cd /path/to/sources/<libdir> （进入你库的根目录）

  • uscan --dehs --report （测试 debian/watch 文件）

  • make dpkg-source （生成 Debian 源码包）

  • git-import-dsc --pristine-tar ../<package>_1.0-1.dsc （用 git-buildpackage 工具导入）

  • cd <package>

  • git config user.name '<Your name>' （设置你的 Debian 姓名）

  • git config user.email '<Your email>' （设置你的 Debian 邮箱地址）

  • git config gitweb.owner '<Your name>' （设置你的 Debian 姓名）

  • git tag （查看标签，看看是不是全都想要）

  • git tag -d debian/0.9-1 （如果这些标签还不合适就把它们删掉）

配置远程仓库并推送上去

  • ssh <user>@git.debian.org /git/pkg-multimedia/setup-repository <package>

  • git remote add alioth ssh://***@git.debian.org/git/pkg-multimedia/<package>.git

  • git push alioth master upstream pristine-tar --tags

现在你应该能在 git.debian.org 的 gitweb 上看到你的新仓库了： http://git.debian.org/?p=pkg-multimedia/pd-motex.git;a=summary
