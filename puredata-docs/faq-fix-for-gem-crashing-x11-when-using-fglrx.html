在 GNU/Linux 上使用 fglrx 显卡驱动时 Gem 导致 X11 崩溃

如果你在用 fglrx 驱动，并且打开 GEM patch 时 X11 崩溃，你需要设置环境变量 GEM_SINGLE_CONTEXT=1，把下面这一行加入你的 ~/.bashrc 或 /etc/profile：

export GEM_SINGLE_CONTEXT=1

如果你用的 shell 不同（例如「tcsh」），做法可能略有差异。
