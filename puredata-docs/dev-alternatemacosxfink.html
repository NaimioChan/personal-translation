Mac OS X 的 Fink 替代构建方法

构建工具

Fink

构建 Pd 所用的大部分外部库都可以很方便地通过 Fink 安装。如果你还没装 Fink，这里有下载说明。下面的命令会安装 Pd 各个部分所需的所有库。

对于 Pd-extended，你需要很多软件包。如果你想直接安装二进制文件、省下编译所有东西的时间，把命令 fink 换成 apt-get。并非所有软件包都有二进制格式，所以那些你只能用 fink 编译。下面这些可以从 stable 二进制发行版安装：

sudo fink install coreutils-default svn-client sed libsndfile1-dev libsndfile1 libogg libvorbis0 libtiff pcre lua51 lua51-dev imlib2 libgnugetopt

下面这些需要从源代码编译：

sudo fink install libtheora0 imagemagick imagemagick10-dev libjpeg libpng3 libmpeg freetype219 gsl mysql15-dev postgresql82-dev ladspa ladspa-dev sdl libusb a52dec-dev a52dec-shlibs libiconv libiconv-dev

这些软件包需要从 unstable 的 Fink 发行版安装。要使用这些包，你还需要把 Fink 安装配置成使用 unstable 发行版（对我来说它一直相当稳定）。Fink FAQ 第 5.8 问说明了做法。

比较好的做法是先把所有依赖都从 stable 装一遍，再切到 unstable 装其余的。如果某个 unstable 包又带来了更多依赖，我就切回 stable 把它们都在那里试着构建，然后再切回 unstable 把所有东西装完。听起来可能很复杂，其实并不是。无非是复制粘贴一些软件包名字，再运行几次 fink configure。

sudo fink install ffmpeg ffmpeg-dev libavutil-dev libavcodec-dev libavcodec1-dev libavcodec1-shlibs libdv4 speex3 lame-dev lame-shlibs fftw3 libftgl1 libhid0 libquicktime0 faac-shlibs faac-dev libfaad1-dev libfaad1-shlibs libpostproc1

这些依赖目前不是自动构建所必需的，但 SVN 里有一些库会用到它们。它们构建起来可能很麻烦，所以是可选的。

flite liblo0 ladspa-cmt flac graphviz fftw

框架

Apple 开发者工具
你需要安装 Apple Developer's Tools，才能得到 Apple 的编译器和工具。它随 Mac OS X 光盘提供，你也可以从 Apple 下载。请确认你还安装了 X11User.pkg 和 X11SDK.pkg。
Tcl/Tk

构建 Pd 需要 Tcl/Tk 框架。目前 Mac 上没有 Tcl/Tk 的定期发布版，但从源代码构建很容易。要下载 Pd-extended 所用的版本，请用这些 rsync 说明。先把 pd-extended rsync 下来，再把 tcltk_core-8-4-branch rsync 到同一个文件夹，然后运行这些命令：

Jack OS X
Pd-extended 在 Mac OS X 上也使用 Jack。除了最基本的测试，我没有更多使用经验，但据说可以正常工作。它确实能正常编译。我用的是这个版本：JackOSX.0.76.pkg.zip 它是个安装程序，下载之后直接运行安装程序即可。

构建

cd tcltk_core-8-4-branch
./tcltk_core-8-4-branch_auto-builder.sh
sudo mv build/tcl/Tcl.framework /Library/Frameworks
sudo mv build/tk/Tk.framework /Library/Frameworks

如果你运行的是 Mac OS X 10.4 Tiger 或更新的版本，这一步在技术上并非必需，因为系统已包含 Tcl/Tk 8.4.7。但运行更新版本的 Tcl/Tk 有很多好处

在开始构建之前，你当然需要先拿到源代码。获取方式有多种，可选方案见 GettingPdSource。然后根据你想构建的东西，继续看 BuildingPd 或 BuildingPdExtended。
