如何安装 PdVst

http://crca.ucsd.edu/~jsarlo/pdvst/http://crca.ucsd.edu/~jsarlo/pdvst/

PdVst 是什么

PdVst 是一个软件系统，它让 Pd patch 可以作为 VST 插件运行。

工作原理

PdVst 由两个主要部分组成，一个 VST 插件和一个定制版的 Pd。当宿主应用程序打开一个 PdVst 插件时，会读取一个 setup 文件来确定该插件的信息，比如要使用的 Pd patch 文件、参数数量等，然后启动定制版的 Pd，并打开在 setup 文件中找到名字的那个 Pd patch 文件。

安装

  • 下载 PdVst.zip
  • 把 pdvst 文件夹复制到你要与 PdVst 配合使用的应用程序（如 Cubase.exe）所在的目录（例如 c:\Program Files\Steinberg\Cubase VST\）
  • 把你的 .pdv、.pd 以及任何所依赖的 Pd 外部对象 .dll 库文件复制到 pdvst 目录。
  • 把你的插件 .dll 文件（例如 Pd_Gain.dll）复制到该应用程序的 vst plugins 目录（例如 c:\Program Files\Steinberg\Cubase VST\VstPlugins\）

要创建你自己的插件，复制并重命名 Pd_Gain.dll 或 Pd_Synth.dll，并创建一个同名的 .pdv setup 文件。

这里是更新后的 0.4 版（2016）

运行方法请参见 http://puredata.info/Members/jyg/software/pdvst 和 https://github.com/jyg/PdVst。
