openSUSE

这是一份在 openSUSE 11 上成功安装 pd-extended 0.40.3（stable）的粗略指南

从 http://downloads.sourceforge.net/pure-data/Pd-0.40.3-extended.tar.bz2 下载源码 tarball

从 http://gem.iem.at/ 下载 stable gem

解压这两个包。把 gem 文件夹放到 pd-extended 文件夹的根目录下。务必把它重命名为 "Gem"。

通过 Yast 下载依赖项。（稍后会补上 openSUSE 的列表——先参照 fedora 或 debian 的 howto 搜索一下）

cd ~/Pd-0.40.3-extended/packages/linux_make

make install

make package

cd ~/Pd-0.40.3-extended/packages/linux_make/build/usr/local

sudo make install
