在 GNU/Linux 上，字体很奇怪，而且／或者过大或过小

当心旧版本的 Tcl/Tk（8.4 或更早）

Tcl/Tk 8.4 及更早的版本会大量猜测字体，而且常常猜错。把 Pd 和 Tcl/Tk 8.5 或更新版本一起使用，字体会好得多。

如果你运行的是基于 Debian 的 GNU/Linux（Debian、Ubuntu、Mint、Knoppix 等），试着确认你的 wish shell 是 8.5 或更新版本：

sudo apt-get install tk8.5

sudo update-alternatives --config wish

重建字体数据库

这是因为 Pd 找不到正确的字体。首先，你要确认已经安装了正确的字体处理软件包 ttf-dejavu 和 x-ttcidfont-conf。你可以在 Synaptic 里检查它们

如果它们已经安装，就在 Terminal 里用这条命令试着重新安装：

sudo apt-get install --reinstall x-ttcidfont-conf ttf-dejavu

指定字体

也可以试着使用 -font-face 启动选项。 你可以用 "fc-match" 命令这样搜索字体：

$ fc-match mono

在 GNU/Linux 上，为 Pd 所熟知的最好的字体是 "Courier 10 Pitch"、"DejaVu Sans Mono"、"Bitstream Vera Sans Mono"、"Droid Sans Mono" 和 "Andale Mono"。

$ pd -font-face "Andale Mono"
