什么是「DSP 环路」？

我单击「Audio ON」时收到消息「error: DSP loop detected (some tilde objects not scheduled)」，而且声音不工作！

在模拟电子系统中，你可以很容易地把调音台的输出接回它的某个输入，把该通道的音量调大，从而得到啸叫。 这是因为模拟系统里的一切几乎都是同时发生的。

然而计算机不是这样工作的，因此你不能要求一个 Pd patch 基于它自己同时产生的输出来计算结果。

Pd 以所谓的块（block）为单位工作（即一组采样，例如默认的 64 个采样），每个块中的所有采样必须先计算完才能输出。

因此，当一个 patch 需要依赖同一个块内计算出的信息才能产生输出时，就出现了 DSP 环路。

你可以使用「Find」菜单下的「Find last error」功能，查出是哪些对象导致了 DSP 环路。

绕过这个问题最简单的办法，是在相互连接的对象之间至少引入一个块的延迟。[send~] 和 [receive~] 对象对此很有用，因为它们自带一个块的延迟。

要改变每个块中计算的采样数，可以使用 [block~] 对象。
