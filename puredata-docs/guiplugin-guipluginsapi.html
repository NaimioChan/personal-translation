GUI 插件 API

从 0.43 开始，Pd 提供了多种方式把你的代码挂接进来，让 GUI 按你想要的方式行事。GUI 插件没有单独的 API，相反，你可以把 Pd 的整个 Tcl 侧都看作 GUI 插件的 API。pd-gui 里有些东西是专为 GUI 插件定制的，关于有哪些可用，你可以通过阅读 pd-gui.tcl 得到大致了解，更具体地说是那些可以挂钩的全局变量和 proc。

这里只是对可用内容做个快速概览，更多信息请查看 Pd 源代码，尤其是 pd-gui.tcl 和 pdtk_canvas.tcl。

用于获取信息的事件

如果你想在状态变化时触发某些操作，最好的办法是绑定到一个虚拟事件

<<EditMode>>

标记为 %W 的窗口的 Edit Mode 发生了变化

<<Loading>>

标记为 %W 的 patch 开始加载

<<Loaded>>

标记为 %W 的 patch 加载完成

用于每个 patch 属性的数组

这些数组都用 $mytoplevel 窗口（也就是 .x%lx 画布 ID）作为键。

::loaded

布尔值，patch 开始加载时设为 0，patch 加载完成后设为 1

::editmode

表示 editmode 状态的布尔值

::editingtext

表示是否有文本框（obj、msg 或 text）正在被编辑的布尔值

窗口的类别

DialogWindow

任何对话框窗口，例如 Find、iemgui、Font 等

PatchWindow

patch 的 Tk 画布所在的窗口

PdWindow

这个类别只适用于 Pd 窗口本身

各类图形元素的标签

Tk 允许你给每个项打上多个标签，Pd 中绘制的每个项都带有一个或多个标签。其中最便于使用的是各种逻辑元素的标准标签：

  • obj - 常规的非图形对象框

  • msg - 消息框

  • cord - 一条连线，信号和消息都算

  • inlet - 一个入口，信号和消息都算

  • outlet - 一个出口，信号和消息都算

  • atom - 浮点数或符号的原子框

  • text - 一段文本注释

  • label - text 的同义词

  • scalar - 一个图形化的标量元素

  • graph - 用于显示数组的图表

  • GOP - 标记画布上可视区域的 Graph-on-Parent 框

用于设置颜色的全局变量

从 Pd-extended 0.41 起，有一组全局变量用来设置 Pd 许多基本元素的颜色，从背景色、框的轮廓和填充，到连线、文字等。 

set ::canvas_fill "white"
set ::text_color "#000"
set ::select_color "#00f"
set ::dash_outline "#f00"
set ::dash_fill "#fff"
set ::box_outline "#ccc"
set ::graph_outline "#777"
set ::atom_box_fill "#eee"
set ::msg_box_fill "#f8f8f6"
set ::obj_box_fill "#f6f8f8"
set ::signal_cord_highlight "#58a"
set ::signal_cord "#558"
set ::signal_nlet $signal_cord
set ::msg_cord_highlight "#474"
set ::msg_cord "#121"
set ::msg_nlet "#fff"
set :mixed_nlet "#88aaff"
