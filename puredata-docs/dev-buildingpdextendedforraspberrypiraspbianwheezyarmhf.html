为 Raspberry Pi（Raspbian Wheezy）构建 Pd-extended

为 Raspberry Pi（Raspbian Wheezy）构建 Pd-extended 0.43.3

*基于 Tedbot 的教程——已针对 Raspbian Wheezy 更新

1. 把源码仓库加入 aptitude 

  $ sudo nano /etc/apt/sources.list

2. 粘贴这一行并保存（ctrl+o、Enter） 

 deb-src http://archive.raspbian.org/raspbian/ wheezy main contrib non-free rpi

ctrl+x 退出

3. 更新 aptitude 

 $ sudo apt-get update

4. 我们需要安装构建用的包 

 $ sudo apt-get install dpkg-dev build-essential devscripts

5. 获取 Pd 的依赖项 

 $ sudo apt-get install rsync autoconf libfftw3-dev liblua5.1-0-dev swig libvorbis-dev ladspa-sdk libspeex-dev libmp3lame-dev lua5.1 tcl-dev

6. 获取源代码（地址将来很可能会变，所以如果链接失效请查看论坛） 

 $ wget http://autobuild.puredata.info/auto-build/2012-10-02/Pd-extended_0.43.3~20121002-source.tar.bz2
 $ wget http://autobuild.puredata.info/auto-build/2012-10-02/Pd-extended_0.43.3~20121002-source.debian.tar.bz2

7. 解包 

 $ tar xjf Pd-extended_0.43.3~20121002-source.tar.bz2
 $ cd pd-extended
 $ tar xjf ../Pd-extended_0.43.3~20121002-source.debian.tar.bz2
 $ cd ..

7. 构建 pd 的依赖项 

 $ sudo apt-get build-dep puredata gem pdp

8. 去掉有问题的 "-lpd" 

 $ nano externals/OSCx/configure

按 Ctrl+w，在 "linux:" 里搜索 "-lpd" 并把它删掉

Ctrl+o，然后按 "Enter" 保存

Ctrl+x 退出。 

 $nano externals/OSCx/configure.ac

搜索 "-lpd"，做同样的修改

9. 开始构建吧 

 $ cd packages/linux_make

然后 

 $ nohup make install > makeinstall.log &

监视它 

 $ tail –f makeinstall.log

4-5 小时后它应该会说："linux_make install succeeded" 按 Ctrl+c 退出

10. 来制作 debian 包吧 

$ nohup make package > makepackage.log &

监视它 

$ tail –f makepackage.log

它应该说类似这样的内容： "dpkg-deb: building package pd-extended' in /home/pi/pd-extended_0.43.3/pd-extended/packages/linux_make/Pd-0.43.3-extended-20121010.deb'." 按 Ctrl+c 退出

11. 安装（pd-extended_0.43.3-20121010.deb 必须和刚生成的那个一致） 

$ sudo dpkg –i Pd-extended_0.43.3-20121010.deb

这样就该搞定了！Pd-extended 现在应该装好了。而且它听起来应该很糟糕。

这就是为什么 Miller 建议你运行这条命令： 

$ sudo chmod 4755 /usr/bin/pd-extended

这会给 pd root 权限（音频输出会好得多）
