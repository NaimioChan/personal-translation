Makefile 模板

如果你要新建一个库，应当从 pure-data SVN 中包含的库模板开始。该模板可用于 GNU/Linux、Mac OS X 和 Windows/MinGW。此外还初步支持为 Android、iPhoneOS 和 Windows/Cygwin 构建库。

你可以在终端里运行下面这条命令，从 SVN 获取整个 template 示例项目：

svn co https://pure-data.svn.sourceforge.net/svnroot/pure-data/trunk/externals/template

该模板也设计得便于制作成 Debian 包。多数情况下，你只需把单词 template 查找替换为你的库名。

要把这个 Makefile 用于你的项目，先编辑 template-meta.pd 文件。在 NAME 注释里把 'template' 一词替换为你的库名，并在 VERSION 注释里设置库的版本。然后，在这个模板项目中任何出现 template 一词的地方，都替换成你的库名。你的项目文件夹必须与库名、meta 文件等同名。

常用命令

make

构建库中的所有对象

make install

构建库中的所有对象，并作为 Libdir 安装

make dist

把所有相关文件打成带版本号的 tarball，便于发布和打包

make clean

清理所有构建产物（即 .o、.pd_linux、.pd_darwin 等文件）

make distclean

清理到与原始发行 tarball 一致的状态

make dpkg-source

生成一个 Debian 源码包

平台特定选项

对象

对于只在某些平台上构建的对象，可以把它们加到各受支持平台专用的 SOURCES 变量里。

SOURCES_android = 
SOURCES_cygwin = 
SOURCES_macosx = 
SOURCES_iphoneos = 
SOURCES_linux = 
SOURCES_windows =

设置要链接的库

对于依赖不同库（比如 libpthread 或 libspeex）的对象，你可能需要对每个平台设置不同的标志。可以用平台专用的 LIBS 变量来做：

LIBS_android = 
LIBS_cygwin = 
LIBS_macosx = 
LIBS_iphoneos = 
LIBS_linux = 
LIBS_windows =

更新日志

  • 1.0.2 移除了 SOURCES_* 变量，并把 CFLAGS、LDFLAGS 和 LIBS 移到编辑区段

  • 1.0.1 新增 dpkg-source，用于生成 Debian 源码包
