调试 Pd 外部对象

使用 gdb

当你的外部对象导致崩溃、而你想定位代码中引起崩溃的那一行时，GDB 特别有用。

设置

hans$ gdb /Applications/Pd-0.39.2-extended-test3/Contents/Resources/bin/pd

(gdb) add-symbol-file my_blah.pd_darwin

启动 Pd，然后用进程名和 PID 附加到它上面：

(gdb) attach pd.12341

用 tab 补全，你会看到有两个 pd 进程。在 Mac OS X 上，编号较大的那个才是你要附加的。

现在设置一个断点：

(gdb) break hid_free

然后让 Pd 重新运行起来：

(gdb) continue

使用 valgrind

Valgrind 特别适合用来监视程序的内存使用情况（分配与释放）、查找内存泄漏，以及发现与内存相关的错误，比如试图读取数组末尾之后的数据。

用法

Valgrind 的调用方式如下：

valgrind pd

解读输出

参见 Valgrind 文档。
