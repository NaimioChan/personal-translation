64 位支持

支持 64 位处理器是 Pd 过去几年里的一个项目。我们离完整的 64 位兼容已经非常接近，这意味着我们可以转向 64 位处理中更令人兴奋的方面。对 Pd 来说，把 32 位浮点数格式换成 64 位浮点数格式，意味着 Pd 里唯一的数值类型也能表示很常见的 32 位整数，比如 UNIX 时间戳以及更多东西。目前，32 位浮点数格式大约只能表示整数的 19 位。

以下是 Pd 中 64 位支持的粗略历史：

0.41

  • Pd vanilla 第一批可用的 64 位构建

0.42

  • Pd vanilla 中已知的全部主要 64 位 bug 已修复

  • Pd-extended 在 GNU/Linux 上第一批可用的 64 位构建

0.43

  • Pd-extended 在 GNU/Linux 上已知的全部主要 64 位 bug 已修复

  • Pd-extended 在 Mac OS X 上完整的 64 位支持，Gem 除外

0.44

  • 支持把 64 位双精度数作为基础数值，见 pd-double
