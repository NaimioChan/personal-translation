如何在 Windows 上使用 pd -stderr？

我怎么才能把 Pd 窗口的所有消息输出到终端或文件里？

----

pd -stderr 是非常方便的调试工具，它让你把一次 Pd 会话中产生的所有消息记录到终端或文件里。这在 UNIX 程序里是非常典型的行为，在 Windows 上却少见得多。尽管如此，在 Windows 上也能做到，只是需要仔细地设置：

  1. 加载 cmd shell（Start -> Run -> cmd）
  2. 在 cmd 里运行：C:\Program Files\pd\bin\pd.com -stderr

现在，通常发往 Pd 窗口的所有消息都会被重定向到 cmd.exe 窗口。
