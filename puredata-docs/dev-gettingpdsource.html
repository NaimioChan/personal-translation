获取 Pd 源代码

从 GIT 下载 Pd 源代码。在 https://github.com/pure-data/pure-data 有一个绿色的 “clone or download” 大按钮

2015 年前后的过时内容：

由于 Pd 的开发是一个庞大且去中心化的过程，获取源代码的仓库有很多个。主要的仓库是 pure-data SVN，此外还有 pure-data git 和 pd-extended.git。获取 Pd 源代码有几种方式。大部分源代码托管在 SourceForge 上的 Subversion（SVN）里，而最新的 'pd vanilla' 核心和 pd-extended 核心在 Git 里。这些仓库都是公开可用的。自动构建服务器用 rsync 获取所有这些源代码，这部分同样是公开可访问的。用下面介绍的 rsync 方式，是获取整套用于构建 Pd-extended 的源代码的简便方法。关于如何把不同仓库组合成一棵一致的开发树，另见 WorkingWithPdExtendedSources。

Pd vanilla（即 pure-data git）

从 0.43 版开始，Pd-vanilla（pure-data）托管在 SourceForge 的 git 上。你可以 browse the source，或者用 git 获取源码：

  • browse pure-data git

git clone git://git.code.sf.net/p/pure-data/pure-data

Pd Subversion 社区仓库

pure-data SourceForge 项目及其 SVN 仓库，是社区汇集源代码的场所。这个 SVN 仓库里包含大部分外部对象、文档和开发项目。旧的 pd 核心和 devel 版本，以及官方的标签和分支，都托管在这里。想进一步了解源代码的布局，见 RepositoryLayout 和 Directory Layout。

  • browse pure-data SVN

svn checkout svn://svn.code.sf.net/p/pure-data/svn/trunk pure-data-svn

Pd-extended

从 0.43 起，Pd-extended 的核心也托管在 SourceForge 的 git 上，其余部分仍留在 pure-data SVN 里。pd-extended.git 的分支比 pure-data 仓库更复杂（master、pure-data 和 patch_series）。按常规，master 是主开发分支。如果你想为 Pd-extended 做补丁，应该基于 master 分支工作。另外两个分支只是用作参考。pure-data 分支是 Pd-extended 当前所基于的 pure-data 仓库版本。patch_series 分支以一系列补丁的形式，展示了 Pd-extended 在 pure-data 之上包含的所有改动。

* browse pd-extended git

git clone git://git.code.sf.net/p/pure-data/pd-extended

Pd-extended 发布分支

Pd-extended 还包含大量来自 pure-data SVN 的库。当 Pd-extended 的下一次发布临近时，会在 pure-data SVN 里创建一个以主/次版本号命名的新分支（即 0.42）。源代码树中的 pd/ 部分随后从 pd-extended git 导入。如果你想取得 Pd-extended 的完整源代码，就检出这些分支之一。

  • browse pd-extended/0.43 SVN

svn checkout svn://svn.code.sf.net/p/pure-data/branches/pd-extended/0.43

nightly 源码 tarball

获取整套源代码的一个简便方式是下载 nightly 源码 tarball： http://autobuild.puredata.info/auto-build/latest/

libpd

libpd 是一层围绕 Pd-vanilla 的包装代码，用来把 Pd 变成可嵌入的库。它可以嵌入到 C++、Java、 OpenFrameworks、Android、iPhoneOS 等环境中。不同平台有若干个不同的 git 仓库： https://github.com/libpd

Gem

Gem 在自己的 SourceForge 项目里开发，有自己的 Git 仓库

  • browse Gem Git

 git clone git://git.code.sf.net/p/pd-gem/gem

其他仓库

  • Matju 在自己的仓库里维护 gridflow：

    • svn checkout http://gridflow.ca/svn/trunk

  • Thomas Grill 的外部对象和 flext 托管在 grrrr on github

  • Pd-anywhere SVN：

    • svn checkout https://pd-anywhere.svn.sourceforge.net/svnroot/pd-anywhere/

  • Pd-anywhere Git：

    • git clone git://pd-anywhere.git.sourceforge.net/gitroot/pd-anywhere/pd-anywhere

  • pd-projects on github

  • pd-project on Gitorious
