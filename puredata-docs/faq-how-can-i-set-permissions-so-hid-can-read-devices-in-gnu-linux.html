如何在 GNU/Linux 上设置读取 HID 设备所需的权限？

Pd-extended 的 [hid] 对象让你可以访问鼠标、键盘、游戏摇杆之类的人机接口设备（HID）。不过在大多数 Linux 发行版中，这些设备的设置使得 Pd 无法直接读取它们，除非你以 root 身份运行 Pd。

以 root 身份运行非系统进程被认为是安全风险，所以另一种办法是修改输入设备的权限，让 pd 能够读取它们。

本指南在 Ubuntu 9.10 Karmic 上测试过。请为更新的版本更新内容并补充附录。

解决办法是写一条 udev 规则来开放权限。Udev 是一个系统守护进程，它根据一组规则，在设备增删时在 /dev 中创建设备树。

按照 Debian udev 规则命名规范，在 /etc/udev/rules.d/85-pure-data.rules 中创建我们为 pd 写的规则：


    sudo mkdir -p /etc/udev/rules.d

    sudo gedit /etc/udev/rules.d/85-pure-data.rules

注意：这是 Debian/Ubuntu 中的位置。请查看你的发行版把 udev 规则放在哪里。

现在把下面的规则加入 /etc/udev/rules.d/85-pure-data.rules：


    #

    #	pure data udev 规则

    #

    #	把我放到 "/etc/udev/rules.d" 里，我的命名基于 debian udev 规则格式

    #

    #	"add" 动作对应设备插入，用设备属性来匹配设备

    #

    #	"remove" 动作使用 ENV 变量来匹配，因为设备的 SYSFS 节点已经消失

    #	因而属性也已被删除

    #

    #	规则构建使用：

    #	- udevadm info -a -p $(udevadm info -q path -n /dev/*device*) : 属性

    #	- sudo udevadm monitor --env /dev/*device* : 事件和环境变量

    #

    #	文档是你的朋友：http://reactivated.net/writing_udev_rules.html

    #

    ################################################################################################

    #	输入设备

    #

    SUBSYSTEM=="input", MODE="666"

注意：每条 udev 规则必须写在一行里。只用空格，不要用制表符。以 `#` 开头的行是注释。

这条规则把输入设备的权限设为 666。重启机器后，HID 对象应该就能打开它们了。

更多安全性

把输入设备设为 666 也给了别人读取你键盘和鼠标输入的机会。如果你觉得这是安全风险，可以把 MODE="666" 换成下面的内容：


    GROUP="input", MODE="660"

然后创建一个 "input" 组，并把你自己加入其中：


    sudo groupadd -f input

    sudo gpasswd -a YOURUSERNAME input

这会把所有输入设备加入 input 组，只有你加入该组的用户才能读取它们。重启机器使规则生效。

检查

检查输入设备的权限：


    $ ls -al /dev/input/

    total 0

    drwxr-xr-x  3 root root     220 2010-06-10 22:00 .

    drwxr-xr-x 16 root root    3640 2010-06-10 22:00 ..

    drwxr-xr-x  2 root root     100 2010-06-10 22:00 by-path

    crw-rw----  1 root input 13, 64 2010-06-10 22:00 event0

    crw-rw----  1 root input 13, 65 2010-06-10 22:00 event1

    crw-rw----  1 root input 13, 66 2010-06-10 22:00 event2

    crw-rw----  1 root input 13, 67 2010-06-10 22:00 event3

    crw-rw----  1 root input 13, 68 2010-06-10 22:00 event4

    crw-rw----  1 root input 13, 63 2010-06-10 22:00 mice

    crw-rw----  1 root input 13, 32 2010-06-10 22:00 mouse0

    crw-rw----  1 root input 13, 33 2010-06-10 22:00 mouse1

这里我用了更安全的方式，可以看到 event 和 mouse 设备对用户和组都标记为 rw。

注意

如果规则似乎不起作用，可以运行 udev 测试，看它是否被读取以及有没有报错。用一个输入设备来运行测试：

sudo udevadm test /dev/input/event0

关于如何编写更详细的规则，参见 udev 教程。其实掌握了以后相当简单。主要是用下面的命令，在插入或移除目标设备时取得可用来匹配该设备的属性列表，然后用它们创建新规则：

udevadm info -a -p $(udevadm info -q path -n /dev/*your device*)
