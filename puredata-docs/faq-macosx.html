如何在 MacOS X 上安装 Pd？

从下载页面下载安装程序。请确认你选对了版本，Intel 还是 PowerPC，否则它无法运行。下载好 .dmg 文件后，双击它。它会打开一个带 Pd 图标的窗口。把 Pd-extended.app 或 Pd.app 拖放到 /Applications。

如果你想在 Mac OS X 10.4/Tiger 或 10.3/Panther 上使用 PDP，就需要安装 X11（10.5/Leopard 自带 X11）。它在你电脑附带的安装 CD/DVD 上。更多细节见如何在 OS X 中安装 X11

你也可以从 http://cjmart.in/2006/12/01/install-x11-on-tiger-without-the-tiger-install-dvd/ 下载旧版本的 X11。安装之后，你需要从 Apple 菜单运行 Software Update...，才能得到最新的版本。如果你不运行 Software Update...，它就无法工作。

或者，你也可以安装 Mac OS X 上开源版本的 X11，它叫 XQuartz。可以在这里找到：XQuartz Releases
