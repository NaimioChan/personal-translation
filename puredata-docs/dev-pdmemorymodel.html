1. DSP 概述

数字信号处理（DSP）可以理解为：把一串在离散时间域上表示某个信号的数字，用某种算法作用于它们，从而变换成另一组数字。得到的结果结构既可以表示对输入信号的显式操作，也可以表示关于输入信号性质的任何其他信息结构。

有限信号表示为对不超过某个数 N 的所有自然数都有定义的序列：x=x(1), ... , x(N)。每个信号 x 都关联一个采样率 R Hz，也就是说采样 x(n) 以每秒 R 个采样的固定速率出现。这对应相邻两个采样之间固定的 1/R 秒间隔。

对 x 的操作产生输出信号 y。输出信号的采样率不必与输入信号相同。事实上，我们可以按某些规则对某个信号做上采样或下采样，从而得到采样率不同的输出信号。

当我们考虑产生可听信号的实时 DSP 时，输出信号也必须关联一个采样率。最简单的情形是输入与输出信号的采样率相同，都为 R。在这种情况下，每一个输出采样总是与一个输入采样相对应，从一个采样 x(n) 到达，到输出采样 y(n) 可用之间的时间，就是输入与输出信号之间的延迟。出于实时的要求，输入与输出采样之间的延迟应当足够小，使输出出现在与输入相同的「感知时刻」。这通常意味着 50ms 或更小的延迟。

输出信号的采样率也决定了可用的最长计算时间，因为下一个采样必须在前一个采样可用之后最多 1/R 秒内准备就绪以供播放。

计算可以逐个采样进行，也可以在一段称为块的采样序列上进行。如果我们定义块大小为 B 个采样，就意味着在开始处理之前先累积 B 个采样，计算完成后再返回 B 个采样。如果（输入与输出）采样率为 R，那么可用于计算整个 B 个采样块的时间是 B/R 秒。

此外，数字处理中还有另一种常见结构，即允许块以某个因子 o 重叠。如果 o = 2，那么第一个块的后半部分就对应第二个块的前半部分。

2. 重新分块

每个 Pd 画布都可以有自己的块大小、块重叠以及上/下采样配置。从一个画布流向另一个画布的信号可能需要调整，以适配不同画布的配置。取决于某个子画布与其容器画布配置之间的关系，子画布上的 DSP 计算会以容器画布的整数倍或整数分之一的频率进行。

重新分块/切换。

在带有重新分块信号的画布内部，DSP 调度具有以下结构：

  1. 入口与出口的前导代码。

  2. 块前导。

  3. 子画布中的对象，包括入口和出口。

  4. 块后记。

  5. 出口的后记代码。

画布内部的采样率是相对于其父画布的采样率定义的：

srate = parent_srate * realoverlap * upsample / downsample;

画布 DSP 例程组的调用频率由下式给出

frequency = (parent_vecsize * realoverlap * upsample)
            / (vecsize * downsample);

零散的笔记

来自 Pd 源代码：

/* "block~ 对象维护其所在画布的 DSP 计算，以容器画布调用频率的整数倍
或整数分之一的频率来调用它。block~ 的创建参数指定块大小和重叠量。
Block~ 本身不做任何 "dsp" 计算，但它会在画布的单位生成器之前和之后
加入前导与后记代码。

子画布完全不必有 block~；如果没有，它里面的 ugen 就直接放入列表，
不带任何前导或后记代码。

Block~ 可以以 switch~ 的形式使用，这时它还起到打开和关闭子画布的作用。
因此，子画布的总体调度顺序是：

  1.  入口与出口的前导代码 (1)
  2.  块前导 (2)
  3.  子画布中的对象，包括入口和出口 (2)
  4.  块后记 (2)
  5.  出口的后记代码 (2)

其中 (1) 表示「如果重新分块」，(2) 表示「如果重新分块或被切换」。

如果我们被重新分块，入口前导和出口后记代码负责重叠与缓冲，以应对
向量大小的变化。如果我们被切换但没有重新分块，就不需要入口前导，
而输出后记只在块被关闭时运行；这种情况下，后记代码只是把零拷贝到
所有信号出口。

block~ 对象状态

  • 这个块中音频信号的大小。

  • 实际要计算的采样数。

  • 窗口重叠因子。

  • 从 0 到 period-1；为零时我们运行这个块。

  • 容器画布的整数分之一。

  • 容器画布的整数倍。

  • 父块调用我们的次数。

  • DSP 链中代码的起始。

  • 这个块的 dspchain 长度。

  • 后记的长度。

  • 如果作为 switch 使用则为真。

  • 如果已开启则为真。

  • 如果入口和出口正在重新分块则为真。

  • 上采样因子。

  • 下采样因子。

  • 就在这个块之后停止（用于一次性触发）。
