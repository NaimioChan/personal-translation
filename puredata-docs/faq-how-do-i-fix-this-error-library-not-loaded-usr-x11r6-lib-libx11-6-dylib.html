如何解决这个错误："Library not loaded: /usr/X11R6/lib/libX11.6.dylib"？

Library not loaded: /usr/X11R6/lib/libX11.6.dylib

如果在启动 Gem、PDP 或 Pd-extended 时在 Pd 窗口中看到这个错误，说明你缺少 X11。（这种情况几乎只出现在 Mac OS X 上，因为 GNU/Linux 通常默认就带 X11。）

要解决这个问题，请安装 X11：如何在 MacOS X 上安装 Pd？
