Mac OS X 上的 MacPorts

在 MacOSXFink 里有一个为构建 Pd-extended 而使用的 Fink 软件包列表。下面是一份 MacPorts 软件包列表，作者认为它们也许可以替代那些 Fink 软件包，以便通过 MacPorts 构建 Pd-extended。

这份列表按在 MacOSXFink 中出现的顺序排列，并配有空行，以突出与那里上下文的对应关系。

正如列表所示，有些 Fink 软件包这位作者没有找到替代品！首先是那些 '*-shlibs' 包。不过它们是 Fink 特有的，如果它们的魔力已经被 DarwinPorts 的软件包覆盖，就可能并不需要，因此不应被看作 DarwinPorts 列表中的缺失。

不过，也有些非 '*-shlibs' 的 Fink 软件包，这位作者没有找到对应的 MacPorts 替代品。因此也许可以合理地得出结论：就目前的样子，DarwinPorts 不能用来构建 Pd-extended。——当然，DarwinPorts 里也可能存在作者没找到的替代品。祝你狩猎愉快。
