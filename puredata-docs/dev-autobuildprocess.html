自动构建流程

关于下载你想要的 Pd 发行版，见 GettingPdSource 里的 rsync from the auto-build farm 一节，下载到的发行版里也包含自动构建脚本。关于在尝试构建之前如何安装所有依赖，另见 开发者文档里的 Setting Up Your Machine for Building 一节。

下面是 PdLab 服务器上自动构建流程的基本概述：

只在主服务器上（debian-stable-i386）

  • 运行 prep-auto-build-upload，为网页建立「auto-build」目录

  • 运行 pure-data-rsync，rsync pure-data 和 pd-gem 这两个 SVN 仓库

  • 运行 pure-data-rsync-checkout，更新每个发行版对应的文件夹

    • 它接着会运行 update-developer-layout.sh，后者会在各处运行 svn update

  • 运行 create-latest-build-listing.py，它会生成 latest 页面

在每台构建服务器上

  • 运行 run-automated-builder，它会为每个发行版启动自动构建脚本，并在失败时尝试把日志邮寄出去

    • 例如 pd-extended-auto-builder.sh，它会把整棵目录树 rsync 到主服务器，然后在那棵树里运行构建，最后尝试上传构建结果

例如，要用自动构建脚本在你自己的机器上下载并构建 pd-extended： 

rsync -av --delete rsync://128.238.56.50/distros/pd-extended/ pd-extended/
./pd-extended/scripts/auto-build/pd-extended-auto-builder.sh
