如何让 MIDI 正常工作？

我想从我的键盘接收 MIDI 数据……该怎么做？

建立基本连接

默认情况下，Pure Data 有 1 个 MIDI 输入和 1 个 MIDI 输出。

要连接到其中一个端口，先插上 MIDI 设备（或者启动你的 MIDI 软件）。接着启动 Pure Data，在 MIDI Settings 对话框里选择设备：Preferences->MIDI Settings...

你可以用 Test Audio and MIDI patch 来测试 MIDI 输入输出是否正常：Media->Test Audio and MIDI。输入和输出通道是 1-16。

注意：如果在 PD 上次启动之后才插上新设备，你必须重启 PD 才能连接到它们。

使用多个设备

如果你想把多个 MIDI 设备／数据流接到 PD 上，可以在 MIDI Settings 对话框里启用 "use multiple devices" 选项，它会启用 4 个输入和 2 个输出。

有了多个输入和输出端口后，多出来的通道在通常的 MIDI 1-16 通道编号之外访问：

  • 端口 1：1-16
  • 端口 2：17-32
  • 端口 3：33-48
  • 端口 4：49-64

MIDI 路由

另一个更有用的选项是使用操作系统特定的 MIDI 混音／路由软件。这样你可以把外部 MIDI 数据流路由进 PD，而不必在 MIDI Settings 对话框里手动选择它们，而且大多数路由软件还允许你保存连接设置。

Mac OS X

用 /Applications/Utilities 里的 Audio-MIDI Setup.app 通过 IAC Driver 为 Pure Data 创建虚拟端口。打开 MIDI 窗口，双击 IAC Driver。点击 Ports 列表下方那个小小的 "+" 图标，添加两个端口："Pure Data In" 和 "Pure Data Out"。接着打开 PD，输入端口选择 "IAC Driver Pure Data In"，输出端口选择 "IAC Driver Pure Data Out"。

现在 Pure Data 有了 2 个虚拟端口，你可以把设备和其它软件的 MIDI 数据路由进 Pure Data，也可以路由出去。要建立连接，可以试试这些软件：MidiPatchBay，或者如果你已经在用 Jack OSX，可以用 Patchage。

Linux

由于 Pure Data 使用 ALSA MIDI，默认情况下它会创建 2 个虚拟端口：1 个输入和 1 个输出。然后你可以用一些工具在 ALSA MIDI 数据流之间建立连接：aconnect、aconnectgui 和 qjackctl（如果你用的是 Jack）。aconnect 是 ALSA 自带的一个简单命令行程序，aconnectgui 为 aconnect 提供了一个简单的图形界面，qjackctl 则包含一套好用的 ALSA MIDI 可视化路由系统。

Windows

Windows 的 MIDI 实现不包含虚拟 MIDI 端口，你需要一个「loopback」程序来创建它们，以便在软件之间路由 MIDI 数据。目前可用的选择有 MIDI-OX、LoopBe1、Maple Virtual Midi Cable 和 loopMIDI。
