在 Xcode 中构建 Pd 外部对象

本页是一篇简短教程，讲如何在 Apple 的 Xcode 中构建 Pd 外部对象。具体来说，它讲解如何构建 Pd externals Howto 中的 "hello world" 示例。

以下是在 Xcode 2 中要做的事情，不过在这方面 Xcode 3 也差不多。

前提条件

首先，你需要从下载区下载 Pd 源代码并解压。就本教程而言，文件的实际位置无关紧要，但后面我们需要源代码来引用 m_pd.h。

1. 建立项目

启动 Xcode 后，先新建一个项目。你要找的项目类型是 "Dynamic Library" 区段中的 "BSD Dynamic Library"。

在主窗口中，选中与你的项目同名的 target（大概也只有一个），打开 target 信息（例如用 command-i）

点击窗口上半部分的 "Build" 按钮。找到下面这些设置，并把它们改成这些值：

  • "Other linker flags"：-undefined dynamic_lookup （似乎是必须的）

  • "Product Name"：helloworld

  • "Executable Prefix"：不需要，直接删掉即可

  • "Executable Extension"：pd_darwin

2. 源文件

我们的项目只需要两个源文件：

  • m_pd.h 在 pd 源代码里找到它，把它加入你的项目（最简单的方式是从 Finder 拖到 "Source" 文件夹里），然后在 "Add to target" 对话框里直接点 "yes"。

  • helloworld.c

  • 通过 File > New File > C File（在 BSD 区段）创建该文件——不需要创建对应的头文件。

  • 把 externals-howto 里的源代码复制进去并保存。

3. 构建 target

没什么要多说的——只是要小心 "Debug" 和 "Build" 设置，你可能改了其中一个的 target 设置却试图构建另一个。

4. 移动产物文件

最后一步是把生成的 helloworld.pd_darwin 从 Xcode 的构建目录移到 pd 知道的目录中，例如 /Library/Pd/（可能需要先创建）

5. 启动 Pd

现在外部对象应该可用了。
