什么是 .pdrc 文件，如何使用它？

(已废弃，参见： 如何保存启动选项，让它们在我每次启动 Pd 时都被加载 )

在较旧版本的 pd（pd<=0.37）中，.pdrc 文件是为 Pd 指定启动选项的标准做法。

新的（与平台相关的）启动选项保存方式见 pdsettings。

在 .pdrc 中，你把希望 Pd 启动时使用的所有命令行选项都写进文件里。格式是每行一个选项，需要多少行就写多少行。例如： 

 -r 48000

 -nomidi

 -lib iem_mp3

 -lib iem_t3_lib

 -lib zexy

 -path /Users/hans/cvs/pure-data/externals/hcs/rawhid/

 -helppath /Users/hans/cvs/pure-data/externals/hcs/rawhid/

.pdrc 放在你的主目录，也就是 ~ 里。因此标准的 UNIX 写法是 ~/.pdrc。

在我这里，MacOS X 上相当于 /Users/hans/.pdrc，在 GNU/Linux 上则是 /home/hans/.pdrc。

通常，像 .pdrc 这样以「.」开头的文件默认是隐藏的。
