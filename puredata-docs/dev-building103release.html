构建 10.3 发行版

Mac OS X 10.3 发行版是 10.4 构建的一个略微修改过的版本。做法如下：

  • 在 macos104-powerpc 构建机上，切换到在 10.3 上构建的 Tcl/Tk framework

    • cd /Library/Frameworks

    • rm Tcl.framework Tk.framework

    • ln -s 10.3/Tcl.framework

    • ln -s 10.3/Tk.framework

  • 在 10.4 上构建的 Gem 在 10.3 上不能用。0.90 是最后一个支持 10.3 的 Gem 版本，所以去拿 Pd-0.39.3-extended，把里面的 Gem.pd_darwin 取出来。要做到这一点，我们需要先把磁盘映像转换成可写格式，然后再转换回发行格式：

    • hdiutil convert -format UDRW -o build.dmg Pd-0.40.3-extended-macosx104-powerpc.dmg

    • hdiutil resize -size 200m build.dmg

    • hdiutil attach build.dmg

    • hdiutil attach Pd-0.39.3-extended-macosx103.dmg

    • cp /Volumes/Pd-extended\ 1/Pd-extended.app/Contents/Resources/extra/Gem.pd_darwin /Volumes/Pd-extended/Pd-extended.app/Contents/Resources/extra/

    • rm /Volumes/Pd-extended/Pd-extended.app/Contents/Resources/extra/Gem/Gem.pd_darwin

    • hdiutil detach /Volumes/Pd-extended/

    • hdiutil detach /Volumes/Pd-extended\ 1/

    • hdiutil resize -size 160m build.dmg

    • hdiutil convert -format UDZO -o Pd-0.40.3-extended-macosx103.dmg build.dmg

    • hdiutil unflatten Pd-0.40.3-extended-macosx103.dmg

    • cd pure-data/pd-extended-v0-40/packages/darwin_app/

    • /Developer/Tools/Rez /Developer/Headers/FlatCarbon/*.r SLA.r -a -o Pd-0.40.3-extended-macosx103.dmg

    • hdiutil flatten Pd-0.40.3-extended-macosx103.dmg
