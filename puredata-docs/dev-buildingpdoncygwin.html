在 Cygwin 上构建 Pd

有了新的 autotools 构建系统和相关的修复，现在可以用 Cygwin 构建并运行 Pd 了。目前还不能加载外部对象，还需要一些构建修复来支持链接 Pd（-lpd）。

安装设置

安装 Cygwin

Cygwin 装起来相对容易。下载 setup.exe 并运行它来安装 Cygwin。装到默认位置。

进到 Select Packages 界面后，点击右上角标着 View 的按钮，把它改成 Full。然后找到 autoconf、automake1.10、tcltk、svn、make、openssh、patch 和 sed，确保它们被设为安装。这表现为显示一个将要安装的版本号，而不是 Skip。

构建

  • cd pd-gui-rewrite/0.43

  • ./autogen.sh && ./configure && make

  • cd src

  • wish pd-gui.tcl

extra 里的外部对象不会构建成功，make 最后会以错误结束，但你会得到一个能用的 Pd。
