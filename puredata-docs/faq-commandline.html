Pd 有哪些命令行选项？

用 pd -help 就能知道。

截至 Pd 0.46-1 版本： 

 音频配置选项：

  -r <n>           -- 指定采样率

  -audioindev ...  -- 音频输入设备；例如 "1,3" 表示第一个和第三个

  -audiooutdev ... -- 音频输出设备（格式相同）

  -audiodev ...    -- 同时指定输入和输出

  -audioaddindev   -- 按名称添加一个音频输入设备

  -audioaddoutdev  -- 按名称添加一个音频输出设备

  -audioadddev     -- 按名称添加一个音频输入和输出设备

  -inchannels ...  -- 音频输入通道（按设备，如 "2" 或 "16,8"）

  -outchannels ... -- 音频输出通道数（格式相同）

  -channels ...    -- 同时指定输入和输出通道

  -audiobuf <n>    -- 指定音频缓冲区大小，单位毫秒

  -blocksize <n>   -- 指定音频 I/O 块大小，单位采样帧

  -sleepgrain <n>  -- 指定空闲时休眠的毫秒数

  -nodac           -- 禁止音频输出

  -noadc           -- 禁止音频输入

  -noaudio         -- 禁止音频输入和输出（-nosound 是同义词） 

  -callback        -- 尽可能使用回调

  -nocallback      -- 使用轮询模式（默认为真）

  -listdev         -- 列出音频和 MIDI 设备

  -oss             -- 使用 OSS 音频 API

  -alsa            -- 使用 ALSA 音频 API

  -alsaadd <name>  -- 向列表中添加一个 ALSA 设备名

  -jack            -- 使用 JACK 音频 API

  -pa              -- 使用 Portaudio API

 MIDI 配置选项：

  -midiindev ...   -- MIDI 输入设备列表；例如 "1,3" 表示第一个和第三个

  -midioutdev ...  -- MIDI 输出设备列表，格式相同

  -mididev ...     -- 同时指定 -midioutdev 和 -midiindev

  -midiaddindev    -- 按名称添加一个 MIDI 输入设备

  -midiaddoutdev   -- 按名称添加一个 MIDI 输出设备

  -midiadddev      -- 按名称添加一个 MIDI 输入和输出设备

  -nomidiin        -- 禁止 MIDI 输入

  -nomidiout       -- 禁止 MIDI 输出

  -nomidi          -- 禁止 MIDI 输入和输出

  -ossmidi         -- 使用 OSS midi API

  -alsamidi        -- 使用 ALSA midi API

 其他选项：

  -path <path>     -- 添加到文件搜索路径

  -nostdpath       -- 不搜索标准（"extra"）目录

  -stdpath         -- 搜索标准目录（默认为真）

  -helppath <path> -- 添加到帮助文件搜索路径

  -open <file>     -- 启动时打开文件

  -lib <file>      -- 加载对象库

  -font-size <n>     -- 指定默认字体大小，单位磅

  -font-face <name>  -- 指定默认字体

  -font-weight <name>-- 指定默认字体粗细（normal 或 bold）

  -verbose         -- 启动时以及搜索文件时输出额外信息

  -noverbose       -- 不输出额外信息

  -version         -- 不运行 Pd；只打印出版本号 

  -d <n>           -- 指定调试级别

  -loadbang        -- 不禁止所有 loadbang（默认为真）

  -noloadbang      -- 禁止所有 loadbang

  -stderr          -- 把输出发送到标准错误而不是 GUI

  -nostderr        -- 把输出发送到 GUI 而不是标准错误（默认为真）

  -gui             -- 启动 GUI（默认为真）

  -nogui           -- 禁止启动 GUI

  -guiport <n>     -- 通过端口 <n> 连接到已存在的 GUI

  -guicmd "cmd..." -- 启动替代的 GUI 程序（例如通过 ssh 远程）

  -send "msg..."   -- 在启动时、patch 加载完成后发送一条消息

  -prefs           -- 启动时加载首选项（默认为真）

  -noprefs         -- 禁止在启动时加载首选项

  -rt or -realtime -- 使用实时优先级

  -nrt             -- 不使用实时优先级

  -sleep           -- 空闲时休眠，不空转（默认为真）

  -nosleep         -- 空转而不休眠（在多 CPU 上可能降低延迟）

  -schedlib <file> -- 插入外部调度器

  -extraflags <s>  -- 传给 schedlib 的字符串参数

  -batch           -- 作为批处理进程离线运行

  -nobatch         -- 交互式运行（默认为真）

  -autopatch       -- 启用从所选对象新建时自动连线（默认为真）

  -noautopatch     -- 取消从所选对象新建时的自动连线

  -compatibility <f> -- 把向后兼容性设为版本 <f>

更多信息，请查看：

-guiport, -guicmd : http://lists.puredata.info/pipermail/pd-list/2007-08/052604.html

-d <n> : http://lists.puredata.info/pipermail/pd-list/2014-10/108158.html

-verbose : 把日志级别提高一级，需要多高就加多少个，然后在 UI 里把日志级别切到 "4 all" 就能全部看到 其余的你可以自己搜索 :-)
