如何在 Debian、Ubuntu、Linux Mint 上安装 Pd？

在 Debian 及其衍生系统（Ubuntu、Kubuntu、Linux Mint 等）上，Pure Data 和许多库都由官方软件仓库提供。要安装 Pure Data，请打开终端并运行：

sudo apt install puredata

大多数库也可以获取到。它们的名字通常带有 pd- 前缀，这让浏览外部对象更方便：

apt search ^pd-

安装库的方式与安装 Pd 相同：

sudo apt install pd-iemnet pd-aubio pd-wiimote

Gem 的软件包名是 gem（没有 pd- 前缀）：

sudo apt install gem

注意：大多数软件包会跟随操作系统的某个特定发行版保持自己的版本。在 Ubuntu LTS 或 Debian stable 上，你找到的 Pd 版本可能已经比最新版本落后好几个版本。如果你不需要任何新功能，这没有问题。如果你需要更新的版本，请往下读

在 Debian 上获取最新版本

puredata 软件包的维护者会通过 backports 仓库提供最新的 Pd 版本。你可以把它加入软件源来启用：

echo "deb http://deb.debian.org/debian $(. /etc/os-release; echo $VERSION_CODENAME)-backports main" | sudo tee -a /etc/apt/sources.list.d/backports.list

运行下面的命令刷新软件源：

sudo apt update

最后，从 backports 安装 puredata：

sudo apt install -t bullseye-backports puredata

请确保把 bullseye 换成你正在使用的 Debian 发行版。本文写作时 bullseye 是稳定版。

在 Ubuntu 上获取最新版本

Ubuntu 也有 backports 仓库，不过他们的维护者似乎并不特别在意 Pure Data。不过 Ubuntu 允许通过个人软件包归档（PPA）自行托管软件包。好在有人做了构建并把它们放到了自己的 PPA 上。从那里安装 puredata 所需的步骤是：

sudo add-apt-repository ppa:pure-data/pure-data
sudo apt update
sudo apt install puredata


库应该从 Deken 装，还是从软件仓库装？

视情况而定。Deken 通常更新更及时。不过来自软件仓库的软件包往往集成得更好。除了 Pd 之外不链接任何其他二进制文件的编译产物，从 Deken 或软件仓库获取多半都能正常工作。从 Deken 获取的、链接了其他库的编译库，可能只能在它最初被创建的系统上工作。来自软件仓库的软件包虽然更旧，但不会有兼容性问题，开箱即用。一般建议使用软件仓库里的软件包。
