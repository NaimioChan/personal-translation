自动构建脚本

这些脚本位于 pure-data SVN 的 /scripts/auto-build 里。

prep-auto-build-upload

在 Web 服务器上建立用来上传已完成构建结果的目录

pure-data-cvs-rsync

从 SourceForge rsync pure-data 和 pd-gem 的 CVS。

pure-data-cvs-rsync-checkout

为每个脚本对应的目录运行「scripts/update-developer-layout.sh」，目前有：pd-devel、pd-extended 和 pd-main。

run-automated-builder

由 cron 每晚运行。对于构建的每个部分，这个脚本会创建日志文件并运行构建脚本。

pd-devel-auto-builder.sh

目前只是一个骨架，这个脚本将会构建 pd-devel 的所有东西。

pd-extended-auto-builder.sh

运行 Pd-extended 的构建。

pd-main-auto-builder.sh

只对 CVS 中 **pd** 部分的 MAIN 的 HEAD 运行构建。
