入门

如果你刚开始使用 Pure Data，这里有一些基础内容。

从 Pure Data 入门

最简单的起步方式是从下面的地址下载 Pd-extended。你可以选择与自己系统相对应的版本。

  • 下载 Pd-extended

安装 Pd-extended（它是带附加功能的 Pd 版本）并启动它。控制台会给出重要信息，不过你现在可以先忽略。

什么是 patch？

Pure Data 中的文件被称为「patch」。来看一个例子。在 Pd-extended 的 *帮助* 菜单中，选择 帮助浏览器。单击列表中的第一项 Manuals，然后点击 + Start Here。双击 fr_Pour-Commencer.pd 打开这个法语示例 patch。然后按其中的说明操作。
