PdParty 标准

文件命名

  • _main.pd = 主 patch 名。
  • thumbnail.png = 代表这个 patch 集的图片文件。

事件

  • 加速度计
  • GPS
  • 触摸 - 创建一个名为 [#touch] 的监听器

便携 patch 格式

.pdz 文件是 zip 文件，其中包含一个目录，目录名应当是你的 patch 名。

网络

  • [netsend] 和 [netreceive] 的行为与 Pd 中一样。
