Atom

更新 - 2023 年 1 月 1 日：Atom 编辑器已停止维护，参见官方 Sunsetting Atom 页面。Tidal 已改用 Pulsar。Tidalcycles 已集成到 Pulsar 的包管理器中，可以直接在 Pulsar 内安装和更新 tidal 插件。（不再需要手动安装插件。）

参见关于如何在 Pulsar 中使用 Tidal 的文档。

注意：已经配置好 Tidalcycles 包、Atom 编辑器可正常使用的 Tidal 用户可以继续使用。但是，Atom 的包管理器已无法安装或更新 Tidal 包，Atom 也不会再有任何更新。建议 Tidal 用户迁移到 Pulsar。

如果你仍有使用 Atom 的需求：

  • Atom GitHub
  • Atom 最终版本 - 下载
  • 对于 Tidalcycles 包：
    • 手动安装
    • 按照 Pulsar 页面上的说明操作
    • 把 ~/.atom/ 换成 ~/.pulsar，让包安装到 Atom 而不是 Pulsar
