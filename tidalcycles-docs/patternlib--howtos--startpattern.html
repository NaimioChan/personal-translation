从头触发一个 pattern

Tidal Cycles 的循环时钟一直在走。有时，你需要以确定性的方式从头开始你的 pattern。有很多方法可以做到。

nudge

nudge 最初是为了微调音频采样播放时机而实现的函数。你可以用它做出漂亮的 swing 效果，也可以用它处理各种时序问题。

你可以给单个 pattern 设置 nudge 值，让它们在时间上偏移：

d1 $ s "bd*4" # nudge 0.9 -- 这里我给这个 pattern 设置了 nudge

如果你想影响所有 pattern，可以通过 all 对每个 pattern 使用 nudge：

d1 $ s "bd*4" # nudge 0.9 -- 这个 pattern 的 nudge
d2 $ fast 2 $ s "~ sn" # nudge 0.4 -- 不同的值

all $ (|+ nudge 0.2) -- 给 nudge 参数加上 0.2
-- 这会相当于 d1 是 # nudge 1.1，d2 是 0.6
nudgeAll 0.2 -- 另一种简写形式

qtrigger 和 trigger

d2 $ sound "bd hh hh hh"
d2 $ qtrigger $ sound "bd hh hh hh"
d2 $ trigger $ sound "bd hh hh hh"

resetCycles

用 resetCycles 来……重置循环计数。它会在你运行的瞬间重置循环计数，而不是等到当前循环结束：

do
  resetCycles
  d1 $ s "bd*4"
  d2 $ s "~ hh ~ hh*2"
