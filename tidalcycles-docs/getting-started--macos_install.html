macOS 安装

自动安装（脚本）

此安装脚本可用于自动安装 TidalCycles 系统所需的全部组件和依赖。如果你是 Tidal 新手，还没有 SuperCollider 和 SuperDirt，推荐使用此方法。如果你已经有了这些组件，或者非常熟悉命令行安装的管理，请使用下方的手动安装步骤。

请查看 GitHub README 了解支持的操作系统版本等详细信息。

  • Silicon/M1：已在 OSX Ventura 上验证
  • 已在 Intel 的 Big Sur、Monterey 上测试

对于其他环境，某些组件可能无法安装。请按照下方安装后的步骤操作。你可能需要执行手动安装步骤。

安装步骤

1. 前提条件：Apple Xcode 命令行工具。 如果已安装，可以跳过此步。如果不确定，运行下面的命令时，若已安装则会直接退出。安装过程会弹出多个对话框，包括 Apple 的许可协议。可能需要 20-30 分钟以上才能完成。

/usr/bin/xcode-select --install

2. tidal-bootstrap。 它会安装以下组件，且只安装缺失的部分。（提示：tidal-bootstrap 可以重复运行。）Haskell 的安装耗时最长也最复杂 - 你会看到许多关于 Haskell、ghcup、cabal 等的消息。这可能需要 20-30 分钟以上。

  • Haskell 语言（Ghcup）
  • cabal：Haskell 和 Tidalcycles 的包系统
  • Tidal pattern 引擎（Tidal Cycles 本身），包含重要的 BootTidal.hs 文件
  • Pulsar：文本编辑器
    • 用于 Pulsar 的 tidalcycles 插件
  • SuperCollider 用于后端音频生成，以及：
    • SuperDirt：tidal 使用的采样库
    • sc-3 插件：单元生成器插件
curl https://raw.githubusercontent.com/tidalcycles/tidal-bootstrap/master/tidal-bootstrap.command -sSf | sh

3. 安装后

  • 查看安装脚本的输出。记录任何错误信息或安装失败。这有助于故障排查。
    • Haskell 问题请检查 /tmp/ghcup-install.log
  • 如果有安装失败，可以重新运行 tidal-bootstrap。它会跳过已成功安装的组件。有时再次运行就能解决问题。
  • 启动一个新的 shell（退出终端）。这会加载新的 PATH 设置。
  • 验证安装。你应该能够运行以下命令。前两个会显示你的 tidal 安装信息。如果它们失败，说明 Haskell 或 Tidal 未正确安装。ls 命令会显示 Pulsar tidalcycles 插件是否安装正确。你应该会看到 osc-min 目录中的文件列表。SuperCollider 的 scsynth 命令会显示版本信息。
cabal list tidal
cabal info tidal
ls ~/.pulsar/packages/tidalcycles/node_modules/osc-min
/Applications/SuperCollider.app/Contents/Resources/scsynth -v

## SuperDirt: Start SuperCollider. From the Language menu, select "Quarks." SuperDirt and Dirt-Samples should be listed and checked.
  • 如果 Pulsar tidalcycles 插件没有正确安装，首先尝试在 Pulsar 内使用包管理器安装。参见 Pulsar 页面中的说明。如果仍然失败，可以尝试手动安装插件。说明同样在 Pulsar 页面中。

4. 开始吧！ 启动 Tidal 按照本指南了解各组件如何协同工作以及如何让它们运行起来。欢迎来到 Tidal！

手动安装

在安装 Tidal 之前，请确保先安装 Haskell（通过 Ghcup）、带 SC3 Plugins 的 SuperCollider、Git。你还需要选择并安装一个与 Tidal Cycles 交互的文本编辑器（见侧边栏）。

安装过程

Ghcup

在终端窗口中，我们会把 GHC 安装的路径添加到一个每次终端加载时都会执行的文件里。对于 macOS 10.14 或更早版本，终端使用 bash，所以我们要修改的文件是 .bashrc：

. "$HOME/.ghcup/env"
echo '. $HOME/.ghcup/env' >> "$HOME/.bashrc"

对于 macOS 10.15 Catalina，终端使用 zsh，所以我们要修改的文件是 .zshrc：

. "$HOME/.ghcup/env"
echo '. $HOME/.ghcup/env' >> "$HOME/.zshrc"

之后，我们先用 cabal 更新它的包目录， 然后安装 TidalCycles 库。以后每次想把 TidalCycles 库 更新到最新版本时，我们也会运行这两个 命令。

cabal update
cabal v1-install tidal

如果你从未安装过 TidalCycles，那么 cabal v1-install tidal 这一步可能需要一些时间。在命令输出 的末尾，应该会显示 Installed tidal-x.x.x（其中 x.x.x 是 最新的版本号）且没有任何错误。

注意：验证安装的步骤见上方的 “3. 安装后” 一节。

SuperDirt

启动你刚安装的 SuperCollider。在看到的文本编辑器中粘贴下面这行代码，然后按 Cmd+Return 求值：

Quarks.checkForUpdates({Quarks.install("SuperDirt", "v1.7.3"); thisProcess.recompile()})

点击这行代码运行它，确保光标在这一行上， 然后按住 Shift 并按回车。

安装需要一些时间。你会看到类似下面的内容：

Installing Vowel
Vowel installed
Installing Dirt-Samples

SuperDirt installed
compiling class library...
...
