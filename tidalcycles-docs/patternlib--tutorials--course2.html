第 5 周

第 1 课：音符

▶ 视频

好，我们带着一期出奇长的视频回来了，讲如何播放音符——用数字或名字给出音符，以及控制采样和合成器…… 顺带讲了一下如何查看（第一个循环的）pattern 内部的实际值。

-- 如果你单独'运行'一个 pattern，不带 'd1' 之类的东西，
-- Tidal 会尽力告诉你第一个循环里有什么。例如：

note "3"

-- 给出：

-- (0>1)|note: 3.0f

-- 0>1 告诉你这是一个从位置 0（第一个循环的开始）
-- 开始、持续到 1（下一个循环的开始）的事件。
-- note 是'控制参数'或'效果器'的名字，3.0f 是值
-- （'f' 告诉你它是一个浮点小数）。

note "3 ~ 5"

-- 上面给出两个事件：

-- (0>⅓)|note: 3.0f
-- (⅔>1)|note: 5.0f

-- 我们可以听听它们：

d1 $ note "3 ~ 5" # s "superpiano"

-- 好听的音符！

-- （.. 如果你什么都没听到，你可能需要安装
-- "sc3plugins"。）

-- Tidal 也能理解音符名字，并替你把它们变成数字。

-- 例如 'c' 等于 '0'

note "c"

-- 这个：

note "a b c d e f g"

-- 等同于：

note "9 11 0 2 4 5 7"

-- 那 1、3、6、8 和 10 去哪了？
-- 给音符加 's' 表示'sharp'（升号），加 1，就能到它们：

note "cs ds fs gs as"

-- 或者用 'f' 表示 'flat'（降号），减 1：

note "df ef gf af bf"

-- 理论上，通过极度升高的 'c' 音你可以到全部
-- 这些音。这两个音完全相同：
d1 $ note "csssssss g" # s "superpiano"

-- 实践中，这么做显然没有太大意义。

-- 通常一个八度有十二个音。默认八度是 5，
-- 加上不同的数字可以从其他八度取音：
note "c5 c6 c4 c6"

-- 来听一下
d1 $ note "c5 c6 c4 c6" # s "superpiano"

-- 我们来想想 'note'、'n'、合成器和采样之间的区别。

-- 并没有一个叫 'superpiano' 的采样文件夹，
-- 你听到的声音是即时合成的。

-- 对合成器，'note' 和 'n' 都可以用来指定音符，
-- 它们意思相同。

d1 $ n "c a f e" # s "superpiano"

d1 $ note "c a f e" # s "superpiano"

-- 对采样，它们的含义不同。'n' 选择一个采样，
-- 'note' 以对应某个音符的速度播放它。

-- 不同音色：
d1 $ n "0 1" # sound "dsynth"

-- 不同音符：
d1 $ note "0 1" # sound "dsynth"

-- 如果你挑一个高音，你会注意到声音短了很多，
-- 因为它是通过更快播放来升高的。
d1 $ note "0 24" # sound "dsynth"

-- 你可能觉得这不好，因为它听起来不如合成器自然
-- 你可能觉得这很好，因为自然是虚构的，而这正是
-- 早期锐舞音乐和 demoscene 的老派 'tracker' 音乐
-- 的工作方式
-- 你可能在不同日子改变主意

-- 在迷你记谱里仍然可以用音符名字：
d1 $ note "c a f e" # sound "dsynth"

-- （其实在任何期望数字的控制参数/效果器 pattern 里
-- 都可以这样.. Tidal 只是把它当作数字）

-- 这个 dsynth 采样是 'c' 调的。如果不是，
-- 这些音符与其他合成器或音色库放在一起
-- 可能会跑调。

-- 'dbass' 采样有三个贝斯音色，同样是 'c' 调，
-- 长度不同。所以同时用 *both* 'note' 和 'n'
-- 来编排音高和所用采样是有道理的：
d1 $ note "c a f e" # sound "dbass" # n "<0 1 2>"

-- 'rash' 音色库的组织方式不同…… 它有一大堆采样，
-- 6 个八度每个音符一个。一个八度 12 个音，
-- 所以是 72 个采样。（其实有 73 个，多了一个
-- note-084.wav，你可以删掉..）这些是我从我的
-- 漂亮 Roland JV1080 合成器上采的样。

-- 所以你可以用 'n' pattern 而不是 'note' pattern，
-- 以数字来播放音符。这听起来比用 'note'
-- 升高音高更'自然'一些。
d1 $ n "20 50" # sound "rash"

-- 你仍然可以用音符名字，但对合成器来说 '0' 是
-- *中央* c，而对这些采样来说那已经是音阶
-- *最低端*了。
d1 $ n "c a f e" # sound "rash"

-- 所以这种情况下你会想挑更高的八度
d1 $ n "c7 a7 f8 e7" # sound "rash"

-- 我倾向于像这样加几个八度：
d1 $ n "c a f e" # sound "rash"
  |+ n 24

-- 把音符加起来很好玩：
d1 $ n "c a f e" # sound "rash"
  |+ n 24
  |+ n "<0 2 7 12>"

-- 也可以这样做，在单个控制参数 pattern'内部'
-- 把数字 pattern 相加
d1 $ n ("c a f e" |+ 24 |+ "<0 2 7 12>")
  # sound "rash"

-- 还有一个 'octave' 控制参数可以按十二个音上下跳：
d1 $ note "c a f e" # sound "superpiano"
  # octave "<4 6 3>"

第 2 课：和弦、琶音与…… Algoraoke

▶ 视频

好，现在热身了！这是一个探索和弦、琶音，以及正在兴起的形式 Algoraoke 的视频——这个词我想是在利兹第一届现场编码大会上由 Ash Sagar 创造的。这个视频包含下一个挑战的预告——做一首'翻唱'，稍后我会更详细地写出来……


-- 好，和弦！我们可以这样弹一个'major'（大调）和弦：

d1 $ n "'maj" # sound "supermandolin"
  # legato 2 # gain 1.4

-- 默认是 c 大调，你可以像这样选别的，比如
-- 先 c 后 e 大调：
d1 $ n "c'maj e'maj" # sound "supermandolin"
  # legato 2 # gain 1.4

-- 卡拉OK（algoraoke）时间
-- 我们拿一首知名歌曲的和弦来用：
-- https://ukutabs.com/r/radiohead/creep/

d1 $ n "<g'maj b'maj c'maj c'min>" # s "supermandolin"
  # room 0.6 # sz 0.9

-- 用 struct 拨弄它一下：
d1 $ qtrigger $ jux ((|- n "12") . rev) $ struct "t(5,8,<0 4>)" $ n "<g'maj b'maj c'maj c'min>" # s "supermandolin"
  # room 0.6 # sz 0.9

-- 你可以这样拿到所有和弦的列表：
import Sound.Tidal.Chords

chordList

-- 试试它们：
d1 $ n "c'sevenFlat9 a'm9sharp5" # sound "supermandolin"

-- 这是原始数据：
chordTable

-- 再说一次，这一切最终都会变成普通的音符数字。
-- 这两个 pattern 是相同的：
d1 $ n "c'sevenFlat9 a'm9sharp5" # sound "supermandolin"

d1 $ n "[0,4,7,10,13] [9,10,23]" # sound "supermandolin"

-- 你可以用另一个 ' 和你想要的音符数，
-- 说明和弦里要有多少个音。

-- 如果你要求的音符比基础和弦里的多，
-- 它会往上找八度里的更多音符，听起来越来越气势恢宏：
d1 $ n "c'maj'4" # s "superpiano"
d1 $ n "c'maj'8" # s "superpiano"
d1 $ n "c'maj'12" # s "superpiano"

-- 当我们开始玩.. 琶音（ARPEGGIOS）时这更清楚

-- 琶音是'破碎'的和弦，音符不是同时响起，
-- 而是一个接一个地演奏：
d1 $ arpeggiate $ n "c'maj" # s "superpiano"

-- 琶音发生在和弦所占的'步'之内：
d1 $ arpeggiate $ n "c'maj e'min7" # s "superpiano"

-- 上面你能听出大调和弦有三个音，小七和弦有四个。
-- 愿意的话你可以用 ' 修改，让它们数量相同：
d1 $ arpeggiate $ n "c'maj'4 e'min7'4" # s "superpiano"

-- "arpeggiate" 有一个更短但更灵活的表亲 "arp"，
-- 它允许你指定另一种拆散和弦的方式：
d1 $ arp "updown thumbup" $ n "<c'maj'4 e'min7'4>" # s "superpiano"

-- 这是当前可用的琶音风格列表，供探索：
-- up, down, updown, downup, converge, diverge, disconverge, pinkyup,
-- pinkyupdown, thumbup thumbupdown

-- 非常好玩
d1 $ jux rev $ arp "<updown thumbup pinkyupdown converge diverge>"
  $ n "<c4'maj'6 e4'min7'8 g5'maj'5 a5'maj'4>" # s "superpiano"
  # room 0.3 # sz 0.7

Julian Rohrhuber 的点评

SuperDirt 的作者 Julian Rohrhuber 在这个视频下添加了一条又长又有趣的评论。

好，来了！以下内容只涉及来自 Tidal sound 函数的合成器（不是像 # delay 那样的全局效果器合成器，它们以不同的方式处理）。

在 SuperDirt 里，合成器的释放由一个内部合成器完成，它位于效果链的末尾。它就是 dirt_gate 合成器。它的定义在 core-synths.scd 里。我把它贴在下面 [1]。它对整个事件（包括你应用的所有效果器）施加一个极小的包络。doneAction 在这个包络完成后被调用。通过在 Tidal 里设置 fadeInTime 和 fadeTime 参数，你可以加硬或软化 attack/decay。

这意味着你可以用不自我释放的合成器来做 SynthDefs，这种做法在 SuperCollider 里我们通常避免，因为那样合成器会无限堆积。但在这里，你可以简单地这样定义一个合成器：

SynthDef(\mess, { |out| Out.ar(out, GrayNoise.ar) }).add;

然后你可以在 Tidal 里用 sound "mess" 播放它。这些合成器由 dirt_gate 合成器释放。

但通常，你会希望合成器有一个特定的振幅包络。那么你可以在自己的 SynthDef 里定义一个，见下面 [2]。注意 sustain 指的是整个合成器的持续时间（这是 SuperCollider 里的一般叫法），它由 Tidal 传过来（要直接设置它，试试 # sustain "0.1 0.3 0.5 1"）。如果你愿意可以用 doneAction: 2（它会在包络结束后释放合成器），但你也完全可以省略这个 doneAction，因为反正合成器会被外部释放。例如：

SynthDef(\mess, {
  | out, sustain = 0.2 |
  Out.ar(out, GrayNoise.ar * XLine.kr(1, 0.001, sustain))
}).add

但有时，你可能想在 SuperDirt 之外使用这个合成器，那时它能自我清理才礼貌。只要确保把你的包络乘上可听的信号，否则你会在每个合成器结束时听到咔哒声。

SynthDef(\mess,
  {
    | out, sustain = 0.2 |
    Out.ar(out,
       GrayNoise.ar * XLine.kr(1, 0.001, sustain, doneAction: 2)
   )
  }
).add

希望这有帮助！

[1]

SynthDef("dirt_gate" ++ numChannels, { |out, in, sustain = 1, fadeInTime = 0.001, fadeTime = 0.001, amp = 1|
		var signal = In.ar(in, numChannels);
		 //  doneAction: 14: free surrounding group and all nodes
		var env = EnvGen.ar(Env([0, 1, 1, 0], [fadeInTime, sustain, fadeTime], \sin), levelScale: amp, doneAction: 14);
		signal = signal * env * DirtGateCutGroup.ar(fadeTime, doneAction: 14);
		OffsetOut.ar(out, signal);
		ReplaceOut.ar(in, Silent.ar(numChannels)) // clears bus signal for subsequent synths
	}, [\ir, \ir, \ir, \ir, \ir, \ir]).add;

第 6 周

第 1 课：用 "off" 做卡农

▶ 视频

稍微提前一点，这是对我心爱的函数 off 的介绍。这是练习单：

-- 我们从两个音符开始：
d1 $ n "c e" # sound "supermandolin"

-- 'off' 做了什么？在上下两个版本之间切换听听
-- 差别。
d1 $ off 0.25 (# crush 4) $ n "c e" # sound "supermandolin"

-- 你能听出原本的两个音符没变，但多加了
-- 别的东西。

-- 'off' 接受三个输入；一个数字、一个函数和一个 pattern。
-- 它做的是保留原 pattern 不动，但在上面加一个副本。
-- 那个副本在时间上偏移第一个输入给出的数字 —— 数字。
-- 副本还被应用了那个函数。
-- 于是我们得到一个在时间上'追随'原版、
-- 并被变换了的版本。在这里，它被失真了。

-- 不用 bitcrush 效果器了，我们改成给 'n' 音符加值。
d1 $ off "0.25" (|+ n 7) $ n "c e" # sound "supermandolin"

-- 现在我们听到一个简单的'卡农'—— 听起来像一个
-- 声部追随另一个。

-- 我们可以把 '0.25' 换成简写 'q'，它代表一个循环的
-- *q*uarter（四分之一）。
d1 $ off "q" (|+ n 7) $ n "c e" # sound "supermandolin"

-- 换成 'e'，它代表一个循环的八分之一。
d1 $ off "e" (|+ n 7) $ n "c e" # sound "supermandolin"

-- 这是当前可用的简写列表：
-- w = 1 (whole)
-- h = 0.5 (half)
-- q = 0.25 (quarter)
-- e = 0.125 (eighth)
-- s = 0.0624 (sixteenth)
-- t = 1/3 (third)
-- f = 0.2 (fifth)

-- 你可以在这些简写前面加数字得到倍数，例如：
d1 $ off "2f" (|+ n 7) $ n "c a f e" # sound "supermandolin"

-- 要一个三十二分音符，可以用 0.5s：
d1 $ off "0.5s" (|+ n 7) $ n "c a f e" # sound "supermandolin"

-- 用一个更复杂的 pattern 试试：
d1 $ off "e" (|+ n 7) $ n (slow 2 "c(3,8) a(3,8) f(5,8) e*2")
  # sound "supermandolin"

-- 音符现在变得很短，以贴合这个更密集 pattern 里
-- 更短的'步'。要让它们成比例地更长，我们可以
-- 使用 legato，比如让它们都长一倍：
d1 $ off "e" (|+ n 7) $ n (slow 2 "c(3,8) a(3,8) f(5,8) e*2")
  # sound "supermandolin"
  # legato 2

-- 或者我们可以用 sustain 以秒为单位指定时长：
d1 $ off "e" (|+ n 7) $ n (slow 2 "c(3,8) a(3,8) f(5,8) e*2")
  # sound "supermandolin"
  # sustain 0.75

-- 我们可以给 pattern 变换版本的 'n' 编排 pattern：
d1 $ off "e" (|+ n "<7 12 -5>") $ n (slow 2 "c(3,8) a(3,8) f(5,8) e*2")
  # sound "supermandolin"
  # sustain 0.75

-- 在上面，7 - 12 - -5 那个 pattern 每三个循环重复一次，
-- c a f e 那个每两个循环重复一次（因为 slow 2）。
-- 它们的组合（或者说相互干涉）持续六个循环。

-- 我们再加一个 'off'，这次偏移一个循环的十六分之一，
-- 并降一个八度。
d1 $ off "s" (|+ n (-12)) $ off "e" (|+ n "<7 12 -5>") $
 n (slow 2 "c(3,8) a(3,8) f(5,8) e*2")
 # sound "supermandolin"
 # sustain 0.75

-- 注意负数必须放在括号里，否则 Haskell 会糊涂，
-- 以为你在做减法！

-- 在迷你记谱里不是这样，所以另一个办法是把
-- 所有负数放进双引号：
d1 $ off "s" (|+ n "-12") $ off "e" (|+ n "<7 12 -5>") $
 n (slow 2 "c(3,8) a(3,8) f(5,8) e*2")
 # sound "supermandolin"
 # sustain 0.75

-- 同样的原则可以用于打击乐，例如：
d1 $ off "<s q e>" (# squiz 2) $ n "{0 1 [~ 2] 3*2, 5 ~ 3 6 4}"
  # sound "cpu2"
  # sustain 0.75

-- 注意上面偏移量本身是有 pattern 的，所以'追随'的
-- pattern 会前后移动。

第 2 课：音阶

▶ 视频

该看看音阶了。用波形在音阶里游走尤其好玩，所以这里有大量对波形的关注。它有点繁琐，因为正如我在视频里解释的，你得用例如 floor <$> 在小数和整数之间转换…… 我得研究一下在 Tidal 里让这变简单。还有练习单：

-- 'arpy' 文件夹里的声音是用以 'c' 起始的五声
-- 'ritusen' 音阶采样的。这个音阶每个八度有五个音。
-- 所以这些是相同的音：
d1 $ n "0 5" # sound "arpy"

d2 $ n "0 12" # sound "superpiano"

-- 这样的五声音阶很好用，因为它们互相都好听。
-- 所以如果我们往旋律里加一个随机音符，
-- 它听起来总是'对'的：

d1 $ n ("0 [7 2] 3 2" |+ irand 3) # sound "arpy"

-- 在常见的十二平均律（12-TET）音阶上就
-- 不是这样了：
d1 $ n ("0 [7 2] 3 2" |+ (irand 3)) # sound "superpiano"

-- 12-TET 是西方钢琴等乐器通常采用的调音音阶。

-- 要使用其他音阶，我们可以用 "scale" 函数把数字
-- 从其他音阶转换到 12-TET。
d1 $ n (scale "ritusen" $ "0 [7 2] 3 2" |+ (irand 3))
  # sound "superpiano"

-- 可用的音阶相当多：
scaleList

-- 用波形从音阶里挑音很好玩。比如，
-- 用平滑的正弦波从小调音阶里选音：
d1 $ segment 16 $ n (scale "minor"
                     $ floor <$> (range 0 14 sine)
                    )
  # sound "supersaw"
  # legato 0.5
  # lpf 1000 # lpq 0.1

-- 记住波形没有结构，所以在你用类似 'segment'
-- 的东西之前不产生事件，上面的例子里它
-- 每循环取 16 个音。

-- 还有个麻烦：波形产生'浮点'小数，
-- 但 scale 只接受'整数' —— 整数。
-- 'floor <$>' 那一段把小数转成整数。
-- "range 0 14" 那一段把通常 0 到 1 的范围
-- 转换成给定的 0 到 14 的范围。

-- 我们可以通过给 range 编排 pattern 让它更刺激：
d1 $ segment 16 $ n (scale "minor"
                     $ floor <$> (range "<0 4 -8>" "<12 14 13 -13>" sine)
                    )
  # sound "supersaw"
  # legato 0.5
  # lpf 1000 # lpq 0.1

-- 用 'struct' 以欧几里得语法给节奏编排 pattern 也许
-- 更刺激…… 顺便把 lpf（低通滤波器）也编排上：
d1 $ struct "t(<9 7>,16)"
  $ n (scale "minor"
        $ floor <$> (range "<0 4 -8>" "<12 14 13 -13>" sine)
      )
  # sound "supersaw"
  # legato 0.5
  # lpf (range 400 5000 saw) # lpq 0.1


-- 这样使用音阶让我们可以玩音的流动，
-- 同时做出'有意义'的曲调。这里我把波形
-- 加在一起，制造一些更长形态的流动：
d1 $ segment 16 $
  n (scale "minor"
      $ floor <$> (slow 2 $ (slow 2 sine + slow 3 cosine) * "<6 -3>"
                  )
    )
  # sound "supersaw"
  # legato 0.5
  # lpf (range 400 5000 saw) # lpq 0.1

-- 回到 struct：
d1 $ struct "t(<9 7>,16)" $
  n (scale "minor"
      $ floor <$> (slow 2 $ (slow 2 sine + slow 3 cosine) * "<6 -3>"
                  )
    )
  # sound "supersaw"
  # legato 0.5
  # lpf (range 400 5000 saw) # lpq 0.1

-- 再加上一个升八度的 'off'：
d1 $ off 0.25 (|+ n 12) $ struct "t(<9 7>,16)" $ segment 16 $
  n (scale "minor"
      $ floor <$> (slow 2 $ (slow 2 sine + slow 3 cosine) * "<6 -3>"
                  )
    )
  # sound "supersaw"
  # legato 0.5
  # lpf (range 400 5000 saw) # lpq 0.1

-- 注意上面 'off' 在 'scale' 函数之外，
-- 所以我们回到了 12-TET 的世界，要升八度得加 '12'，
-- 而不是小调音阶的音数（7）

第 7 周

第 1 课：组合 pattern

▶ 视频

抱歉这周开始得晚了一点。这是一个起步内容，看组合 pattern 的不同方法。我会在下个视频里继续，看看用 ur 函数组合 嵌套 pattern。

-- 组合 pattern

-- 我们已经看过组合 pattern 的不同方法。
-- 像这样简单的东西也是一种组合：

d1 $ fast "1 2 3 4" $ sound "lt mt ht bd*2"

-- 不是特别有趣的一个，但它把一个密度 pattern
-- 和一个音色 pattern 组合起来，创造出一个大于
-- 各部分之和的新 pattern。

-- 不过这一课我们要看的是组合你也许可以称为
-- '独立'pattern 的方法，其中一个不用来操纵另一个。

-- Tidal 常在现场场合使用，但有一些函数能帮你把
-- 多个 pattern 组装成类似完整'作品'的东西，
-- 比如一首有结构的四分钟曲目。

-- 在讲到那之前，先看一些极其简单的组合 pattern
-- 的方法…… 它们可能出奇地有用

-- 首先，`overlay` 只是同时播放给定的两个 pattern：
d1 $ overlay (fast "1 2 3 4" $ sound "lt mt ht ~")
             (sound "clap:4(3,8)" # speed 2)

-- 与它类似的是 `stack`，它让你把任意数量的 pattern
-- 叠在一起。人们往往用它而不是 `overlay`，
-- 因为它更灵活：
d1 $ stack [(fast "1 2 3 4" $ sound "lt mt ht ~"),
            (sound "clap:4(3,8)" # speed 2),
            sound "[kick:5(5,8), snare:3(7,16,3)]"
           ]

-- 上面把一个包含三个 pattern 的列表组合起来。你能看到
-- 列表用方括号（'[' 和 ']'）给出，列表里的 pattern
-- 用逗号（','）分隔。你得记住*不要*在列表末尾
-- 放逗号，只在元素之间放。

-- 上面可能显得没什么用，因为用分开的 pattern 也能
-- 做到。这与上面的声音完全相同：
d1 $ fast "1 2 3 4" $ sound "lt mt ht ~"
d2 $ sound "clap:4(3,8)" # speed 2
d3 $ sound "[kick:5(5,8), snare:3(7,16,3)]"

-- 不过记住 stack 把一切组合成单个 pattern。
-- 这很有用，因为你可以把所有那些 pattern 当做一个
-- 来操纵。例如：
d1 $ chunk 4 (hurry 2) $
  stack [(fast "1 2 3 4" $ sound "lt mt ht ~"),
         (sound "clap:4(3,8)" # speed 2),
         sound "[kick:5(5,8), snare:3(7,16,3)]"
        ]

-- 或者加一个作用于整个 stack 的参数：
d1 $ stack [(fast "1 2 3 4" $ sound "lt mt ht ~"),
            (sound "clap:4(3,8)" # speed 2),
            sound "[kick:5(5,8), snare:3(7,16,3)]"
           ] # squiz "<0 2>"

-- 所以 `overlay` 和 `stack` 把东西叠起来，让它们
-- 同时发生。那怎么把东西在时间上接在一起，
-- 让它们一个接一个地发生？

-- 与 overlay 和 stack 一样，有一个函数 'append'
-- 组合两个 pattern，另一个 'cat' 组合一个 pattern 列表。

-- 两个 pattern：
d1 $ append (fast "1 2 3 4" $ sound "lt mt ht ~")
            (sound "clap:4(3,8)" # speed 2)

-- 一个 pattern 列表：
d1 $ cat [fast "1 2 3 4" $ sound "lt mt ht ~",
          sound "clap:4(3,8)" # speed 2,
          sound "[kick:5(5,8), snare:3(7,16,3)]"
         ]

-- 同样，你会更常看到 `cat` 而不是 `append`。

-- `append` 和 `cat` 保持 pattern 原本的'密度'，
-- 一个循环换一个循环。

-- 还有变体 `fastappend` 和 `fastcat`，它们从每个
-- pattern 取一个循环，把它们全部压进单个循环：

-- 两个 pattern：
d1 $ fastappend (fast "1 2 3 4" $ sound "lt mt ht ~")
  (sound "clap:4(3,8)" # speed 2)

-- 一个 pattern 列表：
d1 $ fastcat [fast "1 2 3 4" $ sound "lt mt ht ~",
              sound "clap:4(3,8)" # speed 2,
              sound "[kick:5(5,8), snare:3(7,16,3)]"
             ]

-- 这没问题，但如果你不想 pattern 之间一个循环一个循环地
-- 轮转，而是想要介于 `stack` 和 `cat` 之间的东西，
-- 让 pattern 可以交叠呢？`seqPLoop` 是一个答案。

-- 用 `seqPLoop`，你说明每个 pattern 何时开始和停止。
-- 我们先模拟之前的 `cat`，让每个 pattern 持续一个循环。
d1 $ seqPLoop [(0, 1, fast "1 2 3 4" $ sound "lt mt ht ~"),
               (1, 2, sound "clap:4(3,8)" # speed 2),
               (2, 3, sound "[kick:5(5,8), snare:3(7,16,3)]")
              ]

-- 现在调整起点和终点，让前两个交叠一个循环，
-- 然后在最后一个播放之前空出一个循环：
d1 $ seqPLoop [(0, 2, fast "1 2 3 4" $ sound "lt mt ht ~"),
               (1, 3, sound "clap:4(3,8)" # speed 2),
               (5, 6, sound "[kick:5(5,8), snare:3(7,16,3)]")
              ]

-- 如果你想多次使用同一个 pattern，可以给它起个名字，
-- 像这样：
let florence = fast "1 2 3 4" $ sound "lt mt ht ~"
in
d1 $ seqPLoop [(0, 2, florence),
               (1, 3, sound "clap:4(3,8)" # speed 2),
               (3, 4, sound "[kick:5(5,8), snare:3(7,16,3)]"),
               (3, 5, florence # coarse 5)
              ]

-- 如果你不想让 pattern 序列循环，就用 seqP。
-- 你需要用类似 `qtrigger` 的东西，让它从循环 0 开始
d1 $ qtrigger $ seqP [(0, 2, fast "1 2 3 4" $ sound "lt mt ht ~"),
                        (1, 3, sound "clap:4(3,8)" # speed 2),
                        (5, 6, sound "[kick:5(5,8), snare:3(7,16,3)]")
                       ]

第 2 课：组合函数

▶ 视频

这是一个关于好用的 . 运算符的快速视频。练习单：

-- 组合函数

-- 假设你想每 3 个循环把这个 pattern 切碎_并且_倒放。
d1 $ sound "bd [~ sd] bd sd" # squiz 2

-- 你可以这样做：
d1 $ every 3 (rev) $ every 3 (chop 8) $
  sound "bd [~ sd] bd sd" # squiz 2

-- 行得通，但有点繁琐。这正是 `.` 运算符派上用场的
-- 地方，它把两个函数变成一个：
d1 $ every 3 (rev . chop 8) $
  sound "bd [~ sd] bd sd" # squiz 2

-- 效果相同，但少打字，很好！

-- 你只需把 `.` 想成把两个函数接成一个管道。

-- 但严格来说：`.` 会拿走输入，传给右边的函数，
-- 拿走_那个_函数的输出，传给左边的函数，
-- 最后返回_那个_函数的返回值。

-- 只要愿意，你可以继续往里接更多函数：
d1 $ every 3 (rev . chop 8 . fast 2) $
  sound "bd [~ sd] bd sd" # squiz 2

-- 你还可以加进效果器：
d1 $ every 3 ((# room 0.7) . rev . chop 8 . fast 2) $
  sound "bd [~ sd] bd sd" # squiz 2

Have fun!

第 3 课：用 "ur" 函数组合曲目

▶ 视频

这是 ur 函数的介绍，它让你用 pattern 造出 pattern，来做成一首曲子。我还谈了使用 ur、seqPLoop 和 stack 时可能遇到的 orbits 和全局效果器（如 reverb、delay）的问题。这仍是 Tidal 有待发展的一块，我很乐意听听你对可能的功能/改进的想法。

这是我解构的 pattern：

d1 $ ur 16 "[bdsd, ~ claps, ~ [bass bass:crunch] ~ bass]"
  [("bdsd", sound "bd [~ sd] bd sd" # squiz 2),
   ("claps", sound "clap:4*2 clap:4*3"
     # delay 0.8 # dt "t" # dfb 0.4
     # orbit 4 # speed 4
   ),
   ("bass", struct "t(3,8)" $ sound "dbass" # shape 0.7 # speed "[1, ~ 2]")
  ]
  [("crunch", (# crush 3))
  ]

第 8 周

第 1 课：平移时间 / 节拍旋转

▶ 视频

天哪，已经到第 8 周了…… 我们用 <~ 和 ~> 来做点时间旅行。这是练习单：

-- 平移时间

-- 我们从一个节奏开始：
d1 $ n "[0 [1 0] 6*2 [3 4*2], 8(5,8)]" # sound "cpu2"

-- 它规律地循环着。让它继续跑，然后运行这个：
d1 $ 0.25 <~ (n "[0 [1 0] 6*2 [3 4*2], 8(5,8)]" # sound "cpu2")

-- 如果你在两者之间切换，你能听出 pattern 在时间上
-- 平移了。`0.25` 表示它平移了四分之一个循环。

-- 只有在你切换到另一个的那一刻你才听得出
-- 两者的差别。你在时间上向前/向后跳，
-- 但一旦到了那里，什么都没变。（！）

-- 好，时间旅行很难谈论。

-- 我们来可视化一下，比较这两个：
drawLine "a b c d"

drawLine $ 0.25 <~ "a b c d"

-- 你能看到 a b c d 序列相同，但在后一种情况里，
-- 循环从 'b' 开始。

-- 所以 '<~' 把我们向_未来_移动了。那不应该是
-- '~>'，而不是 '<~' 吗？？嗯，我们也许是移动到了
-- 未来，但一切都是相对的 —— 从 pattern 的角度看，
-- 它是向过去移动了。而且，虽然我们喜欢认为
-- 我们在向未来前进，但从未来的角度看，
-- 是它向过去移动。再者，不同的人类文化
-- 以不同的方式思考时间。

-- 反正 '~>' 确实存在，比较这两个：

drawLine $ 0.25 <~ "a b c d"

drawLine $ 0.25 ~> "a b c d"

-- 如果你不停地跳来跳去，时间才最有趣。
-- 比如每 3 个循环跳一次：
d1 $ every 3 (0.25 <~) $ n "[0 [1 0] 6*2 [3 4*2], 8(5,8)]" # sound "cpu2"
  # crush 4

-- 向另一个方向跳感觉相当不同：
d1 $ every 3 (0.25 ~>) $ n "[0 [1 0] 6*2 [3 4*2], 8(5,8)]" # sound "cpu2"
  # crush 4

-- 你也可以用 pattern 表示平移量：
d1 $ "<0 0.25 0.75>" ~>
  (n "[0 [1 0] 6*2 [3 4*2], 8(5,8)]" # sound "cpu2" # crush 4)

-- 即使是这种直白的平移，东西也会很快听起来
-- '随机'，直到你的耳朵锁定更长的循环……

-- 插曲——关于语法的一点说明..

-- 不幸的是美元符号的这种用法*不起作用*：
d1 $ "<0 0.25 0.75>" ~> $ n "[0 [1 0] 6*2 [3 4*2], 8(5,8)]"
  # sound "cpu2" # crush 4

-- 这是因为与所有运算符一样，你不能用美元符号
-- 这样把一个 pattern 组合起来再发给 `~>`。haskell 看到
-- 两个相邻的运算符（'$' 和 '~>'）会糊涂。

-- 所以你得用括号：
d1 $ "<0 0.25 0.75>" ~> (n "[0 [1 0] 6*2 [3 4*2], 8(5,8)]"
  # sound "cpu2" # crush 4)

-- 或者绕过这个问题的另一种办法是把*运算符*
-- 包进括号，然后你就可以像普通函数一样用它：
d1 $ (~>) "<0 0.25 0.75>" $ n "[0 [1 0] 6*2 [3 4*2], 8(5,8)]"
  # sound "cpu2" # crush 4

-- 或者把第一个输入和运算符一起包进括号：
d1 $ ("<0 0.25 0.75>" ~>) $ n "[0 [1 0] 6*2 [3 4*2], 8(5,8)]"
  # sound "cpu2" # crush 4

-- 这一切与切碎的循环配合得很好：
d1 $ every 2 ("e" <~) $ every 3 (0.25 <~) $
  loopAt 1 $ chop 8 $ sound "break:8"

第 2 课：二值 pattern

▶ 视频

这是二值 pattern 的快速介绍，重点是用 stitch 和 sew 在一对函数之间切换。这是练习单：

-- 二值 pattern

-- 你发给 SuperDirt 的 pattern 往往包含 String 类型（词）、
-- Double 类型（小数）或 Int 类型（整数）的值。
-- 你大概不会发给 SuperDirt 的一种 pattern 类型
-- 是 Bool 类型 —— Boolean 的缩写。

-- Boolean 值可以是 True 或 False。你大概见过它们
-- 与 'struct' 一起用，例如：

d1 $ struct "t f t t f t f f" $ sound "snare:4"

-- 'struct' 为右边的 pattern 提供结构；每当 boolean pattern 里
-- 有一个 't'（即真值），军鼓就响。

-- 它对欧几里得语法也有效：
d1 $ struct "t(3,8)" $ sound "snare:4"

-- 上面按欧几里得 pattern 创建了一个每循环三个
-- 事件的新 pattern。

-- 我们来看看那个欧几里得 pattern：
drawLine $ struct "t(3,8)" "a"

-- 那么你觉得如果把那个 't'（真）换成 'f'（假）
-- 会怎样？试试：
drawLine $ struct "f(3,8)" "a"

-- 我们也听听那个结构：
d1 $ struct "f(3,8)" $ sound "snare:4"

-- 你能看出和听出播放的是欧几里得 pattern 的*反转*。
-- 原来为真的，现在为假，反之亦然…… 是那些'空'
-- 步拿到了真值，也正是我们最终听到的。

-- 如果同时播放一个 t(3,8) 和一个反转的 f(3,8)
-- 会更清楚：
d1 $ stack [struct "t(3,8)" $ sound "kick:4",
            struct "f(3,8)" $ sound "snare:4"
           ]

-- 你能听出军鼓在'填'底鼓没播放的位置 ——
-- 它们从不同时播放。

-- 这样填补 pattern 非常好玩，有个叫 'stitch' 的函数
-- 让它更容易：
d1 $ stitch "t(3,8)" (sound "kick:4") (sound "snare:4")

-- 你只需给出 boolean pattern 一次，'stitch' 会为第二个
-- pattern 负责反转它。它叫 'stitch'（缝合），
-- 因为就像上上下下把两样东西缝在一起。

-- 你可以做出更复杂的 boolean pattern，快速得到
-- 好玩的 pattern：
d1 $ stitch "t(<3 5>,8,<0 2 3>)" (sound "kick:4") (sound "hc")

d1 $ stitch "t(<3 5>,<8 8 8 6>,<0 2 4>)" (sound "kick:4") (sound "hc")

-- 其实直接在 sound 控制参数 pattern_内部_做缝合
-- 可以少打些字：
d1 $ sound (stitch "t(<3 5>,<8 8 8 6>,<0 2 4>)" "kick:4" "hc")

-- 在上面我只需写一次 'sound'，因为 'stitch' 作用于
-- 字符串 pattern，而不是音色的 pattern。

-- 你也可以在真值 pattern 和假值 pattern 之间交替：
drawLine $ struct "<t f>(3,8)" "a"

-- 如果你更喜欢，可以用 '1' 或 '0' 代替 't' 和 'f'，
-- 结果完全一样：
drawLine $ struct "<1 0>(3,8)" "a"

d1 $ struct "<1 0>(3,8)" $ sound "clap"

-- 你不必用欧几里得语法，可以完全手写出来：
d1 $ stitch "t f t t f f t f" (sound "kick:4") (sound "hc")

-- …… 并使用常用的迷你记谱语法：
d1 $ stitch "t f t [t f]*2 f ~ t f" (sound "kick:4") (sound "hc")
  # room 0.2 # sz 0.8

-- 用 stitch，节奏结构来自 boolean pattern。它有个
-- 同义伙伴 'sew'，它改为保留被缝合的那些 pattern
-- 各自的结构。

-- 试试看：
d1 $ sew "t f" (sound "kick") (sound "clap:4")

-- 噢！我们只听到了底鼓。这是因为 'f' 只在循环的
-- 后半段切换到第二个 pattern，而那时没有新的
-- 'clap' 发生。

-- 如果我们有四个拍手铺满循环，就能听到
-- 后面两个：
d1 $ sew "t f" (sound "kick") (sound "clap:4*4")

-- Sew 用来融合两个更复杂的 pattern 会非常出彩。
-- 先分别听听它们：

d1 $ chunk 4 (hurry 2) $ n "0 .. 7" # sound "cpu"

d1 $ n "0 .. 7" # sound "cpu2" # speed 1.5 # squiz 2

-- 现在缝合起来：
d1 $ sew (iter 4 "t f")
  (chunk 4 (hurry 2) $ n "0 .. 7" # sound "cpu")
  (n "0 .. 7" # sound "cpu2" # speed 1.5 # squiz 2)

-- 上面我用了非常简单的 "t f" 二值 pattern，但用了
-- 'iter 4' 让它每循环平移四分之一…… 所以被缝合
-- pattern 的不同部分会透出来。

第 3 课：把值适配进 pattern

▶ 视频

好，拖了一阵之后，我回来终于把第 8 周收尾！这是对 fit 函数的讲解。我很乐意听听你对它的想法和问题！这是练习单：

-- 我们把列表里的东西适配进 pattern！

-- 这是'类型签名'，它在告诉我们什么？
fit :: Int -> [a] -> Pattern Int -> Pattern a

-- 'fit' 接受一个整数、一个东西的列表、一个整数 pattern，
-- 然后返回一个东西的 pattern。

-- Int - 一个'步长' —— 每个循环在列表里前进多远
-- [a] - 一个列表 —— 你想放进 pattern 里的东西
-- Pattern Int - 引用列表中东西的数字 pattern
-- Pattern a - 结果！'Pattern a' 意味着它可以处理
-- 任何类型的 pattern

-- 我们从简单的开始，步长为 0

d1 $ n (fit 0 [9,10,11,12,13,14] "0 1 2 3") # s "alphabet"

-- 那只是在字母表的四个字母（j、k、l、m）里循环。
-- 我们的列表里有六个数字，但只用到了前四个
-- （0 到 3）。

-- 用上全部六个，再加一点结构：
d1 $ n (fit 0 [9,10,11,12,13,14] "[0 3] [1 2] 4 [~ 5]") # s "alphabet"

-- 注意如果走过列表末尾，你会回到开头。
-- 所以 '0' 和 '6' 都指向六个数字中的第一个，
-- 也就是 '9'（给我们 'j'）
d1 $ n (fit 0 [9,10,11,12,13,14] "0 6") # s "alphabet"

-- 好，如果我们开始玩那个'步长'会怎样？
d1 $ n (fit 1 [9,10,11,12,13,14] "0 1 2 ~") # s "alphabet"

-- 开始有点让人糊涂了，但你应该能听出每个循环，
-- pattern 在列表里前进一步，直到再次回到开头。
-- 所以如果它从 'j'、'k'、'l' 开始，下一个循环它会
-- 前移一位给出 'k'、'l'、'm'，如此继续，直到又
-- 绕回开头。

-- 这对生成旋律很有用。节奏保持不变，
-- 但音符在演化，沿着 pattern 移动
d1 $ note (fit 2 [0,2,7,5,12] "0 ~ 1 [2 3]") # sound "supermandolin"
  # legato 2 # gain 1.3

d2 $ n "0 ~ 2 [3*2 4*2]" # sound "cpu" # speed 2
