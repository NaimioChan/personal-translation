默认音色库

安装 SuperDirt 时也会一并下载一份默认的音频采样音色库。这个音色库被称为 *default*（默认）库，是每个人起步时都有的那一份。其中一些音色相当好用，另一些则可能有点怪。把你喜欢的留下来，把不喜欢的文件夹换掉。你可以在这里看看这个音色库。

Dirt/Clean 音色库

社区目前正在尝试打造一个新的、更精致的默认音色库版本，名字起得颇有反讽意味，叫 Clean Samples。提交你自己的自定义采样就能帮上忙。这是一个进行中的项目。
