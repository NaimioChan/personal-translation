工作坊

欢迎来到这篇 Tidal Cycles 教程。它专为在面向初学者/混合水平的工作坊中作为实操工作单使用而设计。作者 Lucy Cheesman，由 Alex McLean 改编为 wiki 格式。

开始

一切安装完毕后，每次都按以下启动流程操作。

  1. 启动 SuperDirt

运行 SuperCollider IDE 应用时，SuperDirt 应该会自动启动。如果没有，在 SuperCollider IDE 的编辑器窗口中输入 'SuperDirt.start'，然后按住 Ctrl 并按下 Enter 来运行代码（光标需位于代码所在行）。

  1. 启动 Tidal Cycles

在你的文本编辑器（Pulsar、vim、VS Code 等）中新建一个文件，并以 .tidal 扩展名保存（例如 examples.tidal）。当你输入并执行第一条命令时，Tidal 会自动启动。

Estuary

即使你的电脑上还没安装 Tidal，也仍然可以在线体验。Estuary 让你在浏览器中玩 Tidal 和其他几个现场编码系统，无需在电脑上安装任何东西。

Estuary 是学习、教学、与他人一起玩以及测试不同现场编码语言的绝佳场所。

不过要注意，并非 Tidal 的所有功能都能在 Estuary 上使用，只有一个子集（称为 Mini-Tidal）。

Haskell 中的注释

Haskell 在行首用双横线 -- 表示注释。注释是会被解释器忽略的代码。你可以用注释在代码里添加笔记，也可以用注释忽略某一行或某个 pattern：

–- 我是注释

-- 这个 pattern 不会播放
-- d1 $ s "bd hh sn hh"

-- "fast 2" 会被忽略
d1
--  $ fast 2
  $ s "hh*8"

基础 pattern

在 Tidal 中发声的基本格式如下：

d1 $ sound "drum"

你可以用 silence 停止发声：

d1 $ silence

与 sound 搭配的音色有两类：要么是合成器定义（如 superpiano，见合成器），要么是采样。后者情况下，你写的是包含采样集的文件夹名称。默认使用第一个采样，但你可以用 : 加数字从同一集合中选取其他采样：

d1 $ sound "drum:1"

此外，也可以把文件夹和采样分两部分指定：

d1 $ sound "drum" # n 1

注意 s 是 sound 的同义词，所以 d1 $ s "drum" # n 1 是同一个 pattern。

默认音色库

下面列出了 Tidal 自带的部分采样。试试看吧！

flick sid can metal future gabba sn mouth co gretsch mt arp h cp
cr newnotes bass hc tabla bass0 hh bass1 bass2 oc bass3 ho odx
diphone2 house off ht tink perc bd industrial pluck trump printshort
jazz voodoo birds3 procshort blip drum jvbass psr wobble drumtraks koy
rave bottle kurt latibro rm sax lighter lt arpy feel less stab ul

你可以在 Dirt-Samples 文件夹里查看默认音色库还有哪些音色。通过 SuperCollider 菜单找到它：'File > Open user support directory > downloaded-quarks > Dirt-Samples'。此外，你也可以添加自己的自定义采样。在 Pulsar 编辑器中，你可以添加一个设置来加载包含所有 Dirt-Samples 的标签页（见 Pulsar）。

做一个序列：

d1 $ sound "bd hh sn hh"

序列中的步骤越多，播放越快：

d1 $ sound "bd bd hh bd sn bd hh bd"

这是因为 Tidal 处理时间的方式。存在一个通用的循环（有点像音乐上的"小节"），它一直在运行。Tidal 会在一个循环内播放引号之间的所有音色，除非你告诉它不要这样（我们稍后会学怎么做）。你还会注意到 Tidal 会让音色在循环内均匀分布，这意味着我们可以得到多重节奏结构（稍后详述）。我们可以用 setcps 改变循环的长度（其中 cps 代表每秒循环数）——这有点像 BPM（每分钟节拍数）。

setcps 0.6

你可以用 d1, d2, d3...d9 同时播放多个序列：

d2 $ sound "sn sn:2 sn bd sn"

你可以用 hush 停止所有正在运行的 pattern（或按 Ctrl+.）。

你可以把循环长度改成负数来暂停一切（记住负数要加括号）。

setcps (-1)

再用正数重新启动

setcps 0.6

或者你可以 solo 某个通道：

d1 $ sound "arpy cp arpy:2"
d2 $ sound "sn sn:2 bd sn"

solo 2

-- 现在只有第二个 pattern 在播放

unsolo 2

-- 现在两个又都在播放了

mute 2

-- 现在只有第一个 pattern 在播放

unmute 2 -- （或 unmuteAll）

-- 现在两个都在播放

Pulsar 插件为这些常用操作添加了一些快捷键，比如 Ctrl+1 切换第一个 pattern 的静音，或 Ctrl+0 取消所有静音。你可以在 Pulsar 里查看完整的快捷键列表：前往 Edit > Preferences > Packages，选中 tidalcycles，向下滚动到 Keybindings 一节。

更多变化

我们给序列增加更多变化吧：

用 ~ 加入静默/休止：

d1 $ sound "bd ~ sn:3 bd sn:5 ~ bd:2 sn:2"

用方括号把一个子序列塞进一步：

d1 $ sound "bd [bd cp] bd bd"

这样可以做出灵活的拍号：

d1 $ sound "[bd bd sn:5] [bd sn:3]"

你可以在子序列里再嵌套子序列：

d1 $ sound "[[bd bd] bd sn:5] [bd sn:3]"

继续下去……

d1 $ sound "[[bd [bd bd bd bd]] bd sn:5] [bd sn:3]"

你可以用 * 重复一步：

d1 $ sound "bd sd*2"

这对子序列也有效：

d1 $ sound "bd [sd cp]*2"

或者用 / 反过来做：

d1 $ sound "bd sn/2"
d1 $ sound "bd [sn cp]/2"

* 的原理是"加速"一步，让它播放多次。/ 的原理是"放慢"它。

我们还可以用 < 和 > 把 pattern 安排到不同循环上：

d1 $ sound "bd <sd cp arpy>"
d1 $ sound "<bd sn> <sd [cp cp]> <bd [cp cp]>"

这些例子里使用的语法叫迷你记谱，它在 Tidal 内的许多地方都可以使用，不限于 sound 函数。

其他常见的迷你记谱符号有：| 随机选择一个选项，, 同时播放两个 pattern，! 复制一个 pattern。

从两个采样中随机选择一个：

d1 $ sound "[bd:0|bd:1]"
d1 $ sound "[sn|cp]"

同时播放一个军鼓和一个拍手：

d1 $ sound "[sn,cp]"

播放三个底鼓和一个军鼓：

d1 $ sound "bd!3 sn"

注意它与 "bd*3 sn" 的区别：第一个例子里有四个事件，时长全部相同。后者中三个 bd 占半个循环，sn 占另外半个。"bd!3 sn" 等同于 bd bd bd sn。

效果器

Vowel

Tidal 有很多效果器可以用来改变声音。vowel 是一个添加元音音色的滤波器——试试 a, e, i, o 和 u：

d1 $ sound "drum drum drum drum" # vowel "a"

我们创建效果器 pattern 的方式与创建音色 pattern 基本相同。我们把这类效果器和音色 pattern 称为"控制 pattern"。所以：

d1 $ sound "drum drum drum drum" # vowel "a o e e"

记得我们可以用 "<>" 把 pattern 安排到不同循环上：

d1 $ sound "drum drum drum drum" # vowel "<a o e e>"

你可以加入一个非元音字母来暂停 vowel 效果：

d1 $ sound "drum drum drum drum" # vowel "a o p p"

Tidal 会尽力把各个 pattern 相互映射：

d1 $ sound "drum drum drum drum" # vowel "a o e"

结构来自左侧——试着交换一下参数：

d1 $ vowel "a o ~ i" # sound "drum"

Gain、音高与声像

gain 改变不同音色的音量：

d1 $ sound "bd hh sn:1 hh sn:1 hh" # gain "1 0.7 0.5"

speed 和 note 用于给采样变调。speed 影响播放速度（例如 2 = 升一个八度）：

d1 $ sound "numbers:1 numbers:2 numbers:3 numbers:4" # speed "1 1.5 2 0.5"

我们也可以从 speed 参数出发取 pattern：

d1 $ speed "1 2 4" # sound "jungbass:6"

up 以半音为单位把采样升高（例如 12 = 升一个八度）：

d1 $ up "0 ~ 12 24" # sound "jungbass:6"

pan 让我们做出立体声效果（0 = 左，0.5 = 中，1 = 右）：

d1 $ sound "numbers:1 numbers:2 numbers:3 numbers:4" # pan "0 0.5 1"

失真、混响、延迟与滤波器

shape 是可用来添加失真的几个函数之一（但要小心——它也会让声音变得很响）：

d1 $ sound "kurt:4 kurt:4" # shape "0 0.78" # gain "0.7"

延迟通过最多四个函数的组合来实现：

d1 $ sound "cp" # delay 0.8 # delaytime (1/6) # delayfeedback 0.6 # lock 1

用 lock 1 表示提供给 delaytime 的时间以循环为单位而不是秒。

它们全都接收 pattern：

d1 $ sound "industrial:3*4" # delay "<0 0.4 0.8>" # delaytime "0.2 0.05" # delayfeedback "<0.5 0.9>" # lock 1

要添加混响效果，使用函数 dry、room 和 size：

d1 $ sound "[~ sn]*2" # dry 0.4 # room 0.6 # size 0.8

还有若干频率滤波器可用：低通、高通、DJ 型滤波器等等。

低通滤波器：

d1 $ sound "tabla*4" # n "0 1 2 3" # cutoff 400 # resonance 0.2

高通滤波器：

d1 $ sound "tabla*4" # n "0 1 2 3" # hcutoff 600 # hresonance 0.2

cutoff 和 hcutoff 接收以赫兹为单位的截止点频率。resonance 和 hresonance 取值从 0 到 1，但要注意高共振值可能产生非常响的声音。

djf 是一个更直接的滤波器：它接收 0 到 1 之间的数字。小于 0.5 时是低通滤波器，大于 0.5 时是高通滤波器。

你可以查看效果器一节，了解更多效果器知识并查看完整的效果器列表。

变换 pattern

我们可以用变换来构建复杂得多的 pattern。使用 slow 这类函数，你可以开始超越循环。slow 把 pattern 拉伸到更多个循环上：

Slow、fast 和 hurry

d1 $ sound "arpy arpy:1 arpy:2 arpy:3"

d1 $ slow 2 $ sound "arpy arpy:1 arpy:2 arpy:3"

fast 把 pattern 压缩到不到一个循环内。你可能还会看到有人写 density——是一回事。看看：

fast 0.5 is the same as slow 2!

d1 $ fast 2 $ sound "arpy arpy:1 arpy:2 arpy:3"
d1 $ fast 0.5 $ sound "arpy arpy:1 arpy:2 arpy:3"

hurry 与 fast 类似，但还会应用一个速度变换：

d1 $ sound "arpy arpy arpy:1 arpy:2"
d1 $ hurry 2 $ sound "arpy arpy arpy:1 arpy:2"
d1 $ hurry 0.5 $ sound "arpy arpy arpy:1 arpy:2"

请参阅参考手册中的时间一节，进一步了解改变时间的函数。

重组 pattern

Tidal Cycles 提供了许多函数，可以用不同方式改变你的 pattern。本节介绍其中一些，但还有更多。你可以查阅这些参考章节找到更多：alteration、accumulation 和 conditions。

你可以用 rev 倒放一个 pattern：

d1 $ rev $ sound "arpy arpy:1 arpy:2 arpy:3"

或者用 palindrome 先正放再倒放：

d1 $ palindrome $ sound "arpy arpy:1 arpy:2 arpy:3"

iter 让 pattern 每个循环从不同的点开始，按给定的次数平移，直到回到起点：

d1 $ iter 4 $ sound "arpy arpy:1 arpy:2 arpy:3"

every 让我们把变换或效果器安排到不同的循环上。下面这个例子每四个循环以两倍速播放一次：

d1 $ every 4 (fast 2) $ sound "arpy arpy:1 arpy:2 arpy:3"

……你也可以用 # 以同样的方式安排一个效果器：

d1 $ every 4 (# vowel "a o") $ sound "arpy arpy:1 arpy:2 arpy:3"

jux（juxtapose 的缩写）接收一个变换或效果器，在一个音箱播放它，同时原始 pattern 在另一个音箱播放：

d1 $ sound "arpy arpy:1 arpy:2 arpy:3"
d1 $ jux (rev) $ sound "arpy arpy:1 arpy:2 arpy:3"
d1 $ jux (hurry 2) $ sound "arpy arpy arpy:1 arpy:2"

chunk 每次把变换或效果器应用到 pattern 的不同部分。例如参数为 4 时，它会逐步走过循环的每个四分之一。

d1 $ chunk 4 (hurry 2) $ sound  "arpy arpy:1 arpy:2 arpy:3"
d1 $ chunk 4 (# speed 2) $ sound  "alphabet:0 alphabet:1 alphabet:2 alphabet:3"

更深入变换

不止一个变换是可能的！你可以用 . 把它们串起来：

d1 $ jux (rev . (slow 1.5)) $ sound "arpy arpy:1 arpy:2 arpy:3"

记住（几乎）一切都是 pattern，所以我们也可以把这些变换应用到效果器上：

d1 $ sound "jvbass [jvbass jvbass] jvbass ~" # note "1 [3 5] 7"
d1 $ sound "jvbass [jvbass jvbass] jvbass ~" # iter 3 (note "1 [3 5] 7")

你可以用 fast 或 slow、range 以及 sine 或 saw 等振荡器，在任何参数上做出 LFO：

d1 $ s "bd*8" # pan (slow 4 $ sine)
d1 $ s "moog*16" # n "<0 1 2>" # legato 1 # cutoff (range 200 2400 $ saw) # resonance 0.2

默认情况下，sine、cosine 或 saw 等振荡器给出的值从 0 到 1。这对某些参数（如 pan）没问题，但你可以用 range 把这些值缩放到任何你想要的范围。

前面的例子为每个事件触发一个振荡器值。如果每个循环有很多事件，这就够了。但如果事件更少、更长，我们就需要从振荡器中取多个值，才能实现平滑的 LFO 运动。你可以用控制总线做到这一点：

d1 $ s "moog" # n "<0 1 2>" # legato 1 # cutoffbus 1 (segment 32 $ range 200 2400 $ saw) # resonance 0.2

在这里我们可以听到声音在循环过程中如何逐渐变化。许多参数都有对应的总线，命名方式都是参数名加 bus。在最后一个例子里，segment 32 告诉振荡器每个循环取 32 个值。

不同种类的 pattern

到底什么是 pattern？让我们思考一些不同种类的 pattern，以及 Tidal 如何表现它们。

循环 / 重复

我们可以用 n 从文件夹中选取采样，这让我们也能在那里应用 pattern：

d1 $ n "0 1 2 3" # sound "arpy"

run 是写顺序 pattern 的一种简写：

d1 $ n (run 4) # sound "arpy"

或者我们可以用：

d1 $ n "0 .. 3" # sound "arpy"

对称

d1 $ slow 2 $ n "0 1 2 3 3 2 1 0" # sound "arpy"
d1 $ palindrome $ n (run 4) # sound "arpy"

多节拍 / 多重节奏序列

用方括号（有点像一个大子序列！）并以逗号分隔，同时播放两个子序列：

d1 $ sound "[voodoo voodoo:3, arpy arpy:4 arpy:2]"

如果你改用花括号而不是方括号，会得到不同的效果。方括号会把序列的两半都塞进循环里（多重节奏）。花括号则由左手边的 pattern 设定脉冲。右手边的 pattern 随后可以与之重叠（或不足！）（多节拍）：

d1 $ sound "[voodoo voodoo:3, arpy arpy:4 arpy:2]"
d1 $ sound "{voodoo voodoo:3, arpy arpy:4 arpy:2}"
d1 $ sound "[drum bd hh bd, can can:2 can:3 can:4 can:2]"
d1 $ sound "{drum bd hh bd, can can:2 can:3 can:4 can:2}"
d1 $ sound "[bd sn, can:2 can:3 can:1, arpy arpy:1 arpy:2 arpy:3 arpy:5]"
d1 $ sound "{bd sn, can:2 can:3 can:1, arpy arpy:1 arpy:2 arpy:3 arpy:5}"

欧几里得节奏 / Bjorklund

如果你在 pattern 中的某个元素后面的括号里给出两个数字，Tidal 会尝试把第一个数字那么多的音色均匀分布到第二个数字那么多步上：

d1 $ sound "bd(5,8)"

你可以在 pattern 的单个元素内部使用这种记法：

d1 $ sound "bd(3,8) sn*2"
d1 $ sound "bd(3,8) sn(5,8)"

你还可以加上第三个参数，它会"旋转"pattern，使其从不同的一步开始：

d1 $ sound "bd(5,8,2)"

随机性

随机性可以帮助我们快速为 pattern 引入个性和变化。sometimes 的运作有点像 every，但不是在固定周期后发生，而是变化有随机出现的概率：

d1 $ sometimes (# speed "2") $ sound "drum*8"

often（75%）与 sometimes（50%）类似，但发生得更频繁：

d1 $ often (# speed "2") $ sound "drum*8"

irand 生成一个不超过指定数字的随机整数（例如播放一个随机采样）：

d1 $ sound "arpy(3,8)" # n (irand 16)

rand 生成一个 0 到 1 之间的随机小数：

d1 $ sound "tink*16" # gain rand

你可以用 degradeBy 随机移除元素。数字表示一个采样被播放的概率：

d1 $ degradeBy 0.2 $ sound "tink*16"

（单独的 degrade 等同于 degradeBy 0.5）

或者，你可以用 ? 以 50% 的概率移除音色：

d1 $ sound "bd sn:2? bd sn?"

操控采样

到目前为止我们只用了短采样。如果不小心，长采样会给我们带来一些麻烦。让我们看看一个长采样会发生什么：

d1 $ sound "bev"
-- 稍等片刻，然后……
hush

正如你听到的，Tidal 会在每个循环里持续触发采样，哪怕它非常长。即使你停止了 pattern 的播放，你仍然需要听着采样播完。你可以用 cut 在下一个采样被触发时截断当前采样：

d1 $ sound "bev" # cut 1

cut 中的数字定义了一个组，因此你可以在不同 pattern 之间制造干扰来玩：

d1 $ sound "bev ~" # cut 1
d2 $ slow 4 $ sound "pebbles ~" # cut 1

legato 也会截断采样，但使用固定长度：

d1 $ sound "bev ~ bev ~" # legato 1

我们还可以 chop 采样来制造颗粒合成效果：

d1 $ chop 32 $ sound "bev"

striate 与 chop 类似，但以不同的方式组织播放：

d1 $ slow 4 $ chop 4 $ sound "arpy:1 arpy:2 arpy:3 arpy:4"
d1 $ slow 4 $ striate 4 $ sound "arpy:1 arpy:2 arpy:3 arpy:4"

randslice 把采样切成碎片，然后每个循环随机播放一片：

d1 $ randslice 32 $ sound "bev"

我们还可以用 loopAt 把采样适配到固定数量的循环：

d1 $ loopAt 8 $ sound "bev"

一如既往，我们可以为这些函数添加 pattern 和变换，或组合它们做出有趣的效果：

d1 $ loopAt "<8 4 16>" $ chop 64 $  sound "bev*4" # cut 1
d1 $ rev $ loopAt 8 $ chop 128 $ sound "bev"

在采样参考章节查看更多操控长采样的方法。

Superdirt 合成器

到目前为止我们只用过采样，但 SuperDirt 还自带许多 SuperCollider 合成器，如 superpiano、supersaw 或 superfm，也简称 synth。

它们每个都有自己的函数和参数，但总体上可以像采样一样非常相似地使用：

d1 $ n "0 4 7" # sound "superpiano"

你也可以通过 MIDI 或 OSC 控制外部合成器

函数 n 与 note 的区别

使用合成器时，n 和 note 两个函数完全相同：你可能已经注意到，上面的例子播放了一个 C 音、一个 E 音（比 C 高 4 个半音）和一个 G 音（比 C 高 7 个半音）。这与下面完全一样：

d1 $ note "0 4 7" # sound "superpiano"

使用采样时，n 指的是采样文件夹中的文件序号，按字母顺序（升序）排列并从 0（零）开始计数。如果你录下了某件乐器的每一个音，每个采样都可以对应一个音符。但使用 note 时，采样会被升高或降低音高（采样时长也随之改变）。

举例来说：

d1 $ sound "bd*4" # n "<0 4>" # note "0 12 -7 -12"

这会在奇数循环播放 bd 文件夹中的第一个采样，偶数循环播放第五个采样。每个循环中，采样会播放 4 次：一次原样，一次升高一个八度（12 个半音），一次低五度（7 个半音），最后一次低一个八度。

演奏音符

本教程的大部分内容都在讲节奏，但 Tidal Cycles 也提供了演奏音符、音阶、和弦与琶音的方法。

你已经知道怎么演奏音符了：使用 note 函数，或者如果你有逐音符采样的乐器，就用 n 函数选择音符。

你还可以依据西方音乐理论的命名规则书写音符，它使用字母表的前 7 个字母（A 到 G）。例如，下面两行代码是等价的：

d1 $ note "c a f e" # s "supermandolin"
d1 $ note "0 9 5 4" # s "supermandolin"

音符名称在 tidal 中只是被翻译成数字，所以你可以任选一种方法，或两种同时使用！

注意，任何音符名称后面都可以跟 s 或 f 分别表示升号和降号。另外，0 和 c 指的是第五个八度上的 C 音。你可以在任何音符名称后面附加八度数字：

d1 $ note "c4 a3 f6 e5" # s "supermandolin"

用 |+ 或 |- 移动八度也很有用。这会在第三个八度上演奏：

d1 $ note "c a f e" # s "superpiano" |- note 24

想进一步了解如何演奏音阶、和弦与琶音，请参阅和声或 how-to 构建琶音与 演奏和弦
