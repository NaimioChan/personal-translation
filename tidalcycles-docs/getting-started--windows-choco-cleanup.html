Windows 清理 - Chocolatey

（感谢 @il_mix 创建并测试了这些 chocolatey 清理步骤。）

目的：
本文档是一份参考，说明如何从 Windows Chocolatey 安装中进行清理/卸载。涵盖以下多种场景：

  1. 清理 Haskell 组件
  2. 完全清除所有 Chocolatey 组件安装，然后移除 choco 应用本身
  3. 移除单个组件

背景
Chocolatey 是一个包管理系统，用于 Tidal Cycles 的自动安装流程。它涵盖运行 Tidal 所需的全部组件和依赖的完整安装。这是一个不错的方案，大多数时候都能顺利工作。但也可能出现问题，这时可能需要从你的电脑上移除某些组件或整个 Chocolatey 环境。本页只是一份指南，并未涵盖所有问题。

  • Powershell 中的所有步骤都需要以管理员身份运行 Powershell 来完成。
  • 你可以运行这条命令查看 choco 当前安装了哪些组件和版本：
choco list --local-only

Haskell 清理步骤

如果你之前用 chocolatey 安装过，系统里会有旧版本的 Haskell 组件，在新 Haskell 组件装好之后它们可能引发冲突。在这种情况下，你需要先卸载所有 Haskell 文件，然后再运行 Chocolatey 的 Tidal 安装程序。注意，在某些情况下，可能仍然需要（或想要）完全卸载所有 Chocolatey 内容。

  • 卸载 Haskell 组件 
    choco uninstall ghc
choco uninstall cabal
  • 移除本地包 - 删除这些目录： 
    C:\Users\yourUser\AppData\Roaming\ghc
C:\Users\yourUser\AppData\Roaming\cabal
C:\Users\yourUser\AppData\Local\ghc
C:\Users\yourUser\AppData\Local\cabal
  • 移除任何残留的 ghc / cabal 目录： 
    C:\tools\ghc-\<version\>  例如：- C:\tools\ghc-8.10.0
C:\ProgramData\chocolatey\bin\cabal.exe

Tidal 安装选项

清理完 Haskell 后，你有两个选择：

  1. 再次运行完整的自动安装程序。 
    choco install tidalcycles

\- 或者 -

  1. 只用 chocolatey 安装 Haskell，然后手动安装 Tidal 
    choco install ghc
cabal update
cabal v1-install tidal

完全清除 Chocolatey 的步骤

这会移除 Chocolatey 安装的所有东西，然后移除 choco 安装器本身。它会清理环境变量和目录。注意：这会移除 Tidal 技术栈中的所有内容：SuperCollider/SuperDirt、Pulsar、Haskell 等等。以下情况推荐这样做：

  • 你想切换到手动安装
  • 你遇到了严重的安装问题，想"从零开始"

步骤

  • 卸载 chocolatey 安装的组件 
    choco uninstall all -x -y
  • 移除应用程序 - 删除这些目录 
    C:\tools
C:\ProgramData\chocolatey
  • 移除本地包 - 删除这些目录： 
    C:\Users\yourUser\AppData\Roaming\ghc
C:\Users\yourUser\AppData\Roaming\cabal
C:\Users\yourUser\AppData\Local\ghc
C:\Users\yourUser \AppData\Local\cabal
  • 环境变量
    • 用户变量：
      • 删除：ChocolateyLastPathUpdate、ChocolateyToolsLocation
      • 从 Path 中移除：C:\tools\ghc-你的版本号\bin
    • 系统变量：
      • 删除变量：ChocolateyInstall
      • 从 Path 中移除：C:\ProgramData\chocolatey\bin
  • 重启系统

现在你可以继续手动安装步骤，或者用自动安装程序的步骤从零开始。

祝你好运！

有时 Tidal 的安装过程会很复杂、需要很多步骤。坚持下去吧！好消息是，一旦装好，Tidal 技术栈非常稳定可靠。

移除单个组件的步骤

choco 安装的任何包都可以用基本的 choco 命令卸载。难点在于，可能会留下其他目录或文件，之后引发冲突或困惑。（这个旧目录怎么会在我的系统上？）

choco 安装了什么？

choco list --local-only

要卸载一个组件，先运行卸载命令：

choco uninstall <component>
# choco uninstall sc3-plugins

然后搜索你的系统，看看是否有需要移除的残留文件。
