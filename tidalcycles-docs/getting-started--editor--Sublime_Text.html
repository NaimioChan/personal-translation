Sublime Text

Sublime Text 是一款流行的跨平台文本编辑器。它是闭源的，售价 70 美元。不购买也可以继续使用 Sublime Text，但要做好准备每隔几分钟就会弹出一个提醒你购买的烦人窗口。Sublime Text 非常轻量，并且高度可配置。

安装

在所有主流操作系统上，安装过程都应该很简单。前往官方网站下载/安装即可。

Tidal 配置

要在 Sublime Text 中进行现场编码，你需要通过 Package Control 安装 Sublime REPL 包。为了避免改动 Sublime REPL 自带的 Haskell REPL，直接克隆它的一个修改版本即可：

cd ~/Library/Application Support/Sublime Text 3/Packages/SublimeREPL/config
git clone https://gist.github.com/lvm/e0943b0d42507af60eee174ed263adde Tidal

Sublime REPL 所用的启动代码目前已失效。一个简单的修复方法是把 此链接中的代码复制粘贴到 ~/Library/Application Support/Sublime Text 3/Packages/SublimeREPL/config/Tidal/ghci-tidal.conf 中，替换掉原有的内容。

旧版

如果你使用的是经典的 Dirt 而不是新的 SuperDirt，可以使用一个更旧的配置版本：

cd ~/Library/Application Support/Sublime Text 3/Packages/SublimeREPL/config
git clone https://gist.github.com/lennart/8b811cd4f568f7d7100e Tidal

这样，Cmd+Shift+P -> “Sublime REPL: Tidal” 会启动一个加载了 Tidal、绑定了 Dirt 通道并为 hush 和 cps 添加了宏的 ghci 实例。

事先分屏（例如 Cmd+Alt+Shift+2 为两行布局）会把 REPL 加载到另一个分屏中，这样你可以在一侧写代码，在另一侧求值。按行求值代码默认映射到 Ctrl+l，但可以自定义为你喜欢的按键：

{ "keys": ["shift+enter"],
   "command": "repl_transfer_current",
   "args": {"scope": "lines"} }

如果出现错误 Cannot find REPL for `plain`，请尝试把文件重命名为 .hs 而不是 .tidal，因为我们用的是 Haskell REPL 的修改版本。当然，你必须先确保 dirt 已经在运行，才能听到声音。
