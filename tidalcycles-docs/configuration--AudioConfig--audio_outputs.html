音频输出

分离的音频通道

假设你想做一份多轨录音，让不同的 pattern 同时播放、却分开录制；或者想把某些 pattern 的音频路由到外部效果处理器。这怎么可能做到？Tidal 的音频引擎（在大多数情况下）是 SuperDirt，而路由音频通道的关键在于理解如何配置和使用 orbit。你可以把每个 orbit 想象成一个音频输出，它有自己的一组全局效果器（默认是混响和延迟）。

去看一看 SuperDirt 的文档，特别是示例文件 superdirt_startup.scd。你会想把其中的设置代码粘贴到 SuperCollider 编辑器窗口里。如果你把它存进 SuperCollider 的启动文件，那么每次打开 SuperCollider 时它都会自动运行——这个文件可以通过菜单找到。

这段设置代码里你可能想改的大概只有两处。如果你想要六个立体声输出，那总共需要 `12` 个通道，所以要把输出总线通道数设成相应的值，即：

s.options.numOutputBusChannels = 12;

你通过给每个 orbit 一个偏移量，把它们分配到不同的立体声通道上，像这样：

~dirt.start(57120, [0, 2, 4, 6, 8, 10]);

你可能也想顺手改掉这一行里的数字：

~dirt = SuperDirt(2, s);

不过如果你想以立体声方式工作，这个数字应该保持为 2，也就是每个 orbit 的通道数。

如果你的编辑器插件（因而也包括 BootTidal.hs），那么 `d1` 会自动发送到 orbit 0，`d2` 发送到 orbit 1，依此类推。你也可以用 orbit 控制参数明确指定，例如：

d1 $ sound "bd" # orbit 3

现在你尽可以把音频路由到 DAW 里做效果处理或录音，也可以直接从 SuperCollider 把所有通道录成一个多通道文件。

多通道声音

一般来说我们处理的是立体声，也就是用两只扬声器并在它们之间做声像分布。不过有时用四只甚至更多扬声器工作、享受环绕声体验也很不错。多通道声音的设置方式与我们做分离的音频输出时类似。分离输出时我们发送的可能是多个立体声输出，而多通道声音通常只发送一个输出，但带多个通道。

这里是一个在四个通道之间做声像分布的 supercollider 启动文件示例：

(
s.options.numBuffers = 1024 * 256;
s.options.memSize = 8192 * 16;
s.options.maxNodes = 1024 * 32;
s.options.numOutputBusChannels = 4; // 输出通道总数
s.options.numInputBusChannels = 2;

s.waitForBoot {
~dirt = SuperDirt(4, s); // 在四个通道之间声像分布
~dirt.loadSoundFiles;
~dirt.start(57120, [0, 0, 0, 0, 0, 0]);
};
s.latency = 0.3;
);

更多细节请看 SuperDirt 的文档，特别是示例文件 `superdirt_startup.scd`。

这一行设定 supercollider 输出的通道数：

s.options.numOutputBusChannels = 4; // 输出通道总数

这一行设定声像分布跨越的通道数。对于多通道声音，它一般与上面的数字相同。

~dirt = SuperDirt(4, s); // 在四个通道之间声像分布

下面这行里的每个 0 代表一个 orbit，一共给我们六个 orbit。你大概想让它们保持为 0，这样每个 orbit 都从第一个通道开始。

~dirt.start(57120, [0, 0, 0, 0, 0, 0]);

就这样！你可以把这段代码保存进你的 supercollider 启动文件（可以通过 supercollider 菜单找到），这样启动 supercollider 时就不必手动运行它了。

然后要使用它，你可以这样写：

d1 $ sound "bd*16" # pan saw

上面的代码会让底鼓在所有扬声器围成的一圈上轮转播放。如果你有四只扬声器，默认它们位于 `0`、`0.25`、`0.5` 和 `0.75`。因此 `0.125` 会落在头两只扬声器的正中间，而 `0.875` 会落在第一只和最后一只扬声器的正中间。到了 `1`，你又回到了第一只扬声器。

因为 `0` 和 `1` 是同一只扬声器，jux 函数的效果不太好（它会把原 pattern 放在位置 `0` 播放，把变换后的 pattern 放在声像位置 `1` 播放，而在多通道声音里这俩是同一只扬声器）。作为替代，你可以用 `juxBy 0.5`，或者 `jux'`——后者把一组函数分布到多通道环上。

d1 $ juxBy 0.5 rev $ sound "bd cp sn:2 mt*2" # pan saw

d1 $ jux' [id, rev] $ sound "bd cp sn:2 mt*2" # pan saw

d1 $ jux' [id, rev, fast 2] $ sound "bd cp sn:2 mt*2" # pan saw

StageMaster

StageMaster 由 Calum Gunn 制作，是一条轻量级母带处理链，供在 SuperCollider 中进行现场编码表演时使用。它为所有输出添加轻度的压缩、均衡和限幅。
