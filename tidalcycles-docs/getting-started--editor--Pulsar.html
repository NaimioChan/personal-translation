Pulsar

Pulsar 是一款开源、由社区主导的代码编辑器。它基于 Atom，是在宣布停止维护 Atom 之后启动的。Pulsar 有一个包管理器，支持社区贡献，包括我们的 Tidalcycles 包。

更新 - 2023 年 1 月 1 日：Pulsar 的包管理器现已完全支持 Tidalcycles 包。安装 Pulsar 后，就可以直接在 Pulsar 内管理 tidalcycles 的安装与更新。不再需要手动安装包。 更新 - 2023 年 7 月 7 日：macOS 上的 Pulsar 现已签名，不再需要 xattr 命令。

安装 Pulsar 和 Tidalcycles 包

  1. 从 Pulsar 下载页面下载。
  2. 启动 Pulsar 应用
  3. 打开包管理器：从菜单 > Packages > Open Package Manager
    • 选择 Install 标签页
    • 搜索 “tidalcycles”
    • 选择安装

已知问题：

  • macOS 性能问题：可以通过禁用 github 包来解决

其他问题：

  • 默认设置下的自动补全对现场编码来说可能较慢且干扰较大。可能的解决办法：
    • autocomplete-plus 包：把 “Delay Before Suggestions are Shown” 增加到 100 或 1000。
    • 禁用 autocomplete-plus 包

Discord #pulsar 频道：https://discord.com/channels/779427371270275082/1047429699346903132

手动安装 Tidalcycles 包

在大多数情况下，应避免在 Pulsar 中手动安装 tidalcycles 包。请使用 Pulsar 内的包管理器。 如果确实需要手动安装，或者通过包管理器反复安装失败，以下是适用于 macOS 和 Linux 的手动步骤。更多信息参见 pulsar-tidalcycles on github。

  • 启动 Pulsar：这会在你的主目录中创建一个隐藏文件夹 ~/.pulsar。
  • 在命令行中使用 git：（确保你已启动 Pulsar 应用）。这会把 tidalcycles 包安装到 ~/.pulsar/packages/tidalcycles/。
> cd ~/.pulsar/packages
> git clone https://github.com/tidalcycles/pulsar-tidalcycles tidalcycles

安装 tidalcycles 的 node.js 模块

前提条件：npm（node 包管理器）

安装 nvm（node 版本管理器 - 用于安装和管理 npm）

如果 npm 已经安装，可以跳过这些步骤，直接前往：“安装 tidalcycles 的 node 模块。”

推荐的 npm 安装方法是通过 node 版本管理器。

  • 选项和说明参见 NPM 文档。
  • 或直接前往 GitHub 上的 nvm 安装脚本。那里有大量细节、故障排查内容以及对不同操作系统的支持等。参见 “Installing and Updating” 一节。curl 选项不错。
  • nvm 安装脚本会向你的 shell 配置文件（.bash_profile、~/.zshrc、~/.bashrc 等）添加几行内容。这可能导致启动 shell 时有一点延迟。
  • 运行 command -v nvm 验证 nvm 是否安装成功 - 预期输出为 nvm。
  • 然后使用 nvm 安装 npm：
> nvm install node

安装 tidalcycles 的 node 模块

现在使用 npm 运行 npm install 命令。这会安装 tidalcycles 插件所需的 node 模块。

> cd ~/.pulsar/packages/tidalcycles
[userHome]/.pulsar/packages/tidalcycles > npm install

验证结果

  • node modules 目录应已存在：~/.pulsar/packages/tidalcycles/node_modules/
  • 应有三个子目录：binpack directory-tree osc-min
  • 重启 Pulsar 应用。
  • 创建一个 Tidal 文件（扩展名为 *.tidal）并运行一个命令。如果你是 Tidal 新手，更多说明请参见启动 Tidal 页面。

配置 Pulsar

Pulsar 的使用方式与 Atom 相同。要配置和修改偏好设置：

  • 主菜单：Pulsar > Preferences（会加载 Settings 标签页）
  • 选择：Packages > Community Packages > tidalcycles > Settings
  • 可选：设置你的 Sound Browser Folders - 如果你添加了 SuperCollider 中 Dirt-Samples 的完整路径，那么启动 tidal 后就可以在 Pulsar 中轻松浏览和播放这些采样。
  • macOS（可选）：禁用 GitHub 包。macOS 上存在一个已知的性能问题。参见 https://pulsar-edit.dev/

故障排除

潜在错误：

  • Couldn't find module: 'Sound.Tidal.Context' 这表示 Pulsar 无法正确加载 tidal。
  • Variable not in scope: streamSetCycle 你的 “BootTidal.hs” 文件版本与 tidal 版本不兼容。简单的修复方法是注释掉这一行：-- setCycle = streamSetCycle tidal。但最好还是解决版本兼容性问题。
