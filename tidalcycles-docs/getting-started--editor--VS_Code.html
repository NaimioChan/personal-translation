VS Code

VSCode 是微软发布的通用文本/代码编辑器，包含一些开源组件。通过一个扩展，就可以在 VS Code 编辑器中编写 Tidal Cycles 代码。根据某些统计指标，VSCode 是目前市面上最流行的代码编辑器。它高度可配置，并且可以在所有主流操作系统上运行。还有数千款插件，可以支持新的编程语言、框架、编辑 pattern 等等。

安装 VSCode

在电脑上安装 VSCode 应该很简单。前往官方网站，下载与你操作系统对应的版本即可。

Tidal Cycles 扩展

VSCode 有 Tidal Cycles 扩展。如果你想报告问题或为该扩展的开发做贡献，也可以查看它的主仓库。

安装过程很简单：

  1. 打开 VSCode，点击左侧的 Extensions 面板。
  2. 搜索 tidal，点击 install。

特色功能

VSCode 的 Tidal Cycles 扩展拥有其他编辑器扩展所没有的功能：音频文件浏览器。安装完成后，点击左侧窗格中出现的 Tidal Cycles 图标，即可查看当前 Tidal 可用的所有采样，并将它们直接预览/插入到你的代码中。

配置

请务必查看插件的 README 和配置面板，了解更多自定义/配置选项。
