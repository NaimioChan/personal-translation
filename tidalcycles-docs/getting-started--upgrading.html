升级

Tidal Cycles 是一个组合式软件。要升级它，强烈建议把所有东西随 pattern 库一起升级（文本编辑器和 SuperDirt 音频引擎也是如此）。每次发布新版 Tidal 时，通常也会跟着发布新版 SuperDirt，等等……

Ghc

如果你使用的是 Windows，则需要至少安装 9.4.2 版本的 ghc，例如通过 chocolatey。

对于 Linux 和 Mac，你不需要升级 ghc。

库

在终端窗口中用以下命令升级 tidal（Linux/MacOS/Windows）：

cabal update
cabal v1-install tidal

如果你最初是用 'cabal install' 而不是 'cabal v1-install' 安装的 tidal，可能需要改用下面的命令。不过这种方法往往不如上面的可靠。

cabal update
cabal install tidal --lib

如果搞乱了，在 Linux 和 macOS 下你可以从主文件夹删除 .ghc 和 .cabal 文件夹，然后重试。在 Windows 下也可以这样做，删除 c:\Users\<user>\AppData\Roaming\cabal，其中 <user> 是你的用户名。

编辑器插件

你的文本编辑器可能把 Tidal Cycles 插件称为扩展或包。请查看侧边栏，了解更多关于更新你常用文本编辑器的方法。

SuperDirt

要升级 SuperDirt 音色合成器/采样器，打开 SuperCollider，在交互式编辑器中粘贴以下命令。选中文字并按 Shift+Enter：

Quarks.update("SuperDirt")

你需要重新编译类库。可以简单地重启软件来完成，也可以通过顶部 Language 菜单中的 Recompile class library 项来完成。
