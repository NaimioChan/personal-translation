用和弦演奏

上面的列表可以与一个根音用 ' 组合，供 Super Dirt 中的合成器使用，如下所示：

d1 $ n "c'maj e'min" # s "supermandolin"

也可以使用按音乐会音高 C 调准的采样：

d1 $ note "c'maj e'min" # s "gtr"

在和弦后附加 ' 以及一个或多个 i 字符即可实现和弦转位。不带任何 i 的默认状态是原位。一个 i 是第一转位。第二转位如下所示：

d1 $ n "c'major7'ii" # s "supermandolin"

在和弦后附加 ' 和一个整数即可修改和弦中的音符数量。上面的和弦转位可以这样演奏 6 个音符：

d1 $ n "c'major7'6" # s "supermandolin"

在和弦后附加 'o 可以创建和弦的开放排列（Open Voicing）。这会把和弦中的第 1 和第 3 个音符（通常是根音和五音）降低一个八度：

d1 $ n "c'major7'o" # s "superpiano"

根音可以用 s 或 f 分别表示升（sharp）或降（flat）：

d1 $ n "cf'maj c'maj cs'maj" # s "supermandolin"

八度可以用数字设置。默认是 5：

d1 $ n("c4'maj c5'maj c6'maj") # s "supermandolin"

和弦可以用 |+ 运算符 pattern 化：

d1 $ n ("c e f" |+ "<'maj 'min>") # s "supermandolin"

这会给出一个等价于以下的 pattern：

d1 $ n "<[c'maj e'maj f'maj] [c'min e'min f'min]>" # s "supermandolin"
