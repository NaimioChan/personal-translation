Failures - TidalCycles (exited -1)  - Error while running 'C:\ProgramData\chocolatey\lib\TidalCycles\tools\chocolateyinstall.ps1' See log for details

或者这样：

 See log for details.

如果出现这种情况，你需要按照 Pulsar 页面上的说明手动安装 Pulsar 的 TidalCycles 插件。

  • Windows 故障排除页面已更新。安装 Haskell 遇到问题时请使用该页面。

自动安装 - Chocolatey

注意：使用 Chocolatey 的安装又可以正常工作了。

如果你之前用 chocolatey 安装过较旧版本的 Haskell，那么在完成全新安装后运行 Tidal 时可能会遇到问题。这可能是由多个 Haskell 版本并存导致的。例如，你同时有 C:\tools\ghc-8.10.7 和 C:\tools\ghc-9.6.1。要解决这个问题，你需要移除较旧的 Haskell 版本并重新安装 Tidal 包。详细步骤见 Windows Chocolatey 清理。

这种方法使用包管理器 Chocolatey，会安装你需要的所有东西，包括必要的依赖。请注意，这是一个相当庞大的安装过程，需要一些时间，但最终所有组件都会准备就绪。安装程序假定这些组件尚未安装。如果你已经有一些组件（SuperCollider、SuperDirt 等），建议对其余组件使用手动安装步骤（见下文）。

通过 Chocolatey 包管理器安装的组件：

  • git
  • SuperCollider
  • sc3-plugins
  • msys2 -（只有 choco 安装需要）
  • Haskell - ghc 与 cabal
  • SuperDirt，包含 dirt 音色库和 Vowel quark
  • Pulsar-dev 编辑器，附带 TidalCycles 插件包

安装流程

安装共 3 步。期间你可能会看到需要确认的安全弹窗。Windows 7 用户：请查看本页末尾列出的准备步骤。

I - 以管理员身份启动 powershell

  • Windows 10 - 按住 Windows 键并按 'x'，然后在弹出的菜单中选择 Windows PowerShell (admin)。
  • Windows 7 - 点击开始按钮，输入 powershell，然后单击鼠标右键并选择以管理员身份运行。

II - 安装 Chocolatey：包管理器

必须有 Chocolatey 包管理器。如果你尚未安装过它，可以通过运行这条命令获取：

Set-ExecutionPolicy Bypass -Scope Process -Force; iex ((New-Object System.Net.WebClient).DownloadString('https://chocolatey.org/install.ps1'))

III - 安装 TidalCycles

运行以下命令，用 Chocolatey 安装 Tidal Cycles：

choco install tidalcycles

注意：完整安装需要时间（30 分钟以上）。最好让它一直运行到结束，但如果它中途退出或你需要中止 - 可以再次尝试运行这条命令。Choco 会跳过任何已经完成的包依赖。

powershell 脚本结束后，你应该检查 choco 安装日志中有没有错误。
C:\ProgramData\chocolatey\logs\chocolatey.log

IV - 潜在问题与修复

  • SuperCollider quarks 安装 SuperDirt、Dirt Samples 和/或 Vowel 失败
    可以在 SuperCollider IDE 中手动安装它们。要执行的命令见下文的手动安装一节。
  • Tidal 包安装失败
    • 你可以用这条命令确认 tidal 的安装状态：cabal info tidal。如果收到 "There is no package named tidal" 的消息，说明出了问题，你需要运行这些命令。
    • 你可以尝试手动安装 Tidal 包。但在安装/重装 Tidal 包之前，建议删除（或重命名）你本地的 ghc 和 cabal 目录。它们位于你的用户 \AppData\Roaming 目录中，但也可能在 \AppData\ 下的其他目录中。
    C:\Users\<yourUser>\AppData\Roaming\ghc\
C:\Users\<yourUser>\AppData\Roaming\cabal\
C:\Users\<yourUser>\AppData\Local\ghc\
C:\Users\<yourUser>\AppData\Local\cabal\
    • 现在安装 Tidal：
    cabal update
cabal v1-install tidal
  • Pulsar 安装失败
    • 可以从 Pulsar-dev 手动下载安装程序。安装后，按照下面的步骤安装 TidalCycles 插件包。
    • 你也可以尝试只用 choco 安装 Pulsar：choco install pulsar
  • Pulsar 安装成功但没有安装 TidalCycles 插件包
    可以在 Pulsar 内手动完成。从顶部菜单打开 Package Manager，选择 Install，然后搜索 TidalCycles，并选择 install。这会把 TidalCycles 包安装进 Pulsar。更多细节请参阅 "Get a Text Editor" 一节中的 Pulsar 页面。
  • Haskell (ghc) 或 cabal 安装失败。
    你可以再次尝试运行 choco install tidalcycles 命令。或者尝试用 choco 安装 Haskell 组件： 
    choco install ghc
choco install cabal
## 如果你知道版本号，用这些命令
choco install ghc --version=9.6.1
choco install cabal --version=3.10.1.0
  • 安装程序在 SuperDirt 完成后卡住。你可以通过终止一个孤立的进程来解决。请参阅 Windows 故障排除指南。
  • 其他问题请参阅 Windows 故障排除页面。

手动安装

已经安装了部分组件的用户推荐使用这种方法。请确保下面所有组件都已安装。

Haskell

  • 安装 ghcup（Haskell 包安装器）
    • 详情见 Haskell ghcup。
    • 如需帮助，参见 YouTube - windows ghcup install。
    • 在 Windows Powershell（以管理员身份）中运行这条命令：
    Set-ExecutionPolicy Bypass -Scope Process -Force;[System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; try { Invoke-Command -ScriptBlock ([ScriptBlock]::Create((Invoke-WebRequest https://www.haskell.org/ghcup/sh/bootstrap-haskell.ps1 -UseBasicParsing))) -ArgumentList $true } catch { Write-Error $_ }
  • 这应该会安装 ghci v9.25。但 Tidal 1.9.3+ 最好搭配 ghc 9.6.1 和 cabal 3.10.1.0
  • 在 powershell（管理员）中运行这些命令，以获得正确的 ghc 和 cabal 版本：
ghcup install ghc 9.6.1
ghcup install cabal 3.10.1.0
ghcup set ghc 9.6.1
ghcup set cabal 3.10.1.0

-- Validate
ghci --version  
cabal --version

SuperCollider

  • 见 SuperCollider Downloads
  • SuperCollider Readme
    • Windows Readme

SC3 Plugins

如果你想使用 Tidal Cycles 自带的任何合成器，就需要 SC3 Plugins。文档中的大多数示例仍然可以工作，但没有它你的安装很可能不完整。你可以暂时跳过安装，之后想要时再回来装上。

SuperDirt

SuperDirt 是 Tidal 使用的音频引擎。没有它，Tidal Cycles 就不会发出任何声音，也无法通过 OSC 或 MIDI 与其他合成器通信。要安装它，打开 SuperCollider，并在交互式编辑器中运行以下命令（按 Ctrl+Return 求值）：

Quarks.checkForUpdates({Quarks.install("SuperDirt", "v1.7.4"); thisProcess.recompile()})

安装需要一点时间。你可以通过查看日志窗口来判断安装过程是否完成。它很可能会打印类似下面的内容：

Installing SuperDirt
Installing Vowel
Vowel installed
Installing Dirt-Samples
Dirt-Samples installed
SuperDirt installed
compiling class library...
...
（然后是一堆其他输出，最后会出现类似这样的内容：）
...

*** Welcome to SuperCollider 3.12.1. *** For help press Ctrl-D.

Tidal Cycles

  • 确保你的 Haskell 环境正确（见上文），并且你已安装 ghci v9.6 1 和 cabal 3.10.1.0
  • 以管理员 pattern打开 PowerShell（见上文）。
  • 输入以下命令：
cabal update
cabal v1-install tidal

务必使用 v1-install，因为 v2-install tidal 可能无法工作。最后一条命令可能需要一些时间才能完成。请耐心等待 🙂。

Pulsar

  • 见 Pulsar-edit Downloads 下载并安装。
  • 或者到左侧导航栏 Installation > Get a Text Editor 一节下的 Pulsar 页面。
  • 装好 Pulsar 后，你还需要 TidalCycles 插件。使用 Pulsar Package Manager。详情见我们的 Pulsar 页面。

获取帮助

如果安装遇到困难，可以试试以下选项：

  • 仔细重读本页，确认你遵循了所有说明。
  • 单个组件的问题 - 比如 SuperCollider 和 SuperDirt - 请查看它们在 GitHub 上的 ReadMe 页面：
    • SuperCollider Readme
    • SuperDirt Readme
  • TidalCycles Discord - Installation Help 频道
    • 试着在该频道搜索，看看别人是否遇到过你的问题
    • 发帖时务必写明细节 - 具体问题、错误消息、Windows 版本等
    • 更多关于向社区求助的信息，请查看 "how to ask" 频道
  • Forums - Tidal Club 很多聪明人都聚集在这里。
  • 别灰心！Tidal 的技术栈很复杂，但这些组件都是经过验证、健壮且稳定的。一旦全部正常工作，它几乎不需要再费心维护。

给 Windows 7 用户的说明

如果你使用的是 Windows 7，在安装其他所有东西之前需要做一些额外准备：

  1. 确保 Windows 7 已更新到最新补丁。
  2. 安装/升级到 .NET 4.5。可以在这里下载。
  3. 安装 Visual C++ 可再发行组件包。可以在这里下载。
