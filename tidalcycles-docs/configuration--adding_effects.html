添加效果器

本帮助文件基于 SuperDirt GitHub 仓库中的一个文件。想了解更多信息请参阅原版文件；如果你改进了工作流程，也欢迎把它添加到本页，帮助其他用户。为 Tidal 和 SuperDirt 添加新效果器分三步：

  1. 把需要的参数添加到 Tidal
  2. 在 SuperDirt 中添加一个模块定义，这样当参数不是 nil 时就能被找到
  3. 把 SynthDef 添加到 SuperDirt，这样它才能发声

添加一个频谱延迟

我们要给 SuperDirt 添加一个奇怪的频谱延迟。这里假设你已经有一个 SuperDirt 实例，可以在 SuperCollider 交互编辑器中通过 ~dirt 访问到它。

Tidal 侧

我们要添加两个参数：`tsdelay`（float，延迟时间）和 `xsdelay`（int，延迟结构）。运行以下 Tidal 代码（就像运行一个 tidal pattern 那样）：

let tsdelay = pF "tsdelay"
    xsdelay = pI "xsdelay"

如果你想让上面的定义在每次启动 tidal 时都自动可用，就把它们添加进你的 BootTidal.hs 启动文件。

SuperCollider 侧

为 SuperDirt 添加一个模块。这会为这些参数添加一个响应器：

(
~dirt.addModule('spectral-delay', { |dirtEvent|
	dirtEvent.sendSynth('spectral-delay' ++ ~dirt.numChannels,
		// 可选
		// 也可以省略这个参数数组不传，
		// 但写明它能让发生的事情一目了然
		[
			xsdelay: ~xsdelay,
			tsdelay: ~tsdelay,
			sustain: ~sustain,
			out: ~out
		]
	)
}, { ~tsdelay.notNil or: { ~xsdelay.notNil } }); // 只要在两个参数中至少给出了一个，就播放合成器
)

你可以在 SuperCollider 中用这条命令预览效果器的顺序：

~dirt.modules;

如果需要，你可以对效果器重新排序。例如，想让低通滤波器排在延迟之后，就运行下面这行：

~dirt.orderModules(['spectral-delay', 'hpf', 'klm']);

制作一个 SynthDef

最后一步是声明我们的频谱延迟本身，它会声明在一个经典的 SuperCollider SynthDef 中：

(

var numChannels =  ~dirt.numChannels;

SynthDef("spectral-delay" ++ numChannels, { |out, tsdelay, xsdelay = 1, sustain|

	var signal, delayTime, delays, freqs, filtered;
	var size = 16;
	var maxDelayTime = 0.2;

	signal = In.ar(out, numChannels);
	delayTime = tsdelay * maxDelayTime;
	filtered = (1..size).sum { |i|
		var filterFreq = i.linexp(1, size, 40, 17000);
		var sig = BPF.ar(signal, filterFreq, 0.005);
		// 延迟的样式由 xsdelay 按位与决定：
		DelayN.ar(sig, maxDelayTime, i & xsdelay * (1/size) * delayTime )
	};
	signal = signal * 0.2 + (filtered * 4); // 这里控制干湿比例
	ReplaceOut.ar(out, signal)

}).add;
)

最终结果

现在你应该可以在 Tidal 中写下以下代码：

d1 $ sound "can*4" # tsdelay "0 0.25 0.5 0.75 1" # xsdelay "3 124 3 12 62 2"
