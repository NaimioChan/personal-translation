延迟加载

如果你在用庞大的采样音色库，或者用的是一台老电脑，可以按这里所说的，在 SuperDirt 中开启*延迟加载*。

什么是延迟加载？

SuperDirt 不像平常那样把所有音频采样一次性载入内存，而是按请求加载音频采样。这对内存有限的人更友好。

如何开启？

要启用它，先把 SuperDirt 更新到最新一次提交（进入 downloaded-quarks/SuperDirt 文件夹然后 `git pull`），然后在 SuperDirt 启动代码里、任何 `~dirt.loadSoundFiles` 调用之前，放一句 `~dirt.doNotReadYet = true;`。

就这样。它应该能毫无问题地工作。
