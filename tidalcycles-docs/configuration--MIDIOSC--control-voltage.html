控制电压（CV）

当使用带直流输出的声卡时，Tidal 可以向模块合成器发送控制电压。一套面向 Tidal 的 CV 辅助工具发布在 SuperDirt Voltage 库中。

SuperDirt Voltage

音高（带音阶量化）

-- change notes per octave on each cycle
d1 $ pitch "0 10 8 1" # scale "<12 31 8>" # x 0

`pitch` 接受一个音符值 pattern。`scale` 设定每个八度里的音符数。pitch 和 scale 的值会被转换为 `1v/octave`。`pitch` 和 `scale` 都可以做序列化，玩出微音程的疯狂……

`glide` 接受一个强度（以半音计，相对于音阶）和一个速率（以步长计）。

-- glide to pitch
d1 $ pitch "0 10 8 1" # scale "<12 31 8>" # x 0 # glide 12 0.5

Gate

-- sequence gate inputs
d2 $ gate "0 1 0 0 1 1 1" # x 1

`gate` 接受一个 0/1 pattern，为其中的 `1` 值返回 +5v 信号。如果你需要 -5v，就用 `-1`。

电压自动化

-- create stepped automation
d3 $ volt "1 0.2 0.5 -0.2" # x 2

`volt` 让你随心所欲地为电压做序列。

AR（Attack + Release）

-- create ar
d4 $ trig "1 ~ 1 1" # ar 0 0.5 # x 3

-- patternise adsr
d5 $ trig "1 ~ 1 1" # ar (range 0.1 1 sine) "<0 0.4>" # x 4

`trig` 会创建一个触发序列，`ar` 会为每个触发生成一个新的包络。两者都可以做序列化。

在第二个例子里，随着循环推进，每个被触发包络的 attack 时间会逐渐变长。

Clock

-- clock cv output
d6 $ clock # x 5

`clock` 会输出一个 clock cv，与你的 tidal 工程的 bpm 相匹配。你还可以对它 `slow` / `fast`。
