macOS 安装（手动）

先试试一键安装脚本

想要省心、无需操作的安装，可以试试 tidal-bootstrap。如果你想手动安装 Tidal Cycles，请阅读下面的说明。

前置要求

在安装 Tidal 之前，请先确保以下软件已经安装：

  • Haskell（通过 Ghcup）
  • Atom 编辑器（如果出于某种原因你不喜欢 Atom 编辑器，请查看替代方案列表）
  • SuperCollider（选择最新版本）
  • Git

可选前置要求

以下为可选项，但强烈推荐：

  • SC3 Plugins - 如果你想使用 SuperDirt 内置的任何合成器，可能需要 SuperCollider 的 sc3-plugins。文档中的大多数示例仍然可以正常工作，所以你可以跳过这一步，之后再回来安装。

安装 TidalCycles

在终端窗口中，我们要把 GHC 的安装路径添加到一个终端每次加载时都会执行的文件里。

对于 macOS 10.14 或更早版本，终端使用 bash，因此需要修改的文件是 .bashrc：

. "$HOME/.ghcup/env"
echo '. $HOME/.ghcup/env' >> "$HOME/.bashrc"

对于 macOS 10.15 Catalina，终端使用 zsh，因此需要修改的文件是 .zshrc：

. "$HOME/.ghcup/env"
echo '. $HOME/.ghcup/env' >> "$HOME/.zshrc"

之后，我们先用 cabal 更新它的包目录，然后再安装 TidalCycles 库。以后每次想把 TidalCycles 库更新到最新版本时，也都要运行这两条命令。

cabal update
cabal install tidal --lib

如果你之前从未安装过 TidalCycles，那么 cabal install tidal --lib 这一步可能需要一些时间。命令输出的末尾应显示 Installed tidal-x.x.x（其中 x.x.x 是最新版本号），并且没有任何错误。

安装 SuperDirt

启动 SuperCollider，在编辑器窗口中粘贴下面这行代码：

Quarks.checkForUpdates({Quarks.install("SuperDirt", "v1.1.3"); thisProcess.recompile()})

点击这行代码来运行，确保光标位于这一行上，然后按住 Shift 并按 Enter。

安装需要一段时间。你会看到类似下面的输出：

Installing SuperDirt
Installing Vowel
Vowel installed
Installing Dirt-Samples
Dirt-Samples installed
SuperDirt installed
compiling class library...
...
（然后是一堆其他输出，最后会出现类似这样的内容：）
...

*** Welcome to SuperCollider 3.10.0. *** For help press Ctrl-D.

安装 Atom 扩展

启动 Atom，安装 TidalCycles 插件。你可以通过菜单 edit > settings > install 找到它，然后在搜索框中输入“tidalcycles”。

安装完成后，你需要把 tidalcycles 包的 "ghci path" 设置改为：

~/.ghcup/bin/ghci

全部安装并配置好之后，重启 atom。

安装 VS Code 扩展

启动 VS Code，在扩展市场搜索并安装 TidalCycles 扩展。你可以按照这里的说明操作，以确保你知道如何正确使用它。

测试你的安装

现在你可以第一次启动 TidalCycles 和 SuperDirt了。
