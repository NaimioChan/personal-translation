第 2 课：加载采样包

▶ 视频

这是 Tidal Club 的采样包。首先，把采样保存并解压到某个地方：

  • 找个地方建一个课程用的文件夹。可以叫它 "tidalclub"，放在桌面、文档文件夹，或任何你喜欢放东西的地方。
  • 下载上面的 samples-extra.zip 文件，把内容解压到那个文件夹（具体怎么做取决于你使用的操作系统）。

简要步骤如下：

  • 打开 SuperCollider，通过 File -> Open User Support Directory -> downloaded-quarks -> SuperDirt -> superdirt_startup.scd 打开示例启动文件
  • 把内容复制到剪贴板
  • 通过 File -> Edit startup file 打开你的 SuperCollider 启动文件
  • 把内容粘贴进去。（不要把 SuperDirt.startup 也放进去）你会看到一行 ~dirt.loadSoundFiles;，它加载默认采样。
  • 保留那一行，在下面新建一行，形如：

~dirt.loadSoundFiles("/home/alex/Documents/tidalclub/samples-extra/*");

  • 你需要修改上面这行，让它指向你系统上 samples-extra 文件夹的路径。
  • 别忘了路径末尾要有 /*，行末要有分号 ;。
  • 保存文件（File -> Save）

全部完成后，你应该可以重启 SuperCollider（可以通过 Language -> Recompile class library，或者直接关闭再重新打开 SuperCollider），让 SuperDirt 在 SuperDirt 里自动启动，并带上所有新采样。我希望这说清楚了，如果卡住了请一定告诉我！

第 3 课：迷你记谱（第一部分）

▶ 视频

好，欢迎来到迷你记谱周！这是第一个视频和练习单，探索 Tidal 迷你记谱中的音序编排。把下面的内容复制粘贴到 atom（或任何你配置好 tidal 的编辑器）里，来探索视频中的概念。

-- 迷你记谱练习单，第一份！

-- 播放一个 "kick" 音色（文件夹里的第一个）
d1 $ sound "kick"

-- 播放 "kick" 文件夹里的另一个音色（第四个，从零开始数）
d1 $ sound "kick:3"

-- 播放底鼓-军鼓循环。注意两个音色挤进了上面一个音色的时间
d1 $ sound "kick snare"

-- 加得越多走得越快 —— '循环'保持恒定
d1 $ sound "kick snare kick snare"

d1 $ sound "kick snare kick snare kurt hi lo hi lo"

-- 同样，我们可以用 : 加数字来选音色

d1 $ sound "cpu:0 cpu:2 cpu:4 cpu:6 cpu:0 cpu:2 cpu:6 cpu:8"

-- 如果都来自同一个文件夹，更简单的做法是用单独的 "n" pattern
-- 来编排音色，像这样：
d1 $ n "0 2 4 6 0 2 6 8" # sound "cpu"

-- `#` 把不同种类的 pattern 组合在一起，这里是一个 'sound'
-- pattern 和一个 'n' pattern。
-- 我们以后会回到 `#`（以及它与 '$' 的区别）！

-- 你可以用 '~' 得到一个'空'步，也就是音乐上的休止
d1 $ sound "kick snare ~ clap:4"

d1 $ n "0 2 2 ~ 8 ~ 8 ~" # sound "cpu"

-- 你也可以用 [] 把一步"拆解"成一个子序列

-- 先从一个简单的 pattern 开始
d1 $ sound "hi lo hi lo"

-- 在第三步里塞进一个两步的子序列：
d1 $ sound "hi lo [hi hi] lo"

-- 它对 'n' pattern 同样有效
d1 $ n "0 1 [5 5 5] 4" # sound "drum"

-- 你甚至可以在子序列里继续拆解一步：
d1 $ sound "hi lo [hi [hi lo hi lo]] lo"

-- 用它很容易做出好听的复合拍号：
d1 $ sound "[hi lo hi] [hi lo hi lo]"

迷你记谱还有很多可以探索的内容。玩得开心，同时也去探索 default samples 和 extra-samples 采样包里的音色（启动 SuperDirt 时，你会在 SuperCollider 的"post window"里看到它们的列表）。如果你还没有加载 extra-samples，看看前面的第 5 课。

如果你做出了喜欢的东西，一定要把它保存在安全的地方！你可能还想保留一个 pattern 的多个版本，不仅保存最终 pattern，还保存你是怎么一步步做出它的…… 现场编码的音乐很多时候都在修改过程里，而不只是最终结果！

记得经常去看看这一课的论坛页面，那里有大量补充信息。

第 4 课：迷你记谱（第二部分）

▶ 视频

好，我们再深入一点迷你记谱！这是一个视频。我尝试在一"课"里塞进更多东西，于是视频相应地更长了…… 不过我觉得到最后我有点力不从心了！我在字幕里加了一两处澄清。我还尝试了可视化，有些地方比其他地方更有帮助……

这是一份供动手探索的练习单。一定要动手改一改来检验你的假设，努力搞清楚正在发生什么——有任何不清楚的地方请尽管提问。我在最后放了一些任务…… 根据论坛讨论，我们还会补充更多创造性任务。

-- 加速、重复与减速

-- 用 "*" 加速一步
-- https://www.youtube.com/watch?v=h_f11uago28&t=105s

-- 让一步变'快'，使它在自己的一步之内自我重复：
d1 $ sound "hi lo*3"

-- 对子序列也有效
d1 $ sound "hi [hi lo]*2"

-- 对 'n' pattern 也是
d1 $ n "[0 ~ 0] 2 [0 9]*2 2" # sound "cpu"

-- 我们试着把一个 pattern 加速一倍半：
d1 $ sound "bd [sd hc]*1.5"

-- 它有两步，所以加速 1.5 倍就得到三步。
-- 第一次你得到 "bd [sd hc sd]"，第二次得到 "bd [hc sd hc]"

-- 用 "/" 减慢一步
-- https://www.youtube.com/watch?v=h_f11uago28&t=346s

-- 让 'lo' 每两个循环才响一次：
d1 $ sound "hi lo/2"

-- 让 'lo' 每三个循环才响一次：
d1 $ sound "hi lo/3"

-- 减慢一个子序列，让每个循环只响一步：
d1 $ sound "clap [numbers:0 numbers:1 numbers:2]/3"

-- 通过减慢 3 倍，每个循环从一个六步序列里取两步：
d1 $ n "0 0 0 [0 1 3 4 5 6]/3" # sound "cpu2"

-- 用古怪的比率减速，制造怪异的效果！
d1 $ n "0 0 0 [0 1 3 4 5 6]/2.5" # sound "cpu2"

-- 用 "!" 重复一步
-- https://www.youtube.com/watch?v=h_f11uago28&t=275s

-- 如果你想在同一节拍层级上重复步骤，可以用 ! ..
-- 所以这个：
d1 $ sound "hi lo!3"

-- 等同于这个：
d1 $ sound "hi lo lo lo"

-- 单独用一个 ! 表示重复一次。所以这个：
d1 $ sound "hi lo !"

-- 等同于这个：
d1 $ sound "hi lo lo"

-- 子序列也可以重复，所以这两句相同：
d1 $ sound "bd bd [hi lo] !"

d1 $ sound "bd bd [hi lo] [hi lo]"

-- 用 "," 实现复调
-- https://www.youtube.com/watch?v=h_f11uago28&t=668s

-- 用 ',' 你可以让多个子序列同时进行。
-- 当有可能多个音符同时响起时，
-- 这就叫音乐上的"复调"（polyphony）

-- 这就像让多个通道 d1 和 d2 同时活跃：
d1 $ sound "bd sd"

d2 $ sound "rs rs rs"

-- .. 但用 ","" 你可以把它们放进同一个 pattern。它听起来
-- 和上面两个 pattern 同时播放一样：
d1 $ sound "[bd sd, rs rs rs]"

-- 各子序列对齐以填满同一个循环。
-- 所以 "[a b, c d e]" 像这样对齐：
-- |a--b--|
-- |c-d-e-|

-- 默认采样里有一套 'alphabet' 采样可以帮助
-- 理解这个！
d1 $ n "[0 1, 2 3 4]" # sound "alphabet"

-- 还有一种让子序列对齐的方法，用 { } 代替 [ ]：
d1 $ n "{0 1, 2 3 4}" # sound "alphabet"

-- 视频讲解：https://www.youtube.com/watch?v=h_f11uago28&t=822s

-- 它的前三个循环是这样的：
-- |ababab|
-- |cdecde|

-- 发生了什么？Tidal 先像之前那样，把第一个子序列 "0 1"
-- 对齐填满循环。但随后它把其他子序列*按步*适配到它上面。
-- 于是步对齐了，但循环没有对齐！在三个循环的空间里，
-- "a b" 重复了三次，"c d e" 重复了两次

-- [ ] 记谱创造出所谓的音乐'复合节奏'（polyrhythm）——
-- 多个节奏发生在同一个时间窗内，例如：
d1 $ n "[0 5 2 ~, 0 3 4*2 0 3]" # sound "cpu2"

-- { } 记谱创造出'复合拍号'（polymetre）——不同长度的
-- 拍号彼此错进错出，例如：
d1 $ n "{0 5 2 ~, 0 3 4*2 0 3}" # sound "cpu2"

-- 我（Alex）总是把复合节奏和复合拍号搞混，
-- 为了省事干脆把两者都叫复合节奏..

-- 采用线性'钢琴卷帘'式记谱系统的'传统'音乐软件
-- 很难处理复合节奏/拍号，但在 Tidal 里这真的很容易，
-- 而且探索起来*非常*好玩。

-- 用 "." 划分节拍韵律（feet）
-- https://www.youtube.com/watch?v=h_f11uago28&t=988s

-- 你可以用 "." '标记出'规则的节拍'韵步'

-- 所以这个：
d1 $ sound "bd sd . mt ht lt . arpy arpy:4 . snare clap:4 bd"

-- 正是在说这个：
d1 $ sound "[bd sd] [mt ht lt] [arpy arpy:4] [snare clap:4 bd]"

-- 所以 "." 把一个序列切分成等长的几部分

-- 要在 "." 记谱_内部_拆解一步，仍然可以
-- 使用 [] 等：
d1 $ sound "bd sd . mt [ht mt] lt . arpy [arpy:4 arpy:5] . snare clap:4 bd"

-- 这等同于：
d1 $ sound "[bd sd] [mt [ht mt] lt] [arpy [arpy:4 arpy:5]] [snare clap:4 bd]"

-- 用 "<>" 实现每循环一步
-- https://www.youtube.com/watch?v=h_f11uago28&t=1166s

-- 常常每个循环从子序列里挑一步会很好听。
-- 一种做法是：
d1 $ sound "hi [arpy arpy:1 arpy:2 arpy:3]/4"

-- 用 < > 也能做同样的事 —— 它每循环挑一步，
-- 你不必操心里面有多少步：
d1 $ sound "hi <arpy arpy:1 arpy:2 arpy:3>"

-- 复习任务

-- 依次复制下面的每个 pattern，然后用上面介绍的 "<>"、
-- "!"、"[]" 和/或 "." 修改它们，让它们更短。

d1 $ sound "kick snare snare"

d1 $ sound "kick [snare snare]"

d1 $ sound "kick snare kick snare kick snare"

d1 $ n "0 [1 2 3]/3" # sound "cpu2"

d1 $ n "[0 0 2] [4 5 6 7] [4 1] [0 3 0 3]" # sound "cpu2"

d1 $ sound "kick snare kick snare kick snare clap"

d1 $ sound "[kick snare kick snare kick snare] clap"

d1 $ sound "bd sd sd sd bd [sd sd sd]"

-- 尽量把代码写短，不知为何被叫做 "golfing"（高尔夫）。
-- 作为一种练习挺有用，但有时候更长的代码
-- 其实更容易理解和修改！

记得经常去看看这一课的论坛页面，那里有大量补充信息。

第 2 周

第 1 课：初识效果器

▶ 视频

好，该开始探索一些效果器了！在这个视频里，我介绍 SuperDirt 提供的众多效果器中的一部分，并开始讲解 Tidal 如何把两个或更多这样的 pattern 合并成一个。我们以后还会回到这个话题……

如果你发现有些效果器不起作用，请检查你是否在 SuperCollider 里正确安装了 sc3-plugins。

-- Tidal 有很多效果器可以用来改变声音的样子。

-- vowel 是一个添加元音声的滤波器
-- 试试 a、e、i、o 和 u

d1 $ n "0 1 0 [2 4] 2 4 1*2 3" # s "cpu"

d1 $ n "0 1 0 [2 4] 2 ~ 1*2 3" # s "cpu" # vowel "a"

d1 $ n "0 1 0 [2 4] 2 ~ 1*2 3" # s "cpu" # vowel "o"

-- 我们也可以用迷你记谱来创造效果器序列：

d1 $ n "0 1 0 [2 4] 2 ~ 1*2 3" # s "cpu" # vowel "a o e"

-- Tidal 会尽力把各个 pattern 彼此映射。

-- 你可以加一个非元音字母来暂停元音效果

d1 $ n "0 1 0 [2 4] 2 ~ 1*2 3" # s "cpu" # vowel "a p"

-- 'squiz' 是一个不错的失真效果器
d1 $ n "0 1 0 [2 4] 2 ~ 1*2 3" # s "cpu" # squiz "4 1 0 3"

-- 用 '#' 时结构来自左边 —— 试着交换一下参数

d1 $ squiz "4 1 0 3" # n "0 1 0 [2 4] 2 ~ 1*2 3" # s "cpu"

-- 现在每个循环只有四个音色，因为最左边的 'squiz'
-- pattern 里有四个

-- 我们以后会学到更多关于 pattern 之间如何匹配的知识！

-- 'gain' 改变不同音色的音量

d1 $ sound "kick kick snare snare" # gain "1 0.7 0.6 0.5"

d1 $ sound "[hh*16, kick:8 snare:4 [~ kick:8] snare]" # gain "[1 1.2]*8"

-- speed 可以用来改变采样音高
-- （也可以用 'note' 做到，但我们以后再看）

-- speed 改变播放速度，
-- 比如 2 = 以两倍速播放采样 —— 相当于音符升一个八度

d1 $ sound "numbers:1 numbers:2 numbers:3 numbers:4" # speed "1 1.5 2 0.5"

-- 或者我们可以把 pattern 交给 speed 参数

d1 $ speed "1*2 2*2 4*6" # sound "jungbass:6"

-- pan 让我们制造立体声效果 —— 0 = 左，0.5 = 中，1 = 右

d1 $ sound "numbers:1 numbers:2 numbers:3 numbers:4" # pan "0 0.5 1"

-- shape 添加失真（但要小心 —— 它也会让声音大很多）

d1 $ sound "kurt:4 kurt:4"

d1 $ sound "kurt:4(3,8)" # shape "0 0.98" # gain "0.7"

第 2 课：操纵时间

▶ 视频

大家好，这是新的一期视频，探索操纵时间的各种方法。我很喜欢这一课！这是配套的练习单：

-- 该看看时间了

-- "Music is the Time of Numbers"

-- setcps - 改变全局速度

-- 我们同时跑两个 pattern：
d1 $ n "0 2 [3 5] [4 7]" # sound "cpu"

d2 $ n "0(3,8) 8*8" # sound "cpu2"
  # squiz 5

-- 改变 cps（每秒循环数）会改变一切
setcps 0.7

setcps 0.3

-- 作为效果器的时间（！）

-- 你也可以把 cps 作为效果器设置：
d2 $ n "0(3,8) 8*8" # sound "cpu2"
  # squiz 5
  # cps 0.5

-- 不过它仍然是全局的 —— 在一个 pattern 上设置它
-- 会在所有地方生效

-- 不过，你可以给它编排 pattern：
d2 $ n "0(3,8) 8*8" # sound "cpu2"
  # squiz 5
  # cps "0.5 1"

-- 用这种方式你真的可以随意摆弄时间！
d2 $ n "0 [~ 1] 2*2 3 4*3 5 ~ 7" # sound "cpu2"
    # cps "<0.5 2> [1 0.75] <2 1>"

-- 继续之前先重置一下..
hush

setcps 0.6

-- 'fast' 和 'slow' 函数

-- 你可以用 "fast" 和 "slow" 加速/减速
-- 单个 pattern（或其中一部分）


d1 $ slow 2 $ n "0 2 [3 5] [4 7]" # sound "cpu"

d1 $ fast 2 $ n "0 2 [3 5] [4 7]" # sound "cpu"

-- 你也可以给这个速度因子编排 pattern：
d1 $ slow "0.5 1" $ n "0 2 [3 5] [4 7]" # sound "cpu"

d1 $ slow "0.5 <1 2>" $ n "0 2 [3 5] [4 7]" # sound "cpu"

-- 用这种方式给时间编排 pattern 时，你是在
-- 不同版本的、以不同速度运行的 pattern 之间切换。

-- 我们已经学到了足够多，可以把几种简单的
-- 操纵混合起来，创造出变化丰富的 pattern
d1 $ slow "0.5 <1 2>" $
  n "{0 2 [3 5] [4 <7 6>], 0*2 3*3 0}" # sound "cpu"
  # squiz "<8 1 2>"

-- 注意 'speed' 效果器改变的是每个采样的播放速率，
-- 但不改变 pattern 整体的快慢
d1 $ slow "0.5 <1 2>" $
    n "{0 2 [3 5] [4 <7 6>], 0*2 3*3 0}" # sound "cpu"
    # squiz "<8 1 2>"
    # speed 2

-- 我发现把东西稍微加快一点总是更好听。
-- 你的体验也许不同 :）
setcps 0.7

第 3 课：用算术组合 pattern

▶ 视频

如约而至，这是另一个视频。说实话我现在累极了，所以尽管录了几遍，视频还是有点"非线性"——`hurry` 函数的讲解被插在探索合并同类型控制参数 pattern 的不同方法的中间。

这里是一份练习单，希望能帮你理清头绪。带图示的参考资料很快奉上：

-- 好，那么当我们把一个'控制参数'pattern（比如 n、
-- sound、speed 或 squiz）指定不止一次会怎样？

-- 从好用的 'numbers' 音色开始：
d1 $ n "0 1 ~ 2" # sound "numbers"

-- 再放一次那个 'n'，但换一个数字：
d1 $ n "0 1 ~ 2" # sound "numbers" # n "4"

-- 所以.. 你能听出来节奏结构仍然来自左边，
-- 但所有值都被右边的替换了。这就是 `#` 做的事！

-- 我们把右边的 pattern 弄复杂一点：
d1 $ n "0 1 ~ 2" # sound "numbers" # n "4 5"

-- 现在 0 和 1 被替换成了 4，2 被替换成了 5。

-- 这是因为 tidal 根据它们在循环中的位置替你匹配。
-- 0 和 1 在前半部分开始，所以被替换成 '4'。
-- 2 在后半部分开始，所以被替换成 '5'。

-- # 其实是 '|>' 的简写。这一族运算符还有：

-- |> 是结构取左，值取右
-- <| 是值取左，结构取右
-- |< 是结构取左，值取左
-- >| 是结构取右，值取右
-- |<| 是值取右，结构取两侧
-- |>| 是值取左，结构取两侧

-- < 指向值从哪边来，| 落在节奏结构来的那一边。

-- 全部取自左边：
d1 $ n "0 1 2 3" # sound "numbers" |< n "4 5"

-- 全部取自右边：
d1 $ n "0 1 2 3" # sound "numbers" >| n "4 5"

-- 节奏结构取左，值取右：
d1 $ n "0 1 2 3" # sound "numbers" |> n "4 5"

-- 值取左，节奏结构取右：
d1 $ n "0 1 2 3" # sound "numbers" <| n "4 5"

-- 值取左，节奏结构取两侧：
d1 $ n "0 1 2 3" # sound "numbers" |<| n "4 5"

-- 上面 |<| 的用法听起来和 |< 一样，因为节奏
-- 结构对得上。

-- 这样就不同了：
d1 $ n "0 1 2" # sound "numbers" |>| n "4 5"

-- 一些陷阱！

-- 即使你从一边取走一切，另一边仍然得有东西
-- 对得上..
-- 所以这不出声：
d1 $ n "~" # sound "numbers" >| n "4 5"

-- 这里只有 '4' 出声：
d1 $ n "0 ~" # sound "numbers" >| n "4 5"

-- 多数时候你可以忘掉这一切，只用
-- |> ，以及它的别名 # 。

-- 不过，你还能做别的事情！

-- 不从一边取值，而是把值加起来，用 '+'
-- 代替 '>' 或 '<'。

-- 这个：
d1 $ n "0 1 2 3" # sound "numbers" |+ n "4 5"

-- 相当于：
d1 $ n "4 5 7 8" # sound "numbers"

-- 这个：
d1 $ n "0 1 2 3" # sound "numbers" +| n "4 5"

-- 相当于：
d1 $ n "4 7" # sound "numbers"

-- 这是因为节奏来自右边，来自 "4 5"，
-- 所以我们从它出发。4 的开始与 0 匹配，
-- 5 的开始与 2 匹配，加起来就得到 4+0=4，
-- 5+2 = 7。

-- 这些都会变得复杂，尤其是当你处理
-- 步数不同的 pattern 时..

d1 $ n "0 1 2 3" # sound "numbers" |+ n "4 5 6"

-- 但别太担心。你只需要说出你想把什么
-- 加在一起，让 Tidal 替你算！

-- 好了，数字玩够了，我们用一些有趣的
-- pattern 来实践一下。

-- 这里用 |+| 取两侧的结构，把 'n' pattern
-- 加在一起。右边用 < > 迷你记谱语法
-- 每个循环挑一个不同的子序列。
-- 结果是一个有趣的、更长的 pattern：

d1 $ n "0 1 2 [3 5]" # sound "cpu"
  |+| n "<[4 5 3 2] [5 4 3] [6 5]>"
  # squiz 2

-- 我只是加了一点 squiz 让它好听。

-- 这是一个更简单的例子，在三个 12 音八度之间循环，
-- 每循环一个：
d1 $ n "7 5 [2 7] 0" # sound "superpiano"
  |+ n "<-12 0 12>"

-- 其实可以在这些数字 pattern_变成控制参数 pattern 之前_
-- 就对它们应用这些运算，像这样：
d1 $ n ("7 5 [2 7] 0" |+ "<-12 0 12>") # sound "superpiano"

-- 你得用括号确保两个 pattern 先相加，
-- 再传给 'n'。

-- 说清楚一点，这是一个数字 pattern：
-- "7 5 [2 7] 0"

-- 这是一个控制参数 pattern，因为 'n' 把数字变成
-- 合成器控制参数 pattern：
-- n "7 5 [2 7] 0"

-- 这一切对效果器同样有效：
d1 $ n "0(5,8) [4 1]" # sound "drum"
  # squiz "0 2 5"
  |+ squiz "<0 2 3>"

-- 或者，你也可以把数字 pattern 相加，而不是控制参数
-- pattern。这与上面相同：
d1 $ n "0(5,8) [4 1]" # sound "drum"
  # squiz ("0 2 5" |+ "<0 2 3>")

-- 看看你更喜欢哪种写法！

-- 'saw' 是一个在一个循环内从 0 慢慢移动到 1 的 pattern。
-- 这里我把它减慢，让它持续 4 个循环，
-- 在此期间逐渐加快速度：
d1 $ n "[0 4 2] [4 1] 3 [2 0] 3 [3 1] 4 4" # sound "cpu"
  # squiz 3
  # speed "1 [2 3] 3"
  |+ speed (slow 4 saw)

第 1 课：探索 "every"，"$" 的含义

▶ 视频

在开始处理更长的采样之前，先讲讲 every 函数。它是函数如何工作的一个清晰例子，也让我们有机会开始体会括号和 $ 是怎么回事。我还讲了如何把效果器当作函数来添加。

我在损坏的字幕文件上遇到了很多麻烦，就不细说了…… 而且直到剪完字幕我才发现，我那位竖着的灰色长方形朋友决定入镜陪我。它们并不太碍事，所以我决定不重录，希望它们不会太让人分心！

-- every

-- 'every' 是 Tidal 函数家族的一员，它把另一个
-- 函数作为自己的输入之一。

-- 假设我们有一个这样的简单 pattern：
d1 $ sound "bd sd ~ cp"

-- ……我们想让它像这样加速：
d1 $ fast 2 $ sound "bd sd ~ cp"

-- ……但每三个循环只有一次。

-- 我们可以这样用 'every' 来实现：
d1 $ every 3 (fast 2) $ sound "bd sd ~ cp"

-- 你可以把它读作"每第 3 个循环，让
-- 'sound "bd sd ~ cp"' 快一倍。"

-- 我们稍后会拆解它，弄清楚为什么有时用 ()，
-- 有时用 '$'。先看更多使用 'every' 的
-- 实际例子。

-- 任何以单个 pattern 为输入（并返回变换后版本作输出）
-- 的函数都可以配合 every 使用。例如，
-- 我们可以用 'hurry' 代替 fast：
d1 $ every 3 (hurry 2) $ sound "bd sd [~ bd] [cp bd*2]"

-- 或者用 'rev'：
d1 $ every 3 (rev) $ sound "bd sd [~ bd] [cp bd*2]"

-- 因为 'rev' 是单个词，我们其实不必
-- 把它放进括号：
d1 $ every 3 rev $ sound "bd sd [~ bd] [cp bd*2]"

-- 这里有个把效果器当函数用的小技巧..
-- 看看这个：
d1 $ sound "bd sd [~ bd] [cp bd*2]"
   # squiz "5"

-- 我们可以把 '# speed 5' 这部分当作一个函数。
-- 想想看，它对一个 pattern 做了点什么，就像 'fast 2' 一样。

-- 那么.. 这样行得通吗？
d1 $ every 3 (# squiz 5) $ sound "bd sd [~ bd] [cp bd*2]"

-- 行得通！

-- 你还可以叠加多个 'every' 操纵，给它们的首个输入
-- 不同的周期，制造更长形态的变化：
d1 $ every 3 (# squiz 5) $ sound "bd sd [~ bd] [cp bd*2]"

d1 $ every 2 (hurry 2) $ every 3 (# squiz 5) $ sound "bd sd [~ bd] [cp bd*2]"

-- 继续叠加..
d1 $ every 4 rev $ every 2 (hurry 2) $ every 3 (# squiz 5)
   $ sound "bd sd [~ bd] [cp bd*2]"

-- 在 Tidal 里，函数所操纵的 pattern 一般是它的
-- 最后一个输入，这让这样的函数很容易'串联起来'。

-- 好，如约回到最初那个简单的例子：
d1 $ every 3 (fast 2) $ sound "bd sd ~ cp"

-- 我们过一遍 every 的三个'输入'（有时也叫
-- '参数'或'实参'）。

-- [a] 3 - 函数多久应用一次
-- [b] fast 2 - 被应用的函数
-- [c] sound "bd sd ~ cp" - 应用到的 pattern。

-- 再看一眼这个 pattern，你能看到输入
-- 以三种不同的方式给出：
d1 $ every 3 (fast 2) $ sound "bd sd ~ cp"

-- '3' 单独站着。它是一个单独的数字，tidal 毫无
-- 困难地知道它是单独一个输入。

-- 'fast 2' 在括号里 '(fast 2)'。于是在被作为
-- 第二个输入传给 'every' _之前_，'fast' 和数字 '2'
-- 先被组合成一个函数。

-- 'sound "bd sd ~ cp"' 前面有 $。我们_本来也
-- 可以_这样写：
d1 $ every 3 (fast 2) (sound "bd sd ~ cp")

-- 这样完全没问题，但 '$' 做的是同一类事。它把它
-- 左边的东西，作为一个参数传给它右边的函数。
-- '$' 的优先级极低，这意味着它右边的所有内容
-- 会先被计算出来，再传给左边。
d1 $ every 3 (fast 2) $ sound "bd sd ~ cp"

-- 这免去了你围绕函数最后一个输入配对
-- ( 和 ) 的麻烦。它只对最后一个输入有效，
-- 所以很遗憾这样_不_起作用

d1 $ every 3 $ fast 2 $ sound "bd sd ~ cp"

-- 上面会先算出 'fast 2 $ sound "bd sd ~ cp"'，
-- 然后试图把它作为第二个参数传给 'every'，
-- 这对 tidal 来说讲不通，所以它会返回错误。

-- 注意当 Tidal 报错时，如果已经有一个 pattern 在运行，
-- 它会继续运行那个 pattern。如果你正在观众面前
-- 现场编码，你大概不希望一个错误导致静音！

第 3 课：slice 与 splice

▶ 视频

我们来看看用 slice 和 splice 对循环采样做"切拍"的一种方法：

setcps 0.6

-- 先原样听听
d1 $ splice 8 "0 1 2 3 4 5 6 7" $ sound "break:4"

-- 现在换一个更混乱的 pattern
d1 $ splice 8 "6 1 [2 3] ~ 4 1 6*2 7" $ sound "break:4"

-- 试着改变 cps，听听不同速度下的效果

-- 试着操纵切片 pattern
d1 $ splice 8 (fast "1 [0.5 0.75]" "6 1 [2 3] ~ 4 1 6*2 7")
   $ sound "break:4"

-- 现在把上面的一切换用 'slice' 而不是 'splice' 再试一遍。
-- slice _不会_做把声音拼接上移/下移以贴合步子的
-- 音高调整。

-- 这里我从原本 4/4 的循环里取六片，做出
-- 一个 3/4 的华尔兹
d1 $ splice 8 ("0 1 2 3 4 5") $ sound "break:4" # gain 1.1

第 4 课：chop 与 striate

▶ 视频

接着第 3 周第 3 课，我们用 chop 和 striate 看"切拍"的另一种方法，为这一周处理较长采样的工作收尾。这是练习单：

-- 我们拿一个好听的 break 来：
once $ sound "break:8"

-- 我们可以用 'begin' 和 'end' 只播放声音的一部分，
-- 这里是它的最后四分之一：
d1 $ sound "break:8*4" # begin 0.75 # end 1

-- 我们也可以用 'unit "c"' 改变 'speed' 的行为，
-- 让它根据 cps 调整播放速度
d1 $ sound "break:8" # speed 1 # unit "c" # begin 0.75 # end 1

-- 我们播放四个这样的片段来填满循环
d1 $ sound "break:8*4" # speed 1 # unit "c" # begin 0.75 # end 1

-- 然后调整 cps 听听变化，它会完美贴合 cps
setcps 0.8

-- 通常我不会手动用 'unit'、'begin' 和 'end'。
-- 我会用上一课的 splice / slice，或者用 'chop'
-- 把声音切成碎片，并用 'loopAt' 以循环为单位
-- 设定循环长度
d1 $ loopAt 2 $ chop 4 $ sound "break:8"

-- 上面听起来相当连贯，但它其实被切成了四片。
-- 把切碎的片段倒过来放就能听出来：
d1 $ loopAt 2 $ rev $ chop 4 $ sound "break:8"

-- 如果我们把 pattern 减慢，就能分别听到每一片：
d1 $ slow 2 $ loopAt 2 $ chop 4 $ sound "break:8"

-- 换一个采样：
d1 $ slow 2 $ loopAt 2 $ chop 4 $ sound "break:9"

-- 现在如果我们把两个 break 放进序列会怎样？
d1 $ slow 2 $ loopAt 2 $ chop 4 $ sound "break:8 break:9"

-- 用 'chop'，它会先播放 break:8 的所有片段，
-- 再播放 'break:9' 的所有片段。

-- 如果我们把 'chop' 换成它的朋友 'striate'，
-- 两个 break 的片段就会交织起来：
d1 $ slow 2 $ loopAt 2 $ striate 4 $ sound "break:8 break:9"

-- 好玩地调一调那个 striate 值：
d1 $ slow 2 $ loopAt 2 $ striate 32 $ sound "break:8 break:9"

-- 如果你用 striate 多次使用*同一个*循环，
-- 它有点像在拉伸它：
d1 $ slow 4 $ loopAt 1 $ striate 4 $ sound "break:1*4"

-- 它平时听起来是这样的：
once $ sound "break:1"

-- 'bev' 是一个更长的采样..
d1 $ loopAt 16 $ striate 32 $ sound "bev"

d1 $ slow 4 $ jux rev $ loopAt 16 $ striate 128 $ sound "bev*4"

记得经常去看看这一课的论坛页面，那里有大量补充信息。

第 4 周

第 1 课：连续 pattern 与随机函数

▶ 视频

好，我们来看一些连续函数！这是个大话题（所以视频比较长，一部分也因为我玩二值 pattern 跑偏了），但它有助于这一周稍后深入随机性。这个视频基本上全是关于波形的（除了那个二值跑偏）。

-- '连续函数'提供不同种类的波形。
-- 这里有展示正弦、方波、三角波和锯齿波的漂亮图示：
-- https://en.wikipedia.org/wiki/Waveform

-- 这是正弦波形应用到采样播放速度上的声音：
d1 $ sound "bd*32" # speed sine

-- 应用到声像上：
d1 $ sound "bd*32" # pan sine

-- 应用到波形失真上（会很响）：
d1 $ sound "bd*32" # shape sine

-- 你可以像操纵其他种类的 pattern 一样操纵连续 pattern，
-- 比如减慢：
d1 $ sound "bd*32" # shape (slow 2 sine)

-- 这些波形都在 0 和 1 之间移动。所以在最低点，
-- sine 是 0，最高点是 1。接近 0 的值用在 'speed'
-- 上会有问题，因为声音可能被放得极慢，
-- 要很久才能播完。

-- 为了绕开这一点，你可以给 sine 加一个数：
d1 $ sound "bd*32" # speed (sine + 0.5)

-- 或者使用 'range' 函数：
d1 $ sound "bd*32" # speed (range 0.5 1.5 sine)

-- 来听听三角波、锯齿波和方波：
d1 $ sound "bd*32" # speed (range 0.5 1.5 tri)

d1 $ sound "bd*32" # speed (range 0.5 1.5 saw)

d1 $ sound "bd*32" # speed (range 0.5 1.5 square)

-- 如果把连续 pattern 放在左边会怎样？
-- 记住用 '#' 时，节奏结构来自左边。试试：
d1 $ speed (range 0.5 1.5 sine) # sound "bd"

-- 静音！为什么？
-- 因为连续函数其实不包含任何事件。
-- 它们的值连续变化，但不触发任何东西。

-- 如果我们想在连续 pattern 里触发事件，就得
-- 显式地从它采样取值。一种办法是用
-- 'segment' 函数：
d1 $ speed (segment 32 $ range 0.5 2.5 sine) # sound "bd"

-- 上面每个循环采样 32 个值，由它们生成
-- 离散事件。

-- 另一种办法是用 'binary' 或 'boolean' pattern，
-- 搭配 'struct' 函数：
d1 $ speed (struct "t(3,8)" $ slow 2 $ range 0.5 2.5 sine)
  # sound "bd"

-- 't' 代表 'true'（真）。于是这个欧几里得节奏被用来
-- 从连续的 sine 函数里采样事件。我们会在另一个
-- 视频里回到二值 pattern。

-- 你还可以把连续 pattern 相加或相乘：
d1 $ sound "bd*32" # speed (range 0.5 2.5 (sine + (slow 2 saw)))

d1 $ sound "bd*32" # speed (range 0.5 2.5 (sine * (slow 2 saw)))

-- 我在上面的 pattern 里减慢了 'saw'，于是你得到
-- 一个在两个循环内音高逐渐上升的正弦波。

-- 在 Tidal 里，随机函数往往也是连续的。
-- 例如 rand 像 sine、saw 等一样工作，但返回
-- 随机值：
d1 $ sound "bd(5,8)" # speed (range 1 3 rand)

-- perlin 类似，但返回 'perlin 噪声'。在 Tidal 里，
-- 这意味着 pattern 在每个循环之间平滑地
-- 在随机值之间过渡：
d1 $ sound "bd(5,8)" # speed (range 1 3 perlin)

-- 配上一点混响试试：
d1 $ sound "bd(7,16)"
   # room 0.7
   # sz (range 0.4 1 $ slow 4 perlin)

第 2 课：随机马拉松（第一部分）

▶ 视频

接着波形（包括随机波形）那一课，这是两部分中的第一部分，看一大堆随机函数…… 开头先坐在扶手椅上对算法音乐中随机性的本质做一点哲学思考。

我先录了视频后做的练习单。我决定了以后应该反过来做，视频会更有条理，所以可能某个时候会重录。一如既往，告诉我你的想法！我觉得我讲得有点太快，而且到这里我开始自由地混入前面几课讲过的技巧，你可能已经忘了，所以如果你希望我把这一课或其他任何课里的内容再讲一遍，请（虚拟地）举手。你这是在帮大家！

-- 我们从上一课认识的 'rand' 波形开始：

d1 $ n "1*8" # sound "drum"
  # speed (range 1 8 rand)

-- 'resetCycles' 把循环计数重置为 '0'，
-- 就像你刚启动 Tidal 一样：
resetCycles

-- 如果在上面的 pattern 运行时执行 resetCycles，
-- 你会注意到随机流也被重置了。每次启动
-- 或重置 Tidal，你都会得到同样的'随机'数字。

-- 你可以把 rand 应用到任何数值效果器上，
-- 但可能需要调整范围。例如低通滤波器
-- 会切掉高于给定值的频率：
d1 $ sound "drum:5(5,8,<0 4>)"
   # lpf (range 200 8000 rand)
   # lpq 0.2

-- 'irand' 与 'rand' 类似，但从 0 到（不包括）给定数字
-- 生成整数，也就是整数。这对 'n' 和 'note'
-- 控制参数特别有用：

d1 $ sound "rash(5,8)" # n (irand 32)
   # room 0.3 # sz 0.5

-- 在迷你记谱里也有几种做随机事情的
-- 办法。要在子序列之间随机选择，
-- 在它们之间放一个 |（竖线）

-- 这个序列的第二步是从四个子序列中
-- 随机挑选：
d1 $ n "0 [0|1*3|2*8|3 4 5] 2 3" # sound "cpu"
   # speed 1.5

-- 另外，? 会随机'丢弃'一个事件。在下面，
-- 第二步有 50% 的概率被播放。
d1 $ sound "kick clap? kick snare"
  # delay 0.3 # delaytime (1/3) # delayfb 0.8 # speed 1.5

-- （我加了一点回声延迟让它更酷。delay 是
-- 被延迟的音量，delaytime 是回声的长度，
-- delayfb 是延迟的反馈量）

-- 你可以用小数（浮点）数字调整 ? 生效的
-- 概率。例如，让那个拍手有 80% 的概率
-- 被丢弃（也就是 20% 的概率播放）
d1 $ sound "kick clap?0.8 kick snare"
  # speed 1.5

-- 如果你把 ? 应用到子序列上，它会对子序列里的
-- 每个值分别生效
d1 $ sound "kick [clap:4 off clap:5]? kick snare"
  # speed 1.5

d1 $ sound "bd*8? clap:4"

-- 好，接下来是函数，从 scramble 开始。scramble
-- 接受一个数字，是把一个 pattern 等分成几份的份数。
-- 然后它会随机播放这些部分。
d1 $ scramble 4 $ n "0 1 2 3 4 5 6 7" # sound "arpy"
   # room 0.3 # sz 0.8

-- 上面被分成四份，里面共有八个事件，
-- 所以它们成对播放。这意味着 0 后面总是
-- 跟着 1，2 后面总是跟着 3，以此类推。

-- shuffle 接受与 scramble 相同的参数，听起来
-- 非常相似。你能听出区别吗？
d1 $ shuffle 4 $ n "0 1 2 3 4 5 6 7" # sound "arpy"
  # room 0.3 # sz 0.8

-- scramble 随机抽取部分，而 shuffle 以随机顺序
-- 播放各部分。区别在于用 shuffle 时，
-- 每个循环里每个部分你都会恰好听到一次。
-- 用 scramble 的话，有（很小的）概率你只会
-- 听到一个部分被播放四次。


-- 如果同时播放一个拍手来标记循环开始，
-- 你也许更容易听出这一点。这样你就能
-- 听出各部分在循环内没有重复。
d1 $ shuffle 4 $ n "0 1 2 3 4 5 6 7" # sound "arpy"
  # room 0.3 # sz 0.8

d2 $ sound "clap"

-- "choose" 函数用于在单个值之间挑选。
-- 它产生一个连续的流，没有结构，
-- 所以下面这样不会产生任何事件：
d1 $ sound (choose ["bd", "arpy", "snare"])

-- 你需要提供一些结构，用类似 'segment' 的函数，
-- 这里它每个循环取 8 个值：
d1 $ sound (segment 8 $ choose ["bd", "arpy", "snare"])

-- 或者 'struct'，它按二值 pattern 取值：
d1 $ sound (struct "t t ~ t" $ choose ["bd", "arpy", "kick"])

d1 $ sound (struct "t(5,8)" $ choose ["bd", "arpy", "kick"])

-- 或者把它与一个*确实*有结构的 pattern 组合：
d1 $ squiz "0*2 4 2 5 0 6*2 4 7"
  # sound (choose ["bd", "arpy", "kick"])

-- 另一个'陷阱'——choose 的参数是一个值的列表，
-- *不是*pattern，所以通常不能在那里用迷你记谱。

-- 这样*不*行。
d1 $ squiz "0*2 4 2 5 0 6*2 4 7"
  # sound (choose ["bd*5", "arpy*2", "kick clap"])

-- 我会试着在未来的 tidal 版本里修掉这个！有一个
-- 变通办法，就是用 'innerJoin' 函数。这样你就可以
-- 在 pattern 之间选择了：
d1 $ squiz "0*2 4 2 5 0 6*2 4 7"
  # sound (innerJoin $ choose ["bd*5", "arpy*2", "kick clap"])

-- choose 可以和任何参数一起用。

-- 例如：
d1 $ sound "clap:4(3,8)"
  # speed (choose [2,5,0.5])

-- 下面这个例子和上面的有点不同，因为
-- 每个循环只挑选一次新值：
d1 $ sound "clap:4(3,8)"
  # speed "[2|5|0.5]"

-- 用 'segment' 把 choose 按一个循环切分，
-- 也能从 choose 得到同样的行为：
d1 $ sound "clap:4(3,8)"
  # speed (segment 1 $ choose [2,5,0.5])

-- 'wchoose' 函数类似 'choose'，但你可以给
-- 每个选项一个'权重'。比如权重为 '4' 的选项
-- 被选中的可能性是权重 '2' 的两倍：
d1 $ sound "clap*4" # speed (wchoose [(2, 4), (-2, 2)])

-- 上面的拍手会以 '2' 或 '-2' 的速度播放。
-- 你能听出负速度让声音倒着播放！
-- '2' 的权重是 '4'，'-2' 的权重是
-- '2'，所以播放的可能性减半。

-- 这里我把权重设置为：很多底鼓、偶尔拍手、
-- 更少军鼓：
d1 $ squiz "1 4*8 8*2 0*3"
  # sound (wchoose [("bd", 8), ("snare", 0.5), ("clap", 1)])

-- 好了，还有一件事！在 Tidal 里，随机性是
-- "决定论"的。在某个循环时间点上，你总会得到
-- 同一个数字。我们在本课开头见过，用 resetCycles。
-- 它重置循环计数，就像你刚启动 Tidal。
-- 然后你能听到'随机'数字是一样的。

-- 这可能导致意想不到的结果。
-- 听听这个：
d1 $ sound "clap*2" # speed (range 0.1 2 rand) # pan rand

-- 你能听出在左声道，声音的 'speed' 总是低，
-- 而当它移到右边时总是高。怪事！这是因为
-- 同一个'随机'数字流同时被用于 speed 和 pan，
-- 所以它们拿到相同的数字，看起来在相互作用。

-- 这可以是好事！但如果你不想要这种效果，可以通过
-- 操纵其中一个随机 pattern 的时间线来避开。
-- 例如：
d1 $ sound "clap*2" # speed (range 0.1 2 rand)
  # pan (slow 1.001 rand)

-- 我只把那个 'rand' 减慢了一丁点，但这就足以
-- 得到完全不同的数字…… 所以现在左边和右边
-- 出现低速的可能性一样了。

第 3 课：随机马拉松（第二部分）

▶ 视频

-- randcat

-- randcat 是 cat 的变体，cat 我们其实还没看过，
-- 所以先从它开始..
d1 $ sound (cat ["kick snare:4 [~ kick] snare:5", "kick snare:4 . hc(5,8)"])

-- 你能听出 cat '拼接'pattern —— 它按顺序
-- 一个接一个地播放它们。

-- 而 randcat 则以随机顺序播放它们：
d1 $ sound (randcat ["kick snare:4 [~ kick] snare:5", "kick snare:4 . hc(5,8)"])

-- 你想给它多少个备选 pattern 都行：
d1 $ sound (randcat ["kick snare:4 [~ kick] snare:5",
                     "kick snare:4 . hc(5,8)",
                     "snare:3(9,16)"
                    ]
           )

-- 你可以用它随机化 sound 之外的控制参数 pattern，
-- 比如 vowel 效果器：
d1 $ vowel (randcat ["a e*2 i o", "e o u", "o*8"])
   # sound ("kick snare:4 clap:4")


-- wrandcat 之于 randcat，正如 wchoose 之于 choose。
-- 也就是说，你可以给出各选项的相对概率：
d1 $ sound (wrandcat [("bd sn:4(3,8)", 1),
                      ("arpy clap", 0.5),
                      ("cpu(5,8)", 0.25)
                     ]
           )

-- stripe 是个奇怪的家伙。我们先用 cpu2 采样
-- 做一个节奏：
d1 $ n "0 4*2 ~ 4 2 4 5 ~" # sound "cpu2"
  # squiz 2

-- 'fast 2' 会把它压缩进两个循环：
d1 $ fast 2 $ n "0 4*2 ~ 4 2 4 5 ~" # sound "cpu2"
  # squiz 2

-- stripe 类似，但各循环是随机的时长，
-- 虽然仍然贴合循环：
d1 $ stripe 2 $ n "0 4*2 ~ 4 2 4 5 ~" # sound "cpu2"
  # squiz 2

-- 它听起来是随机的，但对照一个规整的拍手，
-- 你能听出每隔一次重复仍然与循环完美对齐：
d2 $ sound "clap:4"

-- degrade - 还记得上一个视频里的 ? 迷你记谱
-- 修饰符吗？它随机丢弃事件：
d1 $ sound "bd*8?"

-- Degrade 是做同样事情的一个函数：
d1 $ degrade $ sound "bd*8"

-- 就像这样：
d1 $ sound "bd*8?0.6"

-- 你可以用 'degradeBy' 指定概率。比如，
-- 给每个事件 60% 的概率被'丢失'：
d1 $ degradeBy 0.6 $ sound "bd*8"

-- 'sometimes' 把一个函数应用到一个 pattern 上，
-- 但只偶尔应用。让我们偶尔加快一下这个节奏：
d1 $ sometimes (hurry 2) $ n "0 ~ 3 1 5 2 ~ 5" # sound "cpu"

-- 这是原始的，相比之下相当无聊：
d1 $ n "0 ~ 3 1 5 2 ~ 5" # sound "cpu"

-- 你也可以用它来应用效果器。
d1 $ sometimes (# crush 4) $ n "0 ~ 3 1 5 2 ~ 5" # sound "cpu"

-- 还有 'sometimesBy' 变体，用来指定概率：
d1 $ sometimesBy 0.3 (# crush 4) $ n "0 ~ 3 1 5 2 ~ 5" # sound "cpu"

-- 不同概率有一些别名：

{-
sometimes = sometimesBy 0.5
often = sometimesBy 0.75
rarely = sometimesBy 0.25
almostNever = sometimesBy 0.1
almostAlways = sometimesBy 0.9
-}

-- 所以你可以这样：
d1 $ rarely (# crush 4) $ n "0 ~ 3 1 5 2 ~ 5" # sound "cpu"

-- somecycles 与 sometimes 类似，但一次作用于
-- 整个循环，而不是单个事件：
d1 $ somecycles (hurry 2) $ n "0 ~ 3 1 5 2 ~ 5" # sound "cpu"
  # speed 1.5

-- 同样，也有 'somecyclesBy' 变体，可以明确
-- 那个概率。要在 90% 的时间应用 squiz：
d1 $ somecyclesBy 0.9 (# squiz 4) $ n "0 ~ 3 1 5 2 ~ 5" # sound "cpu"
  # speed 1.5

-- randslice 有点像几课前认识的 'slice'：
d1 $ slice 4 "0 1 2 3" $ sound "break:8"

-- 不过它不是接收切片 pattern，而是随机挑选切片。
-- 所以要随机播放这个 break 的四分之一：
d1 $ randslice 4 $ sound "break:8"

-- 我们可以用 'loopAt' 把它们贴合到一个循环，
-- 就像之前用 'chop' 和 'striate' 时看到的：
d1 $ loopAt 1 $ randslice 4 $ sound "break:8*4"

-- 我们也可以通过给 'slice' 或 'splice' 一个随机 pattern
-- 来做类似的事：
d1 $ splice 4 (segment 4 $ irand 4) $ sound "break:8"
