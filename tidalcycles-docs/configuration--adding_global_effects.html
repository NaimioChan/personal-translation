添加全局效果器

本帮助文件基于 SuperDirt GitHub 仓库中的一个文件。想了解更多信息请参阅原版文件；如果你改进了工作流程，也欢迎把它添加到本页，帮助其他用户。

注意：请确保你已经启动了 SuperCollider，并且 SuperDirt 正在运行。要启动它，你可以在交互文本编辑器中输入 SuperDirt.start。

我们想给每个 `orbit` 添加一个新的全局效果器。全局效果器和『效果器』完全是两回事。全局效果器始终存在于信号链上，等着你去调它们的参数。效果器则相反，可以专门为某个 pattern 单独使用和调用，它们是按需实例化的。

我们可以在 SuperCollider 中用这条命令查看每个 `orbit` 上声明的所有全局效果器：

// 这些是每个 orbit 上的全局效果器
~dirt.orbits.do { |x| x.globalEffects.postln }

低通滤波器

我们要给每个 `orbit` 添加一个全局低通滤波器。首先需要为它生成一个 `SynthDef`：

构建一个 SynthDef

(
var numChannels = ~dirt.numChannels;
(1..SuperDirt.maxSampleNumChannels).do { |numChannels|
	SynthDef("dirt_global_lpf" ++ numChannels, { |dryBus, effectBus, gate = 1, cutoffFreq = 440|
		var signal = In.ar(dryBus, numChannels);

		var rq;
		signal = signal.asArray.collect { |sig|
			rq = 1/LFNoise2.kr(0.1).exprange(10, 20);
			RLPF.ar(sig, cutoffFreq, rq).tanh;
		};
		signal = signal * EnvGen.kr(Env.asr, gate, doneAction:2);
		DirtPause.ar(signal.sum, graceTime:4);

		Out.ar(effectBus, signal)
	}, [\ir, \ir]).add;
};
)

添加到 orbit 上

我们需要把这个 `SynthDef` 添加到每个 SuperDirt orbit 上：

(
~dirt.orbits.do { |x|
	x.globalEffects = x.globalEffects
		.addFirst(GlobalDirtEffect(\dirt_global_lpf, [\cutoffFreq]))

	x.initNodeTree;
};
)

~dirt.orbits.do { |x| x.globalEffects.postln; " ----------".postln; }

Tidal 侧

把下面这行添加到你的 Tidal 启动文件中：

let cutoffFreq = pF "cutoffFreq"

现在你就可以尽情把玩你的新效果器了：

cps (40/120)
d1 $ sound "[sn [sn sn]][sn [sn sn*3]][sn [sn*5 sn]][bd bd]" # cutoffFreq "220 880"
