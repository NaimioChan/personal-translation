朋友与相关项目

下面列出的是与 TidalCycles 相关的项目，无论是与它对接、启发过它，还是受它启发。

（要查看一份列出所有现场编码环境的长名单，见 all things livecoding 名单。）

移植与解析器 - Uzulangs

TidalCycles 衍生出一个被称为 uzulangs 的现场编码环境家族，它们遵循 tidal 的时间 pattern 模型，并常常采用/扩展其节奏迷你记谱。例如：

  • Estuary 是一个通过现场编码进行协作与学习的平台，在网页浏览器中托管一系列环境，包括“minitidal”——一个 tidal 的解析器
  • Strudel 是 TidalCycles 在 Javascript 上的高级移植，可在网页浏览器中运行
  • Kidal 是 Tidal 在 Kotlin 上的移植
  • Tranquility 是 Tidal 在 Lua 上的移植
  • Modal 是 Tidal 在 Lua 上的又一个移植，专注于扩展迷你记谱并在嵌入式环境中运行。
  • Vortex 是 Tidal 在 Python 上的移植

编辑器

  • Extramuros，浏览器中语言中立、共享缓冲的联网现场编码系统（Estuary 的前身）
  • Feedforward，开发中的一个奇特的基于终端的编辑器
  • Siren - 面向 TidalCycles 和 SuperCollider 的 tracker 界面
  • Troop，一款实时协作工具，让多台计算机可以在同一文档内进行小组现场编码。支持一系列现场编码语言，包括 Tidal

编辑器插件

  • Emacs
  • Sublime text
  • vim
  • VS Code

合成器与采样器

  • Dirt - 原始的“经典” dirt，用 c 实现
  • SuperDirt - SuperCollider 重写版，推荐一般使用（除非在网页浏览器中运行）
  • webdirt - javascript 重写版，estuary 的一部分

SuperCollider（或 SuperDirt）附加组件

  • StageMaster - 供在 SuperCollider 中现场演出时使用的轻量母带链

视觉系统

  • Didactic pattern visualizer - 用 Processing 编写的声音 pattern 可视化器
  • p5jsDirt - 与 p5.js 的集成

同步 / 对接

  • Carabiner，用于与 Link 协议桥接
  • ESPGrid，为包括 supercollider、foxdot 以及 tidal 在内的现场编码环境设计的同步
  • Node.js interface，用于在 javascript 与 tidal 之间传递消息

受 Tidal 启发的系统

  • Krill - 一个受 tidal 启发的基于 javascript 的现场编码环境
  • tidal.pegjs - 是用 PEG.js 编写的、面向 TidalCycles 迷你记谱的解析表达式文法。该 PEG 的目标是轻松地把 Tidal 风格迷你记谱的字符串翻译成带注解的 JavaScript 数据结构，供序列编排使用。可与 Gibber 和 Hydra 搭配使用！

启发 Tidal 的系统

  • Bol processor - 基于作曲文法的算法音乐系统，源自对塔布拉节奏符号记谱的研究
  • Euterpea 是一个嵌入在 Haskell 编程语言中的跨平台、面向特定领域的计算机音乐语言
  • Douglas Repetto 的节拍旋转实验，例如 MEAPsoft 中的 rotcomposer
