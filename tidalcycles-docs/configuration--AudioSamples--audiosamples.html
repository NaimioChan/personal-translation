自定义采样

在 Tidal Cycles 中添加并使用自己的自定义采样相对容易。你其实并不是把采样添加到 Tidal，而是把它们添加进 SuperCollider 和 SuperDirt quark。要做到这一点，你需要自定义你的 SuperDirt 启动代码。

SuperDirt

打开 SuperCollider 时，你需要的不是平常那句 `SuperDirt.start` 代码，而是一段更长的脚本，告诉 SuperDirt 去哪里找你的采样。启动脚本看起来像这样：

(
s.waitForBoot {
    ~dirt = SuperDirt(2, s); // two output channels
    ~dirt.loadSoundFiles("/Users/myUserName/Dirt/samples/*"); // specify sample folder to load
    s.sync; // wait for supercollider to finish booting up
    ~dirt.start(57120, 0 ! 12); // start superdirt, listening on port 57120, create twelve orbits each sending audio to channel 0
};
);

要运行上面的代码，把光标放在代码块内的任意位置，然后按 `Ctrl+Enter`（MacOS 上是 `Command+Enter`）来求值整个代码块。

上面的代码会启动 SuperCollider 服务器，然后带着位于 `/Users/myUserName/Dirt/samples` 的采样启动 SuperDirt。在 SuperDirt 代码仓库里可以找到一份更完整的启动文件。

Windows 路径

如果你在 Windows 上运行，需要转义 Windows 路径里的反斜杠字符：

~dirt.loadSoundFiles("c:\\Users\\myUserName\\Dirt\\samples\\*")

指定多个文件夹

如果你的采样分散在许多文件夹里，可以把它们全部导入：

(
s.waitForBoot {
    ~dirt = SuperDirt(2, s); // two output channels

        
// load samples from multiple folders:
    ~dirt.loadSoundFiles("/Users/myUserName/Dirt/samples/*"); 
    ~dirt.loadSoundFiles("/Users/myUserName/sounds/*"); 
    ~dirt.loadSoundFiles("/Users/myUserName/recordings/chaska-sessions/*");
    ~dirt.loadSoundFiles("/Users/myUserName/recordings/super-duper-experiments/*"); 

    
s.sync; // wait for supercollider to finish booting up
    ~dirt.start(57120, [0, 0]); // start superdirt, listening on port 57120, create two orbits each sending audio to channel 0
};
);

文件夹结构

在上面的例子里，我们导入了路径 `/Users/myUserName/Dirt/samples` 下的一个文件夹。为了让 SuperDirt 认出 Tidal 发来的音色名，`/Users/myUserName/Dirt/samples` 文件夹下需要有按音色名组织的子文件夹，每个音色名文件夹下再放采样文件：

Users/
|-- myUserName/
    |-- Dirt/
        |-- samples/
            |-- myBass/
            |   |-- bass1.wav
            |   |-- bass2.wav
            |   |-- bass3.wav
            |-- hits/
            |   |-- hit1.wav
            |   |-- hit2.wav
            |   |-- hit3.wav
            |-- field/
            |   |-- bridge.wav
            |   |-- mountains1.wav
            |   |-- mountains2.wav
            |   |-- plains.wav
            |   |-- river.wav

Tidal 代码

有了上面的文件夹结构，现在你就可以在 Tidal pattern 里使用 `myBass`、`hits` 和 `field` 这几个音色了：

d1 $ s "mybass hits*4" # n (slow 2 $ run 3)
d2 $ n "<0 2 1>" # s "field" # cut 1
