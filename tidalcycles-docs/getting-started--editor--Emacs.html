Emacs

Emacs 是一款历史悠久的经典程序员编辑器。Emacs 远不止是一个文本编辑器，但它有刚上手时有点难用的名声。曾有一段时间，Emacs 是唯一能与 Tidal 配合的编辑器，不过如果你觉得没把握，可以使用 Pulsar（参见侧边栏的 Pulsar 页面）。

Emacs 有 Tidal 和 SuperCollider 的包。学习 Emacs 一开始可能让人望而生畏，但也是一段非常有回报的经历。Emacs 实际上是一个完整的计算环境，用这个软件你几乎可以做任何能想到的事（收发邮件、读书、编辑代码、浏览电脑上的文件、聊天等等）。Emacs 的核心是定制：有一个成熟的编程语言（Emacs-Lisp）供你使用。

根据你的操作系统，安装方式可能大不相同。请查看适合你系统的推荐发行版。安装完成后，如果你想让事情更简单，一定要看看最流行的几个配置框架之一：

  • Doom Emacs
  • Spacemacs

Linux

安装 Emacs

Debian / Ubuntu / Mint

你可以使用原生包管理器 apt 安装 Emacs 及其 Haskell Mode：

sudo apt-get install emacs24 haskell-mode

Arch / Manjaro

你可以使用 pacman 包管理器安装 Emacs：

sudo pacman –S emacs

手动安装

编辑你的 .emacs 文件

要安装 Emacs 的 Tidal 界面，你需要编辑主文件夹中一个名为 .emacs 的配置文件。如果它不存在，就创建它。然后，添加以下内容，把 ~/projects/tidal 替换为 tidal.el 文件所在的位置：

(add-to-list 'load-path "~/projects/tidal")
(require 'haskell-mode)
(require 'tidal)

下载 tidal.el

tidal.el 文件可以在这里找到：tidal.el。

使用 Spacemacs

如果你使用的是 Emacs 的 Spacemacs 定制发行版，应该可以使用由 rbino 为它制作的 layer。如果你使用 develop 分支，只需把 tidalcycles 添加到 dotspacemacs-configuration-layers，它应该开箱即用。

按 SPC f e R 重新加载配置，或重启 Spacemacs，让更改生效。

每当你打开 .tidal 文件时，Tidal 模式会自动加载。按 Ctrl/Cmd+Return 求值一行。探索其他快捷键，或按自己的喜好映射它们。

使用 Doom Emacs

编辑你的 packages.el 文件。按 space f p，选择 packages.el。添加以下一行：(package! tidal)。在终端中，进入 ~/.emacs.d/bin 并运行 ./doom sync。等待更新过程完成。重新启动 Doom Emacs。

按 space f p 并选择 config.el，编辑你的 BootTidal.hs 路径。在该文件任意位置，输入以下一行：

(setq tidal-boot-script-path "~/.cabal/share/x86_64-osx-ghc-8.8.4/tidal-1.7.4/BootTidal.hs")

你可能想使用一个特定的 BootTidal.hs 文件。指向你喜欢的那一个。我选择的是随 Tidal 安装的默认 BootTidal.hs 文件。

现在你可以打开任何想要的 .tidal 文件。如果没有显示语法高亮，运行 tidal-mode。用 C-c C-s 启动 Haskell，用 C-c C-e 求值区域。

使用 MELPA 包

Tidal Cycles 在 Emacs 中的集成提供了 MELPA 包。 你必须首先确保机器上已安装 MELPA（说明；基本上是在你的 init.el 或 .emacs 文件中加入第一个代码片段， 然后在 Emacs 中执行 M-x package-refresh-contents。

如果运行上一个命令后无法验证签名，这里有一些keyring 更新信息）然后只需运行：

M-x package-install

接着：

tidal

这个扩展为 *.tidal 文件提供了一个主模式。安装好包后，只需打开一个 Tidal 脚本，按 C-c C-s 在 Emacs 中启动 Tidal，然后按 C-return 运行光标所在语句。

MacOS

安装 Emacs

使用 MacOS 可用的某个发行版安装 Emacs，并让它出现在你的应用程序文件夹中：

brew install emacs --cocoa
brew linkapps

配置 Emacs

现在是配置 Emacs 的时候了。执行以下操作：

mkdir ~/tidal
cd ~/tidal
curl -L https://codeberg.org/uzu/tidal/raw/branch/main/tidal.el > tidal.el

在主文件夹中创建一个名为 .emacs 的文件（除非它已经存在）。用文本编辑器打开该文件并插入以下几行：

(require 'package)
(add-to-list 'package-archives 
   '("marmalade" .
     "http://marmalade-repo.org/packages/"))
(package-initialize)
(setq load-path (cons "~/tidal/" load-path))
(require 'tidal)
(setq tidal-interpreter "/usr/local/bin/ghci")

以上内容确保 Emacs 能访问 marmalade 仓库中的扩展（尤其是 Haskell-Mode），确保你之前下载的 tidal.el 文件被加载，并且 Tidal 能找到 Haskell 解释器。

如果你已经通过 Haskell Platform 安装程序安装了 Haskell，请对上面做如下修改：

(setq tidal-interpreter "/usr/bin/ghci")

现在启动 Emacs（如果已经加载，请重启以确保 读取了 .emacs），它应该在你的 Applications 文件夹中（如果你从 终端启动它，可能会加载一个旧版本）。Emacs 启动后，按 alt-x（即按住 alt 再按 x）并输入：

package-refresh-contents

然后再按一次 alt-x 并输入：

package-install

然后输入：

haskell-mode

Windows

安装 Emacs

下载 Emacs for Windows。解压 .zip 文件，然后直接从 bin\\runemacs.exe 运行 Emacs。你需要找到或创建位于你主目录中的 .emacs 文件。这是 Emacs 的配置文件。具体位置可能因 Emacs 的安装/运行方式而异。

如果你双击运行 runemacs.exe，那么你的 .emacs 文件 很可能位于 C:\\Users\\(username)\\AppData\\Roaming\\。 如果你把 runemacs.exe 所在文件夹加入 PATH 并从 命令提示符运行它，那么你的 .emacs 文件很可能位于 c:\\users\\(username)\\。请注意你是如何启动 runemacs.exe 的，如果 .emacs 尚不存在，请在相应的文件夹中创建它。

另外，你也可以尝试让 Emacs 替你自动创建 .emacs 文件，方法是在某个 Emacs 菜单中修改一项配置设置并保存你的配置。

安装 Haskell Mode

Haskell-mode 需要安装在 Emacs 中。在 Windows 上最简单的方法是添加 Marmalade 包管理器。安装 haskell-mode 还有其他方法（详见这里），但 Marmalade 可能最简单。在你的 .emacs 文件中加入以下内容来启用 Marmalade：

(require 'package)
(add-to-list 'package-archives
            '("marmalade" . "http://marmalade-repo.org/packages/"))
(package-initialize)

输入 M-x 然后输入 package-refresh-contents 来刷新包索引。

通过 M-x 然后输入 package-install，再输入 haskell-mode 来安装 haskell-mode。

在 Windows 上，M-x 组合键是 Alt-x。

安装 Tidal 模式

在 .emacs 中加入以下几行来启用 Tidal：

(add-to-list 'load-path "c:/projects/tidal")
(require 'haskell-mode)
(require 'tidal)

把 c:/projects/tidal 替换为包含 tidal.el 的文件夹的路径。此文件可以从 Tidal 仓库获得，在这里。使用它最简单的方法是 克隆 Tidal 仓库，然后修改 .emacs 文件以使用你克隆到的 路径：

git clone https://codeberg.org/uzu/tidal c:\tidal

如果你也这样做，你的 .emacs 配置文件应该是这样的：

(add-to-list 'load-path "c:/tidal")
(require 'haskell-mode)
(require 'tidal)

用 Emacs 测试 Tidal

现在你应该已经安装了 Emacs 的 Tidal 模式。打开一个新文件，给它取个随意的名字，比如 helloworld.tidal。文件打开后，你还需要启动 Tidal。按 Ctrl-C 然后按 Ctrl-S 启动。输入下面这行并按 Ctrl+Enter 求值这个单行块，检查 Emacs 和 Tidal 是否正常工作：

d1 $ brak $ sound "bd sn/2"

Ctrl+Enter：求值单行。

Ctrl+C Ctrl+E：求值多行。

更多快捷键请查看 tidal.el 文件内部。

高级用户：请注意 BootTidal.hs 文件的位置在 tidal.el 文件中被定义为：

ghc-pkg describe $(ghc-pkg latest tidal) | grep data-dir | cut -f2 -d ' '

你可能需要覆盖它，例如使用以下设置（把路径替换为 BootTidal.hs 文件的实际位置）。

(setq tidal-boot-script-path "~/.cabal/share/x86_64-linux-ghc-8.6.5/tidal-1.4.8/BootTidal.hs")

只有当你想调整 superdirtTarget（例如在远程主机上使用 SuperCollider）时，才需要真正修改这个文件。
