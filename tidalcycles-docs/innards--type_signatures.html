类型签名

什么是类型签名？

在 Haskell（Tidal 所栖身的语言）里，类型签名告诉你一个值或函数是什么种类的东西。它们对于弄清一个函数期望你给它什么、以及它会返回什么，特别有用。

你可以用 :t 查出函数的类型，例如想查 rev 的类型签名，可以在编辑器里输入 :t rev 并求值。你会在输出窗口看到：

rev :: Pattern a -> Pattern a

这相当简单，它告诉你该函数接受一个 pattern 作为输入，并返回一个 pattern 作为输出。我们再通过 :t fast 看看 fast 函数：

fast :: Pattern Time -> Pattern a -> Pattern a

这稍微复杂一点，这里有三个 pattern。最后一个是输出，前面的都是输入。所以 fast 接受一个时间 pattern、另一个 pattern，并返回一个 pattern。这也说得通：第一个参数说明它在时间上应该多快，而且可以用 pattern 表达。第二个参数是将要被加速的 pattern，但它没有说明是什么类型的 pattern，只写了 Pattern a，输出也一样。我们之前在 rev 那里见过同样的 Pattern a 类型。这是什么意思？

其实 Pattern a 里的 a 是不受约束的——它可以是任何你想要的东西。所以 rev 函数可以作用于任何类型的 pattern。这是因为 rev 不处理任何具体的值，它只操作时间。

所以这里的 a 是一种通配符，同时用在 rev 的输入和输出上。这意味着你可以给它任何内容的 pattern，但如果你给它整数 pattern，就保证会拿回整数 pattern。所以你可以把那个 a 换成另一种类型，但前提是把它的所有出现都换成同一个类型。

更进一步

一个更复杂的例子是 every：

every :: Pattern Int -> (Pattern a -> Pattern a) -> Pattern a -> Pattern a

现在，every 接受三个参数：一个_整数个循环数_、一个_应用于 pattern 的函数_，以及_pattern 本身_。我们可以看到第一个参数是整数 pattern，没问题。第二个参数比较奇怪——(Pattern a -> Pattern a)。这就是作为参数的函数的表示方式——用括号包起来。由此可以看出第二个参数是一个函数，它接受任意类型的 pattern 作为输入，并返回相同类型的 pattern 作为输出。如果回头看 rev 的类型签名，很明显我们可以把它作为这第二个参数，因为类型匹配。的确，例如 every 3 rev (s "bd sn") 这样的写法相当常见。

希望这能给你一些读懂类型签名的启发。即使不读文档，它们对于理解如何使用函数也非常有用。
