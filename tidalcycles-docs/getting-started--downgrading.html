降级

有时，你可能想回到 Tidal 的旧版本。可以使用 ghc-pkg 命令来实现。在终端中（Windows 用户使用 Powershell）输入以下命令来降级你的 Tidal 安装。

列出所有已安装的版本

此命令会列出你已安装的 Tidal 版本。如果不止一个，将使用最新的版本：

ghc-pkg list tidal

卸载某个版本

要卸载某个版本，可以这样做，例如：

ghc-pkg unregister tidal-1.0.6

对每个版本重复此操作，直到最新的版本是你想要的那个。

选择一个特定版本

如果你想要的版本尚未安装，可以选择所需的版本：

cabal install tidal-0.9.10
