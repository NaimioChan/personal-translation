Linux 安装

自动安装

有一些用户自制的工具可以安装 Tidalcycles 全套组件。请务必看看以下方案：

  • Ansible 方案：Ubuntu / debian / Mint（以及大多数基于 debian 的发行版）
    • 功能齐全的方案，包括 SuperCollider、Haskell、Tidal、SuperDirt、代码编辑器和包依赖
    • 有自定义选项，包括添加额外的采样来源和总线通道设置
    • 更多信息参见 Tidal Club 帖子

手动安装

一套完整的 Tidal Cycles 系统需要几个必备组件：

  • Git
  • Haskell
  • SuperCollider
  • SuperDirt
  • 一个文本编辑器（例如 Pulsar、VS Code、vim/neovim、emacs 等）

大多数现代发行版都会通过其包管理器提供其中全部或大部分组件，方便安装。

以下说明给出了针对不同发行版家族的具体命令。它们标记为：

  • debian - debian 发行版家族包括 debian、各种 \*buntu、Mint、pop!_OS 等
  • arch - Arch 发行版家族包括 Arch Linux、Manjaro 等
  • fedora - fedora 发行版（已测试），可能也适用于其他基于 RPM 的发行版（如 RedHat、OpenSUSE、Rocky Linux 等）
  • all - 无论是哪个发行版，所有人都应运行此命令

选择与你正在运行的发行版相匹配的命令。

配置用户

1. 把你的用户加入 audio 组

all

sudo usermod -a -G audio $USER

2. 注销并重新登录使其生效。可以用下面的命令检查是否成功：

all

groups | grep audio

包预配置

1. 安装依赖

debian

sudo apt update; sudo apt install git jackd2 qjackctl zlib1g-dev gcc g++ ghc cabal-install

arch

sudo pacman -Syu; sudo pacman -S git jack2 qjackctl

fedora

sudo dnf install git-core qjackctl gcc-c++ cabal-install

2. 移除冲突

arch

sudo pacman -R lib32-mesa-demos mesa-demos

SuperCollider 安装

1. 安装 SuperCollider 和 SC3-Plugins

debian

sudo apt install supercollider sc3-{plugins,plugins-language,plugins-server}

arch

sudo pacman -S supercollider sc3-plugins

fedora

sudo dnf install supercollider

fedora 的 sc3-plugins 由第三方仓库提供（你可以选择让它保持启用）

sudo dnf copr enable ycollet/audinux; sudo dnf install supercollider-sc3-plugins; sudo dnf copr disable ycollet/audinux;

SuperDirt 安装

SuperDirt 是 SuperCollider 的一个插件或 “Quark”，既是 TidalCycles 的音频引擎，也提供默认的采样集。

1. 获取最新 SuperDirt 发布的版本号（也可以通过查看 github 页面来完成）

all

git ls-remote https://codeberg.org/musikinformatik/SuperDirt.git | grep tags | tail -n1 | awk -F/ '{print $NF}'

2. 安装 SuperDirt，如有需要请更新版本号。完成后按 Ctrl+d 退出 sclang

all

2.a. 启动 sclang shell

sclang

2.b. 粘贴这一行并按回车（等待一下，它立即返回，但在后台处理）。

Quarks.checkForUpdates({Quarks.install("SuperDirt", "v1.7.4"); thisProcess.recompile()})

Tidal 安装

1. 安装 tidal

arch 是唯一支持通过其核心包管理器安装 Tidal 的发行版，其他发行版需要使用 Haskell 包/环境管理器 cabal (>=3.0.0.0)

arch

sudo pacman -S ghc ghc-libs haskell-{tidal,bifunctors,colour,hosc,mwc-random,network,primitive,random,vector,microspec}

其他所有发行版

cabal update; cabal install tidal --lib

cabal 是出了名的善变。如果出于某种原因它失败了，你可以通过重命名你的 ~/.ghc 和 ~/.cabal 文件夹并重新运行上述命令来安全地重置环境。*

选择文本编辑器

TidalCycles 得到众多文本编辑器的支持，你需要其中之一才能开始：

  • Pulsar（曾为 Atom）
  • VS Code
  • vim/neovim
  • emacs

……以及更多。
