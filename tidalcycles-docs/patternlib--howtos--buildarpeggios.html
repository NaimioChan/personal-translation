构建琶音

本页将教你用不同手法上手编写琶音。这是以更直观的方式学习 Tidal Cycles 的好途径。

从音符构建琶音

先从一个简单的音符序列开始：

d1 $ n "c a f e"
  # sound "supermandolin"

现在，每个循环演奏一个音符：

d1 $ n "<c a f e>"
  # sound "supermandolin"

在此基础上，加上一份该序列的副本，在时间和音高上错开：

d1 $ n (off 0.125 (|+ 7) "<c a f e>")
  # sound "supermandolin"

给原序列增加一些结构：

d1 $ n (off 0.125 (|+ 7)  "<c*2 a(3,8) f(3,8,2) e*2>")
  # sound "supermandolin"
  # legato 2

在一只音箱里反向播放：

d1 $ jux rev $ n (off 0.125 (|+ 7)  "<c*2 a(3,8) f(3,8,2) e*2>")
  # sound "supermandolin"
  # legato 2

再加一层：

d1 $ jux rev $ n (off 0.125 (|+ 12) $ off 0.125 (|+ 7)  "<c*2 a(3,8) f(3,8,2) e*2>")
  # sound "supermandolin"
  # legato 2

从和弦构建琶音

我们先从一个 C 大三和弦开始：

d1 $ n "c'maj"
  # sound "supermandolin"
  # legato 2

用 arp 函数做琶音处理：

d1 $ arp "up" $ n "c'maj"
  # sound "supermandolin"
  # sustain 0.5

给和弦再加一个音符：

d1 $ arp "up" $ n "c'maj'4"
  # sound "supermandolin"
  # sustain 0.5

再加一个和弦：

d1 $ arp "up" $ n "c'maj'4 e'min"
  # sound "supermandolin"
  # sustain 0.5

换一种琶音器：

d1 $ arp "pinkyup" $ n "c'maj'4 e'min"
  # sound "supermandolin"
  # sustain 0.5

哦，琶音器本身也可以用 pattern 表示：

d1 $ arp "<pinkyup down thumbup up>" $ n "c'maj'4 e'min"
  # sound "supermandolin"
  # sustain 0.5

换和弦，加点混响：

d1 $ jux rev $ arp "<pinkyup down thumbup up>" $ n "<c'maj'4 e4'min'8 f4'maj'4>"
  # sound "supermandolin"
  # sustain 2 # room 0.3 # sz 0.9

用 'chunk' 增添变化：

d1 $ chunk 4 (|- note 5) $ jux rev $ 
  arp "<pinkyup down thumbup up>" $ n "<c'maj'4 e4'min'8 f4'maj'4>"
  # sound "supermandolin"
  # sustain 2 # room 0.3 # sz 0.9
