卸载

Tidal Cycles 没有提供便捷的卸载程序。要卸载 Tidal，你需要：

  • 卸载 SuperDirt 和/或 SuperCollider（如果你没有出于其他用途在使用它）。
  • 卸载 Tidal 库和 GHC 编译器。

Linux

在 Linux 上卸载 Tidal Cycles 可能比较麻烦。根据你使用的发行版，有多种安装方式。下面是一些技巧，可帮你找出 Tidal 安装的所有组成部分。

使用 whereis

在终端中输入 whereis scide sclang scsynth，即可获得 SuperCollider 二进制文件的路径。

SuperDirt Quark

打开 SuperCollider。在 File 菜单中点击 Open user support directory。这个菜单会带你到 SuperDirt 在你电脑上的当前安装位置。在 downloaded-quarks 中查找 SuperDirt。别忘了同时卸载 Dirt-Samples 文件夹。它可能相当大（所有采样都存放在这里）。

卸载 stack

如果你是用 Stack 安装的 Tidal，可以使用一个粗暴但简单的办法来卸载它。运行 rm -rf $HOME/.stack。这条命令会删除位于你根目录下的隐藏 stack 文件夹。

Stack 有时会在 $HOME/.local/bin 安装一个二进制文件。愿意的话可以把它删掉。

请反复检查 rm -rf 命令。这是一个强大的工具，会彻底删除东西。使用时务必小心，操作不当可能相当危险。

清理 cabal 和 GHC

要清理 cabal 和 GHC（用户安装的包），请在终端窗口中尝试运行以下命令：

rm ~/.cabal ~/.ghc

请反复检查 rm -rf 命令。这是一个强大的工具，会彻底删除东西。使用时务必小心，操作不当可能相当危险。

Windows

对于 chocolatey 安装，请参阅 Windows Chocolatey 清理中的说明。

MacOS

使用 uninstall-hs

打开一个终端窗口并输入 uninstall-hs。这条命令会删除你电脑上许多与 Haskell 相关的东西。

卸载 ghcup

如果你是用 ghcup 安装的 Tidal，可以尝试一个取巧的办法。打开一个终端窗口，粘贴 rm -rf ~/.ghcup。这会删除位于你根目录下的 .ghcup 隐藏目录。

请反复检查 rm -rf 命令。这是一个强大的工具，会彻底删除东西。使用时务必小心，操作不当可能相当危险。
