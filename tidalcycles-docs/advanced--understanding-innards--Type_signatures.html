类型签名

在 Haskell（Tidal 就活在它里面）中，类型签名告诉你一个值或函数是什么种类的东西。它们对于弄清一个函数期望你给它什么、以及它会返回什么特别有用。

你可以用

:t

查出一个函数的类型，例如要查看 rev 的类型签名，你可以输入

:t rev

到你的编辑器里，然后求值。你会在输出窗口里看到：

rev :: Pattern a -> Pattern a

这很简单，它告诉你它接受一个 pattern 作为输入，并返回一个 pattern 作为输出。我们再通过

:t fast

看看 fast 函数：

fast :: Pattern Time -> Pattern a -> Pattern a

这有点更复杂了，那里有三个 pattern。最后一个是输出，它前面的都是输入。所以

fast

接受时间 pattern、另一个 pattern，然后返回一个 pattern。这也很说得通，第一个参数说明在时间上应该多快，而且它可以被编排成 pattern。第二个参数是即将被加快的那个 pattern，但它没说是什么类型的 pattern，只说了

Pattern a

，输出也一样。我们之前见过同样的

Pattern a

类型，之前在

rev

里见过。这是什么意思？

嗯，

a

在

Pattern a

里是不受约束的——它可以是任何你想要的东西。所以

rev

函数可以作用于任何类型的 pattern。这是因为

rev

不处理任何具体的值，它只操纵时间。

所以

a

在这里是一种通配符，同时用于

    rev

的输入和输出。这意味着你可以给它任何内容的 pattern，但如果你给它整数 pattern，你保证会得到整数 pattern 回来。所以你可以把那个

a

换成另一个类型，但前提是你把它出现的所有地方都换成同一个类型。

一个更复杂的例子是 every：

every :: Pattern Int -> (Pattern a -> Pattern a) -> Pattern a -> Pattern a

现在，

every

接受三个参数：一个整数个的循环数、一个要应用到 pattern 上的函数，以及那个 pattern 本身。我们可以看到第一个参数是整数的 pattern（也就是整数），没问题。第二个参数比较奇怪——

(Pattern a -> Pattern a)

。这就是作为参数的函数的写法——被包在括号里。由此可以看出第二个参数是一个函数，它接受任意类型的 pattern 作为输入，并返回相同类型的 pattern 作为输出。如果我们回看

rev

的类型签名，很明显我们可以把它作为这第二个参数传进去，因为类型吻合…… 实际上，这样做很常见，比如

every 3 rev (s "bd sn")

。

希望这能让你对如何阅读类型签名有所领悟。它们对于理解如何使用函数真的很有用，即使不读文档。
