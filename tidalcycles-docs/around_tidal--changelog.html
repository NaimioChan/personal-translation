变更日志

发布版本

完整版本变更列表见 Tidal Codeberg Releases。Codeberg 还提供其他有价值的信息，包括贡献者、已合并 pull request 的链接等。

Tidal 1.0.0

在底层，Tidal 1.0.0 是一次大规模重写。如果你习惯了以前的版本，这一点主要体现在新功能上。不过也有一些破坏性变更。下面是一份不断增长的变更与新增清单。我（Yaxu）尽力感谢了那些做成/贡献了这些工作的人，如有遗漏深表歉意。没有标注的事项大概全是我自己的错。

名称变更、新函数、行为变化

  • 旧的 scale 已更名为 range
  • scale 现在用于指定音乐调式
  • protate 及其同类函数已被 rot 取代
  • 新增函数 fix，用于操作具有匹配控制参数值的控制参数 pattern
  • 新增函数 mono，用于把 pattern 变为单声部（感谢 bgold）
  • 新增函数 smooth，通过在数值之间插值，把离散/数字的数值 pattern 变成连续/模拟的 pattern（感谢 bgold）
  • 和弦名现在可以直接写进数值 pattern，例如 n "c'maj e'min"。旧的 chordP 已移除。
  • discretise 现在叫 segment
  • e 现在叫 euclid
  • breakOut 现在叫 arpeggiate
  • 函数普遍标准化为『慢』式的行为，例如 scan n 会在 n 个循环上展开工作，而不是把整个渐强压缩进单个循环。
  • 原本只作用于单一数值类型的函数已泛化为在有意义之处作用于任意类型，例如 rand 现在既可作为 double/浮点值的 pattern，也可作为时间/有理数值的 pattern 使用（感谢 msp）
  • 新增若干 select 函数，用于用一个 float pattern 在多个 pattern 之间选择
  • wchoose 的权重不再必须加总为 1
  • weave' 现在叫 weaveWith
  • 新增用于琶音的 arp 函数
  • 提供了向 SuperDirt 以外的系统发送自定义 OSC 的简便方法
  • stut 与 stutWith 的参数含义已改为彼此一致。

交互

  • solo 现在做的是『真正的』独奏。也就是说现在也有 unsolo 了。
  • 现在可以用 once 立即运行一个循环，且只运行一次
  • 实验性的 transition interpolate，用于在新旧值之间过渡合并

其他新功能

  • Tidal 现在可以接收 OSC 和 MIDI 输入——参见 Configuration > I/O。这意味着你可以把数字和字符串送入 Tidal，用作控制参数值、函数参数或解析后的序列
  • pattern（以及控制参数 pattern）的 'Show' 实例现在更可读了
  • 如果你把控制参数 pattern 当作数字来对待，你实际操作的是 n 控制参数，例如 (s "bd" # n "1 2") + 3 会把 3 同时加到 1 和 2 上。
  • 更多参数可以是 pattern 化的，例如 sometimesBy
  • 解析器现在可以生成二元（布尔）pattern，其中欧几里得节奏产生 true 和 false 值，而不是 true 和静默。这在配合例如 sew 和 struct 使用时很有用
  • 配置改由启动脚本完成，而不再使用环境变量

文档

  • 文档已迁移到一个 wiki（感谢包括 kindohm 在内的许多人）
  • 我们过去所说的 'param pattern' 现在称为 'control pattern'（控制参数 pattern）

速度与调度变更

  • setcps 现在用于设定固定速度
  • 速度现在可以用 pattern 表示，把 cps 作为控制参数 pattern 使用即可

pattern 结构

pattern 组合的方式已经重新设计：

  • 旧的『结构来自左边』的格言不再适用——你现在可以控制结构来自哪里
  • |+|、|*| 的行为已经改变。
  • # 的工作方式与以前相同，但它现在是 >| 的别名，而不是 |=|（后者已不存在）。

退步

  • tidal-midi 目前无法工作（但 MIDI 经由 SuperDirt 仍然工作得很好）
  • tidalink 目前无法工作（应该很快会修好）
  • 经典版 Dirt 目前不受支持（同样应该很快会修好）

内部与开发变更

  • 随机数生成改用 system.random（感谢 d0kt0r0
  • MiniTidal 移入了 tidal 核心仓库（感谢 d0kt0r0）
  • 开始了单元测试套件的建设（感谢 vivid-synth、msp、nini-faroux 及其伙伴们）
  • 为 Pattern 提供了更符合律法的 Applicative 和 Monad 实例
  • 定义了 <* 和 *>，它们像 <*> 一样工作，但使用左边或右边的结构
  • <*> 现在使用两边的结构
  • 新增 innerJoin 和 outerJoin，用于『摊平』嵌套 pattern——工作方式类似 join，但分别取内部或外部 pattern 的结构。
  • pattern 现在会标记为 analog 或 digital 之一
  • Tidal 总体上现在是单进程、多线程的程序，而不是以前的多进程
  • websocket 速度协议已被基于 OSC 的协议取代
  • 模块经过了大范围重组，例如 Strategies 不复存在，而 Pattern、Core、Control 和 UI 存在。
  • 编译无警告
  • 更好的 stack 支持（感谢 tonyday567）
  • 充实了数据类型结构（感谢 tonyday567）
  • travis 构建更整洁，测试了更多 Haskell 版本（感谢 tonyday567）
  • 新增用于反转二元（布尔）pattern 的函数 inv
  • 计算现在基于 hZ，而不是按每次循环的计算数计。默认情况下 tidal 以每秒 20 次计算运行。
