Linux 故障排除

Haskell 装好了吗？

打开一个终端窗口，输入：

ghci

你应该会看到类似这样的内容：

GHCi, version 8.6.3: http://www.haskell.org/ghc/  :? for help
Prelude>

如果你没有看到类似上面的内容，可能需要安装 Haskell。你看到的版本号可能不同，不必担心。在撰写本文时，Tidal 的测试一直覆盖到 7.10.3 的版本。

Tidal 库装好了吗？

保持那个 ghci 窗口开着，输入（或粘贴）：

import Sound.Tidal.Context

你现在应该会看到类似这样的内容：

GHCi, version 8.6.3: http://www.haskell.org/ghc/  :? for help
Prelude> import Sound.Tidal.Context
Prelude Sound.Tidal.Context>

如果你反而看到类似这样的错误消息：

<no location info>: error:
  Could not find module ‘Sound.Tidal.Context’

这说明 Tidal 库没有安装。要安装它，打开一个新的终端窗口并输入：

cabal update
cabal new-install tidal --lib

注意：从 1.7 版本开始，你必须改用以下命令：

cabal v1-update
cabal v1-install tidal

关于 'legacy v1 style' 的警告可以忽略。

如果你仍然看到错误消息，请确认你安装的是完整的 Haskell Platform，然后再试一次。如果还是不行，请在某个社区页面上求助。

SuperDirt 正常吗？

CLASS Not Found

如果你看到以下错误：

ERROR: Class not defined.

这说明 SuperDirt 没有安装。通过运行以下命令来安装它：

 include("SuperDirt")

如果安装失败，请确保已安装 git 命令。可以在命令提示符中运行 git --version 来检查。如果找不到该命令，请查看安装页了解如何安装 Git。安装之后，需要重启 SuperCollider 再试一次。

对于刚安装 SuperCollider 的用户，在运行 include("SuperDirt") 之前先重启它也可能解决该错误。

Could not bind to requested port

如果你看到类似这样的错误：

Could not bind to requested port. This may mean it is in use already by another application.
ERROR: Could not open UDP port 57120

这很可能意味着有残留的 SuperCollider 进程在运行，占用了网络端口。关闭 SuperCollider，并在任务管理器中强制结束 sclang 和 scserver。如果不行，重启一次即可清除它们。

Jack 音频服务器正常吗？

Supercollider 运行在 Jack 音频服务器上，以便把声音送到你的扬声器。如果你在 SuperCollider 的 post 窗口中看到以下错误：

Couldn't set realtime scheduling priority 1: Operation not permitted

你需要用这条命令设置 Jack：

sudo dpkg-reconfigure jackd2

并用以下命令把你的用户名加入 audio 组（替换 USERNAME）：

sudo adduser USERNAME audio

你可以通过输入以下命令检查你的用户名是否已经在 audio 组中：

groups USERNAME

你可能需要注销并重新登录，这些设置才能生效。

如果你在 Arch 上且问题仍然存在，可以按照这里的建议尝试 这个方法。

编译错误

你在安装 Tidal Haskell 库时可能会遇到问题。如果遇到错误，问题可能出在 Tidal Haskell 库本身。运行以下命令确保它被正确安装：

cabal update
cabal new-install tidal --lib

有时安装过程会毫无明显原因地失败。这条命令有助于解决这个问题：

sudo ghc-pkg recache
cabal update
cabal new-install tidal --lib

为什么我什么都听不到？

缺少采样

Tidal Cycles 安装时会带上一大批默认音频采样库。下载有时会失败，导致你没有声音可播放。如果一切看起来正常，但并非所有声音都能播放，那很可能是 Tidal 音色库的下载在中途出了问题。

你可以通过 SuperCollider 菜单找到 Dirt-Samples 文件夹来修复：打开 File > Open user Support directory（顶部菜单）。找到 downloaded-quarks，然后是 Dirt-Samples 文件夹。你很可能会发现许多文件夹缺失或为空。你可以从这个链接下载缺失的采样并放到这里。

音频配置

问题也可能来自你的声音系统。检查一切是否连接正确，检查你是否选择了正确的音频接口以及音量是否调高。如果你还是听不到任何声音，问题可能出在别处。

用 'stack' 而不是 'cabal' 安装

如果 Tidal Haskell 库在用 cabal 安装时问题顽固，特别是当它报出与 'network' 库相关的错误时，改用 stack 安装就能解决。

对大多数类 Unix 操作系统来说，安装 stack 最简单的方式是运行：

curl -sSL https://get.haskellstack.org/ | sh

或者：

wget -qO- https://get.haskellstack.org/ | sh

然后在终端窗口中用以下命令完成安装：

stack install tidal

完成后，你只需告诉编辑器插件使用用 stack 安装的 Tidal。在 Atom 中，找到 Tidal Cycles 包的设置，把 ghci path 设置改为：

stack exec --package tidal -- ghci

重启 Atom，一切应该就正常了。
