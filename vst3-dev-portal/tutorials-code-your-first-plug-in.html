目标

在上一教程 用项目生成器 App 生成新插件 的基础上，本教程讲解如何编写音频插件代码以及如何添加一些基本功能。

最终产物是一个音频插件，它可以对音频信号计算增益，并能加载到 Cubase、WaveLab 等 VST 3 宿主中。

第 1 部分：编写你的插件

现在你有了一个自动生成的插件框架。以下各节说明如何添加新参数及其相关的处理算法，以及保存 / 加载工程或预设、创建专用用户界面等其他具体功能。

一个 VST 3 插件包含两个主要类：PlugProcessor（执行处理和状态持久化）和 PlugController（负责与 DAW 通信、处理参数和 UI）。

添加一个参数：Gain

在这个基础插件示例中，我们将添加一个 Gain 参数，用来改变通过插件的音频的音量。

为此，每个 VST 3 参数都需要一个唯一标识符（一个数字）。

  1. 打开文件 plugids.h，输入一个新 id kParamGainId。在本例中，例如为它指定唯一数字 102。

plugids.h

#include "pluginterfaces/vst/vsttypes.h"

enum GainParams : Steinberg::Vst::ParamID
{
    kParamGainId = 102, // 应当是唯一的 id……
};
  1. 打开 plugcontroller.cpp 文件，用 parameters.addParameter 添加这个增益参数

plugcontroller.cpp

// 包含定义了一些 id 的文件
#include "plugids.h"

//----------------------------------------------------------------------------
tresult PLUGIN_API PlugController::initialize (FUnknown*context)
{
    tresult result = EditController::initialize (context);
    if (result != kResultOk)
    {
        return result;
    }

    //---创建参数------------
    parameters.addParameter (STR16 ("Gain"), STR16 ("dB"), 0, .5, Vst::ParameterInfo::kCanAutomate, GainParams::kParamGainId, 0);

    return kResultTrue;
}

ⓘ 注意\

  • 我们添加了 kCanAutomate 标志，它告知 DAW / 宿主该参数可以被自动化。
  • VST 3 参数始终是归一化的（其值为 [0.0, 1.0] 之间的浮点数），这里其默认值设为 0.5。
  1. 现在为这个新参数改造处理器部分。打开 plugprocessor.h 文件，添加一个增益值 Vst::ParamValue mGain。该值用于处理中施加增益。

plugprocessor.h

// ...
static FUnknown* createInstance (void*)
{
    return (Steinberg::Vst::IAudioProcessor*)new PlugProcessor ();
}
protected:
    Steinberg::Vst::ParamValue mGain = 1.;
// ...

添加应用增益的处理

  1. 我们需要从宿主取得所需的值来设置内部的 mGain。这是 process 方法的第一步。在 data.inputParameterChanges 结构中解析来自宿主的参数变化，针对当前要处理的音频块。
    ⓘ 别忘了 #include "public.sdk/source/vst/vstaudioprocessoralgo.h：它要加在 plugprocessor.cpp 文件顶部！
    这里包含了一些用于访问音频缓冲区的辅助函数。

plugprocessor.cpp

#include "pluginterfaces/vst/ivstparameterchanges.h"
#include "public.sdk/source/vst/vstaudioprocessoralgo.h"

//----------------------------------------------------------------------------
tresult PLUGIN_API PlugProcessor::process (Vst::ProcessData&data)
{
    //--- 首先：读取输入的参数变化-----------
    if (data.inputParameterChanges)
    {
        // 针对由其 ID 定义的每个参数
        int32 numParamsChanged = data.inputParameterChanges->getParameterCount ();
        for (int32 index = 0; index < numParamsChanged; index++)
        {
            // 对于这个参数，我们可以遍历值变化的列表（每个音频块可能有 1 个或更多！）
            // 在本例中，我们只取最后一个值（getPointCount - 1）
            Vst::IParamValueQueue* paramQueue = data.inputParameterChanges->getParameterData (index);
            if (paramQueue)
            {
                Vst::ParamValue value;
                int32 sampleOffset;
                int32 numPoints = paramQueue->getPointCount ();
                switch (paramQueue->getParameterId ())
                {
                    case GainParams::kParamGainId:
                        if (paramQueue->getPoint (numPoints - 1, sampleOffset, value) == kResultTrue)
                            mGain = value;
                        break;
                }
            }
        }
    }
    // ....
}

ⓘ 注意
data.inputParameterChanges 在一个处理音频块内对同一参数可能包含不止 1 个变化。这里我们只取列表中的最后一个变化，并将其应用到我们的 mGain。

  1. 真正的处理部分：

plugprocessor.cpp

// ...

//-- Flush 情形：我们只需要更新参数，无法进行处理
if (data.numInputs == 0 || data.numSamples == 0)
    return kResultOk;

//--- 这里，你必须实现自己的处理
int32 numChannels = data.inputs[0].numChannels;

//---使用辅助函数（vstaudioprocessoralgo.h）获取音频缓冲区-------------
uint32 sampleFramesSize = getSampleFramesSizeInBytes(processSetup, data.numSamples);
void** in = getChannelBuffersPointer (processSetup, data.inputs[0]);
void** out = getChannelBuffersPointer (processSetup, data.outputs[0]);

// 这里可以检查静音标志
// 现在我们要产生输出
// 把我们的输出标记为非静音
data.outputs[0].silenceFlags = 0;

float gain = mGain;
// 对每个通道（左和右）
for (int32 i = 0; i < numChannels; i++)
{
    int32 samples = data.numSamples;
    Vst::Sample32* ptrIn = (Vst::Sample32*)in[i];
    Vst::Sample32* ptrOut = (Vst::Sample32*)out[i];
    Vst::Sample32 tmp;
    // 对此通道中的每个采样
    while (--samples >= 0)
    {
        // 施加增益
        tmp = (*ptrIn++) * gain;
        (*ptrOut++) = tmp;
    }
}
//...
  1. VST 3 提供了一种方式，让宿主告知插件其输入为静音（使用 VST 3 的静音标志）：

plugprocessor.cpp

// 这里可以检查静音标志
//---检查是否静音---------------
// 通常我们必须检查每个通道（这里做了简化）
if (data.inputs[0].silenceFlags != 0)
{
    // 也把输出标记为静音
    data.outputs[0].silenceFlags = data.inputs[0].silenceFlags;

    // 插件必须确保：如果它设置了静音标志，输出缓冲区就应当是清零的
    for (int32 i = 0; i < numChannels; i++)
    {
       // 如果缓冲区相同则无需清零（在这种情况下输入缓冲区
        // 已由宿主清零）
        if (in[i] != out[i])
        {
            memset (out[i], 0, sampleFramesSize);
        }
    }
    // 此时无事可做
    return kResultOk;
}

添加状态的保存 / 恢复

Processor 部分代表插件的状态，因此由它负责实现宿主用来保存 / 加载工程和预设的 getState / setState 方法。Controller 部分也会取得 Processor 的状态，通过其 setComponentState 方法，这使其参数也能同步（例如供 UI 使用）。

  1. 在 plugprocessor.cpp 文件中，把 mGain 的值加入宿主提供的状态流 —— 通过 getState 方法，它会将其保存为工程或预设。
    可以使用辅助类 IBStreamer 来处理宿主提供的 IBStream。

plugprocessor.cpp

// 在文件顶部添加这个 include
#include "base/source/fstreamer.h"

//-----------------------------------------------------------------------
tresult PLUGIN_API PlugProcessor::getState (IBStream* state)
{
    // 这里我们需要保存模型（预设或工程）
    float toSaveParam1 = mGain;
    IBStreamer streamer (state, kLittleEndian);
    streamer.writeFloat (toSaveParam1);
    return kResultOk;
}
  1. 在 setState 方法中，插件从宿主接收新的状态，该方法在加载工程或预设之后被调用。

plugprocessor.cpp

//-----------------------------------------------------------------------
tresult PLUGIN_API PlugProcessor::setState (IBStream* state)
{
    if (!state)
        return kResultFalse;

    // 在加载预设或工程时调用，模型必须重新加载
    IBStreamer streamer (state, kLittleEndian);
    float savedParam1 = 0.f;
    if (streamer.readFloat (savedParam1) == false)
        return kResultFalse;
    mGain = savedParam1;

    return kResultOk;
}
  1. 在 setComponentState 方法中，插件的 Controller 部分会收到与 PlugProcessor::setState 中所用相同的状态。PlugController::setComponentState 在 PlugProcessor::setState 之后立即被调用。

plugcontroller.cpp

// 在文件顶部添加这个 include
#include "base/source/fstreamer.h"

//-----------------------------------------------------------------------
tresult PLUGIN_API PlugController::setComponentState (IBStream* state)
{
	// 这里，你取得组件（Processor 部分）的状态
	if (!state)
		return kResultFalse;

    IBStreamer streamer (state, kLittleEndian);
    float savedParam1 = 0.f;
    if (streamer.readFloat (savedParam1) == false)
        return kResultFalse;

	// 与我们的参数同步
	if (auto param = parameters.getParameter (GainParams::kParamGainId))
		param->setNormalized (savedParam1);

    return kResultOk;
}

第 2 部分：进阶步骤

添加一个事件输入

在本例中，我们想用弹奏的「MIDI」事件（noteOn）的力度来修改当前的 Gain 系数。

  1. 如果你的插件不仅需要接收音频，还需要接收事件（例如 MIDI），就必须添加一个事件输入。为此，只需用 addEventInput 在处理器的 initialize 方法中添加事件输入：

plugprocessor.cpp

//-----------------------------------------------------------------------
tresult PLUGIN_API PlugProcessor::initialize (FUnknown* context)
{
    //---始终先初始化父类-------
    tresult result = AudioEffect::initialize (context);
    // 如果一切正常，则继续
    if (result != kResultOk)
    {
        return result;
    }

    //....

    //---创建事件输入 / 输出总线（1 条总线，只有 1 个通道）------
    addEventInput (STR16 ("Event In"), 1);

    return kResultOk;
}

ⓘ 注意
在本例中，我们添加 1 条输入事件总线，只在一个通道上接收。如果你需要接收有区分的事件，例如来自不同通道的事件，只需按下面的方式修改：

addEventInput (STR16 ("Event In"), 4); // 这里是 4 个通道

  1. 我们创建一个新的内部值 mGainReduction（不导出给宿主），它由弹奏的 noteOn 的力度改变，这样你敲得越重，增益衰减就越大（这正是本插件想要的效果）：

plugprocessor.h

// ...
static FUnknown* createInstance (void*)
{
    return (Steinberg::Vst::IAudioProcessor*)new PlugProcessor ();
}
protected:
    Steinberg::Vst::ParamValue mGain= 1.;
    Steinberg::Vst::ParamValue mGainReduction = 0.;
// ...
  1. 现在我们要在 process 方法中接收事件变化：

plugprocessor.cpp

//-----------------------------------------------------------------------
tresult PLUGIN_API PlugProcessor::process (ProcessData& data)
{
    //--- 首先：读取输入的参数变化-----------
    //...

    //---其次：读取输入事件-------------
    // 取得所有事件变化的列表
    Vst::IEventList* eventList = data.inputEvents;
    if (eventList)
    {
        int32 numEvent = eventList->getEventCount ();
        for (int32 i = 0; i < numEvent; i++)
        {
            Vst::Event event;
            if (eventList->getEvent (i, event) == kResultOk)
            {
                // 这里我们不关心事件的通道信息
                switch (event.type)
                {
                    //----------------------
                    case Vst::Event::kNoteOnEvent:
                        // 用力度作为增益调制量：力度最大（1）会导致音频静音
                        mGainReduction = event.noteOn.velocity; // 值在 0 到 1 之间
                        break;
                    
                    //----------------------
                    case Vst::Event::kNoteOffEvent:
                        // noteOff 重置增益调制量
                        mGainReduction = 0.f;
                        break;
                }
            }
        }
    }
  1. 在真正的处理部分中使用这个 mGainReduction：

plugprocessor.cpp

//----------------------------------------------------------------------------
tresult PLUGIN_API PlugProcessor::process (Vst::ProcessData&data)
{
    //....

    float gain = mGain - mGainReduction;
    if (gain < 0.f)  // 增益应当始终为正或零
        gain = 0.f;

    // 对每个通道（左和右）
    for (int32 i = 0; i < numChannels; i++)
    {
        int32 samples = data.numSamples;
        Vst::Sample32* ptrIn = (Vst::Sample32*)in[i];
        Vst::Sample32* ptrOut = (Vst::Sample32*)out[i];
        Vst::Sample32 tmp;
        // 对此通道中的每个采样
        while (--samples >= 0)
        {
            // 施加增益
            tmp = (*ptrIn++) * gain;
            (*ptrOut++) = tmp;
        }
    }
    //...
}

添加一个单声道音频侧链

在本例中，我们想用一个侧链音频输入来调制主音频输入。

  1. 首先，添加一个新的侧链音频输入（busType: kAux），位置在处理器的 initialize 调用中：

plugprocessor.cpp

//-----------------------------------------------------------------------
tresult PLUGIN_API PlugProcessor::initialize (FUnknown*context)
{
    //---始终先初始化父类-------
    tresult result = AudioEffect::initialize (context);
    // 如果一切正常，则继续
    if (result != kResultOk)
    {
        return result;
    }

    //....

    //---创建事件输入 / 输出总线（1 条总线，只有 1 个通道）------
    addEventInput (STR16 ("Event In"), 1);

    // 创建一条单声道侧链输入总线
    addAudioInput (STR16 ("Mono Aux In"), Steinberg::Vst::SpeakerArr::kMono, Steinberg::Vst::kAux, 0);

    return kResultOk;
}
  1. 我们要确保侧链按单声道输入来处理。为此需要覆写 AudioEffect::setBusArrangements 函数：

plugprocessor.h

//-----------------------------------------------------------------------
class PlugProcessor: public AudioEffect
{
public:
    PlugProcessor ();
    
    //...
    // 覆写此函数
    Steinberg::tresult PLUGIN_API setBusArrangements (Steinberg::Vst::SpeakerArrangement* inputs,
                                                    Steinberg::int32 numIns,
                                                    Steinberg::Vst::SpeakerArrangement* outputs,
                                                    Steinberg::int32 numOuts) SMTG_OVERRIDE;
    //...
};

plugprocessor.cpp

//-----------------------------------------------------------------------
tresult PLUGIN_API PlugProcessor::setBusArrangements(Vst::SpeakerArrangement* inputs, int32 numIns,
                                                    Vst::SpeakerArrangement* outputs,
                                                    int32 numOuts)
{
    // 第一个输入是主输入，第二个是侧链输入
    // 确保我们有 2 个输入和 1 个输出
    if (numIns == 2 && numOuts == 1)
    {
        // 我们只支持主输入的通道数与输出相同的情况
        if (Vst::SpeakerArr::getChannelCount (inputs[0]) != Vst::SpeakerArr::getChannelCount (outputs[0]))
            return kResultFalse;

        // 我们接受主输入和输出的所有排列
        // 然后应用它们
        getAudioInput (0)->setArrangement (inputs[0]);
        getAudioOutput (0)->setArrangement (outputs[0]);

        // 现在检查侧链是否为单声道（本例只支持单声道侧链）
        if (Vst::SpeakerArr::getChannelCount (inputs[1]) != 1)
            return kResultFalse;

        // 好，侧链是单声道，我们返回 kResultTrue 表示接受
        return kResultTrue;
    }

    // 我们不接受宿主的这种要求：返回 kResultFalse ！
    return kResultFalse;
}
  1. 改造我们的 process，把侧链输入用作调制：
//-----------------------------------------------------------------------
tresult PLUGIN_API PlugProcessor::process (ProcessData& data)
{
    //--- 首先：读取输入的参数变化-----------
    //...

    //---其次：读取输入事件-------------
    //...

    float gain = mGain - mGainReduction;
    if (gain < 0.f)  // 增益应当始终为正或零
        gain = 0.f;

    void** auxIn = nullptr;
    
    // 检查侧链输入是否已激活
    bool auxActive = false;
    if (getAudioInput (1)->isActive ())
    {
        auxIn = getChannelBuffersPointer (processSetup, data.inputs[1]);
        auxActive = true;
    }
    if (auxActive)
    {
        // 对每个通道（左和右）
        for (int32 i = 0; i < numChannels; i++)
        {
            int32 samples = data.numSamples;
            Vst::Sample32* ptrIn = (Vst::Sample32*)in[i];
            Vst::Sample32* ptrOut = (Vst::Sample32*)out[i];
            // 侧链是单声道，所以取 auxIn[0]：索引 0
            Vst::Sample32* ptrAux = (Vst::Sample32*)auxIn[0];
            Vst::Sample32 tmp;

            // 对此通道中的每个采样
            while (--samples >= 0)
            {
                // 施加调制和增益
                tmp = (*ptrIn++) * (*ptrAux++) * gain;
                (*ptrOut++) = tmp;
            }
        }
    }
    else
    {
        // 对每个通道（左和右）
        for (int32 i = 0; i < numChannels; i++)
        {
            int32 samples = data.numSamples;
            Vst::Sample32* ptrIn = (Vst::Sample32*)in[i];
            Vst::Sample32* ptrOut = (Vst::Sample32*)out[i];
            Vst::Sample32 tmp;
            // 对此通道中的每个采样
            while (--samples >= 0)
            {
                // 施加增益
                tmp = (*ptrIn++) * gain;
                (*ptrOut++) = tmp;
            }
        }
    }
