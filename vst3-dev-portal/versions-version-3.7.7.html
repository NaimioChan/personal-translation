版本 3.7.7（2022/12/12）

版本 3.7.7（2022/12/12）

  • 接口变更：

    • 重构 vsttypes.h 中的 SDK 版本宏，以便 C API 生成器可以使用。
    • 改进 fplatform.h 中对 MinGW 的支持。

  • VSTGUI 更新至 4.12

  • 文档

    • 新教程：从零创建 cmake 插件项目。
    • 新教程：切换到另一个 VSTGUI 子模块或分支。

  • CMake

    • 调整 cmake，使其可以从 SDK 中提取示例。
    • 修复 Windows Arm64EC 的文件夹名称。
    • 移除 ${SDK_ROOT}（位于 smtg_target_configure_version_file 中）。
    • 将 SDK_ROOT 替换为 vst3sdk_SOURCE_DIR。
    • 改进对 MinGW 的支持。
    • 改进 SMTG_AAXSupport.cmake 和 SMTG_CoreAudioSupport.cmake
    • 修复 CMAKE_OSX_DEPLOYMENT_TARGET 的初始化。

  • 插件包装层：

    • Audio Unit 包装层：
      • AUv3 包装层：
        • 修复构建参数组时的崩溃（PR#43）。
        • 修复空参数组导致的崩溃（PR#44）。

  • VST3PluginTestHost v3.4 版本：

    • macOS 上支持 MIDI 2.0，Velocity On/Off、Aftertouch、Polypressure、ControlChange 和 PitchBend 具有更高分辨率。

  • VST 3 Project Generator v2022.11 版本：

    • 支持为生成的插件源代码使用多个命名空间（XX::YY::ZZ），要求最低 C++17。
    • 修复对路径中空格字符的支持。
