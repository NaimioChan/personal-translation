AudioHost

作为跨平台源代码：简单的跨平台（仅在 Linux 上测试过）宿主程序，可让你把 VST 3 插件注册到 Jack Server。首先，你必须下载 Jack Audio SDK 和应用程序服务器（http://www.jackaudio.org）。

  • Windows（未测试）：
 audiohost.exe "C:\PATH_TO_PLUGIN"
  • macOS（未测试）
  • Linux 平台：
audiohost PATH_TO_PLUGIN

在 Windows 和 macOS 上，你也可以通过资源管理器/访达把 VST 3 插件拖放到该可执行文件上。

请查看 SDK 的 "public.sdk/samples/vst-hosting/audiohost" 文件夹！
