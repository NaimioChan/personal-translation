版本 3.7.13（2025/02/28）

  • 接口变更：

    • 修复 -Wundef 警告（PR#17）。
    • 修复公共头文件中警告启用/禁用的问题（Issue#18）。
    • 增加通过 SMTG_DISABLE_DEFAULT_DIAGNOSTICS 在 Windows（Visual Studio）上禁用 #pragma warning 的可能性。

  • VSTGUI 更新至 4.14.2

  • 文档

    • 更新关于 pluginterfaces/gui/iplugview.h 的文档。参见 VST3 论坛。
    • 为每个 VST 3 API 函数补充有关线程和状态上下文的更多信息。

  • CMake

    • 将 cmake_minimum_required 更新为 3.25.0
    • 修复 Mac 上的链接器警告（PR#11）。
    • smtg_target_add_plugin_resource 将资源文件分组并结构化到 IDE 中。
    • 修复资源空白字符问题 论坛。

  • 插件包装层：

    • Audio Unit 包装层：
      • AU/AUv3 包装层：
        • 修复使用 auval 运行 AGain AUv3 时崩溃（public.sdk/source/vst/auv3wrapper/Shared/AUv3Wrapper.mm）。
      • AU 包装层：
        • 修复 auwrapper MIDI 输出错误（PR#76）（public.sdk/ssource/vst/auwrapper/auwrapper.h）。
        • 修复 AU 包装层中的 MIDI CC 输入（PR#74）。（public.sdk/source/vst/auwrapper/auwrapper.mm）。

  • 示例：

    • 在大多数插件中增加对 Vst:: IAudioProcessor::setProcessing 的支持，演示该函数可以如何使用（例如清理延迟线、终止发声等）。
    • 更新 Hostchecker 插件：
      • 重新设计 UI。
      • 增加对调用 queryInterface () 时 COM 正确行为的检查。
      • 增加对 ProcessContext::systemtime 连续性的检查。

  • 辅助类：

    • 修复 openurl.cpp 中 openURLInDefaultApplication 在 macOS 和 Linux 上返回错误结果的问题。
    • 修复 vst3_public_sdk/source/vst/hosting/module_linux.cpp：名称中带额外点的插件包在 Hosting::Module 类中加载失败（Issue#73）。
    • 修复 -Wundef 警告（PR#75）。
    • 修复 HostApplication::queryInterface —— mPlugInterfaceSupport 的 Query Interface 应使用 "_iid" 而非 "iid"（Issue#131）。
    • 修复 seek 到末尾的问题 + 新增函数 take，允许将内存从流中取出：public.sdk/source/vst/utility/memoryibstream.h。
    • 修复 public.sdk/source/vst/utility/dataexchange.cpp 中定时器导致的内存泄漏。
    • 新增校验函数：validateBundleStructure，位于 public.sdk/source/vst/hosting/module_win32.cpp、public.sdk/source/vst/hosting/module_mac.cpp、public.sdk/source/vst/hosting/module_linux.cpp。

  • VST 3 项目生成器 v2025.02：

    • 修复：仅在非空时才添加 SMTG_PREFIX_FOR_FILENAMES_CLI 参数。

  • VST3PluginTestHost 测试宿主 v3.9：

    • 修复：将参数变化添加到输出参数队列，以便编辑控制器能看到变化。
    • 修复：使用参数步进数进行程序变更计算。
