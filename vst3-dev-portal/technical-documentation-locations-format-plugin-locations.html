引言

一个 VST 3 插件应安装到特定的文件夹位置，下表列出不同操作系统的这些预定义位置。

ⓘ 注意
VST 3 不需要像 DirectX 那样进行插件注册。

⚠️ 警告
这些预定义文件夹中可以使用链接、符号链接或快捷方式。

定义了 3 级文件夹位置：

  • User：仅对当前登录用户可用
  • Global：对系统的所有用户可用
  • Application：仅在特定的音频应用程序内可用（本地插件）

ⓘ 注意
宿主应首先扫描优先级更高的层级。必须使用第一个找到的插件（针对给定的 Processor UID）。

macOS 平台上

在 macOS 平台上，宿主程序期望 VST 3 插件位于：

优先级位置路径
1用户/Users/$USERNAME/Library/Audio/Plug-ins/VST3/
2全局/Library/Audio/Plug-ins/VST3/
3全局/Network/Library/Audio/Plug-ins/VST3/
4应用程序$APPFOLDER/Contents/VST3/

ⓘ 注意
宿主在启动时按此顺序递归扫描这些文件夹（Global/Application）。

Windows 平台上

在 Windows 平台上，宿主程序期望 VST 3 插件位于：

优先级位置路径说明
1用户%LOCALAPPDATA%/Programs/Common/VST3/FOLDERID_UserProgramFilesCommon 本机位数：
• 32 位操作系统上为 32 位插件，
• 64 位操作系统上为 64 位插件
主要用于开发场景。
示例：C:\Users\MyUserName\AppData\Local\Programs\Common\VST3
2全局/Program Files/Common Files/VST3/FOLDERID_ProgramFilesCommon 本机位数：
• 32 位操作系统上为 32 位插件，
• 64 位操作系统上为 64 位插件
2全局/Program Files (x86)/Common Files/VST3/64 位 Windows 上的 32 位插件
3应用程序$APPFOLDER/VST3/

ⓘ 注意
宿主在启动时按此顺序递归扫描这些文件夹（Global/Application）。

Linux 平台上

在 Linux 平台上，宿主程序期望 VST 3 插件位于：

优先级位置路径说明
1用户$HOME/.vst3/
2全局/usr/lib64/vst3/在 Fedora 发行版中定义
3全局/usr/lib/vst3/
4全局/usr/local/lib64/vst3/
5全局/usr/local/lib/vst3/
6应用程序$APPFOLDER/vst3/

ⓘ 注意
宿主在启动时按此顺序递归扫描这些文件夹（User/Global/Application）。
