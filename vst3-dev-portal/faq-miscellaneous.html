问：返回值 tresult 是什么？

几乎所有 VST 3 接口都返回 tresult 值。这个整数值让调用方可以获得比只有 true 和 false 的布尔值更细分的错误/成功信息。

各种可能的值定义在 funknown.h 中。它们与 COM 中使用的值相同。检查 tresult 返回值时要小心，因为成功时返回的是 kResultOk，其整数值为 0：

// 这样写是错的!!!!!
if (component->setActive (true))
{
}
 
// 这样写是正确的!!!!!
if (component->setActive (true) == kResultOK)
{
}
// 或者
// 这样写也是正确的!!!!!
if (component->setActive (true) != kResultOK)
{
    // 错误信息....
}

问：哪些版本的 Steinberg 音序器支持 VST 3？

要加载 VST 3 插件，你至少需要：

  • 对于 VST 3.0.0，需要 Cubase/Nuendo 4.1.2。
  • 对于 VST 3.0.1 的功能，需要 Cubase 4.2。
  • 对于 VST 3.5.0 的功能，需要 Cubase 6.0。
  • 参见 其他 VST 3 宿主

问：为什么插件需要子类别？

在工厂实例中导出插件时（检查 againentry.cpp：DEF_CLASS2），你必须定义一个子类别字符串（可以由多个字符串组合而成，例如「Fx|Dynamics|EQ」）。

目前 Cubase/Nuendo 会用这个子类别字符串按以下方式组织插件菜单：

// 文件夹名称的计算（子类别 => 菜单中的文件夹）
"Fx"                        => "Other"
"Fx|Delay"                  => "Delay"
"Fx|Mastering|Delay"        => "Mastering"
"Spatial|Fx"                => "Spatial"
"Fx|Spatial"                => "Spatial"
"Instrument|Fx"             => if used as VSTi "" else if used as Insert "Other"
"Instrument|Sampler"        => "Sampler"
"Fx|Mastering|Surround"     => "Mastering\Surround"
"Fx|Mastering|Delay|Stereo" => "Mastering\Stereo"
"Fx|Mastering|Mono"         => "Mastering\Mono"

这个字符串只应作为插件类型的提示。无法定义所有类型。如果你希望新增类别，请在 VST 开发者论坛（https://sdk.steinberg.net）中讨论，我们可以把它们加入 SDK 的未来版本。

问：能否把一个插件同时定义为 Fx 和 Instrument？

可以。你可以使用 CString kFxInstrument（「Fx|Instrument」）作为子类别（参见 DEF_CLASS2）。这种情况下，Steinberg 音序器会允许用户把它作为效果器和乐器加载。作为乐器加载时（就当前的 Steinberg 音序器 <= 5.5 而言），插件的音频输入总线不会被启用。

问：能否向插件询问它支持哪些扬声器布局？

不能。在插件被实例化之前，没有办法向工厂询问某个插件支持哪些布局。宿主可以实例化插件，并在开始处理之前设置一些不同的扬声器布局，检查插件是否支持它们。

问：哪些版本的 Steinberg 音序器支持 VST 3 音符表达式？

要配合 VST 3 插件使用音符表达式，你至少需要 Cubase/Nuendo 6.0。

问：为 Mac 编译 AudioUnit 时，我在 AUCarbonViewBase.cpp 中遇到编译器错误。该怎么办？

由于 Mac CoreAudio SDK 中的一个问题（Apple 尚未修复），你必须对 AUCarbonViewBase.cpp 文件（位于 CoreAudio/AudioUnits/AUPublic/AUCarbonViewBase）打一个小补丁：
=> 改为：

HISize originalSize = { mBottomRight.h, mBottomRight.v };
// 改为
HISize originalSize = { static_cast<CGFloat>(mBottomRight.h),
                        static_cast<CGFloat>(mBottomRight.v) };

问：如何开发一个能作为 Panner 集成到 Nuendo 中的 SurroundPanner 插件？

要让 surroundPanner 插件在 Nuendo 中可作为 panner（推子后）选择，该插件的 subCategories 应为：kSpatial 或 kSpatialFx（以便也能作为插入效果使用）。例如：

DEF_CLASS2 (INLINE_UID_FROM_FUID(Steinberg::Vst::SPannerProcessor::cid),
            PClassInfo::kManyInstances,
            kVstAudioEffectClass,
            stringPluginName,
            Vst::kDistributable,
            Vst::PlugType::kSpatial ,
            FULL_VERSION_STR, // 插件版本（需要修改）
            kVstVersionString,
            Steinberg::Vst::SPannerProcessor::createInstance)

请确保你重写了函数「tresult PLUGIN_API setBusArrangements ...」，它让你能获取当前的总线布局。

问：如何校验我的插件？

有 Validator 命令行工具，可以在你编译完插件后自动调用（当你使用 SDK 定义的 cmake 时）。它会执行一些标准校验。第二个校验工具是 VST 3 插件测试宿主：查看其菜单项：View => Open plug-in Unit Tests Window

问：我生成的 VST 3 插件在我常用的宿主中不可见？

如果你的插件在 VST 3 插件测试宿主 中可见，但在你的 DAW 中不可见，可能的原因有：

  • 该宿主不支持 VST 3！请查看厂商（已知的 VST 3 宿主列表）
  • 该宿主在 Windows 上不会扫描 新的用户位置。你可以尝试使用主 VST3 文件夹，方法是在生成项目时设置 cmake 变量：
-DSMTG_PLUGIN_TARGET_USER_PROGRAM_FILES_COMMON=0
  • 该宿主无法解析符号链接！你可以尝试把你的插件直接复制到主 VST3 文件夹（C:\Program Files\Common Files\VST3）

问：什么是 GUID，如何创建它？

GUID 是 32 位十六进制数字。VST 3 使用 GUID（又称 UUID）来标识插件（处理器一个，控制器一个）。这些 Globally Unique IDentifiers 必须在创建新插件时生成，并且应当是唯一的。下面是 GUID 的一个示例：(0x84E8DE5F, 0x92554F53, 0x96FAE413, 0x3C935A18)

这必须用在处理器部分的声明中，就像 AGain 示例中这样（againentry.cpp）：

static const FUID AGainProcessorUID (0x84E8DE5F, 0x92554F53, 0x96FAE413, 0x3C935A18);

BEGIN_FACTORY_DEF (stringCompanyName, stringCompanyWeb, stringCompanyEmail)
	//---此工厂中包含的第一个插件-------
	// 它的 kVstAudioEffectClass 组件
	DEF_CLASS2 (INLINE_UID_FROM_FUID(AGainProcessorUID),
                PClassInfo::kManyInstances,	// 基数
				kVstAudioEffectClass,	// 组件类别
				stringPluginName,		// 这里是插件名称
				Vst::kDistributable,
				AGainVST3Category,		// 子类别
				FULL_VERSION_STR,		// 插件版本
				kVstVersionString,		// VST 3 SDK 版本
				Steinberg::Vst::AGain::createInstance)
    //...

如果你使用 VST 3 项目生成器，会自动为你生成新的 GUID。你也可以用 IDE（如 Visual Studio）创建 GUID，或使用一些在线生成器（例如：https://guidgenerator.com/）。

GUID 在 VST 3 中也用作接口标识符（在 VST SDK 源代码中查看使用 DECLARE_CLASS_IID 宏的地方）。
