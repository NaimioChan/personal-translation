引言

用于编辑控制器的扩展宿主回调接口：Vst:: IComponentHandler3

  • [host imp]
  • [扩展 Vst:: IComponentHandler]
  • [发布于：3.5.0]
  • [optional]

插件可以请求宿主为给定的导出参数 ID 创建上下文菜单，或创建通用上下文菜单。宿主可以用与参数 ID 相关的特定条目预填该上下文菜单，例如 "Show automation for parameter"、"MIDI learn" 等…… 插件可以通过两种方式使用该上下文菜单：

  • 通过 Vst:: IContextMenu 接口向菜单添加自己的条目，并调用 Vst:: IContextMenu::popup(...) 创建弹出菜单。使用示例见下文。
  • 提取宿主菜单条目，并把它们添加到插件自己创建的上下文菜单中。

ⓘ 注意
即使你不向菜单添加自己的条目，也建议使用这个上下文菜单接口，因为这被认为对用户有很大价值。

另请参见 Vst:: IContextMenu、Vst:: IContextMenuTarget。

示例

从宿主的角度看

例如，Cubase 在插件使用 createContextMenu 时，会往右键点击某个导出参数所打开的上下文菜单中加入自己的条目。在这个示例中，插件本身只添加 "Open UIDescription Editor" 条目。

ⓘ 注意
使用 VSTGUI 的插件自动具有此上下文菜单功能。

从插件的角度看

向上下文菜单添加插件特定的条目：

//------------------------------------------------------------------------
class PluginContextMenuTarget : public IContextMenuTarget, public FObject
{
public:
    PluginContextMenuTarget () {}
  
    virtual tresult PLUGIN_API executeMenuItem (int32 tag)
    {
        // 如果用户执行了插件的某个菜单条目，就会调用这里。
        // 宿主的条目不会调用它。
        switch (tag)
        {
            case 1: break;
            case 2: break;
        }
        return kResultTrue;
    }
  
    OBJ_METHODS(PluginContextMenuTarget, FObject)
    DEFINE_INTERFACES
        DEF_INTERFACE (IContextMenuTarget)
    END_DEFINE_INTERFACES (FObject)
    REFCOUNT_METHODS(FObject)
};
  
// 以下是创建上下文菜单的代码
void popupContextMenu (IComponentHandler* componentHandler, IPlugView* view, const ParamID* paramID, UCoord x, UCoord y)
{
    if (componentHandler == 0 || view == 0)
        return;
    auto handler = Steinberg::U::cast<IComponentHandler3> (componentHandler);
    if (handler == nullptr)
        return;
    if (IContextMenu* menu = handler->createContextMenu (view, paramID))
    {
        // 这里可以添加你的条目（可选）
        PluginContextMenuTarget* target = new PluginContextMenuTarget ();
         
        IContextMenu::Item item = {0};
        UString128 ("My Item 1").copyTo (item.name, 128);
        item.tag = 1;
        menu->addItem (item, target);
  
        UString128 ("My Item 2").copyTo (item.name, 128);
        item.tag = 2;
        menu->addItem (item, target);
        target->release ();
        //--添加新条目结束
         
        // 这里将弹出上下文菜单（并等待用户交互）
        menu->popup (x, y);
        menu->release ();
    }
}
