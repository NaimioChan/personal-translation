版本 3.6.7（2017/03/03）

  • Linux 支持预览（请查看 ）：为构建 VST 3 插件配置 Linux

  • 许可已变更！请阅读新的 VST 3 许可问题。

  • 使用 cmake 作为项目生成器：如何使用 cmake 构建 VST 3 插件

  • 这是 SDK 最后一个支持 C++98 的版本，未来的版本将使用 C++11。

  • 示例：

    • 新增 VST 3 宿主实现示例：
      • 新增 HostEditor 应用：跨平台（Win/macOS/Linux）独立程序，可打开 VST 3 插件的 UI
    • 更新 validator 应用以支持 Linux
    • AGain 插件更新：
      • 改用 VSTGUI 4，而不再使用 VSTGUI 3
      • 支持 64 位处理（基于模板）
    • 所有基于 VSTGUI 4 的示例现在在 Windows 上支持 HiDPI
    • 修复 mda 插件示例中的程序变更持久化
    • 移除 Xcode 和 Visual Studio 项目，请改用 cmake！
    • 在 Windows 上，我们将 VST 3 插件链接到 MultiThreaded DLL 运行时库（它会使用 Universal C Runtime 库，对于低于 Win 8.1 的旧版 Windows，你可能需要从以下地址安装这些库：https://support.microsoft.com/en-us/kb/2999226）

  • 不再支持 VSTGUI 3.x（已从 SDK 中移除），但你仍可从 github 下载：https://github.com/steinbergmedia/vstgui

  • 插件包装层：

    • VST 3 - Audio Unit 包装层：
      • 修复 AU 包装层的 MIDI 程序变更问题（应为 data1 而不是 data2）。
    • VST 3 - VST 2.x 包装层：
      • 修复 macOS 上的调整大小问题。
      • 修复使用旁通参数时 VST 3 ParamID 与 VST 2 paramID 之间的映射。
