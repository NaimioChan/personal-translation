Windows 上的准备工作

VST 3 的 Microsoft Visual Studio 工程在使用 SDK 中包含的 cmake 生成时，默认会为每个构建出的插件在 官方 VST 3 文件夹（C:\Program Files\Common Files\VST3）中创建符号链接。如果你没有相应权限（例如不是管理员），在该文件夹中无法直接写入这些符号链接，要解决此问题有 4 种方法：

解决方案 1

如果你不想创建这些链接，请带以下参数调用 cmake：

-DSMTG_CREATE_PLUGIN_LINK=0

解决方案 2

你可以选择 新的用户位置（这是默认值）来存放 VST 3 插件，该位置对普通用户来说不应有权限问题，请带以下参数调用 cmake：

-DSMTG_PLUGIN_TARGET_USER_PROGRAM_FILES_COMMON=1

解决方案 3

为了在 Windows 上允许创建这些符号链接，你可以通过启用 开发者模式 来修改 "Settings > System > For developers"：

解决方案 4

为了在 Windows 上允许创建这些符号链接，你需要调整 Windows 的组策略，该功能默认只在 Windows 专业版 中可用，在 Windows 家庭版 中不可用。在 Windows 家庭版 中，你必须先安装它，然后才能更改该文件夹（C:\Program Files\Common Files\VST3）的权限。有些网页展示了如何操作，例如这个：https://www.itechtics.com/enable-gpedit-msc-windows-11。

组策略编辑器可用后，你需要这样启动它：

  • 在 Windows 搜索框中输入 run，启动「运行」应用，然后输入 gpedit.msc

或

  • 在 Windows 搜索框中输入 Edit group policy：

现在 本地组策略编辑器 已启动：

  • 导航到：

Computer Configuration => Windows Settings => Security Settings =>Local Policies => User Rights Assignment => Create symbolic links

在这里，你可以设置哪些用户可以创建符号链接，添加你的用户名。
