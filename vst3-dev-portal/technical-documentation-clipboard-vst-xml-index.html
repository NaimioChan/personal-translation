剪贴板 VST-XML 格式是一种简单的基于文本的 XML 定义，用于通过拖放（基于文本）或复制粘贴（使用操作系统剪贴板）来交换与媒体相关的数据。

它最初设计用于支持 Cubase 与 HALion 之间的音频文件交换。随着时间推移，同一机制被扩展用于传输更多的音乐元素及其上下文。

它能实现什么

剪贴板 VST-XML 允许应用程序传输的不只是单纯的文件引用。

通常传输的元素包括：

  • 音频文件/片段（自 1.0 版起）
  • 速度（自 1.1 版起）
  • 和弦（自 1.2 版起）
  • 音阶（自 1.3 版起）

附加上下文数据

XML 载荷可以包含额外信息，帮助在不同应用程序和插件之间保留编辑上下文，例如：

  • 颜色
  • 工程时间位置
  • 其他元素专属的元数据

这使得拖放与复制粘贴工作流程比单纯的文件传输更有用，因为接收方应用程序和插件可以重建音乐与视觉上下文。

典型工作流程

  1. 像 HALion 这样的源插件把所选元素序列化为剪贴板 VST-XML 文本。
  2. 用户执行拖放或复制粘贴。
  3. 像 Cubase 这样的目标应用程序解析该 XML，并导入元素及其元数据。

支持剪贴板 VST-XML 的已知应用程序和插件

  • Cubase
  • Dorico
  • Nuendo
  • HALion
  • Padshop
  • Studio One
  • Soundly
  • Wavelab

格式说明

本节根据当前的文档类型定义（VST-XML-1.4.dtd）说明剪贴板 VST-XML 的结构。

根节点：vst-xml

项目定义
属性version（必需）
必需的子节点sourceApp
可选的子节点region、chord、scale、signature 子节点

节点：sourceApp

项目定义
内容包含发送方应用程序名称的文本值

节点：region

项目定义
属性id（必需）、type（可选：join 或 silence）、channelID（可选）
必需的子节点filename、start、end 子节点
可选的子节点name、tempo、rootkey、projectTime、color、loop、segment、signature 子节点

节点：segment

项目定义
必需的子节点filename、start、length 子节点
可选的子节点fileOffset

节点：loop

项目定义
属性type（可选：release）
必需的子节点start、end 子节点

节点：chord

项目定义
属性id（必需）
必需的子节点keyNote、pitches、mask 子节点
可选的子节点name、projectTime、bassNote、color 子节点

节点：scale

项目定义
属性id（必需）
必需的子节点mask、keyNote 子节点
可选的子节点name、projectTime、displayName、color 子节点

节点：signature

项目定义
必需的子节点numerator、denominator 子节点
可选的子节点projectTime

叶子标签的含义

标签含义
name人类可读的标签
displayName音阶的替代/显示标签
filename音频文件路径
start起始位置或偏移（取决于上下文）
end结束位置（取决于上下文）
length段长度
fileOffset基于段的载荷所使用的文件偏移
projectTime时间线位置；需要 domain 属性
tempo速度值
rootkey根音值
pitches以文本表示的和弦音高集合
keyNote和弦/音阶的键位音符值
bassNote和弦低音音符值
mask类似位掩码的和声/音阶编码
color颜色值（用于 UI/上下文）
numerator拍号分子
denominator拍号分母

属性参考

属性用于取值
idregion、chord、scale 节点任意文本（例如整数计数器），必需
typeregionjoin、silence 两种值
typelooprelease
channelIDregion任意文本（通常是 GUID）
domainprojectTimequarterNotes 或 seconds（必需）

剪贴板 VST-XML 示例

在第 16 拍位置插入一个音频文件

<?xml version="1.0"?>
<vst-xml version="1.3">
    <sourceApp>MyApp</sourceApp>
    <region id="1" channelID="{B48CE04A-8FE5-4192-BBEE-D178F7B55C26}">
        <name>Region 1</name>
        <filename>c:\toto.wav</filename>
        <start>100</start>
        <end>44200</end>
        <projectTime domain="quarterNotes">16</projectTime>
    </region>
</vst-xml>

在两条不同轨道上分别于 4s 处和第 8 拍插入一个音频文件

<vst-xml version="1.3">

        <start>100</start>
        <end>44200</end>
        <projectTime domain="seconds">4.0</projectTime>
        <color>#91959bff</color>
    </region>

段与循环的合并

<?xml version="1.0"?>
<vst-xml version="1.3">
    <sourceApp>WaveLab</sourceApp>
    <region type="join" id="4" channelID="{B48CE04A-8FE5-4192-BBEE-D178F7B55C26}">
        <name>my Region</name>
        <projectTime domain="seconds">33.5</projectTime>
        <segment>
            <filename>E:\Temp\Audio\Drum2.wav</filename>
            <start>0</start>
            <length>1234</length>
        </segment>
        <segment>
            <filename>c:\toto.wav</filename>
            <start>1227</start>
            <length>44</length>
        </segment>
        <color>#12345678</color>
    </region>
    <region id="1234" channelID="{B48CE04A-8FE5-4192-BBEE-D178F7B55C26}">
        <name>Region 1</name>
        <filename>E:\Temp\Audio\Drum2.wav</filename>
        <start>0</start>
        <end>1234</end>
        <projectTime domain="quarterNotes">16</projectTime>
        <loop>
            <start>0</start>
            <end>1002</end>
        </loop>
        <loop type="release">
            <start>0</start>
            <end>1002</end>
        </loop>
        <tempo>120.0</tempo>
        <rootkey>36</rootkey>
        <signature>
            <numerator>3</numerator>
            <denominator>4</denominator>
        </signature>
    </region>
</vst-xml>
