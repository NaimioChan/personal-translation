版本 3.6.8（2017/11/08）

  • 许可协议有变更！请查看（VST 3 许可问题）。

  • 新的 Steinberg VST 使用准则 PDF

  • 此 SDK 版本要求编译器支持 C++11。在 Windows 上最低需要 Visual Studio 2015！

  • Linux 支持处于 Beta 阶段。

  • 接口变更：

    • 新增 Vst::IComponentHandlerBusActivation（宿主）：允许插件请求宿主激活或停用特定总线（对具有多个输出的乐器很有用）。

  • 新增标志位/枚举：

    • 新增预定义 Ambisonics 扬声器布局：一阶、二阶和三阶（ACN 排序与 SN3D 归一化）：kAmbi1stOrderACN、kAmbi2cdOrderACN、kAmbi3rdOrderACN 及其对应的扬声器：kSpeakerACN0...kSpeakerACN15。
    • 新增预定义 3D 扬声器布局：k70_4、k71_4。

  • 示例：

    • 新增 VST 3 宿主实现示例：
      • 文件夹重组：宿主示例位于单独的文件夹：public.sdk/samples/vst-hosting。
    • 新增 AudioHost（AudioHost - 跨平台独立程序），展示如何在 Jack 环境中集成 VST 3 插件！这需要 Jack Audio（http://www.jackaudio.org），仅在 Linux 下测试过，但应可在 Windows 32 位和 Mac 上工作。

  • 插件包装层：

    • 新增 Audio Unit v3（AUv3）包装层（VST 3 - Audio Unit v3 包装层）。
    • 新增 AAX 包装层（VST 3 - AAX 包装层）。请注意，要为你的插件使用此 AAX 包装层，必须下载 AAX SDK（联系 AVID），已用 AAX SDK 2.3.0 版测试。
