版本 3.6.9（2018/03/01）

  • VSTGUI 4.6

    • 更新到 VSTGUI 4.6。
    • 包含新的 UI 元素：支持音符表达式的 KeyboardView。

  • 接口变更：

    • 重命名一些宏定义：
      • PLATFORM_64 => SMTG_PLATFORM_64
      • WINDOWS => SMTG_OS_WINDOWS
      • MAC => SMTG_OS_MACOS
      • LINUX => SMTG_OS_LINUX
    • 将 Speaker Arrangement 从 vsttypes.h 提取到 vstspeaker.h。
    • 新增 kNoParamId 常量，用于未初始化的参数 id。

  • CMake：

    • 重新组织 cmake 文件。

  • 示例：

    • 修复 Validator 状态测试。
    • NoteExpressionSynth 使用新的 KeyboardView。
    • 新增 HelloWorld VST 3 插件（模板）。

  • 插件包装层：

    • VST 3 - Audio Unit 包装层：针对较新 XCode 版本的修复与适配。
    • Audio Unit v3（AUv3）包装层（VST 3 - Audio Unit v3 包装层）：若干修复，并添加 cmake。
    • AAX 包装层（VST 3 - AAX 包装层）：添加旁通和 VU 参数支持。
    • interappaudio：改进、修复，并添加 cmake。

  • 辅助类：

    • 新增环形缓冲区类（ringbuffer.h）。
