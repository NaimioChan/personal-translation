版本 3.7.8（2023/05/15）

  • 接口变更：

    • 破坏性变更：VST 3.7.5 引入的 moduleinfo.json 文件现在位于 Contents/Resources 文件夹中，以符合 macOS 上的代码签名要求。
    • 新增 Microsoft 统一 Arm64X 二进制定义，用于 VST 3 插件。
    • 新类别：kFxVocals，用于人声专用的工具。
    • 新增标志位/枚举：
      • 新增预定义 Ambisonics 扬声器布局：
        • kAmbi4thOrderACN，搭配新扬声器：kSpeakerACN16 至 kSpeakerACN24，
        • kAmbi5thOrderACN、kAmbi6thOrderACN、kAmbi7thOrderACN：从索引 0 开始，破坏了扬声器位兼容性。同时包含一些辅助函数，用于在 1 至 4 阶与 5 至 7 阶之间映射扬声器索引（convertSpeaker_Ambi_1234Order_to_Ambi567Order 和 convertSpeaker_Ambi_567Order_to_Ambi1234Order）。

  • VSTGUI 更新至 4.12.3

  • CMake

    • 修复「当 vst3sdk 作为子模块时，示例插件不会被构建 - 提供一个选择开关会很有用」（Issue#94）。
    • 修复 CMake 因错误的 $ 转义而失败（Issue#100）。
    • 破坏性变更：选项重命名为更明确的名称：
      • SMTG_ADD_VST3_HOSTING_SAMPLES => SMTG_ENABLE_VST3_HOSTING_EXAMPLES
      • SMTG_ADD_VST3_PLUGINS_SAMPLES => SMTG_ENABLE_VST3_PLUGIN_EXAMPLES
      • SMTG_ADD_VSTGUI => SMTG_ENABLE_VSTGUI_SUPPORT

  • 插件包装层：

    • Audio Unit 包装层：
      • AUv3 包装层：
        • 移除重复的 -loadAudioFile: 方法声明（PR#46）。
        • 修复 iOS 构建错误（PR#47）
        • 修复调用 restartComponent（kParamTitlesChanged）时会重置所有参数值的问题（Issue#45）
      • AUv2Wrapper 包装层：
        • 修复「AUv2 编辑器并不总是可用」（Issues#108）
        • 修复 AUv2 包装层中 SMTG_AUView setFrame 的无限递归调用

  • 示例：

    • 改进部分插件示例中的静音标志处理。
    • Hello World VST 3 插件示例已迁移到 github！

  • 辅助类：

    • 修复在 Linux 上使用 gcc 12 的构建错误（moduleinfoparser.cpp）（PR#49）。
    • 修复由于缺少 Steinberg::SystemClipboard::copyTextToClipboard() 实现而无法在 Linux 上完整构建的问题（Issue#102）。
    • 修复在非 Windows 平台上 validator 输出的 Controller CID 被截断的问题（Issue#109）。
    • 添加安全检查（PR#51）。
    • 修复 moduleinfotool.exe 在 Windows 上的 UTF8 规范化问题。
    • 提高 FStreamer::readString8 的健壮性（PR#5）。
    • 修复警告：循环变量 'flag' 绑定到由类型 'std::optionalJSON::Object::value_type' 的区间产生的临时值
    • 修复在 MinGW 8.1 上无法屏蔽的警告（PR#14）。
    • 移除在 Linux 上无法屏蔽的警告（PR#6。
    • 修复 module_linux.cpp 中的语言标准检查（PR#53）。
    • 修复 module.cpp 中 std::move 调用的限定，以消除 -Wunqualified-std-cast-call 警告（PR#53）。
    • 修复 moduleinfo.h 中 <cstdint> 的包含，以确保定长整数类型可见（PR#53）。

  • Validator 工具：

    • 当某个单位包含过多参数时添加提示信息

  • VST3PluginTestHost v3.5 版本：

    • 新增面向 Windows on Arm 的原生 Arm64EC 版本：允许加载为 Arm64EC 构建的 VST 3 插件。
    • 新增 Windows 内置 ASIO 驱动，支持 x64 和 Arm64EC。
