引言

允许插件与宿主之间就当前使用了哪些键位切换进行信息交换。

扩展的插件接口 Vst:: IEditController，用于键位切换支持：Vst:: IKeyswitchController

  • [plug imp]
  • [extends Vst:: IEditController]
  • [发布于：3.5.0]
  • [optional]

一些乐器插件支持键位切换功能，允许用户在演奏音符时在不同分层音色之间切换。为此，用户必须在演奏新音符之前按下与目标分层关联的特定按键。

一个典型例子是带小提琴音色的采样播放器插件，它可以包含不同的分层或奏法：pizzicato、legato、tremolo 等。在演奏新音符之前按下和/或保持某个特定按键（例如 C-1），插件就会选择演奏 pizzicato；使用 D-1 则演奏 legato，依此类推。

借助 VST Expression Map（Steinberg 在 Cubase 5 中引入），这些键位切换可以在乐谱编辑器中使用，把某个符号（奏法）关联到一个音符。每次演奏该音符时，就会使用相应的键位切换（作为 noteOn 事件发送给插件）。

为了帮助创建这样的映射，VST 3.5 定义了一个新接口 Vst:: IKeyswitchController。如果某个（乐器）插件支持该接口，宿主就可以从插件那里获取事件总线给定通道当前使用的键位切换集合（megatrigg / 奏法：Vst::KeyswitchInfo），然后自动使用它们（就像在 Cubase 6 中那样）来创建 VST Expression Map。

它是如何工作的？

以下是分步示例。我们需要一个带 1 个事件总线的插件，它是单音色的（1 通道），并支持 2 个键位切换：

  1. 该乐器插件应有一个输入事件总线（也可以是更多个）：
//------------------------------------------------------------------
tresult PLUGIN_API MyExampleProcessor::initialize (FUnknown* context)
{
    //---始终初始化父类-------
    tresult result = AudioEffect::initialize (context);
    if (result == kResultTrue)
    {
        // 我们需要一个立体声输出
        addAudioOutput (STR16 ("Stereo Output"), SpeakerArr::kStereo);

        // 创建事件输入总线（1 个总线，仅 1 个通道）
        addEventInput (STR16 ("Event Input"), 1);
    }
    return result;
}
  1. 控制器应具有 Vst:: IKeyswitchController 接口，以下为类声明中的写法：
//------------------------------------------------------------------
class MyExampleController: public EditController, public IKeyswitchController
{
public:
    //...
    //---来自 IKeyswitchController
    virtual int32 PLUGIN_API getKeyswitchCount (int32 busIndex, int16 channel);
    virtual tresult PLUGIN_API getKeyswitchInfo (int32 busIndex, int16 channel, int32 keySwitchIndex, KeyswitchInfo& info);
    //...

    OBJ_METHODS (MyExampleController, EditController)
    DEFINE_INTERFACES
        DEF_INTERFACE (IKeyswitchController)
    END_DEFINE_INTERFACES (EditController)

    REFCOUNT_METHODS(EditController)
    //...
};
  1. 现在我们必须实现 Vst:: IKeyswitchController 接口（只有 2 个函数）；在我们的示例中，Vst:: IKeyswitchController::getKeyswitchCount 应返回 2（2 个键位切换）：
//------------------------------------------------------------------
int32 MyExampleController::getKeyswitchCount (int32 busIndex, int16 channel)
{
    // 我们只接受第一个总线和 1 个通道
    if (busIndex == 0 && channel == 0)
        return 2;
    return 0;
}
  1. 然后，我们必须实现 Vst:: IKeyswitchController::getKeyswitchInfo，它让宿主了解插件支持什么：
//------------------------------------------------------------------
tresult PLUGIN_API MyExampleController::getKeyswitchInfo (int32 busIndex, int16 channel, int32 keySwitchIndex, KeyswitchInfo& info)
{
    // 我们只接受第一个总线和 1 个通道，并且只支持 2 个键位切换
    if (busIndex == 0 && channel == 0 && (keySwitchIndex == 0 || keySwitchIndex == 1)
    {
        memset (&info, 0, sizeof (KeyswitchInfo));

        // 这种情况下，我们希望键位切换在演奏期间保持按下
        info.typeId = kKeyRangeTypeID;

        // 我们可以用 keyRemapped 让键位切换更易用（靠近乐器可用的键位范围）
        // 注意不要使键位切换与真实按键（演奏音）重叠

        if (keySwitchIndex == 0)
        {
            USTRING ("Accentuation").copyTo (info.title, 128);
            USTRING ("Acc").copyTo (info.shortTitle, 128);

            // 如果用户持续按住 C-1 或 C#-1 或 C-0，则应演奏 Accentuation 音色
            info.keyswitchMin = 12; // C-1
            info.keyswitchMax = 13; // C#-1
            info.keyRemapped  = 24; // C-0
        }
        else
        {
            USTRING ("Softly").copyTo (info.title, 128);
            USTRING ("Soft").copyTo (info.shortTitle, 128);

            // 如果用户持续按住 D-1 或 D#-1 或 D-0，则应演奏 Softly 音色
            info.keyswitchMin = 14; // D-1
            info.keyswitchMax = 15; // D#-1
            info.keyRemapped  = 26; // D-0
        }

        info.unitID = -1; // 未使用
        info.flags = 0;  // 未使用

        return kResultTrue;
    }
    return kResultFalse;
}
  1. 最后一步，在处理器组件中，我们必须调整 process 调用，以切换到所需的奏法：
//------------------------------------------------------------------
tresult MyExampleProcessor::process (ProcessData& data)
{
    // ....

    // 获取输入事件队列
    IEventList* inputEvents = data.inputEvents;
    if (inputEvents)
    {
        Event e;
        int32 numEvents = inputEvents->getEventCount ();

        // 遍历每个事件进行检查..
        for (int32 i = 0; i < numEvents; i++)
        {
            if (inputEvents->getEvent (i, e) == kResultTrue)
            {
                switch (e.type)
                {
                    //-----------------------
                    case Event::kNoteOnEvent:
                    {
                        // 这里是音符开
                        // 检查这是否是键位切换
                        switch (e.noteOn.pitch)
                        {
                            // Accentuation 键位切换
                            case 12:
                            case 13:
                            case 24:
                                currentLayer = kAccentuationLayer;
                                break;

                            // Softly 键位切换
                            case 14:
                            case 15:
                            case 26:
                                currentLayer = kSoftlyLayer;
                                break;

                            default:
                                // 在当前层中演奏该音符
                                // ...
                        }
                    }   break;

                    //-----------------------
                    case Event::kNoteOffEvent:
                    {
                        // 检查键位切换是否已释放
                        switch (e.noteOff.pitch)
                        {
                            // Accentuation 键位切换
                            case 12:
                            case 13:
                            case 24:
                            case 14:
                            case 15:
                            case 26:
                                currentLayer = kDefaultLayer;
                                break;
                            default:
                                // 已释放的音符……
                                //...
                        }
                    }   break;
                    //....
                }
            }
        }
    }
    //...
}
