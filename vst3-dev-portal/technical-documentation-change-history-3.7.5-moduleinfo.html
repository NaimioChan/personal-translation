引言

插件包中新增的 moduleinfo.json 文件（位于 Resources 文件夹）以兼容 JSON5 的格式描述插件的内容。其中包含一份兼容性列表，例如允许某个 VST 3 插件替换指定的 VST 2 插件（请查看此处，了解如何为旧的 VST 1/VST 2 插件创建 UID）。

  • [plug imp]
  • [released: 3.7.5]

插件的模块信息文件：moduleinfo.json

请查看 moduleinfo.json，了解有关此文件内容的更多信息。

IPluginCompatibility

如果插件由于未组织成 bundle 形式的包而无法提供 moduleinfo.json，则可以将新接口 IPluginCompatibility 添加到插件工厂中。

ⓘ 注意
如果需要兼容性功能，建议使用 moduleinfo.json 或 IPluginCompatibility。

ⓘ 注意
如果你不提供与任何先前插件版本的兼容性，则不建议实现 IPluginCompatibility。如果暴露了这个对象，宿主就会期望你用它提供兼容性信息；否则它毫无用处。

示例

在 plugentry.cpp 中：

//------------------------------------------------------------------------
class PluginCompatibility : public FObject, public IPluginCompatibility
{
  public:
    //...
    tresult PLUGIN_API getCompatibilityJSON (IBStream* stream) override
    {
        // 此处，UID 为 BD58B550F9E5634E9D2EFF39EA0927B1 的插件可以替换
        // UID 为 AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA 的插件，以及
        // UID 为 BBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBB 的插件
      /* write the JSON compatibility array into the stream
      [
          {
              "New": "BD58B550F9E5634E9D2EFF39EA0927B1",
              "Old": [
                  "AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA",
                  "BBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBB",
              ],
          }
      ]
      */
	    return kResultTrue;
    }
    //... 
};

//------------------------------------------------------------------------
static FUnknown* createCompatibilityInstance (void* context)
{
	return (IPluginCompatibility*)new PluginCompatibility;
}

//------------------------------------------------------------------------
BEGIN_FACTORY_DEF (stringCompanyName, stringCompanyWeb, stringCompanyEmail)

    //...
    DEF_CLASS2 (INLINE_UID_FROM_FUID(PluginCompatibilityUID),
				PClassInfo::kManyInstances,
				kPluginCompatibilityClass,
				stringPluginName,
				Vst::kDistributable,
				"",
				FULL_VERSION_STR,
				kVstVersionString,
				createCompatibilityInstance)
