目标

本教程讲解如何使用静音标志。

静音标志是怎么回事？

在 process 调用中，插件有时需要知道音频输入里究竟真的有音频还是只有静音（缓冲区里全是 0！。这对宿主也有用：它可以知道插件是否会输出静音音频。例如，对于没有内容可演奏的乐器插件（没有输入事件到来），宿主可以通知处理链中后续的插件。这有助于减少计算量并提升整体性能。

但它究竟是如何工作的？下面一节将展示如何在 process 调用中获取这一信息，以及如何把它传递到插件的音频输出。

静音标志是 AudioBusBuffers（silenceFlags）的一部分，它在 process 调用中由宿主传给插件，再由插件传回宿主。

插件收到静音的音频输入

//-----------------------------------------------------------------------
tresult PLUGIN_API AGain::process (ProcessData& data)
{
    //...

    //---检查是否为静音---------------
    // 静音标志是一个位掩码，每一位对应总线的一个通道
    // （例如立体声总线的 L 和 R）。
    // 这里只检查第一个输入总线是否整体静音（立体声情况下：L 和 R 都静音）
    if (data.inputs[0].silenceFlags != 0) // 如果标志不为零 => 说明输入是静音的！
    {
        // 在这个示例中我们对输入信号施加增益
        // 由于已知输入只填满了零，输出也将只填满零！
        for (int32 i = 0; i < numChannels; i++)
        {
            // 如果输出缓冲区与输入缓冲区相同，就无需清除输出缓冲区，
            // 因为已知输入填满了零；否则需要清除输出缓冲区
            if (in[i] != out[i])
            {
                memset (out[i], 0, sampleFramesSize); // 这比对每个采样施加增益更快！
            }
        }

        // 现在必须告知宿主我们的输出也是静音的
        // 只需设置输出总线的 silenceFlags 即可：
        data.outputs[0].silenceFlags = ((uint64)1 << numChannels) - 1; // 立体声时该值为 3（二进制 0011）

        // 到此完成，可以返回了
        return kResultTrue;
    }

ⓘ 注意
当宿主启用静音标志时（输出的静音标志将由宿主设为无静音（=0）），清除输入缓冲区（设为接近零的值，如 10e-7，以避免反规格化问题）是宿主的责任。

插件产生静音输出

//-----------------------------------------------------------------------
tresult PLUGIN_API AGain::process (ProcessData& data)
{
    //...

    //---检查是否为静音---------------
    // 见上文


    // 在某些条件下我们的输出缓冲区可能是静音的：
    // 例如这里的增益可能被设为 0 或小于某个阈值。
    // 我们必须告知宿主我们的输出也是静音的
    // 只需设置输出总线的 silenceFlags 即可：
    if (gain < 0.0000001)
    {
        for (int32 i = 0; i < numChannels; i++)
        {
            // 确保把输出置零
            memset (out[i], 0, sampleFramesSize);
        }
        // 这会把所有通道置为 1
        data.outputs[0].silenceFlags = ((uint64)1 << numChannels) - 1; // 立体声时该值为 3（二进制 0011）
    }
    else
    {
        //...
    }

ⓘ 注意
插件如果产生静音输出，就有责任清除（置零）其输出缓冲区，并正确设置输出的静音标志。

处于旁通状态时

在旁通模式下，插件必须确保其输出与输入处于相同状态：

//-----------------------------------------------------------------------
tresult PLUGIN_API AGain::process (ProcessData& data)
{
    //...

    //---检查是否为静音---------------
    // 见上文


    //---旁通模式下输出应当与输入相同-----
    if (bBypass)
    {
        for (int32 i = 0; i < numChannels; i++)
        {
            // 如果缓冲区相同就不需要复制
            if (in[i] != out[i])
            {
                memcpy (out[i], in[i], sampleFramesSize);
            }
        }
        // 这里必须把输入的静音标志转发到输出！
        // 这对宿主通知处理链中的下一个插件非常重要
        data.outputs[0].silenceFlags = data.inputs[0].silenceFlags;
    }
    else
    {
        //...
    }
