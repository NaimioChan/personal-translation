版本 3.6.10（2018/06/11）

  • Windows 上插件格式的新定义，包含图标支持（VST 3 Bundle：VST 3 位置 / 格式）。

  • 支持 VST 3 Bundle 内的快照。

  • CMake：

    • 调整 cmake 文件，以更好地集成用户项目。
    • 修复 AudioUnit 的通用二进制支持。

  • 插件包装层：

    • 重构 AAX/VST 2 包装层。
    • AAX 包装层（VST 3 - AAX 包装层）：
      • 修复旁通行为。
      • 修复初始信号延迟。
      • 修复与 VST 2 冲突的参数索引问题。

  • 辅助类：

    • 修复 SingleComponentEffect 类中的 activateBus 问题。
    • 修复环形缓冲区类的问题。
