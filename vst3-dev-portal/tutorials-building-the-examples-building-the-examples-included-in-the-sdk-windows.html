在 Windows 上构建 SDK 自带的示例

目标

本教程讲解如何设置计算机并创建用于编译 VST SDK 随附的 VST 3 音频插件示例的环境。这些示例包括简单的 DSP 效果器（Gain、压缩器、延迟……）、合成器乐器，以及一些展示如何处理特定 VST 3 特性（音符表达式、程序变更、通道信息上下文……）的插件。

它们可以加载到 Cubase、WaveLab 等 VST 3 宿主中。

第 1 部分：获取并安装 VST SDK

有关下载 SDK，请参见本节「如何为 VST 3 配置系统」。

从以下地址下载 cmake：https://cmake.org/download/，或使用适用于你的操作系统的包管理器。

第 2 部分：在 Windows 上构建示例

  • 创建一个用于构建的文件夹，并移动到该文件夹（使用 cd）：
mkdir build
cd build
  • 生成解决方案/工程：指定 CMakeLists.txt 所在工程的路径：
cmake.exe -G "Visual Studio 17 2022" -A x64 ../vst3sdk
or without symbolic links
cmake.exe -G "Visual Studio 17 2022" -A x64 ../vst3sdk-DSMTG_CREATE_PLUGIN_LINK=0

ⓘ 注意
你可以在 cmake 在线文档（https://cmake.org/documentation/）中找到不同 Visual Studio 生成器的字符串定义

  • 你必须调整 Windows 的权限，以允许为 VST 3 插件创建符号链接：点击此处！
  • 构建插件（你也可以使用 Visual Studio）：
msbuild.exe vstsdk.sln
(or alternatively, for example, for release)

cmake --build . --config Release

使用 cmake-gui 构建

  • 启动 cmake-gui 应用，它是 cmake 安装的一部分（https://cmake.org/download/）

  • Browse Source...：选择 VST3_SDK 文件夹
  • Browse Build...：选择用于创建输出（工程等）的文件夹。通常是名为 build 的文件夹
  • 你可以勾选 SMTG Options
  • 按下 Configure，在打开的窗口中选择生成器：例如 "Visual Studio 17 2022"

  • 按下 Generate 创建工程
  • 打开你的目标 IDE，编译解决方案/工程。
