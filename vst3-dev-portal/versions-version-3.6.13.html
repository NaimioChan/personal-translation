版本 3.6.13（2019/04/08）

  • VSTGUI 4.8

    • 新增 VSTGUI::CSegmentButton 选择模式 kSingleToggle，以及样式 kHorizontalInverse 和 kVerticalInverse。

  • 接口变更：

    • 新增 PluginType kInstrumentPiano（用于钢琴音色的乐器）。

  • CMake：

    • 小幅重构。
    • 添加对 Visual Studio 2020 的支持。

  • 示例：

    • 在 HostChecker 插件中再添加一些检查。
    • 为 editorhost 添加一些调试输出。

  • 插件包装层：

    • AAX 包装层（VST 3 - AAX 包装层）：
      • 加载预设不应覆盖当前的旁通状态。

  • VST3PluginTestHost：

    • 支持 IPlugInterfaceSupport。
    • 支持 MPE。
    • 可以两次打开同一个插件的编辑器。
