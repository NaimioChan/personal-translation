版本 3.5.1（2011/11/11）

  • 接口变更：

    • 由于 IContextMenu 系列接口缺少调用约定，我们不得不为这组接口生成新的 iid，Steinberg 宿主将会更新（自 6.0.5 起）以正确支持这组接口。已经在使用的旧接口在 Steinberg 宿主中将继续受到支持。对此问题深表歉意……

  • 辅助类：

    • EditController 现在是 SingleComponentEffect 的基类之一。
      • 如果你以前使用过 SingleComponentEffect，请确保现在将 vsteditcontroller.cpp 从项目中排除（如果它曾在项目中）。
    • EditControllerEx1 新增函数：setProgramName。
    • ProgramList 新增函数：setProgramName。

  • 示例：

    • 添加 Visual Studio 2010 项目。
    • 移除 Visual Studio 2003 项目。
    • 修复 AGain Single Component Effect。

  • VSTGUI 4.0

    • 更新到 4.0 最终版本。

  • 插件包装层：

    • VST 3 - VST 2.x 包装层：
      • 修复销毁编辑器时的一个问题。
    • VST 3 - Audio Unit 包装层：
      • 修复编辑器初始大小的问题。
      • 针对 GetParameterInfo 的优化。

  • VST3PluginTestHost：

    • 新功能：将 VST 3 预设转换为 VST 2 预设（fxp 或 fxb）。
