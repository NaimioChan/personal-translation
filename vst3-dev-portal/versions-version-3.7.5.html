版本 3.7.5（2022/05/16）

  • 接口变更：

    • 新增 moduleinfo.json 文件：moduleinfo.json 以兼容 JSON5 的格式描述插件的内容。它包含工厂信息（见 PFactoryInfo）、所含的类（见 PClassInfo）、包含的快照，以及所含类的兼容性列表。例如，该兼容性列表允许一个 VST 3 插件替换指定的 VST 2 插件。
    • 新增接口 IPluginCompatibility，位于 pluginterfaces/base/iplugincompatibility.h，在无法使用 moduleinfo.json 文件时使用。
    • 修复使用 Visual Studio 2022 构建的问题（https://github.com/steinbergmedia/vst3sdk/issues/90）。
    • 修复 Windows ARM64EC 目标的警告。
    • 通过使用 SMTG_CONSTEXPR 修复 constexpr 问题。

  • VSTGUI 4.11

    • 在 Windows 上现在使用 DirectComposition，并支持 CLayeredViewContainer
    • 移除 32 位 Carbon 支持
    • 重做事件处理
    • 各项修复

  • 新增标志位/枚举：

    • 新增预定义 3D 扬声器布局：
      • k50_5_3 => L R C Ls Rs Tfl Tfc Tfr Trl Trr Bfl Bfc Bfr
      • k51_5_3 => L R C LFE Ls Rs Tfl Tfc Tfr Trl Trr Bfl Bfc Bfr
      • ITU 4+5+1 音响系统 E
        • k50_4_1 => L R C Ls Rs Tfl Tfr Trl Trr Bfc
        • k51_4_1 => L R C LFE Ls Rs Tfl Tfr Trl Trr Bfc
      • ITU 3+7+0 音响系统 F
        • k70_3 => L R C Ls Rs Sl Sr Tfl Tfr Trc
        • k72_3 => L R C LFE Ls Rs Sl Sr Tfl Tfr Trc LFE2

  • 文档

    • 新教程，讲解 如何使用静音标志。
    • 将 VST 3 文档迁移到 md 文件。

  • CMake

    • 最低 cmake 版本现在是 3.19。
    • 新函数 smtg_target_setup_as_vst3_example。
    • 为 mac 修改 smtg_target_set_bundle。
    • 新选项：SMTG_CREATE_MODULE_INFO：创建 moduleinfo.json 文件（默认 ON）。
    • 在 project() 中使用 VERSION 和 DESCRIPTION，以便由 cmake 自动生成版本文件。
    • 在 Windows 上将 SMTG_PLUGIN_TARGET_USER_PROGRAM_FILES_COMMON 的默认值改为 ON。
    • 修复 https://github.com/steinbergmedia/vst3sdk/pull/91。

  • 插件包装层：

    • Audio Unit 包装层：
      • 修复 AUv3 校验问题（https://github.com/steinbergmedia/vst3_public_sdk/issues/39）。

  • 示例：

    • 新增 VST 3 插件示例：
      • 新增 multiple_programchanges，展示对多个程序变更参数的支持。
    • 新增 Processing Load 模拟参数，可在 HostChecker 中制造 CPU 负载。
    • 重构示例的 cmake，以使用新的版本处理方式和 smtg_target_setup_as_vst3_example。

  • Validator 工具：

    • 添加 IPluginCompatibility 接口的测试

  • 辅助类：

    • public.sdk/samples/vst-utilities 中用于支持 moduleinfo 的新文件。
    • public.sdk/source/vst/moduleinfo 中用于创建和解析 moduleinfo 的新文件。
    • 修复 https://github.com/steinbergmedia/vst3_public_sdk/issues/37。

  • VST3PluginTestHost v3.3.0 版本：

    • plugintesthost 的 32 位版本已不再提供。

  • VS T3 Project Generator v2022.05 版本：

    • 调整 VST3 Inspector 以支持兼容性 json 文件。
