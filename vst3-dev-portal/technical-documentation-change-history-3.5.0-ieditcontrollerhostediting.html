[3.5.0] 增强的链接参数

引言

从宿主编辑参数：Vst:: IEditControllerHostEditing。

  • [plug imp]
  • [extends Vst:: IEditController]
  • [发布于：3.5.0]
  • [optional]

这允许宿主启动一个参数编辑动作，该动作可以在一次会话中（在 beginEdit 与 endEdit 之间）产生其他参数更改（例如链接的参数）。如果编辑控制器实现了此接口，并且在从插件外部（宿主 / 远程）对某个不可自动化、非只读且未标记为隐藏的参数（一种辅助参数）执行编辑时，宿主会先调用 beginEditFromHost，再调用 setParamNormalized，并以 endEditFromHost 结束。以下是宿主将调用的序列：

示例

//------------------------------------------------------------------------
plugEditController->beginEditFromHost (id);
plugEditController->setParamNormalized (id, value);
plugEditController->setParamNormalized (id, value + 0.1);
// ...
plugEditController->endEditFromHost (id);

另请参见 Vst:: IEditController。
