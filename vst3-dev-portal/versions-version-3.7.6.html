版本 3.7.6（2022/09/05）

常规变更

整个 SDK 中使用的整数类型现在基于 <cstdint> 中定义的标准类型，UTF-16 字符类型现在是 c++11 的 char16_t。这不是 ABI 变更，所有类型的大小与之前相同，旧的已编译插件在所有受支持系统的所有宿主中仍能正常加载。但实现可能需要调整，尤其是在 Windows 上，那里 tchar/char16 类型被直接用于 Windows API。为便于调整，pluginterfaces/base/fstrdefs.h 中提供了简单的转换函数（见 wscast）。

  • 接口变更：

    • 新增 Windows Arm64EC 和 Arm64 Classic 的架构文件夹
    • 新宏 SMTG_HIDDEN_SYMBOL，位于 pluginterfaces/base/fplatform.h

  • VSTGUI 缺陷修复更新 4.11.1

  • 新增标志位/枚举：

    • 修复 ITU 3+7+0 音响系统 F
      • k70_3 => L R C Ls Rs Sl Sr Tfl Tfr Trc
      • k72_3 => L R C LFE Ls Rs Sl Sr Tfl Tfr Trc LFE2

  • 文档

    • 新教程：用 VST 3 插件替换 VST 2 插件的指南。

  • CMake

    • 新文件 SMTG_AddVST3AuV2.cmake：
      • 为 VST 3 插件添加 AUv2 目标
      • 重做 AU Objective-C 命名空间的处理
    • 添加检查：PROJECT_VERSION 是否在 project() 中设置，若未设置则触发 FATAL_ERROR。
    • 当 Xcode 路径中包含 cmake 不支持的空格时显示错误文本。
    • SMTG_DetectPlatform.cmake 中的新函数 smtg_check_language_cxx 可用于检查 C++ 编译器是否可用。

  • 插件包装层：

    • Audio Unit 包装层：
      • 通过一个简单的 cmake 函数（见 smtg_target_add_auv2）简化 AUv2 包装插件的创建。
      • 重做 AUWrapper 的 Objective-C 代码。

  • 示例：

    • 为 Hostchecker 插件添加结构更清晰的单位和参数。

  • Validator 工具：

    • 修复 Windows 上的 validator 输出：发生崩溃时 cout 未被刷新。

  • 辅助类：

    • 在 public.sdk/source/vst/vsteditcontroller.h 和 public.sdk/source/common/pluginview.h 中改用 IPtr 进行重构。
    • 修复 module_win32.cpp 中加载失败且错误码无法打印时的崩溃。
    • 防止 Linux 上的 pluginfactory_constexpr 在调试模式下导出可能在各模块间共享的符号。

  • VST3PluginTestHost v3.3.10 版本：

    • 通过使用强化运行时所需的授权，支持在 macOS 上加载 PACE 保护的插件。

  • VST 3 Project Generator v2022.09 版本：

    • 修复：当 PATH 包含空子串时防止崩溃 PR#3。
