VST 3 支持的宿主需求

VST 3 宿主需要实现的 VST 3 接口：

  • [3.0.0] 宿主支持的接口。
  • 如果支持 MIDI：
    • [3.6.12] MIDI 学习（支持 MIDI 1.0）。
    • 除之前的 MIDI 学习之外：[3.8.0] MIDI 学习 2（支持 MIDI 2.0）。
  • [3.6.12] 宿主查询接口支持。
  • 如果插件实现了 IPluginViewContentScaleSupport，宿主应遵循 [3.6.6] PlugView 内容缩放 的要求。
