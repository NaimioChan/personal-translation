VST 3.0.0 中宿主支持/实现的接口列表

Vst:: IAttributeList

Vst:: IMessage 和 Vst:: IStreamAttributes 中使用的属性列表。

  • [host imp]
  • [released: 3.0.0]
  • [mandatory]

属性列表把值与键关联起来（id：一些预定义的键可在预定义预设属性中找到）。

Vst:: IComponentHandler

用于编辑控制器的宿主回调接口。

  • [host imp]
  • [released: 3.0.0]
  • [mandatory]

允许通过宿主把参数编辑传递给组件（处理器），并支持自动化。使宿主对配置更改作出反应（restartComponent）。

另见 Vst:: IEditController。

Vst:: IEventList

要处理的事件列表。

  • [host imp]
  • [released: 3.0.0]
  • [mandatory]

另见 ProcessData、Event。

Vst:: IUnitHandler

用于单位支持的宿主回调。

  • [host imp]
  • [扩展 Vst:: IComponentHandler]
  • [released: 3.0.0]
  • [optional]

宿主回调接口，与 Vst:: IUnitInfo 一起使用。可通过 queryInterface 从 Vst:: IComponentHandler 获取。

另见 VST 3 单位、Vst:: IUnitInfo。

Vst:: IHostApplication

基本的宿主回调接口。

  • [host imp]
  • [作为 'context' 传入 Steinberg:: IPluginBase::initialize]
  • [released: 3.0.0]
  • [mandatory]

基本的 VST 宿主程序接口。

Vst:: IMessage

插件的私有消息。

  • [host imp]
  • [通过 Vst:: IHostApplication::createInstance 创建]
  • [released: 3.0.0]
  • [mandatory]

消息从处理器组件发送到控制器组件，反之亦然。

另见 Vst:: IAttributeList、Vst:: IConnectionPoint、组件之间的通信。

Vst:: IParamValueQueue

针对特定参数的更改队列。

  • [host imp]
  • [released: 3.0.0]
  • [mandatory]

更改队列可以看作是自动化曲线的一段。对于每个处理块，都会把与该块大小相同的一段传给处理器。该曲线以原始自动化曲线线性近似后的采样点来表示。如果原始曲线已经是线性的，就可以精确传输。非线性曲线必须由宿主转换为线性近似。值队列中的每个点都把曲线的一段定义为一条直线，从块中的上一个点连到新点。因此插件可以计算块内任意采样位置处的曲线值。

隐式点：
在每个处理块中，每个参数的曲线段都会被传输。为了减少点的数量，块位置 0 处的点可以省略。

  • 如果曲线在多个块的区间内斜率为 0，则只在恒定曲线段开始的块中传输一个点。只要曲线斜率为 0，后续块对应的队列将为空。

  • 如果曲线在若干块的区间内具有非 0 的恒定斜率，则只传输该块最后一个采样的值。此时最后一个有效点位于块位置 -1。处理器可以用线性插值计算块内每个采样的值：

    double x1 = -1; // 与当前缓冲区相关的最后一个点的位置
double y1 = currentParameterValue; // 最后传输的值

int32 pointTime = 0;
ParamValue pointValue = 0;
IParamValueQueue::getPoint (0, pointTime, pointValue);

double x2 = pointTime;
double y2 = pointValue;

double slope = (y2 - y1) / (x2 - x1);
double offset = y1 - (slope * x1);

double curveValue = (slope * bufferTime) + offset; // bufferTime 是缓冲区中的任意位置

跳变：
自动化曲线中的跳变必须作为两个点传输：一个带旧值，另一个在下一个采样位置带新值。

另见 Vst:: IParameterChanges、ProcessData。

Vst:: IParameterChanges

一个处理块的全部参数更改。

  • [host imp]
  • [released: 3.0.0]
  • [mandatory]

该接口用于传输当前处理块中要应用到参数的任何更改。更改可以由 GUI 交互引起，也可以由自动化引起。更改以队列列表（Vst:: IParamValueQueue）的形式传输，其中只包含实际发生更改的参数所对应的队列。

参见 Vst:: IParamValueQueue、ProcessData。

Steinberg:: IPlugFrame

传递给 Steinberg:: IPlugView 的回调接口。

  • [host imp]
  • [released: 3.0.0]
  • [mandatory]

使插件能够调整视图大小，并使宿主调整窗口大小。
