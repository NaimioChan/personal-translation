版本 3.6.12（2018/12/03）

  • VSTGUI 4.7

    • 重新设计拖放（Windows 上现在支持带位图的拖拽）。
    • 针对 Windows 7 的独立库支持。
    • 新增 ImageStitcher 工具。
    • 移除了 GDI+ 绘制后端，由 Direct2D 后端替代。
    • 修复启动画面导致的崩溃。
    • 修复 win32 上 VSTGUI Tools 的编译。
    • 清理。

  • 接口变更：

    • 新增 LegacyMIDICCOutEvent（插件）：允许插件生成 MIDI CC 作为输出事件。
    • 新增 IMidiLearn（插件）：允许插件获取当前实时演奏的 MIDI CC，以实现自定义 MIDI 学习。
    • 新增 IPlugInterfaceSupport（宿主）：允许插件向宿主询问某个插件接口是否被宿主支持/使用。
    • 新增 IVst3WrapperMPESupport（包装层）：允许插件在包装层中设置 MPE 支持。

  • CMake：

    • 小幅重构（例如将 WIN 重命名为 SMTG_WIN）。
    • 修复 Windows 32 位的 WIN_ARCHITECTURE_NAME。
    • 修复 SMTG_PACKAGE_ICON_PATH 的选择。
    • 将 WIN_PDB 拆分为 WIN_PDB32 和 WIN_PDB64。

  • 示例：

    • 新增 LegacyMIDICCOut VST 3 插件，展示 LegacyMIDICCOutEvent 的用法。
    • 为 NoteExpressionSynth 添加 IMidiLearn 支持。
    • 添加支持 MPE 的 Audio Unit v3 NoteExpressionSynth 示例。

  • 插件包装层：

    • Audio Unit v3（AUv3）包装层（VST 3 - Audio Unit v3 包装层）：
      • 开箱即用的 MPE 支持。由于 MPE 是音符表达式特性的一个有限子集，这三个表达式会被简单地映射到通过 Vst:: INoteExpressionPhysicalUIMapping 接口返回的音符表达式。
      • 请注意，在 macOS/iOS 上为 AUv3 签名必须有证书。
      • 完整的文件夹重构，便于适配。
    • AAX 包装层（VST 3 - AAX 包装层）：
      • 修复加载预设后自动化未更新的问题
    • VST 2 包装层：
      • 修复编辑器被重复释放的问题。

  • 辅助类：

    • 新文件，包含一些事件辅助工具：vsteventshelper.h。
