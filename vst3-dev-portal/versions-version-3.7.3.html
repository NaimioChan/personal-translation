版本 3.7.3（2021/08/10）

  • 接口变更：

    • 更新 Steinberg:: IPlugViewContentScaleSupport 的文档。

  • VSTGUI 4.10.1

    • 各项修复。

  • 许可证已更新到 2.2.1 版！请阅读新的许可协议 VST 3 许可问题。（如果你已签署 2.0 版的许可协议，则无需再次签署）。

  • 新增标志位/枚举：

    • 新增 RestartFlags 标志 kKeyswitchChanged：通知键位切换已变更（信息、数量）。
    • Panner 新增 FunctionNameType：如 kPanPosCenterX。

  • CMake：

    • 修复 Windows arm 64 上的错误链接路径
    • 添加 -Werror=return-type，使 mac 上的错误与 Windows 或 Linux 上一致
    • 修复在使用 fetchcontent 获取 SDK 时 vst3sdk_SOURCE_DIR 变量未定义的问题
    • 修复通过项目生成器创建的项目中错误的符号可见性

  • 进阶技巧的新教程

  • 插件包装层：

    • AAX 包装层：
      • 重构 initModule/DeInitModule。
      • 使用只读参数时 GetParameterIndex 返回错误索引。
    • VST 2 包装层：
      • 修复调用过多 InitModule 的问题。
      • 重构 initModule/DeInitModule。
    • AUv3 包装层：
      • 在 macOS 11 上支持 AUv3。
      • 简化 AUv3Wrapper 代码。
      • 修复 Logic/GarageBand 在 macOS 11 上不显示编辑器的问题。

  • 重命名 zip SDK 中的文件夹：VST3_SDK => vst3sdk

  • 示例：

    • 在 HostChecker 插件中添加了检查：
      • 检查 IParameterChanges 中是否存在多个 ID 相同的队列。
      • 检查 IParameterChanges 中是否存在同一位置上的多个点。
      • 添加 restartComponent（kKeyswitchChanged）/ restartComponent（kNoteExpressionChanged）/ restartComponent（kParamValuesChanged）。
    • 在 Panner 示例中添加对 ivstparameterfunctionname 的支持。
    • 新增 VST 3 插件示例：
      • 新增「AGain Sample Accurate」，展示逐采样精确的参数变更处理。
    • 修复不带参数启动时的 editorHost 问题。
    • 修复没有可用 VST 3 插件时 VST3Inspector 的崩溃。
    • 修复 mda 插件的警告。
    • 修复使用 gcc 11 的构建。

  • 辅助类：

    • 新增工具文件：
      • audiobuffers.h
      • processdataslicer.h
      • rttransfer.h
      • sampleaccurate.h
      • testing.cpp/.h
