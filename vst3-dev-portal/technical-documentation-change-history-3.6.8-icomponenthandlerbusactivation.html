引言

用于编辑控制器的扩展宿主回调接口：Vst:: IComponentHandlerBusActivation。

  • [host imp]
  • [扩展 Vst:: IComponentHandler]
  • [发布于：3.6.8]
  • [optional]

允许插件请求宿主激活或停用某个特定总线。如果宿主接受该请求，之后会调用 Vst:: IComponent::activateBus。这对于具有多个输出的乐器尤其有用，用户可以从插件 UI 请求激活某个给定的输出总线。

另请参见 Vst:: IComponentHandler。

示例

// 在代码中需要告知宿主启用某个特定总线的位置。
if (auto busActivation = Steinberg::U::cast<IComponentHandlerBusActivation> (componentHandler))
{
    // 这里我们要激活音频输入侧链（第 2 个输入总线：索引 1）
    busActivation->requestBusActivation (kAudio, kInput, 1, true);
}
