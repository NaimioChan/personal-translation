版本 3.7.1（2020/11/17）

  • 新增标志位/枚举：

    • NoteIDUserRange：为插件保留的音符标识符（noteId）范围。保证宿主不使用该范围。

  • CMake：

    • 重命名文件，添加 SMTG_ 前缀。
    • 重命名函数，添加 smtg_ 前缀。
    • 重新组织文件。
    • 使 VSTSDK 更兼容 Mingw32。
    • 支持在无 team ID 的情况下构建 AUv3。
    • 修复 smtg_add_plugin_resource 中的路径处理。

  • 插件包装层：

    • AAX 包装层：
      • 添加对离线处理的支持。
    • AUv3 包装层：
      • 添加对离线处理的支持。
      • 修复输出总线的激活。
      • 修复组件不是从 UI 线程 加载时的问题。

  • 辅助类：

    • GetPluginFactory() 的 def-file 与 declspec。

  • VST3PluginTestHost v3.0 版本：

    • 新增控制电压总线信息列。
    • 帮助菜单中的新链接。
    • 新增启用 MPE 支持。
    • 支持深色/浅色配色方案。
    • 修复「Valid State Transition」测试对仅 64 位插件总是失败 #50 的问题。
    • 修复自动化单元测试。

  • VST 3 Project Generator v2020.10 版本：

    • 新增对 VSTGUI 的支持
    • 在 Windows 上启用符号链接
    • 在 Windows 上将 VST3PluginTestHost.exe 添加为 Debugging->Command
    • 改进 cmake 文件的生成
    • 修复选择错误的 cmake.exe 路径后卡住的问题
