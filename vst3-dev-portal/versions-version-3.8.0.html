版本 3.8.0（2025/10/20）

  • VST 3 的新许可模式：

    • VST 3 现已开源，以 MIT 许可证发布。

  • 接口变更：

    • 对 MIDI 2.0 的支持：新接口 IMidiLearn2 与 IMidiMapping2。这些新接口取代了先前的 IMidiLearn 与 IMidiMapping 接口。
    • 为 MIDI 1.0 系统消息补充缺失的 ControllerNumbers 枚举。
    • 预览 Linux 上的 Wayland 支持（最初由 PreSonus Software Ltd. 编写并贡献给 VST SDK，并已集成到 Linux 上的 Studio One Pro 7.2 及更高版本中）：
      • 新接口 IWaylandHost, IWaylandFrame。
      • 新平台 UI 类型：kPlatformTypeWaylandSurfaceID。

  • VSTGUI 更新至 4.15.0

    • 新增 Task Concurrency API：它便于将任务调度到后台线程执行，可以并发或串行。此 API 还支持从任意其他线程将任务调度到主线程。
    • 增加对自定义视图布局的支持（参见 IViewLayouter 与 CViewContainer::setViewLayouter）。
    • 增加一个类似 CSS Grid 的网格视图布局器（参见 GridLayouter）。
    • 为 UIDescription 增加脚本功能（参见 uidescription-scripting/uiscripting.md）
    • 增加新的文本编辑器视图（参见 lib/ctexteditor.h）
    • 滚动视图现在可以有顶部和左侧边缘视图（参见 CScrollView::setEdgeView）
    • Linux 上的初步 Wayland 支持。

  • 文档

    • 更新 新许可模式的文档。
    • 更新 Steinberg VST 使用准则文档。

  • CMake

    • 修复 SMTG_AddSMTGLibrary.cmake（macOS/Linux）：在创建新符号链接前移除旧链接。
    • 修复 SMTG_PlatformToolset.cmake 用于 Visual Studio 编译器：__cplusplus 未被赋值为正确版本（PR#13）。

  • 示例：

    • 在 legacymidiccout 插件中增加对新 ControllerNumbers 枚举的支持。
    • 增加对新接口 IMidiLearn2 与 IMidiMapping2 的支持，位于 音符表达式合成器 插件中。
    • 为 EditorHost 增加 Wayland 支持。

  • 辅助类：

    • 修复：Validator ScanParametersTest::run() 未正确打印参数类型（Issue#142）。
    • 修复：validator.exe 与 moduleinfotool.exe 调试版本在检查符号链接时抛出中止（Issue#145）。
    • 修复：校验测试套件中的未定义行为（UB）导致测试用例失败（Issue#77）。

  • VST3PluginTestHost 测试宿主 v3.10.10：

    • 修复：Windows 平台上启动时可能崩溃（论坛）。
