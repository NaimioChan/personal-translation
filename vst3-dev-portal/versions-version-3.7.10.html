版本 3.7.10（2024/01/18）

版本 3.7.10（2024/01/18）

  • 接口变更：

    • 最低要求现在是 C++17。
    • PlugType 新增子类别：
      • kFxBass / kFxChannelStrip / kFxDrums / kFxGuitar / kFxMicrophone

  • VSTGUI 更新至 4.13.3

  • 文档

    • 明确 param ID 的范围。
    • 为 模块信息与插件兼容性 添加说明。

  • CMake

    • 修复 smtg_target_make_plugin_package 可能创建无效 VST 3 插件的问题（论坛）。
    • 修复非 bundle 的 Windows 插件的回归问题（Windows 上的非 bundle VST 3 将在 VST SDK 的未来更新中被声明为弃用）。

  • 工具：

    • 两个新脚本，分别用于 macOS（vst3sdk/tools/setup_macos_packages_for_vst3sdk.sh）和 Windows（vst3sdk/tools/setup_win_for_vst3sdk.bat），用于检查开发 VST 3 插件所需的所有工具是否已正确安装。

  • 示例：

    • 新增 VST 3 插件示例：
      • 新增 Utf16Name，展示在插件名和公司名中使用 UTF16 字符。
    • 修复在不同 DPI 屏幕之间移动窗口时的 EditorHost 问题（论坛 / Juce 论坛）。

  • Validator 工具：

    • 添加测试，检查 IPluginBase 由控制器和处理器提供。
    • 在 Windows 上添加对 UTF8 路径的支持。

  • VST3PluginTestHost v3.7 版本：

    • 修复全局缓冲区溢出（AddressSanitizer）问题。
    • 在 Windows 上，如果存在「Steinberg built-in Driver」则默认使用它。

  • VST 3 Project Generator v2024.01 版本：

    • 修复：ProjetGenerator 不应允许在 SDK 文件夹内创建新项目。
    • 调整模板项目：移除乐器的音频输入，并添加一个默认的处理实现作为示例。
