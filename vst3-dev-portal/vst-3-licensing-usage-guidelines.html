商标使用（例如「VST」名称或徽标）在 MIT 许可证 下是可选的，但若使用，必须遵守 Steinberg 的官方商标规则。

在 VST SDK 中，VST 兼容徽标 位于文件夹 VST_SDK/VST3_SDK/vst3_doc/artwork 中。

1. 使用 VST 兼容徽标

如果你选择显示 VST 兼容徽标 或提及 VST 商标，则必须在下列每一项中使用 Steinberg 提供的「VST 兼容徽标」，以包含对 Steinberg 的引用：

a) 包装：

在所有实体产品包装上，VST 兼容徽标 必须清晰可见。

b) 网站：

在每个引用或推广使用 VST SDK 或以其创建的产品网页上，VST 兼容徽标 都必须可见。仅在站点范围的页脚或版本说明中显示 VST 兼容徽标 是不够的。

c) 文档与手册（包括但不限于 PDF 手册、印刷手册、数据表、在线帮助）：

所有形式的产品文档中都必须包含 VST 兼容徽标。如果因空间限制无法包含，则必须清楚地加入提及 Steinberg 的版权归属声明。

d) 营销 / 广告材料：

所有宣传和广告内容中都必须显示 VST 兼容徽标，除非存在空间限制，此时必须提供归属声明。

e) 产品 UI（「关于」框或等同元素）：

VST 兼容徽标 应出现在「关于」框或等同的 UI 元素中（例如帮助菜单或启动画面）。如果空间不足，必须使用归属声明。

f) 法律 / 版本说明页面：

徽标或商标声明必须出现在提及 VST 的相关版本说明或法律页面上。

例外：

如果存在空间限制（例如横幅、宣传赠品），可以使用仅含文字的「VST」引用并附版权声明。

2. 不使用 VST 兼容徽标而使用「VST」

按照其许可证使用 VST SDK 的一方，可以在完全遵守本准则的前提下，使用标准字体的「VST」一词来表示兼容性。以下情形允许使用：

  • 在产品包装上
  • 在网站上
  • 在产品名称中

在任何情况下，VST 兼容徽标 都必须出现在相关上下文中，紧邻「VST」一词的使用位置或与之相关联。

3. 声明兼容性

诸如「兼容 64 位 VST」这样的表述在以下条件下是允许的：

  • 产品实际上确实兼容，并且是使用 VST SDK 开发的。
  • 在同一页面或同一表面上，声明附近显示了 VST 兼容徽标。

4. 在网站上使用

在每个提及使用 SDK 或以其创建的产品、或显示「VST」一词的网页上，都必须出现 VST 兼容徽标。仅放在版本说明中或某一个页面上是不够的。

5. 在包装上使用

任何使用 VST SDK 或以其创建的产品，其包装上都必须印有 VST 兼容徽标。

6. 在产品名称或徽标中使用

在以下情况下，你可以在产品名称中提及与 VST 的兼容性：

  • 「VST」以纯文本形式使用，例如「MyCoolEngine for VST」。
  • VST 兼容徽标 显示在紧邻的视觉范围内。
  • 「VST」未经图形化风格处理、未嵌入 VST 兼容徽标，也未并入核心产品品牌。

7. 在公司名称中使用

严禁在公司名称中使用「VST」一词。

8. 在社交媒体中使用

在以下情况下，「VST」可以出现在社交媒体账号名、频道名称或 URL 中：

  • 该引用表示兼容性（例如「MyCoolEngineForVST」）。
  • VST 兼容徽标 在频道/页面上清晰且持续地显示。

9. 在域名中使用

在以下情况下，允许在域名中使用「VST」（例如 MyCoolEngineForVST.com）：

  • 名称中包含对兼容性的引用（而非独立品牌）。
  • 该域名下的所有网页：
    • 使用该 SDK。
    • 显示 VST 兼容徽标。

10. 在徽标中使用

  • 不允许在公司徽标中包含「VST」。
  • 仅在第 6 节规定的前提下，才允许在产品徽标中使用。

11. 在视频中使用

「VST」可以出现在：

  • 视频标题中（例如教程或演示）
  • 画面引用中

前提是 VST 兼容徽标：

  • 在视频本身中显示
  • 在承载或预览该视频的网页上显示

如果视频的某一帧画面包含「VST」一词，则该画面或紧邻的上下文里也必须出现 VST 兼容徽标。

12. 在分类或 URL 中使用

在以下情况下，允许在 URL 或分类名称中使用「VST」（例如 www.myreviews.com/VSTplugins/）：

  • 该分类是描述性的、通用的。
  • 仅列出使用 VST SDK 或使用其创建的产品。

13. 组合或变体

不允许创建修改过的词或组合，例如「VSTi」或其他缩写、混成词或派生词。

14. 官方 VST 兼容徽标

Steinberg 提供以下 VST 兼容徽标：

最小印刷尺寸 = 20 x 18,7 mm

最小印刷尺寸 = 15 x 10 mm

在所有数字和印刷用途中都必须遵守这些尺寸。

15. 商标归属要求

在任何与产品相关的材料中首次使用「VST」时，必须包含 ® 符号。此外，以下归属声明必须出现在所有产品致谢和文档中：

「VST 是 Steinberg Media Technologies GmbH 的注册商标。」
