版本 3.8.1（2026/08/11）

  • 接口变更：

    • 新接口 ITransportControl，允许插件向宿主请求与走带相关的操作。
    • 新增专用于 MIDI 2.0 Per Note Controller 与 Attributes 的音符表达式类型 ID（Vst::NoteExpressionTypeIDs）（kMidi2AssignablePerNoteControllerStart，...）。
    • 新接口 NoteOnOrchestralArticulation::IInfo，用于 MIDI 2.0 对 Orchestral Articulation Profile 的支持。
    • Midi2Controller 结构体在 ivstmidimapping2.h 中有小幅改动，可确保跨编译器的完整 ABI 兼容性。使用该结构体的开发者需要做一点小适配。
    • 发布基于文本的 XML 定义：Clipboard VST-XML，用于在插件和/或应用之间以拖放和复制粘贴方式交换音频与音乐元素（例如音频文件、和弦、音阶和片段），并附带上下文元数据，例如工程时间和颜色。
    • 为 Linux 新增 VST3 系统路径：/usr/lib64/vst3 和 /usr/local/lib64/vst3（在 Fedora 发行版中定义）。

  • VSTGUI 更新至 4.15.1

  • 文档

    • 修正 ivstprocesscontext.h 中的 doxy 文档。
    • 在文档中为 MIDILearn2 补充说明（n 对 m 映射）。

  • CMake

    • 从主 CMakeLists.txt 中移除 AUWrapper 目标。
    • 针对非 Visual Studio 生成器更好地检测 Windows 32 位构建（PR#14）。

  • 插件包装层：

    • Audio Unit 包装层：
      • AUv2Wrapper 包装层：
        • 改进 MIDI 值转换。
        • 修复 auwrapper.mm：
          • 使用新 AUSDK 构建 AUWrapper。
          • 传给 CFStringGetCharacters 的参数错误（PR#80）。
          • AUWrapper::restartComponent 的 kLatencyChanged 处理（PR#79）。

  • 示例：

    • 修复：示例 音符表达式合成器 插件（Issue#78）中的音符表达式信息不正确。
    • 修复：在 notifyProgramListChange 插件中更改导出的程序数量后缺少对 测试多重程序变更 的调用。
    • 更新 Hostchecker 插件：
      • 检查对 ITransportControl 的支持。
      • 添加 Randomize 参数（Vst::FunctionNameType::kRandomize 与 Vst::FunctionNameType::kRandomizeAroundCurrent）。

  • 辅助类：

    • 修复：module_mac.mm 中未使用的参数（Issue#83）。
    • 更新：Linux VST3 系统路径：在 /usr/lib64/vst3 中添加 vst/source/hosting/module_linux.cpp（PR#82）。
    • 修复：部分编译器（如 Clang 17）下的编译问题，exception.h 文件中缺少 threadchecker 包含（Issue#84）。
    • 修复 macOS 上设置窗口标题的问题：editorhost/source/platform/mac/window.mm（Issues#134）。
    • 修复 VST Hosting / registerWindowClass() 方法：RegisterClassEx() 被重复执行（仅 Windows），位于 editorhost/source/platform/win/window.cpp（Issues#155）。
    • 修复在 Wayland 下切换不同缩放比例时的问题并改进处理。
    • 修复 return false 中控制器初始化失败时缺少 vst/hosting/plugprovider.cpp 的问题。

  • Validator 工具：

    • 修复：Validator 测试未遵守音频处理器调用顺序（Issue#148）。
    • 新增一项测试，用于验证 getParamStringByValue 与 getParamValueByString 能否正确往返转换值。

  • VST3PluginTestHost 测试宿主 v3.11.0：

    • 添加宿主对 ITransportControl 的支持。
    • 使用 Vst::FunctionNameType::kRandomize 与 Vst::FunctionNameType::kRandomizeAroundCurrent 添加对 Randomize 参数（Parameter Function Name）的支持。
