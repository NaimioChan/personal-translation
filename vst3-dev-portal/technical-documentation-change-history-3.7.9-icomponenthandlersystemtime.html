[3.7.9] 获取当前系统时间

本页内容：

  • 引言
  • 示例

引言

用于编辑控制器的扩展插件接口 Vst:: IComponentHandler，Vst:: IComponentHandlerSystemTime 允许插件询问当前的 systemTime（它应与 ProcessContext::systemTime 中使用的时间基准相同，不过这一时间不像 ProcessContext 中的那样做过补偿）。

  • [host imp]
  • [扩展 Vst:: IComponentHandler]
  • [released: 3.7.9]
  • [optional]

示例

//--------------------------------------
// 我们在 editcontroller 中：
  
int64 systemTime = 0;

if (auto handlerSystemTime = Steinberg::U::cast<IComponentHandlerSystemTime> (componentHandler))
    handlerSystemTime->getSystemTime (systemTime);
