引言

一种在播放过程中控制 / 修改 / 改变某个正在演奏的音符的新方式。

编辑控制器组件接口扩展：Vst:: INoteExpressionController

  • [plug imp]
  • [extends Vst:: IEditController]
  • [发布于：3.5.0]
  • [optional]

音符表达式是支持此 VST 3.5 特性的宿主（Cubase 自版本 6 起）中一种新的事件控制器编辑方式。

借助 VST 3 音符表达式，插件能够摆脱 MIDI 控制器事件的限制：它可以访问新的 VST 3 控制器事件，这些事件按照每个音符（事件）的 noteId，为复音织体中的每个单独音符提供奏法信息。

MIDI 的一个主要局限在于控制器信息的性质：控制器只是通道消息（Pitchbend、Modulation 等），无法指派给某个具体的演奏音符，例外是复音压力（polyphonic aftertouch），它只允许改变某个给定的音高（而不是某个给定的音符！）。

在和弦中为每个音符单独加上奏法，会带来自然得多的感觉，就像多位演奏者同时演奏同一乐器，但各自为所奏的音符增添自己的个性。

例如，Cubase 6 引入了第一款兼容 VST 3 音符表达式的虚拟乐器：HALion Sonic SE。HALion Sonic SE 不仅支持针对调音（音高）、音量和声像的“标准”音符表达式控制，还提供额外的、自定义的预分配音符表达式事件类型（kCustomStart，位于 Vst::NoteExpressionTypeIDs 中）。

它是如何工作的？

理解如何在插件一侧支持音符表达式，最好的办法是查看下面这个分步实现示例。更多细节请查看 SDK 中附带的 Note Expression Synth 示例。

分步说明：我们需要一个单音色（1 通道）的乐器插件，带 1 个事件总线，并支持失谐（kTuningTypeID）音符表达式：

  1. 该乐器插件必须至少有一个输入事件总线：
//------------------------------------------------------------------
tresult PLUGIN_API MyExampleProcessor::initialize (FUnknown* context)
{
    //---始终初始化父类-------
    tresult result = AudioEffect::initialize (context);
    if (result == kResultTrue)
    {
        // 我们需要一个立体声输出
        addAudioOutput (STR16 ("Stereo Output"), SpeakerArr::kStereo);

        // 创建事件输入总线（1 个总线，仅 1 个通道）
        addEventInput (STR16 ("Event Input"), 1);
    }
    return result;
}
  1. 控制器必须提供 Vst:: INoteExpressionController 接口，如下所示：
//------------------------------------------------------------------
class MyExampleController: public EditController, public INoteExpressionController
{
public:
    // ...
    //---来自 INoteExpressionController
    virtual int32 PLUGIN_API getNoteExpressionCount (int32 busIndex, int16 channel) SMTG_OVERRIDE;
    virtual tresult PLUGIN_API getNoteExpressionInfo (int32 busIndex, int16 channel, int32 noteExpressionIndex, NoteExpressionTypeInfo& info) SMTG_OVERRIDE;
    virtual tresult PLUGIN_API getNoteExpressionStringByValue (int32 busIndex, int16 channel, NoteExpressionTypeID id, NoteExpressionValue valueNormalized, String128 string) SMTG_OVERRIDE;
    virtual tresult PLUGIN_API getNoteExpressionValueByString (int32 busIndex, int16 channel, NoteExpressionTypeID id, const TChar* string, NoteExpressionValue& valueNormalized) SMTG_OVERRIDE;
    // ...

    OBJ_METHODS (MyExampleController, EditController)
    DEFINE_INTERFACES
        DEF_INTERFACE (INoteExpressionController)
    END_DEFINE_INTERFACES (EditController)

    REFCOUNT_METHODS(EditController)
    //...
};
  1. 现在我们必须实现 Vst:: INoteExpressionController 接口；在我们的示例中，Vst:: INoteExpressionController::getNoteExpressionCount 应返回 1，因为我们只想支持调音：
//------------------------------------------------------------------
int32 PLUGIN_API MyExampleController::getNoteExpressionCount (int32 busIndex, int16 channel)
{
    // 我们只接受第一个总线和 1 个通道
    if (busIndex == 0 && channel == 0)
        return 1;
    return 0;
}
  1. 然后我们必须实现 Vst:: INoteExpressionController::getNoteExpressionInfo，它描述了插件支持哪些音符表达式：
//  ------------------------------------------------------------------
tresult PLUGIN_API MyExampleController::getNoteExpressionInfo (int32 busIndex, int16 channel, int32 noteExpressionIndex,
                            NoteExpressionTypeInfo& info)
{
    // 我们只接受第一个总线和 1 个通道，并且只支持 1 个音符表达式（调音）
    if (busIndex == 0 && channel == 0 && noteExpressionIndex == 0)
    {
        memset (&info, 0, sizeof (NoteExpressionTypeInfo));

        // 设置调音类型
        info.typeId = kTuningTypeID;

        // 设置一些字符串
        USTRING ("Tuning").copyTo (info.title, 128);
        USTRING ("Tun").copyTo (info.shortTitle, 128);
        USTRING ("Half Tone").copyTo (info.units, 128);

        info.unitID = -1; // 不需要单位
        info.associatedParameterID = -1; // 不需要关联的参数

        info.flags = NoteExpressionTypeInfo::kIsBipolar; // 事件是双极性的（居中）

        // 对于调音，转换函数为：plain = 240 * (norm - 0.5); norm = plain / 240 + 0.5;
        // 我们只想支持 +/- 一个八度
        double kNormTuningOneOctave = 12.0 / 240.0;

        info.valueDesc.minimum = 0.5 - kNormTuningOneOctave;
        info.valueDesc.maximum = 0.5 + kNormTuningOneOctave;
        info.valueDesc.defaultValue = 0.5; // [0, 1] 的中点 => 不失谐（240 * (0.5 - 0.5) = 0）
        info.valueDesc.stepCount = 0; // 我们需要连续值（无步进）

        return kResultTrue;
    }

    return kResultFalse;
}
  1. 为了显示音符表达式的值，我们必须实现转换函数：
    • Vst:: INoteExpressionController::getNoteExpressionStringByValue：归一化值 -> 字符串
//------------------------------------------------------------------
tresult PLUGIN_API  MyExampleController::getNoteExpressionStringByValue (int32 busIndex, int16 channel, NoteExpressionTypeID id, NoteExpressionValue valueNormalized, String128 string)
{
    // 这里我们用 id（不是索引）
    if (busIndex == 0 && channel == 0 && id == kTuningTypeID)  
    {
        // 这里必须把归一化值转换为调音的字符串表示
        UString128 wrapper;
        valueNormalized = (240 * valueNormalized) - 120; // 计算半音数
        wrapper.printFloat (valueNormalized, 2);
        wrapper.copyTo (string, 128);

        return kResultTrue;
    }

    return kResultFalse;
}

- [Vst:: INoteExpressionController::getNoteExpressionValueByString](https://steinbergmedia.github.io/vst3_doc/vstinterfaces/classSteinberg_1_1Vst_1_1INoteExpressionController.html#ab79e988315e33b4c30c8f2bd47a0cffc): string -> normalized value

//------------------------------------------------------------------
tresult PLUGIN_API  MyExampleController::getNoteExpressionValueByString (int32 busIndex, int16 channel, NoteExpressionTypeID id,
                            const TChar* string, NoteExpressionValue& valueNormalized);
{
    // 这里我们用 id（不是索引）
    if (busIndex == 0 && channel == 0 && id == kTuningTypeID)
    {
        // 这里必须把给定的调音字符串（半音）转换为归一化值
        String wrapper ((TChar*)string);
        ParamValue tmp;
        if (wrapper.scanFloat (tmp))
        {
            valueNormalized = (tmp + 120) / 240;
            return kResultTrue;
        }
    }

    return kResultFalse;
}
  1. 最后一步，在处理器组件中，我们必须调整 process 调用，以解释宿主发送给插件的音符表达式事件（Vst::NoteExpressionValueEvent）：
//------------------------------------------------------------------
tresult MyExampleProcessor::process (ProcessData& data)
{
    // ....
    // 获取输入事件队列
    IEventList* inputEvents = data.inputEvents;
    if (inputEvents)
    {
        Event e;
        int32 numEvents = inputEvents->getEventCount ();

        // 遍历每个事件进行检查..
        for (int32 i = 0; i < numEvents; i++)
        {
            if (inputEvents->getEvent (i, e) == kResultTrue)
            {
                switch (e.type)
                {
                    //-----------------------
                    case Event::kNoteOnEvent:
                    {
                        // 这里是音符开，我们可能需要演奏些什么，并记录 e.noteOn. noteId
                        break;
                    }
                    //-----------------------
                    case Event::kNoteOffEvent:
                    {
                        // 这里必须释放与此 id 关联的声部：e.noteOff.noteId
                        // 注意，kNoteExpressionValueEvent 事件可能在音符已进入释放阶段后发送
                        break;
                    }
                    //-----------------------
                    case Event::kNoteExpressionValueEvent:
                    {
                        // 这里是音符表达式的解释

                        // 我们只检查并使用调音表达式
                        if (e.noteExpressionValue.typeId == kTuningTypeID)
                        {
                            // 必须找到要更改的声部（该音符可能处于释放状态）
                            VoiceClass* voice = findVoice (e. noteExpressionValue.noteId);
                            if (voice)
                            {
                                // 把所需的值应用到它（针对给定的音符表达式类型（失谐、音量……）
                                voice->setNoteExpressionValue (e. noteExpressionValue.typeId, e. noteExpressionValue.value);
                            }
                            // 如果关联的 id 不再被标记为演奏中的声部（已到达释放末尾），我们就忽略该音符表达式事件
                        }

                        break;
                    }
                }
            }
        }
    }
    // ...
}
