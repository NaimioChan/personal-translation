引言

自 VST 3.6.10 起，VST 3 包可以为 VST 3 宿主包含预渲染的快照图像，作为插件 UI 的视觉表示。

  • 该快照必须具有预定义的格式和文件名，宿主才能识别它。
  • 图像格式必须是 PNG。
  • 图像需要位于包目录内的 Resources/Snapshots/ 文件夹中。
  • 文件名必须以音频处理器的唯一 ID 开头，形式为 84E8DE5F92554F5396FAE4133C935A18，随后是字符串 _snapshot，之后可选地跟 HiDPI 缩放因子 _2.0x，并以文件扩展名 .png 结尾。
  • 例如，again 的快照必须命名如下：
    • 84E8DE5F92554F5396FAE4133C935A18_snapshot.png
    • 84E8DE5F92554F5396FAE4133C935A18_snapshot_2.0x.png 用于 2x 缩放的 HiDPI 变体。
  • 如果省略 HiDPI 缩放因子，则使用缩放因子 1。

Cubase 如何使用快照

在 Right Zone 的 Media Tab 下，用户可以使用快照选择 FX 和乐器。
