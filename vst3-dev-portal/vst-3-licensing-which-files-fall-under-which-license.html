VST SDK 的哪些文件适用哪种许可证？

描述 VST 3 接口的所有文件（位于 SDK 的 "pluginterfaces" 文件夹中），以及所有 Helper 文件（包含在 base 和 public.sdk 文件夹中），都适用前面所述的 MIT 许可证。

这些文件中的每一个都包含以下文本：

//----------------------------------------------------------------------------
// 本文件是 Steinberg SDK 的一部分，受许可条款约束，
// 条款见本发行版顶层目录中的 LICENSE 文件，
// 以及 www.steinberg.net/sdklicenses。
// 除依照 LICENSE 文件中的条款外，不得复制、修改、传播 SDK 的任何部分，
// 包括本文件。
//----------------------------------------------------------------------------
  • 对于 VST SDK 的所有其他文件，适用各自嵌入的许可文本，例如：
    • 所有 VSTGUI 文件适用 BSD 风格 许可证
    • 所有 mda-vst3 示例（public.sdk/samples/mda-vst3 文件夹）适用 BSD 风格 许可证：Copyright (c) 2008 Paul Kellett

VST 2 呢？

「Proprietary Steinberg VST 2」许可证即 VST 2 许可协议，允许你以二进制形式分发你的 VST 2 插件/宿主。但请注意以下要求：

  • 你需要获得 Steinberg Media Technologies GmbH 的书面许可才能分发你的 VST 2 插件/宿主（此手续须在 2018 年 10 月之前完成）。
  • 你需要在你的 VST 2 插件/宿主的「关于」框和/或文档中提及 Steinberg Media Technologies GmbH，并遵守 Steinberg VST 使用准则。
  • 请注意，自 2018 年 10 月 1 日起，Steinberg 不再接受任何 VST 2 许可协议的提交！这意味着：

如果你没有在 2018 年 10 月 之前与 Steinberg 签署许可协议，则不允许分发新的 VST 2 插件或 VST 2 宿主！
