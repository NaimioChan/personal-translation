版本 3.7.9（2023/10/09）

  • 接口变更：

    • 新增 Vst:: IDataExchangeHandler / Vst::IDataExchangeReceiver：以安全高效的方式把数据从实时处理函数发送到控制器的 API。
    • 新增 Vst:: IComponentHandlerSystemTime：从控制器查询系统时间的 API。
    • Linux 上新增：从 IPluginFactory3 的宿主上下文查询 IRunLoop。
    • 新增标志位/枚举：
      • 新增扬声器：kSpeakerLw 和 kSpeakerRw，分别对应左宽声道和右宽声道
      • 新增预定义 3D 扬声器布局（兼容 Dolby Atmos）：
        • k90_4_W => L R C Ls Rs Sl Sr Tfl Tfr Trl Trr Lw Rw
        • k91_4_W => L R C Lfe Ls Rs Sl Sr Tfl Tfr Trl Trr Lw Rw
        • k90_6_W => L R C Ls Rs Sl Sr Tfl Tfr Trl Trr Tsl Tsr Lw Rw
        • k91_6_W => L R C Lfe Ls Rs Sl Sr Tfl Tfr Trl Trr Tsl Tsr Lw Rw

  • VSTGUI 更新至 4.13.0

  • 文档

    • 新教程：数据交换教程 - 如何把数据从实时进程发送到编辑控制器。
    • 关于 在 Linux 上提供 RunLoop 的新文档页。

  • CMake

    • 将最低 cmake 版本改为 3.5.0。
    • 针对 Windows 的部分修复：如果目标安装文件夹不存在则创建它们 (Issue#8)。

  • 插件包装层：

    • AAX 包装层（VST 3 - AAX 包装层）：
      • 修复若干警告
    • Audio Unit 包装层：
      • AUv3 包装层：
        • 修复 iOS 构建错误（PR#47）
        • 使 AUv3 遵循 VST3 线程模型 (PR#62)
        • 修复 AUv3Wrapper 中的「Missing field initializer」警告 (Issue#55)

  • 示例：

    • 新增 VST 3 插件示例 DataExchange，展示 VST 数据交换 API 的用法：public.sdk/samples/vst/dataexchange。
    • 更新 Hostchecker 插件以检查新接口：Vst:: IDataExchangeHandler / Vst::IDataExchangeReceiver / Vst:: IComponentHandlerSystemTime。

  • 辅助类：

    • 系统时间的新辅助工具 public.sdk/source/vst/utility/systemtime.cpp。
    • 新增实现 Vst:: IDataExchangeHandler 的 VST 数据交换 API 辅助类：public.sdk/source/vst/utility/dataexchange.cpp。
    • 修复 vstparameters.h 中的「Missing field initializer」警告 (PR#60)。
    • 修复缓冲区溢出/内存损坏（Issue#15）。
    • 修复未定义行为 - 加载未对齐的地址（Issue#64）。
    • vstgui4 在 Linux 上似乎不完整（Issue#104）。

  • Validator 工具：

    • 允许 moduleinfo.json 与 IPluginCompatibility 共存，不再视为错误而是警告（不推荐！）(Issue#63)。

  • VST 3 Project Generator v2023.09 版本：

    • 将 SMTG_ADD_VSTGUI 重命名为 SMTG_ENABLE_VSTGUI_SUPPORT。
