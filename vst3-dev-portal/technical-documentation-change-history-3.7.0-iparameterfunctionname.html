引言

编辑控制器组件接口扩展：Vst:: IParameterFunctionName。

  • [plug imp]
  • [extends Vst:: IEditController]
  • [released: 3.7.0]
  • [optional]

此接口允许宿主获取给定单位下与特定含义（functionName）关联的参数。例如，宿主可以利用这一信息在自己的 UI 中绘制增益衰减表。要获取该参数的原始值（plain value），宿主应使用 Vst:: IEditController::normalizedParamToPlain。宿主可以自动将参数映射到专用的 UI 控件，例如干湿比旋钮或 Randomize 按钮。如果此接口提供的某个参数带有 kReadOnly 标志，宿主应忽略该参数。

当前已定义的函数名

名称说明
增益衰减
kCompGainReduction
kCompGainReductionMax
kCompGainReductionPeakHold
kCompResetGainReductionMax
随机化
kRandomize在整个参数范围内分配随机值。
kRandomizeAroundCurrent在当前参数值附近分配随机值（例如当前值的 ±5%）。
声像器
kPanPosCenterX（声像中心 X）引力点 X 轴 [0, 1]=>[左-右]（立体声：左右之间的中间位置）。
kPanPosCenterY（声像中心 Y）引力点 Y 轴 [0, 1]=>[前-后]。
kPanPosCenterZ（声像中心 Z）引力点 Z 轴 [0, 1]=>[下-上]。
其他
kLowLatencyMode适用于要求低延迟的现场场景：0 表示禁用 LowLatency，1 表示启用 LowLatency
kDryWetMix允许将原始（干）信号与处理后的（湿）信号混合：0.0 表示仅干信号，0.5 表示 50% 干信号 + 50% 湿信号，1.0 表示仅湿信号

示例

在 mycontroller.h 中

//------------------------------------------------------------------------
// 下面是 VST 3 插件如何支持此 IParameterFunctionName 接口的一个示例。
// 我们需要在某处定义 iid（在 mycontroller.cpp 中）：
  
#include "pluginterfaces/vst/ivstparameterfunctionname.h"

//在 MyController 类声明中
class MyController : public Vst::EditController, public Vst::IParameterFunctionName
{
    // ...
    tresult PLUGIN_API getParameterIDFromFunctionName (UnitID unitID, FIDString functionName,
                                                    Vst::ParamID& paramID) override;
    // ...
  
    OBJ_METHODS (MyController, Vst::EditController)
    DEFINE_INTERFACES
        // ...
        DEF_INTERFACE (Vst::IParameterFunctionName)
    END_DEFINE_INTERFACES (Vst::EditController)
    //...
}

在 mycontroller.cpp 中

namespace Steinberg {
    namespace Vst {
        DEF_CLASS_IID (IParameterFunctionName)
    }
}
  
//------------------------------------------------------------------------
tresult PLUGIN_API MyController::getParameterIDFromFunctionName (UnitID unitID, FIDString functionName,
                                                                 Vst::ParamID& paramID)
{
    using namespace Vst;
  
    paramID = kNoParamId;
  
    if (unitID == kRootUnitId && FIDStringsEqual (functionName, kCompGainReduction))
        paramID = kMyGainReductionId;
  
    return (paramID != kNoParamId) ? kResultOk : kResultFalse;
}

宿主实现示例

if (auto functionName = Steinberg::U::cast<Vst::IParameterFunctionName> (mEditController->getIEditController ())
{
    Vst::ParamID paramID;
    if (functionName->getParameterIDFromFunctionName (Vst::FunctionNameType::kCompGainReduction, paramID) == kResultTrue)
    {
        // 出于性能考虑，paramID 可以被缓存
        Vst::ParamValue norm = mEditController->getIEditController ()->getParamNormalized (paramID);
        Vst::ParamValue plain = mEditController->getIEditController ()->normalizedParamToPlain (paramID, norm);
        // plain 类似于 -6（-6dB）
    }
}
