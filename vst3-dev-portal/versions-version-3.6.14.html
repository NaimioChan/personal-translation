版本 3.6.14（2019/11/29）

  • VSTGUI 4.9

    • 新控件：VSTGUI::CListControl，配合 VSTGUI::CStringList 使用
    • 自定义字体支持：VSTGUI 现在支持使用嵌在其 Bundle/Package 中 Resources/Fonts 下的字体。请注意，在 Windows 上仅当使用 Windows 10 SDK 构建时才有效，且也只能在 Windows 10 上运行。macOS 或 Linux 上没有此限制。

  • CMake：

    • 小幅重构。
    • 添加文件 SMTG_VST3_SDK.cmake。
    • 更好的 FindJack 支持。
    • 更好的 Linux 交叉编译器支持。

  • 示例：

    • 在 HostChecker 插件中添加更多检查和 64 位处理支持。
    • 添加「HostChecker Plug-in」的 AAX 版本。
    • 在 Validator 中添加新测试：
      • 线程化处理、旁通持久化。
      • 运行更多测试的新选项（optExtensiveTests，「Run extensive tests (may take a long time)」）。
      • 改进 MidiMappingTest 的性能。

  • 插件包装层：

    • InterAppAudio 包装层已弃用，可能会在下次 SDK 更新中移除。在 iOS 上请改用 AudioUnit V3。
    • AAX 包装层（VST 3 - AAX 包装层）：
      • 添加 SMPTE 支持。

  • 辅助类：

    • 终止时清空 EditControllerEx1 中的 programLists、programIndexMap 和 units

  • VST3PluginTestHost v2.8.10 版本。

    • Windows 上的菜单变更。
    • 添加新测试。
