引言

当 VST 3 插件打算替换另一个插件时，无论对方是旧版本还是 VST 2 版本，都可能需要将参数重映射告知宿主。IRemapParamID 这个新插件接口便于实现此类重映射。

插件需要此类重映射时，主要有两种使用场景：

  • 当某个 VST 3 插件替换另一个具有不同 UID 的插件（无论是 VST 2 还是以前发布的 VST 3 版本）时。在这种场景下，这个新的 VST 3 插件应使用 Moduleinfo 表明它替换了另一个插件。旧插件的某些参数可能需要重映射到新插件的专用参数，以便宿主重新同步对旧参数的任何引用（例如在自动化或远程控制中）。例如，VST 2 参数使用索引标识，而 VST 3 参数使用 ParamID。借助这个新接口，如果旧索引与新关联的 ParamID 并不相同，宿主就可以将旧索引重映射到新的 ParamID。

  • 当 VST 3 插件更新到新版本，而其中某些参数的 ParamID 发生了变化时。在加载工程时，插件检测到该工程是由旧版本创建的，并通知宿主（kParamIDMappingChanged）：必须使用 IRemapParamID 接口来重新同步某些参数（如果宿主已经持有对插件参数的引用，例如在自动化中）。

IRemapParamID（参数 ID 重映射接口）

插件必须在其 IRemapParamID EditController 中实现此接口。取回的 paramID 应与它所替换的那个相匹配，从而在自动化回放期间保持一致的行为。

  • [plug imp]
  • [released: 3.7.11]

RestartFlags: kParamIDMappingChanged

在上述第二种使用场景中，插件在加载其状态时，通过 kParamIDMappingChanged 标志（位于 IComponentHandler::restartComponent 函数中）告知宿主参数 ID 发生了变化。此通知应由 EditController 在 setComponentState 或 setState 方法中（工程加载期间）触发。随后，宿主即可借助 IRemapParamID 接口重映射任何已使用的参数，例如自动化。

  • [plug imp]
  • [released: 3.7.11]

示例

在 controller.h 中：

//------------------------------------------------------------------------
class TestRemapParamIDController : public EditController, public IRemapParamID
{
public:
    //...
    //--- from IRemapParamID ---------------------------------------------
    tresult PLUGIN_API getCompatibleParamID (const TUID pluginToReplaceUID /*in*/,
                                         Vst::ParamID oldParamID /*in*/,
                                         Vst::ParamID& newParamID /*out*/) override;

    //--- from EditController --------------------------------------------
	tresult PLUGIN_API setComponentState (IBStream* state) override;

    //---Interface---------
    DEFINE_INTERFACES
    	DEF_INTERFACE (IRemapParamID)
    END_DEFINE_INTERFACES (EditController)
    DELEGATE_REFCOUNT (EditController)
    //... 
};

在 controller.cpp 中：

//------------------------------------------------------------------------
tresult PLUGIN_API TestRemapParamIDController::getCompatibleParamID (const TUID pluginToReplaceUID,
                                                                     Vst::ParamID oldParamID,
                                                                     Vst::ParamID& newParamID)
{
	//--- 我们要替换 AGain 插件-------
	//--- 检查宿主是否在请求重映射 AGain 插件的参数
	static const FUID AGainProcessorUID (0x84E8DE5F, 0x92554F53, 0x96FAE413, 0x3C935A18);
	FUID uidToCheck (FUID::fromTUID (pluginToReplaceUID));
	if (AGainProcessorUID != uidToCheck)
		return kResultFalse;

	//--- 宿主想要从 AGain 重映射------------
	newParamID = -1;
	switch (oldParamID)
	{
		//--- 将 kGainId (0) 映射到我们的参数 kMyGainParamTag
		case 0:
		{
			newParamID = kMyGainParamTag;
			break;
		}
	}
	//--- 如果映射成功则返回 kResultTrue------------
	return (newParamID == -1) ? kResultFalse : kResultTrue;
}

tresult PLUGIN_API TestRemapParamIDController::setComponentState (IBStream* state)
{
	//...
    IBStreamer streamer (state, kLittleEndian);

    // 读取状态

    bool remapNeeded = false;
    // 此处判断我们是否解析出该状态来自旧版插件
    //...

    // 然后调用 restartComponent
    if (remapNeeded)
        componentHandler->restartComponent (kParamIDMappingChanged);

    return kResultOk;
}
