引言

此接口 Vst:: ITransportControl 允许插件向宿主请求与走带相关的操作。

  • [host imp]
  • [扩展 Vst:: IComponentHandler]
  • [released: 3.8.1]
  • [optional]

典型用例包括：

  • 跳转（定位）到某个位置
  • 开始或停止播放或录音
  • 调整循环区域
  • 启用或禁用循环播放

所有调用都必须从 UI 线程发起。宿主可能会根据其内部策略或当前编辑模式（例如离线渲染、写保护状态等）接受或拒绝请求。

枚举说明
Locate将走带定位到新位置。需要有效的 TransportPosition。
PlaybackStart从当前位置开始播放。
PlaybackStop停止播放并保持当前位置。
LocateAndPlaybackStart定位到指定位置并开始播放（需要位置）。
PlaybackStopAndLocate停止播放并定位到指定位置（需要位置）。
RecordOnPlaybackStart从当前位置开始录音和播放。
LocateAndRecordOnPlaybackStart定位到指定位置并开始录音和播放（需要位置）。
RecordOff停止录音并继续播放。
RecordOffPlaybackStop停止录音和播放并保持当前位置。
RecordOffPlaybackStopAndLocate停止录音和播放，然后定位到指定位置（需要位置）。
SetCycleStart设置循环区域中包含的第一个采样（需要位置）。
SetCycleEnd设置紧接循环区域结束之后的采样位置（排他性的结束位置，需要位置）。以采样计的循环长度为 end - start。例如，SetCycleStart(100) 与 SetCycleEnd(200) 定义了一个 100 个采样的循环。循环中包含的采样位置为 {100 ... 199}，而采样位置 200 不在循环内。
CycleOn启用循环模式。
CycleOff禁用循环模式。

示例

在 mycontroller.cpp 中

bool mycontroller::startPlayback ()
{
    // hostContext 是在 ComponentBase::initialize (FUnknown* context) 函数中传入的
    if (!hostContext)
        return false;

    Vst::ITransportControl* transportControl = nullptr;
    hostContext->queryInterface (Vst::ITransportControl::iid, (void**)&transportControl);

	if (transportControl && transportControl->isActionSupported (Vst::ITransportControl::PlaybackStart) == kResultTrue)
	{
        transportControl->requestAction (Vst::ITransportControl::PlaybackStart);
        return true;
    }
    return false;
}
