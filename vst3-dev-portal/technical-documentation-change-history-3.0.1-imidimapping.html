引言

MIDI CC 与参数之间的映射是如何工作的。

MIDI 映射接口：Vst:: IMidiMapping

  • [plug imp]
  • [extends Vst:: IEditController]
  • [发布于：3.0.1]
  • [optional]

MIDI 控制器不会直接传输给 VST 组件。MIDI 作为硬件协议有一些限制，而在软件中可以避免这些限制。尤其是控制器数据，其语义往往不明确且常被忽略。此外，直接传递 MIDI 控制器时，它们可能干扰常规的参数自动化，而宿主并不知道插件内部发生了什么。

因此，任何要由 MIDI 控制器控制的功能都必须导出为常规参数。宿主会使用该接口转换传入的 MIDI 控制器数据，并将其作为常规的参数更改传输。这使宿主能够像其他参数一样对它们进行自动化。CtrlNumber 可以是典型的 MIDI 控制器值，并扩展到其他一些值，例如弯音或触后（参见 ControllerNumbers）。如果映射已更改，插件必须调用 Vst:: IComponentHandler::restartComponent（kMidiCCAssignmentChanged）以通知宿主此更改。

示例

在 myeditcontroller.h 中

//--------------------------------------
class MyEditController: public EditControllerEx1, public IMidiMapping
{
    //...
    //---IMidiMapping---------------------------
    tresult PLUGIN_API getMidiControllerAssignment (int32 busIndex, int16 channel, CtrlNumber midiControllerNumber, ParamID& id) SMTG_OVERRIDE;
    //---Interface---------
    OBJ_METHODS (MyEditController, EditControllerEx1)
    DEFINE_INTERFACES
        DEF_INTERFACE (IMidiMapping)
    END_DEFINE_INTERFACES (MyEditController)
    REFCOUNT_METHODS (MyEditController)
};

在 myeditcontroller.cpp 中

//--------------------------------------
tresult PLUGIN_API MyEditController::getMidiControllerAssignment (int32 busIndex, int16 midiChannel, CtrlNumber midiControllerNumber, ParamID& tag)
{
    // 仅针对我的第一个事件总线、MIDI 通道 0 以及 MIDI CC 音量
    if (busIndex == 0 && midiChannel == 0 && midiControllerNumber == kCtrlVolume)
    {
        tag = kGainId;
        return kResultTrue;
    }
    return kResultFalse;
}
