切换到另一个 VSTGUI 子模块或分支

目标

有时出于测试目的，需要切换到另一个 VSTGUI 子模块或分支。本教程说明如何操作。

切换到另一个子模块

进入你本地的 VST SDK 检出目录，在命令行执行以下命令来切换子模块：

git submodule set-url vstgui4 /path/to/vstgui/
git submodule sync
git submodule update --init --recursive --remote vstgui4

路径 /path/to/vstgui/ 应指向一个有效的 VSTGUI 仓库。请注意 set-url命令会修改 .gitmodules 文件。

在 Windows 上，本地路径也请使用 / 作为分隔符，例如 C:/path/to/vstgui/

切换到另一个分支

进入 VSTGUI 子模块并执行 git checkout，即可切换到任意其他分支。

git checkout my_branch
