版本 3.1.0（2010/06/25）

  • SDK 重构：

    • 新增 Base 模块（许多有用的类，例如模板和容器）。
    • 将文件 public.sdk/source/main/pluginfactory.cpp 重命名为 public.sdk/source/main/pluginfactoryvst3.cpp。
    • 将文件 public.sdk/source/main/pluginfactory.h 重命名为 public.sdk/source/main/pluginfactoryvst3.h。
    • 重命名 Microsoft Visual 项目。

  • 新接口：

    • Vst::IEditController2：支持 setKnobMode/openHelp/openAboutBox。
    • Vst::IComponentHandler2：支持从插件 UI 编辑参数组、脏状态，以及请求宿主打开插件编辑器。
    • Vst::IAudioPresentationLatency：向插件通知音频呈现延迟（输入/输出）。

  • 新事件结构：

    • Vst::PolyPressureEvent：PolyPressure 事件支持。

  • 新增标志位/枚举：

    • 用于 subCategories 的新插件类型：PlugType::kMono、PlugType::kStereo、PlugType::kSurround。
    • 新参数标志 ParameterInfo::kIsList：将该参数标记为离散字符串值列表。
    • 新增 IoModes 枚举：Vst::IoModes::kOfflineProcessing，当插件在离线处理上下文中使用时与 setIoMode 配合。

  • 插件包装层：

    • 新增 VST 3 - VST 2.x 包装层：只需添加少量初始化代码，就能为你的 VST 3 插件提供 VST 2.x 版本
    • 新增 VST 3 - Audio Unit 包装层：只需少量构建设置，就能让你的 VST 3 插件提供 AU 支持

  • 示例：

    • 新增 VST 3 插件示例：ADelay 插件、mda VST 3 插件（感谢 Paul Kellet 与 Arne Scheffler）
    • 移除 Visual Studio 2003 项目
    • 清理 AGain，并添加支持侧链的单独版本

  • VST3PluginTestHost：

    • 添加 MIDI 输入支持。
    • 更好的 ASIO 支持。
    • 添加 Mac 64 位支持（Cocoa 视图在 32 位中也受支持）。

  • Validator 中的修复

  • 一些文档变更。
