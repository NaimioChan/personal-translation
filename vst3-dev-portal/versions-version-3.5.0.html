版本 3.5.0（2011/02/04）

  • 接口变更：

    • Vst::INoteExpressionController：[3.5.0] 音符表达式 支持。
    • Vst::IKeyswitchController：[3.5.0] 键位切换 支持（例如用于在 Cubase 6 中构建 VST Expression Map）。
    • Vst::IXmlRepresentationController：参数的 [3.5.0] 远程表示 支持（允许为不同的远程设备定义不同的参数映射）。
    • Vst::IEditControllerHostEditing：从宿主/遥控编辑参数（在从遥控编辑时更好地支持链接的参数）
    • Vst::IComponentHandler3 / Vst::IContextMenu / Vst::IContextMenuTarget：[3.5.0] 上下文菜单支持（允许插件为给定参数创建上下文菜单，其中部分内容由宿主填充）。

  • 新增标志位/枚举：

    • 新增重启标志：Vst::kIoTitlesChanged：通知宿主总线的标题变更。

  • 辅助类：

    • 新增 Vst::XmlRepresentationHelper：用于构建远程表示（基于 xml）的辅助类。参见 [3.5.0] 参数的远程表示支持。
    • Vst::EditControllerEx1：新增 ProgramPitchNames 支持。

  • 示例：

    • 新增 VST 3 乐器示例：
      • 支持音符表达式事件的乐器 Note Expression Synth 插件。
      • 展示 ProgramPitchNames 支持的 PitchNames 效果器。

  • Validator 工具：

    • 更多命令行选项。
    • 允许插件添加自定义测试。

  • VSTGUI 4.0

    • 带有最佳 VST 3 支持的 VSTGUI 预览版本。

  • 插件包装层：

    • VST 3 - Audio Unit 包装层的修复，以及对程序变更的支持。

  • 一些文档变更。
