引言

SDK 包含一些插件实现示例。传奇的 AGain 与 ADelay，多亏 Paul Kellet 提供的开源 mda 插件，一个支持「音符表达式事件」的基础 音符表达式合成器，一个支持 PitchNames 的插件示例，一个检查宿主是否符合 VST 3 规范的 VST 3 宿主检查器，以及更多……

查看 SDK 的 "public.sdk/samples/vst" 文件夹！

ⓘ 注意
它们使用 cmake 作为项目生成器：使用 cmake 构建 VST 3 插件
要添加你自己的插件，请参阅：用项目生成器 App 生成新插件

AGain

SDK 包含一个 AGain 插件，它是一个非常简单的 VST 3 插件。这个插件：

  • 兼容多通道
  • 支持旁通处理
  • 有一个可自动化的增益参数
  • 有一个事件输入总线（可以用 noteOn 力度控制增益系数）
  • 有 VU 峰值表
  • 使用 VSTGUI4 库
  • 还提供带侧链的这个插件版本（展示一个使用相同控制器和不同组件的插件）
  • 提供 AAX 版本
  • 提供 AUv3 版本

查看 SDK 的 "public.sdk/samples/vst/again" 文件夹！

类：

  • AGain
  • AGainWithSideChain（用于侧链版本）
  • AGainController

mda 插件

  • 效果器（立体声到立体声插件）：
    • Ambience：混响。
    • Bandisto：多段失真。
    • BeatBox：鼓替换器。
    • Combo：音箱与扬声器模拟器。
    • DeEsser：高频动态处理器。
    • Degrade：采样品质降级。
    • Delay：带反馈音调控制的简单立体声延迟。
    • Detune：简单的上下移调加厚器。
    • Dither：多种抖动类型，包括噪声整形。
    • DubDelay：带反馈饱和与时间/音高调制的延迟。
    • Dynamics：压缩器/限制器/噪声门。
    • Image：立体声声像调整与 M-S 矩阵。
    • Leslie：旋转扬声器模拟器。
    • Limiter：光电式限制器。
    • Loudness：用于低音均衡与混音校正的等响曲线。
    • MultiBand：带 M-S 处理模式的多段压缩器。
    • Overdrive：软失真。
    • RePsycho!：鼓循环音高变换器。
    • RezFilter：带 LFO 与包络跟随器的共振滤波器。
    • RingMod：简单的环形调制器。
    • Round Panner：3D 声像器。
    • Shepard：连续上升/下降的音调发生器。
    • SpecMeter：立体声 13 段频谱表。
    • Splitter：用于搭建动态处理的频率/电平分频器。
    • Stereo Simulator：Haas 延迟与梳状滤波。
    • Sub-Bass Synthesizer：多种低频增强方法。
    • TalkBox：高分辨率声码器。
    • TestTone：可产生粉红噪声、白噪声、脉冲与扫频的信号发生器。
    • Thru-Zero Flanger：经典磁带镶边模拟。
    • Tracker：音高跟踪振荡器，或音高跟踪 EQ
  • 乐器（1 个事件输入，1 个立体声音频输出）：
    • DX10：音色类似后来的 Yamaha DX 合成器，包括厚重的低音，但音色更温暖、更干净。
    • EPiano：简单的电钢琴。
    • JX10：该插件面向高品质（混叠低于大多数软件合成器）与低处理器占用而设计。
    • Piano：并不以成为世界上最好听的钢琴为目标，但 CPU 与内存占用极低。

测试参数 ID 重映射

非常简单的插件：

  • 演示 VST 3 插件如何替换另一个插件并重映射参数 ID。
  • 当 AGain 插件不可用时，它可以替换该插件。
  • 它演示了接口 Vst:: IRemapParamID（用于把 测试参数 ID 重映射 的参数映射到 AGain 插件参数）以及带兼容性字段的模块信息。
