目标

这是一个简单的 Hello World VST 3 FX 插件，用于演示如何把 VST SDK 作为外部工程使用。

该插件由 VST 3 Project Generator 生成，可在此处获取 https://github.com/steinbergmedia/vst3_example_plugin_hello_world

第 1 部分：如何克隆和构建

打开命令提示符并执行以下操作：

git clone https://github.com/steinbergmedia/vst3_example_plugin_hello_world.git
mkdir build
cd build
cmake ../vst3_example_plugin_hello_world
cmake --build .

第 2 部分：改造 helloworld 示例

  • 这个示例主要是为了演示如何把 VST SDK 作为外部工程使用，我们强烈建议使用 Project Generator 从零开始。

  • 在下面的说明中，我们尝试展示如何在 helloworld 示例的基础上修改源代码来构建你自己的插件。

  • 现在你必须改造一些 uids 和命名，使你的插件具有唯一性（而不是 helloworld 的副本！）

    1. 把插件中的所有字符串从 HelloWorld 重命名为 MyDelay（例如）：

      • HelloWorldProcessor::HelloWorldProcessor 改为 MyDelayProcessor::MyDelayProcessor

    2. 打开文件 vst3_example_plugin_hello_world/include/helloworldcids.h，为 processor 和 controller 创建新的 uids：你可以使用 GUID 生成工具，例如 https://www.guidgenerator.com：

    static const FUID kHelloWorldProcessorUID (0x2A0CC26C, 0xBF88964C, 0xB0BFFCB0, 0x554AF523);
static const FUID kHelloWorldControllerUID (0xB9DBBD64, 0xF7C40A4C, 0x9C8BFB33, 0x8761E244);
    1. 打开文件 version.h 并按以下方式改造其中的字符串：
    #define stringOriginalFilename "MyDelay.vst3"

#define stringFileDescription	"MyDelay VST3"
    1. 打开文件 helloworldentry.cpp 并改造字符串：
    #define stringPluginName "My First Delay"

  • 现在你可以开始为你的效果器/乐器编写代码了（分步说明请参见 编写你的第一个插件）

    1. 在 helloworldcontroller.cpp 中添加参数
    2. 在 helloworldprocessor.cpp 中改造你的处理算法
    3. 在 helloworldprocessor.cpp 中添加持久化
    4. 添加 UI（请查看使用 VSTGUI) 的 SDK 示例

  • 编码愉快！
