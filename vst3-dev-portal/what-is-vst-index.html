VST 3：Virtual Studio Technology 标准

借助 VST（Virtual Studio Technology），Steinberg 于 1996 年确立了世界上领先、支持也最广泛的插件与虚拟乐器标准。通过 VST 3，Steinberg 向音频行业发布了 Steinberg 的 Virtual Studio Technology 的下一个主要版本。VST 3 的代码库被完全重写，不仅带来众多新功能，还提供了迄今最稳定可靠的 VST 平台，是音频技术上的一个重要里程碑。最新技术与新功能的这一结合，源自 Steinberg 作为领先插件接口提供商十二年的开发经验。VST 3 在设计上要为音频行业的众多创新产品提供技术与创意基础，为乐器与效果器插件的用户带来新的创意空间。VST SDK 作为免费技术提供，任何开发者都可以公开使用。

关于 VST 标准

Virtual Studio Technology（VST）接口堪称数字音频领域的一场革命。它由 Steinberg 开发，1996 年首次发布，在你的计算机上构建出完整的专业录音棚环境。VST 允许把虚拟效果处理器和虚拟乐器集成到你的数字音频环境中。它们既可以是硬件效果器和硬件乐器的软件复刻，也可以是 VST 系统中的全新创意效果组件。所有这些都无缝集成到 VST 兼容的宿主程序中，例如数字音频工作站（DAW）。VST 还便于接入外部设备，让你搭建适合自己的系统。作为一项开放标准，VST 提供的能力在过去十年间持续增长。Steinberg 以及几十家其他公司不断推出新的虚拟效果处理器和虚拟乐器。

从技术角度看

VST 插件是宿主程序中使用的一种音频处理组件。宿主程序提供由插件代码处理的音频流和/或事件流。一般而言，VST 插件可以接收音频数据流，对音频进行处理，再把结果返回给宿主程序。VST 插件通常使用计算机的处理器完成处理。音频流被分割成一系列块，宿主按顺序提供这些块。块大小由宿主及其当前环境决定。VST 插件自己维护运行过程中涉及的全部参数状态：宿主不保存任何关于插件如何处理上一个数据块的信息。

从宿主程序的角度看，VST 插件是一个黑盒，具有任意数量的输入、输出（事件（MIDI）或音频）以及相关参数。宿主无需知道插件内部的处理过程就能使用它。插件处理过程可以在内部使用它想要的任何参数，而根据宿主的能力，它也可以允许宿主对用户参数的更改进行自动化。

VST 插件的源代码与平台无关，但交付形式取决于平台的架构：

  • 在 Windows 上，VST 插件是一个多线程 DLL（动态链接库），近来改为打包成文件夹结构。
  • 在 macOS X 上，VST 插件是一个 Mach-O Bundle。
  • 在 Linux 上，VST 插件是一个包。
