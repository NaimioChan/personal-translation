目标

本教程说明如何使用 VST 3 Project Generator 创建新的音频插件并添加一些基本功能，该工具包含在 VST SDK 中。

最终产物是一个音频插件，它可以对音频信号计算一个增益，并能加载到 Cubase、WaveLab 等宿主中。

第 1 部分：获取并安装 VST SDK

有关下载 SDK，请参见「如何为 VST 3 配置系统」一节。

开始新项目有以下几种方式：

  • 你可以使用 helloworld 模板。
  • 或者，更简单、也更被推荐的方式是使用 VST 3 Project Generator 应用，它包含在 VST SDK 中。以下步骤说明如何使用它。

第 2 部分：使用 VST 3 插件 Project Generator 应用

VST 3 Project Generator 应用包含在 VST SDK 中，可用于 Windows 和 macOS。

启动 VST3_Project_Generator 文件夹中的应用，它位于 VST SDK 中。

检查 Preferences 选项卡中是否已有所需信息：参见设置偏好设置。

在 Create Plug-in Project 选项卡中，你需要输入要创建的插件的信息：

更详细的文档请参见 Create Plug-in Project 选项卡，它位于 VST 3 Project Generator 对话框中。

输入完所有信息后，点击 Create。随后会启动一个脚本，在 Output 目录中创建包含已更新文件的项目。此步骤之后会启动 IDE（Visual Studio 或 XCode）。

编译项目并测试你的新插件。插件创建在 Output Directory 中，为了让 VST 3 宿主能看到它，你可能需要把它复制或建立符号链接到官方的 VST 3 位置 / 格式。

例如，如果你把 Type 选为 Audio Effect，就会创建一个简单的 Stereo→Stereo 插件。

理解 VST 3 插件如何工作，一个好办法是在处理器和控制器文件的每个函数中加上断点：

tresult PLUGIN_API MyPluginController::initialize (FUnknown*context);
tresult PLUGIN_API MyPluginController::terminate ();
//...
tresult PLUGIN_API MyPluginProcessor::initialize (FUnknown*context);
//...

然后从调试器启动一个 VST 3 宿主。

就是这样，现在你可以开始写代码了，参见下一个教程编写你的第一个插件。
