引言

把 VST 3 插件包装为 AAX 插件的辅助类。

VST SDK 包含一个辅助类，可把 VST 3 音频处理器和编辑控制器包装成 AAX 插件。

它是如何工作的？

  • 参见 AGainAAX 示例。

  • 有关如何获取 AAX SDK 的更多信息，可访问 Avid Technology AAX SDK 页面。

  • 需要在 external.avid.aax 文件夹（与 public.sdk 文件夹同级）中准备 AAX SDK 2.7 或更高版本。

  • 以下是基于 AGainAAX 示例的步骤：

    • 在 cpp 文件 againaax.cpp 中，你可以定义插件属性：IO 音频、产品 ID ...
    • 在 Windows 上，把链接器输出的 again_aax.aaxplugin 复制到「C:\Program Files\Common Files\Avid\Audio\Plug-Ins\again_aax.aaxplugin\Contents\x64」（调试构建会自动完成，但需要相应的访问权限（你所用 Visual 的管理员权限））。
    • 在 OSX 上，把构建好的 bundle build/Debug/again.aaxplugin 复制到「/Library/Application Support/Avid/Audio/Plug-Ins」。

  • AAX 插件必须使用 PACE Anti-Piracy 的签名工具进行数字签名，才能在商业版 Pro Tools 中使用。

  • 若要在不签名的情况下测试插件，你可以使用 Pro Tools 的特殊版本：Pro Tools Developer，可在此申请：https://developer.avid.com/aax。

  • 运行 Pro Tools 并访问 AAX SDK 需要 iLok 以及 Avid 账号。
