为什么使用 VST SDK？

使用 VST SDK 可以实现不同的使用场景：

  1. 你是插件开发者，想要创建能被 VST 3 宿主程序加载和使用的音频效果器或乐器插件。

    • 音频效果器插件是一种音频处理器效果，以音频为输入并生成音频输出：例如 延迟、移相器、压缩器、混响，…
    • 乐器插件是一种声音/音频发生器，以音符事件为输入并生成音频输出：例如对知名硬件合成器的模拟。乐器插件有 2 种：基于采样的虚拟乐器（以音频采样作为声音生成的基础）与虚拟合成器（使用不同类型的合成方式：物理建模、加法、减法、FM、基于采样，…）

  2. 你是宿主开发者，想要在自己的应用程序中加载 VST 3 插件：

    • 音频效果器和/或
    • 乐器插件。

使用 VST SDK 的优势

直接使用 VST SDK：

  • 你可以确保符合 VST 3 格式。
  • 基于 VST 3 格式开发插件，可以轻松支持新的 VST 3 特性，从而改进这些插件在 DAW 中的集成。一些第三方 SDK 只在所有插件格式之间使用一个通用层，从而限制了实现更好集成的可能，例如 VST 3 独有的特性：
    • 上下文菜单
    • 脏状态
    • 差异化地加载预设或工程
    • 音符表达式
    • 参见 VST 3 的其他优势
  • 你可以获得 VSTGUI 工具与 VST 3 的最佳集成。
  • 它包含主要的插件格式包装层：AAX、AUv3、AU。
  • 附带的 Validator 可以检查你的插件是否符合 VST 3 标准。
