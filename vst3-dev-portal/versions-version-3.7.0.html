版本 3.7.0（2020/07/29）

  • 接口变更：

    • 新增 Vst:: IProcessContextRequirements（由插件实现）。
      • 这是使用 VST SDK 3.7 或更新版本构建时插件需要实现的新必需接口。
    • 新增 Vst:: IProgress（由宿主实现）。
    • 新增 Vst:: IParameterFunctionName（由插件实现）。

  • 新增标志位/枚举：

    • 新增 kIsHidden 标志。使用该标志时，宿主不应显示该参数，且无法从插件外部修改它。
    • 新增预定义 2D 扬声器布局：
      • k90Cine、k91Cine（L R C Lfe Ls Rs Lc Rc Sl Sr）
      • k100Cine、k101Cine（L R C Lfe Ls Rs Lc Rc Cs Sl Sr）
    • 新增预定义 3D 扬声器布局：
      • k90_4、k91_4（L R C Lfe Ls Rs Lc Rc Sl Sr Tfl Tfr Trl Trr）
      • k90_6、k91_6（L R C Lfe Ls Rs Lc Rc Sl Sr Tfl Tfr Trl Trr Tsl Tsr）
    • 新增总线标志：用于音频总线的 kIsControlVoltage。

  • 文档：

    • 添加关于 VST 3 和 MIDI 2.0 的文档：
      • 与 MIDI 1.0 相比，MIDI 2.0 提高了分辨率。
      • MIDI 2.0 的逐音符控制器。

  • CMake：

    • 新增 cmake 文件。
    • 修复 Windows 上使用 powershell 以管理员权限创建 VST 3 文件夹的问题。

  • 示例：

    • 新增 VST 3 插件示例：
      • SyncDelay，使用 Vst:: IProcessContextRequirements。
      • Panner，使用 PlugType::kSpatialFx 作为子类别，展示如何构建 Mono 到 Stereo 的 Panner 插件。
    • 在 HostChecker 插件中添加了检查：
      • 支持 kIsHidden 标志。
      • 支持 Vst:: IProgress（由宿主实现）。
      • 支持 Vst:: IParameterFunctionName。
      • 检查主输入和 侧链 输入是否使用了静音标志。

  • 插件包装层：

    • 修复 AAX/VST 2 BaseWrapper 的 setChunk 属性：未为组件设置 Vst::StateType::kProject。

  • 辅助类：

    • 添加用于加载 FXB/FXP 状态以及写入 FXB 状态的函数，以兼容 VST 2.x（见 public.sdk/source/vst/utility/vst2persistence.h）。
    • 修复使用 MinGW-w64 GCC 编译器的编译。
    • 新辅助工具：openurl.h，可在默认关联应用中打开 URL。

  • VST3PluginTestHost v2.9.0：VST 3 插件测试宿主。

    • 添加了对以下内容的支持：
      • IProgress
      • IProcessContextRequirements
      • IParameterFunctionName
    • 修复按特定顺序关闭同一插件的 2 个或更多 GUI 实例时崩溃的问题
    • 修复对实现 IMidiMapping 的 SingleComponentEffect 插件的支持

  • VST 3 Project Generator v1.0.0 版本：

    • 全新、易用的 VST 3 Project Generator。
