版本 3.5.2（2012/09/25）

  • 接口变更：

    • 音符表达式支持新的事件类型：NoteExpressionTextEvent。

  • 示例：

    • 修复 Visual Studio 2010 项目（已添加筛选器）
    • 针对 XCode4 的适配（again 示例项目使用 VSTGUI 3.6，其 32 位构建需要 10.6 SDK，在更新的 Xcode 工具中该 SDK 已不可用。如果使用 VSTGUI 3.6，就需要使用包含 10.6 SDK 或更早 SDK 的 Xcode 版本。）。

  • 插件包装层：

    • VST 3 - Audio Unit 包装层：

      • 修复 noteOn 与 noteOff 的偏移。
      • 修复 IO 总线变更时的 RestoreState。
      • 新增 MIDI PolyPressure 支持。
      • 不可自动化的参数现在带有 FlagAudioUnitParameterFlag_NonRealTime AU 标志。
      • 修复在 Logic 下单声道轨道未设置采样率的问题。

    • VST 3 - VST 2.x 包装层：

      • 修复 getMidiProgramCategory。

  • 新增标志位/枚举：

    • 新增预定义扬声器布置：基于 Auro 3D 定义的 9.0/9.1/10.0/10.1/11.0/11.1/13.0/13.1（https://www.auro-3d.com/）。

  • 辅助类：

    • Base 中的新增内容：
      • 类 Steinberg::Region。
      • 类 Steinberg::IStreamWrapper。
      • 辅助类 Steinberg::HexBinary：HexBinary 编码与解码。

  • 一些文档变更

    • Vst:: IParameterFinder：为启用重要功能（如 AI Knob），新增了实现该接口的建议。
    • VST 3 插件位置的优先级已变更：宿主应在 Global 层之后扫描 Application 层。

  • 许可证变更，例如源代码文件。
