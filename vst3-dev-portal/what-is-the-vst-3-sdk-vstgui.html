引言

这是一个主要为音频插件（VST®、AudioUnit®、AAX® 等）设计的用户界面工具包。基于插件 UI 的 XML 定义，VSTGUI 包含一个内嵌编辑器（UIDescription Editor），让开发者可以通过拖放 UI 元素来创建插件 UI 界面。

VSTGUI 最初由 Steinberg Media Technologies 于 1998 年前后为其最早的 VST 插件内部开发，后来以二进制库的形式纳入官方 VST SDK。自 2003 年 5 月起，VSTGUI 已开源，现托管在 GitHub 上 https://github.com/steinbergmedia/vstgui。

VSTGUI 的最新正式版本始终包含在 VST SDK 中。
