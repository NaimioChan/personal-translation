版本 3.6.0（2013/11/22）

  • 接口变更：

    • 通过 Vst::IStreamAttributes 提供预设元信息
    • 新事件类型：Vst::ChordEvent、Vst::ScaleEvent

  • 插件包装层：

    • [3.6.0] iOS 应用间音频支持
    • VST 3 - VST 2.x 包装层：
      • 修复在宿主中于单精度与双精度处理之间切换时的问题。
      • 修复 kProgramChangeStatus 下的 setProgram 与 processMidiEvent，其中 programChange 参数使用了错误的 idx。
    • VST 3 - Audio Unit 包装层：
      • 在 macOS X 10.7 中更新到新的 AUPlugIn API。
      • 为 NSDataIBStream 添加虚析构函数。

  • 新增标志位/枚举：

    • 新增预定义 3D 扬声器布置：k81MPEG3D、k222。

  • 辅助类：

    • 修复启用 UNICODE_OFF 时的编译问题。

  • 示例：

    • 新增 VST 3 HostChecker 插件。

  • VSTGUI 4.2

    • 更新到包含 iOS 支持的 4.2 最终版本。

  • VST3PluginTestHost：

    • 新功能：在 VST 3 预设中覆盖插件名称。

  • 许可条款已变更！请阅读新的许可协议 VST 3 许可问题。

  • Xcode 5 说明：要为 macOS X 成功构建示例，需要把 base/mac/config/settings/sdk_deployment_10_6.xcconfig 中的 SDKROOT 变量改为 macosx10.8。
