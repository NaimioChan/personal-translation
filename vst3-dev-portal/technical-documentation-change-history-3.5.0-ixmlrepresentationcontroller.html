引言

如何更好地为参数支持远程设备/控制器（UI 与硬件）。

自 VST 3.5 起，提供了一个新接口：Vst:: IXmlRepresentationController

用于组件的扩展插件接口 Vst:: IEditController：Vst:: IXmlRepresentationController

  • [plug imp]
  • [extends Vst:: IEditController]
  • [发布于：3.5.0]
  • [optional]

基于 XML 的表示是一种为特定远程设备（硬件或软件机架（如 quick controls））导出、组织并分组插件参数的方式。它可以更精确地描述每个参数（哪一个最适合映射到旋钮、匹配受限远程显示的不同标题长度等）。

  • 一个表示由页面组成（这意味着要看到所有导出的参数，用户必须在各页面之间导航）。
  • 一个页面由单元格组成（例如每页 8 个单元格）。
  • 一个单元格由层组成（例如一个单元格可以有一个旋钮、一个显示和一个按钮，也就是 3 层）。
  • 层使用 ParameterID 作为标识符关联到插件参数：
    • 它可以是一个带标题和/或数值显示的旋钮，该显示使用相同的 ParameterID，但也可以使用另一个。
    • 开关
    • 链接，可直接跳转到某个子页面（位于另一页）
    • 更多……请参见 Vst::LayerType

该表示以 XML 文本实现，遵循文档类型定义（DTD）：http://dtd.steinberg.net/VST-Remote-1.1.dtd

             from company HardwareCompany.</comment>
 
     <!-- ===================================== -->

        <page name="Root">
            <cell>
                <layer type="knob" parameterID="0">
                    <titleDisplay>
                        <name>Mix dry/wet</name>
                        <name>Mix</name>
                    </titleDisplay>
                </layer>
            </cell>
            <cell>
                <layer type="display"></layer>
            </cell>
            <cell>
                <layer type="knob" parameterID="3">
                    <titleDisplay>
                        <name>Delay</name>
                        <name>Dly</name>
                    </titleDisplay>
                </layer>
            </cell>
            <cell>
                <layer type="knob" parameterID="15">
                    <titleDisplay>
                        <name>Spatial</name>
                        <name>Spat</name>
                    </titleDisplay>
                </layer>
            </cell>
        </page>
        <page name="Page 2">
            <cell>
                <layer type="LED" ledStyle="spread" parameterID="2">

VST XMLs 表示的位置表

当宿主需要使用 VST XMLs 表示时（例如用于内部用途，如 quick control 分配，以按页面获取插件最重要的参数），宿主会在特定位置检查给定远程设备和给定插件是否存在一个表示 XML 文件，其文件名就是远程名称（关于路径如何定义见下文）。如果找不到，宿主就会通过 Steinberg::Vst::IXmlRepresentationController 向插件询问（如果插件实现了它）。

说明：

  • 优先级列：
    • 指定宿主的扫描顺序。将先检查路径 #1，最后检查 #8。找到的第一个 XML 会被使用，并覆盖其他 XML。
  • 类型列：
    • 用户：专属于当前登录的用户
    • 共享：适用于本机的所有用户
    • 工厂：由插件或应用程序安装程序随插件一起安装
  • $COMPANY 和 $PLUGIN-NAME 文件夹名称只包含文件命名允许的字符
    • 把字符 "\*?/:.<>|\" " 替换为 "_"
  • $UID 是处理器唯一 ID 的字符串表示形式
    • 例如："57F704D1FA974D668083E4B9AF581D23" len=32)
