Moduleinfo

可选的 moduleinfo.json 文件可以是 模块文件包 的一部分，位于 Resources 文件夹中。

该文件包含与 模块工厂 相同的信息，外加一个可选的兼容类列表。该文件以 JSON5 格式编码。

Compatibility JSON 数组用于声明某个类应被视为另一个类或多个类的替代。

这样使用时，宿主无需加载组件就能知道模块提供哪些类。

这个可选的 moduleinfo.json 文件是在 VST SDK 3.7.5 版中新增的，当时位于 bundle 的 Contents 文件夹中。为了符合 macOS 上的代码签名要求，该文件现在（自 3.7.8 版起）位于 Contents/Resources 文件夹中。

SDK

VST SDK 包含一个名为 moduleinfotool 的命令行工具，用于从 VST 插件创建并校验 moduleinfo.json 文件。参见 public.sdk/vst-utilities/moduleinfotool。

moduleinfotool 使用 ModuleInfoLib，宿主可用它读取和解析 moduleinfo.json 文件。参见 public.sdk/source/vst/moduleinfo

对于用 VST SDK 构建的插件，moduleinfo.json 文件会在构建过程中自动创建。
