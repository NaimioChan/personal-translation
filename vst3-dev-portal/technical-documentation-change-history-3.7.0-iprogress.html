[3.7.0] 进度显示

本页内容：

  • 引言

引言

用于编辑控制器的扩展宿主回调接口：Vst:: IProgress。

  • [host imp]
  • [扩展 Vst:: IComponentHandler]
  • [released: 3.7.0]
  • [optional]

允许插件请求宿主为耗时任务创建进度显示。宿主可以将进度可视化为只读 UI 元素。例如，在加载工程时插件需要在后台线程中加载额外数据（如采样），这使宿主能够获取并可视化加载进度的当前状态，并在加载完成时通知用户。注意：在进度进行期间，宿主可以随时卸载插件。请确保插件支持这一使用场景。

示例

如何从插件侧调用

//--------------------------------------
// 我们在 editcontroller 中：
// 作为成员：IProgress::ID mProgressID;
  
if (auto progress = Steinberg::U::cast<IProgress> (componentHandler))
    progress->start (IProgress::ProgressType::UIBackgroundTask, STR ("Load Samples..."), mProgressID);
  
// ...
myProgressValue += incProgressStep;
if (auto progress = Steinberg::U::cast<IProgress> (componentHandler))
    progress->update (mProgressID, myProgressValue);
  
// ...
if (auto progress = Steinberg::U::cast<IProgress> (componentHandler))
    progress->finish (mProgressID);
