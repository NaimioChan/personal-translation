macOS 平台

在 macOS 平台上，VST 3 插件是标准的 macOS 包，其文件扩展名为 ".vst3"，并具有以下文件夹结构：

文件夹说明
MyPlugin.vst3/Contents/Resources/文件夹，包含该插件用到的所有附加资源文件
MyPlugin.vst3/Contents/Resources/moduleinfo.json插件的模块信息
MyPlugin.vst3/Contents/MacOS/文件夹，包含该插件的 macOS 通用二进制（Mach-O）
MyPlugin.vst3/Contents/Info.plist插件的属性列表
MyPlugin.vst3/Contents/PkgInfo指定该包的类型代码和创建者代码（可选）

Windows 平台

在 Windows 平台上，VST 3 插件以类似包的封装（普通文件夹）组织，其文件扩展名为 ".vst3"，并具有以下文件夹结构：

文件夹说明
MyPlugin.vst3/Contents/Resources/文件夹，包含该插件用到的所有附加资源文件
MyPlugin.vst3/Contents/Resources/moduleinfo.json插件的模块信息
MyPlugin.vst3/Contents/x86-win/MyPlugin.vst3文件夹，包含插件二进制文件（用于 i386 架构的 32 位 dll）
MyPlugin.vst3/Contents/x86_64-win/MyPlugin.vst3文件夹，包含插件二进制文件（用于 x86_64 架构的 64 位 dll）
MyPlugin.vst3/Contents/arm64ec-win/MyPlugin.vst3文件夹，包含插件二进制文件（用于 Arm64EC 架构的 64 位 dll）。
在 Windows on Arm 上，Arm64EC 或 x64 应用程序可以加载此架构。
MyPlugin.vst3/Contents/arm-win/MyPlugin.vst3文件夹，包含插件二进制文件（用于 Arm 经典架构的 32 位 dll）（已废弃）
MyPlugin.vst3/Contents/arm64-win/MyPlugin.vst3文件夹，包含插件二进制文件（用于 Arm64 经典架构的 64 位 dll）。

在 Windows on Arm 上，只有 Arm64 应用程序可以加载此架构。
MyPlugin.vst3/Contents/arm64x-win/MyPlugin.vst3文件夹，包含同时带有 Arm64 代码和 Arm64EC 代码的插件二进制文件
（用于 Arm64 经典架构的 64 位 dll）。

在 Windows on Arm 上，Arm64EC、Arm64 或 x64 应用程序可以加载此架构。
Windows on Arm 的推荐架构！
MyPlugin.vst3/desktop.ini用于在 Windows 资源管理器中设置自定义图标
MyPlugin.vst3/Plugin.ico自定义的插件图标

ⓘ 注意
在以前的 SDK 中，VST 3 插件被定义为扩展名为 .vst3 的单个 dll 文件。自 VST 3.6.10 起，这种方式已被废弃。

文件夹（包）与 DLL（.vst3）文件必须同名！

文件 desktop.ini 应包含：

desktop.ini

[.ShellClassInfo]
IconResource=Plugin.ico,0

然后用以下命令行更改它们的属性（s 表示 system，确保 Windows 会为文件夹/包使用它，r 表示只读，h 表示隐藏（可选））：

attrib +s +r +h desktop.ini
attrib +r +h Plugin.ico

在同一进程内的宿主中加载插件 DLL 的限制

参见 Microsoft 关于此事的博客：

操作系统PC 架构宿主进程应用兼容的插件架构
Windows 10Intel x86Intel x86Intel x86
Windows 10/11Intel x64Intel x64Intel x64*
Windows 10/11Intel x64Intel x86Intel x86
Windows 11Arm64Arm64 经典架构Arm64 经典、Arm64X 架构
Windows 11Arm64Arm64ECArm64X、Arm64EC、Intel x64 架构
Windows 11Arm64Intel x64Arm64EC、Intel x64、Arm64X 架构

「简而言之：请同时提供 Arm64EC 和 x64 版本的 DAW 与插件，并请始终使用最新的开发工具链和 SDK。」（Pete Brown - Microsoft）

ⓘ 注意
通过进程外/进程间通信，宿主可以覆盖这些限制，例如允许 Arm64 Classic 宿主处理 Arm64EC 插件。

ⓘ 注意
要详细了解 Arm64X（一种新型二进制文件，可以同时包含经典的 Arm64 代码和 Arm64EC 代码），请点击此处。

Linux 平台

在 Linux 上，VST 3 插件以类似包的封装组织，其文件扩展名为 ".vst3"，并具有以下文件夹结构：

文件夹说明
MyPlugin.vst3/Contents/Resources/文件夹，包含该插件用到的所有附加资源文件
MyPlugin.vst3/Contents/Resources/moduleinfo.json插件的模块信息
MyPlugin.vst3/Contents/i386-linux文件夹，包含插件二进制文件（用于内核架构 i386 的 32 位共享库 .so）
MyPlugin.vst3/Contents/x86_64-linux文件夹，包含插件二进制文件（用于内核架构 x86_64 的 64 位共享库 .so）
MyPlugin.vst3/Contents/XXX-linux其中 XXX 为架构名称，依据命令行 "uname -m"（机器硬件）的输出再加上 "-linux" 构成，例如： • armv3l-linux
• armv4b-linux
• armv4l-linux
• armv5tel-linux
• armv5tejl-linux
• armv6l-linux
• armv7l-linux
• armv8l-linux

ⓘ 注意
文件夹（包）与共享库（.so）文件必须同名！

合并包

注意，所有包都可以合并为一个，从而得到一个跨平台的包/文件夹。

例如：

./MyPlugin.vst3
    ├── Contents
    │   ├── Resources
    │   │   ├── Documentation
    │   │   │   ├── Manual.pdf
    │   │   │   └── WhatsNew.pdf
    │   │   ├── Help
    │   │   │   └── helpdoc.xml

    │   │   │   ├── 84E8DE5F92554F5396FAE4133C935A18_snapshot.png
    │   │   │   └── 84E8DE5F92554F5396FAE4133C935A18_snapshot_2.0x.png
    │   │   ├── VST XMLs
    │   │   │   └── AGain
    │   │   │       └── 84E8DE5F92554F5396FAE4133C935A18
    │   │   │           ├── Generic 8 Cells.xml
    │   │   │           └── WK-Audio ID 8 Cells.xml
    │   │   ├── moduleinfo.json
    │   │   └── MyPlugin.srf
    │   │
    │   ├── armv7l-linux
    │   │   └── MyPlugin.so
    │   │
    │   ├── i686-linux
    │   │   └── MyPlugin.so
    │   │
    │   ├── i386-linux
    │   │   └── MyPlugin.so
    │   │
    │   ├── x86_64-linux
    │   │   └── MyPlugin.so
    │   │
    │   ├── MacOS
    │   │   └── MyPlugin
    │   │
    │   ├── x86_64-win
    │   │   └── MyPlugin.vst3
    │   │
    │   ├── arm64ec-win
    │   │   └── MyPlugin.vst3
    │   │
    │   ├── Info.plist  (macOS Only)
    │   └── PkgInfo     (macOS Only)
    │
    ├── desktop.ini    (Windows only)
    └── Plugin.ico     (Windows only)
