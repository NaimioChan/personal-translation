版本 3.6.6（2016/06/17）

  • 接口变更：

    • 新增 Steinberg:: IPlugViewContentScaleSupport：插件视图内容缩放支持。

  • 新增标志位/枚举：

    • 新增 RestartFlags：kRoutingInfoChanged，通知宿主路由信息（IComponent）已变更。

  • 示例：

    • 新增 VST 3 插件 示例：
      • 新增 VST 3 插件 Program Change，展示如何管理自己的程序列表。
    • 移除 Visual Projects 8 和 9 版本。

  • 插件包装层：

    • VST 3 - Audio Unit 包装层：
      • 更新到最新的 Audio Core 更新。
    • VST 3 - VST 2.x 包装层：
      • 添加对版本的支持（VST 3 -> VST 2）。

  • 辅助类：

    • 添加对旁通（含延迟补偿）的支持（vstbypassprocessor.h）。
    • 添加事件/参数迭代器的辅助工具（vstaudioprocessoralgo.h）。
    • 添加 SpeakerArr 的辅助函数：
      • Speaker getSpeaker (const SpeakerArrangement& arr, int32 index)。
      • bool isSubsetOf (const SpeakerArrangement& arrSubSet, const SpeakerArrangement& arr)。

  • VSTGUI 4.3

    • 更新到 VSTGUI 4.3.1（也可在此获取：http://sourceforge.net/projects/vstgui/files/vstgui/VSTGUI%204.3/)）。
    • VSTGUI 仓库已迁移到 github：https://github.com/steinbergmedia/vstgui。
    • 如果你想为 VSTGUI github 做贡献，请使用 github。

  • VST3PluginTestHost：

    • 修复对 SingleComponent 的支持

  • 新的开发者论坛：

    • 我们终于有了自己的 VST 论坛，请访问 https://sdk.steinberg.net 并将其作为新的交流平台，VST 邮件列表将保留为归档邮件列表。
