以 zip 文件下载完整的 VST 3 包

下载完整的 VST SDK 包，其中包含构建 VST 3 插件或宿主所需的全部内容，并包含用于实时测试你的 VST 3 插件的 VST 3 插件测试宿主，可执行自动化测试（参见 什么是 VST SDK？）：

https://www.steinberg.net/vst3sdk（zip 文件的直接链接，约 100 MB）

从 GitHub 克隆 VST 3 仓库

从 GitHub 克隆 VST SDK 仓库，以便轻松集成到你的工作区：

https://github.com/steinbergmedia/vst3sdk

在线文档

浏览 VST SDK 的在线文档，其中包括 API 参考和示例代码：

https://steinbergmedia.github.io/vst3_doc

浏览 VST 门户，查看完整文档和教程：

https://steinbergmedia.github.io/vst3_dev_portal/pages/index.html

VST 3 论坛

访问 Steinberg 的 VST 开发者论坛，可以获取开发帮助、提交缺陷报告、请求新功能，并与其他 VST 3 开发者交流：

https://sdk.steinberg.net

VSTGUI

下载 VST SDK 时，会包含 VSTGUI 的最后一个官方发布版本，但你也可以从 github 获取它（发布分支和开发分支）：

https://github.com/steinbergmedia/vstgui
