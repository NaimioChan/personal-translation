[3.6.0] 预设元信息

引言

流的元属性：Vst:: IStreamAttributes。

  • [host imp]
  • [扩展 IBStream]
  • [发布于：3.6.0]
  • [optional]

用于从流中访问预设元信息的接口，例如在 setState 中使用，以便告知插件当前发生预设加载的上下文（工程上下文或预设加载（参见 StateType）），或用于获取所加载预设的完整文件路径（如果可用）。

示例

#include "pluginterfaces/base/ustring.h"
#include "pluginterfaces/vst/vstpresetkeys.h"
// ...
 
tresult PLUGIN_API MyPluginProcessor::setState (IBStream* state)
{
    if (auto stream = Steinberg::U::cast<IStreamAttributes> (state))
    {
        IAttributeList* list = stream->getAttributes ();
        if (list)
        {
            // 获取此状态的当前类型（project/Default..）
            String128 string;
            if (list->getString (PresetAttributes::kStateType, string, 128 * sizeof (TChar)) == kResultTrue)
            {
                UString128 tmp (string);
                char ascii[128];
                tmp.toAscii (ascii, 128);
                if (!strncmp (ascii, StateType::kProject, strlen (StateType::kProject)))
                {
                    // 我们处于工程加载上下文中……
                }
            }
 
            // 获取此状态的完整文件路径
            TChar fullPath[1024];
            if (list->getString (PresetAttributes::kFilePathStringType, fullPath, 1024 * sizeof (TChar)) == kResultTrue)
            {
                // 这里我们拿到了完整路径……
            }
        }
    }
    //...在这里读取状态.....
    return kResultTrue;
}
