版本 3.7.2（2021/03/30）

版本 3.7.2（2021/03/30）

  • VSTGUI 4.10

    • 最低要求 C++14。
    • VSTGUI 现在需要显式初始化和终止。参见 VSTGUI::init()。
    • UIDescription 文件现在以 JSON 格式写入，旧的 XML 格式已弃用。
    • 现在可以有条件地把 XML 解析器和 expat 库从构建中移除（将 VSTGUI_ENABLE_XML_PARSER 设为 0）。

  • 许可证已更新到 2.1 版！请阅读新的许可协议 /pages/VST+3+Licensing/Index.md）。（如果你已签署 2.0 版的许可协议，则无需再次签署）。

  • 新增标志位/枚举：

    • 新增预定义 3D 扬声器布局：
      • k220（L R C Ls Rs Lc Rc Cs Sl Sr Tc Tfl Tfc Tfr Trl Trc Trr Tsl Tsr Bfl Bfc Bfr）。
    • 部分布局已重命名：
      • 已将「7.1 Music (Dolby)」重命名为「7.1」。
      • 已将「7.0 Music (Dolby)」重命名为「7.0」。
      • 已将「7.1 Cine (SDDS)」重命名为「7.1 SDDS」。
      • 已将「7.0 Cine (SDDS)」重命名为「7.0 SDDS」。

  • CMake：

    • 代码风格已更改。
    • 每个库通过 target_compile_features 定义各自的 C++ 版本最低要求（pluginterfaces 为 11）。
    • 新增标志：SMTG_CXX_STANDARD，用于覆盖默认使用的 C++ 版本（11）。
    • 新增标志：SMTG_CUSTOM_BINARY_LOCATION：自定义二进制文件的输出位置。
    • 新增标志：SMTG_CXX_STANDARD：插件使用的 C++ 标准版本：14、17、20。
    • 新增标志：SMTG_ENABLE_ADDRESS_SANITIZER：启用 AddressSanitizer。
    • 添加对 C11 原子头文件的检查。
    • 添加启用 Sanitizer 的支持。
    • 新增文件 SMTG_SetDebugExecutable.cmake：可预先配置要运行的调试可执行文件。
    • 修复 Windows 上 SMTG_FindJack.cmake 中的 LOCAL_JACK_LIB。
    • 修复 Windows 上插件链接到公共位置的问题。
    • 修复：validator 单元测试失败时，插件资源/快照未被复制。

  • 插件包装层：

    • AAX 包装层
      • 修复 macOS 上 AAX 的符号导出。
    • AUv2 包装层：
      • 修复使用 Xcode 12 时的 AUv2。

  • 示例：

    • 新增 VST 3 宿主示例：
      • VST 3 Inspector 应用：展示如何使用 VSTGUI 解析可用的 VST 3 插件工厂的示例。
    • validator、audiohost、editorhost、Inspector 应用的最低要求为 C++14。

  • 辅助类：

    • 新的文件处理模块初始化：public.sdk\source\main\moduleinit.cpp、public.sdk\source\main\moduleinit.h。
    • #include 而不是 #include 。
    • 修复 HostAttributeList::getString 中不正确的字符串拷贝回归。
    • 修复部分校验测试：SliceProcessingTest、ValidStateTransitionTest。
    • 修复 module_linux.cpp 在 C++20 模式下的构建。

  • VST3PluginTestHost v3.1.0 版本：

    • 为已实例化的插件新增右键菜单项「Export Presets Parameters as XML」，可自动加载 VST 3 预设并将其导出为 XML 文件。

  • VST 3 Project Generator v2021.03 版本：

    • 该项目现已在 https://github.com/steinbergmedia/vst3projectgenerator 上开源。
    • macOS 的通用二进制（Intel/M1）。
    • 在 macOS 上添加另一个用于查找 cmake 的默认位置。
    • 使用 cmake 进行 bundle ID 设置。
    • 确保键盘焦点导航正确。
