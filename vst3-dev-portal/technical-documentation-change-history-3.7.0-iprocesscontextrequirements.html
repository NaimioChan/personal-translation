[3.7.0] 处理上下文需求

本页内容：

  • 引言

引言

用于组件的扩展 Vst:: IAudioProcessor 接口：Vst:: IProcessContextRequirements。

  • [plug imp]
  • [扩展 Vst:: IAudioProcessor]
  • [released: 3.7.0]
  • [mandatory]

要获取准确的进程上下文信息（Vst::ProcessContext），现在需要实现此接口，并返回你的音频效果器所需的标志位掩码。如果不实现此接口，你在 process 函数中可能完全得不到任何信息。

宿主在 initialize 与 setActive 之间询问一次此信息。之后不能再更改。

这使宿主在知道哪些插件需要哪些信息时，能够更好地优化音频处理图。

⚠️ 警告
使用更早 SDK 版本（< 3.7）构建的插件仍然会获得旧的信息，但这些信息可能不如使用此接口时准确。
