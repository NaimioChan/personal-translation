引言

把 VST 3 插件包装为 Audio Unit v2 插件的辅助类。

VST SDK 包含一个 AudioUnit 包装层，可把 VST 3 音频处理器和编辑控制器封装为 AudioUnit 效果器或乐器。

该包装层是一个小型动态库，用于加载 VST 3 插件。由于 AudioUnit 把重要信息存放在资源分支中，必须为每个 VST 3 插件分别编译此库。

它是如何工作的？

  • 你首先需要构建 SDK（参见此处），然后应得到 xcode 项目。
  • 你可能需要从 Apple 下载 CoreAudio SDK，并在用它构建 SDK 时把 cmake 指向它（参见此处）。
  • 复制 again AU 包装层示例项目目录（public.sdk/source/vst/auwrapper/again/）
  • 按需重命名该副本
  • 编辑项目的目标设置并更改
    • 产品名称
    • 库搜索路径，使其指向 libauwrapper.a 所在的目录
    • 架构设置，使其只包含 VST 3 插件支持的架构
  • 在项目中搜索 AUWRAPPER_CHANGE，并按需更改设置，尤其是在：
    • 编辑 audiounitconfig.h，参见其中的注释
    • 编辑 Info.plist，参见其中的注释
  • 编辑 "Make Links Script"，以便更轻松地调试/开发
  • 构建你的项目
  • 完成 ... 就这些！

对于发布版本，你必须把你的 VST 3 插件的副本或别名放到 bundle 内名为 "plugin.vst3" 的资源文件夹中。
