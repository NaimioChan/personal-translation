引言

将你的 VST 3 插件做成 iOS InterApp-Audio 应用。

VST SDK 提供了一种简便方式，可以把你的 VST 3 插件做成 iOS 应用间音频应用。

SDK 附带一个 iOS VST 3 宿主应用程序，它既可以独立运行，也可以作为应用间音频从属端运行。如果你的插件不使用任何特定的 Windows 或 macOS X API，让插件在 iOS 上运行应该相当容易。

如果你使用 VSTGUI4 并以 VST3Editor 类作为 UI，主要只需为不同设备尺寸创建新的 UI 描述。

它是如何工作的？

创建并设置 Xcode 项目

  • 在 Xcode 中创建一个新的 iOS 应用程序。使用 "Empty Application" 模板。
  • 使用 "C++11" 作为 "C++ Language Dialect"。
  • 激活 "Objective-C Automatic Reference Counting"。
  • 根据你在 Apple 注册的 AppID 更改 Bundle Identifier（参见 Apple 文档）。
  • 为项目激活 "Inter-App Audio" 能力。
  • 为项目激活 "Background Modes" 能力，并勾选 "Audio and Airplay" 模式。
  • 更改 "Header Search Path" 配置，添加指向 VST SDK 根目录的路径。

把音频组件描述添加到 Info.plist

  • 添加一个名为 "AudioComponents" 的新数组。
  • 向该数组添加一个新字典。
  • 向字典添加以下键：manufacturer、name、type、subtype、version。
  • 设置这些键的值：
  • manufacturer 的值必须是在 Apple 注册的那个（即用于 AudioUnits 的那个）。
  • type 的值必须是 'aurx'（Effect）、'aurm'（带 MIDI 的 Effect）、'aurg'（Generator）或 'auri'（Instrument）。
  • version 的值必须为 1。

向项目添加文件

  • 你的 VST 3 插件项目中的所有源码
  • public.sdk/source/vst/interappaudio 中的所有文件
  • public.sdk/source/vst/hosting 中的所有文件
  • base/source/ 中的所有文件（如果之前尚未完成）
  • public.sdk/source/vst/auwrapper/NSDataIBStream.mm（如果之前尚未完成）

如果使用 VSTGUI

  • 添加 vstgui_ios.mm
  • 添加 vstgui_uidescription_ios.mm

代码更改

创建项目时，Xcode 为你创建了一些文件，其中之一是 App Delegate。你需要把基类从 NSResponder<UIApplicationDelegate> 改为 VSTInterAppAudioAppDelegateBase（需要导入其头文件，位置在这里：
public.sdk/source/vst/interappaudio/VSTInterAppAudioAppDelegateBase.h)），然后从中移除所有方法。如果你想为应用添加一些自定义行为，应在 App Delegate 类的实现中进行。例如，如果你只想允许横屏模式，就必须添加以下方法：

//-----------------------------------------------------------------
- (NSUInteger)application:(UIApplication *)application supportedInterfaceOrientationsForWindow:(UIWindow *)window
{
    return UIInterfaceOrientationMaskLandscapeLeft|UIInterfaceOrientationMaskLandscapeRight;
}

如果你重写了由 VSTInterAppAudioAppDelegateBase 实现的某个方法，请务必调用父类方法（头文件中显示了哪些方法已实现）。

UI 处理

在 iOS 上运行时创建不同的 UI

要为 iOS 创建不同的视图，可以检查宿主上下文中是否有 IInterAppAudioWrapper 接口：

//-----------------------------------------------------------------
IPlugView* PLUGIN_API MyEditController::createView (FIDString _name)
{
    ConstString name (_name);
    if (name == ViewType::kEditor)
    {
        if (auto interAudioApp = Steinberg::U::cast<IInterAppAudioHost> (getHostContext ()))
        {
            // 创建并返回 iOS 的视图
        }
        else
        {
            // 创建并返回 Windows/macOSX 的视图
        }
    }
    return 0;
}

使用 VSTGUI

VSTGUI 4.3 或更高版本包含对 iOS 的支持。你可以像在 Windows 或 macOS X 上那样使用它。关于一些限制，请参见 VSTGUI 文档。

使用原生 UIView

如果你想创建一个原生 UIView 作为插件编辑器，就必须创建自己的 IPlugView 派生类，并在 IPlugView::attached 方法中挂接该 UIView。示例见 "public.sdk/samples/vst/adelay/interappaudio/iosEditor.mm"

宿主 UI 集成

在 "public.sdk/samples/vst/InterAppAudio" 中的示例项目使用自定义方案来显示用于控制宿主程序并切换到宿主程序的 UI。如果你想以这种方式添加，可以把它作为示例。你也可以使用 Apple 为其应用间音频示例源码提供的 UI。

但你也可以把宿主 UI 集成实现到自己的插件视图中。你的编辑控制器会通过其 initialize 方法获得指向 IInterAppAudioHost 的接口，你可以用它获取宿主图标、发送命令或切换到宿主。如果你使用这种方法显示宿主控制项，应在编辑控制器中实现 IInterAppAudioConnectionNotification 接口，以便根据连接状态有条件地显示或隐藏这些控制项。
