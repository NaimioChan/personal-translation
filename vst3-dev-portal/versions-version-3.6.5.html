版本 3.6.5（2015/08/28）

  • 接口变更：

    • 新增 Vst::ChannelContext::IInfoListener 接口：告知插件其所在的通道（名称、颜色……）。
    • 新增 Vst::IPrefetchableSupport 接口：允许插件通知宿主它不支持 prefetch/ASIO Guard（可以是动态的）。
    • 新增 Vst::IUnitHandler2 接口：允许插件通知宿主由 IUnitInfo::getUnitByBus 定义的单位-总线分配已变更。
    • 新增 Vst::IAutomationState 接口：告知插件其当前的自动化状态。
    • 使用 "#pragma once" 代替 "#ifndef"。

  • 示例：

    • 新增 VST 3 插件 示例：
      • 新增 VST 3 插件 ChannelContext，展示 Vst::ChannelContext::IInfoListener 接口的工作方式。
      • 新增 VST 3 插件 PrefetchableSupport，展示 Vst::IPrefetchableSupport 接口的工作方式。
    • 「VST 3 Host Checker」插件已更新，加入新的检查。

  • 插件包装层：

    • VST 3 - Audio Unit 包装层：
      • 支持 MIDI 输出。
      • 修复与 macOS X 10.10 命名空间冲突导致的崩溃。
      • 在 AUWrapper::restoreState 中添加 PresetAttributes::StateType 支持。

  • 新增标志位/枚举：

    • 新增预定义 3D 扬声器布局：k91Atmos。

  • VST3PluginTestHost：

    • 添加一些新的单元测试：FX 插件（不是乐器）必须支持旁通参数！
