VST 3.0.0 中插件支持/实现的接口列表

Vst:: IComponent

组件的基接口。

  • [plug imp]
  • [released: 3.0.0]
  • [mandatory]

这是 VST 组件的基本接口，必须始终支持。它包含任何类型处理类的公共部分。特定于媒体类型的部分在单独的接口中定义。实现组件必须同时提供特定接口和 Vst:: IComponent。

另请参见 Steinberg:: IPluginBase。

Vst:: IAudioProcessor

音频处理接口。

  • [plug imp]
  • [extends Vst:: IComponent]
  • [released: 3.0.0]
  • [mandatory]

音频处理插件必须始终支持此接口。

Vst:: IEditController

编辑控制器组件接口。

  • [plug imp]
  • [released: 3.0.0]
  • [mandatory]

效果器或乐器的控制器部分，带有参数处理（导出、定义、转换……）。

另请参见 Vst:: IComponent::getControllerClassId、Vst:: IMidiMapping。

Vst:: IConnectionPoint

把一个组件与另一个组件连接起来。

  • [plug imp]
  • [host imp]
  • [released: 3.0.0]
  • [mandatory]

此接口用于分离组件之间的通信。注意，有些宿主会在组件之间放置代理对象，使它们不直接相连。

另请参见 组件之间的通信。

Vst:: IUnitInfo

用于描述插件结构的编辑控制器扩展。

  • [plug imp]
  • [extends Vst:: IEditController]
  • [released: 3.0.0]
  • [optional]

Vst:: IUnitInfo 描述插件的内部结构。

  • 根单位就是组件本身，因此 getUnitCount 至少必须返回 1。
  • 根单位的 id 必须为 0（kRootUnitId）。
  • 每个单位可以引用一个程序列表——此引用不得改变。
  • 每个使用程序列表的单位引用该列表中的一个程序。

另请参见 VST 3 单位、Vst:: IUnitHandler。

Vst:: IProgramListData

用于访问程序列表数据的组件扩展。

  • [plug imp]
  • [extends Vst:: IComponent]
  • [released: 3.0.0]
  • [optional]

组件可以通过此接口和/或单位预设数据（Vst:: IUnitData）支持程序列表数据。

另请参见 Vst:: IUnitData、复杂插件结构 / 多音色乐器。

Vst:: IUnitData

用于访问单位数据的组件扩展。

  • [plug imp]
  • [extends Vst:: IComponent]
  • [released: 3.0.0]
  • [optional]

组件可以通过此接口或程序列表数据（Vst:: IProgramListData）支持单位预设数据。

另请参见 预设 & 程序列表。

Steinberg:: IPlugView

视图的插件定义。

  • [plug imp]
  • [released: 3.0.0]

视图的大小

创建 IPlugView 之后，插件必须确保在宿主请求时返回正确的大小（IPlugView::getSize ()）。

通常，插件视图的大小是固定的。但宿主和插件都可以使视图被调整大小：

  • 宿主：如果 IPlugView::canResize () 返回 kResultTrue，宿主会设置窗口以便用户调整其大小。在用户调整窗口大小期间，会调用 IPlugView::checkSizeConstraint ()，允许插件把大小改为有效的受支持矩形尺寸；如果 IPlugView::canResize () 返回 kResultTrue，它应始终返回 kResultTrue。宿主随后把窗口调整为此矩形，并且必须调用 IPlugView::onSize ()。

  • 插件：插件可以调用 IPlugFrame::resizeView () 并使宿主调整窗口大小。之后，在同一调用栈中，如果需要调整大小（大小已改变），宿主必须调用 IPlugView::onSize ()。

ⓘ 注意
注意，如果宿主在调用 IPlugView::onSize () 之前（如需）调用了 IPlugView::getSize ()，得到的是旧大小，而不是当前大小！

以下是调用序列：

  • 插件->宿主：IPlugFrame::resizeView (newSize)
  • 宿主->插件（可选）：IPlugView::getSize () 返回 currentSize（不是 newSize！）
  • 宿主->插件：如果 newSize 与当前大小不同：IPlugView::onSize (newSize)
  • 宿主->插件（可选）：IPlugView::getSize () 返回 newSize

ⓘ 注意
请仅在调用 Steinberg:: IPlugView::onSize() 时才调整视图的平台表示大小。

键盘处理

插件视图从宿主接收键盘事件。视图实现不得通过平台回调的方式处理键盘事件，而应让宿主把它们传给视图。宿主在调用 Steinberg:: IPlugView::onKeyDown 时依赖正确的返回值，否则插件视图可能导致宿主的按键命令处理出现故障。

另请参见 Steinberg:: IPlugFrame、平台 UI 类型。
