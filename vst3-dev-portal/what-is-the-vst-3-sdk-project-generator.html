引言

这个开源应用（Win/macOS）让你只需在 GUI 中输入一些参数，就能轻松生成新的 VST 3 插件工程。

请查看 SDK 的 "VST3_Project_Generator" 文件夹！

源代码可在 GitHub - steinbergmedia/vst3projectgenerator: VST 3 Project Generator 获取。

启动 VST 3 项目生成器应用程序

首次启动该应用程序时，会要求你定义 2 个文件夹，分别存放 VST SDK 和 CMake 工具。之后仍可在 Preferences 选项卡中更改这些文件夹，参见设置首选项。

Visit us 菜单包含一些有用链接。

定位 CMake

如果你已下载 CMake 工具，只需告诉 Project Generator 它所在的位置：点击 Locate CMake，并用文件选择器选择 cmake.exe 文件：

如果你之前没有安装 CMake 工具，可以下载它：点击 Download CMake，浏览器会打开 CMake 的专用网页，查看 Download 部分并安装 CMake。

定位 VST SDK

如果你已下载 VST SDK，只需告诉 Project Generator 它所在的位置：点击 Locate VST SDK，并用文件夹选择器选择 VST3_SDK 文件夹：

如果你之前没有安装 VST SDK，可以下载它：点击 Download VST SDK，会出现一个对话框：

下载 VST SDK 有 2 种方式：

  • Commercial：点击后会跳转到可下载的最新 SDK 版本，其中包含所有工具（参见什么是 VST SDK？）；使用此版本的 SDK，你可以创建并商业化你的插件（参见VST 3 有哪些许可选项？）。
  • Open Source：点击后会跳转到 Steinberg 的 Github，你可以在那里克隆 VST SDK；此版本不包含所有可用工具（参见VST 3 有哪些许可选项？）。

已成功定位 VST SDK 和 cmake

一旦找到所需的 2 个位置，应用程序的用户界面应如下所示：

下次启动 Project Generator 应用程序时，将不再要求你重新定位它们！

设置首选项

在创建任何插件项目之前，你必须定义一些全局首选项，这些首选项会在关闭应用程序时自动保存。在 Windows 上，这些首选项保存在注册表项中：Computer\HKEY_CURRENT_USER\Software\com.steinberg.vst3sdk.projectgenerator。

公司信息

此小节中的信息将用于生成与你将要生成的所有插件相关联的工厂信息。加载你插件的宿主程序会读取这些信息，宿主可能会将其显示给用户。

  • Vendor：这是你的公司名称：例如 "Steinberg Media Technologies GmbH"
  • E-Mail：你的电子邮件，宿主可用它把用户引导到你的支持渠道，例如："mailto:support@steinberg.net"
  • URL：你公司的网址：例如 "https://www.steinberg.net"
  • C++ Namespace：可让你预定义一个命名空间，用于包裹你的插件源代码：例如 "MyWantedNamespace"：
//...
namespace MyWantedNamespace {

//-----------------------------------------------------------------------
MyPluginController::MyPluginController ()
{
//...
}
} // 命名空间结束
//...
namespace MyWantedNamespace {

路径首选项

如前文「路径首选项」小节所述，你可以更改多个位置：

  • VST SDK Path：当前使用的、你之前已下载的 VST SDK。
  • CMake Executable Path：当前使用的 CMake 工具

设置并创建插件项目

在此选项卡中，你为新插件的创建定义一些信息：

  • Name：插件在宿主中显示的名称：例如 "AGain"
  • Type：指定插件的主要 VST 3 子类别（PlugType）：
    • Audio Effect：（kFx）一个简单的立体声→立体声音频效果器
    • Instrument：（kInstrument）一个简单的乐器，含 1 个事件输入和 1 个立体声音频输出
  • Use VSTGUI：如果想把 VSTGUI 用作 UI 框架，请勾选此项
  • macOS Deployment Target：在此输入所针对的最低 macOS 版本
  • C++ Class Name：指定插件类的基础名称：例如 "AGain"
class AGainProcessor : public AudioEffect
{
    //...
};

class AGainController : public EditControllerEx1
{
    //...
};
  • Bundle ID：这是所需的 ID，例如 macOS 的 Info.plist 就需要它：例如 "com.steinberg.again"
  • Filename Prefix：（可选）将作为文件前缀添加到所创建的文件：例如 "AGain" => AGainProcessor.cpp / AGainController.h / ...
  • Output Directory：在此定义项目将创建在哪个文件夹中
  • CMake Generator：CMake 工具需要定义一个生成器，以便为特定构建系统创建配置文件：生成器有 2 种：命令行和 IDE。按需选择，例如：
    • 在 Windows 上：Visual Studio 18 2026
    • 在 macOS 上：Xcode
  • CMake Platform：你可以在此定义应使用哪个目标平台，即 x64 或 ARM64EC（在 Windows 上）

所有信息设置完毕后，你可以点击 Create，此时会生成一个脚本，随后使用 CMake 并打开所选的 IDE。底部区域会显示脚本输出，你可以使用专用按钮将其复制：Copy Script Output To Clipboard。
