版本 3.6.11（2018/10/22）

  • VSTGUI 4.7：

    • 更新到 VSTGUI 4.7。
    • Linux 支持从 GTK++ 迁移到 XCB。
    • 重新设计拖放。
    • Windows 上现在支持带位图的拖拽。
    • 针对 Windows 7 的独立库支持。
    • 新增 ImageStitcher 工具。
    • 移除了 GDI+ 绘制后端，由 Direct2D 后端替代。

  • VST 3 bundle 的新图标：VST_Logo_Steinberg.ico 和 VST_Logo_Steinberg.icns（位于 VST_SDK/VST3_SDK/doc/artwork 文件夹）。

  • 接口变更：

    • VST 2 接口不再可用！
    • 新增 Vst:: INoteExpressionPhysicalUIMapping（插件）：允许宿主获取插件所支持音符表达式对应的首选物理映射。

  • CMake：

    • 进一步改进用户项目

  • 插件包装层：

    • AAX 包装层（VST 3 - AAX 包装层）：
      • 修复 UI 调整大小的问题。
      • 修复默认块大小的问题。
    • VST 2 包装层：
      • 修复乐器未被显示为乐器的问题。

  • 辅助类：

    • 将 parameter 类的一些函数设为虚函数（set/getUnitID、getInfo、set/getPrecision）。
