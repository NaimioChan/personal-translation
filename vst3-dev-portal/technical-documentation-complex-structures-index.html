如何处理复杂的插件结构与多音色。

问题

简单的 VST 效果器插件通常不会给宿主带来太多麻烦。它只有一个音频输入和输出总线，以及一组用于控制其声音某些方面的已定义参数。但 VST 插件可以比这复杂得多。当插件实现多音色乐器时，宿主在该插件与其 GUI 的集成方面会面临一系列问题。举几个例子：

  • 插件可以定义多个事件输入和多个音频输出。当归音符事件传输给插件时，宿主如何知道声音会从哪个输出出现？

    • 宿主可能对此感兴趣，以便把 MIDI 轨道链接到相应的音频通道。

  • 插件可以定义一个程序列表，用户可以从插件 GUI 中加载。在多音色乐器中，一个程序只影响插件的某一部分（我们把这部分称为「单位」）。宿主如何了解这些部分以及可加载的插件定义程序？

    • 宿主可能对此感兴趣，以便在其自己的 GUI 中为此功能提供快捷方式。

由于 VST 插件不像硬件 MIDI 乐器那样只是一个黑盒，复杂的插件应帮助其宿主提供比硬件乐器更便利的 GUI 集成。VST 3 使用单位的概念来描述插件的内部结构（见 VST 3 单位），多音色乐器应当支持相应的接口。但 VST 3 中首选的解决方案是通过「简单模式」降低这种复杂性。

简单模式

「VST 3 简单模式」有着（自私的）背景，即支持 Cubase 所谓的「简单乐器轨道」。这些轨道把 MIDI 轨道和 VST 音频通道组合在一起（无需再做任何其他指定，例如选择 MIDI 输出端口或 MIDI 通道）。该模式被定义为「只有一个输入、只有一个输出」。在「简单模式」中，只使用 MIDI 通道 0。因此，乐器必须是单音色的。

现在宿主将使用插件的多个实例，而不是以包含多个同类内部区段的方式使用同一个实例。VST-MA 组件模型支持在插件的多个实例之间共享资源，因为通常每个插件实例都使用同一个模块实例（dll/bundle）。

不过，插件可以选择用同一份实现同时支持简单模式和高级模式。宿主通过检查处理器的类标志（Steinberg::PClassInfo2::classFlags）中是否包含 Vst::kSimpleModeSupported 标志来测试其支持「简单模式」的一般能力。如果插件要用于乐器轨道（或宿主认为它更合适时），会调用 Vst:: IComponent::setIoMode 方法来配置插件（必须在任何其他调用之前！）。单音色插件也应设置该标志，并且无需考虑 setIoMode 调用。

多音色程序列表

对于多音色乐器插件，预设处理可能复杂得多。在这种情况下：

  • 插件可以定义任意数量的程序列表。

  • 每个单位可以引用一个程序列表（此引用不得更改）。

  • 每个使用程序列表的单位引用一个列表项。

  • 对于每个引用程序列表的单位，必须导出一个程序选择参数（Vst:: ParameterInfo::kIsProgramChange）。

  • 插件可以提供用于选择程序的 GUI，但它必须同步相应的程序选择参数。

  • 宿主可能希望以显示简单插件预设的同样方式显示活动单位的程序列表（通常在窗口顶部或底部的单独控制区域中）。宿主必须能够为在插件 GUI 中获得焦点的单位显示正确的列表和正确的程序名称。

为使这一切正常工作，插件必须提供 Vst:: IUnitInfo 的有效实现，并且必须相应地操作回调接口 Vst:: IUnitHandler。

与简单情况类似，宿主可能希望保存和加载预设文件。插件的组件状态在这里并不有用。复杂插件的预设可以是：

  • 一个插件单位的状态

    • 为此，插件必须在其组件部分中实现 Vst:: IUnitData 接口。

  • 程序列表中某个项的内容

    • 为此，插件必须在其组件部分中实现 Vst:: IProgramListData 接口。

插件可以同时支持单位预设和程序列表预设。

另见 预设 & 程序列表、Vst:: IProgramListData、Vst:: IUnitData。

单位与轨道

一个单位可以与总线（或总线的通道）关联。特别是，一个单位可以具有到某个输入 MIDI 通道的固定且唯一的连接。对宿主来说，了解这种连接以及由此得知哪个单位可以关联到特定 MIDI 轨道可能很有用。多音色插件的 GUI 通常不会同时显示所有同类单位的设置。取而代之的是某种单位选择。其想法是能够把插件中的单位选择与宿主中的轨道选择同步起来（双向）。

当插件 GUI 按所述方式组织时，它应通过实现以下方法来支持所述行为

  • Vst:: IUnitInfo::getUnitByBus：找出轨道与单位的关系

  • Vst:: IUnitInfo::getSelectedUnit：让宿主知道应选择哪条轨道

  • Vst:: IUnitInfo::selectUnit：使插件选择其单位

并通过调用

  • Vst:: IUnitHandler::notifyUnitSelection：触发宿主同步其 GUI
