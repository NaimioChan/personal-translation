引言

SDK 提供了一个名为 VST3PluginTestHost 的测试应用程序，适用于 Apple macOS X（Apple Silicon/Intel x86_64）和 Microsoft Windows（x64 与 Arm64EC）。

该应用程序允许你加载插件、模拟某些输入（音频与事件），并像一个基于 ASIO 驱动的小型 VST 3 宿主程序那样工作。

该应用程序中包含一个测试模块，可用于按 VST 3 标准检查你的插件。

请查看 SDK 的 "bin" 文件夹！

如何使用？

命令行

你可以在命令行中带某些选项启动 VST3PluginTestHost：

  • 指定应用程序应扫描 VST 3 插件的文件夹：
    • --pluginfolder "要扫描插件的文件夹"
    • 例如：
      • VST3PluginTestHost.exe --pluginfolder "C:\Development\VST3"
  • 为第一个已加载的乐器把 MIDI 文件渲染成音频文件（samplerate 和 blocksize（音频块大小，以采样为单位）是可选项；若不提供，则使用 ASIO 的当前设置）：
    • --audioexport "MIDI 文件夹位置" "音频输出文件夹" [samplerate] [blocksize]
    • 例如：
      • VST3PluginTestHost.exe --audioexport "C:\Content\MIDI" "C:\Content\Audio Output"
      • VST3PluginTestHost.exe --audioexport "C:\Content\MIDI" "C:\Content\Audio Output" 48000 128

菜单说明

文件

  • File => Load Preset...：为第一个已加载的插件（第一个槽位）加载 VST 3 预设。
  • File => Save Preset...：为第一个已加载的插件保存 VST 3 预设。
  • File => Load MIDI File...：加载一个 MIDI 文件，可通过走带部分播放。所有已加载的插件都会收到 MIDI 事件。加载文件时也会发送 MIDI 程序变更消息。
  • File => Unload MIDI File：卸载当前加载的 MIDI 文件。
  • File => Export Audio...：允许你选择一个包含 MIDI 文件的文件夹，加载每个文件，并导出第一个已加载插件的音频渲染结果。
  • File => Export Audio for current loaded MIDI...：使用当前加载的 MIDI 文件导出第一个已加载插件的音频渲染结果。
  • File => Convert VST 3 Presets to VST 2 Presets：把 VST 3 预设转换为兼容的 VST 2 预设（fxp 或 fxb）。
  • File => Overwrite Plug-in Name in VST 3 Presets...：在一组 VST 3 预设中重命名插件名称。
  • File => Rescan blocklisted VST 3 Plug-in：强制重新扫描此前被列入黑名单的插件。

编辑

  • Edit => Key Commands...：打开 Key Commands 窗口。
  • Edit => Global Preferences...：打开 Global Preferences 窗口，你可以在其中更改 ASIO 驱动等设置。
  • Edit => Plug-In Preferences...：打开 Plug-In Preferences 窗口，你可以在其中配置输入/输出路由等。

视图

  • View => Open Plug-in Information Window：打开一个窗口，显示所有已注册的 VST 3 插件组件与控制器。
  • View => Open Plug-in Unit Tests Window：打开一个窗口，可在其中对插件运行一系列单元测试。
  • View => Open Preset Editor：打开 VST 3 预设编辑器，可用于查看、检查并修改预设，包括添加 Instrument、Style 或 Character 等元数据属性。

VST Player 窗口

音频输入

在本节中，你可以为 Main Input Audio Bus 和 Aux Input Audio Bus（侧链：如果可用）选择插件的音频源，可选范围如下：

  • 正弦波
  • 噪声
  • 静音
  • ASIO 输入（第一立体声）
  • 音频文件（此时使用浏览器（... 按钮）选择文件（wave、aiff））

Volume 滑块可控制源的音量电平。

事件输入

本节模拟发送给插件的音符事件。

  • 可以定义一个模式，并用随机化、半音阶或手动事件初始化。（对于 Chromatic，在模式中选择起始音符，并在弹出菜单中选择 Chromatic。）
  • Active 复选框：启用/禁用该模式的播放。
  • 你可以为该模式选择不同的循环步进（1、1/2、...1/32）
  • 如果你已加载 MIDI 文件，请选择 "No Pattern" 以播放该 MIDI 文件。

VST 机架

本节允许你以串联方式加载多个插件。每个插件将加载到一个槽位中。

  • 要加载插件（音频效果器或乐器），点击相应的弹出菜单并选择一个插件。
  • 要卸载插件，点击其槽位上的 X 按钮。

对于槽位中已加载的每个插件，你可以：

  • 使用 On 按钮启用/禁用插件。
  • 使用 Byp 按钮旁通/处理插件（如果该参数可用）。
  • 要启用/禁用侧链总线，请使用 Aux 按钮（仅当插件有输入侧链时可用）。
  • 使用 Edit 按钮打开其编辑器。第二个 Edit 按钮可用于打开第二个编辑器（有助于检查插件所用的 GUI 框架是否允许这样做！）。
  • 使用 Store 按钮保存预设。
  • 使用 Load 按钮加载预设。
  • 使用 Info 按钮打开该插件的信息页面（见下文）。

上下文菜单

在已打开的插件上点击右键会打开上下文菜单，可触发一些操作：

  • Switch to Generic Editor：打开通用编辑器，而不是插件提供的编辑器。
  • Export Presets Parameters as XML：自动加载该插件的所有可用 VST 3 预设，并为每个预设创建一个包含参数状态的可读 XML 文件。

走带

在本节中你可以：

  • 设置输出音频的增益
  • 在 Time 和 Bars 之间切换时间格式
  • 查看当前时间显示
  • 控制走带状态（Start/Stop/Rewind/Loop）
    • 点击 Play 开始播放 MIDI 文件/模式。
    • 点击 Stop 在当前播放位置暂停 MIDI 文件/模式。
    • 再次点击该按钮可将歌曲位置重置到开头。
    • 激活 Loop 以循环播放整个 MIDI 文件。
  • 将鼠标悬停在信息图标上，可查看当前加载的是哪个 MIDI 文件
  • 更改歌曲位置
    • 歌曲位置指示器显示走带光标的位置。在歌曲位置指示器上方，位置以数字显示。
    • 要移动走带光标，请把歌曲位置指示器拖到新位置。
  • 更改速度和拍号
    • 速度：
      • 将该参数设为 Track，以跟随 MIDI 文件的原始速度。通过 Adjust Tempo 参数，你可以相对于 MIDI 文件的原始速度缩放播放速度。
      • 将该参数设为 Fixed，以手动输入速度。
    • 拍号：
      • 决定拍号。你可以用拍的分数形式输入新的拍号。

VST 3 插件测试窗口

在此窗口中，你可以为特定插件选择特定的测试分支。你可以在测试树（左侧部分）中导航，然后点击 Run Selected 按钮，只处理选中的测试。

关于插件的实例化方式，有 2 种测试：

  • Global Instance：所有测试只实例化一个插件实例。
  • Local Instances：每个测试都会实例化一个新的插件实例。

目前我们定义了 2 组测试：

  • VST 3 一致性
  • 特殊功能

你可以使用 Run All 运行所有可用测试。也可以通过左侧视图中的复选框禁用某些测试。

错误报告将显示在 Errors view 中。在 Messages View 中会显示一些警告（或插件的一些限制）、测试结果和进度。

在此版本的 Plug-in Test Host 中，测试仅限 VST 3 的主要功能，未来版本将扩展测试覆盖范围。

预设编辑器

使用此编辑器，你可以加载并修改通过 VST 机架 的 Store 按钮创建的 VST 3 预设，并添加一些元属性。
