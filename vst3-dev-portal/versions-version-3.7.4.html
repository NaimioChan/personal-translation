版本 3.7.4（2021/12/14）

版本 3.7.4（2021/12/14）

  • 接口变更：

    • 在 Windows 上添加对 _M_ARM64EC 的支持。
    • 新增定义：SMTG_CPU_ARM_64EC、SMTG_CPP14 和 SMTG_CPP17。
    • Windows 上新增VST 3 插件位置（用户本地）：%LOCALAPPDATA%/Programs/Common/VST3/。
    • 在需要处使用 SMTG_CONSTEXPR。

  • VSTGUI 4.10.3

    • 各项修复。

  • 许可证已更新到 2.2.2 版！请阅读新的许可协议 VST 3 许可问题。（如果你已签署 2.0 版的许可协议，则无需再次签署）。

  • CMake：

    • 重构：当使用目标时，通过添加 target 前缀重命名函数/宏：即 smtg_run_vst_validator => smtg_target_run_vst_validator。
    • 破坏性变更：将 smtg_add_vst3_resource 改为 smtg_target_add_plugin_resources，允许在一次调用中添加多个资源。
    • 破坏性变更：将 smtg_add_vst3_snapshot 改为 smtg_target_add_plugin_snapshots，允许在一次调用中添加多个快照。
    • 在 Xcode12 时将 Mac 上的 Universal Binary 默认设为 ON。
    • 添加对 Windows 上新 VST 3 位置的支持：新选项 SMTG_PLUGIN_TARGET_USER_PROGRAM_FILES_COMMON。
    • 修复 XCode 的若干代码签名问题。

  • 插件包装层：

    • VST 2 包装层：
      • 修复在 _DeinitModule() 中对象终止时可能仍需销毁数据的问题。
    • Audio Unit：
      • 将 AU SDK 更新为外部版本（版本 1.1）。
      • 修复 AUWrapper 的离线渲染信息。

  • 示例：

    • 添加到 validator 自检。
    • 为 validator 添加新函数 addErrorWarningTextToOutput。

  • 辅助类：

    • 新文件 pluginterfaces/base/funknownimpl.h（需要 C++11）：提供用于操作 FUnknown 的类。
    • 为所有宿主辅助类添加单元测试。
    • 在插件工厂中展示 const_exp 示例（C++17）：public.sdk/source/main/pluginfactory_constexpr.h。
    • 为 mpeprocessor 类添加文档。

  • VST3PluginTestHost v3.2.20 版本：

    • 适配以扫描 Windows 上新的 VST 3 插件位置。
    • 这是最后一个支持 Windows 上 32 位插件的版本。下一次更新将只支持 64 位插件。

  • VST 3 Project Generator v2021.12 版本：

    • 在 Windows 上的项目生成器中添加平台架构设置（cmake）。
