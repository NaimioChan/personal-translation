引言

单位是插件中的一个逻辑分区。

例如，一个 EQ 段可以是一个单位。单位的用途是：

  • 揭示插件的内部逻辑结构
  • 通过把参数与单位关联来组织参数
  • 支持程序列表
  • 支持处理 复杂插件结构 / 多音色乐器
    • 多个程序列表（与单位关联）
    • 访问程序列表数据
    • 支持 MIDI 轨道与单位的关联
    • 支持插件 GUI 与宿主 GUI 的同步

单位详情

  • 插件可以定义任意数量和任意种类的单位。单位的语义并不重要。

  • 单位以层级方式组织。每个单位可以包含子单位。

  • 该层级的根单位始终存在（显式或隐式），其 ID 为「0」。不定义任何其他单位的插件就只由单位「0」组成。

  • 插件必须为其定义的每个其他单位分配唯一的 ID，并为其提供一个合适的名称以便在 GUI 中显示（Vst::UnitInfo）。

  • 每个单位都可以「包含」参数。插件的所有参数都由 Vst:: IEditController 管理和发布，但每个参数都可以与一个单位关联。（Vst:: ParameterInfo::unitId）。宿主可以把参数列表组织为树视图，以单位层级作为节点。

  • 每个单位都可以与一个程序列表关联。（见 复杂插件结构 / 多音色乐器）

  • 单位可以与特定的总线关联。可以有任意种类的组合，但 VST 3 接口只为特殊情形定义了查询。（见 单位与轨道）

与单位相关的大部分关注点都与 GUI 有关，因此访问接口 Vst:: IUnitInfo 需要作为编辑控制器的扩展来实现。

另见 Vst:: IUnitInfo、预设 & 程序列表。
