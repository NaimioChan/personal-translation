MIDI 2.0 逐音符控制器

MIDI 2.0 逐音符控制器与 VST 3 音符表达式 之间有许多细微差异。好在插件开发者无需为此做任何事。从 MIDI 2.0 到 VST 3 的转换是宿主的职责。

与 MIDI 1.0 相比，MIDI 2.0 提升了分辨率

与 MIDI 1.0 相比，MIDI 2.0 显著提高了许多重要值的分辨率，如力度、压力和控制器。尽管如此，VST 3 的分辨率仍优于 MIDI 2.0。支持 VST 3 的插件和宿主应利用这些能力，不应固守 0-127 的思维。
