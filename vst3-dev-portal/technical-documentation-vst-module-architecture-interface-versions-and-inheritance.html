接口版本与继承

相关页面：

  • VST 模块架构
  • 如何从接口派生类

与 C++ 类不同，VST-MA 接口不使用继承来表达对象的特化。通常所有接口都派生自 FUnknown。这是因为接口一旦发布就绝不能更改。VST 模块架构接口仅将继承用于版本管理！所有特化都会建模为独立的接口！

例如，这些 C++ 类：

class Shape
{
public:
    void setPosition (long x, long y);
protected:
    long x;
    long y;
};
class Rect : public Shape
{
public:
    void setDimension (long width, long height);
protected:
    long width;
    long height;
};

在 VST-MA 中表达时，要为每个继承层级定义一个接口：

class IShape : public FUnknown
{
public:
    virtual void setPosition (long x, long y) = 0;
};
class IRect : public FUnknown
{
public:
    virtual void setDimension (long width, long height) = 0;
};

在下一个程序版本中，Shape 类需要做如下修改：

class Shape
{
public:
    void setPosition (long x, long y);
    void setColor (Color color);
protected:
    long x;
    long y;
    Color color;
};

VST-MA 的表示方式现在通过添加一个继承自 IShape 的新接口来反映对 Shape 的修改，代码如下所示，而先前的接口定义保持不变：

class IShape2 : public IShape
{
public:
    virtual void setColor (Color color) = 0;
};
