引言

把 VST 3 插件包装为 Audio Unit v3 插件的辅助类。

VST SDK 包含一个辅助类，可把 VST 3 音频处理器和编辑控制器包装成 AU v3 插件。

当 VST 3 插件支持音符表达式时，被包装的 AudioUnit 确实支持 MPE。你需要实现 Vst:: INoteExpressionPhysicalUIMapping，把你的音符表达式映射到 MPE 定义的有限三种表达式。

它是如何工作的？

  • 结构：
    • App（容器应用，通过小型播放引擎初始化 AU）
    • Extension（由宿主加载的扩展，也会初始化 AU）
  • 如何配合示例代码使用 VST 3 → AU v3 包装层：
    • 确保已正确设置代码签名
    • 构建并运行目标
  • 如何配合你自己的 VST 插件使用 VST 3 → AU v3 包装层：
    • 复制 public.sdk/samples/vst 中的 again_auv3 或 note_expression_synth_auv3 文件夹，重命名它，并编辑 CMakelist.txt 以添加你的源文件、资源和修改后的目标名称等。
    • 打开 audiounitconfig.h 并更改此文件中的定义。
    • 同时按你的需求更改该文件夹中的其他文件。代码签名是必需的，但你可以使用仅开发者身份进行构建和测试。
    • 构建并运行目标
