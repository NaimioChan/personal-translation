要构建 VST 3 插件，你需要 VST 3 的源代码（接口定义）、一个 IDE/编译器、cmake 以及一个 VST 3 宿主程序。

获取源代码

从下载的 vstsdk.zip 文件

下载 VST SDK：参见 VST SDK 下载。

将 zip 文件解压到计算机上的开发文件夹中。

从 GitHub：

git clone --recursive https://github.com/steinbergmedia/vst3sdk.git

获取用于开发的 IDE

适用于 Windows

在 Windows 上，我们建议你使用 Visual Studio C++ 或 Visual Studio Code。你可以从这里免费获取 https://visualstudio.microsoft.com/free。

适用于 MacOS

在 MacOS 上，首选是 Xcode（可在此处获取 https://developer.apple.com/xcode/）。

适用于 Linux

为了成功构建 SDK，你需要基于 Ubuntu 的 Linux 发行版。其他发行版可能也可以工作，但未经过测试。

  1. 下载 Linux：http://www.ubuntu.com 或 https://www.linuxmint.com
  2. 可直接安装，也可在 Parallels 之类的虚拟机中安装。我们使用的是 Ubuntu 22.04 LTS，并在其上进行了测试。

软件包要求

构建 SDK 示例需要安装若干软件包：

必需：

sudo apt-get install cmake gcc "libstdc++6" libx11-xcb-dev libxcb-util-dev libxcb-cursor-dev libxcb-xkb-dev libxkbcommon-dev libxkbcommon-x11-dev libfontconfig1-dev libcairo2-dev libgtkmm-3.0-dev libsqlite3-dev libxcb-keysyms1-dev

ⓘ 注意
在 Raspbian/Debian 上，请将 "libxcb-util-dev" 替换为 "libxcb-util0-dev"

可选：

sudo apt-get install subversion git ninja-build

推荐的 IDE（可选）：QTCreator

sudo apt-get install qtcreator

ⓘ 注意
你也可以使用 VST3_SDK/tools 文件夹中包含的 bash 文件 "setup_linux_packages_for_vst3sdk.sh"！

ⓘ 注意\

  • 除了 gcc 编译器之外，较新版本的 clang 编译器也可以使用！
  • libgtkmm3 是 VSTGUI 和 editorhost 示例所必需的！
  • Jack Audio 是 audiohost 示例所必需的！

获取 cmake

为了控制编译过程并创建 IDE 工程，VST SDK 使用开源跨平台工具 cmake。

你可以在此下载 cmake：https://cmake.org/download/，或使用适用于你的操作系统（Linux）的包管理器。
