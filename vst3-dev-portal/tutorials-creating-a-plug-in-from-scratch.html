从零创建 cmake 插件工程

本页内容：

  • 目标
  • 构建 CMakeLists.txt
  • 使用 VSTGUI 添加插件 GUI 编辑器

目标

本教程提供了一份分步指南，说明如何从零开始构建 VST 3 插件的 CMakeLists.txt。它涵盖必要的步骤，例如定义插件版本号、添加 C++ 源文件、链接到 sdk 目标，以及设置平台相关的选项。

你也可以使用 VST 3 project generator，它会生成 CMakeLists.txt。

构建 CMakeLists.txt

新建一个目录，用你的新插件名命名它，例如 MyPlugin。然后在新目录中创建 CMakeLists.txt 文件，并用文本编辑器打开它。向其中添加以下行。

设置 cmake 要求的最低版本。在本例中 3.15.0 就足够了。

cmake_minimum_required(VERSION 3.15.0)

另见：https://cmake.org/cmake/help/latest/command/cmake_minimum_required.html

把工程命名为 MyPlugin，添加 VERSION 和一个可选的 DESCRIPTION。

project(MyPlugin
    VERSION 1.0.0
    DESCRIPTION "MyPlugin Effect"
)

另见：https://cmake.org/cmake/help/latest/command/project.html

把变量 vst3sdk_SOURCE_DIR 设为 VST SDK 所在的目录。该目录必须包含 SDK 根目录下的 CMakeLists.txt。把 SDK 添加为子目录，并紧接着调用 smtg_enable_vst3_sdk。

set(vst3sdk_SOURCE_DIR /path/to/vst3sdk)

add_subdirectory(${vst3sdk_SOURCE_DIR} ${PROJECT_BINARY_DIR}/vst3sdk)
smtg_enable_vst3_sdk()

使用 smtg_add_vst3plugin 函数添加插件库及其源文件。

smtg_add_vst3plugin(MyPlugin
    source/version.h
    source/myplugin_cids.h
    source/myplugin_processor.h
    source/myplugin_processor.cpp
    source/myplugin_controller.h
    source/myplugin_controller.cpp
    source/myplugin_entry.cpp
)

把 VST SDK 的 sdk 链接到插件库。

target_link_libraries(MyPlugin
    PRIVATE
        sdk
)

调用 smtg_target_configure_version_file 配置插件版本。它会生成一个临时的 projectversion.h 头文件，该文件会被自动包含到你的工程中。

smtg_target_configure_version_file(MyPlugin)

定义平台相关的设置。

对于 macOS，这包括

  • 把 BUNDLE_IDENTIFIER 设为 org.mycompany.myplugin，
  • 把 COMPANY_NAME 设为合适的 My Company，以及
  • 一个用于在调试时启动插件的可执行文件 .../VST3PluginTestHost.app

对于 Windows，则需要

  • 一个资源文件 resource/win32resource.rc，
  • 把 VS_STARTUP_PROJECT 设为 MyPlugin，以及
  • 一个用于在调试时启动插件的可执行文件 .../VST3PluginTestHost.exe
if(SMTG_MAC)
    smtg_target_set_bundle(MyPlugin
        BUNDLE_IDENTIFIER org.mycompany.MyPlugin
        COMPANY_NAME My Company
    )
    smtg_target_set_debug_executable(MyPlugin
        "/Applications/VST3PluginTestHost.app"
        "--pluginfolder;$(BUILT_PRODUCTS_DIR)"
    )
elseif(SMTG_WIN)
    target_sources(MyPlugin
        PRIVATE 
            resource/win32resource.rc
    )
    if(MSVC)
        set_property(DIRECTORY ${CMAKE_CURRENT_SOURCE_DIR} PROPERTY VS_STARTUP_PROJECT MyPlugin)

        smtg_target_set_debug_executable(MyPlugin
            "$(ProgramW6432)/Steinberg/VST3PluginTestHost/VST3PluginTestHost.exe"
            "--pluginfolder \"$(OutDir)/\""
        )
    endif()
endif()

使用 VSTGUI 添加插件 GUI 编辑器

为了给插件添加 VSTGUI 编辑器，请链接到 vstgui_support 目标。

target_link_libraries(MyPlugin
        PRIVATE
            vstgui_support
    )

添加 myplugin_editor.uisdesc 文件作为资源。该文件需要手动创建。

    smtg_target_add_plugin_resources(MyPlugin
        RESOURCES
            "resource/myplugin_editor.uidesc"
    )

可以使用 VST 3 project generator 创建带有基本 *.uidesc 文件的插件。
