版本 3.7.12（2024/07/23）

版本 3.7.12（2024/07/23）

  • 接口变更：

    • 新增标志位/枚举：
      • 新增预定义扬声器布局：
        • k70_2_TF = 7.0.2 顶部前置 => L R C Ls Rs Sl Sr Tfl Tfr（~ITU 2+7+0.0）。
        • k71_2_TF = 7.1.2 顶部前置 => L R C Lfe Ls Rs Sl Sr Tfl Tfr（~ITU 2+7+0.1）。

  • VSTGUI 更新至 4.14.0

  • 文档

    • 新教程：AudioUnit 教程 - 如何为 VST 3 插件添加 AUv2 支持。

  • CMake

    • 添加改动以支持 Apple AudioUnit SDK，用于 AU 包装层。

  • 插件包装层：

    • AAX 包装层：将项目 aaxwrapper 重命名为 aax_wrapper。
    • Audio Unit 包装层：
      • AU/AUv3 包装层：
        • 添加对旧版 CoreAudio 和新版官方 AudioUnitSDK（版本 1.1.0）的支持。
      • AU 包装层：
        • 添加 MIDI 2.0 支持（力度和 CC 的更高分辨率），使用解码 UMP 消息的辅助工具（public.sdk/source/vst/utility/ump.h）。
        • 添加对 MIDI 学习接口 Vst:: IMidiLearn 的支持。
        • 添加程序列表信息缓存，使编辑控制器不会在处理线程中被调用。
        • 添加 MIDI 映射缓存，不再在音频处理线程中调用 IMidiMapping 接口。
        • 清理 public.sdk/source/vst/auwrapper/auwrapper.mm/auwrapper.h。
        • 修复程序变更信息更新的线程问题。
        • 修复 VST3DynLibrary 类中的引用计数问题。
        • 修复音符挂起问题。
      • AUv3 包装层：
        • 修复触摸/手势（begin/end edit）。

  • 示例：

    • 为每个示例添加 README.md 文件。
    • 重命名项目名称，以提高可读性。
    • 由于缺少 Linux 实现，暂时禁用 Linux 上的 dataexchange 示例。
    • 更新 Hostchecker 插件：
      • 新增宿主检查：在 setActive 之后、Vst:: IAudioProcessor::setProcessing 或 process 之前调用 getLatency。
      • 新增 Randomize + LowLatency + DryWet 参数，支持 Vst:: IParameterFunctionName。

  • 辅助类：

    • hosting/test/connectionproxytest.cpp：避免 connectionproxytest 中可能出现的挂起（PR#66）。
    • hosting/module_mac.mm：修复警告（-Wnullable-to-nonnull-conversion）（PR#67）。
    • hosting/module_win32.cpp：在 Windows 上加载库时给出更好的失败报告（PR#68）。
    • 移除对 VSTGUI 4.1 或更早版本的支持。
    • common/pluginview.cpp：移除析构函数中调用的虚函数（Issue#79）。
    • 重构 public.sdk/source/vst/utility/stringconvert.cpp，并提取出公共基础文件：public.sdk/source/common/commonstringconvert.cpp。
    • 将「FUnknownPtr<XXX> xxx (context);」替换为「auto xxx = Steinberg::U::cast<XXX> (context);」
      • 需要包含「pluginterfaces/base/funknownimpl.h」。
    • 修复 VST 2 预设的加载：tryVst2StateLoad，位于 public.sdk\source\vst\utility\vst2persistence.cpp（PR#72）。

  • VST3PluginTestHost v3.8 版本：

    • 新特性：
      • 文件 => 卸载 MIDI 文件
      • 文件 => 导出音频...
      • 文件 => 为当前加载的 MIDI 导出音频...
      • 走带 => 在时间与小节格式之间切换
      • 走带 => 更改歌曲位置
      • 走带 => 更改速度和拍号
