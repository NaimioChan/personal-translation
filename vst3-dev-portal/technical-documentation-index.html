VST 3 API 文档

VST 3 API 是一套为实时音频处理组件设计的接口集合。此类组件可以是音频效果器，也可以是乐器。

[3.1.0] 音频呈现延迟

告知插件：从生成/获取（从文件或从输入）的那一刻起，其输入需要多久才能到达，以及其输出需要多久才能呈现（到输出或到扬声器）。

[3.1.0] UI 组编辑、脏状态 & 打开编辑器请求

改进插件在宿主中的集成（脏状态、请求打开编辑器、组编辑）。

[3.1.0] KnobMode、打开帮助 & 打开关于框

允许宿主把宿主旋钮模式告知插件的扩展。

[3.5.0] 音符表达式

一种在播放过程中控制 / 修改 / 改变某个正在演奏的音符的新方式。

[3.5.0] 键位切换

允许插件与宿主之间就当前使用了哪些键位切换进行信息交换。

[3.5.0] 参数的远程呈现

如何更好地为参数支持远程设备/控制器（UI 与硬件）。

[3.5.0] 上下文菜单

插件可以请求宿主为给定的已导出参数 ID 创建上下文菜单，或创建一个通用上下文菜单。

[3.5.0] 增强的链接参数

这允许宿主启动一次参数编辑操作，该操作可以产生其他参数变化（例如链接参数），并且都发生在同一个会话中（在 beginEdit 与 endEdit 之间）。

[3.6.0] iOS 应用间音频

将你的 VST 3 插件做成 iOS InterApp-Audio 应用。

[3.6.0] 预设元信息

用于从流中访问预设元信息的接口，例如用于 setState，以便告知插件当前加载预设所处的上下文。

[3.6.5] 通道上下文信息

允许宿主把插件被实例化时所处的上下文告知插件，主要是基于通道的信息（颜色、名称、索引等）。

[3.6.5] 单位-总线分配变更

插件可以通过 notifyUnitByBusChange 告知宿主总线 - 单位分配发生了变化。

[3.6.5] 可预取

指示插件是否（动态地）支持预取。

[3.6.5] 自动化状态

宿主可以把当前的自动化状态（Read/Write/Nothing）告知插件。

[3.6.6] PlugView 内容缩放

在插件无法直接获取此信息的系统（如 Microsoft Windows）上，此接口把内容缩放因子从宿主传递给插件视图。

[3.6.8] 请求总线激活

允许插件请求宿主激活或停用特定的总线。

[3.6.10] UI 快照

VST 3 包中可以包含为 VST 3 宿主预渲染的快照图像，作为插件 UI 的可视化表示。

[3.6.11] NoteExpression 物理 UI 映射

通过此插件接口，宿主可以获取插件所支持的、与音符表达式关联的首选物理映射。

[3.6.12] 旧版 MIDI CC 输出事件

此类事件专用于在处理调用期间为 kEvent 总线生成作为输出事件的 MIDI CC。

[3.6.12] MIDI 学习（MIDI 1.0 支持）

如果编辑控制器实现了此接口，那么只要有针对该插件的实时 MIDI 1.0 CC 输入，宿主就会调用此方法。

[3.6.12] 宿主查询接口支持

允许插件询问宿主是否支持/使用某个插件接口。

[3.6.12] 包装层的 MPE 支持

在支持 MPE（MIDI 复音表达式）到 音符表达式 转换的包装层上实现。

[3.7.0] 参数函数名

此接口允许宿主获取给定单位中与特定含义（functionName）关联的参数。

[3.7.0] 进度显示

此接口允许插件请求宿主为耗时较长的特定任务创建进度显示。

[3.7.0] 处理上下文要求

要获得准确的处理上下文信息（Vst::ProcessContext），现在必须实现此接口。

[3.7.5] 模块信息

moduleinfo.json 以 JSON5 兼容的格式描述插件的内容。

[3.7.9] 获取当前 SystemTime

此接口允许插件向宿主询问当前的系统时间。

[3.7.9] 处理器与控制器之间的数据传输

这些接口允许你通过直接且线程安全的连接，把数据从音频处理器的实时音频上下文发送到编辑控制器的非实时音频上下文。

[3.7.11] 重映射参数 ID

此接口允许插件在需要时请求宿主重映射某些参数 ID。

[3.8.0] 参数 MIDI 映射 2（MIDI 2.0 支持）

说明 MIDI 2.0 CC 与参数之间的映射方式（取代 [3.0.1] 参数 MIDI 映射（MIDI 1.0 支持））。

[3.8.0] MIDI 学习 2（MIDI 2.0 支持）

如果编辑控制器实现了此接口，那么只要有针对该插件的实时 MIDI 2.0 CC 输入，宿主就会调用此方法（取代 [3.6.12] MIDI 学习（MIDI 1.0 支持））。

[3.8.1] 走带控制

此接口允许插件向宿主请求与走带相关的操作。
