VST SDK 说明

VST SDK（Virtual Studio Technology Software Development Kit）是打包在一起的成套软件开发工具。借助它，插件开发者可以创建 VST 3 格式的插件，宿主开发者可以把 VST 3 插件加载到 DAW 或音频编辑器中。

包含的内容

VST SDK 软件包包含：

VST 3 API 接口

这是一个 C++ 接口，定义了 VST 3 插件如何与宿主通信，以及宿主如何与插件通信。它是 VST 3 的核心。

查看 SDK 的 "pluginterfaces/vst" 文件夹！

VST 3 实现辅助类

SDK 提供了一些辅助类，实现了部分 VST 3 接口，用于承载宿主以及创建 VST 3 插件。只需让你的插件 C++ 类派生自这些辅助类。

查看 SDK 的 "public.sdk" 文件夹！

VST 3 插件示例

SDK 包含一些插件实现示例。

VST 3 插件测试宿主

SDK 提供一个名为 VST3PluginTestHost 的测试应用，适用于 Apple macOS（Apple Silicon/Intel x86_64）与 Microsoft Windows（x64 与 Arm64EC）。

VST 3 项目生成器

这个开源应用（Win/macOS）让你只需在 GUI 中输入一些参数，就能轻松生成新的 VST 3 插件工程。

Validator 命令行

validator 是一个小型命令行宿主应用（含源代码），可用于检查插件是否符合 VST 3 规范。

AudioHost

简单的跨平台（仅在 Linux 上测试过）宿主应用，可让你把一个 VST 3 插件注册到 Jack Server。

EditorHost

简单的跨平台（Win/macOS/Linux）宿主应用，可让你打开 VST 3 插件的编辑器。

VST 3 Inspector

简单的跨平台（Win/macOS/Linux）宿主应用，使用 VSTGUI 构建，会扫描 VST 3 文件夹，从工厂收集每个 VST 3 插件的信息，并在其 UI 中显示。

VSTGUI

这是一个主要面向音频插件（VST、AudioUnit 等）的用户界面工具包。基于插件 UI 的 XML 定义，VSTGUI 包含一个内嵌编辑器（UIDescription Editor），让开发者只需拖放 UI 元素就能创建插件 UI。

AAX、AUv3 和 AU 包装层

这些包装层让你以最小的代价，把你的 VST 3 插件生成为其他插件格式的版本。

iOS 应用间音频支持

由你的 VST 3 插件生成 iOS InterApp-Audio 应用

VST 3 许可

VST 3 SDK 采用 MIT 许可证。
