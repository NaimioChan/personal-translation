引言

在典型的录音棚计算机系统上管理大量插件和多个虚拟乐器，常常会因 CPU 性能限制而变得困难。VST 3 仅当插件的相应输入上存在音频信号时才对其执行处理，从而帮助提升整体性能。VST 3 插件不必始终处理输入信号，而是可以经济地、仅在需要时进行处理。

该特性由插件的 Vst:: IAudioProcessor 接口支持。

静音标志是 AudioBusBuffers（silenceFlags）的一部分，在 process 调用中由宿主传给插件，再传回宿主：

  • MyPluginProcessor::process (ProcessData& data)
  • 对于输入：检查此标志：data.inputs[0]silenceFlags
  • 对于输出：当插件生成或不生成静音时设置此项：data.outputs[0].silenceFlags

静音标志是一个位掩码，其中每一位对应总线的一个通道（例如立体声总线的 L 和 R）。

ⓘ注意
当宿主启用静音标志时，由宿主负责清空输入缓冲区（设为接近零的值，例如 10e-7，以避免非规格化问题）（输出静音标志将由宿主设为无静音（=0））；另一方面，如果插件产生静音输出，则由插件负责清空（置零）其输出缓冲区并正确设置输出静音标志。

参见关于如何使用静音标志的教程。
