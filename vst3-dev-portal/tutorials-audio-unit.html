在本教程中，你将学习如何为你的 VST 3 插件添加 AudioUnit 第 2 版支持。

首先，你需要一个 VST 3 插件工程。本教程所用的工程是我们通过 SDK 中的 VST 3 Project Generator 生成的。

添加 AudioUnit 第 2 版目标

获取所需的 AudioUnit SDK

AudioUnit Version 2 目标需要 Apple 官方的 AudioUnit SDK。截至本文撰写时，你可以在 GitHub 上找到它：https://github.com/apple/AudioUnitSDK

如何获取和存放 SDK 由你决定；为保证本教程可复现，我们将在生成工程时通过 CMake 下载它。因此我们直接把以下文本添加到 CMakeLists.txt 中，位置在包含 VST SDK 之前。

include(FetchContent)
FetchContent_Declare(
	AudioUnitSDK
	GIT_REPOSITORY https://github.com/apple/AudioUnitSDK.git
	GIT_TAG        HEAD
)
FetchContent_MakeAvailable(AudioUnitSDK)
FetchContent_GetProperties(
	AudioUnitSDK
	SOURCE_DIR SMTG_AUDIOUNIT_SDK_PATH
)

重要的是设置 SMTG_AUDIOUNIT_SDK_PATH 变量，以告知 VST SDK 到哪里查找 AudioUnit SDK。

创建属性列表

对于 AudioUnit Version 2，你需要一个在 Apple 注册的厂商 OSType。如何操作不在本教程范围内，请在网上搜索相关做法。

除了厂商 OSType，你还需要一个可自行选择的子类型 OSType。厂商和子类型共同决定了你的 AudioUnit Version 2 的唯一性。

现在你可以生成所需的属性列表文件：

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
	<key>CFBundleDevelopmentRegion</key>
	<string>English</string>
	<key>CFBundleExecutable</key>
	<string>$(EXECUTABLE_NAME)</string>
	<key>CFBundleIdentifier</key>
	<string>$(PRODUCT_BUNDLE_IDENTIFIER)</string>
	<key>CFBundleName</key>
	<string>$(PRODUCT_NAME)</string>
	<key>CFBundleInfoDictionaryVersion</key>
	<string>6.0</string>
	<key>CFBundlePackageType</key>
	<string>BNDL</string>
	<key>CFBundleSignature</key>
	<string>????</string>
	<key>CFBundleVersion</key>
	<string>1.0</string>
	<key>CSResourcesFileMapped</key>
	<string>yes</string>
	<key>AudioComponents</key>
	<array>
		<dict>
			<key>factoryFunction</key>
			<string>AUWrapperFactory</string>
			<key>description</key>
			<string>AudioUnit Tutorial</string>
			<key>manufacturer</key>
			<string>Stgb</string>
			<key>name</key>
			<string>Steinberg: AudioUnit Tutorial</string>
			<key>subtype</key>
			<string>0002</string>
			<key>type</key>
			<string>aufx</string>
			<key>version</key>
			<integer>1</integer>
		</dict>
	</array>
</dict>
</plist>

请务必修改 description、manufacturer、name、subtype 和 type 的字符串。type 必须是以下之一：

  • aufx（音频效果器）
  • aumu（乐器）
  • aumf（带 MIDI 输入/输出的音频效果器）

如果你构建的是音频效果器，还需要把支持的通道布局添加到列表中：

<key>AudioUnit SupportedNumChannels</key>
<array>
	<dict>
		<key>Outputs</key>
		<string>2</string>
		<key>Inputs</key>
		<string>2</string>
	</dict>
	<dict>
		<key>Outputs</key>
		<string>2</string>
		<key>Inputs</key>
		<string>1</string>
	</dict>
	<dict>
		<key>Outputs</key>
		<string>1</string>
		<key>Inputs</key>
		<string>1</string>
	</dict>
</array>

把它保存为资源目录中名为 au-info.plist 的文件。

添加 AudioUnit 第 2 版目标

现在你可以把 AudioUnit 目标添加到 CMakeLists.txt 文件末尾：

if (SMTG_MAC AND XCODE AND SMTG_COREAUDIO_SDK_PATH)
	list(APPEND CMAKE_MODULE_PATH "${vst3sdk_SOURCE_DIR}/cmake/modules")
	include(SMTG_AddVST3AuV2)
	smtg_target_add_auv2(VST3_AU_PlugIn_AU
		BUNDLE_NAME audiounit_tutorial
		BUNDLE_IDENTIFIER com.steinberg.vst3sdk.audiounit_tutorial.audiounit
		INFO_PLIST_TEMPLATE ${CMAKE_CURRENT_SOURCE_DIR}/resource/au-info.plist
		VST3_PLUGIN_TARGET VST3_AU_PlugIn)
    smtg_target_set_debug_executable(VST3_AU_PlugIn_AU "/Applications/Reaper.app")
endif(SMTG_MAC AND XCODE AND SMTG_COREAUDIO_SDK_PATH)

现在，生成并构建工程之后，「audiounit_tutorial」插件应当可以在任何 AudioUnit 宿主中使用。
