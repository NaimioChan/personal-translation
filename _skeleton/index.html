非茗的翻译文档库

示例文档库

本页是文档库的首页，说明当前库收录的文档、原文链接、译文更新时间。左侧目录由 nav.js 和本页标题自动生成。

概述

一段话交代文档主题和适用范围。库首页不需要翻译原文的正文。

写入流程

  1. 把 nav.js 里的 title、source、updated、pages 改成当前库的实际内容。
  2. 复制 page.html，每个原文页面存成对应的 HTML 文件，用英文短横线命名。
  3. 替换每个页面 <h1> 之后的正文。
  4. 在仓库根的 assets/libraries.js 里登记当前库库。
