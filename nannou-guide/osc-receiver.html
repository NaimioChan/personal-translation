接收 OSC

教程信息

  • 作者：mitchmindtree
  • 所需知识：
    • nannou 应用剖析
    • OSC 入门
    • 发送 OSC
  • 阅读时间：15 分钟

在上一个教程中，我们通过 OSC 把一个圆形的位置发送了出去。在本教程中我们将做相反的事：从另一个应用接收 OSC 数据包，并把它们显示在窗口中。

我们仍然使用 nannou_osc crate。如果你还没有把它添加到项目中，请参阅OSC 入门。

# #![allow(unused_imports)]
use nannou_osc as osc;
# fn main() {}

设置 OSC 接收端

发送端在其 Model 中存放一个 osc::Sender，而接收端存放的则是一个 osc::Receiver。

我们还会保存一个已收到数据包的列表，以便把它们绘制出来。每个收到的数据包都与发送方的网络地址配对，所以我们把两者都存下来。

# #![allow(dead_code, unused_imports)]
# use nannou_osc as osc;
struct Model {
    receiver: osc::Receiver,
    received_packets: Vec<(std::net::SocketAddr, osc::Packet)>,
}
# fn main() {}

接下来，我们在 model 函数中设置 Model。一个 osc::Receiver 会绑定到一个网络端口 —— 也就是发送应用所指向的同一个端口。请确保它与你的发送端所用的端口一致（在发送教程中我们用的是 1234，这里我们用 34254 以匹配 nannou 的 osc_sender.rs 示例 —— 任选一个你喜欢的，只要发送端和接收端一致即可）。

# #![allow(dead_code, unused_imports)]
# use nannou_osc as osc;
# use nannou::prelude::*;
# struct Model {
#     receiver: osc::Receiver,
#     received_packets: Vec<(std::net::SocketAddr, osc::Packet)>,
# }
// 我们将用来监听 OSC 数据包的端口。
const PORT: u16 = 34254;

fn model(_app: &App) -> Model {
    // 把一个 `osc::Receiver` 绑定到该端口。
    let receiver = osc::receiver(PORT).unwrap();

    // 用来收集数据包及其源地址的 vec。
    let received_packets = vec![];

    Model {
        receiver,
        received_packets,
    }
}
# fn main() {}

绑定可能会失败（例如另一个程序已经占用了该端口），所以 osc::receiver 返回一个 Result。这里我们简单地对它 unwrap()，如果绑定不成功，程序会输出一条错误消息并退出。

接收 OSC 消息

接收端在后台收集传入的数据包。为了取出它们，我们在一个 update 函数中每一帧轮询接收端。try_iter 方法返回一个迭代器，遍历自上次检查以来到达的所有数据包，如果没有数据包则不会阻塞。每一项是一个元组，包含 osc::Packet 和它的来源 SocketAddr。

# #![allow(dead_code, unused_imports)]
# use nannou_osc as osc;
# use nannou::prelude::*;
# struct Model {
#     receiver: osc::Receiver,
#     received_packets: Vec<(std::net::SocketAddr, osc::Packet)>,
# }
fn update(_app: &App, model: &mut Model) {
    // 接收所有待处理的 OSC 数据包。
    for (packet, addr) in model.receiver.try_iter() {
        model.received_packets.push((addr, packet));
    }

    // 我们一次显示 10 个数据包，所以移除多余的。
    while model.received_packets.len() > 10 {
        model.received_packets.remove(0);
    }
}
# fn main() {}

注意：如果你更愿意等待数据包到达而不是没有数据包也继续，可以改用阻塞的 recv 方法。在 nannou 应用中我们通常更喜欢非阻塞的 try_iter，这样绘制和其他事件就不会被拖住。

完整的应用

最后，我们把收到的数据包以文本形式绘制到窗口中。把所有内容合在一起：

use nannou::prelude::*;
use nannou_osc as osc;

// 与发送端所用的端口保持一致。
const PORT: u16 = 34254;

fn main() {
    nannou::app(model).update(update).simple_window(view).run();
}

struct Model {
    receiver: osc::Receiver,
    received_packets: Vec<(std::net::SocketAddr, osc::Packet)>,
}

fn model(_app: &App) -> Model {
    let receiver = osc::receiver(PORT).unwrap();
    let received_packets = vec![];
    Model {
        receiver,
        received_packets,
    }
}

fn update(_app: &App, model: &mut Model) {
    // 接收所有待处理的 OSC 数据包。
    for (packet, addr) in model.receiver.try_iter() {
        model.received_packets.push((addr, packet));
    }

    // 我们一次显示 10 个数据包，所以移除多余的。
    while model.received_packets.len() > 10 {
        model.received_packets.remove(0);
    }
}

fn view(app: &App, model: &Model, _window: Entity) {
    let draw = app.draw();
    draw.background().color(DARK_BLUE);

    // 创建一个字符串，显示目前为止收到的所有数据包。
    let mut packets_text = format!("Listening on port {}\nReceived packets:\n", PORT);
    for &(addr, ref packet) in model.received_packets.iter().rev() {
        packets_text.push_str(&format!("{}: {:?}\n", addr, packet));
    }

    let rect = app.window_rect().pad(10.0);

    draw.text(&packets_text)
        .font_size(16)
        .align_text_top()
        .left_justify()
        .wh(rect.wh());
}

与上一个教程中的发送端（或 nannou 的 osc_sender.rs 示例）一起运行这个应用，你应该能看到 OSC 消息在到达时出现在窗口中。

你可以在 nannou 仓库中找到这个示例的完整可运行版本 osc_receiver.rs。
