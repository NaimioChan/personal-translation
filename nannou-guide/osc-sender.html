在本教程中，我们将介绍如何使用 nannou_osc crate 从 nannou 应用向另一个应用发送 OSC 数据。

我们要编写一个简单的程序：一个圆形在屏幕上移动，同时圆形的位置通过 OSC 发送到另一个应用。我们将继续基于让圆形动起来中的应用来开发。

设置 OSC 发送端

在 main.rs 文件顶部，导入 nannou_osc crate，并通过简写 osc 让它在你的程序中可用。

# #![allow(unused_imports)]
use nannou_osc as osc;
# fn main(){}

接下来我们需要做的第一件事，是在你在其他 nannou 教程中可能见过的 Model 结构体中设置 OSC 发送端。

给这个结构体添加一个名为 sender 的字段，类型为 Sender 结构体。

# #![allow(dead_code, unused_imports)]
# use nannou_osc as osc;
struct Model {
    sender: osc::Sender<osc::Connected>,
}
# fn main() {}

接下来，我们需要用 model 函数来设置 Model 结构体。别担心它一开始看起来有点吓人，我们会一步一步地讲解。

# #![allow(dead_code, unused_imports)]
# use nannou_osc as osc;
# use nannou::prelude::*;
# struct Model {
#   sender: osc::Sender<osc::Connected>,
# }
fn model(_app: &App) -> Model {
    let port = 1234;
    let target_addr = format!("{}:{}", "127.0.0.1", port);

	let sender = osc::sender()
        .expect("Could not bind to default socket")
        .connect(target_addr)
        .expect("Could not connect to socket at address");

    Model { sender }
}
# fn main() {}

首先，让我们选择数据要发送到的网络端口。

# #![allow(unused_variables)]
# fn main() {
let port = 1234;
# }

osc 发送端期望一个格式为 "address:port" 的字符串，例如 "127.0.0.1:1234"。

这个地址可以是内部地址，也可以是你网络中另一台计算机的地址。在本教程中，我们将以自己计算机的内部地址为目标，它用 "127.0.0.1" 表示。

# #![allow(unused_variables)]
# fn main() {
# let port = 1234;
let target_addr = format!("{}:{}", "127.0.0.1", port);
# }

最后，我们需要把 OSC 发送端绑定到网络套接字上。这并不总是成功，所以我们附加了 expect() 方法（点此阅读关于 expect() 的更多信息），在不成功时输出错误消息。如果成功，则用 .connect(target_addr) 方法把发送端连接到目标地址。同样，这也可能不成功，所以我们对该操作的结果也使用 expect() 方法。

# #![allow(unused_variables)]
# use nannou_osc as osc;
# fn main() {
#     let port = 1234;
#     let target_addr = format!("{}:{}", "127.0.0.1", port);
let sender = osc::sender()
    .expect("Could not bind to default socket")
    .connect(target_addr)
    .expect("Could not connect to socket at address");
# }

发送 OSC 消息

一个 OSC 数据包至少由两部分组成：一个 OSC 地址和 0 个或多个包含数据的参数。OSC 地址不要与我们之前连接的网络地址混淆。相反，OSC 地址是一种类似 URL 的路径，例如 /circle/position。

要创建一个 OSC 数据包，我们首先需要构造一个地址。

# #![allow(unused_variables)]
# fn main() {
let osc_addr = "/circle/position".to_string();
# }

然后创建一个参数向量。这些参数需要使用 nannou_osc crate 中 osc::Type 里的类型来格式化。下面我们创建一个包含两个浮点值的参数列表：我们圆形的 x 和 y 坐标。

# #![allow(unused_variables)]
# use nannou_osc as osc;
# fn main() {
# let x = 0.0;
# let y = 0.0;
let args = vec![osc::Type::Float(x), osc::Type::Float(y)];
#
# }

现在，把这两者合在一起，我们就得到了一个 OSC 数据包。发送端期望它们以元组的形式传递。

# #![allow(unreachable_code, unused_variables)]
# fn main() {
# let osc_addr = unimplemented!();
# let args = unimplemented!();
let packet = (osc_addr, args);
# }

通过阅读 send 方法的文档，我们可以看到它返回一个 Result 类型：成功时包含写入的字节数，而更重要的是，不成功时包含一些有用的 CommunicationError 类型的错误。为了丢弃其中的错误部分，我们在最后使用 ok() 方法。

# #![allow(unreachable_code, unused_variables)]
# use nannou_osc as osc;
# struct Model {
#    sender: osc::Sender<osc::Connected>,
# }
# fn main() {
#    let model: Model = unimplemented!();
#    let osc_addr = "/circle/position".to_string();
#    let args = vec![osc::Type::Float(0.0), osc::Type::Float(0.0)];
#    let packet = (osc_addr, args);
    model.sender.send(packet).ok();
# }

完整的应用

use nannou::prelude::*;
use nannou_osc as osc;

fn main() {
    nannou::app(model).simple_window(view).run();
}

struct Model {
    sender: osc::Sender<osc::Connected>,
}

fn model(_app: &App) -> Model {
    // 数据发送到的网络端口
    let port = 1234;

    // osc 发送端期望一个格式为 "address:port" 的字符串，例如 "127.0.0.1:1234"
    // "127.0.0.1" 等同于你的计算机的内部地址。
    let target_addr = format!("{}:{}", "127.0.0.1", port);

    // 这是 osc 发送端，其中包含若干 expect，以防出现问题。
    let sender = osc::sender()
        .expect("Could not bind to default socket")
        .connect(target_addr)
        .expect("Could not connect to socket at address");

    Model { sender }
}

fn view(app: &App, model: &Model, _window: Entity) {
    // 用应用时间推进正弦波
    let sine = app.time().sin();
    let slowersine = (app.time() / 2.0).sin();

    // 获取窗口的边界（用来约束圆形的移动）
    let boundary = app.window_rect();

    // 把正弦波函数映射到窗口边界之间的区间
    let x = map_range(sine, -1.0, 1.0, boundary.left(), boundary.right());
    let y = map_range(slowersine, -1.0, 1.0, boundary.bottom(), boundary.top());

    // 把 x-y 坐标作为 OSC 发送
    let osc_addr = "/circle/position".to_string();
    let args = vec![osc::Type::Float(x), osc::Type::Float(y)];
    let packet = (osc_addr, args);

    model.sender.send(packet).ok();

    // 准备绘制。
    let draw = app.draw();

    // 把背景清成紫色。
    draw.background().color(PLUM);

    // 在 x/y 坐标 0.0, 0.0 处画一个蓝色椭圆
    draw.ellipse().color(STEEL_BLUE).x_y(x, y);

    
}
