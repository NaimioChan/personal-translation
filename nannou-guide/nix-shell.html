Nix Shell

nannou 仓库提供了一个 Nix shell，作为在 macOS 和 Linux 上提供可复现环境的一种方式。这让 nannou 仓库的 CI 简化了一点，同时也让人们更容易借助一个已知可用的环境来试验 nannou。

安装 Nix

Determinate Systems 安装程序是开始使用 Nix 最简单的方式之一。

Nannou 的 Nix 文件

  • default.nix - 一个描述如何构建 nannou Rust 包的 derivation，包含其所有示例以及所有必需的环境变量。这就是运行 nix build 时默认构建的内容。当
  • shell.nix - 一个描述开发 shell 的 derivation，为开发 nannou 及其示例提供所有必需的系统依赖和环境变量。
  • flake.nix - 一个 Nix 清单标准，声明 nannou 包和 devShell。

添加 nannou 依赖

添加新包（例如系统依赖）时：

  1. 在 nixpkgs 中找到该包（nix search nixpkgs <name> 很方便）
  2. 把该包添加到 default.nix 的输入属性集中。
  3. 如果它是运行时依赖，就把该包添加到 buildInputs；如果是构建时依赖，则添加到 nativeBuildInputs。

添加开发 Shell 依赖

要添加方便的开发依赖（例如 rustfmt、rust-analyser），做法相同，只不过把它们添加到 shell.nix 中。

添加环境变量

把它们添加到 default.nix 或 shell.nix 中的 env 属性里。

构建一切

用 nix build 构建 nannou 工作区内的所有二进制文件、示例和 dylib。完成后，在 result 符号链接目录中就能找到所有构建好的二进制文件。

进入 nannou devShell

要进入一个带有 nannou 开发所需的全部工具和环境变量的开发 shell，请使用 nix develop。

要快速进入一个 nannou 开发 shell 来构建下游的 nannou 项目，你可以使用：nix develop github:nannou-org/nannou。
