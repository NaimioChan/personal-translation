PR 评审

你的 PR 已经提交，现在该等待评审了。

请记住，nannou 团队和社区成员大多是在个人时间里照看 nannou 的。因此，很难说你的代码要多久才会被评审和接受。

以下是一些能帮助你尽快让 PR 落地的事情：

  • 遵循 PR 检查清单。
  • 请求评审，向另一位社区成员求助。特别是如果你的 PR 处理的是别人评论过的议题，他们可能会有兴趣看看。来自其他社区成员的评审会让维护者更容易信任并落地你的变更。了解到这一点后，如果你看到其他社区成员的 PR，也可以考虑主动提供你自己的评审！
