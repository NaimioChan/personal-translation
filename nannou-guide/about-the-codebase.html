关于代码库

nannou 社区使用 git 来管理和协作所有的代码与文档，也包括本指南！目前，主代码仓库（repo）托管在 Github 上。

拉取请求

nannou 的所有代码变更和代码评审都通过「拉取请求」（Pull Requests，PR）进行。如果你还不熟悉拉取请求，网上有许多优秀的指南，但简而言之，它是对代码库提出、评审、讨论并合并变更的一种好方式。
