让圆形在屏幕上移动

在本教程中，我们将介绍在 nannou 应用的窗口中移动形状的基础知识。

让我们先写一个简单的程序，在屏幕中央绘制一个圆形。

我们将以nannou 应用剖析中的基础应用作为起点。

把你的 nannou-app 的 view 函数改成这样：

# #![allow(dead_code)]
# #![allow(unused_imports)]
# extern crate nannou;
# use nannou::prelude::*;
# struct Model{}
# fn main() {
#    nannou::app(model)
#        .simple_window(view)
#        .run();
# }
# fn model(_app: &App) -> Model {
#    Model {}
# }
fn view(app: &App, _model: &Model, _window: Entity) {
	// 准备绘制。
    let draw = app.draw();

    // 把背景清成紫色。
    draw.background().color(PLUM);

	// 在坐标 (0.0, 0.0) 处绘制一个半径为 10 的蓝色椭圆
    draw.ellipse().color(STEEL_BLUE).x_y(0.0,0.0);

    
}

添加运动

现在让我们给圆形添加一些运动，让它有一点生气。

为此，我们会用到永远美妙的正弦波。

在 nannou 中，只要取应用推进的时间并把它喂给正弦函数，就能生成这些波形。

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let app: App = unimplemented!();
let sine = app.time().sin();
# }

让我们再做一个，速度只有一半——把时间值除以二。

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let app: App = unimplemented!();
let slowersine = (app.time() / 2.0).sin();
# }

现在我们有了两个生成平滑波浪运动的函数，就让它们来控制我们的小圆吧。

如果把这些值直接放进椭圆的 `.x_y()` 方法里，我们看不到多少运动。这是因为正弦波生成的值在 -1.0 到 1.0 之间，而坐标需要的是像素位置。

但我们的窗口有多宽？为了精确了解这一点，我们可以用一个便捷的方法叫作 window_rect，它在 `app` 变量中可用。

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let app: App = unimplemented!();
let boundary = app.window_rect();
# }

这会把窗口的边界给我们，作为一个便捷的 `Rect`。这是一个结构体，响应大量有用的方法，我们可以用它们分别定义 x 和 y 坐标的最小值与最大值，从而约束圆形的运动。

于是 x 的最小值可用如下方式取得：

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let boundary: geom::Rect = unimplemented!();
boundary.left();
# }

而 x 的最大值是

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let boundary: geom::Rect = unimplemented!();
boundary.right();
# }

y 的最小值是

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let boundary: geom::Rect = unimplemented!();
boundary.bottom();
# }

而 y 的最大值是

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let boundary: geom::Rect = unimplemented!();
boundary.top();
# }

把数值映射到区间

利用这些值，我们就可以把 `sine` 和 `slowersine` 的值映射到窗口边界内的值区间。为此，我们将使用 nannou 中可用的 map_range 函数。

`map_range` 函数接受 5 个参数：`val`、`in_min`、`in_max`、`out_min`、`out_max`。这里的 `val` 是我们的正弦波，它的最小值为 -1.0，最大值为 1.0。对于 x 坐标，我们把它映射到最左点和最右点之间的值区间。

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let app: App = unimplemented!();
#     let sine = app.time().sin();
#     let boundary = app.window_rect();
let x = map_range(sine, -1.0, 1.0, boundary.left(), boundary.right());
# }

然后对 y 值做同样的处理，只不过使用 `slowersine` 变量。

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let app: App = unimplemented!();
#     let sine = app.time().sin();
#     let slowersine = (app.time() / 2.0).sin();
#     let boundary = app.window_rect();
let y = map_range(slowersine, -1.0, 1.0, boundary.bottom(), boundary.top());
# }

现在剩下的唯一事情就是把它放进画圆函数的参数里。

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let app: App = unimplemented!();
#     let draw = app.draw();
#     let sine = app.time().sin();
#     let slowersine = (app.time() / 2.0).sin();
#     let boundary = app.window_rect();
#     let x = map_range(sine, -1.0, 1.0, boundary.left(), boundary.right());
#     let y = map_range(slowersine, -1.0, 1.0, boundary.bottom(), boundary.top());
draw.ellipse().color(STEEL_BLUE).x_y(x, y);
# }

你更新后的 `view` 函数现在应该看起来像这样：

# #![allow(dead_code, unreachable_code, unused_variables)]
# use nannou::prelude::*;
# struct Model{}
# fn main() {}
fn view(app: &App, _model: &Model, _window: Entity) {
    // 准备绘制。
    let draw = app.draw();

    // 基于应用的时间生成正弦波数据
    let sine = app.time().sin();
    let slowersine = (app.time() / 2.0).sin();

    // 获取窗口的边界（用来约束圆形的运动）
    let boundary = app.window_rect();

    // 把正弦波函数映射到窗口边界之间的区间
    let x = map_range(sine, -1.0, 1.0, boundary.left(), boundary.right());
    let y = map_range(slowersine, -1.0, 1.0, boundary.bottom(), boundary.top());

    // 把背景清成紫色。
    draw.background().color(PLUM);

    // 在 x/y 坐标 0.0, 0.0 处绘制一个蓝色椭圆
    draw.ellipse().color(STEEL_BLUE).x_y(x, y);

    
}
