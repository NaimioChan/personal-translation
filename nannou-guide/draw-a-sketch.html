绘制草图

教程信息

  • 作者：tpltnt
  • 预备知识：
    • 入门
  • 阅读时间：5 分钟

Nannou 是一个用 Rust 进行创意编程的框架。框架可以被看作一组有助于达成目标的构建块。草图是用 nannou 获得结果的最小/最快方式。下面是一个只产生蓝色窗口的示例：

use nannou::prelude::*;

fn main() {
    nannou::sketch(view).run();
}

fn view(app: &App) {
    // 获取要在其上绘制的画布
    let draw = app.draw();

    // 把背景设为蓝色
    draw.background().color(BLUE);

    // 把所有内容放到帧上
    
}

你可以按 ESC 退出草图。

讲解代码

一个草图至少由两个函数组成：main() 和 view()。首先我们导入一些构建块：

# #![allow(unused_imports)]
use nannou::prelude::*;
# fn main() {}

这次导入之后，真正的草图代码开始了。main() 函数是所有逻辑开始的地方。代码

# use nannou::prelude::*;
#
# fn main() {
    nannou::sketch(view).run();
# }
# fn view(_app: &App) {}

调用一个函数在唯一那个窗口上绘制（这里是 view()）。这个函数的签名是 fn(_: &App);。如果你不知道什么是函数签名，不必担心。照抄 main() 函数就好。

在 view() 函数里，我们绘制的一切都会呈现在我们的窗口中。

# #![allow(unused_imports)]
# use nannou::prelude::*;
# fn main() {
#    nannou::sketch(view).run();
# }
fn view(app: &App) {
    let draw = app.draw();

    draw.background().color(BLUE);

    
}

这个函数遵循同样的套路。首先做一些设置。这一行

# #![allow(unused_imports, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#    nannou::sketch(view).run();
# }
# fn view(app: &App) {
let draw = app.draw();
# }

让我们把一种类似画布的数据类型赋给变量 draw。现在我们可以通过把背景设为蓝色来在这块画布上涂画。

# #![allow(unused_imports)]
# use nannou::prelude::*;
# fn main() {
#    nannou::sketch(view).run();
# }
# fn view(app: &App) {
# let draw = app.draw();
draw.background().color(BLUE);
# }

现在我们有了一块只有蓝色背景的画布，nannou 会替我们把它呈现在主窗口中。

# #![allow(unused_imports)]
# use nannou::prelude::*;
# fn main() {
#    nannou::sketch(view).run();
# }
# fn view(app: &App) {
# let draw = app.draw();

# }
