Nannou 是一个面向 Rust 的开源创意编程工具包。

本指南的目标是帮助你找到所需要的信息。无论你是初次接触 Nannou、想找一个起点，还是经验丰富的 Nannou 用户、想看更高级的教程，本书都应该有适合你的内容！

我们对开发创意编程工具充满热情，也同样热衷于培育一个温暖、友好、包容的社区。请熟悉我们的行为准则，并随时加入 Nannou 的 Slack 或 Matrix 社区。
