基础 - sketch 与 app

教程信息

  • 作者：mitchmindtree
  • 预备知识：
    • 入门
  • 阅读时间：7 分钟

创建一个新的 nannou 项目时，我们有两种启动程序的选择：

  1. nannou::sketch 和
  2. nannou::app。

让我们来弄清这两者到底有什么区别！

注意：在本教程中提到 app 时，我们指的是通过 nannou::app 运行的 nannou 项目。我们不是指经常作为 nannou 函数第一个参数出现的 App 类型。希望不久的将来我们能给出一篇面向 App 的教程！

草图

草图非常适合快速涂鸦和随性创作。它们只要求一个简单的 view 函数，让开始绘制变得快捷又轻松。

草图模板长这样：

use nannou::prelude::*;

fn main() {
    nannou::sketch(view).run()
}

fn view(app: &App) {
    let draw = app.draw();
    draw.background().color(PLUM);
    draw.ellipse().color(STEEL_BLUE);
    
}

虽然你不能更新或跟踪任何自定义状态，但我们仍然能访问许多有趣的输入，包括时间、键盘状态、鼠标等等。

应用

应用更适合更复杂的作品，甚至完整的应用程序。它们比草图允许更大的灵活性和更细粒度的控制，但也需要稍微多一点的设置。

应用模板长这样：

use nannou::prelude::*;

fn main() {
    nannou::app(model).update(update).run();
}

struct Model {
    _window: Entity,
}

fn model(app: &App) -> Model {
    let _window = app.new_window().view(view).build();
    Model { _window }
}

fn update(_app: &App, _model: &mut Model) {}

fn view(app: &App, _model: &Model) {
    let draw = app.draw();
    draw.background().color(PLUM);
    draw.ellipse().color(STEEL_BLUE);
    
}

更确切地说，主要区别在于应用允许使用自定义状态（即 Model），而草图不行。

实用小贴士！

这一行：

# #![allow(dead_code)]
# use nannou::prelude::*;
# fn main() {
nannou::sketch(view).run()
# }
# fn view(_: &App) {}

其实只是

# #![allow(dead_code)]
# use nannou::prelude::*;
# fn main() {
nannou::app(model).simple_window(view).run()
# }
# struct Model {}
# fn model(_: &App) -> Model { Model {} }
# fn view(_: &App, _: &Model, _: Entity) {}

的简写，只是不需要 model，并且 view 函数略简单一些。

从 sketch 切换到 app

最终你选哪个并没有多大区别，你随时可以在项目中途从一种切换到另一种！

如果你的草图变得特别花哨，而你想增加一些灵活性，可以按以下步骤把它变成一个应用：

  1. 把你的 main 函数从

    # #![allow(dead_code)]
# fn main() {}
struct Model {}

    改为

    # #![allow(dead_code)]
# use nannou::prelude::*;
# fn main() {}
# struct Model {}
fn model(_app: &App) -> Model {
    Model {}
}

  2. 添加一个用于跟踪状态的 Model：

    # #![allow(dead_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {}
fn view(app: &App) {
# }

  3. 添加一个用于创建 Model 的 model 函数：

    # #![allow(dead_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {}
# struct Model {}
fn view(app: &App, _model: &Model, _window: Entity) {
# }
