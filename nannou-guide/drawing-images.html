绘制图像

教程信息

  • 作者：Josiah Savary
  • 前置知识：
    • 入门
    • 绘制草图
  • 阅读时间：20 分钟

在本教程中，我们探索用 nannou 绘制图像。我们会介绍如何从应用 assets 目录中的图像加载纹理、绘制它们，以及应用基本的变换。你也可以在 nannou 源码仓库的 examples 目录中找到这个文件以及其他有用的示例。

什么是纹理？

鉴于本教程的入门性质，我想先简要回答这个问题。引用 Learn Wgpu 网站的话：

纹理是覆盖在三角网格上的图像，让网格看起来更精细。

简而言之，这就是你机器上的 GPU 理解如何绘制图像的方式。Textures and bind groups 这篇文章绝对值得一读，适合想了解更多的人。

入门

首先，我们需要在项目根目录下用一些图像搭起一个 `assets` 目录。我建议把 `nannou` 仓库本身的 assets 目录复制过来作为开始。这可以在命令行中这样完成：

git clone https://github.com/nannou-org/nannou.git
cp -r nannou/assets ./assets
rm -rf nannou

一旦你的项目根目录下有了一个充实的 `assets` 目录，就可以回到 `main.rs` 文件继续后面的步骤了。

创建窗口

我们需要一个地方来显示图像，所以首先，让我们创建一个窗口：

# #![allow(unreachable_code, unused_variables, dead_code)]
use nannou::prelude::*;

struct Model {}

fn main() {
  nannou::app(model).run();
}

fn model(app: &App) -> Model {
  // 创建一个新窗口！
  app.new_window().size(512, 512).view(view).build();
  Model {}
}

fn view(_app: &App, _model: &Model) {
}

如果你 `cargo run` 你的应用，会看到一个空窗口。

设置纹理

现在，在 `main.rs` 文件的顶部，给 `Model` 结构体添加一个名为 `texture` 的图像 Handle<Image> 字段。`Handle` 是对由 Bevy 资产系统管理的资产（这里是图像/纹理）的轻量级引用。

# #![allow(unreachable_code, unused_variables, dead_code)]
# use nannou::prelude::*;
struct Model {
  texture: Handle<Image>,
}
# fn main() {
#   nannou::app(model).run();
# }
# fn model(app: &App) -> Model {
#   // 创建一个新窗口！
#   app.new_window().size(512, 512).view(view).build();
#   let texture: Handle<Image> = unimplemented!();
#   Model { texture }
# }
# fn view(_app: &App, _model: &Model) {
# }

接下来，我们需要加载一张图像来初始化这个结构体。我们可以在 `model` 函数中创建窗口之后，通过应用的 asset_server() 方法，请 Bevy 的资产服务器加载一个图像文件来完成这件事。资产服务器会在项目的 `assets` 目录中查找文件，所以我们只需要写出从该目录根部起的图像路径。加载在后台进行，返回的 `Handle` 一旦资产就绪就可以被绘制。

PNG 和 JPEG 图像默认受支持；更多格式（如 `hdr`、`exr`、`gif`、`webp`、`tiff`）可以通过 `nannou` crate 上同名的 cargo feature 来启用。

# #![allow(unreachable_code, unused_variables, dead_code)]
# use nannou::prelude::*;
# struct Model {
#   texture: Handle<Image>,
# }
# fn main() {
#   nannou::app(model).run();
# }
fn model(app: &App) -> Model {
  // 创建一个新窗口！
  app.new_window().size(512, 512).view(view).build();
  // 从磁盘加载图像并上传到 GPU 纹理
  let texture = app.asset_server().load("images/nature/nature_1.jpg");
  Model { texture }
}
# fn view(_app: &App, _model: &Model) {
# }

忙完这些之后，我们得到的还是一个空窗口……但不会太久了！

绘制纹理

最后，在 `view` 函数中，我们可以用 App 的 Draw API 的 `texture` 方法来绘制存储在模型中的纹理。

# #![allow(unreachable_code, unused_variables, dead_code)]
# use nannou::prelude::*;
# struct Model {
#   texture: Handle<Image>, 
# }
# fn main() {
#   nannou::app(model).run();
# }
# fn model(app: &App) -> Model {
#   // 创建一个新窗口！
#   app.new_window().size(512, 512).view(view).build();
#   // 从磁盘加载图像并上传到 GPU 纹理。
#   let texture = app.asset_server().load("images/nature/nature_1.jpg");
#   Model { texture }
# }
fn view(app: &App, model: &Model) {
  let draw = app.draw();
  draw.background().color(BLACK);

  draw
    .rect()
    .texture(&model.texture);
}

平移与缩放纹理

纹理可以在帧内绘制在任何位置、任何想要的大小。比方说，我们想把这张图像画成窗口左上角的一个 100x100 的正方形。我们的 `view` 函数可能与下面的类似。

# #![allow(unreachable_code, unused_variables, dead_code)]
# use nannou::prelude::*;
# struct Model {
#   texture: Handle<Image>, 
# }
# fn main() {
#   nannou::app(model).run();
# }
# fn model(app: &App) -> Model {
#   // 创建一个新窗口！
#   app.new_window().size(512, 512).view(view).build();
#   // 从磁盘加载图像并上传到 GPU 纹理。
#   let texture = app.asset_server().load("images/nature/nature_1.jpg");
#   Model { texture }
# }
fn view(app: &App, model: &Model) {
  let draw = app.draw();
  draw.background().color(BLACK);

  let win = app.window_rect();
  let r = geom::Rect::from_w_h(100.0, 100.0).top_left_of(win);

  draw
    .rect()
    .texture(&model.texture)
    .xy(r.xy())
    .wh(r.wh());
}
