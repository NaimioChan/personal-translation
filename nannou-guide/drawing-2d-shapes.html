绘制二维图形

教程信息

  • 作者：Seth Boyles
  • 前置知识：
    • 入门
    • 绘制草图
  • 阅读时间：20 分钟

在本教程中，我们将探索如何用 nannou 绘制二维图形。我们会介绍如何绘制基本线条、简单多边形（如椭圆、矩形等），以及更复杂的、你可以随心所欲创建任意形状的多边形！

首先，我们需要一个 nannou 项目文件来动手操作。把下面的内容复制到新文件中：

use nannou::prelude::*;

fn main() {
    nannou::sketch(view).run();
}

fn view(app: &App) {
    // 准备绘制。
    let draw = app.draw();

    // 把背景清成紫色。
    draw.background().color(PLUM);

    // 用默认的大小和位置绘制一个蓝色椭圆。
    draw.ellipse().color(STEEL_BLUE);

    
}

你也可以在 nannou 源码仓库的 examples 目录中找到这个文件以及其他有用的示例。

绘制简单图形

我们试着运行这个文件！（如果你还没做的话，需要把这个文件添加到你的 Cargo.toml 文件中）

你应该会看到一个新窗口，里面的内容看起来像这样：

我们已经在向画布渲染一个圆形了。你可能已经猜到，负责创建圆形的那行代码是对 `ellipse` 函数的调用：

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
draw.ellipse()
    .color(STEEL_BLUE);
# }

这里有很多方法可以改变我们的圆形。先从改变大小开始：

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
draw.ellipse()
    .color(STEEL_BLUE)
    .w(300.0)
    .h(200.0);
# }

这里的 `w` 函数把椭圆的宽度改为 300 像素，`h` 函数把高度改为 200.0 像素。你应该会看到一个我们通常口语所说的椭圆。

我们还可以用 `x_y` 方法改变椭圆的位置：

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
draw.ellipse()
    .color(STEEL_BLUE)
    .w(300.0)
    .h(200.0)
    .x_y(200.0, -100.0);
# }

如你所见，我们通过把不同的方法串联在一起来编辑椭圆，每个方法会改变形状的一个或多个属性。这被称为 Builder 模式。对 `draw.ellipse()` 的调用会返回一个 `Drawing<Ellipse>` 类型的对象。相应地，每次调用构建器方法（如 `w(300.0)` 或 `x_y(200.0, -100.0)`）都会返回我们形状的同一个实例。通过把这些函数调用串联起来，我们就能构建出带有自己想要属性的椭圆。

还有几个方法可以用来构建椭圆。你可以在这里查看其中许多方法的文档。

绘制矩形与四边形

绘制正方形或矩形使用的是与绘制椭圆相同的构建器模式。事实上它们足够相似，你只需把上面示例中的 `ellipse` 换成 `rect`，就能得到一个可以运行的示例：

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
draw.rect()
    .color(STEEL_BLUE)
    .w(300.0)
    .h(200.0);
# }

你会看到这样的图像：

除了 `rect` 之外，你还可以使用 `quad` 方法，它用于绘制四边形。这个函数与 `rect` 类似，但你还可以选择为形状提供自己的坐标。试试下面的代码：

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
let point1 = pt2(-10.0, -20.0);
let point2 = pt2(10.0, -30.0);
let point3 = pt2(15.0, 40.0);
let point4 = pt2(-20.0, 35.0);

draw.quad()
    .color(STEEL_BLUE)
    .w(300.0)
    .h(200.0)
    .points(point1, point2, point3, point4);
# }

你应该会看到如下结果：

上面的 `pt2` 方法会创建一个点对象，表示 XY 坐标空间中的一个点，就像图表或笛卡尔坐标系一样。nannou 的坐标系把 (0,0) 放在窗口的中心。这与许多其他图形创意编程框架不同，它们把 (0,0) 放在窗口的左上角位置。

注意，不同形状的 `Drawing` 构建器对象虽然共享许多相同的构建器方法，但并不共享全部方法。例如，在 `Drawing<Ellipse>` 的实例上尝试使用 `points` 方法会引发错误。

绘制三角形

此外，还有一个简单的形状方法：`tri`，用于绘制三角形。它的行为与 `quad` 类似，你可以提供自己的坐标来决定形状的样子。试试看吧！

绘制线条

`line` 函数提供了一种绘制线条的简单方法：

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
let start_point = pt2(-30.0, -20.0);
let end_point   = pt2(40.0, 40.0);

draw.line()
    .start(start_point)
    .end(end_point)
    .weight(4.0)
    .color(STEEL_BLUE);
# }

只需提供起点和终点，你就得到了一条线。

这对更简单的图形来说很棒，但如果你想画更复杂的东西呢？比如一条正弦波。

要画正弦波，我们会使用 `polyline` 函数。要使用这个函数，我们需要提供一个点的集合（或数组），这些点代表正弦波上的点。我们可以用——还能是什么呢——`sin` 函数来生成这个点数组！

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
let points = (0..50).map(|i| {
  let x = i as f32 - 25.0;          //减去 25 以便把正弦波居中
  let point = pt2(x, x.sin()) * 20.0; //把正弦波缩放 20.0
  (point, STEEL_BLUE)
});
draw.polyline()
    .weight(3.0)
    .points_colored(points);
# }

如你所见，`polyline` 的强大之处在于能够绘制一系列连接有序点数组的线条。有了它，只要能提供或生成表示该形状所需的点，你就可以轻松绘制各种形状或线条。

例如，一个圆形：

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
// 存储我们想画的圆的半径。
let radius = 150.0;
// 映射 0 到 360 的整数数组，用它们表示圆的度数。
let points = (0..=360).map(|i| {
    // 把每个度数转换为弧度。
    let radian = deg_to_rad(i as f32);
    // 对弧度取正弦，求出圆上该点的 x 坐标，
    // 再乘以半径。
    let x = radian.sin() * radius;
    // 对余弦做同样的事，求出 y 坐标。
    let y = radian.cos() * radius;
    // 构造并返回一个带颜色的点对象。
    (pt2(x,y), STEEL_BLUE)
});
// 创建一个折线构建器。小提示：polyline 是一种路径的简写，这种路径
// 通过“描边”细分而不是“填充”细分来绘制。
draw.polyline()
    .weight(3.0)
    .points_colored(points); // 提交我们的点。
# }

一个自定义绘制的圆形！……好吧，也许这并不怎么令人兴奋，毕竟我们已经有一个用 `ellipse` 画圆的简便方法了。但只要对上面的代码做一个简单改动，我们就能生成不同形状的轮廓。让我们试试 `step_by` 函数，它允许我们选择遍历某个范围或其他迭代器时的步进间隔。所以，我们不再调用 `(0..=360).map`，而是调用 `(0..=360).step_by(45).map`：

# #![allow(unused_variables)]
# fn main() {
let points = (0..=360).step_by(45).map(|i| {
#     0.0
# });
# }

其余的代码保持不变。

由于 45 能整除 360 八次，我们的代码生成了 8 个点来表示一个正八边形。

一个八边形！

试着用不同的值传入 `step_by` 做实验，看看你能创造出哪些不同的形状！

顺带一提，你可能已经注意到这次我们没有用 `color` 函数来设置绘制的颜色。取而代之的是，`polyline` 允许给每个点单独着色。这意味着你可以逐点改变折线的颜色。试着动手实验吧！

绘制自定义多边形

要绘制一个自定义的填充多边形（而不只是轮廓），我们会用到与自定义圆形或八边形代码非常相似的代码。主要区别在于，我们不再调用 `polyline` 来创建构建器，而是调用 `polygon`：

# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
let radius = 150.0;
let points = (0..=360).step_by(45).map(|i| {
    let radian = deg_to_rad(i as f32);
    let x = radian.sin() * radius;
    let y = radian.cos() * radius;
    (pt2(x,y), STEEL_BLUE)
});
draw.polygon()
    .points_colored(points);
# }
