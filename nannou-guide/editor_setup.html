编辑器设置

虽然大多数主流开发环境都支持 Rust，但自动补全、跳转到定义等某些特性的支持程度在不同环境之间参差不齐。

VS Code

对于 Rust 新用户，我们推荐使用 VS-Code 作为 Nannou 开发的编辑器和 IDE。目前它对 Rust 语言的支持似乎是最好的，包括语法高亮、自动补全、代码格式化等功能。它还自带集成的 unix 终端和文件导航系统。以下是我们推荐的、使用 VS-Code 进行 Nannou 开发的入门步骤。

  1. 为你的操作系统下载 VS-Code。
  2. 为 VS-Code 安装 rust-analyzer 插件。
  3. 点击 'view' 菜单并选择 'terminal'。
