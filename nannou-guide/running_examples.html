运行示例

熟悉 nannou 最简单的方式是浏览示例。

Nannou 提供了三组示例：

路径描述
examples/一组示例，按类别展示 nannou 的各种用法。
generative_design/来自 Generative Gestaltung 的示例，从 p5.js 移植到 nannou。
nature_of_code/来自 Nature of Code 的示例，从 Processing 移植到 nannou。

要获取这些示例，我们可以克隆 nannou 仓库。

git clone https://github.com/nannou-org/nannou

如果你没有安装 git，可以点击本页顶部的 "Clone or download" 按钮，然后点击 "Download .zip"。

现在，把当前目录切换到 nannou。

cd nannou

用 cargo 运行示例！

cargo run --release --example draw

--release 标志表示我们要在启用优化的情况下构建。

通过 --example 标志传入的值，要与包的 Cargo.toml 文件中 [[examples]] 表内某个条目的 name 属性相匹配。匹配到的条目的 path 属性指向要构建的源文件：

# Draw
[[example]]
name = "draw"
path = "draw/draw.rs"

如果我们翻看 nature of code 目录，决定要运行下面这个示例：

# Chapter 1 Vectors
[[example]]
name = "1_1_bouncingball_novectors"
path = "chp_01_vectors/1_1_bouncingball_novectors.rs"

我们可以这样运行：

cargo run --release --example 1_1_bouncingball_novectors

一般来说，示例的名称几乎总是去掉 .rs 扩展名后的文件名。

如果你是第一次编译 nannou，你会看到 cargo 下载并构建所有必要的依赖。这可能需要一段时间！幸运的是，我们只需要等这一次。

示例编译完成后，你应该会看到如下窗口出现。

要运行任何其他示例，把 draw 替换为所需示例的名称即可。
