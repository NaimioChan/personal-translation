社区教程

这里是社区编写的教程合集。

  • "Schotter Four Ways"。Rick Sidwell 编写的一份全面的生成艺术教程，介绍了 Rust 工作区、草图与应用的区别、多窗口、图像捕获、键盘输入和用户界面。
  • "Creative Coding in Rust with Nannou"。Ben Lovy 编写的 Rust/Nannou 教程，详细介绍了创意编程的地道 Rust 方法。它先搭建了一个适用于一般项目的通用框架，然后用它来编写一个简单的演示应用。
