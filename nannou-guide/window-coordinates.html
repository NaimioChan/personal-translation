基础 - 窗口坐标

教程信息

  • 作者：mitchmindtree
  • 预备知识：

  • 阅读时间：15 分钟

坐标可以用来描述空间中的位置。在我们开始在窗口中的特定位置绘制事物，或者让它们沿特定方向移动之前，理解我们所使用的坐标系会非常有用。

不同种类的坐标系适用于不同的目的。让我们来看看 nannou 的窗口坐标。

这是 window_coordinates.rs 示例的截图。该示例旨在帮助建立对 nannou 窗口坐标工作方式的直觉。在这里，我们看到的是一个尺寸为 600x400 的窗口。我们可以看到：

  • x 和 y 值在窗口中心为 [0.0, 0.0]。这被称为原点。
  • x 值向右增大、向左减小。
  • y 值向上增大、向下减小。
  • 从左边缘到右边缘的距离是 600，等于窗口宽度。
  • 从下边缘到上边缘的距离是 400，等于窗口高度。
  • 从中心到左或右边缘的距离是 300，即窗口宽度的一半。
  • 从中心到上或下边缘的距离是 200，即窗口高度的一半。

换句话说，nannou 使用笛卡尔坐标系来描述窗口空间，其中原点在中心，y 向上增大，窗口边缘之间的距离等于窗口的尺寸。

在窗口坐标中绘制

原点位于中心这一特点贯穿到我们用 nannou 的 draw API 绘制图形的方式中。如果我们把示例改成在 [0.0, 0.0] 处绘制一个李子色、尺寸为 100.0 的方形，看看会发生什么。

# #![allow(unreachable_code, unused_variables)] # use nannou::prelude::*; # fn main() { # let draw: Draw = unimplemented!(); draw.rect() .x_y(0.0, 0.0) .w_h(100.0, 100.0) .color(PLUM); # } 
# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
draw.rect()
    .x_y(0.0, 0.0)
    .w_h(100.0, 100.0)
    .color(PLUM);
# }

注意当我们说 .x_y(0.0, 0.0) 时，这指的是方形中心将被放置的位置。你可能注意到同样的情况也适用于椭圆和文本等其他绘制图元。

旋转方形

通过中心描述位置的这一特性让我们能轻松执行各种对称操作。旋转就是一个很好的例子。让我们试着把李子色方形旋转 45 度。

# #![allow(unreachable_code, unused_variables)] # use nannou::prelude::*; # fn main() { # let draw: Draw = unimplemented!(); draw.rect() .x_y(0.0, 0.0) .w_h(100.0, 100.0) .z_degrees(45.0) .color(PLUM); # } 
# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
draw.rect()
    .x_y(0.0, 0.0)
    .w_h(100.0, 100.0)
    .z_degrees(45.0)
    .color(PLUM);
# }

瞧！

移动方形

好，现在我们去掉旋转，试着把方形定位成让左下角碰到原点、右上角碰到 [100.0, 100.0] 标记。

为此，我们要把方形移动到原点和标记的中间位置，也就是 [50.0, 50.0]。

# #![allow(unreachable_code, unused_variables)] # use nannou::prelude::*; # fn main() { # let draw: Draw = unimplemented!(); draw.rect() .x_y(50.0, 50.0) .w_h(100.0, 100.0) .color(PLUM); # } 
# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
draw.rect()
    .x_y(50.0, 50.0)
    .w_h(100.0, 100.0)
    .color(PLUM);
# }

太治愈了！

好，但如果我们想把方形放在窗口的左上角怎么办？

一种做法是手动计算位置。例如，我们知道左上角等于 \[-300, 200\]。从那里开始，我们需要把方形向右移动半个宽度、向下移动半个高度：

# #![allow(unreachable_code, unused_variables)] # use nannou::prelude::*; # fn main() { # let draw: Draw = unimplemented!(); let side = 100.0; let top_left = pt2(-300.0, 200.0); let offset = vec2(side / 2.0, -side / 2.0); let xy = top_left + offset; draw.rect() .xy(xy) .w_h(side, side) .color(PLUM); # } 
# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
let side = 100.0;
let top_left = pt2(-300.0, 200.0);
let offset = vec2(side / 2.0, -side / 2.0);
let xy = top_left + offset;
draw.rect()
    .xy(xy)
    .w_h(side, side)
    .color(PLUM);
# }

好，这行得通！但费了很大力气。而且如果窗口尺寸变了怎么办？

Rect 来了。

用 Rect 定位

在窗口坐标中工作时最有用的工具之一是Rect 类型。顾名思义，Rect 让我们能以各种有用的方式处理矩形。我们可以对它们进行对齐、内边距、位移、拉伸、细分，检查它们是否包含某个点，等等。

Rect 最有用的应用之一是描述窗口的边界。让我们取名为 win 的窗口 Rect。

# #![allow(unreachable_code, unused_variables)] # use nannou::prelude::*; # fn main() { # let app: App = unimplemented!(); let win = app.window_rect(); # } 
# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let app: App = unimplemented!();
let win = app.window_rect();
# }

让我们用 win 来简化把李子色方形对齐到窗口左上的操作。

对齐

首先，让我们做一个表示李子色方形位置和尺寸的 Rect，命名为 r。

# #![allow(unused_variables)] # use nannou::prelude::*; # fn main() { let r = geom::Rect::from_w_h(100.0, 100.0); # } 
# #![allow(unused_variables)]
# use nannou::prelude::*;
# fn main() {
let r = geom::Rect::from_w_h(100.0, 100.0);
# }

r 现在表示我们的方形，位于 \[0.0, 0.0\]，宽度和高度均为 100.0。我们可以把方形绘制代码改为像这样使用 r 来确认这一点：

# #![allow(unreachable_code, unused_variables)] # use nannou::prelude::*; # fn main() { # let draw: Draw = unimplemented!(); let r = geom::Rect::from_w_h(100.0f32, 100.0f32); draw.rect() .xy(r.xy()) .wh(r.wh()) .color(PLUM); # } 
# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
let r = geom::Rect::from_w_h(100.0f32, 100.0f32);
draw.rect()
    .xy(r.xy())
    .wh(r.wh())
    .color(PLUM);
# }

我们可以像这样把李子色方形对齐到窗口的 top_left_of：

# #![allow(unreachable_code, unused_variables)] # use nannou::prelude::*; # fn main() { # let draw: Draw = unimplemented!(); # let win: geom::Rect = unimplemented!(); let r = geom::Rect::from_w_h(100.0, 100.0).top_left_of(win); draw.rect() .xy(r.xy()) .wh(r.wh()) .color(PLUM); # } 
# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
#     let win: geom::Rect = unimplemented!();
let r = geom::Rect::from_w_h(100.0, 100.0).top_left_of(win);
draw.rect()
    .xy(r.xy())
    .wh(r.wh())
    .color(PLUM);
# }

好多了！

但如果我们想在窗口边缘和方形之间留些内边距怎么办？

让我们来看看！

内边距

我们可以用内边距在某个区域的边缘与其内部内容之间加一些空间。在 nannou 中，我们可以用 pad 方法产生一个带内边距的 Rect 实例。

让我们试着把窗口 rect 加上 25.0 的内边距，并用半透明的蓝色把它画出来：

# #![allow(unreachable_code, unused_variables)] # use nannou::prelude::*; # fn main() { # let draw: Draw = unimplemented!(); # let win: geom::Rect = unimplemented!(); let win_p = win.pad(25.0); draw.rect() .xy(win_p.xy()) .wh(win_p.wh()) .color(Color::srgba(0.3, 0.4, 0.7, 0.5)); # } 
# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
#     let win: geom::Rect = unimplemented!();
let win_p = win.pad(25.0);
draw.rect()
    .xy(win_p.xy())
    .wh(win_p.wh())
    .color(Color::srgba(0.3, 0.4, 0.7, 0.5));
# }

你可能已经猜到了，我们可以用这个新的带内边距的 Rect 来对齐李子色方形，达到想要的效果：

# #![allow(unreachable_code, unused_variables)] # use nannou::prelude::*; # fn main() { # let draw: Draw = unimplemented!(); # let win: geom::Rect = unimplemented!(); let win_p = win.pad(25.0); let r = geom::Rect::from_w_h(100.0, 100.0).top_left_of(win_p); draw.rect() .xy(r.xy()) .wh(r.wh()) .color(PLUM); # } 
# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
#     let win: geom::Rect = unimplemented!();
let win_p = win.pad(25.0);
let r = geom::Rect::from_w_h(100.0, 100.0).top_left_of(win_p);
draw.rect()
    .xy(r.xy())
    .wh(r.wh())
    .color(PLUM);
# }

相对位置

现在我们的李子色方形在左上角安顿好并带上了漂亮的内边距，让我们试着在它正下方画一个同样大小的鲑鱼粉色圆形。

我们好用的 Rect 类型提供了把位置放在另一个 Rect 的 below（下方）、above（上方）、left_of（左侧）和 right_of（右侧）的方法。让我们在方形 Rect 的一个副本上使用 below 方法，这样就可以用得到的 Rect 来画我们的圆形：

# #![allow(unreachable_code, unused_variables)] # use nannou::prelude::*; # fn main() { # let draw: Draw = unimplemented!(); # let win: geom::Rect = unimplemented!(); let win_p = win.pad(25.0); let square = geom::Rect::from_w_h(100.0, 100.0).top_left_of(win_p); draw.rect() .xy(square.xy()) .wh(square.wh()) .color(PLUM); let circle = square.below(square); draw.ellipse() .xy(circle.xy()) .wh(circle.wh()) .color(SALMON); # } 
# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
#     let win: geom::Rect = unimplemented!();
let win_p = win.pad(25.0);
let square = geom::Rect::from_w_h(100.0, 100.0).top_left_of(win_p);
draw.rect()
    .xy(square.xy())
    .wh(square.wh())
    .color(PLUM);

let circle = square.below(square);
draw.ellipse()
    .xy(circle.xy())
    .wh(circle.wh())
    .color(SALMON);
# }

为保持一致，让我们试着在圆形与方形之间加上与方形和窗口边缘之间相同的内边距。

我们可以用 shift 方法把圆形从方形处“移”下来：

# #![allow(unreachable_code, unused_variables)] # use nannou::prelude::*; # fn main() { # let draw: Draw = unimplemented!(); # let win: geom::Rect = unimplemented!(); let pad = 25.0; let win_p = win.pad(pad); let square = geom::Rect::from_w_h(100.0, 100.0).top_left_of(win_p); draw.rect() .xy(square.xy()) .wh(square.wh()) .color(PLUM); let circle = square.below(square).shift_y(-pad); draw.ellipse() .xy(circle.xy()) .wh(circle.wh()) .color(SALMON); # } 
# #![allow(unreachable_code, unused_variables)]
# use nannou::prelude::*;
# fn main() {
#     let draw: Draw = unimplemented!();
#     let win: geom::Rect = unimplemented!();
let pad = 25.0;
let win_p = win.pad(pad);
let square = geom::Rect::from_w_h(100.0, 100.0).top_left_of(win_p);
draw.rect()
    .xy(square.xy())
    .wh(square.wh())
    .color(PLUM);

let circle = square.below(square).shift_y(-pad);
draw.ellipse()
    .xy(circle.xy())
    .wh(circle.wh())
    .color(SALMON);
# }

在结束本教程之前，让我们快速看看这些数字到底意味着什么。

点与像素

600x400 到底量的是什么？毫米？像素？还是别的什么？

在 nannou 中，我们通常用点来描述窗口空间内的位置。点与像素非常相似，只不过点让我们无需操心显示设备的“缩放因子”就能工作。

等等，什么是“缩放因子”？

缩放因子帮助我们推理显示设备上像素的密度。现代显示设备的分辨率与尺寸之间并没有一致的关系。例如，现代手机的分辨率可以高达 1440p，比普通的 1080p 桌面显示器还高，而屏幕尺寸却只有其一小部分！

因此，大多数设备会暴露一个缩放因子。这个值描述了为在不同设备间获得一致用户体验而应应用的推荐 UI 缩放。在 nannou 中，我们把这个缩放后的空间称为点（又叫逻辑像素），把物理像素空间称为像素。通过在点中工作，我们可以让 nannou 替我们处理缩放。

你可以在此处进一步了解 nannou 的窗口库中窗口缩放的工作方式。

要把点转换为像素，我们可以乘以缩放因子：

> # #![allow(unreachable_code, unused_variables)] > # use nannou::prelude::*; > # fn main() { > # let points = 100.0; > # let window: Window = unimplemented!(); > let pixels = points * window.scale_factor(); > # } >

类似地，我们可以通过除以缩放因子把像素转换为点：

> # #![allow(unreachable_code, unused_variables)] > # use nannou::prelude::*; > # fn main() { > # let pixels = 100.0; > # let window: Window = unimplemented!(); > let points = pixels / window.scale_factor(); > # } >
