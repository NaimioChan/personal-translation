安装 Rust

Nannou 是为 Rust 编程语言编写的一个库。因此，第一步是安装 Rust！

要在 Windows 上安装 Rust，请从此处下载并运行安装程序。如果你使用的是 macOS 或 Linux，请打开终端，复制下面的文本，粘贴到终端中并按回车键。

curl https://sh.rustup.rs -sSf | sh

现在 Rust 已经安装好了！

接下来我们将安装一些工具，帮助 IDE 实现自动补全、跳转到定义等好用的功能。

rustup component add rust-src rustfmt-preview rust-analysis

如果你想了解更多关于 Rust 安装过程的信息，请参阅此链接。
