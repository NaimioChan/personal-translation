平台相关设置

在开始之前，先确认我们已经具备安装 Rust 和构建 nannou 项目所需的一切条件。

根据你运行的操作系统不同，你可能还需要一两个额外步骤。

顺便说一句，如果你发现本节指南中缺少某些步骤，欢迎到 nannou 指南仓库提 issue 或 PR！

macOS

确保你已安装 xcode-tools：

xcode-select --install

有些示例还要求安装 cmake。最简单的方法是使用 Homebrew。

brew install cmake

这样应该就具备了构建 nannou 所需的全部开发工具。

Windows

Rust 需要 Visual Studio 的 C++ 构建工具。Rust 之书是这样说的：

在 Windows 上，前往 https://www.rust-lang.org/tools/install 并按照说明安装 Rust。在安装过程中的某个时刻，你会收到一条消息，说明你还需要 Visual Studio 2013 或更高版本的 C++ 构建工具。获取构建工具最简单的方法是安装 Build Tools for Visual Studio 2019。这些工具位于 Other Tools and Frameworks 部分。

Linux

确保安装了以下系统包：

  • 基本开发包

    首先确保基本开发包已安装。

    • rustup（Rust 工具链管理器）需要 curl。
    • build-essential 会被 rustc（Rust 编译器）用于链接。
    • pkg-config 被一些构建脚本用来获取某些库的信息。
    • nannou_audio 需要 alsa 开发包。

Debian/Ubuntu 用户：

sudo apt-get install curl build-essential python cmake pkg-config

  • alsa 开发包

    Fedora 用户：

    sudo dnf install alsa-lib-devel

    Debian/Ubuntu 用户：

    sudo apt-get install libasound2-dev

    Arch 用户：

    sudo pacman -S alsa-lib

  • xcb

    XCB 库提供了与 Xlib 的互操作性。

    Debian/Ubuntu 用户：

    sudo apt install libxcb-shape0-dev libxcb-xfixes0-dev

    你可能还需要 python3 来运行 xcb crate 的构建脚本。

  • vulkan

    在 Linux 上安装 Vulkan 支持通常非常简单，用你的发行版的包管理器即可。话虽如此，根据你的显卡和对专有软件的接受程度，可能有不同的驱动方案需要考虑。以下是如何快速上手的大致指南；不过，如果你特别在意找到最适合自己的方案，我们建议在你的发行版上搜索适用于你显卡的 vulkan 驱动安装方法。

    使用 AMD 显卡的 Fedora：

    sudo dnf install vulkan vulkan-info

    使用 NVIDIA 显卡的 Fedora： 添加专有驱动

    sudo dnf install https://download1.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm https://download1.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm

    然后运行

    sudo dnf install xorg-x11-drv-nvidia akmod-nvidia vulkan-tools

    使用 AMD 或 Intel 显卡的 Debian：

    sudo apt-get install libvulkan1 mesa-vulkan-drivers vulkan-utils

    使用 NVIDIA 显卡的 Debian：

    sudo apt-get install vulkan-tools

    或者，在较旧的版本上（Buster 之前，即 < 10）：

    sudo apt-get install vulkan-utils

    使用 AMD 或 Intel 显卡的 Ubuntu 用户： 为最新驱动添加一个 PPA

    sudo add-apt-repository ppa:oibaf/graphics-drivers
sudo apt-get update
sudo apt-get upgrade

    然后运行

    sudo apt-get install libvulkan1 mesa-vulkan-drivers vulkan-utils

    使用 NVIDIA 显卡的 Ubuntu 用户： 为最新驱动添加一个 PPA

    sudo add-apt-repository ppa:graphics-drivers/ppa
sudo apt-get update
sudo apt-get upgrade

    然后运行

    sudo apt-get install nvidia-graphics-drivers-396 nvidia-settings vulkan vulkan-utils

    使用 AMD 显卡的 Arch：

    sudo pacman -S vulkan-radeon lib32-vulkan-radeon

    使用 Intel 显卡的 Arch：

    sudo pacman -S vulkan-intel

    使用 NVIDIA 显卡的 Arch：

    sudo pacman -S nvidia lib32-nvidia-utils

    Gentoo 运行：

    sudo emerge --ask --verbose dev-util/vulkan-tools dev-util/vulkan-headers

好了，现在我们应该准备好安装 Rust 了！
