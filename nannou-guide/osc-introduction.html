什么是 OSC？

Open Sound Control，即 OSC，是一种在不同软件和/或计算机之间通信的协议。它基于网络技术，提供了一种灵活的方式，在进程之间以高精度共享控制数据，无论是在本机内部还是通过网络连接。

在 nannou 中既可以发送也可以接收 OSC 数据，让你能够控制其他软件，或者让 nannou 被其他软件控制。

设置 OSC

要在 nannou 中使用 OSC，需要在你的 nannou 项目中把 nannou_osc crate 添加为依赖。

打开 nannou 项目根目录下的 Cargo.toml 文件，在 [dependencies] 标签下添加下面这一行：

nannou_osc = "0.19.0"

引号中的值是 OSC 包的版本。在撰写本文时，"0.19.0" 是最新版本。

要获取 osc 库的最新版本，请在命令行执行 cargo search nannou_osc，并从结果中读取版本号。

要在你的 nannou 项目中使用这个 crate，可以在 main.rs 文件顶部添加一条 use 语句来导入 OSC 功能。

# #![allow(unused_imports)]
use nannou_osc as osc;
# fn main() {}
