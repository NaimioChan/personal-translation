创建项目

无论我们要创作一件艺术作品、一个应用、一张快速草图还是一件装置作品，我们都要从创建一个新项目开始。一个新的 nannou 项目让我们可以按我们想要的方式来构建 nannou 应用。

从长远来看，Nannou 的目标是提供一个项目生成器工具，只需几次点击就能完成以下操作以及更多功能。目前，我们只需几个简单步骤就能创建一个新项目：

  1. 用我们项目的名称创建 Rust 项目：

    cargo new my-project

  1. 切换到生成的项目目录。

    cd my-project

  1. 编辑 Cargo.toml 文件，在末尾添加最新版本的 nannou，如下所示：

    [package]
name = "my_project"
version = "0.1.0"
authors = ["mitchmindtree "]
edition = "2024"

[dependencies]
nannou = "0.20"

    请注意，上面的 nannou 版本有可能已经过时。你可以在终端中输入 cargo search nannou 来查看最新版本。也别忘了把作者改成你自己的名字！

  1. 用以下代码替换 src/main.rs 中的代码，来搭建我们的 nannou 应用。

    # extern crate nannou;
use nannou::prelude::*;

fn main() {
    nannou::app(model)
        .update(update)
        .simple_window(view)
        .run();
}

struct Model {}

fn model(_app: &App) -> Model {
    Model {}
}

fn update(_app: &App, _model: &mut Model) {
}

fn view(app: &App, _model: &Model, _window: Entity) {
    let draw = app.draw();
    draw.background().color(PURPLE);
}

    如果你是 Rust 新手，或者暂时还看不懂上面的代码，别担心！在下一章的第一个教程中，我们将一步步拆解这段代码。

  1. 触发首次构建，并通过运行我们的应用来检查一切是否正常！

    cargo run --release

    第一次构建可能需要一段时间，因为我们必须从头构建 nannou 及其所有依赖。之后再运行我们的应用就会快得多！

    项目构建完成后就会开始运行，我们应该能看到一个紫色的窗口。

大功告成！如果一切顺利，你现在就可以开始构建自己的 nannou 项目了。当然，我们多半不会只想要一个紫色窗口。
