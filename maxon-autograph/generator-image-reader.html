图像/视频读取器

简要说明

与项目面板中的媒体读取器类似，区别在于你不需要先导入文件。当你把绑定到表格与设置在文件参数上的列出目录生成器一起使用时，这可以用来从某个目录动态加载图像。

Enable Disk Caching / enableCaching 布尔 开 勾选后，媒体帧会被缓存在媒体缓存中，以便后续请求更快访问。如果在图层上使用这些媒体，修改项目时这通常非常有用。如果只是播放或渲染很长的序列，这个设置可能没什么用，因为它会缓存那些最终因大小限制而被移出缓存的帧。在这些情况下，取消勾选反而能提升性能。

Proxy File / proxyFile 文件 代理文件是一段独立的视频/图像序列，可以替代主视频被读取，通常用于提供较低的分辨率以加速项目。代理文件会依据代理模式参数来使用。为获得最佳效果，代理图像的宽高比和元数据（通道等）应与原始文件相同
Proxy Mode / proxyMode 选项 大于或等于 在已指定代理的情况下何时使用代理文件
- 始终：只要有效就始终使用代理文件
- 从不：从不使用代理文件
- 大于或等于：仅当渲染所请求的缩放不涉及放大代理时才使用代理文件
- 最近：使用相对于所请求的缩放而言缩放程度较小的那个文件（无论是放大还是缩小）
File Alpha Premult / filePremult 选项 自动 控制用于解读文件的 Alpha 预乘元数据。有些软件会标示误导性的数值，可能导致对素材的错误解读。这个参数可以强制采用不同的解读方式。
- 自动：Alpha 预乘元数据采用文件中标示的数值
- 不透明：强制解码器假定文件中包含不透明像素
- 预乘：强制解码器假定文件中包含 Alpha 预乘像素
- 反预乘：强制解码器假定文件中包含非 Alpha 预乘像素（有时称为直通）
Background Color / bgColor 颜色 0, 0, 0, 0 如果图像文件中包含与一个非黑色背景混合的 Alpha 预乘前景，你可以在此指定该背景的颜色来移除它。这在某些情况下很有用，例如某些第三方软件导出的、文件格式不是 png 的错误文件。背景颜色按以下公式移除：output.rgb = src.rgb - background_color.rgb * (1.0 - src.a)

Enable Cryptomatte / enableCryptomatte 布尔 关 启用后，输出的图像是依据下面选项提取出的蒙版。禁用时，由输出部分参数控制从 OpenEXR 文件中输出什么
Matte List / cryptoMatteList -
Layer Source / cryptoLayer 选项 -
Output Mode / cryptoOutputMode 选项 彩色预览上叠加蒙版 选择 Cryptomatte 输出的内容
- 选中的蒙版：RGBA 通道被填充为所选蒙版
- 彩色预览：每个独立的蒙版都以不同颜色显示在图像的红/绿/蓝通道中。这个模式有助于挑选蒙版并把它们加入蒙版列表
- 彩色预览上叠加蒙版：与彩色预览模式相同，但所选蒙版会被加到红色通道上
Expand Wildcards / cryptoExpandWildcards 布尔 关 启用后，蒙版名称可以包含通配符表达式。'*' 字符用于匹配零个或多个任意字符。'?' 匹配任意单个字符。'' 字符可用于转义通配符，以防对象名称包含这些字符
Separate Fields / fieldOrder 选项 关 对于隔行扫描视频，确定哪一场是主导场。要确定哪一场是主导场，可以在时间轴中拖拽素材经过一个有可见运动的镜头。如果运动看起来来回跳动，那是因为选错了主导场。
- 关：假定视频为逐行扫描
- 上场优先：假定视频为上场优先。通常是 HD 或 D1 PAL
- 下场优先：假定视频为下场优先。通常是 DV（PAL 或 NTSC）或 D1 NTSC（但不总是）
Algorithm / deinterlaceMode 选项 复制（Bob） - 复制（Bob）：把每个半幅图像当作完整图像来显示，做法是把每一行都显示两次。
- 时域与空域：一种时域与空域插值器，利用相邻帧和邻近的图像行来重建缺失的行
Override FPS / fpsOverride 浮点 1 设置读取图像序列所使用的帧率
Reformat / reformatMode 选项 无 控制图像的格式
- 无：不修改图像格式
- 自定义：把图像重设为指定的尺寸和像素宽高比
- 预设：把图像重设为指定的格式预设
