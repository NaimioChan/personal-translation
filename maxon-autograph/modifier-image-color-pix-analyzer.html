像素分析器

简要说明

分析图像中的像素，并计算整张图像或用户自定义区域上的最小值、最大值和平均强度等统计数据。统计数据按图像通道计算，并作为关键帧记录在 RGBA、HSVL 和明度子组的参数上。这有助于进一步编辑这些关键帧，或把参数链接到其他参数。

勾选“自动分析”后，统计数据会在播放或拖动时间轴时自动计算。在此模式下，如果勾选了“覆盖关键帧”，Autograph 会始终重新计算关键帧；如果未勾选，则只计算缺失的关键帧。

未勾选“自动分析”时，必须点击“分析帧”或“分析图层范围”按钮来手动启动分析。

分析区域可以手动编辑：选中该行，然后在查看器中编辑矩形。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Analysis Region Mode / roiMode 选项 整个图像 用于跟踪像素的区域。选择分析区域并定义更小的矩形可能会提升性能
- 分析区域
- 整个图像
Analysis Region / analysisRegion -500, -500, 500, 500
Enable RGBA Stats / enableRGB 布尔 开 勾选后，分析时会计算 RGBA 统计值
RGBA / rgbaStats 类别 -
RGBA Min / rgbaMin 颜色 0, 0, 0, 0 最小值
RGBA Max / rgbaMax 颜色 0, 0, 0, 0 最大值
RGBA Mean / rgbaMean 颜色 0, 0, 0, 0 平均值
Enable RGBA Advanced Stats / rgbaEnableExtra 布尔 关 勾选后，还会分析标准差、峰度和偏度
RGBA S.dev. / rgbaSdev 颜色 0, 0, 0, 0 标准差：量化数据的离散程度
RGBA Kurtosis / rgbaKurtosis 颜色 0, 0, 0, 0 数据分布的形状是否与高斯分布相符：数值为 0 表示它是高斯分布。平坦分布的峰度为负值，而尖峰分布的峰度为正值
RGBA Skewness / rgbaSkewness 颜色 0, 0, 0, 0 分布有多对称：数值为 0 表示分布对称，向左拖尾的非对称分布为负偏度，而向右拖尾的分布为正偏度
Enable HSVL Stats / enableHSV 布尔 关 勾选后，分析时会计算 HSVL 统计值
HSVL / hsvlStats 类别 -
HSVL Min / hsvlMin 颜色 0, 0, 0, 0 最小值
HSVL Max / hsvlMax 颜色 0, 0, 0, 0 最大值
HSVL Mean / hsvlMean 颜色 0, 0, 0, 0 平均值
Enable HSVL Advanced Stats / hsvlEnableExtra 布尔 关 勾选后，还会分析标准差、峰度和偏度
HSVL S.dev. / hsvlSdev 颜色 0, 0, 0, 0 标准差：量化数据的离散程度
HSVL Kurtosis / hsvlKurtosis 颜色 0, 0, 0, 0 数据分布的形状是否与高斯分布相符：数值为 0 表示它是高斯分布。平坦分布的峰度为负值，而尖峰分布的峰度为正值
HSVL Skewness / hsvlSkewness 颜色 0, 0, 0, 0 分布有多对称：数值为 0 表示分布对称，向左拖尾的非对称分布为负偏度，而向右拖尾的分布为正偏度
Enable Luminance Stats / enableLuminance 布尔 关 勾选后，分析时会计算明度统计值
Luminance / lumaStats 类别 -
Luminance Mode / lumaFormula 选项 Rec. 709 模式不为无时使用的明度公式
- Rec. 709
- Rec. 2020
- ACES ap-0
- ACES ap-1
- CCIR 601
- 平均：各强度值的平均
- 最大值：各强度值的最大值
Min. Luminance Pixel / minLuminancePixelColor 浮点 0 明度最小的像素的 RGB 值
Min. Luminance Position / minLuminancePixelPos 浮点 2D 0, 0 明度最小的像素的位置
Max. Luminance Pixel / maxLuminancePixelColor 浮点 0 明度最大的像素的 RGB 值
Max. Luminance Position / minLuminancePixelPos 2 浮点 2D 0, 0 明度最大的像素的位置
Auto Analyze / enableAutoAnalysis 布尔 开 勾选后，在播放或拖动时间轴时会即时执行分析。未勾选时，必须用分析帧或分析图层范围按钮手动启动分析
Override Keyframes / autoAnalysisOverride 布尔 关 仅与自动分析相关：勾选后，分析会始终覆盖已有的关键帧；未勾选时，只计算尚不存在的关键帧
Analyze Frame / analyzeFrameButton 按钮 关
Analyze Layer Range / analyzeRangeButton 按钮 关
Light/Shadow Colorspace / input_colorspace 选项 项目显示空间 烘焙关键帧中像素颜色值所用的色彩空间
- 项目工作空间：假定颜色以项目工作空间表示
- 项目显示空间：假定颜色以项目显示空间表示
