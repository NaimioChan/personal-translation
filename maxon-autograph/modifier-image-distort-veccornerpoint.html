向量四角定位

简要说明

这个修改器与 UV 贴图生成器非常相似：它在内部借助运动向量通道分析生成 UV 贴图，并应用到源图像上。此外，这些向量还用于驱动 Corner Pin，因此当向量让源图像漂移过多时可以设置关键帧。运动向量影响参数可以控制运动向量相对于 Corner Pin 的权重，避免向量在局部漂移过多。

说明

向量四角定位修改器与 UV 贴图生成器非常相似，并且共用同一套工作流程。

为了让图像正确匹配移动，向量四角定位在查看器中直接提供一个 Corner Pin 控件，你可以在上面移动目标点。

每次移动目标点时，都会在时间轴上的用户目标点参数上创建一个关键帧。每个关键帧都充当 UV 贴图的一个新参考帧：在关键帧处，UV 贴图造成的变形会被直接透传，只把你调整的 Corner Pin 用作图像的变换。

每当添加或编辑关键帧时，你都需要重新跟踪前后两个关键帧之间的 UV 贴图。为此可以使用查看器上下文界面中的水平工具栏。

前 4 个按钮用于在不同帧范围上启动跟踪。接下来的 4 个按钮用于删除 Corner Pin 上的关键帧。运动向量和 UV 贴图菜单可用于删除磁盘上生成的文件。

如果菜单中未勾选覆盖文件，重新生成会保留所有已存在的文件，从而跳过计算。勾选它会强制重新生成运动向量/UV 贴图。

更改以下参数需要重新计算运动向量：

  • 帧间距
  • 运动估计参数
  • EXR 磁盘缓存路径
  • 文件名标识符
  • 跟踪区域模式或跟踪区域矩形
  • 运动源

更改以下参数需要重新计算 UV 贴图：

  • 任何影响运动向量的参数
  • 对 Corner Pin 所做的任何更改

设置新关键帧

当匹配移动开始漂移时，你可以通过在查看器中移动任意目标点来放置一个新关键帧。之后需要用查看器工具栏重新启动一次跟踪。请确认 UV 贴图设置中的覆盖文件已勾选。

平滑运动

你可能想降低运动向量造成的变形强度。为此可以使用以下参数：

  • 帧间距：提高它可以跨越更长的时间范围来计算向量，使运动更平滑。对于快速运动，这可能导致漂移

  • UV 贴图模糊：对贴图做轻微模糊以避免伪影。过高的模糊会让运动复杂的区域（例如人脸的嘴唇边缘）出现漂移

  • 运动向量影响：降低它会提高 Corner Pin 变换的权重，减少运动向量带来的可见变形。
