修剪路径

简要说明

从起点和/或终点修剪路径

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Start / start 浮点 0
End / end 浮点 1
Offset / offset 浮点 0
Display Mode / mode 选项 保留片段 - 保留片段
- 截断片段
Start/End Contours Mode / start_end_mode 选项 连接路径 - 连接路径
- 分离路径
Start/End Cycling Mode / start_end_cycling_mode 选项 循环 - 循环
- 交替
Accumulate Time Offset / accum_time_offset 布尔 关 勾选后，每条子路径在起点/终点/偏移参数上应用时间偏移的次数等于其实例序号 + 1
Time Offset / start_end_time_offset 时间 0 施加在起点/终点/偏移参数上的时间偏移。与累加时间偏移配合使用时很有用，能让每条子路径在时间上具有不同的修剪偏移
Accumulate Distribution / accum_time_offset_index_mode 选项 正向 迭代子路径以累加时间偏移的方式
- 正向：子路径从 0 迭代到子路径总数 - 1
- 反向：子路径从子路径总数 - 1 迭代到 0
- 打乱：子路径按「打乱种子」控制的随机顺序迭代
Shuffle Seed / accum_time_offset_shuffle_seed 浮点 0 当累加分布设为打乱时，用于随机化子路径的种子
