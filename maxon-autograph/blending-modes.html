混合模式

混合模式可以通过点击图层主行上的按钮（下图中第一个箭头）访问，也可以通过合成选项组中图层模式参数的列表（第二个箭头）访问。

Autograph 不只是把图像简单地叠放在一起，而是提供了一系列混合模式。

这些模式定义在像素层面执行的数学运算，其中：

  • B 是背景
  • A 是前景
  • c 是颜色
  • a 是 Alpha 层
  • Lum 是亮度
  • Min 是最小值
  • Max 是最大值

这个列表中的某些模式会添加一个遮罩 Alpha选项，让你根据 A 的 Alpha 通道以不同强度应用混合。

源之上

Ac * Ba + Bc * (1 - Aa)
源位于目标内部的部分会被合成到目标上。

平均值

(Ac + Bc) / 2
两张图像的平均值。

颜色

SetLum(Ac, Lum(Bc))
创建一个具有源颜色色相与饱和度、以及背景颜色亮度的颜色。这会保留背景的灰阶，适用于为单色图像上色或为彩色图像着色。

颜色加深

如果 Ac > 0
1 - min(1, (1 - Bc) / Ac)
否则为 0

使背景颜色变暗以反映源颜色。用白色绘制不会产生变化。

颜色减淡

如果 Ac < 1
min(1,Bc / (1 - Ac))
否则为 1

使背景颜色变亮以反映源颜色。用黑色绘制不会产生变化。

联合覆盖

如果 Aa <= Ba
Ac + Bc * (1 - Aa / Da) / b
否则
Ac

与正常覆盖模式相同，区别在于当同时被 A 和 B 部分覆盖时，A 会遮住 B。

替换

Ac
用前景图像替换背景图像。

差值

abs(A - B)
得到的颜色是源颜色与目标颜色之间的总差值。

目标之上

Bca × Aa + Aca × (1 - Ba)
目标位于源内部的部分会被合成到源之上并替换目标。

分离覆盖

如果 Aa + Ba >= 1
Ac + Bc * (1 - Aa) / Ba
否则
Ac + Bc

与正常覆盖运算相同，区别在于当同时被 A 和 B 部分覆盖时，两张图像不会重叠。

划分

如果 Dc > 0 且 Ac > 0
Ac / Bc
否则为 0

用图像 B 的数值除图像 A 的数值。避免两个负值变成一个正值。

排除

Ac + Bc - 2 * Ac * Bc
得到的颜色与差值运算相似。不过，排除得到的颜色与差值得到的颜色相比对比度更低。

减去

Bc - Ac
用图像 B 的数值减去图像 A 的数值。

几何平均

2 * Ac * Bc / (Ac + Bc)
与平均值类似，但只在 A 与 B 重叠处生效。

颗粒提取

Bc - Ac + 0.5
从图像 A 中提取颗粒并把它加到图像 B 之上。

颗粒合并

Bc + Ac - 0.5
把一个颗粒层（例如从颗粒提取模式中提取的）合并到图像 B 之上。这与颗粒提取模式相反。

强光

如果 Ac <= 0.5
multiply(Ac)
否则
screen(Ac)

用源颜色决定结果是对颜色做正片叠底还是滤色。如果源颜色比 0.5 亮，目标会像被滤色一样变亮；如果源颜色比 0.5 暗，目标会像被正片叠底一样变暗。

色相

SetLum(SetSat(Ac, Sat(Bc)), Lum(Bc))
创建一个具有源颜色色相、以及背景颜色饱和度与亮度的颜色。

斜边

sqrt(Ac * Ac + Bc * Bc)
介于相加与滤色运算之间。

源之内

Ac * Ba
源位于目标内部的部分会替换目标。

明度

SetLum(Bc, Lum(Ac))
创建一个具有源颜色亮度、以及背景颜色色相与饱和度的颜色。它产生的效果与颜色模式相反。

目标之内

Bc * Aa
目标位于源内部的部分会替换目标。

变亮

max(Ac, Bc)
得到的颜色取源颜色与目标颜色中较亮的一个。如果源更亮，它会替换目标；否则保留目标。

变暗

min(Ac, Bc)
得到的颜色取源颜色与目标颜色中较暗的一个。如果源更暗，它会替换目标；否则保留目标。

减

Ac - Bc
从图像 A 中减去图像 B。

正片叠底

如果 Ac < 0 且 Bc < 0
0
否则
Ac * Bc

源之外

Ac * (1 - Ba)
源位于目标外部的部分会替换目标。

正常

Ac + Bc * (1 - Aa)
源被合成到目标之上。

叠加

如果 Bc <= 0.5
2 * Ac * Bc
否则
1 - 2 * (1 - Bc) * (1 - Sc)

用目标颜色决定结果是对颜色做正片叠底还是滤色。源颜色覆盖目标，同时保留它的高光与阴影。

点光

如果 B >= 0.5
lighten(Ac, 2 * Bc - 1)
否则
darken(Ac, Bc * 2.0)

是全强度变亮与变暗混合模式的混合：它会完全移除所有中间调。

相加

Ac + Dc
源被加到目标上并替换目标。这个运算适用于为两张图像之间的叠化制作动画。

反射

Aa * Aa / (1 - Ba)
使用源图像的数值使输出图像变暗。

饱和度

SetLum(SetSat(Bc, Sat(Ac)), Lum(Bc))
创建一个具有源颜色饱和度、以及背景颜色色相与亮度的颜色。在背景中纯灰（无饱和度）的区域用这个模式绘制不会产生变化。

滤色

Ac + Bc - Ac * Bc
源颜色与目标颜色取补色后相乘，得到的颜色替换目标。得到的颜色至少与源颜色或目标颜色一样亮。

柔光

如果 2 * Ac <= 1
Bc - (1 - 2 * Ac) * Bc * (1 - Bc)
否则
如果 4 * Bc <= 1
Bc + (2 * Ac - 1) * (4 * Bc * (4 * Bc + 1) * (Bc - 1) + 7 * Bc
否则
Bc + (2 * Ac - 1) * (sqrt(Bc) - Bc)

用源颜色决定得到的颜色是变暗还是变亮。如果源颜色比 0.5 亮，目标会变亮；如果源颜色比 0.5 暗，目标会变暗，如同被烧入一样。变暗或变亮的程度与源颜色和 0.5 之间的差值成正比。如果等于 0.5，目标保持不变。

目标之外

Ba * Bc * (1 - Aa)
目标位于源外部的部分会替换目标。

目标覆盖

Aa * (1 - Ba) + Bc
目标被合成到源之上，结果替换目标。

异或

Ac * (1 - Ba) + Bc * (1 - Aa)
源位于目标外部的部分与目标位于源外部的部分相结合。

线性光

如果 Ac < 0.
linear-burn(2 * Ac, Bc)
否则
linear-dodge(2 * (Ac - 0.5), Bc)

用线性加深降低暗色的亮度，用线性减淡提高较亮颜色的亮度。

线性减淡

min(Ac + Bc, 1)
使源图像变亮以反映目标图像的颜色。

线性加深

Bc + Ac -1
使源图像变暗并反映目标图像。

亮光

如果 Ac < 0.5
color-burn(2 * Ac, Bc)
否则
color-dodge(2 * (Ac - 0.5), Bc)

颜色减淡与颜色加深的混合。它是更强烈、更饱和的对比度模式，可以为不饱和的图像增加更多饱和度。
