注视

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Target / center 选项 自定义 选择要注视的目标。目标可以是轴上的无限远点，也可以是自定义点
- X：X 轴上的无限远点
- Y：Y 轴上的无限远点
- Z：Z 轴上的无限远点
- -X：-X 轴上的无限远点
- -Y：-Y 轴上的无限远点
- -Z：-Z 轴上的无限远点
- 自定义：用户定义的中心点
- 无：这适合只应用注视修改器的向上部分
Custom Target / custom_center 浮点 3D 0, 0, 0
Eye / direction 选项 -Z 充当视点的向量。该向量会指向目标。对于摄像机，通常是 -Z 向量
- X
- Y
- Z
- -X
- -Y
- -Z
- 自定义：用户定义的向量
Custom Eye vector / custom_direction 浮点 3D 0, 0, -1
Up / up 选项 Y 可选的向上向量。这会让变换重新定向，使所选向量朝向全局 Y 轴。选择无可以跳过这一步。对于摄像机，通常是 Y 向量
- X
- Y
- Z
- -X
- -Y
- -Z
- 自定义：用户定义的向量
- 无：不重新定向变换
Custom Up vector / custom_up 浮点 3D 0, 1, 0
Amount / amount 浮点 1
