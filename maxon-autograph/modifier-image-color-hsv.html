HSV 工具

简要说明

调整色相、饱和度与亮度，或者执行颜色替换。

颜色替换：

设置源颜色和目标颜色参数。替换的范围由三组参数决定：色相、饱和度和亮度。

颜色调整：

使用色相参数的旋转，以及饱和度和明度的调整。范围与衰减参数可以实现更复杂的调整。

色相抠像：

把输出 Alpha 参数设为全部，并让查看器显示 Alpha 通道。先设置色相参数组的范围参数，然后依次往下处理其他范围参数，用各范围的衰减和调整参数来微调。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Output Alpha / output_alpha 选项 色相 - 源：Alpha 取自源
- 色相：把 Alpha 设为色相修改遮罩
- 饱和度：把 Alpha 设为饱和度修改遮罩
- 亮度：把 Alpha 设为亮度修改遮罩
- 色相饱和度最小值：把 Alpha 设为色相与饱和度修改遮罩之间的最小值
- 色相亮度最小值：把 Alpha 设为色相与亮度修改遮罩之间的最小值
- 饱和度亮度最小值：把 Alpha 设为亮度与饱和度修改遮罩之间的最小值
- 全部最小值：把 Alpha 设为色相、饱和度与亮度修改遮罩之间的最小值
Color Replacement / replacementGroup 类别 -
Source Color / src_color 颜色 0, 0, 0, 1
Destination Color / dst_color 颜色 0, 0, 0, 1
Analysis Region / analysisRegion -500, -500, 500, 500
Set Source Color From Region / analyzeButton 按钮 关
Hue Range / hue_range 浮点 2D 0, 360 被修改的颜色色相范围（以度为单位）。红为 0，绿为 120，蓝为 240。受影响的色相范围是最小的区间。例如，如果范围是（12, 348），那么选中的范围是红色正负 12 度。例外：如果范围宽度正好是 360，则所有色相都会被修改
Hue Rotation / hue_rotation 浮点 0 在范围内旋转颜色色相（以度为单位）
Hue Rotation Gain / hue_rotation_gain 浮点 1 应用于范围内颜色色相旋转的系数。数值为 0 会把范围内的所有值设为常量（在范围中心计算），数值为 1 会把色相旋转加到范围内的所有值上
Hue Rotation Roll-off / hue_rotation_rolloff 浮点 0 色相范围两侧的区间（以度为单位），在该区间内色相旋转逐渐减小到零
Saturation Range / saturation_range 浮点 2D 0, 1 被修改的颜色饱和度范围
Saturation Adjustment / saturation_adjustment 浮点 0 范围内颜色饱和度的调整。饱和度会被钳制到零，以避免颜色反转
Saturation Adjustment Gain / saturation_adjustment_gain 浮点 1 应用于范围内饱和度调整的系数。数值为 0 会把范围内的所有值设为常量（在范围中心计算），数值为 1 会把饱和度调整加到范围内的所有值上。
Saturation Adjustment Roll-off / saturation_adjustment_rolloff 浮点 0 饱和度范围两侧的区间，在该区间内饱和度旋转逐渐减小到零
Brightness Range / brightness_range 浮点 2D 0, 1 被修改的颜色饱和度范围
Brightness Adjustment / brightness_adjustment 浮点 0 范围内颜色亮度的调整
Brightness Adjustment Gain / brightness_adjustment_gain 浮点 1 应用于范围内亮度调整的系数。数值为 0 会把范围内的所有值设为常量（在范围中心计算），数值为 1 会把亮度调整加到范围内的所有值上。
Brightness Adjustment Roll-off / brightness_adjustment_rolloff 浮点 0 亮度范围两侧的区间，在该区间内亮度旋转逐渐减小到零
Clamp Black / clamp_black 布尔 关 钳制低于 0 的强度值
Clamp White / clamp_white 布尔 关 钳制高于 1 的强度值
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
