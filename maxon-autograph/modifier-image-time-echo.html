简要说明

在时间上累积图像以创造运动模糊

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Mode / mode 选项 平均 - 平均
- 滤色
- 最小值
- 最大值
- 混合到前
- 混合到后
Initial Opacity / initial_opacity 浮点 1
Decay / opacity_decay 浮点 1
Num Divisions / num_divisions 浮点 1 用于运动模糊的采样数量。数值越高，在大幅运动时运动模糊越准确，但渲染越慢。
Shutter Angle / shutter_angle 浮点 180 快门角度控制光线可以通过的时间长度。角度越大，运动模糊越强
Shutter Phase / phase_type 选项 居中 - 居中：快门在当前时间之前半个快门时长处打开，并在当前时间之后半个快门时长处关闭
- 起始：快门在当前时间打开，并在快门时长结束之后关闭
- 结束：快门在当前时间减去快门时长处打开，并在当前时间关闭
- 自定义：快门在由自定义相位确定的时间打开：相位是快门角度的偏移量，假定快门在 0 处打开
Custom Phase / custom_phase 浮点 -90 快门角度的偏移量，假定快门在 0° 处打开：快门角度为 180°、相位为 -90° 意味着快门会开启半帧，并以当前时间为中心
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
