运动路径

给 2D 参数添加关键帧时，Autograph 会根据参数随时间的变化在查看器中绘制一条轨迹。这条轨迹称为运动路径，最常用于可视化图层的移动。虽然涉及的参数并不只有位置，但为了简单起见，我们先从它开始添加关键帧。

分别管理空间与时间

给图层做动画时，需要考虑两件事：

  • 图层路径（轨迹）
  • 图层沿这条轨迹移动的速度

运动路径的主要用途是设定图层轨迹，表示2D 参数的空间演变。
要控制图层在这条轨迹上的速度，有更合适的工具可用：

  • 时间轴/摄影表：用于处理关键帧
  • 重定时图表：用于管理图层随时间在这条运动路径上的位置
  • 运动路径工具：用于同时编辑多条运动路径

时间轴中位置参数的每个关键帧，在空间上由运动路径的某个控制点表示。
如果你在时间轴中选中一个关键帧，查看器中对应的控制点也会被选中。

这些控制点被选中时显示为黄色方形。

位置运动路径

一条运动路径由若干圆点组成，每个点表示两个关键帧之间每张插值图像上锚点的位置。
如果把关键帧靠得更近，由于分隔它们的帧数减少，点的密度也会降低。

注意：点的密度与两个关键帧之间相隔的帧数有关，合成帧率也会影响它。帧率越高，点的数量越多。

图层速度唯一的视觉提示是点与点之间的距离。它们相距越远，图层移动越快。

移动运动路径点

点击并拖动运动路径上的一个点，就会修改图层的轨迹。
开始移动后再按住 shift 键，可以把移动限制在单一轴上——水平或垂直。

运动路径的切线处理

在位置参数上创建两个关键帧，默认会得到一条直的运动路径。不过，点击第一个点会显示出一条黄色切线。移动这条切线会使轨迹弯曲。

设置切线大小

点击最后一个点时看不到这条切线，因为它的手柄与控制点位置重合。
但按住 alt/opt 键并点击拖动这个点，就可以画出一条新切线，让路径向另一侧弯曲。

  • 按住 alt/opt 键单击一个控制点，会把切线长度设为零
  • 在这种情况下再点击一次，会赋予一个新的默认长度
  • 右键单击某个点并选择切换切线，也可以使用该功能。

中间关键帧的切线

把播放头移到两个关键帧之间，让图层位于路径的中点，然后在查看器中移动图层来创建一个新关键帧（因此也是一个新控制点）。
同样，可以调整这个新点的切线：

也可以先按住 alt/opt 键，再点击路径，直接在路径上添加一个新点。

警告：用 alt/opt 键添加的这个新点还会自动创建一个自适应模式的新关键帧，而通过移动图层创建的新关键帧则不是自适应模式。

断开切线：

按住 ctrl/cmd 键并点击切线手柄，可以把它们分离，形成一个夹角。

注意：用于绘制和断开切线的快捷键与路径编辑工具中使用的相同。

让图层沿轨迹定向

要自动让图层朝向轨迹方向：

  • 在时间轴中右键单击该图层，然后选择选项 > 沿轨迹定向
  • 调整图层的旋转数值，使其指向正确的方向

移动整条运动路径

要移动整条运动路径，需要选中并移动所有控制点。使用 2D 变换工具时，选择框会选中图层，而不是控制点。
可以通过以下方式快速选中这些点：

  • 在摄影表中选中该参数的所有关键帧，这样会选中所有控制点
  • 点击参数名称，这样会选中所有关键帧

还有一个功能可以让你更快。右键单击任意点，选择选中路径上的所有关键帧。

提示：这个功能有快捷键，你也可以选中任意一个运动路径控制点，按 ctrl/cmd + l，然后移动所有控制点。

注意：这个功能让你在处理单个图层时可以快速移动运动路径。为了更省时间，运动路径工具可以对多个图层同时执行同样的操作。

自适应关键帧与运动路径

当某个关键帧设为自适应时间时，它在路径上的绘制方式会不同。
在查看器中的中间控制点上右键单击，或在时间轴中对应的关键帧上右键单击，选择自适应时间（也可以选中后按 x 键）。

切线与空间插值预设

Autograph 让你可以用上面提到的工具手动管理控制点的切线；但它也提供预设，根据相邻点的位置自动定义切线。
要访问这些选项，你需要：

  • 进入摄影表模块
  • 显示关键帧属性停靠面板

选中一个或多个控制点后，空间插值部分会包含一个插值参数，用于定义应用于当前选择项的模式。

警告：注意不要把它和正下方时间插值部分中的插值参数混淆。

插值预设会用到三个点：

  • 当前控制点
  • 路径上的前一个点
  • 路径上的后一个点

线性

  • 前一条切线始终指向前一个点
  • 后一条切线始终指向后一个点

因此线性插值总会在控制点处形成一个夹角。

平滑

  • 如果当前控制点是三个点中最高或最低的，就把切线水平放置
  • 如果当前控制点是三个点中最左或最右的，就把切线垂直放置
  • 在这两个极限之间，切线会旋转

Catmull-Rom

  • 切线与前一个点和后一个点连成的直线平行
  • 它们的长度与这两点之间的距离成正比

计算当前点的切线时不会考虑相邻点的切线。

三次

确保与平滑贝塞尔插值及 C2 连续切线的切线连续性。

  • 两侧的切线长度相同
  • 会考虑相邻点的切线
  • 曲线的连续性会自动计算，无需手动管理切线

断开

无论使用哪种模式，移动一个点或修改一条切线都会立即把该点的空间插值切换为断开模式。这个术语指的是能够断开切线（按住 ctrl / cmd）并自由操作它们的做法。

警告：在查看器中右键单击一个不处于自适应时间的控制点时，会出现一个所有插值部分，让你更改时间插值。不要把它和只能在关键帧属性停靠面板中使用的空间插值混淆。

在运动路径或其延长线上可视化回退

弹性和弹跳时间插值会让图层沿运动路径非线性移动。

  • 弹跳会让图层从最后一个关键帧弹开，并沿运动路径反向移动多次
  • 弹性除了像弹跳那样反向移动外，还会把运动路径延长到最后一个关键帧之外

使用重定时图表也可以在运动路径上产生非线性移动。发生回退或延长时，运动路径会画得粗得多。

不只用于图层位置

虽然图层位置参数是使用运动路径最常见的情况，但前面提到过，任何 2D 空间参数都可以生成运动路径。

以应用于图像的神光修改器为例。把它的缩放参数设为 3.0 后，用它的位置参数来定义光芒的中心。在位置参数上创建两个关键帧，然后在属性部分或时间轴中选中它，就会出现一条运动路径，表示这个点的轨迹，可以修改它的切线使其弯曲。

警告：要显示除图层位置之外的 2D 参数的运动路径，需要在时间轴或检查器中选中它。
