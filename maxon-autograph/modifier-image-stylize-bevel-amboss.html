倒角浮雕

简要说明

为图像添加浮雕。在亮度模式下，使用源图像的亮度来确定用于生成浮雕的轮廓。在 Alpha 模式下，使用源图像的 Alpha 通道来生成浮雕。

相加：Ac + Dc — 把源加到目标上。

颜色减淡：如果 Ac < 1 → min(1, Bc / (1 - Ac))；否则为 1。

变亮：max(Ac, Bc)。

线性减淡：min(Ac + Bc, 1)。

滤色：Ac + Bc - Ac * Bc。

强光：根据 Ac 决定做正片叠底还是滤色。

实色混合：亮光的阈值。

点光：移除中间调。

柔光：分支的柔光模型。

亮光：颜色加深/颜色减淡。

差值：abs(A - B)。

划分：Ac / Bc（如果有效）。

排除：Ac + Bc - 2AcBc。

减：Ac - Bc。

减去：Bc - Ac。

颜色：SetLum(Ac, Lum(Bc))。

色相：SetLum(SetSat(Ac, Sat(Bc)), Lum(Bc))。

明度：SetLum(Bc, Lum(Ac))。

饱和度：SetLum(SetSat(Bc, Sat(Ac)), Lum(Bc))。

替换：Ac。

目标之上：Bca × Aa + Aca × (1 - Ba)。

目标之外：Ba * Bc * (1 - Aa)。

目标覆盖：Aa * (1 - Ba) + Bc。

目标之内：Bc * Aa。

源之上：Ac * Ba + Bc * (1 - Aa)。

源之外：Ac * (1 - Ba)。

正常：Ac + Bc * (1 - Aa)。

源之内：Ac * Ba。

异或：Ac * (1 - Ba) + Bc * (1 - Aa)。

平均值：(Ac + Bc) / 2。

联合覆盖：根据 Aa ≤ Ba 分支。

分离覆盖：根据 Aa + Ba ≥ 1 分支。

几何平均：2AcBc / (Ac + Bc)。

颗粒提取：Bc - Ac + 0.5。

颗粒合并：Bc + Ac - 0.5。

斜边：sqrt(Ac² + Bc²)。

反射：Aa² / (1 - Ba)。

颜色加深：1 - min(1, (1 - Bc) / Ac)。

变暗：min(Ac, Bc)。

线性加深：Bc + Ac - 1。

正片叠底：Ac * Bc。

正片叠底（运算）：Ac * Bc（保留负值）。
