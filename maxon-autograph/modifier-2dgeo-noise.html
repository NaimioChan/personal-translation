噪波

简要说明

依据噪波置换路径

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Subdivide Steps / subdivide_steps 浮点 3 每条现有线段会被分割为步数 + 1 条新线段
Subdivide Threshold / subdivide_threshold 浮点 1 每条新线段的最小长度
Amplitude / amplitude 浮点 2D -200, 200 施加到各点上的最大位移，单位为像素。x 值影响低于 0.5 的噪波值，y 值影响高于 0.5 的噪波值
Separate XY / separate_xy 布尔 关 勾选后，待置换点的 X 与 Y 分量使用不同的噪波种子。未勾选时，X 与 Y 分量由同一个噪波置换。
Follow Normals / follow_normal 布尔 关 勾选后，置换沿路径法线方向进行。启用该选项时，分离 XY 选项不起作用
Fall-off / falloffGroup 类别 -
Enable Fall-off / enable_falloff 布尔 关
Fall-off Mode / falloff_mode 选项 矩形 - 矩形：只有位于矩形内部的路径部分会被施加修改
- Follow Path：衰减曲线决定路径的哪一部分会被施加修改
Fall-off Curve / falloff_curve 当衰减模式设为矩形时，这是矩形区域内部斜坡的形状。X 轴数值越远离中心越接近 0，越靠近中心越接近 1。当衰减模式设为 Follow Path 时，X 轴数值越接近 0 表示路径起点，越接近 1 表示路径终点
Fall-off Rectangle / falloff_rect -200, -200, 200, 200
Invert Fall-off / invert_falloff 布尔 关 反转衰减效果：原本未启用效果的区域会启用效果，原本启用效果的区域会被削弱
Noise Type / noise_type 选项 Perlin - Perlin：Perlin 噪波
- Simplex：Simplex 噪波
- 单元（F1）
- 单元（F2）
- 单元（F2-F1）
- Voronoise：Voronoise（Inigo Quilez，2014）
Fractal Mode / fractal_mode 选项 FBM - FBM
- 湍流
- 脊状
Ridge Offset / fbm_ridge_offset 浮点 0.7
Seed / seed 颜色 0, 0, 0, 0
Frequency / frequency 浮点 10
Offset / offset 浮点 2D 0, 0
Perspective Offset / perspective_transform 布尔 关 勾选后，偏移量会随每一级倍频递减，以产生透视效果
Scale / scale 浮点 2D 1, 1
Rotation / rotate 浮点 0
Skew / skew 浮点 2D 0, 0
Transform Amount / transform_amount 浮点 1
Slice / slice 浮点 0
Octave Slice Offset / slice_octave_offset 浮点 1 每一级倍频之间切片上的偏移
Octaves / octaves 浮点 1
Octave Offset / octave_translation 浮点 2D 0, 0
Octave Scale / octave_scale 浮点 2D 0.5, 0.5
Octave Rotation / octave_rotation 浮点 0
Attenuation / attenuation 浮点 0.5
Voronoise U / voronoise_u 浮点 0
Voronoise V / voronoise_v 浮点 0
Jitter / jitter 浮点 1
Warp steps / warp_steps 浮点 0 分形域扭曲的步数
Warp amount / warp_amount 浮点 0 分形域扭曲的强度
Curl / curl 布尔 关
Curl Step / curl_step 浮点 100
Curl Amount / curl_amount 浮点 1
Contrast / contrast 浮点 0.25
Level / level 浮点 0.5
Gamma / gamma 浮点 1
Invert / invert 布尔 关
Transform / xformGroup 类别 -
Octaves / OctavesGroup 类别 -
Deform / DeformGroup 类别 -
Grade / AdjustGroup 类别 -
