图层变换

把图形元素链接到图层的源参数后，可以使用变换部分来设定该图层的位置、旋转、缩放和倾斜。可以在堆栈中展开图层来访问这一部分，也可以点击图层，在属性面板中显示其参数：

变换子项

这一部分包含以下参数，它们使用 Autograph 特有的坐标系统：

  • 位置：2D 参数，默认为统一模式
  • 缩放：2D 参数，默认为单一模式
  • 锚点：2D 参数，默认为统一模式
  • 旋转：1D 参数，只有单一模式
  • 倾斜：2D 参数，默认为统一模式
  • 倾斜顺序：非数值参数；定义X 倾斜先于还是后于Y 倾斜应用
  • 强度：整体变换的权重。也可以取 0-1 范围之外的值，甚至负数
  • 反转变换：可以反转变换矩阵

锚点

锚点是确定图层位置数值时使用的参考点。由于图像由大量像素组成，只说它当前位于位置 (160,80)，无法确定它是相对于什么而言——是右上角、左下角还是它的中心处于这些坐标？

因此位置中显示的数值，就是在图像中心、默认取值为 (0,0) 的锚点的数值。它也用作旋转时的轴心，或缩放时的收缩点或扩张点。

要查看锚点的位置，只需在启用移动图层工具的情况下把光标放到查看器上，它由变换控件中间的一个小加号表示。

更改锚点的数值不会改变这个参考点的位置，但会使图像的所有像素相应移动。

以一张 600×300 像素的图像为例。把它拖入合成后，它会位于合成中央，锚点位于图层源的中心。

如果移动该图层，位置的数值会改变，但锚点的数值不变，它仍位于源的中心。

如果你的图像宽 600 像素，意味着它向左延伸 300 像素、向右延伸 300 像素。在锚点参数的 X 分量中输入数值 300，就把锚点放在图像的右边缘；但由于位置的数值保持不变，源的所有像素都会向左移动，直到到达右边缘。

查看器中的锚点工具

查看器中有一个工具，可以轻松地把锚点移动到图像的角、边或中心，而不会移动图像像素。位置和锚点都会计算出新的数值。
可以选择按以下方式移动：

  • 当前选中图层的源
  • 合成坐标系统

变换强度

强度是变换部分的最后一个参数，用于确定该变换的影响程度。把该值设为 0 时变换不产生任何效果，图层回到它加入堆栈时的原始位置，即合成中心。

注意不必局限在 0-1 区间。如果位于合成中心的图层向右移动 200 像素，而强度设为 2.0，移动量会翻倍，图层向右移动 400 像素。

同理，把该值设为 -2.0 不仅会使移动距离翻倍，还会让图层向相反方向移动，即向左 400 像素。

变换矩阵与修改器

变换部分的所有变换参数，包括强度，最终都会在图层上应用所谓的变换矩阵。这是一个数学对象，可以把位置、旋转、缩放和倾斜的变化保存在同一个元素中。

当你应用变换修改器，例如 Card3D、Corner Pin 或 Follow Path 时，它们会直接作用于这个矩阵，并相互连接。得到最终的矩阵后，Autograph 会一次性应用相应的变换，因此只需一次栅格化，从而避免出现像素化效果。

反转变换

该选项用于反转变换矩阵。当一个变换与另一个变换链接时尤其有用，例如在稳定跟踪素材时可以进行补偿。

3D 变换

图层启用 3D 选项后，当前的变换部分会被另一个带 3D 参数的部分取代。2D 变换依然存在，并且可以与 3D 变换组合使用。想进一步了解，请参考 3D 模式章节。
