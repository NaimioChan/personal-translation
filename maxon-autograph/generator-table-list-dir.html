列出目录

简要说明

通过列出目录中的文件来生成一个表格。把它设置在图像/视频读取器生成器的文件参数上时很有用。这样就能动态加载新媒体，而不必先把它们导入项目。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Directory Path / dir_path 文件
List Directories / list_directories 布尔 关 是否在结果表格中包含目录
Filter / regexp 一组以空白分隔的通配符过滤器，例如：*.jpg *.exr *.png
