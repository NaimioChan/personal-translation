音频置换路径

简要说明

使用音频信号波形沿路径置换点

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Audio Source / audio_source 音频 -
Channel / channel_index 选项 平均各通道 - 平均各通道
Start Time Mode / start_time_mode 选项 当前时间 - 自定义起始时间
- 当前时间
Custom Start Time / start_time 时间 0
End Time Mode / end_mode 选项 时长 - 时长
- 绝对时间
Duration / end_time 时间 1
Samples Count / num_samples 浮点 512
Output Mode / output_value_mode 选项 平均 - 振幅
- 最大值
- 最小值
- 均方根（RMS）
- 平均
Subdivide Steps / subdivide_steps 浮点 3 每个现有分段会被分成「细分步数 + 1」个新分段
Subdivide Threshold / subdivide_threshold 浮点 1 每个新分段的最小长度
Amplitude / amplitude 浮点 2D -200, 200
Fall-off / falloffGroup 类别 -
Enable Fall-off / enable_falloff 布尔 关
Fall-off Mode / falloff_mode 选项 矩形 - 矩形：只有位于矩形内部的路径部分会被应用修改
- Follow Path：衰减曲线定义路径的哪一部分会被应用修改
Fall-off Curve / falloff_curve 当衰减模式设为矩形时，这是矩形区域内部渐变的形状。X 轴数值越远离中心越接近 0，越靠近中心越接近 1。当衰减模式设为 Follow Path 时，X 轴数值越接近 0 表示路径起点，越接近 1 表示路径终点
Fall-off Rectangle / falloff_rect -200, -200, 200, 200
Invert Fall-off / invert_falloff 布尔 关 反转衰减效果：原本未启用该效果的区域会被启用，原本已启用的区域则会被削弱
