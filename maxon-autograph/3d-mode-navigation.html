3D 模式

在 3D 中导航

紧邻缩放选项有一个下拉菜单，包含两个选项，用于把 2D 查看器切换为 3D 场景浏览器。
当合成包含 3D 元素时，无论是网格图层还是切换为 3D 模式的 2D 图层，都可以通过把查看器切换到 3D 模式来查看它们在 3D 空间中的位置。

随后使用一个名为自由摄像机的默认摄像机查看场景，它会出现在查看器右上角的选择器中。

要移动这个自由摄像机，使用以下快捷键：

  • 环绕：ctrl/cmd + left-button
  • 平移：alt/opt + left-button 或 middle-button
  • 缩放：ctrl/cmd + alt/opt + left-button 或 "Mouse Scroll Wheel"
  • 框选并对齐选中对象：f 键

叠加层与渲染选项

切换到 3D 模式会改变查看器右上角叠加层菜单的内容，以及左下角渲染选项菜单的内容。
