调色

简要说明

调色修改器让你更改图像的黑场与白场。它也可以用来以一致的调色匹配素材。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 关 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
In Black Point / blackpoint 颜色 0, 0, 0, 0 设置黑场（通常是最暗的像素）。任何等于这个数值的像素都会被设为 0。换句话说，这个颜色会被变成纯黑
In White Point / whitepoint 颜色 1, 1, 1, 1 设置白场（通常是最亮的像素）。任何等于这个数值的像素都会被设为 1。换句话说，这个颜色会被变成纯白。
Out Black Point / black 颜色 0, 0, 0, 0 任何黑色的像素都会被设为这个颜色。例如，这让你可以把一个片段的色调范围与另一个片段匹配。
Out White Point / white 颜色 1, 1, 1, 1 任何白色的像素都会被设为这个颜色。例如，这让你可以把一个片段的色调范围与另一个片段匹配。
Multiply / multiply 颜色 1, 1, 1, 1 把结果乘以这个系数。其效果是在保留黑场的同时让结果变亮。
Offset / offset 颜色 0, 0, 0, 0 偏移会给结果加上一个固定值，实际上就是让整张图像变亮。你也可以给结果加上负值，这时整张图像会变暗。
Gamma / gamma 颜色 1, 1, 1, 1 对结果施加一个恒定的伽马值。这会让中间调变亮或变暗。
Invert / invert 布尔 关 应用反转变换
Clamp Black / clamp_black 布尔 关 启用后，任何低于 0 的输出值都会被设为 0
Clamp White / clamp_white 布尔 关 启用后，任何高于 1 的输出值都会被设为 1
Unpremult / predivide 选项 按需 - 按需：如果图像被标记为 Alpha 预乘，则在应用效果之前把图像的 RGB 通道除以 Alpha 通道
- 从不：即使图像被标记为 Alpha 预乘，也绝不在应用效果之前把图像的 RGB 通道除以 Alpha 通道
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
