色差抠像

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Output mode / output 选项 最终 - 源：显示源
- 校正源：显示预蒙版校正之后的源
- 原始蒙版：显示蒙版校正之前的蒙版
- 校正蒙版：显示蒙版校正之后的蒙版
- 修补：显示修补模式去溢色所用的图
- 状态：显示蒙版状态。白色像素完全属于蒙版内，灰色像素部分属于蒙版内，黑色像素被完全排除。绿色像素显示因蒙版校正而不透明度发生变化的区域。
- 边缘检测：显示边缘修复所用的边缘图
- 最终：显示最终结果
Screen Color / key_color 颜色 0, 1, 0, 1 要抠除的屏幕色
Pre-Matte / Pre-Matte 类别 -
Chroma Smoothing / pre_matte_chroma_blur_size 浮点 2D 0, 0 在抠像前平滑色度分量。
Hue Shift / hue_shift 浮点 0 在抠像前对图像应用的色相偏移。如果输入图像中的屏幕不是纯绿或纯蓝，这有助于把它突显出来。
Key / Key 类别 -
Clean plate / clean_plate 图像 - 可选的干净板输入。如果设置了它，干净板中不透明的像素会优先于指定的屏幕色。
Alpha bias / alpha_bias 颜色 1, 1, 1, 1 Alpha 偏移
Despill bias / despill_bias 颜色 1, 1, 1, 1 去溢色偏移
Balance / despill_balance 浮点 0.5 调整抠像色两个非主导颜色通道之间的平衡。
Matte / Matte 类别 - 蒙版分级与校正参数
Garbage matte / garbage_matte 图像 - 用于标识需要无条件从最终蒙版中移除的区域的蒙版。
Core matte / core_matte 图像 - 用于标识需要无条件加入最终蒙版的区域的蒙版。
Black Point / matte_blackpoint 浮点 0 调整蒙版的黑场。低于此值的所有数值都会被排除在最终蒙版之外。
White Point / matte_whitepoint 浮点 1 调整蒙版的白场。高于此值的所有数值都会被完全包含进最终蒙版。
Lift / matte_lift 浮点 0 蒙版中为黑色的像素会被设为该颜色。
Gain / matte_gain 浮点 1 蒙版中为白色的像素会被设为该颜色。
Multiply / matte_multiply 浮点 1 用该系数乘以蒙版。这会让结果变亮，同时保留黑场。
Offset / matte_offset 浮点 0 给蒙版加上一个固定值。
Gamma / matte_gamma 浮点 1 对蒙版应用一个固定的 gamma 值。这会让蒙版的中间值变亮或变暗。
Invert / matte_invert 布尔 关 反转蒙版
Erode/Dilate / matte_erode_dilate_size 浮点 0 腐蚀（负值）或扩张（正值）蒙版
Fringe restoration / matte_fringe_restore 布尔 关 在校正之后恢复蒙版的边缘
Fringe size / matte_fringe_size 浮点 0 要在蒙版上恢复的边缘大小
Post blur / matte_post_blur_size 浮点 0 模糊校正后的蒙版
Output / Output 类别 -
Despill / despill 布尔 开 是否进行去溢色。未勾选时，只应用蒙版。
Replace Method / replace_method 选项 无 指定受蒙版校正影响的蒙版区域所用的颜色替换方式
- 无
- 源：用源颜色替换
- 硬颜色
- 软颜色
- 修补：用完全位于蒙版内的最近像素的颜色替换
Replacement Color / replacement_color 颜色 1, 1, 1, 1 硬颜色与软颜色去溢色模式所用的替换颜色。
Unpremultiply / output_unpremult 布尔 关 对输出反预乘
