表达式

简要说明

该生成器让你输入一段 Javascript 表达式来产生一个结果值。表达式可以依赖添加到用户参数列表中的那些参数的值。每个参数的变量名就是在该用户参数的齿轮菜单中选择的脚本名。完整 API 见下方详细说明。

如果勾选了多行，表达式会被包裹在一个 javascript 函数中，并且需要一条 return 语句。未勾选时，表达式最后一行的值就是输出值，这在编写单行表达式时很有用。

示例：

返回基于当前时间的噪波的 1D 表达式：

turbulence1D(time)

返回基于 “angle” 与 “distance” 参数的位置的 2D 表达式：

var angleVal = angle.getValue();
var distVal = distance.getValue();
return [Math.cos(angleVal) * distVal, Math.sin(angleVal) * distVal];

说明

全局属性

source

在修改器求值之前的源数值。通常你会把这个值纳入计算以获得输出值；否则，使用表达式生成器可能更合适。

time

表达式求值时的当前时间（单位：秒）。这是相对于该参数本地的时间，不一定就是时间轴上显示的数值，因为它会考虑时间偏移、重映射等因素……

compositionFormat

由 4 个浮点数组成的数组，依次为当前合成格式的左、下、右、上边界，单位为像素坐标

compositionPixelAspectRatio

合成格式的像素宽高比

globalIndex

当表达式被实例器所使用的某个参数调用时的唯一实例序号。它等于 instanceIndex[0] * instanceCount[0] + instanceIndex[1] * instanceCount[1] + instanceIndex[2] * instanceCount[2] + instanceIndex[3] * instanceCount[3]

instanceIndex

维度为 4 的数组，表示调用此表达式的实例器在每个维度上的实例序号

instanceCount

维度为 4 的数组，表示调用此表达式的实例器在每个维度上的实例数量

全局函数

float boxtep(float x, float a)

如果 x >= a 则返回 1，否则返回 0

float mix(float x, float y, float alpha)

线性插值：x * (1 - alpha) + y * alpha

float linearstep(float x, float a, float b)

如果 x >= a && x <= b，返回 (x - a) / (b - a)；否则在 x < a 时返回 0，在 x > b 时返回 1。注意：如果 a < b，会交换 a 与 b，并返回 1 减去结果的值。如果 a == b，返回的结果与 boxstep(x,a) 相同

float smoothstep(float x, float a, float b)

在 a 与 b 之间执行 Hermite 插值。

float gaussstep(float x, float a, float b)

与 smoothstep 相同，但使用基于指数曲线的标准高斯“钟形”曲线。

float remap(float x, float source, float range, float falloff, RemapType interp)

通用重映射函数。当 x 处于 source 的 +/- range 范围内时，结果为 1。超出该范围后，结果在 falloff 距离内降为零。衰减形状由 interp 控制。interp 可以是 Expression.LinearRamp、Expression.SmoothRamp 或 Expression.GaussianRamp 之一。

随机与噪波函数

float perlin1D(float time, float amplitude = 1, bool signedRange = false)

“改进的 Perlin 噪波”，基于 Ken Perlin 2002 年的 Java 参考代码。signedRange：如果为 true，函数返回的值以 0 为中心，而不是在 0 之上

float fbm1D(float time, int octaves = 6, float lacunarity = 2, float gain = 0.5, float amplitude = 1, bool signedRange = false)

fbm（分形布朗运动）是一种多频率噪波函数。频率总数由 octaves 控制。lacunarity 是频率之间的间隔——取值为 2 表示每个倍频程是前一个频率的两倍。gain 控制每个频率相对于前一个频率的缩放程度。signedRange：如果为 true，函数返回的值以 0 为中心，而不是在 0 之上

float turbulence1D(float time, int octaves = 6, float lacunarity = 2, float gain = 0.5, float amplitude = 1, bool signedRange = false)

湍流是 fbm 的一种变体，其中每个噪波项都取绝对值。这会得到更蓬松的外观。

float cellNoise1D(float time, float amplitude = 1, bool signedRange = false)

cellnoise 根据整数位置生成一片恒定值区域

float periodicNoise1D(float time, int period = 1, float amplitude = 1, bool signedRange = false)

在整数位置的采样之间平滑混合的随机函数。这是 Ken Perlin 最初的噪波函数。

array<float> perlinND(array<float> time, float amplitude = 1, bool signedRange = false)

与 perlin1D 相同，但会为输入数组中的每个时间返回一个包含不同值的数组

array<float> fbmND(array<float> time, int octaves = 6, float lacunarity = 2, float gain = 0.5, float amplitude = 1, bool signedRange = false)

与 fbmND 相同，但会为输入数组中的每个时间返回一个包含不同值的数组

array<float> turbulenceND(array<float> time, int octaves = 6, float lacunarity = 2, float gain = 0.5, float amplitude = 1, bool signedRange = false)

与 turbulence1D 相同，但会为输入数组中的每个时间返回一个包含不同值的数组

array<float> cellNoiseND(float time, float amplitude = 1, bool signedRange = false)

与 cellNoise1D 相同，但会为输入数组中的每个时间返回一个包含不同值的数组

array<float> periodicNoiseND(array<float> time, int period = 1, float amplitude = 1, bool signedRange = false)

与 periodicNoise1D 相同，但会为输入数组中的每个时间返回一个包含不同值的数组

float random(float seed, float mini = 0, float maxi = 1)

mini 与 maxi 之间的伪随机函数。

int randomInt(int seed, int mini = 0, int maxi = 100)

mini 与 maxi 之间的伪随机整数函数。

array<float> randomND(array<float> seed, float mini = 0, float maxi = 1)

针对一组不同的随机种子，返回 mini 与 maxi 之间的伪随机值

array<int> randomIntND(array<int> seed, int mini = 0, int maxi = 100)

针对一组不同的随机种子，返回 mini 与 maxi 之间的伪随机值

KeyFrame 类

一个小型对象，用于描述一个关键帧，由 Param 的 API 使用。它具有以下属性：

time：关键帧的时间，单位为秒。如果 time 等于 invalidTime()，该关键帧被视为无效。也可以用 isValid() 函数检查这一点

index：该关键帧在该参数维度的曲线所有关键帧中的序号。

value：关键帧的值，通常是浮点数、字符串或布尔值。

right：关键帧的右侧导数

rightAmount：右侧导数的量，范围为 0-3

left：关键帧的左侧导数

leftAmount：左侧导数的量，范围为 0-3

Param API

每个参数都会以一个变量预先声明给 JS 解释器，该变量的名称就是参数属性中定义的脚本名。参数上可用的函数如下：

int getNDims()

返回该参数的维度数量

var getValue(int dimension = -1, float time = invalidTime(), ExpressionInstanceIndex instance = makeInstanceIndex())

返回参数的值。返回值取决于参数类型以及 dimension 参数的取值。如果参数是数值类型且 dimension 大于等于 0，或者参数只有一个维度，则返回一个 float。如果参数是数值类型、dimension 为 -1 且参数有多个维度，则返回一个大小为 dimension 的 array。如果参数是字符串，返回值始终是 string。如果参数是布尔，返回值始终是 bool。dimension：对于多维参数（例如颜色选择器），指明是返回包含所有维度的数组，还是只返回某个特定维度。time：如果设为 invalidTime()（默认值），返回参数在传给表达式的当前 time 处的值；否则在给定时间对参数求值。instance：如果设为 makeInstanceIndex()（默认值），返回参数在传给表达式的当前 instanceIndex 处的值；否则在给定的 instance 处对参数求值。

var getNearestKeyFrame(int dimension = -1, float time = invalidTime())

返回该参数最近的一个 KeyFrame。用 KeyFrame 的 isValid() 函数判断是否成功返回了一个 KeyFrame。

dimension：如果为 -1，返回该参数所有维度中最近的关键帧，否则只返回给定维度的关键帧。time：如果设为 invalidTime()（默认值），返回参数在传给表达式的当前 time 处的值；否则在给定时间处检查

var getPreviousKeyFrame(int dimension = -1, float time = invalidTime())

返回该参数最近的一个前一个 KeyFrame。用 KeyFrame 的 isValid() 函数判断是否成功返回了一个 KeyFrame。

dimension：如果为 -1，返回该参数所有维度中最近的关键帧，否则只返回给定维度的关键帧。time：如果设为 invalidTime()（默认值），返回参数在传给表达式的当前 time 处的值；否则在给定时间处检查

var getNextKeyFrame(int dimension = -1, float time = invalidTime())

返回该参数最近的一个后一个 KeyFrame。用 KeyFrame 的 isValid() 函数判断是否成功返回了一个 KeyFrame。

dimension：如果为 -1，返回该参数所有维度中最近的关键帧，否则只返回给定维度的关键帧。time：如果设为 invalidTime()（默认值），返回参数在传给表达式的当前 time 处的值；否则在给定时间处检查

var getKeyFrameAt(int dimension = -1, float time = invalidTime())

如果存在，返回给定 time 处的 KeyFrame。用 KeyFrame 的 isValid() 函数判断是否成功返回了一个 KeyFrame。

dimension：如果为 -1 且参数是多维的，返回每个维度一个 KeyFrame 组成的数组。time：如果设为 invalidTime()（默认值），返回参数在传给表达式的当前 time 处的值；否则在给定时间处检查

var getKeyFrames(int dimension = -1, float minTime = invalidTime(), float maxTime = invalidTime())

返回 [minTime, maxTime] 范围内的 KeyFrame 数组

dimension：如果为 -1 且参数是多维的，返回每个维度一个 KeyFrame 数组所组成的数组

var getKeyFrameCount(int dimension = 0)

返回某个特定维度的关键帧数量。注意该函数只按维度工作。

var getKeyFrameIndex(float time, int dimension = 0)

返回给定维度上的曲线在给定 time 处的关键帧序号；如果给定时间上没有关键帧，则返回 -1。
