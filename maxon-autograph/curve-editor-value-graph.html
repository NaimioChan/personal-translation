曲线编辑器：数值图表

曲线编辑器概览

曲线编辑器是时间轴的模块之一。可以通过右侧一个代表曲线的按钮访问它。

激活后，时间轴的右侧部分会被一张图表取代，你可以在其中修改由关键帧创建的曲线的插值，也可以在应用生成器和修改器之后查看参数的演变。
这个模块有两种不同的模式：

  • 数值图表：显示并控制数值参数随时间的演变
  • 重定时图表：显示并控制图层或空间参数沿运动路径的演变

本章将介绍数值图表模式，下一章会重点介绍重定时图表。

在曲线编辑器中显示参数

要在曲线编辑器中显示参数的演变，请在时间轴或检查器中选中它。

视所选参数是否为空间参数，曲线编辑器会自动切换到数值图表或重定时图表。
在上面的示例中，图层的旋转由两个关键帧做动画，在 1 秒内从 180 度变到 0 度。

  • 垂直刻度表示以度为单位的数值：左侧的数值最高到 180
  • 水平刻度表示时间：右侧的最后一个关键帧位于 1 秒处

在曲线编辑器中导航

垂直刻度显示的数值范围是 0 到 180，因为选中参数时，曲线编辑器会自动在取值最高和取值最低的关键帧之间适应视图。
在图表中移动和缩放的快捷键与在摄影表中移动的快捷键相同，缩放上略有差别。

  • 平移（所有方向）：

    • space + left-button
    • middle-button
    • alt/opt + left-button

  • 缩放：

    • alt/opt + "Mouse wheel"：先水平放大或缩小，直到整个合成可见，再垂直放大或缩小
    • "Mouse wheel"：同时水平和垂直放大或缩小
    • ctrl/cmd + alt/opt + left-button：鼠标的方向决定缩放是水平还是垂直
    • f 键用于适应当前选区

也可以使用底部的滚动条。

警告：Autograph 中的快捷键与上下文和鼠标位置相关。这些快捷键在你的鼠标光标位于曲线编辑器上时有效。

面板右上角的一个按钮可以让你适应当前选区，而不必按 f 键。

关键帧属性停靠面板

在右侧，曲线编辑器始终会显示关键帧属性停靠面板，它已经在关键帧一节中介绍过。
这个停靠面板显示所选关键帧的信息。如果选中了多个关键帧，则显示最靠左的那个，即使面板显示有两个关键帧被选中。

警告：如果选中了多个关键帧，在停靠面板中做的任何修改都会应用到所有这些关键帧。

在数值图表中分析旋转动画很容易理解，因为我们为 2D 图层选中的是一个只由单个维度组成的参数。

选中一个关键帧会显示以下参数：

  • 时间：该关键帧所在的时间，以秒为单位定义
  • 数值：存储在该关键帧中的参数值
  • 插值：分配给该关键帧的插值类型
  • 自适应时间：在可能的情况下把关键帧切换为自适应模式

斜率段落定义显示在点两侧的切线参数。

  • 左侧斜率：点左侧的切线斜率
  • 左侧强度：由长度定义的切线张力
  • 右侧斜率：点右侧的切线斜率
  • 右侧强度：由长度定义的切线张力

警告：视分配给关键帧的插值而定，左侧或右侧参数可能不会出现在停靠面板中。

手动调整切线与点

关键帧的数值既可以在关键帧属性停靠面板中修改，也可以直接操作图表上的点来修改。

  • 水平移动一个点会改变它的时间参数
  • 垂直移动一个点会改变它的数值

在图像之间移动关键帧

这些数值可以被修改的精度很高，因此你可以把关键帧放在合成中两张图像之间。但与图层时间偏移一样，在移动点时按住 ctrl/cmd 键，就可以在两个帧之间移动关键帧。

用控制框处理多个点

用选择框选中多个关键帧时会出现一个控制框。

  • 边缘上的手柄会水平或垂直地拉伸点及其切线
  • 控制框的角会等比调整整个框的大小
  • 中心点会移动所有点

把移动限制在一个维度上

默认情况下，中心点可以向任意方向操作。但曲线编辑器顶部的一个按钮可以让你把点的移动限制在单一轴上。

这个轴会根据鼠标方向自动确定。

手动调整切线：

用于操作切线的快捷键与编辑运动路径上的点所用的快捷键相同。

  • 按住 alt/opt 键，然后点击并拖动点，即可画出新的切线
  • 按住 ctrl/cmd 键，点击一条切线，然后点击并拖动切线的点即可断开它们

处理多个分离的维度

当空间参数处于统一模式（也就是位置的默认模式）时，并不太推荐使用数值图表模式的曲线编辑器。这也是选中这类参数时它会自动切换到重定时图表模式的原因。
不过，如果把位置切换为分离模式，每个参数都是 1D 的，可以独立操作。

用颜色来区分不同的维度：

  • X：红色
  • Y：绿色
  • Z：蓝色（用于 3D 图层和元素，例如网格图层、摄像机与灯光）

参数名称显示在对应曲线的旁边。

用生成器和修改器检查参数

选中一个参数即可显示它的动画曲线，无论你用哪种方式为它做动画：

  • 关键帧
  • 生成器
  • 修改器
