控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Use Plain Text / use_plain_text 布尔 关
Source Text / plain_text
Enable Extrude / enableExtrude 布尔 关 勾选后，文本会被挤出，生成 3D 网格
Extrude Size / extrudeSize 浮点 0.05
Extrude Offset / extrudeOffset 浮点 0 把挤出相对中心偏移
Bevel Type / bevelType 选项 圆形 - 平直
- 圆形
- 内圆形
- 雕刻
- 扩展
- 无
Bevel Size / bevelSize 浮点 0 倒角的大小。钳制为挤出大小的一半。
Bevel Segments / bevelSegments 浮点 2 构成倒角的额外分段数
Front Material / frontMaterial 材质链接 - 链接到某个材质。留空时使用填充颜色
Bevel Material / bevelMaterial 材质链接 - 链接到某个材质。留空时使用填充颜色
Body Material / bodyMaterial 材质链接 - 链接到某个材质。留空时使用填充颜色
Back Material / backMaterial 材质链接 - 链接到某个材质。留空时使用填充颜色
UV Calculation / uvType 选项 适应 - 适应：通过把图形位置适配到一个单位正方形内来计算 UV。纹理细节会随图形尺寸缩放。
- 位置：使用图形位置计算 UV。所有图形的纹理细节保持一致。
- 合成：与位置相同，但会考虑合成比例。当纹理来自另一个相同尺寸的合成，或图像纹理的格式设为合成格式时很有用。
Smooth Angle / autoSmoothAngle 浮点 30 当角度超过自动平滑参数时，沿图形自动平滑法线，单位为度
Anchor Point Grouping / anchorPointGrouping 选项 字符 字符缩放与旋转时锚点的分组方式。
- 字符
- 单词
- 行
Fixed Text Box / useFixedTextBox 布尔 关
Text Box / textBox 0, -500, 500, 0
Crop To Composition Format / cropToComp 布尔 开 把此效果的界定区域裁剪为合成的格式。如果你不需要效果在合成边界之外仍有定义，这有助于提升性能。
Motion-Blur Settings / motionBlurSettings 选项 禁用 - 禁用：对该图层禁用运动模糊
- 使用合成设置：使用合成的运动模糊质量与快门设置
- 自定义设置：运动模糊质量与快门设置仅对该图层生效
Motion-Blur Method / motionBlurAlgo 选项 采样 - 步进：传统运动模糊方式，会按分段数参数指定的次数重复渲染文本
- 采样：高保真的运动模糊，速度/质量可调
Motion-Blur Quality Mode / mbQualityMode 选项 自适应 决定运动模糊计算中采样数量的方式。自适应会依据元素速度使用变化的采样数，此时运动模糊质量充当自适应采样数的乘数。采样数使用用户给定的采样数。
- 自适应
- 采样数
Motion-Blur Samples Count / mbSamples 浮点 90 用于处理运动模糊的采样数。数值越高，质量越高，但渲染时间越长。0 会禁用运动模糊。
Motion-Blur Quality / mbQuality 浮点 0.6 自适应运动模糊采样的质量。0 会禁用运动模糊。它充当自适应模式所确定采样数的乘数。
Motion Blur Divisions / divisions 浮点 1 用于运动模糊的采样数。数值越高，在大幅运动时运动模糊越准确，但渲染越慢。
Motion Blur Shutter Angle / shutterAngle 浮点 180 快门角度控制光线可以通过的时间段。角度越大，运动模糊越强
Motion Blur Shutter Phase / shutterPhaseType 选项 居中 - 居中：快门在当前时间之前半个快门时长打开，在当前时间之后半个快门时长关闭
- 起始：快门在当前时间打开，经过快门时长后关闭
- 结束：快门在当前时间减去快门时长时打开，在当前时间关闭
- 自定义：快门在由自定义相位确定的时间打开：相位是快门角度上的偏移量，假定快门在 0 处打开
Motion-blur Custom Phase / customPhase 浮点 -90 快门角度上的偏移量，假定快门在 0 处打开：快门角度为 180、相位为 -90 时，意味着快门会在半个帧内打开，并以当前时间为中心
