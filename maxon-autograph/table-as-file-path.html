表格作为文件路径

当一个元素被导入项目面板时，它属性中的第一个参数就是文件路径。当它被用作图层时，它的源参数默认与读取器的源参数共享；不过你可以在本地取消共享文件路径，以便修改其内容。

除了始终使用同一个文件路径、也就是磁盘上的同一个文件之外，你还可以用关键帧为这个文件路径做动画，也可以把它连接到表格。

通过给文件路径的生成器槽位添加一个绑定到表格生成器，并连接一个表格（其中同一列的每个单元格都包含指向不同文件的路径），就可以在渲染动画之前更换源——甚至在动画渲染的过程中更换。

我们提到过可以把表格连接到文本生成器的源，以创建多语言项目等等。更改读取器的路径则让你能把同样的原理应用到图像上，尤其是当图像被用作 3D 对象的纹理时。

设想一个 3D 场景中有一块带有英文广告的广告牌。这块广告牌的一部分是一个简单的平面，上面放置了一张 PNG 或 JPEG 图像，它既可以来自一个完整的场景，也可以由 2D 图层切换到 3D 模式得到。

要把这条广告本地化成另一个国家的版本，只需要把这张图像换成另一张。不用打开项目手动更改读取器的文件路径，你可以连接一个表格，其中包含每种语言所有图像的全部文件路径。只需更改行参数的值就能更换图像，从而改变广告的语言。

创建一个控制面板，方便地在路径之间切换

不必深入项目内部去更改这个值，这个行值可以连接到一个合成参数，从而方便地创建控制面板。导出为包、引用子项目以及使用渲染管理器时，这个参数都会显示出来（尤其是在批渲染期间，每次渲染迭代都可以更改行的值）。

更改读取器类型的限制：

你可以通过表格把读取器从 JPEG 图像换成 PNG，再换成 TIFF，但请注意你只能在同一个媒体类别内更改媒体类型：

  • 常见图像：Autograph 所使用的 OpenImageIO 库能够解码的任何图像（JPEG、PNG、TIFF、BMP 等）
  • PSD：读取 Photoshop 文件需要专用的读取器，尤其是为了只提取其中一个图层
  • SVG：在 Autograph 中读取和渲染矢量图形的方式与像素图像完全不同
  • 视频：影片/视频文件，例如 Quicktime、MKV、WEBM 等。请注意，图像序列不属于这一类别，而属于常见图像。即使它们在时间上依次相接，它们也是由单张图像文件组成的。
