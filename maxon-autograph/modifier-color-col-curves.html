颜色曲线

简要说明

应用一条查找曲线来单独调整每个通道。 主曲线会与红、绿、蓝曲线相结合，但不与 Alpha 曲线结合。 根据模式参数的不同，应用主曲线时有多种方法可用。 可以使用时间轴的曲线编辑器标签页让曲线随时间动画。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Master / master
Red / red
Green / green
Blue / blue
Alpha / alpha
Mode / mode 选项 正常 - 正常：主曲线分别独立地应用于红、绿、蓝通道
- 加权：与正常相同，但会保留色相与饱和度
- 类似胶片：与正常相同，但色相保持恒定，以避免一些色彩偏移问题
- 亮度：使用亮度让颜色与饱和度保持恒定
Luminance Mode / luminance_formula 选项 Rec. 709 处于亮度模式时使用的亮度公式
- Rec. 709
- Rec. 2020
- ACES ap-0
- ACES ap-1
- CCIR 601
- 平均：强度的平均值
- 最大值：强度的最大值
Clamp Black / clamp_black 布尔 关 启用后，任何低于 0 的输出值都会被设为 0
Clamp White / clamp_white 布尔 关 启用后，任何高于 1 的输出值都会被设为 1
Unpremult / predivide 选项 按需 - 按需：如果图像被标记为 Alpha 预乘，则在应用效果之前把图像的 RGB 通道除以 Alpha 通道
- 从不：即使图像被标记为 Alpha 预乘，也绝不在应用效果之前把图像的 RGB 通道除以 Alpha 通道
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
Input Range Minimum / input_range_min 颜色 0, 0, 0, 0 预期的最小输入强度。超出这个范围的数值会被钳制到这个范围内。
Input Range Maximum / input_range_max 颜色 1, 1, 1, 1 预期的最大输入强度。超出这个范围的数值会被钳制到这个范围内。
Lookup Table Size / lut_size 浮点 4096 包含传递函数的查找表的大小。数值越大越精确，但渲染更慢。
