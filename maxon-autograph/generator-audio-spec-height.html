音频频谱高度图

简要说明

根据音频源的频谱生成图像。这很适合配合置换修改器用作置换贴图。

控件

Enabled / enabled 布尔 开
Output Format / output_format_mode 选项 合成格式 - 格式预设
- 合成格式
- 自定义格式

Audio Source / source 音频 -
Channel / channel_index 选项 平均各通道 是使用某个特定的音频通道来计算频谱，还是对各通道取平均
- 平均各通道
Temporal Radius / temporal_radius 浮点 0 定义计算频谱所用的时间窗口半径。该值越大，频谱越平滑，代价是计算时间更长。注意，使用较大的时间窗口会让过去和未来的音频参与输出，可能导致感知上的延迟或提前。注：窗口半径在内部会被钳制，因此永远不会小于 Bands Count 所需的最小采样数。例如：如果音频为 48Khz，Band Count 为 8192，则最小时间半径为 48000/8192/2，即 0.085
Bands Count / nb_bands 选项 1024 输出中计算的频率范围（即频带）数量。注意频率始终介于 0 与音频信号采样率的一半之间。
- 1024
- 2048
- 4096
- 8192
- 16384
- 32768
Axis Type / axis_type 选项 对数 频谱是以对数还是线性尺度显示。由于大多数频率都相当低，设为对数能给较低频率更多空间。注意更改轴类型时频率曲线不会被调整。
- 线性
- 对数
Orientation / orientation 选项 垂直频率 - 水平频率：频率从低到高水平排列。Y 轴包含频率随时间的变化
- 垂直频率：频率从低到高垂直排列。X 轴包含频率随时间的变化
Central Time Mode / timeMode 选项 当前时间 是使用当前时间还是自定义时间来定义计算频谱的时间
- 自定义
- 当前时间
Custom Central Time / central_time 时间 0
Steps / num_steps 浮点 1 为计算最终频谱而在时间窗口上取平均的频谱数量
