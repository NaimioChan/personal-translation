指数模糊

简要说明

泛光滤镜会把多个不同尺寸的模糊滤镜相加，从而得到比简单模糊更大但更锐利的眩光。 它类似于把 “Count” 个单独的模糊修改器应用到同一张输入图像上，尺寸分别为 'Size'、'Size''Ratio'、'Size''Ratio'^2 等，然后对结果取平均值。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Size / size 浮点 2D 0, 0 应用的最大模糊尺寸。数值越大，遮罩的边缘向外扩展得越多。
Count / Count 浮点 5 泛光滤镜的模糊核数量。数值越大，拖尾越宽。数量为 1 时就是原本的模糊。
Ratio / ratio 浮点 2 泛光滤镜相邻模糊核尺寸之间的比率。比率为 1 时不产生泛光效果，只有原本的模糊。
Bounding Box / rod_mode 选项 扩展 - 扩展
- 裁剪到格式
- 与输入相同
Filter / filter 选项 高斯 - 高斯
- 盒式
- 三角
- 二次
Border / border 选项 RGB 重复、Alpha 黑色 - 重复
- 黑色
- RGB 重复、Alpha 黑色
Crop To Composition Format / crop_source_to_comp 布尔 开 当模糊尺寸与合成相当时，如果你不在意合成之外的强度是否被正确模糊，这个选项有助于提升性能。
Downscale Threshold / downscale_threshold 浮点 15 当模糊尺寸超过这个阈值时，图像会先被缩小再模糊，输出时再放大，这样能以快得多的速度近似出模糊的效果。增大这个数值可以提升质量，代价是处理速度下降。
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
