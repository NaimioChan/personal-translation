OCIO 色彩空间

简要说明

使用 OpenColorIO 在不同色彩空间之间转换颜色。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Input Colorspace / input_colorspace 选项 - 输入的色彩空间
- linear：场景线性，高动态范围。用于渲染与合成。
- sRGB：标准 RGB 显示空间
- sRGBf：标准 RGB 显示空间，但有额外范围以保留浮点高光。
- rec709：Rec. 709（全范围）显示空间
- Cineon：Cineon（对数胶片扫描）
- Gamma1.8：模拟理想的 Gamma 1.8 显示设备。
- Gamma2.2：模拟理想的 Gamma 2.2 显示设备。
- Gamma2.4：模拟理想的 Gamma 2.4 显示设备。
- Gamma2.6：模拟理想的 Gamma 2.6 显示设备。
- Panalog：Sony/Panavision Genesis 对数空间
- REDLog：RED 对数空间
- ViperLog：Viper 对数空间
- AlexaV3LogC：Alexa Log C
- PLogLin：Josh Pines 风格的枢轴对数/线性转换。445->0.18
- SLog：Sony SLog
- SLog1：Sony SLog1
- SLog2：Sony SLog2
- SLog3：Sony SLog3
- CLog：Canon CLog
- Log3G10：Log3G10
- Log3G12：Log3G12
- HybridLogGamma：HybdridLogGamma
- Protune：GoPro Protune
- BT1886：模拟理想的 Gamma 2.4 显示设备。
- st2084：st2084
- raw：原始数据。用于法线、点等。
- Filmic Log：基于对数的胶片调形器，具有 16.5 档宽容度和 25 档动态范围。
- Filmic sRGB：Filmic sRGB 视图变换
- False Color：Filmic 伪彩色视图变换
Output Colorspace / output_colorspace 选项 - 输出的色彩空间
- linear：场景线性，高动态范围。用于渲染与合成。
- sRGB：标准 RGB 显示空间
- sRGBf：标准 RGB 显示空间，但有额外范围以保留浮点高光。
- rec709：Rec. 709（全范围）显示空间

- REDLog：RED 对数空间
- ViperLog：Viper 对数空间
- AlexaV3LogC：Alexa Log C
- PLogLin：Josh Pines 风格的枢轴对数/线性转换。445->0.18
- SLog：Sony SLog
- SLog1：Sony SLog1
- SLog2：Sony SLog2
- SLog3：Sony SLog3
- CLog：Canon CLog
