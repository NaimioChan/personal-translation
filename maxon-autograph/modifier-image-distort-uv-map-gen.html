UV 贴图生成器

简要说明

通过一个运动向量通道分析生成 UV 贴图，然后把它应用到源图像上。

说明

与 UV 贴图修改器类似，这个修改器把 UV 贴图应用到图像上，以便匹配移动源视频的运动。UV 贴图是作为第一遍分析生成的。

用 UV 贴图生成器匹配移动图像的正确设置，是把要匹配移动的标志放在带有原始素材的图层之上。

注意：如果你的标志是一个合成，请务必勾选调整为源格式，这样标志合成内部的变换就不会与 UV 贴图生成器叠加在一起。

把 UV 贴图生成器作为标志图层源的修改器创建出来之后，它还需要知道去哪里找到用来计算运动向量的素材。你必须通过运动源参数引用它

计算 UV 贴图

在匹配移动任何内容之前，我们需要先从源视频计算运动向量。有几个参数控制着生成过程本身：

  • 参考帧：这是生成的 UV 贴图为单位矩阵的那一帧，也就是说，标志在这一帧保持不变。应把它设为你能最好地绘制/贴合要匹配移动的图像的那一帧。

  • 帧范围模式：是为图层的整个范围生成 UV 贴图，还是只为指定的帧范围生成

  • 运动估计：一组用于控制运动估计算法的参数。这些是专家设置，默认值已经调得相当合理

  • 跟踪区域模式：如果设为整幅图像，运动向量和 UV 贴图的尺寸将与源素材相同。为了加快速度，如果要匹配移动的区域在图像中只是一小块，你可以设置一个跟踪区域，并用查看器中的矩形控件来定义要计算的区域。注意在这种模式下，你应该额外留出边距，使运动向量在整个序列中保持明显一致，否则跟踪区域的边缘会出现伪影

  • EXR 磁盘缓存路径：写入运动向量和 UV 贴图的目录。

  • 文件名标识符：这个标识符会添加在生成文件的文件名中，这样你可能更容易识别它们

  • 帧间距：这个参数指明以多大的帧步长计算运动向量。默认值 1 会在每两个连续帧之间计算运动向量。增大这个值会每 N 帧计算一次运动向量，这样运动会平滑得多，但可能引入漂移。对于长时间内的极慢运动，较高的取值很有用。

注意：EXR 磁盘缓存路径的默认值使用 ${ProjectDir} 变量来引用你的项目目录所在的位置。因此请确保项目已保存，否则它将无法把 EXR 写入磁盘。

参数设置好后，点击生成 UV 贴图按钮。对于每一帧，Autograph 都会把前向和后向运动向量写入一个多通道 EXR，并把 UV 贴图写入另一个独立的 EXR 图像。

放置要匹配移动的图像

要在原始素材上放置要匹配移动的图像，请确保把时间轴设在参考帧参数所指的那一帧。如果你需要使用变换或 Corner Pin 来放置图像，请务必用一个合成把要匹配移动的图像封装起来，并把变换放在该合成中。

参考帧处的设置正确之后，只要播放或拖动时间轴，就能看到图像被匹配移动。

如果标志开始漂移，或变成一团糊，你可能得使用更高级的向量四角定位修改器，它允许你设置关键帧来防止漂移。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Reference Frame / referenceFrame 时间 0 生成的 UV 贴图为单位矩阵的那一帧，也就是说，不会产生任何变形。这应该是你要匹配移动的区域清晰可见的那一帧。更改它需要重新计算 UV 贴图序列。
Frame-Range Mode / frameRangeMode 选项 图层范围 指定生成 UV 贴图时使用的帧范围
- 图层范围
- 自定义
Start Frame / firstFrame 时间 0 生成 UV 贴图的起始帧
End Frame / endFrame 时间 1 生成 UV 贴图的结束帧之后的一帧；也就是说，如果你只想生成 1 帧，这个值应为起始帧 + 1
Generate UV-Maps / launchTracking 按钮 关 启动 UV 贴图的生成
Motion Estimation / motionEstimation 类别 -
Motion Source / motionSource 图像 - 用于计算运动向量的素材
Track Region / roi -200, -200, 200, 200 只有该区域内的像素会被跟踪。例如当你只需跟踪图像的一小部分时，这很有用。注意矩形的范围要足够大，能够包含像素在整个跟踪长度内所有可能的位置
Track Region Mode / roiMode 选项 整幅图像 用于跟踪像素的区域。选择跟踪区域并定义一个更小的矩形可以提升性能
- 跟踪区域
- 整幅图像
EXR Disk Cache Path / cache_path 文件 存储计算出的运动向量和 UV 贴图的路径。可以用 $ 变量来指代项目文件所在的目录。如果项目尚未保存，向量会存储在你系统上的临时位置
Filename Identifier / uv_basename 磁盘上的 UV 贴图和运动向量文件按以下方式命名：以 "uv_" 或 "mv_" 开头，后接此标识符，末尾是帧间距、参考帧和帧编号等信息
Frame Distance / frame_distance 浮点 1 计算运动向量时，一帧与其下一帧之间相隔的帧数。数值越高，抖动越平滑。它会影响运动向量和 UV 贴图的跟踪
Use GPU If Available / use_gpu 布尔 关 如果可能，使用 CUDA 计算运动向量。结果会与 CPU 版本略有不同，并且取决于 CUDA 驱动。保持禁用更安全。
UV-Map Blur / blur 浮点 0 在应用 UV 之前对 UV 贴图做后处理平滑。它不影响跟踪过程
Track Red / track_red 布尔 开 跟踪时考虑源图像的红色通道
Track Green / track_green 布尔 开 跟踪时考虑源图像的绿色通道
Track Blue / track_blue 布尔 开 跟踪时考虑源图像的蓝色通道
Algorithm / of_algo 选项 Dense Inverse Search - Dense Inverse Search
- Dual TV L1
Finest Scale / of_dis_finest_scale 浮点 5 计算光流所用的高斯金字塔最细层级（第零层对应原始图像分辨率）。最终光流通过双线性放大获得。
Patch Size / of_dis_patch_size 浮点 8 用于匹配的图像块大小（像素）。通常默认的 8x8 图像块在大多数情况下已经足够好。
Patch Stride / of_dis_patch_stride 浮点 3 相邻图像块之间的步幅。必须小于图像块大小。数值越低，光流质量越高。
Descent Num. Iterations / of_dis_gradient_descent_iters 浮点 25 图像块逆搜索阶段中梯度下降的最大迭代次数。数值更高在某些情况下可以提升质量。
Refinement Num. Iterations / of_dis_var_refinement_iters 浮点 5 每个尺度上变分细化的定点迭代次数。设为 0 可完全禁用变分细化。数值更高通常会产生更平滑、质量更高的光流。
Refinement Smoothness Weight / of_dis_var_refinement_alpha 浮点 20 平滑项的权重
Refinement Gradient Constancy / of_dis_var_refinement_gamma 浮点 10 梯度恒常项的权重
Refinement Color Constancy / of_dis_var_refinement_delta 浮点 5 颜色恒常项的权重
Robust To Illumination Changes / of_dis_use_mean_propagation 布尔 开 计算图像块距离时是否对图像块做均值归一化。默认开启，因为它能提高对光照变化的鲁棒性，通常会明显提升质量。如果你确定自己的序列中不含任何光照变化，可以关闭它。
Spatial Propagation / of_dis_use_spatial_propagation 布尔 开 是否对良好的光流向量使用空间传播。该选项默认开启，因为它在平均意义上表现更好，有时还能帮助从由粗到细方案引入的重大错误中恢复。关闭该选项可以让输出的光流场略微更平滑
Time Step (Tau) / of_dualtvl1_tau 浮点 0.25 数值方案的时间步长
Attachment Weight / of_dualtvl1_lambda 浮点 0.15 数据项（附着项）的权重参数。这是最关键的参数，它决定输出的平滑程度。该参数越小，得到的解越平滑。它取决于图像的运动幅度，因此其取值应针对每个图像序列调整。
Tightness Weight / of_dualtvl1_theta 浮点 0.15 附着项与正则项之间的耦合。理论上它应该取较小的值，以保持两部分相互对应。该方法在该参数很宽的取值范围内都稳定。
Pyramide Size / of_dualtvl1_nscales 浮点 5 创建图像金字塔所用的尺度数量
Num. Warps / of_dualtvl1_warps 浮点 5 每个尺度上的变形次数。这保证了方法的稳定性。数值越高越精确，但更慢
Error Tolerance / of_dualtvl1_epsilon 浮点 0.01 数值方案中使用的停止条件阈值，它在精度与运行时间之间做权衡。较小的值会得到更精确的解，但收敛更慢。
Inner Iterations / of_dualtvl1_inner_iter 浮点 30 过滤异常值时使用的迭代次数
Outer Iterations / of_dualtvl1_outter_iter 浮点 10 数值方案中使用的迭代次数
Scale Step / of_dualtvl1_scale_step 浮点 0.8 金字塔各尺度之间的步长
Median Filter Size / of_dualtvl1_median_filter_size 浮点 5 中值滤波核的大小（1 = 不滤波）。必须是 1、3 或 5

Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
