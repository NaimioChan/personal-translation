方向模糊

简要说明

对图像应用方向模糊。方向模糊会为每个像素沿变换参数所定义的一条路径累积许多像素，方式与运动模糊类似。 质量越高，渲染所需的时间越长。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Position / center 浮点 2D 0, 0
Scale / scale 浮点 2D 1, 1
Anchor Point / center_offset 浮点 2D 0, 0
Rotation / rotate 浮点 0
Skew / skew 浮点 2D 0, 0
Skew Order / skew_order 选项 XY - XY
- YX
Invert Transform / invert 布尔 关
Amount / amount 浮点 1
Centered / centered 布尔 关
Fading / fading 浮点 0
Quality / quality 浮点 0.4 数值越大，采样越多、质量越高，代价是渲染更慢
Crop To Composition Format / crop_source_to_comp 布尔 开 当模糊尺寸与合成相当时，这个选项有助于提升性能
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
