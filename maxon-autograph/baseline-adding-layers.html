添加图层

图层是构成合成的基本元素，它基于堆栈的概念。展开一个图层后，你可以访问构成它的所有元素，以及用来移动、调整尺寸、制作动画、更改时间，或控制它与其他元素合并方式的各种功能。

要在合成中显示，图层需要一个源。没有源的图层可以包含信息，但这些信息不会被应用到任何东西上。这有用吗？其实有用。把图层想象成一个盒子：如果往盒子里放东西，你移动盒子时里面的内容也会跟着移动；如果盒子是空的，你仍然可以移动它。之后当你往盒子里放入东西时，内容会立即出现在正确的位置，因为位置信息由盒子持有，而不是由里面的物体持有。

图层也是如此。你可以在合成中添加并摆放一个空图层，之后再添加甚至替换它的源。这一区分非常重要，因为它让我们可以把图层拆分成几个不同的概念：

  • 它在哪里：由变换定义
  • 它是什么：它看起来什么样？由源定义
  • 它经历了什么：应用了哪些效果？由修改器定义

其他概念将在后面介绍，例如它何时出现，由可见性关键帧和时间偏移定义。

没有源的图层在不同软件里有不同的名称：变换、空或 Null。由于后者在 2D 领域使用最多，Autograph 也使用 Null 这个名称。

当你想要把另一个图层附着到它上面时，Null 图层也非常有用，这得益于父子关系这一概念。通过父子关系，你可以只为堆栈中的一个图层制作动画，却驱动多个图层。

本节只关注 2D 和 3D 图层。其他类型的图层可以包含有关 3D 摄像机与物体、灯光或材质的信息。

图层条目

图层是用来填充合成的基本元素，它构成图层堆栈中的一个元素。

术语与内容：

图层条目左侧的三角形可以访问图层参数，这些参数将在后续小节中介绍。
现在我们先关注图层主行中的内容（从左到右）：

  • 序号：图层在堆栈中的位置编号，从顶部开始，以 001 起。

  • 颜色标签：设置摄影表（时间轴右侧）中色块的颜色。点击该标签可以选择另一种颜色。

  • 名称：定义图层名称。选中后按 f2 或 enter 键即可重命名。恰当地命名图层是保持良好组织的关键。

  • 快速源连接槽：这个槽显示当前连接到图层源的项目的图标。你也可以点击它断开该源，或把它替换为另一个项目或生成器的连接。这个槽是一个快捷方式，让你无需展开源参数就能快速选择图层源。

  • 混合模式与不透明度：这里同样可以快速访问两个参数，它们在展开图层时也可用。点击这个控件左侧的图标可以更改图层的混合模式，右侧部分则用于图层的不透明度。请注意，这个快速访问控件不允许为这两个参数制作动画；要做到这一点，必须展开图层以访问动画控件。另请注意，如果其中某个参数已添加动画，这个“元控件”会部分或完全变灰，以免因操作滑块等原因误添加动画关键帧。

  • 2D/3D 切换：可以把 2D 图层切换为3D 模式，反之亦然，此时变换部分会切换为3D 变换并新增参数。

  • 可见性：以眼睛图标表示，可以让图层被完全隐藏，即把它从查看器显示的渲染中视觉排除。该图层始终存在于堆栈中，并且可以被其他元素通过父子关系或外部源引用（例如图层图像生成器）来使用。该参数不能制作动画，但可以与可见性关键帧配合使用。

  • 独奏：只显示堆栈中启用了该选项的图层。这样可以（通常是临时地）检查一个或多个图层，以便更好地观察它们对堆栈的贡献。可以渲染只考虑独奏模式中所定义图层的合成。

  • 锁定：阻止在堆栈或查看器中选中该图层。在查看器中，点击选择会穿过被锁定的图层，就像它们不在视觉上存在一样。由于锁定的图层无法被选中，因此也无法被移动。

向合成中添加图层

向堆栈中添加图层有多种方式，具体取决于该图层是基于项目面板中导入的源、还是基于生成器，或者只是一个 Null 图层。

向堆栈中添加 Null 图层：

向堆栈中添加 Null 图层是最简单的情况，因为它不基于任何源；你无法从项目面板拖入任何东西来生成它。

新建合成后，点击堆栈顶部的 + 按钮，然后选择 Null（空图层）。会出现一个名为 Null 的新图层。如果堆栈中没有选中任何图层，这个新图层会添加在最上方。如果选中了一个或多个图层，新图层会添加到该选择中最上方图层的上面。因此，当堆栈非常大时，你可以选中一个图层来定义新图层的位置。

用快速访问菜单加快工作流程：

快速访问菜单可以让你直接在查看器内快速添加新的生成器。
只需把鼠标光标放到查看器上，然后新建一个图层：

  • 在未选中任何图层时按 q 键
  • 在选中图层时按 shift + q 键（选中图层时按 q 键会显示修改器菜单）

这个弹出面板分为两部分：

  • 左侧：项目面板中所有可用的项目（读取器和合成）
  • 右侧：所有程序化生成器

点击其中某一项时，会以它作为源创建一个新图层。

从项目面板拖入源：

在项目面板中选中一个或多个源，然后把它们拖放到时间轴中。系统会添加新图层，并把相应的源连接到每个图层上。源的选择顺序决定堆栈中图层的顺序，从下到上。

如果把影片或图像序列拖入一个空合成，系统会询问你是否要按刚拖入的源来调整合成的帧率。

向堆栈中添加新生成器：

由 Autograph 程序化生成的图像生成器可以用作图层源。点击堆栈顶部的 + 按钮即可访问图像生成器列表。与从项目面板拖放一样，系统会添加一个新图层，并把该生成器用作源。

从素材创建合成：

  • 在项目面板中右键点击一个读取器，选择从素材创建合成。系统会创建一个新合成，其名称、尺寸、时长和帧率都与该素材相同。
  • 如果时间轴没有连接到任何合成，你也可以把读取器拖到这个空时间轴中，以创建新的合成和图层。

不透明度

图层不透明度取值范围是 0.0 到 1.0，在与另一张图像混合时用作合并系数。

在像 Autograph 这样的基于图层的合成软件中，这第二张图像通常是下方堆栈的结果，而该系数由混合模式运算使用，用来定义图层在混合中的权重。不透明度充当图层已有 Alpha 通道的乘数，两者在合并运算之前结合。
修改图层不透明度有四种方式：

  • 在图层主行上，使用混合模式 / 不透明度双重控件
  • 在检查器的选择概览中
  • 在堆栈中展开图层参数，更准确地说是合成选项组
  • 在检查器的属性部分中做同样的操作

不透明度只能在堆栈或属性部分中用关键帧制作动画，或通过添加生成器到这个参数来实现。
图层主行只是提供该数值的快速访问，把它复制出来以便在不展开图层的情况下快速设置透明度。

  • 如果图层不透明度用生成器制作了动画，主行控件会变灰。
  • 如果用关键帧制作了动画，它仍然可以访问。因此要小心，避免因操作滑块而误添加动画关键帧。
