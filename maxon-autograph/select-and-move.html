选择与移动

通过 Alpha 通道选择

在堆叠图层时，Autograph 会根据图层堆栈中从下到上每个元素的位置以及每个图层的 Alpha 通道构建一张选择图。这样你就可以选中在查看器中真正看到的元素，而不必担心图层边界框和透明像素可能妨碍你选中可见元素。

在查看器中点击时，会逐个穿过图层的 Alpha 通道，直到找到不透明度高于 0.5（50% 透明）的像素，并选中对应的图层。这种选择会考虑应用修改器之后的不透明度，例如用于移除绿幕的色差抠像。

在下面的视频中，点击绿幕会移动整个图层。但一旦启用色差抠像，就可以穿过透明像素点击，选中并移动用作背景的图像。

注意：移动鼠标时出现的闪烁是选择提示造成的，它可以预览将要选中的是哪个图层。把鼠标悬停在某个图层上时，它同时会在时间轴中亮起，这样你就能看到它在堆栈中的位置。

混合模式与选择图

创建选择图时，Alpha 通道并不是唯一的因素。所使用的图层混合模式同样决定了哪些区域可以点击穿过。

在下面的示例中，一张没有 Alpha 通道的灰尘图像以滤色模式添加到堆栈顶部。暗部能让你看到堆栈的其余部分，而亮部则把它遮住。

滤色模式把黑色部分视为透明，Autograph 在创建选择图时会考虑这一点。因此可以穿过这些消失的黑色部分点击，选中堆栈中更靠下的图层。这种选择精确到像素。

基于边界框选择

对于包含文本等极细元素的图层，基于透明度的选择可能不是最佳选择。Autograph 还提供了改为基于图层边界框的选择模式，它位于查看器左上角的选项中。

选择方式选项包含两种模式：

  • 用 Alpha 通道选择（默认）
  • 用边界框选择

第二种模式用于 After Effects 中的选择，它的选择图由完整的边界框构成，不检查透明度。
为了更轻松地选中图层，尤其是被其他图层遮住的图层，你还可以借助可视堆栈。

变换参数

把图形元素链接到图层的源参数后，可以使用变换部分来定义图层的位置、旋转、缩放和倾斜。
可以在堆栈中展开图层来访问这一部分，也可以选中图层后点击选择概览中的第一行。

在这个变换子项中，可以找到以下使用 Autograph 特有坐标系统的参数：

  • 位置：2D 参数，默认为统一模式
  • 缩放：2D 参数，默认为单一模式
  • 锚点：2D 参数，默认为统一模式
  • 旋转：1D 参数，只有单一模式
  • 倾斜：2D 参数，默认为统一模式
  • 倾斜顺序：非数值参数；定义X 倾斜先于还是后于Y 倾斜应用
  • 强度：整体变换的权重。也可以取 0-1 范围之外的值，甚至负数
  • 反转变换：可以反转变换矩阵

Autograph 提供多种控制这些参数的方式：

  • 用鼠标操作
  • 手动输入数值
  • 在查看器中用方向键配合 alt 键以 1 或 10 像素为单位移动图层
  • 输入数学运算式
  • 使用 Javascript 表达式

这些不同方法在参数管理章节的更改参数值部分有详细介绍。

锚点

锚点是确定图层位置数值时使用的参考点。

由于图像由大量像素组成，只说它当前位于位置 (160,80)，并不能清楚地说明它是相对于什么而言——是右上角、左下角还是它的中心处于这些坐标？

因此位置中显示的数值，就是在图层源中心、默认取值为 (0,0) 的锚点的数值。要查看锚点的位置，只需在启用 2D 变换工具的情况下把光标放到查看器上。

它由变换控件中间的一个小 "+" 号表示：

警告：与 After Effects 不同，Autograph 的坐标系统把 (0,0) 坐标放在合成中心。但要让位置为 (0,0) 的图层完全居中，其取值 (0,0) 时锚点也必须位于源的中心。因此无论图层所用的源尺寸多大，位置和锚点都为 (0,0) 时，图层始终位于合成中心。

以一张 960×540 像素的图像为例。把它拖入 FullHD(1920x1080) 合成后，它会位于合成中央，锚点位于图层源的中心。

更改锚点的数值不会改变这个参考点的位置，但会使图像的所有像素相应移动。如果你的图像宽 960 像素，意味着相对于其中心，它向左延伸 480 像素、向右延伸 480 像素。

在下面的视频中，在锚点参数的 X 分量中输入数值 480，就把锚点放在图像的右边缘；但由于位置的数值保持不变，源的所有像素都会向左移动，直到到达右边缘。

这个锚点也用作旋转时的轴心，或缩放变化时的收缩点或扩张点。
如果移动该图层，位置的数值会改变，但锚点的数值不会，它们仍位于源的右边缘。

移动锚点

我们刚才看到，更改锚点的数值会移动所有像素，而这个参考点保持不动。如果你想移动这个锚点而不移动图层的源图像，还需要在补偿缩放变化的同时更改位置的数值。
好在按住 ctrl/cmd 键并点击 "+" 就可以自动完成。

重新定义锚点

查看器的右上角有一个工具箱，专门按照各种规则重置锚点。它可以让你轻松地把锚点移动到图像的角、边或中心，而不会移动图像像素。

你可以选择按以下方式修正锚点：

  • 单个边界框：每个选中的图层会各自定位锚点
  • 选区边界框：锚点会相对整个选区的整体边界框计算
  • 合成：锚点会按合成格式计算

信息：在图形生成器中选中多个路径或路径组时，也可以使用这个工具。

变换强度

强度是变换部分最后一个数值参数，它通过作为乘数作用于变换，来确定该变换的影响程度。
把该值设为 0 时变换不产生任何效果，图层回到它加入堆栈时的原始位置，即合成中心。

注意不必局限在 0-1 区间。如果位于合成中心的图层向右移动 200 像素，而强度设为 2.0，移动量会翻倍，图层向右移动 400 像素。
同理，把该值设为 -2.0 不仅会使移动距离翻倍，还会让图层向相反方向移动，即向左 -400 像素。

只用变换强度做动画

如果在动画中，一个标志最终要位于屏幕中央，缩放为 1.0、旋转为 0.0，我们可以把它移到第一帧，然后用两个关键帧、一个生成器或一个修改器来为强度参数做动画。

变换修改器的反向顺序

在定义参数章节的开头，我们提到变换部分既是一组参数，本身也是一个参数。这一点通过生成器与修改器槽位的存在体现出来：

矩阵连接与单次栅格化

变换部分的所有变换参数，包括强度，最终都会在图层上应用所谓的变换矩阵。这是一个数学对象，可以把位置、旋转、缩放和倾斜的变化保存在同一个元素中。

图像修改器与变换修改器（例如 Corner Pin）的区别在于，后者会直接作用于这个矩阵，并相互连接。

得到最终的矩阵后，Autograph 会一次性应用相应的变换，因此只需一次栅格化，从而避免出现像素化效果。

反向顺序

添加这些变换修改器时要牢记一个非常重要的点（只针对变换类修改器）：

数学上，矩阵连接总是从最后一个开始，逐步回溯到第一个。Autograph 选择按同样的顺序表示这些修改器，不对这一数学工具做任何自由发挥，遵循这一规范。因此它与软件中所有其他修改器有重大区别。

警告：要了解这些变换修改器的执行顺序，列表必须从下往上读。

反转变换

该选项用于反转变换矩阵。当一个变换与另一个变换链接时尤其有用，例如在稳定跟踪素材时可以进行补偿。

3D 变换

图层启用 3D 选项后，当前的变换部分会转换为另一个带 3D 参数的部分。想进一步了解，请参考图层 - 3D 模式部分。

用「变换控件」移动图层

选中一个或多个图层后，把鼠标放到查看器上会出现一个变换控件。
默认情况下，它会显示：

  • 一个蓝色边框，用于缩放图层
  • 用于改变图层尺寸和位置的控制器

该控件有两种模式，每种模式可以执行一类变换：

  • 移动 / 缩放：在第一种模式（即默认模式）下，可以修改位置和缩放参数。
  • 旋转 / 倾斜：按下 alt/option 键会把这些控制器替换为用于修改旋转和倾斜参数的控制器

要旋转图层：

  • 把光标放在控件之外。
  • 按住鼠标左键，朝想要的方向画圆。

按下 alt/option 键实际改变的是其中一个变换选项，它位于查看器左上角。
要看到这一点，只需打开选项框并按下该键：

上面的视频表明可以更改这个默认选项，从而反转 alt/option 键的行为。

  • 旋转 / 倾斜默认可用，无需按下该键。
  • 移动 / 缩放需要按下 alt/option 键才能使用。

信息：也可以点击并拖动图层的某个像素来选中并移动图层。这种控件变换并非必须，可以用查看器的叠加层选项隐藏。

使用蓝色边框及其选项

蓝色边框可用于缩放图层——可以保持也可以不保持其宽高比。
左上角的框提供两个选项，每个都可以取两种状态：

  • 统一缩放：按 shift 键可以不经菜单更改状态
    • 统一：操作蓝色边框时保持图层的宽高比
    • 分离：独立修改水平和垂直方向的缩放
  • 居中缩放：按 ctrl/cmd 键可以不经菜单更改状态
    • 居中：把轴心设在边界框中心
    • 对角：把轴心设在所操作角的对角上

局部或全局变换控件

给图层应用旋转后，专门用于位置、缩放和倾斜的控制器也会随该角度改变朝向，因为变换空间选项默认为局部模式。
不过也可以切换到全局模式，让控制器与坐标系统的水平轴和垂直轴平行。

逐像素吸附

当查看器缩放系数不是 100% 时，变换控件可以把图层移动到两个像素之间。这种情况下位置数值不是整数，可能使图层图像因像素滤镜而略微模糊。
查看器顶部的这个选项（也称为 Pixel Snapping 或 Pixel Perfect）会在移动时对位置数值取整。

变换多个图层时的独立或共同锚点

选中多个图层时，变换会根据锚点选项的状态来计算。

  • 独立原点：每个图层相对自己的锚点变换
  • 锚点：为选中的图层定义一个共同的锚点，位于中点。

涟漪模式

该选项默认启用，可以让你在位置已经添加关键帧的情况下移动锚点。

控件间距

控件控制器虽然是透明的，但有时会部分遮挡同样大小的图层。
控件间距选项会给所有控制器加上一个以像素为单位的偏移，使它们离控件中心更远。
