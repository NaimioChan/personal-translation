路径生成器

绘制贝塞尔曲线工具让你通过逐个添加构成路径的点来创建路径。

不过，如果你想直接绘制几何图形，有两类工具：

  • 矩形和椭圆工具
  • 路径生成器

矩形和椭圆工具

在绘制贝塞尔曲线工具正下方，有一个表示带四个控制点的正方形轮廓的图标。把鼠标按住在这个图标上会展开两个工具：矩形和椭圆。

这两个工具能更快地创建几何路径；但请记住，绘制完成松开鼠标按键后，它与其他任何可用路径编辑工具修改的路径并无不同。

在查看器中按住鼠标按键即可绘制图形：

  • 按住 ctrl / cmd 可让路径以你最初点击的那个像素为中心
  • 按住 shift 可创建完美的正方形或圆形

创建完成后在选择概览中选中这条路径，可以看到它的属性包括

  • 一个可为路径做动画的形状关键帧参数
  • 路径的布尔运算
  • 变换参数
  • 控制路径生命周期的启用参数

路径生成器

在查看器垂直工具栏中代表实心图形的图标，可以用同样的方式创建几何路径，只不过是通过生成器。

生成器有若干类型：

  • 矩形
  • 椭圆
  • 多边形
  • 星形
  • 文本（详见本节）

与前面工具的主要区别在于，这些生成器是参数化的（也叫程序化）——由数值参数控制——可以按像素设定路径大小，或设定多边形边数、星形分支数。

在查看器中绘制一个矩形时，选择概览会显示：

  • 图标与手工绘制的路径不同
  • 右侧的一个连接槽中会包含一个生成器，其名称显示在第二列
  • 点击这一行会在属性中显示该生成器的参数

警告：生成器不会显示它动态生成的 路径点。因此无法手动编辑它们，但原理与之前相同。生成的路径除非添加样式来绘制，否则不可见。

你还可以点击路径组旁的 "+" 按钮来添加这些生成器。

任何路径都可以随时连接到一个生成器。只需点击右侧的连接槽来替换其内容。这一操作不是破坏性的，因为断开该生成器会恢复路径的原始内容，如下面的视频所示。

路径生成器参数

生成器的参数相对容易理解：

  • 中心：所有生成器都有；为路径位置添加一个偏移。注意创建时锚点始终定义在路径中心。
  • 旋转：基于路径中心的额外旋转
  • 半径：按像素定义路径大小；对星形和多边形生成器只能为 1D，对椭圆可以为 2D；对星形有两个参数：内半径和外半径。
  • 边数：设定多边形的边数或星形的分支数
  • 模式：仅 矩形生成器 有；可用 3 种模式定义其尺寸：
    • 中心 + 边缘偏移
    • 中心 + 尺寸
    • 左上 + 右下

参数的动态行为

参数化生成器的好处在于，它们可以把数值连接到任何其他参数，例如由一个生成器控制，或接受修改器的修改。

例如，我们可以添加一个矩形生成器，把它的边缘偏移连接到一个图层矩形生成器。

这个生成器会分析图层的边界框并据此设定矩形尺寸——在文本周围创建边框时很方便。

你还可以给边缘偏移参数添加一个运算修改器，为这个边框添加内边距。

警告：这种情况下，记得把生成器的变换参数中的 位置 设为 (0,0)，以避免边框与文本之间产生偏移。
