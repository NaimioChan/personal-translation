表格转渐变

简要说明

把表格转换为渐变。这可用于根据外部数据生成渐变

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Table / source -
Stop Position Column / position_column 选项 - - 默认值（线性）
Red Column / r_column 选项 - - 默认值（0）
Green Column / g_column 选项 - - 默认值（0）
Blue Column / b_column 选项 - - 默认值（0）
Alpha Column / a_column 选项 - - 默认值（1）
Left Influence Column / left_influence_column 选项 - - 默认值（0.33）
Right Influence Column / right_influence_column 选项 - - 默认值（0.33）
Interpolation Mode Column / interp_column 选项 - - 默认值（Bezier）
