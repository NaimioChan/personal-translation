3D 查看器与工具

3D 查看器概述

3D 查看器可用于：

  • 处于 3D 模式的合成
  • 在 Autograph 中创建的场景
  • 导入的 3D 素材（.usd、.usda 等……）

要访问 3D 查看器，请在项目面板中双击上面列出的项目之一。对于合成，你还需要切换到 3D 模式。

查看器会自动切换到 3D 模式，并会有新的工具和选项可用。在下面这个示例中，我们选择使用一个带立方体的场景。首先我们会看到 3D 变换工具 (1)，然后是 3D 选项 (2)。

警告：直接查看导入的 3D 素材仅用于显示目的，几乎没有修改的余地。例如 3D 变换工具在此模式下不可用。此外，你无法在 3D 选项中创建或覆盖摄像机。

3D 变换工具

3D 工具与 2D 模式一样可以从查看器左侧访问。目前只有 3D 变换工具可用。

激活 3D 变换工具后，有 4 个选项可用：

  1. 选择（快捷键 alt+d）
  2. 平移（快捷键 alt+s）
  3. 旋转（快捷键 alt+r）
  4. 缩放（快捷键 alt+s）

你可以用这 4 个选项中的任意一个在场景中选择 3D 元素，只需点击它即可。对象被选中时会高亮显示。要进行多选，按住 shift。要取消选择某个元素，按住 ctrl+shift。

如果激活的不是默认的选择，而是其它选项，那么选中时会出现对应的控件。

控件在这里用来协助变换选中的对象。

  • 红色表示在 X 轴/平面上的变换
  • 绿色表示在 Y 轴/平面上的变换
  • 蓝色表示在 Z 轴/平面上的变换
  • 灰色表示在所有轴上的变换

默认情况下，坐标轴以局部模式显示。这意味着对象的变换矩阵也会作用于控件。你可以切换到全局（常被称为世界）模式，把控件的轴锁定到世界轴。你可以在这里切换模式：

不使用控件的 3D 变换工具

你也可以不使用控件来操控对象。选中一个对象后：

  • 按 t 进入平移模式。

    • 默认平移被约束在摄像机平面上
    • 在平移模式下，按 x、y 或 z 可把平移约束在这些轴上。
    • 在平移模式下，按 shift+x、shift+y 或 shift+z 可分别把平移约束在 YZ、XZ 或 XY 平面上

  • 按 r 进入旋转模式。

    • 默认旋转围绕摄像机的朝向轴
    • 在旋转模式下，按 x、y 或 z 可围绕这些轴旋转

  • 按 s 进入缩放模式

    • 默认缩放是等比缩放
    • 在缩放模式下，按 x、y 或 z 可沿这些轴缩放
    • 在缩放模式下，按 shift+x、shift+y 或 shift+z 可分别把缩放约束在 YZ、XZ 或 XY 平面上

注意：第二次按同一个约束键会循环回默认（即无约束）模式。

你可以用鼠标left-button确认变换，或用 esc 或鼠标right-button取消变换。

3D 选项

3D 选项让你操控查看器中的渲染，并执行诸如隐藏叠加层或创建新摄像机之类的操作。

  1. 叠加层菜单让你隐藏那些有助于设置场景、但在最终渲染中不可见的元素。这包括 3D 网格，以及摄像机或灯光等所有不可渲染对象的参考线。

  2. 后期处理按钮让你禁用 3D 后期处理，以加快查看器中的渲染速度

  3. 取景按钮让你框住选中的对象，如果没有选中对象则框住整个场景。具体来说，摄像机会移动，使对象（或场景）的整个边界框都进入查看器。摄像机的焦点/环绕点会变为边界框的中心。

  4. 注视按钮让摄像机留在原位，但使它朝向选中的对象；如果没有选中对象，则朝向整个场景。具体来说，摄像机的方向向量会被设为对象（或场景）整个边界框的中心，而摄像机的向上向量被设为 Y 轴。摄像机的焦点/环绕点会变为边界框的中心。

  5. 可用渲染器的列表

  6. 所选渲染器的设置菜单

  7. 摄像机菜单

摄像机菜单

摄像机菜单让你更改查看器摄像机的参数、创建一台新摄像机、透过场景中已有的摄像机观看，甚至直接更改已有摄像机的参数：

  • 摄像机灯光复选框启用/禁用一盏来自摄像机的默认灯光。这让你无需创建专用灯光就能看到场景中的对象。

  • 从视图创建摄像机按钮会基于当前的查看器摄像机，在场景中创建一台新摄像机。

  • 当前摄像机下拉列表让你透过自由摄像机（即查看器摄像机）或场景中的某台摄像机观看。对于在 Autograph 中创建的场景，这意味着任意可用的摄像机；对于合成，这意味着任意摄像机图层。

注意：列表中带锁图标的摄像机表示该摄像机不可编辑。

  • 锁定到查看器摄像机复选框仅在从可编辑的摄像机观看时可用。它把该摄像机锁定到查看器摄像机。

警告：这意味着对摄像机的任何更改都会完全传递到被锁定的摄像机，并把这些更改写入其中。

  • 焦距和垂直光圈更改当前摄像机上的这些参数

  • 摄像机类型下拉列表让你在透视和正交类型之间选择

  • 分辨率框复选框让你显示或隐藏分辨率框（即显示摄像机输出格式的彩色矩形）。

注意：分辨率框的颜色会随当前摄像机和选项变化：

  • 如果透过不可编辑的摄像机观看，框为橙色/红色
  • 如果透过自由摄像机或任意可编辑的摄像机观看，框为灰色
  • 如果透过可编辑的摄像机观看，并且锁定到摄像机按钮为开，标志为蓝色。

  • Passepartout 让你显示或隐藏过扫描区域（即摄像机输出格式之外的内容）。如果Passepartout 设为 1，过扫描区域内的所有内容都是黑色的

  • 格式下拉列表让你更改摄像机的输出格式。如果选择了自定义格式，则可以使用自定义宽度、高度和 PAR（像素宽高比）

摄像机菜单会显示当前摄像机的名称，其标志颜色遵循与分辨率框相同的颜色规则。

移动摄像机

当前摄像机可以直接在查看器中操控。三种操作是环绕、缩放和平移

  • 环绕：

    • ctrl/cmd + left-button
    • 环绕围绕当前的焦点/环绕点旋转摄像机

  • 缩放：

    • “Mouse wheel”
    • 缩放把摄像机移近或移离焦点/环绕点

注意：缩放实际上是移动摄像机，并不会改变焦距参数。

  • 平移：
    • middle-button
    • alt + left-button
    • 平移根据摄像机视图平面移动焦点/环绕点。
