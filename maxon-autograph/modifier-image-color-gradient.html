颜色渐变

简要说明

与渐变生成器类似，但它会在源 Alpha 不为零的地方用渐变替换源颜色。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0。
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0。
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0。
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0。

Blend Mode / blend_mode 选项 替换

相加：Ac + Dc —— 把源加到目标上。

颜色减淡：如果 Ac < 1 → min(1, Bc / (1 - Ac))；否则为 1。

变亮：max(Ac, Bc)。

线性减淡：min(Ac + Bc, 1)。

滤色：Ac + Bc - Ac * Bc。

强光：根据 Ac 做正片叠底或滤色。

实色混合：亮光的阈值版本。

线性光：根据 Ac 做颜色加深或颜色减淡。

叠加：根据 Bc 做正片叠底或滤色。

点光：移除中间调。

柔光：使用 Ac 与 Bc 的多分支公式。

亮光：颜色加深/颜色减淡。

差值：abs(A − B)。

划分：Ac / Bc（数值 > 0 时）。

排除：Ac + Bc - 2AcBc。

减：Ac - Bc。

减去：Bc - Ac。

颜色：SetLum(Ac, Lum(Bc))。

色相：SetLum(SetSat(Ac, Sat(Bc)), Lum(Bc))。

明度：SetLum(Bc, Lum(Ac))。

饱和度：SetLum(SetSat(Bc, Sat(Ac)), Lum(Bc))。

替换：Ac。

目标之上：Bca × Aa + Aca × (1 - Ba)。

目标之外：Ba * Bc * (1 - Aa)。

目标覆盖：Aa * (1 - Ba) + Bc。

目标之内：Bc * Aa。

源之上：Ac * Ba + Bc * (1 - Aa)。

源之外：Ac * (1 - Ba)。

正常：Ac + Bc * (1 - Aa)。

源之内：Ac * Ba。

异或：Ac * (1 - Ba) + Bc * (1 - Aa)。

平均值：(Ac + Bc) / 2。

联合覆盖：基于 Aa ≤ Ba 的判断逻辑。

分离覆盖：基于 Aa + Ba ≥ 1 的判断逻辑。

几何平均：2AcBc / (Ac + Bc)。

颗粒提取：Bc - Ac + 0.5。

颗粒合并：Bc + Ac - 0.5。

斜边：sqrt(Ac² + Bc²)。

反射：Aa² / (1 - Ba)。

颜色加深：1 - min(1, (1 - Bc) / Ac)。

变暗：min(Ac, Bc)。

线性加深：Bc + Ac - 1。

正片叠底：Ac * Bc。

正片叠底（运算）：Ac * Bc（保留负值）。

Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡。
