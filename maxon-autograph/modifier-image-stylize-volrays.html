体积光

简要说明

与神光类似，但提供更多选项，用于创建从位置参数向外辐射的光照效果。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Mode / mode 选项 亮度 - 亮度：根据输入的亮度生成光线
- Alpha 边缘：根据源的 Alpha 轮廓生成光线
- Alpha：根据原始输入图像的 Alpha 通道生成光线
- Alpha 遮罩：根据原始输入图像的 Alpha 通道生成光线，但在 Alpha 之外做遮罩
Luma Tolerance / lumaTolerance 浮点 0 亮度阈值，低于该值的亮度不生成光线
Edge Size / edgeSize 浮点 0 Alpha 通道边缘的厚度。增大该值会减少在边缘之外生成的光线
Edge Blur / edgeBlur 浮点 2D 3, 3
Position / position 浮点 2D 0, 0
Ray Length / rayLength 浮点 2D 20, 20
Ray Pre-Blur / rayPreBlur 浮点 0
Color Ramp Mode / interp_mode 选项 线性（平均 Alpha） - 伽马渐变
- 线性（平均 Alpha）
- 线性（堆叠 Alpha）
Add To Source / addOnTop 布尔 关
Quality / quality 浮点 7
Enable Flickering / enableFlickering 布尔 开
Flicker Speed / flickerSpeed 浮点 2
Flicker Size / flickerSize 浮点 40
Transform Noise / transformNoise 布尔 关
Desaturate / desaturate 布尔 关
Gain / gain 颜色 1, 1, 1, 1
Gamma / gamma 颜色 1, 1, 1, 1
From Color / fromColor 颜色 1, 1, 1, 1
To Color / toColor 颜色 0, 0, 0, 0
Enable Radial Falloff / enableFalloff 布尔 关
Radial Size / radialSize 浮点 500
Radial Fall-Off / radialFalloff 浮点 1
Crop To Composition Format / cropToComp 布尔 开
Transform Mask / transformMask 布尔 关
Rays Generation Mask / raysGenMask 图像 - 把生成光线的起点限制在该遮罩的 Alpha 通道内
Mask Blur / maskBlur 浮点 0
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
