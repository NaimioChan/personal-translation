转换颜色模型

简要说明

在不同颜色模型之间转换颜色值。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Operation / mode 选项 HSV -> RGB - HSV -> RGB
- RGB -> HSV
- HSL -> RGB
- RGB -> HSL
- YUV -> RGB (Rec.709)
- RGB (Rec.709) -> YUV
- YCbCr -> RGB (Rec.709)
- RGB (Rec.709) -> YCbCr
- Lab -> RGB
- RGB -> Lab
