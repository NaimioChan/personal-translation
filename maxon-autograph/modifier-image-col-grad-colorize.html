渐变着色

简要说明

用渐变给图像重新着色。会用源图像像素的 Alpha 或亮度对渐变取样，从而决定该像素的颜色。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 关 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Offset / offset 浮点 0
Wrap Mode / wrap 选项 钳制 - 钳制
- 重复
- 镜像
Luminance Mode / luma_mode 选项 Rec. 709 模式不为无时使用的亮度公式
- Rec. 709
- Rec. 2020
- ACES ap-0
- ACES ap-1
- CCIR 601
- 平均：强度的平均值
- 最大值：强度的最大值
Channel / source_channel 选项 亮度 - 亮度
- Alpha
Gradient / gradient
Colorspace / input_colorspace 选项 项目显示空间 - 项目工作空间：假定颜色以项目工作空间表示
- 项目显示空间：假定颜色以项目显示空间表示
Enable Threshold Min / enable_thr_min 布尔 关
Threshold Min / thr_min 浮点 0
Enable Threshold Max / enable_thr_max 布尔 关
Threshold Max / thr_max 浮点 1
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
