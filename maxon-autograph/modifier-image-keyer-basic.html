基础抠像

简要说明

这是一个基础亮度抠像器，它根据图像的 RGB 值计算抠像色。再由抠像色计算出背景的透明区域。例如，它可以用来遮掉天空——天空几乎总是图像中最亮的事物。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Mode / mode 选项 亮度 - 亮度：使用源像素的亮度抠像
- 颜色：使用源像素的颜色抠像
- 屏幕：用最大分量减去其他分量所得的色差进行抠像
- 无：只对 RGB 应用去溢色。你可以用内部蒙版控制去溢色区域，也可以配合 Alpha 模式设为添加到内部蒙版使用。如果输出设为未预乘，即使没有蒙版也会对图像去溢色
Luminance Mode / luma_formula 选项 Rec. 709 模式不为无时所用的亮度公式
- Rec. 709
- Rec. 2020
- ACES ap-0
- ACES ap-1
- CCIR 601
- 平均：强度的平均值
- 最大：强度的最大值
Alpha Mode / alpha_mode 选项 忽略源 Alpha - 忽略源 Alpha
- 添加到内部蒙版：源 Alpha 通道会被加到内部蒙版上。这适用于多通道抠像
- 正常：前景抠像乘以源 Alpha
Output / output_mode 选项 预乘 - 源颜色 + 抠像 Alpha：输出前景抠像的源颜色与 Alpha。适用于多通道抠像
- 预乘：颜色为抑制抠像色之后的源颜色乘以 Alpha。Alpha 为前景抠像
- 抠像：前景抠像在 RGBA 通道中输出
Key Color / key_color 颜色 0, 1, 0, 1
Lower Softness / lower_softness 浮点 -0.5 当前景抠像值超过此范围时，背景抠像值从 0 变为 1
Lower Tolerance / lower_tolerance 浮点 0 当前景抠像值超过此范围时，背景抠像值为 1
Center / center 浮点 1 与抠像色对应的前景抠像值，此时背景抠像值应为 1
Upper Softness / upper_softness 浮点 0.5 当前景抠像值超过此范围时，背景抠像值从 1 变为 0
Upper Tolerance / upper_tolerance 浮点 0 当前景抠像值超过此范围时，背景抠像值为 1
Despill / despill 浮点 1 减少前景上的颜色溢色。在 0 到 1 之间时，只对混合区域去溢色。大于 1 时，前景区域也会被去溢色
Despill Angle / despill_angle 浮点 120 以抠像色为中心、进行去溢色的锥体开角。角度越大，受影响的颜色越多
Inside Matte / inside_matte 图像 -
Outside Matte / outside_matte 图像 -
