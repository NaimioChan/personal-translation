表格转路径

简要说明

从表格生成一条路径。适合根据外部数据（例如统计数据）来绘制路径。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Table / source -
X Column / x_column 选项 - - 使用默认轴
Y Column / y_column 选项 - - 使用默认轴
X Offset / x_offset 浮点 0 为每个 X 单元格的数值加上偏移量
X Multiplier / x_multiplier 浮点 1 对每个 X 单元格的数值应用的乘数（在偏移之前）
Y Offset / y_offset 浮点 0 为每个 Y 单元格的数值加上偏移量
Y Multiplier / y_multiplier 浮点 1 对每个 Y 单元格的数值应用的乘数（在偏移之前）
Default Axis Start Value / start_value 浮点 -250 如果其中一条轴没有分配给列，这将是表格第一行的起始值
Default Axis End Value / end_value 浮点 250 如果其中一条轴没有分配给列，这将是表格最后一行的数值
Axis Type / axis_type 选项 线性 - 线性
- 对数
Mode Column / mode_column 选项 - - 默认值（LineTo）
