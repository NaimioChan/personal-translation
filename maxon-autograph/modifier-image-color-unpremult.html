反预乘

简要说明

把图像的红色、绿色和蓝色通道除以它的 Alpha 通道。Alpha 为零的像素保持不变。使用这个修改器的情况很少见，因为 Alpha 预乘是由 Autograph 自动处理的。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Modify Metadata / set_metadata 布尔 开 未勾选时，图像流的预乘元数据保持不变。这可以用来强制指定 Alpha 预乘状态
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
