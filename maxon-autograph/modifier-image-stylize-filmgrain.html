胶片颗粒

简要说明

为图像添加逼真的合成胶片颗粒。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Method / method 选项 精确 快速
精确
Samples / iterations 浮点 20 渲染颗粒所用的采样数。数值越高，质量越好，但渲染时间更长。
Grain Radius / grain_radius_mean 浮点 0.05 颗粒的平均尺寸。数值越高，渲染时间越长。
Grain Diffusion / grain_radius_std 浮点 0 颗粒半径分布的标准差。通常在 0 到颗粒半径之间。
Smoothing / sigma 浮点 0.8 高斯函数的 Sigma；数值越高，平滑越强。想要更好的质量可提高采样数，但会增加渲染时间。

Blend Mode / blend_mode 选项 相加

相加：Ac + Dc —— 把源加到目标上。

颜色减淡：如果 Ac < 1 → min(1, Bc / (1 - Ac))；否则为 1。

变亮：max(Ac, Bc)。

线性减淡：min(Ac + Bc, 1)。

滤色：Ac + Bc - Ac * Bc。

强光：根据 Ac 做正片叠底或滤色。

实色混合：亮光阈值。

线性光：根据 Ac 做加深或减淡。

叠加：根据 Bc 做正片叠底或滤色。

点光：移除中间调。

柔光：分支式柔光公式。

亮光：颜色加深/减淡。

差值：abs(A - B)。

划分：Ac / Bc（如果 Dc > 0 且 Ac > 0）。

排除：Ac + Bc - 2AcBc。

减：Ac - Bc。

减去：Bc - Ac。

颜色：SetLum(Ac, Lum(Bc))。

色相：SetLum(SetSat(Ac, Sat(Bc)), Lum(Bc))。

明度：SetLum(Bc, Lum(Ac))。

饱和度：SetLum(SetSat(Bc, Sat(Ac)), Lum(Bc))。

替换：Ac。

目标之上：Bca × Aa + Aca × (1 - Ba)。

目标之外：Ba * Bc * (1 - Aa)。

目标覆盖：Aa * (1 - Ba) + Bc。

目标之内：Bc * Aa。

源之上：Ac * Ba + Bc * (1 - Aa)。

源之外：Ac * (1 - Ba)。

正常：Ac + Bc * (1 - Aa)。

源之内：Ac * Ba。

异或：Ac * (1 - Ba) + Bc * (1 - Aa)。

平均值：(Ac + Bc) / 2。

联合覆盖：根据 Aa ≤ Ba 分支。

分离覆盖：根据 Aa + Ba ≥ 1 分支。

几何平均：2AcBc / (Ac + Bc)。

颗粒提取：Bc - Ac + 0.5。

颗粒合并：Bc + Ac - 0.5。

斜边：sqrt(Ac² + Bc²)。

反射：Aa² / (1 - Ba)。

颜色加深：1 - min(1, (1 - Bc) / Ac)。

变暗：min(Ac, Bc)。

线性加深：Bc + Ac - 1。

正片叠底：Ac * Bc。

正片叠底（运算）：Ac * Bc（保留负值）。
RGB Seed / seed 颜色 0, 1, 2, 0 每个通道随机分布的种子。把各通道设为相同数值即可得到黑白噪波。
Vary with time / vary_with_time 布尔 开 启用后，种子会随时间调制，使颗粒每帧都发生变化。
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
