发光

简要说明

使用泛光滤镜添加发光，增强图像中的明亮区域。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Output / outputMode 选项 发光加源 发光加源：输出叠加到源图像上的发光
仅发光：只输出生成的发光
发光贴图：便于调整高光与色相隔离
Minimum Highlights / isolateHighlights 浮点 0.25 受发光影响的最低强度。
Maximum Highlights / isolateHighlightsHigh 浮点 1 受发光影响的最高强度。
Enable Hue Isolation / enableIsolateHue 布尔 关 启用后，色相隔离会限制发光的区域。
Isolate Hue / isolateHue 颜色 0, 0, 0, 0 启用色相隔离后，发光只影响与该色相相匹配的区域。
Size / size 浮点 2D 3, 3
Ratio / ratio 浮点 2 泛光滤镜相邻核尺寸之间的比率。数值为 1 时禁用泛光。
Downscale Threshold / downscale_threshold 浮点 15 当模糊尺寸超过该阈值时，模糊前先缩小图像以加快处理速度。
Filter / Filter 选项 高斯 高斯
方框
三角
二次
Iterations / iterations 浮点 5 泛光滤镜中使用的核数量。
Rotate / rotate 浮点 0 旋转发光。
Gain / gain 颜色 1, 1, 1, 1
Gamma / gamma 颜色 1, 1, 1, 1
Saturation / saturation 颜色 1, 1, 1, 1
Blend Mode / blendMode 选项 相加

相加：Ac + Dc —— 把源加到目标上。

颜色减淡：如果 Ac < 1 → min(1, Bc / (1 - Ac))；否则为 1。

变亮：max(Ac, Bc)。

线性减淡：min(Ac + Bc, 1)。

滤色：Ac + Bc - Ac * Bc。

强光：根据 Ac 做正片叠底或滤色。

实色混合：亮光阈值。

线性光：根据 Ac 做加深或减淡。

叠加：根据 Bc 做正片叠底或滤色。

点光：移除中间调。

柔光：分支式柔光公式。

亮光：颜色加深/减淡。

差值：abs(A - B)。

划分：Ac / Bc（如果 Dc > 0 且 Ac > 0）。

排除：Ac + Bc - 2AcBc。

减：Ac - Bc。

减去：Bc - Ac。

颜色：SetLum(Ac, Lum(Bc))。

色相：SetLum(SetSat(Ac, Sat(Bc)), Lum(Bc))。

明度：SetLum(Bc, Lum(Ac))。

饱和度：SetLum(SetSat(Bc, Sat(Ac)), Lum(Bc))。

替换：Ac。

目标之上：Bca × Aa + Aca × (1 - Ba)。

目标之外：Ba * Bc * (1 - Aa)。

目标覆盖：Aa * (1 - Ba) + Bc。

目标之内：Bc * Aa。

源之上：Ac * Ba + Bc * (1 - Aa)。

源之外：Ac * (1 - Ba)。

正常：Ac + Bc * (1 - Aa)。

源之内：Ac * Ba。

异或：Ac * (1 - Ba) + Bc * (1 - Aa)。

平均值：(Ac + Bc) / 2。

联合覆盖：根据 Aa ≤ Ba 分支。

分离覆盖：根据 Aa + Ba ≥ 1 分支。

几何平均：2AcBc / (Ac + Bc)。

颗粒提取：Bc - Ac + 0.5。

颗粒合并：Bc + Ac - 0.5。

斜边：sqrt(Ac² + Bc²)。

反射：Aa² / (1 - Ba)。

颜色加深：1 - min(1, (1 - Bc) / Ac)。

变暗：min(Ac, Bc)。

线性加深：Bc + Ac - 1。

正片叠底：Ac * Bc。

正片叠底（运算）：Ac * Bc（保留负值）。
Add Source / addSource 布尔 关 把输入图像加到输出上。
Expand RoD / expandRoD 布尔 开
Crop To Composition Format / crop_source_to_comp 布尔 开 在不需要模糊合成区域之外时，可提升大尺寸模糊的性能。
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
