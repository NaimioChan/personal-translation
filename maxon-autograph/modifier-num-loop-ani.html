动画循环

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Start Time / start_time 时间 0
Duration / end_time 时间 1
End Time Mode / end_mode 选项 时长 - 自定义：结束时间被直接指定
- 时长：结束时间是起始时间加上一个时长
Start/End Time-space / time_space 选项 参数本地 - 参数本地：起始和结束时间表示为此参数时间的局部时间，意思是如果图层块被偏移，时间会相对于该偏移。
- 合成：起始和结束时间用全局合成时间（即时间轴上显示的时间）表示。注意在此模式下不会考虑图层块上的任何偏移
Before Mode / before_mode 选项 重复 - 保持：在起始时间处保持数值
- 重复：在起始与结束时间之间重复数值动画
- 重复偏移：在起始与结束时间之间重复数值动画，但每个周期还会叠加在一起
- 镜像：与重复相同，但每隔一个周期反转动画
Before Repeat Count / before_count 浮点 0
After Mode / after_mode 选项 重复 - 保持：在结束时间处保持数值
- 重复：在起始与结束时间之间重复数值动画
- 重复偏移：在起始与结束时间之间重复数值动画，但每个周期还会叠加在一起
- 镜像：与重复相同，但每隔一个周期反转动画
After Repeat Count / after_count 浮点 0
