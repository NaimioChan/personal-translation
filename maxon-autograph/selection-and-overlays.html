选择与叠加层

查看器顶部工具栏中有一个按钮，用于控制叠加在图像之上的叠加层。
根据你在查看器中使用的是 2D 还是 3D 模式，这些叠加层会有所不同。

启用所有叠加层选项用于快速隐藏所有叠加层。按 h 键也可以触发。
当至少有一个叠加层被禁用时，图标会变成绿色：

2D 选择提示

把鼠标移到未选中的图层上时，会快速播放一段闪烁提示动画，指示在这个位置左键点击会选中哪个图层。
该图层在时间轴中也会闪烁，指示将选中哪个图层。

2D 选择轮廓

图层被选中时，它们会有黄色或蓝色轮廓。

  • 黄色表示该图层被选中，并且是活动图层
  • 蓝色表示该图层被选中，但不是活动图层。

2D 变换处理器

2D 变换处理器选项会在图层被选中且鼠标光标位于查看器上时隐藏变换处理器。
即使隐藏了这个处理器，仍然可以按住 alt 键来移动和旋转图层。

2D 运动路径

这个选项会隐藏选中图层上的运动路径。

格式框与边界框

这个选项隐藏/显示合成周围的白色矩形，它表示合成格式框。

禁用裁剪到格式选项时可见的虚线矩形，表示合成中实际像素的边界框。使用会增大边界框的修改器（例如模糊或变换）时，你可以很快看出边界框增大到多大。

路径叠加层选项

以下四个选项用于控制图形生成器中路径的显示。
路径叠加层选项在路径叠加层一节中有说明。

2D 选择

变换工具可以选择 2D/3D 图层和 2D 路径。

  • 要选择图层，启用第一个图层选择子工具
  • 要选择路径，启用第二个图层选择子工具

可以通过点击以下位置来选择图层：

  • 如果选择方法设为Alpha 通道，则点击图层的不透明像素
  • 如果选择方法设为用边界框选择，则点击图层边界框内的任意位置

Alpha 通道方法提供更高级的选择方式，只要图层在屏幕上可见，无论它们在图层堆栈中的位置如何都能选中。
也可以通过绘制选择矩形来选择图层。任何边界框与该矩形相交的图层都会被选中。

  • 按住 shift 时，矩形会把图层加入现有选择。
  • 按住 ctrl + shift 时，矩形会从选择中移除图层。

3D 图层可以像 2D 图层一样在 2D 中被选中。

3D 叠加层

每种类型的图元（灯光、摄像机、骨骼）都可以从叠加层中过滤：

  • 所有叠加层
  • 网格
  • 所有 3D 辅助线
    • 灯光辅助线
    • 摄像机辅助线
  • 骨架骨骼
  • 3D 选择叠加层：类似于 2D 的黄色选择轮廓

关于其他 3D 查看器选项的更多信息，请查看 3D 环境 一节。
