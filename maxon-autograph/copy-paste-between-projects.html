项目间复制/粘贴

复制和粘贴参数：维度一致性的问题

在复制/粘贴参数时，同样适用维度的概念。如果你在图层堆栈或属性面板中点击位置参数的名称，然后点击复制，再把它粘贴到另一个2D 参数上（且只能是这种类型的参数），会把两个维度都考虑进去。如果你试图把一个 2D 参数复制/粘贴到 1D 参数上，或者反过来，例如把位置粘贴到2D 旋转上，则不会有任何反应。

为了复制/粘贴、链接或共享参数，它们必须是相同的类型和维度。例如，要把位置链接到缩放，你需要先把它切换到统一模式，而不是保留在单一模式，即使缩放是 2D 参数也一样。

在项目之间复制和粘贴

你可以在 Autograph 中同时创建或打开多个项目，它们位于两个或多个主窗口中。你可以在两个窗口之间、从一个项目到另一个项目复制/粘贴参数，也可以搬运带有生成器和修改器的完整图层、一组图层，甚至一个合成及其子图层。
所有与项目相关的依赖都会根据这些复制/粘贴操作重新创建：

  • 所有缺失的合成都会在项目面板中创建
  • 如果图层使用读取器作为源，它们会被重新创建，并设置正确的路径来加载图像、影片、表格、3D 素材等

这让你可以快速把一个项目中的整块内容复制到另一个项目中。如果你的目标是引用一个外部项目并希望保持动态链接，请改用子项目。

与外部应用程序通信

每次执行复制时，Autograph 实际上会创建一个 JSON 字符串并复制到剪贴板。你只需把它粘贴到文本编辑器中就能看到。

Autograph 用这些信息在项目元素之间、甚至项目之间交换数据。由于这些数据是文本形式的，外部应用程序可以生成这类数据，再通过粘贴导入到 Autograph 中；它也可以在通过复制生成数据后读取这些数据。
