边缘模糊

简要说明

对源图像 Alpha 通道的边缘应用模糊。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Size / size 浮点 2D 0, 0 模糊半径的尺寸。数值越高，模糊越强。
Edge Sharpness / edgeMult 浮点 2 在边缘上应用伽马渐变。数值越低，边缘通常越锐利
Bounding Box / rod_mode 选项 扩展 - 扩展
- 裁剪到格式
- 与输入相同
Filter / filter 选项 高斯 - 高斯
- 盒式
- 三角形
- 二次
Border / border 选项 黑色 - 重复
- 黑色
- 重复 RGB，Alpha 为黑色
Crop To Composition Format / crop_source_to_comp 布尔 关 如果你不在意合成之外的强度是否被正确模糊，它有助于提升与合成尺寸相当的大范围模糊的性能。
Downscale Threshold / downscale_threshold 浮点 15 当模糊的尺寸超过该阈值时，图像会先被缩小再模糊，并在输出时放大，从而以快得多的速度近似模糊的效果。提高该数值能提升质量，但会降低处理速度。
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
