SVG 与图形转换

把 SVG 文件用作图层源

SVG 文件可以像 JPEG、PNG 和 EXR 文件一样用作 图层源。

Autograph 会保留矢量，因此只在必要时才做栅格化，这意味着你可以为变换和其他变形做动画，而不必担心像素化。

管理输出部分参数

读取器属性中的输出部分下拉菜单会列出 SVG 中带样式的路径。

在项目面板中选中一个 SVG 文件后，你可以转到属性部分，选择要渲染的单个路径，或者选择全部来使用所有路径：

注意：选择某个特定部分并不会让你获得编辑矢量路径的权限。要做到这一点，你需要从 SVG 文件创建合成（见下文），把所有路径转换为图形 生成器。

从 SVG 文件新建合成

在项目面板中的读取器上右击，然后选择从 SVG 创建合成。这次转换会在项目面板中创建一个与导入的 SVG 文件同名的新合成。

这会弹出以下对话框：

单个图形图层：

单个图形图层选项会尽力保留作品原有的样式，重建填充和描边样式、渐变、使用正确字体的文本生成器等。

注意：转换之后，可以在树中展开 图形 -> 路径组 x-> 路径 x 来访问每条路径，并使用编辑工具进行编辑。

单个图形图层（无样式）：

如果你并不在意样式，只是想把所有路径归到一起，那么单个图形图层（无样式）选项最为理想。

这个模式会创建一个带描边样式的单一图形图层，它的路径组会包含所有子路径和子组。

作为图层：

作为图层选项会为每个复合路径（Adobe Illustrator 用来表示由其他若干条路径组成的路径的术语）新建一个图层。每个新图层都会添加一个样式来绘制其内容。
