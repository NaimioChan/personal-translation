合并

简要说明

把源图像与另一张图像混合。这与在合成中混合图层时执行的操作相同。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Foreground / foreground 图像 -
Mode / mode 选项 正常

相加：Ac + Dc — 源被加到目标上并替换目标。

颜色减淡：如果 Ac < 1 → min(1, Bc / (1 - Ac))；否则为 1 — 使背景颜色变亮。

变亮：max(Ac, Bc) — 结果取源与目标中较亮的一个。

线性减淡：min(Ac + Bc, 1) — 使图像变亮。

滤色：Ac + Bc - Ac * Bc — 始终使图像变亮。

强光：根据 Ac 决定做正片叠底还是滤色。

实色混合：如果亮光(Ac,Bc) < 0.5 则为 0，否则为 1

线性光：根据 Ac 决定做线性加深还是线性减淡。

叠加：根据 Bc 决定做正片叠底还是滤色。

点光：变亮与变暗的混合；会移除中间调。

柔光：使用 Bc 与 Ac 的复杂公式。

亮光：颜色加深/颜色减淡。

差值：abs(A - B)。

划分：如果 Dc > 0 且 Ac > 0 → Ac / Bc；否则为 0。

排除：Ac + Bc - 2 * Ac * Bc。

减：Ac - Bc。

减去：Bc - Ac。

颜色：SetLum(Ac, Lum(Bc))。

色相：SetLum(SetSat(Ac, Sat(Bc)), Lum(Bc))。

明度：SetLum(Bc, Lum(Ac))。

饱和度：SetLum(SetSat(Bc, Sat(Ac)), Lum(Bc))。

替换：Ac。

目标之上：Bca × Aa + Aca × (1 - Ba)。

目标之外：Ba * Bc * (1 - Aa)。

目标覆盖：Aa * (1 - Ba) + Bc。

目标之内：Bc * Aa。

源之上：Ac * Ba + Bc * (1 - Aa)。

源之外：Ac * (1 - Ba)。

正常：Ac + Bc * (1 - Aa)。

源之内：Ac * Ba。

异或：Ac * (1 - Ba) + Bc * (1 - Aa)。

平均值：(Ac + Bc) / 2。

联合覆盖：取决于 Aa 与 Ba。

分离覆盖：取决于 Aa + Ba。

几何平均：2 * Ac * Bc / (Ac + Bc)。

颗粒提取：Bc - Ac + 0.5。

颗粒合并：Bc + Ac - 0.5。

斜边：sqrt(Ac² + Bc²)。

反射：Aa² / (1 - Ba)。

颜色加深：根据 Ac 使结果变暗。

变暗：min(Ac, Bc)。

线性加深：Bc + Ac - 1。

正片叠底：Ac * Bc。

正片叠底（运算）：Ac * Bc（保留负值）。
