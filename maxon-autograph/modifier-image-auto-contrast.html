自动对比度

简要说明

自动对图像的强度应用对比度，让它们重新映射到 [0,1] 范围内。这在处理由其他软件渲染出来的图像（例如：深度图）时很有用，这类图像的数值所处的范围里最大值与最小值都是未知的。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 关 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Enable Maximum Override / enable_maximum_override 布尔 关 勾选后，用于归一化强度的最大值会被最大值数值覆盖。例如，在用一个很高的数值（如代表无穷大的 1e12）对深度图做归一化时很有用，那样会让归一化损失大量精度。这种情况下，指定一个较小的最大值覆盖值能让深度图呈现更多细节
Maximum Override / maximum_override 颜色 0, 0, 0, 0 用于归一化的最大值
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
