表格转回放事件

简要说明

把表格转换为回放事件。这可用于用外部数据控制动画的触发

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Table / source -
Event Start Time Column / trigger_start_column 选项 -
Event Duration Column / trigger_duration_column 选项 - - 默认值（0）
Animation Start-Time Column / start_column 选项 - - 默认值（0）
Animation Duration Column / duration_column 选项 - - 默认值（0）
Num. Loops Column / loop_column 选项 - - 默认值（1）
