图层点

简要说明

根据指定图层的边界框返回一个 2D 点。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Layer Source / layerMode 选项 下方图层 - 本图层源
- 下方图层
- 上方图层
- 图层引用
Layer / layer 链接 -
Follow Time / followTime 布尔 开 勾选后，图层矩形按所指向图层的本地时间采样；未勾选时，图层矩形按本图层的时间采样
Which / which 选项 带效果的源 - 源
- 带效果的源
- 混合后
Type / rectType 选项 边界框 选择使用图层的格式还是边界框。边界框通常受每个像素修改器（如模糊等）影响，而格式不受修改器影响（重设格式除外）
- 格式：使用源格式
- 边界框：使用源边界框
X / x_anchor 选项 居中 - 左
- 左中
- 居中
- 右中
- 右
Y / y_anchor 选项 居中 - 下
- 下中
- 居中
- 上中
- 上
Horizontal Slide / horiz_slide 浮点 0 以图层尺寸的一半为单位，对输出施加的偏移
Vertical Slide / vert_slide 浮点 0 以图层尺寸的一半为单位，对输出施加的偏移
