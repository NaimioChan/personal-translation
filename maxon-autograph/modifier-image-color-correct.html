参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 关 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Master / master_group 类别 -
Saturation / master_saturation 颜色 1, 1, 1, 1
Contrast / master_contrast 颜色 1, 1, 1, 1
Gamma / master_gamma 颜色 1, 1, 1, 1
Gain / master_gain 颜色 1, 1, 1, 1
Offset / master_offset 颜色 0, 0, 0, 0
Highlights / highlights_group 类别 -
Saturation / highlights_saturation 颜色 1, 1, 1, 1
Contrast / highlights_contrast 颜色 1, 1, 1, 1
Gamma / highlights_gamma 颜色 1, 1, 1, 1
Gain / highlights_gain 颜色 1, 1, 1, 1
Offset / highlights_offset 颜色 0, 0, 0, 0
Midtones / mid_group 类别 -
Saturation / mid_saturation 颜色 1, 1, 1, 1
Contrast / mid_contrast 颜色 1, 1, 1, 1
Gamma / mid_gamma 颜色 1, 1, 1, 1
Gain / mid_gain 颜色 1, 1, 1, 1
Offset / mid_offset 颜色 0, 0, 0, 0

Saturation / shadows_saturation 颜色 1, 1, 1, 1
Contrast / shadows_contrast 颜色 1, 1, 1, 1
Gamma / shadows_gamma 颜色 1, 1, 1, 1
Gain / shadows_gain 颜色 1, 1, 1, 1
Offset / shadows_offset 颜色 0, 0, 0, 0
Shadows / shadows
Highlights / highlights
Luminance Mode / luminance_formula 选项 Rec. 709 处于亮度模式时使用的亮度公式
- Rec. 709
- Rec. 2020
- ACES ap-0
- ACES ap-1
- CCIR 601
- 平均：强度的平均值
- 最大值：强度的最大值
Clamp Black / clamp_black 布尔 关 启用后，任何低于 0 的输出值都会被设为 0
Clamp White / clamp_white 布尔 关 启用后，任何高于 1 的输出值都会被设为 1
