创建与编辑工具

图形工具用于在查看器中绘制和编辑图形。要在查看器中启用图形工具，请点击查看器左侧工具栏中的铅笔图标，或按 d 快捷键启用。

绘制工具

这个模式让你绘制新图形或延长已有的图形。在查看器中点击时，如果光标没有落在已有的点上，Autograph 会根据工具栏选项和当前选择创建一条新路径。

注意：选择用于让 Autograph 确定在哪里创建你的路径

  • 如果没有选中任何内容，Autograph 会创建一个新图层，其源是图形生成器，其中包含一个路径组和一个样式。

  • 如果选中了一个图层：根据遮罩选项（见下图）的不同，Autograph 要么在选中的图层上创建一个遮罩；要么，如果选中的图层是图形图层，就向图形生成器添加一个新的路径组；否则就创建一个新图层。

  • 如果选中了一个图形生成器：Autograph 会添加一个新的路径组和一个新的样式

  • 如果选中了一个路径组：Autograph 会在该路径组中添加一条新路径

  • 如果选中了一条路径：Autograph 会在该路径组中选中路径之后添加一条新路径

工具栏中还有一个重要选项，会影响 Autograph 创建新图形时的行为：

  • 图形点选择：Autograph 不会创建图形，而是切换到选择工具。这有助于避免误创建新图形
  • 图形填充样式：创建新图形时，会创建一个填充样式
  • 图形描边样式：创建新图形时，会创建一个描边样式
  • 图形填充和描边：创建新图形时，会创建一个填充样式和一个描边样式
  • Follow Path 修改器：仅在选中图层时有效：创建新图形时，Autograph 会添加一个Follow Path，使该图层跟随你即将绘制的路径

一旦创建了路径，图形验证按钮就会亮起

验证图形意味着在创建新点时，Autograph 不再继续延长路径。这对于创建开放路径很有用。
右侧按钮用于验证图形而不闭合它。也可以按 esc 键完成。
左侧按钮用于验证图形并闭合它。也可以按 return 键，或点击图形的第一个点完成。

延长开放路径

点击开放路径的任一端点，会重新激活该路径，让你可以在它上面继续绘制，直到你再次验证它。

编辑控制点

选中一个控制点时，它的切线会显示出来，让你可以操作它们：
按住 shift 可把切线吸附到 45° 角。
按住 ctrl 可断开切线

编辑羽化点

羽化指的是图形外边缘上的渐变过渡。在遮罩运动元素时很有用。

白色手柄让你沿该点处路径的法线方向扩展羽化。羽化点创建后会显示出来，可以自由操作。默认情况下，移动图形内部的点时，关联的点会被一起拖动。这种关联可以通过工具栏中的以下选项禁用：

注意：只有在图形上应用了填充样式时，编辑羽化点才有意义。其他样式不支持它。

警告：在 Autograph 当前版本中，图形做动画时羽化有时会不太稳定。我们正在为未来版本研发新的算法来解决这个问题。

预设工具

这个工具用于绘制预设图形，例如椭圆和矩形。与程序化图形生成器不同，这些预设仍然带有可以手动编辑的控制点

程序化图形工具

这个工具让你绘制程序化生成器。这些生成器用数学公式生成路径，不能直接编辑其点。它们提供参数，可以像其他参数一样编辑和制作动画。

其中最有用的是 文本生成器，它让你绘制文本路径。它与文本生成器的主要区别在于，你可以对路径使用修改器，并使用任何样式来渲染文本。

添加/移除点工具

这些模式让你添加或移除点（或羽化点），而不会误移动其他任何东西。

注意：在绘制模式下点击点时按住 ctrl（macOS 上为 cmd），可以达到与移除点工具相同的效果。

选择工具

这个模式让你选择一个或多个点。按住 shift 或绘制选择矩形可以选中多个点。

注意：绘制选择矩形时，按住（ctrl + shift）会把矩形中的点从选择中移除。

选中多个点时会出现变换控件，让你像图层选择工具那样移动、缩放和旋转这些点。

重置切线工具

在这个模式下，点击一个点会重置它的切线。单击而不松开鼠标会创建一个尖角，而按住按键拖动会重新绘制切线。在绘制工具中按住 alt 键也可以做到这一点。

打开/关闭工具

在这个模式下，点击一个点会在该点击处打开或闭合图形

设置第一点工具

在这个模式下，点击一个点会把它设为第一个点。例如在使用修剪路径修改器时很有用。
