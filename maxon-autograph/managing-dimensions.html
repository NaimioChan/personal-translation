维度管理

什么是维度？

一个参数可以由多个称为维度的值组成。例如 Position2D 参数由第一个值“X”（水平位置）和另一个值“Y”（垂直位置）组成。
因此，Position2D 是一个由两个维度组成的单一参数，被称为2D 参数。

维度这一术语在 Position2D 定义空间位置时特别贴切；但它也用于定义颜色之类与位置毫无关系的内容。只需记住，这一术语表示组成一个参数的元素数量。
Autograph 的参数最多有四个维度。以下是一些例子：

  • 2D 旋转：只由一个“浮点”值定义的 1D 参数
  • 2D 位置：由两个“浮点”值定义的 2D 参数
  • 3D 位置：由三个“浮点”值定义的 3D 参数
  • 颜色：由四个“浮点”值定义的 4D 参数

如文档前面所述，即使一个参数有多个维度，复合参数也可以拆分为单一参数。这是因为 Autograph 允许你用三种不同的方式为每个维度指定值：

  • 统一
  • 分离
  • 单一

用于更改模式的菜单位于参数右侧。

统一

Autograph 默认以统一模式显示 2D/3D/4D 参数。所有维度依次并排显示，整个参数只有一个生成器槽、修改器槽和关键帧按钮（如果该参数可以动画）。任何关键帧都会同时为两个维度添加。

分离

分离模式可以让你单独显示 2D/3D/4D 参数。与统一模式不同，每个维度都会显示在单独的一行上，各自带有生成器和修改器槽以及关键帧按钮（如适用）。每个维度都可以单独更改和动画。
参数一旦设为分离模式，用于在三种模式间选择的按钮就会显示在参数名称旁边。

还要注意右侧的各个单独参数处于单一模式，该模式显示为灰色，因为它无法以其他模式显示。

  • 如果参数的单一模式可以切换到统一或分离，图标会明亮显示。
  • 如果单一是显示某个参数的唯一方式，例如 2D 图层的旋转，图标就会变灰，你将无法切换到其他模式。

单一

Autograph 默认以单一模式显示所有 1D 参数和部分 2D 参数，例如图层的缩放。切换到单一后，无论维度数量多少，所有维度都会使用相同的值。
把 Position2D 切换为单一时，只会设置一个供 X 和 Y 共用的值，这会使图层沿对角线移动。

从一种模式切换到另一种

  • 如果参数的单一模式可以切换到统一或分离，图标会明亮显示。
  • 如果单一是显示某个参数的唯一方式，例如 2D 图层的旋转，图标就会变灰，你将无法切换到其他模式。

提取一个维度

有些生成器和修改器只适用于 1D 参数。如果你想把它们添加到 2D/3D/4D 参数的某个特定维度上，或者只想把 4D 参数的某一个维度链接到一个 1D 参数，可以使用以下生成器：

  • 2D -> 1D
  • 3D -> 1D
  • 4D -> 1D

这个生成器包含一个源，用于连接或共享到 2D/3D/4D 参数，以及一个序号，用于定义要选择和保留哪个维度。

请记住，这些维度从 0 到 3 编号：

  • 0 是第一个维度
  • 3 是第四个维度
