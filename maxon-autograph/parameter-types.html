参数类型、状态与操作

参数由什么构成

参数在 Autograph 中无处不在——图层、生成器和修改器上都有。
参数至少包含：

  • 一个名称
  • 一个值或状态
  • 一个生成器或链接槽，由插头图标表示
  • 一个修改器槽，由烧瓶图标表示

同一行还可以包含：

  • 用于管理参数维度的按钮
  • 用于添加关键帧的按钮

参数同时显示在时间轴和检查器中：

这些参数有时会被归入同样是参数的类别中，但情况并不一定如此。

在上图中：

  • 变换是一个参数，它包含生成器和修改器槽，但它同时也是一个参数类别，其中含有位置和缩放之类的子参数。
  • 所选图层的时间重映射部分只用于折叠/展开其子参数；但时间重映射本身并不是一个参数。

可以动画化的参数

除了四个主要的特征元素外，参数还可以有一个按钮，以便对它进行动画。虽然大多数参数都可以动画，但有些参数在没有实际意义时无法动画。
如果参数可以动画，在用于管理维度的按钮旁边会有一个方块，代表关键帧菜单。

在下图中，强度参数可以动画，而倾斜顺序不可以：

你既可以用关键帧来动画参数，也可以通过添加生成器和修改器来实现。

更改参数值

点击参数值会进入一种编辑模式，可以在此修改它。参数背景会变深，其内容在第一次点击时会被完全选中。要更改当前值，只需输入新值，然后按 enter 键确认，或点击参数之外的地方。
你也可以按 tab 编辑下一个参数，或按 shift + tab 编辑上一个参数。
Autograph 还提供其他修改当前参数的方式。

点击并拖动鼠标

在参数上点击鼠标左键，然后按住不放，把鼠标向左或向右移动。

使用键盘方向键：

在编辑模式下，用键盘上的 left 和 right 方向键把光标定位到某一位数字上。
用 up 和 down 方向键把当前数字位增加或减少 1.0：

在查看器中配合 alt 和 shift 键使用键盘方向键

把光标放在查看器上之后，在使用键盘方向键的同时按下 alt 键，可以让所选图层在屏幕上移动一个像素。
需要注意的是，每次按下方向键所移动的距离取决于查看器的缩放比例。我们所说的一个像素，指的是你显示器的像素，而不是合成的像素。

  • 如果查看器的缩放系数设为 100%，显示器上的一个像素对应合成中的一个像素。
  • 如果该值大于 100%，在合成中的位移将小于 1 像素。
  • 如果该值小于 100%，在合成中的位移将大于 1 像素。

使用数学运算：

在编辑模式下，当前值后面可以接一个数学运算，例如加上或乘以另一个值。

  • 当前值可以保留，其后接运算
  • 也可以只用运算替换该值；此时之前的值会被用于该运算。

使用 Javascript 函数

编辑参数时，输入的值会由 Javascript 解释器读取。这意味着可以使用任何基于标准库、且写在一行内的 Javascript 函数。
例如 Math 库中的函数：

  • Math.sqrt(25)：返回 25 的平方根
  • Math.random()：返回 0.0 到 1.0 之间的随机浮点数

参数精度级别

Autograph 对每个参数始终保留最高精度，而不会对数值取整。内部最多存储 12 位小数。不过为了便于读取参数，当参数不处于编辑模式时会显示四舍五入到 2 位小数的值。

参数的颜色标识

参数可以包含：

  • 一个值：例如 40 或 140.55
  • 一个状态：对于开关是开/关，或者列表中可选的某一项

参数内容可以由用户静态定义，也可以由关键帧、生成器和修改器控制。
在所有这些情况下，参数的值或背景都会改变颜色。

当参数使用关键帧时

  • 如果存在关键帧但当前时间上没有关键帧，背景变为深灰色
  • 如果当前时间上有关键帧，背景变为浅灰色

你还会注意到右侧的菱形要么是空心的、要么是实心的，关键帧一节中有更详细的说明。

当参数连接到生成器或链接到另一个参数时

用户手动设定的值会被新值取代。该值随后变灰，背景变为蓝色，与选择概览中用来表示生成器的颜色相同。

对于链接，连接槽周围会显示黄色轮廓，详见这一节。

当参数上添加了修改器时

经过修改器作用后的输出值以黄色显示。

由于参数仍可编辑，背景不会改变颜色，数值也不会变灰。把鼠标移到参数附近时，你会看到用白色绘制的、修改器作用之前的值。

当参数被共享时

对于共享，连接槽周围会显示紫色轮廓，详见这一节。

鼠标右键选项

在参数上点击鼠标右键会显示若干选项：

  • 各种复制/粘贴功能
  • 取消共享：把当前参数从其共享组中移除
  • 跟随时间：在链接参数时启用此选项
  • 移除生成器：删除当前连接到该参数的生成器
  • 公开为合成参数：在当前合成的自定义参数中自动创建一个变量，并把该参数连接到它
  • 重置：删除应用到该参数的所有关键帧、生成器和修改器，并重置为默认值
  • 应用默认值：恢复默认值，但不删除关键帧、生成器或修改器
  • 移除动画：删除该参数上的所有关键帧
  • 在时间轴中显示：在时间轴中显示该参数，详见属性面板文档。
  • 各种链接/共享功能

不同的参数类型

参数的值或状态取决于它能存储的数据类型。在 Autograph 中添加自定义合成参数时，可以看到可用类型的列表。

  • 音频：包含一个音频源或一个音频混音
  • 复选框：可以有两种状态.：开或关
  • 颜色：由 R/G/B/A（红/绿/蓝/Alpha）定义的四个浮点值组成的组
  • 下拉菜单：可以创建自定义菜单来驱动内部参数
  • 文件浏览器：指向文件的路径；可以使用项目变量指定为绝对或相对路径
  • 浮点：包含小数点的单个数值
  • Float2D：包含小数点的两个数值组成的组
  • Float3D：包含小数点的三个数值组成的组
  • 渐变：由位置、颜色以及左右影响定义的色标组成的组
  • 组：其作用方式与我们上面提到的时间重映射部分相同
  • 图像：包含一个图像，无论它来自读取器、子合成还是图层图像
  • 整数：不带小数的单个数值
  • Integer2D：不带小数的两个数值组成的组
  • Integer3D：不带小数的三个数值组成的组
  • 图层引用：不要与只包含图形信息的图像混淆；这里指的是图层的主行，其中含有一个序号，用于确定它在将被引用的堆栈中的位置
  • 矩形：由 L/B/R/T（左/下/右/上）定义的四个浮点值组成的组
  • 文本：只定义源文本，与文本样式相对；严格来说，这一元素通常被称为字符串，或简称 String
  • 时间：由时间码和对应的帧编号组成；用于时间码的帧率由此参数所属合成的帧率决定
  • 2D 变换：2D 变换矩阵和各个单独参数（位置、旋转等）
  • 3D 素材/场景：完整的场景（包括在 Autograph 中从零创建的场景）或从项目面板导入 3D 几何体得到的素材；例如一个 USD 文件
  • 3D 摄像机：3D 摄像机参数（不含其变换），包括摄像机类型、焦距、对焦距离等。
  • 3D 变换：3D 变换矩阵和各个单独参数（位置、旋转等）

在创建名为 Packages 的独立模板时，公开这些参数非常有用。

警告：在复制粘贴或链接与共享参数时，识别参数类型至关重要，因为只有同一类型的参数才能被复制/粘贴，或链接/共享。

其中一些参数类型有多个值，例如 Integer3D、Float3D 或 矩形。管理维度一节说明了如何把这些复合参数拆分为多个单一参数。
