音频分析器

简要说明

使用音频源的频谱分析，返回所选频率范围的数值，并用频率权重曲线执行加权平均。选中频率权重参数时，曲线编辑器会显示音频频谱，便于你观察音频信号的频率分布。当曲线为 0 时，对应的频率不参与结果数值的计算，而权重更高的频率在结果数值中更突出。该曲线让你可以轻松地只提取例如低频或任何特定频率范围。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Audio Source / source 音频 -
Channel / channel_index 选项 平均各通道 是使用某个特定的音频通道来计算频谱，还是对各通道取平均
- 平均各通道
Temporal Radius / temporal_window_radius 浮点 0.1 定义计算频谱所用的时间窗口半径。该值越大，频谱越平滑，代价是计算时间更长。注意，使用较大的时间窗口会让过去和未来的音频参与输出，可能导致感知上的延迟或提前。注：窗口半径在内部会被钳制，因此永远不会小于 Bands Count 所需的最小采样数。例如：如果音频为 48Khz，Band Count 为 8192，则最小时间半径为 48000/8192/2，即 0.085
Bands Count / nb_bands 选项 1024 输出中计算的频率范围（即频带）数量。注意频率始终介于 0 与音频信号采样率的一半之间。
- 1024
- 2048
- 4096
- 8192
- 16384
- 32768
Frequency Weights / weights 定义施加到各频率上的权重的曲线。借助音频频谱的可视化表示，用曲线编辑器编辑该曲线。数值为 0 会取消该频率参与输出，而更高的数值会增强该频率
Axis Type / axis_type 选项 对数 频谱是以对数还是线性尺度显示。由于大多数频率都相当低，设为对数能给较低频率更多空间。注意更改轴类型时频率曲线不会被调整。
- 线性
- 对数
Threshold / threshold 浮点 0 振幅低于该值的频率不会计入最终的加权平均
Multiplier / multiplier 浮点 10 对输出值施加一个后置乘数
Follow Time / followTime 布尔 开 勾选后，音频在被指向的音频源的本地时间上采样。未勾选时，音频在本图层的时间上采样
