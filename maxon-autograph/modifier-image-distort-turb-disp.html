湍流置换

简要说明

湍流置换类似于一个置换修改器，只是它的置换贴图由噪波生成器驱动。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Amount / scale 浮点 2D 10, 10 应用于 uv 贴图上每个像素的 uv 值的缩放系数
Offset / offset 浮点 2D 0, 0 从 uv 贴图每个像素的 u 值中减去的偏移量。它在缩放之后应用
Wrap U / u_wrap 选项 黑色 当 X 坐标超出范围时如何访问源图像
- 黑色
- 钳制到边缘
- 重复
- 镜像
Wrap V / v_wrap 选项 黑色 当 Y 坐标超出范围时如何访问源图像
- 黑色
- 钳制到边缘
- 重复
- 镜像
Warp Method / method 选项 反向 用于应用扭曲的算法。你可能需要把缩放参数乘以 -1 来调整置换贴图的方向
- 正向
- 反向
Supersampling / supersampling 选项 x2 超采样系数。数值越高画质与抗锯齿越好，但渲染更慢
- x1
- x2
- x4
- x8
- x16
Use Map Alpha / multiply_uv_by_source_alpha 布尔 开 勾选后，置换贴图的红色和绿色通道会乘以置换贴图的 Alpha 通道。当红色和绿色通道在 Alpha 为零的位置可能含有非零值时，这很有用。
Bounding Box / rod_mode 选项 合成格式 - 无边界
- 与源相同
- 合成格式
Noise Type / noise_type 选项 Perlin - Perlin：Perlin 噪波
- Simplex：Simplex 噪波
- 单元（F1）
- 单元（F2）
- 单元（F2-F1）
- Voronoise：Voronoise（Inigo Quilez，2014）
Fractal Mode / fractal_mode 选项 FBM - FBM
- 湍流
- 脊状
Ridge Offset / fbm_ridge_offset 浮点 0.7
Seed / seed 颜色 0, 0, 0, 0
Frequency / frequency 浮点 10
Offset / noise_offset 浮点 2D 0, 0
Perspective Offset / perspective_transform 布尔 关 勾选后，偏移量会随每一级倍频递减，以产生透视效果
Scale / noise_scale 浮点 2D 1, 1
Rotation / noise_rotate 浮点 0
Skew / noise_skew 浮点 2D 0, 0
Transform Amount / noise_transform_amount 浮点 1
Slice / slice 浮点 0
Octave Slice Offset / slice_octave_offset 浮点 1 每一级倍频之间切片上的偏移
Octaves / octaves 浮点 1
Octave Offset / octave_translation 浮点 2D 0, 0
Octave Scale / octave_scale 浮点 2D 0.5, 0.5
Octave Rotation / octave_rotation 浮点 0
Attenuation / attenuation 浮点 0.5
Voronoise U / voronoise_u 浮点 0
Voronoise V / voronoise_v 浮点 0
Jitter / noise_jitter 浮点 1
Warp steps / noise_warp_steps 浮点 0 分形域扭曲的步数
Warp amount / noise_warp_amount 浮点 0 分形域扭曲的强度
Curl / curl 布尔 关
Curl Step / curl_step 浮点 100
Curl Amount / curl_amount 浮点 1
Contrast / noise_contrast 浮点 0.25

Gamma / noise_gamma 浮点 1
Invert / noise_invert 布尔 关
Transform / xformGroup 类别 -

Deform / DeformGroup 类别 -
Grade / AdjustGroup 类别 -
