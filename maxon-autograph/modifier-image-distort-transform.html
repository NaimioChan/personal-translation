变换

简要说明

在源图像上应用一个变换。这很适合把变换应用在图层的源上，让变换发生在其他修改器之前；这与图层内置的变换不同，后者是在修改器之后应用的。另一种做法是勾选图层的修改器前变换选项，效果相同。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Transform / transform -
Motion-Blur Settings / motionBlurSettings 选项 禁用 - 禁用：为此变换禁用运动模糊
- 使用合成设置：使用合成的运动模糊质量与快门设置
- 自定义设置：运动模糊质量与快门设置只作用于该图层
Motion-Blur Quality Mode / quality_mode 选项 自适应 决定运动模糊计算中的采样数。自适应会根据元素的速度使用变化的采样数。在这种模式下，运动模糊质量充当自适应采样数的乘数。采样数则使用用户提供的采样数量。
- 自适应
- 采样数
Samples Count / motion_blur_nb_samples 浮点 90 用于处理运动模糊的采样数。数值越高画质越好，但渲染越慢。0 会禁用运动模糊。
Motion-Blur Quality / motion_blur_quality 浮点 0.6 自适应运动模糊采样的质量。0 会禁用运动模糊。它充当由自适应模式确定的采样数的乘数。
Shutter Angle / shutter_angle 浮点 180 快门角度控制光线可以通过的时间段。角度越大，运动模糊越强
Shutter Phase / phase_type 选项 居中 - 居中：快门在当前时间之前半个快门时长打开，在当前时间之后半个快门时长关闭
- 起始：快门在当前时间打开，经过快门时长后关闭
- 结束：快门在当前时间减去快门时长时打开，在当前时间关闭
- 自定义：快门在由自定义相位确定的时间打开：相位是快门角度上的偏移量，假定快门在 0 处打开
Custom Phase / custom_phase 浮点 -90 快门角度上的偏移量，假定快门在 0 处打开：快门角度为 180、相位为 -90 时，意味着快门会在半个帧内打开，并以当前时间为中心
