降噪

简要说明

这个修改器可用于去除图像中的噪波，以及/或增强细节。每个通道的噪波水平会按各频带从图像中分析得出，并假定噪波为高斯且可加。对于斑点噪波或椒盐噪波，中值模糊可能更合适。

首先点击「分析图像」，它会计算并设置噪波水平。如果图像中有很多细节丰富的区域，最好选择一个颜色平坦、不含任何细节的区域来分析，以免把细节当作噪波。可以用分析区域来精确指定要分析的像素。分析区域的一个实用例子，是取边缘检测的反相并加以钳制，使边缘附近的所有像素值都为 0：这样就能得到图像中所有平坦区域的遮罩。

如果图像中没有足够大的平坦区域，应考虑降低低频频带与极低频频带的增益，因为它们的数值可能无法被正确估计。

细节数量参数可用于检查降噪后保留了哪些细节。你可以把它设成一个较高的数值，调整噪波水平增益，使图像中不再残留噪波，然后再把它重置回 0。

另一种检查原图中被移除了哪些内容的方式，是把输出模式设为噪波：如果图像细节保留得太多，就必须调整各参数，直到只看到噪波为止。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 关 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Output Mode / output_mode 选项 结果 - 结果：输出降噪后的图像
- 噪波：只输出噪波。如果图像中能看到图像的细节，说明由于噪波水平/增益过高，降噪参数移除了过多图像细节
- 细节：输出一张只包含图像细节的图像。如果图像中能看到噪波，说明降噪参数并非最优，会产生有噪波的结果
Color Model / color_model 选项 YCbCr - CIE Lab
- 伽马校正 RGB
- 线性 RGB：直接处理原始的线性 RGB 分量。仅在降噪非彩色像素时有用
- YCbCr：输出降噪后的图像
Decomposition Method / decomposition_mode 选项 样条 更改信号分解方式，这会影响噪波水平
- 拉格朗日
- 样条
Analysis Region / analysisMask 图像 - 只有分析区域内的像素会被纳入噪波水平分析
Analyze Image / analysisButton 按钮 关 根据当前图像估计噪波水平。可以用分析区域来指定分析噪波水平的区域
Noise Levels / noiseLevelsGroup 类别 -
Y Level (High) / y_noise_level_0 浮点 0
Cb Level (High) / cb_noise_level_0 浮点 0
Cr Level (High) / cr_noise_level_0 浮点 0
Alpha Level (High) / a_noise_level_0 浮点 0

Cb Level (Medium) / cb_noise_level_1 浮点 0

Alpha Level (Medium) / a_noise_level_1 浮点 0
Y Level (Low) / y_noise_level_2 浮点 0
Cb Level (Low) / cb_noise_level_2 浮点 0

Cr Level (Very Low) / cr_noise_level_3 浮点 0
Alpha Level (Very Low) / a_noise_level_3 浮点 0
Noise Levels Gain / noise_level_gain 浮点 1 应用于所有噪波水平的全局增益
Denoise Amount / denoise_amount 浮点 1 要去除多少噪波。1 会移除低于噪波水平所定义阈值的所有内容，0 保留全部噪波，但可用于给图像增加更多细节。介于 0 与 1 之间时会对阈值做插值
High Freq. Gain / gain_level_0 浮点 1 应用于该特定频带的增益。可以设为 0 来禁用该频带的降噪
Medium Freq. Gain / gain_level_1 浮点 1 应用于该特定频带的增益。可以设为 0 来禁用该频带的降噪
Low Freq. Gain / gain_level_2 浮点 1 应用于该特定频带的增益。可以设为 0 来禁用该频带的降噪
Very Low Freq. Grain / gain_level_3 浮点 1 应用于该特定频带的增益。可以设为 0 来禁用该频带的降噪
Analysis Radius / adaptative_radius 浮点 4 用于分析信号水平的窗口半径。如果为 0，则从整张图像计算信号水平。当图像中有很多平坦区域时，这可能导致边缘被过度模糊
Per-Channels Controls / perChannelGroup 类别 -
Y Gain / y_gain 浮点 1 应用于该通道水平的增益。0 表示不降噪。设为 1 时使用估计出的噪波水平，并乘以各频带增益与全局噪波水平增益
Y Denoise Amount / y_amount 浮点 1 该通道要去除多少噪波。1 会移除低于噪波水平所定义阈值的所有内容，0 保留全部噪波，但可用于给图像增加更多细节。介于 0 与 1 之间时会对阈值做插值。该数值会与全局降噪量相乘。噪波水平会先乘以各频带增益、通道增益与全局噪波水平增益
Cb Gain / cb_gain 浮点 1 应用于该通道水平的增益。0 表示不降噪。设为 1 时使用估计出的噪波水平，并乘以各频带增益与全局噪波水平增益

Cr Gain / cr_gain 浮点 1 应用于该通道水平的增益。0 表示不降噪。设为 1 时使用估计出的噪波水平，并乘以各频带增益与全局噪波水平增益
Cr Denoise Amount / cr_amount 浮点 1 该通道要去除多少噪波。1 会移除低于噪波水平所定义阈值的所有内容，0 保留全部噪波，但可用于给图像增加更多细节。介于 0 与 1 之间时会对阈值做插值。该数值会与全局降噪量相乘。噪波水平会先乘以各频带增益、通道增益与全局噪波水平增益
Alpha Gain / a_gain 浮点 1 应用于该通道水平的增益。0 表示不降噪。设为 1 时使用估计出的噪波水平，并乘以各频带增益与全局噪波水平增益
Alpha Denoise Amount / a_amount 浮点 1 该通道要去除多少噪波。1 会移除低于噪波水平所定义阈值的所有内容，0 保留全部噪波，但可用于给图像增加更多细节。介于 0 与 1 之间时会对阈值做插值。该数值会与全局降噪量相乘。噪波水平会先乘以各频带增益、通道增益与全局噪波水平增益
Details Amount / sharpen_amount 浮点 0 要向图像中补回多少细节。只有高于噪波水平的像素才被视为细节，并受增益参数影响。例如，如果全局噪波水平增益设为 0，那么噪波会像信号一样被视为细节。如果全局噪波水平增益设为 1，则只增强原始信号。要在不降噪的情况下增强细节，请把降噪量参数设为 0
Details Size / sharpen_size 浮点 10 数值越高，越会增强图像中平滑区域的细节
Only Y Details / sharpen_luminance 布尔 关 只增强亮度的细节，以避免颜色上出现伪影
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
