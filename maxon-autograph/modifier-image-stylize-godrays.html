神光

简要说明

沿一条由累积变换定义的路径对图像取平均。通过设置缩放与位置参数，可以用它创建曙暮光（也称神光）：缩放决定光线的长度，位置应设为太阳或光源所在处（可以位于图像之外）。这也可用于为带有 Alpha 通道的元素（例如文本）添加长阴影。它还能用固定数量的采样创建方向模糊，这与使用自适应采样方式的方向模糊不同。

控件

Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Position / center 浮点 2D 0, 0
Scale / scale 浮点 2D 1, 1
Anchor Point / center_offset 浮点 2D 0, 0
Rotation / rotate 浮点 0
Skew / skew 浮点 2D 0, 0
Skew Order / skew_order 选项 XY - XY
- YX
Invert Transform / invert 布尔 关
Amount / amount 浮点 1
Centered / centered 布尔 关
From Color / from_color 颜色 1, 1, 1, 1
To Color / to_color 颜色 1, 1, 1, 1
Gamma / gamma 颜色 1, 1, 1, 1
Steps / steps 浮点 5 数值越高，采样越多、质量越好，但渲染更慢

- 最小值：使用沿累积向量的最小强度
- 最大值：使用沿累积向量的最大强度

- 线性（平均 Alpha）
- 线性（堆叠 Alpha）
Crop To Composition Format / crop_source_to_comp 布尔 开 在处理与合成同等大小的较大模糊、并且不在意合成之外的强度是否被正确模糊时，可用于提升性能
Mask / mask 图像 -
