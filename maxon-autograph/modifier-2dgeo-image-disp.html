图像置换

简要说明

根据图像强度沿路径置换点

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Displacement Map / uv 图像 - 用于置换路径点的贴图。强度为 0.5 时不会置换路径。趋向 0 时，强度会给点施加负向偏移；趋向 1 时则施加正向偏移。
Subdivide Steps / subdivide_steps 浮点 3 每个现有分段会被分成「细分步数 + 1」个新分段
Subdivide Threshold / subdivide_threshold 浮点 1 每个新分段的最小长度
Amplitude / amplitude 浮点 2D -10, 10
Use UV Red Channel for Y / use_uv_red_for_xy 布尔 关 未勾选时，置换图像的红色分量会影响路径的 X 分量，置换图像的绿色分量会影响路径的 Y 分量；勾选后，两个分量都只受图像的红色通道影响。
Follow Normals / follow_normal 布尔 关 勾选后，置换会沿路径法线方向进行
