矩形

简要说明

生成一条矩形路径

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Mode / size_mode 选项 中心 + 边缘偏移 - 中心 + 边缘偏移：矩形由其中心点和每条边的 4 个偏移定义
- 中心 + 尺寸：矩形由其中心点和尺寸定义
- 左上 + 右下：矩形由其左上角点和右下角点定义
Center / center 浮点 2D 0, 0
Edge Offset / edge_offset -100, -100, 100, 100
Size / size 浮点 2D 200, 200
Top Left / top_left 浮点 2D -100, 100
Bottom Right / bottom_right 浮点 2D 100, -100
Top Left Radius / rad_tl 浮点 2D 0, 0
Top Right Radius / rad_tr 浮点 2D 0, 0
Bottom Right Radius / rad_br 浮点 2D 0, 0
Bottom Left Radius / rad_bl 浮点 2D 0, 0
Rotation / rotation 浮点 0
