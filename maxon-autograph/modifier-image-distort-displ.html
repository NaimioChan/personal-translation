置换

简要说明

根据置换贴图图像对源图像进行置换。置换贴图为每个像素指明一个偏移量，即输出图像中像素要移动到的位置。贴图的红色通道用作像素 X 坐标的偏移，绿色通道用作 Y 坐标的偏移。如果勾选了使用贴图 Alpha，置换贴图的红、绿通道会乘以该置换贴图的 Alpha 通道。当红、绿通道在 Alpha 为 0 的位置可能含有非零数值时，这很有用。置换贴图各像素的数值被假定归一化在 [0,1] 范围内：

  • 数值为 1 会让像素偏移源图像尺寸的一半
  • 数值为 0 会让像素偏移负的半个尺寸
  • 数值为 0.5 会让像素保持原位置

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Displacement Map / uv 图像 - 该效果会读取前 2 个通道（即红与绿），分别作为 X 与 Y 坐标
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Amount / scale 浮点 2D 10, 10 应用于 uv 贴图每个像素 uv 值的缩放系数
Offset / offset 浮点 2D 0, 0 从 uv 贴图每个像素的 u 值中减去的偏移量。它在缩放之后应用
Wrap U / u_wrap 选项 黑色 当 X 坐标超出边界时如何访问源图像
- 黑色
- 钳制到边缘
- 重复
- 镜像
Wrap V / v_wrap 选项 黑色 当 Y 坐标超出边界时如何访问源图像
- 黑色
- 钳制到边缘
- 重复
- 镜像
Warp Method / method 选项 反向 用于应用变形的算法。你可能需要通过把缩放参数乘以 -1 来调整置换贴图的方向
- 正向
- 反向
Supersampling / supersampling 选项 x2 超采样系数。数值越高，质量与抗锯齿越好，但渲染越慢
- x1
- x2
- x4
- x8
- x16
Use Map Alpha / multiply_uv_by_source_alpha 布尔 开 勾选后，置换贴图的红、绿通道会乘以该置换贴图的 Alpha 通道。当红、绿通道在 Alpha 为 0 的位置可能含有非零数值时，这很有用。
Depth Map / depth_map 图像 - 如果连接到生成器，且方法设为正向，则红色通道用于给像素赋一个深度，以控制像素的 z 顺序。如果未连接，默认顺序为顶点顺序，即从左到右、从下到上。
Source Outside / forward_fill_outside_with_source 布尔 关 如果方法设为正向，则用原始源图像填充未受置换影响的区域
Fitting / uv_fit 选项 不拟合 - 不拟合
- 将源适配到 UV 贴图
- 将 UV 贴图适配到源
Bounding Box / rod_mode 选项 合成格式 - 无边界
- 与源相同
- 合成格式
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
