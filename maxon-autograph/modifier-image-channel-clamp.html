钳制

简要说明

把图像中的像素值限制在一个范围内。如果启用了最小值，低于最小值的数值会被设为最小值。如果启用了最小值数值，这些数值会被改设为该数值而不是最小值。例如，这可以把所有低于 0 的值变成 1。

如果启用了最大值，高于最大值的数值会被设为最大值。如果启用了最大值数值，这些数值会被改设为该数值而不是最大值。例如，这可以把所有高于 1 的值变成 0。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Minimum Enabled / minimum_enabled 布尔 开 启用下限钳制
Minimum / minimum 颜色 0, 0, 0, 0 下限钳制值
Maximum Enabled / maximum_enabled 布尔 开 启用上限钳制
Maximum / maximum 颜色 1, 1, 1, 1 上限钳制值
Enable Min Value / min_clamp_value_enabled 布尔 关 勾选后，所有低于最小值的数值会被钳制到最小值数值；未勾选时，所有低于最小值的数值会被钳制到最小值。
Min Value / min_clamp_value 颜色 0, 0, 0, 0 勾选启用最小值数值后，低于下限的非法数值会被钳制到该数值。这会把被钳制的区域设成自定义颜色，便于观察钳制范围或制作图形效果。
Enable Max Value / max_clamp_value_enabled 布尔 关 勾选后，所有高于最大值的数值会被钳制到最大值数值；未勾选时，所有高于最大值的数值会被钳制到最大值。
Max Value / max_clamp_value 颜色 1, 1, 1, 1 勾选启用最大值数值后，高于上限的非法数值会被钳制到该数值。这会把被钳制的区域设成自定义颜色，便于观察钳制范围或制作图形效果。
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
