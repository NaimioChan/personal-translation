颜色传递

简要说明

把颜色从参考图像传递到目标图像

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Reference / reference 图像 - 用于传递颜色的参考图像
Reference Mode / ref_frame_mode 选项 静帧 是否使用指定时间码上的静帧，或者逐帧更新参考
- 静帧
- 动画
Reference Still Frame / ref_ref_frame 时间 0 用作参考的帧时间码
Target Mode / target_frame_mode 选项 动画 是否使用指定时间码上的静帧，或者逐帧更新参考
- 静帧
- 动画
Target Still Frame / target_ref_frame 时间 0 用于计算传递的帧时间码。所有其他帧都会应用相同的传递函数
Cross-Correlation / cross_matching 浮点 0.5 用于匹配输入图像分布的互相关系数
Refine Iterations / distribution_matching_order 浮点 0 通过迭代调整数据的高阶特征来匹配源通道的颜色分布
Auto Saturation / auto_saturation_shift 布尔 关 勾选后，饱和度混合会自动计算为原图中最大饱和度值与目标图中最大饱和度值之比
Saturation Mix / saturation_shift 浮点 1 在原图与处理后图像之间混合饱和度
Shading / shading_shift 浮点 0.5 在 1 处的完全传递与 0 处的目标明暗之间混合明暗传递
Match Luminance / match_luminance 布尔 关 勾选后，使用原图中的亮度分布来调整目标图像
Add Original Luminance / enable_add_original_luminance 布尔 关 勾选后，原图亮度会被加到输出图像上。这有助于保留过亮值（大于 1 的数值）
Original Luminance Strength / mult_original_luminance 浮点 0.2 勾选添加原始亮度时，与原亮度相乘的系数
Output Saturation / tint_shift 浮点 1 把输出图像与其灰度版本混合。1 为全彩，0 为灰度
Reference Mask / reference_mask 图像 - 对参考帧应用遮罩，使处理过程中只考虑遮罩内的区域
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
