界面与面板

主面板

Autograph 的界面由四个主面板组成：

  • 项目面板：用于创建、导入和管理项目中使用的所有资源
  • 查看器：可以连接到不同的图形源并对它们进行可视化预览
  • 检查器：由选择概览和属性两部分组成，便于快速访问参数
  • 时间轴：可以组合与动画化各种元素

其他面板，例如 Python 控制台、渲染管理器和文本面板，也可以在“面板”菜单中找到。

界面最顶部是菜单栏，可以在此打开欢迎界面、显示面板、管理工作区和软件设置，以及查看错误信息或更一般的信息。

新建面板

界面上方主菜单栏中的“面板”菜单可以显示面板或新建面板，也可以使用每个面板右上角的选项菜单。
要新建面板，只需点击菜单按钮，选择“面板”，然后选择要添加的面板类型。

默认情况下，新面板会作为选项卡置于当前面板中，此时多个面板就同处于一个容器内。

注意：部分面板，例如渲染管理器和文本面板，只能存在一个实例；而其他面板，例如时间轴和查看器，可以无限添加。

移动面板

要移动面板，按住鼠标左键点击其名称，并在界面上拖动。

  • 蓝色区域可以预览松开鼠标按键后面板的最终位置。
  • 如果把面板移到窗口的某一侧，会出现一条绿色条，指示面板将占满高度还是占满宽度。

关闭面板或容器

使用面板菜单，你可以：

  • 关闭当前面板
  • 关闭所有面板
  • 关闭其他面板（保留当前面板）
  • 关闭容器

拆分与取消停靠面板

面板可以被一分为二，也可以从主窗口中分离出来，这样可以跨多块屏幕组织工作区。
这些选项同样位于面板菜单中：

  • 取消停靠面板：把当前面板放到新的浮动窗口中，例如放到第二块屏幕上。
  • 取消停靠容器：把当前容器放到新的浮动窗口中。
  • 左右拆分：沿垂直方向把一个容器拆成两个。
  • 上下拆分：沿水平方向把一个容器拆成两个。

注意：要把浮动的面板移回并重新连接到主窗口，只需按上文所述通过其标题栏拖动即可。

最小化与最大化面板

该菜单还包含把面板放大至整个界面，或最小化到占用尽可能少空间的选项。

此外还有若干快捷键：

最大化

  • 按 ctrl/cmd + space（同一快捷键也用于返回完整工作区）
  • 双击标题栏左上角的面板图标（再次双击可恢复初始状态）

最小化

要最小化面板，可以缩小其尺寸，直到它只剩一行。

也有若干快捷键可用：

  • ctrl + shift space：折叠/展开面板
  • ctrl/cmd + 双击标题栏左上角的面板图标可将其折叠
  • 单击面板图标即可将其展开

将面板切换为全屏模式

每个面板的最上方都有一个显示器图标。点击它并选择两个选项之一，当前面板就会切换到全屏模式：

  • 全屏（适应）：如果要渲染的图像分辨率高于或低于屏幕分辨率，它会缩放到完全可见。
  • 全屏（100%）：渲染图像的每个像素对应屏幕上的一个像素。视要渲染的图像分辨率而定，它可能小于屏幕，也可能只能部分可见。
  • 显示查看器界面：是否在渲染图像上显示界面元素（控件、叠加层等）

注意：如果你有多块屏幕，切换到此模式时面板所在的那块屏幕就是所使用的屏幕。

重命名面板

双击面板名称即可重命名面板。在由单个合成输出多种格式的响应式设计项目中，把这些查看器命名为 Vertical 9/16、Social 4/3 或 FullHD 会非常有用。
