时间轴

时间轴是界面面板之一，可以在这里按时间顺序放置和可视化不同的元素。每个元素由称为“图层”的一行表示，它们共同构成一个图层堆栈。

两个关键部分

时间轴面板分为两个主要部分：

  • 图层堆栈，位于左侧
  • 摄影表，位于右侧（默认可见，稍后我们会介绍其他可用模块）

可以点击分隔条并左右拖动，来调整这两个部分占用的空间。

时间轴控制器

以下是时间轴控制器第一行的说明：

  • 一个 + 按钮，用于向堆栈添加新图层。它可以是生成器、Null 图层、调整图层或 3D 对象。新图层会添加在当前选区之上。该菜单的内容也可以在快速访问菜单中找到。
  • 一个槽位，可以调出项目面板中所有现有合成的列表；你可以把其中一个指定给当前时间轴、断开当前的合成、新建一个合成，或显示当前合成的属性。
  • 当时间轴连接到子合成时，用于在父合成中上移一级的按钮（page-up 或 ctrl + alt + up）。
  • 用于通过下拉菜单跳入当前堆栈中使用的某个子合成的按钮，如果只有一个子合成则直接跳入。（page-down 或 ctrl + alt + down）。
  • 一个与合成槽位类似的槽位，但专门用于音频混音。
  • 一个切换开关，用于选择摄影表中时间信息的显示方式（帧号或时间码）

正下方是：

  • 一个时间控制器，包含时间码和帧计数器，用于显示或输入摄影表中播放头的位置。

多个时间轴与查看器

你可以使用顶部栏中的面板 > 时间轴 > 新建时间轴菜单，直接向工作区添加新面板，从而同时显示多个时间轴。你可以移动这个新面板到想要的位置，并从列表中选择想查看的合成。

你甚至可以显示两个或多个指向同一合成的时间轴。这样就能查看堆栈的不同部分或摄影表中的不同时间。

把时间轴分配给查看器：

当屏幕上显示两个查看器和两个时间轴时，确定哪个时间轴控制哪个查看器就很重要。每个查看器底部都有一个时间轴选择器，如下所示：

该选择器列出了屏幕上所有可见的时间轴。你可以用它选择由哪个时间轴的当前时间决定某个查看器中渲染的图像。

注意：某个时间轴所连接的合成不一定与通过查看器顶部的选择器连接到查看器的那个合成相同。这样可以同时以多种格式渲染同一合成，也可以用同一个时间轴驱动渲染多个合成。

填充堆栈：

在左侧的堆栈中，可以按照图层堆叠的原理堆叠元素。
要向堆栈添加新图层，你可以：

  • 把源从项目面板拖到堆栈中
  • 点击时间轴左上角的+按钮
  • 复制/粘贴现有图层（也可以在同时打开的两个 Autograph 项目之间进行）

选择和重排图层：

选择图层与在文件浏览器中选择文件的过程类似，只有一些细微差别：

  • 单击只选中一个图层
  • 按住 ctrl/cmd 键可以逐个把图层加入当前选区
  • 按住 shift 键可以选中两次点击之间的成组图层
  • 按 up 或 down 键可以把选区在堆栈中上移或下移一级。

注意：比其他图层更亮的那个图层是活动图层。

选择顺序：

按住 ctrl/cmd 并点击图层时，选择顺序会被保留。当你想复制/粘贴或制作副本一组图层时，点击顺序会决定新图层的堆叠顺序。
使用 shift 键时也是如此：

  • 从下往上选择会保留当前顺序
  • 从上往下选择会相对原图层反转新图层的顺序

当前堆栈中的所有图层都可以：

  • 按 ctrl/cmd + a 来全选
  • 按 ctrl/cmd + shift + a 来取消选择。

注意：按下 ctrl/cmd + a 时，选择顺序定义为从上到下。因此如果你复制/粘贴这些图层，原有的堆叠顺序会被保留。

重排图层：

  • 要在堆栈中把选中的图层上移或下移，点击并拖动它们来重排堆栈
  • 要上移或下移一个图层，右键单击 > 操作：
    • 上移图层（ctrl + shift + up）
    • 下移图层（ctrl + shift + down）

在时间轴中导航

由于 Autograph 可在 Windows、Mac 和 Linux 上使用，必须照顾到所有不具备相同键盘快捷键策略的系统。视所用的鼠标或数位板而定，某些组合在某些系统上有时更易使用。
因此同一个操作提供了多个快捷键：

滚动堆栈：

  • 使用 "Mouse wheel"
  • 按 middle-button

也可以使用右侧的滚动条。

在摄影表中移动：

  • 平移：

    • space + left-button
    • middle-button
    • alt/opt + left-button

  • 缩放：

    • alt/opt + "Mouse wheel"
    • ctrl/cmd + alt/opt + left-button
    • f 键用于适应当前选区，如果未选中任何内容则适应合成时长

警告：Autograph 中的快捷键与上下文和鼠标位置相关。这些快捷键在你的鼠标光标位于时间轴上时有效。

模块与工具

摄影表默认位于时间轴的右侧部分。这个模块可以让你管理合成元素的时间。

  • 每个图层由一个区块表示，只需点击并拖动即可移动它
  • 摄影表也是参数已做动画时选择和移动关键帧的地方

时间轴的右侧部分可能因所用模块和侧面板而异。
标题栏右上角的按钮可以让你在不同模块之间切换，或显示名为停靠的附加面板：

这个标题栏中的按钮从左到右依次为：

  • 多编辑模式选择器

  • 关键帧属性停靠面板

  • 父子关系停靠面板

  • 摄影表模块

  • 曲线编辑器模块

  • 适应当前选区，如果未选中任何内容则适应合成时长（f 键）

  • 播放与选项选项

多编辑模式选择器是附属于摄影表的工具之一。切换到曲线编辑器模块会在左侧显示其他工具。

筛选堆栈

堆栈包含许多项目，展开数百个参数会让导航变得困难。Autograph 提供筛选系统，方便访问最常用的参数，或减少堆栈中显示的图层数量。

按名称筛选图层：

堆栈底部有一个字段用于定义字符串。如果这个字符串能在某个图层的名称中找到——无论在开头、中间还是结尾——该图层就会始终可见。所有不包含这个字符串的图层会从堆栈中隐去，但 Autograph 仍会用它们来计算查看器中可见的图像。

图层名称中的这个字符串会以绿色高亮显示：

只要有任何筛选器处于活动状态——无论是名称搜索还是下面介绍的其他筛选器——堆栈右下角就会出现一个红色 X。
点击它或按 alt/opt + f 可以移除应用到堆栈的所有筛选器。

注意：使用筛选器时，你可能还会注意到堆栈左侧的图层编号中缺少一些序号。这也是当前正在使用筛选器的另一个提示。

筛选器快捷键

在堆栈中选中若干图层后，你可以应用筛选器，只显示该选区的某些参数。如果未选中任何内容，则影响所有图层。这些筛选器可以累加，也可以不累加。
要在现有筛选器上再添加一个，只需在菜单中按住 shift 键，或使用快捷键。不按该键时，添加新筛选器会移除之前的筛选器。

筛选包含关键帧的图层：

点击堆栈右下角的菱形，只会显示包含关键帧的参数。该操作的快捷键是 u。

提示：对同一个筛选器再按一次它所对应的键会删除该筛选器。所以按两次 u 可以先显示再隐藏关键帧。这个提示适用于所有筛选器。

按参数类型筛选图层：

在关键帧筛选器按钮旁边，有一个下拉菜单可以访问变换参数筛选器以及附加选项。

  • 变换：显示并展开所有变换参数。快捷键是 t
  • 位置：快捷键是 p
  • 旋转：快捷键是 r
  • 缩放：快捷键是 s
  • 锚点：快捷键是 a
  • 倾斜：快捷键是 d，取自“deform”
  • 不透明度：快捷键是 o
  • 强度：快捷键是 w，取自“weight”，
  • 可见：快捷键是 v
  • 混合模式：快捷键是 b

折叠/展开图层和参数

按快捷键 e，可以折叠或展开选中的图层。

在此过程中，如果你之前展开过特定参数，例如图层的源，Autograph 会记住展开过哪些参数。这样你可以先折叠图层以在堆栈中腾出更多空间，再展开它并回到相同的查看配置。
