样条变形

简要说明

根据你在查看器中创建的定位钉和图形来变形图像。

说明

图像变形修改器为用户提供了一整套工具，用来对给定的图形源进行变形、扭曲和弯折。这些工具（即模式）既可用于小范围的变形，也可用于大范围的变形。

双定位钉

双定位钉是图像变形工具集中最基本的工具。它用于执行单个“点对点”变形。

双定位钉的设计让用户可以把图形源上的一个点从源位置拖到目标位置。

按下鼠标右键，会在光标位置创建一个源定位钉。然后按住鼠标按键，即可把目标定位钉拖过图像，并在所需位置释放。输入的图像会实时变形，这便于对某个区域做局部的实时修正。

样条变形

样条变形用于通过把一个源图形组变形到一个目标图形组来扭曲图像。与图形生成器类似，这些图形组可以用图形专用工具创建和编辑，只要该模式处于激活状态，这些工具就会出现在垂直工具栏中。

它的实现方式是沿源路径生成固定数量的源定位钉，并在目标路径上生成对应的目标定位钉。定位钉的数量由分辨率参数决定。

流动变形

流动变形沿一条路径使图形源变形。与样条变形类似，流动变形基于一个几何组；这个几何组定义驱动变形的路径。

在内部，流动变形由沿同一条路径分布的一系列源和目标定位钉组成，其中目标定位钉在曲线上偏移一定的距离。

此外，我们还提供两个额外的锚定模式。它们用于消除给定区域内任何变形的效果。

固定定位钉

固定定位钉用于指定图形源中不应受变形影响的区域。

固定定位钉与源和目标定位钉位置重合的双定位钉基本相同。

边界样条

边界样条所定义的边界可以阻止样条一侧的任何变形传递到另一侧。实际上，这个模式可以把变形限制在特定区域内。

边界样条的工作方式是在所定义的路径上设置一系列固定定位钉。

启用后，硬边界选项会在图形组之外创建裁剪遮罩，从而只保留图形组内部的变形。

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Warp Pins / PinList - 变形定位钉的列表
Global warping / scale 浮点 1 应用于变形向量的归一化变形倍数。适合用来（整体）动画变形。
Invert Vectors / invert 布尔 关 反转所有变形向量的方向。用于获得反向的变形
Resolution / resolution 浮点 50 沿基于曲线的变形生成点的频率
Pins Transform / pin_transform - 应用于所有定位钉的变换。这便于用跟踪器让定位钉跟随对象的运动
Borders / bordersWarp 选项 合成格式 定义输入边缘的行为。
- 边界框：输入的边界将保持固定。该操作会沿输入边界引入固定点。推荐用于大多数情况。
- 合成格式：输入的角点将保持固定。该操作会在输入的每个角点引入四个固定点。边缘仍会受到变形影响
- 合成角点：输入的角点将保持固定。该操作会在输入的每个角点引入四个固定点。边缘仍会受到变形影响
- 无：不定义固定边。建议手动放置至少 3 个固定点。
Wrap U / u_wrap 选项 黑色 当 X 坐标超出范围时如何访问源图像
- 黑色
- 钳制到边缘
- 重复
- 镜像
Wrap V / v_wrap 选项 黑色 当 Y 坐标超出范围时如何访问源图像
- 黑色
- 钳制到边缘
- 重复
- 镜像
Supersampling / supersampling 选项 x2 超采样系数。数值越高画质与抗锯齿越好，但渲染更慢
