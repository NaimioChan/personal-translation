向量模糊

简要说明

使用运动向量为图像应用运动模糊

控件

参数 / 脚本名 类型 默认值 说明
Enabled / enabled 布尔 开
Red / process_red 布尔 开 在输出中启用红色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Green / process_green 布尔 开 在输出中启用绿色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Blue / process_blue 布尔 开 在输出中启用蓝色通道。否则，如果存在源，则返回主源的内容，否则返回 0
Alpha / process_alpha 布尔 开 在输出中启用 Alpha 通道。否则，如果存在源，则返回主源的内容，否则返回 0
Amount / shutter_frames 浮点 0.5 围绕当前帧累积的帧数。如果为 0.5，则累积前后各半帧
Motion-Vectors Source / vector_source 选项 生成 选择是否自动生成运动向量
- 生成
- 自定义
Custom Motion-Vectors / motion_vectors 图像 - 要使用的运动向量。向量模糊要求向量是非归一化的
Alt. Track Source / track_source 图像 - 如果设置了该项，就会用它来生成运动向量，而不是用修改器实际的源。当你在它之前应用了其他可能干扰运动向量跟踪的修改器时，这很有用。一个好做法是把它设为原始（已降噪）的底片。
Motion Estimation / motionEstimation 类别 -
Algorithm / of_algo 选项 Dense Inverse Search - Dense Inverse Search
- Dual TV L1
- PyrLK
- Robust Local
- Farneback
Finest Scale / of_dis_finest_scale 浮点 5 计算光流所用的高斯金字塔最精细层级（零层级对应原始图像分辨率）。最终光流通过双线性放大获得。
Patch Size / of_dis_patch_size 浮点 8 用于匹配的图像块尺寸（以像素为单位）。通常默认的 8x8 图像块在大多数情况下已足够好。
Patch Stride / of_dis_patch_stride 浮点 3 相邻图像块之间的步长。必须小于图像块尺寸。数值越低，光流质量越高。
Descent Num. Iterations / of_dis_gradient_descent_iters 浮点 25 图像块逆搜索阶段中梯度下降迭代的最大次数。某些情况下数值越高可提升质量。
Refinement Num. Iterations / of_dis_var_refinement_iters 浮点 5 每个尺度上变分细化的不动点迭代次数。设为 0 可完全禁用变分细化。数值越高通常能得到更平滑、更高质量的光流。
Refinement Smoothness Weight / of_dis_var_refinement_alpha 浮点 20 平滑项的权重
Refinement Gradient Constancy / of_dis_var_refinement_gamma 浮点 10 梯度恒常项的权重
Refinement Color Constancy / of_dis_var_refinement_delta 浮点 5 颜色恒常项的权重
Robust To Illumination Changes / of_dis_use_mean_propagation 布尔 开 计算图像块距离时是否使用图像块的均值归一化。它默认启用，因为对光照变化更稳健，通常能带来明显的质量提升。如果你确定序列中不含任何光照变化，可以关闭它。
Spatial Propagation / of_dis_use_spatial_propagation 布尔 开 是否对优质光流向量使用空间传播。该选项默认启用，因为平均而言效果更好，有时还能帮助从由粗到细方案引入的重大错误中恢复。关闭该选项可以让输出的光流场略微更平滑
Time Step (Tau) / of_dualtvl1_tau 浮点 0.25 数值方案的时间步长
Attachment Weight / of_dualtvl1_lambda 浮点 0.15 数据项的权重参数，即附着参数。这是最相关的参数，决定输出的平滑程度。该参数越小，得到的解越平滑。它取决于图像的运动幅度，因此其数值应针对每个图像序列加以调整。
Tightness Weight / of_dualtvl1_theta 浮点 0.15 附着项与正则项之间的联系。理论上它应取较小值，以保持两部分相互对应。该方法在该参数很大范围的取值下都稳定。
Pyramide Size / of_dualtvl1_nscales 浮点 5 用于创建图像金字塔的尺度数量
Num. Warps / of_dualtvl1_warps 浮点 5 每个尺度上的变形次数。这能保证方法的稳定性。数值越高越精确，但速度越慢
Error Tolerance / of_dualtvl1_epsilon 浮点 0.01 数值方案中使用的停止准则阈值，它在精度与运行时间之间取舍。较小的数值会得到更精确的解，但收敛更慢。
Inner Iterations / of_dualtvl1_inner_iter 浮点 30 过滤离群值时使用的迭代次数
Outer Iterations / of_dualtvl1_outter_iter 浮点 10 数值方案中使用的迭代次数
Scale Step / of_dualtvl1_scale_step 浮点 0.8 金字塔各尺度之间的步长
Median Filter Size / of_dualtvl1_median_filter_size 浮点 5 中值滤波核的尺寸（1 = 不滤波）。必须为 1、3 或 5
Grid Step / of_pyrlk_grid_step 浮点 8
Nearest Neightboors Matches / of_pyrlk_k 浮点 128
Preserve Details / of_pyrlk_sigma 浮点 0.05
Smooth Filter / of_pyrlk_use_post_proc 布尔 开
Smooth Amount / of_pyrlk_fgs_lambda 浮点 500
Smooth Sigma / of_pyrlk_fgs_sigma 浮点 1.5
Use Cross-Segmentation / of_rlof_use_cross_segmentation 布尔 开 启用时，使用由交叉分割得到的自适应支持区域，以提升运动边界处的精度
Use Bilinear Solver / of_rlof_bilinear_solver 布尔 开 勾选后，使用基于双线性解的优化迭代细化
Use M-estimator / of_rlof_use_mestimator 布尔 关 勾选后，启用 M 估计器，这可能提升精度，但会增加运行时间
Small Win Size / of_rlof_small_win_size 浮点 9 启用交叉分割时支持区域的最小窗口尺寸
Large Win Size / of_rlof_large_win_size 浮点 21 支持区域的最大窗口尺寸。窗口尺寸越小，运行越慢，但对噪波越敏感
Segmentation Similarity Threshold / of_rlof_cross_segmentation_thr 浮点 25 启用交叉分割时使用的颜色相似度阈值
Pyramid Size / of_rlof_max_level 浮点 4 使用的金字塔层级最大数量。该数值越大，越有可能对长距离运动得到准确的解。运行时间与该参数呈线性关系。
Use Illumination Model / of_rlof_use_illum_model 布尔 开 通过使用另一种光照模型，使估计对光照变化更稳健。使用该方法会增加计算复杂度。
Use Global Motion Prior / of_rlof_use_global_motion_prior 布尔 开 使用全局运动初始化，以更准确地表示长距离运动。启用该模式会略微增加计算复杂度
Num. Refinement Iterations / of_rlof_max_iterations 浮点 30 细化迭代的次数。数值越低可减少运行时间，但也会降低精度
Global Motion Threshold / of_rlof_global_motion_ransac_thr 浮点 10 它控制全局运动先验所使用的有效跟踪像素的阈值
Interpolation / of_rlof_interp 选项 保边 用于计算稠密光流场的插值方法
- 测地线
- 保边
- 稳健
Superpixel Algo / of_rlof_ric_slic_type 选项 Segment 控制稳健插值方法所使用的超像素算法
- Segment
- Optimized Segment
- Manifolds
Confidence Threshold / of_rlof_forward_backward_thr 浮点 1 前向/后向置信度检查的阈值。如果大于阈值，插值时就不会使用该运动向量
Grid Step / of_rlof_grid_step 浮点 6 生成运动向量的网格尺寸。由于前向/后向阈值，一些向量会被移除
Edge Aware Nearest-Neighboors / of_rlof_epic_k 浮点 128 拟合局部仿射模型时考虑的最近邻匹配数量。通常应在 128 左右。数值越低，插值越快
Preserve Details / of_rlof_epic_sigma 浮点 0.05 定义局部加权仿射拟合中权重下降的速度。数值越高有助于保留精细细节，数值越低有助于去除噪波
Geodesic Distance Weight / of_rlof_epic_lambda 浮点 999 测地距离中保边项的权重
Superpixel Size / of_rlof_ric_sp_size 浮点 15 用于 RIC 插值模式的超像素尺寸
Smooth Filter / of_rlof_use_post_proc 布尔 开 对光流启用一次全局平滑处理
Smooth Amount / of_rlof_fgs_lambda 浮点 500 全局平滑滤波器应用的正则化量
Smooth Sigma Color / of_rlof_fgs_sigma 浮点 1.5 应用于颜色的平滑量，类似双线性滤波器
Use Refinement / of_rlof_use_variational_refinement 布尔 关 启用光流场的变分细化
Pyramid Num Levels / of_farneback_num_levels 浮点 5 用于估计光流的 mipmap 层级数量
Levels Scale / of_farneback_pyr_scale 浮点 0.5 各金字塔层级之间的缩小系数
Window Size / of_farneback_win_size 浮点 13 平均窗口尺寸；数值越大，算法对图像噪波越稳健，也更容易检测到快速运动，但会产生更模糊的运动场。
Iterations / of_farneback_num_iters 浮点 10 求解器的迭代次数
Neighboorhood Size / of_farneback_polyn 浮点 5 用于求解每个像素的像素邻域尺寸。数值越大意味着图像会用更平滑的曲面来近似，从而得到更稳健的算法与更模糊的运动场。通常该数值应为 5 或 7
Gaussian Sigma / of_farneback_poly_sigma 浮点 1.1 用于平滑导数的高斯标准偏差。邻域尺寸为 5 时，可以把高斯西格玛设为 1.1；邻域尺寸为 7 时，1.5 是个不错的数值。
Use Gaussian / of_farneback_use_gaussian 布尔 关 在估计光流时使用窗口尺寸大小的高斯滤波器，而不是同样大小的盒式滤波器。该选项能得到更精确的光流，但速度较慢。要让高斯窗口达到与盒式滤波器相同的稳健程度，应把窗口尺寸设得更大。
Invert Vectors / invert_mv 布尔 关 勾选后，运动向量会被反转
Motion Vectors Blur / mv_blur 浮点 0 应用于运动向量的模糊，用于平滑运动细节
Interpolation Type / interp_type 选项 贝塞尔 控制运动模糊是沿运动向量按直线还是按贝塞尔曲线累积
- 直线
- 贝塞尔
Max Distance / max_distance 浮点 0 对向量进行钳制，使累积路径不超过该距离。数值为 0 时禁用钳制
Sample Density / sample_density 浮点 1 渲染运动模糊所用采样之间的间距。数值越低质量越高，但渲染可能略慢。
Mask / mask 图像 -
Mix / mix_with_source 浮点 1 在 0（原图）与 1（应用效果后的图像）之间过渡
