UV 贴图

简要说明

把 UV 贴图应用到源图像上。UV 贴图会为输出中的每个像素指明：应当用源图像中哪个坐标位置的像素来填充这个输出像素。贴图的红色通道包含源像素的 X 坐标，绿色通道包含 Y 坐标。UV 贴图像素的取值假定已归一化到 [0,1] 范围，其中坐标 (1,1) 对应源图像的右上角，坐标 (0,0) 对应源图像的左下角。

UV 贴图传统上由 3D 渲染器生成，这样贴图工作就可以在合成阶段完成，而不必由 3D 软件本身来做。对于视频素材，Autograph 提供了UV 贴图生成器，它能借助运动向量分析从视频内容生成 UV 贴图。

注意：在 UV 贴图上使用遮罩时，重要的是遮罩不要以抗锯齿方式渲染在蒙版边缘上。

UV 贴图的遮罩是二值的：像素要么被移动，要么不被移动，而只对边缘像素移动一半距离会产生伪影。如果你想提升输出图像的质量，请使用超采样参数，它能在蒙版边界不产生伪影的前提下正确应用滤波。
