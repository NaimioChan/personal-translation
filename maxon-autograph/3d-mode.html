3D 模式

切换到 3D 模式

任何2D 图层都可以添加 3D 能力，以便与 3D 元素融合。要把图层切换为 3D 模式，只需点击图层主行上的 2D/3D 按钮。

该模式激活时，图层的变换部分会被一个3D 变换部分取代。

激活 3D 模式后显示的变换在视觉上与 2D 模式相近，只是倾斜不再可用，而且参数现在有 3 个维度。
如果在切换模式之前应用过 2D 变换，2D 参数会被转换为 3D 参数：

  • 位置数值从像素转换为 3D 单位。
  • 2D 旋转的数值由旋转 Z参数使用

3D 变换强度

强度参数用来确定变换的影响程度。把该值设为 0 时变换不产生任何效果，图层回到它加入堆栈时的原始位置——也就是合成中心。

注意不必局限在 0-1 区间：

旋转顺序与插值类型

3D 变换部分显示两个新参数：

  • 旋转顺序：在经典插值（使用欧拉旋转定理）激活时使用；它提供 6 种不同的旋转顺序
  • 插值方式：经典、四元数、Arcball

关于如何在 2D 和 3D 中管理变换以及 3D 插值方法的更多信息，请参考选择与移动章节。
