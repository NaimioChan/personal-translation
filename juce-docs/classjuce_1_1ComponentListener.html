juce::ComponentListener 类参考

详细说明

获知组件的层级或位置变化。

要监视组件的变化，请使用 Component::addComponentListener() 向组件注册 ComponentListener 的子类。

删除监听器之前一定要先取消注册！

另见
Component::addComponentListener, Component::removeComponentListener

componentBeingDeleted()

virtual void juce::ComponentListener::componentBeingDeleted (Component & component) virtual

当组件正在被删除时调用。

此回调在析构函数内部发出，因此在这里做什么都要极其谨慎。

尤其要注意，调用它的是 Component 基类的析构函数——因此如果被删除的对象是 Component 的子类，那么执行到这一步时，该对象的子类部分早已析构完毕！

参数
component被删除的组件

componentPainted()

virtual void juce::ComponentListener::componentPainted (Component & component, const ComponentPaintDiagnostics & diagnostics) virtual

每次将组件绘制到上下文中时调用。

每次将组件绘制到图形上下文时，都会调用一次。这可能是直接绘制组件，也可能是绘制组件的缓存图像。要了解关于用户可重写的绘制方法的更详细信息，请参阅 componentPaintMethodsCalled()。

此回调可能在尝试绘制组件时被调用。这意味着此回调中耗费的时间可能会被计入任何父组件的 ComponentPaintDiagnostics 中。因此，应尽量把此回调中的工作保持在最低限度，以免扭曲结果。

重要的是不要依赖此回调的精确时序。唯一的保证是回调会在组件绘制后的某个时间发生（不过该绘制调用的内容可能尚未更新到屏幕上）。

参数
component被绘制的组件
diagnostics用于绘制组件的常规诊断信息
另见
componentPaintMethodsCalled
