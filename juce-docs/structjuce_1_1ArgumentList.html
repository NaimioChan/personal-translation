juce::ArgumentList 结构体参考

详细说明

保存命令行参数列表，并提供用于搜索和操作它们的实用方法。

你可以手动创建 ArgumentList，或从 main() 函数传入一些 argv/argc 值进行解析。

getValueForOption()

String juce::ArgumentList::getValueForOption (StringRef option) const

查找给定参数，并返回其赋给的值（针对长选项）或紧随其后的字符串（针对短选项）。

该选项也可以是用竖线分隔的不同版本列表，例如 "--help|-h"。如果找到长选项，它会查找带 '=' 号的赋值形式，例如 "--file=foo.txt"，并返回 '=' 之后的字符串。如果没有 '='，则返回空字符串。如果找到短选项，它会尝试返回紧随其后的参数，除非那是另一个选项。如果未找到参数，则返回空字符串。

removeValueForOption()

String juce::ArgumentList::removeValueForOption (StringRef option)

查找给定参数，并返回其赋给的值（针对长选项）或紧随其后的字符串（针对短选项）。

其行为类似 getValueForOption()，但也会在找到时从列表中移除选项参数（以及任何值参数）。

getFileForOption()

File juce::ArgumentList::getFileForOption (StringRef option) const

如果未找到该选项，或该值无法解析为文件名，则抛出错误。
