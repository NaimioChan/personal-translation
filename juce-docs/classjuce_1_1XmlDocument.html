juce::XmlDocument 类参考

详细说明

解析基于文本的 XML 文档，并由此创建一个 XmlElement 对象。

解析器将解析 DTD 以加载外部实体，但不会根据 DTD 检查文档的有效性。

例如

XmlDocument myDocument (File ("myfile.xml"));

if (auto mainElement = myDocument.getDocumentElement())
{
    use the element
}
else
{
 String error = myDocument.getLastParseError();
}

或者，你可以使用辅助函数进行更简洁的解析。

if (auto xml = parseXML (myXmlFile))
{
 if (xml->hasTagName ("foobar"))
    {
        ...etc
    }
}

成员函数

getDocumentElement()

std::unique_ptr< XmlElement > juce::XmlDocument::getDocumentElement (bool onlyReadOuterDocumentElement = false)

创建一个 XmlElement 对象以表示主文档节点。

此方法将实际解析文本，如果存在解析错误，可能返回 nullptr（你可以使用 getLastParseError() 方法查明错误）。

另见 parse() 方法，它们提供了快速解析文件或字符串的简写方式。

参数
onlyReadOuterDocumentElement若为 true，解析器将只读取文件的第一部分，并且只返回外层文档元素——这样无需解析整个文件即可快速检查大型文件是否包含正确类型的标签
返回
一个新的 XmlElement，如果出错则为 nullptr。
另见
getLastParseError, getDocumentElementIfTagMatches

getDocumentElementIfTagMatches()

std::unique_ptr< XmlElement > juce::XmlDocument::getDocumentElementIfTagMatches (StringRef requiredTag)

进行一项开销很小的检查，查看外层元素是否具有给定标签名，如果匹配则进行完整解析。

如果标签不同，或 XML 解析失败，则返回 nullptr。

setInputSource()

void juce::XmlDocument::setInputSource (InputSource * newSource) noexcept

设置用于解析引用外部实体的文档的输入源对象。

如果文档是从文件创建的，这大概不需要，但如果你要解析某些文本且可能存在引用外部文件的 DTD，则可能需要创建一个自定义输入源，以便获取所需的其他文件。

传入的对象将在不再需要时自动删除。

setEmptyTextElementsIgnored()

void juce::XmlDocument::setEmptyTextElementsIgnored (bool shouldBeIgnored) noexcept

设置一个标志以更改空文本元素的处理方式。

如果为 true（默认状态），则在解析期间将忽略任何只包含空白字符的文本元素。如果你需要捕获仅含空白的文本，应在调用 getDocumentElement() 方法之前将其设为 false。
