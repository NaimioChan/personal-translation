juce::FloatVectorOperations 类参考

详细说明

对浮点数数组进行简单向量运算的集合，在可能的情况下使用 SIMD 指令加速，并提供 FloatVectorOperationsBase 中的所有方法。

disableDenormalisedNumberSupport()

void JUCE_CALLTYPE juce::FloatVectorOperations::disableDenormalisedNumberSupport (bool shouldDisable = true) static noexcept

在 Intel CPU 上，此方法启用 SSE 的 flush-to-zero 和 denormalised-are-zero 模式。

这实际上会设置 MXCSR 寄存器的 DAZ 和 FZ 位。在 ARM CPU 上，这会启用 flush to zero 模式。在音频处理代码之前调用它很方便，因为你会非常希望避免非正规数带来的性能损失。

引用了 JUCE_CALLTYPE。
