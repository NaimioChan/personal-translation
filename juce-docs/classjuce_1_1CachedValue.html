juce::CachedValue< Type > 类模板参考

详细说明

template<typename Type>
class juce::CachedValue< Type >

此类充当 ValueTree 中某个属性的类型化封装。

CachedValue 提供了一种简便方式，可按选定的类型读写 ValueTree 属性。因此，例如 CachedValue<int> 允许你以 int 读写该属性，CachedValue<String> 则允许你以 String 处理它。

它还通过在所用类型中缓存值的副本，实现对值的高效访问。

你可以为 CachedValue 提供可选的 UndoManager，它会在写入底层 ValueTree 时使用。

如果 ValueTree 中的属性缺失，CachedValue 将自动返回一个可选默认值，该值可在初始化 CachedValue 时指定。

要创建一个，你可以使用构造函数将 CachedValue 附加到 ValueTree，也可以用默认构造函数创建一个未初始化的 CachedValue，之后再通过 referTo() 方法附加。

诸如 String、int、double 这类易于转换为 var 的常见类型应当开箱即用；但如果你想使用更复杂的自定义类型，可能需要实现 VariantConverter 的一些模板特化，此类用它们在该类型与 ValueTree 的内部 var 之间进行转换。
