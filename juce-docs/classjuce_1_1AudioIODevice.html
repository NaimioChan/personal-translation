juce::AudioIODevice 类参考

详细说明

具有同步输入和输出通道的音频设备的基类。

它的子类用于实现不同的协议，如 DirectSound、ASIO、CoreAudio 等。

要创建其中之一，你需要使用 AudioIODeviceType 类 - 详情请参阅该类的文档。

如需更简便地管理音频设备及其设置的方法，请看 AudioDeviceManager 类。

另见
AudioIODeviceType, AudioDeviceManager

getXRunCount()

virtual int juce::AudioIODevice::getXRunCount () const virtual noexcept

返回自播放/录音开始以来操作系统报告的欠载或过载次数。

此数字可能不同于手动确定 Xrun 次数（通过测量在音频回调中花费的时间），因为操作系统可能在内部做了一些缓冲 - 在移动设备上尤其如此。

如果播放/录音尚未开始，或此设备不支持获取欠载次数（Android SDK 23 及更低版本），则返回 -1。
