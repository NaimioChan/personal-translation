juce::InAppPurchases 类参考

详细说明

提供应用内购买功能。

你的应用应创建该类的一个实例，在 iOS 上应在应用启动时尽快创建。这是因为应用启动时会恢复此前挂起的任何交易。

创建 InAppPurchases 对象后，调用 addListener() 来附加监听器。

purchaseProduct()

void juce::InAppPurchases::purchaseProduct (const String & productIdentifier, const String & upgradeOrDowngradeFromSubscriptionWithProductIdentifier = {}, bool creditForUnusedSubscription = true)

异步请求购买具有给定 ID 的产品。

参数
productIdentifier产品标识符。
upgradeOrDowngradeFromSubscriptionWithProductIdentifier（仅 Android）指定将被当前购买的订阅所替换的订阅。仅在购买升级或降级自另一订阅的订阅时使用。
creditForUnusedSubscription（仅 Android）控制是否应向用户返还被升级或降级产品上未使用的订阅时间的费用。

被以下对象引用： cancelDownloads()。

restoreProductsBoughtList()

void juce::InAppPurchases::restoreProductsBoughtList (bool includeDownloadInfo, const juce::String & subscriptionsSharedSecret = {})

异步询问用户已购买的产品列表。

完成后，将调用 Listener::purchasesListRestored() 回调。用户可能会被要求先登录。

参数
includeDownloadInfo（仅 iOS）若为 true，则在恢复成功后，传给 Listener::purchasesListReceived() 回调的 downloads 数组将包含与该购买对应的所有下载对象。反之，downloads 数组将为空。
subscriptionsSharedSecret（仅 iOS）在不包含下载信息且此应用设置了自动续期订阅时需要。参见商店中的应用内购买设置。

consumePurchase()

void juce::InAppPurchases::consumePurchase (const String & productIdentifier, const String & purchaseToken = {})

仅 Android：异步发送请求，将具有给定标识符的购买标记为已消费。

要消费产品，需提供产品标识符以及购买该产品时生成的购买令牌。购买令牌也可以通过 getProductsInformation() 获取。通常如果手头已有令牌，最好直接使用它，否则会向商店再发一个异步请求，先获取令牌。

成功消费后，产品将不再出现在 getProductsBought() 中，并且可以再次购买。

在 iOS 上消费会自动发生。如果产品被设为可消费，此函数为空操作。
