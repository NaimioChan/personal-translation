Random() [1/2]

juce::Random::Random (int64 seedValue) explicit noexcept

基于种子值创建一个 Random 对象。

对于给定的种子值，此对象随后生成的数字将是可预测的，因此最好根据时间设置该值，例如

new Random (Time::currentTimeMillis())

setSeedRandomly()

void juce::Random::setSeedRandomly ()

使用由当前时间等各种半随机的系统属性生成的值，为此生成器重新播种。

由于此函数会将时间与上一个种子值相卷积，反复调用它会提高最终结果的随机性。

getSystemRandom()

Random & juce::Random::getSystemRandom () static noexcept

创建新的 Random 对象开销相当小，但如果你想避免这一开销，可以调用此方法获取一个全局共享的 Random 对象。

注意，这会为其被访问的每个线程返回不同的对象，从而保证线程安全。但因此也不要保存指向此对象的引用并在之后从其他线程访问它。

引用了 nextInt()。
