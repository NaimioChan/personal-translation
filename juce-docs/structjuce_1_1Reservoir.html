doBufferedRead()

template<typename Index, typename GetBufferedRange, typename ReadFromReservoir, typename FillReservoir> Range < Index > juce::Reservoir::doBufferedRead (Range < Index > rangeToRead, GetBufferedRange && getBufferedRange, ReadFromReservoir && readFromReservoir, FillReservoir && fillReservoir) inline static

尝试从某种输入流中读取请求的范围，并在 'reservoir' 中进行中间缓冲。

当请求范围中仍有采样待读取时，此函数会检查请求范围的下一部分是否已加载到 reservoir 中。如果该范围可用，doBufferedRead 会以应复制到输出缓冲区的范围调用 readFromReservoir。如果该范围不可用，doBufferedRead 会调用 fillReservoir，请求将新区域加载到 reservoir 中。它会重复这些步骤，直到整个请求区域读取完毕，或者流结束。

这会返回无法成功读取的范围（如果有）。空范围表示整个读取成功。

注意，所有范围（包括作为回调参数提供的范围）都相对于原始的未缓冲输入。也就是说，如果 getBufferedRange 返回范围 [200, 300)，那么 readFromReservoir 可能被传入范围 [250, 300)，以便从 reservoir 复制最后 50 个采样。

参数
rangeToRead应读取范围的绝对位置
getBufferedRange一个 void -> Range<Index> 的函数，返回 reservoir 当前保存的区域
readFromReservoir一个 Range<Index> -> void 的函数，可用于从输入范围指定的 reservoir 区域复制采样
fillReservoir一个 Index -> void 的函数，接收请求的读取位置，并应从该位置开始尝试填充 reservoir。调用此函数后，getBufferedRange 应返回受管缓冲区中包含的新区域

引用了 juce::Range< ValueType >::getIntersectionWith()、juce::Range< ValueType >::getStart()、juce::Range< ValueType >::isEmpty()、juce::Range< ValueType >::setStart()。
