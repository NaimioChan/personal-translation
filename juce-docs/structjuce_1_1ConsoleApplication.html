juce::ConsoleApplication 结构体参考

详细说明

表示控制台应用可以执行的一组命令，并提供用于执行这些命令的辅助函数。

使用这些辅助类实现控制台应用时，你大概想按如下方式操作：

int main (int argc, char* argv[])
{
 ConsoleApplication app;

    app.addHelpCommand ("--help|-h", "Usage:", true);
    app.addVersionCommand ("--version|-v", "MyApp version 1.2.3");

    app.addCommand ({ "--foo",
 "--foo filename",
 "Performs a foo operation on the given file",
                      [] (const auto& args) { doFoo (args); }});

 return app.findAndRunCommand (argc, argv);
}

findAndRunCommand() [1/2]

int juce::ConsoleApplication::findAndRunCommand (const ArgumentList &, bool optionMustBeFirstArg = false) const

在列表中查找与给定参数匹配的第一条命令，并尝试调用它。

如果未找到命令，且没有要运行的默认命令，则以适当的错误消息失败。如果命令调用了 fail() 函数，则会抛出异常，该异常会被自动捕获并处理，此方法将返回传入 fail() 调用的错误码。

如果 optionMustBeFirstArg 为 true，则搜索可用命令时只查看第一个参数——这样可以实现 'git' 风格的命令，即可执行文件名称后面跟一个动词。
