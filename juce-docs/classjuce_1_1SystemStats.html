isOperatingSystem64Bit()

bool juce::SystemStats::isOperatingSystem64Bit () static

如果操作系统是 64 位则返回 true，如果是 32 位则返回 false。

这描述的是操作系统而不是当前进程，因此在 64 位 OS 上运行的 32 位构建会返回 true。要查明当前进程是否为 64 位，请使用 JUCE_64BIT 和 JUCE_32BIT 宏。

getUniqueDeviceID()

String juce::SystemStats::getUniqueDeviceID () static

此方法返回不受存储或外设变化影响的机器唯一 ID。

在非移动平台上，此 ID 会因主板和 CPU 的更换而失效，或在 Android 设备上执行系统恢复后失效。

在 iOS 上还有一些额外的注意事项：返回的 ID 对 'Bundle Identifier' 的厂商部分是唯一的，并且对所有关联 app 都稳定。一旦所有关联 app 被卸载，该键即失效。此函数在某些情况下可能返回空字符串，例如设备自重启以来尚未解锁。

getMachineIdentifiers()

StringArray juce::SystemStats::getMachineIdentifiers (MachineIdFlags flags) static

返回一组可用于唯一标识某台机器的字符串。

要一次获取多种标识符，你可以使用按位或组合标志，例如 uniqueId | legacyUniqueId。

如果某种标识符不可用，它将被从结果的 StringArray 中省略，因此传入 uniqueId | legacyUniqueId 可能返回 0、1 或 2 个结果，取决于平台以及是否遇到任何错误。

如果你之前已生成机器 ID，只想将其与所有可能的标识符核对，可以启用所有标志，然后检查存储的标识符是否与任何结果匹配。
