juce::StringRef 类参考

详细说明

一个简单的类，用于保存对字符串字面量或 String 的临时引用。

与真正的 String 对象不同，StringRef 不分配任何内存，也不取得你给它的字符串的所有权——它只保存对已在其他地方分配的字符串的引用。该类的主要用途是代替 const String& 作为函数参数的类型，此时调用者可以传入字符串字面量或 String 对象。这意味着当调用者使用字符串字面量时，无需分配临时 String 对象，从而大幅降低开销。

由于该类只是指针的封装，你应始终按值传递它，而不是按引用。

void myStringFunction1 (const String&);
void myStringFunction2 (StringRef);

myStringFunction1 ("abc"); // Implicitly allocates a temporary String object.
myStringFunction2 ("abc"); // Much faster, as no local allocations are needed.

有关其使用示例，请参见 XmlElement 或 StringArray 类。

请记住，在许多情况下使用 const String& 参数仍然更好。例如，如果函数要存储字符串，或需要从参数内部创建 String，那么最好让原始参数本身就是 String。
