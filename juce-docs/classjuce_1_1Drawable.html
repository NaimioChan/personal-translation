drawAt()

void juce::Drawable::drawAt (Graphics & g, float x, float y, float opacity) const

在 Graphics 上下文中按给定偏移渲染 Drawable。

传入的坐标用于在绘制前相对于对象自身原点平移它——这基本上是一种快捷写法，等同于：

draw (g, AffineTransform::translation (x, y)).

注意，将来渲染可绘制对象的首选方式是把它当作组件并添加到父级，所以在使用此方法前不妨考虑这一点。

引用了 x、y。

drawWithin()

void juce::Drawable::drawWithin (Graphics & g, Rectangle < float > destArea, RectanglePlacement placement, float opacity) const

在矩形内渲染 Drawable，将其缩放以完整适配，同时不改变宽高比。

该对象可以根据 Justification 类型任意放置在矩形内，既可以尽可能放大，也可以只缩小以适配。

注意，将来渲染可绘制对象的首选方式是把它当作组件并添加到父级，所以在使用此方法前不妨考虑这一点。

参数
g要渲染到的图形上下文
destArea用于容纳可绘制对象的目标矩形
placement定义用于将此对象适配到目标矩形内的对齐方式和重新缩放方式。
opacity要使用的不透明度，范围 0 到 1.0

setDrawableTransform()

void juce::Drawable::setDrawableTransform (const AffineTransform & transform)

设置一个变换，它应用于进行其余绘制调用时所用的同一坐标系。

在处理 Drawable 时，你几乎肯定想调用此函数，而不是 Component::setTransform()。

原因在于，Drawable 的原点与 Component::getPosition() 返回的点并不相同，而是带有一个 Drawable 类内部的额外偏移。

使用 setDrawableTransform() 会在将变换应用到 Component 基类时考虑这个内部偏移。

对于给定对象，你只能使用 Drawable::setDrawableTransform() 或 Component::setTransform()。两者同时使用会导致不可预测的行为。
