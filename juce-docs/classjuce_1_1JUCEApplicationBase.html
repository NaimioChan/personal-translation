juce::JUCEApplicationBase 类参考

详细说明

应用类的抽象基类。

注意在 juce_gui_basics 模块中有一个工具类 JUCEApplication，它派生自 JUCEApplicationBase，并处理了一些杂务。大多数情况下你会希望让类派生自 JUCEApplication 而不是直接使用 JUCEApplicationBase，但如果你没有使用 juce_gui_basics 模块，则可能需要直接使用这个基类。

任何想要运行事件循环的应用都必须声明 JUCEApplicationBase 的子类，并实现其各种纯虚方法。

然后需要在某个 CPP 文件中使用 START_JUCE_APPLICATION 宏来声明该类的实例，并生成合适的平台特定样板代码来启动应用。

例如

class MyJUCEApp  : public JUCEApplication
{
public:
    MyJUCEApp()  {}
    ~MyJUCEApp() {}

 void initialise (const String& commandLine) override
 {
        myMainWindow.reset (new MyApplicationWindow());
        myMainWindow->setBounds (100, 100, 400, 500);
        myMainWindow->setVisible (true);
    }

 void shutdown() override
 {
        myMainWindow = nullptr;
    }

 const String getApplicationName() override
 {
 return "Super JUCE-o-matic";
    }

 const String getApplicationVersion() override
 {
 return "1.0";
    }

private:
    std::unique_ptr<MyApplicationWindow> myMainWindow;
};

// this generates boilerplate code to launch our app class:
START_JUCE_APPLICATION (MyJUCEApp)

moreThanOneInstanceAllowed()

virtual bool juce::JUCEApplicationBase::moreThanOneInstanceAllowed () pure virtual

检查是否允许多个应用实例。

如果你的应用类对此返回 true，则允许运行多个实例（在 Mac 上无法做到）。

如果为 false，第二个实例将不会启动，但你仍会收到对 anotherInstanceStarted() 的回调来告知此事——这让你有机会对用户尝试的操作做出响应。

initialise()

virtual void juce::JUCEApplicationBase::initialise (const String & commandLineParameters) pure virtual

在应用启动时调用。

这将调用一次，让应用进行所需的任何初始化、创建窗口等。

该方法返回后，将运行正常的事件派发循环，直到调用 quit() 方法，此时将调用 shutdown() 方法，让应用清理需要删除的任何内容。

如果在 initialise() 方法执行期间应用最终决定不启动，它可以只调用 quit() 方法，事件循环将不会运行。

参数
commandLineParameters传入的行不包含可执行文件的名称，只有参数列表。要将参数作为数组获取，可以调用 JUCEApplication::getCommandLineParameters()

systemRequestedQuit()

virtual void juce::JUCEApplicationBase::systemRequestedQuit () pure virtual

在操作系统尝试关闭应用时调用。

该方法的默认实现是调用 quit()，但可以重载它以忽略请求或改为执行其他特殊行为。例如，你可能想在退出前让用户有机会保存更改，并让他们有机会取消。

如果你想向应用发送退出信号，这是应调用的正确方法，因为这意味着来自系统的请求会与你自己的应用代码发出的请求以相同方式处理。例如，你会从菜单栏的“退出”项调用该方法。

在 juce::JUCEApplication 中实现。

memoryWarningReceived()

virtual void juce::JUCEApplicationBase::memoryWarningReceived () inline virtual

由操作系统调用，表示你应降低内存占用。

你应重写该方法以尽可能优雅地释放一些内存，否则宿主可能会强制结束你的应用。

目前该方法仅在 iOS 上调用。

引用了 JUCEApplicationBase()。

backButtonPressed()

virtual bool juce::JUCEApplicationBase::backButtonPressed () inline virtual

当设备上的返回按钮被按下时，将调用此方法。

返回值应用于表示返回按钮事件是否已被应用处理，例如，如果你想在 Android 上实现自定义导航而不是标准行为。

目前仅在 Android 设备上实现。

返回
如果事件已处理则为 true，如果应执行操作系统默认行为则为 false

quit()

void juce::JUCEApplicationBase::quit () static

表示主消息循环应停止，应用应终止。

这不是同步的，它只是向主队列投递一条退出消息，当该消息到达时，消息循环将停止，调用 shutdown() 方法，应用将退出。

注意这将导致无条件退出，因此如果你需要在此之前加一层，例如让用户有机会保存工作并可能取消退出，你需要在 systemRequestedQuit() 方法中处理——更多信息参见该方法的帮助。
