juce::AudioChannelSet 类参考

详细说明

表示一组音频通道类型。

例如，你可能有一组左 + 右通道，即立体声通道组。它是 AudioChannelSet::ChannelType 枚举中值的集合，其中每种类型在该组中只能出现一次。

下面的文档列出了哪个 AudioChannelSet 对应 AAX、VST2/VST3 和 CoreAudio/AU 使用的哪种原生布局。CoreAudio 中的布局标签尤其令人困惑。例如，Logic Pro 中标记为 "7.1 SDDS" 的布局对应 CoreAudio/AU 的 kAudioChannelLayoutTag_DTS_7_0 标签，而 AAX 的 DTS 7.1 Layout 则对应 CoreAudio/AU 的 kAudioChannelLayoutTag_MPEG_7_1_A 格式，等等。请不要把 CoreAudio 标签当作扬声器实际布局的指示。

旧版本的 VST3 SDK 仅支持 9.0.4、9.1.4、9.0.6 和 9.1.6 布局的 ITU 版本，其前通道顺序为 "L Lc C Rc R"。为保持正确的相对通道顺序，JUCE 会执行以下映射：L -> wideLeft、Lc -> left、Rc -> right、R -> wideRight

JUCE 随附的 VST3 SDK 版本现在支持上述布局的 Atmos 版本，其前通道顺序为 "Lw L C R Rw"。该顺序与 JUCE 的顺序一致，因此无需重新映射。

create9point0point4()、create9point1point4()、create9point0point6() 和 create9point1point6() 现在分别对应 VST3 的 k90_4_W、k91_4_W、k90_6_W 和 k91_6_W Atmos 布局。

如果需要支持旧的 ITU 布局，请改用 create9point0point4ITU()、create9point1point4ITU()、create9point0point6ITU() 和 create9point1point6ITU()。
