isInterestedInFileDrag()

virtual bool juce::FileDragAndDropTarget::isInterestedInFileDrag (const StringArray & files) pure virtual

用于检查此目标是否对所提供的一组文件感兴趣的回调。

注意，当用户在组件上方拖动鼠标时，此项会被反复调用，因此不要在这里做耗时的操作，比如打开文件查看内容！

参数
files用户正在拖动的文件的（绝对）路径名集合
返回
如果此组件希望接收关于此类对象的其他回调，则为 true；如果返回 false，则不会再发出其他回调。

在 juce::FilenameComponent、juce::FileSearchPathListComponent 和 juce::TreeView 中实现。

fileDragEnter()

virtual void juce::FileDragAndDropTarget::fileDragEnter (const StringArray & files, int x, int y) virtual

回调，表示有文件正被拖动到该组件上方。

当用户拖动时把鼠标移入此组件，会调用此项。

可将此回调作为触发点，让组件重绘自身，以向用户反馈文件能否放置到这里。

参数
files用户正在拖动的文件的（绝对）路径名集合
x鼠标 x 位置，相对于此组件
y鼠标 y 位置，相对于此组件

在以下类中重新实现： juce::FilenameComponent、juce::TreeView。

引用了 x、y。

fileDragMove()

virtual void juce::FileDragAndDropTarget::fileDragMove (const StringArray & files, int x, int y) virtual

回调，表示用户正将某些文件拖动到该组件上方。

当用户拖动时把鼠标移到此组件上方，会调用此项。通常覆盖 itemDragEnter() 和 itemDragExit() 就足够了，但此项让你了解中间发生的情况。

参数
files用户正在拖动的文件的（绝对）路径名集合
x鼠标 x 位置，相对于此组件
y鼠标 y 位置，相对于此组件

在以下类中重新实现： juce::TreeView。

引用了 x、y。

fileDragExit()

virtual void juce::FileDragAndDropTarget::fileDragExit (const StringArray & files) virtual

回调，表示鼠标已移开该组件。

当用户拖动文件时把鼠标移出此组件，会调用此项。

如果你已用 fileDragEnter() 重绘组件并给出反馈，可把此项作为将其重绘为正常状态的信号。

参数
files用户正在拖动的文件的（绝对）路径名集合

在以下类中重新实现： juce::FilenameComponent、juce::TreeView。

filesDropped()

virtual void juce::FileDragAndDropTarget::filesDropped (const StringArray & files, int x, int y) pure virtual

用于指示用户已把文件放置到此组件上的回调。

用户放置文件时会调用此项，你可以以任何合适的方式使用这些文件。

注意，调用此项后可能不会再调用 fileDragExit 方法，因此如果拖动结束时你有需要做的事情，应在这里清理。

参数
files用户正在拖动的文件的（绝对）路径名集合
x鼠标 x 位置，相对于此组件
y鼠标 y 位置，相对于此组件

在 juce::FilenameComponent、juce::FileSearchPathListComponent 和 juce::TreeView 中实现。

引用了 x、y。
