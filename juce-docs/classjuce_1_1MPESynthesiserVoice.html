juce::MPESynthesiserVoice 类参考

详细说明

表示一个 MPE 声部，MPESynthesiser 可以用它来发声。

一个声部一次只演奏一个声音，而合成器持有一个声部数组，以便进行复音演奏。

另见
MPESynthesiser, MPENote

noteStopped()

virtual void juce::MPESynthesiserVoice::noteStopped (bool allowTailOff) pure virtual

由 MPESynthesiser 调用，通知该声部其当前演奏的音符已停止。

它会在渲染回调期间被调用，因此必须足够快且线程安全。

如果 allowTailOff 为 false，或该声部不想做尾音衰减，则必须立即停止所有声音，并调用 clearCurrentNote() 重置该声部的状态，以便合成器把它重新分配给另一个声音。

如果 allowTailOff 为 true 且声部决定做尾音衰减，则允许它开始淡出声音，并可以一直演奏到结束。一旦演奏结束（在渲染回调期间），它必须确保调用 clearCurrentNote()。

引用了 currentlyPlayingNote。

被以下对象引用： MPESynthesiser。

renderNextBlock() [1/2]

virtual void juce::MPESynthesiserVoice::renderNextBlock (AudioBuffer < float > & outputBuffer, int startSample, int numSamples) pure virtual

为该声部渲染下一个数据块。

输出的音频数据必须叠加到所提供缓冲区的当前内容上。本方法只应改动缓冲区中 startSample 到 (startSample + numSamples) 之间的区域。

如果该声部当前静音，则直接返回、不做任何事即可。

如果该声部演奏的声音在本块渲染过程中结束，它必须调用 clearCurrentNote()，告知合成器它已结束。

每次调用时渲染的块大小都可能变化，甚至可能一次只渲染 1 个采样。在渲染回调之间，会调用该声部的方法来告知它音符和控制器事件。

引用了 currentlyPlayingNote。

被以下对象引用： renderNextBlock()、renderNextBlock()。

clearCurrentNote()

void juce::MPESynthesiserVoice::clearCurrentNote () protected noexcept

在声音播放完毕后重置该声部的状态。

子类在演奏完一个音符并可供演奏新音符时必须调用它。

它必须在 stopNote() 方法中调用；或者如果声部正在做尾音衰减，则应在稍后的 renderNextBlock 方法中、尾音一结束就调用。

如果声音恰好已经结束（例如它正在播放一个采样而该采样播放完了），也可以在渲染回调期间的任意时刻调用它。
