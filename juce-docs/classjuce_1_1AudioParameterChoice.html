详细说明

提供一种 AudioProcessorParameter 类，可用于从列表中选择某个带索引的具名选项。

AudioParameterChoice() [1/2]

juce::AudioParameterChoice::AudioParameterChoice (const ParameterID & parameterID, const String & parameterName, const StringArray & choices, int defaultItemIndex, const AudioParameterChoiceAttributes & attributes = {})

创建具有指定参数的 AudioParameterChoice。

注意，attributes 参数是可选的，只有在你想要更改默认选项时才需要提供。

用法示例：

auto attributes = AudioParameterChoiceAttributes().withLabel ("selected");
auto param = std::make_unique<AudioParameterChoice> ("paramID", "Parameter Name", StringArray { "a", "b", "c" }, 0, attributes);
参数
parameterID要使用的参数 ID
parameterName要使用的参数名称
choices要使用的选项集合
defaultItemIndex默认选项的索引
attributesOptional 特性

引用了 choices。
