juce::ComponentBuilder::TypeHandler 类参考

详细说明

本类是那些负责从 ValueTree 加载某类组件的对象的基类。

要把组件树存储为 ValueTree 并重新加载，每种组件类型都必须有一个 TypeHandler 来表示它。

另见
ComponentBuilder::registerTypeHandler(), Drawable::registerDrawableTypeHandlers()

addNewComponentFromState()

virtual Component * juce::ComponentBuilder::TypeHandler::addNewComponentFromState (const ValueTree & state, Component * parent) pure virtual

此方法必须从给定状态创建新组件，将其添加到指定的父组件（可以为 null），并返回它。

ValueTree 会经过预先检查，以确保其类型与此处理器支持的类型匹配。

无需把新 Component 的 ID 设置为与状态的一致——构建器会自行处理。

引用了 addNewComponentFromState()、juce::ComponentBuilder::state。

updateComponentFromState()

virtual void juce::ComponentBuilder::TypeHandler::updateComponentFromState (Component * component, const ValueTree & state) pure virtual

此方法必须根据新的 ValueTree 状态更新现有组件。

用 addNewComponentFromState() 创建的组件在 ValueTree 变化时可能需要更新，此方法就用于此目的。你的实现必须完成从所提供的新状态更新组件所需的一切工作。

ValueTree 会经过预先检查，以确保其类型与此处理器支持的类型匹配，并且该组件将由此类型的 addNewComponentFromState() 方法创建。

引用了 addNewComponentFromState()、juce::ComponentBuilder::state。

被以下对象引用： ComponentBuilder。
