juce::AndroidDocument 类参考

详细说明

提供对 Android 设备上文档的访问。

在此上下文中，“文档”可以是文件或目录。

此类的主要目的是提供对 Android 共享存储中文件的访问。在较新的 Android 版本中，此类文件无法通过文件路径直接访问，而必须改用基于 URI 的 DocumentsContract API 来读写。

示例用例：

  • 在显示系统打开对话框让用户打开文件后，将 FileChooser 的 URL 结果传给 AndroidDocument::fromDocument。然后，你可以使用 getInfo() 检索文件信息，并用 createInputStream 从文件读取。其他函数允许移动、复制和删除文件。
  • 与“打开”用例类似，你可以使用 createOutputStream 写入文件，该文件通常通过系统保存对话框定位。
  • 为了读写共享存储中的文件树，你可以以“选择目录”模式显示系统打开对话框，并将得到的 URL 传给 AndroidDocument::fromTree。然后，你可以遍历目录中的文件、查询它们并创建新文件。这是存储多个文件的好方法，用户可以从其他应用访问这些文件，并且在卸载并重新安装应用后它们仍会保留。

注意，如果你的应用只需要访问其自身内部沙盒中的文件，你大概 not 需要此类。在这种情况下，juce::File 实例应能按预期工作。

AndroidDocument 有点类似 androidx 扩展库中的 DocumentFile 类，因为它表示单个文档，并使用 DocumentsContract 函数实现。

fromFile()

AndroidDocument juce::AndroidDocument::fromFile (const File & filePath) static

创建表示特定路径处文件或目录的 AndroidDocument。

这是为了在较旧的 API 版本（低于 19）或其他平台上使用而提供的，以便无论运行时平台版本如何，都可以使用相同的 AndroidDocument API。

如果运行时平台版本为 19 或更高，并且你希望处理从原生文件选择器获得的 URI，请改用 fromDocument() 或 fromTree()。

如果此函数失败，hasValue() 将在返回的文档上返回 false。

引用了 AndroidDocument()。

fromDocument()

AndroidDocument juce::AndroidDocument::fromDocument (const URL & documentUrl) static

创建表示单个文档的 AndroidDocument。

参数应为表示文档的 URL。此类 URL 由系统文件选择器在非文件夹选择模式下返回。如果你传入树 URL，此函数将失败。

此函数在 API 级别 18 或更低的 Android 设备上以及非 Android 平台上可能失败。如果此函数失败，hasValue() 将在返回的文档上返回 false。如果调用此函数失败，你可能想用 fromFile() 重试创建 AndroidDocument，传入 URL::getLocalFile() 的结果。

引用了 AndroidDocument()。

fromTree()

AndroidDocument juce::AndroidDocument::fromTree (const URL & treeUrl) static

创建表示文件树根目录的 AndroidDocument。

参数应为表示树的 URL。此类 URL 由系统文件选择器在文件夹选择模式下返回。如果你传入指向树内文档的 URL，这将返回指向树根的文档。如果你传入指向单个文件的 URL，这将失败。

面向平台版本 30 或更高时，通过文件路径访问文件系统受到严格限制，访问共享存储必须改用基于 URI 的新系统。撰写本文时，上传到 Play Store 的应用必须以 API 30 或更高为目标。如果你想对共享文件夹具有读写访问权限，你必须：

  • 在 canSelectDirectories 模式下使用原生 FileChooser，让用户选择你的应用可以访问的文件夹。你的应用只能访问此目录的内容；它无法逃逸到文件系统根目录。系统不允许用户授予某些位置的访问权限，包括文件系统根目录和 Download 文件夹。
  • 将用户选择的 URI 传给 fromTree()，并使用得到的 AndroidDocument 读写文件系统。

此函数在 API 级别 20 或更低的 Android 设备上以及非 Android 平台上可能失败。如果此函数失败，hasValue() 将在返回的文档上返回 false。

引用了 AndroidDocument()。

createChildDocumentWithTypeAndName()

AndroidDocument juce::AndroidDocument::createChildDocumentWithTypeAndName (const String & type, const String & name) const

尝试创建具有特定类型和名称的新嵌套文档。

类型应为标准 MIME 类型字符串，例如“image/png”、“text/plain”。

文件名不需要包含扩展名，因为该信息通过 type 参数传递。如果此文档是基于 File 而非基于 URL 的，则将根据 MIME 类型选择合适的文件扩展名。

失败时，返回的 AndroidDocument 可能无效，并且 hasValue() 将返回 false。

copyDocumentToParentDocument()

AndroidDocument juce::AndroidDocument::copyDocumentToParentDocument (const AndroidDocument & target) const

实验性：尝试将此文档复制到新的父级，并返回表示副本的 AndroidDocument。

失败时，返回的 AndroidDocument 可能无效，并且 hasValue() 将返回 false。

如果文档不允许复制，以及在 API 级别 23 或更低的设备上使用基于 URI 的文档时，此函数可能失败。失败时，返回的 AndroidDocument 将从 hasValue() 返回 false。在测试中，Android 模拟器的 API 24、30 或 31 均不支持复制，因此此函数很可能在真实设备上也无法工作。
