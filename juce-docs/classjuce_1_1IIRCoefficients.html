makeLowShelf()

IIRCoefficients juce::IIRCoefficients::makeLowShelf (double sampleRate, double cutOffFrequency, double Q, float gainFactor) static noexcept

返回具有可变 Q 值和增益的低通搁架滤波器的系数。

增益是低频所乘的缩放系数，因此大于 1.0 的值会提升低频，小于 1.0 的值会衰减低频。

引用了 IIRCoefficients()、makeLowPass()。

被以下对象引用： makeLowShelf()。

makeHighShelf()

返回具有可变 Q 值和增益的高通搁架滤波器的系数。

增益是高频所乘的缩放系数，因此大于 1.0 的值会提升高频，小于 1.0 的值会衰减高频。

引用了 IIRCoefficients()、makeLowPass()。

被以下对象引用： makeLowShelf()。

makePeakFilter()

IIRCoefficients juce::IIRCoefficients::makePeakFilter (double sampleRate, double centreFrequency, double Q, float gainFactor) static noexcept

返回以给定频率为中心、具有可变 Q 值和增益的峰值滤波器的系数。

增益是中心频率所乘的缩放系数，因此大于 1.0 的值会提升中心频率，小于 1.0 的值会衰减中心频率。

引用了 IIRCoefficients()、makeLowPass()。

被以下对象引用： makeLowShelf()。
