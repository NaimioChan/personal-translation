构造函数与析构函数

BufferingAudioReader()

juce::BufferingAudioReader::BufferingAudioReader (AudioFormatReader * sourceReader, TimeSliceThread & timeSliceThread, int samplesToBuffer)

创建一个读取器。

参数
sourceReader要包装的源读取器。此 BufferingAudioReader 取得该对象的所有权，并会在不再需要时将其删除
timeSliceThread用于执行后台读取的线程。确保你提供的线程正在运行，且在读取器对象仍然存在时不会被删除。
samplesToBuffer要预读缓冲的采样总数。

引用了 juce::AudioFormatReader::AudioFormatReader()、juce::TimeSliceClient::TimeSliceThread。

成员函数

setReadTimeout()

void juce::BufferingAudioReader::setReadTimeout (int timeoutMilliseconds) noexcept

设置读取器在其 readSamples() 方法中最多可阻塞的毫秒数，超过后便放弃并返回静音。

小于 0 的值表示“永久等待”。默认超时为 0。

readSamples()

bool juce::BufferingAudioReader::readSamples (int *const * destChannels, int numDestChannels, int startOffsetInDestBuffer, int64 startSampleInFile, int numSamples) override virtual

子类必须实现此方法以执行底层读取操作。

调用者应使用 read() 而不是直接调用此方法。

参数
destChannels要填充的目标缓冲区数组。其中一些指针可能为空
numDestChannelsdestChannels 数组中的项目数。此值保证不大于此读取器对象包含的通道数
startOffsetInDestBuffer从 dest 数据起始处开始写入的采样数
startSampleInFile从源数据中开始读取的采样数。此值保证 >= 0。
numSamples要读取的采样数
