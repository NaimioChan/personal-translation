juce::Message 类参考

详细说明

可发送给 MessageListener 的对象的基类。

如果你想发送携带某种自定义数据的消息，只需创建一个 Message 的子类，并添加适当的成员变量来保存数据。

始终在堆上创建 Message 对象的新实例，因为消息投递后它会被自动删除。

另见
MessageListener, MessageManager, ActionListener, ChangeListener
