juce::var 类参考

详细说明

一种变体类，可用于保存一系列原始值。

var 对象可以保存一系列简单原始值、字符串或任何类型的 ReferenceCountedObject。var 类的设计意图是像动态脚本语言中使用的值那样工作。

你可以使用 writeToStream()/readFromStream() 以小型专有二进制格式保存/加载 var 对象，或通过 JSON 类将其保存为 JSON。

JSON, DynamicObject

equals()

bool juce::var::equals (const var & other) const noexcept

如果此 var 与所提供的值相同，则返回 true。

注意，这会忽略类型，因此字符串 var“123”和值为 123 的整数 var 被视为相等。

注意，相等性检查取决于调用 equals() 时所作用对象的“包装”类型。这意味着以下代码会将右侧参数转换为字符串并比较字符串值，因为左侧对象是由字符串初始化的：

var ("123").equals (var (123))

然而，以下代码会将右侧参数转换为 double 并按 double 比较值，因为左侧对象是由 double 初始化的：

var (45.6).equals ("45.6000")
