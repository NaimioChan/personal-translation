refreshComponentForRow()

virtual Component * juce::ListBoxModel::refreshComponentForRow (int rowNumber, bool isRowSelected, Component * existingComponentToUpdate) virtual

这用于创建或更新放在列表某行中的自定义组件。

任何行都可以包含自定义组件，或者只是用 paintListBoxItem() 方法绘制并用 listBoxItemClicked() 处理鼠标点击。

每当自定义组件可能需要更新时都会调用此方法——例如列表发生变化，或调用了 ListBox::updateContent()。

如果指定行不需要自定义组件，则返回 nullptr。（请注意，即使你不创建新组件，如果 existingComponentToUpdate 非空，你可能仍需要删除它）。

如果你确实需要自定义组件，且 existingComponentToUpdate 为 null，则此方法必须创建一个合适的新组件并返回它。

如果 existingComponentToUpdate 非空，它将是先前由此方法创建的组件的指针。在这种情况下，方法要么更新它以确保其正确表示给定行（该行可能与创建组件时对应的行不同），要么删除此组件并返回一个新组件。

你的方法返回的组件将在不再需要时由 ListBox 删除。

请注意，如果你在某行中放入自定义组件，但仍希望列表框自动处理点击、选择等，则需要确保你的自定义组件不会拦截落在其上的所有鼠标事件，例如使用 Component::setInterceptsMouseClicks()。

selectedRowsChanged()

virtual void juce::ListBoxModel::selectedRowsChanged (int lastRowSelected) virtual

重写此方法，以便在行被选中或取消选中时收到通知。

每当某一行被选中或取消选中时都会调用。如果一次性选中一个范围内的多行，此方法对该事件只会调用一次。

参数
lastRowSelected用户最后选中的行。如果当前没有选中任何行，该值可能为 -1。

在以下类中重新实现： juce::FileSearchPathListComponent、juce::TableListBox。

getDragSourceDescription()

virtual var juce::ListBoxModel::getDragSourceDescription (const SparseSet < int > & rowsToDescribe) virtual

要允许从列表拖动行，请实现此方法。

如果这返回非空 variant，则当用户拖动某行时，列表框会尝试在其父级层次中查找 DragAndDropContainer，并用它触发拖放操作，以此字符串作为源描述，以列表框自身作为源组件。
