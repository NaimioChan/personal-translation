juce::WebBrowserComponent::Options::WinWebView2 类参考

详细说明

WebView2 后端专用的 Options。

如果使用其他后端，这些选项将被忽略。

本类的文档由以下文件生成：

withUserDataFolder()

WinWebView2 juce::WebBrowserComponent::Options::WinWebView2::withUserDataFolder (const File & folder) const inline nodiscard

为浏览器实例的用户数据设置非默认存储位置。

在插件项目中，你可能会发现有必要使用此选项并指定诸如 File::SpecialLocationType::tempDirectory 的位置。否则，WebView2 可能因被拒绝访问默认用户数据位置而无法正常工作。

引用了 juce::withMember()。

withBackgroundColour()

WinWebView2 juce::WebBrowserComponent::Options::WinWebView2::withBackgroundColour (const Colour & colour) const inline nodiscard

设置 WebView2 在所有网页内容下方渲染的背景颜色。

此颜色必须完全不通透或完全透明。

引用了 juce::Colour::isOpaque()、juce::Colour::isTransparent()、jassert、juce::withMember()。
