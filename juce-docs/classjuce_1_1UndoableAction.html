getSizeInUnits()

virtual int juce::UndoableAction::getSizeInUnits () inline virtual

返回一个值，指示此对象占用的内存量。

由于 UndoManager 保存 UndoableAction 列表，此项用于算出每个操作占用的空间，以便 UndoManager 算出要保留多少个。

此处返回的默认值为 10——单位是任意的，不必准确。

另见
UndoManager::getNumberOfUnitsTakenUpByStoredCommands, UndoManager::setMaxNumberOfStoredUnits

createCoalescedAction()

virtual UndoableAction * juce::UndoableAction::createCoalescedAction (UndoableAction * nextAction) virtual

允许将多个操作合并到单个操作对象中，以减少存储空间。

如果可能，此方法应创建并返回单个操作，其作用等同于先执行此操作、再执行所提供的操作。

如果无法合并这两个操作，该方法应返回 nullptr。

引用了 UndoableAction()。
