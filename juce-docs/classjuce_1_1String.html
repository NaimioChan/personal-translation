成员类型别名文档

CharPointerType

using juce::String::CharPointerType = CharPointer_UTF8

这是内部用于存储字符串的字符编码类型。

通过将 JUCE_STRING_UTF_TYPE 的值设为 8、16 或 32，你可以更改 String 类的内部存储格式。UTF-8 占用空间最少（如果你的字符串中扩展字符很少），但调用 operator[] 需要遍历字符串以找到所需索引。UTF-32 可以即时随机访问其字符，但每个字符占用 4 个字节。UTF-16 比 UTF-8 占用更多空间，索引也慢，但它是 Windows 中使用的原生 wchar_t 格式。

选择哪种格式关系不大，因为 toUTF8()、toUTF16() 和 toUTF32() 方法让你可以以任何其他格式访问字符串内容。

String() [4/33]

juce::String::String (const char * text)
