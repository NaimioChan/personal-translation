juce::DragAndDropContainer 类参考

详细说明

为组件及其所有子组件启用拖放行为。

要让组件能够发出或接收拖放事件，其某个父组件必须派生自本类。最好由顶层组件来实现它。

然后要开始拖动操作，任何子组件只需调用 startDragging() 方法，此对象将接管，跟踪鼠标并向鼠标经过的、派生自 DragAndDropTarget 的任何子组件发送相应回调。

注意：如果你只需要响应从操作系统拖放到组件上的文件，则不需要这些类：只需覆盖 FileDragAndDropTarget::filesDropped() 即可。

startDragging() [1/2]

void juce::DragAndDropContainer::startDragging (const var & sourceDescription, Component * sourceComponent, const ScaledImage & dragImage = ScaledImage (), bool allowDraggingToOtherJuceWindows = false, const Point < int > * imageOffsetFromMouse = nullptr, const MouseInputSource * inputSourceCausingDrag = nullptr)

开始拖放操作。

这会开始拖放操作——当用户在你的拖动源组件中拖动鼠标时调用它，此对象将跟踪鼠标移动，直到用户松开鼠标按钮，并向鼠标经过的 DragAndDropTarget 对象发送相应消息。

findParentDragContainerFor() 是一个便捷方法，可用于查找组件应使用的拖动容器。

参数
sourceDescription用作被拖动对象描述的字符串或值——它会被传给可能作为放置目标的对象，以便它们决定是否要处理它
sourceComponent被拖动的组件
dragImage在鼠标下方随之拖动的图像。如果为空图像，则改用 sourceComponent 的快照。
allowDraggingToOtherJuceWindows如果为 true，被拖动的组件将显示为桌面窗口，并可以拖到属于其他组件（而非此组件）子级的 DragAndDropTargets 上。
imageOffsetFromMouse如果传入图像，这指定图像相对于鼠标的绘制偏移。如果未指定，图像将以鼠标为中心。如果未传入图像，则忽略此项。
inputSourceCausingDrag启动拖动的鼠标输入源。在 mouseDown 或 mouseDrag 事件中调用时，你可以向此方法传入 MouseEvent::source。如果此参数为 nullptr，JUCE 将使用当前正在拖动的鼠标输入源。如果有多个正在拖动的鼠标输入源（移动端经常如此），JUCE 将使用最接近 sourceComponent 的 mouseInputSource。

被以下对象引用： startDragging()。

findParentDragContainerFor()

DragAndDropContainer * juce::DragAndDropContainer::findParentDragContainerFor (Component * childComponent) static

用于为给定 Component 查找 DragAndDropContainer 的实用工具。

这会沿此组件的父级层级向上搜索，寻找第一个为 DragAndDropContainer 的父组件。

当组件想调用 startDragging 但不知道自己应使用哪个 DragAndDropContainer 时，这很有用。

显然，如果找不到合适的组件，它可能返回 nullptr。

引用了 startDragging()。

performExternalDragDropOfFiles()

bool juce::DragAndDropContainer::performExternalDragDropOfFiles (const StringArray & files, bool canMoveFiles, Component * sourceComponent = nullptr, std::function< void()> callback = nullptr) static

这会把一组文件异步拖放到某个外部应用。

你可以响应 mouseDrag 回调调用此函数，它将使用操作系统原生的拖放操作把一些文件移动或复制到另一个应用。

参数
files要拖动的文件名列表
canMoveFiles如果为 true，接收文件的应用可以将文件移动到新位置（如果合适）。如果为 false，接收方应复制这些文件。
sourceComponent通常 JUCE 会假定鼠标下的组件是拖动的源组件，但你可以用此参数覆盖这一假定。
callback可选的完成回调，将在操作结束时调用。
返回
如果拖动操作成功启动则返回 true，如果因某种原因失败则返回 false

shouldDropFilesWhenDraggedExternally()

virtual bool juce::DragAndDropContainer::shouldDropFilesWhenDraggedExternally (const DragAndDropTarget::SourceDetails & sourceDetails, StringArray & files, bool & canMoveFiles) protected virtual

如果你希望在用户拖到此容器组件之外时能够对外拖动一组文件，请覆盖此方法。

当拖动操作移到 JUCE 窗口之外时会调用此方法；如果你希望它随后执行文件拖放，请把想要的文件名加入传入的数组，并返回 true。

参数
sourceDetails关于拖动操作来源的信息
files返回时填写你想拖动的文件名
canMoveFiles返回时填写：如果接收方可以移动文件则为 true；如果必须复制这些文件则为 false（参阅 performExternalDragDropOfFiles() 方法）
