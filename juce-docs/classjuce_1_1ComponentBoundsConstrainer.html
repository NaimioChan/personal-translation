juce::ComponentBoundsConstrainer 类参考

详细说明

对 Component 的大小或位置施加限制的类。

ResizableCornerComponent、ResizableBorderComponent 和 ResizableWindow 等类会用到它。

基类可以施加一些基本的大小和位置限制，但你也可以为自定义用途对它进行子类化。

另见
ResizableCornerComponent, ResizableBorderComponent, ResizableWindow

setMinimumOnscreenAmounts()

void juce::ComponentBoundsConstrainer::setMinimumOnscreenAmounts (int minimumWhenOffTheTop, int minimumWhenOffTheLeft, int minimumWhenOffTheBottom, int minimumWhenOffTheRight) noexcept

设置组件允许移出屏幕的量。

这些值表示当组件被拖出父级某条边时，必须留在屏幕上的像素数。例如，如果 minimumWhenOffTheTop 设为 10，那么当组件超出屏幕顶部时，其 y 坐标会被裁剪，以保证始终至少有 10 个像素留在屏幕上。换言之，它能取到的最小 y 坐标将是（10 减去组件高度）。

如果为其中某个值传入 0 或负数，则允许组件完全移出该边，不受任何限制。

如果传入很大的数（即大于组件自身尺寸的数），则完全不允许组件与该边重叠。例如，将 minimumWhenOffTheLeft 设为 0xffffff，意味着组件会碰到屏幕左侧而无法继续前进。

setFixedAspectRatio()

void juce::ComponentBoundsConstrainer::setFixedAspectRatio (double widthOverHeight) noexcept

指定调整器应始终保持的宽高比。

如果值为 0，则不强制宽高比。如果非零，宽度将始终保持为高度的这个倍数。
