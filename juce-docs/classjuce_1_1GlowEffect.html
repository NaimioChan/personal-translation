juce::GlowEffect 类参考

详细说明

在组件内容周围添加彩色模糊的组件特效。

（这仅对非不透明组件有效）。

另见

setGlowProperties()

void juce::GlowEffect::setGlowProperties (float newRadius, Colour newColour, Point < int > offset = {})

设置发光的半径和颜色。

半径决定模糊的大小，颜色用于渲染它（要得到不那么强烈的发光，可降低颜色的不透明度）。

applyEffect()

void juce::GlowEffect::applyEffect (Image & sourceImage, Graphics & destContext, float scaleFactor, float alpha) override virtual

重写以实现效果的渲染。

此方法的实现必须以传入的图像为源，并将输出渲染到传入的图形上下文中。

参数
sourceImage源组件刚用其 paint() 方法渲染出的图像。根据组件是否不透明，该图像可能有也可能没有 alpha 通道。
destContext用于绘制结果图像的图形上下文。
scaleFactor已应用到图像的缩放系数——例如若为 2，则图像实际上被放大到原始分辨率的两倍
alpha将结果图像绘制到目标上下文时使用的 alpha

实现 juce::ImageEffectFilter。

引用了 juce::Colours::white。
