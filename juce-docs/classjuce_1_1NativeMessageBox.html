showMessageBox()

void JUCE_CALLTYPE juce::NativeMessageBox::showMessageBox (MessageBoxIconType iconType, const String & title, const String & message, Component * associatedComponent = nullptr) static

显示一个只包含消息和一个 'ok' 按钮的对话框，用于关闭它。

该框以模态方式显示，此方法将阻塞，直到用户点击其按钮（或按下 escape 或 return 键）。

参数
iconType要显示的图标类型。
title要显示在框顶部的标题。
message要在标题下方显示的更长、更具描述性的消息。
associatedComponent如果此项非空，它指定警告窗口应关联的组件。取决于外观风格，这可能用于警告窗口的定位。

引用了 JUCE_CALLTYPE。

void JUCE_CALLTYPE juce::NativeMessageBox::showAsync (const MessageBoxOptions & options, ModalComponentManager::Callback * callback) static

showOkCancelBox()

bool JUCE_CALLTYPE juce::NativeMessageBox::showOkCancelBox (MessageBoxIconType iconType, const String & title, const String & message, Component * associatedComponent = nullptr, ModalComponentManager::Callback * callback = nullptr) static

显示一个带有两个按钮的对话框。

非常适合 ok/cancel 或 yes/no 选择。return 键也可用于触发第一个按钮，escape 键用于第二个按钮。

如果 callback 参数为 null 且启用了模态循环，则框以模态方式显示，此方法将阻塞，直到用户点击按钮（或按下 escape 或 return 键）。如果 callback 参数非空，框将被显示并置于模态状态，但此方法会立即返回，而回调将在用户关闭框时稍后调用。

参数
iconType要显示的图标类型。
title要显示在框顶部的标题。
message要在标题下方显示的更长、更具描述性的消息。
associatedComponent如果此项非空，它指定警告窗口应关联的组件。取决于外观风格，这可能用于警告窗口的定位。
callback如果此项非空，框将异步启动并立即返回，并且在框被关闭时，回调将收到对其 modalStateFinished() 的调用；如果按下了 ok 按钮，其参数为 1，如果取消则为 0。回调对象将由系统拥有并删除，因此请确保它能安全运行，并且不保留任何可能在它被调用之前被删除的对象的引用。你可以使用 ModalCallbackFunction 轻松为此参数传入 lambda。
返回
如果点击了按钮 1 则为 true，如果点击的是按钮 2 则为 false。如果 callback 参数不为空，方法总是返回 false，用户的选择稍后通过回调传递。
另见
ModalCallbackFunction

引用了 JUCE_CALLTYPE。

showScopedAsync()

ScopedMessageBox juce::NativeMessageBox::showScopedAsync (const MessageBoxOptions & options, std::function< void(int)> callback) static nodiscard

使用指定选项显示一个对话框。

该框将被显示并进入模态状态，但此方法会立即返回，回调将在用户关闭该框时稍后被调用。

此函数始终是异步的，即使 callback 为空。

为与 AlertWindow 保持一致，警告窗口返回的结果代码如下。

  • 一个按钮：
    • button[0] 返回 0
  • 两个按钮：
    • button[0] 返回 1
    • button[1] 返回 0
  • 三个按钮：
    • button[0] 返回 1
    • button[1] 返回 2
    • button[2] 返回 0

另一种表述方式是：当有 N 个按钮时，按钮 X 的结果代码等于 ((X + 1) % N)。

参数
options创建对话框时要使用的选项。
callback如果非空，当该框被关闭时，回调的 modalStateFinished() 会被调用，参数为被点击按钮的索引。回调对象由系统拥有并删除，因此请确保其工作安全，且不要保留任何可能在其被调用前已被删除的对象的引用。
返回
一个 ScopedMessageBox 实例。消息框的可见时间不会超过 ScopedMessageBox 的存活时间。

MessageBoxOptions
