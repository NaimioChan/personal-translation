juce::VariantConverter< Type > 结构体模板参考

详细说明

template<typename Type>
struct juce::VariantConverter< Type >

这个模板重载的类可用于在 var 与自定义类型之间转换。

如果未特化，变体转换器会尝试使用已为给定类型检测到的序列化函数。有关其具体内容的详情，请参阅 SerialisationTraits 的文档。

简而言之，必须为该类型定义常量 'marshallingVersion'，以及单个函数 'serialise()'，或函数对 'load()' 和 'save()'。这些可以定义为类型 T 本身的公有成员，也可以定义为 juce::SerialisationTraits<T> 的公有成员，后者是类型 T 的 SerialisationTraits 模板结构体的特化。
