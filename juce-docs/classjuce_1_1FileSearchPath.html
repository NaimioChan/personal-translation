removeRedundantPaths()

void juce::FileSearchPath::removeRedundantPaths ()

移除那些实际上是搜索路径中其他某个目录的子目录的目录。

如果搜索意图是递归的，搜索路径中嵌套文件夹没有意义，因为它们会被搜索两次，导致结果重复。

例如如果路径是 "c:\abc\de;c:\abc"，此方法会将其简化为 "c:\abc"

isFileInPath()

bool juce::FileSearchPath::isFileInPath (const File & fileToCheck, bool checkRecursively) const

判断文件是否位于路径的某个目录内。

如果指定文件是此路径所指定目录之一的子项，这将返回 true。注意，这实际上不进行任何搜索或检查文件是否存在——它只是查看路径名来判断文件是否会在某个目录内。

参数
fileToCheck要查找的文件
checkRecursively如果为 true，那么当文件位于路径中某个目录的子文件夹内（任意深度）时将返回 true。如果为 false，则仅当文件实际上是某个目录的直接子项时才返回 true。
