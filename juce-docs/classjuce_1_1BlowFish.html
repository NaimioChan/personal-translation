encrypt() [3/3]

int juce::BlowFish::encrypt (void * buffer, size_t sizeOfMsg, size_t bufferSize) const noexcept

就地加密数据。

参数
buffer应加密的消息。大小要求见 bufferSize！
sizeOfMsg应加密消息的大小，以字节为单位
bufferSize缓冲区大小，以字节为单位。为容纳加密后的数据，缓冲区必须大于消息：缓冲区大小需等于或大于消息字节数向上取整到下一个能被 8 整除的整数。如果消息的字节数已经能被 8 整除，则需在缓冲区大小上再加 8 字节。如有疑问，直接使用 bufferSize = sizeOfMsg + 8。
返回
解密数据的大小，以字节为单位；如果解密失败则为 -1。

引用了 BlowFish()。
