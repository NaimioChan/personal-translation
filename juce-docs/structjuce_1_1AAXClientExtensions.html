juce::AAXClientExtensions 结构体参考

详细说明

允许 AudioProcessor 实现扩展的 AAX 特定功能的接口。

要使用此类，请创建一个继承自它的对象，实现这些方法，然后在你的 AudioProcessor getAAXClientExtensions() 方法中返回指向该对象的指针。

AudioProcessor, VST2ClientExtensions, VST3ClientExtensions

getPluginIDForMainBusConfig()

virtual int32 juce::AAXClientExtensions::getPluginIDForMainBusConfig (const AudioChannelSet & mainInputLayout, const AudioChannelSet & mainOutputLayout, bool idForAudioSuite) const virtual

AAX 插件需要为你 AudioProcessor 在主总线上支持的每种音频布局配置报告唯一的 "plug-in id"。

如果你希望 AudioProcessor 使用自定义的 "plug-in id"（例如为了与旧版 JUCE 保持向后兼容），请重写此函数。

默认实现将从输入和输出布局计算一个唯一整数，并将该值加到 4 字符代码 'jcaa'（用于原生 AAX）或 'jyaa'（用于 AudioSuite 插件）上。

getPageFileName()

virtual String juce::AAXClientExtensions::getPageFileName () const virtual

返回要使用的页面文件的可选文件名（包括扩展名）。

页面文件允许 AAX 插件指定其参数在各种控制面上显示的方式。有关更多信息，请阅读 AAX SDK 文档中的 Page Table Guide。

默认情况下，将在 *.aaxplugin/Contents/Resources 中搜索此文件。

getPageFileSearchPath

getPageFileSearchPath()

virtual File juce::AAXClientExtensions::getPageFileSearchPath () const inline virtual

可选地返回用于查找页面表文件的搜索路径。

这对于指定插件包之外的位置很有用，以便用户可以更改页面表文件而不会破坏任何代码签名。

如果此函数返回默认构造的 File，则将使用默认位置。AAX SDK 声明该位置为 *.aaxplugin/Contents/Resources。

注意
返回的路径应为目录的绝对路径。
