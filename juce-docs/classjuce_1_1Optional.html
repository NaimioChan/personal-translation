juce::Optional< Value > 类模板参考

详细说明

template<typename Value>
class juce::Optional< Value >

一个简单的可选类型。

在新代码中，你可能更愿意直接使用 std::optional。

在 JUCE 支持的最低语言标准低于 C++17 期间，此类旨在替代 std::optional。当最低语言标准提升到 C++17 后，此类很可能会被标记为已废弃，这与 C++11 之后 juce::ScopedPointer 因 std::unique_ptr 而废弃的方式大致相同。

这并非真正打算供 JUCE 客户端使用。相反，它是供 JUCE 代码内部使用的，其 API 与 std::optional 足够接近，以便将来某个时候能在干扰较小的情况下互换类型，但 without breaking any public APIs。
