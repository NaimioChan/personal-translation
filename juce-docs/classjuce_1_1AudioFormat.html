getFileExtensions()

virtual StringArray juce::AudioFormat::getFileExtensions () const virtual

返回可能适用于此格式文件的所有文件扩展名。

第一项将是创建新文件时首选的那个。因此对于 wav 文件，这可能只返回“.wav”；对于 AIFF 文件，它可能返回两项，“.aif”和“.aiff”

canHandleFile()

virtual bool juce::AudioFormat::canHandleFile (const File & fileToTest) virtual

如果此格式能读取给定文件，则返回 true。

子类不应在此做太多工作，只需检查扩展名或文件类型。基类实现只是将文件扩展名与构造函数中注册的某个扩展名进行比对。

getQualityOptions()

virtual StringArray juce::AudioFormat::getQualityOptions () virtual

返回写入时可使用的一组不同质量选项。

非压缩格式只会返回空数组，但对于 Ogg-Vorbis 或 MP3 之类的格式，它可能会返回一个比特率列表等。

调用 createWriterFor() 时，会传入该数组中的一个索引，用于告知格式需要哪个选项。

在以下类中重新实现： juce::FlacAudioFormat、juce::LAMEEncoderAudioFormat、juce::MP3AudioFormat、juce::OggVorbisAudioFormat、juce::OpusAudioFormat。

createWriterFor() [1/3]

virtual std::unique_ptr< AudioFormatWriter > juce::AudioFormat::createWriterFor (std::unique_ptr< OutputStream > & streamToWriteTo, const AudioFormatWriterOptions & options) pure virtual

尝试创建一个可以写入此音频格式流的对象。

如果因某种原因无法创建写入器（例如传入的参数不合适），这将返回 nullptr。

参数
streamToWriteTo对拥有输出流的 unique_ptr 的引用。如果创建写入器成功，流的所有权将转移给写入器，此参数将被置为 nullptr。如果创建写入器失败，streamToWriteTo 将保持不变，以便可再次用于创建其它格式的写入器。
options指定输出文件细节的选项。如果音频格式不支持这些设置，此函数可能返回 nullptr。

createWriterFor() [2/3]

AudioFormatWriter * juce::AudioFormat::createWriterFor (OutputStream * streamToWriteTo, double sampleRateToUse, unsigned int numberOfChannels, int bitsPerSample, const StringPairArray & metadataValues, int qualityOptionIndex)

尝试创建一个可以写入此音频格式流的对象。

返回的写入器对象可用于向流写入，之后应由调用者删除。

如果因某种原因无法创建流（例如传入的参数不合适），这将返回 nullptr。

参数
streamToWriteTo数据将被写入的流 - AudioFormatWriter 对象在不再需要时会删除它。如果此方法无法创建 AudioFormatWriter，则流不会被删除，这样调用者可以复用它来尝试打开其它格式等
sampleRateToUse文件的采样率，必须是 getPossibleSampleRates() 返回的采样率之一
numberOfChannels通道数
bitsPerSample要使用的每个采样的位数 - 必须是 getPossibleBitDepths() 返回的值之一
metadataValues写入器应尝试写入流的一组元数据值。这些具体是什么取决于格式，子类如果不想处理它们，实际上不必对它们做任何事。请查看具体的格式实现类，了解可以使用的可能值
qualityOptionIndexgetQualityOptions() 方法返回的某个压缩质量选项的索引。如果此格式没有任何质量选项，只需在此参数中传入 0，因为它会被忽略
