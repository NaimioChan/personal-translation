juce::ModifierKeys 类参考

详细说明

表示鼠标按钮和修饰键的状态。

鼠标事件和 KeyPress 对象都使用它来描述 shift、control、alt 等键的状态。

另见
KeyPress, MouseEvent::mods

isCommandDown()

bool juce::ModifierKeys::isCommandDown () const inline noexcept

检查是否设置了 'command' 键标志（在 Windows/Linux 上为 'ctrl'）。

这是一种与平台无关的方式，用于检查操作系统首选的 command 键修饰键——因此在 Mac 上它测试 cmd 键，在 Windows/Linux 上它实际上检查的是 CTRL 键。

引用了 commandModifier、testFlags()。

被以下对象引用： juce::SelectedItemSet< SelectableItemType >::addToSelectionBasedOnModifiers()、juce::LassoComponent< SelectableItemType >::dragLasso()。

isPopupMenu()

bool juce::ModifierKeys::isPopupMenu () const inline noexcept

检查用户是否试图打开弹出菜单。

它检查可能表明用户正在遵循操作系统显示弹出菜单常规方式的平台特定修饰键。

因此在 Windows/Linux 上，此方法实际上测试的是右键点击。在 Mac 上，它测试的是按下 CTRL 键或右键点击。

引用了 commandModifier、testFlags()。

被以下对象引用： juce::SelectedItemSet< SelectableItemType >::addToSelectionOnMouseDown()。
