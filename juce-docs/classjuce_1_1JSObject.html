juce::JSObject 类参考

详细说明

JSObject 表示对底层 JS 对象的所有权引用，这意味着即使后续脚本执行删除了指向它的其他句柄，它仍将保持有效。

此类的对象可用于遍历指定 Javascript 引擎内的当前对象图。

这是一个低层类，只提供直接映射到底层 Javascript Object 实现的操作。JSCursor 类通常提供更方便的接口，其中的函数可能因 Javascript 引擎的当前状态而失败。

getChild() [1/2]

JSObject juce::JSObject::getChild (const Identifier & name) const

返回一个新游标，指向父游标底层对象的一个属性，名称由参数提供。

你可以先用 hasProperty() 检查该属性是否存在，再创建此游标。如果不存在，此构造函数会创建一个新的 JS Object 并按指定名称挂到父对象下。这可用于操作对象图。

引用了 getChild()、JSObject()、name。

被以下对象引用： getChild()、getChild()。
