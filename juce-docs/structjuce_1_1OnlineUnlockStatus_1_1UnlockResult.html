juce::OnlineUnlockStatus::UnlockResult 结构体参考

详细说明

提供关于服务器在调用 attemptWebserverUnlock() 时所作回复的一些细节。

本结构体的文档由以下文件生成：
  • juce_product_unlocking/marketplace/juce_OnlineUnlockStatus.h

公共属性

String errorMessage
如果解锁操作失败，这是 Web 服务器提供的错误信息（或表示无法联系到服务器的信息）。
String informativeMessage
这是 Web 服务器返回的、应展示给用户的信息。
String urlToLaunch
如果 Web 服务器希望引导用户访问某个网页以获取更多信息，这就是它希望用户前往的 URL。
bool succeeded
如果解锁操作成功，此项将被设为 true。
