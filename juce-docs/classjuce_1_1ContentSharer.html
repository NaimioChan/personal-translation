启动内容共享会话时会传入这种类型的回调。

会话结束时，该函数会收到一个标志，表示会话是否成功。失败时，errorText 参数可能包含描述问题的字符串。

shareFilesScoped()

ScopedMessageBox juce::ContentSharer::shareFilesScoped (const Array < URL > & files, Callback callback, Component * parent = nullptr) static nodiscard

共享给定的文件。

每个 URL 应是完整文件路径，或指向应用包内的资源。对于 iOS 上的资源，如果要指定位于“content”目录中的应用包文件，应写成类似 "content/image.png" 的形式。在 Android 上你应只指定文件名，不带扩展名。

完成后你会收到带有共享结果的回调。注意：遗憾的是，在 Android 上返回的成功标志可能是错的，因为共享目标没有标准方式报告共享操作是否成功。此外，在 Android 上可选错误消息始终为空。

参数
files要共享的文件
callback共享会话结束时将在主线程上被调用的回调
parent应用于承载共享视图的组件

shareImagesScoped()

ScopedMessageBox juce::ContentSharer::shareImagesScoped (const Array < Image > & images, std::unique_ptr< ImageFileFormat > format, Callback callback, Component * parent = nullptr) static nodiscard

用于共享图像的便捷函数。

当图像已加载到内存中时这很有用。图像会先写入临时文件，因此如果相关图像已存储在磁盘上，请改为调用 shareFiles()。默认情况下图像会保存为 PNG 文件，但你可以提供自定义 ImageFileFormat 来覆盖此行为。自定义文件格式将由共享器拥有并删除。例如

Graphics g (myImage);
g.setColour (Colours::green);
g.fillEllipse (20, 20, 300, 200);
Array<Image> images;
images.add (myImage);
ContentSharer::getInstance()->shareImages (images, myCallback);

完成后你会收到带有共享结果的回调。注意：遗憾的是，在 Android 上返回的成功标志可能是错的，因为共享目标没有标准方式报告共享操作是否成功。此外，在 Android 上可选错误消息始终为空。

参数
images要共享的图像
format保存图像时使用的文件格式。如果未提供格式，将使用合理的默认值。
callback共享会话结束时将在主线程上被调用的回调
parent应用于承载共享视图的组件

shareDataScoped()

ScopedMessageBox juce::ContentSharer::shareDataScoped (const MemoryBlock & mb, Callback callback, Component * parent = nullptr) static nodiscard

用于共享任意数据的便捷函数。

数据将被写入临时文件，然后共享该文件。如果你的数据已存储在磁盘上，请改为调用 shareFiles()。

完成后你会收到带有共享结果的回调。注意：遗憾的是，在 Android 上返回的成功标志可能是错的，因为共享目标没有标准方式报告共享操作是否成功。此外，在 Android 上可选错误消息始终为空。
