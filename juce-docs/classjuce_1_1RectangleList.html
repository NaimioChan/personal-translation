详细说明

template<typename ValueType>
class juce::RectangleList< ValueType >

以复杂区域的形式维护一组矩形。

此类允许把一组矩形当作一个实心形状处理，可以添加和移除其中的矩形部分，并简化重叠或相邻的矩形。

add() [1/3]

template<typename ValueType> void juce::RectangleList < ValueType >::add (RectangleType rect) inline

把一个新矩形合并到列表中。

被添加的矩形会先被裁剪，去掉与列表中现有矩形重叠的部分，相邻的矩形会被合并进来。

矩形可以是任意大小，也可以为空，但如果它是浮点的，则不应包含任何 INF 值。
