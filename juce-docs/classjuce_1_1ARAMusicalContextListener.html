juce::ARAMusicalContextListener 类参考

详细说明

想要了解 ARAMusicalContext 对象变更的监听器的基类。

使用 ARAMusicalContext::addListener() 将你的监听器注册到 ARAMusicalContext。

didReorderRegionSequencesInMusicalContext()

virtual void juce::ARAMusicalContextListener::didReorderRegionSequencesInMusicalContext (ARAMusicalContext * musicalContext) virtual
