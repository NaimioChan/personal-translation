juce::MouseCursor 类参考

详细说明

表示鼠标光标图像。

此对象既可用于表示某个标准鼠标光标形状，也可表示由图像生成的自定义光标。

showWaitCursor()

void juce::MouseCursor::showWaitCursor () static

让系统显示其默认的 'busy'（忙碌）光标。

这会将系统光标变为沙漏或旋转彩色球，直到鼠标下次移动或调用 hideWaitCursor()。

如果消息循环即将因忙碌而阻塞几秒钟，而你想向用户提供反馈，这会很有用。

引用了 MouseCursor()。

被以下对象引用： showWaitCursor()。

hideWaitCursor()

void juce::MouseCursor::hideWaitCursor () static

如果已调用 showWaitCursor，这将使鼠标恢复正常状态。

这会查看鼠标下方的组件，并将光标更新为该组件的正确光标。
