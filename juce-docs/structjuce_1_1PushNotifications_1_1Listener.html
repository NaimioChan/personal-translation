juce::PushNotifications::Listener 结构体参考

详细说明

注册一个监听器（最好在应用启动时），以接收已收到通知的相关信息，以及异步函数调用的各种回调。

本结构体的文档由以下文件生成：

handleNotification()

virtual void juce::PushNotifications::Listener::handleNotification (bool isLocalNotification, const Notification & notification) virtual

视 OS 和具体情况而定，此函数可能在多种不同情形下被调用。

当用户按下通知时调用。

注意：在 Android 上，如果应用处于后台时收到远程通知、随后用户按下了它，则此回调中收到的通知对象只包含设置了值的 properties 成员。因此，如果你想知道通知的标题、内容等，需要把它们设为附加属性，这样才能从 properties 字典中恢复它们。

注意，如果应用是由通知启动的，那么你在启动时就可能收到此回调。

handleNotificationAction()

virtual void juce::PushNotifications::Listener::handleNotificationAction (bool isLocalNotification, const Notification & notification, const String & actionIdentifier, const String & optionalResponse) virtual

当用户对通知执行某种操作时调用，例如按下操作按钮或以文本输入作答。

注意，按下通知区域（即不是操作按钮）不算作一次操作，这种情况下将调用 receivedNotification()。

注意，如果应用是由通知的操作启动的，那么你在启动时就可能收到此回调。

参数
isLocalNotification如果该通知是本地通知
notification该通知
actionIdentifier标识该操作的 String
optionalResponse用户为带文本输入的通知输入的文本回应。对于不带文本输入选项的通知为空。

localNotificationDismissedByUser()

virtual void juce::PushNotifications::Listener::localNotificationDismissedByUser (const Notification & notification) virtual

对于 iOS10 和 Android，当用户在作出响应之前先关闭通知时，也可能调用此函数。

deliveredNotificationsListReceived()

virtual void juce::PushNotifications::Listener::deliveredNotificationsListReceived (const Array < Notification > & notifications) virtual

在 getDeliveredNotifications() 请求完成后调用。

返回在设备通知区域中可见、且仍在等待用户操作/回应的通知。

在 iOS 上需要 iOS 版本 10 或更高。在 Android 上需要 API 级别 18 或更高。对于不支持的平台，将返回空数组。

deviceTokenRefreshed()

virtual void juce::PushNotifications::Listener::deviceTokenRefreshed (const String & token) virtual

每当 token 被刷新时调用。

你应监视所有 token 更新，因为只有最后分配给设备的 token 有效、可以使用。

remoteNotificationsDeleted()

virtual void juce::PushNotifications::Listener::remoteNotificationsDeleted () virtual

当 Firebase Cloud Messaging 服务器删除待处理消息时调用。

这可能发生在以下情况：1) 发送到服务器的消息过多（提示：使用可折叠消息）。2) 设备长时间未联网（消息在 FCM 上过期前可保存的最长时间，请参考 Firebase 文档）。
