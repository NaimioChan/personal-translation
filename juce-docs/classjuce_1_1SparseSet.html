juce::SparseSet< Type > 类模板参考

详细说明

template<class Type>
class juce::SparseSet< Type >

保存一组基元值，将它们存储为一组范围。

此容器的行为类似数组，但可以高效地保存大的连续值范围。它是一个相当专门的类，主要用于诸如在列表框中保存所选行的集合之类的场景。

用作模板参数的类型必须是整数类型，例如 int、short、int64 等。
