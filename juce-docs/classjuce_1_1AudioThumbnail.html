juce::AudioThumbnail 类参考

详细说明

便于快速绘制音频文件波形形状的缩放视图。

要使用此类，只需为要绘制的文件创建一个 AudioThumbnail 类，调用 setSource 告诉它使用哪个文件或资源，然后调用 drawChannel() 绘制它。

该类将异步扫描波形文件以创建其缩小视图，因此当数据到来时，你应让 UI 重绘自身。为此，AudioThumbnail 是一个 ChangeBroadcaster，并会在其监听器应重绘自身时广播消息。

缩略图内部存储低分辨率的波形数据版本，可以加载和保存这些数据，以避免再次扫描文件。

setSource() [1/3]

bool juce::AudioThumbnail::setSource (InputSource * newSource) override virtual

指定包含音频文件的文件或流。

对于文件，只需调用

setSource (new FileInputSource (file))

你可以在这里传入 nullptr 来清除缩略图。传入的源在不再需要时将由本对象删除。

返回
如果源可以作为有效的音频文件打开则为 true，如果因某种原因失败则为 false。

setReader()

void juce::AudioThumbnail::setReader (AudioFormatReader * newReader, int64 hashCode) override virtual

直接给缩略图一个要使用的 AudioFormatReader。

这会在后台线程中开始解析音频（除非能在缩略图缓存中成功查到哈希码）。注意，读取器对象将由缩略图持有，并在不再需要时稍后删除。缩略图实际上会一直持有该读取器，直到你清除缩略图或更改输入源，因此文件在整个这段时间内都会保持打开。如果你不希望缩略图持续保持文件句柄打开，应改用 setSource() 方法，它只在需要时才打开文件。

实现 juce::AudioThumbnailBase。

drawChannel()

void juce::AudioThumbnail::drawChannel (Graphics & g, const Rectangle < int > & area, double startTimeSeconds, double endTimeSeconds, int channelNum, float verticalZoomFactor) override virtual

绘制某个通道的波形。

波形将绘制在指定的矩形内，其中 startTime 和 endTime 指定音频文件中应位于矩形左右边缘的时间点。

波形会进行垂直缩放，使满幅采样的波形在垂直方向填满矩形，但你也可以通过 verticalZoomFactor 参数额外指定一个垂直缩放系数。
