juce::AudioDeviceManager 类参考

详细说明

管理某些音频和 MIDI 输入/输出设备的状态。

该类跟踪当前选定的音频设备，并通过它从音频回调持续流式传输数据，同时还跟踪一个或多个 MIDI 输入。

思路是，你的应用创建该对象的一个全局实例，让它在内部负责特定类型音频设备的创建与删除。这样当设备变更时，你的回调只需继续运行，无需关心这些。

管理器可以将它的所有设备设置保存为 XML 并重新加载，这使你非常容易保存和重新加载应用的音频设置。

为了便于让用户修改其设置，有一个专门的组件——AudioDeviceSelectorComponent 类，它包含一组设备选择/采样率/延迟控件。

要使用 AudioDeviceManager，请创建一个，并用 initialise() 进行设置。然后调用 addAudioCallback() 向它注册你的音频回调，并用它来处理音频数据。

该管理器还是传入 MIDI 消息的便捷枢纽，允许监听器注册接收来自某个特定 MIDI 设备或来自当前默认 MIDI 输入设备的消息。这样监听器就不必担心在 MIDI 设备被更改或删除时重新注册。

还有一个巧妙之处：所消耗的 CPU 时间会被测量，并可通过 getCpuUsage() 方法获取。

AudioDeviceManager 是一个 ChangeBroadcaster，当其任何设置发生变化时，会向监听器发送变更消息。

initialise()

String juce::AudioDeviceManager::initialise (int maxNumInputChannelsNeeded, int maxNumOutputChannelsNeeded, const XmlElement * savedState, bool selectDefaultDeviceOnFailure, const String & preferredDefaultDeviceName = String (), const AudioDeviceSetup * preferredSetupOptions = nullptr)

打开一组可供使用的音频设备。

这将尝试打开默认音频设备，或先前保存为 XML 的设备。

参数
maxNumInputChannelsNeeded你的应用希望使用的最大输入通道数（实际打开的通道数可能少于请求的数量）
maxNumOutputChannelsNeeded你的应用希望使用的最大输出通道数（实际打开的通道数可能少于请求的数量）
savedState可以是先前由 createStateXml() 生成并保存的状态，如果想让管理器自行选择要打开的最佳设备，则为 nullptr。
selectDefaultDeviceOnFailure如果为 true，那么当 XML 中指定的设备打开失败时，会改用默认设备。如果为 false，则失败时不打开任何设备。
preferredDefaultDeviceName如果此项不为空，且存在具有该名称的设备，则该设备将用作默认设备（假设 XML 中未指定设备）。该字符串实际上可以是包含“*”和“?”字符的简单通配符
preferredSetupOptions如果此项非空，打开设备时该结构体将用作首选的设置集合。如果你使用此参数，preferredDefaultDeviceName 字段将被忽略。如果将 AudioDeviceSetup 的 outputDeviceName 或 inputDeviceName 数据成员设为空字符串，则会使用默认设备。
返回
如果出现任何错误，则为错误消息；如果一切正常，则为空字符串。

setAudioDeviceSetup()

String juce::AudioDeviceManager::setAudioDeviceSetup (const AudioDeviceSetup & newSetup, bool treatAsChosenDevice)

更改当前设备或其设置。

如果你想更改设备属性，比如当前采样率或块大小，可以调用 getAudioDeviceSetup() 获取当前设置，然后调整 AudioDeviceSetup 结构中的相应字段，再将其传回此方法以应用新设置。

参数
newSetup你希望使用的设置。如果你不需要输入或输出设备，请分别将 inputDeviceName 或 outputDeviceName 数据成员设为空字符串。注意此行为与 initialise() 的行为不同。
treatAsChosenDevice如果为 true 且设备正确打开，这些新设置将被视为由用户显式选择，下次调用 createStateXml() 时将返回这些设置。如果为 false，则该设备被视为临时或默认设备，调用 createStateXml() 将返回最近一次以 treatAsChosenDevice 为 true 所做的设置，或最近一次传入 initialise() 的 XML 设置。
返回
如果出现任何错误，则为错误消息；如果一切正常，则为空字符串。

addAudioCallback()

void juce::AudioDeviceManager::addAudioCallback (AudioIODeviceCallback * newCallback)

注册要使用的音频回调。

管理器会将来自当前所用音频设备的回调转发给所有已注册的回调对象。如果有多个回调处于活动状态，它们都会获得相同的输入数据，其输出将被求和。

如有必要，此方法会在返回前对回调对象调用 audioDeviceAboutToStart()。

要移除回调，请使用 removeAudioCallback()。

setMidiInputDeviceEnabled()

void juce::AudioDeviceManager::setMidiInputDeviceEnabled (const String & deviceIdentifier, bool enabled)

启用或禁用某个 MIDI 输入设备。

设备列表可通过 MidiInput::getAvailableDevices() 方法获取。

来自已启用输入设备的任何传入消息都会转发给所有已用 addMidiInputDeviceCallback() 方法注册的监听器。它们可以注册接收来自特定设备的消息，或仅接收来自“默认”MIDI 输入的消息。

通过 AudioDeviceManager 路由 MIDI 输入意味着，当监听器注册接收默认 MIDI 输入时，管理器可以更改这个默认设备，而监听器无需知晓或重新注册。

这也意味着监听器可以对一个已禁用或不存在的 MIDI 输入保持注册，这样当该输入重新启用时，监听器会重新开始接收消息。
