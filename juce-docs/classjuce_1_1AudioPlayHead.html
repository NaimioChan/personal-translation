juce::AudioPlayHead 类参考

详细说明

AudioPlayHead 的子类可以在音频播放期间提供移动播放头的位置和状态信息。

可以将其中的一个提供给 AudioProcessor 对象，以便它了解正在渲染的音频的位置。

另见
AudioProcessor::setPlayHead, AudioProcessor::getPlayHead

getCurrentPosition()

bool juce::AudioPlayHead::getCurrentPosition (CurrentPositionInfo & result) inline

已废弃，请改用 getPosition()。

用当前处理块开始时走带位置的详细信息填充给定结构体。如果此方法返回 false，则当前播放头位置不可用，给定结构体的内容将是未定义的。

你只能从 processBlock() 方法中调用它！在其他时候调用会产生未定义行为，因为宿主可能没有可让时间有意义的上下文，而且如果不是在音频线程上调用，某些宿主几乎肯定会有多线程问题。

引用了 juce::AudioPlayHead::CurrentPositionInfo::bpm、juce::AudioPlayHead::CurrentPositionInfo::editOriginTime、juce::AudioPlayHead::CurrentPositionInfo::frameRate、getPosition()、juce::AudioPlayHead::CurrentPositionInfo::isLooping、juce::AudioPlayHead::CurrentPositionInfo::isPlaying、juce::AudioPlayHead::CurrentPositionInfo::isRecording、juce::AudioPlayHead::CurrentPositionInfo::ppqLoopEnd、juce::AudioPlayHead::CurrentPositionInfo::ppqLoopStart、juce::AudioPlayHead::CurrentPositionInfo::ppqPosition、juce::AudioPlayHead::CurrentPositionInfo::ppqPositionOfLastBarStart、juce::AudioPlayHead::CurrentPositionInfo::resetToDefault()、juce::AudioPlayHead::CurrentPositionInfo::timeInSamples、juce::AudioPlayHead::CurrentPositionInfo::timeInSeconds、juce::AudioPlayHead::CurrentPositionInfo::timeSigDenominator、juce::AudioPlayHead::CurrentPositionInfo::timeSigNumerator。

getPosition()

virtual Optional < PositionInfo > juce::AudioPlayHead::getPosition () const pure virtual

获取当前处理块开始时走带位置的详细信息。

如果此方法返回 nullopt，则当前播放头位置不可用。

非空返回值只表示宿主能够提供某些*相关计时信息。各个 PositionInfo 的 getter 仍可能返回 nullopt。

你只能从 processBlock() 方法中调用它！在其他时候调用会产生未定义行为，因为宿主可能没有可让时间有意义的上下文，而且如果不是在音频线程上调用，某些宿主几乎肯定会有多线程问题。
