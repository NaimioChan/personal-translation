juce::ImageCache 类参考

详细说明

已从文件或内存加载的图像的全局缓存。

如果你加载了一个图像，并可能需要在多个地方使用它，可以用它让同一个图像被共享，而不是将多份副本加载到内存中。

另一个好处是，图像被释放后会在内存中保留几秒钟才真正删除，因此如果你反复加载/删除同一个图像，可以减少每次都要重新加载的几率。

成员函数

getFromFile()

Image juce::ImageCache::getFromFile (const File & file) static

从文件加载图像（如果已缓存，则直接返回该图像）。

如果缓存中已包含从此文件加载的图像，则返回该图像。否则，此方法会尝试加载该文件，将其添加到缓存并返回。

记住，返回的图像是共享的，因此绘制到它上面可能会影响正在使用它的其他对象！如果你想在它上面绘制，请先调用 Image::duplicateIfShared()

参数
file要尝试加载的文件
返回
图像；如果加载出错则为空
另见
getFromMemory, getFromCache, ImageFileFormat::loadFrom

getFromMemory()

Image juce::ImageCache::getFromMemory (const void * imageData, int dataSize) static

从内存中的图像文件加载图像（如果已缓存，则直接返回该图像）。

如果缓存中已包含从此内存块加载的图像，则返回该图像。否则，此方法会尝试加载该文件，将其添加到缓存并返回。

记住，返回的图像是共享的，因此绘制到它上面可能会影响正在使用它的其他对象！如果你想在它上面绘制，请先调用 Image::duplicateIfShared()

参数
imageData包含图像数据的内存块
dataSize数据大小（以字节为单位）
返回
图像；如果加载出错则为无效图像
另见
getFromMemory, getFromCache, ImageFileFormat::loadFrom

getFromHashCode()

Image juce::ImageCache::getFromHashCode (int64 hashCode) static

在缓存中查找具有特定哈希码的图像。

如果缓存中有此哈希码的图像，则返回它，否则返回无效图像。

参数
hashCode由 addImageToCache() 与该图像关联的哈希码

addImageToCache()

void juce::ImageCache::addImageToCache (const Image & image, int64 hashCode) static

用用户定义的哈希码将图像添加到缓存。

传入的图像会被缓存引用（而不是复制），因此添加之后最好不要绘制到它上面，否则会影响可能正在使用它的所有实例。

参数
image要添加的图像
hashCode要与它关联的哈希码
另见
getFromHashCode
