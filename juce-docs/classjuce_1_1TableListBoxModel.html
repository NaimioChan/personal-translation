juce::TableListBoxModel 类参考

详细说明

其中之一被 TableListBox 用作表格内容的数据模型。

你在此类中重写的虚方法负责绘制表格单元格以及响应事件。

getNumRows()

virtual int juce::TableListBoxModel::getNumRows () pure virtual

必须返回表格中当前的行数。

如果行数发生变化，必须调用 TableListBox::updateContent() 让列表刷新。

paintRowBackground()

virtual void juce::TableListBoxModel::paintRowBackground (Graphics &, int rowNumber, int width, int height, bool rowIsSelected) pure virtual

必须绘制表格中某一行的背景。

图形上下文的原点位于该行的左上角，你的方法应填充由 width 和 height 参数指定的区域。

注意，rowNumber 的值可能大于列表中的行数，因此要小心不要假设它小于 getNumRows()。

paintCell()

virtual void juce::TableListBoxModel::paintCell (Graphics &, int rowNumber, int columnId, int width, int height, bool rowIsSelected) pure virtual

必须绘制其中一个单元格。

图形上下文的原点已设置为单元格的左上角，其尺寸由 (width, height) 指定。

注意，rowNumber 的值可能大于列表中的行数，因此要小心不要假设它小于 getNumRows()。

refreshComponentForCell()

virtual Component * juce::TableListBoxModel::refreshComponentForCell (int rowNumber, int columnId, bool isRowSelected, Component * existingComponentToUpdate) virtual

用于创建或更新单元格中使用的自定义组件。

任何单元格都可以包含自定义组件，也可以只用 paintCell() 方法绘制，并用 cellClicked() 处理鼠标点击。

每当自定义组件可能需要更新时都会调用此方法——例如表格发生变化，或调用了 TableListBox::updateContent()。

如果指定单元格不需要自定义组件，则返回 nullptr。（请记住，即使你不创建新组件，仍可能需要删除非空的 existingComponentToUpdate。）

如果你确实需要自定义组件，而 existingComponentToUpdate 为空，则此方法必须创建一个适合该单元格的新组件并返回它。

如果 existingComponentToUpdate 非空，它是指向此前由该方法创建的组件的指针。此时该方法必须更新它，以确保正确表示给定的单元格（可能与创建该组件时所对应的单元格不同），也可以删除此组件并返回一个新组件。

sortOrderChanged()

virtual void juce::TableListBoxModel::sortOrderChanged (int newSortColumnId, bool isForwards) virtual

当表格的排序顺序改变时，会发起此回调。

这可能是因为用户点击了列标题，或因为调用了 TableHeaderComponent::setSortColumnId() 方法。

如果实现此方法，你的方法应以给定列作为键重新排序表格。

getColumnAutoSizeWidth()

virtual int juce::TableListBoxModel::getColumnAutoSizeWidth (int columnId) virtual

返回某一列的最佳宽度。

如果实现此方法，应测量此列中所有项目的宽度并返回最佳尺寸。

返回 0 表示不应更改该列。

这由 TableListBox::autoSizeColumn() 和 TableListBox::autoSizeAllColumns() 使用。

getDragSourceDescription()

virtual var juce::TableListBoxModel::getDragSourceDescription (const SparseSet < int > & currentlySelectedRows) virtual

若要让表格中的行可拖放，请实现此方法。

如果此方法返回非空 variant，则当用户拖动某行时，表格会在其父级层次结构中查找 DragAndDropContainer，并用它触发拖放操作，以此字符串作为源描述，以列表框本身作为源组件。

另见
getDragSourceCustomData，DragAndDropContainer::startDragging

mayDragToExternalWindows()

virtual bool juce::TableListBoxModel::mayDragToExternalWindows () const inline virtual

在对列表行开始拖动操作时调用，以确定该项是否可被拖到其它窗口。

默认返回 true。
