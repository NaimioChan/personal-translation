juce::CameraDevice 类参考

详细说明

控制可能可用的任何视频采集设备。

使用 getAvailableDevices() 列出连接到系统的设备，然后调用 openDevice() 或 openDeviceAsync() 打开其中一个来使用。获得 CameraDevice 对象后，你可以从中获取查看器组件，并用其方法流式写入文件或捕获静态帧。

openDevice()

CameraDevice * juce::CameraDevice::openDevice (int deviceIndex, int minWidth = 128, int minHeight = 64, int maxWidth = 1024, int maxHeight = 768, bool highQuality = true) static

同步打开摄像头设备。

此函数不应用于 iOS 或 Android，请改用 openDeviceAsync()。

index 参数表示要打开 getAvailableDevices() 返回的项中的哪一个。

如果摄像头支持，尺寸约束允许该方法在不同的分辨率之间选择。如果无法指定分辨率（例如在 Mac 上），这些约束将被忽略。

在 Mac 上，如果 highQuality 为 false，摄像头将以预览模式打开，这允许在计算机处理帧跟不上时由操作系统丢帧。

openDeviceAsync()

void juce::CameraDevice::openDeviceAsync (int deviceIndex, OpenCameraResultCallback resultCallback, int minWidth = 128, int minHeight = 64, int maxWidth = 1024, int maxHeight = 768, bool highQuality = true) static

在 iOS 或 Android 上异步打开摄像头设备。

在其他平台上，该函数只是调用 openDevice()。完成后，成功时将以有效的 CameraDevice* 和空的错误 String 调用 resultCallback，失败时则以 nullptr CameraDevice 和非空的错误 String 调用。

这是打开摄像头设备的首选方式，因为它在所有平台上均可工作，而同步的 openDevice() 在 iOS 和 Android 上不可用。

index 参数表示要打开 getAvailableDevices() 返回的项中的哪一个。

如果摄像头支持，尺寸约束允许该方法在不同的分辨率之间选择。如果无法指定分辨率，这些约束将被忽略。

在 iOS 上，如果你想切换设备，先打开新设备再关闭旧设备会更高效，因为这样两个设备可以共享同一个底层摄像头会话。否则必须先关闭会话，而这是一个可能需要数秒的漫长过程。

Android 实现目前支持的最大录制分辨率为 1080p。选择更大的尺寸会使拍摄的照片更大，但视频将被限制在 1080p。

takeStillPicture()

void juce::CameraDevice::takeStillPicture (std::function< void(const Image &)> pictureTakenCallback)

触发静态照片捕获。

完成后，将在消息线程上调用 pictureTakenCallback。

在 Android 上，调用 takeStillPicture() 之前，你需要用 createViewerComponent() 创建预览，并需要让它在屏幕上可见。

Android 不支持同时录制视频和拍摄静态照片。

startRecordingToFile()

void juce::CameraDevice::startRecordingToFile (const File & file, int quality = 2)

开始将视频录制到指定文件。

你应使用 getFileExtension() 找出文件名应使用的正确扩展名。

如果文件已存在，将在录制开始前被删除。

此方法可能不会立即开始录制，因此如果你需要知道文件开始的确切时间，可以在录制结束后调用 getTimeOfFirstRecordedFrame()。

quality 参数可以是 0、1 或 2，分别表示低、中、高。是否实际使用取决于驱动。

在 Android 上，调用 takeStillPicture() 之前，你需要用 createViewerComponent() 创建预览，并需要让它在屏幕上可见。

Android 摄像头还需要独占访问音频设备，因此请务必先用 AudioDeviceManager::closeAudioDevice() 关闭任何已打开的音频设备。

Android 不支持同时录制视频和拍摄静态照片。

AudioDeviceManager::closeAudioDevice, AudioDeviceManager::restartLastAudioDevice
