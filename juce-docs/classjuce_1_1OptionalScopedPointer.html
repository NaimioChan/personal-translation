juce::OptionalScopedPointer< ObjectType > 类模板参考

详细说明

template<class ObjectType>
class juce::OptionalScopedPointer< ObjectType >

持有一个指向某对象的指针，可在此指针离开作用域时选择是否删除该对象。

它在许多方面的行为类似 std::unique_ptr，但允许你指定是否删除该对象。

OptionalScopedPointer() [2/5]

template<class ObjectType> juce::OptionalScopedPointer < ObjectType >::OptionalScopedPointer (ObjectType * objectToHold, bool takeOwnership) inline

创建一个 OptionalScopedPointer 指向给定对象，并指定 OptionalScopedPointer 是否将其删除。

如果 takeOwnership 为 true，则 OptionalScopedPointer 的行为类似 std::unique_ptr，在自身被删除时删除该对象。如果此参数为 false，则 OptionalScopedPointer 只持有指向该对象的普通指针，不会删除它。
