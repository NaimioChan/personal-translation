juce::EnumerateIterator< Iter, Index > 类模板参考

详细说明

template<typename Iter, typename Index = ptrdiff_t>
class juce::EnumerateIterator< Iter, Index >

一个包装其他迭代器的迭代器，根据对 operator++()、operator--()、operator+() 和 operator-() 等算术运算符的调用跟踪该迭代器的相对位置。

你应当永远不需要自己构造此类型的实例。而应使用 enumerate() 函数构造一个可枚举的范围。
