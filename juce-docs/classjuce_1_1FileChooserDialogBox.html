juce::FileChooserDialogBox 类参考

详细说明

文件打开/保存对话框。

这是基于 Juce 的文件对话框；要使用原生文件选择器，请参阅 FileChooser 类。

{
    wildcardFilter = std::make_unique<WildcardFileFilter> ("*.foo", String(), "Foo files");

    browser = std::make_unique<FileBrowserComponent> (FileBrowserComponent::canSelectFiles,
 File(),
                                                      wildcardFilter.get(),
 nullptr);

    dialogBox = std::make_unique<FileChooserDialogBox> ("Open some kind of file",
 "Please choose some kind of file that you want to open...",
                                                        *browser,
 false,
 Colours::lightgrey);

 auto onFileSelected = [this] (int r)
    {
        modalStateFinished (r);

 auto selectedFile = browser->getSelectedFile (0);

        ...etc...
    };

    dialogBox->centreWithDefaultSize (nullptr);
    dialogBox->enterModalState (true,
 ModalCallbackFunction::create (onFileSelected),
 false);
}

构造函数与析构函数

FileChooserDialogBox()

juce::FileChooserDialogBox::FileChooserDialogBox (const String & title, const String & instructions, FileBrowserComponent & browserComponent, bool warnAboutOverwritingExistingFiles, Colour backgroundColour, Component * parentComponent = nullptr)

创建一个文件选择框。

参数
title显示在该框顶部的主标题
instructions可选的较长文本，以较小字体显示在标题下方，更详细地描述需要做什么。
browserComponent将显示在此对话框内的 FileBrowserComponent。请确保在对话框被删除之后（而不是之前！）删除它。
warnAboutOverwritingExistingFiles如果为 true，当用户尝试选择已存在的文件时会被要求确认。（此标志仅在保存文件时使用）
backgroundColour顶层窗口的背景颜色
parentComponent可选组件，应作为文件选择器的父级。如果为 nullptr，则对话框将是顶层窗口。iOS 上的 AUv3 必须指定此参数，因为由于沙盒限制，在 AUv3 中打开顶层窗口是被禁止的。
另见
FileBrowserComponent, FilePreviewComponent
