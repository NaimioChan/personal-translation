withNativeZoomGesture()

LinuxWkWebView juce::WebBrowserComponent::Options::LinuxWkWebView::withNativeZoomGesture (bool x) const inline nodiscard

指定捏合缩放和 CTRL + 滚轮手势是否由 WebView 原生处理。

默认情况下此项禁用，两个事件都会传播到 WebView 托管的页面，在那里可作为 CTRL + 滚轮上/下事件处理。

如果你启用此选项，页面将不再接收这些事件，缩放操作将改由 WebView 无条件执行。此行为与其他任何操作系统实现都不同，因此默认禁用。

引用了 juce::withMember()、x。

withPinchTranslationSensitivity()

LinuxWkWebView juce::WebBrowserComponent::Options::LinuxWkWebView::withPinchTranslationSensitivity (float x) const inline nodiscard

在启用默认 GTK 到 Javascript 转换时，应用于 Linux 上滚轮事件 deltaY 参数的乘数。

默认值为 100.0f。

要禁用此转换，请调用 withNativeZoomGesture (true)。此后在触控板捏合手势期间将不会收到任何滚轮事件。
