juce::Font 类参考

详细说明

表示一种特定的字体，包括其大小、样式等。

除所用的字形外，Font 对象还决定字体是否粗体、斜体、带下划线、大小如何，以及它的字距和水平缩放系数。

setTypefaceName()

void juce::Font::setTypefaceName (const String & faceName)

更改字体的字体族。

例如 "Arial"、"Courier" 等。

也可以将其设为 Font::getDefaultSansSerifFontName()、Font::getDefaultSerifFontName() 或 Font::getDefaultMonospacedFontName()，它们不是平台特定的实际字体族名称，而是用于表示各种默认字体的通用字体族名称。如果你需要知道正在使用的确切字体族，可以调用 Font::getTypefacePtr()->getName()，它会给出平台特定的字体族。

如果机器上找不到合适的字体，就会改用默认字体。

getHeight()

float juce::Font::getHeight () const noexcept

返回此字体的总高度（像素）。

这是最大高度，从上升部的顶部到下伸部的底部。

不过也有一个值得注意的例外：如果你使用了 ascent/descent 覆盖特性。该特性遵循 CSS 语义，作用于 Font 的磅高度。因此，如果你用 setHeight() 指定了字体高度，同时又指定了 ascent 或 descent 覆盖，那么 Font 的视觉渲染高度可能与 getHeight() 返回的值不同。

setAscentOverride()

void juce::Font::setAscentOverride (std::optional< float >)

此设计用于对应 CSS 的 ascent-override 属性。

当字号以磅为单位指定时（使用 setPointHeight()、FontOptions::withPointHeight() 等），字体的 ascent 值（以磅为单位）将等于字号的磅值乘以覆盖值。也就是说，如果字号为 14pt、ascent 覆盖值为 0.5f，则 ascent 为 7pt。

当字号是 not 以磅为单位指定时（使用 setHeight()、FontOptions::withHeight() 等），其行为更为微妙。ascent 覆盖值仍然以字体 em 尺寸的比例来指定字体上升部的大小。不过，现在字体的磅值是通过将 JUCE 高度乘以高度到磅的换算因子得到的，该因子等于 (1.0f / (ascent-in-em-units + descent-in-em-units))。举例来说，如果 JUCE 字体高度为 14、ascent 覆盖值为 0.5f、descent 覆盖值为 0.5f，则字号为 14pt、ascent 为 7pt。将 ascent 覆盖值改为 1.0f、descent 覆盖值改为 0.0f，字号仍保持 14pt，但上升部为 14pt、下降部为 0pt。将 ascent 和 descent 覆盖值都改为 1.0f，字号会变为 7pt，ascent 为 3.5pt。

setDirect2DHinting()

void juce::Font::setDirect2DHinting (bool)

按指定方式启用或禁用 Direct2D hinting。

默认状态为启用。

此选项目前仅在使用 Direct2D 渲染器的 Windows 上生效。

与软件渲染器或 OpenGL 渲染器相比，某些字体在 Direct2D 渲染器下可能看起来差别很大。像 MS PGothic 这样的字体为特定字号提供了带 hinting 的位图，而这些位图可能比字体同时提供的轮廓显得细得多。软件渲染器总是光栅化字体轮廓，而 Direct2D 默认会使用内置位图（如果存在），这更贴近字体设计者的意图。禁用此选项会让 Direct2D 以类似软件渲染器的方式光栅化字体轮廓，从而得到更接近软件渲染器的结果（也就是 JUCE 的传统行为）。

findSuitableFontForText()

Font juce::Font::findSuitableFontForText (const String & text, const String & language = {}) const

尝试找到一个视觉上相似、且能够渲染所提供字符串的字体。

如果通过 setFallbackEnabled() 在这个 Font 上禁用了回退，则此方法总是返回当前 Font 的副本。

否则，会先检查当前字体，再检查 setPreferredFallbackFamilies() 指定的每一个回退字体，并返回第一个能够渲染该字符串的 Font。如果这些字体都不合适，则会使用系统字体回退机制，从当前已安装的字体中查找一个字体。如果系统也找不到合适的字体，则返回原始 Font 的副本。

注意，大多数字体并不包含所有可能的 Unicode 码点的字形，而可能只包含特定文字系统所需的字形。因此，如果所提供的文本要用多种文字系统显示（多种语言、emoji 等），那么很可能没有单个字体能渲染整个文本。较短的字符串通常比较长的字符串产生更好的回退结果，但要注意系统在选择合适字体时可能会考虑组合标记和变体选择符等控制字符，因此逐字符查询回退可能会得到很差的结果。

引用了 Font()、withTypefaceStyle()。

被以下对象引用： setTypefaceName()。
