callFunctionOnMessageThread()

void * juce::MessageManager::callFunctionOnMessageThread (MessageCallbackFunction * callback, void * userData)

使用消息线程调用一个函数。

任何线程都可以调用此方法，让消息线程回调此函数。如果调用此方法的就是消息线程，那么函数会被直接调用；如果是其他线程调用，则会向队列投递一条消息，此方法会阻塞，直到该消息被投递、函数被调用并返回结果。

当心不要因此造成死锁！这很容易发生——例如调用线程持有一个临界区，而某个无关的消息回调在消息线程处理到此回调之前试图锁定它。

参数
callback要调用的函数——其签名必须为
void* myCallbackFunction (void*)
userData用户定义的指针，会传递给被调用的函数
返回
回调函数返回的值。
另见
MessageManagerLock

callSync()

template<typename Function> auto juce::MessageManager::callSync (Function && function) -> CallSyncResult< decltype(function())> inline static

与 callFunctionOnMessageThread() 类似，在消息线程上调用一个函数，并阻塞当前线程直到有结果可用。

当心不要因此造成死锁！这很容易发生——例如调用线程持有一个临界区，而某个无关的消息回调在消息线程处理到此回调之前试图锁定它。

参数
function要调用的函数，它不应带任何参数
返回
如果 function() 返回 void，则 callSync 返回布尔值，其中 'true' 表示函数被成功调用，'false' 表示消息无法投递。如果 function() 返回其他类型 'T'，则 callSync 返回 std::optional<T>，函数被成功调用时该可选值有效，否则为 nullopt。

引用了 callAsync()、getInstance()、isThisTheMessageThread()、jassertfalse。
