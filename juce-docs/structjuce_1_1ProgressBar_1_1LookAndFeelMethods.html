drawProgressBar()

virtual void juce::ProgressBar::LookAndFeelMethods::drawProgressBar (Graphics &, ProgressBar &, int width, int height, double progress, const String & textToShow) pure virtual

绘制进度条。

如果进度值小于 0 或大于 1.0，则应绘制一个填满整个空间的旋转条（即表示应用仍在忙碌但进度未知）。它可以使用当前时间作为播放动画的依据。

要确定绘制哪种样式的进度条，请调用 getResolvedStyle()。

（供 AlertWindow 中的进度条使用）。
