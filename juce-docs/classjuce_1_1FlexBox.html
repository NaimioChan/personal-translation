juce::FlexBox 类参考

详细说明

表示一个 FlexBox 容器，它包含并管理一组 FlexItem 对象的布局。

要使用此类，请适当设置其参数（你可以在线搜索更多关于 FlexBox 协议工作原理的帮助！），然后将子项添加到 items 数组中，并在你的 Component 的 resized() 函数中调用 performLayout()。

成员数据文档

flexDirection

Direction juce::FlexBox::flexDirection = Direction::row

指定 flex 项在 flex 容器中的放置方式，并定义主轴方向。

flexWrap

Wrap juce::FlexBox::flexWrap = Wrap::noWrap

指定项是强制放在单行中，还是可以换行到多行。

如果允许换行，此属性还控制各行的堆叠方向。

alignContent

AlignContent juce::FlexBox::alignContent = AlignContent::stretch

指定当交叉轴上有额外空间时，flex 容器的各行在其中的放置方式。

此属性对单行布局没有影响。

alignItems

AlignItems juce::FlexBox::alignItems = AlignItems::stretch

指定 flex 项沿每一行交叉轴的对齐方式。

justifyContent

JustifyContent juce::FlexBox::justifyContent = JustifyContent::flexStart

定义容器如何沿主轴在项之间及周围分配空间。

对齐是在应用长度和自动外边距之后进行的，因此如果至少有一个 flex-grow 不为 0 的弹性元素，它将不起作用，因为不会存在任何可用空间。

items

Array < FlexItem > juce::FlexBox::items

要布局的项集合。
