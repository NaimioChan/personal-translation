juce::LookAndFeel 类参考

详细说明

LookAndFeel 对象定义所有 JUCE 控件的外观，其子类可用于为应用程序应用不同的“皮肤”。

此类是抽象基类——有关你可以实例化的实际外观风格，请参见 LookAndFeel_V1、LookAndFeel_V2 和 LookAndFeel_V3。

findColour()

Colour juce::LookAndFeel::findColour (int colourId) const noexcept

查找已用给定颜色 ID 号注册的颜色。

如果已使用 setColour() 为此 ID 编号设置了颜色，则返回该颜色。如果未设置，则只返回 Colours::black。

各种用途的颜色 ID 作为枚举存储在其相关的组件中 —— 例如参见 Slider::ColourIds、Label::ColourIds、TextEditor::ColourIds、TreeView::ColourIds 等。

如果你要查找用于绘制组件的颜色，通常最好不要直接调用此方法，而应使用 Component::findColour() 方法。它会先检查是否已直接向组件注册了合适的颜色，如果找不到，则回退到调用组件的 LookAndFeel 的 findColour() 方法。

getDefaultMetricsKind()

virtual TypefaceMetricsKind juce::LookAndFeel::getDefaultMetricsKind () const inline virtual

控件可以调用此方法，了解在创建自己的字体时应使用哪种度量类型。

默认实现返回可移植度量类型，但如果你希望改用旧版度量类型以避免现有项目中的渲染变化，可以重写此方法。在度量类型之间切换可能导致文本以不同大小渲染，因此你应检查应用中文本的渲染大小是否仍然合适，并在重写此函数后必要时调整字体大小。

你可以通过重载 getTypefaceForFont() 执行更复杂的字体样式替换，但这样可让你轻松设置全局字体样式。
