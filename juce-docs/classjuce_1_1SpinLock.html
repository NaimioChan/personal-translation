juce::SpinLock 类参考

详细说明

一个简单的自旋锁类，可用作无竞争情况下的简单、低开销互斥量。

注意，与 CriticalSection 不同，这种锁不可重入，并且在高竞争情况下使用时效率可能较低，但它非常小且几乎不需要初始化。它最适合你只会短暂持有锁的简单情况。

void juce::SpinLock::enter () const noexcept

获取锁。

这会一直阻塞，直到此线程成功获取锁。注意 SpinLock 不可重入，也无法聪明到判断调用线程是否已持有该锁——因此如果某个线程尝试获取它已持有的锁，此方法将永不返回！

强烈建议你永远不要直接调用此方法——而应使用 ScopedLockType 类以 RAII 模式管理加锁。
