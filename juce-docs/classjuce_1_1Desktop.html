setKioskModeComponent()

void juce::Desktop::setKioskModeComponent (Component * componentToUse, bool allowMenusAndBars = true)

接收一个组件并使其全屏，同时移除任务栏、程序坞等。

组件必须已在桌面上，此方法才能生效。它将被调整为完全填满屏幕，任何多余的任务栏、菜单栏等都会被隐藏。

要退出展台模式，只需调用 setKioskModeComponent (nullptr)。调用后，当前使用的组件将恢复为进入该模式之前的大小和位置。

如果 allowMenusAndBars 为 true，当鼠标移到菜单和程序坞（在 Mac 上）等位置时仍允许它们弹出。如果为 false，则会尽量隐藏屏幕上的各种零碎元素。

引用了 Component、setKioskModeComponent()。

被以下对象引用： getMouseWheelMoveCounter()。

beginDragAutoRepeat()

void juce::Desktop::beginDragAutoRepeat (int millisecondsBetweenCallbacks)

确保在当前鼠标拖动操作期间持续发送不间断的鼠标拖动事件。

这让你可以确保即使鼠标未移动，mouseDrag() 事件也会持续发送。这在鼠标接近边缘时自动滚动组件等情况下很有用。

在 mouseDown() 或 mouseDrag() 回调中调用此方法，指定连续鼠标拖动回调之间的最小间隔。回调会持续到鼠标释放，之后间隔将被重置，因此你需要确保每次开始拖动事件时都调用它。传入 0 或更小的间隔将取消自动重复。

另见
mouseDrag

引用了 JUCE_CALLTYPE。

被以下对象引用： getMouseWheelMoveCounter()。
