juce::StreamingSocket 类参考

详细说明

流式（TCP）套接字的封装。

这允许对套接字进行底层使用；如需在套接字之上使用更易用的消息传递层，你还可以试试 InterprocessConnection 类。

另见
DatagramSocket, InterprocessConnection, InterprocessConnectionServer

StreamingSocket() [1/2]

juce::StreamingSocket::StreamingSocket ()

创建一个未初始化的套接字。

要连接它，请使用 connect() 方法，之后你可以对其 read() 或 write()。

要等待其他套接字连接到此套接字，请用 createListener() 方法进入“监听”模式，它可用于为每个到来的连接创建新套接字。

被以下对象引用： waitForNextConnection()。

bindToPort() [2/2]

bool juce::StreamingSocket::bindToPort (int localPortNumber, const String & localAddress)

将套接字绑定到指定的本地端口和本地地址。

如果 localAddress 不是空字符串，则套接字也将绑定到 localAddress。如果你想将套接字绑定到特定的网络适配器，这会很有用。注意，localAddress 必须是分配给你的某个网络地址的 IP 地址，否则此函数将失败。

返回
成功时返回 true；false 可能表示另一个套接字已绑定到同一端口
另见

waitUntilReady()

int juce::StreamingSocket::waitUntilReady (bool readyForReading, int timeoutMsecs)

等待直到套接字可读或可写。

如果 readyForReading 为 true，它将等待直到套接字可读；如果为 false，则等待直到其可写。

如果超时小于 0，将永远等待，否则在指定时间后放弃。

返回
返回时如果套接字已就绪则返回 1，如果在套接字就绪之前超时则返回 0，如果发生错误则返回 -1

read()

int juce::StreamingSocket::read (void * destBuffer, int maxBytesToRead, bool blockUntilSpecifiedAmountHasArrived)

从套接字读取字节。

如果 blockUntilSpecifiedAmountHasArrived 为 true，该方法将阻塞直到读取了 maxBytesToRead 个字节（或直到发生错误）。如果此标志为 false，该方法将在不阻塞的情况下返回当前可用的数据。

返回
读取的字节数，如果出错则返回 -1
另见
waitUntilReady

write()

int juce::StreamingSocket::write (const void * sourceBuffer, int numBytesToWrite)

从缓冲区向套接字写入字节。

返回

createListener()

bool juce::StreamingSocket::createListener (int portNumber, const String & localHostName = String ())

将此套接字置于“监听”模式。

处于此模式时，你的线程可以反复调用 waitForNextConnection()，它会为每个新连接创建新套接字，以便由其他线程并行处理。

参数
portNumber要监听的端口号
localHostName要监听的接口地址——传入空字符串表示监听所有地址
返回
如果成功打开套接字则为 true
另见
waitForNextConnection

waitForNextConnection()
