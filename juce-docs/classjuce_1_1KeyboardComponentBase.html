juce::KeyboardComponentBase 类参考

详细说明

用于绘制自定义 MIDI 键盘组件的基类。

实现 drawKeyboardBackground()、drawWhiteKey() 和 drawBlackKey() 方法来绘制你的内容，此类将处理底层的键盘逻辑。

该组件是一个 ChangeBroadcaster，因此如果你想在键盘滚动时得到通知，可以注册一个 ChangeListener 来接收回调。

paint()

void juce::KeyboardComponentBase::paint (Graphics & g) override virtual

组件可以重写此方法以绘制其内容。

当组件的某个区域需要重绘时会调用 paint() 方法，原因可能是组件的 repaint() 方法被调用，或者屏幕上发生了某些情况导致窗口的某一部分需要重绘。

任何子组件都会绘制在此方法绘制的内容之上。如果你需要绘制在子组件上方，也可以实现 paintOverChildren() 方法来实现。

如果你想让组件重绘自身，这是异步完成的——调用 repaint() 方法会将组件的某个区域标记为“脏”，稍后消息线程会自动调用 paint() 方法来绘制任何需要刷新的部分。在 JUCE（以及几乎所有现代界面框架）中，你永远不会同步重绘。

你应该永远不需要直接调用此方法——要对组件进行快照，可以使用 createComponentSnapshot() 或 paintEntireComponent()。

参数
g执行绘制操作时必须使用的图形上下文。
另见
repaint, paintOverChildren, Graphics

重新实现自 juce::Component。

resized()

void juce::KeyboardComponentBase::resized () override virtual

当此组件的大小发生变化时调用。

组件可以实现此方法，以在其宽度或高度变化时执行诸如布局子组件等操作。

此方法是 setBounds 或 setSize 方法的结果，会同步调用，因此反复更改组件大小会反复调用其 resized 方法（不同于重绘之类会合并多次调用的操作）。

如果组件是桌面上的顶级窗口，其大小也可能因应用程序无法控制的操作系统因素而改变。

moved, setSize

mouseWheelMove()

void juce::KeyboardComponentBase::mouseWheelMove (const MouseEvent & event, const MouseWheelDetails & wheel) override virtual

移动鼠标滚轮时调用。

当滚轮移动时，此回调会发送给鼠标所在的组件。

如果未重写，组件会将此消息转发给其父组件，这样父组件就能收集发生在不关心这些消息的子组件上的鼠标滚轮消息。（请记住，如果你将某个组件作为鼠标监听器附加到其他组件，那么那些滚轮移动最终也会调用此方法并被传递给父组件，这可能不是你期望的行为）。
