juce::URL::InputStreamOptions 类参考

详细说明

用于创建一组选项以传递给 createInputStream() 方法的类。

你可以链式调用此类的方法来创建任意想要的选项集，例如

if (auto inputStream = URL ("http://www.xyz.com/foobar")
                         .createInputStream (URL::InputStreamOptions (URL::ParameterHandling::inAddress)
                                                   .withConnectionTimeoutMs (1000)
                                                   .withNumRedirectsToFollow (0)))
{
    ...
}

构造函数与析构函数

InputStreamOptions()

juce::URL::InputStreamOptions::InputStreamOptions (ParameterHandling parameterHandling) explicit

构造函数。

如果 parameterHandling 为 ParameterHandling::inPostData，则已设置的任何 URL 参数将通过请求体数据传输。否则，这些参数将添加到 URL 地址中。

被以下对象引用： withConnectionTimeoutMs()、withExtraHeaders()、withHttpRequestCmd()、withNumRedirectsToFollow()、withProgressCallback()、withResponseHeaders()、withStatusCode()。

指定在返回响应之前要跟随的重定向次数。

withHttpRequestCmd()

InputStreamOptions juce::URL::InputStreamOptions::withHttpRequestCmd (const String & httpRequestCmd) const nodiscard

指定要使用的 HTTP 请求命令。

如果未设置此项，则当 parameterHandling 设为 ParameterHandling::inPostData，或已通过 withPOSTData()、withFileToUpload() 或 withDataToUpload() 指定了任何 POST 数据时，命令将为 POST。否则为 GET。

引用了 InputStreamOptions()。
