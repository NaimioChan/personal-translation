juce::PushNotifications::Channel 结构体参考

详细说明

仅 Android API 级别 26 或更高：表示发送通知所经由的通知通道。

从 Android API 级别 26 开始，你应在应用启动时、发布任何通知之前调用 setupChannels()。之后在发送通知时，为每个创建的通知指定一个通道。

本结构体的文档由以下文件生成：
