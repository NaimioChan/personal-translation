详细说明

template<typename Type>
class juce::ThreadLocalValue< Type >

为线程本地对象提供跨平台支持。

此类持有一个模板类型对象的内部列表，为每个请求的线程保留一个实例。线程首次尝试访问其值时，会创建一个对象并添加到该线程的列表中。

通常你可能会想创建 ThreadLocalValue 对象的静态实例，或在单例中持有它。

值的模板类必须是基元类型或简单的 POD 结构体。

当线程不再需要使用其值时，可以调用 releaseCurrentThreadStorage() 让存储被另一个线程复用。如果线程在未调用此方法的情况下退出，对象存储将保持分配，直到 ThreadLocalValue 对象被删除。
