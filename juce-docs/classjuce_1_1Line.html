juce::Line< ValueType > 类模板参考

详细说明

template<typename ValueType>
class juce::Line< ValueType >

表示一条线。

此类包含许多用于各种几何任务的有用方法。

ValueType 模板参数应为基本类型——float 或 double 才是它设计的目标。整数类型可以基本工作，但某些执行数学运算的方法可能无法编译，或者不会产生合理的结果。

另见
Point, Rectangle, Path, Graphics::drawLine

getPointAlongLine() [2/2]

template<typename ValueType> Point < ValueType > juce::Line < ValueType >::getPointAlongLine (ValueType distanceFromStart, ValueType perpendicularDistance) const inline noexcept

返回沿此线给定距离并偏向一侧的点。

它实际上先沿线移动给定距离，再沿垂直于此线的方向移动另一段距离，然后返回得到的位置。

参数
distanceFromStart从起点沿线移动的距离。此值可以为负，也可以大于线条本身的长度
perpendicularDistance从线条侧向移动多远。如果你从起点沿线看向终点，则此处的正值向右移动，负值向左移动。

引用了 Line()。
