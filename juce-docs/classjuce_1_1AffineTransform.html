juce::AffineTransform 类参考

详细说明

表示一个二维仿射变换矩阵。

仿射变换是诸如旋转、缩放、切变、调整大小或平移这样的变换。

它们用于各种二维变换任务，例如与 Path 对象配合使用。

另见
Path, Point, Line
