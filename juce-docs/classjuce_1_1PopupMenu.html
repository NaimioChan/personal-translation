juce::PopupMenu 类参考

详细说明

创建并显示一个弹出菜单。

要显示弹出菜单，你可以创建一个这样的对象，向其中添加一些项，然后调用其 show() 方法，该方法返回用户所选项的 id。

例如

void MyWidget::mouseDown (const MouseEvent& e)
{
 PopupMenu m;
    m.addItem (1, "item 1");
    m.addItem (2, "item 2");

    m.showMenuAsync (PopupMenu::Options(),
                     [] (int result)
                     {
 if (result == 0)
                         {
 // user dismissed the menu without picking anything
                         }
 else if (result == 1)
                         {
 // user picked item 1
                         }
 else if (result == 2)
                         {
 // user picked item 2
                         }
                     });
}

子菜单也很简单：

void MyWidget::mouseDown (const MouseEvent& e)
{
 PopupMenu subMenu;
    subMenu.addItem (1, "item 1");
    subMenu.addItem (2, "item 2");

 PopupMenu mainMenu;
    mainMenu.addItem (3, "item 3");
    mainMenu.addSubMenu ("other choices", subMenu);

    m.showMenuAsync (...);
}

show()

int juce::PopupMenu::show (int itemIDThatMustBeVisible = 0, int minimumWidth = 0, int maximumNumColumns = 0, int standardItemHeight = 0, ModalComponentManager::Callback * callback = nullptr)

Displays 菜单并等待用户选择。

这将以模态方式显示菜单，并返回用户所选项的 ID。如果用户在菜单外某处点击以在不选择任何内容的情况下关闭它，则返回 0。

将使用鼠标的当前位置作为显示菜单的位置——要显式设置菜单位置，请改用 showAt()。根据此点在屏幕上的位置，菜单将出现在该点的上方、下方或侧面。

参数
itemIDThatMustBeVisible如果你将其设为某个菜单项的 ID，则菜单首次出现时将确保该项可见。因此如果菜单项太多而无法在屏幕上容纳，它将滚动到该项可见的位置。
minimumWidth菜单的最小宽度，以像素为单位。如果某些项太长而放不下，菜单可能会比这更宽。
maximumNumColumns如果项太多而无法在单个垂直列中容纳，菜单可能会按一系列列来布局——这是允许的最大数量。要使用此值的默认值（大约为 7），你可以传入零。
standardItemHeight如果此项非零，它将用作菜单项的标准高度（自定义项除外）
callback如果此项不是 nullptr，菜单将异步启动并立即返回，当菜单被关闭或选中某项时，回调将收到调用。此对象将由系统拥有并删除，因此请确保它能安全运行，并且它使用的任何指针都在安全的作用域内。
