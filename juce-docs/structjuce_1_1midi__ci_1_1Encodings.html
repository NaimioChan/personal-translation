tryEncode()

std::optional< std::vector< std::byte > > juce::midi_ci::Encodings::tryEncode (Span < const std::byte > bytes, Encoding mutualEncoding) static

尝试用指定编码对所给字节跨度进行编码。

ASCII 编码不会对输入流做任何改动，但只要某个字节的最高位置位，编码就会失败。

decode()

std::vector< std::byte > juce::midi_ci::Encodings::decode (Span < const std::byte > bytes, Encoding mutualEncoding) static

用指定编码对所给字节跨度进行解码。

输入的所有字节都必须是 7 位值，即所有最高位都未置位。
