juce::InputStream 类参考

详细说明

读取数据的流的基类。

整个库都使用输入流和输出流——子类可以重写部分或全部虚函数来实现其行为。

另见
OutputStream, MemoryInputStream, BufferedInputStream, FileInputStream

getTotalLength()

virtual int64 juce::InputStream::getTotalLength () pure virtual

返回此流中可供读取的总字节数。

注意，这是从流开头算起的可用字节数，而不是从当前位置算起。

如果流的实际大小未知，则返回 -1。

read() [1/2]

virtual int juce::InputStream::read (void * destBuffer, int maxBytesToRead) pure virtual

从流中读取一些数据到内存缓冲区。

这是子类实际需要实现的唯一读取方法，因为 InputStream 基类会基于它实现其它读取方法（不过子类直接实现这些方法通常效率更高）。

参数
destBuffer数据的目标缓冲区。它不能为空。
maxBytesToRead要读取的最大字节数——请确保传入的内存块足以容纳这么多字节。该值不能为负数。
返回
实际读取的字节数；如果流在达到 maxBytesToRead 之前就已耗尽，该值可能小于 maxBytesToRead

在 juce::ARAInputStream、juce::BufferedInputStream、juce::FileInputStream、juce::GZIPDecompressorInputStream、juce::MemoryInputStream、juce::SubregionStream 和 juce::WebInputStream 中实现。

readShort()

virtual short juce::InputStream::readShort () virtual

从流中读取两个字节，作为小端序 16 位值。

如果接下来读取的两个字节是 byte1 和 byte2，则返回 (byte1 | (byte2 << 8))。如果流在读取字节过程中耗尽，这将返回零。

readCompressedInt()

virtual int juce::InputStream::readCompressedInt () virtual

使用节省空间的压缩格式，从流中读取一个编码的 32 位数字。

对于较小的值，这比使用 readInt() 和 OutputStream::writeInt() 更节省空间。使用的格式为：有效字节数 + 最多 4 个按小端序排列的字节。

readNextLine()

virtual String juce::InputStream::readNextLine () virtual

从流中读取一个 UTF-8 字符串，直到下一个换行符或回车符。

这将读取直到下一个 "\n" 或 "\r\n" 或流结束。

此调用之后，流的位置将指向换行符之后的字符，但换行符不包含在返回的字符串中。

setPosition()

virtual bool juce::InputStream::setPosition (int64 newPosition) pure virtual

尝试移动流的当前读取位置。

该位置是从流开头算起的绝对字节数。

某些流可能无法做到这一点，此时它们应什么都不做并返回 false。其它流则可能通过重置自身并跳到正确位置来实现，不过这显然有点慢。

返回
如果流成功重新定位，则为 true
另见
getPosition

在 juce::ARAInputStream、juce::BufferedInputStream、juce::FileInputStream、juce::GZIPDecompressorInputStream、juce::MemoryInputStream、juce::SubregionStream 和 juce::WebInputStream 中实现。

skipNextBytes()

virtual void juce::InputStream::skipNextBytes (int64 numBytesToSkip) virtual

从流中读取并丢弃一定数量的字节。

某些输入流可能更高效地实现此功能，但基类只会持续读取数据直到完成所需字节数。对于大幅跳过，用所需位置调用 setPosition() 可能更快。
