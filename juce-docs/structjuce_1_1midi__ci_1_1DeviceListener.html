messageNotAcknowledged()

virtual void juce::midi_ci::DeviceListener::messageNotAcknowledged (MUID x, Message::NAK) inline virtual

调用以表示收到了一条 NAK 消息。

这很有用，例如向用户显示诊断信息，或缓存失败请求的详情以便日后重试。

NAK 的 message 字段是 7 位文本。你可以用 Encodings::stringFrom7BitText() 把它转换为字符串。

引用了 DeviceListener()。

profileSpecificDataReceived()

virtual void juce::midi_ci::DeviceListener::profileSpecificDataReceived (MUID x, ChannelInGroup destination, Profile profile, Span < const std::byte > data) inline virtual

调用以表示收到了某个 profile 的数据。

注意，此函数可能在远程设备试图向本地 Device 的某个 profile 发送数据时调用，也可能在远程设备上的某个 profile 产生数据时调用。

如有必要，各 profile 会自行规定区分这两种情况的方式。

引用了 DeviceListener()。

propertySubscriptionDataReceived()

virtual void juce::midi_ci::DeviceListener::propertySubscriptionDataReceived (MUID x, const PropertySubscriptionData & data) inline virtual

调用以表示收到了订阅更新。

它只接收带有响应者命令（partial、full、notify、end）的消息。

要开始订阅，请使用 Device::sendPropertySubscriptionStart()。

引用了 DeviceListener()。

propertySubscriptionChanged()

virtual void juce::midi_ci::DeviceListener::propertySubscriptionChanged (SubscriptionKey subscription, const std::optional< String > & subscribeId) inline virtual

当远程设备通过接受或终止来更新订阅时调用。

如果订阅被接受，subscribeId 将非空；否则，为空的 subscribeId 表示该订阅已被终止。
