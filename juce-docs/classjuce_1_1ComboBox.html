详细说明

一个让用户从下拉选项列表中选择的组件。

组合框有一个文本字符串列表，每个字符串关联一个 ID 号，用户点击该组件时会在下拉列表中显示。

当前选中的选项显示在组合框中，它可以是只读文本，也可以可编辑。

要了解用户何时选择了不同的项或编辑了文本，你可以为 onChange 成员分配 lambda，或注册 ComboBox::Listener 来接收回调。

paint()

void juce::ComboBox::paint (Graphics & g) override virtual

组件可以重写此方法以绘制其内容。

当组件的某个区域需要重绘时会调用 paint() 方法，原因可能是组件的 repaint() 方法被调用，或者屏幕上发生了某些情况导致窗口的某一部分需要重绘。

任何子组件都会绘制在此方法绘制的内容之上。如果你需要绘制在子组件上方，也可以实现 paintOverChildren() 方法来实现。

如果你想让组件重绘自身，这是异步完成的——调用 repaint() 方法会将组件的某个区域标记为“脏”，稍后消息线程会自动调用 paint() 方法来绘制任何需要刷新的部分。在 JUCE（以及几乎所有现代界面框架）中，你永远不会同步重绘。

你应该永远不需要直接调用此方法——要对组件进行快照，可以使用 createComponentSnapshot() 或 paintEntireComponent()。

参数
g执行绘制操作时必须使用的图形上下文。
另见
repaint, paintOverChildren, Graphics

keyStateChanged()

bool juce::ComboBox::keyStateChanged (bool isKeyDown) override virtual

按下或释放按键时调用。

每当键盘上的某个键被按下或释放（包括 shift 和 ctrl 等修饰键），此方法将在当前拥有键盘焦点的组件上调用。请记住，只有使用组件的 setWantsKeyboardFocus() 方法启用后，组件才会获得焦点。

如果你的实现返回 true，事件将被消费，不会传递给任何其他监听器。如果返回 false，则向此组件注册的任何 KeyListener 的 keyStateChanged 方法都会被调用。一旦其中一个返回 true，过程就会停止；但如果它们全部返回 false，事件将向上传递给此组件的父组件，依此类推。

此方法的默认实现什么都不做并返回 false。

要查明任意时刻哪些键处于按下或释放状态，见 KeyPress::isKeyCurrentlyDown() 方法。

参数
isKeyDown如果某个键被按下则为 true；如果被释放则为 false
另见
keyPressed, KeyPress, getCurrentlyFocusedComponent, addKeyListener

重新实现自 juce::SettableTooltipClient。

createAccessibilityHandler()

std::unique_ptr< AccessibilityHandler > juce::ComboBox::createAccessibilityHandler () override virtual

重写此方法可为该组件返回自定义的 AccessibilityHandler。

默认实现创建并返回一个角色未指定的 AccessibilityHandler 对象，这意味着它对无障碍客户端可见，但没有特定角色、操作回调或接口。要控制无障碍客户端如何查看和交互你的组件子类 AccessibilityHandler，请实现所需行为，并在组件子类中从此方法返回它的实例。

你在此处返回的无障碍处理器保证在其 Component 之前被销毁，因此如有必要，在 AccessibilityHandler 中保存并使用指回 Component 的引用是安全的。

此函数很少应被直接调用。如果你需要查询组件的无障碍处理器，通常最好调用 getAccessibilityHandler()。此规则的例外是 createAccessibilityHandler() 的派生实现，它们可能会发现调用基类实现、然后包装或修改结果很有用。

另见
getAccessibilityHandler
