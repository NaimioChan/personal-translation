juce::Synthesiser 类参考

详细说明

可演奏声音的乐器基类。

要创建合成器，你需要创建 SynthesiserSound 的子类来描述合成器可用的每个声音，以及 SynthesiserVoice 的子类来播放这些声音之一。

然后可以用 addVoice() 和 addSound() 方法给合成器提供一组声音，以及一组可用于演奏它们的声部。如果只给它一个声部，它就是单音的——声部越多，可用的复音数就越多。

然后反复调用 renderNextBlock() 方法来产生音频。输入的任何 MIDI 事件都会被扫描以查找 note on/off 消息，并用它们启动和停止演奏相应声音的声部。

在演奏期间，你也可以调用 noteOn()、noteOff() 和其他控制器方法触发音符。

渲染之前，务必调用 setCurrentPlaybackSampleRate() 告知其目标播放速率。该值会传递给各发声单元，以便它们正确地为输出定音。

noteOn()

virtual void juce::Synthesiser::noteOn (int midiChannel, int midiNoteNumber, float velocity) virtual

触发 note-on 事件。

此处的默认方法会找出所有希望被该音符/通道触发的声音。对每个声音，它会尝试找到一个空闲声部，并用该声部开始演奏。

如果子类需要更复杂的算法，可以覆写它。

本方法会根据传入 renderNextBlock() 的 MIDI 数据自动被调用，但也可以显式调用。

midiChannel 参数是通道，范围从 1 到 16（含）。

noteOff()

virtual void juce::Synthesiser::noteOff (int midiChannel, int midiNoteNumber, float velocity, bool allowTailOff) virtual

触发 note-off 事件。

这会关闭所有正在为给定音符/通道演奏声音的声部。

如果 allowTailOff 为 true，则允许各声部优雅地淡出音符（如果它们能做到）。如果为 false，所有音符会被立即切断。

本方法会根据传入 renderNextBlock() 的 MIDI 数据自动被调用，但也可以显式调用。

midiChannel 参数是通道，范围从 1 到 16（含）。

allNotesOff()

virtual void juce::Synthesiser::allNotesOff (int midiChannel, bool allowTailOff) virtual

关闭所有音符。

这会关闭所有在给定 MIDI 通道上演奏声音的声部。

如果 midiChannel 为 0 或更小，则所有声部都会被关闭，无论它们在哪个通道上演奏。否则它表示一个有效 MIDI 通道，从 1 到 16（含）。

如果 allowTailOff 为 true，则允许各声部优雅地淡出音符（如果它们能做到）。如果为 false，所有音符会被立即切断。

本方法会根据传入 renderNextBlock() 的 MIDI 数据自动被调用，但也可以显式调用。

renderNextBlock() [1/2]

void juce::Synthesiser::renderNextBlock (AudioBuffer < float > & outputAudio, const MidiBuffer & inputMidi, int startSample, int numSamples)

创建下一块音频输出。

这会处理来自所有声部的接下来 numSamples 个数据，并从指定偏移处开始把该输出叠加到所提供的音频块上。注意，数据会叠加到缓冲区的当前内容上，因此如有必要，应在调用本方法前先清空它。

会解析 inputMidi 缓冲区中的 MIDI 事件以查找音符和控制器事件，并用它们触发各声部。注意，startSample 偏移同时作用于音频输出缓冲区和 MIDI 输入缓冲区，因此时间戳在指定区域之外的任何 MIDI 事件都会被忽略。

setMinimumRenderingSubdivisionSize()

void juce::Synthesiser::setMinimumRenderingSubdivisionSize (int numSamples, bool shouldBeStrict = false) noexcept

设置渲染时音频子块可被划分的最小尺寸限制。

渲染时，传给 renderNextBlock() 的音频块会被切分成位于所有传入 MIDI 消息之间的小块，而正是这些更小的子块通过多次调用 renderVoices() 来渲染。

显然，在极端情况下（每个采样都有 MIDI 消息），renderVoices() 可能每个采样被调用一次，导致性能很差，因此该设置允许你为块大小设一个下限。

默认设置为 32，这意味着 MIDI 消息的精度约为 < 1ms，对大多数用途来说应该够了，但你可能想为你的合成器增大或减小该值。

如果 shouldBeStrict 为 true，音频子块将严格永远不会小于 numSamples。

如果 shouldBeStrict 为 false（默认），则允许缓冲区中的第一个音频子块更小，以确保缓冲区中的第一个 MIDI 事件始终是采样精确的（这有时有助于避免量化或相位问题）。
