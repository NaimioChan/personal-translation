Backend

枚举值
defaultBackend 

默认网页浏览器后端。

在 macOS 上将使用 WebKit，在 Linux 上使用 gtk-webkit2，在 Windows 上使用 internet explorer。在 Windows 上，默认值将来可能会变为 webview2。

ie 

在 Windows 上使用 Internet Explorer 作为后端。

默认情况下，IE 会使用一个非常古老的 IE 版本。要更改此行为，你需要在页面的 head 部分添加以下 html 元素：

<meta http-equiv="X-UA-Compatible" content="IE=edge" />

或者你需要为你的应用更改 Windows 注册表值。关于后者的更多信息可以在这里找到：

https://learn.microsoft.com/en-us/previous-versions/windows/internet-explorer/ie-developer/general-info/ee330730(v=vs.85)?redirectedfrom=MSDN#browser-emulation

webview2 

在 Windows 上使用基于 chromium 的 WebView2 引擎。

withNativeIntegrationEnabled()

Options juce::WebBrowserComponent::Options::withNativeIntegrationEnabled (bool enabled = true) const inline nodiscard

为在 WebBrowserComponent 内运行的代码启用原生集成功能。

这会在 window.__JUCE__.backend 下注入数据和函数对象，通过它们，在 WebBrowserComponent 中运行的脚本可以向后台发送事件并调用已注册的原生函数。

只有在你完全控制加载到组件中的内容时，才应启用原生集成。启用这些集成后导航到第三方网站可能会使应用和计算机面临安全风险。

另见
withNativeFunction, withEventListener

引用了 juce::withMember()。

withNativeFunction()

Options juce::WebBrowserComponent::Options::withNativeFunction (const Identifier & name, NativeFunction callback) const inline nodiscard

以给定名称注册一个 NativeFunction。

要从前端调用此函数，你可以导入 JUCE 前端辅助模块，或调用底层前端 API。

回调始终在消息线程上调用。

import { getNativeFunction } from "./juce";

function someJavascriptFunction() {
 const myBackendFunction = getNativeFunction("myBackendFunction");
  myBackendFunction (1, 2, "some string");
}

withInitialisationData()

Options juce::WebBrowserComponent::Options::withInitialisationData (StringRef name, const var & value) const inline nodiscard

确保在 window.__JUCE__.initialisationData.name 下存在一个 Javascript Array，并且它将包含此处提供的值。

初始化数据会在加载任何资源之前注入。为同一名称添加的多个值都将在 Array 中可用。

引用了 juce::withMember()。

withResourceProvider()

Options juce::WebBrowserComponent::Options::withResourceProvider (ResourceProvider provider, std::optional< String > allowedOriginIn = std::nullopt) const inline nodiscard

设置一个 ResourceProvider 对象，它可以完成 WebView 资源请求并返回数据，而无需发起网络操作。

发送到 WebBrowserComponent::getResourceProviderRoot() + "resource.path" 的请求将以路径 "/resource.path" 调用提供者。

如果你用 WebBrowserComponent::getResourceProviderRoot 返回的值调用 WebBrowserComponent::goToURL，你的资源提供者将收到对 "/" 资源的请求，通常你会想为此返回 index.html 的内容。

你还可以指定一个可选的 allowedOriginIn 参数，使你的 ResourceProvider 对从该源加载的脚本可用。例如，如果你指定 "http://localhost:3000"，那么从此类本地开发服务器加载的脚本将能够访问诸如 getResourceProviderRoot() + "live_data.bin" 的资源。

允许外部源在开发时很方便，但在公开发布的二进制文件中存在潜在安全风险。

引用了 juce::withMember()。
