setValue()

void juce::LegacyAudioParameter::setValue (float newValue) inline override virtual

宿主将调用此方法来更改参数的值。

宿主可能在任何时候调用此方法，包括在音频处理回调期间，因此你的实现必须非常高效地处理，并避免任何形式的锁定。

如果你想在内部设置参数值（例如从编辑器组件），则不要直接调用此方法 — 而应使用 setValueNotifyingHost() 方法，它还会向宿主发送一条告知更改的消息。如果不发送该消息，宿主将无法正确自动化你的参数。

传入的值将在 0 到 1.0 之间。

getNumSteps()

int juce::LegacyAudioParameter::getNumSteps () const inline override virtual

返回此参数范围应量化为的步数。

如果你想要连续的值范围，请不要重写此方法，让默认实现返回 getDefaultNumParameterSteps()。

如果你的参数是布尔型，你可能希望让它返回 2。

返回的值是否被使用取决于宿主。如果你希望宿主显示阶梯式自动化值，而不是在相邻值之间进行连续插值，应重写 isDiscrete 使其返回 true。

String juce::LegacyAudioParameter::getParameterID () const inline override virtual

返回此参数唯一的 ID。
