juce::ScopedValueSetter< ValueType > 类模板参考

详细说明

template<typename ValueType>
class juce::ScopedValueSetter< ValueType >

辅助类，提供基于 RAII 的机制，用于临时设置某个值，随后再将其恢复。

例如

int x = 1;

{
 ScopedValueSetter setter (x, 2);

 // x is now 2
}

// x is now 1 again

{
 ScopedValueSetter setter (x, 3, 4);

 // x is now 3
}

// x is now 4
