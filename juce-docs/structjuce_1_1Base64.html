convertToBase64()

bool juce::Base64::convertToBase64 (OutputStream & base64Result, const void * sourceData, size_t sourceDataSize) static

将二进制数据块转换为 base-64 字符串。

这会将结果字符串数据写入给定的流。如果该流发生写入错误，方法将终止并返回 false。

convertFromBase64()

bool juce::Base64::convertFromBase64 (OutputStream & binaryOutput, StringRef base64TextInput) static

将 base-64 字符串转回其二进制表示。

这会将解码后的二进制数据写入给定的流。如果字符串不是有效的 base-64，方法将终止并返回 false。
