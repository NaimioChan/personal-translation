juce::GZIPDecompressorInputStream 类参考

详细说明

此流将使用 zlib 解压源流。

提示：如果你要从这些流之一读取大量小项，通过 BufferedInputStream 传递它可以极大提高性能，因为它需要读取更大块数据的频率更低。

read()

int juce::GZIPDecompressorInputStream::read (void * destBuffer, int maxBytesToRead) override virtual

从流中读取一些数据到内存缓冲区。

这是子类实际需要实现的唯一读取方法，因为 InputStream 基类会基于它实现其它读取方法（不过子类直接实现这些方法通常效率更高）。

参数
destBuffer数据的目标缓冲区。它不能为空。
maxBytesToRead要读取的最大字节数——请确保传入的内存块足以容纳这么多字节。该值不能为负数。
返回
实际读取的字节数；如果流在达到 maxBytesToRead 之前就已耗尽，该值可能小于 maxBytesToRead
