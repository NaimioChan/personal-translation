WebInputStream()

juce::WebInputStream::WebInputStream (const URL & url, bool addParametersToRequestBody)

创建一个新的 WebInputStream，可用于从 URL 读取。

参数
url应获取的 URL。此参数也可包含 POST 数据和/或参数。
addParametersToRequestBody指定已设置的任何 URL 参数是通过请求体数据传输，还是添加到 URL 地址中。这还将决定在未设置自定义命令时使用 POST 还是 GET 命令。

被以下对象引用： Pimpl、juce::WebInputStream::Listener::postDataSendProgress()、withConnectionTimeout()、withCustomRequestCommand()、withExtraHeaders()、withNumRedirectsToFollow()。

connect()

bool juce::WebInputStream::connect (Listener * listener)

等待直到第一个字节可供读取。

此方法将尝试连接到构造函数中给定的 URL，并阻塞，直到收到状态码和所有响应标头，或发生错误。

注意，如果大多数方法在未建立连接的情况下被调用，它们会在内部调用 connect()。因此，除非你想使用自定义监听器，否则不必显式调用 connect。

在成功调用 connect() 之后，getResponseHeaders()、getTotalLength() 和 getStatusCode() 都将是非阻塞的。

参数
listener用于接收 POST 数据上传状态进度回调的监听器。
另见

getTotalLength()

int64 juce::WebInputStream::getTotalLength () override virtual

返回此流中可供读取的总字节数。

注意，这是从流开头算起的可用字节数，而不是从当前位置算起。

如果在未建立连接的情况下调用 getResponseHeaders()，则 getResponseHeaders() 会在内部调用 connect 并阻塞，直到 connect 返回——无论是成功连接还是连接错误。

如果流的实际大小未知，则返回 -1。

read()

int juce::WebInputStream::read (void * destBuffer, int maxBytesToRead) override virtual

从流中读取一些数据到内存缓冲区。

此方法将阻塞，直到 maxBytesToRead 字节可用。

参数
destBuffer数据的目标缓冲区。它不能为空。
maxBytesToRead要读取的最大字节数——请确保传入的内存块足以容纳这么多字节。该值不能为负数。
返回
实际读取的字节数；如果流在达到 maxBytesToRead 之前就已耗尽，该值可能小于 maxBytesToRead

setPosition()

bool juce::WebInputStream::setPosition (int64 wantedPos) override virtual

尝试移动流的当前读取位置。

该位置是从流开头算起的绝对字节数。

对于 WebInputStream，如果 wantedPos 小于当前位置，此方法将失败。如果 wantedPos 大于当前位置，则调用 setPosition() 与调用 read() 相同，即被跳过的数据仍会被下载，只是跳过的字节会被立即丢弃。

返回
如果流成功重新定位，则为 true
