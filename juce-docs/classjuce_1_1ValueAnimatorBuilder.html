juce::ValueAnimatorBuilder 类参考

详细说明

用于构造包装 ValueAnimator 实现的 Animator 的 builder 类。

每个 ValueAnimatorBuilder 对象都是不可变的，每个 "with..." 函数都返回新对象。每个对象都可以独立使用，也可以反复用来构建 Animator 对象。

多次调用 build() 会返回彼此独立的 Animator 对象，各自引用底层实现的新实例。这些 Animator 对象之间互不影响生命周期。但复制一个 Animator 对象时，副本与原对象共享所有权。

你可以把 ValueAnimatorBuilder 实例当作一次性对象，只在对其调用 build() 之前需要。之后你只需保存返回的 Animator 对象，它可以根据需要多次启动与完成。

所有以 "with..." 开头的函数都是可选的，可用于覆盖默认值来影响创建出的 Animator 的行为。

ValueChangedCallback

using juce::ValueAnimatorBuilder::ValueChangedCallback = std::function<void (float)>

值变化回调的类型。

float 参数与传给 Animator::update() 的时间参数相关。更新函数通常由 AnimatorUpdater 调用。值变化回调第一次被调用时该参数为 0.0，当经过的时间等于 Animator 的时长时达到 1.0。不过如果还指定了 EasingFn，这一点会改变。写得正确的缓动函数应保持 0.0 与 1.0 的起止值，但中间值可以超出 [0.0, 1.0] 范围。

在一次进度值为 1.0 的调用之后，会调用完成回调并停止更新，除非 Animator 是无限运行的；那种情况下进度会超过 1.0，并且只有在调用 Animator::complete() 之后才会调用完成回调。

值变化回调是可选的。若要使用，需要在必须传给 withOnStartCallback() 的启动回调中创建它。

另见
withOnStartCallback, withDurationMs, withEasing, runningInfinitely

OnStartReturningValueChangedCallback

using juce::ValueAnimatorBuilder::OnStartReturningValueChangedCallback = std::function< ValueChangedCallback ()>

启动回调的类型。

它可用于在动画开始时做必要的初始化，然后必须返回一个 ValueChangedCallback。

在启动回调之后、完成回调之前，Animator 的每次更新都会调用 ValueChangedCallback。

在调用 Animator::start() 之后，Animator 收到的第一次更新时就会调用启动回调。紧接启动回调之后，会首次调用值变化回调。

EasingFn

using juce::ValueAnimatorBuilder::EasingFn = std::function<float (float)>

可选缓动函数的类型，可传给 withEasing() builder 函数。

如果指定了此函数，它会被调用，进度值从 0.0 走到 1.0（无限运行的 Animator 还会继续超出），这些值原本会直接传给值变化回调。其返回值随后传给值变化回调。

此函数可用于改变动画的线性进程，制造橡皮筋式的运动效果。

withOnStartReturningValueChangedCallback()

ValueAnimatorBuilder juce::ValueAnimatorBuilder::withOnStartReturningValueChangedCallback (OnStartReturningValueChangedCallback value) const inline nodiscard

用此函数指定可选的启动回调。

所提供函数的返回值是一个 ValueChangedCallback。这样你可以在每次启动事件时构造新的 ValueChangedCallback，把同时构造的状态一并捕获。

如果你不需要在每次动画启动时返回新的 ValueChangedCallback，可以改用更简单的 withOnStartCallback 与 withValueChangedCallback。但这两个函数不能与本函数一起使用。
