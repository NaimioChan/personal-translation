juce::MidiDeviceListConnection 类参考

详细说明

要查明可用 MIDI 设备何时变化，请调用 MidiDeviceListConnection::make()，传入一个在每次配置变化时会被调用的 lambda。

要让该 lambda 停止接收回调，请销毁从 make() 返回的 MidiDeviceListConnection 实例，或对它调用 reset()。

// Start listening for configuration changes
auto connection = MidiDeviceListConnection::make ([]
{
 // This will print a message when devices are connected/disconnected
 DBG ("MIDI devices changed");
});

// Stop listening
connection.reset();
