juce::AbstractFifo 类参考

详细说明

封装实现无锁 FIFO 所需的逻辑。

此类处理构建单读者、单写者 FIFO 时所需的逻辑。

它本身并不实际持有任何数据，但你的 FIFO 类可以使用它的一个实例，在读写时管理位置和状态。

要使用它，你可以调用 prepareToWrite() 来确定传入数据块应存储在你自己的缓冲区中的哪个位置，并调用 prepareToRead() 来查明应从何处读取下一个传出块。

例如

struct MyFifo
{
 void addToFifo (const int* someData, int numItems)
    {
 const auto scope = abstractFifo.write (numItems);

 if (scope.blockSize1 > 0)
            copySomeData (myBuffer + scope.startIndex1, someData, scope.blockSize1);

 if (scope.blockSize2 > 0)
            copySomeData (myBuffer + scope.startIndex2, someData + scope.blockSize1, scope.blockSize2);
    }

 void readFromFifo (int* someData, int numItems)
    {
 const auto scope = abstractFifo.read (numItems);

 if (scope.blockSize1 > 0)
            copySomeData (someData, myBuffer + scope.startIndex1, scope.blockSize1);

 if (scope.blockSize2 > 0)
            copySomeData (someData + scope.blockSize1, myBuffer + scope.startIndex2, scope.blockSize2);
    }

    AbstractFifo abstractFifo { 1024 };
 int myBuffer[1024];
};

prepareToWrite()

void juce::AbstractFifo::prepareToWrite (int numToWrite, int & startIndex1, int & blockSize1, int & startIndex2, int & blockSize2) const noexcept

返回传入数据块应写入缓冲区中的位置。

由于你要添加到缓冲区的数据段可能跨越末尾并回绕到开头，因此会返回你缓冲区内的两个块，你应将数据复制到第一个块，剩余数据则溢出到第二个块。

如果你请求的项数太大，无法放入缓冲区的空闲空间，那么 blockSize1 + blockSize2 之和可能小于 numToWrite。如果发生这种情况，你可以决定继续等待并重试此方法，直到有足够空间可用。

调用此方法后，如果你选择将数据写入返回的块中，你必须调用 finishedWrite() 来告诉 FIFO 你实际添加了多少数据。

例如

void addToFifo (const int* someData, int numItems)
{
 int start1, size1, start2, size2;
 prepareToWrite (numItems, start1, size1, start2, size2);

 if (size1 > 0)
        copySomeData (myBuffer + start1, someData, size1);

 if (size2 > 0)
        copySomeData (myBuffer + start2, someData + size1, size2);

 finishedWrite (size1 + size2);
}
参数
numToWrite指示你希望添加到缓冲区的项数
startIndex1退出时，这将包含你的缓冲区中应写入数据的起始索引
blockSize1退出时，这指示可以写入从 startIndex1 开始的块的项数
startIndex2退出时，这将包含你的缓冲区中应写入未能放入第一个块的数据的起始索引
blockSize2退出时，这指示可以写入从 startIndex2 开始的块的项数

prepareToRead()

void juce::AbstractFifo::prepareToRead (int numWanted, int & startIndex1, int & blockSize1, int & startIndex2, int & blockSize2) const noexcept

返回应从缓冲区中读取下一数据块的位置。

由于你要从缓冲区读取的数据段可能跨越末尾并回绕到开头，因此会返回你缓冲区内的两个块，你应从这两个块中读取。

如果你请求的项数大于可用数据量，那么 blockSize1 + blockSize2 之和可能小于 numWanted。如果发生这种情况，你可以决定继续等待并重试此方法，直到有足够数据可用。

调用此方法后，如果你选择读取数据，你必须调用 finishedRead() 来告诉 FIFO 你已消费了多少数据。

例如

void readFromFifo (int* someData, int numItems)
{
 int start1, size1, start2, size2;
 prepareToRead (numSamples, start1, size1, start2, size2);

 if (size1 > 0)

 if (size2 > 0)
