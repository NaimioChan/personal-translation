juce::PushNotifications::ChannelGroup 结构体参考

详细说明

仅 Android API 级别 26 或更高：表示一个通道组。

它允许在向用户显示的通知设置中，把相应的通道按视觉分组。至少需要指定一个通道组，通知才能发送。

本结构体的文档由以下文件生成：
  • juce_gui_extra/misc/juce_PushNotifications.h

公共属性

String identifier
必需：唯一通道组标识符。
String name
必需：通道组的用户可见名称。
