juce::FilenameComponent 类参考

详细说明

将文件名显示为可编辑的文本框，并带有一个“浏览”按钮和一个最近选中文件的下拉列表。

在希望让用户选择文件或目录的对话框中，这是一个很方便的组件。

使用 addListener() 方法附加一个 FilenameComponentListener，每当用户更改文件名时它都会被调用——无论是通过浏览文件并点击“确定”，还是在框中输入新文件名并按回车。

FilenameComponent()

juce::FilenameComponent::FilenameComponent (const String & name, const File & currentFile, bool canEditFilename, bool isDirectory, bool isForSaving, const String & fileBrowserWildcard, const String & enforcedSuffix, const String & textWhenNothingSelected)

创建一个 FilenameComponent。

参数
name此组件的名称。
currentFile初始显示在框中的文件
canEditFilename如果为 true，用户可以手动编辑文件名；如果为 false，则只能通过浏览新文件来更改
isDirectory如果为 true，该文件将被视为目录，并使用合适的目录浏览器
isForSaving如果为 true，文件浏览器将允许选择不存在的文件，因为假定该文件用于保存而非加载
fileBrowserWildcard在文件浏览器中使用的通配符模式——例如 "*.txt;*.foo"。如果传入空字符串，则假定模式为 "*"
enforcedSuffix如果非空，则将其视为后缀，添加到任何输入或选择的文件名上
textWhenNothingSelected在输入任何文件名之前，框中显示的消息。（仅在初始文件无效时才会出现）

引用了 name。

被以下对象引用： createKeyboardFocusTraverser()、juce::FilenameComponent::LookAndFeelMethods::layoutFilenameComponent()。

void juce::FilenameComponent::resized () override virtual

当此组件的大小发生变化时调用。

组件可以实现此方法，以在其宽度或高度变化时执行诸如布局子组件等操作。

此方法是 setBounds 或 setSize 方法的结果，会同步调用，因此反复更改组件大小会反复调用其 resized 方法（不同于重绘之类会合并多次调用的操作）。

如果组件是桌面上的顶级窗口，其大小也可能因应用程序无法控制的操作系统因素而改变。

createKeyboardFocusTraverser()

std::unique_ptr< ComponentTraverser > juce::FilenameComponent::createKeyboardFocusTraverser () override virtual

创建一个 ComponentTraverser 对象，用于确定从此组件传递键盘焦点的逻辑。

如果此组件是键盘焦点容器（由 setFocusContainerType() 方法确定），此方法的默认实现将返回 KeyboardFocusTraverser 的实例。如果组件不是键盘焦点容器，则会在其父组件上递归调用 createKeyboardFocusTraverser()。

如果你重写此方法以返回自定义遍历器对象，则此组件及其所有子组件将使用新对象来做键盘焦点决策。
