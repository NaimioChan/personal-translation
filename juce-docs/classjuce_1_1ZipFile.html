详细说明

从流中解码 ZIP 文件。

这可枚举 ZIP 文件中的条目，并创建合适的流对象来读取每个条目。

createStreamForEntry() [1/2]

InputStream * juce::ZipFile::createStreamForEntry (int index)

创建一个可从 zip 文件某个条目读取的流。

返回的流必须由调用方删除（如果由于某种原因无法打开流，可能返回 nullptr）。

在创建它的 ZipFile 对象被删除后，不得再使用该流。

注意，如果 ZipFile 是使用用户提供的 InputStream 对象创建的，则此方法创建的所有流都会尝试共享同一个源流，因此不能在多个线程上安全使用！（但如果你从 File 或 InputSource 创建 ZipFile，则这样做是安全的）。

uncompressEntry() [1/2]

Result juce::ZipFile::uncompressEntry (int index, const File & targetDirectory, bool shouldOverwriteFiles = true)

解压缩 zip 文件中的某个条目。

这会展开该条目并将其写入目标目录。条目的路径用于确定新文件应放在目标的哪个子文件夹中。

参数
index要解压缩的条目的索引——必须是 0 到（getNumEntries() - 1）之间的有效索引。
targetDirectory要解压缩到的根文件夹
shouldOverwriteFiles是否用同名文件覆盖现有文件
返回
如果所有文件都成功解压则返回 success
