juce::KeyListener 类参考

详细说明

在按键时接收回调。

你可以向组件添加按键监听器，以便在该组件收到按键事件时获知。更多细节请参见 Component::addKeyListener 方法。

keyPressed()

virtual bool juce::KeyListener::keyPressed (const KeyPress & key, Component * originatingComponent) pure virtual

调用以指示某个键已被按下。

如果你的实现返回 true，则按键事件被视为已消费，不会传递给任何其它组件。如果返回 false，则该键将传递给其它可能想使用它的组件。

参数
key按键操作，包括修饰键
originatingComponent接收按键事件的组件

keyStateChanged()

virtual bool juce::KeyListener::keyStateChanged (bool isKeyDown, Component * originatingComponent) virtual

在按下或释放任何键时调用。

调用此方法时，可能关心一个或多个按键状态的类可以使用 KeyPress::isKeyCurrentlyDown() 检查其按键是否已更改。

如果你的实现返回 true，则按键事件被视为已消费，不会传递给任何其它组件。如果返回 false，则该键将传递给其它可能想使用它的组件。

参数
originatingComponent接收按键事件的组件
isKeyDown如果某个键正被按下则为 true，如果正被释放则为 false
