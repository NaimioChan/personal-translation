juce::MPEInstrument 类参考

详细说明

此类表示一个处理 MPE 的乐器。

它具有 MPE 区域布局，并维护当前活动（演奏中）音符及其表现维度值的状态。

你可以触发和调制音符：

  • 通过 processNextMidiEvent 方法传入 MIDI 消息；
  • 通过直接调用 noteOn、noteOff 等方法。

此类实现了 MPE 规定的通道与音符管理逻辑。如果你传入一条消息，它会知道该消息应影响哪些通道上的哪些音符（如果有）。

此类有一个 Listener 类，可用于对音符和状态变化做出反应，并为你的应用触发某些功能。例如，你可以用此类编写 MPE 可视化器。

如果你想编写具有 MPE 功能的实时音频合成器，则应改用 MPESynthesiserBase 等类，它们增加了渲染音频和管理发声单元的能力。

TrackingMode

enum juce::MPEInstrument::TrackingMode

MPE 音符跟踪模式。

当同一 MIDI 通道上同时演奏多个音符时，这决定该通道上收到的 MPE 消息（压力、弯音或音色）将调制其中哪个音符。

默认值为 lastNotePlayedOnChannel。

枚举值
lastNotePlayedOnChannel 

通道上仍在演奏（按键按下和/或延音中）的最新音符。

lowestNoteOnChannel 

通道上按键仍按下的最低音符（按 initialNote）。

highestNoteOnChannel 

通道上按键仍按下的最高音符（按 initialNote）。

allNotesOnChannel 

通道上的所有音符（按键按下和/或延音中）。

enableLegacyMode()

void juce::MPEInstrument::enableLegacyMode (int pitchbendRange = 2, Range < int > channelRange = Range < int >(1, 17))

使乐器进入旧版模式。

如果旧版模式已启用，此方法不做任何事。

作为副作用，这会丢弃所有当前正在播放的音符，并对它们全部调用 noteReleased。

这种特殊的区域布局模式用于向后兼容非 MPE 的 MIDI 设备。在此模式下，乐器会忽略当前的 MPE 区域布局。它改为取一段 MIDI 通道范围（默认：全部通道 1-16）并将其视为音符通道，没有主通道。此范围之外的 MIDI 通道将被忽略。

参数
pitchbendRange旧版模式下使用的音符弯音范围，单位为半音。必须在 0 到 96 之间，否则行为未定义。旧版模式下的默认弯音范围为 +/- 2 个半音。
channelRange旧版模式下用于音符的 MIDI 通道范围。默认使用所有 MIDI 通道（1-16）。

要退出旧版模式，请使用 setZoneLayout 设置新的 MPE 区域布局。
