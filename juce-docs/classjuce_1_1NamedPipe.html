juce::NamedPipe 类参考

详细说明

一种可跨进程的管道，可向其写入数据并从其读取数据。

两个进程可以使用 NamedPipe 对象交换数据块。

read()

int juce::NamedPipe::read (void * destBuffer, int maxBytesToRead, int timeOutMilliseconds)

从管道读取数据。

这会阻塞，直到另一个线程向管道写入了足够的数据以填满指定的字节数，或直到另一个线程调用了 cancelPendingReads() 方法。

如果操作失败则返回 -1，否则返回已读取的字节数。

如果 timeOutMilliseconds 小于零，将无限期等待，否则这是从管道读取的最长超时时间。
