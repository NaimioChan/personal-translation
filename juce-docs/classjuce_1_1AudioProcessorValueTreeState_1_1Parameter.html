juce::AudioProcessorValueTreeState::Parameter 类参考

详细说明

一个保持与已废弃的 AudioProcessorValueTreeState 功能向后兼容的参数类。

先前对

createAndAddParameter (paramID1, paramName1, ...);

的调用可以替换为

using Parameter = AudioProcessorValueTreeState::Parameter;
createAndAddParameter (std::make_unique<Parameter> (paramID1, paramName1, ...));

不过，更好的方法是直接使用 AudioProcessorValueTreeState 构造函数

using Parameter = AudioProcessorValueTreeState::Parameter;
YourAudioProcessor()
    : apvts (*this, &undoManager, "PARAMETERS", { std::make_unique<Parameter> (paramID1, paramName1, ...),
                                                  std::make_unique<Parameter> (paramID2, paramName2, ...),
                                                  ... })

getNumSteps()

int juce::AudioProcessorValueTreeState::Parameter::getNumSteps () const override virtual

返回此参数范围应量化为的步数。

如果你想要连续的值范围，请不要重写此方法，让默认实现返回 getDefaultNumParameterSteps()。

如果你的参数是布尔型，你可能希望让它返回 2。

返回的值是否被使用取决于宿主。如果你希望宿主显示阶梯式自动化值，而不是在相邻值之间进行连续插值，应重写 isDiscrete 使其返回 true。
