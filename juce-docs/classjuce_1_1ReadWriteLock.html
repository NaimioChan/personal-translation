juce::ReadWriteLock 类参考

详细说明

允许同时有多个读取者的临界区。

此类锁的特点：

  • 多个读取者可以同时持有该锁，但同一时刻只能有一个写入者持有。
  • 尝试获取锁的写入者将被阻塞，直到所有读取者和写入者都已释放该锁
  • 在有写入者等待获取锁时，尝试获取锁的读取者将被阻塞，直到该写入者获取并释放了锁
  • 如果某线程已持有读锁并尝试获取写锁，在没有其他读取者的情况下它将成功
  • 如果某线程已持有写锁并尝试获取读锁，这将成功。
  • 支持递归加锁。

exitRead()

void juce::ReadWriteLock::exitRead () const noexcept

释放读锁。

如果调用线程没有获得锁，这可能产生不可预测的结果。

如果线程已多次调用 enterRead() 方法，则每次调用都必须对应一次 exitRead() 调用，其他线程才被允许接管锁。
