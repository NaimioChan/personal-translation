成员枚举

WoW64Mode

enum juce::WindowsRegistry::WoW64Mode

这些值可用于指定应使用 32 位还是 64 位注册表。

在 32 位操作系统上运行时不存在 64 位注册表，因此该模式将被忽略。

枚举值
WoW64_Default 

默认处理：32 位应用使用 32 位注册表，64 位应用使用 64 位注册表。

WoW64_64bit 

始终使用 64 位注册表存储。

(KEY_WOW64_64KEY)。

WoW64_32bit 

始终使用 32 位注册表存储。

(KEY_WOW64_32KEY)。

registerFileAssociation()

bool JUCE_CALLTYPE juce::WindowsRegistry::registerFileAssociation (const String & fileExtension, const String & symbolicDescription, const String & fullDescription, const File & targetExecutable, int iconResourceNumber, bool registerForCurrentUserOnly, WoW64Mode mode = WoW64_Default) static

在注册表中创建文件关联。

这让你可以设置应由给定文件扩展名启动的可执行文件。

参数
fileExtension要关联的文件扩展名，包括开头的点，例如“.txt”
symbolicDescription一个不含空格的短标记，用于标识文件类型
fullDescription文件类型的可读描述
targetExecutable应启动的可执行文件
iconResourceNumber该文件类型显示的图标将通过在可执行文件中查找此资源编号来确定。此处传 0 表示不使用图标
registerForCurrentUserOnly如果为 false，将为所有用户注册关联（除非在安装程序中运行，否则你可能没有权限这样做）。如果为 true，将在 HKEY_CURRENT_USER 中注册关联。
mode用于选择数据库的 WoW64 模式

引用了 JUCE_CALLTYPE、WoW64_Default。
