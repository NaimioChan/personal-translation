juce::DynamicLibrary 类参考

详细说明

处理 DLL 的打开和关闭。

此类可用于打开 DLL 并从中获取函数指针。由于 DLL 在此对象被删除时释放，因此便于使用 RAII 管理库的生命周期。

void * juce::DynamicLibrary::getFunction (const String & functionName) noexcept

尝试在当前打开的 DLL 中查找命名函数并返回指向它的指针。

如果库当前未打开，或者找不到命名函数，此方法将返回空指针。

被以下对象引用： DynamicLibrary()。

getFunction() [2/2]

template<typename Fn> Fn * juce::DynamicLibrary::getFunction (const String & functionName) inline noexcept

尝试在当前打开的 DLL 中查找命名函数，并返回指向它的指针，转换为所请求的函数类型。

如果库当前未打开，或者找不到命名函数，此方法将返回空指针。

模板参数必须是函数类型，例如

auto fn = library.getFunction<void*(const char*)> ("someFunction");

调用者有责任确保所请求的函数签名与动态库实际导出的函数匹配。传递错误的签名将导致未定义行为。

引用了 DynamicLibrary()。
