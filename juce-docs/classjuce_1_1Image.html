juce::Image 类参考

详细说明

持有一个固定大小的位图。

图像以 24 位 RGB 或 32 位预乘 ARGB 格式存储。

要绘制到图像中，请为它创建一个 Graphics 对象。例如

// create a transparent 500x500 image
Image myImage (Image::RGB, 500, 500, true);

Graphics g (myImage);
g.setColour (Colours::red);
g.fillEllipse (20, 20, 300, 200);  // draws a red ellipse in our image

其他创建图像的有用方式包括 ImageCache 类，或 ImageFileFormat，它提供了加载常见图像文件的方法。

另见
Graphics, ImageFileFormat, ImageCache, ImageConvolutionKernel

Image() [2/6]

juce::Image::Image (PixelFormat format, int imageWidth, int imageHeight, bool clearImage)

创建具有指定大小和格式的图像。

图像的内部类型将是 NativeImageType 类——要指定不同的类型，请使用另一个构造函数，它接受要使用的 ImageType。

参数
format首选像素格式。注意这只是一个 hint，会被传给 ImageType 类——不同的 ImageType 可能不支持所有格式，因此可能会用例如 ARGB 代替 RGB。
imageWidth图像的期望宽度，以像素为单位——此值必须大于零（否则会使用宽度 1）
imageHeight图像的期望高度，以像素为单位——此值必须大于零（否则会使用高度 1）
clearImage如果为 true，图像最初会被清除为黑色（如果是 RGB）或透明黑（如果是 ARGB）。如果为 false，图像最初可能包含垃圾数据，因此你需要确保彻底覆盖它。

引用了 Image()。

getClippedImage()

Image juce::Image::getClippedImage (const Rectangle < int > & area) const

返回引用此图像某个子区域的图像。

这不会复制原始图像——新图像会保留对它的引用，因此如果原始图像被更改，子区域的内容也会改变。同样，如果你绘制到子图像中，也会绘制到原始图像的该区域。注意，如果你用 operator= 让原始 Image 对象指向别的内容，子区域图像不会随之改变，它仍指向原来的图像。

传入的区域会被裁剪到此图像的边界内，因此返回的图像可能比你要求的区域小，如果区域越界，甚至可能返回空图像。

引用了 isNull()、isValid()。
