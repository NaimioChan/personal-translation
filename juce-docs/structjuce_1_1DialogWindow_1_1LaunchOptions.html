juce::DialogWindow::LaunchOptions 结构体参考

详细说明

此类定义用于打开 DialogWindow 的一组设置。

打开 DialogWindow 最简单的方法是创建一个 LaunchOptions 结构，用适当的细节初始化其字段，然后调用其 launchAsync() 方法启动对话框。

成员函数

launchAsync()

DialogWindow * juce::DialogWindow::LaunchOptions::launchAsync ()

启动一个新的模态对话框窗口。

这将根据此结构中的设置创建对话框，以模态方式启动并立即返回。返回的窗口将在模态状态终止时自动删除。

当点击对话框的关闭按钮时，它会自动终止其模态状态，但你也可以在 DialogWindow 上调用 exitModalState (returnValue) 以编程方式执行此操作。

如果你的内容组件需要找到包含它的对话框窗口，一个快速技巧是：

if (DialogWindow* dw = contentComponent->findParentComponentOfClass<DialogWindow>())
    dw->exitModalState (1234);

引用了 juce::DialogWindow::DialogWindow()、launchAsync()。

被以下对象引用： launchAsync()、juce::StandalonePluginHolder::showAudioSettingsDialog()。

create()

DialogWindow * juce::DialogWindow::LaunchOptions::create ()

使用这些设置创建一个新的 DialogWindow 实例。

此方法只创建窗口，不会以模态方式运行它。大多数情况下你会想改用 launchAsync() 或 runModal()。

引用了 juce::DialogWindow::DialogWindow()、launchAsync()。

被以下对象引用： runModal()。

runModal()

int juce::DialogWindow::LaunchOptions::runModal ()

以模态方式启动并运行对话框，返回用于终止模态循环的状态码。

注意，内联运行模态循环是一种糟糕的做法。如果可能，请始终使用 launchAsync() 而不是此方法。

引用了 LaunchOptions()。
