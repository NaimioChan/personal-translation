juce::MemoryInputStream 类参考

详细说明

允许以流的方式访问一块数据。

它既可以用来引用共享的内存块，也可以在创建 MemoryInputStream 时生成自己的内部数据副本。

setPosition()

bool juce::MemoryInputStream::setPosition (int64 newPosition) override virtual

尝试移动流的当前读取位置。

该位置是从流开头算起的绝对字节数。

某些流可能无法做到这一点，此时它们应什么都不做并返回 false。其它流则可能通过重置自身并跳到正确位置来实现，不过这显然有点慢。

返回
如果流成功重新定位，则为 true

read()

int juce::MemoryInputStream::read (void * destBuffer, int maxBytesToRead) override virtual

从流中读取一些数据到内存缓冲区。

这是子类实际需要实现的唯一读取方法，因为 InputStream 基类会基于它实现其它读取方法（不过子类直接实现这些方法通常效率更高）。

参数
destBuffer数据的目标缓冲区。它不能为空。
maxBytesToRead要读取的最大字节数——请确保传入的内存块足以容纳这么多字节。该值不能为负数。
返回
实际读取的字节数；如果流在达到 maxBytesToRead 之前就已耗尽，该值可能小于 maxBytesToRead

实现 juce::InputStream。

skipNextBytes()

void juce::MemoryInputStream::skipNextBytes (int64 numBytesToSkip) override virtual

从流中读取并丢弃一定数量的字节。

某些输入流可能更高效地实现此功能，但基类只会持续读取数据直到完成所需字节数。对于大幅跳过，用所需位置调用 setPosition() 可能更快。
