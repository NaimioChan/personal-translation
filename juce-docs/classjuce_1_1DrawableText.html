setPreserveWhitespace()

void juce::DrawableText::setPreserveWhitespace (bool shouldPreserveWhitespace)

设置绘制时是否始终保留空白字符。

默认值为 false。

历史上，DrawableText 有时会在绘制时根据内容裁剪所提供的文本。将此值设为 true 后，将不再进行裁剪。

setFont()

void juce::DrawableText::setFont (const Font & newFont, bool applySizeAndScale)

设置要使用的字体。

注意，字体高度和水平缩放分别用 setFontHeight() 和 setFontHorizontalScale() 设置。如果 applySizeAndScale 为 true，这些高度和缩放值会被改为与所提供字体的尺寸相匹配；如果为 false，则忽略新字体对象的高度和缩放。
