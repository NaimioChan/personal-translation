juce::PixelRGB 类参考

详细说明

表示一个 24 位 RGB 像素，并可在其上执行合成操作。

图像类内部会使用它。

blend() [3/4]

template<class Pixel> forcedinline constexpr void juce::PixelRGB::blend (Pixel src, uint32 extraAlpha) inline constexpr noexcept

把另一个像素混合到此像素上，并对其不透明度额外乘以一个系数。

被叠加像素的不透明度在使用前会按 extraAlpha 系数缩放，因此可以用 PixelRGB 参数进行半透明混合。

引用了 juce::clampPixelComponents()、forcedinline、getEvenBytes()、juce::maskPixelComponents()。

blend() [4/4]

template<class Pixel> forcedinline void juce::PixelRGB::blend (const Pixel & src, BlendMode mode, uint32 extraAlpha = 256u) inline noexcept

用指定的混合模式把另一个像素混合到此像素上，并对其不透明度额外乘以一个系数。

被叠加像素的不透明度在使用前会按 extraAlpha 系数缩放，因此可以用 PixelRGB 参数进行半透明混合。

extraAlpha 的缩放使用有损的定点运算，其中完全不透明用 256 表示。

引用了 juce::clampPixelComponents()、juce::destinationIn、juce::destinationOut、forcedinline、getEvenBytes()、getOddBytes()、juce::maskPixelComponents()、juce::source、juce::sourceOver。
