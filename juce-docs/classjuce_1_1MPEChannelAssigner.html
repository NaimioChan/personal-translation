juce::MPEChannelAssigner 类参考

详细说明

此类负责将新的 MIDI 音符分配到活动 MPE 区域的成员通道。

使用时，创建一个实例并传入它要操作的 MPE 区域，然后对所有 note-on 消息调用 findMidiChannelForNewNote() 方法，对所有 note-off 消息调用 noteOff() 方法。

findMidiChannelForNewNote()

int juce::MPEChannelAssigner::findMidiChannelForNewNote (int noteNumber) noexcept

此方法会使用 MPE 规范中推荐的一组规则，确定指定的 MIDI 音符应分配到哪个成员通道，并返回该通道号。

这些规则的优先级如下：

  • 查找一个空闲通道，其上最后演奏的音符与指定音符相同
  • 按轮转分配查找下一个空闲通道
  • 查找当前正在演奏最接近（但不相同）音符的通道号
参数
noteNumber要分配到通道的 MIDI 音符编号
返回
该音符应分配到的区域成员通道

findMidiChannelForExistingNote()

int juce::MPEChannelAssigner::findMidiChannelForExistingNote (int initialNoteOnNumber) noexcept

如果某个音符已通过 findMidiChannelForNewNote() 添加，这将返回它被分配到的通道，否则返回 -1。

noteOff()

void juce::MPEChannelAssigner::noteOff (int noteNumber, int midiChannel = -1)

你必须对所有收到的 note-off 调用此方法，以便此类在内部跟踪当前正在播放的音符。

你可以指定 note off 发生所在的通道号。如果不指定，它会在所有通道中查找与给定音符编号匹配的已注册 midi 音符。

allNotesOff()

void juce::MPEChannelAssigner::allNotesOff ()

调用此方法可清除所有当前正在播放的音符。
