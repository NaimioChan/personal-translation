juce::AccessibilityTextInterface 类参考

详细说明

表示支持文本接口的 UI 元素的抽象接口。

UI 元素可以用此接口提供仅靠 AccessibilityHandler 的标题、描述和帮助文本属性无法传达的扩展文本信息。这通常用于无障碍客户端可能想逐行朗读、或需要提供文本选择与输入的文本。
