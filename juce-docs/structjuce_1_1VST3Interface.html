详细说明

用于定义 VST3 接口 ID 的有用函数和类。

此结构体中的类和函数有意保持轻量，几乎不依赖 JUCE 或 Steinberg VST3 SDK。

jucePluginId()

Id juce::VST3Interface::jucePluginId (uint32_t manufacturerCode, uint32_t pluginCode, Type interfaceType = Type::component) inline static

返回一个 16 字节数组，指示用于给定 JUCE VST3 插件的 VST3 接口 ID。

除非启用 JUCE_VST3_CAN_REPLACE_VST2，否则这是 JUCE 内部用来为每个 VST3 接口分配 ID 的方式。

如果定义了 JUCE_VST3_COMPONENT_CLASS，当接口类型为 Type::component 时它将返回该值。如果你要发布一个 JUCE VST3 插件，而它需要替代一个最初并非使用 JUCE 构建的 VST3 插件版本，这会很有用。

另见
vst2PluginId, hexStringToId, JUCE_VST3_COMPONENT_CLASS

引用了 ara、compatibility、component、controller、hexStringToId()、jassert、jassertfalse、JUCE_VST3_COMPONENT_CLASS、processor。
