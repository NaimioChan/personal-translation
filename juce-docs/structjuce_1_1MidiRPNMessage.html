juce::MidiRPNMessage 结构体参考

详细说明

表示一条 MIDI RPN（注册参数号）或 NRPN（非注册参数号）消息。

本结构体的文档由以下文件生成：
  • juce_audio_basics/midi/juce_MidiRPN.h

公共属性

int channel
消息的 MIDI 通道，范围 1 到 16。
int parameterNumber
14 位参数索引，范围 0 到 16383（0x3fff）。
int value
参数值，范围 0 到 16383（0x3fff）。
bool isNRPN
如果该消息是 NRPN 则为 true；如果是 RPN 则为 false。
bool is14BitValue
如果该值使用 14 位分辨率（LSB + MSB）则为 true；如果该值是 7 位（仅 MSB）则为 false。
