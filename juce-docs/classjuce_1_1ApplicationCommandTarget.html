juce::ApplicationCommandTarget 类参考

详细说明

命令目标发布一组它能执行的命令 ID。

ApplicationCommandManager 将命令分发给目标，这些目标必须能够提供关于它们能处理哪些命令的信息。

要创建目标，你需要继承此类，实现其所有纯虚方法。

有关如何选择目标来接收命令的信息，请参阅 ApplicationCommandManager::getFirstCommandTarget()。

getNextCommandTarget()

virtual ApplicationCommandTarget * juce::ApplicationCommandTarget::getNextCommandTarget () pure virtual

这必须返回此目标之后要尝试的下一个目标。

当发送命令且第一个目标无法处理该命令时，使用此方法确定下一个应尝试的目标。

如果不知道另一个目标，可能返回 nullptr。

如果你的目标是 Component，通常你会使用 findFirstTargetParentComponent() 方法返回可能想处理它的父组件。

getCommandInfo()

virtual void juce::ApplicationCommandTarget::getCommandInfo (CommandID commandID, ApplicationCommandInfo & result) pure virtual

这必须提供此目标能执行的某个命令的详细信息。

这会以目标在其 getAllCommands() 方法中提供的某个命令 ID 被调用。

它应使用关于命令的合适信息填充 ApplicationCommandInfo 结构的所有相应字段。（commandID 字段已由调用者填充。）

设置信息最简单的方法是使用 ApplicationCommandInfo::setInfo() 方法一次性设置所有字段。

如果命令当前因某种原因处于非激活状态，此方法必须使用 ApplicationCommandInfo::setActive() 明确这一点（或设置 ApplicationCommandInfo::flags 字段的 isDisabled 位）。

命令的任何默认按键都应附加到 ApplicationCommandInfo::defaultKeypresses 字段。

注意，如果你更改了会影响此方法返回的命令状态的内容（例如使某些命令变为激活或非激活），应调用 ApplicationCommandManager::commandStatusChanged() 使管理器刷新其状态。

在 juce::CodeEditorComponent 和 juce::JUCEApplication 中实现。

perform()

virtual bool juce::ApplicationCommandTarget::perform (const InvocationInfo & info) pure virtual

这必须实际执行指定命令。

如果此目标能执行 InvocationInfo 结构的 commandID 字段指定的命令，则应执行它，并且必须返回 true。

如果它无法处理此命令，应返回 false，告知调用者将命令传递给链上的下一个目标。

invoke()

bool juce::ApplicationCommandTarget::invoke (const InvocationInfo & invocationInfo, bool asynchronously)

使此目标调用命令。

你的代码可以调用此方法在此目标上调用命令，但通常你会通过 ApplicationCommandManager::invoke() 或 ApplicationCommandManager::invokeDirectly() 间接调用它。

如果此目标能执行给定命令，它会调用其 perform() 方法来执行。如果不能，则使用 getNextCommandTarget() 确定下一个要尝试的目标，命令将被传递给它。

参数
invocationInfo必须正确填写，描述调用的上下文。
asynchronously如果为 false，命令将在此方法返回前执行。如果为 true，则发布一条消息，使命令稍后在消息线程上执行，此方法立即返回。

perform, ApplicationCommandManager::invoke
