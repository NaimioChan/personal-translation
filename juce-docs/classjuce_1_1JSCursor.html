juce::JSCursor 类参考

详细说明

对持有所有权的根 JSObject 以及相对于它的层级路径的高层封装。

它可用于在 Javascript 对象图中查询和操作相对于根 JSObject 的位置。游标只维护对根 Object 的所有权，因此只要游标指向根，它就会始终处于有效状态，isValid 将返回 true。

使用 getChild 可以向游标的相对路径追加元素。在这种情况下调用 get 或 set 时，你需要确保游标处于有效状态。你可以用 isValid 函数判断游标当前是否指向可达的位置。

构造函数与析构函数

JSCursor()

juce::JSCursor::JSCursor (JSObject root) explicit

创建一个指向所给根对象、并参与其所有权管理的 JSCursor。

这保证了该根对象在此游标的整个生命周期内始终有效。

由 getChild() 创建的子 JSCursor 将包含同一个根对象，并且每一个都会通过引用计数进一步确保该根保持有效。

虽然根的有效性通过共享所有权得到保证，但 JSCursor 本身并不保证有效，除非它也直接指向根。

成员函数

getOrCreateObject()

JSObject juce::JSCursor::getOrCreateObject () const

返回游标所在位置处 Javascript Object 的所有权引用。

如果该位置没有 Object 但游标有效，则会创建一个新 Object。

你只能对有效的 JSCursor 调用此函数。

通过创建所有权引用，你可以创建新的 JSCursor 对象，它拥有底层对象并保证保持有效状态，例如

JSCursor rootCursor { engine.getRootObject() };
auto nonOwningCursor = rootCursor["path"]["to"]["object"];

jassert (nonOwningCursor.isValid());

JSCursor owningCursor { nonOwningCursor.getOrCreateObject(); };
engine.execute (arbitraryScript);

// owningCursor is guaranteed to remain valid even after subsequent script evaluations
jassert (owningCursor.isValid());

isValid()

bool juce::JSCursor::isValid () const

如果游标位置可从其 JSObject 根到达，则返回 true。

这意味着可以安全地对此 JSCursor 调用 set，该位置随后将指向与所给值对应的 Object。

并不保证此位置已有 Object，这种情况下调用 get 将返回 var::undefined()。

isArray()
