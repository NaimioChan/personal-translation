juce::UnitTest 类参考

详细说明

这是执行单元测试的类的基类。

要使用此类编写测试，你的代码应类似如下：

class MyTest  : public UnitTest
{
public:
    MyTest()  : UnitTest ("Foobar testing") {}

 void runTest() override
 {
 testCase ("Part 1", [&]
        {
 expect (myFoobar.doesSomething());
 expect (myFoobar.doesSomethingElse());
        });

 testCase ("Part 2", [&]
        {
 expect (myOtherFoobar.doesSomething());
 expect (myOtherFoobar.doesSomethingElse());
        });

        ...etc...
    }
};

// Creating a static instance will automatically add the instance to the array
// returned by UnitTest::getAllTests(), so the test will be included when you call
// UnitTestRunner::runAllTests()
static MyTest test;

要运行测试，请使用 UnitTestRunner 类。

expect()

void juce::UnitTest::expect (bool testResult, const String & failureMessage = String ())

检查测试结果是否为 true，并记录该结果。

在你的 runTest() 方法中，应对每个想要检查的条件调用此方法，例如

void runTest()
{
 testCase ("basic tests", [&]
    {
 expect (x + y == 2);
 expect (getThing() == someThing);
        ...etc...
    });
}

如果 testResult 为 true，则记录一次通过；如果为 false，则记录一次失败。如果指定了失败消息，测试失败时会将其写入日志。

被以下对象引用： testCase()。

getRandom()

Random juce::UnitTest::getRandom () const

返回一个所有单元测试都应使用的共享 RNG。

如果测试需要随机数，重要的是在发现错误时能够通过使用相同的随机种子值重复测试来重建确切情形，以便重新测试该问题。为此，UnitTestRunner 类会为本次运行创建一个主种子值，将此数字写入日志，然后此方法返回基于该种子的 Random 对象。所有测试都只应使用此方法创建所需的任何 Random 对象。

注意，对于给定的运行，此方法每次调用都会返回相同的对象，因此如果你需要多个不同的 Random 对象，最好的办法是对结果调用 Random::combineSeed()，用一个常量值对其进行置换。
