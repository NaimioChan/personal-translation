juce::AudioProcessor::Bus 类参考

详细说明

描述音频总线的布局和属性。

实际上，总线描述就是一组命名的通道类型。

另见
AudioChannelSet, AudioProcessor::addBus

isLayoutSupported()

bool juce::AudioProcessor::Bus::isLayoutSupported (const AudioChannelSet & set, BusesLayout * currentLayout = nullptr) const

检查是否支持某个特定布局。

参数
set要探测的 AudioChannelSet。
currentLayout如果非空，则假定 AudioProcessor 的当前布局为 currentLayout。退出时，currentLayout 将被修改为表示 AudioProcessor 的总线布局，就如同接收方的布局已被成功更改一样。这很有用，因为更改接收方的布局可能会改变其他总线的总线布局。

getBusesLayoutForLayoutChangeOfBus()

BusesLayout juce::AudioProcessor::Bus::getBusesLayoutForLayoutChangeOfBus (const AudioChannelSet & set) const

返回更改此总线布局后所有总线的结果布局。

更改单个总线的布局也可能改变所有其他总线的布局。此方法返回如果你将此总线的布局更改为给定布局，音频处理器所有总线的布局会是什么。如果无法支持给定布局，则此方法将返回次佳布局。

int juce::AudioProcessor::Bus::getChannelIndexInProcessBlockBuffer (int channelIndex) const noexcept

返回某条总线的通道在 processBlock 缓冲区中的位置。

可以在 processBlock 中调用，以确定主 AudioBuffer 的哪个通道映射到某个总线的通道。

getBusBuffer()

template<typename FloatType> AudioBuffer < FloatType > juce::AudioProcessor::Bus::getBusBuffer (AudioBuffer < FloatType > & processBlockBuffer) const inline

返回一个 AudioBuffer，其中包含特定总线的一组通道指针。

可以在 processBlock 中调用，以获取包含主 AudioBuffer 中某子组的缓冲区，该子组包含该插件的所有通道。
