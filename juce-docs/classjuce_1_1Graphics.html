juce::Graphics 类参考

详细说明

用于绘制组件或图像的图形上下文。

当 Component 需要绘制时，会向它的 Component::paint() 方法传入一个 Graphics 上下文，随后你调用此对象中的方法来实际绘制组件的内容。

也可以从图像创建一个 Graphics，以便直接绘制到该图像上。

另见
Component::paint

Graphics() [1/2]

juce::Graphics::Graphics (const Image & imageToDrawOnto) explicit

创建一个 Graphics 对象，直接绘制到给定图像上。

创建的图形对象将被设置为绘制到该图像上，上下文的裁剪区域为图像的整个尺寸，其原点为图像的原点。要绘制到图像的某个子区域，请使用 reduceClipRegion() 和 setOrigin() 方法。

显然，在此上下文被删除之前，你不应删除该图像。

被以下对象引用： juce::Graphics::ScopedSaveState::ScopedSaveState()、juce::Graphics::ScopedSaveState::~ScopedSaveState()。

更改与当前颜色一起使用的不透明度。

如果绘制使用的是纯色，这会将其不透明度改为这个新值（也就是说，不会将颜色的不透明度乘以该量）。

drawFittedText() [1/2]

void juce::Graphics::drawFittedText (const String & text, int x, int y, int width, int height, Justification justificationFlags, int maximumNumberOfLines, float minimumHorizontalScale = 0.0f, GlyphArrangementOptions options = {}) const

尝试在给定空间内绘制文本字符串。

它会尽力让给定文本在指定矩形内可读，因此很适合用于给东西加标签。

如果文本太大，它会水平压缩，或者在 maximumLinesToUse 允许的情况下分成多行。如果文本实在放不进该空间，它会尽可能多地塞进去，并在末尾加上省略号表示已被截断。

Justification 参数让你指定文本在矩形内如何布局，包括水平和垂直方向。

minimumHorizontalScale 参数指定文本可以水平压缩多少以挤进空间。如果你不希望发生任何水平缩放，可将此值设为 1.0f。若想使用默认值，传 0。

另见
GlyphArrangement::addFittedText

引用了 x、y。
