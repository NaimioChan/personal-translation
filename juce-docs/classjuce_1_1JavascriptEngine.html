juce::JavascriptEngine 类参考

详细说明

此类是 QuickJS 的封装，后者是一个符合 ES2023、可嵌入的 javascript 引擎。

它可能不如浏览器中那些经过 JIT 编译的高级引擎快，但它是一个极其紧凑、低开销的 javascript 解释器，并与 juce var 和 DynamicObject 类集成。你可以轻松让 JS 使用以 DynamicObject 子类定义的原生对象。

使用时，只需创建此类的一个实例并调用 execute() 来运行代码。脚本设置的变量可通过 evaluate() 获取；如果需要为脚本提供原生对象，可用 registerNativeObject() 添加。

evaluate()

var juce::JavascriptEngine::evaluate (const String & javascriptCode, Result * errorMessage = nullptr)

尝试解析并运行一个 javascript 表达式，并返回结果。

如果存在语法错误或表达式无法求值，返回值将是 var::undefined()。errorMessage 参数可让你查明解析错误。如果表达式求值成功但没有结果，返回值将是一个 void var。你可以指定程序允许运行的最长时间，超过该时间将带着错误消息返回。

RelativeTime juce::JavascriptEngine::maximumExecutionTime
