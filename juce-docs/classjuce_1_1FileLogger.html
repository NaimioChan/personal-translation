FileLogger()

juce::FileLogger::FileLogger (const File & fileToWriteTo, const String & welcomeMessage, const int64 maxInitialFileSizeBytes = 128 *1024)

为给定文件创建一个 FileLogger。

参数
fileToWriteTo要使用的文件——新消息将追加到该文件。如果文件不存在，将创建它，以及所需的任何父目录。
welcomeMessage打开时，日志器将向日志写入一个头部、当前日期和时间，以及此欢迎消息
maxInitialFileSizeBytes如果此值为零或更大，那么如果文件已存在但大于此字节数，将截断文件开头以保持大小。这可防止日志文件随时间变得异常庞大。文件将在换行边界处截断。如果此值小于零，则不施加大小限制；如果为零，文件将始终被删除。注意，大小仅在此对象创建时检查一次——之后进行的任何日志记录都将直接追加而不做任何检查

被以下对象引用： createDateStampedLogger()、createDefaultAppLogger()、trimFileSize()。

createDefaultAppLogger()

FileLogger * juce::FileLogger::createDefaultAppLogger (const String & logFileSubDirectoryName, const String & logFileName, const String & welcomeMessage, const int64 maxInitialFileSizeBytes = 128 *1024) static

在此平台上的正确位置创建日志文件的辅助函数。

如果因某种原因无法创建文件，该方法可能返回 nullptr。

参数
logFileSubDirectoryName要在日志文件夹（由 getSystemLogFileFolder 返回）内创建的子目录名称。此处最好使用类似应用程序名称的内容。
logFileName要创建的文件名，例如 "MyAppLog.txt"。
welcomeMessage打开日志时将写入日志的消息。
maxInitialFileSizeBytes（有关更多信息，请参见 FileLogger 构造函数）

createDateStampedLogger()

FileLogger * juce::FileLogger::createDateStampedLogger (const String & logFileSubDirectoryName, const String & logFileNameRoot, const String & logFileNameSuffix, const String & welcomeMessage) static

在此平台上的正确位置创建日志文件的辅助函数。

使用的文件名基于所提供的前缀和后缀字符串以及时间和日期字符串，这意味着将始终创建一个新的空日志文件，而不是追加到现有文件。

如果因某种原因无法创建文件，该方法可能返回 nullptr。

参数
logFileSubDirectoryName要在日志文件夹（由 getSystemLogFileFolder 返回）内创建的子目录名称。此处最好使用类似应用程序名称的内容。
logFileNameRoot要使用的文件名开头部分，例如 "MyAppLog_"。将为其附加时间戳和 logFileNameSuffix
logFileNameSuffix要使用的文件后缀，例如 ".txt"
welcomeMessage打开日志时将写入日志的消息。

引用了 FileLogger()。

getSystemLogFileFolder()

File juce::FileLogger::getSystemLogFileFolder () static

返回应存储日志文件的操作系统特定文件夹。

在 Windows 上，这将返回一个日志器，其路径类似：c:\Documents and Settings\username\Application Data\[logFileSubDirectoryName]\[logFileName]

在 Mac 上，它将创建类似这样的路径：~/Library/Logs/[logFileSubDirectoryName]/[logFileName]
