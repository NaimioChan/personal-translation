juce::AsyncUpdater 类参考

详细说明

具有一个异步触发的回调方法。

该对象允许触发异步回调函数，用于诸如稍后将多次更新合并为单次回调之类的任务。

基本上，一次或多次调用 triggerAsyncUpdate() 将导致消息线程尽快调用 handleAsyncUpdate()。

成员函数

triggerAsyncUpdate()

void juce::AsyncUpdater::triggerAsyncUpdate ()

使回调在稍后时间触发。

该方法会立即返回，之后消息线程将尽快回调 handleAsyncUpdate() 方法。

如果更新回调已处于等待状态但尚未发生，调用此方法不会有任何效果。

从任何线程调用该方法都是线程安全的，但要注意从实时（如音频）线程调用它，因为这涉及向系统队列投递消息，可能会阻塞（在大多数操作系统上通常如此）。

cancelPendingUpdate()

void juce::AsyncUpdater::cancelPendingUpdate () noexcept

这将停止任何待处理的更新发生。

如果在 triggerAsyncUpdate() 之后、handleAsyncUpdate() 回调发生之前调用，这将取消 handleAsyncUpdate() 回调。

注意该方法只是取消下一次回调——如果回调已在另一个线程上执行，这不会阻塞直到回调结束，因此无法保证该方法返回时回调未在运行。

被以下对象引用： handleAsyncUpdate()。

handleUpdateNowIfNeeded()

void juce::AsyncUpdater::handleUpdateNowIfNeeded ()

如果已触发更新且正在等待处理，这将同步调用它。

可将此用作一种“冲刷”操作——如果有更新待处理，将立即调用 handleAsyncUpdate() 方法；如果没有待处理的更新，则什么也不做。

因为它可能调用回调，该方法只能在主事件线程上调用。

引用了 handleUpdateNowIfNeeded()。
