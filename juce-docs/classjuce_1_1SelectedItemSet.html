详细说明

template<class SelectableItemType>
class juce::SelectedItemSet< SelectableItemType >

管理可选项目的列表。

使用其中之一来跟踪用户已高亮的内容，例如图标或列表中的项目。

此类是模板化的，因此你可以用它保存一组指向对象的指针，或一组 ID 编号或句柄，以应对每个项目不一定总有对应对象的情况。

要在项目被选中/取消选中时得到通知，请向此对象注册 ChangeListener。

addToSelectionBasedOnModifiers()

template<class SelectableItemType> void juce::SelectedItemSet < SelectableItemType >::addToSelectionBasedOnModifiers (ParameterType item, ModifierKeys modifiers) inline

选中或取消选中一个项目。

这会使用修饰键来决定是否先取消选中其他项目。

因此如果按住 shift 键，项目将被添加而不取消选中任何内容（与调用 addToSelection() 相同）

如果没有按住任何修饰键，将先清除当前选择（与调用 selectOnly() 相同）

如果按住 ctrl（Mac 上为 command）键，项目将被切换——因此如果它不在集合中就会被添加，如果已在集合中就会被取消选中。

如果你选中的项目同时也可拖动，可能需要使用 addToSelectionOnMouseDown() 和 addToSelectionOnMouseUp() 调用来处理这种用法中的细节。

addToSelectionOnMouseDown()

template<class SelectableItemType> bool juce::SelectedItemSet < SelectableItemType >::addToSelectionOnMouseDown (ParameterType item, ModifierKeys modifiers) inline

根据鼠标按下事件，选中或取消选中同时也可拖动的项目。

如果你在 mouseDown 事件开始时调用 addToSelectionOnMouseDown()，然后在 mouseUp 事件结束时调用 addToSelectionOnMouseUp()，就能轻松处理可同时拖动的对象集合的多选。

例如，如果你已选中多个项目，然后点击其中一个（未拖动），你会期望这取消选中其他项目，只选中你点击的那个。但如果你点击该项目并拖动了它，你会期望它们都保持选中。

调用此方法时，你需要保存布尔返回值，因为 addToSelectionOnMouseUp() 方法需要知道这个值。
