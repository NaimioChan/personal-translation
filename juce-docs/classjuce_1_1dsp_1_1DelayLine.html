详细说明

template<typename SampleType, typename InterpolationType = DelayLineInterpolationTypes::Linear>
class juce::dsp::DelayLine< SampleType, InterpolationType >

一个延迟线处理器，具有多种分数延迟计算算法，支持块处理和逐采样处理，适用于实时调制延迟，或创建带反馈的标准延迟效果。

注意：如果你打算实时改变延迟，可能需要使用斜坡或低通滤波器对延迟的变化进行系统性平滑。

SmoothedValue, FirstOrderTPTFilter

template<typename SampleType, typename InterpolationType = DelayLineInterpolationTypes::Linear> SampleType juce::dsp::DelayLine < SampleType, InterpolationType >::popSample (int channel, SampleType delayInSamples = -1, bool updateReadPointer = true)

从延迟线的某个通道弹出一个采样。

使用此函数可实时调制延迟，或实现带反馈的标准延迟效果。

参数
channel延迟线的目标通道。
delayInSamples设置所需的分数延迟（单位为采样），或设为 -1 以使用之前正在使用的值或通过 setDelay 函数设置的值。
updateReadPointer如果你对每个采样调用一次该函数，应设为 true；如果你需要多抽头延迟功能，应设为 false。
