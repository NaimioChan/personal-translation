juce::ComponentPeer 类参考

详细说明

Component 类在内部使用 ComponentPeer 来创建和管理真实的操作系统窗口。

这是一个抽象基类——平台相关代码中包含它在各个平台上的实现。

用户代码很少需要涉及本类。

StyleFlags

enum juce::ComponentPeer::StyleFlags

这些标志的组合会被传给 ComponentPeer 构造函数。

枚举值
windowAppearsOnTaskbar 

表示窗口应在任务栏上有对应条目（在 MacOSX 上忽略）。

windowIsTemporary 

表示窗口是临时弹出窗口，如菜单、工具提示等。

windowIgnoresMouseClicks 

表示窗口应允许鼠标点击穿透（某些平台上可能无法做到）。

windowHasTitleBar 

表示窗口应具有操作系统特定的普通标题栏和边框。

如果未指定，窗口将无边框。

windowIsResizable 

表示窗口应具有可调整大小的边框。

windowHasMinimiseButton 

表示如果窗口有标题栏，则其上应有最小化按钮。

windowHasMaximiseButton 

表示如果窗口有标题栏，则其上应有最大化按钮。

windowHasCloseButton 

表示如果窗口有标题栏，则其上应有关闭按钮。

windowHasDropShadow 

表示窗口应带有投影（并非所有平台都能做到）。

windowRepaintedExplicitly 

不供公共使用——它告诉窗口不要自行重绘，而只在调用 performAnyPendingRepaintsNow() 方法时重绘。

windowIgnoresKeyPresses 

告诉窗口不捕获任何按键。

可用于插件窗口之类的情况，防止它们干扰宿主的快捷键。

windowRequiresSynchronousCoreGraphicsRendering 

表示不应使用异步 Core Graphics 绘制操作来渲染窗口。

如果出现区域未在预期时间重绘的问题，请使用此项（仅 macOS 和 iOS）。

windowIsSemiTransparent 

不供公共使用——使窗口透明。

setBounds()

virtual void juce::ComponentPeer::setBounds (const Rectangle < int > & newBounds, bool isNowFullScreen) pure virtual

移动并调整窗口大小。

如果原生窗口包含在另一个窗口中，则坐标相对于父窗口的原点，而不是屏幕原点。此时，位置使用与大小相同的坐标空间指定。

举例来说，假设对一个被包含的 ComponentPeer 调用 setBounds()，newBounds 设为 { 10, 20, 30, 40 }，而对等体的原生缩放系数为 1.5。新边界将被转换为物理像素 { 15, 30, 45, 60 }，这意味着对等体将位于父级中的 { 15, 30 } physical pixels 处。

这应导致对 handleMovedOrResized() 的回调。

getPlatformScaleFactor()

virtual double juce::ComponentPeer::getPlatformScaleFactor () const inline virtual noexcept

在 Windows 和 Linux 上，这会返回当前应用于原生窗口的操作系统缩放系数。

它用于在操作系统 API 层面在物理像素与逻辑像素之间转换，除非你直接与原生窗口打交道，否则自己的代码中不应需要用到它。

setCustomPlatformScaleFactor()

virtual void juce::ComponentPeer::setCustomPlatformScaleFactor (std::optional< double >) inline virtual

在 Windows 和 Linux 上，用非空的可选值调用它会覆盖平台为此窗口指定的任何缩放系数。

即使平台尝试设置新的缩放系数，新的缩放系数也会保留！传入空的可选值可恢复到平台提供的缩放系数。

此项供插件包装器使用，因为宿主可能尝试设置与平台缩放系数不同的值。你通常不应直接调用它。

getCustomPlatformScaleFactor()

virtual std::optional< double > juce::ComponentPeer::getCustomPlatformScaleFactor () const inline virtual

返回使用 setCustomPlatformScaleFactor() 设置的自定义缩放系数（如果有）。

如果已设置自定义缩放系数，getPlatformScaleFactor() 将始终返回该值，实际上会覆盖系统请求的任何缩放系数。否则，如果自定义平台缩放系数为 nullopt，系统将自动更新缩放系数。
