详细说明

template<typename FloatType>
struct juce::dsp::FilterDesign< FloatType >

该类提供一组用于生成高阶低通滤波器的 FIR::Coefficients 和 IIR::Coefficients 的函数。

它们可用于直接处理音频（作为均衡器）、在重采样算法中等等。

另见 FIRFilter::Coefficients、FIRFilter、WindowingFunction、IIRFilter::Coefficients、IIRFilter

成员函数

designFIRLowpassWindowMethod()

template<typename FloatType> FIRCoefficientsPtr juce::dsp::FilterDesign < FloatType >::designFIRLowpassWindowMethod (FloatType frequency, double sampleRate, size_t order, WindowingMethod type, FloatType beta = static_cast< FloatType >(2)) static

该方法使用窗函数设计方法作用于 sinc 脉冲响应，为低通滤波器生成 FIR::Coefficients。

它是生成高阶低通滤波器最简单的方法之一，其缺点是：要在阻带中实现给定的衰减，需要比更复杂的方法更多的系数。

它生成线性相位滤波器系数。

注意：flatTop WindowingMethod 生成的脉冲响应最大幅度大于一，根据应用可能需要归一化。

参数
frequency低通滤波器的截止频率
sampleRate滤波器设计中使用的采样率
order滤波器的阶数
type类型，必须是 WindowingFunction::WindowingType
betaKaiser 窗函数可用的可选附加参数

template<typename FloatType> FIRCoefficientsPtr juce::dsp::FilterDesign < FloatType >::designFIRLowpassKaiserMethod (FloatType frequency, double sampleRate, FloatType normalisedTransitionWidth, FloatType amplitudedB) static

它生成线性相位滤波器系数。

designIIRLowpassHalfBandPolyphaseAllpassMethod()

template<typename FloatType> IIRPolyphaseAllpassStructure juce::dsp::FilterDesign < FloatType >::designIIRLowpassHalfBandPolyphaseAllpassMethod (FloatType normalisedTransitionWidth, FloatType stopbandAmplitudedB) static

该方法为低通滤波器生成 IIR::Coefficients 数组，截止频率位于半带处，使用的算法描述于 Pavel Valenzuela 和 Constantinides 的文章“Digital Signal Processing Schemes for efficient interpolation and decimation”。

结果是一个 IIRPolyphaseAllpassStructure 对象。

该结构的两个成员 directPath 和 delayedPath 是 IIR::Coefficients 数组，由多相二阶全通滤波器和第二个数组中的附加延迟构成，可用于在两条并行路径中处理的级联滤波器，最终必须将二者相加才能获得高阶高效低通滤波。

所得通带的增益为 6 dB，因此如果你要将该方法用于两倍过采样以外的用途，别忘了补偿它。

参数
normalisedTransitionWidth通带与阻带之间过渡的归一化尺寸，在 0 到 0.5 之间
stopbandAmplitudedB阻带中预期的最大幅度，单位为 dB（必须为负）
