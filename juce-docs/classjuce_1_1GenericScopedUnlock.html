juce::GenericScopedUnlock< LockType > 类模板参考

详细说明

template<class LockType>
class juce::GenericScopedUnlock< LockType >

自动解锁并重新锁定互斥量对象。

这与 GenericScopedLock 对象相反——它不在对象生命周期内锁定互斥量，而是将其解锁。

确保不要尝试解锁实际上未加锁的互斥量！

例如

CriticalSection myCriticalSection;

for (;;)
{
 const GenericScopedLock<CriticalSection> myScopedLock (myCriticalSection);
 // myCriticalSection is now locked

    ... do some stuff with it locked...

 while (xyz)
    {
        ... do some stuff with it locked...

 const GenericScopedUnlock<CriticalSection> unlocker (myCriticalSection);

 // myCriticalSection is now unlocked for the remainder of this block,
 // and re-locked at the end.

        ...do some stuff with it unlocked ...
    }

 // myCriticalSection gets unlocked here
}

构造函数与析构函数

GenericScopedUnlock()

template<class LockType> juce::GenericScopedUnlock < LockType >::GenericScopedUnlock (const LockType & lock) inline explicit noexcept

创建一个 GenericScopedUnlock。

一旦创建，它将解锁 CriticalSection，当 ScopedLock 对象被删除时，CriticalSection 将被重新加锁。

确保此对象由同一线程创建和删除，否则无法保证会发生什么！最好只将其作为局部栈对象使用，而不要用 new() 运算符创建。

析构函数被调用时 CriticalSection 将被解锁。

确保此对象由同一线程创建和删除，否则无法保证会发生什么！
