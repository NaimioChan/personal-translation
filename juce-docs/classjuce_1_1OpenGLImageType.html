juce::OpenGLImageType 类参考

详细说明

ImagePixelData 的一种类型，将图像数据存储在 OpenGL 帧缓冲区中，使 JUCE Image 对象能够包装帧缓冲区。

通过从 OpenGLFrameBufferImage 实例创建 Image，你随后就可以使用 Graphics 对象以普通的 JUCE 2D 操作绘制到帧缓冲区中。

OpenGLFrameBuffer 仅支持 RGBA 帧缓冲区，因此单通道图像将图像数据保留在 CPU 内存中，并在绘制时上传到纹理。对于这些图像，getFrameBufferFrom() 将返回 nullptr。

请求 Image::RGB 图像会被提升为 Image::ARGB，并以与 Image::ARGB 请求相同的方式使用帧缓冲区。
