juce::RecentlyOpenedFilesList 类参考

详细说明

管理一组文件，用作最近打开文档的列表。

这是一个方便的类，用于保存最近打开文档的列表，并提供了清除不存在的文件、自动将其添加到菜单以及简化持久化等实用方法。

createPopupMenuItems()

int juce::RecentlyOpenedFilesList::createPopupMenuItems (PopupMenu & menuToAddItemsTo, int baseItemId, bool showFullPaths, bool dontAddNonExistentFiles, const File ** filesToAvoid = nullptr)

向菜单添加条目，每一项代表列表中的一个文件。

这对于在应用中创建“打开最近文件...”菜单很方便。菜单项从 baseItemId 值开始连续编号，可以作为完整路径名添加，也可以只添加文件名的最后一部分。

如果 dontAddNonExistentFiles 为 true，则将检查每个文件，只有存在的文件才会被添加。

如果 filesToAvoid 不是 nullptr，则它被视为一个以零结尾的文件对象指针数组。出现在此列表中的任何文件都不会被添加到菜单——原因是你可能已打开了多个文件，因此可能不希望它们在菜单中显示。

它返回已添加的项数。

toString()

String juce::RecentlyOpenedFilesList::toString () const

返回一个字符串，封装列表中的所有文件。

返回的字符串稍后可以传给 restoreFromString() 以重建列表。这对于持久化列表很方便，例如存储在 PropertiesFile 对象中。
