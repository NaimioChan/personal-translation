juce::RuntimePermissions 类参考

详细说明

Class to handle app runtime permissions for certain functionality on some platforms.

The use of this class is currently only required if the app should run on
Android API level 23 and higher.

On lower API levels, the permissions are specified in the app manifest. On iOS,
runtime permission requests are handled automatically by the Apple APIs and not
manually in the app code. On Windows, OS X, and Linux, runtime permissions are not
used at all. In all these cases, request() will simply call through to the
callback with no overhead and pass true (making it safe to use on all platforms).

For example, to enable audio recording on Android in your cross-platform app,
you could modify your code as follows:

Old code:

    audioDeviceManager.initialise (2, 2, nullptr, true, String(), nullptr);

New code:

    RuntimePermissions::request (
        RuntimePermissions::recordAudio,
        [this] (bool wasGranted)
        {
             if (! wasGranted)
             {

e.g. display an error or initialise with 0 input channels return; }

audioDeviceManager.initialise (2, 2, nullptr, true, String(), nullptr); } );

成员枚举

PermissionID

enum juce::RuntimePermissions::PermissionID
枚举值
recordAudio 

访问麦克风的权限（在 Android 上必需）。

例如，要以非零输入通道数初始化 AudioDeviceManager，并打开默认音频输入设备，你需要请求此权限。

bluetoothMidi 

扫描并配对蓝牙 MIDI 设备的权限（在 Android 上必需）。

你需要在调用 BluetoothMidiDevicePairingDialogue::open() 之前请求此权限，否则将找不到任何设备。

readExternalStorage 

读取外部存储（如 SD 卡）的权限。

writeExternalStorage 

写入外部存储（如 SD 卡）的权限。

camera 

使用相机的权限。

readMediaAudio 

读取并非由你的应用创建的音频文件的权限。

在 iOS 和 33 之前的 Android 版本上，效果与 readExternalStorage 相同。

readMediaImages 

读取并非由你的应用创建的图像文件的权限。

在 iOS 和 33 之前的 Android 版本上，效果与 readExternalStorage 相同。

readMediaVideo 

读取并非由你的应用创建的视频文件的权限。

在 iOS 和 33 之前的 Android 版本上，效果与 readExternalStorage 相同。

postNotification

成员函数

request()

void juce::RuntimePermissions::request (PermissionID permission, Callback callback) static

调用此方法以请求运行时权限。

参数
permission要请求的权限的 PermissionID。
callback请求被授予或拒绝后要调用的回调；如果权限已授予，传入的参数为 true，否则为 false。

如果获取该权限不需要也不可能进行运行时请求，则立即调用回调。如果权限已授予或在此平台上无需权限，传入的参数为 true，否则为 false。

如果获取该权限需要运行时请求，则在操作系统授予或拒绝所请求的权限之后（通常是通过向用户显示对话框并等待用户响应），会异步调用回调。

被以下对象引用： juce::StandalonePluginHolder::StandalonePluginHolder()。

isGranted()

bool juce::RuntimePermissions::isGranted (PermissionID permission) static

如果应用已获得此权限（无论是通过先前的运行时请求还是其他方式），或者无需任何权限，则返回 true。

注意，即使 isRequired 返回 false，这也可能为 false。在这种情况下，该权限根本无法在运行时获得。

被以下对象引用： juce::StandalonePluginHolder::StandalonePluginHolder()。
