绘制滚动条上的某个按钮。

参数
g要绘制到的上下文
scrollbar滚动条本身
width按钮的宽度
height按钮的高度
buttonDirection按钮的方向，其中 0 = 上，1 = 右，2 = 下，3 = 左
isScrollbarVertical如果是垂直滚动条则为 true，水平则为 false
isMouseOverButton鼠标当前是否在按钮上（按住时也为 true）
isButtonDown鼠标按键是否被按住

在 juce::LookAndFeel_V2 和 juce::LookAndFeel_V3 中实现。

引用了 juce::ScrollBar::ScrollBar()。

drawScrollbar()

virtual void juce::ScrollBar::LookAndFeelMethods::drawScrollbar (Graphics & g, ScrollBar & scrollbar, int x, int y, int width, int height, bool isScrollbarVertical, int thumbStartPosition, int thumbSize, bool isMouseOver, bool isMouseDown) pure virtual

绘制滚动条的滑块区域。

参数
g要绘制到的上下文
scrollbar滚动条本身
x要绘制的滑块区域左边缘的 x 位置
y要绘制的滑块区域上边缘的 y 位置
width要绘制的滑块区域的宽度
height要绘制的滑块区域的高度
isScrollbarVertical如果是垂直滚动条则为 true，水平则为 false
thumbStartPosition对于垂直滚动条，为滑块顶部的 y 坐标；对于水平滚动条，为其 x 位置
thumbSize对于垂直滚动条，为滑块的高度；对于水平滚动条，为其宽度。如果不应绘制滑块，此值可能为 0。
isMouseOver鼠标是否在滑块区域上；如果鼠标当前正在拖动滑块，也为 true
isMouseDown鼠标当前是否正在拖动滚动条

在 juce::LookAndFeel_V1、juce::LookAndFeel_V2、juce::LookAndFeel_V3 和 juce::LookAndFeel_V4 中实现。

引用了 juce::Component::isMouseOver()、juce::ScrollBar::ScrollBar()、x、y。
