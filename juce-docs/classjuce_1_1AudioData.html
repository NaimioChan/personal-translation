成员函数

interleaveSamples()

template<typename... SourceFormat, typename... DestFormat> void juce::AudioData::interleaveSamples (NonInterleavedSource < SourceFormat... > source, InterleavedDest < DestFormat... > dest, int numSamples) inline static

辅助函数，用于将采样序列从非交错源转换为交错目标。

调用此方法时，你需要从 AudioData 的 SampleFormat 和 Endianness 类型中指定源和目标的数据格式与字节序，并为二者提供数据及通道数。例如，要把大端采样的浮点流转换为交错的本机字节序 16 位整数采样流，可以这样做：

using SourceFormat = AudioData::Format<AudioData::Float32, AudioData::BigEndian>;
using DestFormat   = AudioData::Format<AudioData::Int16,   AudioData::NativeEndian>;

AudioData::interleaveSamples (AudioData::NonInterleavedSource<SourceFormat> { sourceData, numSourceChannels },
 AudioData::InterleavedDest<DestFormat>        { destData,   numDestChannels },
                              numSamples);

引用了 juce::addBytesToPointer()、juce::source。
