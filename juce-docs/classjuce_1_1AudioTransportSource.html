juce::AudioTransportSource 类参考

详细说明

一个 AudioSource，它接收一个 PositionableAudioSource 并允许播放、停止、启动等。

也可以让它使用缓冲区和后台线程进行预读，并且可以校正不同的采样率。

你可能想将其中之一与 AudioSourcePlayer 和 AudioIODevice 一起使用，以控制音频文件的播放。

AudioSource, AudioSourcePlayer

setSource()

void juce::AudioTransportSource::setSource (PositionableAudioSource * newSource, int readAheadBufferSize = 0, TimeSliceThread * readAheadThread = nullptr, double sourceSampleRateToCorrectFor = 0.0, int maxNumChannels = 2)

设置用作输入源的读取器。

这将停止播放、将位置重置为 0，并切换到新的读取器。

传入的源不会被此对象删除，因此必须由调用者管理。

参数
newSource要使用的新输入源。这可以是 nullptr
readAheadBufferSize用于预读的缓冲区大小。如果为零，则不做预读；如果大于零，将使用 BufferingAudioSource 进行预读。如果你在此设置非零值，还需要设置 readAheadThread 参数。
readAheadThread如果你将 readAheadBufferSize 设为非零值，则还需要提供此 TimeSliceThread 对象供后台读取器使用。在 AudioTransport 源仍在使用它时，不得删除该线程对象。
sourceSampleRateToCorrectFor如果此项非零，它指定源的采样率，播放将进行采样率调整，以保持正确的音高播放。如果为 0，则不执行采样率调整
maxNumChannels可能需要播放的最大通道数

引用了 juce::PositionableAudioSource::PositionableAudioSource()。
