成员数据文档

rotation

float juce::PenDetails::rotation

笔设备的旋转角度，以弧度为单位。

表示笔的顺时针旋转或扭转。默认值为 0。

tiltX

float juce::PenDetails::tiltX

指示指针沿 x 轴的倾斜角度，范围为 -1.0 到 1.0，正值表示向右倾斜。

默认值为 0。

tiltY

float juce::PenDetails::tiltY

指示指针沿 y 轴的倾斜角度，范围为 -1.0 到 1.0，正值表示向用户方向倾斜。

默认值为 0。
