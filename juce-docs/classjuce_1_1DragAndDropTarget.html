juce::DragAndDropTarget 类参考

详细说明

派生自本类的组件可以接收由 DragAndDropContainer 拖放到其上的对象。

要创建一个能接收 DragAndDropContainer 拖放内容的组件，请让你的组件派生自本类，并确保它位于某个 DragAndDropContainer 组件内部。

注意：如果你只需要响应从操作系统拖放到组件上的文件，则不需要这些类：请参阅 FileDragAndDropTarget 类。

isInterestedInDragSource()

virtual bool juce::DragAndDropTarget::isInterestedInDragSource (const SourceDetails & dragSourceDetails) pure virtual

用于检查此目标是否对正在拖动的对象类型感兴趣的回调。

参数
dragSourceDetails包含关于拖动操作来源的信息。
返回
如果此组件希望接收关于此类对象的其他回调，则为 true；如果返回 false，则不会再发出其他回调。

在 juce::Toolbar 和 juce::TreeView 中实现。

itemDragEnter()

virtual void juce::DragAndDropTarget::itemDragEnter (const SourceDetails & dragSourceDetails) virtual

用于指示有东西正被拖到此组件上方的回调。

当用户拖动某物时把鼠标移入此组件，会调用此项。

可将此回调作为触发点，让组件重绘自身，以向用户反馈该项能否放置到这里。

用于指示用户正把某个东西拖过此组件的回调。

当用户拖动某物时把鼠标移到此组件上方，会调用此项。通常覆盖 itemDragEnter() 和 itemDragExit() 就足够了，但此项让你了解中间发生的情况。

itemDragExit()

virtual void juce::DragAndDropTarget::itemDragExit (const SourceDetails & dragSourceDetails) virtual

用于指示某个东西已被拖离此组件边缘的回调。

当用户拖动某物时把鼠标移出此组件，会调用此项。

如果你已用 itemDragEnter() 重绘组件并给出反馈，可把此项作为将其重绘为正常状态的信号。

参数
dragSourceDetails包含关于拖动操作来源的信息。

在以下类中重新实现： juce::Toolbar、juce::TreeView。

itemDropped()

virtual void juce::DragAndDropTarget::itemDropped (const SourceDetails & dragSourceDetails) pure virtual

用于指示用户已把某个东西放置到此组件上的回调。

用户放置项时会调用此项，你可以用描述来判断你的对象是否要处理它。

注意，调用此项后可能不会再调用 itemDragExit 方法，因此如果拖动结束时你有需要做的事情，应在这里清理。

参数
dragSourceDetails包含关于拖动操作来源的信息。

在 juce::Toolbar 和 juce::TreeView 中实现。

shouldDrawDragImageWhenOver()

virtual bool juce::DragAndDropTarget::shouldDrawDragImageWhenOver () virtual

覆盖此方法可以让目标告知拖动容器：光标位于其上时是否绘制拖动图像。

默认返回 true，但如果你返回 false，则光标位于此目标上方时不会显示正常的拖动图像。
