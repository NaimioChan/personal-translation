详细说明

为 AudioFormatWriter 提供 FIFO，使你能够将传入数据推入缓冲区，再由后台线程刷新到磁盘。

ThreadedWriter()

juce::AudioFormatWriter::ThreadedWriter::ThreadedWriter (AudioFormatWriter * writer, TimeSliceThread & backgroundThread, int numSamplesToBuffer)

为给定写入器和线程创建一个 ThreadedWriter。

这里传入的写入器对象将由 ThreadedWriter 拥有，并在不再需要时删除。

要停止写入器并将缓冲区刷新到磁盘，只需删除此对象。

引用了 juce::AudioFormatWriter::AudioFormatWriter()。

write()

bool juce::AudioFormatWriter::ThreadedWriter::write (const float *const * data, int numSamples)

将一些传入的音频数据推入 FIFO。

如果缓冲区中有足够的空闲空间，这会将数据添加到其中，

如果 FIFO 太满，无法接受这么多采样，方法将返回 false——此时你可以等到后台线程有时间处理掉一些缓冲数据后再重试，或者放弃并丢弃这个块。

数据必须是包含与 AudioFormatWriter 对象所用通道数相同通道的数组。这些通道都不能为 null。

setDataReceiver()

void juce::AudioFormatWriter::ThreadedWriter::setDataReceiver (IncomingDataReceiver *)

允许你指定一个回调，此写入器会用传入数据更新它。

接收器将被清空，写入器将在数据到达时开始向其中添加数据。传入空指针可移除当前接收器。

在此写入器仍在使用传入对象时，不得删除该对象。

setFlushInterval()

void juce::AudioFormatWriter::ThreadedWriter::setFlushInterval (int numSamplesPerFlush) noexcept

设置调用 AudioFormatWriter::flush 方法之前应写入多少采样。

将其设为 0 可禁用刷新（这是默认值）。
