juce::MidiMessageCollector 类参考

详细说明

收集传入的实时 MIDI 消息，并将它们转换为适合由基于块的音频回调处理的块。

该类也可用作 MidiKeyboardState::Listener 或 MidiInputCallback，因此可以轻松地以 MIDI 输入或键盘组件作为其源。

清除队列中的所有消息。

addMessageToQueue()

void juce::MidiMessageCollector::addMessageToQueue (const MidiMessage & message)

接收传入的实时消息并将其添加到队列。

该消息的时间戳会被记录，它将在下次调用 removeNextBlockOfMessages() 所返回的块中可被取出。

当与 removeNextBlockOfMessages() 的调用重叠时，此方法完全线程安全。

removeNextBlockOfMessages()

void juce::MidiMessageCollector::removeNextBlockOfMessages (MidiBuffer & destBuffer, int numSamples)

将所有待处理消息作为缓冲区从队列中移除。

这还会校正消息的时间戳，确保它们处于 0 到 numSamples - 1 的范围内。

此调用应由音频处理回调之类的东西定期进行，因为其发生的时间被用于计算 MIDI 事件位置。

当与 removeNextBlockOfMessages() 的调用重叠时，此方法完全线程安全。

前提条件：numSamples 必须大于 0。

ensureStorageAllocated()

void juce::MidiMessageCollector::ensureStorageAllocated (size_t bytes)

为收集的消息预分配存储空间。

可以在音频处理开始之前调用此方法，以确保有足够空间容纳预期的 MIDI 消息，从而避免在音频回调内进行分配。

handleIncomingMidiMessage()

void juce::MidiMessageCollector::handleIncomingMidiMessage (MidiInput * source, const MidiMessage & message) override virtual

接收传入的消息。

当 MIDI 事件到达时，MidiInput 对象会调用此方法。它会在高优先级系统线程上被调用，因此避免在这里做耗时的事情，也避免任何 UI 调用。你可能会发现 MidiBuffer 类有助于将传入消息排队以便稍后使用。

参数
source生成该消息的 MidiInput 对象
message传入的消息。消息的时间戳被设为等同于（Time::getMillisecondCounter() / 1000.0）的值，以指明消息到达的时间
