juce::PathFlatteningIterator 类参考

详细说明

把一个 Path 对象展平为一系列直线段。

用其中一个来遍历 Path 对象，它会把所有曲线转换为线段，便于渲染或进行几何运算。

PathFlatteningIterator()

juce::PathFlatteningIterator::PathFlatteningIterator (const Path & path, const AffineTransform & transform = AffineTransform (), float tolerance = Path::defaultToleranceForMeasurement)

创建一个 PathFlatteningIterator。

创建后，使用 next() 方法以第一条线的位置初始化对象中的各个字段。

参数
path要遍历的路径
transform应用于被遍历路径中每个点的变换
tolerance曲线与其被分解成的直线之间允许的偏差量——容差越大，包含的线越少，生成越快，但平滑度越低。

引用了 juce::Path::defaultToleranceForMeasurement。

bool juce::PathFlatteningIterator::next ()

从路径中获取下一条线段。

这会更新成员变量 x1、y1、x2、y2、subPathIndex 和 closesSubPath，使它们描述新的线段。

返回

指示当前线段是否正在闭合一个子路径。

如果当前线是把子路径的终点重新连接到起点的那条线，则此值为 true。

subPathIndex

int juce::PathFlatteningIterator::subPathIndex

当前线段在当前子路径中的索引。
