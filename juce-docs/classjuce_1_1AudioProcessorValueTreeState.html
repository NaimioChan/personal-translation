juce::AudioProcessorValueTreeState 类参考

详细说明

此类包含一个 ValueTree，用于管理 AudioProcessor 的整个状态。

它有自己的内部参数对象类，链接到其 ValueTree 中的值，每个值都由一个字符串 ID 标识。

你可以通过 state 成员变量访问底层 ValueTree 对象，以便按需向其添加额外属性。

它还提供了一些实用的子类，用于将参数直接连接到滑块等图形界面控件。

此类首选的构造函数接收一组 RangedAudioParameters，或包含 RangedAudioParameters 的 AudioProcessorParameterGroups，并将它们直接添加到所附的 AudioProcessor 中。

使用此类的已废弃方式如下：

1) 创建一个 AudioProcessorValueTreeState，并用 createAndAddParameter() 为它提供一些参数。2) 用类型名称初始化 state 成员变量。

已废弃的构造函数将在 JUCE 的未来版本中从 API 中移除！

构造函数与析构函数

AudioProcessorValueTreeState() [1/2]

juce::AudioProcessorValueTreeState::AudioProcessorValueTreeState (AudioProcessor & processorToConnectTo, UndoManager * undoManagerToUse, const Identifier & valueTreeType, ParameterLayout parameterLayout)

为给定处理器创建状态对象，并设置将控制该处理器的所有参数。

使用此构造函数后，你应 not 为 state 分配一个新的 ValueTree，或调用 createAndAddParameter。

注意，每个 AudioProcessorValueTreeState 只应附加到一个处理器，并且必须与处理器具有相同的生命周期，因为它们之间会相互依赖。

ParameterLayout 参数有一组构造函数，允许你在该构造函数内将多个 RangedAudioParameters 以及包含 RangedAudioParameters 的 AudioProcessorParameterGroups 添加到 AudioProcessorValueTreeState。

YourAudioProcessor()
    : apvts (*this, &undoManager, "PARAMETERS",
             { std::make_unique<AudioParameterFloat> ("a", "Parameter A", NormalisableRange<float> (-100.0f, 100.0f), 0),
               std::make_unique<AudioParameterInt> ("b", "Parameter B", 0, 5, 2) })

要以编程方式添加参数，可以在 ParameterLayout 实例上反复调用 add：

AudioProcessorValueTreeState::ParameterLayout createParameterLayout()
{
 AudioProcessorValueTreeState::ParameterLayout layout;

 for (int i = 1; i < 9; ++i)
        layout.add (std::make_unique<AudioParameterInt> (String (i), String (i), 0, i, 0));

 return layout;
}

YourAudioProcessor()
    : apvts (*this, &undoManager, "PARAMETERS", createParameterLayout())
{
}

copyState()

ValueTree juce::AudioProcessorValueTreeState::copyState ()

返回状态值树的副本。

AudioProcessorValueTreeState 的 ValueTree 在消息线程上内部更新，但有些情况下你可能想从其它线程访问状态（getStateInformation 就是一个好例子）。此方法会刷新所有待处理的音频参数值更新，并以线程安全的方式返回状态的副本。

注意：此方法使用锁来同步线程访问，因此虽然它是线程安全的，但不是实时安全的。不要在你的音频处理代码中调用此方法！
