juce::AccessibleState 类参考

详细说明

表示无障碍 UI 元素的状态。

此类的实例由 AccessibilityHandler::getCurrentState() 返回，用于把其当前状态传达给无障碍客户端。

AccessibilityHandler

构造函数与析构函数

AccessibleState()

juce::AccessibleState::AccessibleState () default

构造函数。

表示未设置任何标志的 "默认" 状态。要设置标志，请使用 withX() 方法之一——它们可以串联起来设置多个标志。

被以下对象引用： withAccessibleOffscreen()、withCheckable()、withChecked()、withCollapsed()、withExpandable()、withExpanded()、withFocusable()、withFocused()、withIgnored()、withMultiSelectable()、withSelectable()、withSelected()。
