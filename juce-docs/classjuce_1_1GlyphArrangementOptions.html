成员函数

withLineSpacing()

GlyphArrangementOptions juce::GlyphArrangementOptions::withLineSpacing (float x) const inline nodiscard

我们用此值增加后续各行基线之间的距离。

Line 间距会加在该行下降部的下方，不影响第一行的基线。

基线之间的总距离为 lineHeight * lineHeightMultiple + lineSpacing。

引用了 juce::withMember()、x。

withLineHeightMultiple()

GlyphArrangementOptions juce::GlyphArrangementOptions::withLineHeightMultiple (float x) const inline nodiscard

我们用此值乘以后续各行基线之间的原始距离。

行高倍数会同时应用于上升部和下降部，因此会影响第一行的基线。

基线之间的总距离为 lineHeight * lineHeightMultiple + lineSpacing。

引用了 juce::withMember()、x。
