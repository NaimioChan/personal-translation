juce::TreeViewItem 类参考

详细说明

TreeView 中的项目。

TreeViewItem 可以是树中的叶节点，也可以包含自己的子项目。

要实现包含子项目的项目，请重写 itemOpennessChanged() 方法，使其在打开时使用 addSubItem 方法将新子项目添加到自身。根据项目的性质，它可能选择只在第一次打开时这样做，也可能希望每次都刷新自身。它还可以选择在关闭时删除其子项目，或保留它们。

sortSubItems()

template<class ElementComparator> void juce::TreeViewItem::sortSubItems (ElementComparator & comparator) inline

使用标准数组比较器对子项目列表排序。

这将使用比较器对象将元素排序。比较器对象必须具有以下形式的方法：

int compareElements (TreeViewItem* first, TreeViewItem* second);

……并且此方法必须返回：

  • 如果第一个先于第二个，则返回值 < 0
  • 如果两个对象等价，则返回值 0
  • 如果第二个先于第一个，则返回值 > 0

为提高性能，compareElements() 方法可以声明为 static 或 const。

itemOpennessChanged()

virtual void juce::TreeViewItem::itemOpennessChanged (bool isNowOpen) virtual

当项目被打开或关闭时调用。

当调用 setOpen() 且项目已通过 mightContainSubItems() 方法声明它可能有子项目时，会调用此方法，让项目创建或管理其子项目。

因此，当以 isNowOpen 为 true 调用此方法时（即项目正在被打开），子类可能选择使用 clearSubItems() 和 addSubItem() 刷新其子项目列表。

当以 isNowOpen 为 false 调用此方法时，子类可能想用 clearSubItems() 节省空间，也可能选择保留它们，取决于树的性质。

如果更适合手头任务，你也可以将此回调作为触发点，启动一个异步创建并添加子项目的后台进程。

getItemWidth()

virtual int juce::TreeViewItem::getItemWidth () const inline virtual

如果你的项目需要特定的像素宽度，返回该值；如果你更希望它填满 TreeView 中的任何可用空间，返回 -1。

如果所有项目都返回 -1，则不会显示水平滚动条；但如果任何项目具有固定宽度并超出 TreeView 的宽度，则会出现滚动条。

createItemComponent()

virtual std::unique_ptr< Component > juce::TreeViewItem::createItemComponent () inline virtual

创建一个将用于表示此项目的组件。

你不必实现此方法——如果它返回 nullptr，则不会为该项目使用任何组件，你可以直接用 paintItem() 回调绘制它。但如果你确实返回了组件，它将定位在 TreeView 中，以便用于表示该项目。

返回的组件将由 TreeView 管理，并在之后离开屏幕或不再需要时删除。其位置和大小将完全由树管理，因此不要尝试移动它。

你可能想对组件做的一件事是给它一个指向创建它的 TreeView 的指针。这完全安全，不存在悬空指针的危险，因为 TreeView 总是在自身被删除之前删除该组件。

只要遵守这些规则，你可以返回任何类型的组件。如果你要做项目拖放、或想用 Label 组件编辑项目名称等，这会非常有用。

如果返回非空 variant，则当用户拖动项目时，TreeView 会在其父级层次结构中查找 DragAndDropContainer，并用它触发拖放操作，以此字符串作为源描述，以 TreeView 本身作为源组件。

如果需要更复杂的拖放行为，可以为项目使用自定义组件，并用它们触发拖动。

要在树中接受拖放，见 isInterestedInDragSource()、isInterestedInFileDrag() 等。

另见

isInterestedInFileDrag()

virtual bool juce::TreeViewItem::isInterestedInFileDrag (const StringArray & files) virtual

如果你希望项目能够接受文件拖放，请实现此方法并返回 true。

如果返回 true 并允许放入某些文件，还需要实现 filesDropped() 方法以对它们进行处理。

注意，这会经常被调用，因此请让实现非常快！绝对没有时间去尝试打开文件并思考其中的内容！

要响应其他类型对象的内部拖放，见 isInterestedInDragSource()。

setDrawsInLeftMargin()

void juce::TreeViewItem::setDrawsInLeftMargin (bool canDrawInLeftMargin) noexcept

设置一个标志，指示该项目希望被允许一直绘制到 TreeView 的左边缘。

默认情况下为 false，这意味着调用 paintItem() 方法时，其图形上下文被裁剪为只允许在项目矩形内绘制。如果此标志设为 true，则图形上下文左侧不被裁剪，因此可以一直绘制到左边距。注意上下文原点仍在同一位置，因此其左侧任何内容的坐标将为负。这主要在你想要在高亮项目后面绘制更宽的条时有用。

setDrawsInRightMargin()

void juce::TreeViewItem::setDrawsInRightMargin (bool canDrawInRightMargin) noexcept

设置一个标志，指示该项目希望被允许一直绘制到 TreeView 的右边缘。

与 setDrawsInLeftMargin 类似：当此标志设为 true 时，图形上下文右侧不被裁剪。与 setDrawsInLeftMargin 不同，你会很少需要用到此函数，因为除非你的 TreeViewItem 重写 getItemWidth 返回正值，否则此方法不会裁剪右边距。

getOpennessState()

std::unique_ptr< XmlElement > juce::TreeViewItem::getOpennessState () const

保存当前展开/折叠节点的状态，以便稍后恢复。

这会拍摄哪些子节点已被显式打开或关闭的快照，并将其记录为 XML。为标识节点对象，它使用 TreeViewItem::getUniqueName() 方法创建命名路径。这意味着只要树中包含唯一名称相同的节点，就可以将相同的打开/关闭状态恢复到完全不同的树实例。

你通常想用 TreeView::getOpennessState() 而不是针对特定项目调用它，但如果你需要临时保存树某一部分的状态，这会很方便。

注意，如果树的所有节点都处于默认状态，这可能返回 nullptr。

另见
TreeView::getOpennessState, restoreOpennessState
