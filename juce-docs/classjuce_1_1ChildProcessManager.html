juce::ChildProcessManager 类参考

详细说明

管理一组 ChildProcess，并定期检查它们的返回值。

完成时，它会调用通过 addChildProcessExitedListener() 添加的监听器。

该类主要面向 Linux 上的使用，在那里已终止的子进程只有在终止后读取其返回码才会被清理。为确保这一点，需要调用 ChildProcess::isFinished() 直到它返回 false，或调用 ChildProcess::waitForProcessToFinish() 直到它返回 true。

该类将在 Timer 线程上持续查询返回码，直到进程终止。如果你要在 Linux 上启动和停止多个可能需要很长时间才能完成的 ChildProcess，这会很方便。

由于该类使用 Timer 检查子进程状态，通常只在消息线程上访问返回的 ChildProcess 才是安全的。
