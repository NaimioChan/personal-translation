juce::Analytics 类参考

详细说明

管理分析数据的单例类。

使用 Analytics 对象把一个或多个分析数据发往 AnalyticsDestinations。

另见
AnalyticsDestination, ThreadedAnalyticsDestination, AnalyticsDestination::AnalyticsEvent

成员函数

addDestination()

void juce::Analytics::addDestination (AnalyticsDestination * destination)

向本 Analytics 对象管理的 AnalyticsDestinations 列表中添加一个 AnalyticsDestination。

Analytics 类会接管传给本函数的 AnalyticsDestination 的所有权。

参数
destination要管理的 AnalyticsDestination

getDestinations()

OwnedArray < AnalyticsDestination > & juce::Analytics::getDestinations ()

返回本类管理的 AnalyticsDestinations 数组。

如果你向本类添加了 ThreadedAnalyticsDestination 的子类，可以把它们从列表中移除，以强制它们冲刷掉所有待处理事件。

logEvent()

void juce::Analytics::logEvent (const String & eventName, const StringPairArray & parameters, int eventType = 0)

把一个 AnalyticsEvent 发送给所有 AnalyticsDestinations。

AnalyticsEvent 会被打上时间戳，其 userId 与 userProperties 由先前对 setUserId 和 setUserProperties 的调用所设置的值填充。name、parameters 与 type 由传给本函数的实参填充。

参数
eventName事件名称
parameters事件参数
eventType（可选）一个表示事件类型的整数，不提供时会被设为 0。
