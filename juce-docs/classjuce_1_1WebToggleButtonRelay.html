juce::WebToggleButtonRelay 类参考

详细说明

辅助类，将音频参数信息转发给 WebBrowserComponent 中的对象。

要创建中继，你需要为所中继的状态指定一个标识符。这将使一个 Javascript 对象在 WebBrowserComponent 内以提供的标识符可用。

将中继对象传给 WebBrowserComponent::Options::withOptionsFrom()，使其与 WebBrowserComponent 实例关联。

然后你可以像使用 ButtonParameterAttachment 一样使用 WebToggleButtonParameterAttachment，将中继附加到 RangedAudioParameter。这将使该 Javascript 对象的状态和事件始终与音频参数保持同步。

// Add a relay to your AudioProcessorEditor members
WebToggleButtonRelay muteToggleRelay { "muteToggle" };
WebBrowserComponent webComponent { WebBrowserComponent::Options{}::withOptionsFrom (muteToggleRelay) };
// In your Javascript GUI code you obtain an object from the framework
import * as Juce from "@juce-framework/webview";
const checkboxState = Juce.getToggleState("muteToggle");
