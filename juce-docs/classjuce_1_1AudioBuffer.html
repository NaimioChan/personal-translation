setSize()

template<typename Type> void juce::AudioBuffer < Type >::setSize (int newNumChannels, int newNumSamples, bool keepExistingContent = false, bool clearExtraSpace = false, bool avoidReallocating = false) inline

更改缓冲区的大小或通道数。

这可以扩展或收缩缓冲区的长度，并增加或删除通道。

注意，如果 keepExistingContent 和 avoidReallocating 都为 true，那么只有在通道数或采样长度都不增加时才会避免重新分配。

如果无法分配所需内存，将抛出 std::bad_alloc 异常。

参数
newNumChannels新的通道数。
newNumSamples新的采样数。
keepExistingContent如果为 true，会尽量在新缓冲区中保留旧数据。
clearExtraSpace如果为 true，则分配的额外通道或空间也会被清除。如果为 false，则这部分空间保持未初始化。
avoidReallocating如果为 true，则更改缓冲区大小不会减少当前已分配的内存量（但如果新尺寸比当前占用的更大，仍会增加）。如果为 false，则会进行新的分配，使缓冲区只占用所需的最少内存。

被以下对象引用： juce::AudioBuffer< float >::makeCopyOf()、juce::AudioBuffer< float >::operator=()。
