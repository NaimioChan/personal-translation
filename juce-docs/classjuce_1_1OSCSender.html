juce::OSCSender 类参考

详细说明

一个 OSC 消息发送器。

OSCSender 对象可以连接到某个网络端口，然后通过 UDP 套接字向指定主机发送 OSC 消息和 bundle。

connect()

bool juce::OSCSender::connect (const String & targetHostName, int targetPortNumber)

连接到数据报套接字，并准备好通过该套接字向指定目标发送 OSC 数据包。

注意：操作系统会决定将你的套接字绑定到哪些具体的网络适配器，以及发送方使用哪个本地端口。

参数
targetHostName消息将被发送到的远程主机。
targetPortNumber主机接收消息所用的远程 UDP 端口号。
返回
若连接成功则返回 true，否则返回 false。
另见
send, disconnect.
