juce::StretchableObjectResizer 类参考

详细说明

一个实用工具类，用于将一组尺寸可在最小和最大尺寸之间变化的对象适配到一个空间中。

这个算法比初看起来更棘手，因此我把它放在这个类中，以便各种代码可以共用。

要使用它，请创建一个此类对象，调用 addItem() 添加你需要的项目列表，然后调用 resizeToFit()，它会更改所有项目的尺寸。之后你可以用 getItemSize() 和 getNumItems() 获取新的尺寸。

它目前被 TableHeaderComponent 用于拉伸表头以填满表格宽度。

成员函数

addItem()

void juce::StretchableObjectResizer::addItem (double currentSize, double minSize, double maxSize, int order = 0)

向列表添加一个项目。

order 参数让你可以指定在需要腾出空间时优先调整尺寸的项目组。order 为 0 的项目将是最先被调整尺寸的；如果这仍不能提供足够的空间满足需求，算法会接着尝试调整 order 为 1 的项目，然后为 2，依此类推。

resizeToFit()

void juce::StretchableObjectResizer::resizeToFit (double targetSize)

调整所有项目的尺寸以适配此空间量。

这会尝试在不超过每个项目最小和最大尺寸的前提下适配它们。在没有任何项目可以再扩展或放大的情况下，最终尺寸可能大于或小于传入的尺寸。

调用此方法后，你可以用 getItemSize() 方法获取新的尺寸。
