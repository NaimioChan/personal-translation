juce::SerialisationTraits< T > 结构体模板参考

详细说明

template<typename T>
struct juce::SerialisationTraits< T >

允许将序列化函数附加到特定类型，而无需修改该类型的声明。

SerialisationTraits 的特化必须包含：

  • 一个名为 'marshallingVersion' 的静态 constexpr 数据成员，其值可转换为 std::optional<int>。
  • 以下之一：
    • 通常是一个具有以下签名的单一函数：
      template <typename Archive, typename Item>
static void serialise (Archive& archive, Item& item);
    • 对于在加载和保存时需要做略微不同工作的类型，你可以提供两个具有以下签名的函数，其中 "T" 是 SerialisationTraits 所特化的类型的占位符：
      template <typename Archive>
static void load (Archive& archive, T& item);

template <typename Archive>
static void save (Archive& archive, const T& item);

如果 marshallingVersion 转换为空的可选值，则在编组该类型时将忽略所有版本信息。否则，如果该值转换为非空的可选值，则会在序列化该类型时包含这些版本信息。

在 serialise() 和 load() 内部，你可以调用 archive.getVersion() 来查找被反序列化对象的检测版本。archive.getVersion() 将返回 std::optional<int>，其中 'nullopt' 表示未检测到版本信息。

编组函数也可以直接指定在要编组的类型内部。这种方式可能更可取，因为它更简洁。内部编组函数的写法与外部函数完全相同；即类型必须包含 marshallingVersion，并按上述说明包含单个 serialise 函数或 load/save 函数对。
