juce::MessageManager::Lock 类参考

详细说明

可用于锁定消息管理器的锁。

你可以将此与基于 RAII 的 ScopedLock 类一起使用。

成员函数

enter()

void juce::MessageManager::Lock::enter () const noexcept

获取消息管理器锁。

如果调用线程已独占访问 MessageManager，此方法会立即返回。如果另一个线程当前正在使用 MessageManager，它会等待该线程释放对 MessageManager 的锁。

仅当此线程获取到锁时，此调用才会退出。在线程等待 enter 完成时调用 abort 不会有任何效果。

tryEnter()

bool juce::MessageManager::Lock::tryEnter () const noexcept

尝试锁定消息管理器，如果调用了 abort 则退出。

此方法的行为与 enter 完全相同，区别在于如果调用了 abort 方法，它会中止等待锁。

与其他 JUCE 临界区不同，此方法 will 阻塞等待锁。

为确保行为可预测，如果 tryEnter 返回 false，你应重新检查中止条件。
