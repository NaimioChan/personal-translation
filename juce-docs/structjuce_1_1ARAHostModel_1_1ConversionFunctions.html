juce::ARAHostModel::ConversionFunctions< A, B > 结构体模板参考

详细说明

template<typename A, typename B>
struct juce::ARAHostModel::ConversionFunctions< A, B >

允许在两个不相关类型的指针之间进行转换而不产生警告。

这有点像 ARA_MAP_HOST_REF，但不基于宏。

要使用它，请向需要处理宿主引用的类型添加如下一行：

using Converter = ConversionFunctions<ThisType*, ARAHostRef>;

现在，你可以通过调用 Converter::toHostRef() 和 Converter::fromHostRef() 与宿主引用相互转换。
