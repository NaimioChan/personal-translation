isInterestedInTextDrag()

virtual bool juce::TextDragAndDropTarget::isInterestedInTextDrag (const String & text) pure virtual

用于检查此目标是否对所提供的文本集合感兴趣的回调。

注意，当用户在组件上方四处拖动鼠标时，此方法会被反复调用，因此不要在此处执行耗时操作！

参数
text用户正在拖动的文本
返回
如果此组件希望接收关于此类对象的其他回调，则为 true；如果返回 false，则不会再发出其他回调。

textDragEnter()

virtual void juce::TextDragAndDropTarget::textDragEnter (const String & text, int x, int y) virtual

指示有文本正被拖到此组件上方的回调。

当用户拖动时把鼠标移入此组件，会调用此项。

可将此回调作为触发点，让组件重绘，以向用户反馈文本是否可以放在此处。

参数
text用户正在拖动的文本
x鼠标 x 位置，相对于此组件
y鼠标 y 位置，相对于此组件

引用了 x、y。

textDragMove()

virtual void juce::TextDragAndDropTarget::textDragMove (const String & text, int x, int y) virtual

指示用户正在此组件上方拖动某些文本的回调。

当用户拖动时把鼠标移到此组件上方，会调用此项。通常覆盖 itemDragEnter() 和 itemDragExit() 就足够了，但此项让你了解中间发生的情况。

参数
text用户正在拖动的文本
x鼠标 x 位置，相对于此组件
y鼠标 y 位置，相对于此组件

引用了 x、y。

textDragExit()

virtual void juce::TextDragAndDropTarget::textDragExit (const String & text) virtual

回调，表示鼠标已移开该组件。

当用户在拖动文本时把鼠标移出此组件，会调用此方法。

如果你已用 textDragEnter() 重绘组件并给出反馈，可把此项作为将其重绘为正常状态的信号。

参数
text用户正在拖动的文本

textDropped()

virtual void juce::TextDragAndDropTarget::textDropped (const String & text, int x, int y) pure virtual

指示用户已将文本放到此组件上的回调。

当用户放下文本时会调用此方法，你可以按任何合适的方式使用该文本。

注意，调用此方法后可能不会调用 textDragExit，因此如果拖动结束时需要做任何清理，应在此处完成。

参数
text用户正在拖动的文本
x鼠标 x 位置，相对于此组件
y鼠标 y 位置，相对于此组件

引用了 x、y。
