juce::MouseListener 类参考

详细说明

MouseListener 可以注册到组件，以接收有关该组件上发生的鼠标事件的回调。

mouseMove()

virtual void juce::MouseListener::mouseMove (const MouseEvent & event) virtual

鼠标在组件内移动时调用。

如果鼠标按钮未按下且鼠标在组件上移动，将调用此函数让组件对此做出反应。

组件总是先收到 mouseEnter 回调，再收到 mouseMove。

参数
event有关鼠标事件位置和状态的详细信息，包括事件发生的源组件
另见
mouseEnter, mouseExit, mouseDrag, contains

在以下类中重新实现： juce::Component、juce::MenuBarComponent、juce::MidiKeyboardComponent、juce::ResizableBorderComponent、juce::Slider、juce::TableHeaderComponent。

mouseEnter()

virtual void juce::MouseListener::mouseEnter (const MouseEvent & event) virtual

鼠标首次进入组件时调用。

如果鼠标按钮未按下且鼠标移入组件，将调用此函数让组件对此做出反应。

当鼠标按钮被按住并在移入或移出组件时移动，不会产生 mouseEnter 或 mouseExit 回调 —— 只有 mouseDrag 消息会发送给鼠标最初点击的组件，直到按钮释放。

参数
event有关鼠标事件位置和状态的详细信息，包括事件发生的源组件
另见
mouseEnter, mouseExit, mouseDrag, contains

在以下类中重新实现： juce::Button、juce::Component、juce::MenuBarComponent、juce::MidiKeyboardComponent、juce::ResizableBorderComponent、juce::Slider、juce::TableHeaderComponent。

mouseExit()

virtual void juce::MouseListener::mouseExit (const MouseEvent & event) virtual

鼠标移出组件时调用。

当鼠标移出此组件边缘时将被调用。

如果鼠标按钮被按下，随后拖出组件边缘并释放，那么此回调将在按钮释放时、mouseUp 回调之后发生。

参数
event有关鼠标事件位置和状态的详细信息，包括事件发生的源组件
另见
mouseEnter, mouseExit, mouseDrag, contains

在以下类中重新实现： juce::Component、juce::MenuBarComponent、juce::MidiKeyboardComponent、juce::ResizableBorderComponent、juce::Slider、juce::TableHeaderComponent。

mouseDown()

virtual void juce::MouseListener::mouseDown (const MouseEvent & event) virtual

按下鼠标按钮时调用。

传入的 MouseEvent 对象包含许多方法，可用于查明按下了哪个按钮，以及当时按下了哪些修饰键（例如 shift、ctrl）。

按住按钮后，鼠标移动时将调用 mouseDrag 方法，直到按钮释放。

参数

mouseDrag()

virtual void juce::MouseListener::mouseDrag (const MouseEvent & event) virtual

按住按钮时移动鼠标调用。

当在组件内按下鼠标按钮时，该组件会在鼠标每次移动时收到 mouseDrag 回调，即使鼠标移出组件边界也是如此。

mouseUp()

virtual void juce::MouseListener::mouseUp (const MouseEvent & event) virtual

释放鼠标按钮时调用。

即使按钮释放时鼠标实际上位于另一个组件上，mouseUp 回调也会发送给按下按钮所在的组件。

传入的 MouseEvent 对象包含许多方法，可用于查明在按钮释放前一刻按下了哪些按钮。

mouseWheelMove()

virtual void juce::MouseListener::mouseWheelMove (const MouseEvent & event, const MouseWheelDetails & wheel) virtual

移动鼠标滚轮时调用。

当滚轮移动时，此回调会发送给鼠标所在的组件。

如果没有重写，组件会将此消息转发给其父组件，以便父组件收集发生在对其不感兴趣的子组件上的鼠标滚轮消息。

参数
event有关鼠标事件的详细信息
wheel有关滚轮移动的详细信息

在以下类中重新实现： juce::CodeEditorComponent、juce::ComboBox、juce::Component、juce::KeyboardComponentBase、juce::ListBox、juce::ScrollBar、juce::Slider、juce::TextEditor、juce::Viewport。

mouseMagnify()

virtual void juce::MouseListener::mouseMagnify (const MouseEvent & event, float scaleFactor) virtual

使用捏合缩放手势时调用。

如果没有重写，组件会将此消息转发给其父组件，以便父组件收集子组件未使用的手势消息。

参数
event有关鼠标事件的详细信息
scaleFactor一个乘数，表明目标大小应改变多少。值 1.0 表示不变，大于 1.0 表示应放大。

在以下类中重新实现： juce::Component。
