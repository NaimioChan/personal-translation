juce::Easings 结构体参考

详细说明

收录若干缓动函数，可传给 ValueAnimatorBuilder::withEasing 来变换动画的线性进程。

例如使用 createSpring() 可以把生硬的运动变成类似挂在弹簧上的重物那样的运动。

所有缓动函数的示例见 DemoRunner 中的 AnimationEasingDemo。

createEase()

std::function< float(float)> juce::Easings::createEase () static

返回缓动函数 createCubicBezier (0.25f, 0.1f, 0.25f, 1.0f)。

这表示插值开始时缓慢，随后急剧加速，最后逐渐减慢直至结束。它与 createEaseInOut() 类似，但在起始阶段的加速更急剧。

这等价于在 CSS 中指定 timing-function 时使用 "ease" 关键字。

如果未指定其他缓动函数，这就是 ValueAnimatorBuilder 类使用的默认缓动。

另见
createCubicBezier, createEaseIn, createEaseOut, createEaseInOut

createEaseOutBack()

std::function< float(float)> juce::Easings::createEaseOutBack () static

返回缓动函数 createCubicBezier (0.34f, 1.56f, 0.64f, 1.0f)。

这表示插值开始时很突然，迅速减速，随后超出目标值约 10%，再改变方向缓慢回到目标值。

与 createSpring() 一样，这会产生过冲，从而返回超过 1.0f 的 float 值。

这等价于 https://easings.net/#easeOutBack 上指定的 easeOutBack。

另见
createCubicBezier, createEaseOutBack, createSpring

createEaseInOut()

std::function< float(float)> juce::Easings::createEaseInOut () static

返回缓动函数 createCubicBezier (0.42f, 0.0f, 0.58f, 1.0f)。

这表示插值开始时缓慢，随后加速，最后逐渐减慢直至结束。在起始阶段，其行为类似 createEaseIn()；在结束阶段，其行为类似 createEaseOut()。

这等价于在 CSS 中指定 timing-function 时使用 "ease-in-out" 关键字。

createBounce()

std::function< float(float)> juce::Easings::createBounce (int numBounces = 3) static

返回一个表现得像落地弹力球的缓动函数。

该函数会在 [0, 1] 输入区间上弹跳 numBounces 次后停止，每次弹跳的幅度都比上一次小。

这等价于 https://easings.net/#easeInOutCubic 上指定的 easeInOutCubic。

createOnOffRamp()

std::function< float(float)> juce::Easings::createOnOffRamp () static

返回一个缓动函数：输入值为 0.5f 时达到 1.0f，输入值到达 1.0f 时又回到 0.0f。

这适合用来制作重复的脉动效果。
