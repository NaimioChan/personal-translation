ButtonTracker()

juce::ButtonTracker::ButtonTracker (Button & buttonToTrack, const String & triggeredEventName, const StringPairArray & triggeredEventParameters = {}, int triggeredEventType = 0)

创建其中一个对象后，相应按钮被点击时会自动把分析事件发送给 Analytics 单例。

分析事件的名称与参数由这里提供的变量填充。如果点击改变了按钮状态，参数中会追加一条 {"ButtonState", "On"/"Off"}。

参数
buttonToTrack要跟踪的按钮
triggeredEventName生成的事件的名称
triggeredEventParameters要添加到生成事件中的参数
triggeredEventType（可选）一个表示事件类型的整数，不提供时会被设为 0。
另见
Analytics, AnalyticsDestination::AnalyticsEvent
