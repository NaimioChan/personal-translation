juce::ConsoleApplication::Command 结构体参考

详细说明

表示在命令行参数匹配时可以执行的命令。

另见
ConsoleApplication::addCommand(), ConsoleApplication::findAndRunCommand()
本结构体的文档由以下文件生成：
  • juce_core/misc/juce_ConsoleApplication.h

公共属性

String commandOption
必须出现在参数列表中、此命令才会被调用的选项字符串。
String argumentDescription
此命令所需的命令行参数说明，将作为帮助文本的一部分打印。
String shortDescription
此命令的简短（一行）描述，可由 ConsoleApplication::printCommandList() 打印。
String longDescription
此命令的较长描述，用于扩展帮助。
std::function< void(const ArgumentList &)> command
应调用以执行此操作的实际命令。
