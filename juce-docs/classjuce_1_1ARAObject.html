成员函数

getNumChildren()

virtual size_t juce::ARAObject::getNumChildren () const pure virtual noexcept

返回此对象聚合的 ARA 模型对象的数量。

仅被引用但未被当前对象聚合的对象不计入此数量，例如被引用的 RegionSequence 不算作引用它的 PlaybackRegion 的子对象。

更多细节参见 ARA 文档中关于 ARA 模型图的概述。

在 juce::ARAAudioModification、juce::ARAAudioSource、juce::ARADocument、juce::ARAMusicalContext、juce::ARAPlaybackRegion 和 juce::ARARegionSequence 中实现。

被以下对象引用： traverse()。

getChild()

virtual ARAObject * juce::ARAObject::getChild (size_t index) pure virtual

返回与给定索引关联的子对象。

索引应小于 getNumChildren() 返回的值。

注意，当 ARA 模型图被编辑时，特定对象的索引可能会发生变化。

在 juce::ARAAudioModification、juce::ARAAudioSource、juce::ARADocument、juce::ARAMusicalContext、juce::ARAPlaybackRegion 和 juce::ARARegionSequence 中实现。

引用了 getChild()。

被以下对象引用： getChild()、traverse()。

getParent()

virtual ARAObject * juce::ARAObject::getParent () pure virtual

返回聚合此对象的 ARA 模型对象。

对于 ARADocument 根对象，返回 nullptr。

在 juce::ARAAudioModification、juce::ARAAudioSource、juce::ARADocument、juce::ARAMusicalContext、juce::ARAPlaybackRegion 和 juce::ARARegionSequence 中实现。

引用了 getChild()。

被以下对象引用： traverse()。

traverse()

template<typename Fn> void juce::ARAObject::traverse (Fn && fn) inline

从当前对象开始对 ARA 模型图进行深度优先遍历，并递归访问其子对象。

所提供的函数应接受一个 ARAObject& 参数。

引用了 getChild()、getNumChildren()、traverse()。

被以下对象引用： traverse()。

visit()

virtual void juce::ARAObject::visit (ARAObjectVisitor & visitor) pure virtual

允许获取模型对象的具体类型。

要使用它，请创建一个派生自 ARAObjectVisitor 的新类，并根据你关心的具体类型重写其函数。

在传给 ARAObject::traverse() 的函数内部调用此函数，可以遍历整个 ARA 模型图。

在 juce::ARAAudioModification、juce::ARAAudioSource、juce::ARADocument、juce::ARAMusicalContext、juce::ARAPlaybackRegion 和 juce::ARARegionSequence 中实现。
