appendNumbersToDuplicates()

void juce::StringArray::appendNumbersToDuplicates (bool ignoreCaseWhenComparing, bool appendNumberToFirstInstance, CharPointer_UTF8 preNumberString = CharPointer_UTF8 (nullptr), CharPointer_UTF8 postNumberString = CharPointer_UTF8 (nullptr))

向数组中的字符串添加数字，使每个字符串唯一。

这将向相似字符串组的末尾添加数字。例如如果有两个 "moose" 字符串，它们将变为 "moose (1)" 和 "moose (2)"

参数
ignoreCaseWhenComparing所用的比较是否不区分大小写
appendNumberToFirstInstance一组相似字符串中的第一个是否也追加数字。
preNumberString添加数字时，此字符串在数字之前插入。如果传入 nullptr，将使用默认字符串，即在数字外加括号。
postNumberString此字符串追加在添加的任何数字之后。如果传入 nullptr，将使用默认字符串，即在数字外加括号。

joinIntoString()

String juce::StringArray::joinIntoString (StringRef separatorString, int startIndex = 0, int numberOfElements = -1) const

将数组中的字符串连接成一个字符串。

这将把数组中的一段元素连接成字符串，用给定的字符串分隔它们。

例如 joinIntoString (",") 会将 "a" "b" 和 "c" 组成的数组变成 "a,b,c"。

参数
separatorString要在所有字符串之间插入的字符串
startIndex要连接的第一个元素

minimiseStorageOverheads()

void juce::StringArray::minimiseStorageOverheads ()

减少数组正在使用的存储量。

数组通常分配的存储略多于所需，并且在移除元素后，可能分配了相当多的未使用空间。此方法会将分配的存储量减至最少。
