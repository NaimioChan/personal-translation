juce::UnitTestRunner 类参考

详细说明

运行一组单元测试。

你可以实例化其中一个对象，并用它来对一组 UnitTest 对象调用测试。

通过使用 UnitTestRunner 的子类，你可以拦截日志消息，并在每个测试完成时执行自定义行为。

runTests()

void juce::UnitTestRunner::runTests (const Array < UnitTest * > & tests, int64 randomSeed = 0)

运行一组测试。

测试按顺序执行，结果会被记录。要运行当前存在的所有已注册 UnitTest 对象，请使用 runAllTests()。

如果你想使用预定的种子运行测试，可以将该种子传入 randomSeed 参数，或传入 0 以选择随机生成的种子。
