flexShrink

float juce::FlexItem::flexShrink = 1.0f

指定此项的 flex 收缩因子。

这表示当容器内空间不足时该项收缩的速率。

flexBasis

float juce::FlexItem::flexBasis = 0.0f

指定此项的 flex-basis 值。

这是 flex 项在流动方向上的初始主尺寸。它决定内容框的尺寸，除非通过 box-sizing 另行指定。

alignSelf

AlignSelf juce::FlexItem::alignSelf = AlignSelf::autoAlign

这是该项的 align-self 属性。

这决定该项沿交叉轴（垂直于流动方向）的对齐方式。
