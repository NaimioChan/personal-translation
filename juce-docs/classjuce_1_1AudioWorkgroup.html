juce::AudioWorkgroup 类参考

详细说明

音频工作组句柄，工作组是一组实时线程，它们协作在共同的截止时间内产生音频。

你可以用此类将实时工作线程加入某个工作组。不要直接构造此类的实例，而应使用 AudioProcessor::audioWorkgroupContextChanged() 和 AudioIODevice::getWorkgroup() 之类的函数从系统获取已启用的工作组。

此类只包含一个方法 join()。在你的实时线程中调用它即可注册此工作组。

以下是如何使用此类的一个示例：

Constructor()
{
    startRealtimeThread (Thread::RealtimeOptions{}.withApproximateAudioProcessingTime (samplesPerFrame, sampleRate));
    or
    startRealtimeThread (Thread::RealtimeOptions{}.withProcessingTimeMs (10));
}

void Thread::run() override
{
    WorkgroupToken token;

    getWorkgroup().join (token);

 while (wait (-1) && ! threadShouldExit())
    {
 // If the workgroup has changed, rejoin the workgroup with the same token.
 if (workgroupChanged())
            getWorkgroup().join (token);

 // Perform the work here
    }
}

void AudioProcessor::processBlock()
{
    workerThread->notify();
}

join()

void juce::AudioWorkgroup::join (WorkgroupToken & token) const

此方法尝试将调用线程加入此工作组。

如果加入操作成功，令牌将被启用，即其 getTokenProvider() 函数将返回非空。

如果令牌已启用且代表对另一个工作组的加入，线程会在加入此对象所代表的工作组之前离开那个工作组。如果 'token' 已启用并且传入的是同一个工作组，此方法不会执行任何操作。

请务必注意，令牌的生命周期不应超过相关线程的生命周期，并且必须在同一线程上销毁。

getMaxParallelThreadCount()

size_t juce::AudioWorkgroup::getMaxParallelThreadCount () const

返回建议加入此工作组的最多并行线程数。

此建议基于工作组属性和当前硬件，而非系统负载。在非常繁忙的系统上，使用更少的并行线程可能更有效。
