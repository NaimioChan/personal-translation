mouseWasDraggedSinceMouseDown()

bool juce::MouseEvent::mouseWasDraggedSinceMouseDown () const noexcept

如果用户看起来正在执行拖动手势，则返回 true。

只有在 mouseUp() 或 mouseDrag() 方法中调用时才有意义。

如果用户将鼠标从 mouse-down 发生的位置拖动了超过几个像素，或者鼠标已被按住相当长的时间，则返回 true。

一旦拖动得足够远使此方法返回 true，它就会一直返回 true 直到 mouse-up，即使用户将鼠标移回 mouse-down 发生的位置也是如此。这意味着它对于既可点击又可拖动的对象非常有用，因为你可以在 mouseDrag() 回调中使用它来忽略用户尝试点击时可能产生的小幅移动。

引用了 MouseEvent()。

被以下对象引用： getMouseDownY()。

Component * const juce::MouseEvent::eventComponent

此事件所应用于的组件。
