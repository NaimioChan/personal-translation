juce::universal_midi_packets::Output 类参考

详细说明

一个输出（从 JUCE 项目的角度看），用于向端点发送消息。

Output 在概念上类似于 unique_ptr，因为它是可为空的、仅可移动的类型。你可以通过调用 isAlive() 检查实例是否为空。对于当前已连接的 Output，isAlive() 将返回 true，否则返回 false。特别地，对于默认构造的 Output，isAlive() 将返回 false。如果 isAlive() 返回 false，你应避免调用其它成员函数：虽然这不会导致未定义行为，但在此状态下没有任何函数会产生有用的结果。

如果连接到 Output 的设备变得不可用（例如被拔出或蓝牙连接断开），Output 会将自身置空，对 isAlive() 的调用将返回 false。你可以通过调用 addDisconnectionListener() 注册回调来处理此事件。

需要特别留意的一个陷阱是：对默认构造的 Output 或 isAlive() 返回 false 的其它 Output 调用 addDisconnectionListener() 和 removeDisconnectionListener()。这不会产生任何效果。相反，如果你想向 Output 附加监听器，应使用 Session::connectOutput() 创建一个 Output，并确保该 Output 上的 isAlive() 返回 true 之后再附加监听器。
