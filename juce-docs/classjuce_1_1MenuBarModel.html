void juce::MenuBarModel::menuItemsChanged ()

当你的一些菜单项发生更改时调用此函数。

此方法会向注册到此模型的任何 MenuBarListener 对象触发回调。

如果此模型正在显示来自 ApplicationCommandManager 的项，你可以使用 setApplicationCommandManagerToWatch() 方法，使 ApplicationCommandManager 更改时自动发送更改消息。

setMacMainMenu()

void juce::MenuBarModel::setMacMainMenu (MenuBarModel * newMenuBarModel, const PopupMenu * extraAppleMenuItems = nullptr, const String & recentItemsMenuName = String ()) static

仅 OSX —— 设置当前在 Mac 屏幕顶部作为主菜单栏显示的模型。

你可以传入 nullptr 以停止显示当前模型。注意不要在使用模型时删除它。

可以指定一个可选的额外菜单，其中包含要添加到 Apple 菜单顶部的项。（令人困惑的是，'apple' 菜单并不是那个画着苹果图标的菜单，而是它旁边的那个，顶部是你应用程序的名称，还有服务菜单等）。当选中其中一项时，将使用菜单栏模型来调用它，并且在 menuItemSelected() 回调中，topLevelMenuIndex 参数将为 -1。如果你传入 extraAppleMenuItems 对象，则 newMenuBarModel 必须非空。

如果 recentItemsMenuName 参数非空，则任何具有此名称的子菜单都将被 OSX 的特殊最近文件菜单替换。

引用了 MenuBarModel()。
