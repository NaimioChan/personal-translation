juce::MPESynthesiser 类参考

详细说明

可演奏声音的 MPE 兼容音乐设备的基类。

此类扩展了 MPESynthesiserBase，增加了发声单元的概念：每个发声单元可以演奏由 MPENote 触发的声音，并在音符发声期间由压力、弯音和音色等 MPE 维度调制。

要创建合成器，你需要创建 MPESynthesiserVoice 的子类，它能够一次回放其中一个声音。

然后你可以使用 addVoice() 方法为合成器提供一组可用于演奏音符的发声单元。如果只给它一个发声单元，它就是单音的——发声单元越多，可用的复音数就越多。

然后反复调用 renderNextBlock() 方法产生音频（继承自 MPESynthesiserBase）。发声单元会根据合成器收到的 MPE/MIDI 消息自动启动、停止和调制。

渲染之前，务必调用 setCurrentPlaybackSampleRate() 告知其目标播放速率。该值会传递给各发声单元，以便它们正确地为输出定音。

turnOffAllVoices()

virtual void juce::MPESynthesiser::turnOffAllVoices (bool allowTailOff) virtual

释放所有 MPE 音符并关闭所有发声单元。

如果 allowTailOff 为 true，则允许各声部优雅地淡出音符（如果它们能做到）。如果为 false，所有音符会被立即切断。

本方法意在由用户调用，例如在合成器中实现一个 MIDI 紧急停止按钮。

handleMidiEvent()

void juce::MPESynthesiser::handleMidiEvent (const MidiMessage &) override virtual

处理传入的 MIDI 事件。

本方法会根据传入 renderNextBlock() 的 MIDI 数据自动被调用，但你也可以自行调用它来手动注入 MIDI 事件。

该实现把程序变更消息和非 MPE 相关的控制器消息分别转发给 handleProgramChange 和 handleController，然后直接调用 MPESynthesiserBase::handleMidiEvent 来处理用于 MPE 音符、区域等的 MPE 相关 MIDI 消息。

如果在此处提供的内容之上还需要自定义 MIDI 处理，你可以进一步覆写本方法。

重新实现自 juce::MPESynthesiserBase。

noteAdded()

void juce::MPESynthesiser::noteAdded (MPENote newNote) override protected virtual

尝试开始演奏一个新音符。

此处的默认方法会找到一个适合演奏给定 MPENote 的空闲声部，并用该声部开始发声。如果 isNoteStealingEnabled 返回 true（通过调用 setNoteStealingEnabled 设置），合成器将使用声部抢占算法为该音符寻找空闲声部（前提是本来没有空闲声部）。

本方法会根据传入 renderNextBlock() 的 MIDI 数据自动被调用。不要自行调用它，否则内部 MPE 音符状态会变得不一致。

重新实现自 juce::MPESynthesiserBase。

noteReleased()

void juce::MPESynthesiser::noteReleased (MPENote finishedNote) override protected virtual

停止演奏某个音符。

每当一个 MPE 音符被释放时（通过 note-off 消息，或对已收到 note-off 的音符释放延音/持音踏板），都会调用它，因此它应当停止发声。

这会找到任何正在演奏 finishedNote 的声部，关闭其当前演奏的音符，并调用它的 noteStopped 回调。

本方法会根据传入 renderNextBlock() 的 MIDI 数据自动被调用。不要自行调用它，否则内部 MPE 音符状态会变得不一致。

重新实现自 juce::MPESynthesiserBase。

findFreeVoice()

virtual MPESynthesiserVoice * juce::MPESynthesiser::findFreeVoice (MPENote noteToFindVoiceFor, bool stealIfNoneAvailable) const protected virtual

在各个发声单元中搜索，找出当前未在演奏、且能演奏给定 MPE 音符的发声单元。

如果所有声部都处于活动状态且 stealIfNoneAvailable 为 false，则返回 nullptr。如果所有声部都处于活动状态且 stealIfNoneAvailable 为 true，则会调用 findVoiceToSteal() 来找一个声部。

如果你找空闲声部不是为了演奏音符（例如为了删除它），可以传入一个无效的（默认构造的）MPENote。

findVoiceToSteal()

virtual MPESynthesiserVoice * juce::MPESynthesiser::findVoiceToSteal (MPENote noteToStealVoiceFor = MPENote ()) const protected virtual

选择一个最适合被复用来演奏新音符、或最适合由 reduceNumVoices 删除的发声单元。

默认方法会尝试找到最旧的、且不是正在演奏的最低或最高音符的声部。如果这不适合你的合成器，可以覆写本方法，改用更巧妙的方式。

如果你为可选参数传入有效的 MPENote，则在寻找理想的抢占声部时会考虑该音符的音符编号。如果你改为传入无效的（默认构造的）MPENote，算法的这一部分将被忽略。
