juce::AppleRemoteDevice 类参考

详细说明

接收来自 Apple 红外遥控设备的事件（仅在 OSX 上可用！）。

要使用它，只需创建此类的一个子类，实现 buttonPressed() 回调，然后调用 start() 和 stop() 来开始或停止接收事件。

本类的文档由以下文件生成：

buttonPressed()

virtual void juce::AppleRemoteDevice::buttonPressed (ButtonType buttonId, bool isDown) pure virtual

重写此方法以接收按钮按下的回调。

回调将在应用的消息线程上发生。

有些按钮会触发配对的按下和抬起事件，其中 isDown 参数会先为 true，然后为 false。其他按钮只在按下时发送单个事件。

start()

bool juce::AppleRemoteDevice::start (bool inExclusiveMode)

启动设备，使其运行并响应事件。

参数
inExclusiveMode如果为 true，遥控器将由此应用独占，系统中的其他部分将无法使用。如果为 false，它将与其他应用共享。
