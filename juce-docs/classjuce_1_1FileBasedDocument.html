juce::FileBasedDocument 类参考

详细说明

用于处理某种文档的加载/保存逻辑的类。

编写保存到文件的文档所需的所有加载/保存/另存为函数涉及大量繁琐的逻辑，因此此类试图抽象掉大部分无聊的部分。

你的子类只需实现所有纯虚方法，然后就可以使用更高级的公共方法来执行加载/保存对话框、警告用户覆盖文件等操作。

该文档对象会跟踪自上次保存或加载以来是否发生变化，因此当你做了一些更改时，应调用其 changed() 方法。这会设置一个标志，让它知道自己需要保存，并且还会使用 ChangeBroadcaster 基类广播一条变更消息。

saveIfNeededAndUserAgrees()

SaveResult juce::FileBasedDocument::saveIfNeededAndUserAgrees ()

如果文件需要保存，它会询问用户是否要保存，并在用户同意时保存。

如果你有一个已打开的文档并想关闭它（例如退出应用），这就是应调用的方法。

如果文档不需要保存，它将返回 savedOk，你可以继续删除文档。

如果确实需要保存，它会提示用户；如果用户说“放弃更改”，它将返回 savedOk，因此你同样可以安全地删除文档。

如果用户点击“取消”，它将返回 userCancelledSave，因此你可以中止关闭文档的操作。

如果他们点击“保存更改”，它将尝试保存，并返回 savedOk，如果有问题则返回 failedToWriteToFile。

另见
save, saveAs, saveAsInteractive

loadDocumentAsync()

virtual void juce::FileBasedDocument::loadDocumentAsync (const File & file, std::function< void(Result)> callback) protected virtual

此方法应尝试从给定文件加载你的文档，然后在消息线程上调用提供的回调，并传入加载结果。

对于耗时较长的加载操作，你可能希望重写此函数，在后台线程上执行加载，然后在消息线程上稍后调用回调以表示加载已完成。
