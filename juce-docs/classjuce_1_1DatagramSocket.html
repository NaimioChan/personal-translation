juce::DatagramSocket 类参考

详细说明

数据报（UDP）套接字的封装。

这允许对套接字进行底层使用；如需在套接字之上使用更易用的消息传递层，你还可以试试 InterprocessConnection 类。

另见
StreamingSocket, InterprocessConnection, InterprocessConnectionServer

juce::DatagramSocket::DatagramSocket (bool enableBroadcasting, const SocketOptions & optionsIn)

创建数据报套接字，并允许指定与底层套接字配置相关的选项。

如果你打算从此套接字读取，首先需要用 bindToPort 将其绑定到端口。

如果 enableBroadcasting 为 true，则允许套接字发送广播消息（在 linux 上可能需要额外权限）

bool juce::DatagramSocket::bindToPort (int localPortNumber, const String & localAddress)

将套接字绑定到指定的本地端口和本地地址。

如果 localAddress 不是空字符串，则套接字也将绑定到 localAddress。如果你想将套接字绑定到特定的网络适配器，这会很有用。注意，localAddress 必须是分配给你的某个网络地址的 IP 地址，否则此函数将失败。

返回
成功时返回 true；false 可能表示另一个套接字已绑定到同一端口

waitUntilReady()

int juce::DatagramSocket::waitUntilReady (bool readyForReading, int timeoutMsecs)

等待直到套接字可读或可写。

如果 readyForReading 为 true，它将等待直到套接字可读；如果为 false，则等待直到其可写。

如果超时小于 0，将永远等待，否则在指定时间后放弃。

返回
返回时如果套接字已就绪则返回 1，如果在套接字就绪之前超时则返回 0，如果发生错误则返回 -1

shutdown()

void juce::DatagramSocket::shutdown ()

关闭底层套接字对象。

关闭底层套接字对象并中止任何读或写操作。注意，此后所有其他方法都将返回错误，且该对象不能重复使用。

如果另一个线程正阻塞在读/写调用中，而你希望中止该读/写线程，此方法会很有用。仅在不调用 shutdown 的情况下删除套接字对象，可能导致竞态条件：读/写在套接字被删除前刚刚返回，随后的读/写会试图从无效指针读取。先调用 shutdown，套接字对象仍然有效，但所有当前及后续的读/写调用都会立即返回。

setEnablePortReuse()

bool juce::DatagramSocket::setEnablePortReuse (bool enabled)

允许其他应用程序复用该端口。

允许当前运行的任何其他应用程序绑定到同一端口。如果你的套接字处理敏感数据，请勿使用此选项，因为任何（可能是恶意的）第三方应用都可能读取这些数据。
