juce::OnlineUnlockStatus 类参考

详细说明

在线解锁系统的基类。

此类保存关于你的应用是否已针对当前机器解锁的信息，并处理与网上商店的通信以执行解锁流程。

你大概不会直接使用这个基类，而是使用特定商店的子类，例如 TracktionMarketplaceStatus，它知道如何与你所用的那个在线商店通信。

要使用它，你需要创建一个子类，实现所有纯虚方法（参见这些方法的注释，了解需要它们做什么）。

然后你可以创建子类的实例，它将保存注册状态。通常你会希望在应用运行期间只保留该类的一个实例，然后调用其方法来处理各种注册任务。

代码中需要知道用户是否已注册的部分（例如用于决定某个功能是否可用）应调用 isUnlocked() 来查询。

如果你想创建一个让用户输入详细信息并注册的图形界面，参见 OnlineUnlockForm 类。

isUnlocked()

var juce::OnlineUnlockStatus::isUnlocked () const inline

若产品已成功为此机器授权则返回 true。

它返回 variant 而不是 bool，只是为了稍微增加破解者的麻烦。希望如果此方法被内联，他们就得改动所有调用它的位置，而不只是函数本身。

请记住，破解者需要修改你检查此返回值的每一处才能解锁你的应用，因此你调用此方法的地方越多，他们找到并全部破解就越麻烦。

attemptWebserverUnlock()

UnlockResult juce::OnlineUnlockStatus::attemptWebserverUnlock (const String & email, const String & password)

联系 Web 服务器，并尝试用给定的用户详细信息执行注册。

返回值要么是成功，要么是带有服务器错误信息的失败，因此你应向用户显示该信息。

由于此方法在联系服务器时会阻塞，你必须在后台线程上运行它，而不是在消息线程上。要更轻松地创建用于解锁的图形界面，参见 OnlineUnlockForm。
