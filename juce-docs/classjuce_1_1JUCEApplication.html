juce::JUCEApplication 类参考

详细说明

此类的一个实例用于指定应用程序的初始化和关闭代码。

任何想要运行事件循环的应用程序都必须声明 JUCEApplicationBase 或 JUCEApplication 的子类，并实现其各种纯虚方法。

然后需要在某个 CPP 文件中使用 START_JUCE_APPLICATION 宏来声明该类的实例，并生成合适的平台特定样板代码来启动应用。

注意，此类派生自 JUCEApplicationBase，其中包含大部分有用的方法和功能。这个派生类在这里只是为了方便同时继承 ApplicationCommandTarget，并为一些纯虚基类方法提供默认实现。但你也可以直接从 JUCEApplicationBase 派生你的应用对象，这样做可以避免依赖 juce_gui_basics 模块。

例如

class MyJUCEApp  : public JUCEApplication
{
public:
    MyJUCEApp()  {}
    ~MyJUCEApp() {}

 void initialise (const String& commandLine) override
 {
        myMainWindow.reset (new MyApplicationWindow());
        myMainWindow->setBounds (100, 100, 400, 500);
        myMainWindow->setVisible (true);
    }

 void shutdown() override
 {
        myMainWindow = nullptr;
    }

 const String getApplicationName() override
 {
 return "Super JUCE-o-matic";
    }

 const String getApplicationVersion() override
 {
 return "1.0";
    }

private:
    std::unique_ptr<MyApplicationWindow> myMainWindow;
};

// this generates boilerplate code to launch our app class:
START_JUCE_APPLICATION (MyJUCEApp)

moreThanOneInstanceAllowed()

bool juce::JUCEApplication::moreThanOneInstanceAllowed () override virtual

检查是否允许多个应用实例。

如果你的应用类对此返回 true，则允许运行多个实例（OSX 除外，在那里操作系统会自动阻止你启动应用的第二个实例，除非从命令行显式启动）。

如果为 false，第二个实例将不会启动，但你仍会收到对 anotherInstanceStarted() 的回调来告知此事——这让你有机会对用户尝试的操作做出响应。

实现 juce::JUCEApplicationBase。

systemRequestedQuit()

void juce::JUCEApplication::systemRequestedQuit () override virtual

在操作系统尝试关闭应用时调用。

该方法的默认实现是调用 quit()，但可以重载它以忽略请求或改为执行其他特殊行为。例如，你可能想在退出前让用户有机会保存更改，并让他们有机会取消。

如果你想向应用发送退出信号，这是应调用的正确方法，因为这意味着来自系统的请求会与你自己的应用代码发出的请求以相同方式处理。例如，你会从菜单栏的“退出”项调用该方法。

getCommandInfo()

void juce::JUCEApplication::getCommandInfo (CommandID commandID, ApplicationCommandInfo & result) override virtual

这必须提供此目标能执行的某个命令的详细信息。

这会以目标在其 getAllCommands() 方法中提供的某个命令 ID 被调用。

它应使用关于命令的合适信息填充 ApplicationCommandInfo 结构的所有相应字段。（commandID 字段已由调用者填充。）

设置信息最简单的方法是使用 ApplicationCommandInfo::setInfo() 方法一次性设置所有字段。

如果命令当前因某种原因处于非激活状态，此方法必须使用 ApplicationCommandInfo::setActive() 明确这一点（或设置 ApplicationCommandInfo::flags 字段的 isDisabled 位）。

命令的任何默认按键都应附加到 ApplicationCommandInfo::defaultKeypresses 字段。

注意，如果你更改了会影响此方法返回的命令状态的内容（例如使某些命令变为激活或非激活），应调用 ApplicationCommandManager::commandStatusChanged() 使管理器刷新其状态。

实现 juce::JUCEApplicationBase。

perform()

bool juce::JUCEApplication::perform (const InvocationInfo & info) override virtual

这必须实际执行指定命令。

如果此目标能执行 InvocationInfo 结构的 commandID 字段指定的命令，则应执行它，并且必须返回 true。

如果它无法处理此命令，应返回 false，告知调用者将命令传递给链上的下一个目标。
