juce::OutputStream 类参考

详细说明

将数据写入某种目标的流的基类。

整个库都使用输入流和输出流——子类可以重写部分或全部虚函数来实现其行为。

另见
InputStream, MemoryOutputStream, FileOutputStream

writeCompressedInt()

virtual bool juce::OutputStream::writeCompressedInt (int value) virtual

写入一个 32 位整数的紧凑二进制编码。

如果你要存储大量不太可能出现极大值的整数，这可以节省大量空间，因为小于 0xff 的值只占 2 个字节，小于 0xffff 的只占 3 个字节，依此类推。

使用的格式是：有效字节数 + 最多 4 个字节（小端顺序）。

返回
如果写入操作因某种原因失败，则为 false
另见
InputStream::readCompressedInt

writeString()

virtual bool juce::OutputStream::writeString (const String & text) virtual

以二进制格式将字符串存储到流中。

如果你想向文本文件末尾追加文本，这不是该用的方法！它是用来存储字符串，以便之后通过 InputStream::readString() 取回。

它以 UTF8 将字符串写入流，包括空终止字符。

若要向文件追加文本，请改用 writeText 或 operator<<

返回
如果写入操作因某种原因失败，则为 false
另见
InputStream::readString, writeText, operator<<

writeText()

virtual bool juce::OutputStream::writeText (const String & text, bool asUTF16, bool writeUTF16ByteOrderMark, const char * lineEndings) virtual

向流中写入一段文本字符串。

它可以将文本写为 UTF-8 或 UTF-16，也可以添加 UTF-16 字节序标记字节（0xff、0xfe）以指示字节序（这些只应在文件开头使用）。

如果 lineEndings 为 nullptr，则文本中的行结束符不会被修改。如果你传入 "\\n" 或 "\\r\\n"，则此函数将替换任何现有的换行符。

返回
如果写入操作因某种原因失败，则为 false
