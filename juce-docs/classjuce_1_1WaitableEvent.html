juce::WaitableEvent 类参考

详细说明

允许线程等待其他线程触发的事件。

线程可以调用 WaitableEvent::wait() 挂起调用线程，直到另一个线程通过调用 WaitableEvent::signal() 方法将其唤醒。

WaitableEvent()

juce::WaitableEvent::WaitableEvent (bool manualReset = false) explicit noexcept

创建一个 WaitableEvent 对象。

该对象最初处于未触发状态。

参数
manualReset如果为 false，则在调用 wait() 方法时会自动重置事件。如果 manualReset 为 true，则一旦事件被触发，唯一的重置方式就是调用 reset() 方法。

成员函数

wait() [1/3]

bool juce::WaitableEvent::wait (Seconds timeOut) const

挂起调用线程，直到事件被触发。

这会一直等待，直到另一个线程调用该对象的 signal() 方法，或超时。

事件被触发后，此方法将返回 true；如果在 WaitableEvent 的构造函数中将 manualReset 设为 false，则事件将被重置。

与 wait (double) 不同，不支持负超时，否则会触发断言。要无限期等待，请不带参数调用 wait()。

参数
timeOut最长等待时间。不得为负数。
返回
如果对象已被触发则返回 true，如果先超时则返回 false。
另见
signal, reset

signal()

void juce::WaitableEvent::signal () const

唤醒当前正在等待此对象的所有线程。

如果在没有线程等待时调用 signal()，则下一个调用 wait() 的线程将立即返回并重置信号。

如果 WaitableEvent 是手动重置的，则所有当前和将来等待此对象的线程都会被唤醒，直到显式调用 reset()。

如果 WaitableEvent 是自动重置的，并且有一个或多个线程正在等待该对象，则其中一个会被唤醒。如果当前没有线程等待，则下一个调用 wait() 的线程将被唤醒。线程一旦被唤醒，信号就会自动重置。
