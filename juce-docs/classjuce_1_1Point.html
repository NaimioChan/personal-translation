详细说明

template<typename ValueType>
class juce::Point< ValueType >

一对 (x, y) 坐标。

ValueType 模板应是 int、float、double 之类的基元类型，而不是类。

另见
Line, Path, AffineTransform

getAngleToPoint()

template<typename ValueType> FloatType juce::Point < ValueType >::getAngleToPoint (Point < ValueType > other) const inline noexcept

返回从此点到另一个点的角度。

把此点视为圆心、另一个点视为圆周上的位置，返回值是从 12 点方向起顺时针计的弧度数。因此 12 点 = 0，3 点 = Pi/2，6 点 = Pi，9 点 = -Pi/2

引用了 juce::juce_isfinite()、x、y。
