EdgeTable() [1/5]

juce::EdgeTable::EdgeTable (Rectangle < int > clipLimits, const Path & pathToAdd, const AffineTransform & transform)

创建包含一条路径的边表。

表以固定的垂直范围创建，只有位于该范围内的路径部分才会被加入表中。

参数
clipLimits只有位于此区域内的路径部分才会被添加
pathToAdd要加入表的路径
transform应用于所添加路径的变换

被以下对象引用： clipToEdgeTable()。

optimiseTable()

void juce::EdgeTable::optimiseTable ()

减少表已分配的空间量。

这会将表缩小到占用尽可能少的内存——对于需要存储并重复用于渲染的只读表很有用。

iterate()

template<class EdgeTableIterationCallback> void juce::EdgeTable::iterate (EdgeTableIterationCallback & iterationCallback) const inline noexcept

遍历表中的线，用于渲染。

此函数会遍历表中的每条线，并调用用户定义的类来渲染表中包含的每个像素或连续像素段。

参数
iterationCallback此模板类必须包含以下方法：
inline void setEdgeTableYPos (int y);
inline void handleEdgeTablePixel (int x, int alphaLevel) const;
inline void handleEdgeTablePixelFull (int x) const;
inline void handleEdgeTableLine (int x, int width, int alphaLevel) const;
inline void handleEdgeTableLineFull (int x, int width) const;
（这些方法不必是 'const'，但那样可能有助于提速）

引用了 juce::isPositiveAndBelow()、jassert、x、y。
