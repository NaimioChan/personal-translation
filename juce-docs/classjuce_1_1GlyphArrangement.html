juce::GlyphArrangement 类参考

详细说明

一组字形，每个字形带有一个位置。

你可以创建一个 GlyphArrangement，向其中添加文本，然后将其绘制到图形上下文中。Graphics 类的文本方法内部会使用它，但如果需要更多控制，也可以直接使用。

Font, PositionedGlyph

void juce::GlyphArrangement::addLineOfText (const Font & font, const String & text, float x, float y)

向排列追加一行文本。

void juce::GlyphArrangement::addCurtailedLineOfText (const Font & font, const String & text, float x, float y, float maxWidthPixels, bool useEllipsis)

添加一行文本，如果宽度超过指定大小则截断。

这与 addLineOfText() 相同，但如果该行的宽度超过 maxWidthPixels 中指定的值，则会被截断：若 useEllipsis 为 true，使用省略号（即点号 "..."）；若为 false，则直接丢弃后续字符。

addJustifiedText()

void juce::GlyphArrangement::addJustifiedText (const Font & font, const String & text, float x, float y, float maxLineWidth, Justification horizontalLayout, float leading = 0.0f)

添加一些多行文本，如果过宽则在单词边界处换行。

这会将文本添加到排列中，在文本中出现换行或回车字符处，或行的宽度超过 maxLineWidth 中设置的值处，将其分成新行。

添加的每一行都会按 horizontalLayout 中设置的标志进行布局，因此各行可以在 x 与（x + maxLineWidth）之间的空间内左对齐、右对齐或水平居中。

y 坐标是第一行文本基线的位置——后续各行将放在其下方，间隔为 font.getHeight() + leading。

引用了 x、y。

addFittedText()

void juce::GlyphArrangement::addFittedText (const Font & font, const String & text, float x, float y, float width, float height, Justification layout, int maximumLinesToUse, float minimumHorizontalScale = 0.0f, GlyphArrangementOptions options = {})

尝试将一些文本放入给定的空间。

它会尽力让给定文本在指定矩形内可读，因此很适合用于给东西加标签。

如果文本太大，它会水平压缩，或者在 maximumLinesToUse 允许的情况下分成多行。如果文本实在放不进该空间，它会尽可能多地塞进去，并在末尾加上省略号表示已被截断。

Justification 参数让你指定文本在矩形内如何布局，包括水平和垂直方向。

minimumHorizontalScale 参数指定文本可以水平压缩多少以挤进空间。如果你不希望发生任何水平缩放，可将此值设为 1.0f。若想使用默认值，传 0。
