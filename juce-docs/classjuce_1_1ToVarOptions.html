withExplicitVersion()

ToVarOptions juce::ToVarOptions::withExplicitVersion (std::optional< int > x) const inline nodiscard

默认情况下，转换将使用为该类型定义的 marshallingVersion 序列化该类型。

设置显式版本允许将该类型序列化为较早的版本。

引用了 juce::withMember()、x。

withVersionIncluded()

ToVarOptions juce::ToVarOptions::withVersionIncluded (bool x) const inline nodiscard

默认情况下，对于任何 marshallingVersion 非空的类型，转换将包含版本信息。

将 versionIncluded 设为 false 将导致省略版本信息，这在不需要版本信息的情况下很有用（例如向用户呈现临时信息，而不是写入将来必须反序列化的磁盘数据）。

引用了 juce::withMember()、x。
