juce::AudioProcessorParameter::Listener 类参考

详细说明

希望了解 AudioProcessorParameter 更改的监听器的基类。

使用 AudioProcessorParameter::addListener() 将你的监听器注册到 AudioProcessorParameter。

此 Listener 取代了 AudioProcessorListener 类的大部分功能，后者将被废弃并移除。

parameterValueChanged()

virtual void juce::AudioProcessorParameter::Listener::parameterValueChanged (int parameterIndex, float newValue) pure virtual

当参数已更改时接收回调。

重要提示：这将在参数变化时同步调用，而许多音频处理器会在音频回调期间更改其参数。这意味着你的处理程序代码不仅要完全线程安全，还必须非常快并避免阻塞。如果你需要在消息线程上处理此事件，请使用此回调触发 AsyncUpdater 或 ChangeBroadcaster，然后在消息线程上响应。
