成员函数

loadImage()

void juce::OpenGLTexture::loadImage (const Image & image)

从给定图像创建纹理。

注意，如果图像的尺寸不是 2 的幂，创建的纹理可能更大。

图像将被安排为其左上角位于纹理坐标 (0, 1)。

必须在存在当前上下文时调用。如果没有当前上下文，此函数不做任何事，纹理保持不变。

loadARGB()

void juce::OpenGLTexture::loadARGB (const PixelARGB * pixels, int width, int height)

从原始像素数组创建纹理。

如果 width 和 height 不是 2 的幂，纹理将以更大的尺寸创建，并且只初始化子区域 (0, 0, width, height)。数据直接发送到 OpenGL 驱动而不进行垂直翻转，因此第一个像素将映射到纹理坐标 (0, 0)。

必须在存在当前上下文时调用。如果没有当前上下文，此函数不做任何事，纹理保持不变。

loadARGBFlipped()

void juce::OpenGLTexture::loadARGBFlipped (const PixelARGB * pixels, int width, int height)

从原始像素数组创建纹理。

与 loadARGB 类似，但会垂直翻转数据，使第一个像素落在纹理坐标 (0, 1)；如果 width 和 height 不是 2 的幂，则通过使用更大的纹理尺寸来补偿。

必须在存在当前上下文时调用。如果没有当前上下文，此函数不做任何事，纹理保持不变。

loadAlpha()

void juce::OpenGLTexture::loadAlpha (const uint8 * pixels, int width, int height)

从 alpha 值数组创建 alpha 通道纹理。

如果 width 和 height 不是 2 的幂，纹理将以更大的尺寸创建，并且只初始化子区域 (0, 0, width, height)。数据直接发送到 OpenGL 驱动而不进行垂直翻转，因此第一个像素将映射到纹理坐标 (0, 0)。

必须在存在当前上下文时调用。如果没有当前上下文，此函数不做任何事，纹理保持不变。

release()

void juce::OpenGLTexture::release ()

如果存在纹理，则释放它。

纹理只能在创建它的上下文为当前上下文时释放。如果当前是其他上下文，此函数会触发断言，纹理将泄漏，直到创建它的上下文被销毁。
