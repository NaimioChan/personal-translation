getNumChildren()

size_t juce::ARARegionSequence::getNumChildren () const override virtual noexcept

返回此对象聚合的 ARA 模型对象的数量。

仅被引用但未被当前对象聚合的对象不计入此数量，例如被引用的 RegionSequence 不算作引用它的 PlaybackRegion 的子对象。

更多细节参见 ARA 文档中关于 ARA 模型图的概述。

实现 juce::ARAObject。

visit()

void juce::ARARegionSequence::visit (ARAObjectVisitor & visitor) inline override virtual

允许获取模型对象的具体类型。

要使用它，请创建一个派生自 ARAObjectVisitor 的新类，并根据你关心的具体类型重写其函数。

在传给 ARAObject::traverse() 的函数内部调用此函数，可以遍历整个 ARA 模型图。

实现 juce::ARAObject。

引用了 getChild()。

getTimeRange()

Range < double > juce::ARARegionSequence::getTimeRange (ARAPlaybackRegion::IncludeHeadAndTail includeHeadAndTail = ARAPlaybackRegion::IncludeHeadAndTail::no) const

返回此序列中各区域所覆盖的播放时间范围。

参数
includeHeadAndTail该范围是否包含播放区域的头部和尾部时间。

getCommonSampleRate()

double juce::ARARegionSequence::getCommonSampleRate () const

如果此区域序列中播放区域所使用的所有音频源采样率相同，则在此返回该采样率，否则返回 0.0。

如果区域序列没有播放区域，此函数也会返回 0.0。
