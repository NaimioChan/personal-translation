formatted()

String juce::Time::formatted (const String & format) const

将此日期/时间转换为用户自定义格式的字符串。

此方法使用 C 的 strftime() 函数将时间格式化为字符串。为免你查阅，以下是 strftime 使用的转义码（其他码在某些平台上可能有效，在其他平台上则无效，但这些是常见的）：

  • a 替换为区域设置的缩写星期名。
  • A 替换为区域设置的完整星期名。
  • b 替换为区域设置的缩写月份名。
  • B 替换为区域设置的完整月份名。
  • c 替换为区域设置适当的日期和时间表示。
  • d 替换为月中的日，十进制数 [01,31]。
  • H 替换为小时（24 小时制），十进制数 [00,23]。
  • I 替换为小时（12 小时制），十进制数 [01,12]。
  • j 替换为年中的第几天，十进制数 [001,366]。
  • m 替换为月份，十进制数 [01,12]。
  • M 替换为分钟，十进制数 [00,59]。
  • p 替换为区域设置对应的 a.m. 或 p.m.。
  • S 替换为秒，十进制数 [00,60]。
  • U 替换为年中的周数（星期日为一周的第一天），十进制数 [00,53]。
  • w 替换为星期几，十进制数 [0,6]，0 表示星期日。
  • W 替换为年中的周数（星期一为一周的第一天），十进制数 [00,53]。新年中第一个星期一之前的所有日子都视为第 0 周。
  • x 替换为区域设置适当的日期表示。
  • X 替换为区域设置适当的时间表示。
  • y 替换为不含世纪的年份，十进制数 [00,99]。
  • Y 替换为含世纪的年份，十进制数。
  • Z 替换为时区名称或缩写，若不存在时区信息则替换为空。
  • %% 替换为 %。

getMillisecondCounter()

uint32 juce::Time::getMillisecondCounter () static noexcept

返回自某个固定事件（通常是系统启动）以来的毫秒数。

这会返回一个单调递增的值，不受系统时钟变化的影响。根据平台、硬件等因素，误差应在几毫秒之内。

由于是 32 位返回值，在运行 2^32 秒后自然会回绕到 0，因此要注意考虑到这一点。如果你需要 64 位时间，可以改用 currentTimeMillis()。
