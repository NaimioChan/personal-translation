juce::GenericScopedLock< LockType > 类模板参考

详细说明

template<class LockType>
class juce::GenericScopedLock< LockType >

自动加锁和解锁互斥量对象。

将其之一用作局部变量，以提供基于 RAII 的互斥量加锁。

模板化类可以是 CriticalSection、SpinLock，或任何其他提供 enter() 和 exit() 方法的类。

例如

CriticalSection myCriticalSection;

for (;;)
{
 const GenericScopedLock<CriticalSection> myScopedLock (myCriticalSection);
 // myCriticalSection is now locked

    ...do some stuff...

 // myCriticalSection gets unlocked here
}
另见
GenericScopedUnlock, CriticalSection, SpinLock, ScopedLock, ScopedUnlock

GenericScopedLock()

template<class LockType> juce::GenericScopedLock < LockType >::GenericScopedLock (const LockType & lock) inline explicit noexcept

创建一个 GenericScopedLock。

一旦创建，它将获取锁，当 GenericScopedLock 对象被删除时，锁将被释放。

确保此对象由同一线程创建和删除，否则无法保证会发生什么！最好只将其作为局部栈对象使用，而不要用 new() 运算符创建。
