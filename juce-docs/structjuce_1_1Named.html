juce::Named< T > 结构体模板参考

详细说明

template<typename T>
struct juce::Named< T >

将对象与名称组合。

Named 的实例具有类似引用的语义。也就是说，Named 存储对所包装值的引用，而不是在内部存储该值。

模板参数
T所包装的引用类型。传入 "const T" 会使 Named 实例持有 "const T&"；传入 "T" 会使 Named 实例持有 "T&"。
