juce::dsp::FFT 类参考

详细说明

执行快速傅里叶变换。

这只是一个简单的低占用实现，并未针对速度进行调优——在那些使用更复杂的 FFT 库会显得过于笨重的简单应用中，它可能很有用。（当然，将来它可能会被优化……）

FFT 类本身包含查找表，因此创建它会有一些开销；你应为所需的每种变换尺寸/方向创建并缓存一个 FFT 对象，并重复使用它们来执行实际操作。

performRealOnlyForwardTransform()

void juce::dsp::FFT::performRealOnlyForwardTransform (float * inputOutputData, bool onlyCalculateNonNegativeFrequencies = false) const noexcept

对一块实数数据执行原地正向变换。

由于负频率（高于 N/2 或 pi 的频率）的系数是其正频率对应值的复共轭，对你的特定应用来说可能无需计算它们。你可以使用 onlyCalculateNonNegativeFrequencies 让 FFT 引擎知道你不打算使用它们。注意这只是一个提示：某些 FFT 引擎（目前只有 Fallback 引擎）即使 onlyCalculateNonNegativeFrequencies 为 true，仍会计算负频率。

传入的数组大小必须为 2 * getSize()，前半部分应包含原始输入采样数据。返回时，如果 onlyCalculateNonNegativeFrequencies 为 false，数组将包含 size 个交错的复数实部与虚部数据。如果 onlyCalculateNonNegativeFrequencies 为 true，数组将至少包含 (size / 2) + 1 个复数。两种输出都可以传给 performRealOnlyInverseTransform() 以转换回实数。

引用了 FFT()。

被以下对象引用： perform()。

performRealOnlyInverseTransform()

void juce::dsp::FFT::performRealOnlyInverseTransform (float * inputOutputData) const noexcept

对 performRealOnlyForwardTransform() 中创建的数据执行逆向操作。

尽管 performRealOnlyInverseTransform 只会使用前 ((size / 2) + 1) 个复数，但传入的数组大小仍必须为 2 * getSize()，因为某些 FFT 引擎需要额外空间进行计算。返回时，数组的前半部分将包含重组后的采样。

引用了 FFT()。

performFrequencyOnlyForwardTransform()

void juce::dsp::FFT::performFrequencyOnlyForwardTransform (float * inputOutputData, bool onlyCalculateNonNegativeFrequencies = false) const noexcept

接收一个数组并将其直接变换为幅度频谱。

这对于频率显示或分析之类的事情可能很方便。传入的数组大小必须为 2 * getSize()。

返回时，如果 onlyCalculateNonNegativeFrequencies 为 false，数组将包含 size 个幅度值。如果 onlyCalculateNonNegativeFrequencies 为 true，数组将至少包含 size / 2 + 1 个幅度值。

引用了 FFT()。

被以下对象引用： perform()。
