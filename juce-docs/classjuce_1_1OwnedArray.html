详细说明

template<class ObjectClass, class TypeOfCriticalSectionToUse = DummyCriticalSection>
class juce::OwnedArray< ObjectClass, TypeOfCriticalSectionToUse >

专为持有对象而设计的数组。

它持有一组指向对象的指针，并在对象从数组中移除或数组本身被删除时自动删除这些对象。

按如下形式声明：OwnedArray<MyObjectClass>

……然后添加新对象，例如 myOwnedArray.add (new MyObjectClass());

添加对象后，它们就由数组“拥有”，在移除或替换时会被删除。

要使数组的所有方法线程安全，请将“CriticalSection”作为模板化的 TypeOfCriticalSectionToUse 参数传入，而不是默认的 DummyCriticalSection。

另见
Array, ReferenceCountedArray, StringArray, CriticalSection

将其中一个对象移动到不同位置。

这将把对象移动到指定的索引，并按需挪动中间的各元素。

例如，如果你有数组 { 0, 1, 2, 3, 4, 5 }，那么调用 move (2, 4) 将得到 { 0, 1, 3, 4, 2, 5 }。

参数
currentIndex要移动的对象的索引。如果不是合法索引，则什么也不做
newIndex希望该对象最终落到的索引。如果小于零，将被移动到数组末尾

sort()

template<class ObjectClass, class TypeOfCriticalSectionToUse> template<typename ElementComparator> void juce::OwnedArray < ObjectClass, TypeOfCriticalSectionToUse >::sort (ElementComparator & comparator, bool retainOrderOfEquivalentItems = false) noexcept

对数组中的元素排序。

这将使用比较器对象将元素排序。传入的对象必须具有以下形式的方法：

int compareElements (ElementType* first, ElementType* second);

……并且此方法必须返回：

  • 如果第一个先于第二个，则返回值 < 0
  • 如果两个对象等价，则返回值 0
  • 如果第二个先于第一个，则返回值 > 0

为提高性能，compareElements() 方法可以声明为 static 或 const。

参数
comparator用于比较元素的比较器。
retainOrderOfEquivalentItems如果为 true，则比较器认为等价的项将保持它们当前在数组中出现的顺序。这执行起来较慢，但在某些情况下可能很重要。如果为 false，则使用更快的算法，但等价元素可能被重排。
