FileOutputStream()

juce::FileOutputStream::FileOutputStream (const File & fileToWriteTo, size_t bufferSizeToUse = 16384)

创建一个 FileOutputStream。

如果文件不存在，将首先创建它。如果文件无法创建或打开（例如因为文件的父目录不存在），failedToOpen() 方法将返回 true。

如果打开时文件已存在，流的写入位置将设置为文件末尾。要覆盖现有文件，你可以这样截断它：

FileOutputStream stream (file);

if (stream.openedOk())
{
    stream.setPosition (0);
    stream.truncate();
    ...
}

销毁 FileOutputStream 对象不会强制操作系统立即将缓冲数据写入磁盘。如果需要这样做，应在触发析构函数之前调用 flush()。
