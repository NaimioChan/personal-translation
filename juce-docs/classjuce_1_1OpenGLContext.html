juce::OpenGLContext 类参考

详细说明

创建一个 OpenGL 上下文，它可以附加到组件上。

要渲染 OpenGL 内容，你应创建一个 OpenGLContext 的实例，并调用 attachTo() 让它以某个组件作为渲染目标。

要提供多线程渲染，你可以提供一个 OpenGLRenderer 对象，用于渲染每一帧。

在你的目标组件或 OpenGLRenderer 被删除之前，你务必调用 detach() 或删除 OpenGLContext，以便后台线程能够停止、原生资源能够安全释放。

Core profile 不包含某些旧有功能，其中包括固定功能管线。

setRenderer()

void juce::OpenGLContext::setRenderer (OpenGLRenderer *) noexcept

给上下文指定一个 OpenGLRenderer 用于绘制。

你传给它的对象不会由上下文持有，因此调用方需负责管理其生命周期，并确保在上下文可能使用它时它不被删除。要停止上下文使用某个渲染器，只需用空指针调用此方法。注意：这必须在把上下文附加到目标组件之前调用！

attachTo()

void juce::OpenGLContext::attachTo (Component &)

把上下文附加到目标组件上。

如果组件未完全可见，此调用会等到组件显示后，才真正为它创建原生上下文。

创建原生上下文时会启动一个线程，用于调用 OpenGLRenderer 的各方法。上下文将浮在目标组件之上，目标移动时会跟随它。如果组件被隐藏/显示，上下文可能会被删除并重建。

detach()

void juce::OpenGLContext::detach ()

把上下文从其目标组件分离，并删除所有原生资源。

如果上下文尚未附加，此函数什么也不做。否则它将阻塞，直到上下文及其线程被清理完毕。

setComponentPaintingEnabled()

void juce::OpenGLContext::setComponentPaintingEnabled (bool shouldPaintComponent) noexcept

启用或禁用使用 GL 上下文对其所附加的组件进行 2D 渲染。

如果此项为 false，则只用你的 OpenGLRenderer 来执行所有渲染。如果为 true，则每次目标组件的 paint() 方法需要被调用时，都会用 OpenGLGraphicsContext 来渲染它（在此之前会先调用你的 OpenGLRenderer，如果有的话）。

默认设置为 true。如果你不使用任何 paint() 方法功能，而是在 OpenGLRenderer 中完成所有渲染，应禁用它以提升性能。

注意：这必须在把上下文附加到目标组件之前调用！

setContinuousRepainting()

void juce::OpenGLContext::setContinuousRepainting (bool shouldContinuouslyRepaint) noexcept

启用或禁用连续重绘。

如果设为 true，上下文将运行一个循环，不等待 triggerRepaint() 被调用就不断重新渲染自身，频率由交换间隔决定（见 setSwapInterval）。如果为 false，则每次渲染回调之后，它会等到再次调用 triggerRepaint() 后才重新渲染。默认禁用。

executeOnGLThread()

template<typename T> void juce::OpenGLContext::executeOnGLThread (T && functor, bool blockUntilFinished)

在具有活动上下文的 OpenGL 线程上执行 lambda、函数或函数对象。

此方法会尝试在 OpenGL 线程上执行 functor。如果 blockUntilFinished 为 true，则该方法会阻塞直到 functor 执行完毕。

仅当上下文已附加到组件时才能调用此函数。否则此函数会触发断言。

当你需要执行分配/释放纹理或帧缓冲区之类的日常维护任务时，此函数很有用。因此 functor 执行时不会锁定消息线程。所以它不适用于任何绘制命令或 GUI 代码。任何 GUI 代码都应改在 OpenGLRenderer::renderOpenGL 回调中执行。

参数
