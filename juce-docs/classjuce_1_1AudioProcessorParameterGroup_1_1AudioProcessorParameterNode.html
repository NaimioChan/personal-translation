juce::AudioProcessorParameterGroup::AudioProcessorParameterNode 类参考

详细说明

AudioProcessorParameterGroup 的子项。

它可以是 AudioProcessorParameter 或 AudioProcessorParameterGroup。你可以使用 getParameter 和 getGroup 方法查询是哪一个。

for (auto* child : group)
 if (auto* parameter = node.getParameter())
        parameter->setValueNotifyingHost (0.5f);
 else
        node.getGroup()->AddChild (new Parameter());
