juce::PathStrokeType 类参考

详细说明

描述用于沿路径渲染实心轮廓的描边类型。

可以直接用 PathStrokeType 对象创建路径周围的轮廓形状，Graphics::strokePath 会用它来指定要绘制的描边类型。

另见
Path, Graphics::strokePath

成员枚举

JointStyle

enum juce::PathStrokeType::JointStyle

两条相邻线段之间的拐角所使用的形状类型。

枚举值
mitered 

表示拐角应绘制为尖角。

注意，对于回折的角度，绘制斜接可能需要把顶点延伸得离路径太远，因此会施加斜接限制，超过该限制的拐角将改为斜切绘制。

curved 

表示拐角应绘制为圆角。

beveled 

表示拐角应绘制为用直线削平外侧边缘的形状。

EndCapStyle

enum juce::PathStrokeType::EndCapStyle

线条端点所使用的形状类型。

枚举值
butt 

线条端点平直，不超出端点。

square 

线条端点平直，但会超出端点半个描边粗细。

rounded 

线条端点用圆形收尾。

参数
destPath生成的描边轮廓形状将被复制到该路径中。注意，源 Path 和目标 Path 可以是同一个对象，因此你可以轻松地把一个路径变成它自身的描边版本。

createDashedStroke()

void juce::PathStrokeType::createDashedStroke (Path & destPath, const Path & sourcePath, const float * dashLengths, int numDashLengths, const AffineTransform & transform = AffineTransform (), float extraAccuracy = 1.0f, float dashOffset = 0.0f) const

把该描边类型应用于路径，生成虚线。

这与 createStrokedPath 类似，但使用传入的数组把描边分割成一系列虚线段。

参数
destPath生成的描边轮廓形状将被复制到该路径中。注意，源 Path 和目标 Path 可以是同一个对象，因此你可以轻松地把一个路径变成它自身的描边版本。
sourcePath用作源的路径
dashLengths一个由交替的实线/空白长度组成的数组。例如 { 2, 3, 4, 5 } 会先绘制长度为 2 的线，然后跳过长度 3，再绘制长度 4 的线，跳过 5，并不断重复该模式。
numDashLengthsdashLengths 数组中的长度个数。它最好是偶数，否则模式在重复时会错位。
transform一个可选的变换，用于在取用源路径的各点时对其应用
extraAccuracy如果该值大于 1.0，它会把路径细分到更高的分辨率，这样在你之后放大描边路径时质量会更好。例如，如果你打算按创建时尺寸的 3 倍绘制描边，就应把它设为 3。
dashOffset在虚线模式中开始描边的绝对偏移量。正偏移在视觉上会把模式向左移动。例如，模式为 "20 10"、dashOffset 为 "20" 时，第一段虚线被跳过，描边以长度 10 的空白开始。
