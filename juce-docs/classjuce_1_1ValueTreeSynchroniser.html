juce::ValueTreeSynchroniser 类参考

详细说明

此类可用于监视 ValueTree 状态的所有更改，并将其转换为可传输的二进制编码。

此类的目的是允许通过某种传输机制发送编码后的更改，从而远程同步两个或多个 ValueTree。

要使用它，你需要实现 ValueTreeSynchroniser 的子类，并实现 stateChanged() 方法，将编码后的更改（也许通过网络或其他方式）发送到远程目的地，在那里可将其应用到目标树。

stateChanged()

virtual void juce::ValueTreeSynchroniser::stateChanged (const void * encodedChange, size_t encodedChangeSize) pure virtual

当 ValueTree 更改且需要将给定的状态更改消息应用到任何其他需要与其保持同步的树时，会发生此回调。

数据是一个不透明的二进制块，你应将其传输到目标树所在之处，并使用 applyChange() 将其应用到目标树。

sendFullSyncCallback()

void juce::ValueTreeSynchroniser::sendFullSyncCallback ()

强制发送完整状态消息，由于它编码整棵 ValueTree，消息可能很大。

这会在内部以状态的编码版本调用 stateChanged()。

applyChange()

bool juce::ValueTreeSynchroniser::applyChange (ValueTree & target, const void * encodedChangeData, size_t encodedChangeDataSize, UndoManager * undoManager) static

将编码后的更改应用到给定的目标树。

当你为 stateChanged() 消息发送的更改实现接收端时，这就是你需要调用的函数，以将它们应用到希望保持同步的目标树。
