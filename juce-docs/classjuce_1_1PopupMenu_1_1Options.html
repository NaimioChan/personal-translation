juce::PopupMenu::Options 类参考

详细说明

用于创建一组选项以传递给 show() 方法的类。

你可以链式调用此类的方法，以创建你想要的任意选项集合。例如

PopupMenu menu;
...
menu.showMenu (PopupMenu::Options().withMinimumWidth (100)
                                   .withMaximumNumColumns (3)
                                   .withTargetComponent (myComp));

withTargetComponent() [1/2]

Options juce::PopupMenu::Options::withTargetComponent (Component * targetComponent) const nodiscard

设置显示菜单时要使用的目标组件。

这通常是触发菜单的按钮或其他控件。

目标组件主要用于控制菜单的缩放，因此如果你的程序将在高 DPI 显示器上使用，提供目标组件很重要。

此函数还会设置目标屏幕区域，以便菜单显示在目标组件旁边。如果你需要在特定位置显示菜单，应在 withTargetComponent 之后调用 withTargetScreenArea()。

withTargetScreenArea()

Options juce::PopupMenu::Options::withTargetScreenArea (Rectangle < int > targetArea) const nodiscard

设置菜单应显示在其旁边的屏幕区域。

要在鼠标光标旁边显示菜单，请使用 withMousePosition()，它等价于向此函数传入以下参数：

Rectangle<int>{}.withPosition (Desktop::getMousePosition())

withTargetComponent() 还会设置目标屏幕区域。如果你需要同时设置目标组件和目标屏幕区域，请确保在 withTargetComponent() 之后调用 withTargetScreenArea()。

withItemThatMustBeVisible()

Options juce::PopupMenu::Options::withItemThatMustBeVisible (int idOfItemToBeVisible) const nodiscard

设置菜单初始绘制时必须可见的项。

当菜单项太多而无法在单个屏幕上显示时，这对确保某个特定项被显示很有用。

如果可能，指定项将被定位在菜单的目标屏幕区域。

引用了 Options()。

withParentComponent()

Options juce::PopupMenu::Options::withParentComponent (Component * parentComponent) const nodiscard

设置弹出菜单将绘制到的组件。

某些插件格式（例如 AUv3）不喜欢插件编辑器创建额外窗口。一些 AUv3 宿主会在透明弹出窗口下方显示粉色背景，这令人困惑，且看起来像是插件出现故障。设置父组件可以避免这种不良行为，但缺点是菜单尺寸将受父组件尺寸限制。

引用了 Options()。

withInitiallySelectedItem()

Options juce::PopupMenu::Options::withInitiallySelectedItem (int idOfItemToBeSelected) const nodiscard

设置菜单中要选择的项。

这适用于组合框等控件：理想情况下，用键盘打开组合框时应高亮当前选中的项，从而可通过按键盘上的上/下键选择下一项/上一项，而无需每次打开时都从菜单顶部将高亮行往下移。
