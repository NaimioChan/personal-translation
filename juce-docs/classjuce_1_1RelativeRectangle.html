juce::RelativeRectangle 类参考

详细说明

以一组 RelativeCoordinate 值存储的矩形。

矩形的上、左、下、右边缘位置各存储为一个 RelativeCoordinate。

另见
RelativeCoordinate, RelativePoint

moveToAbsolute()

void juce::RelativeRectangle::moveToAbsolute (const Rectangle < float > & newPos, const Expression::Scope * scope)

更改此矩形各坐标的值，使其解析为指定位置。

调用此方法将保持任何锚点不变，但会把任何绝对或相对位置设为使结果位置与所提供位置匹配所需的值。

isDynamic()

bool juce::RelativeRectangle::isDynamic () const

如果此矩形的位置依赖任何外部符号，则返回 true。

引用基于“this”的符号的坐标被视为非动态。

toString()

String juce::RelativeRectangle::toString () const

返回表示此点的字符串。

这会返回以逗号分隔的坐标列表，顺序为 left、top、right、bottom。如果你用它来定位 Component，请参见 Component::setBounds (const RelativeRectangle&) 的说明了解所用语法。返回的字符串可以传给 RelativeRectangle 构造函数以重新创建该矩形。
