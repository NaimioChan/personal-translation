juce::MouseInputSource 类参考

详细说明

表示来自鼠标设备或多点触控环境中单个手指的线性鼠标事件源。

每个 MouseEvent 对象都包含对生成它的 MouseInputSource 的引用。在只有单个鼠标作为输入的环境中，所有事件都来自同一源，但在多点触控系统中，可能有多个 MouseInputSource 对象同时活动，每个对象代表来自特定手指的事件流。

来自单个 MouseInputSource 的事件始终以固定且可预测的顺序发送：没有事先发送 mouseEnter 就不会调用 mouseMove；mouseDown 与其对应的 mouseUp 之间只会发生 mouseDrag，等等。当来自多个 MouseInputSource 的多个触摸到达时，它们的事件流可能以交错顺序到达，因此你应使用 getIndex() 方法查明每个事件来自哪根手指。

enableUnboundedMouseMovement()

void juce::MouseInputSource::enableUnboundedMouseMovement (bool isEnabled, bool keepCursorVisibleUntilOffscreen = false) const

允许鼠标移动到屏幕边缘之外。

在鼠标按钮当前被按下时调用此方法，会将光标从屏幕上移除，并允许鼠标（看起来）移动到屏幕边缘之外。

这意味着返回给 mouseDrag() 的坐标将是无边界的，这可用于自定义滑块控件或拖动对象等场景，否则移动会受到鼠标碰到屏幕边缘的限制。

松开鼠标按钮时会自动关闭无边界模式，也可以通过再次调用此方法显式关闭。

参数
isEnabled是打开还是关闭此模式
keepCursorVisibleUntilOffscreen如果设为 false，光标将立即隐藏；如果为 true，则仅当它移动到屏幕边缘之外时才隐藏

引用了 MouseInputSource()。

被以下对象引用： isMouse()。
