成员数据文档

ascent

float juce::TypefaceMetrics::ascent {}

typeface 高度中位于基线以上的比例，取值为 0 到 1。

注意，这里的 height 指的是 ascent 与 descent 绝对值之和。也就是说，ascent 与 descent 之和将等于 1。ascent 与 descent 之和通常与字体的 em 尺寸不同。也就是说，对于 14pt 的字体大小，每个 em 有 14 点，但以点计的 ascent 与 descent 之和不太可能等于 14。

heightToPoints

float juce::TypefaceMetrics::heightToPoints {}

把 JUCE 字体高度转换为以点为单位的字体大小时需要相乘的系数。

如果字体的 ascent 和 descent 覆盖值都被设为 0，则可能为 inf！

lineGap

float juce::TypefaceMetrics::lineGap {}

此值反映了字体设计师在排布多行文本时的意图。

它是 typeface 高度的一个比例，在相邻行之间应于 ascent 和 descent 之外额外使用。
