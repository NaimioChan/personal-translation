详细说明

template<typename ElementType, typename TypeOfCriticalSectionToUse = DummyCriticalSection, int minimumAllocatedSize = 0>
class juce::Array< ElementType, TypeOfCriticalSectionToUse, minimumAllocatedSize >

持有原始类型或按值复制对象的可调整大小数组。

数组的例子有：Array<int>、Array<Rectangle> 或 Array<MyClass*>

Array 类可用于存放简单的非多态对象以及原始类型 —— 为此，该类必须满足以下要求：

  • 它必须具有复制构造函数和赋值运算符
  • 它必须能够通过 memcpy 在内存中重定位而不会引起任何问题 —— 因此，其功能依赖外部指针或对自身引用的对象不能使用。

你当然可以拥有指向任何类型对象的指针数组，例如 Array<MyClass*>，但如果你这样做，数组不会取得这些对象的任何所有权 —— 有关持有对象列表的更强大方式，见 OwnedArray 类或 ReferenceCountedArray 类。

要持有字符串列表，你可以使用 Array<String>，但通常更好的做法是使用专用类 StringArray，它提供了更有用的函数。

要使数组的所有方法线程安全，请将“CriticalSection”作为模板化的 TypeOfCriticalSectionToUse 参数传入，而不是默认的 DummyCriticalSection。

另见
OwnedArray, ReferenceCountedArray, StringArray, CriticalSection
