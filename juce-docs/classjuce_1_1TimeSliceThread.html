juce::TimeSliceThread 类参考

详细说明

一个维护客户端列表的线程，依次调用每个客户端，给它们各自运行某种短任务的机会。

构造函数与析构函数

TimeSliceThread()

juce::TimeSliceThread::TimeSliceThread (const String & threadName) explicit

创建一个 TimeSliceThread。

首次创建时，线程尚未运行。使用 startThread() 方法启动它。

被以下对象引用： contains()。

~TimeSliceThread()

juce::TimeSliceThread::~TimeSliceThread () override

析构函数。

删除正在运行的 Thread 对象只会给线程短暂的机会来干净地停止，因此建议在删除之前始终以合理的超时调用 stopThread()，以避免线程被强制杀死（这是件坏事）。

成员函数

addTimeSliceClient()

void juce::TimeSliceThread::addTimeSliceClient (TimeSliceClient * clientToAdd, int millisecondsBeforeStarting = 0)

将客户端添加到列表。

客户端的回调将在 millisecondsBeforeStarting 指定的毫秒数之后开始（这可能在此方法返回之前发生）。

moveToFrontOfQueue()

void juce::TimeSliceThread::moveToFrontOfQueue (TimeSliceClient * clientToMove)

如果给定客户端正在队列中等待，它将被移到前面，并尽快获得一个时间片。

如果指定的客户端尚未添加，则不会有任何操作。

removeTimeSliceClient()

void juce::TimeSliceThread::removeTimeSliceClient (TimeSliceClient * clientToRemove)

从列表中移除一个客户端。

此方法将确保在返回之前对该客户端的所有回调都已完全结束。

removeAllClients()

void juce::TimeSliceThread::removeAllClients ()

从列表中移除所有活动和待处理的客户端。
