void juce::MemoryBlock::setSize (size_t newSize, bool initialiseNewSpaceToZero = false)

调整内存块的大小。

新旧大小中都存在的数据将被保留。增大块时，结尾处新分配的空间可以被清零，也可以保持未初始化。

removeSection()

void juce::MemoryBlock::removeSection (size_t startByte, size_t numBytesToRemove)

从块中截掉一段。

这会移除内存块中的一段并闭合其周围的空隙，将后续数据前移，并减小块的大小。

如果指定的范围超出块的大小，将被裁剪。

toBase64Encoding()

String juce::MemoryBlock::toBase64Encoding () const

返回一个采用 JUCE 专有文本编码的字符串，表示此块的二进制内容。

这使用 JUCE 专有的（即非标准的！）64 位编码系统，将二进制数据转换为 ASCII 字符串，用于诸如存入 XML 等用途。注意，这种专有格式保留在此主要是为了向后兼容，如果你想使用标准的 base-64 编码，可能更愿意使用 Base64::toBase64() 方法。

另见
fromBase64Encoding, Base64::toBase64, Base64::convertToBase64
