juce::MidiInput 类参考

详细说明

表示使用旧式字节流格式的 MIDI 输入设备。

要创建其中之一，请使用静态的 getAvailableDevices() 方法查明有哪些输入可用，然后使用 openDevice() 方法尝试打开一个。

另见
MidiOutput

openDevice()

std::unique_ptr< MidiInput > juce::MidiInput::openDevice (const String & deviceIdentifier, MidiInputCallback * callback = nullptr) static

尝试打开某个 MIDI 输入设备。

如果成功打开，这将返回一个 MidiInput 对象，随后你可以对此设备调用 start() 和 stop()。

如果设备无法打开，将返回空对象。

参数
deviceIdentifier要打开的设备的 ID - 使用 getAvailableDevices() 方法查找可打开的可用设备
callback将接收来自此设备的 MIDI 消息的对象，你也可以用 addCallback() 和 removeCallback() 添加和移除接收者
另见
MidiInputCallback、getDevices

createNewDevice()

std::unique_ptr< MidiInput > juce::MidiInput::createNewDevice (const String & deviceName, MidiInputCallback * callback = nullptr) static

这将尝试创建一个新的 MIDI 输入设备（仅在 Linux、macOS 和 iOS 上可用）。

这将尝试创建一个具有指定名称的新 MIDI 输入设备，供其它应用连接。

注意 - 如果你在 iOS 上调用此方法，必须在 iOS 导出器中启用“Audio Background Capability”设置，否则此方法将失败。

如果无法创建设备则返回空对象。

参数
deviceName要创建的设备的名称
callback将接收来自此设备的 MIDI 消息的对象
