juce::BufferingAudioSource 类参考

详细说明

一种 AudioSource，它接收另一个源作为输入，并用一个线程对其进行缓冲。

将其作为另一个源的包装器创建，它会用后台线程预读以平滑播放。你可以直接创建其中一个，或通过 AudioTransportSource 间接使用。

另见
PositionableAudioSource, AudioTransportSource

构造函数与析构函数

BufferingAudioSource()

juce::BufferingAudioSource::BufferingAudioSource (PositionableAudioSource * source, TimeSliceThread & backgroundThread, bool deleteSourceWhenDeleted, int numberOfSamplesToBuffer, int numberOfChannels = 2, bool prefillBufferOnPrepareToPlay = true)

创建一个 BufferingAudioSource。

参数
source要读取的输入源
backgroundThread用于后台预读的后台线程。在任何使用它的 BufferingAudioSource 被删除之前，不得删除此对象！
deleteSourceWhenDeleted如果为 true，则删除此对象时会同时删除输入源对象
numberOfSamplesToBuffer用于预读的缓冲区大小
numberOfChannels要播放的通道数
prefillBufferOnPrepareToPlay如果为 true，则对此对象调用 prepareToPlay 会阻塞直到缓冲区填满

引用了 juce::PositionableAudioSource::PositionableAudioSource()、juce::TimeSliceClient::TimeSliceThread。
