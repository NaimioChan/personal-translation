juce::ChildProcess 类参考

详细说明

启动并监视子进程。

此类让你可以启动可执行文件并读取其输出。你也可以用它检查子进程是否已结束。

start() [1/2]

bool juce::ChildProcess::start (const String & command, int streamFlags = wantStdOut | wantStdErr)

尝试启动子进程命令。

command 应为可执行文件的名称，后跟所需的任何参数。如果进程已经启动，这将再次启动它。如果出现问题，该方法将返回 false。streamFlags 是若干值的组合，用于指明子进程的哪些输出流应被读取并由 readProcessOutput() 返回。

引用了 command、wantStdErr、wantStdOut。

start() [2/2]

bool juce::ChildProcess::start (const StringArray & arguments, int streamFlags = wantStdOut | wantStdErr)

尝试启动子进程命令。

第一个参数应为可执行文件的名称，后跟所需的任何其他参数。如果进程已经启动，这将再次启动它。如果出现问题，该方法将返回 false。streamFlags 是若干值的组合，用于指明子进程的哪些输出流应被读取并由 readProcessOutput() 返回。

引用了 wantStdErr、wantStdOut。
