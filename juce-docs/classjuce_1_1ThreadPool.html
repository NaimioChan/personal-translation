juce::ThreadPool 类参考

详细说明

一组将运行作业列表的线程。

当 ThreadPoolJob 对象被添加到 ThreadPool 的列表时，其 runJob() 方法将由下一个空闲的池化线程调用。

addJob() [1/2]

void juce::ThreadPool::addJob (ThreadPoolJob * job, bool deleteJobWhenFinished)

向队列添加一个作业。

任务添加后，下一次有线程空闲时就会运行该任务的 ThreadPoolJob::runJob() 方法。根据 runJob() 方法的返回值，线程池会将任务从池中移除，或将其添加到队列末尾以便再次运行。

如果 deleteJobWhenFinished 为 true，则任务对象将由线程池持有，并在不再需要时删除——若这样做，请确保对象的析构函数是线程安全的。

如果 deleteJobWhenFinished 为 false，则只使用该指针而不删除对象，调用方需负责确保在对象从池中移除之前不被删除。

引用了 ThreadPool()。

removeJob()

bool juce::ThreadPool::removeJob (ThreadPoolJob * job, bool interruptIfRunning, int timeOutMilliseconds)

尝试从池中删除一个作业。

如果任务尚未运行，则直接将其移除。如果正在运行，则会等待其完成。

如果在任务运行结束前超时，任务将保留在池中，此方法返回 false。如果任务成功停止并被移除，则返回 true。

参数
job要移除的任务
interruptIfRunning若为 true，则任务当前忙碌时会调用其 ThreadPoolJob::signalJobShouldExit() 方法尝试中断它。若为 false，则允许任务继续运行直到正常停止（或超时）
timeOutMilliseconds此方法在放弃并返回 false 之前等待任务完成的时间长度

bool juce::ThreadPool::waitForJobToFinish (const ThreadPoolJob * job, int timeOutMilliseconds) const

等待直到作业运行完毕并从池中移除。

此方法会一直等待，直到任务不再位于池中——即直到其 runJob() 方法返回 ThreadPoolJob::jobHasFinished。

如果在任务完成前超时，则返回 false；如果任务已成功完成，则返回 true。
