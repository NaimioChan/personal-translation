成员数据文档

deltaX

float juce::MouseWheelDetails::deltaX

滚轮在 X 轴上移动的量。

如果 isReversed 为 true，则负的 deltaX 表示滚轮被物理地向左推。如果 isReversed 为 false，则负的 deltaX 表示滚轮被物理地向右推。

deltaY

float juce::MouseWheelDetails::deltaY

滚轮在 Y 轴上移动的量。

如果 isReversed 为 true，则负的 deltaY 表示滚轮被物理地向上推。如果 isReversed 为 false，则负的 deltaY 表示滚轮被物理地向下推。

isReversed

bool juce::MouseWheelDetails::isReversed

指示用户是否反转了滚轮的方向。

关于此值的影响，参见 deltaX 和 deltaY 的说明。

isSmooth

bool juce::MouseWheelDetails::isSmooth

如果为 true，则滚轮具有连续的、无级进的运动。

isInertial

bool juce::MouseWheelDetails::isInertial

如果为 true，则此事件属于滚轮松开之后惯性动量阶段的一部分。
