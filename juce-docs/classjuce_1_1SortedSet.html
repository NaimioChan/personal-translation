详细说明

template<class ElementType, class TypeOfCriticalSectionToUse = DummyCriticalSection>
class juce::SortedSet< ElementType, TypeOfCriticalSectionToUse >

保存一组唯一的基元对象，例如 int 或 double。

一个集合对于给定值只能保存一个项，因此例如对于整数集合，第二次尝试添加相同的整数将不做任何事。

在内部，项列表保持有序（这意味着所使用的基元类型必须支持 ==、<、>、<= 和 >= 运算符以确定顺序），并且由于使用二分查找法，在集合中搜索已知值非常快。

注意，如果你使用类或结构体作为元素类型，它必须能够通过简单的 memcpy 进行复制或移动，而不需要构造和析构代码。

要使集合的所有方法线程安全，请传入 "CriticalSection" 作为模板参数 TypeOfCriticalSectionToUse，而不是默认的 DummyCriticalSection。
