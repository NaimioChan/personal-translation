getAvailableWriteSpeeds()

Array < int > juce::AudioCDBurner::getAvailableWriteSpeeds () const

返回设备可处理的可能写入速度集合。

这些是相对于“正常”速度的倍数，例如 '24x' 返回 24，等等。请注意，如果驱动器中没有介质，此值可能不可用！

另见
setWriteSpeed, getWriteSpeed

setBufferUnderrunProtection()

bool juce::AudioCDBurner::setBufferUnderrunProtection (bool shouldBeEnabled)

尝试在支持此功能的设备上启用或禁用缓冲区欠载保护。

返回
如果现已启用则为 true。如果设备不支持，则始终返回 false。

getNumAvailableAudioBlocks()

int juce::AudioCDBurner::getNumAvailableAudioBlocks () const

返回磁盘上的空闲块数量。

在 44100Hz 下每秒有 75 个块。

addAudioTrack()

bool juce::AudioCDBurner::addAudioTrack (AudioSource * source, int numSamples)

添加要写入的轨道。

此处传入的源将由本对象保留，并将在将来某个时候使用和删除，可能是在 burn() 方法期间，或在此 AudioCDBurner 对象被删除时。你的调用方法不应保留对它的引用，也不应在此处传入后再次使用它。

burn()

String juce::AudioCDBurner::burn (BurnProgressListener * listener, bool ejectDiscAfterwards, bool performFakeBurnForTesting, int writeSpeed)

运行刻录过程。

此方法将阻塞，直到操作完成。

参数
listener用于接收进度回调的对象
ejectDiscAfterwards刻录完成后是否弹出光盘
performFakeBurnForTesting如果为 true，则不会实际向磁盘写入任何数据
writeSpeedgetAvailableWriteSpeeds() 中的某个写入速度，或 0 或更小表示最快速度。

abortBurn()

void juce::AudioCDBurner::abortBurn ()

如果当前正在进行刻录操作，这会告知它尽快停止。

也可以通过从 BurnProgressListener::audioCDBurnProgress() 返回 true 来停止刻录过程
