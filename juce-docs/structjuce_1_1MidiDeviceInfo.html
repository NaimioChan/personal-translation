juce::MidiDeviceInfo 结构体参考

详细说明

此结构体包含有关 MIDI 1.0 输入或输出端口的信息。

你可以通过调用 MidiInput 和 MidiOutput 的静态 getAvailableDevices() 或 getDefaultDevice() 方法，或对这些类的实例调用 getDeviceInfo()，来获得其中一个这样的结构体。可以通过将标识符传给 openDevice() 方法来打开设备。

成员数据文档

name

String juce::MidiDeviceInfo::name

此设备的名称。

除非设备是用 createNewDevice() 方法创建的，否则这由操作系统提供。

注意，名称不保证唯一，两个同名设备将无法区分。如果你想定位某个特定设备，最好使用标识符。

被以下对象引用： MidiDeviceInfo()、withName()。

identifier

String juce::MidiDeviceInfo::identifier

此设备的标识符。

这由操作系统提供，其格式在不同系统上会有所不同，例如在 macOS 上是数字，而在 Windows 上是较长的字母数字字符串。

被以下对象引用： MidiDeviceInfo()、withName()。
