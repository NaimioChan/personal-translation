withLuminanceMaskSet()

ScopedBlendContextOptions juce::ScopedBlendContextOptions::withLuminanceMaskSet (bool x = true) const inline nodiscard

设置此选项后，后备缓冲区的亮度会在被混合到父缓冲区之前转换为 alpha 值。

转换后，RGB 分量为零，A 分量按 SVG 规范中的公式计算：A = ((0.2125 * R) + (0.7154 * G) + (0.0721 * B)) * A。

引用了 ScopedBlendContextOptions()、juce::withMember()、x。

withScopeClip()

ScopedBlendContextOptions juce::ScopedBlendContextOptions::withScopeClip (Rectangle < int > x) const inline nodiscard

允许为混合上下文指定额外的裁剪，从而减小所需的后备缓冲区尺寸。

默认情况下，后备缓冲区与父上下文的裁剪区域大小相同。即使提供了此值，对于 destinationIn 和 destinationOut 等某些混合模式也会被忽略。

引用了 ScopedBlendContextOptions()、juce::withMember()、x。
