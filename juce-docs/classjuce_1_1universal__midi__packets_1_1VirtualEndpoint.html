juce::universal_midi_packets::VirtualEndpoint 类参考

详细说明

表示一个虚拟设备，它允许此程序向系统上的其它 MIDI 感知应用通告自身。

创建 VirtualEndpoint 将在系统上安装一个新端点。使用 Endpoints 单例枚举端点时，此端点将可见。如果你在 UI 中显示端点列表，建议省略当前应用创建的虚拟端点，以避免混淆。

创建 VirtualEndpoint 之后，可以像任何其它连接一样打开它，方法是调用 Session::connectInput() 和 Session::connectOutput()，并传入该虚拟端点的 EndpointId。

getId()

EndpointId juce::universal_midi_packets::VirtualEndpoint::getId () const

获取此端点的唯一 id。

将此 ID 传给 Session::connectInput() 和/或 Session::connectOutput，以便通过该虚拟端点发送和接收消息。

注意，此 ID not 保证稳定 - 在多次程序运行中创建“相同”的虚拟设备，每次可能会产生不同的 ID。

要获取此设备的当前详细信息，你可以将此 ID 传给 Endpoints::getEndpoint()。

端点上的功能块数量不得改变。

成功时返回 true，否则返回 false。

这可能因多种原因失败，包括：

  • 尝试修改具有静态功能块的端点
  • 尝试更新此端点上不存在的块索引
  • 尝试设置具有无效属性的块，例如起始索引与包含的组数之和大于 16
  • 平台特有的原因，例如 macOS 目前不允许更改块中跨越的组数
