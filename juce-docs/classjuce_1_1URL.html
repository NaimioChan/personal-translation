juce::URL 类参考

详细说明

表示一个 URL，并提供许多操作它的实用函数。

此类可用于在浏览器中启动 URL，也可用于创建可从远程 HTTP 或 FTP 源读取的 InputStream。

createInputStream()

std::unique_ptr< InputStream > juce::URL::createInputStream (const InputStreamOptions & options) const

尝试打开一个可从该 URL 读取的流。

注意，此方法会阻塞，直到收到第一个数据字节或发生错误。

注意，在某些平台（例如 Android）上，不允许在消息线程中执行任何网络操作，因此只能从后台线程调用它。

除非 URL 表示本地文件，否则此方法返回 WebInputStream 的实例。你可以使用 dynamic_cast 将返回值转换为 WebInputStream，从而对传输过程进行更细粒度的控制。

如果 URL 表示本地文件，则此方法仅返回一个 FileInputStream。

参数
options打开流时将使用的一组选项。
返回
有效的输入流，若尝试打开时出错则为 nullptr。
