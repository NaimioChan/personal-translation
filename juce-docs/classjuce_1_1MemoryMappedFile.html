构造函数与析构函数

MemoryMappedFile() [1/2]

juce::MemoryMappedFile::MemoryMappedFile (const File & file, AccessMode mode, bool exclusive = false)

打开一个文件并将其映射到一块虚拟内存区域。

调用此方法时文件应已存在，且应已是你要处理的大小。如果文件在打开后被调整大小，行为是未定义的。

如果文件存在且操作成功，getData() 和 getSize() 方法将返回可读或可写数据的位置和大小。注意，整个文件不会立即读入内存 —— 操作系统只是创建一个虚拟映射，在访问各块时才会惰性地将数据调入内存。

如果文件因某种原因无法打开，getData() 方法将返回空指针。

如果 exclusive 为 false，其他应用也可以打开同一个内存映射文件，并把这种映射作为一种有效的通信方式。如果 exclusive 为 true，映射文件将以独占方式打开 —— 阻止其他应用访问该文件，这可能会提高访问文件的性能。

MemoryMappedFile() [2/2]

juce::MemoryMappedFile::MemoryMappedFile (const File & file, const Range < int64 > & fileRange, AccessMode mode, bool exclusive = false)

打开文件的一个区段并将其映射到一块虚拟内存区域。

调用此方法时文件应已存在，且应已是你要处理的大小。如果文件在打开后被调整大小，行为是未定义的。

如果文件存在且操作成功，getData() 和 getSize() 方法将返回可读或可写数据的位置和大小。注意，整个文件不会立即读入内存 —— 操作系统只是创建一个虚拟映射，在访问各块时才会惰性地将数据调入内存。

如果文件因某种原因无法打开，getData() 方法将返回空指针。

注意：实际使用范围的起点可能会向下取整到操作系统页面大小的整数倍，因此不要假定映射内存会恰好从你请求的位置开始 —— 始终使用 getRange() 检查实际使用的范围。
