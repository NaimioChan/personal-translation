详细说明

template<class SelectableItemType>
class juce::LassoSource< SelectableItemType >

供 LassoComponent 用来管理其所选项的类。

这使 LassoComponent 能够找出套索内的项，并更改所选项的列表。

findLassoItemsInArea()

template<class SelectableItemType> virtual void juce::LassoSource < SelectableItemType >::findLassoItemsInArea (Array < SelectableItemType > & itemsFound, const Rectangle < int > & area) pure virtual

返回位于给定可套索区域内的项集合。

你对此方法的实现必须找出位于给定矩形内的所有相关项，并将它们添加到 itemsFound 数组。

坐标相对于套索组件父组件的左上角。（即它们与套索组件自身的大小和位置相同）。

getLassoSelection()

template<class SelectableItemType> virtual SelectedItemSet < SelectableItemType > & juce::LassoSource < SelectableItemType >::getLassoSelection () pure virtual

返回套索应更新的 SelectedItemSet。

此集合将在 LassoComponent 被拖动时持续更新，因此请确保已向该集合附加 ChangeListener，以便你的 UI 对象能知道选择何时更改并相应地更新自身。

被以下对象引用： juce::LassoComponent< SelectableItemType >::beginLasso()。
