AudioParameterInt() [1/2]

juce::AudioParameterInt::AudioParameterInt (const ParameterID & parameterID, const String & parameterName, int minValue, int maxValue, int defaultValue, const AudioParameterIntAttributes & attributes = {})

创建具有指定参数的 AudioParameterInt。

注意，attributes 参数是可选的，只有在你想要更改默认选项时才需要提供。

用法示例：

auto attributes = AudioParameterIntAttributes().withStringFromValueFunction ([] (auto x, auto) { return String (x); })
                                               .withLabel ("things");
auto param = std::make_unique<AudioParameterInt> ("paramID", "Parameter Name", 0, 100, 50, attributes);
