createPluginInstance()

std::unique_ptr< AudioPluginInstance > juce::AudioPluginFormatManager::createPluginInstance (const PluginDescription & description, double initialSampleRate, int initialBufferSize, String & errorMessage) const

通过尝试此管理器所知道的所有格式，尝试加载此描述对应的类型。

如果无法加载插件，它会返回 nullptr，并在 errorMessage 字符串中留下一条消息。

如果你打算实例化 AudioUnit v3 插件，则必须使用下面的非阻塞异步版本——或者在消息线程之外的线程上调用此方法，且不得阻塞消息线程。

createPluginInstanceAsync()

void juce::AudioPluginFormatManager::createPluginInstanceAsync (const PluginDescription & description, double initialSampleRate, int initialBufferSize, AudioPluginFormat::PluginCreationCallback callback)

通过尝试此管理器所知道的所有格式，尝试异步加载此描述对应的类型。

调用方必须提供一个回调对象，实例化完成后会调用它。

如果无法加载插件，回调函数会被调用，并将 nullptr 作为实例参数传入，同时附带一条错误消息。

回调函数将在消息线程上被调用，因此调用方不得阻塞消息线程。

回调对象在被调用后会自动删除。

调用方负责删除传给回调函数的实例。

如果你打算实例化 AudioUnit v3 插件，则必须使用此非阻塞异步版本——或者从辅助线程调用同步方法。

createARAFactoryAsync()

void juce::AudioPluginFormatManager::createARAFactoryAsync (const PluginDescription & description, AudioPluginFormat::ARAFactoryCreationCallback callback) const

尝试为此描述创建 ::ARAFactoryWrapper。

操作结果会被包装进一个 ARAFactoryResult，并传给调用方提供的回调对象。

操作可能失败，此时回调会收到一个结果对象，其中 ARAFactoryResult::araFactory.get() 将返回 nullptr。

如果成功，返回的 ::ARAFactoryWrapper 会确保 ARAFactory 正常工作所需的模块在该对象的生命周期内保持加载。
