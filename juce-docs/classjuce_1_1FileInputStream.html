getTotalLength()

int64 juce::FileInputStream::getTotalLength () override virtual

返回此流中可供读取的总字节数。

注意，这是从流开头算起的可用字节数，而不是从当前位置算起。

如果流的实际大小未知，则返回 -1。

read()

int juce::FileInputStream::read (void * destBuffer, int maxBytesToRead) override virtual

从流中读取一些数据到内存缓冲区。

这是子类实际需要实现的唯一读取方法，因为 InputStream 基类会基于它实现其它读取方法（不过子类直接实现这些方法通常效率更高）。

参数
destBuffer数据的目标缓冲区。它不能为空。
maxBytesToRead要读取的最大字节数——请确保传入的内存块足以容纳这么多字节。该值不能为负数。
返回
实际读取的字节数；如果流在达到 maxBytesToRead 之前就已耗尽，该值可能小于 maxBytesToRead

setPosition()

bool juce::FileInputStream::setPosition (int64 newPosition) override virtual

尝试移动流的当前读取位置。

该位置是从流开头算起的绝对字节数。

某些流可能无法做到这一点，此时它们应什么都不做并返回 false。其它流则可能通过重置自身并跳到正确位置来实现，不过这显然有点慢。

返回
如果流成功重新定位，则为 true
