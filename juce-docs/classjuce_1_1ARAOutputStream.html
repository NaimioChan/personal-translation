write()

bool juce::ARAOutputStream::write (const void * dataToWrite, size_t numberOfBytes) override virtual

向流中写入一块数据。

创建 OutputStream 的子类时，这是唯一需要重载的写入方法——基类中其它写入类型数据的方法都会调用它来完成工作。

参数
dataToWrite用于接收数据的目标缓冲区。它不能为空。
numberOfBytes要写入的字节数。
返回
如果写入操作因某种原因失败，则为 false
