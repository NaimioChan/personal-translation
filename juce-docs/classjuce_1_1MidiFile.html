juce::MidiFile 类参考

详细说明

读写标准 MIDI 格式文件。

要读取 MIDI 文件，创建一个 MidiFile 对象并调用其 readFrom() 方法。然后可以用 getTrack() 方法从中获取各个 MIDI 轨道。

要写入文件，创建一个 MidiFile 对象，用 addTrack() 方法向其中添加一些 MidiMessageSequence 对象，然后调用其 writeTo() 方法将其写出。

MidiMessageSequence

getTimeFormat()

short juce::MidiFile::getTimeFormat () const noexcept

返回将要写到流中的原始时间格式代码。

读取 MIDI 文件后，本方法返回从文件头读出的时间格式。可以用 setTicksPerQuarterNote() 或 setSmpteTimeFormat() 方法更改它。

如果返回值为正，它表示每四分音符的 MIDI tick 数，参见 setTicksPerQuarterNote()。

如果为负，则高字节表示每秒帧数（但为负值），低字节表示每帧的 tick 数，参见 setSmpteTimeFormat()。

引用了 MidiFile()。

被以下对象引用： getTrack()。

readFrom()

bool juce::MidiFile::readFrom (InputStream & sourceStream, bool createMatchingNoteOffs = true, int * midiFileType = nullptr)

读取 MIDI 文件格式的流。

调用之后，你可以用 getNumTracks() 和 getTrack() 方法获取从文件中读出的轨道。

各轨道中 MIDI 事件的时间戳以 MIDI tick 表示其位置。要转换为秒，请使用 convertTimestampTicksToSeconds() 方法。

参数
sourceStream源流
createMatchingNoteOffs如果为 true，则之前 note-on 缺失的 note-off 会在文件末尾通过对每个轨道调用 MidiMessageSequence::updateMatchedPairs 自动补齐。
midiFileType如果不是 nullptr，该地址处的整数将根据 MIDI 文件的类型被设为 0、1 或 2
返回
如果流读取成功则为 true

引用了 MidiFile()。

被以下对象引用： getTrack()。

convertTimestampTicksToSeconds()

void juce::MidiFile::convertTimestampTicksToSeconds ()

把所有 MIDI 事件的时间戳从 MIDI tick 转换为秒。

这会使用轨道中的 MIDI 时间格式以及速度/拍号信息，把所有时间戳转换为以秒为单位的绝对值。

引用了 convertTimestampTicksToSeconds()、JUCE_LEAK_DETECTOR、MidiFile()。

被以下对象引用： getTrack()。
