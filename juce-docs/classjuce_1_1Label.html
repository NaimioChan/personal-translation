std::unique_ptr< AccessibilityHandler > juce::Label::createAccessibilityHandler () override virtual

重写此方法可为该组件返回自定义的 AccessibilityHandler。

默认实现创建并返回一个角色未指定的 AccessibilityHandler 对象，这意味着它对无障碍客户端可见，但没有特定角色、操作回调或接口。要控制无障碍客户端如何查看和交互你的组件子类 AccessibilityHandler，请实现所需行为，并在组件子类中从此方法返回它的实例。

paint()

void juce::Label::paint (Graphics & g) override protected virtual

组件可以重写此方法以绘制其内容。

当组件的某个区域需要重绘时会调用 paint() 方法，原因可能是组件的 repaint() 方法被调用，或者屏幕上发生了某些情况导致窗口的某一部分需要重绘。

任何子组件都会绘制在此方法绘制的内容之上。如果你需要绘制在子组件上方，也可以实现 paintOverChildren() 方法来实现。

如果你想让组件重绘自身，这是异步完成的——调用 repaint() 方法会将组件的某个区域标记为“脏”，稍后消息线程会自动调用 paint() 方法来绘制任何需要刷新的部分。在 JUCE（以及几乎所有现代界面框架）中，你永远不会同步重绘。

你应该永远不需要直接调用此方法——要对组件进行快照，可以使用 createComponentSnapshot() 或 paintEntireComponent()。

参数

createKeyboardFocusTraverser()

std::unique_ptr< ComponentTraverser > juce::Label::createKeyboardFocusTraverser () override protected virtual

创建一个 ComponentTraverser 对象，用于确定从此组件传递键盘焦点的逻辑。

如果此组件是键盘焦点容器（由 setFocusContainerType() 方法确定），此方法的默认实现将返回 KeyboardFocusTraverser 的实例。如果组件不是键盘焦点容器，则会在其父组件上递归调用 createKeyboardFocusTraverser()。

如果你重写此方法以返回自定义遍历器对象，则此组件及其所有子组件将使用新对象来做键盘焦点决策。
