juce::NormalisableRange< ValueType > 类模板参考

详细说明

template<typename ValueType>
class juce::NormalisableRange< ValueType >

表示任意取值区间与归一化的 0->1 区间之间的映射。

该映射的属性还包括可选的吸附间隔和偏斜因子。

skew

template<typename ValueType> ValueType juce::NormalisableRange < ValueType >::skew = 1

可选的偏斜因子，用于改变值在区间内的分布方式。

偏斜因子让你能以对数方式偏斜映射，使较大或较小的值获得更大比例的可用空间。

因子为 1.0 时完全没有偏斜效果。如果因子 < 1.0，区间下端将占据滑块长度的更多部分；如果因子 > 1.0，区间上端将被扩展。

如果你在此类的构造函数中为 convertFrom0to1Func 和 convertFrom0to1Func 使用了 lambda 函数，则偏斜值将被忽略。

被以下对象引用： NormalisableRange()、NormalisableRange()、operator=()、operator=()。

symmetricSkew

template<typename ValueType> bool juce::NormalisableRange < ValueType >::symmetricSkew = false

如果为 true，偏斜因子从滑块中点应用到其两端。
