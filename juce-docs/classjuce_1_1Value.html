juce::Value 类参考

详细说明

表示共享的变体值。

Value 对象包含对 var 对象的引用，并可以获取和设置其值。可以附加监听器，以便在值更改时收到通知。

Value 类是对共享的、带引用计数的底层数据对象的封装——这意味着多个 Value 对象可以都引用同一份数据，从而当其中任何一个更改它时，所有对象都能收到通知。

用默认构造函数创建 Value 时，它充当对简单 var 对象的封装；但通过创建引用 ValueSource 的自定义子类的 Value，你可以将 Value 映射到任何类型的底层数据上。

重要提示！Value 类不是线程安全的！如果你从多个线程访问同一个，则需要在访问它的任何代码周围使用自己的同步机制。

addListener()

void juce::Value::addListener (Listener * listener)

添加监听器，在值更改时接收回调。

监听器添加到此特定的 Value 对象，而不是它所引用的共享对象。当此对象被删除时，所有监听器都会丢失，即使对同一 Value 的其他引用仍然存在。因此添加监听器时，请确保将其添加到在你需要监听器期间一直存在的 Value 实例上。一般来说，你绝不会想把监听器添加到局部的、基于栈的 Value 上，而更可能添加到成员变量上。
