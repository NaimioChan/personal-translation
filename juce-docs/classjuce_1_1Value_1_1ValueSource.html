juce::Value::ValueSource 类参考

详细说明

由 Value 类在内部使用，作为其共享值对象的基类。

Value 类本质上是指向 ValueSource 对象共享实例的引用计数指针。如果你愿意冒险，可以创建自己的自定义 ValueSource 类，让 Value 对象表示你自己的自定义数据项。
