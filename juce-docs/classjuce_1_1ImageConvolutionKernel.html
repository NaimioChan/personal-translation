createGaussianBlur()

void juce::ImageConvolutionKernel::createGaussianBlur (float blurRadius)

初始化用于高斯模糊的核。

参数
blurRadius它可以比核的实际尺寸更大或更小，但这显然会浪费计算量或在边缘处被裁剪。理想情况下，核应恰好略大于 (blurRadius * 2)。

getKernelSize()

int juce::ImageConvolutionKernel::getKernelSize () const inline

返回核的大小。

applyToImage()

void juce::ImageConvolutionKernel::applyToImage (Image & destImage, const Image & sourceImage, const Rectangle < int > & destinationArea) const

将核应用到图像。

参数
destImage将接收卷积结果像素的图像。
sourceImage要读取的源图像——它可以与目标图像相同，如果不同，则必须大小和格式完全一致。
destinationArea要应用滤波器的图像区域
