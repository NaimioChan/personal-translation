template<typename ElementType>
class juce::dsp::Matrix< ElementType >

通用矩阵与向量类，用于经典数学运算，例如加法、乘法以及线性方程组求解。

solve()

template<typename ElementType> bool juce::dsp::Matrix < ElementType >::solve (Matrix < ElementType > & b) const noexcept

求解由该对象和参数 b 表示的线性方程组，根据参数的尺寸使用不同的算法。

矩阵必须是 N 乘 N 的方阵，b 必须是 N 乘 1 的向量，包含 b 的系数。算法执行完毕后，向量 b 将包含解。

如果线性方程组成功求解，则返回 true。

引用了 clear()。
