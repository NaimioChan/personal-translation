juce::SubregionStream 类参考

详细说明

封装另一个输入流，并从其中的特定部分读取。

这让你可以取流的一个子段，并将其作为独立的完整流呈现。

SubregionStream()

juce::SubregionStream::SubregionStream (InputStream * sourceStream, int64 startPositionInSourceStream, int64 lengthOfSourceStream, bool deleteSourceWhenDestroyed)

从输入源创建 SubregionStream。

参数
sourceStream要读取的源流
startPositionInSourceStream这是源流中对应于此流位置 0 的位置
lengthOfSourceStream这指定此流将从源流传递的最大字节数。当此流的位置超过 lengthOfSourceStream 时，将导致流结束。如果此处传入的长度大于源流的长度（由 getTotalLength() 返回），则使用较小值。为此参数传入负值意味着它将一直读取到源流的流结束。
deleteSourceWhenDestroyed传入的 sourceStream 是否应在此对象自身被删除时由它删除。

引用了 juce::InputStream::InputStream()。

被以下对象引用： isExhausted()。

setPosition()

bool juce::SubregionStream::setPosition (int64 newPosition) override virtual

尝试移动流的当前读取位置。

该位置是从流开头算起的绝对字节数。

某些流可能无法做到这一点，此时它们应什么都不做并返回 false。其它流则可能通过重置自身并跳到正确位置来实现，不过这显然有点慢。

返回
如果流成功重新定位，则为 true

read()

int juce::SubregionStream::read (void * destBuffer, int maxBytesToRead) override virtual

从流中读取一些数据到内存缓冲区。

这是子类实际需要实现的唯一读取方法，因为 InputStream 基类会基于它实现其它读取方法（不过子类直接实现这些方法通常效率更高）。

参数
destBuffer数据的目标缓冲区。它不能为空。
maxBytesToRead要读取的最大字节数——请确保传入的内存块足以容纳这么多字节。该值不能为负数。
返回
实际读取的字节数；如果流在达到 maxBytesToRead 之前就已耗尽，该值可能小于 maxBytesToRead

实现 juce::InputStream。
