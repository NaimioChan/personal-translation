juce::AccessibilityActions 类参考

详细说明

一个简单的封装，用于为 UI 元素构建一组受支持的无障碍操作及相应的回调。

在构造 AccessibilityHandler 时传入其中之一，即可让用户通过受支持的操作与 UI 元素交互。
