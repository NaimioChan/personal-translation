juce::HashMap< KeyType, ValueType, HashFunctionType, TypeOfCriticalSectionToUse > 类模板参考

详细说明

template<typename KeyType, typename ValueType, class HashFunctionType = DefaultHashFunctions, class TypeOfCriticalSectionToUse = DummyCriticalSection>
class juce::HashMap< KeyType, ValueType, HashFunctionType, TypeOfCriticalSectionToUse >

保存若干键/值对之间的映射集合。

键和值对象的类型作为模板参数设置。你还可以指定一个类来提供将键值转换为哈希整数的哈希函数。该类必须具有以下形式：

struct MyHashGenerator
{
 int generateHash (MyKeyType key, int upperLimit) const
 {
 // The function must return a value 0 <= x < upperLimit
 return someFunctionOfMyKeyType (key) % upperLimit;
    }
};

与 Array 类一样，键和值类型应当是值拷贝类型，因此如果你将它们定义为指针类型，此类不会删除它们所指向的对象。

如果你不为 HashFunctionType 模板参数提供类，默认类会为字符串和整数提供一些简单映射。

HashMap<int, String> hash;
hash.set (1, "item1");
hash.set (2, "item2");

DBG (hash [1]); // prints "item1"
DBG (hash [2]); // prints "item2"

// This iterates the map, printing all of its key -> value pairs.
for (HashMap<int, String>::Iterator i (hash); i.next();)
 DBG (i.getKey() << " -> " << i.getValue());
模板参数
HashFunctionType哈希函数的类，必须可拷贝构造。

参数

hashFunctionHashFunctionType 的一个实例，它将被拷贝并存储以供 HashMap 使用。如果 HashFunctionType 具有默认构造函数，则可以省略此参数。
