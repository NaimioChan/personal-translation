juce::AudioFormatManager 类参考

详细说明

一个用于保存可用音频格式列表，并决定使用哪个格式打开指定文件的类。

创建 AudioFormatManager 对象后，应调用 registerFormat() 或 registerBasicFormats() 为它提供可用的格式类型列表。

registerFormat()

void juce::AudioFormatManager::registerFormat (AudioFormat * newFormat, bool makeThisTheDefaultFormat)

向管理器的可用文件类型列表中添加一种格式。

传入的对象将由本对象删除，因此不要保留指向它的指针！

如果 makeThisTheDefaultFormat 为 true，那么调用 getDefaultFormat() 方法时将返回这一个。

registerBasicFormats()

void juce::AudioFormatManager::registerBasicFormats ()

便捷方法，用来轻松注册 JUCE 自带的格式。

这会把 WAV 和 AIFF 添加到列表中，以及在 Projucer 或你的应用程序预处理器定义中启用的任何其它格式。

findFormatForFileExtension()

AudioFormat * juce::AudioFormatManager::findFormatForFileExtension (const String & fileExtension) const

查找已知格式中哪一个被列为适用于给定文件扩展名。

扩展名前面可以带点，因此 “.wav” 或 “wav” 都可以。

getDefaultFormat()

AudioFormat * juce::AudioFormatManager::getDefaultFormat () const

返回已被设为默认的格式。

你可以在注册格式时将其设为默认。当你想要写入文件时这很有用，因为最佳格式可能因平台而异，例如 Mac 上首选 AIFF，Windows 上则用 WAV。

如果没有设置默认格式，此方法只会返回列表中的第一个。

getWildcardForAllFormats()

String juce::AudioFormatManager::getWildcardForAllFormats () const

返回用于匹配文件的通配符集合，其中包含所有已知格式的扩展名。

例如，如果它只认识 wav 和 aiff，则可能返回 “*.wav;*.aiff”。

createReaderFor() [1/2]

AudioFormatReader * juce::AudioFormatManager::createReaderFor (const File & audioFile)

在已知格式中搜索，尝试为该文件创建合适的读取器。

如果所有已注册的格式都无法打开该文件，则返回 nullptr。调用者负责删除返回的读取器。

createReaderFor() [2/2]

AudioFormatReader * juce::AudioFormatManager::createReaderFor (std::unique_ptr< InputStream > audioFileStream)

在已知格式中搜索，尝试为该流创建合适的读取器。

传入的流对象将由本方法或返回的读取器删除，因此调用者不应保留对它的任何引用。

传入的流必须能够重新定位，以便所有格式都能尝试打开它。

如果所有已注册的格式都无法打开该流，则返回 nullptr。如果返回了读取器，则由调用者负责删除该读取器。
