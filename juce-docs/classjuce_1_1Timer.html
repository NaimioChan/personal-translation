juce::Timer 类参考

详细说明

以指定的时间间隔重复回调某个虚方法。

Timer 的 timerCallback() 方法会按给定间隔被反复调用。创建 Timer 对象后，在调用 startTimer() 方法之前它什么也不做；调用后消息线程会按指定间隔开始回调，直到调用 stopTimer() 或对象被删除。

时间间隔的精度无法保证优于大约 10-20ms，而且如果系统繁忙，实际间隔可能比请求的长得多。由于回调由主消息线程发出，任何阻塞消息队列一段时间的事情也会阻止定时器运行，直到它能继续。

如果你需要让多个不同频率的定时器共用一个回调，MultiTimer 类可以做到——其结构与 Timer 类非常相似，但内部包含多个定时器，每个由一个 ID 号标识。

startTimer()

void juce::Timer::startTimer (int intervalInMilliseconds) noexcept

启动定时器并设置所需间隔长度。

如果定时器已启动，这会重置它，因此从调用此方法到下一次定时器回调之间的时间不会小于传入的间隔长度。

此方法可从任何线程调用。它只影响后续回调的调度时间。回调本身始终在消息线程上运行。

参数
intervalInMilliseconds要使用的间隔（小于 1 的值会向上取整为 1）

stopTimer()

void juce::Timer::stopTimer () noexcept

停止定时器。

此方法可从任何线程调用。它会取消此定时器所有未来的回调。如果消息线程上已有回调正在运行，此方法不会等待它结束，可能在该回调仍在执行时就返回。

不要在回调仍可能运行时从其他线程销毁 Timer（或它使用的数据）。销毁定时器之前，最佳做法是从消息线程停止该定时器。如果 Timer 将从后台线程销毁，可考虑使用 MessageManager::callSync() 在消息线程上调用 stopTimer()。

引用了 Timer()。

被以下对象引用： juce::AnimatedPosition< Behaviour >::beginDrag()、juce::AnimatedPosition< Behaviour >::setPosition()、stopTimer()、juce::StandalonePluginHolder::~StandalonePluginHolder()。
