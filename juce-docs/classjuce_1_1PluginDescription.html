juce::PluginDescription 类参考

详细说明

用于表示某种特定插件类型的一些事实的小型类。

此类用于存储和管理插件的详细信息，而无需实际加载插件实例。

一个 KnownPluginList 包含 PluginDescription 对象的列表。

如果此描述与创建给定标识符字符串的另一个描述等效，则返回 true。

它包含的信息比 XML 编码少，并且与插件的文件位置无关，因此可用于存储插件 ID 以便在不同机器间使用。

uniqueId

int juce::PluginDescription::uniqueId = 0

插件的唯一 ID。

请注意，这在格式之间可能不唯一，例如 VST 和某些其他格式实际上可能具有相同的 id。

uniqueId 字段取代了 deprecatedUid 字段，并修复了 FUID 相同的 VST3 插件会依平台生成不同 uid 值的问题。保留 deprecatedUid 字段是为了向后兼容，使现有宿主可以从旧 uid 迁移到新的 uniqueId。
