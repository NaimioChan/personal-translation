juce::Expression 类参考

详细说明

一个用于动态求值简单数值表达式的类。

此类可以解析涉及浮点数、命名符号和函数的简单 C 风格字符串表达式。支持 +、-、*、/ 基本算术运算以及括号，任何字母数字标识符都被视为命名符号，将在表达式求值时解析。

使用标识符和函数的表达式在求值时需要提供 Expression::Scope 的子类，该对象应能够解析符号名称并执行所用的函数。

adjustedToGiveNewResult()

Expression juce::Expression::adjustedToGiveNewResult (double targetValue, const Scope & scope) const

尝试返回此表达式的副本，但调整某个常量以使表达式解算为目标值。

例如，如果表达式是 "x + 10" 且 x 为 5，那么请求目标值为 8 将返回表达式 "x + 3"。显然有些表达式无法以这种方式反解，此时可能只是通过给原表达式加上一个常量来调整。

bool juce::Expression::referencesSymbol (const Symbol & symbol, const Scope & scope) const

如果此表达式使用了指定符号则返回 true。

如果提供了合适的作用域，搜索将解引用并递归检查所有符号，从而可以确定此表达式在求值的任何层级是否依赖于给定符号。如果 scope 参数为空，则只检查表达式是否包含对该符号的任何直接引用。
