详细说明

template<class ObjectClass, class TypeOfCriticalSectionToUse = DummyCriticalSection>
class juce::ReferenceCountedArray< ObjectClass, TypeOfCriticalSectionToUse >

持有一组派生自 ReferenceCountedObject 的对象，或实现了基本引用计数处理方法的对象。

模板参数指定你要指向的对象的类 —— 让类可引用计数最简单的方法是让它继承 ReferenceCountedObject 或 SingleThreadedReferenceCountedObject，但如果需要，你也可以通过实现名为 incReferenceCount()、decReferenceCount() 和 decReferenceCountWithoutDeleting() 的一组方法来打造自己的可引用计数类。关于这些方法应如何表现的示例，请参见 ReferenceCountedObject。

ReferenceCountedArray 持有派生自 ReferenceCountedObject 的对象，并在对象被添加和移除时负责递增和递减其引用计数。

要使数组的所有方法线程安全，请将“CriticalSection”作为模板化的 TypeOfCriticalSectionToUse 参数传入，而不是默认的 DummyCriticalSection。

sort()

template<class ObjectClass, class TypeOfCriticalSectionToUse> template<class ElementComparator> void juce::ReferenceCountedArray < ObjectClass, TypeOfCriticalSectionToUse >::sort (ElementComparator & comparator, bool retainOrderOfEquivalentItems = false) noexcept

对数组中的元素排序。

这将使用比较器对象将元素排序。传入的对象必须具有以下形式的方法：

int compareElements (ElementType first, ElementType second);

……并且此方法必须返回：

  • 如果第一个先于第二个，则返回值 < 0
  • 如果两个对象等价，则返回值 0
  • 如果第二个先于第一个，则返回值 > 0

为提高性能，compareElements() 方法可以声明为 static 或 const。

参数
comparator用于比较元素的比较器。
retainOrderOfEquivalentItems如果为 true，则比较器认为等价的项将保持它们当前在数组中出现的顺序。这执行起来较慢，但在某些情况下可能很重要。如果为 false，则使用更快的算法，但等价元素可能被重排。
另见
