size_t juce::ARAPlaybackRegion::getNumChildren () const inline override virtual noexcept

返回此对象聚合的 ARA 模型对象的数量。

仅被引用但未被当前对象聚合的对象不计入此数量，例如被引用的 RegionSequence 不算作引用它的 PlaybackRegion 的子对象。

notifyContentChanged()

void juce::ARAPlaybackRegion::notifyContentChanged (ARAContentUpdateScopes scopeFlags, bool notifyARAHost)

将插件发起的内容更新通知给 ARA 宿主和所有监听器。

每当更新内部内容表示时（例如用户编辑了底层音频修改中某个音符的音高之后），插件模型管理代码必须在消息线程上调用此函数。监听器会立即收到通知。如果 notifyARAHost 为 true，则会向宿主排入一条通知，并在其下次轮询更新时发出。

参数
scopeFlags内容更新的范围。
notifyARAHost如果为 true，ARA 宿主将收到内容变更通知。
