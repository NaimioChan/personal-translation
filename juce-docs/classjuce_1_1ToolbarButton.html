juce::ToolbarButton 类参考

详细说明

设计用于放在工具栏上的一种按钮。

这个简单的按钮可以指定两个 Drawable 对象——一个用于正常状态，另一个（可选）用于按钮为切换按钮时的“开”状态。

另见
Toolbar, ToolbarItemFactory, ToolbarItemComponent, Drawable, Button

ToolbarButton()

juce::ToolbarButton::ToolbarButton (int itemId, const String & labelText, std::unique_ptr< Drawable > normalImage, std::unique_ptr< Drawable > toggledOnImage)

创建一个 ToolbarButton。

参数
itemId此工具栏项类型的 ID。会传递给 ToolbarItemComponent 构造函数
labelText按钮上显示的文本（如果工具栏使用的样式会显示文本标签）。会传递给 ToolbarItemComponent 构造函数
normalImage按钮应作为图标使用的可绘制对象。传入的对象将由此对象保留，并在不再需要或删除此按钮时删除。
toggledOnImage如果按钮处于打开状态，按钮可用作图标的一个可绘制对象（见 Button::getToggleState() 方法）。如果此处传入 nullptr，则无论切换状态如何，都会使用普通图像。此处传入的对象将由此对象拥有，并在不再需要或删除此按钮时删除。

被以下对象引用： enablementChanged()。

getToolbarItemSizes()

bool juce::ToolbarButton::getToolbarItemSizes (int toolbarThickness, bool isToolbarVertical, int & preferredSize, int & minSize, int & maxSize) override virtual

此方法必须根据给定的工具栏尺寸和方向，返回此项目的尺寸标准。

preferredSize、minSize 和 maxSize 值都必须由你的实现方法设置。如果工具栏是水平的，这些指的是项目的宽度；对于垂直工具栏，它们指项目的高度。

preferredSize 是组件期望的尺寸，必须介于最小和最大尺寸之间。对于固定尺寸的项目，只需将三个变量设为相同值。

toolbarThickness 参数告知工具栏的深度——等同于调用 Toolbar::getThickness()。

isToolbarVertical 参数告知工具栏是水平还是垂直方向。

实现 juce::ToolbarItemComponent。

引用了 juce::ToolbarItemComponent::isToolbarVertical()。

void juce::ToolbarButton::paintButtonArea (Graphics & g, int width, int height, bool isMouseOver, bool isMouseDown) override virtual

resized()

void juce::ToolbarButton::resized () override virtual

当此组件的大小发生变化时调用。

组件可以实现此方法，以在其宽度或高度变化时执行诸如布局子组件等操作。

此方法是 setBounds 或 setSize 方法的结果，会同步调用，因此反复更改组件大小会反复调用其 resized 方法（不同于重绘之类会合并多次调用的操作）。

如果组件是桌面上的顶级窗口，其大小也可能因应用程序无法控制的操作系统因素而改变。

moved, setSize
