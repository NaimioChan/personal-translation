详细说明

template<typename FloatType>
class juce::dsp::LookupTableTransform< FloatType >

用于近似计算昂贵算术运算的类。

初始化后，该类可以像它所近似的函数一样通过 operator() 使用。

示例：

LookupTableTransform<float> tanhApprox ([] (float x) { return std::tanh (x); }, -5.0f, 5.0f, 64);
auto outValue = tanhApprox (4.2f);

注意：如果你尝试用超出所提供范围的输入调用该函数，它将返回第一个或最后一个记录的 LookupTable 值。

calculateMaxRelativeError()

template<typename FloatType> double juce::dsp::LookupTableTransform < FloatType >::calculateMaxRelativeError (const std::function< FloatType(FloatType)> & functionToApproximate, FloatType minInputValue, FloatType maxInputValue, size_t numPoints, size_t numTestPoints = 0) static

计算指定参数集下近似值的最大相对误差。

返回值越接近零，近似就越精确。

该函数在一系列点上将本类的近似输出与其所近似的函数进行比较，并返回最大相对误差。这可用于判断该近似是否适合给定的问题。通常可以通过增大 numPoints 来提高近似精度。

参数
functionToApproximate被近似的函数。这应是从 FloatType 到 FloatType 的映射。
minInputValue使用的最低输入值。
maxInputValue使用的最高输入值。
numPoints存储的预计算值的数量。
numTestPoints用于误差计算的输入值数量。更大的数值可以提高误差计算的精度。如果为零，则使用 100 * numPoints。

引用了 initialise()。
