详细说明

template<typename FloatType>
class juce::dsp::LookupTable< FloatType >

用于高效近似计算昂贵算术运算的类。

该近似基于预计算值之间的线性插值。近似函数应作为可调用对象连同要预计算的数据点数一起传给构造函数。使用更多点可以提高近似精度，代价是占用更多内存。

考虑使用 LookupTableTransform 作为易于使用的替代方案。

示例：

LookupTable<float> lut ([] (size_t i) { return std::sqrt ((float) i); }, 64);
auto outValue = lut[17];
