juce::DrawableComposite 类参考

详细说明

一个可绘制对象，充当一组其他 Drawable 的容器。

注意，尽管这是一个 Component，它会取得子组件的所有权并负责删除它们，因此你可以把它当作自包含的图形对象使用。其意图是你不要向其中添加自己的组件，只添加其他 Drawable 对象。

getContentBoundsUntransformed()

Rectangle < float > juce::DrawableComposite::getContentBoundsUntransformed () const override virtual

返回此可绘制对象在其原始坐标系中预期占据的区域。

这些边界不受 setDrawableTransform() 影响。

DrawableComposite 会返回 getContentArea() 的值，而基类实现会返回 getDrawableBounds() 的值。

因此，从 SVG 文件解析出的 Drawable 从此函数返回的会是 SVG 的 viewBox。
