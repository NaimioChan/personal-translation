juce::RSAKey 类参考

详细说明

RSA 公钥/私钥密钥对加密类。

此类型的对象构成 RSA 公钥/私钥对的一半。使用 createKeyPair() 方法创建用于编码/解码的匹配对。

如果你需要在网络服务器上配合兼容的加/解密算法使用此类，可以在 PHP 中这样实现同样的功能：

include ('Math/BigInteger.php');  // get this from: phpseclib.sourceforge.net

function applyToValue ($message, $key_part1, $key_part2)
{
    $result = new Math_BigInteger();
    $zero  = new Math_BigInteger();
    $value = new Math_BigInteger (strrev ($message), 256);
    $part1 = new Math_BigInteger ($key_part1, 16);
    $part2 = new Math_BigInteger ($key_part2, 16);

 while (! $value->equals ($zero))
    {
        $result = $result->multiply ($part2);
 list ($value, $remainder) = $value->divide ($part2);
        $result = $result->add ($remainder->modPow ($part1, $part2));
    }

 return ($result->toBytes());
}

……或者在 Java 中用类似这样的代码：

public class RSAKey
{
 static BigInteger applyToValue (BigInteger value, String key_part1, String key_part2)
    {
 BigInteger result = BigInteger.ZERO;
 BigInteger part1 = new BigInteger (key_part1, 16);
 BigInteger part2 = new BigInteger (key_part2, 16);

 if (part1.equals (BigInteger.ZERO) || part2.equals (BigInteger.ZERO)
             || value.compareTo (BigInteger.ZERO) <= 0)
 return result;

 while (! value.equals (BigInteger.ZERO))
        {
            result = result.multiply (part2);
 BigInteger[] div = value.divideAndRemainder (part2);
            value = div[0];
            result = result.add (div[1].modPow (part1, part2));
        }

 return result;
    }
}

在公钥对象上调用此方法以编码数据，然后使用匹配的私钥对象对其解码。

如果操作无法完成，例如该密钥未正确初始化，则返回 false。

注意：此方法只是简单地将此密钥应用于此数据。如果你编码了一些数据，然后试图用不匹配的密钥解码，此方法仍会照常执行并返回 true，但结果不会是你期望的。检查结果是否符合预期是你的责任。

createKeyPair()

void juce::RSAKey::createKeyPair (RSAKey & publicKey, RSAKey & privateKey, int numBits, const int * randomSeeds = nullptr, int numRandomSeeds = 0) static

创建公钥/私钥密钥对。

每个密钥执行的单向加密只能用另一个密钥逆转。

numBits 参数指定密钥大小，例如 128、256、512 位。更大的大小更安全，但此方法执行时间会更长。

randomSeeds 参数允许你选择性地传入一组值来为随机数生成播种，从而提高所生成密钥的安全性。如果提供，请确保提供的值多于 2 个，且提供得越多，安全性越好。

引用了 createKeyPair()、RSAKey()。

被以下对象引用： applyToValue()。
