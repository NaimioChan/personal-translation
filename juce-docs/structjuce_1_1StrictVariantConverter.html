juce::StrictVariantConverter< Type > 结构体模板参考

详细说明

template<typename Type>
struct juce::StrictVariantConverter< Type >

一种辅助类型，可用于实现内部使用 FromVar::convert 和 ToVar::convert 的 VariantConverter 特化。

如果你已为特定类型实现 SerialisationTraits，又不想编写重复该实现的自定义 VariantConverter，可以改为编写：

template <>
struct juce::VariantConverter<MyType> : public juce::StrictVariantConverter<MyType> {};
