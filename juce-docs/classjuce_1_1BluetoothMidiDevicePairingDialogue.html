juce::BluetoothMidiDevicePairingDialogue 类参考

详细说明

打开蓝牙 MIDI 配对对话框，让用户查看并连接当前在附近找到的蓝牙 MIDI 设备。

该对话框会忽略非 MIDI 蓝牙设备。

只有在蓝牙 MIDI 设备完成配对后，其 MIDI 端口才会通过 JUCE 的 MidiInput 和 MidiOutput 类可用。

此对话框目前仅在面向 10.11+ 版本的 macOS、iOS 和 Android 上可用。面向较旧版本的 macOS 时，你应改用“Audio MIDI Setup”应用（位于 /Applications/Utilities）来配对蓝牙 MIDI 设备。在 Windows 上，你应使用系统设置。在 Linux 上，目前不支持蓝牙 MIDI 设备。

open()

bool juce::BluetoothMidiDevicePairingDialogue::open (ModalComponentManager::Callback * exitCallback = nullptr, Rectangle < int > * btWindowBounds = nullptr) static

如果可用，打开蓝牙 MIDI 配对对话框。

参数
exitCallback当模态蓝牙对话框关闭时将被调用的回调。
btWindowBounds将要打开的蓝牙窗口的边界。对话框本身由操作系统打开，因此 JUCE 无法自定义。
返回
如果对话框已打开则为 true，出错时为 false。

isAvailable()

bool juce::BluetoothMidiDevicePairingDialogue::isAvailable () static

检查此平台上是否有可用的蓝牙 MIDI 配对对话框。

在 iOS 上，对于 iOS 8.0 及更高版本，这将为 true。

在 Android 上，仅对 Android SDK 23 及更高版本为 true，并且还要求设备本身支持通过蓝牙传输 MIDI。

在桌面平台上，这通常为 false，因为蓝牙配对不是在应用内完成，而是通过其他方式完成。

返回
如果蓝牙 MIDI 配对对话框可用则为 true，否则为 false。
