compareAndSetBool()

template<typename Type> bool juce::Atomic < Type >::compareAndSetBool (Type newValue, Type valueToCompare) inline noexcept

原子地将此值与目标值比较，如果相等，则将其设为新值。

此操作在原子意义上等同于执行以下操作：

bool compareAndSetBool (Type newValue, Type valueToCompare)
{
 if (get() == valueToCompare)
    {
 set (newValue);
 return true;
    }

 return false;
}

在内部，此方法以 memory_order_seq_cst（最严格的 std::memory_order）调用 std::atomic::compare_exchange_strong。

返回
如果比较为真且值已被替换则返回 true；如果比较失败且值保持不变则返回 false。
