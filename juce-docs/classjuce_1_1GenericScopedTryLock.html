juce::GenericScopedTryLock< LockType > 类模板参考

详细说明

template<class LockType>
class juce::GenericScopedTryLock< LockType >

自动加锁和解锁互斥量对象。

将其之一用作局部变量，以提供基于 RAII 的互斥量加锁。

模板化类可以是 CriticalSection、SpinLock，或任何其他提供 enter() 和 exit() 方法的类。

例如

CriticalSection myCriticalSection;

for (;;)
{
 const GenericScopedTryLock<CriticalSection> myScopedTryLock (myCriticalSection);

 // Unlike using a ScopedLock, this may fail to actually get the lock, so you
 // should test this with the isLocked() method before doing your thread-unsafe
 // action.
 if (myScopedTryLock.isLocked())
    {
       ...do some stuff...
    }
 else
    {
        ...our attempt at locking failed because another thread had already locked it...
    }

 // myCriticalSection gets unlocked here (if it was locked)
}

构造函数与析构函数

GenericScopedTryLock()

template<class LockType> juce::GenericScopedTryLock < LockType >::GenericScopedTryLock (const LockType & lock, bool acquireLockOnInitialisation = true) inline explicit noexcept

创建一个 GenericScopedTryLock。

如果 acquireLockOnInitialisation 为 true，那么一旦创建此 ScopedTryLock，它将尝试用 tryEnter 获取锁。

你可以调用 retryLock 重试获取锁。

当 GenericScopedTryLock 被删除时，锁将被释放（如果已成功获取锁）。

确保此对象由同一线程创建和删除，否则无法保证会发生什么！最好只将其作为局部栈对象使用，而不要用 new() 运算符创建。
