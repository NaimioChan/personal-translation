juce::universal_midi_packets::Block 类参考

详细说明

表示 Function Block Block（FB）或 Group Terminal Block Block（GTB）。

GTB 仅在 USB MIDI 中可用，因此非 USB 传输上的设备不会暴露 GTB 信息。如果设备只暴露 GTB 而不暴露 FB，则 GTB 定义中不可用的任何字段将使用默认值。
