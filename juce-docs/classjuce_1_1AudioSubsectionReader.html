juce::AudioSubsectionReader 类参考

详细说明

此类用于包装 AudioFormatReader，只从文件的一个子区域读取。

因此，如果你有一个能读取 1000 个采样文件的读取器，可以用它包装成只访问例如第 100 到 200 个采样，超出该范围的采样将返回 0。从此读取器访问采样 0 实际上会读取另一个读取器子区域中的第一个采样，该采样可能位于非零位置。

readMaxLevels() [1/2]

void juce::AudioSubsectionReader::readMaxLevels (int64 startSample, int64 numSamples, Range < float > * results, int numChannelsToRead) override virtual

查找音频流某一段中的最高和最低采样电平。

这会从流中读取一块采样，并测量该段中各通道的最高和最低采样电平，以归一化浮点电平的形式返回。

参数
startSample音频流中开始读取的偏移量。它可以超出流的起点或终点。
numSamples要读取的采样数
results该数组将为每个通道填充 Range 值。数组必须包含 numChannels 个元素。
numChannelsToRead要扫描的数据通道数。该值必须大于零，但不能超过读取器包含的通道总数
