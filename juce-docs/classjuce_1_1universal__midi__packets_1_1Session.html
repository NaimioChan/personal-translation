juce::universal_midi_packets::Session 类参考

详细说明

允许创建到端点的新连接，也可创建新的虚拟端点。

会话在内部是引用计数的，这意味着由会话表示的系统资源在 Session 对象以及它创建的每个 Input、Output、VirtualEndpoint、LegacyVirtualInput 和 LegacyVirtualOutput 都被销毁之前不会被释放。

在内部，会话会缓存打开的连接，因此到同一端点的多个 Input 或 Output 将共享与该连接相关的资源。因此，为了尽量减少资源占用，你应创建尽可能少的会话，并在创建新连接时重用它们。为你项目中逻辑上独立的组件保留单独的会话可能仍有意义，例如一个多窗口应用，其中每个窗口都有自己的文档及关联的 MIDI 配置。

createVirtualEndpoint()

VirtualEndpoint juce::universal_midi_packets::Session::createVirtualEndpoint (const String & name, const DeviceInfo & deviceInfo, const String & productInstanceID, PacketProtocol protocol, Span < const Block > initialBlocks, BlocksAreStatic)

如果支持虚拟端点且配置有效，则返回一个新的 VirtualEndpoint。

如果创建端点失败，这将返回一个无效的 VirtualEndpoint。

要真正通过此端点发送和接收消息，请使用 connectInput() 和 connectOutput()，并传入 VirtualEndpoint::getId() 的结果。这将创建一个 Input 或 Output，其用法与任何其它类型的设备相同。

如果功能块是静态的，所有块都必须标记为活动。如果功能块不是静态的，则块最初可以是未激活的。设备处于活动状态期间，声明的功能块数量不得改变，因此如果你需要动态数量的块，请将块布局标记为非静态，并将任何最初未使用的块标记为未激活。

一个端点上最多只允许 32 个块。如果你传入超过 32 个块，此函数将失败。

如果当前平台不支持虚拟设备，此函数也可能失败。

某些平台（较旧的 macOS、较旧的 Linux）支持虚拟 MIDI 1.0 设备但不支持虚拟 UMP 设备。在此类平台上，此函数将失败。你可能希望检查这种情况，并调用 createLegacyVirtualInput() 和/或 createLegacyVirtualOutput() 作为后备。

如果会话未存活，这将总是失败并返回一个未存活的 VirtualEndpoint。

在 Android 上，此函数只会在较新的平台（API 级别 >= 35）上成功。你可能需要调用 Endpoints::setVirtualMidiUmpServiceActive() 使虚拟 UMP 服务可用。你可以使用 EndpointsListener::virtualMidiServiceActiveChanged() 监听虚拟 MIDI 服务的状态变化。在 Android 上，任意时刻最多只能有一个 VirtualEndpoint 存活，尝试创建额外的虚拟端点将失败。

createLegacyVirtualInput()

LegacyVirtualInput juce::universal_midi_packets::Session::createLegacyVirtualInput (const String & name)

创建一个兼容 MIDI 1.0 的输入端口。

在平台 API 支持的情况下，这将显式创建一个单组 MIDI 1.0 端口。

要使用该输入，请将 LegacyVirtualInput::getId() 的结果传给 connectInput()。

有几处特殊情况需要留意：

  • Windows MIDI Services 只允许创建 UMP 端点，而不允许创建 MIDI 1.0 端口，因此在该平台上我们会创建一个带单个 MIDI 1.0 Block 的端点。
  • Android 要求在应用清单中声明虚拟端口。JUCE 声明了一个带单个输入和输出的虚拟字节流设备，以及一个带单个双向端口的虚拟 UMP 设备。默认情况下这些虚拟设备是禁用的，但可以通过调用 Endpoints::setVirtualMidiBytestreamServiceActive() 和 Endpoints::setVirtualMidiUmpServiceActive() 启用。每个服务可用之后，你可以分别恰好创建一个 VirtualEndpoint、一个 LegacyVirtualInput 和/或一个 LegacyVirtualOutput。不支持额外的虚拟端口。
