handleIncomingMidiMessage()

virtual void juce::MidiInputCallback::handleIncomingMidiMessage (MidiInput * source, const MidiMessage & message) pure virtual

接收传入的消息。

当 MIDI 事件到达时，MidiInput 对象会调用此方法。它会在高优先级系统线程上被调用，因此避免在这里做耗时的事情，也避免任何 UI 调用。你可能会发现 MidiBuffer 类有助于将传入消息排队以便稍后使用。

参数
source生成该消息的 MidiInput 对象
message传入的消息。消息的时间戳被设为等同于（Time::getMillisecondCounter() / 1000.0）的值，以指明消息到达的时间

在 juce::AudioProcessorPlayer 和 juce::MidiMessageCollector 中实现。

handlePartialSysexMessage()

virtual void juce::MidiInputCallback::handlePartialSysexMessage (MidiInput * source, const uint8 * messageData, int numBytesSoFar, double timestamp) inline virtual

每当多包 sysex 消息的一个数据包到达时发送的通知。

如果一条长 sysex 消息被拆分为多个数据包，则每到达一个数据包就会调用此回调，直到消息结束，此时将以完整消息调用常规的 handleIncomingMidiMessage() 回调。

传入的消息将包含一个 sysex 的开头，但不会以终止字节 0xf7 结束。
