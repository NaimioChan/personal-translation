juce::midi_ci::ProfileHost 类参考

详细说明

作为 ResponderListener 使用时，此类的实例可以对远程设备发起的 profile 事务组织合适的回复。

ProfileHost 实例还包含用于通知远程设备本地 profile 状态变化的方法。

存储本地设备上各 profile 的当前状态。

void juce::midi_ci::ProfileHost::setProfileEnablement (ProfileAtAddress, int numChannels)

在指定组/通道上激活或停用某个 profile。

该 profile 应已通过 addProfile() 添加。numChannels 为正数将启用该 profile，非正数将停用它。这也包括组和功能块 profile；传入任何正数都将在整个组或块上启用该 profile。

getState()

SupportedAndActive juce::midi_ci::ProfileHost::getState (ProfileAtAddress profileAtAddress) const inline

返回指定组/通道上给定 profile 受支持且已激活的通道数量。

如果受支持的通道数为 0，则该 profile 在该组/通道上不受支持。

如果已激活的通道数为 0，则该 profile 在该组/通道上未激活。

引用了 juce::midi_ci::ProfileAtAddress::address、juce::midi_ci::ProfileAtAddress::profile。
