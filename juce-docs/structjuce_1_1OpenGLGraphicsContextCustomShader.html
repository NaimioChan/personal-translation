juce::OpenGLGraphicsContextCustomShader 结构体参考

详细说明

用于创建与 OpenGL 2D 渲染上下文配合使用的自定义着色器。

给定基于 GL 的渲染上下文，你可以编写一个片段着色器来应用某种逐像素效果。

构造函数与析构函数

OpenGLGraphicsContextCustomShader()

juce::OpenGLGraphicsContextCustomShader::OpenGLGraphicsContextCustomShader (const String & fragmentShaderCode)

创建自定义着色器。

着色器代码直到真正需要时才会编译，因此在没有活动 GL 上下文时调用此构造函数是可以的。

代码应为普通的片段着色器。除了通常的 GLSL 变量外，还自动声明了一个名为 "pixelPos" 的 varying vec2，表示正在绘制的像素在图形上下文中的像素位置。还有一个 varying 值 "pixelAlpha"，表示该像素应与之相乘的 alpha，使任何裁剪区域遮罩的边缘都能正确抗锯齿。
