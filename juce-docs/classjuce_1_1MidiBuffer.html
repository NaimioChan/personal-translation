juce::MidiBuffer 类参考

详细说明

保存一串带时间戳的 MIDI 事件。

与 AudioBuffer 类似，它保存一组带整数时间戳的 MIDI 事件。缓冲区始终保持按时间戳排序。

如果你处理的 MIDI 事件序列可能需要被操作，或需要读写到 MIDI 文件，那么 MidiMessageSequence 可能是更合适的容器。MidiBuffer 是为更底层的原始 MIDI 数据流设计的。

addEvent() [1/2]

bool juce::MidiBuffer::addEvent (const MidiMessage & midiMessage, int sampleNumber)

向缓冲区中添加一个事件。

采样编号用于确定事件在缓冲区中的位置，缓冲区始终保持有序。MidiMessage 的时间戳会被忽略。

如果添加的事件的采样位置与缓冲区中已有一个或多个事件相同，则新事件会被放在这些已有事件之后。

要读取事件，请使用 MidiBufferIterator 对象。

成功时返回 true，失败时返回 false。

addEvent() [2/2]

bool juce::MidiBuffer::addEvent (const void * rawMidiData, int maxBytesOfMidiData, int sampleNumber)

从原始 MIDI 数据向缓冲区中添加一个事件。

采样编号用于确定事件在缓冲区中的位置，缓冲区始终保持有序。

如果添加的事件的采样位置与缓冲区中已有一个或多个事件相同，则新事件会被放在这些已有事件之后。

会检查事件数据以计算该 MIDI 事件实际占用的字节数，因此 maxBytesOfMidiData 可能长于实际存储的数据。例如，传入一个 note-on 和 4 字节的长度，实际只会存储 3 字节。如果 MIDI 数据无效，则可能根本不添加事件。

要读取事件，请使用 MidiBufferIterator 对象。

成功时返回 true，失败时返回 false。

引用了 MidiBuffer()。

addEvents()

void juce::MidiBuffer::addEvents (const MidiBuffer & otherBuffer, int startSample, int numSamples, int sampleDeltaToAdd)

从另一个缓冲区向本缓冲区添加一批事件。

参数
otherBuffer包含要添加事件的缓冲区
startSample源缓冲区中要添加事件的最低采样编号。时间戳小于该值的源事件都会被忽略
numSamples源缓冲区中要添加事件的采样有效范围，即源缓冲区中时间戳大于或等于 (startSample + numSamples) 的事件都会被忽略。如果该值小于 0，则取 startSample 之后的所有事件。
sampleDeltaToAdd会加到被添加到本缓冲区的事件的源时间戳上的值

引用了 addEvents()、MidiBuffer()。

被以下对象引用： isEmpty()。
