成员函数

generateKeyFile()

String JUCE_CALLTYPE juce::KeyGeneration::generateKeyFile (const String & appName, const String & userEmail, const String & userName, const String & machineNumbers, const RSAKey & privateKey) static

生成密钥文件的内容，可发送到用户机器以解锁产品。

返回值是一段文本，包含一个经 RSA 编码的块，后面跟一些人类可读的详细信息。如果你把这段文本传给 OnlineUnlockStatus::applyKeyFile()，它会解密该文本；若密钥匹配且机器编号匹配，就会解锁该机器。

通常在服务器上的用法是构建一个小型可执行文件，它仅调用此方法并打印结果，这样 Web 服务器就可以用该结果作为产品自动注册机制的回复。keyGenerationAppMain() 函数就是构建此类函数的示例。

generateExpiringKeyFile()

String JUCE_CALLTYPE juce::KeyGeneration::generateExpiringKeyFile (const String & appName, const String & userEmail, const String & userName, const String & machineNumbers, const Time expiryTime, const RSAKey & privateKey) static

与上面的密钥文件生成方法类似，但带有到期时间。

你必须提供一个 Time，超过该时间后此密钥文件不再被视为有效。

注意：当应用被到期密钥文件解锁时，OnlineUnlockStatus::isUnlocked 仍会返回 false。此后你必须检查 OnlineUnlockStatus::getExpiryTime，看此到期密钥文件是否仍在有效期内，并据此处理。

keyGenerationAppMain()

int juce::KeyGeneration::keyGenerationAppMain (int argc, char * argv []) inline static

这是一个简单的密钥生成器实现，你可以轻松地将其包装进命令行 main() 函数，以便在服务器上使用。

例如，你可以在名为 "unlocker" 的命令行应用中使用它，然后这样调用：

unlocker MyGreatApp joebl.nosp@m.oggs.nosp@m.@foob.nosp@m.ar.c.nosp@m.om Joe_Bloggs 1234abcd,95432ff 22d9aec92d986dd1,923ad49e9e7ff294c

引用了 juce::StringArray::add()、generateKeyFile()、juce::StringArray::size()。
