juce::Span< Value, Extent > 类模板参考

详细说明

template<typename Value, size_t Extent = dynamicExtent>
class juce::Span< Value, Extent >

对存储在 Array 或 vector 或其他类似容器中的连续对象的非拥有视图。

这有点类似 C++20 的 std::span，但接口更有限。

本类的文档由以下文件生成：
  • juce_core/containers/juce_Span.h

继承 juce::detail::NumBase< dynamicExtent >。
