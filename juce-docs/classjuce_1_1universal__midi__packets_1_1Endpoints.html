juce::universal_midi_packets::Endpoints 类参考

详细说明

系统已知的 Endpoints。

用此来定位能够发送和接收 MIDI 消息的硬件和软件设备。

调用 makeSession() 创建一个管理到这些设备连接的会话。

getEndpoint()

std::optional< Endpoint > juce::universal_midi_packets::Endpoints::getEndpoint (const EndpointId &) const

获取某个特定端点的信息，如果信息不可用则返回 nullopt。

目前，在 Android 上对于已连接但未打开的 UMP 设备，此函数可能返回 nullopt。

如果你要在面向用户的列表中显示端点名称，建议在 getEndpoint() 返回值时使用 Endpoint 名称。否则，如果 getStaticDeviceInformation() 返回值，可以使用 StaticDeviceInformation 名称。如果两个函数都返回 nullopt，说明设备未知或已断开连接。

getBackend()

std::optional< Backend > juce::universal_midi_packets::Endpoints::getBackend () const

返回此平台上与 MIDI 设备通信所使用的技术。

这主要在 Windows 上相关，那里有多种不同的 MIDI 实现。

此 getter 的预期用途是让程序检测 Windows MIDI Services（WMS）是否已激活并正在运行。如果 WMS 初始化失败，实现将回退到更早、功能更有限的实现。程序可能希望检测这种情况，以便引导用户安装 WMS SDK。

如果没有可用的 MIDI 技术，则返回 nullopt。

isVirtualMidiBytestreamServiceActive()

bool juce::universal_midi_packets::Endpoints::isVirtualMidiBytestreamServiceActive () const

只有当此函数返回 true 时，创建虚拟旧式端口才会成功。

在支持虚拟 MIDI 连接的平台上（macOS、iOS、ALSA、Windows MIDI Services），这通常返回 true。在不支持虚拟 MIDI 的平台上（较旧的 Windows MIDI API），这总是返回 false。在 Android 上，在虚拟 MIDI 服务启动之前这返回 false，服务运行期间返回 true。你可以监听 virtualMidiServiceActiveChanged()，以便在服务状态变化时采取行动（例如创建或销毁虚拟端口）。

isVirtualMidiUmpServiceActive()

bool juce::universal_midi_packets::Endpoints::isVirtualMidiUmpServiceActive () const

只有当此函数返回 true 时，创建虚拟 UMP 端点才会成功。

在支持虚拟 MIDI 连接的较新平台上（较新的 macOS 和 iOS、较新的 ALSA、Windows MIDI Services），这通常返回 true。在不支持虚拟 MIDI 的平台上（较旧的 Windows MIDI API），这总是返回 false。在 Android 上，在虚拟 MIDI 服务启动之前这返回 false，服务运行期间返回 true。你可以监听 virtualMidiServiceActiveChanged()，以便在服务状态变化时采取行动（例如创建或销毁虚拟端口）。

setVirtualMidiBytestreamServiceActive()

void juce::universal_midi_packets::Endpoints::setVirtualMidiBytestreamServiceActive (bool)

默认情况下，Android MIDI 服务初始为禁用状态，但可通过调用此函数并传入 true 来启用。

此函数是 not synchronous 的，因此服务将在此函数返回后的某个时间点启动或停止。要查明服务状态何时变化，请监听 virtualMidiServiceActiveChanged() 并检查 isVirtualMidiBytestreamServiceActive() 的结果。

在 Android 以外的平台上，此调用不做任何事。

setVirtualMidiUmpServiceActive()

void juce::universal_midi_packets::Endpoints::setVirtualMidiUmpServiceActive (bool)

默认情况下，Android MIDI 服务初始为禁用状态，但可通过调用此函数并传入 true 来启用。

此函数是 not synchronous 的，因此服务将在此函数返回后的某个时间点启动或停止。要查明服务状态何时变化，请监听 virtualMidiServiceActiveChanged() 并检查 isVirtualMidiUmpServiceActive() 的结果。在不支持虚拟 UMP 的 Android 版本（API 级别 < 35）上，此调用不做任何事。

在 Android 以外的平台上，此调用不做任何事。
