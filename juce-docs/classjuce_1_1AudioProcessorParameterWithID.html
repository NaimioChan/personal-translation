getParameterID()

String juce::AudioProcessorParameterWithID::getParameterID () const inline override virtual

返回此参数唯一的 ID。

参数索引在插件版本之间不稳定，这意味着在某个插件版本中位于特定索引处的参数，可能在后续版本中移动到不同的索引。

与参数索引不同，此函数返回的 ID 应相对稳定（取决于插件格式），因此更适合存储/召回自动化数据。
