juce::ScopedWriteLock 类参考

详细说明

自动锁定和解锁一个 ReadWriteLock 对象。

将其中的一个用作局部变量，以控制对 ReadWriteLock 的访问。

例如

ReadWriteLock myLock;

for (;;)
{
 const ScopedWriteLock myScopedLock (myLock);
 // myLock is now locked

    ...do some stuff...

 // myLock gets unlocked here
}

构造函数与析构函数

ScopedWriteLock()

juce::ScopedWriteLock::ScopedWriteLock (const ReadWriteLock & lock) inline explicit noexcept

创建一个 ScopedWriteLock。

它一经创建就会调用 ReadWriteLock::enterWrite()，而当 ScopedWriteLock 对象被删除时，ReadWriteLock 将被解锁。

确保此对象由同一线程创建和删除，否则无法保证会发生什么！最好只将其作为局部栈对象使用，而不要用 new() 运算符创建。

~ScopedWriteLock()

juce::ScopedWriteLock::~ScopedWriteLock () inline noexcept

析构函数。

析构函数被调用时，将调用 ReadWriteLock 的 exitWrite() 方法。

确保此对象由同一线程创建和删除，否则无法保证会发生什么！
