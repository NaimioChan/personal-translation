详细说明

template<class ElementType, class TypeOfCriticalSectionToUse>
class juce::ArrayAllocationBase< ElementType, TypeOfCriticalSectionToUse >

实现一些基本的数组存储分配函数。

此类并非真正供公开使用 —— 它曾是容器类的一部分，但后来已被 ArrayBase 取代。最终它将从 API 中移除。

ensureAllocatedSize()

template<class ElementType, class TypeOfCriticalSectionToUse> void juce::ArrayAllocationBase < ElementType, TypeOfCriticalSectionToUse >::ensureAllocatedSize (int minNumElements) inline

如果分配的存储量小于给定数量，则增加它。

这将保留数组中当前持有的任何数据，但会在末尾添加额外空间，以确保其至少与传入的大小一样大。如果它已经更大，则不采取任何操作。
