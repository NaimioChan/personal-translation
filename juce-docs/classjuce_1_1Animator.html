juce::Animator 类参考

详细说明

用于管理通过各 builder 类创建的各种动画器生命周期的包装类。

它使用引用计数。复制一个 Animator 时，得到的对象会指向同一个底层实例，并且只要还有 Animator 对象引用它，该底层实例就保证有效。

Animator 对象可以注册到 AnimatorUpdater，后者只保存对底层实例的弱引用。如果某个 AnimatorUpdater 引用了该底层实例，而它因为所有 Animator 对象都被删除而遭摧毁，更新器会自动把它从队列中移除，不需要手动移除。

成员枚举

Status

enum class juce::Animator::Status strong

Animator 的状态，它决定各 AnimatorUpdater 与其他 Animator 会如何与之交互。

枚举值
idle 

Animator 处于空闲状态，即使挂在 AnimatorUpdater 上，状态也不会推进。

inProgress 

Animator 处于活动状态，每当其更新函数被调用时状态就向前推进。

finished 

Animator 已完成运行，可能会调用其 onCompletion 回调。

它不再需要调用其更新函数。

start()

void juce::Animator::start () const

把 Animator 标记为可启动。

你必须调用此函数，Animator 才能脱离空闲状态。

调用此函数后，Animator 的启动回调会在下一次更新时执行，紧接着是对其更新函数的首次调用。

你可以在把 Animator 加入 AnimatorUpdater 之前或之后调用此函数。在 start() 被调用之前，Animator 只会闲置在更新器的队列里。

complete()

void juce::Animator::complete () const

把 Animator 标记为可完成。

ValueAnimator 在进度达到 >= 1.0 时会自动完成，除非它无限运行。AnimatorSet 在其所有组成动画器完成后也会自行完成。

用此函数可以让 Animator 快速走完。调用后 isComplete 会返回 true，并且保证你会收到一次进度值为 1.0 的更新回调，随后执行 onComplete 回调。

update()

Status juce::Animator::update (double timestampMs) const

由 AnimatorUpdater 各类为活动中的动画器定时调用。

传入的时间戳必须单调递增。底层 Animator 据此跟踪通向完成的进度。

特殊情况下你可以自己调用此函数，但通常你会想让 AnimatorUpdater 来调用。使用 VBlankAnimatorUpdater 可以保证 update 与显示器的垂直刷新同步调用，从而得到平滑的动画。

另见
AnimatorUpdater, VBlankAnimatorUpdater

isComplete()

bool juce::Animator::isComplete () const

如果 Animator 已经到达完成点，就返回 true：这可能是因为对它调用了 complete()，也可能（对 ValueAnimator 而言）是因为进度达到了 >= 1.0。

通常不需要调用此函数，因为已完成的 Animator 无论如何都会收到一次进度值为 1.0 的更新回调，随后调用完成回调。
