juce::ToolbarItemFactory 类参考

详细说明

可创建 ToolbarItemComponent 对象的工厂对象。

ToolbarItemFactory 的子类会公布一组它可以创建的工具栏项类型。

每种项目类型由唯一 ID 标识，同一种项目类型可以同时存在多个实例（甚至在同一工具栏上，例如间隔或分隔条）。

Toolbar, ToolbarItemComponent, ToolbarButton

getAllToolbarItemIds()

virtual void juce::ToolbarItemFactory::getAllToolbarItemIds (Array < int > & ids) pure virtual

必须返回此工厂可创建的所有项目类型的 ID 列表。

ID 应添加到传入的数组中。

项目 ID 可以是你选择的任何整数，但 0 除外（0 被视为空 ID），以及 SpecialItemIds 枚举中的预定义 ID。

如果希望工具栏能包含内置类型（separatorBarId、spacerId 和 flexibleSpacerId），还应将它们添加到此列表中。

此处返回的列表由 ToolbarItemPalette 类用于获取可用项目列表，它们在调色板上的顺序将反映其在此列表中的顺序。

另见
ToolbarItemPalette

getDefaultItemSet()

virtual void juce::ToolbarItemFactory::getDefaultItemSet (Array < int > & ids) pure virtual

必须返回应作为默认集添加到工具栏的项目集。

此方法由 Toolbar::addDefaultItems() 用于确定要创建哪些项目。

你的方法添加到传入数组中的项目将以相同顺序添加到工具栏。项目可在此列表中出现多次。

createItem()

virtual ToolbarItemComponent * juce::ToolbarItemFactory::createItem (int itemId) pure virtual

必须创建工厂在其 getAllToolbarItemIds() 方法中列出的某个项目的实例。

itemId 参数可以是你的 getAllToolbarItemIds() 方法列出的任何值，但 SpecialItemIds 枚举中的内置项目类型除外，它们由工具栏代码内部创建。

尽量不要保留返回对象的指针，因为它会被工具栏自动删除；并请记住，同一项目类型很可能同时存在多个实例。
