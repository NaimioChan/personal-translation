详细说明

路径是一系列直线和曲线的序列，它们可以构成闭合形状，也可以是开放式的。

要使用路径，你可以先创建一个空路径，然后向其中添加直线和曲线来构成形状，之后它可以由 Graphics 上下文渲染，或用于几何运算。

例如

Path myPath;

myPath.startNewSubPath (10.0f, 10.0f);          // move the current position to (10, 10)
myPath.lineTo (100.0f, 200.0f);                 // draw a line from here to (100, 200)
myPath.quadraticTo (0.0f, 150.0f, 5.0f, 50.0f); // draw a curve that ends at (5, 50)
myPath.closeSubPath();                          // close the subpath with a line back to (10, 10)

// add an ellipse as well, which will form a second sub-path within the path
myPath.addEllipse (50.0f, 50.0f, 40.0f, 30.0f);

// double the width of the whole thing
myPath.applyTransform (AffineTransform::scale (2.0f, 1.0f));

// and draw it to a graphics context with a 5-pixel thick outline
g.strokePath (myPath, PathStrokeType (5.0f));

一个路径对象实际上可以包含多条子路径，这些子路径本身可以是开放的或闭合的。

bool juce::Path::contains (float x, float y, float tolerance = defaultToleranceForTesting) const

检查某个点是否位于路径内。

closeSubPath()

void juce::Path::closeSubPath ()

用一条回到起点的直线闭合当前子路径。

创建三角形这样的闭合形状时，不要用 3 次 lineTo() 调用——而应使用两次 lineTo() 调用，随后用 closeSubPath() 将最后的点连回起点。

这确保闭合形状能被识别为闭合，这对于绘制描边等任务很重要，因为描边需要知道是否要绘制端帽。

preallocateSpace()

void juce::Path::preallocateSpace (int numExtraCoordsToMakeSpaceFor)

为向路径添加给定数量的坐标预分配足够空间。

如果你即将向路径添加大量直线或曲线，先调用此方法可以大大提高效率，避免结构增长时昂贵的重新分配。实际要传入的值有点难以计算，因为所需空间取决于你要添加的内容——例如每个 lineTo() 或 startNewSubPath() 需要 3 个坐标（x、y 和一个类型标记）。每个 quadraticTo() 需要 5 个，而 cubicTo() 需要 7 个。闭合子路径需要 1 个。

setUsingNonZeroWinding()

void juce::Path::setUsingNonZeroWinding (bool isNonZeroWinding) noexcept

更改填充路径时使用的环绕规则。

如果设为 true（默认值），路径使用非零环绕规则来判断哪些点位于路径内部。如果设为 false，则使用交替环绕规则。

当形状的某些区域与其他区域重叠时，环绕规则就会起作用，它决定重叠区域被视为内部还是外部。

修改该值只是设置一个标志，不会影响路径的内容。
