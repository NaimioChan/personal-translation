juce::dsp::StateVariableTPTFilter< SampleType > 类模板参考

详细说明

template<typename SampleType>
class juce::dsp::StateVariableTPTFilter< SampleType >

一个 IIR 滤波器，可对音频信号执行低通、带通和高通滤波，每倍频程衰减 12 dB，使用 TPT 结构，专为快速调制而设计（更多信息参见 Vadim Zavalishin 关于 TPT 结构的文档）。

其行为基于模拟状态变量滤波器电路。

注意：此处的带通并非 RBJ CookBook 中的带通，因为其增益可能高于 0 dB。要获得经典的 0 dB 带通，需要将结果乘以 R2。

注意 2：使用该类可以避免在使用其他滤波器仿真结构和 IIR 滤波器类改变截止频率时常见的某些响亮音频伪影。不过，该类在改变截止频率时可能仍需要额外平滑。

另见 IIRFilter、SmoothedValue
