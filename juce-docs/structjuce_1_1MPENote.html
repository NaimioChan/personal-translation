juce::MPENote 结构体参考

详细说明

该结构体表示一个正在发声的 MPE 音符。

音符由唯一 ID 标识，或者由 MIDI 通道和初始音符标识。它具有五个维度的连续表现力控制。其当前值表示为 MPEValue 对象。

MPENote() [1/2]

juce::MPENote::MPENote (int midiChannel, int initialNote, MPEValue velocity, MPEValue pitchbend, MPEValue pressure, MPEValue timbre, KeyState keyState = MPENote::keyDown) noexcept

构造函数。

参数
midiChannel音符的 MIDI 通道，介于 2 和 15 之间。（通道 1 和通道 16 在 MPE 中永远不能作为音符通道。）
initialNoteMIDI 音符编号，介于 0 和 127 之间。
velocity该音符的 note-on 力度。
pitchbend该音符初始的逐音符弯音。
pressure该音符的初始压力。
timbre该音符的音色值。
keyState音符的键状态（键是否按下和/或音符是否被保持）。该值不能为 MPENote::off，因为你正在触发一个新音符。（若未指定，默认值将是 MPENote::keyDown。）

引用了 initialNote、keyDown、keyState、midiChannel、pitchbend、pressure、timbre。

被以下对象引用： operator!=()、operator==()。

pitchbend

MPEValue juce::MPENote::pitchbend { MPEValue::centreValue () }

该音符当前的逐音符弯音（以 MIDI 弯音轮位置的单位表示）。

该维度可在音符发声期间被调制。

注意：此值不考虑当前使用的弯音范围，也不考虑可能同时施加的额外主弯音。要计算 MPENote 的实际有效弯音，你大概应该改用成员 totalPitchbendInSemitones。

noteOffVelocity

MPEValue juce::MPENote::noteOffVelocity { MPEValue::minValue () }

收到 note-off 之后该音符的释放力度（“lift”）。

只有在收到该音符的 note-off 之后（且 keyState 被设为 MPENote::off 或 MPENote::sustained），该维度才会有有意义的值。初始时该值未定义。

totalPitchbendInSemitones

double juce::MPENote::totalPitchbendInSemitones

该音符当前的有效弯音，以半音为单位，相对于 initialNote。

你应使用此值来计算音符的实际有效音高。该值由 MPEInstrument 计算并设为逐音符弯音值（存储在 MPEValue::pitchbend 中）与该 MPE 区域主弯音之和，二者分别按该区域的逐音符弯音范围和主弯音范围加权。
