parameterValueChanged()

void juce::AudioProcessor::ParameterChangeForwarder::parameterValueChanged (int parameterIndex, float newValue) override virtual

当参数已更改时接收回调。

重要提示：这将在参数变化时同步调用，而许多音频处理器会在音频回调期间更改其参数。这意味着你的处理程序代码不仅要完全线程安全，还必须非常快并避免阻塞。如果你需要在消息线程上处理此事件，请使用此回调触发 AsyncUpdater 或 ChangeBroadcaster，然后在消息线程上响应。

void juce::AudioProcessor::ParameterChangeForwarder::parameterGestureChanged (int parameterIndex, bool gestureIsStarting) override virtual

指示参数更改手势已开始。

例如，如果用户正在拖动滑块，则在首次按下鼠标按钮时会以 gestureIsStarting 为 true 调用此方法，而在释放时会以 gestureIsStarting 为 false 再次调用。

重要提示：这将同步调用，而许多音频处理器会在音频回调期间调用它。这意味着你的处理程序代码不仅要完全线程安全，还必须非常快并避免阻塞。如果你需要在消息线程上处理此事件，请使用此回调触发 AsyncUpdater 或 ChangeBroadcaster，稍后在消息线程上响应。
