juce::ReferenceCountedObject 类参考

详细说明

提供引用计数方法的基类。

要为某个类添加引用计数，请让它派生自此基类，并使用 ReferenceCountedObjectPtr 类指向它。

例如

class MyClass : public ReferenceCountedObject
{
 void foo();

 // This is a neat way of declaring a typedef for a pointer class,
 // rather than typing out the full templated name each time.
 using Ptr = ReferenceCountedObjectPtr<MyClass>;
};

MyClass::Ptr p = new MyClass();
MyClass::Ptr p2 = p;
p = nullptr;
p2->foo();

一旦有新的 ReferenceCountedObject 被赋给某个指针，就要小心不要手动删除该对象。

此类使用 Atomic<int> 值来保存引用计数，因此引用计数可以在多个线程上更新。注意，虽然跨线程共享的 ReferenceCountedObject 上创建和删除 ReferenceCountedObjectPtr 是线程安全的，但修改或交换 ReferenceCountedObject 并非线程安全。

若需要更快但非线程安全的版本，请改用 SingleThreadedReferenceCountedObject。

另见
ReferenceCountedObjectPtr, ReferenceCountedArray, SingleThreadedReferenceCountedObject
