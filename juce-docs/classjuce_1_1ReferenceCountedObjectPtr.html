juce::ReferenceCountedObjectPtr< ObjectType > 类模板参考

详细说明

template<class ObjectType>
class juce::ReferenceCountedObjectPtr< ObjectType >

一个指向引用计数对象的智能指针类。

模板参数指定你要指向的对象的类 —— 让类可引用计数最简单的方法是让它继承 ReferenceCountedObject 或 SingleThreadedReferenceCountedObject，但如果需要，你也可以通过实现名为 incReferenceCount()、decReferenceCount() 和 decReferenceCountWithoutDeleting() 的一组方法来打造自己的可引用计数类。关于这些方法应如何表现的示例，请参见 ReferenceCountedObject。

使用此类时，你可能想创建一个 typedef 来缩写完整的模板名 —— 例如

struct MyClass  : public ReferenceCountedObject
{
 using Ptr = ReferenceCountedObjectPtr<MyClass>;
    ...
}

ReferenceCountedObject, ReferenceCountedObjectArray
