juce::NetworkServiceDiscovery::Advertiser 结构体参考

详细说明

一个对象，运行一个线程来反复广播可发现服务的存在。

使用时，只需创建一个 Advertiser 实例，它就会持续广播，直到你删除它。

Advertiser()

juce::NetworkServiceDiscovery::Advertiser::Advertiser (const String & serviceTypeUID, const String & serviceDescription, int broadcastPort, int connectionPort, RelativeTime minTimeBetweenBroadcasts = RelativeTime::seconds (1.5))

创建并启动一个 Advertiser 线程，按给定属性进行广播。

参数
serviceTypeUID用户提供的字符串，用于定义此服务代表的类型
serviceDescription会出现在客户端 Service::description 字段中的描述字符串
broadcastPort用于广播服务发现数据包的端口号
connectionPort将发送出去、出现在 Service::port 字段中的端口号
minTimeBetweenBroadcasts发送广播消息之间的等待间隔

引用了 juce::RelativeTime::seconds()。
