getLocalMachineIDs()

StringArray juce::OnlineUnlockStatus::MachineIDUtilities::getLocalMachineIDs () static

此方法基于网络 MAC 地址、硬盘 ID 等信息计算一些机器 ID，但如果你愿意，也可以重载它以生成自己的 ID 列表。

返回的 ID 应是简短的字母数字字符串，不含任何标点字符。由于用户可能需要手动输入，比较时会忽略大小写。

注意，列表中的第一项被视为「主」ID，也就是展示给用户并向 marketplace Web 服务器注册的那个 ID。后续 ID 仅作为后备，用于避免在产品首次注册后机器硬件发生增删时，检查注册状态出现误判。
