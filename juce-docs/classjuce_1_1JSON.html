juce::JSON 类参考

详细说明

包含用于在 var 对象与 JSON 格式文本之间相互转换的静态方法。

var 类在结构上与 JSON 格式数据兼容，因此这些函数允许你将 JSON 解析为 var 对象，也可将 var 对象转换为 JSON 格式文本。

成员函数

parse() [1/4]

Result juce::JSON::parse (const String & text, var & parsedResult) static

解析一段 JSON 格式文本，并返回包含解析错误的结果代码。

这将在 parsedResult 参数中返回解析后的结构，并返回一个 Result 对象以指示解析是否成功，若不成功，其中将包含错误消息。

如果你不关心错误消息，可以使用其他快捷 parse 方法，它们在解析失败时只返回 var()。

注意，这只解析合法的 JSON，也就是说给定的项必须是对象或数组定义。如果还想解析任意类型的原始 JSON 对象，请使用 fromString() 方法。

被以下对象引用： juce::midi_ci::Encodings::jsonFrom7BitText()。

toString() [1/2]

String juce::JSON::toString (const var & objectToFormat, bool allOnOneLine = false, int maximumDecimalPlaces = 15) static

返回一个字符串，其中包含 var 对象的 JSON 格式表示。

如果 allOnOneLine 为 true，结果将压缩为一行文本，不含回车符。如果为 false，则会以更易读的格式排版。maximumDecimalPlaces 参数决定科学计数法中浮点数的精度。
