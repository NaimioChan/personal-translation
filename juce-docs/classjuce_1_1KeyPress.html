juce::KeyPress 类参考

详细说明

表示一次按键，包括所需的任何修饰键。

例如，一个 KeyPress 可以表示 CTRL+C、SHIFT+ALT+H、空格键、Escape 等。

另见
Component, KeyListener, KeyPressMappingSet, Button::addShortcut

KeyPress() [2/4]

juce::KeyPress::KeyPress (int keyCode, ModifierKeys modifiers, juce_wchar textCharacter) noexcept

为某个键和一些修饰键创建 KeyPress。

例如 CTRL+C 为：KeyPress ('c', ModifierKeys::ctrlModifier, 0) SHIFT+Escape 为：KeyPress (KeyPress::escapeKey, ModifierKeys::shiftModifier, 0)

参数
keyCode代表该键的代码——此值必须是本类中列出的特殊常量之一，或 8 位字符代码，例如字母（忽略大小写）、数字或“,”、“.”这样的简单键。注意，这与 textCharacter 参数不同，例如键码为 'a' 且带 Shift 修饰键时，textCharacter 的值应为 'A'。
modifiers要与该按键关联的修饰键
textCharacter如果将此按键输入文本编辑器时会打印出的字符。如果该按键是非打印字符，此值可能为 null
另见
getKeyCode, isKeyCode, getModifiers

createFromDescription()

KeyPress juce::KeyPress::createFromDescription (const String & textVersion) static

将文本形式的键描述转换为 KeyPress。

这会尝试解码按键的文本形式，例如 "ctrl + c" 或 "spacebar"。

它并非设计用来处理任意输入，而应传入由 getTextDescription() 方法创建的字符串。

如果字符串无法解析，返回的对象将是无效的。

另见
getTextDescription

引用了 KeyPress()。

getTextDescription()

String juce::KeyPress::getTextDescription () const

创建该键组合的文本描述。

例如 "ctrl + c" 或 "delete"。

要将按键存储到文件中，请使用此方法，并配合 createFromDescription() 稍后取回。

getTextDescriptionWithIcons()

String juce::KeyPress::getTextDescriptionWithIcons () const

创建该键组合的文本描述，尽可能使用 Unicode 图标符号。

在 OSX 上，这会使用 Apple 的 command、option、shift 等符号，而不是 getTextDescription() 返回的文本修饰键描述

isCurrentlyDown()

bool juce::KeyPress::isCurrentlyDown () const

检查用户当前是否按住了组成此 KeyPress 的键。

注意，如果按下了任何额外的修饰键，这将返回 false——例如，如果按键是 CTRL+X 而用户实际按住的是 CTRL+ALT+x，则结果为 false。

isKeyCurrentlyDown()

键码的值可以是本类中定义的特殊常量之一，或 8 位字符代码。
