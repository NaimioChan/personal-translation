handleNoteOn()

virtual void juce::MidiKeyboardState::Listener::handleNoteOn (MidiKeyboardState * source, int midiChannel, int midiNoteNumber, float velocity) pure virtual

当 MidiKeyboardState 的某个琴键被按下时调用。

当状态在处理 MidiKeyboardState::processNextMidiBuffer() 方法中的缓冲区，或用 MidiKeyboardState::noteOn() 方法演奏音符时，会同步调用它。

注意，该回调可能来自音频回调线程，因此注意不要阻塞，并避免在回调中进行任何 UI 活动。

在 juce::MidiMessageCollector 中实现。

引用了 juce::MidiKeyboardState::MidiKeyboardState()。
