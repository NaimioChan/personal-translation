writeEscapeChars()

void juce::CppTokeniserFunctions::writeEscapeChars (OutputStream & out, const char * utf8, const int numBytesToRead, const int maxCharsOnLine, const bool breakAtNewLines, const bool replaceSingleQuotes, const bool allowStringBreaks) inline static

接受一个 UTF8 字符串，对所有非 ASCII 字节使用标准 C++ 转义序列，然后写入流。

虽然严格来说它并不是分词函数，但在处理 C++ 代码时同样经常派得上用场！

注意，如果你处理的是 String，addEscapeChars() 比这个函数更易用。
