juce::universal_midi_packets::Endpoint 类参考

详细说明

表示单个 MIDI 端点，它最多可有一个输入和一个输出。

Endpoint 对象只保存创建 Endpoint 实例那一刻物理端点最后已知状态的快照。比起存储 Endpoint 实例，更好的做法是存储一个 EndpointId，并调用 Endpoints::getEndpoint() 获取最新快照。

要连接到端点，请使用 Session::connectInput() 或 Session::connectOutput() 在特定会话的上下文中创建连接。

getProductInstanceId()

String juce::universal_midi_packets::Endpoint::getProductInstanceId () const inline

如果可用，返回产品实例 ID，否则返回空字符串。

产品实例 ID 应与设备序列号一致，并且在每个制造商、系列和型号内应唯一。

此 ID 可用于区分具有相同 DeviceInfo 的不同设备。它还可用于判断不同端点是否与同一设备相关联。

getProtocol()
