成员函数

getDefaultFile()

File juce::PropertiesFile::Options::getDefaultFile () const

可以调用此方法，根据此结构体中的值建议一个应使用的文件。

因此在 Mac 上，这会返回一个名为：~/Library/[osxLibrarySubFolder]/[folderName]/[applicationName].[filenameSuffix] 的文件

在 Windows 上，它会返回类似：C:\Documents and Settings\username\Application Data\[folderName]\[applicationName].[filenameSuffix]

在 Linux 上，它会返回 ~/[folderName]/[applicationName].[filenameSuffix]

如果 folderName 变量为空，则会使用应用名称（或在 Mac 上省略文件夹名）。

路径也会因 commonToAllUsers 是否为 true 而有所不同。

成员数据文档

applicationName

String juce::PropertiesFile::Options::applicationName

应用程序的名称——用于帮助生成存储属性文件的路径和文件名。

filenameSuffix

String juce::PropertiesFile::Options::filenameSuffix

属性文件使用的后缀。

这实际上是什么并不重要——你可能想用 ".settings" 或 ".properties" 之类。如果后缀包含前缀点（例如 ".settings"），则 applicationName 的后缀将被替换为你的后缀（"MyApp.exe" -> "MyApp.settings"）。如果你的 filenameSuffix 不包含该点，则后缀将被附加到 applicationName 之后（"MyApp.exe" -> "MyApp.exe.settings"）。

folderName

String juce::PropertiesFile::Options::folderName

你希望属性文件所在的子文件夹名称。

有关其使用方式的更多详情，请参阅 getDefaultFile() 方法。

osxLibrarySubFolder

String juce::PropertiesFile::Options::osxLibrarySubFolder

如果你在 Mac 上使用属性文件，必须设置此值——否则会导致运行时断言。

PropertiesFile 类过去总是把设置文件放在 "Library/Preferences" 中，但 Apple 已改变其建议，现在规定设置应放在 "Library/Application Support" 中。

由于较旧的应用会因此类行为的静默改变而出现问题，你现在必须显式设置 osxLibrarySubFolder 值，以指示你想使用哪个路径。

在较新的应用中，你应始终将其设为 "Application Support" 或 "Application Support/YourSubFolderName"。

如果你的应用需要加载旧版 juce 创建的设置文件，并且你想保持向后兼容，则可以将其设为 "Preferences"。但为了更好地符合 Apple 的规定，推荐的做法是编写一些代码，在 ~/Library/Preferences 中找到旧设置文件，将其移动到 ~/Library/Application Support，然后使用新路径。

commonToAllUsers

bool juce::PropertiesFile::Options::commonToAllUsers

如果为 true，文件将创建在用户之间共享的位置。

默认构造函数将此值初始化为 false。

ignoreCaseOfKeyNames

bool juce::PropertiesFile::Options::ignoreCaseOfKeyNames

如果为 true，表示属性名称以不区分大小写的方式匹配。

更多信息见 PropertySet 构造函数。默认构造函数将此值初始化为 false。

doNotSave

bool juce::PropertiesFile::Options::doNotSave

如果设为 true，可阻止将文件写入磁盘。

millisecondsBeforeSaving

int juce::PropertiesFile::Options::millisecondsBeforeSaving

如果此项为零或更大，则值更改后，对象将等待这段时间，然后保存文件。

如果此项为零，文件在更改时会立即写入磁盘（这可能比较慢，因为每次调用值更改方法时都会同步重写）。如果小于零，则在显式调用 save() 或 saveIfNeeded() 之前不会保存文件。默认构造函数将其设为几秒的合理值，因此你只在需要特殊处理时才需要更改它。

storageFormat

StorageFormat juce::PropertiesFile::Options::storageFormat

指定文件应写入为 XML、二进制等格式。

默认构造函数将其设为 storeAsXML，因此只有在你希望使用其他格式时才需要显式设置。

processLock

InterProcessLock * juce::PropertiesFile::Options::processLock

可选的 InterprocessLock 对象，用于防止多个线程或进程同时写入文件。

PropertiesFile 将保留指向此对象的指针，但不会取得其所有权——调用方负责确保在 PropertiesFile 被删除之前该锁不会被删除。默认构造函数将此值初始化为 nullptr，因此除非你想使用锁，否则无需改动它。
