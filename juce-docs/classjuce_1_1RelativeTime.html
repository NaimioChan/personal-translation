juce::RelativeTime 类参考

详细说明

一个相对的时间度量。

时间以秒数存储，为双精度浮点精度，可正可负。

如果你需要绝对时间（即日期 + 时间），请参见 Time 类。

getDescription()

String juce::RelativeTime::getDescription (const String & returnValueForZeroTime = "0") const

返回时间的可读文本描述。

返回字符串的确切格式取决于时间的长短 —— 例如

“1 min 4 secs”、“1 hr 45 mins”、“2 weeks 5 days”、“140 ms”

因此只打印最显著的两个单位。

returnValueForZeroTime 是长度为零时返回的结果。根据你的应用需求，你可能想用它返回更贴切的内容，例如“empty”或“0 secs”等。

另见
inMilliseconds, inSeconds, inMinutes, inHours, inDays, inWeeks

getApproximateDescription()

String juce::RelativeTime::getApproximateDescription () const

这返回一个大致描述该时间距今多久的字符串，可用于显示文件的年龄等。

这只会尝试精确到最接近的数量级，因此返回诸如“5 years”、“2 weeks”、“< 1 minute”、“< 1 sec”等字符串。
