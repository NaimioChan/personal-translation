juce::WebBrowserComponent::EvaluationResult 类参考

详细说明

在 MacOS、iOS 和 Linux 上，如果求值失败，getResult 将返回 nullptr。

在这种情况下，getError 将返回一个非空的 Error 结果，其中包含有关求值失败原因的更多信息。它可能是例如语法错误或引用了未定义的对象。

在 Windows 和 Android 上，getResult 将始终返回指向变体的有效指针，而 getError 将始终返回 nullptr。如果发生求值失败，getResult 返回 void 变体，这与成功求值但结果为 null 无法区分。遗憾的是，这些平台不提供检测求值错误的方法。
