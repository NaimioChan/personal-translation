juce::AccessibilityTableInterface 类参考

详细说明

表示支持表格接口的 UI 元素的抽象接口。

通常支持表格接口的 UI 元素示例有列表、表格和树。

getHeaderHandler()

virtual const AccessibilityHandler * juce::AccessibilityTableInterface::getHeaderHandler () const pure virtual

返回表头的 AccessibilityHandler；如果没有表头，则返回 nullptr。

如果你提供表头，它的子级数量必须与表格的列数完全相同。

getRowSpan()

virtual Optional < Span > juce::AccessibilityTableInterface::getRowSpan (const AccessibilityHandler &) const pure virtual

给定表格中某个单元格的处理程序，返回该单元格覆盖的行；如果该单元格在表格中不存在，则返回 null。

此函数替代了 AccessibilityCellInterface 中的 getRowIndex 和 getRowSpan 函数。大多数情况下，由表格自身跟踪单元格位置比委托给各个单元格更容易。
