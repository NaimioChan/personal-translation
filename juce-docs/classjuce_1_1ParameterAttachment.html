juce::ParameterAttachment 类参考

详细说明

用于实现将插件参数链接到 UI 元素的「附件」或「控制器」。

要实现新的附件类型，请创建一个新类，并把此类的实例作为数据成员包含在内。你的类应向 ParameterAttachment 的构造函数传入一个函数，该函数随后会在参数变化时于消息线程上被调用。你可以用这个函数更新 UI 控件的状态。你的类还应注册为 UI 控件的监听器，并通过调用 setValueAsCompleteGesture，或调用 beginGesture、setValueAsPartOfGesture 和 endGesture 来响应 UI 元素的变化。

请务必在新附件构造函数的末尾调用 sendInitialUpdate，以便 UI 立即反映参数的状态。

ParameterAttachment()

juce::ParameterAttachment::ParameterAttachment (RangedAudioParameter & parameter, std::function< void(float)> parameterChangedCallback, UndoManager * undoManager = nullptr)

监听一个参数，并在参数变化时调用提供的函数。

如果提供了 undoManager，则每当 UI 通过此附件请求更改参数时，都会在它上面调用 beginNewTransaction。

参数

parameterChangedCallback将在消息线程上于参数变化时被调用的函数
undoManager当 UI 请求更改参数时，用于开始事务的 UndoManager。

成员函数

sendInitialUpdate()

void juce::ParameterAttachment::sendInitialUpdate ()

调用构造函数中注册的 parameterChangedCallback 函数，使 UI 反映当前参数状态。

在对所管理的 UI 控件完成所有必要设置（例如添加 ComboBox 条目、使按钮可切换）之后，应调用此函数。

setValueAsCompleteGesture()

void juce::ParameterAttachment::setValueAsCompleteGesture (float newDenormalisedValue)

在受管理的参数上触发一次完整的手势消息。

在 UI 控件的监听器回调中，响应诸如按下按钮这类一次性 UI 变更时调用此函数。

beginGesture()

void juce::ParameterAttachment::beginGesture ()

在受管理的参数上开始一个手势。

当 UI 即将开始连续交互时调用此函数，例如在滑块上按下鼠标按钮时。

setValueAsPartOfGesture()

void juce::ParameterAttachment::setValueAsPartOfGesture (float newDenormalisedValue)

在手势进行期间更新参数值。

在连续交互期间调用此函数，例如滑块值变化的回调。

endGesture()

void juce::ParameterAttachment::endGesture ()

结束受管理参数上的手势。

当 UI 完成连续交互时调用此函数，例如在滑块上松开鼠标按钮时。
