成员函数

withClientWindow()

XEmbedComponentOptions juce::XEmbedComponentOptions::withClientWindow (unsigned long x) const inline nodiscard

返回这些选项的副本，其中指定了客户端窗口 ID。

这对应于客户端发起的嵌入工作流。

省略此选项对应于宿主发起的嵌入工作流。

引用了 jassert、juce::withMember()、x。

XEmbedComponentOptions juce::XEmbedComponentOptions::withAllowForeignWidgetToResizeComponent (bool x = true) const inline nodiscard

引用了 juce::withMember()、x。

withIgnoreXembedMapped()

XEmbedComponentOptions juce::XEmbedComponentOptions::withIgnoreXembedMapped (bool x = true) const inline nodiscard

启用此选项后，无论 XEMBED_MAPPED 标志的值如何，客户端窗口都将被无条件映射。

通常不应使用此选项。默认值为 false。

它由 JUCE 插件宿主内部使用，以兼容某些声称支持 XEmbedInfo、却没有设置该标志的插件。

引用了 juce::withMember()、x。
