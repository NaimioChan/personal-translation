详细说明

template<typename SampleType>
class juce::dsp::Oversampling< SampleType >

一个执行多通道过采样的处理器。

该类可配置为进行 2、4、8 或 16 倍过采样，使用多个级联，采用多相全通 IIR 滤波器或 FIR 滤波器，并带延迟补偿。

过采样的原理是提高给定非线性处理的采样率，以防止其产生混叠。Oversampling 的工作方式是：将输入信号上采样 N 倍，使用提高后的内部采样率处理上采样信号，然后将结果下采样回原始采样率。

根据你对延迟和相位失真的需求，在 FIR 或 IIR 滤波之间选择。使用 FIR 滤波器时相位是线性的，但延迟被最大化。使用 IIR 滤波时，相位在奈奎斯特频率附近会有折衷，但延迟被最小化。

getLatencyInSamples()

template<typename SampleType> SampleType juce::dsp::Oversampling < SampleType >::getLatencyInSamples () const noexcept

返回整体处理的延迟，单位为采样。

你可以在主处理器中使用此信息来补偿过采样带来的额外延迟（例如配合干/湿混合器），并向 DAW 报告延迟。

注意：如果你没有选择使用整数延迟，那么延迟可能不是整数，因此你可能需要在处理代码中对其值进行舍入或适当补偿，因为插件只能向 DAW 报告以采样为单位的整数延迟值。

addOversamplingStage()

template<typename SampleType> void juce::dsp::Oversampling < SampleType >::addOversamplingStage (FilterType, float normalisedTransitionWidthUp, float stopbandAmplitudedBUp, float normalisedTransitionWidthDown, float stopbandAmplitudedBDown)

向 Oversampling 类添加一个新的过采样级，将当前过采样倍数乘以二。

这与默认构造函数配合使用以创建自定义过采样链，在任何添加之前需要调用 clearOversamplingStages。

注意：上采样和下采样滤波有不同的目的，前者去除上采样伪影，而后者去除过采样处理产生的不需要的频率成分，因此通常上采样时的衰减要比下采样时更高。

参数
normalisedTransitionWidthUp0 到 0.5 之间的值，指定上采样滤波时通带与阻带之间过渡的陡峭程度（越低越好）
stopbandAmplitudedBUp上采样滤波时阻带中的幅度，单位为 dB，必须为负
normalisedTransitionWidthDown0 到 0.5 之间的值，指定下采样滤波时通带与阻带之间过渡的陡峭程度（越低越好）
stopbandAmplitudedBDown下采样滤波时阻带中的幅度，单位为 dB，必须为负
