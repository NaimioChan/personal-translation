juce::AudioCDReader 类参考

详细说明

从音频 CD 读取的一种 AudioFormatReader。

其中之一可将 CD 当作一个大音频流来读取。使用 getPositionOfTrackStart() 方法查找各个轨道在流中的位置。

getLastIndex()

int juce::AudioCDReader::getLastIndex () const

返回上次 read() 调用期间找到的索引编号。

索引扫描默认关闭 — 使用 enableIndexScanning() 开启。

然后调用 read() 方法时，如果在该块内遇到索引，则存储该索引编号并由本方法返回。

当然，某些设备可能不支持索引。

（如果你不知道 CD 索引是什么，那你很可能永远不需要它们）。
