成员函数

decibelsToGain()

template<typename Type> Type juce::Decibels::decibelsToGain (Type decibels, Type minusInfinityDb = Type (defaultMinusInfinitydB)) inline static

将 dBFS 值转换为其等效的增益电平。

增益 1.0 = 0 dB，更低的增益对应负的分贝值。任何低于 minusInfinityDb 的分贝值都将返回增益 0。

被以下对象引用： gainWithLowerBound()、juce::dsp::Gain< FloatType >::setGainDecibels()、juce::dsp::LogRampedValue< FloatType >::setLogParameters()。

gainToDecibels()

template<typename Type> Type juce::Decibels::gainToDecibels (Type gain, Type minusInfinityDb = Type (defaultMinusInfinitydB)) inline static

将增益电平转换为 dBFS 值。

增益 1.0 = 0 dB，更低的增益对应负的分贝值。如果增益为 0（或负值），该方法将返回 minusInfinityDb 所提供的值。

引用了 juce::jmax()。

被以下对象引用： juce::dsp::Gain< FloatType >::getGainDecibels()。

gainWithLowerBound()

template<typename Type> Type juce::Decibels::gainWithLowerBound (Type gain, Type lowerBoundDb) inline static

根据以 dBFS 指定的下限限制增益值。

如果你要确保增益值永远不会降到零，这会很有用。

引用了 decibelsToGain()、jassert、juce::jmax()。

toString()

template<typename Type> String juce::Decibels::toString (Type decibels, int decimalPlaces = 2, Type minusInfinityDb = Type (defaultMinusInfinitydB), bool shouldIncludeSuffix = true, StringRef customMinusInfinityString = {}) inline static

将分贝读数转换为字符串。

默认情况下，返回的字符串会附加 'dB' 后缀，但将 shouldIncludeSuffix 参数设为 false 可以去掉它。如果提供了 customMinusInfinityString 参数，当值低于 minusInfinityDb 时将返回它，否则返回值为 "-INF"。
