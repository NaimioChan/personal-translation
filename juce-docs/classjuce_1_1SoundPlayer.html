play() [4/5]

void juce::SoundPlayer::play (PositionableAudioSource * audioSource, bool deleteWhenFinished = false, double sampleRateOfSource = 0.0)

播放来自可定位音频源的声音。

这将输出来自可定位音频源的声音。与其他 playSound 方法相比，这让你对声音播放有稍多的控制。例如，如果你想提前停止声音，可以用 AudioTransportSource 调用此方法，然后调用 audioSource->stop。注意，如果你的 audioSource 是 AudioTransportSource，你必须调用 audioSource->start 来开始播放。

一旦音频源因任何原因停止播放（例如声音播放完毕或你调用了 audioSource->stop），音频设备管理器将不再持有对该音频源的任何引用。因此，对已结束的 audioSource 调用 audioSource->start() 不会重新启动声音。如果需要，只需用同一个 audioSource 再次调用 playSound。

参数
audioSource要播放的音频源
deleteWhenFinished如果为 true，则设备管理器播放完毕后将删除该音频源。
sampleRateOfSource源的采样率。如果为零，JUCE 将假定采样率与音频输出设备相同。

play() [5/5]

void juce::SoundPlayer::play (AudioBuffer < float > * buffer, bool deleteWhenFinished = false, bool playOnAllOutputChannels = false)

播放来自音频采样缓冲区的声音。

这将输出音频采样缓冲区中包含的声音。如果 deleteWhenFinished 为 true，则声音播放完毕后将自动删除该音频采样缓冲区。

如果 playOnAllOutputChannels 为 true，那么当输出通道多于缓冲区通道时，可用通道将在多个输出上重复使用，以便向所有输出通道发送内容。如果为 false，则缓冲区只在最先的若干输出通道上播放。

audioDeviceIOCallbackWithContext()

void juce::SoundPlayer::audioDeviceIOCallbackWithContext (const float *const * inputChannelData, int numInputChannels, float *const * outputChannelData, int numOutputChannels, int numSamples, const AudioIODeviceCallbackContext & context) override virtual

处理传入和传出的一个音频数据块。

子类的实现应按其需要使用传入音频，并且必须在返回前用下一个输出数据块填满所有输出通道。

通道数据的排列所用数组索引与 AudioIODevice::getOutputChannelNames() 返回的通道名称数组相同，但那些未在 AudioIODevice::open() 中指定的通道，其关联通道指针将为 nullptr，因此记得检查这一点。

参数
inputChannelData一组包含每个传入通道音频数据的数组 - 该数据在函数返回前有效。设备打开时启用的每个输入通道都会有一路数据（见 AudioIODevice::open()）
numInputChannelsinputChannelData 数组中通道数据指针的数量。
outputChannelData一组需要用要发送到设备各输出通道的数据填充的数组。设备打开时启用的每个输出通道都会有一路数据（见 AudioIODevice::open()）数组的初始内容未定义，因此如果输出是静音，回调函数必须将所有通道填充为零。不这样做可能会产生相当难听的声音！
numOutputChannelsoutputChannelData 数组中通道数据指针的数量。
numSamples输入和输出数组中每个通道的采样数。采样数取决于音频设备的缓冲区大小，并且通常会保持不变，但这并非保证。例如在 Android 上，在支持该功能的设备上，Android 会把你的音频处理切分成若干个更小的回调以确保更高的音频性能。因此请确保你的代码能应对从一个回调到下一个回调的合理缓冲区大小变化。
context可能传递给 AudioIODeviceCallback 的附加信息。

重新实现自 juce::AudioIODeviceCallback。

audioDeviceAboutToStart()

void juce::SoundPlayer::audioDeviceAboutToStart (AudioIODevice * device) override virtual

调用以指示设备即将开始回调。

这将在音频回调开始之前被调用，无论是在此回调刚被添加到音频设备时，还是在因采样率或块大小变化而重启设备之后。

你可以借此机会，通过对传入的指针调用 AudioIODevice::getCurrentSampleRate() 和 AudioIODevice::getCurrentBufferSizeSamples()，查明设备将使用的采样率和块大小。

参数
device将用于驱动回调的音频 IO 设备。注意，如果你要保存此指针，它只在下次调用 audioDeviceStopped 之前有效。
