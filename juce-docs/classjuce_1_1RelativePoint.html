moveToAbsolute()

void juce::RelativePoint::moveToAbsolute (Point < float > newPos, const Expression::Scope * evaluationContext)

更改此点各坐标的值，使其解析为指定位置。

调用此方法将保持任何锚点不变，但会把任何绝对或相对位置设为使结果位置与所提供位置匹配所需的值。

toString()

String juce::RelativePoint::toString () const

返回表示此点的字符串。

这会返回以逗号分隔的一对坐标。有关坐标所用字符串语法的详细信息，请参见 RelativeCoordinate 构造函数说明。返回的字符串可以传给 RelativePoint 构造函数以重新创建该点。
