juce::SamplerVoice 类参考

详细说明

一种 SynthesiserVoice 的子类，可播放 SamplerSound。

要使用它，请创建一个 Synthesiser，向其中添加一些 SamplerVoice 对象，然后给它一些 SampledSound 对象来播放。

另见
SamplerSound, Synthesiser, SynthesiserVoice

canPlaySound()

bool juce::SamplerVoice::canPlaySound (SynthesiserSound *) override virtual

如果该声部对象能演奏给定声音，则必须返回 true。

如果存在不同类的声音和不同类的声部，声部可以选择要接受哪些。

如果只有一种声部和声音，该方法的一种典型实现可能只是返回 true；也可能检查传入的声音对象的类型，看它是否是能理解的那种。

stopNote()

void juce::SamplerVoice::stopNote (float velocity, bool allowTailOff) override virtual

调用以停止一个音符。

它会在渲染回调期间被调用，因此必须足够快且线程安全。

力度表示音符被释放的速度——0 表示缓慢，1 表示快速。

如果 allowTailOff 为 false，或该声部不想做尾音衰减，则必须立即停止所有声音，并调用 clearCurrentNote() 重置该声部的状态，以便合成器把它重新分配给另一个声音。

如果 allowTailOff 为 true 且声部决定做尾音衰减，则允许它开始淡出声音，并可以一直演奏到结束。一旦演奏结束（在渲染回调期间），它必须确保调用 clearCurrentNote()。

renderNextBlock() [1/2]

void juce::SamplerVoice::renderNextBlock (AudioBuffer < float > & outputBuffer, int startSample, int numSamples) override virtual

为该声部渲染下一个数据块。

输出的音频数据必须叠加到所提供缓冲区的当前内容上。本方法只应改动缓冲区中 startSample 到 (startSample + numSamples) 之间的区域。

如果该声部当前静音，则直接返回、不做任何事即可。

如果该声部演奏的声音在本块渲染过程中结束，它必须调用 clearCurrentNote()，告知合成器它已结束。

每次调用时渲染的块大小都可能变化，甚至可能一次只渲染 1 个采样。在渲染回调之间，会调用该声部的方法来告知它音符和控制器事件。
