juce::TypeHelpers::ParameterType< Type > 结构体模板参考

详细说明

template<typename Type>
struct juce::TypeHelpers::ParameterType< Type >

ParameterType 结构体用于在将某种对象作为参数传递时找到最合适的类型。

当然，这只在某些特殊的模板场景中才可能有用。

例如 "myFunction (typename TypeHelpers::ParameterType<int>::type, typename TypeHelpers::ParameterType<MyObject>::type)" 会求值为 "myfunction (int, const MyObject&)"，即基本类型保持按值传递，而对象作为 const 引用传递，以避免复制。
