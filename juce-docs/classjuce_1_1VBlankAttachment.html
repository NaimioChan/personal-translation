juce::VBlankAttachment 类参考

详细说明

用于将 Component 更新与呈现 Component 的显示器的垂直空白事件同步的辅助类。

这在为 Component 的内容做动画时很有用。

VBlankAttachment() [2/4]

juce::VBlankAttachment::VBlankAttachment (Component * c, std::function< void()> callbackIn)

构造函数。

创建一个附件，它将在传入的 Component 当前可见的显示器的每个垂直空白事件中调用传入的函数。

Component 必须在 VBlankAttachment 的整个生命周期内有效。

你应优先使用另一个构造函数，其中回调还会接收时间戳参数。提供此构造函数只是为了兼容早期的 JUCE 实现。

VBlankAttachment() [3/4]

juce::VBlankAttachment::VBlankAttachment (Component * c, std::function< void(double)> callbackIn)

构造函数。

创建一个附件，它将在传入的 Component 当前可见的显示器的每个垂直空白事件中调用传入的函数。

Component 必须在 VBlankAttachment 的整个生命周期内有效。

提供的回调会以秒为单位的单调递增值调用，该值对应下一帧的呈现时间。使用此值在所有使用 VBlankAttachment 的类之间同步绘制。
