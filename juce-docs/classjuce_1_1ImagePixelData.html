juce::ImagePixelData 类参考

详细说明

这是以特定于实现的方式保存图像数据的基类。

你可能永远不需要直接使用此类——它由 Image 类内部使用，用来存储实际的图像数据。要直接访问像素数据，应使用 Image::BitmapData 而不是此类。

ImagePixelData 对象由 ImageType 的子类间接创建。

applyGaussianBlurEffectInArea()

virtual void juce::ImagePixelData::applyGaussianBlurEffectInArea (Rectangle < int > bounds, float radius) virtual

如果可用，对此图像应用原生模糊效果。

此模糊会应用于输入图像的所有通道。它的计算开销可能比盒式模糊更大，但应能产生更高质量的结果。

默认实现会在 CPU 上逐像素修改图像，速度较慢。原生图像类型可能提供优化过的实现。

引用了 moveImageSection()。

被以下对象引用： applyGaussianBlurEffect()、applyGaussianBlurEffectInArea()。

applySingleChannelBoxBlurEffectInArea()

virtual void juce::ImagePixelData::applySingleChannelBoxBlurEffectInArea (Rectangle < int > bounds, int radius) virtual

如果可用，对此图像应用原生模糊效果。

它用于模糊单通道图像，在渲染投影时很有用。它通过串联多个盒式模糊实现。结果在视觉上应类似于高斯模糊，但精度较低。

默认实现会在 CPU 上逐像素修改图像，速度较慢。原生图像类型可能提供优化过的实现。
