juce::XmlElement::TextFormat 结构体参考

详细说明

一个结构体，包含在将 XML 元素表示为字符串时用于格式化文本的选项。

本结构体的文档由以下文件生成：
  • juce_core/xml/juce_XmlElement.h

newLineChars

const char* juce::XmlElement::TextFormat::newLineChars = "\r\n"

允许设置换行字符。

如果将其设为 nullptr，则整个 XML 文档将放在一行中。
