juce::Range< ValueType > 类模板参考

详细说明

template<typename ValueType>
class juce::Range< ValueType >

一个通用区间对象，简单地表示任何具有起点和终点的线性区间。

注意，检查值是否落在区间内时，起始值被视为包含在内，而区间终点不包含。

模板参数应为原始整数或浮点类型，不过如果类类型的行为类似数字，也可以使用。

template<typename ValueType> Range juce::Range < ValueType >::constrainRange (Range < ValueType > rangeToConstrain) const inline noexcept

返回给定区间向前或向后移动以纳入此区间之后的结果。

如果提供的区间长度大于此区间，返回值将是此区间。

否则，如果提供的区间小于此区间，返回值将是新的区间，其向前或向后移动，以不超出此区间，但保持其原有长度。

引用了 juce::jmax()、juce::jmin()、Range()。
