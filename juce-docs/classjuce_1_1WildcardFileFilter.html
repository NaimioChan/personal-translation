juce::WildcardFileFilter 类参考

详细说明

一种 FileFilter 类型，通过通配符模式匹配工作。

此过滤器只允许匹配指定模式之一的文件通过，但允许所有目录通过。

构造函数与析构函数

WildcardFileFilter()

juce::WildcardFileFilter::WildcardFileFilter (const String & fileWildcardPatterns, const String & directoryWildcardPatterns, const String & filterDescription)

为一个或多个模式创建通配符过滤器。

wildcardPatterns 参数是以逗号或分号分隔的模式集合，例如“*.wav;*.aiff”将查找以 .wav 或 .aiff 结尾的文件。

将空字符串作为模式传入将无法匹配任何内容，因此将文件或目录模式参数留空，即可控制是查找文件还是目录。

description 是在可能的模式列表中向用户显示的名称，因此对于 wav/aiff 示例，描述可以是“音频文件”。

被以下对象引用： isDirectorySuitable()。
