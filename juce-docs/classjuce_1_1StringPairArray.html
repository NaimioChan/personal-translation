operator[]()

const String & juce::StringPairArray::operator[] (StringRef key) const

查找与某个键字符串对应的值。

如果未找到这样的键，则只返回空字符串。要检查给定键是否实际存在（因为它可能与空字符串配对），请使用 getAllKeys() 方法获取列表。

显然返回的引用不应存储起来供以后使用，因为它所指的字符串在数组变化时可能消失。
