juce::MidiRPNGenerator 类参考

详细说明

生成一串合适的 MIDI CC 消息来表示 RPN 或 NRPN 消息。

然后可以把该序列（作为 MidiBuffer）直接发送给 MidiOutput。

MidiBuffer juce::MidiRPNGenerator::generate (int channel, int parameterNumber, int value, bool isNRPN = false, bool use14BitValue = true) static

生成表示具有给定参数的 RPN 或 NRPN 消息的 MIDI 序列。

参数
channelRPN/NRPN 消息的 MIDI 通道。
parameterNumber参数编号，范围为 0 到 16383。
value参数值，范围为 0 到 16383；如果 sendAs14BitValue 为 false，则范围为 0 到 127。
isNRPN你需要 MIDI RPN 还是 NRPN 序列（默认是 RPN）。
use14BitValue如果为 true（默认），该值具有 14 位精度（两个 MIDI 字节）。如果为 false，则该值具有 7 位精度（单个 MIDI 字节）。
