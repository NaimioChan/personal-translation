getId()

EndpointId juce::universal_midi_packets::LegacyVirtualInput::getId () const

获取此输入的唯一 id。

你可以将此 ID 传给 Session::connectInput()，以接收发送到此输入的消息。

注意，此 ID not 保证稳定 - 在多次程序运行中创建“相同”的虚拟设备，每次可能会产生不同的 ID。

要获取此设备的当前详细信息，你可以将此 ID 传给 Endpoints::getEndpoint()。
