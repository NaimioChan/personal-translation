juce::RangedDirectoryIterator 类参考

详细说明

允许使用 C++11 的范围 for 语法遍历文件和文件夹。

在下面的示例中，我们递归地查找某个目录中的所有隐藏文件。

std::vector<File> hiddenFiles;

for (DirectoryEntry entry : RangedDirectoryIterator (File ("/path/to/folder"), isRecursive))
 if (entry.isHidden())
        hiddenFiles.push_back (entry.getFile());

RangedDirectoryIterator() [2/2]

juce::RangedDirectoryIterator::RangedDirectoryIterator (const File & directory, bool isRecursive, const String & wildCard = "*", int whatToLookFor = File::findFiles, File::FollowSymlinks followSymlinks = File::FollowSymlinks::yes)

为给定目录创建一个 RangedDirectoryIterator。

生成的迭代器可直接用于“range-for”表达式。

参数
directory要搜索的目录
isRecursive是否同时搜索所有子目录
wildCard要匹配的文件模式。其中可包含多个以分号或逗号分隔的模式，例如“*.jpg;*.png”
whatToLookForFile::TypesOfFileToFind 枚举中的一个值，指定要查找文件、目录还是两者。
followSymlinks遇到符号链接时使用的策略

引用了 juce::File::findFiles、juce::File::yes。
