juce::ListenerList< ListenerClass, ArrayType > 类模板参考

详细说明

template<typename ListenerClass, typename ArrayType = Array<ListenerClass*>>
class juce::ListenerList< ListenerClass, ArrayType >

持有一组对象，并能通过一次调用对集合中的每个对象调用成员函数回调。

在任何监听器回调期间添加监听器、移除监听器、清空监听器，甚至删除 ListenerList 本身都是安全的。如果你不需要这些额外保证，可以考虑改用 LightweightListenerList。

如果在回调期间添加了 Listener，保证它不会在同一次迭代中被调用。

如果在回调期间移除了 Listener，保证在其尚未被调用的情况下不会再调用它。

如果在回调期间 ListenerList 被清空或删除，保证不会再调用任何监听器。

在没有互斥量的情况下并发调用监听器是不安全的。如果你需要此功能，请使用 LightweightListenerList 或 ThreadSafeListenerList。

调用监听器时，可以通过使用“BailOutChecker”提前跳出迭代。BailOutChecker 是一种类型，它有一个具有以下签名的公有成员函数：

bool shouldBailOut() const

在每次调用监听器之前都会调用此函数。有关示例，请参见 DummyBailOutChecker。
