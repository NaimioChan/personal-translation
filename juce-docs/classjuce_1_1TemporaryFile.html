juce::TemporaryFile 类参考

详细说明

管理一个临时文件，此对象被删除时该文件将被删除。

此对象旨在作为基于栈的对象使用，利用其作用域确保临时文件不会遗留。

例如：

{
 File myTargetFile ("~/myfile.txt");

 // this will choose a file called something like "~/myfile_temp239348.txt"
 // which definitely doesn't exist at the time the constructor is called.
 TemporaryFile temp (myTargetFile);

 // create a stream to the temporary file, and write some data to it...
 if (auto out = std::unique_ptr<FileOutputStream> (temp.getFile().createOutputStream()))
    {
        out->write ( ...etc )
        out.reset(); // (deletes the stream)

 // ...now we've finished writing, this will rename the temp file to
 // make it replace the target file we specified above
 bool succeeded = temp.overwriteTargetFileWithTemporary();
    }

 // ...and even if something went wrong and our overwrite failed,
 // as the TemporaryFile object goes out of scope here, it'll make sure
 // that the temp file gets deleted.
}

TemporaryFile() [4/6]

juce::TemporaryFile::TemporaryFile (const File & targetFile) explicit

在指定文件所在的同一目录中创建临时文件。

如果你有一个想要覆盖的文件，但又不想在写入失败时损坏原文件，这会很有用。你可以用它来在目标文件旁创建临时文件，然后写入临时文件，最后使用 overwriteTargetFileWithTemporary() 用刚写入的文件替换目标文件。

在你实际写入之前，此类不会创建任何文件。并请记住，此对象被删除时临时文件也会被删除！

参数
targetFile你打算覆盖的文件——临时文件将创建在与它相同的目录中

overwriteTargetFileWithTemporary()

bool juce::TemporaryFile::overwriteTargetFileWithTemporary () const

尝试将临时文件移动以覆盖构造函数中指定的目标文件。

如果你使用了指定目标文件的构造函数，这将尝试用临时文件替换该文件。

在调用此方法之前，请确保：

  • 你确实已写入临时文件
  • 你已关闭用于写入它的任何打开的流
  • 并且你没有打开指向目标文件的任何流，否则会阻止其被覆盖

如果文件移动成功，返回 true，临时文件将已消失。如果失败，临时文件可能仍然存在，但会在此对象销毁时被删除。
