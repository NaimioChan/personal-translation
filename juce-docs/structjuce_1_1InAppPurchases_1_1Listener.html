productPurchaseFinished()

virtual void juce::InAppPurchases::Listener::productPurchaseFinished (const PurchaseInfo &, bool, const String &) inline virtual

每当购买完成时调用，并附带购买是否成功的额外状态。

对于托管内容（仅 iOS），PurchaseInfo 内的 downloads 数组将包含与该购买对应的所有下载对象。对于非托管内容，downloads 数组将为空。

InAppPurchases 类将拥有这些下载对象，并在它们完成后立即删除它们。

注意：同一次购买可能会多次收到此回调。若发生这种情况，只有最新的那组下载对象和最新的 orderId 有效，旧的都不应再使用！

当所有购买的列表被恢复时调用。

注意：同一次购买可能会多次收到此回调。若发生这种情况，只有最新的那组下载对象和最新的 orderId 有效，旧的都不应再使用！

productDownloadProgressUpdate()

virtual void juce::InAppPurchases::Listener::productDownloadProgressUpdate (Download &, float, RelativeTime) inline virtual

仅 iOS：当产品下载进度更新时调用。

如果下载在上次应用会话中被中断，此回调可能会在应用启动后调用。

如果下载正在进行且应用被关闭，操作系统可能会让下载在后台继续。如果你打开应用时下载仍在进行，就会收到此回调。如果下载在你再次启动应用之前已在后台完成，你收到的将是 productDownloadFinished 回调。下载只有在被明确取消或完成时才会停止。

productDownloadPaused()

virtual void juce::InAppPurchases::Listener::productDownloadPaused (Download &) inline virtual

仅 iOS：当产品下载被暂停时调用。

如果下载处于暂停状态且应用在下载完成前被关闭，此回调也可能在应用启动后调用。

只有下载成功完成或被取消后，你才不会再在启动时收到此回调。

productDownloadFinished()

virtual void juce::InAppPurchases::Listener::productDownloadFinished (Download &, const URL &) inline virtual

仅 iOS：当产品下载完成时调用（无论成功与否）。

调用 Download::getStatus() 检查下载是否成功完成。

你有责任将下载的内容移到应用目录，并清理不再需要的任何文件。

下载完成后，下载对象会被销毁，不应再访问。
