ColourGradient() [2/3]

juce::ColourGradient::ColourGradient (Colour colour1, float x1, float y1, Colour colour2, float x2, float y2, bool isRadial)

创建一个渐变对象。

(x1, y1) 是用 colour1 绘制的位置。同样 (x2, y2) 是 colour2 应处的绘制位置。两者之间是一个渐变。

如果 isRadial 为 true，颜色会形成以 (x1, y1) 为圆心的圆形渐变。

会用到颜色的 alpha 透明度，因此注意：如果从透明色渐变到实色，透明色的 RGB 会在渐变的某些部分显现出来。例如从 Colour::transparentBlack 渐变到 Colours::white 会在中间产生发灰的颜色，而从 Colour::transparentWhite 渐变到 Colours::white 则全程都是白色。

isRadial

bool juce::ColourGradient::isRadial

如果为 true，渐变应呈圆形填充，以 point1 为中心，point2 定义圆周上的一点。

如果为 false，渐变在两点之间是线性的。

被以下对象引用： vertical()、vertical()。

endRadius

float juce::ColourGradient::endRadius = -1.0f

当 isRadial 为 true 且此值设为非负值时，point2 成为渐变结束圆的圆心，endRadius 定义其半径。

此时 point1 成为渐变起始圆的圆心，startRadius 定义其半径。

否则，point1 是起始圆和结束圆共同的圆心，point2 定义圆周上的一点。结束半径则按 point1 与 point2 之间的距离计算。

startRadius

float juce::ColourGradient::startRadius = 0.0f

如果 isRadial 为 true 且 endRadius 设为非负值，此项指定渐变起始圆的半径。
