createProbablePrime()

BigInteger juce::Primes::createProbablePrime (int bitLength, int certainty, const int * randomSeeds = nullptr, int numRandomSeeds = 0) static

创建具有给定位长的随机素数。

certainty 参数指定测试素性时使用的迭代次数。安全值可以是 20-30 以上的任意值。

randomSeeds 参数允许你选择性地传入一组值来为随机数生成播种，从而提高所生成密钥的安全性。

isProbablyPrime()

bool juce::Primes::isProbablyPrime (const BigInteger & number, int certainty) static

测试一个数是否为素数。

这不是万无一失的测试，它使用 Miller-Rabin 测试来判断该数是否为素数。

certainty 参数指定测试时使用的迭代次数——安全值可以是 20-30 以上的任意值。
