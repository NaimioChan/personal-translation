juce::HostProvidedContextMenu 结构体参考

详细说明

包装宿主提供的某个特定参数的上下文菜单。

你可以选择创建一个标准的 PopupMenu 来显示宿主提供的选项；也可以请求宿主在指定位置显示原生菜单。

getEquivalentPopupMenu()

virtual PopupMenu juce::HostProvidedContextMenu::getEquivalentPopupMenu () const pure virtual

获取一个 PopupMenu，其中包含宿主指定的条目。

大多数宿主会在该菜单中填入与参数相关的选项，例如显示其自动化轨道。如果你希望添加额外选项，可以在显示之前自由修改该菜单。

showNativeMenu()

virtual void juce::HostProvidedContextMenu::showNativeMenu (Point < int > pos) const pure virtual

请求宿主在相对于编辑器左上角的位置显示其原生菜单。

你提供的位置应使用逻辑像素。要在鼠标光标旁显示菜单，请在编辑器上调用 Component::getMouseXYRelative() 并将结果传给此函数。
