MidiMessage() [6/10]

juce::MidiMessage::MidiMessage (const void * data, int maxBytesToUse, int & numBytesUsed, uint8 lastStatusByte, double timeStamp = 0, bool sysexHasEmbeddedLength = true)

从某些数据中读取下一条 MIDI 消息。

这会从数据流中读取制作一条完整消息所需的字节数，并返回它实际用掉的字节数。这让你可以从文件或流中读取一串 MIDI 消息。

参数
data要读取的数据
maxBytesToUse允许读取的最大字节数
numBytesUsed返回实际需要的字节数
lastStatusByte在 MIDI 消息序列中，如果某条消息的首字节与前一条消息的首字节相同，则该首字节可以被省略，因此当消息首字节确实被省略时，你可以用这个参数提供要使用的字节。
timeStamp赋予该 MIDI 消息的时间——该值不使用任何特定单位，因此取决于具体应用
sysexHasEmbeddedLength读取 sysex 时，该标志指示是否预期数据以一个表示其长度的可变长度字段开头

getTimeStamp()

double juce::MidiMessage::getTimeStamp () const inline noexcept

返回与该消息关联的时间戳。

该时间的确切含义和单位会各不相同，因为消息用于各种不同的场景。

如果你是从 MIDI 文件中获取该消息，它可能是以秒为单位的时间，也可能是 tick 数，参见 MidiFile::convertTimestampTicksToSeconds()。

如果该消息在 MidiBuffer 中使用，它可能表示从缓冲区起始处算起的音频采样数。

如果该消息由 MidiInput 创建，关于它如何初始化该值，详见 MidiInputCallback::handleIncomingMidiMessage()。

另见
setTimeStamp, addToTimeStamp
