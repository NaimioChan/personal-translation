juce::TextInputTarget 类参考

详细说明

抽象基类，可由充当文本编辑器的组件实现。

此类允许不同类型的文本编辑器组件提供统一的接口，可供操作系统特定的输入法、屏幕键盘等使用。

getTextBounds()

virtual RectangleList < int > juce::TextInputTarget::getTextBounds (Range < int > textRange) const pure virtual

返回编辑器中某段文本的边界框。

由于该范围可能跨越多行，此方法返回一个 RectangleList。

边界相对于组件的左上角，如果文本很长且禁用了自动换行，可能超出组件的边界。

在 juce::CodeEditorComponent 和 juce::TextEditor 中实现。
