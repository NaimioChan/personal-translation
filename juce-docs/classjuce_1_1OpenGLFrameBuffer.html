getTextureID()

GLuint juce::OpenGLFrameBuffer::getTextureID () const noexcept

返回把此缓冲区用作纹理时的纹理 ID 号。

纹理可能大于缓冲区本身，参见 getTextureWidth() 和 getTextureHeight()。缓冲区的内容占据纹理的左上角，因此缓冲区的左上角像素位于纹理坐标 (0, 1)。

引用了 OpenGLFrameBuffer()。

被以下对象引用： getWidth()。

int juce::OpenGLFrameBuffer::getTextureWidth () const noexcept

readPixels()

bool juce::OpenGLFrameBuffer::readPixels (PixelARGB * targetData, const Rectangle < int > & sourceArea, RowOrder order)

从帧缓冲区读取一块像素区域到 32 位 ARGB 像素数组。

参数
targetData要填充的数组。它必须至少能容纳 sourceArea.getWidth() * sourceArea.getHeight() 个像素，这些像素连续写入，行间无填充。
sourceArea要读取的区域，使用 OpenGL 坐标，原点位于帧缓冲区的左下角。
order该区域各行写入 targetData 的顺序。
返回
若像素读取成功则返回 true，若帧缓冲区当前未分配则返回 false。

targetArea要写入的区域，使用 OpenGL 坐标，原点位于帧缓冲区的左下角。
ordersrcData 中各行的顺序。
返回
