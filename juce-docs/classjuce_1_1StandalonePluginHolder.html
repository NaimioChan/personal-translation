juce::StandalonePluginHolder 类参考

详细说明

一个创建并播放 AudioProcessor 独立实例的对象。

该对象将使用其它插件包装器所用的同一个 createPluginFilter() 函数创建你的处理器，并通过 AudioDeviceManager 和 AudioProcessorPlayer 让它在计算机的音频/MIDI 设备上运行。

StandalonePluginHolder()

juce::StandalonePluginHolder::StandalonePluginHolder (PropertySet * settingsToUse, bool takeOwnershipOfSettings = true, const String & preferredDefaultDeviceName = String (), const AudioDeviceManager::AudioDeviceSetup * preferredSetupOptions = nullptr, const Array < PluginInOuts > & channels = Array < PluginInOuts >(), bool shouldAutoOpenMidiDevices = true) inline

创建一个默认插件的实例。

设置对象可以是一个 PropertySet，该类应使用它来存储其设置——takeOwnershipOfSettings 指示此对象是否会在不再需要时自动删除设置。设置也可以为 nullptr。

可以传入默认设备名称。

最好可以使用完整的设置选项对象，它优先于 preferredDefaultDeviceName，并允许你选择输入和输出设备名称、采样率、缓冲区大小等。

在所有情况下，只要 settingsToUse 不为 null，它都会优先于“首选”选项。

引用了 autoOpenMidiDevices、channelConfiguration、init()、juce::RuntimePermissions::isGranted()、isInterAppAudioConnected()、juce::RuntimePermissions::isRequired()、jassert、JUCE_ANDROID、options、processor、juce::RuntimePermissions::recordAudio、juce::RuntimePermissions::request()、settings、shouldMuteInput。

被以下对象引用： getInstance()。
