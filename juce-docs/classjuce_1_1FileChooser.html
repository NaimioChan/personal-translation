juce::FileChooser 类参考

详细说明

创建一个对话框，用于选择要加载或保存的文件或目录。

std::unique_ptr<FileChooser> myChooser;

void loadMooseFile()
{
    myChooser = std::make_unique<FileChooser> ("Please select the moose you want to load...",
 File::getSpecialLocation (File::userHomeDirectory),
 "*.moose");

 auto folderChooserFlags = FileBrowserComponent::openMode | FileBrowserComponent::canSelectDirectories;

    myChooser->launchAsync (folderChooserFlags, [this] (const FileChooser& chooser)
    {
 File mooseFile (chooser.getResult());

        loadMoose (mooseFile);
    });
}

FileChooser()

juce::FileChooser::FileChooser (const String & dialogBoxTitle, const File & initialFileOrDirectory = File (), const String & filePatternsAllowed = String (), bool useOSNativeDialogBox = true, bool treatFilePackagesAsDirectories = false, Component * parentComponent = nullptr)

创建一个 FileChooser。

创建之后，使用某个 browseFor... 方法来显示它。

参数
dialogBoxTitle在对话框中显示的文本字符串，用于告诉用户当前情况
initialFileOrDirectory对话框打开时应选中的文件或目录。如果此参数设为 File()，则改用合理的默认目录。使用原生对话框时，并非所有平台都会真正选中该文件。例如在 macOS 上，当 initialFileOrDirectory 是文件时，只会把 initialFileOrDirectory 的父目录用作原生文件选择器的初始目录。

注意：在 iOS 上保存文件时，用户无法更改文件名，因此最好在 initialFileOrDirectory 中至少包含一个有效的文件名。找不到文件名时，将使用“Untitled”。

此外，如果你在 iOS 上传入一个已存在的文件，该文件会被自动复制到用户选择的目标位置，并且如果它可以预览，其预览也会显示在对话框中。你仍然可以写入这个文件副本，因为它的 URL 会由 getURLResult() 返回。当你想保存例如图像时这很有用：你可以传入一个带低质量预览的（临时）文件，在用户选定目标位置后，再把高质量图像写入该副本文件。如果你创建了这样的临时文件，需要在不再需要时自行删除它。

参数
filePatternsAllowed一组文件模式，用于指定可选择哪些文件——各模式之间用逗号或分号分隔，例如 "*" 或 "*.jpg;*.gif"。原生 MacOS 文件浏览器只支持指定扩展名的通配符，因此 "*.jpg" 可以，但 "myfilename*" 不行。空字符串表示允许所有文件
useOSNativeDialogBox如果为 true，则在可能时使用原生对话框；如果为 false，则始终使用基于 Juce 的浏览器对话框
treatFilePackagesAsDirectories如果为 true，则在 OS X 上调用并使用原生对话框时，文件选择器将允许选择包（package）内的文件。
parentComponent可选组件，应作为文件选择器的父级。如果为 nullptr，则 FileChooser 将是顶层窗口。iOS 上的 AUv3 必须指定此参数，因为由于沙盒限制，在 AUv3 中打开顶层窗口是被禁止的。
另见
browseForFileToOpen, browseForFileToSave, browseForDirectory

browseForFileToOpen()

bool juce::FileChooser::browseForFileToOpen (FilePreviewComponent * previewComponent = nullptr)

显示用于选择要打开文件的对话框。

这会以“打开文件”模式模态显示对话框，因此不允许选择不存在的文件或目录。

参数
previewComponent可选组件，显示在对话框内，用于展示用户正在浏览的文件的特殊信息。此对象不会删除该组件，因此调用者必须自行处理。
返回
如果用户选择了文件则返回 true，此时请使用 getResult() 方法了解所选文件。如果用户取消则返回 false。

launchAsync()

void juce::FileChooser::launchAsync (int flags, std::function< void(const FileChooser &)>, FilePreviewComponent * previewComponent = nullptr)

使用此方法异步启动文件浏览器窗口。

这会根据此结构中的设置创建文件浏览器对话框，并以模态方式启动它，然后立即返回。

你必须指定一个回调，在文件浏览器被取消或选中文件时调用。要中止文件选择，只需删除 FileChooser 对象。

你必须确保回调对象的生命周期长于文件选择器的生命周期。

引用了 FileChooser()。

getResult()

File juce::FileChooser::getResult () const

返回由某个 browseFor 方法最后选择的文件。

调用相应的 browseFor... 方法后，此方法让你了解用户选择了什么文件或目录。

注意，只有当 browse 方法返回 true（即用户按下“确定”而不是取消）时，返回的文件才有效。

在移动平台上，文件浏览器可能返回 URL 而不是本地文件。因此在移动平台上，你应改为调用 getURLResult()。

如果你使用多文件选择，则应改用 getResults() 方法获取所有已选择文件的列表。

getURLResult()

URL juce::FileChooser::getURLResult () const

返回由某个 browseFor 方法最后选择的文档。

如果你在移动平台上使用 FileChooser，而它可能返回指向远程文档的 URL，请使用此方法。如果选择的是本地文件，你可以通过 URL::getLocalFile 方法把这个文件转换为 JUCE File 类。

注意：在 iOS 上你必须直接使用返回的 URL 对象（也允许从返回的 URL 复制或移动构造另一个 URL），而不是只把路径保存为 String 然后再用该 String 创建新的 URL。这是因为返回的 URL 内部包含访问其指向文件所需的安全书签。之后，一旦你不再处理该 URL 指向的文件，就应释放该 URL 对象，以便系统可以释放安全书签（此类 URL 的数量是有限的）。

registerCustomMimeTypeForFileExtension()

void juce::FileChooser::registerCustomMimeTypeForFileExtension (const String & mimeType, const String & fileExtension) static

把特定文件扩展名关联到 MIME 类型。

在 Android 上，当在原生文件选择器对话框中使用通配符过滤器时，JUCE 需要把常见文件扩展名转换为 MIME 类型。JUCE 有一张广泛的转换表，可以透明地在最常见的文件类型和 MIME 类型之间转换，但可能缺少一些较冷门的文件类型。使用此方法注册你自己的 MIME 类型到文件扩展名的转换。如果你认为 JUCE 的内部表中缺少常见的 MIME 类型/文件扩展名条目，请联系 JUCE 团队。在其他平台上此方法不起作用。
