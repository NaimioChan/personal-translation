详细说明

影响 AudioFormatWriter 所产生输出数据格式的选项。

特定格式的写入器可能会忽略其中一些选项。

成员枚举

SampleFormat

enum class juce::AudioFormatWriterOptions::SampleFormat strong

用于向 AudioFormatWriter 提供输出采样格式的提示。

使用 automatic 可获得旧行为。当使用 32 位位深时，integral 和 floatingPoint 两个值可与 WavAudioFormat 一起使用。其它格式不受此设置影响。

枚举值
automatic 

让写入器根据其它参数值决定格式。

integral 

整数格式，例如 WavAudioFormat 下的 PCM。

floatingPoint 

IEEE 浮点格式。

withMetadataValues()

AudioFormatWriterOptions juce::AudioFormatWriterOptions::withMetadataValues (const std::unordered_map< String, String > & x) const inline nodiscard

返回这些选项的副本，并将元数据容器设为指定值。

作为此函数的替代方案，你可以使用 withMetadata 函数逐个指定键值对。

之后再次调用此函数会覆盖此前添加的所有元数据。

此参数是一组元数据值，写入器应尝试将其写入流中。具体是什么取决于格式，子类如果不想处理它们，实际上也可以完全不做任何处理。请查看具体的格式实现类，了解可使用的值。

引用了 juce::withMember()、x。

withMetadata()

AudioFormatWriterOptions juce::AudioFormatWriterOptions::withMetadata (const String & key, const String & value) const inline nodiscard

返回这些选项的副本，并将指定元数据添加进去。

之后调用此函数会添加新的元数据值，同时保留此前添加的值。

这里你可以指定写入器应尝试写入流的元数据值。具体是什么取决于格式，子类如果不想处理它们，实际上也可以完全不做任何处理。请查看具体的格式实现类，了解可使用的值。
