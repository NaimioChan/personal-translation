getNumChildren()

size_t juce::ARAMusicalContext::getNumChildren () const inline override virtual noexcept

返回此对象聚合的 ARA 模型对象的数量。

仅被引用但未被当前对象聚合的对象不计入此数量，例如被引用的 RegionSequence 不算作引用它的 PlaybackRegion 的子对象。

更多细节参见 ARA 文档中关于 ARA 模型图的概述。

实现 juce::ARAObject。

getChild()

ARAObject * juce::ARAMusicalContext::getChild (size_t index) inline override virtual

返回与给定索引关联的子对象。

索引应小于 getNumChildren() 返回的值。

注意，当 ARA 模型图被编辑时，特定对象的索引可能会发生变化。

实现 juce::ARAObject。

visit()

void juce::ARAMusicalContext::visit (ARAObjectVisitor & visitor) inline override virtual

允许获取模型对象的具体类型。

要使用它，请创建一个派生自 ARAObjectVisitor 的新类，并根据你关心的具体类型重写其函数。

在传给 ARAObject::traverse() 的函数内部调用此函数，可以遍历整个 ARA 模型图。
