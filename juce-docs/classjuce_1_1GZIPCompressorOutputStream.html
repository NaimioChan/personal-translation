juce::GZIPCompressorOutputStream 类参考

详细说明

使用 zlib 压缩写入其中的数据的流。

重要提示：当你对 GZIPCompressorOutputStream 调用 flush() 时，gzip 数据会被关闭——这意味着无法再向其写入数据，之后任何尝试调用 write() 的操作都会触发断言。

参数
destStream压缩数据将写入的流
compressionLevel压缩数据的程度，介于 0 和 9 之间，其中 0 为非压缩存储，1 为最快/最低压缩，9 为最慢/最高压缩。此范围之外的任何值表示应使用默认压缩级别。
windowBits这在内部用于更改 zlib 使用的窗口大小——除非你因某种原因特别需要设置其值，否则保持为 0
