juce::MidiKeyboardState 类参考

详细说明

表示一个钢琴键盘，跟踪当前按下的琴键。

本对象可以解析 MIDI 事件流，用它们更新自己对各个 MIDI 通道上哪些琴键被按下的认知。

当琴键被按下或松开时，它可以把这些事件广播给监听器对象。

它还允许通过 noteOn() 和 noteOff() 方法触发琴键按下/松开事件，这些事件的 MIDI 消息会被合入由 processNextMidiBuffer() 处理的 MIDI 流中。

成员函数

reset()

void juce::MidiKeyboardState::reset ()

重置该对象的状态。

所有通道的所有内部数据都会被重置，但不会因此发出任何事件。

如果你想释放当前按下的任何琴键，并为此发出 note-up MIDI 消息，请改用 allNotesOff() 方法。

isNoteOn()

bool juce::MidiKeyboardState::isNoteOn (int midiChannel, int midiNoteNumber) const noexcept

如果给定的 MIDI 琴键在给定 MIDI 通道上当前处于按下状态，则返回 true。

通道号必须在 1 到 16 之间。如果你想查看某个通道范围内是否有音符处于开启状态，请使用 isNoteOnForChannels() 方法。

isNoteOnForChannels()

bool juce::MidiKeyboardState::isNoteOnForChannels (int midiChannelMask, int midiNoteNumber) const noexcept

如果给定的 MIDI 琴键在一组 MIDI 通道中的任一通道上当前处于按下状态，则返回 true。

通道掩码中，每个要测试的 MIDI 通道对应一个置位的位：位 0 = MIDI 通道 1，位 1 = MIDI 通道 2，依此类推。

如果在指定的至少一个通道上有音符处于开启状态，则返回 true。

noteOn()

void juce::MidiKeyboardState::noteOn (int midiChannel, int midiNoteNumber, float velocity)

打开指定的音符。

这会导致在下一次调用 processNextMidiBuffer() 时，向 MIDI 缓冲区注入一个合适的 MIDI note-on 事件。

它还会向监听器触发同步回调，告知它们该琴键已按下。

noteOff()

void juce::MidiKeyboardState::noteOff (int midiChannel, int midiNoteNumber, float velocity)

关闭指定的音符。

这会导致在下一次调用 processNextMidiBuffer() 时，向 MIDI 缓冲区注入一个合适的 MIDI note-off 事件。

它还会向监听器触发同步回调，告知它们该琴键已松开。

但如果该音符在给定通道上实际上并未按下，本方法实际上不会做任何事。

allNotesOff()

void juce::MidiKeyboardState::allNotesOff (int midiChannel)

这会关闭给定 MIDI 通道上所有当前按下的音符。

如果你为 MIDI 通道传入 0，则会关闭所有通道上的所有音符。

调用本方法会接着调用 noteOff()，因此可能触发同步回调，并向 MIDI 流中添加事件。

processNextMidiEvent()

void juce::MidiKeyboardState::processNextMidiEvent (const MidiMessage & message)

查看一个琴键松开/按下事件，并用它更新本对象的状态。

要处理装满 MIDI 消息的缓冲区，请改用 processNextMidiBuffer() 方法。

processNextMidiBuffer()

void juce::MidiKeyboardState::processNextMidiBuffer (MidiBuffer & buffer, int startSample, int numSamples, bool injectIndirectEvents)

扫描 MIDI 流中的按下/松开事件，并把自身的事件加入其中。

这会查找所有按下/松开事件，用它们更新内部状态，并同步向监听器发出合适的回调。

如果 injectIndirectEvents 为 true，则会把产生最近那些 noteOn() 和 noteOff() 调用的 MIDI 事件添加到缓冲区中。

只会影响缓冲区中时间戳介于 startSample 和 (startSample + numSamples) 之间的部分，添加的事件也会放在这些时间之间。

如果你准备使用本方法，就需要定期调用它，才能获得令人满意的效果。

要一次处理单个 MIDI 事件，请改用 processNextMidiEvent() 方法。
