findAllTypesForFile()

virtual void juce::AudioPluginFormat::findAllTypesForFile (OwnedArray < PluginDescription > & results, const String & fileOrIdentifier) pure virtual

这会尝试为二进制模块文件中所有可用的插件类型创建描述。

该文件将是某种 DLL 或 bundle。

通常只会返回一个类型，但某些插件（例如 VST shell）可以用单个 DLL 创建一组不同的插件子类型，此时每个子类型都会作为单独对象返回。

在 juce::AudioUnitPluginFormatHeadless、juce::LADSPAPluginFormatHeadless、juce::LV2PluginFormatHeadless、juce::VST3PluginFormatHeadless 和 juce::VSTPluginFormatHeadless 中实现。

searchPathsForPlugins()

virtual StringArray juce::AudioPluginFormat::searchPathsForPlugins (const FileSearchPath & directoriesToSearch, bool recursive, bool allowPluginsWhichRequireAsynchronousInstantiation = false) pure virtual

在一组建议的目录中搜索此格式的任何插件。

该路径可能会被忽略，例如 AU 插件由操作系统而非手动查找。

参数
directoriesToSearch这指定了应在哪些目录中搜索插件。
recursive搜索是否应递归遍历文件夹。
allowPluginsWhichRequireAsynchronousInstantiation如果此项为 false，则要求异步创建的插件将被排除。

在 juce::AudioUnitPluginFormatHeadless、juce::LADSPAPluginFormatHeadless、juce::LV2PluginFormatHeadless、juce::VST3PluginFormatHeadless 和 juce::VSTPluginFormatHeadless 中实现。
