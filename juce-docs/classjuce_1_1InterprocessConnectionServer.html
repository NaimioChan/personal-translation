juce::InterprocessConnectionServer 类参考

详细说明

一个等待客户端套接字连接到此主机上某端口的对象，并为每个连接创建 InterprocessConnection 对象。

要使用它，请创建一个派生自它的类并实现 createConnectionObject() 方法，以便为每个尝试连接的客户端创建合适的连接对象。

beginWaitingForSocket()

bool juce::InterprocessConnectionServer::beginWaitingForSocket (int portNumber, const String & bindAddress = String ())

启动一个侦听给定端口号的内部线程。

在它运行期间，如果有另一个进程尝试使用 InterprocessConnection::connectToSocket() 方法连接，该对象将调用 createConnectionObject() 来创建与该客户端的连接。

使用 stop() 停止线程运行。

参数
portNumber服务器接收连接的端口
bindAddress服务器侦听连接的地址。空字符串表示应侦听分配给此机器的所有地址。

getBoundPort()

int juce::InterprocessConnectionServer::getBoundPort () const noexcept

返回该服务器当前绑定到的本地端口号。

当你以端口号零调用 beginWaitingForSocket 时，如果你需要知道操作系统实际将套接字绑定到了哪个端口，这会很有用。

如果函数失败，则返回 -1。

createConnectionObject()

virtual InterprocessConnection * juce::InterprocessConnectionServer::createConnectionObject () protected pure virtual

为想要连接到本服务器的客户端进程创建一个合适的连接对象。

当有客户端进程尝试连接时，侦听线程将调用它，它必须返回一个新的 InterprocessConnection 对象，随后该对象将作为连接的本端运行。
