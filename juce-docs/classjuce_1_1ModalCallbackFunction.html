详细说明

此类提供了一些便捷的工具方法，用于创建 ModalComponentManager::Callback 对象，这些对象将在模态组件被关闭时调用带参数的静态函数。

create() [2/2]

template<typename ParamType> ModalComponentManager::Callback * juce::ModalCallbackFunction::create (void(* functionToCall)(int, ParamType), ParamType parameterValue) inline static

这是一个工具函数，用于创建一个会调用带一个参数的静态函数的 ModalComponentManager::Callback。

你提供的函数必须接受两个参数——第一个是 int，即模态组件被关闭时使用的结果代码，第二个可以是自定义类型。注意，此自定义值将被复制并存储，因此它必须是原始类型或提供按值复制语义的类。

例如

static void myCallbackFunction (int modalResult, double customValue)
{
 if (modalResult == 1)
        doSomethingWith (customValue);
}

Component* someKindOfComp;
...
someKindOfComp->enterModalState (true, ModalCallbackFunction::create (myCallbackFunction, 3.0));

forComponent() [1/2]

template<class ComponentType> ModalComponentManager::Callback * juce::ModalCallbackFunction::forComponent (void(* functionToCall)(int, ComponentType *), ComponentType * component) inline static

这是一个工具函数，用于创建一个会调用带一个组件的静态函数的 ModalComponentManager::Callback。

你提供的函数必须接受两个参数——第一个是 int，即模态组件被关闭时使用的结果代码，第二个可以是 Component 类。该组件将存储为 WeakReference，因此如果它在此回调被调用之前被删除，传给该函数的指针将为 null。

例如

static void myCallbackFunction (int modalResult, Slider* mySlider)
{
 if (modalResult == 1 && mySlider != nullptr) // must check that mySlider isn't null in case it was deleted
        mySlider->setValue (0.0);
}

Component* someKindOfComp;
Slider* mySlider;
...
someKindOfComp->enterModalState (true, ModalCallbackFunction::forComponent (myCallbackFunction, mySlider));

创建一个会调用带一个组件的静态函数的 ModalComponentManager::Callback。

你提供的函数必须接受三个参数——第一个是 int，即模态组件被关闭时使用的结果代码，第二个是 Component 类，第三个是自定义类型（必须是原始类型或具有按值复制语义）。该组件将存储为 WeakReference，因此如果它在此回调被调用之前被删除，传入该函数的指针将为 null。

例如

static void myCallbackFunction (int modalResult, Slider* mySlider, String customParam)
{
 if (modalResult == 1 && mySlider != nullptr) // must check that mySlider isn't null in case it was deleted
        mySlider->setName (customParam);
}

Component* someKindOfComp;
Slider* mySlider;
...
someKindOfComp->enterModalState (true, ModalCallbackFunction::forComponent (myCallbackFunction, mySlider, String ("hello")));
