juce::CriticalSection 类参考

详细说明

一个可重入互斥量。

CriticalSection 充当可重入互斥量对象。锁定和解锁它的最佳方式是使用 RAII，即使用局部的 ScopedLock 对象——在代码库中查找许多示例了解如何做到这一点。

几乎所有情况下，你都希望将 CriticalSection 声明为成员变量。偶尔你可能希望将其声明为静态变量，但此时应留意 C++ 中常见的静态对象构造顺序警告。

另见
ScopedLock, ScopedTryLock, ScopedUnlock, SpinLock, ReadWriteLock, Thread, InterProcessLock

成员函数

enter()

void juce::CriticalSection::enter () const noexcept

获取锁。

如果锁已由调用线程持有，该方法立即返回。如果锁当前由另一个线程持有，则将等待直到其变为空闲。

强烈建议你永远不要直接调用此方法——而应使用 ScopedLock 类以 RAII 模式管理加锁。

tryEnter()

bool juce::CriticalSection::tryEnter () const noexcept

尝试在不阻塞的情况下锁定此临界区。

此方法的行为与 CriticalSection::enter 完全相同，区别在于如果锁当前由另一个线程持有，调用线程不会等待，而是立即返回 false。

返回
如果锁当前由另一个线程持有则返回 false，否则返回 true。

exit()

void juce::CriticalSection::exit () const noexcept

释放锁。

如果调用线程没有获得锁，这可能产生不可预测的结果。

如果线程已多次调用 enter() 方法，则每次调用都必须对应一次 exit() 调用，其他线程才被允许接管锁。
