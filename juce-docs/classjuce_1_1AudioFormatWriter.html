juce::AudioFormatWriter 类参考

详细说明

将采样写入音频文件流。

写入特定音频格式的子类将由 AudioFormat 对象创建。

用 AudioFormat::createWriterFor() 方法创建一个之后，你可以调用它的 write() 方法存储采样，然后将其删除。

另见
AudioFormat, AudioFormatReader

write()

virtual bool juce::AudioFormatWriter::write (const int ** samplesToWrite, int numSamples) pure virtual

将一组采样写入音频流。

注意，如果你要写入 AudioBuffer 的内容，可以使用 writeFromAudioSampleBuffer()。

参数
samplesToWrite一个包含各通道待写入采样数据的数组的数组。这是一个以零结尾的数组的数组，其通道数可以与实际使用的流不同，写入器应尽力处理这种情况。如果格式为定点格式，无论源的位深如何，每个通道都将格式化为使用完整 32 位范围 -0x80000000 到 0x7fffffff 的有符号整数数组。如果是浮点格式，你应将数组视为 float 数组，只需将其强制转换为 (int**) 传入方法即可。
numSamples要写入的采样数

flush()

virtual bool juce::AudioFormatWriter::flush () virtual

某些格式可能支持刷新操作，确保在继续之前文件处于有效状态。

如果支持，这意味着在大文件中写入数据时定期调用 flush，那么即使程序崩溃，文件也应仍保持可读状态。不用说，此方法必须从调用 write() 的同一线程中调用！如果格式支持刷新且操作成功，则返回 true。

writeFromAudioReader()

bool juce::AudioFormatWriter::writeFromAudioReader (AudioFormatReader & reader, int64 startSample, int64 numSamplesToRead)

从 AudioFormatReader 读取一段采样，并将其写入输出。

这将处理两种格式之间转换所需的任何浮点转换。不过它不会处理采样率转换。

如果 numSamplesToRead < 0，它将写入读取器的整个长度。

返回
如果在操作期间无法正常读取或写入则返回 false
