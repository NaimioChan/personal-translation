成员函数

getPointer()

std::optional< var > juce::JSONUtils::getPointer (const var & v, String pointer) static

给定一个 JSON 数组/对象 'v' 和一个表示 JSON 指针的字符串，返回 'pointer' 所引用值的副本。

如果由于引用了缺失的数组索引或字段而无法跟随指针，则返回 nullopt。

更多详情请参阅 JSON 指针 RFC 6901：https://datatracker.ietf.org/doc/html/rfc6901

setPointer()

std::optional< var > juce::JSONUtils::setPointer (const var & v, String pointer, const var & newValue) static

给定一个 JSON 数组/对象 'v'、一个表示 JSON 指针的字符串以及新属性值 'newValue'，返回 'v' 的副本，其中指针引用的属性或数组索引已设为 'newValue'。

如果由于引用了缺失的数组索引或字段而无法跟随指针，则返回 nullopt。

更多详情请参阅 JSON 指针 RFC 6901：https://datatracker.ietf.org/doc/html/rfc6901

var juce::JSONUtils::makeObject (const std::map< Identifier, var > & source) static

将提供的键/值对转换为 JSON 对象。

makeObjectWithKeyFirst()

var juce::JSONUtils::makeObjectWithKeyFirst (const std::map< Identifier, var > & source, Identifier key) static

将提供的键/值对转换为 JSON 对象，并把提供的键放在对象中的第一位。

这很有用，因为 MIDI-CI 规范要求某些字段（例如 status）应放在 MIDI-CI 头部的开头。

deepEqual()

bool juce::JSONUtils::deepEqual (const var & a, const var & b) static

当且仅当 a 的内容与 b 的内容匹配时返回 true。

与 var::operator== 不同，这会递归检查所含的 DynamicObject 和 Array 实例是否相等。
