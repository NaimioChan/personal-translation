详细说明

template<typename RendererRef, typename Interface>
class juce::ARAHostModel::PlaybackRegionRegistry< RendererRef, Interface >

::PlaybackRendererInterface 和 ::EditorRendererInterface 插件扩展接口所使用的基类。

宿主会希望为每个插件创建一个或通常更多的 ARA 插件扩展实例，用于播放和编辑器渲染。随后宿主创建的 PlaybackRegions 必须通过相应的接口分配给这些实例。

PlaybackRegion 或已分配的 RendererInterface 哪一个先被删除，取决于宿主实现和具体用例。

通过使用这些辅助类，你可以确保在这两种情况下 ARA DocumentController 都保持有效状态。要使用它们，请从 PlugInExtensionInstance::getPlaybackRendererInterface() 或 PlugInExtensionInstance::getEditorRendererInterface() 获取一个对象。

然后调用 add()，把一个 PlaybackRegion 注册到那个特定 PlugInExtensionInstance 的接口上。

这样，删除该 PlaybackRegion 时，它会从那个扩展实例中注销。但如果你希望在 PlaybackRegion 之前删除插件扩展实例，可以在删除插件扩展实例之前先删除 PlaybackRegionRegistry 实例，它会负责注销所有 PlaybackRegions。

添加或移除 PlaybackRegions 时，插件实例必须处于未准备状态，即在 AudioProcessor::prepareToPlay() 之前或 AudioProcessor::releaseResources() 之后。

auto playbackRenderer = std::make_unique<PlaybackRendererInterface> (plugInExtensionInstance.getPlaybackRendererInterface());
auto playbackRegion   = std::make_unique<PlaybackRegion> (documentController, regionSequence, audioModification, audioSource);

// Either of the following three code variations are valid
// (1) ===================================================
playbackRenderer.add (playbackRegion);
playbackRenderer.remove (playbackRegion);

// (2) ===================================================
playbackRenderer.add (playbackRegion);
playbackRegion.reset();

// (3) ===================================================
playbackRenderer.add (playbackRegion);
playbackRenderer.reset();
