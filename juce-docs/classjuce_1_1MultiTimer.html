juce::MultiTimer 类参考

详细说明

一种定时器类，可以运行多个不同频率的定时器，它们共用同一个回调。

此类与 Timer 类非常相似，但允许你运行多个独立的定时器，每个都有唯一的 ID 号。此类中的方法与 Timer 中的完全对应，只是多了这个 ID 号。

要使用它，你需要创建 MultiTimer 的子类并实现 timerCallback() 方法。然后就可以用 startTimer() 启动定时器，每次触发回调时都会传入引发该回调的定时器 ID。

startTimer()

void juce::MultiTimer::startTimer (int timerID, int intervalInMilliseconds) noexcept

启动一个定时器并设置所需的时间间隔。

如果定时器已启动，这会重置它，因此从调用此方法到下一次定时器回调之间的时间不会小于传入的间隔长度。

参数
timerID标识要启动的定时器的唯一 ID 号。此定时器被触发时，该 id 会传回 timerCallback() 方法
intervalInMilliseconds要使用的间隔（小于 1 的值会向上取整为 1）

引用了 MultiTimer()。

被以下对象引用： timerCallback()。

stopTimer()

void juce::MultiTimer::stopTimer (int timerID) noexcept

停止一个定时器。

如果已用给定 ID 号启动了定时器，它会被取消。此方法返回后，该定时器不会再产生回调。

如果从其他线程调用，当前可能正在执行的回调可以在方法返回前完成。
