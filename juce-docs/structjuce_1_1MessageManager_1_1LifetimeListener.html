juce::MessageManager::LifetimeListener 结构体参考

详细说明

在 MessageManager 启动或停止时接收回调。

监听器的生命周期与进程相同：它们在 MessageManager 重启（例如插件重新加载）后仍保持注册。管理器被删除时它们不会被自动注销。

如果在当前管理器已创建之后再注册，你收不到该实例的 messageManagerStarting()。如果需要补上，可在构造函数中检查 getInstanceWithoutCreating()。

成员函数

messageManagerStarting()

virtual void juce::MessageManager::LifetimeListener::messageManagerStarting () pure virtual

在新的 MessageManager 已构造、其平台消息队列就绪之后，且在分发循环开始运转之前调用。

这在消息线程上运行。已投递的回调要等消息循环启动（或宿主开始泵送）后才会执行。不要在这里等待已投递的消息；此时循环尚未运转，那样会死锁。

messageManagerStopping()

virtual void juce::MessageManager::LifetimeListener::messageManagerStopping () pure virtual

在管理器停止接受新消息之后，且在 DeletedAtShutdown 对象和 MessageManager 本身被销毁之前调用。

MessageManager 实例仍然可用。不要投递消息，它们会被丢弃。

引用了 LifetimeListener()。
