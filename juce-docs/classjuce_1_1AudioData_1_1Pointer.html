详细说明

template<typename SampleFormat, typename Endianness, typename InterleavingType, typename Constness>
class juce::AudioData::Pointer< SampleFormat, Endianness, InterleavingType, Constness >

用作 AudioData::Pointer 的模板参数。

表示这些采样只能用于常量数据。指向具有特定编码的音频数据块的指针。

此对象可用于从编码音频采样块中读写。要创建它，需以一系列模板参数指定音频格式，例如：

// this creates a pointer for reading from a const array of 16-bit little-endian packed samples
AudioData::Pointer <AudioData::Int16,
                    AudioData::LittleEndian,
                    AudioData::NonInterleaved,
                    AudioData::Const> pointer (someRawAudioData);

// these methods read the sample that is being pointed to
float firstSampleAsFloat = pointer.getAsFloat();
int32 firstSampleAsInt = pointer.getAsInt32();
++pointer; // moves the pointer to the next sample
pointer += 3; // skips the next 3 samples

convertSamples() 方法让你将一段采样从一种格式复制到另一种格式，并自动转换其格式。

getAsInt32()

template<typename SampleFormat, typename Endianness, typename InterleavingType, typename Constness> int32 juce::AudioData::Pointer < SampleFormat, Endianness, InterleavingType, Constness >::getAsInt32 () const inline noexcept

以 32 位整数返回第一个采样的值。

返回的值将在 0x80000000 到 0x7fffffff 范围内，较短的数值会被移位以填满该范围（例如，如果你读取的是 24 位数据，返回时数值会左移 8 位）。如果源数据是浮点，超出 -1.0 到 1.0 的值将被削波，使 -1.0 映射到 -0x7fffffff，1.0 映射到 0x7fffffff。

被以下对象引用： juce::AudioData::Pointer< DataFormat, Endianness, std::conditional_t< IsInterleaved, Interleaved, NonInterleaved >, std::conditional_t< IsConst, Const, NonConst > >::findMinAndMax()。

返回此格式表示为 32 位整数时的精度。

这是采样格式中大于 0 的最小可表示数值，转换到 32 位范围。例如，如果格式是 8 位，其分辨率为 0x01000000；如果格式是 24 位，其分辨率为 0x100。
