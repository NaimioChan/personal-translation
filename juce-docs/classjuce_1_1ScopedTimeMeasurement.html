juce::ScopedTimeMeasurement 类参考

详细说明

用于测量在某个作用域中所花时间的简单 RAII 类。

示例：

{ double timeSec;

{ ScopedTimeMeasurement m (timeSec); doSomething(); }

Logger::writeToLog ("doSomething() took " + String (timeSec) + "seconds"); }

参数
resultInSeconds测量结果将存储在此变量中。
