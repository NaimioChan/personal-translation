juce::ComponentAnimator 类参考

详细说明

此类已被取代，现在建议使用 juce_animation 模块中的 Animator 类。

为一组组件制作动画，将它们移动到新位置和/或淡出其 alpha 级别。

要为组件制作动画，请创建 ComponentAnimator 实例，或（最好）使用 Desktop::getAnimator() 提供的全局动画器对象，并调用其 animateComponent() 方法开始移动。

如果你使用自己的 ComponentAnimator 实例，你需要确保它完成移动组件之前不被删除，否则组件将在到达目的地之前被放弃。

在组件被制作动画期间删除它们是没问题的 —— 动画器会检测到这一点并安全地停止使用它们。

该类是一个 ChangeBroadcaster，当任何组件开始或完成动画时会发送通知。

animateComponent()

void juce::ComponentAnimator::animateComponent (Component * component, const Rectangle < int > & finalBounds, float finalAlpha, int animationDurationMilliseconds, bool useProxyComponent, double startSpeed, double endSpeed)

开始让组件从当前位置移动到指定位置。

如果组件已处于动画过程中，该动画将被放弃，并开始新的动画，让组件从当前位置开始移动。

起始速度和结束速度参数让你可以为组件的移动施加一定的加速度。

参数
component要移动的组件
finalBounds组件要移动到的目标边界。如果想让组件留在原地，只需为此值传入 component->getBounds()
finalAlpha动画结束时组件应具有的 alpha 值
animationDurationMilliseconds动画应持续的时间，单位为毫秒
useProxyComponent如果为 true，表示组件应被一个内部管理的临时组件替换，该临时组件是原组件的快照。这样可避免组件在移动过程中自行绘制，因此可能更高效。此选项还允许你在启动动画后立即删除原组件，因为动画可以在没有它的情况下继续进行。如果使用代理，本次调用会使原组件变为不可见，然后在动画结束时重新可见。这也意味着代理组件会被临时添加到组件的父级中，因此如果这会使父组件困惑，或父组件有可能决定删除其子级，请避免使用。
startSpeed一个值，用于指示动画的相对起始速度。如果为 0，组件将从静止开始加速；值越大，表示初始速度大于零。如果值大于 1，组件将在行程中途减速。若要让组件在整个动画过程中以恒定速率移动，请将起始速度和结束速度都设为 1.0
endSpeed组件在动画结束时应具有的相对速度。如果为 0，组件将在最终位置减速至停止；值越大，表示组件停止时仍在移动。若要让组件在整个动画过程中以恒定速率移动，请将起始速度和结束速度都设为 1.0

fadeOut()

void juce::ComponentAnimator::fadeOut (Component * component, int millisecondsToTake)

开始对本组件的 alpha 值进行淡出。

这是使用代理、以目标 alpha 值 0.0f 调用 animateComponent() 的快捷方式。调用此方法后你可以安全地删除组件，这不会干扰动画的进行。

fadeIn()

void juce::ComponentAnimator::fadeIn (Component * component, int millisecondsToTake)

开始对组件做淡入。

这是以目标 alpha 值 1.0f 调用 animateComponent() 的快捷方式。

cancelAnimation()

void juce::ComponentAnimator::cancelAnimation (Component * component, bool moveComponentToItsFinalPosition)

如果组件当前正在做动画，则停止它。

如果 moveComponentToItsFinalPosition 为 true，组件将立即移动到其目标位置和大小。如果为 false，则留在它当前所在的位置。

cancelAllAnimations()

void juce::ComponentAnimator::cancelAllAnimations (bool moveComponentsToTheirFinalPositions)

清除所有活动的动画。

如果 moveComponentsToTheirFinalPositions 为 true，所有组件都会被立即设置到最终位置。如果为 false，则留在它们当前所在的位置。

getComponentDestination()

Rectangle < int > juce::ComponentAnimator::getComponentDestination (Component * component)

返回组件的目标位置。

如果组件正在做动画，则返回调用 animateComponent() 时指定的目标位置。

如果指定组件当前没有在做动画，此方法只返回其当前位置。
