juce::ZipFile::Builder 类参考

详细说明

用于创建新的 zip 文件。

创建一个 ZipFile::Builder 对象，并调用其 addFile() 方法添加一些文件，然后可以用 write() 将其写入流。

addFile()

void juce::ZipFile::Builder::addFile (const File & fileToAdd, int compressionLevel, const String & storedPathName = String ())

将文件添加到将要加入归档的条目列表。

文件不会立即读取：文件将在稍后调用 writeToStream() 方法时读取。

compressionLevel 可以在 0（不压缩）到 9（最大压缩）之间。如果指定了 storedPathName 参数，你可以自定义为此文件存储的部分路径名。

void juce::ZipFile::Builder::addEntry (std::unique_ptr< InputStream > streamToRead, int compressionLevel, const String & storedPathName, Time fileModificationTime)

将流添加到将要加入归档的条目列表。

参数
streamToRead此流不会被立即读取——只存储指向流的指针，稍后在调用 writeToStream() 方法时使用，并在不再需要时由 Builder 对象删除，因此要非常小心它的生命周期以及它所依赖的任何对象的生命周期！它不能为 null。
compressionLevel这可以在 0（不压缩）到 9（最大压缩）之间。
storedPathName为此文件存储的部分路径名
fileModificationTime将作为此条目最后修改时间存储的时间戳
