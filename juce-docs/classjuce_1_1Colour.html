juce::Colour 类参考

详细说明

表示一种颜色，同时包含透明度值。

颜色在内部以 8 位无符号的红、绿、蓝和 alpha 值存储。

Colour() [3/11]

juce::Colour::Colour (uint32 argb) explicit noexcept

从 32 位 ARGB 值创建颜色。

此数字的格式为：((alpha << 24) | (red << 16) | (green << 8) | blue)。

所有分量在 0x00 到 0xff 范围内。alpha 为 0x00 表示完全透明，alpha 为 0xff 表示不透明。

contrasting() [2/3]

Colour juce::Colour::contrasting (Colour targetColour, float minLuminosityDiff) const nodiscard noexcept

返回尽可能接近目标颜色、同时与此颜色形成对比的颜色。

返回的颜色将是 targetColour，但其明度会被上下微调，使其与此颜色的明度至少相差 minLuminosityDiff 所指定的量。
