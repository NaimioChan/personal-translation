soundToPlay

URL juce::PushNotifications::Notification::soundToPlay

Optional：通知应为静音时留空。

当名称设为 default_os_sound 时，将使用默认声音。

在 OSX 上使用自定义声音时，把 URL 设为某个声音文件的名称（最好不含扩展名），并直接把该声音文件放在 bundle 的 Resources 目录中（可在 Projucer 中勾选 Xcode Resource 实现），也就是说它不能位于 Resources 的子目录（如 Resources/sound）中。另外，如果在 bundle 的 Resources 目录中找不到声音文件，OS 可能会在以下路径中查找：~/Library/Sounds、/Library/Sounds、/Network/Library/Sounds、/System/Library/Sounds。

在 iOS 上使用自定义声音时，把 URL 设为 bundle 内的相对路径，并包含文件扩展名。例如，若你的 bundle 中有 sounds 文件夹，内含 my_sound.caf 文件，则 URL 应为 sounds/my_sound.caf。

在 Android 上使用自定义声音时，把 URL 设为在 Projucer 中导出 Android 工程时包含的 raw 资源文件名称（不含扩展名，参见 Extra Android Raw Resources 设置）。

Array <int> juce::PushNotifications::Notification::vibrationPattern

Optional：以毫秒为单位设置振动模式。

第一个值表示等待多久后开始振动，第二个值表示振动多久，第三个值表示不振动多久，依此类推。例如，若模式为 1000, 2000, 3000, 4000，则收到通知一秒后设备振动两秒，接着三秒不振动，最后振动四秒。
