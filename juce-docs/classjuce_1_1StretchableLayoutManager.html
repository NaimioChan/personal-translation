juce::StretchableLayoutManager 类参考

详细说明

用于布局一组组件，这些组件有首选尺寸和尺寸限制，但允许拉伸以填满可用空间。

例如，如果你有一个包含若干其他组件的组件，且每个组件应获得总尺寸的一份，你可以使用其中之一在父组件调整尺寸时调整子组件的尺寸。然后你可以添加 StretchableLayoutResizerBar，让用户轻松地重新缩放它们。

一个 StretchableLayoutManager 只在一个维度上工作，因此如果你有一组垂直堆叠的组件，你会用一个来管理它们的高度。要构建复杂的组件布局（例如具有多个嵌套面板的应用），你会使用多个 StretchableLayoutManager。例如使用两个（一个垂直、一个水平），就可以创建可调整大小的电子表格式表格。

例如

class MyComp  : public Component
{
 StretchableLayoutManager myLayout;

    MyComp()
    {
        myLayout.setItemLayout (0,          // for item 0
                                50, 100,    // must be between 50 and 100 pixels in size
                                -0.6);      // and its preferred size is 60% of the total available space

        myLayout.setItemLayout (1,          // for item 1
                                -0.2, -0.6, // size must be between 20% and 60% of the available space
                                50);        // and its preferred size is 50 pixels
    }

 void resized()
    {
 // make a list of two of our child components that we want to reposition
 Component* comps[] = { myComp1, myComp2 };

 // this will position the 2 components, one above the other, to fit
 // vertically into the rectangle provided.
        myLayout.layOutComponents (comps, 2,
                                   0, 0, getWidth(), getHeight(),
 true);
    }
};

layOutComponents()

void juce::StretchableLayoutManager::layOutComponents (Component ** components, int numComponents, int x, int y, int width, int height, bool vertically, bool resizeOtherDimension)

获取一组与布局项目对应的组件，并定位它们以填满空间。

这会尝试给每个项目其首选尺寸，无论是相对尺寸还是绝对尺寸。

参数
components与 StretchableLayoutManager 对象已通过 setItemLayout() 被告知的每个带编号项目相对应的组件数组
numComponents传入数组中组件的数量。这应与已告知此对象的项目数量相同。
x应布局组件的矩形的左边缘
y应布局组件的矩形的上边缘
width应布局组件的矩形的宽度
height应布局组件的矩形的高度
vertically如果为 true，组件将按垂直堆叠定位，以填满矩形的高度。如果为 false，它们将并排成水平一行，填满可用宽度
resizeOtherDimension如果为 true，表示组件的另一维度将被调整尺寸以适应空间——即如果 'vertically' 参数为 true，它们的 x 位置和宽度会调整为适合 x 和 width 参数；如果 'vertically' 为 false，它们的 y 位置和高度会调整为适合 y 和 height 参数。

引用了 x、y。

getItemCurrentPosition()

int juce::StretchableLayoutManager::getItemCurrentPosition (int itemIndex) const

返回其中一个项目的当前位置。

这仅在调用 layOutComponents() 之后才是有效的调用，因为它返回此项目最后被放置的位置。如果布局是垂直的，返回的值将是项目顶部相对于放置项目的矩形顶部的 y 位置（因此例如项目 0 的位置将始终为 0，即使传入 layOutComponents() 的矩形并不在 y = 0 处）。如果布局是水平完成的，返回的位置是项目的左侧位置，同样相对于所用矩形的 x 位置。
