juce::ThreadWithProgressWindow 类参考

详细说明

一个线程，在它忙于运行时自动弹出一个带有进度条和取消按钮的模态对话框。

这些对于执行某种任务同时向用户反馈还剩多少时间等非常方便。

例如

class MyTask  : public ThreadWithProgressWindow
{
public:
    MyTask()    : ThreadWithProgressWindow ("busy...", true, true)
    {
    }

 void run()
    {
 for (int i = 0; i < thingsToDo; ++i)
        {
 // must check this as often as possible, because this is
 // how we know if the user's pressed 'cancel'
 if (threadShouldExit())
 break;

 // this will update the progress bar on the dialog box
 setProgress (i / (double) thingsToDo);

 //   ... do the business here...
        }
    }
};

void doTheTask()
{
    MyTask m;

 if (m.runThread())
    {
 // thread finished normally
    }
 else
    {
 // user pressed the cancel button
    }
}

构造函数与析构函数

ThreadWithProgressWindow()

juce::ThreadWithProgressWindow::ThreadWithProgressWindow (const String & windowTitle, bool hasProgressBar, bool hasCancelButton, int timeOutMsWhenCancelling = 10000, const String & cancelButtonText = String (), Component * componentToCentreAround = nullptr)

创建该线程。

初始时对话框不可见，只在调用 runThread() 方法时才会出现。

参数
windowTitle置于对话框顶部的标题
hasProgressBar对话框是否应有进度条（见 setProgress()）
hasCancelButton对话框是否应有取消按钮
timeOutMsWhenCancelling按下“取消”时，在强制终止线程之前等待其停止的时长（见 Thread::stopThread()）
cancelButtonText应显示在取消按钮中的文本（如果有取消按钮）。留空则使用默认的“Cancel”
componentToCentreAround如果非空，窗口将以此组件为中心定位。

被以下对象引用： threadComplete()。

runThread()

bool juce::ThreadWithProgressWindow::runThread (Priority priority = Priority::normal)

启动线程并等待其完成。

这将启动线程、显示对话框，并等待线程正常结束或取消按钮被按下。

返回之前，对话框将被隐藏。

参数
priority启动线程时使用的优先级——取值见 Thread::Priority
返回
如果线程正常结束则返回 true；如果用户按下取消则返回 false

引用了 juce::Thread::normal。
