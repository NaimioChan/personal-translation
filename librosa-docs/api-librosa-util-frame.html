librosa.util.frame

librosa.util.frame(x, *, frame_length, hop_length, axis=-1, writeable=False, subok=False) [源码]

把数据数组切成（可重叠的）帧。

本实现使用底层的跨步（stride）操作，避免复制数据。 所得帧表示是同一输入数据的新视图。

例如，一维输入 x = [0, 1, 2, 3, 4, 5, 6] 可用帧长 3、跳距 2 以两种方式分帧。 第一种（axis=-1）得到数组 x_frames：

[[0, 2, 4],
 [1, 3, 5],
 [2, 4, 6]]

其中每一列 x_frames[:, i] 是输入 x[i * hop_length : i * hop_length + frame_length] 的一段连续切片。

第二种方式（axis=0）得到数组 x_frames：

[[0, 1, 2],
 [2, 3, 4],
 [4, 5, 6]]

其中每一行 x_frames[i] 是输入的一段连续切片。

该操作可推广到更高维输入，如下方示例所示。 一般来说，分帧操作会使维数加 1：新的“帧轴”加在分帧轴之前（若 axis < 0） 或之后（若 axis >= 0）。

参数

参数类型说明
xnp.ndarray

待分帧的数组

frame_lengthint > 0 [scalar]

帧长

hop_lengthint > 0 [scalar]

帧之间前进的步数

axisint

分帧所沿的轴。

writeablebool

若为 False，则 x 的分帧视图为只读。 若为 True，则分帧视图可读写。此时写入分帧视图 也会写入输入数组 x。

subokbool

若为 True，则保留子类；否则返回的数组强制为基类数组（默认）。

返回值

返回值类型说明
x_framesnp.ndarray [shape=(…, frame_length, N_FRAMES, …)]

x 的分帧视图，例如 axis=-1（在最后一维分帧）时为：

x_frames[..., j] == x[..., j * hop_length : j * hop_length + frame_length]

若 axis=0（在第一维分帧），则：

x_frames[j] = x[j * hop_length : j * hop_length + frame_length]

异常

异常说明
ParameterError

若 x.shape[axis] < frame_length，数据不足以填满一帧。

若 hop_length < 1，帧无法前进。

参见

  • numpy.lib.stride_tricks.as_strided

示例

从单声道信号中提取 2048 采样点一帧、每帧前进 64 个采样点的帧

>>> y, sr = librosa.loadx('trumpet')
>>> frames = librosa.util.frame(y, frame_length=2048, hop_length=64)
>>> frames
array([[-1.407e-03, -2.604e-02, ..., -1.795e-05, -8.108e-06],
       [-4.461e-04, -3.721e-02, ..., -1.573e-05, -1.652e-05],
       ...,
       [ 7.960e-02, -2.335e-01, ..., -6.815e-06,  1.266e-05],
       [ 9.568e-02, -1.252e-01, ...,  7.397e-06, -1.921e-05]],
      dtype=float32)
>>> y.shape
(117601,)
>>> frames.shape
(2048, 1806)

或沿第一轴而非最后一轴分帧：

>>> frames = librosa.util.frame(y, frame_length=2048, hop_length=64, axis=0)
>>> frames.shape
(1806, 2048)

对立体声信号分帧：

>>> y, sr = librosa.loadx('trumpet', mono=False)
>>> y.shape
(2, 117601)
>>> frames = librosa.util.frame(y, frame_length=2048, hop_length=64)
(2, 2048, 1806)

把 STFT 切成 32 帧一段、重叠 50% 的定长片段

>>> y, sr = librosa.loadx('trumpet')
>>> S = np.abs(librosa.stft(y))
>>> S.shape
(1025, 230)
>>> S_patch = librosa.util.frame(S, frame_length=32, hop_length=16)
>>> S_patch.shape
(1025, 32, 13)
>>> # 第一个片段包含 S 的前 32 帧
>>> np.allclose(S_patch[:, :, 0], S[:, :32])
True
>>> # 第二个片段包含第 16 至 16+32=48 帧，依此类推
>>> np.allclose(S_patch[:, :, 1], S[:, 16:48])
True
