librosa.util.cite

librosa.util.cite(version=None, *, bib=False) [源码]

打印 librosa 的引用信息。

参数

参数类型说明
versionstr or None

要引用的 librosa 版本。若为 None，则使用当前版本。

bibbool

若为 True，返回指定 librosa 版本的 BibTeX 条目。 若为 False（默认），返回指定 librosa 版本的 DOI。

返回值

返回值类型说明
doistr

指定 librosa 版本的 DOI。

异常

异常说明
ParameterError

若引用索引中找不到所请求的版本。

示例

>>> librosa.cite("0.10.1")
"https://doi.org/10.5281/zenodo.8252662"
>>> bib = librosa.cite("0.11.0", bib=True)
>>> print(bib[:140], "...")
@misc{https://doi.org/10.5281/zenodo.15006942,
  doi = {10.5281/ZENODO.15006942},
  url = {https://zenodo.org/doi/10.5281/zenodo.15006942},
 ...
