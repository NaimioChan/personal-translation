librosa.stft

librosa.stft(y, *, n_fft=2048, hop_length=None, win_length=None, window='hann', center=True, dtype=None, pad_mode='constant', out=None) [源码]

短时傅里叶变换（STFT）。

STFT 通过在短时重叠窗上计算离散傅里叶变换（DFT）， 把信号表示到时频域。

该函数返回复值矩阵 D，其中

  • np.abs(D[..., f, t]) 是第 t 帧中频率 bin f 的幅度，

  • np.angle(D[..., f, t]) 是第 t 帧中频率 bin f 的相位。

整数 t 与 f 可借助工具函数 frames_to_samples 与 fft_frequencies 换算为物理单位。

参数

参数类型说明
ynp.ndarray [shape=(…, n)], real-valued

输入信号。支持多声道。

n_fftint > 0 [scalar]

补零后的加窗信号长度。 STFT 矩阵 D 的行数为 (1 + n_fft/2)。 默认值 n_fft=2048 个采样点在 22050 Hz 采样率（librosa 的默认采样率）下 对应 93 毫秒的物理时长。该值很适合音乐信号。 不过在语音处理中，推荐取 512，在 22050 Hz 采样率下对应 23 毫秒。 无论何种情况，建议把 n_fft 设为 2 的幂， 以提升快速傅里叶变换（FFT）算法的速度。

hop_lengthint > 0 [scalar]

相邻 STFT 列之间的音频采样点数。

取值越小，D 的列数越多，但不影响 STFT 的频率分辨率。

若未指定，默认为 win_length // 4（见下文）。

win_lengthint <= n_fft [scalar]

音频的每一帧都用长度为 win_length 的 window 加窗， 然后补零至 n_fft 长度。补零加在窗的左右两侧， 使窗在帧内居中。

取值越小，STFT 的时间分辨率越高（即区分时间上紧密相邻的脉冲的能力）， 代价是频率分辨率降低（即区分频率上紧密相邻的纯音的能力）。 该效应称为时频定位权衡，需要根据输入信号 y 的特性来调整。

若未指定，默认为 win_length = n_fft。

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

可以是：

  • 窗规格（str、tuple 或 number）； 见 scipy.signal.get_window

  • 窗函数，例如 scipy.signal.windows.hann

  • 长度为 n_fft 的向量或数组

默认为升余弦窗（‘hann’），适用于音频信号处理中的大多数应用。

centerbool

若为 True，信号 y 会被补零，使帧 D[:, t] 以 y[t * hop_length] 为中心。

若为 False，则 D[:, t] 从 y[t * hop_length] 开始。

默认为 True，这样借助 librosa.frames_to_samples 即可方便地把 D 对齐到时间网格。 不过要注意，用 librosa.stream 分析信号时， center 必须设为 False。

dtypenp.dtype, optional

D 的复数数值类型。默认根据输入信号的精度推断。

pad_modestr or function

若 center=True，该参数会传给 np.pad， 用于对信号 y 的边缘补零。默认（pad_mode="constant"） 情况下，y 两侧都补零。

注意

并非 numpy.pad 支持的所有填充模式都在此支持。 不支持 wrap、mean、maximum、median 与 minimum。

至多依赖信号边缘输入值的其他模式（如 constant、edge、linear_ramp）受支持。

若 center=False，该参数被忽略。

outnp.ndarray or None

用于存放 STFT 结果的预先分配的复值数组。 它必须与给定输入参数的形状和 dtype 兼容。

若 out 比所提供的输入信号所需的更大，则只使用 out 的前缀切片。

若未提供，则分配新数组并返回。

返回值

返回值类型说明
Dnp.ndarray [shape=(…, 1 + n_fft/2, n_frames), dtype=dtype]

短时傅里叶变换系数的复值矩阵。

若提供了预先分配的 out 数组，则 D 是 out 的引用。

若 out 比所需的更大，则 D 是切片视图：D = out[…, :n_frames]。

参见

  • istft：

    逆 STFT

  • reassigned_spectrogram：

    时频重分配频谱图

说明

该函数在级别 20 缓存。

示例

>>> y, sr = librosa.loadx('trumpet')
>>> S = np.abs(librosa.stft(y))
>>> S
array([[5.395e-03, 3.332e-03, ..., 9.862e-07, 1.201e-05],
       [3.244e-03, 2.690e-03, ..., 9.536e-07, 1.201e-05],
       ...,
       [7.523e-05, 3.722e-05, ..., 1.188e-04, 1.031e-03],
       [7.640e-05, 3.944e-05, ..., 5.180e-04, 1.346e-03]],
      dtype=float32)

改用左对齐帧，而非居中帧

>>> S_left = librosa.stft(y, center=False)

使用更短的跳距

>>> D_short = librosa.stft(y, hop_length=64)

显示频谱图

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots()
>>> img = librosa.display.specshow(S, vscale='dBFS',
...                                y_axis='log', x_axis='time', ax=ax)
>>> ax.set_title('Power spectrogram')
>>> librosa.display.colorbar_db(img)
