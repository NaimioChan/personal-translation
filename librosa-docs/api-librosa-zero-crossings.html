librosa.zero_crossings

librosa.zero_crossings(y, *, threshold=1e-10, ref_magnitude=None, pad=True, zero_pos=True, axis=-1) [源码]

找出信号 y 的过零点：即满足 sign(y[i]) != sign(y[j]) 的索引 i。

若 y 是多维的，则沿指定的 axis 计算过零点。

参数

参数类型说明
ynp.ndarray

输入数组

thresholdfloat >= 0

若非零，则把满足 -threshold <= y <= threshold 的值截断为 0。

ref_magnitudefloat > 0 or callable

若为数值，则阈值相对于 ref_magnitude 缩放。

若为可调用对象，则阈值相对于 ref_magnitude(np.abs(y)) 缩放。

padbool

若为 True，则把 y[0] 视为合法的过零点。

zero_posbool

若为 True，则数值 0 被视为正号。

若为 False，则 0、-1 和 +1 的符号两两不同。

axisint

计算过零点所沿的轴。

返回值

返回值类型说明
zero_crossingsnp.ndarray [shape=y.shape, dtype=bool]

沿所选轴表示 y 中过零点的指示数组。

说明

本函数在层级 20 缓存。

示例

>>> # Generate a time-series
>>> y = np.sin(np.linspace(0, 4 * 2 * np.pi, 20))
>>> y
array([  0.000e+00,   9.694e-01,   4.759e-01,  -7.357e-01,
        -8.372e-01,   3.247e-01,   9.966e-01,   1.646e-01,
        -9.158e-01,  -6.142e-01,   6.142e-01,   9.158e-01,
        -1.646e-01,  -9.966e-01,  -3.247e-01,   8.372e-01,
         7.357e-01,  -4.759e-01,  -9.694e-01,  -9.797e-16])
>>> # Compute zero-crossings
>>> z = librosa.zero_crossings(y)
>>> z
array([ True, False, False,  True, False,  True, False, False,
        True, False,  True, False,  True, False, False,  True,
       False,  True, False,  True], dtype=bool)
>>> # Stack y against the zero-crossing indicator
>>> librosa.util.stack([y, z], axis=-1)

>>> np.nonzero(z)
(array([ 0,  3,  5,  8, 10, 12, 15, 17, 19]),)
