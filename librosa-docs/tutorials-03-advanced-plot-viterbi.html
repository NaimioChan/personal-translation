维特比解码

本笔记本演示如何用维特比解码对逐帧状态预测施加时间平滑。

我们的示例问题是静音/非静音检测。

绘制频谱

fig, ax = plt.subplots()

可以看到，这段录音中既有静音段，也有非静音段。

# As a first step, we can plot the root-mean-square (RMS) curve
rms = librosa.feature.rms(y=y)[0]

times = librosa.frames_to_time(np.arange(len(rms)))

fig, ax = plt.subplots()
ax.plot(times, rms)
ax.axhline(0.02, color="r", alpha=0.5)
ax.set(xlabel="Time", ylabel="RMS")

0.02 处的红线表示静音检测的合理阈值。 然而 RMS 曲线偶尔会短暂低于该阈值， 我们希望检测器不要把这些短暂的下陷算作静音。 这正是维特比算法派上用场的地方！

第一步，我们通过 logistic 映射把原始 RMS 分数 转换为似然（概率）

\(P[V=1 | x] = \frac{\exp(x - \tau)}{1 + \exp(x - \tau)}\)

其中 \(x\) 表示 RMS 值，\(\tau=0.02\) 是我们的阈值。 变量 \(V\) 表示信号是非静音（1）还是静音（0）。

我们用 RMS 的标准差做归一化，以扩展概率向量的取值范围

r_normalized = (rms - 0.02) / np.std(rms)
p = np.exp(r_normalized) / (1 + np.exp(r_normalized))

可以绘制概率随时间变化的曲线：

fig, ax = plt.subplots()
ax.plot(times, p, label="P[V=1|x]")
ax.axhline(0.5, color="r", alpha=0.5, label="Decision threshold")
ax.set(xlabel="Time")
ax.legend()

它看起来与第一张图很像，只是判决阈值移到了 0.5。 简单的静音检测器会独立地判定每一帧，与相邻帧无关， 结果如下：

fig, ax = plt.subplots(nrows=2, sharex=True)
librosa.display.specshow(S_full, vscale="dBFS",
                         y_axis="log", x_axis="time", sr=sr, ax=ax[0])
ax[0].label_outer()
ax[1].step(times, p>=0.5, label="Non-silent")
ax[1].set(ylim=[0, 1.05])
ax[1].legend()

用维特比算法可以做得更好。 我们用状态 0 表示静音，状态 1 表示非静音。 假设静音帧之后是静音或非静音的概率相同，而非静音之后 更可能是非静音。 这通过构建自环转移矩阵来实现， 其中 transition[i, j] 表示下一帧从状态 i 转移到状态 j 的概率。

transition = librosa.sequence.transition_loop(2, [0.5, 0.6])
print(transition)

现在可以解码了！ 这里使用 viterbi_discriminative，因为输入是 以数据为条件的状态似然（本例中的数据是 rms）。

states = librosa.sequence.viterbi_discriminative(full_p, transition)

fig, ax = plt.subplots(nrows=2, sharex=True)
librosa.display.specshow(S_full, vscale="dBFS",
                         y_axis="log", x_axis="time", sr=sr, ax=ax[0])
ax[0].label_outer()
ax[1].step(times, p>=0.5, label="Frame-wise")
ax[1].step(times, states, linestyle="--", color="orange", label="Viterbi")
ax[1].set(ylim=[0, 1.05])
ax[1].legend()

可以看到维特比输出的状态变化次数比逐帧预测更少， 而且对能量的瞬时下陷不那么敏感。 这直接由转移矩阵控制。 自转移概率越高，解码器越不容易切换状态。
