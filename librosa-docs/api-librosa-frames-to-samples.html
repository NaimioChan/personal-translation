librosa.frames_to_samples

librosa.frames_to_samples(frames, *, hop_length=512, n_fft=None) [源码]

把帧索引转换为音频采样点索引。

参数

参数类型说明
framesnumber or np.ndarray [shape=(n,)]

帧索引或帧索引向量

hop_lengthint > 0 [scalar]

相邻帧之间的采样点数

n_fftNone or int > 0 [scalar]

可选：FFT 帧的长度。 若给出，时间换算会包含 n_fft // 2 的偏移， 以抵消使用非中心化 STFT 时的加窗效应。

返回值

返回值类型说明
timesnumber or np.ndarray

各给定帧号对应的时间（以采样点计）：

times[i] = frames[i] * hop_length

参见

  • frames_to_time：

    把帧索引转换为时间值

  • samples_to_frames：

    把采样点索引转换为帧索引

示例

>>> y, sr = librosa.loadx('choice')
>>> tempo, beats = librosa.beat.beat_track(y=y, sr=sr)
>>> beat_samples = librosa.frames_to_samples(beats, sr=sr)
