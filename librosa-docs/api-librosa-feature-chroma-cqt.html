librosa.feature.chroma_cqt

librosa.feature.chroma_cqt(*, y=None, sr=22050, C=None, hop_length=512, fmin=None, norm=inf, threshold=0.0, tuning=None, n_chroma=12, n_octaves=7, window=None, bins_per_octave=36, cqt_mode='full') [源码]

常数 Q 色度图

参数

参数类型说明
ynp.ndarray [shape=(…, n,)]

音频时间序列。支持多声道。

srnumber > 0

y 的采样率

Cnp.ndarray [shape=(…, d, t)] [Optional]

预先计算好的常数 Q 频谱图

hop_lengthint > 0

相邻色度帧之间的采样点数

fminfloat > 0

CQT 中分析的最低频率。 默认：C1 ~= 32.7 Hz

normint > 0, +-np.inf, or None

色度图的逐列归一化。

thresholdfloat

归一化之前的能量阈值。低于 阈值的值会被丢弃，从而得到稀疏的色度图。

tuningfloat [scalar] or None

相对 A440 调音的偏差（以 CQT 频格的比例计）

n_chromaint > 0

要生成的色度频格数

n_octavesint > 0

在 fmin 之上分析的八度数

windowNone or np.ndarray

传给 filters.cq_to_chroma 的可选窗参数。 必须是 n_chroma 的整数倍。 默认：36（每个半音 3 个频格） 若为 None，则与 n_chroma 一致。

bins_per_octaveint > 0, optional

CQT 中每个八度的频格数。

cqt_mode[‘full’, ‘hybrid’]

常数 Q 变换模式

返回值

返回值类型说明
chromagramnp.ndarray [shape=(…, n_chroma, t)]

输出的色度图

示例

比较长窗 STFT 色度图与 CQT 色度图

>>> y, sr = librosa.loadx('nutcracker', duration=15)
>>> chroma_stft = librosa.feature.chroma_stft(y=y, sr=sr,
...                                           n_chroma=12, n_fft=4096)
>>> chroma_cq = librosa.feature.chroma_cqt(y=y, sr=sr)
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
>>> librosa.display.specshow(chroma_stft, y_axis='chroma', x_axis='time', ax=ax[0])
>>> ax[0].set(title='chroma_stft')
>>> ax[0].label_outer()
>>> img = librosa.display.specshow(chroma_cq, y_axis='chroma', x_axis='time', ax=ax[1])
>>> ax[1].set(title='chroma_cqt')
>>> fig.colorbar(img, ax=ax)
