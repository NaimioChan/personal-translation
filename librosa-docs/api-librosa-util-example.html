librosa.util.example

librosa.util.example(key, *, hq=False, url=False) [源码]

获取由 ‘key’ 标识的示例录音。

首次请求某个示例时，会通过 HTTPS 从远程仓库下载。 之后的所有请求都使用本地缓存的录音副本。

示例列表（及其 key）见 librosa.util.list_examples。

默认情况下，本地文件缓存在 pooch.os_cache(‘librosa’) 指定的目录中。 可在导入 librosa 之前设置环境变量 LIBROSA_DATA_DIR 来覆盖：

>>> import os
>>> os.environ['LIBROSA_DATA_DIR'] = '/path/to/store/data'
>>> import librosa

参数

参数类型说明
keystr

要加载曲目的标识符

hqbool

若为 True，返回高质量版本的录音。 若为 False，返回 22KHz 单声道版本的录音。

urlbool

若为 True，返回示例文件的 URL 而非本地路径。 若为 False（默认），返回示例文件的本地路径。

返回值

返回值类型说明
pathstr

所请求示例文件的路径或远程 URL

参见

  • librosa.util.list_examples
  • pooch.os_cache

示例

加载 Johannes Brahms 的 “Hungarian Dance #5”

>>> y, sr = librosa.load(librosa.example('brahms'))

以高质量模式加载 Kevin MacLeod 的 “Vibe Ace”（librosa 此前自带的示例）

>>> y, sr = librosa.load(librosa.example('vibeace', hq=True))
