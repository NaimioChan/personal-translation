librosa.amplitude_to_db

librosa.amplitude_to_db(S, *, ref=1.0, amin=1e-05, top_db=80.0, axes='auto') [源码]

把幅度频谱图转换为 dB 刻度的频谱图。

这等价于 power_to_db(S**2, ref=ref**2, amin=amin**2, top_db=top_db)，提供它只是为了方便。

参数

参数类型说明
Snp.ndarray

输入的幅度

refscalar or callable

若为标量，则幅度 abs(S) 相对于 ref 缩放： 20 * log10(S / ref)。 输出中的零对应于 S == ref 的位置。

若为可调用对象，则参考值按 ref(S, axis=axes, keepdims=True) 计算。

aminfloat > 0 [scalar]

S 与 ref 的最小阈值

top_dbfloat >= 0 [scalar]

把输出截断在峰值以下 top_db 处： max(20 * log10(S/ref)) - top_db 对于多声道输入，当 axes=’auto’ 时，峰值会按每个声道分别计算。

axesNone, “auto”, int, or tuple of int

计算参考值时沿哪些轴（若 ref 可调用）。 若为 auto，则按 S 的末尾维度推断 axes：

  • 若 S 为标量，则 axes=None

  • 若 S 为一维，则 axes=(-1,)

  • 若 S 为 >=2 维，则 axes=(-2, -1)

返回值

返回值类型说明
S_dbnp.ndarray

以 dB 计量的 S

参见

  • power_to_db, db_to_amplitude

说明

该函数在级别 30 上缓存。
