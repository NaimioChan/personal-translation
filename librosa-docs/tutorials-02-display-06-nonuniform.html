非均匀坐标网格

本节演示如何显式设置坐标位置，以可视化间距不均匀的数据，例如音乐中按节拍同步的特征。

通常可视化音频数据时，可视化的坐标轴具有可预期的间距。例如，波形通常在样本之间具有均匀的时间间距（由采样率决定），频谱图则具有均匀间隔的频率 bin（如果使用傅里叶分析）、几何间距（如果使用常数 Q 分析）等等。

有时你可能想可视化间距不均匀、但在显示中仍保留正确坐标位置的数据。librosa.display.specshow 支持这一点，允许你用 x_coords 和 y_coords 参数显式设置坐标轴的坐标。

一个简单的用例是可视化按节拍同步的特征，其时间轴由节拍位置而非样本索引定义。我们先计算均匀间隔的特征与按节拍同步的特征，以便说明两者看起来如何。

import librosa
import numpy as np
import matplotlib.pyplot as plt
from IPython.display import HTML

y, sr = librosa.loadx("brahms")
HTML(librosa.util.example_info("brahms", html=True))

chroma = librosa.feature.chroma_cqt(y=y, sr=sr, threshold=2)
tempo, beats = librosa.beat.beat_track(y=y, sr=sr, trim=False)

现在 beats 中包含了检测到的节拍的帧索引。为确保覆盖整段音频，我们可以把开头（第 0 帧）加入节拍数组，并用 librosa.util.sync 在每个区间内聚合色度特征。

beats = librosa.util.fix_frames(beats, x_min=0)
chroma_sync = librosa.util.sync(chroma, beats, aggregate=np.median)

fig, ax = plt.subplots(nrows=2)
librosa.display.specshow(chroma, y_axis="chroma", x_axis="time", ax=ax[0])
ax[0].set(title="Uniformly sampled chroma", xlabel=None)
librosa.display.specshow(chroma_sync, y_axis="chroma", ax=ax[1])
ax[1].set(title="Beat-synchronous chroma", xlabel=None)

上图基本可用，但两个横轴使用的是完全不同的布局：上面以秒为单位，下面以节拍索引（0, 1, 2, …）为单位。更重要的是，节拍间距的不均匀导致两个子图的视觉表示之间出现明显偏移，这在上图中约 35 秒开始的最后一段尤其明显。

我们可以通过把第二次 specshow 调用的 x_coords 参数显式设为节拍时间来解决，节拍时间可以用 librosa.frames_to_time 计算。提供 x_coords 时，坐标数组的长度应与所显示数据的长度一致：

# Convert beat frames to times
beat_times = librosa.frames_to_time(beats, sr=sr)
print(f"chroma_sync.shape = {chroma_sync.shape}\nbeat_times.shape = {beat_times.shape}")
chroma_sync.shape = (12, 112)
beat_times.shape = (112,)
fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
librosa.display.specshow(chroma, y_axis="chroma", x_axis="time", ax=ax[0])
ax[0].set(title="Uniformly sampled chroma", xlabel=None)

librosa.display.specshow(chroma_sync, y_axis="chroma",
                         x_coords=beat_times, x_axis="time",
                         ax=ax[1])
ax[1].set(title="Beat-synchronous chroma", xlabel=None)

现在两个子图在时间上对齐了，我们还可以用 x_axis=’time’ 参数，基于所提供的坐标自动把 x 轴刻度格式化为秒，而不是假设均匀采样。注意按节拍同步的图看起来结束得较早：这是因为数据只定义到最后一个节拍位置。

小结

显式坐标位置可用于任何 specshow 显示，且该功能不限于时间类坐标轴。每个 x_axis= 或 y_axis= 设置都涉及相应坐标网格的计算，而 x_coords 和 y_coords 参数允许你用自己的坐标位置覆盖这些计算，实现高度定制的显示。一般来说，你仍然会想用 x_axis= 和 y_axis= 参数来自动格式化坐标轴。
