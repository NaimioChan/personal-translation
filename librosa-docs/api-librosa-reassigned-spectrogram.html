librosa.reassigned_spectrogram

librosa.reassigned_spectrogram(y, *, sr=22050, S=None, n_fft=2048, hop_length=None, win_length=None, window='hann', center=True, reassign_frequencies=True, reassign_times=True, ref_power=1e-06, fill_nan=False, clip=True, dtype=None, pad_mode='constant') [源码]

时频重指派频谱图。

重指派向量按 [1] 中的式 5.20 与 5.23 计算：

t_reassigned = t + np.real(S_th/S_h)
omega_reassigned = omega - np.imag(S_dh/S_h)

其中 S_h 是用原始窗计算的复数 STFT，S_dh 是用原始窗的导数计算的复数 STFT，S_th 是用原始窗乘以相对窗中心的时间偏移后计算的复数 STFT。其他算法见 [2]，方法的历史与讨论见 [3] 与 [4]。

[1] Flandrin, P., Auger, F., & Chassande-Mottin, E. (2002). Time-Frequency reassignment: From principles to algorithms. In Applications in Time-Frequency Signal Processing (Vol. 10, pp. 179-204). CRC Press.

[2] Fulop, S. A., & Fitz, K. (2006). Algorithms for computing the time-corrected instantaneous frequency (reassigned) spectrogram, with applications. The Journal of the Acoustical Society of America, 119(1), 360. doi:10.1121/1.2133000

[3] Auger, F., Flandrin, P., Lin, Y.-T., McLaughlin, S., Meignen, S., Oberlin, T., & Wu, H.-T. (2013). Time-Frequency Reassignment and Synchrosqueezing: An Overview. IEEE Signal Processing Magazine, 30(6), 32-41. doi:10.1109/MSP.2013.2265316

[4] Hainsworth, S., Macleod, M. (2003). Time-frequency reassignment: a review and analysis. Tech. Rep. CUED/FINFENG/TR.459, Cambridge University Engineering Department

ynp.ndarray [shape=(…, n)], real-valued

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

Snp.ndarray [shape=(…, d, t)] or None

（可选）用传给 reassigned_spectrogram 的其他参数计算出的复数 STFT

n_fftint > 0 [scalar]

FFT 帧长。默认 2048。

hop_lengthint > 0 [scalar]

跳距，即相邻帧之间的采样点数量。 若未提供，默认为 win_length // 4。

win_lengthint > 0, <= n_fft

窗长。默认 n_fft。 详见 stft。

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

  • 窗的规格（字符串、元组、数字）； 见 scipy.signal.get_window

  • 窗函数，如 scipy.signal.windows.hann

  • 用户指定的、长度为 n_fft 的窗向量

详见 stft。

centerbool

  • 若为 True（默认），对信号 y 做填充，使帧 S[:, t] 以 y[t * hop_length] 为中心。推荐用法见 说明。

  • 若为 False，S[:, t] 从 y[t * hop_length] 开始。

reassign_frequenciesbool

  • 若为 True（默认），返回的频率为瞬时频率估计。

  • 若为 False，返回的频率为所有帧的 STFT bin 频率的只读视图。

reassign_timesbool

  • 若为 True（默认），返回的时刻为各 bin 校正（重指派）后的时间估计。

  • 若为 False，返回的时刻为所有 bin 的 STFT 帧时间的只读视图。

ref_powerfloat >= 0 or callable

估计时频重指派所需的最小功率阈值。 任何满足 np.abs(S[f, t])**2 < ref_power 的 bin，其频率与时间均返回为 np.nan，除非 fill_nan 为 True。若提供 0，则只有功率为零的 bin 返回为 np.nan（除非 fill_nan=True）。

fill_nanbool

  • 若为 False（默认），低于 ref_power 所给功率阈值的 bin，其频率与时间重指派结果返回为 np.nan。

  • 若为 True，这些 bin 的频率与时间重指派结果返回为 bin 中心频率与帧时间。

clipbool

  • 若为 True（默认），超出 [0, 0.5 * sr] 范围的估计频率，或超出 [0, len(y) / sr] 范围的时刻，将被裁剪到这些范围内。

  • 若为 False，可能返回超出频谱图范围的估计频率与时刻。

dtypenumeric type

STFT 计算所用的复数数值类型。默认与输入信号的精度匹配。

pad_modestr

若 center=True，在信号边缘使用的填充模式。 默认情况下，STFT 使用零填充。

返回值

返回值类型说明
freqs, times, magsnp.ndarray [shape=(…, 1 + n_fft/2, t), dtype=real]
  • 瞬时频率：

    freqs[..., f, t] 是 bin f、帧 t 的频率。 若 reassign_frequencies=False，则是形状相同的只读数组，包含所有帧的 bin 中心频率。

  • 重指派时刻：

    times[..., f, t] 是 bin f、帧 t 的时刻。 若 reassign_times=False，则是形状相同的只读数组，包含所有 bin 的帧时间。

  • 短时傅里叶变换的幅度：

    mags[..., f, t] 是 bin f、帧 t 的幅度。

警告说明

支撑集为零的频率或时间估计将产生除零警告，并返回为 np.nan，除非 fill_nan=True。

参见

  • stft：

    短时傅里叶变换

说明

建议对此函数使用 center=False，而非 librosa 默认的 True。与 stft 不同，重指派时刻并不对齐到各帧的左侧或中心，因此填充信号不影响重指派时刻的含义。不过，重指派假定每个 FFT bin 中的能量只关联于一个信号分量与一个冲激事件。

若 reassign_times 为 False，返回的帧时间将依据 center 的取值对齐到帧的左侧或中心。此时若 center 为 True，建议使用 pad_mode="wrap"，以便对边界帧的瞬时频率做有效估计。

示例

>>> import matplotlib.pyplot as plt
>>> amin = 1e-10
>>> n_fft = 64
>>> sr = 4000
>>> y = 1e-3 * librosa.clicks(times=[0.3], sr=sr, click_duration=1.0,
...                           click_freq=1200.0, length=8000) +\
...     1e-3 * librosa.clicks(times=[1.5], sr=sr, click_duration=0.5,
...                           click_freq=400.0, length=8000) +\
...     1e-3 * librosa.chirp(fmin=200, fmax=1600, sr=sr, duration=2.0) +\
...     1e-6 * np.random.randn(2*sr)
>>> freqs, times, mags = librosa.reassigned_spectrogram(y=y, sr=sr,
...                                                     n_fft=n_fft)
>>> mags_db = librosa.amplitude_to_db(mags, ref=np.max)
>>> fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
>>> img = librosa.display.specshow(mags_db, x_axis="s", y_axis="linear", sr=sr,
...                          hop_length=n_fft//4, ax=ax[0])
>>> ax[0].set(title="Spectrogram", xlabel=None)
>>> ax[0].label_outer()
>>> ax[1].scatter(times, freqs, c=mags_db, cmap="magma", alpha=0.1, s=5)
>>> ax[1].set_title("Reassigned spectrogram")
>>> librosa.display.colorbar_db(img, ax=ax)
