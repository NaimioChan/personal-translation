librosa.feature.poly_features

librosa.feature.poly_features(*, y=None, sr=22050, S=None, n_fft=2048, hop_length=512, win_length=None, window='hann', center=True, pad_mode='constant', order=1, freq=None) [源码]

获取把 n 阶多项式拟合到频谱图各列所得的系数。

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的音频采样率

Snp.ndarray [shape=(…, d, t)] or None

（可选）频谱图幅度

n_fftint > 0 [scalar]

FFT 帧长度

hop_lengthint > 0 [scalar]

STFT 的跳距。详见 librosa.stft。

win_lengthint <= n_fft [scalar]

每一帧音频都用 window() 加窗。 窗的长度为 win_length，随后补零 至 n_fft 长度。 若未指定，默认为 win_length = n_fft。

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

  • 窗的规格（字符串、元组或数值）； 见 scipy.signal.get_window

  • 窗函数，例如 scipy.signal.windows.hann

  • 长度为 n_fft 的向量或数组

centerbool

  • 若为 True，则对信号 y 进行填充，使帧 t 以 y[t * hop_length] 为中心。

  • 若为 False，则帧 t 起始于 y[t * hop_length]

pad_modestr

若 center=True，在信号边缘使用的填充模式。 默认情况下，STFT 使用零填充。

orderint > 0

要拟合的多项式阶数

freqNone or np.ndarray [shape=(d,) or shape=(…, d, t)]

频谱图频格的中心频率。 若为 None，则使用 FFT 频格的中心频率。 否则，可以是一个含 d 个中心频率的数组， 也可以是由 librosa.reassigned_spectrogram 构建的中心频率矩阵

返回值

返回值类型说明
coefficientsnp.ndarray [shape=(…, order+1, t)]

每一帧的多项式系数。

coefficients[..., 0, :] 对应最高次（order），

coefficients[..., 1, :] 对应次高次（order-1），

直到常数项 coefficients[..., order, :]。

示例

>>> y, sr = librosa.loadx('trumpet')
>>> S = np.abs(librosa.stft(y))

对每一帧拟合 0 阶（常数）多项式

>>> p0 = librosa.feature.poly_features(S=S, order=0)

对每一帧拟合线性多项式

>>> p1 = librosa.feature.poly_features(S=S, order=1)

对每一帧拟合二次多项式

>>> p2 = librosa.feature.poly_features(S=S, order=2)

绘制结果以便比较

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=4, sharex=True, figsize=(8, 8))
>>> times = librosa.times_like(p0)
>>> ax[0].plot(times, p0[0], label='order=0', alpha=0.8)
>>> ax[0].plot(times, p1[1], label='order=1', alpha=0.8)
>>> ax[0].plot(times, p2[2], label='order=2', alpha=0.8)
>>> ax[0].legend()
>>> ax[0].label_outer()
>>> ax[0].set(ylabel='Constant term ')
>>> ax[1].plot(times, p1[0], label='order=1', alpha=0.8)
>>> ax[1].plot(times, p2[1], label='order=2', alpha=0.8)
>>> ax[1].set(ylabel='Linear term')
>>> ax[1].label_outer()
>>> ax[1].legend()
>>> ax[2].plot(times, p2[0], label='order=2', alpha=0.8)
>>> ax[2].set(ylabel='Quadratic term')
>>> ax[2].legend()
>>> librosa.display.specshow(S, vscale='dBFS',
...                          y_axis='log', x_axis='time', ax=ax[3])
