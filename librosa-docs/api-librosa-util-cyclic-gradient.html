librosa.util.cyclic_gradient

librosa.util.cyclic_gradient(data, *, edge_order=1, axis=-1) [源码]

估计函数在均匀采样的周期域上的梯度。

这基本上与 np.gradient 相同，区别在于边缘效应通过环绕观测值（即假定周期性）处理， 而非外推。

参数

参数类型说明
datanp.ndarray

在周期域上均匀间隔位置观测到的函数值

edge_order{1, 2}

用于估计梯度的差分近似的阶数

axisint

计算梯度所沿的轴。

返回值

返回值类型说明
gradnp.ndarray like data

沿指定轴对 data 求得的梯度。

参见

  • numpy.gradient

示例

该示例用 64 个采样点，分别以直接（非周期）与周期梯度计算来估计余弦（-正弦）的梯度。

>>> import matplotlib.pyplot as plt
>>> x = 2 * np.pi * np.linspace(0, 1, num=64, endpoint=False)
>>> y = np.cos(x)
>>> grad = np.gradient(y)
>>> cyclic_grad = librosa.util.cyclic_gradient(y)
>>> true_grad = -np.sin(x) * 2 * np.pi / len(x)
>>> fig, ax = plt.subplots()
>>> ax.plot(x, true_grad, label='True gradient', linewidth=5,
...          alpha=0.35)
>>> ax.plot(x, cyclic_grad, label='cyclic_gradient')
>>> ax.plot(x, grad, label='np.gradient', linestyle=':')
>>> ax.legend()
>>> # 放大序列的前一部分
>>> ax.set(xlim=[0, np.pi/16], ylim=[-0.025, 0.025])
