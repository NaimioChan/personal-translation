librosa.tone

librosa.tone(frequency, *, sr=22050, length=None, duration=None, phi=None) [源码]

构造给定频率的纯音（余弦）信号。

参数

参数类型说明
frequencyfloat > 0

频率

srnumber > 0

输出信号的期望采样率

lengthint > 0

输出信号的期望采样点数。 当同时指定 duration 与 length 时， length 优先。

durationfloat > 0

期望的时长（秒）。 当同时指定 duration 与 length 时， length 优先。

phifloat or None

相位偏移，单位为弧度。若未指定，默认为 -np.pi * 0.5。

返回值

返回值类型说明
tone_signalnp.ndarray [shape=(length,), dtype=float64]

合成的纯正弦音信号

异常

异常说明
ParameterError

  • 若未提供 frequency。

  • 若 length 与 duration 均未提供。

示例

生成一个纯正弦音 A4

>>> tone = librosa.tone(440, duration=1, sr=22050)

或用 length 生成相同的信号

>>> tone = librosa.tone(440, sr=22050, length=22050)

显示频谱图

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots()
>>> S = librosa.feature.melspectrogram(y=tone)
>>> librosa.display.specshow(S, vscale='dBFS[power]',
...                          x_axis='time', y_axis='mel', ax=ax)
