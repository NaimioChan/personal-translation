librosa.segment.agglomerative

librosa.segment.agglomerative(data, k, *, clusterer=None, axis=-1) [源码]

自底向上的时间分割。

使用受时间约束的凝聚聚类方法，把 data 划分为 k 个连续段。

参数

参数类型说明
datanp.ndarray

要聚类的数据

kint > 0 [scalar]

要产生的段数

clusterersklearn.cluster.AgglomerativeClustering, optional

可选的 AgglomerativeClustering 对象。 若为 None，将实例化一个带约束的 Ward 对象。

axisint

聚类所沿的轴。 默认取最后一个轴（-1）。

返回值

返回值类型说明
boundariesnp.ndarray [shape=(k,)]

检测到的各段的左边界（帧号）。第一个左边界始终为 0。

参见

  • sklearn.cluster.AgglomerativeClustering

示例

按色度相似度聚类，切分为 20 段

>>> y, sr = librosa.loadx('nutcracker', duration=15)
>>> chroma = librosa.feature.chroma_cqt(y=y, sr=sr, threshold=0.5)
>>> bounds = librosa.segment.agglomerative(chroma, 20)
>>> bound_times = librosa.frames_to_time(bounds, sr=sr)
>>> bound_times
array([ 0.   ,  0.65 ,  1.091,  1.927,  2.438,  2.902,  3.924,
        4.783,  5.294,  5.712,  6.13 ,  7.314,  8.522,  8.916,
        9.66 , 10.844, 11.238, 12.028, 12.492, 14.095])

在色度图上绘制分割结果

>>> import matplotlib.pyplot as plt
>>> import matplotlib.transforms as mpt
>>> fig, ax = plt.subplots()
>>> trans = mpt.blended_transform_factory(
...             ax.transData, ax.transAxes)
>>> librosa.display.specshow(chroma, y_axis='chroma', x_axis='time', ax=ax)
>>> hl = librosa.display.highlight(ax=ax)
>>> ax.vlines(bound_times, 0, 1, linestyle='--', path_effects=hl,
...           label='Segment boundaries',
...           transform=trans)
>>> ax.legend()
>>> ax.set(title='Power spectrogram')
