librosa.feature.spectral_contrast

librosa.feature.spectral_contrast(*, y=None, sr=22050, S=None, n_fft=2048, hop_length=512, win_length=None, window='hann', center=True, pad_mode='constant', freq=None, fmin=200.0, n_bands=6, quantile=0.02, linear=False) [源码]

计算频谱对比度

频谱图 S 的每一帧都被划分为若干子带。 对每个子带，通过比较 上分位数（峰值能量）与下分位数（谷值能量）的平均能量， 估计能量对比度。高对比度值一般 对应清晰、窄带的信号，而低对比度值 对应宽带噪声。[1]

[1] Jiang, Dan-Ning, Lie Lu, Hong-Jiang Zhang, Jian-Hua Tao, and Lian-Hong Cai. “Music type classification by spectral contrast feature.” In Multimedia and Expo, 2002. ICME’02. Proceedings. 2002 IEEE International Conference on, vol. 1, pp. 113-116. IEEE, 2002.

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的音频采样率

Snp.ndarray [shape=(…, d, t)] or None

（可选）频谱图幅度

n_fftint > 0 [scalar]

FFT 帧长度

hop_lengthint > 0 [scalar]

STFT 的跳距。详见 librosa.stft。

win_lengthint <= n_fft [scalar]

每一帧音频都用 window() 加窗。 窗的长度为 win_length，随后补零 至 n_fft 长度。 若未指定，默认为 win_length = n_fft。

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

  • 窗的规格（字符串、元组或数值）； 见 scipy.signal.get_window

  • 窗函数，例如 scipy.signal.windows.hann

  • 长度为 n_fft 的向量或数组

centerbool

  • 若为 True，则对信号 y 进行填充，使帧 t 以 y[t * hop_length] 为中心。

  • 若为 False，则帧 t 起始于 y[t * hop_length]

pad_modestr

若 center=True，在信号边缘使用的填充模式。 默认情况下，STFT 使用零填充。

freqNone or np.ndarray [shape=(d,)]

频谱图频格的中心频率。 若为 None，则使用 FFT 频格的中心频率。 否则，可以是一个含 d 个中心频率的数组。

fminfloat > 0

第一个频带 [0, fmin] 的频率截止点。 后续频带将覆盖 [fmin, 2*fmin]`、`[2*fmin, 4*fmin] 等。

n_bandsint > 1

频率频带数

quantilefloat in (0, 1)

用于确定峰值与谷值的分位数

linearbool

若为 True，返回幅度的线性差值： peaks - valleys。 若为 False，返回对数差值： log(peaks) - log(valleys)。

返回值

返回值类型说明
contrastnp.ndarray [shape=(…, n_bands + 1, t)]

频谱对比度值的每一行对应一个 基于八度的频率

示例

>>> y, sr = librosa.loadx('trumpet')
>>> S = np.abs(librosa.stft(y))
>>> contrast = librosa.feature.spectral_contrast(S=S, sr=sr)
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> img1 = librosa.display.specshow(S, vscale='dBFS',
...                          y_axis='log', x_axis='time', ax=ax[0])
>>> librosa.display.colorbar_db(img1)
>>> ax[0].set(title='Power spectrogram')
>>> ax[0].label_outer()
>>> img2 = librosa.display.specshow(contrast, x_axis='time', ax=ax[1])
>>> fig.colorbar(img2, ax=[ax[1]])
>>> ax[1].set(ylabel='Frequency bands', title='Spectral contrast')
