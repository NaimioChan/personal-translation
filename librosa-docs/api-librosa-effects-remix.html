librosa.effects.remix

librosa.effects.remix(y, intervals, *, align_zeros=True) [源码]

通过重新排列时间区间来对音频信号做混音。

参数

参数类型说明
ynp.ndarray [shape=(…, t)]

音频时间序列。支持多声道。

intervalsiterable of tuples (start, end)

可迭代对象（类列表或生成器），其中第 i``th 项 ``intervals[i] 给出 y 某个切片的起点与终点（以采样点数计）。

align_zerosbool

若为 True，区间边界会映射到 y 中最近的过零点。若 y 为立体声，则先转为单声道再计算过零点。

返回值

返回值类型说明
y_remixnp.ndarray [shape=(…, d)]

按 intervals 指定顺序重新排列后的 y

示例

加载示例曲目并倒转节拍

>>> y, sr = librosa.loadx('choice')

计算节拍

>>> _, beat_frames = librosa.beat.beat_track(y=y, sr=sr,
...                                          hop_length=512)

把帧转换为采样点索引

>>> beat_samples = librosa.frames_to_samples(beat_frames)

由相邻事件生成区间

>>> intervals = librosa.util.frame(beat_samples, frame_length=2,
...                                hop_length=1).T

倒转节拍区间

>>> y_out = librosa.effects.remix(y, intervals[::-1])
