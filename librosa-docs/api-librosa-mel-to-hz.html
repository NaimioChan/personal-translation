librosa.mel_to_hz

librosa.mel_to_hz(mels, *, htk=False) [源码]

把 mel bin 编号转换为频率

参数

参数类型说明
melsnp.ndarray [shape=(n,)], float

要转换的 mel bin

htkbool

使用 HTK 公式而不是 Slaney 公式

返回值

返回值类型说明
frequenciesnp.ndarray [shape=(n,)]

输入 mel 值对应的频率（Hz）

参见

  • hz_to_mel

示例

>>> librosa.mel_to_hz(3)
200.
>>> librosa.mel_to_hz([1,2,3,4,5])
array([  66.667,  133.333,  200.   ,  266.667,  333.333])
