librosa.onset.onset_strength_multi

librosa.onset.onset_strength_multi(*, y=None, sr=22050, S=None, n_fft=2048, hop_length=512, lag=1, max_size=1, ref=None, detrend=False, center=True, feature=None, aggregate=None, channels=None, **kwargs) [源码]

跨多个通道计算频谱通量起始强度包络。

通道 i 在时刻 t 的起始强度由下式确定：

mean_{f in channels[i]} max(0, S[f, t+1] - S[f, t])

参数

参数类型说明
ynp.ndarray [shape=(…, n,)]

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

Snp.ndarray [shape=(…, d, m)]

预先计算好的（对数功率）频谱图

n_fftint > 0 [scalar]

未提供 S 时，feature() 所用的 FFT 帧长。

hop_lengthint > 0 [scalar]

未提供 S 时，feature() 所用的跳距。

lagint > 0

计算差分的时间滞后

max_sizeint > 0

局部最大值滤波器的尺寸（以频率 bin 计）。 设为 1 表示关闭滤波。

refNone or np.ndarray [shape=(d, m)]

可选的预先计算参考频谱，形状与 S 相同。 若未提供，将从 S 计算。 若提供，将覆盖由 max_size 控制的局部最大值滤波。

detrendbool [scalar]

对起始强度滤波以去除直流分量

centerbool [scalar]

把起始函数平移 n_fft // (2 * hop_length) 帧。 这对应于短时傅里叶变换中使用居中的分帧分析。

featurefunction

计算时间序列特征（如缩放后的频谱图）的函数。 默认使用 librosa.feature.melspectrogram，取 fmax=sr/2

必须支持参数：y, sr, n_fft, hop_length

aggregatefunction or False

合并各频率 bin 的起始强度时所用的聚合函数。

若为 False，则不做聚合。

默认：np.mean

channelslist or None

通道边界数组或 slice 对象。 若为 None，则生成单个通道覆盖全部频带。

**kwargsadditional keyword arguments

未提供 S 时传给 feature() 的附加参数。

返回值

返回值类型说明
onset_envelopenp.ndarray [shape=(…, n_channels, m)]

包含各指定通道起始强度包络的数组

异常

异常说明
ParameterError

若 (y, sr) 与 S 均未提供

参见

  • onset_strength

说明

此函数在缓存级别 30 上缓存。

示例

先加载一段音频并绘制频谱图

>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('choice', duration=5)
>>> D = np.abs(librosa.stft(y))
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> img1 = librosa.display.specshow(D, vscale='dBFS',
...                          y_axis='log', x_axis='time', ax=ax[0])
>>> ax[0].set(title='Power spectrogram')
>>> ax[0].label_outer()
>>> librosa.display.colorbar_db(img1, ax=ax[0])

在四个子带上构造标准的起始函数

>>> onset_subbands = librosa.onset.onset_strength_multi(y=y, sr=sr,
...                                                     channels=[0, 32, 64, 96, 128])
>>> img2 = librosa.display.specshow(onset_subbands, x_axis='time', ax=ax[1])
>>> ax[1].set(ylabel='Sub-bands', title='Sub-band onset strength')
>>> fig.colorbar(img2, ax=[ax[1]])
