librosa.power_to_db

librosa.power_to_db(S, *, ref=1.0, amin=1e-10, top_db=80.0, axes='auto') [源码]

把功率频谱图（幅度平方）转换为分贝（dB）单位

以数值稳定的方式计算缩放 10 * log10(S / ref)。

参数

参数类型说明
Snp.ndarray

输入功率

refscalar or callable

若为标量，幅度 abs(S) 相对于 ref 缩放：

10 * log10(S / ref)

输出的零值对应于 S == ref 的位置。

若为可调用对象，参考值按 ref(S, axis=axes, keepdims=True) 计算。

aminfloat > 0 [scalar]

abs(S) 与 ref 的最小阈值

top_dbfloat >= 0 [scalar]

把输出在低于峰值 top_db 处截断： max(10 * log10(S/ref)) - top_db 对多声道输入，当 axes=’auto’ 时， 峰值按每个声道分别计算。

axes: None, “auto”, int, or tuple of int

计算参考值（若 ref 为可调用对象）所沿的轴。 若为 auto，则轴将推断为 S 的尾部维度：

  • 若 S 为标量，则 axes=None

  • 若 S 为一维，则 axes=(-1,)

  • 若 S 为二维及以上，则 axes=(-2, -1)

返回值

返回值类型说明
S_dbnp.ndarray

S_db ~= 10 * log10(S) - 10 * log10(ref)

参见

  • perceptual_weighting
  • db_to_power
  • amplitude_to_db
  • db_to_amplitude

说明

此函数在缓存级别 30 上缓存。

示例

从波形 y 得到功率频谱图

>>> y, sr = librosa.loadx('trumpet')
>>> S = np.abs(librosa.stft(y))
>>> librosa.power_to_db(S**2)
array([[-41.809, -41.809, ..., -41.809, -41.809],
       [-41.809, -41.809, ..., -41.809, -41.809],
       ...,
       [-41.809, -41.809, ..., -41.809, -41.809],
       [-41.809, -41.809, ..., -41.809, -41.809]], dtype=float32)

计算相对峰值功率的 dB 值

>>> librosa.power_to_db(S**2, ref=np.max)
array([[-80., -80., ..., -80., -80.],
       [-80., -80., ..., -80., -80.],
       ...,
       [-80., -80., ..., -80., -80.],
       [-80., -80., ..., -80., -80.]], dtype=float32)

或与中位数功率比较

>>> librosa.power_to_db(S**2, ref=np.median)
array([[16.578, 16.578, ..., 16.578, 16.578],
       [16.578, 16.578, ..., 16.578, 16.578],
       ...,
       [16.578, 16.578, ..., 16.578, 16.578],
       [16.578, 16.578, ..., 16.578, 16.578]], dtype=float32)

并绘制结果

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
>>> imgpow = librosa.display.specshow(S**2, sr=sr, y_axis='log', x_axis='time',
...                                   ax=ax[0])
>>> ax[0].set(title='Power spectrogram')
>>> ax[0].label_outer()
>>> imgdb = librosa.display.specshow(librosa.power_to_db(S**2, ref=np.max),
...                                  sr=sr, y_axis='log', x_axis='time', ax=ax[1])
>>> ax[1].set(title='Log-Power spectrogram')
>>> fig.colorbar(imgpow, ax=ax[0])
>>> librosa.display.colorbar_db(imgdb, ax=ax[1])
