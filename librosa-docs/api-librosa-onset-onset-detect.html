librosa.onset.onset_detect

librosa.onset.onset_detect(*, y=None, sr=22050, onset_envelope=None, hop_length=512, backtrack=False, energy=None, units='frames', normalize=True, sparse=True, **kwargs) [源码]

通过在起始强度包络中拾取峰值来定位音符起始点事件。

peak_pick 的参数是在 [1] 提供的数据集上做大规模超参数优化后选定的。

[1] CPJKU/onset_db

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

onset_envelopenp.ndarray [shape=(…, m)]

（可选）预先计算好的起始强度包络

hop_lengthint > 0 [scalar]

跳距（以采样点为单位）

backtrackbool

若为 True，检测到的起始点事件会回溯至 energy 最近的前置极小值。

这在用起始点作为分割切片点时最有用。

注意

仅在 sparse=True 时支持回溯。

energynp.ndarray [shape=(m,)] (optional)

用于回溯检测到的起始点事件的能量函数。 若未提供，则使用 onset_envelope。

units{‘frames’, ‘samples’, ‘time’}

检测到的起始点事件所用的编码单位。 默认使用 ‘frames’。

normalizebool

若为 True（默认），在检测前把起始包络归一化到最小值为 0、最大值为 1。这有助于统一 librosa.util.peak_pick 的参数。

否则起始包络不做归一化。

sparsebool

若为 True（默认），检测结果以帧、采样点或时间索引数组的形式返回（由 units= 指定）。

若为 False，检测结果编码为稠密布尔数组，当帧索引 n 处有起始点时 onsets[n] 为 True。

注意

仅在 sparse=False 时支持多声道输入。

**kwargsadditional keyword arguments

峰值拾取的附加参数。

详见 librosa.util.peak_pick。

返回值

返回值类型说明
onsetsnp.ndarray [shape=(n_onsets,) or onset_envelope.shape]

检测到的起始点的估计位置，单位由参数指定。默认是帧索引。

若 sparse=False，onsets[…, n] 表示帧索引 n 处检测到起始点。

注意

若检测不到任何起始强度，onset_detect 返回空数组（sparse=True）或全 False 数组（sparse=False）。

异常

异常说明
ParameterError

若 y 与 onsets 均未提供

或 units 不属于 ‘frames’、‘samples’、‘time’ 之一

参见

  • onset_strength：

    逐帧计算起始强度

  • onset_backtrack：

    回溯起始点事件

  • librosa.util.peak_pick：

    从时间序列中拾取峰值

示例

从信号中获取起始点时刻

>>> y, sr = librosa.loadx('trumpet')
>>> librosa.onset.onset_detect(y=y, sr=sr, units='time')
array([0.07 , 0.232, 0.395, 0.604, 0.743, 0.929, 1.045, 1.115,
       1.416, 1.672, 1.881, 2.043, 2.206, 2.368, 2.554, 3.019])

或使用预先计算好的起始包络

>>> o_env = librosa.onset.onset_strength(y=y, sr=sr)
>>> times = librosa.times_like(o_env, sr=sr)
>>> onset_frames = librosa.onset.onset_detect(onset_envelope=o_env, sr=sr)
>>> import matplotlib.pyplot as plt
>>> D = np.abs(librosa.stft(y))
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> librosa.display.specshow(D, vscale='dBFS',
...                          x_axis='time', y_axis='log', ax=ax[0], sr=sr)
>>> ax[0].set(title='Power spectrogram')
>>> ax[0].label_outer()
>>> ax[1].plot(times, o_env, label='Onset strength')
>>> ax[1].vlines(times[onset_frames], 0, o_env.max(), color='r', alpha=0.9,
...            linestyle='--', label='Onsets')
>>> ax[1].legend()
