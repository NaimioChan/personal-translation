librosa.effects.deemphasis

librosa.effects.deemphasis(y, *, coef=0.97, zi=None, return_zf=False) [源码]

用 preemphasis() 的逆运算对音频信号去加重：

若 y = preemphasis(x, coef=coef, zi=zi)，则去加重为：

>>> x[i] = y[i] + coef * x[i-1]
>>> x = deemphasis(y, coef=coef, zi=zi)

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频信号。支持多声道。

coefpositive number

预加重系数。coef 的典型取值在 0 到 1 之间。

极限情况 coef=0 时信号不变。

coef=1 时结果为信号的一阶差分。

默认值（0.97）与 MFCC 的 HTK 实现中所用的预加重滤波器一致 [1]。

[1] https://htk.eng.cam.ac.uk/

zinumber

滤波器初始状态。若要反转之前的 preemphasis()，应使用相同的值。

默认情况下 zi 初始化为 ((2 - coef) * y[0] - y[1]) / (3 - coef)。该值对应 preemphasis() 中 zi 默认初始化 2*x[0] - x[1] 经变换后的结果。

return_zfbool

若为 True，返回最终的滤波器状态。 若为 False，只返回预加重后的信号。

返回值

返回值类型说明
y_outnp.ndarray

去加重后的信号

zfnumber

若 return_zf=True，同时返回最终的滤波器状态

参见

  • preemphasis

示例

应用标准的预加重滤波器，再用去加重还原

>>> y, sr = librosa.loadx('trumpet')
>>> y_filt = librosa.effects.preemphasis(y)
>>> y_deemph = librosa.effects.deemphasis(y_filt)
>>> np.allclose(y, y_deemph)
True
