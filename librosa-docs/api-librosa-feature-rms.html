librosa.feature.rms

librosa.feature.rms(*, y=None, S=None, frame_length=2048, hop_length=512, center=True, pad_mode='constant', dtype=<class 'numpy.float32'>) [源码]

计算每一帧的均方根（RMS）值。

输入可以给时间序列 y，也可以给 频谱图幅度 S。 由音频采样点计算 RMS 值更快，因为它不需要 做 STFT 计算。不过，用频谱图能更准确地 表示能量随时间的分布，因为它的帧可以加窗， 所以若能拿到 S，优先使用它。

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

（可选）音频时间序列。若未输入 S 则必需。 支持多声道。

Snp.ndarray [shape=(…, d, t)] or None

（可选）频谱图幅度。若未输入 y 则必需。

frame_lengthint > 0 [scalar]

计算能量时分析帧的长度（采样点数）

hop_lengthint > 0 [scalar]

STFT 的跳距。详见 librosa.stft。

centerbool

若为 True 且作用于时域输入（y），则在信号 两侧各填充 frame_length//2。 若作用于频谱图输入，则此参数无效。

pad_modestr

居中分析时的填充模式。合法取值 见 numpy.pad。

dtypenp.dtype, optional

输出数组的数据类型。默认为 float32。

返回值

返回值类型说明
rmsnp.ndarray [shape=(…, 1, t)]

每一帧的 RMS 值

示例

>>> y, sr = librosa.loadx('trumpet')
>>> librosa.feature.rms(y=y)
array([[1.248e-01, 1.259e-01, ..., 1.845e-05, 1.796e-05]],
      dtype=float32)

或者由频谱图输入

>>> S, phase = librosa.magphase(librosa.stft(y))
>>> rms = librosa.feature.rms(S=S)
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> times = librosa.times_like(rms)
>>> ax[0].semilogy(times, rms[0], label='RMS Energy')
>>> ax[0].set(xticks=[])
>>> ax[0].legend()
>>> ax[0].label_outer()
>>> librosa.display.specshow(S, vscale='dBFS',
...                          y_axis='log', x_axis='time', ax=ax[1])
>>> ax[1].set(title='log Power spectrogram')

用全为 1 的 STFT 窗且不做帧居中，以得到与由音频采样点 y 计算出的 RMS 一致的结果

>>> S = librosa.magphase(librosa.stft(y, window=np.ones, center=False))[0]
>>> librosa.feature.rms(S=S)
>>> plt.show()
