librosa.feature.tonnetz

librosa.feature.tonnetz(*, y=None, sr=22050, chroma=None, **kwargs) [源码]

计算调性质心特征（tonnetz）

这种表示使用 [1] 的方法，把色度特征 投影到一个 6 维基上，分别用二维坐标表示纯五度、 小三度与大三度。

[1] Harte, C., Sandler, M., & Gasser, M. (2006). “Detecting Harmonic Change in Musical Audio.” In Proceedings of the 1st ACM Workshop on Audio and Music Computing Multimedia (pp. 21-26). Santa Barbara, CA, USA: ACM Press. doi:10.1145/1178723.1178727.

参数

参数类型说明
ynp.ndarray [shape=(…, n,)] or None

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

chromanp.ndarray [shape=(n_chroma, t)] or None

每一帧中每个色度频格的归一化能量。 若为 None，则计算 CQT 色度图。

**kwargsAdditional keyword arguments to chroma_cqt,

若 chroma 未预先计算，则传给 chroma_cqt。

Cnp.ndarray [shape=(…, d, t)] [Optional]

预先计算好的常数 Q 频谱图

hop_lengthint > 0

相邻色度帧之间的采样点数

fminfloat > 0

CQT 中分析的最低频率。 默认：C1 ~= 32.7 Hz

normint > 0, +-np.inf, or None

色度图的逐列归一化。

thresholdfloat

归一化之前的能量阈值。低于 阈值的值会被丢弃，从而得到稀疏的色度图。

tuningfloat [scalar] or None

相对 A440 调音的偏差（以 CQT 频格的比例计）

n_chromaint > 0

要生成的色度频格数

n_octavesint > 0

在 fmin 之上分析的八度数

windowNone or np.ndarray

传给 filters.cq_to_chroma 的可选窗参数

bins_per_octaveint > 0, optional

CQT 中每个八度的频格数。 必须是 n_chroma 的整数倍。 默认：36（每个半音 3 个频格） 若为 None，则与 n_chroma 一致。

cqt_mode[‘full’, ‘hybrid’]

常数 Q 变换模式

返回值

返回值类型说明
tonnetznp.ndarray [shape(…, 6, t)]

每一帧的调性质心特征。

  • Tonnetz 各维度：

    • 0：五度 x 轴

    • 1：五度 y 轴

    • 2：小调 x 轴

    • 3：小调 y 轴

    • 4：大调 x 轴

    • 5：大调 y 轴

参见

  • chroma_cqt：

    由常数 Q 变换计算色度图。

  • chroma_stft：

    由 STFT 频谱图或波形计算色度图。

示例

从一首歌曲的谐波分量计算 tonnetz 特征

>>> y, sr = librosa.loadx('nutcracker', duration=10, offset=10)
>>> y = librosa.effects.harmonic(y)
>>> tonnetz = librosa.feature.tonnetz(y=y, sr=sr)
>>> tonnetz
array([[ 0.007, -0.026, ...,  0.055,  0.056],
       [-0.01 , -0.009, ..., -0.012, -0.017],
       ...,
       [ 0.006, -0.021, ..., -0.012, -0.01 ],
       [-0.009,  0.031, ..., -0.05 , -0.037]])

把 tonnetz 特征与 chroma_cqt 作比较

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> img1 = librosa.display.specshow(tonnetz,
...                                 y_axis='tonnetz', x_axis='time', ax=ax[0])
>>> ax[0].set(title='Tonal Centroids (Tonnetz)')
>>> ax[0].label_outer()
>>> img2 = librosa.display.specshow(librosa.feature.chroma_cqt(y=y, sr=sr),
...                                 y_axis='chroma', x_axis='time', ax=ax[1])
>>> ax[1].set(title='Chroma')
>>> fig.colorbar(img1, ax=[ax[0]])
>>> fig.colorbar(img2, ax=[ax[1]])
