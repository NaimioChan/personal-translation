librosa.sequence.viterbi

librosa.sequence.viterbi(prob, transition, *, p_init=None, return_logp=False, transition_min_prob=None) [源码]

根据观测似然做维特比解码。

给定观测似然序列 prob[s, t]（表示时刻 t 的观测由状态 s 产生的条件似然），以及编码从状态 i 转移到状态 j 的条件概率的 转移矩阵 transition[i, j]，维特比算法 [1] 会计算 由这些观测得出的最可能状态序列。

[1] Viterbi, Andrew. “Error bounds for convolutional codes and an asymptotically optimum decoding algorithm.” IEEE transactions on Information Theory 13.2 (1967): 260-269.

参数

参数类型说明
probnp.ndarray [shape=(…, n_states, n_steps), non-negative]

prob[..., s, t] 是时刻 t 的观测由状态 s 产生的概率。

transitionnp.ndarray [shape=(n_states, n_states), non-negative]

transition[i, j] 是从 i->j 的转移概率。 每一行的和为 1。

p_initnp.ndarray [shape=(n_states,)]

可选：初始状态分布。 若未提供，则假定为均匀分布。

return_logpbool

若为 True，返回状态序列的对数似然。

transition_min_probfloat, >=0

可选：若提供，表示解码时考虑的最小转移概率。

返回值

返回值类型说明
statesnp.ndarray [shape=(…, n_steps,)]

最可能的状态序列。 若 prob 包含多个输入声道，则每个声道独立解码。

logpscalar [float] or np.ndarray, optional

若 return_logp=True，为给定观测下 states 的对数概率。

示例

示例取自 https://en.wikipedia.org/wiki/Viterbi_algorithm#Example

本例中有两个状态 healthy 与 fever， 初始概率分别为 60% 与 40%。

观测有三种可能：normal、cold 与 dizzy，它们在各状态下的概率为：

healthy => {normal: 50%, cold: 40%, dizzy: 10%} 以及 fever => {normal: 10%, cold: 30%, dizzy: 60%}

最后是转移概率：

healthy => healthy (70%) 以及 fever => fever (60%)。

三天内的观测序列为 [normal, cold, dizzy]， 我们希望知道对应各天的最大似然状态指派，下面用维特比算法计算。

>>> p_init = np.array([0.6, 0.4])
>>> p_emit = np.array([[0.5, 0.4, 0.1],
...                    [0.1, 0.3, 0.6]])
>>> p_trans = np.array([[0.7, 0.3], [0.4, 0.6]])
>>> path, logp = librosa.sequence.viterbi(p_emit, p_trans, p_init=p_init,
...                                       return_logp=True)
>>> print(logp, path)
-4.19173690823075 [0 0 1]
