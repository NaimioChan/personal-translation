librosa.display.wavebars

librosa.display.wavebars(y, *, sr=22050, n_bars=100, gap_ratio=0.4, rounding_ratio=0.5, axis='time', offset=0.0, invert=False, invert_color=None, transpose=False, label=None, ax=None, **patch_kwargs) [源码]

把波形可视化为一系列表示幅度包络的条。

这种可视化适合显示信号的简化视图，最适合追求简洁的小图。

参数

参数类型说明
ynp.ndarray [shape=(n,) or (2,n)]

音频时间序列（单声道或立体声） 若为立体声，左声道的幅度包络用于条的上半部分，右声道的幅度包络（取负）用于条的下半部分。 若为单声道，信号包络沿轴镜像。

srnumber > 0 [scalar]

y 的采样率（每秒采样点数）

n_barsint > 0

波形图中显示的条数。 图的总时长将被划分为 n_bars 段，每段的幅度包络用一个条表示。

gap_ratiofloat in [0, 1]

相邻条之间留作间隙的宽度占条宽的比例。

rounding_ratiofloat in [0, 1]

用于给条角做圆角的宽度占条宽的比例。 取 0.5 会得到圆角条，取 0 会得到直角条。

axisstr or None
  • 坐标轴刻度与刻度标记的显示样式。可取值为：

    • ‘time’：标记显示为毫秒、秒、分钟或小时。

    • ‘h’：标记显示为小时、分钟和秒。

    • ‘m’：标记显示为分钟和秒。

    • ‘s’：标记显示为秒。

    • ‘ms’：标记显示为毫秒。

    • ‘lag’：同 time，但超过中点部分按负值计。

    • ‘lag_h’：同 lag，但以小时表示。

    • ‘lag_m’：同 lag，但以分钟表示。

    • ‘lag_s’：同 lag，但以秒表示。

    • ‘lag_ms’：同 lag，但以毫秒表示。

    • None、‘none’ 或 ‘off’：隐藏刻度与刻度标记。

offsetfloat

波形图的起始偏移（单位秒）。

invertbool

若为 True，反转显示的前景与背景，使坐标轴背景着色。 若为 False（默认），则包络显示着色，背景保持不变。

invert_colorstr, tuple, None

若 invert 为 True，此参数指定反转波形显示所用的颜色。 若为 None（默认），颜色设为当前坐标轴的背景色。

transposebool

若为 True，波形纵向而非横向显示。

labelstr or None

应用于此图的标签字符串。 若为 None，不添加标签。

axmatplotlib.axes.Axes or None

用于绘制的坐标轴，代替默认的 plt.gca()。

**patch_kwargsdict

传给 matplotlib.patches.FancyBboxPatch 的其他关键字参数

返回值

返回值说明
matplotlib.collections.PatchCollection

表示波形幅度包络的图块集合。

参见

  • waveshow

示例

把波形绘制为条，并与 waveshow 版本的图对比

>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('libri1', duration=10)
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> librosa.display.waveshow(y=y, sr=sr, ax=ax[0], label='waveshow()')
>>> ax[0].legend()
>>> ax[0].label_outer()
>>> librosa.display.wavebars(y=y, sr=sr, ax=ax[1], label='wavebars()')
>>> ax[1].legend()
>>> plt.show()

绘制不同细节程度、直角以及反转颜色的图。

>>> fig, ax = plt.subplots(nrows=3, sharex=True, sharey=True)
>>> librosa.display.wavebars(y=y, sr=sr, n_bars=100, rounding_ratio=0,
...                          invert=True, ax=ax[0], label='100 bars')
>>> librosa.display.wavebars(y=y, sr=sr, n_bars=200, rounding_ratio=0,
...                          color='C1', invert=True, ax=ax[1], label='200 bars')
>>> librosa.display.wavebars(y=y, sr=sr, n_bars=50, rounding_ratio=0,
...                          color='C2', invert=True, ax=ax[2], label='50 bars')
>>> ax[0].legend()
>>> ax[1].legend()
>>> ax[2].legend()
>>> ax[0].label_outer()
>>> ax[1].label_outer()
>>> plt.show()
