效果

librosa.effects 提供时间序列操作、谐波-打击源分离以及标准音频效果的封装函数。

它还提供一些用于裁剪、切分或拼接信号的基础函数。

函数说明

hpss

把音频时间序列分解为谐波分量与打击分量。

harmonic

从音频时间序列中提取谐波成分。

percussive

从音频时间序列中提取打击成分。

time_stretch

按固定倍率对音频序列进行时间拉伸。

pitch_shift

将波形的音高偏移 n_steps 个半音。

remix

通过重新排列时间区间来重混音频信号。

trim

裁掉音频信号首尾的静音。

split

把音频信号切分为非静音区间。
