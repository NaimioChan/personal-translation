时间单位转换

函数说明

frames_to_samples

把帧下标转换为音频采样下标。

frames_to_time

把帧数转换为时间（秒）。

samples_to_frames

把采样下标转换为 STFT 帧。

samples_to_time

把采样下标转换为时间（秒）。

time_to_frames

把时间戳转换为 STFT 帧。

time_to_samples

把时间戳（秒）转换为采样下标。

blocks_to_frames

把块下标转换为帧下标

blocks_to_samples

把块下标转换为采样下标

blocks_to_time

把块下标转换为时间（秒）

samples_like

返回与特征矩阵时间轴相匹配的采样下标数组。

times_like

返回与特征矩阵时间轴相匹配的时间值数组。
