可视化时频内容

本节介绍 librosa.display.specshow，这是可视化频谱图类数据的主要函数。

频谱图

本教程前面的章节演示了短时傅里叶变换（STFT）的基本用法，它可用于可视化信号频率内容随时间的变化。这类可视化称为频谱图，你可能此前已经接触过这个概念。频谱图虽然可以当作图像来理解，并用 matplotlib 的通用图像显示函数（例如 matplotlib.pyplot.imshow）来显示，但其中有不少细节容易出错，要处理好需要费些功夫。

举个例子，我们先计算一个 STFT，然后直接用 imshow 显示。首先设置导入并加载示例文件。

import numpy as np
import librosa
import matplotlib.pyplot as plt
from IPython.display import HTML

y, sr = librosa.loadx("trumpet")
HTML(librosa.util.example_info("trumpet", html=True))

现在可以计算 STFT、创建图形并调用 imshow。注意，调用 imshow 时必须把 stft 数组从复数转换为实数，否则会因类型不匹配而报错。

stft = librosa.stft(y)
print(f"stft shape={stft.shape}")
fig, ax = plt.subplots()
ax.imshow(np.abs(stft))
stft shape=(1025, 230)

这里立刻能看出几个问题：

  1. 宽高比在水平方向上被压缩了。

  2. 坐标轴没有标注。

  3. 对应频率的纵轴是倒过来的。

  4. 图像偏暗，难以辨认。

以上每一点都只需花一点功夫就能修正，但这往往会产生大量重复的样板代码，在每张图之间反复复制。

librosa 的 display 模块提供了一小组函数，能让绘制频谱图简单得多。

specshow 基础

librosa 中用于频谱图显示的核心函数是 librosa.display.specshow。如果去读这个函数的文档，可能会觉得有点繁琐，因为它为不同种类的频谱图实现了大量显示选项。

在逐一介绍所有选项之前，先快速修正示例中的频谱图显示。

fig, ax = plt.subplots()
librosa.display.specshow(stft, x_axis="time", y_axis="hz", vscale="dB")
  • 按顺序逐个说明参数：

    • x_axis 设为 ‘time’。在背后，specshow 会使用 librosa.frames_to_time 计算帧索引（stft 的列）与时间之间的转换，并替我们标注好绘图。这里依赖默认的采样率和跳距参数（sr=22050 与 hop_length=512），它们可以按需设置。

    • y_axis 做类似的工作，只是它使用 librosa.fft_frequencies 计算行索引到频率（以 Hz 计）的映射。同样，这里依赖默认的帧长度 n_fft=2048 和采样率，二者可以在 specshow 中按需设置。

    • vscale 负责数据的数值缩放。这里使用分贝刻度，它会自动把复数 stft 值转换为幅度（通过 np.abs），再用 librosa.amplitude_to_db 对其进行缩放。关于颜色映射如何工作的更多信息，参见有效使用颜色一节。

specshow 还会设置方向和宽高比，使结果看起来像我们通常期望的频谱图显示。

再进一步，还可以给这张图加上颜色条，让数值更容易解读。

fig, ax = plt.subplots()
img = librosa.display.specshow(stft, x_axis="time", y_axis="hz", vscale="dB")
librosa.display.colorbar_db(img)

上面的例子作为频谱内容的可视化已经相当好用。不过它并不适合所有使用场景，这正是 specshow 的灵活性派上用场的地方。

音乐频谱图显示中的一个常见问题是，傅里叶分析假设频率是线性间隔的（0, sr/n_fft, 2*sr/n_fft, …, sr/2），而人对频率和音高的感知往往用几何方式表示更合适。从视觉上看，上图在 (4000 Hz, 8000 Hz) 上占用的纵向空间是 (2000 Hz, 4000 Hz) 的两倍，尽管两者都只代表一个八度。实际中，这会使 1KHz 以下的频率显示变得模糊——音符的基频常常落在这一范围——它们会被视觉压缩，难以分辨。

通常用对纵轴施加对数变换来解决。但傅里叶分析在这里有一个问题：最小频率是 0，而 log(0) → -∞，这意味着极低频率会占据无限的纵向空间。specshow 通过对坐标轴采用半对数变换来近似处理：65 Hz 以下频率线性表示，高于该频率则对数表示。把 y_axis=’log’ 即可启用对数频率显示：

fig, ax = plt.subplots()
img = librosa.display.specshow(stft, x_axis="time", y_axis="log", vscale="dB")
librosa.display.colorbar_db(img)

重要的是，绘图的底层坐标轴仍然以自然单位（秒、Hz）表示，只有视觉输出被变换。这样一来，叠加其他绘图元素（如基频轮廓或时间标记）或把坐标轴与其他图关联起来都很简单，如下例所示。

fig, ax = plt.subplots(nrows=2, sharex=True, height_ratios=[4, 1])
img = librosa.display.specshow(stft, x_axis="time", y_axis="log", vscale="dB", ax=ax[0])
librosa.display.colorbar_db(img)

ax[0].axhline(librosa.note_to_hz("F4"), label="Frequency F4", color="C3")
ax[0].axvline(3.0, label="Time 3.0 seconds", color="C1", linestyle="--")
ax[0].legend(loc="upper right")
ax[0].label_outer()
librosa.display.waveshow(y=y, sr=sr, ax=ax[1])
ax[1].axvline(3.0, label="Time 3.0 seconds", color="C1", linestyle="--")

注意在 waveshow 和 specshow 中，都可以用 ax= 参数指定在哪个坐标轴上绘制。

控制 specshow

到目前为止，我们只用了默认设置和有限的几个参数来绘制一张基础但可读的频谱图。

接下来看看如何使用自定义参数并改变图表的样式。首先，以更高的采样率加载示例，并做高分辨率分析。

# Use the native sampling rate of the example by setting sr=None
y, sr = librosa.loadx("trumpet", sr=None)

# Use larger frames (4096 samples) to account for the higher sampling rate
# Use a smaller hop length to get a higher time resolution in the stft
stft = librosa.stft(y, n_fft=4096, hop_length=256)
print(f"stft shape={stft.shape}")
stft shape=(2049, 919)

现在可以把分析参数传给 specshow，让它正确构造坐标轴。顺便还可以通过设置 top_db 改变分贝缩放的阈值（默认是 80，这里设为 60 以抑制低幅度噪声）。最后，可以用 cmap_seq= 为顺序数据选择不同的颜色映射。这里使用白底黑字的颜色映射，适合印刷介质。

fig, ax = plt.subplots()
img = librosa.display.specshow(stft, x_axis="time", y_axis="log", vscale="dB",
                               sr=sr, hop_length=256, top_db=60,
                               cmap_seq="gray_r")
librosa.display.colorbar_db(img)

小结与提示

对于 specshow 提供的功能，我们其实只触及了皮毛，本教程后续章节会深入细节。

  • 有几点值得牢记：

    • 最重要的参数是 x_axis 和 y_axis。其余大多数参数都是为了支持不同坐标轴缩放的单位转换。

    • 这里的方向并没有什么特殊之处：任何坐标轴都可以是时间轴或频率轴。这使得绘制横向频谱图、时间-时间图、频率-频率图等都很容易。非频谱数据可视化一节给出了一些例子。

    • 底层的显示对象由 matplotlib.pyplot.pcolormesh 生成。pcolormesh 能接受的任何参数也都可以传给 specshow。
