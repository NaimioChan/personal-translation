librosa.feature.fourier_tempogram

librosa.feature.fourier_tempogram(*, y=None, sr=22050, onset_envelope=None, hop_length=512, win_length=384, center=True, window='hann') [源码]

计算傅里叶速度图：起始强度包络的短时傅里叶变换。[1]

[1] Grosche, Peter, Meinard Müller, and Frank Kurth. “Cyclic tempogram - A mid-level tempo representation for music signals.” ICASSP, 2010.

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

onset_envelopenp.ndarray [shape=(…, n)] or None

可选，由 librosa.onset.onset_strength 得到的预先计算好的起始强度包络。 支持多声道。

hop_lengthint > 0

相邻起始点测量之间的音频采样点数

win_lengthint > 0

起始窗的长度（以帧／起始点测量计） 默认设置（384）对应于 384 * hop_length / sr ~= 8.9s。

centerbool

若为 True，起始窗居中。 若为 False，窗左对齐。

windowstr, function, number, tuple, or np.ndarray [shape=(win_length,)]

窗的规格，同 stft。

返回值

返回值类型说明
tempogramnp.ndarray [shape=(…, win_length // 2 + 1, n)]

起始包络的复数短时傅里叶变换。

异常

异常说明
ParameterError

若 y 与 onset_envelope 均未提供

若 win_length < 1

参见

  • tempogram
  • librosa.onset.onset_strength
  • librosa.util.normalize
  • librosa.stft

示例

>>> # 计算局部起始点自相关
>>> y, sr = librosa.loadx('nutcracker')
>>> hop_length = 512
>>> oenv = librosa.onset.onset_strength(y=y, sr=sr, hop_length=hop_length)
>>> tempogram = librosa.feature.fourier_tempogram(onset_envelope=oenv, sr=sr,
...                                               hop_length=hop_length)
>>> # 计算自相关速度图，不做归一化以便比较
>>> ac_tempogram = librosa.feature.tempogram(onset_envelope=oenv, sr=sr,
...                                          hop_length=hop_length, norm=None)
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=3, sharex=True)
>>> ax[0].plot(librosa.times_like(oenv), oenv, label='Onset strength')
>>> ax[0].legend(frameon=True)
>>> ax[0].label_outer()
>>> librosa.display.specshow(np.abs(tempogram), sr=sr, hop_length=hop_length,
>>>                          x_axis='time', y_axis='fourier_tempo', cmap='magma',
...                          ax=ax[1])
>>> ax[1].set(title='Fourier tempogram')
>>> ax[1].label_outer()
>>> librosa.display.specshow(ac_tempogram, sr=sr, hop_length=hop_length,
>>>                          x_axis='time', y_axis='tempo', cmap='magma',
...                          ax=ax[2])
>>> ax[2].set(title='Autocorrelation tempogram')
