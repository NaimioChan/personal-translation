librosa.iirt

librosa.iirt(y, *, sr=22050, win_length=2048, hop_length=None, center=True, tuning=0.0, pad_mode='constant', flayout='sos', res_type='soxr_hq', **kwargs) [源码]

使用 IIR 滤波器的时频表示

该函数使用由 IIR 滤波器组成的多速率滤波器组，返回 一个时频表示。 [1]

首先，按给定的 sample_rates 对 y 进行所需的重采样。

然后，设计一个包含 n 个带通滤波器的滤波器组。

重采样后的输入信号整体通过滤波器组处理。 （使用 scipy.signal.filtfilt 或 sosfiltfilt 使相位线性。） 滤波器组的输出被切分为帧。 对每个频带，通过把 win_length 个连续的滤波后时间采样点 求和来计算短时均方功率（STMSP）。

以默认参数调用时，它将生成时频表示 （音高滤波器组）：

  • 85 个滤波器，以 MIDI 音高 [24, 108] 作为 center_freqs。

  • 每个滤波器的带宽为一个半音。

[1] Müller, Meinard. “Information Retrieval for Music and Motion.” Springer Verlag. 2007.

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

win_lengthint > 0

窗长度。主要用于居中（见下文），以及 简化与其他基于帧的分析（如 stft）的兼容性。

hop_lengthint > 0 [scalar]

跳距，即相邻帧之间的采样点数。 若未提供，默认取 win_length // 4。

centerbool

  • 若为 True，信号 y 会被填充，使帧 D[..., :, t] 以 y[t * hop_length] 为中心。

  • 若为 False，则 D[…, :, t]` 从 y[t * hop_length] 开始

tuningfloat [scalar]

相对于 A440 的调音偏差，以 bin 的比例表示。

pad_modestr

当 center=True 时，信号边缘使用的填充模式。 默认情况下，该函数使用零填充。

flayoutstr

  • 若为 sos（默认），使用一系列二阶滤波器配合 scipy.signal.sosfiltfilt 进行滤波。 对高阶滤波器可最小化数值精度误差，但速度较慢。

  • 若为 ba，使用标准差分方程配合 scipy.signal.filtfilt 进行滤波。 对高阶滤波器可能不稳定。

res_typestr

重采样模式。详见 librosa.resample。

**kwargsadditional keyword arguments

传给 librosa.filters.semitone_filterbank 的额外参数 （例如可用于提供另一组 center_freqs 与 sample_rates）。

返回值

返回值类型说明
bands_powernp.ndarray [shape=(…, n, t), dtype=dtype]

输入信号的短时均方功率。

异常

异常说明
ParameterError

若 flayout 不是 None、ba 或 sos。

示例

>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('trumpet', duration=3)
>>> D = np.abs(librosa.iirt(y, sr=sr))
>>> C = np.abs(librosa.cqt(y=y, sr=sr))
>>> fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
>>> img = librosa.display.specshow(C, vscale='dBFS',
...                                y_axis='cqt_hz', x_axis='time', ax=ax[0])
>>> ax[0].set(title='Constant-Q transform')
>>> ax[0].label_outer()
>>> img = librosa.display.specshow(D, vscale='dBFS',
...                                y_axis='cqt_hz', x_axis='time', ax=ax[1])
>>> ax[1].set_title('Semitone spectrogram (iirt)')
>>> librosa.display.colorbar_db(img, ax=ax)
