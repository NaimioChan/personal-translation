librosa.salience

librosa.salience(S, *, freqs, harmonics, weights=None, aggregate=None, filter_peaks=True, fill_value=nan, kind='linear', axis=-2) [源码]

谐波显著度函数。

参数

参数类型说明
Snp.ndarray [shape=(…, d, n)]

输入的时频幅度表示（如 STFT 或 CQT 幅度）。 必须为实值且非负。

freqsnp.ndarray, shape=(S.shape[axis]) or shape=S.shape

与 S 沿所选轴的元素对应的频率值。

频率也可以随时间变化，例如由 reassigned_spectrogram 计算得到，此时形状应与 S 一致。

harmonicslist-like, non-negative

参与显著度计算的谐波。第一个谐波（1） 对应 S 本身。小于 1 的值（如 1/2）对应次谐波。

weightslist-like

求和时各谐波的权重。（默认：均匀权重）。长度必须与 harmonics 相同。

aggregatefunction

聚合函数（默认：np.average）

若 aggregate=np.average，则按指定权重对每个谐波计算加权平均。 对其他所有聚合函数，各谐波同等对待。

filter_peaksbool

若为 True，只在幅度峰值频率处返回谐波求和结果。否则在整个频谱上返回谐波求和。 默认 True。

fill_valuefloat

输出表示中非峰值处的填充值。（默认：np.nan）仅在 filter_peaks == True 时使用。

kindstr

谐波估计的插值类型。 见 scipy.interpolate.interp1d。

axisint

计算谐波所沿的轴

返回值

返回值类型说明
S_salnp.ndarray

S_sal 的形状与 S 相同，度量每个频率处的总谐波能量。

参见

  • interp_harmonics

示例

>>> y, sr = librosa.loadx('trumpet', duration=3)
>>> S = np.abs(librosa.stft(y))
>>> freqs = librosa.fft_frequencies(sr=sr)
>>> harms = [1, 2, 3, 4]
>>> weights = [1.0, 0.5, 0.33, 0.25]
>>> S_sal = librosa.salience(S, freqs=freqs, harmonics=harms, weights=weights, fill_value=0)
>>> print(S_sal.shape)
(1025, 115)
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
>>> librosa.display.specshow(S, vscale='dBFS',
...                          sr=sr, y_axis='log', x_axis='time', ax=ax[0])
>>> ax[0].set(title='Magnitude spectrogram')
>>> ax[0].label_outer()
>>> img = librosa.display.specshow(S_sal, vscale='dBFS',
...                                sr=sr, y_axis='log', x_axis='time', ax=ax[1])
>>> ax[1].set(title='Salience spectrogram')
>>> librosa.display.colorbar_db(img, ax=ax)
