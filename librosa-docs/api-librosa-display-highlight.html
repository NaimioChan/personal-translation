librosa.display.highlight

librosa.display.highlight(*, artist=None, ax=None, color=None, bright_color='white', dark_color='black', luminance_threshold=0.5, **kwargs) [源码]

为 matplotlib artist 应用对比高亮效果。

这主要用于在 artist（例如折线图）与底层图像（例如频谱图或散点图）之间提供对比。 例如，如果底层图像（按所选色图）整体偏暗，则应使用亮色高亮（默认“白色”）； 如果底层图像整体偏亮，则应使用暗色高亮（默认“黑色”）。

本函数设计为根据 ax 坐标轴对象的内容（若有）自动推断应应用哪种高亮。 如果在 ax 上找不到颜色映射数据，则退而使用坐标轴的 facecolor 或图的 facecolor。

若提供 artist，高亮效果会原地应用，但这一步是可选的。（见下方示例。）

亮色与暗色高亮的颜色，以及判定选用哪种颜色的亮度阈值，可通过 bright_color、dark_color 和 luminance_threshold 参数自定义。

也可以跳过自动颜色推断，直接通过 color 参数指定高亮颜色。

参数

参数类型说明
artistmatplotlib.artist.Artist, optional

要应用高亮效果的 artist。若未提供，函数仍会根据 ax 的内容返回相应的路径效果对象，但不会把它们应用到任何 artist 上。

axmatplotlib.axes.Axes, optional

用于检查颜色映射数据、以确定合适高亮颜色的坐标轴。 若未提供，函数会尝试从 artist 推断合适的坐标轴对象，若失败则默认使用当前坐标轴（plt.gca()）。

colorcolor specifier, optional

直接用于高亮的颜色规格，跳过自动颜色推断。若未提供，函数将根据 ax 的内容和 luminance_threshold 决定使用 bright_color 还是 dark_color。

bright_colorcolor specifier, default ‘white’

当判定底层坐标轴为暗色时用于高亮的颜色。

dark_colorcolor specifier, default ‘black’

当判定底层坐标轴为亮色时用于高亮的颜色。

luminance_thresholdfloat, default 0.5

判定底层坐标轴被认为亮或暗的亮度阈值。 亮度通过把相关颜色转换到 YIQ 颜色空间并取 Y（亮度）分量计算。若亮度高于此阈值，坐标轴被视为亮色，高亮使用 dark_color；若亮度低于此阈值，坐标轴被视为暗色，高亮使用 bright_color。

**kwargsdict

创建高亮效果时传给 matplotlib.patheffects.withStroke 的其他关键字参数。常用选项包括 linewidth（默认为 2）和 alpha（默认为 1.0）。

注意

若提供 foreground，它将覆盖 color 参数和自动颜色推断。为避免混淆，建议通过 color 参数指定高亮颜色，不要在 kwargs 中提供 foreground。

返回值

返回值类型说明
effectslist of matplotlib.patheffects.AbstractPathEffect

实现该高亮的路径效果对象列表。若提供了 artist，这些效果已原地应用到该 artist。若未提供 artist，这些效果可通过 artist.set_path_effects(effects) 应用到任意 artist。

示例

在亮色或暗色色图上，分别绘制带高亮和不带高亮的 f₀ 轮廓

>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('trumpet')
>>> f0, _, _ = librosa.pyin(y, fmin=100, fmax=1000)
>>> times = librosa.times_like(f0)
>>> D = librosa.stft(y)
>>> fig, ax = plt.subplots(nrows=2, ncols=2, sharex=True, sharey=True)
>>> librosa.display.specshow(D, x_axis='time', y_axis='log_oct3', ax=ax[0, 0],
...                          vscale='dBFS')
>>> ax[0, 0].plot(times, f0)
>>> ax[0, 0].set_title('Dark image, no highlight')
>>> librosa.display.specshow(D, x_axis='time', y_axis='log_oct3', ax=ax[0, 1],
...                          vscale='dBFS')
>>> line = ax[0, 1].plot(times, f0)[0]  # 'plot' returns a list of artists
>>> librosa.display.highlight(artist=line)
>>> ax[0, 1].set_title('Dark image, highlighted')
>>> librosa.display.specshow(D, x_axis='time', y_axis='log_oct3', ax=ax[1, 0],
...                          vscale='dBFS', cmap='gray_r')
>>> ax[1, 0].plot(times, f0)
>>> ax[1, 0].set_title('Bright image, no highlight')
>>> librosa.display.specshow(D, x_axis='time', y_axis='log_oct3', ax=ax[1, 1],
...                          vscale='dBFS', cmap='gray_r')
>>> # We can also construct the highlight first and then supply it to the plot command
>>> hl = librosa.display.highlight(ax=ax[1, 1])
>>> ax[1, 1].plot(times, f0, path_effects=hl)
>>> ax[1, 1].set_title('Bright image, highlighted')
>>> for a in ax.flat:
...     a.label_outer()
>>> plt.show()
