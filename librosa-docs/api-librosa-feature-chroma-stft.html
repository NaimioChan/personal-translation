librosa.feature.chroma_stft

librosa.feature.chroma_stft(*, y=None, sr=22050, S=None, norm=inf, n_fft=2048, hop_length=512, win_length=None, window='hann', center=True, pad_mode='constant', tuning=None, n_chroma=12, **kwargs) [源码]

从波形或功率谱计算色度图。

本实现派生自 chromagram_E [1]

[1] Ellis, Daniel P.W. “Chroma feature analysis and synthesis” 2007/04/21 https://www.ee.columbia.edu/~dpwe/resources/matlab/chroma-ansyn/

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

Snp.ndarray [shape=(…, d, t)] or None

功率谱

normfloat or None

逐列归一化。 详见 librosa.util.normalize。 若为 None，则不执行归一化。

n_fftint > 0 [scalar]

FFT 帧长度，在提供 y, sr 而未提供 S 时使用

hop_lengthint > 0 [scalar]

跳距，在提供 y, sr 而未提供 S 时使用

win_lengthint <= n_fft [scalar]

每一帧音频都用 window() 加窗。 窗的长度为 win_length，随后补零 至 n_fft 长度。 若未指定，默认为 win_length = n_fft。

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

  • 窗的规格（字符串、元组或数值）； 见 scipy.signal.get_window

  • 窗函数，例如 scipy.signal.windows.hann

  • 长度为 n_fft 的向量或数组

centerbool

  • 若为 True，则对信号 y 进行填充，使帧 t 以 y[t * hop_length] 为中心。

  • 若为 False，则帧 t 起始于 y[t * hop_length]

pad_modestr

若 center=True，在信号边缘使用的填充模式。 默认情况下，STFT 使用零填充。

tuningfloat [scalar] or None

相对 A440 调音的偏差，以色度频格的小数计。 若为 None，则自动估计。

n_chromaint > 0 [scalar]

要生成的色度频格数（默认为 12）。

**kwargs

用于参数化色度滤波器的额外关键字参数。

ctroctfloat > 0 [scalar]

见 octwidth

octwidthfloat > 0 or None [scalar]

ctroct 与 octwidth 指定一个优势窗： 以 ctroct 为中心（单位为八度，A0 = 27.5Hz）、 半宽为 octwidth 的高斯加权。 把 octwidth 设为 None 可使用平坦加权。

normfloat > 0 or np.inf

每个滤波器的归一化因子

base_cbool

若为 True，则滤波器组以 ‘C’ 开始。 若为 False，则滤波器组以 ‘A’ 开始。

dtypenp.dtype

输出基矩阵的数据类型。 默认使用 32 位（单精度）浮点数。

返回值

返回值类型说明
chromagramnp.ndarray [shape=(…, n_chroma, t)]

每一帧中每个色度频格的归一化能量。

参见

  • librosa.filters.chroma：

    色度滤波器组的构建

  • librosa.util.normalize：

    向量归一化

示例

>>> y, sr = librosa.loadx('nutcracker', duration=15)
>>> librosa.feature.chroma_stft(y=y, sr=sr)
array([[1.   , 0.962, ..., 0.143, 0.278],
       [0.688, 0.745, ..., 0.103, 0.162],
       ...,
       [0.468, 0.598, ..., 0.18 , 0.342],
       [0.681, 0.702, ..., 0.553, 1.   ]], dtype=float32)

使用能量（幅度）谱代替功率谱

>>> S = np.abs(librosa.stft(y))
>>> chroma = librosa.feature.chroma_stft(S=S, sr=sr)
>>> chroma
array([[1.   , 0.973, ..., 0.527, 0.569],
       [0.774, 0.81 , ..., 0.518, 0.506],
       ...,
       [0.624, 0.73 , ..., 0.611, 0.644],
       [0.766, 0.822, ..., 0.92 , 1.   ]], dtype=float32)

使用帧更长、预先计算好的功率谱

>>> S = np.abs(librosa.stft(y, n_fft=4096))**2
>>> chroma = librosa.feature.chroma_stft(S=S, sr=sr)
>>> chroma
array([[0.994, 0.873, ..., 0.169, 0.227],
       [0.735, 0.64 , ..., 0.141, 0.135],
       ...,
       [0.6  , 0.937, ..., 0.214, 0.257],
       [0.743, 0.937, ..., 0.684, 0.815]], dtype=float32)
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> img = librosa.display.specshow(S, vscale='dBFS[power]',
...                                y_axis='log', x_axis='time', ax=ax[0])
>>> librosa.display.colorbar_db(img)
>>> ax[0].label_outer()
>>> img = librosa.display.specshow(chroma, y_axis='chroma', x_axis='time', ax=ax[1])
>>> fig.colorbar(img, ax=[ax[1]])
