多声道显示

本节演示在单张图中显示多声道音频数据的方法。

虽然 librosa 的信号处理函数是为处理多声道数据而设计的，但可视化函数通常假设音频是单声道的。不过 librosa 确实提供了一些功能，通过把数据的每个声道映射到同一张图内不同的子图，来简化多声道可视化的构造。这由 librosa.display.multiplot 函数实现。

波形的 multiplot

第一个例子中，我们用 librosa.display.multiplot 在同一张图里显示多声道音频数据的波形。为说明这一点，我们先取一段单声道信号，然后用 librosa.effects.hpss 把它分解为谐波和打击成分。接着在同一张图里显示原始信号、谐波成分和打击成分。

import librosa
import matplotlib.pyplot as plt
from IPython.display import HTML

y, sr = librosa.loadx("choice")
HTML(librosa.util.example_info("choice", html=True))

首先，我们演示如何把三个声道分别画到 3 行子图数组中。

y_harmonic, y_percussive = librosa.effects.hpss(y)

fig, ax = plt.subplots(nrows=3, sharex=True, sharey=True)
librosa.display.waveshow(y, sr=sr, ax=ax[0], label="Original", color="C0")
librosa.display.waveshow(y_harmonic, sr=sr, ax=ax[1], label="Harmonic", color="C1")
librosa.display.waveshow(y_percussive, sr=sr, ax=ax[2], label="Percussive", color="C2")
fig.legend(loc="outside right")

这相对直接，但用 multiplot 可以更简洁地完成：

fig, ax = plt.subplots(nrows=3, sharex=True, sharey=True)
librosa.display.multiplot("waveshow", y, y_harmonic, y_percussive,
                          sr=sr,
                          labels=["Original", "Harmonic", "Percussive"],
                          axes=ax)
fig.legend(loc="outside right")

在底层，multiplot 做了几件事来简化这个过程：

  • 它自动把每个输入分配给不同的子图。

  • 它让所有子图的显示参数保持一致。

  • 它在子图之间循环使用颜色（以及其他样式元素）。

  • 它根据 labels 参数为每个子图指定标签。

  • 内部子图的坐标轴设为 label_outer 模式，隐藏多余的装饰。

上面的例子中，我们把 multiplot 与变长参数列表（y, y_harmonic, y_percussive）一起使用，但它也可以用于单个多声道数组，例如：

y_all = librosa.to_multi(y, y_harmonic, y_percussive)
librosa.display.multiplot("waveshow", y_all, sr=sr,
                          labels=['Original', 'Harmonic', 'Percussive'])

同样可以正常工作。

注意

在 librosa 文档的所有示例代码中，我们偏好 matplotlib 的「面向对象」API，即显式创建 Figure 和 Axes 对象并传给显示函数。

multiplot 与 librosa 中所有其他显示函数一样，也支持「pyplot」API，即隐式创建图和坐标轴。例如，下面的代码会产生与上面相同的结果：

librosa.display.multiplot("waveshow", y, y_harmonic, y_percussive,
                          sr=sr,
                          labels=['Original', 'Harmonic', 'Percussive'])

它会自动为你创建一张新图和尺寸合适的子图数组。

频谱图的 multiplot

上面的例子把 waveshow 函数分派到每个子图，但 multiplot 也可以与 specshow 一起使用。例如，我们可以很快构造出多声道频谱图显示，如下所示。

y_all = librosa.to_multi(y, y_harmonic, y_percussive)
stft_all = librosa.stft(y_all)

fig, ax = plt.subplots(nrows=3, sharex=True, sharey=True)
imgs = librosa.display.multiplot("specshow", stft_all, sr=sr,
                                 y_axis="log_oct3", x_axis="time", vscale="dBFS",
                                 titles=["Original", "Harmonic", "Percussive"],
                                 axes=ax)
librosa.display.colorbar_db(imgs[0], ax=ax, location="right")

与 waveshow 一样，所有公共显示参数在各子图之间共享。multiplot 的返回值始终是与子图数组 axes 形状相同的 numpy ndarray，其中每个元素对应该子图上所调用底层显示函数（此处为 specshow）的返回值。这里我们用第一个返回值生成整张图的单一颜色条。注意在此情况下这样做是正确的，因为三个子图共享 dBFS 数值刻度，而它总是产生一致的颜色映射。如果各子图的数值刻度不同，那么单一颜色条就不合适了。

对于频谱图显示，标注子图不应使用 label 参数。multiplot 还接受 titles 参数，用它设置每个子图的标题，如上所示。

混合 multiplot

Multiplot 还可以在子图数组的不同切片上混用不同的显示函数。只需对 axes 数组切片并传给不同的 multiplot 调用即可。

fig, ax = plt.subplots(nrows=2, ncols=3, sharex=True, sharey="row",
                       gridspec_kw={"height_ratios": [3, 1]})

# Waves along the bottom
librosa.display.multiplot("waveshow", y_all, sr=sr,
                          labels=["Original", "Harmonic", "Percussive"],
                          axes=ax[1, :])

# Spectrograms along the top
imgs = librosa.display.multiplot("specshow", stft_all, sr=sr,
                                 y_axis="log_oct3", x_axis="time", vscale="dBFS",
                                 titles=["Original", "Harmonic", "Percussive"],
                                 axes=ax[0, :])
# Colorbar on the top row only
librosa.display.colorbar_db(imgs[0], ax=ax[0, :], location="right")

# Zoom in for a better view of the waveforms
ax[0, 0].set(xlim=[12, 14])

高级样式

默认情况下，multiplot 会为每个子图自动循环使用样式属性（例如颜色）。不过这完全可以配置。正如 matplotlib.pyplot.subplots 支持 sharex 和 sharey 参数来关联相关子图的坐标轴，multiplot 允许以不同方式共享属性。设置 share_properties=True 时，所有子图样式相同：

fig, ax = plt.subplots(nrows=3, sharex=True, sharey=True)
librosa.display.multiplot("waveshow", y_all, share_properties=True,
                          sr=sr,
                          # Use titles instead of labels, since now all three
                          # subplots have the same styling
                          titles=["Original", "Harmonic", "Percussive"],
                          axes=ax)

类似地，设置 share_properties=”row” 或 “col” 只会分别关联同一子图行或列中子图的样式属性。

不过 multiplot 更进一步，允许任意一组子图共享样式属性。这对创建类似 DAW 的显示很有帮助，你可能想用颜色标记相关的子图组。为说明这一点，我们用 3 声道数据模拟一个 6 声道显示，构造三对立体声声道，每对按原声道配色。为了给子图分组，我们创建一个形状与子图数组相同的数组 group，为每个子图指定组号。组号相同的子图将共享样式属性。

这个例子中，我们改用反色的 wavebars 显示模式，并把子图间距减小到零，让显示更紧凑。

y_paired = librosa.to_multi(y, y, y_harmonic, y_harmonic, y_percussive, y_percussive)

fig, ax = plt.subplots(nrows=6, ncols=1, sharex=True, sharey=True, gridspec_kw={"hspace": 0})

# Property group is a list of size 6 here, but
# it could be a numpy array if the axes are multi-dimensional.
group = [0, 0, 1, 1, 2, 2]

librosa.display.multiplot("wavebars", y_paired,
                          share_properties=group,
                          sr=sr,
                          invert=True,
                          n_bars=200,
                          labels=["Original L", "Original R",
                                  "Harmonic L", "Harmonic R",
                                  "Percussive L", "Percussive R"],
                          axes=ax)
fig.legend(loc="outside right")

图例

上面的例子中，我们用 fig.legend 创建汇聚所有子图绘图元素的单一图例。有时，为子图的子集创建专属图例会更有帮助。虽然可以通过管理 matplotlib artist 句柄列表手动实现，librosa 提供了一个便捷函数 librosa.display.legend_for_axes，可用于创建只限于一部分子图的图例。

为说明这一点，我们再做一次分离更激进的谐波-打击分解，并把它与原来的分解一起画在 2×2 的子图数组中。

y_harmonic2, y_percussive2 = librosa.effects.hpss(y, margin=(8, 4))

fig, ax = plt.subplots(nrows=2, ncols=2, sharex=True, sharey=True)
librosa.display.multiplot("waveshow", y_harmonic, y_percussive,
                          sr=sr,
                          labels=["Harmonic 1", "Percussive 1"],
                          axes=ax[:, 0])
librosa.display.multiplot("waveshow", y_harmonic2, y_percussive2,
                          sr=sr,
                          labels=["Harmonic 2", "Percussive 2"],
                          axes=ax[:, 1])
librosa.display.legend_for_axes(ax[:, 0], loc="outside upper left", ncols=2)
librosa.display.legend_for_axes(ax[:, 1], loc="outside upper right", ncols=2)

小结

Librosa 的 multiplot 函数提供了一种便捷的方式，用来创建音频数据的多声道可视化。它可以在同一张图中显示多声道音频数据，也可以在子图数组的不同切片上混用不同的显示函数。share_properties 参数允许灵活地为子图设置样式，legend_for_axes 函数则提供了一种便捷的方式为一部分子图创建图例。
