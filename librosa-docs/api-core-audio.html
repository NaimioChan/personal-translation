音频信号

函数说明

load

把音频文件加载为浮点时间序列。

loadx

按键加载示例音频文件。

stream

以固定长度的缓冲区流式读取音频。

resample

把时间序列从 orig_sr 重采样到 target_sr

get_duration

计算音频时间序列、特征矩阵或文件的时长（以秒计）。

get_samplerate

获取给定文件的采样率。

to_mono

对各声道的采样求平均，把音频信号转为单声道。

to_stereo

把两个信号合成立体声信号。

to_multi

把多个信号合成多声道信号。

clicks

构造“节拍器音轨”。

tone

在给定频率上构造纯音（余弦）信号。

chirp

构造“chirp”（扫频）信号。

autocorrelate

有界延迟自相关

zero_crossings

找出信号 y 的过零点：即满足 sign(y[i]) != sign(y[j]) 的下标 i。
