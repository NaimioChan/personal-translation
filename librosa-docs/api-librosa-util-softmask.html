librosa.util.softmask

librosa.util.softmask(X, X_ref, *, power=1, split_zeros=False) [源码]

以数值稳健的方式计算软掩码运算。

M = X**power / (X**power + X_ref**power)

参数

参数类型说明
Xnp.ndarray

与掩码正值元素对应的（非负）输入数组

X_refnp.ndarray

参考元素或背景元素的（非负）数组。 形状必须与 X 相同。

powernumber > 0 or np.inf

若为有限值，以数值稳定的方式返回软掩码

若为无穷大，返回等价于 X > X_ref 的硬（二值）掩码。 注意：对于硬掩码，相等时一律判给 X_ref（mask=0）。

split_zerosbool

若为 True，X 与 X_ref 都很小（接近 0）的元素将得到 0.5 的掩码值。

否则，这些元素的掩码置为 0。

返回值

返回值类型说明
masknp.ndarray, shape=X.shape

输出的掩码数组

异常

异常说明
ParameterError

若 X 与 X_ref 形状不同。

若 X 或 X_ref 存在负值

若 power <= 0

示例

>>> X = 2 * np.ones((3, 3))
>>> X_ref = np.vander(np.arange(3.0))
>>> X
array([[ 2.,  2.,  2.],
       [ 2.,  2.,  2.],
       [ 2.,  2.,  2.]])
>>> X_ref
array([[ 0.,  0.,  1.],
       [ 1.,  1.,  1.],
       [ 4.,  2.,  1.]])
>>> librosa.util.softmask(X, X_ref, power=1)
array([[ 1.   ,  1.   ,  0.667],
       [ 0.667,  0.667,  0.667],
       [ 0.333,  0.5  ,  0.667]])
>>> librosa.util.softmask(X_ref, X, power=1)
array([[ 0.   ,  0.   ,  0.333],
       [ 0.333,  0.333,  0.333],
       [ 0.667,  0.5  ,  0.333]])
>>> librosa.util.softmask(X, X_ref, power=2)
array([[ 1. ,  1. ,  0.8],
       [ 0.8,  0.8,  0.8],
       [ 0.2,  0.5,  0.8]])
>>> librosa.util.softmask(X, X_ref, power=4)
array([[ 1.   ,  1.   ,  0.941],
       [ 0.941,  0.941,  0.941],
       [ 0.059,  0.5  ,  0.941]])
>>> librosa.util.softmask(X, X_ref, power=100)
array([[  1.000e+00,   1.000e+00,   1.000e+00],
       [  1.000e+00,   1.000e+00,   1.000e+00],
       [  7.889e-31,   5.000e-01,   1.000e+00]])
>>> librosa.util.softmask(X, X_ref, power=np.inf)
array([[ True,  True,  True],
       [ True,  True,  True],
       [False, False,  True]], dtype=bool)
