进阶 I/O 用例

本节介绍超出 librosa 当前所提供 I/O 功能的进阶输入输出用例。

读取特定格式

librosa 使用 soundfile 读取音频。 soundfile 支持的编解码器列表见 libsndfile 文档。

注意

soundfile 的安装说明见 此处。

Librosa 的 load 函数面向常见情形：把一段（录音片段的）完整内容加载到内存中；但有些应用需要更大的灵活性。 这类情况下，我们建议直接使用 soundfile。 用 soundfile 读取音频文件的方式与 librosa 类似。一个重要的区别是读取的数据形状为 (nb_samples, nb_channels)，而在 librosa.core.load 中为 (nb_channels, nb_samples)。此外信号默认不会被重采样到 22050 Hz，因此在 librosa 中做后续处理前需要转置并重采样。下面的示例等价于 librosa.load(librosa.util.ex(‘trumpet’))：

1import librosa
2import soundfile as sf
3
4# Get example audio file
5filename = librosa.ex('trumpet')
6
7data, samplerate = sf.read(filename, dtype='float32')
8data = data.T
9data_22k = librosa.resample(data, samplerate, 22050)

分块读取

对于很长的音频信号，不把整个音频文件加载进内存可能更有益。Librosa 0.7 引入了流式接口，可用于依次处理短的音频片段。 librosa.stream 把输入文件切分成音频块，每块对应给定的帧数，可按如下示例迭代：

 1import librosa
 2
 3sr = librosa.get_samplerate('/path/to/file.wav')
 4
 5# Set the frame parameters to be equivalent to the librosa defaults
 6# in the file's native sampling rate
 7frame_length = (2048 * sr) // 22050
 8hop_length = (512 * sr) // 22050
 9
10# Stream the data, working on 128 frames at a time
11stream = librosa.stream('path/to/file.wav',
12                        block_length=128,
13                        frame_length=frame_length,
14                        hop_length=hop_length)
15
16chromas = []
17for y in stream:
18   chroma_block = librosa.feature.chroma_stft(y=y, sr=sr,
19                                              n_fft=frame_length,
20                                              hop_length=hop_length,
21                                              center=False)
22   chromas.append(chromas)

在这个示例中，每个音频片段 y 都包含相当于 128 帧的样本， 更具体地说，len(y) == frame_length + (block_length - 1) * hop_length。 每个片段 y 与随后的片段重叠 frame_length - hop_length 个样本，这保证了流式处理的结果与把整个序列一次性处理的结果等价（前提是禁用填充与居中）。

流式接口的更多细节参见 librosa.stream。

读取类文件对象

若要从类文件对象（也称虚拟文件）读取音频，同样可以使用 soundfile。 只要底层编解码器受 soundfile 支持，librosa.load 与 librosa.stream 也同样适用。

例如：从 zip 压缩包中读取文件：

1import zipfile as zf
2import soundfile as sf
3import io
4
5with zf.ZipFile('test.zip') as myzip:
6    with myzip.open('stereo_file.wav') as myfile:
7        tmp = io.BytesIO(myfile.read())
8        data, samplerate = sf.read(tmp)

从 URL 下载并读取：

1import io
2import urllib.request
3import soundfile as sf
4
5url = "https://librosa.org/data/audio/snare-accelerate.ogg"
6
7with urllib.request.urlopen(url) as response:
8    data, samplerate = sf.read(io.BytesIO(response.read()))

写出音频文件

soundfile 提供了输出功能，可直接用于 numpy 数组形式的音频缓冲区：

 1import numpy as np
 2import soundfile as sf
 3
 4rate = 44100
 5data = np.random.uniform(-1, 1, size=(rate * 10, 2))
 6
 7# Write out audio as 24bit PCM WAV
 8sf.write('stereo_file.wav', data, samplerate, subtype='PCM_24')
 9
10# Write out audio as 24bit Flac
11sf.write('stereo_file.flac', data, samplerate, format='flac', subtype='PCM_24')
12
13# Write out audio as 16bit OGG
14sf.write('stereo_file.ogg', data, samplerate, format='ogg', subtype='vorbis')
