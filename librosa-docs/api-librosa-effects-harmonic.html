librosa.effects.harmonic

librosa.effects.harmonic(y, *, kernel_size=31, power=2.0, mask=False, margin=1.0, n_fft=2048, hop_length=None, win_length=None, window='hann', center=True, pad_mode='constant') [源码]

从音频时间序列中提取谐波成分。

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频时间序列。支持多声道。

kernel_sizeint or tuple (kernel_harmonic, kernel_percussive)

中值滤波器的核大小。

  • 若为标量，谐波与打击使用相同大小。

  • 若为元组，第一个值指定谐波滤波器的宽度，第二个值指定打击滤波器的宽度。

powerfloat > 0 [scalar]

构造软掩码矩阵时维纳滤波器的指数。

maskbool

返回掩码矩阵而不返回成分。

marginfloat or tuple (margin_harmonic, margin_percussive)

掩码的边缘大小。

  • 若为标量，谐波与打击使用相同大小。

  • 若为元组，第一个值指定谐波掩码的边缘，第二个值指定打击掩码的边缘。

n_fftint > 0 [scalar]

补零之后加窗信号的长度。 STFT 矩阵的行数为 (1 + n_fft/2)。

hop_lengthint or None

相邻 STFT 列之间的音频采样点数。 若未指定，默认为 win_length // 4。

win_lengthint or None

每帧音频用长度为 win_length 的 window 加窗，再补零至 n_fft。 若未指定，默认为 win_length = n_fft。

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

窗的规格。支持的取值见 scipy.signal.get_window。

centerbool

若为 True，对信号做填充，使第 t 帧的中心位于 y[t * hop_length]。

pad_modestr

center=True 时使用的填充模式。 可用的模式见 numpy.pad。

返回值

返回值类型说明
y_harmonicnp.ndarray [shape=(…, n)]

只含谐波部分的音频时间序列

参见

  • hpss：

    分离谐波与打击成分

  • percussive：

    只提取打击成分

  • librosa.decompose.hpss：

    用于频谱图的 HPSS

示例

>>> # Extract harmonic component
>>> y, sr = librosa.loadx('choice')
>>> y_harmonic = librosa.effects.harmonic(y)
>>> # Use a margin > 1.0 for greater harmonic separation
>>> y_harmonic = librosa.effects.harmonic(y, margin=3.0)
