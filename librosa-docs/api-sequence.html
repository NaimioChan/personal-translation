序列建模

librosa.sequence 提供序列处理函数，例如动态时间规整（DTW）、递归量化分析（RQA）以及各种形式的维特比解码。

还提供用于构造转移矩阵或对对齐路径做后处理的辅助工具。

函数说明

dtw

动态时间规整（DTW）。

rqa

递归量化分析（RQA）

path_to_steps

把 DTW 规整路径转换为分数步长数组。

viterbi

由观测似然做维特比解码。

viterbi_discriminative

由判别式状态预测做维特比解码。

viterbi_binary

由二值（多标签）判别式状态预测做维特比解码。

transition_uniform

在 n_states 上构造均匀转移矩阵。

transition_loop

在 n_states 上构造自环转移矩阵。

transition_cycle

在 n_states 上构造循环转移矩阵。

transition_local

构造局部化转移矩阵。
