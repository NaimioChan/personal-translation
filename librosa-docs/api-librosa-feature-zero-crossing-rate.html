librosa.feature.zero_crossing_rate

librosa.feature.zero_crossing_rate(y, *, frame_length=2048, hop_length=512, center=True, **kwargs) [源码]

计算音频时间序列的过零率。

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频时间序列。支持多声道。

frame_lengthint > 0

计算过零率的帧长度

hop_lengthint > 0

每一帧前进的采样点数

centerbool

若为 True，通过填充 y 的边缘使帧居中。 这与 librosa.stft 中的填充类似， 但使用边缘值的副本而不是零填充。

**kwargs

传给 librosa.zero_crossings 的额外关键字参数

thresholdfloat >= 0

若指定，则把 -threshold <= y <= threshold 的值 裁剪为 0。

ref_magnitudefloat > 0 or callable

若为数值，则阈值相对 ref_magnitude 缩放。 若为可调用对象，则阈值相对 ref_magnitude(np.abs(y)) 缩放。

zero_posbool

若为 True，则把数值 0 视为正号。 若为 False，则 0、-1 与 +1 的符号各不相同。

axisint

计算过零点所沿的轴。 .. note:: 默认情况下，pad 参数设为 False，这与 librosa.zero_crossings 指定的默认值不同。

返回值

返回值类型说明
zcrnp.ndarray [shape=(…, 1, t)]

zcr[..., 0, i] 是帧 i 中过零点的比例

参见

  • librosa.zero_crossings：

    计算时间序列中的过零点

示例

>>> y, sr = librosa.loadx('trumpet')
>>> librosa.feature.zero_crossing_rate(y)
array([[0.044, 0.074, ..., 0.488, 0.355]])
