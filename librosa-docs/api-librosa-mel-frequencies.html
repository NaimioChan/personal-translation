librosa.mel_frequencies

librosa.mel_frequencies(n_mels=128, *, fmin=0.0, fmax=11025.0, htk=False) [源码]

计算一组按 mel 刻度调音的声学频率数组。

mel 刻度是声学频率的准对数函数， 其设计使得感知上相近的音高间隔（例如八度） 在整个听觉范围内看起来宽度相等。

由于 mel 刻度的定义取决于有限次主观心理声学实验， 音频信号处理文献中并存着多种实现 [1]。默认情况下，librosa 复现 Slaney 的经典 MATLAB Auditory Toolbox 的行为 [2]。 按该默认实现，赫兹到 mel 的换算在 1 kHz 以下为线性， 在 1 kHz 以上为对数。另一种可用的实现复现 隐马尔可夫工具包 [3]（HTK），按如下公式：

mel = 2595.0 * np.log10(1.0 + f / 700.0).

选用哪种实现由 htk 关键字参数决定：设 htk=False 得到 Auditory toolbox 的实现，设 htk=True 则得到 HTK 实现。

[1] Umesh, S., Cohen, L., & Nelson, D. Fitting the mel scale. In Proc. International Conference on Acoustics, Speech, and Signal Processing (ICASSP), vol. 1, pp. 217-220, 1998.

[2] Slaney, M. Auditory Toolbox: A MATLAB Toolbox for Auditory Modeling Work. Technical Report, version 2, Interval Research Corporation, 1998.

[3] Young, S., Evermann, G., Gales, M., Hain, T., Kershaw, D., Liu, X., Moore, G., Odell, J., Ollason, D., Povey, D., Valtchev, V., & Woodland, P. The HTK book, version 3.4. Cambridge University, March 2009.

参数

参数类型说明
n_melsint > 0 [scalar]

mel bin 的数量。

fminfloat >= 0 [scalar]

最低频率（Hz）。

fmaxfloat >= 0 [scalar]

最高频率（Hz）。

htkbool

若为 True，使用 HTK 公式把 Hz 换算为 mel。 否则（False），使用 Slaney 的 Auditory Toolbox。

返回值

返回值类型说明
bin_frequenciesndarray [shape=(n_mels,)]

包含 n_mels 个频率（单位 Hz）的向量，在 mel 轴上均匀分布。
