librosa.effects.pitch_shift

librosa.effects.pitch_shift(y, *, sr, n_steps, bins_per_octave=12, res_type='soxr_hq', scale=False, **kwargs) [源码]

把波形的音高移动 n_steps 个步。

若 bins_per_octave 设为 12，一个步等于一个半音。

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的音频采样率

n_stepsfloat [scalar]

移动 y 音高的步数（可为小数）

bins_per_octaveint > 0 [scalar]

每个八度的步数

res_typestr

重采样类型。默认使用 ‘soxr_hq’。

更多信息见 librosa.resample。

scalebool

对重采样后的信号做缩放，使 y 与 y_hat 的总能量大致相等。

**kwargsadditional keyword arguments.

详见 librosa.decompose.stft。

返回值

返回值类型说明
y_shiftnp.ndarray [shape=(…, n)]

音高移动后的音频时间序列

参见

  • time_stretch：

    时间拉伸

  • librosa.phase_vocoder：

    频谱图相位声码器

  • pyrubberband.pyrb.pitch_shift：

    使用 RubberBand 的高质量音高移动

示例

向上移动大三度（若 bins_per_octave 为 12 则为四步）

>>> y, sr = librosa.loadx('choice')
>>> y_third = librosa.effects.pitch_shift(y, sr=sr, n_steps=4)

向下移动三全音（若 bins_per_octave 为 12 则为六步）

>>> y_tritone = librosa.effects.pitch_shift(y, sr=sr, n_steps=-6)

向上移动 3 个四分音

>>> y_three_qt = librosa.effects.pitch_shift(y, sr=sr, n_steps=3,
...                                          bins_per_octave=24)
