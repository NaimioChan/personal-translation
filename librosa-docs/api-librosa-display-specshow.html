librosa.display.specshow

librosa.display.specshow(data, *, x_coords=None, y_coords=None, x_axis=None, y_axis=None, vscale=None, sr=22050, hop_length=512, n_fft=None, win_length=None, fmin=None, fmax=None, tempo_min=16, tempo_max=480, tuning=0.0, bins_per_octave=12, key='C:maj', Sa=None, mela=None, thaat=None, auto_aspect=True, htk=False, unicode=True, intervals=None, unison=None, top_db=80.0, cmap_seq='magma', cmap_bool='gray_r', cmap_div='coolwarm', cmap_cyclic='twilight_shifted', div_thresh=0.0, ax=None, **kwargs) [源码]

显示频谱图/色度图/CQT 等。

显示功能的详细概览见显示与可视化教程。

参数

参数类型说明
datanp.ndarray [shape=(d, n)]

要显示的矩阵（例如频谱图）

x_coords, y_coordsnp.ndarray [shape=data.shape[0 or 1]]

输入数据可选的位置坐标。 可用它们显式设定每个元素 data[i, j] 的位置，例如在自然时间坐标下显示节拍同步特征。

若未提供，则由 x_axis 和 y_axis 推断。

x_axis, y_axisNone or str

x 轴和 y 轴的范围。

有效类型为：

  • None、‘none’ 或 ‘off’：不显示任何坐标轴装饰。

频率类型：

  • ‘linear’、‘fft’、‘hz’：频率范围由 FFT 窗和采样率决定。

  • ‘log’：频谱以对数刻度显示。

  • ‘oct3’：频谱以对数刻度显示，频率按 1/3 八度间隔以科学计数法标注

  • ‘fft_note’：频谱以对数刻度显示，并标注音高。

  • ‘fft_svara’：频谱以对数刻度显示，并标注 svara。

  • ‘mel’：频率由 mel 刻度决定。

  • ‘mel_oct3’：同上面的 ‘oct3’，但使用 mel 刻度。

  • ‘cqt_hz’：频率由 CQT 刻度决定。

  • ‘cqt_oct3’：同上面的 ‘oct3’，但使用 CQT 刻度。

  • ‘cqt_note’：音高由 CQT 刻度决定。

  • ‘cqt_svara’：同 cqt_note，但使用 Hindustani 或 Carnatic svara

  • ‘vqt_hz’：同 cqt_hz，但使用可变 Q 变换（VQT）刻度。

  • ‘vqt_oct3’：同上面的 ‘oct3’，但使用 VQT 刻度。

  • ‘vqt_fjs’：同 cqt_note，但使用 Functional Just System（FJS）记谱法。这要求基于纯律的可变 Q 变换表示。

  • ‘vqt_note’：同 ‘cqt_note’，但使用 VQT 刻度。

所有频率类型都以 Hz 为单位绘制。

oct3 类型对频率使用 SI 前缀，例如 1 kHz、2 MHz，很适合使用高频数据的科学应用。

注意

‘log’、‘fft_note’、‘fft_svara’、‘log_oct3’、‘mel’ 和 ‘mel_oct3’ 轴使用对称对数刻度，以保留 0 Hz 附近的频率 bin。CQT 和 VQT 轴使用对数刻度。

生成输入数据所用的任何频谱图参数（hop_length、sr、bins_per_octave 等）在调用 specshow 时也应一并提供。

类别类型：

  • ‘chroma’：音高由色度滤波器决定。音级按给定的调排列在整数位置（0-11）上。

  • chroma_h、chroma_c：音高由色度滤波器决定，并按给定的 thaat（Hindustani）或 melakarta raga（Carnatic）标注为 Hindustani（chroma_h）或 Carnatic（chroma_c）的 svara。

  • ‘chroma_fjs’：音高由基于纯律的色度滤波器决定。所有音级都会被标注。

  • ‘tonnetz’：坐标轴按 Tonnetz 维度（0-5）标注

  • ‘frames’：标记显示为帧计数。

时间类型：

    • ‘time’标记显示为毫秒、秒、分钟或小时。：

      数值以秒为单位绘制。

  • ‘h’：标记显示为小时、分钟和秒。

  • ‘m’：标记显示为分钟和秒。

  • ‘s’：标记显示为秒。

  • ‘ms’：标记显示为毫秒。

  • ‘lag’：同 time，但超过中点部分按负值计。

  • ‘lag_h’：同 lag，但以小时、分钟和秒表示。

  • ‘lag_m’：同 lag，但以分钟和秒表示。

  • ‘lag_s’：同 lag，但以秒表示。

  • ‘lag_ms’：同 lag，但以毫秒表示。

节奏：

    • ‘tempo’标记显示为每分钟拍数（BPM）：

      使用对数刻度。这对于可视化 feature.tempogram 的输出很有用。

    • ‘fourier_tempo’同 ‘tempo’，但用于：

      使用 feature.fourier_tempogram 在频域计算节奏图的情况。

vscalestr

data 的可选数值变换。支持以下取值：

  • ‘dB’：以 1 为参考幅度的分贝值

  • ‘dB[<value>]’：以给定值为参考幅度的分贝值，例如 ‘dB[0.1]’。

  • ‘dB[power]’：同上，但把 data 视为功率而非幅度

  • ‘dB[power,<value>]’：同上，但显式给出参考功率值，例如 ‘dB[power,0.1]’。

  • ‘dBFS’：相对于满量程的分贝值，以 np.max(data) 为参考幅度

  • ‘dBFS[power]’：同上，但把 data 视为功率而非幅度

  • ‘phase’：以弧度计的相位值，范围为 [-π, π]。

  • ‘dphase’：以弧度计的展开相位差。每个像素对应观测相位与“频率在上一步保持平稳时的预期相位”之间的残差。取值范围为 [-π, π]。

  • ‘dphase_t’：同上，但沿垂直轴而非水平轴计算差值。这适用于时间轴为垂直、频率轴为水平的转置频谱图。

注意

使用相位差模式（dphase 或 dphase_t）时，必须通过 x_axis 和 y_axis 参数（例如 ‘time’、‘fft’）提供 x 和 y 坐标，或通过 x_coords 和 y_coords 参数显式给出。所有类时间轴和类频率轴都受支持。

srnumber > 0 [scalar]

用于确定 x 轴时间尺度的采样率。

hop_lengthint > 0 [scalar]

跳距，也用于确定 x 轴时间尺度

n_fftint > 0 or None

STFT/频谱图显示中每帧的采样点数。 默认由 data 的形状推断为 2 * (d - 1)。 若 data 是使用奇数帧长生成的，可在此指定正确的值。

win_lengthint > 0 or None

每个窗的采样点数。 默认推断为与 n_fft 相同。 这主要用于在傅里叶节奏图显示中指定奇数窗长。

fminfloat > 0 [scalar] or None

频谱图最低 bin 的频率。用于 mel、CQT 和 VQT 刻度。

若 y_axis 为 cqt_hz 或 cqt_note 且未给出 fmin，默认设为 note_to_hz('C1')。

fmaxfloat > 0 [scalar] or None

用于设定 mel 频率刻度

tempo_minfloat > 0 [scalar]

节奏图显示的最低速度（单位：每分钟拍数）。

tempo_maxfloat > 0 [scalar]

节奏图显示的最高速度（单位：每分钟拍数）。

tuningfloat

相对 A440 的调音偏差，以 bin 的分数表示。

用于 CQT 频率刻度，此时 fmin 被调整为 fmin * 2**(tuning / bins_per_octave)。

bins_per_octaveint > 0 [scalar]

每个八度的 bin 数量。用于 CQT 频率刻度。

keystr

使用音符轴（cqt_note、chroma）时的参考调。

Safloat or int

若使用 Hindustani 或 Carnatic svara 轴装饰，请指定 Sa。

对于 cqt_svara，Sa 应指定为以 Hz 计的频率。

对于 chroma_c 或 chroma_h，Sa 应对应 Sa 在色度图内的位置。 若未提供，Sa 默认为 0（等价于 C）

melastr or int, optional

若使用 chroma_c 或 cqt_svara 显示模式，请指定 melakarta raga。

thaatstr, optional

若使用 chroma_h 显示模式，请指定父 thaat。

auto_aspectbool

若水平和垂直维度覆盖相同的范围且类型匹配，坐标轴将采用 ‘equal’ 纵横比。

要覆盖此行为，请设为 False。

htkbool

在 mel 频率轴上绘制时，指定使用哪个版本的 mel 刻度。

  • False：使用 Slaney 公式（默认）

  • True：使用 HTK 公式

更多信息见 core.mel_frequencies。

unicodebool

使用音符或 svara 装饰时，设 unicode=True 将使用 unicode 字形表示变音记号和八度编码。

设 unicode=False 将使用 ASCII 字形。若字体不支持乐谱符号，这会有所帮助。

intervalsstr or array of floats in [1, 2), optional

使用 FJS 记谱法（chroma_fjs、vqt_fjs）时的音程规格。

支持的取值说明见 core.interval_frequencies。

unisonstr, optional

使用 FJS 记谱法（chroma_fjs、vqt_fjs）时，同度音程的音名。若未提供，则由 fmin 推断（VQT 显示），或假定为 ‘C’（色度显示）。

top_dbfloat

使用分贝刻度时，允许低于峰值的分贝数，超过即被截断。

cmap_seqstr or matplotlib.colors.Colormap

分贝刻度所用顺序型色图的名称。默认是 ‘magma’。

cmap_boolstr or matplotlib.colors.Colormap

布尔数据所用色图的名称。默认是 ‘gray_r’。

cmap_divstr or matplotlib.colors.Colormap

发散数据所用发散型色图的名称。默认是 ‘coolwarm’。

cmap_cyclicstr or matplotlib.colors.Colormap

相位数据所用循环色图的名称。默认是 ‘twilight_shifted’。

div_threshfloat

判定是否使用发散型色图的阈值。 若数据中同时存在高于和低于此阈值的值，则使用发散型色图。

axmatplotlib.axes.Axes or None

用于绘制的坐标轴，代替默认的 plt.gca()。

**kwargsadditional keyword arguments

透传给 matplotlib.pyplot.pcolormesh 的参数。

默认设置以下选项：

  • rasterized=True

  • shading='auto'

  • edgecolors='None'

返回值

返回值类型说明
colormeshmatplotlib.collections.QuadMesh

matplotlib.pyplot.pcolormesh 生成的色块网格对象

参见

  • colorbar_db
  • colorbar_phase
  • infer_cmap：

    自动色图检测

  • matplotlib.pyplot.pcolormesh

说明

若未通过 kwargs 提供 cmap 选项，它会由数据自动推断。 若指定了 vscale，分贝数据将使用顺序型色图，相位和相位差数据将使用循环色图。

若推断出发散型色图，则对颜色刻度做归一化，使中心值（默认 div_thresh=0）位于色图中心。

要使用 matplotlib 的默认色图，请显式设 cmap=None。

示例

使用默认参数可视化 STFT 幅度谱

>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('choice', duration=15)
>>> fig, ax = plt.subplots(nrows=2, ncols=1, sharex=True)
>>> D = librosa.stft(y)
>>> img = librosa.display.specshow(D, y_axis='linear', x_axis='time',
...                                vscale='dBFS', sr=sr, ax=ax[0])
>>> ax[0].set(title='Linear-frequency magnitude spectrogram')
>>> ax[0].label_outer()

或使用对数刻度，并采用更大的跳距

>>> hop_length = 1024
>>> D = librosa.stft(y, hop_length=hop_length)
>>> librosa.display.specshow(D, y_axis='log', sr=sr, hop_length=hop_length,
...                          vscale='dBFS', x_axis='time', ax=ax[1])
>>> ax[1].set(title='Log-frequency magnitude spectrogram')
>>> ax[1].label_outer()
>>> librosa.display.colorbar_db(img, ax=ax)
