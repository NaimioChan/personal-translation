librosa.to_stereo

librosa.to_stereo(*, left, right, downmix=True, pad=True, norm=True, out=None) [源码]

把两个信号合并为立体声信号。

参数

参数类型说明
leftnp.ndarray [shape=(…, n)] or None

左声道信号。支持多声道。

rightnp.ndarray [shape=(…, m)] or None

右声道信号。支持多声道。

downmixbool

若为 True，合并前把左右声道下混为单声道。

若为 False，左右两路信号相加合并。

padbool

若为 True，用零填充较短的声道，使其与较长声道等长。 若为 False，把较长声道裁剪至较短声道的长度。

normbool

若为 True（默认），各信号通过求平均合并。

若为 False，各信号通过求和合并。

outnp.ndarray [shape=(2, n_out)] or None

预先分配的输出缓冲区。若提供，其形状必须为 (2, n_out)，且 dtype 精度不低于结果 dtype； 它会被清零并原地写入后返回，从而避免新分配。若为 None（默认），则分配新数组。

返回值

返回值类型说明
y_stereonp.ndarray [shape=(2, n_out)]

立体声信号，左声道在第一行，右声道在第二行。 若提供了 out，返回的就是 out 本身。

参见

  • to_mono
  • to_multi
  • util.fix_length

说明

left 与 right 至少要提供一个。

示例

把两个单声道信号合并为硬声像立体声信号

>>> y1 = librosa.tone(440.0, sr=22050, duration=1.0)
>>> y2 = librosa.tone(550.0, sr=22050, duration=1.0)
>>> y_stereo = librosa.to_stereo(left=y1, right=y2)

把单声道信号上混至立体声的左声道或右声道

>>> y_left = librosa.to_stereo(left=y1, right=None)
>>> y_right = librosa.to_stereo(left=None, right=y2)

把立体声信号下混至左声道，并把第三个单声道信号混入右声道

>>> y3 = librosa.tone(660.0, sr=22050, duration=1.0)
>>> y_mix = librosa.to_stereo(left=y_stereo, right=y3, downmix=True)

保持原立体声信号各声道独立，但把第三个信号混入右声道：

>>> y_mix = librosa.to_stereo(left=y_stereo, right=y3, downmix=False)
