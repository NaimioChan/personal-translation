工具

librosa.util 包含整个包中使用的各种工具函数。

工具函数大致分为以下几类：

  • 数值运算（基于数值的处理、优化等）

  • 数组形状操作（切片、分帧、填充等）。

  • 匹配（事件或时间区间）

  • 文件与数据（随包示例、元数据等）

  • 数据验证（类型与范围检查）
