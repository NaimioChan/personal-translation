librosa.blocks_to_samples

librosa.blocks_to_samples(blocks, *, block_length, hop_length) [源码]

把块下标转换为采样下标

参数

参数类型说明
blocksnp.ndarray

块下标，或块下标组成的数组

block_lengthint > 0

每块的帧数

hop_lengthint > 0

帧之间前进的采样数

返回值

返回值类型说明
samplesnp.ndarray [shape=samples.shape, dtype=int]

与所给每个块的起始位置相对应的采样下标。

注意这些下标对应每个块的第一个采样，并非以帧为中心。

参见

  • blocks_to_frames
  • blocks_to_time

示例

获取流中每个块的采样下标

>>> filename = librosa.ex('brahms')
>>> sr = librosa.get_samplerate(filename)
>>> stream = librosa.stream(filename, block_length=16,
...                         frame_length=2048, hop_length=512)
>>> for n, y in enumerate(stream):
...     n_sample = librosa.blocks_to_samples(n, block_length=16,
...                                          hop_length=512)
