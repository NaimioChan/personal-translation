数值运算

函数说明

localmax

找出数组中的局部极大值

localmin

找出数组中的局部极小值

peak_pick

用一套灵活的启发式规则在信号中挑选峰值。

softmask

以数值稳健的方式计算软掩码运算。

count_unique

统计沿给定轴的不同取值个数。

is_unique

判断输入沿给定轴的取值是否全部互不相同。

nnls

非负最小二乘。

cyclic_gradient

在均匀采样的周期域上估计函数的梯度。

dtype_c2r

找出与复数类型对应的实数 numpy 类型。

dtype_r2c

找出与实数类型对应的复数 numpy 类型。

buf_to_float

把整数缓冲区转换为浮点值。

tiny

计算与输入数据类型对应的极小值。

abs2

计算实数或复数数组的幅度平方。

phasor

由角度构造复数相量表示。

sync

在指定的边界之间对多维数组做聚合。

interp_broadcast

通过插值对两个数组做广播

axis_sort

沿数组的行或列排序。

normalize

沿选定轴对数组归一化。

sparsify_rows

返回输入数组的行稀疏逼近
