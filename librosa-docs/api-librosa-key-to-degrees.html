librosa.key_to_degrees

librosa.key_to_degrees(key) [源码]

构造给定调式所包含的自然音阶级数。

参数

参数类型说明
keystr

必须采用 TONIC:key 的形式。主音必须大写（CDEFGAB）， 调式必须小写 （maj、min、ionian、dorian、phrygian、lydian、mixolydian、aeolian、locrian）。

调式支持以下缩写：调式名称的前三个字母 （例如 “mix”），或去掉 “ian” 的调式名称（例如 “mixolyd”）。

major 与 maj 都可以作为缩写使用。

支持单个和多个变音记号（b!♭ 表示降号，#♯ 表示升号）。

示例：C:maj, C:major, Dbb:min, A♭:min, D:aeo, E𝄪:phryg。

返回值

返回值类型说明
degreesnp.ndarray

一个数组，包含给定调中七个音阶级数 各自的半音编号（0=C，1=C#，……，11=B）， 从主音开始。

参见

  • key_to_notes

示例

>>> librosa.key_to_degrees('C:maj')
array([ 0,  2,  4,  5,  7,  9, 11])
>>> librosa.key_to_degrees('C#:maj')
array([ 1,  3,  5,  6,  8, 10,  0])
>>> librosa.key_to_degrees('A:min')
array([ 9, 11,  0,  2,  4,  5,  7])
>>> librosa.key_to_degrees('A:min')
array([ 9, 11,  0,  2,  4,  5,  7])
