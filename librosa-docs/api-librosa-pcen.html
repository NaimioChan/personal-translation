librosa.pcen

librosa.pcen(S, *, sr=22050, hop_length=512, gain=0.98, bias=2, power=0.5, time_constant=0.4, eps=1e-06, b=None, max_size=1, ref=None, axis=-1, max_axis=None, zi=None, return_zf=False) [源码]

逐通道能量归一化（PCEN）

此函数先对时频表示 S 做自动增益控制，再做非线性压缩，从而对其归一化 [1]

P[f, t] = (S / (eps + M[f, t])**gain + bias)**power - bias**power

重要：eps、gain、bias、power 的默认值与原始论文一致，其中 S 为 40 个频带的 mel 频谱图，窗长 25 ms，帧移 10 ms，原始音频值位于区间 [-2**31; 2**31-1[ 内。若使用这些默认值，建议确保原始音频已恰当缩放到该区间，而不是最常见的 [-1, 1[。

矩阵 M 是对 S 施加低通时间 IIR 滤波的结果：

M[f, t] = (1 - b) * M[f, t - 1] + b * S[f, t]

若未提供 b，则按如下方式计算：

b = (sqrt(1 + 4* T**2) - 1) / (2 * T**2)

其中 T = time_constant * sr / hop_length。[2]

此归一化旨在抑制背景噪声、突出前景信号，可作为分贝缩放的替代（amplitude_to_db）。

本实现还支持通过指定 max_size > 1 在频率 bin 之间做平滑。若使用该选项，滤波后的频谱图 M 按如下方式计算：

M[f, t] = (1 - b) * M[f, t - 1] + b * R[f, t]

其中 R 已沿频率轴做过最大值滤波，与 onset.onset_strength 中实现的 SuperFlux 算法类似：

R[f, t] = max(S[f - max_size//2: f + max_size//2, t])

这可用于对跨越或横跨多个频带的信号做自动增益控制，对高频率分辨率的频谱图可能更有利。

[1] Wang, Y., Getreuer, P., Hughes, T., Lyon, R. F., & Saurous, R. A. (2017, March). Trainable frontend for robust and far-field keyword spotting. In Acoustics, Speech and Signal Processing (ICASSP), 2017 IEEE International Conference on (pp. 5670-5674). IEEE.

[2] Lostanlen, V., Salamon, J., McFee, B., Cartwright, M., Farnsworth, A., Kelling, S., and Bello, J. P. Per-Channel Energy Normalization: Why and How. IEEE Signal Processing Letters, 26(1), 39-43.

参数

参数类型说明
Snp.ndarray (non-negative)

输入（幅度）频谱图

srnumber > 0 [scalar]

音频采样率

hop_lengthint > 0 [scalar]

S 的跳距，以采样点表示

gainnumber >= 0 [scalar]

增益因子。典型值应略小于 1。

biasnumber >= 0 [scalar]

非线性压缩的偏置点（默认：2）

powernumber >= 0 [scalar]

压缩指数。典型值应在 0 到 0.5 之间。 power 越小压缩越强。 在极限 power=0 时，多项式压缩变为对数压缩。

time_constantnumber > 0 [scalar]

IIR 滤波的时间常数，以秒计。

epsnumber > 0 [scalar]

用于保证滤波器数值稳定的小常数。

bnumber in [0, 1] [scalar]

低通滤波器的滤波系数。 若未提供，将由 time_constant 推断。

max_sizeint > 0 [scalar]

作用于频率轴的最大值滤波器宽度。 保持为 1 时不做滤波。

refNone or np.ndarray (shape=S.shape)

可选的预先计算参考频谱（上文的 R）。 若未提供，将从 S 计算。

axisint [scalar]

输入频谱图的（时间）轴。

max_axisNone or int [scalar]

输入频谱图的频率轴。 若为 None 且 S 为二维，将推断为与 axis 相反的另一轴。 若 S 非二维且 max_size > 1，将报错。

zinp.ndarray

滤波器的初始延迟值。

可以是之前调用 pcen 得到的 zf（最终延迟值），或由 scipy.signal.lfilter_zi 计算得到。

return_zfbool

若为 True，连同 PCEN 输出 P 一起返回最终滤波延迟值。 这在流式处理中最有用：前一处理块的最终状态可用于初始化下一块。

若为 False（默认），只返回 PCEN 值 P。

返回值

返回值类型说明
Pnp.ndarray, non-negative [shape=(n, m)]

S 经逐通道能量归一化后的版本。

zfnp.ndarray (optional)

最终滤波延迟值。仅在 return_zf=True 时返回。

示例

在 mel 频谱上比较 PCEN 与对数幅度（dB）缩放

>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('robin')
>>> # We recommend scaling y to the range [-2**31, 2**31[ before applying
>>> # PCEN's default parameters. Furthermore, we use power=1 to get a
>>> # magnitude spectrum instead of a power spectrum.
>>> S = librosa.feature.melspectrogram(y=y, sr=sr, power=1)
>>> log_S = librosa.amplitude_to_db(S, ref=np.max)
>>> pcen_S = librosa.pcen(S * (2**31))
>>> fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
>>> img = librosa.display.specshow(log_S, x_axis='time', y_axis='mel', ax=ax[0])
>>> ax[0].set(title='log amplitude (dB)', xlabel=None)
>>> ax[0].label_outer()
>>> imgpcen = librosa.display.specshow(pcen_S, x_axis='time', y_axis='mel', ax=ax[1])
>>> ax[1].set(title='Per-channel energy normalization')
>>> librosa.display.colorbar_db(img, ax=ax[0])
>>> fig.colorbar(imgpcen, ax=ax[1])
>>> plt.show()

比较使用最大值滤波与不使用最大值滤波的 PCEN

>>> pcen_max = librosa.pcen(S * (2**31), max_size=3)
>>> fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
>>> librosa.display.specshow(pcen_S, x_axis='time', y_axis='mel', ax=ax[0])
>>> ax[0].set(title='Per-channel energy normalization (no max-filter)')
>>> ax[0].label_outer()
>>> img = librosa.display.specshow(pcen_max, x_axis='time', y_axis='mel', ax=ax[1])
>>> ax[1].set(title='Per-channel energy normalization (max_size=3)')
>>> fig.colorbar(img, ax=ax)
>>> plt.show()
