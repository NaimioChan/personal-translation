librosa.display.ChromaSvaraFormatter

class librosa.display.ChromaSvaraFormatter(Sa=None, mela=None, abbr=True, unicode=True) [源码]

以 svara 代替音名的色度轴格式化器。

若给出 mela，则使用卡纳提克 svara 名称。否则使用印度斯坦 svara 名称。若未给出 Sa，则默认为 0（等同于 C）。

参数

参数类型说明
Safloat or None

与 Sa 对应的 MIDI 音符号。若为 None，默认为 0（C）。

melastr, int, or None

对于卡纳提克 svara，为 melakarta 拉格的序号或名称。 若为 None，则使用印度斯坦 svara 名称。

abbrbool

若为 True，使用 svara 名称的缩写。

若为 False，使用完整的 svara 名称。

unicodebool

若为 True，使用 Unicode 符号表示变音记号。

若为 False，使用 ASCII 符号表示变音记号。
