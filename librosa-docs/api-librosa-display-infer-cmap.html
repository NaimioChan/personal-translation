librosa.display.infer_cmap

librosa.display.infer_cmap(data, *, robust=True, cmap_seq='magma', cmap_bool='gray_r', cmap_div='coolwarm', div_thresh=0.0) [源码]

根据给定数据得到默认色图。

若数据为布尔值，使用黑白两色色图。

若数据同时包含正值和负值，使用发散型色图。

否则使用顺序型色图。

参数

参数类型说明
datanp.ndarray

输入数据

robustbool

若为 True，计算范围时丢弃数据的最高和最低 2%。

cmap_seqstr or matplotlib.colors.Colormap

顺序型色图

cmap_boolstr or matplotlib.colors.Colormap

布尔型色图

cmap_divstr or matplotlib.colors.Colormap

发散型色图

div_threshfloat

判定是否使用发散型色图的阈值。 若数据中同时存在高于和低于此阈值的值，则使用发散型色图。

返回值

返回值类型说明
cmapmatplotlib.colors.Colormap

用于 data 的色图
