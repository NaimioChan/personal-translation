librosa.istft

librosa.istft(stft_matrix, *, hop_length=None, win_length=None, n_fft=None, window='hann', center=True, dtype=None, length=None, out=None) [源码]

逆短时傅里叶变换（ISTFT）。

按照 [1] 中所述（到第 2 节为止，即从 MSTFT 重建）， 通过最小化 stft_matrix 与其 STFT 与 y 之间的均方误差， 把复值频谱图 stft_matrix 转换为时间序列 y。

总体来说，窗函数、跳距及其他参数应与 stft 中相同， 这样通常可以由未经修改的 stft_matrix 完美重建信号。

[1] D. W. Griffin and J. S. Lim, “Signal estimation from modified short-time Fourier transform,” IEEE Trans. ASSP, vol.32, no.2, pp.236–243, Apr. 1984.

参数

参数类型说明
stft_matrixnp.ndarray [shape=(…, 1 + n_fft//2, t)]

由 stft 得到的 STFT 矩阵

hop_lengthint > 0 [scalar]

STFT 各列之间的帧数。 若未指定，默认取 win_length // 4。

win_lengthint <= n_fft = 2 * (stft_matrix.shape[-2] - 1)

重建时间序列时，每帧会被加窗， 且每个采样点会按 window 函数（见下文）的 窗平方和进行归一化。

若未指定，默认取 n_fft。

n_fftint > 0 or None

输入频谱图中每帧的采样点数。 默认推断为 2 * (stft_matrix.shape[-2] - 1)， 这假定 n_fft 为偶数。若 STFT 是用 奇数 n_fft 计算的，该推断会差一；此时请传入原始的 n_fft 以恢复正确的帧长。

windowstr, tuple, number, function, np.ndarray [shape=(n_fft,)]

  • 窗的规格（str、tuple 或 number）； 参见 scipy.signal.get_window

  • 窗函数，例如 scipy.signal.windows.hann

  • 用户指定的、长度为 n_fft 的窗向量

centerbool

  • 若为 True，假定 D 使用中心化帧。

  • 若为 False，假定 D 使用左对齐帧。

dtypenumeric type

y 的实数数值类型。默认与输入频谱图的 数值精度一致。

lengthint > 0, optional

若提供，输出 y 会被零填充或裁剪到恰好 length 个采样点。

outnp.ndarray or None

用于存放重建信号 y 的预分配复值数组。 其形状必须与给定输入参数相符。

若未提供，则新分配一个数组并返回。

返回值

返回值类型说明
ynp.ndarray [shape=(…, n)]

由 stft_matrix 重建的时域信号。 若 stft_matrix 的轴数多于两个 （例如来自立体声输入信号），则 y 的前导维度形状与之相同。

参见

  • stft：

    短时傅里叶变换

说明

该函数在级别 30 上缓存。

示例

>>> y, sr = librosa.loadx('trumpet')
>>> D = librosa.stft(y)
>>> y_hat = librosa.istft(D)
>>> y_hat
array([-1.407e-03, -4.461e-04, ...,  5.131e-06, -1.417e-05],
      dtype=float32)

要精确保留输入信号的长度，需要显式填充。 否则 y 末尾的部分帧将不会被表示。

>>> n = len(y)
>>> n_fft = 2048
>>> y_pad = librosa.util.fix_length(y, size=n + n_fft // 2)
>>> D = librosa.stft(y_pad, n_fft=n_fft)
>>> y_out = librosa.istft(D, length=n)
>>> np.max(np.abs(y - y_out))
8.940697e-08
