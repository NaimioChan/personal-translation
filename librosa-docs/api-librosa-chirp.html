librosa.chirp

librosa.chirp(*, fmin, fmax, sr=22050, length=None, duration=None, linear=False, phi=None) [源码]

构造“chirp”（扫频）信号。

chirp 从频率 fmin 扫描到 fmax（单位：Hz）。

参数

参数类型说明
fminfloat > 0

起始频率

fmaxfloat > 0

终止频率

srnumber > 0

输出信号的目标采样率

lengthint > 0

输出信号的目标采样数。 当 duration 与 length 同时给出时，length 优先。

durationfloat > 0

目标时长（秒）。 当 duration 与 length 同时给出时，length 优先。

linearbool

  • 若为 True，使用线性扫频，即频率随时间线性变化

  • 若为 False，使用指数扫频。

默认为 False。

phifloat or None

相位偏移，单位为弧度。 若不指定，默认为 -np.pi * 0.5。

返回值

返回值类型说明
chirp_signalnp.ndarray [shape=(length,), dtype=float64]

合成出的 chirp 信号

异常

异常说明
ParameterError

  • 若 fmin 或 fmax 未提供。

  • 若 length 与 duration 均未提供。

参见

  • scipy.signal.chirp

示例

生成从 A2 到 A8 的指数 chirp

>>> exponential_chirp = librosa.chirp(fmin=110, fmax=110*64, duration=1, sr=22050)

或者用 length 生成同样的信号

>>> exponential_chirp = librosa.chirp(fmin=110, fmax=110*64, sr=22050, length=22050)

或者改为生成线性 chirp

>>> linear_chirp = librosa.chirp(fmin=110, fmax=110*64, duration=1, linear=True, sr=22050)

显示指数 chirp 与线性 chirp 的频谱图。

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
>>> S_exponential = np.abs(librosa.stft(y=exponential_chirp))
>>> librosa.display.specshow(S_exponential, vscale='dBFS',
...                          x_axis='time', y_axis='linear', ax=ax[0])
>>> ax[0].set(title='Exponential chirp', xlabel=None)
>>> ax[0].label_outer()
>>> S_linear = np.abs(librosa.stft(y=linear_chirp))
>>> librosa.display.specshow(S_linear, vscale='dBFS',
...                          x_axis='time', y_axis='linear', ax=ax[1])
>>> ax[1].set(title='Linear chirp')
