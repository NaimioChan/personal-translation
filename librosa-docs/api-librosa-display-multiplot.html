librosa.display.multiplot

librosa.display.multiplot(func, *data, axes=None, fig=None, orient='v', share_properties=None, fig_kw=None, sharex=True, sharey=True, label_outer=True, labels=None, titles=None, prop_cycle=None, **kwargs) [源码]

在子图数组上可视化多条相关的波形或频谱图。

示例用途包括：

  • 显示多声道音频文件中的多条波形。

  • 显示多声道音频文件中的多张频谱图。

参数

参数类型说明
funcstr

多图可视化使用的显示函数名称。可取值为 ‘waveshow’、‘wavebars’ 和 ‘specshow’。

*dataone or more np.ndarray

多图可视化的输入数据。 若只提供一个数组，则将其解释为多声道数组，其前导维对应要绘制的不同声道或信号。 若提供多个数组，则每个数组视为一个声道或输入信号，并绘制在自己的子图上。

axesmatplotlib.axes.Axes, np.ndarray, or None

多图可视化使用的坐标轴。若为 None，将在 fig 上新建坐标轴数组。 若提供 Axes 对象数组，其形状必须与数据形状兼容。 若只提供一个坐标轴对象，则视为 1x1 数组（即单个子图）。

figmatplotlib.figure.FigureBase or None

多图可视化使用的图。若为 None，需要时新建一个图。 若提供了 axes，图将由 axes 推断，fig 参数将被忽略。

orientstr {‘h’, ‘v’}

多图网格的排列方向。可取值为 ‘h’（水平）和 ‘v’（垂直）。当输入数据只有一个非单例维（例如形状为 (n, k) 且 k > 1）时，由它决定子图的排列方式。

share_propertiesbool, str, np.ndarray, or None

多图网格的属性共享方案。可取值为：

  • None 或 False：不共享任何属性，每个子图视为独立的组。

  • True：所有子图共享相同属性，属于同一组。

  • ‘row’：同一行的子图共享属性，属于同一组

  • ‘col’：同一列的子图共享属性，属于同一组。

  • np.ndarray：为每个子图自定义组标识数组。数组形状必须与坐标轴网格的形状一致。取值相同的任意两个元素视为属于同一组，并共享属性。

fig_kwdict or None

新建图时传给 plt.subplots 的其他关键字参数。

sharexbool

新建图时子图之间是否共享 x 轴。

shareybool

新建图时子图之间是否共享 y 轴。

label_outerbool

使用共享坐标轴时，是否只在最外层的坐标轴上显示标签。

labelssequence of str or None

应用于多图网格中各个子图的标签。若为 None，则不添加标签。若提供序列，它必须与坐标轴的形状兼容。

titlessequence of str or None

应用于多图网格中各个子图的标题。若为 None，则不添加标题。若提供序列，它必须与坐标轴的形状兼容。

prop_cyclecycler.Cycler or None

为子图分配属性所用的属性循环。若为 None，则使用 plt.rcParams[“axes.prop_cycle”] 中的默认属性循环。

**kwargs

传给各个子图显示函数的其他关键字参数。

返回值

返回值说明
np.ndarray

多图网格中每个子图对应的显示函数返回的显示对象组成的数组。 该数组的形状与坐标轴网格的形状兼容。

参见

  • waveshow
  • wavebars
  • specshow
  • legend_for_axes

示例

在数组中以堆叠方式显示多条同步信号。这里让 multiplot 替我们创建图和坐标轴对象。

>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('choice', duration=10)
>>> yh, yp = librosa.effects.hpss(y)
>>> librosa.display.multiplot('waveshow', y, yh, yp,
...                           labels=['Original', 'Harmonic', 'Percussive'],
...                           # The remaining parameters are passed through to waveshow
...                           sr=sr,
...                           invert=True)
>>> plt.gcf().legend()
>>> plt.show()

只要与数据形状兼容，multiplot 也可以接受预先构造好的坐标轴作为输入。下面的示例用频谱图显示演示这一点。

>>> y_stack = librosa.to_multi(y, yh, yp)
>>> stft = librosa.stft(y=y_stack)
>>> fig, ax = plt.subplots(nrows=3, sharex=True, sharey=True, figsize=(8, 8))
>>> img = librosa.display.multiplot('specshow', stft, axes=ax,
...                                 titles=['Original', 'Harmonic', 'Percussive'],
...                                 x_axis='time', y_axis='log', vscale='dBFS')
>>> librosa.display.colorbar_db(img[0], ax=ax, label='dBFS')
>>> plt.show()
