librosa.filters.cq_to_chroma

librosa.filters.cq_to_chroma(n_input, *, bins_per_octave=12, n_chroma=12, fmin=None, window=None, base_c=True, dtype=<class 'numpy.float32'>) [源码]

构造把常数 Q 变换的 bin 映射到色度 bin 的线性变换矩阵。

参数

参数类型说明
n_inputint > 0 [scalar]

输入分量（CQT bin）的数量

bins_per_octaveint > 0 [scalar]

CQT 中每八度的 bin 数量

n_chromaint > 0 [scalar]

色度中（每八度）的输出 bin 数量

fminNone or float > 0

第一个常数 Q 通道的中心频率。 默认：‘C1’ ~= 32.7 Hz

windowNone or np.ndarray

若提供，cq_to_chroma 滤波器组将与 window 做卷积。

base_cbool

若为 True，第一个色度 bin 从 ‘C’ 开始 若为 False，第一个色度 bin 从 ‘A’ 开始

dtypenp.dtype

输出基的数据类型。 默认使用 32 位（单精度）浮点数。

返回值

返回值类型说明
cq_to_chromanp.ndarray [shape=(n_chroma, n_input)]

变换矩阵：Chroma = np.dot(cq_to_chroma, CQT)

异常

异常说明
ParameterError

若 n_input 不是 n_chroma 的整数倍

说明

本函数在层级 10 缓存。

示例

计算 CQT，并把各 bin 折叠到色度

>>> y, sr = librosa.loadx('trumpet')
>>> CQT = np.abs(librosa.cqt(y, sr=sr))
>>> chroma_map = librosa.filters.cq_to_chroma(CQT.shape[0])
>>> chromagram = chroma_map.dot(CQT)
>>> # Max-normalize each time step
>>> chromagram = librosa.util.normalize(chromagram, axis=0)
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=3, sharex=True)
>>> imgcq = librosa.display.specshow(CQT, vscale='dBFS',
...                                  y_axis='cqt_note', x_axis='time',
...                                  ax=ax[0])
>>> ax[0].set(title='CQT Magnitude')
>>> ax[0].label_outer()
>>> librosa.display.specshow(chromagram, y_axis='chroma', x_axis='time',
...                          ax=ax[1])
>>> ax[1].set(title='Chroma (wrapped CQT)')
>>> ax[1].label_outer()
>>> chroma = librosa.feature.chroma_stft(y=y, sr=sr)
>>> imgchroma = librosa.display.specshow(chroma, y_axis='chroma', x_axis='time', ax=ax[2])
>>> ax[2].set(title='librosa.feature.chroma_stft')
