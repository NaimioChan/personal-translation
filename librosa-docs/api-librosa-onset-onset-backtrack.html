librosa.onset.onset_backtrack

librosa.onset.onset_backtrack(events, energy) [源码]

把检测到的起始点事件回溯至能量函数最近的前置局部极小值。

此函数可用于把检测到的起始点时刻由检测到的峰值幅度回退到其前面的最小值。

在利用起始点确定分割切片点时最有用，如 [1] 所述。

[1] Jehan, Tristan. “Creating music by listening” Doctoral dissertation Massachusetts Institute of Technology, 2005.

参数

参数类型说明
eventsnp.ndarray, dtype=int

起始点事件帧索引列表，由 onset_detect 计算得到

energynp.ndarray, shape=(m,)

一个能量函数

返回值

返回值类型说明
events_backtrackednp.ndarray, shape=events.shape

输入事件匹配到 energy 最近的前置极小值后的结果。

示例

用起始包络回溯事件

>>> y, sr = librosa.loadx('trumpet', duration=3)
>>> oenv = librosa.onset.onset_strength(y=y, sr=sr)
>>> times = librosa.times_like(oenv, sr=sr)
>>> # Detect events without backtracking
>>> onset_raw = librosa.onset.onset_detect(onset_envelope=oenv,
...                                        backtrack=False)
>>> onset_bt = librosa.onset.onset_backtrack(onset_raw, oenv)

用 RMS 值回溯事件

>>> S = np.abs(librosa.stft(y=y))
>>> rms = librosa.feature.rms(S=S)
>>> onset_bt_rms = librosa.onset.onset_backtrack(onset_raw, rms[0])

绘制结果

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=3, sharex=True)
>>> librosa.display.specshow(S, vscale='dBFS',
...                          y_axis='log', x_axis='time', ax=ax[0])
>>> ax[0].label_outer()
>>> ax[1].plot(times, oenv, label='Onset strength')
>>> ax[1].vlines(librosa.frames_to_time(onset_raw), 0, oenv.max(), label='Raw onsets')
>>> ax[1].vlines(librosa.frames_to_time(onset_bt), 0, oenv.max(), label='Backtracked', color='r')
>>> ax[1].legend()
>>> ax[1].label_outer()
>>> ax[2].plot(times, rms[0], label='RMS')
>>> ax[2].vlines(librosa.frames_to_time(onset_bt_rms), 0, rms.max(), label='Backtracked (RMS)', color='r')
>>> ax[2].legend()
