librosa.feature.tempogram

librosa.feature.tempogram(*, y=None, sr=22050, onset_envelope=None, hop_length=512, win_length=384, center=True, window='hann', norm=inf) [源码]

计算速度图：起始强度包络的局部自相关。[1]

[1] Grosche, Peter, Meinard Müller, and Frank Kurth. “Cyclic tempogram - A mid-level tempo representation for music signals.” ICASSP, 2010.

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

onset_envelopenp.ndarray [shape=(…, n) or (…, m, n)] or None

可选，由 librosa.onset.onset_strength 得到的预先计算好的起始强度包络。

若为多维，则对每个频带（第一维）独立计算 速度图。

hop_lengthint > 0

相邻起始点测量之间的音频采样点数

win_lengthint > 0

起始点自相关窗的长度（以帧／起始点测量计） 默认设置（384）对应于 384 * hop_length / sr ~= 8.9s。

centerbool

若为 True，起始点自相关窗居中。 若为 False，窗左对齐。

windowstr, function, number, tuple, or np.ndarray [shape=(win_length,)]

窗的规格，同 stft。

norm{np.inf, -np.inf, 0, float > 0, None}

归一化模式。设为 None 可禁用归一化。

返回值

返回值类型说明
tempogramnp.ndarray [shape=(…, win_length, n)]

起始强度包络的局部自相关。

若给定多频带输入（onset_envelope.shape==(m,n)），则 tempogram[i] 是 onset_envelope[i] 的速度图。

异常

异常说明
ParameterError

若 y 与 onset_envelope 均未提供

若 win_length < 1

参见

  • fourier_tempogram
  • librosa.onset.onset_strength
  • librosa.util.normalize
  • librosa.stft

示例

>>> # 计算局部起始点自相关
>>> y, sr = librosa.loadx('nutcracker', duration=30)
>>> hop_length = 512
>>> oenv = librosa.onset.onset_strength(y=y, sr=sr, hop_length=hop_length)
>>> tempogram = librosa.feature.tempogram(onset_envelope=oenv, sr=sr,
...                                       hop_length=hop_length)
>>> # 计算全局起始点自相关
>>> ac_global = librosa.autocorrelate(oenv, max_size=tempogram.shape[0])
>>> ac_global = librosa.util.normalize(ac_global)
>>> # 为便于显示，估计全局速度
>>> tempo = librosa.feature.tempo(onset_envelope=oenv, sr=sr,
...                               hop_length=hop_length)[0]
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=4, figsize=(10, 10))
>>> times = librosa.times_like(oenv, sr=sr, hop_length=hop_length)
>>> ax[0].plot(times, oenv, label='Onset strength')
>>> ax[0].label_outer()
>>> ax[0].legend(frameon=True)
>>> librosa.display.specshow(tempogram, sr=sr, hop_length=hop_length,
...                          x_axis='time', y_axis='tempo', cmap='magma',
...                          ax=ax[1])
>>> hl = librosa.display.highlight(ax=ax[1], linewidth=4, color='w', alpha=.75)
>>> ax[1].axhline(tempo, path_effects=hl, linewidth=2, color='k', linestyle='--',
...               label='Estimated tempo={:g}'.format(tempo))
>>> ax[1].legend(loc='upper right')
>>> ax[1].set(title='Tempogram')
>>> x = np.linspace(0, tempogram.shape[0] * float(hop_length) / sr,
...                 num=tempogram.shape[0])
>>> ax[2].plot(x, np.mean(tempogram, axis=1), label='Mean local autocorrelation')
>>> ax[2].plot(x, ac_global, '--', alpha=0.75, label='Global autocorrelation')
>>> ax[2].set(xlabel='Lag (seconds)')
>>> ax[2].legend(frameon=True)
>>> freqs = librosa.tempo_frequencies(tempogram.shape[0], hop_length=hop_length, sr=sr)
>>> ax[3].semilogx(freqs[1:], np.mean(tempogram[1:], axis=1),
...               label='Mean local autocorrelation', base=2)
>>> ax[3].semilogx(freqs[1:], ac_global[1:], '--', alpha=0.75,
...               label='Global autocorrelation', base=2)
>>> ax[3].axvline(tempo, color='black', linestyle='--', alpha=.8,
...               label='Estimated tempo={:g}'.format(tempo))
>>> ax[3].legend(frameon=True)
>>> ax[3].set(xlabel='BPM')
>>> ax[3].grid(True)
