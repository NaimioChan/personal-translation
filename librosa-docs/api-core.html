核心功能

Librosa 是一个用于音乐与音频分析的 Python 包。它提供了构建音频检索系统所需的组成单元。

核心功能（加载音频、频谱表示等）可从包的顶层访问，而更为专业的功能（节拍跟踪、可视化等）则组织在各个子模块中。
