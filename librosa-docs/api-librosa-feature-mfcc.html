librosa.feature.mfcc

librosa.feature.mfcc(*, y=None, sr=22050, S=None, n_mfcc=20, dct_type=2, norm='ortho', lifter=0, mel_norm='slaney', **kwargs) [源码]

Mel 频率倒谱系数（MFCC）

参数

参数类型说明
ynp.ndarray [shape=(…, n,)] or None

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

Snp.ndarray [shape=(…, d, t)] or None

对数功率 mel 频谱图

n_mfccint > 0 [scalar]

要返回的 MFCC 个数

dct_type{1, 2, 3}

离散余弦变换（DCT）类型。 默认使用 2 型 DCT。

normNone or ‘ortho’

若 dct_type 为 2 或 3，设置 norm='ortho' 将使用正交归一 DCT 基。 dct_type=1 不支持归一化。

lifternumber >= 0
  • 若 lifter>0，对 MFCC 施加 liftering（倒谱滤波）：：

    M[n, :] <- M[n, :] * (1 + sin(pi * (n + 1) / lifter) * lifter / 2)

设置 lifter >= 2 * n_mfcc 会强调高阶系数。 随着 lifter 增大，系数加权趋于近似线性。

mel_normfloat, ‘slaney’, or None

传给 melspectrogram 的 norm 参数

**kwargs

在时间序列输入时传给 melspectrogram 的额外关键字参数

n_fftint > 0 [scalar]

FFT 帧长度

hop_lengthint > 0 [scalar]

相邻帧之间的采样点数。 见 librosa.stft

win_lengthint <= n_fft [scalar]

每一帧音频都用 window() 加窗。 窗的长度为 win_length，随后补零 至 n_fft 长度。 若未指定，默认为 win_length = n_fft。

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

  • 窗的规格（字符串、元组或数值）； 见 scipy.signal.get_window

  • 窗函数，例如 scipy.signal.windows.hann

  • 长度为 n_fft 的向量或数组

centerbool

  • 若为 True，则对信号 y 进行填充，使帧 t 以 y[t * hop_length] 为中心。

  • 若为 False，则帧 t 起始于 y[t * hop_length]

pad_modestr

若 center=True，在信号边缘使用的填充模式。 默认情况下，STFT 使用零填充。

powerfloat > 0 [scalar]

当输入为时间信号时，在计算 mel 频谱图之前作用于频谱的指数， 例如 1 表示幅度，2 表示功率（默认），等等。

**kwargs

mel 滤波器组参数的额外关键字参数

n_melsint > 0 [scalar]

要生成的 mel 频带数

fminfloat >= 0 [scalar]

最低频率（Hz）

fmaxfloat >= 0 [scalar]

最高频率（Hz）。 若为 None，使用 fmax = sr / 2.0

htkbool [scalar]

使用 HTK 公式代替 Slaney 公式

dtypenp.dtype

输出基矩阵的数据类型。 默认使用 32 位（单精度）浮点数。

返回值

返回值类型说明
Mnp.ndarray [shape=(…, n_mfcc, t)]

MFCC 序列

参见

  • melspectrogram
  • scipy.fft.dct

示例

由时间序列生成 mfcc

>>> y, sr = librosa.loadx('libri1')
>>> librosa.feature.mfcc(y=y, sr=sr)
array([[-565.919, -564.288, ..., -426.484, -434.668],
       [  10.305,   12.509, ...,   88.43 ,   90.12 ],
       ...,
       [   2.807,    2.068, ...,   -6.725,   -5.159],
       [   2.822,    2.244, ...,   -6.198,   -6.177]], dtype=float32)

使用不同的跳距与 HTK 风格的 mel 频率

>>> librosa.feature.mfcc(y=y, sr=sr, hop_length=1024, htk=True)
array([[-5.471e+02, -5.464e+02, ..., -4.446e+02, -4.200e+02],
       [ 1.361e+01,  1.402e+01, ...,  9.764e+01,  9.869e+01],
       ...,
       [ 4.097e-01, -2.029e+00, ..., -1.051e+01, -1.130e+01],
       [-1.119e-01, -1.688e+00, ..., -3.442e+00, -4.687e+00]],
      dtype=float32)

使用预先计算好的对数功率 mel 频谱图

>>> S = librosa.feature.melspectrogram(y=y, sr=sr, n_mels=128,
...                                    fmax=8000)
>>> librosa.feature.mfcc(S=librosa.power_to_db(S))
array([[-559.974, -558.449, ..., -411.96 , -420.458],
       [  11.018,   13.046, ...,   76.972,   80.888],
       ...,
       [   2.713,    2.379, ...,    1.464,   -2.835],
       [   2.712,    2.619, ...,    2.209,    0.648]], dtype=float32)

获取更多分量

>>> mfccs = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=40)

可视化 MFCC 序列

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> img = librosa.display.specshow(S, vscale='dBFS[power]',
...                                x_axis='time', y_axis='mel', fmax=8000,
...                                ax=ax[0])
>>> librosa.display.colorbar_db(img)
>>> ax[0].set(title='Mel spectrogram')
>>> ax[0].label_outer()
>>> img = librosa.display.specshow(mfccs, x_axis='time', ax=ax[1])
>>> fig.colorbar(img, ax=[ax[1]])
>>> ax[1].set(title='MFCC')
>>> plt.show()

比较不同的 DCT 基

>>> m_slaney = librosa.feature.mfcc(y=y, sr=sr, dct_type=2)
>>> m_htk = librosa.feature.mfcc(y=y, sr=sr, dct_type=3)
>>> fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True, layout='compressed')
>>> img1 = librosa.display.specshow(m_slaney, x_axis='time', ax=ax[0])
>>> ax[0].set(title='RASTAMAT / Auditory toolbox (dct_type=2)')
>>> fig.colorbar(img, ax=[ax[0]])
>>> img2 = librosa.display.specshow(m_htk, x_axis='time', ax=ax[1])
>>> ax[1].set(title='HTK-style (dct_type=3)')
>>> fig.colorbar(img2, ax=[ax[1]])
>>> plt.show()
