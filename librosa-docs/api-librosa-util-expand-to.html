librosa.util.expand_to

librosa.util.expand_to(x, *, ndim, axes) [源码]

扩展输入数组的维数

参数

参数类型说明
xnp.ndarray

输入数组

ndimint

要扩展到的维数。必须至少为 x.ndim

axesint or slice

要从 x 中保留的目标轴。 其余各轴的长度均为 1。

返回值

返回值类型说明
x_expnp.ndarray
  • x 的扩展版本，满足：

    x_exp[axes] == x x_exp.ndim == ndim

参见

  • np.expand_dims

示例

把一维数组扩展为 (n, 1) 形状

>>> x = np.arange(3)
>>> librosa.util.expand_to(x, ndim=2, axes=0)
array([[0],
   [1],
   [2]])

把一维数组扩展为 (1, n) 形状

>>> librosa.util.expand_to(x, ndim=2, axes=1)
array([[0, 1, 2]])

把二维数组扩展为 (1, n, m, 1) 形状

>>> x = np.vander(np.arange(3))
>>> librosa.util.expand_to(x, ndim=4, axes=[1,2]).shape
(1, 3, 3, 1)
