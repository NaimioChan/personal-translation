librosa.resample

librosa.resample(y, *, orig_sr, target_sr, res_type='soxr_hq', fix=True, scale=False, axis=-1, **kwargs) [源码]

把时间序列从 orig_sr 重采样到 target_sr

默认使用高质量方法（soxr_hq）做带限 sinc 插值。下面列出的其他 res_type 取值在速度与质量之间提供不同的取舍。

参数

参数类型说明
ynp.ndarray [shape=(…, n, …)]

音频时间序列，沿指定轴有 n 个采样点。

orig_srnumber > 0 [scalar]

y 的原始采样率

target_srnumber > 0 [scalar]

目标采样率

res_typestr (default: soxr_hq)

重采样类型

  • ‘soxr_vhq’、‘soxr_hq’、‘soxr_mq’ 或 ‘soxr_lq’：

    soxr 的极高、高、中、低质量基于 FFT 的带限插值。 'soxr_hq' 是 soxr 的默认设置。

  • ‘soxr_qq’：

    soxr 快速三次插值（非常快，但非带限）

  • ‘kaiser_best’：

    resampy 高质量模式

  • ‘kaiser_fast’：

    resampy 更快的方法

  • ‘fft’ 或 ‘scipy’：

    scipy.signal.resample 傅里叶方法。

  • ‘polyphase’：

    scipy.signal.resample_poly 多相滤波。（快）

  • ‘linear’：

    samplerate 线性插值。（非常快，但非带限）

  • ‘zero_order_hold’：

    samplerate 在采样点之间重复上一个值。（非常快，但非带限）

  • ‘sinc_best’、‘sinc_medium’ 或 ‘sinc_fastest’：

    samplerate 的高、中、低质量带限 sinc 插值。

注意

并非所有选项都是带限插值器。若使用 soxr_qq、polyphase、linear 或 zero_order_hold，需要留意可能的混叠效应。

注意

samplerate 与 resampy 不会随 librosa 一并安装。 要使用 samplerate 或 resampy，需要手动安装：

$ pip install samplerate
$ pip install resampy

注意

使用 res_type='polyphase' 时，仅支持整数采样率。

fixbool

调整重采样后信号的长度，使其恰好为 ceil(target_sr * len(y) / orig_sr)

scalebool

缩放重采样后的信号，使 y 与 y_hat 的总能量大致相等。

axisint

要重采样的目标轴。默认为最后一个轴。

**kwargsadditional keyword arguments

若 fix==True，传给 librosa.util.fix_length 的附加关键字参数。

返回值

返回值类型说明
y_hatnp.ndarray [shape=(…, n * target_sr / orig_sr, …)]

y 沿目标轴从 orig_sr 重采样到 target_sr 的结果

异常

异常说明
ParameterError

若 res_type='polyphase' 且 orig_sr 或 target_sr 不全是整数值。

参见

  • librosa.util.fix_length
  • scipy.signal.resample
  • resampy
  • samplerate.converters.resample
  • soxr.resample

说明

此函数在缓存级别 20 上缓存。

示例

从 22 KHz 降采样到 8 KHz

>>> y, sr = librosa.loadx('trumpet', sr=22050)
>>> y_8k = librosa.resample(y, orig_sr=sr, target_sr=8000)
>>> y.shape, y_8k.shape
((117601,), (42668,))
