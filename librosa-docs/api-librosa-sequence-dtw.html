librosa.sequence.dtw

librosa.sequence.dtw(X=None, Y=None, *, C=None, metric='euclidean', step_sizes_sigma=None, weights_add=None, weights_mul=None, subseq=False, backtrack=True, global_constraints=False, band_rad=0.25, return_steps=False) [源码]

动态时间规整（DTW）。

该函数对两个序列执行 DTW 与路径回溯。 我们沿用 [1] 中描述的命名与算法思路。

[1] Meinard Mueller Fundamentals of Music Processing — Audio, Analysis, Algorithms, Applications Springer Verlag, ISBN: 978-3-319-21944-8, 2015.

参数

参数类型说明
Xnp.ndarray [shape=(…, K, N)]

音频特征矩阵（如色度特征）

如果 X 的维数超过二维（例如多声道输入），计算与 Y 的距离时会使用全部前导维度。

Ynp.ndarray [shape=(…, K, M)]

音频特征矩阵（如色度特征）

Cnp.ndarray [shape=(N, M)]

预先计算的距离矩阵。若提供，则不得再提供 X 与 Y， 并且会忽略 metric。

metricstr

代价函数的标识符，见 scipy.spatial.distance.cdist() 的文档

step_sizes_sigmanp.ndarray [shape=[n, 2]]

指定 DTW 允许使用的步长。

weights_addnp.ndarray [shape=[n, ]]

用于惩罚特定步长的加性权重。

weights_mulnp.ndarray [shape=[n, ]]

用于惩罚特定步长的乘性权重。

subseqbool

启用子序列 DTW，例如用于检索任务。

backtrackbool

在累积代价矩阵中启用回溯。

global_constraintsbool

对代价矩阵 C 施加全局约束（Sakoe-Chiba 带）。

band_radfloat

Sakoe-Chiba 带的半径（宽度的一半）为 int(radius*min(C.shape))。

return_stepsbool

若为真，函数会额外返回 steps，即步长矩阵， 其中包含代价累积步骤中所用步长的索引。

返回值

返回值类型说明
Dnp.ndarray [shape=(N, M)]

累积代价矩阵。 最终索引位置 D[-1, -1] 处的值为总对齐代价。

wpnp.ndarray [shape=(L, 2)]

带索引对的规整路径。 数组的每一行包含一个索引对 (n, m)。 仅在 backtrack 为 True 时返回。 注意，规整路径的长度 L 未必与输入数据的长度一致， 取决于 step_sizes_sigma 的取值与 subseq。

stepsnp.ndarray [shape=(N, M)]

步长矩阵，包含代价累积步骤中所用步长的索引。 仅在 return_steps 为 True 时返回。

异常

异常说明
ParameterError

如果进行对角匹配而 Y 比 X 短，或提供了 X、Y 与 C 的不兼容组合。

如果输入维度不兼容。

如果代价矩阵含有 NaN 值。

示例

>>> import numpy as np
>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('brahms', offset=10, duration=15)
>>> X = librosa.feature.chroma_cens(y=y, sr=sr)
>>> noise = np.random.rand(X.shape[0], 200)
>>> Y = np.concatenate((noise, noise, X, noise), axis=1)
>>> D, wp = librosa.sequence.dtw(X, Y, subseq=True)
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> img = librosa.display.specshow(D, x_axis='frames', y_axis='frames',
...                                ax=ax[0])
>>> hl = librosa.display.highlight(ax=ax[0])
>>> ax[0].set(title='DTW cost', xlabel='Noisy sequence', ylabel='Target')
>>> ax[0].plot(wp[:, 1], wp[:, 0], label='Optimal path', path_effects=hl)
>>> ax[0].legend()
>>> fig.colorbar(img, ax=ax[0])
>>> ax[1].plot(D[-1, :] / wp.shape[0])
>>> ax[1].set(xlim=[0, Y.shape[1]], ylim=[0, 2],
...           title='Matching cost function')
