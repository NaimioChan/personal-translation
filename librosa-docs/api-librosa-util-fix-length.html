librosa.util.fix_length

librosa.util.fix_length(data, *, size, axis=-1, **kwargs) [源码]

沿目标轴把数组 data 的长度修正为恰好 size。

若 data.shape[axis] < n，则按提供的 kwargs 补零。 默认情况下，data 在末尾补零。

参数

参数类型说明
datanp.ndarray

待调整长度的数组

sizeint >= 0 [scalar]

数组的期望长度

axisint, <= data.ndim

修正长度所沿的轴

**kwargsadditional keyword arguments

传给 np.pad 的参数

返回值

返回值类型说明
data_fixednp.ndarray [shape=data.shape]

沿指定轴裁剪或补零到长度 size 后的 data。

参见

  • numpy.pad

示例

>>> y = np.arange(7)
>>> # 默认：补零
>>> librosa.util.fix_length(y, size=10)
array([0, 1, 2, 3, 4, 5, 6, 0, 0, 0])
>>> # 裁剪到期望长度
>>> librosa.util.fix_length(y, size=5)
array([0, 1, 2, 3, 4])
>>> # 使用边缘填充而非补零
>>> librosa.util.fix_length(y, size=10, mode='edge')
array([0, 1, 2, 3, 4, 5, 6, 6, 6, 6])
