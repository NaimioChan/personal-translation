librosa.segment.path_enhance

librosa.segment.path_enhance(R, n, *, window='hann', max_ratio=2.0, min_ratio=None, n_filters=7, zero_mean=False, clip=True, **kwargs) [源码]

针对自相似矩阵与交叉相似矩阵的多角度路径增强。

此函数把多个对角线平滑滤波器与自相似（或递归）矩阵 R 做卷积，再按逐元素最大值聚合结果。

严格地说，输出是矩阵 R_smooth，满足：

R_smooth[i, j] = max_theta (R * filter_theta)[i, j]

其中 * 表示二维卷积，filter_theta 是方位角为 theta 的平滑滤波器。

其目的是在速度变化时对自相似矩阵做连贯的时间平滑。

平滑滤波器在 min_ratio 与 max_ratio 之间按均匀间隔的方向生成。

此函数受 [1] 的多角度路径增强启发，不同之处在于它是在相似度矩阵空间中建模速度差异，而非在生成自相似矩阵之前重采样底层特征。

[1] Müller, Meinard and Frank Kurth. “Enhancing similarity matrices for music audio analysis.” 2006 IEEE International Conference on Acoustics Speech and Signal Processing Proceedings. Vol. 5. IEEE, 2006.

注意

若使用 recurrence_matrix 构造输入相似度矩阵，务必设置 self=True 以包含主对角线。否则对角线将被抑制，很可能产生不连续，污染平滑滤波器的响应。

参数

参数类型说明
Rnp.ndarray

要平滑的自相似或交叉相似矩阵。 注意：不支持稀疏输入。

若递归矩阵为多维，如 shape=(c, n, n)， 则对每个前导通道分别独立做增强。

nint > 0

平滑滤波器的长度

windowwindow specification

所用的平滑滤波器类型。窗规格格式的更多信息见 filters.get_window。

max_ratiofloat > 0

支持的最大速度比

min_ratiofloat > 0

支持的最小速度比。 若未提供，默认为 1/max_ratio

n_filtersint >= 1

所用的不同平滑滤波器数量，在 min_ratio 与 max_ratio 之间均匀分布。

若 min_ratio = 1/max_ratio（默认），使用奇数个滤波器可确保包含主对角线（ratio=1）。

zero_meanbool

默认情况下，平滑滤波器非负且和为 1（即平均滤波器）。

若 zero_mean=True，则从滤波器的非对角坐标减去一个常数，使其和为零。这主要用于抑制块而增强对角线。

clipbool

若为 True，平滑后的相似度矩阵将在 0 处截断，不含负值。

**kwargsadditional keyword arguments

传给 scipy.ndimage.convolve 的附加参数

返回值

返回值类型说明
R_smoothnp.ndarray, shape=R.shape

平滑后的自相似或交叉相似矩阵

示例

用 51 帧的对角平滑滤波器增强递归矩阵中的路径

>>> y, sr = librosa.loadx('nutcracker')
>>> hop_length = 2048
>>> chroma = librosa.feature.chroma_cqt(y=y, sr=sr, hop_length=hop_length)
>>> chroma_stack = librosa.feature.stack_memory(chroma, n_steps=10, delay=3)
>>> rec = librosa.segment.recurrence_matrix(chroma_stack, mode='affinity', self=True)
>>> rec_smooth = librosa.segment.path_enhance(rec, 51, window='hann', n_filters=7)

绘制平滑前后的递归矩阵

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(ncols=2, sharex=True, sharey=True)
>>> img = librosa.display.specshow(rec, x_axis='s', y_axis='s',
...                          hop_length=hop_length, ax=ax[0])
>>> ax[0].set(title='Unfiltered recurrence')
>>> imgpe = librosa.display.specshow(rec_smooth, x_axis='s', y_axis='s',
...                          hop_length=hop_length, ax=ax[1])
>>> ax[1].set(title='Multi-angle enhanced recurrence')
>>> ax[1].label_outer()
>>> fig.colorbar(img, ax=ax[0], orientation='horizontal')
>>> fig.colorbar(imgpe, ax=ax[1], orientation='horizontal')
