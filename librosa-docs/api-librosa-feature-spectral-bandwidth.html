librosa.feature.spectral_bandwidth

librosa.feature.spectral_bandwidth(*, y=None, sr=22050, S=None, n_fft=2048, hop_length=512, win_length=None, window='hann', center=True, pad_mode='constant', freq=None, centroid=None, norm=True, p=2) [源码]

计算 p 阶频谱带宽。

帧 t 的频谱带宽 [1] 按下式 计算：

(sum_k S[k, t] * (freq[k, t] - centroid[t])**p)**(1/p)

[1] Klapuri, A., & Davy, M. (Eds.). (2007). Signal processing methods for music transcription, chapter 5. Springer Science & Business Media.

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的音频采样率

Snp.ndarray [shape=(…, d, t)] or None

（可选）频谱图幅度

n_fftint > 0 [scalar]

FFT 帧长度

hop_lengthint > 0 [scalar]

STFT 的跳距。详见 librosa.stft。

win_lengthint <= n_fft [scalar]

每一帧音频都用 window() 加窗。 窗的长度为 win_length，随后补零 至 n_fft 长度。 若未指定，默认为 win_length = n_fft。

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

  • 窗的规格（字符串、元组或数值）； 见 scipy.signal.get_window

  • 窗函数，例如 scipy.signal.windows.hann

  • 长度为 n_fft 的向量或数组

centerbool

  • 若为 True，则对信号 y 进行填充，使帧 t 以 y[t * hop_length] 为中心。

  • 若为 False，则帧 t 起始于 y[t * hop_length]

pad_modestr

若 center=True，在信号边缘使用的填充模式。 默认情况下，STFT 使用零填充。

freqNone or np.ndarray [shape=(d,) or shape=(…, d, t)]

频谱图频格的中心频率。 若为 None，则使用 FFT 频格的中心频率。 否则，可以是一个含 d 个中心频率的数组， 也可以是由 librosa.reassigned_spectrogram 构建的中心频率矩阵

centroidNone or np.ndarray [shape=(…, 1, t)]

预先计算好的质心频率

normbool

按帧归一化频谱能量（总和为 1）

pfloat > 0

对频谱质心偏差取幂的幂次。

返回值

返回值类型说明
bandwidthnp.ndarray [shape=(…, 1, t)]

每一帧的频率带宽

示例

由时间序列输入

>>> y, sr = librosa.loadx('trumpet')
>>> spec_bw = librosa.feature.spectral_bandwidth(y=y, sr=sr)
>>> spec_bw
array([[1273.836, 1228.873, ..., 2952.357, 3013.68 ]])

由频谱图输入

>>> S, phase = librosa.magphase(librosa.stft(y=y))
>>> librosa.feature.spectral_bandwidth(S=S)
array([[1273.836, 1228.873, ..., 2952.357, 3013.68 ]])

使用可变的频格中心频率

>>> freqs, times, D = librosa.reassigned_spectrogram(y, fill_nan=True)
>>> librosa.feature.spectral_bandwidth(S=np.abs(D), freq=freqs)
array([[1274.637, 1228.786, ..., 2952.4  , 3013.735]])

绘制结果

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> times = librosa.times_like(spec_bw)
>>> centroid = librosa.feature.spectral_centroid(S=S)
>>> ax[0].semilogy(times, spec_bw[0], label='Spectral bandwidth')
>>> ax[0].set(ylabel='Hz', xticks=[], xlim=[times.min(), times.max()])
>>> ax[0].legend()
>>> ax[0].label_outer()
>>> librosa.display.specshow(S, vscale='dBFS',
...                          y_axis='log', x_axis='time', ax=ax[1])
>>> ax[1].set(title='log Power spectrogram')
>>> ax[1].fill_between(times, np.maximum(0, centroid[0] - spec_bw[0]),
...                 np.minimum(centroid[0] + spec_bw[0], sr/2),
...                 alpha=0.5, label='Centroid +- bandwidth')
>>> hl = librosa.display.highlight(ax=ax[1], color='k', linewidth=3, alpha=0.5)
>>> ax[1].plot(times, centroid[0], label='Spectral centroid', color='w', path_effects=hl)
>>> ax[1].legend(loc='lower right')
