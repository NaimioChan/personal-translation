librosa.display.colorbar_phase

librosa.display.colorbar_phase(im, *, numticks=9, ax=None, fig=None, **kwargs) [源码]

为表示以弧度计的相位数据的图像附加颜色条。

颜色条将在 π 的有理数倍处显示刻度。

参数

参数类型说明
immatplotlib.cm.ScalarMappable

要附加颜色条的图像。 通常是 specshow 返回的 matplotlib.image.AxesImage 或 matplotlib.collections.QuadMesh。

numticksint > 0

颜色条上显示的刻度数。 默认是 9，对应 π/4 的倍数。

axmatplotlib.axes.Axes or None

要附加颜色条的坐标轴。 若为 None，颜色条附加到 im 所在的坐标轴。

figmatplotlib.figure.Figure, SubFigure, or None

要附加颜色条的图。 若为 None，颜色条附加到 im 所在的图。

**kwargs

传给 fig.colorbar 的其他关键字参数。

返回值

返回值类型说明
cbarmatplotlib.colorbar.Colorbar

创建的颜色条对象。

参见

  • specshow
  • colorbar_db
  • matplotlib.colorbar.Colorbar

示例

为相位频谱图附加颜色条

>>> import matplotlib.pyplot as plt
>>> import librosa
>>> y, sr = librosa.loadx('trumpet')
>>> S = librosa.stft(y)
>>> fig, ax = plt.subplots()
>>> im = librosa.display.specshow(S, ax=ax, y_axis='log', x_axis='time', vscale='phase')
>>> librosa.display.colorbar_phase(im)
>>> plt.show()

为其中一个子图坐标轴附加颜色条，并以 π/3 的倍数显示。

>>> fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
>>> im_mag = librosa.display.specshow(S, ax=ax[0], y_axis='log', x_axis='time', vscale='dBFS')
>>> cbar = librosa.display.colorbar_db(im_mag, ax=ax[0], label='dBFS')
>>> im_ph = librosa.display.specshow(S, ax=ax[1], y_axis='log', x_axis='time', vscale='dphase')
>>> cbar = librosa.display.colorbar_phase(im_ph, ax=ax[1], numticks=7)
>>> ax[0].label_outer()
>>> plt.show()
