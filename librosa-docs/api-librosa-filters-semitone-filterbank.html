librosa.filters.semitone_filterbank

librosa.filters.semitone_filterbank(*, center_freqs=None, tuning=0.0, sample_rates=None, flayout='ba', **kwargs) [源码]

在指定的中心频率和采样率上构造多速率 IIR 带通滤波器组。

默认情况下，这些中心频率取为三角钢琴键盘的 88 个基频，采用 A440 调音标准，即中央 C 上方的 A 音设为 440 Hz。中心频率按十二平均律调音，因此按 2**(1/12) 的比率呈指数增长，也就是每八度十二个音。

用户可以在保持十二平均律的前提下修改 A440 调音。A440 目前是音乐行业的国际标准（ISO 16），但有些乐团按 A441-A445 调音，巴洛克音乐家则按 A415 调音。

详情见 [1]。

[1] Müller, Meinard. “Information Retrieval for Music and Motion.” Springer Verlag. 2007.

参数

参数类型说明
center_freqsnp.ndarray [shape=(n,), dtype=float]

各滤波核的中心频率。 同时决定滤波器组中滤波器的数量。

tuningfloat [scalar]

相对于 A440 的调音偏差，以半音（十二平均律中八度的 1/12）的小数部分表示。

sample_ratesnp.ndarray [shape=(n,), dtype=float]

多速率滤波器组中各滤波器的采样率。

flayoutstr

  • 若为 ba，则用标准差分方程配合 scipy.signal.filtfilt 做滤波。 对高阶滤波器可能不稳定。

  • 若为 sos，则用一系列二阶滤波器配合 scipy.signal.sosfiltfilt 做滤波。 可把高阶滤波器的数值精度误差降到最低，但速度较慢。

**kwargsadditional keyword arguments

传给私有函数 _multirate_fb() 的附加参数。

返回值

返回值类型说明
filterbanklist [shape=(n,), dtype=float]

列表的每一项包含单个滤波器的滤波系数。

fb_sample_ratesnp.ndarray [shape=(n,), dtype=float]

每个滤波器的采样率。

示例

>>> import matplotlib.pyplot as plt
>>> import numpy as np
>>> import scipy.signal
>>> semitone_filterbank, sample_rates = librosa.filters.semitone_filterbank(
...     center_freqs=librosa.midi_to_hz(np.arange(60, 72)),
...     sample_rates=np.repeat(4410.0, 12),
...     flayout='sos'
...     )
>>> magnitudes = []
>>> for cur_sr, cur_filter in zip(sample_rates, semitone_filterbank):
...     w, h = scipy.signal.sosfreqz(cur_filter,fs=cur_sr, worN=1025)
...     magnitudes.append(20 * np.log10(np.abs(h)))
>>> fig, ax = plt.subplots(figsize=(12,6))
>>> img = librosa.display.specshow(
...     np.array(magnitudes),
...     x_axis="hz",
...     sr=4410,
...     y_coords=librosa.midi_to_hz(np.arange(60, 72)),
...     vmin=-60,
...     vmax=3,
...     ax=ax
...     )
>>> librosa.display.colorbar_db(img)
>>> ax.set(
...     xlim=[200, 600],
...     yticks=librosa.midi_to_hz(np.arange(60, 72)),
...     title='Magnitude Responses of the Pitch Filterbank',
...     xlabel='Frequency (Hz)',
...     ylabel='Semitone filter center frequency (Hz)'
... )
