librosa.midi_to_svara_h

librosa.midi_to_svara_h(midi, *, Sa, abbr=True, octave=True, unicode=True) [源码]

把 MIDI 编号转换为印度斯坦 svara

非有限的 MIDI 编号（例如 NaN、inf）将返回空字符串。

参数

参数类型说明
midinumeric or np.ndarray

要转换的 MIDI 编号

Sanumber > 0

参照 Sa 的 MIDI 编号。

abbrbool

若为 True（默认），返回缩写名称（‘S’、‘r’、‘R’、‘g’、‘G’、……）

若为 False，返回长格式名称（‘Sa’、‘re’、‘Re’、‘ga’、‘Ga’、……）

octavebool

若为 True，在相邻八度的 svara 上添加上点或下点。

若为 False，忽略八度高度信息。

unicodebool

若为 True，使用 Unicode 符号标注八度信息。

若为 False，八度标注使用低位 ASCII（’ 与 ,）。

仅在 octave=True 时生效。

返回值

返回值类型说明
svarastr or np.ndarray of str

给定 MIDI 编号所对应的 svara

参见

  • hz_to_svara_h
  • note_to_svara_h
  • midi_to_svara_c
  • midi_to_note

示例

转换单个 MIDI 编号：

>>> librosa.midi_to_svara_h(65, Sa=60)
'm'

Sa 位于 MIDI 编号 60 时的前三个 svara：

>>> librosa.midi_to_svara_h([60, 61, 62], Sa=60)
array(['S', 'r', 'R'], dtype='<U1')

若 Sa=67，则 MIDI 60–62 位于低一个八度：

>>> librosa.midi_to_svara_h([60, 61, 62], Sa=67)
array(['ṃ', 'Ṃ', 'P̣'], dtype='<U2')

或者不使用 Unicode 标注：

>>> librosa.midi_to_svara_h([60, 61, 62], Sa=67, unicode=False)
array(['m,', 'M,', 'P,'], dtype='<U2')

或者升高一个八度，Sa=60，且使用非缩写音名

>>> librosa.midi_to_svara_h([72, 73, 74], Sa=60, abbr=False)
array(['Ṡa', 'ṙe', 'Ṙe'], dtype='<U3')
