librosa.feature.tempo

librosa.feature.tempo(*, y=None, sr=22050, onset_envelope=None, tg=None, hop_length=512, start_bpm=120, std_bpm=1.0, ac_size=8.0, max_tempo=320.0, aggregate=<function mean>, prior=None) [源码]

估计速度（每分钟拍数）

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频时间序列。支持多声道。

srnumber > 0 [scalar]

时间序列的采样率

onset_envelopenp.ndarray [shape=(…, n)]

预先计算好的起始强度包络

tgnp.ndarray

预先计算好的速度图。若提供，则忽略 y 与 onset_envelope，并由速度图的形状 推断 win_length。

hop_lengthint > 0 [scalar]

时间序列的跳距

start_bpmfloat [scalar]

BPM 的初始猜测

std_bpmfloat > 0 [scalar]

速度分布的标准差

ac_sizefloat > 0 [scalar]

自相关窗的长度（以秒计）

max_tempofloat > 0 [scalar, optional]

若提供，则只估计低于此阈值的速度

aggregatecallable [optional]

用于估计全局速度的聚合函数。 若为 None，则对每一帧独立估计速度。

priorscipy.stats.rv_continuous [optional]

速度（单位为每分钟拍数）的先验分布。 默认使用伪对数正态先验。 若提供，则忽略 start_bpm 与 std_bpm。

返回值

返回值类型说明
temponp.ndarray

估计的速度（每分钟拍数）。 若输入为多声道，则为每个声道提供一个速度估计。

参见

  • librosa.onset.onset_strength
  • librosa.feature.tempogram

说明

本函数在缓存级别 30 上缓存。

示例

>>> # 估计静态速度
>>> y, sr = librosa.loadx('nutcracker', duration=30)
>>> onset_env = librosa.onset.onset_strength(y=y, sr=sr)
>>> tempo = librosa.feature.tempo(onset_envelope=onset_env, sr=sr)
>>> tempo
array([143.555])
>>> # 或者用均匀先验估计静态速度
>>> import scipy.stats
>>> prior = scipy.stats.uniform(30, 300)  # 在 30-300 BPM 上均匀
>>> utempo = librosa.feature.tempo(onset_envelope=onset_env, sr=sr, prior=prior)
>>> utempo
array([161.499])
>>> # 或者估计动态速度
>>> dtempo = librosa.feature.tempo(onset_envelope=onset_env, sr=sr,
...                                aggregate=None)
>>> dtempo
array([ 89.103,  89.103,  89.103, ..., 123.047, 123.047, 123.047])
>>> # 使用合适的对数正态先验估计动态速度
>>> prior_lognorm = scipy.stats.lognorm(loc=np.log(120), scale=120, s=1)
>>> dtempo_lognorm = librosa.feature.tempo(onset_envelope=onset_env, sr=sr,
...                                        aggregate=None,
...                                        prior=prior_lognorm)
>>> dtempo_lognorm
array([ 89.103,  89.103,  89.103, ..., 123.047, 123.047, 123.047])

把估计的速度与起始点自相关画在一起

>>> import matplotlib.pyplot as plt
>>> # 转换为标量
>>> tempo = tempo.item()
>>> utempo = utempo.item()
>>> # 计算 2 秒加窗自相关
>>> hop_length = 512
>>> ac = librosa.autocorrelate(onset_env, max_size=2 * sr // hop_length)
>>> freqs = librosa.tempo_frequencies(len(ac), sr=sr,
...                                   hop_length=hop_length)
>>> # 在 BPM 轴上绘制。跳过第一个（0 滞后）频格。
>>> fig, ax = plt.subplots()
>>> ax.semilogx(freqs[1:], librosa.util.normalize(ac)[1:],
...              label='Onset autocorrelation', base=2)
>>> ax.axvline(tempo, 0, 1, alpha=0.75, linestyle='--', color='r',
...             label='Tempo (default prior): {:.2f} BPM'.format(tempo))
>>> ax.axvline(utempo, 0, 1, alpha=0.75, linestyle=':', color='g',
...             label='Tempo (uniform prior): {:.2f} BPM'.format(utempo))
>>> ax.set(xlabel='Tempo (BPM)', title='Static tempo estimation')
>>> ax.grid(True)
>>> ax.legend()
>>> plt.show()

在速度图上绘制动态速度估计

>>> fig, ax = plt.subplots()
>>> tg = librosa.feature.tempogram(onset_envelope=onset_env, sr=sr,
...                                hop_length=hop_length)
>>> librosa.display.specshow(tg, x_axis='time', y_axis='tempo', cmap='magma', ax=ax)
>>> hl = librosa.display.highlight(ax=ax, alpha=.85, linewidth=3, color='k')
>>> ax.plot(librosa.times_like(dtempo), dtempo, linewidth=2,
...         path_effects=hl, label='Tempo estimate (default prior)')
>>> ax.plot(librosa.times_like(dtempo_lognorm), dtempo_lognorm, color='C0',
...         linestyle='--', linewidth=2,
...         path_effects=hl, label='Tempo estimate (lognorm prior)')
>>> ax.set(title='Dynamic tempo estimation')
>>> ax.legend()
>>> plt.show()
