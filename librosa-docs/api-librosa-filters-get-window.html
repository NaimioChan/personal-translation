librosa.filters.get_window

librosa.filters.get_window(window, Nx, *, fftbins=True) [源码]

计算窗函数。

这是对 scipy.signal.get_window 的封装，额外支持可调用对象或预先算好的窗。

参数

参数类型说明
windowstr, tuple, number, callable, or list-like

窗的规格：

  • 若为字符串，则是窗函数名（例如 ‘hann’）

  • 若为元组，则是窗函数名及其参数 （例如 (‘kaiser’, 4.0)）

  • 若为数值，则视为 ‘kaiser’ 窗的 beta 参数， 与 scipy.signal.get_window 中的处理一致。

  • 若为可调用对象，则是一个接受一个整数参数（窗长）的函数

  • 若为类列表对象，则是长度恰为 Nx 的预先算好的窗

Nxint > 0

窗的长度

fftbinsbool, optional

若为 True（默认），生成供 FFT 使用的周期窗 若为 False，生成用于滤波器设计的对称窗。

返回值

返回值类型说明
get_windownp.ndarray

长度为 Nx、类型为 window 的窗

异常

异常说明
ParameterError

若 window 以长度不等于 n_fft 的向量形式给出， 或规格有误。

参见

  • scipy.signal.get_window

说明

本函数在层级 10 缓存。
