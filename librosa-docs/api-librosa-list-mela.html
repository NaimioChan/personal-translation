librosa.list_mela

librosa.list_mela() [源码]

按名称和索引列出 melakarta raga。

melakarta raga 名称转写自 [1]，只有第 45 号 （subhapanthuvarali）例外。

[1] Bhagyalekshmy, S. (1990). Ragas in Carnatic music. South Asia Books.

返回值

返回值类型说明
mela_mapdict

把 melakarta raga 名称映射到索引（1，2，……，72）的字典

参见

  • mela_to_degrees
  • mela_to_svara
  • list_thaat

示例

>>> librosa.list_mela()
{'kanakangi': 1,
 'ratnangi': 2,
 'ganamurthi': 3,
 'vanaspathi': 4,
 ...}
