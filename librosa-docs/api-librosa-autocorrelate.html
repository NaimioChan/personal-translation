librosa.autocorrelate

librosa.autocorrelate(y, *, max_size=None, axis=-1) [源码]

有界延迟自相关

参数

参数类型说明
ynp.ndarray

要求自相关的数组

max_sizeint > 0 or None

最大相关延迟。 若不指定，默认为 y.shape[axis]（无界）

axisint

沿哪个轴求自相关。 默认取最后一个轴（-1）。

返回值

返回值类型说明
znp.ndarray

沿指定轴截断的自相关 y*y。 若指定了 max_size，则 z.shape[axis] 被限制在 max_size 以内。

说明

该函数在级别 20 上缓存。

示例

计算 y 的完整自相关

>>> y, sr = librosa.loadx('trumpet')
>>> librosa.autocorrelate(y)
array([ 6.899e+02,  6.236e+02, ...,  3.710e-08, -1.796e-08])

计算最长 4 秒的起始强度自相关

>>> import matplotlib.pyplot as plt
>>> odf = librosa.onset.onset_strength(y=y, sr=sr, hop_length=512)
>>> ac = librosa.autocorrelate(odf, max_size=4 * sr // 512)
>>> fig, ax = plt.subplots()
>>> ax.plot(ac)
>>> ax.set(title='Auto-correlation', xlabel='Lag (frames)')
