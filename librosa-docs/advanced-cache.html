缓存

本节介绍 librosa 的函数缓存。它让你可以跨会话保存并复用中间计算结果。

启用缓存

缓存默认关闭。要启用缓存，必须在加载 librosa 之前设置环境变量 LIBROSA_CACHE_DIR。 可以在启动 python 解释器之前于命令行中设置：

$ export LIBROSA_CACHE_DIR=/tmp/librosa_cache
$ ipython

或者在 python 中、导入 librosa 之前设置：

>>> import os
>>> os.environ['LIBROSA_CACHE_DIR'] = '/tmp/librosa_cache'
>>> import librosa

警告

缓存不实现任何淘汰策略。因此若不清理，它在磁盘上可能无限增长。 要直接清空缓存，调用：

>>> librosa.cache.clear()

缓存配置

缓存基于 joblib.Memory 实现。 默认配置可通过设置以下环境变量覆盖

  • LIBROSA_CACHE_DIR ：缓存目录在磁盘上的路径

  • LIBROSA_CACHE_MMAP ：可选的内存映射模式 {None, ‘r+’, ‘r’, ‘w+’, ‘c’}

  • LIBROSA_CACHE_COMPRESS ：是否压缩磁盘上数据的标志 {0, 1}

  • LIBROSA_CACHE_VERBOSE ：控制显示多少调试信息 {int, non-negative}

  • LIBROSA_CACHE_LEVEL ：控制缓存层级：该值越大，缓存的数据越多 {int}

这些参数的详细说明请参阅 joblib.Memory 文档。

自 0.7 起，librosa 的缓存是对 joblib.Memory 对象的包装（并非扩展）。 该 memory 对象可通过 librosa.cache.memory 直接访问。

缓存层级

缓存层级的运作方式与日志级别类似。 LIBROSA_CACHE_LEVEL 取值较小时，只缓存最重要（最常用）的数据。 随着缓存层级提高，被缓存的函数类别越多。 因此应用程序可能运行得更快，代价是占用更多磁盘空间。

各缓存层级如下：

  • 10：滤波基，与音频数据无关（mel、chroma、constant-q）

  • 20：低层特征（cqt、stft、zero-crossings 等）

  • 30：高层特征（tempo、beats、decomposition、recurrence 等）

  • 40：后处理（delta、stack_memory、normalize、sync）

默认缓存层级为 10。
