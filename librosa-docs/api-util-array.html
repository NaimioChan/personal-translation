数组形状操作

函数说明

frame

把数据数组切分为（重叠的）帧。

pad_center

沿目标轴把数组填充到目标长度。

expand_to

用这样的方式扩展输入数组的维度：

fix_length

沿目标轴把数组 data 的长度固定为恰好 size。

fix_frames

把帧列表约束在 [x_min, x_max] 范围内

index_to_slice

由索引数组生成切片数组。

stack

沿目标轴堆叠一个或多个数组。

shear

按给定因子剪切数组（或矩阵）。
