librosa.feature.melspectrogram

librosa.feature.melspectrogram(*, y=None, sr=22050, S=None, n_fft=2048, hop_length=512, win_length=None, window='hann', center=True, pad_mode='constant', power=2.0, **kwargs) [源码]

计算 mel 标度的频谱图。

若提供频谱图输入 S，则直接通过 mel_f.dot(S) 把它映射到 mel 基上。

若提供时间序列输入 y, sr，则先计算其幅度频谱图 S，再通过 mel_f.dot(S**power) 映射到 mel 标度。

默认情况下，power=2 作用于功率谱。

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

Snp.ndarray [shape=(…, d, t)]

频谱图

n_fftint > 0 [scalar]

FFT 帧长度

hop_lengthint > 0 [scalar]

相邻帧之间的采样点数。 见 librosa.stft

win_lengthint <= n_fft [scalar]

每一帧音频都用 window() 加窗。 窗的长度为 win_length，随后补零 至 n_fft 长度。 若未指定，默认为 win_length = n_fft。

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

  • 窗的规格（字符串、元组或数值）； 见 scipy.signal.get_window

  • 窗函数，例如 scipy.signal.windows.hann

  • 长度为 n_fft 的向量或数组

centerbool

  • 若为 True，则对信号 y 进行填充，使帧 t 以 y[t * hop_length] 为中心。

  • 若为 False，则帧 t 起始于 y[t * hop_length]

pad_modestr

若 center=True，在信号边缘使用的填充模式。 默认情况下，STFT 使用零填充。

powerfloat > 0 [scalar]

幅度 mel 频谱图的指数。 例如，1 表示能量，2 表示功率，等等。

**kwargs

mel 滤波器组参数的额外关键字参数

n_melsint > 0 [scalar]

要生成的 mel 频带数

fminfloat >= 0 [scalar]

最低频率（Hz）

fmaxfloat >= 0 [scalar]

最高频率（Hz）。 若为 None，使用 fmax = sr / 2.0

htkbool [scalar]

使用 HTK 公式代替 Slaney 公式

norm{None, ‘slaney’, or number} [scalar]

若为 ‘slaney’，把三角形 mel 权重除以 mel 频带的宽度（面积归一化）。 若为数值，则用 librosa.util.normalize 把每个滤波器归一化 为单位 l_p 范数。受支持的 norm 取值（包括 +-np.inf）的完整 说明见 librosa.util.normalize。 否则保留所有三角形的峰值为 1.0

dtypenp.dtype

输出基矩阵的数据类型。 默认使用 32 位（单精度）浮点数。

示例

>>> y, sr = librosa.loadx('trumpet')
>>> librosa.feature.melspectrogram(y=y, sr=sr)
array([[3.837e-06, 1.451e-06, ..., 8.352e-14, 1.296e-11],
       [2.213e-05, 7.866e-06, ..., 8.532e-14, 1.329e-11],
       ...,
       [1.115e-05, 5.192e-06, ..., 3.675e-08, 2.470e-08],
       [6.473e-07, 4.402e-07, ..., 1.794e-08, 2.908e-08]],
      dtype=float32)

使用预先计算好的功率谱会得到相同的结果：

>>> D = np.abs(librosa.stft(y))**2
>>> S = librosa.feature.melspectrogram(S=D, sr=sr)

显示 mel 频率频谱图系数，并为 mel 滤波器组的构建传入自定义 参数（默认为 fmax=sr/2）：

>>> # 把参数传给 mel 滤波器
>>> S = librosa.feature.melspectrogram(y=y, sr=sr, n_mels=128,
...                                     fmax=8000)
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots()
>>> S_dB = librosa.power_to_db(S, ref=np.max)
>>> img = librosa.display.specshow(S_dB, x_axis='time',
...                          y_axis='mel', sr=sr,
...                          fmax=8000, ax=ax)
>>> librosa.display.colorbar_db(img)
>>> ax.set(title='Mel-frequency spectrogram')
