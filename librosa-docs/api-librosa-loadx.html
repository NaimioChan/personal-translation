librosa.loadx

librosa.loadx(key, *, hq=None, **kwargs) [源码]

按键名加载示例音频文件。

它是对 librosa.util.example 的封装，功能与 load 相同， 但可以直接从内置示例中加载，更加方便。

注意

该函数主要用于演示目的， 以及让文档示例更简洁。 若要通用地加载音频文件，请改用 load。

参数

参数类型说明
keystr

要加载的曲目标识符

hqbool, optional

若为 True，返回录音的高质量版本。 若为 False，返回 22KHz 单声道版本的录音。

  • 若未提供，hq 会根据 kwargs 中的其他参数推断：：

    • 若提供了 sr 且大于 22050（或为 None），则 hq 设为 True。

    • 若提供了 mono 且设为 False，则 hq 设为 True。

    • 否则 hq 设为 False。

**kwargsadditional keyword arguments

传给 load 的额外关键字参数

返回值

返回值类型说明
ynp.ndarray [shape=(n,) or (…, n)]

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

参见

  • load
  • librosa.util.example
  • librosa.util.list_examples

示例

加载 ‘trumpet’ 示例的默认版本

>>> y, sr = librosa.loadx('trumpet')

加载 ‘trumpet’ 示例的立体声版本

>>> y, sr = librosa.loadx('trumpet', mono=False)
>>> # This is equivalent to the following more verbose code:
>>> y, sr = librosa.load(librosa.ex('trumpet', hq=True), mono=False)
