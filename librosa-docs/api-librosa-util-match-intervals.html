librosa.util.match_intervals

librosa.util.match_intervals(intervals_from, intervals_to, strict=True) [源码]

把一组时间区间匹配到另一组。

这适用于把节拍时刻映射到片段等任务。

intervals_from 的每个元素 [a, b] 匹配到 intervals_to 中使区间 Jaccard 相似度最大的元素 [c, d]：

max(0, |min(b, d) - max(a, c)|) / |max(d, b) - min(a, c)|

在 strict=True 模式下，若没有与 [a,b] 交集为正的区间，则抛出异常。

在 strict=False 模式下，与 intervals_to 中任何元素都无交集的区间 [a, b] 改为匹配到使下式最小的区间 [c, d]：

min(|b - c|, |a - d|)

即边界最接近 [a, b] 的不相交区间 [c, d]。

注意

intervals_to 的一个元素可能匹配到 intervals_from 的多个条目。

参数

参数类型说明
intervals_fromnp.ndarray [shape=(n, 2)]

源区间的时间范围。 第 i 个区间跨越 intervals_from[i, 0] 到 intervals_from[i, 1] 的时间。 intervals_from[0, 0] 应为 0，intervals_from[-1, 1] 应为曲目时长。

intervals_tonp.ndarray [shape=(m, 2)]

与 intervals_from 类似。

strictbool

若为 True，区间只有相交才能匹配。 若为 False，不相交的区间也可匹配。

返回值

返回值类型说明
interval_mappingnp.ndarray [shape=(n,)]

intervals_from 的每个区间在 intervals_to 中对应的区间。

异常

异常说明
ParameterError

若任一输入区间数组形状不正确

若 strict=True 且 intervals_from 的某个元素与 intervals_to 的所有元素都不相交。

参见

  • match_events

示例

>>> ints_from = np.array([[3, 5], [1, 4], [4, 5]])
>>> ints_to = np.array([[0, 2], [1, 3], [4, 5], [6, 7]])
>>> librosa.util.match_intervals(ints_from, ints_to)
array([2, 1, 2], dtype=uint32)
>>> # [3, 5] => [4, 5]  (ints_to[2])
>>> # [1, 4] => [1, 3]  (ints_to[1])
>>> # [4, 5] => [4, 5]  (ints_to[2])

在 strict 模式下无法做上述的逆向匹配， 因为 [6, 7] 与 ints_from 中的所有区间都不相交。 使用 strict=False 时结果如下：

>>> librosa.util.match_intervals(ints_to, ints_from, strict=False)
array([1, 1, 2, 2], dtype=uint32)
>>> # [0, 2] => [1, 4]  (ints_from[1])
>>> # [1, 3] => [1, 4]  (ints_from[1])
>>> # [4, 5] => [4, 5]  (ints_from[2])
>>> # [6, 7] => [4, 5]  (ints_from[2])
