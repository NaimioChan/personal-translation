librosa.util.shear

librosa.util.shear(X, *, factor=1, axis=-1) [源码]

按给定因子剪切数组（或矩阵）。

列 X[:, n] 将按 factor * n 发生位移（循环平移）

这主要用于在滞后表示与递归表示之间转换：以 factor=-1 剪切会把主对角线变成水平线。以 factor=1 剪切会把水平线变成对角线。

参数

参数类型说明
Xnp.ndarray [ndim=2] or scipy.sparse array/matrix

待剪切的数组或矩阵

factorint

剪切因子：X[:, n] -> np.roll(X[:, n], factor * n)

axisint

剪切所沿的轴

返回值

返回值类型说明
X_shearsame type as X

剪切后的矩阵或数组

示例

>>> E = np.eye(3)
>>> librosa.util.shear(E, factor=-1, axis=-1)
array([[1., 1., 1.],
       [0., 0., 0.],
       [0., 0., 0.]])
>>> librosa.util.shear(E, factor=-1, axis=0)
array([[1., 0., 0.],
       [1., 0., 0.],
       [1., 0., 0.]])
>>> librosa.util.shear(E, factor=1, axis=-1)
array([[1., 0., 0.],
       [0., 0., 1.],
       [0., 1., 0.]])
