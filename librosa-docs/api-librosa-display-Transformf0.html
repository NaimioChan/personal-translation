librosa.display.Transformf0

class librosa.display.Transformf0(f0, *, sr=22050, hop_length=512, bins_per_octave=12, norm=1, offset=0, transpose=False, is_inverted=False) [源码]

用于处理波形可视化中 f0 位移的工具类。

参数

参数类型说明
f0np.ndarray

基频值数组（单位 Hz），每帧一个值。清音帧的取值可以为 NaN。

srnumber > 0

音频采样率，与 hop_length 一起用于计算时间戳。

hop_lengthint > 0

相邻两个 f0 帧之间的音频采样点数。

bins_per_octaveint > 0

音高轴使用的每个八度的 bin 数量。

normfloat

作用于音高轴的归一化因子。

offsetfloat

作用于帧时间戳的时间偏移（单位秒）。

transposebool

若为 True，时间轴为第二维而非第一维。

is_invertedbool

若为 True，应用 f0 位移变换的逆变换。
