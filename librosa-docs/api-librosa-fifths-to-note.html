librosa.fifths_to_note

librosa.fifths_to_note(*, unison, fifths, unicode=True) [源码]

计算从指定同音出发、经过给定数量纯五度后的音名。

本函数主要作为 函数纯律系统（FJS）记谱转换的工具函数使用。

本函数不假定“五度圈”或十二平均律， 因此由于变音记号的累积，12 个五度一般不会产生 同一音级的音。

参数

参数类型说明
unisonstr

起始（同音）音的名称，例如 ‘C’ 或 ‘Bb’。 支持 Unicode 变音记号。

fifthsint

相对同音偏移的纯五度数量。

unicodebool

若为 True（默认），则变音记号使用 Unicode 符号 (♯𝄪♭𝄫)。

若为 False，则变音记号被编码为低阶 ASCII 表示：

♯ -> #, 𝄪 -> ##, ♭ -> b, 𝄫 -> bb

返回值

返回值类型说明
notestr

所请求的音名

示例

>>> librosa.fifths_to_note(unison='C', fifths=6)
'F♯'
>>> librosa.fifths_to_note(unison='G', fifths=-3)
'B♭'
>>> librosa.fifths_to_note(unison='Eb', fifths=11, unicode=False)
'G#'
