librosa.effects.split

librosa.effects.split(y, *, top_db=60, ref=<function max>, frame_length=2048, hop_length=512, aggregate=<function max>) [源码]

把音频信号切分为非静音区间。

参数

参数类型说明
ynp.ndarray, shape=(…, n)

音频信号。支持多声道。

top_dbnumber > 0

低于参考电平多少分贝即视为静音的阈值

refnumber or callable

参考幅度。默认使用 np.max，与信号中的峰值幅度比较。

frame_lengthint > 0

每个分析帧的采样点数

hop_lengthint > 0

相邻分析帧之间的采样点数

aggregatecallable [default: np.max]

跨声道聚合（若 y.ndim > 1）所用的函数

返回值

返回值类型说明
intervalsnp.ndarray, shape=(m, 2)

intervals[i] == (start_i, end_i) 为非静音区间 i 的起止时间（以采样点数计）。
