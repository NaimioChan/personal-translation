librosa.util.interp_broadcast

librosa.util.interp_broadcast(*, x1, x1_pos, x2, x2_pos, interp_pos=None, op=<ufunc 'multiply'>, kind='linear', fill_value=0, axis=-2) [源码]

通过插值对两个数组做广播

沿给定轴把两个数组插值到公共网格，再执行广播操作 （如 np.multiply）将它们合并。它可用于获取 DFT / AC 乘积 [1] 与 基频节拍图 [2]。

[1] Peeters, G. “Spectral and Temporal Periodicity Representations of Rhythm for the Automatic Classification of Music Audio Signal.” In IEEE Transactions on Audio, Speech, and Language Processing, vol. 19, no. 5, pp. 1242–1252, July 2011.

[2] Cozens, James, and Simon Godsill. “Dynamic Time Signature Recognition, Tempo Inference, and Beat Tracking Through the Metrogram Transform.” In IEEE Open Journal of Signal Processing, pp. 1–9, 2023.

参数

参数类型说明
x1np.ndarray

除插值轴之外，各维与 x2 广播兼容的数组。

x1_posnp.ndarray

x1 沿插值轴的位置数据。

x2np.ndarray

除插值轴之外，各维与 x1 广播兼容的数组。

x2_posnp.ndarray

x2 沿插值轴的位置数据。

interp_posnp.ndarray

插值网格的位置数据。 默认：x1_pos。

opfunction [optional]

对两个插值后的数组执行的广播操作。 默认：np.multiply。

kindstr

插值类型。见 scipy.interpolate.interp1d。 默认："linear"

fill_valuefloat

外推到观测范围之外时使用的填充值。 默认：0

axisint

插值所沿的轴。 默认：-2

返回值

返回值类型说明
resultnp.ndarray or (np.ndarray, np.ndarray)

插值后合并两个数组的结果。 若 op 设为 None，则分别返回插值后的数组 (y1, y2)。

参见

  • librosa.feature.metrogram

示例

>>> import numpy as np
>>>
>>> # 两个长度与采样位置都不同的数组
>>> x1 = np.array([1, 1, 1])
>>> x1_pos = np.array([0, 0.5, 1])
>>> x2 = np.array([5, 10])
>>> x2_pos = np.array([0, 1])
>>>
>>> # 插值到 x1_pos 并做广播相乘（默认行为）
>>> product = librosa.util.interp_broadcast(
...     x1=x1,
...     x1_pos=x1_pos,
...     x2=x2,
...     x2_pos=x2_pos,
...     axis=0,
... )
>>>
>>> product
array([ 5. ,  7.5, 10. ])
