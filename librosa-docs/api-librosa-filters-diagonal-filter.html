librosa.filters.diagonal_filter

librosa.filters.diagonal_filter(window, n, *, slope=1.0, angle=None, zero_mean=False) [源码]

构建二维对角滤波器。

主要用于平滑递归矩阵或自相似矩阵。

参数

参数类型说明
windowstr, tuple, number, callable, or list-like

滤波器所用的窗函数。

详情见 get_window。

注意这里使用的窗应取非负值。

nint > 0

滤波器的长度

slopefloat

所要生成的对角滤波器的斜率

anglefloat or None

若给出，则忽略 slope 参数， 由 angle 直接设定滤波器方向（单位为弧度）。 否则，angle 取为 arctan(slope)。

zero_meanbool

若为 True，使用零均值滤波器。 否则，使用非负的平均滤波器。

若想增强路径并抑制块状结构，应启用该项。

返回值

返回值类型说明
kernelnp.ndarray, shape=[(m, m)]

二维滤波核

说明

本函数在层级 10 缓存。
