librosa.segment.recurrence_matrix

librosa.segment.recurrence_matrix(data, *, k=None, width=1, metric='euclidean', sym=False, sparse=False, mode='connectivity', bandwidth=None, self=False, axis=-1, full=False) [源码]

从数据矩阵计算递归矩阵。

当 data[..., i] 是 data[..., j] 的 k 近邻之一且 |i - j| >= width 时，rec[i, j] 非零

rec[i, j] 的具体取值有多种形式，由下面的 mode 参数决定：

  • 连通性：rec[i, j] = 1 or 0 表示帧 i 与 j 是重复。

  • 亲和度：rec[i, j] > 0 度量帧 i 与 j 的相似程度。这也称为（稀疏）自相似矩阵。

  • 距离：rec[i, j] > 0 度量帧 i 与 j 的距离。这也称为（稀疏）自距离矩阵。

通用术语递归矩阵可指上述三种形式中的任意一种。

参数

参数类型说明
datanp.ndarray [shape=(…, d, n)]

特征矩阵。 若数据超过二维（如多声道输入），比较前会把前面的维度展平。 例如，形状为 (2, d, n) 的立体声输入会 自动重排为 (2 * d, n)。

kint > 0 [scalar] or None

每个样本的近邻数量

默认：k = 2 * ceil(sqrt(t - 2 * width + 1))， 若 t <= 2 * width + 1 则为 k = 2

widthint >= 1 [scalar]

仅当 |i - j| >= width 时 才连接近邻 (data[..., i], data[..., j])

width 不能超过数据长度。

metricstr

近邻计算所用的距离度量。

详见 sklearn.neighbors.NearestNeighbors。

symbool [scalar]

设 sym=True 时只连接互为近邻的点

sparsebool [scalar]

若为 False，返回稠密类型（ndarray） 若为 True，返回稀疏类型（scipy.sparse.csc_array）

modestr, {‘connectivity’, ‘distance’, ‘affinity’}

若为 ‘connectivity’，产生二值连通矩阵。

若为 ‘distance’，非零元素包含点之间的距离。

若为 ‘affinity’，非零元素映射为 exp( - distance(i, j) / bandwidth)，其中 bandwidth 如下文所述。

bandwidthNone, float > 0, ndarray, or str
  • 字符串选项包括：

    • ‘med_k_scalar’

    • ‘mean_k’

    • ‘gmean_k’

    • ‘mean_k_avg’

    • ‘gmean_k_avg’

    • ‘mean_k_avg_and_pair’

若提供 ndarray，则把它作为每个 i、j 对的 bandwidth。

若使用 mode='affinity'，可用 bandwidth 选项设置 亲和核上的 bandwidth。

若未提供取值或为 None，默认为 'med_k_scalar'。

若 bandwidth='med_k_scalar'，标量 bandwidth 设为所有样本第 k 近邻距离的中位数。

若 bandwidth='mean_k'，对每个样本对 (i, j)，bandwidth 取样本 i 与样本 j 到第 k 近邻距离的算术平均。

若 bandwidth='gmean_k'，对每个样本对 (i, j)，bandwidth 取样本 i 与 j 到第 k 近邻距离的几何平均 [1]。

若 bandwidth='mean_k_avg'，对每个样本对 (i, j)，bandwidth 取样本 i 与样本 j 到前 k 个近邻的平均距离的算术平均。 这与 Wang et al. (2014) [2] 的方法类似，但不包含 i 与 j 之间的距离。

若 bandwidth='gmean_k_avg'，对每个样本对 (i, j)，bandwidth 取样本 i 与样本 j 到前 k 个近邻的平均距离的几何平均。

若 bandwidth='mean_k_avg_and_pair'，对每个样本对 (i, j)，bandwidth 取三项的算术平均：样本 i、样本 j 分别到前 k 个近邻的平均距离，以及 i 与 j 之间的距离。 这与 Wang et al. (2014) 的方法类似。[2]

[1] Zelnik-Manor, Lihi, and Pietro Perona. (2004). “Self-tuning spectral clustering.” Advances in neural information processing systems 17.

[2] Wang, Bo, et al. (2014). “Similarity network fusion for aggregating data types on a genomic scale.” Nat Methods 11, 333–337. https://doi.org/10.1038/nmeth.2810 (1,2)

selfbool

若为 True，主对角线填入自连接： mode='distance' 时为 0，否则为 1。

若为 False，主对角线留空。

axisint

计算递归所沿的轴。 默认取最后一个索引（-1）。

fullbool

若使用 mode ='affinity' 或 mode='distance'，可用此选项计算完整的亲和矩阵或距离矩阵，而非常只保留各样本前 k 个近邻处非零元素的稀疏矩阵。 此选项在 mode='connectivity' 下无效。

使用 mode='distance' 时，设 full=True 将忽略 k 与 width。 使用 mode='affinity' 时，设 full=True 将只在 bandwidth 估计中使用 k，并忽略 width。

返回值

返回值类型说明
recnp.ndarray or scipy.sparse.csc_array, [shape=(t, t)]

递归矩阵

参见

  • sklearn.neighbors.NearestNeighbors
  • scipy.spatial.distance.cdist
  • librosa.feature.stack_memory
  • recurrence_to_lag

说明

此函数在缓存级别 30 上缓存。

示例

在 CQT 空间中查找近邻

>>> y, sr = librosa.loadx('nutcracker')
>>> hop_length = 1024
>>> chroma = librosa.feature.chroma_cqt(y=y, sr=sr, hop_length=hop_length)
>>> # Use time-delay embedding to get a cleaner recurrence matrix
>>> chroma_stack = librosa.feature.stack_memory(chroma, n_steps=10, delay=3)
>>> R = librosa.segment.recurrence_matrix(chroma_stack)

或把近邻数量固定为 5

>>> R = librosa.segment.recurrence_matrix(chroma_stack, k=5)

抑制 ±7 帧内的近邻

>>> R = librosa.segment.recurrence_matrix(chroma_stack, width=7)

使用余弦相似度代替欧氏距离

>>> R = librosa.segment.recurrence_matrix(chroma_stack, metric='cosine')

要求互为近邻

>>> R = librosa.segment.recurrence_matrix(chroma_stack, sym=True)

使用亲和矩阵代替二值连通矩阵

>>> R_aff = librosa.segment.recurrence_matrix(chroma_stack, metric='cosine',
...                                           mode='affinity')

绘制特征矩阵与递归矩阵

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(ncols=2, sharex=True, sharey=True)
>>> imgsim = librosa.display.specshow(R, x_axis='s', y_axis='s',
...                          hop_length=hop_length, ax=ax[0])
>>> ax[0].set(title='Binary recurrence (symmetric)')
>>> imgaff = librosa.display.specshow(R_aff, x_axis='s', y_axis='s',
...                          hop_length=hop_length, cmap='magma_r', ax=ax[1])
>>> ax[1].set(title='Affinity recurrence')
>>> ax[1].label_outer()
>>> fig.colorbar(imgsim, ax=ax[0], orientation='horizontal', ticks=[0, 1])
>>> fig.colorbar(imgaff, ax=ax[1], orientation='horizontal')
