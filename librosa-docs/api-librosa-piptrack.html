librosa.piptrack

librosa.piptrack(*, y=None, sr=22050, S=None, n_fft=2048, hop_length=None, fmin=150.0, fmax=4000.0, threshold=0.1, win_length=None, window='hann', center=True, pad_mode='constant', ref=None) [源码]

在经阈值处理、抛物线插值后的 STFT 上做音高跟踪。

本实现使用 [1] 所述的抛物线插值方法。

[1] https://ccrma.stanford.edu/~jos/sasp/Sinusoidal_Peak_Interpolation.html

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频信号。支持多声道。

srnumber > 0 [scalar]

y 的音频采样率

Snp.ndarray [shape=(…, d, t)] or None

幅度或功率频谱图

n_fftint > 0 [scalar] or None

提供 y 时使用的 FFT 帧长。

hop_lengthint > 0 [scalar] or None

跳距（采样点数量）

fminfloat > 0 [scalar]

频率下限。

fmaxfloat > 0 [scalar]

频率上限。

thresholdfloat in (0, 1)

频谱 S 中的某个 bin 若大于 threshold * ref(S)，则被视为音高。

默认情况下，ref(S) 取 max(S, axis=0)（每列的最大值）。

win_lengthint <= n_fft [scalar]

每个音频帧都用 window 加窗。 窗长为 win_length，随后补零至 n_fft。

未指定时默认为 win_length = n_fft。

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

  • 窗的规格（字符串、元组或数字）； 见 scipy.signal.get_window

  • 窗函数，如 scipy.signal.windows.hann

  • 长度为 n_fft 的向量或数组

centerbool

  • 若为 True，对信号 y 做填充，使帧 t 以 y[t * hop_length] 为中心。

  • 若为 False，帧 t 从 y[t * hop_length] 开始

pad_modestr

若 center=True，在信号边缘使用的填充模式。 默认情况下，STFT 使用零填充。

另见：np.pad。

refscalar or callable [default=np.max]

若为标量，则作为判断音高时比较 S 的参考值。

若为可调用对象，参考值按 ref(S, axis=0) 计算。

返回值

返回值类型说明
pitches, magnitudesnp.ndarray [shape=(…, d, t)]

其中 d 为位于 fmin 与 fmax 之间的 FFT bin 子集。

pitches[..., f, t] 包含 bin f、时刻 t 的瞬时频率

magnitudes[..., f, t] 包含对应的幅度。

在非极大幅度的 bin 上，pitches 与 magnitudes 均取 0。

说明

此函数在缓存级别 30 上缓存。

S 与 y 必须提供其一。

若未给出 S，则使用 librosa.stft 的默认参数从 y 计算。

示例

从波形输入计算音高

>>> y, sr = librosa.loadx('trumpet')
>>> pitches, magnitudes = librosa.piptrack(y=y, sr=sr)

或从频谱图输入计算

>>> S = np.abs(librosa.stft(y))
>>> pitches, magnitudes = librosa.piptrack(S=S, sr=sr)

或使用替代参考值做音高检测，此时每帧中高于平均频谱能量的值被视为音高

>>> pitches, magnitudes = librosa.piptrack(S=S, sr=sr, threshold=1,
...                                        ref=np.mean)
