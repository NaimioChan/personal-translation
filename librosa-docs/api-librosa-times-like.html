librosa.times_like

librosa.times_like(X, *, sr=22050, hop_length=512, n_fft=None, axis=-1) [源码]

返回与特征矩阵时间轴对应的时间值数组。

参数

参数类型说明
Xnp.ndarray or scalar

  • 若为 ndarray，X 是特征矩阵，例如 STFT、色度图或 mel 频谱图。

  • 若为标量，X 表示帧数。

srnumber > 0 [scalar]

音频采样率

hop_lengthint > 0 [scalar]

相邻帧之间的采样点数

n_fftNone or int > 0 [scalar]

可选：FFT 帧的长度。 若给定，时间换算会附加 n_fft // 2 的偏移， 以在使用非居中 STFT 时抵消加窗效应。

axisint [scalar]

表示 X 时间轴的轴。 默认取最后一维（-1）。

返回值

返回值类型说明
timesnp.ndarray [shape=(n,)]

与 X 各帧对应的时间（秒）数组。

参见

  • samples_like：

    返回与特征矩阵时间轴对应的采样索引数组。

示例

输入特征矩阵：

>>> y, sr = librosa.loadx('trumpet')
>>> D = librosa.stft(y)
>>> times = librosa.times_like(D, sr=sr)
>>> times
array([0.   , 0.023, ..., 5.294, 5.317])

输入标量：

>>> n_frames = 2647
>>> times = librosa.times_like(n_frames, sr=sr)
>>> times
array([  0.00000000e+00,   2.32199546e-02,   4.64399093e-02, ...,
         6.13935601e+01,   6.14167800e+01,   6.14400000e+01])
