librosa.clicks

librosa.clicks(*, times=None, frames=None, sr=22050, hop_length=512, click_freq=1000.0, click_duration=0.1, click=None, length=None) [源码]

构造“节拍器音轨”。

返回一个信号，其中在每个指定的时间点上放置了 click 声音。

参数

参数类型说明
timesnp.ndarray or None

放置咔嗒声的时间，单位为秒

framesnp.ndarray or None

放置咔嗒声的帧下标

srnumber > 0

输出信号的目标采样率

hop_lengthint > 0

若位置由 frames 指定，则为帧之间的采样数。

click_freqfloat > 0

默认咔嗒信号的频率（Hz）。默认为 1KHz。

click_durationfloat > 0

默认咔嗒信号的时长（秒）。默认为 100ms。

clicknp.ndarray or None

（可选）用来代替默认咔嗒声的咔嗒信号样本。支持多声道。

lengthint > 0

输出信号的目标采样数

返回值

返回值类型说明
click_signalnp.ndarray

合成出的咔嗒信号。 默认是单声道的；若提供了 click 信号，则声道数与之相同。

异常

异常说明
ParameterError

  • 若 times 与 frames 均未提供。

  • 若 click_freq、click_duration 或 length 中的任一值超出范围。

示例

>>> # Sonify detected beat events
>>> y, sr = librosa.loadx('choice', duration=10)
>>> tempo, beats = librosa.beat.beat_track(y=y, sr=sr)
>>> y_beats = librosa.clicks(frames=beats, sr=sr)
>>> # Or generate a signal of the same length as y
>>> y_beats = librosa.clicks(frames=beats, sr=sr, length=len(y))
>>> # Or use timing instead of frame indices
>>> times = librosa.frames_to_time(beats, sr=sr)
>>> y_beat_times = librosa.clicks(times=times, sr=sr)
>>> # Or with a click frequency of 880Hz and a 500ms sample
>>> y_beat_times880 = librosa.clicks(times=times, sr=sr,
...                                  click_freq=880, click_duration=0.5)

把咔嗒声波形与频谱图并排显示

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> S = librosa.feature.melspectrogram(y=y, sr=sr)
>>> librosa.display.specshow(S, vscale='dBFS[power]',
...                          x_axis='time', y_axis='mel', ax=ax[0])
>>> librosa.display.waveshow(y_beat_times, sr=sr, label='Beat clicks',
...                          ax=ax[1])
>>> ax[1].legend()
>>> ax[0].label_outer()
>>> ax[0].set_title(None)
