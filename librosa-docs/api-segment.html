结构与分割

librosa.segment 提供用于音频结构分析和分割的函数。

包括递归（自相似）矩阵与交叉相似矩阵的计算、相似矩阵的滤波与变换，以及基于聚类的时间分割。

函数说明

cross_similarity

计算从一个数据序列到参考序列的交叉相似度。

recurrence_matrix

由数据矩阵计算递归矩阵。

recurrence_to_lag

把递归矩阵转换为滞后矩阵。

lag_to_recurrence

把滞后矩阵转换为递归矩阵。

timelag_filter

在时间滞后域中应用滤波器。

path_enhance

针对自相似矩阵与交叉相似矩阵的多角度路径增强。

agglomerative

自底向上的时间分割。

subsegment

通过特征聚类对分割结果再细分。
