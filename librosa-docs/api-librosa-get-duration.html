librosa.get_duration

librosa.get_duration(*, y=None, sr=22050, S=None, n_fft=2048, hop_length=512, center=True, path=None) [源码]

计算音频时间序列、特征矩阵或文件名的时长（以秒计）。

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的音频采样率

Snp.ndarray [shape=(…, d, t)] or None

STFT 矩阵，或任意由 STFT 派生出的矩阵（例如色度图 或 mel 频谱图）。 由频谱图输入算出的时长只能精确到帧的分辨率。若需要高精度， 最好直接使用音频时间序列。

n_fftint > 0 [scalar]

计算 S 时使用的 FFT 帧长度

hop_lengthint > 0 [ scalar]

S 各列之间的音频采样点数

centerbool

  • 若为 True，S[:, t] 以 y[t * hop_length] 为中心

  • 若为 False，则 S[:, t] 从 y[t * hop_length] 开始

pathstr, path, or file-like

若提供，则忽略其余所有参数， 直接根据音频文件计算时长。 注意这样可避免把内容加载进内存， 因此适合查询长文件的时长。

与 load 中一样，它也可以是整数或可交给 soundfile 处理的 已打开文件句柄。

返回值

返回值类型说明
dfloat >= 0

输入时间序列或频谱图的时长（以秒计）。

异常

异常说明
ParameterError

若 y、S 与 path 均未提供。

说明

get_duration 可以作用于文件（path）、频谱图（S） 或音频缓冲区（y, sr）。这三个选项只应提供其中一个。 如果确实提供了多个（例如 path 与 S）， 则 path 优先于 S，S 优先于 (y, sr)。

示例

>>> # Load an example audio file
>>> y, sr = librosa.loadx('trumpet')
>>> librosa.get_duration(y=y, sr=sr)
5.333378684807256
>>> # Or directly from an audio file
>>> librosa.get_duration(filename=librosa.ex('trumpet'))
5.333378684807256
>>> # Or compute duration from an STFT matrix
>>> y, sr = librosa.loadx('trumpet')
>>> S = librosa.stft(y)
>>> librosa.get_duration(S=S, sr=sr)
5.317369614512471
>>> # Or a non-centered STFT matrix
>>> S_left = librosa.stft(y, center=False)
>>> librosa.get_duration(S=S_left, sr=sr)
5.224489795918367
