librosa.cqt

librosa.cqt(y, *, sr=22050, hop_length=512, fmin=None, n_bins=84, bins_per_octave=12, tuning=0.0, filter_scale=1, norm=1, sparsity=0.01, window='hann', scale=True, pad_mode='constant', res_type='soxr_hq', dtype=None) [源码]

计算音频信号的常数 Q 变换。

本实现基于 [1] 所述的递归子采样方法。

[1] Schoerkhuber, Christian, and Anssi Klapuri. “Constant-Q transform toolbox for music processing.” 7th Sound and Music Computing Conference, Barcelona, Spain. 2010.

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

hop_lengthint > 0 [scalar]

相邻 CQT 列之间的采样数。

fminfloat > 0 [scalar]

最低频率。默认为 C1 ~= 32.70 Hz

n_binsint > 0 or None [scalar]

从 fmin 开始计数的频带数。 若为 None，则频带数推断为在 sr/2 以下能容纳的最大值。

bins_per_octaveint > 0 [scalar]

每八度的频带数

tuningNone or float

调音偏移，单位为频带分数。

若为 None，则根据信号自动估计调音。

所得 CQT 的最低频率会被调整为 fmin * 2**(tuning / bins_per_octave)。

filter_scalefloat > 0

滤波器缩放因子。较小的值（<1）使用更短的窗，以提高时间分辨率。

norm{inf, -inf, 0, float > 0}

基函数归一化所用的范数类型。 参见 librosa.util.normalize。

sparsityfloat in [0, 1)

通过舍弃每个基中最高达 sparsity 比例的能量来稀疏化 CQT 基。

设 sparsity=0 可关闭稀疏化。

windowstr, tuple, number, or function

基滤波器的窗规格。 详见 filters.get_window。

scalebool

若为 True，则按每个声道滤波器长度的平方根缩放 CQT 响应。这类似于 FFT 中的 norm='ortho'。

若为 False，则不缩放 CQT。这类似于 FFT 中的 norm=None。

pad_modestr

居中帧分析的填充模式。

另见：librosa.stft 与 numpy.pad。

res_typestr

递归降采样所用的重采样模式。

dtypenp.dtype

输出数组的（复数）数据类型。默认按输入信号的数值精度推断。

返回值

返回值类型说明
CQTnp.ndarray [shape=(…, n_bins, t)]

每个时刻每个频率上的常数 Q 值。

参见

  • vqt
  • librosa.resample
  • librosa.util.normalize

说明

该函数在级别 20 上缓存。

示例

生成并绘制常数 Q 功率谱

>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('trumpet')
>>> C = np.abs(librosa.cqt(y, sr=sr))
>>> fig, ax = plt.subplots()
>>> img = librosa.display.specshow(C, vscale='dBFS',
...                                sr=sr, x_axis='time', y_axis='cqt_note', ax=ax)
>>> ax.set_title('Constant-Q power spectrum')
>>> librosa.display.colorbar_db(img)

限制频率范围

>>> C = np.abs(librosa.cqt(y, sr=sr, fmin=librosa.note_to_hz('C2'),
...                 n_bins=60))
>>> C
array([[6.830e-04, 6.361e-04, ..., 7.362e-09, 9.102e-09],
       [5.366e-04, 4.818e-04, ..., 8.953e-09, 1.067e-08],
       ...,
       [4.288e-02, 4.580e-01, ..., 1.529e-05, 5.572e-06],
       [2.965e-03, 1.508e-01, ..., 8.965e-06, 1.455e-05]])

使用更高的频率分辨率

>>> C = np.abs(librosa.cqt(y, sr=sr, fmin=librosa.note_to_hz('C2'),
...                 n_bins=60 * 2, bins_per_octave=12 * 2))
>>> C
array([[5.468e-04, 5.382e-04, ..., 5.911e-09, 6.105e-09],
       [4.118e-04, 4.014e-04, ..., 7.788e-09, 8.160e-09],
       ...,
       [2.780e-03, 1.424e-01, ..., 4.225e-06, 2.388e-05],
       [5.147e-02, 6.959e-02, ..., 1.694e-05, 5.811e-06]])
