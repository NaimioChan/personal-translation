增强色度特征与色度变体

本 notebook 演示多种增强色度特征的技术，并介绍 librosa 中实现的色度变体。

增强色度特征

在 librosa 色度函数的默认参数设置之外，我们还施加以下增强：

  1. 谐波-打击-残差源分离，以消除瞬态。

  2. 最近邻平滑，以消除经过音和稀疏噪声。这受到 Cho and Bello, 2011 [1] 中基于重现的平滑技术的启发。

  3. 局部中值滤波，以抑制残留的不连续。

[1] Taemin Cho & Juan Pablo Bello. (2011). A Feature Smoothing Method for Chord Recognition Using Recurrence Plots. Proceedings of the 12th International Society for Music Information Retrieval Conference, 651–656. https://doi.org/10.5281/zenodo.1417557

首先，绘制原始色度

chroma_orig = librosa.feature.chroma_cqt(y=y, sr=sr)

# For display purposes, let's zoom in on a 15-second chunk from the middle of the song
idx = tuple([slice(None), slice(*list(librosa.time_to_frames([45, 60])))])

# And for comparison, we'll show the CQT matrix as well.
C = np.abs(librosa.cqt(y=y, sr=sr, bins_per_octave=12*3, n_bins=7*12*3))

fig, ax = plt.subplots(nrows=2, sharex=True)
img1 = librosa.display.specshow(C[idx], vscale="dBFS",
                                y_axis="cqt_note", x_axis="time", bins_per_octave=12*3,
                                ax=ax[0])
librosa.display.colorbar_db(img1, ax=ax[0])
ax[0].label_outer()

img2 = librosa.display.specshow(chroma_orig[idx], y_axis="chroma", x_axis="time", ax=ax[1])
fig.colorbar(img2, ax=[ax[1]])
ax[1].set(ylabel="Default chroma")

如果把音频信号的谐波成分分离出来，效果会更好。这里我们用较大的 margin 来把谐波与打击成分分开：

y_harm = librosa.effects.harmonic(y=y, margin=8)
chroma_harm = librosa.feature.chroma_cqt(y=y_harm, sr=sr)

fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
librosa.display.specshow(chroma_orig[idx], y_axis="chroma", x_axis="time", ax=ax[0])
ax[0].set(ylabel="Default chroma")
ax[0].label_outer()

librosa.display.specshow(chroma_harm[idx], y_axis="chroma", x_axis="time", ax=ax[1])
ax[1].set(ylabel="Harmonic")

不过其中仍有一些噪声。我们可以用非局部滤波把它清理掉。这会有效地去除特征中任何稀疏的加性噪声。

chroma_filter = np.minimum(chroma_harm,
                           librosa.decompose.nn_filter(chroma_harm,
                                                       aggregate=np.median,
                                                       metric="cosine"))

fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
librosa.display.specshow(chroma_harm[idx], y_axis="chroma", x_axis="time", ax=ax[0])
ax[0].set(ylabel="Harmonic")
ax[0].label_outer()

librosa.display.specshow(chroma_filter[idx], y_axis="chroma", x_axis="time", ax=ax[1])
ax[1].set(ylabel="Non-local")

使用水平中值滤波器可以抑制局部的不连续和瞬态。

chroma_smooth = scipy.ndimage.median_filter(chroma_filter, size=(1, 9))

fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
librosa.display.specshow(chroma_filter[idx], y_axis="chroma", x_axis="time", ax=ax[0])
ax[0].set(ylabel="Non-local")
ax[0].label_outer()

librosa.display.specshow(chroma_smooth[idx], y_axis="chroma", x_axis="time", ax=ax[1])
ax[1].set(ylabel="Median-filtered")

色度变体

librosa 中实现了三种色度变体：chroma_stft、chroma_cqt 和 chroma_cens。chroma_stft 与 chroma_cqt 是绘制色度的两种替代方式。chroma_stft 对输入音频做短时傅里叶变换，并把每个 STFT bin 映射到色度；chroma_cqt 使用常数 Q 变换，把每个 cq-bin 映射到色度。

色谱图的 STFT 方法与 CQT 方法的比较。

chromagram_stft = librosa.feature.chroma_stft(y=y, sr=sr)
chromagram_cqt = librosa.feature.chroma_cqt(y=y, sr=sr)

fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
librosa.display.specshow(chromagram_stft[idx], y_axis="chroma", x_axis="time", ax=ax[0])
ax[0].set(ylabel="STFT")
ax[0].label_outer()

librosa.display.specshow(chromagram_cqt[idx], y_axis="chroma", x_axis="time", ax=ax[1])
ax[1].set(ylabel="CQT")

CENS 特征（chroma_cens）是 Müller and Ewart, 2011 [2] 中提出的色度特征变体，它对常数 Q 色谱图做额外的后处理，从而得到对动态和音色不变的特征。

因此，CENS 特征适用于音频匹配与检索之类的应用。

  • 以下步骤是对色谱图做的额外处理，均在 chroma_cens 中实现：

    1. 对每个色度向量做 L1 归一化

    2. 基于“类对数”幅度阈值对幅度做量化

    3. 用滑动窗平滑（可选参数）

    4. 降采样（未实现）

[2] Meinard Müller & Sebastian Ewert. (2011). Chroma Toolbox: Matlab Implementations for Extracting Variants of Chroma-Based Audio Features. Proceedings of the 12th International Society for Music Information Retrieval Conference, 215–220. https://doi.org/10.5281/zenodo.1416032

原始常数 Q 色谱图与 CENS 特征的比较。

chromagram_cens = librosa.feature.chroma_cens(y=y, sr=sr)

fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
librosa.display.specshow(chromagram_cqt[idx], y_axis="chroma", x_axis="time", ax=ax[0])
ax[0].set(ylabel="Orig")
