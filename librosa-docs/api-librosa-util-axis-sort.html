librosa.util.axis_sort

librosa.util.axis_sort(S, *, axis=-1, index=False, value=None) [源码]

沿数组的行或列排序。

参数

参数类型说明
Snp.ndarray [shape=(d, n)]

待排序的数组

axisint [scalar]

计算排序值所沿的轴

  • axis=0 按峰值列索引对行排序

  • axis=1 按峰值行索引对列排序

indexbool [scalar]

若为真，除置换后的数据外还返回索引数组。

valuefunction

返回排序顺序对应索引的函数。 默认：np.argmax。

返回值

返回值类型说明
S_sortnp.ndarray [shape=(d, n)]

按排序顺序置换列或行后的 S

idxnp.ndarray (optional) [shape=(d,) or (n,)]

若 index == True，为用于置换 S 的排序索引。 idx 的长度与所选 axis 对应。

异常

异常说明
ParameterError

若 S 的维数不恰好为 2（S.ndim != 2）

示例

可视化频谱图 S 的 NMF 输出

>>> # 按峰值频率 bin 对 W 的列排序
>>> y, sr = librosa.loadx('trumpet')
>>> S = np.abs(librosa.stft(y))
>>> W, H = librosa.decompose.decompose(S, n_components=64)
>>> W_sort = librosa.util.axis_sort(W)

或按最低频率 bin 排序

>>> W_sort = librosa.util.axis_sort(W, value=np.argmin)

或对行排序而非列

>>> W_sort_rows = librosa.util.axis_sort(W, axis=0)

同时获取排序索引，并用其置换 H 的行

>>> W_sort, idx = librosa.util.axis_sort(W, index=True)
>>> H_sort = H[idx, :]
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=2, ncols=2)
>>> img_w = librosa.display.specshow(W, vscale='dBFS',
...                                  y_axis='log', ax=ax[0, 0])
>>> ax[0, 0].set(title='W')
>>> ax[0, 0].label_outer()
>>> img_act = librosa.display.specshow(H, x_axis='time', ax=ax[0, 1])
>>> ax[0, 1].set(title='H')
>>> ax[0, 1].label_outer()
>>> librosa.display.specshow(W_sort, vscale='dBFS',
...                          y_axis='log', ax=ax[1, 0])
>>> ax[1, 0].set(title='W sorted')
>>> librosa.display.specshow(H_sort, x_axis='time', ax=ax[1, 1])
>>> ax[1, 1].set(title='H sorted')
>>> ax[1, 1].label_outer()
>>> cbar = librosa.display.colorbar_db(img_w, ax=ax[:, 0], orientation='horizontal')
>>> cbar.ax.tick_params("x", rotation=45)
>>> fig.colorbar(img_act, ax=ax[:, 1], orientation='horizontal')
