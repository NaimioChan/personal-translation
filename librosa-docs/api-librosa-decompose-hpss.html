librosa.decompose.hpss

librosa.decompose.hpss(S, *, kernel_size=31, power=2.0, mask=False, margin=1.0) [源码]

中值滤波谐波-打击源分离（HPSS）。

若 margin = 1.0，则把输入频谱图分解为 S = H + P，其中 H 包含谐波分量，P 包含打击分量。

若 margin > 1.0，则把输入频谱图分解为 S = H + P + R，其中 R 包含未归入 H 或 P 的残余分量。

本实现基于 [1] 与 [2] 所述的算法。

[1] Fitzgerald, Derry. “Harmonic/percussive separation using median filtering.” 13th International Conference on Digital Audio Effects (DAFX10), Graz, Austria, 2010.

[2] Driedger, Müller, Disch. “Extending harmonic-percussive separation of audio.” 15th International Society for Music Information Retrieval Conference (ISMIR 2014), Taipei, Taiwan, 2014.

参数

参数类型说明
Snp.ndarray [shape=(…, d, n)]

输入频谱图。可以是实值（幅度）或复值。 支持多声道。

kernel_sizeint or tuple (kernel_harmonic, kernel_percussive)

中值滤波器的核尺寸。

  • 若为标量，谐波与打击使用同一尺寸。

  • 若为元组，第一个值指定谐波滤波器的宽度，第二个值指定打击滤波器的宽度。

powerfloat > 0 [scalar]

构造软掩码矩阵时维纳滤波器的指数。

maskbool

返回掩码矩阵而不是分量。

掩码矩阵包含非负实数值，可用于度量 S 中的能量被归入谐波分量或打击分量的比例。

分量可通过乘以 S * mask_H 或 S * mask_P 恢复。

marginfloat or tuple (margin_harmonic, margin_percussive)

掩码的边距（如 [2] 所述）

  • 若为标量，谐波与打击使用同一尺寸。

  • 若为元组，第一个值指定谐波掩码的边距，第二个值指定打击掩码的边距。

返回值

返回值类型说明
harmonicnp.ndarray [shape=(…, d, n)]

谐波分量（或掩码）

percussivenp.ndarray [shape=(…, d, n)]

打击分量（或掩码）

参见

  • librosa.util.softmask

说明

该函数在级别 30 上缓存。

示例

分离为谐波与打击两部分

>>> y, sr = librosa.loadx('choice', duration=5)
>>> D = librosa.stft(y)
>>> H, P = librosa.decompose.hpss(D)
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=3, sharex=True, sharey=True)
>>> img = librosa.display.specshow(D, vscale='dBFS',
...                                y_axis='log', x_axis='time', ax=ax[0])
>>> ax[0].set(title='Full power spectrogram')
>>> ax[0].label_outer()
>>> ref = np.max(np.abs(D))  # reference for dBFS scaling comes from full mix
>>> librosa.display.specshow(H, vscale=f'dB[{ref}]',
...                          y_axis='log', x_axis='time', ax=ax[1])
>>> ax[1].set(title='Harmonic power spectrogram')
>>> ax[1].label_outer()
>>> librosa.display.specshow(P, vscale=f'dB[{ref}]',
...                          y_axis='log', x_axis='time', ax=ax[2])
>>> ax[2].set(title='Percussive power spectrogram')
>>> librosa.display.colorbar_db(img, ax=ax)

或者使用更窄的水平滤波器

>>> H, P = librosa.decompose.hpss(D, kernel_size=(13, 31))

只获取谐波／打击掩码，而不获取频谱

>>> mask_H, mask_P = librosa.decompose.hpss(D, mask=True)
>>> mask_H
array([[1.853e-03, 1.701e-04, ..., 9.922e-01, 1.000e+00],
       [2.316e-03, 2.127e-04, ..., 9.989e-01, 1.000e+00],
       ...,
       [8.195e-05, 6.939e-05, ..., 3.105e-04, 4.231e-04],
       [3.159e-05, 4.156e-05, ..., 6.216e-04, 6.188e-04]],
      dtype=float32)
>>> mask_P
array([[9.981e-01, 9.998e-01, ..., 7.759e-03, 3.201e-05],
       [9.977e-01, 9.998e-01, ..., 1.122e-03, 4.451e-06],
       ...,
       [9.999e-01, 9.999e-01, ..., 9.997e-01, 9.996e-01],
       [1.000e+00, 1.000e+00, ..., 9.994e-01, 9.994e-01]],
      dtype=float32)

用大于 1.0 的边距分离为谐波、打击与残余分量

>>> H, P = librosa.decompose.hpss(D, margin=3.0)
>>> R = D - (H+P)
>>> y_harm = librosa.istft(H)
>>> y_perc = librosa.istft(P)
>>> y_resi = librosa.istft(R)

通过加大边距获得更纯净的打击分量

>>> H, P = librosa.decompose.hpss(D, margin=(1.0,5.0))
