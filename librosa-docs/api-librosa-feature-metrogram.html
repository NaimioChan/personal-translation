librosa.feature.metrogram

librosa.feature.metrogram(*, tg, freqs, factors=None, aggregate=<function sum>, kind='linear', fill_value=0) [源码]

Metrogram 变换。[1]

本函数汇总速度图中节拍比例的出现情况。例如，一个在 90BPM 与 30BPM 处 有两个同时存在的能量峰的速度图，会表现出很强的 1/3 比例存在。由此 可以通过求拍点频率与强拍频率之比来进行拍号估计。

默认情况下，这里使用的比例因子如 [2] 所述。

[1] Cozens, James, and Simon Godsill. “Dynamic Time Signature Recognition, Tempo Inference, and Beat Tracking Through the Metrogram Transform.” In IEEE Open Journal of Signal Processing, pp. 1–9, 2023.

[2] Abimbola, Jeremiah, Daniel Kostrzewa, and Paweł Kasprowski. “METER2800: A novel dataset for music time signature detection.” In Data in Brief, vol. 51, 109736, 2023.

参数

参数类型说明
tgnp.ndarray

预先计算好的速度图。

freqsnp.ndarray

速度图轴对应的频率（单位 BPM）。

factorsnp.ndarray

要估计的节拍比例。 若未提供，默认为 1/3、1/4、1/5 与 1/7。

aggregatecallable [optional]

聚合函数，在每一时间点上为每个比例 压缩速度轴。默认为 np.sum。

kindstr

在速度轴上使用的插值方法。

fill_valuefloat

在观测到的速度范围之外外推时使用的 填充值。

返回值

返回值类型说明
metrogramnp.ndarray

指定比例因子对应的 metrogram 变换。 若 aggregate 设为 None，则返回所有单个速度频格的比例。

示例

>>> import numpy as np
>>> import matplotlib.pyplot as plt
>>> import librosa
>>> y, sr = librosa.loadx("sweetwaltz")
>>> # 加长窗，以捕捉较慢的强拍脉冲
>>> win_length = 384 * 4
>>> fourier_tempogram = librosa.feature.fourier_tempogram(y=y, win_length=win_length)
>>> fourier_freqs = librosa.fourier_tempo_frequencies(win_length=win_length)
>>> ac_tempogram = librosa.feature.tempogram(y=y, win_length=win_length)
>>> ac_freqs = librosa.tempo_frequencies(ac_tempogram.shape[-2])
>>> # 合并傅里叶与 AC 速度网格（也可以只用其中一种）
>>> # 从 ac_freqs 中移除 np.inf，以避免产生 nan 结果
>>> funt_freqs = np.union1d(fourier_freqs, ac_freqs[1:])
>>> fundamental_tempogram = librosa.util.interp_broadcast(
...     x1=ac_tempogram,
...     x1_pos=ac_freqs,
...     x2=fourier_tempogram[..., :-1],  # 两种速度图在时间轴上长度必须相同
...     x2_pos=fourier_freqs,
...     interp_pos=funt_freqs,
... )
>>> metrogram = librosa.feature.metrogram(tg=fundamental_tempogram, freqs=funt_freqs)
>>> fig, ax = plt.subplots()
>>> librosa.display.specshow(np.abs(metrogram), x_axis="time", ax=ax)
>>> ax.set(title="Metrogram")
