librosa.db_to_amplitude

librosa.db_to_amplitude(S_db, *, ref=1.0) [源码]

把 dB 刻度的频谱图转换为幅度频谱图。

这实际上就是 amplitude_to_db 的逆运算：

db_to_amplitude(S_db) ~= 10.0**(0.5 * S_db/10 + log10(ref))

参数

参数类型说明
S_dbnp.ndarray

dB 刻度的数值

refnumber > 0

可选的参考幅度。

返回值

返回值类型说明
Snp.ndarray

线性幅度值

说明

该函数在级别 30 上缓存。
