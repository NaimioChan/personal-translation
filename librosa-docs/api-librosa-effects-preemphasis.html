librosa.effects.preemphasis

librosa.effects.preemphasis(y, *, coef=0.97, zi=None, return_zf=False) [源码]

用一阶差分滤波器对音频信号做预加重：

y[n] -> y[n] - coef * y[n-1]

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频信号。支持多声道。

coefpositive number

预加重系数。coef 的典型取值在 0 到 1 之间。

极限情况 coef=0 时信号不变。

coef=1 时结果为信号的一阶差分。

默认值（0.97）与 MFCC 的 HTK 实现中所用的预加重滤波器一致 [1]。

[1] https://htk.eng.cam.ac.uk/

zinumber

滤波器初始状态。对不重叠的帧依次调用时，可将其设为上一次调用返回的 zf。（见下方示例。）

默认情况下 zi 初始化为 2*y[0] - y[1]。

return_zfbool

若为 True，返回最终的滤波器状态。 若为 False，只返回预加重后的信号。

返回值

返回值类型说明
y_outnp.ndarray

预加重后的信号

zfnumber

若 return_zf=True，同时返回最终的滤波器状态

参见

  • deemphasis

示例

应用标准的预加重滤波器

>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('trumpet')
>>> y_filt = librosa.effects.preemphasis(y)
>>> # and plot the results for comparison
>>> S_orig = librosa.amplitude_to_db(np.abs(librosa.stft(y)), ref=np.max, top_db=None)
>>> S_preemph = librosa.amplitude_to_db(np.abs(librosa.stft(y_filt)), ref=np.max, top_db=None)
>>> fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
>>> librosa.display.specshow(S_orig, y_axis='log', x_axis='time', ax=ax[0])
>>> ax[0].set(title='Original signal')
>>> ax[0].label_outer()
>>> img = librosa.display.specshow(S_preemph, y_axis='log', x_axis='time', ax=ax[1])
>>> ax[1].set(title='Pre-emphasized signal')
>>> librosa.display.colorbar_db(img, ax=ax)

分块流式处理时逐块做预加重。注意第二块用第一次调用返回的最终状态 zf 初始化 zi。

>>> y_filt_1, zf = librosa.effects.preemphasis(y[:1000], return_zf=True)
>>> y_filt_2, zf = librosa.effects.preemphasis(y[1000:], zi=zf, return_zf=True)
>>> np.allclose(y_filt, np.concatenate([y_filt_1, y_filt_2]))
True
