librosa.key_to_notes

librosa.key_to_notes(key, *, unicode=True, natural=False) [源码]

列出全部 12 个半音音名，并按照给定调或调式的记法拼写。

该函数用于解决同一音高的不同拼写之间的等音 关系（例如 C♯ 与 D♭），在生成人类可读的输出 （例如绘图）来表示音高内容时特别有用。

音名的确定遵循以下规则：

  1. 若调的主音带有变音记号（升号或降号），则所有音符 都一致使用该变音记号。

  2. 若主音不带变音记号，则推断变音记号，使自然音阶级数 所用的总数最少。

  3. 若出现平局（例如 C:maj 与 A:min 的情形），优先使用升号。

参数

参数类型说明
keystr

必须采用 TONIC:key 的形式。主音必须大写（CDEFGAB）， 调式必须小写 （major、minor、ionian、dorian、phrygian、lydian、 mixolydian、aeolian、locrian）。

调式支持以下缩写：调式名称的前三个字母 （例如 “mix”），或去掉 “ian” 的调式名称（例如 “mixolyd”）。

major 与 maj 都可以作为调式缩写使用。

支持单个和多个变音记号（b!♭ 表示降号，#♯ 表示升号， 𝄪𝄫 表示重变音记号，或它们的任意组合）。

示例：C:maj, C:major, Dbb:min, A♭:min, D:aeo, E𝄪:phryg。

unicodebool

若为 True（默认），变音记号使用 Unicode 符号（♯𝄪♭𝄫）。

  • 若为 False，Unicode 符号将被映射为低位 ASCII 表示：：

    ♯ -> #, 𝄪 -> ##, ♭ -> b, 𝄫 -> bb, ♮ -> n

naturalbool

若为 True，用还原号（♮）标出还原的变音记号。 若为 False（默认），不打印还原记号。

例如，note_to_degrees(‘D:maj’)[0] 在 natural=False（默认）时为 C，在 natural=True 时为 C♮。

返回值

返回值类型说明
noteslist

notes[k] 为给定调下第 k 个半音（从 C 开始） 的名称。包含所有 12 个半音（0 到 11）。

参见

  • midi_to_note

示例

C:maj 将全部使用升号

>>> librosa.key_to_notes('C:maj')
['C', 'C♯', 'D', 'D♯', 'E', 'F', 'F♯', 'G', 'G♯', 'A', 'A♯', 'B']

A:min 的音名相同

>>> librosa.key_to_notes('A:min')
['C', 'C♯', 'D', 'D♯', 'E', 'F', 'F♯', 'G', 'G♯', 'A', 'A♯', 'B']

A♯:min 将使用升号，但把第 0 个音（C）拼写为 B♯

>>> librosa.key_to_notes('A#:min')
['B♯', 'C♯', 'D', 'D♯', 'E', 'E♯', 'F♯', 'G', 'G♯', 'A', 'A♯', 'B']

G♯:maj 将使用重升号，把第 7 个音（G）拼写为 F𝄪：

>>> librosa.key_to_notes('G#:maj')
['B♯', 'C♯', 'D', 'D♯', 'E', 'E♯', 'F♯', 'F𝄪', 'G♯', 'A', 'A♯', 'B']

F♭:min 将使用重降号

>>> librosa.key_to_notes('Fb:min')
['D𝄫', 'D♭', 'E𝄫', 'E♭', 'F♭', 'F', 'G♭', 'A𝄫', 'A♭', 'B𝄫', 'B♭', 'C♭']

G:loc 使用降号

>>> librosa.key_to_notes('G:loc')
['C', 'D♭', 'D', 'E♭', 'E', 'F', 'G♭', 'G', 'A♭', 'A', 'B♭', 'B']

若 natural=True，则打印还原记号。

>>> librosa.key_to_notes('G:loc', natural=True)
['C', 'D♭', 'D♮', 'E♭', 'E♮', 'F', 'G♭', 'G', 'A♭', 'A♮', 'B♭', 'B♮']
>>> librosa.key_to_notes('D:maj', natural=True)
['C♮', 'C♯', 'D', 'D♯', 'E', 'F♮', 'F♯', 'G', 'G♯', 'A', 'A♯', 'B']
>>> librosa.key_to_notes('G#:maj', unicode = False, natural = True)
['B#', 'C#', 'Dn', 'D#', 'En', 'E#', 'F#', 'F##', 'G#', 'An', 'A#', 'B']

可以与 key_to_degrees 结合，得到给定音阶的音名：

>>> notes = librosa.key_to_notes('D:maj')
>>> degrees = librosa.key_to_degrees('D:maj')
>>> print([notes[d] for d in degrees])
['D', 'E', 'F♯', 'G', 'A', 'B', 'C♯']
