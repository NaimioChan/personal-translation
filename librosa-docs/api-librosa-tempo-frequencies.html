librosa.tempo_frequencies

librosa.tempo_frequencies(n_bins, *, hop_length=512, sr=22050) [源码]

计算与起始点自相关或节拍图矩阵对应的频率（单位为每分钟节拍数）。

参数

参数类型说明
n_binsint > 0

延迟 bin 的数量

hop_lengthint > 0

相邻 bin 之间的采样点数

srnumber > 0

音频采样率

返回值

返回值类型说明
bin_frequenciesndarray [shape=(n_bins,)]

以 BPM 为单位的各 bin 频率向量。

注意

bin_frequencies[0] = +np.inf 对应 0 延迟

示例

获取 384 个 bin（8 秒）节拍图对应的速度频率

>>> librosa.tempo_frequencies(384, sr=22050)
array([      inf,  2583.984,  1291.992, ...,     6.782,
           6.764,     6.747])
