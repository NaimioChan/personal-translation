librosa.lpc

librosa.lpc(y, *, order, axis=-1) [源码]

用 Burg 法求线性预测系数

该函数用 Burg 法估计作用于 y 的 order 阶线性 滤波器的系数。Burg 法是 Yule-Walker 方法的扩展， 两者有时都被称为基于自相关的 LPC 参数 估计。

它遵循 Marple 在引言中所描述的方法与实现思路。 [1] 注：该论文描述的是另一种方法， 此处并未实现，选用它是因为其引言对 Burg 方法有清楚的解释。

[1] Larry Marple. A New Autoregressive Spectrum Analysis Algorithm. IEEE Transactions on Acoustics, Speech, and Signal Processing vol 28, no. 4, 1980.

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

要拟合的时间序列。支持多声道。

orderint > 0

线性滤波器的阶数

axisint

计算系数所沿的轴

返回值

返回值类型说明
anp.ndarray [shape=(…, order + 1)]

LP 预测误差系数，即滤波器的分母多项式。 注意沿指定 axis 的长度为 order+1。

异常

异常说明
ParameterError

  • 若 y 不是 librosa.util.valid_audio 所认可的合法音频

  • 若 order < 1 或不是整数

FloatingPointError

  • 若 y 病态

参见

  • scipy.signal.lfilter

示例

在整段序列上计算 y 的 16 阶 LP 系数

>>> y, sr = librosa.loadx('libri1')
>>> librosa.lpc(y, order=16)

计算 LP 系数，并绘制对原始序列的 LP 估计

>>> import matplotlib.pyplot as plt
>>> import scipy
>>> y, sr = librosa.loadx('libri1', duration=0.020)
>>> a = librosa.lpc(y, order=2)
>>> b = np.hstack([[0], -1 * a[1:]])
>>> y_hat = scipy.signal.lfilter(b, [1], y)
>>> fig, ax = plt.subplots()
>>> ax.plot(y)
>>> ax.plot(y_hat, linestyle='--')
>>> ax.legend(['y', 'y_hat'])
>>> ax.set_title('LP Model Forward Prediction')
