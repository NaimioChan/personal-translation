librosa.yin

librosa.yin(y, *, fmin, fmax, sr=22050, frame_length=2048, hop_length=None, trough_threshold=0.1, center=True, pad_mode='constant') [源码]

使用 YIN 算法估计基频（F0）。

YIN 是一种基于自相关的基频估计方法 [1]。 首先在短的（重叠）音频帧上计算归一化差分函数。 然后在差分函数中选取首个低于 trough_threshold 的极小值，作为信号周期的估计。 最后用抛物线插值对估计的周期加以细化，再转换为对应的频率。

[1] De Cheveigné, Alain, and Hideki Kawahara. “YIN, a fundamental frequency estimator for speech and music.” The Journal of the Acoustical Society of America 111.4 (2002): 1917-1930.

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频时间序列。支持多声道。

fminnumber > 0 [scalar]

最小频率，单位为赫兹。 推荐的最小值为 librosa.note_to_hz('C2')（约 65 Hz）， 不过更低的值也可能可行。

fmaxnumber > fmin, <= sr/2 [scalar]

最大频率，单位为赫兹。 推荐的最大值为 librosa.note_to_hz('C7')（约 2093 Hz）， 不过更高的值也可能可行。

srnumber > 0 [scalar]

y 的采样率，单位为赫兹。

frame_lengthint > 0 [scalar]

帧长，以样本为单位。 默认的 frame_length=2048 在采样率 22050 Hz 下对应约 93 ms 的时间尺度。

hop_lengthNone or int > 0 [scalar]

相邻 YIN 预测之间相隔的音频样本数。 若为 None，默认为 frame_length // 4。

trough_thresholdnumber > 0 [scalar]

峰值估计的绝对阈值。

centerbool

若为 True，信号 y 会被填充，使帧 D[:, t] 以 y[t * hop_length] 为中心。 若为 False，则 D[:, t] 从 y[t * hop_length] 开始。 默认为 True，这样可以借助 librosa.core.frames_to_samples 简化把 D 对齐到时间网格的过程。

pad_modestr or function

若 center=True，该参数会传给 np.pad，用于填充信号 y 的边缘。默认（pad_mode="constant"）下， y 两侧以零填充。 若 center=False，该参数被忽略。 .. see also:: np.pad

返回值

返回值说明
f0: np.ndarray [shape=(…, n_frames)]

基频的时间序列，单位为赫兹。

若输入为多声道，则各通道分别估计各自的 f0 曲线。

参见

  • librosa.pyin：

示例

从音频输入计算基频（F0）曲线

>>> y = librosa.chirp(fmin=440, fmax=880, duration=5.0, sr=22050)
>>> librosa.yin(y, fmin=440, fmax=880, sr=22050)
array([442.66354675, 441.95299983, 441.58010963, ...,
    871.161732  , 873.99001454, 877.04297681])
