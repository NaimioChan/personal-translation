频谱特征

函数说明

chroma_stft

从波形或功率频谱图计算色度图。

chroma_cqt

常数 Q 色度图

chroma_cens

计算色度变体“色度能量归一化”（CENS）

chroma_vqt

可变 Q 色度图

tonnetz

计算音调质心特征（tonnetz）

melspectrogram

计算 mel 刻度频谱图。

mfcc

Mel 倒谱系数（MFCC）

spectral_centroid

计算频谱质心。

spectral_bandwidth

计算 p 阶频谱带宽。

spectral_contrast

计算频谱对比度

spectral_flatness

计算频谱平坦度

spectral_rolloff

计算滚降频率。

poly_features

获取对频谱图各列进行 n 阶多项式拟合的系数。

rms

计算每一帧的均方根（RMS）值。

zero_crossing_rate

计算音频时间序列的过零率。
