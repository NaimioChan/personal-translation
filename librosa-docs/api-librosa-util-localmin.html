librosa.util.localmin

librosa.util.localmin(x, *, axis=0) [源码]

查找数组中的局部极小值

若满足以下条件，则元素 x[i] 视为局部极小值：

  • x[i] < x[i-1]

  • x[i] <= x[i+1]

注意第一个条件是严格不等，且第一个元素 x[0] 永远不会被视为局部极小值。

参数

参数类型说明
xnp.ndarray [shape=(d1,d2,…)]

输入向量或数组

axisint

计算局部极小性所沿的轴

返回值

返回值类型说明
mnp.ndarray [shape=x.shape, dtype=bool]

沿 axis 的局部极小性指示数组

参见

  • localmax

示例

>>> x = np.array([1, 0, 1, 2, -1, 0, -2, 1])
>>> librosa.util.localmin(x)
array([False,  True, False, False,  True, False,  True, False])
>>> # 二维示例
>>> x = np.array([[1,0,1], [2, -1, 0], [2, 1, 3]])
>>> librosa.util.localmin(x, axis=0)
array([[False, False, False],
       [False,  True,  True],
       [False, False, False]])
>>> librosa.util.localmin(x, axis=1)
array([[False,  True, False],
       [False,  True, False],
       [False,  True, False]])
