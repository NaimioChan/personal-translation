librosa.note_to_svara_c

librosa.note_to_svara_c(notes, *, Sa, mela, abbr=True, octave=True, unicode=True) [源码]

把西方音名转换为卡纳提克 svara

注意，此转换假定使用十二平均律。

参数

参数类型说明
notesstr or iterable of str

要转换的音符（例如 ‘C#’ 或 [‘C4’, ‘Db4’, ‘D4’]

Sastr

对应 Sa 的音符（例如 ‘C’ 或 ‘C5’）。

若未提供八度信息，默认取八度 0 （C0 ~= 16 Hz）

melastr or int [1, 72]

melakarta raga 名称或索引

abbrbool

若为 True（默认），返回缩写名称（‘S’、‘R1’、‘R2’、‘G1’、‘G2’、……）

若为 False，返回长格式名称（‘Sa’、‘Ri1’、‘Ri2’、‘Ga1’、‘Ga2’、……）

octavebool

若为 True，在相邻八度的 svara 上添加上点或下点。

若为 False，忽略八度高度信息。

unicodebool

若为 True，使用 Unicode 符号标注八度信息。

若为 False，八度标注使用低位 ASCII（’ 与 ,）。

仅在 octave=True 时生效。

返回值

返回值类型说明
svarastr or np.ndarray of str

给定音符所对应的 svara

参见

示例

>>> librosa.note_to_svara_h(['C4', 'G4', 'C5', 'D5', 'G5'], Sa='C5', mela=1)
['Ṣ', 'P̣', 'S', 'G₁', 'P']
