librosa.hz_to_svara_h

librosa.hz_to_svara_h(frequencies, *, Sa, abbr=True, octave=True, unicode=True) [源码]

把频率（单位 Hz）转换为印度斯坦 svara

注意，此转换假定使用十二平均律。

参数

参数类型说明
frequenciespositive number or np.ndarray

要转换的频率（单位 Hz）

Sapositive number

参照 Sa 的频率（单位 Hz）。

abbrbool

若为 True（默认），返回缩写名称（‘S’、‘r’、‘R’、‘g’、‘G’、……）

若为 False，返回长格式名称（‘Sa’、‘re’、‘Re’、‘ga’、‘Ga’、……）

octavebool

若为 True，在相邻八度的 svara 上添加上点或下点。

若为 False，忽略八度高度信息。

unicodebool

若为 True，使用 Unicode 符号标注八度信息。

若为 False，八度标注使用低位 ASCII（’ 与 ,）。

仅在 octave=True 时生效。

返回值

返回值类型说明
svarastr or np.ndarray of str

给定频率所对应的 svara

参见

  • midi_to_svara_h
  • note_to_svara_h
  • hz_to_svara_c
  • hz_to_note

示例

转换三个八度中的 Sa：

>>> librosa.hz_to_svara_h([261/2, 261, 261*2], Sa=261)
['Ṣ', 'S', 'Ṡ']

用完整名称转换一个八度的频率：

>>> freqs = librosa.cqt_frequencies(n_bins=12, fmin=261)
>>> librosa.hz_to_svara_h(freqs, Sa=freqs[0], abbr=False)
['Sa', 're', 'Re', 'ga', 'Ga', 'ma', 'Ma', 'Pa', 'dha', 'Dha', 'ni', 'Ni']
