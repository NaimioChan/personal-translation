频率单位转换

函数说明

hz_to_note

把一个或多个频率（Hz）转换为最接近的音名。

hz_to_midi

获取给定频率对应的 MIDI 音符号

hz_to_svara_h

把频率（Hz）转换为印度斯坦 svara

hz_to_svara_c

把频率（Hz）转换为卡纳提克 svara

hz_to_fjs

把纯律音阶中的一个或多个频率（Hz）转换为 FJS 记谱法音名。

midi_to_hz

获取 MIDI 音符的频率（Hz）

midi_to_note

把一个或多个 MIDI 号码转换为音名字符串。

midi_to_svara_h

把 MIDI 号码转换为印度斯坦 svara

midi_to_svara_c

把 MIDI 号码转换为给定 melakarta 拉格中的卡纳提克 svara

note_to_hz

把一个或多个音名转换为频率（Hz）

note_to_midi

把一个或多个拼写音名转换为 MIDI 号码。

note_to_svara_h

把西方音名转换为印度斯坦 svara

note_to_svara_c

把西方音名转换为卡纳提克 svara

hz_to_mel

把 Hz 转换为 mel

hz_to_octs

把频率（Hz）转换为（小数）八度数。

mel_to_hz

把 mel 频带序号转换为频率

octs_to_hz

把八度数转换为频率。

A4_to_tuning

把参考音高频率（例如 A4=435）转换为调音估计，单位为每八度的频带分数。

tuning_to_A4

把相对于 0 的调音偏差转换为相对于 A440 的参考音高频率。
