librosa.feature.inverse.mfcc_to_audio

librosa.feature.inverse.mfcc_to_audio(mfcc, *, n_mels=128, dct_type=2, norm='ortho', ref=1.0, lifter=0, **kwargs) [源码]

把 Mel 频率倒谱系数转换为时域音频信号

本函数主要是以下步骤的便捷封装：

  1. 把 mfcc 转换为 mel 功率谱（mfcc_to_mel）

  2. 把 mel 功率谱转换为时域音频（mel_to_audio）

参数

参数类型说明
mfccnp.ndarray [shape=(…, n_mfcc, n)]

Mel 频率倒谱系数

n_melsint > 0

Mel 频率数

dct_type{1, 2, 3}

离散余弦变换（DCT）类型。 默认使用 2 型 DCT。

normNone or ‘ortho’

若 dct_type 为 2 或 3，设置 norm='ortho' 将使用正交归一 DCT 基。 dct_type=1 不支持归一化。

reffloat

（逆）分贝计算的参考功率

lifternumber >= 0
  • 若 lifter>0，施加逆倒谱滤波：：

    M[n, :] <- M[n, :] / (1 + sin(pi * (n + 1) / lifter)) * lifter / 2

**kwargs

传递给 mel_to_audio 的额外关键字参数

Mnp.ndarray [shape=(…, n_mels, n), non-negative]

由 feature.melspectrogram 得到的频谱图

srnumber > 0 [scalar]

底层信号的采样率

n_fftint > 0 [scalar]

中间 STFT 的 FFT 帧长度

hop_lengthNone or int > 0

STFT 的跳距。若未提供，默认为 n_fft // 4

win_lengthNone or int > 0

STFT 的窗长度。默认等于 n_fft

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

窗的规格，需被 stft 或 istft 支持

centerbool

若为 True，假定 STFT 使用居中的帧。 若为 False，假定 STFT 使用左对齐的帧。

pad_modestr

若 center=True，在信号边缘使用的填充模式。 默认情况下，STFT 使用零填充。

powerfloat > 0 [scalar]

幅度 mel 频谱图的指数

n_iterint > 0

Griffin-Lim 的迭代次数

lengthNone or int > 0

若提供，输出的 y 会被补零或裁剪为恰好 length 个采样点。

dtypenp.dtype

时域信号的实数数值类型。默认为 32 位浮点数。

**kwargs

mel 滤波器组参数的额外关键字参数

fminfloat >= 0 [scalar]

最低频率（Hz）

fmaxfloat >= 0 [scalar]

最高频率（Hz）。 若为 None，使用 fmax = sr / 2.0

htkbool [scalar]

使用 HTK 公式代替 Slaney 公式

返回值

返回值类型说明
ynp.ndarray [shape=(…, n)]

由 mfcc 重建的时域信号
