librosa.interval_to_fjs

librosa.interval_to_fjs(interval, *, unison='C', tolerance=1.0317460317460319, unicode=True) [源码]

把音程转换为功能纯律系统（FJS）记法。

FJS 记法体系的完整概述参见 https://misotanni.github.io/fjs/en/index.html， 以及下面的示例。

FJS 转换的做法是：先找出与目标音程在一个给定容差范围内的 毕达哥拉斯音程，由此得到核心音名。 如果该音程并非由纯五度派生，则其余因子会编码为上标 （对于上方（otonal）音程）和下标（对于下方（utonal）音程）。

参数

参数类型说明
intervalfloat > 0 or iterable of floats

要用 FJS 记法书写的（纯律）音程。

unisonstr

同度音的名称（对应 interval=1）。

tolerancefloat

识别核心音名所用的容差阈值。

unicodebool

若为 True（默认），变音记号使用 Unicode 符号（♯𝄪♭𝄫）， 上方与下方变音记号使用上标/下标。

若为 False，变音记号将编码为低位 ASCII 表示：

♯ -> #, 𝄪 -> ##, ♭ -> b, 𝄫 -> bb

上方与下方变音记号分别用 ^## 与 _## 表示（参见下面的示例）。

返回值

返回值类型说明
note_fjsstr or np.ndarray(dtype=str)

相对于给定同度音、以 FJS 记法表示的音程。

异常

异常说明
ParameterError

若提供的音程不为正数

若提供的音程无法用纯律质因数分解 来识别。

示例

毕达哥拉斯音程会按预期出现，不带上方 或下方扩展：

>>> librosa.interval_to_fjs(3/2, unison='C')
'G'
>>> librosa.interval_to_fjs(4/3, unison='F')
'B♭'

托勒密大三度会带上上方的 ‘5’：

>>> librosa.interval_to_fjs(5/4, unison='A')
'C♯⁵'

托勒密小三度则会带上下方的 ‘5’：

>>> librosa.interval_to_fjs(6/5, unison='A')
'C₅'

更复杂的音程会带有复合变音记号。 例如：

>>> librosa.interval_to_fjs(25/14, unison='F#')
'E²⁵₇'
>>> librosa.interval_to_fjs(25/14, unison='F#', unicode=False)
'E^25_7'

也支持数组输入：

>>> librosa.interval_to_fjs([3/2, 4/3, 5/3])
array(['G', 'F', 'A⁵'], dtype='<U2')
