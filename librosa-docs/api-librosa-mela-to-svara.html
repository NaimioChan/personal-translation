librosa.mela_to_svara

librosa.mela_to_svara(mela, *, abbr=True, unicode=True) [源码]

拼写给定 melakarta raga 的卡纳提克 svara 名称

该函数用于解决音级之间的等音 关系：

  • Ri2 / Ga1

  • Ri3 / Ga2

  • Dha2 / Ni1

  • Dha3 / Ni2

对于 raga 之外的 svara，名称的选择会保持前后顺序， 使所有 Ri 都排在所有 Ga 之前，所有 Dha 都排在所有 Ni 之前。

参数

参数类型说明
melastr or int

melakarta raga 的名称或数值索引

abbrbool

若为 True，使用单字母 svara 名称：S、R、G、……

若为 False，使用完整名称：Sa、Ri、Ga、……

unicodebool

若为 True，编号使用 Unicode 符号，例如 Ri₁

若为 False，使用低位 ASCII，例如 Ri1。

返回值

返回值类型说明
svaralist of str

12 个音级各自的 svara 名称。

参见

  • key_to_notes
  • mela_to_degrees
  • list_mela

示例

Melakarta #1（Kanakangi）使用 R1、G1、D1、N1

>>> librosa.mela_to_svara(1)
['S', 'R₁', 'G₁', 'G₂', 'G₃', 'M₁', 'M₂', 'P', 'D₁', 'N₁', 'N₂', 'N₃']

#19（Jhankaradhwani）使用 R2 与 G2，因此第三个 svara 为 Ri：

>>> librosa.mela_to_svara(19)
['S', 'R₁', 'R₂', 'G₂', 'G₃', 'M₁', 'M₂', 'P', 'D₁', 'N₁', 'N₂', 'N₃']

#31（Yagapriya）使用 R3 与 G3，因此第三和第四个 svara 为 Ri：

>>> librosa.mela_to_svara(31)
['S', 'R₁', 'R₂', 'R₃', 'G₃', 'M₁', 'M₂', 'P', 'D₁', 'N₁', 'N₂', 'N₃']

#34（Vagadheeswari）使用 D2 与 N2，因此 Ni1 变为 Dha2：

>>> librosa.mela_to_svara(34)
['S', 'R₁', 'R₂', 'R₃', 'G₃', 'M₁', 'M₂', 'P', 'D₁', 'D₂', 'N₂', 'N₃']

#36（Chalanatta）使用 D3 与 N3，因此 Ni2 变为 Dha3：

>>> librosa.mela_to_svara(36)
['S', 'R₁', 'R₂', 'R₃', 'G₃', 'M₁', 'M₂', 'P', 'D₁', 'D₂', 'D₃', 'N₃']

# You can also query by raga name instead of index:

>>> librosa.mela_to_svara('chalanatta')
['S', 'R₁', 'R₂', 'R₃', 'G₃', 'M₁', 'M₂', 'P', 'D₁', 'D₂', 'D₃', 'N₃']
