librosa.midi_to_note

librosa.midi_to_note(midi, *, octave=True, cents=False, key='C:maj', unicode=True) [源码]

把一个或多个 MIDI 编号转换为音名字符串。

MIDI 编号会四舍五入到最接近的整数。

非有限值（NaN、inf、-inf）将返回空字符串。

音名的格式为 ‘C0’、‘C♯0’、‘D0’、……

参数

参数类型说明
midiint or iterable of int

要转换的 MIDI 编号。

octavebool

若为 True，包含八度编号

centsbool

若为 true，为带小数的音符追加音分标记。 例如 midi_to_note(69.3, cents=True) == 'A4+03'

keystr

解析等音关系时使用的调号。

unicodebool

若为 True（默认），变音记号使用 Unicode 记法：♭ 或 ♯

若为 False，变音记号使用兼容 ASCII 的记法：b 或 #

返回值

返回值类型说明
notesstr or np.ndarray of str

描述各 MIDI 音符的字符串。

异常

异常说明
ParameterError

若 cents 为 True 而 octave 为 False

参见

  • midi_to_hz
  • note_to_midi
  • hz_to_note
  • key_to_notes

示例

>>> librosa.midi_to_note(0)
'C-1'
>>> librosa.midi_to_note(37)
'C♯2'
>>> librosa.midi_to_note(37, unicode=False)
'C#2'
>>> librosa.midi_to_note(-2)
'A♯-2'
>>> librosa.midi_to_note(104.7)
'A7'
>>> librosa.midi_to_note(104.7, cents=True)
'A7-30'
>>> librosa.midi_to_note(np.arange(12, 24)))
array(['C0', 'C♯0', 'D0', 'D♯0', 'E0', 'F0', 'F♯0', 'G0', 'G♯0', 'A0',
       'A♯0', 'B0'], dtype='<U3')

使用调号解析等音关系

>>> librosa.midi_to_note(range(12, 24), key='F:min')
array(['C0', 'D♭0', 'D0', 'E♭0', 'E0', 'F0', 'G♭0', 'G0', 'A♭0', 'A0',
       'B♭0', 'B0'], dtype='<U3')
