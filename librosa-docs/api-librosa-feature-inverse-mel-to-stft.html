librosa.feature.inverse.mel_to_stft

librosa.feature.inverse.mel_to_stft(M, *, sr=22050, n_fft=2048, power=2.0, **kwargs) [源码]

由 mel 功率谱近似得到 STFT 幅度。

参数

参数类型说明
Mnp.ndarray [shape=(…, n_mels, n), non-negative]

由 feature.melspectrogram 得到的频谱图

srnumber > 0 [scalar]

底层信号的采样率

n_fftint > 0 [scalar]

所得 STFT 的 FFT 帧长度；输出有 1 + n_fft // 2 个频率频格

powerfloat > 0 [scalar]

幅度 mel 频谱图的指数

**kwargs

mel 滤波器组参数的额外关键字参数

fminfloat >= 0 [scalar]

最低频率（Hz）

fmaxfloat >= 0 [scalar]

最高频率（Hz）。 若为 None，使用 fmax = sr / 2.0

htkbool [scalar]

使用 HTK 公式代替 Slaney 公式

norm{None, ‘slaney’, or number} [scalar]

若为 ‘slaney’，把三角形 mel 权重除以 mel 频带的宽度（面积归一化）。 若为数值，则用 librosa.util.normalize 把每个滤波器归一化 为单位 l_p 范数。受支持的 norm 取值（包括 +-np.inf）的完整 说明见 librosa.util.normalize。 否则保留所有三角形的峰值为 1.0

dtypenp.dtype

输出基矩阵的数据类型。 默认使用 32 位（单精度）浮点数。

返回值

返回值类型说明
Snp.ndarray [shape=(…, 1 + n_fft // 2, t), non-negative]

近似的线性幅度频谱图

参见

  • librosa.feature.melspectrogram

  • librosa.filters.mel
  • librosa.util.nnls

示例

>>> y, sr = librosa.loadx('trumpet')
>>> S = librosa.util.abs2(librosa.stft(y))
>>> mel_spec = librosa.feature.melspectrogram(S=S, sr=sr)
>>> S_inv = librosa.feature.inverse.mel_to_stft(mel_spec, sr=sr)

直观比较结果

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=3, sharex=True, sharey=True)
>>> img = librosa.display.specshow(S, vscale='dBFS[power]', top_db=None,
...                          y_axis='log', x_axis='time', ax=ax[0])
>>> ax[0].set(title='Original STFT')
>>> ax[0].label_outer()
>>> librosa.display.specshow(S_inv, vscale='dBFS[power]', top_db=None,
...                          y_axis='log', x_axis='time', ax=ax[1])
>>> ax[1].set(title='Reconstructed STFT')
>>> ax[1].label_outer()
>>> librosa.display.specshow(S_inv - S, vscale=f'dB[power,{S.max()}]', top_db=None,
...                          vmax=0, y_axis='log', x_axis='time', ax=ax[2])
>>> ax[2].set(title='Residual error (dB)')
>>> librosa.display.colorbar_db(img, ax=ax)
