librosa.hybrid_cqt

librosa.hybrid_cqt(y, *, sr=22050, hop_length=512, fmin=None, n_bins=84, bins_per_octave=12, tuning=0.0, filter_scale=1, norm=1, sparsity=0.01, window='hann', scale=True, pad_mode='constant', res_type='soxr_hq', dtype=None) [源码]

计算音频信号的混合常数 Q 变换。

这里，混合 CQT 在高频处使用伪 CQT，因为 该处跳距长于滤波器长度的一半，而在低频处使用完整的 CQT。

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

hop_lengthint > 0 [scalar]

相邻 CQT 列之间的采样点数。

fminfloat > 0 [scalar]

最低频率。默认取 C1 ~= 32.70 Hz

n_binsint > 0 or None [scalar]

频率 bin 的数量，从 fmin 开始 若为 None，则 bin 数量推断为在 sr/2 以下能够 容纳的最大数量。

bins_per_octaveint > 0 [scalar]

每个八度的 bin 数量

tuningNone or float

调音偏移，以 bin 的比例表示。

若为 None，将从信号中自动估计调音。

所得 CQT 的最低频率会被调整为 fmin * 2**(tuning / bins_per_octave)。

filter_scalefloat > 0

滤波器的 filter_scale 因子。较大的值会使用更长的窗。

norm{inf, -inf, 0, float > 0}

基函数归一化所使用的范数类型。 参见 librosa.util.normalize。

sparsityfloat in [0, 1)

通过丢弃每个基函数中最多 sparsity 比例的能量来稀疏化 CQT 基函数。

将 sparsity=0 可禁用稀疏化。

windowstr, tuple, number, or function

基滤波器的窗规格。 详见 filters.get_window。

scalebool

若为 True，按每个通道滤波器长度的平方根缩放 CQT 响应。这相当于 FFT 中的 norm='ortho'。

若为 False，则不对 CQT 缩放。这相当于 FFT 中的 norm=None。

pad_modestr

中心化帧分析的填充模式。

另参见：librosa.stft 与 numpy.pad。

res_typestr

重采样模式。详见 librosa.cqt。

dtypenp.dtype, optional

计算 CQT 时使用的复数类型。 默认根据输入信号的精度推断。

返回值

返回值类型说明
CQTnp.ndarray [shape=(…, n_bins, t), dtype=np.float]

每个时刻各频率上的常数 Q 能量。

参见

  • cqt
  • pseudo_cqt

说明

该函数在级别 20 上缓存。
