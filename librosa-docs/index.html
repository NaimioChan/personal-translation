librosa 文档

librosa 是一个用于音频与音乐信号处理的 Python 库。它提供了构建音乐信息检索（MIR）系统所需的基础算法与工具。

安装 librosa

pip

安装 librosa 最简单的方式是通过 Python 包索引（PyPI）。这样可以确保所有必需的依赖都得到满足。执行以下命令即可：

pip install librosa

conda

如果使用 conda/Anaconda 环境，可以从 conda-forge 频道安装 librosa：

conda install -c conda-forge librosa

源码

如果你从 releases 页面手动下载了压缩包，可以用 setuptools 脚本安装：

tar xzf librosa-VERSION.tar.gz
cd librosa-VERSION/
python setup.py install

如果你打算开发 librosa 或修改源代码，可以用 pip install -e 安装，以链接到你正在开发的源码树：

tar xzf librosa-VERSION.tar.gz
cd librosa-VERSION/
pip install -e .

也可以用 pip 安装最新的开发版本：

pip install git+https://github.com/librosa/librosa

引用 librosa

在学术工作中引用 librosa 有两种方式，取决于你是因为在自己的工作中使用了它，还是因为它的设计与动机而引用它。

除引用 librosa 本身之外，我们还建议你引用描述 librosa 所实现方法的原始文献。这些文献通常可以在各函数的文档中找到。

为使用而引用

如果你在自己的工作中使用并引用，请从 Zenodo 获取相应的 DOI 与引用信息，引用你所使用的版本。这样能确保所有贡献者因你所做的工作而获得署名。

也可以在 Python 中运行以下命令，查看当前安装版本的 DOI：

print(librosa.cite())

如果需要论文的 BibTeX 条目，可以运行：

print(librosa.cite(bib=True))

为设计而引用

如果你想因为 librosa 的设计、动机等而引用它，请引用发表在 SciPy 2015 上的 librosa 论文。[1]

[1] McFee, Brian, Colin Raffel, Dawen Liang, Daniel PW Ellis, Matt McVicar, Eric Battenberg, and Oriol Nieto. “librosa: Audio and music signal analysis in python.” In Proceedings of the 14th python in science conference, pp. 18-25. 2015.

作为经验法则：

  • 用带版本号的 librosa 引用，记录实验中所用的软件实现。

  • 引用你所依赖的核心算法对应的原始方法文献。

  • 在讨论 librosa 本身、其设计或它作为软件库的贡献时，引用 SciPy 论文。
