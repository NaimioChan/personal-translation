librosa.griffinlim_cqt

librosa.griffinlim_cqt(C, *, n_iter=32, sr=22050, hop_length=512, fmin=None, bins_per_octave=12, tuning=0.0, filter_scale=1, norm=1, sparsity=0.01, window='hann', scale=True, pad_mode='constant', res_type='soxr_hq', dtype=None, length=None, momentum=0.99, init='random', rng=None, random_state=<DEPRECATED parameter>) [源码]

使用“快速”Griffin-Lim 算法近似地反演常数 Q 幅度频谱图。

给定常数 Q 频谱图的幅度（C），该算法随机初始化 相位估计，然后交替执行正变换与逆 CQT 运算。 [1]

本实现基于针对短时傅里叶变换的（快速）Griffin-Lim 方法 [2]， 但经过改造以适用于常数 Q 频谱图。

[1] D. W. Griffin and J. S. Lim, “Signal estimation from modified short-time Fourier transform,” IEEE Trans. ASSP, vol.32, no.2, pp.236–243, Apr. 1984.

[2] Perraudin, N., Balazs, P., & Søndergaard, P. L. “A fast Griffin-Lim algorithm,” IEEE Workshop on Applications of Signal Processing to Audio and Acoustics (pp. 1–4), Oct. 2013.

滤波器缩放因子。较小的值（<1）会使用更短的窗， 以提高时间分辨率。

norm{inf, -inf, 0, float > 0}

基函数归一化所使用的范数类型。 参见 librosa.util.normalize。

sparsityfloat in [0, 1)

通过丢弃每个基函数中最多 sparsity 比例的能量来稀疏化 CQT 基函数。

基滤波器的窗规格。 详见 filters.get_window。

scalebool

若为 True，按每个通道滤波器长度的平方根缩放 CQT 响应。这相当于 FFT 中的 norm='ortho'。

若为 False，则不对 CQT 缩放。这相当于 FFT 中的 norm=None。

pad_modestr

中心化帧分析的填充模式。

另参见：librosa.stft 与 numpy.pad。

res_typestr

递归降采样所使用的重采样模式。

可用选项列表参见 librosa.resample。

dtypenumeric type

y 的实数数值类型。默认根据 输入 CQT 的精度推断。

lengthint > 0, optional

若提供，输出 y 会被零填充或裁剪到恰好 length 个采样点。

momentumfloat > 0

快速 Griffin-Lim 的动量参数。 将其设为 0 即回到原始的 Griffin-Lim 方法。 接近 1 的取值可以加快收敛，但大于 1 可能不收敛。

initNone or ‘random’ [default]

若为 ‘random’（默认），相位值会依据 random_state 随机初始化。当输入 C 是没有初始相位估计的 幅度频谱图时，建议这样做。

若为 None，则相位由 C 初始化。当可以给出 相位的初始猜测，或希望从之前的输出继续运行 Griffin-Lim 时，这很有用。

rngNone, int, sequence of int, np.random.Generator, or np.random.RandomState

伪随机数生成器的状态。当 rng 为 None 时，会使用操作系统提供的 熵新建一个 numpy.random.Generator。 除 numpy.random.Generator 之外的类型会 传给 numpy.random.default_rng 以实例化 Generator。

random_stateNone, int, np.random.RandomState, or np.random.Generator

警告

该参数在 1.0.0 中已弃用，将在 1.2.0 中移除。

若为 int，random_state 是用于相位初始化的随机数 生成器的种子。

若为 np.random.RandomState 或 np.random.Generator 实例，则直接使用该随机数生成器本身。

若为 None，默认使用 np.random.default_rng() 对象。

若同时提供 rng 与 random_state，则抛出异常。

示例

一个基本的 CQT 反演示例

>>> y, sr = librosa.loadx('trumpet', sr=None)
>>> # Get the CQT magnitude, 7 octaves at 36 bins per octave
>>> C = np.abs(librosa.cqt(y=y, sr=sr, bins_per_octave=36, n_bins=7*36))
>>> # Invert using Griffin-Lim
>>> y_inv = librosa.griffinlim_cqt(C, sr=sr, bins_per_octave=36)
>>> # And invert without estimating phase
>>> y_icqt = librosa.icqt(C, sr=sr, bins_per_octave=36)

绘制结果的波形

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=3, sharex=True, sharey=True)
>>> librosa.display.waveshow(y, sr=sr, color='C0', ax=ax[0])
>>> ax[0].set(title='Original', xlabel=None)
>>> ax[0].label_outer()
>>> librosa.display.waveshow(y_inv, sr=sr, color='C1', ax=ax[1])
>>> ax[1].set(title='Griffin-Lim reconstruction', xlabel=None)
>>> ax[1].label_outer()
>>> librosa.display.waveshow(y_icqt, sr=sr, color='C2', ax=ax[2])
>>> ax[2].set(title='Magnitude-only icqt reconstruction')
