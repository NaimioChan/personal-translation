多声道

本节概述 librosa 如何处理多声道信号。 一句话总结：在 librosa 0.8 之前只支持单声道输入的大多数函数，现在无需任何改动即可支持多声道音频。

维度

讨论多声道之前，先回顾单声道（monaural）信号的处理方式。 Librosa 把一切信号及其派生数据都作为 numpy.ndarray（N 维数组）对象处理。 默认情况下，librosa 加载多声道信号时会把所有通道平均，得到单声道混音。 结果对象是形状为 (N_samples,) 的一维数组，表示样本值的时间序列。 后续处理通常会得到时间序列的更高维变换，例如短时傅里叶变换（librosa.stft）得到形状为 (N_frequencies, N_frames) 的二维数组。 注意第二（末尾）个维度对应信号中的帧数，与长度成正比；第一个维度对应每一帧上测得的频率（或更一般地，特征）数量。

处理多声道信号时，我们可以通过在调用 librosa.load 时指定 mono=False 跳过默认的降混步骤，如下：

import librosa

# Get the "high-quality" multi-channel version of
# an example track
filename = librosa.ex('trumpet', hq=True)

# Load as multi-channel data
y_stereo, sr = librosa.load(filename, mono=False)

此时结果对象有两个维度而不是一个，形状为 y_stereo.shape == (N_channels, N_samples)。 这样，可以用 y_stereo[0] 访问第一个通道，用 y_stereo[1] 访问第二个通道；若通道多于两个，依此类推。

Librosa 按以下通用模式表示数据：

  • 末尾维度对应时间（样本、帧等）

  • 前导维度可对应通道

  • 中间维度对应「特征」（或频率、谐波等）。

该模式的设计目标是：切出单个通道时索引方式保持一致。 下面的示例对此做了演示。

示例

第一个示例：对上面加载的立体声示例信号计算短时傅里叶变换。 做法与信号为单声道时完全相同，即：

D_stereo = librosa.stft(y_stereo)

所得 STFT 的形状为 D_stereo.shape == (N_channels, N_frequencies, N_frames)。 切片 D_stereo[0] 对应第一个通道 y_stereo[0] 的 STFT，D_stereo[1] 是第二个通道 y_stereo[1] 的 STFT，依此类推。

再看一个更进阶的示例：我们可以用 librosa.interp_harmonics 构造多声道谐波频谱图：

S_stereo = np.abs(D_stereo)

# Get the default Fourier frequencies
freqs = librosa.fft_frequencies(sr=sr)

# We'll interpolate the first five harmonics of each frequency
harmonics = [1, 2, 3, 4, 5]

S_harmonics = librosa.interp_harmonics(S_stereo, freqs=freqs, h_range=harmonics)

结果对象现在有四个维度：S_harmonics.shape == (N_channels, N_harmonics, N_frequencies, N_frames)。 如上所述，前导维度对应通道，末尾维度对应时间（帧），中间维度对应派生特征。 这样，索引某个通道（例如用 S_harmonics[1] 取第二个通道）即可得到由该通道导出的整个特征数组，输出形状为 (N_harmonics, N_frequencies, N_frames)。

文档

阅读库文档时，你可能会遇到像 librosa.stft 这样把输入信号参数描述为：

y : np.ndarray [shape=(..., n)], real-valued

这里的 “…” 类似于 Python 的 Ellipsis 对象，在此上下文中充当「0 个或多个维度」的占位符。 这类似于 numpy 用 Ellipsis 在 numpy.ndarray 对象中跳过可变数量的维度。 例如，要从上面的多声道谐波频谱图中切出单独一帧 n，可以写成：

S[:, :, :, n]

或者：

S[..., n]

后者通常更可取，因为它能推广到任意多个前导维度。

凡是把函数描述为接受含 “…” 的形状时，含义是：除非另有说明，输出会保留这些（任意多个）前导维度。

有些函数接受 axis= 参数，用于指定运算所沿的目标轴。 一般约定是，axis=-1（最后一个轴）通常对应「时间」（或样本、帧），而 axis=-2（倒数第二个轴）通常对应「频率」或其他派生特征。

例外

并非 librosa 中所有函数都能自然地推广到多声道数据，不过大多数可以。 同样，有些函数虽然可以推广，但方式可能与你预期的不符。 本节简要说明多声道支持受限之处。

输出为稀疏形式（即帧索引）的检测器，例如节拍跟踪（librosa.beat）和起始点检测（librosa.onset.onset_detect），不支持多声道输入。 这是因为各通道的输出事件数可能不同，因而无法一致地存入 numpy.ndarray 输出对象。

起始点与节拍检测仅在提供 sparse=False 参数时才能处理多声道输入，此时输出的检测结果会编码为（稠密）布尔数组，而不是稀疏的帧索引或时间戳。

由 librosa.segment.recurrence_matrix 计算的自相似矩阵与交叉相似矩阵对多声道支持有限。 这是因为输出对象可能是稀疏数据结构（如 scipy.sparse.csr_array），无法推广到多于两个维度。 这些函数仍接受多声道输入，但在比较不同时间步的特征时会压平前导维度（通道）。 若需要各通道独立的相似矩阵，建议逐通道分别处理。

分解与序列对齐和相似矩阵一样支持有限。 谐波-打击源分离（librosa.decompose.hpss）可以完全接受多声道输入并独立处理，但其他分解函数（librosa.decompose.nn_filter 与 librosa.decompose.decompose）对多声道输入的处理方式有所限制。 librosa.decompose.dtw 与 librosa.decompose.rqa 等序列对齐函数的工作方式与相似矩阵函数类似，会把前导维度视为额外的「特征」维度，并在对齐前予以压平。

显示函数对多声道支持有限。 librosa.display.waveshow 可接受单声道或 2 声道输入，但第二个通道仅在缩小到包络模式时才会用到。 librosa.display.specshow 不接受多声道输入。

进阶用法与注意事项

librosa 对多声道的支持相当灵活。 特别是，你可以把通道组织在两个或更多维度上，尽管单一声道维度是最常见的用法。 例如，若要同时处理一批长度相同的立体声录音，可以把这些信号收集到形状为 y.shape = (N_tracks, N_channels, N_samples) 的数组中。 此时任何派生数据（如上面示例中的频谱图）都会有两个前导维度，第一个对应音轨，第二个对应音轨内的通道。 理论上可以使用任意多个前导维度，但应谨慎以尽量减少内存占用。
