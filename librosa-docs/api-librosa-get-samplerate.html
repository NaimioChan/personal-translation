librosa.get_samplerate

librosa.get_samplerate(path) [源码]

获取给定文件的采样率。

参数

参数类型说明
pathstr, int, soundfile.SoundFile, or file-like

要加载的文件路径。 与 load 中一样，它也可以是整数或可交给 soundfile 处理的 已打开文件句柄。 也可以提供一个已存在的 soundfile.SoundFile 对象。

返回值

返回值类型说明
srnumber > 0

给定音频文件的采样率

示例

获取附带音频文件的采样率

>>> path = librosa.ex('trumpet')
>>> librosa.get_samplerate(path)
22050
