librosa.to_mono

librosa.to_mono(*signals, pad=True, norm=True, out=None) [源码]

通过在各声道上对采样求平均，把音频信号转为单声道。

参数

参数类型说明
*signalsnp.ndarray [shape=(…, n)]

一个或多个待转为单声道的信号。 每个输入信号可以是单声道或多声道，且长度不必全部相同。

padbool

若为 True，把输出补零至最长输入的长度： n_out = max(y.shape[-1] for y in signals)。

若为 False，把输出裁剪至最短输入的长度： n_out = min(y.shape[-1] for y in signals)。

normbool

若为 True（默认），各信号通过求平均合并。

若为 False，各信号通过求和合并。

outnp.ndarray [shape=(n_out,)] or None

预先分配的输出缓冲区。若提供，其形状必须为 (n_out,)，且 dtype 精度不低于结果 dtype； 它会被清零并原地写入后返回，从而避免新分配。若为 None（默认），则分配新数组。

返回值

返回值类型说明
y_mononp.ndarray [shape=(n_out,)]

把全部信号合并成的单一单声道信号。 若提供了 out，返回的就是 out 本身。

参见

  • to_stereo
  • to_multi
  • util.fix_length

说明

输出信号的 dtype 是能容纳所有输入信号的最宽类型。 若输入信号的 dtype 不同，输出会被提升为最宽的类型。

警告

任何多声道输入信号都会先下混为单声道，再与其他信号合并。 这意味着对于多声道输入 y1 与 y2，当 norm=True 时， 下面两种写法一般并不等价：

>>> y_mono = librosa.to_mono(y1, y2)
>>> y_mono = librosa.to_mono(np.vstack((y1, y2)))

示例

下混立体声输入

>>> y, sr = librosa.loadx('trumpet', mono=False)
>>> y.shape
(2, 117601)
>>> y_mono = librosa.to_mono(y)
>>> y_mono.shape
(117601,)

混合三个长度不同的独立单声道输入

>>> y_440 = librosa.tone(440.0, sr=22050, duration=1.0)
>>> y_550 = librosa.tone(550.0, sr=22050, duration=1.5)
>>> y_660 = librosa.tone(660.0, sr=22050, duration=2.0)
>>> y_mono = librosa.to_mono(y_440, y_550, y_660, pad=True)
>>> y_mono.shape
(44100,)
