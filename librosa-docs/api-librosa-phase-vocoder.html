librosa.phase_vocoder

librosa.phase_vocoder(D, *, rate=None, t_out=None, kind='linear', hop_length=<DEPRECATED parameter>, n_fft=<DEPRECATED parameter>) [源码]

相位声码器。给定 STFT 矩阵 D，按 rate 倍加速

基于 [1] 提供的实现。

这是简化实现，主要用于参考和教学。它不尝试处理瞬态，很可能产生许多可听见的伪影。若需更高质量的实现，推荐 RubberBand 库 [2] 及其 Python 封装 pyrubberband。

[1] Ellis, D. P. W. “A phase vocoder in Matlab.” Columbia University, 2002. https://www.ee.columbia.edu/~dpwe/resources/matlab/pvoc/

[2] https://breakfastquay.com/rubberband/

参数

参数类型说明
Dnp.ndarray [shape=(…, n_bins, n_frames), dtype=complex]

STFT 矩阵

ratefloat > 0 [scalar]

加速因子：rate > 1 更快，rate < 1 更慢。 用于恒定速率的时间伸缩。

t_outnp.ndarray [shape=(n_output,)], optional

可选数组，给出每个输出帧对应的输入帧索引（可为分数），用于指定各输出帧对应的输入时刻。取值必须位于 [0, n_frames) 内。 可用于变速率时间伸缩。 若给定，rate 必须为 None。

kindstr

幅度插值方式，如 ‘linear’ 或 ‘nearest’。 受支持选项的完整列表见 scipy.interpolate.interp1d。

hop_lengthint > 0 [scalar] or None

D 相邻列之间的采样点数量。

若为 None，默认取 n_fft//4 = (D.shape[-2]-1)//2

警告

此参数自 1.0 起已弃用，将在 1.1 中移除。当前实现中未使用。

n_fftint > 0 or None

D 中每帧的采样点数量。 默认（None）由 D 的形状推断。 若 D 使用奇数长度窗构造，可在此指定正确的帧长。

警告

此参数自 1.0 起已弃用，将在 1.1 中移除。当前实现中未使用。

返回值

返回值类型说明
D_stretchednp.ndarray [shape=(…, n_bins, t / rate), dtype=complex]

时间伸缩后的 STFT。 变速率伸缩时，输出将有 len(t_out) 帧。

参见

  • pyrubberband

示例

>>> # Play at double speed
>>> y, sr   = librosa.loadx('trumpet')
>>> D       = librosa.stft(y, n_fft=2048, hop_length=512)
>>> D_fast  = librosa.phase_vocoder(D, rate=2.0, hop_length=512)
>>> y_fast  = librosa.istft(D_fast, hop_length=512)
>>> # Or play at 1/3 speed
>>> y, sr   = librosa.loadx('trumpet')
>>> D       = librosa.stft(y, n_fft=2048, hop_length=512)
>>> D_slow  = librosa.phase_vocoder(D, rate=1./3, hop_length=512)
>>> y_slow  = librosa.istft(D_slow, hop_length=512)
