librosa.fft_frequencies

librosa.fft_frequencies(*, sr=22050, n_fft=2048) [源码]

np.fft.rfftfreq 的替代接口

参数

参数类型说明
srnumber > 0 [scalar]

音频采样率

n_fftint > 0 [scalar]

FFT 帧长度

返回值

返回值类型说明
freqsnp.ndarray [shape=(1 + n_fft/2,)]

频率 (0, sr/n_fft, 2*sr/n_fft, ..., sr/2)

示例

>>> librosa.fft_frequencies(sr=22050, n_fft=16)
array([     0.   ,   1378.125,   2756.25 ,   4134.375,
         5512.5  ,   6890.625,   8268.75 ,   9646.875,  11025.   ])
