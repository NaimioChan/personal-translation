librosa.display.waveshow

librosa.display.waveshow(y, *, sr=22050, max_points=11025, axis='time', offset=0.0, marker='', where='post', label=None, transpose=False, mask=None, ax=None, invert=False, invert_color=None, **kwargs) [源码]

在时域中可视化波形。

本函数构建的图会根据绘图视口的时间跨度，在基于原始采样的信号视图（matplotlib.pyplot.step）与信号幅度包络视图（matplotlib.pyplot.fill_between）之间自适应切换。

更具体地说，当图所跨越的时间区间短于 max_points / sr（默认为 1/2 秒）时，使用基于采样的视图；否则使用降采样的幅度包络。 这样做是为了限制视觉元素的复杂度，以保证绘制高效且视觉上易于解读。

使用交互式渲染时（例如在 Jupyter notebook 或 IPython 控制台中），视口的变化（无论来自部件控件还是程序化更新）都会使图自动更新。

注意

可视化立体声波形时，生成幅度包络的方式是上边界取自左声道、下边界取自右声道，因此可能得到纵向不对称的图。

放大到采样视图时，只显示第一个声道。若要在采样级别可视化两个声道，建议分别绘制每个信号。

要把立体声波形显示为两个独立的信号图，见 multiplot。

参数

参数类型说明
ynp.ndarray [shape=(n,) or (2,n)]

音频时间序列（单声道或立体声） 若为立体声，左声道的幅度包络用于图的上半部分，右声道的幅度包络（取负）用于图的下半部分。 若为单声道，信号包络沿轴镜像。

srnumber > 0 [scalar]

y 的采样率（每秒采样点数）

max_pointsint > 0

最多绘制的采样点数。当图覆盖的时间跨度小于 max_points / sr（默认 1/2 秒）时，绘制采样点。

若绘制原始采样会超过 max_points，则改为可视化由 y 的非重叠窗提取的降采样幅度包络。幅度包络的参数经过设定，使最终生成的图不会超过 max_points 帧。

axisstr or None

坐标轴刻度与刻度标记的显示样式。可取值为：

    • ‘time’标记显示为毫秒、秒、分钟或小时。：

      数值以秒为单位绘制。

  • ‘h’：标记显示为小时、分钟和秒。

  • ‘m’：标记显示为分钟和秒。

  • ‘s’：标记显示为秒。

  • ‘ms’：标记显示为毫秒。

  • ‘lag’：同 time，但超过中点部分按负值计。

  • ‘lag_h’：同 lag，但以小时表示。

  • ‘lag_m’：同 lag，但以分钟表示。

  • ‘lag_s’：同 lag，但以秒表示。

  • ‘lag_ms’：同 lag，但以毫秒表示。

  • None、‘none’ 或 ‘off’：隐藏刻度与刻度标记。

offsetfloat

波形图的起始偏移（单位秒）

markerstr

采样值使用的标记符号。（默认：不使用标记）

参见：matplotlib.markers。

where{‘pre’, ‘mid’, ‘post’}

此设置决定波形图和包络图在观测点之间的插值方式。

详见 matplotlib.pyplot.step。

默认：‘post’

labelstr or None

应用于此图的标签字符串。 注意该标签

transposebool

若为 True，波形纵向而非横向显示。

masknp.ndarray [shape=(n,)] or None

若提供，此掩码用于决定显示哪些采样点。 掩码应为与 y（y.shape[-1]）等长的一维布尔数组，其中 True 表示该采样点应显示，False 表示应忽略。

注意

此掩码只被包络显示直接使用，原始采样显示不会被掩码。 mask 参数是供 wavef0 函数使用的，不建议用户直接使用。

axmatplotlib.axes.Axes or None

用于绘制的坐标轴，代替默认的 plt.gca()。

invertbool

若为 True，反转显示的前景与背景，使坐标轴背景着色。 若为 False（默认），则波形显示着色，背景保持不变。

注意

仅当波形显示是坐标轴中唯一的元素时才应使用此选项。

invert_colorstr, tuple, None

若 invert 为 True，此参数指定反转波形显示所用的颜色。 若为 None（默认），颜色设为当前坐标轴的背景色。

**kwargs

传给 matplotlib.pyplot.fill_between 和 matplotlib.pyplot.step 的其他关键字参数。

注意只支持这两个函数共有的参数。

返回值

返回值说明
librosa.display.AdaptiveWaveplot

类型为 librosa.display.AdaptiveWaveplot 的对象

示例

用包络视图绘制单声道波形

>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('choice', duration=10)
>>> fig, ax = plt.subplots(nrows=3, sharex=True)
>>> librosa.display.waveshow(y, sr=sr, ax=ax[0])
>>> ax[0].set(title='Envelope view, mono')
>>> ax[0].label_outer()

或绘制立体声波形

>>> y, sr = librosa.loadx('choice', mono=False, duration=10)
>>> librosa.display.waveshow(y, sr=sr, ax=ax[1])
>>> ax[1].set(title='Envelope view, stereo')
>>> ax[1].label_outer()

或以半透明方式绘制谐波与打击分量

>>> y, sr = librosa.loadx('choice', duration=10)
>>> y_harm, y_perc = librosa.effects.hpss(y)
>>> librosa.display.waveshow(y_harm, sr=sr, color='C1', alpha=0.75, ax=ax[2], label='Harmonic')
>>> librosa.display.waveshow(y_perc, sr=sr, color='C2', alpha=0.75, ax=ax[2], label='Percussive')
>>> ax[2].set(title='Multiple waveforms')
>>> ax[2].legend()
>>> plt.show()

放大图形以显示原始采样值

>>> fig, (ax, ax2) = plt.subplots(nrows=2, sharex=True)
>>> ax.set(xlim=[6.1, 6.25], title='Sample view')
>>> librosa.display.waveshow(y, sr=sr, ax=ax, label='Full signal')
>>> librosa.display.waveshow(y_harm, sr=sr, color='C1', alpha=0.75, ax=ax2, label='Harmonic')
>>> librosa.display.waveshow(y_perc, sr=sr, color='C2', alpha=0.75, ax=ax2, label='Percussive')
>>> ax.label_outer()
>>> ax.legend()
>>> ax2.legend(ncols=2)
>>> plt.show()

绘制转置波形并配合自相似矩阵

>>> fig, ax = plt.subplot_mosaic("hSSS;hSSS;hSSS;.vvv", layout='compressed')
>>> y, sr = librosa.loadx('trumpet')
>>> chroma = librosa.feature.chroma_cqt(y=y, sr=sr)
>>> sim = librosa.segment.recurrence_matrix(chroma, mode='affinity')
>>> librosa.display.specshow(sim, ax=ax['S'], sr=sr,
...                          x_axis='time', y_axis='time',
...                          auto_aspect=False)
>>> ax['S'].label_outer()
>>> ax['S'].sharex(ax['v'])
>>> ax['S'].sharey(ax['h'])
>>> ax['S'].set(title='Self-similarity')
>>> librosa.display.waveshow(y, ax=ax['v'])
>>> ax['v'].label_outer()
>>> ax['v'].set(title='transpose=False')
>>> librosa.display.waveshow(y, ax=ax['h'], transpose=True)
>>> ax['h'].label_outer()
>>> ax['h'].set(title='transpose=True')
>>> plt.show()
