有效使用颜色

本节深入讨论 librosa.display.specshow 如何用颜色表示数据，然后给出一些用颜色制作有效可视化的技巧。

热身：matplotlib 颜色映射

在 matplotlib 中，颜色映射（colormap）告诉显示系统如何把数值转换为屏幕上显示的颜色。这里我们关注用于把数值数据（例如分贝测量值）平滑转换为颜色、没有突兀跳变的连续颜色映射。matplotlib 文档对可用的颜色映射及其预期用途有很好的概述。

librosa.display.specshow 中的颜色映射

虽然 matplotlib 提供了一个通用的默认颜色映射（通常是 viridis），但 librosa.display.specshow 会忽略这个默认值，转而根据所显示数据的类型推断颜色映射。

specshow 区分四类颜色数据，每类使用不同的颜色映射：

  • 顺序数据 → magma

  • 发散数据 → coolwarm

  • 布尔数据 → gray_r

  • 循环数据 → twilight_shifted

前三类可以通过检查数据的统计特征或数值格式自动推断，所用启发式规则如下：

  • 顺序：数据全部为正或全部为负。

  • 发散：数据同时包含正值和负值。

  • 布尔：数据具有 bool 数据类型。

注意，设置 vscale=’dB’（或相关的分贝模式）时总是回退到顺序颜色映射。循环数据从不自动推断，而是通过把 vscale 设为相位模式（例如 phase 或 dphase）来指定。

如果你读过本教程前面的章节，一定已经见过利用这一功能的例子。这里我们在一张图里把四类都展示出来。

import librosa
import numpy as np
from IPython.display import HTML
import matplotlib.pyplot as plt

y, sr = librosa.loadx("pistachio", duration=10, offset=10)
HTML(librosa.util.example_info("pistachio", html=True))

# Compute an STFT (for sequential decibel values and cyclical phase values)
stft = librosa.stft(y)

# Compute spectral differences (for diverging ± values)
diffs = librosa.feature.delta(librosa.amplitude_to_db(np.abs(stft)))

# Compute a recurrence matrix (for boolean values)
rec = librosa.segment.recurrence_matrix(librosa.amplitude_to_db(np.abs(stft)), mode="connectivity")

fig, ax = plt.subplots(2, 2, figsize=(10, 8))

# Draw each of the subplots
i1 = librosa.display.specshow(stft, x_axis="time", y_axis="log", vscale="dBFS", ax=ax[0, 0])
i2 = librosa.display.specshow(stft, x_axis="time", y_axis="log", vscale="dphase", ax=ax[0, 1])
i3 = librosa.display.specshow(diffs, x_axis="time", y_axis="log", ax=ax[1, 0])
i4 = librosa.display.specshow(rec, x_axis="time", y_axis="time", ax=ax[1, 1])

# Add colorbars for each subplot
fig.colorbar(i1)
fig.colorbar(i2)
fig.colorbar(i3)
fig.colorbar(i4)

# Label each subplot
ax[0, 0].set_title("Sequential (dB)")
ax[0, 1].set_title("Cyclic (phase differences)")
ax[1, 0].set_title("Diverging (spectral differences)")
ax[1, 1].set_title("Boolean (Recurrence)")

注意

对于发散数据和布尔数据显示，specshow 还会创建适合该数据类型的归一化对象。这就是为什么发散显示的例子（左下）对于正值和负值似乎具有不对称的刻度，但中性色（灰色）仍然以零为中心。

类似地，布尔显示（右下）会自动量化为只显示两种颜色。

颜色条与颜色条辅助函数

在上面的例子中，我们用 fig.colorbar() 为每个子图添加了颜色条，把不同的颜色与数据中的特定数值对应起来。默认颜色条在许多场合都够用，但 librosa.display 还提供了一些辅助函数，用于创建与所显示数据结合更紧密的颜色条。

例如，librosa.display.colorbar_db 有助于创建以分贝标注的颜色条：

fig, ax = plt.subplots()
img = librosa.display.specshow(stft,
                               vscale="dBFS",
                               x_axis="time",
                               y_axis="log",
                               ax=ax)
librosa.display.colorbar_db(img)

类似地，librosa.display.colorbar_phase 有助于为角度数据（例如相位差）创建颜色条，其位置以 π 的分数标注：

fig, ax = plt.subplots()
img = librosa.display.specshow(stft,
                               vscale="dphase",
                               x_axis="time",
                               y_axis="log",
                               ax=ax)
librosa.display.colorbar_phase(img)

覆盖颜色映射推断

上面列出的默认颜色映射可以通过设置 cmap_seq=、cmap_div=、cmap_bool= 或 cmap_cyclic= 来配置。例如，我们可以用不同的颜色映射重做上面的第一个例子，同时仍然在四类之间自动选择：

cmaps = dict(
    cmap_seq="plasma",
    cmap_div="berlin",
    cmap_bool="spring",
    cmap_cyclic="hsv",
)

fig, ax = plt.subplots(2, 2, figsize=(10, 8))

# Draw each of the subplots
i1 = librosa.display.specshow(stft, x_axis="time", y_axis="log", vscale="dBFS", ax=ax[0, 0], **cmaps)
i2 = librosa.display.specshow(stft, x_axis="time", y_axis="log", vscale="dphase", ax=ax[0, 1], **cmaps)
i3 = librosa.display.specshow(diffs, x_axis="time", y_axis="log", ax=ax[1, 0], **cmaps)
i4 = librosa.display.specshow(rec, x_axis="time", y_axis="time", ax=ax[1, 1], **cmaps)

# Add colorbars for each subplot
fig.colorbar(i1)
fig.colorbar(i2)
fig.colorbar(i3)
fig.colorbar(i4)

# Label each subplot
ax[0, 0].set_title("Sequential (dB)")
ax[0, 1].set_title("Cyclic (phase differences)")
ax[1, 0].set_title("Diverging (spectral differences)")
ax[1, 1].set_title("Boolean (Recurrence)")

如果想绕过自动颜色映射选择，直接设置 cmap= 即可：

fig, ax = plt.subplots()
img = librosa.display.specshow(stft, x_axis="time", y_axis="log", vscale="dBFS", cmap="gray_r", ax=ax)
librosa.display.colorbar_db(img)

最后，如果想绕过自动颜色映射选择、同时仍然使用 matplotlib 配置中的默认颜色映射（不必显式说明它是什么），可以设置 cmap=None。这里的文档环境配置为使用 viridis 作为默认颜色映射：

fig, ax = plt.subplots()
img = librosa.display.specshow(stft, x_axis="time", y_axis="log", vscale="dBFS", cmap=None, ax=ax)
librosa.display.colorbar_db(img)

注意，显式设置 cmap 会覆盖所有自动颜色映射推断和归一化。这主要影响发散数据和布尔数据，但一般来说，推荐用 cmap_seq=、cmap_div=、cmap_bool= 或 cmap_cyclic= 来覆盖默认颜色映射，同时保留自动归一化行为。

高亮

在频谱图上叠加其他绘图元素往往很有用，例如估计的音高轮廓（如我们的基频示例所示）。

这会给配色带来挑战，因为连续数据常用的颜色映射往往占据色彩空间的很大一部分，剩下可用于突出显示、通常显眼的颜色很少。

为解决这个问题，librosa.display 提供了一个通用辅助函数 librosa.display.highlight，它会给绘图元素添加高亮或阴影，使其在背景图像上更显眼。highlight 能自动检测背景主要以浅色还是深色为主，并据此选择形成对比的阴影或高亮颜色。

例如，我们可以把同一份频谱图数据分别以深色和浅色模式绘制，并在两种情况下都轻松地高亮一条线元素：

fig, ax = plt.subplots(2, 1, figsize=(10, 8), sharex=True, sharey=True)

librosa.display.specshow(stft, x_axis="time", y_axis="log", vscale="dBFS", ax=ax[0], cmap_seq="magma")
ax[0].set_title("Dark background")

line1 = ax[0].axhline(1000, color="C0", label="1000 Hz", linewidth=3)

hl2 = librosa.display.highlight(artist=line1, linewidth=6)  # Add a highlight

librosa.display.specshow(stft, x_axis="time", y_axis="log", vscale="dBFS", ax=ax[1], cmap_seq="magma_r")
ax[1].set_title("Light background")

line2 = ax[1].axhline(1005, color="C1", label="1005 Hz", linewidth=3)

hl2 = librosa.display.highlight(artist=line2, linewidth=6)  # Add a shadow

fig.legend(loc="center right")

小结

librosa.display.specshow 内置支持根据所显示数据的类型自动选择颜色映射。display 模块还提供了一些辅助函数，用于创建颜色条和高亮绘图元素。所有这些功能都高度可配置，并且设计上与 matplotlib 良好配合，以支持简单地构造清晰有效的显示。
