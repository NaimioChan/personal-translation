librosa.util.dtype_r2c

librosa.util.dtype_r2c(d, *, default=<class 'numpy.complex64'>) [源码]

查找与实数 dtype 对应的复数 numpy dtype。

该函数用于在由实值数据构造复数组时（例如在傅里叶变换中） 保持数值精度与内存占用。

float32（单精度）类型对应 complex64， 而 float64（双精度）对应 complex128。

参数

参数类型说明
dnp.dtype

要转换为复数类型的实值 dtype。 若 d 本身已是复数类型，则原样返回。

defaultnp.dtype, optional

当 d 不匹配已知 dtype 时使用的默认复数目标类型

返回值

返回值类型说明
d_cnp.dtype

复数 dtype

参见

  • dtype_c2r
  • numpy.dtype

示例

>>> librosa.util.dtype_r2c(np.float32)
dtype('complex64')
>>> librosa.util.dtype_r2c(np.int16)
dtype('complex64')
>>> librosa.util.dtype_r2c(np.complex128)
dtype('complex128')
