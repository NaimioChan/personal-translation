librosa.filters.window_sumsquare

librosa.filters.window_sumsquare(*, window, n_frames, hop_length=512, win_length=None, n_fft=2048, dtype=<class 'numpy.float32'>, norm=None) [源码]

计算窗函数在给定跳距下的平方和包络。

这用于估计短时傅里叶变换中对观测加窗所引起的调制效应。

参数

参数类型说明
windowstr, tuple, number, callable, or list-like

窗的规格，同 get_window

n_framesint > 0

分析帧的数量

hop_lengthint > 0

相邻帧之间前进的样本数

win_length[optional]

窗函数的长度。 默认与 n_fft 相同。

n_fftint > 0

每个分析帧的长度。

dtypenp.dtype

输出的数据类型

norm{np.inf, -np.inf, 0, float > 0, None}

构造窗时所用的归一化模式。 注意这不会影响平方运算。

返回值

返回值类型说明
wssnp.ndarray, shape=``(n_fft + hop_length * (n_frames - 1))``

窗函数的平方和包络

示例

固定帧长（2048）时，比较 Hann 窗在不同跳距下的调制效应：

>>> n_frames = 50
>>> wss_256 = librosa.filters.window_sumsquare(window='hann', n_frames=n_frames, hop_length=256)
>>> wss_512 = librosa.filters.window_sumsquare(window='hann', n_frames=n_frames, hop_length=512)
>>> wss_1024 = librosa.filters.window_sumsquare(window='hann', n_frames=n_frames, hop_length=1024)
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=3, sharey=True)
>>> ax[0].plot(wss_256)
>>> ax[0].set(title='hop_length=256')
>>> ax[1].plot(wss_512)
>>> ax[1].set(title='hop_length=512')
>>> ax[2].plot(wss_1024)
>>> ax[2].set(title='hop_length=1024')
