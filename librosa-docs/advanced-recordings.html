示例文件

librosa 附带少量示例录音，主要用于演示库中的各种函数。 从 0.8 版开始，这些示例会在请求时从远程服务器自动获取。 示例录音在首次请求后会缓存在本地，因此每个文件只应下载一次。

直接下载文件

若想确保示例数据始终存在于你的计算机上，可以直接克隆数据仓库：

$ git clone https://github.com/librosa/data.git /path/to/librosa-data

为确保 librosa 能找到示例文件，可以在导入 librosa 之前设置 LIBROSA_DATA_DIR 环境变量：

$ export LIBROSA_DATA_DIR=/path/to/librosa-data/audio
$ python my_librosa_script.py

或者直接在 Python 中设置：

>>> import os
>>> os.environ['LIBROSA_DATA_DIR'] = '/path/to/librosa-data/audio'
>>> import librosa

这样会绕过一切远程网络访问，直接使用数据文件的本地副本。

示例说明

函数 librosa.util.list_examples() 为每首曲子提供简要说明，librosa.util.example_info() 则给出给定曲目的若干元数据与许可信息。

下表更详细地说明这些录音是什么，以及它们在文档中主要用于什么。 Key 指调用 librosa.example() 时用于标识曲目的描述符。
