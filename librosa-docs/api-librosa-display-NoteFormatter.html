librosa.display.NoteFormatter

class librosa.display.NoteFormatter(octave=True, major=True, key='C:maj', unicode=True) [源码]

音符的刻度格式化器

参数

参数类型说明
octavebool

若为 True，在音名之后一并显示八度编号。

否则只显示音名（及音分偏差）

majorbool

若为 True，刻度始终带标签。

若为 False，仅当跨度小于 2 个八度时刻度才带标签

keystr

用于确定音高拼写的调。

unicodebool

若为 True，变音记号使用 unicode 符号。

若为 False，变音记号使用 ASCII 符号。

参见

  • LogHzFormatter
  • matplotlib.ticker.Formatter
