librosa.display.SvaraFormatter

class librosa.display.SvaraFormatter(Sa, octave=True, major=True, abbr=False, mela=None, unicode=True) [源码]

Swara 的刻度格式化器

参数

参数类型说明
Sanumber > 0

Sa 的频率（单位 Hz）

octavebool

若为 True，在音名之后一并显示八度编号。

否则只显示音名（及音分偏差）

majorbool

若为 True，刻度始终带标签。

若为 False，仅当跨度小于 2 个八度时刻度才带标签

abbrbool

若为 True，使用 swara 名称的缩写。

若为 False，使用完整的 swara 名称。

melastr or int

对于 Carnatic swara，指定相应 melakarta raga 的索引或名称

要使用 Hindustani swara，请设 mela=None

unicodebool

若为 True，变音记号使用 unicode 符号。

若为 False，变音记号使用 ASCII 符号。
