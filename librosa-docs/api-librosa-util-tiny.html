librosa.util.tiny

librosa.util.tiny(x) [源码]

计算与输入数据类型对应的极小值。

这是 x.dtype（例如 float32）所能表示的最小的「可用」数。

这主要用于确定除法或乘法运算中发生数值下溢的阈值。

参数

参数类型说明
xnumber (real or complex) or np.ndarray

用于计算极小值的数组。 这里真正相关的只有 x.dtype

返回值

返回值类型说明
tiny_valuefloat

x 所属类型的最小正可用数。 若 x 为整数类型，则改为返回 np.float32 的极小值。

参见

  • numpy.finfo

示例

标准双精度浮点数：

>>> librosa.util.tiny(1.0)
2.2250738585072014e-308

或显式指定为双精度

>>> librosa.util.tiny(np.asarray(1e-5, dtype=np.float64))
2.2250738585072014e-308

或复数

>>> librosa.util.tiny(1j)
2.2250738585072014e-308

单精度浮点数：

>>> librosa.util.tiny(np.asarray(1e-5, dtype=np.float32))
1.1754944e-38

整数

>>> librosa.util.tiny(5)
1.1754944e-38
