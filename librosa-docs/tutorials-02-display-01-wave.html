可视化音频波形

本节介绍在 librosa 中可视化音频波形的主要方式。

我们在可视化什么？

正如我们在简介部分看到的，音频信号的波形是一串采样值，表示气压如何随时间变化。 一种自然的可视化方式，就是用 matplotlib 中的常规绘图工具，把采样值绘制为时间或采样索引的函数。

注意

librosa 的全部显示功能都构建在 matplotlib 之上，我们 假定你对其有一定程度的熟悉。如果你完全没有用 matplotlib 绘过图，也许可以先看看 matplotlib 用户指南。

import numpy as np
import librosa
import matplotlib.animation as animation
import matplotlib.pyplot as plt
from IPython.display import HTML

# Load the trumpet example at its native sampling rate
y, sr = librosa.loadx("trumpet", sr=None)
HTML(librosa.util.example_info("trumpet", html=True))

这幅图是个合理的起点，但它掩盖了一个重要细节： 横轴是采样索引，而不是时间。 只要在绘图前把采样索引换算为时间值，就能轻易修正：

fig, ax = plt.subplots()
times = np.arange(len(y)) / sr  # Calculate sample times
ax.plot(times, y)
ax.set(title="Trumpet example", xlabel="Time (s)")

现在我们有了可解释的时间轴，用自然单位绘图也更容易把数据在多个显示之间对应起来，我们在本教程后面的部分会看到这一点。 我们还能从信号中辨别出一些信息，主要是关于时序和幅度的。 当信号相对短而简单时（例如像我们的小号示例这样的单音），这样做效果足够好，但更长、更复杂的信号会带来几个困难：

  1. 可视化会被信号中最大的峰值所主导，而且

  2. 由于采样点数量很多，绘图本身在计算上变得很重。

为了说明这一点，我们来载入一个更长的示例。

y, sr = librosa.loadx("nutcracker", sr=None)

现在要在图中识别出有意义的视觉结构就难多了。 交互式操作（例如使用 Jupyter / IPython 的交互式绘图）也慢得多。

为了解决这些问题，librosa 提供了几个专为波形可视化设计的显示例程。

Waveshow

librosa 中绘制波形的主要显示函数是 librosa.display.waveshow。它为我们处理时间轴换算和装饰， 但更重要的是，它实现了一种自适应包络绘制算法，在保留图形视觉内容的同时降低了显示的复杂度。

在底层，waveshow 会把信号汇总为一条幅度包络，既保留整体形状，又减少需要绘制的数据量。

我们来把它和上面直接绘图的做法比较一下。

fig, ax = plt.subplots(nrows=2)
times = np.arange(len(y)) / sr  # Calculate sample times again
ax[0].plot(times, y)
ax[0].set(title=f"Direct plot, {len(y)} samples", xlabel="Time (s)")

librosa.display.waveshow(y, sr=sr, ax=ax[1])
ax[1].set(title="Waveshow plot")

两幅图的整体结构相似，但 waveshow 更容易看清一些更细的细节。

更重要的是，waveshow 的图高效得多，因为它只绘制幅度包络，而不是每一个单独的采样。

放大之后，waveshow 仍然保留细节。 在大尺度上它显示包络；在小尺度上，它会自动切换为可见区域内的全分辨率采样。

我们来看一个例子，把完整的图与 waveshow 的图并排比较。

y, sr = librosa.loadx("trumpet")

times = np.arange(len(y)) / sr

fig, ax = plt.subplots()
# Add some line styling and zordering so that the two plots are distinguishable
ax.plot(times, y, label="Direct plot", linewidth=2, linestyle="-.", zorder=1)
librosa.display.waveshow(y, sr=sr, ax=ax, label="Waveshow plot", alpha=0.5)
ax.legend(loc="upper left")

# We'll zoom in to the middle of the track +- 0.001 seconds
t_mid = len(y)/sr * 0.5

n_frames = 200
window = np.geomspace(t_mid, 0.001, num=n_frames)

def _update(delta):
    """Update the plot for each frame."""
    # The `delta` parameter tells us how far in to
    # zoom the display around the middle time point
    ax.set(xlim=[t_mid - delta, t_mid + delta])
    return None

ani = animation.FuncAnimation(fig,
                              func=_update,
                              frames=window,
                              repeat=False,
                              interval=1000/30)

的确，放大之后两幅图是相同的。 此外，你可能注意到，在缩小和放大的例子之间，时间轴会自适应地格式化为便于人阅读的时间单位。 这由 waveshow（以及所有在类似时间轴上的 librosa 显示函数）自动完成，但可以通过设置 axis 参数轻易覆盖。

风格化显示

音频信号的另一种常见视觉惯用法，是用竖条而不是连续曲线来表示幅度 包络。这本质上是一种审美选择，但它有助于生成视觉上更简洁的图， 很适合用于演示或示意图，尤其是在处理较短的示例信号时。

我们可以用 librosa.display.wavebars 来完成这件事。它使用与 waveshow 大体相同的 底层逻辑，但没有自适应的分辨率切换。

fig, ax = plt.subplots(nrows=3)
times = np.arange(len(y)) / sr
ax[0].plot(times, y)
ax[0].set(title=f"Direct plot, {len(y)} samples", xlabel="Time (s)")

librosa.display.waveshow(y, sr=sr, ax=ax[1])
ax[1].set(title="Waveshow plot")

librosa.display.wavebars(y, sr=sr, ax=ax[2])
ax[2].set(title="Wavebars plot")

反色显示

在 waveshow 和 wavebars 中，图形的背景都留空，由带颜色的元素表示信号。 这是科学绘图中常见的视觉策略，尤其在多个信号可能叠加在同一坐标轴上时。 不过，在展示多个信号时，这可能变得难以用视觉分辨，而空白区域本可以派上更好的用场。 许多数字音频工作站（DAW）通过在各自的图形坐标轴上渲染信号，并填充背景色而不是前景色来标识信号，从而解决这个问题。

waveshow 和 wavebars 函数都通过把 invert 参数设为 True 来支持这种风格的显示。 例如，我们可以按如下方式可视化立体声信号的左右声道：

y, sr = librosa.loadx("nutcracker", mono=False)

fig, ax = plt.subplots(nrows=2, sharex=True)
librosa.display.waveshow(y[0], sr=sr, ax=ax[0], invert=True, color="C0")
ax[0].set(ylabel="Left channel")
librosa.display.waveshow(y[1], sr=sr, ax=ax[1], invert=True, color="C1")
ax[1].set(ylabel="Right channel", xlabel="Time (s)")
ax[0].label_outer()  # Hide x-axis decoration on the top plot

小结

在实践中，waveshow 通常是波形显示的最佳默认选择。 当你明确想要采样级的控制时使用直接绘图，而当更合适的是简化、风格化的视图时使用 wavebars。
