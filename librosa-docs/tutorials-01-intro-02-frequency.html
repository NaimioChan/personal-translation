频率与时频分析

本节演示如何计算并可视化音频信号的频率内容，以及如何计算频谱图以观察频率内容随时间的变化。

傅里叶分析

上一节中，我们了解了如何加载音频信号并绘制其波形。这是信号的时域表示：我们看到气压（对模拟录音而言是电压）如何随时间变化。分析信号的另一种方式是考察它的频率内容。这通过傅里叶变换完成，它把信号分解为不同频率正弦波之和。傅里叶变换不把信号表示为随时间的采样值序列，而是表示为一组正弦波，每个正弦波都有特定的幅度与相位偏移，它们叠加起来构成原信号。

离散傅里叶变换（DFT）由 numpy 或 scipy 中实现的快速傅里叶变换算法（FFT）计算：

import numpy as np
import librosa
from IPython.display import HTML

y, sr = librosa.loadx("trumpet")

y_dft = np.fft.fft(y)

DFT 的结果是一个复值数组，长度与输入信号相同。复数的模给出每个频率正弦波的幅度，辐角给出相位偏移。

print("Time-domain shape: ", y.shape)
print("DFT shape: ", y_dft.shape)
print("DFT data type: ", y_dft.dtype)
Time-domain shape:  (117601,)
DFT shape:  (117601,)
DFT data type:  complex64

一般来说，DFT 产生的频率个数总是与输入信号的采样数相同。DFT 测得的频率覆盖 [-sr/2, +sr/2] Hz 的范围。我们可以绘制傅里叶变换的幅度来展示信号的频率内容。要正确绘制，需要知道 DFT 计算中用到哪些频率。这由 np.fft.fftfreq 函数提供。该函数以 DFT 的长度以及采样周期（采样率的倒数）为参数，返回与 DFT 输出相对应的频率数组。

frequencies = np.fft.fftfreq(len(y), d=1 / sr)

现在可以把傅里叶变换的幅度对频率作图，看看信号里有什么内容。我们把时域信号画在频率图上方以便对照。

import matplotlib.pyplot as plt

fig, ax = plt.subplots(nrows=2)
librosa.display.waveshow(y, sr=sr, ax=ax[0])
ax[0].set(title="Time-domain")
ax[1].plot(frequencies, np.abs(y_dft), color="C1")
ax[1].set(title="Frequency domain",
          xlabel="Frequency (Hz)",
          ylabel="Magnitude")

频率域图中有几点值得注意：

  1. 频率范围从 -11025 到 +11025 Hz。

  2. 图围绕 0 Hz 对称。

  3. 图中没有任何信息表明某个频率在信号的何处出现：幅度是在整个信号上聚合得到的。

如果你初次接触，“负频率”这个概念可能令人困惑。不深入技术细节地说，当输入信号是实值（数字音频录音即是如此）时，表示信号所需的全部信息都包含在非负频率范围内。这就是频率域幅度图在水平方向上对称的原因。

处理音频信号时，通常只考虑非负频率，以至于大多数 FFT 实现都提供了只测量这些频率的简化函数。这通常称为 rfft（实数输入 FFT）。不要混淆：rfft 函数的输出仍然是复值的，只是不计算负频率成分。

y_rfft = np.fft.rfft(y)
frequencies_rfft = np.fft.rfftfreq(len(y), d=1 / sr)

fig, ax = plt.subplots()
ax.plot(frequencies_rfft, np.abs(y_rfft), color="C1")
ax.set(title="Frequency domain (non-negative frequencies)",
       xlabel="Frequency (Hz)",
       ylabel="Magnitude")

rfft 的结果中频率个数约为完整 DFT 的一半，且频率都是非负的：

print("Full FFT shape: ", y_dft.shape)
print("Full FFT data type: ", y_dft.dtype)
print("RFFT shape: ", y_rfft.shape)
print("RFFT data type: ", y_rfft.dtype)
print("Frequencies: ", frequencies_rfft)

时变分析

上面第三点值得进一步探讨。对于大多数有意思的音频信号，与每个可听频率相关的能量并非始终不变。相反，某个特定频率的幅度会在某些时刻较高（例如该频率上有一个音符正在发声），在其他时刻则较低。

DFT 确实编码了表示与重构数字信号所需的全部信息，但这并不意味着得到的表示必然直观或易于直接解读。

这时时变表示的思路就有了用处。与其一次分析整个信号，通常更有效的做法是把信号切成短片段（通常称为帧）分别分析。做法有很多，最常用的一种称为短时傅里叶变换（STFT）。

librosa 通过 librosa.stft 函数实现：

stft = librosa.stft(y)

librosa.stft 函数的输出现在是一个二维数组。第一维对应频率，第二维对应帧索引。

print(stft.shape)
(1025, 230)

默认情况下，librosa.stft 使用 n_fft=2048 个采样的帧长，以及 512 个采样的跳距。这意味着 stft 数组的每一列对应输入信号的一个 2048 采样窗，相邻列之间偏移 512 个采样。在默认采样率 22050 Hz 下换算为时间，即帧长 93 ms、跳距 23 ms。随后每帧用 DFT 分析（使用 np.fft.rfft），得到 n_fft // 2 + 1 = 1025 个频率。具体测得的频率可以像上面那样用 np.fft.rfftfreq 函数计算，也可以使用 librosa.fft_frequencies 函数：

frequencies_stft = librosa.fft_frequencies(sr=sr, n_fft=2048)
print(frequencies_stft)
[    0.       10.767    21.533 ... 11003.467 11014.233 11025.   ]

按照一般惯例，librosa 中数组的尾部维度对应时间（以采样或帧为单位）。因此 stft[:, t] 是信号在第 t 帧的频率内容，而 stft[f, :] 是频率 f 的时间演变。要在帧索引与时间之间转换，librosa 提供了 librosa.frames_to_time 函数：

frame_times = librosa.frames_to_time(np.arange(stft.shape[1]), sr=sr, hop_length=512)
print(frame_times)

frame_times = librosa.times_like(stft, sr=sr, hop_length=512)
print(frame_times)

频谱图

正如上一节所见，音频数据作为一串数字难以理解，但可视化后就容易多了。stft 这类时频表示也是如此。可视化音频信号时频内容最常见的方法，是把 STFT 的幅度画成二维图像，横轴对应时间，纵轴对应频率，每个像素的颜色对应该时间与频率处 STFT 的幅度。这称为频谱图。

librosa 提供了 librosa.display.specshow 函数来绘制频谱图。我们来画出前面加载的小号信号的频谱图，并附上它的波形以便对照。

fig, ax = plt.subplots(nrows=2, sharex=True)
img = librosa.display.specshow(stft, vscale="dBFS",
                               sr=sr, hop_length=512, x_axis="time", y_axis="hz", ax=ax[0])
librosa.display.colorbar_db(img, label="dBFS")
ax[0].set(title="Spectrogram")
ax[0].label_outer()
librosa.display.waveshow(y, sr=sr, ax=ax[1])
ax[1].set(title="Time-domain")

注意

vscale=’dBFS’ 参数用于把频谱图的颜色按相对于满刻度的分贝数（dBFS）缩放，即所有值都相对于频谱图中的最大值来缩放。

为便于对照，音频嵌入在下方。听一听这个示例，试着跟上上面的波形图与频谱图。

from IPython.display import Audio
Audio(url=librosa.example("trumpet", url=True))


  • 这个例子中有几点需要注意：

    1. 只绘制了 STFT 的幅度。相位信息通常不做可视化。这由 np.abs(stft) 完成，正如上面绘制信号频率内容时那样。

    2. 幅度用 librosa.amplitude_to_db 函数转换为分贝，使图在视觉上更易解读。

与上面的波形图不同，频谱图展示了信号的频率内容如何随时间变化，对应小号上吹奏的不同音符。重要的是，即使对于这样一个简单的单音信号，频谱图也揭示了波形中不明显的许多复杂性，例如谐波结构（正在发声的基频整数倍处的能量）。

小结

本节中，我们了解了如何计算音频信号的傅里叶变换以分析其频率内容。也了解了如何计算频谱图以可视化信号频率内容随时间的变化。

STFT 这类时频表示是 librosa 提供的许多分析工具的核心，并用于后续章节中的许多示例。

关于如何可视化频谱图数据的更多细节，请参阅显示教程的 频谱图 一节。
