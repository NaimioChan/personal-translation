时频表示

函数说明

stft

短时傅里叶变换（STFT）。

istft

逆短时傅里叶变换（ISTFT）。

reassigned_spectrogram

时频重分配频谱图。

cqt

计算音频信号的常数 Q 变换。

icqt

计算逆常数 Q 变换。

hybrid_cqt

计算音频信号的混合常数 Q 变换。

pseudo_cqt

计算音频信号的伪常数 Q 变换。

vqt

计算音频信号的可变 Q 变换。

iirt

使用 IIR 滤波器的时频表示

fmt

快速 Mellin 变换（FMT）

lpc

基于 Burg 方法的线性预测系数

phase_vocoder

相位声码器。
