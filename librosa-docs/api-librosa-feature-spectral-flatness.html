librosa.feature.spectral_flatness

librosa.feature.spectral_flatness(*, y=None, S=None, n_fft=2048, hop_length=512, win_length=None, window='hann', center=True, pad_mode='constant', amin=1e-10, power=2.0) [源码]

计算频谱平坦度

频谱平坦度（又称音调系数）是一种度量，用于 量化声音有多大程度像噪声，而不是像 音调 [1]。频谱平坦度高（接近 1.0） 表示频谱与白噪声相似。 它常被转换为分贝。

[1] Dubnov, Shlomo “Generalization of spectral flatness measure for non-gaussian linear processes” IEEE Signal Processing Letters, 2004, Vol. 11.

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频时间序列。支持多声道。

Snp.ndarray [shape=(…, d, t)] or None

（可选）预先计算好的频谱图幅度

n_fftint > 0 [scalar]

FFT 帧长度

hop_lengthint > 0 [scalar]

STFT 的跳距。详见 librosa.stft。

win_lengthint <= n_fft [scalar]

每一帧音频都用 window() 加窗。 窗的长度为 win_length，随后补零 至 n_fft 长度。 若未指定，默认为 win_length = n_fft。

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

  • 窗的规格（字符串、元组或数值）； 见 scipy.signal.get_window

  • 窗函数，例如 scipy.signal.windows.hann

  • 长度为 n_fft 的向量或数组

centerbool

  • 若为 True，则对信号 y 进行填充，使帧 t 以 y[t * hop_length] 为中心。

  • 若为 False，则帧 t 起始于 y[t * hop_length]

pad_modestr

若 center=True，在信号边缘使用的填充模式。 默认情况下，STFT 使用零填充。

aminfloat > 0 [scalar]

S 的最小阈值（即为保证数值稳定性而叠加的噪声底限）

powerfloat > 0 [scalar]

幅度频谱图的指数。 例如，1 表示能量，2 表示功率，等等。 计算频谱平坦度通常使用功率谱。

返回值

返回值类型说明
flatnessnp.ndarray [shape=(…, 1, t)]

每一帧的频谱平坦度。 返回值在 [0, 1] 范围内，且常被转换为 dB 标度。

示例

由时间序列输入

>>> y, sr = librosa.loadx('trumpet')
>>> flatness = librosa.feature.spectral_flatness(y=y)
>>> flatness
array([[0.001, 0.   , ..., 0.218, 0.184]], dtype=float32)

由频谱图输入

>>> S, phase = librosa.magphase(librosa.stft(y))
>>> librosa.feature.spectral_flatness(S=S)
array([[0.001, 0.   , ..., 0.218, 0.184]], dtype=float32)

由功率谱输入

>>> S, phase = librosa.magphase(librosa.stft(y))
>>> S_power = S ** 2
>>> librosa.feature.spectral_flatness(S=S_power, power=1.0)
array([[0.001, 0.   , ..., 0.218, 0.184]], dtype=float32)
