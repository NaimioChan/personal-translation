librosa.hz_to_midi

librosa.hz_to_midi(frequencies) [源码]

获取给定频率对应的 MIDI 音符号

参数

参数类型说明
frequenciesfloat or np.ndarray [shape=(n,), dtype=float]

要转换的频率

返回值

返回值类型说明
note_numsnumber or np.ndarray [shape=(n,), dtype=float]

frequencies 对应的 MIDI 音符

参见

  • midi_to_hz
  • note_to_midi
  • hz_to_note

示例

>>> librosa.hz_to_midi(60)
34.506
>>> librosa.hz_to_midi([110, 220, 440])
array([ 45.,  57.,  69.])
