librosa.util.sync

librosa.util.sync(data, idx, *, aggregate=None, pad=True, axis=-1) [源码]

在指定的边界之间对多维数组做聚合。

注意

为确保完全覆盖，可能会向 idx 中添加边界点。

若要把特征矩阵与节拍跟踪器的输出同步，请确认帧索引编号已正确对齐且使用相同的跳距。

参数

参数类型说明
datanp.ndarray

多维特征数组

idxsequence of ints or slices

有序的边界索引数组，或可迭代的切片对象集合。

aggregatefunction

聚合函数（默认：np.mean）

padbool

若为 True，idx 会被补齐以覆盖完整范围 [0, data.shape[axis]]

axisint

聚合数据所沿的轴

返回值

返回值类型说明
data_syncndarray

data_sync 的维度与 data 相同，但 axis 方向的坐标会按 idx 缩减。

例如，axis=-1 的二维 data 应满足：

data_sync[:, i] = aggregate(data[:, idx[i-1]:idx[i]], axis=-1)

异常

异常说明
ParameterError

若索引集合的类型不一致（要么全是切片，要么全是整数）

说明

本函数在层级 40 缓存。

示例

节拍同步的 CQT 频谱图

>>> y, sr = librosa.loadx('choice')
>>> tempo, beats = librosa.beat.beat_track(y=y, sr=sr, trim=False)
>>> C = np.abs(librosa.cqt(y=y, sr=sr))
>>> beats = librosa.util.fix_frames(beats)

默认使用均值聚合

>>> C_avg = librosa.util.sync(C, beats)

用中位数聚合代替均值

>>> C_med = librosa.util.sync(C, beats,
...                              aggregate=np.median)

或者做子节拍同步

>>> sub_beats = librosa.segment.subsegment(C, beats)
>>> sub_beats = librosa.util.fix_frames(sub_beats)
>>> C_med_sub = librosa.util.sync(C, sub_beats, aggregate=np.median)

绘制结果

>>> import matplotlib.pyplot as plt
>>> beat_t = librosa.frames_to_time(beats, sr=sr)
>>> subbeat_t = librosa.frames_to_time(sub_beats, sr=sr)
>>> fig, ax = plt.subplots(nrows=3, sharex=True, sharey=True)
>>> librosa.display.specshow(C, vscale='dBFS',
...                          x_axis='time', ax=ax[0])
>>> ax[0].set(title='CQT power, shape={}'.format(C.shape))
>>> ax[0].label_outer()
>>> librosa.display.specshow(C_med, vscale='dBFS',
...                          x_coords=beat_t, x_axis='time', ax=ax[1])
>>> ax[1].set(title='Beat synchronous CQT power, '
...                 'shape={}'.format(C_med.shape))
>>> ax[1].label_outer()
>>> librosa.display.specshow(C_med_sub, vscale='dBFS',
...                          x_coords=subbeat_t, x_axis='time', ax=ax[2])
>>> ax[2].set(title='Sub-beat synchronous CQT power, '
...                 'shape={}'.format(C_med_sub.shape))
