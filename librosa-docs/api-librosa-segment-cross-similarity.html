librosa.segment.cross_similarity

librosa.segment.cross_similarity(data, data_ref, *, k=None, metric='euclidean', sparse=False, mode='connectivity', bandwidth=None, full=False) [源码]

计算从一个数据序列到参考序列的交叉相似度。

输出为矩阵 xsim，当 data_ref[..., i] 是 data[..., j] 的 k 近邻之一时，xsim[i, j] 非零。

参数

参数类型说明
datanp.ndarray [shape=(…, d, n)]

比较序列的特征矩阵。 若数据超过二维（如多声道输入），比较前会把前面的维度展平。 例如，形状为 (2, d, n) 的立体声输入会 自动重排为 (2 * d, n)。

data_refnp.ndarray [shape=(…, d, n_ref)]

参考序列的特征矩阵。 若数据超过二维（如多声道输入），比较前会把前面的维度展平。 例如，形状为 (2, d, n_ref) 的立体声输入会 自动重排为 (2 * d, n_ref)。

kint > 0 [scalar] or None

每个样本的近邻数量

默认：k = 2 * ceil(sqrt(n_ref))， 若 n_ref <= 3 则为 k = 2

metricstr

近邻计算所用的距离度量。

详见 sklearn.neighbors.NearestNeighbors。

sparsebool [scalar]

若为 False，返回稠密类型（ndarray） 若为 True，返回稀疏类型（scipy.sparse.csc_array）

modestr, {‘connectivity’, ‘distance’, ‘affinity’}

若为 ‘connectivity’，产生二值连通矩阵。

若为 ‘distance’，非零元素包含点之间的距离。

若为 ‘affinity’，非零元素映射为 exp( - distance(i, j) / bandwidth)，其中 bandwidth 如下文所述。

bandwidthNone, float > 0, ndarray, or str
  • 字符串选项包括：

    • ‘med_k_scalar’

    • ‘mean_k’

    • ‘gmean_k’

    • ‘mean_k_avg’

    • ‘gmean_k_avg’

    • ‘mean_k_avg_and_pair’

若提供 ndarray，则把它作为每个 i、j 对的 bandwidth。

若使用 mode='affinity'，可用此参数设置 亲和核上的 bandwidth。

若未提供取值或为 None，默认为 'med_k_scalar'。

若 bandwidth='med_k_scalar'，bandwidth 自动设为各 data[:, i] 到其第 k 近邻距离的中位数。

若 bandwidth='mean_k'，对每个样本对 (i, j)，bandwidth 取样本 i 与样本 j 到第 k 近邻距离的算术平均。

若 bandwidth='gmean_k'，对每个样本对 (i, j)，bandwidth 取样本 i 与 j 到第 k 近邻距离的几何平均 [1]。

若 bandwidth='mean_k_avg'，对每个样本对 (i, j)，bandwidth 取样本 i 与样本 j 到前 k 个近邻的平均距离的算术平均。 这与 Wang et al. (2014) [2] 的方法类似，但不包含 i 与 j 之间的距离。

若 bandwidth='gmean_k_avg'，对每个样本对 (i, j)，bandwidth 取样本 i 与样本 j 到前 k 个近邻的平均距离的几何平均。

若 bandwidth='mean_k_avg_and_pair'，对每个样本对 (i, j)，bandwidth 取三项的算术平均：样本 i、样本 j 分别到前 k 个近邻的平均距离，以及 i 与 j 之间的距离。 这与 Wang et al. (2014) 的方法类似。[2]

[1] Zelnik-Manor, Lihi, and Pietro Perona. (2004). “Self-tuning spectral clustering.” Advances in neural information processing systems 17.

[2] Wang, Bo, et al. (2014). “Similarity network fusion for aggregating data types on a genomic scale.” Nat Methods 11, 333–337. https://doi.org/10.1038/nmeth.2810 (1,2)

fullbool

若使用 mode ='affinity' 或 mode='distance'，可用此选项计算完整的亲和矩阵或距离矩阵，而非常只保留各样本前 k 个近邻处非零元素的稀疏矩阵。 此选项在 mode='connectivity' 下无效。

使用 mode='distance' 时，设 full=True 将忽略 k 与 width。 使用 mode='affinity' 时，设 full=True 将只在 bandwidth 估计中使用 k，并忽略 width。

返回值

返回值类型说明
xsimnp.ndarray or scipy.sparse.csc_array, [shape=(n_ref, n)]

交叉相似度矩阵

参见

说明

此函数在缓存级别 30 上缓存。

示例

在两个序列之间查找 CQT 空间中的近邻

>>> hop_length = 1024
>>> y_ref, sr = librosa.loadx('pistachio')
>>> y_comp, sr = librosa.loadx('pistachio', offset=10)
>>> chroma_ref = librosa.feature.chroma_cqt(y=y_ref, sr=sr, hop_length=hop_length)
>>> chroma_comp = librosa.feature.chroma_cqt(y=y_comp, sr=sr, hop_length=hop_length)
>>> # Use time-delay embedding to get a cleaner recurrence matrix
>>> x_ref = librosa.feature.stack_memory(chroma_ref, n_steps=10, delay=3)
>>> x_comp = librosa.feature.stack_memory(chroma_comp, n_steps=10, delay=3)
>>> xsim = librosa.segment.cross_similarity(x_comp, x_ref)

或把近邻数量固定为 5

>>> xsim = librosa.segment.cross_similarity(x_comp, x_ref, k=5)

使用余弦相似度代替欧氏距离

>>> xsim = librosa.segment.cross_similarity(x_comp, x_ref, metric='cosine')

使用亲和矩阵代替二值连通矩阵

>>> xsim_aff = librosa.segment.cross_similarity(x_comp, x_ref, metric='cosine', mode='affinity')

绘制特征矩阵与递归矩阵

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(ncols=2, sharex=True, sharey=True)
>>> imgsim = librosa.display.specshow(xsim, x_axis='s', y_axis='s',
...                          hop_length=hop_length, ax=ax[0])
>>> ax[0].set(title='Binary cross-similarity (symmetric)')
>>> imgaff = librosa.display.specshow(xsim_aff, x_axis='s', y_axis='s',
...                          cmap='magma_r', hop_length=hop_length, ax=ax[1])
>>> ax[1].set(title='Cross-affinity')
>>> ax[1].label_outer()
>>> fig.colorbar(imgsim, ax=ax[0], orientation='horizontal', ticks=[0, 1])
>>> fig.colorbar(imgaff, ax=ax[1], orientation='horizontal')
