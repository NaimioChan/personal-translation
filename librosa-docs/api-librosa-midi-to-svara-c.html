librosa.midi_to_svara_c

librosa.midi_to_svara_c(midi, *, Sa, mela, abbr=True, octave=True, unicode=True) [源码]

把 MIDI 编号转换为给定 melakarta raga 中的卡纳提克 svara

非有限的 MIDI 编号（例如 NaN、inf）将返回空字符串。

参数

参数类型说明
midinumeric

要转换的 MIDI 编号

Sanumber > 0

参照 Sa 的 MIDI 编号。

默认：60（261.6 Hz，C4）

melaint or str

melakarta raga 的名称或索引

abbrbool

若为 True（默认），返回缩写名称（‘S’、‘R1’、‘R2’、‘G1’、‘G2’、……）

若为 False，返回长格式名称（‘Sa’、‘Ri1’、‘Ri2’、‘Ga1’、‘Ga2’、……）

octavebool

若为 True，在相邻八度的 svara 上添加上点或下点。

若为 False，忽略八度高度信息。

unicodebool

若为 True，使用 Unicode 符号标注八度信息以及下标 数字。

若为 False，八度标注使用低位 ASCII（’ 与 ,）。

返回值

返回值类型说明
svarastr or np.ndarray of str

给定 MIDI 编号所对应的 svara
