librosa.to_multi

librosa.to_multi(*signals, downmix=True, pad=True, norm=True, out=None) [源码]

把多个信号合并为多声道信号。

参数

参数类型说明
*signalsnp.ndarray [shape=(…, n)]

一个或多个待合并为多声道信号的信号。 每个输入信号可以是单声道或多声道，且长度不必全部相同。

downmixbool

若为 True，合并前把每个输入信号下混为单声道。

若为 False，各输入信号相加合并，且它们的声道布局（除末尾长度维之外的形状）必须完全相同。

padbool

若为 True，把输出补零至最长输入信号的长度。

若为 False，把输出裁剪至最短输入信号的长度。

normbool

若为 True（默认），各信号通过求平均合并。

若为 False，各信号通过求和合并。

outnp.ndarray [shape=(m, n_out) or shape=(…, n_out)] or None

预先分配的输出缓冲区。若提供，其形状必须与结果一致， 且 dtype 精度不低于结果 dtype； 它会被清零并原地写入后返回，从而避免新分配。若为 None（默认），则分配新数组。

返回值

返回值类型说明
y_multinp.ndarray [shape=(m, n_out) or shape=(…, n_out)]

输入信号的多声道组合，其中 m 对应信号数量（若 downmix=True）， n_out 是由填充模式决定的输出信号长度。 若提供了 out，返回的就是 out 本身。

参见

  • to_mono
  • to_stereo
  • util.fix_length

示例

把三个长度不同的单声道信号合并为多声道信号

>>> y1 = librosa.tone(440.0, sr=22050, duration=1.0)
>>> y2 = librosa.tone(550.0, sr=22050, duration=1.0)
>>> y3 = librosa.tone(660.0, sr=22050, duration=2.0)
>>> y_multi = librosa.to_multi(y1, y2, y3, pad=True)
>>> y_multi.shape
(3, 44100)
