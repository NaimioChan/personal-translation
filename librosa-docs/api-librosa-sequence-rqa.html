librosa.sequence.rqa

librosa.sequence.rqa(sim, *, gap_onset=1, gap_extend=1, knight_moves=True, backtrack=True) [源码]

递归量化分析（RQA）

本函数实现 Serra、Serra 与 Andrzejak（SSA）描述的形式各异的 RQA。[1] 这些方法以自相似矩阵或互相似矩阵 sim 为输入，通过动态规划计算路径对齐的得分。

注意与动态时间规整（dtw）不同，这里的对齐路径取最大值而非最小值，因此输入应衡量相似度而非距离。

最简单的 RQA 方法记为 L（SSA 式 3），等价于 Eckman、Kamphorst 与 Ruelle 描述的方法 [2]，它累加输入中取值为正的对角路径长度：

  • score[i, j] = score[i-1, j-1] + 1 若 sim[i, j] > 0

  • score[i, j] = 0 否则。

第二种方法记为 S（SSA 式 4），与第一种相似，但除严格的对角移动外还允许“马步”（如同国际象棋中的马）：

  • score[i, j] = max(score[i-1, j-1], score[i-2, j-1], score[i-1, j-2]) + 1 若 sim[i, j] > 0

  • score[i, j] = 0 否则。

第三种方法记为 Q（SSA 式 5 与式 6），在此基础上允许对齐中出现需要付出代价的缺口，而不是在 sim[i, j] == 0 时直接清零。 缺口由两个额外参数 gap_onset 与 gap_extend 计罚，每引入或延伸一个缺口（分别）时就从对齐路径的值中减去。

注意把 gap_onset 与 gap_extend 设为 np.inf 即可得到第二种方法，禁用马步则得到第一种。

[1] Serrà, Joan, Xavier Serra, and Ralph G. Andrzeja. “Cross recurrence quantification for cover song identification.” New Journal of Physics 11, no. 9 (2009): 093017.

[2] Eckmann, J. P., S. Oliffson Kamphorst, and D. Ruelle. “Recurrence plots of dynamical systems.” World Scientific Series on Nonlinear Science Series A 16 (1995): 441-446.

参数

参数类型说明
simnp.ndarray [shape=(N, M), non-negative]

用作输入的相似度矩阵。

它既可以是递归矩阵（自相似），也可以是两个序列之间的互相似矩阵。

gap_onsetfloat > 0

为对齐序列引入缺口的惩罚

gap_extendfloat > 0

延伸对齐序列中已有缺口的惩罚

knight_movesbool

若为 True（默认），允许对齐中出现“马步”， 例如 (n, m) => (n + 1, m + 2) 或 (n + 2, m + 1)。

若为 False，只允许对角移动 (n, m) => (n + 1, m + 1)。

backtrackbool

若为 True，返回对齐路径。

若为 False，只返回得分矩阵。

返回值

返回值类型说明
scorenp.ndarray [shape=(N, M)]

对齐得分矩阵。 score[n, m] 是以帧 n 与 m 结尾的最佳对齐序列的累计值。

pathnp.ndarray [shape=(k, 2)] (optional)

若 backtrack=True，path 包含最佳对齐序列中成对对齐帧的列表。

path[i] = [n, m] 表示第 n 行与第 m 列对齐。

示例

简单的对角路径增强（L 模式）

>>> import numpy as np
>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('nutcracker', duration=30)
>>> chroma = librosa.feature.chroma_cqt(y=y, sr=sr)
>>> # Use time-delay embedding to reduce noise
>>> chroma_stack = librosa.feature.stack_memory(chroma, n_steps=10, delay=3)
>>> # Build recurrence, suppress self-loops within 1 second
>>> rec = librosa.segment.recurrence_matrix(chroma_stack, width=43,
...                                         mode='affinity',
...                                         metric='cosine')
>>> # using infinite cost for gaps enforces strict path continuation
>>> L_score, L_path = librosa.sequence.rqa(rec,
...                                        gap_onset=np.inf,
...                                        gap_extend=np.inf,
...                                        knight_moves=False)
>>> fig, ax = plt.subplots(ncols=2)
>>> librosa.display.specshow(rec, x_axis='frames', y_axis='frames', ax=ax[0])
>>> ax[0].set(title='Recurrence matrix')
>>> librosa.display.specshow(L_score, x_axis='frames', y_axis='frames', ax=ax[1])
>>> hl = librosa.display.highlight(ax=ax[1])
>>> ax[1].set(title='Alignment score matrix')
>>> ax[1].plot(L_path[:, 1], L_path[:, 0], label='Optimal path', path_effects=hl)
>>> ax[1].legend()
>>> ax[1].label_outer()
>>> plt.show()

使用缺口与马步的完整对齐

>>> # New gaps cost 5, extending old gaps cost 10 for each step
>>> score, path = librosa.sequence.rqa(rec, gap_onset=5, gap_extend=10)
>>> fig, ax = plt.subplots(ncols=2, sharex=True, sharey=True)
>>> librosa.display.specshow(rec, x_axis='frames', y_axis='frames', ax=ax[0])
>>> ax[0].set(title='Recurrence matrix')
>>> librosa.display.specshow(score, x_axis='frames', y_axis='frames', ax=ax[1])
>>> ax[1].set(title='Alignment score matrix')
>>> hl = librosa.display.highlight(ax=ax[1])
>>> ax[1].plot(path[:, 1], path[:, 0], label='Optimal path', path_effects=hl)
>>> ax[1].legend()
>>> ax[1].label_outer()
>>> plt.show()
