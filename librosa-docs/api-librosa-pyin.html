librosa.pyin

librosa.pyin(y, *, fmin, fmax, sr=22050, frame_length=2048, hop_length=None, n_thresholds=100, beta_parameters=(2, 18), boltzmann_parameter=2, resolution=0.1, max_transition_rate=35.92, switch_prob=0.01, no_trough_prob=0.01, fill_na=nan, center=True, pad_mode='constant', transition_min_prob=0.0001) [源码]

使用概率 YIN（pYIN）估计基频（F0）。

pYIN [1] 是用于基频（F0）估计的 YIN 算法 [2] 的变体。 pYIN 的第一步使用 YIN 算法计算 F0 候选值及其概率。 第二步用维特比解码估计最可能的 F0 序列与浊音标志。

[1] Mauch, Matthias, and Simon Dixon. “pYIN: A fundamental frequency estimator using probabilistic threshold distributions.” 2014 IEEE International Conference on Acoustics, Speech and Signal Processing (ICASSP). IEEE, 2014.

[2] De Cheveigné, Alain, and Hideki Kawahara. “YIN, a fundamental frequency estimator for speech and music.” The Journal of the Acoustical Society of America 111.4 (2002): 1917-1930.

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频时间序列。支持多声道。

fminnumber > 0 [scalar]

最低频率，单位赫兹。 推荐下限为 librosa.note_to_hz('C2')（约 65 Hz）， 更低的取值也可能可行。

fmaxnumber > fmin, <= sr/2 [scalar]

最高频率，单位赫兹。 推荐上限为 librosa.note_to_hz('C7')（约 2093 Hz）， 更高的取值也可能可行。

srnumber > 0 [scalar]

y 的采样率，单位赫兹。

frame_lengthint > 0 [scalar]

帧长，以采样点计。 默认 frame_length=2048 在 22050 Hz 采样率下 对应约 93 ms 的时间尺度。

hop_lengthNone or int > 0 [scalar]

相邻 pYIN 预测之间的音频采样点数量。 若为 None，默认为 frame_length // 4。

n_thresholdsint > 0 [scalar]

峰值估计所用的阈值数量。

beta_parameterstuple

阈值先验所用 beta 分布的形状参数。

boltzmann_parameternumber > 0 [scalar]

谷值先验所用玻尔兹曼分布的形状参数。 值越大，更多质量分配给更小的周期。

resolutionfloat in (0, 1)

音高 bin 的分辨率。 0.01 对应音分。

max_transition_ratefloat > 0

最大音高变化率，单位每八度每秒。

switch_probfloat in (0, 1)

由浊音切换为非浊音或反向切换的概率。

no_trough_probfloat in (0, 1)

当没有低于阈值的谷值时，加到全局最小值上的最大概率。

fill_naNone, float, or np.nan

f0 中非浊音帧的默认值。 若为 None，非浊音帧将包含最佳猜测值。

centerbool

若为 True，对信号 y 做填充，使帧 D[:, t] 以 y[t * hop_length] 为中心。 若为 False，D[:, t] 从 y[t * hop_length] 开始。 默认 True，这便于借助 librosa.core.frames_to_samples 把 D 对齐到时间网格。

pad_modestr or function

若 center=True，此参数传给 np.pad，用于填充信号 y 的边缘。默认（pad_mode="constant"）用零填充 y 的两侧。 若 center=False，此参数被忽略。 .. see also:: np.pad

transition_min_probNone or float > 0

若为 None，维特比解码对每个时间步考虑所有可能的前驱状态，给出精确推断。 否则只考虑概率至少为 transition_min_prob 的转移。这是近似推断，但能显著减少计算时间。

返回值

返回值类型说明
f0np.ndarray [shape=(…, n_frames)]

基频的时间序列，单位赫兹。

voiced_flagnp.ndarray [shape=(…, n_frames)]

时间序列，包含表示各帧是否为浊音的布尔标志。

voiced_probnp.ndarray [shape=(…, n_frames)]

时间序列，包含各帧为浊音的概率。

注意

若提供多声道输入，f0 与浊音信息按每个声道分别估计。

示例

从音频输入计算基频（F0）曲线

>>> y, sr = librosa.loadx('trumpet')
>>> f0, voiced_flag, voiced_probs = librosa.pyin(y,
...                                              sr=sr,
...                                              fmin=librosa.note_to_hz('C2'),
...                                              fmax=librosa.note_to_hz('C7'))
>>> times = librosa.times_like(f0, sr=sr)

把 F0 叠加在频谱图上

>>> import matplotlib.pyplot as plt
>>> D = librosa.amplitude_to_db(np.abs(librosa.stft(y)), ref=np.max)
>>> fig, ax = plt.subplots()
>>> img = librosa.display.specshow(D, x_axis='time', y_axis='log', ax=ax)
>>> ax.set(title='pYIN fundamental frequency estimation')
>>> librosa.display.colorbar_db(img)
>>> ax.plot(times, f0, label='f0', path_effects=librosa.display.highlight(ax=ax))
>>> ax.legend(loc='upper right')
