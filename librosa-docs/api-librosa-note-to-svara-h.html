librosa.note_to_svara_h

librosa.note_to_svara_h(notes, *, Sa, abbr=True, octave=True, unicode=True) [源码]

把西方音名转换为印度斯坦 svara。

注意此转换假定十二平均律。

参数

参数类型说明
notesstr or iterable of str

要转换的音名（如 ‘C#’ 或 [‘C4’, ‘Db4’, ‘D4’]

Sastr

对应 Sa 的音名（如 ‘C’ 或 ‘C5’）。

若未提供八度信息，默认为八度 0 （C0 ~= 16 Hz）

abbrbool

若为 True（默认），返回缩写名称（‘S’、‘r’、‘R’、‘g’、‘G’……）

若为 False，返回完整名称（‘Sa’、‘re’、‘Re’、‘ga’、‘Ga’……）

octavebool

若为 True，用上点或下点标记相邻八度中的 svara。

若为 False，忽略八度高度信息。

unicodebool

若为 True，使用 unicode 符号标记八度信息。

若为 False，使用低位 ASCII（’ 和 ,）标记八度。

仅在 octave=True 时生效。

返回值

返回值类型说明
svarastr or np.ndarray of str

给定音名对应的 svara

参见

  • midi_to_svara_h
  • hz_to_svara_h
  • note_to_svara_c
  • note_to_midi
  • note_to_hz

示例

>>> librosa.note_to_svara_h(['C4', 'G4', 'C5', 'G5'], Sa='C5')
['Ṣ', 'P̣', 'S', 'P']
