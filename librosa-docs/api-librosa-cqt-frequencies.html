librosa.cqt_frequencies

librosa.cqt_frequencies(n_bins, *, fmin, bins_per_octave=12, tuning=0.0) [源码]

计算常数 Q 各频带的中心频率。

参数

参数类型说明
n_binsint > 0 [scalar]

常数 Q 频带数

fminfloat > 0 [scalar]

最低频率

bins_per_octaveint > 0 [scalar]

每八度的频带数

tuningfloat

相对于 A440 调音的偏差，单位为频带分数

返回值

返回值类型说明
frequenciesnp.ndarray [shape=(n_bins,)]

每个 CQT 频带的中心频率

示例

>>> # Get the CQT frequencies for 24 notes, starting at C2
>>> librosa.cqt_frequencies(24, fmin=librosa.note_to_hz('C2'))
array([  65.406,   69.296,   73.416,   77.782,   82.407,   87.307,
         92.499,   97.999,  103.826,  110.   ,  116.541,  123.471,
        130.813,  138.591,  146.832,  155.563,  164.814,  174.614,
        184.997,  195.998,  207.652,  220.   ,  233.082,  246.942])
