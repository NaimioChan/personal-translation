librosa.util.abs2

librosa.util.abs2(x, dtype=None) [源码]

计算实数或复数数组的幅度平方。

该函数等价于调用 np.abs(x)**2，但略为高效。

参数

参数类型说明
xnp.ndarray or scalar, real or complex typed

输入数据，类型为实数（float32、float64）或复数（complex64、complex128）

dtypenp.dtype, optional

输出数组的数据类型。 若未提供，则根据 x 推断

返回值

返回值类型说明
pnp.ndarray or scale, real

x 的幅度平方

示例

>>> librosa.util.abs2(3 + 4j)
25.0
>>> librosa.util.abs2((0.5j)**np.arange(8))
array([1.000e+00, 2.500e-01, 6.250e-02, 1.562e-02, 3.906e-03, 9.766e-04,
   2.441e-04, 6.104e-05])
