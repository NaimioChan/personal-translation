librosa.filters.wavelet_lengths

librosa.filters.wavelet_lengths(*, freqs, sr=22050, window='hann', filter_scale=1, gamma=0, alpha=None) [源码]

返回小波基中每个滤波器的长度。

参数

参数类型说明
freqsnp.ndarray (positive)

各滤波器的中心频率（单位 Hz）。 必须按升序排列。

srnumber > 0 [scalar]

音频采样率

windowstr or callable

作用于滤波器的窗函数

filter_scalefloat > 0 [scalar]

滤波窗的分辨率。值越大，使用的窗越长。

gammanumber >= 0 [scalar, optional]

用于确定滤波器长度的带宽偏移量，用法同变 Q 变换。

第 k 个滤波器的带宽由下式决定：

B[k] = alpha[k] * freqs[k] + gamma

alpha[k] 是 freqs[k+1] 与 freqs[k-1] 相对差值的两倍：

alpha[k] = (freqs[k+1]-freqs[k-1]) / (freqs[k+1]+freqs[k-1])

若 freqs 呈等比数列（如在 CQT 与 VQT 中），则向量 alpha 为常数，且满足：

(1 + alpha) * freqs[k-1] = (1 - alpha) * freqs[k+1]

此外，若 gamma=0（默认），alpha 还使得偶数 k 与 奇数 k 的滤波器交错排列：

freqs[k-1] + B[k-1] = freqs[k+1] - B[k+1]

若指定 gamma=None，则按下列方式计算 gamma，使各滤波器的带宽与频率 freqs[k] 处的等效矩形带宽（ERB）成正比：

gamma[k] = 24.7 * alpha[k] / 0.108

该关系由 [1] 推导得出。

[1] Glasberg, Brian R., and Brian CJ Moore. “Derivation of auditory filter shapes from notched-noise data.” Hearing research 47.1-2 (1990): 103-138.

alphanumber > 0 [optional]

可选的预先算好的相对带宽参数。 注意当 len(freqs)==1 时必须提供该参数，因为无法从单一频率推断带宽。 否则，若不指定，将按上述规则自动推导。

返回值

返回值类型说明
lengthsnp.ndarray

每个滤波器的长度。

f_cutofffloat

使所有滤波器主瓣都至少衰减 3dB 的最低频率。

这第二个输出在 cqt 与 vqt 中用于确保所有小波频带都保持在奈奎斯特频率以下。

异常

异常说明
ParameterError

  • 若 filter_scale 不是严格正数

  • 若 gamma 为负数

  • 若有任一频率 <= 0

  • 若频率数组未按升序排列

说明

本函数在层级 10 缓存。
