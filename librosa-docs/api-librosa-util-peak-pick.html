librosa.util.peak_pick

librosa.util.peak_pick(x, *, pre_max, post_max, pre_avg, post_avg, delta, wait, sparse=True, method='greedy', axis=-1) [源码]

用一套灵活的启发式规则在信号中挑选峰值。

若样本 n 对应的 x[n] 满足以下三个条件，则把该样本 n 选为峰值：

  1. x[n] == max(x[n - pre_max:n + post_max])

  2. x[n] >= mean(x[n - pre_avg:n + post_avg]) + delta

  3. n - previous_n > wait

其中 previous_n 是上一个被选为峰值的样本（按贪心方式选取）。

本实现基于 [1] 与 [2]。

[1] Boeck, Sebastian, Florian Krebs, and Markus Schedl. “Evaluating the Online Capabilities of Onset Detection Methods.” ISMIR. 2012.

[2] CPJKU/onset_detection

参数

参数类型说明
xnp.ndarray

用于挑选峰值的输入信号

pre_maxint >= 0 [scalar]

在 n 之前多少个样本的范围内计算最大值

post_maxint >= 1 [scalar]

在 n 之后多少个样本的范围内计算最大值

pre_avgint >= 0 [scalar]

在 n 之前多少个样本的范围内计算均值

post_avgint >= 1 [scalar]

在 n 之后多少个样本的范围内计算均值

deltafloat >= 0 [scalar]

均值的阈值偏移量

waitint >= 0 [scalar]

选中一个峰值后需要等待的样本数

sparsebool [scalar]

若为 True，输出为检测到的峰值的索引。 若为 False，输出为与 x 形状相同的稠密布尔数组。

method{‘greedy’, ‘dp_count’, ‘dp_value’} [scalar]

挑选峰值所用的方法。默认为 ‘greedy’，即 Böck 等人（2012）的方法。贪心方法在上述约束下选取尽可能早的峰值（即索引值最小的那些）。 ‘dp_*’ 方法实现动态规划方法，显式地最大化所选峰值的数量（dp_count）或所选峰值 p 处数值 x[p] 之和（dp_value）。

axisint [scalar]

检测峰值所沿的轴。

返回值

返回值类型说明
peaksnp.ndarray [shape=(n_peaks,) or shape=x.shape, dtype=int or bool]

x 中峰值的索引（sparse=True），或布尔数组，其中 peaks[…, n] 表示帧索引 n 处有峰值（sparse=False）

异常

异常说明
ParameterError

若有任一输入超出其定义范围

示例

>>> y, sr = librosa.loadx('trumpet')
>>> onset_env = librosa.onset.onset_strength(y=y, sr=sr,
...                                          hop_length=512,
...                                          aggregate=np.median)
>>> peaks = librosa.util.peak_pick(onset_env, pre_max=3, post_max=3, pre_avg=3, post_avg=5, delta=0.5, wait=10)
>>> peaks
array([  3,  27,  40,  61,  72,  88, 103])

使用稠密输出构造表示峰值的布尔数组 >>> librosa.util.peak_pick(onset_env, pre_max=3, post_max=3, pre_avg=3, post_avg=5, … delta=0.5, wait=10, sparse=False) array([False, False, …, False, False])

>>> import matplotlib.pyplot as plt
>>> times = librosa.times_like(onset_env, sr=sr, hop_length=512)
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> D = np.abs(librosa.stft(y))
>>> librosa.display.specshow(D, vscale='dBFS',
...                          y_axis='log', x_axis='time', ax=ax[1])
>>> ax[0].plot(times, onset_env, alpha=0.8, label='Onset strength')
>>> ax[0].vlines(times[peaks], 0,
...              onset_env.max(), color='r', alpha=0.8,
...              label='Selected peaks')
>>> ax[0].legend(frameon=True, framealpha=0.8)
>>> ax[0].label_outer()
