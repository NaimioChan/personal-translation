librosa.feature.inverse.mel_to_audio

librosa.feature.inverse.mel_to_audio(M, *, sr=22050, n_fft=2048, hop_length=None, win_length=None, window='hann', center=True, pad_mode='constant', power=2.0, n_iter=32, length=None, dtype=<class 'numpy.float32'>, **kwargs) [源码]

使用 Griffin-Lim 把 mel 功率谱反演为音频。

本函数主要是以下操作的便捷封装：

>>> S = librosa.feature.inverse.mel_to_stft(M)
>>> y = librosa.griffinlim(S)

参数

参数类型说明
Mnp.ndarray [shape=(…, n_mels, n), non-negative]

由 feature.melspectrogram 得到的频谱图

srnumber > 0 [scalar]

底层信号的采样率

n_fftint > 0 [scalar]

中间 STFT 的 FFT 帧长度

hop_lengthNone or int > 0

STFT 的跳距。若未提供，默认为 n_fft // 4

win_lengthNone or int > 0

STFT 的窗长度。默认等于 n_fft

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

窗的规格，需被 stft 或 istft 支持

centerbool

若为 True，假定 STFT 使用居中的帧。 若为 False，假定 STFT 使用左对齐的帧。

pad_modestr

若 center=True，在信号边缘使用的填充模式。 默认情况下，STFT 使用零填充。

powerfloat > 0 [scalar]

幅度 mel 频谱图的指数

n_iterint > 0

Griffin-Lim 的迭代次数

lengthNone or int > 0

若提供，输出的 y 会被补零或裁剪为恰好 length 个采样点。

dtypenp.dtype

时域信号的实数数值类型。默认为 32 位浮点数。

**kwargs

mel 滤波器组参数的额外关键字参数

fminfloat >= 0 [scalar]

最低频率（Hz）

fmaxfloat >= 0 [scalar]

最高频率（Hz）。 若为 None，使用 fmax = sr / 2.0

htkbool [scalar]

使用 HTK 公式代替 Slaney 公式

norm{None, ‘slaney’, or number} [scalar]

若为 ‘slaney’，把三角形 mel 权重除以 mel 频带的宽度（面积归一化）。 若为数值，则用 librosa.util.normalize 把每个滤波器归一化 为单位 l_p 范数。受支持的 norm 取值（包括 +-np.inf）的完整 说明见 librosa.util.normalize。 否则保留所有三角形的峰值为 1.0

返回值

返回值类型说明
ynp.ndarray [shape(…, n,)]

由 M 重建的时域信号
