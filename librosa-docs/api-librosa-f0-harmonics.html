librosa.f0_harmonics

librosa.f0_harmonics(x, *, f0, freqs, harmonics, kind='linear', fill_value=0, axis=-2) [源码]

计算时变基频在选定谐波处的能量。

本函数可用于把 频率 * 时间 表示化简为 谐波 * 时间 表示，相当于对基频做了归一化。当 f0 对应音高时，结果可作为音色的表示；当 f0 对应速度时，结果可作为节奏的表示。

本函数与 interp_harmonics 不同，后者计算的是所有频率的谐波。

参数

参数类型说明
xnp.ndarray [shape=(…, frequencies, n)]

输入数组（例如 STFT 幅度）

f0np.ndarray [shape=(…, n)]

输入中每帧的基频（f0） 形状应与 x.shape[-1] 一致

freqsnp.ndarray, shape=(x.shape[axis]) or shape=x.shape

X 沿所选轴各元素对应的频率值。 频率也可以是时变的，例如由 reassigned_spectrogram 计算得到，此时形状应与 x 一致。

harmonicslist-like, non-negative

要计算的谐波，形式为 harmonics[i] * f0 小于 1 的值（例如 1/2）对应次谐波。

kindstr

插值类型。见 scipy.interpolate.interp1d。

fill_valuefloat

外推到观测频率范围之外时填充的值。

axisint

x 中对应频率的轴

返回值

返回值类型说明
f0_harmnp.ndarray [shape=(…, len(harmonics), n)]

每个时间步上，基频各指定谐波处的插值能量。

参见

  • interp_harmonics
  • librosa.feature.tempogram_ratio

示例

本例先估计基频（f0），再提取前 12 个谐波

>>> y, sr = librosa.loadx('trumpet')
>>> f0, voicing, voicing_p = librosa.pyin(y=y, sr=sr, fmin=200, fmax=700)
>>> S = np.abs(librosa.stft(y))
>>> freqs = librosa.fft_frequencies(sr=sr)
>>> harmonics = np.arange(1, 13)
>>> f0_harm = librosa.f0_harmonics(S, freqs=freqs, f0=f0, harmonics=harmonics)
>>> import matplotlib.pyplot as plt
>>> fig, ax =plt.subplots(nrows=2, sharex=True)
>>> librosa.display.specshow(S, vscale='dBFS',
...                          x_axis='time', y_axis='log', ax=ax[0])
>>> times = librosa.times_like(f0)
>>> highlight = librosa.display.highlight(ax=ax[0])
>>> for h in harmonics:
...     ax[0].plot(times, h * f0, label=f"{h}*f0", path_effects=highlight)
>>> ax[0].legend(ncols=4, loc='lower right')
>>> ax[0].label_outer()
>>> librosa.display.specshow(f0_harm, vscale='dBFS',
...                          x_axis='time', ax=ax[1])
>>> ax[1].set_yticks(harmonics-1)
>>> ax[1].set_yticklabels(harmonics)
>>> ax[1].set(ylabel='Harmonics')
