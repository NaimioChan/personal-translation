librosa.griffinlim

librosa.griffinlim(S, *, n_iter=32, hop_length=None, win_length=None, n_fft=None, window='hann', center=True, dtype=None, length=None, pad_mode='constant', momentum=0.99, init='random', rng=None, random_state=<DEPRECATED parameter>) [源码]

使用“快速”Griffin-Lim 算法近似地反演幅度频谱图。

给定短时傅里叶变换幅度矩阵（S），该算法随机 初始化相位估计，然后交替执行正变换与逆 STFT 运算。 [1]

注意，这里假定重建的是实值时域信号，并且 S 只包含非负频率分量（与 stft 计算的结果一致）。

“快速”GL 方法 [2] 使用动量参数来加速收敛。

[1] D. W. Griffin and J. S. Lim, “Signal estimation from modified short-time Fourier transform,” IEEE Trans. ASSP, vol.32, no.2, pp.236–243, Apr. 1984.

[2] Perraudin, N., Balazs, P., & Søndergaard, P. L. “A fast Griffin-Lim algorithm,” IEEE Workshop on Applications of Signal Processing to Audio and Acoustics (pp. 1-4), Oct. 2013.

参数

参数类型说明
Snp.ndarray [shape=(…, n_fft // 2 + 1, t), non-negative]

由 stft 产生的短时傅里叶变换幅度数组。

n_iterint > 0

运行的迭代次数

hop_lengthNone or int > 0

STFT 的跳距。若未提供，默认取 n_fft // 4

win_lengthNone or int > 0

STFT 的窗长。默认等于 n_fft

n_fftNone or int > 0

每帧的采样点数。 默认根据 S 的形状推断为偶数。 不过，若使用了奇数帧长，可以显式设置 n_fft。

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

窗的规格，支持 stft 或 istft 所支持的任意形式

centerbool

若为 True，假定 STFT 使用中心化帧。 若为 False，假定 STFT 使用左对齐帧。

dtypenp.dtype

时域信号的实数数值类型。默认根据 输入频谱图的精度推断。

lengthNone or int > 0

若提供，输出 y 会被零填充或裁剪到恰好 length 个采样点。

pad_modestr

当 center=True 时，信号边缘使用的填充模式。 默认情况下，STFT 使用零填充。

momentumnumber >= 0

快速 Griffin-Lim 的动量参数。 将其设为 0 即回到原始的 Griffin-Lim 方法 [1]。 接近 1 的取值可以加快收敛，但大于 1 可能不收敛。

initNone or ‘random’ [default]

若为 ‘random’（默认），相位值会依据 random_state 随机初始化。当输入 S 是没有初始相位估计的 幅度频谱图时，建议这样做。

若为 None，则相位由 S 初始化。当可以给出 相位的初始猜测，或希望从之前的输出继续运行 Griffin-Lim 时，这很有用。

rngNone, int, sequence of int, np.random.Generator, or np.random.RandomState

伪随机数生成器的状态。当 rng 为 None 时，会使用操作系统提供的 熵新建一个 numpy.random.Generator。 除 numpy.random.Generator 之外的类型会 传给 numpy.random.default_rng 以实例化 Generator。

random_stateNone, int, np.random.RandomState, or np.random.Generator

警告

该参数在 1.0.0 中已弃用，将在 1.2.0 中移除。

若为 int，random_state 是用于相位初始化的随机数 生成器的种子。

若为 np.random.RandomState 或 np.random.Generator 实例，则直接使用该 随机数生成器本身。

若为 None，默认使用 np.random.default_rng() 对象。

若同时提供 rng 与 random_state，则抛出异常。

示例

一个基本的 STFT 反演示例

>>> y, sr = librosa.loadx('trumpet')
>>> # Get the magnitude spectrogram
>>> S = np.abs(librosa.stft(y))
>>> # Invert using Griffin-Lim
>>> y_inv = librosa.griffinlim(S)
>>> # Invert without estimating phase
>>> y_istft = librosa.istft(S)

绘制结果的波形

>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=3, sharex=True, sharey=True)
>>> librosa.display.waveshow(y, sr=sr, color='C0', ax=ax[0])
>>> ax[0].set(title='Original', xlabel=None)
>>> ax[0].label_outer()
>>> librosa.display.waveshow(y_inv, sr=sr, color='C1', ax=ax[1])
>>> ax[1].set(title='Griffin-Lim reconstruction', xlabel=None)
>>> ax[1].label_outer()
>>> librosa.display.waveshow(y_istft, sr=sr, color='C2', ax=ax[2])
>>> ax[2].set_title('Magnitude-only istft reconstruction')
