librosa.fourier_tempo_frequencies

librosa.fourier_tempo_frequencies(*, sr=22050, win_length=384, hop_length=512) [源码]

计算傅里叶速度图矩阵所对应的频率（以每分钟节拍数计）。

参数

参数类型说明
srnumber > 0

音频采样率

win_lengthint > 0

每个分析窗包含的帧数

hop_lengthint > 0

各 bin 之间的采样点数

返回值

返回值类型说明
bin_frequenciesndarray [shape=(win_length // 2 + 1 ,)]

以 BPM 为单位的 bin 频率向量。

示例

获取 384 个 bin（8 秒）速度图对应的速度频率

>>> librosa.fourier_tempo_frequencies(win_length=384, sr=22050)
array([ 0.   ,  0.117,  0.234, ..., 22.266, 22.383, 22.5  ])
