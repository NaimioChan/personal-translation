术语表

sample

时间序列中的单个值。在音频中，它对应波形在某一时刻的幅度。

sampling rate

时间序列每秒的采样数。 用正数 sr 表示。

time series

通常指音频信号，用 y 表示，以浮点值的一维 numpy.ndarray 存储。y[t] 对应波形在采样点 t 处的幅度。

frame

为分析目的而截取的一小段时间序列。它通常对应频谱图矩阵中的一列。

window

计算频谱图时用于对帧内样本加权的向量或函数。

frame length

分析窗（或帧）中的样本数（正整数）。 用整数变量 n_fft 表示。

hop length

相邻帧之间的样本数，例如频谱图相邻列之间的样本数。用正整数 hop_length 表示。

window length

窗函数（如 Hann 窗）的长度（宽度）。注意它可能小于短时傅里叶变换中使用的帧长度。通常用正整数变量 win_length 表示。

Fourier transform

一种把时域信号变换为频域表示的数学运算。离散傅里叶变换（DFT）通常用快速傅里叶变换（FFT）算法计算。

DFT

一种把时域信号变换为频域表示的数学运算。离散傅里叶变换（DFT）通常用快速傅里叶变换（FFT）算法计算。

FFT

一种把时域信号变换为频域表示的数学运算。离散傅里叶变换（DFT）通常用快速傅里叶变换（FFT）算法计算。

STFT

短时傅里叶变换（STFT）是对时间序列的加窗帧依次做傅里叶变换所得的序列。STFT 通常表示为复值矩阵 D，行对应频率 bin，列对应帧（时间）。

spectrogram

一个矩阵 S，行对应频率 bin，列对应帧（时间）。频谱图可以是实值或复值的。按惯例，实值频谱图记为 numpy.ndarray 形式的 S，而复值 STFT 矩阵记为 D。

magnitude

复数 z 可以表示为实部与虚部的组合， \(z = a + jb\)（其中 j 表示虚数单位）。 z 的幅度是它到原点的距离，按勾股定理计算： \(|z| = \sqrt{a^2 + b^2}\)。

phase

复数 \(z = a + jb\) 的相位，是复平面上正实轴与原点至点 (a, b) 连线的夹角。 相位按 \(\phi = \arctan(b / a)\) 计算。

decibel

一种对数单位，用于表示两个量（通常是功率或强度）之比。在音频中，分贝常用于表示信号幅度相对于某一参考电平的大小。

dB

一种对数单位，用于表示两个量（通常是功率或强度）之比。在音频中，分贝常用于表示信号幅度相对于某一参考电平的大小。

dBFS

满刻度相对分贝（dBFS）是数字音频系统中衡量幅度电平的单位。0 dBFS 表示数字电平可能达到的最大值，负值表示更低的幅度。

frequency bin

在离散傅里叶变换（DFT）表示中，信号表示为有限一组频率上正弦分量的组合。 每个频率索引 k 对应一个频率 bin。

fundamental frequency

基频（f0）是周期波形的最低频率，通常被听作声音的音高。注意并非所有波形都是周期的。

f0

基频（f0）是周期波形的最低频率，通常被听作声音的音高。注意并非所有波形都是周期的。

pitch

声音的感知频率，通常与周期波形的基频（f0）相关联。在音乐中，音高通常表示为音名（如 A4、C#5）或 MIDI 音符号。

pitch class

音级是彼此相隔整数个八度的所有音高的集合。 例如，音 C 的音级包括 C、C1、C2、C3 等。在西方音乐中，共有 12 个音级，对应半音阶中的 12 个音。

chroma

色度表示衡量给定帧/时刻每个音级（如半音阶中的 12 个音）的相对能量大小。

pitch class profile

色度表示衡量给定帧/时刻每个音级（如半音阶中的 12 个音）的相对能量大小。

onset

一个音符或声音事件的起始时刻。

onset (strength) envelope

起始包络 onset_env[t] 衡量帧 t 处音符起始点的强度。通常以一维 numpy.ndarray 形式的浮点值 onset_envelope 存储。

novelty function

起始包络 onset_env[t] 衡量帧 t 处音符起始点的强度。通常以一维 numpy.ndarray 形式的浮点值 onset_envelope 存储。

novelty curve

起始包络 onset_env[t] 衡量帧 t 处音符起始点的强度。通常以一维 numpy.ndarray 形式的浮点值 onset_envelope 存储。

tempo

一段音乐的进行速度，通常以每分钟节拍数（BPM）衡量。

beat

节拍是音乐中时间的基本单位，常对应听者可以跟着打拍子的规律脉冲。

cqt

常数 Q 变换（CQT）是一种信号的时频表示，其频率 bin 按对数间隔分布，窗长与频率成反比缩放。

mel scale

mel 刻度是一种音高的感知刻度，近似人耳对不同频率的响应。mel 刻度在 1 kHz 以下近似线性，在 1 kHz 以上为对数。

mel spectrogram

mel 频谱图是一种信号的时频表示，其频率轴已变换到 mel 刻度。

mel frequency cepstral coefficient

mel 频率倒谱系数（MFCC）是声音短时功率谱的一种表示，基于对数功率 mel 频谱图的线性余弦变换。MFCC 常用作语音与音频处理中的特征。

MFCC

mel 频率倒谱系数（MFCC）是声音短时功率谱的一种表示，基于对数功率 mel 频谱图的线性余弦变换。MFCC 常用作语音与音频处理中的特征。

tempogram

一段音乐随时间的节奏结构表示。 它利用自相关或傅里叶分析，衡量起始包络中各周期成分的强度。

recurrence matrix

一个方阵，衡量所有时间或帧索引对 (i, j) 上的特征之间的相似度。

self-similarity matrix

一个方阵，衡量所有时间或帧索引对 (i, j) 上的特征之间的相似度。

beat synchronous features

节拍同步特征是通过在检测到的节拍间隔上对齐并聚合特征计算得到的。

multi-channel audio

含多个声道的音频信号，例如立体声（2 声道）或环绕声（5.1 声道）。多声道音频通常表示为形状为 (n_channels, n_samples) 的二维 numpy.ndarray。

MIDI

乐器数字接口（MIDI）是一项技术标准，描述了在电子乐器、计算机及其他相关设备之间传输演奏数据的协议、数字接口与连接器。

MIDI number

MIDI 音符号是一个整数值，表示 MIDI 标准中某个特定的音。例如，中央 C（C4）的 MIDI 音符号为 60。 有时会扩展到小数值，以便表示所有频率。

Scientific Pitch Notation

科学音高记谱法（SPN）是一种根据音级与八度编号为音命名的标准体系。

SPN

科学音高记谱法（SPN）是一种根据音级与八度编号为音命名的标准体系。

accidental

变音记号是表示音高变化的音乐记谱符号。 常见的变音记号包括升号（#）、降号（b）与还原号（♮）。

cent

十二平均律音阶中一个半音的一百分之一（1/100）。

A440

一种调音标准，把音 A4（中央 C 之上的 A）的音高定为 440 Hz。

12TET

一种调音体系，把一个八度均分为 12 个等份（半音），常用于西方音阶。

Just intonation

一种调音体系，用简单的整数比确定各音的频率，从而得到协和音程。

svara

印度古典音乐中的一个音高，可以理解为 raga 语境下的一个音。

Sa

印度古典音乐中的主音 svara。

thaat

印度斯坦古典音乐中根据音阶与音符模式对 raga 进行分类的体系。

melakarta

卡纳提克古典音乐中根据音阶与音符模式对 raga 进行分类的体系。

mela

卡纳提克古典音乐中根据音阶与音符模式对 raga 进行分类的体系。
