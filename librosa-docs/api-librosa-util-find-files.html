librosa.util.find_files

librosa.util.find_files(directory, *, ext=None, recurse=True, case_sensitive=False, limit=None, offset=0) [源码]

获取目录或目录子树中（音频）文件的排序列表。

参数

参数类型说明
directorystr

查找文件的路径

extstr or list of str

要纳入搜索的文件扩展名或扩展名列表。

默认：['aac', 'au', 'flac', 'm4a', 'mp3', 'ogg', 'wav']

recursebool

若为 True，则搜索 directory 的所有子目录。

否则只搜索 directory。

case_sensitivebool

若为 False，扩展名的大写形式也能匹配到文件。

limitint > 0 or None

最多返回 limit 个文件。若为 None，返回全部文件。

offsetint

从列表中 offset 处开始返回文件。

使用负值可从列表末尾开始偏移。

返回值

返回值类型说明
fileslist of str

音频文件列表。

示例

>>> # 获取目录子树中的所有音频文件
>>> files = librosa.util.find_files('~/Music')
>>> # 只在特定目录中查找，不包括子树
>>> files = librosa.util.find_files('~/Music', recurse=False)
>>> # 只查找 mp3 文件
>>> files = librosa.util.find_files('~/Music', ext='mp3')
>>> # 或只查找 mp3 与 ogg
>>> files = librosa.util.find_files('~/Music', ext=['mp3', 'ogg'])
>>> # 只取前 10 个文件
>>> files = librosa.util.find_files('~/Music', limit=10)
>>> # 或最后 10 个文件
>>> files = librosa.util.find_files('~/Music', offset=-10)
>>> # 避免在路径字符串中包含搜索模式
>>> import glob
>>> directory = '~/[202206] Music'
>>> directory = glob.escape(directory)  # Escape the special characters
>>> files = librosa.util.find_files(directory)
