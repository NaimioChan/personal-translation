librosa.hz_to_octs

librosa.hz_to_octs(frequencies, *, tuning=0.0, bins_per_octave=12) [源码]

把频率（Hz）转换为（带小数的）八度数。

参数

参数类型说明
frequenciesnumber >0 or np.ndarray [shape=(n,)] or float

标量或频率向量

tuningfloat

相对于 A440 的调音偏差，以每个八度的（分数）bin 数计。

bins_per_octaveint > 0

每个八度的 bin 数量。

返回值

返回值类型说明
octavesnumber or np.ndarray [shape=(n,)]

每个频率对应的八度数

参见

  • octs_to_hz

示例

>>> librosa.hz_to_octs(440.0)
4.
>>> librosa.hz_to_octs([32, 64, 128, 256])
array([ 0.219,  1.219,  2.219,  3.219])
