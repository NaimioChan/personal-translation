Superflux 起始点

本 notebook 演示如何用 librosa 复现 Boeck 与 Widmer 2013 年 [1] 的 Superflux 起始点检测算法。

该算法在存在颤音时能提升起始点检测的准确率。

[1] Böck, Sebastian, and Gerhard Widmer. Maximum filter vibrato suppression for onset detection. In Proc. of the 16th Int. Conf. on Digital Audio Effects (DAFx). Maynooth, Ireland (Sept 2013), vol. 7, p. 4. 2013.

这些参数直接取自论文

n_fft = 1024
hop_length = int(librosa.time_to_samples(1./200, sr=sr))
lag = 2
n_mels = 138
fmin = 27.5
fmax = 16000.
max_size = 3

论文使用的是对数频率表示，为简单起见，我们改用 mel 频谱图。

S = librosa.feature.melspectrogram(y=y, sr=sr, n_fft=n_fft,
                                   hop_length=hop_length,
                                   fmin=fmin,
                                   fmax=fmax,
                                   n_mels=n_mels)

fig, ax = plt.subplots()
librosa.display.specshow(S, vscale="dBFS[power]",
                         y_axis="mel", x_axis="time", sr=sr,
                         hop_length=hop_length, fmin=fmin, fmax=fmax, ax=ax)

接下来用 librosa 的默认值计算起始强度包络与起始事件。

odf_default = librosa.onset.onset_strength(y=y, sr=sr, hop_length=hop_length)
onset_default = librosa.onset.onset_detect(y=y, sr=sr, hop_length=hop_length,
                                           units="time")

再用 superflux 方法做同样的计算

odf_sf = librosa.onset.onset_strength(S=librosa.power_to_db(S, ref=np.max),
                                      sr=sr,
                                      hop_length=hop_length,
                                      lag=lag, max_size=max_size)

onset_sf = librosa.onset.onset_detect(onset_envelope=odf_sf,
                                      sr=sr,
                                      hop_length=hop_length,
                                      units="time")

仔细观察可以发现，默认的起始点检测器（上面的子图）在颤音强烈的区域出现了若干误报，例如约 0.62s 或 1.80s 处。

superflux 方法（中间的图）受颤音影响较小，在这些位置没有检测到起始事件。

fig, ax = plt.subplots(nrows=3, sharex=True)

frame_time = librosa.frames_to_time(np.arange(len(odf_default)),
                                    sr=sr,
                                    hop_length=hop_length)

librosa.display.specshow(S, vscale="dBFS[power]",
                         y_axis="mel", x_axis="time", sr=sr,
                         hop_length=hop_length, fmin=fmin, fmax=fmax, ax=ax[2])
ax[2].set(xlim=[0, 5.0])

ax[0].plot(frame_time, odf_default, label="Spectral flux")
ax[0].vlines(onset_default, 0, odf_default.max(), color="r", label="Onsets")
ax[0].legend()
ax[0].label_outer()

ax[1].plot(frame_time, odf_sf, color="g", label="Superflux")
ax[1].vlines(onset_sf, 0, odf_sf.max(), color="r", label="Onsets")
ax[1].legend()
ax[0].label_outer()
