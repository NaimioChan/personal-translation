显示

可视化信号与频谱数据。

Librosa 的显示功能构建在 matplotlib 之上。display 模块提供一组便捷函数，让常见可视化的构造更为容易，同时为音乐相关的坐标轴（时间、频率、音高等等）提供一套自定义刻度格式化器。
