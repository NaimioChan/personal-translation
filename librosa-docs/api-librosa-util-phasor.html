librosa.util.phasor

librosa.util.phasor(angles, *, mag=None) [源码]

由角度构造复数相量表示。

未提供 mag 时，等价于：

z = np.cos(angles) + 1j * np.sin(angles)

或按欧拉公式：

z = np.exp(1j * angles)

提供 mag 时，等价于：

z = mag * np.exp(1j * angles)

与上面给出的等价写法相比，本函数在时间和内存上都更为高效，且数值结果一致。

参数

参数类型说明
anglesnp.ndarray or scalar, real-valued

角度，单位为弧度

magnp.ndarray or scalar, optional

若提供，相量将按 mag 缩放。

若不提供（默认），相量的幅度为 1。

mag 的形状必须能与 angles 相乘。

返回值

返回值类型说明
znp.ndarray or scalar, complex-valued

与给定角度及可选的幅度对应的复数 z。

示例

构造角度为 0、pi/2 和 pi 的单位相量：

>>> librosa.util.phasor([0, np.pi/2, np.pi])
array([ 1.000e+00+0.000e+00j,  6.123e-17+1.000e+00j,
       -1.000e+00+1.225e-16j])

构造幅度为 1/2 的相量：

>>> librosa.util.phasor(np.pi/2, mag=0.5)
(3.061616997868383e-17+0.5j)

或者使用角度数组与幅度数组：

>>> librosa.util.phasor(np.array([0, np.pi/2]), mag=np.array([0.5, 1.5]))
array([5.000e-01+0.j , 9.185e-17+1.5j])
