librosa.util.valid_audio

librosa.util.valid_audio(y) [源码]

判断变量是否包含合法的音频数据。

必须满足以下条件：

  • type(y) 为 np.ndarray

  • y.dtype 为浮点类型

  • y.ndim != 0（至少有一个维度）

  • np.isfinite(y).all() 即所有样本都必须是有限值

参数

参数类型说明
ynp.ndarray

待验证的输入数据

返回值

返回值类型说明
validbool

若所有检查均通过则为 True

异常

异常说明
ParameterError

若上述任一条件不满足

参见

  • numpy.float32

说明

本函数在层级 20 缓存。

示例

可以构造一个能被解释为音频信号的数组

>>> y = np.random.randn(5000)
>>> librosa.util.valid_audio(y)
True

若在某个位置插入非有限的样本值，则验证失败

>>> y[5] = np.nan
>>> librosa.util.valid_audio(y)
...
ParameterError: Audio buffer is not finite everywhere
