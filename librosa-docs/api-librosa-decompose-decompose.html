librosa.decompose.decompose

librosa.decompose.decompose(S, *, n_components=None, transformer=None, sort=False, fit=True, **kwargs) [源码]

分解特征矩阵。

给定频谱图 S，将其分解为 components 与 activations，使得 S ~= components.dot(activations)。

默认使用非负矩阵分解（NMF）完成，但任何 sklearn.decomposition 类型的对象都可以使用。

参数

参数类型说明
Snp.ndarray [shape=(…, n_features, n_samples), dtype=float]

输入的特征矩阵（例如幅度频谱图）

若输入有多个声道（前导维度），分解前会自动展平。

若输入为多声道，分解前会自动把声道与特征展平到同一根轴上。例如，形状为 (2, n_features, n_samples) 的立体声输入 S 会被自动重塑为 (2 * n_features, n_samples)。

n_componentsint > 0 [scalar] or None

期望的分量数

若为 None，则使用 n_features 个分量

transformerNone or object

若为 None，使用 sklearn.decomposition.NMF

否则，任何接口与 NMF 类似的对象都可以使用。transformer 必须遵循 scikit-learn 的约定，即输入数据为 (n_samples, n_features)。

transformer.fit_transform() 会在 S.T（而非 S）上运行，其返回值（转置后）存为 activations

分量按 transformer.components_.T 获取：

S ~= np.dot(activations, transformer.components_).T

或等价地：

S ~= np.dot(transformer.components_.T, activations.T)
sortbool

若为 True，分量按峰值频率升序排序。

注意

若与 transformer 一起使用，排序作用于分解参数的副本，而不作用于 transformer 的内部参数。

警告

若输入数组的维度多于二维（例如多声道频谱图），则不支持按轴排序，会抛出 ParameterError 异常。

fitbool

若为 True，则由输入 S 估计分量。

若为 False，则假定分量已预先算好并保存在 transformer 中，不再改变。

**kwargs传给默认 transformer 的额外关键字参数

sklearn.decomposition.NMF

返回值

返回值说明
components: np.ndarray [shape=(…, n_features, n_components)]

分量（基元素）矩阵。

activations: np.ndarray [shape=(n_components, n_samples)]

变换后的矩阵／激活矩阵

异常

异常说明
ParameterError

若 fit 为 False 且未提供 transformer 对象。

若输入数组为多声道且指定了 sort=True。

参见

  • sklearn.decomposition：

    SciKit-Learn 矩阵分解模块

示例

用 NMF 把幅度频谱图分解为 16 个分量

>>> y, sr = librosa.loadx('pistachio', duration=5)
>>> S = np.abs(librosa.stft(y))
>>> comps, acts = librosa.decompose.decompose(S, n_components=16)

按峰值频率升序对分量排序

>>> comps, acts = librosa.decompose.decompose(S, n_components=16,
...                                           sort=True)

或者使用稀疏字典学习

>>> import sklearn.decomposition
>>> T = sklearn.decomposition.MiniBatchDictionaryLearning(n_components=16)
>>> scomps, sacts = librosa.decompose.decompose(S, transformer=T, sort=True)
>>> import matplotlib.pyplot as plt
>>> layout = [list(".AAAA"), list("BCCCC"), list(".DDDD")]
>>> fig, ax = plt.subplot_mosaic(layout, constrained_layout=True)
>>> librosa.display.specshow(S, vscale='dBFS',
...                          y_axis='log', x_axis='time', ax=ax['A'])
>>> ax['A'].set(title='Input spectrogram')
>>> ax['A'].label_outer()
>>> librosa.display.specshow(comps, vscale='dBFS',
...                          y_axis='log', ax=ax['B'])
>>> ax['B'].set(title='Components')
>>> ax['B'].label_outer()
>>> ax['B'].sharey(ax['A'])
>>> librosa.display.specshow(acts, x_axis='time', ax=ax['C'], cmap='gray_r')
>>> ax['C'].set(ylabel='Components', title='Activations')
>>> ax['C'].sharex(ax['A'])
>>> ax['C'].label_outer()
>>> S_approx = comps.dot(acts)
>>> img = librosa.display.specshow(S_approx, vscale='dBFS',
...                                y_axis='log', x_axis='time', ax=ax['D'])
>>> ax['D'].set(title='Reconstructed spectrogram')
>>> ax['D'].sharex(ax['A'])
>>> ax['D'].sharey(ax['A'])
>>> ax['D'].label_outer()
>>> librosa.display.colorbar_db(img, ax=list(ax.values()))
