librosa.display.AdaptiveWaveplot

class librosa.display.AdaptiveWaveplot(times, y, steps, envelope, sr=22050, max_samples=11025, transpose=False, label=None) [源码]

用于管理自适应波形可视化的辅助类。

该对象用于在基于采样的波形可视化与基于包络的波形可视化之间动态切换。当显示被放大到可见采样数不超过 max_samples 时，使用基于采样的显示。当显示原始采样所需的采样数超过 max_samples 时，改用基于包络的绘图。

你通常无需直接实例化该对象，它由 waveshow 自动构造。
