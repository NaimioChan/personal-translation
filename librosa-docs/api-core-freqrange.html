频率范围生成

函数说明

fft_frequencies

np.fft.rfftfreq 的替代接口

cqt_frequencies

计算常数 Q 各频带的中心频率。

mel_frequencies

计算一组按 mel 刻度调谐的声学频率。

tempo_frequencies

计算与起始点自相关矩阵或速度图矩阵相对应的频率（单位：每分钟节拍数）。

fourier_tempo_frequencies

计算与傅里叶速度图矩阵相对应的频率（单位：每分钟节拍数）。
