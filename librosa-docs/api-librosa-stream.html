librosa.stream

librosa.stream(path, *, block_length, frame_length, hop_length, sr=None, mono=True, offset=0.0, duration=None, fill_value=None, res_type='soxr_hq', dtype=<class 'numpy.float32'>) [源码]

以定长缓冲区流式读取音频。

这主要用于处理无法一次性完整装入内存的大文件。

该函数不会像 load 那样把整个音频信号载入内存， 而是按指定的帧长与跳距产生跨越固定帧数的音频 块。

虽然该函数力求与 load 行为相近， 但使用者应注意以下几点：

  1. 该函数不直接返回音频缓冲区， 而是返回一个生成器，可对其迭代以产生音频块。此处 块 指跨越给定帧数（帧之间可能重叠）的音频缓冲区。

  2. 支持自动重采样，但并非所有 block_length、frame_length 与 hop_length 的组合都与所有采样率兼容。 具体来说，(block_length * hop_length * native_sr) / sr 必须为精确整数，其中 native_sr 是重采样前流的原始采样率。

  3. 许多分析需要访问整个信号才能正确工作，例如 resample、cqt 或 beat_track，因此这些方法不适用于流式数据。

  4. block_length 参数指定每个块包含多少帧音频。 取值越大，内存占用越多，但后续处理效率更高。 最佳取值最终取决于具体应用与系统其他约束。

  5. 默认情况下，大多数 librosa 分析（例如短时傅里叶变换）假定帧居中， 这需要在信号开头与结尾补零。信号被切分成块时这无法正确工作， 因为会在信号中间引入补零。要禁用该特性， 请在所有基于帧的分析中使用 center=False。

  6. 如果提前跳出生成器循环，底层音频文件句柄与重采样缓冲区会一直保持打开， 直到生成器对象被垃圾回收。要显式释放资源， 请调用生成器的 .close() 方法。

正确的用法见下方示例。

参数

参数类型说明
pathstr, int, sf.SoundFile, or file-like object

要流式读取的输入文件路径。

此处允许使用 soundfile 支持的任意编解码器。

也可以提供已有的 soundfile.SoundFile 对象。

block_lengthint > 0

每个块包含的帧数。

注意文件末尾可能没有足够的数据填满整个块，默认情况下该块会较短。 若要补零使每个块都保持完整长度，请设置 fill_value（见下文）。

frame_lengthint > 0

每帧的采样点数。

hop_lengthint > 0

帧之间前进的采样点数。

注意当 hop_length < frame_length 时，相邻帧会重叠。 同样，一个 块 的最后一帧会与下一个 块 的第一帧重叠。

srnumber > 0 [scalar]

目标采样率。若未提供，则使用文件的原生采样率。

monobool

流式读取时把信号转为单声道

offsetfloat

从该时间（秒）之后开始读取

若为负值，则相对于文件末尾解释。

durationfloat

最多加载这么多音频（秒）

fill_valuefloat [optional]

若对信号补零以产生定长块， 该值将用于信号末尾。

大多数情况下期望 fill_value=0（静音）， 但也可指定任意值。

res_typestr

重采样类型，必须为以下之一：

  • ‘soxr_vhq’、‘soxr_hq’、‘soxr_mq’ 或 ‘soxr_lq’：

    soxr 的极高、高、中、低质量基于 FFT 的带限插值。 'soxr_hq' 是 soxr 的默认设置。

  • ‘soxr_qq’：

    soxr 快速三次插值（非常快，但不带限）

dtypenumeric type

所产生的音频缓冲区的数据类型

产出

产出类型说明
ynp.ndarray

最多含 (block_length-1) * hop_length + frame_length 个采样点的音频缓冲区。

示例

每次对 256 帧的块做短时傅里叶变换。 注意流式操作要求帧左对齐，因此必须设置 center=False 以避免补零产生伪影。

>>> filename = librosa.ex('brahms')
>>> sr = librosa.get_samplerate(filename)
>>> stream = librosa.stream(filename,
...                       block_length=256,
...                       frame_length=4096,
...                       hop_length=1024)
>>> for y_block in stream:
...     D_block = librosa.stft(y_block, center=False)

或在流上计算 mel 频谱图，使用更短的帧与不重叠的窗

>>> filename = librosa.ex('brahms')
>>> sr = librosa.get_samplerate(filename)
>>> stream = librosa.stream(filename,
...                         block_length=256,
...                         frame_length=2048,
...                         hop_length=2048)
>>> for y_block in stream:
...     m_block = librosa.feature.melspectrogram(y=y_block, sr=sr,
...                                              n_fft=2048,
...                                              hop_length=2048,
...                                              center=False)
