Rainbowgram

本 notebook 演示如何使用 “Rainbowgram” 同时可视化幅度与（展开的）（差分）相位，正如 NSynth 论文 [1] 中所展示的那样。

[1] Engel, Jesse, Cinjon Resnick, Adam Roberts, Sander Dieleman, Mohammad Norouzi, Douglas Eck, and Karen Simonyan. “Neural audio synthesis of musical notes with wavenet autoencoders.” In International Conference on Machine Learning, pp. 1068-1077. PMLR, 2017.

标准导入

import numpy as np
import matplotlib.pyplot as plt
import librosa

我们实现了一种 stft 方法用于可视化 rainbowgram，并用一个 chirp 信号演示了效果。chirp 信号从一个低频开始，频率随时间逐渐升高。随后我们分离出信号的幅度与相位成分。

sr = 22050
y = librosa.chirp(fmin=32, fmax=32 * 2**5, sr=sr, duration=10, linear=True)
D = librosa.stft(y)

# For rainbowgrams, we'll also need a separate array to represent the magnitude of the STFT.
# Here we'll measure it in decibels, and scale it to the range of [0, 1].
mag = librosa.amplitude_to_db(np.abs(D), ref=np.max)
alpha = (mag - mag.min()) / (mag.max() - mag.min())

通过 vscale=’dphase’ 参数，librosa.display.specshow 可以直接可视化 STFT 的相位结构。该模式用于展示每个时频位置的相位，与上一时间步的相位相比，相对于该频率上正弦波应有的相位偏离了多少。

fig, ax = plt.subplots()
img = librosa.display.specshow(D,
                         vscale="dphase",
                         cmap="hsv",
                         alpha=alpha,
                         ax=ax,
                         y_axis="log",
                         x_axis="time")
ax.set_facecolor("#000")
librosa.display.colorbar_phase(img)
plt.show()

上面的图用 HSV 色彩映射表示相位，在安静区域淡出到黑色背景，基本复现了 NSynth 论文中的 “rainbowgram” 可视化。中心颜色（0，青色）对应与 STFT 分析频率相当接近的频率，而红色值（±π）表示明显偏离中心频率。

HSV 色彩映射在感知亮度上确实存在突变，并且围绕中心点并不对称，因此得到的可视化在某些情况下可能有误导性。我们可以改用 twilight_shifted 色彩映射，它被设计为感知均匀，在中心值（0）处为中性色（灰），向两端（±π）分别发散到红与蓝。该色彩映射是 vscale=’dphase’ 模式的默认值，但也可以显式使用。

由于 twilight_shifted 色彩映射在两端呈深色，背景若为中性灰而非黑色，会更容易看清。

fig, ax = plt.subplots()
img = librosa.display.specshow(D,
                         vscale="dphase",
                         cmap="twilight_shifted",
                         alpha=alpha,
                         ax=ax,
                         y_axis="log",
                         x_axis="time")
ax.set_facecolor("#888")
librosa.display.colorbar_phase(img)

对于印刷品，使用白色背景并反转色彩映射可能更合适。这可以用常规的 twilight 色彩映射实现，它在中心值（0）处为深色，向两端（±π）发散到浅色。

fig, ax = plt.subplots()
img = librosa.display.specshow(D,
                         vscale="dphase",
                         cmap="twilight",
                         alpha=alpha,
                         ax=ax,
                         y_axis="log",
                         x_axis="time")
ax.set_facecolor("#fff")
librosa.display.colorbar_phase(img)

类似的相位结构图也可以由其他复值变换生成，例如 CQT。vscale=’dphase’ 适用于 x_axis 与 y_axis 参数给出的任何时频网格。

C = librosa.cqt(y, sr=sr, n_bins=12*6, bins_per_octave=12)
C_mag = librosa.amplitude_to_db(np.abs(C), ref=np.max)
alpha_cqt = (C_mag - C_mag.min()) / (C_mag.max() - C_mag.min())
fig, ax = plt.subplots()
img = librosa.display.specshow(C,
                         vscale="dphase",
                         cmap="twilight_shifted",
                         alpha=alpha_cqt,
                         ax=ax,
                         bins_per_octave=12,
                         y_axis="cqt_hz",
                         x_axis="time")
ax.set_facecolor("#888")
librosa.display.colorbar_phase(img)
