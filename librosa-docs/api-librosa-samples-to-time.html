librosa.samples_to_time

librosa.samples_to_time(samples, *, sr=22050) [源码]

把采样点索引转换为时间（秒）。

参数

参数类型说明
samplesnp.ndarray

采样点索引或采样点索引数组

srnumber > 0

采样率

返回值

返回值类型说明
timesnp.ndarray [shape=samples.shape]

与 samples 对应的时间值（秒）

参见

  • samples_to_frames：

    把采样点索引转换为帧索引

  • time_to_samples：

    把时间值转换为采样点索引

示例

获取每 512 个采样点对应的时间戳
