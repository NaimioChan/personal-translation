librosa.A4_to_tuning

librosa.A4_to_tuning(A4, *, bins_per_octave=12) [源码]

把参考音高频率（例如 A4=435）转换为调音估计，单位为每八度的频带分数。

在假定十二平均律的情况下，这可用于确定某给定频率相对于 A440 的调音偏差。默认每八度使用 12 个频带。

该方法是 tuning_to_A4 的逆运算。

参数

参数类型说明
A4float or np.ndarray [shape=(n,), dtype=float]

与 A4 对应的参考频率。

bins_per_octaveint > 0

每八度的频带数。

返回值

返回值类型说明
tuningfloat or np.ndarray [shape=(n,), dtype=float]

相对于 A440 的调音偏差，单位为（小数）每八度频带数。

参见

  • tuning_to_A4

示例

该方法的基础情形：A440 相对于自身的调音偏移为 0。

>>> librosa.A4_to_tuning(440.0)
0.

用默认的每八度 12 个频带，把一个非 A440 频率转换为相对于 A440 的调音偏移。

>>> librosa.A4_to_tuning(432.0)
-0.318

一次性把两个参考音高频率转换为对应的调音估计，但使用每八度 24 个频带。

>>> librosa.A4_to_tuning([440.0, 444.0], bins_per_octave=24)
array([   0.,   0.313   ])
