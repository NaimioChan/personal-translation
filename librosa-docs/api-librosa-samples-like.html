librosa.samples_like

librosa.samples_like(X, *, hop_length=512, n_fft=None, axis=-1) [源码]

返回与特征矩阵的时间轴相匹配的采样点索引数组。

参数

参数类型说明
Xnp.ndarray or scalar

  • 若为 ndarray，X 是特征矩阵，如 STFT、色度图或 mel 频谱图。

  • 若为标量，X 表示帧数。

hop_lengthint > 0 [scalar]

相邻帧之间的采样点数量

n_fftNone or int > 0 [scalar]

可选：FFT 帧长。 若给出，时间换算将包含 n_fft // 2 的偏移， 以抵消使用非居中 STFT 时的加窗效应。

axisint [scalar]

表示 X 时间轴的轴。 默认取最后一个轴（-1）。

返回值

返回值类型说明
samplesnp.ndarray [shape=(n,)]

与 X 各帧对应的采样点索引 ndarray。

参见

  • times_like：

    返回与特征矩阵的时间轴相匹配的时间值数组。

示例

提供特征矩阵输入：

>>> y, sr = librosa.loadx('trumpet')
>>> X = librosa.stft(y)
>>> samples = librosa.samples_like(X)
>>> samples
array([     0,    512, ..., 116736, 117248])

提供标量输入：

>>> n_frames = 2647
>>> samples = librosa.samples_like(n_frames)
>>> samples
array([      0,     512,    1024, ..., 1353728, 1354240, 1354752])
