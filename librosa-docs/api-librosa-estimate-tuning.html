librosa.estimate_tuning

librosa.estimate_tuning(*, y=None, sr=22050, S=None, n_fft=2048, resolution=0.01, bins_per_octave=12, **kwargs) [源码]

估计音频时间序列或频谱图输入的调音。

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频信号。支持多声道。

srnumber > 0 [scalar]

y 的音频采样率

Snp.ndarray [shape=(…, d, t)] or None

幅度或功率频谱图

n_fftint > 0 [scalar] or None

若提供了 y，所用 FFT 帧的长度。

resolutionfloat in (0, 1)

调音的分辨率，以 bin 的分数表示。 0.01 对应以音分为单位的测量。

bins_per_octaveint > 0 [scalar]

每个八度的频率 bin 数

**kwargsadditional keyword arguments

传给 piptrack 的其他参数

返回值

返回值说明
tuning: float in [-0.5, 0.5)

估计的调音偏差（以 bin 的分数表示）。

注意若输入为多声道，则给出跨越所有声道的单一调音估计。

参见

  • piptrack：

    基于抛物线插值的音高跟踪

示例

以时间序列输入

>>> y, sr = librosa.loadx('trumpet')
>>> librosa.estimate_tuning(y=y, sr=sr)
-0.08000000000000002

以十分之一音分为单位

>>> librosa.estimate_tuning(y=y, sr=sr, resolution=1e-3)
-0.016000000000000014

使用频谱图输入

>>> S = np.abs(librosa.stft(y))
>>> librosa.estimate_tuning(S=S, sr=sr)
-0.08000000000000002

向 librosa.piptrack 透传参数

>>> librosa.estimate_tuning(y=y, sr=sr, n_fft=8192,
...                         fmax=librosa.note_to_hz('G#9'))
-0.08000000000000002
