librosa.tuning_to_A4

librosa.tuning_to_A4(tuning, *, bins_per_octave=12) [源码]

把调音偏差（相对 0）转换为相对于 A440 的基准音高频率。

在非 A440 调音体系下工作时，若已知调音偏移并假定十二平均律， 该函数可用于确定基准音高频率。默认每八度使用 12 个 bin。

该方法是 A4_to_tuning 的逆运算。

参数

参数类型说明
tuningfloat or np.ndarray [shape=(n,), dtype=float]

相对于 A440 的调音偏差，单位为每八度的分数 bin。

bins_per_octaveint > 0

每八度的 bin 数。

返回值

返回值类型说明
A4float or np.ndarray [shape=(n,), dtype=float]

与 A4 对应的基准频率。

参见

  • A4_to_tuning

示例

该方法的基础情形：调音偏差为 0 时得到 A440 基准音高。

>>> librosa.tuning_to_A4(0.0)
440.

把非零调音偏移转换为对应的基准音高频率。

>>> librosa.tuning_to_A4(-0.318)
431.992

以每八度 36 个 bin 一次性把 3 个调音偏差转换为各自的基准音高频率。

>>> librosa.tuning_to_A4([0.1, 0.2, -0.1], bins_per_octave=36)
array([   440.848,    441.698   439.154])
