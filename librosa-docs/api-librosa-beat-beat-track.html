librosa.beat.beat_track

librosa.beat.beat_track(*, y=None, sr=22050, onset_envelope=None, hop_length=512, start_bpm=120.0, tightness=100, trim=True, bpm=None, prior=None, units='frames', sparse=True) [源码]

动态规划节拍跟踪器。

依照 [1] 的方法，节拍检测分三个阶段进行：

  1. 测量起始强度

  2. 由起始点相关性估计速度

  3. 在起始强度中挑选与估计速度大致相符的峰值

[1] Ellis, Daniel PW. “Beat tracking by dynamic programming.” Journal of New Music Research 36.1 (2007): 51-60. http://labrosa.ee.columbia.edu/projects/beattrack/

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频时间序列。

srnumber > 0 [scalar]

y 的采样率。

onset_envelopenp.ndarray [shape=(…, m)] or None

（可选）预先算好的起始强度包络。

hop_lengthint > 0 [scalar]

相邻两个 onset_envelope 值之间的音频采样数。

start_bpmfloat > 0 [scalar]

速度估计器的初始猜测值（单位：每分钟节拍数）。

tightnessfloat [scalar]

节拍围绕速度分布的紧凑程度。

trimbool [scalar]

裁掉起始较弱的首尾节拍。

bpmfloat [scalar] or np.ndarray [shape=(…)]

（可选）若提供，则使用 bpm 作为速度，而不从 onsets 估计速度。

若为多声道，可以为所有声道分别提供速度估计。

速度估计也可以是随时间变化的，此时 bpm 的形状应与 onset_envelope 一致，即每一帧对应一个估计值。

priorscipy.stats.rv_continuous [optional]

可选的速度先验分布。 若提供，则忽略 start_bpm。

units{‘frames’, ‘samples’, ‘time’}

检测到的节拍事件所用的编码单位。 默认使用 ‘frames’。

sparsebool

若为 True（默认），检测结果以帧、采样或时间下标的数组返回（由 units= 指定）。

若为 False，检测结果编码为稠密布尔数组，若帧下标 n 处有节拍，则 beats[..., n] 为真。

注意

仅在 sparse=False 时支持多声道输入。

返回值

返回值类型说明
tempofloat [scalar, non-negative] or np.ndarray

估计出的全局速度（单位：每分钟节拍数）。

若为多声道且未提供 bpm，则为每个声道分别返回一个速度。

注意

即使是单声道输入，默认情况下速度也以 ndarray 返回。此时该数组只有一个元素且为一维。这样做是为了让多声道输入的返回类型保持一致。

beatsnp.ndarray

估计出的节拍事件位置。

若 sparse=True（默认），节拍位置以指定的单位给出（默认是帧下标）。

若 sparse=False（多声道输入时必须如此），节拍事件以每一帧的布尔值表示。

注意

若检测不到任何起始强度，beat_tracker 会把速度估计为 0 BPM 并返回空列表。

异常

异常说明
ParameterError

若 y 与 onset_envelope 均未提供，或 units 不是 ‘frames’、‘samples’、‘time’ 之一

参见

  • librosa.onset.onset_strength

示例

使用时间序列输入跟踪节拍

>>> y, sr = librosa.loadx('choice', duration=10)
>>> tempo, beats = librosa.beat.beat_track(y=y, sr=sr)
>>> tempo
135.99917763157896

打印节拍对应的帧

>>> beats
array([  3,  21,  40,  59,  78,  96, 116, 135, 154, 173, 192, 211,
       230, 249, 268, 287, 306, 325, 344, 363])

或者把它们打印为时间戳

>>> librosa.frames_to_time(beats, sr=sr)
array([0.07 , 0.488, 0.929, 1.37 , 1.811, 2.229, 2.694, 3.135,
       3.576, 4.017, 4.458, 4.899, 5.341, 5.782, 6.223, 6.664,
       7.105, 7.546, 7.988, 8.429])

把节拍检测结果输出为布尔数组而非帧下标

>>> tempo, beats_dense = librosa.beat.beat_track(y=y, sr=sr, sparse=False)
>>> beats_dense
array([False, False, False,  True, False, False, False, False,
   False, False, False, False, False, False, False, False,
   False, False, False, False, ..., False, False,  True,
   False, False, False, False, False, False, False, False,
   False, False, False, False, False, False, False, False,
   False])

使用预先算好的起始包络跟踪节拍

>>> onset_env = librosa.onset.onset_strength(y=y, sr=sr,
...                                          aggregate=np.median)
>>> tempo, beats = librosa.beat.beat_track(onset_envelope=onset_env,
...                                        sr=sr)
>>> tempo
135.99917763157896
>>> beats
array([  3,  21,  40,  59,  78,  96, 116, 135, 154, 173, 192, 211,
       230, 249, 268, 287, 306, 325, 344, 363])

把节拍事件与起始强度包络画在一起

>>> import matplotlib.pyplot as plt
>>> hop_length = 512
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> times = librosa.times_like(onset_env, sr=sr, hop_length=hop_length)
>>> M = librosa.feature.melspectrogram(y=y, sr=sr, hop_length=hop_length)
>>> librosa.display.specshow(M, vscale='dBFS[power]',
...                          y_axis='mel', x_axis='time', hop_length=hop_length,
...                          ax=ax[0])
>>> ax[0].label_outer()
>>> ax[0].set(title='Mel spectrogram')
>>> ax[1].plot(times, librosa.util.normalize(onset_env),
...          label='Onset strength')
>>> ax[1].vlines(times[beats], 0, 1, alpha=0.5, color='r',
...            linestyle='--', label='Beats')
>>> ax[1].legend()
