librosa.vqt

librosa.vqt(y, *, sr=22050, hop_length=512, fmin=None, n_bins=84, intervals='equal', gamma=None, bins_per_octave=12, tuning=0.0, filter_scale=1, norm=1, sparsity=0.01, window='hann', scale=True, pad_mode='constant', res_type='soxr_hq', dtype=None) [源码]

计算音频信号的变 Q 变换。

本实现基于 [1] 所描述的递归子采样方法。

[1] Schörkhuber, Christian, Anssi Klapuri, Nicki Holighaus, and Monika Dörfler. “A Matlab toolbox for efficient perfect reconstruction time-frequency transforms with log-frequency resolution.” In Audio Engineering Society Conference: 53rd International Conference: Semantic Audio. Audio Engineering Society, 2014.

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

hop_lengthint > 0 [scalar]

相邻 VQT 列之间相隔的样本数。

fminfloat > 0 [scalar]

最小频率。默认为 C1 ~= 32.70 Hz

n_binsint > 0 or None [scalar]

从 fmin 开始的频率 bin 数量。 若为 None，则取能容纳在 sr/2 以下的最大 bin 数量。

intervalsstr or array of floats in [1, 2)

可以是区间集的字符串标识，例如 ‘equal’、‘pythagorean’、‘ji3’ 等；也可以是介于 1 与 2 之间表示各区间数值的数组。 .. see also:: librosa.interval_frequencies

gammanumber > 0 [scalar]

用于确定滤波器长度的带宽偏移量。

若 gamma=0，则得到常数 Q 变换。

若取 ‘gamma=None’，gamma 的取值会使得各滤波器带宽等于相应等效矩形带宽（ERB）的一个固定比例。做法是求解满足下式的 gamma：

B_k = alpha * f_k + gamma = C * ERB(f_k),

其中 B_k 是中心频率为 f_k 的滤波器 k 的带宽，alpha 本应为常数 Q 因子的倒数，而 C = alpha / 0.108 是所有滤波器共用的常数比例。

这里使用 ERB(f_k) = 24.7 + 0.108 * f_k，该曲线由 [2] 中的实验数据拟合得到。

[2] Glasberg, Brian R., and Brian CJ Moore. “Derivation of auditory filter shapes from notched-noise data.” Hearing research 47.1-2 (1990): 103-138.

bins_per_octaveint > 0 [scalar]

每八度的 bin 数量

tuningNone or float

调音偏移量，以 bin 的小数部分表示。

若为 None，则从信号中自动估计调音。

所得 VQT 的最小频率将被调整为 fmin * 2**(tuning / bins_per_octave)。

filter_scalefloat > 0

滤波器尺度因子。较小的值（<1）使用更短的窗，从而提高时间分辨率。

norm{inf, -inf, 0, float > 0}

基函数归一化所用的范数类型。 见 librosa.util.normalize。

sparsityfloat in [0, 1)

通过丢弃每个基中最多 sparsity 比例的能量来稀疏化 VQT 基。

设置 sparsity=0 可关闭稀疏化。

windowstr, tuple, number, or function

基滤波器的窗规格。 详情见 filters.get_window。

scalebool

若为 True，按各通道滤波器长度的平方根缩放 VQT 响应。这类似于 FFT 中的 norm='ortho'。

若为 False，则不对 VQT 缩放。这类似于 FFT 中的 norm=None。

pad_modestr

居中分帧分析时的填充模式。

另见：librosa.stft 与 numpy.pad。

res_typestr

递归降采样所用的重采样方式。

dtypenp.dtype

输出数组的数据类型。默认为与输入信号的数值精度相匹配的类型。

示例

生成并绘制变 Q 功率谱

>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('choice', duration=5)
>>> C = np.abs(librosa.cqt(y, sr=sr))
>>> V = np.abs(librosa.vqt(y, sr=sr))
>>> fig, ax = plt.subplots(nrows=2, sharex=True, sharey=True)
>>> librosa.display.specshow(C, vscale='dBFS',
...                          sr=sr, x_axis='time', y_axis='cqt_note', ax=ax[0])
>>> ax[0].set(title='Constant-Q power spectrum', xlabel=None)
>>> ax[0].label_outer()
>>> img = librosa.display.specshow(V, vscale='dBFS',
...                                sr=sr, x_axis='time', y_axis='cqt_note', ax=ax[1])
>>> ax[1].set_title('Variable-Q power spectrum')
>>> librosa.display.colorbar_db(img, ax=ax)
