librosa.util.example_info

librosa.util.example_info(key, *, html=False) [源码]

显示给定示例录音的许可与元数据信息。

首次请求某个示例时，会通过 HTTPS 从远程仓库下载。 之后的所有请求都使用本地缓存的录音副本。

示例列表（及其 key）见 librosa.util.list_examples。

默认情况下，本地文件缓存在 pooch.os_cache(‘librosa’) 指定的目录中。 可在导入 librosa 之前设置环境变量 LIBROSA_DATA_DIR 来覆盖。

参数

参数类型说明
keystr

录音的标识符（见 list_examples）

htmlbool

若为 True，以 HTML 格式返回信息。 若为 False，以纯文本格式打印信息。

返回值

返回值类型说明
infostr or None

若 html 为 True，返回 HTML 格式的字符串。 否则无返回值。
