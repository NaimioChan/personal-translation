使用不同的频率轴

本节介绍各种频谱表示形式的频谱图显示，以及用于标注绘图坐标轴的不同记谱系统。

频率范围

上一节介绍了如何用 specshow 可视化短时傅里叶变换（STFT）。 STFT 大概是音频频谱分析最常见的起点，但它并非唯一的选择。

取决于你想强调什么，STFT 未必是最佳的显示选择。CQT 和 mel 频谱图使用不同的频率刻度，specshow 需要知道它显示的是哪一种。这由 y_axis= 参数控制。

下面用同一段音频比较三种频谱图：STFT、CQT 和 mel。

import matplotlib.pyplot as plt
import librosa
from IPython.display import HTML

y, sr = librosa.loadx("sweetwaltz", duration=20)
HTML(librosa.util.example_info("sweetwaltz", html=True))

Description

# Compute an STFT
stft = librosa.stft(y)

# Compute a CQT.  n_bins=None will use as many frequencies as necessary to cover
# the frequency range
cqt = librosa.cqt(y=y, sr=sr, n_bins=None)

# Compute a mel spectrogram
mel = librosa.feature.melspectrogram(y=y, sr=sr)

# And create three subplots for them
fig, ax = plt.subplots(nrows=3, sharex=True, sharey=True)

librosa.display.specshow(stft, x_axis="time", y_axis="hz", vscale="dBFS", ax=ax[0])
librosa.display.specshow(cqt, x_axis="time", y_axis="cqt_hz", vscale="dBFS", ax=ax[1])
librosa.display.specshow(mel, x_axis="time", y_axis="mel", vscale="dBFS[power]", ax=ax[2])

ax[0].set(ylabel="STFT")
ax[1].set(ylabel="CQT")
ax[2].set(ylabel="Mel")
for axi in ax.flat:
    axi.label_outer()

注意

这些显示使用 dBFS 数值缩放，即分贝是相对于输入中的最大值计算的。对于 STFT 和 CQT，输出的幅度对应振幅，而对于 mel 频谱图，输出以功率衡量。因此为了正确显示，我们需要告诉 vscale：分贝是由功率测量而非振幅测量得到的。

要点在于，STFT 和 CQT 以源自振幅的 dB 单位显示，而 mel 频谱图通常以源自功率的 dB 单位显示。

与上一节的 STFT 分析一样，这里依赖 librosa.cqt 和 librosa.feature.melspectrogram 的默认参数。如果偏离这些默认值，就必须相应地告知 specshow。

# Use 3 bins per semitone, and span 8 octaves
cqt = librosa.cqt(y=y, sr=sr, n_bins=8*3*12, bins_per_octave=3*12)

fig, ax = plt.subplots()
librosa.display.specshow(cqt, x_axis="time", y_axis="cqt_hz", vscale="dBFS",
                         sr=sr, bins_per_octave=3*12)
ax.set(title="CQT with 8 octaves, 36 bins per octave")

一般来说，在计算频谱图时设置的参数很可能也与显示相关。这里在计算 CQT 时指定了 n_bins 和 bins_per_octave。我们不需要在 specshow 中指定 n_bins，因为它可以从 cqt 的形状推断出来。我们确实需要告诉它每倍频程有多少个 bin，而这一点无法仅从数据的形状推断。如果拿不准该向 specshow 传哪些参数，所有可接受的参数都列在 librosa.display.specshow 的文档中。

坐标轴标注

到目前为止，我们都用 Hz 来标注频率轴。这是一个不错的默认选择，但并不总是信息量最大的选择。在音乐应用中，音名或倍频程频带通常更容易读。

specshow 为此提供了几种不同的格式：

  • cqt_hz，以 Hz 表示的频率，主刻度位于相对于 fmin 参数的倍频程处，

  • cqt_oct3，以1/3 倍频程频带表示的频率，

  • cqt_note，以科学音高记谱法表示的频率，

  • cqt_svara，以印度斯坦或卡纳提克记谱法表示的频率，相对于给定的 Sa 频率。

前两种模式在声学中更常见，后两种则在音乐学中更常见。所有情况下，底层的显示单位都不变（Hz），只有坐标轴的标注发生变化。

下面的例子比较 Hz、oct3 和 note：

fig, ax = plt.subplots(nrows=3, sharex=True, figsize=(8, 8))
librosa.display.specshow(cqt, x_axis="time", y_axis="cqt_hz", vscale="dBFS",
                         sr=sr, bins_per_octave=3*12, ax=ax[0])
librosa.display.specshow(cqt, x_axis="time", y_axis="cqt_oct3", vscale="dBFS",
                         sr=sr, bins_per_octave=3*12, ax=ax[1])
librosa.display.specshow(cqt, x_axis="time", y_axis="cqt_note", vscale="dBFS",
                         sr=sr, bins_per_octave=3*12, ax=ax[2])
for axi in ax.flat:
    axi.label_outer()

这些显示展示的是同一份底层 CQT 数据，只有刻度标签不同。

当把显示限制在更窄的频率范围时，差异会更加明显。

fig, ax = plt.subplots(nrows=3, sharex=True, figsize=(8, 8))
librosa.display.specshow(cqt, x_axis="time", y_axis="cqt_hz", vscale="dBFS",
                         sr=sr, bins_per_octave=3*12, ax=ax[0])
librosa.display.specshow(cqt, x_axis="time", y_axis="cqt_oct3", vscale="dBFS",
                         sr=sr, bins_per_octave=3*12, ax=ax[1])
librosa.display.specshow(cqt, x_axis="time", y_axis="cqt_note", vscale="dBFS",
                         sr=sr, bins_per_octave=3*12, ax=ax[2])

for axi in ax.flat:
    axi.set(ylim=[250, 500])
    axi.label_outer()

以上示例都用 cqt 来演示不同的刻度格式，但实际上这些格式可以结合多种（并非全部）频率表示使用，例如 mel_oct3、fft_note 等。支持的组合记录在 librosa.display.specshow 中。

小结

specshow 把底层数据与坐标轴标注方式分离开来。因此，同一张频谱图可以根据语境用 Hz、音名、倍频程频带或其他约定来标注。实践中，最重要的一步是选择一个既匹配你计算的表示、又匹配你想沟通的受众的 y_axis= 设置。
