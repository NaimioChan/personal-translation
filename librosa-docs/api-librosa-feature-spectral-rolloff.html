librosa.feature.spectral_rolloff

librosa.feature.spectral_rolloff(*, y=None, sr=22050, S=None, n_fft=2048, hop_length=512, win_length=None, window='hann', center=True, pad_mode='constant', freq=None, roll_percent=0.85) [源码]

计算滚降频率。

对每一帧，滚降频率定义为这样一个频谱图频格的中心频率： 该帧频谱中至少 roll_percent（默认为 0.85）的 能量位于该频格及其下方的频格中。它可以用来， 例如，把 roll_percent 设为接近 1（或 0）的值来近似最大（或 最小）频率。

参数

参数类型说明
ynp.ndarray [shape=(…, n)] or None

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的音频采样率

Snp.ndarray [shape=(d, t)] or None

（可选）频谱图幅度

n_fftint > 0 [scalar]

FFT 帧长度

hop_lengthint > 0 [scalar]

STFT 的跳距。详见 librosa.stft。

win_lengthint <= n_fft [scalar]

每一帧音频都用 window() 加窗。 窗的长度为 win_length，随后补零 至 n_fft 长度。 若未指定，默认为 win_length = n_fft。

windowstr, tuple, number, function, or np.ndarray [shape=(n_fft,)]

  • 窗的规格（字符串、元组或数值）； 见 scipy.signal.get_window

  • 窗函数，例如 scipy.signal.windows.hann

  • 长度为 n_fft 的向量或数组

centerbool

  • 若为 True，则对信号 y 进行填充，使帧 t 以 y[t * hop_length] 为中心。

  • 若为 False，则帧 t 起始于 y[t * hop_length]

pad_modestr

若 center=True，在信号边缘使用的填充模式。 默认情况下，STFT 使用零填充。

freqNone or np.ndarray [shape=(d,) or shape=(…, d, t)]

频谱图频格的中心频率。 若为 None，则使用 FFT 频格的中心频率。 否则，可以是一个含 d 个中心频率的数组， .. note:: 假定 freq 已按升序排列

roll_percentfloat [0 < roll_percent < 1]

滚降百分比。

返回值

返回值类型说明
rolloffnp.ndarray [shape=(…, 1, t)]

每一帧的滚降频率

示例

由时间序列输入

>>> y, sr = librosa.loadx('trumpet')
>>> # 用 roll_percent=0.85（默认）近似最高频率
>>> librosa.feature.spectral_rolloff(y=y, sr=sr)
array([[2583.984, 3036.182, ..., 9173.145, 9248.511]])
>>> # 用 roll_percent=0.99 近似最高频率
>>> rolloff = librosa.feature.spectral_rolloff(y=y, sr=sr, roll_percent=0.99)
>>> rolloff
array([[ 7192.09 ,  6739.893, ..., 10960.4  , 10992.7  ]])
>>> # 用 roll_percent=0.01 近似最低频率
>>> rolloff_min = librosa.feature.spectral_rolloff(y=y, sr=sr, roll_percent=0.01)
>>> rolloff_min
array([[516.797, 538.33 , ..., 764.429, 764.429]])

由频谱图输入

>>> S, phase = librosa.magphase(librosa.stft(y))
>>> librosa.feature.spectral_rolloff(S=S, sr=sr)
array([[2583.984, 3036.182, ..., 9173.145, 9248.511]])
>>> # 使用更高的滚降百分比：
>>> librosa.feature.spectral_rolloff(y=y, sr=sr, roll_percent=0.95)
array([[ 3919.043,  3994.409, ..., 10443.604, 10594.336]])
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots()
>>> librosa.display.specshow(S, vscale='dBFS',
...                          y_axis='log', x_axis='time', ax=ax)
>>> hl = librosa.display.highlight(ax=ax, linewidth=3, alpha=0.5)
>>> ax.plot(librosa.times_like(rolloff), rolloff_min[0],
...         path_effects=hl,
...         label='Roll-off frequency (0.01)')
>>> ax.plot(librosa.times_like(rolloff), rolloff[0],
...         path_effects=hl,
...         label='Roll-off frequency (0.99)')
>>> ax.legend(loc='lower right')
>>> ax.set(title='log Power spectrogram')
