幅度缩放

函数说明

magphase

将复值频谱图 D 分解为幅度（S）与相位（P）两个分量，满足 D = S * P。

amplitude_to_db

把幅度频谱图转换为 dB 刻度的频谱图。

db_to_amplitude

把 dB 刻度的频谱图转换为幅度频谱图。

power_to_db

把功率频谱图（幅度的平方）转换为分贝（dB）单位

db_to_power

把 dB 刻度的数值转换为功率值。

perceptual_weighting

对功率频谱图做感知加权。

frequency_weighting

计算一组频率的加权值。

multi_frequency_weighting

计算一组频率的多种加权值。

A_weighting

计算一组频率的 A 计权值。

B_weighting

计算一组频率的 B 计权值。

C_weighting

计算一组频率的 C 计权值。

D_weighting

计算一组频率的 D 计权值。

pcen

逐声道能量归一化（PCEN）

mu_compress

μ-law 压缩

mu_expand

μ-law 扩展
