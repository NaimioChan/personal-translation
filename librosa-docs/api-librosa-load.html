librosa.load

librosa.load(path, *, sr=22050, mono=True, offset=0.0, duration=None, dtype=<class 'numpy.float32'>, res_type='soxr_hq') [源码]

把音频文件加载为浮点时间序列。

音频会自动重采样到给定采样率 （默认 sr=22050）。

若想保留文件的原生采样率，请使用 sr=None。

参数

参数类型说明
pathstr, int, pathlib.Path, soundfile.SoundFile, or file-like object

输入文件的路径。

soundfile 支持的任意编解码器均可使用。

任意字符串文件路径，或任意实现 Python 文件接口的对象 （例如 pathlib.Path）都可以作为 path。

若编解码器由 soundfile 支持，则 path 也可以是 一个已打开的文件描述符（int）或已存在的 soundfile.SoundFile 对象。

srnumber > 0 [scalar]

目标采样率

取 ‘None’ 时使用原生采样率

monobool

把信号转为单声道

offsetfloat

从该时间之后开始读取（以秒计）。

若为负值，则相对于文件末尾解释。

durationfloat

最多只加载这么长的音频（以秒计）

dtypenumeric type

y 的数据类型

res_typestr

重采样类型（见注意事项）

注意

默认使用 soxr 的高质量模式（‘HQ’）。

其他重采样模式参见 resample

返回值

返回值类型说明
ynp.ndarray [shape=(n,) or (…, n)]

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

示例

>>> # Load an ogg vorbis file
>>> filename = librosa.ex('trumpet')
>>> y, sr = librosa.load(filename)
>>> y
array([-1.407e-03, -4.461e-04, ..., -3.042e-05,  1.277e-05],
      dtype=float32)
>>> sr
22050
>>> # Load a file and resample to 11 KHz
>>> filename = librosa.ex('trumpet')
>>> y, sr = librosa.load(filename, sr=11025)
>>> y
array([-8.746e-04, -3.363e-04, ..., -1.301e-05,  0.000e+00],
      dtype=float32)
>>> sr
11025
>>> # Load 5 seconds of a file, starting 15 seconds in
>>> filename = librosa.ex('brahms')
>>> y, sr = librosa.load(filename, offset=15.0, duration=5.0)
>>> y
array([0.146, 0.144, ..., 0.128, 0.015], dtype=float32)
>>> sr
22050
>>> # Load using an already open SoundFile object
>>> import soundfile
>>> sfo = soundfile.SoundFile(librosa.ex('brahms'))
>>> y, sr = librosa.load(sfo)
