librosa.display.wavef0

librosa.display.wavef0(y, *, f0, sr=22050, hop_length=512, bins_per_octave=12, time_axis='time', freq_axis='cqt_note', offset=0.0, key='C:maj', Sa=None, mela=None, thaat=None, unicode=True, ax=None, method='waveshow', transpose=False, **kwargs) [源码]

可视化带有 f0 位移的波形。

它可以在同一张紧凑的图中同时可视化基频（f0）估计值与音频信号的波形或幅度包络。

参数

参数类型说明
ynp.ndarray [shape=(n,) or (2,n)]

音频时间序列（单声道或立体声） 若为立体声，左声道的幅度包络用于图的上半部分，右声道的幅度包络（取负）用于图的下半部分。 若为单声道，信号包络沿轴镜像。

f0np.ndarray [shape=(m,)]

以 Hz 计的基频（f0）估计值。 应使用音高估计算法计算，例如 librosa.pyin 或 librosa.yin。

srnumber > 0 [scalar]

y 的采样率（每秒采样点数）

hop_lengthint > 0

相邻 f0 估计之间的跳距（以采样点数计）。 这应与计算 f0 时所用的跳距一致。

bins_per_octaveint > 0

用于按 f0 缩放波形幅度位移的每八度频率 bin 数量。它与波形的峰值幅度（用作位移范数）共同决定：向上或向下偏离 f0 一个八度对应多少个 bin 的垂直位移。

time_axisstr

时间轴刻度与刻度标记的显示样式。 可取值为：

  • ‘time’：标记显示为毫秒、秒、分钟或小时。

  • ‘h’：标记显示为小时、分钟和秒。

  • ‘m’：标记显示为分钟和秒。

  • ‘s’：标记显示为秒。

  • ‘ms’：标记显示为毫秒。

  • ‘lag’：同 time，但超过中点部分按负值计。

  • ‘lag_h’：同 lag，但以小时表示。

  • ‘lag_m’：同 lag，但以分钟表示。

  • ‘lag_s’：同 lag，但以秒表示。

  • ‘lag_ms’：同 lag，但以毫秒表示。

  • None、‘none’ 或 ‘off’：隐藏刻度与刻度标记。

freq_axisstr

频率轴刻度与刻度标记的显示样式。 可取值为：

  • ‘cqt_note’：标记显示为音名。

  • ‘cqt_hz’：标记显示为以 Hz 计的频率。

  • ‘cqt_oct3’：标记以 Hz 显示，采用 1/3 八度间隔。

  • ‘cqt_svara’：标记显示为印度古典音乐中的 svara 名称。

offsetfloat

波形图的起始偏移（单位秒）。

keystr

频率轴的调号。 使用 cqt_note 模式时，它用于确定频率轴上的音名。

Safloat or None

频率轴的 Sa（主音）频率，单位 Hz。 cqt_svara 模式下必需。

melastr or int or None

频率轴的 mela（音阶）名称或索引。 使用 cqt_svara 模式时，它用于确定频率轴上的 svara 名称。

thaatstr or None

频率轴的 thaat（音阶）名称。 使用 cqt_svara 模式时，它用于确定频率轴上的 svara 名称。

unicodebool

若为 True，频率轴标签使用 Unicode 字符。

axmatplotlib.axes.Axes or None

用于绘制的坐标轴，代替默认的 plt.gca()。

methodstr

可视化带 f0 位移波形所用的方法。 可取值为：

  • ‘waveshow’：使用 librosa.display.waveshow 可视化带 f0 位移的波形。

  • ‘wavebars’：使用 librosa.display.wavebars 把带 f0 位移的波形可视化为条。

transposebool

若为 True，波形纵向而非横向显示。

**kwargsdict

转发给 method 所选绘图函数的其他关键字参数。

若 method=’waveshow’，它们必须是 librosa.display.waveshow 支持的关键字参数（例如 max_points）。

若 method=’wavebars’，它们必须是 librosa.display.wavebars 支持的关键字参数（例如 n_bars、gap_ratio、rounding_ratio、invert 和 invert_color）。

适用于一种方法的关键字参数在另一种方法下无效。

返回值

返回值说明
AdaptiveWaveplot or PatchCollection

若 method=’waveshow’，返回 librosa.display.AdaptiveWaveplot 类型的对象；若 method=’wavebars’，返回 matplotlib.collections.PatchCollection。

参见

  • waveshow
  • wavebars

示例

使用 waveshow 可视化带 f0 位移的波形

>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('trumpet')
>>> f0, _, _ = librosa.pyin(y, fmin=librosa.note_to_hz('C2'),
...                         fmax=librosa.note_to_hz('C7'),
...                         sr=sr, hop_length=512)
>>> fig, ax = plt.subplots()
>>> librosa.display.wavef0(y=y, f0=f0, sr=sr, ax=ax,
...                        method='waveshow')
>>> ax.set(title='Waveform with f0 displacement (waveshow)')
>>> plt.show()

使用 wavebars 可视化带 f0 位移的波形，并以 Hz 而非音名标注。 这里使用较多的条数以显示更多细节。

>>> fig, ax = plt.subplots()
>>> librosa.display.wavef0(y=y, f0=f0, sr=sr, ax=ax, n_bars=256,
...                        method='wavebars', freq_axis='cqt_hz')
>>> ax.set(title='Waveform with f0 displacement (wavebars, cqt_hz)')
>>> plt.show()

通过 specshow 把位移后的波形叠加在 CQT 图上。

>>> fig, ax = plt.subplots()
>>> C = librosa.cqt(y, sr=sr)
>>> librosa.display.specshow(C, ax=ax, sr=sr, x_axis='time', y_axis='cqt_note',
...                          vscale='dBFS', cmap='gray_r')
>>> hl = librosa.display.highlight(ax=ax)
>>> librosa.display.wavef0(y=y, f0=f0, sr=sr, ax=ax, path_effects=hl)
