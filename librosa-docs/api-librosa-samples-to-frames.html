librosa.samples_to_frames

librosa.samples_to_frames(samples, *, hop_length=512, n_fft=None) [源码]

把采样点索引转换为 STFT 帧。

参数

参数类型说明
samplesint or np.ndarray [shape=(n,)]

采样点索引或采样点索引向量

hop_lengthint > 0 [scalar]

相邻帧之间的采样点数量

n_fftNone or int > 0 [scalar]

可选：FFT 帧长。 若给出，时间换算将包含 - n_fft // 2 的偏移， 以抵消 STFT 中的加窗效应。

注意

这可能产生负的帧索引。

返回值

返回值类型说明
framesint or np.ndarray [shape=(n,), dtype=int]

与给定时长对应的帧号：

frames[i] = floor( samples[i] / hop_length )

参见

  • samples_to_time：

    把采样点索引转换为时间值

  • frames_to_samples：

    把帧索引转换为采样点索引

示例
