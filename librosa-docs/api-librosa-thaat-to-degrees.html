librosa.thaat_to_degrees

librosa.thaat_to_degrees(thaat) [源码]

构造给定 thaat 的 svara 音级索引（度数）

参数

参数类型说明
thaatstr

thaat 的名称

返回值

返回值类型说明
indicesnp.ndarray

指定 thaat 所含七个 svara 音级索引的列表（从 0=Sa 开始）

参见

  • key_to_degrees
  • mela_to_degrees
  • list_thaat

示例

>>> librosa.thaat_to_degrees('bilaval')
array([ 0,  2,  4,  5,  7,  9, 11])
>>> librosa.thaat_to_degrees('todi')
array([ 0,  1,  3,  6,  7,  8, 11])
