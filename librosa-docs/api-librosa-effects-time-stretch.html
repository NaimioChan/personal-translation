librosa.effects.time_stretch

librosa.effects.time_stretch(y, *, rate, **kwargs) [源码]

按固定比率对音频序列做时间拉伸。

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频时间序列。支持多声道。

ratefloat > 0 [scalar]

拉伸比率。若 rate > 1，信号被加速。 若 rate < 1，信号被减速。

**kwargsadditional keyword arguments.

详见 librosa.decompose.stft。

返回值

返回值类型说明
y_stretchnp.ndarray [shape=(…, round(n/rate))]

按指定比率拉伸后的音频时间序列

参见

  • pitch_shift：

    音高移动

  • librosa.phase_vocoder：

    频谱图相位声码器

  • pyrubberband.pyrb.time_stretch：

    使用 RubberBand 的高质量时间拉伸

示例

压缩到两倍速

>>> y, sr = librosa.loadx('choice')
>>> y_fast = librosa.effects.time_stretch(y, rate=2.0)

或放慢到原速的一半

>>> y_slow = librosa.effects.time_stretch(y, rate=0.5)
