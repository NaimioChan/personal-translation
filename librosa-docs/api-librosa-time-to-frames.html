librosa.time_to_frames

librosa.time_to_frames(times, *, sr=22050, hop_length=512, n_fft=None) [源码]

把时间戳转换为 STFT 帧。

参数

参数类型说明
timesnp.ndarray [shape=(n,)]

时间（秒）或时间值向量

srnumber > 0 [scalar]

音频采样率

hop_lengthint > 0 [scalar]

相邻帧之间的采样点数

n_fftNone or int > 0 [scalar]

可选：FFT 帧的长度。 若给定，时间换算会附加 - n_fft // 2 的偏移， 以抵消 STFT 中的加窗效应。

注意

这可能导致帧索引为负。

返回值

返回值类型说明
framesnp.ndarray [shape=(n,), dtype=int]

与给定时间对应的帧号：

frames[i] = floor( times[i] * sr / hop_length )

参见

  • frames_to_time：

    把帧索引转换为时间值

  • time_to_samples：

    把时间值转换为采样索引

示例

获取每 100 毫秒对应的帧号

>>> librosa.time_to_frames(np.arange(0, 1, 0.1),
...                         sr=22050, hop_length=512)
array([ 0,  4,  8, 12, 17, 21, 25, 30, 34, 38])
