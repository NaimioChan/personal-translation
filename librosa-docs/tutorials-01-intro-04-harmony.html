和声与色度

本节介绍用于分析音频录音中谐波内容的工具。

频率与谐波

上一节中，我们看到了如何识别单音信号的基频（f0）。基频通常就是我们把一个声音当成「音高」来识别的那个频率。 然而声音往往比单一的频率复杂得多。 大多数有意思的声音都包含能量和许多相关频率，对于乐器（包括人声）而言，这些频率通常体现为基频的谐波。 对于频率 f，第 n 次谐波（n = 1, 2, 3, …）就是频率 n*f。

import librosa

import matplotlib.pyplot as plt
from IPython.display import HTML

y, sr = librosa.loadx("trumpet")
HTML(librosa.util.example_info("trumpet", html=True))

在上面的小号示例中，我们可以观察到一个重复的竖直图案。 如果在 f0 处有能量（颜色较亮），例如信号开头附近约 620 Hz 处，那么在频率为其两倍（约 1240 Hz）、三倍 （1860 Hz）等等的位置也有能量。 能量在基频各次谐波上的这种分布，构成了乐器的音色。

常数 Q 谱

到目前为止，我们一直依赖短时傅里叶变换（STFT）来分析信号随时间变化的频率内容。 对于谐波内容分析，STFT 有几个局限：

  1. 频率集合在 0 到 sr/2 之间线性分布。 这本身并不错，但它与谐波的概念并不直接对应，因为谐波是几何分布的。

  2. 帧长对所有频率都是固定的（n_fft）。这意味着低频在帧内只会完成少数几个周期， 而高频则会完成很多个周期。结果是对低频的分辨能力相对较差，而这在分析音乐信号时可能很重要。

常数 Q 变换（CQT）正是为了解决这些问题而提出的。 其基本思想与 STFT 相当接近，都是把信号切成小块，再与一组固定频率的参考正弦波进行比较。 区别在于：1）频率采用几何间隔选取， 因此第 n`th frequency is given as `2**(n / bins_per_octave) * f_min（f_min > 0 为最小分析频率）；2）CQT 不在各频率上固定帧的时长，而是在各频率上固定所完成的周期数，并允许帧长变化（同时仍以给定的索引为中心）。

在 librosa 中计算信号的 CQT 可以用下面的代码：

C = librosa.cqt(y=y, sr=sr)

默认情况下，CQT 每八度使用 12 个频带，最小频率为 C1 （约 32.7 Hz），并跨越 7 个八度，覆盖 32.7（C1）到 3951（B7）的范围。

我们可以像 STFT 那样通过 specshow 函数来可视化 CQT，但要注意 y_axis 参数现在不同了：

fig, ax = plt.subplots()
img = librosa.display.specshow(C, vscale="dBFS",
                               x_axis="time", y_axis="cqt_hz",
                               ax=ax)
librosa.display.colorbar_db(img, label="dBFS")

上图应当与 STFT 的可视化看起来有些相似，有两点不同：

  1. 频率分辨率更低：现在只有 84 个频率，而不是 1025 个。

  2. 频率范围更低：图在约 4 KHz 处结束，而不是 STFT 中的 11 KHz。

这两点都可以通过设置 CQT 的参数来调整。 例如，要使用比默认 12 更多的每八度频带数，可以设置 bins_per_octave=36。这里支持任何正整数，不过通常取十二的奇数倍比较合适，这样可以在提高分辨率的同时保持与 12TET / A440 体系的对齐。

注意，当你增加每八度频带数时，也必须相应地增加频带总数。所以如果我们从每八度 12 个频带增加到 36 个频带，也就应该从 84 个频带增加到 252 个频带，以保持相同的频率范围。 你只需改变 n_bins 参数，就能扩展或收缩频率范围。

我们来创建一个新的 CQT，具有更高的频率分辨率和略高的频率范围。

C = librosa.cqt(y=y, sr=sr,
                bins_per_octave=12 * 3,  # writing it this way makes the octave division clear
                n_bins=12 * 3 * 8)       # this makes it clear that we have 8 octaves now

我们也可以像之前那样可视化，但需要告诉 specshow 使用正确的每八度频带数。 （关于在 specshow 中配置频率范围的更多信息，请参阅频率范围。）

fig, ax = plt.subplots()
img = librosa.display.specshow(C, vscale="dBFS",
                               x_axis="time", y_axis="cqt_hz",
                               bins_per_octave=12 * 3,
                               ax=ax)
librosa.display.colorbar_db(img, label="dBFS")

从视觉上看，CQT 图现在应当与我们最初看到的 STFT 图非常相似。 然而在数值上，它们是相当不同的对象：

print(f"STFT shape={S.shape}")
print(f"CQT shape={C.shape}")
STFT shape=(1025, 230)
CQT shape=(288, 230)

除了表示更紧凑之外，在提取谐波相关的频率内容时，CQT 也比 STFT 更便于使用。

色度

到这里，要把音符（基频）与谐波区分开来就困难得多了，而且一般来说有更多信息需要理清。

当我们分析录音的谐波内容时，往往并不关心确切的频率和音高，而是关心音级，即把音高归约到一个八度之内。 这正是色度表示想要捕捉的东西，它们一般通过把时频表示（在这里是 CQT）中与每个音级对应的所有频率上的信息聚合起来实现。 例如，C 音级会从 32.7、65.4、130.8、261.6 等频率收集能量。 C♯ 音级则会从 34.6、69.3、138.6、277.2 等频率收集能量，这个模式对从 C 到 B 的所有音级依次重复。

librosa 实现了若干种构造色度表示的方法，这里我们演示基于 CQT 的方法。 默认情况下，它会使用每八度 36 个频带、跨越 7 个八度的 CQT。

chroma = librosa.feature.chroma_cqt(y=y, sr=sr)

sphinx_gallery_thumbnail_number = 5 我们同样可以用 specshow 来可视化，这次把 y_axis 模式设为 chroma。 我们会把它画在上面 CQT 图的下方，便于直接对比两者。

fig, ax = plt.subplots(nrows=2, sharex=True, height_ratios=(3, 1))
imgcqt = librosa.display.specshow(C, vscale="dBFS",
                                  x_axis="time",
                                  y_axis="cqt_hz",
                                  bins_per_octave=12*3,
                                  ax=ax[0])
librosa.display.colorbar_db(imgcqt, label="dBFS")
ax[0].label_outer()  # only show x-axis labels on the bottom plot
imgchroma = librosa.display.specshow(chroma,
                                     x_axis="time",
                                     y_axis="chroma",
                                     ax=ax[1])
fig.colorbar(imgchroma, ax=ax[1], aspect=20/3)  # aspect compensates for the 3:1 height ratio of these plots

色度的每一行对应一个音级，其数值对应在该音级内检测到的相对能量多少。 注意这些数值现在被归一化到 [0, 1] 区间，这样做是为了对响度变化有一定的稳健性。

与 f0 估计不同，任意时刻都可能有多个音级同时活跃。 因此色度特征常用作自动和弦估计的特征表示，其中每个时间步被映射为诸如 F:maj 或 D:min 的和弦标签。 虽然可以用模板匹配来构建一个基本的和弦估计方法 （参见 librosa.sequence.viterbi_discriminative 中的例子），但现代方法一般都 涉及有监督机器学习，超出了 librosa 的范围。

小结

本节介绍了常数 Q 变换和色度表示，作为表示音乐信号中谐波内容的手段。 不过上面描述的方法都相当基础，借助更高级的预处理和后处理技巧，有很多改进的余地。 如果你想进一步了解如何设计有效的色度表示，可以看看增强色度。
