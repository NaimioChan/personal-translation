librosa.filters.window_bandwidth

librosa.filters.window_bandwidth(window, n=1000) [源码]

获取窗函数的等效噪声带宽（ENBW）。

窗的 ENBW 由 [1]（公式 11）定义为平方和与和的平方之比，并做归一化：

enbw = n * sum(window**2) / sum(window)**2

[1] Harris, F. J. “On the use of windows for harmonic analysis with the discrete Fourier transform.” Proceedings of the IEEE, 66(1), 51-83. 1978.

参数

参数类型说明
windowcallable or str

窗函数，或窗函数名， 例如：scipy.signal.hann 或 ‘boxcar’

nint > 0

估计窗带宽时所用的系数量

返回值

返回值类型说明
bandwidthfloat

给定窗函数的等效噪声带宽（以 FFT bin 为单位）

说明

本函数在层级 10 缓存。
