librosa.icqt

librosa.icqt(C, *, sr=22050, hop_length=512, fmin=None, bins_per_octave=12, tuning=0.0, filter_scale=1, norm=1, sparsity=0.01, window='hann', scale=True, length=None, res_type='soxr_hq', dtype=None) [源码]

计算逆常数 Q 变换。

给定音频信号 y 的常数 Q 变换表示 C， 该函数产生近似 y_hat。

参数

参数类型说明
Cnp.ndarray, [shape=(…, n_bins, n_frames)]

由 cqt 产生的常数 Q 表示

srnumber > 0 [scalar]

信号的采样率

hop_lengthint > 0 [scalar]

相邻帧之间的采样点数

fminfloat > 0 [scalar]

最低频率。默认取 C1 ~= 32.70 Hz

bins_per_octaveint > 0 [scalar]

每个八度的 bin 数量

tuningfloat [scalar]

调音偏移，以 bin 的比例表示。

CQT 的最低频率会被调整为 fmin * 2**(tuning / bins_per_octave)。

filter_scalefloat > 0 [scalar]

滤波器缩放因子。较小的值（<1）会使用更短的窗， 以提高时间分辨率。

norm{inf, -inf, 0, float > 0}

基函数归一化所使用的范数类型。 参见 librosa.util.normalize。

sparsityfloat in [0, 1)

通过丢弃每个基函数中最多 sparsity 比例的能量来稀疏化 CQT 基函数。

将 sparsity=0 可禁用稀疏化。

windowstr, tuple, number, or function

基滤波器的窗规格。 详见 filters.get_window。

scalebool

若为 True，按每个通道滤波器长度的平方根缩放 CQT 响应。这相当于 FFT 中的 norm='ortho'。

若为 False，则不对 CQT 缩放。这相当于 FFT 中的 norm=None。

lengthint > 0, optional

若提供，输出 y 会被零填充或裁剪到恰好 length 个采样点。

res_typestr

重采样模式。 支持的模式参见 librosa.resample。

dtypenumeric type

y 的实数数值类型。默认根据输入 CQT 的 数值精度推断。

返回值

返回值类型说明
ynp.ndarray, [shape=(…, n_samples), dtype=np.float]

由 CQT 表示重建的音频时间序列。

参见

  • cqt
  • librosa.resample

说明

该函数在级别 40 上缓存。

示例

使用默认参数

>>> y, sr = librosa.loadx('trumpet')
>>> C = librosa.cqt(y=y, sr=sr)
>>> y_hat = librosa.icqt(C=C, sr=sr)

或者使用不同的跳距与频率分辨率：

>>> hop_length = 256
>>> bins_per_octave = 12 * 3
>>> C = librosa.cqt(y=y, sr=sr, hop_length=256, n_bins=7*bins_per_octave,
...                 bins_per_octave=bins_per_octave)
>>> y_hat = librosa.icqt(C=C, sr=sr, hop_length=hop_length,
...                 bins_per_octave=bins_per_octave)
