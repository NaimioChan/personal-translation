librosa.util.valid_intervals

librosa.util.valid_intervals(intervals) [源码]

确保数组是时间区间的合法表示：

  • intervals.ndim == 2

  • intervals.shape[1] == 2

  • 对所有 i 都有 intervals[i, 0] <= intervals[i, 1]

参数

参数类型说明
intervalsnp.ndarray [shape=(n, 2)]

时间区间集合

返回值

返回值类型说明
validbool

若 intervals 通过验证则为 True。
