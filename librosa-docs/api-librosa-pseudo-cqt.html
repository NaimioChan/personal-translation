librosa.pseudo_cqt

librosa.pseudo_cqt(y, *, sr=22050, hop_length=512, fmin=None, n_bins=84, bins_per_octave=12, tuning=0.0, filter_scale=1, norm=1, sparsity=0.01, window='hann', scale=True, pad_mode='constant', dtype=None) [源码]

计算音频信号的伪常数 Q 变换。

该方法使用单一的 FFT 尺寸，取不小于以下二者最大值的 2 的幂中最小的一个：

  1. 最长的 CQT 滤波器

  2. hop_length 的 2 倍

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

hop_lengthint > 0 [scalar]

CQT 相邻列之间的采样点数量。

fminfloat > 0 [scalar]

最低频率。默认 C1 ~= 32.70 Hz

n_binsint > 0 or None [scalar]

从 fmin 起的频率 bin 数量。 若为 None，bin 数将推断为可容纳于 sr/2 以下的最大值。

bins_per_octaveint > 0 [scalar]

每八度的 bin 数

tuningNone or float

调音偏移，以 bin 的分数单位表示。

若为 None，将从信号自动估计调音。

所得 CQT 的最低频率将被修正为 fmin * 2**(tuning / bins_per_octave)。

filter_scalefloat > 0

滤波器 filter_scale 因子。值越大，所用窗越长。

norm{inf, -inf, 0, float > 0}

基函数归一化所用的范数类型。 见 librosa.util.normalize。

sparsityfloat in [0, 1)

通过丢弃每个基中最多 sparsity 比例的能量，使 CQT 基稀疏化。

设 sparsity=0 关闭稀疏化。

windowstr, tuple, number, or function

基滤波器的窗规格。 详见 filters.get_window。

scalebool

若为 True，按各声道滤波器长度的平方根缩放 CQT 响应。这类似于 FFT 中的 norm='ortho'。

若为 False，不缩放 CQT。这类似于 FFT 中的 norm=None。

pad_modestr

居中分帧分析所用的填充模式。

另见：librosa.stft 与 numpy.pad。

dtypenp.dtype, optional

CQT 计算所用的复数数据类型。 默认与输入信号的精度匹配。

返回值

返回值类型说明
CQTnp.ndarray [shape=(…, n_bins, t), dtype=np.float]

每个频率在各时刻的伪常数 Q 能量。

说明

此函数在缓存级别 20 上缓存。
