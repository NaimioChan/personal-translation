librosa.feature.inverse.mfcc_to_mel

librosa.feature.inverse.mfcc_to_mel(mfcc, *, n_mels=128, dct_type=2, norm='ortho', ref=1.0, lifter=0) [源码]

把 Mel 频率倒谱系数反演为近似的 mel 功率谱。

反演分两步进行：

  1. 对 MFCC 施加逆 DCT

  2. 应用 librosa.db_to_power，把以 dB 标度的结果映射为功率谱

参数

参数类型说明
mfccnp.ndarray [shape=(…, n_mfcc, n)]

Mel 频率倒谱系数

n_melsint > 0

Mel 频率数

dct_type{1, 2, 3}

离散余弦变换（DCT）类型。 默认使用 2 型 DCT。

normNone or ‘ortho’

若 dct_type 为 2 或 3，设置 norm='ortho' 将使用正交归一 DCT 基。 dct_type=1 不支持归一化。

reffloat

（逆）分贝计算的参考功率

lifternumber >= 0
  • 若 lifter>0，施加逆倒谱滤波：：

    M[n, :] <- M[n, :] / (1 + sin(pi * (n + 1) / lifter) * lifter / 2)

返回值

返回值类型说明
Mnp.ndarray [shape=(…, n_mels, n)]

由 mfcc 恢复出的近似 mel 功率谱

警告

警告说明
UserWarning

当 lifter 数组中的临界值引发下溢时发出。
