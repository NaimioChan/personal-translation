librosa.display.TimeFormatter

class librosa.display.TimeFormatter(lag=False, unit=None) [源码]

时间轴的刻度格式化器。

自动在秒、分:秒、时:分:秒之间切换。

参数

参数类型说明
lagbool

若为 True，时间轴按滞后坐标解释。超过中点的部分会转换为负时间。

unitstr or None

轴标签与刻度字符串表示所用的单位缩写。 支持的单位列表： * “h”：以小时为基准的格式（H:MM:SS） * “m”：以分钟为基准的格式（M:SS） * “s”：以秒为基准的格式（科学计数法形式的 S.sss） * “ms”：以毫秒为基准的格式（科学计数法形式的 s.µµµ） * None：根据底层时间范围的时长自适应：超过 3600 秒时与 “h” 类似；60 到 3600 秒之间与 “m” 类似；1 到 60 秒之间与 “s” 类似；不足 1 秒时与 “ms” 类似。

参见

  • matplotlib.ticker.Formatter

示例

用于普通时间

>>> import matplotlib.pyplot as plt
>>> times = np.arange(30)
>>> values = np.random.randn(len(times))
>>> fig, ax = plt.subplots()
>>> ax.plot(times, values)
>>> ax.xaxis.set_major_formatter(librosa.display.TimeFormatter())
>>> ax.set(xlabel='Time')
>>> plt.show()

手动把 x 轴的实际时间单位设为毫秒

>>> times = np.arange(100)
>>> values = np.random.randn(len(times))
>>> fig, ax = plt.subplots()
>>> ax.plot(times, values)
>>> ax.xaxis.set_major_formatter(librosa.display.TimeFormatter(unit='ms'))
>>> ax.set(xlabel='Time (ms)')
>>> plt.show()

用于滞后图

>>> times = np.arange(60)
>>> values = np.random.randn(len(times))
>>> fig, ax = plt.subplots()
>>> ax.plot(times, values)
>>> ax.xaxis.set_major_formatter(librosa.display.TimeFormatter(lag=True))
>>> ax.set(xlabel='Lag')
>>> plt.show()
