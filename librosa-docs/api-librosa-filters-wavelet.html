librosa.filters.wavelet

librosa.filters.wavelet(*, freqs, sr=22050, window='hann', filter_scale=1, pad_fft=True, norm=1, dtype=<class 'numpy.complex64'>, gamma=0, alpha=None, **kwargs) [源码]

使用加窗复正弦构造小波基。

本函数在指定的一组中心频率上构造小波滤波器组。

参数

参数类型说明
freqsnp.ndarray (positive)

各滤波器的中心频率（单位 Hz）。 必须按升序排列。

srnumber > 0 [scalar]

音频采样率

windowstr, tuple, number, or function

施加于滤波器的窗函数。

filter_scalefloat > 0 [scalar]

滤波窗的尺度。 较小的值（<1）使用更短的窗，以获得更高的时间分辨率。

pad_fftbool

把所有滤波器居中填充到不小于其长度的最近的 2 的整数次幂。

默认以零填充，但可通过在 kwargs 中设置 mode= 字段覆盖。

norm{inf, -inf, 0, float > 0}

基函数归一化所用的范数类型。 见 librosa.util.normalize

dtypenp.dtype

输出基的数据类型。 默认使用 64 位（单精度）复数浮点数。

gammanumber >= 0

变 Q 变换的带宽偏移量。

alphanumber > 0 [optional]

可选的预先算好的相对带宽参数。 注意当 len(freqs)==1 时必须提供该参数，因为无法从单一频率推断带宽。 否则，若不指定，将按上述规则自动推导。

**kwargsadditional keyword arguments

当 pad==True 时传给 np.pad() 的参数。

返回值

返回值类型说明
filtersnp.ndarray, len(filters) == n_bins

每个 filters[i] 是一个（复数）时域滤波器

lengthsnp.ndarray, len(lengths) == n_bins

每个滤波器的（分数）长度，以样本为单位

参见

  • wavelet_lengths
  • librosa.cqt
  • librosa.vqt
  • librosa.util.normalize

说明

本函数在层级 10 缓存。

示例

创建常数 Q 基

>>> freqs = librosa.cqt_frequencies(n_bins=84, fmin=librosa.note_to_hz('C1'))
>>> basis, lengths = librosa.filters.wavelet(freqs=freqs, sr=22050)

在时域与频域中绘制一个八度的滤波器

>>> import matplotlib.pyplot as plt
>>> basis, lengths = librosa.filters.wavelet(freqs=freqs, sr=22050)
>>> fig, ax = plt.subplots(nrows=2, figsize=(10, 6))
>>> notes = librosa.midi_to_note(np.arange(24, 24 + len(basis)))
>>> for i, (f, n) in enumerate(zip(basis, notes[:12])):
...     f_scale = librosa.util.normalize(f) / 2
...     ax[0].plot(i + f_scale.real)
...     ax[0].plot(i + f_scale.imag, linestyle=':')
>>> ax[0].set(yticks=np.arange(len(notes[:12])), yticklabels=notes[:12],
...           ylabel='CQ filters',
...           title='CQ filters (one octave, time domain)',
...           xlabel='Time (samples at 22050 Hz)')
>>> ax[0].legend(['Real', 'Imaginary'])
>>> F = np.abs(np.fft.fftn(basis, axes=[-1]))
>>> # Keep only the positive frequencies
>>> F = F[:, :(1 + F.shape[1] // 2)]
>>> librosa.display.specshow(F, x_axis='linear', y_axis='cqt_note', ax=ax[1])
>>> ax[1].set(ylabel='CQ filters', title='CQ filter magnitudes (frequency domain)')
