librosa.decompose.nn_filter

librosa.decompose.nn_filter(S, *, rec=None, aggregate=None, axis=-1, **kwargs) [源码]

通过最近邻聚合进行滤波。

每个数据点（例如频谱图的每一列）都以其在特征空间中的最近邻聚合结果替换。

这可用于对频谱图或特征矩阵去噪。

提供加权循环矩阵作为输入并指定 aggregate=np.average，即可得到非局部均值方法 [1]。

类似地，设 aggregate=np.median 可得到 REPET-SIM [2] 中的稀疏去噪。

[1] Buades, A., Coll, B., & Morel, J. M. (2005, June). A non-local algorithm for image denoising. In Computer Vision and Pattern Recognition, 2005. CVPR 2005. IEEE Computer Society Conference on (Vol. 2, pp. 60-65). IEEE.

[2] Rafii, Z., & Pardo, B. (2012, October). “Music/Voice Separation Using the Similarity Matrix.” International Society for Music Information Retrieval Conference, 2012.

参数

参数类型说明
Snp.ndarray

要滤波的输入数据（频谱图）。支持多声道。

rec(optional) scipy.sparse array or np.ndarray

可选地提供预先算好的最近邻数组，如 librosa.segment.recurrence_matrix 所生成。

aggregatefunction

聚合函数（默认：np.mean）

若 aggregate=np.average，则按 rec 中（每行的）权重计算加权平均。

对于其他聚合函数，所有邻居同等对待。

axisint

沿哪个轴滤波（默认为列）

**kwargs

若未提供 rec，则作为附加关键字参数传给 librosa.segment.recurrence_matrix

返回值

返回值类型说明
S_filterednp.ndarray

滤波后的数据，形状与输入 S 相同。

异常

异常说明
ParameterError

若提供了 rec 且其形状与 S 不兼容。

参见

  • decompose
  • hpss
  • librosa.segment.recurrence_matrix

说明

该函数在级别 30 上缓存。

示例

用非局部中值滤波对色度图去噪。 默认使用欧氏距离选择邻居，但可通过设置 metric 参数直接覆盖。

>>> y, sr = librosa.loadx('brahms', offset=30, duration=10)
>>> chroma = librosa.feature.chroma_cqt(y=y, sr=sr)
>>> chroma_med = librosa.decompose.nn_filter(chroma,
...                                          aggregate=np.median,
...                                          metric='cosine')

要使用非局部均值，请提供亲和矩阵并设 aggregate=np.average。

>>> rec = librosa.segment.recurrence_matrix(chroma, mode='affinity',
...                                         metric='cosine', sparse=True)
>>> chroma_nlm = librosa.decompose.nn_filter(chroma, rec=rec,
...                                          aggregate=np.average)
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(nrows=5, sharex=True, sharey=True, figsize=(10, 10))
>>> librosa.display.specshow(chroma, y_axis='chroma', x_axis='time', ax=ax[0])
>>> ax[0].set(title='Unfiltered')
>>> ax[0].label_outer()
>>> librosa.display.specshow(chroma_med, y_axis='chroma', x_axis='time', ax=ax[1])
>>> ax[1].set(title='Median-filtered')
>>> ax[1].label_outer()
>>> imgc = librosa.display.specshow(chroma_nlm, y_axis='chroma', x_axis='time', ax=ax[2])
>>> ax[2].set(title='Non-local means')
>>> ax[2].label_outer()
>>> imgr1 = librosa.display.specshow(chroma - chroma_med,
...                          y_axis='chroma', x_axis='time', ax=ax[3])
>>> ax[3].set(title='Original - median')
>>> ax[3].label_outer()
>>> imgr2 = librosa.display.specshow(chroma - chroma_nlm,
...                          y_axis='chroma', x_axis='time', ax=ax[4])
>>> ax[4].label_outer()
>>> ax[4].set(title='Original - NLM')
>>> fig.colorbar(imgc, ax=ax[:3])
>>> fig.colorbar(imgr1, ax=[ax[3]])
>>> fig.colorbar(imgr2, ax=[ax[4]])
