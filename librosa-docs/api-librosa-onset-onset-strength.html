librosa.onset.onset_strength

librosa.onset.onset_strength(*, y=None, sr=22050, S=None, lag=1, max_size=1, ref=None, detrend=False, center=True, feature=None, aggregate=None, **kwargs) [源码]

计算频谱通量起始强度包络。

时刻 t 的起始强度由下式确定：

mean_f max(0, S[f, t] - ref[f, t - lag])

其中 ref 是 S 沿频率轴做局部最大值滤波后的结果 [1]。

默认情况下，若提供了时间序列 y，S 为对数功率 mel 频谱图。

[1] Böck, Sebastian, and Gerhard Widmer. “Maximum filter vibrato suppression for onset detection.” 16th International Conference on Digital Audio Effects, Maynooth, Ireland. 2013.

参数

参数类型说明
ynp.ndarray [shape=(…, n)]

音频时间序列。支持多声道。

srnumber > 0 [scalar]

y 的采样率

Snp.ndarray [shape=(…, d, m)]

预先计算好的（对数功率）频谱图

lagint > 0

计算差分的时间滞后

max_sizeint > 0

局部最大值滤波器的尺寸（以频率 bin 计）。 设为 1 表示关闭滤波。

refNone or np.ndarray [shape=(…, d, m)]

可选的预先计算参考频谱，形状与 S 相同。 若未提供，将从 S 计算。 若提供，将覆盖由 max_size 控制的局部最大值滤波。

detrendbool [scalar]

对起始强度滤波以去除直流分量

centerbool [scalar]

把起始函数平移 n_fft // (2 * hop_length) 帧。 这对应于短时傅里叶变换中使用居中的分帧分析。

featurefunction

计算时间序列特征（如缩放后的频谱图）的函数。 默认使用 librosa.feature.melspectrogram，取 fmax=sr/2

aggregatefunction

合并各频率 bin 的起始强度时所用的聚合函数。

默认：np.mean

**kwargsadditional keyword arguments

未提供 S 时传给 feature() 的附加参数。

返回值

返回值类型说明
onset_envelopenp.ndarray [shape=(…, m,)]

包含起始强度包络的向量。 若输入包含多个声道，则对每个声道分别计算起始包络。

异常

异常说明
ParameterError

若 (y, sr) 与 S 均未提供

或 lag、max_size 不是正整数

示例

先加载一段音频并绘制频谱图

>>> import matplotlib.pyplot as plt
>>> y, sr = librosa.loadx('trumpet', duration=3)
>>> D = np.abs(librosa.stft(y))
>>> times = librosa.times_like(D, sr=sr)
>>> fig, ax = plt.subplots(nrows=2, sharex=True)
>>> librosa.display.specshow(D, vscale='dBFS',
...                          y_axis='log', x_axis='time', ax=ax[0], sr=sr)
>>> ax[0].set(title='Power spectrogram')
>>> ax[0].label_outer()

构造标准的起始函数

>>> onset_env = librosa.onset.onset_strength(y=y, sr=sr)
>>> ax[1].plot(times, 2 + onset_env / onset_env.max(), alpha=0.8,
...            label='Mean (mel)')

用中位数聚合，并自定义 mel 选项

>>> onset_env = librosa.onset.onset_strength(y=y, sr=sr,
...                                          aggregate=np.median,
...                                          fmax=8000, n_mels=256)
>>> ax[1].plot(times, 1 + onset_env / onset_env.max(), alpha=0.8,
...            label='Median (custom mel)')

用常数 Q 变换频谱图代替 mel

>>> C = np.abs(librosa.cqt(y=y, sr=sr))
>>> onset_env = librosa.onset.onset_strength(sr=sr, S=librosa.amplitude_to_db(C, ref=np.max))
>>> ax[1].plot(times, onset_env / onset_env.max(), alpha=0.8,
...          label='Mean (CQT)')
>>> ax[1].legend()
>>> ax[1].set(ylabel='Normalized strength', yticks=[])
