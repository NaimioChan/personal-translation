librosa.util.dtype_c2r

librosa.util.dtype_c2r(d, *, default=<class 'numpy.float32'>) [源码]

查找与复数 dtype 对应的实数 numpy dtype。

该函数用于在由复值数据构造实数组时（例如在逆傅里叶变换中） 保持数值精度与内存占用。

complex64（单精度）类型对应 float32， 而 complex128（双精度）对应 float64。

参数

参数类型说明
dnp.dtype

要转换为实数类型的复值 dtype。 若 d 本身已是实数（浮点）类型，则原样返回。

defaultnp.dtype, optional

当 d 不匹配已知 dtype 时使用的默认实数目标类型

返回值

返回值类型说明
d_rnp.dtype

实数 dtype

参见

  • dtype_r2c
  • numpy.dtype

示例

>>> librosa.util.dtype_c2r(np.complex64)
dtype('float32')
>>> librosa.util.dtype_c2r(np.float32)
dtype('float32')
>>> librosa.util.dtype_c2r(np.int16)
dtype('float32')
>>> librosa.util.dtype_c2r(np.complex128)
dtype('float64')
