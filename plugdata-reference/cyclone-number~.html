[number~]

信号发生器/监视器

描述

使用 [number~] 监视或生成信号。这是一个功能有限的抽象对象，不是真正的克隆。
"tilde" 符号指监视模式，如果你点击它，它会变成生成模式（以向下箭头标记，在那里你可以点击/拖动并输入数字）。点击箭头会把它切换回监视模式。

入口

入口 1

  • signal：待监测/显示的 signal
  • bang：交替模式

入口 2

  • float：用于信号生成的斜坡时间

出口

出口 1

  • signal：生成的信号

出口 2

  • float：被监测信号的值

方法

消息说明
set <float>设置值但不生成信号
list <f,f>设置要生成的值与斜坡时间，单位 ms
ft1 <float>设置斜坡时间，单位 ms
interval <float>设置显示时间间隔，单位 ms
bgcolor <f, f, f>用 RGB 设置背景颜色
textcolor <f, f, f>设置文字颜色，RGB
minimum <float>设置最小 generation 值
maximum <float>设置最大 generation 值

选项

选项说明
@monitormode <float>非 0 设为监听模式
@sigoutmode <float>非 0 设为发生器模式
@ft1斜坡时间
@interval <float>显示时间间隔，单位 ms
@minimum <float>最小生成值
@maximum <float>最大生成值
@bgcolor <f, f, f>用 RGB 设置背景颜色
@textcolor <f, f, f>文本颜色，用 RGB
