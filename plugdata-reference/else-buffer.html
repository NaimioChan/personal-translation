[buffer]

获取/设置数组缓冲区

描述

[buffer] 做的不多，也没有 [array] 做不到的事，但它是获取和设置数组值的便利对象，有点像 [message] 这样的存储对象。你可以从真正的数组、[table] 或 [array] 对象获取/设置数组。

入口

入口 1

  • list：调整大小、设置数组并输出列表
  • bang：输出数组

入口 2

  • list：调整大小并设置数组

出口

出口 1

  • list：数组的值

参数

#类型默认值说明
1symbolnone数组名

方法

消息说明
set <list>第 1 项是索引，之后的是从该索引起的值
name <symbol>设置数组名称
