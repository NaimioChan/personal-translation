cyclone · 数组与表格

[record~]

在数组中录制信号

描述

[record~] 最多把 64 个信号通道录制到数组中。默认情况下，数组填满后录制停止。

入口

入口 1

  • signal：要录制到数组的 signal
  • float：开始（非 0）或停止（0）录制
  • list：循环起点和终点，单位 ms

入口 2

  • float/signal：起点，单位 ms

入口 3

  • float/signal：结束点，单位 ms

出口

出口 1

  • signal：同步输出：信号从 0（起点）到 1（终点）

参数

#类型默认值说明
1symbol—数组名（必填）
2float1要录制的通道（1-64）

方法

消息说明
set <symbol>设置用于录制信号的数组
reset重置循环点并重新开始录制
append <float>追加模式开启（1）或关闭（0）
loop <float>循环模式开（1）或关（0）
loopstart <float>循环起始点，单位 ms
loopend <float>循环结束点，单位 ms

选项

选项说明
@append <float>追加模式开（1）或关（0）
默认：0
@loop <float>循环模式开（1）或关（0）
默认：0
@loopstart <float>循环起始点，单位 ms
默认：0
@loopend <float>循环结束点，单位 ms
默认：0
