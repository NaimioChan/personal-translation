ELSE · MIDI

[midi.learn]

MIDI 学习

描述

[midi.learn] 是一个基于 [savestate] 的抽象对象，能学习并保存任意 MIDI 输入数据。通过 bang 或点击激活它，并向它发送 MIDI 数据，让它学习数据来自何处。信息会存储到所属 patch 中。
学习到的 control/program change 后面跟着数字，它们指定 “control/program number” 和 “channel”，对于 note 和 bend 消息则只跟 “channel number”（不支持 touch 和 polytouch）。

入口

入口 1

  • bang：激活 MIDI 学习

出口

出口 1

  • list：来自已学习输入的 MIDI

出口 2

  • anything：已学习的控制器

参数

#类型默认值说明
1float0非 0 设为 abstraction 模式
2symbolnone发送名称

方法

消息说明
query在右侧出口打印/发送存储的输入
forget遗忘输入
set <symbol>设置 send 名
teach <anything>学习特定的 MIDI 消息
