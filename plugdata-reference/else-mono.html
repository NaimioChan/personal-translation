ELSE · MIDI

[mono]

单音声部管理器

描述

[mono] 接收 note 消息并处理它们，以模拟单音合成器行为。它的内部记忆最多能记住最后 10 个输入声部 *且音高需 >= 0）。

入口

入口 1

  • list：MIDI 音符消息（音符, 力度）
  • float：音符值

入口 2

  • float：力度值

出口

出口 1

  • float：音符值

出口 2

  • float：力度值

参数

#类型默认值说明
1float0滑音时间，单位 ms
2float—非 0 设为 legato 模式

方法

消息说明
mode <float>优先级模式（0：最后，1：高，2：低）
legato <float>非 0 为 legato 模式，为零则恢复默认
flush为挂起的音符发送 note off 并清空记忆
clear清空记忆

选项

选项说明
-last把模式设为 "last
-high把模式设为 "high
-low把模式设为 "low
