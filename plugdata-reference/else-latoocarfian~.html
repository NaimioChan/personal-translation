Latoocarfian 混沌发生器

描述

[latoocarfian~] 是使用差分方程的混沌发生器；
x[n] = sin(a * y[n-1]) + d * sin(a * x[n-1]);
y[n] = sin(b * x[n]) + c * sin(b * y[n-1]);

入口

入口 1

  • float/signal：频率，单位 Hz（接受负值）
  • list：2 个 float 分别设置 x[n-1] 和 y[n-1]

出口

出口 1

  • signal：Latoocarfian 混沌信号

参数

#类型默认值说明
1floatNyquist设置频率，单位 Hz
2float1设置 a
3float3设置 b
4float0.5设置 c
5float0.5设置 d
6float0.5设置 y[n-1] 的初始值
7float0.5设置 x[n-1] 的初始值

方法

消息说明
coeffs <f, f, f, f>list 设置 'a'、'b'、'c' 和 'd' 的值
