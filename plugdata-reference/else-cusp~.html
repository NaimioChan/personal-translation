[cusp~]

尖点映射混沌发生器

描述

[cusp~] 是使用差分方程的混沌生成器；
y[n] = a - b * sqrt(abs(y[n-1]))
该方程的输出速率以 Hz 为单位（默认：Nyquist）。
对象基于 SuperCollider 的 "CuspN" UGEN。

入口

入口 1

  • float/signal：频率，单位 Hz（接受负值）
  • list：3 个 float 设置 'a'、'b' 和 y[n-1]
  • set <float, float>：<channel, freq> 设置单个频率通道

出口

出口 1

  • signal：cusp 映射混沌信号

参数

#类型默认值说明
1floatNyquist设置频率，单位 Hz
2float1设置 'a'
3float0.19设置 'b'
4float0设置 y[n-1] 的初始值

选项

选项说明
-mc <list>用频率列表设置多通道输出
