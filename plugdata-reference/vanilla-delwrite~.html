[delwrite~]

写入延时线

描述

delread~ 与 delread4~ 对象从同名 delwrite~ 对象中分配的延时线读取。注意，在本帮助文件中我们使用的延时名称带有 "$0"（Pd 中用于强制局部性的 patch ID 编号）。同一个 delwrite~ 对象可以配多于一个 delread~ 和/或 delread4~ 对象。如果 delread~/delread4~ 中指定的延时时间超过延时线的长度或小于零，它会被裁剪到延时线的长度。

如果 delwrite~ 在 DSP 循环中晚于 delread~ 或 delread4~ 对象运行，延时的下限受一个向量长度（通常为 64 个采样点）的限制。

入口

入口 1

  • signal：输入到延时时间的 signal
  • clear：清空延时时间

出口

无记录。

参数

#类型默认值说明
1symbol—延时线名
2float—延时线长度，单位 msec（读取对象中的最大延时时间）
