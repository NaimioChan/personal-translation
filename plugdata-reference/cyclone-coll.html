cyclone · 数据管理

[coll]

存储/编辑消息集合

描述

[coll] 在给定地址（整数或 symbol）上存储/编辑任何消息。如果输入列表以 int 开头，它会把其他元素存储在该 int 地址上。

入口

入口 1

  • bang：输出下一个地址及其数据
  • float/symbol："int float" 或 "symbol" 地址：输出已存储的数据
  • list：第 1 个元素是用于存储剩余数据的 int 地址

出口

出口 1

  • anything：给定地址处存储的消息

出口 2

  • float/symbol：所存储消息的整数或 symbol 地址

出口 3

  • bang：当完成读取操作时

出口 4

  • bang：当完成 dump 操作时

参数

#类型默认值说明
1symbol—要加载的名称或文件名（同名 coll 共享内容）
2float0非 0 阻止搜索文件

方法

消息说明
assoc <symbol, int>将 symbol 别名关联到 int 地址
clear从 [coll] 删除所有地址（整个数据集合）
deassoc <symbol, int>解除 int 地址的 symbol 别名关联
delete <int/symbol>删除该地址（如果是 int，则更大的地址递减 1）
dump输出所有值（第 1 出口）、地址（第 2 出口），完成后发送 bang（第 4 出口）
end把指针设为最后一个条目/地址
embed <float><1> 把内容随 patch 保存，<0> 则不保存
filetype <symbol>设置读取/写入的文件类型（无 symbol 时设为无扩展名：默认）
flags <float, float>第一个选项是 embed 选项，第二个未使用（直接用 'embed' 即可）
goto <int/symbol>设置要前往的地址（只设置指针，无输出）
insert <int, anything>一个 int 地址和要插入的任意消息，将等于/大于该地址的地址递增
insert2 <int, anything>同 insert，但只有为包含新地址而需要时才递增
length向左出口发送存储值的数量
max <int>在左出口发送所有 <nth> 元素的最大值（从 1 开始，默认）
merge <int/symbol, any>设置地址以及要追加到已存储消息的任意消息
min <float>在左出口发送所有 <nth> 元素的最小值（从 1 开始，默认）
next同 bang：输出下一个地址及其数据
nth <int/symbol, int>地址和要输出的第 n 个元素（从 1 开始）
nstore <int, symbol, any>或 <symbol, int, any>：将任意数据存储到带 symbol 别名的 int 地址
nsub <int/sym, int, any>地址、一个元素（从 1 开始）以及要替换成的任意值
open打开数据收集窗口（允许手动编辑数据）
prev输出上一个地址及其数据
read <symbol>打开由 symbol 指定的文件（无 symbol 时打开对话框窗口）
readagain重新打开上次的文件 - 如果没有打开过文件，则显示对话框
refer <symbol>引用具有该 symbol 名称的另一个 [coll] 对象中的数据
remove <int/symbol>删除地址及其数据且不重新编号（与 delete 不同）
renumber <int>连续列出 int 地址，参数设置起始值（默认 0）
renumber2 <int>从给定地址开始将 int 地址递增一（默认：0）
separate <int>从给定的 <int> 及以上的地址递增 1（打开一个槽）
sort <float, float><flag> -1：升序 / 1：降序，<sort element> 从 0 开始（-1 是地址）
start把指针设为第一个条目/地址
store <int/sym, any>int 或 symbol 地址以及在它那里存储的任意消息
sub <int/sym, int, any>同 nsub，但替换后的消息会发送出去
subsym <symbol, symbol>用第一个给定的 symbol 替换地址 symbol（第 2 个元素）
swap <int/sym, int/sym>交换两个地址之间的数据
wclose关闭包含该集合的数据窗口
write <symbol>保存 symbol 指定的文件（无 symbol 时打开对话框）
writeagain重新保存上次的文件 - 如果没有保存过文件，则显示对话框

选项

选项说明
@embed<1> 随 patch 保存内容，<0> 不保存
默认：0
@threaded<1> 多线程处理，<0> 非多线程
默认：1
