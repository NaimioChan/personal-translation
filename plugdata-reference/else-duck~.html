[duck~]

侧链压缩

描述

[duck~] 是一个实现 duck 音量效果（又称 sidechain compression）的抽象对象。它依据控制信号的电平衰减输入信号。你也可以把被 duck 的信号与控制输入信号混合。

入口

入口 1

  • signal：输入信号

入口 2

  • signal：控制信号

出口

出口 1

  • signal：闪避后的信号，单独输出或与控制信号混合

参数

#类型默认值说明
1float-60阈值，单位 dB
2float1衰减比
3float10起音时间，单位 ms
4float10释放时间，单位 ms

方法

消息说明
thresh <float>设置阈值，单位 dB
ratio <float>设置衰减比
attack <float>设置起音时间，单位 ms
release <float>设置释放时间，单位 ms
mix <float>非 0 与控制信号混合

选项

选项说明
-mix与控制信号混合
