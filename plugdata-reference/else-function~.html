[function~]

函数发生器

描述

[function~] 从参数/列表输入生成函数。0 到 1 的输入值读取该函数。它需要列表中有奇数个元素，从 3 个值开始，语法是 (point1, period, point2, period, point3, 等...)。所有 period 的总和被归一化为 1！

入口

入口 1

  • signals：从 0 到 1 的值读取函数
  • list：3 个或更多 float 设置函数

出口

出口 1

  • signals：函数输出

参数

#类型默认值说明
1listno function3 个或更多 float，用于设置函数

方法

消息说明
curve <list>设置每条线段的指数值

选项

选项说明
-curve <float/symbol>为所有段设置曲线类型
