vanilla · 滤波器

[biquad~]

二阶（2 极点 / 2 零点）滤波器

描述

Biquad~ 计算以下差分方程：

`y(n) = ff1 * w(n) + ff2 * w(n-1) + ff3 * w(n-2)`

`w(n) = x(n) + fb1 * w(n-1) + fb2 * w(n-2)`

滤波器的系数语法（通过参数或列表输入设置）是：fb1 fb2 ff1 ff2 ff3

入口

入口 1

  • signal：待滤波的输入信号
  • list：五个系数（fb1 fb2 ff1 ff2 ff3）

出口

出口 1

  • signal：滤波后的信号输出

参数

#类型默认值说明
1list—初始化 5 个系数（fb1 fb2 ff1 ff2 ff3）

方法

消息说明
set <float, float>设置最近两个输入采样点
clear清空滤波器的记忆缓冲区
