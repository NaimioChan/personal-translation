[resonant~]

带通谐振滤波器（恒定裙边）

描述

[resonant~] 是类似 [bandpass~] 的带通谐振器滤波器，但它没有 0 dB 的最大值，因此改变 Q 会提高滤波器的增益。除了 'Q' 和 'bw'，也可以把谐振设为 't60'（与 [resonator~] 一样）。

入口

入口 1

  • signal：要滤波或激励谐振器的 signal

入口 2

  • float/signal：中心频率，单位 Hz

入口 3

  • signal：谐振（Q、bw 或 t60）

出口

出口 1

  • signal：谐振器/滤波后信号

    方法：
  • clear：清空滤波器的记忆
  • bypass <float>：1（bypass 开），0（bypass 关）
  • t60：以衰减时间设置共振参数，单位 ms
  • bw：把谐振参数设为带宽，单位八度

参数

#类型默认值说明
1float0中心频率，单位 Hz
2float0谐振

方法

消息说明
clear清空滤波器的记忆
q把谐振参数设为 Q（默认）
bw把谐振参数设为带宽，单位八度
t60把谐振参数设为衰减时间，单位 ms
