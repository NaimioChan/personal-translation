[status]

报告 0/非 0 跳变

描述

[status] 对 "零到非 0" 的跳变在左出口发送 bang，对 "非 0 到零" 的跳变在右出口发送 bang。

入口

入口 1

  • float：要检测跳变的数值
  • bang：依据当前状态重新发送 bang

出口

出口 1

  • bang：如果检测到 0 到非 0 的转换

出口 2

  • bang：如果检测到非 0 到 0 的转换

参数

#类型默认值说明
1floatno status初始状态值

方法

消息说明
change更改内部状态
