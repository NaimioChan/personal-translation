cyclone · 信号发生器

[cycle~]

波表振荡器

描述

[cycle~] 是线性插值振荡器*，它反复读取波形的一个周期。默认的内部波形是一个周期的余弦波（大小为 16k，64 位），但你可以从给定的数组设置其他波形。

入口

入口 1

  • float/signal：设置频率，单位 Hz（允许负值）

入口 2

  • float/signal：相位偏移

出口

出口 1

  • signal：周期性重复的波形

参数

#类型默认值说明
1float0设置频率，单位 Hz
2symbolinternal cosine table设置用作波表的数组（但只从缓冲区读取 512 个点）
3float0设置给定数组内的偏移量

方法

消息说明
frequency <float>设置频率，单位 Hz
phase <float>设置相位偏移量
set仅 "set" 消息才会设为默认余弦波
set <symbol, float>设置数组名和偏移量（仅读取 512 个点）
setall <symbol>使用数组的整个长度设置数组
buffer <symbol>设置数组（类似于 setall 消息）
buffer_offset <float>设置缓冲区内的偏移量
buffer_sizeinsamps <f>将缓冲区大小更改为 2 的幂（16 到 65536）

选项

选项说明
@frequency <float>
@phase <float>
@buffer <symbol>
@buffer_offset <float>
@buffer_sizeinsamps <float>
