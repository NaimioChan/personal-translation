[glide2~]

信号滑音/滑奏

描述

[glide2~] 与 [glide~] 一样，但上升和下降各有不同的斜坡时间。

入口

入口 1

  • signal：待平滑的传入信号

入口 2

  • float：上升斜坡时间，单位 ms

入口 3

  • float：下降斜坡时间，单位 ms

出口

出口 1

  • signal：平滑/滤波后的 signal

参数

#类型默认值说明
1float0上升斜坡时间，单位 ms
2float0下降斜坡时间，单位 ms

方法

消息说明
reset将 glide 重置为输入值
exp <float>设置指数因子

选项

选项说明
-exp <float>设置指数因子
默认：1 - linear
