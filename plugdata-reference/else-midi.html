ELSE · MIDI

[midi]

读写 MIDI 文件

描述

[midi] 播放/录制 raw MIDI 流，可以保存/读取 MIDI 文件，或导入/导出到 txt 文件。

入口

入口 1

  • float：要录制的原始 MIDI 数据
  • bang：外部时钟 tick

出口

出口 1

  • float：来自 MIDI 文件的原始 MIDI 数据流

出口 2

  • bang：在序列结束时发送

参数

#类型默认值说明
1symbol—要加载的 MIDI 或文本文件

方法

消息说明
loop <float>非 0 设为循环模式
record开始录制原始 MIDI 输入
play开始播放序列
start设置为同步模式并期望时钟 tick（bang）
stop停止录制/播放并回到开头
pause暂停录制/播放
continue继续录制/播放
speed <float>设置读取速度，为原始速度的 %
dump一次性输出 MIDI 数据流
panic冲刷挂起音符
clear清空对象中的序列
save <symbol>保存为 MIDI 文件

选项

选项说明
-loop设置循环模式
默认：no loop
