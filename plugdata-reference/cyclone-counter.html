cyclone · 数据运算

[counter]

在范围内计数

描述

[counter] 在给定范围内按 '1' 向上和/或向下计数。

入口

入口 1

  • bang：前进到下一个值并输出
  • float：同 bang

入口 2

  • bang：切换向上/向下方向
  • float：设置方向，0：向上，1：向下，2：上下（交替）

入口 3

  • bang：把计数器设为最小值（无输出）
  • float：设置计数器值，无输出 - 若超出范围，则依据 compatmode 重设最小值/最大值（见 help）

入口 4

  • bang：把计数器设为最小值并输出
  • float：设置计数器值并输出 - 若超出范围，则依据 compatmode 重设最小值/最大值（见 help）

入口 5

  • bang：把计数器设为最大值并输出
  • float：设置最大值（无输出）

出口

出口 1

  • float：计数器的当前值

出口 2

  • bang：当达到最大值时（如果设置了 'carrybang' 且正在向上计数）
  • float：达到最大值时为 1，下一轮开始时为 0（且设置了 'carryint' 并正在向上计数）

出口 3

  • bang：当达到最小值时（如果设置了 carrybang 且正在向下计数）
  • float：达到最小值时为 1，下一轮开始时为 0（如果设置了 carryint 并正在向下计数）

出口 4

  • float：统计计数器达到最大值的次数

参数

#类型默认值说明
1listdirection = 0 (up), min = 0, max = 2^24<f>：最大值；<f,f>：最小值、最大值； <f,f,f>：方向（0-上，1-下，2-上下），最小值、最大值

方法

消息说明
carrybang设置为 "carrybang" 模式：在每轮计数时发送 bang
carryint设置为 "carryint" 模式（默认）：在一轮计数结束时发送 "1"，在下一轮开始时发送 "0"
dec将计数器减 1（与方向无关）
down把方向设为向下
flags <list>第 1 个 float 设置 'carryflag'：0 (carryint)、1 (carrybang)。第 2 个设置 'compatmode' 模式：0 (current)、1 (ancient)
goto <float>同 'set' 消息
inc将计数器加 1（与方向无关）
jam <float>把计数器设为该值并输出 - 超出范围的值被忽略
next输出下一个值（同 bang）
max <float>设置最大值（不输出）
min <float>设置最小值并输出
set <float>设置计数器的下一个值（考虑方向）- 无输出
setmin <float>设置最小值（不输出）
state（任意入口）在 Pd 窗口打印当前设置状态
up把计数器方向设为向上
updown设置方向为到达极限时上下切换
compatmode <f>设置 @compatmode 属性：（0 = current，1 = ancient）
carryflag <f>设置 @carryflag 属性：（0 = carryint，1 = carrybang）

选项

选项说明
@carryflag0 为 carryint / 1 为 carrybang
默认：0
@compatmode0 为 current / 1 为 ancient（见帮助）
默认：0
