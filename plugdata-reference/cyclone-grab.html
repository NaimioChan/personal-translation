[grab]

抓取另一个对象的输出

描述

[grab] 向另一个对象发送消息并 "抓取" 其输出，改由自己的出口发出，而不是被抓取的对象。

入口

入口 1

  • anything：要向输出被捕获的对象发送的消息

出口

出口 1（可重复）

  • anything：从另一个对象抓取到的 anything

出口 2

  • anything：发送给输出被抓取的对象的消息

参数

#类型默认值说明
1float1除最右侧出口之外的出口数量
2symbol—入口中的消息发送到以此 symbol 命名的 receive 对象

方法

消息说明
set <symbol>设置 receive 名称（如果给出了第 2 个参数）
