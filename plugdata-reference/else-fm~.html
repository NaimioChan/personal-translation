ELSE · 信号发生器

[fm~]

频率调制单元

描述

[fm~] 是简单的频率调制单元，由一对正弦振荡器组成，其中一个调制另一个的频率输入。调制频率按载波的比率设置，调制指数与由此得到的频率相乘。该对象支持多通道。

入口

入口 1

  • float/signal：载波频率，单位 hz

入口 2

  • float/signal：作为载波比值的调制频率

入口 3

  • float/signal：调制指数

出口

无记录。

参数

#类型默认值说明
1float0载波频率，单位 hz
2float1作为载波比值的调制频率
3float0调制指数
