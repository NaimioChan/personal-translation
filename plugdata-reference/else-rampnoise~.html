[rampnoise~]

斜坡噪声

描述

[rampnoise~] 是带插值的低频（带限）噪声发生器，因此它会从一个随机值斜坡到另一个随机值，产生随机斜坡。随机值在 -1 和 1 之间，速率为单位 Hz（接受负频率）。如果想要可复现的输出，使用 seed 消息。
[rampnoise~] 对象产生的频率限制在从 0 到其运行频率的频带内。它最高可达采样率，此时基本上就是一个白噪声发生器。

入口

入口 1

  • list/signals：频率，单位 Hz

出口

出口 1

  • signals：带限阶跃噪声

参数

#类型默认值说明
1float0频率，单位 Hz

方法

消息说明
seed <float>float 设置随机种子，无 float 则设置唯一的内部种子
set <float, float><channel, freq> 设置单个密度通道

选项

选项说明
-seed <float>设置随机种子
-ch <float>输出通道数
默认：1
-mc <list>用频率列表设置多通道输出
