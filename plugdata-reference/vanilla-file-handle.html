vanilla · 文件管理

[file-handle]

操作文件句柄

描述

你从文件读出或写入文件的数据是字节列表，在 Pd 中表现为 0 到 255 的数字列表（使用超出范围的数字符号会导致未定义行为。）'file handle' 对象的第 2 个入口在 'file define' 子 patch 中有说明。

入口

入口 1

  • float：读取字节数

入口 2

  • symbol：更改关联的文件句柄

出口

出口 1

  • list：数据字节

出口 2

  • bang：如果文件无法打开、到达文件末尾或发生读取错误
  • seek <float>：定位输出

方法

消息说明
open <symbol>打开文件
seek <list>定位文件
close关闭文件
verbose <float>打开或关闭详细输出
creationmode <octal>限制将要创建的文件的权限

选项

选项说明
-q设置静默详细程度
-v设置详细程度为 loud
-m文件创建模式（user/group/other 权限），八进制
