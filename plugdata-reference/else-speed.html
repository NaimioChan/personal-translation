[speed]

在若干拍内改变 bpm 速度

描述

[speed] 与 [line] 有些关系。你给它一个目标 bpm 值和到达该值所需的时间（以拍计，加速或减速）。然后输出整体的速度（单位 ms，通过右出口），并在到达目标前为每一拍给出 bpm 值（左出口），从而正确模拟渐快或渐慢。

入口

入口 1

  • float：立即设置 bpm
  • list：<f,f> — 目标值、拍数；<f,f,f> — 起始值、目标值、拍数

出口

出口 1

  • float：BPM 变化

出口 2

  • float：总时间，单位 ms

参数

#类型默认值说明
1float120初始 bpm

方法

消息说明
set <list>以 'set' 开头的 float/list 会等待 bang 触发
bang在 'set' 消息之后触发该对象
