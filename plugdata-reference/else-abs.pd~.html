[abs.pd~]

pd~ 子进程的简单封装

描述

[abs.pd~] 通过 [pd~] 把 pd 文件加载到子进程中，并让事情更方便，例如使子进程能够接收来自连接到父进程的 MIDI 设备的 MIDI 数据（借助 [sendmidi]）。此外，你可以点击该对象来打开子进程的 patch。

入口

入口 1

  • signal：pd~ 子进程的左输入
  • anything：发往子进程的消息

入口 2

  • signal：pd~ 子进程的右输入

出口

出口 1

  • signal：子进程的左输出

出口 2

  • signal：子进程的右输出

参数

#类型默认值说明
1symbolnone要加载的 pd 文件

方法

消息说明
start <symbol>启动子进程，无 symbol 则重启上一个
stop停止子进程
show打开 pd 窗口
