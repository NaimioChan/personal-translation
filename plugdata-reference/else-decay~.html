[decay~]

指数衰减

描述

[decay~] 基于 SuperCollider 的 "Decay" UGEN。它是一个单极点滤波器，由脉冲产生指数衰减。衰减时间（单位 ms）是信号衰减 60dB 所需的时间。同一滤波器也用于 ELSE 库的其他对象（asr~/adsr~/lag~/lag2~）。

入口

入口 1

  • float：控制触发
  • bang：控制触发
  • signals：冲量触发

入口 2

  • float/signals：衰减时间，单位 ms

出口

出口 1

  • signals：衰减后的信号

参数

#类型默认值说明
1float1000衰减时间，单位 ms

方法

消息说明
clear清空滤波器的记忆
