[clone]

生成抽象对象的多个副本

描述

clone 为所需的抽象对象（作为对象加载到另一个 patch 中的 patch）创建任意数量的实例

入口

入口 1（可重复）

  • list：第 1 个数选择实例；列表其余部分发送到该实例的入口
  • signal：发送到所有实例的 signal

出口

出口 1（可重复）

  • data outlets：输出时前置实例编号
  • signal outlets：所有实例的输出，或作为多通道信号，或求和为单声道信号

参数

#类型默认值说明
1symbol—抽象对象名
2float—实例数量
3list—抽象对象的可选参数

方法

消息说明
resize <float>调整副本数量
vis <list>打开副本，接受副本编号与可视化状态（1 打开，0 关闭）
next <list>将消息转发到下一个实例的入口（递增并循环重复）
this <list>将经由 "this" 或 "next 发送的消息转发到上一个实例的入口
set <list>设置 "next"/"this" 计数器
all <list>向所有实例的入口发送消息

选项

选项说明
-x避免包含设置声部编号的第一个参数
-s <float>设置起始声部编号
默认：0
-di把多通道输入信号分发到各个克隆 patch
-do合并信号输出以构成多通道信号
-d同时设置 -di 与 -do 选项
