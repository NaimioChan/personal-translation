[range.hsl]

范围水平滑块

描述

[range.hsl] 是一个范围水平滑块 GUI 抽象对象（基于 .mmb 的一个对象）。它有 4 种运行模式，见下文。

入口

入口 1

  • bang：输出最后的值
  • list：设置范围值并输出

出口

出口 1

  • list：最小/最大范围值

方法

消息说明
set <f, f>设置范围值
width <float>设置宽度大小
height <float>设置高度大小
range <f, f>设置范围值
mode <float>设置模式（0 - shift，1 - select，2 - expand，3 - expand）
bgcolor <f, f, f>设置背景颜色
fgcolor <f, f, f>设置前景色
send <symbol>设置 send symbol
receive <symbol>设置 receive symbol

选项

选项说明
-width <float>
-height <float>
-range <f, f>
-mode <float>
-bgcolor <f, f, f>
-fgcolor <f, f, f>
-send <symbol>
-receive <symbol>
