[grain.live~]

实时粒度合成器

描述

[grain.live~] 是实时输入粒度处理器，生成颗粒云。

入口

入口 1

  • signal：待颗粒化处理的 signal 输入
  • bang：播放一个 cloud grains 事件

入口 2

  • float：事件中的颗粒数（默认 16，最小值 1，最大值 256）

出口

出口 1

  • signal：左通道输出

出口 2

  • signal：右通道输出

方法

消息说明
dur <f>设置 cloud 事件时长，单位 ms（默认 500）
sync <f>非 0 设为同步模式（默认 0）
size <f, f>设置最小/最大颗粒大小，单位 ms（默认：50 到 450）
transp <f, f>设置最小/最大移调，单位音分（默认：-1200 到 1200）
pan <f, f>设置左/右声像边界（默认：-1 到 1）
pos <f, f>设置延时线中的最小/最大位置（默认：0 到 1）
amp <f, f>设置最小/最大振幅值（默认：0.1 到 1）
rev <float>设置颗粒反向的概率，单位 %（默认：0）
env <any>包络类型（sin、hann、tri、gauss）或函数列表
autotune <f>非 0 自动调音到给定音阶（默认 0）
scale <list>自动调音到的音分刻度（默认平均律）

选项

选项说明

-dur <f>
-size <f, f>
-picth <f, f>
-autotune <f>
-pan <f, f>

-scale <list>

默认：5000
