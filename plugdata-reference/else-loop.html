[loop]

循环计数器

描述

[loop] 是循环计数器，但也能像 [until] 那样循环 bang（使用 -b 选项）。一个 float 设置向上计数的迭代次数。含两个元素的 list 设置起始值和结束值（并允许向上或向下计数）。计数器步长值可用 list 中的第三个可选元素设置。

入口

入口 1

  • float：设置迭代次数并启动循环
  • list：设置范围起始/结束以及（可选的）步长，并运行循环
  • bang：启动循环

入口 2

  • float：设置迭代次数

出口

出口 1

  • float/bang：计数器输出，或在 bang 模式下输出 bang

参数

#类型默认值说明
1float1<f> — 迭代次数，<f f f> — 起点、终点、步长
2float—设置结束值（可选）
3float1设置计数器步进值

方法

消息说明
offset <float>设置计数器的起始值（用于 float）
set <list>float 设置迭代次数，list 设置起始/结束值和步长（可选）
step <float>设置计数器的增量值
range <list>设置起始/结束值
pause停止循环
continue暂停后继续循环

选项

选项说明
-offset <float>设置偏移量
默认：0
-step <float>设置计数器步进值
默认：1
-b <float>设置为 bang 模式
