[gemvertexbuffer]

渲染顶点缓冲区

入口

入口 1

  • gemlist

出口

出口 1

  • gemlist

方法

消息说明
position / posX / posY / posZ从表格更新顶点位置
color / colorR / colorG / colorB / colorA从表格更新顶点颜色
normal / normalX / normalY / normalZ从表格更新顶点法线
texture / textureU / textureV从表格更新顶点纹理坐标
resize <float>更改要使用的顶点数量
draw_range <float> <float>设置局部绘制的范围
program <float>设置 GLSL 程序的 ID。
position_enable <float>, color_enable <float>, texture_enable <float>, normal_enable <float>, attribute_enable <float>启用/禁用 position、color、texture、normal 和 attribute 数据的使用
attribute <name> <table> (offset)从表格添加属性/更新属性
reset_attributes清空属性数据
print_attributes打印活动属性
