[keycode]

从键盘获取按键码

描述

[keycode] 依据物理位置输出键盘的键码，因此与布局无关（但请不要在加载 Pd 和该对象后更改布局，这会有问题，尤其在 Windows 上.. 右出口输出键码，左出口输出按键状态（1 表示按下 / 0 表示释放）。键码对应来自 <https://github.com/depp/keycode> 的 USB HID usage tables。

入口

无记录。

出口

出口 1

  • float：按下键时为 1，松开时为 0

出口 2

  • float：键码（与键盘布局无关）
