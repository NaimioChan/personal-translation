[rotate~]

通道轮换

描述

[rotate~] 为 'n' 个通道（默认 2）执行等功率旋转。它接收一个位置控制，一个完整周期从 0 到 1，0 到 -1 的负值会被回绕。

入口

入口 1（可重复）

  • signal：通道输入

入口 2

  • signal：位置（从 -1 到 1）

出口

出口 1（可重复）

  • signal：通道输出

参数

#类型默认值说明
1float2通道数（最小值 2）
2float0旋转位置
