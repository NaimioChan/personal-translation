[nyquist~]

获取奈奎斯特频率

描述

[nyquist~] 以频率或周期报告 Nyquist（即采样率的一半）。它在加载 patch 时、收到 bang 时或采样率变化时发送。它以 Hz 或 kHz 报告频率，以秒或毫秒报告周期。与 [sr~] 一样，它不报告上/下采样率。

入口

入口 1

  • bang：取得 Nyquist 频率或周期

出口

出口 1

  • float：Nyquist 频率或周期

方法

消息说明
hz设置并获取 Nyquist 频率，单位 Hz
khz设置并获取 Nyquist 频率，单位 kHz
ms设置并获取 Nyquist 周期，单位 ms
sec设置并获取 Nyquist 周期，单位 s

选项

选项说明
-khz设为频率，单位 kHz
-ms设为周期，单位 ms
-sec设为周期，单位 s
