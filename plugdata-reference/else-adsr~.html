ELSE · 包络与 LFO

[adsr~]

attack/decay/sustain/release 门控包络

描述

[adsr~] 是一个 attack/decay/sustain/release 门控包络。门开启时（从 0 变为任意值），生成 attack 斜坡，然后一段 decay 斜坡到达 sustain 点（以门值的比例指定）。门关闭时（从任意值变为 0），[adsr~] 在指定的 release 时间（单位 ms）内降到 0。

入口

入口 1

  • signal：门控值
  • float：MIDI 力度范围内的门控值（0-127 对应 0-1）
  • bang：触发/重新触发

入口 2

  • signal：通过脉冲和门信号重新触发的 signal

入口 3

  • float/signal：起音时间，单位 ms

入口 4

  • float/signal：衰减时间，单位 ms

入口 5

  • float/signal：延音振幅（与 gate 值之比）

入口 6

  • float/signal：释放时间，单位 ms

出口

出口 1

  • signal：包络信号

出口 2

  • float：包络状态（开=1 / 关=0）

参数

#类型默认值说明
1float10起音时间，单位 ms
2float10衰减时间，单位 ms
3float1延音振幅（与 gate 值之比）
4float10释放时间，单位 ms
5float1曲线参数

方法

消息说明
curve <float>设置对数曲线参数
lin设置为线性模式
lag设为滞后滤波模式
rel <float>非零设为立即释放模式
gate <float>控制 gate 值
retrigger以控制速率重新触发

选项

选项说明
-curve <float>设置曲线参数
默认：1
-lin设为 linear 模式
默认：log
-lag设为滞后滤波模式
-rel设为立即释放模式
