[float2bits]

把 float 转换为各个位

描述

[float2bits] 把十进制 float（IEEE754 单精度 32 位）值转换为二进制形式（32 位组成的列表）。顺便说，这正是 Pure Data 中使用的 float 类型。

入口

入口 1

  • float：设置 float 值并转换为比特
  • bang：转换为位

入口 2

  • float：设置要转换为比特的 float

出口

出口 1

  • anything：收到 bang 时输出位列表，收到 'split' 消息时输出 "signal"、"exponent" 和 "mantissa" 值

参数

#类型默认值说明
1float—设置要转换为比特的 float

方法

消息说明
set <float>设置 float 值且不做转换
split分别发送 "mantissa"、"exponent" 和 "signal" 值
