[setdsp~]

DSP 开关界面

描述

[setdsp~] 是一个方便的抽象对象，用于显示和设置 Pd 音频引擎（即 'DSP'）的状态。只需点击它，即可通过其开关界面切换为 On/Off。该对象常见于 ELSE 库音频对象文档的右上角。
默认情况下，[setdsp~] 对象会检查当前 DSP 状态并据此加载（开或关）。但你也可以给它一个参数来设置开/关。

入口

入口 1

  • float：非 0 - 开，0 - 关
  • bang：更改状态

出口

出口 1

  • float：dsp 状态 - 1（开），0（关）

参数

#类型默认值说明
1floatcurrent DSP state非 0 - 开，0 - 关
