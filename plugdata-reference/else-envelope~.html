ELSE · 包络与 LFO

[envelope~]

包络波形

描述

[envelope~] 提供 6 种不同的包络，通过相位输入生成。

入口

入口 1

  • float/signal：相位输入

入口 2

  • float：相位偏移

出口

出口 1

  • signal：包络波形

参数

#类型默认值说明
1anythingsinsin、hann、tri、vsaw <float>、gauss <float>、trapezoid <float, float>

方法

消息说明
phase <float>相位偏移量（从 0 到 1）
anything设置包络类型和参数：<sin>、<hann>、<tri>、<vsaw, float>、<gauss float> 和 <trap float float>

选项

选项说明
phase <float>相位偏移
默认：0
