[canvas.mouse]

画布的鼠标交互

描述

[canvas.mouse] 当你的鼠标与画布窗口交互时获取鼠标点击和鼠标坐标。可选参数设置深度层级。在编辑模式下该对象不输出任何内容。

入口

入口 1

  • zero：设置坐标为零
  • reset：重置鼠标坐标

出口

出口 1

  • float：鼠标点击状态（1=开, 0=关）

出口 2

  • float：横坐标

出口 3

  • float：垂直坐标

参数

#类型默认值说明
1float0深度
2float0非 0 设为 "position mode
3float0非 0 允许在编辑模式下输出
