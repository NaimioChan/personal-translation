[markov]

创建/播放马尔可夫链

描述

[markov] 从 float、symbol 或 list 的序列创建任意阶的马尔可夫链（可用于创建复音链）。可以改变阶数并重新创建链。可以在链创建后继续喂入信息，并用新信息重新创建。也可以清空记忆以从头开始。用第 2 个参数可以保存状态，此时链会随 patch 一起保存。

入口

入口 1

  • bang：从马尔可夫链取值并前进到下一个

出口

出口 1

  • anything：Markov 链输出

参数

#类型默认值说明
1float1设置顺序
2float0非 0 设为 savestate 模式

方法

消息说明
create从记忆创建 Markov 链并转到开头
clear清空记忆
learn <anything>用新信息馈入记忆
savesate <float>
reset转到链的开头
random转到链中的随机位置
order <float>设置顺序
seed <float>float 设置随机种子，无 float 则设置唯一的内部种子

选项

选项说明
seed <float>设置随机种子
