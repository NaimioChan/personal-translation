Gem · 图形

[pix_record]

把一串 pix 写入影片文件

入口

入口 1

  • gemlist

出口

出口 1

  • gemlist

出口 2

  • float：已写入的帧数

出口 3

  • list：关于可用编解码器/属性的信息

方法

消息说明
file <symbol>指定要写入的文件
record <float>开始/停止录制
bang抓取下一个传入的 pix
auto <float>开始/停止抓取所有传入的 pix
codeclistcodeclist：将可用编解码器列出到出口 3
codex <float>选择编解码器
codec <symbol>按短名选择编解码器
set <symbol> <float>把名为 ar1 的属性设为 arg2 值
dialog弹出对话框以选择编解码器（如果可用）
