ELSE · 数据管理

[spread]

比较 float 并分发它们

描述

与 [moses] 类似，[spread] 把传入的 float 与各参数比较，并分发到不同的出口。与 [moses] 的一个区别是它接受多个参数，并且多出一个模式。

入口

入口 1

  • float：输入到 spread 的值

出口

出口 1（可重复）

  • float：作为比较结果输出到出口

参数

#类型默认值说明
1list0要比较的 float 值

方法

消息说明
args <list>替换参数
mode <f>设置模式

选项

选项说明
-mode <f>设置模式，0 和 1（与 [moses] 相反）
默认：0
