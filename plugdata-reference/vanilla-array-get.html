vanilla · 数组与表格

[array-get]

以列表获取内容

描述

以列表形式获取内容（全部或一个范围）

入口

入口 1

  • bang：输出数组的元素
  • float：onset（从此处开始输出的索引，0 为起点）

入口 2

  • float：从 onset 开始输出的点数（-1 表示数组末尾）

入口 3

  • symbol：设置数组名称
  • pointer：使用 -s 选项时为指向该数组的指针

出口

出口 1

  • list：bang 时给定范围内的数组元素

参数

#类型默认值说明
1symbolnone未给出选项时的数组名
2float0初始起音
3float-1 (end of array)初始点数量

选项

选项说明
-s <symbol, symbol>主结构的 struct 名称和字段名
-f <symbol, symbol>元素结构的 struct 名称和字段名
