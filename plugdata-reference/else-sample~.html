ELSE · 缓冲区

[sample~]

音频缓冲区

描述

[sample~] 是一个创建音频缓冲区的抽象对象，你可以用它加载采样或往其中录制。它可以加载和保存多通道文件。

入口

入口 1

  • open <symbol>：打开采样文件
  • info：输出尺寸、采样率和通道
  • reopen：重新打开先前打开的文件
  • clear：用零填充所有数组
  • trim <f,f>：裁剪到采样范围
  • save <symbol>：设置要写入的文件
  • depth <f>：位深（16、24 或 32）
  • show：打开缓冲区子 patch 窗口
  • hide：关闭缓冲区子 patch 窗口
  • sr <f>：设置采样率（默认：patch 的采样率）
  • rename <symbol>：重命名缓冲区
  • normalize <f>：- 归一化到给定的 float 值
  • size <f>：最大缓冲区大小，单位采样点
  • ms <f>：最大缓冲区大小，单位 ms

出口

出口 1

  • list <f,f,f>：采样的大小、采样率和通道数

参数

#类型默认值说明
1symboldefault sample_$0缓冲区名
2symbolnone要加载的音频文件（可选）

选项

选项说明
-size最大缓冲区大小，单位采样点
-ms最大缓冲区大小，单位 ms
-ch通道数
默认：1
