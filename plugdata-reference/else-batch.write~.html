[batch.write~]

表格批量写入

描述

[batch.write~] 是基于 [tabwriter~] 和发给 pd 的 'fast-forward' 消息的便捷抽象对象，它以批处理方式录制到数组（来自 [sample~] 这类对象）。

入口

入口 1

  • bang：录制整个数组
  • signal：各通道要录制的 signal 输入

入口 2（可重复）

  • signal：各通道要录制的 signal 输入

出口

出口 1

  • bang：对象完成录制时输出 bang

参数

#类型默认值说明
1symbolnone要写入的数组名
2float1, max 64要录制的通道数

方法

消息说明
set <symbol>设置数组值
