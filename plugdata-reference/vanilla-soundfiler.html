[soundfiler]

把表格读写到声音文件

描述

soundfiler 对象把浮点数组读写为二进制声音文件，这些文件可以包含 wave、aiff、caf、next 或 ascii 文本格式的未压缩 2 或 3 字节整数（"pcm"）或 4 字节浮点采样点。声音文件的通道数不必与给出的数组数量一致（多余的丢弃，未提供的通道置零）。

通道数限制为 64。

### 'read' 消息的选项：

- -wave, -aiff, -caf, -next

- -skip &lt;文件中要跳过的采样帧数&gt;

- -resize（把数组调整为声音文件的大小）

- -maxsize &lt;可调整到的最大采样点数&gt;

- -raw &lt;headersize&gt; &lt;channels&gt; &lt;bytespersample&gt; &lt;endianness&gt;

- 你可以让 soundfiler 自行判断文件属于哪个已知的声音文件格式，或者用 "-raw" 选项覆盖所有头部和类型信息，这会使所有头部和类型信息被忽略。字节序是 "l"（"little"），用于 Intel 机器，或 "b"（"big"），用于较老的 PPC Macintosh。你可以给 "n"（natural）以采用你机器偏好的字节顺序。

- -ascii - 读取包含 ascii 数字的文件

- 可与 -resize 组合使用。文件中的换行被忽略，非数字字段被替换为零。如果指定了多个数组，各数组的第一个元素应排在文件最前面，接着是所有的第二个元素，以此类推（交错排列）。

### 'write' 消息的选项：

- -wave, -aiff, -caf, -next, -ascii

- -big, -little（采样点字节序）

- -skip &lt;数组中要跳过的采样帧数&gt;

- -nframes &lt;最多写入的数量&gt;

- -bytes &lt;2、3 或 4&gt;

- -normalize

- -rate &lt;采样率&gt;

入口

入口 1

  • read <list>：设置要打开的文件名，以及可选的、用于加载各通道的一个或多个数组
  • write <list>：设置要写入的文件名，以及用于指定各通道的一个或多个数组

出口

出口 1

  • float：采样点数（读取文件时）

出口 2

  • list：采样率、头大小、通道数、每采样点字节数与字节序（读取文件时）

方法

消息说明
read <list>'设置要打开的文件名，并可选地指定一个或多个数组来载入通道。可选选项：-wave、-aiff、-caf、-next、-skip <float>、-maxsize <float>、-ascii、-raw <list>'
write <list>'设置要写入的文件名，并指定一个或多个数组来描述通道。可选选项：-wave、-aiff、-caf、-next、-big、-little、-skip <float>、-nframes <float>、-ascii、-normalize、-rate <float>'
