[text-define]

创建、存储和/或编辑文本

描述

“text define” 维护一个 text 对象，并可以给它命名，使其他对象能找到它（以后应该还会有某种替代的匿名查找方式）。

可选的 `-c` 选项允许你在读写文件时把回车符解释为分隔符。

入口

入口 1

  • bang：输出指向包含该文本的 scalar 的指针

出口

出口 1

  • pointer：指向包含该数组的标量的指针

出口 2

  • anything：文本变化时输出 "updated"

参数

#类型默认值说明
1symbol—设置文本名称

方法

消息说明
clear清空文本内容
send <symbol>向具名 receive 对象发送指针
read <symbol>从文件读取（可选 -c 选项）
write <symbol>写入文件（带可选的 -c 选项）
sort排序文本内容
click打开文本窗口
close关闭文本窗口

选项

选项说明
-k随 patch 保存/保留文本内容
