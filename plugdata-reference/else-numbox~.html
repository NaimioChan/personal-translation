[numbox~]

信号数值框

描述

[numbox~] 是一个信号 GUI 数字框。它可用于按固定速率显示/监视信号值，或带斜坡时间生成信号值。

入口

入口 1

  • float：设置生成值
  • signal：要显示的值

出口

出口 1

  • signal：监听时的输入，或改为生成的值

方法

消息说明
set <float>用给定的 float 设置初始值和生成值；若无 float 则设置当前值
size <float>设置字体大小
width <float>设置数字宽度
range <float, float>设置拖动的最小值与最大值
bgcolor <f, f, f>用 RGB 设置背景颜色
fgcolor <f, f, f>用 RGB 设置前景色
ramp <float>设置斜坡时间，单位 ms
rate <float>设置刷新率，单位 ms
load <float>设置初始生成值（默认 0）

选项

选项说明
-size <float>字号（最小 8）
默认同 patch
-load <float>用给定的 float 设置初始值并生成值；如果没给 float，则设置当前值。
-width <float>设置数字宽度（最小 1）
默认：6
-range <float, float>拖动范围
默认：0, 0 - 无限
-bgcolor <f, f, f>用 RGB 设置背景颜色
默认：255 255 255
-fgcolor <f, f, f>用 RGB 设置前景色
默认：0 0 0
-ramp <float>设置斜坡时间，单位 ms（最小 0）
默认：10
-rate <float>设置刷新速率，单位 ms（最小 15）
默认：100
