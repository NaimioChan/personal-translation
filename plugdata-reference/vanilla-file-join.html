vanilla · 文件管理

[file-join]

'''join'' 一组组成部分，以 ''/'' 作为分隔符

描述

此对象对文件名执行常见的字符串操作。不进行任何检查来验证任何路径组件的有效性/存在性。

'file join' 对象同时接受 symbol 和数字。

入口

入口 1

  • list：待拼接的组件列表

出口

出口 1

  • symbol：拼接后的路径或文件

出口 2

  • null：未启用的出口！
