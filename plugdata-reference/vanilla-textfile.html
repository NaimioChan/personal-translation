[textfile]

读写文本文件

描述

'cr' = 只用回车符结束行（省略分号）。你也可以用这种方式读取文件，此时回车符会被映射为分号。

textfile 对象在内存与文本文件之间读写。你可以读取文件并把各行依次作为列表输出，也可以收集各行再把它们写出。例如，你可以用这个对象为 Gem 生成 “模型”。

要记录文本消息并保存到文件，先发送 “clear” 清空 qlist，再发送 “add” 添加消息（以分号结束）。消息 “add2” 添加一个原子列表，但不以分号结束，以便你构造变长消息。

你也可以只用这个对象来存储异构的列表序列。

入口

入口 1

  • bang：输出整行并转到下一行

出口

出口 1

  • anything：textfile 对象中存储的行

出口 2

  • bang：当到达序列末尾时

方法

消息说明
rewind转到开头（并停止）
clear清空 textfile
add <anything>向 textfile 添加一条消息
add2 <anything>添加一条消息但不终止它
set <anything>清空 textfile 并添加一条消息
print将内容打印到 Pd 窗口
read <symbol, cr>读取文件（可选 'cr' 参数）
write <symbol, cr>写入文件（带可选的 'cr' 参数）
