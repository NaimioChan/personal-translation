[bin.shift~]

移位分箱

描述

[bin.shift~] 用于频谱处理，可在其中平移采样点（或频率 bin）。它类似于 Pd Vanilla 的 [lrshift~] 对象，后者可在任意块大小下工作，把采样点向左或向右平移。

入口

入口 1

  • signal：待移位的 signal

入口 2

  • float：设置要移位的 bin 数量

出口

出口 1

  • signal：分箱偏移后的信号

参数

#类型默认值说明
1float0设置移位数
2float0非 0 设为 wrap 模式

方法

消息说明
wrap <float>非 0 设为 wrap 模式
