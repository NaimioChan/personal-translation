ELSE · 信号发生器

[blip~]

带限余弦振荡器

描述

[blip~] 使用 DSF（Discrete-Summation Formulae）以余弦之和的形式生成波形。它接收基频（单位 Hz）、谐波数量、第一个之后各分音的乘数以及最低谐波编号（默认生成脉冲波形）。该对象基于 Csound 的 'gbuzz' opcode。

入口

入口 1

  • float/signal：基频，单位 Hz

入口 2

  • signal：冲量复位相位

入口 3

  • float/signal：相位调制输入

入口 4

  • float/signal：频谱倍数

出口

出口 1

  • signal：带限振荡器输出

参数

#类型默认值说明
1float0基频，单位 Hz
2float1分音数量
3float1频谱倍数
4float1最低谐波

方法

消息说明
n <float>分音数量
low <float>最低谐波
midi <float>非 0 将频率输入设为 MIDI 音高
soft <float>非 0 设为软同步模式

选项

选项说明
-midi把频率输入设为 MIDI 音高
默认：Hz
-soft设为软同步模式
默认：hard
