[gain~]

单声道增益

描述

[gain~] 是便捷的单声道增益抽象对象，用于调整信号的增益。它有斜坡时间、最大增益、缩放模式和 init 控件。

入口

入口 1

  • signal：将要调整增益的传入信号
  • bang：静音/取消静音

出口

出口 1

  • signal：调整后的增益信号

出口 2

  • float：滑块值，从 0-1（与最大增益无关）

方法

消息说明
set <float>设置滑块（范围被裁剪到 0-1）
mode <float>缩放模式；0（四次方，默认）、1（dB）或 2（线性）
gain <float>设置最大增益（<= 0 的值被忽略）
ramp <float>设置滑块值的斜坡时间，单位 ms（默认：20）
savestate <float>非 0 将保存对象状态
learn学习一个 MIDI 控制器
forget遗忘一个 MIDI 控制器

选项

选项说明
-max <float>设置最大增益（需 > 0，默认 1）
-mode <float>设置缩放模式；0 (quartic)、1 (dB) 或 2 (linear)
默认：quartic
-ramp <float>设置斜坡时间（最小 5）
默认：20
-savestate保存对象状态
默认：0
