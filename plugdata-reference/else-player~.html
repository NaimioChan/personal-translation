[player~]

多通道播放器

描述

[player~] 是一个基于 [soundfiler] 和 [tabplayer~] 的便捷抽象。它比 [play.file~] 通用得多。例如，你可以以不同速度播放，也可以倒放。

入口

入口 1

  • float：非 0 播放，<0> 停止
  • bang：播放（等同于非 0）

出口

出口 1（可重复）

  • signal：通道 $nth 的缓冲区信号

出口 2

  • bang：播放完缓冲区时输出 bang

参数

#类型默认值说明
1float1 if no file is given, or sound file's if given（可选）通道数量（最大 64）
2symbolnone要打开的文件名称
3float0autostart <1：开，0：关>
4float0循环 <1：开，0：关>

方法

消息说明
open <symbol>打开文件（无 symbol 则打开对话框）
set <symbol>设置要打开的文件（需要 reload 消息）
show显示缓冲区子 patch 窗口
hide隐藏缓冲区子 patch 窗口
start <float>设置起点，单位 ms
end <float>设置终点，单位 ms
range <f, f>按比例设置起点与终点（0 到 1）
speed <float>设置播放速度，单位 %
pos <float>设置位置（0 到 1）并开始播放
play <f, f, f>不给 float 时播放整个文件。第 1 个 float 设置起点，第 2 个设置终点（单位 ms），第 3 个设置速度倍率
<stop>停止播放并输出 0（无法恢复）
<pause>在特定点暂停（可恢复）
<resume>暂停后恢复播放
fade <float>设置淡入淡出时间，单位 ms（默认 0）
xfade <float>非 0 设为交叉淡化模式（默认 0）
loop <float>非 0 启用循环，<0> 禁用（默认 0）

选项

选项说明
-speed <float>默认 100
-range <f, f>默认 0 1
-fade <float>默认 0
-xfade开启 xfade 模式
-loop循环模式开启
