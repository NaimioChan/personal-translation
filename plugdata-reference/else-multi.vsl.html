[multi.vsl]

多重垂直滑块

描述

[multi.vsl] 是一个多滑块 GUI 抽象。

入口

入口 1

  • bang：输出所有滑块的值（取决于模式）
  • list：从第一个 (0) 开始设置并输出滑块的值

出口

出口 1

  • list：默认模式下的滑块编号 / 滑块值，或在 "list mode" 下作为列表的全部值

出口 2

  • list：收到 export 消息时的值列表

方法

消息说明
mode <float>非 0 设为 'list mode'
dump按顺序输出值，形式为滑块编号 / 值
set <list>从第一个 float 定义的索引开始设置值
setall <float>设置所有滑块的值
get <list>从第一个 float 获取滑块值
dim <f, f>设置水平/垂直尺寸
width <float>设置水平大小
height <float>设置垂直大小
range <f, f>设置滑块的输出范围
n <float>设置滑块数量
jump <float>非 0 设为点击跳转模式
import <list>设置滑块数量与值（并 dump 它们）
export将滑块值以列表输出
savestate <float>非 0 将保存对象状态
send <symbol>设置 send 名称
receive <symbol>设置 receive 名称
bgcolor <f, f, f>用 RGB 设置背景颜色
fgcolor <f, f, f>用 RGB 设置前景色
linecolor <f, f, f>设置线条颜色，RGB

选项

选项说明
-n <float>设置滑块数量大小
默认：8
-range <float, float>设置滑块的范围
默认：0 127
-name <symbol>设置数组名称
默认：internal
-jump <float>非 0 设为点击即跳跃模式
默认：0
-dim <float, float>设置 x/y 尺寸
默认：200 127
-savestate <float>非 0 将保存对象状态
默认：0
-send <symbol>设置发送 symbol
默认：empty
-receive <symbol>设置接收 symbol
默认：empty
-bgcolor <f, f, f>用 RGB 设置背景颜色
默认：255 255 255
-fgcolor <f, f, f>用 RGB 设置前景色
默认：220 220 220
-linecolor <f, f, f>用 RGB 设置线条颜色
默认：0 0 0
-set <list>设置滑块的值
默认：0 0 0 0 0 0 0 0
-mode <float>非零设为 'list mode'
默认：0
