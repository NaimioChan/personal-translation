ELSE · 效果器

[flanger~]

镶边效果

描述

[flanger~] 是一个简单的 flanger FX 对象。

入口

入口 1

  • signal：flanger 输入

入口 2

  • float：速率，单位 Hz

入口 3

  • float：深度（单位 ms）

入口 4

  • float：前馈/反馈线的系数

出口

出口 1

  • signal：flanger 输出

参数

#类型默认值说明
1float0速率，单位 Hz
2float0深度，单位 ms
3float0系数

选项

选项说明
-tri把波形设为三角波
默认：sine
