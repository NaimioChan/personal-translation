ELSE · 界面

[circle]

圆形滑块

描述

[circle] 是二维滑块 GUI 抽象对象（另见 [else/slider2d)。

入口

入口 1

  • bang：输出最后的值
  • list：设置 x、y 并输出

出口

出口 1

  • list：x/y 值

方法

消息说明
set <float, float>设置 x 与 y
size <float>设置大小
range <float, float>设置范围（x 与 y 的最小值和最大值）
yrange <float>设置范围（y 的最小值和最大值）
xrange <float>设置范围（x 的最小值和最大值）
line <float>非 0 设置线条可见性
grid <float>非 0 设置网格可见性
bgcolor1 <f, f, f>用 RGB 设置圆内的背景颜色
bgcolor2 <f, f, f>用 RGB 设置圆外的背景颜色
bgcolor <f, f, f>用 RGB 设置两个背景色
fgcolor <f, f, f>用 RGB 设置前景色
savestate <float>非 0 将保存对象状态
clip <float>非 0 在圆内裁剪

选项

选项说明
-size <float>设置 x/y 大小
默认：127
-line <float>非 0 设置线条可见性
默认：1
-fgcolor <f, f, f>用 RGB 设置前景色
默认：0 0 0
-grid <float>非 0 设置网格可见性
默认：0
-savestate <float>非 0 时将保存对象状态
默认：0
-range <f, f>设置范围（x 和 y 的最小值和最大值）
默认：-1 1
-xrange <f> / -yrange <f>分别设置 x/y 范围
-bgcolor1 <f, f, f>用 RGB 设置界内背景颜色
默认：255 255 255
-bgcolor2 <f, f, f>用 RGB 设置界外颜色
默认：255 255 255
-bgcolor <f, f, f>用 RGB 设置两个背景颜色
默认：255 255 255
-clip <float>非 0 设为裁剪模式
默认：1
