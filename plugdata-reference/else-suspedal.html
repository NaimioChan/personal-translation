ELSE · MIDI

[suspedal]

延音踏板

描述

[suspedal] 开启时保持 MIDI Note-Off 消息，关闭时把它们发送出去。它有两种延音模式，'regular'（默认）和 'tonal' —— 如同现代钢琴的设计。

入口

入口 1

  • float：note 消息的音高部分
  • list：来自 note 消息的一对 pitch/velocity 值

入口 2

  • float：note 消息的力度部分

入口 3

  • float：踏板开关：开 <1> 或关 <0>

出口

出口 1

  • float：note 消息的音高值

出口 2

  • float：note 消息的力度值

参数

#类型默认值说明
1float0 - offfloat - 非 0 打开踏板

方法

消息说明
clear清空记忆（不输出 note-off 消息）
flush输出所有被保持的 note-off 消息
tonal <float>非 0 设为 "tonal" 模式
retrig <float>设置重新触发模式 <0、1、2 或 3>
sustain <float>踏板开关：开 <1> 或关 <0>

选项

选项说明
-retrig设置重触发模式 <0, 1, 2 或 3>
默认：0
-tonal把延音设为 "tonal" 模式
