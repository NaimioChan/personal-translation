ELSE · 信号发生器

[pm2~]

2 个算子的相位调制矩阵

描述

[pm2~] 是一个 2 运算符 FM（实际上是相位调制）合成器。每个振荡器都可以调制自身和其他振荡器。

入口

入口 1

  • float/signal：频率，单位 Hz

入口 2

  • signal：运算器 1 的主电平

入口 3

  • signal：运算器 2 的主电平

出口

出口 1

  • signal：左输出

出口 2

  • signal：右输出

参数

#类型默认值说明
1float0频率，单位 hz

方法

消息说明
idx <list>设置调制矩阵值
'i'to'j' <float>设置索引（'1to2' 把 op1 设为 op2 的索引，等等）
ratio <list>设置运算符的频率比
detune <list>设置运算符的失谐频率
pan <list>设置运算符的声像
vol <list>设置运算符的音量
ratio'n' <float>设置 op 频率比（'ratio1' 设置 op1，等等）
detune'n' <float>设置 op 失谐（'detune1' 设置 op1，等等）
pan'n' <float>设置 op 声像（'pan1' 设置 op1，等等）
vol'n' <float>设置 op 音量（'pan1' 设置 op1，等等）

选项

选项说明
-ratio <float>设置频率比（默认全部 = 1）
-vol <list>设置音量（默认 all = 1）
-detune <list>设置频率失谐（默认全部 = 0）
-pan <list>设置声像（默认 all = 0）
-idx <list>设置调制矩阵（默认全部 = 0）
