[fdn.rev~]

反馈延时网络混响器

描述

[fdn.rev~] 是一个反馈延时网络混响器，可用于后期反射（又称混响尾音）。主要参数为：衰减时间（t60）和高频阻尼。

入口

入口 1

  • signal：待混响的输入信号
  • list：设置反射时间，单位 ms

入口 2

  • float：衰减时间，单位 s（t60）

入口 3

  • float：高频阻尼，单位 %（0 到 100）

出口

出口 1

  • signal：FDN 混响器的左输出

出口 2

  • signal：FDN 混响器的右输出

方法

消息说明
time <float>混响衰减时间，单位 s（t60）
damping <float>高频阻尼，单位 %（0 到 100）
set <list>设置行数以及最小/最大时间
exp <float>非 0 以指数方式设置延时时间
clear清空延时线和混响
print在 Pd 窗口打印延时线和其他参数

选项

选项说明
-time <float>t60 混响时间，单位 s
默认：4
-damping <float>高频阻尼，单位 %
默认：0
