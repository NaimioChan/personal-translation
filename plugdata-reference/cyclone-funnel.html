cyclone · 数据管理

[funnel]

依据入口标记数据

描述

[funnel] 从多个入口接收数据并把它们汇集到一个出口。传入的数据带有入口编号标记，可用 [route] 或 [spray] 取出。它也可用于把值存入 table/coll。

入口

入口 1（可重复）

  • anything：要打上标记并输出的任意数据
  • bang：发送该入口中最后接收到的消息

出口

出口 1

  • list：前面带入口编号的传入消息

参数

#类型默认值说明
1float2设置 'n' 个入口
2float0第一个入口编号偏移量

方法

消息说明
set <anything>设置一条消息并且不输出
offset <float>设置入口编号的偏移量
