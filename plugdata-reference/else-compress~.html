ELSE · 效果器

[compress~]

压缩器

描述

[compress~] 是执行压缩的抽象对象。它衰减高于给定阈值的输入 signal。

入口

入口 1

  • signal：输入信号

出口

出口 1

  • signal：压缩后的信号

出口 2

  • float：衰减量，单位 dB

参数

#类型默认值说明
1float-10阈值，单位 dB
2float1衰减比（默认 1）
3float10起音时间，单位 ms
4float10释放时间，单位 ms
5float0输出增益调整，单位 dB
6float512RMS 平均长度，单位采样点

方法

消息说明
thresh <float>设置阈值，单位 dB
ratio <float>设置衰减比
attack <float>设置起音时间，单位 ms
release <float>设置释放时间，单位 ms
gain <float>输出增益调整，单位 dB
size <float>RMS 平均长度，单位采样点（1 到 512）
