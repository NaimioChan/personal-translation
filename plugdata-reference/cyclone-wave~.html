cyclone · 数组与表格

[wave~]

波表读取器

描述

以相位 signal 作为输入（从 0 和 1）时，[wave~] 会读取给定的表格。它有很多插值选项，并可在数组中设置起点和终点。

入口

入口 1

  • signal：用于读取数组的相位信号

入口 2

  • signal：起点，单位 ms

入口 3

  • signal：结束点，单位 ms

出口

出口 1

  • signal：给定 wavetable 通道的指定部分

参数

#类型默认值说明
1symbol—数组名（必填）
2float0起点，单位 ms
3floatlength of the array in ms结束点，单位 ms
4float1输出通道数

方法

消息说明
set <symbol>设置数组名
interp <float>设置插值模式 <0-7>
@interp_bias <float>hermite 插值偏置
@interp_tension <float>hermite 插值张力

选项

选项说明
@interp <float>插值模式
默认：1（linear）
@interp_bias <float>默认：0
@interp_tension <float>默认：0
