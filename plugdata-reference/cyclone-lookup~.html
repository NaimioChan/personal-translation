cyclone · 效果器 · 数组与表格

[lookup~]

传递函数查找表

描述

[lookup~] 把数组用作波形整形失真的传递函数，其中信号输入值（从 -1 到 1）被映射到表格的索引。

入口

入口 1

  • signal：要用作索引的 signal

入口 2

  • float/signal：数组的起点

入口 3

  • float/signal：数组的结束点

出口

出口 1

  • signal：传递函数查表（波形整形）的输出

参数

#类型默认值说明
1symbol—用于查找的数组/表格名
2float0数组/表格中的初始起点
3float511数组/表格中的初始终点

方法

消息说明
set <symbol>设置用于查询的数组/表格
