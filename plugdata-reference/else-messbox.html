[messbox]

GUI 消息框

描述

[messbox] 对象是可以在运行模式下输入消息的对象。它像 atom 框，但能做消息框所做的一切。任何消息类型都可以。它处理美元符号、逗号和分号的方式与常规消息框相同。详见 [pd syntax]。

入口

入口 1

  • bang：输出消息
  • anything：用 "$1" "$2" 等设置消息并输出

出口

出口 1

  • anything：消息

方法

消息说明
set <anything>设置消息
append追加到消息
dim <f, f>设置宽度与高度
fontsize <float>设置字体大小
bold非 0 设为粗体
bgcolor <f, f, f>设置背景颜色
fgcolor <f, f, f>设置文字颜色

选项

选项说明
-fontsize <float>字体大小
-size <f, f>大小
-fgcolor <f, f, f>前景颜色
-bgcolor <f, f, f>背景颜色
-bold非 0 设为粗体
