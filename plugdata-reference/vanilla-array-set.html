vanilla · 数组与表格

[array-set]

用列表设置内容

描述

用列表设置内容（全部或一个范围）

入口

入口 1

  • list：待写入数组的值列表

入口 2

  • float：onset（从此处开始设置的索引，0 为起点）

入口 3

  • symbol：设置数组名称
  • pointer：使用 -s 选项时为指向该数组的指针

出口

无记录。

参数

#类型默认值说明
1symbolnone未给出选项时的数组名
2float0初始起音

选项

选项说明
-s <symbol, symbol>主结构的 struct 名称和字段名
-f <symbol, symbol>元素结构的 struct 名称和字段名
