ELSE · 数组与表格

[tabreader]

表格读取器

描述

[tabreader] 默认接受 0 到 1 的索引，并以不同的插值方法读取数组，支持多通道。数组中不需要有保护点，因为这些由内部处理。

入口

入口 1

  • float：设置索引/相位

出口

出口 1

  • signal：表格值

参数

#类型默认值说明
1symbolnone数组名（可选）

方法

消息说明
set <symbol>设置整个数组用作波形
index <float>非 0 设置读取的索引
loop <float>非 0 设为循环模式
none设置为无插值
lin设置为线性插值
cos设置为余弦插值
cubic设置为三次插值
lagrange设置为 Lagrange 插值
hermite <f, f>设置为 Hermite 插值

选项

选项说明
-lin设置插值类型
-cos设置插值类型
-cubic设置插值类型
-lagrange设置插值类型
-hermite <f, f>设置插值类型
-none设置插值类型
-ch <float>设置初始加载的通道
默认：1
-index设为索引模式
-loop设为循环模式
