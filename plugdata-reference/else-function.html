[function]

函数 GUI

描述

[function] 是断点函数 GUI，主要与 [function~] 或 [envgen~] 一起使用。你可以在上面点击拖动，或向它发送列表。

入口

入口 1

  • float：0-1 的值被当作索引
  • list：设置并输出断点函数
  • bang：输出断点函数

出口

出口 1

  • list：用于 [envgen~]/[function~] 的断点函数

方法

消息说明
i <float>表格的索引（输出函数值）
set <list>设置断点函数
duration <float>重置总时长
min <float>设置图形边界的最小值
max <float>设置图形边界的最大值
resize <float>依据最小值/最大值设置新的图形边界
height <float>设置高度
width <float>设置宽度
fgcolor <f, f, f>设置前景的 RGB 颜色
bgcolor <f, f, f>设置背景的 RGB 颜色
send <symbol>设置 send symbol
receive <symbol>设置 receive symbol
savestate <float>非 0 将保存对象状态

选项

选项说明
-height <float>默认 100
-width <float>默认 200
-send <symbol>默认 none
-receive <symbol>默认 none
-bgcolor <f, f, f>
-fgcolor <f, f, f>
-resize <float>
-min <float>默认 0
-max <float>默认 1
-savestate保存对象状态
默认：0
-set <list>默认 0 1000 0
