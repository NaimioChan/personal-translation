[popmenu]

GUI 弹出菜单

描述

[popup] 是一个弹出菜单 GUI。点击它就会出现弹出菜单供选择元素（symbol 或 float）。可以点击选中项来选择，也可以用上下方向键并回车来选择。默认输出的是索引，但也可以输出元素或两者都输出。

入口

入口 1

  • float：设置并输出值
  • bang：输出值
  • set <float>：设置所选项

出口

出口 1

  • float：当前条目

方法

消息说明
fontsize <float>设置字体大小
width <float>设置菜单的宽度
height <float>设置菜单的高度
clear清空所有菜单项
add <list>向菜单添加一项
bg <list>设置背景颜色
fg <list>设置前景颜色
receive <symbol>设置消息的 receive symbol
send <symbol>设置消息的 send symbol
var <symbol>为菜单分配一个变量
param <symbol>为菜单分配一个参数
mode <float>设置输出模式，0=index（默认）、1=item、2=both
label <symbol>设置菜单标签
outline <float>切换菜单轮廓
keep <float>选择后保持菜单打开
pos <float>设置菜单位置
lb <float>设置下限
load <list>加载菜单项列表
savestate <float>保存当前状态
loadbang <float>对象加载时触发

选项

选项说明
-load <float>设置载入值，没有 float 则设置当前值
默认：0
-size <float>设置大小，单位像素
默认：50
-bg <list>设置背景颜色，用十六进制或 RGB 列表
默认：#dfdfdf
-fg <list>设置前景色，用十六进制或 RGB 列表
默认：#000000
-send <symbol>设置发送 symbol
默认：empty
-receive <symbol>设置接收 symbol
默认：empty
-noloadbang初始化时禁用输出
默认：0
-nokeep重新打开时忘记条目
默认：0
-savestate记住上次状态
默认：0
-var <symbol>为菜单指定变量
默认：empty
-param <symbol>为菜单指定参数
默认：empty
-mode <float>设置输出模式，0=index，1=item，2=both
默认：0
