[bitsafe~]

把 NaN/Inf 和非规格化信号替换为 0

描述

[bitsafe~] 把新到达信号中的 NaN（非数值）和 +/- infinity 值替换为 0，这在配合 cyclone 中的位运算或任何其他可能出现这些值的情况时很有用。此外，cyclone 中的 bitsafe~ 会滤除非规格化数并把它们变为 0，尽管原始的 MAX 对象不会这样做。

入口

入口 1

  • signal：将 NaN/Inf 值替换为 0 的输入信号

出口

出口 1

  • signal：在原为 NaN/Inf 值处取 0 的 signal
