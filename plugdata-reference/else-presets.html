ELSE · 数据管理

[presets]

预设管理器

描述

[presets] 管理 patch 和抽象对象的预设，并具有插值和变形功能。修改下面的数字和 symbol，保存一个预设和 patch，重新打开即可调用预设。使用 "read" 消息可恢复到此示例的默认状态。

入口

入口 1

  • float：设置预设编号并加载
  • bang：保存预设（等同于不带 float 的 'save'）
  • list：从列表导入预设

入口 2

  • float：插值值（处于插值模式时）

出口

出口 1

  • list：接收 "export" 消息时以列表形式给出的预设

出口 2

  • bang：当预设为空时

参数

#类型默认值说明
1listnone一个或多个 receive 名称

方法

消息说明
set <float>设置预设编号
load <float>按预设编号加载。如果没有给出 float，则加载最后设置的预设编号
save <float>保存到预设编号。如果未给出 float，则保存最后设置的预设
n <float>设置预设数量
morph <f, f>设置预设之间变形的时间与颗粒
interp <f>设置为插值模式
exp <f>设置插值/变形的指数因子
clear <float>清空指定编号预设的数据，不给 float 则清空所有预设
show打开预设窗口以便查看/编辑值
hide关闭预设窗口
args <list>替换接收名称参数
read <symbol>从文件导入预设，不给 symbol 则打开对话框窗口
write <symbol>把预设写入文件，没有 symbol 则打开对话框窗口
export将预设导出为 list

选项

选项说明
-n <float>设置预设数量
默认：64
-file <symbol>设置要导入的文件
默认：none
-morphtime <float>设置 morph 时间
默认：0
-morph <f, f>设置 morph 时间和颗粒
默认：0 20
-interp设为插值模式
默认：no interpolation
-exp <float>设置 morph/插值的指数因子
默认：1
