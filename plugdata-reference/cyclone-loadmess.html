[loadmess]

当 patch 加载时发送消息

描述

[loadmess] 在 patch 加载时自动输出一条消息，或在 patch 是另一个被打开的 patch 的抽象对象时输出。

入口

入口 1

  • bang：输出其键入的消息

出口

出口 1

  • anything：加载的消息（当 patch 被加载时，或收到 bang/被点击时）

参数

#类型默认值说明
1anythingbang要发送的消息

方法

消息说明
set <anything>set 后接任意消息，设置 loadmess 所持有的消息，无任何输出

选项

选项说明
@defer <0/1>输出被延迟（@defer 0 会先于 @defer 1 发送）
默认：0
