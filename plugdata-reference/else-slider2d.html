[slider2d]

二维滑块

描述

[slider3d] 是一个二维滑块 GUI 抽象对象（另见 [circle)。

入口

入口 1

  • bang：输出最后的值
  • list：设置 x、y 并输出

出口

出口 1

  • list：x/y 值

方法

消息说明
set <f,f>设置 x 与 y
size <f>设置大小
width <f>设置 x（水平）大小
height <f>设置 y（垂直）大小
xrange <f,f>设置 x 范围
yrange <f,f>设置 y 范围
line <f>- 非 0 设置线条可见性
grid <f>非 0 设置网格可见性
bgcolor <f,f,f>用 RGB 设置背景颜色
fgcolor <f,f,f>用 RGB 设置前景色
savestate <float>非 0 将保存对象状态

选项

选项说明
-size <f>设置 x/y 大小
默认：127
-dim <f,f>分别设置 x/y 尺寸
默认：127
-range设置 x/y 范围
默认：0 127
-xrange/-yrange分别设置 x/y 范围
-line <f>非 0 设置线条可见性
默认：1
-grid <f>非 0 设置网格可见性
默认：0
-bgcolor <f,f,f>设置背景颜色
默认：255 255 255
-fgcolor <f,f,f>设置前景色
默认：0 0 0
-savestate <float>非 0 将保存对象状态
默认：0
