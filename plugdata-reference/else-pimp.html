ELSE · 信号发生器

[pimp]

控制 phasor + imp

描述

这类似 [pimp~]，但在控制速率下工作（最大分辨率为 1 ms）。

入口

入口 1

  • float：频率，单位 Hz

入口 2

  • float：相位同步（重置内部相位）

出口

出口 1

  • float：phase" 值，从 0 到 127

出口 2

  • bang：在周期切换时输出 bang

参数

#类型默认值说明
1float0频率，单位 Hz
2float0初始相位偏移量

方法

消息说明
rate <float>速率周期，单位 ms

选项

选项说明
-rate <float>速率周期，单位 ms（最小 0.1）
默认：5
