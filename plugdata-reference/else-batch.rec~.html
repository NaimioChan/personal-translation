[batch.rec~]

声音文件批量录制

描述

[batch.rec~] 是基于 [writesf~] 和发给 pd 的 'fast-forward' 消息的便捷抽象对象，它以批处理方式录制到声音文件，可用 [sample~]、[play.file~]、[player~] 等对象加载。

入口

入口 1（可重复）

  • signal：各通道要录制的 signal 输入

出口

出口 1

  • bang：对象完成录制时输出 bang

参数

#类型默认值说明
1symbolfile.wav（可选）要保存到的文件名
2symbol1, max 64要录制的通道数

方法

消息说明
rec <float>按给定的时间开始录制，单位 ms。如果没有给出 float，则使用最后设置的值
set <symbol>设置文件名（无 symbol 时打开对话框）
