ELSE · 触发与时钟

[timed.gate]

控制定时 gate

描述

当收到 bang 或 float 时，[timed.gate] 发送一个定时 gate（在给定时长内为 float 的值，否则为 0）。

入口

入口 1

  • float：带 gate 值的控制触发
  • bang：带上次/初始 gate 值的控制触发

入口 2

  • float：门控时间，单位 ms

出口

出口 1

  • float：定时门

参数

#类型默认值说明
1float0, no gate门控时间，单位 ms
2float1初始门控振幅
3float0非 0 设为重触发模式

方法

消息说明
ms <float>门控时间，单位 ms
retrigger <float>非 0 设为重触发模式
