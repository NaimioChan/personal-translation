[bonk~]

起音检测与频谱包络测量

描述

起音检测与频谱包络测量

入口

入口 1

  • signal：待分析的 signal 输入
  • bang：通过 "raw" 出口轮询当前频谱

出口

出口 1

  • list：raw" attack 的频谱（所用 11 个频段的响度值）

出口 2

  • list：cooked" 乐器编号（如果有模板）、力度和温度

方法

消息说明
thresh <float, float>设置低阈值和高阈值
mask <float, float>设置能量掩膜配置：分析次数和下降系数
attack-frames <float>设置测量增长所用的帧数
minlevel <float>设置要输出的最小 "velocity"（忽略更轻的音符）
spew <float>非 0 打开 spew 模式，为零则关闭
useloudness <float>非 0 设为可选的响度单位（实验性）
debug <float>非 0 设为调试模式
print <float>非 0 时打印出设置、模板和滤波器组设置
debounce <float>设置学习模式下两次起音之间的最小时间（单位 msec）
learn <float>遗忘并学习给定次数（推荐 10）
forget遗忘上一个模板
write <symbol>把模板写入文件
read <symbol>从文件读取模板

选项

选项说明
-npts窗口大小，单位点
默认：256
-hop分析周期（"hop size"），单位点
默认：128
-nfilters要使用的滤波器数
默认：11
-halftones滤波器带宽，单位半音
默认：6
-minbandwidth最小带宽，单位 bins
默认：1.5
-overlap滤波器之间的重叠因子
默认：1
-firstbin最低滤波器的中心频率，单位 bins
默认：1
