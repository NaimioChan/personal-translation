cyclone · 转换器

[fromsymbol]

把 symbol 转换为 anything

描述

[fromsymbol] 把 symbol 消息转换为 anything（任意类型的消息）。先在下方原子 symbol 框中输入一个 float，看看它如何转换为 float 消息，然后查看右侧的更多例子。

入口

入口 1

  • symbol：待转换为任意消息类型的 symbol
  • bang：输出 bang
  • float：直接作为 float 通过
  • list：如果第一个元素是 float，则直接通过
  • anything：第 1 个元素被当作 symbol 并转换

出口

出口 1

  • anything：由 symbol 转换而来的消息

选项

选项说明
@separator <symbol>设置分隔字符
默认："space
