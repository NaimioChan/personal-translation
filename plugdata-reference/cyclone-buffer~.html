cyclone · 缓冲区

[buffer~]

音频缓冲区

描述

[buffer~] 把音频存储在内存缓冲区中。它读写多通道音频文件，可以与 [play~] 及其他相关对象一起使用。这是一个抽象对象，没有 Max/MSP 原版的全部功能。

入口

入口 1

  • open：打开缓冲区子 patch 窗口

出口

无记录。

参数

#类型默认值说明
1symbol—缓冲区名
2symbol—要加载的音频文件（可选）
3float0 or -1 if audio file is given缓冲区大小，单位 ms
4floatdefault 1 or audio file's (if given)通道（1 到 64）

方法

消息说明
clear用零填充所有数组
crop <f, f>把采样点裁剪到以 ms 为单位的范围并调整缓冲区大小
read <symbol>设置要加载的文件（无 symbol 时打开对话框）
readagain再次读取并加载先前打开的文件
write <symbol>设置要写入的文件（无 symbol 时打开对话框）
format <any>设置位深 - 详见 [pd read/write]
writewave <symbol>设置要写入的 wave 文件（无 symbol 时打开对话框）
writeaiff <symbol>设置要写入的 aiff 文件（无 symbol 时打开对话框）
filetype <symbol>symbol 设置要写入的文件类型（"wave" 或 "aiff"）
open打开缓冲区子 patch 窗口
wclose关闭缓冲区子 patch 窗口
sr <float>设置写入文件的采样率
fill <any>见上文的 [pd function/generators]
apply <any>见上文的 [pd function/generators]
set <symbol>更改缓冲区名称
name <symbol>同 'name'
normalize <f>归一化到给定的 float 值
setsize <float>设置缓冲区大小，单位 ms
sizeinsamps <f>设置缓冲区大小，单位采样点

选项

选项说明
@size <float>设置缓冲区大小，单位 ms
@samps <float>设置缓冲区大小，单位采样点
