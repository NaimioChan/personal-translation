vanilla · 数组与表格

[element]

获取指向数组元素的指针

描述

“element” 在右侧接收一个指针，在左侧接收一个索引号。它从指针（应当是一个数组）中查找一个字段，并输出由该索引号指定的数组元素。不存在指向数组本身的指针，只有指向单个元素的指针。模板和字段名通过创建参数指定。

索引范围从 0 到元素个数减一；
超出范围的索引会被悄悄替换为最接近的端点。

如果你不知道模板名，可以指定 “-”，此时对象会自行推断模板名，这可能会在效率和清晰度上付出一些代价。

入口

入口 1

  • float：设置元素索引并输出指针

入口 2

  • pointer：指向数组的指针

出口

出口 1

  • pointer：指向数组内元素的指针

参数

#类型默认值说明
1symbol—模板名称
2symbol—字段名

方法

消息说明
set <symbol, symbol>设置模板和字段名
