[set]

设置标量中的值

描述

“Set” 在最右侧入口接收指向标量的指针。其余入口设置数值字段。symbol 有特殊处理方式，如下所示。数组通过 “element” 对象访问，列表通过 “text” 对象访问。只有最左侧入口是 “热” 的。

要设置值为 symbol 的字段，给 set 对象加上 “-symbol” 参数。（遗憾的是，你不能在同一个 “set” 对象里混用 symbol 和数值。）

你可以把模板 “-” 当作通配符使用（这可能比使用特定模板名更慢）。另外，如果指定了零个或一个字段，你可以发送 “set” 消息来设置新的模板名和字段名：

入口

入口 1（可重复）

  • float/symbol：scalar 中的值

入口 2

  • pointer：指向标量的指针

出口

无记录。

参数

#类型默认值说明
1symbol—结构名称
2list—字段名称的 symbol（每个都会创建一个入口）

方法

消息说明
set <symbol, symbol>如果未给字段或只给一个字段，可以用 'set' 设置结构名和字段

选项

选项说明
-symbol这样可以设置 symbol 值
