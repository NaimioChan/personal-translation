cyclone · 信号运算

[count~]

按采样率计数

描述

[count~] 输出每经过一个采样点就增加 1 的 signal。它从给定的最小值开始，可以在给定的最大值处循环（实际上该值为最大值 - 1）。

入口

入口 1

  • bang：触发计数器并从最小值开始计数
  • float：触发计数器并从给定数字开始计数
  • list：最多 4 个 float，用于重置参数
  • signal：0 到非 0 的跳变启动计数器。非 0 到 0 停止它

入口 2

  • float：设置循环的最大值（0 表示取消最大值）

出口

出口 1

  • signal：触发时输出最小值或计数值

参数

#类型默认值说明
1float0最小值
2float0 - no loop循环的最大值
3float0指定初始为关 <0> 还是开 <1>
4float0autoreset 开 <1> 或关 <0>

方法

消息说明
stop停止计数器并重置为最小值
autoreset <1/0><1> 启用、<0> 禁用自动重置
min <float>设置最小值，不触发计数器
set <f, f>设置最小值与最大值，不触发

选项

选项说明
@autoreset <float>1（启用 autoreset）0（禁用）
