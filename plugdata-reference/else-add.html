ELSE · 数据运算

[add]

数值累加器

描述

[add] 把输入值累加到一个起始总和值（默认 0）。起始总和可以作为参数或通过 'set' 消息设置。向右入口发送 bang 可以把总和重置为起始总和值。

入口

入口 1

  • float：待累加的值
  • bang：把总和重置到起点

出口

出口 1

  • float：累加得到的值

参数

#类型默认值说明
1float0起始总和

方法

消息说明
set <float>设置起始和值
