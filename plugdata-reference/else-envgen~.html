ELSE · 包络与 LFO

[envgen~]

包络发生器

描述

[envgen~] 是一个包络（以及通用 line）发生器（这里它生成到 1 的 1000 ms line 和到 0 的 500 ms line）。

入口

入口 1

  • float/signal：门控：开/起音（非 0）或关/释音（0）
  • bang：用最后一次 gate 开启时的值启动包络
  • list：设置并运行包络（时长与目标的成对值。若为奇数，第 1 个 float 是起始点）

入口 2

  • signals：用于重新触发包络的冲量

出口

出口 1

  • signals：包络信号

出口 2

  • float：状态：1 <on>，0 <off>

参数

#类型默认值说明
1list0 0<f> — 初始输出值，<f,f,..> 设置包络

方法

消息说明
setgain <float>设置总增益
curve <list>设置每条线段的指数值
attack同 bang 或 gate on
release同 gate off
pause暂停输出
resume暂停后恢复包络
suspoint <float>设置延音点
retrigger <float>重新触发时间，单位 ms
legato <float>非 0 设为 legato 模式
loop <float>非 0 设为循环模式
samps <float>非 0 设为采样点而非 ms

选项

选项说明
-exp <list>为每一段设置带额外指数元素的函数
-init <float>默认 0
-retrigger <float>默认 0
-legato把连奏模式设为开，默认为关
-suspoint <float>默认 0
curve <float/symbol>为所有段设置曲线（默认 linear）
