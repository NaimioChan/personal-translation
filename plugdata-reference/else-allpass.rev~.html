[allpass.rev~]

全通混响器

描述

[allpass.rev~] 用作混响器、全通滤波器和延时。默认情况下，你可以设置延时时间和混响/衰减时间（单位 ms，“t60”），后者是脉冲的能量下降 60dB 所需的时间（但你可以把这个参数改为增益系数）。

入口

入口 1

  • signal：要滤波的 signal

入口 2

  • float/signal：延时时间，单位 ms

入口 3

  • float/signal：衰减时间，单位 ms

出口

出口 1

  • signal：滤波后的信号

参数

#类型默认值说明
1float0最大和初始延时时间，单位 ms
2float0衰减时间，单位 ms
3float0非 0 设为增益模式

方法

消息说明
size <float>更改最大延时大小（单位 ms）
clear清空延时缓冲区
gain <float>非 0 设为增益模式
