ELSE · 缓冲区

[susloop~]

用于采样器的延音循环器

描述

[susloop~] 生成一个控制信号，用于读取缓冲区并在给定区段循环。它响应 gate 输入（float 或 signal）。

入口

入口 1

  • float/signal：0 到非 0：开始并循环。非 0 到 0：循环关闭
  • bang：触发：从 0 开始并循环

入口 2

  • float/signal：设置增量值（速率/速度）

出口

出口 1

  • signal：采样器的控制信号

出口 2

  • float：状态（开：1 / 关：0）

参数

#类型默认值说明
1float1递增值
2float0循环开始
3float2ˆ32 - 1循环结束
4float2ˆ32 - 1采样点长度

方法

消息说明
release循环关闭
stop停止并回到 0，期待一个触发来重新开始
pause暂停/停止递增
continue暂停后继续
loop <f,f>设置延音循环范围，单位采样点 <start, end>
size <float>设置采样点大小
