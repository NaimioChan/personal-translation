cyclone · 缓冲区 · 数据管理

[funbuff]

存储整数对

描述

[funbuff] 存储、管理和调用成对的整数 x/y。

入口

入口 1

  • bang：在 Pd 主窗口中打印对象的信息
  • float：x/y 对的 x 值 - 如果之前向右入口发送过 y 值，则保存该 x/y 对，否则输出一个 y 值
  • list：两个元素：在缓冲区中存储一个 x/y 数值对

入口 2

  • float：x/y 对的 y 值

出口

出口 1

  • float：数对的 y 值

出口 2

  • float：收到 "next" 消息时，与上一个 x 值的差值

出口 3

  • bang：当到达缓冲区末尾时

参数

#类型默认值说明
1symbol—设置要在缓冲区中加载的文件名

方法

消息说明
set <list>设置缓冲区中的 x/y 对（允许多于一对）
clear从缓冲区擦除所有对
select <f, f>从索引（由第 1 个 float 指定）开始选取若干 x/y 对（由第 2 个 float 指定）——用于复制/剪切/粘贴
copy将选中的 x/y 对复制到剪贴板
cut将选中的 x/y 对复制到剪贴板并删除它
paste添加剪切或复制的 x/y 对
undo撤销最近一次剪切或粘贴操作
delete <f, f>给一个 float 时删除与该 'x' 值匹配的对，给两个 float 时删除匹配的 x/y 对
dump将所有对输出到中间出口（y 值）和左出口（x 值）
embed <float>非 0 值在保存 patch 时保存缓冲区内容
goto <float>把缓冲区指针设为指定的 <float> 缓冲区元素
next输出缓冲区元素的 y 值并转到下一个指针
find <float>查找 'y' 与给定数值匹配的 'x' 值
interp <float>如果给定的 'x' 不存在，则从相邻的 2 个 x/y 对插值出 'y' 值
interptab <f, s>同 interp，但使用 symbol <s> 指定的表格
min向左出口发送缓冲区中最低的 'y' 值
max向左出口发送缓冲区中最高的 'y' 值
print在 Pd 主窗口打印状态信息
read <symbol>从 symbol 指定的文件名读取缓冲区内容。如果未给出 symbol，则显示文件打开框
write <symbol>把缓冲区内容写入 symbol 指定的文件名。如果没有给出 symbol，则显示打开文件框
