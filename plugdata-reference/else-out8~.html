ELSE · 音频输入输出

[out8~]

八声道输出

描述

[out8~] 是一个便捷的八声道输入/输出抽象。它具有静音、DSP 开关、斜坡时间、最大增益和缩放模式的控制。注意，你需要在 preferences => audio 中指定至少 8 个输出通道。

入口

入口 1

  • signal：传入信号（路由到 [dac~ 1]）

入口 2

  • signal：传入信号（路由到 [dac~ 2]）

入口 3

  • signal：传入信号（路由到 [dac~ 3]）

入口 4

  • signal：传入信号（路由到 [dac~ 4]）

入口 5

  • signal：传入信号（路由到 [dac~ 5]）

入口 6

  • signal：传入信号（路由到 [dac~ 6]）

入口 7

  • signal：传入信号（路由到 [dac~ 7]）

入口 8

  • signal：传入信号（路由到 [dac~ 8]）

出口

无记录。

参数

#类型默认值说明
1float1最大增益（需 > 0）
2float0缩放模式：0（四次方）、1（dB）或 2（线性）

方法

消息说明
set <float>设置滑块（范围被裁剪到 0-1）
<on/off>把 DSP Engine（Compute Audio）设为 On 或 Off
mode <float>缩放模式：0（四次方，默认）、1（dB）或 2（线性）
mute静音/取消静音按钮
gain <float>设置最大增益（<= 0 的值被忽略）
ramp <float>设置滑块值的斜坡时间，单位 ms（默认：20）
