[colors]

选取/转换颜色

描述

[colors] 是取色器和颜色转换器。你可以设置输出格式，也可以从其他输入格式转换。你选取的颜色和发送给该对象的颜色会被存储，并在下次打开取色器时调出。该对象适合在抽象对象内部设置颜色属性。

入口

入口 1

  • bang：输出/转换颜色

出口

出口 1

  • anything：颜色值（用 RGB、hex、iemgui 或 ds）

方法

消息说明
pick打开取色器
rgb <f, f, f>RGB（红、绿、蓝）颜色值
hex <symbol>十六进制颜色值
iemgui <float>iemgui 的颜色格式值
ds <float>Data Structures 的颜色值
cmyk <f, f, f, f>CMYK（Cyan、Magenta、Yellow 和 Key）颜色值
hsl <f, f, f>HSL（Hue、Saturation 和 Lightness）颜色值
hsv <f, f, f>HSV（Hue、Saturation 和 Value）颜色值
gray <float>灰度值，从 0 到 100
to <symbol>把转换设为 "rgb"、"hex"、"gui" 或 "ds"

选项

选项说明
-rgb设为 RGB 列表输出
默认：hexadecimal
-iemgui设为 iemguis 输出
默认：hexadecimal
-ds设为 Data Structures 输出
默认：hexadecimal
