Gem · 图形

[pix_set]

设置图像的像素数据

入口

入口 1

  • gemlist
  • bang：发送图像（例如用于更新纹理）

入口 2

  • list：交错图像数据（R1 G1 B1 A1 R2 B2...）或（R1 B1 G1 R2 B2...）或（L1 L2 L3...）

出口

出口 1

  • gemlist

参数

#类型默认值说明
1float—宽度
2float—高度

方法

消息说明
RGB设置颜色空间
RGBA设置颜色空间
GREY设置颜色空间
fill <list>用 value 设置整幅图像（value 可以是 G、RGB 或 RGBA）
set <float> <float>设置图像的大小
