ELSE · 信号发生器

[fbsine2~]

带混沌相位索引的反馈正弦

描述

[fbsine2~] 是一个基于下列差分方程的非插值声音发生器（当 im = 1、fb = 0 且 a = 1 时，结果为正弦波）；
x(n+1) = sin(im * y(n) + fb * x(n));
y(n+1) = (a * y(n) + c) % 2pi

入口

入口 1

  • float/signal：频率，单位 Hz（接受负值）
  • list：2 个 float 分别设置 x[n-1] 和 y[n-1]

出口

出口 1

  • signal：反馈正弦混沌信号

参数

#类型默认值说明
1floatNyquist设置频率，单位 Hz
2float1设置 'im'
3float0.1设置 'fb'
4float1.1设置 'a'
5float0.5设置 'c'
6float0.1设置 x[n] 的初始值
7float0.1设置 y[n] 的初始相位值

方法

消息说明
coeffs <f, f, f, f>分别设置 'im'、'fb'、'a' 与 'c' 的值
clear清空 x[n-1] 和 y[n-1] 的值
