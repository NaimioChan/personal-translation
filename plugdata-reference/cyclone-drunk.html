cyclone · 随机与噪声

[drunk]

随机醉步

描述

[drunk] 从当前数值出发，在给定的步长范围内生成随机数（生成 "drunk walk"）。随机数从 0 到给定的最大值，且与前一个数相差一个小于给定步长的随机值。

入口

入口 1

  • bang：触发一次随机输出
  • float：设置新的当前值并输出
  • list：若干 float 按此顺序设置 <value, maximum, step size>

入口 2

  • float：设置上界

入口 3

  • float：设置步长

出口

出口 1

  • float：drunken walk 结果输出的随机数

参数

#类型默认值说明
1float128设置最大值
2float2设置最大步长

方法

消息说明
seed <float>设置内部随机数发生器的随机种子
set <float>设置当前值（不输出）
