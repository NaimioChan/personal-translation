ELSE · 效果器 · 缓冲区

[del~ in]

延时线输入

描述

定义一条延时线并写入其中。如果第一个参数既没有指定 "in" 也没有指定 "out"，默认就是 [del~ in]。

入口

入口 1

  • signal：输入到延时线的 signal

出口

出口 1

  • signal：用于强制执行顺序的哑出口

参数

#类型默认值说明
1symbolinternal name relative to patch设置延时线名称
2float1 sample延时大小，单位 ms 或采样点

方法

消息说明
clear清空延时线
size <float>更改延时大小
freeze <float>非 0 冻结，为零则解冻

选项

选项说明
-samps把时间值设为 samples
默认：ms
