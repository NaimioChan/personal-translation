ELSE · 界面

[pic]

载入图片

描述

[pic] 加载可以交互的图片。它只支持文件类型：.gif、.ppm 和 .pgm。你点击图片，它发送 bang（默认），或者在点击时发送 1、释放时发送 0（在 latch 模式下）。

入口

入口 1

  • open <symbol>：打开由 symbol 命名的图像文件

出口

出口 1

  • bang：点击图像时输出 bang
  • float：处于 latch 模式时为 1/0
  • list：报告尺寸模式下的图片宽度/高度

方法

消息说明
open <symbol>打开由 symbol 命名的图像文件
set <symbol>同 open，但 pd 不询问是否保存更改
latch <float>非 0 设为锁存模式
outline <float>非 0 设为轮廓模式
size <float>非 0 设为报告长度模式
send <symbol>设置 send symbol
receive <symbol>设置 receive symbol

选项

选项说明
-open <symbol>设置要打开的文件名
默认：empty
-send <symbol>设置发送 symbol
默认：empty
-receive <symbol>设置接收 symbol
默认：empty
-outline设为轮廓模式
默认：no outline
-size设为 "report size" 模式
默认：no report
-latch设为 "latch" 模式
默认："bang" 模式
