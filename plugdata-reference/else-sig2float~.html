[sig2float~]

转换后的 float

别名：s2f~

描述

[sig2float~] 把信号转换为 float。转换按第 1 个参数或右入口定义的时间速率进行。

入口

入口 1

  • signal：要转换为 float 的 signal 值
  • bang：同步转换率

入口 2

  • float：转换时间，单位 ms

出口

出口 1

  • float：转换后的 float

参数

#类型默认值说明
1float0自时钟间隔，单位 ms
2float0块内的采样点偏移量

方法

消息说明
set <float>设置时间，不进行同步
float打开（非 0）或关闭（0）
start打开
stop关闭
offset <float>设置块内的采样点偏移量

选项

选项说明
-off将其关闭
默认：on
