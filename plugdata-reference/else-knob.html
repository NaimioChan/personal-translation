ELSE · 界面

[knob]

旋钮 GUI

入口

入口 1

  • float：设置并输出值
  • bang：输出值

出口

出口 1

  • float：旋钮的值

方法

消息说明
set <float>设置值（不输出）
load <float>设置 load 值，无 float 则设置当前值
size <float>设置大小，单位像素
arcstart <float>设置弧起始值，无 float 则设为当前值
arc <float>非零设置为弧线绘制模式
square <float>非零设为方波绘制模式
bgcolor <list>用十六进制或 RGB list 设置背景颜色
fgcolor <list>用十六进制或 RGB 列表设置前景色
circular <float>非零设置为圆形拖动模式
angle <float>设置角度范围值，单位度
offset <float>设置角度偏移，单位度
send <symbol>设置 send symbol
receive <symbol>设置 receive symbol
exp <float>设置指数值
ticks <float>设置 tick 数量
discrete <float>非零设置为离散模式
jump <float>非零设置为点击即跳转模式
readonly <float>设置只读模式
number <float>设置数字模式
savestate <float>保存当前状态
lb <float>设置 loadbang 模式
numbersize <float>设置所显示数字的大小
numberpos <float, float>设置所显示数字的位置
active <float>激活或停用旋钮
reset将旋钮重置为其默认状态
param <symbol>设置旋钮的参数
var <symbol>为旋钮分配一个变量
arccolor <list>设置旋钮的弧形颜色

选项

选项说明
-set <float>设置值（不输出）
-load <float>设置载入值，没有 float 则设置当前值
默认：0
-size <float>设置大小，单位像素
默认：50
-arc <float>非零设为弧线绘制模式
默认：1
-nosquare <float>不绘制方形
默认：0
-nooutline <float>不绘制轮廓
默认：0
-bgcolor <list>设置背景颜色，用十六进制或 RGB 列表
默认：#dfdfdf
-fgcolor <list>设置前景色，用十六进制或 RGB 列表
默认：#000000
-circular <float>非零设为圆形拖动模式
默认：0
-angle <float>设置角度范围值，单位度
默认：320
-offset <float>设置角度偏移，单位度
默认：0
-send <symbol>设置发送 symbol
默认：empty
-receive <symbol>设置接收 symbol
默认：empty
-exp <float>设置指数值
默认：1
-ticks <float>设置刻度数
默认：0
-discrete <float>非零设为离散模式
默认：0
-jump <float>非零设为点击即跳跃模式
默认：0
