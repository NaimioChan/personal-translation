[rand.dist]

随机分布

描述

[rand.dist] 是基于 [array quantile] 的抽象对象，生成遵循概率密度函数（由数组给出）的随机数。float 输入（例如来自外部随机源）则改为输出 array quantile。第一个参数是包含概率密度函数的表格名。输出范围默认为 0 到 127，但可以用第 2、3 个参数或第 2、3 个入口修改。输出分辨率是范围除以表格最大索引（下例中为 127，因此 0-127 范围输出整数）。

入口

入口 1

  • bang：生成随机输出
  • float：范围 0-127）获取分位数

入口 2

  • float：最小随机值

入口 3

  • float：随机值的最大值

出口

出口 1

  • float：随机值

参数

#类型默认值说明
1symbolnone设置表格名称
2float0设置最小输出
3float127设置最大输出

方法

消息说明
seed <float>float 设置随机种子，无 float 则设置唯一的内部种子
set <symbol>设置数组名

选项

选项说明
-seed <float>随机种子值
