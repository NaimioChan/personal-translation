ELSE · 包络与 LFO

[asr~]

attack/sustain/release 门控包络

描述

[asr~] 是一个起音/保持/释放门控包络。门开启时（从 0 变为任意值），[asr~] 按指定的起音时间（单位 ms）从 0 到达门值。门关闭时（从任意值变为 0），[asr~] 按指定的释放时间（单位 ms）到达 0。

入口

入口 1

  • signals：门控值
  • float：MIDI 力度范围内的门控值（0-127 对应 0-1）
  • bang：以控制速率触发（类似 impulse）

入口 2

  • float/signal：起音时间，单位 ms

入口 3

  • float/signal：衰减时间，单位 ms

入口 4

  • float/signal：延音振幅（与 gate 值之比）

出口

出口 1

  • signals：包络信号

出口 2

  • float：包络状态（开=1 / 关=0）

参数

#类型默认值说明
1float10起音时间，单位 ms
2float10释放时间，单位 ms
3float1曲线参数

方法

消息说明
curve <float>设置对数曲线参数
lin设置为线性模式
lag设为滞后滤波模式
rel <float>非零设为立即释放模式
gate <float>控制 gate 值

选项

选项说明
-curve <float>设置曲线参数
默认：1
-lin设为 linear 模式
默认：log
-lag设为滞后滤波模式
-rel设为立即释放模式
