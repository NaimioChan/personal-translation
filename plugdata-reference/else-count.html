ELSE · 数据运算

[count]

一个计数器

描述

[count] 在最小值和最大值之间计数并回绕。它有向上计数、向下计数和两者交替的模式。

入口

入口 1

  • bang：计数
  • float：设置新的计数值并输出

入口 2

  • list：更新参数

出口

出口 1

  • float：计数值

出口 2

  • bang：达到计数限制时输出 bang

参数

#类型默认值说明
1list—1 个 float 设置最大值 / 2 个 float 设置最小值和最大值

方法

消息说明
set <float>设置新的计数值
reset <float>不带 float 时重置到重置点，带 float 时同时设置新的重置点
max <float>设置最大值
min <float>设置最小值
up设置计数方向向上
down设置计数方向向下
alt <float>非 0 设为交替模式（在向上/向下之间）

选项

选项说明
-alt设为交替模式
reset <float>设置起始与重置值
