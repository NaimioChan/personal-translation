ELSE · 数据管理

[pack2]

合并原子

描述

[pack2] 与 Pd Vanilla 的 [pack] 有点像，但任意入口都会触发输出（不过 "set" 消息会避免输出）。它还可以初始化 symbol 值，并且不会为你创建 list 选择器。此外，你可以用 list 消息更改多个元素，初始化为 float 的元素可以变成 symbol，反之亦然。

入口

入口 1

  • bang：输出存储的元素列表
  • float/symbol：要设置到槽位 0 并输出的 float 或 symbol
  • set <anything>：要设置到槽位 0 的 float 或 symbol

入口 2（可重复）

  • float/symbol：要设置到槽位 $nth 并输出的 float 或 symbol
  • set <anything>：要设置到槽位 $nth 的 float 或 symbol

出口

出口 1

  • list：由给定元素组成的消息

参数

#类型默认值说明
1anythingtwo floats set to '0'元素数量 = 入口数量。<f> 或 <symbol> — 初始值
