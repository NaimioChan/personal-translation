ELSE · 数组与表格

[tabgen]

表格发生器

描述

[tabgen] 是一个抽象对象，为给定的表格名称生成不同的函数。

入口

入口 1

  • anything：用于生成函数的命令（详见 [pd examples]）

出口

无记录。

参数

#类型默认值说明
1float—（可选）在初始化时设置数组大小
2symbolnone设置表格名称
3anythingnone用于生成函数的命令

方法

消息说明
size <float>调整表格大小（需要重新生成表格）
set <symbol>设置表格名称
clear清空表格

选项

选项说明
-ms把表格长度设为 ms
默认：points
