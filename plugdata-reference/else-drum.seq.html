[drum.seq]

鼓序列样式 GUI

描述

[drum.seq] 提供一个鼓网格，让你可以激活格子来表示击打。

入口

入口 1

  • bang：取得序列值并移动到下一个
  • list：设置轨道、槽位和状态（无输出）
  • float：设置槽位值并输出轨道值

出口

出口 1

  • list：轨道与槽位值（从 1 开始索引）
  • bang：当到达序列的末尾时

方法

消息说明
track <list>设置轨道值（第 1 个值设置轨道编号）
goto <float>设置槽值
clear清空激活的单元格（无输出）
export <float>导出轨道，不给 float 则以数组导出全部
import <list>以数组导入内容
tracks <float>设置轨道数量（清空数据）
slots <float>设置槽数量（清空数据）
size <float>设置单元格大小，单位 px（清空数据）
embed <float>非 0 将内部内容随对象一同保存
export <list>通过 "export" 消息得到的上下文数组

选项

选项说明
-tracks <float>设置轨道
默认：2
-slots <float>设置槽位数量
默认：8
-size <float>设置单元格大小，单位像素
默认：20
-embed设置嵌入模式
默认：no embedding
