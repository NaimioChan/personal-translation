[autofade2~]

自动淡入/淡出

描述

[autofade2~] 是用于多通道输入的自动淡入/淡出（淡入/淡出各自有独立时间）。它响应门控制，并使用内部查找表提供 7 种不同的淡变曲线。当上一个输入值为 0 而新到达的值不是时，发生门开启。当上一个值为非 0 值而新到达的值为 0 时，发生门关闭。最大增益取决于门开启电平。

入口

入口 1

  • signal：待淡入/淡出的输入信号
  • anything：淡化类型 <quartic, sin, sqrt, hann, lin, hannsin, linsin>

入口 2（可重复）

  • signal：待淡入/淡出的输入信号

入口 3

  • float/signal：门控；!= 0 时「淡入」，否则「淡出」

出口

出口 1（可重复）

  • signal：自动淡化后的 signal

出口 2

  • float：淡入/淡出完成时发送 1 或 0

参数

#类型默认值说明
1symbolquartic（可选）淡入淡出类型 <quartic, sin, sqrt, lin, hann, lin, hannsin, linsin>
2float0淡入时间，单位 ms
3float0淡出时间，单位 ms
4float1通道数

方法

消息说明
fadein <float>淡入时间，单位 ms
fadeout <float>淡出时间，单位 ms
