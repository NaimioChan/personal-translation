[comment]

注释 GUI

描述

[comment] 是一个仅作为注释（标签或说明）的 GUI，在编辑模式下可以直接在其中输入文字。它被广泛用于 cyclone 的文档中，并且（不同于 pd vanilla 的注释）允许你设置字体、大小、颜色、背景颜色、粗体、斜体、下划线和对齐方式。该对象并不完全兼容 Max6+ 版本！它现在也与 [else/note] 相关。

入口

入口 1

  • set <anything>：设置注释

出口

无记录。

方法

消息说明
set <anything>设置注释
append <anything>向注释追加一条消息
prepend <anything>向注释前添加一条消息
fontsize <float>设置字体大小
fontname <symbol>设置字体类型
bold <float>非 0 设为粗体
italic <float>非 0 设为斜体
outline <float>非 0 设置轮廓
underline <float>非 0 设置下划线
textjustification <f>设置对齐方式（0：左，1：居中，2：右）
textcolor <f, f, f>设置 RGB 文字颜色（值从 0 到 255）
bgcolor <f, f, f>设置 RGB 背景颜色（值从 0 到 255）
bg <float>背景选项（0 抑制背景）
receive <symbol>设置 receive symbol

选项

选项说明
@fontname <symbol>默认 'dejavu sans mono'，Mac 上为 'menlo'
@fontface <float>默认 0
@fontsize <float>默认同 patch
@textjustification <float>默认 0
@textcolor <f, f, f>默认 0 0 0
@bgcolor <f, f, f>默认 255 255 255
@bg <float>默认 0
@text <anything>设置注释
默认："comment
@underline <float>默认 0
@bold <float>默认 0
@italic <float>默认 0
@receive <symbol>默认 'empty'
