vanilla · 数据管理

[text-set]

替换或添加一行

入口

入口 1

  • list：要添加或替换的消息

入口 2

  • float：要替换或添加的消息编号（如果大于消息数量）

入口 3

  • float：开始替换的元素编号，若为负数则替换整条消息

入口 4

  • symbol：设置文本名称
  • pointer：使用 -s 选项时为指向文本的指针

出口

无记录。

参数

#类型默认值说明
1symbolnone未给出选项时的文本名称
2float0设置消息编号
3float-1设置元素编号

选项

选项说明
-s <symbol, symbol>主结构的 struct 名称和字段名
