vanilla · 音频输入输出

[output~]

简单的立体声输出 GUI 抽象对象

描述

这是一个非常简单的抽象对象，在 Pd 的文档（帮助文件和示例）中被广泛使用。这里收录它只是为了方便。

Output~ 接收立体声信号，并有 GUI 控件用于设置音量增益和静音。数字框以 dB 设置输出增益（从 0 到 100），每当你点击它拖动时，DSP 引擎就会被打开。静音 bang 关闭音量（设为 0），但当你再次点击它取消静音时会恢复到上次的设置。

左入口也接收 bang 消息用于静音/取消静音，以及 'level' 消息用于以 dB 控制电平输出。

入口

入口 1

  • signal：左侧信号输入
  • bang：静音/取消静音

入口 2

  • signal：右信号输入

出口

无记录。

方法

消息说明
level <float>设置输出电平
