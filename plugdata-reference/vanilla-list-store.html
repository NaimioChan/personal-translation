vanilla · 数据管理

[list-store]

操作列表

描述

把列表与子列表合成或拆分

入口

入口 1

  • list：把传入列表与已存储列表连接并输出（bang 是零元素列表，会输出已存储列表）

入口 2

  • anything：设置存储的列表（bang 是零元素列表，并清空它）

出口

出口 1

  • list：bang 时输出存储的列表，list 输入时输出拼接后的列表，或通过 'get' 消息输出子列表

出口 2

  • bang：当 get 消息失败时

参数

#类型默认值说明
1listempty初始化存储的列表

方法

消息说明
prepend <list>向存储的列表前添加一个列表
append <list>向已存储的 list 追加一个 list
get <list>输出一个元素（如果只给出一个 float）或子列表，其中第一个元素设置起始索引，第二个设置结束索引（-1 为列表末尾）
set <list>从第一个元素起，从索引开始设置值
insert <list>从第一个元素给出的索引之前插入值
delete <list>只给一个 float 时删除指定的一项，或按第二个元素指定的数量从第一个元素给出的索引处开始删除（-1 表示从给定索引删除所有项）
send <symbol>向具名接收方发送存储的 list
