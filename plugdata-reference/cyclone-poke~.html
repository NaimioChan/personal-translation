cyclone · 数组与表格

[poke~]

写入数组

描述

[poke~] 把信号写入数组，索引由信号指定。

入口

入口 1

  • float/signal：要写入数组的值
  • list <f, f, f>：<value>、<index> 和 <channel>

入口 2

  • float/signal：要记录到的索引

入口 3

  • float：设置所记录值所属的通道

出口

无记录。

参数

#类型默认值说明
1symbol—要写入的数组名
2float1通道（1-64）

方法

消息说明
set <symbol>设置数组名称
