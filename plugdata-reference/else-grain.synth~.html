[grain.synth~]

粒度合成

描述

[grain.synth~] 是基于波形的粒度合成器，生成成云的有音高颗粒。

入口

入口 1

  • bang：播放 <dur> 时长的 pitched clouds

入口 2

  • float：密度（颗粒数）

出口

出口 1

  • signal：左通道输出

出口 2

  • signal：右通道输出

方法

消息说明
n <float>事件云中颗粒的数量（默认 16，最小 1，最大 256）
set <symbol>设置表格名称与波形
sync <f>非 0 设为同步模式（默认 0）
dur <f>设置 cloud 事件时长，单位 ms（默认 500）
size <f, f>设置最小/最大颗粒大小，单位 ms（默认：50 到 450）
pitch <f, f>设置最小/最大音高值（MIDI，默认：30 到 90）
pan <f, f>设置左右声像边界（默认：-1 到 1）
amp <f, f>最小/最大振幅值（默认 0.1 到 1）
env <any>包络类型（sin、hann、tri、gauss）或函数列表
autotune <f>非 0 自动调音到给定音阶（默认 0）
scale <list>自动调音到的音分刻度（默认平均律）
base <f>设置音阶的基准 MIDI 音高（默认：60）

选项

选项说明
-n <float>
-t <symbol>表格名称
-dur <f>
-size <f, f>
-pitch <f, f>
-pan <f, f>
-amps <f, f>
-autotune <f>
-scale <list>
-base <f>
-env <any>
-sync
