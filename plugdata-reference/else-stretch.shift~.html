[stretch.shift~]

变调时间伸缩

描述

[stretch.shift~] 类似 [gran.player~]，但用于实时输入。它通过颗粒化提供独立的时间拉伸和音高变换。

入口

入口 1

  • signal：音频 signal 输入
  • bang：重置到延时线开头

入口 2

  • float：设置颗粒大小

入口 3

  • float：设置速度

入口 4

  • float：设置移调，单位音分

出口

出口 1

  • signal：对应通道的缓冲区信号

参数

#类型默认值说明
1float5000设置缓冲区大小，单位 ms
2float100设置播放速度
3float0设置移调，单位音分
4float25设置颗粒大小，单位 ms

方法

消息说明
size <float>设置缓冲区大小，单位 ms
