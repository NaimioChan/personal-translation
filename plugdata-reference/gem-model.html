Gem · 图形

[model]

渲染 Alias/Wavefront 模型

入口

入口 1

  • gemlist

出口

出口 1

  • gemlist

参数

#类型默认值说明
1<symbol>—要加载的 OBJ 文件名

方法

消息说明
open <symbol>加载 obj 文件
rescale <float>归一化模型（必须在打开模型之前设置）
material<float>使用材质信息（来自 mtl 文件）
group <float>仅绘制模型的指定部分（0 == 所有组）
revert <float>反转面
smooth <float>设置平滑系数（0.0 == flat，1.0 == smooth）
texture <float>0 == 线性纹理，1 == 球面映射，2 == UV 映射
loader <symbol>选择首先使用哪个后端来打开模型
