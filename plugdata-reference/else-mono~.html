[mono~]

单音信号声部管理器

描述

[mono~] 模拟单音合成器行为，与 [mono] 十分相似，但还可以用 portamento 设置让音高输出滑音。

入口

入口 1

  • list：MIDI 音符对（音符和力度）
  • float：MIDI 音符

入口 2

  • float：MIDI 力度

出口

出口 1

  • signal：MIDI 音高值

出口 2

  • signal：力度值，归一化为 0-1

出口 3

  • signal：用于重新触发包络的冲量

参数

#类型默认值说明
1float0滑音时间，单位 ms
2float0非 0 设为 legato 模式

方法

消息说明
glide <float>设置滑音时间，单位 ms
mode <float>设置优先级模式，0=last，1=high，2=low
legato <float>非零设置为连奏模式，0 恢复默认
flush为挂起的音符发送 note off 并清空记忆
clear清空记忆且不输出

选项

选项说明
-last选择最后音
-high选择最高音
-low选择最低音
