[mtx.ctl]

矩阵控制 GUI

描述

[mtx.ctl] 提供用户矩阵界面控件。网格中的格子可以是开或关。输出是一个包含 3 个 float 的 list，分别指定：列、行和状态。

入口

入口 1

  • list：设置并输出列、行和状态

出口

出口 1

  • list：列、行、状态

方法

消息说明
set <list>设置列、行和状态（无输出）
get <list>输出行/列的值
clear清空激活的单元格
flush冲刷激活单元格的值
export将内容导出为数组
import以数组导入内容
rows <float>设置行数
columns <float>设置列数
size <float>设置单元格大小，单位 px
embed <float>非 0 将内部内容随对象一同保存

选项

选项说明
-n <f, f>列数与行数
-size <float>单元格大小，单位像素
-embedembed 选项
