[seq]

MIDI 音序器

描述

[seq] 播放/录制原始 MIDI 流，并可保存/读取 MIDI 序列文件。多轨 MIDI 文件的所有轨道会被合并为一条。

入口

入口 1

  • bang：以正常速度开始或重新开始播放序列
  • float：要录制的原始 MIDI 数据流

出口

出口 1

  • float：来自所播放序列的原始 MIDI 数据流

出口 2

  • bang：在序列结束时发送（对循环有用）

参数

#类型默认值说明
1symbol—待加载的 MIDI/文本文件

方法

消息说明
read <symbol>从 MIDI/文本文件读取（无 symbol 则打开对话框）
start <float>以给定的速度开始/重启序列
stop停止录制/播放并回到开头
record开始录制
append在存储序列的末尾录制
clear清空已存储的序列
tick每次 tick 发送 bang
write <symbol>保存为 MIDI/文本文件
delay <float>第一个事件的起音时间，单位 ms
addeventdelay <float>为起音延时增加值（单位 ms）
hook <float>把所有事件时间乘以给定的数
print在 Pd 窗口打印序列的前 16 个事件
pause暂停播放
continue继续播放
