ELSE · 包络与 LFO

[lfo]

控制 LFO

描述

[lfo] 是控制速率的 LFO，带一些常用波形。它不需要开启 DSP 就能工作，

入口

入口 1

  • float：频率，单位 Hz，最大 100（接受负值）
  • anything：设置波形（sine、tri、saw、vsaw 和 square）

入口 2

  • float：从 0 - 1 的相位重置

入口 3

  • float：刷新率，单位 ms（最小为 5 ms）

出口

出口 1

  • float：LFO 的波形，范围 0 - 127

参数

#类型默认值说明
1float0设置频率，单位 Hz（默认 0）
2float0设置初始相位，从 0 - 1（默认 0）
3float5设置刷新率，单位 ms（默认 5）

选项

选项说明
-sine把波形设为正弦波（默认）
-tri把波形设为三角波
-saw把波形设为锯齿波
-square <float>把波形设为方波并设置宽度（从 0 到 1）
-vsaw <float>把波形设为可变锯齿波并设置宽度（从 -1 到 1）
