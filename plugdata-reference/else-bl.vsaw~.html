ELSE · 信号发生器

[bl.vsaw~]

带限锯齿-三角波振荡器

描述

[bl.vsaw~] 是可变锯齿波振荡器，也能像 [else/vsaw~] 一样变成三角波振荡器，但它是带限的。

入口

入口 1

  • list/signals：频率，单位 Hz

入口 2

  • float/signal：脉冲宽度（从 0 到 1）

入口 3

  • float/signal：相位同步（重置内部相位）

入口 4

  • float/signal：相位偏移（调制输入）

出口

出口 1

  • signals：可变的锯齿-三角波信号

参数

#类型默认值说明
1float0频率，单位 Hz
2float0初始宽度
3float0初始相位偏移量

方法

消息说明
midi <float>非 0 将频率输入设为 MIDI 音高
soft <float>非 0 设为软同步模式
set <float, float><channel, freq> 设置单个频率通道

选项

选项说明
-midi把频率输入设为 MIDI 音高
默认：Hz
-soft设为软同步模式
默认：hard
-mc <list>用频率列表设置多通道输出
