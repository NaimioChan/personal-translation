ELSE · MIDI

[sfz~]

混合采样播放器

描述

[sfz~] 基于 "sfizz"，是一个用于演奏 SFZ 格式音色乐器的合成器。有关 SFZ 格式、播放器和可下载乐器的更多细节，见 https://sfzformat.com/

入口

入口 1

  • float：原始 MIDI 输入
  • list：键位，力度

出口

出口 1

  • signal：左输出

出口 2

  • signal：右输出

参数

#类型默认值说明
1symbolnone设置要加载的文件

方法

消息说明
open <float>加载 soundfont 文件（隐含 .sfz 扩展名）
note键位，力度
ctl <float>控制变化：值、控制号
bend <float>弯音值
touch <float>触后值
polytouch <f, f>polytouch 值：值，键
flush为所有音符发送 note off
panic立即停止所有声音
scale <list>重调音用的音分刻度（未给出 list 时为 12 平均律）
base <float>音阶的基础 MIDI 音高
scala <symbol>打开 scala 调律文件
a4 <float>设置 A4 的频率，单位 Hz
transp <float>移调：音分，通道（可选）
