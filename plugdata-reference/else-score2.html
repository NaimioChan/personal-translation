[score2]

乐谱音序器变体

描述

[score2] 是 [score] 的一个变体，其节奏记谱语法与 [pattern] 相同。

入口

入口 1

  • start：启动序列
  • stop：停止序列
  • float：非 0 启动，0 停止序列

出口

出口 1

  • anything：事件数据

出口 2

  • float：事件时长，单位 ms

出口 3

  • anything：乐谱数据（小节号、速度以及由用户填写的其他内容）

出口 4

  • bang：当序列结束时

参数

#类型默认值说明
1symbolnone click: clicking on the object opens data/edit window (same as 'open')要加载的乐谱文件

方法

消息说明
pause暂停播放
continue继续播放
show打开编辑窗口
hind关闭编辑窗口
open <symbol>从文件导入乐谱，不给 symbol 则打开对话框窗口
save <symbol>把乐谱写入文件，没有 symbol 则打开对话框窗口
