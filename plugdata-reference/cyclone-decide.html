cyclone · 随机与噪声

[decide]

随机输出 0 或 1

描述

[decide] 在 1 与 0 之间随机交替（序列取决于随机种子值）。

入口

入口 1

  • bang：在 0 或 1 之间随机选择
  • float：同 bang

入口 2

  • float：设置随机数生成器的随机种子。0 将使用随机种子，其他任意整数 float 即为种子

出口

出口 1

  • float：0 或 1，随机选择

参数

#类型默认值说明
1floata random internal one设置随机种子
