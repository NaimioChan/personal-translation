[scope3d~]

3D 示波器显示

描述

[scope3d~] 以 3D 显示信号。这是一个用 Lua 编写的对象，非常非常实验性，很可能会变化和出问题。

入口

入口 1

  • signal：要在 X 轴显示的 signal
  • list：一个 float 同时设置 'nsamples' 和 'nlines'

入口 2

  • signal：要在 Y 轴显示的 signal

入口 3

  • signal：要在 Z 轴显示的 signal

出口

无记录。

方法

消息说明
nsamples <float>设置每行的采样点数（2-8192，默认：256）
nlines <float>设置缓冲区中的行数（8-256，默认：128）
dim <f, f>设置宽度/高度（默认：200 100）
fgcolor <f, f, f>设置 front/signal 的 RGB 颜色（值 0-255）
bgcolor <f, f, f>设置背景 RGB 颜色（值 0-255）
gridcolor <f, f, f>设置网格 RGB 颜色（值 0-255）
zoom <float>设置缩放级别
perspective <float>设置透视程度
rotate <f, f>绕 x/y 轴旋转，单位度
rotatex <float>绕 x 轴旋转，单位度
rotatey <float>绕 y 轴旋转，单位度
receive <symbol>接收 symbol（默认为空）
drag <float>启用/禁用鼠标交互
grid <float>启用/禁用网格显示
rate <float>设置刷新周期，单位 ms
width <float>设置线宽

选项

选项说明
-nsamples <float>设置每行的采样点数（2-8192，默认 256）
默认：8
-nlines <float>设置缓冲区中的行数（8-256，默认 128）
默认：256
-dim <f, f>设置宽度/高度（默认 200 100）
默认：140 140
-fgcolor <f, f, f>设置 front/signal 的 RGB 颜色（值 0-255）
-bgcolor <f, f, f>设置背景 RGB 颜色（值 0-255）
-gridcolor <f, f, f>设置网格 RGB 颜色（值 0-255）
-zoom <float>设置缩放级别
默认：1
-perspective <float>设置透视级别
默认：1
-rotate <f, f>绕 x/y 轴旋转，单位度
-rotatex <float>绕 x 轴旋转，单位度
-rotatey <float>绕 y 轴旋转，单位度
-drag <float>启用/禁用鼠标交互
默认：1
-grid <float>启用/禁用网格可视化
默认：1
-rate <float>设置刷新周期，单位 ms
默认：50
-width <float>设置线宽
默认：1
