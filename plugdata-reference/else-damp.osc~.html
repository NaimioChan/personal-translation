ELSE · 信号发生器

[damp.osc~]

阻尼简谐运动振荡器

描述

[damp.osc~] 基于一个复极点谐振滤波器（[vcf2~]），有两个出口（实部/余弦与虚部/正弦）。它接收以 Hz 或 midi 表示的频率和以 ms 表示的衰减时间。它由 0 到非 0 跳变的信号触发，或由控制率的列表触发。

入口

入口 1

  • float/signal：频率，单位 Hz
  • list：频率与触发值（归一化到 MIDI 范围）

入口 2

  • float/signal：触发，决定最大振幅

入口 3

  • float/signal：衰减时间，单位 ms

出口

出口 1

  • signal：初始相位为余弦的阻尼振荡器

出口 2

  • signal：初始相位为正弦的阻尼振荡器

参数

#类型默认值说明
1float0频率，单位 Hz
2float0衰减时间，单位 ms

方法

消息说明
midi <float>设为 MIDI 音高频率输入

选项

选项说明
-midi设为 MIDI 音高频率输入
