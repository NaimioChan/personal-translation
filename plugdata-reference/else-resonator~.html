ELSE · 滤波器

[resonator~]

谐振复单极点滤波器

描述

[resonator~] 与 [resonant~] 一样，只是谐振参数以 't60' 的谐振时间定义。它有 3 种模式，默认是 bandpass（类似 [resonant~]），另外还有 lowpass（类似 [lowpass~]）和 highpass（你猜对了，类似 [highpass~]）。注意 t60 值为 0 会旁路输入！[resonator~] 对象组成的谐振器组见 [resonbank~]。另一个类似的滤波器见 [resonator2~]。

入口

入口 1

  • float/signal：中心频率，单位 Hz

入口 2

  • signal：激励信号

入口 3

  • float/signal：t60 衰减时间，单位 ms（共振）

出口

出口 1

  • signal：谐振器/滤波后信号

参数

#类型默认值说明
1float0频率
2float0t60 衰减时间，单位 ms

方法

消息说明
clear清空滤波器的记忆
lop设为低通模式
bp设为带通模式
hip设为高通模式

选项

选项说明
-lop设置低通模式
-hip设置高通模式
