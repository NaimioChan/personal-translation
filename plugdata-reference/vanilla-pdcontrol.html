[pdcontrol]

与 pd 和/或本 patch 通信

描述

pdcontrol 让你在网页浏览器中打开一个 URL，或与 patch 通信以获取它所属的目录、参数或它的可见/不可见状态。

可选参数用于指定本 patch（0）、所属 patch（1）、它的上一层所有者（2），依此类推，还可以选填一个相对于该 patch 目录的文件名。（如果所有者不存在，所有权编号会被静默缩减，所以这里任何大于零的值都被忽略。）

入口

入口 1

  • browse <symbol>：打开由 symbol 给出的 URL
  • dir <float, symbol>：输出 patch 的目录。可选的 float 和 symbol 设置深度和文件名
  • isvisible：输出 float 以指明 patch 是否可见（1 为可见，0 为不可见）
  • args <float>：输出 patch 的参数。可选的 float 设置深度

出口

出口 1

  • list：args、dir symbol 或 visibility float 的列表
