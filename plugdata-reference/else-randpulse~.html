[randpulse~]

随机脉冲串振荡器

描述

[randpulse~] 是一个随机脉冲串振荡器（在随机值和 0 之间交替，即开/关）。它接受负频率，具有脉冲宽度和同步的入口。

入口

入口 1

  • list/signals：频率，单位 Hz

入口 2

  • float/signal：脉冲宽度（0-1）

入口 3

  • float/signal：相位同步（内部相位重置）

出口

出口 1

  • signals：随机脉冲信号

参数

#类型默认值说明
1float0频率，单位 Hz
2float0.5初始脉冲宽度

方法

消息说明
seed <float>非 0 设为随机 gate 值模式
set <float, float><channel, freq> 设置单个密度通道

选项

选项说明
-seed <float>随机种子值
-ch <float>输出通道数
默认：1
-mc <list>用频率列表设置多通道输出
