[tabwriter~]

把信号录制到数组

描述

[tabwriter~] 把最多 64 个信号通道录制到数组中，并能以采样点精度触发。

入口

入口 1

  • signal：要录制到数组通道 0 的 signal
  • rec：（重新）开始录制
  • stop：停止录制

入口 2（可重复）

  • signal：要录制到数组通道 $nth 的 signal

入口 3

  • signal：非 0 从该索引开始录制，0 停止

出口

出口 1

  • signal：正在录制的输出索引

出口 2

  • bang：当录音到达数组末尾时

参数

#类型默认值说明
1symbol—数组名（可选）
2float1要录制的通道（最大 64）

方法

消息说明
set <symbol>设置用于录制信号的数组
start <float>起始点，单位 ms（默认 0）
end <float>结束点，单位 ms（默认：数组的初始大小）
range <f, f>按比例设置起点与终点的范围（0 到 1）
reset将起点/终点重置为从 0 到（当前）数组的长度
continue <float>非 0 从上次停止处继续录制
loop <float>非 0 启用循环录制，为 0 则禁用

选项

选项说明
-continue <f>
-loop <f>
-start <f>
-end <f>
-ch <f>通道数
