[phasor~]

相位斜坡生成器

描述

phasor~ 对象输出相位斜坡，其值为 0 到 1，并依据频率输入重复这个周期。它看起来像锯齿波信号，但传统上用于通过 cos~ 或 tabread4~ 做表格查找。频率输入可以是 float 或信号。正频率值生成向上的斜坡，负值生成向下的斜坡。

右入口用 0 到 1 的值重置相位（其中 '1' 与 '0' 相同，'0.5' 是半个周期

入口

入口 1

  • signal：频率值，单位 Hz

入口 2

  • float：相位周期重置（从 0 到 1）

出口

出口 1

  • signal：相位斜坡（范围 0 到 1）

参数

#类型默认值说明
1float0初始频率值，单位 Hz
