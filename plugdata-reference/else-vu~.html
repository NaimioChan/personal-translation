[vu~]

用于 [vu] 的振幅检测器

描述

[vu~] 结合 [rms~] 和 [peak~]，为 Pd Vanilla 的 [vu] GUI 提供 dBFs 输出。

入口

入口 1

  • float：要分析的 signal

出口

出口 1

  • float：RMS 振幅值，单位 dBFs

出口 2

  • float：以 dBFS 表示的峰值振幅值

参数

#类型默认值说明
1float1024分析窗口大小，单位采样点
2floathalf the window size步长，单位采样点

方法

消息说明
set <f,f>设置窗大小与跳跃大小，单位采样点
