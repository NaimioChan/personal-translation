[wavetable~]

周期性重复的波形

别名：wt~

描述

[wavetable~] 是一个插值波表振荡器，类似 Pd Vanilla 的 [tabosc4~]。它接受负频率，有用于相位同步和相位调制的入口。

入口

入口 1

  • list/signals：设置频率，单位 Hz

入口 2

  • float/signals：相位同步（重置内部相位）

入口 3

  • float/signals：相位偏移（调制输入）

入口 4

  • float/signals：交叉淡化输入（0-1）

出口

出口 1

  • signals：周期性重复的波形

参数

#类型默认值说明
1symbolnone数组名（可选）
2float0设置频率，单位 Hz
3float0设置相位偏移量
4float0设置交叉淡化

方法

消息说明
table <symbol>设置整个数组用作波形
set <float, float>设置单个频率通道
size <float>以点数设置大小
offset <float>设置表格中的偏移量
midi <float>非 0 将频率输入设为 MIDI 音高
soft <float>非 0 设为软同步模式
none设置为无插值模式
lin设置为线性插值模式
cos设置为余弦插值模式
lagrange设置为 Lagrange 插值模式
spline设置为样条插值模式（默认）

选项

选项说明
-none/-lin/-cos/-lagrange设置插值模式
默认：spline
-midi把频率输入设为 MIDI 音高
默认：Hz
-soft设为软同步模式
默认：hard
