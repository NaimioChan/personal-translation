ELSE · 文件管理

[dir]

访问文件目录

描述

[dir] 访问目录中的文件。

入口

入口 1

  • bang：输出 <n>、<directory> 并转储文件

出口

出口 1

  • symbol：目录中的文件

出口 2

  • symbol：当前目录

出口 3

  • float：<n> 找到的文件数

出口 4

  • float：打开新目录为 1，无法打开为 0

参数

#类型默认值说明
1float0目录层级，0 — 当前 patch 的目录，1 — 父 patch 的目录，等等
2symbolrelative directory level要打开的目录

方法

消息说明
open <symbol>打开目录并加载内容，无 symbol 则打开二进制文件所在目录
reopen重新加载上次打开的目录的内容
reset重置为 patch 的目录
dir在右侧出口输出当前目录
dump在（第二个）出口列出目录中的文件
n在（第三个出口）输出找到的文件数量
seek <float>定位并输出该编号对应的文件
next递增 seek 值并输出文件
ext <symbol>设置扩展名

选项

选项说明
-ext <symbol>设置文件扩展名类型
