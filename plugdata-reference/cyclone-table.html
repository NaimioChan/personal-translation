cyclone · 数组与表格

[table]

依给定消息索引值或其它操作

别名：cyclone/table

描述

[table] 存储并编辑一个数字数组。你可以通过打开它或双击它来进行图形化编辑。它还有若干消息方法，见下文。

入口

入口 1

  • bang：等同于带一个 0 到 32768 之间随机数作为参数的 quantile 消息（见 [pd All_Messages] 中的 quantile）
  • float：索引（x）：输出该索引处的值，或将右入口的值（如果有）存储在该索引处
  • list：一对索引 (x) 及其值 (y)：把 `y` 设为 `x`

入口 2

  • float：设置要存储在左侧入口所发送索引处的值 (y)

出口

出口 1

  • float：依给定消息索引值或其它操作

参数

#类型默认值说明
1symbolnone设置表格名称 - 名称相同的 [table] 对象具有相同的值

方法

消息说明
clear把所有值设为 0
const <float>用给定数值填充表格
cancel取消上一次右入口的输入（使下一次左入口输入输出一个数值）
dump在左侧出口输出存储的数字
embed <float>1 切换是否把数据作为 patch 的一部分保存 - 默认 0（不保存）
flags <f, f><1, 0> 在保存时把内容随之保存，<0, 1> 则不保存
fquantile <float>发送这样一个地址：其之前所有值之和 >= 所有表格值之和乘以 <float>（介于 0 和 1 之间）
getbits <list>第 1 个 float 是要查询的地址，第 2 个是起始位位置（0-31，从 LSB 到 MSB），第 3 个是从起始位向右应发送多少位（作为单个十进制整数）
goto <float>把指针设为该数值指定的地址
inv <float>查找第一个 >= 该 float 的表格值并发送其地址
length输出表格长度
load设置为 load 模式：左入口接收到的所有数字从地址 0 开始存储直到末尾（多余的数被忽略），或被普通消息解除 load 模式
max获取存储的最大值
min获取存储的最小值
name <symbol>设置表格名，同 `refer`
next在左出口发送所指向地址处存储的值，并把指针设为下一个地址（到达末尾时回到第 1 个地址）
normal从 `load mode` 更改为 `normal` 模式（见 `load message`）
open打开编辑器窗口（等同于双击它）
prev类似 `next` 消息，但减小指针地址（到达开头时回绕到最后地址）
quantile <int>发送这样一个地址：其之前所有值之和 >= 所有表格值之和乘以 <int> 再除以 2^15（32768）
read <symbol>打开并读取由 symbol 指定的文件中的数据。如果未给出 symbol，则显示打开对话框
refer <symbol>设置对象从由 symbol 指定的具名表格读取
send <symbol, float>把 float 指定地址处存储的值发送给所有以该 symbol 为名的 [receive] 对象
set <list>第一个 float 指定起始地址，后面的数值指定从该地址起要存储的值
setbits <list>更改已存储数值的位值：第 1 个 float 是地址，第 2 个是起始位位置（0-31，从 LSB 到 MSB），第 3 个是从起始位开始应修改多少位，第 4 个是这些位应设为的值（十进制或十六进制形式）
size <float>设置表格中的值数量（
sum输出所有值的总和
wclose关闭编辑窗口
write打开标准保存文件对话框，将其保存为文本文件格式

选项说明
