cyclone · 数组与表格

[play~]

数组播放器

描述

[play~] 播放数组的任意部分，可以以不同速度（带插值）播放，也可以倒放。它还可以循环，交叉淡化可选。插值与 [tabread4~] 的相同。

入口

入口 1

  • float：播放（非 0）或停止（0）播放
  • signal：播放位置，单位 ms

出口

出口 1（可重复）

  • signal：某个通道的播放

出口 2

  • bang：当它停止/结束播放时

参数

#类型默认值说明
1symbol—表格名称（必需）
2float1输出通道数（1-64）

方法

消息说明
set <symbol>设置数组名称
start <f, f, f>设置 <beginning, end, duration>，单位 ms，并开始播放
stop停止播放并输出 0（无法恢复）
pause- 在特定点暂停（可继续）
resume恢复播放
loop <float>- <non-0> - 开，<0> - 关
loopinterp <float><非 0> 交叉淡化开启，<0> 交叉淡化关闭
interptime <float>- 设置交叉淡化时间，单位 ms

选项

选项说明
@loop <float>循环模式开（1）或关（0）
@loopinterp <float>交叉淡化开（1）或关（0）
@interptime <float>交叉淡化时间，单位 ms
