cyclone · 信号运算

[plusequals~]

每个采样点都是之前所有输入采样点之和

别名：+=~ cyclone/+=~

描述

[plusequals~] 或 [+=~] 累加收到的值。每个输入采样点都加到之前的和上进行累加。所以从 0 开始，由 1 组成的信号会输出序列（1、2、3、4 等……）。
内部累加和可以用 bang（左入口）重置为 0，也可以用右入口中不为 0 的信号重置（采样精度）——还可以设为任意值（用 set 消息）。

入口

入口 1

  • signal：累加值（仅在连接了 signal 时输出）
  • bang：把初始存储值重置为 0

入口 2

  • signal：不为 0 的 signal 会把初始存储值重置为 0

出口

出口 1

  • signal：每个采样点都是之前所有输入采样点之和

参数

#类型默认值说明
1float0设置和的初始存储值

方法

消息说明
set <float>把存储的值设为那个数
