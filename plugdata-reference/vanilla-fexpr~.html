[fexpr~]

逐采样点求值音频信号表达式

描述

{{< md_include "objects/expr-family.md" >}}

入口

入口 1

  • signal：'$x1' 的输入

入口 2（可重复）

  • float：如果入口类型为 '$f#' 或 '$i#'
  • symbol：如果入口类型为 '$s#' 或 '$i#'
  • signal：如果入口类型为 '$x#'

出口

出口 1（可重复）

  • signal：表达式结果

参数

#类型默认值说明
1list—表达式，包含运算符、函数、入口类型、float 和 symbols

方法

消息说明
set <list>设置先前输入/输出值的值
stop/start停止/开始计算
clear <symbol>清空输入/输出记忆，可选 symbol 指定某个输入（如 x1）或输出（y1）
