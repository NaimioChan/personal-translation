ELSE · 信号发生器

[circuit~]

模拟电路仿真器

描述

[circuit~] 依据用分号分隔的电路文本描述来模拟模拟电路。把 '$sn' 作为第一个传入（其中 'n' 是从 1 开始编号的入口序号），即可用输入 signal 调制电压、电流、电阻和电位器。要创建音频输入，请使用带有可调制参数的电压源。每个探针元件都会创建一个音频出口。该对象可能相当耗费 CPU！

入口

入口 1

  • signal：用于 $s0 的输入信号
  • bang：重置并启动模拟

入口 2（可重复）

  • signal：用于 $s$nth 的输入信号

出口

出口 1（可重复）

  • signal：来自 probe $nth 的输出信号

参数

#类型默认值说明
1list0电路的文本描述

方法

消息说明
enable <float>设置新的文字注释
dcblock <float>向 note 追加一条消息
oversample <float>向 note 追加一条消息
iter <float>向 note 追加一条消息
reset重置模拟

选项

选项说明
-dcblock <float>启用/禁用 DC 偏移阻断
-oversample <float>设置过采样量
-iter <float>设置晶体管/二极管质量
