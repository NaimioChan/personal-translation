ELSE · 触发与时钟

[tempo]

节拍器

描述

[tempo] 对象按以 bpm 或 ms 指定的时间发送 bang。它有一个 swing 参数，并由 toggle 打开和关闭。

入口

入口 1

  • float：切换（开/关）
  • bang：同步节拍器

入口 2

  • float：速度，单位 ms、Hz 或 bpm

入口 3

  • float：摇摆偏差参数（单位 %）

出口

出口 1

  • bang：摇摆偏差参数（单位 %）

参数

#类型默认值说明
1float0bpm/Hz/ms
2float0swing 偏差，单位 %

方法

消息说明
start打开节拍器
mul <float>设置速度细分
stop关闭节拍器
ms <f, f>把时间设为 ms，可选的 float 设置速度与摇摆
hz <f, f>把时间设为 Hz，可选的 float 设置速度与摇摆
bpm <f, f>把时间设为 bpm，可选的 float 设置速度与摇摆
seed <float>float 设置随机种子，无 float 则设置唯一的内部种子

选项

选项说明
-on初始时开启
-ms把时间度量设为 ms
默认：bpm
-hz把时间度量设为 Hz
默认：bpm
-mul <float>设置速度细分
默认：1
-seed <float>设置随机种子
默认：没有 float 时设置一个唯一的内部种子
