[gran.player~]

多通道颗粒播放器

描述

[gran.player~] 类似 [player~]，但通过粒化提供独立的时间拉伸和音高变换。

入口

入口 1

  • bang：（重新）从开头开始播放缓冲区
  • float：1 等同于 "start"，0 等同于 "stop

入口 2

  • float：颗粒大小，单位 ms

入口 3

  • float：设置移调，单位音分

入口 4

  • float：设置移调，单位音分

出口

出口 1（可重复）

  • signal：对应通道的缓冲区信号

出口 2

  • bang：播放完缓冲区时输出 bang

参数

#类型默认值说明
1float1 if no file is given, or sound file's if given（可选）通道（最大 64）
2symbolnone要打开的文件名称
3float0autostart <1：开，0：关>
4float0循环 <1：开，0：关>

方法

消息说明
open <symbol>用 symbol 名称打开文件（无 symbol 则打开对话框）并开始播放
start同 bang
stop停止并回到开头
size <float>设置增益大小，单位 ms
loop <float>循环开 <1> 或关 <0>
range <f, f>设置采样点的播放范围（0 到 1）
pause暂停播放缓冲区
continue取消暂停并继续播放缓冲区
reload将文件重新加载到缓冲区并开始播放
set <symbol>设置要打开的文件（需要 reload 消息）

选项

选项说明
-speed <float>设置播放速度
默认：100
-transp <float>设置移调，单位音分
默认：0
-size <float>设置颗粒大小，单位 ms
默认：75
-loop打开循环模式
默认：off
-range <float, float>设置采样点范围
默认：0 1
