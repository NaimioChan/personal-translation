[choice]

为传入列表搜索最佳匹配

描述

choice 对象持有一组向量，每个向量最多有十个元素。当收到一个数字列表时，它输出与之最接近的已知向量的索引。匹配质量是两个向量归一化后的点积，也就是说，方向与输入最接近的向量胜出。

如果给定一个非 0 的创建参数，choice 会倾向于给最近较少输出的向量更高权重，以避免重复的输出。

你可以用它依据属性在一批行为之间交互式地选择。例如，你可能存储了许多旋律，其中一些是切分的、一些是半音的、一些有一百多年历史、一些是军号号声、一些是圣诞颂歌。然后你可以要求找出一个切分的军号号声 (1, 0, 0, 1, 0

入口

入口 1

  • print：在打印输出窗口中打印调试信息

出口

出口 1

  • float：最佳匹配的索引（从零起）

参数

#类型默认值说明
