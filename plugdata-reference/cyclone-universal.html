cyclone · 数据管理

[universal]

向所有同类型对象发送消息

描述

[universal] 把消息发送给一个 patch 和/或子 patch 窗口中同一对象的所有实例。

入口

入口 1

  • anything：向某种对象类型发送任意消息

出口

无记录。

参数

#类型默认值说明
1float0非 0 也发送到子 patch

方法

消息说明
send <anything>向某种对象类型发送任意消息
