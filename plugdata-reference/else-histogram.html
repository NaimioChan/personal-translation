[histogram]

概率分布直方图

描述

[histogram] 把收到正整数（视为索引，float 会被截断）的次数记录到表格中。list 输入被视为 MIDI 音符消息，只记录 note on。

入口

入口 1

  • float：要记录到直方图中的正整数
  • list：要记录到直方图中的 note on 音高

出口

出口 1

  • list：输入后的出现次数与索引

出口 2

  • list：'export' 消息时的表格值

出口 3

  • float：'query' 消息时的出现次数

参数

#类型默认值说明
1symbolinternal设置表格名称

方法

消息说明
clear清空直方图表格
query <float>查询某个索引出现的次数
export将直方图表格导出为 list
import <list>以 list 导入直方图数据
embed <float>非 0 将直方图数据随 patch 一同嵌入
size <float>清空并调整表格大小
name <symbol>设置表格名称

选项

选项说明
-size <float>设置表格长度
默认：128
-embed随 patch 嵌入直方图数据
默认：否
