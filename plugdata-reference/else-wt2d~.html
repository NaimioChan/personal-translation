ELSE · 信号发生器

[wt2d~]

二维波表振荡器

描述

[wt2d~] 是一个插值波表振荡器，类似 [wt~]，但除了水平维度，还能扫过一个切片波表的垂直维度。与 ELSE 中其他振荡器一样，它有用于相位调制和同步的输入。

入口

入口 1

  • list/signals：设置频率，单位 Hz 或 MIDI

入口 2

  • float/signals：相位同步（重置内部相位）

入口 3

  • float/signals：相位偏移（调制输入）

入口 4

  • float/signals：x 维度的交叉淡化输入

入口 5

  • float/signals：y 维度的交叉淡化输入

出口

出口 1

  • signals：周期性重复的波形

参数

#类型默认值说明
1symbolnone数组名
2float0设置频率，单位 Hz
3float0设置相位偏移量
4float0设置 x 维度的交叉淡化
5float0设置 y 维度的交叉淡化

方法

消息说明
table <symbol>设置整个数组用作波形
set <float, float>设置单个频率通道
n <float> <float>设置要扫描的 x 与 y 切片数量
midi <float>非零设置为以 MIDI 音高输入频率
soft <flaot>非零设为软同步模式
none设置为无插值模式
lin设置为线性插值模式
cos设置为余弦插值模式
lagrange设置为 lagrange 插值模式
spline设置为样条插值模式

选项

选项说明
-none禁用插值
-lin把插值模式设为 linear
-cos把插值模式设为 cosine
-lagrange把插值模式设为 lagrange
-n <list>设置 x 和 y 的切片数
-midi把频率输入设为 MIDI 音高
-soft设为软同步模式
