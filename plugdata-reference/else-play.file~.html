[play.file~]

播放声音文件

描述

[play.file~] 是一个基于 [readsf~] 的便捷抽象，用于从计算机读取文件。注意，文件采样点需要与 Pd 的采样率相同。该对象可以用绝对路径打开文件，也能相对于父 patch 搜索文件。

入口

入口 1

  • bang：（重新）开始播放采样点
  • float：非 0（重新）开始播放，0 停止

出口

出口 1（可重复）

  • signal：通道 $nth 的采样信号

出口 2

  • bang：播放完采样点时输出 bang

参数

#类型默认值说明
1float1 if no file is given, or sound file's if given（可选）通道数量（最大 64）
2symbolnone要打开的文件名称
3float0autostart <1：开，0：关>
4float0循环 <1：开，0：关>

方法

消息说明
start（重新）开始播放采样点
stop停止播放采样点
open <symbol>用 symbol 名称打开文件（无 symbol 则打开对话框）
set <symbol>设置下次开始播放时要打开的文件
loop <float>循环开 <1> 或关 <0>

选项

选项说明
-loop打开循环模式
