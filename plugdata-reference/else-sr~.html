ELSE · 信号运算

[sr~]

设置/设定采样率

描述

[sr~] 可设置采样率，并在加载 patch 时、收到 bang 时或采样率变化时报告采样率的频率或周期。频率以 Hz 或 kHz 报告，周期以秒或毫秒报告。与 [samplerate~] 不同，它不报告升/降采样率。默认输出是采样率的频率，单位 Hz。

入口

入口 1

  • bang：取得采样率的频率或周期

出口

出口 1

  • float：采样率频率或周期

方法

消息说明
hz设置并获取采样率频率，单位 Hz
khz设置并获取采样率频率，单位 kHz
ms设置并获取采样率周期，单位 ms
sec设置并获取采样率周期，单位 s

选项

选项说明
-khz把输出设为频率，单位 kHz
-ms把输出设为周期 ms
-sec把输出设为周期，单位 s
