[impseq~]

脉冲发生器与序列器

描述

当收到 signal 触发（0 到非 0 的跳变）或 bang 时，[impseq~] 从给定序列中发送一个脉冲。

入口

入口 1

  • signal：用于从序列生成脉冲的触发
  • bang：在控制速率下从序列生成冲量

出口

出口 1

  • signal：来自序列的冲量值

出口 2

  • signal：到达序列末尾时产生冲量

参数

#类型默认值说明
1list1float 列表设置序列

方法

消息说明
set <list>设置一个或多个脉冲值，不输出
goto <float>转到序列中的某个位置索引（从 1 开始）
