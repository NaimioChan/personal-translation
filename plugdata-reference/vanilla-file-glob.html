[file-glob]

查找匹配某模式的路径名

描述

关于通配（globbing）的跨平台说明：

[file glob] 试图统一通配符匹配在不同平台上的行为。因此，它并不支持某个模式匹配实现的所有特性（或者只是碰巧支持）。

以下规则应能帮助你写出使用平台无关通配的 patch。

- 模式可以在最后一个路径分量中包含通配符 '*'（匹配任意数量的字符）和 '?'（匹配单个字符）。不支持其他通配符。

- 在最后一个路径分量之外的路径分量中包含通配符的模式，其行为是*未定义*的（且取决于平台）。不要这样做。

- 以 '/' 结尾的模式只匹配目录

- 以其他任何内容结尾的模式会匹配文件与目录

- 以 "." 开头的文件/目录，只有在匹配模式中显式包含开头的点时才会匹配。

- 特殊文件/目录 "." 和 ".." 只有在显式请求时才匹配，绝不会用通配符模式匹配。

入口

入口 1

  • symbol：要查找的图案

出口

出口 1

  • list：以路径 symbol 和类型返回找到的文件/目录（文件 <0>，目录 <1>）

出口 2

  • bang：如果未找到任何内容或发生错误

方法

消息说明
verbose <float>打开或关闭详细输出

选项

选项说明
-q设置静默详细程度
-v设置详细程度为 loud
