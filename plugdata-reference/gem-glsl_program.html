Gem · 图形

[glsl_program]

将 GLSL 模块链接为着色器程序

入口

入口 1

  • gemlist

出口

出口 1

  • gemlist

出口 2

  • float：GLSL 程序的 ID

方法

消息说明
shader <list>由 [glsl_fragment] 和 [glsl_vertex] 报告生成的 shader 模块 ID 列表
link链接通过 "shader" 消息给出的 shader 模块
link <list>链接给定的 shader 模块（等同于 "shader <list>"+"link"）
print打印关于你的 openGL 实现中 GLSL 支持以及已链接程序的信息
<uniformName> <uniformParm>...把名为 uniformName 的 uniform 变量设为（一列）uniformParms。仅在成功链接程序后才有效
geometry_intype <inputtype>几何图形的输入类型
geometry_outtype <outputtype>输出几何类型
geometry_type <inputtype> <outputtype>"intype" 和 "outtype 的组合
geometry_outvertices <#vertices>要创建的顶点数量
keepuniforms <float>启用（默认）或禁用跨重载缓存 uniform 变量
