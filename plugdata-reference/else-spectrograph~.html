[spectrograph~]

频谱图

描述

[spectrograph~] 是一个用于可视化 0Hz 到 Nyquist 的 FFT 振幅的抽象对象。它使用 Hann 表进行分析。

入口

入口 1

  • signal：待绘图的传入信号
  • bang：速率为 0 时绘图

出口

无记录。

方法

消息说明
size <f>设置 FFT 大小
db <f>非 0 设为 dB 振幅刻度
log <f>非 0 设为对数频率刻度
dim <f,f>设置水平/垂直尺寸
rate <f>设置绘图速率，单位 ms

选项

选项说明
-size <f>FFT 大小（最小 128）
默认：1024
-db <f>非 0 设为 dB 振幅刻度
默认：linear
-log <f>非 0 设为对数频率刻度
默认：linear
-dim <f,f>设置水平/垂直尺寸
默认：300 140
-rate <float>设置图形刷新速率，单位 ms
默认：100
