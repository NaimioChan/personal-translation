ELSE · 界面

[pad]

鼠标板

描述

[pad] 是一个 GUI 对象，报告其区域内的鼠标坐标和点击状态。如果点击并拖动，可以获得 GUI 区域之外的值。

入口

无记录。

出口

出口 1

  • list：坐标列表（x, y）
  • click <float>：报告鼠标按键按下 <1> 与释放 <0>

方法

消息说明
dim <f, f>设置尺寸（水平和垂直）
width <float>设置宽度
height <float>设置高度
color <f, f, f>设置 RGB 颜色

选项

选项说明
-dim <f, f>设置水平与垂直尺寸
默认：127 127
