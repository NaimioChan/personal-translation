[rand.hist]

来自直方图的随机值

描述

[rand.hist] 基于直方图（指定每个索引被输出的次数）生成带权重的随机数。左下角的示例中，随机序列里 0 的出现概率为 30%，1 为 20%，2 为 50%。list 设置新的直方图。在 "unrepeat" 模式下，输出的随机序列不重复，右下角的随机序列包含索引 0 三次、索引 1 两次。序列结束时，右侧出口输出一个 bang。此时 'restart' 消息会清空记忆，以便开始新的序列。

入口

入口 1

  • bang：生成随机输出
  • list：设置新的直方图并清空内存

出口

出口 1

  • float：从直方图输出的随机索引

出口 2

  • bang：序列结束时输出 bang

参数

#类型默认值说明
1list—设置直方图

方法

消息说明
seed <float>float 设置随机种子，无 float 则设置唯一的内部种子
set <f, f>设置索引和出现次数值
clear清空记忆
inc <float>设置索引并把出现次数加 1
dec <float>设置索引并把出现次数减 1
size <float>清空记忆并设置新的 'n' 大小
eq <float>为所有元素设置相同的出现次数
unrepeat非 0 设置不重复模式

选项

选项说明
-seed <float>随机种子值
默认：内部唯一
-size <float>设置直方图大小
默认：128
-eq <float>设置所有索引出现次数相等
默认：0
-uunrepeat 模式
默认：
