cyclone · 数据管理

[join]

把各项合并成一个列表

描述

[join] 在任意入口接收任意类型的消息（anything、float、symbol、list），并把它们全部组合成一个输出列表。

入口

入口 1（可重复）

  • anything：要合并成 list 的任意消息类型
  • bang：强制输出已存储的消息

出口

出口 1

  • list：由连接后的消息组成的列表

参数

#类型默认值说明
1float2入口数量（最小值 2 / 最大值 255）

方法

消息说明
triggers <list>定义一个输入编号列表，这些输入会触发输出（使入口变为 "hot"）：0 是第一个入口，1 是第二个，依此类推（-1 使所有入口变为 "hot"）
set <anything>向该入口设置一条消息，无输出

选项

选项说明
@triggers <list>默认 "0"（左入口为热入口）
