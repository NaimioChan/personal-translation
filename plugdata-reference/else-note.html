ELSE · 界面

[note]

文本注释

描述

[note] 是一个仅用于显示文本注释的 GUI。它基本上等同于 Pd 的 comment，但优势在于可以设置字体、大小、颜色、背景色、粗体、斜体、下划线和对齐方式。

入口

入口 1

  • set <anything>：设置新的文字注释

出口

无记录。

方法

消息说明
set <anything>设置新的文字注释
append <anything>向 note 追加一条消息
prepend <anything>向音符前添加一条消息
font <symbol>设置字体名称
size <float>设置字体大小
bold <float>非 0 设为粗体
italic <float>非 0 设为斜体
underline <float>非 0 设置下划线
just <float>设置对齐方式（0：左，1：居中，2：右）
width <float>设置宽度，单位像素
color <f, f, f>设置 RGB 文字颜色（值从 0 到 255）
bgcolor <f, f, f>设置 RGB 背景颜色（值从 0 到 255）
bg <float>背景选项（0 抑制背景）
outline <float>非 0 设置轮廓
receive <symbol>设置 receive symbol

选项

选项说明
-font <symbol>默认 'dejavu sans mono'，Mac 上为 'menlo'
-bold
-italic
-size <float>默认同 patch
-just <float>默认 0
-color <f, f, f>默认 0 0 0
-bgcolor <f, f, f>默认 255 255 255
-bg
-outline
-note <anything>设置音符
默认："note
-underline
-receive <symbol>默认 'empty'
-width <float>默认 0
