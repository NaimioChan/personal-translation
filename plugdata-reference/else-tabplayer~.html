[tabplayer~]

数组/表格播放器

描述

[tabplayer~] 播放数组，它比 [tabplay~] 更强大，因为它支持多通道，可以倒放和以不同速度播放。它还能循环。

入口

入口 1

  • float：非 0 播放，0 停止
  • bang：播放（等同于非 0）
  • signal：门控开/冲量 — 启动，门控关 — 停止（触发模式下除外）

出口

出口 1

  • signal：某个通道的播放

出口 2

  • bang：当它停止/结束播放时，或循环时

参数

#类型默认值说明
1symbol—表格名称（可选）
2float1输出通道数（最大值 64）

方法

消息说明
tr <float>非 0 设为触发模式，为零则设为 gate 模式
set <symbol>设置数组名
start <float>设置起点，单位 ms
end <float>设置终点，单位 ms
range <f, f>按比例设置起点与终点的范围（0 到 1）
pos <f>按比例设置范围内的位置（0 到 1）
reset将范围重置为从 0 到数组长度
speed <float>设置播放速度，单位 %
play <f, f, f>开始播放，可选 <start in ms, end in ms, speed rate>
<stop>停止播放并输出 0（无法恢复）
<pause>在特定点暂停（可恢复）
<resume>暂停后恢复播放
loop <float>非 0 启用循环，<0> 禁用
fade <float>设置淡入淡出时间，单位 ms
xfade <float>循环时设置为交叉淡化模式
sr <float>设置采样点的采样率（默认：Pd 的采样率）

选项

选项说明
-fade <float>
-speed <float>
-tr设为触发模式
-loop设为循环模式
-tr设为触发模式
-loop设为循环模式
-xfade设为交叉淡化模式
-sr <float>
-range <f, f>
