高斯白噪声

来源：

Steven W. Smith：
《The Scientist and Engineer's Guide to Digital Signal Processing》

#define PI 3.1415926536f

float R1 = (float) rand() / (float) RAND_MAX;
float R2 = (float) rand() / (float) RAND_MAX;

float X = (float) sqrt( -2.0f * log( R1 )) * cos( 2.0f * PI * R2 );
