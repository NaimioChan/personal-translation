并联梳状延时计算

  • 作者或来源：Juhana Sadeharju ( if.tenuf.cin@aihuok )
  • 创建时间：2002-05-23 19:49:40

这个公式可以在与并联梳状结构相关的专利中找到。该公式让并联梳状滤波器产生的第一批回声呈均匀分布的序列。如果 T_ ,...,T_n 是按递增顺序排列的延迟线，则可通过令 T_(k-1)/T_k = 常数、T_n/(2*T_1) = 常数来导出该公式，其中 2*T_1 是紧跟回声 T_n 之后到来的回声。
这是我自己琢磨出来的，因为专利里没有讲。这个公式并不是能想出的最好公式。我用一种搜索方法来找在足够长时间内足够均匀的回声序列。该公式只在短时间内均匀。
这个公式对串联全通与 FDN 结构效果不好，不过用同样的思路可以为它们导出类似的公式。搜索方法对这些结构也适用。
