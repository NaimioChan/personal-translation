高斯随机数

// 高斯随机数
// 这个算法（改编自 Reinhard Scholl 的《Natur als fraktale Grafik》）
// 实现一种高斯分布随机数的生成方法，均值为 0、方差为 1
//（标准高斯分布），映射到 -1 到 +1 的范围，
// 最大值在 0 处。
// 如果只需要正结果，可以对返回值取 abs()。
// 变量 q 定义精度，q=15 时两个数之间的最小
// 距离为 1/(2^q div 3)=1/10922，
// 通常能给出不错的结果。
// 注意：这里使用的 random() 函数是 Delphi/Pascal 的
// 标准 random 函数，产生 0 到参数-1 的*线性*
// 分布数，等效的 C 函数大概是 rand()。
const q=15;
      c1=(1 shl q)-1;
      c2=(c1 div 3)+1;
      c3=1/c1;

function GRandom:single;
begin
 result:=(2*(random(c2)+random(c2)+random(c2))-3*(c2-1))*c3;
end;
