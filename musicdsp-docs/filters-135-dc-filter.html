直流滤波器

  • 作者或来源：hc.niweulb@lossor.ydna
  • 类型：单极点/单零点直流滤波器
  • 创建时间：2003-01-04 01:18:23

这基于以下文档中的代码：
《Introduction to Digital Filters (DRAFT)》
Julius O. Smith III (jos@ccrma.stanford.edu)
(http://www-ccrma.stanford.edu/~jos/filters/)
---

某些音频算法（非对称波形整形、级联滤波器……）会产生直流偏移。这种偏移会累积，降低信噪比。

那么怎么解决？Julius O. Smith 文档中的示例代码是：
...
y(n) = x(n) - x(n-1) + R * y(n-1)
// “R”在 0.9 .. 1 之间
// n=当前，(n-1)=先前的输入/输出值
...
“R”取决于采样率和低频点。如果你不知道采样率，就不要把“R”设成固定值（例如 0.99）。而应设 R 为：
(-3dB @ 40Hz)：R = 1-(250/samplerate)
(-3dB @ 30Hz)：R = 1-(190/samplerate)
(-3dB @ 20Hz)：R = 1-(126/samplerate)

'How to calculate "R" for a given (-3dB) low frequency point?'

R = 1 - (pi*2 * frequency /samplerate)

(pi=3.14159265358979)
