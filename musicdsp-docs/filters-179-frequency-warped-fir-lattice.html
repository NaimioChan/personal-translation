频率弯曲 FIR 格型

  • 作者或来源：ten.enegatum@liam
  • 类型：使用全通链的 FIR
  • 创建时间：2004-08-24 11:39:28

完全未优化，在数组和额外开销方面相当吃资源（函数需要两个数组存放格型滤波器的内部状态，并向另外两个数组输出下一状态）。在这个实现里，你大概需要在处理循环中来回倒换 taps1/newtaps，交替把其中一组数组传给 wfirlattice。

频率弯曲格型滤波器就是把格型滤波器中每个延时都换成全通滤波器。通过调整全通滤波器，可以调整滤波器的频率响应（例如设计一个近似某种滤波器的 FIR。摆弄弯曲系数就能让 FIR 上下“扫动”，而不改变其他系数）。关于弯曲滤波器的更多内容可在 Aki Harma 的网站上找到（http://www.acoustics.hut.fi/~aqi/）。

float wfirlattice(float input, float *taps1, float *taps2, float *reflcof, float lambda, float *newtaps1, float *newtaps2, int P)
// input 是滤波器输入
// taps1、taps2 是滤波器先前的状态（初始化为 0）
// reflcof 是反射系数，滤波器稳定需 abs(reflcof) < 1
// lamba 是弯折参数（0 = 不弯折，0.75 在 44.1 kHz 下接近 bark 刻度）
// newtaps1、newtaps2 是滤波器的新状态
// P 是滤波器的阶数
{
	float forward;
	float topline;

	forward = input;
	topline = forward;

	for (int i=0;i<P;i++)
	{
		newtaps2[i] = topline;
		newtaps1[i] = float(lambda)*(-topline + taps1[i]) + taps2[i];
		topline = newtaps1[i]+forward*(reflcof[i]);
		forward += newtaps1[i]*(reflcof[i]);
		taps1[i]=newtaps1[i];
		taps2[i]=newtaps2[i];
	}
	return forward;
}

Couldn't you easily do away with newtaps entirely? As in:

for(int i=0;i&lt;P;i++)
{
    taps1[i]=lambda*(taps1[i]-topline)+taps2[i];
    taps2[i]=topline;
    topline=taps1[i]+forward*reflcof[i];
    forward+=taps1[i]*reflcof[i];
}
