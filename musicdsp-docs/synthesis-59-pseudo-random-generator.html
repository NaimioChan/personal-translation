伪随机发生器

  • 作者或来源：Hal Chamberlain, "Musical Applications of Microprocessors" (Phil Burk)
  • 类型：线性同余，32 位
  • 创建时间：2002-01-17 03:11:50

它可用于生成随机数字序列，或合成白噪声音频信号。
如果你只用其中一部分位，请通过右移使用最高有效位，不要只把低位掩掉。

/* 基于线性同余法计算 32 位伪随机数。 */
unsigned long GenerateRandomNumber( void )
{
   /* 改变此值可获得不同的随机序列。 */
   static unsigned long randSeed = 22222;
   randSeed = (randSeed * 196314165) + 907633515;
   return randSeed;
}
