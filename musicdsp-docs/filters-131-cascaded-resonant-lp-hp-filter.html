级联谐振低通/高通滤波器

  • 作者或来源：ed.bew@raebybot
  • 类型：低通+高通
  • 创建时间：2002-12-16 19:02:11
// 级联谐振低通/高通组合滤波器
// 这个滤波器的原始来源是存档中 Paul Kellet 的代码。
// 这是 Delphi 中的级联版本，低通的输出送入高通。
// 截止频率范围为 0<=x<1，映射到 0..奈奎斯特频率
// 输入变量为：
// cut_lp：低通截止频率（0..1）
// cut_hp：高通截止频率（0..1）
// res_lp：低通谐振（0..1）
// res_hp：高通谐振（0..1）
var n1,n2,n3,n4:single; // 滤波器延迟，这些需初始化为 0！
    fb_lp,fb_hp:single; // 存放计算出的反馈量
const p4=1.0e-24; // 消除 Pentium 4 的非正规数问题

function dofilter(inp,cut_lp,res_lp,cut_hp,res_hp:single):single;
begin
 fb_lp:=res_lp+res_lp/(1-cut_lp);
 fb_hp:=res_hp+res_hp/(1-cut_lp);
 n1:=n1+cut_lp*(inp-n1+fb_lp*(n1-n2))+p4;
 n2:=n2+cut_lp*(n1-n2);
 n3:=n3+cut_hp*(n2-n3+fb_hp*(n3-n4))+p4;
 n4:=n4+cut_hp*(n3-n4);
 result:=i-n4;
end;
