抖动代码

  • 作者或来源：Paul Kellett
  • 类型：带噪声整形的抖动
  • 创建时间：2002-01-17 03:13:20

这是一个简单的高通三角 PDF 抖动实现（一种好的通用抖动），可选二阶噪声整形（在 0.1 Fs 以下把噪声底降低 11dB）。
代码假定输入数据在 +1 到 -1 范围内，且不检查过载！

为多个声道生成抖动时，为了省时间，可以复用前一个随机数的低位，而不必再次调用 rand()。例如 r3=(r1 & 0x7F)<<8;

  int   r1, r2;                //矩形 PDF 随机数
  float s1, s2;                //误差反馈缓冲区
  float s = 0.5f;              //设为 0.0f 则不做噪声整形
  float w = pow(2.0,bits-1);   //字长（通常 bits=16）
  float wi= 1.0f/w;
  float d = wi / RAND_MAX;     //抖动幅度（2 lsb）
  float o = wi * 0.5f;         //去除直流偏移
  float in, tmp;
  int   out;

//对每个采样点……

  r2=r1;                               //可通过以下方式得到 HP-TRI 抖动：
  r1=rand();                           //减去前一个 rand()

  in += s * (s1 + s1 - s2);            //误差反馈
  tmp = in + o + d * (float)(r1 - r2); //直流偏移与抖动

  out = (int)(w * tmp);                //向下截断
  if(tmp<0.0f) out--;                  //这比 floor() 更快

  s2 = s1;
  s1 = in - wi * (float)out;           //误差
