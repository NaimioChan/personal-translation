用于参数边沿滤波的低通滤波器

  • 作者或来源：Olli Niemitalo
  • 创建时间：2002-01-17 02:06:29
  • 关联文件：filter001.gif

用这个滤波器平滑突变的参数变化
（见关联文件！）

/* - 三个一阶滤波器并联组合
 * - 输出始终在输入范围内
 * - 频率响应滚降约 18 dB/oct
 * - 相当快，每采样 2x3 次并行乘法，无内部缓冲区
 * - 时间可缩放，可用于不同采样率
 * - 冲激响应和边沿响应的微分连续
 * - 需要较高的内部数值精度
 */
{
        /* 参数 */
        // 从边沿开始到到达新值一半所需的采样数
        const double        scale = 100;
        // 0 < Smoothness < 1。越大越好，但可能导致精度问题
        const double        smoothness = 0.999;

        /* 预计算变量 */
        double                a = 1.0-(2.4/scale); // 也可以直接设置
        double                b = smoothness;      //         -"-
        double                acoef = a;
        double                bcoef = a*b;
        double                ccoef = a*b*b;
        double                mastergain = 1.0 / (-1.0/(log(a)+2.0*log(b))+2.0/
                        (log(a)+log(b))-1.0/log(a));
        double                again = mastergain;
        double                bgain = mastergain * (log(a*b*b)*(log(a)-log(a*b)) /
                            ((log(a*b*b)-log(a*b))*log(a*b))
                            - log(a)/log(a*b));
        double                cgain = mastergain * (-(log(a)-log(a*b)) /
                        (log(a*b*b)-log(a*b)));

        /* 运行时变量 */
        long                streamofs;
        double                areg = 0;
        double                breg = 0;
        double                creg = 0;

        /* 主循环 */
        for (streamofs = 0; streamofs < streamsize; streamofs++)
        {
                /* 更新滤波器 */
                areg = acoef * areg + fromstream [streamofs];
                breg = bcoef * breg + fromstream [streamofs];
                creg = ccoef * creg + fromstream [streamofs];

                /* 并联合并滤波器 */
                long                temp =   again * areg
                                       + bgain * breg
                                       + cgain * creg;

                /* 检查削波 */
                if (temp > 32767)
                {
                        temp = 32767;
                }
                else if (temp < -32768)
                {
                        temp = -32768;
                }

                /* 存储新值 */
                tostream [streamofs] = temp;
        }
}

2014-07-14 22:02:46 · moc.liamg@uttrep.imas

Works nicely, thanks. The gain calculations can be simplified quite a bit, to just one gain parameter.

gain = 1.0 / (-1.0 / log(a) + 2.0 / log(a * b) - 1.0 / log(a * b * b))

Then,

again = gain,
bgain = -2.0 * gain, and
cgain = gain.
