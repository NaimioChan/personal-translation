我的带限波形做法

  • 作者或来源：Anton Savov (gb.liam@ottna)
  • 类型：经典锯齿波示例
  • 创建时间：2009-06-22 18:09:08

这是我<丑陋>的 C++ 代码，用来在表中生成一个锯齿波的单周期。
通常我会把“基频”表做得足够大，以容纳当前采样率下大约 20-40Hz 的波形。
另外，我把表做大一倍，然后做“mipmap”。
所以尺寸应当是 2 的幂，比如 44100Hz 下取 1024，即 44100/1024 = ~43.066Hz。
之后 mipmap 的尺寸依次减半：512、256、128、64、32、16、8、4 和 2。

如果“吉布斯”效应是我理解的那样——那我有一个简单的解法。
以下是我粗糙的代码：

int sz = 1024; // 表的大小
int i = 0;
float *table; // 指向表的指针
double scale = 1.0;
double pd; // 相位
double omega = 1.0 / (double)(sz);

while (i < sz)
{
	double amp = scale;
	double x = 0.0; // 采样值
	double h = 1; // 谐波次数（从 1 开始）
	double dd; // 修正高频“振铃”
	pd = (double)(i) / (double)(sz); // 计算相位
	double hpd = pd; // 该谐波的相位
	while (true) // 开始对该采样点循环
	{
		if ((omega * h) < 0.5) // 谐波频率是否在范围内？
		{
			dd = cos(omega * h * 2 * pi);
			x = x + (amp * dd * sin(hpd * 2 * pi));
			h = h + 1;
			hpd = pd * h;
			amp = 1.0 / h;
		}
		else { break; }
	}
	table[i] = x;
	++i;
}

the peaks are around +/- 0.8
a square can be generated by just changing h = h+2; the peaks would be +/- 0.4

any bugs/improvements?
