Lo-Fi 压碎器

  • 作者或来源：David Lowenfels
  • 类型：平滑控制的量化器/抽取器
  • 创建时间：2003-04-01 15:34:40

又一个 bitcrusher 算法。不过这个有平滑的参数控制。

Normfreq 从 0 到 1.0；（freq/samplerate）
假定输入在 0 到 1 之间。
当 bits < 1.0 时，输出增益大于 1；

function output = crusher( input, normfreq, bits );
    step = 1/2^(bits);
    phasor = 0;
    last = 0;

    for i = 1:length(input)
       phasor = phasor + normfreq;
       if (phasor >= 1.0)
          phasor = phasor - 1.0;
          last = step * floor( input(i)/step + 0.5 ); %quantize
       end
       output(i) = last; %sample and hold
    end
end
