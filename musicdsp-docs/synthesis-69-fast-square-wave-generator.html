快速方波发生器

  • 作者或来源：Wolfgang (ed.tfoxen@redienhcsw)
  • 类型：非带限振荡器……
  • 创建时间：2002-02-10 12:46:22

产生 -1.0f .. +1.0f 的方波。
所得波形不是带限的，所以对合成大概没什么用。
不过对 LFO 之类倒是挺有用。

Idea: use integer overflow to avoid conditional jumps.

// 初始化：
typedef unsigned long ui32;

float sampleRate = 44100.0f; // 任意值
float freq = 440.0f; // 440 Hz
float one = 1.0f;
ui32 intOver = 0L;
ui32 intIncr = (ui32)(4294967296.0 / hostSampleRate / freq));

// 循环：
(*((ui32 *)&one)) &= 0x7FFFFFFF; // 屏蔽符号位
(*((ui32 *)&one)) |= (intOver & 0x80000000);
intOver += intIncr;
