相位调制与频率调制 II

  • 作者或来源：James McCartney
  • 创建时间：2003-12-01 08:24:26

在数字振荡器中，FM 与 PM 的区别在于：FM 在相位积分之前加到频率上，而 PM 在相位积分之后加到相位上。相位积分是指把振荡器的旧相位与当前频率（弧度/采样）相加，得到振荡器的新相位。要获得与 FM 相同的波形，等效的 PM 调制器是 FM 调制器的积分。由于正弦波的积分是反相余弦波，这不成问题。在包含多个分音的调制器中，等效 PM 调制器的各分音相对幅度会不同。例如方波的积分是三角波；它们的谐波成分相同，但各分音的相对幅度不同。这些差异无关紧要，因为我们并不是要精确重现 FM，而是要重现真实（或非真实）的乐器。

PM 更好的原因是：PM 与 FM 中都可能在 0 Hz 处产生非零能量，在 FM 中，如果 FM 波再次用作调制器，这会造成音高偏移；而在 PM 中，直流分量只会产生相移。PM 更好的另一个原因是，调制指数（决定产生的边带数量，在普通 FM 中按调制器幅度除以调制器频率计算）不依赖调制器频率，它始终等于调制器幅度（以弧度计）。解决直流频率偏移问题的好处是，可以级联载波-调制器对，也可以做反馈调制。调制指数计算更简单，则让各声部在所有音高上更容易保持相同的谐波结构。

相位调制的基本数学在任何电子通信理论教材中都能找到。

下面是一些实现 FM、PM 与 AM 的数字振荡器 C 代码。它展示了 FM 与 PM 在实现上的差异。它仅作示例，并非高效实现。

/* 数字振荡器的示例实现，支持 FM、PM & AM */

#define PI 3.14159265358979
#define RADIANS_TO_INDEX (512.0 / (2.0 * PI))

typedef struct{	/* 振荡器数据 */
	double freq;   /* 振荡器频率，单位弧度/采样点 */
	double phase;  /* 累积的振荡器相位，单位弧度 */
	double wavetable[512]; /* 波形查找表 */
} OscilRec;


/* oscil — 计算一个采样点的振荡器输出，其频率、相位和
*    波表位于 orec 指向的 OscilRec 结构中。
*/
double oscil(orec, fm, pm, am)
	OscilRec *orec;  /* 指向 oscil 数据的指针 */
	double fm; /* 频率调制输入，单位弧度/采样点 */
	double pm; /* 相位调制输入，单位弧度 */
	double am; /* 幅度调制输入，单位任意 */
{
	long tableindex;            /* 波表索引 */
	double instantaneous_freq;  /* 振荡器频率 + 频率调制 */
	double instantaneous_phase; /* 振荡器相位 + 相位调制 */
	double output;              /* 振荡器输出 */

	instantaneous_freq  = orec->freq  + fm; /* 获取瞬时频率 */
	orec->phase += instantaneous_freq;      /* 累加相位 */
	instantaneous_phase = orec->phase + pm; /* 获取瞬时相位 */

	/* 转换为查找表索引 */
	tableindex = RADIANS_TO_INDEX * instantaneous_phase;
	tableindex &= 511; /* 对 512 取模 === 消除 2*k*PI 的整数倍 */

	output = orec->wavetable[tableindex] * am; /* 查表并乘以 am 输入 */

	return (output);  /* 返回振荡器输出 */
}
