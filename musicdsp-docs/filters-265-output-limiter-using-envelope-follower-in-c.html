使用包络跟随器的 C++ 输出限制器

  • 作者或来源：moc.oohay@nniveht
  • 创建时间：2009-04-27 08:46:35

这里有一个 Limiter 类，如果信号会导致削波，它会自动压缩。

你可以控制限制器的起音与衰减参数。起音决定限制器对输出电平突然上升的响应速度。我发现 attack=10ms、decay=500ms 对我的应用效果很好。

这个 C++ 示例演示了用模板参数让同一份代码同时适用于 float 或 double（无需复制代码），也演示了通过 “skip” 参数让同一份代码适用于交错音频数据（任意声道数）或线性数据。注意，即便在这种情况下，当模板以编译期常量 skip 实例化时，编译器也能生成完全优化的输出。

在 Limiter::Process() 中你可以看到包络类被逐样本调用，这说明只要代码结构正确，即使对单个样本调用函数也能被编译器完全优化掉。

虽然这是一个相当简单的算法，但我想分享使用模板参数来开发例程的技巧：这些例程能适用于任意大小的浮点表示或多声道音频数据，同时保持完全优化。

这些类基于 musicdsp.org 存档中的想法。

class EnvelopeFollower
{
public:
	EnvelopeFollower();

	void Setup( double attackMs, double releaseMs, int sampleRate );

	template<class T, int skip>
	void Process( size_t count, const T *src );

	double envelope;

protected:
	double a;
	double r;
};

//----------

inline EnvelopeFollower::EnvelopeFollower()
{
	envelope=0;
}

inline void EnvelopeFollower::Setup( double attackMs, double releaseMs, int sampleRate )
{
	a = pow( 0.01, 1.0 / ( attackMs * sampleRate * 0.001 ) );
	r = pow( 0.01, 1.0 / ( releaseMs * sampleRate * 0.001 ) );
}

template<class T, int skip>
void EnvelopeFollower::Process( size_t count, const T *src )
{
	while( count-- )
	{
		double v=::fabs( *src );
		src+=skip;
		if( v>envelope )
			envelope = a * ( envelope - v ) + v;
		else
			envelope = r * ( envelope - v ) + v;
	}
}

//----------

struct Limiter
{
	void Setup( double attackMs, double releaseMs, int sampleRate );

	template<class T, int skip>
	void Process( size_t nSamples, T *dest );

private:
	EnvelopeFollower e;
};

//----------

inline void Limiter::Setup( double attackMs, double releaseMs, int sampleRate )
{
	e.Setup( attackMs, releaseMs, sampleRate );
}

template<class T, int skip>
void Limiter::Process( size_t count, T *dest )
{
	while( count-- )
	{
		T v=*dest;
		// 不必担心，这里会被优化
		e.Process<T, skip>( 1, &v );
		if( e.envelope>1 )
			*dest=*dest/e.envelope;
		dest+=skip;
	}
}
