16 位到 8 位一阶抖动

  • 作者或来源：Jon Watte
  • 类型：一阶误差前馈抖动代码
  • 创建时间：2002-04-12 13:52:36

这大概是你能实现的最简单的抖动算法，但它很可能比直接截断到 N 位听起来更好。

注意，你可能不想把完整差值无限地传递下去。最严重的性能损失很可能来自饱和条件判断，而在许多 DSP 和整数 SIMD 类指令或 CMOV 上，可以用合适的指令避开它。

最后，如果音质至关重要（例如从 > 16 位转到 16 位），你大概想用本站别处给出的更高阶抖动函数。

// 本代码将 16 位有符号 short 单声道信号 
// 降位并抖动为 8 位无符号 char 信号， 
// 采用一阶前馈误差项抖动。

#define uchar unsigned char

void dither_one_channel_16_to_8( short * input, uchar * output, int count, int * memory )
{
  int m = *memory;
  while( count-- > 0 ) {
    int i = *input++;
    i += m;
    int j = i + 32768 - 128;
    uchar o;
    if( j < 0 ) {
      o = 0;
    }
    else if( j > 65535 ) {
      o = 255;
    }
    else {
      o = (uchar)((j>>8)&0xff);
    }
    m = ((j-32768+128)-i);
    *output++ = o;
  }
  *memory = m;
}
