QFT 与 DQFT（双精度）类

  • 作者或来源：Joshua Scholar
  • 创建时间：2003-05-17 16:17:35
  • 关联文件：qft.tar_1.gz

由于这是一个 Visual C++ 工程（尽管其中的 C++ 相对可移植），我猜主要读者是 PC 用户，所以附带了一个 zip 文件。有些 PC 用户不知道拿 tgz 文件怎么办。

QFT 与 DQFT（双精度）类提供以下功能：

1. 实值 FFT 与逆 FFT 函数。注意，所得频谱的实部与虚部使用各自独立的数组。

2. 把频谱分解为偶数样本的频谱与奇数样本的频谱。这对构建滤波器组很有用。

3. 由偶数样本与奇数样本的独立频谱重新合成一个频谱。这对构建滤波器组很有用。

4. 离散 Sin 变换（QFT 把 FFT 分解为 DST 与 DCT）。

5. 离散 Cos 变换。

6. 由于 QFT 的最后一级是从外向内计算的，最后一部分可以保持未解包状态，只在需要时计算——适用于并不需要完整频谱的场合（我用它来计算相关与卷积，只需要一半结果）。
ReverseNoUnpack()
UnpackStep()
和 NegUnpackStep()
实现这一功能。

注意：Reverse() 会对结果做归一化（除以块长的一半），但 ReverseNoUnpack() 不会。

7. 另外，如果你只想要前半部分结果，可以调用 ReverseHalf()。

注意：Reverse() 会对结果做归一化（除以块长的一半），但 ReverseHalf() 不会。

8. QFT 的数值稳定性不如普通 FFT。使用单精度计算时，块长 2^15 会使其精度降到勉强够用的程度。在这个尺寸下，对测试声音文件做单精度计算时，每个块偶尔会有一个样本偏差 2，几个样本偏差 1。满音量白噪声在块的结尾、开头和中间，会产生几个偏差高达 6 的样本。

无论输入是什么，误差总是出现在块内相同的位置。存在某种抵消效应，块越大越敏感。

为了做卷积之类只需对其中一个输入做一次正变换的运算，我写了 AccurateForward() 函数。块大于 2^12 时它使用普通 FFT 算法，并递归分解为偶数与奇数 FFT。

无论如何，你总可以用双精度例程获得更高精度。DQFT 甚至有接受 float 输入、返回双精度频谱输出的例程。

关于可移植性：

1. 文件 qft.cpp 与 dqft.cpp 开头有定义：
#define _USE_ASM

如果把这些定义注释掉，剩下的就是不包含汇编语言的 C++。

2. “criticalSection.h” 中有不必要的 Windows 专用代码。
我使用临界区是因为对象不可重入（每个对象都有常驻的暂存内存），但临界区显然是操作系统相关的。无论如何，那段代码很容易去掉。

如果你看我的代码，会发现示例里内置了测试，用来确认结果大致正确。并不是我预期答案会差很远，而是我当时取消注释了某些例程的“无汇编语言”版本，想确认它们没坏。
