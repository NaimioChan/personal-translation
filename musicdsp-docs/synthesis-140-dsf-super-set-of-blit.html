DSF（BLIT 的超集）

按 Moorer 风格的离散求和公式

等价于计算 sum{k=0:N-1}(a^k * sin(beta + k*theta))
改自 Emanuel Landeholm 的 C 代码
输出不应削波超出 [-1,1]

若用于虚拟模拟的 BLIT 合成：
N = maxN;
a = attn_at_Nyquist ^ (1/maxN); % 隐藏扫描频率时最高谐波突然出现与消失
beta = pi/2;
num = 1 - a^N * cos(N*theta) - a*( cos(theta) - a^N * cos(N*theta - theta) ); % 不要在 beta 上浪费时间

如果 a > 1，还能得到增长的谐波，但必须去掉代码中的 min 语句，而且缩放会变得很奇怪。

function output = dsf( freq, a, H, samples, beta)
%a = 滚降系数
%H = 谐波泛音数量（不含基频）
%beta = 谐波相移

samplerate = 44.1e3;
freq = freq/samplerate; %归一化频率

bandlimit = samplerate / 2; %Nyquist 频率
maxN = 1 + floor( bandlimit / freq ); %防止混叠
N = min(H+2,maxN);

theta = 2*pi * phasor(freq, samples);

epsilon = 1e-6;
a = min(a, 1-epsilon); %防止除以零

num = sin(beta) - a*sin(beta-theta) - a^N*sin(beta + N*theta) + a^(N+1)*sin(beta+(N-1)*theta);
den = (1 + a * ( a - 2*cos(theta) ));

output = 2*(num ./ den - 1) * freq; %减一以去除直流，按频率缩放以归一化
output = output * maxN/N;           %可选：随滚降增大重新缩放以获得更大输出

function out = phasor(normfreq, samples);
out = mod( (0:samples-1)*normfreq , 1);
out = out * 2 - 1;                  %转为双极性
