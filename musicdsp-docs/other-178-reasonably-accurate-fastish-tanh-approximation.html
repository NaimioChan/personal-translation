精度尚可、速度较快的 tanh 近似

  • 作者或来源：Fuzzpilz
  • 创建时间：2004-08-17 22:56:29

相当显然，但也许还不够显然，因为我在这里的代码片段中见过对 tanh() 的调用。

基本上就是这个：

tanh(x) = sinh(x)/cosh(x)
= (exp(x) - exp(-x))/(exp(x) + exp(-x))
= (exp(2x) - 1)/(exp(2x) + 1)

把它与一个比通常略不精确的 exp 近似结合起来（下面我用三阶泰勒近似），就成了。对波形整形很有用。

关于 exp 近似的说明：

它只对 x 以上的输入值正常工作，但由于 tanh 是奇函数，这不成问题。

exp(x) = 1 + x + x^2/(2!) + x^3/(3!) + ...

把泰勒级数在第三项后截断，得到

1 + x + x^2/2 + x^3/6。

可以用下面这个省掉一些乘法

6 + x * (6 + x * (3 + x))

代价是需要除以 6，但它被并入 tanh 部分的加法里：

(a/6 - 1)/(a/6 + 1) = (a - 6)/(a + 6)。

精度：

我没有非常仔细地研究，但它总是 <= 真实 tanh（x<0 时 >=），最大偏差出现在约 +/- 1.46 处，结果约为正确值的 .95 倍。

即使你为指数使用更好的近似，甚至直接调用 exp，这仍然比 tanh 快。
大概还有别的办法改进其中某些部分；当然，如果你要用它，你会想弄清自己的具体应用有没有额外的简化空间，但这是个不错的起点。

/* 单精度绝对值，比 fabsf() 快得多（若使用 MSVC++ 6 Standard——其他实现可能没这么慢） */
float sabs(float a)
{
int b=(*((int *)(&a)))&0x7FFFFFFF;
return *((float *)(&b));
}

/* 近似的是 tanh(x/2) 而非 tanh(x)——视你的用法而定，修正这一点很可能只是白白多一次乘法（不过影响不大，也可以在 sabs 中用一次整数加法完成）  */
float tanh2(float x)
{
float a=sabs(x);
a=6+a*(6+a*(3+a));
return ((x<0)?-1:1)*(a-6)/(a+6); /* 除了使用 <，也可以直接检查符号位是否置位（((*((int *)(&x)))&0x80000000)），但并不值得这么做 */
}

Here it is (this one does NOT assume a premultiplied x)..

plain code:

function Tanh2(x:Single):Single;
var   a,b:Single;
begin
x:=x*2;
a:=abs(x);
b:=(6+a*(3+a));
Result:=(x*b)/(a*b+12);
end;


asm:

function Tanh22(x:Single):Single;

      c6  :Single=6;
      c12 :Single=12;
      Mul2:Single=2;

        FLD     x
        FMUL    Mul2
        FLD     ST(0)
        FABS                 // a
        FLD     c3
        FADD    ST(0),ST(1)
        FMUL    ST(0),ST(1)
        FADD    c6           // b
        FMUL    ST(2),ST(0)  // x*b
        FMULP   ST(1),ST(0)  // a*b
        FADD    c12
        FDIVP   ST(1),ST(0)
