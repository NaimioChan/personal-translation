折返失真

  • 作者或来源：ed.bpu@eriflleh
  • 类型：失真
  • 创建时间：2005-05-28 19:11:06

一个简单的折返失真滤波器。
如果信号超过给定的阈值电平，它就在正/负阈值边界处镜像折返，直到信号落回合法范围（-threshold..+threshold）内。
没有范围限制，所以输入不必在 -1..+1 范围内。
threshold 应大于 0。
视用途而定（低阈值时），把输入重新缩放到满幅度是有意义的。

它大致执行以下代码
（只是没有循环）

while (in>threshold || in<-threshold)
{
  // 在正阈值处镜像
  if (in>threshold) in= threshold - (in-threshold);
  // 在负阈值处镜像
  if (in<-threshold) in= -threshold + (-threshold-in);
}
float foldback(float in, float threshold)
{
  if (in>threshold || in<-threshold)
  {
    in= fabs(fabs(fmod(in - threshold, threshold*4)) - threshold*2) - threshold;
  }
  return in;
}
