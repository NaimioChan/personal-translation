晶体管差分放大器仿真

  • 作者或来源：ed.luosfosruoivas@naitsirhC
  • 类型：波形整形器
  • 创建时间：2004-08-09 07:46:11

在准备电子元件考试时，我学到了几个用于仿真这类东西的方程。其中一个简化方程就是差分放大器的 tanh(x) 公式。它并不精确，但由于放大器只被小幅度驱动，其行为通常甚至相当线性。
放大器是差分的，这意味着二次项被消除，所以声音也类似电子管。
为了极快的速度，这段代码用纯汇编语言编写（尚未用 SSE 代码优化），在 VST 插件中运行非常快。
代码用 Delphi 写成。如果你想翻译汇编代码，应当知道参数是通过寄存器传递的：pinp=EAX，pout=EDX，sf=ECX。

procedure Transistor(pinp,pout : PSingle; sf:Integer; Faktor: Single);
asm
 fld Faktor
@Start:
 fld [eax].single
 fmul st(0),st(1)

 fldl2e
 fmul
 fld st(0)
 frndint
 fsub st(1),st
 fxch st(1)
 f2xm1
 fld1
 fadd
 fscale     { result := z * 2**i }
 fstp st(1)

 fld st(0)
 fmulp

 fld st(0)
 fld1
 faddp
 fld1
 fsubp st(2),st(0)
 fdivp

 fstp [edx].single

 add eax,4
 add edx,4
 loop    @Start
 fstp st(0)
end;
