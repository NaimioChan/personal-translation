三阶样条插值

  • 作者或来源：Dave from Muon Software, originally from Josh Scholar
  • 创建时间：2002-01-17 03:14:54

（摘自 Joshua Scholar 关于样条插值的一般性讨论……）
根据采样理论，完美的插值可以这样得到：把每个样本替换为以该样本为中心的 sinc 函数，在目标奈奎斯特频率上振铃，然后在每个目标点把所有来自源中每个点的 sinc 函数贡献相加。
Sinc 函数的振铃衰减得非常慢，所以每个目标样本都需要来自一大片邻域源样本的贡献。幸运的是，根据定义 sinc 函数是带限的，所以一旦源信号针对目标奈奎斯特频率做了预滤波，并相对目标奈奎斯特频率有合理的过采样，普通插值技术就相当有效，尽管如果没过采样它们会相当没用。

我们想要的插值例程至少应具备以下特性：

1. 显然它要连续。但由于对信号做有限差分（我不太了解真正的微分）相当于一个每倍频程只衰减约 6 dB 的低频衰减器，高阶导数的连续性也很重要。

2. 它必须足够“硬”，以便在过采样漏掉峰值时找到它们。这就是我所说的 sinc 函数有限带宽与过采样结合使插值成为可能所起的作用。

我读过一些关于样条的论文，但大多数样条内容与图形学有关，使用控制点描述，与我们要做的插值完全无关。读这些东西时，我很快得出结论：

1. 样条只是由多项式组成的分段函数，设计成在过渡点具有某种高阶连续性。

2. 样条高度任意，因为你可以在每个过渡点选择任意导数（任意阶）。当然，你指定的阶数越高，多项式阶数就越高。

3. 我对多项式的了解已经足够构造任何样条。一条穿过 'n' 个点、在 'm[1]' 个点指定一阶导数、在 'm[2]' 个点指定二阶导数等的多项式，将是 n-1+m[1]+m[2]…… 阶多项式。

构造三阶样条的一种方法（诚然对构造更高阶样条没有帮助）是在两条抛物线之间做线性插值。在每个点（称为结点）上，有一条穿过该点、前一点和后一点的抛物线。在每个点之间，对各个点的多项式做线性插值。这也许能帮你想象样条。

作为起点，我为每个结点使用穿过 5 个点的多项式，并用 MuPad（一个类似 Mathematica 的免费程序）推导出一条穿过两个点（结点）的多项式，使它在每个点上具有与穿过周围 5 个点的四阶多项式相同的前两阶导数。我的直觉是，基于穿过 3 个点的多项式，邻域不够大，无法获得良好的连续性。测试时我发现，基于 5 点多边形的效果远好于基于 3 点的，而 7 点的效果几乎和 3 点一样差。5 点似乎是个甜点。

不过，我本可以把导数设为几乎任意值——基于穿过周围点的多项式来取值只是一个猜测。

我读到过，采样理论的数学对 sinc 函数有另一种解释：你可以通过构造一条穿过每个点、阶数与点数相同的多项式来上采样，这会给出与 sinc 函数插值相同的答案（但只有点数无限多时才完美收敛）。你现在大概头都晕了——提这一点的唯一目的是指出，完美插值的“硬度”恰好等同于一条穿过目标点、阶数与目标点数相同的多项式。

//在 L0 与 H0 之间插值，取前一点（L1）与后一点（H1）
points into account
inline float ThirdInterp(const float x,const float L1,const float L0,const
float H0,const float H1)
{
    return
    L0 +
    .5f*
    x*(H0-L1 +
       x*(H0 + L0*(-2) + L1 +
          x*( (H0 - L0)*9 + (L1 - H1)*3 +
             x*((L0 - H0)*15 + (H1 -  L1)*5 +
                x*((H0 - L0)*6 + (L1 - H1)*2 )))));
}

The samples being interpolated represent the wave amplitude at a particular instant of time, T - an impulse train. So each sample is the amplitude at T=0,1,2,3 etc.

The purpose of interpolation is to determine the amplitude, a, for an arbitrary t, where t is any real number:

   p1      p0  a   n0      n1
   :       :   :   :       :
   0-------1---t---2-------3------> T
           :   :
           :   : 
           <-x->

x = t - T(p0)
