非规格化数防止器

  • 作者或来源：eb.tenyks@didid
  • 创建时间：2006-08-05 16:37:20

因为我仍然看到有人给信号加噪声或偏移来避免缓慢的非规格化，所以这里给出一段代码，改为把（接近）极小的数清零。

为什么清零更好？因为完全静音的号好过一点偏移或噪声。宿主或效果器可以检测静音信号，并以安全的方式选择不处理它们。
再加上，加偏移或噪声能消除大量非规格化，但仍有残留。
另外，截断正是 DAZ（Denormals Are Zero）SSE 标志所做的事。

这段代码使用整数比较和一条 CMOV，所以需要 Pentium Pro 或更高。没必要做 SSE 版本，因为如果你有 SSE 代码，大概已经在用 DAZ 标志了（但我建议插件不要乱动 SSE 标志，因为宿主很可能已经打开了 DAZ）。这是给 FPU 代码用的。应该比糟糕的 FPU 比较快得多。

Den_Thres 是你的阈值，它本身不能是非规格化数（那没有意义）。函数是 Delphi 的，如果你想移植，只需确保 EAX 是缓冲区、EDX 是长度（Delphi 寄存器调用约定——与 C++ 不同）。

const  Den_Thres:Single=1/$1000000;

procedure PrevFPUDen_Buffer(Buffer:Pointer;Length:Integer);
asm
    PUSH  ESI
    PUSH  EDI
    PUSH  EBX

    MOV   ECX,EDX
    LEA   EDI,[EAX+4*ECX]
    NEG   ECX
    MOV   EDX,Den_Thres
    SHL   EDX,1
    XOR   ESI,ESI

    @Loop:
    MOV   EAX,[EDI+4*ECX]
    LEA   EBX,[EAX*2]
    CMP   EBX,EDX
    CMOVB EAX,ESI
    MOV   [EDI+4*ECX],EAX

    INC   ECX
    JNZ   @Loop

    POP   EBX
    POP   EDI
    POP   ESI
End;

You can zero out denormals by adding and subtracting a small number. 

void kill_denormal_by_quantization(float &val)
{
  static const float anti_denormal = 1e-18;
  val += anti_denormal;
  val -= anti_denormal;
}

Reference: Laurent de Soras' great article on denormal numbers:
ldesoras.free.fr/doc/articles/denormal-en.pdf

I tend to add DC because it is faster than quantization. A slight DC offset (0.000000000000000001) won't hurt. That's -360 decibels...
