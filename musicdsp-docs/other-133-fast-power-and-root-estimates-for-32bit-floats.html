32 位浮点的快速幂与根估计

  • 作者或来源：ed.bew@raebybot
  • 类型：浮点函数
  • 创建时间：2002-12-18 21:07:27

原始代码由 Stefan Stenzel 编写（也在这个存档里，见“pow(x,4) 近似”）——为更大的灵活性做了扩展。

fastpow(f,n) 给出浮点数 f 的整数 n 次幂的相当*粗糙*的估计（y=f^n）。它很快，但结果可能偏差不小，因为我们直接动了浮点指数。-> 只在需要粗略估计、精度不太重要时使用。

fastroot(f,n) 给出 f 的 n 次方根。精度方面同样如此。

//C/C++ 源代码：
float fastpower(float f,int n)
{
 long *lp,l;
 lp=(long*)(&f);
 l=*lp;l-=0x3F800000l;l<<=(n-1);l+=0x3F800000l;
 *lp=l;
 return f;
}

float fastroot(float f,int n)
{
 long *lp,l;
 lp=(long*)(&f);
 l=*lp;l-=0x3F800000l;l>>=(n-1);l+=0x3F800000l;
 *lp=l;
 return f;
}

//Delphi/Pascal 源代码：
function fastpower(i:single;n:integer):single;
var l:longint;
begin
 l:=longint((@i)^);
 l:=l-$3F800000;l:=l shl (n-1);l:=l+$3F800000;
 result:=single((@l)^);
end;

function fastroot(i:single;n:integer):single;
var l:longint;
begin
 l:=longint((@i)^);
 l:=l-$3F800000;l:=l shr (n-1);l:=l+$3F800000;
 result:=single((@l)^);
end;
