简单压缩器类（C++）

  • 作者或来源：Citizen Chunk
  • 类型：立体声、前馈、峰值压缩器
  • 创建时间：2005-05-28 19:11:42
  • 关联文件：simpleSource.zip

如今似乎人人都想做一个自己的压缩器插件，但很少有人知道从哪开始。在 KVR 开发论坛回答了太多问题之后，我想干脆贴一些可直接使用的 C++ 源码好了。

这是一个简单立体声峰值压缩器的 C++ 实现。它采用前馈拓扑，在增益衰减之前检测侧链电平。侧链检测整流后的峰值电平，并做立体声联动以保持声像。起音/释音使用 EnvelopeDetector 类（发布在“分析”部分）。

注意：
- 处理开始前务必调用 initRuntime()（即在 resume() 中调用）。
- process 函数接受立体声输入。
- 设置压缩器参数时，VST 参数必须映射到实用范围。（例如不要试图 setAttack( 0.f )。）
