正弦计算

  • 作者或来源：Phil Burk
  • 类型：波形生成，sin() 的泰勒近似
  • 创建时间：2002-01-17 00:57:01

来自 JSyn 的代码，实现基于泰勒展开的正弦波发生器。它不如滤波器方法高效，但具有线性频率控制，因此适合 FM 或其他需要精确频率的时变应用。生成的正弦至少精确到 16 位。

for(i=0; i < nSamples ; i++)
{
  //生成锯齿相位累加器，为正弦生成提供相位
  IncrementWrapPhase(phase, freqPtr[i]);
  //将相位折回结果更精确的区间

  if(phase > 0.5)
    yp = 1.0 - phase;
  else
  {
    if(phase < -0.5)
       yp = -1.0 - phase;
    else
        yp = phase;
  }

  x = yp * PI;
  x2 = x*x;

  //泰勒展开至 x**9/9!，分解为乘加运算
  fastsin = x*(x2*(x2*(x2*(x2*(1.0/362880.0)
            - (1.0/5040.0))
            + (1.0/120.0))
            - (1.0/6.0))
            + 1.0);

  outPtr[i] = fastsin * amplPtr[i];
}
