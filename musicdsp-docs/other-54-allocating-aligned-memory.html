分配对齐内存

  • 作者或来源：Benno Senoner
  • 类型：内存分配
  • 创建时间：2002-01-17 03:08:46

分配内存区域时，我们最多浪费 align_size + sizeof(int) 字节。
我们把 aligned_ptr - unaligned_ptr 的差值存在对齐区域之前的一个 int 里。
free() 例程需要这个，因为我们要释放全部内存，而不只是对齐区域。
用 aligned_malloc() 分配的内存必须用 aligned_free() 释放！

/* align_size 必须是 2 的幂！！ */
void *aligned_malloc(size_t size, size_t align_size) {

  char *ptr,*ptr2,*aligned_ptr;
  int align_mask = align_size - 1;

  ptr=(char *)malloc(size + align_size + sizeof(int));
  if(ptr==NULL) return(NULL);

  ptr2 = ptr + sizeof(int);
  aligned_ptr = ptr2 + (align_size - ((size_t)ptr2 & align_mask));


  ptr2 = aligned_ptr - sizeof(int);
  *((int *)ptr2)=(int)(aligned_ptr - ptr);

  return(aligned_ptr);
}

void aligned_free(void *ptr) {

  int *ptr2=(int *)ptr - 1;
  ptr -= *ptr2;
  free(ptr);
}
