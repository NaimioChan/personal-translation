廉价伪正弦 LFO

  • 作者或来源：moc.regnimmu@regnimmuf
  • 创建时间：2004-04-07 09:39:28

虽然代码用标准 C++ 写成，但这个算法其实更适合 DSP，因为那里可以利用乘加指令，而且所需的相位累加器很容易通过给计数器做掩码来实现。

它提供一种相当廉价的近似正弦波形，作为 LFO 足够好了。

// x 应介于 -1.0 与 1.0 之间
inline
double pseudo_sine(double x)
{
    // Compute 2*(x^2-1.0)^2-1.0
    x *= x; 
    x -= 1.0;
    x *= x;
    // 以下几行将范围变换到 -1.0 与 1.0 之间。
   // 如果 0.0 到 1.0 的范围可以接受或更合适
   // （例如在调制延迟线中），则可以节省一些指令周期。
    x *= 2.0;
    x -= 1.0;
}
