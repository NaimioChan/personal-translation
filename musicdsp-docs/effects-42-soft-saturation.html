软饱和

  • 作者或来源：Bram de Jong
  • 类型：波形整形器
  • 创建时间：2002-01-17 02:18:37

这只对 x 的正值有效。a 应在 0..1 范围内。

x <= a:
  f(x) = x
x > a:
  f(x) = a + (x-a)/(1+((x-a)/(1-a))^2)
x > 1:
  f(x) = (a+1)/2

2006-08-23 06:19:05 · moc.liamg@ubibik

Substituting x=1 into equation 2 (taking many steps)

f(x) = a + (x-a)/(1+ ((x-a)/(1-a))^2)
     = a + (1-a)/(1+ ((1-a)/(1-a))^2)
     = a + (1-a)/(1+ 1^2)
     = a + (1-a)/2
     = 2a/2 + (1-a)/2
     = (2a + 1 - a) /2
     = (a+1) / 2

2006-08-24 11:03:04 · musicdsp@Nospam dsparsons.co.uk

You can normalise the output:
f(x)'=f(x)*(1/((a+1)/2))

This gives a nice variable shaper with smooth curve upto clipping at 0dBFS
