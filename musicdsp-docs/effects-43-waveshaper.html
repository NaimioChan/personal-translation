波形整形器

  • 作者或来源：Jon Watte
  • 类型：波形整形器
  • 创建时间：2002-01-17 02:19:17

我的一个最爱是改用 sin() 函数。
如果做到极端，它会有个“不幸”的副作用：去掉奇次谐波——三角波会被映射成纯正弦波。
当 a 从大约 .1 变到 5 甚至更大时，这都有效！
a = 0 的数学极限实际上会让它在那一点变成线性函数，但不幸的是 FPU 并不擅长微积分 :-) 一旦 a 超过 1，除了“软”波形整形之外，你还会开始得到削波。不过这时它更像效果器，而不是母带工具了 :-)

由于这些只是各种形式的波形整形，你也可以全用查找表来做。在我的版本里，那就能去掉有点昂贵的 sin() 函数。

(input: a == "overdrive amount")

z = M_PI * a;
s = 1/sin(z)
b = 1/a

if (x > b)
  f(x) = 1
else
  f(x) = sin(z*x)*s
