使用 MinBLEPS 的波形发生器

  • 作者或来源：ku.oc.nomed.nafgpr@ekcol
  • 创建时间：2002-08-05 18:44:50
  • 关联文件：MinBLEPS.zip

使用 MinBLEPS 的带限锯齿/方波（含 PWM）发生器的 C 代码与 MSVC6 工程文件。

本代码基于 Eli 的 MATLAB MinBLEP 代码，并使用他原始的 minblep.mat 文件。它不维护所有活动 MinBLEP 的列表，而是把每个 MinBLEP 的输出存入缓冲区，后续所有 MinBLEP 与波形输出都在其中相加。这一优化使其快到可以实时使用。

在高频扫描时会产生轻微混叠。我不知道 Eli 的原始代码是否也如此，因为我没有 MATLAB。任何帮助都欢迎。

工程名为 “hardsync”，因为用 MinBLEPS 很容易生成硬同步。
