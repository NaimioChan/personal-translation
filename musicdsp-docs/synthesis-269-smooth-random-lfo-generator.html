平滑随机 LFO 发生器

  • 作者或来源：Rob Belcham
  • 创建时间：2009-06-30 08:31:24

我找一种适合调制延迟线的随机 LFO 已经很久了（例如用于合唱/混响调制），自己写了一个之后，觉得应该把它作为我对 music-dsp 社区的首次贡献。

我的目标是得到一种基于正弦、随机但平滑的波形，频率控制没有不连续，并保持在 -1:1 范围内。听上去很像布朗噪声，或者风穿过麦克风（例如 rate = 100Hz 时）。

它写成了 Matlab 的 m 函数，移植到 C 应该不难。

振荡器生成一个随机电平的阶梯波形，每一级停留的时间随机（在界限内）。这些电平之间做线性插值，用来驱动正弦波的频率。为了实现幅度变化，每次过零时生成一个新的随机幅度缩放因子，幅度系数以简单的指数方式渐变到该值。

一个调用示例：
t = 4; Fs = 44100;
y = random_lfo(100, t*Fs, Fs);
axis([0, t*Fs, -1, 1]);
plot(y)

玩得开心！

% 随机 LFO 生成器
% 生成无间断的随机正弦波形
%   rate = 平均速率，单位 Hz
%   N = 运行长度（采样点数）
%   Fs = 采样频率，单位 Hz
function y = random_lfo(rate, N, Fs)

step_freq_scale = Fs / (1*rate); 
min_Cn = 0.1 * step_freq_scale;
An = 0;
lastA = 0;
Astep = 0; 
y = zeros(1,N); % 输出
x = 0;  % 正弦相位
lastSign = 0;
amp_scale = 0.6;
new_amp_scale = 0.6;
amp_scale_ramp = exp(1000/Fs)-1;
for (n=1:N)
    if (An == 0) || (An>=Cn)
        % 生成新的随机频率缩放因子
        Cn = floor(step_freq_scale * rand());
        % 限幅以防止快速跳变
        Cn = max(Cn, min_Cn);
        % 生成新值 & 步进系数
        newA = 0.1 + 0.9*rand();
        Astep = (newA - lastA) / Cn;
        A = lastA;
        lastA = newA;
        % 重置计数器
        An = 0;
    end
    An = An + 1;
    % 生成输出
    y(n) = sin(x) * amp_scale;
    % 斜坡幅度 
    amp_scale = amp_scale + ( new_amp_scale - amp_scale ) * amp_scale_ramp;
    sin_inc = 2*pi*rate*A/Fs;
    A = A + Astep;
    % 相位递增 
    x = x + sin_inc;
    if (x >= 2*pi)
        x = x - 2*pi;
    end
    % 在每个过零点缩放
    if (sign(y(n)) ~= 0) && (sign(y(n)) ~= lastSign)
        lastSign = sign(y(n));
        new_amp_scale = 0.25 + 0.75*rand();
    end;
end;
