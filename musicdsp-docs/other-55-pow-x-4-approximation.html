Pow(x,4) 近似

  • 作者或来源：Stefan Stenzel
  • 创建时间：2002-01-17 03:09:20

非常 hack，但通过修改指数与尾数给出 x**4 的粗略估计。

float p4fast(float in)
{
  long *lp,l;

  lp=(long *)(&in);
  l=*lp;

  l-=0x3F800000l; /* 去除偏置 */
  l<<=2;          /* **4 */
  l+=0x3F800000l; /* 加偏置 */
  *lp=l;

  /* 由于使用了 & 运算符，编译器将从内存读取 */
  return in;
}
