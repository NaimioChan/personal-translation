Moog VCF 变体 1

  • 作者或来源：CSound source code, Stilson/Smith CCRMA paper., Paul Kellett version
  • 类型：24dB 谐振低通
  • 创建时间：2002-01-17 02:03:52

第二行 “q =” 以前用的是 exp()——我不确定我做的有没有更快，但这一行本来就需要琢磨，因为它决定哪些频率会自激。
我觉得可以调整得比现在更好听。

高通 / 带通：

它们只有 6dB/oct，但听起来仍然有音乐性——24dB/oct 低通那种“多汁”的声音保留了下来。

// Moog 24 dB/oct 共振低通 VCF
// 参考：CSound 源码、Stilson/Smith CCRMA 论文。
// 由 paul.kellett@maxim.abel.co.uk 于 2000 年 7 月修改

  float f, p, q;             //滤波器系数
  float b0, b1, b2, b3, b4;  //滤波器缓冲区（当心非正规数！）
  float t1, t2;              //临时缓冲区

// 根据频率与共振 [0.0...1.0] 设置系数

  q = 1.0f - frequency;
  p = frequency + 0.8f * frequency * q;
  f = p + p - 1.0f;
  q = resonance * (1.0f + 0.5f * q * (1.0f - q + 5.6f * q * q));

// Filter (in [-1.0...+1.0])

  in -= q * b4;                          //反馈
  t1 = b1;  b1 = (in + b0) * p - b1 * f;
  t2 = b2;  b2 = (b1 + t1) * p - b2 * f;
  t1 = b3;  b3 = (b2 + t2) * p - b3 * f;
            b4 = (b3 + t1) * p - b4 * f;
  b4 = b4 - b4 * b4 * b4 * 0.166667f;    //削波
  b0 = in;

// 低通输出：  b4
// 高通输出：  in - b4;
// 带通输出：  3.0f * (b3 - b4);
