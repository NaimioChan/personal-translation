混响延时时间计算

  • 作者或来源：Andy Mucho
  • 创建时间：2002-01-17 02:19:54

这来自我前阵子随手记下的一些笔记，主题是自动计算扩散延时。给定初始延迟线增益和时间，为 numlines 条延迟线计算各延时时间与反馈增益……

int   numlines = 8;
float t1 = 50.0;        // d0 时间
float g1 = 0.75;        // d0 增益
float rev = -3*t1 / log10 (g1);

for (int n = 0; n < numlines; ++n)
{
  float dt = t1 / pow (2, (float (n) / numlines));
  float g = pow (10, -((3*dt) / rev));
  printf ("d%d t=%.3f g=%.3f\n", n, dt, g);
}

/*
上述参数取 t1=50.0、g1=0.75 时得到：

 d0 t=50.000 g=0.750
 d1 t=45.850 g=0.768
 d2 t=42.045 g=0.785
 d3 t=38.555 g=0.801
 d4 t=35.355 g=0.816
 d5 t=32.421 g=0.830
 d6 t=29.730 g=0.843
 d7 t=27.263 g=0.855

若想更扩散，可在反馈路径中加入带一个周期延迟的双反馈路径，
相当于在反馈路径里造出一个移相器，
这样会更有意思。不过最佳相移量该取多少，
我现在还说不准。
*/
