恶意样本的解药

  • 作者或来源：moc.eh-u@sru
  • 类型：过滤非规格化数、NaN、无穷大
  • 创建时间：2005-03-24 00:32:54

处理样本时可能发生很多意外。一个讨厌的情况是非规格化，它会让 CPU 在最简单的指令上消耗多得离谱的周期。

但更糟的是，如果递归结构中出现 NaN 或无穷大，也许是因为除以零，那么之后所有与这些值相乘的样本都会被“感染”，变成 NaN 或无穷大。你的声音“BLIPPP”一下，然后就没别的了，音箱一片寂静。

因此我写了一个小函数，把所有这些情况都设为 0.0f。

你会注意到我把 float 缓冲区当作无符号整数处理，并利用比较结果 0 或 1 来避免分支。

用 GCC 编译时，这个函数不应产生任何“隐藏”分支，但你还是应该检查汇编代码。有时候加些括号就能奏效……

;) Urs

#ifndef UInt32
#define UInt32 unsigned int
#endif

void erase_All_NaNs_Infinities_And_Denormals( float* inSamples, int& inNumberOfSamples )
{
	UInt32* inArrayOfFloats = (UInt32*) inSamples;

	for ( int i = 0; i < inNumberOfSamples; i++ )
	{
		UInt32 sample = *inArrayOfFloats;
		UInt32 exponent = sample & 0x7F800000;

			// exponent < 0x7F800000 时，若为 NaN 或 Infinity 则为 0，否则为 1
			// exponent > 0 时，若为非规格化数则为 0，否则为 1

		int aNaN = exponent < 0x7F800000;
		int aDen = exponent > 0;

		*inArrayOfFloats++ = sample * ( aNaN & aDen );

	}
}
