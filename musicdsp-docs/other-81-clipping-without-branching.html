无分支削波

  • 作者或来源：Laurent de Soras (moc.ecrofmho@tnerual)
  • 类型：最小值、最大值与削波
  • 创建时间：2004-04-07 09:35:57

对小数值可能会降低精度。也就是说，如果钳制到 [-1; 1]，结果的小数部分会被量化到 23 位（或更多，取决于临时结果的位深）。因此，1e-20 会被舍入为 0。另一个（正面的）副作用是消除非规格化数。

float max (float x, float a)
{
   x -= a;
   x += fabs (x);
   x *= 0.5;
   x += a;
   return (x);
}

float min (float x, float b)
{
   x = b - x;
   x += fabs (x)
   x *= 0.5;
   x = b - x;
   return (x);
}

float clip (float x, float a, float b)
{
   x1 = fabs (x-a);
   x2 = fabs (x-b);
   x = x1 + (a+b);
   x -= x2;
   x *= 0.5;
   return (x);
}
