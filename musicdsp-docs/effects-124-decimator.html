这是一段简单的位深与采样率降低代码，也许有人用得上。参数是 bits（1..32）与 rate（0..1，1 表示原始采样率）。
这样调用函数：
y=decimate(x);

实现该算法的 VST 插件（包含完整的 Delphi 源码）可以从这里下载：
http://tobybear.phreque.com/decimator.zip

欢迎评论/建议/改进，请发送到：tobybear@web.de

// bits：1..32
// rate：0..1（1 为原始采样率）

********** Pascal source **********
var m:longint;
    y,cnt,rate:single;

// 首次调用 decimate() 之前， 
// 至少要调用一次本函数
procedure setparams(bits:integer;shrate:single);
begin
 m:=1 shl (bits-1);
 cnt:=1;
 rate:=shrate;
end;

function decimate(i:single):single;
begin
 cnt:=cnt+rate;
 if (cnt>1) then
 begin
  cnt:=cnt-1;
  y:=round(i*m)/m;
 end;
 result:=y;
end;
int bits=16;
float rate=0.5;

long int m=1<<(bits-1);
float y=0,cnt=0;

float decimate(float i)
{
 cnt+=rate;
 if (cnt>=1)
 {
  cnt-=1;
  y=(long int)(i*m)/(float)m;
 }
 return y;
}
