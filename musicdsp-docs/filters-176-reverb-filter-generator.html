混响滤波器生成器

  • 作者或来源：Stephen McGovern
  • 类型：FIR
  • 创建时间：2006-09-01 07:07:58

这是一个 MATLAB 函数，粗略计算房间的冲激响应。输出随后可与音频片段卷积，产生良好而真实的混响。我写过一篇论文讨论该算法使用的理论，见 http://stevem.us/rir.html。

注意：

1) N 取值大会占用大量内存。
2) 输出会按输出的最大值归一化。

function [h]=rir(fs, mic, n, r, rm, src);
%RIR   房间冲激响应。
%   [h] = RIR(FS, MIC, N, R, RM, SRC) 用镜像法
%         计算房间冲激响应。
%
%      FS  = 采样率。
%      MIC = 行向量，给出麦克风的
%            x、y、z 坐标。  
%      N   = 程序将计入 (2*N+1)3 个虚源。 
%      R   = 墙面反射系数，一般为 -1<R<1。
%      RM  = 行向量，给出房间的尺寸。  
%      SRC = 行向量，给出声源的 
%            x、y、z 坐标。
%
%   示例：
%
%      >>fs=44100;
%      >>mic=[19 18 1.6];
%      >>n=12;
%      >>r=0.3;
%      >>rm=[20 19 21];
%      >>src=[5 2 1];
%      >>h=rir(fs, mic, n, r, rm, src);
%
%   注意：
%
%   1) 所有距离单位为米。
%   2) 输出经过缩放，使输出向量 
%      绝对值的最大值等于一。
%   3) 要实现该滤波器，需要做快速 
%      卷积。FCONV.m 程序可完成此事。它可 
%      在 Mathworks File Exchange 找到，网址为
%      www.mathworks.com/matlabcentral/fileexchange/。也可 
%      在 www.2pi.us/code/fconv.m 找到。
%   4) 该模型已有论文发表，见：
%      www.2pi.us/rir.html
%      
%
%版本 3.4.1
%版权所有 Â© 2003 Stephen G. McGovern

%下面部分注释引用的是我论文中的公式。

nn=-n:1:n;                            % 序列的索引
rms=nn+0.5-0.5*(-1).^nn;              % 公式 2、3 & 4 的一部分
srcs=(-1).^(nn);                      % 公式 2、3 & 4 的一部分
xi=srcs*src(1)+rms*rm(1)-mic(1);      % 公式 2 
yj=srcs*src(2)+rms*rm(2)-mic(2);      % 公式 3 
zk=srcs*src(3)+rms*rm(3)-mic(3);      % 公式 4 

[i,j,k]=meshgrid(xi,yj,zk);           % 把向量转换为三维矩阵
d=sqrt(i.^2+j.^2+k.^2);               % 公式 5
time=round(fs*d/343)+1;               % 类似公式 6

[e,f,g]=meshgrid(nn, nn, nn);         % 把向量转换为三维矩阵
c=r.^(abs(e)+abs(f)+abs(g));          % 公式 9
e=c./d;                               % 等价于公式 10

h=full(sparse(time(:),1,e(:)));       % 等价于公式 11
h=h/max(abs(h));                      % 缩放输出
