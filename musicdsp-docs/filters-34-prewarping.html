预畸变

  • 作者或来源：robert bristow-johnson (better known as "rbj" )
  • 类型：说明
  • 创建时间：2002-01-17 02:10:26

预畸变就是识别出 BLT 引入的弯曲。
要确定频率响应，我们在 z=exp(j*w*T) 处计算数字 H(z)，在 s=j*W 处计算模拟 Ha(s)。下面将确认 jw 到单位圆的映射，并准确展示这个映射是什么（教科书里也是同样的内容）：

BLT 说：s = (2/T) * (z-1)/(z+1)

代入：s = j*W = (2/T) * (exp(j*w*T) - 1) / (exp(j*w*T) + 1)

j*W = (2/T) * (exp(j*w*T/2) - exp(-j*w*T/2)) / (exp(j*w*T/2) + exp(-j*w*T/2))

= (2/T) * (j*2*sin(w*T/2)) / (2*cos(w*T/2))

= j * (2/T) * tan(w*T/2)

或

模拟 W = (2/T) * tan(w*T/2)

所以当真实输入频率为 w 时，数字滤波器表现出的幅度增益与相移，等同于模拟滤波器在假设频率 W 处的表现。当 w*T 接近 pi（奈奎斯特）时，数字滤波器的行为就像 W -> inf 时的模拟滤波器。设计方程中你有多少自由度，就可以把模拟设计频率调到恰到好处，使确定性的 BLT 弯曲发生后，得到的弯曲频率正好正确。对于简单低通，你只有一个自由度：截止频率。你可以预先补偿它，让真正的截止频率正确，但也仅此而已；在截止频率以上，你会看到低通比同频率的等效模拟滤波器更快地跌向 -inf dB。
