简单倾斜均衡器

  • 作者或来源：moc.liamg@321tiloen
  • 类型：倾斜
  • 创建时间：2009-05-29 15:13:21

有几种实现方式。（分频、搁架、变形搁架 [hs->lp, ls->hp] ……等）
这一种试图模仿 “Elysia: mPressor” 压缩器中 “Niveau” 滤波器的行为。

[“Tilt”滤波器]：
它使用一个中心频率（F0），然后提升 F0 以上或以下的一个频段，同时对另一频段做相反的处理。

以 “mPressor” 为例——更极端的设置会把滤波器变成一阶低通或高通。这是通过让某个频段的增益因子接近 -1 实现的。（例如：+6db -> 低通；-6db -> 高通）

Lubomir I. Ivanov

//=======================
// tilt eq 设置
//
// srate -> 采样率
// f0 -> 20-20 kHz
// gain -> -6 / +6 dB
//=======================
amp = 6/log(2);
denorm = 10^-30;
pi = 22/7;
sr3 = 3*srate;

// 条件：
// gfactor 是比例增益
//
gfactor = 5;
if (gain > 0) {
    g1 = -gfactor*gain;
    g2 = gain;
} else {
    g1 = -gain;
    g2 = gfactor*gain;
};

//两个独立增益
lgain = exp(g1/amp)-1;
hgain = exp(g2/amp)-1;

//滤波器
omega = 2*pi*f0;
n = 1/(sr3 + omega);
a0 = 2*omega*n;
b1 = (sr3 - omega)*n;

//==================================
// 采样循环
// in -> 输入样本
// out -> 输出样本
//==================================
lp_out = a0*in + b1*lp_out;
out = in + lgain*lp_out + hgain*(in - lp_out);
