波形整形器（简述）

  • 作者或来源：Jon Watte
  • 类型：多项式；失真
  • 创建时间：2002-08-15 00:45:22

> 另一个问题：什么是“波形整形器”算法？它只是失真的另一种说法吗？

典型的“波形整形器”是某种函数，它接收输入样本值 X，并将其变换为输出样本 X'。典型实现是一张包含若干点的查找表，以及这些点之间的某种插值（比如三次插值）。人们说起波形整形器时，通常指的就是这个。注意，波形整形器与滤波器不同，它没有任何状态。X -> X' 的映射是无状态的。

有些波形整形器用多项式或其他数学函数实现。硬削波就是用 min() 和 max() 函数（或者三参数 clamp() 函数，本质相同）实现的波形整形器。一种非常柔和、有音乐性的失真用三次多项式实现，类似 X' = (3/2)X - (1/2)X^3。多项式波形整形器的好处是，你知道它能把带宽扩展到的最大程度就是它的阶数。因此，要确保三次多项式无混叠，需要 3 倍过采样。对于基于查找表的波形整形器，你无法知道这一点（除非把 N 点表当作 N 点多项式 :-)）。

float waveshape_distort( float in ) {
  return 1.5f * in - 0.5f * in *in * in;
}
