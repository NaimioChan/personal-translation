Moog VCF 变体 2

  • 作者或来源：CSound source code, Stilson/Smith CCRMA paper., Timo Tossavainen (?) version
  • 类型：24dB 谐振低通
  • 创建时间：2002-01-17 02:04:57

in[x] 与 out[x] 是成员变量，初始化为 0.0。控制量：

fc = 截止频率，近似线性 [0,1] -> [0, fs/2]
res = 谐振 [0, 4] -> [无谐振, 自激]
Tdouble MoogVCF::run(double input, double fc, double res)
{
  double f = fc * 1.16;
  double fb = res * (1.0 - 0.15 * f * f);
  input -= out4 * fb;
  input *= 0.35013 * (f*f)*(f*f);
  out1 = input + 0.3 * in1 + (1 - f) * out1; // 极点 1
  in1  = input;
  out2 = out1 + 0.3 * in2 + (1 - f) * out2;  // 极点 2
  in2  = out1;
  out3 = out2 + 0.3 * in3 + (1 - f) * out3;  // 极点 3
  in3  = out2;
  out4 = out3 + 0.3 * in4 + (1 - f) * out4;  // 极点 4
  in4  = out3;
  return out4;
}

2003-11-11 11:05:42 · ten.bjc.fieltednabpop@cnahoj

input is name of a variable with type double.

input -= out4 * fb;

is just a shorter way for writing:

input = input - out4 * fb;

and the *= operator is works similar:

input *= 0.35013 * (f*f)*(f*f);

is equal to

input = input * 0.35013 * (f*f)*(f*f);

/ Johan
