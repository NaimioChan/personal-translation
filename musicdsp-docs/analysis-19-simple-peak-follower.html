简单峰值跟随器

  • 作者或来源：Phil Burk
  • 类型：幅度分析
  • 创建时间：2002-01-17 01:57:19

这个简单的峰值跟随器会跟踪信号的峰值。输入上升时它快速上升，输入下降后它指数衰减。它可用于驱动 VU 表，或用于自动增益控制电路。

// halfLife = 冲击后输出衰减到一半值所需的时间（秒）

static float output = 0.0;

float scalar = pow( 0.5, 1.0/(halfLife * sampleRate)));

if( input < 0.0 )
  input = -input;  /* 取绝对值。 */

if ( input >= output )
{
   /* 遇到峰值时，跟随峰值升到顶端。 */
   output = input;
}
else
{
   /* 信号较弱时输出按指数衰减。 */
   output = output * scalar;
   /*
   ** 当 current 接近 0.0 时，将其置为 0.0，以避免浮点下溢
   ** 浮点下溢会引发大量中断，
   ** 从而导致性能严重下降。
   */
   if( output < VERY_SMALL_FLOAT ) output = 0.0;
}
