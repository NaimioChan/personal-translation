另一种廉价正弦 LFO

  • 作者或来源：moc.cinohp-e@ofni
  • 创建时间：2004-05-14 18:32:57

一个易于计算的 LFO 伪代码。

把两个相位不同的这种输出相减，甚至能做出粗糙的三角波。

PJ

r = the rate 0..1

--------------
p += r
if(p > 1) p -= 2;
out = p*(1-abs(p));
--------------

if (phase1>1) phase1 -= 2;

if (phase2>1) phase2 -= 2;

out = (phase1*(1-abs(phase1)) - phase2*(1-abs(phase2))) * 10;

2006-08-03 10:25:10 · uh.etle.fni@yfoocs

A better way of making a triangle LFO (out range is -1..1):

rate = 0..1;
p = -1;
{
    p += rate;
    if (p>1) p -= 4.0f;
    out = abs(-(abs(p)-2))-1;
}
