带限波形……

  • 作者或来源：Paul Kellet
  • 创建时间：2002-01-17 00:56:04

（摘自 Paul 的邮件）

下面是另一种基于 sinc 函数串的波形生成方法（实际上是在 t=0 到 t=period/2 之间沿一条 sinc 交替循环）。

代码对脉冲串加直流偏置后积分，得到锯齿波，但其他波形也可以用通常的办法做出来……注意在很高或很低的频率下可能需要调整 'dc' 与 'leak'。

我不知道这有多原创（我该多读点东西），但它的质量可用，尤其是在低频。用 sinc 查表，或者截断/加窗的 sinc，也许还有优化余地？

我认为把 'dp' 微调到略小于 1，让各条 sinc 整齐衔接，应该可以最小化混叠，但我还没找到最好的做法。欢迎任何意见。

float p=0.0f;      //当前位置
float dp=1.0f;     //每个采样点的位置增量
float pmax;        //最大位置
float x;           //sinc 函数中的位置
float leak=0.995f; //泄漏积分器
float dc;          //直流偏移
float saw;         //输出


//设置频率……

  pmax = 0.5f * getSampleRate() / freqHz;
  dc = -0.498f/pmax;


//对每个采样点……

  p += dp;
  if(p < 0.0f)
  {
    p = -p;
    dp = -dp;
  }
  else if(p > pmax)
  {
    p = pmax + pmax - p;
    dp = -dp;
  }

  x= pi * p;
  if(x < 0.00001f)
     x=0.00001f; //避免除以 0

  saw = leak*saw + dc + (float)sin(x)/(x);
