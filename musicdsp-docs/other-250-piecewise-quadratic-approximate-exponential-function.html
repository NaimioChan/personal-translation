分段二次近似指数函数

  • 作者或来源：Johannes M.-R.
  • 类型：以 2 为底指数函数的近似
  • 创建时间：2007-06-18 08:09:58

代码假定为向零舍入模式，以及 IEEE 754 浮点。
要实现其他底数，把输入乘以该底数的以 2 为底对数。

inline float fpow2(const float y)
{
	union
	{
		float f;
		int i;
	} c;

	int integer = (int)y;
	if(y < 0)
		integer = integer-1;

	float frac = y - (float)integer;

	c.i = (integer+127) << 23;
	c.f *= 0.33977f*frac*frac + (1.0f-0.33977f)*frac + 1.0f;

	return c.f;
}
