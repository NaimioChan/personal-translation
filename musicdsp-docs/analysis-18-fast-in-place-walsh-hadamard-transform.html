快速原位 Walsh-Hadamard 变换

  • 作者或来源：Timo H Tossavainen
  • 类型：小波变换
  • 创建时间：2002-01-17 01:54:52

如果我没记错，它们也叫 Walsh-Hadamard 变换。
基本上类似傅里叶，但基函数是不同序的方波。
这是我前阵子做变换数据压缩研究时写的。
下面是一些对 long int 做原位 Walsh-Hadamard 变换的代码（要除以 n 才是变换结果），我记得输出顺序是位反转的。
逆变换与正变换相同（期望输入为位反转顺序）。
即 x = 1/n * FWHT(FWHT(x))（x 是向量）。

void inline wht_bfly (long& a, long& b)
{
        long tmp = a;
        a += b;
        b = tmp - b;
}

// 整数 log2 运算
int inline l2 (long x)
{
        int l2;
        for (l2 = 0; x > 0; x >>=1)
        {
                ++ l2;
        }

        return (l2);
}

////////////////////////////////////////////
// 快速原地 Walsh-Hadamard 变换           //
////////////////////////////////////////////

void FWHT (std::vector& data)
{
  const int log2 = l2 (data.size()) - 1;
  for (int i = 0; i < log2; ++i)
  {
    for (int j = 0; j < (1 << log2); j += 1 << (i+1))
    {
       for (int k = 0; k < (1<<i); ++k)
       {
           wht_bfly (data [j + k], data [j + k + (1<<i)]);
       }
    }
  }
}
