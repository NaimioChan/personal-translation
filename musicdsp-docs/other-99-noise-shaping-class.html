噪声整形类

  • 作者或来源：ude.anaidni@iehsc
  • 类型：九阶噪声整形抖动
  • 创建时间：2002-04-23 06:49:06
  • 关联文件：NS9dither16.h

这是一个九阶噪声整形与抖动类的实现，运行相当快（它有一个函数使用 Intel x86 汇编，但如果你在非 Intel 平台上运行，可以换成别的舍入函数）。_aligned_malloc 与 _aligned_free 需要 MSVC++ Processor Pack，可从 www.microsoft.com 获取。你可以用 “new” 与 “delete” 替换它们，但分配对齐内存似乎能让它跑得更快。另外，如果你不用 Win32，可以把 ZeroMemory 换成把内存置 0 的 memset。
输入应为 -32768 到 32767 的浮点数（processS 会在这些点为你削波，但当你试图把浮点转成 short 时，削波是不好的）。给审阅者的备注——把代码放在 NSDither.h 之类的文件里并给出链接可能更好——它相当长。

Great class! But I found one more mistake: function my_mod(9, 9) gives 9 instead of 0 (9 % 9 = 0). 

HistPos = my_mod((HistPos+8), order);
EH[HistPos+9] = EH[HistPos] = output - samp;

 -> HistPos + 9 = 18 (max EH index is 17) which leads to out of array boundary and crash.

So my_mod should look like:

__inline my_mod(int x, int n)
{
    if(x >= n) x-=n;
    return x;
}
