漂移发生器

  • 作者或来源：ti.oohay@odrasotniuq
  • 类型：随机
  • 创建时间：2004-09-23 16:07:34

我用这个漂移来调制合成器的任意声音参数。
如果让它轻微调制 FM 调制器的幅度或频率，效果非常明显。
它基于一个经过正弦弯曲的增量随机变量。
我喜欢它，因为它是“连续的”（与“采样保持”相对），而且我可以设置变化速率和最大变化量。
它可以向上或向下到达约束（+/- 最大漂移），但在接近极限时会逐渐降低变化速率。
我完全把它当 LFO 用（-1.f .. +1.f）。
我用查表代替 sin() 函数，因为这样可以更换曲线（不同的表），从而改变随机分布……

希望我说清楚了……（叹气…… :-)）
再见！！！
附：谢谢你们之前对我投稿的帮助 ;-)

const int kSamples //下方 fSinTable 的采样点数
float fSinTable[kSamples] // 查表 sin() [0 - 2pi[，幅度 [-1.f .. 1.f]
float fWhere// 索引
float fRate // 最大变化速率
float fLimit //最大值或最小值
float fDrift // 输出
