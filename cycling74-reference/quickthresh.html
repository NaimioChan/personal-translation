quickthresh

快速和弦检测

描述

把在时间上挨得很近收到的数字合并起来。quickthresh 是 thresh 的更快、低延迟的替代品，针对和弦检测做了优化。

参数

threshold [number] ms 可选

基本阈值时间，单位为毫秒；在这段时间内收到的所有音符。基本阈值的默认值为 40 ms。

fudge [number] ms 可选

"fudge" 时间，单位为毫秒 —— 若在基本阈值时间结束时，有任何音符在这段时间内演奏，阈值就会延长。若未提供，默认值为 10 ms。

extension [number] ms 可选

阈值延长时间，单位为毫秒。这是必要时在第一个参数上额外增加的一段时间，用于把额外的音符（由于演奏不整齐）收入列表。默认值为 20 ms。

消息

bang

bang 会重置 quickthresh 并输出其缓冲区中的音符。

int

在一定时间阈值内出现的传入取值会被存储并作为列表输出。时间阈值的工作方式请参见参数说明。

参数：

  • input [int]

(inlet1)

设置基本阈值时间的毫秒值。在这段时间内在左入口收到的所有取值都会收集到一个列表中。

参数：

  • threshold [int]

(inlet2)

设置 "fudge" 时间，单位为毫秒。若在基本阈值时间结束时，有任何传入取值落在这段时间内，阈值就会延长，以便把更多取值加入列表。

参数：

  • fudge [int]

(inlet3)

第四个入口：设置阈值延长时间，单位为毫秒。这是对基本阈值时间的延长，当取值在 "fudge" 时间区域内到达对象的入口时使用。

参数：

  • extension [int]

float

左入口：在一定时间阈值内出现的传入取值会被存储并作为列表输出。时间阈值的工作方式请参见各参数的说明。

参数：

  • input [float]

(inlet1)

第二个入口：设置基本阈值时间的毫秒值。在这段时间内在左入口收到的所有取值都会收集到一个列表中。

参数：

  • threshold [float]

(inlet2)

第三个入口：设置 "fudge" 时间，单位为毫秒。若在基本阈值时间结束时，有任何传入取值落在这段时间内，阈值就会延长，以便把更多取值加入列表。

参数：

  • fudge [float]

(inlet3)

第四个入口：设置阈值延长时间，单位为毫秒。这是对基本阈值时间的延长，当取值在 "fudge" 时间区域内到达对象的入口时使用。

参数：

  • extension [float]

set

set 一词后面跟三个毫秒值，可用于设置三个阈值参数取值（基本阈值时间、"fudge" 时间和阈值延长时间）。

参数：

  • threshold [int]
  • fudge [int]
  • extension [int]

输出

float

当 quickthresh 用尽其阈值时间后，凡是在该时间阈值内演奏的传入取值都会作为列表输出。
