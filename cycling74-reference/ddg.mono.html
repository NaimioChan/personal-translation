Max for Live

ddg.mono

用于虚拟合成器的单音合成控制器

描述

ddg.mono 在 Max 中为虚拟单音合成器提供 MIDI 消息处理。它实现了最后/最高/最低音符优先，以及连奏/重触发乐句处理。

参数

note priority [int] 可选

0 - 2 范围内可选的一个整数参数可用来指定音符优先。模式设置为：

mode 0（retrigger）：每次按键都重触发（默认）。
mode 1（legato）：当有音符按住时，新音符忽略力度。
mode 2（laststep）：只在最后一个音符上发送 noteoff 消息。

特性

legatomode [atom_long]

设置连奏模式。
可选值：

0 = 'Retrigger'（重触发模式）
每次按键都重触发（默认）。

1 = 'Legato'（连奏模式）
当有音符按住时，新音符忽略力度。

2 = 'Last Step'

mode [atom_long]

设置音符优先模式。
可选值：

0 = 'Last Note'
1 = 'High Note'
2 = 'Low Note'

消息

int

第一个入口：该数字被当作 MIDI note-on 消息的音高值处理。所收到数字及其对应力度值的输出取决于 mode 特性和触发模式（用 legato 或 retrig 消息设置）。

第二个入口：该数字被存储为力度值，以便与左入口收到的音高数字配对。

参数：

  • MIDI-note-value [int]

(inlet1)

右入口：该数字被存储为一个力度值，用来与左入口收到的音高数字配对。

参数：

  • MIDI-velocity-value [int]

clear

clear 消息会发送一条 note-off 消息，以停止当前正在播放的所有音符。

laststep

laststep 消息会使 ddg.mono 对象为最后演奏的音符发送一条 note-off 消息。

legato

legato 消息会使 ddg.mono 对象只在新音符演奏时才送出输出。

retrig

retrig 消息会使 ddg.mono 对象在每次按键时送出输出（即重触发此前演奏过的音符）。
