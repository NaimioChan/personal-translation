mpeparse

解析原始 MPE MIDI 数据

描述

把原始多维复音表情（MPE）MIDI 字节分离成标准的消息类型。

参数

无。

特性

hires [int] : 0

hires 特性用于支持高分辨率弯音缩放。当该特性设为 0 时，mpeparse 会接受并输出标准 MIDI 范围 0 到 127 的弯音整数值。当该特性设为 1 时，它接受高分辨率 MIDI 数据，并输出 -1 到 1 范围内的浮点值。当该特性设为 2 时，它接受高分辨率 MIDI 数据，并输出 -8192 到 8191 范围内的整数值（标准 14 位 MIDI 高分辨率弯音范围）。
可选值：

0 = 'Off (0-127)' （ 标准 8 位 MIDI 弯音范围（默认） ）
1 = 'Float (-1 to 1)' （ 使用音频信号范围内的弯音消息 ）
2 = '14-bit Fixed (-8192 to 8191)' （ 标准 14 位 MIDI 高分辨率弯音范围 ）

index [int] : 0

设置 mpeparse 只在指定的声部号（1 到 15）上输出。

strict [int] : 0

强制 MPE 作用域

消息

bang

清除 mpeparse 对象对到此刻为止收到的任何不完整 MPE MIDI 消息的记忆。

int

入口收到的数字被当作一条 MIDI 消息的字节处理（通常来自 midiin 或 polymidiin 对象）。状态字节决定用哪个出口输出数据字节。

参数：

  • byte [int]

float

转换为 int。

参数：

  • byte [float]

mpeevent

'mpeevent' 一词后面跟 6 个整数，分别指定区域首个通道、区域索引、声部号、通道号、MIDI 消息号和数据。

参数：

  • MPE-messages [list]

输出

int

第四个出口：该数字是一个音色变更值。

第五个出口：该数字是一个触后（通道压力）值。

第六个出口：该数字是一个弯音值。

第七个出口：该数字是声部号（若为全局则为 -1）。

第八个出口：该数字是区域首个通道。

第九个出口：该数字是区域索引（若为全局则为 -1）。

list

最左出口：一条 note-on/note-off 消息。第一个数字是音高值，第二个数字是力度值。

第二个出口：一条复音按键压力消息。第一个数字是触后（压力）值，第二个数字是音高值（音符号）。

第三个出口：一条控制消息。第一个数字是控制值，第二个数字是控制器编号。

list

最右出口：MPE 事件消息。MPE 事件消息是一个列表，由符号 mpeevent 以及 6 个整数组成，这些整数分别指定区域首个通道、区域索引、声部号、通道号、MIDI 消息号和数据。该消息可以发送给封装在 poly~ 对象中的补丁，使用 polymidiin 对象。
