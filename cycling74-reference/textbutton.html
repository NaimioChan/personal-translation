Max

textbutton

带文字的按钮

参数

无。

特性

active [int] : 1

当激活模式设为 0 时，textbutton 对象不会响应鼠标点击，且对象会变灰。该特性默认启用。

align [atom] renamed

设置文字的对齐方式。

annotation_name [symbol] :

信息视图标题

bgcolor [4 floats]

以 RGBA 格式设置按钮处于 "off" 状态时 textbutton 对象的背景颜色。

bgoncolor [4 floats]

以 RGBA 格式设置按钮处于 "on" 状态时 textbutton 对象的背景颜色。

blinktime [int] : 150

指定 textbutton 对象被点击或收到 bang 消息时闪烁的持续时间（单位：毫秒）。

fontlink [int] : 0

切换是否把按钮大小设为当前选定的字体大小与字符宽度。

legacytextcolor [int] : 0 >= 7.0.0

切换文字的遗留行为，以及是否为 "off" 状态选择文字颜色。off 状态的文字颜色通过 textcolor 特性设置。

mode [int] : 0

设置按钮模式。
可选值：

0 = 'Button'
1 = 'Toggle'

outputmode [int] : 1

设置输出模式。输出模式有：

0：鼠标按下时送出输出
1：鼠标抬起时送出输出（默认）
可选值：

0 = 'Mouse down'
1 = 'Mouse up'

param_connect [symbol] :

在对象与具有参数的兼容对象（如 gen~ 或 jit.gl.slab）的某个参数之间建立双向连接。该对象可用来改变参数的值，参数值变化时它也会随之更新。设置 param_connect 最简便的方法，是使用该特性在 inspector 中的菜单，或使用 Object Action 菜单的 Connect 子菜单。菜单会列出兼容对象的所有可用参数。

用消息设置 param_connect 特性时，需要给出目标参数的路径，即宿主对象的脚本名后跟两个冒号，再加上参数名。例如，对于一个 gen~ 对象，若其脚本名为 gen~_AB，则 freq 参数的路径为 gen~_AB::freq。可以在宿主对象或参数尚不存在时就为 param_connect 设值，该对象会在参数出现后与之建立连接。更多细节请参阅用户指南中 param_connect 条目。

parameter_enable [int]

启用后，该对象可与 Max for Live Parameters 以及 Max 中的初始参数值设置配合使用。

parameter_mappable [int] : 1

启用 parameter_mappable 后，该对象即可通过映射功能映射到键盘或 MIDI 输入。（默认值 = 1）。

rounded [float] : 0.

设置让 textbutton 形状圆角化所用的像素量。

spacing_x [float] : 4.

设置 textbutton 对象的水平间距（单位：像素）。

spacing_y [float] : 4.

设置 textbutton 对象的垂直间距（单位：像素）。

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

text [symbol] : Button

设置按钮标签，并在 mode 设为 1（切换）时设置 "off" 状态标签。未设置参数时，按钮标签会被清除。

textcolor [4 floats]

以 RGBA 格式设置按钮处于 "off" 状态时 textbutton 对象的文字颜色。textcolor 特性映射到 accentcolor 样式颜色。

texton [symbol] : Button On

处于 "on" 状态时的按钮标签。未设置参数时，按钮标签会被清除。

textoncolor [4 floats]

以 RGBA 格式设置按钮处于 "on" 状态时 textbutton 对象的文字颜色。textoncolor 特性映射到 color 样式颜色。

textovercolor [4 floats]

以 RGBA 格式设置鼠标悬停时、按钮处于 "off" 状态下 textbutton 对象的文字颜色。textovercolor 特性映射到 selectioncolor 样式颜色。

tosymbol [int] : 1

以单个符号输出文字

truncate [int] : 1

设置文字截断模式。对齐模式有：

0：不截断
1：从右侧截断（例如 abcdef...。这是默认值。
2：从中间截断（例如 abcd...wxyz
可选值：

0 = 'No truncation'
1 = 'Truncate from the right'
2 = 'Truncate from the middle'

underline [int] : 0

单词 underline 后面跟 0 或 1，切换 textbutton 对象中文字的下划线。默认值为 0（无下划线）。

usebgoncolor [int] : 0 >= 7.0.0

切换是否使用背景 "on" 颜色。

usegradient [int] : 1

启用时，按钮背景以渐变绘制。禁用时，背景以纯色绘制。无论 usegradient 取哪种设置，背景都会使用 bgcolor 特性绘制。

usetextovercolor [int] : 0 >= 7.0.0

切换鼠标悬停在文字上时是否使用不同的颜色。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

行为取决于当前的 mode 设置。

mode 0（按钮）：bang 消息会重新触发对象的输出。

mode 1（触发）：bang 消息会切换对象的状态并触发输出。

int

若 mode 特性设为 0（按钮），会从左出口送出一个 bang，并把 text 消息显示出来、从中间出口送出。

若 mode 特性设为 1（切换），且数字输入为 1，则 textbutton 被设为 'on'，从左出口送出 1，并把 texton 消息显示出来、从中间出口送出。
若数字输入为 0，则 textbutton 被设为 'off'，从左出口送出 0，并把 text 消息显示出来、从中间出口送出。

参数：

  • input [int]

float

float 消息会被转换为 int。用法见 int 条目。

参数：

  • input [float]

(mouse)

若 mode 特性设为 0（按钮），用鼠标点击 textbutton 时，只要按住鼠标它就会保持高亮；按下鼠标键时会从左出口送出一个 bang，松开鼠标键时再从左出口送出另一个 bang。鼠标点击时按钮文字也会从中间出口送出。

若 mode 特性设为 1（切换），且切换的初始状态为 0，则 textbutton 被设为 'on'，从左出口送出 1，并把 texton 消息显示出来、从中间出口送出。
若切换的初始状态为 1，则 textbutton 被设为 'off'，从左出口送出 0，并把 text 消息显示出来、从中间出口送出。

set

若 mode 特性设为 1（切换），set 消息会切换 on 或 off 状态，而不从任何出口送出任何内容。单词 set 后面跟任何非零数字，会把切换状态设为 on；set 0 则把它设为 off。

参数：

  • set-input [int]

setsymbol

若 mode 特性设为 1（切换），单词 setsymbol 后面跟 texton 或 text 符号，会让 textbutton 显示该符号，但不会产生任何输出。该符号区分大小写。

参数：

  • button-text-item [list]

symbol

若 mode 特性设为 1（切换），单词 symbol 后面跟 texton 或 text 符号，会让 textbutton 显示该符号、切换到切换状态，并触发相应的输出。

参数：

  • button-text-item [list]
