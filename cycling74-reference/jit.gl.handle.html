Jitter

jit.gl.handle

Use mouse movement to control position/rotation

描述

jit.gl.handle responds to mouse clicks and drags in the destination by generating rotate and position messages out its left outlet.

讨论

When the context is being drawn to a jit.window or jit.pwindow, jit.gl.handle responds to mouse clicks and drags in the destination by generating rotate and position messages out its left outlet. When these messages are sent to 3D objects, the objects can then be rotated and moved in space using the mouse.

If the messages from jit.gl.handle are sent directly to jit.gl.render, mouse motion has the effect of moving and rotating the entire 3D space defined by the renderer. In this setup, the inherit_transform attribute should be set to 1, so that the jit.gl.handle object does not move within the world as well. While mouse input is present, the jit.gl.handle is drawn as circles around a sphere on the x, y, and z axes. Clicking and dragging on the sphere rotates connected objects. Dragging with the command key held moves the objects along the xy plane relative to the camera. Dragging with the option key held moves the objects towards and away from the camera.

This OB3D object optionally takes one argument: the name of a drawing context. This is a named instance of a jit.world, or jit.pworld object, or a jit.gl.node sub-context. This value may also be set via the OB3D drawto attribute. If no argument is present, the object is implicitly added to the first valid drawing context or sub-context found in the current patch or by searching up the patcher hierarchy.

特性

auto_handle [int]

Enable/disable auto handle mode. When enabled the handle will perform mouse picking to select 3D objects under the mouse. This mode is enabled by default when the jit.gl.handle left inlet is unconnected.

auto_rotate [int]

Continue spinning along last rotation when no UI input is present (default = 0)

auto_time [int]

The time between automatic rotations for auto_rotate (default = 0)

filters [10 symbols]

Specify a list of filterclass names that can be picked when auto_handle is enabled (default = all). Possible values include all and default. Additional values include any user-specified filterclass names (maximum allowed = 10).

fixed_delta [float] >= 9.0.0

Locks the delta time value used when animating, in seconds (default = 0). When non-zero, updates are calculated using this value, rather than the actual time between frames. Useful for non realtime frame capture. If non-zero will override that of the bound jit.world fixed_delta value.

hilite_color [4 floats]

Set the hilite color, used when select_mode is hilite (default = 1. 1. 0. 1.).

hover [int]

Enable/disable mouse hovering (default = 0).

radius [float]

The radius of control sphere in 3D world (default = 1.0)

rgb_axes [int]

Sphere axis color flag (default = 1) When the flag is set, the sphere axes are drawn in RGB colors, Otherwise, the color attribute determines the color used.

select_mode [symbol]

Set the selection mode to use when auto_handle = 1 (default = none).
Possible values:

'none'
'bounds'
'wireframe'
'hilite'
'depth'

tracking [float]

The rotation amount relative to amount of mouse movement (default = 1.)

ui_priority [int]

UI priority value (default = -700). When multiple UI objects are listening to the same window, ui_priority determines the order objects receive input. Lower values test first.

visible [int]

Visibility flag (default = 1) When the flag is set, the sphere axes are visible in the 3D world.

OB3D 特性

anim [symbol]

处理该实例所有空间变换的 jit.anim.node 对象的名称（默认值 = UID）。默认值引用一个内部对象，但可以把它设为某个已存在的外部 jit.anim.node 实例的名称来覆盖。这样可以更高级地控制空间变换。

anchor [3 floats]

局部空间中的锚点位置（默认值 = 0. 0. 0.）。用于偏移应用变换所围绕的局部 3D 原点。

animmode [symbol]

决定 anim_move 与 anim_turn 消息在哪个空间中影响该对象的位置和朝向（默认值 = parent）。
local = 相对局部轴旋转
parent = 相对父级轴旋转
world = 相对世界轴旋转

antialias [int]

抗锯齿标志（默认值 = 0）在某些硬件上，必须同时启用 blend_enable 特性，抗锯齿才会生效。

aux_color [4 floats]

辅助颜色，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

axes [int]

x/y/z 轴渲染关/开（默认值 = 0）

cull_face [int]

面剔除模式（默认值 = 0（不剔除））
0 = 不剔除
1 = 剔除背面
2 = 剔除正面

depth_clear [int]

深度缓冲清除标志（默认值 = 0）该标志置位时，渲染对象之前会清除深度缓冲。

depth_enable [int]

深度缓冲标志（默认值 = 1）该标志置位时，启用深度缓冲。

depth_write [int]

深度写入标志（默认值 = 1）。该标志置位时，启用对深度缓冲的写入。若 depth_enable 已关闭，则此设置无效。

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

line_width [float]

绘制线的宽度（默认值 = 1.）

name [symbol]

实例名称（默认值 = UID）

point_mode [symbol]

启用 points 绘图图元（poly_mode 2）时使用的点绘制模式（默认值 = circle）。
可选值：

'square' ( 把点绘制为方形 )
'circle' ( 把点绘制为圆形 )
'square_depth' ( 把点绘制为带深度缩放的方形 )
'circle_depth' ( 把点绘制为带深度缩放的圆形 )
'user_shader' ( 允许在自定义顶点着色器中写入 gl_PointSize )

point_size [float]

绘制点的大小（默认值 = 1.）

poly_mode [2 ints]

多边形渲染模式（默认值 0 0）渲染模式以 frontface backface 的形式给出。支持的渲染模式有：
0 = 渲染为填充多边形
1 = 渲染为线
2 = 渲染为点

position [3 floats]

3D 原点，形式为 x y z（默认值 = 0. 0. 0.）

quat [4 floats]

当前旋转的四元数表示（默认值 = 0. 0. 0. 1.）。四元数是一种数学构造，它是一个四维向量，可以看作绕任意轴的旋转。四元数是 3D 空间中朝向的一种有用表示。

rotate [4 floats]

旋转角度以及绕其进行旋转的 xyz 向量，形式为 rotation-angle x y z（默认值 = 0. 0. 0. 1.）

rotatexyz [3 floats]

把当前旋转设为绕 x、y、z 正轴旋转的复合，也称为欧拉角（默认值 = 0. 0. 0.）。默认顺序为 yzx，可用 jit.gl.render 的 rotate_order 特性更改。角度以度为单位。

scale [3 floats]

3D 缩放系数，形式为 x y z（默认值 = 1. 1. 1.）

smooth_shading [int]

平滑着色标志（默认值 = 0）该标志置位时，渲染时使用平滑着色。

transform_reset [int]

模型视图与投影变换重置标志（默认值 = 0）该标志置位时，渲染对象之前会把模型视图变换与投影变换设为单位变换。这适用于精灵或公告板叠加，或按窗口大小自动缩放。transform_reset 标志的模式有：
0 = 不做任何事（默认值）
1 = 等比正交 glOrtho(-aspect, aspect, -1.0, 1.0, near_clip, far_clip);
2 = 归一化正交 glOrtho(-1.0, 1.0, -1.0, 1.0, near_clip, far_clip);
3 = 近裁剪面为 0.001 的等比透视 gluPerspective(lens_angle, aspect, 0.001/*near_clip*/, far_clip);
4 = 近裁剪面为 0.001 的归一化透视 gluPerspective(lens_angle, 1.0, 0.001/*near_clip*/, far_clip);

viewalign [int]

视图对齐变换标志（默认值 = 0）
