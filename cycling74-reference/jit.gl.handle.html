jit.gl.handle

用鼠标移动来控制位置/旋转

描述

jit.gl.handle 会响应目标窗口中的鼠标点击与拖拽，从左出口送出 rotate 与 position 消息。

讨论

当上下文绘制到 jit.window 或 jit.pwindow 时，jit.gl.handle 会响应目标窗口中的鼠标点击与拖拽，从左出口送出 rotate 与 position 消息。把这些消息送给 3D 对象后，就可以用鼠标在空间中旋转和移动这些对象。

如果把 jit.gl.handle 的消息直接送给 jit.gl.render，鼠标移动的效果就是移动并旋转渲染器所定义的整个 3D 空间。这种用法下，应把 inherit_transform 特性设为 1，这样 jit.gl.handle 对象本身就不会在世界中跟着移动。存在鼠标输入时，jit.gl.handle 会绘制成位于 x、y、z 轴上、环绕一个球体的若干圆圈。在球体上点击并拖拽会旋转与之相连的对象。按住 command 键拖拽会沿相对于摄像机的 xy 平面移动对象。按住 option 键拖拽会让对象朝向或远离摄像机移动。

这个 OB3D 对象可选地接受一个参数：绘制上下文的名称。它就是一个 jit.world、jit.pworld 对象或 jit.gl.node 子上下文的具名实例。该值也可以通过 OB3D 的 drawto 特性设置。若没有给出参数，对象会被隐式加入当前补丁中找到的第一个有效绘制上下文或子上下文，或者沿补丁层级向上搜索找到的第一个。

特性

auto_handle [int]

启用/禁用自动手柄模式。启用后，手柄会执行鼠标拾取，以选中鼠标下方的 3D 对象。当 jit.gl.handle 的左入口未连接时，该模式默认启用。

auto_rotate [int]

在没有 UI 输入时按上一次的旋转持续自转（默认值 = 0）

auto_time [int]

auto_rotate 两次自动旋转之间的时间间隔（默认值 = 0）

filters [10 symbols]

指定启用 auto_handle 时可以拾取的 filterclass 名称列表（默认值 = all）。可选值包括 all 和 default。其他取值包括任何用户指定的 filterclass 名称（最多允许 10 个）。

fixed_delta [float] >= 9.0.0

锁定动画时所用的 delta time 取值，以秒为单位（默认值 = 0）。非零时，更新会用该取值来计算，而不是用帧之间的实际时间。用于非实时帧捕获很有用。若非零，会覆盖所绑定的 jit.world 的 fixed_delta 取值。

hilite_color [4 floats]

设置高亮颜色，在 select_mode 为 hilite 时使用（默认值 = 1. 1. 0. 1.）。

hover [int]

启用/禁用鼠标悬停（默认值 = 0）。

radius [float]

3D 世界中控制球体的半径（默认值 = 1.0）

rgb_axes [int]

球体坐标轴颜色标志（默认值 = 1）。设置该标志时，球体的各坐标轴以 RGB 颜色绘制；否则由 color 特性决定所用的颜色。

select_mode [symbol]

设置 auto_handle = 1 时要使用的选择模式（默认值 = none）。
可选值：

'none'
'bounds'
'wireframe'
'hilite'
'depth'

tracking [float]

相对于鼠标移动量的旋转量（默认值 = 1.）

ui_priority [int]

UI 优先级取值（默认值 = -700）。当多个 UI 对象监听同一个窗口时，ui_priority 决定对象接收输入的顺序。取值越小越先测试。

visible [int]

可见性标志（默认值 = 1）。设置该标志时，球体的各坐标轴在 3D 世界中可见。

OB3D 特性

anim [symbol]

处理该实例所有空间变换的 jit.anim.node 对象的名称（默认值 = UID）。默认值引用一个内部对象，但可以把它设为某个已存在的外部 jit.anim.node 实例的名称来覆盖。这样可以更高级地控制空间变换。

anchor [3 floats]

局部空间中的锚点位置（默认值 = 0. 0. 0.）。用于偏移应用变换所围绕的局部 3D 原点。

animmode [symbol]

决定 anim_move 与 anim_turn 消息在哪个空间中影响该对象的位置和朝向（默认值 = parent）。
local = 相对局部轴旋转
parent = 相对父级轴旋转
world = 相对世界轴旋转

antialias [int]

抗锯齿标志（默认值 = 0）在某些硬件上，必须同时启用 blend_enable 特性，抗锯齿才会生效。

aux_color [4 floats]

辅助颜色，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

axes [int]

x/y/z 轴渲染关/开（默认值 = 0）

cull_face [int]

面剔除模式（默认值 = 0（不剔除））
0 = 不剔除
1 = 剔除背面
2 = 剔除正面

depth_clear [int]

深度缓冲清除标志（默认值 = 0）该标志置位时，渲染对象之前会清除深度缓冲。

depth_enable [int]

深度缓冲标志（默认值 = 1）该标志置位时，启用深度缓冲。

depth_write [int]

深度写入标志（默认值 = 1）。该标志置位时，启用对深度缓冲的写入。若 depth_enable 已关闭，则此设置无效。

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

line_width [float]

绘制线的宽度（默认值 = 1.）

name [symbol]

实例名称（默认值 = UID）

point_mode [symbol]

启用 points 绘图图元（poly_mode 2）时使用的点绘制模式（默认值 = circle）。
可选值：

'square' ( 把点绘制为方形 )
'circle' ( 把点绘制为圆形 )
'square_depth' ( 把点绘制为带深度缩放的方形 )
'circle_depth' ( 把点绘制为带深度缩放的圆形 )
'user_shader' ( 允许在自定义顶点着色器中写入 gl_PointSize )

point_size [float]

绘制点的大小（默认值 = 1.）

poly_mode [2 ints]

多边形渲染模式（默认值 0 0）渲染模式以 frontface backface 的形式给出。支持的渲染模式有：
0 = 渲染为填充多边形
1 = 渲染为线
2 = 渲染为点

position [3 floats]

3D 原点，形式为 x y z（默认值 = 0. 0. 0.）

quat [4 floats]

当前旋转的四元数表示（默认值 = 0. 0. 0. 1.）。四元数是一种数学构造，它是一个四维向量，可以看作绕任意轴的旋转。四元数是 3D 空间中朝向的一种有用表示。

rotate [4 floats]

旋转角度以及绕其进行旋转的 xyz 向量，形式为 rotation-angle x y z（默认值 = 0. 0. 0. 1.）

rotatexyz [3 floats]

把当前旋转设为绕 x、y、z 正轴旋转的复合，也称为欧拉角（默认值 = 0. 0. 0.）。默认顺序为 yzx，可用 jit.gl.render 的 rotate_order 特性更改。角度以度为单位。

scale [3 floats]

3D 缩放系数，形式为 x y z（默认值 = 1. 1. 1.）

smooth_shading [int]

平滑着色标志（默认值 = 0）该标志置位时，渲染时使用平滑着色。

transform_reset [int]

模型视图与投影变换重置标志（默认值 = 0）该标志置位时，渲染对象之前会把模型视图变换与投影变换设为单位变换。这适用于精灵或公告板叠加，或按窗口大小自动缩放。transform_reset 标志的模式有：
0 = 不做任何事（默认值）
1 = 等比正交 glOrtho(-aspect, aspect, -1.0, 1.0, near_clip, far_clip);
2 = 归一化正交 glOrtho(-1.0, 1.0, -1.0, 1.0, near_clip, far_clip);
3 = 近裁剪面为 0.001 的等比透视 gluPerspective(lens_angle, aspect, 0.001/*near_clip*/, far_clip);
4 = 近裁剪面为 0.001 的归一化透视 gluPerspective(lens_angle, 1.0, 0.001/*near_clip*/, far_clip);

viewalign [int]

视图对齐变换标志（默认值 = 0）

消息

reset

把 jit.gl.handle 及与之相连的对象恢复到最初的观察原点，并撤销所有旋转。

OB3D 消息

bang

等价于 draw 消息。

draw

在具名的绘制目标中绘制该对象。若支持 matrixoutput 特性且其设为 1，几何矩阵会从对象的左出口送出。

drawraw

等价于 draw，且 inherit_all 特性设为 1。

drawimmediate

等价于 draw，但忽略任何可能的渲染器设置

anim_move

沿给定的轴移动对象，参照 animmode 所指示的空间。

参数：

  • x [float]
  • y [float]
  • z [float]

anim_turn

按给定的量沿各轴旋转对象，参照 animmode 所指示的空间。

参数：

  • x [float]
  • y [float]
  • z [float]

anim_grow

按给定的量沿各轴缩放对象。

参数：

  • x [float]
  • y [float]
  • z [float]

anim_reset

把局部变换特性重置为默认值（position = 0 0 0、rotatexyz = 0 0 0、scale = 1 1 1）

update_node
