expr

求值数学表达式

描述

用类 C 语言求值一个表达式。使用变量和运算符来产生输出值。

讨论

用 expr 对象执行采用 C 语言风格数学运算的数学计算。该对象对使用 "变量" $i1-$i9（第 1 至第 9 个入口，按整数取用）、$f1-$f9（各入口按浮点数取用）和 $s1-$s9（各入口按符号取用）以及/或者同类型常量的表达式进行求值。运算符有 +、-、*、/、&、|、&&、||、!、~ 和 ^，此外还可以使用一组预定义的数学与统计函数。expr 中的函数列表如下：min、max、int（转换为整数）、float（转换为浮点数）、pow（幂）、sqrt（平方根）、exp（e 的 x 次幂）、log10（对数）、ln（自然对数）、log（自然对数）、sin、cos、tan、asin（反正弦）、acos、atan、atan2、sinh、cosh、tanh、fact（阶乘）、random、noise、round、floor、ceil、size（表的大小）、sum（表内容之和）、Sum（带边界求和）、avg（表内容平均值）、Avg（带边界平均值）、store（存入表）。

参数

expression [list] 可选

expr 对象的参数是一个数学表达式，由数字、算术运算符（如 + 或 *）、比较（如 < 或 >）、C 函数（如 min () 或 pow ()）、table 对象的名称，以及对应入口收到的 int、float 和符号的可变参数（$i、$f 和 $s）组成。

constant [number] 可选

数字可以在数学表达式中用作常量。

inlet-format [symbol] 可选

用于指定与某个入口关联的数据格式的可变参数，由数据类型（$i 或 $f）和入口编号组合而成（例如 $i2）。该参数会被指定入口收到的数字替换。

table-info [$s] 可选

指定从表中访问数据的可变参数，用参数 $s 和一个入口编号来描述，该编号会被替换为要访问的 table 的名称。该参数后面应紧跟一个带方括号的数字，用来指定 table 中的地址。（示例：$s2[7] 或 $s3[$i1]。）

(other) [symbol] 可选

expr 对象理解以下算术运算符：+、-、*、/、%。其他运算符有 ~（按位取反）、^（按位异或）、&、&&、|、|| 和 !（非）。

list

左入口收到的列表的各项会被当作各自来自不同的入口，并对表达式进行求值。若列表中的项少于入口数，其余各个入口中最近收到的值会被使用。以上任一消息在左入口出现都会对表达式求值并从出口送出结果。若某个可变参数从未收到过值，该值在表达式求值时被视为 0。入口数由输入的可变参数个数决定。入口数最多为 9 个。
