Ableton DSP

abl.device.echo~

调制延迟

描述

一种调制延迟效果，可以分别为两条独立的延迟线设置延迟时间，同时还能控制包络与滤波器调制。

参数

无。

特性

channel_mode [int]

设置通道模式。
可选值：

0 = 'Stereo'
1 = 'Ping-pong'
2 = 'Mid/Side'

clip [int]

把输入增益同样施加到干信号上，从而可以产生失真，带来真实的硬件手感。

delay [2 floats]

设置左、右通道的延迟时间，单位为秒。[0.001, 5.]

drywetmode [int]

设置处理后信号与干信号的平衡方式。
可选值：

0 = 'Linear' ( Linear )
使用线性干/湿混合

1 = 'Equal-loudness' ( Equal-loudness )
让 50/50 的混合对大多数信号听上去响度相同

duck [int]

启用后，只要有输入信号，湿信号就会被按比例降低。

duck_release [float]

设置闪避释放时间，单位为秒。[0.02, 1.5]

duck_threshold [float]

设置闪避阈值，单位为 dB。[-60., 0.]

fbinvert [int]

启用/禁用把反馈信号取反后再加回输入。对较短的延迟时间而言，这会显著改变声音。

feedback [float]

设置各通道输出被送回到其输入的反馈量。[0., 1.5]

gate [int]

启用/禁用输出门。

gate_release [float]

设置门释放时间，单位为秒。[0.05, 3.]

gate_threshold [float]

设置门阈值，单位为 dB。[-60., 0.]

input [float]

设置输入增益，单位为 dB。[-40., 40.]

mix [float]

设置输出信号的干/湿比。[0., 1.]

mod_delay [float]

调整施加到延迟时间上的调制量。[0., 1.]

mod_envelope [float]

在调制振荡器与包络跟随器之间混合。[0., 1.]

mod_freq [float]

设置调制振荡器的频率，单位为 Hz。[0.01, 40.]

mod_mult [int]

启用/禁用把延迟时间调制深度放大四倍。在较短的延迟时间下，这会产生很深的镶边声音。

mod_phase [float]

调整左、右通道波形之间的偏移量。在 180 度时，两个通道会完全反相。[0., 180.]

mod_waveform [int]

设置调制波形。
可选值：

0 = 'Sine'
1 = 'Triangle'
2 = 'Saw up'
3 = 'Saw down'
4 = 'Square'
5 = 'Random'

noise [float]

设置添加到信号上的噪声量。[0., 1.]

noise_morph [float]

在不同类型的噪声之间变形。[0., 1.]

output [float]

设置输出增益，单位为 dB。[-76., 12.]

repitch [int]

这会在改变延迟时间时造成音高变化，类似硬件延迟设备的行为。禁用时，改变延迟时间会在新、旧延迟时间之间做交叉淡化。

repitch_smoothing_time [float]

调整改变延迟时间时新的音高变化被应用的速度。[0.01, 1.]

reverb [float]

设置混响量。[0., 1.]

reverb_decay [float]

设置混响尾音的长度。[0., 1.]

reverb_location [int]

设置混响被加入处理链中的位置。
可选值：

0 = 'Pre' ( Pre )
延迟之前

1 = 'Post' ( Post )
延迟之后

2 = 'Feedback' ( Feedback )
位于延迟反馈环路之内

width [float]

设置湿信号的立体声宽度。0 会得到单声道信号，而 1 到 2 的取值会形成加宽的立体声全景。[0., 2.]

wobble [float]

设置添加到信号上的晃动量。这会给延迟时间加入不规则的调制，模拟磁带延迟。[0., 1.]

wobble_morph [float]

在不同类型的晃动调制之间变形。[0., 1.]

ins [symbol]

声明额外的入口，用于以事件速率或信号速率控制 float 类型的特性。已映射到入口的已声明特性将被忽略。该特性只能在对象实例化时设置。
