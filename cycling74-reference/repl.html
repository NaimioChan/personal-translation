Max

repl

发送、接收并输出 Max Console 命令

描述

repl 对象为你输入 Max Console 窗口的命令创建一个具名的目标（"target"），从而提供一种用命令行界面控制补丁的方式。（REPL 是 Read Evaluate Print Loop 的缩写。）目标要么是全局的——从任何 Max Console 窗口接收命令——要么是局部的，即属于 Max Console 位于右侧栏的那个补丁。你可以通过向 repl 的入口发送任何消息，把对命令的响应回送给用户。

你也可以用 repl 来评估命令，就像把它们输入 Max Console 窗口一样，同时也可以打印到控制台。

参数

OBJARG_NAME [OBJARG_TYPE] 可选

若给出了参数，它会被赋给目标名。默认会使用一个自动生成的唯一名称。

特性

defer [int] : 0

延迟命令

exec [int] : 0

执行命令

global [int] : 0

当 global 特性为 1 时，repl 对象可在任何 Max Console 窗口中作为目标使用。当 global 为 0 时，该对象仅在 Max Console 位于右侧栏的那个补丁中可作为目标使用。

mirror [int] : 0

启用 mirror 时，评估发往 repl 入口的消息所产生的任何结果都会被回显到右出口。把表达式发往 js 目标或 .js 子目标（属于 v8 对象）通常会产生结果，尽管该结果可能等于 undefined。例如，若同时启用 mirror 和 exec，把 js 3 + 4 发往 repl 会使 7 从右出口送出。若把 js let x = 3 + 4 发往 repl，undefined 会从右出口送出，因为在 JavaScript 中给变量赋值的结果是未定义的。

name [symbol]

目标的名称；用户必须在消息前面加上该名称，或者加上该名称后跟一个句点和附加文本。

print [int] : 1

启用 print 时，repl 收到的任何消息都会以 name 特性的取值作为前缀发布到 Max Console。你可以用它来模拟对 repl 收到的用户命令的 "响应"。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

anything

若启用 print 特性，收到的任何消息都会以目标名作为来源标记回显到 Max Console 窗口。若启用 exec 特性，收到的任何消息都会像输入到 Max Console 中那样被评估。

参数：

  • any message [list]

array

把数组发往 repl 的入口时，其内容会按 print 和 exec 特性的当前状态被打印和/或评估。数组中属于字符串、symbol 或数字的元素会被评估或打印。数组元素按索引升序处理。

参数：

  • name [symbol]

string

把字符串发往 repl 的入口时，其文本会按 print 和 exec 特性的当前状态被打印和/或评估

参数：

  • name [symbol]
