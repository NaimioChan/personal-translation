live.adsrui

ADSR 用户界面

描述

live.adsrui 对象是一个用户界面，用于按经典的 Attack、Decay、Sustain、Release 模型来定义包络的形状。每个分段都有可单独定义的长度与指数斜率。该对象设计为与其配套对象 live.adsr~ 无缝配合工作。

参数

无。

特性

active [long]

当 active 特性设为 0 时，鼠标操作不产生输出，并使用非激活颜色。

attack_slope [float]

起音阶段的斜率（-1 到 1）。

attack_time [float]

起音阶段的持续时长，单位为毫秒。该取值会被钳位到 attack_domain 特性。

decay_domain [2 floats]

decay 取值可以移动的定义域（即范围）。

decay_slope [float]

衰减阶段的斜率（-1 到 1）。

decay_time [float]

衰减阶段的持续时长，单位为毫秒。该取值会被钳位到 decay_domain 特性。

domain_exponent [float]

绘制起音/衰减/释音取值时会应用该指数。该指数让你可以调整用户用鼠标移动把手时的行为。

enable_final [long]

启用后，末端把手可以垂直移动。

enable_initial [long]

启用后，起始把手可以垂直移动。禁用时，该把手不会被绘制。

enable_peak [long]

启用后，峰值把手可以同时水平和垂直移动。禁用时，峰值把手只能水平移动。

final [float]

释音阶段结束时 ADSR 达到的取值。

initial [float]

ADSR 起始时的取值。

outputmode [long]

默认开启。启用后，载入该对象时会把补丁中存储的取值送出。在 Max for Live 设备中使用 live.adsrui、且 live.adsrui 输出到会在 Live Set 中存储 ADSR 取值的对象（例如 live.numbox）时，请关闭该特性，以避免冲突。

peak [float]

起音阶段结束时 ADSR 达到的取值。

release_domain [2 floats]

release 取值可以移动的定义域（即范围）。

release_slope [float]

释音阶段的斜率（-1 到 1）。

release_time [float]

释音阶段的持续时长，单位为毫秒。该取值会被钳位到 release_domain 特性。

show_bounds [long]

启用后，会显示用于指示对象边界的线条。

show_slopehandles [long]

启用后，会绘制斜率把手，并可以用鼠标或键盘操作它们。

sustain [float]

衰减阶段结束时 ADSR 达到的取值。

sustain_exponent [float]

绘制延音取值时会应用的指数。该指数让你可以调整用户用鼠标移动把手时的行为。

tethering [long]

默认开启。启用后，传入取值会立即从各出口送出，而不会在回送到各入口时造成堆栈溢出。把 live.adsrui 连接到 Max for Live 中其他支持参数的对象时，请关闭该特性，以避免自动化时出现意外行为。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

list

送到最左入口的列表会同时设置所有 ADSR 包络取值。

float

数字会设置与该入口相关联的特性。

bang

任意入口：bang 会刷新界面显示并产生输出。

key

选中该对象时，可以用键盘上的方向键微调把手。
