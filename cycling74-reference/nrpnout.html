Max

nrpnout

格式化 14 位 MIDI NRPN 消息

描述

格式化 14 位 MIDI 非注册参数号消息，以便用 midiout 对象发送。

讨论

非注册参数消息由若干组字节组成，用于指定 14 位参数号（2 组用于参数号的最高有效字节（MSB），1 组用于参数号的最低有效字节（LSB））、14 位取值（2 组用于取值的 MSB 与 LSB）或 7 位 delta 取值（1 组），随后是一个空功能（2 组），用于终止对参数的改动。

参数

parameter-channel [list] 可选

初始参数是初始的非注册参数号（取值范围 0-16383），供 nrpnout 格式化参数改动消息时使用。非注册参数号会自动限制在 0 到 16383 之间。该参数号也可以用 'MSB:LSB' 格式的符号表示（例如 '1:0' 表示参数 128）。若未指定控制器号，初始控制器号为 0。

控制器号参数之后是通道号的初始值，用于格式化控制消息。若没有通道参数，nrpnout 初始在通道 1 上格式化控制消息。要使用该参数，前面必须有一个控制器号参数。通道号会被截断到 1-16 范围内。

特性

hires [int] : 1

启用后，nrpnout 会为所提供的输入格式化高分辨率 14 位 NRPN 消息。若你知道所用参数只用 MSB 响应 7 位取值，把 hires 设为 0 可避免对象输出不准确的取值。若所用参数用 MSB 为 0、LSB 承载取值的「高分辨率」7 位取值响应，该设置不会起作用。

running [int] : 0

若启用了 running status，则格式化后的 NRPN 消息中除第一组字节外，其余各组字节的状态字节都会被省略。

消息

bang

用 nrpnout 当前存储的数字送出一条非注册参数消息

int

该数字是要由 nrpnout 格式化为完整 MIDI 非注册参数号消息的 14 位非注册参数取值。

参数：

  • input [int]

(inlet1)

中间左入口：该 delta 会由 nrpnout 格式化为完整的 MIDI 非注册参数号消息。超出 -127-127 范围的 delta 会被忽略。

参数：

  • delta [int]

(inlet2)

中间右入口：该数字会存储为 nrpnout 所发送消息的非注册参数号。超出 0-16383 范围的参数号会被忽略。

参数：

  • parameter [int]

(inlet3)

右入口：该数字会存储为 nrpnout 送出的连续控制器消息所用的 MIDI 通道。通道号会被截断，保持在 1-16 范围内。

参数：

  • channel [int]

list

两个 7 位取值组成的一对：最高有效字节（MSB）在前，最低有效字节（LSB）在后。7 位的 MSB 会移位并与 7 位的 LSB 做 OR 运算，以指定 14 位非注册参数取值。该 14 位取值会由 nrpnout 格式化为完整的 MIDI 非注册参数号消息。

参数：

  • msb [int]
  • lsb [int]

set

0 到 16383（即 (1 << 14) - 1）之间的参数会存储为 nrpnout 所发送消息的非注册参数号。

set 消息也接受由最高有效字节（MSB）和其后的最低有效字节（LSB）组成的参数列表。7 位 MSB 会移位并与 7 位 LSB 做 OR 运算，以指定 14 位参数号。例如 set 1 0 表示非注册参数号 128。

参数号参数也可以用 'MSB:LSB' 格式的符号表示。例如 set 1:0 表示非注册参数号 128。

超出 0-16383 范围的非注册参数号会被忽略。

参数：

  • parameter [list]

输出

int

当左入口或第二个入口收到取值（value 或 delta）时，完整的 MIDI NRPN 消息会逐字节从出口送出。
