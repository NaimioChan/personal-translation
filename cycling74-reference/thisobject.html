Max

thisobject

监视和控制具名对象

描述

用 thisobject 按名称连接到对象。thisobject 可以配合 max、dsp 这类全局具名对象使用。它也可以连接具有脚本名的对象，包括用 pattr 路径指向的其他补丁中的对象。你还可以用名称 patcher 连接到包含该 thisobject 的补丁，其效果与 thispatcher 对象类似。thisobject 与 getattr 相似，但允许你用 target 特性更改具名的目标对象，而 getattr 则用连线与其目标建立连接。

参数

target object [symbol] 可选

若给出，第一个参数用于指定 thisobject 要监视和控制的目标对象的名称。

selected attribute [symbol] 可选

若给出，第二个参数用于指定所选的特性，thisobject 在收到 bang 时会报告该特性的取值。

特性

attr [symbol]

attr 特性选择目标对象上由 thisobject 报告取值的特性：在收到 bang 时，或在取值变化且 listen 已启用时，该取值会从出口送出。

listen [int]

启用 listen 后，目标对象所选特性的取值变化会让新取值从 thisobject 对象的左出口送出。

listenvalue [int]

启用 listenvalue 后，目标对象的取值变化会让新取值从 thisobject 对象的左出口送出。

prefix [int]

启用后，输出的特性取值前面会带上该特性的名称。

target [symbol]

target 特性指定 thisobject 所用对象的名称。对象名可以是 max、dsp 这样的全局名，也可以是有脚本名的对象。更改 target 特性时，会先检查保留名 patcher 和 patcherassoc，然后是 max 这类全局名，最后是脚本名。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

bang 会输出目标对象所选特性的当前取值。

int

把一个 int 送给目标对象

float

把一个 float 送给目标对象

list

把一个 list 送给目标对象

anything

任意消息都会送给目标对象

targetattach

targetattach 消息会尝试把 thisobject 挂接到一个具名目标对象上。如果在最初设置 target 时该具名对象还不存在，这个功能会很有用。当 thisobject 所在的补丁文件被加载时，它会挂接到该具名目标上。

targetattrdict

targetattrdict 会把目标对象的特性名、标签和取值组成的字典从右出口输出。

targetbang

targetbang 消息向目标对象发送一个 bang。

targetvalue

如果目标对象是带取值的用户界面对象，targetvalue 消息会把目标对象的当前取值从左出口输出。
