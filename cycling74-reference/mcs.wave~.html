mcs.wave~

可变大小的波表（多通道 I/O）

描述

wave~ 从 buffer~ 的一部分中读取数据以产生重复波形，它需要一个取值在 0 与 1 之间的信号输入（例如使用 phasor~）来定义在缓冲区中的位置。当 wave~ 对象被实例化为 mcs.wave~ 时，它的各输出会合并为一个多通道输出，除此以外它的功能与 wave~ 完全相同。

参数

buffer-name [symbol] 可选

必需。给出 buffer~ 对象的名称，wave~ 会使用它的采样内存作为所存储的波形。注意，若 buffer~ 中的底层数据发生变化，wave~ 的信号输出也会变化，因为它不会复制 buffer~ 中的采样数据。wave~ 总是使用多通道 buffer~ 的第一个通道。

start-point [number] ms 可选

在 buffer~ 名称参数之后，你可以为波形的起始点和结束点键入一个取值，它以毫秒为单位表示相对于 buffer~ 对象采样内存开头的偏移。默认情况下，起始点为 0。若你想设置非零的起始点，又想把采样的结尾保留为波形的结束点，只需在 buffer~ 名称之后键入一个参数。wave~ 对象使用 buffer~ 的采样率来确定循环点。若把 signal 连接到起始点（中间）入口，则初始的波形起始点参数会被忽略。

end-point [number] ms 可选

在起始点参数之后，你可以为波形的结束点键入一个取值，它以毫秒为单位表示相对于 buffer~ 对象采样内存开头的偏移。默认情况下，结束点是采样的结尾。若把 signal 连接到结束点（右）入口，则初始的波形结束点会被忽略。

number-of-output-channels [int] 可选

设置输出通道数，它决定 wave~ 对象将拥有多少个出口。若由 buffer~ 对象（正在被 wave~ 播放）的通道数多于 wave~ 的输出数，多出的通道不会被播放。若 buffer~ 对象的通道数较少，多出的 wave~ 信号输出为 0。

特性

interp [int]

插值模式如下：

Value- Description

0- 不插值。用 interp 0 消息可以禁用波表插值。
1- 高质量线性插值（默认）
2- 低质量线性插值。该模式使用 MSP 1.x 版 wave~ 对象中的插值方法。虽然该模式比模式 1 更快，但它无法播放任意长度的 buffer~ 对象，并且会产生更多插值伪影。
3- 余弦插值
4- 三次插值
5- 样条插值
6- Hermite 插值

可选值：

0 = 'None'（不插值）
1 = 'Linear'
2 = 'Low-Quality'
3 = 'Cosine'（余弦插值）
4 = 'Cubic'（三次插值）
5 = 'Spline'（样条插值）
6 = 'Hermite'（Hermite 插值）

interp_bias [float]

设置 Hermite 插值的偏置参数

interp_tension [float]

设置 Hermite 插值的张力参数

消息

int

中间入口或右入口：可以用数字替代信号对象来控制波形的起始点和结束点，前提是接收该数字的入口没有连接 signal。wave~ 对象使用 buffer~ 的采样率来确定循环点。

参数：

  • start/end-point [int]

float

中间入口或右入口：可以用数字替代信号对象来控制波形的起始点和结束点，前提是接收该数字的入口没有连接 signal。wave~ 对象使用 buffer~ 的采样率来确定循环点。

参数：

  • start/end-point [float]

list

发送到左入口、带两个取值的 list 消息会以毫秒为单位设置波形的起始点和结束点。第一个取值决定起始点，第二个取值决定结束点。

参数：

  • start/end-point [list]

(mouse)

双击 wave~ 对象会打开一个窗口，显示加载在该对象所关联缓冲区中的音频文件。

set

单词 set 后面跟一个 symbol，会设置 buffer~，wave~ 用它来存放所存储的波形。该 symbol 后面可以选择性地跟两个取值，用来设置新的波形起始点和结束点。若没有给出这些取值，则使用默认的起始点和结束点（采样的起点和终点）。若有信号对象连接到起始点和/或结束点入口，则起始点和/或结束点的取值会被忽略。

参数：

  • buffer-name [symbol]
  • start-point (millisecond-offset) [float]
  • end-point (millisecond-offset) [float]

signal

左入口：从 0 递增到 1 的输入信号取值用于扫描 buffer~ 对象中指定范围的采样点。phasor~ 的输出可以用来把 wave~ 当作振荡器来控制，把 buffer~ 中的这段采样点范围视为一个重复波形。但要注意，当改变 phasor~ 的频率时（它连接在 wave~ 的左入口上），若所存储的波形包含波形的多次重复或不完整的重复，从 wave~ 送出的信号所感知到的音高可能并不与 phasor~ 本身的频率精确对应。你可以把 phasor~ 取反，以倒放该波形。

中间入口：波形的起点，以毫秒为单位表示相对于 buffer~ 对象采样内存开头的偏移。

右入口：波形的终点，以毫秒为单位表示相对于 buffer~ 对象采样内存开头的偏移。

输出

signal

buffer~ 中由 wave~ 对象起始点和结束点指定的那部分会被 wave~ 对象入口中从 0 到 1 的信号取值扫描，buffer~ 中相应的采样点取值会从 wave~ 对象的出口送出。若 wave 入口收到的信号是重复信号（例如来自 phasor~ 的锯齿波），得到的输出会是一个（从 buffer~ 中摘取的）波形，它以与输入信号重复频率相对应的频率重复。
