mcs.groove~

可变速率循环采样播放

描述

groove~ 对象是一个可变速率、循环的采样播放对象，它引用存储在与之同名的 buffer~ 对象中的音频信息。当 groove~ 对象被实例化为 mcs.groove~ 时，它的音频输出会合并为一路多通道输出。

讨论

除非 timestretching 特性被设为 1，mcs.groove~ 的插值都是三次插值。timestretching 被设为 1 时，可以用 mode、quality 和 formant 特性控制转换质量。wave~ 对象为缓冲区播放提供了额外的插值选项。

参数

buffer-name [symbol] 可选

命名那个 buffer~ 对象，其中包含交由 mcs.groove~ 播放的采样。

number-of-outputs [int] 可选

第二个参数可以指定输出通道数。默认的通道数是 1。若正在播放的 buffer~ 的通道数少于 mcs.groove~ 的输出通道数，多出的通道会输出零信号。若 buffer~ 的通道数更多，且是 2 或 4 的倍数，则各通道会被混合。对于 groove~ 和 mc.groove~，各通道分别从不同的出口送出。对于 mcs.groove~，所有通道都从第一个出口作为多通道信号输出。

特性

basictuning [int] : 440 >= 7.0.0

为音高移动操作设置以 A 的频率为基准的调律标准（440 = 默认，范围为 400 - 500）

followglobaltempo [int] : 0 >= 7.0.0

启用 followgobaltempo 后，mcs.groove~ 会用 originaltempo 与全局速度之间的比值算出当前速度，并随全局速度的变化而调整。

formant [float] : 1. >= 7.0.0

单词 formant 后面跟一个浮点值，设置执行音高移动时共振峰缩放的量。

formantcorrection [int] : 0 >= 7.0.0

单词 formantcorrection 后面跟一个 0 或 1，在执行音高校正时停用/启用共振峰校正。

lock [int] : 0 >= 7.0.0

锁定到走带

loop [int] : 0

loop 一词后面跟 0 或 1，会禁用/启用循环。
可选值：

0 = 'Off'
1 = 'On'
2 = 'Pendulum'

loopend [Time Value] : 0 ms

设置循环终点。终点时间可以用任一种 Max 时间格式指定。

loopinterp [int] : 0

单词 loopinterp 后面跟 1，会启用循环起点与终点附近的插值。loop 0 会关闭循环插值。默认情况下，循环插值是关闭的。打开循环插值会禁用重采样。

loopstart [Time Value] : 0 ms

设置循环起点。起点时间可以用任一种 Max 时间格式指定。

mode [symbol] : basic >= 7.0.0

设置要使用的 timestretching 模式。每种模式都针对处理不同类型的音频素材做过优化。所有模式都是零延迟。除非 timestretching 特性被设为 1，mcs.groove~ 的插值为三次插值。timestretching 被设为 1 时，可以用 mode、quality 和 formant 特性控制转换质量。

可选值：

'basic'（默认工作模式）
这是默认的工作模式。

'monophonic'（单声部音源（人声、长笛））
该模式最适合单声部乐器（例如独唱人声、长笛等）

'rhythmic'（针对瞬态保留做过优化）
该模式用于经过时间拉伸的打击乐。它能提供最佳的瞬态保留效果。

'general'（在频谱完整性与瞬态保留之间取得平衡）
该模式在一般情形下兼顾频谱完整性与瞬态保留。

'extremestretch'（用于拉伸比大于 2.0 的情形）
该模式用于拉伸比大于 2.0 的情形，追求更具艺术性的效果。

'efficient'（良好的 CPU 性能）
该模式追求良好的 CPU 性能与质量之间的折衷。

name [symbol]

buffer~ 名称

originallength [Time Value] : 0 ticks >= 7.0.0

音频文件以拍为单位的原始长度。followglobaltempo 用它来相对于全局走带速度计算速度。设置 originallength 会计算出 originaltempo。

originaltempo [float] : 120. >= 7.0.0

音频文件的原始速度。followglobaltempo 用它来相对于全局走带速度计算速度。设置 originaltempo 会计算出 originallength。

phase [Time Value] : 0 ticks >= 7.0.0

pitchcorrection [int] : 0 >= 7.0.0

单词 pitchcorrection 后面跟一个 0 或 1，启用/停用共振峰校正的半音音准校正。若需要更全面的实时音准校正，请使用 retune~ 对象。

pitchshift [float] : 1. >= 7.0.0

以原始音高的倍数来指定 pitchshift（即 2.0 = 音高翻倍，.5 = 原始音高减半，等等）。

pitchshiftcent [int] : 0 >= 7.0.0

把音高移动指定为正或负的音分取值（即 100 = 升高一个半音，-1200 = 降低一个八度）。音分可以用 int 或 float 指定。

quality [symbol] : basic >= 7.0.0

Timestretching 输出质量。

可选值：

'basic'（基础质量（默认））
'good'（良好质量）
'better'（更好的质量）
'best'（最高质量）

slurtime [float] : 0. >= 7.0.0

设置校正达到完全校正量所需的时间。通常，音符在起始处会有些不稳定，因为声音的起音阶段噪声较多，也因为歌手在音符起音之后会逐渐调整自己的音准。滑音时间使音高校正听起来自然，因为它模拟了这种效果。取值越大，适应时间越慢，校正要产生校正后的音高所需的时间也越长。不过，较长的滑音时间也能更好地保留颤音。

timestretch [int] : 0 >= 7.0.0

单词 timestretch 后面跟一个 0 或 1，用于禁用/启用 timestretching。

transport [symbol] : internal

设置要关联的 transport 对象的名称。默认使用全局 transport。当 mcs.groove~ 对象与某个 transport 关联后，循环点要用由 3 个元素组成的列表指定，分别对应以小节、拍和单位表示的时间。

单词 setloop 后面跟两个数字，会以毫秒为单位设置循环起点与终点。

参数：

  • start-point [list]
  • end-point [list]

signal

左入口：定义从 buffer~ 播放声音时的采样增量。采样增量为 0 会停止播放。采样增量为 1 会以正常速度播放采样。采样增量为 -1 会以正常速度倒放采样。采样增量为 2 会以两倍正常速度播放采样。采样增量为 .5 会以一半正常速度播放采样。采样增量可以随时间变化，以实现颤音或其他类型的变速效果。mcs.groove~ 对象使用 buffer~ 的采样率来确定播放速度。

若已为 mcs.groove~ 定义了循环起点与终点且循环已打开，当采样播放到达循环终点时，采样位置会被设为循环起点，并以当前采样增量继续播放。

中间入口：以毫秒为单位设置循环的起点。

右入口：以毫秒为单位设置循环的终点。

startloop

使 mcs.groove~ 从循环起点开始播放采样。若没有定义循环，mcs.groove~ 会从头开始播放。

stop

stop 一词会使 mcs.groove~ 停止播放，直到收到下一条 int、float 或 startloop 消息。

输出

signal

左出口：采样输出。若 groove~ 或 mc.groove~ 有两个或四个输出通道，左出口播放采样的左声道。对于 mcs.groove~，所有通道都从左出口输出。

中间出口：采样输出。若 groove~ 或 mc.groove~ 有两个或四个输出通道，中间出口播放左声道以外的通道。mcs.groove~ 没有中间出口，因此这不适用于该对象。

右出口：同步输出。在采样的循环部分期间，该出口输出一个 signal，它从循环开始时的 0. 变到循环结束时的 1.。
注意：要让缓冲区播放开始（进而产生同步输出），必须把 groove~ 对象的某个输出通道连接到另一个信号对象。
