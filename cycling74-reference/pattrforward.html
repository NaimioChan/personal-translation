pattrforward

把任意消息发送给具名对象

描述

根据收到的消息来转发消息，或选择新的消息转发目标。你也可以使用 pattrforward 对象把消息直接转发到由 pattr 或 autopattr 对象暴露的某个对象的指定入口，也可以把消息直接发给子补丁、抽象对象或 bpatcher。

讨论

pattrforward 对象在指定要发消息的目标对象路径时，使用对象的脚本名（即其 varname 特性，通过对象的 Inspector 设置）。例如，若你想给子补丁中名为 my_dial 的对象发消息，而你又把该子补丁的脚本名设为 my_controls，那么就把消息 send my_controls::my_dial 发给 pattrforward 对象，为后续消息设置目标。

参数

target [symbol] 可选

可以选择用一个符号参数来指定目标对象。

特性

send [symbol]

send 一词后面跟补丁层级中任意对象的补丁名，用于设置目标对象。名称可以指向 pattrforward 对象所在补丁以外的其他补丁中的对象。用双冒号语法（'::'）分隔补丁层级的各个层级。例如，some_subpatcher::some_object 或 parent::some_other_object 都是有效的目标对象名称。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

bold

bold italic

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

bang 会传给目标对象。

int

一个 int 会传给目标对象。

参数：

  • input [int]

float

一个 float 会传给目标对象。

参数：

  • input [float]

list

一个 list 会传给目标对象。

参数：

  • input [list]

anything

发往 pattrforward 对象的传入消息会被分析。若消息的第一个元素与符号 in0、in1 … inN 匹配，pattrforward 对象会把其余所有参数转发到目标对象的指定入口。in0 指最左边的入口（这是 pattrforward 对象的默认行为），in1 指从左数第二个入口，以此类推。

若目标对象是子补丁、抽象对象或 bpatcher，可以用特殊元素 inx 把消息直接发给该补丁对象（本质上是为了与补丁关联的虚拟 thispatcher 对象通信）。

参数：

  • input [list]

(mouse)

双击 pattrforward 对象会在其父补丁中显示当前的目标对象。

输出

anything

在 pattrforward 入口收到的消息会发给补丁层级中任意位置的具名对象。
