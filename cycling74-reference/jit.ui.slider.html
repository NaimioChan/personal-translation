jit.ui.slider

渲染窗口中的交互式滑动条

描述

使用控件用鼠标在渲染窗口中移动和调整该 UI 对象的大小。

参数

无。

特性

background_color [4 floats]

UI 对象主体的颜色（默认值 = 0.7 0.7 0.7 1.）

border [int]

启用 UI 对象四周的边框（默认值 = 1）

border_color [4 floats]

UI 对象四周边框的颜色（默认值 = 0. 0. 0. 1.）

border_size [float]

UI 对象四周边框的大小（单位：像素）

canvas [symbol]

要绘制到的 jit.ui.canvas 名称
jit.ui 对象总是需要设置 canvas 特性，除非它们被附接到 jit.ui.group 对象上。
这种情况下，它们会继承该组的 canvas 特性。

constant_pixel_size [int]

无论渲染窗口大小如何都保持像素大小一致（默认值 = 1）。
启用后，即使渲染窗口被调整大小，UI 对象也保持其像素尺寸。

enable [int]

启用标志（默认值 = 1）
该标志置位时即启用绘制。

enable_label [int]

启用标签文字（默认值 = 1）
该标志置位时会显示标签文字。

enable_mouse_editing [int]

启用鼠标编辑（默认值 = 1）
启用后且补丁未锁定时，可以用鼠标调整 UI 对象的大小并移动它。

enum_items [0 atoms]

设置一个用作滑动条取值的 symbol 列表，只有把 mode 特性设为 "enum" 时它才会生效。

font [symbol]

字体名称

fontsize [float]

字体大小

group [symbol]

所分配到的 jit.ui.group 对象名称
设置后，该 UI 对象会被分配到那个 jit.ui.group

height [int]

UI 对象的高度（单位：像素）

隐藏 UI 对象背景（默认值 = 0）

鼠标悬停在 UI 对象上时的背景颜色（默认值 = 0.9 0.9 0.9 1）

highlight_hover [int]

启用悬停高亮（默认值 = 0）
启用后，鼠标位于 UI 对象区域上方时，背景会变为 highlight_color。

忽略鼠标点击（默认值 = 0）
设为 1 时，除非处于编辑模式，否则 UI 对象不响应鼠标点击。

把滑动条指示器改为 "filled" 或 "indicator"（默认值 = "filled"）

'filled'
'indicator'

label [symbol]

UI 对象的标签文字

mode [symbol]

滑动条模式可以是 "enum" 或 "slider"（默认值 = "slider"）。处于 "enum" 模式时，滑动条取值将从用特性 enum_items 设置的符号列表中选择。
可选值：

'slider'
'enum'

设置 group 特性时，该对象在 UI 组内的顺序索引。

position [2 ints]

UI 对象的位置相对其锚点的位置保持不变。

position_anchor [2 ints]

UI 对象的锚点位置（单位：像素）
UI 对象的位置始终相对其锚点位置保持不变。渲染窗口被调整大小时，锚点在渲染窗口内按比例保持相同的位置，而 UI 对象跟随其锚点。

position_anchor_percentage [2 ints]

UI 对象锚点位置，以渲染窗口大小的百分比表示（默认值 = 50 50）
把 UI 对象的锚点位置设为渲染窗口尺寸的百分比。窗口被调整大小时，UI 对象保持其相对该锚点的位置。

read_image_background [symbol]

载入一张图像并把它显示在 UI 对象的背景上
该特性的参数是图像的路径。

read_image_slider [symbol]

载入一张图像并把它显示在 UI 对象的滑动条区域上
该特性的参数是图像的路径。

roundness_corners [float]

UI 对象边角的圆角程度（默认值 = 0.2）

scale [float]

UI 对象的等比缩放，以单个标量数值表示（默认值 = 1）

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。
