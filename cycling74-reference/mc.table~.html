MC

mc.table~

Signal Table Lookup (multichannel)

描述

Use table~ to remap incoming signal values with a table object.

参数

无。

特性

annotation_name [symbol] :

信息视图标题

embed [int] : 1

When the embed attribute is enabled, table values are saved in a patcher file and restored when it is reopened.

extend [int]

The extend attribute controls how table~ responds when an input index value (either signal or float) is less than zero or greater than the table size.
Possible values:

0 = 'Zero' ( Output zero )
When extend is Zero (0), a zero signal is output when the index is outside the table bounds.

1 = 'Extend' ( Output lowest or highest table values )
When extend is set to Extend (1), table~ outputs the value at index 0 is output when the input index less than zero. It outputs the value at the highest table index is when the input index is greater than the table size.

2 = 'Wrap' ( Wrap index )
When extend is set to Wrap (2), table~ performs a modulo operation on the input index. Example: if the table size is 128 and the input is 130, the value at index 2 (130 mod 128) will be output.

3 = 'Ignore' ( Don't change output )
When extend is set to Ignore (3), any input index outside the table size is ignored and does not change the output.

inmap [atom]

The inmap attribute specifies a range of input samples to map to table indices. For instance if your input signal will be between 0 and 1, you can use an inmap of 0 1, which will scale to the current size of the table. If the table changes size, the current input map adjusts automatically. To clear the current inmap, use a value of none or 0 0.

inputmode [int]

The inputmode attribute determines how input values produce output values.
Possible values:

0 = 'Lookup' ( Lookup )
When inputmode is set to Lookup (0), an incoming value is used as an index into the table.

1 = 'Increment Index' ( Increment Index )
When inputmode is set to Increment Index (1), a change event in the input signal (according to the setting of the triggermode attribute) causes the table to output the value at the next index.

2 = 'Random Distribution' ( Random Distribution )
When inputmode is set to Random Distribution (2), a change event in the input signal (according to the setting of the triggermode attribute) causes the table to output a value based on using the table data as a probability distribution. See the bang message for more details.

interp [int]

The interp attribute determines how input values between integer table indices produce output.
Possible values:

0 = 'None' ( Truncate Index )
When interp is set to None (0), an incoming value is truncated to its integer value before the lookup. No interpolation is performed.

1 = 'Linear' ( Linear Interpolation )
When interp is set to Linear (1), the output for any input value between two table indices is linearly interpolated between the table values at those two indices. For example, an input of 1.5 -- with table values of 5 at index 1 and 10 at index 2 -- produces an output of 7.5.

2 = 'Round' ( Round Index )
When interp is set to Round (2), an incoming value is rounded to the nearest integer value before the lookup. No interpolation is performed.

name [symbol]

The name attribute permits table data to be shared among multiple table objects (table~, table, or itable) with the same name. Changing the name switches the table used for lookup.

outscale [atom]

The outscale attribute specifies a range of output samples. The current range of the table will map to the specified range. For example, if you want the output of table~ to range from 0 - 1, set outscale to 0 1. The output scaling adjusts automatically to keep output values in the specified range even if the table range changes. To clear the current outscale use a value of none or 0 0.

parameter_enable [int]

启用后，该对象可与 Max for Live Parameters 配合使用。

parameter_mappable [int] : 1

When parameter_mappable is enabled, the object will be available for mapping to keyboard or MIDI input using the Mappings feature. (default = 1).

range [int]

Sets the range of table values. If the signed attribute is not enabled, the maximum table value is one less than the range. For example if the range is 128, table values range from 0 to 127. If signed is enabled, table values range from +/- the range value. For example if the range is 128, table values will be -128 to 128.

signed [int] : 0

If the signed attribute is enabled, table values range from +/- the range value. For example if the range is 128, table values will be -128 to 128. Changing the state of signed attribute does not modify table values.

size [int]

Sets the number of elements in the table. Indices range from 0 to one less than the size.

triggermode [int]

The triggermode attribute determines how input values are interpret as change events for triggering either an incremented index or random probability output according to the setting of the inputmode attribute. When inputmode is set to 0 (Lookup), the triggermode attribute has no effect and is disabled.
Possible values:

0 = 'Zero to Non-Zero' ( Zero to Non-Zero )
When triggermode is set to Zero to Non-Zero (0), a non-zero sample value in the input that follows a zero sample value causes a change event to occur.

1 = 'Change' ( Change )
When triggermode is set to Change (1), a sample value in the input that differs from the previous value causes a change event to occur.

多通道组特性

chans [int]

chans 特性设置 MC 包装对象中的通道数与实例数。若要定义固定的通道数而不受连接到该对象的内容影响，请通过键入参数来设置 chans，例如键入 mc.cycle~ @chans 100 会在 MC 包装对象内创建 100 个 cycle~ 对象的实例。若 chans 为 0，包装对象会自动适应其输入多通道信号中的通道数（取所有已连接信号的最大值）。若某个对象的入口没有连接任何多通道信号，而你想要多个实例，就需要把 chans 特性设为非零值。

若在音频开启时改变 chans，实例数要到音频重启后才会改变。不过，若在音频开启时减少 chans，多出的通道将不再处理音频，并输出零信号。

initialvalues [list]

initialvalues 特性只在对象创建时起作用，因此必须通过键入参数来设置。initialvalues 为 MC 包装对象中相继创建的各个实例设置第一个（也只是第一个）初始参数。例如，键入 mc.cycle~ @chans 4 @initialvalues 50 60 70 80 会为包装对象内的 cycle~ 实例指定初始频率。第一个实例的频率为 50，第二个为 60，第三个为 70，第四个为 80。注意 initialvalues 并不决定实际的实例数；实例数可以用 chans 特性来设置。若实例数多于 initialvalues 特性的元素个数，多出的实例以默认值实例化。

若要为所有实例设置某个参数的默认值，请在任何键入特性之前把它作为参数键入。例如，把上面的例子改成：mc.cycle~ 100 @chans 10 @initialvalues 50 60 70 80。在这个例子中，前四个实例和之前一样设置，但接下来的六个实例以频率参数 100 创建。

若要在包装对象创建之后改变实例取值或特性，请使用 setvalue、applyvalues 或 replicatevalues 消息。

values [list]

可以把 values 用作 initialvalues 特性的另一个名称。

target [int]

target 特性设置一个索引，用于指定某个包装实例。随后的消息会发给单个实例，而不是所有实例。强烈建议改用更可靠的 setvalue 消息，而不要使用 target 特性。setvalue 的声部索引会覆盖 target 的当前设置。当 target 为 0 时，收到的消息发给所有实例；当 target 为 -1 时，收到的消息不做任何事。注意 target 只影响消息，不影响特性取值的设置。

usebusymap [int]

启用 usebusymap 后，MC 包装对象根据 busy map 控制各个实例是否处理音频，该 busy map 由 mc.noteallocator~ 或 mc.voiceallocator~ 对象维护。当 busy map 中某个通道被标记为「free」或「released」时，与声部索引对应的该通道上不会有任何实例进行音频处理。禁用 usebusymap 时，MC 包装对象中的实例始终处理音频。若启用了 usebusymap 但没有可用的本地或具名 busy map，情况也是如此。（本地与具名 busy map 的说明见 busymapname 特性。）为简洁起见也可以使用名称 bz。

zero [int]

启用 zero 特性后，MC 包装对象中因使用 busy map 而停用的通道会输出零信号。若想省下少量 CPU，可以禁用 zero，但要冒信号数据未清除而带来响亮难听噪声的风险。在这种情况下，MC 包装对象中已停用的通道对其输出通道不做任何处理。若 usebusymap 被禁用，或没有可用的活动本地 busy map 或具名 busy map，则 zero 特性的设置不起作用。

方便的是，当 usebusymap 在 mc.mixdown~ 对象中启用时，停用的通道不会被混入输出。被包装对象在禁用 zero 的情况下产生的未使用信号送入 mc.mixdown~ 时会被忽略，从而降低难听的声音混过混合输出的风险。

busymapname [symbol]

启用 usebusymap 特性后，MC 包装对象默认使用同一补丁中任意 mc.voiceallocator~ 或 mc.noteallocator~ 的局部 busy map。若要改用具名的全局 busy map，把 busymapname 特性设为想要的名称即可。为简洁起见也可以使用名称 @bzname。

op [symbol]

设置 generate 消息被调用时要使用的函数。若你把 attrui 设为编辑 op 特性，就能看到一份包含 40 多种可用函数的便捷菜单，不必去记它们的名称。

voiceprob [float]

voiceprob 特性用于 setvalue 消息带 $ 或 * 参数的情形。它决定 setvalue 消息被发出的概率。例如 voiceprob 为 0.9 时，有 90% 的概率把 setvalue 消息发往随机选中的声部。

消息

bang

The bang message treats the table as a probability distribution and outputs a signal corresponding to a randomly chosen index within the table. A location in the table with a higher value is more likely to have its index selected.

int

See description for float

float

When a signal is not connected to the inlet of table~, a number sets the index to use for table lookup output. If the number contains a fractional part and interp is set to Linear, the output will be interpolated between two table values. The number is also mapped to an index according to the current setting of the inmap attribute and the table value is scaled according to the outscale attribute.

(mouse)

Double-clicking on a table~ object opens a window where you can edit the values of the lookup table.

goto

The word goto, followed by a table index, sets the next table index used by either the prev or next messages as they increment or decrement through the table. Unlike a float or int, goto itself does not change the output of the table~ object and its index is not modified by the inmap attribute.

next

When a signal is not connected to the inlet of table~, the next message adds one to the most recent table index set by the int, or float, then causes the table~ to output the value at this index as a signal. If a goto message immediately preceded next, the value at the specified index is output. Note that next does not force the table index to an integer value, so it preserves any fractional part of the index caused by a previous float message. When next increments the index and it is larger than the table size, it wraps around to zero.

prev

When a signal is not connected to the inlet of table~, the prev message subtracts one from the most recent table index set by the int, or float, then causes the table~ to output the value at this index as a signal. If a goto message immediately preceded prev, the value at the specified index is output. Note that prev does not force the table index to an integer value, so it preserves any fractional part of the index caused by a previous float message. When prev decrements the index and it becomes less than zero, it will wrap around to the end of the table.

signal

Incoming signal values are used as indices for table lookup.

多通道组消息

deviate

围绕一个中心值为每个通道生成随机值。中心值后面可选的数字用于指定上界范围的大小，使其可以与下界范围的大小不同。
例如：deviate 100 cutoff 1000 会围绕 1000 Hz（在 900 到 1100 Hz 之间）为包装对象中各个对象的 cutoff 特性生成随机值。deviate 100 1000 200 会把 900 到 1200 之间的随机值以 float 消息发给包装对象中的各个对象。
若未给出消息名，默认使用 float 消息。

参数：

  • range [float]
  • message-name [symbol]
  • center-value [float]
  • upper-range [float]

exponential

exponential 消息生成指数列。第一个参数是下列表达式中的 N，第二个（可选）参数是 K：
K * exp(-1 * N * channel)，其中 channel 从第一个通道的 0 开始。
若未给出第二个参数，默认值为 1。例如：exponential 1 10 对四个通道会生成 10、3.678、1.353 和 0.498 这些值。exponential -1 2 会生成 2、5.437、14.78 和 40.17。
若未给出消息名，默认使用 float 消息。

参数：

  • exponent [float]
  • message-name [symbol]
  • multiplier [float]

scaledexponential

scaledexponential 消息生成指数列，指数按通道总数缩放。第一个参数是下列表达式中的 N，第二个（可选）参数是 K：
K * exp(-1 * N * (channel / num_channels)，其中 channel 从第一个通道的 0 开始。
若未给出第二个参数，默认值为 1。例如：exponential -1 2 对六个通道会生成 2、2.363、2.791、3.297、3.895、4.602 这些值。四个通道的 scaledexponential -1 2 会生成 2、2.568、3.297、4.324。scaledexponential 提供了一种让指数列的取值范围大致不随通道数变化的方法。
若未给出消息名，默认使用 float 消息。

参数：

  • exponent [float]
  • message-name [symbol]
  • base [float]

increment

increment 消息为每个通道生成一组递增的值。范围从第二个参数开始，每个通道的值按第一个参数递增。若未给出消息名，则默认使用 float 消息。
例如：四个通道的 increment 5 2 会生成 2、7、12 和 17。
若未给出消息名，默认使用 float 消息。

参数：

  • increment-amount [float]
  • message-name [symbol]
  • start-value [float]

harmonic

harmonic 消息生成谐波列：第二个参数为基频（F），第一个参数为下列表达式中的倍率（N）：
F * (1 + N * channel)，其中 channel 从第一个通道的 0 开始。
例如：五个通道的 harmonic 1 440 会生成 440、880、1320、1760 和 2200。四个通道的 harmonic 0.5 440 会生成 440、660、880 和 1100。
若未给出消息名，默认使用 float 消息。

参数：

  • multiplier [float]
  • message-name [symbol]
  • fundamental [float]

subharmonic

subharmonic 消息生成次谐波列：第二个参数为基频（F），第一个参数为下列表达式中的倍率（N）：
F / (1 + N * channel)，其中 channel 从第一个通道的 0 开始。
例如：五个通道的 subharmonic 1 440 会生成 440、220、146.7 和 110。
若未给出消息名，默认使用 float 消息。

参数：

  • multiplier [float]
  • message-name [symbol]
  • fundamental [float]

spread

spread 消息生成一段分配到各通道的取值。范围输出中包含第一个边界值，但不包含第二个边界值（其他选项见 spreadinclusive、spreadexclusive 和 spreadincludesecond）。
例如：四个通道的 spread 0 10 会生成 0、2.5、5 和 7.5。
若未给出消息名，默认使用 float 消息。
默认情况下生成的值呈线性分布。若给出可选的 exponent 参数且其大于 0，生成的值呈指数分布。

参数：

  • boundary-value [float]
  • message-name [symbol]
  • other-boundary-value [float]
  • exponent [float]

spreadinclusive

spreadinclusive 消息生成一段分配到各通道的取值。范围输出中同时包含第一个和第二个边界值。
例如：四个通道的 spreadinclusive 0 10 会生成 0、3.33、6.66 和 10。
若未给出消息名，默认使用 float 消息。
默认情况下生成的值呈线性分布。若给出可选的 exponent 参数且其大于 0，生成的值呈指数分布。

参数：

  • boundary-value [float]
  • message-name [symbol]
  • other-boundary-value [float]
  • exponent [float]

spreadexclusive

spreadexclusive 消息生成一段分配到各通道的取值。范围输出中既不包含第一个边界值，也不包含第二个边界值。
例如：四个通道的 spreadexclusive 0 10 会生成 2、4、6 和 8。
若未给出消息名，默认使用 float 消息。
默认情况下生成的值呈线性分布。若给出可选的 exponent 参数且其大于 0，生成的值呈指数分布。

参数：

  • boundary-value [float]
  • message-name [symbol]
  • other-boundary-value [float]
  • exponent [float]

spreadincludefirst

spreadincludefirst 消息生成一段分配到各通道的取值。它与 spread 消息相同。范围输出中包含第一个边界值，但不包含第二个边界值。
例如：四个通道的 spreadincludefirst 0 10 会生成 0、2.5、5 和 7.5。
若未给出消息名，默认使用 float 消息。
默认情况下生成的值呈线性分布。若给出可选的 exponent 参数且其大于 0，生成的值呈指数分布。

参数：

  • boundary-value [float]
  • message-name [symbol]
  • other-boundary-value [float]
  • exponent [float]

spreadincludesecond

spreadincludesecond 消息生成一段分配到各通道的取值。范围输出中不包含第一个边界值，但包含第二个边界值。
例如：四个通道的 spreadincludesecond 0 10 会生成 2.5、5、7.5 和 10。
若未给出消息名，默认使用 float 消息。
默认情况下生成的值呈线性分布。若给出可选的 exponent 参数且其大于 0，生成的值呈指数分布。

参数：

  • boundary-value [float]
  • message-name [symbol]
  • other-boundary-value [float]
  • exponent [float]

decide

decide 消息为每个通道生成一个 0 到 1 之间均匀分布的随机值；若该值小于第一个参数设定的概率值，就把第二个参数赋给该通道。若随机值大于概率值，则把 0 赋给该通道。（若未给出第二个参数，默认使用 1。）
例如：四个通道的 decide 0 10 会生成 0、0、0、0，因为生成 1 的概率为零。decide 0.5 10 在第一个和第四个通道随机生成的值超过 0.5 时，可能生成 10、0、0、10。
若未给出消息名，默认使用 float 消息。

参数：

  • probability [float]
  • message-name [symbol]
  • value [float]

randomrange

randomrange 消息为所有通道生成一段在第一个参数与第二个参数之间均匀分布的随机值。
若未给出消息名，默认使用 float 消息。

参数：

  • low-value [float]
  • message-name [symbol]
  • high-value [float]

generate

generate 消息运行名称存放在 op 特性中的函数。传给 generate 的参数会交给被调用的函数。例如：若 op 设为 deviate，则 generate 50 440 等同于发送消息 deviate 50 440。

参数：

  • low-value [float]
  • message-name [symbol]
  • high-value [float]

ease.linear

MC 包装对象提供对 Ease Package 中缓动函数的访问。这些函数通过由 ease. 与缓动函数名拼接而成的消息名来访问。例如，要使用 in_out_circular 函数，就发送消息 ease.in_out_circular。
ease 消息在通道范围内生成一个包含端点的非线性取值序列。使用两个数字参数时，第一个值是范围的低端，第二个是范围的高端。对于 in_ 和 in_out_ 函数，这意味着低端值赋给第一个通道，高端值赋给最后一个通道。对于 out_ 函数变体，高端值赋给第一个通道，低端值赋给最后一个通道。
给 ease 消息提供三个数字参数时，前两个参数与两参数情形一样指定范围，而第三个参数（会被约束在 0 与 1 之间）定义一个中点。在第一个通道与最接近中点的通道之间，应用函数的整个取值范围。在中点与最后一个通道之间，以取值反向的方式应用函数的取值范围，形成镜像。当第三个参数为 0.5 时镜像完全精确，否则会偏向 0 或 1。中点取 1 时，结果与完全不给出第三个参数相同。中点取 0 时，结果与完全反向相同。换句话说，就好像把原本指定的 in_ 版本函数换成了 out_ 版本——反之亦然。
可用的消息有：ease.linear、ease.in_back、ease.in_out_back、ease.out_back、ease.in_bounce、ease.in_out_bounce、ease.out_bounce、ease.in_circular、ease.in_out_circular、ease.out_circular、ease.in_cubic、ease.in_out_cubic、ease.out_cubic、ease.in_elastic、ease.in_out_elastic、ease.out_elastic、ease.in_exponential、ease.in_out_exponential、ease.out_exponential、ease.in_quadratic、ease.in_out_quadratic、ease.out_quadratic、ease.in_quartic、ease.in_out_quartic、ease.out_quartic、ease.in_quintic、ease.in_out_quintic、ease.out_quintic、ease.in_sine、ease.in_out_sine 以及 ease.out_sine。关于这些函数的细节及其行为演示，请参阅 Ease Package 的文档。
若未给出消息名，默认使用 float 消息。

参数：

  • low-value [float]
  • message-name [symbol]
  • high-value [float]
  • mid-point [float]

smoothstep

smoothstep 函数的作用与 ease 消息类似，都生成一个包含端点的非线性取值范围，但它使用 smoothstep 函数生成非线性斜坡。更多信息请参阅 ease 消息的文档。
若未给出消息名，默认使用 float 消息。

参数：

  • low-value [float]
  • message-name [symbol]
  • high-value [float]
  • mid-point [float]

setvalue

setvalue 一词后面同时跟一个通道索引（从 1 开始）和任意可发往被包装对象的消息，会把该消息送给 MC 包装对象中的单个实例。setvalue 0 后面跟一个消息，会把该消息送给所有实例。setvalue 消息可以用在任何入口。
setvalue 消息也可以用符号代替数字，表示目标通道索引应随机选择：

  • setvalue * 会随机选择通道，但在所有通道都被选过之前避免重复选择（类似 Max 的 urn 对象）。在选择通道之前，* 还会根据 voiceprob 特性的当前值决定是否发出消息。若 voiceprob 为 0.1，有 10% 的概率发出消息；若 voiceprob 为 0.9，有 90% 的概率发出消息。
  • setvalue + 会随机选择通道，但在所有通道都被选过之前避免重复选择（类似 Max 的 urn 对象）。与 * 不同，它总会发出消息。
  • setvalue $ 会随机选择一个通道（类似 Max 的 random 对象）。在选择通道之前，$ 还会根据 voiceprob 特性的当前值决定是否发出消息。若 voiceprob 为 0.1，有 10% 的概率发出消息；若 voiceprob 为 0.9，有 90% 的概率发出消息。
  • setvalue # 会随机选择一个通道（类似 Max 的 random 对象）。与 $ 不同，它总会发出消息。

参数：

  • channel [int]
  • message [symbol]
  • message arguments [list]

setvaluerange

setvaluerange 一词后面跟一个低通道索引和一个高通道索引（从 1 开始）以及任意可发往被包装对象的消息，会把该消息送给指定范围内的通道。
例如：setvaluerange 1 4 50 把消息 50 送给通道 1 至 4。若第二个参数为 -1，消息会送给其后的所有通道。例如 setvaluerange 2 -1 50 把消息 50 送给通道 2 到当前声部数之间的所有通道。
注意：使用 *、+、$ 和 # 的随机通道选择功能对 setvaluerange 消息无效。

参数：

  • low channel [int]
  • high channel [int]
  • message [symbol]
  • message arguments [list]

applymessages

applymessages 一词后面跟一个或多个数字和/或符号，会把各个消息依次送给 MC 包装对象中的各个实例，从第一个实例开始。例如，消息 applymessages 0 bang 会把 '0' 消息送给第一个实例、把 'bang' 消息送给第二个实例。若实例数多于 applymessages 的参数个数，多出的实例不受影响。

参数：

  • messages [list]

applyvalues

applyvalues 一词后面跟一个可选的消息名和一个或多个消息参数，会把参数中的各个值依次送给 MC 包装对象中的各个实例，从第一个实例开始。例如消息 applyvalues 4 5 6 会把 4 送给第一个实例、5 送给第二个实例、6 送给第三个实例。若实例数多于 applyvalues 的参数个数，多出的实例不受影响。

参数：

  • message-name [symbol]
  • values [list]

replicatevalues

replicatevalues 一词后面跟一个可选的消息名和一个或多个消息参数，会把参数中的各个值依次送给 MC 包装对象中的各个实例，从第一个实例开始。与 applyvalues 不同，若 replicatevalues 消息的参数不够发，它会回到第一个元素继续把值依次送给后续实例。例如，对有三个实例的 MC 包装对象使用 replicatevalues 4 5，会把 4 送给第一个实例、5 送给第二个实例、4 送给第三个实例。

参数：

  • message-name [symbol]
  • values [list]

applynvalues

applyvalues 只能设置一个值，而 applynvalues 消息可以把带多个值的消息或特性设置发给 MC 包装对象中的各个实例，从第一个实例开始。对于需要多个值的消息，例如发往 wave~ 用来设置起点/终点的 list 消息，这很有用。消息语法为 [applynvalues N value1, value2 etc.]，其中 N 是为每个实例设置的值个数。例如，消息 applynvalues 2 500 600 900 1000 会把 500 600 送给第一个实例、把 900 1000 送给第二个实例。若实例数多于 applynvalues 中指定的数量，多出的实例不受影响。

参数：

  • message [int]
  • values [list]

replicatenvalues

replicatevalues 只能设置一个值，而 replicatenvalues 消息可以把带多个值的消息或特性设置发给 MC 包装对象中的各个实例，从第一个实例开始。对于需要多个值的消息，例如发往 wave~ 用来设置起点/终点的 list 消息，这很有用。消息语法为 [replicatenvalues N value1, value2 etc.]，其中 N 是为每个实例设置的值个数。与 applynvalues 不同，若 replicatenvalues 消息要发的参数不够，它会回到第一组继续把值依次送给后续实例。例如，对有三个实例的 MC 包装对象使用 replicatenvalues 2 500 600 900 1000，会把 500 600 送给第一个实例、900 1000 送给第二个实例、500 600 送给第三个实例。

参数：

  • message [int]
  • values [list]
