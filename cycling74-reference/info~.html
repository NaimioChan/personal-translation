MSP

info~

报告采样的信息

描述

使用 info~ 对象报告已读入 buffer~ 对象中的文件里的信息，以响应 bang。若该信息不存在，则为 0。info~ 的工作不要求打开音频。循环与调律信息可在 AIFF 文件中找到。

参数

buffer-name [symbol] 可选

为 buffer~ 对象命名，info~ 将报告该对象的信息。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

左入口：触发一次报告，报告关联的 buffer~ 对象中所含采样的信息。

(mouse)

双击 info~ 会打开一个编辑窗口，你可以在其中查看与其关联的 buffer~ 对象的内容。

set

单词 set 后面跟一个 buffer~ 对象的名称，用于设置哪个 buffer~ 将被 info~ 所引用。

参数：

  • buffer-name [symbol]

输出

Sample Information

info~ 报告的绝大部分信息取自最近读入关联 buffer~ 的音频文件。若该信息不存在，则只有采样率会从左出口送出。声音文件中缺失的任何项目都不会有输出。

float

左出口：采样的采样率。

第三个出口：延音循环起点，单位为毫秒。

第四个出口：延音循环终点，单位为毫秒。

第五个出口：释音循环起点，单位为毫秒。

第六个出口：释音循环终点，单位为毫秒。

第七个出口：关联 buffer~ 对象的总时长，单位为毫秒。

第八个出口：最近读入的音频文件的名称。

第九个出口：最近读入的音频文件的通道数。

第十个出口：最近读入的音频文件的完整路径名。

list

第二个出口：该采样的乐器信息，具体如下：

1. 该采样的 MIDI 音高。

2. 相对该采样原始 MIDI 音符号的失谐量，以弯音单位表示。

3. 播放该采样时要使用的最低 MIDI 音符号。

4. 播放该采样时要使用的最高 MIDI 音符号。

5. 播放该采样时要使用的最低 MIDI 力度。

6. 播放该采样时要使用的最高 MIDI 力度。

7. 该采样的增益（0-127）。
