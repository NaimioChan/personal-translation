mcs.matrix~

信号路由与混合矩阵（多通道 I/O）

描述

matrix~ 是一个由信号连接器与混音器（加法器）组成的阵列。它可以有任意数量的入口与出口。从每个入口进入的信号都可以路由到一个或多个出口，增益量可变。若某个出口连接了多于一个入口，其输出信号就是来自这些入口的信号之和。
当 matrix~ 对象被创建为 mcs.matrix~ 时，它所有的信号入口会合并成一个多通道入口，所有的信号出口会合并成一个多通道出口。mcs.matrix~ 的行为在其他方面与 matrix~ 相同。

讨论

输入与输出之间的连接可以有自己的增益，并且每条连接都可以包含一个斜坡时间，以避免咔哒声。

参数

inlets [int] 可选

第一个参数指定入口数量。

outlets [int] 可选

第二个参数指定出口数量。

default-connect-gain [float] 可选

若第三个参数给出了一个浮点数，它为 connect 消息设置一个默认增益，用于 connect 的增益参数未提供的情形。

特性

exclusive [int]

exclusive 特性控制是否允许从单个输入发出多个连接或连到单个输出的多个连接。
可选值：

0 = 'Off'（无连接限制）
1 = 'Inputs'（阻止来自同一输入的多个连接）
2 = 'Outputs'（阻止连到同一输出的多个连接）
3 = 'Inputs + Outputs'（阻止来自同一输入的多个连接和连到同一出口的多个连接。）

numouts [int]

别名：chans

输出数量

ramp [float]

别名：ramptime

以毫秒为单位设置斜坡时间，使信号的切换不产生可听见的咔哒声。

消息

list

左入口：由三个数字组成的列表用于连接输入与输出。第一个数字指定输入通道，第二个数字指定输出通道。若第三个数字为 0，则该输入与输出断开。若第三个数字非零，它被解释为该输入与输出之间连接的增益。

注意：若要指定各条连接各自的增益，必须使用三元素列表消息，而不能使用 connect 消息。用 connect 消息建立的连接，其增益始终是最初交给 mcs.matrix~ 对象的第三个参数所指定的值。不过，后续的列表消息可以改变用 connect 消息建立的连接的增益。
列表消息还可以附加可选的第四个元素，专门为这一条连接指定以毫秒为单位的斜坡时间。例如：1 2 .8 500 会把第一个输入连接到第二个输出，并指定增益为 .8、斜坡时间为 .5 秒）。

参数：

  • inlet-to-outlet indices [list]

clear

左入口：单词 clear 会移除所有连接。

connect

左入口：单词 connect 后跟一个或多个 int，会把第一个 int 指定的入口连接到列表中其余 int 所指定的一个或多个出口。入口与出口从左到右编号，从零开始。例如，消息 connect 0 0 1 会把从左数第一个入口连接到最左侧的出口以及从左数第二个出口。若列表中的最后一项是 float，它会设置所有指定连接的增益。

参数：

  • inlet-to-outlet indices [list]

dictionary

mcs.matrix~ 对象可以接收字典来配置自身的状态。收到字典时，此前所有的连接都会被清除，并替换为字典中的连接。还可以用字典设置某些特性，包括默认增益和斜坡时间。

参数：

  • dict-name [symbol]

disconnect

左入口：disconnect 一词后面跟一个或多个 int，会断开第一个 int 所指定的输入与列表中其余 int 所指定的一个或多个输出之间的连接。

参数：

  • inlet-to-outlet indices [list]

dump

左入口：dump 一词会令 mcs.matrix~ 对象所有连接的当前状态以每条连接一个列表的形式，从该对象最右侧的出口送出。该列表由两个数字组成，分别指定入口和出口，后面跟一个 float，指定该连接的增益。注意，当前增益不一定与所有 matrix~ 对象连接的目标增益相同，因为一条连接的增益可以随时间斜坡过渡到它新的目标值。

dumpconnections

左入口：单词 dumpconnections 会把 matrix~ 对象当前的内容以字典形式从该对象最右侧的出口送出。

dumptarget

左入口：dumptarget 一词会令 mcs.matrix~ 对象所有连接的目标状态以每条连接一个列表的形式，从该对象最右侧的出口送出。该列表由两个数字组成，分别指定输入和输出，后面跟一个 float，指定该连接的目标增益。注意，目标增益不一定与当前增益相同；当前增益可以用 dump 消息获取。

print

左入口：print 一词会令 mcs.matrix~ 对象所有连接的当前状态以每条连接一个列表的形式，打印到 Max Console。该列表由两个数字组成，分别指定输入和输出，后面跟一个 float，指定该连接的增益。

输出

list

右出口：一组描述 matrix~ 对象所有连接当前状态或目标状态的列表，会在收到 dump 或 dumptarget 消息时从右出口送出。

signal

每个出口的输出信号是其各相连入口之和，并按各连接的增益值进行缩放。
