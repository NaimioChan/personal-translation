Max

itable

数据表编辑器

描述

在你的补丁窗口中提供表内容的可视化显示。

参数

tablename [symbol] 可选

参数为 itable 命名。Max 会查找同名的文件来载入。若两个或多个 table 或 itable 对象同名，它们也会共用相同的取值。

特性

annotation_name [symbol] :

信息视图标题

autohint [int] : 1

切换鼠标位于表上时是否显示鼠标位置。

bgcolor [4 floats]

以 RGBA 格式设置表背景颜色。

embed [int] : 1

切换是否将表内嵌并把它随主补丁一起保存。默认行为为 1（保存子补丁）。

linecolor [4 floats]

以 RGBA 格式设置直线工具模式下使用的颜色。linecolor 特性映射到 elementcolor 样式颜色。

name [symbol]

指定表的名称。你也可以用参数指定某个 itable 对象的名称。Max 会查找同名的、已保存为独立文件的 itable 对象。若两个或多个表对象同名，它们也会共用相同的取值。

若要了解在 Max for Live 中如何使用具名对象，请点击此处。

notename [int] : 0

切换是否用 MIDI 音符号显示 Y 轴。

param_connect [symbol] :

在对象与具有参数的兼容对象（如 gen~ 或 jit.gl.slab）的某个参数之间建立双向连接。该对象可用来改变参数的值，参数值变化时它也会随之更新。设置 param_connect 最简便的方法，是使用该特性在 inspector 中的菜单，或使用 Object Action 菜单的 Connect 子菜单。菜单会列出兼容对象的所有可用参数。

用消息设置 param_connect 特性时，需要给出目标参数的路径，即宿主对象的脚本名后跟两个冒号，再加上参数名。例如，对于一个 gen~ 对象，若其脚本名为 gen~_AB，则 freq 参数的路径为 gen~_AB::freq。可以在宿主对象或参数尚不存在时就为 param_connect 设值，该对象会在参数出现后与之建立连接。更多细节请参阅用户指南中 param_connect 条目。

parameter_enable [int]

启用后，该对象可与 Max for Live Parameters 以及 Max 中的初始参数值设置配合使用。

parameter_mappable [int] : 1

启用 parameter_mappable 后，该对象即可通过映射功能映射到键盘或 MIDI 输入。

pointcolor [4 floats]

用 0. - 1. 的 RGBA 格式设置数据显示点的颜色。

range [int]

指定编辑窗口的 y 轴上可显示的取值范围。新建的表取值范围为 128，从 0 到 127。

selectioncolor [4 floats] >= 7.0.0

以 RGBA 格式设置选择工具模式下使用的选中颜色。

shadowalpha [float] : 0.

阴影 alpha

阴影混合

shadowproportion [float] : 0.

阴影比例

signed [int] : 0

切换是否存储并显示带符号整数值。新建的带符号取值的表的取值范围为 128，从 -128 到 127。

size [int]

指定表中存储的取值数量。默认值为 128 个值，索引编号从 0 到 127。

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

textcolor [4 floats]

以 RGBA 格式设置表的文字颜色。textcolor 特性映射到 textcolor_inverse 样式颜色。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

左入口：等同于带一个 0 到 32,768 之间随机数字作为参数的 quantile 消息。

int

左入口：该数字指定 itable 中的一个地址。存储在该地址的取值会从左出口送出。不过，若右入口收到过某个值，itable 会把该值存入指定的地址，而不是送出一个数字。

右入口：该数字指定要存入 itable 的一个值。左入口接下来收到的地址数字会使该值存入那个地址。

参数：

  • index [int]

(inlet1)

右入口：该数字指定一个要存入 itable 的值。左入口随后收到的地址号会使该值存到那个地址上。

参数：

  • input [int]

float

转换为 int。

参数：

  • index [float]

list

左入口：第二个数字会存入 itable，存到第一个数字指定的地址（索引）处。

参数：

  • index [int]
  • value [int]

clear

左入口：把表中的所有值设为 0。

const

左入口：const 一词后面跟一个数字，会把这个数字存到表中的所有地址上。

参数：

  • input [int]

dump

左入口：把表中存储的所有数字从地址 0 开始，接连不断地送往左出口。

fquantile

左入口：fquantile 一词后面跟一个 0 到 1 之间的数字，会把这个数字乘以表中所有数字之和。随后 table 送出这样一个地址：截至该地址的所有值之和大于或等于该结果。

参数：

  • input [float]

getbits

取出表中存储的某个数字的一个或多个特定位的取值，并从左出口把该取值送出。第一个参数是要查询的地址；第二个参数是该地址所存数字中的起始位位置（位位置的编号为 0 到 31，从最低有效位到最高有效位）；第三个参数指定应从起始位位置往右送出多少位。指定的这些位以单个十进制整数的形式从出口送出。

参数：

  • address [int]
  • start [int]
  • bits [int]

goto

左入口：goto 一词后面跟一个数字，会把指针设到该数字指定的地址上。指针最初设在表的开头。

参数：

  • index [int]

handtool

handtool 一词后面跟一个 0 或 1，用于切换是否把 itable 对象设置为使用手形工具。它等价于设置 tool 特性。

参数：

  • flag [list]

inv

左入口：inv 一词后面跟一个数字，会找出第一个大于或等于该数字的值，并把该值的地址送往左出口。

参数：

  • value [int]

length

输出表大小

linetool

linetool 一词后面跟一个 0 或 1，用于切换是否把 itable 对象设置为使用线形工具。它等价于设置 tool 特性。

参数：

  • flag [list]

load

左入口：让对象进入载入模式。在载入模式下，左入口收到的每个数字都会存入表中，从地址 0 开始，直到表被填满为止（或直到表被 normal 消息带出载入模式）。若收到的数字多于表的容量所能容纳的数量，多出的数字会被忽略。

max

取出存储的最大值

min

取出存储的最小值

(mouse)

存储在 table 中的值可以用鼠标以图形方式输入和编辑。

next

左入口：把 goto 指针所指向的地址中存储的值送往左出口，然后把指针设到下一个地址。若指针当前位于 itable 对象的最后一个地址，它会回绕到第一个地址。

normal

左入口：撤销先前的 load 消息；把 itable 对象带出载入模式，恢复为正常工作。

penciltool

penciltool 一词后面跟一个 0 或 1，用于切换是否把 itable 对象设置为使用铅笔工具。它等价于设置 tool 特性。

参数：

  • flag [list]

prev

左入口：产生的输出与 next 一词相同，但随后指针是递减而不是递增。若指针当前位于 itable 对象的第一个地址，它会回绕到最后一个地址。

quantile

左入口：quantile 一词后面跟一个数字，会把这个数字乘以 itable 对象中所有数字之和。该结果随后除以 2^15（32,768）。接着 table 送出这样一个地址：截至该地址的所有值之和大于或等于该结果。

参数：

  • number [int]

read

左入口：read 一词后面跟一个名称，会打开并读取 Text 或 Max 二进制格式文件中的数据值。不带参数时，read 会打开标准的 Open Document 对话框，以选择要从中读取值的文件。若文件包含有效数据，现有表的全部内容会被该数据替换。

参数：

  • filename [symbol]

refer

左入口：refer 一词后面跟另一个表的名称，会把接收方的 itable 对象设置为从具名的 table 对象读取它的数据值。

参数：

  • name [symbol]

selecttool

selecttool 一词后面跟一个 0 或 1，用于切换是否把 itable 对象设置为使用选择工具。它等价于设置 tool 特性。

参数：

  • flag [list]

send

send 一词后面跟一个 receive 对象的名称，再跟一个地址号，会把存储在该地址上的值送给所有叫这个名字的 receive 对象，而不把该值送往 itable 对象的出口。

参数：

  • receive-name [symbol]
  • address [int]

set

左入口：set 一词后面跟一串数字，会把值存入若干特定地址。set 一词后面的第一个数字指定一个地址。下一个数字是要存入该地址的值，此后的每个数字依次存入后面各个地址。

参数：

  • start [int]
  • values [list]

setbits

左入口：修改 itable 对象中存储的某个数的一个或多个特定位的值。setbits 一词后面跟四个数字参数。第一个参数是所涉及的地址；第二个参数是该地址所存数字中的起始位位置（位位置编号为 0 到 31，从最低有效位到最高有效位）；第三个参数指定从起始位位置起向右应修改多少位，第四个参数是这些位要设成的值（用十进制或十六进制形式表示）。
例如，消息 setbits 47 5 3 6 会查看 itable 对象中的地址 47，从位位置 5（右起第六位）开始，把从该位置起的 3 位替换为位 110（十进制整数 6 的二进制形式）。假设 itable 对象的地址 47 存储的数字是 87。87 的二进制形式是 1 010 111，因此把位位置 5 起的 3 位替换为 110 会把该数字变成 1 110 111，也就是十进制整数 119 的二进制形式。所以 itable 对象中地址 47 存储的新数字将是 119。

参数：

  • address [int]
  • start [int]
  • count [int]
  • value [int]

sum

左入口：把 itable 对象中所有值之和送往左出口。

write

左入口：打开标准的保存文件对话框，以选择把 itable 对象中的数据值写入哪个名称的文件。文件可按 Text 或 Max 二进制格式保存。
