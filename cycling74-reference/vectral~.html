MSP

vectral~

基于信号向量的包络跟随器

描述

用 vectral~ 对象过滤基于帧的信号数据，例如 fft~ 对象的输出。

讨论

它可以按下列模式之一运行：
rampsmooth <up> <down>- 在 up/down 帧上线性斜坡到新的取值
slide <up> <down>- 对数式移动到新的取值
deltaclip <max> <min>- 把采样点的变化限制在给定的范围内

参数

vector-size [int] 可选

该参数是执行操作所用的向量大小。默认为 512，但应当根据你送入 vectral~ 对象的向量大小做相应的设置。

消息

clear

清空对象的采样点记忆（以免数值爆掉）。

deltaclip

左入口：单词 deltaclip 后面跟两个 float，把相邻向量各频率槽的变化限制在给定的取值内。这等价于时域的 deltaclip~ 对象。

参数：

  • low-limit [float]
  • high-limit [float]

rampsmooth

左入口：单词 rampsmooth 后面跟两个 int，会让该向量在相邻各帧之间按线性方式平滑。这些参数指定两个方向上用于插值取值的帧数。这等价于 rampsmooth~ 对象所做的时域滤波。

参数：

  • number-of-interpolating-frames [list]

signal

左入口：输出向量索引的同步信号。取值范围通常是 0 到 n-1（其中 n 是该向量的大小）。

中间入口：在中间入口收到的同步信号用于同步正在处理的向量的输入索引。该同步信号的取值范围通常是 0 到 n-1（其中 n 是该向量的大小）。若左入口与中间入口 “不同步”，传入向量的各频率槽会按两个信号的差值发生偏移。

右入口：要过滤的信号数据。这通常是频域信息，例如 fft~ 或 fftin~ 对象的输出。

size

左入口：单词 size 后面跟一个数字，设置执行操作所用的向量大小。默认为 512。

参数：

  • vector-size [int]

slide

左入口：单词 slide 后面跟两个 float，会让 vectral~ 对相邻向量做对数插值，其方式等价于时域的 slide~ 对象。这两个参数决定滑动量的分母系数。

参数：

  • slide-denominator-coefficients (2 floats) [list]

输出

signal

送入右入口的信号经过平滑后的版本，具体取决于赋给 vectral~ 对象的参数。
