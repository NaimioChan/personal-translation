Max

counter

基于 bang 消息计数

描述

输出受指定范围约束的当前 bang 消息计数。可以设置为向上计数、向下计数，或先向上再向下计数。

参数

options [int] 可选

若只有一个参数，它会为 counter 设置初始的最大计数值。若有两个参数，第一个数字设置初始最小值，第二个数字设置初始最大值。若有三个参数，第一个数字指定计数方向，第二个数字是最小值，第三个数字是最大值。若没有参数，方向为向上，最小值为 0，最大值为 2,147,483,647（32 位有符号整数所能取到的最大值）。

特性

carryflag [int] : 0

设置第三个出口输出的数据类型（数字或 bang）。
可选值：

0 = 'Numeric'
1 = 'Bang'

compatmode [int] : 0

在导入用 Max 3.x 及更早版本创建的补丁时提供兼容性。选中 "Ancient" 时，向入口 3 和 4 发送一个 int 会改变最小计数值，而不只是临时重置它（后者会使第四个入口的行为完全等同于把 min 消息发给 counter 对象）。
可选值：

0 = 'Current'
1 = 'Ancient'

消息

bang

左入口：发出左入口收到的 bang 消息的当前计数。

左中间入口：改变计数方向。

中间入口：把计数重置为指定的最小值，该值会在下次左入口收到 bang 时发出。

右中间入口：把计数重置为指定的最小值，并立即发出该值。

右入口：把计数重置为指定的最大值，该值会被立即发出。

int

左入口：效果与 bang 相同。

左中间入口：设置计数方向。0 使 counter 向上计数，1 使其向下计数，2 使其向上再向下计数。

中间入口：该数字把 counter 设置为一个新值，该值会在下次左入口收到 bang 时发出。若该数字小于当前最小值，最小值会被重置为该数字。若该数字大于当前最大值，counter 会被设置为该数字，但最大值实际上保持不变，而最小值被设置为等于最大值。

中右入口：该数字把 counter 设置为一个新值并立即发出。若该数字小于当前最小值，最小值会被重置为该数字。若该数字大于当前最大值，该数字会被发出，但最大值实际上保持不变，而最小值被设置为等于最大值。

右入口：重置 counter 发出的最大值。若该数字小于当前最小值，则最大值等于最小值。若随后最小值被改为低于你输入的最大值的值，counter 对象会保留它通过此入口收到的正确最大值。与 bang 消息不同，此入口中的 int 不会使 counter 对象输出任何东西。

参数：

  • input [int]

float

所有其他入口：转换为 int。

参数：

  • input [float]

carrybang

左入口：使 counter 在计数向上并达到最大限制时从右中间出口发出一个 bang，并使 counter 在计数向下并达到最小限制时从左中间出口发出一个 bang。（默认情况下，counter 在这些情形下发出的是数字 1，而不是 bang。）carrybang 消息的状态会随使用它的补丁一起保存。

carryint

左入口：撤销先前收到的 carrybang 消息的效果。把 counter 重置为从左中间出口和右中间出口发出数字 1 和 0（而不是 bang），以标示 counter 何时达到和离开其最小值和最大值。carryint 消息的状态会随使用它的补丁一起保存。

dec

左入口：把 counter 递减（向下）并发出新的值，不论该对象通常被设置为按哪个方向计数。

down

左入口：把 counter 设置为向下计数。

flags

flags 消息后面跟两个数字，会设置 Underflow/Carry 模式并设置 Minimum-Mode 重置能力。若第一个数字为 0，counter 在到达最大值时会输出 1，否则输出 0。若第一个数字为 1，counter 在到达最大值时会输出一个 bang。若第二个数字为 0，入口 3 和 4 中的整数会临时覆盖最小计数值。若第二个数字为 1，入口 3 和 4 中的整数会永久改变最小计数值。

参数：

  • carry-mode [int]
  • minimum-mode [int]

goto

左入口：效果与 set 相同。

参数：

  • input [int]

inc

左入口：把 counter 递增（向上）并发出新的值，不论该对象通常被设置为按哪个方向计数。

jam

左入口：jam 一词后面跟一个数字，会把 counter 设置为该数字并立即把该数字发出。若该数字超出最小与最大计数范围，此消息会被忽略。

参数：

  • input [int]

max

左入口：max 一词后面跟一个数字，会把 counter 的最大值重置为该数字。若该数字小于当前最小值，最大值被视为等于最小值，尽管你设置的实际最大值存储在 counter 对象内部。

参数：

  • maximum [int]

min

左入口：min 一词后面跟一个数字，会把 counter 的最小值重置为该数字，并使 counter 对象把自身设置为该数字并立即输出。若该数字大于当前最大值，最小值会被设置为等于最大值。

参数：

  • minimum [int]

next

左入口：与 bang 相同。

set

左入口：set 一词后面跟一个数字，会把 counter 设置为该数字，该数字会在下次左入口收到 bang 时发出。

参数：

  • input [int]

setmin

左入口：setmin 一词后面跟一个数字，会设置 counter 对象的最小计数值，而不影响其当前计数值，也不产生任何输出。

参数：

  • minimum [int]

state

state 消息会使 counter 对象把其当前状态报告给 Max 控制台。

up

左入口：把 counter 设置为向上计数。

updown

左入口：设置 counter 对象的计数方向，使其先向上计数直到到达指定的最大值，再向下计数直到到达指定的最小值，然后向上、再向下，如此反复。

输出

bang

左中间出口：若左入口收到过 carrybang 消息，那么当计数向下移动并达到最小限制时，会发出一个 bang（而不是默认发出的数字 1）。当计数离开最小限制时，不发出任何东西。这仅在模式 1（向下计数）或模式 2（向上再向下计数）下有效。

右中间出口：若左入口收到过 carrybang 消息，那么当计数向上移动并达到最大限制时，会发出一个 bang（而不是默认发出的数字 1）。当计数离开最大限制时，不发出任何东西。这仅在模式 0（向上计数）或模式 2（向上再向下计数）下有效。

int

左出口：当左入口收到 bang、next、inc、dec 或一个数字时，会在指定的最小与最大限制范围内发出当前计数。若计数方向为既向上又向下，计数在到达指定限制时会折返到另一方向。若计数只有一个方向，向上或向下，计数在到达其限制时会回绕到相反的一端。

当方向为向上，或向上再向下时，counter 从指定的最小值开始计数。当方向为向下时，counter 从最大值开始。

左中间出口：当计数向下移动并达到最小限制时，发出数字 1。当计数离开最小限制时，发出 0。这仅在模式 1（向下计数）或模式 2（向上再向下计数）下有效。

右中间出口：当计数向上移动并达到最大限制时，发出数字 1。当计数离开最大限制时，发出 0。这仅在模式 0（向上计数）或模式 2（向上再向下计数）下有效。

右出口：另外还会记录 counter 到达最大限制的次数。每次到达最大值时，都会把该计数发出。
