Max

qlist

存储一组消息

描述

以消息的形式存储一组定时或不定时的 "cues"，这些消息既可以经由它的出口送出，也可以远程发送到补丁中的各个 receive 对象。

讨论

双击该对象会打开一个文本编辑器，你可以在其中输入或编辑 qlist 对象的提示列表。提示列表的每一行都是一条以分号结尾的消息。各行不需要编号或加索引（与 coll 对象不同），但这里有几处特殊之处需要说明。

提示列表中的行有三种不同的消息格式：只含数值的行（即一个 int、float 或 list）、以 symbol 开头的行（即消息名和参数），以及以数值（或数值组成的 list）开头、随后带有一个带参数的 symbol（消息名）的行。qlist 对这三种行的处理方式各不相同。只含数值的行从 qlist 对象的左出口送出，而以符号开头的行则远程发送到以该符号命名的 receive 对象。（注意，这类似于从 message 对象框远程发送消息 —— 第一个分号之前的内容从出口送出，每个分号之后的消息则远程发送到具名的 receive 对象。）以数值（或若干数值）开头、但在数字之后带有消息和参数的行，会被当作两行来处理 —— 第一部分（全为数值）从左出口送出，第二部分（消息）则远程发送到一个 receive 对象。

当 qlist 收到输出数据的命令（例如 next 消息）时，它会把所有以符号开头的行发送到相应的 receive 对象，并在输出完以数字开头的那一行的数值内容之后停下。qlist 对象还有一个内部计时器，用于自动依次播放。发送一个 bang 消息给 qlist 会使它播放提示列表的全部内容。当某一行以数字开头时，qlist 会把该数字用作毫秒延迟时间，然后再继续输出或发送其余的提示。

qlist 对象会把它的提示列表随补丁一起保存。

无。

消息

bang

向 qlist 发送 bang 会触发整个提示列表的自动播放。它从第一行开始发送消息，直到遇到以数字开头的行，此时 qlist 会把该数字用作毫秒延迟时间，然后继续发送其余消息。正在自动播放的 qlist 可以用 stop 消息停止。

append

append 一词后面跟任意参数，会把这些参数追加到 qlist 对象提示列表的最后一项。要追加分号，必须在分号前面加一个反斜杠字符。

参数：

  • message [list]

clear

clear 一词会清除提示列表的内容。这与发送不带参数的 set 消息相同。

(mouse)

用鼠标双击 qlist 对象，会在一个用户可修改的编辑窗口中把它的内容以文本形式显示出来。

fwd

fwd 一词后面跟一个数字，用于 "fast forward" 跳过给定数量的行，而不向具名的 receive 对象远程发送消息。例如 fwd 2 会输出提示列表中接下来两行以数值开头的行。以符号开头的行会被忽略。

参数：

  • lines [int]

insert

insert 一词后面跟任意参数，会把这些参数作为一个新项追加到 qlist 对象的提示列表中。要追加分号，必须在分号前面加一个反斜杠字符。

参数：

  • message [list]

next

next 一词用于输出提示列表中的下一行。它会远程发送所有以符号开头的行，并在遇到并输出一行以数值开头的行之后停下。若 next 一词后面跟一个非零参数，它会忽略以符号开头的行，只输出下一行以数值开头的行。

参数：

  • ignore-symbols [int]

open

open 一词会打开 qlist 对象的文本编辑窗口。

read

read 一词让你可以通过标准的 Max 打开文件对话框从磁盘读取文件。若后面跟一个符号参数，Max 会把该符号用作文件名（或文件路径加文件名），并尝试从磁盘读取具有该名称的文本文件。

参数：

  • filename [symbol]

rewind

移到文件的开头

set

set 一词可用于设置 qlist 对象的内容。它会完全清除先前提示列表的所有内容。发送不带参数的 set 消息与发送 clear 消息相同。

参数：

  • cue-list-contents [list]

stop

stop 一词可用于停止一个 qlist，该对象因收到 bang 消息而正处于播放过程中。

tempo

tempo 一词后面跟一个浮点数值，可用于让 qlist 以比提示列表内部所存毫秒值更快或更慢的速度自动播放。默认 tempo 为 1.0，表示播放速度不缩放。tempo 为 0.5 时以半速播放提示列表，而 tempo 为 2. 时以两倍速播放。

参数：

  • tempo-multiplier [float]

wclose

wclose 一词会关闭 qlist 对象的文本编辑窗口。

write

write 一词让你可以通过标准的 Max 保存文件对话框保存文件。若后面跟一个符号参数，Max 会把该符号用作文件名（或文件路径加文件名），并把具有该名称的文本文件写入磁盘。

参数：

  • filename [symbol]

输出

bang

中间出口。当提示列表到达末尾、没有更多行可发送或输出时，会送出一个 bang。

bang

右出口。当文件已成功从磁盘读出时，会送出一个 bang。

int

左出口。qlist 对象在提示列表中的某一行以数字开头时，会输出一个数值或一组数值。输出通常是对 next 或 fwd 消息的响应，但也可能是对象内部计时器在收到 bang 消息而播放整个提示列表时的结果。

list

左出口。qlist 对象在提示列表中的某一行以数字开头时，会输出一个数值或一组数值。输出通常是对 next 或 fwd 消息的响应，但也可能是对象内部计时器在收到 bang 消息而播放整个提示列表时的结果。
