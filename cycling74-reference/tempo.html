Max

tempo

按节拍器速度输出数字

描述

产生节拍器式的输出，可用每分钟节拍数控制，并可指定全音符的分割方式。

参数

tempo [int or float] 可选

第一个参数设置初始速度，从每分钟 5 到 300 拍。若没有参数，初始速度为每分钟 120 拍。第二个参数是节拍倍率，默认为 1。第三个参数设置输出的初始节奏值，从全音符（1）到六十四分音符三连音（96）。若没有给出该参数，初始值为 16。

消息

bang

左入口：启动 tempo 对象的节拍器进程；若 tempo 已经启动，则重新启动。

int

转换为 float。

参数：

  • input [int]

float

左入口：若该数字不是 0，效果与 bang 相同。若该数字是 0，效果与 stop 相同。

第二个入口：该数字作为速度存储，单位为每分钟节拍数（每分钟四分音符数）。

第三个入口：该数字是节拍倍率，可以拉长一拍所用的时间。它会按某个倍数减慢速度。例如，倍率为 2 时会使 tempo 以一半的速度送出输出。

右入口：该数字是 tempo 送出的节奏值，以全音符的分数形式指定。例如，数字 8 会使 tempo 相对于指定的（四分音符）速度输出八分音符。从出口送出的数字会在 0 到比节奏值小 1 的数字之间连续循环。全音符的分割数必须在 1 到 96 之间。

参数：

  • input [float]

clock

单词 clock 后面跟一个已存在的 setclock 对象的名称，会把 tempo 对象设置为由该 setclock 对象控制，而不是由 Max 内部的毫秒时钟控制。单独的单词 clock 会把 tempo 对象重新设置为使用 Max 常规的毫秒时钟。

参数：

  • name [symbol]

stop

左入口：停止 tempo。

tempo

左入口：单词 tempo 后面跟一个 float，会把当前速度设为该数字。

参数：

  • tempo [list]

输出

int

tempo 启动后会以连续循环的方式输出数字，从 0 到比指定的节奏值小 1 的数字。数字送出的速度由速度（每分钟四分音符数）和输出的节奏值（全音符的分数）决定。
