MSP

vst~

承载 VST、VST3 与 Audio Unit 插件

描述

用 vst~ 对象载入实时的 VST、VST3 或 Audio Unit 插件，并在 MSP 中使用它的音频处理。当 vst~ 以 mcs.vst~ 的形式实例化时，该插件的音频输入会被合并为单个多通道入口，音频输出会被合并为单个多通道出口。

讨论

有些插件有自己的编辑窗口，双击对象时该窗口会显示出来。否则，双击对象会显示一个默认的参数编辑窗口。信号入口数与出口数默认为 2，但插件所需的数目可能少于这个数。如果你想指定更多的入口和出口数量，可以把它们作为可选参数提供。
载入到 vst~ 对象中的音频插件可以通过启用全局走带来同步（从 Extras 菜单选择 GlobalTransport，然后点击全局走带的 Activate 按钮）。

参数

number-of-inputs/outputs [int] 可选

若第一个参数是数字，或者第一个和第二个参数都是数字，它们就设置音频入口和出口的数量。若只有一个数字，它设置出口数。若有两个数字，第一个设置入口数，第二个设置出口数。

VST-plugin-filename [symbol] 可选

设置对象创建时要载入的 VST 或 Audio Unit 插件文件的名称。你可以在对象创建之后用 plug 消息载入插件（或替换当前正在使用的那个）。

preset-effects-name [symbol] 可选

在插件名称之后，可以指定一个包含该插件预设效果的名称。若找到了，它会在插件载入之后被载入。

特性

annotation_name [symbol] :

注释名称

autosave [int] : 1

自动保存快照

bypass [int] : 0

旁通插件的处理，让所有音频原样通过 vst~ 对象。

currentplug [atom] 只读

当前载入的插件

enablehscroll [int] : 0 >= 7.0.0

启用水平滚动条

enablevscroll [int] : 1 >= 7.0.0

启用垂直滚动条

floateditorwindow [int] : 0

浮动编辑窗口

genericeditor [int] : 0 >= 7.0.0

为插件使用通用编辑器界面。请注意，某些 Audio Unit 插件不会显示通用界面。

legacytransport [int] : 0

早期版本的 Max 没有正确地把 Max 走带与插件的内部走带关联起来。如果现有补丁的正常工作需要旧有的行为，可以启用此特性以实现向后兼容。新行为（特性禁用）通常更可取。

mcisolate [int] : 0

把参数变化隔离到指定通道。

parameter_enable [int] >= 7.0.0

启用后，该对象可与 Max for Live Parameters 以及 Max 中的初始参数值设置配合使用。

prefer [symbol] : VST

在没有其他信息的情况下（例如指向插件文件的绝对路径，或明确的键入型插件路径，如 OSX 上的 C74_VST:/[pluginname]、C74_VST3:/[pluginname] 或 C74_AU:/[pluginname]），prefer 特性会用来在使用 plug 消息时，优先载入某一种插件格式，然后再考虑其他可用的格式。请注意，也可以用 plug_vst、plug_vst3 和 plug_au 这几个变体来覆盖所指定的偏好。
可选值：

'VST'
'VST3'
'AudioUnit'

transport [symbol]

设置走带名称。默认情况下此项未设置，vst~ 对象会使用默认走带（Max 中为 Global Transport，Max for Live 中为 Live 的走带）。设置此项后可以同步到用户自定义的走带与时钟源。

valuemode [int] : 0

决定 vst~ 对象右数第五个出口的输出。在 Value 模式（默认：0）下，对象会送出参数的索引，后面跟一个 0. 到 1. 之间的浮点值（例如 2 0.25）。在 String 模式（1）下，对象会送出参数的索引，后面跟一个 symbol 取值（例如 2 -6dB）。在 Both 模式（2）下，对象会送出参数的索引，后面跟一个浮点值和一个 symbol 取值（例如 2 0.25 -6dB）。
可选值：

0 = 'Value'（输出参数归一化后的取值（0. - 1.））
1 = 'String'（输出参数的符号取值）
2 = 'Both'（先输出参数归一化后的取值，再输出符号取值）

快照特性

autosave [int] 只写

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

int

左入口：改变当前载入插件的效果程序。第一个程序的编号是 1。

参数：

  • effect-program [int]

float

左入口：浮点值会被转换为 int 值，并用来改变当前载入插件的效果程序。第一个程序的编号是 1。

参数：

  • effect-program [float]

list

左入口：改变当前载入插件中的某个参数取值。列表的第一个元素是参数编号（从 1 开始），第二个元素是参数取值。第二个数字应当是 0 到 1 之间的 float，其中 0 是该参数的最小值，1 是最大值。

参数：

  • plugin-parameter [symbol]
  • setting [float]

anything

一个为插件参数命名的 symbol，后面跟一个 0 到 1 之间的 float，用于设置该参数的取值。

参数：

  • plugin-parameter [symbol]
  • setting [float]

(drag)

当把插件文件从 File Browser 拖到 vst~ 对象上时，该插件会被载入。

(mouse)

双击 vst~ 对象会打开插件的编辑窗口。

disable

单词 disable 后面跟一个非零参数时，会停止当前载入插件的任何后续处理，并输出零信号。disable 0 会启用该插件的处理。

参数：

  • mute-flag (0 or nonzero) [int]

drop

卸载当前载入的插件。

get

单词 get 后面跟一个数字或符号参数，会报告参数值与插件信息。这些内容从 vst~ 对象右数第五个出口送出，形式为一个列表，第一个元素是查询索引（或插件信息索引），第二个元素是所要的信息。

若给出的是 symbol 参数，且该 symbol 对应某个参数的名称，get 消息会输出该具名参数的当前参数值（一个 0 到 1 之间的 float）。否则不输出任何内容。

若给出的是数字参数，且该数字参数介于 1 与当前载入插件的参数个数之间（含两端），get 消息会输出该编号参数的当前参数值（一个 0 到 1 之间的 float）。若该参数为 0，则不输出任何内容。

若给出的是负数的数字参数，get 消息会输出一个列表，第一个元素是该数字参数，其余元素指定下列信息：

get -1 插件的入口数
get -2 插件的出口数
get -3 插件的程序个数（VST）或出厂预设个数（Audio Unit）
get -4 插件的参数个数
get -5 插件的 canMono 标志是否置位。它表示该插件既可用于立体声语境，也可用于单声道语境
get -6 若插件有自己的编辑窗口则为 1，否则为 0
get -7 若插件是合成器插件则为 1，否则为 0
get -8 插件的唯一 ID，为一个整数值
get -9 四个整数值，分别表示插件 UI 编辑窗口所需矩形的左、上、右、下坐标
get -10 一个整数值，表示插件的初始延迟（以采样点为单位），让你可以在补丁中自动补偿插件的延迟
get -11 插件的用户预设文件个数（仅 Audio Unit）

参数：

  • parameter-data-query-index or parameter-name [int or symbol]

getsubnames

左入口：用 vst~ 对象承载一个未以特定插件名实例化的 VST shell 插件（例如 WaveShell）时，单词 getsubnames 会使一串子插件名称从 vst~ 对象右数第二个出口送出。

midievent

单词 midievent 后跟两到四个数字，会把一个 MIDI 事件发送给插件。前三个数字参数是 MIDI 消息的字节。第四个参数是可选的，它是一个用于 MIDI 音符消息的失谐参数。取值范围为 -63 到 64 音分，默认值为 0。

参数：

  • MIDI-message (2 to 4 numbers) [list]

mpeevent

向所承载的 VST、VST3 或 Audio Unit 插件发送 MPE 消息。

参数：

  • MPE-messages [list]

open

不带参数的单词 open 会打开插件的编辑窗口。若该窗口此前打开过，编辑窗口的位置会保持不变。单词 open 后面跟两个分别指定窗口左侧和顶部坐标的整数值时，会打开插件的编辑窗口，或把它移动到给定的坐标。

参数：

  • window-coordinates [list]

params

单词 params 会使一串插件的参数从右数第六个出口送出。

pgmnames

单词 pgmnames 会使一串插件当前的程序名称从右出口送出。

plug

左入口：不带参数的单词 plug 会打开标准的打开文件对话框，让你选择要承载的新 VST 或 Audio Unit 插件。单词 plug 后面跟一个 symbol 参数时，会在 Max 搜索路径中查找指定名称的插件。若打开并找到了新的插件，旧的插件（若有）会被丢弃，新插件会被载入。plug 消息可选的第二个参数可用于指定某个 shell 插件（例如 WaveShell）内部的插件名称。它既可以是插件的符号名称，也可以是用 printids 消息显示出来的关联 ID 值）。

对于 mc.vst~，若特性 @mcisolate 设为 1，发送 plug 消息将允许用户为每个实例单独载入一个 VST。当 @mcisolate 设为 0 时，收到的任何 plug 消息都会把该插件载入到所有实例。

Max 应用程序启动时，系统 VST 文件夹会被加入 Max 搜索路径。在 Macintosh 上，该路径通常是 /Library/Audio/Plug-ins/VST/，而在 Windows 上则是注册表键 HKLM\Software\VST 下 VSTPluginsPath 字符串值所指定的文件夹。在 Mac OS 上，Audio Unit 插件会被扫描，Apple 内置插件和用户安装插件的 .auinfo 文件会被加入搜索路径。

参数：

  • plug-in-name [symbol]

plug_au

按名称尝试载入一个 AudioUnit 插件。等价于 plug C74_AU:/<plug-in name>。

参数：

  • filename [list]

plug_vst

按名称尝试载入一个 VST 插件。等价于 plug C74_VST:/<plug-in name>。

参数：

  • filename [list]

plug_vst3

按名称尝试载入一个 VST3 插件。等价于 plug C74_VST3:/<plug-in name>。

参数：

  • filename [list]

presetnames

仅对 Audio Unit 插件：单词 presetnames 会使一串该插件的用户预设文件名从右出口送出。

printids

左入口：用 vst~ 对象承载一个未以特定插件名实例化的 VST shell 插件（例如 WaveShell）时，单词 printids 会使一串子插件 ID 显示在 Max Console 中。

read

不带参数时，read 会打开标准的打开文件对话框，提示选择一个包含效果程序的文件，可以是程序组格式或单个程序格式。read 接受一个可选的 symbol 参数，它会在 Max 搜索路径中查找 VST 插件程序组或效果程序文件。

参数：

  • filename [symbol]

scan

重新扫描系统 VST 文件夹以查找新的插件。在 Macintosh 上，该路径通常是 /Library/Audio/Plug-ins/VST/，而在 Windows 上则是注册表键 HKLM\Software\VST 下 VSTPluginsPath 字符串值所指定的文件夹。在 Mac OS 上，Audio Unit 插件会被扫描，Apple 内置插件和用户安装插件的 .auinfo 文件会被加入搜索路径。可选参数 0、1、2 或 3 把扫描类型分别设为 0=默认、1=部分、2=完整、3=重置。

参数：

  • scan type [int]

set

左入口：单词 set 后面跟一个符号，会把当前效果程序的名称改为该符号。

参数：

  • effect-program-name [symbol]

signal

要由插件处理的输入。若插件是乐器插件，该输入会被忽略。

subname

左入口：单词 subname 后面跟一个插件名称或插件 ID，会使某个 shell VST 插件（例如 WaveShell）以指定的名称/ID 被重新实例化。

参数：

  • plug-in-name [symbol]

sysexevent

单词 sysexevent 后面跟一串数字，会把一条 sysex 消息发送给插件。该消息应当完整且格式正确（例如带有开头的 0xF0（240）字节和结尾的 0xF7（247）字节）。若列表中的第一个数字不是 0xF0（240），它会被解释为该消息的采样点偏移。

参数：

  • sample-offset [int]
  • sysex-bytes [list]

unplug

卸载当前载入的插件。

wclose

关闭插件的编辑窗口。

write

对于 VST 插件，不带参数时 write 会打开标准的 Save As 对话框，提示你选择效果程序文件的名称和类型（单个程序或程序组）。write 接受一个可选的 symbol 参数，用于指定完整或部分的目标路径名。这种情况下写入的是单个程序文件。对于 Audio Unit 插件，文件名参数是必需的，它指定一个用户预设的名称，该预设会被写入标准的插件用户预设位置。

参数：

  • file/pathname [symbol]

writebank

没有参数时，writebank 会打开标准的 Save As 对话框，提示你选择效果程序组文件的名称。writebank 接受一个可选的 symbol 参数，用于指定完整或部分的目标路径名。对于 Audio Unit 插件，writebank 消息与 write 相同，只会把当前设置保存到具名文件。

参数：

  • program-bank-file/pathname [symbol]

writepgm

没有参数时，writepgm 会打开标准的 Save As 对话框，提示你选择单个效果程序文件的名称。writepgm 接受一个可选的 symbol 参数，用于指定完整或部分的目标路径名。对于 Audio Unit 插件，writepgm 消息与 write 相同，会把当前设置保存到具名文件。

参数：

  • inividual-effect-program-file/pathname [symbol]

快照消息

snapshot >= 7.0.0

创建快照。embedsnapshot 打开时，快照会保存到当前补丁中；否则会保存到外部文件。可以通过该消息的一个参数指定文件名。

参数：

  • file-name [symbol]

restore >= 7.0.0

恢复快照。embedsnapshot 打开时，会使用嵌入当前补丁中的快照；否则会从外部文件加载。可以通过该消息的一个参数指定文件名。

参数：

  • file-name [symbol]

addsnapshot

添加新快照。若没有参数，会把新快照追加到当前快照列表末尾。若第一个参数是包含文件路径的字符串，Max 会尝试把 .maxsnap 文件保存到该位置。若第一个参数是数字，会把快照保存到该槽位，其后的槽位索引依次递增。若第二个参数是字符串，会设置该快照的名称。

参数：

  • userpath [String]
  • index [Number]
  • name [String]

deletesnapshot

删除给定索引处的快照，其后的槽位索引依次递减。

参数：

  • index [Number]

exportsnapshot

从第一个参数指定的索引处导出快照。第二个参数指定导出 maxsnap 文件的文件名与路径。若第二个参数为空，会打开 File 对话框，供你指定文件名和位置。

参数：

  • index [Number]
  • filename [String]

importsnapshot

把快照导入到第一个参数指定的索引处。第二个参数指定要加载 maxsnap 文件的文件名与路径。若第二个参数为空，会打开 File 对话框，供你选择文件。

参数：

  • index [Number]
  • filename [String]

setsnapshotname

设置给定索引处快照的名称。

参数：

  • index [Number]
  • name [String]

setembedsnapshot

设置该索引处快照的嵌入状态。

参数：

  • index [Number]
  • embedstate [Number]

movesnapshot

更改快照的索引。

参数：

  • srcindex [Number]
  • dstindex [Number]

输出

float

右数第五个出口：响应 get 消息而送出的参数值或插件信息值。

int

右数第五个出口：响应 get 消息而送出的参数值或插件信息值。

右数第四个出口：插件收到的原始 MIDI 字节（但不包括用 midievent 消息收到的任何 MIDI 消息）。不过请注意，有些插件会把自己的 MIDI 输入回显到自己的 MIDI 输出。

list

右数第二个出口：当某个 VST shell 插件（例如 WaveShell）在未指定插件名称的情况下被实例化时，响应 printids 消息，会从第七个出口送出一串指定子插件 ID 的 symbol。

signal

左出口（以及由输出数量参数所定义的其他信号出口）：来自插件的音频输出。左出口是左通道（即通道 1）。

symbol

右数第六个出口：响应 params 消息时，插件的参数会以一连串 symbol 的形式送出。
注意：有些插件，尤其是自带编辑器的插件，无法给参数命名。

右数第三个出口：响应 pgmnames 消息时会送出一连串 symbol。若没有程序名，会输出消息 pgmnames: Default。

右数第二个出口：当某个 VST shell 插件（例如 WaveShell）在未指定插件名称的情况下被实例化时，响应 getsubnames 消息，会从第七个出口送出一串指定插件名称的 symbol。

右出口：响应 presetnames 消息时，Audio Unit 插件的用户预设文件会以一连串 symbol 的形式送出。
