Max

transport

控制时钟

描述

为链接到 transport 的对象启动和停止时间的流逝。若给出了名称，transport 对象会控制给定名称的时间上下文；否则它会控制 Max 的全局 'internal' transport。transport 对象报告的时间与 Max 中使用的时间格式一致。

讨论

面向 Max for Live 用户的说明：目前，转换 Max for Live 中拍时间形式的乐曲位置时，只会考虑全局速度，当 Live set 包含速度变化时可能不准确。

参数

无。

特性

clocksource [symbol]

transport 当前的时间来源。默认来源是 Max 的内部时钟，但也可以使用其他时间来源。

name [symbol]

可以有多个具名 transport 同时运行。默认情况下，transport 会与 Max 的全局 transport 关联。若提供了名称，就会创建一个使用该名称的新 transport，并可以用该特性来引用它。

resetbarcount [int]

切换收到拍号变化时，小节/拍/单位计数器是否前进到下一小节的开头。默认情况下该功能被禁用（0）。

tempo [float]

设置该 transport 的速度，单位为每分钟拍数（BPM）。

size [2 floats] 只写

消息

bang

报告当前状态

int

左入口：切换 transport 是在运行还是停止
右入口：以 ticks 为单位设置 transport 的当前位置

参数：

  • input [int]

float

左入口：切换 transport 是在运行还是停止
右入口：以 ticks 为单位设置 transport 的当前位置

参数：

  • input [float]

list

用时间单位设置 transport 的当前位置。

参数：

  • position [list]

(mouse)

双击 transport 对象会打开 GlobalTransport 窗口。

dump

使 transport 当前状态的报告被发送到 Max Console。

getclocksources

使一份活动时钟来源的列表从右出口送出。

timesig

用两个数字设置该 transport 的拍号。默认是 4 4。

参数：

  • beats [list]
  • value [list]

输出

float

第三个出口：当 transport 收到 bang 时，单位会从第三个出口送出。

第四个出口：当 transport 收到 bang 时，当前分辨率（每拍的 ticks 数）会从第四个出口送出。

第五个出口：当 transport 收到 bang 时，当前速度会从第五个出口送出。

第八个出口：当 transport 收到 bang 时，原始 ticks 的数量会从第八个出口送出。

int

第一个出口：当 transport 收到 bang 时，当前小节会从第一个出口送出。

第二个出口：当 transport 收到 bang 时，当前拍（小节内的拍）会从第二个出口送出。

第七个出口：当 transport 收到 bang 时，Transport State 会从第七个出口送出。取值 1 表示 transport 处于开启状态，取值 0 表示 transport 处于关闭状态。

list

第六个出口：当 transport 收到 bang 时，当前拍号会从第六个出口送出。

第九个出口：当消息 getclocksources 被发往 transport 时，一份活动时钟来源的列表会从右出口送出。
