MC

mc.generate~

为一段通道范围生成取值

描述

mc.generate~ 对象允许随触发信号或参数输入的变化，以信号速率更新 deviate、spread 和 harmonic 这类 MC 包装特性。其中一条包装消息被指派为运算符。

参数

initial-parameter-1 [float] 可选

参数 1 的初始值

initial-parameter-2 [float] 可选

参数 2 的初始值

initial-parameter-3 [float] 可选

参数 3 的初始值

特性

chans [int]

chans 特性设置输出多通道信号的通道数。若在音频开启时改变 chans 特性，通道数会在音频重新启动时改变。

op [symbol]

用 op 选择用于生成取值的运算符。可选值为 deviate、increment、spread、spreadinclusive、spreadexclusive、spreadincludesecond、spreadincludefirst、harmonic、subharmonic、exponential、scaledexponential 和 decide。有关这些运算符的信息，参见 MC Wrapper Messages 指南。

p1 [float]

设置第一个运算符参数的取值

p2 [float]

设置第二个运算符参数的取值

p3 [float]

设置第三个运算符参数的取值

ramptime [float]

若 ramptime 特性为零，新的运算符计算结果会立即输出，并与之前的取值不连续。非零的 ramptime 指定输出信号斜坡到新计算取值所用的毫秒数。新取值实际上是延迟了斜坡时间。
