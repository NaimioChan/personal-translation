jit.phys.picker

物理世界中的约束拾取

描述

jit.phys.picker 对象会响应绘制目标中的鼠标点击与拖动，对与鼠标相交的 jit.phys.body 对象创建约束。多点触控拾取由 touch 消息支持。

讨论

发生相交时，会把 jit.phys.body 的名称与当前鼠标状态从最左出口送出。若启用了 dynamics，会在被拾取的刚体上创建一个点到点约束，该约束一直保持到松开鼠标按键为止。启用该特性时拖动刚体，按住 option 键会让对象朝摄像机移近或移远。若按住 option 键并松开鼠标，该约束会继续保留，让你可以把鼠标重新定位到该刚体上。

特性

body [symbol] 只读

当前与鼠标相交的 jit.phys.body 的名称。

dynamics [int]

启用/禁用对相交刚体的动态约束拾取（默认值 = 1）。

enable [int]

启用物理模拟中的拾取器约束与射线检测（默认值 = 1）。

filterclass [symbol]

设置该对象碰撞过滤器类的名称（默认值 = default）。其他对象必须在各自的 filters 列表中指定该 filterclass 名称，才能与这个对象发生碰撞。允许的唯一名称最多为 10 个。

filters [10 symbols]

指定一个 filterclass 名称列表，用于启用与这些类别的碰撞（默认值 = all）。可选值包括 all 与 default。其他取值可以是任何用户指定的 filterclass 名称（最多允许 10 个）。

hover [int]

启用/禁用鼠标悬停，从而可以在不按下鼠标按键的情况下进行拾取（默认值 = 0）。

local_position [3 floats] 只读

被拾取刚体上约束的局部空间位置（默认值 = 0 0 0）。

output_positions [int]

启用/禁用选中对象时输出局部位置与世界空间位置取值（默认值 = 0）。启用后，会在对象名称与鼠标状态之后输出被点击对象上的局部位置，以及约束的世界空间位置。

pickmode [symbol]

决定约束如何施加到相交刚体上（默认值 = surface）。
可选值：

'center'（ 约束施加到刚体的质心 ）
'surface'（ 约束施加到相交的表面点 ）

position [3 floats] 只读

当前的约束拾取位置（默认值 = 0 0 0）。

strength [float]

设置约束强度（默认值 = 0.2）。它决定每个模拟步中会修正多大比例的关节误差。建议使用 0.1 到 0.8 之间的取值。

stretch [float]

设置约束拉伸（默认值 = 0.0）。设为正值后，作用在刚体上的力可以按与拉伸取值成正比的程度违反该约束。

ui_priority [int]

UI 优先级取值（默认值 = -800）。当多个 UI 对象监听同一个窗口时，ui_priority 决定各对象接收输入的顺序。取值越小越先检测。

worldname [symbol]

该约束拾取器所绑定的 jit.phys.world 上下文的名称。

消息

touch

更新位于 index 的多点触控点（若不存在则创建）。若 down 为 1，则启用该约束，位置由 screen-x 与 screen-y 设置。

参数：

  • index [long]
  • down [long]
  • screen-x [long]
  • screen-y [long]
