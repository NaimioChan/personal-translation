pak

任一元素变化时输出列表

描述

pak 对象（读作 "pock"）提供 pack 的大部分功能，但只要任意入口收到输入就会输出整个列表。

参数

list-elements [any] 可选

入口数量由参数数量决定。每个参数为 pak 所产生的列表中的一个条目设定初始类型和取值。若没有参数，该对象会以两个入口创建，两个列表元素最初被设为 (int) 0。

消息

bang

输出当前存储的列表

int

该数字作为一个条目存储在列表中，它在列表中的位置对应收到它的那个入口，然后整个列表被输出。若该入口已用 float 或 symbol 参数初始化，传入的数字会被转换成 float 或空符号。

参数：

  • input [int]

float

该数字作为一个条目存储在列表中，它在列表中的位置对应收到它的那个入口，然后整个列表被输出。若该入口已用 int 或 symbol 参数初始化，传入的数字会被转换成 int 或（空）符号。

参数：

  • input [float]

list

任何多条目消息都被当作列表处理。传入列表中的第一个条目存储在与其被收到的入口相对应的位置上。其后的每个条目都如同在后继入口中到达一样被存储（受可用入口数量限制）。所有取值存储完毕后，列表被输出。

参数：

  • input [list]

anything

与 list 作用相同。

参数：

  • input [list]

set

设定数据但不输出

参数：

  • message [list]

输出

list

列表的长度由参数数量决定。任意入口收到输入时，已存储的列表从出口送出。
