Max

speedlim

限制消息的吞吐速度

描述

把输入消息的吞吐速度限制在一个固定的时间下限内。时间可以毫秒为单位指定，也可以使用相对于速度的间隔。

讨论

speedlim 接受一个可选参数，即限速时间。该对象使用 Max 的 时间格式语法，speedlim 对象使用的间隔既可以是固定的，也可以是相对速度的。它的输出还可以用相对于速度的语法进行量化。
左入口接受任何消息，并依据参数值把它输出。右入口接受 int 以修改限速时间。

参数

delta-time [int, float, symbol] 可选

设置两次输出之间的初始最小时间。时间可以用 Max 中使用的任何一种时间格式指定。若没有参数，最小时间为 0 毫秒。

特性

defer [float] : 0.

打开此项以在低优先级队列中送出输出。

quantize [Time Value] : 0 ticks

仅在适当的时候按指定的时间边界送出输出。这是通过对送出输出所用的时间做内部调整来实现的。量化可以用下列时间格式指定：bars.beats.units、ticks 或音符时值。

threshold [Time Value] : 0 ms

时间阈值，低于它时只允许一条消息通过。时间可以用 Max 中使用的任何一种时间格式指定。

usurp [int] : 1

当 usurp 被启用、且收到多条本可输出的消息时，最近收到的消息会替换当前任何待发的消息。当 usurp 被禁用时，收到的所有消息都会被送出。

消息

bang

其功能与把 anything 消息应用于 bang 消息的传递时相同。

int

左入口：其功能与用于传递整数的 anything 消息相同。

右入口：该数字被存为相继输出之间的最小时间量，以毫秒为单位。

参数：

  • input [int]

float

其功能与用于传递浮点数的 anything 消息相同。。

参数：

  • input [float]

list

左入口：其功能与用于传递列表的 anything 消息相同。
右入口：可以用一个列表按 Max 的某一种时间格式指定时间。

参数：

  • input [list]

anything

左入口：只要距上一次输出已过去某个最小时间，消息就经出口送出。否则，消息会被保留，直到该时间量过去（或被另一条输入消息覆盖）。

参数：

  • input [list]

输出

anything

只要距上一次输出已过去指定的最小时间量，左入口收到的消息就经出口送出。否则，speedlim 会等到该时间量过去，然后送出它自上一次输出以来收到的最后一条消息。
