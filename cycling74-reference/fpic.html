Max

fpic

显示图像

参数

无。

特性

alpha [float] : 1.

设置所显示图像的透明度。取值范围是 0.（透明）到 1.0（不透明）之间的浮点值。

autofit [int] : 0

切换是否自动缩放载入的图像文件以适合 fpic 对象的显示区域。使用 SVG 文件时该特性不可用。
可选值：

0 = 'Off'（不缩放）
不缩放图像。

1 = 'Autofit'（完整缩放）
把图像缩放到对象框的尺寸，忽略宽高比（拉伸或压扁图像以填满对象的显示区域）。

2 = 'Use Aspect Ratio'（按宽高比缩放）
把图像缩放到对象框的尺寸，并考虑原始宽高比。

destrect [4 floats]

指定所载入图形图像的左上角与右下角位置。若这些值与图形图像的尺寸不符，图像会被缩放以适应当前的 fpic 窗口大小。注意 destrect 特性不会被保存；若要指定水平和/或垂直偏移，请使用 xoffset 和 yoffset 特性。

embed [int] : 0

切换是否把你正在使用的图形嵌入并作为主补丁的一部分保存。默认行为为 0（不把图像与补丁文件一起保存）。

forceaspect [int] : 0 >= 7.0.0

启用后，对 fpic 的 x 或 y 缩放比例所做的任何改动都会自动调整另一个，使 fpic 对象的宽高比与源图像保持一致。

pic [symbol] : <none>

指定供 fpic 使用的图形文件的路径名。

xoffset [float] : 0.

指定子补丁的左上角在 fpic 对象查看窗口中水平偏移的像素数。

yoffset [float] : 0.

指定子补丁的左上角在 fpic 对象查看窗口中垂直偏移的像素数。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang >= 7.0.0

fpic 载入的图像在收到 bang 时会作为矩阵从出口送出。

(drag)

当把图像文件从 Max File Browser 拖到 fpic 对象上时，该图像会被载入。

(mouse)

在未锁定的补丁中，按住 Macintosh 上的 Shift 和 Command 键或 Windows 上的 Shift 和 Control 键，并在 fpic 上拖动，即可改变图片的偏移；拖动时，图片当前的偏移显示在补丁窗口的 Assistance 区域。

noscale

禁用图像缩放

offset

offset 一词后面跟两个数字，指定图片左上角相对于 fpic 对象框左上角水平和垂直偏移的像素数。默认情况下，图片的左上角位于 fpic 的左上角（即偏移为 0,0）。通过连续发送略有不同的 offset 消息，可以在 fpic 内部移动图片，fpic 也可以开窗显示大图片的不同部分。（为了让移动图像时有平滑过渡的外观，使用 offset 消息时不会擦除旧图像。如果你的图片含有空白背景、无法遮住其下方的画面，这可能会导致不想要的外观。）

参数：

  • horizontal [int]
  • vertical [int]

pict

pict 一词后面跟 Max 搜索路径中某个图形文件的名称，会打开该文件并显示图片，替换先前显示的任何图片。fpic 对象接受 PNG 文件；若安装了 QuickTime 7.1 或更高版本，还接受 QuickTime 附录中列出的其他图片文件格式。

参数：

  • filename [list]

read

read 一词后面跟一个指定文件名的 symbol，会在 Max 的文件搜索路径中查找该名称的 QuickTime 图形文件，若存在就打开它，并在图形窗口中显示。若文件名包含空格或特殊字符，应把名称用双引号括起来，或在每个特殊字符前加一个反斜杠（\）。read 一词单独使用时，会弹出标准的 Open Document 对话框，并显示 QuickTime 支持的常见图形文件。

参数：

  • filename [list]

readany

readany 一词后面跟一个指定文件名的 symbol，其作用与 read 消息相同，只是 Open Document 对话框不会按当前支持的文件类型过滤其显示内容。

参数：

  • filename [list]

rect

单词 rect 后面跟四个数字，用于指定缩放矩形的大小，使输入图像缩放后能放进去，会从磁盘把图形文件载入 RAM 并显示出来。前两个数字以偏移值的形式指定它在图形窗口中的位置，后两个数字以像素为单位指定矩形的宽度和高度。

参数：

  • horizontal [int]
  • vertical [int]
  • width [int]
  • height [int]
