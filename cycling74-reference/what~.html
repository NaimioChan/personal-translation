MSP

what~

为音频取值列表生成脉冲

描述

what~ 对象在其输入信号越过某个取值阈值时会生成一个脉冲——即一个采样点的信号取值为 1。该对象接受一个阈值列表，并会为其中所有取值生成脉冲。把 phasor~ 连到 what~ 可以创建重复的节奏。例如，送入列表 0 0.25 0.5 and 0.75 时，what~ 会在每个 phasor~ 斜坡上输出四次脉冲。

讨论

启用 Scheduler in Audio Interrupt 后，what~ 对象是采样点精确的。更多细节见此处。

参数

values [list] 可选

若有一个或多个取值是 what~ 的参数，它们就定义了初始的取值列表。

特性

matches [atom]

设置要检测的取值

syncupdate [int]

启用 syncupdate 后，用于改变要检测取值的消息要到输入相位器重置时才会生效。重置定义为信号的方向反转。

triggermode [int] : 2

决定 what~ 如何匹配信号输入中的取值。
可选值：

0 = 'Ascending'（检测上升斜坡中的取值）
上一个采样点必须小于或等于目标值，且当前采样点必须大于目标值。

1 = 'Descending'（检测下降斜坡中的取值）
上一个采样点必须大于或等于目标值，且当前采样点必须小于目标值。

2 = 'Ascending or Descending'（检测上升或下降斜坡中的取值）
只要上升条件或下降条件之一成立，该取值就会被检测到。该模式适用于检测同时具有正频率和负频率的相位器中的斜坡。

3 = 'Equals'（检测精确取值）
若取值与当前采样点完全相等，该取值就会被检测到。不建议对相位器斜坡使用该模式，因为斜坡不太可能输出恰好等于某个特定取值的采样点。

消息

int

一个 int 设置单个要检测的取值，并替换已有的一切取值。

float

一个 float 设置单个要检测的取值，并替换已有的一切取值。

list

list 设置新的要检测取值，并替换已有的一切取值。list 消息是设置 matches 特性的另一种方式。若启用了 syncupdate，新的取值要到输入相位器重置时才会被使用。

clear

clear 消息会移除所有已添加到 what~ 对象的取值。若启用了 syncupdate，这些取值要到输入相位器重置时才会被清除。

signal

用于阈值分析的输入信号，通常是 phasor，不过任何信号都可以使用。
