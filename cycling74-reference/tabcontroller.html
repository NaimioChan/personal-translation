tabcontroller

定义和管理补丁标签页

描述

tabcontroller 对象放在顶层补丁中。当给它提供一个由标签页名称与补丁引用组成的字典时，它会为该字典中的每个条目在那个补丁中创建标签页。字典中的引用可以指向内嵌子补丁或补丁文件。使用补丁文件时，在你点击该标签页之前不会载入这些文件。此外，标签页可以以垂直滚动列表的形式显示在补丁窗口左侧。这些功能使得使用 tabcontroller 的补丁可以显示任意长的补丁列表，因而非常适合用来呈现一组相关的教程或范例。注意，标签页中的 RNBO 或 Gen 子补丁会在载入其父补丁时立即载入。

参数

无。

特性

disableinternals [int]

启用 disableinternals 后，点击由 patcher 指定的、tabcontroller 字典中的标签页不会有任何效果。这样就可以把内嵌子补丁标签页用作基于文件的补丁标签页的分类标题。disableinternals 默认禁用。

exclusivemidi [int]

启用 exclusivemidi 后，MIDI 输入和输出只在当前显示的补丁中有效。exclusivemidi 默认禁用。

folder [symbol]

命名一个文件夹，用于把补丁作为标签页添加进来，类似于 addfolder 消息的作用。

orientation [int]

设置主补丁窗口中标签页的方向。要显示大型滚动标签页列表，请使用 left（1）方向，因为补丁窗口的水平空间有限，而窗口顶部的标签页不会滚动。注意，tabcontroller 目前是让标签页显示在窗口左侧的唯一途径；这无法通过补丁特性实现。
可选值：

0 = 'top'（ 标签页在顶部 ）
标签页会像帮助文件那样显示在补丁窗口顶部。

1 = 'left'（ 标签页在左侧 ）
标签页会显示在补丁窗口左侧。

recursive [int]

使用 folder 特性时，若启用 recursive 特性，tabcontroller 会为指定文件夹的子文件夹中找到的补丁添加标签页。

showroot [int]

启用 showroot 特性后，会为包含 tabcontroller 对象的顶层（"root"）补丁显示一个标签页。使用 showroot 在用 tabcontroller 开发时很有帮助，但在把你的作品分享给他人之前，你大概会想把它关掉。注意 showroot 只能作为 tabcontroller 的特性参数来设置——不能通过消息或 Inspector 更改。因此，若要关闭 showroot，你需要重新输入 tabcontroller 对象。

消息

add

add 消息在当前标签页集合的末尾添加一个标签页。第一个参数是标签页名称；若没有其他参数，它同时也是要载入该标签页的补丁文件名。第二个可选参数是补丁文件名。在第二个参数之后，其余参数会在补丁载入时传给补丁，用于替换 #1 - #9，或供 patcherargs 对象使用。

参数：

  • tabname [symbol]
  • patchername [symbol]
  • arguments [list]

addfolder

addfolder 消息会为作为参数传入的具名文件夹中的每个补丁文件添加一个标签页。每个补丁的标签页名称就是它的文件名。

参数：

  • foldername [symbol]

clear

clear 消息会清除 tabcontroller 管理的所有当前标签页。

dictionary

当 tabcontroller 收到一个字典时，它会清除所有已有的标签页，并为字典中的每个条目创建一个新标签页。若要在载入包含 tabcontroller 的补丁时创建标签页，请把字典存储在一个 dict 对象中，并把它的 embed 设为 1，然后把 dict 连接到 tabcontroller，并把 loadbang 连接到 dict。

tabcontroller 所期望的字典格式是一个以 tabs 为键的字典数组。每个条目包含键 tab（值为标签页名称），以及 patcher（指定一个内嵌子补丁）或 filename（值为补丁文件名）。对于垂直的标签页列表，你可以用 indent 指定可选的标签页缩进层级；默认（最靠左）的缩进为 0。示例：


"tabs": [

"tab" : "one",
"patcher" : "xyz"
},

"tab" : "two",
"filename" : "myfile.maxpat",
"indent" : 1,
"arguments" : [2, 3, 4]




参数：

  • dictionaryname [symbol]

remove

remove 消息移除一个具名标签页。注意，只有基于文件的标签页可以被移除。内嵌子补丁标签页，或与含有子补丁标签页的补丁相关联的标签页，不能被移除。

参数：

  • tabname [symbol]

setactive

setactive 消息把与指定标签页名称相关联的补丁带到主补丁窗口前面，必要时载入它，并高亮该标签页的名称，必要时滚动标签页列表以显示该名称。

参数：

  • tabname [symbol]

setactivefilename

setactivefilename 消息把具有指定文件名的补丁带到主补丁窗口前面，必要时载入它，并高亮其标签页的名称，必要时滚动标签页列表以显示该标签页名称。

参数：

  • filename [symbol]
