Jitter

jit.gl.shader

管理 GL 着色器

描述

管理把着色器编译、绑定并提交给 OpenGL 的过程。一个着色器同时由顶点程序与片元（又称像素）程序组成，二者可以定义在一个 xml 着色器描述文件（JXS）中，也可以单独提交。目前支持高级语言 GLSL。

讨论

通过 OB3D 的 shader 方法可以把着色器附加到任何 OB3D 上。若着色器被附加到某个 OB3D，该 OB3D 会自动管理 jit.gl.shader 对象的编译与绑定。

着色器程序可以通过 JXS include tag 包含外部源代码。此外，从 Max 9.1 起，外部源代码可以直接通过 #include 指令内联。

			#include "Package:/MyPackage/GLSL/myinclude.glsl"

该包含器同时支持 Max path prefixes 与相对路径。相对路径将相对于正在加载的着色器文件（若存在），或相对于正在加载的 Max 补丁（若是内嵌着色器）。

该 OB3D 对象可选地接受一个参数：一个 绘制上下文的名称。它是一个 jit.world 或 jit.pworld 对象的具名实例，也可以是一个 jit.gl.node 子上下文。该取值也可以通过 OB3D 的 drawto 特性设置。若未给出参数，对象会被隐式加入当前补丁中找到的第一个有效绘制上下文或子上下文，或者沿补丁层级向上搜索找到的第一个有效绘制上下文或子上下文。

特性

autowatch [int] >= 9.0.0

启用对源文件变化的监视（默认值 = 1）。文件监视打开时，文件被修改后会自动重新编译。这让你可以为自己的文件使用外部编辑器。

embed [int] >= 9.0.0

启用后，着色器文件会随其补丁一起保存。若对象被载入的补丁没有 file 参数，则默认启用 embed。若提供了 file 参数，除非用户显式启用，否则 embed 会被禁用。

file [symbol]

要使用的着色器描述文件（JXS）（默认值 = none）

verbose [int]

启用或禁用向 Max 控制台窗口的详细输出（默认值 = 0）。

OB3D 特性

automatic [int]

自动渲染标志（默认值 = 1）该标志置位时，关联的 jit.gl.render 对象收到 bang 消息时即进行渲染

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

name [symbol]

实例名称（默认值 = UID）

消息

(drag)

把 JXS 文件从 Max File Browser 或桌面拖到一个 jit.gl.shader 对象上，就会加载该文件。

bind

手动绑定并编译着色器对象。

compile

手动编译着色器对象。

(mouse)

双击可打开着色器编辑器。若未加载文件，编辑器会加载一个起始着色器，作为新着色器的基础。该文件必须保存到磁盘，才能在编辑器关闭后继续使用。

dispose

处置并卸载当前着色器。

dump

把指定的着色器数据转储到 Max 控制台窗口。有效类型为 params、source、assembly。

参数：

  • type [symbol]

getparamdefault

把指定着色器参数的默认数据取值从最右出口送出。

参数：

  • name [symbol]

getparamdescription

获取参数描述

getparamlist

把所有着色器参数的名称从最右出口送出。

getparamtype

把指定着色器参数的数据类型名称从最右出口送出。

参数：

  • name [symbol]

getparamval

把指定着色器参数的数据取值从最右出口送出。

参数：

  • name [symbol]

link

手动链接着色器对象。

open

打开着色器编辑器。若未加载文件，编辑器会加载一个起始着色器，作为新着色器的基础。该文件必须保存到磁盘，才能在编辑器关闭后继续使用。

param

用给定的原子取值设置所指定的着色器参数，这些取值如 JXS（Jitter 着色器）文件中所定义。

program_param

一个几何着色器程序参数。

read

从磁盘加载给定的 JXS 着色器文件。

参数：

  • filename [symbol]

unbind

手动解除绑定的着色器对象。

OB3D 消息

bang

等价于 draw 消息。

draw

在具名的绘制目标中绘制该对象。若支持 matrixoutput 特性且其设为 1，几何矩阵会从对象的左出口送出。

drawraw

等价于 draw，且 inherit_all 特性设为 1。

drawimmediate

等价于 draw，但忽略任何可能的渲染器设置
