Jitter

jit.gl.shader

Manage a GL shader

描述

Manages the process of compiling, binding and submitting a shader to OpenGL. A shader consists of both a vertex program and a fragment (aka pixel) program, which can be defined in a xml shader description file (JXS), or submitted individually. Currently the high level language GLSL is supported.

讨论

Shaders can be attached to any OB3D thru the OB3D shader method. If the shader is attached to an OB3D, the OB3D will automatically manage the compiling and binding for the jit.gl.shader object.

Shader programs can include external source code via the JXS include tag. Additionally, as of Max 9.1 external source code can be inlined directly via the #include directive.

			#include "Package:/MyPackage/GLSL/myinclude.glsl"

The includer supports both Max path prefixes, and relative paths. The relative path will be relative to the loading shader file if it exists, or the loading Max patch if it is an embedded shader.

This OB3D object optionally takes one argument: the name of a drawing context. This is a named instance of a jit.world, or jit.pworld object, or a jit.gl.node sub-context. This value may also be set via the OB3D drawto attribute. If no argument is present, the object is implicitly added to the first valid drawing context or sub-context found in the current patch or by searching up the patcher hierarchy.

特性

autowatch [int] >= 9.0.0

Enable watching for changes in the source file (default = 1). When file watching is on, the file is recompiled automatically when it is modified. This allows you to use an external editor for your file.

embed [int] >= 9.0.0

When enabled, the shader file is saved with its patcher. If the object is loaded in a patch with no file argument, embed is enabled by default. If a file argument is provided, embed will be disabled unless explicitly enabled by the user.

file [symbol]

The shader description file (JXS) to use (default = none)

verbose [int]

Enables or disables verbose output to the max console window (default = 0).

OB3D 特性

automatic [int]

自动渲染标志（默认值 = 1）该标志置位时，关联的 jit.gl.render 对象收到 bang 消息时即进行渲染

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

name [symbol]

实例名称（默认值 = UID）

消息

(drag)

Dragging a JXS file from the Max File Browser or desktop to a jit.gl.shader object, will load the file.

bind

Manually binds and compiles the shader object.

compile

Manually compiles the shader object.

(mouse)

Double click to open the shader editor. If no file is loaded the editor will load a starter shader to use as the basis for a new shader. This file must be saved to disk for use after the editor is closed.

dispose

Dispose of and unload the current shader.

dump

Dumps the indicated shader data to the max console window. Valid types are params, source, assembly.

参数：

  • type [symbol]

getparamdefault

Sends the default data values for the indicated shader parameter out the right-most outlet.

参数：

  • name [symbol]

getparamdescription

Get a parameter description

getparamlist

Sends the names of all the shader parameters out the right-most outlet.

getparamtype

Sends the name of the datatype for the indicated shader parameter out the right-most outlet.

参数：

  • name [symbol]

getparamval

Sends the data values for the indicated shader parameter out the right-most outlet.

参数：

  • name [symbol]

link

Manually links the shader object.

open

Opens the shader editor. If no file is loaded the editor will load a starter shader to use as the basis for a new shader. This file must be saved to disk for use after the editor is closed.

param

Sets the given shader parameter with the given atom values as defined in a JXS (Jitter shader) file.

program_param

A geometry shader program parameter.

read

Loads the given JXS shader file from disk.

参数：

  • filename [symbol]

unbind

Manually unbinds the shader object.

OB3D 消息

bang

等价于 draw 消息。

draw

在具名的绘制目标中绘制该对象。若支持 matrixoutput 特性且其设为 1，几何矩阵会从对象的左出口送出。

drawraw

等价于 draw，且 inherit_all 特性设为 1。

drawimmediate

等价于 draw，但忽略任何可能的渲染器设置
