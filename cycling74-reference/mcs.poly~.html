MC

mcs.poly~

管理补丁的复音 / DSP

描述

用 mcs.poly~ 把一个补丁封装在对象框内，把补丁文件名和想要加载的实例数量指定为 poly~ 对象的参数，并控制已加载补丁实例中的对象处理与路由。

讨论

mcs.poly~ 对象把其入口收到的信号与事件（消息）送往补丁实例内部的 in 和 in~ 对象；对于 mcs.poly~ 对象各实例的信号或事件输出，则用 out 和 out~ 对象来处理。与 poly~ 不同，使用 mcs.poly~ 时，每个 in~ 对象的音频输入会合并为单个多通道输入，每个 out~ 对象的音频输出会合并为单个多通道输出。

参数

patcher-name [symbol] 可选

第一个参数必须指定要加载的补丁名称，该补丁必须已经存在且位于 Max 搜索路径中。为 mcs.poly~ 对象提供了补丁参数时，不会自动打开子补丁窗口供编辑。

number-of-instances [int] 可选

补丁实例的数量对应于可用「声部」的数量。该数字可以是 1 与 1023 之间的任意数字，并且可以用 voices 消息动态更改。

local and flag (0 or 1) [symbol] 可选

当 local 设为 1 时，mcs.poly~ 对象会维护自己的调度器，在音频处理过程中运行，而不使用 Max 的全局调度器，从而让多个补丁实例所产生的事件获得更精细的时间分辨率。局部调度器在处理一向量音频之前立即运行，就好像在 poly~ 对象的上下文中打开了 "Scheduler in Audio Interrupt" 一样。局部调度默认禁用 —— 对于任何已加载的补丁，调度器的局部性都是永久的，无法通过向 poly~ 对象发送消息来改变。

'up' and up-sampling-factor [symbol] 可选

使用 up 参数后跟一个为 2 的幂的数字，对当前加载的补丁进行升采样本地 DSP 处理（例如，up 2 在 44100 Hz 的采样率下指定 88200 Hz）。升采样可以用 up 消息动态更改。

'down' and down-sampling factor [symbol] 可选

使用 down 参数后跟一个为 2 的幂的数字，对当前加载的补丁进行降采样本地 DSP 处理（例如，down 2 在 44100 Hz 的采样率下指定 22050 Hz）。降采样可以用 down 消息动态更改。

'args' and list-of-argument-values [symbol] 可选

使用参数 args 并在其后跟一个参数值，可以初始化所加载补丁中的任何井号参数（例如 args #1）。若使用该参数，args 必须是最后一个使用的参数词；出现在单词 args 之后的一切都会被当作参数值。

特性

args [20 atoms]

当用消息为 mcs.poly~ 对象所加载的补丁指定参数时，必须通过设置 patchername 特性重新加载该补丁，新参数才会在初次加载之后生效。

filterparams [int] : 0 >= 9.0.0

Parameter Filter Mode
可选值：

0 = 'Off'
1 = 'Filter non-'param' Parameters'

legacynotemode [int] : 0 >= 8.0.0

设为 1 时，legacynotemode 允许 note 和 midinote 消息使用旧版（Max 8 之前）的声部分配算法，它会持续播放声部 1。设为 0 时，note 和 midinote 消息会循环使用最近最少使用的声部。

midimode [int] : 0 >= 7.2.0

当 midimode 设为 '1' 时，发送给 mcs.poly~ 的所有 MIDI 消息都会被送往所有声部。注意，这不适用于 mpeevent 消息。若要把所有 mpeevent 消息都送往所有声部，请为 voice 参数使用 '-1' 值，例如：'mpeevent 1 1 2 210 117'（一条发往所有声部的触后消息）。

mpemode [int] : 0 >= 7.2.0

当该特性设为 '1' 时，mcs.poly~ 会根据 mpeevent 消息的 voice 参数执行直接的声部分配。

parallel [int]

当该特性被设为启用并行处理时，mcs.poly~ 对象会启用多个线程来为所有补丁实例运行音频处理。若禁用，mcs.poly~ 会在音频处理线程中运行所有补丁实例。parallel 特性一旦改变，就必须重启 DSP 链。当 Max 由 Live 应用程序托管时，该特性会被禁用。

注意：目前，你无法把单个子补丁指定到另一个核心上。启用后，该特性会把声部数量分摊到可用的处理器数量上。它主要针对那些在同一个 mcs.poly~ 对象的多个声部内占用大量 CPU 的补丁，而且多线程的开销只有在信号向量大小较大时（至少 32 或更大）才划算。其他情形不会从中获益。最好使用默认的 threadcount（它等于物理核心数）。

patchername [32 symbols]

别名：patchernames

加载到 mcs.poly~ 对象中的一个或多个补丁文件的文件名。mcs.poly~ 对象可以在不同的声部上加载不同的补丁，具体在 patchername/patchernames 特性的参数中指定。若没有 voices 参数，该特性所指定的补丁总数就是声部数；若有 voices 参数，则各个补丁会循环重复，直到达到声部号为止。

replicate [int] : 1 >= 8.0.0

复制输入

resampling [int]

切换是否使用高质量重采样滤波器。这些滤波器默认启用。

steal [int]

启用声部抢占会让 mcs.poly~ 对象把 note 或 midinote 消息中的数据发送给仍被标记为 "busy" 的实例；这会产生咔嗒声，具体取决于各个实例如何处理这种打断。声部抢占默认禁用。

target [int]

会接收到达 mcs.poly~ 对象各入口的后续消息（除 mcs.poly~ 对象自身专门使用的消息之外）的那个 mcs.poly~ 实例 —— 例如，消息 target 2 会把消息路由到第二个实例。若 target 消息指定的取值大于已加载补丁当前的实例（副本）数量，消息会被送往编号最高的实例（例如，发送消息 target 2 给只包含单个实例的 mcs.poly~ 对象，会把后续消息送往第一个实例）。消息 target 0 会把输入送往所有实例，而给 target 消息使用任何负数值都会禁用对所有实例的输入。

voices [int]

声部数

vs [int]

指定 mcs.poly~ 对象所加载补丁的信号向量大小。信号向量大小会在下一次编译 DSP 链时被设置。vs 消息不会强制重新编译 DSP 链。vs 0 表示不指定固定向量尺寸。默认值为当前的信号向量大小。

zone [int] : 0 >= 7.2.0

用该特性设置 mcs.poly~ 要监听的 MPE 'zone'。默认值为 '0'（忽略区域）。

消息

bang

向加载到 poly 对象中的补丁发送一个 bang。该消息的结果由所加载的补丁决定。

int

执行用户自行设计的 mcs.poly~ 补丁本身所特有的功能。

参数：

  • input [int]

float

执行用户自行设计的 mcs.poly~ 补丁本身所特有的功能。

参数：

  • input [float]

list

若要向 mcs.poly~ 实例发送一条以用于控制 mcs.poly~ 对象本身的词之一开头的消息，请在消息开头加上 list 一词。例如，把消息 list target 2 发往 mcs.poly~ 的左入口，会把 target 2 从所有 in 1 对象的出口输出，而不是把当前目标实例切换为第二个补丁。

参数：

  • message [list]

anything

mcs.poly~ 的入口数和出口数由所加载的补丁决定。由 mcs.poly~ 对象加载的补丁，其入口既接受信号连接也接受事件连接。

信号在已加载的补丁内部通过 in~ 对象（用于信号）或 in 对象（用于事件）进行路由。mcs.poly~ 对象的入口总数由已加载补丁中编号最大的 in~ 或 in 对象决定（例如，若有一个参数为 3 的 in~ 和一个参数为 4 的 in，则 mcs.poly~ 对象会有四个入口。所有入口都接受信号连接，即使并非每个入口都有对应的 in~ 对象。

信号输入会馈送到所有实例。

参数：

  • message [list]

allnotesoff

通过向每个正在播放音符的实例发送一条消息，停用所有正在播放的音符；该消息由最近通过 note 或 midinote 消息收到的 MIDI 音高后跟零力度（note off 消息）组成。

busymap

把作为参数指定的编号所对应的声部忙碌状态，从 mcs.poly~ 对象指定的消息出口报告出去。

参数：

bypass

让传入的信号直接通过。第一个参数指定声部，第二个参数指定状态。若要旁通所有声部，请发送消息 'bypass 0 1'。

参数：

  • voice [int]
  • on/off [int]

(mouse)

双击 mcs.poly~ 会打开一个显示窗口，可以在其中查看已加载补丁的内容。

down

用 down 消息后面跟一个为 2 的幂的数字，可以对当前已加载补丁的局部 DSP 处理进行降采样（例如，down 2 在采样率为 44100 Hz 时表示 22050 Hz）。降采样不是动态的。必须先重启 DSP，改动才能生效。虽然 up 和 down 都是可以向 mcs.poly~ 对象发送的合法消息，但 down 消息的优先级高于 up。

参数：

  • sampling-factor [int]

exclude

发送 exclude 一词，后面跟一个声部号和一个 1，可以让某个 mcs.poly~ 实例在 mcs.poly~ 收到 note 或 midinote 消息时，不被纳入音符分配而收到消息。默认情况下，所有声部都被启用以参与音符分配。发送 exclude 一词，后面跟一个声部号和一个 0，可以重新让该实例在 mcs.poly~ 收到 note 或 midinote 消息时接收消息。

参数：

  • voice-number [int]
  • status [int]

midievent

midievent 一词后面跟两到四个数字，会向 mcs.poly~ 发送一个 MIDI 事件。前三个数字参数是 MIDI 消息的字节。第四个参数是可选的，是用于 MIDI 音符消息的失谐参数。midievent 消息旨在与 polymidiin 对象配合使用。

参数：

  • MIDI-message (2 to 4 numbers) [list]

midinote

midinote 消息后面跟两个或更多取值。音符取值通常是两个数字，分别指定一个 MIDI 音符号和一个力度值，但对于工作方式与标准 MIDI 模型不同的补丁，也可以使用任意数字。

若第二个音符取值不为 0，mcs.poly~ 对象会把音高与力度路由到第一个可用的实例。若力度为 0（即 MIDI note-off 消息），该音高与力度会被送往生成该音符的那个 mcs.poly~ 实例。要确定 midinote 消息会被送往已加载补丁的哪个实例，可以发送 0（非忙）或 1（忙）消息给已加载补丁中的 thispoly~ 对象。

参数：

  • voice [int]
  • note-values [list]

mpeevent

MPE 事件消息是一个列表，由符号 mpeevent 以及随后的 6 个整数组成，这 6 个整数分别指定 Zone First Channel、Zone Index、Voice Number、Channel Number、MIDI Message Number 和 Data。该消息要送给封装在 mcs.poly~ 对象中的补丁，可以用 polymidiin 对象发送。

参数：

  • message [list]

mute

关闭由 mcs.poly~ 对象加载的补丁中指定实例的信号处理，并发送一条 bang 消息给该指定实例的 thispoly~ 对象。把 0 作为第二个参数发送会打开该补丁实例。消息 mute 0 1 会静音所有实例，而 mute 0 0 会打开该补丁所有实例的信号处理。若用 mute 0 1 消息把所有实例都静音了，则在用 mute 0 0 消息解除全部实例的静音之前，无法单独解除某个实例的静音。

参数：

  • instance [int]
  • on/off-flag [int]

mutemap

从指定的 mcs.poly~ 消息出口报告声部静音

参数：

  • outlet-number [int]

note

单词 note 后跟一条消息，会把数据送往补丁的第一个实例中的第一个 in 对象，该实例尚未通过把 1 发送给补丁实例内部的 thispoly~ 对象而把自己标记为 "busy"。

参数：

  • voice-allocated-data [list]

notemessage

notemessage 消息用于向每个活动声部（即由 mcs.poly~ 对象加载的子补丁的单个实例）发送消息。该消息直接发送到 mcs.poly~ 对象，靠的是 in 对象（寻址 mcs.poly~ 对象时，子补丁中的第一个 in 对象保留给 midinote 消息）。在顺序上，notemessage 消息跟在 note 消息之后——该消息的第一个参数被当作音高，用于后续 notemessage 消息的 ID。notemessage 消息可以有任意长度，并可在子补丁中解包和路由。在 note-off 消息完成前涉及一段时间的情形中（例如使用 adsr~ 对象），notemessage 消息会一直被接收处理，直到该声部被关闭。

注意：使用 notemessage 时要正确关闭声部，唯一的办法是向 thispoly~ 对象送入信号，该对象位于 mcs.poly~ 对象所加载的子补丁中（若未向 thispoly~ 对象连接信号，MIDI note-off 消息会立即关闭声部分配）。

参数：

  • message [list]

open

单词 open 后面跟一个数字，会打开补丁的指定实例。你可以查看补丁任意实例的活动，最多可达声部数（由 voices 消息或 mcs.poly~ 对象的参数设定）。不带参数时，open 消息打开当前作为目标的那个实例（参见 target 消息）。

参数：

  • instance-index [int]

setvalue

单词 setvalue 后跟一个实例索引（从 1 开始）以及任意消息，会把该消息送给 MC 包装中的单个声部。setvalue 0 后跟一条消息，会把该消息送给所有声部。setvalue 消息可以用在任何入口中。setvalue 指定的实例索引会覆盖 target 特性的当前取值，但在消息送出之后不会改变它。

参数：

  • instance-index [int]
  • message [symbol]
  • message arguments [list]

threadcount

单词 threadcount 后面跟一个数字，设置用于划分 mcs.poly~ 各实例音频处理的线程数。默认值是计算机中可用的处理器核心数。通常，为获得最佳性能，线程数应设为计算机中的处理器核心数。这也可以通过发送消息 threadcount 0 来实现。若一个 mcs.poly~ 对象有十六个实例而 threadcount 为 4，则四个线程中的每个线程都会处理其中四个 mcs.poly~ 实例的音频。

参数：

  • number of threads [int]

up

使用 up 消息并在其后跟一个为 2 的幂的数字，即可对当前加载的补丁的本地 DSP 处理进行升采样（例如在 44100 Hz 的采样率下，up 2 指定 88200 Hz）。升采样不是动态的。必须重启 DSP，更改才会生效。虽然 up 与 down 都是可以发给 mcs.poly~ 对象的消息，但 down 消息优先于 up。

参数：

  • sampling-factor [int]

wclose

关闭参数所指定编号实例的窗口。若没有使用数字参数，wclose 会关闭编号最大的那个补丁窗口。

参数：

  • instance-index [int]

输出

anything

mcs.poly~ 对象的出口数由所加载补丁中各 out 对象的最高参数编号决定。若存在任何 out~，还会多出一个出口。例如，若有一个 out 3 对象，mcs.poly~ 对象就会有五个出口。用于各 out~ 对象的多通道信号位于 mcs.poly~ 对象的最左侧，其后是各 out 对象对应的事件出口，再后是一个声部号出口。

若补丁实例多于一个，送往各补丁实例中 out~ 对象入口的信号会被混合。out~ 的索引决定该信号位于 mcs.poly~ 对象多通道出口中的哪个输出通道。
