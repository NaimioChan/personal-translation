Max

chooser

显示可选条目的滚动列表

描述

chooser 对象与 umenu 对象相似，但它显示的是可选条目的滚动列表，而不是弹出式菜单。

参数

无。

特性

autopopulate [int] : 0

当 autopopulate 特性启用时，chooser 对象会在每次用路径设置 prefix 特性，或用数据库查询设置 collection 或 filekind 特性时更新它的条目列表。当 autopopulate 禁用时，改变该对象当前的文件夹或文件查询不会影响条目列表。不过，如果你在改变 prefix、collection 或 filekind 特性之后再启用 autopopulate，条目列表会立即更新。

bgcolor [4 floats]

以 RGBA 格式设置 chooser 对象某一行的背景颜色。另一行的背景颜色由 stripecolor 特性设置。

collection [symbol] :

当 collection 特性被设为一个集合名称时，条目列表会被填入该具名集合中包含的文件名。你可以使用 File Browser 定义文件集合。
可选值：

''
'Lessons'
'Plug-ins'
'Sample Collection'
'Vizzie Control'
'Vizzie Effect'
'Vizzie Generate'
'Vizzie Input'
'Vizzie Mix-Composite'
'Vizzie Output'
'Vizzie Transform'
'Vizzie Utility'

depth [int] : 0

如果 depth 的值为 0，只有 prefix 所指定文件夹中包含的文件会被加入条目列表。如果 depth 大于零，那么 prefix 文件夹的子文件夹中的条目也会被加入列表，并在它们前面加上文件夹名称。所包含的子文件夹中的条目最多到 depth 特性指定的层级。

enabledrag [int] : 1

当 enabledrag 特性启用时，你可以把列表中具名的文件条目拖到任何接受它的 Max 对象上（例如 playlist~）。

factorycontent [int] : 0

当 factorycontent 特性启用时，通过使用 collection 或 filekind 查询添加到 chooser 中的文件会包含随 Max 应用程序一起分发的示例文件。

filekind [symbol] :

filekind 特性让你可以构建一个 chooser 条目列表，其中包含 Max 搜索路径中当前存在的某一指定类型的所有文件。为了让文件名出现，必须启用 autopopulate 特性。
可选值：

'audiofile'
'audioplugin'
'bitmapandvectorfile'
'clipping'
'collective'
'dict'
'dictfile'
'file'
'gendsp'
'genexpr'
'genjit'
'helpfile'
'imagefile'
'java'
'javascript'
'jitterdatafile'
'json'
'lesson'
'livedevice'
'llllfile'
'lua'
'material'
'maxdatafile'
'maxforlive'
'maxpresets'
'maxsnapshot'
'midifile'
'model'
'moviefile'
'object'

'pass'

'rnbopat'

'stylesheet'

'tutorial'
'vectorimagefile'
'video'
'vignette'
'webpage'
'xmlfile'

filtertext [symbol] :

filtertext 特性定义一个文本过滤器，用于修改由 prefix、collection 或 filekind 特性填充的列表。只有包含 filtertext 中文本的文件才会被包含在 chooser 对象的列表中。当 filtertext 为空时，不进行任何过滤。

headerheight [int] : 0

headerheight 特性以像素为单位设置 chooser 对象表头的高度。默认情况下该高度为零，表头不显示。

headerlabel [symbol] :

表头标签

items [atom]

items 特性由 Inspector 使用，用于在你编辑完列表中的所有条目之后设置它们的文本。不过，用消息修改该特性时，你只能设置第一个条目，所以我们建议先使用 clear 消息，再使用一系列 append 消息来设置多个条目的列表。

keynavigate [int] : 1

keynavigate 特性启用/禁用 chooser 的字母键搜索导航。启用时（1）且 chooser 对象处于选中状态，按下键盘上的一个字母会让 chooser 选中以该字母开头的条目。禁用时，键搜索导航不工作。如果你在补丁中使用了其他按键命令（例如配合 key 对象），禁用该特性会很有用。

margin [int] : 0

margin 特性设置绘制条目文本时使用的左右文本边距。当 margin 特性为 0 时，该对象使用等于当前所用字体高度 80% 的默认边距来绘制文本。

multiselect [int] : 0

当 multiselect 启用时，chooser 对象允许用户通过 shift 点击或 command / control 点击一次选中多个条目。此外，multiselect 特性会改变 chooser 对象把选中条目从各出口送出的方式。第一个和第三个条目索引出口会送出消息 selectedindices，后跟由所选各个条目的一个或多个索引组成的列表。第二个和第四个条目内容出口送出消息 selecteditems，后跟由包含所选各个条目内容的一个或多个符号组成的列表。

parameter_enable [int]

允许此对象与 Max for Live Parameters 一起使用，并允许在 Max 环境中设置初始参数取值。

parameter_mappable [int] : 1

启用 parameter_mappable 后，该对象就可以用 Mappings 功能映射到键盘或 MIDI 输入。

prefix [symbol] :

prefix 特性指定一个文件路径，用于填充项目列表。若某文件的名称包含 filtertext 特性当前值中的文本，且其类型包含在 types 特性指定的类型之中，该文件就会被列入列表。此外，depth 特性控制是否列出 prefix 文件夹中各子文件夹内的文件。要让 prefix 所指定文件夹的内容填充项目列表，必须启用 autopopulate 特性。

prefix_mode [int] : 0

prefix_mode 特性控制用 chooser 对象列出文件夹内容（使用 prefix）时如何输出所选文件的路径位置。
可选值：

0 = 'Concatenate'
文件名与其所在的文件夹名合并，构成一个完整的路径名。

1 = 'Prepend'
所在的文件夹名作为一个独立的符号输出，后面跟着文件名。启用 multiselect 时不能使用这种 prefix 模式。

2 = 'Ignore'
只输出文件名。

preview [int] : 0

启用 preview 特性后，chooser 对象会在每个项目的左侧显示一个播放按钮。若把 chooser 的第五个出口连接到能播放列表中所示文件类型的对象（sfplay~、jit.movie 或 jit.playlist），点击某个项目旁边的播放按钮就会向所连接的对象发送命令，开始播放该项目指定的文件。

selectedclick [int] : 0

启用 selectedclick 后，点击已经选中的项目会报告该项目。否则只有在选择发生变化时才会报告项目。

selectioncolor [4 floats]

以 RGBA 格式设置 chooser 对象当前选中项目的背景颜色。只有启用 useselectioncolor 特性，才会显示选中项目的自定义背景颜色。

showdotfiles [int] : 0

切换是否显示名称以点号（句点）开头的任何文件。这类文件通常不显示。

stripecolor [4 floats]

以 RGBA 格式设置第二行（交替行）的背景颜色。另一类行的背景颜色由 bgcolor 特性设置。

style [symbol] :

设置 chooser 对象视觉显示所用的样式。

textcolor [4 floats]

以 RGBA 格式设置 chooser 对象的文字颜色。

types [atom]

types 特性与 prefix 特性配合使用。它可按一个或多个类型对 prefix 文件夹中的文件进行筛选。这些类型是四字符类型码，与 folder 对象所用的相同，例如 AIFF、WAVE、TEXT 和 JSON。

useselectioncolor [int] : 0

切换是否使用 selectcolor 特性来定义自定义的选择颜色。

通用对象框特性

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

把当前选中项目的内容从第二个出口送出，把当前选中项目的索引从左出口送出。

int

把当前选中项目设为指定的索引，然后从第二个出口送出该项目的内容，从左出口送出它的索引。

参数：

  • index [int]

float

把当前选中项目设为指定的索引，然后从第二个出口送出该项目的内容，从左出口送出它的索引。

参数：

  • index [float]

anything

若 chooser 对象中存在内容与该消息匹配的项目，该项目就会被选中。随后该项目的内容从第二个出口送出，其索引从左出口送出。若没有匹配项，当前选中项目不变，也不产生任何输出。

参数：

  • contents [list]

append

append 一词后面跟任意消息，会把该消息追加到 chooser 对象项目列表的末尾。

参数：

  • message [list]

clear

移除所有项目

count

把项目列表中当前的项目数量从右出口送出，前面带上 count 一词。

delete

delete 一词后面跟一个或多个项目编号，会把所编号的项目从项目列表中移除。

参数：

  • indices [list]

deselect

deselect 一词会从 chooser 对象中移除选中项目的视觉表示。它不会改变 chooser 对象的当前值，所以 bang 仍会输出最后选中的项目。

dictionary

dictionary 一词后面跟一个字典名，会为 chooser 设置项目。你也可以把一个 dict 对象的第一个出口连接到 chooser 的第一个入口。要使其生效，字典需要包含一个 "items" 条目。例如，下面的字典条目会用 "hank, carol, andreas, roland" 这些项目填充 chooser：

"items" : [ "hank", "carol", "andreas", "roland" ]

参数：

  • dict-name [symbol]

insert

insert 一词后面跟一个索引号和一个消息，会在索引指定的位置向列表插入一个新项目。

参数：

  • index [int]
  • message [list]

(mouse)

单击某个项目会选中该项目，使其内容从第二个出口送出、其索引从左出口送出。双击某个项目会把它的内容从第四个出口送出、把它的项目索引从第三个出口送出。

next

next 消息选中列表中的下一个项目，然后从第二个出口送出所选中项目的内容、从左出口送出它的索引。

play

play 一词后面跟一个索引号，会向连接到第五个出口的对象（例如 sfplay~ 或 jit.movie）发送命令，打开并播放指定的媒体文件。索引参数用于选择要播放的文件。

参数：

  • index [int]

prev

prev 消息选中列表中的上一个项目，然后从第二个出口送出所选中项目的内容、从左出口送出它的索引。

progress

当 preview 特性打开时，progress 一词后面跟一个 0.0 到 1.0 之间的 float，会更新当前预览进度圈的显示。

参数：

  • position [float]

set

set 一词后面跟一个数字，会把当前选中项目设为指定的索引，但不产生任何输出。

参数：

  • index [int]

setnext

选中列表中当前选中项目下方的项目，但不产生任何输出。

setprev

选中列表中当前选中项目上方的项目，但不产生任何输出。

sort

sort 一词后面跟一个正数，会把 chooser 对象的项目按字母升序排列（A-Z）。sort 后面跟一个负数，会把项目列表按字母降序排列（Z - A）。

参数：

  • direction [int]

stop

stop 一词会让任何项目当前的预览播放停止。
