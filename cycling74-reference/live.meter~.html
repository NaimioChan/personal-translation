Max for Live

live.meter~

Live 风格的可视峰值电平指示器

描述

live.meter~ 是一个简单的单声道 Live 风格信号电平表，可以接在任何电平介于 -1 与 1 之间的信号上（其他信号应先做缩放）。

讨论

live.meter~ 的可视输出显示当前信号电平、最近的峰值电平，并在信号大于或等于 1 时给出红色的 "over" 指示。你可以用 Interval 特性改变重绘间隔，电平表的方向则用 Orientation 特性设置。

参数

无。

特性

active [int] : 1

启用（1）或禁用（0）电平表显示。

bgcolor [4 floats]

以 RGBA 格式设置背景颜色。

clip_size [int] : 0

设置用于显示大于 1.0 的输入（信号削波）的区域大小。
可选值：

0 = 'Normal'
1 = 'Extended'
2 = 'Disabled'

coldcolor [4 floats]

以 RGBA 格式设置 Cold 信号颜色。

display_range [2 floats] : -70. 6.

以 dB 为单位设置电平表的显示范围。

drawpeakhold [int] : 1

启用后，短期信号峰值会在视觉上短暂 "保持"。

hotcolor [4 floats]

以 RGBA 格式设置 Warning 信号颜色。

inactivecoldcolor [4 floats]

以 RGBA 格式设置 Cold 信号（非激活）颜色。

inactivewarmcolor [4 floats]

以 RGBA 格式设置 Warm 信号（非激活）颜色。

interval [int] : 20

以毫秒为单位设置 live.meter~ 显示的最大更新时间间隔。最小更新间隔为 10 毫秒，最大为 2 秒，默认为 50 毫秒。该消息还会设置 meter~ 送出该时间间隔内收到的峰值的速率。threshold_db 或 threshold_linear 特性用于限制刷新与输出，具体取决于 mode 特性的设置。

mode [int] : 0

设置 live.meter~ 对象的显示与输出模式。
可选值：

0 = 'deciBel'
1 = 'Linear'

orientation [int] : 0

设置电平表显示的方向。可选项为 Horizontal 或 Vertical
可选值：

0 = 'Vertical'
1 = 'Horizontal'

overloadcolor [4 floats]

以 RGBA 格式设置 Overload 信号颜色。

threshold_db [float] : 1.

当 live.meter~ 对象的 mode 特性设为 0 时，本特性设置以分贝为单位的刷新阈值。若信号峰值的变化量大于该阈值，对象会重绘，并把取值从出口送出。

threshold_linear [float] : 0.01

当 live.meter~ 对象的 mode 特性设为 1 时，本特性设置以分贝为单位的刷新阈值。若信号峰值的变化量大于该阈值，对象会重绘，并把取值从出口送出。

warmcolor [4 floats]

以 RGBA 格式设置 Warm 信号颜色。

消息

int

转换为 float。

参数：

  • signal-value [int]

float

当 live.meter~ 对象的入口没有连接信号时，一个浮点数会让电平表表现得就像有一个峰值幅度与之相等的信号被送入其输入。相应的 LED 会亮起，峰值电平的取值会从出口送出（0.0 表示静音，0.0 到 1.0 会点亮除过载 LED 之外的任何 LED，超过 1.0 会点亮包括过载在内的所有 LED）。

参数：

  • signal-value [float]

db

单词 db 后面跟一个指定分贝值的浮点数，会让 live.meter~ 对象表现得就像有一个峰值电平为该 dB 值的信号被送入其输入。相应的 LED 会亮起，该取值会从出口送出。

参数：

  • db-value [float]

signal

输入信号的峰值幅度由屏幕上的电平表显示。
