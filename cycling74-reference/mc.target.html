MC

mc.target

格式化消息以控制 MC 对象

描述

mc.target 对象简化了用于指定 MC 包装对象中特定实例的 setvalue 消息的创建。

参数

prepend [symbol] 可选

一个 symbol 参数（若存在）会设置一个在 setvalue 消息输出中使用的消息。例如，若该参数为 tree，则对于声部索引 1 和一个取值为 10 的 int，产生的消息输出会是 setvalue 1 tree 10。

initial voice [int] 可选

若给出 int 参数，则设置声部索引的初始取值。默认情况下声部索引初始为 0。setvalue 0 会告诉 MC 包装，把跟在 0 后面的消息发送给所有实例。

特性

append [atomarray]

append 特性可以设为一个或多个条目，它们会被放在该对象产生的 setvalue 消息的末尾。默认不追加任何内容。

prepend [atomarray]

prepend 特性可以设为一个或多个条目，它们会被放在该对象产生的 setvalue 消息各参数的起首（换句话说，setvalue 始终排在最前）。默认不前置任何内容。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

bold

bold italic

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

左入口：bang 会在前面加上 setvalue 与当前声部索引后，重复送到左出口。

int

左入口：该数字会在前面加上 setvalue 与当前声部索引后，重复送到左出口。

右入口：设置供左入口后续收到的消息所触发的 setvalue 消息使用的声部索引（0 - 1024）。

float

左入口：该数字会在前面加上 setvalue 与当前声部索引后，重复送到左出口。

右入口：转换为 int。设置供左入口后续收到的消息所触发的 setvalue 消息使用的声部索引（0 - 1024）。

list

左入口：该列表会在前面加上 setvalue 与当前声部索引后，重复送到左出口。

anything

左入口：该消息会在前面加上 setvalue 与当前声部索引后，重复送到左出口。

voice

任意入口：单词 voice 后面跟一个数字（0 - 1024），设置供左入口后续收到的消息所触发的 setvalue 消息使用的声部索引。

参数：

  • index [int]
