Max

matrixctrl

矩阵开关控制

描述

提供一个用户界面控件，其中包含网格状排列的一组单元格。单元格状态可以是开/关，也可以是递增的步进值。该对象尤其适合用于控制 matrix~ 对象。

讨论

matrixctrl 是一个用户界面对象，由矩形网格状排列的、称为单元格的类开关控件组成。matrixctrl 对象中的所有单元格外观和行为都相同。每个单元格有两个或更多状态。默认情况下，单元格有两个状态，分别表示 "off" 和 "on"。你可以创建具有任意数量状态的单元格。点击某个单元格会使其状态加 1。单元格达到最后一个状态后，再次点击会回到它的零状态——因此，只有两个状态的单元格会随着每次鼠标点击在这两个状态之间来回切换。

matrixctrl 最初是为了控制 MSP 对象 matrix~ 而设计的，但也适用于其他用户界面用途，例如开关组、视觉指示器组以及面向鼓机的音序器。

注意：matrixctrl 对象通常使用以 Portable Network Graphics（.png）格式保存的图像。如果你在 Windows 上使用 Max，我们建议你安装 QuickTime，并选择完整安装所有可选组件，以便使用 PNG 或 PICT 文件以外的图像。

无。

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

图片文件格式

Specifications

matrixctrl 对象所用的背景图片按惯例以 Portable Network Graphics（.png）格式保存。如果你在 Windows 上使用 Max，并且想处理 PNG 或 PICT 文件以外的图像，我们建议你安装 QuickTime，并选择完整安装所有可选组件。用作文件名的符号必须是 Max 当前搜索路径中某个文件的名称，或者是该文件的绝对路径名（例如 "MyDisk:/Documents/UI Pictures/Cell.png"）。如果 matrixctrl 大于所选的图片，会添加该图片的副本把对象填满。

单元格图片文件必须是下列格式：





图片由一组图像网格组成。所有图像都具有相同的宽度和高度。每一列图像代表一种单元格状态。图片必须至少有两列，因为单元格至少要有两种状态。

第一行图像用于单元格的空闲（或 "not clicked"）外观。第一行图像是必需的；其后所有行都是可选的。第二行是表示被点击外观的图像；单元格被点击时会用这些图像来绘制该单元格。鼠标松开后，单元格的外观恢复为其空闲图像。第三行图像用于 matrixctrl 处于非激活状态时，即它收到 active 0 消息时。

图像蒙版可用于创建轮廓为非矩形的单元格。这些蒙版位于图片文件下面若干行。如果你希望为其中任何一个单元格图像使用蒙版，就必须为所有图像都提供蒙版——每一行图像都会有一行对应的蒙版。与 Max 中所有基于图片的控件一样，黑色像素会创建对应图像中将被绘制的区域，而 while 像素会创建不可见的区域。

输出

list

当单元格因鼠标点击而改变状态时，会从 matrixctrl 对象的左出口送出一个列表。该列表包含被点击单元格的列、行和取值（状态）。把列表发往对象的左入口也可以设置单个单元格。行与列的编号从零开始，位于矩阵的左上角。

入口中收到的数字会与参数比较。如果数字相同且顺序相同，它们会作为一个列表从出口送出。
