Max

polyin

接收 MIDI 复音压力

参数

port [symbol] 可选

指定接收传入 MIDI 消息的端口。若没有给出参数，polyin 会接收所有端口上所有通道的消息。

device [symbol] 可选

可以把 MIDI 输入设备的名称用作第一个参数来指定端口。名称 'all' 可用于启用从任意端口接收 MIDI 消息。名称 'none' 可用于阻止该对象从任意端口接收 MIDI 消息。

port-channel [list] 可选

一个字母与数字的组合（用空格分隔）表示接收复音键压力消息所用的端口和特定 MIDI 通道。大于 16 的通道号会被回绕，以保持在 1-16 范围内。

key-channel [list] 可选

一个数字与数字的组合（用空格分隔）表示接收复音键压力消息所用的特定键和特定 MIDI 通道。大于 16 的通道号会被回绕，以保持在 1-16 范围内。

channel [int] 可选

可以只用数字代替字母与数字的组合。通道号参数的确切含义取决于 MIDI Setup 对话框中为每个端口指定的通道偏移。

特性

matchport [int] : 0

若 port 参数与任何已有的端口或设备名都不匹配，则把对象的 MIDI 端口设为 'none'。

name [symbol]

根据设备名设置对象的 MIDI 端口。该特性会依据特性值尝试做区分大小写的部分字符串匹配。

消息

anything

与 port 作用相同，但不需要写 "port" 一词。

参数：

  • MIDI-input-port (a through z) [list]

(mouse)

双击 polyin 对象会显示一个弹出菜单，用于选择 MIDI 端口或设备。

(MIDI)

polyin 对象从 MIDI 输入设备收到的 MIDI 复音压力消息获取输入。

port

port 一词后面跟一个 a-z 的字母，或某个 MIDI 输入端口或设备的名称，用来设定该对象从哪个端口接收传入的程序变更消息。port 一词是可选的，可以省略。名称 'all' 可用于允许从任意端口接收 MIDI 消息。名称 'none' 可用于阻止该对象从任意端口接收 MIDI 消息。

参数：

  • port [symbol]

输出

int

左出口：该数字为传入复音键压力消息的压力取值。

第二个出口：该数字为传入消息的音高取值（键号）。

若参数中包含了特定通道号，则只有两个出口。若参数没有指定通道号，polyin 会有第三个出口，位于右侧，它会输出传入 note-on 消息的通道号。
