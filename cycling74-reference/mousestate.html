mousestate

报告鼠标信息

描述

当光标位于某个 Max 补丁窗口内时，提供鼠标/光标的按键状态和光标位置信息。鼠标按键每 50ms 采样一次，而鼠标位置在每个输入 bang 时采样一次。

参数

无。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

1 = 'bold'
2 = 'italic'
3 = 'bold italic'

设置对象的字体。

设置对象的字体大小（单位：磅）。
可选值：

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

送出鼠标当前位置的水平坐标和垂直坐标，以及自上次输出以来的位置变化。

mode

mode 一词后面跟一个 long 值，指定第二个和第三个出口的鼠标坐标所使用的参照类型。值为 0 表示使用屏幕相对坐标，其中 0,0 是主显示器的左上角。值为 1 表示补丁相对坐标，其中 0,0 是 mousestate 对象所在补丁内容区域的左上角。值为 2 表示最前端补丁相对坐标，其中 0,0 是最顶层补丁窗口内容区域的左上角。

参数：

  • input [int]

(mouse)

TEXT_HERE

nopoll

撤销 poll 消息，使 mousestate 恢复到报告前先等待 bang 的正常状态。

poll

使 mousestate 在鼠标移动时以及收到 bang 时，送出鼠标位置和鼠标位置的变化量。

reset

把 0,0 点重置为它的默认设置，即屏幕左上角。

zero

重置 mousestate 当作测量鼠标位置基准的 0,0 点。鼠标的当前位置被视为新的 0,0 点。

输出

int

mousestate 必须先在其入口收到至少一条 bang 或 poll 消息，才会送出任何输出。

左出口：每次按下鼠标左键时送出 1。每次松开鼠标左键时送出 0。

第二个出口：鼠标的水平位置，以鼠标位于 0 点右侧的像素数计量。

第三个出口：鼠标的垂直位置，以鼠标位于 0 点下方的像素数计量。

第四个出口：自上次报告鼠标位置以来，鼠标水平位置的变化量。

第五个出口：自上次报告鼠标位置以来，鼠标垂直位置的变化量。

第六个出口：每次按下鼠标中键时送出 1。每次松开鼠标中键时送出 0。

第七个出口：每次按下鼠标右键时送出 1。每次松开鼠标右键时送出 0。

第八个出口：自上次报告鼠标滚轮 delta 以来，鼠标滚轮水平运动的变化量。

第九个出口：自上次报告鼠标滚轮 delta 以来，鼠标滚轮垂直运动的变化量。

右出口：鼠标滚轮标志的列表，表示滚轮是否处于平滑/连续模式（0 / 1），以及当前运动是否属于惯性运动阶段（0 / 1）。并非所有鼠标都支持这些标志。
