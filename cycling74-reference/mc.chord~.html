mc.chord~

存储并调取与某个索引关联的信号取值

描述

mc.chord~ 对象有点像能生成音频信号的 Max coll 对象的一个版本。你可以存储与唯一索引关联的数字列表（可以把它们看作 和弦），然后用消息或信号调取这些列表。调取时，列表取值会按照若干分配模式之一，分配给多通道信号中的各个通道。

参数

channels [int] 可选

作为参数提供的 int 设置初始的输出通道数。

特性

allocmode [int]

决定列表取值如何分配给通道
可选值：

0 = 'Lowest' （从第一个通道开始）
当 allocmode 设为 Lowest (0) 时，列表项从第一项开始输出，分配给第一个输出通道。

1 = 'Highest' （从最后一个通道开始）
当 allocmode 设为 Highest (1) 时，列表项从第一项开始输出，分配给最后一个输出通道，第二项分配给倒数第二个通道，依此类推。

2 = 'Cyclic' （分配给最久未使用的通道）
当 allocmode 设为 Cyclic (2) 时，列表项按升序分配给最久未使用的通道。

3 = 'Random' （随机分配）
当 allocmode 设为 Random (3) 时，列表项分配给随机选中的通道。

busymapname [symbol]

别名：bzname

设置用于决定通道分配的 busy map 的名称（位于 mc.noteallocator~ 或 mc.voiceallocator~ 对象中）。当存在生效的 busy map（usebusymap 已启用）时，各项会按照当前的 allocmode 分配给通道，但只使用非 busy 的通道。取值 none 会把 busy map 重置为该补丁的默认 busy map。

chans [int]

设置 mc.chord~ 的两路多通道输出中的通道数。若音频已开启，改动会在下次重启音频时生效。

embed [int]

启用 embed 时，当前存储在 mc.chord~ 内部的列表与索引数据会保存在它的补丁中，并在重新打开该补丁时调取。

extendmode [int]

设置不存在的索引如何被匹配或忽略
可选值：

0 = 'Nearest' （匹配最近者）
当收到与现有索引都不匹配的 int 时，会输出与最接近的索引关联的列表。

1 = 'Zero' （输出零）
当收到与现有索引都不匹配的 int 时，会输出零信号。

2 = 'Ignore' （什么都不做）
当收到与现有索引都不匹配的 int 时，输出不发生任何变化。

inputmode [int]

决定信号取值的变化如何映射到输出
可选值：

0 = 'Lookup' （把信号取值当作索引）
当 inputmode 设为 Lookup (0) 时，信号取值通过截断转换为 int。当该 int 取值变化时，就用它去匹配一个已存储的列表。

1 = 'Increment Index' （信号变化时输出下一个）
当 inputmode 设为 Increment Index (1) 时，输入信号中任何符合 triggermode 当前值的变化，都会使下一个已存储的列表以循环方式输出。

offmode [int]

决定取值为非激活状态的输出通道如何处置
可选值：

0 = 'Zero' （把非激活的输出置零）
当 offmode 设为 Zero (0) 时，非激活的输出通道被置零。

1 = 'Hold'
当 offmode 设为 Hold (1) 时，非激活的输出通道保持先前的取值。你可以通过 mc.chord~ 第二个出口输出的多通道信号中对应通道的信号取值，判断哪些输出通道处于激活状态。

triggermode [int]

决定递增索引 inputmode 所依据的信号变化
可选值：

0 = 'Zero to Non-Zero' （在零到非零的跳变时触发变化）
当 triggermode 设为 Zero to Non-Zero (0) 时，用于递增输出索引（在 inputmode 设为 Increment Index 时）的信号变化，定义为上一个采样点为零而当前采样点非零。

1 = 'Change' （任何信号变化）
当 triggermode 设为 Change (1) 时，用于递增输出索引（在 inputmode 设为 Increment Index 时）的信号变化，定义为输入信号中上一个采样点与当前采样点取值之间的任何差异。

usebusymap [int]

别名：bz

启用 usebusymap 时，mc.chord~ 只会把输出取值分配给当前 busy map 中非 busy 的通道。

消息

bang

bang 把下一个已存储的列表作为多通道信号从左出口输出；重复发送 bang 消息会循环遍历所有已存储的列表。

int

一个 int 会把与该数字关联的列表作为多通道信号从左出口输出。若该数字处没有存储列表，则输出零信号。

float

转换为 int

list

list 从第二个取值开始，把这些项存储在第一个取值指定的索引处。例如：5 30 40 50 会把列表 30 40 50 存储在索引 5 处。

clear

clear 消息清除该对象中存储的所有列表。要用列表关联的索引删除单个列表，请使用 delete。

delete

delete 一词后面跟一个索引，会删除与该索引关联的取值列表。

dictionary

当 mc.chord~ 收到格式正确的 dictionary 时，它会用该字典中的列表替换已存储的所有列表。数据必须采用与键 data 关联的字典数组的形式。每个字典都有键 index，其中是与该列表关联的索引，后面跟着与键 values 关联的一组取值。

参数：

  • name [symbol]

signal

当 inputmode 设为 Lookup (0) 时，信号取值会被截断为整数。当这个整数值变化时，mc.chord~ 会检查它是否匹配某个已存储列表的索引；若匹配，就把关联的列表作为多通道信号输出。
当 inputmode 设为 Increment Index (1) 时，输入信号取值中任何变化都会使下一个已存储的列表以循环方式输出。

store

store 一词后面跟一个列表参数，会把该列表中的项从第二个取值开始，存储在第一个取值指定的索引处。例如：store 5 30 40 50 会把列表 30 40 50 存储在索引 5 处。

参数：

  • values [list]
