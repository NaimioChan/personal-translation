Jitter

jit.displays

设置并查询显示器特性

描述

检测连接到你的计算机上的其他显示硬件，并让你可以使用标准的 Jitter get* 与 set* 消息来枚举任意及所有显示器的数量和坐标。该对象在实例化时会记住系统显示设置的原始状态，这些状态可以方便地调取回来，你也可以用它来启用显示器镜像。
通常，jit.displays 对象会被保存为演出补丁设置的一部分，以便自动确定所连接硬件的准确位置，并按需移动输出窗口。

参数

无。

特性

resetmode [int]

仅限 Macintosh
显示模式标志（默认值 = 1）
启用或禁用对象被释放时的重置。该 jit.displays 对象在实例化时会记住系统显示设置的原始状态（显示设置也可以用 snapshot 消息保存。resetmode 1 会在补丁关闭或对象以其他方式被释放时，让原始显示设置恢复。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

等价于 count 消息。以 count number-of-displays 的形式，把所连接显示器的数量从该对象的出口送出。

coords

以 coords display-index left top bottom right 的形式，把指定索引所对应显示器的屏幕坐标作为列表从该对象的右出口送出。显示器从 0 开始计数（0 是主显示器）。

参数：

  • display-index [int]

count

以 count number-of-displays 的形式，把所连接显示器的数量从该对象的出口送出。

currentstate

以 currentstate display-index width height color-bit-depth refresh-rate 的形式，把显示器的当前状态作为列表从该对象的出口送出。注意，LCD 显示器报告的刷新率为 0。

参数：

  • display-index [int]

getmode

把 display-index 所指定显示器的可用显示模式作为一连串列表从右出口送出，每行一个显示器。每个显示器由一个列表描述，形式为 mode display-index mode-index width height color-bit-depth refresh-rate。注意：LCD 显示器的刷新率为 0。

参数：

  • display-index [int]

manual

仅限 Macintosh
把显示器设置为与参数所指定的理想配置最接近的配置。

参数：

  • display-index [int]
  • width [int]
  • height [int]
  • bit-depth [int]

mirror

仅限 Macintosh
启用视频镜像，把 src-display-index 所指定编号的显示器镜像到 dst-display-index 所指定编号的显示器。

参数：

  • src-display-index [int]
  • dst-display-index [int]

move

改变 src-display-index 所指定编号显示器的逻辑屏幕位置。另外两个参数指定新的屏幕位置。若所选位置与另一个显示器的位置重叠，会自动分配一个不重叠的新位置。move 之后显示器的最终位置可以用 coords 消息来核实。

参数：

  • display-index [int]
  • newxtop [int]
  • newytop [int]

reset

让所有显示器回到它们的快照状态（参见 snapshot 方法）。注意，reset 对视频镜像设置没有任何影响，这些设置必须手动维持。

setmode

改变显示模式。两个参数分别指定显示器索引和模式索引（由 getmode 消息得到）。

参数：

  • display-index [int]
  • mode-index [int]

snapshot

保存当前显示模式（在所有活动显示器上），以供 reset 和 resetmode 消息使用。对象实例化时会自动生成一份快照。

unmirror

仅限 Macintosh
在指定的显示器上禁用视频镜像。

参数：

  • display-index [int]
