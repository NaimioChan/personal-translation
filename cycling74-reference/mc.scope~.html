MC

mc.scope~

可视化音频信号

描述

用 scope~ 对象以示波器风格的显示来可视化音频信号。

参数

无。

特性

自动模式

以 RGBA 格式设置背景颜色。

设置要显示的每像素采样点数

inactivealpha [float] : 0.3

当 scope~ 显示多个通道时，inactivealpha 设置用于绘制除当前高亮通道之外的其他通道的不透明度。

mctrigchan [int] : 0

当 scope~ 显示多个通道且启用了 trigger 时，mctrigchan 设置用于触发输入的通道。当 mctrigchan 为 0 时，所有通道都用于触发。当 mctrigchan 为非零取值时，它设置将用于触发的通道。若你希望把 Y 输入用作触发通道，请把 X 输入通道总数加到通道号上。例如，若有 4 个 X 通道和 4 个 Y 通道，通道 5 代表第一个可用作触发的 Y 通道。

range [2 floats] : -1. 1.

垂直显示的最小/最大幅度

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

trigger [int] : 0

触发模式决定一条新的波形迹线从何时开始（在延迟之后）。
trigger 1 设置向上触发，此时信号必须从低于 triglevel 变为等于或高于它。
trigger 2 设置向下触发，此时信号必须从高于 triglevel 电平变为等于或低于它。
默认触发模式为 0，它在非零延迟时段之后不会等待，就再次采集采样点。
可选值：

0 = 'None'
1 = 'Up'
2 = 'Down'

triglevel [float] : 0.

用于触发触发模式的阈值。当触发模式为 1 或 2 时，波形必须增或减越过该取值才能触发一条新的迹线。若你显示的是周期性波形，触发电平的微小变化会使波形向左或向右移动。

消息

int

左入口：显示缓冲区中每个取值所收集的采样点数。数字越小，图像越展开，但在屏幕上滚动得越快。最小值为 2，最大值为 8092，默认初始值为 256。在 X 或 Y 模式下，会使用该时段内见到的最最大或最小值。在 X-Y 模式下，会使用该时段内一个具代表性的采样点。

右入口：显示缓冲区的大小。它控制 scope~ 重新显示新信息的速率，以及这些信息的缩放比例。缓冲区更大时，信号图像在屏幕上停留的时间更长，视觉上会被压缩。缓冲区更小时，信号图像在刷新之前停留的时间更短，视觉上会被展开。

看起来，显示缓冲区每个元素对应的采样点数与显示缓冲区大小这两个控件做的是同一件事，但它们的实际效果有细微差别。你可能需要同时试验这两个控件，才能为你的应用找到最佳的显示参数。

参数：

  • object-settings [int]

(mouse)

单击可冻结显示，按住点击期间一直保持冻结

signal

左入口：要在示波器 X 轴上显示的信号
右入口：要在示波器 Y 轴上显示的信号

若左入口与右入口都连接了信号对象，scope~ 会以 X-Y 模式运行，所绘各点的水平位置对应左（X）入口进来的信号取值，垂直位置对应右（Y）入口进来的信号取值。若两路信号完全相同且同相，会看到一条从左向右上升的直线。若两路信号完全相同且相位相差 180 度，会看到一条从左向右下降的直线。其他组合可能产生圆、椭圆以及 Lissajous 图形。

输出

visual

输入信号的波形会显示在示波器的显示区域内。
