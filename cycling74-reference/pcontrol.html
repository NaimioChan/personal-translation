Max

pcontrol

打开与关闭子窗口

描述

用作 patcher/subpatcher 窗口与功能的遥控器。

参数

无。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

close

关闭连接到 pcontrol 对象出口的任何子补丁或 patcher 对象的补丁窗口。

参数：

  • patcher [list]

help

help 一词后面跟一个符号，会在 Max 的 max-help 文件夹中打开一个帮助文件，其名称为该符号后接 .help。

参数：

  • filename [symbol]

load

load 一词后面跟一个补丁文件名，若能在 Max 的搜索路径中找到该文件，就会打开它。文件名后面还可以可选地跟上至多九个数字和/或符号，它们会替换被打开补丁中相应的可变 # 参数（#1 到 #9）。

参数：

  • filename [list]

loadunique

loadunique 一词后面跟一个补丁文件名，若能在 Max 的搜索路径中找到该文件，就打开它的单个实例。若该文件已经加载，先前加载的副本会被激活（即该文件只能打开一个副本）。与 load 消息一样，文件名后面还可以可选地跟上至多九个数字和/或符号，它们会替换被打开补丁中相应的可变 # 参数（#1 到 #9）。

参数：

  • patcher [list]

open

打开连接到 pcontrol 对象出口的任何子补丁或 patcher 对象的补丁窗口。

参数：

  • patcher [list]

shroud

shroud 一词后面跟一个补丁文件名，会打开该文件但不显示其窗口。（请谨慎使用该消息，因为让补丁打开却不可见可能会带来一些令人不安的结果。）

参数：

  • filename [list]

shroudunique

shroudunique 一词后面跟一个补丁文件名，会打开该文件但不显示其窗口。与 loadunique 一样，若该文件已经加载，则不会再加载另一个副本。（请谨慎使用该消息，因为让补丁打开却不可见可能会带来一些令人不安的结果。）

参数：

  • filename [list]

输出

Patcher-Control

当 pcontrol 的入口收到相应的消息时，连接到 pcontrol 对象出口的任何子补丁或 patcher 对象都可以打开或关闭其补丁窗口，或启用/禁用 MIDI 与音频。enable 一词后面跟 1 或 0，会为连接到 pcontrol 出口的补丁打开或关闭 MIDI 与音频。后面跟 1 1 或 0 1 时，enable 消息还会为该已连接补丁内部的任何子补丁打开或关闭 MIDI 与音频。
