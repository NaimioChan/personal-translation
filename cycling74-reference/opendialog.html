Max

opendialog

打开对话框以选择文件或文件夹

描述

使用 opendialog 对象从标准对话框窗口中选定某一类型的文件或文件夹。要选择文件夹，请使用 "fold" 类型。 opendialog 会报告所选文件或文件夹的完整路径名，该路径名可以在 read 或 load 一词之后传给任何 Max 对象。

参数

folder [symbol] 可选

把 opendialog 设为只选择文件夹

soundfile [symbol] 可选

用该参数列出音频文件（AIFF、NeXT/Sun 和 WAV，以及一些通用的数据文件类型）。Jitter 附录 A 列出了所有可以打开的文件。

file-types [symbol] 可选

一个或多个符号设置文件类型或文件扩展名（以 '.' 开头）的列表，它们决定 opendialog 对象列出哪些文件。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

打开标准的 Open Document 对话框窗口，用于选择文件或文件夹。

anything

一个或多个符号被解释为一个或多个类型代码，用于决定 opendialog 对象列出哪些文件。文件的类型代码示例：TEXT 表示文本文件，maxb 表示 Max 二进制格式补丁文件，.maxpat 表示现代 Max 补丁文件，AIFF 表示 AIFF 格式音频文件。不带参数的 types 会让该对象接受所有文件类型，这是默认设置。

参数：

  • filetype [list]

path

若指定路径有效，则打开指向该路径的标准对话框窗口，并缓存该路径，供其后通过 bang 消息打开时使用。省略 filepath 参数会取消此前设置的任何路径。

参数：

  • filepath [symbol]

set

set 一词后面跟一个或多个四字母文件类型代码或文件扩展名（以 '.' 开头），会在不打开对话框窗口的情况下把 opendialog 对象设为查找指定的文件类型或扩展名。文件的类型代码示例：TEXT 表示文本文件，maxb 表示 Max 二进制格式补丁文件，.maxpat 表示现代 Max 补丁文件，AIFF 表示 AIFF 格式音频文件。不带参数的 set 会让该对象接受所有文件类型，这是默认设置。

参数：

  • filetype [list]

setpath

指定用 bang 消息打开标准对话框窗口时要使用的目录路径（前提是该路径有效）。省略 filepath 参数会取消此前设置的任何路径。

参数：

  • filepath [symbol]

sound

把 opendialog 设为列出音频文件（AIFF、NeXT/Sun 和 WAV，以及一些通用的数据文件类型），并打开一个标准对话框窗口。Jitter 附录 A 列出了所有可以打开的文件。

types

types 一词后面跟一个或多个四字母文件类型代码，会把 opendialog 对象设为查找指定的文件类型或扩展名，并打开一个标准对话框窗口。文件的类型代码示例：TEXT 表示文本文件，maxb 表示 Max 二进制格式补丁文件，.maxpat 表示现代 Max 补丁文件，AIFF 表示 AIFF 格式音频文件。不带参数的 types 会让该对象接受所有文件类型，这是默认设置。

参数：

  • filetype [list]

输出

bang

若用户取消了对话框，会从右出口送出一条 bang 消息。

symbol

左出口：用户所选文件的绝对路径名，以符号形式送出。输出的路径名包含斜杠分隔符。

绝对路径名的形式如下：

"C:/Max Folder/extras/mystuff/mypatch.pat"

可以用 conformpath 对象把一种 pathtype 和/或 pathstyle 的路径转换成另一种。
