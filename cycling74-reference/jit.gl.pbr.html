jit.gl.pbr

为 3D 对象生成基于物理的渲染材质

描述

为基于物理的渲染（ PBR ）生成着色器，它们会自动适应纹理输入以及活动光源的数量。基于图像的光照（ IBL ）效果经由 environment_texture 输入来实现。

讨论

该 OB3D 对象可选地接受一个参数：绘制上下文的名称。它可以是 jit.world 或 jit.pworld 对象的具名实例，也可以是 jit.gl.node 子上下文。该值也可以通过 OB3D 的 drawto 特性设置。若未给出参数，对象会被隐式加入当前补丁中找到的第一个有效绘制上下文或子上下文，或者沿补丁层级向上搜索找到的第一个有效绘制上下文或子上下文。

特性

drawto [symbol]

渲染上下文或子上下文名称

gamma_correction [int]

启用伽马校正（默认值 = 1）。启用后会把渲染输出从线性色彩空间转换为非线性的 sRGB 色彩空间。除非要在管线的后续阶段（例如经由 jit.gl.pass）施加伽马校正，否则用户应保持启用。

height_scale [float]

启用 parallax 时的高度缩放系数（默认值 = 1）

metalness [float]

决定材质计算中的金属度取值（默认值 = 0.）。全金属材质只保留反射光或镜面光，不显示漫反射（albedo）颜色。如果送入了 metallic_texture 贴图，则 metalness 应设为 1 才能得到预期的输出。

name [symbol]

实例名称（默认值 = UID）

override [int]

覆盖 jit.gl 对象的颜色材质特性

parallax [int]

启用视差高度图（默认值 = 0）。需要向 heightmap_texture 输入送入一张高度图图像。启用后，法线贴图与环境光遮蔽贴图都会被忽略，tex_gen 模式也会被禁用。

parallax_shadowing [2 floats]

视差高度图的阴影取值（默认值 = 0.3 0.1）。第一个取值设置自身阴影的量（在启用 self_shadow 时），第二个取值设置环境光遮蔽阴影的量。

reflection [int]

启用来自环境贴图的反射（默认值 = 1）。启用后，会从环境贴图输入生成一张镜面反射贴图，着色器在渲染时会使用镜面反射计算。

roughness [float]

决定双向反射分布函数（ BRDF ）中微表面的粗糙度（默认值 = 0.3）。完全光滑的表面的粗糙度为 0。如果送入了 roughness_texture 贴图，则 roughness 应设为 1 才能得到预期的输出。

self_shadow [int]

启用 parallax 时开启自身阴影（默认值 = 0）。

shadow_eps [float] >= 7.0.0

阴影 epsilon（eps）会修改阴影的形状，并修正自阴影误差（默认值 = 0.2）。当绑定对象是阴影接收者时使用该取值。

shadow_hard [float] >= 7.0.0

调整阴影硬度（默认值 = 0.7）。当绑定对象是阴影接收者时使用该取值。

shadow_radius [float] >= 7.0.0

调整阴影模糊半径（默认值 = 0.3）。当绑定对象是阴影接收者时使用该取值。

shadow_soft [float] >= 7.0.0

调整阴影柔和度（默认值 = 0.3）。会覆盖 shadow_radius 与 shadow_hard 特性。当绑定对象是阴影接收者时使用该取值。

tex_gen [symbol]

纹理坐标生成模式（默认值 = "none"）。启用后，纹理坐标由两个平面（biplanar）或三个平面（triplanar）在世界空间中的投影生成。
可选值：

'none' （ 不生成 ）
'biplanar' （ 由两个投影平面生成 ）
'triplanar' （ 由三个投影平面生成 ）

tex_repeat [2 floats]

纹理坐标的水平与垂直乘数（默认值 = 1 1）。大于 1 的取值在纹理映射时会造成重复。该特性对 tex_gen 模式的 none 与 triplanar 都有效。

triplanar_blend [float]

当 tex_gen 模式为 triplanar 时，三平面混合量会调节各平面投影之间的过渡（默认值 = 0.7）。

OB3D 特性

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

mat_ambient [4 floats]

环境光材质属性，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

mat_diffuse [4 floats]

漫反射光材质属性，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

mat_emission [4 floats]

材质自发光属性，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

mat_specular [4 floats]

镜面反射光材质属性，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

shininess [float]

材质的镜面光泽度值（默认值 = 16.0）该值应为 0.-255. 范围内的浮点数。

消息

albedo_texture

设置用于 albedo 贴图的纹理。albedo 纹理与标准的漫反射纹理一样，设置渲染的基础颜色（如果带纹理的对象是金属材质，则设置基础反射率）。与标准漫反射纹理不同，PBR 渲染中的 albedo 纹理通常不含方向光照或环境光遮蔽。

ambient_texture

设置用于环境光遮蔽贴图的纹理。环境光遮蔽纹理用于为表面阴影部分添加额外细节，是可选的。

clear

向 jit.gl.pbr 发送 clear 消息会清除对应输入处的图像贴图。

emission_texture

设置用于自发光贴图的纹理。自发光贴图决定对象表面发出的光的颜色。在最终渲染图像中，自发光光照（emission_texture * mat_emission）的颜色会被加到计算出的光照颜色上。

environment_texture

设置用于环境贴图的纹理。环境贴图用于借助基于图像的光照（ IBL ）效果计算反射。这些通常是 .env 文件，同一张纹理会被读入一个 jit.gl.cubemap，再由 jit.gl.skybox 渲染，不过任何纹理都可以使用。

heightmap_texture

设置用于高度图的纹理。高度图存储对象的高度数据。每个像素存储一个高度取值，代表与对象表面正面垂直的高度距离。

metallic_texture

设置用于金属度贴图的纹理。金属度纹理决定带纹理对象的反射率，并支持灰度贴图，其中 0 表示无金属度（不向 albedo 添加反射光颜色）、1 表示全金属度（只显示反射光）。metallic_texture 会乘以 metalness 特性来计算最终的反射率。

normals_texture

设置用于法线贴图的纹理。法线贴图决定被映射对象表面的反射角度，供计算光照时使用。

param

设置 pbr 材质参数取值

参数：

  • name [symbol]
  • values [list]

roughness_texture

设置用于粗糙度贴图的纹理。粗糙度影响表面反射的质量。粗糙度低会得到清晰锐利的反射，而粗糙度越高会使反射发生漫反射，得到更宽更模糊的反射。整体粗糙度由粗糙度 roughness 特性乘以粗糙度纹理来决定。

sendinput

向某个输入纹理发送消息。若第一个参数是 int，则它指定要发送消息的纹理索引，否则所有输入纹理都会收到该消息。

参数：

  • index [int]
  • message [symbol]
  • values [list]
