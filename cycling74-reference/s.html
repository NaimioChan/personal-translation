Max

s

无需连线即可发送消息

描述

send 会把给定的消息发送给以同一参数命名的 receive 对象，让你可以在补丁窗口之间或同一窗口内发送任意种类的消息，而无需使用连线。send 对象只需在对象框中输入简写字母 "s" 即可实例化。

讨论

两个或多个 receive 对象接收消息的顺序是不确定的。

send 对象的Object Action Menu 底部有两个特殊条目：Show others 和 Create receive。
Show others 会弹出一个上下文菜单，显示其他所有同名 send 和 receive 对象的实例。这等同于使用 (mouse) 方法。
Create receive 让你可以快速创建一个同名的 receive 对象。

注意：支持使用 send 和 receive 的 Max for Live 设备之间通信，但在设备之间发送数据时可能会有一些延迟。

参数

name [symbol] 可选

为 send 对象命名。所有同名的 send 对象都会向任何同名 receive 对象发送数据。

如果你希望 Max for Live 设备中带名称的 send / receive 对象只对该设备唯一，请用三个短横线（---）作为 send / receive 目标名称的开头（例如 s ---filtercutoff）。

补丁初始化时，这三个短横线会被替换为一个对 Live 唯一的编号（例如 s 024filtercutoff）；

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

(mouse)

双击 send 对象会打开所有包含同名 receive 对象的窗口，还会列出 poly~ 对象中承载的、共享具名 receive 对象的补丁的实例编号。

输出

anything

没有出口。send 入口收到的消息会从任何同名 receive 的出口送出，即使该 receive 位于另一个已加载的补丁中。
