MSP

fftout~

供 pfft~ 加载的补丁使用的输出

描述

fftout~ 对象向 pfft~ 对象提供一个信号输出。

讨论

fftout~ 对象执行逆快速傅里叶变换，并施加一个加窗函数（一个包络），使 pfft~ 对象能够管理输出信号窗的重叠相加。

参数

outlet-assignment [int] 可选

决定 pfft~ 中哪一个出口接收 fftout~ 对象的输出。出口的指定从 1 开始，1 对应 pfft~ 最左边的出口。多个 fftout~ 对象通常会有不同的出口编号。

phase-offset [float] 可选

送给 fftout~ 的第二个 float 参数若介于 0. 与 1. 之间，则指定施加于 fftout~ 所执行的逆 FFT 的窗上的相位偏移。由于 fft~ 的输出相位偏移了 180 度，所以在 pfft~ 子补丁内直接使用 fft~ 对象时，相位偏移取 0.5（相当于 180 度）可能会有帮助。

window-envelope-function [symbol] 可选

告诉 fftout~ 在对输入信号做重叠 fft 时使用哪一个窗包络函数。可选值有 square（即无窗包络）、hanning（默认）和 hamming。若使用 nofft 参数，则 fftout~ 会把它的输入信号直接回送到输出，而不执行快速傅里叶变换。这样你就可以从 pfft~ 向父补丁输出原始控制信号。注意，使用 nofft 选项时，生成输出信号的过程仍然要执行重叠相加。

特性

nofft [int]

设置 nofft 后，fftout~ 允许音频不执行逆 fft，就从子补丁经 pfft~ 的出口送出。pfft~ 在默认的半频谱帧模式下，以及 pfft~ 在 fullspectrum 模式下，存在一些特异行为，这是出于遗留原因而如此。

当 pfft~ 处于默认的半频谱模式时，fftout~ 会忽略加窗函数，只写入送往外层 MSP 补丁的输出帧的前半部分。

若重叠为 2，这个半帧方框窗恰好成立，使帧与帧之间没有重叠。若重叠因子大于 2，则有几种办法来处理重叠，使重叠的帧不会累加成比期望输出大 N 倍的取值。

第一种办法是启用 @overlapscale 1。这会把输出除以重叠帧的数量，使所有重叠帧之和取平均。

第二种办法是用 @windowsqueeze N 压缩窗，使其适配该数量的 fft 跳（fftsize/overlap）。对默认半频谱而言，由于专用的半帧方框窗，通常应设为 1 个跳。对带默认 hanning 窗的全频谱，通常应设为 2。这有助于避免过多重叠帧累加在一起后被平均。

overlapscale [int]

若启用 nofft，输出会除以重叠帧的数量，使所有重叠帧之和取平均。

userwindow [symbol] :

当 window 特性设为 user 时，userwindow 特性设置用哪个缓冲区作为窗函数。

window [symbol] : hanning

把窗函数设为内置窗函数之一，或设为用户指定的缓冲区。
可选值：

'square'
'triangle'
'hanning'
'hamming'
'blackman'
'user'

windowsqueeze [int]

若启用 nofft，可以用 windowsqueeze 压缩窗，使其适配该数量的 fft 跳（fftsize/overlap）。

对默认半频谱，由于专用的半帧方框窗，windowsqueeze 通常应设为 1 个跳。对带默认 hanning 窗的全频谱，windowsqueeze 通常应设为 2。这有助于避免过多重叠帧累加在一起后被平均。

消息

copyinput

把最近一次完成的 FFT 逆变换帧复制进单声道 buffer~，复制发生在输出相位旋转与加窗之前。目标缓冲区会被调整为 FFT 大小。可选的 scale 后跟一个有限非零数值时，会把复制的采样点除以该数值。在 fullspectrum 模式下，每个复数时域对按实部加虚部合并，与 fftout~ 产生的信号一致。双精度帧会被转换成 buffer~ 所用的 float 采样格式。该消息在 nofft 或遗留 FFT 后端下不受支持。在 DSP 初始化之前，或在 DSP 尚未产生帧之前，该消息不起作用。

参数：

  • buffer-name [symbol]
  • options [atom]

copyoutput

把最近一次完成的 FFT 逆变换帧复制进单声道 buffer~。默认会施加输出相位旋转；加上 nophase 可以省略它。加上 window 会施加当前的输出窗，也可以用 scale 后跟一个有限非零数值来除未加窗的采样点。两者同时给出时，window 优先于 scale。fullspectrum、精度转换、大小调整与可用性方面的行为与 copyinput 所述一致。

参数：

  • buffer-name [symbol]
  • options [atom]

signal

左入口：将要逆变换回时域的信号的实部。

右入口：将要逆变换回时域的信号的虚部。
注意，fftout~ 的实部与虚部入口只期望频谱的前半部分，也就是 fftin~ 所输出的部分。这个半频谱在 pfft~ 的术语里称为频谱帧。

updatewindow

根据当前特性或用户窗缓冲区重新构建窗，并在下一个 FFT 帧边界处发布完整的窗。音频线程不会被阻塞。在 DSP 初始化之前，或者当另一个窗更新尚未完成时，该消息不起作用。

输出

signal

fftout~ 对象把频域信号变换回时域，此时它们会被重叠相加，并由载入该子补丁的 pfft~ 对象中相应的出口输出。fftout~ 对象本身没有出口。
