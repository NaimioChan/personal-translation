Max

comment

说明性注释或标签

描述

comment 会显示键入其中的文本，用作标签或说明文字。

参数

无。

特性

bgcolor [4 floats]

以 RGBA 格式设置注释框的背景颜色。bgcolor 特性映射到 clearcolor 样式颜色。

bubble [int] : 0

启用气泡注释

bubble_bgcolor [4 floats]

气泡背景颜色

bubble_outlinecolor [4 floats]

气泡轮廓颜色

bubblepoint [float] : 0.5

气泡箭头位置（0-1）

bubbleside [int] : 1

设置气泡注释上箭头的起始边。
可选值：

0 = 'Top'
1 = 'Left'
2 = 'Bottom'
3 = 'Right'

bubbletextmargin [int] : 5

气泡文字边距

bubbleusescolors [int] : 0 >= 8.0.0

开启用注释的 textcolor 和 bgcolor 绘制气泡轮廓与背景。

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

suppressinlet [int] : 0 >= 7.1.0

禁止显示入口。

underline [int] : 0

切换是否给注释文字加下划线。该值只能通过 comment 对象 Inspector 中的 Underline 设置来设定。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

append

append 一词后面跟任意消息，会把 comment 对象设为在它已有文本之后显示该消息。

参数：

  • message [list]

prepend

prepend 一词后面跟任意消息，会把 comment 对象设为在它已有文本之前显示该消息。

参数：

  • message [list]

set

set 一词后面跟任意消息，会把 comment 对象设为显示该消息。

参数：

  • message [list]

setwithtruncation

set 一词后面跟一个 symbol 和一个宽度（单位：像素），会把该 symbol 截断到给定宽度。可选的第三个 symbol 会追加到截断后的文本上。

参数：

  • message [symbol]
  • width [int]
  • suffix [symbol]

string

TEXT_HERE

菜单项

Color

选中该对象后，从 Object 菜单选择 Color... 菜单项会打开一个颜色拾取器，可用它调整 comment 对象的外观。

输出

(visual)

comment 没有出口，不发送任何输出，也不影响补丁的功能。
