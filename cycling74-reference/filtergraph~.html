MSP

filtergraph~

滤波器编辑器

描述

用 filtergraph~ 对象通过图形界面为 biquad~ 或 cascade~ 对象生成滤波器系数。

讨论

filtergraph~ 对象显示区的横轴表示频率，纵轴表示幅度。所显示的曲线反映当前滤波器模型的频率响应。频率响应就是滤波器对音频信号中所含频率的放大或衰减量。实际的滤波由 biquad~（或 cascade~）对象根据 filtergraph~ 提供的系数完成。

截止频率（或中心频率）是给定滤波器活动的焦点频率。它的具体含义随滤波器类型而不同，但一般可以认定为图形幅度曲线上的一个过渡点（或一个峰/谷的中心）。在显示区中它用一个彩色矩形标出，矩形的宽度对应该滤波器的带宽。

带宽（以 Hz 为单位的过渡带）是滤波器作用的主要范围，以截止频率为中心。滤波器带宽的边界位于频率响应相对截止频率或中心频率有 3dB 幅度变化之处。Q（又称谐振）把滤波器的“宽度”描述为中心/截止频率与带宽之比。用 Q 代替带宽，可以让我们在移动中心/截止频率的同时保持各八度上的带宽不变。搁架式滤波器的 Q 参数常被称为 S（或斜率），尽管它与 Q 名义上是同一个东西。

滤波器的增益是中心频率或截止频率处的线性幅度。增益参数的解释在某种程度上取决于滤波器的类型。增益还可能影响滤波器响应中的一个搁架或一大片区域。

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Defer Automation Output int

消息

bang

左入口：在 display 模式下，bang 会使 filtergraph~ 对象把它内部存储的双二阶系数从最左出口送出。在交互式滤波器模式下，bang 还会使当前滤波器参数从各自对应的出口送出（见输出）。

int

所有 int 取值都会被转换成 float。

第 1-5 个入口：在 display 模式下，前五个入口之一收到 float，会改变界面上所选滤波器相应的 biquad~ 滤波器系数（依次为 a0、a1、a2、b1 与 b2）的当前取值，根据这些系数重新计算滤波器的频率响应，并使当前滤波器系数组成的列表从最左出口输出。

第 6 个入口：设置界面上所选滤波器的中心频率或截止频率参数并触发输出。

第 7 个入口：设置界面上所选滤波器的增益参数并触发输出。

第 8 个入口：设置界面上所选滤波器的 Q（谐振）或 S（斜率）参数并触发输出。

注意：向其中任意一个入口输入都会重新计算界面上当前所选滤波器的图形并触发输出。

参数：

  • filter-parameter [int]

float

第 1-5 个入口：在 display 模式下，前五个入口之一收到 float，会改变相应的 biquad~ 滤波器系数（依次为 a0、a1、a2、b1 与 b2）的当前取值，根据这些系数重新计算滤波器的频率响应，并使当前滤波器系数组成的列表从最左出口输出。

第 6 个入口：设置滤波器的中心频率或截止频率参数并触发输出。

第 7 个入口：设置滤波器的增益参数并触发输出。

第 8 个入口：设置滤波器的 Q（谐振）或 S（斜率）参数并触发输出。

注意：向其中任意一个入口输入都会重新计算当前滤波器的图形并触发输出。

allpass

左入口：allpass 一词把 filtergraph~ 对象的滤波器类型设为 allpass 模式。它等同于 mode 9 消息。滤波器的频率响应基于三个参数：cf（中心频率，或截止频率）、增益与 Q（谐振），不过只有增益参数对幅值响应有影响。全通滤波器的作用是修改相位响应（用 phasespect 1 消息查看相位响应）。

参数：

  • center-frequency [float]
  • gain [float]
  • Q [float]

analog

左入口：analog 一词后跟 0 或 1，切换 bandpass 与 peaknotch 滤波器的模拟滤波器原型参数。与标准的数字版本不同，这些“仿模拟”滤波器在奈奎斯特频率处没有陷波，因而模仿模拟滤波器的响应。仿模拟滤波器的计算开销略大，所以该选项默认设为 0（禁用）。

参数：

  • analog-filter-prototype [list]

bandpass

左入口：bandpass 一词把 filtergraph~ 对象的滤波器类型设为 bandpass 模式。它等同于 mode 3 消息。滤波器的频率响应基于三个参数：cf（中心频率）、增益与 Q（谐振）。

参数：

  • center-frequency [float]
  • gain [float]
  • Q [float]

bandstop

左入口：bandstop 一词把 filtergraph~ 对象的滤波器类型设为 bandstop 模式。它等同于 mode 4 消息。滤波器的频率响应基于三个参数：cf（中心频率）、增益与 Q（谐振）。

参数：

  • cutoff-frequency [float]
  • gain [float]
  • Q [float]

cascade

左入口：cascade 消息仅在显示模式下有效。单词 cascade 后面最多跟 24 组、每组五个对应滤波器系数的 float 取值，会显示一条复合滤波器响应，它展示了一组双二阶滤波器级联后的相乘结果。

参数：

  • filter-coefficient-list [list]

constraints

左入口：单词 constraints 后面跟七个数，可让你把频率、幅度和 Q 取值约束在指定范围内。这有助于约束通过点击并拖动得到的取值。第一个数应为整数，它指定要为其设置约束的滤波器编号。其余六个数是浮点取值，依次设置最小与最大频率值、最小与最大幅度值、最小与最大 Q 值。把约束值指定为零会移除该取值的约束。constrints 消息会促使滤波器系数输出。

参数：

  • filter-index [int]
  • minimum-frequency [float]
  • maximum-frequency [float]
  • minimum-gain [float]
  • maximum-gain [float]
  • minimum-Q [float]
  • maximum-Q [float]

dictionary

单词 dictionary 后面跟一个 symbol，它引用某个具名 filterdesign 对象字典，会使 filtergraph~ 对象使用该字典中的取值作为滤波器系数。

参数：

  • dictionary-name [symbol]

display

左入口：单词 display 把 filtergraph~ 对象的滤波器类型设为仅显示。它等价于 mode 0 消息。在显示模式下，filtergraph~ 只是显示一组五个 biquad~ 滤波器系数所对应的频率响应。

参数：

  • filter-type [list]

displaydot

左入口：displaydot 消息后面跟一个 0 或 1，在 filtergraph~ 处于显示模式时切换可鼠标操作的带宽区域的显示。这样你就能把 filtergraph~ 当作一个界面，用来设计并显示你自己的滤波器算法。默认值为禁用（默认情况下，显示模式只起显示作用）。

参数：

  • mousable-bandwidth-display [list]

flat

单词 flat 后面跟一个列表，它指定多重滤波器数组中各滤波器的索引，会把指定滤波器设为平坦响应（即滤波时不产生谐振）对滤波器所做的更改随滤波器类型而变：

低通和高通滤波器：Q 值设为 0.707，增益系数设为 1。（0dB）

带通和带阻滤波器会被忽略。

所有其他滤波器类型：增益系数设为 1。（0dB）

参数：

  • filter-indices [list]

gainmode

左入口：单词 gainmode 后面跟一个 0 或 1，为低通、高通、带通和带阻滤波器切换增益参数。这些滤波器的传统定义使用固定的 1.0 增益，但为它们启用增益后，就可以缩放其幅值响应，而无需在滤波器输出端额外使用一个信号乘法。默认值为 0（禁用）。

参数：

  • gain-parameter [list]

highorder

highorder 消息仅在显示模式下有效。单词 highorder 后面跟一个列表，其中包含 n 组双二阶滤波器 "a" 系数和 n-1 组双二阶滤波器 "b" 系数，将显示 n 阶滤波器的响应。

参数：

  • a/b-grouped-filter-coefficients [list]

highpass

左入口：单词 highpass 把 filtergraph~ 对象的滤波器类型设为高通模式。它等价于 mode 2 消息。滤波器的频率响应基于三个参数：cf（截止频率）增益，以及 Q（谐振）或 S（斜率——用于搁架式滤波器）。

参数：

  • cutoff-frequency [float]
  • gain [float]
  • Q [float]

highshelf

左入口：单词 highshelf 把 filtergraph~ 对象的滤波器类型设为高通搁架模式。它等价于 mode 7 消息。滤波器的频率响应基于三个参数：cf（截止频率）增益，以及 S（斜率）。

参数：

  • cutoff-frequency [float]
  • gain [float]
  • slope [float]

lowpass

左入口：单词 lowpass 把 filtergraph~ 对象的滤波器类型设为低通模式。它等价于 mode 1 消息。滤波器的频率响应基于三个参数：cf（中心频率，或截止频率）增益，以及 Q（谐振）。

参数：

  • cutoff-frequency [float]
  • gain [float]
  • Q [float]

lowshelf

左入口：单词 lowshelf 把 filtergraph~ 对象的滤波器类型设为低通搁架模式。它等价于 mode 6 消息。滤波器的频率响应基于三个参数：cf（中心频率，或截止频率）增益，以及 S（斜率）。

参数：

  • center-frequency [float]
  • gain [float]
  • slope [float]

markers

左入口：单词 markers 后面跟一个最多 64 个频率值的列表，会把这些频率处的可视标记（竖线）放在图形背后。markers 消息会设置线性和对数频率显示共用的标记。

参数：

  • frequency-value-markers [list]

mode

左入口：单词 mode 后面跟一个 0-9 的数字，设置当前的滤波器类型。数字与对应的滤波器类型如下。

数字 - 滤波器类型

0 - 仅显示
1 - 低通
2 - 高通
3 - 带通
4 - 带阻
5 - 峰值陷波
6 - 低通搁架
7 - 高通搁架
8 - 谐振
9 - 全通

在显示模式下，filtergraph~ 显示一组五个 biquad~ 滤波器系数所对应的频率响应。在其他模式下，它绘制基于三个参数的滤波器频率响应：cf（中心频率，或截止频率）增益，以及 Q（谐振）或 S（斜率——用于搁架式滤波器）。

参数：

  • filter-type [int]

(mouse)

你可以通过在 filtergraph~ 对象的显示区上点击并拖动来更改滤波器参数。默认情况下，鼠标水平拖动映射到截止频率，垂直移动映射到增益（若启用了 gainmode）。不过，如果光标正位于某个滤波器频带的边缘上，该频带矩形会高亮，表示此时点击并拖动会把 x 轴移动映射为调整滤波器带宽，而不是截止频率。 .
如果多个带宽区域互相重叠，可以在最上层那个区域上双击，在其中循环切换。这对于访问可能被较大区域「覆盖」的较小带宽区域很有用。

options

左入口：单词 options 后面跟五个整数，可让你为给定滤波器设置其专属选项。第一个数指定要为其设置选项的滤波器。其余四个整数依次设置滤波器模式（mode 消息）、启用增益标志（gainmode 消息）、模拟滤波器原型标志（analog 消息）和交互式滤波器模式标志（displaydot 消息）。options 消息会促使滤波器系数重新求值并输出。

参数：

  • filter-number [int]
  • filter-mode [int]
  • gain-enable-flag [int]
  • analog-filter-prototype-flag [int]
  • interactive-filter-mode-flag [int]

params

左入口：单词 params 后面跟三个指定频率、增益和 Q 的数时，会为当前选中的滤波器设置滤波器参数并触发输出。后面跟四个指定滤波器编号、频率、增益和 Q 的数时，这条消息会为所指示的滤波器设置滤波器参数并促使输出。

参数：

  • filter-index [int]
  • frequency [float]
  • gain [float]
  • Q [float]

peaknotch

左入口：单词 peaknotch 把 filtergraph~ 对象的滤波器类型设为峰值陷波模式。它等价于 mode 5 消息。滤波器的频率响应基于三个参数：cf（中心频率，或截止频率）增益，以及 Q（谐振）。

参数：

  • center-frequency [float]
  • gain [float]
  • Q [float]

query

左入口：单词 query 后面跟一个 float 取值，会促使该频率处图形的幅度与相位响应以列表形式从 filtergraph~ 对象的第六个出口送出。

参数：

  • frequency [float]

resonant

左入口：单词 resonant 把 filtergraph~ 对象的滤波器类型设为谐振模式（谐振带通滤波器）。它等价于 mode 8 消息。滤波器的频率响应基于三个参数：cf（中心频率）增益，以及 Q（谐振）。

参数：

  • center-frequency [float]
  • gain [float]
  • Q [float]

selectfilt

在界面中高亮某个特定滤波器。若要切换到某个滤波器来编辑它，请使用 whichfilt。

参数：

  • filter-index [int]

set

左入口：单词 set 后面跟一个由五个 int 取值组成的列表（对应 biquad~ 滤波器系数），会为 filtergraph~ 对象设置这些系数的内部取值，但不促使输出。若 filtergraph~ 处于显示模式，它会显示由这些系数得到的滤波器的频率响应。

第六个入口：一个由三个取值组成的列表，分别对应中心/截止频率、增益和 Q/S（谐振/斜率），会设置这些取值、重新计算新的滤波器系数，但不促使输出。在显示模式下这条消息没有效果。

参数：

  • a0/center frequency [float]
  • a1/gain [float]
  • a2/Q [float]
  • b1 [float]
  • b2 [float]

setconstraints

左入口：单词 setconstraints 后面跟七个数，可让你把频率、幅度和 Q 约束值设在指定范围内而不促使输出。这有助于约束通过点击并拖动得到的取值。第一个数应为整数，它指定要为其设置约束的滤波器编号。其余六个数是浮点取值，依次设置最小频率、最大频率、最小幅度、最大幅度、最小 Q 和最大 Q。把约束值指定为零会移除该取值的约束。

参数：

  • filter-index [int]
  • minimum-frequency [float]
  • maximum-frequency [float]
  • minimum-gain [float]
  • maximum-gain [float]
  • minimum-Q [float]
  • maximum-Q [float]

setfilter

左入口：单词 setfilter 后面跟一个数，按编号指定多重滤波器数组中当前选中的滤波器。滤波器编号从 0 开始。

参数：

  • filter number [list]

setoptions

左入口：单词 setoptions 后面跟五个整数，可让你为给定滤波器设置其专属选项而不触发输出。第一个数指定要为其设置选项的滤波器（滤波器编号从 0 开始）。其余四个整数依次设置滤波器模式（mode 消息）、启用增益标志（gainmode 消息）、模拟滤波器原型标志（analog 消息）和交互式滤波器模式标志（displaydot 消息）。

参数：

  • filter-number [int]
  • filter-mode [int]
  • gain-enable-flag [int]
  • analog-filter-prototype-flag [int]
  • interactive-filter-mode-flag [int]

setparams

左入口：单词 setparams 后面跟三个指定频率、增益和 Q 的数时，会为当前选中的滤波器设置滤波器参数而不触发输出。后面跟四个指定滤波器编号、频率、增益和 Q 的数时，这条消息会为所指示的滤波器设置滤波器参数，而不触发输出。

参数：

  • filter-index [int]
  • frequency [float]
  • gain [float]
  • Q [float]

whichfilt

把某个特定滤波器选为当前正在编辑的滤波器（不在显示区中高亮它）。

参数：

  • filter-index [int]

输出

float

第二到第五个出口：在 filtergraph~ 对象上点击时，输出频率、增益（线性）、谐振（Q）和带宽。

int

最右侧（第七个）出口：滤波器索引。为由 nfilters 特性决定、所有被显示的级联双二阶滤波器输出其索引号。

list

最左出口：供 biquad~ 对象使用的由 5 个浮点滤波器系数组成的列表。这些系数在响应鼠标点击以及系数入口或滤波器参数入口发生变化时输出。打开音频时也会输出，若开启了自动输出选项，还可选择在加载补丁时输出（参见 autoout 消息）。

第六个出口：响应 query 消息（见上文）而输出由 2 个浮点取值（幅度、相位）组成的列表。
