Max

clocker

按固定间隔报告已过去的时间

描述

clocker 对象是一个节拍器，报告自启动以来已经过去的时间。该对象使用 Max 的 时间格式语法，因此 clocker 对象使用的间隔既可以是固定的，也可以是相对速度的。它的输出可以用相对速度的语法进行量化；若设置了 autostarttime 特性，该对象还可以在一个相对速度的位置启动。

参数

time-interval [int, float, symbol] 可选

第一个参数为 clocker 送出输出的时间间隔设置一个初始值。该时间间隔既可以是一个以毫秒为单位指定时间的数字（例如 clocker 200），也可以是一个 notevalue（例如 clocker 4nd）。

注意：虽然 clocker 对象允许你用 Max 任何一种标准时间格式来指定时间，但当用毫秒或 notevalue 之外的任何其他时间单位指定时间时，应使用 Interval 特性参数。

若没有参数，初始时间间隔设为 5 毫秒。若为延迟间隔指定了 notevalue、ticks 或 bars.beats.units，则除非传输正在运行，clocker 对象不会工作。

特性

active [int] : 0

打开或关闭 clocker 对象。

autostart [int] : 0

若打开（非零），clocker 对象会在 autostarttime 特性指定的时间自动开始运行。

autostarttime [Time Value] : 0 ticks

若启用 autostart 特性（非零），clocker 对象会在该特性指定的时间自动开始运行。autostart 的作用相当于一个 timepoint 对象，它是 clocker 对象内部的。

defer [float] : 0.

打开此项以在低优先级队列中送出输出。

interval [Time Value] : 5 ms

设置 clocker 对象送出 bang 的时间间隔。时间可以用 Max 中使用的任何一种时间格式指定。

quantize [Time Value] : 0 ticks

仅在适当的时候按指定的时间边界送出输出。这是通过对送出输出所用的时间做内部调整来实现的。量化可以用下列时间格式指定：bars.beats.units、ticks 或音符时值。

transport [symbol] : internal

该特性为一个传输命名。若时间用'relative'单位指定（例如：ticks、bars.beats.units 或 notevalues），则会用所命名的传输根据速度、拍号和其他相关信息来确定延迟时间。

消息

bang

左入口：启动 clocker 对象。若 clocker 对象未在运行，bang 消息会开始计数。若 clocker 对象正在运行，bang 消息会重设计数。

int

左入口：任何非零数字都会启动 clocker 对象。自 clocker 启动以来已经过去的时间会按固定间隔从出口送出。0 会停止 clocker 对象。

参数：

  • non-zero-to-start [int]

float

同 int。

参数：

  • non-zero-to-start [float]

list

右入口：可以用列表按 Max 的某一种时间格式指定时间。

参数：

  • input [list]

anything

与 list 相同。

参数：

  • interval [list]

clock

clock 一词后面跟一个现有 setclock 对象的名称，会把 clocker 对象设为由该 setclock 对象控制，而不是由 Max 内部的毫秒时钟控制。clock 一词单独使用，则把 clocker 对象设回使用 Max 常规的毫秒时钟。

参数：

  • setclock object name [symbol]

reset

左入口：把已过去的时间重置为 0，但不停止也不重启时钟；clocker 会继续按相同的固定间隔报告新的已过去时间。当 clocker 未在运行时，该消息没有意义，因为停止时它本来总会重置为 0。

stop

左入口：停止 clocker 对象。
