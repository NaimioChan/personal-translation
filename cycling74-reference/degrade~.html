MSP

degrade~

信号质量降低器

描述

degrade~ 接收任何给定信号，并按指定/需要降低采样率与位深。

参数

resampling-frequency-ratio [float] 可选

第一个参数设置重采样频率比，如上所述。若未提供该参数，默认值为 1.0。

number-of-quantization-bits [int] 可选

第二个参数设置用于量化输入信号的位数。若未提供该参数，默认值为 24。

消息

int

右入口：用于量化输入信号的位数。该值必须在 1-52 范围内。位数越少，信号质量越低。

参数：

  • number-of-quantization-bits [int]

float

中间入口：对输入信号进行重采样的频率比，从而有效降低其采样率。该比值是重采样率除以系统采样率。例如，若 MSP 当前的采样率为 44100 Hz，比值为 0.75，则输出信号的有效采样率为 33075 Hz。

参数：

  • resampling-frequency-ratio [float]

signal

左入口：要降低质量的信号。

输出

signal

输出信号是经过重采样与量化之后的输入信号。注意，此对象在重采样时故意不使用任何插值，量化时也不使用任何抖动。它的用途是制造“low-fi”效果。

注意：听此对象的输出时要小心。量化到很少的位数会产生非常响、非常嘈杂的信号。
