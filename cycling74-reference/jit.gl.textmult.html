jit.gl.textmult

多个 3D 文本

描述

jit.gl.textmult 对象与 jit.gl.multiple 非常相似，只是用于文本。它允许把一组单词当作多个 jit.gl.text 对象来处理，这些对象可以通过矩阵控制。它还能为当前这些单词计算一个布局位置矩阵，并输出以供在补丁中复用。

参数

drawto [message] 可选

用于绘制的具名绘制上下文（默认值 = none）。具名绘制上下文是 jit.world、jit.pworld 或 jit.gl.node 对象的具名实例。若不提供参数，该对象会隐式地找到一个上下文。

inputs_number [integer] 可选

该对象将拥有的输入数量。输入数量决定可以使用的 glparams 数量。

特性

align []

设置计算布局矩阵时所用的水平对齐方式。取值为 0: left, 1: center, 2: right, 3: justify。在当前实现中，justify 的行为与左对齐相同。

color []

网格的颜色（默认值 = 1. 1. 1. 1.）

enable []

启用标志（默认值 = 1）该标志置位时，绘图被启用。

position []

3D 原点，形式为 x y z（默认值 = 0. 0. 0.）

line_length []

设置单词换行到新行之前允许的最大布局宽度。该取值所用的坐标空间与生成的文本几何体相同，而不是以字符数量计。

leadscale []

多行文本之间的行距，以标准行距的倍数表示。（默认值 = 1.）

tracking []

字距（字符内间距），以该字体的标准字距的倍数表示。（默认值 = 1.）

scale []

3D 缩放系数，形式为 x y z（默认值 = 1. 1. 1.）

texture []

要应用的纹理名称（默认值 = none）。

fontname []

设置所用字体类型的名称。

depth []

3D 几何体相对于字体高度的深度（z 方向范围）（默认值 = 0.）。若深度为 0，则不会生成挤出的字符侧面，绘制会快得多。仅在 mode 为 3d 时有效。

weight []

文本字重（默认值 = normal）

slant []

文本倾斜（默认值 = normal）

use_individual_texcoord []

设置纹理坐标的行为。若设为 0，每个单词会映射到纹理的单个像素。若设为 1，每个单词会被整张纹理覆盖。

设置对象的字体。

切换补丁锁定后对象是否隐藏。

ignoreclick [int] : 0

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]
