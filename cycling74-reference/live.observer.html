Max for Live

live.observer

监视 Live 对象的变化

描述

live.observer 用于监听 Live 对象各特性取值的变化。该对象与 live.path 对象配合工作，后者会把 id nn 消息发送到 live.observer 的右入口。

指定对象 id 与特性之后，其取值会从左出口送出。从此以后，每次该特性发生变化（'notification'）时都会送出该取值，响应 bang 消息时也会送出。

左出口专用于取值消息，其他所有输出都送往右出口。

并非所有特性都可以观察，请查阅 Live Object Model 了解哪些可以。另外，无法在通知中修改 Live set，也就是说，正在接收由 live.observer 出口自发送出的取值消息时不能修改。

除了特性之外，也可以观察 Live 对象的子项。它们的取值是对象 id 或 id 列表。

注意：Live API 在 Live 的主线程中运行，所有发往该 API 及从该 API 发出的消息都自动延后执行。

把特性名或子项名指定为 live.observer 的参数。

入口

Left inlet

获取下面描述的所有命令消息。

Right inlet

收到对象 id 消息 id nn 后，选中要操作的对象。响应 id 消息时，若此前已选中某个特性，会把该特性的当前取值从左出口送出。
id 0 表示没有对象，即发往左入口的所有消息都会被忽略，这也是初始状态。

出口

左出口

送出所选对象上所选特性的当前取值。取值类型取决于该特性，如 Live Object Model 中所述，可能是 int、float、symbol、id nn 或 id 列表。

右出口

送出对 getproperty、gettype、getid 的响应。

备注：
并非所有特性都可以观察。
特性的类型在 Live Object Model 中给出。

出口输出示例

Inspector

Persistence

live.observer 对象的 Inspector 中有一个特殊条目，名为 "Use Persistent Mapping"。启用该设置后，与对象关联的 id 会在 Live 文档保存与恢复时、以及 Max Device 在 Live 应用程序与 Max 编辑器之间或在 Live Set 内移动时保持持久。从 Live 8.2.2 起，Live API 的 id 在多次启动 Live 之间保持持久，再加上 Persistence 特性（live.object、live.observer 与 live.remote~ 都有该特性），就可以创建更简单的设备，让它们与 Live 用户界面中的元素保持关联。
