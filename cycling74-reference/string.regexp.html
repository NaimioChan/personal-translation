Max

string.regexp

用正则表达式处理输入

参数

expression [symbol] 可选

可以用一个正则表达式作为参数来设置正则表达式（正则表达式格式与元字符信息见上文）。

substitution [symbol/list] 可选

可选的第二个参数将设置替换字符串。

特性

re [symbol]

词语 re，后面跟一个兼容 PERL 的正则表达式，设定在任何 symbol 或 list 输入内做解析或替换时使用的正则表达式规则。

若正则表达式包含空格，在用 re 消息指定它、或把它作为键入 string.regexp 对象的参数时，必须把它用双引号括起来。

正则表达式使用下列形式与语法：

[...] 定义一个字符的「类」。其中的任何字符都可能被匹配。其中还可以出现若干特殊符号：

...-... 指定一个范围（在 ASCII 码范围内）

\\d 指定一位十进制数字（\\D 指定非十进制数字）。注意必须使用双反斜杠 —— Max 会抹掉单反斜杠。

\\s 指定空白（\\S 指定非空白）。注意必须使用双反斜杠 —— Max 会抹掉单反斜杠。

\\w 指定字母数字（\\W 指定非字母数字）。注意必须使用双反斜杠 —— Max 会抹掉单反斜杠。

^... 指定一个补集

...* 出现零次

...+ 至少出现一次

...? 出现一次或完全不出现

(...) 指定一个捕获组，可在诸如 %n 这样的替换字符串中引用它，其中 n 是圆括号从左到右的顺序位置。

substitute [symbol]

substitute 一词后面跟一个符号，会传入一个用于替换的符号。如果 substitute 一词后面没有跟符号，则移除先前的替换符号。

注意：如果你需要在任何替换字符串中输出一个后面跟数字的 %，应使用 %%，这样 % 就不会被读作捕获组。

消息

bang

重新处理此前收到的 string 并触发输出。

int

把传入的整数转换为字符串，然后按 string 消息所述方式处理。

参数：

  • value [int]

float

把传入的浮点数转换为字符串，然后按 string 消息所述方式处理。

参数：

  • value [float]

list

把传入的 list 转换为字符串，然后按 string 消息所述方式处理。

参数：

  • list-value [list]

anything

把输入的列表转换为字符串，然后按 string 消息所述的方式处理。

在中间入口，可以提供 symbol/list 作为新的 re。在右入口，可以提供 symbol/list 作为 substitute。

参数：

  • list-value [list]

string

在左入口，字符串会作为目标字符串由 PCRE 引擎处理，并使用所提供的任何 re 和 substitute。

输出

symbol or list

左出口：若已用 substitute 消息设置替换字符串，输入的列表或 symbol 会连同所需的替换一起从左出口送出（注意：替换字符串可以包含捕获组，形式为 %n）。

中间左出口：若正则表达式中包含圆括号，它们会被当作捕获组。中间左出口在被处理的字符串内每次匹配时报告这些捕获组，并把它们作为嵌套数组输出；每个子字符串匹配对应一个数组，各自包含所捕获的字符串。

中间出口：中间出口报告正则表达式与被处理字符串的部分内容相匹配的子字符串所组成的数组。

中间右出口：在未发生匹配的情况下，中间右出口透传原始输入。

右出口：最右出口用于报告任何子字符串匹配的偏移量（起点、终点）；也就是说，这些偏移量可供 string.slice 用来从输入字符串导出子字符串。偏移量以嵌套数组的形式提供；每个子字符串匹配对应一个数组，含起点和终点偏移量。
