MSP

stepfun~

生成由输入相位器定序的函数

描述

stepfun~ 对象生成断点函数，其时间由一个输入相位器斜坡序列决定。若输入斜坡是非线性的，stepfun~ 的输出也会同样是非线性的。

参数

无。

特性

curvemode [int] : 2

决定如何解释列表输入
可选值：

0 = 'Off'（无曲线数据）
当 curvemode 设为 Off 时，传入的列表总会被解释为一串取值-时间对。

1 = 'On'（始终解释为曲线数据）
当 curvemode 设为 On 时，传入的列表总会被解释为一组三个取值：取值、时间和曲线参数。

2 = 'Auto'（使用所连接的 function 对象的曲线模式）
当 curvemode 设为 Auto 时，传入的列表会依据最初发送该数据的 function 对象的当前设置来解释。

curvepattern [atom]

每一步的可选曲线参数序列

pattern [atom]

输出取值的序列；stepfun~ 会在这些取值之间生成斜坡。

syncupdate [int]

启用 syncupdate 后，对 pattern 的修改要等到输入重置或者输出序列走完才生效。
可选值：

0 = 'Off' （立即更改）
1 = 'Input Reset' （输入重置时更改）
2 = 'After End Step' （输出序列走完时更改）

消息

bang

bang 会把序列步重置到起点

int

左入口：转换为 float
右入口：设置当前步号；若右入口连有信号，此消息不起作用。

float

左入口收到的 float 会把序列设为单个常量取值；若 float 后面跟一个列表，它会被解释为序列的初始取值，这符合 function 对象送出的断点函数格式约定。

list

list 设置输出取值的序列；若该列表带有曲线数据且 curvemode 特性设为解析曲线取值，则相应步的曲线参数也会被设置。曲线参数在 -1 与 1 之间变化，取值 0 表示没有曲线。更多信息见 function 对象。

signal

左入口：相位器序列输入
右入口：步号

step

消息 step 后面跟一个数字会设置当前步。步从 0 开始编号。若右入口连有信号，step 消息不起作用。
