Gen

poke

把取值写入 data/buffer 对象

描述

把取值写入 data/buffer 对象。第一个参数应当是 gen 补丁中某个 data 或 buffer 对象的名称。第二个参数（若省略则为第三个入口）指定要使用哪个通道。第一个入口指定要写入的取值，第二个入口指定在 data/buffer 中的采样索引。若索引超出范围，则不写入任何取值。

构造

  • { arguments={name, value, position, channel, overdub}, inlets={} }
  • { arguments={name, value, position, channel}, inlets={overdub} }
  • { arguments={name, position, channel}, inlets={value, overdub} }
  • { arguments={name, channel}, inlets={value, position, overdub} }
  • { arguments={name}, inlets={value, position, channel, overdub} }

入口

value [float]

要写入的值

position [float]

要写入的位置（单位取决于 @index 特性）

channel [int]

要写入的通道（从零开始）

overdub [float]

overdub 混合：要保留的原始信号量

特性

boundmode [enum] : ignore 只写

处理超出范围的索引："ignore" 阻止写入，"wrap" 把索引回绕到缓冲区范围内，"fold" 与 "mirror" 通过交替方向把索引回绕回范围内，"clip" 与 "clamp" 把索引约束在缓冲区边界内。
可选值：

0 = 'clamp'
1 = 'ignore'
2 = 'wrap'
3 = 'clip'
4 = 'fold'
5 = 'mirror'

channelmode [enum] : ignore 只写

处理无效的通道索引："ignore" 阻止写入，"wrap" 把索引回绕到缓冲区的通道中，"fold" 与 "mirror" 通过交替方向把索引回绕回范围内，"clip" 与 "clamp" 把索引约束在可用的通道内。
可选值：

0 = 'clamp'
1 = 'ignore'
2 = 'wrap'
3 = 'clip'
4 = 'fold'
5 = 'mirror'

index [enum] : samples 只写

指定如何为缓冲区建立索引："samples" 按缓冲区内的采样点偏移来索引，"phase" 把 0..1 范围内的信号转换为跨越整个缓冲区，"lookup" 或 "signal" 把 -1..1 范围内的信号转换为跨越整个缓冲区。
可选值：

0 = 'samples'
1 = 'phase'
2 = 'lookup'
3 = 'signal'

overdubmode [enum] : accum 只写

overdubbing 如何应用："mix" 按照 overdub 系数在当前采样点与新采样点之间交叉淡化，"accum" 按 overdub 系数缩放新采样点并把它加到当前采样点上。
可选值：

0 = 'accum'
1 = 'mix'

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。
