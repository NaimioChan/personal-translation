MSP

gridmeter~

以亮度显示信号电平

描述

gridmeter~ 对象以亮度显示多个信号（通常来自多通道 Max 对象）的 RMS 电平，并指示输入信号的有无。

参数

无。

特性

attack [float] : 300.

设置电平表的启动时间，单位为毫秒

bgcolor [4 floats]

设置背景颜色

cellheight [int] : 12

设置电平表单元格的高度（单位：像素）

cellwidth [int] : 16

设置电平表单元格的宽度（单位：像素）

color [4 floats]

设置电平表的颜色

columns [int] : 8

设置最大列数

contrast [float] : 0.7

设置信号电平的亮度范围（默认值 0.5）。contrast 特性的范围为 0.1 - 0.9。

dividersize [int] : 2

设置分隔各电平表的水平与垂直分隔线的尺寸（单位：像素）

elementcolor [4 floats]

设置无信号时各指示器的颜色

hotcolor [4 floats] : 0.86275 0.39126 0.39126 1.

设置信号取值超过 0 dB 时显示的颜色

interval [float] : 20.

设置信号轮询间隔，单位为毫秒

range [float] : 60.

设置显示的 dB 范围；取值越大可能会降低颜色的对比度。

release [float] : 300.

设置电平表的释音时间，单位为毫秒

shape [int] : 0

设置电平表单元格的形状
可选值：

0 = 'Square'（矩形形状）
1 = 'Round'（圆形或椭圆形）

style [symbol] :

设置 gridmeter~ 显示所用的样式。
