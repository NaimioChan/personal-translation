MSP

snapshot~

把信号值转换为数字

描述

用 snapshot~ 对象在收到 bang 时或按指定的间隔把一个信号取值转换为 float 消息。该间隔可以用 Max 的时间格式语法设为固定的时间或相对于速度的时间。

讨论

snapshot~ 对象在启用 Scheduler in Audio Interrupt 时是采样点精确的。更多细节见此处。

参数

reporting-interval [list] time-value 可选

以 ms 为单位或用 Max 的时间格式语法设置报告间隔。若间隔为 0，snapshot~ 只会在收到 bang 消息时输出数据。

特性

active [int]

启用 active 后，snapshot~ 会按 interval 特性指定的速率输出采样点取值。

interval [Time Value] : 0 ms

报告间隔

offset [int]

信号向量中将被报告的那个采样点的索引。该索引被限制在 0 与当前信号向量大小减一之间。

消息

bang

报告最近一次收到的信号向量中、由 offset 特性指定的偏移量处的采样点取值。若 offset 为 0，并且在启用 Scheduler in Audio Interrupt 时 bang 消息是在高优先级线程上收到的，snapshot~ 会报告当前调度器时间所处的采样点偏移量处的取值。

int

左入口：任何非零取值都会开启基于间隔的报告，0 则将其关闭。若已指定非零间隔，报告默认开启。
右入口：设置报告间隔，单位为 ms。若间隔为 0，自动报告停止。

参数：

  • internal-clock-enable-flag [int]

float

左入口：任何非零取值都会开启基于间隔的报告，0 则将其关闭。若已指定非零间隔，报告默认开启。
右入口：设置报告间隔，单位为 ms。若间隔为 0，自动报告停止。

参数：

  • internal-clock-enable-flag [float]

list

用 Max 时间格式 语法设置间隔。

参数：

anything

用 Max 时间格式 语法设置间隔。

参数：

sampleinterval

参数：

输出

float

当 snapshot~ 收到 bang，或启用了周期报告时，输入信号的采样点取值会从其出口送出。
mc.snapshot~ 从其右出口输出 voice 以及所连接多通道信号的通道号，随后从其左出口输出该通道的采样点取值。
