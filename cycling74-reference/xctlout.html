xctlout

格式化 14 位 MIDI 控制器消息

描述

格式化 14 位 MIDI 连续控制器消息，以便用 midiout 对象发送。

讨论

单条 14 位 MIDI 连续控制器消息由两组字节组成，一组是数值的最高有效字节（MSB，位于控制器 0-95 上），另一组是最低有效字节（LSB，位于 MSB 控制器 + 32 上）。

参数

ctrllr-channel [list] 可选

第一个参数是 xctlout 格式化控制消息时所用高分辨率控制器编号的初始值（范围 0-95）。控制器编号会自动限制在 0 到 95 之间。若没有指定控制器编号，初始控制器编号为 1。

在控制器编号参数之后是格式化控制消息所用通道号的初始值。若没有通道参数，xctlout 最初在通道 1 上格式化控制消息。要使用该参数，必须在它前面给出控制器编号参数。通道号会被裁剪到 1-16 范围内。

特性

lsbfirst [int] : 0

启用后，格式化后的连续控制器消息中的 LSB 字节组会先被发送，然后是 MSB 字节组。某些 MIDI 硬件要求如此。

running [int] : 0

若启用了 running status，格式化后的连续控制器消息中第二组（LSB）字节的状态字节会被省略。

消息

bang

使用 xctlout 中当前存储的数字送出一条高分辨率 MIDI 连续控制器消息

int

该数字是一个 14 位连续控制器值，将由 xctlout 格式化为一条完整的高分辨率 MIDI 连续控制器消息。

参数：

  • input [int]

(inlet1)

中间入口：该数字被存储为 xctlout 发送的 control change 消息的控制器编号。0-95 范围之外的控制器编号会被忽略。

参数：

  • controller [int]

(inlet2)

右入口：该数字被存储为 xctlout 送出的连续控制器消息的 MIDI 通道。通道号会被裁剪，以保持在 1-16 范围内。

参数：

  • channel [int]

float

该数字是一个 14 位连续控制器值，将由 xctlout 格式化为一条完整的高分辨率 MIDI 连续控制器消息。

参数：

  • input [float]

list

一对 7 位数值（先是最高有效字节（MSB），其次是最低有效字节（LSB））会被按位或到一起，形成一个 14 位连续控制器值。该 14 位值将由 xctlout 格式化为一条完整的高分辨率 MIDI 连续控制器消息。

参数：

  • msb [int]
  • lsb [int]

输出

int

当左入口收到一个值时，完整的高分辨率 MIDI 连续控制器消息会逐字节地从出口送出。
