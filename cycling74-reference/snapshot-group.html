MSP

snapshot-group

快照组共有的消息与特性

参数

无。

特性

autosave [int] 只写

保存所属补丁时，该对象快照的状态也会一并保存。

消息

snapshot >= 7.0.0

创建快照。embedsnapshot 打开时，快照会保存到当前补丁中；否则会保存到外部文件。可以通过该消息的一个参数指定文件名。

参数：

  • file-name [symbol]

restore >= 7.0.0

恢复快照。embedsnapshot 打开时，会使用嵌入当前补丁中的快照；否则会从外部文件加载。可以通过该消息的一个参数指定文件名。

参数：

  • file-name [symbol]

addsnapshot

添加新快照。若没有参数，会把新快照追加到当前快照列表末尾。若第一个参数是包含文件路径的字符串，Max 会尝试把 .maxsnap 文件保存到该位置。若第一个参数是数字，会把快照保存到该槽位，其后的槽位索引依次递增。若第二个参数是字符串，会设置该快照的名称。

参数：

  • userpath [String]
  • index [Number]
  • name [String]

deletesnapshot

删除给定索引处的快照，其后的槽位索引依次递减。

参数：

  • index [Number]

exportsnapshot

从第一个参数指定的索引处导出快照。第二个参数指定导出 maxsnap 文件的文件名与路径。若第二个参数为空，会打开 File 对话框，供你指定文件名和位置。

参数：

  • index [Number]
  • filename [String]

importsnapshot

把快照导入到第一个参数指定的索引处。第二个参数指定要加载 maxsnap 文件的文件名与路径。若第二个参数为空，会打开 File 对话框，供你选择文件。

参数：

  • index [Number]
  • filename [String]

setsnapshotname

设置给定索引处快照的名称。

参数：

  • index [Number]
  • name [String]

setembedsnapshot

设置该索引处快照的嵌入状态。

参数：

  • index [Number]
  • embedstate [Number]

movesnapshot

更改快照的索引。

参数：

  • srcindex [Number]
  • dstindex [Number]
