jit.gl.volume

Create a volume visualization

描述

Creates a transparent volume from a volumetric density field. This process is GL accelerated by using graphics hardware.

讨论

Internally, jit.gl.volume creates a 3d jit.gl.texture object and applies it to multiple view-aligned slices of geometry. The resulting slices are then blended together using the standard ob3d blend modes. The density and intensity attributes subsequently control which features are visibile. By enabling the cubes attribute, slices will be rendered in both horizontal and vertical direction, which may result in a visualization which that is comparatively better or worse depending on the volume dataset being used.

This OB3D object optionally takes one argument: the name of a drawing context. This is a named instance of a jit.world, or jit.pworld object, or a jit.gl.node sub-context. This value may also be set via the OB3D drawto attribute. If no argument is present, the object is implicitly added to the first valid drawing context or sub-context found in the current patch or by searching up the patcher hierarchy.

特性

bounds [int]

Flag which enables or disables the rendering of the bounding box surrounding the volume (default = 0).

density [float]

The density threshold for constructing the surface. (default = 0.5)

intensity [float]

The intensity scale factor for multiplying against volume density values. (default = 0.5)

slices [int]

Sets he number of slices used as proxies for rendering the volume data.

OB3D 特性

alpha_mode [symbol]

用独立的 alpha 混合函数与方程对混合过程进行更精细的控制。
可选值：

'link' ( 与 blend_mode 链接（默认值） )
'max' ( 取最大值 )
'add' ( 求和 )
'replace' ( 用源替换目标 )
'ignore' ( 忽略源 )

anim [symbol]

处理该实例所有空间变换的 jit.anim.node 对象的名称（默认值 = UID）。默认值引用一个内部对象，但可以把它设为某个已存在的外部 jit.anim.node 实例的名称来覆盖。这样可以更高级地控制空间变换。

anchor [3 floats]

局部空间中的锚点位置（默认值 = 0. 0. 0.）。用于偏移应用变换所围绕的局部 3D 原点。

animmode [symbol]

决定 anim_move 与 anim_turn 消息在哪个空间中影响该对象的位置和朝向（默认值 = parent）。
local = 相对局部轴旋转
parent = 相对父级轴旋转
world = 相对世界轴旋转

automatic [int]

自动渲染标志（默认值 = 1）该标志置位时，关联的 jit.gl.render 对象收到 bang 消息时即进行渲染

aux_color [4 floats]

辅助颜色，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

axes [int]

x/y/z 轴渲染关/开（默认值 = 0）

blend [symbol]

具名混合模式。可选值有：
add = blend_mode 1 1
multiply = blend_mode 2 1
screen = blend_mode 4 1
exclusion = blend_mode 4 5
colorblend = blend_mode 3 4
alphablend = blend_mode 6 7
coloradd = blend_mode 3 1
alphaadd = blend_mode 6 1

blend_enable [int]

混合标志（默认值 = 0）该标志置位时，所有被渲染的对象都启用混合。

blend_mode [2 ints]

与混合模式关联的源通道和目标通道（默认值 = 6 7）混合模式以 src_blend_mode dst_blend_mode 的形式给出。支持的取值有：
0 = zero
1 = one
2 = destination color
3 = source color
4 = one minus destination color
5 = one minus source color
6 = source alpha
7 = one minus source alpha
8 = destination alpha
9 = one minus destination alpha
10 = source alpha saturate

depth_clear [int]

深度缓冲清除标志（默认值 = 0）该标志置位时，渲染对象之前会清除深度缓冲。

depth_enable [int]

深度缓冲标志（默认值 = 1）该标志置位时，启用深度缓冲。

depth_write [int]

深度写入标志（默认值 = 1）。该标志置位时，启用对深度缓冲的写入。若 depth_enable 已关闭，则此设置无效。

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

filterclass [symbol]

该对象拾取过滤器类的名称（默认值 = default）。它控制对象对 jit.gl.handle 和 jit.gl.picker 对象是否可见。要选中该对象，filterclass 的值必须在拾取对象的 filters 列表中。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

name [symbol]

实例名称（默认值 = UID）

position [3 floats]

3D 原点，形式为 x y z（默认值 = 0. 0. 0.）

quat [4 floats]

当前旋转的四元数表示（默认值 = 0. 0. 0. 1.）。四元数是一种数学构造，它是一个四维向量，可以看作绕任意轴的旋转。四元数是 3D 空间中朝向的一种有用表示。

rotate [4 floats]

旋转角度以及绕其进行旋转的 xyz 向量，形式为 rotation-angle x y z（默认值 = 0. 0. 0. 1.）

rotatexyz [3 floats]

把当前旋转设为绕 x、y、z 正轴旋转的复合，也称为欧拉角（默认值 = 0. 0. 0.）。默认顺序为 yzx，可用 jit.gl.render 的 rotate_order 特性更改。角度以度为单位。

scale [3 floats]

3D 缩放系数，形式为 x y z（默认值 = 1. 1. 1.）

smooth_shading [int]

平滑着色标志（默认值 = 0）该标志置位时，渲染时使用平滑着色。

transform_reset [int]

模型视图与投影变换重置标志（默认值 = 0）该标志置位时，渲染对象之前会把模型视图变换与投影变换设为单位变换。这适用于精灵或公告板叠加，或按窗口大小自动缩放。transform_reset 标志的模式有：
0 = 不做任何事（默认值）
1 = 等比正交 glOrtho(-aspect, aspect, -1.0, 1.0, near_clip, far_clip);
2 = 归一化正交 glOrtho(-1.0, 1.0, -1.0, 1.0, near_clip, far_clip);
3 = 近裁剪面为 0.001 的等比透视 gluPerspective(lens_angle, aspect, 0.001/*near_clip*/, far_clip);
4 = 近裁剪面为 0.001 的归一化透视 gluPerspective(lens_angle, 1.0, 0.001/*near_clip*/, far_clip);

viewalign [int]

视图对齐变换标志（默认值 = 0）
