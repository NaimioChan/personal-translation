jit.gl.meshwarp

视频映射工具

描述

jit.gl.meshwarp 对象会对投射在二维网格上的视觉素材进行变形。它可用于视频映射或其他创意应用。

参数

drawto [message] 可选

用于绘制的具名绘制上下文（默认值 = none）。具名绘制上下文是 jit.world、jit.pworld 或 jit.gl.node 对象的具名实例。若不提供参数，该对象会隐式地找到一个上下文。

特性

apply_mask []

使用已有的遮罩隐藏或显示 meshwarp 平面（默认值 = 0）

color []

网格的颜色（默认值 = 1. 1. 1. 1.）

checkerboard []

在 meshwarp 输出上显示棋盘格测试模式，而不是输入纹理（默认值 = 0）。

checkerboardscale []

启用 checkerboard 时设置棋盘方格缩放（默认值 = 1.）。

curvature []

快速设置 X 与 Y 两个方向的 NURBS 阶数，它决定底层画布网格的弯曲程度（范围 0. 到 1.）。根据当前的 mesh_dim，设置 nurbs_order 的两个维度。该特性为 float 类型，但输出会被钳位为 int 取值，因此调整时可能显得跳变。

edgeblendleft []

在归一化的网格空间中设置左边缘混合宽度（范围 0. 到 1.，默认值 = 0.）。

edgeblendright []

在归一化的网格空间中设置右边缘混合宽度（范围 0. 到 1.，默认值 = 0.）。

edgeblendtop []

在归一化的网格空间中设置上边缘混合宽度（范围 0. 到 1.，默认值 = 0.）。

edgeblendbottom []

在归一化的网格空间中设置下边缘混合宽度（范围 0. 到 1.，默认值 = 0.）。

edgeblendcurveleft []

设置左边缘混合曲线（范围 0.1 到 10.，默认值 = 1.）。取值为 1. 时得到线性斜坡。

edgeblendcurveright []

设置右边缘混合曲线（范围 0.1 到 10.，默认值 = 1.）。取值为 1. 时得到线性斜坡。

edgeblendcurvetop []

设置上边缘混合曲线（范围 0.1 到 10.，默认值 = 1.）。取值为 1. 时得到线性斜坡。

edgeblendcurvebottom []

设置下边缘混合曲线（范围 0.1 到 10.，默认值 = 1.）。取值为 1. 时得到线性斜坡。

enable []

启用标志（默认值 = 1）该标志置位时，绘图被启用。

invert_mask []

置位该标志后，遮罩会被反转。只有在各遮罩内部包含的内容才会显示在 meshwarp 平面中。

layer []

对象的图层编号（默认值 = 0）。在自动模式下，图层编号决定渲染顺序（从低到高）。同一图层中的对象无法保证谁先被渲染。

lock_to_aspect []

锁定缩放，使其匹配输入纹理的比例（默认值 = 0）。设为激活后，scale 特性只会响应第二个特性参数（y 缩放）。

mask_mode []

置位该标志后，会启用遮罩模式，并支持以下编辑操作：

  • 新建遮罩：在 meshwarp 平面上 shift + 双击
  • 移动遮罩：在蓝色遮罩圆点上 ctrl/cmd + 拖动
  • 删除遮罩：在蓝色遮罩圆点上 shift + 双击
  • 修改遮罩形状：在黄色遮罩圆点上 点击并拖动
  • 添加遮罩顶点：在遮罩边缘线上 shift + 双击
  • 删除遮罩顶点：在黄色遮罩圆点上 shift + 双击

maskfeather []

设置所有遮罩的羽化量（范围 0. 到 0.95，默认值 = 0.）。

maskfeathercurve []

设置所有遮罩的羽化曲线（范围 0.1 到 10.，默认值 = 2.）。取值为 1. 时得到线性斜坡。

meshdim []

UI 网格的维度。设置所显示的、可点击的顶点数量（默认值 = 4 4）

nurbs_order []

设置底层 NURBS 画布网格的 X 与 Y 阶数。阶数决定画布网格的弯曲程度（默认值 = 1 1）。

output_texture []

捕获到内部纹理（默认值 = 0）。启用后，对该 meshwarp 的渲染会被捕获到纹理，并把纹理名称从左出口输出。纹理的维度等于渲染窗口的维度。

position []

3D 原点，形式为 x y z（默认值 = 0. 0. 0.）

rotatez []

设置绕正 z 轴的当前旋转（默认值 = 0.）。角度以度为单位。

scale []

3D 缩放系数，形式为 x y z（默认值 = 1. 1. 1.）

scalemask []

设置所有遮罩的缩放系数（范围 0.01 及以上，默认值 = 1.）。

show_position_handle []

显示 / 隐藏位置手柄圆圈的标志（默认值 = 1）

show_scale_handles []

显示 / 隐藏缩放手柄圆圈的标志（默认值 = 1）

show_ui []

显示或隐藏 jit.gl.meshwarp 的交互式用户界面（默认值 = 1）。置位该标志后，若对象当前未被选中，它会以高亮显示。

texture []

要应用的纹理名称（默认值 = none）。

grid_color []

设置 UI 网格格线的颜色（默认值 = random）；

消息

jit_gl_texture

把由 texture-name 指定的纹理绑定到该对象。等同于把 texture 特性设为 texture-name。

mesh_matrix

meshwarp 的顶点数据可以用矩阵设置。该矩阵必须是二维的，并有两个通道，分别存放 X 与 Y 顶点坐标。

maskfeatherat

用语法 maskfeatherat index value 设置特定遮罩的羽化量。遮罩索引从 1 开始计数。

maskfeathercurveat

用语法 maskfeathercurveat index value 设置特定遮罩的羽化曲线。遮罩索引从 1 开始计数。

output_mesh_matrix

把 meshwarp 顶点数据以矩阵形式输出。

read

从 JSON 文件（.json）读入 jit.gl.meshwarp 对象的完整当前状态。若未指定文件名，会打开文件对话框让你选择文件。

redo

重做最近一次撤销的 UI 更改。也可以按键盘上的 "ctrl + y/cmd + shift + z" 来调用。

reset

把 jit.gl.meshwarp 重置为默认状态。它会重置 scale、position、rotation 与 color 特性。

reset_mask

删除任何已存在的遮罩。

save

把 jit.gl.meshwarp 对象的完整当前状态保存到 JSON 文件（.json）。若未指定文件名，会打开文件对话框让你选择文件。

scalemaskat

用语法 scalemaskat index value 设置特定遮罩的缩放系数。遮罩索引从 1 开始计数。

undo

撤销最近的 UI 更改。也可以按键盘上的 "ctrl/cmd + z" 来调用。
