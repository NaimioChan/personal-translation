bpatcher

嵌入一个带可见界面的子补丁

描述

bpatcher 对象承载一个补丁或子补丁的内容，只显示落在它的对象框矩形范围内的那些可视元素。bpatcher 对象中间入口和出口的数量，由它内部所含子补丁中的 inlet 和 outlet 对象数量决定。

讨论

bpatcher 对象的入口用于把消息发送给它内部包含的补丁，而不是把消息发送给 bpatcher 对象本身或设置它的特性。设置 bpatcher 对象的特性或给它发送消息，必须通过对 thispatcher 对象发送脚本消息来实现。示例请参见 replace 消息。

参数

无。

特性

args [256 atoms] :

args 特性让你设置传给补丁的参数，这些参数会连同 bpatcher 一起保存在它的父补丁中。参数可以替换被包含补丁中的 #1 - #9，和/或被 patcherargs 对象解析。

bgcolor [4 floats] : 1. 1. 1. 1.

设置 bpatcher 窗口中可见补丁的背景颜色。

bgmode [int] : 0

决定 bpatcher 如何绘制它的背景
可选值：

0 = 'Transparent'（不绘制背景）
1 = 'Patcher Background Color'（用被包含补丁的 bgcolor 绘制背景）
2 = 'Override Background Color'（用 bpatcher 对象的 bgcolor 绘制背景）

border [int] : 0

启用后，border 特性会在对象框的四周绘制一个像素宽的黑色边框

clickthrough [int] : 0

启用后，在 bpatcher 中空白处的点击会被发送给父补丁中位于该 bpatcher 下方的任何对象。打开 clickthrough 只有在 bpatcher 对象的背景是透明的时才有意义。

embed [int] : 0

启用后，embed 会把被包含的补丁保存在它的父补丁中。禁用时（默认），被包含的补丁从 name 特性指定的文件中加载。

enablehscroll [int] : 0

启用一个水平滚动条，用于滚动被包含补丁的内容

enablevscroll [int] : 0

启用一个垂直滚动条，用于滚动被包含补丁的内容

lockeddragscroll [int] : 0

决定你是否能通过按住 shift 和 command 键（Windows 上为 control 键）并拖动来滚动 bpatcher 的内容
可选值：

0 = 'Unlocked Only'（拖动滚动只在父补丁未锁定时有效）
1 = 'Locked and Unlocked'（拖动滚动始终启用）
2 = 'Never'（拖动滚动从不启用）

lockedsize [int] : 0

当 lockedsize 启用时，你无法通过拖动 bpatcher 对象的选框来调整它的矩形大小。不过你可以使用 Inspector 改变大小。

name [symbol] : <none>

指定 bpatcher 要使用的补丁文件的路径名。name 特性只能使用 Inspector 设置。

offset [2 floats] : 0. 0.

消息

(drag)

把补丁文件从 Max File Browser 拖到 bpatcher 对象上时，该文件会被加载。

(mouse)

当包含 bpatcher 对象的窗口被锁定（或按住 Macintosh 上的 Command 键或 Windows 上的 Control 键）并且在 bpatcher 对象的框内点击鼠标时，该手势由框内的补丁处理。
如果在点击 bpatcher 对象时按住 Macintosh 上的 Shift 和 Command 键或 Windows 上的 Shift 和 Control 键，拖动鼠标会移动框内补丁可见部分的左上角。补丁窗口的 Assistance 区域会显示偏移的像素值。如果 bpatcher Inspector 窗口中的 Enable Drag-Scrolling 未勾选，该功能会被禁用。
如果在 bpatcher 对象中点击时按住 Macintosh 上的 Command 和 Option 键或 Windows 上的 Control 和 Alt 键，会弹出一个弹出式菜单，让你在它自己的窗口中打开框内所包含补丁的原始文件，或更换框中当前包含的补丁。

replace

replace 消息的用途是与发往 thispatcher 对象的脚本消息配合使用。如果你通过入口把 replace 消息发送给 bpatcher 对象，只有当 bpatcher 内没有补丁时它才会生效；bpatcher 对象的入口用于把消息发送进它的子补丁，而不是把消息发送给 bpatcher 对象本身。
若要通过脚本消息使用 replace 消息功能，请使用 Inspector 给你的 bpatcher 对象设置脚本名，然后使用消息 script sendbox <bpatcher-name> replace <patcher-name> 把该消息发送给具名的 bpatcher 对象。

参数：

  • filename [symbol]

输出

(User-Defined)

如果 bpatcher 中使用的补丁包含 outlet 对象，它们会按对应的从左到右顺序出现在 bpatcher 对象的框上，成为出口。
