Max

vexpr

对列表求数学表达式的值

描述

使用 C 语言风格的数学运算执行数学计算。处理的输入是列表，而不是单个取值的集合。

讨论

与它的配套对象 expr 一样，vexpr 对象对表达式求值，这些表达式使用 "变量" $i1-$i9（第一个到第九个入口，按整数处理）、$f1-$f9（各入口作为 float）和 $s1-$s9（各入口作为 symbol），和/或使用同类型的常量。vexpr 对象还有一种标量运行模式，可以让你把对象的入口取值当作单条目列表，与输入列表中的所有条目一起求值。

参数

expression [list] 可选

传给 vexpr 对象的参数是一个数学表达式，它由数字、+ 或 * 之类的算术运算符、< 或 > 之类的比较、min () 或 pow () 之类的 C 函数、table 对象的名称，以及为各入口收到的 int、float 和 symbol 而设的可变参数（$i、$f 和 $s）组成。

constant [number] 可选

数字可以在数学表达式中用作常量。

format [symbol] 可选

用于指定与某个入口关联的数据格式的可变参数，由数据类型（$i 或 $f）和入口编号组合而成（例如：$i2）。该参数会被指定入口收到的数字或符号替换。

table [symbol] 可选

指定从表中访问数据的可变参数，用参数 $s 和一个入口编号来描述，该编号会被替换为要访问的 table 的名称。该参数后面应紧跟一个带方括号的数字，用来指定 table 中的地址。（示例：$s2[7] 或 $s3[$i1]。）

(other) [symbol] 可选

vexpr 对象认识下列算术运算符：+、-、*、/、%。其他运算符有 ~（按位取反）、^（按位异或）、&、&&、|、|| 以及 !（非）。

vexpr 能认识许多 C 语言数学函数。函数后面必须紧跟圆括号，括号中包含该函数所需的参数。如果函数要求参数之间用逗号分隔，该逗号前面必须加一个反斜杠（\），以免 Max 被它弄混。例如：(pow ($i1\,2) + $f2)。

vexpr 能认识的 C 语言函数有：abs、min、max、sin、cos、tan、asin、acos、atan、atan2、sinh、cosh、tanh、int（转换为整数）、float（转换为浮点数）、pow、sqrt、fact（阶乘）、exp（e 的 x 次幂）、log10（对数）、ln 或 log（自然对数）以及 random。可以通过把外部代码资源放入 Max 的启动文件夹来添加更多函数。

特性

maxsize [int]

设置 vexpr 对象所有运行模式下列表的最大长度。默认列表长度为 256，列表长度上限为 32,767。

scalarmode [int]

scalarmode 一词后面跟一个非零数字，用于设置标量运算模式。在标量模式下，发送长度为 1 的列表（即单个值）会使该值应用到另一个列表的每个元素上。消息 scalarmode 0 会禁用标量模式。

消息

bang

使用最近收到的数字 / 符号列表对表达式求值，并送出结果。

int

在任意入口收到的 int 或 float 会被当作只有一项的 list。

参数：

  • number [int]

float

在任意入口收到的 int 或 float 会被当作只有一项的 list。

参数：

  • number [float]

list

各个列表的项按从左到右的顺序逐个使用，替换表达式中可变的参数，进行一系列求值。当左入口收到列表时，先使用各列表的第一项对表达式求值，再使用各列表的第二项，依此类推。这些求值得到的一系列结果随后作为一个列表送出。

参数：

  • values [list]

anything

各个列表的项按从左到右的顺序逐个使用，替换表达式中可变的参数，进行一系列求值。当左入口收到列表时，先使用各列表的第一项对表达式求值，再使用各列表的第二项，依此类推。这些求值得到的一系列结果随后作为一个列表送出。

参数：

  • values [list]

输出

float

若某个入口的输入是单个数字而不是列表，且表达式按浮点值求值，则送出的单个结果是一个 float 而不是列表。

int

若某个入口的输入是单个数字而不是列表，且表达式按整数值求值，则送出的单个结果是一个 int 而不是列表。

list

当左入口收到列表时，vexpr 会取它各个不同入口已收到列表的第一项，把这些项放到表达式中可变参数的位置上，对表达式求值。随后它用各列表的第二项做同样的事，依此类推，直到用完最短列表的最后一项。然后它把所有不同的结果作为一个列表送出。
