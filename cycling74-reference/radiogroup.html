Max

radiogroup

单选按钮或复选框

描述

提供用于选项选择的用户界面。有两种工作模式：单选按钮和复选框。

讨论

radiogroup 对象有两种工作模式：单选按钮和复选框。在单选按钮模式下，radiogroup 对象在一个组中提供数量可由用户定义的按钮，同一时间只能选中其中一个。在复选框模式下，radiogroup 对象中的指示器充当一组开/关指示器。复选框模式还支持让复选框充当整数二进制表示形式的位模式指示器（见 flagmode 消息）。

注意：radiogroup 可以横向调整大小，这样它会延伸到放在按钮或复选框右侧的注释框下方。这样一来，点击按钮右侧的文本也会设置按钮选中项或复选框状态。

参数

无。

特性

activecolor [4 floats]

以 RGBA 格式设置活动单选按钮/复选框的颜色。

annotation_name [symbol] :

信息视图标题

bgcolor [4 floats]

以 RGBA 格式设置对象的背景颜色。

elementcolor [4 floats]

以 RGBA 格式设置单选按钮/复选框处于关闭状态时的颜色。该颜色仅在 shape 特性设为 Square (1) 或 Circle (2) 时才适用。

enabled [atom]

启用/禁用按钮。单词 enabled 后面跟后面跟一个由 0 和 1 组成的列表，其长度与按钮或复选框的数量相同，会禁用（0）或启用（1）列表中与按钮或复选框对应位置上的项（例如 enableitem 1 1 1 0 只会禁用第四个按钮或复选框）。

flagmode [int] : 0

设置 radiogroup 对象的标志模式。在该模式下，每个复选框对应一个整数值中的一位（即第一个单选按钮或复选框对应 1 位，第二个按钮或复选框对应 2 位，第三个按钮或复选框对应 4 位，以此类推）。消息 flagmode 0 会禁用该模式（默认）。

inactive [int] : 0

切换整组单选按钮或复选框的激活或非激活状态。

itemtype [atom_long] : 0

0 = 'Radio Buttons'

offset [int] : 16

设置按钮/复选框顶部之间的像素偏移（间距）。最小偏移为 14 像素，默认偏移为 16 像素。

指定当前选中的按钮或复选框。

设置单选按钮/复选框的形状。

size [atom_long] : 2

指定按钮或复选框的数量。默认值为 2，最大值为 64。注意：若你留意在复选框模式下使用 radiogroup 对象并启用了标志模式，你只能设置 32 个复选框。

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

在单选按钮模式下：bang 会输出当前选中的单选按钮编号。

在复选框模式下：bang 会输出一个由 0 和 1 组成的列表，表示各复选框的开/关状态。

在标志模式下：bang 送出与当前勾选的复选框的位模式对应的整数（即若第一、二、三个复选框被勾选，bang 会输出取值 7）送出 radiogroup 对象的输出。

int

在单选按钮模式下：整数会设置单选按钮选中项并输出输入值。编号从 0 开始，负数表示不选中任何按钮。

在标志模式下：radiogroup 对象入口收到的整数值会设置按钮或复选框，以反映该整数值的位模式（即取值 19 会选中第一、二、五个复选框，对应二进制值 10011），并把该整数值从 radiogroup 对象的输出送出。

参数：

  • selection [int]

list

在复选框模式下：由 0 和 1 组成的列表会设置复选框状态，并导致输出输入的列表。若你已指定复选框模式，并用 flagmode 1 消息设置了标志模式，由 0 和 1 组成的列表会设置复选框状态，并导致输出输入的列表。

参数：

  • states [list]

disableitem

在单选按钮和复选框模式下：禁用所指定编号的项（它们会以灰色绘制，不会响应点击，但仍会响应 set 消息、整数或列表）。

参数：

  • indices [list]

enableitem

在单选按钮和复选框模式下：单词 enableitem 后面跟后面跟一个数字或数字列表，会启用所指定编号的项——前提是它们已被 disableitem 消息禁用。

参数：

  • indices [list]

(mouse)

在 radio button 模式下，点击单选按钮会设置单选按钮选中项并输出对应的按钮编号（编号从零开始）。在 check box 模式下，点击复选框会改变其状态（从 1 变 0 或从 0 变 1），并输出一个与各复选框开/关状态对应的 0 和 1 列表。若整组按钮/复选框处于非激活状态（变灰），它不会响应点击。若个别项被禁用（变灰），它不会响应点击，不过该组中处于激活状态的项仍会照常响应点击。Flag Mode 是 check box 模式的一种变体，其中各复选框对应二进制值的位位置（即第一个复选框对应 1 位，第二个对应 2 位，第三个对应 4 位，以此类推）。点击复选框会选中或取消选中该复选框，并输出与位模式对应的整数值。

set

在单选按钮模式下：单词 set 后面跟一个数字，会设置当前选中的单选按钮，不触发任何输出。

在复选框模式下：单词 set 后面跟一个由 0 和 1 组成的列表，会设置复选框状态，不触发任何输出。

若你在使用复选框模式的同时也使用了标志模式，数字会按与该数字位模式对应的模式设置前 32 个复选框的状态，而不触发输出（更多信息见 flagmode 一节）。

参数：

  • selection [list]

输出

int

在单选按钮模式下：点击单选按钮会输出与所选单选按钮对应的 int。编号从 0 开始。

在标志模式下：点击复选框会输出与所勾选复选框表示的位模式对应的 int（即若第一、二、三个复选框被勾选，bang 会输出取值 7）。

list

在复选框模式下：bang 会输出一个 0 和 1 列表，表示整组复选框的开/关状态。
