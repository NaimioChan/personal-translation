MSP

phaseshift~

扭曲信号的相位

描述

phaseshift~ 对象是一个二阶全通滤波器。

讨论

phaseshift~ 对象提供随输入频率变化的非线性延迟时间，仿真模拟移相器效果中出现的相移元件。级联多个 phaseshift~ 对象可以产生更强烈的效果。由于相移本身在多数情况下是听不出来的，通常你会希望把 phaseshift~ 的输出与它的输入信号混合，这样在延迟信号加到原始信号上时就会发生频率抵消。

参数

frequency [number] 可选

相位过渡频带的中心频率

q [number] 可选

相位过渡频带的 Q（带宽）

float

参数：

  • frequency/Q [float]

clear

重置滤波器状态，使内部反馈归零

signal

左入口：将被相移的信号

中间入口：信号将被相移 180 度的频率

右入口："Q" 因子（相位从 0 度过渡到 360 度的陡峭程度）

输出

signal

输入信号，其频率成分或谐波会依据自身的频率以及该对象的 frequency 与 Q 参数的取值，发生从 0 度到 360 度的相移。
