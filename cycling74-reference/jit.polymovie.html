jit.polymovie

管理多个 jit.movie 对象

描述

jit(.gl).polymovie 管理多个 jit.movie 实例，并允许通过预载文件来快速切换文件。矩阵输出请使用 jit.polymovie，纹理输出请使用 jit.gl.polymovie。

参数

drawto [message] 可选

要在其中绘制的具名绘制上下文（默认值 = none）。具名绘制上下文是 jit.world、jit.pworld 或 jit.gl.node 对象的具名实例。若未提供参数，对象会隐式地查找上下文。

特性

autorestart [int]

切换实例播放时启用自动重新开始到循环入点（默认值 = 0）。禁用时，播放会从上次播放的位置继续。

cachemode [int]

（实验性）当 viddll 作为视频引擎时启用自动缓存特性。

cache_sizeauto [float]

（实验性）当 cachemode 启用时设置自动的 cache_size（默认值 = 5）

cache_size [float]

当 viddll 作为视频引擎时，为所有影片实例设置 cache_size（默认值 = 0.5）。

drawto [symbol]

用于纹理输出的具名绘制上下文

target [int]

将接收后续 jit.movie 消息的 polymovie 目标实例。例如 target 2, play 0 会告诉第二个目标播放第一个影片文件。目标由 target 特性动态激活。激活的目标会把它们的影片输出名（纹理或矩阵）加入 polymovie 的输出列表。若激活了 3 个目标，影片输出列表将包含 3 个矩阵或纹理名，例如 jit_gl_texture texname1 texname2 texname3。送出 target 0 会停用除第一个之外的所有目标。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

anything

获取和设置活动影片实例上的 jit.movie 特性。更多信息请参见 play。

appendfolder

载入在 path 处文件夹中找到的所有影片文件，并追加到当前的影片列表。

参数：

  • path [symbol]

appendmovie

把 path 处的影片追加到影片列表末尾。

参数：

  • path [symbol]

clear

移除并释放所有已载入文件的资源。

getdict

从第三个出口输出影片状态字典。该字典包含当前已载入影片文件的完整列表，以及载入后被修改过的任何 jit.movie 特性。另见 readdict 与 writedict。

play

播放 index 处的影片（从 0 开始）。播放某个实例会使它变为活动状态，并成为任何特性或播放消息（例如 start 与 stop）的接收者。

参数：

  • index [int]

readdict

从 path 处的字典读取影片列表内容。若未给出 path，会打开文件对话框。关于 polymovie 字典用法的更多信息请参见 getdict。

参数：

  • path [symbol]

readfolder

载入在 path 处文件夹中找到的所有影片文件，替换当前已载入的影片列表。

参数：

  • path [symbol]

scrub

拖动定位活动影片的播放头。更多信息请参见 play。position 参数的取值在 0（影片开头）与 1（影片结尾）之间。

参数：

  • position [float]

sendmovies

设置所有已载入实例上的 jit.movie 特性。

start

在活动影片实例上开始播放。更多信息请参见 play。

stop

停止活动影片实例上的播放。更多信息请参见 play。

writedict

把影片列表内容写入 path 处的字典。若未给出 path，会打开文件对话框。关于 polymovie 字典用法的更多信息请参见 getdict。

参数：

  • path [symbol]
