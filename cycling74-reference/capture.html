Max

capture

存储数值以便查看或编辑

描述

按收到条目的顺序存储它们，以供查看、编辑和保存。

参数

maximum [int] 可选

第一个参数设置可存储条目的最大数量。若没有参数，capture 最多会存储 512 个条目。一旦超出最大值，每收到一个新条目，最早存储的条目就会被丢弃。

display-format [symbol] 可选

如果第二个参数是 a，所有条目在编辑窗口中都以 ASCII 形式显示。如果第二个参数是 x，所有数字在编辑窗口中都以十六进制形式显示。如果第二个参数是 m，小于 128 的数字以十进制显示，大于 128 的数字以十六进制显示。若没有参数，所有条目都以十进制显示。

特性

listout [int] : 0

启用后，capture 对象会把它的内容作为一个列表倾倒出来。否则该对象每次一个条目地发送它的内容。默认值 = 0。

precision [int] : 4

把浮点数打印到 capture 对象的窗口时使用的浮点精度。默认值 = 4。

size [atom_long] : 512

capture 对象内部缓冲区中可以存储的条目的最大数量。调整大小时，该对象会尝试保留已有的捕获数据。如果当前的捕获位置已经大于新的大小（即缓冲区被缩小时），它会被重置为 0。默认值 = 512。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

int

数字或符号按它们被收到的顺序存储。

参数：

  • input [int]

float

数字或符号按它们被收到的顺序存储。

参数：

  • input [float]

list

列表中的所有数字和/或符号按从第一个到最后一个的顺序存储。

参数：

  • input [list]

anything

所有数字和/或符号按从第一个到最后一个的顺序存储。

参数：

  • input [list]

clear

清除 capture 对象的内容。

count

送出自上次 count 消息以来所收集的条目数量，从 capture 对象的右出口送出。收到 count 消息时，除非 flag 已置位，该对象的内部计数会被重置为 0。

参数：

  • flag [int]

(mouse)

在已锁定的补丁中双击该对象会打开一个窗口，显示内部存储的所有数值。

dump

把 capture 对象的内容每次一个条目地从左出口输出。

open

使与 capture 对象关联的窗口变为可见。该窗口还会被置于最前面。在已锁定的补丁中双击 capture 对象有相同的效果。

wclose

关闭与 capture 对象关联的窗口。

write

单词 write 后跟一个符号，会把 capture 对象的内容保存进一个文本文件，并把该符号用作文件名。

参数：

  • filename [symbol]

输出

int

右出口：响应 count 消息时，从右出口送出自上次收到 count 消息以来所收到的条目数量。

int, float, symbol

左出口：响应 dump 消息时，捕获到的内容每次一个地从左出口送出。

在补丁窗口被锁定时双击 capture 会打开一个编辑窗口，可以在其中查看和编辑已存储的数字。编辑该窗口实际上不会改变 capture 的内容，但对于把数值剪切并粘贴到 table 或一个单独的文件中很有用。（虽然编辑窗口打开期间 capture 可以继续存储条目，但编辑窗口不会更新。必须关闭并重新打开它才能查看新存储的条目。）
