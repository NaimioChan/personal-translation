ubumenu

弹出菜单

描述

把文本显示为弹出菜单。可以手动选择，或设置传入的数字。同时输出选择编号与选择文本。

参数

无。

特性

align [atom] renamed

设置文本对齐模式。对齐模式有：
0 左对齐（默认）
1 居中（1）
2 右对齐（2）

allowdrag [int] : 1 >= 7.0.2

切换是否可以从文件夹拖放内容来填充 umenu 对象（默认值 = 1）。

annotation_name [symbol] :

信息视图标题

applycolors [int] : 0

当 applycolors 打开，且 menumode 设为 "Normal" 时，下拉菜单的背景将使用 bgfillcolor。

arrow [int]

切换是否绘制 umenu 对象上的向下箭头（默认值 = 1）。

autopopulate [int] : 0

切换是否用文件夹内容自动填充 umenu 对象（默认值 = 0）。当它收到有效的文件夹路径作为 prefix 消息的参数时，或者在补丁载入时（如果该对象存储了有效的 prefix），就会进行自动填充。更多信息请参阅 prefix、populate 和 types 消息的说明。

bgfillcolor [4 floats] >= 7.0.0

以 RGBA 格式设置 umenu 对象的背景颜色。

blanksym [symbol] : <none>

文本为空时输出的符号

collection [symbol] : >= 7.0.0

切换是否用 Collections 文件夹的内容自动填充 umenu 对象（默认值 = 1）。当启用 autopopulate 特性时就会进行自动填充。

color [4 floats] >= 7.0.0

以 RGBA 格式设置开关 ON 的颜色。当 menumode 设为 "Toggle" 时，color 特性设置激活状态下的字体颜色。

depth [int] : 0

设置 umenu 对象从有效文件路径填充时使用的文件夹递归深度。

elementcolor [4 floats] >= 7.0.0

以 RGBA 格式设置开关 OFF 的颜色。当 menumode 设为 "Toggle" 时，elementcolor 特性设置非激活状态下的字体颜色。

items [atom]

items 特性只能通过 umenu 对象的 Inspector 访问，它让你可以在对话框中输入想要出现在菜单上的条目。菜单项之间用逗号分隔（例如 red, orange, yellow, green）。

labelclick [int] : 0

打开或关闭 Label Click 模式。在此模式下，当对象处于 Label 模式时，可以在对象矩形内点击，菜单的当前值会从左出口送出。此外，当前条目的文本会以下划线显示。

menumode [int] : 0

设置 umenu 对象的外观与行为。模式有：

0：Normal 模式——普通的弹出式菜单（默认）。
1：Scrolling 模式——可以通过向上或向下拖动鼠标在各个菜单项之间滚动，一次显示一项。
2：Label 模式——显示所选菜单项的文字，其周围没有边框，也不响应鼠标。
3：Toggle 模式——单击模式 3 下的对象会让它在激活状态与非激活状态之间交替。从非激活变为激活时，对象会从最右出口发送消息 toggle 1，并切换到用 color 特性设置的颜色。从激活变为非激活时，对象会从最右出口发送消息 toggle 0，并切换到用 elementcolor 特性设置的颜色。无论是激活还是取消激活，对象还会从中间出口发送它当前的消息，并从左出口发送它当前的项号。
按住 Control 点击可以改变处于 Toggle 模式的 umenu 对象的当前状态。
可选值：

0 = 'Normal'
1 = 'Scrolling'
2 = 'Label'
3 = 'Toggle'

param_connect [symbol] :

在对象与具有参数的兼容对象（如 gen~ 或 jit.gl.slab）的某个参数之间建立双向连接。该对象可用来改变参数的值，参数值变化时它也会随之更新。设置 param_connect 最简便的方法，是使用该特性在 inspector 中的菜单，或使用 Object Action 菜单的 Connect 子菜单。菜单会列出兼容对象的所有可用参数。

用消息设置 param_connect 特性时，需要给出目标参数的路径，即宿主对象的脚本名后跟两个冒号，再加上参数名。例如，对于一个 gen~ 对象，若其脚本名为 gen~_AB，则 freq 参数的路径为 gen~_AB::freq。可以在宿主对象或参数尚不存在时就为 param_connect 设值，该对象会在参数出现后与之建立连接。更多细节请参阅用户指南中 param_connect 条目。

parameter_enable [int]

启用后，该对象可与 Max for Live Parameters 以及 Max 中的初始参数值设置配合使用。

parameter_mappable [int] : 1

启用 parameter_mappable 后，该对象即可通过映射功能映射到键盘或 MIDI 输入。（默认值 = 1）。

pattrmode [int] : 0

设置 umenu 对象向 pattr 对象报告其内部状态所用的方式。若参数为 0（默认），umenu 对象按编号报告其内部状态（例如项列表中的第 3 项）。若参数为 1，umenu 对象按 symbol 报告其内部状态（例如项列表中的 'carrots' 项）。

prefix [symbol] :

设置一个作用于整个菜单的前缀，输出之前它可以被拼接或前置到所有菜单项文字上。若该前缀是一个有效的文件夹路径，就可以用 populate 和 types 消息自动把该文件夹中的文件列表填入 umenu 对象。更多信息请参阅这些消息的条目。发送不带任何参数的 prefix 消息会清除当前存储的前缀。

prefix_mode [int] : 0

设置前缀模式的输出行为。模式有：

0：concatenate 模式；前缀被加到传出消息的最前面，中间不加空格。
1：prepend 模式；前缀作为一个单独的 symbol 加到传出消息列表的最前面。
2：ignore 模式；前缀不用于输出。
可选值：

0 = 'Concatenate'
1 = 'Prepend'
2 = 'Ignore'

showdotfiles [int] : 0

切换是否显示名称以点号（.）开头的文件。默认是关闭。

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

textcolor [4 floats]

以 RGBA 格式设置 umenu 对象的文字颜色。textcolor 特性映射到 textcolor_inverse 样式颜色。

truncate [int] : 1

切换 umenu 对象中文字过长时截断发生的位置。默认值是 1（截断文字右侧的末尾）。值为 2 会让文字以与 textbutton 对象相同的方式从中间截断。
可选值：

0 = 'Truncation full words'
1 = 'Truncate from the right'
2 = 'Truncate from the middle'

types [symbol]

设置供 populate 消息使用的文件类型过滤器。最多可以列表形式输入 64 个文件类型或文件扩展名（以 '.' 开头）。默认情况下不过滤任何文件类型。有效的四字母文件类型代码列表，请参见文件类型指南。

underline [int] : 0

切换 umenu 对象中文字的下划线。默认值是 0（不加下划线）。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

送出当前显示的菜单项。

int

该数字指定要送出的菜单项，并使 umenu 显示该项。菜单项从 0 开始编号。与任何弹出式菜单一样，也可以用鼠标从 umenu 中选择菜单项。

参数：

  • index [int]

float

转换为 int。

参数：

  • index [float]

(drag)

把文件夹从 Max File Browser 拖到 umenu 对象上时，该文件夹的内容会被载入为菜单选项。

把文件夹从 Max File Browser 拖到未锁定补丁窗口的空白处时，会创建一个已载入该文件夹内容的 umenu 对象。

append

append 一词后面跟任意消息，会把该消息追加为菜单中新的最后一项。

参数：

  • message [list]

checkitem

checkitem 一词后面跟一个项号以及 1 或 0，会在该项号旁加上（1）或移除（0）勾选标记。

参数：

  • index [int]
  • checked [int]

clear

移除 umenu 中的所有项。

clearchecks

clearchecks 一词会移除所有项的勾选标记。

count

把 umenu 中的项数从右出口送出，前面带上 count 一词。

delete

delete 一词后面跟一个或多个对应列表中各项的数字，会从 umenu 中删除该项或这些项。

参数：

  • indices [list]

dictionary

dictionary 一词后面跟一个字典名称，会为 umenu 设置菜单项。你也可以把 dict 对象的第一个出口连接到 umenu 的第一个入口。要做到这一点，字典中需要包含一个 "items" 条目。例如，下面的字典条目会用 "hank, carol, andreas, roland" 这些项填入 umenu：

"items" : [ "hank", "carol", "andreas", "roland" ]

参数：

  • dict-name [symbol]

dump >= 8.0.0

输出的是 'dump' 一词、该项的条目编号以及内容。例如：'dump 1 one'。

enableitem

enableitem 一词后面跟一个指定菜单项的数字以及 1 或 0，会启用或停用指定的项号。已停用的菜单项无法选中，但如果在鼠标位于其上方时松开，它们的文字与项号会从最右出口送出，分别带上 disabled_eval 和 disabled_item 这两个 symbol 作为前缀。

参数：

  • index [int]
  • enable [int]

gettoggle

从右出口报告 umenu 对象 Toggle 状态的当前值（1 或 0，表示打开或关闭），前面带上 toggle 一词。

insert

insert 一词后面跟一个数字和一条消息，会把该消息插入到该数字指定的地址处，必要时把所有相等或更大的地址加 1。

参数：

  • index [int]
  • message [list]

mode

遗留消息。请使用 menumode 特性。mode 一词后面跟一个 1-4 范围内的数字，用于设置 umenu 对象的外观与行为。普通的弹出式菜单样式是 1（默认）。Scrolling 模式（2）可以向上或向下拖动鼠标在各个菜单项之间滚动，一次显示一项。Label 模式（3）显示所选菜单项的文字，其周围没有边框，也不响应鼠标。Toggle 模式（4）设置按钮样式。单击模式 3 下的对象会让它在激活状态与非激活状态之间交替。从非激活变为激活时，对象会从最右出口发送消息 toggle 1。从激活变为非激活时，对象会从最右出口发送消息 toggle 0，并切换到用 bgcolor 特性设置的颜色。无论是激活还是取消激活，对象还会从中间出口发送它当前的消息，并从左出口发送它当前的项号。

参数：

  • display [int]

(mouse)

用鼠标点击可以选择要送出的菜单项，并使 umenu 显示该项。

next

选择下一个菜单项，并使 umenu 对象显示该项。这条消息会忽略已停用的菜单项或分隔符菜单项。

populate

若 umenu 对象有一个有效的文件夹路径作为它的 prefix，populate 消息会令菜单根据指定路径的当前内容（并由 types 列表过滤）重新填充它的 items 列表。填充完成后，添加到 umenu 对象的项数会从右出口输出，前面带上 populate 一词。

prev

选择上一个菜单项，并使 umenu 对象显示该项。这条消息会忽略已停用的菜单项或分隔符菜单项。

set

set 一词后面跟一个数字或 symbol，会指定一个由 umenu 显示的菜单项，但不把它从出口送出。若 set 的参数是一个 symbol，set 会搜索以该 symbol 开头的菜单项。

参数：

  • item [list]

setcheck

（仅 Macintosh）setcheck 一词后面跟一个指定某个 UTF-8 字符十进制表示的数字（例如 8226 表示项目符号，62 表示大于号），用于设置所要用作勾选标记的字符。不带参数的 setcheck 一词指定默认的平方根复选框。

参数：

  • character [int]

setitem

setitem 一词后面跟一个项号和任意消息，会把指定的菜单项设置为该消息。

参数：

  • index [int]
  • message [list]

setrgb

setrgb 一词后面跟六个 0 到 255 之间、用于指定 RGB 值的数字，会用前三个数字设置前景（文字）颜色，用后三个数字设置背景（填充）颜色。

参数：

  • fore-red [int]
  • fore-green [int]
  • fore-blue [int]
  • back-red [int]
  • back-green [int]
  • back-blue [int]

setsymbol

setsymbol 一词后面跟一条消息，会按名称指定一个要显示的菜单项，且不触发任何输出。

参数：

  • menu item [symbol]

settoggle

settoggle 一词后面跟一个 1 或 0，若 umenu 对象处于 Toggle 模式，就把它的状态设为指定状态，并像对象被点击过一样执行输出（symbol toggle 后面跟一个 0 或 1，表示 Toggle 状态）。不带参数时，这条消息只是切换对象的状态并触发输出。

参数：

  • state [int]

showchecked

这条消息的工作方式如下。若当前显示的项带有勾选标记，则什么都不做。否则，从菜单中的第一项开始，找出一个带有勾选标记的项，并把菜单设为显示该项。若不存在这样的项，则什么都不做。

symbol

与带 symbol 参数的 set 消息完全相同，只是会送出找到的项号（并且，若启用了 Evaluate Item Text 功能，该项的文字会从右出口送出）。

参数：

  • item [symbol]

toggle

toggle 一词后面跟一个 1 或 0，若 umenu 对象处于 Toggle 模式，就把它的状态设为指定状态，并像对象被点击过一样执行输出（symbol toggle 后面跟一个 0 或 1，表示 Toggle 状态）。不带参数时，这条消息只是切换对象的状态并触发输出。

参数：

  • state [int]

输出

anything

中间出口：所选菜单项的文字作为消息送出。

右出口：count、gettoggle 和 populate 消息会使状态消息从右出口送出。

int

左出口：所选菜单项的编号会被送出。菜单项从 0 开始编号。

连接

preset

把 umenu 的左出口连接到 preset 对象的入口，会建立起双向连接，其中 umenu 显示当前的预设集，并作为按编号和/或名称选择预设的前端。
