Max

bline

用 bang 生成斜坡

描述

生成一段由传入的 bang 消息驱动的线性斜坡。它接受一组断点分段（以及要跨越的事件数），并在各个值之间输出平滑的斜坡。

讨论

bline 与 Max 的 line 对象类似，不同之处在于它由发往其左入口的 bang 消息驱动。这使该对象拥有灵活的时间基准，在处理处理时间可变的事件（例如在 Jitter 中渲染矩阵）时很有用。它既能处理整数也能处理浮点数，可以被停止（用 stop 消息），也可以使用多分段列表（类似 MSP 的 line~ 对象）。

参数

initial-value [number] 可选

可选。可以用一个参数来设置对象要存储的初始值以及输出类型——若第一个参数是 int，bline 对象输出整数值；若第一个参数是 float，则会让 bline 对象输出浮点值。若没有给出参数，初始值为 0，输出类型为 int。

消息

bang

把断点列表中的新一步从左出口送出。若当前的斜坡分段列表已经结束，bang 消息会从右出口送出

int

把 bline 对象设为指定的整数值。所有未完成的断点分段都会被遗忘（即时间被视为 0，bline 在收到 bang 时输出目标值）。

参数：

  • input [int]

float

把 bline 对象设为指定的浮点值。所有未完成的断点分段都会被遗忘（即时间被视为 0，bline 在收到 bang 时输出目标值）。

参数：

  • input [float]

list

bline 对象使用由数字对组成的数据列表来设置断点分段的取值。每一对中的第一个数字可以是 int 或 float，用来指定目标值；后面跟一个整数，指定在到达目标值之前必须收到多少个 bang 消息——注意这与其他 Max 断点对象（如 line）不同，后者指定的是以毫秒为单位的目标时间值。

参数：

  • segment-pairs [list]

set

把 bline 对象设为指定的值。所有未完成的断点分段都会被遗忘（即时间被视为 0，bline 在收到 bang 时输出目标值）。

参数：

  • input [number]

stop

让 bline 停止送出数字，直到收到新的斜坡分段列表。

输出

bang

右出口：当 bline 到达其目标值时，会送出 bang。

int

左出口：数字会响应收到的 bang 消息而送出，描述一条朝目标值前进的直线。若在这条线完成之前又指定了断点分段列表，新线会从最近一次的输出值开始，以避免不连续。

若左入口收到的值没有附带时间值，它会立即被送出。
