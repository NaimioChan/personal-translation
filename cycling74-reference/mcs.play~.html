mcs.play~

基于位置的采样播放（多通道 I/O）

描述

用 play~ 对象作为 buffer~ 的播放接口，它根据缓冲区内的偏移量播放采样。它通常与 line~ 对象配合使用，但也可以与任何能产生以毫秒为单位变化的位置取值的信号配合使用。groove~ 对象提供了另一种播放采样的方案。
当 play~ 对象被创建为 mcs.play~ 时，它所有的信号出口会合并成一个多通道出口。mcs.play~ 的行为在其他方面与 play~ 相同。

参数

buffer-name [symbol] 可选

第一个参数指定 buffer~ 对象的名称，play~ 会用它的采样内存进行播放。

number-of-output-channels [int] 可选

指定输出通道数。默认的通道数是一。若正在播放的 buffer~ 通道数少于 play~ 的输出通道数，多出的通道会输出零信号。若 buffer~ 的通道数更多，各通道会被混合。

特性

interptime [float]

设置循环插值所用的交叉淡化时间。若给定的取值大于循环的总时长，则使用循环的总时长。默认的交叉淡化时长是 50 毫秒。

loop [int]

在循环模式下，当播放到达结束时间（参见 start 消息）时，它会从起始时间重新继续。循环模式默认关闭。

loopinterp [int]

启用围绕循环起点和终点的插值。默认情况下，循环插值处于关闭状态。

消息

int

左入口：1（或非零取值）开始播放当前所设置的 buffer~ 对象，0 停止播放。

参数：

  • start/stop-playback [int]

(mouse)

在 buffer~ 上双击会打开一个显示窗口，你可以在其中查看 buffer~ 对象的内容，也就是 play~ 对象所引用的那个对象。

pause

左入口：发送消息 pause 会让播放在当前播放位置暂停。可以用 resume 消息重新开始播放。

resume

左入口：若播放曾被暂停，则从音频缓冲区中暂停处继续播放。

set

单词 set 后跟一个 buffer~ 对象的名称，会用该 buffer~ 进行播放。

参数：

  • buffer-name [symbol]

signal

左入口：在 buffer~ 对象的采样内存中，从哪个位置开始播放（单位为毫秒）。若该信号随时间递增，play~ 会正向播放采样点。若递减，play~ 会反向播放采样点。若保持不变，play~ 会反复输出同一个采样点，这相当于采样值的一个直流偏移。

play~ 对象播放的方向与速度，可以通过以信号速率提供给 play~ 对象的整数消息来设置。通常用 line~ 对象完成这一点。

整数消息成对出现——第一个整数指定缓冲区中开始的位置（单位为毫秒），随后的一对数字指定缓冲区中的结束位置以及进行播放的时间（单位为毫秒）。这些消息常以用逗号分隔的消息形式发送。以下是一些例子：

0, 2000 2000- 从缓冲区开头开始，以正常速度播放 2 秒音频
500, 0 500- 以正常速度反向播放缓冲区的前半秒。
0, 1000 500- 以双倍速度播放缓冲区的前一秒（即向上移调一个八度）

start

左入口：单词 start 后跟一个以毫秒为单位的起始时间，会移动到当前 buffer~ 中的指定位置并开始播放。在起始时间之后，可以指定一个可选的结束时间，它会设定播放停止的位置。还可以提供第三个可选值，用来设置从起点到终点的播放时长。不带参数使用时，start 会从 buffer~ 的开头开始，播放到末尾（等价于用整数值 1 开始播放）。起始时间可以大于结束时间，以便反向播放缓冲区中的一段。

参数：

  • start-time [list]
  • end-time [list]
  • duration [list]

stop

左入口：stop 消息会让播放在当前播放位置停止。（这等价于发送整数值 0 来停止播放）。

输出

signal

从 buffer~ 读出的采样输出。若 play~ 有两个或四个输出通道，左出口的信号包含采样的左通道，其他出口的信号则包含来自其余通道的采样。
