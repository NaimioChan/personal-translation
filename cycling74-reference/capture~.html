MSP

capture~

存储信号以便以文本形式查看

描述

使用 capture 对象收集信号取值，以便调试或考察信号。若要录制信号取值，请使用 record~ 或 sfrecord~ 对象。

参数

behavioral-flag (f) [symbol] 可选

若第一个参数是字母 f，capture~ 会存储它最先收到的那些信号采样点，之后一旦其存储缓冲区满，就忽略后续采样点。若没有字母 f，capture~ 会存储它最近收到的信号采样点，必要时丢弃更早的采样点。

maximum-samples [int] 可选

限制 capture~ 能容纳的采样点数量（也就是摘录段的长度）。若没有键入数字，capture~ 会存储 4096 个采样点。可能的最大采样点数只受 Max 应用程序可用内存量的限制。还可以键入第二个数字参数来设置显示精度（小数点右侧的位数），采样点在编辑窗口中将按该精度显示。设为 mc 模式（mc.capture~）时，maximum-samples 取值会应用于每个通道。捕获到的取值按通道号顺序显示。

signal-vector-indices (up to 10 ints) [list] 可选

最多 10 个索引组成的列表，索引位于一个信号向量之内。若没有给出索引，capture~ 会记录整个向量。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'

'30'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

clear

擦除 capture~ 的内容。

(mouse)

双击 capture~ 会打开一个窗口来查看和编辑其内容。编辑窗口中的数字可以复制并粘贴到图形 buffer~ 编辑窗口。

open

让 capture~ 对象的编辑与查看窗口变为可见。该窗口同时会被带到最前面。

signal

信号的一段摘录会以文本形式存储，用于查看、编辑或保存到文件。（摘录段的长度可以作为键入型参数指定给该对象。）

wclose

关闭与 capture~ 对象关联的窗口。

write

把 capture~ 的内容保存到文本文件。会打开一个标准文件对话框来给文件命名。单词 write 后面跟一个符号，会以该符号作为文件名把文件保存到与包含 capture~ 的补丁相同的文件夹中。若该补丁尚未保存，capture~ 文件会保存在与 Max 应用程序相同的文件夹中。

参数：

  • filename [symbol]

输出

(text)

capture~ 不输出任何内容，也没有出口，但它捕获为文本的信号可以保存到文件，或复制粘贴到别处进行编辑。
