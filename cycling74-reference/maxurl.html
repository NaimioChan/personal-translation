Max

maxurl

发出 HTTP 请求

描述

maxurl 是 libcurl 的封装，可以发出 HTTP 请求。用它来抓取和提交网页内容。关于 curl 的更多信息，请参阅 Curl Docs Page. 要了解并练习 HTTP 请求，可以看看 httpbin.org.

参数

thread count [int] 可选

如果你希望 maxurl 按顺序发出 HTTP 请求，就把线程数设为 1。如果你想同时发出多个请求，就把线程数设为大于 1 的值。这样 maxurl 就能并发执行这么多请求。如果你以 3 个线程启动 maxurl 并让它发出 5 个请求，3 个请求会立即开始，另外 2 个会排队，等最初 3 个请求中任意一个完成后就开始。

消息

abort

不带任何参数的 abort 消息会中止此 maxurl 正在执行的所有运行中的请求。也可以选择给出一组响应字典名，只中止那些请求。要做到后者，你需要在发请求时指定一个响应字典名。请参阅下面 dictionary 消息的 "response_dict" 字段。

参数：

  • response dictionary name [list]

abortall

中止所有运行中的请求和已排队的请求。

delete

向指定的 URL 发送一条 HTTP DELETE 请求。

参数：

  • url [list]

dictionary

用于发出更高级 HTTP 请求的字典输入。

key namevalue
response_dict（string）设置响应字典名
url（string）设置 maxurl 应向其发出请求的 url。（例如 "http://cycling74.com" ）
http_method（string）四个选项之一："get"、"post"、"put" 或 "delete"
post_data（string）一个 url 编码的字符串，其中包含你的 post 变量（例如 "key1=val1&key2=val2"）（dictionary）如果 post_data 是另一个字典，maxurl 会把这个字典编码为 json 数据放入 post body 中。
filename_out（string）输出文件的完整路径名。如果设置该项，响应字典的 "body" 键会为空。
filename_in（string）输入文件的完整路径名。如果设置该项，且 http_method 为 "put" 或 "post"，maxurl 会把这个文件读作 http 请求的 body。用它或 'multiput_form' 字段把文件上传到服务器。
useragent（string）你的请求所用的 user agent 名。用它来伪装成其他浏览器。默认情况下 maxurl 在 windows 上把自己声明为 Firefox。
timeout（number）以秒为单位设置超时时长。注意！如果耗时超过所设超时时长，运行中的连接会被终止。
connect_timeout（number）以秒为单位设置连接到远程主机的超时时长。
parse_type（string）"none"、"json" 或 "xml" 三者之一。默认值为 "none"。如果设为 "json" 或 "xml"，maxurl 会相应尝试从 json 或 xml 数据把响应数据解析为字典。
headers（字符串数组）直接设置请求头（例如 ["Content-Type=text/plain; charset=UTF-8", "Server=httpbin"]）。
cookie（string）cookie 会被接受，并在同一个 maxurl 对象的各个请求之间共享。不过，你也可以在这里用类似 'name1=value1;name2=value2;' 的内容直接设置请求的 cookie。
http_auth（string）设置要随请求发送的 http 认证信息，格式为 "username:password"。默认情况下，maxurl 会尝试所有认证方法（basic、digest、gss negotiate、ntlm）
multipart_form（由字典组成的数组，或单个字典，或多个字典）各个部分应有 2-3 个键："name"、"file"、"content" 或 "contenttype"。例如：[ {"name":"file-0", "file": "/full/path/to/filename.jpg"}, {"name": "file-1", "file": "/full/path/to/filename2.jpg"}, {"name": "filecount", "content": "2" } ] OR: { "part1" : {"name":"myfirstfile", "file": "/full/path/to/filename.jpg"}, "part2" : {"name": "anotherfile", "file": "/full/path/to/filename2.jpg"}, "part3" : {"name": "filecount", "content": "2" } }
overwrite_response_dict（long）0 或 1。如果设为 1（默认值），maxurl 允许你发出多个请求，让数据返回到同一个响应字典中。如果设为 0，当已存在使用同一响应字典的运行中或已排队请求时，maxurl 不会允许你把请求排队。
overwrite_output_file（long）0 或 1。默认情况下该项设为 0，maxurl 不会覆盖输出文件。如果设为 1，你可以强制 maxurl 覆盖输出文件。如果存在正在把数据写入该文件名的运行中请求，该请求会被中止。
proxy（string）设置代理服务器。
proxy_type（string）http（默认值）、socks4、socks4a 或 socks5
proxy_auth（string）如果你的代理需要密码，把该项设为 "username:password"

参数：

  • name [symbol]

向指定的 URL 发送一条 HTTP PUT 请求。url 后面跟随的任何符号对都会以 url 编码形式作为键值对发送。

参数：

  • url [list]

verbosity >= 7.0.0

决定 maxurl 对象把关于其处理过程的信息发布到 Max 控制台的详细程度。详细程度范围为 0 - 6，其中 0 禁用所有控制台报告，1 是默认值、也是最基本的详细级别，6 则最为详尽。
