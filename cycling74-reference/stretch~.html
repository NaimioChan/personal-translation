MSP

stretch~

基于 Ztx 的音频缓冲区音高/时间修改

描述

使用 stretch~ 对象对 buffer~ 对象的内容进行破坏性音高与时间修改。

参数

buffer-name [symbol] 可选

指定保存破坏性音高/时间修改结果的缓冲区名称。

特性

basictuning [int] : 440

为音高校正操作设置以 A 音的频率为基准的调律标准（440 = 默认值，范围为 400 - 500）

followglobaltempo [int] : 0

启用 followgobaltempo 后，stretch~ 会根据 originaltempo 与当前全局速度之间的比值算出当前速度。

formant [float] : 1.

单词 formant 后跟一个浮点值，设置进行音高移动时共振峰缩放的程度。

formantcorrection [int] : 0

单词 formantcorrection 后面跟一个 0 或 1，在执行音高校正时停用/启用共振峰校正。

mode [symbol]

设置要使用的 timestretching 模式。每种模式都为处理不同种类的音频素材做了优化

可选值：

'basic'（默认工作模式）
这是默认的工作模式。

'monophonic'（单声源（人声、长笛））
该模式最适合单声部乐器（例如独唱人声、长笛等）

'rhythmic'（优化瞬态保留）
该模式用于时间拉伸的打击乐。它能提供最佳的瞬态保留。

'general'（在频谱完整性与瞬态保留之间取得平衡）
该模式在一般情况下平衡频谱完整性与瞬态保留。

'polyphonic'（多声源（钢琴、吉他））
对于钢琴或吉他这类乐器，多声部模式是更好的选择。

'pads'（强调频谱质量而非瞬态保留）
该模式强调频谱质量而非瞬态保留。

'extremestretch'（用于大于 2.0 的拉伸比率）
该模式用于大于 2.0 的拉伸比率，意图是获得更艺术化的效果。

'efficient'（良好的 CPU 性能）
该模式旨在在 CPU 性能与质量之间取得良好的权衡。

originallength [Time Value] : 0 ticks

音频文件以拍为单位的原始长度。followglobaltempo 用它来相对于全局走带速度计算速度。设置 originallength 会计算出 originaltempo。

originaltempo [float] : 120.

音频文件的原始速度。followglobaltempo 用它来相对于全局走带速度计算速度。设置 originaltempo 会计算出 originallength。

pitchcorrection [int] : 0

单词 pitchcorrection 后面跟一个 0 或 1，启用/停用共振峰校正的半音音准校正。若需要更全面的实时音准校正，请使用 retune~ 对象。

pitchshift [float] : 1.

以原始音高的倍数来指定 pitchshift（即 2.0 = 音高翻倍，.5 = 原始音高减半，等等）。

pitchshiftcent [int] : 0

以正的或负的音分值来指定 pitchshift（即 100 = 升高一个半音，-1200 = 降低一个八度）。音分值可以用 int 或 float 指定。

progress_enable [int] : 1

计算音高/时间移动时启用/禁用进度条显示。

quality [symbol] : better

选择 timestretching 输出的质量。

可选值：

'basic'
'good'
'better'
'best'

readagain [int] : 1

进行音高或 timestretching 处理时，处理来自原始缓冲区而不是当前缓冲区的音频

slurtime [float] : 0.

设置校正达到完全校正量所需的时间。通常，音符在起始处会有些不稳定，因为声音的起音阶段噪声较多，也因为歌手在音符起音之后会逐渐调整自己的音准。滑音时间使音高校正听起来自然，因为它模拟了这种效果。取值越大，适应时间越慢，校正要产生校正后的音高所需的时间也越长。不过，较长的滑音时间也能更好地保留颤音。

stretch [float] : 1.

把 timestretching 设为一个相对于当前缓冲区长度的系数（例如 2.0 = 长度加倍，.5 = 长度减半，等等）。

消息

bang

bang 消息开始处理，以修改当前所引用缓冲区的内容。

apply

与 bang 相同

cancel

取消当前正在运行的操作。

(mouse)

双击 stretch~ 会打开一个显示窗口，你可以在其中查看自己所做音高/时间修改的结果。修改完成后，显示窗口的内容就会更新。

dictionary

你可以用字典定义更复杂的拉伸与音高移动。你定义一个时间点（sourcetime、sourcetimesample 或 sourcetimebbu），并定义这个点应被变换到的位置（desttime、desttimesample 或 desttimebbu）。例如下面这个字典会

  • 创建 marker01，它会拉伸文件，使 500 ms 处的音频落在第一小节上，并把音频向下移调 100 音分，直到下一个标记
  • 创建 marker02，它会进行拉伸，使 1000 ms 处的素材位于 1.2.0 bbu 上，并把音频以 1.1 的倍数向上移调，直到下一个标记
  • 创建 marker03，它会把整段采样（“end”）拉伸为两倍长
					{ "marker01" : { "sourcetime" : "500", "desttimebbu" : "1.0.0", "pitchshiftcent" : -100 } , "marker02" : { "sourcetime" : 1000, "desttime" : 1.2.0, "pitchshift" : 1.1 } , "marker03" : { "sourcetime" : “end”, "desttime" : “*2”, } }

参数：

  • dictionary-name [symbol]

set

单词 set 后跟一个音频缓冲区的名称，设置 stretch~ 对象所引用的音频缓冲区的名称。

参数：

  • buffer-name [symbol]
