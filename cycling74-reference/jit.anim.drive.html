jit.anim.drive

为 3D 变换添加动画

描述

随时间以缓动方式为相对变换添加动画。jit.anim.drive 对象与 jit.anim.node 以及 OpenGL 对象配合来完成该功能。双击该对象会打开一个 ui 映射字典，从而可以把某些用户界面操作映射到动画消息。

讨论

通过编辑 ui-map 字典来实现按键与鼠标输入的 UI 映射。按键输入映射到字母数字键和箭头键（用 up、down、left 和 right 表示，而不是键符号）。鼠标映射会查找下列字典条目：
水平方向：mouse_horizontal, mouse_h, mouse_x
按下按键时的水平方向：mouse_down_horizontal, mouse_down_h, mouse_down_x
垂直方向：mouse_vertical, mouse_v, mouse_y
按下按键时的垂直方向：mouse_down_vertical, mouse_down_v, mouse_down_y
UI 输入可以映射到 move、turn 和 grow 消息。

特性

active [int] 只读

指示对象当前是否正在播放动画。

automatic [int]

启用自动更新消息（默认值 = 1）。要求 targetname 对象属于一个有效的 OpenGL 上下文。

drawto [symbol]

指派给具名绘制上下文，从而可以自动收到更新。

ease [float]

同时设置 easein 和 easeout 两个特性（默认值 = 1.）。

easefunc [symbol]

决定缓动的应用方式（默认值 = linear）。
可选值：

'linear'
'quadratic'
'cubic'

easein [float]

决定某条动画消息从当前取值变为新取值需要多长时间（以秒为单位）（默认值 = 1.）。该特性只影响 move、turn 和 grow 三种动画。

easeout [float]

决定某条动画消息从当前取值变为 0 需要多长时间（以秒为单位）（默认值 = 1.）。该特性只影响 move、turn 和 grow 三种动画。

evalreport [int]

启用/禁用把求值参数的报告从 dumpout 送出（默认值 = 0）。该报告是一个 3 元素列表，其中各个元素依次表示 moveto、rotateto 和 scaleto 消息当前的求值参数。

fixed_delta [float] >= 9.0.0

锁定动画时所用的 delta time 取值，以秒为单位（默认值 = 0）。非零时，更新会用该取值来计算，而不是用帧之间的实际时间。用于非实时帧捕获很有用。若非零，会覆盖所绑定的 jit.world 的 fixed_delta 取值。

name [symbol]

指定实例的名称（默认值 = UID）。

position [3 floats]

3D 空间中当前存储的位置。该特性用于 moveto 和 springto 消息（默认值 = 0 0 0）。

quat [4 floats]

3D 空间中当前的朝向，以四元数取值存储。该特性用于 rotateto 消息（默认值 = 0 0 0 1）。

scale [3 floats]

3D 空间中当前存储的缩放。该特性用于 scaleto 消息（默认值 = 1 1 1）。

speed [float]

动画的速度（单位/秒）。（默认值 = 30.）

spring_damp [float]

施加到 springto 消息所用弹簧方程的阻尼量（默认值 = 0.1）。

spring_mass [float]

施加到 springto 消息所用弹簧方程的质量（默认值 = 1.）。

spring_stiff [float]

施加到 springto 消息所用弹簧方程的刚度（默认值 = 0.2）。

spring_thresh [float]

用于判断弹簧模拟何时不再活动的阈值。用于 springto 消息（默认值 = 0.0001）。

ui_dict_layout [symbol]

ui_listen 启用时，设置默认 ui 映射字典所用的键盘布局。该取值存储在应用程序首选项中，会影响以后所有实例化的 jit.anim.drive。若要覆盖默认 ui 映射，请参阅 ui_map 和 ui_map_clone 特性。
可选值：

'azerty'
'qwerty'
'qwertz'
'qzerty'
'azerty_v2'（包含绕 Z 轴的键盘转向）
'qwerty_v2'（包含绕 Z 轴的键盘转向）

targetname [symbol]

目标对象的名称，该对象应当是 OpenGL 对象或 jit.anim.node 对象。

ui_listen [int]

让 UI 鼠标与键盘消息从上下文窗口接收（默认值 = 0）。要求 targetname 对象属于一个有效的 OpenGL 上下文。

ui_map [symbol]

要克隆为 UI 映射字典的已注册字典名。自 Max 9.0.5 起，该特性的作用与 ui_map_clone 完全相同。

ui_map_clone [symbol]

要克隆为 UI 映射字典的已注册字典名。演示参见 anim.drive.ui.dict 示例补丁。

ui_priority [int]

UI 优先级取值（默认值 = 900）。当多个 UI 对象监听同一窗口时，ui_priority 决定各对象接收输入的顺序。取值较小的先测试。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

若当前正在播放动画，则把动画消息输出。

anim_reset

禁用所有动画

(mouse)

鼠标事件

dictionary

把传入的字典克隆后用于设置 ui 映射。

参数：

  • name [symbol]

grow

按给定的量沿各轴缩放所挂接的对象。各轴参数会乘以 speed。

参数：

  • x [float]
  • y [float]
  • z [float]

move

按所给的轴移动所挂接的对象，移动相对于该对象的 movemode 特性所指示的空间。各轴参数会乘以 speed。

参数：

  • x [float]
  • y [float]
  • z [float]

moveto

在指定的时长（秒）内把所挂接的对象移动到指定位置。移动会根据 easefunc 特性施加缓入缓出。

参数：

  • x [float]
  • y [float]
  • z [float]
  • duration [float]

rotateto

在指定的时长（秒）内把所挂接的对象旋转到指定的四元数朝向。旋转会根据 easefunc 特性施加缓入缓出。

参数：

  • x [float]
  • y [float]
  • z [float]
  • w [float]
  • duration [float]

scaleto

在指定的时长（秒）内把所挂接的对象缩放到指定的缩放取值。缩放会根据 easefunc 特性施加缓入缓出。

参数：

  • x [float]
  • y [float]
  • z [float]
  • duration [float]

springto

用质量-弹簧模拟把所挂接的对象移动到指定位置。

参数：

  • x [float]
  • y [float]
  • z [float]

turn

按给定的量沿各轴旋转所挂接的对象。各轴参数会乘以 speed。

参数：

  • x [float]
  • y [float]
  • z [float]

ui_dict

参见 dictionary 列表

ui_key

发送指定的按键。若该按键在 ui 映射字典中，就会启用对应的动画。

参数：

  • key [symbol]

ui_keyup

发送指定的 keyup。若该按键在 ui 映射字典中，就会禁用对应的动画。

参数：

  • key [symbol]

ui_mouse

发送鼠标事件。若该事件在 ui 映射字典中，就会启用对应的动画。

参数：

  • screen-x [int]
  • screen-y [int]
  • mouse-down [int]

update_drive

参见 bang 条目
