Max for Live

live.push

Push 2 与 3 的配置

描述

live.push 允许 Max for Live 设备覆盖所连接 Push 乐器的设置。只有当包含 live.push 的 Max for Live 设备被选中，或该设备是设备链中的第一个时，Push 的设置才会被覆盖。这一行为可通过 play_usage 特性配置。

参数

无。

特性

play_flat_zone [int]

音准正确的打击垫宽度（mm），-1 表示使用 Push 上设定的取值。仅对带表情打击垫的 Push 有效。

play_in_tune_location [symbol]

当 In Tune Location 设为 Finger 时，你最初按下手指的位置弯音为零。例如，若你把手指放在打击垫的右侧，音高会保持准，直到你水平滑动手指才开始弯音。当 In Tune Location 设为 Pad 时，手指按在打击垫上的位置决定初始弯音，垫中心处弯音为零。仅对带表情打击垫的 Push 有效，且该 Push 的 Expression Mode 设为 MPE。
可选值：

'default' ( 使用 Push 上设定的取值 )
'finger' ( 演奏者最初把手指放在打击垫上的位置 )
该设置意味着无论手指接触哪里，音符初始都是准的。

'pad' ( 打击垫的中部 )
该设置意味着音符触发时可能音不准（配合 MPE 弯音）。

play_note_colors [128 symbols]

一个最多含 128 个 symbol 的列表，若 play_pad_map 为 serial，这些 symbol 会用作每个 MIDI 音符的颜色。第一个颜色用于 MIDI 音符 0，第二个用于 MIDI 音符 1，依此类推。若 symbol 少于 128 个，给定的这些 symbol 会重复。需要注意的是，MIDI 音符在矩阵打击垫上的位置会随用户选择的布局以及 Push 上的八度升、降按钮而变化，因此所分配的颜色不一定对应某个特定的打击垫。
有三个 symbol 具有特殊含义：

  • scale_base_note - 使用 Push 通常用于音阶基音的颜色，目前是该轨道的颜色
  • scale_note - 使用 Push 通常用于音阶内非基音音符的颜色，目前是白色
  • non_scale_note - 使用 Push 通常用于不在音阶内的音符的颜色，目前是黑色（熄灭）

其余可能的 symbol 都是具体的颜色：orange_one、orange_one_shade、orange_one_shade_two、brown_two、brown_two_shade、brown_two_shade_two、yellow_highlight、purple、ocean、deep_ocean、sky、green_green、green_green_shade、red_red、red_red_shade、red_red_shade_two、blue_blue、light_grey、dark_grey、black、white

play_pad_map [symbol]

控制 MIDI 音符如何分配到各个打击垫上。在 scale 与 serial 两种模式下，用户都可以用 Push Layout 按钮循环切换布局，从而快速访问宏变体与音符音序。
可选值：

'scale' ( 打击垫音符遵循音阶 )
映射到打击垫的 MIDI 音符以及打击垫的颜色都遵循所选音阶、调律系统和调内或半音模式。

'serial' ( 打击垫音符忽略音阶 )
所有 MIDI 音符都按顺序显示，不参考所选音阶或调律系统。使用 play_note_colors 提供的颜色。

play_slide_height [int]

带滑动表情的打击垫高度（mm），-1 表示使用 Push 上设定的取值，小于 10mm 的取值向上取整为 10mm。仅对带表情打击垫的 Push 有效。

play_usage [symbol]

何时使用以 play_ 开头的那些特性的取值来覆盖 Push，同时考虑到可能使用 live.push 的其他设备。
可选值：

'never'（从不覆盖 Push 行为）
从不覆盖 Push 行为。

'first_or_selected'（若设备位于链中首位或设备被选中则覆盖 Push）
若该设备是设备链中第一个想要覆盖 Push 行为的设备，或者该设备被选中，则激活自定义设置。

'first'（若设备位于链中首位则覆盖 Push）
若该设备是设备链中第一个想要覆盖 Push 行为的设备，则激活自定义设置。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。
