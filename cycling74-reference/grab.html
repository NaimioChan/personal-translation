Max

grab

截取另一个对象的输出

描述

grab 可以发送消息并从接收对象中取出结果。
注意： grab 对象不能用于在 Live 集成设备之间从 send 到 receive 通信。

参数

number-of-outlets [int] 可选

第一个参数设置除右出口之外的出口数量。若没有参数，grab 有 1 个额外出口。

receive-name [symbol] 可选

若第二个参数是 symbol，入口收到的消息会发给该 symbol 命名的所有 receive 对象，而不是从右出口送出。这种情况下，原本在没有第二个参数时会送出传入消息的最右出口将不存在。

若已在 grab 中输入第二个参数，指定某个 receive 对象的名称，那么单词 set 后面跟一个 symbol，会指定另一个（不同的）receive 对象的名称，grab 可以经由它从远端对象抓取消息。

参数：

  • input [symbol]

输出

anything

右出口：右出口只应连接到其他对象最左侧的入口。入口收到的消息会送往所有连接到右出口的对象的左入口。不过这些对象从其出口送出的内容会被 grab 截取。

其他出口：原本会从连接到右出口的那些对象的出口送出的内容，会改为在收到 grab 的消息时从 grab 对象的出口送出。原本会从其他对象最左出口送出的内容，会从 grab 最左出口送出，依此类推。注意：只有从其他对象的出口送出的输出才能被 grab 截取。其他类型的输出，例如 MIDI 消息的发送或在 Max Console 中打印，无法被 grab 截取。此外，grab 不会截取 seq、metro 和 clocker 这类定时对象的输出。

不过，把 grab 的右出口连接到 patcher 对象的入口，并不会截取子补丁的输出。它只会截取子补丁内 inlet 对象的输出，而这与该入口的输入完全相同。不过，grab 可以通过一个 receive 对象与远程对象通信，该对象的名称由 grab 的第二个参数给出。

若存在第二个参数，入口收到的消息会直接送往该参数命名的 receive 对象，而不是从右出口送出。任何这类 receive 对象都应只连接到其他对象最左侧的入口。若使用了第二个参数，原本用于截取其他对象输出的最右出口不会出现。

注意，若 grab 通过多个同名 receive 对象远程连接到其他对象，grab 与这些其他对象通信的顺序是未定义的，因此它们的输出从 grab 对象其他出口送出的顺序不可预测。
