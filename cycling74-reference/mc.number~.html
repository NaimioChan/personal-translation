mc.number~

多通道信号监视器与常量发生器

描述

使用 mc.number~ 对象显示或生成多通道信号取值。

讨论

mc.number~ 对象以两种不同的模式工作。点击对象框左侧的图标即可切换模式。

在信号监视模式下（以波形表示），它显示连接到左入口的多通道信号的取值。点击数字下方的圆点之一，可选择要显示的输入通道。

在信号输出模式下（以向下箭头表示），mc.number~ 显示从左入口收到或键入到对象框中的取值。该数字也会成为 mc.number~ 多通道信号输出中某个通道的常量信号值。点击数字即可高亮该对象以便键入，或在数字上滚动以改变其取值。点击数字显示下方的圆点之一，可选择要生成信号的通道。

参数

无。

特性

bgcolor [4 floats]

背景颜色

chans [int] : 0

chans 的取值非零时，mc.number~ 对象会显示并输出固定数量的通道，与所连接多通道信号的通道数无关。chans 为 0（默认值）时，对象会自动适应所连接多通道信号的通道数。

color [4 floats]

设置活动通道指示器的颜色。

displaychan [int] : 1

displaychan 特性设置在信号监视模式或信号输出模式下当前选中的显示通道。此外，displaychan 特性的取值还决定由发往对象左入口的数字来设置取值的那个输出通道。

ft1 [float] : 0.

ft1 特性设置输出信号的斜坡时间，单位为毫秒。默认时间为 0。

interval [float] : 100.

设置 mc.number~ 对象的显示更新速率（单位为毫秒）。这同时也是对所连接多通道信号进行采样、并以 float 取值从对象中间出口输出的速率。

maximum [atom] : <none>

设置可显示或可输出的最大值。

minimum [atom] : <none>

设置可显示或可输出的最小值。

monitormode [int] : 1

monitormode 特性启用或禁用信号监视模式。

numdecimalplaces [int] : 0

设置所显示或所键入的取值显示的小数位数。

sigoutmode [int] : 1

sigoutmode 特性启用或禁用信号输出模式。

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

textcolor [4 floats]

设置 mc.number~ 对象数字取值的颜色。textcolor 特性映射到 textcolor_inverse 样式颜色。

消息

bang

bang 消息目前没有作用。

int

转换为 float。

参数：

  • input-value or ramp-time [int]

float

左入口：该取值成为多通道输出中当前所显示通道的常量信号。当 mc.number~ 处于信号输出模式时，该取值会被显示。若斜坡时间非零，输出信号会在其先前取值与新设置的取值之间做斜坡变化。
右入口：设置斜坡时间，单位为毫秒。默认时间为 0。

参数：

  • input-value or ramp-time [float]

(inlet1)

右入口：设置以毫秒为单位的斜坡时间。默认时间为 0。

参数：

  • ramp time [float]

list

第一个数字为输出信号设置一个常量值（详情请参见上文 float 消息），第二个数字设置斜坡时间，单位为毫秒。

参数：

  • input-value [number]
  • ramp-time [int]

allow

单词 allow 后面跟一个数字，设置可以使用哪些显示模式。allow 1 把 mc.number~ 限制为信号输出显示模式。allow 2 把 mc.number~ 限制为输入监视显示模式。allow 3（默认值）允许两种模式，并让你点击对象左侧的图标在两者之间切换。

参数：

  • display-mode-availability [int]

flags

flags 消息是为 mc.number~ 对象的遗留支持而提供的；原有的全部功能现在都由对象特性提供。

参数：

  • appearance/behavior [int]

max

单词 max 后面跟一个可选数字，为信号输出设置 mc.number~ 的最大值。不带参数的单词 max 会清除此前设置的最大值。

参数：

  • maximum value [number]

min

单词 min 后面跟一个可选数字，为信号输出设置 number~ 的最小值。不带参数的单词 min 会清除此前设置的最小值。

参数：

  • minimum value [number]

mode

单词 mode 后面跟一个数字，在当前允许的情况下设置当前显示模式（参见 allow 消息）。mode 1 设置信号输出模式。mode 2 设置信号输入监视模式。

参数：

  • display-mode [int]

(mouse)

点击 number~ 左侧的图标，可在信号监视模式（波形）与信号输出模式（箭头）之间切换。处于信号输出模式时，点击数字即可高亮它以便键入。在数字上滚动可改变它。两种模式下都可以点击数字下方的圆点，选择要显示的通道取值。

set

单词 set 后面跟一个数字，使 mc.number~ 对象在信号输出模式下显示该数字，但不产生输出。

参数：

  • set input [float]

signal

mc.number~ 按 interval 特性指定的速率对所连接的多通道信号采样取值。采样得到的取值从中间出口送出，并由右出口先送出一个通道索引。mc.number~ 处于信号监视模式时，它显示当前选中显示通道的采样取值。

输出

float

中间出口：输入多通道信号的采样值按 interval 特性指定的速率送出。

float

右出口：就在中间出口输出采样值之前，mc.number~ 输出该采样信号取值的通道索引。

signal

左出口：音频开启时，mc.number~ 输出由常量值构成的多通道信号，这些值由信号输出模式下的取值设置，或从左入口接收。若设置了非零的斜坡时间，输出变化会在指定时间内从先前取值斜坡过渡到新取值。
