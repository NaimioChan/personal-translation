coll.codebox

存储并编辑一组数据

描述

允许存储、组织、编辑和取出各种消息，使用一个 UI 对象来显示和编辑。

参数

无。

特性

bgcolor [4 floats]

设置对象背景边框的颜色。

editlocked [int] : 0

允许在补丁锁定时编辑 codebox 文本。

embed [int]

切换是否把文本编辑器的内容嵌入补丁。禁用后可以显示会变化的文本内容，而不会把补丁标记为 dirty，也不会提示保存。

linenumbers [int] : 1

显示包含非空行行号的左侧列。

linenumberwidth [int32] : 20

设置左侧行号列的宽度，单位为像素。

margin [int32] : 4

设置左右边距的宽度，单位为像素

style [symbol] :

样式

textcolor [4 floats]

默认文字颜色（通常会被语法着色覆盖）

precision [int]

转换后的浮点值的小数位数（默认值 = 6）。

name [symbol]

coll 的名称。名称相同的多个对象会共享同一份数据。你也可以用 refer 消息共享数据。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

int

该数字指的是存储在 coll 中的某条消息的地址。若该地址处存有消息，则会输出该存储的消息。若存储的消息是单个 symbol，输出时总会在前面加上单词 "symbol"。

参数：

  • index [int]

float

该数字指的是存储在 coll 中的某条消息的地址。若该地址处存有消息，则会输出该存储的消息。若存储的消息是单个 symbol，输出时总会在前面加上单词 "symbol"。

参数：

  • index [float]

list

第一个取值被用作地址（coll 中的存储位置），列表中的其余项就存储在该地址处。地址总会以 int 形式存储。

参数：

  • index [int]
  • data [list]

(mouse)

双击 coll 对象，会在编辑窗口中把内容显示为文本。数据可以在该编辑器中手动编辑。

参数：

  • double-click []

anything

参见 symbol 列表。

参数：

  • index [any]

append

append 消息会新建一个条目，其索引比当前最大索引大 1。例如，若 coll 为空，append xyz 会添加一个与索引 0 关联的条目 xyz。第二次执行 append xyz 会再添加一个与索引 1 关联的条目 xyz。

参数：

  • data [list]

assoc

把一个 symbol 与数字地址关联起来，前提是该数字地址已经存在。关联之后，对该 symbol 的任何引用都会被解释为对该数字地址的引用。每个数字地址只能关联一个 symbol。

参数：

  • address name [symbol]
  • data index [int]

bang

参见 next 词条。

symbol

取出存储在以该 symbol 命名的地址处的消息。若没有地址与该 symbol 关联，则不产生任何输出。若存储的消息是单个 symbol，输出时总会在前面加上单词 "symbol"。

参数：

  • index [symbol]

clear

清除所有数据

deassoc

移除 symbol 与数字地址之间的关联。该 symbol 对 coll 将不再有任何意义。

参数：

  • address name [symbol]
  • data index [int]

delete

移除所给地址处的数据。若指定的地址是数字，所有编号更大的地址都会减 1。

参数：

  • index [any]

dump

把所有存储的地址从第 2 个出口送出，把所有存储的消息从第 1 个出口送出，顺序与它们的存储顺序一致。转储完成后，会从第 4 个出口送出一个 bang。

end

把指针（供 goto、next 和 prev 消息使用）设为最后一个地址。

filetype

设置可以把哪些文件类型读入和写入 coll 对象。不带参数的 filetype 消息会恢复默认的文件行为。

参数：

  • filetype [symbol]

flags

设置用于在其所在的补丁中保存自身内容的标志。消息 flags 1 0 通知对象把自身内容作为补丁文件的一部分保存。消息 flags 0 0 使内容不被保存。

参数：

  • save-setting [int]
  • unused [int]

goto

把指针（供 goto、next 和 prev 消息使用）设到某个特定地址，但不触发输出。若指定的地址不存在，指针会设在集合的开头。数据会在随后收到 bang、next 或 prev 消息时输出。

参数：

  • index [list]

insert

把消息插入到该数字指定的地址处，必要时把所有相等或更大的地址加 1。

参数：

  • index [int]
  • data [list]

insert2

参见 insert 词条。

参数：

  • index [int]
  • data [list]

length

统计 coll 中包含的条目数量，并把该数量从第 1 个出口送出。

max

获取任意条目中的最高值。可选的整数参数（默认值 = '1'）指定使用哪个元素位置。

参数：

  • element [int]

maxany

获取任意条目在任意元素位置上的最高值。

merge

把数据追加到指定索引处数据的末尾。若该地址尚不存在，则会创建它。

参数：

  • index [int]
  • data [list]

min

获取任意条目中的最低值。可选的整数参数（默认值 = '1'）指定使用哪个元素位置。

参数：

  • element [int]

minany

获取任意条目在任意元素位置上的最低值。

next

送出当前地址处存储的地址与数据，然后把指针设为下一个地址。若指针当前位于集合中的最后一个地址，它会回绕到第一个地址。若该地址是 symbol 而不是数字，则从第 2 个出口送出 0。

nstore

把消息存储在指定的数字地址处，并关联指定的 symbol。其效果等同于把消息存储在 int 地址处，再用 assoc 消息把一个 symbol 与该数字关联。

参数：

  • index [int]
  • association [symbol]
  • data [list]

nsub

用一个新值替换某个数据元素。例如，nsub 2 4 7 把地址 2 的第四个元素替换为值 7。数字值与 symbol 都可以按这种方式替换。

参数：

  • index [int]
  • position [int]
  • data [any]

nth

返回存储列表中所指位置处的数据元素，并从第 1 个出口送出。例如，nth 75 2 会输出地址 75 处存储列表中的第二个条目。

参数：

  • index [int]
  • position [int]

open

为当前数据打开一个数据编辑窗口，并把它置于焦点。

prev

送出当前地址处存储的地址与数据，然后把指针设为上一个地址。若指针当前位于集合中的第一个地址，它会回绕到最后一个地址。若该地址是 symbol 而不是数字，则从第 2 个出口送出 0。

read

不带参数时，read 会弹出标准的 Open Document 对话框来选择要载入的文件。若给出了参数，则载入该名称的文件。

参数：

  • filename [symbol]

readagain

载入最近一次读取过的文件的内容。若此前没有发生过文件载入，该请求会被当作 read 消息处理。

refer

把数据引用改为另一个具名 coll 对象中的数据。对被引用的任何 coll 中所存数据的改动，都会由所有同名对象共享。

参数：

  • object name [symbol]

remove

从集合中移除该地址及其内容。

参数：

  • index [any]

renumber

把数据条目重新编号为连续且递增的顺序。可选参数指定数据的起始数字地址。

参数：

  • data index [int]

renumber2

把所有索引加 1

参数：

  • data index [int]

separate

把所有索引大于所给值的数据的数字索引递增。这为后续的添加腾出一个空位。

参数：

  • data index [int]

sort

把数据按指定顺序排序。若第一个参数为 -1，条目按升序排序。若第一个参数为 1，条目按降序排序。
第二个参数指定用什么数据来对内容排序。若第二个参数为 -1，则使用与数据关联的索引（数字或 symbol）。若第二个参数缺省或为 0，则使用数据中的第一个条目。若第二个参数为 1 或更大，则使用该数据元素决定排序顺序。

参数：

  • sort order (-1 or 1) [int]
  • entry (-1, 0, or 1) [int]

start

把指针（供 goto、next 和 prev 消息使用）设为 coll 中的第一个地址。

store

把消息存储在所给 symbol 命名的地址处。例如，store triad 0 4 7 会把 0 4 7 存储在名为 triad 的地址处。

参数：

  • index [symbol]
  • data [list]

sub

与 nsub 相同，区别在于条目被替换之后，会把该指定地址处存储的消息送出。

参数：

  • index [int]
  • position [int]
  • data [list]

subsym

更改与数据关联的 symbol。第一个参数是要使用的新 symbol，第二个参数是要替换的 symbol 关联符。

参数：

  • new name [symbol]
  • old name [symbol]

swap

交换与两个地址关联的索引。数据本身不变，但它们使用的索引被互换。

参数：

  • index [int]
  • index [int]

wclose

关闭数据编辑窗口

write

不带参数时，write 会弹出标准的 Open Document 对话框来选择要写入的文件名。若给出了参数，该名称会被用作存储的文件名。

参数：

  • filename [symbol]

writeagain

把内容保存到最近一次写入过的文件。若此前没有发生过文件写入，该请求会被当作 write 消息处理。
