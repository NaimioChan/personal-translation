Max for Live

live.object

对 Live 对象执行操作

描述

live.object 用于对通过 live.path 对象选中的 Live 对象执行操作。这些操作包括获取 Live API 当前状态的信息，以及设置取值来控制 Live。

注意：Live API 在 Live 的主线程中运行，所有发往该 API 及从该 API 发出的消息都自动延后执行。

参数

无。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

bold

bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'

'11'
'12'
'13'

'36'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

入口

Left inlet

获取下面描述的所有命令消息。

Right inlet

收到对象 id 消息 id nn 后，选中要操作的对象。
id 0 表示没有对象，即发往左入口的所有消息都会被忽略，这也是初始状态。

出口

左出口

送出对 get、call、bang、getid、getinfo、gettype 和 getpath 的响应。

消息

getid

当前对象的 id 会从出口送出，前面带有单词 id。若没有当前对象，会送出 id 0。

id nn

操作：
设置当前对象。该消息发送到右入口或左入口时效果相同。为清晰起见，建议始终使用右入口提供对象 id。

- 无输出 -

getpath

操作：
送出当前对象的规范路径。

出口输出示例
左path pathpath live_set return_tracks 0

gettype

操作：
送出当前对象的类型（又称类名）。

出口输出示例
左type object-typetype Song

getinfo

操作：
送出当前对象的描述。

输出到左出口（大多数行可能出现多次，最后一行为 info done）：

info type object-type
info description description
info children list-child object-type
info child child object-type
info property property property-type
info function function
info done

示例输出：

info children clip_slots ClipSlot
info child canonical_parent Song
info property is_triggered bool
info property name symbol
info property tempo float
info function fire
info function fire_as_selected
info function set_fire_button_state
info done

bang, getid

操作：
把当前 Live 对象的 id 从出口送出。

出口输出示例

call

参数：
function 函数名
parameter-list 可选的参数列表

操作：
调用当前对象的给定函数，可带上一个参数列表。

备注：
参数的类型在 Live Object Model 中给出。

出口输出示例

参数：

set

参数：
list-child 当前对象的某个列表子项的名称

把该列表子项设为包含给定的这些 id。

备注：
并非所有子项都可以设置。

- 无输出 -

set

参数：

id nn 该名称对应的新子对象

操作：

并非所有子项都可以设置。

Inspector

Persistence

live.object 对象的 Inspector 中有一个特殊条目，名为 "Use Persistent Mapping"。启用该设置后，与对象关联的 id 会在 Live 文档保存与恢复时、以及 Max Device 在 Live 应用程序与 Max 编辑器之间或在 Live Set 内移动时保持持久。从 Live 8.2.2 起，Live API 的 id 在多次启动 Live 之间保持持久，再加上 Persistence 特性（live.object、live.observer 与 live.remote~ 都有该特性），就可以创建更简单的设备，让它们与 Live 用户界面中的元素保持关联。
