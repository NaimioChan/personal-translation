jit.qt.movie

播放或编辑影片

描述

关于矩阵运算符的更多内容

Jitter MOP

既然矩阵是 Jitter 的核心，大多数 Jitter 对象属于矩阵运算符这一类也就不奇怪了。每个矩阵运算符都有若干个矩阵输入和若干个矩阵输出。矩阵输入按从左到右的顺序用 "in"、"in2"、"in3" 等名称称呼，矩阵输出用 "out"、"out2"、"out3" 等名称称呼，即除最左边第一个输入和最左边第一个输出分别只叫 "in" 和 "out" 之外，其余名称都由输入/输出编号后缀而来。我们把输入或输出的名称称为 "I/O-name"。

矩阵输入和输出在内部通常各自持有保存信息的矩阵。这是必要的，因为 Jitter 是异步框架（也就是说，各个矩阵并不会同时到达所有输入）。矩阵输入和输出的若干方面可以用命令 [I/O-name] 加上下列后缀之一来设置："_dim" 设置指定 I/O 矩阵的维度，"_type" 设置指定矩阵的类型，"_planecount" 设置指定矩阵的通道数，"_name" 设置指定矩阵的名称。有一种特殊情况没有任何内部矩阵，就是第一个输入 "in"。这是因为该特殊输入实际上触发矩阵运算符的计算，所以不像其他输入那样需要缓存到计算发生为止。因此没有机制可以设置 "in" 的 dim、planecount、type 或 name。

矩阵运算符接受我们称为「matrix args」的参数，即 [planecount (int)] [ type (symbol)] [dim (int list)]。若给出了这些参数，adapt 特性会被关闭，否则会被打开。若 adapt 模式打开，则每当第一个输入收到矩阵时，就相当于把 dim、planecount 和 type 特性设置为该输入矩阵的对应值。若其他输入和输出链接到这些特性，它们所链接的特性也会随之改变。adapt 模式打开时哪些输入和输出会链接到哪些特性，请查阅「MOP」表。最左侧的输入不适用该规则，因此该行所有列都标记为 "n/a"。

jit.matrix 对象是一个具名矩阵，可用于矩阵数据的存储与取出、重采样，以及矩阵类型与 planecount 转换等操作。

MOP 参数

planecount [int] 可选

显式设置输出以及右侧各输入的通道数。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

type [symbol] 可选

显式设置输出以及右侧各输入的矩阵类型。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

dimensions [list] 可选

显式设置输出以及右侧各输入的矩阵维度。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

MOP 特性

adapt [int]

矩阵自适应标志（若给出了矩阵参数则默认值为 0，否则为 1）。该标志置位时，jit.matrix 对象会自适应输入矩阵的 planecount、type 和 dimensions。

[in/out]_dim [32 ints]

矩阵数据的维度（默认值 = 1 1）

[in/out]_name [symbol]

矩阵输入或输出的名称（默认值 = UID）

[in/out]_planecount [int]

矩阵输入或输出数据的通道数。除特殊情况外，该值等于 planecount。

[in/out]_type [symbol]

输入或输出矩阵的数据类型。除特殊情况外，该值等于 type。

outputmode [int]

输出模式（默认值 = 1（计算并输出矩阵））
0 = 无输出（不计算）
1 = 计算并输出矩阵
2 = 透传输入（不计算）
3 = 透传输出（不计算）

type [int]

矩阵数据类型（默认值 = char
支持的数据类型有 char、long、float32 和 float64。

MOP 消息

等价于 outputmatrix 消息。

exportattrs

getattributes

从对象的右出口送出一串列表，描述对象的特性，每条特性一行。每行的形式为 attribute attribute-name get get-value set foo set-value data-type(s) number-of-values。

getstate

从对象的右出口送出一串列表，描述对象的状态，每条特性一行。每行的形式为 attribute-name attribute-value1 attribute-value2... attribute-valueN。

importattrs

导入以 XML 格式指定的特性来设置对象的特性。若未指定文件名，会打开文件对话框让你选择文件。

参数：

jit_matrix

处理具名矩阵的输入。若该消息在左入口收到，通常会触发输出。若该消息在其他入口收到，数据通常会被缓存，直到左入口收到 jit_matrix 消息。

参数：

  • matrix-name [symbol]

outputmatrix

把矩阵从左出口送出。

summary

从对象最右出口送出一串列表，描述对象及其特性和消息。第一行的形式为 summary objectname object-name。第二、三行用 summary (matrixinputcount/matrixoutletcount) number-of-(inlets/outlets) 的形式给出对象的入口和出口数量。第四行用 summary matrixoutput descriptor planelink planelink-value typelink typelink-value dimlink dimlink-value types data-type(s) 的形式描述 matrixoutput。随后逐条列出对象的每个特性，每条特性一行。每行的形式为 summary attribute attribute-name attribute-value1 attribute-value2 ... attribute-valueN。

特性

adapt [int]

输出矩阵维度自适应影片尺寸标志

automatic [int]

绑定到 jit.world 时启用自动矩阵输出。

autostart [int]

影片打开时自动播放标志（默认值 = 1）

colormode [symbol]

输出矩阵的颜色编码。仅支持 32 位。
可选值：

'argb'（ ARGB（alpha、red、green、blue）色彩模式 ）
'uyvy'（ UYVY（YUV 4:2:2 打包）色彩模式 ）

drawto [symbol]

渲染上下文名称，在启用 output_texture 时使用。

dstrect [4 ints]

用于把媒体解压到内部矩阵的输出矩阵部分（默认值 = 0 0 (matrix width) (matrix height)）
矩形的边界用 left top right bottom 的形式表示。所有取值都相对于输出矩阵查看区的左上角。

duration [int]

影片的时长。设置时长时，整个影片会被缩放到新的长度，除非使用了附加参数 noscale。在这种情况下，影片长度会在不缩放的前提下改变。若要更精确地控制缩放，请使用 scale 消息。

engine [symbol]

视频引擎后端。此参数只能在 max 对象框中设置。若未指定，则由 Video Engine Max 偏好设置决定。截至撰写本文时，可选值包括 avf（仅 Mac）和 qt。

影片的内部帧率

framecount [int] 只读

影片中的帧数

framereport [int]

帧报告标志（默认值 = 0）。启用后，每处理一帧时都会把 framecalc 消息从 jit.movie 对象最右侧的出口送出，随后再送出处理该帧所花费的毫秒数。

interp [int]

输出插值标志

loop [int]

循环模式（默认值 = 1（起始到结尾））
可选值：

0 = 'off' ( 0 = 不循环 )
1 = 'normal' ( 1 = 正常循环（起始到结尾） )
2 = 'palindrome' ( 2 = 往返循环（起始到结尾再到起始，如此反复） )
3 = 'playback-limits' ( 3 = 不循环，但使用 looppoints 来定义播放界限 )

loopend [int]

影片循环点的终点。时间以 time 取值指定。

looppoints [2 ints]

影片的循环点。时间以 time 取值指定。

loopreport [int]

循环通知标志（默认值 = 0）。启用后，当正在播放的影片经过循环点时，jit.movie 对象会送出 loopnotify 消息。在往返循环模式下，影片的开头和结尾都会送出该消息。

loopstart [2 ints]

moviepath [symbol] 只读

消息

read

从磁盘文件、URL 或剪贴板读取影片。如果没有任何参数，或者把 dialog 用作 src-name 参数，就会显示一个文件选择对话框供你选择文件。如果把 scrap 用作 src-name 参数，对象会尝试从剪贴板载入影片。如果参数可解析为 http://、ftp:///、file:// 或 rtsp:// URL，对象会尝试从该位置载入影片。否则，参数会被视为本地文件名。
如果启用了 autostart，影片会立即开始播放。

参数：

  • src-name [symbol]

framedump

开始一次帧转储：影片会从 start-frame 指定的帧开始（默认为 1），并自动按顺序输出各帧（无需 bang 或 outputmatrix 消息），直到 end-frame 指定的帧，每帧之间跳过 frame-skip 帧。起始帧的默认值为 1，结束帧的默认值为影片的总帧数。frame-skip 的默认值为 1。
运行期间，每输出一帧之后，消息 framedump current_frame 会从右出口送出。完成时，会输出消息 framedump done。

参数：

  • start-frame [int]
  • end-frame [int]
  • frame-skip [int]

cancelframedump

停止帧转储过程。参见 framedump。

asyncread

如果可能，以异步方式从磁盘文件读取影片。如果没有任何参数，或者把 dialog 用作 src-name 参数，就会显示一个文件选择对话框供你选择文件。任何参数都会被当作本地文件名。目前，异步读取尚不支持基于 URL 或剪贴板的影片；此时会改用常规的 read 行为。

参数：

  • src-name [symbol]

(drag)

载入媒体文件
