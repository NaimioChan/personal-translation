MSP

cycle~

正弦振荡器

描述

用 cycle~ 对象生成周期波形。默认波形是一个周期的余弦波。你也可以使用 wave~ 对象，它提供了额外的灵活性，不过优化程度略低。

讨论

cycle~ 对象是一个插值振荡器，它使用波表反复读取一个周期的波形。波表可以用 'set' 消息更换。该波表可以是任意大小，但历史上被限制为 512 个采样点。

参数

frequency [number] hz 可选

振荡器频率（初始）振荡器的初始频率

buffer-name [symbol] 可选

用于定义振荡器波表的 buffer~ 对象的名称。若给出了频率参数，buffer~ 名称跟在频率之后。若未给出 buffer~ 名称，cycle~ 会使用内部的 64 位 16K 余弦波表。

sample-offset [int] 可选

若已给出 buffer~ 名称，则此项定义进入具名 buffer~ 对象采样内存的采样点偏移。cycle~ 只使用多通道 buffer~ 的第一个通道。

特性

buffer [symbol]

包含外部波形的缓冲区。用该特性设置 buffer~ 相当于发送 setall 消息。

buffer_autoupdate [int]

若正在使用外部 buffer~（见 buffer，cycle~ 对象会自动更新其内部波形，以响应那个 buffer~ 内容的变化，就像 buffer 名称被重新设置了一样。

buffer_offset [atom_long]

缓冲区的第一个采样点（若由外部缓冲区提供波形）

buffer_sizeinsamps [atom_long]

覆盖波表所用缓冲区的大小。若使用 set 消息，大小为 512；若使用 setall 消息，大小为整个 buffer~ 长度。用该特性定义不同的大小（大小应为 2 的幂）。把该大小设为 0 时，实际大小为 512；把它设为 -1 时，实际大小为整个 buffer~ 长度。
可选值：

'-1'
'0'
'16'
'32'
'64'
'128'
'256'
'512'
'1024'
'2048'
'4096'
'8192'
'16384'
'32768'
'65536'

frequency [float]

振荡器频率

phase [float]

相位偏移

消息

float

左入口：振荡器的频率
右入口：振荡器的相位，范围 0.0 到 1.0

参数：

  • frequency-or-phase [float]

(mouse)

双击显示 buffer~ 的内容

reset

在左入口，reset 消息后跟一个 0 - 1 的浮点数，会重置 cycle~ 对象的相位。信号从指定的相位继续输出。如果你有多个相位不同步的 cycle~ 对象，给它们全部发送 reset 消息就会让它们同步。

参数：

  • phase [float]

set

设置一个 buffer~ 对象用作波表，只使用前 512 个采样点。若未给出名称，将使用含 16K 个采样点的内部余弦波表。用 setall 消息把整个 buffer~ 用作波表。

参数：

  • buffer-name [symbol]
  • sample-offset [int]

setall

设置一个 buffer~ 对象用作波表，使用整个 buffer~ 长度。这与 set 消息形成对比，后者只使用 buffer~ 的前 512 个采样点。

参数：

  • value [symbol]

signal

左入口：振荡器的频率
右入口：振荡器的相位，范围 0.0 到 1.0

输出

signal

以指定频率、指定相位重复的波形（默认为余弦）。
