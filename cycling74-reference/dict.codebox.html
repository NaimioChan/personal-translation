dict.codebox

创建并访问字典

描述

dict.codebox 对象是一个用于显示和编辑字典的界面对象。用 dict.codebox 对象可以创建具名字典、克隆已有字典，以及查询已有字典以访问其数据。

参数

无。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

从第 1 个出口送出对该字典的引用。

clear

清空字典的内容，恢复到干净状态。

remove

从字典中移除一个键及其关联的值。

参数：

  • key [symbol]

getkeys

把字典中所有键组成的列表送到第 3 个出口。默认情况下，键按加入字典的顺序排序。用可选参数指定按字母顺序排序。

参数：

  • alphabetize [bool]

contains

把一个 0 或 1 送到第 3 个出口，指示指定的键在字典中是否存在。

参数：

  • key [symbol]

getnames

把当前存在的所有字典组成的列表送到第 4 个出口。

getsize

把某个键所关联的值的数量送到第 2 个出口。

参数：

  • key [symbol]

gettype

把某个键所关联的值的类型送到第 2 个出口。

参数：

  • key [symbol]

get

把某个键所关联的值送到第 2 个出口。

参数：

  • key [symbol]

set

把某个键的值设为指定的值。

参数：

  • key [symbol]
  • value [list]

append

把值添加到指定键所关联数组的末尾。

参数：

  • key [symbol]
  • value [list]

replace

把某个键的值设为指定的值。若为该键指定了层级，而该层级不存在，则会在字典中创建它。

参数：

  • key [symbol]
  • value [list]

setparse

把某个键的值设为用 JSON 定义的字典内容。

参数：

  • key [symbol]
  • value [symbol]

parse

通过以 JSON 提供新内容来替换字典的内容。

参数：

  • key [symbol]
  • value [symbol]

clone

创建传入字典的克隆。若在第 1 个入口收到，则从第 1 个出口送出对这个新克隆的引用。否则只克隆该字典，不送出。

参数：

  • name [symbol]

dictionary

创建传入字典的克隆。若在第 1 个入口收到，则从第 1 个出口送出对这个新克隆的引用。否则只克隆该字典，不送出。

参数：

  • name [symbol]

read

从 JSON 或 YAML 文件读取字典内容。若未提供路径/文件名，会弹出一个对话框。文件格式由文件扩展名决定，即 '.json' 或 '.yaml'。成功/失败通知会以 read [filename] 0/1 的形式送到最右侧的出口。

参数：

  • filename [symbol]

readagain

重新读取先前由 read 或 write 消息指定的 JSON 或 YAML 文件。若此前没有指定过文件，会弹出标准的 File Dialog 供用户手动选择要读取的文件。成功/失败通知会以 read [filename] 0/1 的形式送到最右侧的出口。

import

从 JSON 或 YAML 文件读取字典内容。若未提供路径/文件名，会弹出一个对话框。文件格式由文件扩展名决定，即 '.json' 或 '.yaml'。成功/失败通知会以 import [filename] 0/1 的形式送到最右侧的出口。

参数：

  • filename [symbol]

readany

从 JSON 或 YAML 文件读取字典内容。若未提供路径/文件名，会弹出一个对话框。文件格式和扩展名不做检查。假定文件内容为 JSON 格式。成功/失败通知会以 read [filename] 0/1 的形式送到最右侧的出口。

参数：

  • filename [symbol]

write

把字典内容写入 JSON 或 YAML 文件。若未提供路径/文件名，会弹出一个对话框。文件格式由文件扩展名决定，即 '.json' 或 '.yaml'。成功/失败通知会以 write [filename] 0/1 的形式送到最右侧的出口。

参数：

  • filename [symbol]

export

把字典内容写入 JSON 或 YAML 文件。若未提供路径/文件名，会弹出一个对话框。文件格式由文件扩展名决定，即 '.json' 或 '.yaml'。成功/失败通知会以 export [filename] 0/1 的形式送到最右侧的出口。

参数：

  • filename [symbol]

writeagain

把字典内容写入 JSON 或 YAML 文件。将使用先前 'write' 或 'export' 消息的参数所提供的文件。成功/失败通知会以 write [filename] 0/1 的形式送到最右侧的出口。

(mouse)

双击 dict 对象会打开字典编辑窗口。

edit

打开字典编辑窗口。

wclose

若字典编辑窗口已打开，则关闭它。

pull_from_coll

把某个具名 coll 对象的内容拉入该字典。coll 中的索引会成为键，而那些索引对应的值则成为字典各键的值。

参数：

  • coll-name [symbol]

push_to_coll

把字典的内容推入某个具名 coll 对象。字典中的键会成为 coll 中的索引，而那些索引对应的值则成为字典各键的值。

参数：

  • coll-name [symbol]
