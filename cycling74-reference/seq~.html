seq~

信号驱动的事件音序器

描述

seq~ 对象是一个由信号输入驱动的事件音序器。可以用 seq~ 创建与控制数据组成的循环序列，这些序列与 phasor~ 同步。

讨论

它针对连续的斜坡输入做了优化，但任何经过任意取值范围的信号都能使用。序列事件可以实时录制，也可以用 add 消息插入。seq~ 可以包含任意数量的序列，但同一时间只有一个序列可用于播放与录制。

参数

无。

消息

bang

会使 seq~ 对象当前的序列号、运行模式（record、overdub、play）以及当前事件总数等信息被打印到 Max 窗口。

int

与 anything 相同。

参数：

  • input [int]

float

与 anything 相同。

参数：

  • input [float]

list

与 anything 相同。

参数：

  • input [list]

anything

用 seq~ 对象录制并播放消息。入口收到的所有事件都会根据输入信号的当前取值被存储。除发往 seq~ 对象自身的命令外，任何消息都可以被排入序列。该示例展示了绕过这一限制的一种简单办法。
注意：若把 MIDI 输入流转换为 MIDI 事件列表，就可以用 seq~ 为 MIDI 数据排列序列。这一转换是必要的，能避免输出损坏的 MIDI 流——若只把 MIDI 流中原始的 int 消息逐条排入序列，而 seq~ 对象又不是在做简单的前向线性播放，就会出现这种情况。

参数：

  • input [list]

add

单词 add 后跟一个 int、一个 float 和一条消息，会把该消息所指定的 Max 事件插入到 int 所指定的序列号中、float 所指定的时间点上。（例如 add 2 0.5 honk 会插入消息 honk，让它在序列 2 的中点处播放。）

参数：

  • sequence-name (symbol), start time (float), optional end time (float) and Max-Event (message) [list]

clear

单词 clear 后跟一个序列的名称，会擦除该序列。消息 clear all 会擦除当前所有序列。

delete

单词 delete 后跟一个指定序列名的 symbol、一个 float 和一条消息，会删除该消息所指定的一个或多个 Max 事件，其位置由 float 指定，位于 symbol 所指定的序列名中。还可以额外指定一个结束时间。以下是一些示例：

delete mysequence 5.：删除 mysequence 中时间为 5 的所有事件。
delete mysequence 6.5 8.：删除 mysequence 中时间在 6.5 与 8 之间的所有事件。
delete mysequence -1. 99. explosion：只删除事件 explosion，无论它出现在哪里。

参数：

  • sequence-number (int), time (float), and Max-Event (message) [list]

dump

会使当前已存储事件序列的内容从中间出口送出。单词 dump 后跟一个数字时，只输出该数字所指定的序列。

参数：

  • sequence-number (int) [int]

erase

clear 的同义词。

offset

单词 offset 后跟一个数字，会把序列的编号偏移指定的数字。

参数：

  • number-to-offset-sequence-numbering [int]

overdub

单词 overdub 后跟 1，会使 seq~ 以 "overdub" 模式开始对当前序列（由 seqnum 消息设置）进行 Max 事件录制。录制从循环的当前位置开始，并在输入信号到达 1 的位置回绕，信号越过其原本的取值后仍继续录制。消息 overdub 0 会关闭 overdub 模式。

参数：

  • overdub-enable-flag (0 or 1) [int]

play

单词 play 后跟 1，会使 seq~ 从输入信号当前取值所指定的循环位置开始，播放当前序列（由 seqnum 消息设置）的 Max 事件。play 0 会关闭播放。默认情况下，播放是关闭的。

参数：

  • playback-enable-flag (0 or 1) [int]

read

把包含用 seq~ 对象的 write 消息所创建的 Max 事件序列的文本文件读入. seq~ 对象的内存中。若单词 read 后面没有出现 symbol 参数，会打开一个标准打开文件对话框，显示可用的文本文件。单词 read 后跟一个 symbol 时，会把文件名与该 symbol 对应的文件读入 seq~ 对象的内存，而不打开对话框。

参数：

  • filename [symbol]

record

单词 record 后跟 1，会使 seq~ 从输入信号当前取值所指定的循环位置开始，把事件录制进当前序列（由 seqnum 消息设置）。record 0 会关闭录制。默认情况下，录制是关闭的。

参数：

  • playback-enable-flag (0 or 1) [int]

seq

功能与 seqnum 相同。

参数：

  • sequence (int or symbol) [int]

seqnum

单词 seqnum 后跟一个数字或 symbol，设置当前正在录制或播放的 Max 事件序列。

参数：

  • sequence (int or symbol) [int]

signal

输出介于 0. 与 1.0 之间（通常是 phasor~ 的输出）的输入信号，用来驱动该事件音序器。

symbol

与 anything 相同。

参数：

  • input [symbol]

write

把当前所有 Max 事件序列的内容保存到一个文本文件。会打开一个标准文件对话框来为文件命名。单词 write 后跟一个 symbol 时，会把该 symbol 用作文件名保存文件，位置与包含 seq~ 对象的补丁所在的文件夹相同。若该补丁尚未保存，seq~ 文件会保存到与 Max 应用程序相同的文件夹中。

参数：

  • filename [symbol]

输出

any message

左出口：用 play 1 消息启用播放后，seq~ 对象会输出在输入信号所指定的时间上录制的所有事件。

list

右出口：dump 消息会使 seq~ 对象以列表形式输出指定序列的内容，该列表由指定序列号的 int、指定与该时间点相关联的信号取值的 float，以及要在该时间输出的 int、float、symbol 或 list 组成。
