Max for Live

live.remote~

对 Ableton Live 和 Max for Live 中参数的实时控制。

描述

live.remote~ 对象让你可以实时地远程控制 Ableton Live 和 Max for Live 中的参数。要更深入地了解 Live 的参数，请在 Live Object Model 中查找 DeviceParameter Object Class。

讨论

Live 和 Max for Live 中的参数使用 live.path 或 live.map 来选中，其 id 会被发送到 live.remote~ 的右入口。DeviceParameter 的示例路径是 live_set master_track mixer_device volume。另一种做法是，在 Ableton Live 的界面中右键点击某个参数，然后在上下文菜单中选择 "Copy LOM Path"，即可得到该参数的路径（仅 Ableton Live 12 可用）。

整数或浮点取值会以消息或以音频信号的形式发送到 live.remote~ 的左入口。这些取值会以采样点精确的方式施加（若由 Max 的音频线程送出），延迟恒为一个音频缓冲区。

当某个参数由 live.remote~ 控制时，该参数在 Live 中会被禁用，就像它由 Macro 参数控制一样（但没有那个绿点）。这意味着任何参数自动化都会被禁用，而 Live Set 中的取值不会被改动。此外，不会创建撤销步骤。包络仍保持活动。若要停止远程控制某个设备参数并重新启用它，请把 id 0 发送到 live.remote~ 的右入口。

参数

无。

特性

smoothing [float]

设置每个传入事件所使用的斜坡时间。这还会对你传入的任何信号做时间上的降采样。例如，平滑取值为 1 ms 时，会每 1 ms 对传入信号采样一次，并送出那些输出信号线性近似的斜坡事件。该特性默认值为 1 ms。

normalized [int]

切换 live.remote~ 对象的归一化模式，该模式会自动把输入取值缩放到目标参数的取值范围。当 normalized 特性设为 1 时，把信号或 0 到 1 范围内的取值发送给 live.remote~，会自动把这些取值缩放到接收参数的取值范围。若 normalized 特性设为 0，自动缩放会被禁用。此时你需要提供介于该参数最小值与最大值之间的取值才能控制它。

入口

Left inlet

value (signal/float) 设置右入口中由 id 指定的参数对象的取值。有效范围请参考目标参数的 min 与 max 属性。该取值曲线与 Live 中该参数的 GUI 控件呈线性关系。

Right inlet

id nn 设置对象 id；该消息采用 id nn 的格式，用于选中 Live 和 Max for Live 中要控制的目标参数（DeviceParameter Object）。
id 0 表示没有对象，即远程控制停止控制目标参数。这也是初始状态。

消息

float

左入口收到的浮点取值会在下一个音频缓冲区开始时，或在一个待处理的斜坡结束时，被施加到选中的 Live 参数（DeviceParameter Object）上（若有）（见 smoothing）。

参数：

  • value [float]

int

左入口收到的整数取值会在下一个音频缓冲区开始时，或在一个待处理的斜坡结束时，被施加到选中的 Live 参数（DeviceParameter Object）上（若有）（见 smoothing）。

参数：

  • value [int]

list

用一个包含两个浮点数的列表启动斜坡，类似于 line~ 对象。送入 “1 500” 表示从当前取值开始，将在 500 ms 后到达取值 1。新的斜坡总会覆盖当前斜坡，所以如果你想缩短一个斜坡，再送一个取值即可。

参数：

  • target-value [float]
  • delta-time [number]

signal

左入口收到的信号输入取值会实时施加到选中的参数（DeviceParameter Object）上（若有）。

id

右入口：设置选中的对象。若该 id 不是参数（DeviceParameter Object），该消息不起作用。

参数：

  • parameter id [int]

getid

映射对象的 id 会从出口送出，前面带有单词 id。若没有映射对象，会送出 id 0。

Inspector

Persistence

live.remote~ 对象的 Inspector 中有一个特殊条目，名为 "Use Persistent Mapping"。启用该设置后，与该对象关联的 id（此处即该参数的 id）在 Ableton Live Set 保存和恢复时会保持存在，在 Max Device 于 Live 应用程序与 Max 编辑器之间移动时、或在 Live Set 内部移动时同样如此。从 Live 8.2.2 开始，Live API 的 id 在 Live 的多次启动之间保持持久，这一点连同 Persistence 特性（即 live.object、live.observer 和 live.remote~ 的特性），使得可以创建更简单的设备，这些设备能与 Ableton Live 用户界面中的元素保持关联。
