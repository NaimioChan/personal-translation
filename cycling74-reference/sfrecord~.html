MSP

sfrecord~

录制到磁盘上的音频文件

描述

用 sfrecord~ 对象把 MSP 输出录制并保存为音频文件。

参数

number-of-input-channels [int] 可选

设置输入通道数，它决定 sfrecord~ 对象将拥有的入口数量。最大通道数为 64，默认值为 1。创建的音频文件将与该参数拥有相同的通道数。能否真正录制到最大通道数取决于你的处理器与硬盘的速度。

buffer-size [int] 可选

可选的第二个参数设置缓冲区大小。默认值是 20160。

特性

beginramp [float]

起始斜坡时间（ms）

bitdepth [int]

别名：format

每个采样点的位数

dither [int] : 0

写入 PCM（整数）文件时启用三角形抖动。
可选值：

0 = 'Off'（写入 PCM 文件时不应用抖动）
1 = 'Dither'（写入 PCM 文件时应用三角形抖动（TPDF））
2 = 'Dither + Noise Shaping'（写入 PCM 文件时应用带噪声整形的三角形抖动（TPDF））

endramp [float]

结束斜坡时间（ms）

nchans [int]

设置要录制的音频文件的通道数（1-64）。默认值为 1。

quantization [int] : 0

写入 PCM（整数）文件时选择量化规则。
可选值：

0 = 'Round'（量化到整数取值时采用四舍五入。）
1 = 'Floor'（量化到整数取值时采用向下取整。）

resample [float]

对文件进行升采样或降采样。采样率以浮点值表示——1.0 为当前采样率，0.5 为当前采样率的一半，2.0 为当前采样率的两倍，以此类推。

sortloop [int] : 0

当 sortloop 特性打开时，用 loop 消息所做的录制会被重新排序，使文件的开头成为最近一次录制的开头。若 sortloop 关闭（默认），录制的开头很可能位于所得音频文件的中间某处。

消息

int

左入口：若已用 open 消息打开文件，非零值开始录制，0 停止录制并关闭文件。sfrecord~ 需要再收到一条 open 消息才能重新录制，前提是此前已送出 0。

若出现错误，例如硬盘空间不足，录制也可能自行停止。

参数：

  • recording-start/stop-flag (0 or nonzero) [int]

loop

左入口：若已用 open 消息打开文件，单词 loop 后跟一个以毫秒为单位的长度，会开始一次录制，在指定的时长内捕获最近的声音。当 sfrecord~ 对象在其左入口收到 0 时，录制会停止。

参数：

  • length (milliseconds) [float]

open

左入口：打开一个文件用于录制。默认情况下文件类型是 AIFF，但 sfrecord~ 也支持 WAVE、OGG、FLAC 和 Raw Data。open 一词不带参数时，会调出标准的 Save As 对话框，让你选择文件名。可选的符号 aiff、wave、ogg、flac 或 raw 指定文件格式（也可以在 Save As 对话框里用 Format 弹出菜单设置）。若 open 后面跟第二个符号，它会在当前的默认卷中创建一个文件。同名的已有文件会被覆盖。格式符号（如 aiff）可以跟在可选的文件名参数之后。若只给 open 消息一个参数，且该参数是一个文件名，则文件类型由文件扩展名决定（例如 "open test.wav" 会把文件类型设为 wave）。

参数：

  • file-type [symbol]
  • filename [symbol]

print

输出关于录制进度的晦涩状态信息。

record

左入口：若已用 open 消息打开文件，单词 record 后跟一个以毫秒为单位的时间，会按指定的时长开始录制。录制可以在到达终点之前停止，方法是向 sfrecord~ 的左入口送出一个 0。

参数：

  • recording-time [float]

samptype

左入口：单词 samptype 后跟一个 symbol，指定录制音频文件时要使用的采样类型。支持以下采样数据种类：

int8：8 位整数
int16：16 位整数
int24：24 位整数
int32：32 位整数
float32：32 位浮点
float64：64 位浮点
mulaw：8 位 "mu"-law 编码
alaw：8 位 a-law 编码
可选的第二个参数为 0 或 1，指定是否应使用字节交换；字节交换只在写入 'raw' 音频文件时有用。

参数：

  • sample-type [symbol]
  • byte-swap-flag [int]

signal

打开录制后，sfrecord~ 的每个入口都接受一个信号，该信号会被录制到音频文件的一个通道中。

start

start 消息接受一个文件名参数，以及一个用于设置要录制的通道数的可选参数。若音频已打开，start 会创建用于录制的文件并立即开始录制。若收到 start 时音频处于关闭状态，则音频一打开就开始录制。

参数：

  • filename [symbol]
  • channelcount [int]

stop

stop 消息停止当前的录制并关闭正在写入的文件。

输出

signal

自该文件开始录制以来经过的时间，单位为毫秒。若录制已经停止，则该信号值会停留在最近一次录制的长度，直到开始新的录制。
