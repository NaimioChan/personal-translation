Max

gamepad

报告 gamepad 控制器事件

描述

跟踪并输出所有已连接 gamepad 控制器上的按钮、摇杆、扳机和传感器事件。用 senddevice 消息发送设备控制消息，以实现触觉反馈震动事件和设备 LED 颜色。gamepad 对象是 Simple DirectMedia Layer 2.0 库 gamepad 实现的轻量封装。

讨论

随着 gamepad 控制器产生事件，它们以 event_type value 的形式输出。可能的事件有：
axis_left_x
axis_left_y
axis_right_x
axis_right_y
axis_left_trigger
axis_right_trigger
button_a
button_b
button_x
button_y
button_dpad_up
button_dpad_down
button_dpad_left
button_dpad_right
button_left_shoulder
button_right_shoulder
button_left_stick
button_right_stick
button_start
button_back
button_guide
button_misc1
button_touchpad
sensor_gyro
sensor_accel
touchpad_up
touchpad_down
touchpad_motion

参数

无。

特性

interval [float]

全局轮询间隔设置处理传入 gamepad 控制器事件队列的速率。默认值为 5 毫秒。改动该特性会改变所有补丁中所有 gamepad 控制器对象的该设置。

rawdata [int]

输出原始 SDL 摇杆数据，而不是 gamepad 映射后的数据。这有助于生成设备映射，或诊断 gamepad 设备映射问题。改动该特性会改变所有补丁中所有 gamepad 控制器对象的该设置。

消息

addmapping

从 symbol 添加 SDL 控制器映射。你可以在出色的 SDL_GameControllerDB 社区数据库中找到示例控制器映射。

参数：

  • mapping_text [symbol]

addmappingfile

从文件添加 SDL 控制器映射，例如来自出色的 SDL_GameControllerDB 社区数据库的 gamecontrollerdb.txt。若你把名为 "gamecontrollerdb.txt" 的文件放在 Max 搜索路径中，gamepad 会在用创建的第一个 gamepad 实例初始化 SDL 之前载入该映射文件。对某些控制器来说，这比创建之后再载入映射文件效果更好。

参数：

  • filename [symbol]

senddevice

单词 senddevice 后面跟一个表示逻辑设备 ID 的数字，会把后面的消息发往该设备。若设备索引为负，后面的消息会发往所有设备。可能的消息有 led、rumble 和 rumbletriggers。

led 消息后面跟 red、green 和 blue 取值，范围为 0-1。rumble 消息后面跟 low、high 和 duration 取值，其中 low 表示低频震动量，范围为 0-1，high 表示高频震动量，范围为 0-1，duration 以毫秒为单位。rumbletriggers 消息后面跟 left、right 和 duration 取值，其中 left 表示左扳机震动量，范围为 0-1，right 表示右扳机震动量，范围为 0-1，duration 以毫秒为单位。

参数：

  • Device ID [int]
  • Message [symbol]
  • Value [list]

sendinstance

sendinstance 消息的功能与 senddevice 消息相同，只是用唯一的 gamepad 实例 id 来引用，而不是逻辑设备 ID。

参数：

  • Instance ID [int]
  • Message [symbol]
  • Value [list]
