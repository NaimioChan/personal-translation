mc.ezadc~

音频输入与开关按钮

描述

ezadc~ 相当于 adc~ 对象的用户界面版本。它显示为一个按钮，可以用鼠标点击来打开或关闭音频。

参数

无。

特性

bgcolor [4 floats]

背景颜色

color [4 floats] >= 7.0.0

选择用于显示音频开启状态的颜色。

elementcolor [4 floats] >= 7.0.0

选择用于显示音频关闭状态的颜色。

local [int] : 0

开关为局部

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

消息

int

非零数字会打开所有已加载补丁中的音频处理。0 的取值会关闭所有音频处理。

参数：

  • stop/start-flag [int]

list

由整数组成的 list 为每个信号入口设置逻辑输入通道。

参数：

  • input-channel-designations [list]

(mouse)

点击 ezadc~ 会在打开与关闭之间切换音频处理。对象高亮表示音频已开启。

local

单词 local 后面跟 1，会让点击打开 ezadc~ 对象的效果等同于向它发送 startwindow message。消息 local 0 会把 ezadc~ 对象恢复为默认模式，此时点击打开它等同于发送 start 消息。

参数：

  • behavioral [int]

open

打开 Audio Status 窗口。该窗口还会被置于最前面。

set

单词 set 后面跟两个数字，为对象的某个信号出口设置逻辑输入通道。第一个数字指定出口编号，其中 1 是最左侧的出口。第二个数字指定逻辑输入通道（1 到 512）。若第二个数字为 0，该出口送出零信号。

参数：

  • logical-output-channel [int]
  • logical-input-channel [int]

start

打开所有已加载补丁的音频处理。

startwindow

只在此 ezadc~ 所在的补丁以及该补丁的子补丁中开启音频处理。关闭所有其他补丁中的音频处理。

stop

关闭所有已加载补丁的音频处理。

wclose

关闭 Audio Status 窗口。

输出

signal

左出口：来自通道 1 的音频输入。

右出口：来自通道 2 的音频输入。
