Max

jstrigger

按顺序执行 Javascript 指令

描述

jstrigger 对象与 trigger 对象类似，区别在于括号内键入的参数会传给 Javascript 求值器。关于 Javascript 在 Max 中的实现的更多信息，请参阅 Javascript in Max 手册。关于 Javascript 本身的完整信息，请查阅一本参考书，例如 O'Reilly 出版的 David Flanagan 所著《JavaScript 权威指南》。

参数

sequential-Javascript-instructions [numbers, symbols, or expressions] 可选

jstrigger 对象的参数既可以是常量，也可以是表达式。常量是数字或符号。对于每个常量都会创建一个出口；当对象在左入口收到消息时，该常量值会从对应的出口送出。例如，jstrigger 在参数为 ready set 74 时会先把 74 从右出口送出，接着把 set 从中间出口送出，再把 ready 从左出口送出。

表达式是包含在括号内的 Javascript 表达式。括号内可以包含不止一条 Javascript 语句，但你必须用分号（;）分隔这些语句。最后一条语句之后的分号不是必需的，return 一词也不是必需的。若要返回列表，你可以创建一个数组对象，也可以把各项放在方括号中并用逗号分隔。Javascript 允许你在逗号之间写入表达式。参见 Examples 一节。

对于每个表达式都会创建一个出口；当 jstrigger 对象在左入口收到消息时，该表达式的值会从对应的出口送出。

注意，在对象框中任何分号或逗号的使用都要求前面有一个反斜杠（\)字符，否则你会在 Max Console 中看到下面这条错误消息，并且该对象不会被创建：

* error: object box has comma or semicolon

此外，强烈建议使用单引号（'）而不是双引号来定义字符串字面量。使用双引号可能会在对象被保存并在补丁中重新创建时，在 jstrigger 中产生意想不到的结果。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

每个参数最近存储的值会被赋给 a 数组。然后按从右到左的顺序对对象中的表达式求值，每个表达式或常量的值从对应于该表达式的出口送出。

int

依据 Javascript 参数而定，与上下文相关/由用户指定。

参数：

  • input [int]

float

依据 Javascript 参数而定，与上下文相关/由用户指定。

参数：

  • input [float]

list

依据 Javascript 参数而定，与上下文相关/由用户指定。

参数：

  • input [list]

anything

依据 Javascript 参数而定，与上下文相关/由用户指定。

参数：

  • input [list]

输出

anything

当 jstrigger 对象在其入口收到消息时，表达式按从右到左的顺序求值，其结果从对应的出口按从右到左的顺序送出。
