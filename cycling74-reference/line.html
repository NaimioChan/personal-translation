Max

line

生成定时斜坡

描述

在指定的时间内生成从一个值到另一个值的斜坡和线段。

参数

initial [number] 可选

设置要存储在 line 中的初始值以及对象的输出类型（浮点或整数）。若没有参数，初始值为 0，输出类型为 int。

grain [number] 可选

为 grain 设置初始值：即数字送出的时间间隔。若未指定 grain，line 每 20 毫秒输出一个数字。允许的最小 grain 为 1 毫秒；任何小于 1 的数字都会被设为 20。

特性

compatmode [int] : 0

用于在导入用 Max 7.x 及更早版本创建的补丁时提供兼容性。把 compatmode 设为 1 即可使用旧版行为。

floatoutput [int] : 2

设置 line 对象的浮点输出模式。默认值为 2（auto）。
可选值：

0 = 'Off'（浮点输出关闭）
不输出浮点值。若 initial 参数是整数，floatoutput 会被设为关闭。

1 = 'On'（浮点输出打开）
若在 initial 参数中指定了浮点值，则输出浮点值。

2 = 'Auto'（浮点输出自动）
若距离 <= 1、line 没有 float 参数，且步长 < 0.4，则输出浮点值。

grain [float] : 20.

设置 grain 取值：即数字送出的时间间隔。默认值为 20 毫秒。允许的最小 grain 为 1 毫秒。

maxpoints [int] : 129

设置用户自定义点的最大数量。默认值为 129。若要允许更多的点，请使用 maxpoints 特性。

消息

int

左入口：该数字是目标值，应在中间入口的数字所指定的时间内到达该值。若自上一次目标值以来未指定过时间，时间被视为 0，line 会立即输出目标值。

注意：line 对象的输出类型由对象的第一个参数设置（参见参数）。

中间入口：该数字是到达目标值所需的时间，单位为毫秒。

右入口：该数字是定期送出中间数字的时间间隔（单位：毫秒）。

参数：

  • input [int]

float

执行与 int 相同的功能，但仅当对象参数为 float 时才处理浮点数。

参数：

  • input [float]

list

用各种列表组合来达到目标值。
在其中一种列表组合中，第一个数字指定起始值，后面跟一个逗号和一对数字。该对中的第一个数字指定目标值。该对中的第二个数字指定 line 到达目标值所用的总时间（单位：毫秒）。在这段时间内，数字会从当前存储的值到目标值之间以直线的形式定期输出。

这类列表的一个例子是 0, 1 1000 0 1000。在这个例子中，line 会在一秒内从起始值 0 到 1，然后再用一秒回到 0。第一条斜坡到达目标值后，下一条就开始。左入口随后收到的 list、float 或 int 会清除所有尚未生成的斜坡。

在另一种组合中，第一个数字指定目标值（其后不跟逗号），第二个数字指定 line 到达目标值所用的总时间（单位：毫秒）。第三个数字是可选的，用于设置 grain。grain 会影响数字送出的时间间隔。一旦在列表中设置了 grain，它们会覆盖默认值，直到手动重置。

这类列表的一个例子是 1 1000 100。在这个例子中，line 会在一秒内从当前值到 1，每 100 毫秒输出一个值。

若列表的元素个数大于三且为偶数，每一对元素被视为断点函数中的一个目标值-斜坡时间对。若列表的元素个数大于三且为奇数，最后一个元素会被忽略。

参数：

  • input [list]

clock

单词 clock 后面跟一个已存在的 setclock 对象的名称，会把 line 对象设置为由该 setclock 对象控制，而不是由 Max 内部的毫秒时钟控制。单独的单词 clock 会把 line 对象重新设置为使用 Max 常规的毫秒时钟。

参数：

  • setclock object name [symbol]

pause

左入口：暂停内部斜坡，但不改变目标值，也不清除待处理的目标-时间对。line 会继续输出收到 pause 消息时它当时的值，直到收到 resume 消息或输入新的斜坡为止。

resume

左入口：若 line 对象是因 pause 消息而暂停的，则恢复内部斜坡以及后续待处理的目标-时间对。

set

左入口：set 一词后面跟一个数字，会以该数字作为新的起始值，从该值继续前往下一个收到的目标值。该 set 消息还会让正在送出数字的 line 停止。

参数：

  • input [float]

stop

左入口：让 line 停止送出数字，直到收到新的目标值为止。

输出

bang

右出口：当 line 到达目标值时，会送出 bang。

注意：实际到达目标值所用的时间略少于指定的时间（时间减去 grain）。

int

左出口：数字会定期送出，描述一条朝目标值前进的直线。若在这条线完成之前又指定了新的目标值和时间，新线会从最近一次的输出值开始，以避免不连续。

若左入口收到的值没有附带时间值，它会立即被送出（时间被视为 0）。
