jit.gradient.ui

用于创建一维渐变矩阵的 GUI

描述

jit.gradient.ui 对象提供了一个便捷的 GUI，用于创建和操作 4 通道一维渐变矩阵。其功能与 jit.gradient 对象类似。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

设置对象的字体大小（单位：磅）。
可选值：

'8'

'11'
'12'
'13'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

alpha_last

单词 alpha_last 后跟一个 0 或 1，用于设置矩阵中哪个通道存放 Alpha 值（默认值 = 0）。alpha_last 被禁用（设为 0）时，输出格式为 ARGB。alpha_last 被启用（设为 1）时，输出格式为 RGBA。

bang

收到 bang 消息时，对象会把当前的渐变矩阵从其出口送出。

clear

单词 clear 会清除矩阵中除第一个（索引 0）之外的所有颜色。

move_pointer

单词 move_pointer 后跟一个指定指针索引的整数，以及一个取值在 0. - 1.0 范围内的浮点数，会把该指针索引定位到渐变范围上的相应位置。

output_matrix_dim

单词 output_matrix_dim 后跟一个整数，用于指定渐变矩阵的维度（大小）。该大小与输出矩阵的渐变分辨率相关；较小的尺寸会使渐变包含的色阶更少。

pointer_color

单词 pointer_color 后跟一个指定指针索引的整数，以及四个取值在 0. - 1.0 范围内的浮点数，用于设置渐变范围上某个指针索引的颜色。
