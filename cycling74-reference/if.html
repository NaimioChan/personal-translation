if

if/then/else 形式的条件语句

描述

按照以 if-then-else 形式给出的条件语句对输入求值。

参数

if [symbol] 可选

if 对象的参数以一条条件语句开头，其语法与 expr 相同。then 一词跟在条件语句之后，接着是一条消息表达式。消息表达式之后是可选的 else 和第二条消息表达式。
if 对条件表达式求值，若结果非零，则对 then 一词之后的消息表达式求值。否则，若提供了 else 消息，则对 else 一词之后的第二条消息表达式求值。

then, else [symbol] 可选

消息表达式与你在 message 框中输入的内容类似。

$i1, $f1, $s1 [symbol] 可选

对于可替换参数，要使用 $i1、$f1 或 $s1，而不是 $1。入口数量由输入了多少个不同的可变更参数决定。入口数量最多为 9。

send [symbol] 可选

不允许使用逗号或分号。要给远程的 receive 对象发送消息，可以在消息表达式前面加上 send，后面跟 receive 对象的名称。

out2 [symbol] 可选

消息表达式中的关键字 out2 会为 if 对象创建第二个出口，即右出口。若 out2 位于某条消息表达式之前，该表达式的结果会从右出口而不是左出口送出。

set

set 一词后面跟一个或多个数字时，会把这些数字当作各自来自不同入口来处理，用新值替换已存储的值，但不对条件语句求值，也不从出口送出任何内容。若消息中的数字少于入口数量，其余各入口中已存储的值保持不变。

参数：

  • set-input [list]

symbol

符号只能从第一个入口接收。若在第一个入口收到符号，它会替换与之关联的 $s 参数被存储起来，然后对表达式求值，只是符号不能参与比较，也不能与其他运算符一起使用。若该符号与某个 table 对象同名，你可以指定表中要取值的某个位置。

参数：

  • input [symbol]

输出

anything

参数中 then 或 else 部分之后的消息会从出口送出。若参数中有 out2 一词，就会有两个出口，跟在 out2 之后的消息会从右出口送出。若参数中有 send 一词，紧跟其后的词是一个 receive 对象的名称，而再往后的消息会发送给具有该名称的 receive 对象。
