Ableton DSP

abl.device.autofilter~

经典模拟滤波器仿真。

特性

circuit [int]

选择用于 Low-pass、High-pass、Band-pass、Notch 和 Morph 滤波器的滤波电路。
可选值：

0 = 'SVF'（状态变量滤波器）
声音干净的滤波器

1 = 'DFM'（DFM 滤波器）
DFM 滤波器在内部反馈更多自身失真，从而在从细微的滤波器扫频到温暖驱动之间获得宽广的音色范围。

djcontrol [float]

控制低通与高通滤波之间的过渡。大于 0.0 的取值会滤除低频，小于 0.0 的取值会滤除高频。滤波器谐振也会随滤波变化而偏移：接近 0.0% 的取值只会略微提升被强调的频率；随着取值接近 -1.0 或 1.0，这种提升会逐渐增强。 [-1., 1.]

drive [float]

在信号到达滤波器之前对它施加额外的输入驱动以增加失真。取 0.0 时信号保持干净、不被改变。随着 drive 取值增大，多数滤波器类型会逐渐混入失真，得到更饱和的声音。 [0., 1.]

envamount [float]

决定包络调制对滤波器频率的影响程度。 [-1., 1.]

envattack [float]

设置包络对上升的输入电平响应有多快。 [0., 0.1]

envhold [int]

打开时，包络会先完成整个起音阶段，再开始释音阶段。

envrelease [float]

设置包络对下降的输入电平响应有多快。 [0., 3.]

filterslope [int]

设置 low-pass、high-pass、band-pass、notch 与 notch + LP 滤波器的滤波器斜率。
可选值：

0 = '12dB'
1 = '24dB'

filtertype [int]

设置滤波器类型
可选值：

0 = 'Low-pass'
1 = 'High-pass'
2 = 'Band-pass'
3 = 'Notch'
4 = 'Morph'
5 = 'DJ'
6 = 'Comb'
7 = 'Resampling'
8 = 'Notch+LP'
9 = 'Vowel'

frequency [float]

设置滤波器截止频率 [20., 20000.]

lfoamount [float]

设置 LFO 调制的量。 [0., 1.]

lfomorph [float]

使 LFO 波变形形。 [-1., 1.]

lfophase [float]

调整左右 LFO 通道之间的偏移。为 180 度时，两个 LFO 通道完全反相。 [0., 360.]

lfophaseoffset [float]

沿波形移动两个 LFO 通道的起始点。 [0., 360.]

lfoquantize [int]

设置 LFO 的量化模式。
可选值：

0 = 'None'（None）
不量化

1 = 'Steps'（Steps）
把 LFO 周期划分为若干离散的间隔。

lforate [float]

设置 LFO 的速率，单位为 Hz。 [0.1, 60.]

lfosmoothing [float]

对 LFO 的 Sample and Hold 波形施加平滑处理。 [0., 1.]

lfospin [float]

使左右两个 LFO 相互失谐。 [0., 0.5]

lfosteps [int]

定义用多少个离散步来划分 LFO 周期。

lfostereo [int]

设置 LFO 的立体声偏移模式。
可选值：

0 = 'Phase'（Phase）
用度数偏移左右两个调制通道。

1 = 'Spin'（Spin）
使 LFO 的左右通道逐渐分离。

lfowaveform [int]

设置 LFO 使用的波形。
可选值：

0 = 'Sine'
1 = 'Triangle'
2 = 'Analog Triangle'
3 = 'Triangle 8-Step'
4 = 'Triangle 16-Step'
5 = 'Saw Up'
6 = 'Saw Down'
7 = 'Square'
8 = 'Random'
9 = 'Random Sample and Hold'
10 = 'Wander'
11 = 'Ramp Up'
12 = 'Ramp Down'
13 = 'Sharktooth'

mix [float]

设置输出信号的干/湿比。[0., 1.]

morph [float]

设置滤波器在其变形循环中的位置。
对于 Morph 滤波器，可以在低通、带通与高通滤波之间平滑过渡。
对于 Comb 滤波器，可以在滤波器 frequency 设定的各倍数频率处出现的峰或陷波之间移动滤波器。
对于 Notch+LP 滤波器，可以相对于低通截止频率移动陷波的位置。对于 Vowel 滤波器，可以逐步对共振峰的增益做归一化。 [0., 1.]

morphslope [int]

设置 Morph 滤波器的滤波器斜率。
可选值：

0 = '6dB'
1 = '12dB'
2 = '24dB'
3 = '48dB'

output [float]

定义设备输出处的湿信号电平，单位为 dB。 [-70., 0.]

oversample [int]

启用过采样高音质模式，有助于减少不需要的伪影。

resonance [float]

定义在 frequency 指定的截止频率处的强调量。 [0., 1.]

sceq [int]

启用后，内部包络只会对由所设滤波器类型与 Sidechain EQ 控件指定的频率范围作出反应。默认选择的是高通滤波器，因此包络主要响应瞬态，而合成器包络、底鼓尾音之类的较慢成分会被忽略。

sceqtype [int]

选择用于侧链 EQ 的滤波器类型。
可选值：

0 = 'Low Shelf'
1 = 'Bell'
2 = 'High Shelf'
3 = 'Low-pass'
4 = 'Band-pass'
5 = 'High-pass'

scfrequency [float]

设置侧链输入 EQ 滤波的频率。 [30., 15000.]

scgain [float]

调整外部侧链信号的电平。 [-15., 15.]

sclisten [int]

启用此开关可旁通设备的输出，使只有侧链输入可闻。这对微调侧链设置很有用。

scmono [int]

把侧链信号转换为单声道，使包络跟随器调制在左右通道上完全一致。启用时，只把对象的第三个入口用作侧链信号。禁用时，第三个与第四个入口都会被使用。

scresonance [float]

设置侧链 EQ 滤波器的谐振。 [0.1, 12.]

softclip [int]

启用后对设备输出施加软削波。这对限制高谐振值造成的峰值很有用。

vowelformant [float]

在下列元音之间变形：a、e、i、o 和 u。 [0., 1.]

vowelpitch [float]

按设定的半音数向上或向下移动共振峰。 [-36., 36.]

ins [symbol]

声明额外的入口，用于以事件速率或信号速率控制 float 类型的特性。已映射到入口的已声明特性将被忽略。该特性只能在对象实例化时设置。
