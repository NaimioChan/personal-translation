mc.range~

生成一个具有一段常量取值范围的多通道信号

描述

mc.range~ 对象生成一个多通道信号，其中填充着分布在某一给定范围内的常量值。

参数

size [int] 可选

设置多通道输出中的通道数。

特性

chans [int]

chans 特性设置输出多通道信号的通道数，决定将用多少个通道来定义该范围。若在音频已开启时修改 chans，多出的通道会被设为零。音频重启后，输出通道数会被设为 chans 的值。

exp [float] : 0.

允许对该范围进行指数缩放；其取值是对范围内每个元素的位置（介于 0 - 1 之间）施加的幂函数的指数。

hi [float]

设置计算各通道输出值时使用的高值。相对于 lo 和 hi 特性的实际取值，由 inclusive 特性的设置决定。

inclusive [int]

决定在计算每个输出通道的取值时如何使用端点值。
可选值：

0 = 'Neither'（忽略端点）
计算 mc 通道取值时既不使用低端点值也不使用高端点值。例如，5 个通道，lo 为 0.0 且 lo 为 1.0 时会生成 0.17、0.33、0.5、0.67 和 0.83 这些信号值。

1 = 'Both'（使用端点）
计算 mc 通道取值时，第一个通道使用低端点值，最后一个通道使用高端点值。例如，5 个通道，lo 为 0.0 且 lo 为 1.0 时会生成 0.0、0.25、0.5、0.75 和 1.0 这些信号值。

2 = 'Low Only'（仅使用低值）
计算 mc 通道取值时，第一个通道使用低端点值，其余通道取值据此推算。例如，5 个通道，lo 为 0.0 且 lo 为 1.0 时会生成 0.0、0.2、0.4、0.6 和 0.8 这些信号值。

3 = 'High Only'（仅使用高值）
计算 mc 通道取值时，最后一个通道使用高端点值，其余通道取值据此推算。例如，5 个通道，lo 为 0.0 且 lo 为 1.0 时会生成 0.2、0.4、0.6、0.8 和 1.0 这些信号值。

lo [float]

设置计算各通道输出值时使用的低值。相对于 lo 和 hi 特性的实际取值，由 inclusive 特性的设置决定。

reflection [float] : 1.

reflection 特性设置范围内的一个相对位置，输出在该位置达到高值，然后返回到低值。默认情况下，reflection 的值为 1，对输出范围没有影响。若 reflection 被设为 0 到 1 之间的某个值，则输出会在输出通道空间的中间某处达到高值，并在输出多通道信号的最后一个通道上返回到低值。当 reflection 趋近于零时，输出开始变得像一个反转的范围；当 reflection 被设为 0 时，输出被完全反转。

消息

bang

bang 消息会促使把当前的范围取值以一系列 setvalue 消息从右出口送出。例如，对于从 0 到 1 的三个取值构成的范围，mc.range~ 会输出 setvalue 1 0、setvalue 2 0.5 和 setvalue 3 1.0。在右出口的输出之后，所有范围取值组成的列表会从中间出口送出。

signal

若把多通道信号连接到左入口，则前两个通道的取值决定输出范围，覆盖 lo 和 hi 特性的取值。
