Jitter

jit.avc

控制 FireWire VTR

描述

使用 1394 AV/C 协议与 FireWire VTR 设备（例如数码相机和 DV 录像机）通信。可以用它通过消息控制这些设备的走带。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

close

关闭 AV/C 连接。若删除该对象，或关闭包含该对象的补丁，连接会自动关闭。

custom

向 DV 设备发送自定义的数据串。消息通常以一串十六进制数发送。可接受的消息由 1394 Trade Association 记录。相关规范是 "AV/C Tape Recorder/Player Subunit"。

参数：

  • sequence [list]

fastwind

使走带快退。

ff

使走带快进。

getdevice

以 device active-device 的形式，把当前活动设备的名称从对象右出口送出。

gettime

以 time DVdevicemedia-time 的形式，把当前活动设备的名称从对象右出口送出。

gettransport

gettransport 消息会把它所连接的 VTR 设备走带的精确状态从 jit.avc 对象的右出口报告出来。

open

若能找到兼容设备，就打开到该设备的 AV/C 连接。

pause

暂停走带播放。

sf6：以慢速正向特效速度播放

sf3：以慢速正向特效速度播放
sf2：以慢速正向特效速度播放

sr：以最慢的慢速反向特效速度播放（sr = 最慢，sr6 = 慢，sr1 = 最快）
sr6：以慢速反向特效速度播放
sr5：以慢速反向特效速度播放

参数：

  • command [symbol]

record

把 DV 设备设为录制。允许使用以下可选参数：
recpause：在录制所有信号时暂停
insertvideo：用新信号替换视频信号，但保持介质上其他任何信号不变
insertaudio：用新信号替换音频信号，但保持介质上其他任何信号不变
insertav：用新信号替换音频和视频信号，但保持介质上其他任何信号不变
insertsubcode：用新信号替换子码信号，但保持介质上其他任何信号不变
insertvideopause：暂停录制信号，并把录制模式设为 record insertvideo
insertaudiopause：暂停录制信号，并把录制模式设为 record insertaudio
insertavpause：暂停录制信号，并建立录制模式 record insertav
insertsubcodepause：暂停录制信号，并把录制模式设为 record insertsubcode

参数：

  • command [symbol]

recpause

在录制所有信号时暂停。

rewind

把走带倒回。

stop

使走带停止。

time

使所连接的 DV 设备在任何已加载的介质上定位到指定的时间。时间由四个整数参数指定，分别表示小时、分钟、秒和帧。许多设备不支持此功能。
