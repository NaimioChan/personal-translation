MSP

round~

对输入信号取值取整

描述

用 round~ 对象把输入的信号舍入到某个整数倍。

讨论

你可以设置该对象的 'nearest' 特性，以决定它是舍入到绝对最近的整数倍，还是舍入到该取值与零之间最近的整数倍（对正数来说这会向下舍入）。默认情况下该特性处于开启状态。

参数

int or float [number] 可选

设置输入信号要舍入到的取值。默认值为 0.（不做改动）。

特性

nearest [int]

置为 1（默认值）时，round~ 对象会舍入到指定信号取值的最近倍数。

注意：该特性并不设置舍入步长（步长使用 round~ 对象的右入口设置），它只是指定要进行到最近信号取值的舍入。下面是一些例子：

舍入间隔设为 3、nearest 特性设为 1 时：
输入信号取值 5.8 会返回 6
输入信号取值 3.7 会返回 3
输入信号取值 -1 会返回 0
输入信号取值 -2.7 会返回 -3

舍入间隔设为 3、nearest 特性设为 0 时：
输入信号取值 5.8 会返回 3
输入信号取值 3.7 会返回 3
输入信号取值 -1 会返回 0
输入信号取值 -2.7 会返回 0

消息

int

右入口：一个 int 会使输入舍入到指定数字的最近倍数。若该入口连接了信号，int 消息会被忽略。

参数：

  • rounding-multiple-specifier [int]

float

右入口：一个 float 会使输入舍入到指定数字的最近倍数。若该入口连接了信号，float 消息会被忽略。

参数：

  • rounding-multiple-specifier [float]

signal

左入口：取值会被舍入的信号。

右入口：其取值被用于舍入的信号。左入口收到的信号取值会舍入到绝对最近的整数倍，或者舍入到本入口收到的取值与 0 之间最近的整数倍（更多信息见 nearest 消息）。

输出

signal

舍入后的输入信号。
