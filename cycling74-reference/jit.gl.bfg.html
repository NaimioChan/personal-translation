jit.gl.bfg

程序化基函数纹理生成器

描述

从程序化基函数库生成 OpenGL 纹理输出。这些函数在显卡上作为 OpenGL GLSL 着色器处理。函数分为三类：噪声、分形与扭曲。

特性

adapt [int] : 1

启用对输入的自适应（默认值 = 1）。启用后，纹理输出维度将与输入维度一致。

basis [symbol]

用于求值的基函数名称。（默认值 = noise.perlin）
可选值：

'noise.perlin'（ 经典 Perlin 噪声，周期性变体）
'noise.simplex'（ Simplex 加权伪随机取值）
'noise.cell'（ 相干的块状噪声）
'noise.checker'（ 周期性棋盘方格）
'fractal.multi.rigid'（ 带锐利脊线的乘法分形）
'fractal.multi.hybrid'（ 加性与乘性混合的分形）
'fractal.fbm'（ 分形布朗运动）
'fractal.multi'（ 相似度随尺度变化的乘法分形）
'fractal.hetero'（ 异质乘法分形）
'noise.voronoi'（ 距离加权的伪随机特征点）
'noise.voronoi.crackle'（ Voronoi 的变体）
'noise.voronoi.smooth'（ 带距离过滤的 Voronoi 变体）
'noise.voronoise'（ 广义 Voronoi 与噪声）
'noise.voronoi.id'（ 单元格按 ID 着色的 Voronoi 变体）
'distorted'（ 定义域扭曲的组合噪声）
'distorted.2axis'（ 沿 2 个轴的扭曲）
'input.distorted'（ 输入纹理的扭曲）
'input.distorted.2axis'（ 沿 2 个轴的输入纹理扭曲）

basis.inner [symbol]

当 basis 为扭曲类型函数时设置内层基函数（默认值 = noise.perlin）。
可选值：

'noise.perlin'
'noise.simplex'
'noise.cell'
'noise.checker'
'fractal.multi.rigid'
'fractal.multi.hybrid'
'fractal.fbm'
'fractal.multi'
'fractal.hetero'
'noise.voronoi'
'noise.voronoi.crackle'
'noise.voronoi.smooth'
'noise.voronoise'
'noise.voronoi.id'

basis.outer [symbol]

当 basis 为扭曲类型函数时设置外层基函数（默认值 = noise.simplex）。
可选值：

'noise.perlin'
'noise.simplex'
'noise.cell'
'noise.checker'
'fractal.multi.rigid'
'fractal.multi.hybrid'
'fractal.fbm'
'fractal.multi'
'fractal.hetero'
'noise.voronoi'
'noise.voronoi.crackle'
'noise.voronoi.smooth'
'noise.voronoise'
'noise.voronoi.id'

colorize [int]

用余弦函数对输出纹理着色（默认值 = 0）。关于如何调整着色，参见 palette 特性。

dim [2 ints]

adapt 被禁用时的纹理输出维度（默认值 = 256 256）

dimscale [2 floats]

输出的维度缩放因子（默认值 = 1 1）。用于对纹理输出做升采样或降采样。
output.dim = input.dim*dimscale

distortion [float]

调整扭曲类型函数的扭曲量（默认值 = 1）。

filter [symbol]

过滤模式
可选值：

'none'
'nearest'
'linear'

fractal_params [4 floats]

调整分形类型函数的参数。这些参数依次对应 h、lacunarity、offset 和 gain。并非所有分形函数都响应所有参数。未使用的参数被设为 0。
fractal.multi.rigid 使用 h、lacunarity、offset、gain
fractal.multi、fractal.hetero 和 fractal.multi.hybrid 使用 h、lacunarity、offset
fractal.fbm 使用 h、lacunarity

offset [2 floats]

生成空间网格坐标时使用的各维度偏移（默认值 = 0 0）。

out_name [32 symbols] 只读

输出纹理名称

palette [3 floats]

启用 colorize 时调整着色效果（默认值 = 0 1 2）。

rect [4 floats]

slab 几何体矩形（默认值 = 0 0 1 1）。这四个取值表示几何体矩形左、下、右、上四边的归一化坐标。要水平翻转图像，请使用 rect 1 0 0 1；要垂直翻转图像，请使用 rect 0 1 1 0。

rectangle [int]

启用内部纹理对象上的纹理矩形模式（默认值 = 1）。启用时，内部 GL 纹理被当作矩形纹理处理，从 GLSL 着色器中取样时必须用 sampler2DRect 引用、用 texture2DRect 取样。禁用时，纹理维度会被升采样到最接近的 2 的幂数值，并且必须用 sampler2D 和 texture2D 引用和取样。某些纹理特性和 GLSL 效果要求禁用 rectangle 模式。

scale [2 floats]

生成空间网格坐标时使用的各维度缩放系数（默认值 = 1 1）。

time [float]

时间动画参数

type [symbol]

输出纹理数据类型（默认值 = auto）。当 type 为 auto 时，类型由输入纹理或矩阵的类型设定。
可选值：

'auto'（ 自适应输入数据类型 ）
'char'（ 8 位无符号字节 ）
'long'（ 32 位整数 ）
'half'（ 16 位浮点数 ）
'float'（ 32 位浮点数 ）
'float16'（ 16 位浮点数 ）
'float32'（ 32 位浮点数 ）

voronoi_crackle [3 floats]

Voronoi crackle 效果取值（默认值 = 8.0 2.0 0.5）。仅在 basis 为 noise.voronoi.crackle 时使用

voronoi_jitter [float]

Voronoi 抖动量（默认值 = 1）。仅在 basis 为 noise.voronoi 类型函数时使用。

voronoi_shade [float]

当 basis 为 noise.voronoi.id 时模拟单元格明暗效果（默认值 = 0.5）。

voronoi_smooth [float]

当 basis 为 noise.voronoi.smooth 时调整平滑系数（默认值 = 64）。

voronoise_amt [float]

当 basis 为 noise.voronoise 时调整 Voronoi 与噪声函数之间的混合比例（默认值 = 0）。

zoom [float]

同时调整 scale 和 offset 的取值，以模拟相对函数中心推近拉远（默认值 = 1）。

OB3D 特性

alpha_mode [symbol]

用独立的 alpha 混合函数与方程对混合过程进行更精细的控制。
可选值：

'link' ( 与 blend_mode 链接（默认值） )
'max' ( 取最大值 )
'add' ( 求和 )
'replace' ( 用源替换目标 )
'ignore' ( 忽略源 )

blend [symbol]

具名混合模式。可选值有：
add = blend_mode 1 1
multiply = blend_mode 2 1
screen = blend_mode 4 1
exclusion = blend_mode 4 5
colorblend = blend_mode 3 4
alphablend = blend_mode 6 7
coloradd = blend_mode 3 1
alphaadd = blend_mode 6 1

blend_enable [int]

混合标志（默认值 = 0）该标志置位时，所有被渲染的对象都启用混合。

blend_mode [2 ints]

与混合模式关联的源通道和目标通道（默认值 = 6 7）混合模式以 src_blend_mode dst_blend_mode 的形式给出。支持的取值有：
0 = zero
1 = one
2 = destination color
3 = source color
4 = one minus destination color
5 = one minus source color
6 = source alpha
7 = one minus source alpha
8 = destination alpha
9 = one minus destination alpha
10 = source alpha saturate

depth_clear [int]

深度缓冲清除标志（默认值 = 0）该标志置位时，渲染对象之前会清除深度缓冲。

depth_enable [int]

深度缓冲标志（默认值 = 1）该标志置位时，启用深度缓冲。

depth_write [int]

深度写入标志（默认值 = 1）。该标志置位时，启用对深度缓冲的写入。若 depth_enable 已关闭，则此设置无效。

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

name [symbol]

实例名称（默认值 = UID）

texture [8 symbols]

要应用的纹理名称（默认值 = none）。若指定了多个纹理，则使用多重纹理。

可选值：

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

可选值：

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

OB3D 消息

bang

等价于 draw 消息。

draw

在具名的绘制目标中绘制该对象。若支持 matrixoutput 特性且其设为 1，几何矩阵会从对象的左出口送出。

drawraw

等价于 draw，且 inherit_all 特性设为 1。

drawimmediate

等价于 draw，但忽略任何可能的渲染器设置

jit_gl_texture

把 texture-name 指定的纹理绑定到该对象。等价于把 texture 特性设为 texture-name。

参数：

  • texture-name [symbol]
