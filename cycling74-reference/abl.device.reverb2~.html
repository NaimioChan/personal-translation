Ableton DSP

abl.device.reverb2~

反馈延迟网络混响

描述

一种带早期反射、扩散网络、输入滤波与冻结功能的混响音频效果。混响的输入信号会先经过高切与低切滤波器，再经过早期反射以及产生混响尾音的扩散网络进行处理。

参数

无。

特性

bandpassfreq [float]

控制输入滤波器的中心频率。[50., 18000.]

bandwidth [float]

控制输入滤波器频带的宽度。[0.5, 9.]

chorus [int]

开启或关闭扩散网络的合唱效果。

chorusamount [float]

调整扩散网络中合唱调制的幅度。[0.01, 4.]

chorusrate [float]

调整扩散网络中合唱调制的频率。[0.01, 8.]

cut [int]

通过阻止输入信号叠加到已冻结的混响上来修改 freeze。关闭时，输入信号会影响扩散的幅度。

decaytime [float]

调整扩散网络的尾音衰减到其初始幅度的 1/1000（-60 dB）所需的时间。[0.2, 60.]

density [int]

通过改变并行处理链的数量来控制混响输出的密度。更高的设置需要更多 CPU 资源。
可选值：

0 = 'Sparse' ( Sparse density )
最低的密度设置，并行处理链最少。占用的 CPU 资源最少。

1 = 'Low' ( Low density )
较低的密度设置，并行处理链较少。

2 = 'Mid' ( Medium density )
中等密度设置，并行处理链适中。

3 = 'High' ( High density )
最高的密度设置，并行处理链最多。占用的 CPU 资源最多。

diffuse [float]

调整扩散的幅度。[0.03, 1.9953]

diffusion [float]

控制扩散网络的密度。较低的取值会产生较单薄的回声，较高的取值会产生更密的回声。[0.001, 0.96]

flat [int]

当 freeze 启用时，绕过扩散网络滤波器。

freeze [int]

把混响扩散网络内的反馈提升到 100%，使混响无限延续。冻结也可以用来测试输出信号，或生成丰富、持续低鸣的纹理。

highcut [int]

启用或禁用输入信号的高切滤波器。禁用滤波器可以节省一些 CPU 开销。

highpass [int]

启用或禁用扩散网络中的高频滤波器。该滤波器提供随频率变化的混响衰减。可以关闭它以节省 CPU 消耗。

highpassfreq [float]

设置扩散网络中高频滤波器的频率。[20., 16000.]

highpasstype [int]

设置扩散网络中高频滤波器的滤波器类型。
可选值：

0 = 'Shelf' ( Shelving filter )
1 = 'Lowpass' ( Low-pass filter )

highpassgain [float]

设置扩散网络中高频滤波器的幅度。[0.2, 1.]

lowcut [int]

启用或禁用输入信号的低切滤波器。禁用滤波器可以节省 CPU 开销。

lowshelf [int]

启用或禁用扩散网络中的低频搁架式滤波器。该滤波器提供随频率变化的混响衰减。可以关闭它以节省 CPU 消耗。

lowshelffreq [float]

设置扩散网络中低频搁架式滤波器的频率。[20., 15000.]

lowshelfgain [float]

设置扩散网络中低频搁架式滤波器的增益。[0.2, 1.]

mix [float]

调整输入信号（干）与处理后信号（湿）之间的平衡。[0., 1.]

predelay [float]

控制第一个早期反射开始之前的延迟时间，单位为毫秒。人对房间大小的印象部分取决于这一延迟。自然声音的典型取值在 1ms 到 25ms 之间。[0.5, 250.]

reflections [float]

调整早期反射的幅度。[0.03, 1.9953]

scale [float]

控制扩散的粗糙度。较高的取值往往会产生更暗的声音。[0.05, 1.]

shape [float]

塑造早期反射的突出程度，以及它们与扩散声音的重叠程度。取值较小时反射衰减得更渐进，取值较大时反射衰减得更迅速。[0., 1.]

size [float]

控制虚拟房间的大小。取值较高时会给混响带来一种游移、扩散的延迟效果。取值很小时会带来强烈的染色、金属感。[0.222, 500.]

smoothing [int]

指定 size 特性的取值被调整时的行为
可选值：

0 = 'None' ( No smoothing )
扩散网络的延迟时间立即改变，改变 Size 取值时可能造成伪影。

1 = 'Slow' ( Slow smoothing )
新的延迟时间在更长的时间段内更新，在两个取值之间过渡时声音更平滑。

2 = 'Fast' ( Fast smoothing )
新的延迟时间在更短的时间段内更新，在两个取值之间过渡时声音更平滑。

spin [int]

开启或关闭早期反射的调制。

spinamount [float]

调整早期反射调制的幅度。[2., 55.]

spinrate [float]

调整早期反射调制的频率。[0.074, 1.3]

stereo [float]

确定输出立体声像的宽度。在 120 度时，每只耳朵收到的混响通道与另一只耳朵无关。取值为 0 时，输出信号为单声道。[0., 120.]
