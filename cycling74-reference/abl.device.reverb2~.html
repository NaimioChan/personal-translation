Ableton DSP

abl.device.reverb2~

Feedback Delay Network Reverb

描述

A reverb audio effect with early reflections, a diffusion network, input filtering, and freeze capabilities. The reverb's input signal passes through high- and low-cut filters before being processed through early reflections and a diffusion network that creates the reverberant tail.

参数

无。

特性

bandpassfreq [float]

Controls the center frequency of the input filter. [50., 18000.]

bandwidth [float]

Controls the width of the input filter band. [0.5, 9.]

chorus [int]

Toggles the chorus effect of the Diffusion Network on and off.

chorusamount [float]

Adjusts the amplitude of the chorus modulation in the diffusion network. [0.01, 4.]

chorusrate [float]

Adjusts the frequency of the chorus modulation in the diffusion network. [0.01, 8.]

cut [int]

Modifies freeze by preventing the input signal from adding to the frozen reverberation. When off, the input signal will contribute to the diffused amplitude.

decaytime [float]

Adjusts the time required for the diffusion network's tail to drop to 1/1000th (-60 dB) of its initial amplitude. [0.2, 60.]

density [int]

Controls the density of the reverb's output by changing the amount of parallel processing chains. Higher settings require more CPU resources.
Possible values:

0 = 'Sparse' ( Sparse density )
Lowest density setting with minimal parallel processing chains. Uses the least CPU resources.

1 = 'Low' ( Low density )
Low density setting with few parallel processing chains.

2 = 'Mid' ( Medium density )
Medium density setting with moderate parallel processing chains.

3 = 'High' ( High density )
Highest density setting with maximum parallel processing chains. Uses the most CPU resources.

diffuse [float]

Adjusts the amplitude of the diffusion. [0.03, 1.9953]

diffusion [float]

Controls the Diffusion Network's density. Low values produce thinner sounding echoes while higher values produce denser ones. [0.001, 0.96]

flat [int]

Bypasses the diffusion network filters when freeze is enabled.

freeze [int]

Increases the feedback within the reverb's diffusion network to 100% so that reverberation will sustain endlessly. Freeze can also be used to test the output signal or to generate rich, droney textures.

highcut [int]

Enables or disables the high-cut filter for the input signal. Disabling the filter will save some CPU power.

highpass [int]

Enables or disables the high-frequency filter in the diffusion network. This filter provides frequency-dependent reverberation decay. May be turned off to save CPU consumption.

highpassfreq [float]

Sets the frequency of the high-frequency filter in the diffusion network. [20., 16000.]

highpasstype [int]

Sets the type of filter for the high-frequency filter in the diffusion network.
Possible values:

0 = 'Shelf' ( Shelving filter )
1 = 'Lowpass' ( Low-pass filter )

highpassgain [float]

Sets the amplitude of the high-frequency filter in the diffusion network. [0.2, 1.]

lowcut [int]

Enables or disables the low-cut filter for the input signal. Disabling the filter can save CPU power.

lowshelf [int]

Enables or disables the low-frequency shelf filter in the diffusion network. This filter provides frequency-dependent reverberation decay. May be turned off to save CPU consumption.

lowshelffreq [float]

Sets the frequency of the low-frequency shelf filter in the diffusion network. [20., 15000.]

lowshelfgain [float]

Sets the gain of the low-frequency shelf filter in the diffusion network. [0.2, 1.]

mix [float]

Adjusts the balance between the input signal (dry) and the processed signal (wet). [0., 1.]

predelay [float]

Controls the delay time, in milliseconds, before the onset of the first early reflection. One's impression of the size of a room depends partly on this delay. Typical values for natural sounds range from 1ms to 25ms. [0.5, 250.]

reflections [float]

Adjusts the amplitude of the early reflections. [0.03, 1.9953]

scale [float]

Controls the coarseness of the diffusion. Higher values tend to produce a darker sound. [0.05, 1.]

shape [float]

Sculpts the prominence of early reflections, as well as their overlap with the diffused sound. With small values the reflections decay more gradually, with large values the reflections decay more rapidly. [0., 1.]

size [float]

Controls the size of the virtual room. A high value will lend a shifting, diffused delay effect to the reverb. A very small value will give it a highly colored, metallic feel. [0.222, 500.]

smoothing [int]

Specifies the behavior of the size attribute when its value is adjusted
Possible values:

0 = 'None' ( No smoothing )
The Diffusion Network's delay times are changed immediately, which can cause artifacts when changing the Size value.

1 = 'Slow' ( Slow smoothing )
New delay times are updated over a longer time period, which results in a smoother sound when transitioning between values.

2 = 'Fast' ( Fast smoothing )
New delay times are updated over a shorter time period, which results in a smoother sound when transitioning between values.

spin [int]

Toggles the modulation of the early reflections on and off.

spinamount [float]

Adjusts the amplitude of the early reflections modulation. [2., 55.]

spinrate [float]

Adjusts the frequency of the early reflections modulation. [0.074, 1.3]

stereo [float]

Determines the width of the output's stereo image. At 120 degrees, each ear receives a reverberant channel that is independent of the other. At 0, the output signal is mono. [0., 120.]
