mc.tapin~

延迟线的输入

描述

mc.tapin~ 接收一个多通道输入并把它复制进一条延迟线。借助 mc.tapout~，你可以在各不相同的延迟时间上从该延迟线中读取。你必须把一个 mc.tapin~ 对象的出口连接到你想与这条延迟线一起使用的 mc.tapout~ 对象。注意这并不是信号连接，因为对象之间没有信号流动。它只是一种表明这些对象共享同一条延迟内存的方式。

参数

maximum-delay [number] ms 可选

最大延迟时间，单位为毫秒。它决定延迟线内存的大小。若在对象创建之后提高了采样率，mc.tapin~ 会尝试重新调整延迟线的尺寸。若没有给出参数，默认的最大延迟时间为 100 毫秒。

消息

int

左入口：一个 int 会以毫秒为单位指定的新最大延迟时间重新设置延迟线内存的大小（这会清空延迟线的内存，可能在输出中产生咔嗒声）。

参数：

  • memory-size [int]

float

左入口：一个 float 会以毫秒为单位指定的新最大延迟时间重新设置延迟线内存的大小（这会清空延迟线的内存，可能在输出中产生咔嗒声）。

参数：

  • memory-size [float]

clear

清空延迟线的内存（这可能在输出中产生咔嗒声）。

freeze

freeze 一词后面跟一个非零数字时，会让 mc.tapin~ 冻结其缓冲区内存。这意味着对象会一直把它在冻结那一刻已经记录进内存的内容从出口播放出来，不再记录任何新的输入。freeze 一词后面跟 0 时，会把对象重置为其默认状态，即不断把任何给定输入记录并重新记录进其内存缓冲区，并在指定的延迟时间之后把它输出。

参数：

  • behavioral-flag (0 or nonzero) [int]

signal

信号会被写入一条可由 mc.tapout~ 对象读取的延迟线。

输出

tap

为了让延迟线正常工作，必须把 mc.tapin~ 的出口连接到 mc.tapout~ 的左入口。它不能连接到任何其他对象。
