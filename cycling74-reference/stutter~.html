MSP

stutter~

用于颗粒播放的信号捕获缓冲区

描述

stutter~ 对象保存其信号输入（左入口）的历史。收到一个 int（左入口）时，它会把最近收到的那么多个采样点复制到另一个播放缓冲区。该缓冲区可以由其相位 0-1（右入口）循环读取。收到 bang（左入口）或触发信号（中间入口）时，最近的整数个采样点会被复制到播放缓冲区。

参数

max-buffer-length [int] samples 可选

缓冲区的最大长度，以采样点数计。它决定录音缓冲区的内存大小。对象被触发时，录音缓冲区的一部分会被复制到播放缓冲区。

initial-buffer-size [int] samples 可选

在收到触发时从录音缓冲区复制到播放缓冲区的初始缓冲区大小，以采样点数计。

trigger-polarity [int] 可选

中间入口接受触发信号所用的极性。若参数大于 0，stutter~ 接受正触发；否则 stutter~ 接受负触发。

number-of-copied-samples [int] samples 可选

在 perform 循环（信号向量大小）的每次迭代中从录音缓冲区复制到播放缓冲区的采样点数。该值越大，stutter~ 对象的内存需求越小，CPU 需求越大。

number-of-outputs [int] 可选

可选的第五个参数让你指定 stutter~ 对象在从播放缓冲区播放时所用的多个独立信号输出。默认值为 1，最大值为 30。stutter~ 对象的相位信号输入个数也由该参数决定。

消息

bang

左入口：bang 会使最近一批录制的采样点被复制到播放缓冲区。你可以用 bang 代替中间入口的触发信号，也可以与它配合使用。

int

左入口：指定播放缓冲区的大小（以采样点数计）。它可以是任何不超过 stutter~ 的第一个参数所决定的最大内存的数值。

参数：

  • playback-buffer-size [int]

ampvar

单词 ampvar 后面跟一个浮点数，指定输出信号中随机的幅度变化。默认值为 0（无变化）。

参数：

  • random-amplitude-variation [float]

clear

清除该对象的采样内存。

dropout

单词 dropout 后面跟一个浮点数，决定播放信号丢音的百分比概率（即 'gapping' 或不出声）。默认值为 0（不丢音）。

参数：

  • drop-out-chance [float]

maxsize

单词 maxsize 后面跟一个数字，设置缓冲区的最大大小，以采样点数计。

参数：

  • max-buffer-size [int]

polarity

单词 polarity 后面跟一个 0 或 1，把 stutter~ 的触发极性分别改为负或正。

参数：

  • trigger-polarity [int]

print

单词 print 会让该对象在 Max Console 中打印其所有参数设置的详细清单。

repeat

单词 repeat 后面跟一个浮点数，决定录音缓冲区不被复制到播放缓冲区、从而使上一次的播放缓冲区被重复的百分比变化。默认值为 0（不重复）。

参数：

  • repeat-chance [float]

setbuf

单词 setbuf 后面跟缓冲区名称、采样点偏移量和通道这几个参数，会把指定的采样点复制到具名的 buffer~ 对象。注意：stutter~ 始终把其内部缓冲区用作播放缓冲区；如有需要，被复制的采样点可以送往具名的 buffer~ 对象，以作他用。把指定数量的内存移动到该缓冲区所需的时间为 n/m，其中 n 是被复制的采样点数，m 是 stutter~ 对象的第四个参数。

参数：

  • buffer-name [symbol]
  • sample-offset [int]
  • channel-number [int]

signal

左入口：送入左入口的信号会存储在录音缓冲区中，它们可以被复制到播放缓冲区并用作播放源。

中间入口：接受触发信号，该信号可指定为正或负。当信号按正确的方向改变极性时，从左入口录制的采样点会被复制到播放缓冲区。

右入口及后续入口：每个入口 0-1 范围内的相位信号输入控制该入口的播放缓冲区输出速度。stutter~ 对象中相位入口的个数用第五个参数设置；默认只有一个入口。指定多个相位入口可以让你在采样缓冲区中指定多个播放点。

输出

signal

所有出口：stutter~ 对象的各出口产生来自播放缓冲区的信号，其位置与速度由该播放出口的相位输入决定。出口的个数由 stutter~ 对象的第五个参数决定。
