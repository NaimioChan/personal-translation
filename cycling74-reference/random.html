Max

random

生成随机数

描述

输出 0 到比所指定参数小 1 的范围内的随机数。

参数

range [int/float] 可选

为随机输出设置初始上限。若为 int，输出将始终介于 0 与比该最大上限小 1 之间。若为 float，输出将介于 0 与该最大上限之间。若没有参数，该上限初始设为 1，这会使 random 在每次收到 bang 时都输出 0。

seed [int] 可选

第二个参数用于为随机数生成器设置“种子”值。如果未指定参数，则使用时间值来初始化种子。

特性

classic [int] : 0

启用/禁用经典模式，它使用统计特性极差的旧版随机数生成器。默认值为 0（禁用）。

cycle [atom_long] : 0

当 cycle 大于零时，它决定在 random 把其随机数生成器状态重置为当前 seed 之前的输出次数。结果是一个重复模式，其内容由 seed 取值决定。当 cycle 为 0 时，random 从不重置其状态。

floatoutput [int] : 0

用当前的 range 启用/禁用 float 输出。

range [2 atoms] : 0 1

range 可以是任意两个数值，包括负值。若 range 中包含浮点数，floatoutput 会被启用，该对象会生成浮点输出。

seed [atom_long] : 0

seed 特性设置随机数生成器的状态。当 seed 为 0（默认值）时，random 使用系统启动以来经过的时间作为种子。当 seed 非零时，该值用于初始化（"seed"）随机数生成器，从而得到同样可预测但在统计上随机的序列。你可以通过更改 seed 或用 reset 消息来重置随机数生成器的状态。

消息

bang

左入口：送出 0 到比其最大上限小 1 之间的随机生成数。

int

右入口：该数字被存为随机输出的最大上限。输出将始终介于 0 与比该最大上限小 1 之间。

参数：

  • maximum [int]

float

右入口：该数字被存为随机输出的最大上限。此外 floatoutput 会被启用，该对象会生成浮点输出

参数：

  • maximum [float]

list

右入口：这些数字用于设置对象的 range。range 可以是任意两个数值，包括负值。若 range 中包含浮点数，floatoutput 会被启用，该对象会生成浮点输出。

参数：

  • minimum [atom]
  • maximum [atom]

reset

不带参数时，reset 消息把循环计数器（在启用 cycle 特性时使用）重置为零。当存在一个可选的 int 参数时，该参数会成为循环计数器的新取值，并从循环起点 "快进" 到指定循环位置，使下一次输出落在循环中的该位置。在更改 seed 之后立即使用 reset 很有用，可确保循环从头到尾输出各个取值。

参数：

  • cycle-index [int]

输出

int

在左入口收到 bang 时，random 会生成 0 到比其最大上限小 1 之间的随机数。
