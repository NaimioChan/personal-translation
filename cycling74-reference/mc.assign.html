mc.assign

把消息分配给 MC 对象

描述

mc.assign 对象按照你定义的通道与延迟模式，把 MC 通道分配给传入的消息（数字、列表与符号）。

讨论

mc.assign 对象有一个 pattern 特性，它定义了一条传入消息如何以 setvalue 消息的形式传递给相连的 MC 对象。该模式使用一小组符号来描述它响应传入消息时的行为。mc.assign 对象的 mode 特性决定模式如何处理传入的消息。
当 mode 设为 Step 时，传入消息会沿着模式一次前进一步。当 mode mode 设为 Normal 时，mc.assign 会为每条传入消息完整地播放一遍模式。当 mode 设为 Listiter 时，list 消息会被拆成一个个单独的数字。例如，传入列表消息 50 60 70 而模式为 2 3 时，会产生三条消息：setvalue 2 50、setvalue 3 60 和 setvalue 2 70。
下面逐个说明各个可用模式元素的行为：

  • 模式中的 number（int）总是把消息送往指定的通道。若模式为 2 3 4，一条传入消息会生成发往通道 2、3 和 4 的 setvalue 消息。
  • |（竖线）符号用于开始和结束一个“和弦”，它把传入消息送往多个通道。例如，要把传入消息同时送往通道 2 和 3，模式应为 | 2 3 |。这种同时行为在 mode 特性的所有设置下都会发生。
  • 模式中的 x 会跳过该消息，不产生任何输出。
  • 模式中的 *（星号）会随机选择通道。它也可以选择跳过某条消息。* 输出传入消息的概率由 density 特性设置。若 density 设为 0.9，模式中的一个 * 平均有 90% 的时间会输出该消息（10% 的时间跳过该消息）。在所有通道都被选过之前，* 元素不会重复。换句话说，它的行为像 Max 的 urn 对象。（与下面描述的 $ 对比。）
  • 模式中的 +（加号）会像 * 那样随机选择通道且不重复，但与 * 不同，+ 从不跳过消息。
  • 模式中的 $（美元符号）会随机选择通道。它也可以选择跳过某条消息。$ 输出传入消息的概率由 density 特性设置。若 density 设为 0.1，模式中的一个 $ 平均有 10% 的时间会输出该消息（90% 的时间跳过该消息）。与 * 元素不同，$ 可能重复取值。换句话说，它的行为像 Max 的 random 对象。
  • 模式中的 #（井号）会像 $ 元素那样随机选择通道，但与 $ 不同，# 从不跳过消息。
  • 模式中的 ^（脱字符）按升序循环遍历通道。例如，一个有 4 个通道的 mc.assign 对象若包含模式 ^ 1，它会在通道 1、1、2、1、3、1、4、1 上输出传入消息，然后才重复。

参数

无。

特性

chans [int]

chans 特性决定随机或循环模式元素所能生成的最大值。不过 chans 不会约束模式中直接写出的数字。

delays [atom]

delays 特性设置一组重复出现的延迟时间，用于遍历模式中的和弦。例如，若 delays 设为 100 200，而模式中有一个四项和弦（如 | 1 2 3 4 |），一条传入消息会立即在通道 1 上输出，然后在 100ms 后在通道 2 上输出，再在 200ms 后在通道 3 上输出，最后在 100ms 后在通道 4 上输出（因为延迟模式会重复）。要清除 delays 特性并让和弦中的所有消息同时输出，发送不带参数的消息 delays 或单词 none。

density [float]

决定当模式元素为 * 或 $ 时播放事件的概率。当 density 设为 0.9 时，传入消息有 90% 的概率被送出，有 10% 的概率被跳过。

mode [int]

mode 特性决定当前的 pattern 与 delays 如何处理传入消息。
可选值：

0 = 'Normal' （播放完整模式）
每条传入消息都走完整个模式。

1 = 'Step' （逐步走过模式）
每条传入消息使用当前模式的一个元素，下一条传入消息则使用下一个元素。

2 = 'Listiter' （遍历传入的列表）
每条传入消息都走完整个模式。成组的模式元素（竖线之内的部分）被拆成一个个单独的数字；模式向前推进，一次输出一个列表元素，直到列表末尾与模式末尾都到达为止。若模式比列表短，它会从头重复。若列表比模式短，它会从头重复。

pattern [atom]

决定通道分配的循环模式。pattern 特性由通道号或符号元素组成，这些元素产生循环或随机的通道取值（详见上文讨论）。mc.assign 对象的 pattern 特性始终非空；默认模式为 1 2 3 4 5 6。要清除模式，把 pattern 特性设为 none，或发送不带参数的消息 pattern。

pos [int]

pos 特性是模式中的当前位置。若模式当前正在生成输出消息，对位置的改动大多会被忽略。

消息

bang

bang 消息会被重复送到 mc.assign 的左出口，前面加上 setvalue 一词以及由当前模式决定的通道号。

int

一个数字会被重复送到 mc.assign 的左出口，前面加上 setvalue 一词以及由当前模式决定的通道号。

float

一个数字会被重复送到 mc.assign 的左出口，前面加上 setvalue 一词以及由当前模式决定的通道号。

list

一条列表会被重复送到 mc.assign 的左出口，前面加上 setvalue 一词以及由当前模式决定的通道号。

anything

一条消息会被重复送到 mc.assign 的左出口，前面加上 setvalue 一词以及由当前模式决定的通道号。
