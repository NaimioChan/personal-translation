Jitter

jit.openexr

读取或写入 OpenEXR 图像。

描述

在 OpenEXR 图像与 jit.matrix 对象之间相互转换，可处理任意数量的通道或颜色分量。

讨论

OpenEXR 是一种高动态范围（HDR）图像文件格式，由 Industrial Light and Magic 开发，用于计算机成像应用。
jit.openexr 对象支持 16 位无符号整数以及 16 位（又称 "half"）和 32 位浮点颜色分量取值。half 取值有 1 个符号位、5 个指数位和 10 个尾数位。对于线性图像，该格式在每个颜色分量上每个色阶提供 1024（210）个取值，共 30 个色阶（25 - 2），并在低端（非规格化数）额外提供 10 个精度降低的色阶。half 格式支持非规格化数、正无穷、负无穷以及 NaN。它与 NVIDIA 的 Cg 图形语言中的 half 数据类型完全相同。
在转换为 jit.matrix 对象或从该对象转换回来时，half 取值会被提升为 32 位浮点取值（float32），16 位整数取值会被转换成 8 位无符号 char，64 位浮点取值会被转换成 32 位，32 位整数取值会被转换成 16 位无符号。
OpenEXR 还支持若干无损压缩方法（PIZ、ZIP、RLE），对于带有胶片颗粒的图像可达到约 2:1 的压缩比。

关于矩阵运算符的更多内容

Jitter MOP

既然矩阵是 Jitter 的核心，大多数 Jitter 对象属于矩阵运算符这一类也就不奇怪了。每个矩阵运算符都有若干个矩阵输入和若干个矩阵输出。矩阵输入按从左到右的顺序用 "in"、"in2"、"in3" 等名称称呼，矩阵输出用 "out"、"out2"、"out3" 等名称称呼，即除最左边第一个输入和最左边第一个输出分别只叫 "in" 和 "out" 之外，其余名称都由输入/输出编号后缀而来。我们把输入或输出的名称称为 "I/O-name"。

矩阵输入和输出在内部通常各自持有保存信息的矩阵。这是必要的，因为 Jitter 是异步框架（也就是说，各个矩阵并不会同时到达所有输入）。矩阵输入和输出的若干方面可以用命令 [I/O-name] 加上下列后缀之一来设置："_dim" 设置指定 I/O 矩阵的维度，"_type" 设置指定矩阵的类型，"_planecount" 设置指定矩阵的通道数，"_name" 设置指定矩阵的名称。有一种特殊情况没有任何内部矩阵，就是第一个输入 "in"。这是因为该特殊输入实际上触发矩阵运算符的计算，所以不像其他输入那样需要缓存到计算发生为止。因此没有机制可以设置 "in" 的 dim、planecount、type 或 name。

矩阵运算符接受我们称为「matrix args」的参数，即 [planecount (int)] [ type (symbol)] [dim (int list)]。若给出了这些参数，adapt 特性会被关闭，否则会被打开。若 adapt 模式打开，则每当第一个输入收到矩阵时，就相当于把 dim、planecount 和 type 特性设置为该输入矩阵的对应值。若其他输入和输出链接到这些特性，它们所链接的特性也会随之改变。adapt 模式打开时哪些输入和输出会链接到哪些特性，请查阅「MOP」表。最左侧的输入不适用该规则，因此该行所有列都标记为 "n/a"。

jit.matrix 对象是一个具名矩阵，可用于矩阵数据的存储与取出、重采样，以及矩阵类型与 planecount 转换等操作。

MOP 参数

planecount [int] 可选

显式设置输出以及右侧各输入的通道数。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

type [symbol] 可选

显式设置输出以及右侧各输入的矩阵类型。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

dimensions [list] 可选

显式设置输出以及右侧各输入的矩阵维度。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

MOP 特性

adapt [int]

矩阵自适应标志（若给出了矩阵参数则默认值为 0，否则为 1）。该标志置位时，jit.matrix 对象会自适应输入矩阵的 planecount、type 和 dimensions。

[in/out]_dim [32 ints]

矩阵数据的维度（默认值 = 1 1）

[in/out]_name [symbol]

矩阵输入或输出的名称（默认值 = UID）

[in/out]_planecount [int]

矩阵输入或输出数据的通道数。除特殊情况外，该值等于 planecount。

[in/out]_type [symbol]

输入或输出矩阵的数据类型。除特殊情况外，该值等于 type。

outputmode [int]

输出模式（默认值 = 1（计算并输出矩阵））
0 = 无输出（不计算）
1 = 计算并输出矩阵
2 = 透传输入（不计算）
3 = 透传输出（不计算）

type [int]

矩阵数据类型（默认值 = char
支持的数据类型有 char、long、float32 和 float64。

特性

adjust [int]

启用或禁用按 ILM 提出的显示映射流程调整 HDR 图像数据的标志（默认值 = 0）。启用后，可以用 exposure、defog、kneehigh、kneelow 和 normalize 这些特性控制下列显示映射过程：

1. 从原始像素取值中减去 defog，以补偿雾化。
2. 把去雾后的像素取值乘以 2(exposure + 2.47393)。
3. 此时取值为 1.0 的那些值称为 "middle gray"。若 defog 与 exposure 都设为 0.0，则 middle gray 对应原始像素取值 0.18。在第 6 步中，middle gray 取值会被映射到比显示器最大强度低 3.5 个色阶的强度。
4. 应用拐点函数。该拐点函数有两个参数，kneeLow 与 kneeHigh。低于 2kneeLow 的像素取值不会被拐点函数改变。高于 kneeLow 的像素取值会按对数曲线降低，使得取值 2kneeHigh 映射到 23.5（在第 6 步中，该取值会被映射到显示器的最大强度）。
5. 对像素取值进行伽马校正。
6. 缩放取值，使 middle gray 像素映射到 84.66（即比显示器最大强度低 3.5 个色阶）。
7. 若转换为 8 位无符号整数取值（char），把取值限制在 [0, 255]。

channels [32 symbols]

要使用的通道名列表。把 OpenEXR 文件读入 jit.matrix 对象时，这些通道会被依次映射到矩阵的各个通道。若某个通道不存在，它会被填零。写入 jit.matrix 对象时，该列表中列出的名称会被用来为存入 OpenEXR 文件时的各个通道命名。（默认值 = null）

defog [float]

从像素取值中减去的值，用于补偿记录设备中杂散光造成的雾化（默认值 = 0.0）。

exposure [float]

设置图像在显示器上的表观曝光。它会提亮或压暗所显示的图像，让你能显出高光端或暗部端的细节。（默认值 = 0.0）

gamma [float]

对像素取值进行伽马校正所用的系数（默认值 = 2.2）

kneehigh [float]

kneeHigh 与 kneeLow 之间的像素取值设定所显示图像的白色电平，决定哪个取值被映射到显示器的最大强度（默认值 = 3.5）

kneelow [float]

kneehigh 与 kneelow 之间的像素取值设定所显示图像的白色电平，决定哪个取值被映射到显示器的最大强度（默认值 = 0.0）。

normalize [int]

启用或禁用归一化的标志，归一化用于把浮点数据重映射到 0-1 的均匀范围。该操作会在显示映射过程之前执行。（默认值 = 0）

outputfile [int]

为了从 JS 输出 openexr 文件的内容，用户必须提供输入矩阵或启用 outputfile。

verbose [int]

切换是否把信息打印到 Max Console。
