omx.5band~

OctiMax 5 频段压缩器

描述

omx.5band~ 以 5 频段压缩器的形式提供 Octimax 的信号处理能力。

参数

无。

消息

bands_enum

单词 bands_enum 后面跟 0 或 1，用于设置频段数量。可选项有：

0：4 频段

参数：

bassenhancement

单词 bassenhancement 后面跟一个非零数字时，会启用多频段压缩器对低频的专门增强；后面跟 0 时，则不施加任何低频增强。

参数：

  • low-frequency-emphasis-flag [int]

bassenhancement_mixlevel

单词 bassenhancement_mixlevel 后面跟一个数字，用于设置输出前加入到音频信号中的低频增强量。

参数：

  • low-frequency-enhancement-level [int]

bypass

单词 bypass 后面跟一个非零数字时，会把未作任何处理的干信号原样直接从出口送出；后面跟 0 时，会输出经 omx.5band~ 处理后的信号。

参数：

  • bypass-flag [int]

choosePreset

单词 choosePreset 后面跟一个 0-2 范围内的数字，会为 omx.4band~ 对象选择一个预设。这些预设应被视为“起始点”，应根据你的具体用途或想要的声音加以调整。预设选项有：

0：通用——对声音做整体提升，采用 3 比 1 的压缩且不限幅。低频增强被打开，增添一点温暖感。
1；流行——设置 50:1 的压缩，并在最低的两个频段使用强力驱动的限幅。这为声音带来扎实的低频。
2：热门电台——是通用与流行两种设置之间的折中。你会注意到各处的时间都大致相同，低频段中启动与释放相应地更慢。
3：FM 电台——与流行和热门电台设置的主要差别在高频部分，那里的压缩更紧一些。

参数：

  • preset-number [int]

freeze_threshold

单词 freeze_threshold 后面跟一个数字，用于设置冻结阈值（以低于满刻度多少 dB 表示）。当输入信号降到冻结阈值以下时，释放会完全停滞。与门控阈值一起，该阈值有助于防止背景嘶声被放大。

参数：

  • freeze threshold [float]

gating_threshold

单词 gating_threshold 后面跟一个数字，用于设置释音门阈值（以低于满刻度多少 dB 表示）。当信号低于该阈值时，压缩器的释音时间会放慢到 3 倍。

参数：

  • release-gate-threshold [float]

inagc_atk

单词 inagc_atk 后面跟一个数字，用于设置输入压缩器的启动速率。启动速率决定压缩器施加增益衰减的快慢。取值范围为对数刻度上的 0-150，取值越大表示启动越快。

参数：

  • input-compressor-attack-rate [int]

inagc_progressive

单词 inagc_progressive 后面跟 1 或 0，用于启用或禁用渐进释放模式，该模式会让输入压缩器在增益衰减较深时释放得更快。

参数：

lim_smoothrelease

单词 lim_smoothrelease 后面跟一个数字，按如下方式设置限幅器响应模式：

0：冲击感强。冲击感强的响应采用极短的启动与释放时间，适用于透明的限幅，或用于提升响度。不过一旦使用过度，可能会产生互调失真。
1：平滑。平滑释放采用较长的启动与释放时间。结果仍是一个快速的前瞻限幅器，但互调失真更小、冲击感也更弱。
