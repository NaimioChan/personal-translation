MSP

onepole~

单极点低通滤波器

描述

onepole~ 对象实现了最简单的 IIR 滤波器，提供每倍频程 6dB 的衰减。该滤波器非常高效，适合平缓地滚降刺耳的高频，也适合平滑控制信号。

讨论

该滤波器的标准差分方程为

y(n) = a_{0} x(n) + b_{1} y(n-1)
其中

b_{1} = 1 - a_{0}

它可以化简为

y(n) = y(n-1) + a_{0}[ x(n) - y(n-1) ]

随着 a_{0} 系数的取值降低（b_{1} 增大），输入会被越来越强地平滑，有效截止频率（f_c）也会降低。由 f_c 截止频率计算 a_0 系数所用的方程为

a_{0} = sin(f_c * (pi/nyquist))

其中 f_s 是采样频率，f_c 是以赫兹表示的截止频率。onepole~ 是 biquad~ 对象的一种更高效的实现，使用以下系数：

a_{0} &= a_{0}
a_{1} &= 0
a_{2} &= 0
b_{1} &= -b_{1}
b_{2} &= 0
注意 b_{1} 的符号翻转，因为 biquad 对反馈系数使用的是翻转后的符号。

参数

center-frequency [float] hz 可选

设置滤波器的中心频率，如上所述。

Hz/linear/radians [symbol] 可选

使用符号 Hz、linear 或 radians 作为可选的第二个参数，可设置频率输入模式。默认模式是 Hz（等同于不提供模式参数）。使用 linear 参数会把频率输入模式设为 linear（0 - 1）。使用 radians 参数会把频率输入模式设为 radians（0 - 1）。

消息

int

右入口：设置滤波器的频率（若未连接信号）。默认情况下，频率以 Hz 表示，允许范围是从 0 到当前采样率的四分之一。为方便起见，onepole~ 还有两种额外的输入模式，使用更常规的输入范围 0 - 1（参见 linear 与 radians 消息）。

参数：

  • center-frequency (Hz) [int]

float

右入口：设置滤波器的频率（若未连接信号）。默认情况下，频率以 Hz 表示，允许范围是从 0 到当前采样率的四分之一。为方便起见，onepole~ 还有两种额外的输入模式，使用更常规的输入范围 0 - 1（参见 linear 与 radians 消息）。

参数：

  • center-frequency (Hz or 0 through 1 specified by object-argument) [float]

Hz

任意入口：把频率输入模式设为 Hz（默认）。

clear

任意入口：清除 onepole~ 的内部状态。由于 onepole~ 不像其他滤波器类型那样存在固有的不稳定性，这应该永远都不需要。

linear

任意入口：把频率输入模式设为 linear（0 - 1）。linear 模式就是标准 Hz 模式的一个缩放版本，区别在于 0-1 范围内的取值会遍历整个频率范围。

radians

任意入口：把频率输入模式设为 radians（0 - 1）。radians 模式让你可以直接设置方程的中心频率（f_c），虽然输入范围相同（0-1），但输出具有弯曲的频率响应，更接近人耳的指数音高刻度。

signal

左入口：待滤波的信号。

右入口：可以用一个信号来设置滤波器的频率，效果与 float 相同。若有信号连接到该入口，其取值每隔一个信号向量被采样一次。

输出

signal

经过滤波的信号。
