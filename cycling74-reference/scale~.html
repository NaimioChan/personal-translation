MSP

scale~

把信号取值的输入范围映射到输出范围

描述

用 scale~ 对象把信号取值的输入范围映射到输出范围。各范围可以按 hi 和 lo 反写来指定，以实现反相映射。若指定了，映射也可以是指数型的。

参数

minimum-in-value [number] 可选

第一个参数是缩放运算所用的最小输入取值。

maximum-in-value [number] 可选

第二个参数是缩放运算所用的最大输入取值。

minimum-out-value [number] 可选

第三个参数是缩放运算所用的最小输出取值。

maximum-out-value [number] 可选

第四个参数是缩放运算所用的最大输出取值。

scaling-curve [float] 可选

这个可选的第五个参数规定缩放曲线的性质。该参数必须是大于 1. 的浮点数，取值越大，指数曲线越陡。

在 classic 模式下，该参数的典型值为 1.06，数字按以下表达式转换：
(out_high-out_low >= 0) ? (out_low + (out_high-out_low) * ( (out_high - out_low) * exp(-1*(in_high-in_low)*log(power)) * exp(x*log(power)) )) : (-1) * ( out_low + (out_high-out_low) * ( (out_high - out_low) * exp(-1*(in_high-in_low)*log(power)) * exp(x*log(power)) ) )

在 non- classic（modern）模式下，缩放曲线的取值必须高于 0.，并按以下表达式转换：

((x-in_low)/(in_high-in_low) == 0) ? out_low : (((x-in_low)/(in_high-in_low)) > 0) ? (out_low + (out_high-out_low) * ((x-in_low)/(in_high-in_low))^exp) : ( out_low + (out_high-out_low) * -((((-x+in_low)/(in_high-in_low)))^(exp)))

注意，在 Max 6.0.4 之前，指数是反的。因此，若你给它的指数为 2，对象的行为就像指数是 0.5；若你给它的指数为 0.5，它的行为就像指数是 2。6.0.4 之前版本的补丁可能需要更新才能正常工作。

特性

classic [int]

Classic 模式使用与老 IRCAM 补丁向后兼容的指数函数。
可选值：

0 = 'Off'
当 classic 为 0 时，scale~ 先把输入缩放到 0 到 1 之间，再施加指数（幂）函数，然后缩放所得输出。

1 = 'On'
当 classic 为 1 时，scale~ 与遗留的 IRCAM "linedrive" 缩放兼容。此模式不推荐用于新作品。

2 = 'Off + Inverse'
当 classic 为 2 时，scale~ 的行为与 classic 0 类似，区别在于当输出范围使取值反相时，也就是说当第一个输出取值大于第二个输出取值时，指数也会反相，使缩放曲线保持非反相输出范围所产生的形状。
