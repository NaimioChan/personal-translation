sprintf

格式化由词与数字组成的消息

描述

在 Max 内部使用常见的 C 语言 "printf" 函数。你可以组合 symbol、组织数字列表，或格式化消息或菜单项。完整文档请参阅标准的 C 库参考手册。

参数

symout [symbol] 可选

若第一个参数是词语 symout，sprintf 对象会把生成的字符串作为单个 symbol 输出。否则输出是 symbol 和/或数字组成的列表。词语 symout 本身不包含在 sprintf 的输出中。

format [symbol] 可选

参数构成一条要送出的消息，格式类似 C 编程语言。参数可以是词、数字，也可以是针对传入 symbol（%s), ints（%ld）、传入 float（%f）以及要格式化为 ASCII 字符的 int（%c）的可变参数。入口的数量由可变参数的数量决定，每个入口按顺序对应一个可变参数。

消息

bang

左入口：用当前存储的取值格式化消息。

上述任何消息在左入口都会格式化消息并把它送出。若可变的数字参数（%ld 或 %f）还没有收到取值，就会用 0 代替该参数。若 %s 或 %c 参数还没有收到取值，该参数会留空。

int

可以在任何对应 %ld 或 %c 参数的入口收到。该数字会被存放在该参数的位置上。%c 参数会把 int 转换为等价的 ASCII 字符。

参数：

  • input [int]

float

可以在任何对应 %f 参数的入口收到。该数字会被存放在该参数的位置上。

参数：

  • input [float]

list

左入口：列表中的每一项都被当作是在各自独立的入口收到的，最多到入口的数量。

参数：

  • input [list]

anything

其功能与 list 相同。

参数：

  • input [list]

symbol

可以在任何对应 %s 参数的入口收到。该 symbol 会被存放在该参数的位置上。

参数：

  • input [symbol]

输出

anything

按键入的参数指定的消息会被格式化并送出，其中可变的参数已做替换。
