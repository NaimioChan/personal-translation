MSP

framesnap~

以列表形式输出一个 FFT 帧或信号向量

描述

framesnap~ 对象与 snapshot~ 类似，但它输出的列表包含信号向量的内容，在 pfft~ 对象内部使用时便于捕获 FFT 帧。

参数

interval [int] 可选

可选的数字参数设置以毫秒为单位的内部采样间隔。若该参数为 0 或未给出，framesnap~ 不会自动生成输出。此时你需要发送 bang 消息来输出一帧信号数据。

特性

active [int]

启用/禁用 framesnap~ 对象的输出。

interval [Time Value] : 0 ms

设置输出间隔。该间隔可以用任意 Max 时间格式指定。

消息

bang

bang 消息生成一个包含当前信号向量内容的列表。

int

见下文 float 消息。

参数：

  • report [int]

float

（左入口）向左入口发送一个非零的数会启动该对象对信号取值的自动报告。左入口收到零会停止自动报告。
（右入口）向 framesnap~ 对象的右入口发送一个数，会设置以毫秒为单位的内部采样间隔。若该间隔设为 0，framesnap~ 不会自动生成输出。此时你需要发送 bang 消息来输出一帧信号数据。

参数：

  • report [float]

list

任何符合 Max 时间格式的消息（ms、hh:mm:ss、ticks bars.beats.units、notevalues、hz 或 samples）都可以用来指定 framesnap~ 对象使用的内部采样间隔。

参数：

  • time [list]

anything

任何符合 Max 时间格式消息的消息（例如 ms、hh:mm:ss、ticks bars.beats.units、notevalues、hz 或 samples，）都可以用来指定 framesnap~ 对象使用的内部采样间隔。

参数：

  • time [list]

sampleinterval

单词 sampleinterval 后面跟一个整数，设置以毫秒为单位的内部采样间隔。

参数：

  • time [int]

signal

连接到 framesnap~ 对象左入口的信号，会在该对象收到 bang 或其内部采样间隔时钟触发时用于输出一个列表。

start

消息 start 在采样间隔非零时启动 framesnap~ 对象的自动输出。若采样输出为零，start 消息等价于 bang 消息，会产生单次信号向量输出。

stop

消息 stop 在该对象的采样间隔非零时停止 framesnap~ 对象的自动输出。
