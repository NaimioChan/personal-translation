Max

thispatcher

向补丁发送消息

描述

允许用 Max 消息修改补丁窗口。

讨论

thispatcher 可用于修改和/或关闭补丁窗口——它会向自己所在的补丁窗口发送消息。

参见 bpatcher 参考页，了解如何把 thispatcher 对象与 bpatcher 配合使用。

注意：不支持用 thispatcher 对象创建新对象。

参数

无。

特性

快照特性

autosave [int] 只写

保存所属补丁时，该对象快照的状态也会一并保存。

消息

anything

参见 "Patcher Messages" 与 "Scripting Messages" 讨论。

参数：

  • message [list]

end

供内部使用。

savewindow

savewindow 一词后面跟一个非零数字，表示由 window flags 消息发往 thispatcher 造成的任何异常窗口设置，都会在下次保存补丁时作为补丁的一部分保存下来。消息 savewindow 0 表示由 window flags 消息发往 thispatcher 造成的窗口改动在保存补丁时不会被保留；保存的是先前的补丁窗口设置。如果从未收到过 savewindow 消息，补丁会以常规的窗口外观保存。

参数：

  • flag [int]

setactivetab

在带标签页的补丁中，传入 setactivetab 消息、后面跟上子补丁在标签页本身上显示的名称，即可更改当前活动标签页。

参数：

  • message [list]

参数：

  • file-name [symbol]

参数：

补丁行为与显示

The script message

script 消息发往 thispatcher 后，可以动态控制对象的创建、删除、尺寸与定位以及连线。script 一词后面跟一个表示某种功能的关键字。关键字后面是用于指定该消息影响哪些对象的参数。

在随后对每条 script 消息的讨论中，语法部分用尖括号给出关键字之后该消息所需的参数。每条消息还附有一个示例。

变量名是一个符号，用于命名一个新建或已存在的对象。你可以通过从 Object 菜单中选择 Name... 来设置变量名，也可以使用某些脚本消息（例如 new 和 select）来设置。

补丁消息

anything

除了下面列出的补丁消息之外，thispatcher 还接受用来控制 patcher inspector 中各项特性的消息，只需发送特性名，后面跟上相应的取值。

clean

clean 消息会重置窗口里补丁的 dirty 位，这样就不会再被要求保存补丁中的更改。

dirty

dirty 消息与 clean 方法的作用相反；它会设置窗口里补丁的 dirty 位。

dispose

*风险自负*——关闭补丁，或销毁 thispatcher 对象所在的子补丁。

front

front 消息会把包含 thispatcher 对象的窗口提到最前。如果补丁未打开，该消息会打开补丁并把它提到最前。

loadbang

loadbang 消息会把 loadbang 消息发送给补丁中的所有对象——包括 loadbang 对象自身。

lockdown

lockdown 消息会禁用补丁的编辑。

locked

locked 消息后面跟 0 或 1，会锁定或解锁补丁。

path

path 消息会把包含 thispatcher 对象的补丁的完整路径名从 thispatcher 对象的右出口输出。

如果补丁是抽象对象（由 bpatcher 托管、位于 poly~ 中等），这条消息报告的是最顶层补丁的路径，而不是该抽象对象的路径。

presentation

presentation 消息后面跟 0 或 1，会让补丁进入或退出演示模式。

showparameterwindow

这条消息后面跟 1 或 0，会在补丁中存在参数时显示或隐藏 Parameter 窗口。注意在 Max for Live 环境中，该窗口是只读的。

title

title 消息后面跟一个 symbol，会更改补丁窗口中显示的标题。

topmost

topmost 消息后面跟 0 或 1，用于设置补丁窗口是否始终置顶。参数为 1 会让窗口始终置顶。请注意，只有在补丁至少显示过一次之后，topmost 消息才会生效。

write

当发给一个未保存到磁盘的补丁时，write 消息会打开一个标准的文件对话框窗口，用户可以在其中手动设置文件名和保存文件的位置。如果补丁已保存到磁盘，write 消息会把文件以相同的名称重新保存到同一位置。

脚本消息

bringtofront

把对象移到它当前所在层的最前面。

语法：script bringtofront <variable-name>

示例：script bringtofront visigoth

如果 visigoth 位于前景层，这条消息会把它移到前景层的最前面。否则会把它移到背景层的最前面。

class

给指定类的第一个参数匹配的实例分配一个变量名

语法：script class <variable-name> <class-name> <arguments (optional)>

示例：script class rubadub + 4

把名称 rubadub 分配给补丁中第一个找到的 +，其参数为 4。

connect

用一条连线把两个对象连接起来

语法：script connect <outlet-variable-name> <outlet-index> <inlet-variable-name> <inlet-index>

示例：script connect fooboo 0 bobo 0

把变量名为 fooboo 的对象的左出口连接到变量名为 bobo 的对象的左入口。

注意：加上关键字 hidden（例如 script hidden connect fooboo 0 bobo 0)）会创建隐藏的连接。

connectcolor

修改已有连线的颜色，把它设为 Max 的 16 种标准颜色之一。

语法：script connectcolor <outlet-variable-name> <outlet-index> <inlet-variable-name> <inlet-index> <color>

示例：script connectcolor rover 0 dover 2 12

把 rover 对象的左出口与 dover 对象的第 3 个入口之间的连线颜色改为索引 12 处存储的颜色。

delete

删除补丁窗口中的一个对象。

语法：script delete <variable-name>

示例：script delete footog

删除与变量名 footog 关联的对象。

disconnect

断开由一条连线连接的两个对象

语法：script disconnect <outlet-variable-name> <outlet-index> <inlet-variable-name> <inlet-index>

示例：script disconnect fooboo 0 bobo 0

这条消息会撤销 fooboo 的左出口与 bobo 的左 inlet 之间的连接。

hidden

指定某个对象（或连接）在创建时会被隐藏。

示例：script hidden new footog toggle 101 93 15 0

创建一个与变量名 footog 关联的隐藏对象。hidden 关键字在指定对象之间的连接时同样可以使用。

hide

隐藏一个可见对象。

语法：script hide <variable-name>

示例：script hide visigoth

隐藏名为 visigoth 的对象

ignoreclick

设置对象不响应鼠标点击。

语法：script ignoreclick <variable-name>

示例：script ignoreclick visigoth

让名为 visigoth 的对象忽略鼠标点击。

move

把对象移动到一个相对于补丁窗口当前左上角的绝对位置。注意 0,0 点在图标栏下面。

语法：script move <variable-name> <top> <left>

示例：script move molly 0 100

把名为 molly 的对象移到窗口左边缘、距顶部向下 100 像素处。

new

在补丁窗口中创建一个新对象并为它命名。

语法：script new <variable-name> <creation message>

示例：script new footog toggle 101 93 15 0

在 101 93 处创建一个 15 像素见方的 toggle 对象，并把它赋给变量 footog。

script new 消息参数（类名之后的部分）的格式基于遗留的 Max 文件格式。

newdefault

在补丁窗口中创建一个带默认属性的具名新对象。

语法：script newdefault <variable-name> <creation message>

示例：script newdefault thatgraph 10 10 filtergraph~

在 10 10 处创建一个默认大小的 filtergraph~ 对象，并把它赋给变量 thatgraph。

示例：script newdefault buffy 200 100 pack foo bar bap

在 200 100 处创建一个以参数 foo bar bap 实例化的 pack 对象，并把它赋给变量 buffy。

nth

给指定类的第 n 个实例分配一个变量名

语法：script nth <variable-name> <class-name> <index>

示例：script nth yoyo toggle 1

把名称 yoyo 分配给补丁中找到的第一个 toggle。

补丁中对象的顺序由从前到后的次序决定。位于补丁后方、画在其他对象背后的对象，在搜索顺序中排在最前。

offset

把对象从当前位置移动一段距离。正的距离把对象向右下方移动，负的距离把它向左上方移动。

语法：script offset <variable-name> <delta-x> <delta-y>

示例：script offset molly 30 -40

把名为 molly 的对象向右移动 30 像素、向上移动 40 像素。

offsetfrom

把对象从另一个对象处移动一段设定的距离。

语法：script offsetfrom <variable-name-to-move> <target-variable-name> <top-left-flag> <delta-x> <delta-y>

如果距离是相对于对象的左上角，top-left-flag 为 1；如果相对于右下角，则为 0。

示例：script offsetfrom molly panther 1 -100 -120

把名为 molly 的对象移到名为 panther 的对象的左侧 100 像素处，并高出名为 panther 的对象的顶部 120 像素。

respondtoclick

设置对象响应鼠标点击。

语法：script respondtoclick <variable-name>

示例：script respondtoclick visigoth

让名为 visigoth 的对象响应鼠标点击。

selected

给找到的第一个被选中的对象分配一个变量名

语法：script selected <variable-name>

示例：script selected impo

把名称 impo 分配给找到的第一个被选中的对象。显然，这条 script 消息只在补丁未锁定时才有效，因为在已锁定的补丁中无法选中任何对象。

下面介绍的三条连接消息中，入口和出口都用 index 指定，其中 0 表示最左边的入口或出口。第一个指定的变量是要连接或断开其出口的对象，第二个变量是要连接其入口的对象。消息随后就可以从出口流向入口。

send

向对象发送消息。这条消息与使用带分号的 message 对象框或 send 对象相同，但你可以利用脚本的对象变量名功能来指定接收消息的对象——用 script send 与具名的 receive 对象通信是无效的。消息只能发送给与 thispatcher 对象处在同一个补丁中的对象，即接收 script send 消息的那个对象。

语法：script send <variable-name> <message>

示例：script send foobert 666

变量名为 foobert 的对象会收到一条 int 666 消息。如果 foobert 是数字框，它显示的值会变成 666。

sendbox

向对象框发送消息。这条消息与 send 完全相同，区别在于它把消息发送给对象的对象框，而不是该对象框所指代的对象。目前只有一个对象——bpatcher——其对象与对象框是不同的两个对象。对象框是 bpatcher，而对象是补丁。你可以让 bpatcher 做什么呢？一个例子是 border 消息。想找其他思路，可以看看 bpatcher Inspector 里面。

语法：script sendbox <variable-name> <message>

示例：script sendbox bpbp border 0

如果 bpbp 命名的是一个 bpatcher 对象，这条 script 消息会告诉它不要绘制边框。

sendtoback

把对象移到它当前所在层的最后面。

语法：script sendtoback <variable-name>

示例：script sendtoback visigoth

如果 visigoth 位于前景层，这条消息会把它移到前景层的最后面。否则会把它移到背景层的最后面。注意，处于“后面”的对象正是变量赋值消息 nth 和 class 最先找到的对象。

show

显示一个隐藏的对象。

语法：script show <variable-name>

示例：script show visigoth

让名为 visigoth 的对象变为可见。

size

更改对象的尺寸。有些对象对自身尺寸有限制，但它们通常不会防范自己不期望的尺寸，所以使用这条消息时要多加小心。例如 toggle 对象期望自己是正方形。如果把它变成矩形，它可能无法正确绘制。

语法：script size <variable-name> <width> <height>

示例：script size togipoo 30 30

把名为 togipoo 的对象改为 30 × 30 像素。

向对象发送消息

输出

symbol

右出口：响应 path 消息时，输出包含补丁文件的文件夹或卷的完整路径名。如果补丁尚未保存，则没有输出。

window

左出口：收到 window getsize 消息时，thispatcher 会送出 window size 一词，后面跟窗口左、上、右、下边界的屏幕坐标（以屏幕左上角为原点的像素值）。收到 window gettitle 消息时，会根据窗口是否有标题栏，送出 window title 或 window notitle 消息。收到 window getflags 消息时，thispatcher 会送出 window flags 一词，后面跟滚动条与尺寸调整框（grow 或 nogrow）、关闭框（close 或 noclose）以及缩放框（zoom 或 nozoom）的可见性。
