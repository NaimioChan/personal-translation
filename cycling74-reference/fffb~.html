MSP

fffb~

快速固定滤波器组

描述

fffb~ 对象实现了一组带通滤波器对象，其中每一个都类似于 reson~ 滤波器对象。输入信号会施加到所有滤波器上，各个滤波器的输出可以分别取用。当 fffb~ 对象被实例化为 mcs.fffb~ 时，该对象只有一路多通道输出，其中包含各个滤波器。否则每个滤波器各有一个独立的出口。

讨论

此对象比使用多个 reson~ 对象更高效，但为了速度，它不接受用信号来改变参数。

参数

number-of-filters [int] 可选

指定滤波器的数量（默认值 4，最小 1，fffb~ 最大 128，mcs.fffb~ 最大 1024）。

1st-filter-frequency [float] 可选

设置第一个滤波器的中心频率。

filter-frequency-ratios [float or symbol] 可选

设置相邻滤波器的频率比值。这里用 'H' 可让各滤波器按谐波列调律。

Q [float] 可选

设置施加到所有滤波器上的 Q 值。

gain [float] 可选

设置施加到所有滤波器上的增益。

消息

list

先给出一个滤波器索引，后面只跟一个频率，或跟一个频率与一个 Q 设置，会把该索引编号所指的那个滤波器设为紧随其后的那些设置。

参数：

  • filter-index and settings [list]

anything

先给出一个滤波器索引，后面只跟一个频率，或跟一个频率与一个 Q 设置，会把该索引编号所指的那个滤波器设为紧随其后的那些设置。

参数：

  • filter-index and settings [list]

Q

左入口：symbol Q 后面跟一个由 int 和一个或多个 float 组成的列表，会设置各滤波器的 Q 值，从索引由第一个数字给出的那个滤波器开始。该滤波器的 Q 值被设为列表中的第二个数字。列表中后面还有的数字会设置紧接第一个指定滤波器之后那些滤波器的 Q 值。索引从 0 开始计数。

参数：

  • bandwidths [list]

QAll

左入口：单词 QAll 后面跟一个 float，会把所有滤波器的 Q 设为给定的浮点取值。

参数：

  • general-bandwidth [float]

clear

清除 fffb~ 对象对先前输入与输出的记忆。

freq

左入口：单词 freq 后面跟一个由 int 和一个或多个 float 组成的列表，会设置各滤波器的中心频率，从索引由第一个数字给出的那个滤波器开始。该滤波器的频率被设为列表中的第二个数字。列表中后面还有的数字会设置紧接第一个指定滤波器之后那些滤波器的频率。索引从 0 开始计数。

例如，消息 freq 3 1974.0 333.0 1234.0 会把第四个滤波器的频率设为 1974Hz、第五个设为 333Hz、第六个设为 1234Hz。

参数：

  • filter-frequencies [list]

freqAll

左入口：单词 freqAll 后面跟一个 float，会把所有滤波器的中心频率设为给定的浮点取值。

参数：

  • general-center-frequency [float]

freqRatio

左入口：单词 freqRatio 后面跟一个由两个或更多数字组成的列表，会把第一个滤波器的中心频率设为列表中的第一个取值，并反复用第二个取值乘以第一个取值来设置其余滤波器的频率，使相邻滤波器的频率比值等于第二个取值。例如，消息 freqRatio 440. 2. 会把第一个滤波器的频率设为 440Hz、第二个设为 880Hz、第三个设为 1760Hz，依此类推。

若列表中的第二项是字母 H 而不是数字，则各滤波器会按谐波列调律。例如，消息 freqRatio 100 H 会把各滤波器的频率设为 100Hz、200Hz、300Hz、400Hz，依此类推。

参数：

  • frequency-ratios [list]

gain

左入口：单词 gain 后面跟一个由 int 和一个或多个 float 组成的列表，会设置各滤波器的增益，从索引由第一个数字给出的那个滤波器开始。该滤波器的增益被设为列表中的第二个数字。列表中后面还有的数字会设置紧接第一个指定滤波器之后那些滤波器的增益。索引从 0 开始计数。

参数：

  • amplitudes [list]

gainAll

左入口：单词 gainAll 后面跟一个 float，会把所有滤波器的增益设为给定的浮点取值。

参数：

  • general-amplitude [float]

signal

左入口上的信号会被送往所有滤波器。

输出

signal

每个滤波器的输出由各自独立的出口提供。最左侧的出口是第一个滤波器的输出。
