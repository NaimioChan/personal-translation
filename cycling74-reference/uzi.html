Max

uzi

发送大量 bang 消息

描述

快速输出指定数量的 bang 消息。uzi 专为连发大量 bang 消息而设计。

参数

initial [int] 可选

设置在左入口收到 bang 时初始要送出的 bang 消息数量。如果没有参数，uzi 初始被设为送出一个 bang。

base [int] 可选

可选的第二个参数设置右出口计数的基数。未给出第二个参数时，基数默认为 1。

消息

bang

左入口：开始尽可能快地接连送出 bang 消息。要发送的 bang 消息数量由任一入口最后收到的数字决定。

int

左入口：设置要发送的 bang 消息数量，然后开始尽可能快地接连送出这些消息。

参数：

  • input [int]

(inlet1)

右入口：设置要发送的 bang 消息数量，但不引起输出。

参数：

  • bangs-without-output [int]

break

与 pause 相同。

continue

与 resume 相同。

offset

offset 一词后面跟一个 bang 数量，会把对象设为输出一个偏移给定数量后的 bang 计数（该数字会从先前指定的 bang 数量中减去，得到新的 bang 总数）。

参数：

  • start [int]

pause

左入口：使 uzi 在送出其输出的过程中停止。（由于 uzi 会尽可能快地送出输出，该消息必须以某种方式由 uzi 自身的输出触发。）uzi 会记录自己已发送了多少条 bang 消息，如果它在送完所有 bang 消息之前收到 pause 消息，那么之后可以用 resume 或 continue 消息让它送出剩余的 bang 消息。

resume

左入口：如果 uzi 在送出其输出的过程中被 pause 消息停止，resume 会使它送出剩余的输出。

输出

bang

左出口：当 uzi 在左入口收到 bang 或 int 时，会尽可能快地接连送出一定数量的 bang 消息。bang 消息的数量由任一入口最近收到的数字决定。

中间出口：最后一个 bang 从左出口送出后，uzi 会从中间出口送出一个 bang。这可以用作所有 bang 消息都已发送的信号，很像 counter 对象上的 "carry" 出口。

int

右出口：送出每个 bang 的编号。左入口每收到一个 int 或 bang，编号从 1（或从可选的第二个参数指定的基数）开始。如果 uzi 因 resume 或 continue 消息而重新开始，编号从中断处继续。
