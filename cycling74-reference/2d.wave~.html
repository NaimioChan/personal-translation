MSP

2d.wave~

2 维波表

描述

2d.wave~ 与 wave~ 类似，但多了一个轴。音频文件中给定的 ms 范围会被分成 n 行。Y 相位输入决定播放时使用哪一行（或哪几行）。当 2d.wave~ 对象以 mcs.2d.wave~ 的形式实例化时，它的各个输出会合并为一个多通道输出，但在其他方面其行为与 2d.wave~ 完全相同。

讨论

试试载入一段 16 小节的循环，并把 rows 设为 16（设成 7 也行）。也可以试试把音频文件中一小段（约 150 ms）当作 2 维波表使用。把一个轴的相位器设得很快，把另一个轴设得很慢。

参数

buffer-name [symbol] 可选

必需的。给出 buffer~ 对象的名称，2d.wave~ 用它存放的采样内存来保存自己的波形。请注意，若 buffer~ 中的底层数据发生变化，2d.wave~ 的信号输出也会变化，因为它并不复制 buffer~ 中的采样数据。2d.wave~ 总是使用多通道 buffer~ 的前 n 个通道，其中 n 是 2d.wave~ 对象输出通道的数量。通道数的默认值由 2d.wave~ 对象的第三个参数设定，为 1。

start and end-points [number] 可选

在 buffer~ 名称参数之后，你可以键入波形的起点与终点取值，以从 buffer~ 对象采样内存起始处算起的毫秒偏移量表示。默认情况下起点为 0，终点为采样的末尾。若想设置非零的起点、同时保留采样末尾作为波形终点，只需在 buffer~ 名称之后使用一个键入型参数。若起点（中间）入口连接了 signal，则初始的波形起点参数会被忽略。若终点（右）入口连接了 signal，则初始的波形终点会被忽略。buffer~ 文件中的通道数以及要使用的行数也可以指定。

number-of-output-channels [int] 可选

设置输出通道的数量，它决定 2d.wave~ 对象将会具有的出口数量。通道数上限为 8。默认值为 1。若所播放音频文件的输出通道数多于 2d.wave~ 对象，则编号更大的通道不会被播放。若音频文件的通道数更少，则从 2d.wave~ 多出的出口送出的信号为 0。

rows [int] 可选

设置把文件分成的 rows 初始数量。

float

第 3 个或第 4 个入口：可以用数字代替 signal 对象来控制波形的起点与终点，前提是接收该数字的入口没有连接信号。

list

TEXT_HERE

(mouse)

双击 2d.wave~ 对象会打开一个窗口，显示载入到该对象所关联缓冲区中的音频文件。

rows

rows 一词后跟一个 int，设置音频文件中给定的一段范围将被分成的行数。在 2d.wave~ 的第 2 个入口收到的相位输入信号取值决定播放时使用哪一行（或哪几行）。默认值为 0。

参数：

  • number-of-divisions [int]

set

set 一词后跟一个 symbol，设置 buffer~，让 2d.wave~ 用它来存放波形。该 symbol 后面可选地跟两个取值，用来设置新的波形起点与终点。若没有给出这些取值，则使用默认的起点与终点（采样的起始与末尾）。若起点和/或终点入口连接了 signal 对象，则起点和/或终点取值会被忽略。

参数：

  • buffer-name [symbol]
  • start-point [float]
  • end-point [float]

signal

左入口：从 0 递增到 1 的输入信号取值用来扫描 buffer~ 对象中指定的一段采样点。phasor~ 的输出可以像振荡器那样用来控制 2d.wave~，把 buffer~ 中那段采样点当作一段重复波形。不过请注意，改变左入口上连接的 phasor~ 的频率时，从 2d.wave~ 送出的信号所感知到的音高可能并不完全对应 phasor~ 自身的频率，前提是所存储的波形中包含波形的多次重复或部分重复。你可以把 phasor~ 反相来倒放该波形。

第 2 个入口：从 0 递增到 1 的输入信号取值用来决定使用 rows 消息所指定的哪一行（或哪几行）来播放。你可以把 phasor~ 反相来颠倒各行的播放顺序。

第 3 个入口：波形的起点，以从 buffer~ 对象采样内存起始处算起的毫秒偏移量表示。

第 4 个入口：波形的终点，以从 buffer~ 对象采样内存起始处算起的毫秒偏移量表示。

输出

signal

buffer~ 中由 2d.wave~ 对象起点与终点所指定的那部分，会被 2d.wave~ 对象入口中 0 到 1 范围内的信号取值扫描，并把 buffer~ 中对应的采样取值送出 2d.wave~ 对象的出口。若该对象入口收到的信号是一段重复信号（例如来自 phasor~ 的锯齿波），则得到的输出会是一段以对应于输入信号重复的该频率反复出现的波形（摘自 buffer~）。
