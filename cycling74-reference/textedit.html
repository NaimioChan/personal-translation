Max

textedit

输入文字

描述

在补丁中提供一个用户界面，可以收集从计算机键盘键入的文字。

参数

无。

特性

annotation_name [symbol] :

信息视图标题

autoscroll [int] : 1

切换文本显示区域中的自动滚动。消息 autoscroll 1 让你可以用光标，或在 textedit 窗口中点击并拖动来滚动——当行数设为 1 且自动换行被禁用（见 wordwrap 消息）时，你就能滚动到超出 textedit 窗口所显示文字量的位置。默认值为 0（禁用自动滚动）。

bangmode [int] : 0

当 bangmode 设为 "Bang Outputs Typed Text"（0 = 默认值）时，收到 bang 后 textedit 对象会输出当前正在键入的文字。当设为 "Bang Outputs Entered Text"（1）时，textedit 对象会输出先前输入的文字（会等到正在键入的文字完成后再送出新的取值）。
可选值：

0 = 'Bang Outputs Typed Text'
1 = 'Bang Outputs Entered Text'

bgcolor [4 floats]

以 RGBA 格式设置 textedit 对象的背景颜色。

border [float] : 2.

设置 textedit 对象边框的大小（单位：像素）。默认值为 1。

bordercolor [4 floats]

以 RGBA 格式设置 textedit 对象的边框颜色。bordercolor 特性映射到 elementcolor 样式颜色。

clickmode [int] : 0

设置 textedit 对象在文本显示区域中响应鼠标点击的方式。消息 clickmode 0 会把所点击的单个字符从 textedit 对象的右出口送出。用消息 clickmode 1 设置对象，则会送出用户点击的单词。默认值为 0（选择字符）。
可选值：

0 = 'Output Character'
1 = 'Output Word'

keymode [int] : 0

设置 textedit 对象在其文本显示区域中键入字符时响应回车的方式。消息 keymode 0 允许输入文本，并正常显示回车。用消息 keymode 1 设置对象，会让回车输出当前缓冲区的全部内容。默认值为 0。

lines [int] : 0

设置 textedit 对象显示的行数。

nosymquotes [int] : 0

设置 textedit 对象是否在单个符号周围显示引号。请注意，符号一旦从 textedit 送出，在 Max 中就会用引号表示。nosymquotes 对包含多个元素的内容没有影响（无论启用还是禁用 nosymquotes，"foo bar bap" bep 都会显示成一样）。

outputmode [int] : 0

设置 textedit 对象是把内容作为消息（0）输出，还是作为单个符号（1）输出。消息 outputmode 0 会让对象的输出以消息形式送出。用消息 outputmode 1 设置对象，会把缓冲区内容作为单个符号输出。默认值为 0（以消息输出）。

param_connect [symbol] :

在对象与具有参数的兼容对象（如 gen~ 或 jit.gl.slab）的某个参数之间建立双向连接。该对象可用来改变参数的值，参数值变化时它也会随之更新。设置 param_connect 最简便的方法，是使用该特性在 inspector 中的菜单，或使用 Object Action 菜单的 Connect 子菜单。菜单会列出兼容对象的所有可用参数。

用消息设置 param_connect 特性时，需要给出目标参数的路径，即宿主对象的脚本名后跟两个冒号，再加上参数名。例如，对于一个 gen~ 对象，若其脚本名为 gen~_AB，则 freq 参数的路径为 gen~_AB::freq。可以在宿主对象或参数尚不存在时就为 param_connect 设值，该对象会在参数出现后与之建立连接。更多细节请参阅用户指南中 param_connect 条目。

parameter_enable [int]

启用后，该对象可与 Max for Live Parameters 配合使用。

parameter_mappable [int] : 1

启用 parameter_mappable 后，该对象即可通过映射功能映射到键盘或 MIDI 输入。

readonly [int] : 0

切换 textedit 对象的只读模式。消息 readonly 1 会禁止用户向文本框中输入任何内容。针对 textedit 缓冲区当前内容进行操作的消息（如 clear、append 或 separator）不受 readonly 消息影响。默认值为 0（只读模式关闭）。

rounded [float] : 8.

设置 textedit 对象圆角的半径（单位：像素）。

separator [symbol] : nothing

把一个符号指定为行分隔符，并在输出缓冲区内容时把它当作回车处理。若缓冲区包含文字 "red green blue"，而对象收到消息 separator green，则下一个 bang 会让 textedit 输出 red（回车）blue。

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

tabmode [int] : 1

切换是否可以让 Tab 键输出当前缓冲区的全部内容。默认值为 1（开启）。

textcolor [4 floats]

以 RGBA 格式设置文字颜色。textcolor 特性映射到 textcolor_inverse 样式颜色。

valuemode [int] : 0

设为 0（默认值）时，textedit 会原样保存/恢复键入对象的内容，并把文字作为数字与符号的列表输出，即使这些符号是分号（;）或逗号（,）。设为 1 时，textedit 会对文字求值，就像点击 message 对象框一样，并把求值后的文字保存为 textedit 的取值，同时遵循分号和逗号等特殊字符。若你想把 textedit 当作 message 对象框来用——例如发送带分号的消息、用逗号分隔消息等——这一模式会很有帮助。

wordwrap [int] : 1

设置 textedit 对象显示长于 textedit 显示区域的消息的方式。消息 wordwrap 0 会禁用显示区域内按单词边界进行的文本换行。wordwrap 默认启用（设为 1）。

通用对象框特性

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

输出 textedit 对象缓冲区中键入或存储的内容。

int

设置 textedit 对象缓冲区的内容，且不产生输出。

参数：

  • input [int]

float

设置 textedit 对象缓冲区的内容，且不产生输出。

参数：

  • input [float]

list

只要列表由数字构成，就设置 textedit 对象缓冲区的内容且不产生输出；否则会显示错误消息。

参数：

  • input [list]

(mouse)

用鼠标点击 textedit 对象（当补丁窗口已锁定时），会让 textedit 对象根据点击模式的设置，把选中的字母或单词从右出口送出（见 clickmode 消息）。

(typing)

当 textedit 对象处于高亮状态时，键入会把文字输入文本显示区域并修改其缓冲区，除非对象被设为只读模式（见 readonly 消息）。所键入字符的 ASCII 值会从中间出口送出。

(drag)

把文件拖到 textedit 对象上时，会添加完整文件名，替换先前键入的任何文字。松开鼠标时按住 option/command（Mac）或 option/alt（Windows）键，会把文件名追加到现有文字之后，而不是替换它。若文件在 Max 的搜索路径中，则只添加文件名。若文件不在 Max 的搜索路径中，则会添加完整的文件路径。

append

单词 append 后面跟一个消息，会把该消息追加到 textedit 对象的缓冲区，且不产生任何输出。

参数：

  • input [list]

clear

清除 textedit 对象缓冲区的内容。

dictionary

消息 dictionary 后面跟一个有效的字典名称，会把 dictionary 中 "text" 键的内容显示在 textedit 对象中，且不产生输出。若要把 set 或 append 消息发往 textedit，dictionary 中应包含 "mode" : "set" 或 "mode" : "append" 这一项。

参数：

  • dict-name [symbol]

select

会让所有文字（若有）高亮显示，并在对象不处于只读模式时，把对象设为键盘事件的目标。

set

单词 set 后面跟任意消息，会设置 textedit 对象缓冲区的内容，且不产生输出。

参数：

  • input [list]

输出

symbol

左出口：textedit 对象缓冲区当前存储的内容会在前面加上单词 text，在对象收到 bang 消息时输出。若 textedit 已被设为在回车时输入文字（使用 keymode 1 消息），则回车也会输出键入的文字和缓冲区的内容。

symbol

中间出口：所键入按键的 ASCII 值。

symbol

右出口：用户在 textedit 对象的文本框中点击的单词或字母。
