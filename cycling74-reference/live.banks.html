Max for Live

live.banks

为 Push 控制器管理 Max for Live Device 参数组。

描述

创建、编辑和删除 Max for Live Device 参数组，也就是显示在 Ableton Push 控制器上的那些组。组随设备一起保存，但可以在实时中修改，从而引发 Push 显示屏上的更新。例如，你可能想根据设备状态显示或隐藏某个组内的特定参数。

参数

无。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'

'16'

'24'
'30'
'36'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

(mouse)

双击打开 Parameter Banks 窗口。该功能只在编辑器中可用，在 Live 内部被禁用。

delete

删除一个参数组。删除组会使索引更高的那些组的索引值递减。

参数：

  • bank_id [int]

edit

编辑由 bank_id 指定的参数组（索引从 0 开始）。要更改组名，可传入新名字作为 bank_name，也可以传入 -（减号）以使用现有的名字。可选的参数列表应采用 parameter_index parameter_name 形式的索引/名字对列表。例如，edit 0 newname 0 foo 2 bar 4 - 5 bap 会把组 0 的名字改为 newname，并把参数编码器槽 0 改为使用参数 foo、槽 2 使用参数 bar、移除槽 4 中的参数，再把槽 5 分配给名为 bap 的参数。

要添加按钮分配，请在编码器分配列表后面加上单词 @buttons，再跟一个使用与上面相同格式的参数列表。

参数：

  • bank_id [int]
  • bank_name [symbol]
  • bank_parameters [list]

getcount

从出口送出 count 消息，后面跟参数组的数量。

getname

从出口送出 name 消息，后面跟指定参数组的索引（int）和名字（symbol）。

参数：

  • bank_id [int]

getparameters

从出口送出 parameters 消息，后面跟指定参数组的索引（int）以及该组中参数名字（symbol）的列表。

参数：

  • bank_id [int]

new

在 bank_id 指定的索引处创建一个参数组（索引从 0 开始）。如果该索引处已经存在参数组，新参数组会插入到指定索引，所有索引更高的参数组索引都会加一。参数组需要一个名称，由 bank_name 指定。参数列表应是一个最多含 8 个 symbol 的列表，给出参数组编码器槽位 0-7 对应的参数名。可以用一个 -（减号）表示某个槽位不关联参数。

若要添加按钮分配，在编码器分配列表之后加上单词 @buttons，再跟一个使用与上面相同格式的参数列表。

注意：创建参数组时，可以指定的索引高于参数组数量。也就是说，可以从一组空参数组开始，先创建参数组 3。这种情况下，槽位 0、1、2 中会创建占位参数组。占位参数组在 Parameter Banks 窗口中用灰色文字显示。编辑占位参数组会让它变成“真正”的参数组。在占位参数组占据的索引处创建新参数组会就地替换该占位参数组，而不是执行插入。

参数：

  • bank_id [int]
  • bank_name [symbol]
  • bank_parameters [list]
