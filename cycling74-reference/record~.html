MSP

record~

把声音录制到缓冲区中

描述

record~ 把信号录制到 buffer~ 对象中。你可以用可选的 input-channels 参数指定要录制多少个通道。当 buffer~ 被填满时录制停止。

参数

buffer-name [symbol] 可选

必需。给出 buffer~ 的名称，record~ 会把录制的采样点写入其中。

input-channels [int] 可选

指定输入通道的数量（1、2、4、50 等）。这决定 record~ 拥有多少个入口。最右边的两个入口始终用于设置录制开始点与结束点。

特性

append [int]

单词 append 后面跟一个非零数字会启用 append 模式。在此模式下，当录制打开时，它会从上次停止的地方继续。append 0 禁用 append 模式。这种情况下，录制打开时总是从开始点开始。append 模式默认初始为关闭。

loop [int]

单词 loop 后面跟一个非零数字会启用循环录制模式。在循环模式下，当录制到达录制的结束点（见上文）时，它会在开始点继续。loop 0 禁用循环录制模式。这种情况下，录制到达结束点时就会停止。循环模式默认初始为关闭。record~ 对象还会考虑 buffer~ 对象采样率的变化，前提是为了确定循环点而修改了 buffer~ 对象的长度。

loopend [Time Value] : 0 ms

设置对象的循环结束点。采样间隔可以用 Max 中使用的任意一种 时间格式 来指定。

loopstart [Time Value] : 0 ms

设置对象的循环开始点。采样间隔可以用 Max 中使用的任意一种 时间格式 来指定。

transport [symbol]

要与之关联的 transport 对象的名称。默认使用全局走带。

消息

int

左入口：任何非零数字都会开始录制；0 停止录制。除非 append 模式打开，否则录制从开始点开始。

右入口左边的入口：设置录制在 buffer~ 中的开始点（以毫秒为单位）。默认情况下，开始点是 0（buffer~ 的开头）。

右入口：设置录制的结束点。默认情况下，结束点是 buffer~ 对象所分配内存的末尾。

参数：

  • recording-flag (0 or nonzero) [int]

float

左入口：任何非零数字都会开始录制；0 停止录制。除非 append 模式打开，否则录制从开始点开始。

右入口左边的入口：设置录制在 buffer~ 中的开始点（以毫秒为单位）。默认情况下，开始点是 0（buffer~ 的开头）。

右入口：设置录制的结束点。默认情况下，结束点是 buffer~ 对象所分配内存的末尾。

参数：

  • recording-flag (0 or nonzero) [float]

list

list 可用于为 transport 指定循环开始点与循环结束点，或者计时/同步设置。

参数：

  • loop-start/loop-end/timing-parameters [list]

anything

list 可用于为 transport 指定循环开始点与循环结束点，或者计时/同步设置。

参数：

  • loop-start/loop-end/timing-parameters [list]

(mouse)

双击 record~ 会打开一个编辑窗口，在其中可以查看与其关联的 buffer~ 对象的内容。

reset

单词 reset 会把录制循环点重置为默认值（默认值会录制所指定 buffer~ 的整个时长）。

set

单词 set 后面跟一个 buffer~ 的名称，会把 buffer~ 改成 record~ 将把录制的采样点写入其中的那个。

参数：

  • buffer-name [symbol]

signal

左入口：当录制打开时，信号会以当前采样率被录制到 buffer~ 的采样内存中。

中间入口：如果 record~ 有不止一个输入通道，这些入口会把额外的通道录制到 buffer~ 中。

输出

signal

同步输出。录制期间，该出口会输出一个 signal，它在开始点录制时为 0，在录制到达结束点时变为 1。未在录制时，输出零信号。
