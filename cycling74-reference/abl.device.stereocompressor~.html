Ableton DSP

abl.device.stereocompressor~

立体声压缩器

描述

带三种压缩模式的立体声压缩器。

参数

attack [number] 可选

启动时间

release [number] 可选

释放时间

threshold [number] 可选

阈值

gain [number] 可选

补偿增益

特性

attack [float]

设置输入信号超过阈值后达到最大压缩所需的时间（毫秒）。[0.01, 1000.]

autorelease [int]

启用后，会根据传入音频自动调整释音时间。

compression [float]

设置模式为 Peak 或 RMS 时输入电平与输出电平之间的压缩比率。例如比率为 3 表示输入超过阈值电平后每增加 3 dB，输出电平只增加 1 dB。比率为 1 时不会产生压缩。[1., 3.4e38]

envfollowermode [int]

设置压缩释音的形态。在 Logarithmic 模式下，被强烈压缩的峰值会比压缩较少的素材有更快的释音时间。相比 Linear 模式，这可以带来更平滑、更不易察觉的压缩。
可选值：

0 = 'Linear'
1 = 'Logarithmic'

expansion [float]

设置模式为 Expand 时输入电平与输出电平之间的扩展比率。例如比率为 1 比 2 表示输入超过阈值电平后每增加 1 dB，输出电平增加 2 dB。比率为 1 时不会产生扩展。[1., 2.]

gain [float]

设置压缩之后施加到信号上的增益量，单位为 dB。[-36, 36.]

knee [float]

调整输入电平接近阈值时压缩器响应得有多快。为 0 dB 时，信号在超过阈值之前不施加任何压缩。这被称为硬拐点行为。取值越高，压缩会在接近阈值时更平缓地开始。[0., 18.]

makeup [int]

启用后，会在阈值与比率变化时自动补偿输出电平。注意，这种补偿发生在 Output Gain 控件之前。

mix [float]

设置输出信号的干/湿比。[0., 1.]

model [int]

压缩器模型
可选值：

0 = 'Peak'
1 = 'RMS'
2 = 'Expand'

release [float]

设置输入信号降到阈值以下后压缩停止所需的时间（毫秒）。注意，当 Auto Release 开启时该项无效。[1., 3000.]

threshold [float]

设置开始压缩的输入电平（单位：dB）。[-70.6, 6.]

ins [symbol]

声明额外的入口，用于以事件速率或信号速率控制 float 类型的特性。已映射到入口的已声明特性将被忽略。该特性只能在对象实例化时设置。
