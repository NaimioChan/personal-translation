Ableton DSP

abl.dsp.meldosc~

元振荡器

描述

abl.dsp.meldosc~ 对象封装了 Live 的 Meld 合成器中所用的振荡器。

参数

frequency [number] 可选

设置振荡器频率。范围：[0.0, 22050.0]

macro1 [number] 可选

设置 Macro 1 的取值。范围：[0.0, 1.0]

macro2 [number] 可选

设置 Macro 2 的取值。范围：[0.0, 1.0]

特性

frequency [float]

设置振荡器频率，单位为 Hz。范围：[0.0, 20500.0]

macro1 [float]

设置 Macro 1。功能取决于 type。范围：[0.0, 1.0]
Basic shapes：shape。
Bitgrunge：frequency。
Bubble：density。
Chip：tone。
Crackle：density。
Dual basic shapes：shape。
Extratone：pitch。
Filtered noise：frequency。
FM bass (squelch)：FM amount。
Fold FM：FM amount。
Harmonic FM：FM amount。
Noiseloop：rate。
Noisy shapes：shape。
Rain：tone。
Shepard's Pi：rate。
Simple FM：FM amount。
Square 5th：5th amount。
Square sync：freq 1。
Subosc：tone。
Swarm oscillators：motion。
Tarp：decay。

macro2 [float]

设置 Macro 2。功能取决于 type。范围：[0.0, 1.0]
Basic shapes：tone。
Bitgrunge：mult。
Bubble：spread。
Chip：rate。
Crackle：intensity。
Dual basic shapes：detune。
Extratone：env amount。
Filtered noise：narrowness。
FM bass (squelch)：feedback。
Fold FM：shape。
Harmonic FM：FM ratio。
Noiseloop：fade。
Noisy shapes：rough。
Rain：rate。
Shepard's Pi：width。
Simple FM：FM ratio。
Square 5th：pulse width。
Square sync：freq 2。
Sub：aux。
Swarm oscillators：spacing。
Tarp：tone。

type [int]

振荡器类型
可选值：

0 = 'Basic Shapes' ( Basic Shapes )
在经典合成器波形之间渐变，添加泛音或改变脉冲宽度。

1 = 'Bitgrunge' ( Bitgrunge )
一种伪随机 lo-fi 方波振荡器，让人想起从磁带加载老式电脑游戏的过程。

2 = 'Bubble' ( Bubble )
合成气泡发生器。

3 = 'Chip' ( Chip )
一种 chiptune 振荡器，提供音高、脉冲宽度和音程。

4 = 'Crackle' ( Crackle )
合成噼啪声发生器。

5 = 'Dual Basic Shapes' ( Dual Basic Shapes )
在经典合成器波形之间渐变，添加泛音或改变脉冲宽度。

6 = 'Extratone' ( Extratone )
一种以高速率重新触发底鼓振荡器的振荡器，产生类似颗粒的音调。

7 = 'Filtered Noise' ( Filtered Noise )
带谐振带通滤波器的噪声发生器。

8 = 'Fold Fm' ( Fold FM )
一种带调制量和波形折叠的谐波 FM 振荡器。

9 = 'Harmonic Fm' ( Harmonic FM )
一种带调制比和调制量的谐波 FM 振荡器。

10 = 'Noise Loop' ( Noise Loop )
一种以高速率循环噪声缓冲区的振荡器，产生类似颗粒的音调。

11 = 'Noisy Shapes' ( Noisy Shapes )
在经典合成器波形之间渐变，并定义噪声注入量。

12 = 'Rain' ( Rain )
带合成雨滴和风声的雨声发生器。

13 = 'Shepard's Pi' ( Shepard's Pi )
一种带深度和方向的 Shepard 音调振荡器。

14 = 'Simple Fm' ( Simple FM )
一种带调制指数和调制量的简单 FM 振荡器。

15 = 'Square 5th' ( Square 5th )
把方波渐变为高五度的方波，并可调整脉冲宽度。

16 = 'Square Sync' ( Square Sync )
两个同步的方波，各自的频率都可以定义。

17 = 'Squelch' ( FM Bass )
一种带调制指数量与运算符反馈的 FM 振荡器。

18 = 'Sub' ( Sub )
一种带波形渐变和额外子振荡器（aux）的子振荡器。

19 = 'Swarm Saw' ( Swarm Saw )
一族带调制和频率间距的锯齿波。

20 = 'Swarm Sine' ( Swarm Sine )
一族带调制和频率间距的正弦波。

21 = 'Swarm Square' ( Swarm Square )
一族带调制和频率间距的方波。

22 = 'Swarm Triangle' ( Swarm Triangle )
一族带调制和频率间距的三角波。

23 = 'Tarp' ( Tarp )
一种带衰减和音色控制的冲量/鼓振荡器。
