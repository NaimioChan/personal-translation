MSP

plus~

相加信号

描述

用 +~ 对象把两个信号相加，或给一个信号加上一个偏移值。

参数

initial-offset [number] 可选

设置一个初始偏移量，要加到左入口送入的信号上。若右入口连接了信号，该参数会被忽略。若没有参数，且右入口没有连接信号，初始值默认是 0。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'

'12'
'13'
'14'
'16'

'20'

'30'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

int

左入口：一个偏移量，要加到右入口送入的信号上。若左、右入口都连接了信号，则任一个入口上连接的 float 或 int 都会被忽略。

右入口：一个偏移量，要加到左入口送入的信号上。若左、右入口都连接了信号，则任一个入口上连接的 float 或 int 都会被忽略。

参数：

  • offset [int]

float

左入口：一个偏移量，要加到右入口送入的信号上。若左、右入口都连接了信号，则任一个入口上连接的 float 或 int 都会被忽略。

右入口：一个偏移量，要加到左入口送入的信号上。若左、右入口都连接了信号，则任一个入口上连接的 float 或 int 都会被忽略。

参数：

  • offset [float]

signal

左入口：该信号加到右入口送入的信号，或右入口收到的常量值上。送至同一个入口的所有信号输入都会相加。若同时向左入口送入一个信号和一个数字，则会用这些取值执行指定的运算。

右入口：该信号加到左入口送入的信号，或左入口收到的常量值上。送至同一个入口的所有信号输入都会相加。

输出

signal

两个输入之和。
