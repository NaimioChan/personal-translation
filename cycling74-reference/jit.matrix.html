Jitter

jit.matrix

Jitter 矩阵！

描述

jit.matrix 对象是一个具名矩阵，可用于矩阵数据的存储与取出、重采样，以及矩阵类型与 planecount 转换等操作。

特性

adapt [int]

矩阵自适应标志（若给出了矩阵参数则默认值为 0，否则为 1）。该标志置位时，jit.matrix 对象会自适应输入矩阵的 planecount、type 和 dimensions。

dim [32 ints]

矩阵数据的维度（默认值 = 1 1）

dimstride [32 ints] 只读

每个维度上的字节步幅

dstdimend [32 ints]

目标维度的结束位置（默认值 = 所有 dim 取值减 1）

dstdimstart [32 ints]

目标维度的起始位置（默认值 = 全为 0）

interp [int]

矩阵插值标志（默认值 = 0）该标志置位时，输入矩阵在复制到内部矩阵时会被插值。

name [symbol]

矩阵的名称（默认值 = UID）

planecount [int]

矩阵数据中的通道数（默认值 = 4）

planemap [32 ints]

把输入的各个通道映射到输出的各个通道（默认值 = 0 1 2 3 ...）

thru [int]

Thru 模式标志（默认值 = 1）该标志置位时，收到一个矩阵就会输出一个矩阵。

size [int] 只读

矩阵的总字节大小

srcdimend [32 ints]

源维度的结束位置（默认值 = 所有 dim 取值减 1）

srcdimstart [32 ints]

源维度的起始位置（默认值 = 全为 0）

usedstdim [int]

Destdim 使用标志（默认值 = 0）该标志置位时，把输入矩阵复制到内部矩阵时会使用目标维度的特性。

usesrcdim [int]

Srcdim 使用标志（默认值 = 0）该标志置位时，把输入矩阵复制到内部矩阵时会使用源维度的特性。

type [symbol]

矩阵数据类型（默认值 = char）
可选值：

'char'（Char 数据）
Char 数据（0-255）

'long'（Long 数据）
Long 数据

'float32'（32 位浮点数据）
32 位浮点数据

'float64'（64 位浮点数据）
64 位浮点数据

消息

bang

输出当前存储的矩阵。

int

把所有单元格设为 value(s) 指定的取值并输出数据。位置由长度等于维度数（dimcount）的列表指定。

参数：

  • values [list]

float

把所有单元格设为 value(s) 指定的取值并输出数据。取值由长度等于维度数（dimcount）的列表指定。

参数：

  • values [list]

list

把所有单元格设为 value(s) 指定的取值并输出数据。位置由长度等于维度数（dimcount）的列表指定。

参数：

  • values [list]

(drag)

把兼容的媒体文件拖放到对象上即可将其加载。

clear

把矩阵的所有取值设为零。

exportimage

把当前帧导出为图像文件，文件名由第一个参数指定。第二个参数设置文件类型（默认值 = png）。可用的文件类型有 png、tiff 和 jpeg。
你可以使用 Max Preferences 来为 PNG 图像指定默认图像分辨率。

参数：

  • filename [symbol]
  • file-type [symbol]

exportmovie

把矩阵导出为影片。exportmovie 消息接受一个可选参数来指定文件名。若未指定文件名，会打开文件对话框让你选择文件。
参见 jit.record 对象，了解 write 参数及其默认值。

参数：

  • filename [symbol]
  • FPS [float]
  • codec [symbol]
  • quality [symbol]
  • timescale [int]

exprfill

对 expression 求值以填充矩阵。若提供了 plane 参数，表达式只作用于单个通道。否则，它作用于矩阵中的所有通道。关于表达式的更多信息请参阅 jit.expr。与 jit.expr 对象不同，这里不支持一次提供多个表达式、用不同的表达式填充多个通道。请对每个希望填充的通道分别多次调用本方法。

参数：

  • plane [int]
  • expression [symbol]

fillplane

单词 fillplane 后面跟一个指定通道号与取值的整数时，会用该单一取值填充指定的通道。

参数：

  • plane [int]
  • value [int]

getcell

把 position 所指定单元格中的取值从对象的右出口送出，形式为 cell cell-position0... cell-positionN val plane0-value... planeN-value 的列表。

参数：

  • position [list]

importmovie

把影片导入到矩阵中。若未指定文件名，会打开文件对话框让你选择文件。time-offset 参数可用于设置所导入影片的时间偏移（默认值为 0）。

参数：

  • filename [symbol]
  • time-offset [int]

jit_gl_texture

把 texture-name 指定的纹理复制到矩阵。

参数：

  • texture-name [symbol]

op

单词 op 后面跟一个 jit.op 对象运算符的名称以及一组取值，等价于加入一个 jit.op 对象：把指定的运算符设为特性，并把此 jit.matrix 对象指定为输出矩阵。额外的 value 参数既可以是矩阵名，也可以是常量。若只提供一个取值参数，此矩阵会同时被视为输出与左操作数。例如，"op + foo bar" 等价于运算 thismatrix = foo + bar，而 "op * 0.5" 等价于运算 thismatrix = thismatrix * 0.5。

read

把 Jitter 二进制数据文件（.jxf）读入矩阵集。若未指定文件名，会打开文件对话框让你选择文件。

参数：

  • filename [symbol]

setall

把所有单元格设为 value(s) 指定的取值。位置由长度等于维度数（dimcount）的列表指定。

参数：

  • values [list]

setcell

把 position 所指定的单元格设为 value 所指定的取值。位置由长度等于维度数（dimcount）的列表指定。可选的参数 plane plane-number 可用于指定某个通道。若指定了通道，value 应为单个数字，否则它应为长度等于 planecount - 1 的数字列表。

参数：

  • position [list]
  • group（可选）
    plane [literal]
    plane-number [int]
    end group
  • val [literal]
  • values [list]

setcell1d

单词 setcell1d 后面跟一个指定 x 坐标的数字和一个取值列表，它与 setcell 消息类似，但由于维度数（1）是固定的，无需用 "val" 记号把坐标与取值分开。

setcell2d

单词 setcell2d 后面跟一对指定 x 与 y 坐标的数字和一个取值列表，它与 setcell 消息类似，但由于维度数（2）是固定的，无需用 "val" 记号把坐标与取值分开。

setcell3d

单词 setcell3d 后面跟三个指定 x、y 与 z 坐标的数字和一个取值列表，它与 setcell 消息类似，但由于维度数（3）是固定的，无需用 "val" 记号把坐标与取值分开。

setplane1d

单词 setplane1d 后面跟一个指定 x 坐标的数字、一个指定通道的数字和一个取值，它与 setcell 消息类似，但由于维度数（1）是固定的，无需用 "val" 记号把坐标与取值分开，也无需用 "plane" 记号指定要设置哪个通道。

setplane2d

单词 setplane2d 后面跟一对指定 x 与 y 坐标的数字、一个指定通道的数字和一个取值，它与 setcell 消息类似，但由于维度数（2）是固定的，无需用 "val" 记号把坐标与取值分开，也无需用 "plane" 记号指定要设置哪个通道。

setplane3d

单词 setplane3d 后面跟三个指定 x、y 与 z 坐标的数字、一个指定通道的数字和一个取值，它与 setcell 消息类似，但由于维度数（1）是固定的，无需用 "val" 记号把坐标与取值分开，也无需用 "plane" 记号指定要设置哪个通道。

val

把所有单元格设为 value(s) 指定的取值。位置由长度等于维度数（dimcount）的列表指定，并输出数据。

参数：

  • values [list]

write

把矩阵集写为 Jitter 二进制数据文件（.jxf）。若未指定文件名，会打开文件对话框让你选择文件。

参数：

  • filename [symbol]
