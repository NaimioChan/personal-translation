Max

pictslider

基于图片的滑动条控件

描述

一种用外部文件中的图片来呈现外观的滑动条控件。它使用两幅图片——一幅用于 "knob"，一幅用于滑块在其上移动的背景。pictslider 对象带有默认图片，如果你不想自己提供图片就会使用这些默认图片，但它的预期用途是创建外观可定制的控件。

讨论

你可以用 pictslider 对象创建水平或垂直的滑动条，也可以创建二维控制器（虚拟触控板或摇杆）。

注意：pictslider 对象通常使用以 Portable Network Graphics（.png）格式保存的图像。如果你在 Windows 上使用 Max，我们建议你安装 QuickTime，并选择完整安装所有可选组件，以便使用 PNG 或 PICT 文件以外的图像。

无。

图片文件格式

Specifications

pictslider 对象使用两个图片文件：一个用于背景，一个用于用鼠标在背景上移动的滑块。

背景图片文件可以是 PICT 格式，或者，若安装了 QuickTime 3.0 版或更高版本，也可以是 Jitter 附录 A 中列出的其他图形文件格式之一。背景图片文件必须具有下列布局：



只需要一幅图像；若只提供一幅图像，它会用于绘制背景的所有状态。额外的图像放在第一幅图像的右侧。你可以添加用于控件非激活状态的图像。非激活图像会在控件收到 active 0 消息之后使用。

滑块文件必须是 PICT 格式，并具有下列布局：



图片由一幅或多幅图像组成的网格构成。所有图像的宽度和高度都相同。

只需要一幅图像；若只提供一幅图像，它会用于绘制滑块的所有状态。额外的图像放在第一幅图像的右侧。你可以为控件的 "clicked" 状态或非激活状态、或两者都添加图像。"clicked" 图像会在用户拖动控件的滑块时显示。非激活图像会在控件收到 active 0 消息之后使用。

图像蒙版可以用来创建轮廓非矩形的滑块。这些蒙版在图片文件中直接位于对应图像的下方。若你想为任何一幅滑块图像使用蒙版，就必须为所有滑块图像都提供蒙版——每幅图像都会有一行对应的蒙版。蒙版图像中的黑色像素构成对应图像中会被绘制的区域，白色像素则构成不可见的区域。

输出

int

用鼠标点击并拖动滑动条上的滑块，或向它的任一入口发送值，都会使它的水平值从左出口发出、垂直值从右出口发出。传入的值会被限制在由 Inspector 中设置的 top/bottom 和 left/right 值所决定的范围内。
