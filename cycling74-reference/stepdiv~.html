MSP

stepdiv~

为函数的每一步生成相位器

描述

stepdiv~ 对象产生一个信号输出，它由一系列相位器组成，其时间依据 function 对象生成的断点函数列表中的各 delta time 而定。当左入口连有相位器信号时，stepdiv~ 会按各断点的相对时间对该相位器进行细分。未连信号输入时，stepdiv~ 会在指定的 delta time 上产生相位器。把 stepdiv~ 的左出口与右出口连到 stepfun~，即可生成真正的函数数据。

参数

无。

特性

curvemode [int] : 2

决定如何解释列表输入
可选值：

0 = 'Off'（无曲线数据）
当 curvemode 设为 Off 时，传入的列表总会被解释为一串取值-时间对。

1 = 'On'（始终解释为曲线数据）
当 curvemode 设为 On 时，传入的列表总会被解释为一组三个取值：取值、时间和曲线参数。

2 = 'Auto'（使用所连接的 function 对象的曲线模式）
当 curvemode 设为 Auto 时，传入的列表会依据最初发送该数据的 function 对象的当前设置来解释。

loop [int]

当 stepdiv~ 没有信号输入时，loop 特性若启用，则相位器序列在被 bang 消息触发之后就会循环。

pattern [atom]

你可以把一或多个时间赋给 pattern 特性，以设定每个输出相位器的相对时长或绝对时长。pattern 也可以通过 list 与 what 消息设置。

syncupdate [int]

启用 syncupdate 后，对 pattern 的修改要等到输入相位器重置（若左入口连有信号）或者输出序列走完（若未连信号）才生效。

消息

bang

未连信号输入时，bang 消息会启动相位器输出。若启用了 loop 特性，函数的所有步都送出之后，输出会从头重新开始。启用 Scheduler in Audio Interrupt 时，输出的起点是采样点精确的。

int

左入口：转换为 float
右入口：若未连信号入口，则设置当前步号

float

左入口：以指定的时间设置一个只含单步的模式。

list

列表会被解释为 line~ 格式的断点函数，该格式由 function 生成。这些时间值用于相位器的绝对时长或相对时长。

signal

若连有信号，stepdiv~ 会把输入相位器划分成一系列输出相位器，各输出相位器的时长反映每一步在整段函数中所占的时间比例。例如，时间 50 和 25 会产生两个相位器；第一个持续输入相位器时长的前 2/3，第二个持续最后的 1/3。

what

消息 what 后面跟一个或多个数字，会把这些取值当作从起点算起的偏移量而不是 delta time，从而创建一系列相位器。例如 what 0.25 0.5 0.75 会生成由三个相位器组成的序列，它们会分别在输入相位器的 25%、50% 与 75% 处重置。
