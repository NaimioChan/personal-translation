Jitter

jit.gl.mesh

Generate GL geometry from matrices

描述

Creates a geometric surface from a jit.matrix connected to the left-most inlet containing spatial coordinates. Additional geometry can be specified by attaching other jit.matrix or jit.gl.buffer objects to the other inlets.

讨论

Matrices feed into inlets represent (from left to right): vertex, texcoord, normal, color, specular (unused), edgeflag (unused), tangent, bitangent (unused), and index data. Inlets marked unused are legacy from the gl2 engine and will ignore matrix input when used in glcore. Any inlet (including those marked unused) can be bound to a jit.gl.buffer object via the jit_gl_buffer message.

This OB3D object optionally takes one argument: the name of a drawing context. This is a named instance of a jit.world, or jit.pworld object, or a jit.gl.node sub-context. This value may also be set via the OB3D drawto attribute. If no argument is present, the object is implicitly added to the first valid drawing context or sub-context found in the current patch or by searching up the patcher hierarchy.

特性

auto_colors [int]

Enables or disables the calculation of vertex colors (default = 0).

auto_normals [int]

Enables or disables the calculation of normal directions used for calculating lighting (default = 1).

auto_tangents [int]

Enables or disables the calculation of tangent directions (only available if texcoords and normals exist) (default = 0).

color_mode [symbol]

The mode to use for the calculating vertex colors. (default = position) Supported modes are:
Possible values:

'vertex'
'position'
'texcoord'
'normal'
'tangent'

draw_mode [symbol]

The mode to use for rendering the geometry. (default = tri_grid) Supported modes are:
Possible values:

'tri_grid'
'quad_grid'
'points'
'lines'
'line_strip'
'line_loop'
'triangles'
'tri_fan'
'tri_strip'
'quads'
'quad_strip'
'polygon'
'lines_adjacency'
'line_strip_adjacency'
'triangles_adjacency'
'triangle_strip_adjacency'

smooth_tangents [int]

Enables smooth tangents calculations when auto_tangents is enabled (default = 0). When on, tangent generation enables a secondary smoothing process, which can improve the look of tangent based effects (e.g. jit.gl.pbr heightmap) at the cost of extra processing.

tf_name [symbol]

When set to the name of an existing jit.gl.tf object, this mesh will be bound to that object and used to render the transform feedback processs.

usebvh [int]

Enable BVH-based picking (default = 1). When enabled, jit.gl.mesh builds a bounding volume hierarchy from its geometry so that mouse picking hits the actual triangles of the mesh. When disabled, no BVH is built and picking falls back to bounding box testing, faster and less precise. Set this to 0 for meshes where a per-triangle hit isn't meaningful, e.g. an unstructured collection of triangles, or where the geometry changes continuously and you would rather not pay to rebuild the hierarchy. Meshes drawn with a point or line draw_mode have no surface to intersect and use bounding box picking automatically.

当前旋转的四元数表示（默认值 = 0. 0. 0. 1.）。四元数是一种数学构造，它是一个四维向量，可以看作绕任意轴的旋转。四元数是 3D 空间中朝向的一种有用表示。

旋转角度以及绕其进行旋转的 xyz 向量，形式为 rotation-angle x y z（默认值 = 0. 0. 0. 1.）

把当前旋转设为绕 x、y、z 正轴旋转的复合，也称为欧拉角（默认值 = 0. 0. 0.）。默认顺序为 yzx，可用 jit.gl.render 的 rotate_order 特性更改。角度以度为单位。

shininess [float]

材质的镜面光泽度值（默认值 = 16.0）该值应为 0.-255. 范围内的浮点数。

smooth_shading [int]

平滑着色标志（默认值 = 0）该标志置位时，渲染时使用平滑着色。

tex_map [int]

自动生成纹理坐标控制的模式（默认值 = 0）
0 = 不生成坐标。
1 = 使用 OpenGL 的纹理生成，模式为 GL_OBJECT_LINEAR。这会以相对对象固定的朝向应用纹理。
2 = 使用 OpenGL 的纹理生成，模式为 GL_SPHERE_MAP。可用于创建反射效果。
3 = 使用 OpenGL 的纹理生成，模式为 GL_EYE_LINEAR。这会以相对 OpenGL 眼坐标固定的朝向应用纹理。
模式 1 和 3 受下面列出的 tex_plane_s 与 tex_plane_t 特性的值影响。

tex_plane_s [4 floats]

纹理生成系数 a b c d，适用于 tex_map 模式 1 和 3。（默认值 = 1. 0. 0. 0.）
这四个系数定义一个平面，用于生成 s 纹理坐标，它对应纹理图像的 x 轴。若 tex_map 模式为 1，则 s = ax + by + cz + dw，其中 x、y、z、w 是顶点的齐次坐标。

tex_plane_t [4 floats]

纹理生成系数 a b c d，适用于 tex_map 模式 1 和 3。（默认值 = 0. 1. 0. 0）
这四个系数定义一个平面，用于生成 t 纹理坐标，它对应纹理图像的 y 轴。

shader [symbol]

texture [8 symbols]

transform_reset [int]

模型视图与投影变换重置标志（默认值 = 0）该标志置位时，渲染对象之前会把模型视图变换与投影变换设为单位变换。这适用于精灵或公告板叠加，或按窗口大小自动缩放。transform_reset 标志的模式有：
0 = 不做任何事（默认值）
1 = 等比正交 glOrtho(-aspect, aspect, -1.0, 1.0, near_clip, far_clip);
2 = 归一化正交 glOrtho(-1.0, 1.0, -1.0, 1.0, near_clip, far_clip);
3 = 近裁剪面为 0.001 的等比透视 gluPerspective(lens_angle, aspect, 0.001/*near_clip*/, far_clip);
4 = 近裁剪面为 0.001 的归一化透视 gluPerspective(lens_angle, 1.0, 0.001/*near_clip*/, far_clip);

消息

(drag)

Drag and drop a Jitter material file

color_matrix

Specifies a matrix of color values. This must be the same size as the matrix specified by the vertex_matrix message, and can be a 3 or 4 plane matrix.

index_matrix

The word index_matrix, followed by a symbol, specifies a matrix of indices. It can be any size, but it must have 1 plane and be an integer matrix.

jit_gl_buffer

Bind a jit.gl.buffer object to this mesh. When bound, the buffer data is used by the mesh when rendering. The mesh inlet determines how the data is used (e.g. as color data or normal data), but this can be overridden by the jit.gl.buffer type attribute.

normal_matrix

The word normal_matrix, followed by a symbol, specifies a matrix of normal values. This must be the same size as the matrix specified by the vertex_matrix message. It must be a 3 plane matrix.

reset

Reset all parameters to the default state and clear any stored mesh data.

tangent_matrix

The word tangent_matrix, followed by a symbol, specifies a matrix of tangent values. This must be the same size as the matrix specified by the vertex_matrix message. It must be a 3 plane matrix.

texcoord_matrix

The word texcoord_matrix, followed by a symbol, specifies a matrix of texture coordinate values. This must be the same size as the matrix specified by the vertex_matrix message. It can be a 2, 3, or 4 plane matrix.

vertex_attr_matrix

The word vertex_attr_matrix, followed by a symbol, specifies a matrix of arbitrary per-vertex data

vertex_matrix

The word vertex_matrix, followed by a symbol, specifies a matrix of vertex values. It can be 3 or 4 planes.
