Max

sel

根据输入匹配情况输出 bang

描述

针对任何与其参数匹配的输入，有选择地输出一个 bang，并把不匹配的消息从最右出口送出。

参数

selectors [anything] 可选

参数可以是 int、float 或 symbol 的混合。参数的数量决定出口的数量（此外还有最右侧的那个出口）。如果没有参数，则只有一个其他出口，它被指定为整数编号 0。

inlet [int] 可选

如果只有一个 int 参数（或没有参数），右侧会创建一个第二个入口。该入口收到的数字会代替参数被存储。如果有多个参数，或者唯一的一个参数不是 int，则不会创建右入口。

特性

fuzzy [atom] : 0.

当 matchfloat 设为 1 时，fuzzy 特性允许进行模糊浮点比较。当向 select 发送 float 时（可能是经由 dial 对象或其他类似对象，这种情况下会发送很长的浮点数），这会很有用。例如，如果把数字 0.49999999 发送给带有参数 0.5 的 select，打开 matchfloat 并把 fuzzy 设为 0.01，就会让这两个浮点数被视为匹配。

matchfloat [int] : 0 >= 8.3.0

别名：exact

当 matchfloat 设为 1 时，select 对象会执行浮点比较。在此模式下，可以用 fuzzy 特性来匹配与给定 float selector 相距指定距离以内的浮点数。当 matchfloat 设为 0 时，float 会被忽略。旧的 exact 特性现在是 matchfloat 的别名。

消息

bang

功能与 anything 相同。bang 消息匹配参数中的 'bang' 符号。

int

功能与 anything 相同。

注意：如果某个 int 作为参数被多次列出，则只从最左侧的出口送出 bang 消息。

参数：

  • input [int]

(inlet1)

右入口：替换参数的值。只有存在单个 int 参数时才有右入口。

参数：

  • value [int]

float

功能与 anything 相同。

注意：如果某个 float 作为参数被多次列出，则只从最左侧的出口送出 bang 消息。

参数：

  • input [float]

list

执行与 anything 相同的功能。

参数：

  • input [list]

anything

如果列表中的第一个元素与对象参数匹配，所有输入都会作为 bang 从对应的某个出口有选择地输出；否则原样从对象最右侧的出口送出。

参数：

  • input [list]

symbol

执行与 anything 相同的功能。

参数：

  • input [symbol]

输出

anything

如果左入口收到的数字或符号与任何参数都不匹配，则从最右侧的出口送出。

bang

如果左入口收到的数字或符号与某个参数相同，则从与该参数对应的出口送出 bang。
