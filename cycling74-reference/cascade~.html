cascade~

级联的双二阶滤波器组

描述

使用 cascade~ 用一串双二阶滤波器对输入信号进行滤波。

参数

无。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

设置对象框轮廓的颜色。

1 = 'bold'

3 = 'bold italic'

消息

list

滤波器系数可以在左入口或右入口以 list 形式提供。系数应以五个为一组，每一组对应一个二阶节或双二阶。list 中的前五个系数用于该串中的第一个二阶节，接下来五个用于第二个，依此类推。

参数：

  • filter-coefficients [list]

bypass

单词 bypass 后面跟一个非零数字会打开旁通模式，并让未经滤波的干信号直通到该对象的出口；后面跟 0 则输出滤波后的信号。

参数：

  • operational-flag [int]

clear

把所有系数与采样点记忆重置为 0。

dictionary

单词 dictionary 后面跟一个符号，该符号引用一个具名的 filterdesign 对象字典（通过 name 特性设置），会让 cascade~ 对象使用该字典中的取值作为滤波器系数。

参数：

  • dictionary-name [symbol]

signal

左入口：待滤波的信号。该信号由一串双极点双零点（即双二阶）滤波器滤波，这类滤波器常被称为“二阶节”。

zero

单词 zero 后面跟一个非零数字会让滤波后的信号被静音；后面跟 0 则输出滤波后的信号（当旁通模式打开时，这不会阻止未滤波的信号出现在出口处）。

参数：

  • operational-flag [int]

输出

signal

经过滤波的信号。
