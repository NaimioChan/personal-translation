Max

text

把消息格式化为文本文件

描述

把传入的消息收集并格式化为文本，以文本行的形式输出。

参数

filename [symbol] 可选

命名一个在对象载入时要读入的文本文件。

特性

precision [int]

转换后的浮点值的小数位数。

stringout [int]

把各行作为字符串对象输出

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

int

把整数存储在 text 中。

参数：

  • input [int]

float

把 float 存储在 text 中。

参数：

  • input [float]

list

把列表存储在 text 中。

参数：

  • input [list]

anything

该消息存储在 text 对象中，放在先前存储的所有消息之后，其后跟一个空格。

参数：

  • input [list]

clear

清除 text 的内容。

cr

在 text 内容的末尾放入一个回车符，以开始新的一行。若 text 中的最后一个字符是空格，该回车符会替换那个空格。

(mouse)

用鼠标双击 text 对象（当补丁窗口被锁定时）会打开一个编辑窗口，可以在其中查看和编辑 text 的内容。text 对象在编辑窗口打开期间会忽略改变其文本的消息。与 capture 对象不同，在 text 的编辑窗口中所做的改动会真正改变该对象的内容。

dump

单词 dump 会使 text 把它的内容从对象的左出口送出。

filetype

单词 filetype 后面跟一个符号，设置可以被 text 对象读取和写入的文件类型。文件类型使用标准的 四字母文件类型代码 来指定（例如 filetype ffoo）。不带参数的 filetype 消息会恢复默认的文件行为——即 Max 二进制或文本文件格式。在 Windows 上，文件类型会根据 init 文件夹中 max-fileformats.txt 文件里包含的、发给 max 的消息，映射到文件名扩展名，该文件在启动时加载。如果你要定义自己的文件类型，可能需要在 init 文件夹中放入自己的文本文件，以指定扩展名与你的四字母类型代码之间的映射。

参数：

  • filetype-code (four letters) [symbol]

line

单词 line 后面跟一个数字，会让 text 把该行号的内容（最多 256 个字符）送出来，并在前面加上单词 set（用于设置 message 对象框的内容）。行号从 1 开始编号；任何小于 1 的行号消息都会被转换为 line 1。如果请求的行号不存在，则不会送出任何内容。

参数：

  • index [int]

open

打开对象的文本窗口进行编辑。在已锁定的补丁中双击 text 对象效果相同。编辑窗口打开期间，text 对象会忽略用于更改其文本的消息。与 capture 对象不同，在 text 的编辑窗口中所做的修改确实会改变对象的内容。不过，在编辑窗口关闭之前，这些修改不会被保存，也不会被传送到 text 对象。

query

单词 query 会把一个数字从对象的右出口送出，该数字指明 text 对象中存储的行数。

read

单词 read 后面跟一个指定文件名的符号，会读取某个文本文件的内容。若未指定文件名或路径名，read 消息会调出标准的 Open Document 对话框，以便指定文本文件。若要对此对象使用自定义文件类型，请使用 filetype 消息。

参数：

  • filename [symbol]

settitle

单词 settitle 后面跟任意单词，设置文本窗口的标题。若你希望不止一个单词作为默认文本出现，必须把这些单词放在双引号中，或在各空格前加上反斜杠（\）。

参数：

  • window-name [symbol]

symbol

单词 symbol 后面跟任意单词，会把该单词存储在 text 内容的末尾。若你想存储一个否则会被 text 理解为特定消息的单词，这很有用。例如 symbol clear 会把单词 clear 连同其后的一个空格存储在 text 内容的末尾，而不是擦除内容。

参数：

  • any symbol [symbol]

t_symbol

把该符号存储在 text 中。

参数：

  • input [symbol]

tab

在 text 内容的末尾放置一个制表位。若 text 中最后一个字符是空格，制表位会替换该空格。

wclose

关闭与 text 对象关联的窗口。

write

单词 write 后面跟一个指定文件名的符号，会把 text 的内容保存为当前默认文件夹中的文本文件，除非该文件用绝对路径名指定。若未指定文件名或路径名，write 消息会打开标准的 Save As 对话框，以便把 text 的内容保存到单独的文本文件中。若要对此对象使用自定义文件类型，请使用 filetype 消息。

请注意，在编辑窗口关闭之前，对 text 对象的修改不会被保存。

参数：

  • filename [symbol]

输出

bang

中间出口：当文件响应 read 消息加载完毕时，会从中间出口送出一个 bang。

int

右出口：响应 query 消息时，会从右出口送出一个数字，它对应 text 对象中存储的文本行数。

symbol

左出口：收到 line 消息时，会把指定行号的文本送出来，并在前面加上单词 set。该消息可用于设置 message 对象框的内容（也可以发给任何其他适用这条特定 set 消息的对象）。
