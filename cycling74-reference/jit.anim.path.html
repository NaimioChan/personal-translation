Jitter

jit.anim.path

对 3D 变换点构成的路径求值

描述

接收一系列 3D 变换点，并在它们之间插值。有关这种插值的更多信息，参见 jit.path 对象。每个点存储 11 个取值：一个时间取值、3 个位置取值、3 个缩放取值和 4 个四元数旋转取值。

特性

autohandles [int]

每次编辑路径时都启用把手取值的计算（默认值 = 1）。

automatic [int]

启用来自所挂接渲染上下文的自动动画通知（默认值 = 1）。

closed [int] 只读

表示路径是闭合的（第一个点与最后一个点相等）。

drawpath [symbol]

用于绘制该路径的 jit.gl.path 对象的名称。

drawto [symbol]

指派给具名绘制上下文，从而可以自动收到更新。

duration [float] 只读

路径时长，以秒为单位（默认值 = 0.）

endreport [int]

启用动画结束报告（默认值 = 0）。动画结束时会把符号 endnotify 从 dumpout 送出。仅在 loop = 0 时有效。

evalquat [int]

输出求值得到的四元数取值（默认值 = 0）。为路径添加朝向取值时会启用。

evalreport [int]

启用/禁用把求值参数的报告从 dumpout 送出（默认值 = 0）。该报告是一个 3 元素列表，其中各个元素依次以 0 到 1、0 到 duration、0 到 length 表示当前的求值参数。

evalscale [int]

输出求值得到的缩放取值（默认值 = 0）。为路径添加缩放取值时会启用。

fixed_delta [float] >= 9.0.0

锁定动画时所用的 delta time 取值，以秒为单位（默认值 = 0）。非零时，更新会用该取值来计算，而不是用帧之间的实际时间。用于非实时帧捕获很有用。若非零，会覆盖所绑定的 jit.world 的 fixed_delta 取值。

interpmode [symbol]

路径插值方法（默认值 = linear）。
可选值：

'linear'（线性插值）
线性插值

'spline'（Hermite 插值）
线性插值

length [float] 只读

路径长度（默认值 = 0.）

loop [int]

路径动画循环方式（默认值 = 1）。
可选值：

0 = 'off'
1 = 'on'
2 = 'palindrome'

loopreport [int]

启用动画循环报告（默认值 = 0）。动画循环时会把符号 loopnotify 从 dumpout 送出。仅在 loop 不为 0 时有效。

name [symbol]

指定实例的名称（默认值 = UID）。

play [int]

启用路径动画（默认值 = 0）。

pointcount [int] 只读

路径点的数量（默认值 = 0）。

position [3 floats] 只读

当前路径位置（默认值 = 0. 0. 0.）。

quat [4 floats] 只读

当前路径的四元数朝向（默认值 = 0. 0. 0. 1.）

rate [float]

动画速率取值（默认值 = 1.）

scale [3 floats] 只读

当前路径的缩放取值（默认值 = 1. 1. 1.）。

shortestrot [int]

在旋转之间采用最短路径（默认值 = 1）。

targetname [symbol]

目标对象的名称，该对象应当是 OpenGL 对象或 jit.anim.node 对象。

time [float]

当前路径时间取值（默认值 = 0.）

timemode [symbol]

决定添加到路径中的时间取值如何设定（默认值 = relative）。
可选值：

'absolute'（时间取值设为参数值）
'relative'（时间取值设为参数值加上此前的时间取值）
