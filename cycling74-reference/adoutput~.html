MSP

adoutput~

访问音频驱动输出通道

描述

使用 adoutput~ 对象可录制当前的音频输出，或把它送回你的补丁。相对于实际输出，adoutput~ 的输出延迟了一个信号向量。

讨论

默认情况下，adoutput~ 把音频驱动的通道 1 从其左出口送出、把通道 2 从其右出口送出。可选的参数用来指定你想要的通道。记住，这些并不是 dac~ 和 adc~ 所用的逻辑通道——它们是音频驱动对象「真正的」通道。通道号为 0 会关闭对应的输出。通道号大于当前音频驱动的真实通道数时，输出同样为零。

参数

audiodriver-output-channels [int] 可选

参数指定当前音频驱动的输出通道。可指定的通道数量没有上限。默认情况下，adoutput~ 会创建两个出口，并把当前音频驱动通道 1 和 2 的音频输出分配给它们。注意，这些通道号与 dac~ 和 adc~ 对象所用的逻辑通道号并不相同，它们代表驱动在任何重映射发生之后的「物理」输出。逻辑 dac~ 通道与音频驱动真实通道之间的关系，可以用 Audio Status 窗口的 I/O Mappings 子窗口来配置。

消息

set

set 一词后面跟两个数字，会把某个音频驱动输出通道分配给 adoutput~ 对象的一个信号出口。第一个数字是出口的索引，取值 0 表示左出口。第二个数字是音频驱动输出设备通道的索引，其中 1 表示第一个通道。若第二个数字为 0，指定的出口就会被关闭并输出零信号。

参数：

  • outlet-index [int]
  • audiodriver-output-channel-index [int]

输出

signal

adoutput~ 的每个出口输出一路来自所分配 audiodriver 通道的信号，延迟量为当前信号向量大小的采样点数。
