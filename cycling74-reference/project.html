参数

特性

amxdtype [int]

设置把项目导出为 Max for Live 设备时将创建的设备类型。
可选值：

0 = 'None'
1 = 'Audio'
2 = 'MIDI'
3 = 'Instrument'
4 = 'MIDI Generator'
5 = 'MIDI Transformation'

autolocalize [int]

若启用，加入 Project 的文件在被纳入 Project 之前，总会先复制到 Project 的文件夹中。

autoorganize [int]

若启用，Project 文件夹中的文件会根据文件类别（例如 "Patchers"、"Code"、"Media" 等）自动归入相应的子文件夹。

browsertext [symbol] :

设置项目的注解名称。若已设置，可以在 File Browser 中用这个名称搜索该项目。

devpath [symbol] : .

允许你为基于 AMXD 的项目开发选择一个项目专用文件夹。设置后，该项目的所有设备文件都会保存到该位置并从该位置引用。禁用时，项目使用全局文件夹 ~/Documents/Max 8/Max for Live Devices。

devpathtype [int] : 0

若启用，允许你为 Development Path 设置中指定的文件夹指定路径类型。
可选值：

0 = 'disabled'
1 = 'relative to device'
2 = 'absolute'

hideprojectwindow [int]

若启用（且仅当 Project 含有标记为 "Open on Project Load" 的补丁时），Project 窗口在 Project 打开后不会显示。

includepackages [int] : 0

冻结时包含 Packages

readonly [int]

若启用，导出的 Max for Live 设备将为只读。

showdependencies [int]

若启用，隐式依赖项会显示在 Project 窗口中。

sortmode [int]

设为 "Manual" 时，项目项可以手动排列。设为 "Ascending" 时，项目项会自动按 A-Z 排列。设为 "Descending" 时，项目项会自动按 Z-A 排列。
可选值：

0 = 'Manual'
1 = 'Ascending'
2 = 'Descending'

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。
