Max

jweb

网页浏览器

描述

jweb 对象使用跨平台的 Chromium Embedded Framework（CEF），在 Max UI 对象中承载网页。

参数

无。

特性

disablefind [int]

启用后，disablefind 会阻止用户用 Find... 命令在当前页面上查找文本。

history [symbol] :

指定一个具名字典（dict 对象），浏览器历史记录会记录在其中，最多记录由 historysize 特性设定的页数。先前访问过的页面可以用 gotohistory 消息重新载入。

historysize [int] : 25

设置浏览器历史记录的大小；默认值为 25 页。

rendermode [int]

当 rendermode 特性设置为 ‘offscreen’ 时，jweb 会先渲染到一个离屏缓冲区，然后绘制到补丁窗口。该模式较慢，但如果你需要 UI 元素显示在 jweb 对象前面，它很有用。设置为 ‘onscreen’ 时，jweb 渲染更快，但会直接在补丁中渲染（不使用离屏缓冲区），绘制在其他任何 UI 元素之上。设置为 'offscreen with transparent background' 时，jweb 对象的背景会被透明地渲染。
可选值：

0 = 'Offscreen'
1 = 'Onscreen'
2 = 'Offscreen with Transparent Background'

url [symbol] :

当前页面的 URL

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

anything

你可以向所包含网站的 JavaScript 发送任意消息。要能够接收消息，请务必按 Web Browser and jweb 指南所述设置 JavaScript。

back

back 消息会重新载入上一页数据，作用类似于常规网页浏览器中的 'Back' 按钮。

executejavascript

用 executejavascript 可以在当前显示的网页中注入并运行一段 JavaScript 代码。所给的代码会被插入新的 script 标签中并执行。

参数：

  • script [symbol]

forward

当已经载入多页序列、且对象收到了 back 消息时，forward 一词会前进到对象页面历史中的下一页。forward 的作用类似于常规网页浏览器中的 'Forward' 按钮。

gotohistory

若 history 特性已被设为某个具名字典，则 gotohistory 后面跟一个索引会导航到该字典中该索引对应的页面。最近访问过的页面存储在索引 0 处。

参数：

  • index [int]

(mouse)

在已锁定的补丁中，用鼠标（和键盘）与 jweb 显示的页面交互。

mute

mute 1 会静音该页面的音频输出；mute 0 会取消静音

参数：

  • mute-state [int]

read

read 一词后面跟指定 URL 或文件路径名的符号时，会读取该网页或文件并尝试渲染其内容。页面成功载入后，对象会从出口送出两条消息：url，后面跟根据所给参数载入的最终 URL；以及 title，后面跟作为符号的已载入页面标题。

参数：

  • url [symbol]

readfile

readfile 一词后面跟指定文件路径名的符号时，会读取该文件并尝试渲染其内容。不带参数的 readfile 一词会打开文件对话框以选择文件。页面成功载入后，对象会从出口送出两条消息：url，后面跟根据所给参数载入的最终 URL；以及 title，后面跟作为符号的已载入页面标题。

参数：

  • file path [symbol]

reload

reload 消息会使浏览器刷新当前页面，作用类似于常规网页浏览器中的 'Reload' 按钮。reload 一词后面跟非零参数时，会忽略本地缓存的文件。

参数：

  • ignorecache [int]
