jit.gl.environment

管理用于基于图像的光照（IBL）的环境纹理

描述

jit.gl.environment 对象利用内部的 jit.gl.cubemap 与 jit.openexr 对象来加载并上传等距柱状投影的 exr 环境贴图。加载完成后，数据会按需要转换并传给请求它的对象。环境绑定到 jit.gl.node 子上下文，而同一子上下文中一次只能有一个环境处于激活状态。

讨论

支持对象包括：
jit.gl.pbr
jit.gl.material
jit.gl.skybox

与 PBR 一起使用时，会为 IBL 效果生成辐照度贴图与反射贴图。

该对象会根据支持对象发出的请求来处理立方体贴图。若立方体贴图是通过 read 或 jit_matrix 消息加载的，就存储在内部；若它是 jit_gl_texture 消息的结果，则存储在外部。

特性

adapt [int]

加载时让内部立方体贴图适应输入文件的维度（默认值 = 1）。仅当使用内部立方体贴图时有效。启用后 edge_length 不再起作用。

drawto [symbol]

具名的绘制上下文或子上下文绘制目标。设置后，同一（子）上下文中的任何支持对象都能访问该环境。

edge_length [int]

设置立方体贴图边长的长度（默认值 = 64）。仅当 adapt 被禁用且使用内部立方体贴图时有效。

enable [int]

启用该环境贴图，供同一（子）上下文中的支持对象访问（默认值 = 1）。同一时间只能有一个环境贴图处于激活状态；要在已启用的环境贴图之间切换，参见 activate 消息提供的便捷方式。

file [symbol]

设置一个图像文件，与内部立方体贴图一起读入，用于环境贴图处理。

gamma_correction [int]

对输入启用伽马校正（默认值 = 1）。仅当使用内部立方体贴图时有效。改变该取值后需要重新加载输入文件才会生效。

name [symbol] 只读

环境贴图名称

reflect_edge [int]

设置生成的反射贴图边长的长度（默认值 = 128）。取值越高，PBR 反射的分辨率与感知质量越好（在平坦表面上尤为明显），代价是加载时间更长、GPU 内存占用更多。改变该取值会导致反射贴图重新生成，从而让渲染器停顿。

消息

bang

输出立方体贴图的纹理名称

(drag)

拖放图像文件以进行环境贴图处理

activate

在启用了多个环境的上下文中，同一时间只能有一个环境处于激活状态。该消息告诉上下文把此环境设为激活的那个。必须打开 enable 特性才能激活。

jit_gl_texture

把具名纹理数据上传到立方体贴图，用于环境贴图处理

read

读入一个图像文件，用于环境贴图处理
