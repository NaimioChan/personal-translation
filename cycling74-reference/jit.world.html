Jitter

jit.world

Jitter world 上下文

描述

jit.world 对象封装了若干 Jitter 对象的功能，包括 jit.window、jit.gl.render、jit.gl.node、jit.gl.cornerpin 和 jit.phys.world。当它们位于同一补丁中时，物理对象与 GL 对象会自动加入 jit.world 上下文，视频对象的自动输出也会被启用。

讨论

通常 jit.world 窗口一收到第一次绘制调用就会显示上下文对象，无论那是通过外部 bang 还是内部通过自动渲染（enable 为 1）。若启用了 output_texture，正确显示与输出需要两次绘制调用。若 output_matrix 与 matrix_mode_async 都已启用，正确的矩阵输出还需要额外一次绘制调用。

参数

name [symbol] 可选

绘制上下文名称

特性

border [int]

显示窗口边框（默认值 = 1）。

auto_handle [int]

启用自动把手变换操作器模式（默认值 = 0）。变换模式默认为旋转，通过 command 与 option 修饰键可改为平移或缩放。shift 修饰键在局部轴与世界轴之间切换。

enable [int]

启用自动渲染（默认值 = 0）。启用后，渲染会自动执行。

depth_sort [int] >= 9.0.0

启用深度排序模式（默认值 = 0）。启用后，每帧渲染之前会按对象与摄像机的距离对对象排序。

dim [2 ints]

内部纹理的维度（默认值 = 640 x 480）。只有当期望的纹理输出维度与窗口 size 不同时才设置该特性。若不给参数，纹理维度会自适应窗口大小。

displaylink [int]

启用渲染绘制与显示交换的同步（默认值 = 1）（仅限 Mac）。启用后，渲染绘制调用会与显示交换同步。

drawbang [symbol]

draw bang 的输出时机（默认值 = prerender）。决定中间出口的 draw bang 发生在渲染之前还是渲染之后。
可选值：

'prerender'（ 渲染之前 ）
'postrender'（ 渲染之后 ）

drawto [symbol]

内部 jit.gl.render 上下文的名称（默认值 = UID）。jit.world 的 drawto 是内部 jit.gl.node 子上下文的父上下文。

capture [int]

捕获到内部纹理（默认值 = 0）。启用后，所有渲染都会被捕获到纹理，并且纹理名称会从左出口送出。该纹理还会绘制到内部的 jit.gl.cornerpin 上以便在窗口中显示。是 output_texture 的同义词。

fixed_delta [float] >= 9.0.0

锁定动画对象所用的 delta time 取值，以秒为单位（默认值 = 0）。非零时，正在做动画的对象会用该取值计算更新，而不是用帧之间的实际时间。用于非实时帧捕获很有用。

floating [int]

启用浮动窗口样式（默认值 = 0）。

fps [float]

自动渲染的每秒帧数（默认值 = 30）。设置 fps 也会设置 interval。这些特性只有在 enable 为 1 且 displaylink 为 0 时才有效果。

fsaa [int]

启用全场景抗锯齿（默认值 = 0）。

fsmenubar [int]

在全屏下启用菜单栏（默认值 = 1）。

fullscreen [int]

启用全屏（默认值 = 0）。

enable_cornerpin [int]

启用内部的 jit.gl.cornerpin 对象（默认值 = 0）。启用后 cornerpin 的把手可见，鼠标处理器也会启用。启用还会把 output_texture 设为 1。可以用 sendcornerpin 发送 cornerpin 的特性与消息。

erase_color [4 floats]

作为 RGBA 取值的背景色与清除色（默认值 = 0.2 0.2 0.2 1.0）。

esc_fullscreen [int]

启用后，escape 键会把窗口切到全屏（默认值 = 1）。

interval [int]

自动渲染的毫秒间隔（默认值 = 33）。设置 interval 也会设置 fps。这些特性只有在 enable 为 1 且 displaylink 为 0 时才有效果。

gizmos [int] >= 9.0.0

为绑定到该上下文的 jit.gl.light 与 jit.gl.camera 对象启用 gizmo 的绘制与操作（默认值 = 0）。

matrix_mode_async [int] >= 8.0.0

启用异步矩阵输出（默认值 = 1）。启用后 jit.world 会使用 CPU 效率更高的异步代码路径进行矩阵输出。若希望同步输出，请禁用该特性。

ortho [int]

正交投影模式（默认值 = 0）
0 = 关闭正交投影（使用透视投影）
1 = 开启正交投影，使用镜头角度
2 = 开启正交投影，忽略镜头角度
可选值：

0 = 'Off (Perspective)'
1 = 'Orthographic (Lens Angle)'
2 = 'Orthographic (No Lens Angle)'

output_matrix [int]

把场景作为矩阵输出（默认值 = 0）。启用后，所有渲染都会被捕获到纹理，然后读回一个内部矩阵，并且矩阵名称会从左出口送出。该纹理还会绘制到内部的 jit.gl.cornerpin 上以便在窗口中显示。

output_texture [int]

捕获到内部纹理（默认值 = 0）。启用后，所有渲染都会被捕获到纹理，并且纹理名称会从左出口送出。该纹理还会绘制到内部的 jit.gl.cornerpin 上以便在窗口中显示。是 capture 的同义词。

name [symbol]

绘制上下文名称（默认值 = UID）。Jitter GL 对象通过其 drawto 特性挂接到该上下文。jit.world 的名称实际上是内部 jit.gl.node 子上下文的名称。
在 Max for Live 设备中使用 jit.world 需要隐式命名的上下文或 ---（三连短横线）命名的上下文。

phys_worldname [symbol]

内部 jit.phys.world 物理世界名称（默认值 = UID）。

position [3 floats]

3D 原点，形式为 x y z（默认值 = 0. 0. 0.）。该特性设置内部 jit.gl.node 的 position。

preserve_aspect [int]

输入图像的保持宽高比标志（默认值 = 1）

size [2 ints]

窗口大小（默认值 = 640 480）

rect [4 ints]

窗口矩形以像素为单位指定，给出窗口相对于左上角的左、上、右、下坐标。

sync [int]

垂直同步标志，会让窗口的更新与显示器的刷新保持同步（默认值 = 1）。

rotate [4 floats]

旋转角度以及执行旋转所绕的三个轴，形式为 rotation-angle x y z（默认值 = 0. 0. 1. 0.）。该特性设置内部 jit.gl.node 的 rotate。

quat [4 floats]

指定 3D 空间中的一个四元数朝向（默认值 = 0 0 0 1）。该特性设置内部 jit.gl.node 的 quat。

rotatexyz [3 floats]

指定 3D 空间中的一个欧拉朝向（默认值 = 0 0 0）。该特性设置内部 jit.gl.node 的 rotatexyz。

scale [3 floats]

3D 缩放系数，形式为 x y z（默认值 = 1. 1. 1.）。该特性设置内部 jit.gl.node 的 scale。

running_fps [float] 只读 >= 9.0.0

发送 getrunning_fps 会返回该上下文实际渲染的每秒帧数（相对于由 fps 设置的期望每秒帧数）。

transparency [int] >= 9.0.0

启用全局透明模式（默认值 = 0）。启用后，任何具有颜色透明度（即颜色的 alpha 分量小于 1）或 blend_enable 为 1 的对象都会被加入一个透明 pass，并借助正确的深度缓冲与场景中任何不透明对象合成。

windowposition [2 ints]

窗口位置以像素为单位，由相对于屏幕左上角的全局坐标中的 x 与 y 偏移值指定。

visible [int]

启用窗口可见性（默认值 = 1）。禁用可见性后，窗口类特性不再有效果。这些特性包括 size、windowposition、floating、border 和 fullscreen。窗口不可见时要设置输出纹理的维度，请使用 dim 特性。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

绘制并更新所有自动客户端与动画。只应在 enable 为 0 时调用。

int

设置 enable 特性。启用后帧更新会自动处理。

clear

把矩阵或纹理图像从背景中清除，并替换为 erase_color。

(mouse)

在对象框上双击会把窗口置于最前；当鼠标左键按下时，窗口上的鼠标事件会从转储出口送出，并在前面带上符号 mouse，若通过 sendwindow 消息启用了 idlemouse 则为 mouseidle。

该事件是一个列表，包含鼠标光标的水平与垂直坐标，后面跟着若干代表按键状态与修饰键状态的标志。这些标志是：鼠标按键、command（mac）或 control（win）键、shift 键、capslock 键、option / alt 键、control 键（mac）、鼠标左键、鼠标右键和鼠标中键。

draw

绘制并更新所有自动客户端与动画。只应在 enable 为 0 时调用。

front

把窗口置于最前。

jit_gl_texture

把具名纹理绘制到背景上。
