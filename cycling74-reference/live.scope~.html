live.scope~

可视化音频信号

描述

用 live.scope~ 来可视化音频信号。该对象可以作为 scope~ 的替代方案。

参数

无。

特性

active [long]

切换对象的激活模式。当 active 特性设为 0 时，波形绘制停止。当 active 特性设为 1 时，波形绘制启用，并使用激活颜色。

line_width [float64]

波形线的宽度。默认值为 1。

grid_line_width [float64]

网格线的宽度。默认值为 1。

vertical_divisions [long]

y 轴上网格划分的数量。要看到这些划分，必须把 grid 特性设为 'vertical' 或 'horizontal and vertical'。

grid [long]

设置要显示哪些网格线。可选值为：
0：关闭
1：水平
2：垂直
3：水平与垂直

若选择 1（水平），x 轴会被分段，从而得到网格的水平划分。若选择 2（垂直），y 轴会被分段，从而得到网格的垂直划分。

smooth [long]

smooth 特性让你可以从视觉上平滑波形的线条。该特性有三个取值：off、type 1 和 type 2。
Off：不应用平滑。不做平滑时，低频波形看起来可能比较粗糙。不过，对于高频和复杂频率的波形，不使用任何平滑会显示最精确的结果。
Type 1：改善视觉效果，同时尽可能保留精度。
Type 2：在低频时视觉效果最好，但在较高频率下精度会显著下降。

trigger_direction [long]

触发信号越过触发阈值时需要行进的方向，只有这样才能触发一次新的波形绘制。也就是说，若方向设为 'up'，阈值设为 '0'，则当信号向 +1 方向移动并越过 0 时，会绘制新的波形。该特性与 trigger_threshold 特性配合使用。要让这两个特性中的任意一个生效，mode 都必须设为 'trigger'。

active [long]

激活状态

trigger_threshold [float64]

设置触发阈值。这是触发信号（连接到 live.scope~ 的第二个入口）为触发一次新的波形绘制而必须越过的取值。该特性与 trigger_direction 特性配合使用。要让这两个特性中的任意一个生效，mode 都必须设为 'trigger'。

samples [float64]

设置要捕获的采样点数。

range [float64]

在 live.scope~ 对象中显示的最小与最大幅度。当幅度超出指定范围时，视觉显示会被裁剪。

decay_time [float64]

设置波形线淡出所需的时间，单位为毫秒。

mode [long]

设置 live.scope~ 的绘制模式。有两种可能的模式：history 与 trigger。history 模式捕获并显示最近 N 个采样点，而 trigger 模式则根据送往第二个入口的外部触发信号来捕获并显示。处于 trigger 模式时，你可以调整 trigger_direction 与 trigger_threshold 特性。当第二个入口的信号越过 trigger_threshold 取值时，live.scope~ 会开始捕获来自第一个入口的信号。

interval [float64]

设置波形绘制更新的时间，单位为毫秒。

horizontal_divisions [long]

x 轴上网格划分的数量。要看到这些划分，必须把 grid 特性设为 'horizontal' 或 'horizontal and vertical'。

rounded [float64]

live.scope~ 对象的边角圆角化量。可选值为 0-10。

bgcolor [4 floats]

当 active 特性设为 0 时，以 RGBA 格式设置背景颜色。

activebgcolor [4 floats]

当 active 特性设为 1 时，以 RGBA 格式设置背景颜色。

linecolor [4 floats]

当 active 特性设为 0 时，以 RGBA 格式设置波形线的颜色。

activelinecolor [4 floats]

当 active 特性设为 1 时，以 RGBA 格式设置波形线的颜色。

gridcolor [4 floats]

当 active 特性设为 0 时，以 RGBA 格式设置网格颜色。

activegridcolor [4 floats]

当 active 特性设为 1 时，以 RGBA 格式设置网格颜色。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

bold

bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

把 bang 送到 live.scope~ 的任一入口时，都会触发一次新的波形绘制。

signal

左入口：要在 live.scope~ 中显示的信号
右入口：触发信号
