MSP

filterdesign

创建滤波器规格

描述

用 filterdesign 对象创建一份 字典，其中包含一个滤波器的规格，该规格可以由另外几个对象实现，包括 cascade~ 对象。

参数

无。

特性

frequency [2 floats]

滤波器的截止频率，所用的单位由 units 特性定义。对低通与高通滤波器，用一个频率即可定义截止点。对带通与带阻滤波器，需要两个频率。

name [symbol]

输出字典所绑定到的名称

order [int]

滤波器的阶数，也就是极点与零点的个数。作为参照，biquad~ 对象是一个二阶滤波器（2 个极点与 2 个零点）。

passband_ripple [float]

Chebyshev Type 1 滤波器通带内的幅值纹波，单位为分贝。在滤波器阶数不变的情况下，纹波越大，过渡带越窄。

response [symbol]

滤波器响应形状
可选值：

'lowpass'（低频通过，高频被衰减）
'highpass'（高频通过，低频被衰减）
'bandpass'（一个频段通过，低频与高频被衰减）
'bandstop'（一个频段被衰减，低频与高频通过）

samplerate [int]

当 unit 特性设为 hertz 时所用的采样率。若采样率设为 0，则使用 MSP 的采样率。

sos_output [int]

是否在输出字典中包含二阶节的系数。这是 cascade~、zplane~ 和 filtergraph~ 所用的原生格式。

stopband_attenuation [float]

Chebyshev Type 2 滤波器阻带的最小衰减量，单位为分贝。在滤波器阶数给定不变时，衰减量越大，过渡带越宽；阻带衰减量越小，过渡带越窄。

tf_output [int]

是否在输出字典中包含单节传递函数系数。这种表示对低阶滤波器效果良好，但随着滤波器阶数提高，很快就会受浮点精度舍入的影响。

topology [symbol]

用于实现该滤波器的零点与极点的组织方式。
可选值：

'butterworth'（过渡平缓，通带平坦，阻带单调下降）
'chebyshev-1'（过渡最陡，通带纹波可定义，阻带单调下降）
'chebyshev-2'（过渡适中，通带平坦，阻带纹波可定义）

units [symbol]

用于指定频率的计量单位
可选值：

'hertz'（每秒周数，基于 samplerate 特性）
'normalized'（范围从 0.0 到 1.0；1.0 为奈奎斯特频率）
'radians'（范围从 0.0 到 pi；pi 为奈奎斯特频率）

zpk_output [int]

是否在输出字典中包含零点-极点-增益表示。对高阶滤波器而言，零点-极点-增益（ZPK）比单节传递函数（见 tf_output 特性）能更准确地表示滤波器的响应。若在为二阶节计算系数（见 sos_output 特性），ZPK 表示会作为中间阶段被计算出来。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

发送一个 bang 会用当前的特性生成 filterdesign 字典，并把它从第一个出口送出。

(mouse)

双击 filterdesign 对象会打开一个字典编辑窗口，用于查看或编辑当前的特性。

输出

dictionary

一份包含所指定滤波器特性的 filterdesign 字典。
