Max for Live

live.modulate~

调制 Ableton Live 与 Max for Live 的参数

描述

live.modulate~ 对象让你可以用信号对象实时调制 Live 参数的取值。要了解关于 Live 参数的更多内容，请在 Live Object Model 中查阅 DeviceParameter Object Class。

讨论

live.modulate~ 通过向右入口发送诸如 id 3 这样的标识符来调制一个有效的 Live 参数。送往左入口、范围在 -1 到 1 之间的信号会调制该参数。

输入范围会映射到被映射参数的完整范围。这意味着对于 'bipolar' 参数，信号取值 1 会按 maximum - minimum 调制当前基准值。例如，若当前值为 50、最小值与最大值分别为 0 和 100，而调制信号为 1，则得到的调制值会是 50 + 100。结果随后会被钳位到最小值与最大值之间。

对单极性参数，-1 到 1 的输入范围被解释为最小值与当前值之间范围的百分比。例如，若最小值为 0、当前值为 50，调制信号取值 0.0 会得到调制参数值 25（当前值与最小值的中点）。调制信号取值 -1 会得到调制参数值 0。

关于缩放与参数调制类型如何共同改变对象行为的更多信息，请参见 live.modulate~ 的帮助补丁。

从这个意义上说，它类似于 live.remote~，不过 live.modulate~ 不会接管它所调制的参数的控制权。相反，当前值充当一个可以改变的 'nominal' 参照点，输入信号则对该参照点施加偏移。

要停止调制某个参数，请发送一条 id 0 消息到 live.modulate~ 的右入口。

参数

无。

特性

depth [float]

live.modulate~ 对象的输入范围是 -1 到 1，它映射到被调制参数的完整范围。
你可以用 depth 特性控制调制深度。换言之，你可以把调制限制在小于完整范围的一个量上，该量以 0 到 1 之间的深度值表示。

smoothing [float]

设置用于每个传入事件的斜坡时间。这还会对你送入的任何信号自动降采样。例如，平滑值为 1 ms 会把信号降采样到 1 ms，并发送斜坡事件，从而输出初始信号的线性近似。该特性的默认值为 1 ms。

消息

int

左入口收到的整数取值会在下一个音频缓冲区开始时，或在一个待处理的斜坡结束时，被施加到选中的 Live 参数（DeviceParameter Object）上（若有）（见 smoothing）。

参数：

  • value [int]

float

左入口收到的浮点取值会在下一个音频缓冲区开始时，或在一个待处理的斜坡结束时，被施加到选中的 Live 参数（DeviceParameter Object）上（若有）（见 smoothing）。

参数：

  • value [float]

list

用一个包含两个浮点数的列表启动斜坡，类似于 line~ 对象。送入 “1 500” 表示从当前取值开始，将在 500 ms 后到达取值 1。新的斜坡总会覆盖当前斜坡，所以如果你想缩短一个斜坡，再送一个取值即可。

参数：

  • target-value [float]
  • delta-time [number]

getid

映射对象的 id 会从出口送出，前面带有单词 id。若没有映射对象，会送出 id 0。

id

右入口：设置选中的 Live 对象。若 id 不是参数（DeviceParameter Object），该消息无效。

参数：

  • parameter id [int]

signal

左入口收到的信号输入取值会实时施加到选中的参数（DeviceParameter Object）上（若有）。

Inspector

Persistence

live.modulate~ 对象的 Inspector 中有一个标为 "Use Persistent Mapping" 的特殊条目。启用该设置后，与对象相关联的 id 会在 Live 文档被保存与恢复时，以及在 Max Device 于 Live 应用程序与 Max 编辑器之间、或 Live Set 内部移动时保持持久。从 Live 8.2.2 开始，Live API 的 id 在 Live 各次启动之间保持持久；这一点连同 Persistence 特性（live.modulate~、live.object、live.observer 和 live.remote~ 的）一起，使得创建与 Live 用户界面元素保持关联的更简单设备成为可能。
