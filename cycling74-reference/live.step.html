Max for Live

live.step

步进音序器 UI 对象

描述

live.step 显示多条序列，这些序列由若干步骤组成，步骤包含音高、力度与时长。另有两个额外的步骤（Extra 1 与 Extra 2）可供用户自定义显示。

参数

无。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

若 target_seq 特性设为 0，bang 消息会把所有序列的当前步骤所关联的取值从对象的左出口送出。若 target_seq 特性设为大于 0 的值，bang 消息会把当前指定序列的当前步骤所关联的取值从对象的左出口送出。

int

若 target_seq 特性设为 0，一个整数会把所有序列的当前步骤设为该整数（索引编号从 1 开始）。若 target_seq 特性设为大于 0 的值，一个整数会设置当前指定序列的当前步骤。与当前步骤关联的取值会从对象的左出口送出。

参数：

  • step-index [int]

active

若 target_seq 特性设为 0，消息 active 0 会停用所有序列。单词 active 后跟任何非零取值都会激活所有序列。
若 target_seq 特性设为大于 0 的值，消息 active 0 会停用指定的序列。单词 active 后跟任何非零取值都会激活指定的序列。

参数：

  • 0/1 [int]

copy

单词 copy 会复制整条序列。可以用一或两个可选的整数参数来指定起始索引与结束索引（索引编号从 1 开始）。例如，copy 2 会从索引 2 开始复制序列，而 copy 2 5 会从索引 2 开始复制、到索引 5 结束。

参数：

  • start-index [int]
  • stop-index [int]

dictionary

用某个具名字典的内容替换 live.step 的当前序列或所有序列。若字典中存在多条序列，每一条序列都会被替换。

参数：

  • dictionary-name [symbol]

direction

单词 direction 后跟 0-4 范围内的整数，设置序列播放的播放方向。播放选项为：
0：向前
1：向后
2：往复
3：轮换
4：随机

若 target_seq 特性设为 0，当 live.step 对象的播放通过 time 消息控制时，该整数参数会设置所有序列的方向。
若 target_seq 特性设为大于 0 的值，当 live.step 对象的播放通过 time 消息控制时，一个整数会设置指定序列的方向。

参数：

  • direction-value [int]

doedit

单词 doedit 后跟 0-4 范围内的数字，提供了一种简便手段来移动或轮换存储在 live.step 对象中的参数。由数字参数指定的模式为：
0：把音高向上移调。
1：把音高向下移调。
2：把步骤向左轮换。
3：把步骤向右轮换
4：根据 mode 特性随机化步骤。例如，若 mode 设为 velocity，doedit 4 只会随机化力度。
若要使用更高级的编辑功能，请使用 up、down、left、right、random、scramble 和 sort 消息。

参数：

  • edit-mode [int]

down

单词 down 会根据 target_seq 与 mode 特性减小序列的取值。例如，若 mode 特性设为 velocity，down 消息只会减小当前指定序列的力度（若 target_seq 特性设为 0，则为所有序列）。
down 消息可以使用一个可选参数来指定要减小的参数，而不必使用 mode 特性。可选参数为：
all：减小所有参数
pitch：把音高向下移调
velocity：减小力度
duration：减小时长
extra1：减小用户可自定义的 Extra 1 参数的取值
extra2：减小用户可自定义的 Extra 2 参数的取值

参数：

  • parameter [symbol]

dump

把当前指定序列的所有步骤的取值（pitch、velocity、duration、extra1、extra2）从 live.step 对象的右出口送出。

dump_to_dict

通过转储出口送出一个字典，内容为当前序列或所有序列（若 target_seq 设为 0）。

duration

单词 duration 后跟一个整数（指定进入序列的起始索引，索引编号从 1 开始）和一个取值列表（单位为 ticks），会设置由 target_seq 特性指定的当前序列的时长取值。

参数：

  • start-index/values [list]

extra1

单词 extra1 后跟一个整数（指定进入序列的起始索引，索引编号从 1 开始）和一个取值列表，会设置由 target_seq 特性指定的当前序列的 extra1 取值。

参数：

  • start-index/values [list]

extra2

单词 extra2 后跟一个整数（指定进入序列的起始索引，索引编号从 1 开始）和一个取值列表，会设置由 target_seq 特性指定的当前序列的 extra2 取值。

参数：

  • start-index/values [list]

fetch

单词 fetch 后跟一个符号（指定某个步骤参数：pitch、velocity、duration、extra1 或 extra2）和一个整数（指定步骤编号），会从 live.step 对象的第四个（dumpout）出口以 <parameter-name> <step-number> <value> 的形式送出一个列表。

参数：

  • parameter name [symbol]
  • step number [int]

fold

单词 fold 后跟 0 或 1，切换折叠显示模式。启用折叠后，live.step 对象只显示由 target_seq 特性指定的序列中存在的那些音高，而不是所有可能的音高。折叠模式只显示每一条单独序列特有的音高。
注：诸如 up、down 和 random 这类序列编辑消息在执行操作时使用折叠状态下显示的音高列表（即 random 消息只会从折叠模式中所显示的音高中随机选取。这些操作同样取决于目标序列）。针对所有序列。

参数：

  • 0/1 [int]

fold_pitch

单词 fold_pitch 后跟一个整数或一个整数列表（指定 MIDI 音符号），设置 live.step 对象在折叠模式下要显示的音高。与 fold 消息一样，fold_pitch 消息设置的是由 target_seq 特性指定的序列中要显示的音高。

参数：

  • pitches-list [list]

getactive

消息 getactive 会把当前指定序列的激活状态从 live.step 对象的第四个（dumpout）出口送出，形式为以单词 active 开头的列表。

getcurrentstep

消息 getcurrentstep 会把序列的当前步骤从 live.step 对象的第四个（dumpout）出口送出，形式为以单词 currentstep 开头的数字。处理多条序列时，getcurrentstep 消息会报告目标序列（由 target_seq 特性指定）的当前步骤。

getdirection

消息 getdirection 会把当前指定序列的方向状态从 live.step 对象的第四个（dumpout）出口送出，形式为以单词 direction 开头的列表。

getduration

消息 getduration 会把由 target_seq 特性指定的序列中所有时长取值的列表从 live.step 对象的第四个（dumpout）出口送出，形式为以单词 duration 开头的列表。

getextra1

消息 getextra1 会把由 target_seq 特性指定的序列中所有 extra1 取值的列表从 live.step 对象的第四个（dumpout）出口送出，形式为以单词 extra1 开头的列表。

getextra2

消息 getextra2 会把由 target_seq 特性指定的序列中所有 extra2 取值的列表从 live.step 对象的第四个（dumpout）出口送出，形式为以单词 extra2 开头的列表。

getinterval

消息 getinterval 会把当前指定序列的间隔从 live.step 对象的第四个（dumpout）出口送出，形式为以单词 interval 开头的列表。

getloop

消息 getloop 会把当前指定序列的循环点从 live.step 对象的第四个（dumpout）出口送出，形式为以单词 loop 开头的列表。

getmodelist

消息 getmodelist 会把显示模式的列表从 live.step 对象的第四个（dumpout）出口送出，形式为列表，列表前面带单词 modelist。

getnstep

消息 getnstep 会把当前指定序列中的步数从 live.step 对象的第四个（dumpout）出口送出，形式为列表，列表前面带单词 nstep。

getpitch

消息 getpitch 会把由 target_seq 特性指定的序列中所有音高值组成的列表从 live.step 对象的第四个（dumpout）出口送出，形式为列表，列表前面带单词 pitch。

getstep

消息 getstep 会把当前指定序列中指定索引处的取值（pitch、velocity、duration、extra1、extra2）组成的列表从 live.step 对象的第四个（dumpout）出口送出，形式为列表，列表前面带单词 step。

参数：

  • step-index [int]

getvelocity

消息 getvelocity 会把由 target_seq 特性指定的序列中所有力度值组成的列表从 live.step 对象的第四个（dumpout）出口送出，形式为列表，列表前面带单词 velocity。

getzoom

消息 getzoom 会把当前指定序列的缩放音高值从 live.step 对象的第四个（dumpout）出口送出，形式为列表，列表前面带单词 zoom。

init

恢复并送出在 live.step 对象的 Inspector 中勾选 Initial Enabled 时所输入的初始值。

interval

设置当前指定序列的间隔。

参数：

  • time-value [list]

left

单词 left 会根据 target_seq 与 mode 特性轮换（左移）序列的取值。例如，若 mode 特性设为 velocity，left 消息只会轮换当前指定序列的力度（若 target_seq 特性设为 0，则轮换所有序列的力度）。
left 消息可以带一个可选参数来指定要轮换的参数，这样就不必使用 mode 特性。可选参数有：
all：把所有参数向左轮换
pitch：把所有音高向左轮换
velocity：把所有力度向左轮换
duration：把所有时长向左轮换
extra1：把所有用户可定义的 Extra 1 参数向左轮换
extra2：把所有用户可定义的 Extra 2 参数向左轮换

参数：

  • parameter [symbol]

loop

单词 loop 后面跟两个指定起始与结束索引的数字，会设置当前指定序列的循环点。

参数：

  • start-index [int]
  • stop-index [int]

(mouse)

每当用鼠标编辑 live.step 对象时，都会从对象的 dumpout 出口送出消息 changed 以及一个 0-2 范围内的数字。该数字指明 live.step 显示的哪一部分被修改了，具体如下：

0：音高、力度、时长、extra1 或 extra2 设置被修改。
1：界面的循环部分被修改。
2：在界面的标尺区域做了编辑。

next

next 消息会把所有序列下一步相关的取值从对象的左出口送出。若 target_seq 特性设为大于 0 的取值，next 消息会把当前指定序列下一步相关的取值从对象的左出口送出。

nstep

设置目标序列中的步数。

参数：

  • number of steps [int]

paste

当 paste 消息不带参数收到时，所有参数会被粘贴到它们被复制时的同一位置。可以用一个可选参数指定参数类型（pitch、velocity、duration、extra1、extra2），从而只粘贴特定的项目。另有一个可选的编号参数，用来指定复制出来的各步被粘贴到的起始索引（索引编号从 1 开始）。

参数：

  • parameter [symbol]
  • start-index [int]

pitch

单词 pitch 后面跟一个整数与一个取值列表时，该整数指定序列中的起始索引（索引编号从 1 开始），这些取值会设置由 target_seq 特性指定的当前序列的音高值。

参数：

  • start-index/values [list]

random

单词 random 会根据 target_seq 与 mode 特性随机化序列的取值。例如，若 mode 特性设为 velocity，random 消息只会把当前指定序列的力度打乱（若 target_seq 特性设为 0，则打乱所有序列的力度）。
random 消息可以带一个可选参数来指定要打乱的参数，这样就不必使用 mode 特性。可选参数有：
all：随机化所有参数
pitch：随机化所有音高
velocity：随机化所有力度
duration：随机化所有时长
extra1：随机化用户可定义的 Extra 1 参数的所有取值
extra2：随机化用户可定义的 Extra 2 参数的所有取值

参数：

  • parameter [symbol]

reset

reset 消息让你停用当前步。它等同于把当前步设为 0。

right

单词 right 会根据 target_seq 与 mode 特性轮换（右移）序列的取值。例如，若 mode 特性设为 velocity，left 消息只会轮换当前指定序列的力度（若 target_seq 特性设为 0，则轮换所有序列的力度）。
right 消息可以带一个可选参数来指定要轮换的参数，这样就不必使用 mode 特性。可选参数有：
all：把所有参数向右轮换
pitch：把所有音高向右轮换
velocity：把所有力度向右轮换
duration：把所有时长向右轮换
extra1：把所有用户可定义的 Extra 1 参数向右轮换
extra2：把所有用户可定义的 Extra 2 参数向右轮换

参数：

  • parameter [symbol]

scramble

单词 scramble 会根据 target_seq 与 mode 特性随机化序列取值的顺序。例如，若 mode 特性设为 velocity，left 消息只会打乱当前指定序列的力度（若 target_seq 特性设为 0，则打乱所有序列的力度）。
scramble 消息可以带一个可选参数来指定要打乱的参数，这样就不必使用 mode 特性。可选参数有：
all：随机化所有参数的顺序
pitch：随机化所有音高的顺序
velocity：随机化所有力度的顺序
duration：随机化所有时长的顺序
extra1：随机化所有用户可定义的 Extra 1 参数的顺序
extra2：随机化所有用户可定义的 Extra 2 参数的顺序
如果你不使用 mode all，而是把 1 作为参数传入，scramble 会让你的各步保持同步。例如，scramble pitch 1 消息会重新排列各音高，但其他参数会跟着一起移动。

参数：

  • parameter [symbol]
  • keep-step-sync [int]

set

若 target_seq 特性设为 0，单词 set 后面跟一个整数会把所有序列的当前步设为该整数（索引编号从 1 开始）。
若 target_seq 特性设为大于 0 的取值，单词 set 后面跟一个整数会设置当前指定序列的当前步。

参数：

  • step-index [int]

setall

单词 setall 后面跟一个数字时，若 live.step 对象处于显示模式，会把这个取值赋给当前目标序列中的每一层。可以用一个可选的首参数指定特定的层（例如 setall velocity 85），从而设置某一层中的所有取值。当 editlooponly 特性设为 1 时，setall 消息只会作用于循环选区内的索引。

参数：

  • value [list]

settimeshift

单词 settimeshift 后面跟一个指定偏移的正数或负数时，会从序列中的当前步移动到相对位置并触发那一步（例如，当前步编号为 3 时发送消息 settimeshift -1 会触发第 2 步的内容）。

参数：

  • time-shift [float]

sort

单词 sort 会根据 target_seq 与 mode 特性对序列的各步取值排序。例如，若 mode 特性设为 velocity，sort 消息只会对当前指定序列的力度值排序（若 target_seq 特性设为 0，则对所有序列的力度值排序）。
sort 消息可以使用可选参数来指定排序的行为、同步方式与方向。这些参数可用来设置要排序的参数，这样就不必使用 mode 特性。可选参数有：
all：对所有参数排序
pitch：对音高排序
velocity：对力度排序
duration：对时长排序
extra1：对所有用户可定义的 Extra 1 参数排序
extra2：对所有用户可定义的 Extra 2 参数排序
第一个整数参数指定是否让各步的取值保持同步——只有当 mode 特性未设为 all 时才有效。例如，消息 sort pitch 1 会根据音高重新排列各步，但与音高关联的力度、时长以及用户可定义的 extra1 与 extra2 取值会保持不变。可选的第二个整数参数可用来设置排序顺序：
1：升序（默认） -1：降序。

参数：

  • parameter [symbol]
  • keep-step-sync [int]
  • direction [int]

step

单词 step 后面跟一个含四个整数的列表时，会设置特定某一步的取值。必需的参数有：

索引（索引编号从 1 开始）
MIDI 音符号（0-127）
音符力度（0-127）
时长（30、60、120、240、480、960、1920、3840 ticks）

参数：

  • index [int]
  • midi-note [int]
  • velocity [int]
  • duration [int]

time

单词 time 后面跟一个含 6 个数字的列表，定义序列中的时间位置。必需的参数有 bar、beat、unit、resolution-in-ppq、time-signature-numerator 与 time-signature-denominator。live.step 对象没有内部 clock，因此如果你想用它来驱动 live.step 对象，就需要频繁发送 time 消息。

参数：

  • bar [int]
  • beat [int]
  • unit [int]
  • resolution [int]
  • time-sig-numerator [list]
  • time-sig-denominator [list]

up

单词 up 会根据 target_seq 与 mode 特性增大序列的取值。例如，若 mode 特性设为 velocity，up 消息只会增大当前指定序列的力度（若 target_seq 特性设为 0，则增大所有序列的力度）。
up 消息可以带一个可选参数来指定要增大的参数，这样就不必使用 mode 特性。可选参数有：
all：增大所有参数
pitch：把音高向上移调
velocity：增大力度
duration：增大时长
extra1：增大所有用户可定义的 Extra 1 参数的取值
extra2：增大所有用户可定义的 Extra 2 参数的取值

参数：

  • parameter [symbol]

velocity

单词 velocity 后面跟一个整数与一个取值列表时，该整数指定序列中的起始索引（索引编号从 1 开始），这些取值会设置由 target_seq 特性指定的当前序列的力度值。

参数：

  • start-index/values [list]

zoom

设置当前指定序列显示范围的上限与下限。

参数：

  • low-pitch [float]
  • high-pitch [float]

zoom_fit

单词 zoom_fit 会让 live.step 对象当前显示的音高范围自动调整，使最高与最低的音符取值成为显示的上限与下限。

zoom_in

单词 zoom_in 会让 live.step 对象显示当前音高范围在顶部与底部各缩减五分之一（7 步），产生「放大」效果。

zoom_out

单词 zoom_out 会让 live.step 对象显示当前音高范围在顶部与底部各扩大五分之一（7 步），产生「缩小」效果。

输出

anything


第四个出口：响应 dumpout 消息而产生的输出，这些消息用于查询 live.step 对象。

int


第三个出口：鼠标悬停信息。
第五个出口：序列索引输出。

list


最左出口：步取值。
第二个出口：每个序列的当前循环点。
