MSP

meter~

可视峰值电平指示器

描述

用 meter~ 对象监视 -1 到 1 范围内的任何信号（其他信号应先做缩放）。

讨论

默认情况下，电平表上每个“LED”代表与上一格相差 3dB。若信号大于等于 1，则红色的“over”LED 会亮起，并持续约一秒。你可以用 interval 消息改变重绘间隔。改变电平表的大小会得到它的垂直或水平朝向，取决于它的高度大于宽度还是相反。meter~ 会按每个重绘间隔输出收到的峰值信号取值。其他外观设置，例如 LED 的数量及其颜色，可以用对象的 Inspector 设置。可以用 mc.meter~ 监视多通道信号，它会自动适应收到的通道数。

参数

无。

特性

bgcolor [4 floats]

设置 meter~ 对象背景颜色的 RGBA 取值。

dbperled [int] : 3

设置每个 LED 代表的信号电平量，单位为分贝。默认情况下，每个 LED 代表相对相邻 LED 的 3dB 音量变化。

interval [atom_long] : 50

设置 meter~ 显示的更新间隔时间，单位为毫秒。最小更新间隔为 10 毫秒，最大为 2 秒，默认为 50 毫秒。该消息还设置 meter~ 送出在该时间间隔内收到的峰值的速率。

monotone [int] : 0 >= 7.0.0

切换电平指示器的单色显示

nhotleds [int] : 3

设置 meter~ 对象上显示的“hot”警告 LED 的总数（对应 rgba2 消息设置的颜色）。

ntepidleds [int] : 3

设置 meter~ 对象上显示的“tepid”中段 LED 的总数（对应 rgba5 消息设置的颜色）。

numleds [int] : 12

单词 numleds 后面跟一个 10 到 20 之间的数字，设置 meter~ 对象上显示的 LED 总数。范围为 10-20 个 LED。

nwarmleds [int] : 3

设置 meter~ 对象上显示的“warm”偏低中段 LED 的总数（对应 rgba4 消息设置的颜色）。

offcolor [4 floats] >= 7.0.0

设置“off”电平指示器的颜色。offcolor 特性会映射到 elementcolor 样式颜色。

oncolor [4 floats] >= 7.0.0

设置“on”电平指示器的颜色。oncolor 特性会映射到 color 样式颜色。

orientation [int] : 0 >= 8.0.0

设置 meter~ 对象的朝向。设为 0（自动）时，朝向会根据对象的尺寸自动改变。
可选值：

0 = 'Automatic'
1 = 'Horizontal'
2 = 'Vertical'

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

消息

int

转换为 float。送入一个取值会让电平表表现得如同一个峰值幅度相等的信号被送入其输入。相应的 LED 会亮起，峰值电平取值会从出口送出（0.0 显示静音，0.0 到 1.0 会点亮除过载 LED 以外的所有 LED，高于 1.0 的取值会点亮包括过载在内的所有 LED）。

参数：

  • input-peak-value [int]

float

送入一个 float 取值会让电平表表现得如同一个峰值幅度相等的信号被送入其输入。相应的 LED 会亮起，峰值电平取值会从出口送出（0.0 显示静音，0.0 到 1.0 会点亮除过载 LED 以外的所有 LED，高于 1.0 的取值会点亮包括过载在内的所有 LED）。

参数：

  • input-peak-value [float]

(mouse)

补丁窗口解锁后，你可以拖动 meter~ 的大小调整区域改变它的形状，从而把它从水平朝向改为垂直朝向。

signal

传入信号的峰值幅度由屏幕上的电平表 LED 显示。收到多通道信号时，会显示每个通道的峰值幅度。

输出

float

音频处理开启时，会把上一个更新间隔内收到的峰值（绝对值）从出口送出。对于 mc.meter~，只输出第一个通道的峰值。
