Max

pipe

延迟数字、列表或符号

描述

延迟数字、数字列表或符号。pipe 使用 Max 的 时间格式语法，因此延迟间隔既可以是固定的，也可以是相对速度的。

参数

initialization [list] 可选

pipe 对象的参数个数取决于你想延迟的列表中有多少个条目，但最后一个参数总是用来设置延迟时间的初始值。

若没有指定参数，初始值为 0，延迟时间为 0 ms。

若只有一个参数，则它设置延迟时间。

若有两个参数，第一个参数设置一个存储在 pipe 中的初始值，第二个参数设置延迟时间。

若参数多于两个，pipe 会创建额外的入口和出口，以便延迟更多的数字。

pipe 对象允许你用一个以毫秒为单位指定时间的数字（例如 pipe 200），或一个 notevalue（例如 pipe 2n）来指定时间间隔。

注意：虽然 pipe 对象允许你用 Max 任何一种标准时间格式来指定时间，但当用毫秒或 notevalue 之外的任何其他时间单位指定时间时，应使用 delaytime 特性参数（例如 pipe @ delaytime 11025 samples）。

若为延迟间隔指定了 notevalue、ticks 或 bars.beats.units，则除非传输正在运行，该对象不会工作。

特性

clock [symbol]

使用 clock 特性可以指定一个具名的 setclock 对象来计时，而不是用 Max 内部的毫秒时钟。clock 一词单独使用时，会把 pipe 对象设回使用 Max 常规的毫秒时钟。

delaytime [Time Value] : 0 ms

用 Max 的任何一种时间格式设置该对象的延迟时间。

quantize [Time Value] : 0 ticks

把 pipe 的输出量化到一个指定的时间边界。这是通过对用于送出输出的时间做内部调整来实现的。量化可以用下列时间格式指定：bars.beats.units、ticks 或 notevalue。

固定的时间单位（例如：ms、seconds、hz、samples 等）不会产生任何效果。

消息

bang

让当前存储在 pipe 中的数字在指定时间之后再次输出（此外，已经在延迟中的数字也会照常送出）。

int

左入口：设置值并触发延迟

中间入口：设置值但不触发延迟

右入口：设置延迟时间

参数：

  • delay [int]

float

float 会被转换成 int，除非该入口是用 float 参数初始化的。

左入口：设置值并触发延迟

中间入口：设置值但不触发延迟

右入口：设置延迟时间

参数：

  • delay [float]

list

左入口：对列表中的每个元素，都会为对应的输入设置一个值并触发一次延迟。

中间入口：当一个列表被送到 pipe 的某个中间入口时，该列表的第一个元素设置对应的输入，随后的元素设置随后的输入。这些值会一直存储，直到有 bang 送到 pipe 的第一个入口。

右入口：用 Max 的一种时间格式指定时间。

anything

参见 list 条目

clear

停止所有输出

flush

立即送出当前正被 pipe 延迟的所有值，并清空 pipe 对象的记忆。每个出口送出的值，其顺序与它们在对应入口被收到的顺序相反。

stop

停止所有输出

输出

int

当 pipe 对象的左入口收到一个取值时，它会延迟指定的时间，然后从左出口送出。若存在中间入口，这些入口中的取值也会在左入口收到取值时被延迟，并从各自对应的出口送出。与 delay 不同，pipe 中可以同时延迟多个取值。右入口收到新的延迟时间时，不影响 pipe 中已在延迟的取值何时送出。
