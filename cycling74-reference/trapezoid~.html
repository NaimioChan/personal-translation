trapezoid~

梯形波表

描述

trapezoid~ 是一个梯形波表，带有用于改变上升/下降斜坡相位位置的信号输入。默认的 lo/hi 点为 0. 和 1.，但可以用 lo/hi 消息改变它们。

参数

ramp-up [float] 可选

可以用一个浮点取值指定上升斜坡的取值。参数 0. 0. 会产生斜坡波形，0.5 0.5 会产生三角波形。

ramp-down [float] 可选

可以用一个浮点取值指定下降斜坡的取值。参数 0. 0. 会产生斜坡波形，0.5 0.5 会产生三角波形。

特性

hi [float]

设置 trapezoid~ 信号输出的最大值。默认值为 1.0

lo [float]

设置 trapezoid~ 信号输出的最小值。默认值为 0.

wrapmode [int] : 1

控制最左侧相位信号输入超出 0 - 1 范围时的处理方式。
可选值：

0 = 'Clip'（Clip 输入）
当 wrapmode 设为 0（Clip）时，相位会被限幅在 0 与 1 之间。

1 = 'Wrap'（Wrap 输入）
当 wrapmode 设为 1（Wrap）时，大于 1 的相位取值只使用该数字的小数部分。例如，输入 4.3 会被当作 0.3。小于 0 的相位取值会把该取值的小数部分从 1 中减去。例如输入 -0.4 会被当作 0.6。

消息

float

左入口：任何 float 或信号，或者从 0 逐渐变化到 1 的输入信号，都会用来扫描 trapezoid~ 对象的波表。phasor~ 或其他音频信号的输出可以把 trapezoid~ 当作振荡器来控制，把波表的内容视为重复的波形。

中间入口：梯形波形的上升斜坡部分，以一个周期的分数表示，范围在 0 到 1.0 之间。默认为 .1。

右入口：梯形波形的上升斜坡部分，以一个周期的分数表示，范围在 0 到 1.0 之间。默认为 0.9。

参数：

  • trapezoidal-control [float]

signal

左入口：任何 float 或信号，或者从 0 逐渐变化到 1 的输入信号，都会用来扫描 trapezoid~ 对象的波表。phasor~ 或其他音频信号的输出可以把 trapezoid~ 当作振荡器来控制，把波表的内容视为重复的波形。

中间入口：梯形波形的上升斜坡部分，以一个周期的分数表示，范围在 0 到 1.0 之间。默认为 .1。

右入口：梯形波形的上升斜坡部分，以一个周期的分数表示，范围在 0 到 1.0 之间。默认为 0.9。

输出

signal

一个与 trapezoid~ 对象输入信号所引用的取值相对应的信号。若用 phasor~ 或其他音频信号的输出来扫描 trapezoid~ 对象，输出就会是周期性的波形。
