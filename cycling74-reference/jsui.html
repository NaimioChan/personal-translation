Max

jsui

Javascript 用户界面与图形（旧引擎）

描述

提供一个用 Javascript（ECMAScript 5）制作用户界面元素的环境。它提供了 js 对象中所有可用的编程工具，同时还公开了 mgraphics 与 sketch 绘制例程以产生可视化输出。

讨论

jsui 对象是一个由 javascript 驱动的通用用户界面对象。已有许多现成可用的模板（下面展示了其中一部分）。补丁处于编辑模式时，你可以 ctrl-click（mac）或 right-click（pc）调出上下文菜单，用它查看并编辑当前载入的 javascript 文件，或从 jsui-library 中选择一个模板文件。若该 javascript 文件还关联有帮助文件（本补丁中包含的所有模板对象都是如此），则会载入关联的帮助文件，而不是 jsui.maxhelp。Inspector 让你设置 javascript 文件、javascript 参数、大小、边框标志，以及禁用全场景抗锯齿（fsaa）。

目前，只有当对象的编辑模式大小与演示模式大小相同时，鼠标位置和对象重绘才会在 jsui 对象中被正确报告。

参数

无。

特性

annotation_name [symbol] :

信息视图标题

border [int] : 1

切换是否围绕 jsui 对象绘制边框。默认值为 1（绘制边框）。

filename [symbol] : none

filename 一词后面跟一个指定路径名的符号，用于指定要载入的 Javascript 文件。

jsarguments [256 atoms] :

指定要传给 jsui 对象中所含 Javascript 代码的任意参数。

nofsaa [int] : 0

切换全屏抗锯齿

param_connect [symbol] :

在对象与具有参数的兼容对象（如 gen~ 或 jit.gl.slab）的某个参数之间建立双向连接。该对象可用来改变参数的值，参数值变化时它也会随之更新。设置 param_connect 最简便的方法，是使用该特性在 inspector 中的菜单，或使用 Object Action 菜单的 Connect 子菜单。菜单会列出兼容对象的所有可用参数。

用消息设置 param_connect 特性时，需要给出目标参数的路径，即宿主对象的脚本名后跟两个冒号，再加上参数名。例如，对于一个 gen~ 对象，若其脚本名为 gen~_AB，则 freq 参数的路径为 gen~_AB::freq。可以在宿主对象或参数尚不存在时就为 param_connect 设值，该对象会在参数出现后与之建立连接。更多细节请参阅用户指南中 param_connect 条目。

parameter_enable [int]

启用后，该对象可与 Max for Live Parameters 配合使用。

parameter_mappable [int] : 1

启用 parameter_mappable 后，该对象即可通过映射功能映射到键盘或 MIDI 输入。

template [symbol] : jsui_default.js

若 jsui 对象没有显式加载文件（例如通过 filename 特性），template 文件会被载入内存并求值，可作为进一步开发的起点。用户在编辑或打开外部编辑器时，会被提示把该模板保存为文件。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

若定义了名为 bang 的函数，则调用它。

int

若定义了名为 msg_int 的函数，则调用它。

参数：

  • user-defined [int]

float

若定义了名为 msg_float 的函数，则调用它。

参数：

  • user-defined [float]

list

与 anything 作用相同。

参数：

  • user-defined [list]

anything

用消息名调用函数，把消息参数赋给函数的参数。例如，若对象定义了名为 xyz 的函数，消息 xyz 1 2 3 会以参数 1、2 和 3 调用 xyz 函数。

参数：

  • user-defined [list]

(drag)

把文件从 File Browser 拖到 jsui 对象上时，该文件会被载入并执行。

autowatch

autowatch 一词后面跟一个 1，会为 Javascript 源文件打开文件监视。文件监视打开时，文件被修改后会自动重新编译。这让你可以为 Javascript 文件使用外部编辑器。你保存文件时，jsui 对象会察觉到。autowatch 0 关闭文件监视。

参数：

  • flag [int]

compile

重新编译当前文件。若后面跟一个符号，则会载入、编译该符号参数指定的 Javascript 文件，并把它设为当前载入的文件。

参数：

  • filename [symbol]

delprop

单词 delprop 后面跟一个名称，删除该具名特性。

参数：

  • property [symbol]

editfontsize

修改编辑窗口中所用文本的字号，该窗口包含对象的 Javascript 源文件。

参数：

  • size [int]

getprop

单词 getprop 后面跟一个名称，把对象中存储的该特性名的取值从左出口输出。

参数：

  • property [symbol]

jsargs

把当前 Javascript 参数设置为随后跟的任何消息参数。

参数：

  • arguments [list]

jsfile

jsfile 一词后面跟一个符号，会载入、编译该符号参数所指定的 Javascript 文件，并把当前载入的 Javascript 文件设为该文件。

参数：

  • filename [symbol]

loadbang

调用 loadbang 函数

(mouse)

双击 js 对象会打开一个文本窗口，可以在其中编辑该对象的 Javascript 源文件。保存该文本窗口时，文本会作为该对象的脚本被编译。

open

打开文本窗口，可在其中编辑对象的 Javascript 源文件。

setprop

setprop 一词后面跟一个名称以及一个或多个名称或数字，会把具名属性设置为该名称后面的内容。例如，把 setprop xyz 1 2 3 发给一个 js 对象。xyz 属性将取值为列表 1 2 3。

参数：

  • property and settings [list]

size

size 一词后面跟两个 int 参数，设置 jsui 对象的宽度和高度。

参数：

  • width [int]
  • height [int]

statemessage

用于测试传给 Javascript 源文件内各函数的消息。

参数：

  • messages [list]

wclose

关闭编辑对象 Javascript 源文件的文本窗口。

输出

anything

当在 jsui 对象内执行的 Javascript 代码调用 outlet 函数时，数字、列表或符号会从 jsui 对象的出口送出。
