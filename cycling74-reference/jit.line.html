jit.line

生成与渲染上下文同步的定时斜坡

描述

在指定的时间内生成从一个取值到另一个取值的斜坡与线段，并与外部渲染上下文同步、由它定时输出。jit.line 可以作为标准 Max line 对象的直接替代，但消除了 line 定时器与上下文帧之间输出不同步造成的卡顿。

参数

无。

特性

automatic [int]

启用自动更新与输出（默认值 = 1）。需要一个有效的 drawto 上下文来与之同步。禁用时，更新与输出需要 bang 消息。

drawto [symbol]

绑定到具名的绘制上下文，从而在 automatic 启用时自动接收到更新。

enable [int]

启用动画与插值取值的输出（默认值 = 1）。

fixed_delta [float64]

用于计算时间输出的固定帧增量时间（默认值 = 0.0）。非零时，时间函数会用该值来计算输出，而不用距上次更新以来的增量时间。当需要以固定速率动画、而不受实际更新速率影响时，这会很有用。

name [symbol]

指定实例的名称（默认值 = UID）。

targetname [symbol]

目标名称（未使用）

timevalue [float] 只读

当前插值取值

ui_priority [int]

UI 优先级（未使用）

消息

bang

在 automatic 禁用时输出插值取值

int

设置当前取值并立即输出

float

设置当前取值并立即输出

list

用各种列表组合来达到目标取值。
在其中一种列表组合里，第一个数字指定起始取值，其后跟一个逗号和一对数字。该对中的第一个数字指定目标取值，第二个数字指定 jit.line 应在其中达到该目标取值的总时长（单位：毫秒）。在这段时间内，数字会从当前存储的取值到目标取值之间按线性规律连续输出。

这类列表的一个例子是 0, 1 1000 0 1000。在这个例子里，输出会在一秒内从起始取值 0 升到 1，然后在一秒内降回 0。一旦第一个斜坡到达目标取值，下一个就开始了。此后在左入口送入的 list、float 或 int 会清除所有尚未生成的斜坡。

若列表的元素个数为大于三的偶数，每两个元素被视为断点函数中的一对「目标取值-斜坡时间」。若列表的元素个数为大于三的奇数，最后一个元素会被忽略。

update
