notequals

比较数字是否不相等

描述

比较两个取值，判断一个取值是否不等于第二个。若该数字不等于比较数字则输出 1，若等于则输出 0。

参数

initial-comparison-value [int or float] 可选

设置初始值，用于与左入口收到的数值做比较。float 参数会强制进行浮点比较。

特性

fuzzy [atom] : 0.

非零时，用于模糊浮点比较的 epsilon 值。注意这不是一个绝对容差值，而是经过缩放以容纳极大和极小数值的相对误差。单词 epsilon 可以用来表示系统的 FLT_EPSILON 值。

为零时（默认），使用标准的浮点比较，这可能导致看起来相等的数字无法被判定为相等。

fuzzy 特性仅在浮点模式下可用（即对象以浮点参数实例化时）。

消息

bang

左入口：用当前存储的数字执行比较。若没有参数，!= 初始用于比较的取值为 0。

int

左入口：该数字会与右入口中的数字比较。若两个数字不相等，!= 输出 1。若相等，!= 输出 0。

参数：

  • input [int]

(inlet1)

右入口：该数字会被存储，用于与左入口收到的数字比较。

参数：

  • comparison-value [int]

float

在比较前会转换为 int，除非 != 带有 float 参数。

参数：

  • input [float]

set

设置用于比较的数字，不引起输出（bang 会输出它）。

参数：

  • set-input [int]

list

左入口：比较第一个和第二个数字，若不相等则输出 1，若相等则输出 0。

参数：

  • input [number]
  • comparison-value [number]

输出

int

若两个入口中的数字不相等则为 1，若相等则为 0。
