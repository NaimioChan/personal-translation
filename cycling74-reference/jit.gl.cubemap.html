jit.gl.cubemap

管理立方体贴图纹理目标

描述

在 OpenGL 上下文中维护一个立方体贴图纹理目标。它有 6 个输入——立方体的每个面各一个。立方体贴图通常用于为反射、折射等材质效果映射环境。向任意入口送入纹理时，jit.gl.cubemap 会自适应纹理的输入类型。

讨论

该 OB3D 对象可选地接受一个参数：绘制上下文的名称。它可以是 jit.world 或 jit.pworld 对象的具名实例，也可以是 jit.gl.node 子上下文。该值也可以通过 OB3D 的 drawto 特性设置。若未给出参数，对象会被隐式加入当前补丁中找到的第一个有效绘制上下文或子上下文，或者沿补丁层级向上搜索找到的第一个有效绘制上下文或子上下文。

参数

无。

特性

adapt [int]

启用对输入的自适应（默认值 = 1）。启用后，纹理输出维度将与输入维度一致。

autotype [symbol] 只读

自动类型

bordercolor [4 floats]

设置纹理的边界颜色

edge_length [int]

立方体一条棱的像素长度。立方体的每个面在维度上都是 edge_length*edge_length。

file [symbol]

设置要读取的全景格式图像文件

filter [symbol]

应用于纹理的过滤。

gamma_correction [int]

伽马校正

level [int]

指定写入输入数据的 mipmap 层级（默认值 = 0）。当 level 为非零时，输入会覆盖指定 mipmap 层级上的 mipmap 图像，其中 1 是最大分辨率/最近的层级。必要的话会按相应层级缩放数据。mipmap 中各层级的高度与宽度都只有上一层级的一半。

matrix_name [6 symbols] 只读

要访问的具名矩阵（默认值 = none）

mipmap [symbol]

纹理 mipmap 插值样式（默认值 = none）。mipmap 是预先计算好的一系列图像，其中每一幅的分辨率依次降低。mipmap 插值用于缩小过滤，这是一种通过根据 3D 场景中带纹理对象的位置来改变所显示纹理信息量的技术，用以提高效率。当纹理空间中片元的面积大于一个纹素时，就会改用经过过滤（尺寸缩小）的纹理副本。这样，距离近的物体可以使用最高分辨率的图像，随着物体越来越远再换成分辨率更低的副本。把 mipmap 设为 bilinear（性能更好）或 trilinear（图像质量更好）后，每当纹理被更新时都会启用自动 mipmap 生成。
可选值：

'none'
'nearest'
'linear'
'bilinear'
'trilinear'

type [symbol]

强制把传入的纹理转换为特定类型。若设为 auto，jit.gl.cubemap 会自适应传入的类型，否则会强制转换为指定的类型。
可选值：

'auto'
'char'
'float16'
'float32'

wrap [3 symbols]

纹理回绕模式。

OB3D 特性

automatic [int]

自动渲染标志（默认值 = 1）该标志置位时，关联的 jit.gl.render 对象收到 bang 消息时即进行渲染

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

name [symbol]

实例名称（默认值 = UID）
