Max

standalone

为独立应用程序配置参数

描述

standalone 对象让你设置从 Max 补丁创建独立应用程序的选项，它与 File 菜单中的 Build Application/Collective... 项配合使用。顶层补丁中只应有一个 standalone 对象。

参数

无。

特性

allwindowsactive [int]

控制独立应用程序启动时 All Windows Active 的初始设置。

appicon_mac [symbol]

在 MacOS 上指定一个 .icns 文件作为独立应用程序的应用程序图标。

appicon_win [symbol]

在 Windows 上指定一个 .ico 文件作为独立应用程序的应用程序图标。

bundleidentifier [symbol]

提供给操作系统的、用于你的应用程序包的唯一标识符字符串，例如 "com.mycompany.myappname"。

cantclosetoplevelpatchers [int]

选中后，该选项会让你构建出的独立应用程序中无法关闭顶层补丁。

cefsupport [int]

在独立应用程序中为 jweb 对象启用 Max 的 CEF 支持。禁用可减小独立应用程序的体积。

copysupport [int]

启用后，Max 会把额外的资源复制到独立应用程序的支持文件夹，包括整套 externals、着色器、Javascript 支持文件等。禁用可减小独立应用程序的体积。注意，扩展以及 MIDI/音频 externals 始终会被包含，即使该选项被禁用。

database [int]

在独立应用程序中启用 Max 的文件数据库支持。

gensupport [int]

启用 Max 对 gen~、jit.gen、jit.pix 和 jit.gl.pix 对象的支持。禁用可减小独立应用程序的体积。

noloadbangdefeating [int]

打开补丁时，若按住 Command 和 Shift 键（Macintosh）或 Control 和 Shift 键（Windows），loadbang 对象的动作可以被禁用。勾选后，该选项会让你的独立应用程序无论键盘处于什么状态都始终执行 loadbang 动作。

overdrive [int]

控制独立应用程序启动时 Overdrive 的初始设置。

preffilename [symbol]

把独立应用程序的默认设置保存到一个自定义 Preference 文件夹，其名称由一个 symbol 指定。打开独立应用程序时，它会把该独立应用程序的偏好设置保存到位于 ~/Library/Application Support/[preffilename]（Mac）或 C:\Users\[Your username]\AppData\Roaming\[preffilename]（Windows）的文件夹。若未设置此项，独立应用程序的偏好设置默认会在 ~/Library/Application Support/Cycling '74 或 C:\Users\[Your username]\AppData\Roaming\Cycling '74 内创建一个以该应用命名的文件夹。

searchformissingfiles [int]

勾选后，Max 会用搜索路径在独立应用程序内部查找未包含在集合体中的文件。这包括可能不在补丁中、但被 Max 调用来支持所含对象正常运作的对象。例如，JSUI 对象需要各种 jitter 对象才能工作，但并不要求你在补丁中实例化它们。

禁用缺失文件搜索的主要原因是测试你的独立应用程序，看它被移到另一台机器后是否包含工作所需的全部文件。

请注意，为了让你的独立应用程序的用户能够拖放文件或以其他方式使用未包含在你应用中的文件，该选项必须启用（它默认就是启用的）。

statusvisible [int]

状态窗口标志

usesearchpath [int]

勾选后，独立应用程序会创建一个由应用所在文件夹的所有子文件夹组成的搜索路径。不勾选该选项主要对 Mac 用户有意义：他们可能想把独立应用程序放进 Applications 文件夹，又想避免把 Applications 文件夹的所有子文件夹加入搜索路径所带来的启动开销。在 Windows 上，应用位于它自己的文件夹内，所以通常没有多少子文件夹需要顾虑。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。
