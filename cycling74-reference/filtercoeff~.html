filtercoeff~

信号速率滤波器系数生成器

描述

filtercoeff~ 对象是供 biquad~ 对象使用的信号速率滤波器系数计算器。它由三个更高层的参数计算滤波器系数：频率、幅度和共振（Q）或斜率（S）。其内部计算基于 filtergraph~ 对象的计算。

参数

default-filter-type [symbol] 可选

可以用一个 symbol 参数设置默认的滤波器类型（highpass、lowpass 等等……）。

resampling-factor [int] 可选

可选的第二个参数可用于指定重采样系数。

消息

int

整数值会被转换为 float。

第一个入口：设置滤波器的中心频率或截止频率参数，并触发输出。

第二个入口：设置滤波器的增益参数，并触发输出。

第三个入口：设置滤波器的 Q（共振）或 S（斜率）参数，并触发输出。（注意，slope 一词只用于搁架式滤波器的第三个参数，大致等同于共振）。

参数：

  • filter-parameters [int]

float

第一个入口：设置滤波器的中心频率或截止频率参数，并触发输出。

第二个入口：设置滤波器的增益参数，并触发输出。

第三个入口：设置滤波器的 Q（共振）或 S（斜率）参数，并触发输出。（注意，slope 一词只用于搁架式滤波器的第三个参数，大致等同于共振）

参数：

  • filter-parameters [float]

list

最多由 3 个浮点数组成的列表会分别指定中心频率、增益和 Q 因子。若有信号连接到通常接收这些参数的任一入口，就会覆盖来自 list 的任何输入，而这些参数的效果完全取决于所选的滤波器类型。

参数：

  • center-frequency [float]
  • initial-gain [float]
  • Q [float]

allpass

左入口：单词 allpass 把滤波器类型设为全通模式。该滤波器的频率响应基于两个参数：中心/截止频率和 Q（共振）。增益参数设为单位增益（1.0）。全通滤波器旨在修改相位响应，保持平坦的幅值响应

参数：

  • center-frequency [float]
  • Q [float]

bandpass

左入口：单词 bandpass 把滤波器类型设为带通模式。该滤波器的频率响应基于两个参数：中心频率和 Q（共振）。增益参数设为单位增益（1.0）。

参数：

  • center-frequency [float]
  • Q [float]

bandstop

左入口：单词 bandstop 把滤波器类型设为带阻模式。该滤波器的频率响应基于两个参数：中心频率和 Q（共振）。增益参数设为单位增益（1.0）。

参数：

  • center-frequency [float]
  • Q [float]

gainapass

左入口：单词 gainapass 把滤波器类型设为增益可由用户控制的全通模式。该滤波器的频率响应基于三个参数：中心/截止频率、增益和 Q（共振），不过只有增益参数对幅值响应有影响。全通滤波器旨在修改相位响应，保持平坦的幅值响应

参数：

  • center-frequency [float]
  • initial-gain [float]
  • Q [float]

gainbpass

左入口：单词 gainbpass 把滤波器类型设为增益可由用户控制的带通模式。该滤波器的频率响应基于三个参数：中心频率、增益和 Q（共振）。

参数：

  • initial-gain [float]
  • Q [float]

gainbstop

左入口：单词 gainbstop 把滤波器类型设为增益可由用户控制的带阻模式。该滤波器的频率响应基于三个参数：中心频率、增益和 Q（共振）。

参数：

参数：

  • center-frequency [float]

左入口：单词 gainlpass 把滤波器类型设为增益可由用户控制的低通模式。该滤波器的频率响应基于三个参数：cf（截止频率）增益，和 Q（共振）。

参数：

  • center-frequency [float]
  • initial-gain [float]
  • Q [float]

highpass

左入口：单词 highpass 把滤波器类型设为高通模式。该滤波器的频率响应基于两个参数：cf（截止频率）和 Q（共振）。增益参数设为单位增益（1.0）。

左入口：单词 resonant 把滤波器类型设为共振模式（共振带通滤波器）。该滤波器的频率响应基于两个参数：中心频率和 Q（共振）。增益参数设为单位增益（1.0）。

参数：

  • center-frequency [float]
  • Q [float]

signal

第一个入口：设置滤波器的中心频率或截止频率参数，并触发输出。

第二个入口：设置滤波器的增益参数，并触发输出。

第三个入口：设置滤波器的 Q（共振）或 S（斜率）参数，并触发输出。（注意，slope 一词只用于搁架式滤波器的第三个参数，大致等同于共振）

输出

signal

五个信号出口为 biquad~ 对象输出信号速率滤波器系数。
