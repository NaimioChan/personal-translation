jit.mgraphics

2D 矢量图形

描述

jit.mgraphics 对象支持用 MGraphics API 绘制 2D 矢量图形。

讨论

这是 JGraphics API 的 Max 包装。关于 JGraphics 的文档可在线获取：https://sdk.cdn.cycling74.com/max-sdk-8.2.0/group__jgraphics.html 。两者都大致基于 http://cairographics.org 的 API。查看 JGraphics 文档时请注意，其中的函数不会传入 t_jgraphics *，除此之外参数是类似的。

关于矩阵运算符的更多内容

Jitter MOP

既然矩阵是 Jitter 的核心，大多数 Jitter 对象属于矩阵运算符这一类也就不奇怪了。每个矩阵运算符都有若干个矩阵输入和若干个矩阵输出。矩阵输入按从左到右的顺序用 "in"、"in2"、"in3" 等名称称呼，矩阵输出用 "out"、"out2"、"out3" 等名称称呼，即除最左边第一个输入和最左边第一个输出分别只叫 "in" 和 "out" 之外，其余名称都由输入/输出编号后缀而来。我们把输入或输出的名称称为 "I/O-name"。

矩阵输入和输出在内部通常各自持有保存信息的矩阵。这是必要的，因为 Jitter 是异步框架（也就是说，各个矩阵并不会同时到达所有输入）。矩阵输入和输出的若干方面可以用命令 [I/O-name] 加上下列后缀之一来设置："_dim" 设置指定 I/O 矩阵的维度，"_type" 设置指定矩阵的类型，"_planecount" 设置指定矩阵的通道数，"_name" 设置指定矩阵的名称。有一种特殊情况没有任何内部矩阵，就是第一个输入 "in"。这是因为该特殊输入实际上触发矩阵运算符的计算，所以不像其他输入那样需要缓存到计算发生为止。因此没有机制可以设置 "in" 的 dim、planecount、type 或 name。

矩阵运算符接受我们称为「matrix args」的参数，即 [planecount (int)] [ type (symbol)] [dim (int list)]。若给出了这些参数，adapt 特性会被关闭，否则会被打开。若 adapt 模式打开，则每当第一个输入收到矩阵时，就相当于把 dim、planecount 和 type 特性设置为该输入矩阵的对应值。若其他输入和输出链接到这些特性，它们所链接的特性也会随之改变。adapt 模式打开时哪些输入和输出会链接到哪些特性，请查阅「MOP」表。最左侧的输入不适用该规则，因此该行所有列都标记为 "n/a"。

jit.matrix 对象是一个具名矩阵，可用于矩阵数据的存储与取出、重采样，以及矩阵类型与 planecount 转换等操作。

MOP 参数

planecount [int] 可选

显式设置输出以及右侧各输入的通道数。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

type [symbol] 可选

显式设置输出以及右侧各输入的矩阵类型。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

dimensions [list] 可选

显式设置输出以及右侧各输入的矩阵维度。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

MOP 特性

adapt [int]

矩阵自适应标志（若给出了矩阵参数则默认值为 0，否则为 1）。该标志置位时，jit.matrix 对象会自适应输入矩阵的 planecount、type 和 dimensions。

[in/out]_dim [32 ints]

矩阵数据的维度（默认值 = 1 1）

[in/out]_name [symbol]

矩阵输入或输出的名称（默认值 = UID）

[in/out]_planecount [int]

矩阵输入或输出数据的通道数。除特殊情况外，该值等于 planecount。

[in/out]_type [symbol]

输入或输出矩阵的数据类型。除特殊情况外，该值等于 type。

outputmode [int]

输出模式（默认值 = 1（计算并输出矩阵））
0 = 无输出（不计算）
1 = 计算并输出矩阵
2 = 透传输入（不计算）
3 = 透传输出（不计算）

type [int]

矩阵数据类型（默认值 = char
支持的数据类型有 char、long、float32 和 float64。

stroke_preserve_with_alpha

描边当前路径，施加全局 Alpha，并保留该路径以供后续路径操作使用。

参数：

  • alpha [float]

stroke_with_alpha

描边当前路径，施加全局 Alpha，并在填充后丢弃该路径。

参数：

  • alpha [float]

svg_create

创建一个具名的 svg 对象，用指定源的内容填充。源可以是文件名，也可以是 XML svg 字符串。

参数：

  • svg_name [symbol]
  • source [symbol]

svg_destroy

销毁具名 svg 对象。

参数：

  • svg_name [symbol]

svg_get_size

获取具名 svg 对象的大小。结果会以 svg_get_size 为前缀从 dumpout 出口送出。

参数：

  • svg_name [symbol]

svg_render

渲染具名 svg 对象。

参数：

  • svg_name [symbol]

svg_set

重用通过 svg_create 创建的现有 SVG 对象。

参数：

  • svg_name [symbol]

text_measure

返回某个字符串在当前绘制上下文的图形设置下的宽度与高度。结果会以 text_measure 为前缀从 dumpout 出口送出。

参数：

  • text [symbol]

text_path

向当前路径添加一条文字路径。

参数：

  • text [symbol]

transform

把变换矩阵与另一个矩阵相乘。

参数：

  • xx [float]
  • xy [float]
  • yx [float]
  • yy [float]
  • x0 [float]
  • y0 [float]

translate

平移变换矩阵。

参数：

  • tx [float]
  • ty [float]

translate_source_rgba

设置源颜色变换的偏移取值。

参数：

  • redoffset [float]
  • greenoffset [float]
  • blueoffset [float]
  • alphaoffset [float]

user_to_device

把用户坐标转换为设备坐标。用户坐标是传给绘图函数的那些坐标。设备坐标是显示设备的坐标。结果会以 user_to_device 为前缀从 dumpout 出口送出。

参数：

  • x [float]
  • y [float]
