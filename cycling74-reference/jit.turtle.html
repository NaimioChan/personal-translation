Jitter

jit.turtle

2 维海龟绘图解释器

描述

jit.turtle 对象模拟简单的 LOGO 风格绘图。它把入口收到的单个 char 取值解释为描述海龟绘图命令的 ASCII 字母。合法的 ASCII 输入会生成相应的绘图命令，供 Max 的 lcd 对象或 jit.lcd 对象使用。

讨论

jit.turtle 对象支持分支（通过 [ 与 ] 符号），嵌套分支的栈大小上限为 1024。这本身虽然有趣，但与自动字符串生成器（Max 补丁或 jit.linden 之类的对象）一起使用时最为有用。对 jit.turtle 对象来说没有任何意义的 ASCII 码会被忽略。用户希望绕过的符号，可以用一个带有相应 ASCII 数值的 select 或 route 对象来滤除，把它放在命令来源与 jit.turtle 对象之间即可。

虽然 jit.turtle 对象不使用 Jitter 矩阵来存储和生成数据，但它使用 Jitter 特性系统来设置和查询自己的内部状态（origin、angle、scale 与 clearmode 都是 Jitter 特性）。

海龟绘图软件包相当普遍，其中一些的语法还彼此冲突。该对象使用的海龟语法是针对 Lindenmayer 系统（即 L-system）的可视化而优化的，这类系统往往使用同一组命令。

如果你在学校（或其他地方）从未受过海龟绘图的折磨，那么基本思路是这样的：

你是一只海龟。仿佛这还不够糟，你还被限制为只能以离散步长转向和前进（你也可以转身）。不过作为补偿，你的创造者给了你两项相对普通爬行动物而言非常酷的基因优势：

1）你有取之不尽的墨水，从你的尾巴里分泌出来（通常称为 PEN）。通过在移动和转向时把尾巴拖过地面，你就可以向全世界（或者至少向任何看到的人）讲述做一只海龟有多糟。

2）你可以来回做量子跳跃，跳到你以前到过的地理位置和朝向（不过平心而论，在到达那里之前你对那些位置其实一无所知）。这称为 BRANCHING，它让你这只小小的海龟也能画出一些极其复杂的图像。

jit.turtle 对象有以下基本指令集，它把送到入口的 ASCII 字符识别为这些指令：

F：尾巴放下，前进一个离散步长（画线）。

f：尾巴抬起，前进一个离散步长（移动位置但不画线）。

+：向右转。

-：向左转。

|：转身。

#：尾巴按得更重，画出更粗的线。

!：尾巴按得更轻，画出更细的线。

[：开始一个分支。

]：结束一个分支。

使用开始或结束分支的命令，可以让你记住一个位置与角度，之后再神奇地回到那里。

海龟的起始位置可以通过 origin 特性改变。海龟每执行一次前进命令所移动的步数（以像素为单位）可以用 scale 特性设置。每次转向的度数由 angle 特性设置。

参数

无。

特性

angle [int]

海龟每次转向的度数（默认值 = 30）

clearmode [int]

复位时清除标志（默认值 = 1）该标志置位时，收到 reset 命令会发送一条 clear 消息。

origin [2 ints]

海龟在 reset 之后开始绘图的点，以笛卡尔坐标表示（默认值 = 80 120）

scale [int]

海龟每次前进所走的步长（以像素为单位）（默认值 = 10）
