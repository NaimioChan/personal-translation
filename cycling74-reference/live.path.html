Max for Live

live.path

在 Live 应用程序中导航到对象

描述

live.path 用于导航到 live.object、live.observer 和 live.remote~ 对象所操作的 Live 对象。这种导航完全基于路径，与 Live 中当前存在的对象无关（导航到不存在的路径时，左出口和中间出口送出的是 id 0 消息，而不是错误消息）。

注意：Live API 在 Live 的主线程中运行，所有发往该 API 及从该 API 发出的消息都自动延后执行。

参数

initial path [symbol] 可选

把初始路径指定为 live.path 的参数，不要加任何引号。

特性

入口

Single inlet

获取下面描述的所有命令消息。

出口

左出口

消息 id nn 是在响应 goto、bang 或 getid 消息时才会送出的。若即使对象在 Live 中的位置发生变化，你也想继续操作在 goto 或 bang 时确定的某个对象，请使用这个出口。

例如，假设一个新建的 Live set 有两条轨道，"1 Audio" 是最左边的轨道，"2 MIDI" 在它右边。若你导航到 "2 MIDI" 轨道（goto live_set tracks 1），并在 "1 Audio" 与 "2 MIDI" 之间新建一条 Audio 轨道，那么原来那条 MIDI 轨道现在位于 live_sets tracks 2。但由于该 MIDI 轨道的 id 号会保持不变，左出口也不会送出新的 id，连接到这个出口的 live.xxx 对象会继续操作这条 MIDI 轨道，直到你发送另一次 goto。

中间出口

只要当前路径上对象的 id 发生变化（例如当前路径被改变，或 Live 中这个位置上的对象被替换），就会送出 id nn。若你想始终操作同一个路径，无论那里可能是什么对象，请使用这个出口。这个出口对于 live_set view detail_clip 之类的情况非常有用。

还是上面那个例子。若把 live.xxx 对象连接到 live.path 的中间出口，它们就会操作新建的那条音频轨道。

中间出口未经入口消息触发、而是由 Live 中的变化自发地送出对象 id，这称为通知。
注意：无法从这种通知中修改 Live set。

右出口

送出对 getpath、getchildren、getcount 的响应。

消息

getid

TEXT_HERE

getcount

参数：
child-name 是当前路径上对象的某个子项的名称。

操作：
向右出口送出一条 count 消息，其中包含该子项的名称及其条目数。

备注：
给定的子项必须是列表。

出口输出示例
右count child-name countcount clip_slots 2

参数：

  • child-name [symbol]

getchildren

操作：
把当前路径上对象的子项列表（若有）送到右出口。

备注：
子项名称与 goto 消息中使用的名称相同。

出口输出示例
右children list-of-child-nameschildren canonical_parent clip_slots

getpath

操作：
向右出口送出一条 path 消息，其中带有当前路径。

出口输出示例
右path pathpath live_set scenes 1

bang, getid

操作：
把当前路径上对象的 id 送到左出口和中间出口。若当前路径上没有对象，则送出 id 0。

出口输出示例
左id nnid 5
middleid nnid 5

path

与 goto 相同，但仅限于以根对象名开头的绝对路径，例如 live_app、live_set、this_device 或 control_surfaces N。

参数：

  • absolute-path [symbol]

goto

参数：
path 是绝对路径（以 live_app、live_set 或 control_surfaces N 开头）或相对路径，或 up

操作：
导航到给定路径，并把该路径上对象的 id 从左出口和中间出口送出。若该路径上没有对象，则送出 id 0。

备注：
不能前往列表特性，只能前往它的某个成员。
无效：goto live_set scenes
正确：goto live_set scenes 3

出口输出示例
左id nnid 5
middleid nnid 5

参数：

  • path [symbol]
