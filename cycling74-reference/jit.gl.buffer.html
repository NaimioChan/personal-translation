jit.gl.buffer

GPU 上的网格数据缓冲区

描述

jit.gl.buffer 对象是对存储在 GPU 上的一块数据缓冲区的具名引用。数据经由 jit.gl.mesh 渲染，而 jit.gl.tf 用于执行变换反馈效果。

特性

instance_div [int]

把缓冲区除以该取值，并把数值分摊到实例总数上（默认值 = 1）。例如，可用于在大量网格实例构成的数组中创建颜色分组。需要启用 instanced。

instanced [int]

启用后，在使用 jit.gl.mesh 执行硬件实例化时，缓冲区纹理可以向网格的每个被绘制的实例传递不同的取值（默认值 = 0）。

map [symbol]

取一个已存在的 jit.matrix 对象的名称。设置后，缓冲区数据会每帧写入该具名矩阵。目标矩阵会相应地调整维度与类型，以容纳缓冲区的内容。

要清除该映射，可发送不带参数的 map 消息。

name [symbol] 只读

内部用于管理纹理缓冲区。

outname [symbol]

与 jit.gl.tf 配合使用时必需；该名称用在 jit.gl.shader 的变换反馈着色器代码中，用于在 GPU 上对缓冲区中的数据迭代进行处理。

texbuf [int]

启用后，缓冲区会被绑定为 1D 纹理缓冲区（默认值 = 0）。这样就可以在着色器代码中使用 texelFetch 命令来做纹理式查找。需要注意的是，所有普通纹理都会先绑定，然后才绑定纹理缓冲区。着色器中通过 samplerBuffer 采样器方法来访问纹理缓冲区。

所以，如果你把两个纹理缓冲区连接到 jit.gl.mesh 上，看起来像这样：

					[ jit.gl.buffer @type vertex_attr0 @texbuf 1 ] 
[ jit.gl.buffer @type vertex_attr1 @texbuf 1 ]

那么在你的着色器参数声明里需要类似这样的写法：

					<param name="tex1" type="int" default="0" /> 
<param name="tex2" type="int" default="1" /> 
<param name="texbuf1" type="int" default="2" /> 
<param name="texbuf2" type="int" default="3" />

而在程序主体中则是：

					uniform sampler2DRect tex1; 
uniform sampler2DRect tex2; 
uniform samplerBuffer texbuf1; 
uniform samplerBuffer texbuf2;

这样你就能用 texelFetch 访问被采样的纹理，供着色器的其余部分使用：

					vec3 bufval = texelFetch(texbuf1, index).xyz;

其中 index 是介于 0 与缓冲区宽度减一之间的整数。

示例补丁参见 tb.pl.disco.duck

type [symbol]

设置要作为纹理绑定的缓冲区类型（position、normal、color、vertex_attr0 等）。当传给 jit.gl.mesh（或先经过 jit.gl.tf，再传给 jit.gl.mesh）时，它会把纹理绑定到网格对象对应的内部缓冲区。
可选值：

'position'
'texcoord'
'normal'
'tangent'
'bitangent'
'vertex_attr'
'vertex_attr0'
'vertex_attr1'
'vertex_attr2'
'vertex_attr3'
