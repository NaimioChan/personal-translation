MSP

sync~

让 MSP 与外部源同步

描述

sync~ 对象像 phasor~ 一样输出 0-1 的斜坡。该斜坡的频率可以用每分钟拍数（BPM）指定，也可以通过打拍定速、MIDI 节拍时钟，或一段包含 'click track' 的音频信号给 sync~ 发送速度基准来指定。另外，sync~ 还会生成 MIDI 节拍时钟，用于同步外部设备。

参数

无。

特性

rtport [symbol] : None

可选地，sync~ 对象可以与 Max 的 MIDI 系统建立直接连接，无需补丁连线即可接收 MIDI 时钟消息。这能确保 MIDI 时钟获得最佳时序精度。

默认情况下，该特性设为 None，处于禁用状态。选择 All 会把来自任意端口、所有端口的全部 MIDI 时钟消息都路由给 sync~ 对象 —— 如果你的 MIDI 时钟环境只有一个简单来源，这会很有用。用法更复杂时，请从菜单中选择具体的 MIDI 时钟来源，以避免 MIDI 时钟消息互相冲突。
可选值：

'None'（MIDI RT 端口已禁用）
不使用 MIDI RT 端口传输 MIDI 时钟

'All'（MIDI RT 端口全向模式）
使用 Max 在任何（以及每一个）端口上可用的任何（以及每一条）MIDI 时钟消息

'(available MIDI ports)'（当前激活的 MIDI RT 端口）
使用特定的 MIDI 端口接收 MIDI 时钟消息

消息

bang

用一串 bang 消息来设定打拍定速。一条 bang 消息被解释为一次拍击。如果 sync~ 对象连续收到三次时间间隔较为一致的拍击，它就会把速度改成与之匹配的值。

int

MIDI 节拍时钟。整数输入被解释为 MIDI 数据 —— 你可以直接连接 rtin 对象的输出。sync~ 会响应 MIDI 节拍时钟的 start/stop（int 250 与 252）以及 tick（248）。其他所有取值都会被忽略。

参数：

  • MIDI-data [int]

float

设置时钟的 BPM。

参数：

  • beats-per-minute [float]

bpm

单词 bpm 后面跟一个数字，会把当前输出斜坡的速率设为与所指定的每分钟拍数对应的频率。

参数：

  • bpm-rate [float]

midioffset

单词 offset 后面跟一个 0.-1.0 范围内的浮点数，用于调整当前输出斜坡的 MIDI 输出“相位”。

参数：

  • output-phase [float]

offset

单词 offset 后面跟一个 0.-1.0 范围内的浮点数，用于调整当前输出斜坡的“相位”。

参数：

  • ramp-phase [float]

ppq

单词 ppq（每四分音符的脉冲数），后面跟一个数字，用于指定每个四分音符输出的 tick 数。默认情况下，MIDI 节拍时钟指定的 PPQ 为 24。ppq 消息主要用来为设置为不同拍号的外部设备把速度加倍或减半。sync~ 对象生成的斜坡信号，还可以进一步用 rate~ 对象缩放后输出。

参数：

  • number-of-ticks-per-quarter-note [int]

signal

sync~ 对象会把自身速度设为与音频节拍音轨输入相匹配。该节拍音轨应在目标速度的四分音符间隔处包含幅度峰值。只有当 sync~ 检测到大于 0.1 的峰值，且该峰值处于约 30-240 BPM 的速度范围内时，信号输入才会影响速度。

start

单词 start 会让当前输出斜坡停止，并把斜坡重置为 0。start 消息与收到 MIDI 节拍时钟的 start 取值（250）效果相同。收到 start 消息时，sync~ 会从 MIDI 节拍时钟出口输出数字 250，这样任何外部设备也会随之启动。

stop

单词 stop 会让当前输出斜坡停止，并保持不动，直到收到 start 消息。它等同于发送 MIDI 节拍时钟的 stop 取值（252）。收到 stop 消息时，sync~ 对象会从其 MIDI 节拍时钟出口发送数字 252。处于停止状态时，sync~ 对象不会发送 MIDI 节拍时钟 tick。

输出

bpm

中间出口：每当速度变化时，sync~ 都会输出 bpm 消息，后面跟一个 float 取值，用于指定新的速度。

click

中间出口：当 sync~ 对象收到音频拍点时，它会从中间出口发送一条 click 消息。

int

右出口：sync~ 会生成与其输出斜坡相匹配的 MIDI 节拍时钟流。通常需要时，该出口会直接连接到 midiout 对象。

midi

中间出口：当 sync~ 对象收到 MIDI 节拍时钟 tick 时，它会从中间出口发送一条 midi 消息。

signal

左出口：与 phasor~ 对象相似，sync~ 对象会生成锯齿波形，在当前速度下每过一个四分音符就从 0 递增到 1。这个斜坡可以根据需要用 rate~ 对象缩放，以便配合 wave~ 及其他对象使用。

tap

中间出口：当 sync~ 对象收到一次拍击时，它会从中间出口发送一条 tap 消息。
