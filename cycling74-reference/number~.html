MSP

number~

信号监视器与常量发生器

描述

使用 number~ 对象来显示信号取值或生成信号取值。

讨论

number~ 对象有两种不同的显示模式。在信号监视模式中，它显示左入口收到的 signal 取值。

在信号输出模式中，它显示最近在左入口收到的 float 或 int 取值、或直接键入到 number~ 对象框中的取值（该信号会从左出口送出）。当 number~ 对象被高亮时（表现为一个向下的黄色箭头），用键盘输入数字会改变其取值。点击鼠标或按下 Return 或 Enter 会存储待键入的数值，并把它作为新的信号取值从左出口送出。

参数

无。

特性

bgcolor [4 floats]

设置 number~ 对象框在显示且未被点击时的背景颜色。

ft1 [float] : 0.

单词 ft1 后面跟一个数字，设置插值斜坡时间，单位为毫秒。默认时间为 0。

interval [float] : 100.

设置更新间隔，单位为毫秒。它控制 number~ 处于输入监视显示模式时显示更新的速率，也控制数字从该对象右出口送出的速率。

maximum [atom] : <none>

设置该对象所能显示或送出的最大取值。

minimum [atom] : <none>

设置该对象所能显示或送出的最小取值。

monitormode [int] : 1

切换信号监视模式。默认值为 1（开）。

numdecimalplaces [int] : 0

显示的小数位数

sigoutmode [int] : 1

切换信号输出模式。默认值为 1（开）。

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

textcolor [4 floats]

设置 number~ 对象框在显示且未被点击时的数字取值颜色。textcolor 特性映射到 textcolor_inverse 样式颜色。

消息

bang

在信号输出模式下，bang 消息会输出当前的信号取值。

int

转换为 float。
左入口：该取值作为常量信号从左出口送出。当 number~ 处于信号输出显示模式时，该取值会被显示。若当前斜坡时间非零，输出信号会在其先前取值与新设置的取值之间做斜坡变化。
右入口：设置斜坡时间，单位为毫秒。默认时间为 0。

参数：

  • input [int]

float

左入口：该取值作为常量信号从左出口送出。当 number~ 处于信号输出显示模式时，该取值会被显示。若当前斜坡时间非零，输出信号会在其先前取值与新设置的取值之间做斜坡变化。
右入口：设置斜坡时间，单位为毫秒。默认时间为 0。

参数：

  • input [float]

(inlet1)

右入口：设置以毫秒为单位的斜坡时间。默认时间为 0。

参数：

  • input [float]

list

第一个数字设置从左出口送出的信号取值，第二个数字设置斜坡时间，单位为毫秒。

参数：

  • input-value [number]
  • ramp-time [int]

allow

单词 allow 后面跟一个数字，设置可以使用哪些显示模式。allow 1 把 number~ 限制为信号输出显示模式。allow 2 把 number~ 限制为输入监视显示模式。allow 3 允许两种模式，并让用户通过点击 number~ 左侧的三角形区域在两者之间切换。

参数：

  • display-mode-availability [int]

flags

flags 消息是为 number~ 对象的遗留支持而提供的；原有的全部功能现在都由对象特性提供。

参数：

  • appearance/behavior [int]

max

单词 max 后面跟一个可选数字，为信号输出设置 number~ 的最大取值。注意，与浮点数数字框不同，number~ 的最大取值不限于整数取值。若单词 max 后面没有跟数字，则清除任何最大取值。

参数：

  • maximum-value [number]

min

单词 min 后面跟一个可选数字，为信号输出设置 number~ 的最小取值。注意，与浮点数数字框不同，number~ 的最小取值不限于整数取值。若单词 min 后面没有跟数字，则清除任何最小取值。

参数：

  • minimum-value [number]

mode

单词 mode 后面跟一个数字，在当前允许的情况下设置当前显示模式（参见 allow 消息）。mode 1 设置信号输出显示模式。mode 2 设置信号输入监视显示模式。

参数：

  • display-mode [int]

(mouse)

点击 number~ 左侧的三角形区域，会在信号监视显示模式（绿色波形）与信号输出显示模式（黄色或绿色向下箭头）之间切换。处于信号输出显示模式时，在显示数字的区域点击会改变从 number~ 左出口送出的信号取值，和/或把它选中以便键入。

set

单词 set 后面跟一个数字，使 number~ 对象显示该数字，但不产生输出。

参数：

  • set-input [float]

signal

任意信号，其取值会按固定间隔被采样并从右出口送出。当 number~ 处于信号监视显示模式时，会显示该信号取值。

输出

float

右出口：输入信号的采样值按 interval 消息指定的速率送出。

signal

左出口：音频开启时，number~ 从其左出口送出常量信号，该信号等于最近在左入口收到的（或由用户键入的）数字。它送出该取值时不依赖于其 signal 输入，也不管它当前是否处于信号输出显示模式。若最近在右入口收到的斜坡时间被设为非零值，输出会在指定时间内于先前取值与新设置的取值之间做插值。
