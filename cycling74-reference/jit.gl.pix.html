Jitter

jit.gl.pix

从 gen 补丁生成像素处理着色器

描述

jit.gl.pix 对象从补丁生成新的像素处理着色器。jit.gl.pix 本质上是一个 jit.gl.slab 对象，其着色器文件是从 Gen 补丁生成的。

filter [symbol]

设置内部纹理对象上的纹理过滤模式（默认值 = linear）。它控制纹理以大于其原生分辨率的尺寸渲染时所用的放大过滤器。该过滤器决定纹理的像素（即 texel）如何插值以填满更大的屏幕空间。
可选值：

'none'（ 不施加过滤（与 nearest 相同） ）
'nearest'（ 使用最邻近的单个像素的颜色 ）
'linear'（ 计算最邻近四个 texel 的加权平均 ）

rect [4 floats]

几何矩形（默认值 = 0 0 1 1）。这四个取值表示几何矩形左、下、右、上四边的归一化坐标。要水平翻转图像请使用 rect 1 0 0 1，要垂直翻转请使用 rect 0 1 1 0。

rectangle [int]

启用内部纹理对象上的纹理矩形模式（默认值 = 1）。启用时，内部 GL 纹理被当作矩形纹理处理，从 GLSL 着色器中取样时必须用 sampler2DRect 引用、用 texture2DRect 取样。禁用时，纹理维度会被升采样到最接近的 2 的幂数值，并且必须用 sampler2D 和 texture2D 引用和取样。某些纹理特性和 GLSL 效果要求禁用 rectangle 模式。

exportcode

把 gen 补丁导出为着色器代码。没有参数时，jit.gl.pix 会导出一个带 GLSL 代码的标准 Jitter JXS 着色器文件。可选参数可以是 'jxs'、'webgl' 或 'isf'。

在 'webgl' 的情况下，jit.gl.pix 会导出一个 .html 文件，适合在 WebGL 上下文中加载。该代码使用 TWGL 作为辅助库，并要求 twgl-full.min.js 文件与导出的 html 文件位于同一目录。

在 'isf' 的情况下，jit.gl.pix 会导出一个 .fs 片段着色器，适合在 ISF（Interactive Shader Format）上下文中加载

参数：

  • target [symbol]
