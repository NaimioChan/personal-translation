Max

panel

带颜色的背景区域

描述

panel 对象让你可以创建带颜色的面板，用于构建用户界面。面板可以有多种形状，包括圆形、三角形、箭头，以及可带圆角的矩形。还可以使用阴影和渐变。

参数

无。

特性

arrow_orientation [int] : 0

若 shape 设为 3（箭头），该特性设置箭头的指向。
可选值：

0 = 'Left to Right'
1 = 'Right to Left'
2 = 'Top to Bottom'
3 = 'Bottom to Top'

bgfillcolor [4 floats] >= 7.0.0

以 RGBA 格式设置 panel 的颜色。默认情况下，面板被配置为显示渐变，但可以用format palette把它改为使用单一颜色填充。

border [int] : 0

以像素为单位设置 panel 对象边框的大小。

bordercolor [4 floats]

以 RGBA 格式设置 panel 边框的颜色。

drag_window [int] : 0

当 drag_window 设为 1 且补丁处于锁定状态时，在面板上点击拖动会拖动补丁窗口。

horizontal_direction [int] : 0

若 shape 设为 2（三角形），该特性设置三角形的水平朝向。
可选值：

0 = 'Left to Right'
1 = 'Right to Left'

rounded [int] : 8

设置矩形面板圆角的大小，单位为像素。

shadow [int] : 0

以像素为单位设置 panel 对象「阴影」效果的大小。正数产生「凸起」的阴影效果，负数产生「凹陷」的效果。要启用该特性，必须把面板的 bgfillcolor 特性配置为显示颜色填充，即使用Color Palette（经由format palette）或 Object Inspector。

shape [int] : 0

设置面板的形状。
可选值：

0 = 'Rectangle'
1 = 'Circle'
2 = 'Triangle'
3 = 'Arrow'

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

vertical_direction [int] : 0

若 shape 设为 2（三角形），该特性设置三角形的垂直朝向。
可选值：

0 = 'Top to Bottom'
1 = 'Center'
2 = 'Bottom to Top'

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

(mouse)

当 drag_window 设为 1 且补丁处于锁定状态时，在面板上点击拖动会拖动补丁窗口。

size

size 一词后面跟两个数字，指定 panel 对象的宽度和高度，单位为像素。面板的默认尺寸为宽度 69、高度 57。

参数：

  • width (pixels) [int]
  • height (pixels) [int]

输出

none

面板没有输出，用于构建用户界面。
