Jitter

jit.gl.pass

用着色器处理渲染场景 pass

描述

jit.gl.pass 对象封装了一个或多个子 pass 的处理。一个子 pass 由单帧 gl 与后处理着色器组成，并在一个 xml pass 描述文件（JXP）中定义。通过串联多个 jit.gl.pass 对象，可以获得复杂的场景处理层级。

讨论

关于 JXP 文件格式的详细讨论，参见 Render Passes 用户指南。

关于创建自定义 pass 效果的示例，参见 pass.custom.effects 示例补丁。

用 @fxname 按 pass 名称读取 JXP 文件。该名称与文件名并不相同，它由 JXP 文件中的 pass 名称决定。下面是内置的 <pass> 效果，均链接到对应的示例：

atmospheric - 大气散射与地面雾
bloom-hq - 产生沿明亮区域边缘延伸的大气光
fxaa - 快速近似抗锯齿
gamma - 色调映射、gamma 校正与抖动噪声 pass
motionblur-hq - 基于像素速度的模糊效果
motionglitch - Data mosh 式故障效果
smear - 像素涂抹效果
ssao - 屏幕空间环境光遮蔽
ssr - 屏幕空间反射近似
tonemap - 修改像素的色调值
tssao-gi - 带全局光照的时域屏幕空间环境光遮蔽
tssao-gi-ssr - 带全局光照与屏幕空间反射的时域屏幕空间环境光遮蔽
dof-hq - 带散景参数与自动对焦的高质量景深
taa - 时域抗锯齿
gi - 通过 ReSTIR 的全局光照
vignette - 电影感暗角
grain - 胶片颗粒

特性

amount [4 floats]

该特性只由默认 pass 效果使用，用于控制混合量。

autowatch [int] >= 9.0.0

启用对源文件变化的监视（默认值 = 1）。文件监视打开时，文件被修改后会自动重新编译。这让你可以为自己的文件使用外部编辑器。

child [symbol]

子 jit.gl.pass 名称（默认值 = none）。由连线自动设置，也可通过提供有效的 jit.gl.pass 对象名手动设置。

embed [int] >= 9.0.0

启用后，着色器文件会随其补丁一起保存。若对象被载入的补丁没有 file 参数，则默认启用 embed。若提供了 file 参数，除非用户显式启用，否则 embed 会被禁用。

file [symbol]

JXP 文件名（默认值 = none）

fxname [symbol]

加载具名 pass 效果。可以从该菜单加载若干内置 pass 效果，如下所列。也可以加载来自 Packages 的自定义 pass 效果。这些效果的 jxp 文件必须位于包文件夹内的 media/jitter/passes 文件夹中。切换 fxname 会覆盖 file 特性。
可选值：

'atmospheric'
'bloom'
'bloom-tonemap'
'bloom-hq'
'depth'
'depth2pass'
'dof'
'dof-hq'
'fxaa'
'gamma'
'grain'
'motionblur-hq'
'motionblur'
'motion-gauss-blur'
'motionglitch'
'motionglitch-ext'
'gi'
'smear'
'ssao'
'ssao-gl2'
'ssr'
'taa'
'tonemap'
'tssao-gi-ssr'
'tssao-gi'
'vignette'

out_name [symbol] 只读

输出纹理名称（默认值 = UID）。若出现名称冲突，UID 会被追加到发生冲突的那个名称上。

quality [symbol]

内部纹理品质（默认值 = med）。更改品质会改变 type 特性，该特性属于内部的 jit.gl.texture 对象。
可选值：

'med' ( type = float16 )
'hi' ( type = float32 )

OB3D 特性

automatic [int]

自动渲染标志（默认值 = 1）该标志置位时，关联的 jit.gl.render 对象收到 bang 消息时即进行渲染

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

name [symbol]

实例名称（默认值 = UID）

texture [8 symbols]

要应用的纹理名称（默认值 = none）。若指定了多个纹理，则使用多重纹理。

OB3D 消息

bang

等价于 draw 消息。

draw

在具名的绘制目标中绘制该对象。若支持 matrixoutput 特性且其设为 1，几何矩阵会从对象的左出口送出。

drawraw

等价于 draw，且 inherit_all 特性设为 1。

drawimmediate

等价于 draw，但忽略任何可能的渲染器设置

jit_gl_texture

把 texture-name 指定的纹理绑定到该对象。等价于把 texture 特性设为 texture-name。
