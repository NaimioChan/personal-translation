Max

preset

存储与调取设置

描述

preset 只需点一下鼠标就能存储和调取任何指定界面对象的参数。它也可以用作用户界面链接，指向一个具名的 pattrstorage 对象。

参数

无。

特性

active1 [4 floats]

以 RGBA 格式设置对象的活动预设颜色

bgcolor [4 floats]

以 RGBA 格式设置对象的背景颜色

bubblesize [int32] : 8

设置预设 "bubble" 的大小（单位：像素）。bubble 必须大于 2 像素。

dirty [int] : 0

启用后，存储或清除预设会把 preset 的父补丁标记为 dirty，这样关闭文档时会提示你保存更改。

embed [int] : 1

切换是否能把预设作为主补丁的一部分保存（默认行为为 1（预设随补丁一起保存）。

emptycolor [4 floats]

以 RGBA 格式设置对象的空预设槽颜色。

ignoreconnected [int] : 0

忽略连接到预设入口的对象

ignoreemptyinterp [int] : 1

忽略空的多重插值

paramonly [int] : 0

启用后，preset 只存储连接到其最右出口的对象中的参数，而不是存储所有特性。这仅适用于带参数的对象，例如 gen~ 和 rnbo~。

pattrstorage [symbol]

pattrstorage 特性以 pattrstorage 对象的名称为参数，并把 preset 对象设置为可把它用作界面对象，来操作具名 pattrstorage 对象的内容。

stored1 [4 floats]

以 RGBA 格式设置对象的已存储预设颜色。

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

textcolor [4 floats]

以 RGBA 格式设置对象的文字颜色。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold

bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

送出最近一次用 int 或鼠标点击调取的预设的设置。

int

发送任何整数都会触发相同编号的预设。

参数：

  • slotnumber [int]

float

float 会调取相邻两个预设之间线性插值得到的预设。第一个预设是该 float 取值的整数部分，第二个预设是下一个更高的整数。第一个预设的权重是 1 减去该 float 取值的小数部分。第二个预设的权重是该 float 取值的小数部分。例如输入 2.7 时，预设 2 会贡献 30%，预设 3 会贡献 70%。并不是所有把数据存储在预设中的对象都能对存储的数据进行插值。对于这些对象，使用的数据会从权重最高的预设槽中选出。

参数：

  • interpolation_value [float]

list

见 bang 条目。

anything

若找到名称匹配的预设，就会调取它。

参数：

  • name [symbol]

clear

清除最近一次发送的预设的内容。clear 一词后面跟一个数字，会清除该编号预设的内容。

参数：

  • slotnumber [int]

clearall

清除所有预设的内容。

(mouse)

在 preset 对象中点击某个按钮会调取一个已存储的预设。

在 preset 对象中按住 Shift 点击某个按钮会存储一个预设。

可见预设的数量可以通过调整 preset 对象框的大小来改变。单个 preset 对象中预设的最大数量为 2048。

name

name 一词后面跟一个 symbol，设置该预设的 ID Name。ID Name 让预设拥有唯一的 ID，这样为它创建的文件不会被读取到其他预设中。

参数：

  • ID [symbol]

read

read 一词后面不带参数或跟一个数字，会显示 Open Document 对话框，用于选择要读取的预设数据文件。若该预设已被赋予 Preset Name Code，则只显示该代码所指定类型的文件。数字参数指定文件数据应读取到的预设编号。若该数字为 0 或 -1，文件中的数据会从第一个预设开始，读取到文件中包含的预设数量的预设中。若 read 一词后面跟一个 symbol，或一个数字加一个 symbol，则不显示对话框。此时该 symbol 被当作读取预设所用的文件名。数字的作用如前所述。

参数：

  • filename [symbol]
  • slotnumber [int]

recallmulti

recallmulti 的参数是一系列 float 取值，表示预设槽（整数部分）和权重（小数部分）。调取到的预设取值是所有预设的加权组合。权重会被归一化，因此不要求和为 1。例如：recallmulti 4.6 6.1 3.3 会把预设槽 4、6 和 3 分别以 0.6、0.1 和 0.3 的权重组合起来。并不是所有把数据存储在预设中的对象都能对存储的数据进行插值。对于这些对象，使用的数据会从权重最高的预设槽中选出。

参数：

  • preset_weights [list]

setname

setname 后面跟一个 int 预设槽编号和一个名称，会把该名称赋予该槽编号。把鼠标移到预设槽上时，或把 umenu 或 chooser 对象连接到 preset 时，会显示这些名称。赋予名称之后，可以通过把名称作为消息发送来调取预设。
若槽编号为 0，名称会被赋予当前预设。

参数：

  • slotnumber [int]
  • name [symbol]

store

store 一词后面跟一个数字，会把同一窗口中所有界面对象的当前设置存储到该数字所指的预设中。若给出了可选的名称参数，它会被赋予所存储的预设。

预设按从左到右、从上到下编号。设置存储到某个预设中后，该圆点的颜色会改变，表示里面已有内容。也可以按住 Shift 键并用鼠标点击预设，把设置存储到该预设中。

参数：

  • slotnumber [int]
  • name [symbol]

write

write 一词后面不带参数或跟一个数字，会显示 Save As 对话框，用于指定写入预设数据的目标文件名。若该预设已被赋予 Preset Name Code，文件会以该代码作为其文件类型。数字参数指定应从哪个预设编号写入预设数据。若该数字为 0 或 -1，则写入所有预设。若 write 一词后面跟一个 symbol，或一个数字加一个 symbol，则不显示对话框。此时该 symbol 被当作写入数据所用的文件名，文件会被放入当前默认文件夹中。数字的作用如前所述。

参数：

  • filename [symbol]
  • slotnumber [int]

输出

(internal)

第三个出口：连接到 preset 第三个出口的任何界面对象都会被排除在该 preset 的作用之外。（当你希望用 preset 影响的对象很多、只想排除少数几个时，这一点特别有用。）

数据存储在预设中的对象几乎包括所有界面对象。虽然 itable 对象会被存储和调取，但 table 对象必须用连线连接到 preset 对象的第一个出口。

preset 的第一个出口也可以连接到一个 send 对象，以便与连接到同名 receive 对象的对象通信。

int

第二个出口：调取预设时，会送出该预设的编号。

第四个出口：存储预设时，会送出该预设的编号。

int or float

左（第一个）出口：调取预设时，无论是通过鼠标点击还是通过入口中的数字，该预设中存储的设置都会从该出口送到所有已连接的对象；若没有连接任何对象，则送到补丁中所有界面对象。

右（第五个）出口：与左出口类似，但右出口还会送出所有随该预设一起存储的已连接对象的特性状态。

连接

chooser

把 chooser 对象连接到 preset 的入口，会显示所有预设的编号和名称。点击 chooser 中的某一行会调取所显示的预设。预设被添加、移除或命名时，chooser 的显示会更新。

nodes

把 nodes 对象连接到 preset 的入口，会为每个预设添加一个节点；上限由 maxdynamicnodes 特性设定，该特性属于 nodes 对象。连接之后，nodes 就充当多路插值的界面，如 recallmulti 消息下所述。

umenu

把 umenu 对象连接到 preset 的入口，会在菜单中显示所有预设的编号和名称。从 umenu 中选择某个菜单项会调取所显示的预设。预设被添加、移除或命名时，菜单会更新。
