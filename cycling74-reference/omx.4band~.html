omx.4band~

OctiMax 4 频段压缩器

描述

omx.4band~ 以 4 频段压缩器的形式提供 Octimax 的信号处理能力。

参数

无。

消息

bypass

单词 bypass 后面跟一个非零数字时，会把未作任何处理的干信号原样直接从出口送出；后面跟 0 时，会输出经 omx.4band~ 处理后的信号。

参数：

  • bypass-flag [int]

choosePreset

单词 choosePreset 后面跟一个 0-2 范围内的数字，会为 omx.4band~ 对象选择一个预设。这些预设应被视为“起始点”，应根据你的具体用途或想要的声音加以调整。预设选项有：

0：标准——适用于任何内容，所有音乐流派、电影、电视观看等。
1；流行——适合任何现代流派，包括摇滚、乡村、迷幻舞曲。
2；电影——与标准类似，但针对动态范围较大的电影配乐做了优化。

参数：

  • preset-number [int]

gating_threshold

单词 gating_threshold 后面跟一个数字，用于设置释音门阈值（以低于满刻度多少 dB 表示）。当信号低于该阈值时，压缩器的释音时间会放慢到 3 倍。

参数：

  • release-gate-threshold [float]

inagc_b1_atk

单词 inagc_b1_atk 后面跟一个数字，用于设置输入压缩器的启动速率。启动速率决定压缩器施加增益衰减的快慢。取值范围为对数刻度上的 0-150，取值越大表示启动越快。

参数：

  • attack-rate-coefficient [int]

inagc_b1_rel

单词 inagc_b1_rel 后面跟一个数字，用于设置输入压缩器的释放速率。释放速率决定压缩器恢复到单位增益的快慢。取值范围为对数刻度上的 0-150，取值越大表示释放越快。

参数：

  • release-rate-coefficient [int]

inagc_range

单词 inagc_range 后面跟一个数字，用于设置输入压缩器所施加的最大增益量（单位：dB）。压缩比固定为 infinity:1。

参数：

lim_drive

meterData

单词 meterData 会触发输出（以即时命令的方式，而非 meterRate 消息所描述的计量间隔）一些取值，这些取值描述压缩器各种内部电平的当前状态，可用于驱动 GUI 对象以提供视觉反馈。

meterRate

单词 meterRate 后面跟一个数字，用于指定上述电平表数据的发送间隔（单位：毫秒）。

参数：

  • output-interval [int]

meters

单词 meters 后面跟 1 或 0，打开或关闭计量输出。计量打开时，会按 meterRate 消息指定的速率从最右出口送出一个取值列表。这些取值描述压缩器各种内部电平的当前状态，可用于驱动 GUI 对象以提供视觉反馈。

参数：

  • metering-output-flag [int]

ngenabled

单词 ngenabled 后面跟 1 或 0，打开或关闭噪声门。当没有其他信号存在时，噪声门可有效降低背景嘶声。omx.4band~ 具有两个噪声门：一个作用于整个信号，另一个只影响较高的频率，例如嘶声。

参数：

  • noise-gate-enable-flag [int]

saveSettings

单词 saveSettings 会使所有参数值从第三个出口送出。

signal

音频输入，即待压缩的信号或信号对。

输出

list

第三个出口：响应 saveSettings 消息的参数取值。

第四个出口：计量数据。计量打开时，会输出描述各种内部电平的取值列表。参见 meters 消息的说明。

signal

从最左侧两个出口送出：应用动态处理之后的输入信号（若存在）。
