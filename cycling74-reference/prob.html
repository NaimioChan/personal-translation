Max

prob

创建一个加权转移表

描述

创建一张加权数值转移表。收到 bang 消息时，会计算权重以及一个可能的转移。

讨论

prob 在其入口接受由三个数字组成的列表。第三个数字表示从最初两个数字所代表的状态出发的概率权重。例如 1 2 4 表示从状态 1 转到状态 2 的权重为 4。当 prob 收到 bang 时，它会根据当前的转移权重，从当前状态随机跳到另一个状态。若可以转移，新状态会从左出口送出；若不能，则从右出口送出一个 bang。对于任意一个特定状态，所有可能转移状态的权重会相加。因此，若一个状态可以跳到权重分别为 3、4 和 1 的三个状态，那么第一个（3）出现的几率为 37.5%，第二个为 50%，第三个为 12.5%。注意任何状态都可以用 (state state weight) 形式的列表转移到自身。

参数

无。

特性

embed [int] : 0

非零（开）时，prob 的内容会随包含它的补丁一起保存。为零（关，默认值）时，prob 会在补丁关闭时忘记自己的内容。

消息

bang

根据紧接的前一次输出以及各后继数字的指定似然度，加权随机地选择一个要送出的数字。若尚未收到任何输入，或者 prob 对象的内容已用 clear 消息清除，则不会产生输出。

int

设置（但不送出）当前的数字取值。随后响应 bang 消息的输出，将由所存储的、从该数字出发的可能转移矩阵决定。

参数：

  • input [int]

list

这些数字会在从一数字到另一数字的转移概率矩阵（即一阶马尔可夫链）中建立一项。列表应由三个数字组成：当前值、下一个值，以及当前值后面跟着下一个值的概率。列表中的前两个数字确定一种可能的输出值接续：即第一个数字后面可能跟着第二个数字。第三个数字设置该数字序列出现的相对似然度。第一个数字送出后，下一次输出由赋予每个可能后继数字的相对似然度决定。

参数：

  • matrix [list]

clear

清除 prob 对象的内容。

dump

在 Max Console 中打印出所存转移概率（马尔可夫链）的完整列表。

reset

reset 一词后面跟一个数字，用于告诉 prob：当它「卡」在一个没有可能后继数字的数字上时，应回退到哪个数字。

参数：

  • value [int]

输出

bang

右出口：若当前数字（最后选中的数字）在转移概率矩阵中没有列出任何可能的转移，那么响应入口的 bang 时，会送出一个 bang（且左出口不送出任何内容）。

int

左出口：入口收到 bang 时，prob 会送出一个数字，该数字是它根据对最后选中数字的了解以及赋予每个可能后继数字的相对似然度来选择的。
