jit.anim.node

执行层级变换

描述

jit.anim.node 对象表示 3D 空间中的一种变换（位置、朝向和缩放）。OpenGL 对象绑定到 jit.anim.node 后会获得 position、rotate 和 scale 特性。此外，还可以在层级变换结构中建立父子关系，此时子级 jit.anim.node 对象相对于其父级来做变换。

讨论

所提供的消息可以相对于当前变换做平移、旋转和缩放，可选局部空间、父空间或绝对世界空间。当 jit.anim.node 绑定到 jit.gl.camera 时，还提供额外的特性用于高级控制。

特性

anchor [3 floats]

调整节点锚点（轴心）的位置（默认值 = 0 0 0）。节点绕该位置旋转。

anim [symbol]

父 anim_node 名称

animmode [symbol]

同时设置 turnmode 和 movemode 两个特性（默认值 = parent）。
可选值：

'local'（相对于局部轴做变换）
'parent'（相对于父级轴做变换）
'world'（相对于世界轴做变换）

automatic [int]

启用来自绘制上下文的自动更新（默认值 = 1）。

direction [3 floats]

设置朝向的一种方式。节点会调整为让自己局部 Z 轴与所给的轴对齐。（默认值 = 0 0 1）

inherit_position [int]

启用从父节点继承位置取值（默认值 = 1）。

inherit_rotate [int]

启用从父节点继承旋转取值（默认值 = 1）。

inherit_scale [int]

启用从父节点继承缩放取值（默认值 = 1）。

invtransform [16 floats] 只读

取回逆世界变换

locklook [int]

强制节点始终指向 lookat 取值，忽略朝向消息与特性（默认值 = 0）。

lockplane [int]

让 move 消息下指定通道的平移取值置零（默认值 = 0）。
可选值：

0 = 'none'
1 = 'x-plane'
2 = 'y-plane'
3 = 'z-plane'

lookat [3 floats]

设置朝向的一种方式。节点会调整为让自己局部 Z 轴指向所给的 3D 位置。（默认值 = 0 0 0）

movemode [symbol]

决定 move 消息在哪个空间影响该节点的位置（默认值 = parent）。
可选值：

'local'（相对于局部轴移动）
'parent'（相对于父级轴移动）
'world'（相对于世界轴移动）

name [symbol]

实例名称。ob3d 对象可以把自身的 anim 特性设为此取值，从而绑定到该节点。

parentpos [3 floats]

由 anim 特性所指名的节点设置。指定 3D 空间中的一个位置，该位置会与局部位置拼接，以得出世界位置。（默认值 = 0 0 0）

parentquat [4 floats]

由 anim 特性所指名的节点设置。指定一个四元数朝向，该朝向会与局部朝向拼接，以得出世界朝向。（默认值 = 0 0 0 1）

parentrot [4 floats]

由 anim 特性所指名的节点设置。指定一个轴角朝向，该朝向会与局部朝向拼接，以得出世界朝向。（默认值 = 0 0 0 1）

parentscale [3 floats]

由 anim 特性所指名的节点设置。指定一个缩放取值，该取值会与局部缩放拼接，以得出世界缩放。（默认值 = 1 1 1）

position [3 floats]

指定 3D 空间中的一个位置。该位置相对于父节点所提供的位置。（默认值 = 0 0 0）

quat [4 floats]

指定 3D 空间中的一个四元数朝向。该朝向相对于父节点所提供的朝向。（默认值 = 0 0 0 1）

rotate [4 floats]

指定 3D 空间中的一个轴角朝向。该朝向相对于父节点所提供的朝向。（默认值 = 0 0 0 1）

rotate_order [symbol]

设置 rotatexyz 特性所采用的旋转施加顺序（默认值 = auto）。例如设为 xyz 时，对象先绕其 X 轴旋转，再绕 Y 轴，最后绕 Z 轴。auto 默认实现的是 yzx 顺序。若要复现 Max 5 的行为，请用 zyx。若已绑定 ob3d，该取值会覆盖 rotate_order，也就是从其 jit.gl.render 上下文继承来的那个特性。
可选值：

'auto'
'xyz'
'xzy'
'yxz'
'yzx'
'zxy'
'zyx'

rotatexyz [3 floats]

指定 3D 空间中的一个欧拉朝向。该朝向相对于父节点所提供的朝向。（默认值 = 0 0 0）

scale [3 floats]

局部 3D 缩放因子，形式为 x y z（默认值 = 1. 1. 1.）

scalemode [symbol]

决定 inherit_scale 启用时，继承来的 parentscale 沿哪些轴施加（默认值 = local）。当 inherit_scale 禁用或该节点没有父节点时无效。
可选值：

'local'（继承的缩放沿该节点自身的局部（已旋转）轴施加）
'parent'（继承的缩放沿父级的轴施加）

transform [16 floats]

获取并设置完整的局部 4x4 矩阵变换。

tripod [int]

强制节点像架在三脚架上那样摆放朝向。无论 turnmode 为何，Y 轴的 turn 取值都在世界空间中施加（默认值 = 0）。

turnmode [symbol]

决定 turn 消息在哪个空间影响该节点的朝向（默认值 = parent）。
可选值：

'local'（相对于局部轴旋转）
'parent'（相对于父级轴旋转）
'world'（相对于世界轴旋转）

worlddir [3 floats] 只读

取回世界空间方向向量。

worldpos [3 floats] 只读

由局部位置与父级位置推导出的 3D 空间位置。（默认值 = 0 0 0）

worldquat [4 floats] 只读

由局部朝向与父级朝向推导出的 3D 空间朝向。（默认值 = 0 0 0 1）

worldrot [4 floats] 只读

由局部朝向与父级朝向推导出的 3D 空间朝向。（默认值 = 0 0 0 1）

worldscale [3 floats] 只读

由局部缩放与父级缩放推导出的 3D 空间缩放取值。（默认值 = 1 1 1）

worldtransform [16 floats] 只读

完整的世界变换

消息

bang

输出当前的世界变换坐标，也就是局部变换与父级变换拼接的结果。

anim_grow

按给定的量沿各轴缩放该节点。

参数：

  • x [float]
  • y [float]
  • z [float]

anim_move

沿所给的轴移动该节点，移动相对于 movemode 所指示的空间。

参数：

  • x [float]
  • y [float]
  • z [float]

anim_reset

把局部变换特性重置为默认值（position = 0 0 0、rotatexyz = 0 0 0、scale = 1 1 1）

anim_turn

按给定的量沿各轴旋转该节点，旋转相对于 turnmode 所指示的空间。

参数：

  • x [float]
  • y [float]
  • z [float]

concat

把当前变换与传入的 4x4 矩阵拼接（相乘）。操作完成后会更新局部变换特性。

grow

参见 anim_grow 列表

参数：

  • x [float]
  • y [float]
  • z [float]

localtoworld

从传入的局部坐标取回世界空间位置。这些局部坐标相对于当前的世界空间变换。

参数：

  • x [float]
  • y [float]
  • z [float]

localtoworld_quat

从传入的局部四元数取回世界空间四元数。返回的四元数是当前世界空间四元数与局部四元数的乘积。

参数：

  • x [float]
  • y [float]
  • z [float]
  • w [float]

move

参见 anim_move 列表

参数：

  • x [float]
  • y [float]
  • z [float]

reset

参见 anim_reset 列表

turn

参见 anim_turn 列表

参数：

  • x [float]
  • y [float]
  • z [float]

update_node

参见 bang 条目

worldtolocal

从传入的世界坐标取回局部空间位置。这些局部坐标相对于当前的世界空间变换。

参数：

  • x [float]
  • y [float]
  • z [float]

worldtolocal_quat

从传入的世界四元数取回局部四元数。返回的四元数是当前逆世界空间四元数与世界四元数的乘积。

参数：

  • x [float]
  • y [float]
  • z [float]
  • w [float]
