Jitter

jit.gl.material

为 3D 对象生成材质

描述

为高质量渲染生成着色器，它们会自动适应纹理输入以及活动光源的数量。

讨论

该 OB3D 对象可选地接受一个参数：绘制上下文的名称。它可以是 jit.world 或 jit.pworld 对象的具名实例，也可以是 jit.gl.node 子上下文。该值也可以通过 OB3D 的 drawto 特性设置。若未给出参数，对象会被隐式加入当前补丁中找到的第一个有效绘制上下文或子上下文，或者沿补丁层级向上搜索找到的第一个有效绘制上下文或子上下文。

特性

darkness [float]

材质暗度。仅当漫反射着色模型为 minnaert 时有效。

diffuse_model [symbol]

漫反射着色模型
可选值：

'lambert' ( Lambertian 漫反射着色模型 )
'oren_nayer' ( Oren-Nayer 漫反射着色模型 )
'toon' ( Toon 漫反射着色模型 )
'minnaert' ( Minnaert 漫反射着色模型 )

diffuse_size [float]

漫反射 toon 分量的大小。仅当漫反射着色模型为 toon 时有效。

diffuse_smooth [float]

漫反射 toon 分量的平滑度。仅当漫反射着色模型为 toon 时有效。

drawto [symbol]

渲染上下文名称

fog [symbol]

雾类型
可选值：

'none' ( 无雾 )
'linear' ( 线性雾 )
'exp' ( 指数雾 )
'exp2' ( 平方指数雾 )

heightmap_mode [symbol]

在使用高度图输入时要采用的高度图模式（默认值 = parallax）。
可选值：

'parallax' ( 视差高度图模式 )
视差高度图模式与法线贴图配合使用，通过置换纹理坐标来增强深度效果。使用 parallax 模式时需要 normals 输入。

'vtf' ( 顶点纹理取样模式 )
顶点纹理取样模式在顶点程序中采样高度图纹理的第一个通道（红色通道），并按该值沿法线置换顶点位置。vtf 模式要求纹理输入必须是非矩形纹理（@rectangle 0）。

'vtf_normals' ( 带法线生成的顶点纹理取样模式 )
带法线生成的顶点纹理取样模式与 vtf 模式类似，但它还会为置换后的网格重新生成光照法线。

override [int]

覆盖 jit.gl 对象的颜色材质特性

roughness [float]

材质粗糙度。仅当漫反射着色模型为 oren_nayer 时有效。

shadow_eps [float] >= 7.0.0

阴影 epsilon（eps）会修改阴影的形状，并修正自阴影误差（默认值 = 0.2）。当绑定对象是阴影接收者时使用该取值。

shadow_hard [float] >= 7.0.0

调整阴影硬度（默认值 = 0.7）。当绑定对象是阴影接收者时使用该取值。

shadow_radius [float] >= 7.0.0

调整阴影模糊半径（默认值 = 0.3）。当绑定对象是阴影接收者时使用该取值。

shadow_soft [float] >= 7.0.0

调整阴影柔和度（默认值 = 0.3）。会覆盖 shadow_radius 与 shadow_hard 特性。当绑定对象是阴影接收者时使用该取值。

specular_model [symbol]

高光着色模型
可选值：

'blinn' ( Blinn 高光着色模型 )
'phong' ( Phong 高光着色模型 )
'toon' ( 卡通高光着色模型 )
'ward' ( Ward 高光着色模型 )
'cook_torrance' ( Cook-Torrance 高光着色模型 )

specular_size [float]

高光卡通分量的大小。仅当高光着色模型为 toon 时有效。

specular_smooth [float]

高光卡通分量的平滑度。仅当高光着色模型为 toon 时有效。

type [symbol] 只读

材质类型（材质的描述性名称）。

OB3D 特性

automatic [int]

自动渲染标志（默认值 = 1）该标志置位时，关联的 jit.gl.render 对象收到 bang 消息时即进行渲染

aux_color [4 floats]

辅助颜色，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

fog_params [7 floats]

雾参数，形式为 red green blue alpha density start end（默认值 = 0. 0. 0. 0. 0. 0. 0.）列表中颜色各元素应在 0.-1. 范围内。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

mat_ambient [4 floats]

环境光材质属性，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

mat_diffuse [4 floats]

漫反射光材质属性，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

mat_emission [4 floats]

材质自发光属性，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

mat_specular [4 floats]

镜面反射光材质属性，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

matfile [symbol]

要应用的 Jitter 材质文件（.jitmtl）

name [symbol]

实例名称（默认值 = UID）

shininess [float]

材质的镜面光泽度值（默认值 = 16.0）该值应为 0.-255. 范围内的浮点数。

smooth_shading [int]

平滑着色标志（默认值 = 0）该标志置位时，渲染时使用平滑着色。

等价于 draw 消息。
