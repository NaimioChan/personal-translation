mc.midiplayer~

根据音频信号生成 MIDI 事件

描述

mc.midiplayer~ 对象根据代表触发、音符号和力度取值的音频信号生成 midievent 的 note-on 与 note-off 消息。通常你会把 mc.midiplayer~ 连到 vst~，它允许以音频速率产生采样点精确的 MIDI 事件（假定所承载的插件支持）。

参数

无。

特性

chanmod [int]

mc.midiplayer~ 的每个输入音频通道一次只能生成一个 MIDI 事件。chanmod 特性决定多个音频通道如何映射到 MIDI 通道。chanmod 的最小值为 1，表示所有音频通道都在 MIDI 通道 1 上生成音符事件。chanmod 的最大值为 16，此时 mc.midiplayer~ 使用全部 16 个可用的 MIDI 通道。启用 mpemode 时，chanmod 的最大值为 15，因为 MPE 把通道 1 用于全局 MIDI 事件。

defaultdur [float]

当 triggermode 设为 Phasor 时，mc.midiplayer~ 会在 phasor 斜坡起始处送出一个 note-on，并在 phasor 重置时送出一个 note-off。defaultdur 设置斜坡中触发 note-off 事件的那个点。例如，若 defaultdur 设为 0.5，则当输入的 phasor 到达 0.5 时送出 note-off。要为每个通道设置时长比例，请使用带 dur 选择符的 setvalue 消息。改变 defaultdur 时，它不会覆盖已设置的任何通道专用时长取值。要让某个通道使用 defaultdur 的取值作为音符时长，把它的通道专用时长设为零。

defaultnote [int]

设置用于之后所有音符事件的音符号。它的效果与向对象的中间入口发送一个数字相同。若 mc.midiplayer~ 的中间（音符号）入口连有信号，则忽略该设置。要为每个通道设置音符号，请向中间入口发送带数字参数的 setvalue 消息。改变 defaultnote 时，它不会覆盖已设置的任何通道专用音符号取值。要让某个通道使用 defaultnote 的取值作为音符号，把它的通道专用音符号设为零。

defaultvelocity [int]

设置用于之后所有 note-on 事件的力度。它的效果与向对象的中间入口发送一个数字相同。若 mc.midiplayer~ 的右（力度）入口连有信号，则忽略该设置。要为每个通道设置力度取值，请向右入口发送带数字参数的 setvalue 消息。改变 defaultvelocity 时，它不会覆盖已设置的任何通道专用音符号取值。要让某个通道使用 defaultvelocity 的取值作为它的力度，把它的通道专用力度设为零。

mpemode [int]

启用 mpemode 时，音符事件不在 MIDI 通道 1 上送出，且 chanmod 特性的最大值为 15。

playzero [int]

启用 playzero 时，即使音符号为零，MIDI 音符事件也会播放。当 triggermode 设为 Edge 或 Change、且用同一路信号来触发和指定音符号时，禁用 playzero 很有用。注意：输入的 力度 取值为 0 时会禁用音符事件，无论 playzero 如何设置。

triggermode [int]

确定输入的触发信号（连到左入口）如何生成音符事件
可选值：

0 = 'Phasor'（根据 phasor 斜坡触发音符）
当 triggermode 设为 Phasor 时，斜坡中第一个上升的采样点取值会触发 note-on，第一个下降（重置）的采样点会触发 note-off。若时长比例（通过 dur 消息或 defaaultdur 特性给出）小于 1.0，则 note-off 会在斜坡取值到达所指定取值时被触发。

1 = 'Edge'（根据逻辑采样点取值跳变触发音符）
当 triggermode 设为 Edge 时，输入信号从零到非零的跳变会触发 note-on，从非零到零的跳变会触发 note-off。

2 = 'Change'（根据采样点取值变化触发音符）
当 triggermode 设为 Change 时，采样点取值一变就触发 note-on。若已有音符正在播放，会先送出正在播放那个事件的 note-off。若不希望音符连续不断地播放，禁用 playzero 特性会有帮助，因为音符号取值为零会（在必要时）触发 note-off 而不播放另一个音符。

velcurve [float]

velcurve 特性为 MIDI 事件的力度值引入非线性。若想要更传统的曲线，请使用负值（默认值为 -0.75）。取值为 0 表示没有非线性，正值则引入一种不那么传统的非线性：输入值越低，相对输入值越高时上升得越快。内置的非线性函数基于一条简单的 Bezier 曲线；若想在输入到达 mc.midiplayer~ 的右入口之前对输入进行缩放以获得更多选项，请参阅 Ease 包。

消息

int

中间入口的一个数字为后续的音符事件设置音符号。右入口的一个数字为后续的音符事件设置力度值。这会为所有 MIDI 通道全局设置取值。若要按通道设置音符号、力度或时值，请使用 setvalue 消息。若相应入口上连接了信号，这些取值会被忽略。

float

参见 int 消息。

setvalue

setvalue 消息把后续音符事件的音符号、力度或时值赋予各个通道。通道号总是紧跟在单词 setvalue 之后。在通道号之后，若 setvalue 消息发往中间入口，则一个数字为指定通道设置音符号。若 setvalue 消息发往右入口，则一个数字为指定通道设置力度。在任意入口，setvalue channel dur value 会在 triggermode 设为 Phasor 时为该通道赋予一个时值比例。更多细节请参阅 defaultdur 特性。

signal

若中间入口连接了信号，它设置触发新音符时所用的音符号。若右入口连接了信号，它设置触发新的 note-on 时所用的力度值。
