Max

vstscan

音频插件扫描器

描述

vstscan 提供音频插件扫描的接口，使该功能可以呈现在补丁和独立应用程序中。你可以用 vstscan 构建插件名称菜单，供补丁代码使用。

参数

无。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

cancel

cancel 消息会立即停止插件扫描（正在扫描的那个插件会被列入黑名单）。

listau

通过 vstscan 对象最左侧的出口列出 AudioUnit 插件。每个条目前面带有选择器 plug_au。可选参数 instrument、effect 和 blacklist 可以单独使用或组合使用，把列表限制为所需类型的插件。

参数：

  • types [list]

listvst

通过 vstscan 对象最左侧的出口列出 VST 插件。每个条目前面带有选择器 plug_vst。可选参数 instrument、effect 和 blacklist 可以单独使用或组合使用，把列表限制为所需类型的插件。

参数：

  • types [list]

listvst3

通过 vstscan 对象最左侧的出口列出 VST3 插件。每个条目前面带有选择器 plug_vst3。可选参数 instrument、effect 和 blacklist 可以单独使用或组合使用，把列表限制为所需类型的插件。

参数：

  • types [list]

scan

重新扫描系统插件文件夹以查找新插件。在 MacOS 上，该路径通常是（对 VST 插件而言）/Library/Audio/Plug-ins/VST/ ，而在 Windows 上则是注册表键 HKLM\Software\VST 下 VSTPluginsPath 字符串值所指定的文件夹。扫描过程会在 Max 的偏好设置文件夹中生成信息文件，并把它们加入搜索路径。

从 Max 8 起有两种扫描模式。最小/快速扫描方式只依据磁盘上的文件快速收集插件信息，而不访问插件本身；完整/慢速扫描则对已安装的插件执行一次完整扫描，访问插件以确定其兼容性与功能。"slow" 扫描只会慢一次，以后运行时会执行一次快速更新，以确定操作系统自上次扫描以来发生的任何变化。

scanmode 参数可用于指定扫描类型：

  • 0 或 default（默认）：执行默认的完整/慢速扫描。若此前选择的是最小/快速扫描，则启用完整/慢速扫描并执行一次完整扫描。若完整/慢速扫描已启用，则执行一次快速更新扫描。
  • 1 或 partial：若之前的扫描把某些插件列入了黑名单，则重置这些插件的黑名单状态并执行一次更新扫描。
  • 2 或 full：完全重置之前扫描收集到的信息，并执行一次完整扫描。
  • 3 或 reset：重置扫描状态并选择最小/快速扫描。

参数：

  • scanmode [list]

skip

若某个插件无法在合理的时间内完成扫描，可能导致进程挂起长达 5 分钟（此时 Max 会显示一个对话框，询问是否跳过该插件）。skip 消息可以强制 Max 立即跳过扫描。正在扫描的那个插件会被列入黑名单，扫描继续进行。
