array.sort

根据检测的结果对 array 对象的元素排序

描述

每一对条目都会被输出，由使用者比较它们，然后传回 1（左边 > 右边）或 0（左边 <= 右边）来确定最终的排序顺序。

讨论

与 array.map 和 array.reduce 类似，当对象遍历数组的元素时，向最右入口发送一个值以完成对每一对的处理，直到得出最终结果。

参数

无。

特性

simple [int]

简单排序模式
可选值：

0 = 'Off'
1 = 'Ascending'
2 = 'Descending'
