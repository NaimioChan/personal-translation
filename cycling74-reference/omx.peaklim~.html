omx.peaklim~

OctiMax 峰值限幅器

描述

omx.peaklim~ 是一个峰值限幅器，它允许对信号幅度进行指定的控制。

参数

无。

消息

bypass

单词 bypass 后面跟一个非零数字时，会把未经改变的干输入信号不做任何处理直接从出口送出；后面跟 0 时，会输出经过 omx.peaklim~ 处理的信号。

参数：

  • bypass-flag [int]

ingain

单词 ingain 后面跟 0-100 的数字，设置限幅之前施加到信号上的增益（-24 到 +24 dB）。

参数：

  • pre-limiter-gain [float]

meterData

计量打开时，单词 meterData 会使最右出口按 meterRate message 指定的速率送出包含两个取值的列表。这些取值描述当前施加到两个输入信号上的增益衰减量，单位为 dB。

meterRate

单词 meterRate 后面跟一个数字，用于指定上述电平表数据的发送间隔（单位：毫秒）。

参数：

  • data-output-interval [int]

meters

单词 meters 后面跟 1 或 0，打开或关闭计量输出。计量打开时，会按 meterRate message 指定的速率从最右出口送出包含两个取值的列表。这些取值描述当前施加到两个输入信号上的增益衰减量，单位为 dB。

参数：

  • metering-flag [int]

mode

单词 mode 后面跟一个数字，按如下方式设置限幅器响应模式：0 = punchy，1 = smooth。punchy 响应带来极短的起音与释音时间，适用于透明限幅，或用于制造响度。不过若过度使用，可能会产生互调失真。smooth 响应使用较长的起音与释音时间。结果仍是一个快速的前瞻限幅器，但互调失真更少、冲击感更弱。

参数：

  • response-mode-flag [int]

outgain

单词 outgain 后面跟一个数字（0-100），设置限幅之后施加到信号上的增益（-24 到 +24 dB）。

参数：

  • post-limiter-gain [float]

saveSettings

单词 saveSettings 会使所有参数值从第三个出口送出。

signal

音频输入，即待压缩的信号或信号对。

threshold

单词 threshold 后面跟一个数字（0-100），设置限幅器阈值（低于满刻度 -24 到 +24 dB）。当输入信号电平超过该阈值时，它会被按需衰减，以使电平保持在阈值以下。

参数：

  • limiter-threshold [float]

输出

list

第三个出口：响应 saveSettings 消息的参数取值。

第四个出口：计量数据。计量打开时，会输出描述各种内部电平的取值列表。参见 meters 消息的说明。

signal

从最左侧两个出口送出：应用动态处理之后的输入信号（若存在）。
