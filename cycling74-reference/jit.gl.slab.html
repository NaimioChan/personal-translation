jit.gl.slab

处理纹理数据

描述

使用片元着色器高效地生成、处理和合成图像。开发自定义纹理效果，在显卡上处理。

讨论

该 OB3D 对象可选地接受一个参数：绘制上下文的名称。它可以是 jit.world 或 jit.pworld 对象的具名实例，也可以是 jit.gl.node 子上下文。该值也可以通过 OB3D 的 drawto 特性设置。若未给出参数，对象会被隐式加入当前补丁中找到的第一个有效绘制上下文或子上下文，或者沿补丁层级向上搜索找到的第一个有效绘制上下文或子上下文。

特性

autowatch [int] >= 9.0.0

启用对源文件变化的监视（默认值 = 1）。文件监视打开时，文件被修改后会自动重新编译。这让你可以为自己的文件使用外部编辑器。

bypass [int] >= 9.0.0

旁路 slab 处理标志（默认值 = 0）。启用时，输入不经处理直接传到输出。

activeinput [int]

用于纹理与矩阵消息的当前输入（默认值 = 0）。从 Java 或 JavaScript 调用输入消息时很有用。

adapt [int] : 1

启用对输入的自适应（默认值 = 1）。启用后，纹理输出维度将与输入维度一致。

colormode [symbol]

纹理颜色模式（默认值 = argb）
可选值：

'argb'
'uyvy'

embed [int] >= 9.0.0

启用后，着色器文件会随其补丁一起保存。若对象被载入的补丁没有 file 参数，则默认启用 embed。若提供了 file 参数，除非用户显式启用，否则 embed 会被禁用。

dim [2 ints]

adapt 被禁用时的纹理输出维度（默认值 = 256 256）

dimscale [2 floats]

输出的维度缩放因子（默认值 = 1 1）。用于对纹理输出做升采样或降采样。
output.dim = input.dim*dimscale

file [symbol]

要使用的着色器描述文件（JXS）（默认值 = none）

filter [symbol]

设置内部纹理对象上的纹理过滤模式（默认值 = linear）。它控制纹理以大于其原生分辨率的尺寸渲染时所用的放大过滤器。该过滤器决定纹理的像素（即 texel）如何插值以填满更大的屏幕空间。
可选值：

'none'（ 不施加过滤（与 nearest 相同） ）
'nearest'（ 使用最邻近的单个像素的颜色 ）
'linear'（ 计算最邻近四个 texel 的加权平均 ）

inputs [int]

slab 输入数量（默认值 = 2）。该值当前的上限为 32。

out_name [32 symbols] 只读

输出纹理名称

outputs [int]

纹理输出数量（默认值 = 1）。纹理输出对应着色器的渲染目标。该值当前的上限为 8。多重渲染目标的示例参见 mrt.slab.unpack

rect [4 floats]

slab 几何体矩形（默认值 = 0 0 1 1）。这四个取值表示几何体矩形左、下、右、上四边的归一化坐标。要水平翻转图像，请使用 rect 1 0 0 1；要垂直翻转图像，请使用 rect 0 1 1 0。

rectangle [int]

启用内部纹理对象上的纹理矩形模式（默认值 = 1）。启用时，内部 GL 纹理被当作矩形纹理处理，从 GLSL 着色器中取样时必须用 sampler2DRect 引用、用 texture2DRect 取样。禁用时，纹理维度会被升采样到最接近的 2 的幂数值，并且必须用 sampler2D 和 texture2D 引用和取样。某些纹理特性和 GLSL 效果要求禁用 rectangle 模式。

thru [int]

启用 thru 模式（默认值 = 1）。该标志置位时，只要收到输入就会送出纹理输出。

scale [float]

type [symbol]

输出纹理数据类型（默认值 = auto）。当 type 为 auto 时，类型由输入纹理或矩阵的类型设定。
可选值：

'auto'（ 自适应输入数据类型 ）

OB3D 特性

alpha_mode [symbol]

用独立的 alpha 混合函数与方程对混合过程进行更精细的控制。
可选值：

'link' ( 与 blend_mode 链接（默认值） )
'max' ( 取最大值 )
'add' ( 求和 )
'replace' ( 用源替换目标 )
'ignore' ( 忽略源 )

blend [symbol]

具名混合模式。可选值有：
add = blend_mode 1 1
multiply = blend_mode 2 1
screen = blend_mode 4 1
exclusion = blend_mode 4 5
colorblend = blend_mode 3 4
alphablend = blend_mode 6 7
coloradd = blend_mode 3 1
alphaadd = blend_mode 6 1

blend_enable [int]

混合标志（默认值 = 0）该标志置位时，所有被渲染的对象都启用混合。

blend_mode [2 ints]

与混合模式关联的源通道和目标通道（默认值 = 6 7）混合模式以 src_blend_mode dst_blend_mode 的形式给出。支持的取值有：
0 = zero
1 = one
2 = destination color
3 = source color
4 = one minus destination color
5 = one minus source color
6 = source alpha
7 = one minus source alpha
8 = destination alpha
9 = one minus destination alpha
10 = source alpha saturate

depth_clear [int]

深度缓冲清除标志（默认值 = 0）该标志置位时，渲染对象之前会清除深度缓冲。

depth_enable [int]

深度缓冲标志（默认值 = 1）该标志置位时，启用深度缓冲。

depth_write [int]

深度写入标志（默认值 = 1）。该标志置位时，启用对深度缓冲的写入。若 depth_enable 已关闭，则此设置无效。

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

name [symbol]

实例名称（默认值 = UID）

texture [8 symbols]

要应用的纹理名称（默认值 = none）。若指定了多个纹理，则使用多重纹理。
