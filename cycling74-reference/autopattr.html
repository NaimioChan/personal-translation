Max

autopattr

把多个对象暴露给 pattr 系统

描述

使补丁中的多个对象自动纳入 pattr 系统。

注意：在补丁的每一层级上，只应使用一个 autopattr 对象的实例。

参数

name [symbol] 可选

可以用一个符号参数来设置 autopattr 对象的 name。若没有给出参数，autopattr 对象会被赋予一个任意的、半随机的名称，例如 u197000004。

特性

autoname [int]

autoname 一词后面跟一个 1 或 0，用于启用或禁用 autopattr 对象的 autoname 状态。默认值为 0（关闭）。启用后，autopattr 对象会自动为补丁中所有受 pattr 系统支持的未命名对象命名，并尽可能与它们绑定。只有在补丁载入时、autopattr 对象再次被实例化时，或 autopattr 对象收到消息 autoname 1 时，才会进行命名。在 autopattr 对象实例化之后放入补丁的新对象，在上述任一条件满足之前都不会被自动命名。

autorestore [int]

autorestore 一词后面跟一个 1 或 0，用于启用或禁用 autopattr 对象的 autorestore 状态。默认值为 1（开启）。启用后，autopattr 对象会在补丁载入时自动送出它上次保存的值，并把它们分发给已绑定的对象。补丁每次保存时都会保存这些值。

dirty [int]

dirty 一词后面跟一个 1 或 0，用于启用或禁用补丁的 dirty 标志。默认值为 0（禁用）。启用后，只要自身状态发生变化，autopattr 对象就会把补丁标记为 dirty。

greedy [int]

greedy 一词后面跟一个 1 或 0，用于启用或禁用 autopattr 对象的特性收集功能。默认值为 0（禁用）。启用后，连接到 autopattr 对象左出口的对象，其所有内部特性都会暴露给 pattr 系统（若存在常规值，也会一并暴露）。

name [symbol]

name 一词后面跟一个符号，用于设置 autopattr 对象的补丁名称。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

bang 会原样通过 autopattr 对象，并从它的中间右出口送出。

int

一个 int 会原样通过 autopattr 对象，并从它的中间右出口送出。

参数：

  • input [int]

float

float 会原样通过 autopattr 对象，并从它的中间右出口送出。

参数：

  • input [float]

list

list 会原样通过 autopattr 对象，并从它的中间右出口送出。

参数：

  • input [list]

anything

任何 message 都会被分析。若 message 的第一个元素与 autopattr 维护的某个对象名称相符，则 message 中随后的参数会设置该对象的值。若 message 的第一个元素与 get (name) 相符，而 (name) 又与 autopattr 维护的某个对象名称相符，则把该对象的值从 autopattr 对象的右出口送出，并在前面加上该对象的名称。否则，message 会原样通过 autopattr 对象，并从它的中间右出口送出。

参数：

  • input/arguments [list]

getattributes

使 autopattr 对象维护的所有对象名称组成的列表从右出口送出，并在前面加上符号 attributes。

getstate

使一串列表从 autopattr 对象的右出口送出，autopattr 维护的每个对象对应一个列表。每个列表以对象名称开头，后面跟该对象的当前值。

输出

(internal)

左出口：连接到 autopattr 对象左出口的任何用户界面对象（或其他响应 autopattr 所用内部消息系统的对象），都会被自动命名（如有必要）并与之绑定。若 autopattr 对象的 greedy 特性已启用，与该绑定对象相关的所有特性也会暴露给 pattr 系统。名称由对象的类名自动生成（例如，连接一个 number box 时它可能被命名为 number[1]。）截至本文写作时，下列 Max 用户界面对象都可以按这种方式绑定：dial、function、gain~、ggate、gswitch、js、jsui（关于如何配合 JavaScript 使用 pattr 系统，参见 Max 手册中的 JavaScript 部分）、led、matrixctrl、multislider、number box（int 和 float）、pictctrl、pictslider、radiogroup、rslider、slider、table、textedit、toggle 和 umenu。

中间左出口：连接到 autopattr 对象中间左出口的任何用户界面对象（或其他响应 autopattr 所用内部消息系统的对象），都会被自动命名（如有必要），并从 autopattr 对象的已绑定对象列表中排除。

anything

中间右出口：任何 message，只要与 get 或 set 请求（这类请求发给 autopattr 维护的某个对象）不相符，都会原样通过中间右出口。

右出口：get 查询（查询 autopattr 维护的某个对象）会从右出口送出，该出口也叫 dumpout 出口。
