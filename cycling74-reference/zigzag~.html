zigzag~

链表函数编辑器

描述

用 zigzag~ 生成多段线性斜坡。该对象与 line~ 类似，但会在斜坡输出之后保留其信息，并允许修改该斜坡的列表取值。

讨论

zigzag~ 对象使用链表实现，而不是 line~ 对象基于栈的实现，后者在输出之后不会保留信息。除了简单地记住当前的 “线”，zigzag~ 对象还允许你通过插入、删除或追加点来修改列表。

zigzag~ 对象链表中每个元素都有一个取值（y）以及一个过渡时间取值（delta-x），后者指定从一个取值过渡到另一个取值所用的时间长度。当 zigzag~ 包含一个列表时，该列表可以被触发（起始点与结束点可以设置和改变）、以不同速度向前或向后遍历，以及循环。可以跳转到列表中的某个位置，也可以保持该位置。

参数

initial-value [int or float] 可选

设置 zigzag~ 对象的一个初始取值（y）。

特性

loopmode [int]

单词 loopmode 后面跟 1 会打开循环。loopmode 0 关闭循环。默认情况下循环是关闭的。loopmode 2 会以 “钟摆” 模式打开循环，此时取值与时间对会以向前和向后交替的方向遍历。默认情况下循环是关闭的
可选值：

0 = 'No Loop'（循环关闭）
1 = 'Forward'（向前循环打开）
2 = 'Palindrome'（回文循环）

maxpoints [int]

指定用于斜坡的用户自定义点的数量。默认值为 2048。

mode [int]

mode 指定 zigzag~ 对象响应消息与信号取值的方式。
mode 0（默认值）：当 zigzag~ 对象收到 bang 时，它会跳转到起点（若方向为负，则跳转到终点）并从那里开始输出取值。与该跳转关联的时间值，其长度由 bangdelta 消息定义。bangdelta 的默认值为 0。若该模式下有信号连接到 zigzag~ 对象的左入口，列表的当前索引就由该信号决定；此前设置的任何 speed、loopmode、start 和 end 消息都会被忽略。

mode 1：就 bang 的效果而言，行为与 mode 0 完全相同。在 mode 1 中，信号输入的处理方式不同。若在 mode 1 下有信号连接到 zigzag~ 对象的左入口，该输入信号就起触发信号的作用；当输入信号的斜率从非负变为负时，该对象就会被重新触发，就好像收到了一个 bang。

mode 2：跳转到列表中的下一个索引（若当前方向为负，则跳转到前一个索引）并从那里开始输出取值。与该跳转关联的时间值，其长度由 bangdelta 消息定义。bangdelta 的默认值为 0。若在 mode 2 下有信号连接到 zigzag~ 对象的左入口，该输入信号就起触发信号的作用；当输入信号的斜率从非负变为负时，该对象就会被重新触发，就好像收到了一个 bang。

消息

bang

左入口：zigzag~ 对象按其行为模式响应 bang 消息，该模式用 mode 消息设置。

若 zigzag~ 对象设为 mode 0 或 mode 1，bang 消息会让 zigzag~ 对象转到起点（若方向为负，则转到终点）并从那里开始输出取值。

若 zigzag~ 对象设为 mode 2，bang 消息会让 zigzag~ 对象跳转到列表中的下一个索引（若当前方向为负，则跳转到前一个索引）并从那里开始输出取值。

int

左入口：转换为 float。

右入口：指定取值与时间对将被输出的速率。取值为 1.0 时会以正常速度向前遍历列表。播放速率为 -1 时会向后（即反向）遍历列表。取值为 .5 时会以正常速度的一半遍历链表（实际上把延迟时间取值加倍）。

（左入口：转换为 float。）

参数：

  • output-rate-coefficient [int]

float

左入口：zigzag~ 对象链表中的每个元素都是一个对，由一个目标取值（y）和紧随其后的第二个数字组成，后者指定以毫秒计的总时长（delta-x）。在这段时间里，数字会从当前索引取值开始、按线性方式规律地输出到目标取值。列表 0 0 3.5 500 10 1000 描述一条线：在时刻 0 以取值 0 开始，半秒后升到取值 3.5，再过 1 秒又升到取值 10。

右入口：指定取值与时间对将被输出的速率。取值为 1.0 时会以正常速度向前遍历列表。播放速率为 -1 时会向后（即反向）遍历列表。取值为 .5 时会以正常速度的一半遍历链表（实际上把延迟时间取值加倍）。

参数：

  • output-rate-coefficient [number]

list

以（取值）（斜坡时间）对的形式设置并触发一个函数，用来定义斜坡上的各个点。发送 list 消息会立即触发该斜坡。

参数：

  • index and event-pair [list]

append

append 一词后跟一个列表时，会把新的（取值）（斜坡时间）对添加到当前列表末尾。发送 append 消息会立即触发一段仅由这些新点构成的斜坡。

参数：

  • value [number]
  • transition-time [number]

bangdelta

左入口：bangdelta 一词后跟一个 float 或 int，指定 zigzag~ 对象收到 bang 时各取值之间发生过渡所用的时间。默认值为 0（即，立即过渡）。

参数：

  • transition-time [number]

bound

左入口：bound 一词后跟两个数字，分别指定起始与结束索引（其中 0 是第一个元素），用来设置 zigzag~ 对象链表的起点与终点。

参数：

  • start-index [int]
  • end-index [int]

delete

左入口：delete 一词后跟一个 int，指定一个位置（其中 0 是第一个元素），会从列表中删除与该索引关联的取值与时间对。若想从列表中移除多个事件对，可以在 delete 消息后跟一个 list。消息 delete 0 会从列表中移除当前的第一个取值与时间对；第二个取值与时间对（即索引 1 处的取值与时间对）现在会成为列表中的第一个取值。

参数：

  • index [int/list]

dump

左入口：dump 一词会使一个由当前存储的所有取值与时间对组成的列表，以下列形式

index value delta-x

被送出到 zigzag~ 对象的第 3 个出口。

end

左入口：end 一词后跟一个 int，指定一个位置（其中 0 是第一个元素），用来设置 zigzag~ 对象被 bang 触发时停止输出的那个点。

参数：

  • end-index [int]

insert

左入口：insert 一词后跟一个 int（指定一个位置，其中 0 是第一个元素）和一个列表，会在指定索引之前插入新的事件对。消息 insert 0 5 500 会在链表中（索引 0 处）创建一个新的第一项，其取值为 5、时间为 500 毫秒。

参数：

  • index and event-pair [list]

jump

左入口：jump 一词后跟一个 int，指定一个位置（其中 0 是第一个元素），会跳到链表中该位置，并从该位置开始输出取值与时间对。可选用一个 int 指定过渡到下一个取值所用的时间，以毫秒计（默认值为 0）。

参数：

  • index and transition-time [list]

jumpend

左入口：jumpend 一词使 zigzag~ 对象立即向前跳到链表上的最后一个取值 (y)。

参数：

  • transition-time [number]

jumpstart

左入口：jumpstart 一词使 zigzag~ 对象立即跳到链表上的第一个取值 (y)，然后输出当前选中的列表或列表中选中的那部分。

参数：

  • transition-time [number]

line

line 一词后跟一个 line~ 格式的断点列表（由 function 对象输出），为 zigzag~ 定义一段斜坡。该列表应由交替出现的取值、时间对组成。

参数：

  • breakpoints [list]

next

左入口：next 一词跳到链表中的下一个取值与时间对。可选用一个 int 指定过渡到下一个取值所用的时间（默认值为 0）。

参数：

  • transition-time [number]

prev

左入口：prev 一词跳到链表中的上一个取值与时间对。可选用一个 int 指定过渡到上一个取值所用的时间（默认值为 0）。

参数：

  • transition-time [number]

print

左入口：print 一词会把 zigzag~ 对象的当前状态与内容打印到 Max Console 中。输出内容包括当前模式、loopmode、当前列表的起始、结束与循环长度、该对象的钟摆状态与移动取值，随后是链表中各个索引的清单，以及它们各自的 y 与 delta-x 取值。

ramptime

左入口：ramptime 一词后跟一个数字，设置输出信号到达目标取值所用的斜坡时间，以毫秒计。

参数：

  • transition-time [number]

set

在用户定义的取值与 ramptime 消息前加上 set 一词，就可以设置 zigzag~ 的斜坡而不触发播放。

参数：

  • index [int]
  • value [number]
  • transition-time [number]

setindex

左入口：setindex 一词后跟一个 int（指定一个位置，其中 0 是第一个元素）和一对浮点数，为列表中指定的位置设置目标取值 (y) 与过渡时间量 (delta-x)。

参数：

  • index [int]
  • value [number]
  • transition-time [number]

setline

setline 一词后跟一个 line~ 格式的断点列表（由 function 对象输出），为 zigzag~ 定义一段斜坡而不触发它。要触发该斜坡，需要向第一个入口发送一个 bang。该列表应由交替出现的取值、时间对组成。

参数：

  • breakpoints [list]

signal

左入口：zigzag~ 对象根据其行为模式响应信号取值，行为模式用 mode 消息设置。
若 zigzag~ 对象设为 mode 0，则列表的当前索引由输入信号取值决定；此前设置的任何 speed、loopmode、start 与 end 消息都会被忽略。
若把信号连接到 zigzag~ 对象的左入口并处于 mode 1，则输入信号充当触发信号；当输入信号的斜率由非负变为负时，该对象会像收到 bang 一样被重新触发。
若把信号连接到 zigzag~ 对象的左入口并处于 mode 2，则输入信号充当触发信号；当输入信号的斜率由非负变为负时，该对象会像收到 bang 一样被重新触发。

右入口：信号取值指定取值与时间对将被输出的速率。取值为 1.0 时会以正常速度向前遍历列表。播放速率为 -1 时会向后（即反向）遍历列表。信号取值为 .5 时会以正常速度的一半遍历链表（实际上把延迟时间取值加倍）。输入信号的取值每个输入向量采样一次。因此，任何周期大于当前采样率/(2*vector_size) 的周期性频率调制都会产生混叠。

skip

左入口：skip 一词后跟一个正数或负数，会跳过 zigzag~ 对象链表中指定数量的索引。正数向前跳，负数向后跳。可选用一个整数指定过渡到下一个或上一个取值所用的时间（默认值为 0）。

参数：

  • number-of-skipped-indices and transition-time [list]

speed

左入口：speed 一词后跟一个正数或负数的浮点数，指定取值与时间对将被输出的速率。消息 speed 1.0 会以正常速度向前遍历列表，speed -1 会向后遍历列表，speed .5 会以正常速度的一半遍历链表（实际上把延迟时间取值加倍）。

参数：

  • output-rate [number]

start

左入口：start 一词后跟一个 int，指定一个位置（其中 0 是第一个元素），用来设置 zigzag~ 对象被 bang 触发时开始输出的那个点。

参数：

  • start-index [number]

stop

发送 stop 消息会让斜坡停在当前位置。

输出

bang

右出口：循环时，到达循环（重新触发）点会送出一个 bang 消息。此外还会送出一个 bang，条件是 zigzag~ 已生成完其所有斜坡。

list

第 3 个出口：响应 dump 消息时，会输出一个列表，该列表由当前存储的所有取值与时间对组成，形式为

index value (y) delta-x

。

signal

第 1 个出口：当前的目标取值，或者一段按当前存储的取值与目标时间朝目标取值移动的斜坡。

第 2 个出口：当前的索引。
