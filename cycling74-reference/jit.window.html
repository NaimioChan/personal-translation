Jitter

jit.window

在窗口中显示数据

描述

使用 jit.window 对象把像素或图形绘制到窗口。jit.window 可以显示 jit.matrix 数据以及 OpenGL 3D 图形。

特性

border [int]

显示窗口边框

clamp [int]

钳位矩阵取值

depthbuffer [int]

启用深度缓冲

doublebuffer [int]

启用后缓冲

dstrect [4 ints]

矩阵目标矩形由坐标 left, top, bottom, right 给出。所有取值都相对于窗口的左上角。

floating [int]

启用浮动窗口样式

fsaa [int]

启用全场景抗锯齿

fullscreen [int]

启用全屏

grow [int]

启用窗口的鼠标尺寸调整区域。该标志置位时，可以通过在右下角点击并拖拽来调整窗口大小。

idlemouse [int]

启用后，会报告空闲鼠标事件（默认值 = 0）。禁用时，只有在鼠标按键按下时才报告鼠标事件。

interp [int]

启用矩阵插值

mousewheel [int]

启用鼠标滚轮消息

name [symbol]

窗口的名称。Jitter OpenGL 对象通过窗口的名称挂接到渲染上下文。

noaccel [int]

禁用 OpenGL 硬件加速

pickray [int]

启用拾取射线输出

planemap [4 ints]

把输入的各个通道映射到输出的各个通道（默认值 = 0 1 2 3 ...）

pos [2 ints]

窗口位置以像素为单位，由相对于屏幕左上角的全局坐标中的 x 与 y 偏移值指定。

rect [4 ints]

窗口矩形以像素为单位指定，给出窗口相对于左上角的左、上、右、下坐标。

size [2 ints]

窗口大小

srcrect [4 ints]

把输入矩阵复制到内部矩阵时所使用的输入矩阵部分。（默认值 = 0 0 (matrix width) (matrix height)）矩形范围以 left, top, bottom, right 的形式表示。所有取值都相对于输入矩阵查看区的左上角。

stereo [int]

启用立体声缓冲区

sync [int]

垂直同步标志，会让窗口的更新与显示器的刷新保持同步。

title [symbol]

窗口标题。若未设置标题，窗口的标题会被设为该窗口的 name。

usedstrect [int]

启用目标矩形

usesrcrect [int]

启用源矩形

visible [int]

启用窗口可见性

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

(mouse)

在对象框上双击会把窗口置于最前；当鼠标左键按下时，窗口上的鼠标事件会从转储出口送出，并在前面带上符号 mouse，若启用了 idlemouse 则为 mouseidle。

该事件是一个列表，包含鼠标光标的水平与垂直坐标，后面跟着若干代表按键状态与修饰键状态的标志。这些标志是：鼠标按键、command（mac）或 control（win）键、shift 键、capslock 键、option / alt 键、control 键（mac）、鼠标左键、鼠标右键和鼠标中键。

front

把窗口置于最前

sendtexture

向内部纹理发送消息

参数：

  • name [symbol]
  • message [symbol]
  • values [list]
