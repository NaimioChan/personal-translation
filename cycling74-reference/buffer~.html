MSP

buffer~

存储音频采样

描述

把 buffer~ 对象用作一块记忆缓冲区，其中的采样点可被保存、编辑或引用。

讨论

buffer~ 对象会与许多不同的对象配合使用，包括 play~ / groove~（播放缓冲区）、record~（把音频录制进缓冲区）、info~（报告缓冲区的信息）、peek~（像 table 对象那样向缓冲区写入或从缓冲区读取）、lookup~（把缓冲区用于波形整形）、cycle~（指定一个 512 点的波形）以及 wave~（指定一个波形）。

参数

name [symbol] 可选

第一个参数是一个名称，其他对象通过它来引用该 buffer~ 以访问其内容。

关于在 Max for Live 中使用具名对象的信息，请点击此处。

filename [symbol] 可选

在 buffer~ 对象的名称之后，你可以输入一个音频文件的名称，在创建 buffer~ 时载入该文件。

duration [number] ms 可选

在可选的 filename 参数之后，可以再给出一个以毫秒为单位的时长，用来设置 buffer~ 的大小，它会限制其中存储的声音总量。（不过，新时长可以作为 read 消息的一部分给出。）若没有输入时长，buffer~ 就没有采样记忆区。但它并不限制可读入的音频文件的大小。

channels [int] 可选

在时长之后，还可以再输入一个参数，用来指定要存储在 buffer~ 中的音频通道数。（这是为了告诉 buffer~ 最初要分配多少内存；不过，如果读入的音频文件通道数更多，buffer~ 会为多出的通道分配更多内存。）buffer~ 可以有任意数量的通道，仅受可用 RAM 容量的限制。默认情况下，buffer~ 只有一个通道。

特性

chans [int]

buffer~ 中的通道数。

dither [int] : 0

写入 PCM（整数）文件时启用三角形抖动。
可选值：

0 = 'Off'（写入 PCM 文件时不应用任何抖动）
1 = 'Dither'（写入 PCM 文件时应用三角形抖动（TPDF））
2 = 'Dither + Noise Shaping'（写入 PCM 文件时应用带噪声整形的三角形抖动（HP-TPDF））

file [symbol]

别名：audiofile

设置 buffer~ 对象中所用音频文件的名称。设置该特性时，会定位该文件，若找到，则按当前的大小或时长读入其内容。换句话说，设置 file 特性等同于发送 read 消息，而不是 replace 消息。

filetype [symbol]

buffer~ 对象所用的音频文件格式。默认的文件类型是 AIFF。
可选值：

'aiff'（Apple Interchange File Format（默认））
'wave'（WAVE）
'raw'（原始数据）
'au'（NeXT/Sun）

format [symbol]

磁盘上缓冲区的位深或采样类型

为了向后兼容，除了下面的符号名称之外，还可以用以下数值来设置 format：
8 - 8 位整数
16 - 16 位整数
24 - 24 位整数
32 - 32 位整数
可选值：

'int8'（8 位整数）
'int16'（16 位整数（默认））
'int24'（24 位整数）
'int32'（32 位整数）
'float32'（32 位浮点）
'float64'（64 位浮点）
'mulaw'（8 位 mu-law 编码）
'alaw'（8 位 a-law 编码）

quantization [int] : 0

写入 PCM（整数）文件时选择量化规则。
可选值：

0 = 'Round'（量化到整数取值时采用四舍五入。）
1 = 'Floor'（量化到整数取值时采用向下取整。）

samps [int]

buffer~ 的长度，以采样点数表示。

size [float]

buffer~ 的长度，以毫秒表示。

sr [float]

buffer~ 的采样率，单位为每秒采样点数（Hz）。默认情况下，采样率为当前的输出采样率，或最近载入的音频文件的采样率。

消息

bang

重绘 buffer~ 对象波形显示窗口的内容。双击 buffer~ 对象即可打开该显示窗口。

(remote)

buffer~ 的内容可以被 peek~ 和 record~ 对象改动，也可以被 2d.wave~、play~、wave~、groove~、buffir~、cycle~ 和 lookup~ 对象引用或播放。

(drag)

从 Max File Browser 把音频文件拖到 buffer~ 对象上时，该文件会被载入。

apply

apply 一词后面跟一个由一到三个符号或数字组成的列表，会对 buffer~ 的当前内容应用一个加窗函数。

apply 一词后面跟一个指定加窗函数的符号，会对 buffer~ 的当前内容应用该函数。支持的函数包括 triangle、hamming、hanning、blackman、welch 和 kaiser。再给出的第二个符号参数 half（例如 apply blackman half）会先计算该函数，然后只把后半部分应用到整个 buffer~。

注意：kaiser 函数需要第二个浮点参数来指定 beta 参数，该参数位于可选的 half 参数之前（例如 apply kaiser 4.5 half）。

apply 一词后面跟 gain 一词和一个指定增益值的浮点数，会用该增益系数缩放每个采样点。offset 加一个指定常数值的浮点数，该常数会被加到 buffer~ 中的每个采样点上。

apply 一词后面跟 getdeltas 一词，会把每个采样值替换成一个新值，表示它与前一个采样点的差值。

参数：

  • function-and-parameters [list]

clear

清除 buffer~ 的内容。

clearlow

像 clear 消息那样清除缓冲区的内容，但把清除作为低优先级任务来执行。

crop

crop 消息后面跟两个以毫秒指定起始与结束时间的数字，会裁剪缓冲区中的音频数据。它会把 buffer~ 调整为所选内容的长度。

参数：

  • start and end times (ms) [list]

crop_samples

crop 消息后面跟两个以采样点数指定起始与结束时间的数字，会裁剪缓冲区中的音频数据。它会把 buffer~ 调整为所选内容的长度。

参数：

  • start and end times (samples) [list]

(mouse)

双击 buffer~ 会打开一个显示窗口，你可以在其中查看 buffer~ 的内容。当用户用鼠标在 buffer~ 对象的编辑窗口中点击或拖动时，光标在 buffer~ 中的时间位置（以毫秒为单位）会从出口送出。

duplicate

duplicate 一词后面跟一个指定某个 buffer~ 名称的符号，会导入该具名缓冲区的内容。

参数：

  • buffer-name [symbol]

enumerate

在 Max Console 中张贴信息，列出所有引用了存于某个 buffer~ 对象中的相同数据的 buffer~ 对象，该对象收到了 enumerate 消息。（标注信息："(this one)"，会出现在 buffer~ 对象（收到 enumerate 消息的那个）的地址旁边）。

fill

fill 一词后面跟一个由一到三个符号或数字组成的列表，用来指定 buffer~ 对象的内容将如何填充。

fill 一词后面跟一个浮点数，会把 buffer~ 中的每个采样点都设为该值。

fill 一词后面跟一个指定函数的符号，会用该函数的一个周期填充 buffer~。支持的函数包括 sin（正弦）、cos（余弦）和 sinc。可选的第二个参数（例如 fill sin 2）可用来定义填充 buffer~ 时所用函数的周期数。还有一个可选的第三个参数，定义用来填充 buffer~ 的周期的有理数部分（例如 fill cos 1 4 会用余弦函数的四分之一个周期填充 buffer~）。

注意：sinc 函数需要两个 int 参数来指定零交叉的个数，还需要一个额外的标志，用来切换是否让函数从零开始（例如 fill sinc 4 1）。

参数：

  • constant/function [list]

import

import 一词后面跟一个文件名，若该文件存在于 Max 的搜索路径中，就会立即把它读入 buffer~，而不打开 Open Document 对话框。若不带文件名，import 会打开 Open Document 对话框，让你选择一个文件。导入的文件会保留原文件的采样率和字长，但循环点与标记不会被导入。文件名之后可以跟一个 float，表示文件中开始读取的起始时间（以毫秒为单位）。（文件的开头为 0。）

起始时间之后可以跟第二个参数——一个浮点值，用来指定要读入 buffer~ 的声音时长（以毫秒为单位）。该时长会覆盖对象采样记忆区的当前大小。若该时长用负值指定，buffer~ 会读入整个文件，并相应调整其采样记忆区的大小和文件中的通道数。
时长之后可以跟第三个参数，用来指定要读入的通道数。若没有指定通道数（也就是说，消息中只包含 offset 和 duration 信息），buffer~ 会读入音频文件头部所标明的通道数。
若只指定两个参数，buffer~ 会导入音频文件头部所标明的通道数。若指定三个参数，buffer~ 会导入第三个参数所指定的通道数。若第三个参数为 0，buffer~ 会导入音频文件头部所标明的通道数。

参数：

  • filename [list]

importreplace

单词 importresize 后面跟一个文件名时，如果该文件位于 Max 的搜索路径中，就会立即把它读入 buffer~，而不打开 Open Document 对话框。不指定文件名时，import 会弹出 Open Document 对话框让你选择文件。导入的文件保留原文件的采样率和字长，但循环点和标记不会被导入。importreplace 在功能上与 import 消息完全相同，只是导入时默认启用自动调整时长与通道数。除非另有指定，将用导入文件的时长和通道数来调整缓冲区内部采样记忆的大小。

参数：

  • filename [list]

name

单词 name 后面跟一个 symbol，会改变其他对象（如 cycle~、groove~、lookup~、peek~、play~、record~ 和 wave~）用来引用 buffer~ 的名称。此前以旧名引用该 buffer~ 的对象会失去与它的连接。每个 buffer~ 对象都应起一个唯一的名称；如果你给某个 buffer~ 对象起的名称已经属于另一个 buffer~，该名称将不再与最先拥有它的那个 buffer~ 相关联。

参数：

  • buffer-name [symbol]

normalize

单词 normalize 后面跟一个浮点数时，会对 buffer~ 对象中的采样值进行缩放，使最高峰值与该参数给出的值一致。这可能会放大或衰减音频，但无论哪种情况，每个值都会被缩放。

参数：

  • normalization_factor [list]

open

打开 buffer~ 的采样显示窗口；若该窗口已打开，则把它置于最前。

printmodtime

在 Max Console 中发布关于 buffer~ 上次修改时间（即被写入，或特性被修改）的信息。

read

读取 AIFF、Next/Sun 或 WAV 文件，存入 buffer~ 的采样记忆中。单词 read 后面跟一个文件名时，如果该文件位于 Max 的搜索路径中，就会立即把它读入 buffer~，而不打开 Open Document 对话框。不指定文件名时，read 会弹出 Open Document 对话框让你选择文件。导入的文件保留原文件的采样率和字长，但循环点和标记不会被导入。文件名后面可以跟一个浮点数，表示文件中开始读取的起始时间，单位为毫秒。（文件开头为 0。）
起始时间后面可以跟第二个参数——一个浮点值，指定要读入 buffer~ 的声音时长，单位为毫秒。该时长不会覆盖对象采样记忆的当前大小。它会清除当前 buffer~ 数据，然后在 buffer~ 的开头填入请求的数量。不过，如果时长由负值指定，buffer~ 会读入整个文件并调整其采样记忆的大小。
时长后面可以跟第三个整数参数，指定要读入的通道数。
如果只指定两个参数，buffer~ 只读入 buffer~ 当前拥有的通道数。如果音频文件的通道数多于 buffer~ 当前拥有的通道数，所有通道的音频将被相加。如果指定三个参数，buffer~ 会读取第三个参数指定的通道数。如果第三个参数为 0，buffer~ 会读入音频文件文件头中标示的通道数。

参数：

  • filename [list]

readagain

从最近加载的文件（由先前的 read 或 replace 消息指定）中读取声音数据。

参数：

  • filename [list]

readraw

把磁盘上任意文件的内容读入 buffer~ 对象，其中的数据被解读为音频。各参数决定 buffer~ 如何解读该文件中的数据。

可选参数有：

  • filename：要读入 buffer~ 的文件名或文件路径（默认值 = 打开文件对话框）
  • sample-rate：要读入数据的采样率（默认值 = 44100.）
  • channels：要读入数据的通道数（默认值 = 1）
  • format：要读取的格式；可选 int8、int16、int24、int32 或 float32（默认值 = float32）
  • byte-offset：文件中开始读取处的字节偏移量（默认值 = 0）
  • duration-in-frames：每通道要读取的采样点总数，取值为 0 时从 byte-offset 读到文件末尾（默认值 = 0）
  • little-endian-flag：读取采样点时使用大端（0）还是小端（0）字节序（默认值 = 0）

参数：

  • filename [symbol]
  • sample-rate [float]
  • channels [int]
  • format [symbol]
  • byte-offset [int]
  • duration-in-frames [int]
  • little-endian-flag [int]

replace

replace 消息等价于带负时长参数的 read 消息。

参数：

  • filename [list]

replacechannel

replacechannel 消息可用于在单个缓冲区中把一个通道的数据复制到另一个通道，也可用于把外部文件的数据复制到当前缓冲区中的某个通道（若指定了 src file 参数）。数据被复制到指定 dst channel 的开头，原有内容被清零。

可选参数指定源数据中的偏移量和时长（单位：毫秒）。一个可选标志决定缓冲区是调整为源数据的长度，还是保持不变。

参数：

  • dst channel [int]
  • src file [symbol]
  • src channel [int]
  • src offset (ms) [float]
  • src duration (ms) [float]
  • resize to src duration flag [int]

replacechannel_samples

replacechannel 消息可用于在单个缓冲区中把一个通道的数据复制到另一个通道，也可用于把外部文件的数据复制到当前缓冲区中的某个通道（若指定了 src file 参数）。数据被复制到指定 dst channel 的开头，原有内容被清零。

可选参数指定源数据中的偏移量和时长（单位：采样点）。一个可选标志决定缓冲区是调整为源数据的长度，还是保持不变。

参数：

  • dst channel [int]
  • src file [symbol]
  • src channel [int]
  • src offset (ms) [int]
  • src duration (ms) [int]
  • resize to src duration flag [int]

samptype

左入口：单词 samptype 后面跟一个符号，指定解读音频文件的采样数据时要使用的采样类型（从而覆盖音频文件实际的采样类型）。这有时称为 "header munging"。

支持以下类型的采样数据：

int8- 8 位整数
int16- 16 位整数
int24- 24 位整数
int32- 32 位整数
float32- 32 位浮点数
float64- 64 位浮点数
mulaw- 8 位 "mu"-law 编码
alaw- 8 位 a-law 编码

参数：

  • sample-type [symbol]

set

单词 set 后面跟一个 symbol，会改变其他对象（如 cycle~、groove~、lookup~、peek~、play~、record~ 和 wave~）用来引用 buffer~ 的名称。此前以旧名引用该 buffer~ 的对象会失去与它的连接。每个 buffer~ 对象都应起一个唯一的名称；如果你给某个 buffer~ 对象起的名称已经属于另一个 buffer~，该名称将不再与最先拥有它的那个 buffer~ 相关联。

参数：

  • buffer-name [symbol]

setsize >= 7.0.0

以毫秒为单位设置缓冲区采样记忆的长度。可选的第二个参数设置缓冲区中的通道数。这会限制可存储的数据量，除非该长度限制被 replace 消息或 read 消息中的时长参数覆盖。

参数：

  • buffer-size-in-milliseconds [float]
  • number-of-channels [int]

sizeinsamps

单词 sizeinsamps 后面跟一个以采样点为单位的时长，设置 buffer~ 对象采样记忆的大小。这会限制可存储的数据量，除非该长度限制被 replace 消息或 read 消息中的时长参数覆盖。

参数：

  • buffer-duration [int]
  • number-of-channels [int]

trim

trim 消息后面跟两个可选数字（以毫秒为单位指定首尾静音填充的时长），再跟一个可选数字指定要分析的通道（不提供通道：分析所有通道），会修剪缓冲区中的音频数据，去掉开头和末尾的静音。如果指定了填充，会在开头和/或末尾添加静音。buffer~ 将被调整为修剪后的音频长度，再加上任何填充。

参数：

  • start-pad-in-ms [float]
  • end-pad-in-ms [float]
  • reference-channel [int]

trim_samples

trim 消息后面跟两个可选数字（以采样点为单位指定首尾静音填充的时长），再跟一个可选数字指定要分析的通道（不提供通道：分析所有通道），会修剪缓冲区中的音频数据，去掉开头和末尾的静音。如果指定了填充，会在开头和/或末尾添加静音。buffer~ 将被调整为修剪后的音频长度，再加上任何填充。

参数：

  • start-pad-in-samples [int]
  • end-pad-in-samples [int]
  • reference-channel [int]

wclose

若 buffer~ 的采样显示窗口已打开，则关闭它。

write

把 buffer~ 的内容保存为音频文件。除非 write 后面跟一个符号，否则会打开标准文件对话框来给文件命名；若跟了一个符号，文件就以该符号作为文件名保存到当前默认文件夹中。除非你在标准 Save As 对话框中用 Format 弹出菜单改变格式，否则文件将按 filetype 特性指定的格式保存，或者按最近打开的那个音频文件的文件类型保存。默认情况下，buffer~ 以 AIFF 格式保存。

参数：

  • filename [symbol]

writeaiff

把 buffer~ 的内容保存为 AIFF 文件。除非 writeaiff 后面跟一个符号，否则会打开标准 Save As 对话框来给文件命名；若跟了一个符号，文件就以该符号作为文件名保存到当前默认文件夹中。

参数：

  • filename [symbol]

writeflac

把 buffer~ 的内容保存为 FLAC 文件。除非 writeflac 后面跟一个符号，否则会打开标准 Save As 对话框来给文件命名；若跟了一个符号，文件就以该符号作为文件名保存到当前默认文件夹中。

参数：

  • filename [symbol]

writeraw

把 buffer~ 的内容保存为不带文件头的原始文件。默认采样格式是 16 位，但输出采样格式可以用 samptype 消息设置。除非 writeraw 后面跟一个符号，否则会打开标准 Save As 对话框来给文件命名；若跟了一个符号，文件就以该符号作为文件名保存到当前默认文件夹中。

可选参数有：

  • filename：保存原始文件的文件名或文件路径（默认值 = 打开保存对话框）
  • format：要写入的格式；可选 int8、int16、int24、int32 或 float32（默认值 = float32）
  • duration-in-frames：每通道要写入的采样点总数（通道数由 buffer~ 对象的内容决定。取值为 0 时把整个缓冲区写入磁盘（默认值 = 0）
  • little-endian-flag：写入采样点时使用大端（0）还是小端（1）字节序（默认值 = 0）

参数：

  • filename [symbol]
  • format [symbol]
  • duration-in-frames [int]
  • little-endian-flag [int]

writewave

把 buffer~ 的内容保存为 WAV 文件。除非 writewave 后面跟一个符号，否则会打开标准 Save As 对话框来给文件命名；若跟了一个符号，文件就以该符号作为文件名保存到当前默认文件夹中。

参数：

  • filename [symbol]

输出

bang

右出口：文件读取或文件写入操作完成时，buffer~ 的右出口会送出一个 bang。

float

左出口：当用户在 buffer~ 对象的编辑窗口中用鼠标点击或拖动时，光标在 buffer~ 中的时间位置（以毫秒为单位）会从左出口送出。
