Max

translate

在不同时间格式之间转换

描述

translate 对象可把任意 Max 时间取值从固定或相对时间取值转换为其他任意固定或相对时间取值。

参数

input-format [symbol] 可选

第一个参数设置要预期的输入格式。这些参数是设置本对象相应特性的快捷方式，二者作用相同。时间可以用 Max 中使用的任意时间格式来指定。

output-format [symbol] 可选

第二个参数设置要输出的格式。这些参数是设置本对象相应特性的快捷方式，二者作用相同。时间可以用 Max 中使用的任意时间格式来指定。

特性

in [symbol] : bbu

设置要转换的输入的时间格式。
可选值：

'ticks'
'ms'
'bars.beats.units'
'samples'
'hz'
'notevalues'
'hh:mm:ss'

listen [int] : 1

启用 listen 后，当 transport 速度或拍号变化时，transport 会为最近一次输入输出新的取值。listen 默认启用。

listmode [int] : 0

启用 listmode 后，传入的列表会被当作一系列单个取值逐个转换，产生一个由转换后时间取值组成的列表。不过，只有当输入和输出时间格式都是单值时，才会进行列表转换。当 listmode 被禁用，或输入或输出时间格式是多值时，输入的列表会被当作描述单个时间值的多个元素来处理。

mode [symbol] : interval

设置时间取值的模式。translate 对象可以用相对于系统起始值 1.1.0 的 位置来输出时间取值，也可以用 区间来输出；在区间模式下，取值 1.1.0 表示一小节、一拍、零个单位（默认分辨率下 4/4 拍时为 2400 ticks）。
注意：视单位转换的类型而定，该特性可能不适用。
可选值：

'interval' （取值表示一个时间区间）
'position' （取值表示时间中的一个位置）

out [symbol] : ticks

设置用于输出的时间格式
可选值：

'ticks'
'ms'
'bars.beats.units'
'samples'
'hz'
'notevalues'
'hh:mm:ss'

transport [symbol]

用于速度信息的 transport 对象的名称。默认值是全局的 'internal' transport。

消息

bang

最后传入的时间会被转换为指定的输出类型。在适当的情况下，会通过检查 in 特性来重新评估最后传入时间的输入类型。

int

时间取值会从输入时间格式转换为输出时间格式，并从出口送出。

参数：

  • time [int]

float

时间取值会从输入时间格式转换为输出时间格式，并从出口送出。

参数：

  • time [float]

list

启用 listmode 且输入和输出时间格式都是单值时，列表项会被逐个转换，并产生一个对应的输出列表。例如，若输入格式是 ticks、输出格式是 ms，速度为 120 BPM，则输入列表 480 240 120 会产生输出 500 250 125。
当 listmode 被禁用，或输入或输出时间格式是多值时，输入的列表会被当作描述单个时间值的多个元素来处理。

参数：

  • time [list]

anything

时间取值会从输入时间格式转换为输出时间格式，并从出口送出。

参数：

  • time [list]
