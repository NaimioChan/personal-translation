jit.mo

jit.time.sin

使用指定模式输出 float 时间值，用于实时动画

描述

使用指定模式输出 float 时间值，用于实时动画。可用于生成与其他 jit.world 和 jit.mo 对象同步的控制函数、帧与帧之间的时间差，或累计运行时间。

参数

无。

特性

timevalue [float64] 只读

当前时间或函数值（只读）。

start [float64]

线性函数起点（默认值 = -1.0）。

offset [float64]

输出偏移（默认值 = 0.0）。

loop [long]

在制作动画时启用和禁用相位循环（默认值 = 1）。把相位设为 0 可以重置动画

phase [float64]

输出相位偏移（默认值 = 0.0）。把它设为 0 会重新开始一段动画

fixed_delta [float64]

用于计算时间输出的固定帧增量时间（默认值 = 0.0）。非零时，时间函数会用该值来计算输出，而不用距上次更新以来的增量时间。当需要以固定速率动画、而不受实际更新速率影响时，这会很有用。

freq [float64]

函数频率（默认值 = 1.0）。以 Hz 为单位

delta [float64]

为图形制作动画的帧间隔时间（默认值 = 0.0）。启用 automatic 时，该值由渲染上下文自动设置。

function [symbol]

mode = function 时使用的函数类型（默认值 = line）。Line 在 start 和 end 值之间生成线性插值，sin 输出正弦函数，saw 给出类似相位器的重复斜坡，perlin 使用 Perlin 噪声函数

period [long]

Perlin 噪声函数的周期长度（默认值 = 8）。

end [float64]

线性函数终点（默认值 = 1.0）。

scale [float64]

输出乘数（默认值 = 1.0）。

interval [time]

动画间隔（默认值 = 0 ms）。该特性使用 Max 时间格式语法，因此间隔可以是固定值，也可以与速度相关。设为非零值时，speed 特性不再可由用户设置，而会根据间隔值自动设置。

speed [float64]

动画速度倍率（默认值 = 1.0）。

loopreport [long]

启用动画循环报告（默认值 = 0）。启用后，动画循环时会从 dumpout 送出符号 loopnotify。

rand_amt [float64]

缩放随机偏移值（默认值 = 0.0）。

mode [symbol]

时间输出如何计算（默认值 = accum）。不同的模式有 accum、function 和 delta。Accum 提供累计运行时间。Function 使用指定的 function 特性生成周期函数，可用于生成与动画图形同步的 float LFO 和斜坡。Delta 给出帧与帧之间的时间量，适合驱动平滑的实时动画。

enable [long]

启用函数输出（默认值 = 1）。
