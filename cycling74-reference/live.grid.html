Max for Live

live.grid

一个由步组成、带有约束和方向的用户界面网格

描述

live.grid 是一个用户界面对象，设计用于配合 chucker~ 对象。它提供一个由步组成的显示网格、用于移调的约束，以及用于控制 chucker~ 对象的播放方向。

参数

无。

设置 live.grid 对象显示中的行数。未设置 matrixmode 特性时，行数最少为 2；已设置时最少为 1。

stepcolor [4 floats]

设置 live.grid 对象的步颜色，格式为 RGBA。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

int

设置、显示并输出当前步。从 live.grid 对象的左出口送出的列表形式为 step(s) direction (optional, depending on the visibility of the directions panel)。当 live.grid 对象处于矩阵模式且该列中没有选中任何取值时，会送出 0 作为步取值。

参数：

  • step-index [int]

list

当 direction 特性设为 0 时，由 2 个取值组成的列表设置步索引和取值。
当 direction 特性设为 1 时，由 3 个取值组成的 list 设置步索引、取值和方向。
当 matrixmode 特性设为 1 时，由 3 个取值组成的列表设置对象的行为：x、y 和 state (0/1)。可选的第四个取值可用于设置方向（-1/0/1）。

参数：

  • input-list [list]

clear

clear 消息只在 matrixmode 特性启用时使用，它会取消选中当前设置的所有行和列。

constraint

设置特定步的约束。例如，消息 constraint 3 0 0 1 1 把第三步的约束设为 0 0 1 1（列编号从 1 开始）。

参数：

  • constraint of the step [list]

directions

设置网格方向，用于指示某一步的播放方向：
-1：向后
0：停止
1：向前

参数：

  • directions [list]

down

把所有步的当前取值减一。新的步取值会从第二个出口送出。

注意：修改当前步取值时也会考虑当前的约束（如果有）；由此产生的移动可能会“舍入”到最接近的步。

freeze

把索引设为 0 可隐藏用于指示冻结取值的叠加层。任何大于零的索引都会设置并显示冻结的步。

参数：

  • step-index [int]

getcell

单词 cell 后面跟一对数字，用于指定某个单元格的 x 和 y 索引（该单元格位于 live.grid 显示中），会送出一个列表，该列表由单词 cell、一对指定 x 和 y 索引的数字，以及该单元格的取值组成（列编号从 1 开始）。

参数：

  • x-index [int]
  • y-index [int]

getcolumn

单词 getcolumn 后面跟一个指定 live.grid 显示中某一列的数字，会从第四个（dumpout）出口送出一个列表，该列表由单词 column、一个指定列索引的数字，以及当前列取值的列表组成（列编号从 1 开始）。

参数：

  • column [int]

getconstraint

单词 getconstraint 后面跟一个指定 live.grid 显示中某一列的数字，会送出一个列表，该列表由列号后跟一个列表组成，后者指示该列中每个单元格的约束状态，自下而上排列（列编号从 1 开始）。约束的表示方式如下：
0：约束
1：无约束

参数：

  • column [int]

getdirections

单词 getdirections 后面跟一个指定 live.grid 显示中某一列的数字，会从第四个（dumpout）出口送出一个列表，该列表由列号后跟方向组成（列编号从 1 开始）。方向的表示方式如下：
-1：向后
0：停止
1：向前

参数：

  • column [int]

getrow

单词 getrow 后面跟一个指定 live.grid 显示中某一行的数字，会从第四个（dumpout）出口送出一个列表，该列表由单词 row、一个指定行索引的数字，以及当前行取值的列表组成（行编号从 1 开始）。

参数：

  • row [int]

init

恢复并输出初始取值。

left

把所有步的取值向左轮换。新的步取值会从第二个出口送出。

注意：修改当前步取值时也会考虑当前的约束（如果有）；由此产生的移动可能会“舍入”到最接近的步。

linkdump

当 link 特性设为 1 时，linkdump 消息会把用于把一个 live.grid 对象同步到另一个 live.grid 对象所需的全部消息从对象的右出口送出。

random

单词 random 会生成新的步取值或步约束，取决于当前的 mode。可选的第二个参数可用于选择要随机化的用户界面对象某一部分：
steps：随机化步的取值
constraint：随机化约束，并确保步的取值相对于新的约束网格是正确的
directions：如果 direction 特性设为 1，则随机化方向。

参数：

  • type (optional) [list]

reset

单词 reset 会设置默认取值或清除约束，取决于当前的 mode。可选的第二个参数可用于选择要重置的用户界面对象某一部分：
steps：重置步的取值（注意：由于重置可能与当前的约束相互作用，某个步的取值可能不会被完全重置）
constraint：清除所有约束
directions：如果 direction 特性设为 1，则把所有方向设为 forward。

参数：

  • type (optional) [list]

right

把所有步进的取值向右轮换。新的步进取值从第二个出口送出。

注意：改变当前步进取值时，也会把当前的约束（若有）考虑在内；由此产生的偏移可能会被“取整”到最接近的步进。

set

设置并显示当前输出的步进，但不产生输出。

参数：

  • step-index [int]

setcell

单词 setcell 后面跟一对数字和一个数值，这对数字给出 x 与 y，即 live.grid 显示中某个单元格的索引（列编号从 1 开始），随后会设置该指定单元格的取值。

参数：

  • x-index [int]
  • y-index [int]
  • value [int]

steps

一次性设置所有步进的取值。取值编号从 1 开始。

参数：

  • step values [list]

up

增大（提高）所有步进的取值。新的步进取值从第二个出口送出。

注意：改变当前步进取值时，也会把当前的约束（若有）考虑在内；由此产生的偏移可能会被“取整”到最接近的步进。

输出

anything


第五个出口：用于查询 live.grid 对象的 dumpout 消息。
最右出口：当 link 特性设为 1 时，同步消息通过该出口送出。

list


最左出口：当前步进取值：y 取值、方向（可选，取决于方向面板是否可见）。
第二个出口：每当步进取值通过鼠标或消息发生变化时，这些取值都会从该出口送出。若 live.grid 对象处于 Matrix Mode，则所有“开启”点的步进取值/y 取值坐标都会从该出口送出。
第三个出口：每当方向取值通过鼠标或消息发生变化时，这些取值都会从该出口送出。请注意，当 direction 特性设为 0 时，该出口不输出任何内容。
第四个出口：鼠标悬停信息：x、y、方向（可选，取决于方向面板是否可见）。此外，用鼠标改动某个设置时，会送出消息 mousechange N，其中 N 表示改动类型（0 = steps, 1 = directions, 2 = constraints）。
