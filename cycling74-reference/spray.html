Max

spray

把一个取值分发到按编号的出口

描述

接受列表作为输入，其中第一个数字被当作出口编号，其后跟着的一个或多个取值按从右到左的顺序，从该出口及其右侧的各出口送出。参数设置出口数量（没有固定上限）。默认出口数量为 2。

参数

outlets [int] 可选

第一个参数设置出口数量。若没有参数，该对象有两个出口。

offset [int] 可选

第二个参数为出口的编号设置一个偏移。若没有第二个参数，出口编号从 0 开始。

listmode [int] 可选

第三个参数若设为 '1'，就把对象设为"列表模式"。在"列表模式"下，整个列表经所指示的出口输出（并应用第二个对象参数提供的可选偏移），而不是把列表拆包、把各个元素从顺序排列的出口送出。该参数默认为 '0'。

消息

int

在 Max Console 中张贴一条错误消息，指出 spray 需要一个列表。

参数：

  • input [int]

list

列表中的第一个数字用于指定出口编号，最左出口的编号从 0 开始；第二个是要从该出口送出的 int 或 float 取值。若列表中还有更多元素，就从列表中第一个数字所指定出口右侧的后续出口送出。列表只能包含 int 或 float；symbol 会被忽略。若第一个数字是 -1，列表中其余的元素会重复送到所有出口。

参数：

  • input [list]

offset

词语 offset 后面跟一个数字，会把对象的输出左移给定的出口数（负数表示右移的出口数）。

参数：

  • shift [int]

输出

int

当 spray 收到一个列表时，第一个数字用于指定一个出口，第二个 int 或 float 从该出口送出。列表中任何额外的数字都从右侧的后续出口送出。
