Max

trigger

把输入送往多个位置

描述

按从右到左的顺序输出收到的任何输入，并按所指定的对象参数进行格式化。

讨论

trigger 也可以用简单的名称 "t" 来实例化。

参数

formats [symbol] 可选

参数的数量决定出口的数量。每个出口送出 int、float、bang、list 或 symbol，由符号参数（i、f、b、l 或 s）指定。如果没有参数，则有两个出口，两者都送出 int。

constant [anything] 可选

当指定 int、float 或 symbol 时，该值作为常量输出。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'

'64'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

使每个出口送出 bang、整数 0、float 0.、列表 0 或空符号。

int

该数字会以输入的参数所指定的形式从每个出口送出：int、float、list、symbol（尽管是空的）或 bang。

参数：

  • input [int]

float

该数字会以输入的参数所指定的形式从每个出口送出：int、float、list、symbol（尽管是空的）或 bang。

参数：

  • input [float]

list

该列表会从任何分配了字母 l 的出口送出。在其他出口，该列表会被转换并作为整数 0、float 0.、空符号 "" 或 bang 送出。

参数：

  • input [list]

anything

任何内容都可以按指定的格式输出（与 list 相同，但被解释为 symbol）。

参数：

  • input [list]

输出

bang

入口收到的任何内容在从 b 出口送出之前都会被转换为 bang。

float

入口收到的数字会按从右到左的顺序从每个出口送出。该数字在送出之前会根据与每个出口对应的参数转换为 int、float、list、symbol 或 bang。入口收到的 symbol、list 或 bang 会被 i 出口转换为整数 0，被 f 参数转换为 float 0.。

int

入口收到的数字会按从右到左的顺序从每个出口送出。该数字在送出之前会根据与每个出口对应的参数转换为 int、float、list、symbol 或 bang。入口收到的 symbol、list 或 bang 会被 i 出口转换为整数 0，被 f 参数转换为 float 0.。

list

入口收到的列表会由 l 出口原样送出。其他任何内容在送出之前都会被转换为单项列表 0。

symbol

入口收到的符号会由 s 出口原样送出。其他任何内容在送出之前都会被转换为空符号 ""。注意：唯一能识别这个空符号的对象是 print，它会勇敢地在 Max Console 中打印这条空消息。其他对象要么忽略这个空符号，要么在 Max Console 中打印错误消息。
