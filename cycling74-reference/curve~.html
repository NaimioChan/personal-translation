MSP

curve~

指数斜坡发生器

描述

用 curve~ 对象生成一个在指定时间内从初始值变化到目标值的信号。它类似于 line~ 对象，用指数函数的分段近似产生非线性的斜坡。

讨论

此对象使用 Max 的 时间格式语法；包络时间既可以是单值的固定时间，也可以是相对于速度的时间。curve~ 对象用指数函数的分段近似产生非线性的斜坡。你在 curve~ 对象的右入口中指定这个指数函数的参数。取值从 0 到 1 时，数值上升过程中会产生“指数”曲线；取值从 -1 到 0 时会产生“对数”曲线。曲线参数越接近 0，曲线越接近直线；参数离 0 越远，曲线越陡峭。curve~ 还可以接受一个最多两三个参数的列表（若只有两个参数，则沿用上一个曲线参数），或一个含两组或更多“取值、时间、参数”三元组的列表。curve~ 在一个列表中最多只能有 42 个这样的三元组。向量越小时，对象对指数的近似越好，但对象的计算开销也越大。

当开启 Audio Interrupt 中的 Scheduler 时，curve~ 对象是采样点精确的。更多细节见此处。

参数

initial-value [number] 可选

第一个参数设置信号输出的初始值。该参数的默认值为 0。

curve-parameter [number] 可选

第二个参数设置初始曲线参数。曲线参数的默认值为 0。

特性

activeout [int] : 0

当 activeout 为 1 时，curve~ 有第二个信号出口，斜坡处于活动状态时输出 1，不活动时输出 0。这个信号可以连接到 thispoly~ 或 mc.noteallocator~ 这类复音声部分配对象，以便在斜坡线活动期间保持忙碌状态。activeout 只能作为键入型参数设置给 curve~。

maxpoints [int]

指定曲线中允许的用户自定义点的最大数量。默认为 129 个点。

shapemode [int] : 0

保持曲线形状

消息

int

左入口：该数字是目标值，将在中间入口的数字所指定的时间内到达该值。若自上一个目标值以来未指定过时间，则时间视为 0，输出信号立即跳变到目标值（int 会转换为 float）。

参数：

  • target-value [int]

float

左入口：该数字是目标值，将在中间入口的数字所指定的时间内到达该值。若自上一个目标值以来未指定过时间，则时间视为 0，输出信号立即跳变到目标值。

参数：

  • target-value [float]

list

左入口：第一个数字指定目标值；第二个数字指定到达该值所需的时间，单位为毫秒；可选的第三个数字指定曲线参数，其中取值 0 到 1 产生指数曲线，取值 -1 到 0 产生对数曲线。曲线参数越接近 0，曲线越像直线；参数离 0 越远，曲线越像阶跃。在指定的时间内，curve~ 会生成一个从当前存储值到目标值的指数斜坡信号。

中间入口：可以用一个列表按 Max 的某一种时间格式指定时间。

参数：

  • target-value [number]
  • ramp-time [float]
  • curve-parameter [float]

anything

左入口：第一个数字指定目标值；第二个数字指定到达该值所需的时间，单位为毫秒；可选的第三个数字指定曲线参数，其中取值 0 到 1 产生指数曲线，取值 -1 到 0 产生对数曲线。曲线参数越接近 0，曲线越像直线；参数离 0 越远，曲线越像阶跃。在指定的时间内，curve~ 会生成一个从当前存储值到目标值的指数斜坡信号。

中间入口：可以用一个列表按 Max 的某一种时间格式指定时间。

参数：

  • target-value [number]
  • ramp-time [float]
  • curve-parameter [float]

factor

单词 factor 后跟一个浮点数，会调整 curve~ 的非线性整形参数。

参数：

  • nonlinear-factor [float]

pause

左入口：暂停内部的指数斜坡，但不改变目标值，也不清除待处理的“目标-时间-参数”三元组。curve~ 会继续输出收到 pause 消息那一刻的当前值，直到收到 resume 消息，或直到输入新的斜坡。

resume

左入口：如果 curve~ 对象是因 pause 消息而暂停的，则恢复内部指数斜坡以及后续待处理的“目标-时间”对。

stop

左入口：停止内部的指数斜坡，并清除待处理的“目标-时间-参数”三元组。curve~ 会继续输出收到 stop 消息那一刻的当前值，并把目标值重置为该值。

输出

bang

右出口：当 curve~ 生成完所有斜坡后，会送出 bang。

signal

左出口：当前目标值，或一条按最近收到的目标值、过渡时间与曲线参数向目标值行进的指数曲线。

signal

中间出口：若启用了 activeout，curve~ 会多一个信号出口，对象的斜坡处于活动状态时输出 1。
