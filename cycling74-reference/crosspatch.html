Max

crosspatch

矩阵对象的连线编辑器

描述

把 crosspatch 连接到客户端对象（包括 matrix~、mcs.matrix~、mc.matrix~、matrix、gate~、mc.gate~、mcs.gate~、gate、selector、mc.selector~、mcs.selector~ 和 switch），即可用连线界面编辑输入与输出之间的连接。

讨论

当 crosspatch 连接到单个客户端对象时，它工作在双向模式下。在此模式下，crosspatch 可以改变客户端对象，并且对所连接对象的改动会反映在 crosspatch 的视觉状态上。在双向模式下，你无法改变 crosspatch 的输入或输出数量；它始终显示所连接对象的输入与输出数量。当 crosspatch 连接到两个或更多矩阵对象时，它工作在单向模式下。在此模式下，由 crosspatch 的界面所作的对矩阵对象的改动不会反映在视觉状态上，你可以自由改变输入与输出的数量。这意味着界面与它所控制对象的底层状态可能会失去同步。为避免这一点，请只把 crosspatch 用在双向模式下。
当你把 crosspatch 连接到一个 mc.matrix 对象（它是 MC Wrapper 中多个 matrix~ 的实例）时，其中包含的所有 matrix~ 实例的状态会一起改变。你无法用 crosspatch 编辑 matrix~ 对象中的单个实例，即一个 mc.matrix 内的那些。

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

bang 消息会把当前的连接状态复制到连接在左出口的各个对象。若存在与 crosspatch 连接协议不兼容的已连接对象，则把当前状态的字典从左出口送出。dump 消息把类似的字典从右出口送出。

list

一串数字用于增添或删除一个连接，并更新已连接的客户端。第一个数字是输入（始终以零为基准），第二个数字是输出（始终以零为基准），第三个数字是增益值。若增益值为零，则删除该连接，否则把该增益与连接关联起来。

参数：

  • input-index [int]
  • output-index [int]
  • gain-or-zero [float]

clear

clear 消息清除当前所有连接，并更新所有已连接的客户端。

dictionary

当 crosspatch 收到一个包含连接信息的字典时，它会清除现有的连接，并用字典中包含的连接替换这些连接，同时更新已连接的客户端。对于编号大于当前输入和输出数量的输入或输出，其连接会被忽略。

参数：

  • dictionary-name [symbol]

dump

dump 消息会从右出口送出一个包含当前连接的字典。

dumpconnections

dumpconnections 消息会从右出口送出一个包含当前连接的字典。

indisable

indisable 一词后面跟一个从 0 开始的输入索引；若第二个参数非零，就在视觉上禁用该输入；若第二个参数为 0，则启用它。例如：indisable 1 1 会禁用第二个输入，indisable 1 0 会重新启用它。当你禁用某个输入时，若未启用 allowdisabled，连到该输入的所有连接都会被移除。此外，除非启用了 allowdisabled，否则你无法把任何东西连到一个已禁用的输入上。输入的禁用状态不会保存在补丁中。

参数：

  • input-index [int]
  • disable [int]

(mouse)

要在输入和输出之间建立连接，请点击对象输入侧或输出侧上的白色圆圈，然后移动或拖拽到目标圆圈。鼠标移到目标上时，该目标会高亮。若是松开鼠标来开始连接，请再次点击以完成连接。若是拖拽鼠标，请松开按键。
要删除已有的连接，请在线条上点击一次以选中它，然后按 delete 或 backspace 键。
要编辑连线的增益，请点击该线条并向上或向下拖动。拖动时会出现一个旋钮指示当前的增益。
当你用 crosspatch 编辑连接时，任何已连接的矩阵对象都会随之更新，以反映增益或连接状态的变化。

outdisable

outdisable 一词后面跟一个从 0 开始的输出索引；若第二个参数非零，就在视觉上禁用该输入；若第二个参数为 0，则启用它。例如：outdisable 1 1 会禁用第二个输出，outdisable 1 0 会重新启用它。当你禁用某个输出时，若未启用 allowdisabled，连到该输出的所有连接都会被移除。此外，除非启用了 allowdisabled，否则你无法把任何东西连到一个已禁用的输出上。输出的禁用状态不会保存在补丁中。

参数：

  • output-index [int]
  • disable [int]
