Max

menubar

显示自定义菜单栏

描述

menubar 对象提供对菜单栏的控制。它允许你的补丁显示自己的菜单，并把菜单项添加到标准的 File 和 Edit 菜单中。当某个菜单项被选择时，会把该项编号从包含该项的菜单所对应的出口送出。

讨论

在已锁定的补丁中双击该对象会打开一个文本编辑窗口，在那里编写脚本即可配置 menubar。
当你关闭脚本窗口并确认保存改动后，脚本文件会被解释。如果没有错误，当 menubar 在入口收到非零数字时，定制的菜单栏就可以使用了。
每条消息前面都应有 #X，并以分号（;）结尾。
下面是一个 menubar 脚本示例：
#X about About Note Algorithms…;
#X closeitem;
#X menutitle 5 Algorithm;
#X item 5 1 Transpose;
#X item 5 2 Invert;
#X item 5 3 Randomize;
#X end;

注意，我们建议把菜单项中每个字母都大写，以与菜单中其他各项的风格保持一致。

参数

display and behavior [int] 可选

该参数设置对象菜单栏中菜单的数量。若给出该参数，它必须至少为 5（一个额外的菜单）。始终存在的四个默认菜单是 File、Edit、Windows. 和 Help。在 Macintosh 上，带 Apple 图标的 Standard System Menu 以及 Max 应用程序菜单会出现在其他菜单的左侧。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

设置对象框轮廓的颜色。

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

int

非零数字会显示 menubar 对象的菜单，0 则会恢复菜单栏先前的内容（Max 的菜单或另一个 menubar 对象的菜单）。

参数：

  • show-menus-flag (0 or non-zero) [int]

about

这是一条脚本消息（见上文），用于修改标准菜单，并且是脚本中要出现的第一项。它接受以下参数：
• 第一个菜单项的文字（即 About My Program…）。

在 Macintosh 上，About 项出现在应用程序菜单（Max 菜单）的第一项。在 Windows 上，它出现在 Help 菜单的第一项。为兼容较老版本的 Macintosh Max，可以选择使用 apple 消息。

参数：

  • text of first menu item [list]

append

append 消息会把一个菜单项添加到之前在 menubar 对象脚本中用 menutitle 消息定义过的菜单里。参数如下：
• 菜单编号
• 菜单项编号
• 菜单项文字
• 元字符（可选，详见 item 消息）

如果该对象的菜单当前正在显示，该项会立即在菜单中可用。如果当前没有显示，则等到下次显示菜单时该项会出现在指定的菜单中。回到常规的 Max 菜单之后，menubar 对象菜单中通过 append 消息添加的任何项都不会再次显示（除非你再发一条 append 消息），也不会保存在对象的脚本中。

参数：

  • menu number, item number, text [list]

appendpermanent

appendpermanent 消息会把一个菜单项添加到之前在 menubar 对象脚本中用 menutitle 消息定义过的菜单里。参数如下：
• 菜单编号
• 菜单项编号
• 菜单项文字
• 元字符（可选，详见 item 消息）

如果该对象的菜单当前正在显示，该项会立即在菜单中可用。如果当前没有显示，则等到下次显示菜单时该项会出现在指定的菜单中。在 menubar 对象的整个生命周期内都会显示的项会被添加到对象的脚本中。

参数：

  • menu number, item number, text [list]

apple

这是一条脚本消息（见上文），用于修改标准菜单；使用时它是脚本中要出现的第一项。它接受以下参数：
• 第一个菜单项的文字（即 About My Program…）。

在 Macintosh 上，About 项出现在应用程序菜单（Max 菜单）的第一项。在 Windows 上，它出现在 Help 菜单的第一项。为了与较老的 Macintosh 版 Max 兼容，可以选择使用这条消息。

参数：

  • text of first menu item [list]

checkitem

后面跟一个菜单编号、一个菜单项编号和一个 0 或 1 的代码，若代码为 1，checkitem 会在指定项前面加上勾选标记，否则会去掉该勾选标记。

参数：

  • checkitem [list]

closeitem

这是一条脚本消息（见上文），用于修改标准菜单。closeitem 消息接受一个可选的 0 或 1 参数。如果在脚本中输入了 "closeitem"、"closeitem 1"，或者完全不输入任何消息，File 菜单中就会出现 Close 项，用于关闭当前活动的窗口。如果在脚本中输入了 "closeitem 0"，File 菜单中的 Close 项会被禁用。

(mouse)

在已锁定的补丁中双击 menubar 对象会打开一个文本编辑窗口，你可以在其中插入脚本来配置 menubar 的外观和行为。

edit

这是一条脚本消息（见上文），用于修改标准菜单。它接受以下参数：
• 要输出的菜单项编号
• 要添加到 Edit 菜单的菜单项文字

edit 消息会把菜单项插入标准 Edit 菜单中 Clear 项之后、Overdrive 和 Resume 项之前（当 menubar 被激活时，后两项会移入 Edit 菜单）。一条空行把自定义插入的项与默认项分开。每一项都有一个与之关联的编号，当该项被选择时会从 menubar 的第三个出口送出。你添加的项在 Edit 菜单中出现的顺序由它们在脚本中的顺序决定，而不是由与每一项关联的（任意的）编号决定。

参数：

  • item number, text [list]

enableitem

后面跟一个菜单编号、一个菜单项编号和一个 0 或 1 的代码，若代码为 1，enableitem 会启用指定的项，否则会禁用（并灰显）该项。

参数：

  • menu-number, item-number, and enable/disable-flag (0 or 1) [list]

end

这是一条脚本消息（见上文），用于结束脚本定义。它会构建菜单并报告遇到的任何错误。

file

这是一条脚本消息（见上文），用于修改标准菜单。它接受以下参数：
• 要输出的菜单项编号
• 要添加到 File 菜单的菜单项文字

file 消息会把菜单项插入标准 File 菜单的顶部（在 Midi Setup... 菜单项之前）。每一项都有一个与之关联的编号，当该项被选择时会从出口送出。你添加的项在 File 菜单中出现的顺序由它们在脚本中的顺序决定，而不是由与每一项关联的（任意的）编号决定。

参数：

  • item number, text [list]

item

这是一条脚本消息（见上文），用于新建菜单和菜单项。它接受以下参数：
• 菜单编号
• 菜单项编号
• 菜单项文字
• 元字符（可选）

item 消息会把一个菜单项添加到之前用 menutitle 消息定义过的额外菜单中。你的菜单项在菜单中出现的顺序由它们在脚本中的顺序决定，而不是由与每一项关联的（任意的）编号决定。菜单项编号参数只指定当用户选择该菜单项时从 menubar 对象的出口送出的编号。最好把菜单项编号从 1 开始，并按照你希望它们在菜单中出现的顺序排列菜单项。
有两个字符可用来改变菜单项的外观：
/：后面跟一个字符，把该字符指定为 Command 键等效键
(：禁用该菜单项

这些特殊字符不能作为实际菜单项文字的一部分出现。例如，文字 On/Off 会显示为 Onff_O，而不是 On/Off。

参数：

  • menu number, item number, text [list]

markitem

这条消息已不再受支持。

参数：

  • menu-number, item-number, and ASCII-code [list]

menutitle

这是一条脚本消息（见上文），用于新建菜单和菜单项。它接受以下参数：
• 菜单编号（必须至少为 5，且不得超过 menubar 对象参数中指定的出口数量。
• 菜单名称

menutitle 消息会在 Window 菜单之前添加一个新菜单。第一个额外菜单的编号是 5。菜单编号既决定该额外菜单在菜单栏中的顺序，也决定用户选择其菜单项时所用的出口。menutitle 消息必须先于任何引用其菜单编号的 item 消息出现在脚本中。

参数：

  • item number, name of menu [list]

newitem

这是一条脚本消息（见上文），用于修改标准菜单。它接受以下参数：
• 要输出的菜单项编号。

后面跟一个非零数字的 newitem 消息会指示 Max 把指定的编号从 menubar 对象的 File 菜单出口送出——当用户从 File 菜单中选择 New 命令时——而不是打开一个新的补丁窗口。消息 newitem 0（或不发任何 newitem 消息）会让 New 命令按正常方式执行。

参数：

  • menu item number [int]

open

这是一条脚本消息（见上文），用于修改标准菜单。它接受以下参数：
• 要输出的菜单项编号。

后面跟一个非零数字的 open 消息会指示 Max 把指定的编号从 menubar 对象的 File 菜单出口送出——当用户从 File 菜单中选择 Open... 命令时——而不是显示 Open Document 对话框。消息 open 0（或不发任何 open 消息）会让 Open... 命令按正常方式执行。

参数：

  • menu item number [int]

saveas

这是一条脚本消息（见上文），用于修改标准菜单。它接受以下参数：
• 要输出的菜单项编号。

后面跟一个非零数字的 saveas 消息会指示 Max 把指定的编号从 menubar 对象的 File 菜单出口送出——当用户从 File 菜单中选择 Save 或 Save As... 时——而不是执行标准的 Save 操作。选择 Save 时从出口送出的编号会比选择 Save As... 时送出的编号小 1。消息 saveas 0（或不发任何 saveas 消息）会让 Save 和 Save As... 命令按正常方式执行。

参数：

  • menu item number [int]
