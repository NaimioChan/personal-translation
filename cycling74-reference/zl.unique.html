Max

zl.unique

以多种方式处理列表

描述

执行多种列表处理功能。用参数设定所执行的功能，并可用 mode 消息更改所执行的功能。zl 对象各入口和出口的行为随所选模式而变化。

参数

length [int] 可选

可选的整数参数为 zl 对象的所有操作模式设置最大列表长度。默认列表长度为 256，最大列表长度上限为 32,767。

mode [symbol] 可选

单词 change、compare、delace、ecils、group、indexmap、iter、join、lace、len、lookup、median、mth、nth、queue、reg、rev、rot、scramble、sect、slice、sort、stack、stream、sub、sum、swap、thin、union 或 unique 用作可选参数，以设定 zl 对象的模式。各种模式的说明见 mode 消息。

function-int [int] 可选

对下列操作模式，可以额外用一个数字作为参数来指定该模式的功能：

ecils：指定从输入列表末尾开始、要送出的列表项数量，这些项从 zl 对象的右出口送出。

group：指定要输出的、最近存储的列表项数量。

iter：zl 对象当前存储的内容会以一系列列表的形式输出，每个列表包含由该值指定的项数。

mth：指定输入列表中某个元素的位置（以 0 作为列表第一个元素的索引），并输出列表中的该元素。

nth：用数值形式指定输入列表中某个元素的位置（即 1 表示列表第一个元素的索引），并输出列表中的该元素。

rot：指定当前存储的列表要旋转的位置数。正值向右旋转列表，负值向左旋转。

slice：指定要送出的列表项数量，这些项从 zl 对象的左出口送出。

stream：指定输出列表的长度。对象会收集通过左入口输入的这么多项。列表长度凑齐后，列表从左出口输出。右出口会输出 1 或 0，取决于列表长度是否已设定。1 表示列表长度已设定，且对象正在收集流。

function-list [list] 可选

对下列操作模式，可以额外用一个列表作为参数来指定该模式的功能：

filter：该对象接受用一个列表作为参数。左入口收到列表时，对象会立即输出一个输入列表的版本，其中不包含参数列表中指定的元素。对象还会输出一个列表，列出所有被滤除的列表项的索引。右入口收到列表时只会设定要滤除的项，而不产生输出。

lookup：该对象接受用一个列表作为参数。右入口收到数字时，对象会输出由左入口收到的数字所指定的列表索引处的元素。（若右入口收到 6.2 3 5.6 5.3 3.8 2.4，则左入口收到 2 时对象会从左侧输出送出 5.6）。

reg：在此模式下，对象的作用是保存一个列表的寄存器。对象接受用一个列表作为参数，以设定对象的初始存储内容。

特性

fuzzy [atom] : 0.

zlmaxsize [atom_long]

为 zl 对象的所有操作模式设置最大列表长度。这等价于给对象使用参数，但允许动态更改列表长度。默认列表长度为 256，最大列表长度上限为 32,767。

消息

bang

左入口：bang 消息会输出最近计算出的列表或值。zl 对象的许多模式通过其右入口接收输入，这时只会设定输入而不触发输出。在这些情况下，随后在左入口收到 bang 会触发输出。

int

右入口：zl 的某些模式接受右入口的 int 输入，其行为如下：

ecils：指定从输入列表末尾开始、要送出的列表项数量，这些项从 zl 对象的右出口送出。超出该入口所指定数量的其余列表元素从对象的左出口送出。

group：指定要输出的、最近存储的列表项数量。

iter：zl 对象当前存储的内容会以一系列列表的形式输出，每个列表包含由该值指定的项数。最终输出的列表可能短于该数量，取决于对象存储的内容。

mth：指定输入列表中某个元素的位置（以 0 作为列表第一个元素的索引），并输出列表中的该元素。

nth：用数值形式指定输入列表中某个元素的位置（即 1 表示列表第一个元素的索引），并输出列表中的该元素。

rot：指定当前存储的列表要旋转的位置数。正值向右旋转列表，负值向左旋转。

slice：指定要送出的列表项数量，这些项从 zl 对象的左出口送出。超出该入口所指定数量的其余列表元素从对象的右出口送出。

sort：指定排序顺序。sort -1 按降序对输入列表排序，而带任何其他值的 sort 消息按升序对输入列表排序。

stream：指定输出列表长度。

mode

单词 mode 后跟下列符号之一：change、compare、delace、ecils、group、iter、indexmap、join、lace、len、lookup、median、mth、nth、queue、reg、rev、rot、scramble、sect、slice、sort、stack、stream、sub、sum、swap、thin、union 或 unique，用于设定 zl 对象的当前模式。各模式如下：

change：在两个入口都接受列表。左入口收到列表会触发输出，而右入口收到列表只会设定输入而不产生输出。只有当输入列表与上一次收到的列表不同时，对象才输出该输入列表。若不同，则新列表连同右出口的 1 一起从左出口送出。若列表没有变化，则左出口不送出任何内容，同时右出口送出 0。

compare：在两个入口都接受列表。左入口收到列表会触发输出，而右入口收到列表只会设定输入而不产生输出。若两个入口的列表相同，则从左出口送出 1。若两个列表不同，则从左出口送出 0，并从右出口送出一个列表，列出两个列表中不同元素的索引。

delace：在左入口接受列表，并从两个出口各送出一个列表，它由输入列表中每隔一个的元素组成（若输入列表为 6.2 3 5.6 5.3 3.8 2.4，则左侧输出列表为 6.2 5.6 3.8，右侧输出列表为 3 5.3 2.4）。

ecils：用于把一个列表分成两个列表。此模式额外接受一个数字参数，用于指定列表的大小（以元素个数计）。该值也可以在此模式下作为右入口的输入来指定。左入口收到的列表会被拆成两个列表 —— 第一个列表包含由参数指定的项数，从列表末尾开始向第一个列表元素方向反向计数，并从右出口送出。其余列表元素从对象的左出口送出。注意：列表先从右出口送出。

group：额外接受一个数字参数，用于指定列表的大小（以元素个数计）。左入口收到的列表会被存储起来，并把列表长度与右入口收到的数字或 zl 对象的参数进行比较。若列表项比右入口或参数指定的数字长，则从左出口送出一个长度等于该数字的列表。其余符号或列表元素会被存储。

indexmap：该对象接受用一个列表作为参数。右入口收到的一组数字（从 0 开始）指示用于生成新列表的列表元素索引。例如，若右入口收到 0 0 0 1 3 5，则左入口收到 A B C D E F G H 时，对象会从左侧输出送出 A A A B D F）。小于 0 或大于/等于传入列表元素个数的索引会被钳制到 0 和（元素个数 - 1）。

iter：额外接受一个数字参数，用于指定列表的大小（以元素个数计）。左入口收到的一个符号列表会被存储起来，并以一系列列表的形式从左出口送出，每个列表包含由参数或右入口收到的数字指定的项数。最终输出的列表可能短于指定的项数，取决于 zl 对象存储的内容。

join：在两个入口都接受列表，并从左出口送出一个列表，它是两个输入列表的组合。

lace：在两个入口都接受列表，并从左出口送出一个列表，其中两个输入列表的项互相交错（若左侧输入列表为 6.2 5.6 3.8，右侧输入列表为 3 5.3 2.4，则输出列表为 6.2 3 5.6 5.3 3.8 2.4）。

len：在左入口接受列表，并从左出口输出列表中的元素个数。

lookup：在右入口接受列表。收到该列表之后，左入口收到的数字会使对象输出由该数字指定的列表索引处的元素。（若右入口收到 6.2 3 5.6 5.3 3.8 2.4，则左入口收到 2 时对象会从左侧输出送出 5.6）。

median：接受一个数字列表，并输出这些数字的中位数。

mth：作用与 mode nth 模式完全相同，只是列表索引编号从 0 开始，而不是从 1 开始。

nth：在左入口接受列表，并从左出口输出列表的第 n 个元素。

queue：作用为先进先出（FIFO）栈；它输出最早收到的消息。

reg：作用为保存一个列表的寄存器。左入口收到的列表会立即从左出口送出。右入口收到的列表会被存储。一个 bang 会把存储的列表从左出口送出。

rev：在其左入口接受列表，并把该列表以相反顺序从左出口送出。

rot：用于旋转列表的内容。额外用一个参数指定列表项要旋转的位置数 —— 正数向右旋转列表，负数向左旋转。该值也可以在此模式下作为右入口的输入来指定。

scramble：在任一入口接受列表。左入口收到列表会使对象立即输出该输入列表的打乱版本（一个包含与输入列表相同元素但顺序随机的列表）。右入口收到列表会设定输入列表而不产生输出（随后在左入口收到 bang 会使右侧输入列表的随机版本从对象的左出口送出）。
sect：在两个入口都接受列表，并从左出口送出一个列表，包含两个列表共有的元素。

slice：用于把一个列表分成两个列表。此模式额外接受一个数字参数，用于指定列表的大小（以元素个数计）。该值也可以在此模式下作为右入口的输入来指定。左入口收到的列表会被拆成两个列表 —— 第一个列表包含由参数指定的项数，并从左出口送出。其余列表元素从对象的右出口送出。注意：列表先从右出口送出。

sort：用于对列表的内容排序。额外用一个参数指定排序顺序。sort -1 按降序对输入列表排序，而带任何其他值的 sort 消息按升序对输入列表排序。该值也可以在此模式下作为右入口的输入来指定。

stream：在右入口接受一个数字，用于指定输出列表的长度。收到该数字后，对象会收集通过左入口输入的这么多项。列表长度凑齐后，列表从左出口输出。右出口会输出 1 或 0，取决于列表长度是否已设定。1 表示列表长度已设定，且对象正在收集流。

sub：在两个入口都接受列表，并从左出口送出左侧列表中每次出现右侧列表的输出位置。

stack：作用为后进先出（LIFO）栈；它输出最近收到的消息。

stream：会输出列表中的最后 N 项，其中 N 可由用户指定。

sum：接受一个数字列表，并输出这些数字的总和。

swap：该对象接受用一个列表作为参数。右入口收到的一对数字（从 0 开始）指示要在左入口收到的列表中交换的一对索引。例如，若右入口收到 1 3，则左入口收到 A B C D 时，对象会从左侧输出送出 A D C B。多对数字可用于执行多次连续的交换操作。

thin：在左入口接受列表，并送出一个列表，包含输入列表中所有不重复的元素。

union：在两个入口都接受列表，并从左出口送出一个列表，包含两个输入列表的内容。若左侧和右入口含有任何共同的项，则只输出一个符号。

unique：在两个入口都接受列表，并从左出口送出一个列表，其中是左侧输入列表中未出现在右侧输入列表中的那些项。

参数：

  • mode [symbol]
  • setting [int]

zlclear

重新初始化 zl 对象。

zlreset

重新初始化 zl 对象。zlreset 的作用与 zlclear 略有不同，它不会把 ecils、iter、mth、nth、rot、slice 和 sort 的模式参数清零。group 的模式参数不会被 zlclear 或 zlreset 重置。

输出

list

左出口：


在 change 模式下，仅当输入列表与上一次收到的列表不同时才送出该输入列表。若不同，则新列表从左出口送出。若列表没有变化，则左出口不送出任何内容。

在 delace 模式下，送出一个列表，它由输入列表中从第一个元素开始的每隔一个元素组成（若输入列表为 6.2 3 5.6 5.3 3.8 2.4，则左侧输出列表为 6.2 5.6 3.8）。

在 ecils 模式下，送出一个列表，包含由数字参数指定的元素个数，从列表末尾开始向开头计数。

在 filter 模式下，送出一个列表，其中的元素已把与过滤列表匹配的元素移除。

在 group 模式下，送出一个列表，包含由数字参数指定的元素个数。

在 indexmap 模式下，根据左入口输入的列表取值，从指定的索引组成一个新列表。

在 iter 模式下，送出若干个列表，每个列表包含由数字参数指定的元素个数。最终输出的列表可能短于指定的项数，取决于 zl 对象存储的内容

在 join 模式下，送出一个列表，包含两个入口收到的列表的所有元素。

在 lace 模式下，送出一个列表，其中两个输入列表的项互相交错（若左侧输入列表为 6.2 5.6 3.8，右侧输入列表为 3 5.3 2.4，则输出列表为 6.2 3 5.6 5.3 3.8 2.4）。

在 len 模式下，送出一个与列表项数对应的数字。

在 lookup 模式下，送出由左入口收到的数字所指定的列表索引处的列表元素。（若右入口收到 6.2 3 5.6 5.3 3.8 2.4，则左入口收到 2 时对象会从左侧输出送出 5.6）。

在 median 模式下，送出输入列表的中位数。

在 mth 模式下，送出列表的第 m 个元素（其中 0 是列表第一个元素的索引）。

在 nth 模式下，送出列表的第 n 个元素。

在 queue 模式下，送出最早收到的元素。

在 reg 模式下，送出输入，或右入口最近存储的输入值。

在 rev 模式下，送出以相反顺序排列的输入列表。

在 rotate 模式下，送出按数字参数指定的正值或负值向右或向左旋转后的输入列表。

在 scramble 模式下，送出输入列表的打乱版本（一个包含与输入列表相同元素但顺序随机的列表）。

在 sect 模式下，送出一个列表，包含两个入口收到的列表共有的所有元素。

在 slice 模式下，送出一个列表，包含由数字参数指定的元素个数。

在 stack 模式下，送出最近收到的消息。

在 stream 模式下，送出由要收集的元素重复指定次数所组成的流或列表。

在 sum 模式下，送出输入列表的总和。

在 swap 模式下，送出一个把指定元素互换后的列表。

在 thin 模式下，送出一个列表，包含输入列表中所有不重复的元素。

在 union 模式下，送出一个列表，包含两个列表的项，但不重复两个列表共有的项。若左侧和右入口含有任何共同的项，则只输出一个符号。

在 unique 模式下，送出一个列表，其中是左侧输入列表中未出现在右侧输入列表中的那些项。

list



右出口：

在 change 模式下，若输入列表与上一次收到的列表不同，则从右出口送出 1。若列表没有变化，则左出口不送出任何内容，同时右出口送出 0。

在 delace 模式下，送出一个列表，它由输入列表中从第二个元素开始的每隔一个元素组成（若输入列表为 6.2 3 5.6 5.3 3.8 2.4，则右侧输出列表为 3 5.3 2.4）。

在 ecils 模式下，送出一个列表，包含由数字参数指定的元素之前的所有列表元素。

在 filter 模式下，送出一个列表，列出未被滤除的列表元素的索引编号。

在 mth 模式下，送出一个列表，包含除数字参数指定的列表元素之外的所有列表元素（其中 0 是列表中第一个元素的索引）。

在 nth 模式下，送出一个列表，包含除数字参数指定的列表元素之外的所有列表元素（其中 1 是列表中第一个元素的索引）。

在 slice 模式下，送出一个列表，包含由数字参数指定的元素之后的所有列表元素。

在 sect 模式下，若两个输入列表没有共同的元素，则从右出口送出一个 bang。

在 sub 模式下，左侧输入列表中由数字参数指定的列表元素数量从对象的右出口送出。若使用可选的第二个参数来指定一个值，用以替换由输入值指定的数字，则得到的列表从 zl 对象的右出口送出。

在 stream 模式下，右出口会输出 1 或 0，取决于列表长度是否已设定。1 表示列表长度已设定，且对象正在收集流。

在 change 模式下，若输入列表与上一次收到的列表不同，则新列表连同右出口的 1 一起从左出口送出。若列表没有变化，则左出口不送出任何内容，同时右出口送出 0。
