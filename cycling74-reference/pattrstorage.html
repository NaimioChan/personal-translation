Max

pattrstorage

保存和调取 pattr 预设

描述

查看和修改客户端对象的数据，并存储或调取预设。

讨论

通过 pattrstorage 对象，你可以获取/设置任何 pattrstorage 或 autopattr 数据（类似 pattrhub，不过你可以与任何对 pattr 或 autopattr 暴露的对象通信，而不限于同一补丁中的对象）。数据可以作为两个已存储取值之间的插值取值来调取。

参数

name [symbol] 可选

可以选择用一个符号参数来设置 pattrstorage 对象的脚本名。不给参数时，pattrstorage 对象会被赋予一个随意、半随机的名称，例如 u197000004。

特性

activewritemode [int] : 0

设置客户端对象的 active 属性的写入模式。默认值为 0（禁用）。启用后，客户端对象的活动状态会随 XML 预设数据文件一起保存，并在该文件被重新读取时恢复。

annotation_name [symbol] :

信息视图标题

autopattr_vis [int] : 0

设置 autopattr 对象在 clientwindow 和 storagewindow 显示中的可见性。默认值为 0（禁用）。由于 autopattr 对象不用于构成路径名，就显示而言一般可以忽略它们。在执行 pattrstorage 对象的功能（例如为一整组对象设置 active 状态或 priority，而这组对象由单个 autopattr 对象暴露）时，用户需要知道这些对象实际所属容器对象的名称。启用 autopattr_vis 可以让这一过程在视觉上和概念上更清晰一些。

autorestore [int] : 1

启用或禁用 pattrstorage 对象的 autorestore 状态。默认值为 1（开启）。启用后，补丁载入时 pattrstorage 对象会自动尝试定位并读取表示预设数据的 XML 文件。pattrstorage 对象会尝试载入最后保存的文件。若该 pattrstorage 对象从未保存过文件，它会尝试载入名为 (name).xml 的文件，其中 (name) 是该 pattrstorage 对象的补丁名（通常是它的参数）。

autowatch [int] : 0

设置 pattrstorage 对象的文件监视行为。默认值为 0（禁用）。启用文件监视后，最近读取或写入的 XML 数据文件一旦被修改就会自动重新载入。这让你可以为 XML 数据文件使用外部编辑器。你保存文件时，pattrstorage 对象会察觉到。注意，文件被重新读取时，当前所有未保存的数据都会丢失。

backupmode [int] : 0

设置写入文件时 pattrstorage 对象要维护和轮换的备份 XML 文件数量。默认值为 0（禁用）。该参数指定在文件开始轮换（即被自动删除以给新的备份腾出空间）之前，pattrstorage 对象应制作多少个备份。最新的备份名为 pstoname.bak.xml。其次是 pstoname_1.bak.xml，接着是 pstoname_2.bak.xml，以此类推。

changemode [int] : 0

设置 pattrstorage 对象的数据过滤行为。默认值为 0（禁用）。启用后，只把发生变化的取值从 pattrstorage 对象发给客户端对象，重复的数据会被过滤掉。

client_rect [4 floats] : 100. 100. 500. 600.

为客户端列表窗口设置新的大小和位置。窗口位置用 4 个数字（left、top、right、bottom）以全局坐标指定。

dirty [int] : 0

启用或禁用补丁 dirty 标志。默认值为 0（禁用）。启用后，pattrstorage 对象的状态一旦发生变化，就会把该补丁标为 dirty。

fileusagemode [int] : 0

启用或禁用把 JSON/XML 存储文件包含进集合体与独立应用程序的能力。默认值为 0（包含存储文件）。

flat [int] : 0

启用或禁用 pattrstorage 对象的客户端列表显示标志。默认值为 0（禁用）。启用后，pattrstorage 对象的 2 个窗口不会显示客户端的分层视图，而只显示含数据的对象（不含补丁），以及它们的完整路径名或别名。

greedy [int] : 0

设置 pattrstorage 对象的客户端搜索行为标志。greedy 特性提供了一种限制单个 pattrstorage 对象所管理数据量的方法。可用值如下：

0 = 禁用（默认值）。pattrstorage 对象能看到所有 pattr 对象，或绑定到 autopattr 对象的对象，它们位于该 pattrstorage 对象的任意子补丁中（也包括那些子补丁的子补丁，即沿补丁层级向下穿透），直到发现另一个 pattrstorage 对象为止。虽然子补丁中发现的 pattrstorage 对象会成为父 pattrstorage 对象的客户端，但该层级以及补丁层级中更下方的其他对象都不会成为客户端。

1 = 观察所有内容。当 greedy 特性设为 1 时，pattrstorage 对象能看到所有内容，一直深入补丁层级的底部（包括沿途发现的所有 pattrstorage 对象）。

2 = 仅客户端。当 greedy 特性设为 2 时，pattrstorage 对象只能看到其所在补丁中的潜在客户端对象。不会搜索其他补丁。
可选值：

0 = 'Off'
1 = 'Everything'
2 = 'Clients Only'

notifymode [int] : 0

设置 pattrstorage 对象的添加/移除通知行为。默认值为 0（禁用）。启用后，只要有对象被加入或移出它的客户端列表，pattrstorage 对象就会从它的出口发出一条消息，形式为 [add/remove] [object pathname]。注意，为响应某些事件，pattrstorage 对象偶尔必须清空并完整重建它的客户端列表；当 notifymode 已启用且对象被频繁添加和移除时，这会产生大量输出。

outputmode [int] : 0

设置 pattrstorage 对象的自动输出行为。默认值为 0（禁用）。启用后，只要有值被送往它的某个客户端对象，pattrstorage 对象就会从它的出口发出一条消息，形式为 [object pathname] [data ...]。可用模式如下：

0 = 禁用
1 = 输出送往客户端对象的所有值
2 = 只输出送往客户端对象的发生变化的值（见 changemode）
3 = 输出送往客户端对象的所有值，这些值不是由发往 pattrstorage 对象的消息引发的
4 = 只输出送往客户端对象的发生变化的值，这些值不是由发往 pattrstorage 对象的消息引发的（见 changemode）
5 = 输出送往客户端对象的所有值，这些值不是由发往任何 pattr 系统对象（pattr、pattrhub、pattrforward、pattrstorage）的消息引发的。
6 = 只输出送往客户端对象的发生变化的值，这些值不是由发往任何 pattr 系统对象的消息引发的（见 changemode）
可选值：

0 = 'Off'
1 = 'Output all values'
2 = 'Output changed values'
3 = 'Output all values (external)'
4 = 'Output changed values (external)'
5 = 'Output all values (non-pattr)'
6 = 'Output changed values (non-pattr)'

parameter_enable [int]

启用本对象在 Max 中配合 Max for Live Parameters 以及 设置初始参数值 使用。

savemode [int] : 1

设置 pattrstorage 对象的保存行为。默认值为 1（对象被释放时提示）。在此模式下，若对象被释放时 pattrstorage 对象的预设数据已经发生变化（自上次文件 read 或 write 操作以来，预设曾被存储、删除或修改），对象会提示用户写出预设文件。在模式 2 下，每当补丁被保存时，pattrstorage 都会尝试自动保存预设文件（无需用户交互）。在模式 0 下，pattrstorage 既不提示也不自动保存。在模式 3 下，每当补丁被释放时，pattrstorage 都会尝试自动保存预设文件（无需用户交互）。

可用值如下：

0 = 既不提示也不自动保存
1 = 对象被释放时提示用户保存预设文件（默认值）
2 = 每当补丁被保存时尝试自动保存，若不成功则提示用户保存预设文件
3 = 补丁被释放时尝试自动保存（无需用户交互）。若失败，则提示用户
可选值：

0 = 'None'
1 = 'Prompt (free)'
2 = 'Autosave (save), or prompt'
3 = 'Autosave (free), or prompt'

storage_rect [4 floats] : 200. 200. 800. 500.

为存储数据窗口设置新的大小与位置。窗口位置用 4 个数字（left、top、right、bottom）以全局坐标指定。

subscribemode [int] : 0

设置订阅模式。默认值为 0（禁用）。启用后，pattrstorage 对象使用用户指定的订阅列表来确定哪些对象是客户端，而不再发现并维护补丁/补丁层级中的所有对象（按 greedy 特性的判定。可以用 subscribe 和 unsubscribe 消息向该列表添加对象或从中移除对象，用 getsubscriptionlist 消息输出当前已订阅对象的列表。

writefilter [int] : 1

启用时（默认），缺失对象的数据会被排除在 pattrstorage 对象保存的预设文件之外。禁用时，这些数据会被保留。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

None

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值

deciBel：显示响度（dB）

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

int

调取由 int 指定的预设中的数据。

参数：

  • index [int]

float

调取由 float 指定的预设中的数据。若该数字落在两个整数之间（例如 1.5），pattrstorage 对象会在该浮点数整数部分对应的预设中存储的数据与编号比它大一的预设中存储的数据之间插值（例如 1.5 会让 pattrstorage 在预设 1 和 2 之间按 50% 插值）。关于插值模式的更多信息，请参见 interp 消息。

参数：

  • index [float]

anything

发往 pattrstorage 对象的入站消息会被分析。若消息的第一个元素与 pattrstorage 对象所维护的某个对象的路径名或别名匹配（可在该对象的客户端列表中看到），消息中后续的各个参数就用于设置那个对象的值。否则忽略该消息。

参数：

  • arguments [list]

active

active 一词后面跟一个指定客户端对象路径名或别名的符号以及 1 或 0，用于设置该对象的活动状态。客户端对象处于活动状态时（默认），调取预设时会调取它的数据——否则，调取时会忽略该对象。设置父对象（例如包含其他客户端对象的 patcher-any 客户端对象）的 active 状态时，父对象各个子对象的 active 状态会自动设为相同的值。

参数：

  • client [list]

alias

alias 一词后面跟两个符号，会为路径名由第一个参数给出的客户端对象生成一个别名。该别名允许用第二个参数给出的名称来指代该对象。

例如，alias a_patcher::a_pattr the_pattr 会把位于 a_patcher::a_pattr 处的对象起别名为 the_pattr。

在 pattrstorage 对象内，别名可以与路径名互换使用，便于用更简单、更短的名称指代很长的路径。

get alias get alias 一词后面跟一个指定客户端对象路径名的符号，会从 pattrstorage 对象的出口返回该对象的别名（若有），前面带有符号 alias。

参数：

  • client [symbol]
  • alias [symbol]

clear

clear 一词会从 pattrstorage 对象的内部列表中移除所有预设。

client_close

关闭客户端列表窗口。

clientwindow

打开 pattrstorage 对象的客户端列表窗口（标题栏显示 clientwindow (name)，其中 (name) 是创建该窗口的 pattrstorage 对象的补丁名）。

参数：

  • name [list]

copy

copy 一词后面跟 2 个或 3 个参数，会把存储的取值从一个带编号的预设复制到另一个。后面跟 2 个数字时，第一个数字指定的预设槽中存储的取值会被复制到第二个数字指定的预设槽。若该槽尚不存在，会自动创建。后面跟一个符号和 2 个数字时，pattrstorage 对象（由该符号所指代）中、第一个数字指定的预设槽里存储的取值，会被复制到接收 copy 消息的对象中、第二个数字指定的预设槽。例如，消息 copy parent::psto_parent 3 1 会把 pattrstorage 对象（名为 psto_parent）的预设 3 复制到 pattrstorage 对象（即接收 copy 消息的对象）的预设 1；而该 psto_parent 对象位于 pattrstorage 对象的父补丁中。为使其可靠工作，客户端路径名必须完全一致。若不一致，该客户端的数据会被忽略。

参数：

  • pattrstorage [symbol]
  • from-index [int]
  • t0-index [int]

(mouse)

双击 pattrstorage 对象会打开该对象的客户端列表窗口，就像该对象收到了 clientwindow 消息一样。

delete

delete 一词后面跟一个数字时，会清空索引由该数字指定的预设中的所有数据，并把该预设从 pattrstorage 对象的内部列表中移除。若 delete 后面没有参数，则清空并移除所有预设。关于查看对象预设列表的更多信息，请参见 getslotlist 消息。

参数：

  • index [list]

dump

dump 一词会以一系列消息的形式从 pattrstorage 对象的出口报告所有客户端对象的当前值，每条消息的形式为 [object pathname] [data ...]。输出 dump done 消息时，dump 的输出就结束了。

fade

等同于 recall 消息。已废弃。

参数：

  • list [list]

fillempty

fillempty 一词会把所有客户端对象的空预设槽的值设为各自对象的当前值。对于客户端 pattr 对象，若带有 initial 值，则改用该初始值。不会有数据发送给客户端对象本身。

getactive

getactive 一词后面跟一个指定客户端对象路径名或别名的符号，会从 pattrstorage 对象的出口报告该客户端对象的活动状态，前面带有符号 active。

参数：

  • client [list]

getalias

getalias 一词后面跟一个指定客户端对象路径名或别名的符号，会让 pattrstorage 从它的出口返回该客户端对象的别名。

参数：

  • client [list]

getclientlist

getclientlist 一词会以一系列消息的形式从 pattrstorage 对象的出口报告所有客户端对象的路径名，每条消息前面带有符号 clientlist。输出 clientlist done 消息时，getclientlist 的输出就结束了。

getcurrent

getcurrent 一词会从 pattrstorage 对象的出口报告当前活动的预设，前面带有符号 current。

getedited

getedited 一词会从 pattrstorage 对象的出口报告当前活动预设的编辑状态，前面带有符号 edited。若当前活动预设中的数据曾被编辑，状态报告为 1。否则，编辑状态报告为 0。

getinterp

getinterp 一词后面跟一个指定客户端对象路径名或别名的符号，会从 pattrstorage 对象的出口报告该对象的插值模式，前面带有符号 interp。

参数：

  • client [list]

getlockedslots

getlockedslots 一词会以列表的形式从 pattrstorage 对象的出口报告所有已锁定槽的索引，前面带有符号 lockedslots。

getpriority

getpriority 一词后面跟一个指定客户端对象路径名或别名的符号，会从 pattrstorage 对象的出口报告该对象的优先级，前面带有符号 priority。

参数：

  • client [list]

getslotlist

getslotlist 一词会从 pattrstorage 对象的出口报告所有有效预设的编号，前面带有符号 slotlist。

getslotname

getslotname 一词后面跟一个数字时，会让由该数字指定的预设槽的名称从 pattrstorage 对象的出口输出，前面带有符号 slotname。

参数：

  • index [int]

getslotnamelist

getslotnamelist 一词后面跟一个可选的数字时，会让所有已使用槽的槽名以一系列消息的形式从 pattrstorage 对象的出口送出，每条消息前面带有符号 slotname。输出 slotname done 消息时，getslotnamelist 的输出就结束了。

不带参数，或参数为 0 时，getslotnamelist 消息会让从 0 到已存储的最大槽号之间的所有槽都输出，无论该槽是否已定义。这便于把 getslotnamelist 消息与 umenu 之类的对象配合使用。若要过滤掉未定义的槽（即使它们有名称），请带非 0 参数发送 getslotnamelist 消息。

关于更多信息，请参见 pattrstorage 对象的帮助文件。

参数：

  • range [int]

getstate

getstate 一词会让 pattrstorage 对象的当前状态以字典的形式从该对象输出，前面带有 state。

getstoredvalue

getstoredvalue 一词后面跟一个指定客户端对象路径名或别名的符号以及一个指定预设的数字，会从 pattrstorage 对象的出口报告该对象在该预设槽中存储的取值，形式为 [object pathname or alias] [data ...]。

参数：

  • client [list]

getsubscriptionlist

getsubscriptionlist 一词会让所有已订阅对象的名称以一系列消息的形式从 pattrstorage 对象的出口送出，每条消息前面带有符号 subscriptionlist。输出 subscriptionlist done 消息时，getsubscriptionlist 的输出就结束了。关于更多信息，请参见 subscribemode 特性。

grab

grab 一词会让 pattrstorage 对象重新获取所有客户端对象的当前值。当 pattrstorage 对象管理的客户端对象的数据在内部发生变化、而不向 pattr 系统发送通知时，这一点尤其有用。

insert

insert 一词后面跟一个数字时，会把 pattrstorage 维护的每个对象的数据存储到一个带编号的预设中。数字参数指定要存储的预设索引。指定索引及更大的所有预设编号会自动递增，为插入的预设腾出位置。

参数：

  • index [int]

interp

interp 一词后面跟至少 1 个、至多 3 个参数（symbol、symbol、float/symbol），用于设置特定客户端对象的插值状态与模式。第一个符号指定客户端对象的路径名或别名。第二个符号参数决定模式，可以是下列取值之一：

off- 不插值。等同于不加额外参数。

linear- 线性插值。用 float 或 fade 消息调取的预设将使用标准线性算法插值。

thresh- 阈值。接受可选的第三个参数，用于设置阈值。用 float 或 fade 消息调取预设时，若渐变量低于阈值，会调取第一个指定预设中的数据；若渐变量大于或等于阈值，会调取第二个指定预设中的数据。

ithresh- 反向阈值。接受可选的第三个参数（float），用于设置阈值。用 float 或 fade 消息调取预设时，若渐变量大于或等于阈值，会调取第一个指定预设中的数据；若渐变量小于阈值，会调取第二个指定预设中的数据。

pow- 幂曲线。接受可选的第三个参数（float），用于设置渐变量取幂时的指数。用 float 或 fade 消息调取预设时，会沿所述的曲线在两个指定预设之间调取数据。幂曲线可用于为渐变包络制作更快或更慢的"起音"与"衰减"。

table- 表格指定的曲线。接受可选的第三个参数（symbol），用于指定用于曲线查找的表格的名称。用 float 或 fade 消息调取预设时，会沿表格中所述的曲线在两个指定预设之间调取数据。表格假定包含 0 到 100 之间的值，表示新的渐变量 * 100（这在 pattrstorage 对象内部会被截断，但不会归一化）。表格的长度会被拉伸，以匹配预期的渐变值（0 到 1 之间），因此表格条目数不限。若查找的渐变量没有恰好落在表格指定的某个值上，则用线性插值来确定新的渐变量。表格指定插值的示例请参见 pattrstorage 帮助文件。

参数：

  • arguments [list]

locate

locate 一词后面跟一个对应某对象路径名或别名的符号时，会打开包含该对象所在的补丁。

参数：

  • client [symbol]

lock

lock 一词后面跟 2 个数字，用于设置某个特定预设编号的锁定状态。第一个参数指定要锁定或解锁的预设编号。第二个参数指定锁定状态，应为 0（未锁定）或 1（已锁定）。已锁定的预设不能被删除（用 delete 或 remove 消息）或被覆盖（用 store 消息）。已锁定的预设可以被移动（在其他预设上执行 insert、remove 或 renumber 消息的结果）。锁定状态保存在预设数据文件中。

参数：

  • index [int]
  • status [int]

lockall

lockall 一词后面跟一个数字，用于一次性设置所有预设的锁定状态。该参数指定锁定状态，应为 0（未锁定）或 1（已锁定）。已锁定的预设不能被删除（用 delete 或 remove 消息）或被覆盖（用 store 消息）。已锁定的预设可以被移动（在其他未锁定的预设上执行 insert、remove 或 renumber 消息的结果）。锁定状态保存在预设数据文件中。

参数：

  • status [int]

priority

priority 一词后面跟一个指定客户端对象路径名或别名的符号以及一个数字，用于设置该对象的调取与显示优先级。调取预设时，客户端对象的数据将按 priority 确定的顺序恢复。较低的优先级先执行。允许使用负的优先级。优先级只在补丁层级的单一层级内有效。父补丁中的数据总是比嵌套补丁中的数据先恢复。

参数：

  • client [list]

purge

purge 一词重建 pattrstorage 对象的内部客户端列表，移除已被删除或移动的客户端对象的条目。通常，pattrstorage 对象会保留对此类对象的引用，这样当这些对象重新出现时，它们的设置（priority、active、interp 等）就能恢复。

read

read 一词后面跟一个可选的、指定文件名的符号，会把表示预设数据的 JSON 或 XML 文件从磁盘读入 pattrstorage 对象。若给出了参数且它表示有效的文件路径，文件就会从该位置读取——否则会显示一个标准文件对话框，供用户手动选择要读取的文件。

参数：

  • filename [list]

readagain

readagain 一词会重新读取先前由 read 或 write 消息指定的 JSON 或 XML 文件。若先前没有指定文件，会显示一个标准文件对话框，供用户手动选择要读取的文件。

参数：

  • filename [list]

recall

recall 一词后面跟 1 到 4 个参数，会从某个预设中调取数据。若 recall 后面跟一个数字或浮点数，则会调取取值存储在指定预设（或用浮点数表示的插值预设——见 float 消息）中的所有对象的数据。若 recall 后面跟 2 个参数——一个符号和一个数字——且 symbol 参数与某个客户端对象的路径名或别名匹配，则只调取指定对象的数据。数字参数始终指定要调取的预设的索引（或插值索引）。

后面跟 3 或 4 个参数时，recall 消息会按两个预设之间指定的权重调取这两个预设的插值数据。若 recall 一词后面跟两个指定两个预设索引的数字，以及一个指定插值取值、介于 0 与 1.0 之间的浮点数，则会调取取值存储在指定预设中的所有对象的数据。

若 recall 后面跟一个指定客户端对象路径名或别名的符号，再跟两个指定两个预设索引的数字和一个浮点插值取值，则只调取指定对象的数据。

在后两种情况下，浮点参数指定插值的权重，应当介于 0. 与 1. 之间。浮点参数为 0. 就只调取与第一个索引匹配的预设的数据，1. 则调取与第二个索引匹配的预设的数据。关于插值模式的更多信息，见 interp 消息。

参数：

  • client-name, preset-indices, and interpolation-value [list]

recallmulti

recallmulti 一词后面跟至少 2 个数字参数，可以对多个预设做加权调取。每个参数决定最终输出中某个预设的（归一化）权重。若参数是整数，权重为 100%。若参数是浮点数，该数字的整数部分决定预设编号，浮点部分决定权重。例如，recallmulti 1.3 2.3 5.4 会把预设 1 的权重设为 30%、预设 2 为 30%、预设 5 为 40%。由于权重是归一化的，总权重可以高于 100%；例如，recallmulti 1.5 3.5 6.8 会算出正确的权重（分别为 27.77%、27.77% 和 44.44%），而 recallmulti 1 2 3、recallmulti 1.5 2.5 3.5 和 recallmulti 1.99 2.99 3.99 的结果都相同（每个成员 33.33%）。

参数：

  • weighted-pairs [list]

remove

remove 一词后面跟一个数字，会删除 pattrstorage 在某个编号预设中维护的所有对象的数据。数字参数指定要移除的预设的索引。高于该指定索引的所有预设编号都会自动递减。

参数：

  • index [int]

renumber

renumber 一词会把存储的预设重新编号到连续的预设槽位中，从槽位 1 开始。

resolvealias

resolvealias 一词后面跟一个指定客户端对象别名的符号，会从 pattrstorage 对象的出口返回该对象的完整路径名（如果有），并在前面带上 resolvealias 符号。

参数：

  • client [list]

setall

setall 一词后面跟一个指定客户端对象路径名或别名的符号，以及数量可变、与该客户端对象取值对应的其他参数，会把指定客户端对象的值在所有预设槽位中设为该值。不会向客户端对象本身发送任何数据。

参数：

  • client [list]

setstate

setstate 一词后面跟一个字典名（形式为 dictionary [dictname] 或单符号形式 obj:dictionary:[name]），会设置 pattrstorage 对象的内部状态。通常应使用 getstate 消息提供的状态字典，以确保该字典有效。

参数：

  • dictionary-name [symbol]

setstoredvalue

setstoredvalue 一词后面跟一个指定客户端对象路径名或别名的符号、一个指定预设的数字，以及数量可变、与该客户端对象所预期的数据对应的其他参数，会把指定预设槽位中该指定客户端对象的值设为指定的数据。

参数：

  • client [list]

slotname

slotname 一词后面跟一个数字和一个可选的符号，会设置由该数字指定的预设槽位的名称。若未给出符号参数，该槽位的名称会被移除。未定义的槽位可以赋予名称，以作标记之用。若有 preset 对象链接到 pattrstorage 对象，它会显示对应的 pattrstorage 槽位的槽位名。

参数：

  • index [int]
  • slotname [symbol]

storage_close

关闭存储数据窗口。

storagewindow

打开 pattrstorage 对象的存储数据窗口（标题栏显示 storagewindow (name)，其中 (name) 是创建该窗口的 pattrstorage 对象的补丁名）。

参数：

  • name [list]

store

store 一词后面跟 1 个或 2 个参数，会把数据存储到某个编号预设中。若 store 一词后面跟一个数字，则会存储 pattrstorage 维护的所有对象的数据。若 store 后面跟 2 个参数——一个符号和一个数字——且符号参数与某个客户端对象的路径名或别名匹配，则只存储指定对象的数据。数字参数始终指定要存储的预设的索引。若数字参数指定的预设索引已在使用，现有数据会被覆盖，且不会有警告。

允许使用 '0' 这个存储槽位，但它*不会保存在文件中*。它可用作插值操作或其他非永久性实验的临时槽位。

参数：

  • client-and-index [list]

storeagain

storeagain 一词就是用最近使用过的预设槽位执行一次 store 操作。若先前没有使用过预设槽位（若从未向该对象发送过 store 消息），该消息会被忽略。

参数：

  • client [list]

storenext

storenext 一词会使用下一个空的预设槽位执行一次 store 操作，从预设 1 开始向上计数。例如，若预设槽位 1、2 和 4 中已存储了数据，而 pattrstorage 对象收到 storenext 消息，客户端对象的当前状态就会被存储到预设槽位 3。再发一次 storenext 消息会把数据存储到预设槽位 5。

参数：

  • client [list]

subscribe

subscribe 一词后面跟一个或多个符号，每个符号对应一个对象的路径名或别名，会把指定对象加入 pattrstorage 对象的订阅列表。更多信息见 subscribemode 特性。

参数：

  • target [list]

unsubscribe

unsubscribe 一词后面跟一个或多个符号，每个符号对应一个对象的路径名或别名，会把指定对象从 pattrstorage 对象的订阅列表中移除。更多信息见 subscribemode 特性。

参数：

  • target [list]

write

write 一词后面跟一个可选的、指定文件名的符号，会把任何预设数据写入磁盘上的 JSON 文件。若给出了参数且它表示有效的文件路径，文件就会保存到该位置——否则会显示一个标准文件对话框，供用户手动选择要保存的文件的名称和位置。

参数：

  • filename [list]

writeagain

writeagain 一词会把任何预设数据写入先前由 read 或 write 消息指定的磁盘上的 JSON 文件。若先前没有指定文件，会显示一个标准文件对话框，供用户手动选择要保存的文件的名称和位置。

参数：

  • filename [list]

writejson

writejson 一词后面跟一个可选的、指定文件名的符号，会以 JSON 格式把任何预设数据写入磁盘上的文件。若给出了参数且它表示有效的文件路径，文件就会保存到该位置——否则会显示一个标准文件对话框，供用户手动选择要保存的文件的名称和位置。

参数：

  • filename [symbol]

writexml

writexml 一词后面跟一个可选的、指定文件名的符号，会以 XML 格式把任何预设数据写入磁盘上的文件。若给出了参数且它表示有效的文件路径，文件就会保存到该位置——否则会显示一个标准文件对话框，供用户手动选择要保存的文件的名称和位置。

参数：

  • filename [symbol]

输出

anything

多个消息，对应于上文的各个输入消息。
