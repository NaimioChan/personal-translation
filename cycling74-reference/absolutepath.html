Max

absolutepath

把文件名转换为绝对路径

描述

把文件名或路径转换为绝对路径。若找不到该文件，则输出符号 notfound。

讨论

把文件名或路径转换为绝对路径。若找不到该文件，则输出符号 notfound。

除标准的 Max 路径语法（Drive:/path/to/file）之外，absolutepath 还支持下列额外的路径前缀：

  • ~:- 相对于用户主文件夹的路径
  • C74:- 相对于 Cycling '74 资源文件夹的路径（在 macOS 上，该文件夹位于应用程序包内 Max.app/Contents/Resources/C74/；在 Windows 上，它是 resources 文件夹，位于 Max.exe 可执行文件旁边
  • Usermax:- 相对于 Max 9 文件夹的路径（该文件夹位于用户的 Documents 文件夹中）
  • Desktop:- 相对于用户 Desktop 文件夹的路径
  • Tempfolder:- 相对于 Max 临时文件夹的路径（Max 退出时该文件夹会被自动清空）
  • Package:/<package-name>/- 相对于 package-name 中指定的包的路径
  • Project:- 相对于包含 absolutepath 对象的工程（若有）的路径
  • Patcher:- 相对于包含 absolutepath 对象的补丁（若有）的路径

参数

无。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

anything

以符号形式给出的文件名或路径。输入的路径名可以用斜杠、冒号或反斜杠作为分隔符。

参数：

  • pathname [symbol]

types

types 消息后面跟一串四字母文件类型代码，用于指定 absolutepath 能够识别的文件类型。

参数：

  • filetypes [list]

输出

any symbol

若找到传入的文件名或路径，输出为绝对路径。输出的路径名使用斜杠分隔符。

绝对路径名的形式如下：

"C:/Max Folder/extras/mystuff/mypatch.pat"
