MSP

phasor~

生成锯齿波信号

描述

使用 phasor~ 对象生成适合采样点精确控制与计时任务的锯齿波。若想生成听感更平滑的锯齿波，请改用带限的 saw~ 对象。斜坡速率可以按频率（Hz）设置，也可以使用与速度相关的 Max 时间格式语法按间隔设置。

参数

initial-frequency [list] time-value 可选

以 Hz 设置初始频率，或使用与速度相关的 Max 时间格式语法按间隔设置。

特性

frequency [Time Value] : 0 ms

斜坡速率或间隔

jitter [float]

jitter 特性设置每次相位重置时随机频率变化的范围。上下的频率偏移量为 jitter 取值乘以频率的 1/100。示例：若当前频率为 440 且 jitter 为 1.0，phasor~ 将生成介于 439.56 与 440.44 Hz 之间的随机频率。jitter 仅在频率入口未连接信号且 lock 特性被禁用时适用。

limit [float]

limit 特性设置因非零的 jitter 特性而导致频率可偏离其设定值的绝对量。若 jitter 被减小，频率可能会被逐渐改变，以使其更接近设定值。

lock [int]

lock 设为 1 时，phasor~ 会与 Max（或 Max for Live）的走带同步。走带关闭时，phasor~ 将输出零频率。为获得准确的计时，必须启用 Scheduler in Audio Interrupt。启用 lock 特性后，频率只能使用与速度相关的 Max 时间格式语法设置（例如：ticks、bars.beats.units 或音符时值）。

phaseoffset [float]

phaseoffset 特性设置打开音频时的初始相位，也设置 phasor~ 收到 reset 消息时所赋予的相位。phaseoffset 在消除 mc.phasor~ 内多个实例之间的相关性时很有用。若从未设置过 phaseoffset 特性，或发送不带参数的 phaseoffset 一词，则启动音频处理时初始相位不会被更改。在右入口用 float 设置相位时，该更改是立即生效的，但它只会发生一次。phaseoffset 特性使得在多个 phasor~ 对象之间，或在使用 mc.phasor~ 时，可以建立可重复的相位关系。

syncupdate [int]

syncupdate 设为 1 时，phasor~ 的频率只在其周期末尾、相位跳回 0 时才被设置。在该模式下，phasor~ 收到频率变化时不会立即改变其斜率，而是等到相位重置。这可以防止从缓冲区读取时常见的音高毛刺。

transport [symbol] : internal

该特性为一个时间 transport 命名。若使用 'relative' 单位（例如：ticks、bars.beats.units 或音符时值）指定频率，则用所命名的 transport 根据速度、拍号及其他相关信息来确定频率。默认值是全局的 'internal' transport。

消息

bang

syncupdate 设为 1 且 左入口没有连接信号输入时，在左入口发送一个 bang 会强制频率立即更新（而不是等待相位周期结束并跳回 0）。

int

左入口：设置锯齿波的频率（Hz）。若该入口连接了信号，此消息会被忽略。

右入口：设置波形的相位（从 0 到 1）。信号输出从该相位继续。

参数：

  • frequency [int]

float

左入口：设置锯齿波的频率（Hz）。若该入口连接了信号，此消息会被忽略。

右入口：设置波形的相位（从 0 到 1）。信号输出从该相位继续。

参数：

  • frequency [float]

list

用 Max 时间格式语法设置斜坡间隔。

参数：

  • transport/time-settings [list]

anything

用 Max 时间格式语法设置斜坡间隔。

参数：

  • transport/time-settings [list]

reset

reset 消息立即把相位设为 phaseoffset 特性的取值。

signal

左入口：以 Hz 设置频率

右入口：连接到右入口的信号可以用非零取值触发相位重置。发生由信号触发的重置时，相位会被设为 phaseoffset 特性的当前取值。

输出

signal

按指定频率从 0 到 1 反复递增的波形。
