jit.cellblock

编辑数据的行与列

描述

提供二维数据的存储、查看与编辑。其格式类似于许多其他开发环境中能找到的 "grid" 显示工具。jit.cellblock 内的当前单元格位置、格式、显示方式和内容可以用鼠标设置，也可以用 Max 消息设置。

参数

无。

特性

automouse [int] : 1

启用/禁用用鼠标点击拖动来滚动或选择单元格。默认值为 1（启用）。

bblend [int] : 0

指定 jit.cellblock 对象显示时的背景混合百分比。当同时存在列与行的背景色覆盖时，该消息让你可以 "blend" 这些颜色。列色优先于行色；若某单元格同时受行色和列色影响，通常只会显示列色。bblend 消息让你可以用一个百分比值把列色变为透明，从而让行色得以显示。该消息不加区分地把颜色透明度应用到所有列色上。

bgcolor [4 floats]

以 RGBA 格式设置 jit.cellblock 对象的默认背景色。

border [int] : 1

切换是否在 jit.cellblock 周围绘制边框。

bordercolor [4 floats]

以 RGBA 格式设置 jit.cellblock 对象的默认边框颜色。

colhead [int] : 0

切换第一列的行为。若选中 header 选项，第一列的颜色会变为 rgba 设置的颜色，且在 selmode 5 下不能直接编辑。

cols [int] : 10

设置 jit.cellblock 内可见的列数。若列数多于可显示的数量，就会显示滚动条。

colwidth [int] : 66

设置各个单元格的默认列宽。更改这些设置可能会改变滚动条是否显示。

datadirty [int] : 0

启用或禁用补丁的 dirty 标志。默认值为 0（禁用）。启用后，jit.cellblock 对象在其单元格数据发生变化时会把补丁标记为 dirty。

fblend [int] : 0

指定 jit.cellblock 对象显示时的前景混合百分比。当同时存在列与行的前景色覆盖时，该消息让你可以 "blend" 这些颜色。列色优先于行色；若某单元格同时受行色和列色影响，通常只会显示列色。fblend 消息让你可以用一个百分比值把列色变为透明，从而让行色得以显示。该消息不加区分地把颜色透明度应用到所有列色上。

fgcolor [4 floats]

以 RGBA 格式设置 jit.cellblock 对象的默认前景色。

grid [int] : 1

切换是否在每个单个单元格周围绘制边框。

gridlinecolor [4 floats]

以 RGBA 格式设置 jit.cellblock 对象的默认网格线颜色。

hcellcolor [4 floats]

以 RGBA 格式设置 jit.cellblock 对象的默认选中单元格颜色。

headercolor [4 floats]

以 RGBA 格式设置 jit.cellblock 对象的默认表头颜色。

hscroll [int] : 1

切换水平滚动条行为。设为 0 时，当要显示的信息多于当前设置所能应付的量时，该特性会覆盖 jit.cellblock 对象对滚动条显示的自动处理。

hsync [int] : 1

切换是否与另一个 jit.cellblock 对象同步水平移动，该对象的第三个出口连接到 jit.cellblock 对象最右侧的入口。

interval [int] : 250

设置更新 coll 或 jit.matrix 对象内容显示的间隔，单位为毫秒。

just [int] : 0

设置所有单元格的默认文字对齐方式 —— 左（0）、居中（1）或右（2）。
可选值：

0 = 'Left'
1 = 'Center'
2 = 'Right'

neverdirty [int] : 0

启用 neverdirty 后，对列、行或单元格属性的更改不会把补丁标记为 dirty。

outmode [int] : 0

设置 cellblock 的输出模式。输出模式设置有：

0. 分开的值：每个单元格分别送出，单元格内的每个数据项也作为单独的值送出。

1. 作为单个列表：若选中多于一个单元格，所有单元格内容会格式化为单个列表，并作为一次单元格输出送出。

2. 作为单个 symbol：若选中多于一个单元格，或某个单元格有多个值（例如一个列表），所有值会合并为一个以空格分隔的 symbol 送出。

可选值：

0 = 'Individual cells'
1 = 'As one list'
2 = 'As one symbol'

precision [int] : 2

设置所有单元格的默认浮点精度。这不会改变单元格的实际内容 —— 只改变这些内容的显示精度。

readonly [int] : 0

设置 jit.cellblock 对象的只读模式。模式设置有：

-1：消除任何 readonly 设置。该选项把 cell/col/row 从结构中移除，防止 cell/col/row 设置对整体 cellblock 设置造成干扰。
0：readonly 关闭
1：readonly 开启

rowhead [int] : 0

切换第一行的行为。若选中 header 选项，第一行的颜色会变为 rgba 设置的颜色，且在 selmode 5 下不能直接编辑。

rowheight [int] : 18

rowheight 一词后面跟一个数字，会设置各个单元格的默认行高。更改这些设置可能会改变滚动条是否显示。

rows [int] : 10

设置 jit.cellblock 内可见的列数和行数。若行数多于可显示的数量，就会显示滚动条。

savemode [int] : 0

切换是否能把 jit.cellblock 对象的单元格内容作为主补丁的一部分保存。默认行为是 0（把数据保存为单独的文件）。

selmode [int] : 1

设置 cellblock 的选择模式。选择模式设置有：

0. 不选择

1. 选择单个单元格

2. 选择整列

3. 选择整行

4. 选择单个单元格，除非选中了列或行表头，此时选中整列或整行。

5. 就地编辑。选中单个单元格，可以把值直接键入该单元格。

可选值：

0 = 'No Selection'
1 = 'One Cell'
2 = 'Column'
3 = 'Row'
4 = 'Header Select'
5 = 'Inline Edit'

selsync [int] : 1

切换是否与另一个 jit.cellblock 对象同步选择，该对象的第三个出口连接到 jit.cellblock 对象最右侧的入口。

signalmode [symbol] : monitor

信号分析模式
可选值：

'monitor'（当前值）
根据显示间隔显示当前的信号值。

'peak'（峰值）
显示上一间隔中的峰值。

'average'（平均值）
显示上一间隔内收到的所有值的平均值。

'rms'（均方根）
显示上一间隔内收到的值的 RMS（均方根）。

signalusecols [int] : 0

信号使用列

textcolor [4 floats]

以 RGBA 格式设置 jit.cellblock 对象的默认文字颜色。

vscroll [int] : 1

切换垂直滚动条行为。设为 0 时，当要显示的信息多于当前设置所能应付的量时，该特性会覆盖 jit.cellblock 对象对滚动条显示的自动处理。

vsync [int] : 1

切换是否与另一个 jit.cellblock 对象同步垂直移动，该对象的第三个出口连接到 jit.cellblock 对象最右侧的入口。

消息

bang

把内容送往对象的左出口，并通过第三个出口以 set value-list 的形式送出一条消息。

list

在 cellblock 内选择一个单元格。消息 list col-number row-number 等价于消息 select col-number row-number。

参数：

  • column [int]
  • row [int]

append

append 一词后面跟一个数据元素或一串元素，会把指定的有效 Max 数据添加到当前选中单元格的内容中。

参数：

  • input [list]

cell

cell 消息让你可以控制 cellblock 内单个单元格的外观。使用 cell 消息会覆盖 row 和 col 两种消息所做的更改。

参数：

  • column [int]
  • row [int]
  • setting [symbol]
  • value [list]

clear

clear 消息从 cellblock 中移除数据。消息 clear <col-number row-number> 清除指定单元格的内容。clear all 会清除 cellblock 的全部内容。消息 clear current 会清除当前选中的一个或多个单元格的内容。不带参数的 clear 消息等价于消息 clear current。

参数：

  • option [list]

col

col 消息让你可以控制 cellblock 内单个列的外观。用 col 消息覆盖颜色设置，会覆盖用 row 消息所做的一切颜色更改。但使用 cell 消息会覆盖 col 和 row 两种消息的颜色更改。

参数：

  • column [int]
  • setting [symbol]
  • value [list]

deref

把 jit.cellblock 对象与任何已连接的 coll 对象断开。

dump

把所有非空单元格的内容清单送往对象的左出口，每个单元格一行。每行输出的形式为 col-number row-number cell-contents。

jit_deref

消息 jit_deref 会解除对当前所引用的 jit.matrix 对象的引用。

jit_matrix

消息 jit_matrix 会让 jit.cellblock 对象的显示/编辑直接引用收到的 jit.matrix，而不是维护自己的数据结构。

参数：

  • name [symbol]

mode

设置运行模式

参数：

  • operational-mode [list]

plane

plane 一词后面跟一个整数，指定 jit.matrix 对象中某个带编号的通道，会显示该通道。特殊消息 plane -1 会同时显示 RGBA 的 jit.matrix 对象的全部四个通道。

参数：

  • input [int]

prepend

把指定的有效 Max 数据添加到当前选中单元格内容的开头。

参数：

  • input [list]

read

若指定了文件名，就打开并读取磁盘上 cellblock 文件的内容。不会尝试校验其内容。若未指定文件名，会显示文件对话框，以便选择已保存的 cellblock 文件。

参数：

  • filename [symbol]

refer

refer 一词后面跟一个 coll 对象的名称，会显示该具名 coll 对象内部列表的内容。对 jit.cellblock 中数据的更改会改变所连接的 coll 对象的内容。

参数：

  • name [symbol]

refresh

让 jit.cellblock 对象重绘。

row

row 消息让你可以控制 cellblock 内单个行的外观。

参数：

  • row [int]
  • setting [symbol]
  • value [list]

rowblend

rowblend 一词后面跟两个 0-100 范围内的数字，分别指定前景与背景混合百分比。为 cellblock 对象混合前景色与背景色。

参数：

  • foreground [int]
  • background [int]

select

select 消息后面跟一个列号和一个行号，会按当前的 selmode 选择所请求的单元格。jit.cellblock 最左侧的出口按 [column, row, cell contents] 的格式输出一条消息。第三个出口按 sync select [column, row] 的格式输出一条消息，可连接到另一个 jit.cellblock，以便在两个 cellblock 之间同步。

参数：

  • column-number [int]
  • row-number [int]

send

send 一词后面跟一个 receive 对象的名称，会在不使用已连接连线的情况下传送 cellblock 的值；它等价于通过 send 对象送出输出。

send receive-object col-number row-number 会把指定单元格中的数据送给指定的接收对象。send receive-object all 会把所有非空单元格的内容以一串列表的形式送给指定的 receive 对象，形式为 cell-data-type value。

参数：

  • name [symbol]
  • option [list]

set

把单元格的数据替换为指定的数据。支持两种形式：
set current value 替换当前选中单元格的内容。
set col-number row-number values 替换指定单元格的内容。

参数：

  • input [list]

setwithoutdirty

setwithoutdirty 一词后面跟任意发给 jit.cellblock 的消息，会在不把补丁标记为 dirty 的情况下执行该消息。例如：setwithoutdirty col 0 just 1 会设置第 0 列的文字对齐方式而不把补丁标记为 dirty，而发送这条消息时通常会引起这种标记。你也可以通过启用 neverdirty 特性来永久禁用补丁的 dirty 标记。讽刺的是，这样做本身就会把补丁标记为 dirty。

参数：

  • message [list]

signal

根据 signalmode 特性的设置显示信号输入。

sync

在 jit.cellblock 对象的右入口接收来自另一个 jit.cellblock 对象的输入，使两个 cellblock 可以保持位置与选择的同步。同步让多个 jit.cellblock 对象可以像连接在一起那样作出反应。同步的一种用途是强制外部 cellblock 对象充当主 jit.cellblock 的表头行和表头列。关于设置同步的更多信息，见 mode 消息。

参数：

  • messages [list]

text

把当前选中单元格的值替换为传入的文本值。这是为接收 textedit 对象的输出而提供的一种便捷方式。

参数：

  • input [list]

write

打开一个文件，把 cellblock 文件的内容写入磁盘。若指定了文件名，就创建并写入该文件。若未指定文件名，会显示一个文件对话框，供你选择路径名和文件。注意，当 jit.cellblock 指代矩阵时，write 会被禁用。

参数：

  • filename [symbol]

writeagain

若已经写入过文件，writeagain 消息可以让它无需用户进一步干预就被重新写入。

菜单项

Color

在对象被选中时，从 Object 菜单中选择 Color... 菜单项会打开一个 颜色拾取器，可用来调整 jit.cellblock 对象的外观。

输出

list

左出口：一个列表，包含当前选中的列号、行号以及单元格的内容。输出的形式取决于 mode outmode 设置，该设置决定内容是逐个给出、作为单个列表给出，还是作为单个符号给出。

list

中间出口：Max 消息 set 以及随后的单元格内容会作为「辅助」输出送出，用于把单元格内容路由到 textedit 或 message 对象。

list

右出口：同步消息从右出口送出，用作其他 jit.cellblock 对象右入口的来源。这些消息也可用于判断 cellblock 内当前的移动状态——例如，sync click 消息通知某个单元格已被点击选中，而 sync select 消息通知某个单元格已被选中（无论是通过点击，还是通过程序）。
