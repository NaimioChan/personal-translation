jit.phys.ghost

碰撞传感器与力场

描述

jit.phys.ghost 对象表示物理世界中由基本碰撞形状定义的传感器区域。该碰撞形状是若干简单形状之一。此外还可以启用力场，作用于发生碰撞的对象。力场的方向向量可以基于世界坐标，也可以相对于 jit.phys.ghost 对象。

特性

central_exp [float]

若 central_mode 为 decrease 或 increase，则调整中心力缩放曲线的指数。默认值 1 给出线性曲线，大于 1 为指数曲线，小于 1 为对数曲线。

central_force [float]

施加中心力

central_mode [symbol]

指定在由 central_force 启用时，刚体与中心的距离如何影响中心力（默认值 = decrease）。
可选值：

'constant'（距离对中心力没有影响）
'decrease'（中心力随距离减小）
'increase'（中心力随距离增大）

collision_mode [symbol]

指定碰撞字典的格式（默认值 = simple）
可选值：

'simple' ( 报告接触点位置与法线平均值 )
'complete' ( 报告所有接触点的位置与法线 )

collisions [int]

启用或停用从第一个出口送出碰撞字典的报告。

enable [int]

在物理模拟中启用该幽灵对象（默认值 = 1）。

filters [10 symbols]

决定该幽灵对象碰撞对象的名称列表；有效特性为 all 和 default。额外的有效特性由碰撞对象的 filterclass 特性定义。

force [3 floats]

用从幽灵对象中心指向刚体中心的向量，按 amount 缩放后，对发生碰撞的各个刚体施加力。若 amount 为正，刚体从幽灵中心向外弹出；若为负，则被拉向幽灵中心。

name [symbol]

指定实例的名称（默认值 = UID）。

position [3 floats]

以 x y z 形式表示的幽灵对象世界空间位置（默认值 = 0. 0. 0.）。

quat [4 floats]

以 x y z w 形式表示幽灵对象朝向的四元数（默认值 = 0. 0. 0. 1.）。

rotate [4 floats]

以 角度（单位为度） x y z 形式表示幽灵对象朝向的轴角（默认值 = 0. 0. 0. 1.）。

rotate_order [symbol]

设置对所有子 gl 对象施加到 rotatexyz 特性的旋转顺序（默认值 = auto）。例如设为 xyz 时，对象先绕其 X 轴旋转，再绕 Y 轴，最后绕 Z 轴。默认值 'auto' 实现的是 yzx 顺序。
可选值：

'auto'
'xyz'
'xzy'
'yxz'
'yzx'
'zxy'
'zyx'

rotatexyz [3 floats]

以 x y z 形式表示的幽灵对象欧拉角朝向，单位为度（默认值 = 0. 0. 0.）。

scale [3 floats]

以 x y z 形式表示的幽灵对象缩放系数（默认值 = 1. 1. 1.）。不能施加到 concave 形状上。

shape [symbol]

碰撞形状类型（默认值 = sphere）。
可选值：

'sphere'
'cube'
'capsule'
'cone'
'cylinder'
'convexhull'
'concave'
'dynamicmesh'

torque [3 floats]

用一个 3D 世界空间向量对发生碰撞的各个刚体施加力矩（角力）（默认值 = 0 0 0）。

worldname [symbol]

该幽灵对象所绑定的 jit.phys.world 上下文的名称。

消息

bang

更新幽灵对象所受的力并输出碰撞字典

central_impulse

用从幽灵对象中心指向刚体中心的向量，按 amount 缩放后，对发生碰撞的各个刚体施加冲量（瞬时力）。若 amount 为正，刚体从幽灵中心向外弹出；若为负，则被拉向幽灵中心。冲量强度与对象之间的距离成反比。

参数：

  • amount [float]

impulse

用一个由 x、y、z 描述的世界空间向量对发生碰撞的各个刚体施加冲量（瞬时力）。可选参数 relative-x、relative-y、relative-z 描述刚体上施加该力的相对位置，否则视为中心力。

参数：

  • x [float]
  • y [float]
  • z [float]
  • relative-x [float]
  • relative-y [float]
  • relative-z [float]

reset

清除所有力

torque_impulse

用一个由 x、y、z 描述的世界空间向量对发生碰撞的各个刚体施加冲量力矩（瞬时角力）。

参数：

  • x [float]
  • y [float]
  • z [float]
