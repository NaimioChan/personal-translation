Jitter

jit.phys.conetwist

物理世界中的锥形扭转约束

描述

jit.phys.conetwist 是一种特殊的点对点约束，它限制平移，并允许对旋转设限。x 轴充当扭转轴。这可用于表示身体的肢体，比如手臂与腿。对该约束可以施加马达力。若只绑定了一个刚体，它会被约束到世界空间中的一个点。

特性

bias [float]

限制的位置修正幅值（默认值 = 0.3）。该特性设置位置误差被修正的严格程度。多数情况下，该取值不应大于 1。

body1 [symbol]

要约束的第一个 jit.phys.body 的名称。

body2 [symbol]

要约束的第二个 jit.phys.body 的名称。

collisions [int]

启用所附着的刚体之间的碰撞（默认值 = 0）。

enable [int]

在物理模拟中启用该约束（默认值 = 1）。

position1 [3 floats]

body1 的轴心点，以相对于 body1 质心的 3D 向量表示（默认值 = 0 0 0）。

position2 [3 floats]

body2 的轴心点，以相对于 body2 质心的 3D 向量表示（默认值 = 0 0 0）。若 body2 为空，则这是该约束的世界空间位置。

quat1 [4 floats]

body1 相对于该约束的四元数朝向（默认值 = 0 0 0 1）。

quat2 [4 floats]

body2 相对于该约束的四元数朝向（默认值 = 0 0 0 1）。若 body2 为空，则这是该约束的世界空间朝向。

relaxation [float]

限制修正速度误差的速率，实际上就是限制的强度（默认值 = 1.0） 。取值越低表示限制越弱。多数情况下，松弛取值不应大于 1。

rotate1 [4 floats]

body1 相对于该约束的旋转（默认值 = 0 0 0 1）。

rotate2 [4 floats]

body2 相对于该约束的旋转（默认值 = 0 0 0 1）。若 body2 为空，则这是该约束的世界空间朝向。

rotatexyz1 [3 floats]

body1 相对于该约束的欧拉旋转（默认值 = 0 0 0）。

rotatexyz2 [3 floats]

body2 相对于该约束的欧拉旋转（默认值 = 0 0 0）。若 body2 为空，则这是该约束的世界空间朝向。

strength [float]

设置约束强度（默认值 = 0.2）。它决定每个模拟步中会修正多大比例的关节误差。建议使用 0.1 到 0.8 之间的取值。

stretch [float]

设置约束拉伸（默认值 = 0.0）。设为正值后，作用在刚体上的力可以按与拉伸取值成正比的程度违反该约束。

swing1limit [float]

绕摆动 1 轴两个方向允许旋转的限度，单位为度（默认值 = 180）。限度为 180 度时，绕该轴的旋转不受约束。

swing2limit [float]

绕摆动 2 轴两个方向允许旋转的限度，单位为度（默认值 = 180）。限度为 180 度时，绕该轴的旋转不受约束。

twistlimit [float]

绕扭转轴两个方向允许旋转的限度，单位为度（默认值 = 180）。限度为 180 度时，绕该轴的旋转不受约束。

worldname [symbol]

该约束所绑定到的 jit.phys.world 上下文的名称。

worldpos [3 floats] 只读

推导出的约束世界位置（默认值 = 0 0 0）

worldquat [4 floats] 只读

推导出的约束世界四元数（默认值 = 0 0 0 1）
