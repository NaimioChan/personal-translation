Max

filepath

管理并报告 Max 搜索路径

描述

提供对 Max 搜索路径的访问，并允许修改补丁所用的搜索路径。

讨论

filepath 对象用于 File Preferences 补丁中，报告和更改 Max 在某些时刻用于查找文件的各种文件夹。它可以帮助管理 File Preferences 补丁中的搜索路径，或者管理单个补丁专用的路径。

参数

path-type [symbol] 可选

指定 Max 搜索路径类型之一（search、startup、help、action 或 default）

preference [int] 可选

大于零的数字指定 Preferences 文件中的一个槽位。若参数为 0 或未给出数字，该路径不会被保存到 Preferences 文件中。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

bold

bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'

'14'

'18'
'20'
'24'
'30'
'36'
'48'
'64'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

bang 会把当前保存的路径名作为列表输出。

append

append 一词后面跟一个指定文件夹的 symbol，会把该文件夹加入路径列表（但不会保存到 Preferences 文件中）。可选的整数子文件夹标志置为 1 时，还会一并加入所有子文件夹。

参数：

  • folder [list]
  • subfolder-flag [int]

clear

该方法已过时。目前它没有任何效果。

参数：

  • input [int]

revert

把路径名重置为上一次保存的 Max 文件首选项。

set

set 一词后面跟一个 Max 搜索路径类型的名称（search、startup、help、action 或 default），会把当前搜索路径设为指定的类型。可选的整数子文件夹标志置为 1 时，还会一并加入所有子文件夹。

参数：

  • pathtype [list]
  • subfolder-flag [int]

输出

symbol

收到 bang 时输出的当前存储的路径名。
