Max

array.regexp

用正则表达式处理输入

描述

借助 array.regexp，可以使用 PERL 兼容的正则表达式（PCRE）在数组中匹配或进行替换。

讨论

第一个参数是一个 symbol，用于设置正则表达式（RE），左入口的 re 特性也一样。后续参数（或 substitute 特性）会被当作替换中要使用的数组值。左入口的任何其他输入会被转换为数组对象，并当作被处理的对象 "字符串"。

被处理的数组会按 re 和 substitute 的值来处理。中间出口报告 RE 与被处理数组的部分内容相匹配的各处实例所组成的数组。若 RE 中包含圆括号，它们会被当作捕获组，左中间出口会在被处理数组内每次匹配时把它们放进一个数组。若已设置 'substitute' 数组，最左侧输出会返回经过必要替换的被处理数组。

注意，与 Max 中其他支持正则表达式、期望 UTF-8 数据的对象不同，array.regexp 可以处理任意字节缓冲，包括含 0 的二进制缓冲。任何输入的列表或数组都会被转换为字节数组（8 位值，0-255）。若打算处理字符串，需要先用 atoi 或类似对象把它们转换为字节列表，然后再使用 array.regexp。

参数

expression [symbol] 可选

可以用一个正则表达式作为参数来设置正则表达式（正则表达式格式与元字符信息见上文）。

substitution [array] 可选

可选的第二个参数用于设置替换数组。与其他 regexp 对象一样，替换数组中可以包含捕获组；这里的捕获组可以用经典形式 %n（例如 %1 表示第一个捕获组），也可以编码为字节（% = 37，1 = 49）。

特性

re [symbol]

PCRE 参考是进一步了解 Max 中正则表达式如何构建的最佳去处，但这里先给出基础知识的快速概要：

单词 re 后面跟一个 PERL 兼容的正则表达式，用于设置解析或在任何 symbol 或列表输入中进行替换时要使用的正则表达式规则。

若正则表达式中包含空格，在使用 re 消息指定时，或作为输入参数提供给 array.regexp 对象时，必须用双引号括起来。

正则表达式使用以下形式和语法：

[...] 定义一个字符 'class'。其中的任何字符都可能被匹配。其中也可以出现若干特殊符号：

...-... 指定一个范围（在 ASCII 码范围内）

\\d 指定一个十进制数字（\\D 指定非十进制数字）。注意必须使用双反斜杠——Max 会抹掉单个反斜杠。

\\s 指定空白（\\S 指定非空白）。注意必须使用双反斜杠——Max 会抹掉单个反斜杠。

\\w 指定一个字母数字（\\W 指定非字母数字）。注意必须使用双反斜杠——Max 会抹掉单个反斜杠。

^... 指定……的补集

...* 出现零次

...+ 至少出现一次

...? 出现一次或完全不出现

(...) 指定一个捕获组，可以在替换数组中以 %n 的形式引用，其中 n 是该圆括号从左到右的位置。

substitute [atom]

单词 substitute 后面跟一串 0 到 255 之间的整数值，用于指定替换中要使用的数组。若单词 substitute 后面不跟任何值，则移除先前的替换符号。单词 <none> 也可以指定不进行任何替换。单词 emptyarray 表示应当进行替换，但匹配到的值应从最终输出数组中删除。

注意：若需要在任何替换数组中输出一个后面跟数字的 %，应使用 %%（编码为：37 37），这样 % 才不会被解释为捕获组。

输出

symbol or list

左出口：若已用 substitute 消息设置替换数组，输入的列表或 symbol 会连同所需的替换一起从左出口送出）。

左中间出口：若正则表达式中包含圆括号，它们会被当作捕获组。左中间出口在被处理的数组内每次匹配时报告这些捕获组，并把它们作为嵌套数组输出；每个子数组匹配对应一个数组，各自包含所捕获的数组。

中间出口：中间出口报告正则表达式与被处理数组的部分内容相匹配的子数组所组成的数组。

右中间出口：在未发生匹配的情况下，右中间出口透传原始输入。

右出口：最右出口用于报告任何子数组匹配的偏移量（起点、终点）；也就是说，这些偏移量可供 array.slice 用来从输入数组导出子数组。偏移量以嵌套数组的形式提供；每个子数组匹配对应一个含起点和终点偏移量的数组。
