Max

print

在 Max Console 中打印任何消息

描述

print 会把任何输入打印到 Max Console 中，用于调试、传消息或分析。从 Object Action Menu 中选择 "Show Output" 会打开侧栏 Max Console，并把输出过滤为只显示来自 print 的打印输出。

参数

identifier [anything] 可选

该参数是 print 对象的标识符。在 Max Console 中打印的每条消息前面都会加上 print 对象的名称。名称可以是数字，也可以是单词。若没有给出参数，print 对象的名称就是 print。给 print 一个参数有助于区分两个或多个 print 对象的输出。

特性

bettersymquotes [int] : 0

启用后，为清晰起见，数字型 symbol 会在 Max Console 中加上引号（例如 "3.14"，而带引号的 symbol 会被加上斜杠（例如 \"3.14\"）。禁用时（默认），会使用遗留行为（数字型 symbol 不加引号，带引号的 symbol 不显示斜杠）。

deltatime [int] : 0

打印消息之间的时间

floatprecision [int] : 0

选择 regular、low 或 high 精度的 float 显示
可选值：

0 = 'regular'
1 = 'low'
2 = 'high'

level [int] : 0

选择 Max Console 中显示文本的样式。除 Error 样式外，这些样式只用于显示，在 Max 中没有其他含义。使用 Error 样式显示的消息也会出现在补丁中任何 error 对象处。

有四种样式可用：Print (0)、Warn (1)、Error (2)、Bug (3)


可选值：

0 = 'Print' ( 普通（默认） )
在 Max 8 的默认主题中，白色文字配默认（深色）背景。

1 = 'Warn' ( 警告 )
在 Max 8 的默认主题中，绿色文字配默认（深色）背景。

2 = 'Error' ( 错误 )
在 Max 8 的默认主题中，白色文字配红色背景。

3 = 'Bug' ( 缺陷 )
在 Max 8 的默认主题中，蓝色文字配默认（深色）背景。

popup [int] : 0

收到消息时弹出

time [int] : 0

在消息前打印调度器时间

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

执行与 anything 相同的功能。

int

执行与 anything 相同的功能。

参数：

  • input [int]

float

执行与 anything 相同的功能。

参数：

  • input [float]

list

执行与 anything 相同的功能。

参数：

  • input [list]

anything

消息不会被 print 对象解释。它们只是原样打印在 Max Console 中。

参数：

  • input [list]

array

向 print 发送数组时，数组的内容会在控制台中当作单行显示出来。

参数：

  • array [symbol]

(mouse)

双击任何 print 对象都会打开 Max Console 或把它置于最前。

dictionary

向 print 发送字典时，字典完全展开后的内容会在控制台中当作单行显示出来。

参数：

  • dict [symbol]

string

向 print 发送字符串对象时，字符串的内容会在控制台中按单行显示出来。

参数：

  • string [symbol]

输出

anything

没有出口。入口收到的消息会打印在 Max Console 中。
