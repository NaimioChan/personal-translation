MSP

peek~

读写采样值

描述

使用 peek~ 向具名的 buffer~ 读写采样值。与相关对象 index~ 和 poke~ 不同，取值与索引是以 Max 消息的形式指定的，而且该对象即使音频未打开也能工作。

参数

buffer-name [symbol] 可选

缓冲区名称

buffer-channel [int] 可选

要读写的缓冲区通道

clipping-enable-flag [int] 可选

若设为 1，则写入 buffer~ 的取值会被削波到 -1.0 至 1.0 之内。参见 clip 消息。

消息

int

存储在指定 sample-index 处的取值会从 peek~ 对象的出口送出。不过，若刚刚在中间入口收到一个取值，peek~ 就会改为把该取值存储在 buffer~ 中指定的采样点索引处。若 sample-index 超出 buffer~ 的范围，则不读取也不写入任何数据。

参数：

  • sample-index [int]

float

浮点取值会被转换为 int 取值。

左入口：设置要存储的采样点。
右入口：设置缓冲区通道。

参数：

  • sample-index/buffer-channel [float]

list

该取值被存储在 buffer~ 中指定的 sample-index 与 buffer-channel 处。若省略 buffer-channel，则使用最近一次使用的通道。若 sample-index 超出 buffer~ 的范围，则不会写入任何数据。

参数：

  • sample-index [int]
  • value [number]
  • buffer-channel [int]

clip

若设为 1，则写入 buffer~ 的取值会被削波到 -1.0 至 1.0 之内。设为 0 可禁用。

参数：

  • clipping-enable-flag [int]

(mouse)

双击可查看 buffer~ 的内容

set

设置要读写的 buffer~

参数：

  • buffer-name [symbol]

输出

float

buffer~ 中位于表索引处的采样值，该表索引由在左入口收到的 float 或 int 指定，会从 peek~ 对象的出口送出。
