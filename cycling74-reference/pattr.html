Max

pattr

提供一个带具名数据包装器的别名

描述

存储自己的数据，或者绑定到另一个对象，以便与其他基于 pattr 的对象（例如 pattrstorage）共享其内容。可用于数据路由或预设创建。

讨论

pattr 对象可以看作数据的别名。它有两种工作模式。默认情况下，pattr 对象维护自己的数据。这些数据可以是任何普通的 Max 类型（int、float、list、symbol）。pattr 对象也可以绑定到另一个对象，只要那个对象有一个 pattr 对象能够解析的补丁名称。在这种情况下，pattr 对象只是引用另一个对象内部的数据，并且受限于该对象所期望的数据类型。绑定之后，发给 pattr 对象的数据会被转发给被引用的对象（目标），而对目标所做的改动会反映在 pattr 对象中。

参数

name [symbol] 可选

可以选用一个符号参数来设置 pattr 对象的 name。若没有参数（也没有用 @name 语法显式设置 name 特性），pattr 对象会被赋予一个任意的、半随机的名称，例如 u197000004。

特性

annotation_name [symbol] :

信息视图标题

autorestore [int]

启用（1）或禁用（0）pattr 对象的 autorestore 状态。默认值为 1（启用）。启用后，补丁加载时 pattr 对象会自动输出它上次保存的取值（并且，若绑定了另一个对象，会把该取值发送给那个对象。关于绑定对象的更多信息，见下面的 bindto 特性）。

bindto [symbol]

bindto 一词后面可跟一个可选的 symbol 参数，用于设置 pattr 对象的绑定状态。默认状态为未绑定（无参数）。默认情况下，pattr 对象维护自己的数据。使用 bindto 功能「绑定」后，pattr 对象会维护另一个对象的数据，并自动为该对象获取和设置取值。bindto 接受一个可选的 symbol 参数，用于指定 pattr 将绑定到哪个对象的名称。绑定目标不必与 pattr 对象处于同一补丁层级。此时，可以用双冒号语法（'::'）分隔补丁层级的各个层级，以便描述名称解析所用的路径（例如 somepatcher::someobject）。若被命名的对象比 pattr 对象处于更高的补丁层级，可以用 parent 一词来指代更高层级上的补丁（例如 parent::objectaboveme、parent::parent::objectaboveobjectaboveme 或 parent::patchernexttome::someobject）。

若被命名的对象含有特性，而用户希望绑定到某个具体的特性，同样用双冒号语法来指定该特性的名称（例如 someobject::someattribute）。不带参数发送 bindto 消息会解除 pattr 对象与任何已绑定对象的绑定，并让它恢复维护自己的内部状态。关于该功能的更多信息，请参阅 pattr 帮助文件。

default_active [int]

启用（1）或禁用（0）pattr 对象的默认活动状态，即它被 pattrstorage 对象发现时的状态。默认值为 1（活动）。更多信息请参阅 pattrstorage 对象的参考页。

default_interp [2 atoms]

default_interp 一词后面跟一个符号和一个可选的第二个参数，用于定义 pattr 对象的默认插值设置，即它被 pattrstorage 对象发现时的设置。默认值为 linear。更多信息请参阅 pattrstorage 对象的参考页。

default_priority [int]

default_priority 一词后面跟一个 int，用于定义 pattr 对象的默认优先级，即它被 pattrstorage 对象发现时的优先级。默认值为 0。更多信息请参阅 pattrstorage 对象的参考页。

dirty [int]

启用（1）或禁用（0）补丁的 dirty 标志。默认值为 0（禁用）。启用后，只要 pattr 对象的状态发生变化，就会把补丁标记为 dirty。

initial [256 atoms] :

pattr 对象的初始值。若 autorestore 设为 1，补丁载入时会恢复该值，而不是恢复补丁最后一次保存时 pattr 对象的取值。initial 特性可以与 init 消息配合使用，把 pattr 对象重置为指定的值。

invisible [int]

invisible 一词后面跟一个 1 或 0，决定 pattr 对象对 pattrstorage 对象是否不可见。默认值为 0（可见）。

max [atom] :

int 和 float 取值（包括列表中的取值）的最大值，默认禁用（<none>）。当 parameter_enable 打开时，该值与参数的上界范围值关联。

min [atom] :

int 和 float 取值（包括列表中的取值）的最小值，默认禁用（<none>）。当 parameter_enable 打开时，该值与参数的下界范围值关联。

parameter_enable [int]

启用后，该对象可与 Max for Live Parameters 配合使用。

parameter_mappable [int] : 1

启用 parameter_mappable 后，该对象即可通过映射功能映射到键盘或 MIDI 输入。

thru [int]

调整 pattr 对象的 thru 行为。默认值为 1（变化时输出取值）。对所有变化都启用时，对象会在取值发生变化时输出自己的值，或在收到 bang 时输出。设为 0（变化时抑制输出（仅 bang））时，对象只在收到 bang 消息时才输出自己的值。设为 2（由入口触发时抑制输出）时，取值只会在并非由发往 pattr 对象入口的消息所触发的变化发生时输出。
可选值：

0 = 'Suppress output on change (bang only)'
1 = 'Output value on change'
2 = 'Suppress output when triggered from inlet'

type [symbol] : atom

type 一词后面跟一个对应有效类型的符号，用于设置 pattr 对象在未绑定时内部维护的数据类型。默认值为 atom。可用的类型包括 char、long、float32、float64、symbol 和 atom。
可选值：

'atom'
'char'
'long'
'float32'
'float64'
'symbol'

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

从左出口送出 pattr 对象维护的数据。

int

一个 int 会存储在 pattr 对象内部，并从其左出口送出。该值也可以选择继续传给已绑定的对象（关于已绑定对象的更多信息，请参阅 bindto 特性）。

参数：

  • input [int]

float

一个 float 会存储在 pattr 对象内部，并从其左出口送出。该值也可以选择继续传给已绑定的对象（关于已绑定对象的更多信息，请参阅 bindto 特性）。

参数：

  • input [float]

list

一个 list 会存储在 pattr 对象内部，并从其左出口送出。该值也可以选择继续传给已绑定的对象（关于已绑定对象的更多信息，请参阅 bindto 特性）。

参数：

  • input [list]

anything

任意 message 都会存储在 pattr 对象内部，并从其左出口送出。该值也可以选择继续传给已绑定的对象（关于已绑定对象的更多信息，请参阅 bindto 特性）。

参数：

  • input [list]

assign

assign 一词后面跟一个浮点取值，会让该值被存储、显示，并从 pattr 对象的左出口送出。若对象的 Parameter Enabled 特性被设置（勾选），且 Parameter Visibility 特性设为 Stored Only，assign 消息不会把新值加入 Live 应用程序的撤销链。

参数：

  • input [float]

(mouse)

双击已启用参数的 pattr 对象，会在 Max for Live 中打开 Parameters Window。

dictionary

一份 dictionary 的副本会存储在 pattr 对象内部，并从其左出口送出。该字典也可以选择继续传给已绑定的对象（关于已绑定对象的更多信息，请参阅 bindto 特性）。

参数：

  • input [symbol]

init

若 pattr 对象的 initial 特性已设置，init 消息会把 pattr 对象的取值设为 initial 特性的值。

输出

(internal)

连接到 pattr 对象中间出口的用户界面对象（或响应 pattr 所用内部消息系统的其他对象）会被自动命名（如有必要）并绑定。名称由对象的类名自动生成（例如，相连的 数字框 可能被命名为 number[1]）。目前可以用这种方式绑定以下 Max 用户界面对象：dial、function、gain~、ggate、gswitch、js（需要用户支持）、jsui（关于在 JavaScript 中使用 pattr 系统的更多信息，请参阅 JavaScript in Max 手册）、led、matrixctrl、multislider、nslider、数字框（int 和 float）、pattr、pattrstorage、pictctrl、pictslider、radiogroup、rslider、slider、swatch、table、textedit、toggle 和 umenu。

anything

左出口：当 pattr 对象收到新数据、一个 bang，或检测到其已绑定对象的取值发生变化时，会送出该取值。

右出口：get 查询——针对 pattr 对象各特性的查询——会从右出口送出，该出口也称为 dumpout 出口。
