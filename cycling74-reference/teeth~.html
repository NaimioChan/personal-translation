MSP

teeth~

带前馈和反馈延迟控制的梳状滤波器

描述

teeth~ 对象实现了一个梳状滤波器，其中信号略微延迟的副本被加到它自身之上，造成相位抵消，并形成看起来像梳子的频谱。

讨论

teeth~ 对象是 comb~ 对象的变体，实现的滤波公式与之类似：

y[n] = a * x[n] + b * x[n - FFdelay] + c * y[n - FBdelay]

参数

maxdelaytime [float] ms 可选

以毫秒为单位设置最大延迟时间；这将是前馈与反馈延迟的上限。若未给出参数或参数为零，默认的最大延迟时间为 10 毫秒。

feedforward-delay [float] ms 可选

以毫秒为单位设置前馈延迟的初始取值。若有信号连接到该入口，则为该入口作为参数提供的系数会被忽略。若未给出参数，延迟时间默认为 10 毫秒。

feedback-delay [float] ms 可选

以毫秒为单位设置反馈延迟的初始取值。若有信号连接到该入口，则为该入口作为参数提供的系数会被忽略。若未给出参数，延迟时间默认为 10 毫秒。

gain [float] 可选

设置增益的初始取值。若有信号连接到该入口，则为该入口作为参数提供的系数会被忽略。若未给出参数，该取值默认为 0。

feedforward-gain [float] 可选

设置前馈增益的初始取值。若有信号连接到该入口，则为该入口作为参数提供的系数会被忽略。若未给出参数，该取值默认为 0。

feedback-gain [float] 可选

设置反馈增益的初始取值。若有信号连接到该入口，则为该入口作为参数提供的系数会被忽略。若未给出参数，该取值默认为 0。

消息

int

第 2 到第 6 个入口中的滤波器参数可以用 float 而不是信号来指定。若该入口同时也连接了信号，则 float 会被忽略。

参数：

  • filter-parameters [int]

float

第 2 到第 6 个入口中的滤波器参数可以用 float 而不是信号来指定。若该入口同时也连接了信号，则 float 会被忽略。

参数：

  • filter-parameters [float]

clear

清空 teeth~ 对象中先前输出的记忆，把它们重置为 0。

signal

左入口：要滤波的信号。teeth~ 对象是 comb~ 的变体 —— 一种梳状滤波器，它把当前输入采样点与更早的输入和/或输出采样点混合，以等间距的频率间隔增强和削弱输入信号。与 comb~ 对象不同，teeth~ 增加了前馈与反馈，使效果更为极端。

第二个入口：前馈 —— 在过去的输入采样点被加到当前输入之前的那段延迟，以毫秒为单位。

第三个入口：反馈 —— 在过去的输出采样点被加到当前输入之前的那段延迟，以毫秒为单位。

第四个入口：增益系数 —— 用于缩放送往输出的输入采样点的量。

第五个入口：增益系数 —— 用于缩放送往输出的前馈的量。

右入口：增益系数 —— 用于缩放送往输出的反馈的量。

list

这五个参数可以在左入口中以列表形式提供。列表中的第一个数字是前馈延迟，下一个数字是反馈延迟，第三个数字是输入采样点的增益系数，第四个数字是前馈增益系数，第五个数字是反馈增益系数。若有信号连接到某个入口，则列表中为该入口提供的系数会被忽略。

参数：

  • feedforward-delay [float]
  • feedback-delay [float]
  • gain [float]
  • feedforward-gain [float]
  • feedback-gain [float]

输出

signal

经过滤波的信号。
