Max

borax

报告 note-on 和 note-off 信息

描述

获取并输出关于 note-on 和 note-off 事件的全面信息。信息包括音符数量、事件详情以及音符事件之间的时间。

参数

无。

特性

size [int] : 128

size 特性只能作为键入的参数来修改，它设置 borax 能跟踪的最高音符号。默认值是 128，适用于 MIDI 音符号。若你把 borax 用于非 MIDI 用途，可以把 size 指定到最大 16384 个 "note" 值。

消息

bang

右入口：通过为当前持有的所有音符发送 note-off 来重置 borax，抹去 borax 对象对所收到所有音符的记忆，并把它的计数器和时钟置为 0。

int

左入口：该数字是 MIDI note-on 消息或 note-off 消息（力度为 0 的 note-on）的音高值。音高会与中间入口的力度配对。borax 会忽略它已经持有的音高的 note-on 消息，并忽略已经关闭的音高的 note-off 消息。若该音符不是重复的，borax 会送出音高和力度值以及其他信息。

参数：

  • pitch [int]

(inlet1)

中间入口：该数字被存储为力度，用来与左入口收到的音高数字配对。

参数：

  • velocity [int]

delta

使 delta 时间（自上次 note-on 以来经过的时间）和 delta 计数（已报告的 delta 时间次数）被送出。

list

第二个数字被存储为力度，第一个数字被用作音高-力度对的音高。若该音符不是重复的，borax 会送出音高和力度值以及其他信息。

参数：

  • pitch [int]
  • velocity [int]

输出

int

左出口：borax 收到的每个 note-on 都会被分配一个唯一编号，该编号等于（自上次重置以来）收到的 note-on 总数。收到该 note-on 时送出这个编号，音符关闭时也送出同一个编号。

第 2 出口：每个音符还会被分配一个唯一的声部号，等于当前可用的最小编号。（分配给某个声部的音符关闭时，该声部就变为可用。）收到该 note-on 时送出这个编号，音符关闭时也送出同一个编号。

第 3 出口：每当收到 note-on 或 note-off 时，都会送出 borax 当前持有的音符数量。

第 4 出口：送出该 note-on 或 note-off 的音高。

第 5 出口：送出该 note-on 或 note-off 的力度。

第 6 出口：收到 note-off 时，送出（自上次重置以来）所有已完成音符的总数。

第 7 出口：收到 note-off 时，送出该音符的时长，单位为毫秒。

第 8 出口：每当报告一次 delta 时间，都会送出 delta 时间的总数。

右出口：收到 note-on 时，送出 delta 时间（自上一个 note-on 以来经过的时间，单位为毫秒）。左入口收到 delta 消息也会产生同样的输出。

bang 在右入口收到时，会让 borax 为它当前持有的所有音符提供 note-off。这些 note-off 触发的输出与它们真的被收到时相同。
