Max

array.expr

对数组求数学表达式的值

描述

使用 C 语言风格的数学运算执行数学计算。作用于数组形式的输入，而不是单个数值的集合。

参数

expression [list] 可选

传给 vexpr 对象的参数是一个数学表达式，它由数字、+ 或 * 之类的算术运算符、< 或 > 之类的比较、min () 或 pow () 之类的 C 函数、table 对象的名称，以及为各入口收到的 int、float 和 symbol 而设的可变参数（$i、$f 和 $s）组成。

constant [number] 可选

数字可以在数学表达式中用作常量。

format [symbol] 可选

用于指定与某个入口关联的数据格式的可变参数，由数据类型（$i 或 $f）和入口编号组合而成（例如 $i2）。该参数会被指定入口收到的数字替换。

table [symbol] 可选

指定从表中访问数据的可变参数，用参数 $s 和一个入口编号来描述，该编号会被替换为要访问的 table 的名称。该参数后面应紧跟一个带方括号的数字，用来指定 table 中的地址。（示例：$s2[7] 或 $s3[$i1]。）

(other) [symbol] 可选

vexpr 对象理解下列算术运算符：+、-、*、/、%。其他运算符有 ~（按位取反）、^（按位异或）、&、&&、|、|| 和 !（非）。

vexpr 能理解许多 C 语言的数学函数。函数后面必须紧跟一对圆括号，括号内包含该函数所需的任何参数。若函数需要在参数之间使用逗号，该逗号前面必须加一个反斜杠（\），以免 Max 因此产生混淆。例如：(pow ($i1\,2) + $f2)。

vexpr 能理解的 C 语言函数有：abs、min、max、sin、cos、tan、asin、acos、atan、atan2、sinh、cosh、tanh、int（转换为整数）、float（转换为浮点数）、pow、sqrt、fact（阶乘）、exp（e 的 x 次幂）、log10（对数）、ln 或 log（自然对数）和 random。可以通过放在 Max 启动文件夹中的外部代码资源来添加额外的函数。

array.expr 还理解特殊函数 arrayidx()（无参数），它提供一个 int，表示当前正在处理的数组索引。

特性

fillmode [int] : 0

fillmode 决定如何调整长度与送入左入口的数组不一致的数组。有几个选项可用。
可选值：

0 = 'Repeat' （重复元素）
数组的所有元素会被重复，以达到所需长度。若传入左入口的数组长度为 3，数组 [ 2 ] 会变成 [ 2, 2, 2 ]；[ 2 1 ] 会变成 [ 2 1 2 ]。

1 = 'Repeat Last' （重复最后一个元素）
数组的最后一个元素会被重复，以达到所需长度。若传入左入口的数组长度为 3，数组 [ 2 ] 会变成 [ 2, 2, 2 ]；[ 2, 1 ] 会变成 [ 2, 1, 1 ]。

2 = 'Repeat Zero' （重复零）
整数 0 会被重复，以达到所需长度。若传入左入口的数组长度为 3，数组 [ 2 ] 会变成 [ 2, 0, 0 ]；[ 2, 1 ] 会变成 [ 2, 1, 0 ]。

3 = 'Interpolate (Linear)' （线性插值）
会对数组进行线性插值，以达到所需长度。若传入左入口的数组长度为 3，数组 [ 1, 3 ] 会变成 [ 1, 2, 3 ]；[ 5, 1 ] 会变成 [ 5, 3, 1 ]。若所有元素都是 ints，插值将以整数进行；若任一元素是 float，插值会返回浮点数。

把传入的列表转换为数组，然后按 array 消息所述处理。

参数：

  • list-value [list]

anything

把传入的列表转换为数组，然后按 array 消息所述处理。

参数：

  • list-value [list]

array

每个数组的元素按从左到右的顺序逐个使用，以替换表达式的多次求值中的可变参数。左入口收到数组时，表达式先用每个数组的第一个元素求值，再用每个数组的第二个元素求值，依此类推。这些求值的一系列结果随后作为一个数组送出。

若各数组长度不同，将用 fillmode 决定如何处理长度差异。

dictionary

把传入的 dictionary 对象包装成数组，然后按 array 消息所述方式处理。

参数：

  • dictionary-value [list]

string

把 string 对象包装成数组，然后按 array 消息所述方式处理。

参数：
