jit.gl.textureset

一组用于存储/重排序的纹理

描述

jit.gl.textureset 对象保存一组内部纹理，可以向其中写入，也可以从中读出。这对于数据存储和/或纹理重排序可能很有用。jit.gl.textureset 模仿 jit.matrixset 的功能，但输出纹理而不是矩阵。

参数

texturecount [int] 可选

纹理组中的纹理数量（默认值 = 1）

drawto [message] 可选

用于绘制的具名绘制上下文（默认值 = none）。具名绘制上下文是 jit.world、jit.pworld 或 jit.gl.node 对象的具名实例。若不提供参数，该对象会隐式地找到一个上下文。

特性

adapt [int]

启用 jit.gl.texture 的 adapt to input 特性（默认值 = 1）。启用后，纹理输出的维度会与输入的维度一致。

dims [int]

当 adapt 特性被禁用时，设置输出纹理的维度（默认值 = 256 256）。

index [int]

设置传入纹理会被写入该纹理组中的哪一张纹理（默认值 = 0）

insert [int]

传入帧的插入位置（默认值 = -1，即禁用）。设为非负值时，每张传入的纹理都会插入到该索引处，位于该索引及其之上的帧会向上移一位（超出 texturecount-1 的帧会被逐出）。把 insert 设为 0 会产生先进先出（FIFO）延迟线行为——此时 outputtexture N 返回的是 N 次捕获之前的帧。把 insert 设为 -1 则恢复基于索引的写入。
