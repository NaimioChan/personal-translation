Max

message

发送任意消息

描述

message 会显示并发送任何给定的消息，并且能够处理指定的参数。

参数

message [list] 可选

补丁窗口未锁定时，可以键入 message 对象框的初始内容。任何消息都可以包含在 message 对象框中。某些字符具有特殊含义。

changeable-arg [symbol] 可选

美元符号（$）后面紧跟着 1-9 范围内的数字，是一个可变参数。该参数的值可以被入口收到的列表中对应的项替换。（例如：$2 会把列表中第二项存为它的值，然后再送出 message 对象框的内容。）可变参数的初始值为 0。

comma [symbol] 可选

逗号（,）把一条消息分成若干条独立的消息，这些消息会按顺序依次送出。（例如：3, 4, 5 会先送出 3，再送出 4，然后送出 5。）

backslash [symbol] 可选

反斜杠（\）用于取消（转义）特殊字符的特性。当反斜杠紧挨在美元符号、逗号或分号之前时，该字符被当作普通字符处理。（例如：Notes played were C\, E\, and G。）

特性

bgfillcolor [4 floats] >= 7.0.0

以 RGBA 格式设置 message 对象框的背景色。message 对象框可以通过 format palette 配置为显示渐变背景色。

convertobj [int] : 0

别名：parseobj

启用 convertobj 后，发送到 message 右入口的包含字典、数组或字符串的消息会被转换为文本表示，而不是对象引用。举例来说，由 1、2、3 组成的数组会把 message 的内容设为 1 2 3（当 convertobj 已启用时），而在 convertobj 已禁用时则会设为类似 array u821001852 的内容（具体数字会有所不同）。

dontreplace [int] : 0 >= 7.0.4

启用 dontreplace 后，加载文件或从剪贴板粘贴时，message 对象框中不会有任何文本。若你想用该对象显示传入的消息或数据，这会很有用。

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

左入口：送出 message 对象框的内容。在 message 对象框上点击鼠标效果相同。

右入口：把 message 对象框的内容设为 'bang'，但不触发输出。

int

左入口：该数字替换参数 $1 中存储的值（若存在这样的参数），然后送出 message 对象框的内容。

右入口：设置 message 对象框的内容，但不触发输出。

参数：

  • input [int]

float

左入口：该数字替换参数 $1 中存储的值（若存在这样的参数），然后送出 message 对象框的内容。

右入口：设置 message 对象框的内容，但不触发输出。

参数：

  • input [float]

list

列表中的每一项替换其对应 $ 参数的值（若存在这样的参数），然后送出 message 对象框的内容。

右入口：设置 message 对象框的内容，但不触发输出。

参数：

  • input [list]

anything

参见 list 条目

参数：

  • message [list]

append

append 一词后面跟任意消息，会把 message 对象框设为在它已包含的任何文本之后显示该消息，但不触发输出。

参数：

  • message [list]

(mouse)

在 message 对象框上点击鼠标会把它内容从该对象的出口送出。

prepend

prepend 一词后面跟任意消息，会把 message 对象框设为在它已包含的任何文本之前显示该消息，但不触发输出。

参数：

  • message [list]

set

set 一词后面跟一条消息，会把 message 对象框的内容设为该新消息，但不触发输出。单独使用 set 一词会清空 message 对象框的内容。

参数：

  • message [list]

setargs

setargs 一词后面跟一条消息，会设置接收方 message 对象框的可变参数（例如 $1），但不触发输出。

参数：

  • message [list]

symbol

左入口：该符号替换参数 $1 中存储的值（若存在这样的参数），然后送出 message 对象框的内容。

右入口：设置 message 对象框的内容，但不触发输出。

参数：

  • input [symbol]

菜单项

Color

选中该对象后，从 Object 菜单选择 Color... 菜单项会打开一个 颜色拾取器，可用于调整 message 对象框的外观。

输出

anything

message 对象框的内容会从出口送出。若其中含有分号，消息的其余部分（或直到下一个分号为止的部分）会发送给指定的 receive 对象，而不是从出口送出。
