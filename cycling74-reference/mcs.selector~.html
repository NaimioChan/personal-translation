mcs.selector~

把多通道信号的一个通道分配到出口

描述

用 selector~ 对象可在若干输入信号之间选择其一（或全都不选）。selector~ 类似于 Max 的 switch 对象，但处理的是信号；不过若没有选中任何输入，它会输出由零值组成的信号。
当 selector~ 对象被创建为 mcs.selector~ 时，它所有的信号入口会合并成一个多通道入口。mcs.selector~ 的行为在其他方面与 selector~ 类似，不同之处在于：当连接到其右入口的多通道信号的输入数发生变化时，mcs.selector~ 会改变自身的输入数（自动适配）。

参数

number-of-inputs [int] 可选

入口数

initially-open-inlet [int] 可选

指定初始选中哪个输入。若为 0，则所有信号都被关闭，并送出一个零信号。

特性

ramptime [float] : 0.

别名：ramp

设置切换连接时用于淡化的斜坡时间，单位为毫秒。当 ramptime 特性非零时，切换激活输入时 selector~ 会在各输入之间交叉淡化，把此前处于激活状态的输入淡出，并把正在变为激活状态的输入淡入。

stepmode [int] : 0

启用后，左入口中信号值的所有整数变化（无论是递增还是递减）都会把当前打开的输入通道加 1，并在可用通道之间回绕。取值为零会停止输出。

消息

bang

与 next 消息相同。

int

选择把哪个输入路由到出口。若取值为 0 或负数，则向所有出口送出零信号。若取值大于输入数，则使用最右侧的输入。若左入口连接了信号，则忽略此消息。

参数：

  • open-input [int]

float

float 输入会被截断，并像 int 消息一样用于选择把哪个输入通道路由到出口。

next

向左入口发送 next 消息会关闭当前的输入通道并打开下一个，在所有通道之间回绕。若当前处于关闭状态（设为 0）或已设为最后一个通道，则把第一个通道路由到出口。

signal

左入口：若左入口连接了信号，selector~ 会以一种用信号值决定把哪个输入信号送往其出口的模式运行。若左入口进来的信号为 0 或负数，则关闭输出并送出零信号。若为 1 但小于 2，则把最左入口右边第一个入口进来的信号送往出口。若信号为 2 但小于 3，则使用右边下一个入口进来的信号，依此类推。

右入口：多通道信号中的一个通道会被送往 mcs.selector~ 对象的出口，具体取决于左入口最近一次收到的 int 或 float 取值，或左入口进来的信号。最左入口右边第一个信号入口视为输入 1，再往右是输入 2，依此类推。

输出

signal

输出是来自所选输入通道的信号，由左入口的数字或信号指定。若所有输入都已关闭，则输出为零信号。
