bendout

发送 MIDI 弯音消息

描述

把 MIDI 弯音值发送给 MIDI 设备。

参数

port [symbol] 可选

指定发送 MIDI 弯音消息的端口。从右入口收到的大于 16 的通道号会被回绕，以保持在 1-16 范围内。若没有给出参数，bendout 最初从端口 a、MIDI 通道 1 发送。

port-and-channel [list] 可选

以及 int 一个字母与数字的组合（用空格分隔）表示发送弯音消息所用的端口和特定 MIDI 通道。大于 16 的通道号会被回绕，以保持在 1-16 范围内。

midi-device [symbol] 可选

MIDI 输出设备的名称可用作第一个参数来指定端口。名称 'none' 可用于阻止对象在任何端口上发送 MIDI 消息。

channel [int] 可选

可以只用数字代替字母与数字的组合。通道号参数的确切含义取决于 MIDI Setup 对话框中为每个端口指定的通道偏移。

特性

matchport [int] : 0

若 port 参数与任何已有的端口或设备名都不匹配，则把对象的 MIDI 端口设为 'none'。

name [symbol]

根据设备名设置对象的 MIDI 端口。该特性会依据特性值尝试做区分大小写的部分字符串匹配。

消息

int

左入口：该数字会作为 MIDI 弯音值在指定的通道和端口上发送。数字被限制在 0 到 127 之间。

参数：

  • input [int]

(inlet1)

右入口：该数字被存储为发送弯音消息所用的通道号。

参数：

  • MIDI-channel [int]

float

转换为 int。

参数：

  • input [float]

anything

参见 port 消息

参数：

  • MIDI-port [list]

(mouse)

双击 bendout 对象会显示一个弹出菜单，用于选择 MIDI 端口或设备。

port

左入口：port 一词后面跟一个字母 a-z 或 MIDI 输出端口或设备的名称，用于指定发送 MIDI 消息所用的端口。port 一词是可选的，可以省略。名称 'none' 可用来阻止对象在任何端口上发送 MIDI 消息。

参数：

  • MIDI-port [symbol]

输出

(MIDI)

没有出口。输出是一条直接发送到对象 MIDI 输出端口的 MIDI 弯音消息。
