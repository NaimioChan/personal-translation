key

报告键盘按键

描述

跟踪并输出计算机键盘上按键的键码、ASCII 值和修饰键值。

参数

无。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

消息

(keyboard)

key 的输入直接来自计算机键盘。没有入口。

输出

int

计算机键盘上每按下一个键都会送出输出。对于多键组合（例如 Mac 美式键盘上先按 option-E 再按 E），只有最后按下的键会产生输出。

左出口：按下键的 Unicode 值，UTF-16 编码。该出口给出所按键的 ASCII 值（即它输出的是文本字符，而不是所按下键的键码）。
第二个出口：所键入键的平台相关键码。这些键码因具体物理键盘以及操作系统而异。取值来自 Apple 的键码定义（例如 a=0、s=1、d=2、f=3）。当你想识别按键的位置而不是按下的哪个键时，该出口很有用（例如用计算机键盘实现一个音乐键盘时）。某个按键位置报告的取值是固定的，与所选语言无关，也与按下的修饰键无关（例如，无论选择英文还是德文键盘布局，左 shift 键右边那个键被按下时报告的取值都是 6。

第三个出口：输出值是一组比特位，表示按键按下时各修饰键的状态。该值可以经过 & 对象来产生由各个修饰键设置的开关。右出口的数值输出与 & 对象的参数一起列出，该参数会产生一个开关：
按键事件：输出 128。开关 = & 128（Windows 上若按下鼠标按钮则报告 0，Macintosh 上始终报告 0）
Windows Control 键：输出 384。开关 = & 256（系统会使用它，因此不作报告）
Macintosh Command 键：输出 384。开关 = & 256（系统会使用它，因此只有在 Windows 上与 "alt" 同时按下时才报告）
Shift 键：输出 640。开关 = & 512
Caps Lock 键（开启）：输出 1152。开关 = & 1024
Windows Alt 键：输出 2176。开关 = & 2048（系统会使用它，因此只有在 Windows 上与 "cmd" 或 "ctrl" 同时按下时才报告）
Macintosh Option 键：输出 2176。开关 = & 2048
Windows 鼠标右键：输出 4224。开关 = & 4096（系统会使用它，因此只有在 Windows 上与 "alt" 同时按下时才报告）
Macintosh Control 键：输出 4224。开关 = & 4096

第四个出口：所键入键的平台无关键码。
