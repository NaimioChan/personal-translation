ifft~

逆快速傅里叶变换

描述

ifft~ 对输入信号执行逆 FFT（快速傅里叶逆变换）。

参数

number-of-IFFT-samples [int] 可选

第一个参数指定 IFFT 的点数（采样点数）。它必须是 2 的幂。默认点数是 512。最小点数是 16。FFT 的最大点数是 1048576。

interval [int] 可选

第二个参数指定连续两次 IFFT 之间的采样点数。该值必须不小于点数，而且也必须为 2 的幂。默认间隔是 512。

offset [int] 可选

第三个参数指定 IFFT 在间隔内开始的偏移量。该值必须为 0，或者为信号向量大小的整数倍。

特性

fftsize [int]

FFT Size 是 IFFT 的点数（采样点数）。它必须是 2 的幂。默认点数是 512。最小点数是 16。FFT 的最大点数是 1048576。对该值的任何改动都会在下次打开信号处理时生效。

float32 [int]

若启用 float32，IFFT 将使用 32 位浮点精度执行。这样就能借助 SIMD 优化过的代码获得更快的性能。若启用了 legacy，则忽略该标志。对该值的任何改动都会在下次打开信号处理时生效。

interval [int]

连续两次 IFFT 之间的采样点数。该值必须不小于点数，而且也必须为 2 的幂。默认间隔是 512。对该值的任何改动都会在下次打开信号处理时生效。

legacy [int]

若启用 legacy，IFFT 将使用没有 SIMD 优化的 legacy IFFT 实现来执行。对该值的任何改动都会在下次打开信号处理时生效。

offset [int]

IFFT 在间隔内开始的偏移量。该值必须为 0，或者为信号向量大小的整数倍。对该值的任何改动都会在下次打开信号处理时生效。

消息

phase

执行 IFFT 时相对于一个周期起点的偏移量

参数：

  • offset [int]

signal

左入口：将被逆变换的复信号的实部。

右入口：将被逆变换的复信号的虚部。

若只有左入口和左出口连接了信号，则执行实数 IFFT（快速傅里叶逆变换）。否则执行复数 IFFT。

输出

signal

左出口：输入的逆傅里叶变换的实部。输出在输入的所有的点都接收完毕之后才开始。

中间出口：输入的逆傅里叶变换的虚部。输出在输入的所有的点都接收完毕之后才开始。

右出口：一个同步 signal，在 IFFT 输出期间从 0 递增到点数减 1。当 IFFT 不输出时（即间隔大于点数的情形），该同步 signal 为 0。
