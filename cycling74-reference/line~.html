MSP

line~

线性信号斜坡发生器

描述

使用 line~ 对象可以生成信号斜坡或包络。它使用 Max 的 时间格式语法；包络时间既可以是由单一取值固定下来的，也可以与速度相关。

讨论

line~ 对象在启用 Scheduler in Audio Interrupt 时是采样点精确的。更多细节见此处。

参数

initial-value [float or int] 可选

设置信号输出的初始值。默认值为 0。

特性

activeout [int] : 0

当 activeout 为 1 时，line~ 有第二个信号出口，斜坡处于活动状态时输出 1，不活动时输出 0。这个信号可以连接到 thispoly~ 或 mc.noteallocator~ 这类复音声部分配对象，以便在斜坡线活动期间保持忙碌状态。activeout 只能作为键入型参数设置给 line~。

maxpoints [int]

指定 line 中允许的用户自定义点的最大数量。默认值为 129 个点。maxpoints 只能作为键入型参数设置给 line~。

消息

int

左入口：该数字是目标值，将在右入口的数字所指定的时间内到达该值。若自上一个目标值以来未指定过时间，则时间视为 0，输出信号立即跳变到目标值。

右入口：该数字是时间，单位为毫秒，输出信号将在这段时间内到达目标值。

参数：

  • target-value/delta-time [int]

float

左入口：该数字是目标值，将在右入口的数字所指定的时间内到达该值。若自上一个目标值以来未指定过时间，则时间视为 0，输出信号立即跳变到目标值。

右入口：该数字是时间，单位为毫秒，输出信号将在这段时间内到达目标值。

参数：

  • target-value/delta-time [float]

list

左入口：第一个数字指定一个目标值，第二个数字指定 line~ 到达该目标值所用的总时间（单位：毫秒）。在指定的时间内，line~ 会从当前值生成一条斜坡信号到目标值。

line~ 在一个列表中最多接受 128 个“目标-时间”对，用来生成复合斜坡。（例如 0 1000 1 1000，它会从当前值在一秒内变到 0，再在一秒内变到 1。）一旦其中一条斜坡到达它的目标值，下一条就开始。左入口随后收到的 list、float 或 int 会清除所有尚未生成的斜坡。

由一个数字后跟一个逗号以及最多 128 个“目标-时间”对组成的列表会为斜坡设置初始值。例如 0, 1 1000 会设置初始值 0、新值 1 和目标时间 1000 ms。

右入口：可以用一个列表以 Max 的某种 时间格式来指定时间。

参数：

  • target-value [float]
  • delta-time [number]

anything

左入口：第一个数字指定一个目标值，第二个数字指定 line~ 到达该目标值所用的总时间（单位：毫秒）。在指定的时间内，line~ 会从当前值生成一条斜坡信号到目标值。

line~ 在一个列表中最多接受 128 个“目标-时间”对，用来生成复合斜坡。（例如 0 1000 1 1000，它会从当前值在一秒内变到 0，再在一秒内变到 1。）一旦其中一条斜坡到达它的目标值，下一条就开始。左入口随后收到的 list、float 或 int 会清除所有尚未生成的斜坡。

由一个数字后跟一个逗号以及最多 128 个“目标-时间”对组成的列表会为斜坡设置初始值。例如 0, 1 1000 会设置初始值 0、新值 1 和目标时间 1000 ms。

右入口：可以用一个列表以 Max 的某种 时间格式来指定时间。

参数：

  • target-value [float]
  • delta-time [number]

pause

左入口：暂停内部斜坡，但不改变目标值，也不清除待处理的目标-时间对。line~ 会继续输出收到 pause 消息时它当时的值，直到收到 resume 消息或输入新的斜坡为止。

resume

左入口：若 line~ 对象此前因 pause 消息而暂停，则恢复其内部斜坡以及后续待处理的目标时间对。

stop

左入口：停止内部斜坡并清除待处理的目标时间对。line~ 会继续输出收到 stop 消息时它当前所持有的取值，并把其目标取值重置为该值。

输出

bang

右出口：当 line~ 生成完其所有斜坡后，会送出 bang。

signal

左出口：当前的目标取值，或者根据当前存储的取值与目标时间朝目标取值移动的斜坡。

signal

中间出口：若启用了 activeout，line~ 会多出一个信号出口，当对象的斜坡处于活动状态时输出 1。
