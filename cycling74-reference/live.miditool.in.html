Max for Live

live.miditool.in

获取 Live 中 MIDI 片段的音符与上下文数据。专为在 MIDI Tool Generator 或 MIDI Tool Transformation 中使用而设计。

描述

live.miditool.in 对象用在 MIDI Tool Generator 或 MIDI Tool Transformation 中，负责获取 Live 中当前选中片段的音符与上下文信息。与 live.miditool.out 对象配合，你可以开发出可从 Tool Tabs 控制和触发的生成式或转换式流程。

讨论

live.miditool.in 对象是 Max for Live MIDI Tool 的基本构件，只能在类型为 Note Generator 或 Note Transformation 的 AMXD 中使用。它无法在 Audio Effect、MIDI Effect 或 Instrument 设备中工作。

当 live.miditool.in 收到 bang 时，它会开始一个新的 apply cycle，或继续现有的 apply cycle。开始 apply cycle 会获取当前选中片段的音符与上下文信息。音符以字典形式从最左出口送出，上下文信息以字典形式从中间出口送出。在 MIDI Tool 之外进行用户交互，例如选中另一个片段，会导致 apply cycle 停止。下次收到 bang 时，会开始一个新的 apply cycle。继续 apply cycle 会返回你开始该 cycle 时那个片段的音符与上下文信息；如果你在上一个 cycle 中改动了该片段，返回的信息不会反映它更新后的状态。如果在 Tool Tabs 中点击 "Apply" 按钮，一次交互就会开始并结束一个 cycle。最右出口用于接收 Live 发来的、与 apply cycle 无关的通知。例如，当用户选中某个音域时，Live 会通过该出口送出一条 "pitch_range" 消息。
