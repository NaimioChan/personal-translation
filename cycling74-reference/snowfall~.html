MSP

snowfall~

相位器驱动的粒子

描述

snowfall~ 对象把一个多维粒子控制为一条或多条音频斜坡，其寿命由从 0 到 1 的输入相位器斜坡触发并控制。该对象通常会在一个由准独立粒子组成的更大系统中使用，此时通过 MC 包装把它用作 mc.snowfall~。

参数

dimenions [int] 可选

设置维度数（1 - 4），它决定信号输出的个数。默认值为 1。

特性

boundarymode [int]

boundarymode 特性控制粒子输出取值达到当前 minimum 或 maximum 时会发生什么。它对所有维度都是全局的。
可选值：

0 = 'bounce' （反弹模式）
使粒子反转其当前方向。

1 = 'end' （结束模式）
使粒子停止输出；信号输出将变为零。

2 = 'wrap' （回绕模式）
使粒子移动到相反的边界。若粒子达到当前最大值，其取值会跳到最小值。若粒子达到当前最小值，其取值会跳到最大值。

3 = 'clip' （限幅模式）
粒子的取值保持在边界取值（最大值或最小值）上。

dimensions [int]

设置维度数（1 - 4），它决定信号输出的个数。默认值为 1。dimensions 特性在对象创建后无法更改。它可以通过参数或键入型特性设置。

direction [4 floats]

direction 包含最多四个取值，每个维度一个。
粒子启动时，direction 特性决定其运动速度。该取值以每秒的单位数表示。例如，direction 设为 5 时，意味着输出取值会在一秒内增加 5。若 direction 特性为负，输出取值往往会随时间减小。若 direction 特性为正，输出取值往往会随时间增大。

directiondev [4 floats]

directiondev 包含最多四个取值，每个维度一个。
设置围绕 direction 取值的随机偏差，该取值用于设定粒子的速度与方向。

endmode [int]

设置粒子结束时的行为，无论是因触及最大或最小边界而结束，还是因输入信号重置或归零而结束。
可选值：

0 = 'End Value' （设为结束取值）
当 endmode 设为 End Value 时，粒子结束时输出被设为 endvalue 特性的当前取值。

1 = 'Current Value' （保持在当前取值）
当 endmode 设为 Current Value 时，粒子结束时输出保持在其当前取值上。

endvalue [4 floats]

endvalue 包含最多四个取值，每个维度一个。
设置粒子寿命结束时输出的取值。

energyramp [4 floats]

energyramp 包含最多四个取值，每个维度一个。
作为粒子计算的一部分，energyramp 会与传入的 0 - 1 斜坡信号取值相乘。若你不希望粒子随输入斜坡取值增大而移动得更快，请把 energyramp 设为零。

initial [4 floats]

initial 包含最多四个取值，每个维度一个。
设置粒子的起始输出取值。

initialdev [4 floats]

initialdev 包含最多四个取值，每个维度一个。
设置围绕初始取值的随机偏差，该初始取值用于选择起始输出取值。

interval [float]

设置新粒子轨迹计算之间的时间间隔（单位为毫秒）。

intervaldev [float]

设置围绕 interval 取值的随机偏差，该取值用于选择更新间隔。

max [4 floats]

max 包含最多四个取值，每个维度一个。
设置粒子的最大边界取值。粒子一旦达到该取值，其行为就由 boundarymode 特性的当前设定决定。

min [4 floats]

min 包含最多四个取值，每个维度一个。
设置粒子的最小边界取值。粒子一旦达到该取值，其行为就由 boundarymode 特性的当前设定决定。

scalemax [4 floats]

scalemin 包含最多四个取值，每个维度一个。
设置粒子输出取值的缩放系数。粒子的取值始终介于缩放最小值与缩放最大值之间。

scalemin [4 floats]

scalemax 包含最多四个取值，每个维度一个。
设置粒子输出取值的缩放系数。粒子的取值将始终 bettern 缩放最小值与缩放最大值。

squish [4 floats]

squish 包含最多四个取值，每个维度一个。
当 boundarymode 特性设为 Bounce 时，squish 特性会与粒子方向反转的力度相乘。

startmode [int]

起始模式
可选值：

0 = 'Initial Value'
1 = 'Current Value'

wanderprob [4 floats]

wanderprob 包含最多四个取值，每个维度一个。
设置在任何一次特定更新时方向发生反转的概率。请注意，interval 越小，wanderprob 的效果就越强。

消息

signal

相位器斜坡的起始会使粒子开始其输出信号斜坡。通常粒子的输出会在输入斜坡重置为零时结束。
