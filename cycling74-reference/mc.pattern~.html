MC

mc.pattern~

信号模式音序器与录音器

描述

mc.pattern~ 对象保存模式——即信号取值组成的序列。与 seq~ 一样，播放由 phasor 驱动，但与 seq~ 不同，它的输出由一个或多个音频通道上的信号构成。除了事件录音，mc.pattern~ 还有一个用于从 Max 消息或通过算法生成事件的接口。

参数

channels [int] 可选

若给出键入型参数，它设置对象所含模式的通道数。这也可以通过 chans 特性设置。

特性

autorecord [int] : 0

把 autorecord 设为 1，mc.pattern~ 便开始把入口收到的传入数字录制到从通道 1 开始的后续各个通道。每个通道到达末尾后（因为传入的 phasor 信号复位为 0），录制会切换到下一个通道。当所有通道都录制过一次后，autorecord 会自行关闭。若想在自动关闭发生之前关掉 autorecord，请发送 autorecord 0 消息。autorecord 是记录 int 与 float 取值的唯一方式。按通道录制（通过 record 消息）需要一个由通道和取值组成的 list。请注意，赋予已录制取值的时间是相对于当前 phasor 输入取值的，而不是你开始录制的时间。

chans [int]

设置保存模式的通道数，以及多通道信号中的信号数量。若在音频开启时设置 chans 特性，该改动要到重启音频后才生效。

defaultmute [int] : 0

以键入型参数的方式为所有通道设置默认静音设置。对象创建之后，再改变 defaultmute 没有效果。defaultmute 的默认值是关闭静音。

defaultquantize [float] : 0.

以键入型参数的方式为所有通道设置默认录制量化设置。对象创建之后，再改变 defaultquantize 没有效果。defaultquantize 的默认值是 0。

defaultramp [int] : 0

以键入型参数的方式为所有通道设置默认斜坡设置。对象创建之后，再改变 defaultramp 没有效果。default 的默认值是关闭斜坡。

defaultwrap [int] : 0

以键入型参数的方式为所有通道设置默认回绕设置。对象创建之后，再改变 defaultwrap 没有效果。defaultwrap 的默认值是关闭回绕。

embed [int] : 0

启用 embed 后，对象的当前状态会随补丁一起保存。

immediate [int] : 1

启用 immediate 后，凡是被录制或添加到模式中的取值，只要其时间在当前输入信号位置之后，就会被播放。禁用 immediate 后，新录制或新添加的取值要到输入信号复位后才会播放。

in [float] : 1.

in 特性定义会使 mc.pattern~ 产生输出的输入信号范围。通常 in 为 1，这允许 mc.pattern~ 由 phasor~ 对象驱动。若把 in 设为 10，那么你需要提供一个从 0 到 10 的斜坡才能播放整个模式。in 的取值不影响模式取值的已存储相位。你可以用 ref 特性重新定义已存储相位的范围。

individual [int] : 0

启用 individual 特性后，每个通道由多通道信号中相应输入通道上的一个 phasor 驱动。若输入通道少于输出通道，多出来的输出会被静音。禁用 individual 时，单个 phasor 驱动所有通道。请注意，individual 模式会影响录制，因此若两个通道的输入 phasor 不同步，同时发往这两个通道的同一个取值录制下来的位置可能不同。

ref [float] : 1.

ref 特性设置模式中事件相位的最大值。通常 ref 为 1，这意味着事件的相位取值将在 0 到 1 之间。若把 ref 设为 10，事件的相位取值就可以在 0 到 10 之间。改变 ref 时，mc.pattern~ 中存储的所有取值都会被重新缩放，使其相对位置与之前相同。

消息

int

转换为 float

float

音频开启时，录制通过 autorecord 消息处于活动状态，传入的数字会被录制到当前正在自动录制的通道。所有已录制的取值都会加到该通道上已有的数据之上。若想把取值录制到特定通道，请使用 list 消息。

list

音频开启时，若该通道已启用录制，一条含两项的 list 消息会把列表中的第二项录制到列表第一项指定的通道。例如，若通道 1 已启用录制，消息 1 0.4 会把取值 0.4 录制到通道 1。

add

add 消息向一个通道添加一个值。它接受三个必需参数。第一个是要添加值的通道。若该通道为 0，该值会被添加到所有通道。第二个参数是把该值添加到模式中的时间（介于 0 与 1 之间）。第三个参数是该值。add 消息无论音频开启还是关闭都会生效。同样，对于你正在添加值的通道，录音也不必处于开启状态。

addrange

addrange 消息向一个通道添加一段范围的值。它至少接受四个必需参数。第一个是要添加值的通道。若该通道为 0，这些值会被添加到所有通道。第二个参数是要添加的值的个数。若有四个参数，第三个参数指定要添加的那段范围的下限值，第四个参数指定要添加的那段范围的上限值。这种情况下，这些值是在整个模式的空间内（介于 0 与 1 之间）添加的。若有六个参数，第三个和第四个指定时间范围，第五个和第六个参数指定取值范围。时间范围必须从低到高指定，且这两个值不能相等。例如：addrange 1 5 10 20 会向通道 1 添加下列值：0 10、0.2 12.5、0.4 15、0.6 17.5 0.8 20。注意 addrange 消息并不会用满你指定的整段时间。若想填满整段时间，请使用 addrangeinclusive。

addrangeinclusive

addrangeinclusive 消息向一个通道添加一段范围的值。它的功能与 addrange 消息完全相同，区别在于它会用这段取值填满整段时间。只有当时间范围被明确指定时才建议这样做；换句话说，如果你试图填满 0 到 1 的时间范围，最终得到的事件会比你指定的少一个，因为位于 1 的最后一个事件会覆盖位于 0 的第一个事件，毕竟 0 和 1 代表同一时间。例如：addrange 1 5 0.2 0.4 10 20 会向通道 1 添加下列值：0.2 10、0.25 12.5、0.3 15、0.35 17.5、0.4 20。

clear

没有参数时，单词 clear 会移除所有通道的全部值。后面跟一个通道编号时，clear 会移除单个通道的全部值。

delete

单词 delete 后面跟一个通道编号和一个时间，会移除指定通道编号上与该时间关联的任何值。例如：若此前已通过 add 1 0.5 50 向通道 1 添加了值 50，发送 delete 1 0.5 就会把它移除。

deleterange

单词 deleterange 后面跟一个通道编号和两个指定时间范围的数字，会移除落在该时间范围内的所有值。

dictionary

用 dictionary 消息可以用新数据设置一个或多个通道。你可以通过发送 getcontent 消息来查看字典要求的格式，该消息会把包含 mc.pattern~ 当前状态的字典从右出口送出。与读入一份新内容并使用 read 消息不同，dictionary 消息只会用新内容清除字典中所含通道已有的模式。这让你可以构造一个只修改单个通道的字典，而其他通道保持不动。

dump

dump 消息会在 Max 控制台中打印所有通道的所有时间和值。

filldeviate

filldeviate 消息向所有通道添加值。它接受三个或四个参数。当 filldeviate 有三个参数时，第一个参数是这些值所处的时间位置，第二个参数是所生成值的中心值，第三个参数是相对该中心值的偏移量。当 filldeviate 有四个参数时，第一个参数是中心时间位置，第二个参数是相对中心时间的偏移量，第三个参数是中心值，第四个参数是取值偏移量。例如：filldeviate 0.5 2 1 对一个四通道的 mc.pattern~ 可能生成如下结果：通道 1 -- 0.5 1.7，通道 2 -- 0.5 2.1，通道 3 -- 0.5 2.9，通道 4 -- 0.5 1.8。

fillrange

fillrange 消息向所有通道添加一段递增或递减的取值。它接受两个、三个或四个参数。当 fillrange 有两个参数时，第一个参数是这些值所处的时间位置，第二个参数是该值。该值会在指定的时间添加到所有通道。
当 fillrange 有三个参数时，第一个参数是一个时间，第二个和第三个参数指定一段范围。从第二个参数指定的值开始，fillrange 向所有通道添加值，逐个递增或递减，直到最后一个通道的值等于第三个参数。若 fillrange 有四个参数，前两个参数是一段范围的时间，后两个参数是一段范围的值。例如：fillrange 0.25 0.75 1 4 对一个四通道的 mc.pattern~ 会生成如下结果：通道 1 -- 0.5 1，通道 2 -- 0.375 2，通道 3 -- 0.5 3，通道 4 -- 0.625 4。

getcontent

getcontent 消息会把包含当前模式数据的字典从右出口送出。

mute

若 mute 消息有一个参数，则该值为非零时所有通道都被静音，该值为零时解除静音。若 mute 消息有两个参数，第一个参数指定要静音的通道编号，第二个参数是静音状态。注意 mute 是 mc.pattern 对象提供的唯一一种禁用一个或多个通道输出的方式；没有播放 / 暂停控制。要暂停播放，请把输入 phasor~ 的频率设为零。

quantize

quantize 消息为一个或多个通道设置录音量化值。若 quantize 有一个参数，它为所有通道设置录音量化。若 quantize 有两个参数，第一个参数指定通道编号，第二个参数设置量化值。量化值应小于或等于 1；当量化值非零时，录制下来的值会在时间上平移，使其时间为量化值的整数倍。录音量化对通过 add 或 fill 消息添加到通道的值没有影响。

ramp

ramp 消息接受一个或两个参数。若 ramp 有一个参数，它设置所有通道是否使用线性输出斜坡。若 ramp 有两个参数，第一个参数指定通道编号，第二个参数启用或禁用播放斜坡。斜坡被禁用时，输出信号在送出一个值之后保持恒定，随后才跳到新的值。斜坡被启用时，mc.pattern~ 会输出一条从上一个值到当前值的线性斜坡。模式开头和结尾处的斜坡行为受该通道回绕状态的影响（见下面的 wrap）。

read

read 消息接受一个可选的文件名参数。若未给出文件名，会显示标准的打开对话框。mc.pattern~ 接受由 write 消息生成的 JSON 格式文件。

record

record 消息接受一个或两个参数。只有一个参数时，它开始（非零）或停止（录音）。有两个参数时，第一个参数设置通道编号，第二个参数在该通道上开始（若非零）或停止（若为零）录音。注意，赋予录制值的那些时间是相对于当前 phasor 输入值而言的，而不是你开始录音的时间。

setvalue

setvalue 消息提供了另一种语法，用来把消息发送到指定的通道或所有通道。消息的格式是 setvalue 后面跟一个通道编号，再后面是发往该通道的消息。可以跟在 setvalue 后面的消息有 add、clear、delete、deleterange、float、int、list、quantize、ramp、record 和 wrap。使用这些消息时要省略通道编号，因为它已经写在 setvalue 一词的后面。例如，若想删除通道 2 上时间 0.5 处的事件，可以写成 setvalue 2 delete 0.5。

signal

mc.pattern~ 对象的模式播放可以由其音频输入中一个或多个相位器斜坡驱动。若启用了 individual 特性，mc.pattern~ 会期待一个多通道信号，其中每个通道都有一个相位器，用于播放对象多=-通道输出中对应的通道。若 individual 被禁用，则由单个相位器斜坡信号一起播放所有模式。

wrap

wrap 消息接受一个或两个参数。若 wrap 有一个参数，它设置是否使用输出回绕。若 wrap 有两个参数，第一个参数指定通道编号，第二个参数启用或禁用输出回绕。回绕被禁用时，输出值在模式的开头（即输入 phasor 复位时）被设为零。回绕被启用时，初始输出值是模式结束前的最后一个值。

write

write 消息接受一个可选的文件名参数，用来指定文件的写入位置。若未给出文件名，会显示标准的保存文件对话框。mc.pattern~ 写出的文件为 JSON 格式，与 getcontent 消息输出的字典相对应。
