Max

serial

从串口发送和接收

参数

port [symbol] 可选

指定 serial 对象要使用的串口。若使用字母快捷方式（a-z），a 指定计算机中的第一个逻辑串口，而 b- z 用于指定其他端口。

portname [symbol] 可选

若使用实际的 portname，则该符号是操作系统为你的端口指定的名称。print 到 serial 对象可用于生成可用 portname 和字母快捷方式的列表。若所选端口在 serial 对象实例化时正在使用或不可用，则会显示错误消息，且该对象将无法工作。若未指定端口，默认端口为 a。

rate [int] 可选

端口名或字母快捷方式之后可以使用一个可选参数来指定该串口的波特率（默认速率为 4800 波特）。任何值都允许（尽管并非所有端口都能设为所有波特率）。一些常见速率为 300、600、1200、1800、2400、3600、7200、9600、19200、38400、57600 和 115200。

data [int] 可选

波特率之后，下一个参数指定该串口的数据位数（默认为 8 个数据位）。其他可选值为 5、6 和 7。

stop [int] 可选

下一个参数指定该串口的停止位数。默认为 1。其他可选值为 1.5（仅 Windows）和 2。

parity [int or symbol] 可选

下一个参数指定该串口的校验方式（默认为无校验，用 0 或 no 指定）。其他可选值为 1（奇校验）和 2（偶校验）。

特性

asyncread [int] : 0

默认情况下（0 = Off），只有当 bang 到达，或启用了 poll 时，该对象才从串口读取。启用时（1 = On），读取会在后台定期进行，bang 消息（或轮询）会使异步读取的字节被输出。

autoopen [int]

切换是否自动打开串口。

baud [int]

指定该串口的波特率（默认速率为 4800 波特）。任何值都允许（尽管并非所有端口都能设为所有波特率）。一些常见速率为 300、600、1200、1800、2400、3600、7200、9600、19200、38400、57600 和 115200。

break_duration [int] : 1000

指定 break 信号的持续时间，以微秒为单位（默认持续时间为 1ms，即 1000us）。某些应用程序（如 DMX）在标记帧时要求 break 持续时间处于特定范围内。

bufsize [int]

设置 serial 对象使用的输入缓冲区大小。默认缓冲区大小为 2048。

chunk [int]

设置用于输出的数据块大小（数据列表长度）。

databits [int]

设置数据位数（可接受的值为 5、6、7 或 8）。

defer [int] : 1

把消息的输出推迟到优先级较低的主线程。在使用 Overdrive 时最为适用。

drain [int]

（仅 Mac）切换 drain 启用状态。启用后，写入时通信会等待所有数据都已传输到终端。默认值为 0（禁用）。

dtr [int] : 2

启用或禁用 serial 对象所用串口的 DTR（data terminal ready）功能。
可选值：

0 = 'off' （ 禁用 DTR ）
1 = 'on' （ 启用 DTR ）
2 = 'default' （ 使用连接默认值（不更改） ）

parity [int]

设置该端口的校验方式。可选值为 0（无）、1（奇）和 2（偶）。

poll [float] : 0.

若为非零，该特性的取值决定轮询数据的间隔毫秒数。你可以用它来代替连接一个 metro，以固定的间隔向 serial 对象发送 bang。为零时，轮询被禁用。

postbreak_duration [int] : 0

指定 break 之后 'mark'（也称为 Mark After Break，或 MAB）的持续时间，以微秒为单位。默认 MAB 为 0us（即没有 MAB）。某些应用程序（如 DMX）在标记帧的开头时需要 MAB。

rts [int] : 2

启用或禁用 serial 对象所用串口的 RTS（Request To Send）线。注意这并不实现流控制。
可选值：

0 = 'off' （ 禁用 RTS ）
1 = 'on' （ 启用 RTS ）
2 = 'default' （ 使用连接默认值（不更改） ）

serport [int]

仅供对象 Inspector 使用。用户应使用 port 消息。

stopbits [int]

设置与串口通信时使用的停止位数。可选值为 1（1 个停止位）或 2（2 个停止位）。在 Windows 上，取值 15 和 1.5 可用于 1.5 个停止位（macOS 不支持）。

xonxoff [int] : 2

启用 Xon/Xoff 串口流控制。
可选值：

0 = 'off' （ 禁用 Xon/Xoff 流控制。 ）
1 = 'on' （ 启用 Xon/Xoff 流控制。 ）
2 = 'default' （ 使用连接默认值（不更改） ）

切换补丁锁定后对象是否忽略鼠标点击。

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

可选值：

0 = 'left'
1 = 'center'
2 = 'right'

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'

3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

把自上次 bang 消息以来在串口上收到的每个字符，按字符收到的顺序以整数形式从 serial 对象的左出口送出。在输出数据送出之前，消息 read（后跟一个指定已收到字节数的数字）会从 serial 对象的右出口送出。

int

把该数字从 serial 对象访问的串口送出。超出 0-255 范围的数字会用取模运算符回绕到该范围。在数据送出之后，消息 write（后跟一个指定已发送字节数的数字）会从 serial 对象的右出口送出。

参数：

  • input [int]

float

转换为 int。

参数：

  • input [float]

list

把列表中的每个数字按顺序从串口送出。超出 0-255 范围的数字会用取模运算符回绕到该范围。在数据送出之后，消息 write（后跟一个指定已发送字节数的数字）会从 serial 对象的右出口送出。

参数：

  • input [list]

break

向 serial 对象使用的串口发送一条 break 命令。break 完成后，消息 break 会从该对象的右出口送出。

close

关闭已打开的串口连接，从而允许其他应用程序使用该串口。

getport

把当前打开的串口的名称或快捷方式从 serial 对象的右出口送出，前面加上单词 port。

open

打开一个新的串口连接。

port

单词 port 后跟一个符号，指定该对象要使用的串口。若使用字母快捷方式，a 指定计算机中的第一个逻辑串口。b - z 指定其他端口。若使用实际的 portname，则该符号是操作系统为你的端口指定的名称。有关列出可用 portname 和字母快捷方式的方法，请参见 print 消息。若所选端口在发送 port 消息时正在使用或不可用，则会显示错误消息，且该对象会回退到先前选择的端口；若之前没有选择过端口，则该对象将无法工作。

参数：

  • port [list]

print

把可用串口的列表及其字母快捷方式发送到 Max Console。消息 port [portname] [portname]... 也会从该对象的右出口送出，并附带可用端口的列表。

refresh

刷新已知/可用串口的列表。更多信息请参见 print 消息。

reset

（仅 Mac）使用 Basic Stamp 初始化序列重置当前打开的串口。

输出

(serial output)

当其入口收到一个数字或列表时，serial 会以当前波特率把数据从指定的串口送出。

int

当 serial 收到 bang 消息且串口上已收到字符时，收到的字符会按其收到的顺序以数字形式送出。

list

当 serial 收到 bang 消息、串口上已收到字符且已启用分块时，收到的字符会按其收到的顺序以列表形式送出。列表的长度由 chunk 消息的参数决定（更多信息请参见 chunk 的消息列表）。

右出口：报告错误和状态消息。
