MSP

adsr~

ADSR 包络发生器

描述

adsr~ 对象是一个可由信号控制的 Attack-Decay-Sustain-Release 信号。在某些情况下，function 与 line~ 对象的组合可能是有用的替代方案。

讨论

触发入口中的任何非零取值都会触发一个包络，其振幅为该取值。就像由输入 float 触发的 adsr~ 一样，零值表示“note-off”，并会开始释放阶段。与事件触发模型不同，由信号触发的 adsr~ 必须先收到零才会重新触发。

adsr~ 对象使用 Max 的 时间格式语法；包络时间既可以用固定格式指定，也可以用相对于速度的格式指定。

参数

attack [float] 可选

初始的起音时间

decay [float] 可选

初始的衰减时间

sustain [float] 可选

初始的延音电平

release [float] 可选

初始的释音时间

特性

attack [Time Value] : 0 ms

以毫秒为单位设置 ADSR 包络的起音。

decay [Time Value] : 0 ms

以毫秒为单位设置 ADSR 包络的衰减。

legato [int]

作为输入给出时，单词 legato 后面跟一个 0 或非零数字，会禁用或启用 legato 模式。若启用了 legato 模式，则包络处于活动状态时发生重新触发，包络不会落到零——而是会在起音时段内以斜坡过渡到新的振幅。

maxsustain [float]

作为输入给出时，单词 maxsustain 后面跟一个 float，设置包络停留在延音阶段的最长时间。负数表示不设上限；包络会永远停留在延音阶段，直到收到 note-off。若要创建一个简单的三段式无延音包络（ADR），可以使用消息 maxsustain 0.0。

release [Time Value] : 0 ms

以毫秒为单位设置 ADSR 包络的释音。

retrigger [float]

作为输入给出时，单词 retrigger 后面跟一个 float，设置当包络处于活动状态时发生重新触发、斜坡降到零所需的时间（默认为 5 毫秒）。这种斜坡处理可防止咔嗒声。

sustain [float]

设置 ADSR 包络的延音，以振幅的倍数表示。例如取值为 0.5 表示延音电平为振幅高度的一半。

triggermode [int]

triggermode 特性决定包络是等待收到零以完成释放阶段，还是一次触发后就一直播放到底。
可选值：

0 = 'ADSR'（常规 ADSR 触发）
在 ADSR 模式下，包络在收到非零信号或 float 时开始，并在收到零时开始释放阶段。

1 = 'Play to End'（播放到结束）
在 Play to End 模式下，包络开始并播放起音、衰减和释放段，在此期间忽略后续输入，直到包络完成。

消息

int

转换为 float

参数：

  • trigger/ADSR-parameters [int]

float

左入口：非零数字触发一个包络，其振幅为给定取值。包络会一直保持，直到输入零以触发释放阶段，或直到另一个非零 int 重新触发包络。

第二个入口：以毫秒为单位设置起音时间。

第三个入口：以毫秒为单位设置衰减时间。

第四个入口：设置包络的延音电平，以振幅的倍数表示。例如取值为 2 表示延音电平为振幅高度的两倍。

第五个入口：以毫秒为单位设置包络的释音时间。

参数：

  • trigger/ADSR-parameters [float]

list

由四个数字组成的 list 会设置起音、衰减、延音和释音取值。

参数：

  • attack [float]
  • decay [float]
  • sustain [float]
  • release [float]

anything

左入口：与 list 作用相同。

其他任何入口：list 可以用来按 Max 的其中一种时间格式指定时间。

参数：

  • attack [float]
  • decay [float]
  • sustain [float]
  • release [float]

signal

左入口：非零取值触发一个包络，并以该取值作为其振幅。包络开始后，零信号值会开始包络的释放阶段。若启用了 triggermode，即使信号为零，包络也会完整走完。

第二个入口：以毫秒为单位设置起音时间。

第三个入口：以毫秒为单位设置衰减时间。

第四个入口：设置包络的延音电平，以振幅的倍数表示。例如取值为 0.5 表示延音电平为振幅的一半。

右入口：以毫秒为单位设置释音时间。

输出

message

右出口送出 mute 消息，可用于管理内部 poly~ 实例的静音，配合 thispoly~ 对象使用。

message

第四个出口响应针对各种特性的查询消息（即 getattack）。

signal

左出口：包络。

中间出口：在处于起音、衰减或延音阶段时发送 1、其他情况（释放、重新触发或非激活）发送 0，以此标记包络的开始。你可以把此出口与 sah~ 对象配合使用，以采样点精度把音高（或其他信息）与包络的开始同步。
