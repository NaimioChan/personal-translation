关于矩阵运算符的更多内容

Jitter MOP

既然矩阵是 Jitter 的核心，大多数 Jitter 对象属于矩阵运算符这一类也就不奇怪了。每个矩阵运算符都有若干个矩阵输入和若干个矩阵输出。矩阵输入按从左到右的顺序用 "in"、"in2"、"in3" 等名称称呼，矩阵输出用 "out"、"out2"、"out3" 等名称称呼，即除最左边第一个输入和最左边第一个输出分别只叫 "in" 和 "out" 之外，其余名称都由输入/输出编号后缀而来。我们把输入或输出的名称称为 "I/O-name"。

矩阵输入和输出在内部通常各自持有保存信息的矩阵。这是必要的，因为 Jitter 是异步框架（也就是说，各个矩阵并不会同时到达所有输入）。矩阵输入和输出的若干方面可以用命令 [I/O-name] 加上下列后缀之一来设置："_dim" 设置指定 I/O 矩阵的维度，"_type" 设置指定矩阵的类型，"_planecount" 设置指定矩阵的通道数，"_name" 设置指定矩阵的名称。有一种特殊情况没有任何内部矩阵，就是第一个输入 "in"。这是因为该特殊输入实际上触发矩阵运算符的计算，所以不像其他输入那样需要缓存到计算发生为止。因此没有机制可以设置 "in" 的 dim、planecount、type 或 name。

矩阵运算符接受我们称为「matrix args」的参数，即 [planecount (int)] [ type (symbol)] [dim (int list)]。若给出了这些参数，adapt 特性会被关闭，否则会被打开。若 adapt 模式打开，则每当第一个输入收到矩阵时，就相当于把 dim、planecount 和 type 特性设置为该输入矩阵的对应值。若其他输入和输出链接到这些特性，它们所链接的特性也会随之改变。adapt 模式打开时哪些输入和输出会链接到哪些特性，请查阅「MOP」表。最左侧的输入不适用该规则，因此该行所有列都标记为 "n/a"。

jit.matrix 对象是一个具名矩阵，可用于矩阵数据的存储与取出、重采样，以及矩阵类型与 planecount 转换等操作。

MOP 参数

planecount [int] 可选

显式设置输出以及右侧各输入的通道数。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

type [symbol] 可选

显式设置输出以及右侧各输入的矩阵类型。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

dimensions [list] 可选

显式设置输出以及右侧各输入的矩阵维度。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

MOP 特性

adapt [int]

矩阵自适应标志（若给出了矩阵参数则默认值为 0，否则为 1）。该标志置位时，jit.matrix 对象会自适应输入矩阵的 planecount、type 和 dimensions。

[in/out]_dim [32 ints]

矩阵数据的维度（默认值 = 1 1）

[in/out]_name [symbol]

矩阵输入或输出的名称（默认值 = UID）

[in/out]_planecount [int]

矩阵输入或输出数据的通道数。除特殊情况外，该值等于 planecount。

[in/out]_type [symbol]

输入或输出矩阵的数据类型。除特殊情况外，该值等于 type。

outputmode [int]

输出模式（默认值 = 1（计算并输出矩阵））
0 = 无输出（不计算）
1 = 计算并输出矩阵
2 = 透传输入（不计算）
3 = 透传输出（不计算）

type [int]

矩阵数据类型（默认值 = char
支持的数据类型有 char、long、float32 和 float64。

参数：

outputmatrix

把矩阵从左出口送出。

summary

从对象最右出口送出一串列表，描述对象及其特性和消息。第一行的形式为 summary objectname object-name。第二、三行用 summary (matrixinputcount/matrixoutletcount) number-of-(inlets/outlets) 的形式给出对象的入口和出口数量。第四行用 summary matrixoutput descriptor planelink planelink-value typelink typelink-value dimlink dimlink-value types data-type(s) 的形式描述 matrixoutput。随后逐条列出对象的每个特性，每条特性一行。每行的形式为 summary attribute attribute-name attribute-value1 attribute-value2 ... attribute-valueN。

  • top [int]
  • bottom [int]
  • right [int]
  • 互斥组
    color-index [int]
    red [int]
    green [int]
    blue [int]
    互斥组结束

paintpoly

绘制由最多 254 个整数 x/y-pair 参数所指定的多边形。每个整数对以一个像素为单位，相对于 jit.lcd 对象显示区的左上角。指定的 x/y 对与第一个整数对取值相同时，多边形就会闭合。

参数：

  • x/y int pairs [list]

paintrect

绘制由 left、top、right 与 bottom 整数参数所指定的矩形。边缘位置以像素为单位，相对于 jit.lcd 对象显示区的左上角。其后还可以跟用于指定矩形颜色的可选附加参数。若使用单个整数参数，它指定 Max 调色板中的一种颜色。三个整数参数指定一种 RGB 颜色。

参数：

  • left [int]
  • top [int]
  • bottom [int]
  • right [int]
  • 互斥组
    color-index [int]
    red [int]
    green [int]
    blue [int]
    互斥组结束

paintroundrect

绘制一个圆角矩形。left、top、right 与 bottom 整数参数描述该矩形的上下端点，而 horizontal-roundness 与 vertical-roundness] 整数参数指定以像素为单位的圆角量。圆角矩形的位置相对于 jit.lcd 对象显示区的左上角。其后还可以跟用于指定矩形颜色的可选附加参数。若使用单个整数参数，它指定 Max 调色板中的一种颜色。三个整数参数指定一种 RGB 颜色。

参数：

  • left [int]
  • top [int]
  • bottom [int]
  • right [int]
  • horizontal-roundness []
  • vertical-roundness []
  • 互斥组
    color-index [int]
    red [int]
    green [int]
    blue [int]
    互斥组结束

penmode

设置后续绘制操作的传输模式。传输模式用 0-39 范围内的整数参数设置。由于 JUCE 不支持 pen mode，唯一可用的 penmode 是 32（Blend）。其他所有 penmode 都会被忽略。

参数：

  • penmode-index [int]

pensize

设置后续绘制操作要使用的笔粗细。笔粗细用两个整数参数设置，不过由于 QuickDraw 模拟上的差异，第二个参数不受支持。

参数：

  • number-of-pixels [int]

readpict

把 pict-name 符号所指定的图片文件从磁盘读入 RAM。随后就可以用 drawpict 与 tilepict 消息把这个具名图片绘制到 lcd 中。

参数：

  • pict-name [symbol]

reset

擦除 jit.lcd 对象显示区的内容，并把对象重置为其默认取值。该消息等价于发往 jit.lcd 对象的这一系列消息：
clear
pensize 1
penmode 0
frgb 0 0 0（黑色）
brgb 255 255 255（白色）

scrollrect

把 left、top、right 与 bottom 整数参数所定义的矩形按 x-offset 与 y-offset 整数参数所指定的方向移动或「滚动」，也就是把前四个参数在 jit.lcd 对象显示区内按第五、第六个 int 所指定的方向移动。

参数：

  • left [int]
  • top [int]
  • right [int]
  • bottom [int]
  • left [int]
  • x-offset [int]
  • y-offset [int]

setpixel

把由 x-offset 与 y-offset 坐标所指定位置的像素设置为 red、green 与 blue 参数所指定的 RGB 值。RGB 值应是 0-255 范围内的整数。像素位置是相对于 jit.lcd 对象显示区的左上角指定的。

参数：

  • x-offset [int]
  • y-offset [int]
  • red [int]
  • green [int]
  • blue [int]

textface

设置渲染文本时要使用的字体样式。字体样式可以用单个 symbol 参数逐一指定，也可以作为一个列表指定。有效的字体样式有 normal、bold、italic、underline、outline、shadow、condense 与 extend；

参数：

  • font-style [list]

textmode

用 0-39 范围内的整数参数设置文本渲染模式。支持的 textmode 有：
0 = Copy
1 = Or
2 = Xor
3 = Bic
4 = NotCopy
5 = NotOr
6 = NotXor
7 = NotBic
32 = Blend
33 = AddPin
34 = AddOver
35 = SubPin
36 = Transparent
37 = AddMax
38 = SubOver
39 = AddMin
关于每种渲染模式效果的更多信息，请参阅 Inside Macintosh 中的 QuickDraw 文档。

参数：

  • mode-index [int]

tilepict

通过平铺一张图片来填充矩形。可以用 jit.matrix 对象的名代替 PICT 文件的名，前提是该具名的 jit.matrix 对象是一个 4 通道的 char 数据矩阵。

可以用四个可选整数指定一个目标矩形，图片会平铺到该矩形中；还可以再加上四个整数，用于指定操作中要使用图片的哪一区域。目标矩形与源矩形用它们以像素为单位的左、上、宽、高值指定。目标矩形与源矩形是相对矩阵的左上角指定的。若未指定目标矩形，目标会被设为 lcd 矩阵的大小，源则设为与图片相同的大小。

参数：

  • pict-name [symbol]
  • dst-left [int]
  • dst-top [int]
  • dst-right [int]
  • dst-bottom [int]
  • src-left [int]
  • src-top [int]
  • src-right [int]
  • src-bottom [int]

write

用当前字体与 textmode 在当前笔位置写入 symbol 参数所指定的文本。

参数：

  • symbol [symbol]

writepict

把 jit.lcd 对象显示区的当前内容写入一个 PICT 文件。若没有给出文件名参数，会弹出一个 Save As 对话框，提示你选择写入 PICT 文件的文件名与位置。

参数：

  • filename [symbol]
