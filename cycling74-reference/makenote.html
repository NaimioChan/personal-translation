Max

makenote

生成一对 note-on/note-off

描述

输出一条 MIDI note-on 消息，它与一个力度值配对，并在指定时间之后跟随一条 note-off 消息。这样就可以进行生成式 MIDI 输出，而不必自己管理 note-off 的生成。

讨论

该对象使用 Max 的 time format 语法。makenote 对象用来指定 not-on 与 note-off 之间时间间隔的时值既可以是固定值，也可以是相对速度的（必须是单值）。还可以用第三个参数来指定 MIDI 输出通道（此时 makenote 对象会具有四个输入和三个输出）。

参数

velocity [number] 可选

设置初始力度值（int 或 float），用于与传入的音高数字配对。若没有参数，初始力度为 0。

duration [number] 可选

设置初始音符时值（即 note-off 送出之前的时间），可以使用 Max 的任意时间单位。简单的 int 或 float 会把时值设为毫秒。若第二个参数不存在，note-off 会紧接 note-on 之后。

channel [number] 可选

设置初始 MIDI 通道号。若使用第三个参数，makenote 对象会多出一个第四个入口（用于指定 MIDI 通道号）和一个额外的第三个出口（用于指定 MIDI 输出通道）。

特性

duration [Time Value] : 0 ms

makenote 在 note-off 消息送出之前所等待的时值。

repeatmode [int]

设置音符被再次触发时的行为。模式有：

repeatmode 0（默认）：在该音高的 note-off 送出之前重复某个音高时，没有预先指定的行为。
repeatmode 1：若再次触发某个仍在发声的音符，makenote 对象会发送一条 note-off（力度 0）消息来停止第一个音符，然后发送一条新的 note-on 消息。
repeatmode 2：若再次触发某个仍在发声的音符，makenote 对象会取消第一个音符已排定的输出——只有最后演奏的音符会发送 note-off（力度 0）消息。
repeatmode 3：若再次触发某个仍在发声的音符，makenote 对象会重新排定第一个音符的 note-off 输出，而不触发新的 note-on 消息。
repeatmode 4：若再次触发某个仍在发声的音符，makenote 对象会忽略被再次触发的音符，note-off 的时间不受影响。
可选值：

0 = 'Poly'
1 = 'Re-trigger'
2 = 'Stop Last'
3 = 'Update Duration'
4 = 'Ignore'

消息

int

第一个入口：该数字被当作 MIDI note-on 消息的音高值。它与一个力度值配对，这两个数字会送出各个出口。经过一定时间后，会为该音高送出一条 note-off 消息（力度为 0 的 note-on）。

第二个入口：该数字被存为力度，用于与左入口收到的音高数字配对。

第三个入口：该数字被存为 makenote 在 note-off 消息送出之前所等待的时值。
第四个入口：该数字指定一条 MIDI 输出通道。只有 makenote 对象以三个参数初始化时，第四个入口才会存在。

参数：

  • input [int]

float

第一个入口：该数字被当作 MIDI note-on 消息的音高值。它与一个力度值配对，这两个数字会送出各个出口。经过一定时间后，会为该音高送出一条 note-off 消息（力度为 0 的 note-on）。

第二个入口：该数字被存为力度，用于与左入口收到的音高数字配对。

第三个入口：该数字被存为 makenote 在 note-off 消息送出之前所等待的时值。
第四个入口：该数字指定一条 MIDI 输出通道。只有 makenote 对象以三个参数初始化时，第四个入口才会存在。

参数：

  • input [float]

list

左入口：第二个数字被当作力度，从右出口送出。第一个数字被当作音高，从左出口送出。稍后会送出一条对应的 note-off 消息。
若 makenote 对象以三个参数实例化，则可以使用一个四项列表，其中额外的第四个元素指定 MIDI 通道号，该值会从对象最右侧的出口送出。

参数：

  • input [list]

anything

与 list 作用相同。

参数：

  • input [list]

clear

清除 makenote 当前持有的所有音符，但不送出 note-off。

clock

clock 一词后面跟一个现有 setclock 对象的名称，会把 makenote 对象设为由该 setclock 对象控制，而不是由 Max 内部的毫秒时钟控制。clock 一词单独使用，会把 makenote 对象设回使用 Max 常规的毫秒时钟。

参数：

  • clock-name [symbol]

stop

使 makenote 为它当前持有的所有音高立即送出 note-off。

输出

int

左出口：左入口收到的数字会立即送出，并与另一个出口送出的力度值配对。经过一定时长后，同一个数字会与力度 0 配对送出。

右出口：中间入口中的数字会作为力度值送出，并与左出口送出的音高值配对。经过一定时长后，0 会与同一个音高配对送出。
