Max

console

补丁中的控制台输出

描述

在你的补丁中镜像并筛选发往 Max 窗口的消息。

讨论

从概念上讲，记住存在一个包含所有发往 Max 窗口的消息的全局列表会很有帮助。点击 Max 窗口中的 X 会清空一切。把 clear 消息发给 console 也同样如此。类似地，write 消息会写入所有数据，与筛选设置无关。

参数

无。

特性

classfilter [atom]

设置 classfilter 会使 console 对象只报告来自指定对象类的消息。例如，@classfilter print 会输出 print 对象接收到的任何内容，而不输出其他任何东西。

patcherfilter [atom]

patcherfilter 特性可以设置为任意补丁的名称，以把输出限制为由该补丁产生的控制台消息。你可以把 patcherfilter 设置为 "thispatcher"，以把输出限制为包含 console 对象的那个补丁所产生的消息。

showonlyerrors [int] : 0

把 console 对象的输出限制为只有 error 类型的消息。

textfilter [atom]

textfilter 特性需要一个单词或一串单词。设置后，它按消息内容筛选，放行与整个筛选字符串匹配的消息。筛选字符串可以是多元素的，不需要加引号。例如，textfilter foo bar 不会找到含 foo 或 bar 的内容，而会找到含 “foo bar” 的内容。筛选会包含报告该消息的对象的名称。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

clear

把 clear 消息发给任何 console 对象都会清空 Max 控制台窗口的全部内容。

write

把 write 消息发给任何 console 对象都会把 Max 控制台的全部内容写入一个文本文件，忽略所有筛选。可选的参数让你可以指定文件路径。若未提供文件路径，会打开一个文件浏览器窗口，让你指定写入位置。

参数：

  • filepath [symbol]
