MSP

plugsync~

报告宿主同步信息

描述

plugsync~ 对象提供有关 Ableton Live 宿主应用程序当前状态的信息。

讨论

在任何宿主中都能获得采样计数信息，连 Max 也不例外。该对象输出的其他信息是否有效，取决于宿主实现了哪些同步能力；flags（第 9 个）出口的取值会告诉你哪些信息有效。调度器运行时，plugsync~ 的输出是连续的。

参数

无。

消息

bang

bang 消息可用于手动轮询 plugsync~ 对象，使它输出计时信息。

输出

float

第四个出口：当前的拍内分数，从 0 到 1.0。如果宿主不支持同步，输出为 0。如果宿主不支持同步，该出口没有输出。

float

第六个出口：当前速度，以每拍的采样点数表示。该数字可以用以下公式换算为每分钟拍数：(sampling-rate / samples-per-beat) * 60。如果宿主不支持同步，该出口没有输出。

float

第七个出口：当前的拍数，以 1 PPQ 表示。该数字会包含拍与拍之间的小数部分。如果宿主不支持同步，该出口没有输出。

int

左出口：如果宿主的走带当前正在运行则为 1；如果已停止或暂停则为 0。

int

第二个出口：宿主序列中的当前小节数，第一小节从 1 开始。如果宿主不支持同步，该出口没有输出。

int

第三个出口：宿主序列中的当前拍数，第一拍从 1 开始。如果宿主不支持同步，该出口没有输出。

int

第八个出口：当前的采样计数，由宿主定义。

int

第九个出口：一个表示来自 plugsync~ 的其他信息是否有效的数字。用以下数值做位掩码，以确定来自 plugsync~ 的信息是否有效。

采样计数有效 - 1（始终为真）

拍有效 - 2（第 2、3、4 和 7 个出口有效）

拍号有效 - 4（第 5 个出口有效）

速度有效 - 8（第 6 个出口有效）

走带有效 - 16（左出口有效）

list

第五个出口：当前的拍号，为一个先包含分子、后包含分母的列表。例如 3/4 拍会作为列表 3 4 输出。如果宿主不支持拍号信息，则该出口没有输出。
