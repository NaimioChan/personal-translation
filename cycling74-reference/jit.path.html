Jitter

jit.path

把一系列 N 维点作为一条路径求值

描述

jit.path 对象接收一系列 N 维点，并根据输入参数取出插值后的取值。它适合用来创建用于参数渐变的用户界面。

讨论

jit.path 对象使用线性插值或 Hermite 样条插值来执行这种插值。Hermite 样条会用 Catmull-Rom 方法自动计算，该方法为每个点生成一条切线。插值后的取值根据输入参数取出。还可以选择从第二个出口输出一个填满插值取值的矩阵，其通道数等于路径的维度。
可以用消息把点加入路径，也可以传入由点取值组成的一维矩阵。会输出一个二维矩阵，其中第一行是路径上的各个点，第二行是自动计算出的切线。
把前三个维度当作 x/y/z 位置取值，就可以算出路径的长度。路径也可以选择按长度求值。

特性

autohandles [int]

每次编辑路径时都启用把手取值的计算（默认值 = 1）。

closed [int] 只读

表示路径是闭合的（第一个点与最后一个点相等）。

dim [int]

路径维度，也是点矩阵与 eval 矩阵中的通道数（默认值 = 0）。

duration [float] 只读

路径时长，以秒为单位（默认值 = 0.）

evalmatrixmode [symbol]

决定求值矩阵的求值方式（默认值 = eval）。在 evalmatrixmode eval 下，求值结果按各点之间的距离分布。在 evalmatrixmode evallength 下，求值结果沿路径长度均匀分布。
可选值：

'eval' ( 按 pointcount 归一化 )
'evallength' ( 按 pathlength 归一化 )

evalmatrixname [symbol] 只读

eval 矩阵的名称（默认值 = UID）。这是只读特性，配合 calc_evalmatrix 消息使用，在 javascript 中访问 jit.path 时很有用。

evalmatrixsize [int]

求值矩阵的大小（默认值 = 100）。

grain [int]

做动画时所用的时间粒度，以毫秒为单位（默认值 = 50）。

interpmode [symbol]

路径插值方法（默认值 = linear）。
可选值：

'linear'（线性插值）
'spline'（Hermite 插值）

length [float] 只读

路径长度（默认值 = 0.）

loop [int]

路径动画循环方式（默认值 = 1）。
可选值：

0 = 'off'
1 = 'on'
2 = 'palindrome'

outmatrixname [symbol] 只读

点输出矩阵的名称（默认值 = UID）。这是只读特性，配合 calc_outmatrix 消息使用，在 javascript 中访问 jit.path 时很有用。

play [int]

启用路径动画（默认值 = 0）。

pointcount [int] 只读

路径点的数量（默认值 = 0）。

rate [float]

动画速率取值（默认值 = 1.）

thru [int]

接收输入矩阵的输出点矩阵（默认值 = 1）。

time [float]

当前路径时间取值（默认值 = 0.）

timemode [symbol]

决定加入路径的时间取值的处理方式（默认值 = relative）。当 timemode 设为 absolute 且 usetime 打开时，向路径插入新点会忽略点索引，并按各点的时间取值排序。
可选值：

'absolute' ( 时间取值设为参数值 )
'relative' ( 时间取值设为参数值加上前一个时间取值 )

usetime [int]

确定第一个路径维度是否被用作时间取值（默认值 = 0）。

消息

bang

输出点矩阵

append

把点取值追加到路径末尾。若 dim 为 0，它会被设为参数列表的长度。

参数：

  • values [list]

calc_evalmatrix

用路径的求值结果填充来算出求值矩阵。该矩阵是 1D，大小等于 evalmatrixsize，通道数等于路径 dim。配合 evalmatrixname 特性，在 javascript 中访问 jit.path 时使用很有用。

calc_outmatrix

用路径的点和把手取值填充来算出点输出矩阵。该矩阵是 2D，大小等于点的个数，通道数等于路径 dim。配合 outmatrixname 特性，在 javascript 中访问 jit.path 时使用很有用。

calchandles

使用 Catmull-Rom 方法计算路径中每个点的路径把手。这会覆盖此前存储的所有把手。

clear

从路径中移除所有点

closepath

在路径末端添加一个与第一个点相等的点，以闭合路径。

delete

删除 index 处的点

参数：

edit

编辑 index 处的点

参数：

  • values [list]

edithandle

编辑 index 处的点把手

参数：

  • index [int]
  • values [list]

eval

用 parameter（0. 与 1. 之间）对路径求值，并输出插值得到的取值。

参数：

  • parameter [float]

evallength

用 length-parameter（0 与 pathlength 之间）对路径求值，并输出插值得到的取值。

参数：

  • length-parameter [float]

evaltime

使用 time（0 与 duration 之间）对路径求值，并输出插值结果。必须把 usetime 特性设为 1，这样路径的第一个 dim 会被当作时间取值处理。

参数：

gethandle

参数：

  • index [int]
  • values [list]

next

把路径动画推进到下一个点。

outputeval
