MSP

zplane~

在 Z 平面上绘制滤波器极点与零点

描述

zplane~ 对象提供了一种在 Z 平面上绘制滤波器极点与零点以供显示的方法。把 zplane~ 对象与 filtergraph~ 对象配合使用，或者为它提供一组 biquad~ 系数。

讨论

与 filtergraph~ 对象一样，它本身不处理音频信号，但它会在内部响应当前的 MSP 采样率。zplane~ 对象旨在帮助进行 MSP 的数字滤波器设计与可视化，并提供一个基础的教学工具，可用于帮助讲解数字滤波器理论。
你可以通过在 zplane~ 对象的显示区上点击并拖动来改变滤波器参数。在任意极点（在显示区中显示为 x）或零点（在显示区中显示为 o）上点击并拖动，会修改滤波器系数并输出新的滤波器系数取值。

参数

无。

特性

bgcolor [4 floats]

以 RGBA 格式设置 zplane~ 对象的背景颜色。

gridlinecolor [4 floats]

以 RGBA 格式设置网格与线条的颜色。gridlinecolor 特性映射到 elementcolor 样式颜色。

order [int] : 2

单词 order 后跟一个 2 到 24 之间的偶数，设置极点与零点的数量。

pconstrain [int] : 0

设为 1 时，极点会被约束在单位圆内，从而得到稳定的滤波器。参数为零会关闭该功能（默认值）。

polezerocolor [4 floats]

以 RGBA 格式设置极点零点颜色。polezerocolor 特性映射到 color 样式颜色。

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

消息

bang

使当前的极点与零点取值被重新输出。

float

第一个到第五个入口：在头五个入口之一收到 float 会改变对应的 biquad~ 滤波器系数（依次为 a0、a1、a2、b1 和 b2）的当前取值，重新计算并在 Z 平面上显示滤波器的极点零点图，并使极点与零点的列表被输出。

参数：

  • biquad-filter-coefficients [float]

(inlet1)

第二个入口：设置 biquad~ 滤波器 a1 系数的当前取值。

参数：

  • coefficient value [float]

(inlet2)

第三个入口：设置 biquad~ 滤波器 a2 系数的当前取值。

参数：

  • coefficient value [float]

(inlet3)

第四个入口：设置 biquad~ 滤波器 b1 系数的当前取值。

参数：

  • coefficient value [float]

(inlet4)

第五个入口：设置 biquad~ 滤波器 b2 系数的当前取值。

参数：

  • coefficient value [float]

list

左入口：一组对应 biquad~ 滤波器系数的五个 float 取值会设置 zplane~ 对象中这些系数的内部取值，并使该对象直观地显示该（些）滤波器的极点与零点，同时输出极点与零点数据。

若送出的取值多于五个，它们会被解释为多组级联的双二阶系数。zplane~ 对象会显示一幅复合的极点零点图，它展示一组级联的双二阶滤波器相乘的结果。最多可以级联 24 组、每组五个 float 取值。

参数：

  • a0 [float]
  • a1 [float]
  • a2 [float]
  • b1 [float]
  • b2 [float]

dictionary

单词 dictionary 后跟一个 symbol，该 symbol 引用具名的 filterdesign 对象字典（通过 name 特性设置），这会使 zplane~ 对象使用该字典中的取值作为滤波器系数。

参数：

  • dictionary-name [symbol]

logscale

单词 logscale 后跟一个零或一，在线性（默认值）与对数频率显示之间切换。

参数：

  • logscale-flag [int]

(mouse)

你可以通过在 zplane~ 对象的显示区上点击并拖动来改变滤波器参数。在任意极点（在显示区中显示为 x）或零点（在显示区中显示为 o）上点击并拖动，会修改滤波器系数并输出新的滤波器系数取值。

range

单词 range 后跟一个浮点数值，改变 zplane~ 对象显示区的视觉缩放。默认值为 1.5。

参数：

  • visual scaling amount [float]

输出

list

左出口：一组提供给 biquad~ 对象的 5 个浮点滤波器系数。这些系数会因鼠标点击以及系数入口中的取值变化而输出。

第二个出口：一组以复数（实部、虚部）表示的「零点」位置取值。它们对应滤波器的「a」系数。二阶（双二阶）滤波器会有 2 个零点，四阶滤波器会有四个，依此类推……

第三个出口：一组以复数（实部、虚部）表示的「极点」位置取值。它们对应滤波器的「b」系数。二阶（双二阶）滤波器会有 2 个零点，四阶滤波器会有四个，依此类推……

第四个出口：一组浮点取值，表示每个级联滤波器的总增益。
