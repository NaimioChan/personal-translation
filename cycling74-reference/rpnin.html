Max

rpnin

输出收到的 NRPN 值

描述

输出来自特定非注册参数号（NRPN）和 MIDI 通道的取值。

讨论

非注册参数消息由若干组字节构成，用于指定一个 14 位参数号（2 组用于参数号的最高有效字节（MSB），1 组用于参数号的最低有效字节（LSB））、一个 14 位取值（2 组用于该取值的 MSB 和 LSB）或一个 7 位增量取值（1 组），后面可选地跟一个空功能（2 组）以终止对该参数的修改。

参数

param-channel [list] 可选

初始参数是单个非注册参数号（取值范围 0-16383），供 nrpnin 识别。该参数号也可以用 'MSB:LSB' 格式的符号表示（例如 '1:0' 表示参数 128）。若没有参数号，或参数为负数，nrpnin 会识别所有非注册参数号。若参数中指定了单个参数号，则通常用于发送参数号的那个出口就不需要，也不会被创建。

控制器号参数之后是接收参数消息所用的单个通道号。若没有通道参数，nrpnin 会在所有通道上接收参数消息。要使用该参数，前面必须有一个参数号参数。若只想指定通道号而不指定参数号，把参数号写为 -1。通道号会被截断到 1-16 范围内。

特性

hires [int] : 1

决定对象如何响应格式不同的输入
可选值：

0 = 'Off'（关闭）
若你知道所监视的参数只用 MSB 发送 7 位取值，该模式可避免对象输出不准确的取值。若所监视的参数用 MSB 为 0、LSB 承载取值的「高分辨率」7 位取值发送，该设置不会起作用。

1 = 'MSB first'（MSB 优先（默认））
在该模式下，nrpnin 对象期望来自非注册参数的高分辨率 14 位取值。对象需要收到一对 MSB（CC 6）+ LSB（CC 38）才开始输出。一旦收到 MSB（LSB 会被重置为 0），此后会接受 LSB 消息来微调取值并触发输出。为保留旧版行为，若多个 MSB 消息到达而没有对应的 LSB，则收到新 MSB 时会输出前一个 MSB 的取值（新 MSB 会等待 LSB 或另一个 MSB）。

2 = 'MSB output'（MSB 输出）
在该模式下，nrpnin 对象会在收到 MSB（CC 6）时产生输出。此时，任何 LSB（CC 38，微调）或 MSB 消息都会产生输出。收到 MSB 不会把 LSB 重置为 0（模式 1 中会重置）。该模式适用于只使用 MSB 的信号源，或想能在 MSB 到达之前微调所生成取值的情形。

3 = 'Output any'（输出任意）
在该模式下，nrpnin 对象会在收到任何取值消息（CC 6 或 CC 38）时产生输出。这可能导致取值跳变，但对某些用途可能是合适的。收到 MSB 不会把 LSB 重置为 0（模式 1 中会重置）。

permissive [int] : 0

设置参数号时允许缺少 MSB

消息

int

这些数字是 MIDI 消息流的各个字节，来自 midiin 之类的对象。

参数：

  • input [int]

list

这些数字是 MIDI 消息流的字节，来自 midiin 之类的对象。

参数：

  • input [list]

set

set 消息不带任何参数，或参数为 -1 时，会让 nrpnin 输出来自任意非注册参数的传入 14 位 MIDI 非注册参数消息。0 到 16383（即 (1 << 14) - 1）之间的参数会让 nrpnin 只输出来自所指定参数的传入 14 位 MIDI 非注册参数消息。

set 消息也接受由最高有效字节（MSB）和其后的最低有效字节（LSB）组成的参数列表。7 位 MSB 会移位并与 7 位 LSB 做 OR 运算，以指定 14 位参数号。例如 set 1 0 表示非注册参数号 128。

参数号参数也可以用 'MSB:LSB' 格式的符号表示。例如 set 1:0 表示非注册参数号 128。

参数：

  • parameter [int]

输出

int

左出口：该数字是传入 MIDI NRPN 消息的取值（若有指定），为单个 14 位取值。对任何 NRPN 消息，只会指定 value 与 delta 之一，不会两者都指定。

第二个出口：该数字是传入 MIDI NRPN 消息的 delta（若有指定），为单个 7 位取值。对任何 NRPN 消息，只会指定 value 与 delta 之一，不会两者都指定。

若参数中没有指定具体的参数号，参数号会作为单个 14 位取值从第二个出口送出。

若参数中不包含具体的通道号，通道号会从额外的一个右出口送出。
