Max

lcd

显示图形（已废弃）

参数

无。

特性

bgtransparent [int] : 0

切换背景透明。消息 bgtransparent 1 会把 lcd 对象的背景设为透明。当设为 1 时，对象的背景会保持透明，直到你用 clear 消息将其清除。当特性值设为 0（默认）时，背景初始为白色，与早期版本的 Max 一致。

border [int] : 1

border 一词后跟 0 或 1，用于切换 lcd 对象窗口周围边框的绘制，该功能默认开启。border 0 消息会关闭此功能。

enablesprites [int] : 0

切换精灵的绘制。消息 enablesprites 0 会关闭此功能（默认）。启用精灵后，lcd 会占用更多内存。

idle [int] : 0

切换是否报告鼠标在 lcd 对象上方的空闲位置。随着鼠标移动，鼠标位置的坐标会以两项列表的形式从中间出口送出。这些数字表示相对于 lcd 显示区左上角的局部坐标。第一个数字是该角右侧的像素数，第二个数字是该角向下的像素数。idle 0 关闭此功能，该功能默认关闭。

local [int] : 1

切换是否可以用鼠标在 lcd 中绘图。消息 local 1 开启该功能（默认）。无论哪种情况，在对象矩形范围内拖动鼠标时，lcd 仍会报告鼠标的位置。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold

bold italic

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'

'24'
'30'
'36'
'48'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

anything

anything 指那些向后兼容的首字母大写消息。

参数：

  • arguments [list]

ascii

ascii 一词后跟一个 0 到 255 之间的数字，会在当前笔位置写入对应该 ASCII 值的字符，然后把笔位置移到该字符右侧。超出 0-255 范围的数字会通过取模运算限制到该范围内。

参数：

  • ascii value [int]

backsprite

backsprite 一词后跟一个 symbol，会把具名精灵的绘制顺序设为最先绘制（并且最后显示）。该命令可用于改变精灵的绘制顺序。（通常，精灵按记录的顺序绘制。）

参数：

  • any symbol [list]

brgb

设置背景颜色

参数：

  • red [int]
  • green [int]
  • blue [int]

clear

擦除 lcd 显示的内容

参数：

  • arguments [list]

clearpicts

clearpicts 一词后面跟一个符号，会从内存中删除 lcd 对象的全部具名图片，使它们无法再被绘制。若要从 lcd 对象的显示中移除这些图像，该命令后面应再跟一条 clear 消息。

clearsprites

删除 lcd 对象的所有具名精灵。

closesprite

closesprite 一词后跟一个为精灵命名的 symbol 参数，会关闭精灵命令收集，并把所定义的区域与该 symbol 关联。在 closesprite 消息之后，绘制命令恢复正常工作。

参数：

  • any symbol [list]

color

Max 调色板的选择用 0 - 255 范围内的数字指定。超过 255 的值会通过取模运算限制到该范围内。

参数：

  • color-id [int]

deletepict

deletepict 一词后面跟一个符号，会从内存中删除该具名图片，使它无法再被绘制。若要从 lcd 对象的显示中移除该图像，该命令后面应再跟一条 clear 消息。

参数：

  • any symbol [list]

deletesprite

deletesprite 一词后跟一个 symbol，会删除具名精灵。

参数：

  • any symbol [list]

drawpict

drawpict 一词后跟一个 symbol，会绘制具名图片。其后可选地跟四个数字，用于指定一个目标矩形（图片在其中缩放并绘制）以及一个源矩形（指明该操作中要使用的图片区域）。这些矩形以像素为单位的 left、top、width 和 height 值来指定。目标矩形相对于 lcd 显示区的左上角。源矩形相对于图片的左上角。若不给出，这两个矩形都设为与图片同样大小。

参数：

  • arguments [list]

drawsprite

drawsprite 一词后跟一个 symbol，会绘制具名精灵。其后可选地跟一对数字，用于指定绘制该精灵的水平与垂直偏移。

参数：

  • any symbol [list]

font

font 消息使用 Max 6 通用的字体编号映射指定一个字体 ID，并指定字号，以选择在响应 write 或 ascii 消息绘制文本时所用的字体。

参数：

  • font-id [list]
  • font-size () [list]

frgb

设置前景（画笔）颜色

参数：

  • red () [int]

frontsprite

frontsprite 一词后跟一个 symbol，会把具名精灵的绘制顺序设为最后绘制（并且最先显示）。该命令可用于改变精灵的绘制顺序。（通常，精灵按记录的顺序绘制。）

参数：

  • any symbol [list]

getpenloc

getpenloc 一词会送出一条消息，由 penloc 一词后跟两个数字组成，从 lcd 对象的右出口送出。这些数字表示相对于 lcd 显示区左上角的局部坐标。第一个数字是该角右侧的像素数，第二个数字是该角向下的像素数。

参数：

  • local-coordinates [list]

getpixel

getpixel 一词后跟两个整数，用于指定相对 lcd 对象显示区左上角的偏移，会送出一条消息，由 pixel 一词后跟三个以 RGB 格式指定该像素颜色的数字、以及另外两个指定该像素偏移的数字组成。

参数：

  • x-offset () [int]
  • y-offset () [int]

getsize

从右出口送出一条消息，由 size 一词和两个数字组成，报告 lcd 显示区以像素为单位的宽度和高度。

hidesprite

禁用具名精灵的绘制

参数：

  • any symbol [list]

line

line 一词后跟两个 int 参数，分别表示相对当前笔位置的水平与垂直偏移（以像素为单位），会从当前笔位置到由指定偏移确定的点画一条线，该点成为新的笔位置。正参数把线画向右或向下；负参数画向上或向左。

参数：

  • x position [int]
  • y position [int]

linesegment

linesegment 一词后跟四个 int 参数，用于指定一条线段的两端，会画一条线。这些数字表示起点端点的水平与垂直偏移，以及终点端点的水平与垂直偏移，以像素为单位，相对于 lcd 显示区的左上角。颜色可选地用单个数字指定，该数字从 Max 的调色板中选择一种颜色（类似于 color 消息），也可以用另外三个描述 RGB 值的数字指定（类似于 frgb 消息）。

参数：

  • x start () [int]
  • y start () [int]
  • x end () [int]
  • y end () [int]

lineto

lineto 一词后跟两个 int 参数，分别表示水平与垂直的终点，会从当前笔位置到参数所指定的位置画一条线。

参数：

  • x endpoint [int]
  • y endpoint [int]

(mouse)

你可以用鼠标在 lcd 中手绘（前提是该功能未被 local 0 消息关闭）。鼠标会按当前的笔与颜色特性绘制，鼠标位置会从出口送出。

move

把笔位置从当前位置向下并向右移动若干像素。move 一词后必须跟两个 int 参数，分别表示相对当前笔位置的水平与垂直偏移（以像素为单位）。可以使用负参数把笔位置向上或向左移动。

参数：

  • x position [int]
  • y position [int]

moveto

设置绘制下一条图形指令时的笔位置。moveto 消息必须包含两个 int 参数，分别表示相对 lcd 显示区左上角的水平与垂直偏移（以像素为单位）。

参数：

  • x position [int]
  • y position [int]

oprgb

oprgb 一词后跟三个 0 到 255 之间的数字，用于指定一个 RGB 值，作为支持该值的 penmode 的 opcolor。
若 penmode 设为 32，则 alpha 通道值由这三个 RGB 值取平均得出，并把平均值映射到 0. - 1.0 范围（例如，当 penmode 设为 32 时，oprgb 值 128 128 128 的 alpha 值为 .5）。

参数：

  • red [int]
  • green [int]
  • blue [int]

paintarc

paintarc 一词后跟六个 int 参数，分别指定一个椭圆（弧将跨该椭圆绘制）的左、上、右、下边界，以及起始角度（0 为顶部）和弧的角度，会绘制一段弧。

参数：

  • left () [int]
  • top () [int]
  • right () [int]
  • bottom () [int]
  • start-angle [degrees]
  • degrees-arc [degrees]
  • red [int]
  • green [int]
  • blue [int]

paintoval

paintoval 一词后跟四个 int 参数，分别指定一个椭圆的左、上、右、下边界，会绘制一个椭圆。这些边界以像素为单位，相对于 lcd 显示区的左上角。颜色可选地用单个数字指定，该数字从 Max 的调色板中选择一种颜色（类似于 color 消息），也可以用另外三个描述 RGB 值的数字指定（类似于 frgb 消息）。

参数：

  • left () [int]
  • top () [int]
  • right () [int]
  • bottom () [int]
  • red [int]
  • green [int]
  • blue [int]

paintpoly

paintpoly 一词后最多可跟 254 个 int 参数，用于指定一系列 x/y 配对，定义要在 lcd 中绘制的多边形。这些 x/y 配对以像素为单位，相对于 lcd 显示区的左上角。

参数：

  • x/y int pairs [list]

paintrect

绘制填充矩形时，矩形的左、上、右、下位置以像素为单位，相对于 lcd 显示区的左上角。颜色可选地用单个数字指定，该数字从 Max 的调色板中选择一种颜色（类似于 color 消息），也可以用另外三个描述 RGB 值的数字指定（类似于 frgb 消息）。

参数：

  • left () [int]
  • top () [int]
  • right () [int]
  • bottom () [int]
  • red [int]
  • green [int]
  • blue [int]

paintroundrect

paintroundrect 一词后跟六个 int 参数，分别指定矩形的左、上、右、下位置以及以像素为单位的水平与垂直圆角量，会绘制一个圆角矩形。边缘位置以像素为单位，相对于 lcd 显示区的左上角。颜色可选地用单个数字指定，该数字从 Max 的调色板中选择一种颜色（类似于 color 消息），也可以用另外三个描述 RGB 值的数字指定（类似于 frgb 消息）。

参数：

  • left () [int]
  • top () [int]
  • right () [int]
  • bottom () [int]
  • horizontal-roundness () [int]
  • vertical-roundness () [int]
  • red [int]
  • green [int]
  • blue [int]

penmode

penmode 一词后跟一个 0-7 范围内的数字，用于设置后续绘图操作的传输模式。以下是传输模式常量；

Copy 0
Or 1
Xor 2
Bic 3
NotCopy 4
NotOr 5
NotXor 6
NotBic 7

参数：

  • transfer-mode [list]

pensize

pensize 一词后跟两个相等的 int 参数，分别指定以像素为单位的水平与垂直粗细（例如 4 4），会设置当前的 pensize。水平与垂直粗细必须相等。

参数：

  • horizontal-thickness () [int]
  • vertical-thickness () [int]

readpict

readpict 一词后跟一个指定文件名的 symbol，会在 Max 的文件搜索路径中查找该名称的图形文件（可用 Windows 版 QuickTime Picture Viewer 打开的 .pct 文件），并把该图片文件从磁盘读入 RAM。这个具名图片随后可以在 lcd 中用 drawpict 和 tilepict 消息绘制。响应 readpict 消息时，对象会从 lcd 对象的右出口送出一条消息，由 pict 一词、一个指定图片文件名的 symbol，以及两个指定该文件宽度和高度的数字组成。若读取失败，错误消息 pict <pictname> error 会从右出口送出。

参数：

  • filename [list]

recordsprite

开始记录绘制命令，这些命令会存储在一个具名精灵中。录制期间，绘制命令不会影响 lcd 对象窗口的内容。

reset

erase 消息会擦除当前显示，并把颜色、笔和笔位置重置为默认状态。它等价于消息

clear, pensize 1, penmode 0, frgb 0 0 0, brgb 255 255 255, moveto 0 0

参数：

  • arguments [list]

scrollrect

scrollrect 一词后跟六个 int 参数，分别指定要滚动的矩形的左、上、右、下位置以及沿 x 和 y 方向滚动的像素数，会在 lcd 对象的显示区内滚动一个矩形。

参数：

  • left () [int]
  • top () [int]
  • right () [int]
  • bottom () [int]
  • x-offset () [int]
  • y-offset () [int]

setpixel

setpixel 一词后跟两个数字（用于指定相对 lcd 显示区左上角的局部坐标中的位置）和三个 0-255 范围内的整数（用于以 RGB 格式指定一种颜色），会把指定位置的像素设为所选颜色。

参数：

  • x coordinate [int]
  • y coordinate [int]
  • red [int]
  • green [int]
  • blue [int]

size

size 一词后跟两个整数，会改变 lcd 对象的窗口大小。最大尺寸为 8192 x 8192。

参数：

  • horizontal-size () [int]
  • vertical-size () [int]

textface

textface 一词后跟一个或多个指定文本样式的名称，会设置在渲染文本时使用的字体样式。文本样式名称为 normal、bold 和 italic。

参数：

  • text-styles [list]

tilepict

tilepict 一词后跟一个图片名参数，会通过平铺图片来填充一个矩形。其后可选地跟四个数字，用于指定图片在其中平铺的目标矩形，以及四个数字，用于指定源矩形（指明该操作中要使用的图片区域）。这些矩形以像素为单位的 left、top、width 和 height 值来指定。目标矩形相对于 lcd 显示区的左上角。源矩形相对于图片的左上角。若不给出，目标矩形设为与 lcd 同样大小，源矩形设为与图片同样大小。

参数：

  • arguments [list]

write

write 一词后跟任意 symbol，会从当前笔位置开始写入该 symbol，并把笔位置移到文本末尾。

参数：

  • any symbol [list]

writepict

writepict 一词后跟一个可选的文件名参数，会把 lcd 显示区的当前内容写入 PNG 文件。

参数：

  • filename [symbol]

输出

int

第 3 个出口：若当前按着鼠标键，会从第 3 个出口送出 1。否则送出 0。

list

第 1 个出口：当你按住鼠标键在 lcd 中绘制时，随着鼠标移动，鼠标位置的坐标会以两项列表的形式从出口送出。这些数字表示相对于 lcd 左上角的局部坐标。第一个数字是该角右侧的像素数，第二个数字是该角向下的像素数。

list

第 2 个出口：若 idle 特性设为一，随着鼠标移动，鼠标位置的坐标会以两项列表的形式从第 2 个出口送出。这些数字表示相对于 lcd 显示区左上角的局部坐标。第一个数字是该角右侧的像素数，第二个数字是该角向下的像素数。

penloc

第 4 个出口：响应 getpenloc 消息时，lcd 会输出一条消息，由 penloc 一词后跟两个数字组成，这两个数字以相对于 lcd 显示区左上角的局部坐标表示笔的位置。第一个数字是该角右侧的像素数，第二个数字是该角向下的像素数。

update

第 4 个出口：update 一词会在 lcd 收到来自 Max 的、要它重绘自身的 update 消息时输出。这仅在 lcd 处于 onscreen 模式时才会发生
