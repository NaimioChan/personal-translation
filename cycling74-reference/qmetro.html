Max

qmetro

定期输出 bang 消息

描述

充当节拍器，按指定的固定间隔输出 bang。该对象使用 Max 的 时间格式语法，因此 metro 对象所用的间隔既可以是固定的，也可以与速度相关。

讨论

对象的输出可以用与速度相关的语法进行量化；若设置了 autostarttime 特性，对象还可以在与速度相关的时点启动。

参数

interval [number] ms 可选

可选的第一个参数为 metro 送出输出的时间间隔设置初始值。该时间间隔既可以是用毫秒指定时间的数字（例如 metro 100），也可以是 notevalue（例如 metro 4n）。

注意：虽然 metro 对象允许你用 Max 标准的任意一种 时间格式来指定时间，但若要用毫秒或 notevalues 之外的任何其他时间单位指定时间，应使用 interval 特性参数（例如 metro @interval 11025 samples）。

若没有参数，初始时间间隔为 5 毫秒。

特性

active [int] : 0

打开和关闭 metro。

autostart [int] : 0

若打开（非零），metro 会在 autostarttime 特性所指定的时间自动开始运行。

autostarttime [Time Value] : 0 ticks

若启用了 autostart 特性（非零），metro 会在 this 特性所指定的时间自动开始运行。autostart 的作用相当于 metro 内部的一个 timepoint 对象。

defer [float] : 0.

打开此项以在低优先级队列中送出输出。

interval [Time Value] : 5 ms

设置 metro 送出 bang 的时间间隔。时间可以用 Max 中使用的任意一种 时间格式来指定。

quantize [Time Value] : 0 ticks

仅在适当的时候按指定的时间边界送出输出。做法是对送出输出所用的时间做内部调整。量化可以用下列时间格式指定：bars.beats.units、ticks 或音符时值。

若适用的时间是「固定」单位（例如：ms、seconds、hz、samples 等），则该特性不起作用。

transport [symbol] : internal

transport 对象的名称，用于在使用与速度相关的时间单位时确定 metro 的间隔。默认值为 internal，即全局传输。在 Max for Live 中，默认值为 Live 传输。

消息

bang

左入口：启动 metro 对象。

int

左入口：除 0 以外的任何数字都会启动 metro 对象。metro 会定期从出口送出 bang。0 会停止 metro。

右入口：该数字是 metro 送出 bang 的时间间隔，单位为毫秒。右入口收到的新数字要到下一次输出送出之后才会生效。

参数：

  • input [int]

float

与 int 作用相同。

参数：

  • input [float]

list

右入口：可以用列表按 Max 的某一种时间格式指定时间。

参数：

  • input [list]

anything

与 list 相同。

参数：

  • interval [list]

clock

单词 clock 后面跟一个已存在的 setclock 对象的名称，会把 metro 对象设置为由该 setclock 对象控制，而不是由 Max 内部的毫秒时钟控制。单独的单词 clock 会把 metro 对象重新设置为使用 Max 常规的毫秒时钟。

参数：

  • name [symbol]

stop

左入口：停止 metro。

输出

bang

bang 会在 metro 启动时立即送出，此后则定期送出。
