jit.phys.body

刚体与碰撞形状

描述

jit.phys.body 对象表示物理模拟中的一个刚体与碰撞形状。碰撞形状可以是若干简单形状之一、复合形状（简单形状的组合），或由顶点矩阵定义。

讨论

由顶点网格定义的形状包括 convexhull、concave 和 dynamicmesh。这些形状各自都需要传入一个 3 通道、float32、1D 或 2D 的矩阵。若顶点矩阵是 1D，则被解读为三角形网格；若是 2D，则被解读为 tri_grid 网格。

特性

anim [symbol]

要从中接收变换更新的 jit.anim.node 对象的名称。

collisions [int]

启用或禁用从第二个（dumpout）出口报告碰撞。

damping [2 floats]

设置施加到刚体上的线性与角度阻尼，取值范围为 0. 到 1.（默认值 0.2 0.2）。阻尼可用于模拟空气阻力。

enable [int]

在物理模拟中启用该刚体（默认值 = 1）。

enable_sleep [int]

在该刚体上启用休眠，当线性速度与角速度为 0 时会使其失活（默认值 = 0）。

filterclass [symbol]

设置该对象碰撞过滤器类的名称（默认值 = default）。其他对象必须在自己的 filters 列表中指定该 filterclass 名称，才能与此对象发生碰撞。允许的唯一名称最多为 10 个。

filters [10 symbols]

指定要与之启用碰撞的 filterclass 名称列表（默认值 = all）。可选值包括 all、worldbox 与 default。其他取值包括任何用户指定的 filterclass 名称（最多允许 10 个）。

force [3 floats]

用一个 3D 世界空间向量对该刚体施加力（默认值 = 0 0 0）。若启用了 forces_relative，该向量会被转换到对象空间。

forces_relative [int]

forces_relative 标志会使所有力在施加前被转换到对象空间（默认值 = 0）。

friction [float]

摩擦力大小（反向力）（默认值 = 0.5）。当该刚体与另一个有摩擦的刚体接触时施加。

kinematic [int]

运动学标志（默认值 = 0）。使用该模式可以禁用刚体上的动力学、保持与世界其他刚体的碰撞，并用 position 与 quat 特性来做动画。这样可以实现由用户驱动动画的刚体。

local_scaling [int]

局部缩放标志（默认值 = 0）。启用后，scale 特性会对碰撞形状施加局部缩放变换。禁用后，每次修改 scale 时刚体都会从物理世界中移除并重新加入。

mass [float]

刚体质量（默认值 = 1.）。设为 0. 时刚体动力学被禁用，但碰撞仍然有效。

name [symbol]

指定实例的名称（默认值 = UID）。

position [3 floats]

以 x y z 形式表示的刚体世界空间位置（默认值 = 0. 0. 0.）。

quat [4 floats]

以 x y z w 形式表示刚体朝向的四元数（默认值 = 0. 0. 0. 1.）。

reduce_hull [int]

当刚体的 shape 特性设为 convexhull 时启用自动顶点精简（默认值 = 1）。

resetpos [3 floats]

以 x y z 形式表示的刚体重置位置（默认值 = 0. 0. 0.）。这是刚体收到 reset 消息后会回到的世界空间位置。

resetquat [4 floats]

以 x y z w 形式表示刚体重置朝向的四元数（默认值 = 0. 0. 0. 1.）。这是刚体收到 reset 消息后会回到的朝向。

restitution [float]

恢复系数取值，即弹性（默认值 = 0.1）。与其他刚体碰撞时保留的动能比例。

rolling_friction [float]

滚动摩擦力大小（作用于滚动对象的反向力）（默认值 = 0.0）。当该刚体与另一个有摩擦的刚体接触时施加。

rotate [4 floats]

以 角度（单位为度） x y z 形式表示刚体朝向的轴角（默认值 = 0. 0. 0. 1.）。

rotate_order [symbol]

设置对所有子 gl 对象施加到 rotatexyz 特性的旋转顺序（默认值 = auto）。例如设为 xyz 时，对象先绕其 X 轴旋转，再绕 Y 轴，最后绕 Z 轴。默认值 'auto' 实现的是 yzx 顺序。要复现 Max 5，请用 zyx。若绑定了 ob3d，这会覆盖从其 jit.gl.render 上下文继承的 rotate_order。
可选值：

'auto'
'xyz'
'xzy'
'yxz'
'yzx'
'zxy'
'zyx'

rotatexyz [3 floats]

以 x y z 形式表示的刚体欧拉角朝向，单位为度（默认值 = 0. 0. 0.）。

scale [3 floats]

以 x y z 形式表示的刚体缩放系数（默认值 = 1. 1. 1.）。

send_scale [int]

发送缩放标志（默认值 = 1）。启用后，缩放取值会发送给绑定对象。

shape [symbol]

碰撞形状类型（默认值 = sphere）。
可选值：

'sphere'
'cube'
'capsule'
'cone'
'cylinder'
'convexhull'（需要一个顶点矩阵。会生成一个包住这些顶点的凸包。）
'concave'（需要一个顶点矩阵。会生成一个凹形形状，允许网格形状中有凹陷）
'compound'（简单形状的组合体）
'dynamicmesh'（需要一个顶点矩阵。处理动态变化的网格形状，并且要求刚体不动。）

targetname [symbol]

目标对象的名称，可以是 OpenGL 对象或 jit.anim.node。该对象会接收 position、quat，可能还有 scale 取值。

torque [3 floats]

用一个 3D 世界空间向量对该刚体施加力矩（角力）（默认值 = 0 0 0）。

total_force [3 floats] 只读

当前施加到该刚体上的总力。

total_torque [3 floats] 只读

当前施加到该刚体上的总力矩。

velocity [3 floats]

该刚体当前的速度，单位为每秒（默认值 = 0 0 0）。

velocity_ang [3 floats]

该刚体当前的角速度，单位为弧度每秒（默认值 = 0 0 0）。

worldname [symbol]

该刚体所绑定的 jit.phys.world 上下文的名称。

消息

bang

更新刚体所受的力与矩阵输入，并输出 position 与 quat 取值。

addchild

向复合刚体添加一个子 shape。可选参数为位置 x/y/z、四元数 x/y/z/w 和缩放 x/y/z。

参数：

  • shape [symbol]
  • x [float]
  • y [float]
  • z [float]
  • quat-x [float]
  • quat-y [float]
  • quat-z [float]
  • quat-w [float]
  • scale-x [float]
  • scale-y [float]
  • scale-z [float]

getchild_dict

把复合刚体子形状的字典描述从 dumpout 送出。

impulse

用一个由 x、y、z 描述的世界空间向量对该刚体施加冲量（瞬时力）。若启用了 forces_relative，该向量会被转换到对象空间。可选参数 relative-x、relative-y、relative-z 描述刚体上施加该力的相对位置，否则视为中心力。

参数：

  • x [float]
  • y [float]
  • z [float]
  • relative-x [float]
  • relative-y [float]
  • relative-z [float]

removechild

从复合刚体中移除位于 index 的子形状。

参数：

  • index [int]

removechildren

移除复合刚体中的所有子形状。

reset

重置刚体特性 position 与 quat，并把所有力归零。

setchild_position

设置复合刚体中位于 index 的子形状的位置。

参数：

  • index [int]
  • x [float]
  • y [float]
  • z [float]

setchild_quat

参数：

  • index [int]
  • x [float]
  • y [float]
  • z [float]
  • w [float]

setchild_scale

设置复合刚体中位于 index 的子形状的缩放系数。

参数：

  • index [int]
  • x [float]
  • y [float]
  • z [float]

setchild_shape

设置复合刚体中位于 index 的子对象的形状。

参数：

  • index [int]
  • shape [symbol]

setresetstate

把 resetpos 与 resetquat 特性设为它们当前的状态。

torque_impulse

用一个由 x、y、z 描述的世界空间向量对该刚体施加冲量力矩（瞬时角力）。若启用了 forces_relative，该向量会被转换到对象空间。

参数：

  • x [float]
  • y [float]
  • z [float]
