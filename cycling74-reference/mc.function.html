Max

mc.function

断点函数编辑器

描述

以浮点数形式绘制或存储一组 x、y 点。输出整个函数可作为 line~ 的输入。你还可以获取任意 x 值对应的插值 y 值。

参数

无。

特性

annotation_name [symbol] :

信息视图标题

autosustain [int] : 0

设置 function 的 sustain 模式。共有三个可选值：'Off'、'Next-to-Last Point' 和 'Any Single Point'。默认值为 0（关闭）。
可选值：

0 = 'Off'
关闭 sustain 模式。

1 = 'Next-to-Last Point'
function 中倒数第二个点会自动成为 sustain 点。该设置要求当前 function 中多于两个点。

2 = 'Any Single Point'
允许你点击 function 中的任意点，把它设为 sustain 点。若 autosustain 已开启，且已经存在另一个 sustain 点，那个点会被关闭。

bgcolor [4 floats]

以 RGBA 格式设置背景的显示颜色。

classic_curve [int]

启用时，曲线用旧式公式绘制；禁用时，曲线的绘制方式更接近 curve~ 对象的输出，而该对象通常由 function 控制。

clickadd [int] : 1

切换用户能否通过用鼠标点击并拖动来创建新的断点。该功能默认启用。

clickmove [int] : 1

切换用户能否通过用鼠标拖动来移动已有的断点。该功能默认启用。

clicksustain [int] : 2

clicksustain 特性控制你可以如何用鼠标指定 sustain 点。共有三个可选值：关闭、cmd/ctrl 点击和双击。默认值为 2（双击）。
可选值：

0 = 'Off'
用鼠标指定 sustain 点的功能被关闭。

1 = 'Cmd/Ctrl Click'
按住 Cmd/Ctrl 并用鼠标点击即可指定 sustain 点。

2 = 'Double-Click'
用鼠标双击即可指定 sustain 点。

constrainpointchanges [int] : 0

启用后，constrainpointchanges 会限制通过 list 消息改动的断点的 X 值，使其保持在前后两个断点的 X 值之间。例如，若启用了 constrainpointchanges，点 2 位于 300，点 4 位于 800，则通过诸如 3 500 1 这样的三元素列表改动点 3 时，它会被约束在 300 与 799.9 之间。

cursor [float] : -1.

设置游标沿 function 对象 X 轴的位置。

domain [float] : 1000.

设置显示的最大 X 值。

grid [int] : 0

设置 function 背后显示的网格
可选值：

0 = 'Off'（不显示网格）
1 = 'Horizontal'（显示水平网格）
2 = 'Vertical'（显示垂直网格）
3 = 'Horizontal and Vertical'（同时显示水平和垂直网格）

gridcolor [4 floats]

以 RGBA 格式设置网格颜色

gridstep_x [float] : 100.

设置水平网格间距

gridstep_y [float] : 0.1

设置垂直间距

legend [int] : 1

切换当某个点被高亮或被更新时是否显示数值

linecolor [4 floats]

以 RGBA 格式设置线段的显示颜色。

linethickness [float] : 1.

设置各点之间所绘制线条的宽度。

mode [int] : 0

设置 function 是否包含曲线信息。这会同时改变 function 的显示与输出格式。不包含曲线信息时，第二个出口的格式与 line 和 line~ 对象兼容。包含曲线信息时，输出与 curve~ 对象兼容。
可选值：

0 = 'Linear'（线性模式）
不包含也不显示曲线信息

1 = 'Curve'（曲线模式）
包含曲线信息；可以用 setcurve 消息，或在某一段上按住 option-（alt-）拖动，来改变线段的曲率。

mousemode [int] : 0

mousemode 特性决定拖动移动点时的行为。
可选值：

0 = 'Free'（自由）
在 Free 模式下，被移动的点只能在其前一个点和后一个点之间移动，其他所有点保持不变。

1 = 'Shift'（平移）
在 Shift 模式下，其后所有点会在水平轴上移动相同的量，与正在移动的点保持相对距离。

2 = 'Reorder'（重排）
在 Reorder 模式下，被移动的点可以在水平轴上拖过相邻的点。各点会重新排序，使 function 保持有序，从而让你通过拖动来重新排列顺序。

mousereport [int] : 0

启用时，第三个出口会送出一个三项列表，其中包含当前光标位置以及光标下当前点的索引（若光标不在任何点上则为 -1）。在已锁定的补丁中，当光标位于该对象之上时才会输出。

outputmode [int] : 0

启用时，第二个出口送出的列表会包含 function 第一个点的 X 坐标。默认情况下 outputmode 处于禁用状态，以便与 line~ 和 curve~ 对象兼容，这两个对象期望列表以初始 Y（目标）值开头。

param_connect [symbol] :

在对象与具有参数的兼容对象（如 gen~ 或 jit.gl.slab）的某个参数之间建立双向连接。该对象可用来改变参数的值，参数值变化时它也会随之更新。设置 param_connect 最简便的方法，是使用该特性在 inspector 中的菜单，或使用 Object Action 菜单的 Connect 子菜单。菜单会列出兼容对象的所有可用参数。

用消息设置 param_connect 特性时，需要给出目标参数的路径，即宿主对象的脚本名后跟两个冒号，再加上参数名。例如，对于一个 gen~ 对象，若其脚本名为 gen~_AB，则 freq 参数的路径为 gen~_AB::freq。可以在宿主对象或参数尚不存在时就为 param_connect 设值，该对象会在参数出现后与之建立连接。更多细节请参阅用户指南中 param_connect 条目。

parameter_enable [int]

启用后，该对象可与 Max for Live Parameters 以及 Max 中的初始参数值设置配合使用。

parameter_mappable [int] : 1

启用 parameter_mappable 后，该对象即可通过映射功能映射到键盘或 MIDI 输入。（默认值 = 1）。

pointalign [float] : 0.

pointalign 特性会覆盖 pointsize 特性，用于控制点相对于 function 边界框的位置。取值从 0（不覆盖，定位基于 pointsize）到 20（此时 function 的各点会居中于半径为 20 像素的圆内）。

pointsize [float] : 2.5

设置 function 中所有点的半径大小。该值除了影响点的大小，还会影响所有点的位置，以免较大的点被裁掉。pointsize 的取值范围是 1 到 20。

range [2 floats] : 0. 1.

设置 Y 值显示范围的最小值和最大值。

shadowalpha [float] : 0.

shadowalpha 特性设置表示 function 的线条下方渐变阴影的不透明度。取 0（默认值）时渐变不可见；取 1 时完全不透明。只有当 shadowalpha 非零时，其他阴影绘制特性才会对对象的外观产生影响。

shadowblend [float] : 0.1

设置与对象的 pointcolor 混合以生成阴影的黑色量。shadowblend 的取值越接近 0 越暗；越接近 1 越亮。

shadowproportion [float] : 0.

设置阴影渐变中的垂直中点。0 在底部，1 在顶部。

shadowreflectionpoint [float] : 0.

启用 shadowsigned 后，shadowreflectionpoint 决定阴影在垂直方向上被分割并对称反射的位置点。0 位于底部（不反射）；1 位于顶部。

shadowsigned [int] : 0

启用时，阴影可以绕某个点（shadowreflectionpoint）反射，从而产生镜像效果，这在 function 的范围包含负值时很适用。

snap2grid [int] : 0

决定添加或移动点时是否把点约束到网格取值上。snap2grid 的行为与用 grid 特性设置的网格可见性无关。
可选值：

0 = 'Off'（关闭）
不会发生网格吸附

1 = 'Horizontal'（仅水平）
只在水平维度上发生网格吸附

2 = 'Vertical'（仅垂直）
只在垂直维度上发生网格吸附

3 = 'Horizontal and Vertical'（水平和垂直都包括）
在水平和垂直两个维度上都发生网格吸附

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

textcolor [4 floats]

以 RGBA 格式设置文字的显示颜色。

zoom_x [2 floats] : 0. 1.

设置 function 对象显示的水平缩放。缩放值用一对 0.0 - 1.0 范围内的浮点值来设置。

zoom_y [2 floats] : 0. 1.

设置 function 对象显示的垂直缩放。缩放值用一对 0.0 - 1.0 范围内的浮点值来设置。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

触发从左中间出口输出当前断点列表，其格式供 line~ 对象使用。例如，若 function 中的断点为 X = 1, Y = 0；X = 10, Y = 1；X = 20, Y = 0，则输出为 0, 1 9 0 10。若启用了可选的输出模式，输出则为 0 0 1 9 0 10。

若 function 中存在任何 sustain 点，bang 会输出截至该 sustain 点为止的所有点的列表。通过发送下一条消息，可以继续输出 function 中后续的点，直到下一个 sustain 点或结束点（以适用者为准）。更多信息见 next 和 sustain 消息的说明。

int

该取值被当作 X 值，并从左出口输出对应的 Y 值。Y 值由 function 的线性浮点插值生成。若 X 值位于第一个或最后一个断点之外，Y 值为 0。

参数：

  • x-value [int]

float

该取值被当作 X 值，并从左出口输出对应的 Y 值。Y 值由 function 的线性浮点插值生成。若 X 值位于第一个或最后一个断点之外，Y 值为 0。

参数：

  • input [float]

list

若列表包含两个值，会向 function 添加一个新点。第一个值是 X，第二个值是 Y。

若列表包含三个值，会修改 function 中已有的点。第一个值是要修改的断点的索引（从 0 开始），第二个是该断点的新 X 值，第三个是该断点的新 Y 值。（若列表中的索引号指向不存在的断点，该消息会被忽略。）

若列表包含四个值，且 mode 特性被设为 1（curve），则第三个值是曲线量：大于 0 的值产生指数曲线，小于 0 的值产生对数曲线。

参数：

  • x-value [number]
  • y-value [number]
  • curve [number]

clear

clear 一词单独使用会抹去所有现有的断点。clear 一词后面也可以跟一个或多个断点索引（从 0 开始），以清除选中的断点。

参数：

  • indices [list]

clearfix

clearfix 一词清除所有 fix 状态（把它们设为 0）。

clearsustain

clearsustain 一词清除所有 sustain 状态（把它们设为 0）。

color >= 7.0.0

color 消息为浅色背景上的断点和线条设置一个索引 0 到 15 的颜色。该消息已不再受支持。

参数：

  • color index [int]

copy

copy 消息把当前 function 的所有点复制到剪贴板，以便粘贴到另一个 function 对象中。

dump

从 function 对象的第三个出口送出一系列描述各个断点的多元素列表。每个列表包含该断点的 X 和 Y 值，若存在曲线值则随后跟上该曲线值。可以选择用一个 symbol 参数把 receive 对象指定为发送目标。

参数：

  • receive-name [symbol]

fix

fix 一词后面跟一个指定点索引的数字以及 0 或 1：若第二个数字为 1，则阻止用户改动该点；若第二个数字为 0，则允许用户改动该点。默认情况下点是可以移动的，除非已发送过 clickmove 0 来禁止移动所有点。

参数：

  • index [number]
  • flag [int]

getfix

getfix 一词不带参数时，会使 function 对象从该对象的第三个出口送出一个包含所有 fix 点的列表。若提供索引作为参数，则输出该点的 fix 状态。

参数：

  • point-indices [list]

getsustain

getsustain 一词不带参数时，会使 function 对象从该对象的第三个出口送出一个包含所有 sustain 点的列表。若提供索引作为参数，则输出该点的 sustain 状态。

参数：

  • point-indices [list]

lineout

lineout 一词后面跟 0、1 或不带参数，都等价于 bang 消息。

listdump

从 function 对象的第三个出口送出一个列表，其中包含各个断点的所有 X 和 Y 值。可以选择用一个 symbol 参数把 receive 对象指定为发送目标。

参数：

  • receive-name [symbol]

(mouse)

你可以用鼠标添加或编辑断点。

  • 在 function 中的空白处点击会添加一个断点。你可以立即通过拖动来移动它。可以用 clickadd 特性禁用添加断点。
  • 在已有断点上拖动会移动该断点。可以用 clickmove 特性禁用修改断点。
  • 按住 Shift 点击断点会将其删除。
  • 按住 Command 点击（Mac OS）或按住 control 点击（Windows）断点，会切换该点的 sustain 特性。sustain 点的点击行为可以用 clicksustain 特性设置。
  • 若 mode 特性已被设为 Curve，按住 option-（Windows 上为 alt-）在线段上拖动会修改该线段的曲率。

next

next 消息从第二个出口送出一个列表，它从上一次 bang 或 next 消息的输出结束处的 sustain 点继续。例如，若 function 的断点为 (a) X = 1, Y = 0；(b) X = 10, Y = 1；(c) X = 20, Y = 0，且点 b 是一个 sustain 点，则 bang 消息会输出 0, 1 9，随后的 next 消息会输出 1, 0 10.。next 消息到达结束点之后，再发的 next 消息等价于 bang 消息。next 也等价于 bang，前提是没有发送过到达 sustain 点的 bang，或 function 不含 sustain 点。

nth

nth 一词后面跟一个数字，会把该数字当作断点的索引（从 0 开始），并从左出口输出该断点的 Y 值。若不存在指定索引的断点，则不会输出。

参数：

  • index [int]

paste

paste 消息把先前复制的 function 的所有点粘贴到 function 对象中。

quantize_x

该消息会使所有点自动吸附到由 gridstep_x 特性定义的水平网格上。

quantize_y

该消息会使所有点自动吸附到由 gridstep_y 特性定义的垂直网格上。

set

在 function 的图形编辑器中已经定义了若干个点的情况下，一个相应的 x-y 坐标对列表会设置每个点的位置。

参数：

  • x-y-coordinate-pairs [list]

setcurve

setcurve 一词后面跟一个指定 function 点索引的整数（从 1 开始编号）和一个指定曲线的浮点值，会在指定点与下一个点之间创建一条曲线线段。

曲线因子取值从 0 到 1.0 时，随着取值增大产生 "指数" 曲线；取值从 -1.0 到 0 时产生 "对数" 曲线。曲线参数越接近 0，曲线越接近直线；参数离 0 越远，曲线越陡。要使该消息生效，必须把 mode 特性设为 1（curve 模式）。

参数：

  • index [int]
  • curve-factor [float]

setdomain

setdomain 一词后面跟一个 float 或 int 值，会设置显示的最大 X 值，然后修改所有断点的 X 值，使它们在新值域下仍保持相同的位置。

参数：

  • maximum [float]

setrange

setrange 一词后面跟两个 float 或 int 值，会设置 Y 值显示范围的最小值和最大值，然后修改所有断点的 Y 值，使它们在新范围下仍保持相同的位置。

参数：

  • minimum [number]
  • maximum [number]

sustain

sustain 一词后面跟一个指定点索引的数字以及 0 或 1：若第二个数字为 1，则把该点变为 sustain 点；若第二个数字为 0，则把它变为普通点。默认情况下点是普通的（非 sustain）。sustain 点的行为在上面 bang 消息的说明中讨论过。在 Macintosh 上按住 Command 点击，或在 Windows 上按住 Control 点击，也会切换某个点的 sustain 特性。

参数：

  • index [int]
  • flag [int]

xyc

xyc 一词后面跟两个指定 X 和 Y 值的数字以及一个指定曲线因子的浮点数，会向 function 添加一个带曲线信息的新点。

曲线因子取值从 0 到 1.0 时，随着取值增大产生 "指数" 曲线；取值从 -1.0 到 0 时产生 "对数" 曲线。曲线参数越接近 0，曲线越接近直线；参数离 0 越远，曲线越陡。要使该消息生效，必须把 mode 特性设为 1（curve 模式）。

参数：

  • x-value [number]
  • y-value [number]
  • curve-factor [float]

输出

bang

右出口：鼠标编辑操作完成时，会送出一个 bang。

float

左出口：响应入口收到的 float 或 int X 值时，送出插值得到的 Y 值；或者响应 nth 消息时，送出存储的 Y 值。

list

左中间出口：收到 bang 时，会从该出口送出一个包含所有存储值信息的列表。该格式用于输入到 line~ 对象。

若 function 对象处于线性模式（通过 mode 特性设置），会为第一个存储的 Y 值送出一个 float，随后送出一个 list，其中包含若干对数字，表示其后每个存储的 Y 值及其过渡时间（X 与前一个 X 之差）。若 function 对象处于线性模式（通过 mode 特性设置），会为第一个存储的 Y 值送出一个 float，随后送出一个 list，其中包含若干对数字，表示其后每个存储的 Y 值及其过渡时间（X 与前一个 X 之差）。

若 function 对象处于曲线模式（通过 mode 特性设置），会为第一个存储的 Y 值送出一个 float，随后送出一个 list，其中包含若干组三个数字，表示其后每个存储的 Y 值、其过渡时间（X 与前一个 X 之差）以及一个曲线因子值（见 setcurve 消息列表）。

第三个出口：若 function 对象处于线性模式（通过 mode 特性设置），则会送出一系列两项列表，其中包含 function 对象各个断点的 X 和 Y 值，该输出在收到 dump 消息时发生。

若 function 对象处于曲线模式（通过 mode 特性设置），则会送出一系列三项列表，其中包含 function 对象各个断点的 X 和 Y 值以及曲线因子，该输出在收到 dump 消息时发生。
