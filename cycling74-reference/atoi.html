Max

atoi

把字符转换为整数

参数

无。

特性

utf8 [int] : 0

utf8 设置 atoi 的输出模式；启用时，输出的数字所表示的输入字符采用 UTF-8 编码。禁用时，Unicode 字符用 UTF-32 表示。启用 utf8 时，输出的字符编码列表的大小可能大于输入中的字符数。对于编码小于 127（ASCII）的字符，UTF-8 和 UTF-32 编码没有差别。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

左入口：可以用 bang 消息触发输出当前存储的数值列表。在右侧两个入口，bang 会被当作符号处理。

int

左入口：数字各位的字符编码值会被存储在内部，并作为列表从出口送出。

参数：

  • input [int]

float

左入口：数字各位的字符编码值会被存储在内部，并作为列表从出口送出。

参数：

  • input [float]

list

列表中的每个 int 都会按上述方式转换为字符编码，且列表各项之间会插入一个空格字符（ASCII 值 32）。中间入口用于向当前存储的列表追加内容，右入口则设置内部存储列表的内容，但不触发输出。

参数：

  • input [list]

anything

左入口：符号中每个字母、数字或其他字符的字符编码值都会被存储在内部，并作为列表从出口送出。

中间入口：符号中每个字母、数字或其他字符的字符编码值会被追加到当前存储的列表。不触发输出。

右入口：符号中每个字母、数字或其他字符的字符编码值会被存储在内部，替换先前存储的列表，但不输出。

参数：

  • input [list]

clear

左入口：clear 消息用于清除内部存储的数值列表的内容。右侧两个入口中的 clear 一词会被当作符号处理。

输出

list

输入的字符编码表示会作为整数列表从出口送出。
