Max

setclock

创建并控制一个替代时钟

描述

允许创建标准毫秒时钟的替代品。这包括若干种改变计时活动的计时模式。每个 setclock 都关联一个名称（其第一个参数），该名称可作为 "clock" 消息的参数传给 Max 中许多使用计时的对象，例如 metro、line 和 pipe。

参数

name [symbol] 可选

必需。第一个参数是 setclock 对象的名称，计时对象（如 clocker、line、metro、pipe 和 tempo）可通过它引用 setclock。这些计时对象一旦收到消息 clock 后跟一个 setclock 对象的名称，就会使用该 setclock 作为其计时源，而不是 Max 常规的毫秒时钟。setclock 对象不必与引用它的计时对象位于同一个补丁中。可以存在多个同名的 setclock 对象；同名的 setclock 对象共享相同的时钟时间信息。（注意：共享同一名称参数的不同 setclock 对象可以键入不同的模式参数，但实际上它们会以最先用该名称加载的那个 setclock 的模式运行。因此，同名但模式不同的 setclock 对象可能行为不可预测，因为 Max 加载它们的顺序往往未知。）

第二个（可选）参数描述这个 setclock 对象将具有的时钟运行模式。第二个参数可能的模式有：

mode [symbol] 可选

单词 pass 指定被动模式。在此模式下，setclock 对象的当前时钟时间由左入口收到的数字设定，相关联的计时对象会跟随该时钟时间，就如同它是正常推进的毫秒时钟一样。若没有第二个参数，模式默认为 pass。

单词 add 指定相加模式。左入口收到的数字会加到当前时钟时间上，以确定新的时钟时间。

单词 mul 指定相乘模式。左入口收到的数字被用作一个因子，所有相关联的计时对象会据此修改其时间设置。例如，因子 2.0 会使所有使用该 setclock 作为时钟源的计时对象把其时间取值加倍（也就是速度减半）。另一种（也许更贴切）理解 mul 模式行为的方式，是把传入的 float 看作一个除数，setclock 用它来除自己时钟时间推进的速度。因此，当它收到数字 2.0 时，会把自己的时钟速度除以 2.0，使跟随该时钟的对象以一半的速度推进。

单词 interp 指定插值模式。左入口收到的数字会逐渐加到 setclock 的当前时间上，所经过的时间段由自上次收到数字以来流逝的时间量决定。在该时间段内，setclock 会进行线性插值，把其时钟设为中间取值。

multiplier [float] 可选

若第二个参数为 mul，则可选的第三个参数为所有相关联计时对象的时间指定一个乘数。若没有第三个参数，乘数默认为 1.0。

消息

bang

左入口：根据 setclock 对象自身的时钟，送出当前的时间取值。计时对象（如 clocker、line、metro、pipe 和 tempo）可以使用 setclock 作为其时钟源，而不是 Max 常规的毫秒时钟。

int

左入口：该数字的含义取决于键入的第二个参数，它指明 setclock 对象的运行模式。若模式为 pass [ive]（默认模式），该数字设定一个绝对时钟时间，计时对象可将其与自己的初始时间取值比较来使用。若模式为 add [itive]，该数字会加到 setclock 对象的当前时钟时间上。若模式为 interp [olate]，setclock 会按该量逐步改变其时钟时间，所经过的时间段由自上次收到数字以来流逝的时间决定。（不过，负数会使时钟时间立即减少。）若模式为 ext [ernal]，该数字直接被忽略。若模式为 mul [tiplicative]，该数字被用作相关联计时对象的乘数。例如数字 0.5 会使相关联计时对象的增长速率（速度）减半。

右入口：设置 setclock 向相关联计时对象报告其时钟信息的时间间隔，以毫秒为单位。默认为 5 毫秒。

参数：

  • timing [int]

float

与 int 作用相同。

参数：

  • timing [float]

(inlet1)

右入口：设置时间更新间隔。

参数：

  • interval [int]

clock

单词 clock 后跟一个单词，指定 setclock 对象的名称的名称，计时对象（如 clocker、line、metro、pipe 和 tempo）可通过它引用 setclock。

参数：

  • clock name [symbol]

(mouse)

用鼠标双击会在 Max Console 中打印状态消息。

reset

单词 reset 后跟一个毫秒数，设置该对象向相关联计时对象报告其时钟信息的时间间隔。只要按设定的间隔到了下一次应报告的时间，就会报告该信息。请注意，reset 消息仅在 setclock 处于插值模式时有效。

参数：

  • interval [float]

set

单词 set 后跟一个毫秒数，设置该对象向相关联计时对象报告其时钟信息的时间间隔。该信息会立即报告给那些相关联的对象。请注意，set 消息仅在 setclock 处于被动或相加模式时有效。

参数：

  • interval [float]

输出

int

当左入口收到 bang 时，setclock 会从出口送出当前的时间读数。
