MSP

normalize~

按最大幅度进行缩放

描述

normalize~ 通过把每个输入采样点的取值乘以一个缩放系数来对其输入进行实时归一化——该缩放系数等于最大输出值（以信号形式送出，或在右入口以 float 送出）除以目前为止收到的最大信号输入值。

讨论

你可以用 reset 消息、或在左入口输入一个 float 来改变最大输入值。若“reset”后面没有跟参数，则新的最大输入值（以及初始最大输入值）为 0.000001。

参数

initial-maximum-output-amplitude [float] 可选

初始最大输出幅度。默认值为 1。

消息

int

转换为 float。

参数：

  • maximum-output-amplitude [int]

float

右入口：最大输出幅度可以以 float 而非 signal 的形式送出。若右入口已连接信号，则右入口中收到的 float 会被忽略。

参数：

  • maximum-output-amplitude [float]

reset

左入口：单词 reset 后面跟一个数字，会把最大输入幅度重置为该数字。若 reset 后面没有数字，或该数字为 0，则最大输入幅度会被设为 0.000001。

参数：

  • maximum-input-amplitude [float]

signal

左入口：输入信号被归一化——即被缩放，使其峰值幅度等于指定的最大值。

右入口：最大输出幅度，即对输出进行整体缩放。

输出

signal

输入信号按最大输出幅度除以最大输入幅度所得的值进行缩放。
