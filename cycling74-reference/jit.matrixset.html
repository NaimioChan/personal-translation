Jitter

jit.matrixset

一组用于存储/重排序的矩阵

描述

jit.matrixset 对象保存一组内部矩阵，可以向其中写入，也可以从中读出。这对于数据存储和/或矩阵重排序可能很有用。

参数

无。

特性

dim [32 ints]

矩阵数据的维度（默认值 = 1 1）

dstdimend [32 ints]

目标维度的结束位置（默认值 = 所有 dim 取值减 1）

dstdimstart [32 ints]

源维度的起始位置（默认值 = 全为 0）

index [int]

传入矩阵将被写入其中的那个矩阵（默认值 = 0）

interp [int]

插值标志（默认值 = 0）该标志置位时，输入矩阵在复制到内部矩阵时会被插值。

matrixcount [int]

矩阵集中矩阵的数量（默认值 = 1）

planecount [int]

矩阵数据中的通道数（默认值 = 4）

planemap [32 ints]

把输入的各个通道映射到输出的各个通道（默认值 = 0 1 2 3 ...）

thru [int]

Thru 模式标志（默认值 = 1）该标志置位时，收到一个矩阵就会输出一个矩阵。

type [symbol]

矩阵数据的类型（默认值 = char）
可选值：

'char'
'long'
'float32'
'float64'

srcdimend [32 ints]

源维度的结束位置（默认值 = 所有 dim 取值减 1）

srcdimstart [32 ints]

源维度的起始位置（默认值 = 全为 0）

usedstdim [int]

Destdim 使用标志（默认值 = 0）该标志置位时，把输入矩阵复制到内部矩阵时会使用目标维度的特性。

usesrcdim [int]

Srcdim 使用标志（默认值 = 0）该标志置位时，把输入矩阵复制到内部矩阵时会使用源维度的特性。

消息

bang

从左出口送出一个矩阵。

clear

把所有取值设为零。

exportmovie

把矩阵导出为影片。exportmovie 消息接受一个可选参数来指定文件名。若未指定文件名，会打开文件对话框让你选择文件。

默认 FPS 为 30。单位：每秒帧数

默认 codec 为 h264。受支持的编解码器列表请查看 jit.record 的 codec 特性。

参数：

  • filename [symbol]
  • FPS [float]
  • codec [symbol]

importmovie

把影片导入到矩阵集中。若未指定文件名，会打开文件对话框让你选择文件。time-offset 与 index-offset 参数可用于设置所导入影片的时间偏移与索引偏移（两个参数的默认值均为 0）。number-of-frames 参数指定要导入的帧数（默认值设为 matrixcount 特性所指定的取值）。注意，importmovie 消息不会调整 jit.matrixset 的大小。

参数：

  • filename [symbol]
  • time-offset [int]
  • index-ffset [int]
  • number-of-frames [int]

read

把 Jitter 二进制数据文件（.jxf）读入矩阵集。若未指定文件名，会打开文件对话框让你选择文件。

参数：

  • filename [symbol]

write

把矩阵集写为 Jitter 二进制数据文件（.jxf）。若未指定文件名，会打开文件对话框让你选择文件。

参数：
