Max

imovie

播放视频

描述

在补丁窗口内的一个界面对象中播放影片。

参数

无。

特性

autofit [int] : 0

设置影片是否自动适应 imovie 窗口的大小。

border [int] : 1

切换是否在 imovie 对象周围绘制边框。默认值为 1（绘制边框）。

moviedim [2 ints] 只读

以像素为单位显示影片的原始尺寸。

name [symbol]

指定 imovie 对象将显示的文件的名称。用作文件名的符号必须是 Max 当前搜索路径中某个文件的名称，或者是该文件的绝对路径名（例如 "MyDisk:/Documents/movies/krakatoa.mov"）。文件名可以通过对象的 Inspector 指定。name 一词单独使用时，会弹出标准的 Open Document 对话框。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

与 resume 相同。

int

设置影片的当前时间位置。若影片正在播放，它会从新设置的位置开始播放。0 始终是开头。结束时间因影片而异。（length 消息会从左出口报告结束时间位置。）

参数：

  • location [int]

(drag)

把一个 QuickTIme 影片文件从 Max File Browser 拖到 imovie 对象上时，该文件会被载入。

active

active 一词后面跟一个非零数字，会使影片处于激活状态（默认）。后面跟 0 时，active 会使影片处于非激活状态。非激活的影片不会播放，也不会改变位置。

参数：

  • flag [int]

clear

效果与不带参数的 dispose 相同。

dispose

从 imovie 对象的内存中移除所有影片。若 dispose 一词后面跟的是某个已载入影片的名称，则只移除该名称所指的影片。

参数：

  • filename [symbol]

duration

从左出口报告影片的时长（以毫秒为单位）。

getduration

从左出口报告影片的结束时间位置（以 Time Units 为单位）。

getrate

从右出口报告当前速率乘以 65536 的结果。因此，正常速度报告为 65536，半速报告为 32768，反向双倍速报告为 -131072，等等。若影片未在播放，速率报告为 0；若尚未载入任何影片，则不送出任何内容。

gettime

报告影片的当前时间位置。

length

length 消息的功能等价于 getduration 消息。

loadintoram

loadintoram 一词后面跟一个非零数字，会在可能的情况下尝试把整个影片载入内存。默认值为 0。

参数：

  • flag (0 or non-zero) [int]

loop

loop 一词后面跟一个 0-2 范围内的数字，控制当前影片的循环。选项有：
0：关闭循环（默认） 1：打开循环 2：回文模式（先正向再反向）

参数：

  • flag [int]

loopend

设置循环的结束点。默认值是表示影片结尾的时间值。

参数：

  • endpoint [int]

looppoints

looppoints 一词后面跟两个数字，设置循环的起点和终点。默认值是：起点为 0（即影片的开头），终点为影片的末尾。

参数：

  • start [int]
  • end [int]

loopset

参见 looppoints 条目。

参数：

  • start [int]
  • end [int]

loopstart

设置循环的起始点。默认值为 0（影片的开头）。

参数：

  • startpoint [int]

matrix

matrix 一词后面跟九个浮点数，会对图像执行一次变换矩阵运算，然后把当前影片重新载入 RAM。这一变换与把点从一个坐标空间（即原始图像）映射到另一个坐标空间（原始图像经过缩放、旋转或平移的版本）所用的变换相同。

变换矩阵运算由九个矩阵元素组成

参数：

  • transform [list]

(mouse)

双击 imovie 对象会使影片窗口成为活动窗口。

mute

mute 一词后面跟一个非零数字，会关闭影片的声音（若它有声音）。后面跟 0 时，mute 会打开影片的声音（默认）。

参数：

  • flag [int]

next

next 一词后面跟一个数字，会把时间位置向前移动该数量。若未提供数字，next 会把时间向前移动 5。（这些单位实际代表的时间因影片而异。）

参数：

  • time-units [int]

nextmovie

若影片正在播放则停止它，并切换到紧接在当前影片之前载入的那部影片。（影片的存储顺序与载入顺序相反。）若没有前一部影片，nextmovie 会回绕到最近载入的影片。注意，即使 nextmovie 已经改变了 "当前影片"，影片窗口的标题也不会自动改变。

palindrome

palindrome 一词后面跟一个非零数字，会把影片设为以回文模式播放（先正向再反向）。必须打开循环。palindrome 0（默认）会禁用回文模式。

参数：

  • flag [int]

passive

passive 一词后面跟一个非零数字，会设置被动模式。在被动模式下，启动影片不会引起帧变化，除非收到 bang 消息。passive 0（默认）会把影片对象设为响应正常的 start 消息。

参数：

  • flag [int]

pause

暂停影片播放

prev

prev 一词后面跟一个数字，会把时间位置向后移动该数量。若未提供数字，prev 会把时间向后移动 5。

参数：

  • time-units [int]

quality

quality 一词后面跟一个数字，设置影片重绘之间的最小间隔（单位：毫秒）。默认值为 0（即没有最小值）。

参数：

  • interval [int]

rate

rate 一词后面跟一个或多个整数或浮点数，用于设置影片的播放速度。若 rate 后面跟一个整数，该数字被视为整数播放速度。若 rate 后面跟两个数字，第一个数字被视为分子，第二个被视为分数速度的分母。1 是正常播放速度，0 表示影片停止，负的 rate 则反向播放。rate 1 2 会让影片以半速播放。送出非零的 rate 消息后，影片会立即开始播放，因此你可能希望在 rate 消息之前先送一个整数，以定位到所需的起始位置。

参数：

  • speed [list]

rd

与 read 相同。

参数：

  • filename [symbol]

read

read 一词后面跟一个符号时，会在 Max 的文件搜索路径中查找该名称的影片文件，若存在就打开它，并在影片窗口中显示影片的第一帧。若文件名中包含空格或特殊字符，应把名称用双引号括起来，或者在每个特殊字符前面加上反斜杠（\）。read 一词单独使用时，会弹出标准的 Open Document 对话框，并读入你选中的任何影片文件。read 消息至少能打开 26 种不同类型的文件。其中包括 MPEG 这类影片文件，AIFF 和 MP3 这类音频文件，以及 GIF 和 JPEG 这类图形文件。

参数：

  • filename [symbol]

readany

readany 消息会打开任何类型的文件，尝试把它解释为影片或其他受支持的媒体文件。

参数：

  • filename [symbol]

rect

rect 一词后面跟四个数字，用于指定影片在影片窗口内显示时所用矩形的大小。前两个数字以相对坐标指定该矩形在影片窗口中的位置，后两个数字以像素为单位指定该矩形的宽度和高度。

参数：

  • x [int]
  • y [int]
  • width [int]
  • height [int]

reload

reload 一词会把当前影片重新载入内存（可用于刷新；例如，若影片正在播放，先送出 stop 消息再送出 reload，影片就会重新载入内存，并像新载入的影片那样从头开始播放）。

resume

从影片的当前位置开始播放，使用最近一次指定的播放速度。

start

把影片的播放速度设为 1 并从头开始播放。若 start 一词后面跟某个已载入影片的名称，该影片会在开始播放之前成为当前影片。

参数：

  • filename [symbol]

startat

startat 一词后面跟一个数字，设置影片的当前时间位置并从该点开始播放。

参数：

  • location [list]

stop

停止影片。

switch

switch 一词后面跟一个符号，会在不改变传输状态的情况下把具名影片设为活动影片（参见 start 消息）。

参数：

  • filename [symbol]

time

time 一词后面跟一个指定帧号的数字时，会跳转到该数字指定的时间位置。没有给出参数时，time 消息的功能等同于 gettime 消息。

参数：

  • frame [int]

timescale

从左出口报告影片的时间刻度（每秒的 Time Units 数量）。

vol

vol 一词后面跟 1-255 范围内的数字，用于设置影片的音量。也可以选用 vol 一词后面跟 0. - 1.0 范围内的浮点值来设置音量。

参数：

  • volume [number]

输出

int

左出口：收到 length 消息时送出影片的结束时间；收到 time 消息时送出影片的当前时间；收到 start 消息时送出 0。

中间出口：在影片内部点击或拖动鼠标时，送出鼠标相对于影片左边缘的水平位置。

右出口：在影片内部点击或拖动鼠标时，送出鼠标相对于影片上边缘的垂直位置。
