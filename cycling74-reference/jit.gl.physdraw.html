jit.gl.physdraw

A physics opengl debug drawer

描述

The jit.gl.physdraw object performs debug drawing of the objects in a physics simulation, including jit.phys.body, jit.phys.multiple, and constraint objects such as jit.phys.hinge and jit.phys.6dof. A valid opengl context and a valid jit.phys.world context are required for debug drawing of the physics world.

讨论

该 OB3D 对象可选地接受一个参数：绘图上下文的名称。它可以是 jit.world 或 jit.pworld 对象的具名实例，也可以是 jit.gl.node 子上下文。该值也可以通过 OB3D 的 drawto 特性设置。若未给出参数，对象会被隐式加入当前补丁中找到的第一个有效绘图上下文或子上下文，或者沿补丁层级向上搜索找到的第一个有效绘图上下文或子上下文。

特性

constraintsize [float]

Set the size for drawing contraints in the physics world (default = 2).

contactsize [float]

Set the size for drawing contact points and vectors in the physics world (default = 6).

draw_aabb [int]

Enable drawing of the physics object's aabb (axis-aligned bounding box) (default = 0).

draw_bodies [int]

Enable rigid body drawing (default = 1).

draw_worldbox [int]

Enable worldbox drawing (default = 1).

rgb [int]

Drawer color flag (default = 1). When the flag is set, drawer uses RGB colors. Otherwise, the color attribute determines the color used.

worldname [symbol]

The name of a jit.phys.world context this drawer is bound to.

OB3D 特性

alpha_mode [symbol]

用独立的 alpha 混合函数与方程对混合过程进行更精细的控制。
可选值：

'link' ( 与 blend_mode 链接（默认值） )
'max' ( 取最大值 )
'add' ( 求和 )
'replace' ( 用源替换目标 )
'ignore' ( 忽略源 )

anim [symbol]

处理该实例所有空间变换的 jit.anim.node 对象的名称（默认值 = UID）。默认值引用一个内部对象，但可以把它设为某个已存在的外部 jit.anim.node 实例的名称来覆盖。这样可以更高级地控制空间变换。

anchor [3 floats]

局部空间中的锚点位置（默认值 = 0. 0. 0.）。用于偏移应用变换所围绕的局部 3D 原点。

animmode [symbol]

决定 anim_move 与 anim_turn 消息在哪个空间中影响该对象的位置和朝向（默认值 = parent）。
local = 相对局部轴旋转
parent = 相对父级轴旋转
world = 相对世界轴旋转

antialias [int]

抗锯齿标志（默认值 = 0）在某些硬件上，必须同时启用 blend_enable 特性，抗锯齿才会生效。

aux_color [4 floats]

辅助颜色，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

axes [int]

x/y/z 轴渲染关/开（默认值 = 0）

blend [symbol]

具名混合模式。可选值有：
add = blend_mode 1 1
multiply = blend_mode 2 1
screen = blend_mode 4 1
exclusion = blend_mode 4 5
colorblend = blend_mode 3 4
alphablend = blend_mode 6 7
coloradd = blend_mode 3 1
alphaadd = blend_mode 6 1

blend_enable [int]

混合标志（默认值 = 0）该标志置位时，所有被渲染的对象都启用混合。

blend_mode [2 ints]

与混合模式关联的源通道和目标通道（默认值 = 6 7）混合模式以 src_blend_mode dst_blend_mode 的形式给出。支持的取值有：
0 = zero
1 = one
2 = destination color
3 = source color
4 = one minus destination color
5 = one minus source color
6 = source alpha
7 = one minus source alpha
8 = destination alpha
9 = one minus destination alpha
10 = source alpha saturate

cull_face [int]

面剔除模式（默认值 = 0（不剔除））
0 = 不剔除
1 = 剔除背面
2 = 剔除正面

depth_clear [int]

深度缓冲清除标志（默认值 = 0）该标志置位时，渲染对象之前会清除深度缓冲。

depth_enable [int]

深度缓冲标志（默认值 = 1）该标志置位时，启用深度缓冲。

depth_write [int]

深度写入标志（默认值 = 1）。该标志置位时，启用对深度缓冲的写入。若 depth_enable 已关闭，则此设置无效。

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

filterclass [symbol]

该对象拾取过滤器类的名称（默认值 = default）。它控制对象对 jit.gl.handle 和 jit.gl.picker 对象是否可见。要选中该对象，filterclass 的值必须在拾取对象的 filters 列表中。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

line_width [float]

绘制线的宽度（默认值 = 1.）

name [symbol]

实例名称（默认值 = UID）

point_mode [symbol]

启用 points 绘图图元（poly_mode 2）时使用的点绘制模式（默认值 = circle）。
可选值：

'square' ( 把点绘制为方形 )
'circle' ( 把点绘制为圆形 )
'square_depth' ( 把点绘制为带深度缩放的方形 )
'circle_depth' ( 把点绘制为带深度缩放的圆形 )
'user_shader' ( 允许在自定义顶点着色器中写入 gl_PointSize )

point_size [float]

绘制点的大小（默认值 = 1.）

poly_mode [2 ints]

多边形渲染模式（默认值 0 0）渲染模式以 frontface backface 的形式给出。支持的渲染模式有：
0 = 渲染为填充多边形
1 = 渲染为线
2 = 渲染为点

position [3 floats]

3D 原点，形式为 x y z（默认值 = 0. 0. 0.）

smooth_shading [int]

平滑着色标志（默认值 = 0）该标志置位时，渲染时使用平滑着色。

消息

OB3D 消息

bang

等价于 draw 消息。

draw

在具名的绘制目标中绘制该对象。若支持 matrixoutput 特性且其设为 1，几何矩阵会从对象的左出口送出。

drawraw

等价于 draw，且 inherit_all 特性设为 1。

drawimmediate

等价于 draw，但忽略任何可能的渲染器设置

anim_move

沿给定的轴移动对象，参照 animmode 所指示的空间。

参数：

  • x [float]
  • y [float]
  • z [float]

anim_turn

按给定的量沿各轴旋转对象，参照 animmode 所指示的空间。

参数：

  • x [float]
  • y [float]
  • z [float]

anim_grow

按给定的量沿各轴缩放对象。

参数：

  • x [float]
  • y [float]
  • z [float]

anim_reset

把局部变换特性重置为默认值（position = 0 0 0、rotatexyz = 0 0 0、scale = 1 1 1）
