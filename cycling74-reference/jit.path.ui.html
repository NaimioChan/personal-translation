jit.path.ui

Creates a 3d path with visual interface

描述

The jit.path.ui object combines the functionality of jit.path and jit.gl.path, adding the capability of editing the path directly in the rendering window.

参数

drawto [message] 可选

The named drawing context in which to draw (default = none). A named drawing context is a named instance of a jit.world, jit.pworld or jit.gl.node object. If no argument is provided the object will find a context implicitly.

特性

animation_mode [symbol]

Animation mode (default = time). When using time the animation is executed using the time values in the path. When using length the animation is executed at constant speed along the whole path.
Possible values:

'time' ( Animates using time values )
'length' ( Animates at constant speed )

automatic [int]

Enable automatic animation timing (default = 1). When enabled, animation is synchronized to the internal draw bang of the rendering context. When disabled, animation is advanced by incoming bang messages, using the elapsed time between bangs as the animation time step.

autohandles [int]

Enable the calculation of handle values every time the path is edited (default = 1).

color [2 lists]

Path color (default = 0.8 0.8 0.8 1). When changing the color attribute, the color of the points will be automatically set.

continuous_path_matrix_output [int]

Ouput the point matrix every time a point or handle is modified (default = 0). Every time a point or an handle is modified in the rendering window, jit.path.ui will output the point matrix from the first outlet.

duration [float] 只读

Path duration in seconds (default = 3.). This is a read-only attribue, meaning you can't modify the duration of the path with it. To modify duration of the path use setduration.

edit_handles_x [int]

Enable mouse editing on x axis for handles (default = 1). When disabled it is not possible to move an handle on the x axis using the mouse.

edit_handles_y [int]

Enable mouse editing on y axis for handles (default = 1). When disabled it is not possible to move an handle on the y axis using the mouse.

edit_handles_z [int]

Enable mouse editing on z axis for handles (default = 1). When disabled it is not possible to move an handle on the z axis using the mouse.

edit_points_x [int]

Enable mouse editing on x axis for points (default = 1). When disabled it is not possible to move a point on the x axis using the mouse.

edit_points_y [int]

Enable mouse editing on y axis for points (default = 1). When disabled it is not possible to move a point on the y axis using the mouse.

edit_points_z [int]

Enable mouse editing on z axis for points (default = 1). When disabled it is not possible to move a point on the z axis using the mouse.

endreport [int]

Enable animation end reporting (default = 0). The symbol endnotify is sent out the dumpout when the animation ends. Only valid if loop = 0.

evalreport [int]

Enable/disable the evaluation parameter reporting out the dumpout (default = 0). The report is a 2 element list where each element represents the current evaluation parameters as 0 to 1 and 0 to duration.

evalautorotatexyz [int]

Output rotation values to align with path direction (default = 0). When enabled and the path is animating, it will output three rotation values after the three position values from the third outlet.

evalmatrixmode [symbol]

Determines how the eval-matrix is evaluated (default = eval). In evalmatrixmode eval, the evaluated values are spaced using the distance between the points. In evalmatrixmode evallength, the evaluated values are spaced evenly along the path length.
Possible values:

'eval' ( Normalized by pointcount )
'evallength' ( Normalized by pathlength )

evalmatrixsize [int]

The size of the eval-matrix (default = 100).

extrudescale [2 floats]

Scaling factor for path contours (default = 0.4).

interpmode [symbol]

Path interpolation method (default = linear).
Possible values:

'linear' ( Linear interpolation )
'spline' ( Hermite interpolation )

length [float] 只读

Path length (default = 17.49)

loop [int]

Path animation loop method (default = 1).
Possible values:

0 = 'off'
1 = 'on'
2 = 'palindrome'

loopreport [int]

Enable animation loop reporting (default = 0). The symbol loopnotify is sent out the dumpout when the animation loops. Only valid if loop is not 0.

play [int]

Enable path animation (default = 0). When play is stopped and then resumed, the animation will start from where it stopped.

rate [float]

Animation rate value (default = 1.)

show []

Show or hide the path (default = 1). When the path is hidden animation through the jit.path.ui still works, only the graphical interface disappears.

time [float]

Current path time value (default = 0.)

timemode [symbol]

Determine how time values added to the path (default = relative). When timemode is set to absolute and usetime is on, inserting a new point to the path will ignore the point index and sort the points according to their time value.
Possible values:

'absolute' ( Time value is set to argument )
'relative' ( Time value is set to argument plus previous time value )

usetime [int]

Determine if first path plane is used as time value (default = 0).

消息

bang

When automatic is disabled and play is enabled, a bang advances the animation using the elapsed time since the previous bang. When automatic is enabled, animation is driven by the rendering context instead.

append

Append a point at the end of the path. If timemode is "absolute", the point will be inserted at an index in the path according to its time value.

calchandles

Calculate the path handles of each point in the path using the Catmull-Rom method. This will overwrite any previously stored handles.

clear

Brings the path back to default configuration

closepath

Close the path by adding a point to the end equal to the first point. When clicing on the first point in the rendering window with the path closed, another menu will appear next to the first point menu, showing the data for the closing point.

delete_point

Delete the point at index

参数：

  • index [int]

editpoint

Edit the point at index

参数：

  • index [int]
  • values [list]

edithandle

Edit the point handle at index

参数：

  • index [int]
  • values [list]

eval

Evaluate the path using parameter, (between 0. and 1.) and output the interpolated values.

参数：

  • parameter [float]

evallength

Evaluate the path using the length-parameter (between 0 and pathlength) and output the interpolated values.

参数：

  • length-parameter [float]

evaltime

Evaluate the path using time (between 0 and duration) and output the interpolated values. The usetime attribute must be set to 1, causing the first dim of the path to be treated as time values.

参数：

  • time [float]

gethandle

Get handle values at index and output through dump outlet.

参数：

  • index [int]

getpoint

Get the point values at index and output through dump outlet. point.

参数：

  • index [int]

get_pointcount

Get number of points and output through dump outlet.

get_duration

Get total path duration and output through dump outlet.

get_length

Get path length and output through dump outlet.

gotopoint

Output the position of the point at index from the third outlet, also if the path is animating.

参数：

  • index [int]

insert_point

Insert a new point at index. Index value is ignored if usetime is enabled and timemode is set to "absolute".

参数：

  • index [int]
  • values [list]

load

Load a path from the hard drive.

参数：

  • path [symbol]

next

Advance the path animation to the next point.

openpath

Open the path if closed, removing the last point.

outputeval

Output a matrix from the second outlet, filled with the evaluated values of the path. The matrix is 1D, the size is equal to the evalmatrixsize, and the planes are equal to path dim.

outputpath

Output the matrix containing the path points and handles from the first outlet.

prev

Rewind the path animation to the previous point

setduration

Set duration of whole path. The time value assigned to each point will be the new duration value divided the number of points - 1.

参数：

  • value [float]

settime

Set time at index. If necessary, the path will be resorted prior to evaluation.

参数：

  • index [int]

start

Start path animation

stop

Stop path animation

write

Write the path to the hard disk in json format.

参数：

  • path [symbol]
