jit.path.ui

创建带可视化界面的 3D 路径

描述

jit.path.ui 对象结合了 jit.path 与 jit.gl.path 的功能，并增加了直接在渲染窗口中编辑路径的能力。

参数

drawto [message] 可选

用于绘制的具名绘制上下文（默认值 = none）。具名绘制上下文是 jit.world、jit.pworld 或 jit.gl.node 对象的具名实例。若不提供参数，该对象会隐式地找到一个上下文。

特性

animation_mode [symbol]

动画模式（默认值 = time）。使用 time 时，动画按照路径中的时间取值执行。使用 length 时，动画沿着整条路径以恒定速度执行。
可选值：

'time' ( 使用时间取值进行动画 )
'length' ( 以恒定速度进行动画 )

automatic [int]

启用自动动画计时（默认值 = 1）。启用时，动画与渲染上下文的内部绘制 bang 同步。禁用时，动画由传入的 bang 消息推进，并使用两次 bang 之间流逝的时间作为动画的时间步长。

autohandles [int]

每次编辑路径时都启用把手取值的计算（默认值 = 1）。

color [2 lists]

路径颜色（默认值 = 0.8 0.8 0.8 1）。改变 color 特性时，点的颜色会被自动设置。

continuous_path_matrix_output [int]

每当点或把手被修改时输出点矩阵（默认值 = 0）。每当在渲染窗口中修改一个点或一个把手时，jit.path.ui 会从第一个出口输出点矩阵。

duration [float] 只读

路径时长，以秒为单位（默认值 = 3.）。这是一个只读特性，也就是说你无法用它修改路径的时长。要修改路径的时长，请使用 setduration。

edit_handles_x [int]

启用对把手的 x 轴鼠标编辑（默认值 = 1）。禁用时，无法用鼠标在 x 轴上移动把手。

edit_handles_y [int]

启用对把手的 y 轴鼠标编辑（默认值 = 1）。禁用时，无法用鼠标在 y 轴上移动把手。

edit_handles_z [int]

启用对把手的 z 轴鼠标编辑（默认值 = 1）。禁用时，无法用鼠标在 z 轴上移动把手。

edit_points_x [int]

启用对点的 x 轴鼠标编辑（默认值 = 1）。禁用时，无法用鼠标在 x 轴上移动点。

edit_points_y [int]

启用对点的 y 轴鼠标编辑（默认值 = 1）。禁用时，无法用鼠标在 y 轴上移动点。

edit_points_z [int]

启用对点的 z 轴鼠标编辑（默认值 = 1）。禁用时，无法用鼠标在 z 轴上移动点。

endreport [int]

启用动画结束报告（默认值 = 0）。动画结束时会把符号 endnotify 从 dumpout 送出。仅在 loop = 0 时有效。

evalreport [int]

启用或禁用从 dumpout 出口报告的求值参数（默认值 = 0）。该报告是一个含 2 个元素的列表，其中每个元素分别以 0 到 1 与 0 到 duration 的方式表示当前的求值参数。

evalautorotatexyz [int]

输出用于对齐路径方向的旋转值（默认值 = 0）。启用且路径正在动画时，它会在第三个出口的三个位置值之后输出三个旋转值。

evalmatrixmode [symbol]

决定求值矩阵的求值方式（默认值 = eval）。在 evalmatrixmode eval 下，求值结果按各点之间的距离分布。在 evalmatrixmode evallength 下，求值结果沿路径长度均匀分布。
可选值：

'eval' ( 按 pointcount 归一化 )
'evallength' ( 按 pathlength 归一化 )

evalmatrixsize [int]

求值矩阵的大小（默认值 = 100）。

extrudescale [2 floats]

路径轮廓的缩放系数（默认值 = 0.4）。

interpmode [symbol]

路径插值方法（默认值 = linear）。
可选值：

'linear'（线性插值）
'spline'（Hermite 插值）

length [float] 只读

路径长度（默认值 = 17.49）

loop [int]

路径动画循环方式（默认值 = 1）。
可选值：

0 = 'off'
1 = 'on'
2 = 'palindrome'

loopreport [int]

启用动画循环报告（默认值 = 0）。动画循环时会把符号 loopnotify 从 dumpout 送出。仅在 loop 不为 0 时有效。

play [int]

启用路径动画（默认值 = 0）。当 play 停止后再继续时，动画会从停止处开始。

rate [float]

动画速率取值（默认值 = 1.）

show []

显示或隐藏路径（默认值 = 1）。路径被隐藏时，通过 jit.path.ui 进行的动画仍然有效，只是图形界面消失。

time [float]

当前路径时间取值（默认值 = 0.）

timemode [symbol]

决定加入路径的时间取值的处理方式（默认值 = relative）。当 timemode 设为 absolute 且 usetime 打开时，向路径插入新点会忽略点索引，并按各点的时间取值排序。
可选值：

'absolute' ( 时间取值设为参数值 )
'relative' ( 时间取值设为参数值加上前一个时间取值 )

usetime [int]

决定是否把路径的第一个通道用作时间取值（默认值 = 0）。

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

varname [symbol]

消息

bang

当 automatic 被禁用且 play 已启用时，一个 bang 会使用距上一次 bang 流逝的时间来推进动画。当 automatic 启用时，动画改由渲染上下文驱动。

append

在路径末尾追加一个点。若 timemode 为 "absolute"，该点会根据其时间取值插入到路径中的相应索引处。

calchandles

使用 Catmull-Rom 方法计算路径中每个点的路径把手。这会覆盖此前存储的所有把手。

clear

把路径恢复为默认配置

closepath

通过在末尾添加一个与第一个点相同的点来闭合路径。在路径已闭合的情况下于渲染窗口中点击第一个点时，第一个点的菜单旁会出现另一个菜单，显示用于闭合的那个点的数据。

delete_point

删除 index 处的点

参数：

  • index [int]

editpoint

编辑 index 处的点

参数：

  • index [int]
  • values [list]

edithandle

编辑 index 处的点把手

参数：

  • index [int]
  • values [list]

eval

用 parameter（0. 与 1. 之间）对路径求值，并输出插值得到的取值。

参数：

  • parameter [float]

evallength

用 length-parameter（0 与 pathlength 之间）对路径求值，并输出插值得到的取值。

参数：

  • length-parameter [float]

evaltime

使用 time（0 与 duration 之间）对路径求值，并输出插值结果。必须把 usetime 特性设为 1，这样路径的第一个 dim 会被当作时间取值处理。

参数：

  • time [float]

gethandle

取出 index 处的把手取值，并通过转储出口输出。

参数：

  • index [int]

getpoint

获取 index 处的点取值，并通过 dump 出口输出。 point。

参数：

  • index [int]

get_pointcount

获取点的数量并通过 dump 出口送出。

get_duration

获取路径的总时长并通过 dump 出口送出。

get_length

获取路径长度并通过 dump 出口送出。

gotopoint

从第三个出口送出 index 处点的位置，即使路径正在动画时也是如此。

参数：

  • index [int]

insert_point

在 index 处插入一个新点。若 usetime 已启用且 timemode 设为 "absolute"，则忽略索引值。

参数：

  • index [int]
  • values [list]

load

从硬盘载入路径。

参数：

  • path [symbol]

next

把路径动画推进到下一个点。

openpath

若路径已闭合则打开它，并移除最后一个点。

outputeval

从第二个出口输出一个矩阵，其中填满路径的求值结果。该矩阵是 1D 的，大小等于 evalmatrixsize，通道数等于路径的 dim。

outputpath

从第一个出口输出包含路径的点与把手的矩阵。

prev

把路径动画回退到上一个点

setduration

设置整条路径的 duration。分配给每个点的时间取值将是新的 duration 取值除以点数 - 1。

参数：

  • value [float]

settime

设置 index 处的时间。必要时，路径会在求值之前重新排序。

参数：

  • index [int]

start

开始路径动画

stop

停止路径动画

write

以 json 格式把路径写入硬盘。

参数：

  • path [symbol]
