MSP

polybuffer~

管理多个 buffer~ 对象

描述

polybuffer~ 让你可以操作一组 buffer~ 对象。每个 buffer~ 都会以 polybuffer~ 的第一个参数加一个索引来命名（也就是说，对于 polybuffer~ toto 对象，每个 buffer~ 会被命名为 toto.N，其中 N 就是索引）。

参数

name [symbol] 可选

设置 polybuffer~ 的名称，并定义 buffer~ 的名称。例如，若 polybuffer~ 对象的名称是 toto，则 buffer~ 会被命名为 toto.1、toto.2、toto.3……同名 polybuffer~ 对象共享同一个 buffer~。

特性

embed [int] : 0

保存时把缓冲区引用保存在补丁中。注意：空缓冲区会作为空缓冲区存储：它们的大小与通道数会被保存，但内容不会被保存。

quiet [int] : 0

抑制加载多个同名 polybuffer~ 补丁时出现的警告。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

(drag)

拖入一个声音文件，列表里就会添加一个 buffer~。拖入一个文件夹，该文件夹中包含的声音文件会被加载进 buffer~ 对象。

append

显示对话框以选择要添加到 polybuffer~ 的声音文件，或加载参数中指定的声音文件。

参数：

  • filename [list]

appendempty

添加一个指定长度与通道数的空 buffer~。

参数：

  • length () [float]
  • channels [int]

clear

删除每一个 buffer~。

(mouse)

在已锁定的补丁中双击 polybuffer~ 对象，会打开一个窗口，你可以在其中查看关于各个缓冲区的信息。

dump

输出包含以下信息的列表：索引、缓冲区名称、声音文件路径、长度、通道与采样率。

getbufferlist

输出消息 bufferlist，后面跟着 buffer~ 的名称。当每一个 buffer~ 名称都从出口送出之后，就会送出 done 消息。

getcount

输出消息 count，后面跟着 buffer~ 对象的数量，也就是 polybuffer~ 对象中包含多少个这样的对象。

getshortname

输出 buffer~ 名称，后面跟着去掉扩展名的声音文件名。迭代完成时输出 done。

getsize

输出 polybuffer~ 所使用的内存大小，单位为字节。

open

打开 polybuffer~ 对象的窗口，查看关于各个缓冲区的信息。

readfolder

从指定文件夹加载多个声音文件。若未提供参数，会弹出一个对话框。

参数：

  • name [list]

send

把消息送往各个 buffer~ 对象。索引对应 buffer~ 的索引，索引为 0 会把消息送往每一个 buffer~。例如，send 0 clear 会把消息 clear 送往每一个 buffer~……也就是这个 polybuffer~ 中包含的全部对象。

参数：

  • index [int]
  • anything [list]

wclose

关闭窗口编辑器

writetofolder

把一个文件夹中的每一个 buffer~ 写出。若未提供参数，会弹出一个对话框。

参数：

  • name [list]
