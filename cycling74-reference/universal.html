Max

universal

向所有同类型对象发送消息

描述

把一个输入消息发送给补丁中同一类对象的所有实例。消息到达的顺序未定义。

参数

mode [int] 可选

如果参数中存在 1，universal 会把收到的消息发送给它所在补丁的子补丁中以及包含 universal 对象的补丁中指定类的对象。

特性

descend [int] : 0

如果把 descend 设为 1，universal 会把收到的消息发送给它所在补丁的子补丁中以及包含 universal 对象的补丁中指定类的对象。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

向补丁中同一类对象的所有实例发送 bang。

int

向补丁中同一类对象的所有实例发送 int。

参数：

  • input [int]

float

向补丁中同一类对象的所有实例发送 float。

参数：

  • input [float]

list

向补丁中同一类对象的所有实例发送 list。

参数：

  • input [list]

anything

把 anything 一词之后的消息发送给补丁中能应用该消息的任意对象的所有实例。

参数：

  • input [list]

send

若要向某些类名同时也是 Max 保留消息名的对象（如 int 和 float）发送消息，需要用 send 消息作为消息的开头。send 可以用于任何类。

参数：

  • input [list]

输入

universal 对象期望的输入是一个符号，用于命名某个对象类（例如 table 或 dspstate~），后面跟一个消息选择符以及该消息的任意数量参数。消息及其参数（如果有）会发送给同一补丁内该类的所有实例（可能还包括其子补丁）。

输出

该对象没有出口，但接收它发送的消息的对象可能会从自己的出口产生某种形式的输出。不过，把消息发送给各个对象的顺序并不保证。使用 send 和 receive 对象时也是如此。
