MSP

subdiv~

相位器的整数细分

描述

subdiv~ 对象把输入相位器信号均匀细分成任意整数个输出相位器信号。

讨论

subdiv~ 对象在启用 Scheduler in Audio Interrupt 时是采样点精确的。更多细节见 这里。

参数

subdivisions [int] 可选

键入型参数设置输入的初始细分数。

特性

div [int]

设置细分个数（从 1 到 16384）

lockprob [int]

启用 lockprob 后，循环概率模式被锁定到循环时长模式上，因此每个时长事件都会做一次概率判定。禁用 lockprob 后，概率跟随细分后的相位器输出。换个说法，禁用 lockprob 时，概率会保持其在循环时长模式中的位置。

pattern [atom]

建立可修改每一步相位器输出时长的循环时长模式。模式由 1 及以上的整数组成，让你能把输入拆成不等的时长。例如，若你把输入按 3 细分，把 pattern 设为 1 2，就会输出一个占输入时间 1/3 的相位器，接着是第二个占输入时间 2/3 的相位器。
注意 subdiv~ 不支持与当前输入细分边界不对齐的时长模式。举个例子，pattern 为 2 2 2 不会产生预期结果，因为中间那个元素跨过了输入重置的位置。通常可以通过增大细分数并降低输入相位器的速率来避免这一限制。一般而言，模式可以跨越当前细分的整数倍，只要它们总在输入重置时重置，就能正常工作。例如在细分数为 3 时，pattern 为 2 1 1 2 1 1 1 会得到预期结果，因为输出斜坡总会在输入重置时重置。
若 pattern 不在输入重置边界处结束，它会被补上一个末尾元素。例如，若细分数为 5，把 pattern 设为 1 2 会在模式重置之前产生一个为 2 的第三步。

prob [atom]

用 prob 可以为每个输出斜坡设置概率模式。模式由 0、1 或 0 到 1 之间的浮点数组成。模式取值为 0 时，subdiv~ 在该步的输出为常量 0。模式取值为 1 时，subdiv~ 的输出为正常的相位器斜坡。取值在 0 与 1 之间时，它被当作该步出现相位器的概率。模式的长度不必与细分数相同。例如：模式 0 1 0.5 在三步的一个循环中，第一次从不输出、第二次总是输出、第三次有一半时间输出。要清除该模式（并始终输出每一步），把 prob 消息的参数设为 none 或不带参数。
当 prob 概率模式与 pattern 时长倍数模式同时使用时，每当时长模式开始一个新步，都会查询 prob 模式。

silentmode [int]

决定相位器输出被跳过时的索引输出
可选值：

0 = 'Hold Previous Step' （不更改步号）
当 silentmode 设为 Hold Previous Step（0）时，若相位器输出为零，subdiv~ 的索引输出相对上一步不变。

1 = 'Output -1' （输出 -1）
当 silentmode 设为 Output -1（1）时，若相位器输出为零，subdiv~ 的索引输出为 -1。

syncupdate [int]

若启用了 syncupdate，对细分数值的修改要等到输入或输出重置时才生效，具体取决于该枚举的取值。
可选值：

0 = 'Off' （不进行更新同步）
对细分数值的修改立即生效。

1 = 'Output Reset' （在输出重置时更新）
对细分数值的修改在输出相位器重置时生效。

2 = 'Input Reset' （在输入重置时更新）
对细分数值的修改在输入相位器重置时生效。
