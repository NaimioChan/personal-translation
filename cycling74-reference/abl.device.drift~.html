Ableton DSP

abl.device.drift~

Drift 合成器

描述

Drift 合成器

参数

无。

特性

drift [float]

设置每个声部的变化量。这种变化会轻微影响声部声音的不同方面，例如音高与滤波器截止频率。 [0., 1.]

env1attack [float]

从初始值行进到峰值所需的时间（秒）。 [0., 60.]

env1decay [float]

从峰值行进到延音电平所需的时间（秒）。 [0., 60.]

env1release [float]

音符结束后回到零所需的时间（秒）。 [0.01, 60.]

env1sustain [float]

衰减阶段结束时达到的电平，并保持到音符结束。 [0., 1.]

env2attack [float]

从初始值行进到峰值所需的时间（秒）。 [0., 60.]

env2decay [float]

从峰值行进到延音电平所需的时间（秒）。 [0., 60.]

env2freq [float]

设置循环包络的频率，单位为 Hz。 [0.17, 1700.]

env2hold [float]

设置循环包络保持在其最大电平的时间。 [0., 1.]

env2mode [int]

启用/禁用包络 2 是否用作循环包络。
可选值：

0 = 'Envelope'
1 = 'Cycling'

env2release [float]

音符结束后回到零所需的时间（秒）。 [0.01, 60.]

env2sustain [float]

衰减阶段结束时达到的电平，并保持到音符结束。 [0., 1.]

env2tilt [float]

设置循环包络的中点。取值极低或极高时，这也会影响包络的斜率。 [0., 1.]

filtermod1amount [float]

用所选的调制源调制低通滤波器频率。设为 1 时，该调制会产生约九个八度的频率偏移。 [-1., 1.]

filtermod2amount [float]

用所选的调制源调制低通滤波器频率。设为 1 时，该调制会产生约九个八度的频率偏移。 [-1., 1.]

filtermodsrc1 [int]

设置用于调制低通滤波器截止频率的调制源。
可选值：

0 = 'Env 1'
1 = 'Env 2 / Cyc'
2 = 'LFO'
3 = 'Key'
4 = 'Velocity'
5 = 'Modwheel'
6 = 'Pressure'
7 = 'Slide'

filtermodsrc2 [int]

设置用于调制低通滤波器截止频率的调制源。
可选值：

0 = 'Env 1'
1 = 'Env 2 / Cyc'
2 = 'LFO'
3 = 'Key'
4 = 'Velocity'
5 = 'Modwheel'
6 = 'Pressure'
7 = 'Slide'

filtertracking [float]

设置根据所弹音符决定的滤波器调制量。 [0., 1.]

gain [float]

设置乐器的总音量，单位为 dB。 [-70.6, 0.]

glidetime [float]

调整重叠的音符把音高滑向下一个到来的音高所需的时间（秒）。只有声部模式设为 mono 且音符以 legato 方式演奏时才能使用 Glide。 [0., 2.]

hpfreq [float]

定义高通滤波器截止频率的中心。 [10., 20500.]

legato [int]

启用/禁用触发新声部时是否在不重触发包络的情况下改变其音高。只有声部模式设为 mono 时才能使用 Legato。

lfoamount [float]

调整施加于传入信号的 LFO 调制量。 [0., 1.]

lfofreq [float]

设置 LFO 的速率，单位为 Hz。[0.17, 1700.]

lfomodamount [float]

设置 LFO 量受所选调制源调制的程度。[0., 1.]

lfomodsrc [int]

设置一个用于调制 LFO 量的源。
可选值：

0 = 'Env 1'
1 = 'Env 2 / Cyc'
2 = 'LFO'
3 = 'Key'
4 = 'Velocity'
5 = 'Modwheel'
6 = 'Pressure'
7 = 'Slide'

lforetrigger [int]

启用/禁用 LFO 重触发。启用后，每次触发音符时 LFO 都会从相同的相位位置重新开始。

lfoshape [int]

可从多种 LFO 波形中选择。单次波形会把 LFO 变成单次衰减包络。
可选值：

0 = 'Sine'
1 = 'Triangle'
2 = 'Saw Up'
3 = 'Saw Down'
4 = 'Square'
5 = 'Sample & hold'
6 = 'Wander'
7 = 'Linear env'
8 = 'Exponential env'

lpfreq [float]

定义低通滤波器的截止频率中心。[20., 20000.]

lpres [float]

设置低通滤波器的谐振。[0., 1.1]

启用/禁用噪声发生器。

启用/禁用噪声发生器的滤波器。

noisegain [float]

osc1gain [float]

设置振荡器 1 的增益，单位为 dB。若滤波器处理已开启，较高的振荡器增益取值会使滤波器重现模拟电路中的某些行为。[-70.6, 6.]
