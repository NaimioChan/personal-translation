Max

detonate

播放由音符事件组成的乐谱

描述

提供用 Max 消息管理的乐谱播放。乐谱可以从 MIDI 文件载入，也可以用 Max 函数生成。乐谱不限于 MIDI 音符和取值；任何信息都可以用 detonate 存储和回放。

讨论

当 detonate 在左入口收到 start 消息或 startat 消息时，它会送出起始音符事件的 delta 时间（若是 startat，则送出所找到音符之后那个音符的 delta 时间）。此后，detonate 每收到一次 next 消息，就会送出该事件的所有其他音符数据以及下一个事件的 delta 时间，从而在乐谱中前进。因此，从左出口送出的数字可用于控制播放节奏：延迟指定的时间，然后触发 next 消息。

当 detonate 在左入口收到 nth 消息（或在停止状态下收到一个数字）时，它会把这些信息用作索引号（第一个音符事件的索引号为 0），并送出该索引事件的所有音符数据。不过它不会把该音符的 delta 时间从左出口送出，而是送出该音符的开始时间——即自乐谱开始以来的总时间。

在 detonate 于左入口收到 follow 或 followat 消息之后，若第 2 个入口收到一个数字，且该数字与乐谱中当前音符的音高一致（或与紧随其后的两个音符之一一致），就会送出所匹配音符的全部数据，但不包括 delta 时间。

参数

label [symbol] 可选

为对象提供一个名称。任何具有相同名称参数的 detonate 对象都会共享同一份事件数据。

消息

bang

执行与 next 相同的功能。

int

收到 record 消息之后，所有收到的数字都会被当作某个音符事件的参数处理。

左入口：距上一次录制事件的 delta 时间（延迟），单位为毫秒。这表示 "起音间隔——音符开始之间的时间——，它实际上决定了这些事件被录下来的节奏。这不必是它们实际发生的真实时间；detonate 相信它收到的任何（非负）delta 时间。

录音时，当 detonate 在左入口收到一个数字，它会把这个数字当作起音间隔（自上一个事件以来经过的时间），把它与其他入口最近收到的数字合并，并把它们作为一个音符事件一起录制下来。与大多数 Max 对象一样，其他入口收到的数字会被存储起来，供之后由最左入口收到数字所触发的音符事件使用。

当 detonate 收到过 follow 消息后，随后在第 2 个入口收到的数字会被当作音符的键号（音高）。若该数字与乐谱中当前音符（或附近某个音符）的音高相同，就会送出为该音符记录的信息——delta 时间除外。

当 detonate 既不在录制也不在跟随状态时，左入口收到的数字与 nth 消息效果相同。

参数：

  • parameter [int]

(inlet1)

第 2 个入口：该数字被当作音符的键号（音高）。若从未收到过键号，则默认使用 60。

参数：

  • pitch [int]

(inlet2)

第 3 个入口：音符的力度。若力度为 0——表示 note-off——，该事件会被当作同一个键上更早一个 note-on 的结束，并决定那个较早音符的时值。若从未收到过力度数字，则默认为 64。

参数：

  • velocity [int]

(inlet3)

第 4 个入口：可以不使用 note-off 消息，而是把音符时值作为 note-on 事件的一部分提供。若从未收到过时值，且没有收到结束该音符的 note-off 事件，则默认使用 10 毫秒的时值。

参数：

  • duration [int]

(inlet4)

第 5 个入口：音符的 MIDI 通道。若从未指定过通道，音符会录制在通道 1 上。

参数：

  • channel [int]

(inlet5)

第 6 个入口：录制该音符事件所用的轨道号。detonate 无法进行 Overdub 录制，但每个录制的音符都可以带上一个轨道号，以便在内部存储成各个独立的音符轨道。若从未收到过轨道号，音符会录制在轨道 1 上。

参数：

  • track [int]

(inlet6)

第 7 个入口：附加在音符事件上的一个 "extra" 数字，可用于任何用途。该数字可用于提供一个额外的事件参数，或作为一个与音符同步的控制值。若该入口从未收到过数字，则默认记录为 0。

参数：

  • extra [int]

(inlet7)

右入口：第二个 "extra" 数字。

参数：

  • extra-2 [int]

float

转换为 int。

参数：

  • parameter [float]

list

列表中的第一个数字被用作 delta 时间，其余数字则按从左到右的顺序，分别当作在其余各入口收到的数字来处理。

参数：

  • event-values [list]

clear

清除 detonate 的内容。

(mouse)

在已锁定的补丁中双击 detonate 对象，会打开一个图形编辑窗口，用于编辑已存储的 detonate 数据。

delay

消息 delay 后面跟一个数字，会把整个已录制的音符值序列移动，使该序列的第一个音符从指定的数字开始。

参数：

  • offset [int]

export

类似 write，但可以使用额外的参数。若第一个参数非零，保存文件时时间会以毫秒表示，而不是以某一速度下的小节、拍和 tick 表示。若该参数为 0 或未给出，文件按拍保存。第二个参数指明 MIDI 文件格式：Type 0（所有音符在单条轨道上）；或 Type 1（多轨格式，用 track 参数分隔音符）。若给出可选的 tempo 参数，该值也会写入文件（多轨文件总会写入速度；若未给出速度，Type 0 文件中不会指定速度，但会用 120 bpm 的默认速度来计算各事件的拍偏移）。

从 Max 9.1.0 起，time 参数为 2 时会按 detonate 对象中指定的毫秒时间导出标准 MIDI 文件。此前，所有时间都会乘以二，以便与 Pd 的 explode 对象保持旧式互操作。

参数：

  • filename [symbol]
  • time [int]
  • file-format [int]
  • tempo [float]

follow

使 detonate 表现得像一个读谱器，把收到的音高信息与它乐谱中存储的事件进行比较。当第 2 个（音高）入口收到一个键号，且该键号与乐谱中当前音符的音高相同时，detonate 会把为该事件记录的信息送出（delta time 除外），然后前进到下一个音符事件。

参数：

  • pitch [int]

followat

followat 一词后面跟一个音高、一个力度和一个 MIDI 通道号，会让 detonate 在其存储的乐谱中查找具有这些属性的音符事件。若找到这样的音符，detonate 就从下一个事件开始跟随乐谱。若未找到，它只会在 Max Console 中打印 detonate: note not found。

参数：

  • pitch [int]
  • velocity [int]
  • channel [int]

import

与 read 相同。

参数：

  • filename [symbol]
  • time [int]

mute

允许对满足特定条件的音符事件有选择地静音。mute 一词后面必须跟一个事件参数编号、一个参数取值，以及一个 1 或 0 的取值，分别表示 "mute" 或 "unmute"。

参数：

  • event-parameter [int]
  • parameter-value [int]
  • mute-flag [int]

next

用 start 消息开始播放乐谱之后，next 会送出乐谱中当前音符的事件信息（delta time 除外），然后送出下一个音符的 delta time。这个 delta time 反过来可以用作延时时间，之后再向 detonate 发送另一个 next 消息。当在乐谱最后一个音符上收到 next 时，该音符之后没有音符了，所以会从左出口送出一个特殊值 -1，表示乐谱结束。若在乐谱未播放时收到 next 消息，detonate 只会在 Max Console 中打印消息 not playing。

nth

nth 一词后面跟一个数字，会送出乐谱中由该数字指定的那个事件的信息。（事件从 0 开始编号。）左出口送出的是该事件的（累计）起始时间，用来代替该事件的 delta time。

参数：

  • event [int]

open

参见 (mouse) 消息。

params

params 一词后面跟三个数字，用于在收到的音高与乐谱中当前音符的音高不匹配时修改 detonate 的跟随乐谱行为。第一个数字告诉 detonate 在乐谱中前进之前可以容忍多少个错误。第二个数字告诉它在错误太多时应在乐谱中前进多少毫秒。第三个数字若非零，则告诉 detonate 把收到的高一个八度或低一个八度的音高当作匹配。例如，消息 params 3 1000 1 表示允许连续三个错误（八度偏移视为匹配），然后在乐谱中前进一秒并继续。默认情况下，detonate 允许 2 个错误，然后前进 200 毫秒，并且不把八度音高偏移视为与所存音符匹配。

参数：

  • tolerance [int]
  • advance [int]
  • octave-match [int]

read

read 一词单独使用时，会打开一个对话框，用于读入标准 MIDI 文件作为 detonate 乐谱的内容。若 read 后面跟的是 Max 搜索路径中某个 MIDI 文件的名称，就会直接读入该文件，不打开对话框。read 消息后面也可以跟一个数字——若该数字非零，文件中的时间值会被解释为毫秒，而不是某一速度下的小节、拍和 tick。若该数字为 0 或未给出，时间按小节和拍读取。

从 Max 9.1.0 起，time 参数为 2 会按指定的毫秒时间导入标准 MIDI 文件。此前，所有这类时间都会除以二，以便与 Pd 的 explode 对象保持旧式互操作。

参数：

  • filename [symbol]
  • time [int]

record

左入口：开始录制各入口进来的数字，把它们当作要录制的音符事件的参数。左入口每收到一个数字，就记录一个事件的起点。

restore

与 record 相同。

setparam

setparam 消息后面跟九个列表元素，会设置对象的参数，很像把信息输入对象的 inspector。列表的第一个元素是一个数字，指明要编辑哪个参数。其余元素是从左到右列出的所需设置："parameter name"、"display mode"、"minimum value"、"maximum value"、"default value"、"graph interval"、"default scaling"，以及 "Display MIDI note number" 标志。

参数：

  • parameter [number]
  • name [symbol]
  • display-mode [int]
  • minimum [int]
  • maximum [int]
  • default [int]
  • interval [int]
  • scaling [int]
  • note-number [int]

start

开始播放乐谱，做法只是送出第一个 delta time。乐谱开始播放之后，就可以用 next 消息来送出下一个事件的信息。

startat

startat 一词后面跟一个音高、一个力度和一个 MIDI 通道号，会让 detonate 在其存储的乐谱中查找具有这些属性的音符事件。若找到这样的音符，detonate 会送出下一个事件的 delta time，随后发送的 next 消息将指向那个下一个事件。若未找到这样的音符，detonate 只会在 Max Console 中打印 detonate: note not found。

参数：

  • pitch [int]
  • velocity [int]
  • channel [int]

stop

让 detonate 停止录制、播放或跟随。在 record、start 和 follow 之间直接切换之前，不必先停止 detonate。

unmute

unmute 一词后面跟一个事件参数编号和一个参数取值，会撤销先前按同一条件执行的 mute。例如，unmute 4 10 与 mute 4 10 0 含义相同。

参数：

  • parameter [int]
  • value [int]

unmuteall

撤销此前所有 mute 消息的效果。

wclose

关闭先前打开的编辑窗口。

write

不带参数时，write 消息会打开一个对话框，用于把 detonate 的内容保存为标准 MIDI 文件。write 一词后面也可以跟一个 symbol，这时 detonate 的内容会写入指定名称的文件，不显示对话框。单轨内容会保存为 Type 0 MIDI 文件，多轨数据则保存为 Type 1 文件。若给出可选的 tempo 参数，该值也会写入文件（多轨文件总会写入速度；若未给出速度，Type 0 文件中不会指定速度，但会用 120 bpm 的默认速度来计算各事件的拍偏移）。

保存补丁时，detonate 的内容会作为补丁的一部分保存。

参数：

  • filename [symbol]
  • tempo [float]

writemax

writemax 消息后面跟一个 symbol，会把 detonate 的内容保存为以该 symbol 命名的 Max 文本文件。

参数：

  • filename [symbol]

输出

int

左出口：当左入口收到 start、startat 或随后发送的 next 消息时，会送出下一个音符事件的 delta time。当乐谱中最后一个事件由一个 next 消息播放时，该音符之后没有音符了，所以会送出一个特殊值 -1 作为 delta time，表示最后一个音符已播放。

当左入口收到一个 nth 消息时（或收到一个 int，且 detonate 已停止），会送出指定音符的起始时间。

第 2 个出口：响应一个 nth 消息，或一个 int（当 detonate 已停止），或播放时的一个 next 消息，或跟随过程中匹配到的音高，会送出该音符的音高。

第 3 个出口：音符的力度。

第 4 个出口：音符的时值。

第 5 个出口：音符的 MIDI 通道。

第 6 个出口：音符的轨道号。

第 7 个出口：与该音符关联的一个额外取值。

右出口：与该音符关联的第二个额外取值。
