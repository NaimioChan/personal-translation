xmidiin

输出原始 MIDI 数据

描述

监听指定的 MIDI 端口并输出收到的原始 MIDI 数据。

参数

port [symbol] 可选

指定从哪个端口（a-z）接收传入的 MIDI 消息。若没有参数，xmidiin 从端口 a 接收（或从 MIDI Setup 对话框中列出的第一个输入端口接收）。

device [symbol] 可选

可以把 MIDI 输入设备的名称用作第一个参数来指定端口。名称 'all' 可用于启用从任意端口接收 MIDI 消息。名称 'none' 可用于阻止该对象从任意端口接收 MIDI 消息。

特性

matchport [int] : 0

若 port 参数与任何已有的端口或设备名都不匹配，则把对象的 MIDI 端口设为 'none'。

name [symbol]

根据设备名设置对象的 MIDI 端口。该特性会依据特性值尝试做区分大小写的部分字符串匹配。

消息

anything

与 port 作用相同。

参数：

  • port [list]

(mouse)

双击 xmidiin 对象会显示一个弹出菜单，用于选择 MIDI 端口或设备。

(MIDI)

xmidiin 对象接收来自某个 MIDI 输入设备的所有 MIDI 消息。

lastport

lastport 一词会从最右出口（若存在）报告最近通过 xmidiin 对象发送 MIDI 字节的设备名称。

port

port 一词后面跟一个字母 a- z，或一个 MIDI 输入端口或设备的名称，用于设置该对象从哪个端口接收传入的 MIDI 消息。port 一词是可选的，可以省略。名称 'all' 可用于启用从任意端口接收 MIDI 消息。名称 'none' 可用于阻止该对象从任何端口接收 MIDI 消息。

参数：

  • port [symbol]

输出

int

从指定端口收到的所有 MIDI 消息都会逐字节从左出口送出。注意，xmidiin 不会对传入 MIDI 流中 running status 的任何用法进行 "清理"。

list

右出口会报告正在发送的 MIDI 设备的名称，格式为 port <portname>。当使用端口名 'all' 时，这一点特别有用。

设备名称只会被送出一次：每当发送设备发生变化时（就在来自新发送者的第一个字节之前），或者当 lastport 消息被发送给该对象时。
