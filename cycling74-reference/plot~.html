MSP

plot~

可视化二维数据

描述

使用 plot~ 对象可以把一组组数据以点的形式绘制在一个定义域上。待可视化的数据来源可以是 Max 列表、MSP buffer~ 或音频信号。绘图数量可以用 @numplots 特性更改，其中每个 "subplot" 都通过专用的入口来寻址。内置提供了多种开箱即用的配置作为 Max 对象原型。

参数

无。

特性

applyfont [int] : 0

启用 applyfont 后，当前的 fontname 和 fontsize 会应用到 plot~ 绘制的所有文字标签。禁用 applyfont 时，fontname 和 fontsize 只用于（由 domainlabel 和 rangelabel 特性设置的）定义域与值域标签。

audioframerate [float] : 15.

plot~ 可视化音频信号时的显示更新速度。这种情况下的绘制由一个时钟驱动，该时钟以指定的每秒帧数运行。

audioframesize [atom_long] : 0

为创建一个数据帧而从音频输入收集的采样点数。默认情况下，音频信号的可视化方式是收集采样值，直到绘图中的点数被填满（audioframesize=0）。然后所有点都会被更新并绘制。另一个 audioframesize 取值必须大于 numpoints 特性的值。

有些情况下，先收集更大一组采样点、然后只可视化其中的一部分是更理想的。例如要可视化 FFT 的输出时，通常只希望查看一帧的前半部分或后半部分，因为它们互为镜像。通过设置 audioframesize，会收集 @audioframesize 个采样点，而实际只绘制前 @numpoints 个。

bgcolor [4 floats] : 1. 1. 1. 1.

背景颜色

domainlabel [symbol] :

底部（水平）文字

fillhorizontalspace [int] : 0

启用 fillhorizontalspace 特性后，绘图点的 X 坐标会被拉开，以填满 plot~ 对象框的整个宽度。禁用时，点之间会留出间隔，使两端各留下一个额外的边距，其宽度与各点之间的间隔成比例。

fontname [symbol] : Lato

fontname 特性设置定义域与值域标签的字体。如果启用了 applyfont，它也会应用到该对象显示的所有文字。

fontsize [float] : 10.

fontsize 特性设置定义域与值域标签的字号。如果启用了 applyfont，它也会应用到该对象显示的所有文字。

gridcolor [4 floats] : 0.5 0.5 0.5 1.

以 RGBA 格式设置网格颜色。

gridorigincolor [4 floats] : 0. 0. 0. 1.

以 RGBA 格式设置原点处的网格颜色。

margins [4 floats] : 8. 8. 8. 8.

缩进边距（上、右、下、左）

numplots [int] : 1

要绘制的数据集数量。该对象会根据需要增减入口。每个 'subplot' 都通过其专用的入口来寻址。

numpoints [int] : 4

设置所有绘图在定义域上显示的点数

rangelabel [symbol] :

左侧（垂直）文字

thinmode [symbol] : sample

当数据集的大小（点数）超过可用于逐点离散显示的像素数时的数据抽稀行为。
可选值：

'none' ( 所有点都会被绘制，并按需重叠 )
'sample' ( 绘制前会根据 thinto 减少点数 )

thinthresh [int] : 10

开始缩减数据集时调用 thinmode 的临界点。默认情况下该特性设为 10，也就是说一旦屏幕上有 10 个点被绘制在同一个像素位置，就会调用 thinmode。

thinto [float] : 0.2

调用 thinmode 时数据集的缩减系数。默认系数为 0.2，也就是在某个给定像素位置会有 5 个取值相互重叠。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

int

设置某个子绘图的首个取值。

参数：

  • input [int]

float

设置某个子绘图的首个取值。

参数：

  • input [float]

list

要在定义域上绘制的数据集。接收该列表的入口决定由哪个子绘图来绘制这些数据。如果列表大于绘图中的点数，列表会被截断。

参数：

  • numbers-to-plot [list]

definecolor

定义绘制与接收该消息的入口相关联的子绘图所用的颜色。颜色分量的顺序为红、绿、蓝、alpha。

参数：

  • color [color]

definedomain

定义与接收该消息的入口相关联的子绘图的定义域。实际点数不会改变，因为那是由 @numpoints 特性设置的。该消息设置这些点所跨越的数值定义域。例如可能有 256 个点代表 [0.0, 1.0] 的定义域。在这种情况下，定义域本质上只是这些点的标签。可选的第三个参数指定定义域采用 'linear' 还是 'log' 缩放。

参数：

  • domain-start [number]
  • domain-end [number]
  • domain-style [symbol]

definefilter

定义在绘图之前应用于数据集的滤波器。目前有两个可用选项（'none' 和 'atodb'）。

参数：

  • filter-name [symbol]

defineline

定义与接收该消息的入口相关联的子绘图中用于显示线条的样式。选项为 'linear'、'lines'、'curve'、'origin' 或 'none'。

虽然 'lines' 的显示速度比 'linear' 更快，但 'linear' 选项在某些情况下看起来更好（通常是在使用较大粗细值时）。这两种显示样式的差别与线段在拐角处如何连接有关：'lines' 不做任何处理，而 'linear' 选项会做平滑连接。

参数：

  • line-style [symbol]

definenumber

定义与接收该消息的入口相关联的子绘图中用于显示数字的样式。选项为 'above'、'below'、'center' 或 'none'。

参数：

  • number-style [symbol]

definepoint

定义与接收该消息的入口相关联的子绘图中用于显示点的样式。选项为 'dot'、'circle'、'square' 或 'none'。

参数：

  • point-style [symbol]

definerange

定义与接收该消息的入口相关联的子绘图的值域。所显示的数据集中超出该范围的取值将落在绘图绘制范围之外。

参数：

  • range-start [number]
  • range-end [number]
  • range-style [symbol]

definethickness

定义与接收该消息的入口相关联的子绘图中线条的粗细。粗细为 1 表示 1 'pixel' 的线宽。

参数：

  • line-thickness [number]

definexgrid

定义在定义域上为与接收该消息的入口相关联的子绘图绘制垂直标记线所在的位置点。定义域上的这些点应处于 'definedomain' 消息所指定的范围内。

参数：

  • x-axis-points [list]

definexlabels

定义与接收该消息的入口相关联的子绘图在定义域上各点的标签。对于每个你希望加上标签的点，必须提供一个 float-symbol 对，用于定义该点在定义域中的位置（按 'definedomain' 消息所定义）以及该位置的标签。

参数：

  • pairs-of-points-and-labels [list]

definexorigin

定义定义域上作为绘图原点的取值。

参数：

  • origin [float]

defineygrid

定义在值域上为与接收该消息的入口相关联的子绘图绘制水平标记线所在的位置点。值域上的这些点应处于 'definerange' 消息所指定的范围内。

参数：

  • y-axis-points [list]

defineylabels

定义与接收该消息的入口相关联的子绘图在值域上各点的标签。对于每个你希望加上标签的点，必须提供一个 float-symbol 对，用于定义该点在值域中的位置（按 'definerange' 消息所定义）以及该位置的标签。

参数：

  • pairs-of-points-and-labels [list]

defineyorigin

定义值域内作为绘图原点的取值。当线条样式设为 'origin' 时，这会影响线条的起始位置。

参数：

  • origin [float]

dictionary

配置一个子绘图。该字典可以包含子绘图的数据、外观，或两者兼有。

参数：

  • dictionary-name [symbol]

edit

为某个子绘图打开一个字典编辑器窗口。对绘图做出修改后，只需关闭该窗口，改动就会生效。

getdictionary

获取某个子绘图的状态。返回的字典将包含该子绘图的完整状态，包括数据配置与外观配置。

参数：

  • subplot-number [int]

(mouse)

把鼠标位置与行为送到出口

refer

把给定入口的子绘图设为引用具名 buffer~ 对象中的数据。如果给该消息提供了第二个参数，它将决定应显示 buffer~ 中的哪个通道。第三和第四个参数以毫秒为单位设置缓冲区的起始与结束时间。如果未提供这些参数，则使用整个缓冲区。

参数：

  • buffer-name [symbol]
  • channel-number [number]
  • start-time [number]
  • end-time [number]

signal

其采样点将被收集并用作待显示数据集的信号。除非已经定义了 audioframesize，否则采样点会按与 numpoints 特性相同大小的数据块收集。

输出

list

发送 'mouse' 消息时，会一并送出归一化的鼠标坐标和鼠标按键状态。
