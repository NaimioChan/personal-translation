Jitter

jit.fpsgui

帧率表

描述

报告计时信息以及矩阵或纹理信息。目前可用的报告有：fps（每秒帧数）、ms（接收到数据之间的毫秒数）、输入类型、dimensions、planecount 和 name。

参数

无。

特性

bgcolor [4 floats]

设置 jit.fpsgui 对象显示区的数据背景颜色的 RGBA 取值。

bgcolor2 [4 floats]

设置 jit.fpsgui 对象显示区的模式背景颜色的 RGBA 取值。bgcolor2 特性映射到 elementcolor 样式颜色。

dim [32 ints] 只读

显示传入矩阵的当前维度。

fps [float] 只读

显示传入矩阵的当前 fps（每秒帧数）速率。

interval [int]

计算 fps 和 ms 时使用的采样周期，单位为毫秒（默认值 = 100）

mode [int] : 0

设置显示模式（默认值 = 0 (fps)）
0 = fps
1 = ms
2 = 矩阵类型
3 = 矩阵维度
4 = 矩阵 planecount
5 = 矩阵名称
可选值：

0 = 'fps'
1 = 'ms'
2 = 'type'
3 = 'dim'
4 = 'planes'
5 = 'name'

ms [float] 只读

显示接收到数据之间流逝的毫秒数。

name [symbol] 只读

显示传入矩阵的当前名称。

planecount [int] 只读

别名：planes

显示传入矩阵当前的 planecount。

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

textcolor [4 floats]

设置 jit.fpsgui 对象显示区的数据文字颜色的 RGBA 取值。textcolor 特性映射到 textcolor_inverse 样式颜色。

timeout [int]

计时器重置之前的时间间隔，单位为毫秒（默认值 = 2000）

type [symbol] 只读

显示传入矩阵当前的数据类型。

usetimeout [int]

设置超时标志（默认值 = 1）。该标志置位时，启用对 timeout 特性的使用。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

anything

发往该对象的任意消息都会使它计算 fps 和 ms。矩阵特性显示的是 n/a。

参数：

  • any-message [list]

getstate

从对象的右出口送出一系列描述传入矩阵状态的列表，每行一个特性。每一行列表的形式为 attribute-name attribute-value1 attribute-value2… attribute-valueN。

jit_gl_texture

使对象计算 fps 和 ms。name 特性显示的是纹理名称。

参数：

  • name [symbol]

(mouse)

用鼠标点击可以选择 jit.fpsgui 对象的显示模式。
