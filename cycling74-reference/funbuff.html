Max

funbuff

存储数字对

描述

存储、管理并调取数字对。

参数

filename [symbol] 可选

该参数指定补丁载入时要读入 funbuff 的文件名。改动一个 funbuff 的内容不会影响另一个同名 funbuff 对象的内容。

也可以用文本编辑器窗口创建 funbuff 的文件，正文以单词 funbuff 开头，后面跟一串用空格分隔的数字，交替指定 x 和 y 取值。已存为文件的 funbuff 可以从 File 菜单选择 Open as Text... 作为文本查看和编辑。文本形式的数字可以从其他来源粘贴进来，例如 capture 对象的编辑窗口，甚至来自其他程序，例如文字处理软件。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

左入口：在 Max Console 中打印有关 funbuff 对象内容当前状态的信息：它包含多少个元素、包含的最小和最大 x 与 y 取值，以及它的定义域与值域（对 x 轴和 y 轴分别是最大值减去最小值）。

int

左入口：该数字是一对 x,y 取值中的 x 值。若右入口已收到 y 值，这两个数字会一起存储到 funbuff 中。否则，该 x 值会使 funbuff 中存储的对应 y 值从左出口送出。

若没有与收到的数字相匹配的已存储 x 值，funbuff 会使用小于该收到数字的最接近的 x 值，并送出对应的 y 值。

参数：

  • x-value [int]

(inlet1)

右入口：该数字是一个 y 值，会与左入口接下来收到的 x 值配对，并存储到 funbuff 中。

参数：

  • y-value [int]

float

任一入口：转换为 int。

参数：

  • x or y value [float]

clear

清除 funbuff 的内容。

copy

把当前选区（用 select 消息选定）复制到全局 funbuff 剪贴板。随后可以把该剪贴板上存储的数据粘贴到另一个 funbuff 对象中（用 paste 消息）。

cut

把当前选区（用 select 消息选定）复制到全局 funbuff 剪贴板，并从 funbuff 对象中删除它。随后可以把该剪贴板上存储的数据粘贴到另一个 funbuff 对象中（用 paste 消息）。

delete

左入口：单词 delete 后面跟两个数字，会在 funbuff 中查找这样的 x,y 对，若存在就删除它。若 delete 后面只跟一个数字，则只查找该 x 值，若存在就删除。

参数：

  • x-value [int]
  • y-value [int]

dump

左入口：把存储的所有数对紧挨着从中间出口和左出口依次送出。y 值从中间出口送出，x 值从左出口送出，交替进行。各数对按 x 值升序送出。

embed

单词 embed 后面跟一个非零数字，会使 funbuff 数据存储在补丁内部。默认设置是不把 funbuff 数据存储在补丁内部。

参数：

  • flag [int]

find

单词 find 后面跟一个数字，会（从左出口）输出所有其 y 值等于所指数字的 x 值（索引）。

参数：

  • y-value [int]

goto

单词 goto 后面跟一个数字，会把指针设置到该数字所指定的 x 值（索引）。随后的 next 消息会返回指定 x 处的 y 值。

参数：

  • index [int]

interp

左入口：单词 interp 后面跟一个数字，会以该数字作为 x 值，测出它在 funbuff 中两个相邻 x 值之间的位置，然后（从左出口）送出在两个相邻 y 值之间处于相应位置的 y 值。若收到的数字已经是某个已存储 x,y 对中的 x 值，则送出对应的 y 值。若收到的数字超出 funbuff 中存储的最小或最大 x 值，则送出与最小或最大 x 值相关联的 y 值。若 funbuff 为空，则送出 0。

参数：

  • x-value [int]

interptab

左入口：单词 interptab 后面跟一个数字和一个具名 table 对象的名称，其功能与（上文提到的）interp 消息类似，区别在于它把表中的数据用作插值函数。这样可以方便地在 funbuff 中相邻取值之间进行非线性插值。

参数：

  • value [int]
  • tablename [symbol]

max

把当前存储在 funbuff 中的最大 y 值从左出口送出。

min

把当前存储在 funbuff 中的最小 y 值从左出口送出。

next

找到指针所指向的 x 值（或者，若指针指向的数字尚未作为 x 值存储，则取下一个更大的 x 值），并把对应的 y 值从左出口送出。此外，funbuff 会计算该 x 值与指针先前所指取值之间的差，把差值从中间出口送出，并把 goto 指针重置到下一个更大的 x 值。

paste

单词 paste 会把全局 funbuff 剪贴板的内容复制到一个 funbuff 对象中。剪贴板的内容由 select、copy 和 cut 消息设置。这些消息提供了一种便捷方式，可以在任何已打开补丁中的不同 funbuff 对象之间复制数据。

print

在 Max Console 中打印有关 funbuff 当前状态的诊断信息。

read

调出 Open Document 对话框，以便把 x,y 取值文件读入 funbuff。若单词 read 后面跟一个 symbol，Max 会在文件搜索路径中查找该名称的文件，直接载入 funbuff。funbuff 的文件格式在下一页描述。

参数：

  • filename [symbol]

select

左入口：单词 select 后面跟两个整数，分别表示起始索引和范围，会选定 funbuff 的一个区域，该区域可以用 cut、copy 和 paste 消息编辑。例如 select 2 3 会选定 funbuff 中从索引 2 到索引 5 的部分。

参数：

  • starting-index and range [list]

set

左入口：单词 set 后面跟一对或多对用空格分隔的数字，会把每一对存储为 x,y 对。

参数：

  • value-pair [list]

undo

undo 消息用于撤销前一条 cut 或 paste 消息的结果。

write

调出标准的 Save As 对话框，以便把 funbuff 的内容保存为单独的文件。若单词 write 后面跟一个 symbol，funbuff 的内容会立即保存到文件中，并以该 symbol 作为文件名。

参数：

  • filename [symbol]

输出

bang

右出口：当指针到达 funbuff 末尾时，响应 next 消息不会送出任何数字，而是送出一个 bang 来通知已到达末尾。

int

左出口：当左入口收到 x 值时，送出对应的 y 值。（或者，若 funbuff 中尚未存储这样的 x 值，则送出与下一个更小的 x 值相对应的 y 值。）当左入口收到单词 next 时，funbuff 会送出与其指针所指向 x 值相对应的 y 值（或者，若没有这样的 x 值，则送出下一个更大的 x 值的 y 值）。

中间出口：当左入口收到单词 next 时，funbuff 会送出指针所指向的 x 值与先前所指 x 值之间的差，然后把指针重置到下一个 x 值。
