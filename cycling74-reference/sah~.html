MSP

sah~

对信号进行采样保持

描述

用 sah~ 在触发信号按若干触发条件之一满足某个阈值时，从输入信号中捕获（"sample"）并输出（"hold"）一个取值。默认的触发模式（Ascending）要求信号从处于或低于该阈值变为高于该阈值。就在触发条件被满足的那一刻，输入信号被采样并"保持"，直到触发条件再次被满足，此时输入会被再次采样。一般来说，这可以让一个信号与另一个信号的行为同步。

参数

initial-trigger-value [number] 可选

初始触发取值

特性

duration [atom_long] : 0

别名：dur

通常 sah~ 的信号输出保持恒定。当 duration 为非零取值时，任何新的非零取值会在指定的若干个采样点内保持恒定，之后变为 0。

thresh [float] : 0.

设置用于使输入信号被采样并输出的那个触发信号的取值。

triggermode [int] : 0

决定 sah~ 如何分析触发信号，以使输入被采样并输出。经典（也是默认）的 triggermode 为 0（Ascending）。
可选值：

0 = 'Ascending'
Ascending 模式检测触发信号从低于阈值变为高于阈值。对递增的斜坡很有用（例如带正频率的 phasor~）。

1 = 'Descending'
Descending 模式检测触发信号从高于阈值变为低于阈值。对递减的斜坡很有用（例如带负频率的 phasor~）。

2 = 'Ascending or Descending'
Ascending + Descending 模式检测触发信号从低于阈值变为高于阈值 或从高于阈值变为低于阈值。该模式与相位器一起使用可能产生意外结果，但对连续型触发输入（例如正弦波）可能更合适。

3 = 'Equals'
Equals 模式检测触发信号取值中的某个确切取值。该模式不推荐用于可能永远达不到某个具体取值的连续函数，但对检测脉冲或其他预期会出现某个具体取值的信号可能有用。

4 = 'Zero-to-Nonzero'
Zero-to-Nonzero 模式检测从零取值变为非零取值的触发信号。这对检测斜坡的起点或传入的音频可能有用。在该模式下 thresh 的取值会被忽略。

5 = 'Nonzero-to-Zero'
Nonzero-to-zero 模式检测从非零取值变为零取值的触发信号。这对检测信号关闭可能有用。在该模式下 thresh 的取值会被忽略。

6 = 'Phase'
Phase 模式把阈值当作相位值处理，使用与 what~ 对象相同的相位检测算法。在 Phase 模式下，sah~ 检测 phasor~ 对象输出中的重置，并把它们定义为阈值为 0 时的触发。Phase 模式对正的与负的 phasor~ 频率都适用。
