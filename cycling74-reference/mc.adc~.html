mc.adc~

音频输入与开关

描述

adc~（“模数转换器”）对象输出来自硬件输入设备的一路或多路信号，每个出口一路。

参数

inputs [int] 可选

若 adc~ 有一个数字参数，它决定从逻辑输入通道 1 开始、由音频输入硬件产生信号的出口个数。若 adc~ 有多个参数，则被当作分配给其各出口的逻辑输入通道列表。若未提供参数，adc~ 将有两个出口，初始设为逻辑输入通道 1 和 2。

若把符号作为第一个参数提供给 adc~，其输出将来自 Max 混音器中一个具名的 inport 端口。若补丁层级中多个 adc~ 实例共用同一名称，它们将使用同一个混音器输入端口。

消息

int

非零的数字会打开所有已加载补丁中的音频处理。0 会关闭所有已加载补丁中的音频处理。

参数：

  • on/off-flag [int]

list

由整数组成的 list 为每个信号入口设置逻辑输入通道。

参数：

  • input-channel-designations [list]

(mouse)

双击 adc~ 会打开 Audio Status 窗口。

open

打开 Audio Status 窗口。

set

单词 set 后面跟两个数字，为对象的某个信号出口设置逻辑输入通道。第一个数字指定出口编号，其中 1 是最左侧的出口。第二个数字指定逻辑输入通道（1 到 1024）。若第二个数字为 0，该出口送出零信号。

参数：

  • logical-output-channel [int]
  • logical-input-channel [int]

start

打开所有已加载补丁的音频处理。

startwindow

只在此 adc~ 所在的补丁以及该补丁的子补丁中开启音频处理。关闭所有其他补丁中的音频处理。

stop

关闭所有已加载补丁的音频处理。

wclose

若 Audio Status 窗口已打开，则关闭它

输出

signal

来自硬件输入设备的音频以一系列信号输出，每个出口一路。
