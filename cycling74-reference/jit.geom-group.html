Jitter Geometry

jit.geom-group

Jitter Geometry 对象共有的消息与特性

参数

无。

特性

async [int]

启用异步几何体处理（默认值 = 1）。启用后，几何体处理在后台线程中进行。改变 async 的取值会改变所有绑定到该上下文的几何体运算符的这一取值。

bypass [int]

旁通几何体处理（默认值 = 0）。启用后，几何体输入会原样传给图中下一个几何体运算符。

enable [int]

启用该几何体运算符（默认值 = 1）。禁用后，不处理也不输出任何几何体。

name [symbol] 只读

几何体运算符名称（默认值 = UID）。查询 name 特性会返回该几何体运算符的唯一标识符 symbol。

消息

bang

为生成器类运算符输出几何体。其他类型的运算符会忽略该消息。

cancel

尝试取消该运算符中当前处于活动状态的任何几何体处理。

clear

清除并重置该几何体运算符。

output

为生成器类运算符输出几何体。其他类型的运算符会忽略该消息。
