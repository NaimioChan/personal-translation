jit.phys.multiple

用矩阵模拟多个刚体

描述

jit.phys.multiple 对象使用若干 jit.matrix 对象来模拟物理世界中的刚体。两个出口连接到 position 与 rotate 矩阵输入，也就是 jit.gl.multiple 对象，从而可以方便地可视化刚体形状。

讨论

可设置的参数包括 position、rotate、rotatexyz、scale、mass、friction、restitution、damping、force、torque 和 mesh。所有参数都接受 float32 矩阵。各参数矩阵的 dim 大小可以不同，它们会回绕到由 dimparam 特性指定的矩阵维度（mesh 除外）。

特性

constraint [symbol]

指定用于内部约束矩阵的约束类型（默认值 = none）。设置后，会沿位置矩阵的每个维度，在每个刚体与其最近邻之间自动创建约束。
可选值：

'none'
'point2point'
'hinge'
'barslide'
'conetwist'
'6dof'

constraint_matrix [int]

启用把约束位置报告为 jit_matrix（默认值 = 0）

constraintoutname [symbol]

约束输出矩阵名称

damping [2 floats]

设置施加到刚体上的线性与角度阻尼，取值范围为 0. 到 1.（默认值 0.2 0.2）。阻尼可用于模拟空气阻力。

enable [int]

在物理模拟中启用各刚体（默认值 = 1）。

enable_sleep [int]

对所有刚体启用休眠，当线性速度与角速度为 0 时会使其失活（默认值 = 0）。

filterclass [symbol]

设置该对象碰撞过滤器类的名称（默认值 = default）。其他对象必须在自己的 filters 列表中指定该 filterclass 名称，才能与此对象发生碰撞。允许的唯一名称最多为 10 个。

filters [10 symbols]

指定要与之启用碰撞的 filterclass 名称列表（默认值 = all）。可选值包括 all、worldbox 与 default。其他取值包括任何用户指定的 filterclass 名称（最多允许 10 个）。

force [3 floats]

用一个 3D 世界空间向量对各个刚体施加力（默认值 = 0 0 0）。若启用了 forces_relative，该向量会被转换到对象空间。

forces_relative [int]

forces_relative 标志会使所有力在施加前被转换到对象空间（默认值 = 0）。

friction [float]

摩擦力大小（反向力）（默认值 = 0.5）。当该刚体与另一个有摩擦的刚体接触时施加。

kinematic [int]

运动学标志（默认值 = 1）。使用该模式可以禁用各刚体上的动力学、启用碰撞，并用 position 与 rotate 矩阵来做动画。

local_scaling [int]

局部缩放标志（默认值 = 0）。启用后，scale 特性会对碰撞形状施加局部缩放变换。禁用后，每次修改 scale 时刚体都会从物理世界中移除并重新加入。

mass [float]

刚体质量（默认值 = 1.）。设为 0. 时刚体动力学被禁用，但碰撞仍然有效。

name [symbol]

指定实例的名称（默认值 = UID）。

physparams [11 symbols]

对应对象入口、可通过传入矩阵修改的物理刚体特性列表。有效特性为 position、rotation、rotatexyz、scale、mass、friction、restitution、damping、force、torque 和 mesh。

posoutname [symbol] 只读

位置输出矩阵名称

reduce_hull [int]

当刚体的 shape 特性设为 convexhull 时启用自动顶点精简（默认值 = 1）。

restitution [float]

恢复系数取值，即弹性（默认值 = 0.1）。与其他刚体碰撞时保留的动能比例。

rolling_friction [float]

滚动摩擦力大小（作用于滚动对象的反向力）（默认值 = 0.0）。当该刚体与另一个有摩擦的刚体接触时施加。

rotoutname [symbol] 只读

旋转输出矩阵名称

shape [symbol]

碰撞形状类型（默认值 = sphere）。
可选值：

'sphere'
'cube'
'capsule'
'cone'
'cylinder'
'convexhull'（会生成一个包住由 mesh 矩阵指定顶点的凸包。）
'concave'（会根据 mesh 矩阵指定的顶点，生成一个允许形状中有凹陷的凹形形状。）
'dynamicmesh'

shareshape [int]

启用刚体实例之间的碰撞形状共享（默认值 = 0）。启用后，所有刚体实例都会采用统一的形状缩放，并忽略 scale 矩阵（若存在）。

torque [3 floats]

用一个 3 维世界空间向量对刚体施加力矩（角力）（默认值 = 0 0 0）。

worldname [symbol]

刚体所绑定的 jit.phys.world 上下文的名称。

设置对象的字体。

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

可选值：

0 = 'None'
1 = 'Hint'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

更新刚体并输出矩阵

damping_matrix

若 damping 参数位于 physparams 列表中，用于该参数的具名矩阵。必须是 2 通道 float32 矩阵。

参数：

  • matrix name [symbol]

force_matrix

若 force 参数位于 physparams 列表中，用于该参数的具名矩阵。必须是 3 通道 float32 矩阵。

参数：

  • matrix name [symbol]

friction_matrix

若 friction 参数位于 physparams 列表中，用于该参数的具名矩阵。必须是 1 通道 float32 矩阵。

参数：

  • matrix name [symbol]

getconstraint_dict

把已修改的约束特性的字典描述从 dumpout 送出。

impulse

用一个由 x、y、z 描述的世界空间向量对刚体施加冲量（瞬时力）。可选参数 relative-x、relative-y、relative-z 描述刚体上施加该力的相对位置，未给出时为作用于刚体中心的力。

参数：

  • x [float]
  • y [float]
  • z [float]
  • relative-x [float]
  • relative-y [float]
  • relative-z [float]

mass_matrix

若 mass 参数位于 physparams 列表中，用于该参数的具名矩阵。必须是 1 通道 float32 矩阵。

参数：

  • matrix name [symbol]

mesh_matrix

若 mesh 参数位于 physparams 列表中，用于该参数的具名矩阵。指定一个由顶点取值组成的矩阵，用于确定刚体的凸包或凹网格。必须是 3 通道 float32 矩阵。

参数：

  • matrix name [symbol]

position_matrix

若 position 参数位于 physparams 列表中，用于该参数的具名矩阵。必须是 3 通道 float32 矩阵。

参数：

  • matrix name [symbol]

reset

重置所有实例刚体特性 position 与 quat，并把所有力清零。

restitution_matrix

若 restitution 参数位于 physparams 列表中，用于该参数的具名矩阵。必须是 1 通道 float32 矩阵。

参数：

  • matrix name [symbol]

rotate_matrix

若 rotate 参数位于 physparams 列表中，用于该参数的具名矩阵。必须是 4 通道 float32 矩阵。

参数：

  • matrix name [symbol]

rotatexyz_matrix

若 rotatexyz 参数位于 physparams 列表中，用于该参数的具名矩阵。必须是 3 通道 float32 矩阵。

参数：

  • matrix name [symbol]

scale_matrix

若 scale 参数位于 physparams 列表中，用于该参数的具名矩阵。必须是 3 通道 float32 矩阵。

参数：

  • matrix name [symbol]

sendbody

向某个刚体实例发送一条消息。若第一个参数是 symbol，则会把它当作刚体实例名。若第一个参数是整数，则后面应跟一个列表，其长度等于 position 矩阵的维度数。可用的消息包括 physparams 特性的所有取值（mesh 除外），以及 impulse 与 torque_impulse 消息。

参数：

  • body-name (optional) [symbol]
  • body-index (optional) [list]
  • message [symbol]
  • values [list]

sendbody_reset

向某个刚体实例发送一条消息，并附带 reset 消息。更多信息参见 sendbody 消息。

参数：

  • body-name (optional) [symbol]
  • body-index (optional) [list]
  • message [symbol]
  • values [list]

sendconstraint

向内部约束发送一条消息

torque_impulse

用一个由 x、y、z 描述的世界空间向量对刚体施加力矩冲量（瞬时角力）。

参数：

  • x [float]
  • y [float]
  • z [float]

torque_matrix

若 torque 参数位于 physparams 列表中，用于该参数的具名矩阵。必须是 3 通道 float32 矩阵。

参数：

  • matrix name [symbol]
