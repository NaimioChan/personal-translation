MSP

lessthaneq~

Is less than or equal to, comparison of two signals

描述

<=~ outputs a 1 signal when the left input is less-than or equal-to the right input and a 0 when it is less-than the right input. The right input can be a signal or a float.

参数

initial-comparison-value [number] 可选

Sets an initial comparison value for the signal coming into the left inlet. 1 is sent out if the signal is less than or equal to the argument; otherwise, 0 is sent out. If a signal is connected to the right inlet, the argument is ignored. If no argument is present, and no signal is connected to the right inlet, the initial value is 0 by default.

特性

fuzzy [atom] : 0.

非零时，用作模糊浮点比较的 epsilon 值。注意这不是一个绝对容差值，而是经过缩放以容纳极大值和极小值的相对误差。可以用 epsilon 一词来表示系统的 FLT_EPSILON 值。

为零（默认值）时，使用标准浮点比较，这可能导致看似相等的数字不被判定为相等。

消息

int

右入口：用于与左入口传入的信号做比较的数值。若右入口也连接了信号，则 float 或 int 会被忽略。

参数：

  • comparison-value [int]

float

右入口：用于与左入口传入的信号做比较的数值。若右入口也连接了信号，则 float 或 int 会被忽略。

参数：

  • comparison-value [float]

signal

In left inlet: The signal is compared to a signal coming into the right inlet, or a constant value received in the right inlet. If it is less-than or equal-to the value in the right inlet, 1 is sent out; otherwise, 0 is sent out.

In right inlet: The signal is used for comparison with the signal coming into the left inlet.

输出

signal

If the signal in the left inlet is less than or equal to the value in the right inlet, 1 is sent out; otherwise, 0 is sent out.
