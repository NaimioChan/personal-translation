jit.mo

jit.mo.line

用指定的函数生成动画化的单维矩阵

描述

用指定的函数生成动画化的单维矩阵。jit.mo.func 在性质上类似声音振荡器，可以依据给定的函数在整个矩阵上生成随时间变化的单元格取值。

参数

Dimension [number] 可选

设置输出矩阵的维度（元素个数）。若挂接到 jit.mo.join 对象（通过 join 特性），该取值会被覆盖。jit.mo 对象只支持 dimcount 为 1 的矩阵。

特性

rand_amt [float64]

缩放随机偏移值（默认值 = 0.0）。

start [float64]

线性函数起点（默认值 = -1.0）。

join [symbol]

设置 jit.mo.join 对象的绑定。设置之后，动画参数由该具名对象控制。

function [symbol]

用于生成矩阵的函数类型。可用的函数类型有 line、sin、saw、tri、perlin

delta [float64]

用于驱动函数图动画的帧增量时间（默认值 = 0.0）。绑定到 jit.mo.join 时，该值会自动设置。

offset [float64]

输出偏移（默认值 = 0.0）。

loop [long]

在动画时启用或禁用相位循环（默认值 = 1）。非循环的动画可以通过把相位设为 0 来重置

phase [float64]

输出相位偏移（默认值 = 0.0）。

period [long]

Perlin 噪声函数的周期长度（默认值 = 8）。

scale [float64]

输出乘数（默认值 = 1.0）。

end [float64]

线性函数终点（默认值 = 1.0）。

speed [float64]

动画速度乘数（默认值 = 0.0）。

loopreport [long]

启用动画循环报告（默认值 = 0）。启用后，动画循环时会从 dumpout 送出符号 loopnotify。

freq [float64]

输出频率（默认值 = 1.0）。函数在矩阵宽度上重复的次数
