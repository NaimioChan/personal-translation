mcs.amxd~

承载 Max for Live 设备

描述

用 mcs.amxd~ 对象加载 Max for Live 设备并在 MSP 中使用它。借助 mcs.amxd~，各个音频输入会被合并为一个多通道输入，其音频输出会被合并为一个多通道输出。

参数

devicename [symbol] 可选

要载入的 Max for Live 设备的名称。

特性

active [int] : 1

把 active 设为 false 会停用音频与 MIDI 处理。

annotation_name [symbol] :

添加在注释前面的字符串。它会显示在 Live 的 Info 窗格以及 Max 的 Clue 窗口中。

autosize [int] : 1

载入时自动计算 Max for Live 设备的窗口大小。

mcisolate [int] : 0

把参数变化隔离到指定通道。

parameter_enable [int]

允许此对象与 Max for Live Parameters 一起使用，并允许在 Max 环境中设置初始参数取值。

patchername [symbol] : <none>

指定要载入的 Max for Live 设备

showheader [int] : 1

为 Max for Live 设备显示 Header。

快照特性

autosave [int] 只写

保存所属补丁时，该对象快照的状态也会一并保存。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

anything

用一条由参数名和取值组成的消息来控制 Parameter 取值，例如："Gain -6"

参数：

  • Parameter [list]

(drag)

从补丁窗口侧栏或 Finder/Explorer 中把一个 Max for Live 的 .amxd 文件拖到 mcs.amxd~ 对象上，即可把该 Max for Live 设备载入该对象。

(mouse)

把 "open 1" 消息送往 mcs.amxd~ 对象，会打开 UI 编辑器，在那里你可以用鼠标调整参数。

drag_replace

在未锁定的补丁中，把任意 Max for Live 设备拖到 mcs.amxd~ 对象上即可替换已载入的设备。

getinfo

从第 3 出口获取关于某个特定参数的信息。

参数：

  • parameter-name [symbol]

getparams

从第 3 出口获取所有可用参数的列表。

getvalue

从第 3 出口获取某个特定参数的取值。

参数：

  • parameter-name [symbol]

midievent

midievent 一词后跟两到四个数字，会把一个 MIDI 事件发送给 Max for Live 设备。前三个数字参数是 MIDI 消息的字节。第四个（可选）参数是用于 MIDI 音符消息的失谐参数。取值范围为 -63 到 64 音分，默认值为 0。

参数：

  • MIDI-message (2 to 4 numbers) [list]

midiin

在第二个入口，向该 Max for Live 设备发送 MIDI 消息。

参数：

  • MIDI [int]

open

不带参数的 open 消息会为 Max for Live 设备打开一个浮动窗口。若该窗口此前打开过，则会把它所在位置的编辑窗口带到前面。

参数：

  • window-coordinates [list]

signal

要由 Max for Live 设备处理的输入。若该设备是乐器插件，该输入会被忽略。

快照消息

snapshot >= 7.0.0

创建快照。embedsnapshot 打开时，快照会保存到当前补丁中；否则会保存到外部文件。可以通过该消息的一个参数指定文件名。

参数：

  • file-name [symbol]

restore >= 7.0.0

恢复快照。embedsnapshot 打开时，会使用嵌入当前补丁中的快照；否则会从外部文件加载。可以通过该消息的一个参数指定文件名。

参数：

  • file-name [symbol]

addsnapshot

添加新快照。若没有参数，会把新快照追加到当前快照列表末尾。若第一个参数是包含文件路径的字符串，Max 会尝试把 .maxsnap 文件保存到该位置。若第一个参数是数字，会把快照保存到该槽位，其后的槽位索引依次递增。若第二个参数是字符串，会设置该快照的名称。

参数：

  • userpath [String]
  • index [Number]
  • name [String]

deletesnapshot

删除给定索引处的快照，其后的槽位索引依次递减。

参数：

  • index [Number]

exportsnapshot

从第一个参数指定的索引处导出快照。第二个参数指定导出 maxsnap 文件的文件名与路径。若第二个参数为空，会打开 File 对话框，供你指定文件名和位置。

参数：

  • index [Number]
  • filename [String]

importsnapshot

把快照导入到第一个参数指定的索引处。第二个参数指定要加载 maxsnap 文件的文件名与路径。若第二个参数为空，会打开 File 对话框，供你选择文件。

参数：

  • index [Number]
  • filename [String]

setsnapshotname

设置给定索引处快照的名称。

参数：

  • index [Number]
  • name [String]

setembedsnapshot

设置该索引处快照的嵌入状态。

参数：

  • index [Number]
  • embedstate [Number]

movesnapshot

更改快照的索引。

参数：

  • srcindex [Number]
  • dstindex [Number]
