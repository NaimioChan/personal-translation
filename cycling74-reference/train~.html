MSP

train~

脉冲串发生器

描述

train~ 生成一个脉冲信号，其周期可以用毫秒来指定（关于以指定频率生成脉冲波的方法，见 <~）。它在从 0 变为 1 时还会送出 bang，因此可以用作间隔为浮点数的节拍器。

讨论

如下例所示，该信号输出可以用作 sah~ 的控制输入；而在间隔非常小的时候，它是可以听到的。

参数

inter-pulse-interval [number] ms 可选

以毫秒为单位设置脉冲间隔的初始取值。默认值为 1000 ms。若有信号对象连接到该入口，则相应的初始参数取值会被忽略。

pulse-width [number] 可选

设置脉冲宽度的初始取值。默认值为 0.5。若有信号对象连接到该入口，则相应的初始参数取值会被忽略。

phase [number] 可选

设置脉冲相位的初始值。默认为 0。若有信号对象连接到该入口，对应的初始参数取值会被忽略。

特性

interval [float]

指定从左出口送出的脉冲串的周期（脉冲循环之间的时间间隔），单位为毫秒。信号输入会覆盖该特性取值。

phase [float]

设置脉冲 “开” 部分起音的相位。取值为 0 时，“开” 部分位于间隔的开头；其他取值（最大为 1，与 0 等效）会把 “开” 部分延迟总脉冲间隔的某个比例。信号输入会覆盖该特性取值。

resetmode [int]

当 resetmode 设为 1 时，train~ 会推迟间隔的变化。若间隔为 2000，而你把它改为 400，train~ 会等到当前循环结束才把间隔改为 400。当 resetmode 设为 0（默认值）时，间隔会立即改变。

width [float]

控制脉冲宽度或占空比。取值为 0 时 “开” 脉冲最小，取值为 1 时最大。取值为 0.5 时，脉冲处于 1 的时间与处于 0 的时间各占一半。信号输入会覆盖该特性取值。

消息

bang

向 train~ 发送 bang 会重置循环，使 train~ 的 “高” 部分立即开始。

int

可以用数字代替信号对象来控制周期、脉冲宽度和相位。若入口同时还连接了 signal，float 与 int 消息会被忽略。

参数：

  • parameter-settings [int]

float

可以用数字代替信号对象来控制周期、脉冲宽度和相位。若入口同时还连接了 signal，float 与 int 消息会被忽略。

参数：

  • parameter-settings [float]

signal

左入口：指定从左出口送出的脉冲串的周期（脉冲循环之间的时间间隔），单位为毫秒。

中间入口：控制脉冲宽度或占空比。信号取值表示脉冲间隔中用于脉冲 “开” 部分（信号取值为 1）的比例。取值为 0 时 “开” 脉冲最小（通常只有一个采样点），取值为 1 时最大（通常是整个间隔减去一个采样点）。取值为 0.5 时，脉冲处于 1 的时间与处于 0 的时间各占一半。

右入口：设置脉冲 “开” 部分起音的相位。取值为 0 时，“开” 部分位于间隔的开头；其他取值（最大为 1，与 0 等效）会把 “开” 部分延迟总脉冲间隔的某个比例。

输出

bang

右出口：当脉冲的 “开” 部分开始时，会从右出口送出一个 bang。借助该出口，你可以把 train~ 当作与信号同步的节拍器使用，其间隔可以用浮点取值（或 signal）指定。不过，脉冲的 “开” 部分与 bang 消息的实际输出之间存在不可预测的延迟，这部分取决于当前的 Max 调度器间隔。若调度器间隔设为 1 毫秒，则可保证延迟不超过一毫秒。

signal

左出口：具有指定间隔、宽度和相位的脉冲（矩形）波串。
