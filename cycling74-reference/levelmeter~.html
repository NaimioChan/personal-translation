MSP

levelmeter~

RMS 电平表

描述

当你需要一个带动态响应特性的信号电平表时，请使用 levelmeter~。meter~ 对象以更简单、更紧凑的形式提供电平测量。

参数

无。

特性

attack [atom_long] : 300

attack 一词后面跟一个数字，以毫秒为单位设置 levelmeter~ 对象的起音时间。默认值为 0。

bgcolor [4 floats]

以 RGBA 格式设置背景颜色。

coolcolor [4 floats] : 0.70588 0.82353 0.39126 1.

设置 levelmeter~ 对象较低的“冷”色范围颜色的 RGBA 取值。

displaychan [int] : 1

显示通道

hotcolor [4 floats] : 0.86275 0.39126 0.39126 1.

设置 levelmeter~ 对象热的“过载”范围颜色的 RGBA 取值。

inactivealpha [float] : 0.3

当把多通道信号发送到 levelmeter~ 时，inactivealpha 特性用于设置未聚焦通道的表针颜色的 alpha 取值。

interval [atom_long] : 20

以毫秒为单位设置 levelmeter~ 显示的更新间隔时间。最小更新间隔是 10 毫秒，最大是 2 秒，默认是 100 毫秒。该消息还会设置 levelmeter~ 送出在该时间间隔内收到的峰值的速率。

markercolor [4 floats]

以 RGBA 格式设置标记颜色。markercolor 特性映射到 accentcolor 样式颜色。

markers [8 ints] : -60 -48 -36 -24 -12 -6 0 6 12

设置 levelmeter~ 显示中标记的数值位置（例如 -60 -48 -36 -24 -12 -6 0 6 12）。

markersused [int] : 9

设置 levelmeter~ 显示中的标记数量。

needlecolor [4 floats]

以 RGBA 格式设置 levelmeter~ 对象表针的颜色取值。needlecolor 特性映射到 color 样式颜色。

offset [atom_long] : 0

设置 levelmeter~ 对象显示的分贝偏移。

range [2 atom_longs] : -60 12

设置 levelmeter~ 对象的显示范围。默认范围是 -40 dB 到 12 dB。

release [atom_long] : 300

以毫秒为单位设置 levelmeter~ 对象的释音时间。默认值为 0。

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

warmcolor [4 floats] : 0.86275 0.58824 0.31373 1.

设置 levelmeter~ 对象中间的“暖”色范围颜色的 RGBA 取值。

消息

bang

输入信号最近一次算出的 RMS 幅度由屏幕电平表上的表针显示并输出。

int

int 设置 levelmeter~ 显示并输出的 dB 值。

参数：

  • input [int]

clear

clear 一词清除 FB 延迟级的内存。

mode

mode 一词后面跟一个 0 到 5 之间的整数，会把 levelmeter~ 的工作模式设置如下：
0 = "fast"（无动态响应特性或分贝偏移）
1 = "VU"（起音 = 330；释音 = 330；分贝偏移 = -20）
2 = "DIN 45 406(IEC PPM type IIb)"（起音 = 10；释音 = 1500；分贝偏移 = -14）
3 = "BBC (IEC PPM type IIa)"（起音 = 10；释音 = 3000；分贝偏移 = -14）
4 = "Nordic (IEC PPM type I)"（起音 = 5；释音 = 2000；分贝偏移 = -14）
5 = "EBU Digital"（起音 = 0；释音 = 1500；分贝偏移 = -14）
（对象默认采用 "fast" 模式。）

参数：

  • operational-mode [int]

(mouse)

若输入是 MC 信号，点击数字下方的圆点即可选择要显示的通道值。

signal

输入信号的 RMS 幅度由屏幕电平表上的表针显示。收到多通道信号时，各通道的 RMS 幅度会分别显示在各自的通道选择器上。

输出

int

音频处理打开时，信号在当前更新间隔内的 RMS（均方根）值（以分贝为单位）会从出口送出。
