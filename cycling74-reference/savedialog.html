Max

savedialog

打开询问文件名的对话框

描述

打开文件对话框，用于选择或输入要写入的文件名。savedialog 接受一个或多个文件类型构成的列表，允许你保存文件并为其选择类型。

讨论

要选择文件夹，请使用 "fold" 类型。savedialog 会报告所选文件或文件夹的完整路径名，可在 write 或 save 一词之后把它传给任何 Max 对象。

参数

filetypes [symbol] 可选

设置一个或多个将作为选项显示给用户的文件类型。符号 fold 规定对话框只应让用户选择文件夹。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

使标准的 Save As 对话框出现，允许用户输入文件名并选择文件夹位置。得到的位置和文件名会作为符号输出。

anything

一个或多个 四字母文件类型代码 设置对话框中显示的类型列表。文件的示例类型代码有：TEXT 表示文本文件，maxb 表示 Max 二进制格式补丁文件，AIFF 表示 AIFF 格式音频文件。符号 fold 规定对话框只应让用户选择文件夹。

参数：

  • filetype [list]

name

name 一词后面跟一个符号，指定默认文件名。

参数：

  • filename [symbol]

path

若指定路径有效，则打开指向该路径的标准对话框窗口，并缓存该路径，供其后通过 bang 消息打开时使用。省略 filepath 参数会取消此前设置的任何路径。

参数：

  • filepath [symbol]

set

set 一词后面跟 四字母文件类型代码，会在不打开对话框的情况下把 savedialog 对象设置为显示所需的文件类型。用户在对话框中选择 Save 时，所选的文件类型会从中间出口送出。

参数：

  • filetype [list]

setpath

指定用 bang 消息打开标准对话框窗口时要使用的目录路径（前提是该路径有效）。省略 filepath 参数会取消此前设置的任何路径。

参数：

  • filepath [symbol]

输出

bang

右出口：若用户在对话框中选择 Cancel，或发生错误，则会送出一个 bang。

symbol

左出口：文件的绝对路径名，以符号形式给出。输出的路径名包含斜杠分隔符。

绝对路径名的样子如下：

"C:/Max Folder/extras/mystuff/mypatch.pat"

conformpath 对象可用于把一种 pathtype 和/或 pathstyle 的路径转换为另一种。

symbol

中间出口：四字母文件类型代码，指定当前选中的文件类型。
