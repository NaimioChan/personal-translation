Max

pictctrl

基于图片的控件

描述

用图片文件中的图像作为外观，创建按钮、开关、旋钮及其他控件。

讨论

注意：pictctrl 对象对象惯常使用以 Portable Network Graphics（.png）格式保存的图像。如果你在 Windows 上使用 Max，我们建议你安装 QuickTime 并选择完整安装所有可选组件，以便处理 PNG 或 PICT 文件以外的图像。

参数

无。

特性

active [int] : 1

切换 pictctrl 对象的鼠标控制。默认值为 1（启用）。若 pictctrl 对象的图片文件中存在另一组非活动图像，且设置了 inactive images 特性，active 消息还会改变控件的外观。

annotation_name [symbol] :

信息视图标题

clickedimage [int] : 0

切换是否使用图片文件中的另一组图像帧，以便用户点击并拖动鼠标指针时让旋钮呈现不同的外观。clickedimage 0 会禁用该功能。

clickincrement [int] : 0

设置每次点击对象时输出值递增 1（点击递增模式）。点击后的任何鼠标移动都会被忽略。达到最高值后，下次点击时取值回到零。所有其他鼠标跟踪模式都被禁用。clickincrement 0 会禁用点击递增模式。

clip [int] : 1

使 pictctrl 在旋钮模式下把鼠标移动限制在旋钮的范围内。后面跟 0 时，pictctrl 在超出最大值（在旋钮范围内）时会回绕到最小值，反之在超出最小值时会回绕到最大值。

degrees [int] : 270

指定 pictctrl 在旋钮模式下的旋转角度。

frames [int] : 10

指定图片文件中的图像数量（列数）。帧数不必与控件的取值范围相同；对于任何给定的取值，pictctrl 对象都会使用最接近的图像。

imagemask [int] : 0

非零时，表示你的图片文件带有图像蒙版。默认值为 0（无图像蒙版）。启用 imagemask 会启用对图像透明部分的检查。若 threshold 特性设为大于零且小于 1 的值，对图像 transport 部分的鼠标点击会被 pictctrl 忽略。

inactiveimage [int] : 0

非零时，表示你的图片文件为它的非激活状态额外带有一行图像。默认值为 0（无非激活状态）。

mode [int] : 0

选择 pictctrl 对象的操作模式。
Button（默认）
Toggle
Dial mode
可选值：

0 = 'Button'
1 = 'Toggle'
2 = 'Dial'

multiplier [int] : 0

设置一个倍率值。当 pictctrl 处于旋钮模式时，对象的取值会在送出出口之前乘以该数字。乘法发生在加上偏移值之前。默认倍率值为 1。

name [symbol] : <default>

指定 pictctrl 对象将用于将用于控件的按钮或旋钮文件的图形文件。按照惯例，pictslider 对象使用以 Portable Network Graphics（.png）格式保存的图像。如果你在 Windows 上使用 Max，并想处理 PNG 或 PICT 文件以外的图像，我们建议你安装 QuickTime 并选择完整安装所有可选组件。用作文件名的符号必须是 Max 当前搜索路径中某个文件的名称，或者该文件的绝对路径名（例如 "MyDisk:/Documents/UI Pictures/CoolButton.png"）。

offset [atom_long] : 0

设置一个偏移值。当 pictctrl 处于旋钮模式时，偏移值会在送出出口之前加到对象的取值上。默认偏移值为 0。

param_connect [symbol] :

在对象与具有参数的兼容对象（如 gen~ 或 jit.gl.slab）的某个参数之间建立双向连接。该对象可用来改变参数的值，参数值变化时它也会随之更新。设置 param_connect 最简便的方法，是使用该特性在 inspector 中的菜单，或使用 Object Action 菜单的 Connect 子菜单。菜单会列出兼容对象的所有可用参数。

用消息设置 param_connect 特性时，需要给出目标参数的路径，即宿主对象的脚本名后跟两个冒号，再加上参数名。例如，对于一个 gen~ 对象，若其脚本名为 gen~_AB，则 freq 参数的路径为 gen~_AB::freq。可以在宿主对象或参数尚不存在时就为 param_connect 设值，该对象会在参数出现后与之建立连接。更多细节请参阅用户指南中 param_connect 条目。

parameter_enable [int]

启用本对象以配合 Max for Live Parameters 使用，并可在 Max 中设置参数的初始值。

parameter_mappable [int] : 1

启用 parameter_mappable 后，该对象即可通过映射功能映射到键盘或 MIDI 输入。

range [int] : 128

设置 pictctrl 对象在旋钮模式下的取值范围。默认值为 128。

ratio [int] : 2

指定鼠标指针必须移动多少个像素，旋钮的值才会改变一个增量。若 pictctrl 对象使用环形跟踪，ratio 消息指定光标相对于对象中心必须移动多少度才能使取值增加一。

snap [int] : 0

设置 pictctrl 贴合到图像的原始大小。后面跟 0 时，pictctrl 不会贴合到图像的原始大小。

threshold [float] : 0.

threshold 特性是某个 alpha 值，图像像素的 alpha 值必须超过它，鼠标点击才会生效。这样就可以使用带透明度的图像，图像中透明的部分不会记录鼠标点击。要让该特性生效，应把它设为大于零且小于 1 的值（建议值为 0.5）。把 threshold 设为更高的值可以忽略图像中半透明的部分。若要忽略对图像透明部分的点击，你还需要使用 PNG 格式的图像文件，并告知 pictctrl 对象你的图像带有透明度，方法是启用 imagemask 特性。

trackcircular [int] : 0

设置 pictctrl 对象在你点击它并相对于控件中心沿圆弧拖动鼠标时作出响应（环形跟踪模式）。顺时针移动鼠标会增大控件的值，逆时针移动则减小其值。启用环形跟踪会禁用所有其他跟踪模式。trackcircular 0 会禁用环形跟踪。

trackhorizontal [int] : 0

设置 pictctrl 对象在你点击它并水平拖动鼠标时作出响应；向右移动鼠标会增大对象的取值，向左移动则减小该值。启用这种操作模式会禁用环形跟踪模式和点击递增模式（见 clickincrement 和 trackcircular 消息）。

tracking [int] : 0

切换实时跟踪。若实时跟踪开启，按住鼠标按键在对象的矩形边界内外移动时，pictctrl 对象会改变其状态。tracking 0 会禁用实时跟踪

trackvertical [int] : 0

让 pictctrl 对象在你点击它并垂直拖动鼠标时作出响应；向上移动鼠标会增大对象的值，向下移动则减小该值。启用这种操作模式会禁用 环形跟踪模式 和 点击递增模式 模式（参见 clickincrement 和 trackcircular 消息）。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

图片文件格式

Specifications

在补丁窗口中新建 pictctrl 对象时，它没有关联的图片文件。用 Inspector 中的 Open 按钮为该控件选择图片文件。按惯例，pictctrl 对象使用以 Portable Network Graphics（.png）格式保存的图像。如果你在 Windows 上使用 Max，且想使用 PNG 或 PICT 文件以外的图像，我们建议你安装 QuickTime，并选择完整安装所有可选组件。文件中图片的布局随 pictctrl 所使用的操作模式而变化。三种模式都要求图片由网格状排列的图像组成，其中所有图像的宽度和高度都相同。

Button 模式布局最简单：



第一行图像是必需的：这两幅图像分别用于按钮的空闲状态和点击状态（对应取值 0 和 1）。下一行图像（如果存在）用于控件处于非激活状态时的显示。再后面的各行包含顶行图像的蒙版，以及非激活图像（如果存在）。

Toggle 模式布局类似：



在这种模式下，最上面两行是必需的。第一行图像用于控件取值为 0 时，下一行用于取值为 1 时。第三行是可选的；它用于控件处于非激活状态时的显示。（注意，非激活状态没有 "clicked" 图像，因为控件处于非激活状态时会忽略鼠标点击。）再后面的各行包含图像的蒙版。

Dial 模式的布局尺寸取决于它有多少个图像帧，该数量必须与 Inspector 中设置的 Image Frames 参数一致：



第一行图像是必需的：控件的每一个视觉上不同的状态各对应一幅图像。你希望旋钮有多少个可见状态，就需要多少幅 pict。注意，旋钮能够接收和送出的取值范围比 pict 所表示的范围更大（例如，即使你只用八个 pict 帧来表示旋钮的范围，你的旋钮范围也可以是 128）。下一行图像是可选的，用于用户在对象上点击并拖动以改变其值时。再接下来的一行也是可选的；（注意，非激活状态没有 "clicked" 图像，因为控件处于非激活状态时会忽略鼠标点击。）随后的各行包含图像的蒙版。

输出

int

pictctrl 对象的当前值。在 toggle 和 button 模式下，该值为 0 或 1。在 dial 模式下，该值由你在 Inspector 窗口中设置的范围、偏移和倍数决定。
