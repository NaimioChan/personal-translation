Max

multislider

把数据显示为滑块或滚动显示

描述

把数据显示为滑块数组或滚动显示。配置为滑块时，取值以数字列表的形式设置（和输出）。配置为滚动显示时，multislider 接收数字，把它们绘制出来，并滚动显示区域。

讨论

滑块值通过向 multislider 对象发送列表来设置，该对象会自动重新配置，使滑块数量与列表中的元素数量相同。滑块的数量、它们的范围、样式以及其他特性都可以在该对象的 Inspector 中设置。绘制样式包括条形或细线滑块手柄（在把它用作滑块时），或者在滚动模式下使用点值或零到点。

参数

无。

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

清除处于滚动模式的 multislider 对象。

select

有选择地设置滑块取值。例如 select 1 30 2 4 5 50 把第一个滑块设为 30、第二个设为 4、第五个滑块设为 50（最上方或最左侧的滑块永远是 1 号）。

参数：

  • value-pairs [list]

set

set 一词后面跟一个滑块编号和一个取值，会把该编号的滑块设为该取值，且不触发任何输出。

参数：

  • slider [number]
  • value [number]

setlist

setlist 一词后面跟一个滑块取值列表，会把各滑块设为列表中列出的取值，且不触发任何输出。

参数：

  • values [list]

setmax

setmax 一词后面跟一个数字，设置 multislider 对象的高值。

参数：

  • value [float]

setmin

setmin 一词后面跟一个数字，设置 multislider 对象的低值。

参数：

  • value [float]

sum

以 float 输出当前所有滑块取值之和。

输出

float

右出口：由 fetch 消息指定的某个编号滑块的取值。输出会反映当前的数据类型设置（见 settype 消息）。

int

右出口：由 fetch 消息指定的某个编号滑块的取值。输出会反映当前的数据类型设置（见 settype 消息）。

list

左出口：当 multislider 在其入口收到 list、int 或 float 时，会输出一个包含其当前取值的列表。用鼠标改变滑块时也会送出该列表。
