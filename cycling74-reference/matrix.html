Max

matrix

事件路由矩阵

描述

matrix 对象控制各入口与出口之间的连接。你可以把任意入口路由到出口的任意组合。每条连接都有一个关联的增益系数，所有流经 matrix 的值都可以缩放。它与信号对象 matrix~ 共用同一套控制协议，但与 matrix~ 不同，matrix 对象的出口不会把多个输入的取值相加。最好把 matrix 理解为功能多得多的 gate 和 switch 的组合。

参数

number-of-inputs [int] 可选

设置输入的数量；若未给出，默认值为 2。

number-of-outputs [int] 可选

设置输出的数量；若未给出，默认值为 2。

default-connect-gain [float] 可选

若第三个参数给出了一个浮点数，它为 connect 消息设置一个默认增益，用于 connect 的增益参数未提供的情形。

特性

defaultgain [float]

默认增益

exclusive [int]

互斥连接
可选值：

0 = 'Off'
1 = 'Inputs'
2 = 'Outputs'
3 = 'Inputs + Outputs'

inhibit [int]

启用 inhibit 后，bang 或 clear 这类消息不会通过 matrix 传递。

inrange [float]

设置输入范围，用于约束传入的取值和/或缩放。设置输入范围后，传入的数字和列表会被约束在范围之内。若同时设置了 outscale 特性，传入的取值还会被缩放，从而从输入范围映射到输出缩放。

outscale [float]

设置输出范围，用于约束输出的取值和/或缩放。设置输出缩放后，取值在从对象各出口送出之前会被约束在范围之内。若同时设置了 inrange 特性，传入的取值还会被缩放，从而从输入范围映射到输出缩放。

scalemode [int]

启用 scalemode 特性后，输入缩放、增益缩放和输出缩放会应用到不以数字开头的消息中的数字参数。例如，启用 scalemode 后，消息 set 74 会对 74 进行缩放。

消息

list

左入口：列表会添加或移除入口与出口之间的一条连接。消息的格式为 input index（对象从左数第二个入口从 0 开始）、output index（从 0 开始）、gain。非零增益会添加一条具有指定增益的连接；增益为 0 会删除该连接（若存在）。
在其他任何入口收到的列表会被路由到任何已连接的出口。

clear

左入口：clear 消息会移除所有入口与出口之间的连接。

connect

左入口：connect 一词后面跟入口索引、出口索引以及可选增益，会添加入口与出口之间的一条连接。若未给出增益值，该连接将使用默认增益（通过键入的参数或 defaultgain 特性设置）。

参数：

  • index [list]

dictionary

dictionary 一词后面跟一个命名 Max 字典对象的符号，会用字典中的连接替换所有连接。若字典中没有连接，则清除现有连接。要查看字典的格式，请发送 dumpdictionary 消息，并打印或以其他方式捕获从对象左出口送出的结果字典。

参数：

  • dictionary name [symbol]

disconnect

左入口：disconnect 一词后面跟入口索引和出口索引，会删除入口与出口之间的一条连接（若存在）。

参数：

  • index [list]

dumpconnections

dumpdictionary 消息会输出一条 Max 字典消息，列出 matrix 对象当前的所有连接。
