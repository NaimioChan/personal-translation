funnel

用入口编号标记数据

描述

标识传入数据的入口。它可以根据来源把取值存储到 table 或 coll 中，也可以用 spray 这样的对象来设置目标。

参数

inlets [int] 可选

第一个参数设置 funnel 的入口数量。若没有参数，则有两个入口。

offset [int] 可选

第二个参数为第一个入口编号指定偏移量。若没有第二个参数，入口编号从 0 开始。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'

4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

任意入口：该入口的编号，以及该入口中存储的（最近收到的）数字，作为两个元素的列表送出。

int

任意入口：该入口的编号和收到的数字作为列表送出。

参数：

  • input [int]

float

任意入口：该入口的编号和收到的数字作为列表送出。

参数：

  • input [float]

list

任意入口：该入口的编号会前置到列表中，然后送出这个新列表。在列表中，float 不会被转换成 int。列表可以包含 int、float 和 symbol（前提是列表的第一个元素不是 symbol）。

参数：

  • inputs [list]

anything

功能与 list 相同。

参数：

  • inputs [list]

offset

单词 offset 后面跟一个数字，会按给定数字为入口编号设置偏移量。

参数：

  • offset [int]

set

任意入口：单词 set 后面跟一串与入口数量相对应的数字，会设置输入的数字列表，而不把它们送经各出口。

参数：

  • inputs [list]

输出

list

当任意入口收到数字或列表时，funnel 会输出一个由入口编号后接输入组成的列表。funnel 与其他对象（如 coll、funbuff 和 table）配合使用会很有用。
