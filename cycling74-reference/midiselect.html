midiselect

选择并解读原始 MIDI 数据

描述

midiselect 接收原始 MIDI 字节并分离输入流。要选出用于输出的 MIDI 数据通过对象特性来设置。每个 MIDI 数据选择特性都对应一个独立的数据出口。任何未被选中的输入数据都会从对象的第八个出口送出。

讨论

注意：由于 MIDI 编码的特性，ch 特性的使用是累积的：需要指定至少一个通道；否则所有原始 MIDI 数据都会从第 8 个出口送出。

参数

无。

特性

bend [int] : 0

当 bend 特性设为 1 时，Pitch Bend 信息从第 6 个出口送出，否则 Pitch Bend 会作为 raw MIDI Data 从第 8 个出口送出。

ch [16 atoms]

ch 特性让你指定要选中哪些 MIDI 输入channels。你可以通过实例化 midiselect 对象并给出参数 @ch all 来选择所有通道的输入，也可以选择特定通道（例如，参数 @ch 1 3 5 只会选中第一、第三和第五个通道上的 MIDI 信息）。

ctl [128 atoms]

ctl 特性让你指定要选中哪些 MIDI controller 消息。默认不选中任何 controlers。你可以选择要过滤的特定 controller（例如，参数 @ctl 7 9 64 会选中 controller 7（Volume）、9（Pan）、64（Sustain Pedal））。要选中所有 controller，使用参数 @ctl all。要不选中任何 controller（默认），使用 @ctl none。

hires [int] : 0 >= 8.1.6

0 - 2 范围内的整数设置 midiparse 对象用于弯音消息的范围。
可选值：

0 = 'Off (0-127)'（标准 8 位 MIDI 弯音范围（默认））
1 = 'Float (-1 to 1)'（在音频信号范围内使用弯音消息）
2 = '14-bit Fixed (-8192 to 8191)'（标准 14 位 MIDI 高分辨率弯音范围）

note [128 atoms]

note 特性让你指定要选中哪些 MIDI note 消息。默认不选中任何 notes。你可以选择要过滤的特定音符（例如，@note 60 64 67 会选中 C4、E4、G4 音符）。要选中所有音符，使用参数 @note all。要不选中任何音符（默认），使用 @note none。

pgm [int] : 0

当 pgm 特性设为 1 时，Program Change 信息从第 4 个出口送出。否则，Program Change 会作为 raw MIDI Data 从第 8 个出口送出。

poly [128 atoms]

poly 特性让你指定要选中哪些 MIDI poly pressure。默认不选中任何 poly pressure。你可以选择要过滤的特定音符（例如，@poly 60 64 67 会选中 C4、E4、G4 音符）。要选中所有音符，使用参数 @poly all。要不选中任何音符（默认），使用 @poly none。

touch [int] : 0

当 touch 特性设为 1 时，After touch 数据从第 5 个出口送出。否则，Aftertouch 会作为 raw MIDI Data 从第 8 个出口送出。

消息

bang

清除 midiselect 对象对到此刻为止收到的任何不完整 MIDI 消息的记忆。

int

入口收到的数字（通常来自 seq 或 midiin 对象）会被当作 MIDI 消息的字节处理。状态字节和过滤特性决定用哪个出口输出数据字节。

参数：

  • byte [list]

float

入口收到的浮点数会被转换为整数值，并当作 MIDI 消息的字节处理。状态字节和过滤特性决定用哪个出口输出数据字节。

参数：

  • byte [float]

输出

int

第 4 个出口：该数字是 program change。

第 5 个出口：该数字是触后（channel pressure）取值。

第 6 个出口：该数字是弯音取值。

第 7 个出口：该数字是 MIDI 通道号。

list

最左出口：一条 note-on 消息。第一个数字是音高取值，第二个数字是力度取值。

第 2 个出口：一条复音键压力消息。第一个数字是触后（压力）取值，第二个数字是音高取值（键号）。

第 3 个出口：一条控制消息。第一个数字是控制取值，第二个数字是控制器号。
