sfinfo~

报告音频文件信息

描述

sfinfo~ 给出声音文件的通道数、采样位数、采样率、sampletype、文件名与时长。

参数

filename [symbol] 可选

指定一个文件，sfinfo~ 在随后收到 bang 消息时会报告该文件的信息。该文件必须存在于 Max 搜索路径中。

特性

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

bold italic

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

设置对象的字体大小（单位：磅）。
可选值：

'8'

切换补丁锁定后对象是否隐藏。

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

设置对象是否属于补丁的演示模式。

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

若文件已经打开（无论是用 open 消息打开，还是通过 sfinfo~ 的参数指定），bang 会从 sfinfo~ 对象的出口报告通道数、采样位数、采样率和以毫秒为单位的长度。

(drag)

把支持的音频文件直接拖到 sfinfo~ 上即可报告信息。

getnamed

左入口：单词 getnamed 后面跟一个 symbol，用来指定某个 sfplay~ 对象的名称，此时会查询这个具名的 sfplay~ 对象，并从它的出口报告通道数、采样位数、采样率、以毫秒为单位的文件长度、采样类型和文件名。

参数：

  • object-name [symbol]

open

open 一词后面跟一个音频文件的名称时，若该文件存在于 Max 的搜索路径中就会打开它。若不带文件名，open 会调出标准的打开文件对话框，让你选择一个文件。文件被打开后，sfinfo~ 会查询该文件，并从它的出口报告通道数、采样位数、采样率、以毫秒为单位的文件长度、采样类型和文件名。

参数：

  • filename [symbol]

输出

alaw

8 位 a-law 编码

第六个出口：音频文件的文件名

float

第三个出口：音频文件的采样率。

第四个出口：音频文件以毫秒为单位的时长。

float32

32 位浮点数

float64

64 位浮点数

int

左出口：音频文件中的通道数。

第二个出口：音频文件的采样位数（通常为 16）。

int16

16 位整数

int24

24 位整数

int32

32 位整数

int8

8 位整数

mulaw

8 位 "mu"-law 编码

symbol

第五个出口：音频文件的采样类型。

支持以下类型的采样数据：

uint8

无符号 8 位整数
