Max

seq

用于录制和播放 MIDI 数据的音序器

描述

seq 是原始 MIDI 字节的音序器。你可以控制播放速度（仅在你启动播放时），读写文件，以及从实时 MIDI 输入录制。另见 midiparse 和 midiformat，在原始 MIDI 形式与常规形式之间转换时你可能需要它们。

参数

filename [symbol] 可选

指定一个文件名，在加载补丁时自动读入 seq。

特性

overridetempo [int] : 0

若启用（默认值 = 0（禁用）），tempo 特性的取值将覆盖序列所请求的任何速度。这种情况下，读取新文件时不会更新 tempo 特性，序列数据中出现 tempo 元消息时也不会更新。在此情况下，元消息仍会从 seq 对象的右出口输出。

sequencetempo [float] 只读

序列未经修改的速度。这是一个只读取值，仅为方便使用。

tempo [float] : 120.

若 seq 读取过含速度信息的 MIDI 文件，tempo 特性会反映当前播放时间处的当前速度。若文件没有速度信息，默认速度为 120。（120 BPM）。可以修改 tempo 特性来改变播放速度，但它会被 MIDI 文件中存在的速度变化覆盖，也会在读取新 MIDI 文件时被覆盖。

消息

bang

开始播放存储在 seq 中的序列。

int

当 seq 正在录制时，其入口收到的数字会被解释为 MIDI 消息的字节（通常来自 midiformat 或 midiin）。MIDI 通道消息和系统独占消息可以被 seq 录制，但 seq 不直接响应 start、stop、MIDI clock 等 MIDI 实时消息。

参数：

  • input [int]

float

转换为 int。

参数：

  • input [float]

addeventdelay

addeventdelay 一词后面跟一个数字，会在所录制序列中第一个事件的 delay 起始时间（单位：毫秒）上增加该数字。序列中的所有事件都会被平移，使第一个事件在指定的起始时间发生。

参数：

  • onset-time (milliseconds) [float]

append

在已存储序列的末尾开始录制，不清除现有序列。

clear

清除当前存储在 seq 对象中的序列。

delay

delay 一词后面跟一个数字，会设置所录制序列中第一个事件的起始时间，单位毫秒。序列中的所有事件都会被平移，使第一个事件在指定的起始时间发生。

参数：

  • onset-time (milliseconds) [int]

dump

打开标准的 Open Document 对话框，用于选择已保存的序列或标准 MIDI 文件。所选文件会以文本形式在新的 Untitled 文本窗口中打开，可以编辑并保存。

hook

hook 一词后面跟一个 float，会把所存储序列中所有事件时间乘以该数字。例如，若该数字为 2.0，所有事件时间都会加倍，序列播放会慢一倍。甚至可以在序列播放时进行乘法操作。

参数：

  • event-time-multiplier [float]

TEXT_HERE

print

在 Max Console 中打印所录制序列的前十六个事件。

read

不带参数时，read 会调出标准的 Open Document 对话框，从而可以把先前录制的序列读入 seq，替换当前序列。以符号作为参数时，read 会搜索指定名称的文件读入 seq 对象。

注意：seq 对象可读写单轨（格式 0）和多轨（格式 1）标准 MIDI 文件。它也能读写文本文件，其中每一行由一个以毫秒为单位的起始时间（自序列开始以来经过的时间）以及在该起始时间录制的一条 MIDI 消息的各个字节（以空格分隔）组成。例如，



0 144 60 112;

1000 144 60 0;

1500 192 31;

1500 144 60 112;

2500 144 60 0;

会在通道 1 上演奏音符中央 C 一秒钟，然后半秒后切换到音色号 31 并再次演奏中央 C 一秒钟。

参数：

  • filename [symbol]

record

开始录制在入口收到的 MIDI 消息。

start

单词 start 单独使用与 bang 效果相同。单词 start 后跟一个数字时，会以该数字决定的速度播放已存储的序列。消息 start 1024 表示正常速度。若该数字为 512，seq 会以原始录制速度的一半播放该序列，start 2048 会以原始速度的两倍播放，以此类推。

消息 start -1 会启动音序器，但 seq 不再跟随 Max 的毫秒时钟，而是等待 tick 消息来推进其时钟。参见 tick 消息。

参数：

  • tempo-multiplier [int]

stop

若音序器正在录制或播放，则停止它。当直接从播放切换到录制或反过来切换时，无需收到 stop 消息。

tick

在 seq 收到 start -1 消息后，它会等待 tick 消息来推进其时钟。为了以原始录制的速度播放该序列，seq 每秒必须收到 48 条 tick 消息。这相当于在 120MM 的速度下每个四分音符 24 条 tick 消息（MIDI Clock 消息的标准）。通过使用 tick 消息推进音序器，你可以改变播放速度，或让 seq 与另一个计时源（例如传入的 MIDI Clock 消息）同步。

write

调出标准的 Save As 对话框，从而可以把已录制的序列保存为单独的文件。若想用文本编辑器编辑该序列，请勾选对话框中的 Save As Text 选项。以符号作为参数时，write 会写入指定名称的文件。非零的 int 参数（作为单个参数，或跟在文件名参数之后）会使 seq 对象写入多轨标准 MIDI 文件（格式 1）。

参数：

  • filename [symbol]
  • format [int]

输出

bang

中间出口：表示 seq 已播放完当前序列。（该 bang 在序列最后一个事件播放之前立即送出。）

int

左出口：当入口收到 bang 或 start 时，seq 中存储的序列会以单个 MIDI 字节的形式从该出口送出，通常用于发送给 midiparse 或 midiout。

list

右出口：若 seq 加载的当前序列包含 MIDI meta 消息，这些消息会从右出口送出，前面加上单词 meta，随后是 meta 消息的名称和数据。

已知的 meta 消息有：sequencenumber、text、copyright、sequenceortrackname、instrumentname、lyric、marker、cuepoint、midichannelprefix、endoftrack、tempo、smpteoffset、timesignature、keysignature、sequencerspecific。其他任何消息都会被标识为 unknown。文本消息（text、copyright、sequenceortrackname、instrumentname、lyric、marker、cuepoint）会转换为符号。tempo meta 消息以 BPM 值显示。
