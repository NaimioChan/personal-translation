MC

mc.gradient~

在多通道信号的空间上生成时变函数

描述

向 mc.gradient~ 添加断点，以指定一个定义域与值域均从 0 到 1 的函数。输出范围映射到多通道信号的空间上。把 phasor~ 或其他时变的单通道或多通道信号连到 mc.gradient~ 对象以驱动它的输出。

参数

chans [int] 可选

改变输出多通道信号的通道数。输出通道数在音频重新启动之前不会改变。chans 特性的默认值为 0，表示由对象的参数决定输出通道数。

特性

chans [int] : 4

设置多通道输出信号的通道数

mode [int] : 0

确定在函数定义域上振荡的方向。可选值为 up、down 和 up/down。目前只支持 up 模式。
可选值：

0 = 'up'（取值递增）
在函数定义域上，Y 范围内的振荡取值递增。

1 = 'down'（取值递减）
在函数定义域上，Y 范围内的振荡取值递减（目前不支持）。

2 = 'up down'（回文模式）
在函数定义域上，Y 范围内的振荡取值先递增后递减（目前不支持）。

消息

float

返回 0.0 - 1.0 范围内指定 x 位置处每个通道的函数取值。

参数：

  • function-values [float]

list

list 消息会添加一个新的断点。最多可用 4 个值来指定断点的 x 位置、y 上限值、y 下限值和相位偏移。若列表包含两个值，则在 x 位置处创建一个 y 值固定的断点。可选的第三个值指定 y 下限值的范围，第四个值可用来指定相位取值（默认 0.）。若给出的 x 取值与已有断点匹配，该断点会被修改。

参数：

  • x-value [number]
  • y1-value [number]
  • y2-value [number]
  • phase [number]

chanval

返回给定通道与输入位置处输出函数的取值。

参数：

  • channel [int]
  • x-position [float]

clear

clear 消息移除当前函数中的所有断点，把它恢复到默认状态。

printfunction

printfunction 消息把当前函数打印到控制台。

signal

单通道信号控制所有断点。多通道信号按从左到右的顺序把每个通道映射到一个单独的断点；若输入通道数大于断点数，则回绕。
