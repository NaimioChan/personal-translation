techno~

信号驱动的步进音序器

描述

techno~ 是一个基于信号的步进音序器，便于实现事件的采样点精确时序。

参数

无。

消息

amplitude

单词 amplitude 后跟一个指定音序器步的数字和一个指定幅度取值的 float，设置某一步输出音符的幅度（作为绝对系数）。该幅度以这一步音符的绝对系数来指定——幅度为 1.0 时，该步刚开始处幅度输出信号的取值就是 1.0。

参数：

  • sequencer-step [int]
  • amplitude-value [float]

attack

单词 attack 后跟一个指定音序器步的数字和一个指定曲线指数的 float，设置用于计算幅度轨迹的曲线，该轨迹从上一步开始处的 0.0 到当前步开始处的幅度取值。用于指定曲线指数的取值与 curve 消息所用的相同。

参数：

  • sequencer-step [int]
  • attack-curve-exponent [float]

curve

单词 curve 后跟一个指定音序器步的数字和一个指定曲线指数的 float，设置用于计算从上一步开始的音高轨迹的曲线。

取值 1.0 表示从上一步开始的线性滑动；取值 0.5 表示平方根函数；取值 2.0 表示二阶抛物线滑动；以此类推。curve 消息让你可以设置并试验不同类型的滑音。

参数：

  • sequencer-step [int]
  • curve-exponent [float]

decay

单词 decay 后跟一个指定音序器步的数字和一个指定曲线指数的 float，设置用于计算衰减轨迹的曲线，该轨迹从上一步开始处的幅度取值到下一步开始处的 0.0。用于指定曲线指数的取值与 curve 消息所用的相同。

参数：

  • sequencer-step [int]
  • decay-trajectory-exponent [float]

length

单词 length 后跟一个数字，设置序列中的音符数量。默认值为 1。

参数：

  • number-of-steps [int]

pitch

单词 pitch 后跟一个指定音序器步的数字和一个以赫兹频率指定音高的 float，设置该步音符的音高。

参数：

  • sequencer-step [int]
  • frequency [float]

pos

单词 pos 后跟一个指定音序器步的整数和一个指定起始位置的 float，把该步放到指定的位置。一个步不能放在上一步之前，也不能放在下一步之后。例如，均匀间隔的四步序列中各步的位置为 0.0、0.25、0.5 和 0.75，因此第三步（索引 2）的 pos 消息只能指定 0.25 到 0.75 之间的位置。

参数：

  • sequencer-step [int]
  • start-position (step-size-coefficient) [float]

repeatpos

单词 repeatpos 后跟一个或多个 float，可以重复设置非均匀的音序器步宽。lengths 消息后面的 float 个数等于重复的步分段大小减一——该分段大小可以是序列总步数的任意偶数因子。例如对于八步序列，该分段的长度可以是 2、4 或 8 步。这些浮点参数必须严格递增，且位于 0 到 1 之间，它们设置各步的相对宽度。例如，可以用下列任意一条消息为步数为偶数的序列设置均匀划分：

repeatpos 0.5

repeatpos 0.25 0.5 0.75

repeatpos 0.125 0.25 0.375 0.5 0.625 0.75 0.875

消息 repeatpos 0.66 影响一个两步长的重复分段，让第一步占 66% 的时间、第二步占 34%。（这就像鼓机上经典的 "swing"。）

参数：

  • step-width [list]

signal

信号用作 techno~ 对象的输入，以指定序列中的步位置。该信号的范围为 0 - 1.0，表示一个相位取值，以序列总步数（用 length 消息设置）的比例来表示。习惯上用一个 phasor~ 对象作为 techno~ 对象的输入。所有输入信号都会被限幅到 0 - 1.0 的范围。

输出

signal

左入口：振荡器的音高信号输出。

中间入口：一个幅度包络。你可以把这个信号输出与你的振荡器的输出相乘。

右入口：步序列中的当前位置。每一步代表 1.0 的距离，总输出范围从 0 到 size 消息所设置的取值。
