playbar

控制视频或音频文件的播放

描述

与 movie、imovie、sfplay~ 或 jit.movie 配合，控制媒体的播放、位置和循环。

参数

无。

特性

bgcolor [4 floats] >= 7.0.0

以 RGBA 格式设置 playbar 对象的背景颜色。

color [4 floats] >= 7.0.0

以 RGBA 格式设置 playbar 对象控件的颜色。

disabledcolor [4 floats] >= 7.0.0

以 RGBA 格式设置对象被禁用时 playbar 对象控件的颜色。

hideloop [int] : 0

隐藏循环控件

hiderwff [int] : 0

隐藏快退/快进控件

refreshrate [float] : 30.

当 playbar 正在控制 jit.movie 时，refreshrate 特性设置影片播放的速率（单位 fps）。

selectioncolor [4 floats] >= 7.0.0

以 RGBA 格式设置 playbar 对象的选中颜色。

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'

4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

bang

若 playbar 对象的左出口连接到 movie 或 imovie 对象，bang 会把这两个对象链接起来，使 playbar 可以控制该影片。在 playbar 与 movie 链接之后，任何发往 movie 对象、会改变其位置或播放状态的消息都会反映到 playbar 对象上。（当载入含有已连接的 playbar 与 movie 对象的补丁文件时，链接会自动发生。因此，只有在构建补丁时才有必要发送 bang 给 playbar。）

loop

loop 一词后面跟一个非零数字会打开循环；loop 后面跟 0 会关闭循环。

参数：

  • flag [int]

(mouse)

可以用鼠标点击并拖动来开始/停止影片、快退/快进影片，或选取影片中的某个特定位置。

palindrome

palindrome 一词后面跟一个非零数字会打开往返播放（向前和向后循环）；palindrome 后面跟 0 会关闭往返播放。往返播放必须打开循环。
注意：往返播放模式不能与 sfplay~ 对象一起使用。

参数：

  • flag [int]

输出

(internal)

左出口：一旦 playbar 与 movie 对象链接起来，playbar 就会控制该影片。playbar 只支持同时连接到一个 movie 对象。该连接必须用连线建立，不能通过 send- receive 对来完成。

int

右出口：由 playbar 处理的每条命令都会以编号形式从其右出口送出。命令编号及其含义的目录可在 QuickTime Standard Movie Play Controller 文档中找到。通过正确解读这些命令，你有可能把 playbar 用于影片控制之外的其他用途。不过，在与一个时长非零的影片链接到 playbar 之前，控制器中的 "thumb" 没有范围。
