MSP

table~

信号查表

描述

用 table~ 配合 table 对象重新映射传入的信号取值。

参数

无。

特性

annotation_name [symbol] :

信息视图标题

embed [int] : 1

启用 embed 特性后，表格取值会被保存在补丁文件中，并在重新打开该补丁时恢复。

extend [int]

extend 特性控制当输入索引取值（信号或 float）小于零或大于表格大小时 table~ 的响应方式。
可选值：

0 = 'Zero'（输出零）
当 extend 为 Zero (0) 时，若索引超出表格边界，就输出零信号。

1 = 'Extend'（输出最低或最高的表格取值）
当 extend 设为 Extend (1) 时，若输入索引小于零，table~ 就输出索引 0 处的取值。若输入索引大于表格大小，它输出最高表格索引处的取值。

2 = 'Wrap'（回绕索引）
当 extend 设为 Wrap (2) 时，table~ 会对输入索引执行取模运算。例如：若表格大小为 128 而输入为 130，将输出索引 2（130 mod 128）处的取值。

3 = 'Ignore'（不改变输出）
当 extend 设为 Ignore (3) 时，任何超出表格大小的输入索引都会被忽略，不会改变输出。

inmap [atom]

inmap 特性指定一段要映射到表格索引的输入采样点范围。例如若你的输入信号会处于 0 与 1 之间，你可以为 inmap 指定 0 1，它会被缩放至表格的当前大小。若表格大小改变，当前的输入映射会自动调整。要清除当前的 inmap，请使用 none 或 0 0 取值。

inputmode [int]

inputmode 特性决定输入取值如何产生输出取值。
可选值：

0 = 'Lookup'（查表）
当 inputmode 设为 Lookup (0) 时，传入取值被用作查表的索引。

1 = 'Increment Index'（递增索引）
当 inputmode 设为 Increment Index (1) 时，输入信号中的一次变化事件（依据 triggermode 特性的设置）会让表格输出下一个索引处的取值。

2 = 'Random Distribution'（随机分布）
当 inputmode 设为 Random Distribution (2) 时，输入信号中的一次变化事件（依据 triggermode 特性的设置）会让表格把表格数据当作概率分布来输出取值。更多细节见 bang 消息。

interp [int]

interp 特性决定整数表格索引之间的输入取值如何产生输出。
可选值：

0 = 'None'（截断索引）
当 interp 设为 None (0) 时，传入取值在查表之前会被截断为整数值。不进行插值。

1 = 'Linear'（线性插值）
当 interp 设为 Linear (1) 时，处于两个表格索引之间的任何输入取值，其输出都会在两个索引处的表格取值之间线性插值。例如输入为 1.5 —— 索引 1 处的表格取值为 5、索引 2 处为 10 —— 则输出为 7.5。

2 = 'Round'（取整索引）
当 interp 设为 Round (2) 时，传入取值在查表之前会被取整为最接近的整数值。不进行插值。

name [symbol]

name 特性允许同名的多个表格对象（table~、table 或 itable）共享表格数据。更改 name 会切换用于查表的表格。

outscale [atom]

outscale 特性指定一段输出采样点范围。表格当前的范围会映射到所指定的范围。例如若你希望 table~ 的输出在 0 - 1 之间，就把 outscale 设为 0 1。即使表格范围改变，输出缩放也会自动调整，使输出取值保持在所指定的范围内。要清除当前的 outscale，请使用 none 或 0 0 取值。

parameter_enable [int]

启用后，该对象可与 Max for Live Parameters 配合使用。

parameter_mappable [int] : 1

启用 parameter_mappable 后，该对象就可以通过映射特性映射到键盘或 MIDI 输入。（默认值 = 1）。

range [int]

设置表格取值的范围。若未启用 signed 特性，最大的表格取值比范围小一。例如若 range 为 128，表格取值的范围是 0 到 127。若启用了 signed，表格取值的范围是 range 取值的 ±。例如若 range 为 128，表格取值将是 -128 到 128。

signed [int] : 0

若启用了 signed 特性，表格取值的范围是 range 取值的 ±。例如若 range 为 128，表格取值将是 -128 到 128。改变 signed 特性的状态不会修改表格取值。

size [int]

设置表格中元素的个数。索引范围从 0 到比 size 小一。

triggermode [int]

triggermode 特性决定输入取值如何被解释为变化事件，以便依据 inputmode 特性的设置，触发递增的索引或随机概率输出。当 inputmode 设为 0 (Lookup) 时，triggermode 特性不起作用，处于禁用状态。
可选值：

0 = 'Zero to Non-Zero'（零到非零）
当 triggermode 设为 Zero to Non-Zero (0) 时，输入中紧跟在零采样点取值之后的一个非零采样点取值，会引发一次变化事件。

1 = 'Change'（变化）
当 triggermode 设为 Change (1) 时，输入中与上一个取值不同的采样点取值，会引发一次变化事件。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

bang 消息把表格当作概率分布，输出一个对应于表格内随机选定索引的信号。表格中取值较高的位置，其索引被选中的可能性更大。

int

参见 float 的说明

float

当没有信号连接到 table~ 的入口时，一个数字会设置用于查表输出的索引。若该数字含有小数部分，且 interp 设为 Linear，输出就会在两个表格取值之间插值。该数字还会依据 inmap 特性的当前设置映射为索引，而表格取值会依据 outscale 特性缩放。

(mouse)

双击 table~ 对象会打开一个窗口，你可以在其中编辑查找表的取值。

goto

单词 goto 后面跟一个表格索引，用于设置 prev 或 next 消息在表格中递增或递减时使用的下一个表格索引。与 float 或 int 不同，goto 本身不会改变 table~ 对象的输出，它的索引也不会被 inmap 特性修改。

next

当没有信号连接到 table~ 的入口时，next 消息会把 int 或 float 最近设置的表格索引加一，然后让 table~ 把该索引处的取值作为信号输出。若 goto 消息紧接在 next 之前，则输出所指定索引处的取值。注意 next 不会把表格索引强制为整数值，因此先前 float 消息造成的索引小数部分会被保留。当 next 递增索引后索引大于表格大小时，它会回绕到零。

prev

当没有信号连接到 table~ 的入口时，prev 消息会把 int 或 float 最近设置的表格索引减一，然后让 table~ 把该索引处的取值作为信号输出。若 goto 消息紧接在 prev 之前，则输出所指定索引处的取值。注意 prev 不会把表格索引强制为整数值，因此先前 float 消息造成的索引小数部分会被保留。当 prev 递减索引后索引小于零时，它会回绕到表格末尾。

signal

传入的信号取值被用作查表的索引。
