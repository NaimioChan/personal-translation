Max

dropfile

拖放文件

描述

dropfile 定义一个用于拖放文件的区域，并在有文件输入时输出文件路径与文件类型。

参数

无。

特性

border [float] : 2.

设置 dropfile 对象边框的大小（单位：像素）。

bordercolor [4 floats]

以 RGBA 格式设置 dropfile 边框的颜色。

folderslash [int] : 1

切换在触发输出时是否在文件夹名称末尾添加斜杠字符（/）。

rounded [float] : 8.

设置让 dropfile 对象的边角圆角化所用的像素量。

types [symbol]

types 一词后面跟一个或多个四字母文件类型代码，会把 dropfile 对象设为搜索指定的文件类型，并打开一个标准的对话框窗口。文件类型代码的示例包括：文本文件的 TEXT、Max 二进制格式补丁文件的 maxb，以及 AIFF 格式音频文件的 AIFF。不带参数的 types 会让对象接受所有文件类型，这是默认设置。

设置对象在补丁窗口中的位置和大小。

消息

(drag)

当从 Finder 或 Max File Browser 把一个文件图标拖到已锁定的补丁窗口中的 dropfile 对象上时，该对象会把文件的类型与告知它接受的那些类型做比对。若文件属于可接受的类型，dropfile 对象框的轮廓会高亮显示。若在光标位于 dropfile 对象框内时松开鼠标按键，dropfile 对象会从其出口输出文件的类型和完整路径名。

输出

any symbol

右出口：可接受文件的四字母文件类型代码从右出口送出。

symbol

左出口：当可接受的文件图标被拖到 dropfile 上并在其对象框内松开鼠标时，该文件的绝对路径名会作为单个符号送出。输出的路径名包含斜杠分隔符。

绝对路径名形如：

"C:/Max Folder/extras/mystuff/mypatch.pat"

可以用 conformpath 对象把路径从一种 pathtype 和/或 pathstyle 转换为另一种。

当文件夹的别名被拖到 dropfile 上时，别名会被解析以生成输出路径。

若你想用 dropfile 对象让另一个接受带文件名参数的 read 消息的对象读取文件，请把 prepend read 对象放在 dropfile 与将要打开文件的对象之间，如示例所示。
