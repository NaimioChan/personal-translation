mc.playlist~

以多通道输出播放声音文件

描述

用 mc.playlist~ 来组织声音文件，并用多通道输出播放它们。每个文件的波形都显示在一个片段中，你可以在其中选取该文件的一部分用于播放。在 mc.playlist~ 内拖动片段即可重新排序，也可以借助片段左边缘的圆点状把手把片段拖到其他 mc.playlist~ 对象上。

无。

设置校正达到完全校正量所需的时间。通常，音符在起始处会有些不稳定，因为声音的起音阶段噪声较多，也因为歌手在音符起音之后会逐渐调整自己的音准。滑音时间使音高校正听起来自然，因为它模拟了这种效果。取值越大，适应时间越慢，校正要产生校正后的音高所需的时间也越长。不过，较长的滑音时间也能更好地保留颤音。必须先启用 timestretch 与 pitchcorrection。

参数特性

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

int

0 会停止声音文件的播放。大于零的数字会开始播放索引为该数字的片段。索引从 1 开始计数。

参数：

  • clip [int]

append

把一个新声音文件加入列表。第一个（可选）参数指定该声音文件。第二个（可选）参数指定该片段的槽位编号（从 1 开始）。若未列出参数，在已锁定的补丁中点击 append 消息会打开一个对话框，你可以在其中选择要追加的文件。

参数：

  • soundfile [symbol]
  • clip-number [int]

clear

从播放列表中移除所有片段。若只想移除一个片段，请在已锁定的补丁中右键点击要移除的文件，并从上下文菜单中选择 "Remove"。

(drag)

把一个多通道音频文件拖放到未锁定的补丁中，即可创建新的 mc.playlist~ 对象。若要把更多音频文件载入某个 mc.playlist~ 对象，请把新文件拖到 mc.playlist~ 界面上，直到当前载入文件的上方或下方出现一条线。要在 mc.playlist~ 内重新排列轨道，请在已锁定的补丁中按住并向上或向下拖动把手（左侧圆点）。要替换当前载入的文件，请把新文件拖到旧文件上，直到整条轨道被高亮。

getcontent

单词 getcontent 会把所有片段的内容和行为以字典格式从 mc.playlist~ 的最后一个出口送出。把最后一个出口连接到 dict.view 对象即可看到这些内容。请注意，对于 "absolutepath" 项，只有当文件不在 Max 的搜索路径中时，才会显示每个片段的完整文件路径。若文件在 Max 的搜索路径中，则只显示文件名。

(mouse)

用鼠标播放和停止播放列表，也可以用它选取采样的细小部分用于播放。

next

播放 mc.playlist~ 中载入的下一个片段。

pause

在当前播放位置暂停当前片段的播放。

remove

单词 remove 后面跟一个从 1 开始的片段编号，会从列表中移除该片段。

参数：

  • clip-number [int]

resume

若播放已暂停，则从当前位置恢复播放。使用信号驱动的播放时，此消息无效。

selection

用一个归一化范围（0.0 是起点，1.0 是终点）选择片段的播放端点。第一个参数指定哪个片段（从 1 开始计数）。第二个参数是该片段的起点，第三个参数是终点。若只给出两个参数，它们就作为 mc.playlist~ 中所有片段的起点和终点。若只给出一个参数，它作为片段编号，并清除该片段上的任何选择。

参数：

  • clip [int]
  • start [float]
  • end [float]

selectionms

以毫秒为单位选择片段的播放端点。第一个参数指定哪个片段（从 1 开始计数）。第二个参数是该片段的起点，第三个参数是终点。若只给出两个参数，它们就作为 mc.playlist~ 中所有片段的起点和终点。若只给出一个参数，它作为 mc.playlist~ 中所有片段的终点。

参数：

  • clip [int]
  • start [float]
  • end [float]

setclip

sfplay~ 的特性在 mc.playlist~ 中同样可用。要控制某个特定片段，请使用 "setclip" 消息，后面跟片段编号、特性名和取值。消息 "setclip 2 loop 1" 会为片段 2 打开循环。

参数：

  • clip [int]
  • attribute [symbol]
  • value [anything]

signal

输入信号可用于以采样点精确的方式触发预先存储的提示。当左入口收到信号取值时，会监测该信号取值的整数部分。当输入信号的整数部分变为等于某个预先存储的提示的索引时，该提示就会被触发。索引从 1 开始。信号取值为 0 会停止音频。负值会被忽略。

输出

dictionary

最右边的出口会响应 'getcontent' 消息，送出一份 mc.playlist~ 内容的字典摘要。

list

第三个出口送出形如 'start N clipname' 或 'done N clipname' 的消息，其中 N 是索引，'clipname' 是片段的名称。

signal

mc.playlist~ 输出一个多通道信号，其通道数由 channelcount 特性指定。

第二个出口提供一个单通道同步信号。该信号值的整数部分是正在播放的片段的索引。小数部分是该片段内的瞬时位置。
