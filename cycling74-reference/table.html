Max

table

存储和编辑数字数组

参数

name [symbol] 可选

参数为 table 命名。Max 会查找同名的文件来载入。若两个或多个 table 对象同名，它们也会共用相同的取值。

特性

annotation_name [symbol] :

信息视图标题

embed [int] : 1

切换是否能把表嵌入，并把其数据作为主补丁的一部分保存。默认行为是 1（保存数据）。

name [symbol]

指定表的名称。你也可以用参数指定某个 table 对象的名称。Max 会查找同名的、已保存为独立文件的表。若两个或多个表对象同名，它们也会共用相同的取值。

notename [int] : 0

切换是否用 MIDI 音符号显示 Y 轴。

parameter_enable [int]

启用后，该对象可与 Max for Live Parameters 配合使用。

parameter_mappable [int] : 1

启用 parameter_mappable 后，该对象即可通过映射功能映射到键盘或 MIDI 输入。（默认值 = 1）。

range [int]

指定编辑窗口的 y 轴上可显示的取值范围。新建的表取值范围为 128，从 0 到 127。

setresizes [int] : 0

set 消息会调整表大小

signed [int] : 0

切换是否存储并显示带符号整数值。新建的带符号取值的表范围是 256，即从 -128 到 127。

size [int]

指定表中存储的取值数量。默认值为 128 个值，索引编号从 0 到 127。

通用对象框特性

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

valuepopuplabel [int] : 0

可选值：

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

等同于带一个 0 到 32,768 之间随机数作为参数的 quantile 消息。更多细节参见 quantile 消息。

int

按地址从 table 中取出数字，并把它从左出口送出。

参数：

  • index [int]

(inlet1)

把该值存储到左入口接下来收到的索引号处。

参数：

  • value [int]

float

转换为 int

参数：

  • index [float]

list

第二个数字存储在第一个数字指定的地址（索引）处。

参数：

  • index [int]
  • value [int]

cancel

使表忽略在右入口收到的数字，这样左入口接下来收到的数字会输出一个数字，而不是把数字存储到那个地址上。

clear

把所有值设为 0

const

用某个数字填充表

参数：

  • value [int]

(mouse)

表中存储的取值可以用鼠标以图形方式输入和编辑。在补丁窗口中首次创建 table 对象时，会打开该 table 对象的图形编辑窗口，可以用鼠标绘制来输入取值。编辑窗口提供一组图形编辑工具。当补丁窗口被锁定时，可以用鼠标双击 table 对象来打开图形编辑窗口。

dump

把表中存储的所有数字一个接一个立即从左出口送出，从地址 0 开始。

flags

更改 table 对象在 Inspector 中的保存选项。第一个参数影响 Save with Patcher 选项，第二个参数影响 Don’t Save 选项。若参数为零，该选项不被勾选，否则被勾选。

参数：

  • save-with-patcher [list]
  • dont-save [list]

fquantile

给定一个 0 到 1 之间的数字，会把该数字乘以表中所有数字之和。接着，表送出这样一个地址：截至该地址的所有值之和大于或等于该结果。

参数：

  • multiplier [float]

getbits

取出表中存储的某个数字的一个或多个特定位的取值，并从左出口把该取值送出。第一个参数是要查询的地址；第二个参数是该地址所存数字中的起始位位置（位位置的编号为 0 到 31，从最低有效位到最高有效位）；第三个参数指定应从起始位位置往右送出多少位。指定的这些位以单个十进制整数的形式从出口送出。

参数：

  • address [int]
  • start [int]
  • bits [int]

goto

把指针设到该数字指定的地址上。指针最初设在表的开头。

参数：

  • index [int]

inv

找到第一个大于或等于该数字的取值，并把该取值的地址从左出口送出。

参数：

  • value [int]

length

输出表大小

load

把表置于载入模式。在载入模式下，左入口收到的每个数字都会存入表中，从地址 0 开始，一直持续到表被填满（或直到表被 normal 消息带出载入模式）。若收到的数字多于表的容量所能容纳的数量，多出的数字会被忽略。

max

取出存储的最大值

min

取出存储的最小值

next

把指针所指向的地址中存储的取值从左出口送出，然后把指针设到下一个地址。若指针当前位于表的最后一个地址，它会回绕到第一个地址。

normal

把表带出载入模式，恢复为正常工作。更多细节参见 load 消息。

open

打开对象的图形编辑器窗口并把它带到前景。在已锁定的补丁中双击 table 对象有相同效果。

prev

产生的输出与 next 消息相同，但随后指针是递减而不是递增。若指针当前位于表的第一个地址，它会回绕到最后一个地址。

quantile

把传入的数字乘以表中所有数字之和。该结果随后除以 2^15（32,768）。接着，表送出这样一个地址：截至该地址的所有值之和大于或等于该结果。

参数：

  • number [int]

read

打开并读取 Text 或 Max 二进制格式文件中的数据值。没有参数时，read 会打开标准的 Open Document 对话框来选择文件。若文件包含有效数据，现有表的全部内容会被文件内容替换。

参数：

  • filename [symbol]

refer

把接收方的 table 对象设置为从具名的表读取它的数据值。

参数：

  • name [symbol]

send

把传入地址上存储的取值送给所有叫这个名字的 receive 对象。

参数：

  • receive-name [symbol]
  • address [int]

set

把取值存储到某些地址中。第一个参数指定一个地址。下一个数字是要存入该地址的值，其后的每个数字依次存入随后的地址。

参数：

  • start [int]
  • values [list]

setbits

修改表中存储的某个数的一个或多个特定位的值。第一个参数是所涉及的地址；第二个参数是该地址所存数字中的起始位位置（位位置编号为 0 到 31，从最低有效位到最高有效位）；第三个参数指定从起始位位置起向右应修改多少位，第四个参数是这些位要设成的值（用十进制或十六进制形式表示）。

参数：

  • address [int]
  • start [int]
  • count [int]
  • value [int]

sum

输出所有值之和

wclose

关闭图形编辑窗口

write

打开标准的保存文件对话框，以选择把表中的数据值写入哪个名称的文件。文件可按 Text 或 Max 二进制格式保存。

输出

bang

当 table 的内容因图形编辑窗口中的编辑而改变时，会从右出口送出 bang。

int

table 送出的所有数字都从左出口送出。
