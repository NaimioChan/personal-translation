Jitter

jit.gl.sketch

在 OpenGL 中使用绘图命令

描述

基于 3-D 绘图命令进行记录与绘制。这些命令涵盖从简单的海龟绘图到 OpenGL API 的大部分内容。

讨论

该 OB3D 对象可选地接受一个参数：绘制上下文的名称。它可以是 jit.world 或 jit.pworld 对象的具名实例，也可以是 jit.gl.node 子上下文。该值也可以通过 OB3D 的 drawto 特性设置。若未给出参数，对象会被隐式加入当前补丁中找到的第一个有效绘制上下文或子上下文，或者沿补丁层级向上搜索找到的第一个有效绘制上下文或子上下文。

特性

OB3D 特性

alpha_mode [symbol]

用独立的 alpha 混合函数与方程对混合过程进行更精细的控制。
可选值：

'link' ( 与 blend_mode 链接（默认值） )
'max' ( 取最大值 )
'add' ( 求和 )
'replace' ( 用源替换目标 )
'ignore' ( 忽略源 )

anim [symbol]

处理该实例所有空间变换的 jit.anim.node 对象的名称（默认值 = UID）。默认值引用一个内部对象，但可以把它设为某个已存在的外部 jit.anim.node 实例的名称来覆盖。这样可以更高级地控制空间变换。

anchor [3 floats]

局部空间中的锚点位置（默认值 = 0. 0. 0.）。用于偏移应用变换所围绕的局部 3D 原点。

animmode [symbol]

决定 anim_move 与 anim_turn 消息在哪个空间中影响该对象的位置和朝向（默认值 = parent）。
local = 相对局部轴旋转
parent = 相对父级轴旋转
world = 相对世界轴旋转

antialias [int]

抗锯齿标志（默认值 = 0）在某些硬件上，必须同时启用 blend_enable 特性，抗锯齿才会生效。

automatic [int]

自动渲染标志（默认值 = 1）该标志置位时，关联的 jit.gl.render 对象收到 bang 消息时即进行渲染

auto_material [int]

自动材质特性标志（默认值 = 1）该标志置位且对象启用了光照时，对象的漫反射与环境光材质分量会被设为对象的颜色，镜面反射与自发光光照分量则被禁用。

aux_color [4 floats]

辅助颜色，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

axes [int]

x/y/z 轴渲染关/开（默认值 = 0）

blend [symbol]

具名混合模式。可选值有：
add = blend_mode 1 1
multiply = blend_mode 2 1
screen = blend_mode 4 1
exclusion = blend_mode 4 5
colorblend = blend_mode 3 4
alphablend = blend_mode 6 7
coloradd = blend_mode 3 1
alphaadd = blend_mode 6 1

blend_enable [int]

混合标志（默认值 = 0）该标志置位时，所有被渲染的对象都启用混合。

blend_mode [2 ints]

与混合模式关联的源通道和目标通道（默认值 = 6 7）混合模式以 src_blend_mode dst_blend_mode 的形式给出。支持的取值有：
0 = zero
1 = one
2 = destination color
3 = source color
4 = one minus destination color
5 = one minus source color
6 = source alpha
7 = one minus source alpha
8 = destination alpha
9 = one minus destination alpha
10 = source alpha saturate

capture [symbol]

要渲染到的纹理名称——例如 jit.gl.nurbs @capture mytex 会捕获到 jit.gl.texture @name mytex。

cull_face [int]

面剔除模式（默认值 = 0（不剔除））
0 = 不剔除
1 = 剔除背面
2 = 剔除正面

depth_clear [int]

深度缓冲清除标志（默认值 = 0）该标志置位时，渲染对象之前会清除深度缓冲。

depth_enable [int]

深度缓冲标志（默认值 = 1）该标志置位时，启用深度缓冲。

depth_write [int]

深度写入标志（默认值 = 1）。该标志置位时，启用对深度缓冲的写入。若 depth_enable 已关闭，则此设置无效。

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

filterclass [symbol]

该对象拾取过滤器类的名称（默认值 = default）。它控制对象对 jit.gl.handle 和 jit.gl.picker 对象是否可见。要选中该对象，filterclass 的值必须在拾取对象的 filters 列表中。

fog_params [7 floats]

雾参数，形式为 red green blue alpha density start end（默认值 = 0. 0. 0. 0. 0. 0. 0.）列表中颜色各元素应在 0.-1. 范围内。

fog [float]

雾效果的强度（默认值 = 0.）

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

lighting_enable [int]

光照启用标志（默认值 = 0）该标志置位时，会计算光照。

line_width [float]

绘制线的宽度（默认值 = 1.）

mat_ambient [4 floats]

环境光材质属性，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

mat_diffuse [4 floats]

漫反射光材质属性，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

mat_emission [4 floats]

材质自发光属性，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

mat_specular [4 floats]

镜面反射光材质属性，形式为 red green blue alpha（默认值 = 0. 0. 0. 0.）列表各元素应在 0.-1. 范围内。

matfile [symbol]

要应用的 Jitter 材质文件（.jitmtl）

name [symbol]

实例名称（默认值 = UID）

point_mode [symbol]

启用 points 绘图图元（poly_mode 2）时使用的点绘制模式（默认值 = circle）。
可选值：

'square' ( 把点绘制为方形 )
'circle' ( 把点绘制为圆形 )
'square_depth' ( 把点绘制为带深度缩放的方形 )
'circle_depth' ( 把点绘制为带深度缩放的圆形 )
'user_shader' ( 允许在自定义顶点着色器中写入 gl_PointSize )

point_size [float]

绘制点的大小（默认值 = 1.）

poly_mode [2 ints]

多边形渲染模式（默认值 0 0）渲染模式以 frontface backface 的形式给出。支持的渲染模式有：
0 = 渲染为填充多边形
1 = 渲染为线
2 = 渲染为点

position [3 floats]

3D 原点，形式为 x y z（默认值 = 0. 0. 0.）

quat [4 floats]

当前旋转的四元数表示（默认值 = 0. 0. 0. 1.）。四元数是一种数学构造，它是一个四维向量，可以看作绕任意轴的旋转。四元数是 3D 空间中朝向的一种有用表示。

rotate [4 floats]

旋转角度以及绕其进行旋转的 xyz 向量，形式为 rotation-angle x y z（默认值 = 0. 0. 0. 1.）

rotatexyz [3 floats]

把当前旋转设为绕 x、y、z 正轴旋转的复合，也称为欧拉角（默认值 = 0. 0. 0.）。默认顺序为 yzx，可用 jit.gl.render 的 rotate_order 特性更改。角度以度为单位。

scale [3 floats]

3D 缩放系数，形式为 x y z（默认值 = 1. 1. 1.）

shadow_caster [int]

投影标志（默认值 = 0）该标志置位时，对象会投射阴影。

shininess [float]

材质的镜面光泽度值（默认值 = 16.0）该值应为 0.-255. 范围内的浮点数。

smooth_shading [int]

平滑着色标志（默认值 = 0）该标志置位时，渲染时使用平滑着色。

tex_map [int]

自动生成纹理坐标控制的模式（默认值 = 0）
0 = 不生成坐标。
1 = 使用 OpenGL 的纹理生成，模式为 GL_OBJECT_LINEAR。这会以相对对象固定的朝向应用纹理。
2 = 使用 OpenGL 的纹理生成，模式为 GL_SPHERE_MAP。可用于创建反射效果。
3 = 使用 OpenGL 的纹理生成，模式为 GL_EYE_LINEAR。这会以相对 OpenGL 眼坐标固定的朝向应用纹理。
模式 1 和 3 受下面列出的 tex_plane_s 与 tex_plane_t 特性的值影响。

tex_plane_s [4 floats]

纹理生成系数 a b c d，适用于 tex_map 模式 1 和 3。（默认值 = 1. 0. 0. 0.）
这四个系数定义一个平面，用于生成 s 纹理坐标，它对应纹理图像的 x 轴。若 tex_map 模式为 1，则 s = ax + by + cz + dw，其中 x、y、z、w 是顶点的齐次坐标。

tex_plane_t [4 floats]

纹理生成系数 a b c d，适用于 tex_map 模式 1 和 3。（默认值 = 0. 1. 0. 0）
这四个系数定义一个平面，用于生成 t 纹理坐标，它对应纹理图像的 y 轴。

shader [symbol]

要应用的着色器名称（默认值 = none）

texture [8 symbols]

要应用的纹理名称（默认值 = none）。若指定了多个纹理，则使用多重纹理。

transform_reset [int]

模型视图与投影变换重置标志（默认值 = 0）该标志置位时，渲染对象之前会把模型视图变换与投影变换设为单位变换。这适用于精灵或公告板叠加，或按窗口大小自动缩放。transform_reset 标志的模式有：
0 = 不做任何事（默认值）
1 = 等比正交 glOrtho(-aspect, aspect, -1.0, 1.0, near_clip, far_clip);
2 = 归一化正交 glOrtho(-1.0, 1.0, -1.0, 1.0, near_clip, far_clip);
3 = 近裁剪面为 0.001 的等比透视 gluPerspective(lens_angle, aspect, 0.001/*near_clip*/, far_clip);
4 = 近裁剪面为 0.001 的归一化透视 gluPerspective(lens_angle, 1.0, 0.001/*near_clip*/, far_clip);

viewalign [int]

视图对齐变换标志（默认值 = 0）

screentoworld

单词 screentoworld 后面跟一对指定 x 和 y 坐标的数字，会返回一个数组，其中包含与给定屏幕像素相关联的 x、y 和 z 世界坐标，其使用的摄像机深度与 0,0,0 相同。可选地还可以指定第三个深度参数，它可能对命中检测以及其他应用有用。深度值通常用 0.-1. 的范围指定，其中 0 是近裁剪面，1. 是远裁剪面。

单词 strokepoint 后面跟三个指定 x、y、z 坐标的数字，会在这些坐标指定的位置定义一个锚点。有些描边样式（例如 basic2d）会忽略 z 坐标。
