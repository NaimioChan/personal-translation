Jitter

jit.pwindow

显示 Jitter 数据与图像

描述

用 jit.pwindow 在补丁中绘制像素（jit_matrix 数据）或 OpenGL 3D 图形场景（jit_texture 数据）。收到 jit_matrix 消息时，它会把矩阵作为像素数据显示；收到 jit_texture 消息时，它使用被动 OpenGL 渲染上下文来显示它们。

参数

无。

特性

border [float] : 0.

启用边框绘制

bordercolor [4 floats] : 0. 0. 0. 1.

以 RGBA 格式设置边框颜色。必须置位 Draw border 标志，边框才可见。

colormode [symbol] : argb

矩阵颜色模式
可选值：

'argb'（ ARGB 颜色 ）
以 ARGB 格式指定的颜色（默认）

'uyvy'（ UYVY 颜色 ）
以 UYVY 格式指定的颜色

depthbuffer [int]

启用深度缓冲

doublebuffer [int]

启用双缓冲

dstrect [4 ints] : 0 0 320 240

矩阵目标矩形由坐标 left, top, bottom, right 给出。所有取值都相对于窗口的左上角。

fsaa [int]

启用全场景抗锯齿

idlemouse [int] : 0

启用后，会报告空闲鼠标事件（默认值 = 0）。禁用时，只有在鼠标按键按下时才报告鼠标事件。

interp [int] : 0

启用矩阵插值

name [symbol]

窗口的名称。Jitter OpenGL 对象通过窗口的名称挂接到渲染上下文。

onscreen [int] : 1

启用直接绘制到屏幕

pickray [int] : 0

Pickray

planemap [4 ints] : 0 1 2 3

从输入矩阵到输出的通道映射（默认值 = 0 1 2 3）。

size [2 ints]

窗口大小

srcrect [4 ints] : 0 0 320 240

把输入矩阵复制到内部矩阵时所使用的输入矩阵部分。（默认值 = 0 0 (matrix width) (matrix height)）矩形的比例用 left top right bottom 的形式表示。所有取值都相对于输入矩阵查看区的左上角。

stereo [int]

启用立体声缓冲

sync [int]

垂直同步标志，会让窗口的更新与显示器的刷新保持同步。

usedstrect [int] : 0

启用目标矩形

usesrcrect [int] : 0

启用源矩形

消息

bang

输出当前存储的矩阵

jit_gl_texture

使用被动 OpenGL 渲染上下文把纹理绘制到屏幕。在此模式下，jit.pwindow 始终绘制在最上层的补丁层上，会遮挡占据补丁同一区域的其他任何补丁元素。

参数：

  • texture-name [symbol]

jit_matrix

把矩阵作为 ARGB 像素数据绘制到屏幕。在此模式下，jit.pwindow 可以放在 Max 补丁层级的任意层，因此文字和对象可以显示在输入矩阵数据之上。

参数：

  • matrix-name [symbol]

(mouse)

当鼠标左键按下时，鼠标事件会从转储出口送出，并在前面带上符号 mouse，若已启用则带上 mouseidle（前提是启用了 idlemouse）。

该事件是一个列表，包含鼠标光标的水平与垂直坐标，后面跟着若干代表按键状态与修饰键状态的标志。这些标志是：鼠标按键、command（mac）或 control（win）键、shift 键、capslock 键、option / alt 键、control 键（mac）、鼠标左键、鼠标右键和鼠标中键。
