array.fill

生成指定长度的数组

描述

创建一个指定长度的新数组对象，并预先填充元素。

参数

length [int] 可选

生成的数组的长度。

initial-contents [list] 可选

用于填充数组的任何数据（若没有任何初始数据，数组将用 0 填充）。

特性

mode [int] : 0

mode 决定如何调整长度与输出数组不一致的数据。有几个选项可用。
可选值：

0 = 'Repeat' （重复元素）
数组的所有元素会被重复，以达到所需长度。若传入左入口的数组长度为 3，数组 [ 2 ] 会变成 [ 2, 2, 2 ]；[ 2 1 ] 会变成 [ 2 1 2 ]。

1 = 'Repeat Last' （重复最后一个元素）
数组的最后一个元素会被重复，以达到所需长度。若传入左入口的数组长度为 3，数组 [ 2 ] 会变成 [ 2, 2, 2 ]；[ 2, 1 ] 会变成 [ 2, 1, 1 ]。

2 = 'Repeat Zero' （重复零）
整数 0 会被重复，以达到所需长度。若传入左入口的数组长度为 3，数组 [ 2 ] 会变成 [ 2, 0, 0 ]；[ 2, 1 ] 会变成 [ 2, 1, 0 ]。

3 = 'Interpolate (Linear)' （线性插值）
会对数组进行线性插值，以达到所需长度。若传入左入口的数组长度为 3，数组 [ 1, 3 ] 会变成 [ 1, 2, 3 ]；[ 5, 1 ] 会变成 [ 5, 3, 1 ]。若所有元素都是 ints，插值将以整数进行；若任一元素是 float，插值会返回浮点数。

range [atom] : 0 1

生成值的范围

seed [int]

随机种子

urn [int] : 0

Urn 模式
