jit.gl.tf

管理几何网格上的变换反馈

描述

jit.gl.tf 对象会绑定到 jit.gl.mesh 对象，从 jit.gl.buffer 对象接收输入，并使用定义在 jit.gl.shader 对象中的着色器程序，对网格几何体施加变换反馈效果。

讨论

变换反馈是一种高级渲染技术，它允许你在处理变换的顶点部分之后，把着色器的状态捕获到缓冲区中，然后重新提交以便多次处理。这对于创建基于 GPU 的粒子系统，或任何需要多个阶段或先前状态感知的顶点处理尤其有用。

要把缓冲区加入变换反馈流程，你需要同时创建一个 jit.gl.tf 对象以及一个或多个 jit.gl.buffer 对象。jit.gl.tf 对象必须带一个参数，指明缓冲区（输入）的总数；此外对每个 jit.gl.buffer，你都必须指定缓冲区的 type 与 outname 特性。每个 jit.gl.buffer 里的 type 必须与 jit.gl.mesh 的某个内部缓冲区匹配（position、normal、color、vertex_attr 等），并且会覆盖着色器中按其指示要使用的默认缓冲区。outname 可以是任意 symbol，但它会被着色器用来在 GPU 内存中执行反馈操作，所以务必确保它与着色器中的 out 名称一致。因此，如果你有这样的设置：那么在着色器 params 声明中你需要类似这样的写法：

			<param name="position" type="vec3" state="POSITION" /> 
<param name="velocity" type="vec3" state="NORMAL" />

而在程序主体中，你要像这样同时声明 in 与 out 两个名称：

			in vec3 position; 
in vec3 velocity;
out vec3 Position1;
out vec3 Velocity1;

系统设置好之后，你必须通过 jit.gl.tf 的 enable 特性来启动变换反馈。

参数

numbuffers [int] 可选

要创建的入口数量。每个入口都可以绑定到一个 jit.gl.buffer。最大为 8，不过反馈缓冲区的实际最大数量取决于硬件，通常为 4。

特性

bufnames [8 symbols]

目前为只读。显示绑定到 jit.gl.tf 对象的缓冲区列表。缓冲区的顺序反映了从左到右已绑定的入口。

enable [int]

设为 1 时启用变换反馈。禁用时，已绑定的输入缓冲区会按其初始状态传递。

建议在修改输入缓冲区之前禁用它，并在修改完成后再重新启用。启用状态下改变输入缓冲区的状态可能会导致意外行为。

initcount [int]

将要传给变换反馈阶段的图元初始数量。与几何着色器配合创建发射器时，这对粒子模拟很有用。若设为 0，则在启用时传递整个缓冲区。

name [symbol] 只读

jit.gl.tf 对象的只读名称。该名称在内部用于处理反馈绑定。

numbuffers [int]

在 jit.gl.tf 对象名之后作为参数设置，报告缓冲区入口的数量。

shader [symbol]

jit.gl.shader 对象的名称，供 jit.gl.tf 对象绑定。

texture [32 symbols]

绑定到变换反馈着色器流程的一张或多张纹理的名称（默认值 = none）。

消息

jit_gl_buffer

把具名的 jit.gl.buffer 对象绑定到该入口。注意，传入的缓冲区必须设置 outname 特性，才能在与该入口对应的 jit.gl.shader 中引用它。jit.gl.buffer 对象的出口已经用该消息前缀预先格式化，因此把它们连接起来就会自动绑定传入的缓冲区。
