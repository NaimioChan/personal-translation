Max

regexp

用正则表达式处理输入

描述

借助 regexp，可以使用 PERL 兼容的正则表达式（PCRE）在 symbol 和列表中匹配或进行替换。

讨论

该参数是一个 symbol，用于设置正则表达式（RE），左入口的 re 特性也一样。substitute 特性传入一个用于替换的 symbol——若没有给出 symbol，它会移除先前那个。左入口的任何其他 symbol 或列表都被当作被处理的字符串，并按这些参数处理。

被处理的数组会按 re 和 substitute 的取值处理。中间出口报告 RE 与被处理的数组的部分内容相匹配的各处实例所组成的数组。若 RE 中包含圆括号，它们会被当作捕获组，左中间出口会在被处理的数组内每次匹配时把它们放进一个数组。若已设置 'substitute' 数组，最左侧输出会返回经过必要替换的被处理的数组。

中间出口报告 RE 与被处理的字符串的部分内容相匹配的各处实例所组成的列表。若 RE 中包含圆括号，它们会被当作捕获组，左中间出口会在被处理的字符串内每次匹配时把它们放进一个列表。若已设置 'substitute' 字符串，最左侧输出会返回经过必要替换的被处理的字符串。（注意：替换字符串中可以包含捕获组，形式为 %n）

若要在输出中保留双引号，输入时必须在它们前面加一个反斜杠字符（\）来转义。未转义的引号永远不会被匹配。在表达式中，双引号也必须转义才能被匹配。

参数

expression [symbol] 可选

可以用一个正则表达式作为参数来设置正则表达式（正则表达式格式与元字符信息见上文）。

substitution [symbol] 可选

可选的第二个参数将设置替换字符串。

特性

binary [int]

当 binary 模式禁用（默认）时，regexp 对象把被处理的字符串和替换字符串当作 UTF-8 文本。
启用时（1），regexp 对象会把取值列表作为单个字节（范围 0 -255）处理，而不是当作文本。这既适用于被处理的字符串，也适用于替换 "字符串"。任何不在 0 到 255 之间的取值都会被转换为 0，替换字符串中的 %n 捕获组引用除外。binary 模式按下述方式改变对象的输出，使其不同于默认行为：

  • 子字符串输出的开头是 substring N，其中 N 是在被处理的字符串中找到的子字符串数量。随后会输出 N 条含匹配取值的消息，最后是 substring done。
  • 捕获组输出的开头是 capture N，其中 N 是被处理的字符串中捕获组集合的数量（这应与子字符串数量一致）。随后，消息 capture group X 会开始一组捕获，其中 X 是当前集合从 0 开始的索引。然后，集合中的每个捕获都会输出一条消息。每个集合以 capture group X done 结束，整个输出以 capture done 结束。


对于复杂的二进制/按字节匹配工作，array.regexp 对象可能是更好的选择（它始终处于二进制模式，而数组对象更适合二进制输出），不过对于更习惯处理 Max 列表的用户来说，binary 模式为 regexp 对象增加了一种处理字节流的方法。

legacyoutputorder [int] >= 9.1.0

在 Max 9.1.0 之前，子字符串（中间）和捕获组（左中）出口会错误地从左到右送出输出。这在 Max 9.1.0 中已修正，但旧行为对遗留补丁仍然可用且处于启用状态。对于新对象，会使用修正后的输出顺序。

re [symbol]

PCRE 参考是进一步了解 Max 中正则表达式如何构建的最佳去处，但这里先给出基础知识的快速概要：

单词 re 后面跟一个 PERL 兼容的正则表达式，用于设置解析或在任何 symbol 或列表输入中进行替换时要使用的正则表达式规则。

若正则表达式中包含空格，在使用 re 消息指定时，或作为输入参数提供给 regexp 对象时，必须用双引号括起来。

正则表达式使用以下形式和语法：

[...] 定义一个字符 'class'。其中的任何字符都可能被匹配。其中也可以出现若干特殊符号：

...-... 指定一个范围（在 ASCII 码范围内）

\\d 指定一个十进制数字（\\D 指定非十进制数字）。注意必须使用双反斜杠——Max 会抹掉单个反斜杠。

\\s 指定空白（\\S 指定非空白）。注意必须使用双反斜杠——Max 会抹掉单个反斜杠。

\\w 指定一个字母数字（\\W 指定非字母数字）。注意必须使用双反斜杠——Max 会抹掉单个反斜杠。

^... 指定……的补集

...* 出现零次

...+ 至少出现一次

...? 出现一次或完全不出现

(...) 指定一个捕获组，可以在替换字符串中以 %n 的形式引用，其中 n 是该圆括号从左到右的位置。

substitute [symbol]

substitute 一词后面跟一个符号，会传入一个用于替换的符号。如果 substitute 一词后面没有跟符号，则移除先前的替换符号。

注意：如果你需要在任何替换字符串中输出一个后面跟数字的 %，应使用 %%，这样 % 就不会被读作捕获组。

tosymbol [int]

单词 tosymbol 后面跟 0、1 或 2，会改变 regexp 对象的输出行为。
设为 1 时，对象左出口的输出会是单个 symbol。设为 2 时，子字符串和捕获组的输出也会被转换为 symbol。见下文：
可选值：

0 = 'Off'（把所有输出转换为 Max 原子）
禁用时（0，对象左出口的输出会由各个单独元素组成的列表构成，这些元素被解释为 Max 原子（数字或 symbol，取决于输入 [注意：这种情况下带前导零的数字，如 01，会被转换为数字 1]）。


1 = 'Substitution Output'（把替换后的输出转换为 symbol）
设为 1 时，对象左出口的输出会是单个 symbol。

2 = 'Everything'（把所有输出转换为 symbol）
设为 2 时，对象左出口的输出会是单个 symbol，所有子字符串或捕获组输出也会是 symbol 或 symbol 列表。在上面的例子中，01 会保留为 symbol "01"（而 1 会是 symbol "1"）。

消息

int

int 在 regexp 对象入口收到时，会被当作被处理的字符串，按所提供的正则表达式和 symbol 替换来处理。

参数：

  • subject-string [int]

float

float 在 regexp 对象入口收到时，会被当作被处理的字符串，按所提供的正则表达式和 symbol 替换来处理。

参数：

  • subject-string [float]

list

在 regexp 对象入口收到的任何 symbol 或列表（不匹配对象特性的）都会被当作被处理的字符串，按所提供的正则表达式和 symbol 替换来处理。

参数：

  • subject-string [list]

anything

执行与 list 消息相同的功能。

参数：

  • subject-string [list]

输出

symbol or list

左出口：若已用 substitute 消息设置替换字符串，输入的列表或 symbol 会连同所需的替换一起从左出口送出（注意：替换字符串中可以包含捕获组，形式为 %n）。

左中间出口：若正则表达式中包含圆括号，它们会被当作捕获组。左中间出口在被处理的字符串内每次匹配时报告这些捕获组，并以列表的形式输出它们。

中间出口：中间出口报告正则表达式与被处理的字符串的部分内容相匹配的各处实例所组成的列表。

右中间出口：在未发生匹配的情况下，右中间出口透传原始输入。

右出口：最右出口用于报告对象特性的取值。
