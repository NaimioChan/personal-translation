MSP

tapin~

延迟线的输入

描述

tapin~ 接收输入的信号并拷贝到一条延迟线中。借助 tapout~ 对象，你可以在不同的延迟时间读取这条延迟线。你必须把一个 tapin~ 对象的出口连接到你想与该延迟线一起使用的 tapout~ 对象。注意这不是信号连接，因为对象之间没有信号传递。它只是表明这些对象共用同一块延迟记忆的一种方式。

参数

maximum-delay [number] ms 可选

以毫秒为单位的最大延迟时间。它决定延迟线记忆的大小。若在对象创建之后提高采样率，tapin~ 会尝试调整延迟线的大小。若无参数，默认的最大延迟时间为 100 毫秒。

消息

int

左入口：一个 int 会以毫秒为单位指定的新最大延迟时间重新设置延迟线内存的大小（这会清空延迟线的内存，可能在输出中产生咔嗒声）。

参数：

  • memory-size [int]

float

左入口：一个 float 会以毫秒为单位指定的新最大延迟时间重新设置延迟线内存的大小（这会清空延迟线的内存，可能在输出中产生咔嗒声）。

参数：

  • memory-size [float]

clear

清空延迟线的内存（这可能在输出中产生咔嗒声）。

freeze

单词 freeze 后跟一个非零数字会让 tapin~ 冻结其缓冲区记忆。这意味着该对象会把它在冻结那一刻已录制进其记忆的内容持续从输出中送出，而不再录制任何新的输入。单词 freeze 后跟 0 会把对象复位到默认状态：不断把任何给定输入录制并重新录制进其记忆缓冲区，并在指定的延迟时间之后输出。

参数：

  • behavioral-flag (0 or nonzero) [int]

signal

信号被写入一条延迟线，该延迟线可由 tapout~ 对象读取。

输出

tap

为了让延迟线正常工作，tapin~ 的出口必须连接到 tapout~ 的左入口。它不能连接到任何其他对象。
