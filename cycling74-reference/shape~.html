MSP

shape~

按时间缩放的断点包络生成器

描述

可以为 shape~ 对象定义一个包络，格式与 line~ 或 zigzag~ 对象相同（并通过连接一个 function 对象对它进行图形化编辑）。与 line~ 不同，shape~ 的时间取值会被归一化，因此输出发生在从 0 到 1（或从 1 到 0）的相位器信号斜坡之内。这意味着你可以采样点精确地触发输出，并通过使用不同的斜坡持续时间（或 phasor~ 频率）来决定函数的时间。

参数

无。

特性

constant [int]

设置包络开头有多少个分段会按各自以毫秒为单位的时间取值，以恒定的时间来播放，而不受输入斜坡持续时间的影响。constant 的默认值为零，意味着没有任何分段会以恒定时间播放——所有分段都会被缩放。若 constant 为 1，第一个（"attack）分段将具有恒定时间，其余分段会被缩放，以占据输入斜坡中从输出的恒定部分结束时的输入值开始的那一部分。例如，若第一个分段是恒定的，并且它在输入等于 0.5 时结束，则包络余下的部分会被重新归一化，以容纳在 0.5 与 1 之间的空间里。
注意，constant 特性只对上升斜坡有效，并且只能指定包络开头的分段。

curvemode [int]

设置 shape~ 是否播放曲线断点，以及它如何解释传入的列表。
可选值：

0 = 'Off'（不使用曲线断点）
当 curvemode 被禁用（Off）时，shape~ 把传入的列表解释为 time, alue 对来设置它的断点。若此前设置过任何曲线断点，它们会作为线性斜坡播放。

1 = 'On'（使用曲线断点）
当 curvemode 被启用（On）时，shape~ 把传入的列表解释为由 time, value, curvature 组成的三元组。所有曲线断点都会带着各自的曲率输出。

2 = 'Auto'（使用所连接 function 的 mode 设置）
当 curvemode 设为 Auto 时，shape~ 会根据 mode 特性来决定如何解释传入的列表，该特性属于所连接的 function 或 mc.function 对象。若 mode 设为 0（Linear），列表被解释为 time, value 对。若 mode 设为 1（Curve），列表被解释为 time, value, curvature 三元组。若任何分段含有非零曲率，它们会带着各自的曲率播放。
为了让 Auto 模式正常工作，function 对象的第二个出口必须直接连接到 shape 的左入口。

syncupdate [int] : 0

启用 syncupdate 后，对断点函数的改动不会影响 shape~ 的输出，直到输入相位器或斜坡重置为止。禁用 syncupdate 后，shape~ 一收到新的断点列表，改动就会立即发生。

消息

int

转换为 float

float

左入口中的 float 定义函数的初始值。若后面没有 list 消息，单独一个 float 不会导致定义新函数（也不会替换已有的函数）。

参数：

  • initial-value [float]

list

list 消息定义 shape~ 所使用的断点函数。列表的格式有两种可选形式，取决于 curvemode 特性的设置。当 curvemode 被禁用时，列表的格式是 value, time 对，其中第一个数字是目标值，第二个数字是从上一个值到达该值所需的时间，单位为毫秒。该格式（以及一个初始的 float value0）由 function 对象的第二个出口产生。毫秒时间值会被归一化；换句话说，它们会被除以函数的总长度。断点之间的时间越长就越大于较短的时间，但精确的时间取决于传入斜坡的持续时间。
当 curvemode 被启用时，列表格式以初始的 float 开头，后面跟每个断点由 value, time, curvature 组成的数字三元组。曲率取值在 -1 到 1 之间。

参数：

  • breakpoints [list]

signal

shape~ 在输入斜坡开启或重置时开始输出。
