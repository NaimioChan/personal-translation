MSP

waveform~

buffer~ 查看器与编辑器

描述

使用 waveform~ 对象查看或编辑 buffer~ 的内容。

参数

无。

特性

allowdrag [int] : 1 >= 7.0.0

切换拖放功能。

attr_bpm [float] : 120.

把每分钟节拍数指定为时间参照单位，它相对于一个速度和每小节的拍数；这两者都可以用 bpm 消息设置。waveform~ 还可以通过 setbpm 消息算出适合你当前选区的一个速度。

beats [int] : 4

若 waveform~ 对象设为以 bpm 单位显示时间（用 setunit 特性设置），则切换是否以拍为单位显示时间。默认值为 0（关闭）。

bgcolor [4 floats]

以 RGBA 格式设置背景颜色，该颜色用于填充整个对象矩形，然后再在其上绘制其余显示组件。

buffername [symbol]

设置 buffer~ 对象的名称。

chanoffset [int] : 1

指定要显示的多通道音频文件中的某个通道。通道编号从 1 开始，取值必须在 1-4 范围内。
可选值：

'1'
'2'
'3'
'4'

clipdraw [int] : 0

设为 1 时，绘制模式下正在编辑的取值会被限幅到显示范围（显示范围由 vzoom 消息决定）。clipdraw 0 禁用限幅，允许取值自由缩放到窗口范围之外。默认值为 0，即不限幅。

grid [float] : 1000.

指定选区的起点与终点应对齐到竖网格线，网格线由 grid 消息设置。由于网格线的间距受当前时间计量单位以及偏移取值（若已指定偏移）影响，对齐到网格也会受这些参数影响。

gridcolor [4 floats]

以 RGBA 格式设置 gridcolor。特性 gridcolor 映射到 elementcolor 样式颜色。

invert [int] : 0

切换是否反转 waveform~ 对象显示中选中部分与未选中部分所用的颜色。默认值为 0（不反转）。

labels [int] : 1

别名：ruler

切换是否在显示区顶部横向显示时间计量的数字标签。任何非零 int 都会让标签被绘制。参数为 0，或不给参数，则禁用标签。

norulerclick [int] : 1

切换是否可以在 waveform~ 显示区的标尺区域中点击与拖动。默认是启用。

offset [float] : 0.

让所有标签与时间计量标记按指定的毫秒数平移。对齐行为也会随之平移。offset 可以通过送出消息 offset 0.，或者送出不带参数的 offset 消息来移除。

outmode [int] : 4

决定什么时候响应鼠标活动送出选区的起点与终点取值。只有选区的起点与终点（出口 3 和 4）会受影响。无论选择哪种模式，鼠标信息始终从出口 5 送出。
none：不响应鼠标活动送出选区的起点与终点取值。送出不带参数的 outmode 消息与带参数 none 的同一条消息效果相同。
down：只有你在 waveform~ 对象显示区内点击时，才送出（从出口 3 和 4）当前的选区起点与终点取值。
up：只有你在 waveform~ 对象显示区内点击之后松开鼠标按键时，才送出选区的起点与终点。
downup：在 waveform~ 对象显示区内点击时，以及松开鼠标按键时，都会送出选区的起点与终点。
continuous：在点击、松开以及整个拖动操作过程中，只要取值发生变化，就会送出选区的起点与终点。

quiet [int] : 0

切换是否在拖动时从 waveform~ 对象输出取值。默认值为 0（拖动时送出取值），反转 waveform~ 对象显示中选中部分与未选中部分所用的颜色。默认值为 0（拖动时输出数据）。

reflection [int] : 0

反射

reflectioncolor [4 floats]

反射颜色

selectalpha [float] : 0.5

该特性用于导入包含 waveform~ 对象的旧版补丁。以前，选区矩形是用两条遗留消息（rgb2 和 rgb7）以及一种 "blend" 传递模式绘制的。Max 用 alpha 通道设置选区颜色，并会自动把该特性应用到包含此对象的旧版本补丁。矩形。

selectioncolor [4 floats]

设置选框的颜色，该选框以 RGBA 格式标识出选区范围。

setmode [int] : 0

决定 waveform~ 对象如何响应鼠标操作。
可选值：

0 = 'None'（设为仅显示模式）
使 waveform~ 进入「仅显示」模式，此时点击和拖动都不产生效果。为了方便使用，以及添加自定义界面行为，鼠标操作仍会按照 mouseoutput 模式发送。不带参数的 mode 消息与 mode none 的效果相同。

1 = 'Select'（设为默认显示模式）
设置 waveform~ 对象的默认显示模式。在选择模式下，光标在 waveform~ 显示区域内显示为 I 形光标。你可以用鼠标点击并拖动来选择一段取值范围。鼠标操作会使 waveform~ 按照 mouseoutput 设置生成更新消息。

2 = 'Loop'（设为循环显示模式）
设置另一种循环选区样式，它用鼠标的垂直移动来增大和缩小选区长度，水平移动则映射为位置。这种样式很适合用来控制 groove~ 对象。选中循环模式后，把光标移到显示区域内，光标外观会变成双 I 形光标。

3 = 'Move'（设为移动显示模式）
设置 waveform~ 对象的移动显示模式。该模式让你可以浏览 waveform~ 视图。鼠标垂直移动可放大和缩小，水平移动则沿 x 轴的时间范围滚动。在图形上点击某一点，该点会成为本次鼠标事件后续过程的中心参考点（直到松开鼠标按键）。这样你就能「抓住」某处并放大它，而不必不断重新居中显示。

4 = 'Draw'（设为绘制显示模式）
设置 waveform~ 对象的绘制显示模式。该模式允许你用铅笔工具编辑目标 buffer~ 的取值。在绘制模式下点击并拖动会直接改动 buffer~ 的采样点，且无法撤销。拖动时采样点取值按线性插值，因此变化是连续的，即使缩得太小、看不见单个采样点也是如此。

setunit [int] : 0

设置显示所用的时间度量单位。
可选值：

0 = 'Millisecond'（把计时单位设为毫秒）
把显示单位设为毫秒（默认值）。

1 = 'Samples'（把计时单位设为目标 buffer~ 中的采样点位置）
使时间值显示为目标 buffer~ 中的采样点位置。除非显示已通过 offset 消息偏移，否则第一个采样点编号为 0。

2 = 'Phase'（把计时单位设为 buffer~ 内的相位）
使时间按 buffer~ 内的相位显示，相位经过归一化，0 指第一个采样点、1 指最后一个。当需要与使用 0-1 信号同步的对象（例如 phasor~ 和 wave~）配合工作时，这种度量单位特别有用。

3 = 'BPM'（把计时单位设为每分钟节拍数）
把每分钟节拍数指定为时间参考单位，它取决于速度和每小节节拍数，两者都可以用 bpm 消息设置。waveform~ 还可以通过 setbpm 消息计算一个符合当前选区的速度。

shadowalpha [float] : 0.

阴影 alpha

shadowblend [float] : 0.

阴影混合

shadowline [int] : 1

绘制阴影线

shadowproportion [float] : 0.

阴影比例

snapto [int] : 0

设置 waveform~ 选区的对齐模式。snap 使选区的起点和终点自动移动到 buffer~ 中的特定位置，这些位置由对齐模式定义。
可选值：

0 = 'Nothing'（禁用对齐）
禁用对齐以允许自由选择（默认值）。

1 = 'Grid'（把起点和终点对齐到垂直网格线）
指定选区的起点和终点应对齐到由 grid 特性设置的垂直网格线。由于网格线的间距受当前时间度量单位影响，也受偏移值影响（若已指定偏移），因此网格对齐同样会受这些参数影响。

2 = 'Zero Crossing'

style [symbol] : >= 7.0.0

设置要应用到对象上的样式。可使用 Format Palette 设置样式。

ticks [int] : 0

指定每条网格线之间应绘制的刻度数。默认值为八。参数为 0 或不带参数时禁用刻度标记。

vlabels [int] : 0

切换是否沿 waveform~ 显示区最右侧边缘绘制垂直轴标签。任何非零数值都会使标签被绘制。参数为 0 或不带参数时禁用它们。

voffset [float] : 0.

设置 waveform~ 显示区的垂直偏移。取值为 0. 时把 x 轴放在中间，这是默认值。

vticks [int] : 1

禁用或启用沿 waveform~ 显示区左右边缘绘制垂直轴刻度标记。任何非零 int 都会使刻度标记被绘制。参数为 0 或不带参数时禁用它们。

vzoom [float] : 1.

设置 waveform~ 显示区的垂直缩放。

waveformcolor [4 floats]

设置以 RGBA 格式指定的前景色，该颜色用于把 buffer~ 数据绘制为波形图。waveformcolor 特性映射到 color 样式颜色。

zoom_orientation [int] : 0

根据鼠标方向改变缩放方向。
可选值：

0 = 'Up'（鼠标向上移动时缩放）
1 = 'Down'（鼠标向下移动时缩放）

zoomstyle [int] : 0

设置放大状态下的绘制样式
可选值：

0 = 'Line'（把波形绘制为线条）
1 = 'Bars'（把波形绘制为零线上方或下方的条形）

zoomthresh [float] : 1.

若像素与采样点之比（缩放系数）大于或等于 zoomthresh，则使用放大绘制样式，而不使用填充渐变。若 zoomthresh 的值为 0，则从不使用放大绘制样式。

消息

bang

在任意入口收到 bang 都会使 waveform~ 转储/输出收到该 bang 的那个入口所对应的取值。

int

转换为 float，具体取决于各个入口。

左入口：以毫秒为单位设置显示起始时间。改变该值会偏移和/或缩放视图，使 buffer~ 采样数据中所要求的时间对齐到显示区左边缘。默认值为 0（显示从目标 buffer~ 的开头开始）。

第二个入口：以毫秒为单位设置显示长度。默认值为 buffer~ 的长度。
第三个入口：以毫秒为单位设置选区的起始时间。
第四个入口：以毫秒为单位设置选区的结束时间。

参数：

  • display-settings [int]

float

左入口：以毫秒为单位设置显示起始时间。改变该值会偏移和/或缩放视图，使 buffer~ 采样数据中所要求的时间对齐到显示区左边缘。默认值为 0（显示从目标 buffer~ 的开头开始）。

第二个入口：以毫秒为单位设置显示长度。默认值为 buffer~ 的长度。
第三个入口：以毫秒为单位设置选区的起始时间。
第四个入口：以毫秒为单位设置选区的结束时间。

参数：

  • display-settings [float]

list

第五个入口：第五个入口提供链接输入，它允许任意数量的 waveform~ 对象共享各自的起始、长度、选区起点和选区终点取值。这些取值中任何一个发生变化时，waveform~ 都会把它们作为一个列表从右出口送出。若该出口连接到另一个 waveform~ 对象的链接输入，后者就会在收到这些列表时得到更新。

要构成回路，可以把第二个 waveform~ 对象的列表输出连接到第一个对象的链接输入。这样，其中任一对象上的改动（例如通过鼠标点击）都会反映到另一个对象上。当这些 waveform~ 对象查看同一个 buffer~ 的不同通道时，这尤其有用。任意数量的 waveform~ 对象都可以用这种方式链接起来，形成一条长长的环形链。此时 waveform~ 会防止出现反馈。

参数：

  • start [float]
  • length [float]
  • select-start [float]
  • select-end [float]
  • select-start-ms [int]
  • select-end-ms [int]

(drag)

waveform~ 对象的点击与拖动行为会随对象的运行模式而变化（参见 setmode 特性）。

bpm

把每分钟节拍数指定为时间参考单位，它取决于速度和每小节节拍数，两者都可以用 bpm 消息设置。waveform~ 还可以通过 setbpm 消息计算一个符合当前选区的速度。

参数：

  • tempo [int]
  • beats-per-bar [int]

buftime

单词 buftime 后跟一个 20 到 60000 之间的数值，设置 waveform~ 对象因其关联的 buffer~ 对象发生变化而重绘时的最小绘制间隔（单位：毫秒）。把这个数值设得更高会对 CPU 占用带来一定影响。默认值为 500ms。

参数：

  • drawing-interval [int]

crop

crop 消息会把目标 buffer~ 中的音频数据裁减到当前选区。它把 buffer~ 调整为选区长度，把选中的采样点复制进去，并按默认设置显示结果。除选中的范围外，buffer~ 的其余内容都会被清除。这是一次「破坏性编辑」，无法撤销。

line

单词 line 后跟一个表示毫秒时间的整数或浮点数值，会把一条垂直线叠加到波形显示上由参数所指示的毫秒位置处。其目的是能够直观地指示波形在任意给定时刻的播放位置在哪里。若 line 的参数为负值，该垂直线会被隐藏。
单词 line 后跟一个 symbol，定义用于显示该线条的单位。可选项有：

bpm：每分钟节拍数
ms：毫秒（默认值）
phase：相位（范围 0. - 1.0）
samples

参数：

  • time [list]

mode

这是一条遗留消息 —— 该功能现在由 setmode 特性提供。

参数：

  • mouse-response-mode (symbol) [list]

(mouse)

waveform~ 对象响应点击与拖动的方式，会随该对象通过 setmode 特性配置的方式而变化。

mouseoutput

单词 mouseoutput 后跟一个 symbol 参数，决定在响应鼠标操作时何时送出选区起点和终点取值。只有选区起点和终点（出口 3 和出口 4）会受影响。无论 mouseoutput 模式如何，鼠标信息总是从出口 5 送出。有效的 symbol 参数有 none、down、up、downup 和 continuous。

none- 不因鼠标操作而送出选区起点和终点取值。不带参数地发送 mouseoutput 消息，与带参数 none 的同一消息效果相同。
down- 只有当你点击 waveform~ 内部时，才送出（从出口 3 和出口 4）当前的选区起点和终点取值。
up- 只有当你点击 waveform~ 内部之后松开鼠标按键时，才送出选区起点和终点。
downup- 当你点击 waveform~ 内部时，以及松开鼠标按键时，都会送出选区起点和终点。
continuous- 在点击、松开以及整个拖动操作过程中，只要取值发生变化就送出选区起点和终点。

参数：

  • mouse-output-mode (symbol) [list]

name

与 set 消息相同。单词 name 后跟一个 symbol，即某个 buffer~ 对象的名称，它把 waveform~ 链接到目标 buffer~，并按默认显示取值绘制该目标。可选的 int 参数设置通道偏移，用于查看多通道 buffer~ 对象。被链接的 buffer~ 的名称会复制到 buffername 特性，通道偏移会复制到 chanoffset 特性。两者都会随补丁保存。

若不带参数地发送 name 消息，它会清除 waveform~。

参数：

  • buffer-name [symbol]
  • channel [int]

normalize

单词 normalize 后跟一个 float，会缩放目标 buffer~ 中的采样点取值，使最高峰值等于参数给出的取值。这可能会放大或衰减音频，但无论哪种情况，buffer~ 中的每个取值都会被缩放，而且该操作无法撤销。

参数：

  • maximum-peak-value [list]

replacebuffercontents

单词 replacebuffercontents 后跟一个 symbol 参数，会替换与 waveform~ 对象关联的缓冲区的当前内容，并显示新的缓冲区内容。

参数：

  • filename [symbol]

set

与 name 消息相同。单词 set 后跟一个 symbol，即某个 buffer~ 对象的名称，它把 waveform~ 链接到目标 buffer~，并按默认显示取值绘制该目标。可选的 int 参数设置通道偏移，用于查看多通道 buffer~ 对象。被链接的 buffer~ 的名称会复制到 buffername 特性，通道偏移会复制到 chanoffset 特性。两者都会随补丁保存。

若不带参数地发送 set 消息，它会清除 waveform~。

参数：

  • buffer-name [symbol]
  • channel [int]

setbpm

单词 setbpm 不带参数时，会使 waveform~ 根据当前选区范围计算一个速度。它会自动把显示时间单位改为 bpm，就像你发送了消息 unit bpm 一样。所选择的速度使选区范围构成小节的逻辑倍数或细分，同时保持当前的每小节节拍数取值，并尝试找出符合其条件、且最接近当前速度的取值。选中合适的速度后，偏移参数会被调整，使选区范围的起始时间正好落在小节线上。

其结果是选区会被一个相容的速度精确框定。这种技术的一个用途是为某段音频快速建立时间标签和刻度标记。尽可能准确地选出一个完整小节后，发送 setbpm 消息并打开对齐到标签，就能立即把选区范围量化到节拍度量值上。

若目标 buffer~ 中包含的音频片段已经按逻辑上的节拍数或小节数裁减好，最好的做法是先选中 buffer~ 的整个范围（通过发往选区起点和终点入口的消息），再发送 setbpm 消息。若 buffer~ 裁减得精确，得到的速度叠加应当相当准确，并能立即连同节拍度量信息一起显示速度。

计算出新的速度后，它会从最右侧的出口（链接出口）送出，用于更新所有已链接的 waveform~ 对象，并按外围补丁所需的任何方式使用。

snap

单词 snap 后跟一个 symbol 参数，设置 waveform~ 选区的对齐模式。snap 使选区的起点和终点自动移动到 buffer~ 中的特定位置，这些位置由对齐模式定义。可用的参数有 none、grid 和 zero。

none- 禁用对齐，允许自由选择。这是默认值。不带参数的 snap 消息效果相同。
grid- 指定选区的起点和终点应对齐到由 grid 消息设置的垂直网格线。由于网格线的间距受当前时间度量单位影响，也受偏移值影响（若已指定偏移），因此网格对齐同样会受这些参数影响。
tick- 使选区起点和终点对齐到 ticks 消息所指定的刻度划分。
zero- 该模式不是把选区对齐到均匀网格，而是搜索 buffer~ 数据的零交叉点。零交叉点定义为正采样点紧随负采样点之后、或反之的位置。这有助于找到循环点和编辑点。

参数：

  • snap-mode (symbol) [list]

undo

该模式只对 waveform~ 选区有效。它会使选区起点和终点恢复到紧邻的上一组取值。当你用鼠标做精细编辑调整、不小心点错位置，或者以其他方式无意间改变了选区时，这会很有帮助。反复使用 undo 命令会在最近两个选区状态之间来回切换。

unit

单词 unit 后跟一个 symbol 参数，设置显示所用的时间度量单位。有效的 symbol 参数有 ms、samples、phase 和 bpm。

ms- 把显示单位设为毫秒。这是默认值。
samples- 使时间值显示为目标 buffer~ 中的采样点位置。除非显示已通过 offset 消息偏移，否则第一个采样点编号为 0。
phase- 使时间按 buffer~ 内的相位显示，相位经过归一化，0 指第一个采样点、1 指最后一个。当需要与使用 0-1 信号同步的对象（例如 phasor~ 和 wave~）配合工作时，这种度量单位特别有用。
bpm- 把每分钟节拍数指定为时间参考单位，它取决于速度和每小节节拍数，两者都可以用 bpm 消息设置。waveform~ 还可以通过 setbpm 消息计算一个符合当前选区的速度。

参数：

  • unit-of-measurement (symbol) [list]

输出

float

第一个出口：波形的显示起始时间，单位毫秒。

第二个出口：显示长度，单位毫秒。

第三个出口：选区的起始时间，单位毫秒。

第四个出口：选区的结束时间，单位毫秒。

list

第五个出口：这是鼠标出口，它送出关于鼠标点击/拖动/松开循环的信息，这些循环由在 waveform~ 对象内点击而发起。该列表包含三个数值。

第一个数值是一个 float，指定鼠标的水平（x）位置，以相对 waveform~ 对象的 0-1 比例单位表示。x 在 waveform~ 的左边缘始终为 0，在右边缘为 1.。

列表中的第二个数值是鼠标的浮点 y 取值，其缩放与 buffer~ 的取值匹配。在默认的 vzoom = 1. 和 voffset = 0. 下，waveform~ 顶部给出的 y 取值为 1，底部为 -1。

最后，列表中的第三个数值是一个 int，指示当前正处于鼠标事件的哪一部分。在鼠标按下（即点击）时，该值为 1。拖动期间为 2，松开鼠标时为 0。在编写鼠标点击的自定义响应时，这些会很有帮助。注意，无论鼠标是否移动，鼠标按下（1）消息之后会紧接着送出拖动（2）消息，以表示拖动阶段已经开始。

第六个出口：只要这些取值之一发生变化（通过鼠标操作、float 输入等），waveform~ 就会送出一个列表，其中包含它的显示起始时间、显示长度、选区起始时间和选区结束时间。更多信息参见上面的链接输入说明。
