Jitter

mc.jit.catch~

把信号数据变换为矩阵

描述

把 MSP 信号变换为一串 Jitter 矩阵。

参数

channels [] 可选

输入信号的数量。每个通道都会创建一个入口，输出矩阵会把每个通道的数据放在各自单独的通道上。

特性

downsample [int]

降采样因子（默认值 = 1）。若降采样取值设为 n，则每 n 个连续采样点为一组取平均。

framesize [int]

在某些模式下为输出矩阵的宽度。（默认值 = 320）

mode [int]

有四种不同的模式：在模式 0 下，自上次输出以来的所有数据都会以一维矩阵输出。在模式 1 下，能容纳进 framesize 整数倍的已缓冲数据会以二维形式输出；未输出的数据会留到下一次。在这前两种模式下，每收集一个采样点都应被输出且只输出一次。在模式 2 下，会输出最近数据的一个 framesize。模式 3 会让 jit.catch~ 表现得像示波器一样，在通道 trigchan 上的信号越过 triglevel、方向为 trigdir 时触发。若在整个内部数据缓冲区（100 ms）的时长内都未越过阈值，jit.catch~ 会临时回到模式 2 的行为，输出最近的数据，直到再次越过阈值。

trigdir [int]

用于识别触发点交叉的方向：0 为向上，1 为向下。（默认值 = 0）

trigchan [int]

在模式 3 下用于触发点的通道（默认值 = 0）

trigthresh [float]

在模式 3 下触发重绘的信号电平（默认值 = 0.0）

消息

bang

收到 bang 可能会触发一次矩阵输出，具体取决于 mode 以及自上次 bang 以来已收到的信号数据量。

bufsize

bufsize 一词后面跟一个浮点数，设置将被采样的缓冲区大小。

signal

在 jit.catch~ 对象任意入口收到的信号数据都会被转换为一串 Jitter 矩阵，并从该对象的出口送出。
