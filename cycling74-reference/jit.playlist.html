jit.playlist

播放视频文件

描述

用 jit.playlist 来组织成组的视频文件并播放它们。每个视频都在一个片段中获得可视化表示，你可以在其中从整个视频文件中选取一段。片段可以在某个 jit.playlist 内拖动以重新排序，也可以借助片段左侧的把手（圆点）把它们拖到其他 jit.playlist 对象上。

讨论

jit.playlist 对象从 jit.movie 继承下列特性。各特性的说明请参见 jit.movie 参考页。
colormode
interp
unique
vol
rate
seamless_loopcount（仅 avf 引擎）
cache_size（仅 viddll 引擎）

从 jit.movie 继承的特性会全局应用于播放列表中的每个片段。使用 setclip 消息可以为特定片段覆盖这些取值。全局的与片段特定的特性取值都保存在播放列表的内容字典中，并随补丁一起重新载入。可通过 getcontent 消息访问这些取值。

参数

无。

特性

accentcolor [4 floats]

设置循环图标在关闭时的颜色。

allowreorder [int] : 1

允许通过把某个片段左侧的把手（圆点）拖到其他片段上方或下方，来重新排列 jit.playlist 中的片段。
可选值：

0 = 'Off'
1 = 'On'
2 = 'Automatic'

bgcolor [4 floats]

以 RGBA 格式设置对象的背景颜色。

clipheight [float] : 30.

分配给每个片段用于显示的高度。根据 expansion 特性，把新片段拖入 jit.playlist 时该值可能会被改变。

color [4 floats]

以 RGBA 格式设置对象的控件颜色（打开时）。

drawto [symbol]

渲染上下文名称，在启用 output_texture 时使用。若未指定取值，该特性会被隐式设置。这种情况下请使用 getclipattr 消息查询该取值。

elementcolor [4 floats]

以 RGBA 格式设置对象的片段分隔线颜色。

expansion [symbol] : squeeze

在没有可用空白空间时，向 jit.playlist 添加片段所采用的容纳方式。
可选值：

'squeeze'（保持对象框的尺寸，缩小所有片段的高度以腾出空间。）
'static'（既保持对象框的尺寸，也保持所有片段的高度。需要借助滚动条才能看到视野之外的片段。）
'grow'（向下扩大对象框的尺寸，同时保持所有片段的高度。）

loop [int]

打开/关闭循环。

loopreport [int] : 0

当 loopreport 设为 1 时，每当所选视频文件播放到一次循环的末尾，都会把 "loopnotify" 一词连同片段编号和文件名一起从 jit.playlist 的第二个出口送出。

output_texture [int]

当 output_texture 设为 1 时，jit.playlist 中的视频文件会以纹理形式输出。纹理输出功能需要一个有效的 GL 上下文（例如 jit.world 或 jit.pworld）。

parameter_enable [int]

允许此对象与 Max for Live Parameters 一起使用，并允许在 Max 环境中设置初始参数取值。

parameter_mappable [int] : 1

启用 parameter_mappable 后，该对象就可以用 Mappings 功能映射到键盘或 MIDI 输入。

reportprogress [int] : 0

当 reportprogress 设为 1 时，当前播放位置会以 0-1 的浮点数从 jit.playlist 的第二个出口送出。

selectioncolor [4 floats]

以 RGBA 格式设置对象的选中颜色。

showname [int] : 1

当 showname 设为 1 时，视频文件的名称会显示在 jit.playlist 界面中。

style [symbol] :

设置要应用到对象上的 样式。可使用 Format Palette 设置样式。

textcolor [4 floats]

以 RGBA 格式设置文件名文字的颜色。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

Clip Modulation Mode int

设置 Live 应用程序所用的 Clip 调制模式。调制模式有：

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

Unit Style int

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

int

0 会停止视频播放。大于零的数字会开始播放索引为该数字的片段。索引从 1 开始计数。

append

把一个新视频文件加入列表。第一个参数指定该视频文件。第二个（可选）参数指定该片段的槽位编号（从 1 开始）。若未列出参数，在已锁定的补丁中点击 append 消息会打开一个对话框，你可以在其中选择要追加的文件。

参数：

  • video file [symbol]
  • clip number [int]

clear

从播放列表中移除所有片段。若只想移除一个片段，请在已锁定的补丁中右键点击要移除的文件，并从上下文菜单中选择 "Remove"。

(drag)

把一个兼容的媒体文件拖放到未锁定的补丁中，即可创建新的 jit.playlist 对象。若要把更多媒体文件载入某个 jit.playlist 对象，请把新文件拖到 jit.playlist 界面上，直到当前载入文件的上方或下方出现一条线。要在 jit.playlist 内重新排列轨道，请在已锁定的补丁中按住并向上或向下拖动把手（左侧圆点）。要替换当前载入的文件，请把新文件拖到旧文件上，直到整条轨道被高亮。

getclipattr

单词 getclipattr 后面跟片段编号和特性名，会把该特性的取值从 jit.playlist 的通知（中间）出口送出。这样你就能获取某个特定片段的特性状态。你可以获取只读特性（如 duration、moviedim 等），以及 jit.movie 支持的大部分特性。

参数：

  • clip [int]
  • attribute [symbol]

getcontent

单词 getcontent 会把所有片段的内容和行为以字典格式从 jit.playlist 的最后一个出口送出。把最后一个出口连接到 dict.view 对象即可看到这些内容。请注意，大多数内容状态不会打印其默认值。只有显式设置过取值时才会打印。对于 "absolutepath" 项，只有当文件不在 Max 的搜索路径中时，才会显示每个片段的完整文件路径。若文件在 Max 的搜索路径中，则只显示文件名。

(mouse)

用鼠标在 jit.playlist 中播放和停止某个片段。也可以用它选取采样的细小部分用于播放。

next

播放 jit.playlist 中载入的下一个片段。

pause

在当前播放位置暂停当前片段的播放。

remove

单词 remove 后面跟一个从 1 开始的片段编号，会从列表中移除该片段。

参数：

  • clip-number [int]

resume

若播放已暂停，则从当前位置恢复播放。

selection

用一个归一化范围（0.0 是起点，1.0 是终点）选择片段的播放端点。第一个参数指定哪个片段（从 1 开始计数）。第二个参数是该片段的起点，第三个参数是终点。若只给出两个参数，它们就作为 jit.playlist 中所有片段的起点和终点。若只给出一个参数，它作为片段编号，并清除该片段上的任何选择。

参数：

  • clip [int]
  • start [float]
  • end [float]

selectionms

以毫秒为单位选择片段的播放端点。第一个参数指定哪个片段（从 1 开始计数）。第二个参数是该片段的起点，第三个参数是终点。若只给出两个参数，它们就作为 jit.playlist 中所有片段的起点和终点。若只给出一个参数，它作为 jit.playlist 中所有片段的终点。

参数：

  • clip [int]
  • start [float]
  • end [float]

setclip

jit.movie 的特性在 jit.playlist 中同样可用。要控制某个特定片段，请使用 "setclip" 消息，后面跟片段编号、特性名和取值。消息 "setclip 2 loop 1" 会为片段 2 打开循环。

参数：

  • clip [int]
  • attribute [symbol]
  • value [anything]
