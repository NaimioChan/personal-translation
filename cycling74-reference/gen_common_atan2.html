Gen

atan2

The arctangent of the input coordinate

描述

Returns the angle to the coordinate (x,y) in radians.

构造

  • { arguments={opposite}, inlets={adjacent} }
  • { arguments={}, inlets={opposite, adjacent} }

入口

opposite [float]

opposite side of triangle

adjacent [float]

adjacent side of trangle
