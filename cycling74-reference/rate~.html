MSP

rate~

对 phasor~ 的输出进行时间缩放

描述

rate~ 对象接受来自 phasor~ 的输入信号，并用从其右入口以 float 形式收到的乘数对它做时间缩放。小于 1 的数会使每个相位周期产生多段斜坡。大于 1 的数产生的斜坡更少。这可用于在 MSP 中实现与 phasor~ 同步的系统。

参数

multiplier [float] 可选

用于缩放输出信号的乘数取值。

sync-mode-flag [int] 可选

设置同步模式（参见 sync 消息）。

特性

sync [int]

设置 rate~ 对象的同步模式。同步模式决定 rate~ “in” 是否与输入信号保持同相，以及所用的同步方法。当 rate~ 对象的输出“同相”时，输入与输出信号会在其周期的最小公倍数处精确对齐（即它们在同一时刻穿过零点并开始新的周期）。如果信号同相，而收到新的乘数取值，rate~ 对象会相应地改变其输出斜坡的频率。但是，乘数取值的改变意味着两个信号可能不再同相。rate~ 对象会以三种不同方式之一处理这种情况，具体取决于同步模式
可选值：

0 = 'cycle'（设置用于同步的 cycle 模式）
参数 @sync 0 或 @sync cycle 设置 rate~ 对象的 cycle 模式。在 cycle 模式下，rate~ 对象在当前周期结束之前不会改变其输出的相位。当输入斜坡达到峰值并从零重新开始时，rate~ 对象会立即重新开始输出斜坡，从而在输出信号中造成不连续，并立即实现相位同步。

1 = 'lock'（设置用于同步的 lock 模式）
参数 @sync 1 或 @sync lock 设置 rate~ 对象的 lock 模式。在同步 lock 模式下，rate~ 对象每当收到新的乘数时就执行同步。rate~ 对象会立即计算出与新乘数取值“同相”所对应的正确斜坡位置，并跳到该位置。

2 = 'off'（禁用同步模式）
参数 @sync 2 或 @sync off 会禁用 rate~ 对象的同步模式（默认模式）。在此模式下，rate~ 从不响应相位差异；收到新乘数时，rate~ 对象会调整其输出斜坡的速度，它们不受打断地继续下去。由于此模式从不在斜坡信号中引入不连续跳变，因此在相位不重要时可能有用。

消息

int

左入口：设置 rate~ 对象信号输出的相位值。

右入口：用于缩放 phasor~ 信号输入的信号乘数取值。大于 1 的整数值会产生更少的斜坡。这可用于把多个过程同步到单个参考 phasor~ 对象上，并保持它们的比值关系。

参数：

  • phase/multiplier [int]

float

左入口：设置 rate~ 对象信号输出的相位值。

右入口：用于缩放 phasor~ 信号输入的信号乘数取值。小于 1.0 的 float 取值会使每个相位周期产生多段斜坡。大于 1.0 的数产生的斜坡更少。这可用于把多个过程同步到单个参考 phasor~ 对象上，并保持它们的比值关系。

参数：

  • phase/multiplier [float]

goto

左入口：单词 goto 后面跟一个 float，会使 rate~ 对象立即跳到指定的取值。可选的第二个参数可用于指定跳到该取值的时间（例如 goto 1.0 .5 会在 phasor~ 对象输入信号斜坡的中间点输出取值 1.0）。

参数：

  • jump-to-value [float]
  • time-of-action [float]

oneshot

消息 oneshot 1 会打开 “oneshot” 模式，此时 rate~ 只输出一段斜坡周期。消息 oneshot 0 会关闭 “oneshot” 模式，此时 rate~ 在被要求（即通过 sync cycle 消息）时可以连续循环各段斜坡。

参数：

  • loop-flag (0 or nonzero) [int]

reset

左入口：单词 reset 会在下一次重置时把输出锁定到输入。它等价于消息 goto 0. 0。

signal

左入口：来自 phasor~ 对象的输入信号。

右入口：rate~ 对象用一个乘数取值对来自 phasor~ 的输入信号做时间缩放。该乘数取值可以指定为参数，也可以以 float 形式接收到 rate~ 对象的右入口。

输出

signal

同步后的信号从出口送出。
