Gen

delay

把信号延迟一定的时间（以采样点为单位指定）

描述

把信号延迟一定的时间（以采样点为单位指定）。第一个参数指定最大延迟时间（以采样点为单位，默认值为采样率）。第二个参数指定延迟抽头入口/出口对的个数（默认值为 1）。第一个入口是要延迟的信号。其余入口分别指定每个抽头的延迟时间（以采样点为单位）。当 @feedback 为 1 时，delay 与 history 一样允许补丁中存在反馈环，但最小延迟为 1 个采样点。当 @feedback 为 0 时，最小延迟时间为零个采样点（若 @interp 为 cubic、spline 或 spline6，则更大）

构造

  • { arguments={size, taps}, inlets={input, ...} }
  • { arguments={size}, inlets={input, ...} }
  • { arguments={}, inlets={input, ...} }

入口

input [float]

要延迟的输入

... [float]

输入延迟抽头

特性

feedback [bool] : 1 只写

指定该对象能否接收反馈信号（仅适用于可视化的 gen 补丁编辑）。若设为 0，delay 对象不会接收传入的反馈信号（除非反馈路径中还有另一个 feedback delay 或 history 对象）。启用 @feedback 后，最小延迟时间会增加 1 个采样点。

interp [enum] : linear 只写

指定插值模式："none" 与 "step" 不进行插值，"linear" 进行两点线性插值，"cosine" 进行两点余弦插值，"cubic" 进行四点三次插值，"spline" 进行四点 Catmull-Rom 样条插值，"spline6" 进行六点（5 阶）B 样条插值。
可选值：

0 = 'none'
1 = 'spline6'
2 = 'step'
3 = 'cosine'
4 = 'cubic'
5 = 'fastcubic'
6 = 'linear'
7 = 'spline'

name [string] : 只写

指定延迟线的名称。该名称会用在生成的代码中，也用于在两次编辑之间保留延迟数据。
