pfft~

补丁的频谱处理管理器

描述

pfft~ 对象用于简化使用快速傅里叶变换（FFT）的频谱音频处理。除了执行 FFT 与逆快速傅里叶变换（IFFT）之外，pfft~（在其伙伴对象 fftin~ 与 fftout~ 的帮助下）还负责管理创建实时短时傅里叶变换（STFT）分析/重合成系统所需的信号加窗、重叠与相加。

讨论

pfft~ 对象上入口的数量由所包含子补丁中 fftin~ 和/或 in 对象的数量决定。载入到 pfft~ 对象中的补丁只能由该补丁内的 fftin~ 对象赋予信号入口。详情参见 fftin~ 与 in。

参数

subpatch-name [symbol] 可选

要载入的补丁名称

FFT-size [int] samples 可选

指定由 FFT/IFFT 在频域之间来回变换的重叠窗的 FFT 大小，以采样点为单位。窗大小必须是 2 的幂，默认为 512。最小值为 32，除非启用了 legacy，此时为 16。最大值为 1048576。（注意：pfft~ 对象的子补丁所处理的频谱 "frames" 的大小将是此大小的一半，因为频谱的后一半是前一半的镜像、因而是冗余的，除非存在 full-spectrum-flag。）

overlap-factor (hop-size-denominator) [int] 可选

第三个参数决定 FFT 分析与再合成窗口的重叠因子。所执行的快速傅里叶变换的跳距（相邻两个 FFT 窗口之间的采样点数）等于快速傅里叶变换的大小除以该重叠因子。（例如，若帧大小为 512、重叠设为 4，则跳距为 128 个采样点）。该值必须是 2 的幂，默认值为 2。大多数应用建议取 4。

start-offset [int] samples 可选

第四个参数指定快速傅里叶变换开始首次分析的采样偏移量。它必须是当前信号向量大小的整数倍，默认值为 0。

full-spectrum-flag (0 or nonzero) [int] 可选

可以用非零的第五个参数指定 "全频谱模式"。在该模式下，pfft~ 对象会在内部计算复数 FFT，并处理从 DC 到 SR 的完整镜像频谱（而不是简单地去掉频谱中冗余的那一半）。这会额外消耗计算能力，但在某些较为冷门的频谱处理应用中可能有用。

'args' and list-of-argument-values [symbol] 可选

使用参数 args 并在其后跟一个参数值，可以初始化所加载补丁中的任何井号参数（例如 args #1）。若使用该参数，args 必须是最后一个使用的参数词；出现在单词 args 之后的一切都会被当作参数值。

特性

args [10 atoms]

用于初始化已加载补丁中任何井号参数（例如 args #1）的参数值。

fftsize [int]

FFT Size 是 FFT 中的点数（采样点数）。它必须是 2 的幂。默认点数为 512。最小点数为 16。最大点数为 1048576。对该值的任何更改都将在下次打开信号处理时生效。

float32 [int]

若启用 float32，FFT 将使用 32 位浮点精度执行。这样就能借助 SIMD 优化过的代码获得更快的性能。若启用了 legacy，则忽略该标志。对该值的任何改动都会在下次打开信号处理时生效。

fullspectrum [int]

若启用 fullspectrum，pfft~ 对象会在内部计算复数 FFT，并处理从 DC 到 SR 的完整镜像频谱（而不是简单地去掉频谱中冗余的那一半）。这会额外消耗计算能力，但在某些较为冷门的频谱处理应用中可能有用。对该值的任何更改都将在下次打开信号处理时生效。

legacy [int]

若启用了 legacy，FFT 将使用不带 SIMD 优化的遗留 FFT 实现来执行。对此值的任何改动，都会在下次开启信号处理时生效。

overlap [int]

FFT 分析与再合成窗口的重叠因子。所执行的快速傅里叶变换的跳距（相邻两个 FFT 窗口之间的采样点数）等于快速傅里叶变换的大小除以该重叠因子。（例如，若帧大小为 512、重叠设为 4，则跳距为 128 个采样点）。该值必须是 2 的幂，默认值为 2。大多数应用建议取 4。

patchername [symbol]

要加载的补丁文件名。

startoffset [int]

快速傅里叶变换开始首次分析的采样偏移量。它必须是当前信号向量大小的整数倍，默认值为 0。

消息

bang

加载到 pfft~ 对象中的补丁，只有 bang 消息能由补丁内的 in 对象接收。输入数量由所包含的子补丁中的 in 对象决定。详见 in。

int

送给 pfft~ 对象的整数取值会使该对象按其内部用户定义的功能行事。

参数：

  • input [int]

float

送给 pfft~ 对象的浮点取值会使该对象按其内部用户定义的功能行事。

参数：

  • input [float]

list

送给 pfft~ 对象的列表会使该对象按其内部用户定义的功能行事。

anything

送给 pfft~ 对象的任何消息会使该对象按其内部用户定义的功能行事。

参数：

clear

清除 pfft~ 对象的所有内部缓冲区。

用鼠标双击 pfft~ 对象会打开一个 Max 补丁窗口，其中包含该对象所加载的补丁。

mute

单词 mute 后面跟 1 或 0，会静音或取消静音 pfft~，从而关闭所包含子补丁内的信号处理。

参数：

open

单词 open 会打开加载到 pfft~ 对象中的子补丁。

参数：

  • subpatch-filename [int]

wclose

若所包含的子补丁处于打开状态，则关闭它。

参数：

  • subpatch-filename [int]

输出

message

已加载补丁中的 out 对象收到的任何消息，都会出现在 pfft~ 对象与该 out 对象的数字参数相对应的消息出口。 pfft~ 对象的消息出口出现在最右侧信号出口的右边。

signal

输出是这一基于 FFT 的信号处理子补丁的结果。与 fft~ 和 ifft~ 对象一样，pfft~ 也会从输入到输出引入轻微的延迟（不过其延迟不到 fft~ / ifft~ 组合延迟的一半）。输入/输出延迟等于窗口大小减去跳距（例如，对 1024 个采样点的 FFT 窗口、重叠因子为 4 时，跳距等于 256，从输入到输出的总延迟为 768 个采样点）。出口数量由已加载子补丁中 fftout~ 和/或 out 对象的数量决定。加载到 pfft~ 对象中的补丁可以由补丁内的 fftout~ 或 out 对象提供出口。详见 fftout~ 与 out。
