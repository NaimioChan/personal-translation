MSP

adstatus

报告并控制音频驱动设置

描述

使用 adstatus 对象可控制 Max 的音频设置。

参数

Controllable-settings: [symbol] 可选

第一个参数是一个符号，用来指定由 adstatus 对象控制的设置。有些设置还需要一个额外的整数参数。可用的设置如下：

cpu：报告当前的 CPU 利用率。
cpulimit：报告并设置 CPU 利用率上限，即 0-100 的百分比。
driver：列出可用的音频驱动，并允许更改当前所用的驱动。
info：报告顶层
input 中使用的函数调用次数与信号数量（需要一个额外的参数，指定 1 到 512 之间的逻辑通道号（由 adc~ 对象使用））：列出可用的音频驱动输入通道，并允许更改当前的设置。
iovs：报告当前音频驱动可用的 I/O 向量大小，并
latency：若音频驱动支持，则以采样点数报告该驱动的输入与输出延迟。
numinputs：报告当前音频驱动的输入通道数。
numoutputs：报告当前音频驱动的输出通道数。
option（需要一个额外的参数，指定选项编号（从 1 开始）：若当前音频驱动使用了该编号的选项，则报告可用于设置该选项取值的各种选择。
optionname（需要一个额外的参数，指定选项编号（从 1 开始）：若当前音频驱动使用了该编号的选项，则会报告该选项的名称。
output（需要一个额外的参数，指定 1 到 512 之间的逻辑通道号（由 dac~ 对象使用））：列出可用的音频驱动输出通道，并允许更改当前的设置。
overdrive：控制 overdrive mode 的设置（此时调度器运行于
sigvs：报告可用的信号向量大小，并允许更改当前的信号向量大小设置。
sr：报告可用的采样率，并允许更改当前的采样率设置。
switch：打开或关闭 DSP。
takeover：控制 scheduler in audio interrupt mode 的设置。
timecode：若音频驱动支持，则报告当前的时间码取值。

消息

bang

左入口：报告该设置的当前状态。在很多情况下，会把消息从 adstatus 对象的左出口送出，用 set 消息把弹出菜单对象设置为显示当前的设置。在这些情况下，设置的数值会从 adstatus 对象的右出口送出。具体行为见下面的「输出」一节。

int

左入口：更改该设置。大多数情况下，这个数字对应某个菜单项的索引，该菜单项的取值是由 bang 消息送给 adstatus 时设置的。

参数：

  • input [int]

(inlet1)

右入口：若 adstatus 对象与 input、iovs、output、sigvs、sr 这些设置一起使用，右入口中的 int 会以数值方式设置该值，而不是用菜单索引来设置（参见 reset 或 loadbang 消息）。对于其他所有设置，右入口中的数字与左入口中的作用完全相同。

参数：

  • input [int]

float

左入口：更改该设置。大多数情况下，这个数字对应某个菜单项的索引，该菜单项的取值是由 bang 消息送给 adstatus 时设置的。

参数：

  • input [float]

loadbang

左入口：输出用于 umenu 设置的消息，并在载入补丁时报告该设置的状态。clear 与 append 消息会从左出口送出，以便用一列可能取值来设置 umenu 对象，随后再送出一条 set 消息，把 umenu 设为对应的索引。设置的数值会从 adstatus 对象的右出口送出。具体行为见下面的「输出」一节。

override

左入口：override 一词后面跟一个 1，会为该对象所关联的设置打开覆盖模式。启用覆盖模式后，对该设置的任何更改都不会保存到 MSP Preferences 文件中。override 0 消息会关闭覆盖模式。默认情况下，所有设置的覆盖模式都是关闭的。不过，有些设置是音频驱动专属的，可能不会被驱动保存。

参数：

  • flag [int]

set

左入口：set 一词后面跟一个 1 到 512 之间的数字，会更改与 adstatus input 对象或 adstatus output 对象相关联的逻辑通道。为新的逻辑通道所设置的当前真实音频驱动输入或输出通道，会从该对象的各出口送出。

参数：

  • logical-channel-number [int]

update

左入口：update 一词会获取该设置的当前状态。
