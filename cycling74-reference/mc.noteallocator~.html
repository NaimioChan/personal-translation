MC

mc.noteallocator~

管理 MIDI 音符事件的声部号

描述

mc.noteallocator~ 对象为 MIDI 与 MPE 音符事件分配声部号，并用一个可选的多通道信号判定声部的忙碌状态。它还维护一张声部 busy map，供其他 MC 对象使用，以避免对未在演奏音符的通道做不必要的处理。

参数

voice count [int] 可选

若给出数字参数，它设置最大声部数。你可以在对象存活期间通过设置 voices 特性来改变声部数。

特性

direct [int] : 0

用信号输入设置 busy map

hires [int] : 3

hires 特性用于支持高分辨率弯音缩放。该特性设为 0 时，mc.noteallocator~ 会接受并输出标准 MIDI 范围 0 到 127 内的弯音整数值。该特性设为 1 时，它接受高分辨率 MIDI 数据并输出 -1 到 1 范围内的浮点值。该特性设为 2 时，它接受高分辨率 MIDI 数据并输出 -8192 到 8191 范围内的整数值（标准的 14 位 MIDI 高分辨率弯音范围）。该特性设为 3（默认值）时，它接受高分辨率 MIDI 数据并输出 0 到 16383 范围内的整数值（无符号 14 位 MIDI 高分辨率弯音范围）。
可选值：

0 = 'Off (0-127)'
1 = 'Float (-1 to 1)'
2 = '14-bit Fixed (-8192 to 8191)'
3 = '14-bit Fixed (0 to 16383)'

mpemode [int] : 0

启用 mpemode 后，mc.noteallocator~ 会输出 mpeevent 消息中包含的声部号，而不是根据其内部忙碌状态分配声部号。使用 MPE 模式时，传入 MPE 消息的来源（例如键盘或其他设备）负责声部分配的细节。MPE 模式默认禁用。

name [symbol] :

name 特性为该对象的 busy map 指定一个全局名。默认情况下，mc.noteallocator~ 的 busy map 没有名称，只对同一补丁内的 MC 对象可用。具名 busy map 对所有用 busymapname 特性引用它的 MC 对象（任何补丁中）都可访问。

steal [int] : 1

启用 steal 后，若没有空闲声部可用，mc.noteallocator~ 会重新分配（「抢占」）一个忙碌声部。被抢占的声部号是最近最少被分配的那个。禁用 steal 后，若所有声部都忙碌，mc.noteallocator~ 不会产生任何输出。只有当某个声部变为空闲时才会恢复输出，这可以是经由输入的多通道音频信号，也可以是传入的 MIDI note-off 事件。

voices [int] : 0

voices 特性设置 mc.noteallocator~ 会分配并输出的最大声部号。voices 为 0（默认值）时，活动声部数由所连接多通道信号的通道数决定。若没有连接信号，mc.noteallocator~ 默认使用 15 个声部。

消息

midievent

当 mc.noteallocator~ 在其入口收到一条 midievent 消息（来自 midiparse 对象）时，它会分配一个声部号并从右出口输出，然后把该 midievent 消息中的 MIDI 音符、控制器、触后或弯音值送往指定的各个出口。

参数：

  • MIDI [list]

mpeevent

当 mc.noteallocator~ 在其入口收到一条 mpeevent 消息（来自 mpeparse 对象）时，它会分配一个声部号并从右出口输出，然后把该 mpeevent 消息中的 MIDI 音符、控制器、触后或弯音值送往指定的各个出口。

参数：

  • MPE [list]

signal

连接一个可选的多通道信号，可避免 mc.noteallocator~ 在其音频电平降为零之前重新分配声部。
