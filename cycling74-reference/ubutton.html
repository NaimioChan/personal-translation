Max

ubutton

透明按钮

描述

创建一个透明的可点击区域，可以放置在图形或其他对象之上。被点击时会产生一条 bang 消息。

讨论

鼠标点击按钮时，左中间出口会送出一个 bang；鼠标键释放时，左出口会送出一个 bang。注意，新建一个 ubutton 时可以调整它的大小——把按钮放到补丁窗口后继续拖动鼠标即可。

参数

无。

特性

信息视图标题

dragtrack [int] : 0

dragtrack 一词后面跟一个非零数值，会启用 "Track Mouse While Dragging" 模式。在此模式下，点击后按住鼠标键时，会连续发送位置消息以及内部/外部消息（鼠标点击部分已在上文描述）。dragtrack 0 会禁用此行为，该行为默认关闭。拖动鼠标会持续生成这些消息对，直到鼠标键被释放。拖动跟踪默认关闭。也可以在 ubutton 对象的 Inspector 中启用它。

切换 ubutton 被点击时是否显示高亮。

hltcolor [4 floats]

param_connect [symbol] :

在对象与具有参数的兼容对象（如 gen~ 或 jit.gl.slab）的某个参数之间建立双向连接。该对象可用来改变参数的值，参数值变化时它也会随之更新。设置 param_connect 最简便的方法，是使用该特性在 inspector 中的菜单，或使用 Object Action 菜单的 Connect 子菜单。菜单会列出兼容对象的所有可用参数。

用消息设置 param_connect 特性时，需要给出目标参数的路径，即宿主对象的脚本名后跟两个冒号，再加上参数名。例如，对于一个 gen~ 对象，若其脚本名为 gen~_AB，则 freq 参数的路径为 gen~_AB::freq。可以在宿主对象或参数尚不存在时就为 param_connect 设值，该对象会在参数出现后与之建立连接。更多细节请参阅用户指南中 param_connect 条目。

参数特性

Order int

设置该参数的调取顺序。编号较小的先被调取。编号相同的参数，其调取顺序未定义。

Parameter Mode Enable int

参数模式启用（无法从 Parameters 窗口设置）

Link to Scripting Name int

勾选后，Scripting Name 会链接到 Long Name 特性。

Long Name symbol

参数的长名称。该名称在每条补丁层级中必须唯一。

Short Name symbol

设置对象界面显示所用的短名称。最大长度取决于字符宽度，但通常在 5 到 7 个字符之间。

Type int

指定数据类型。Live 集成中使用的数据类型有：

Float
Int
Enum（枚举列表）
Blob

注意：按照惯例，Live 应用程序在计算中使用浮点数；原生整数表示最多只有 256 个取值，默认范围是 0-255（类似于 Jitter 中使用的 char 数据类型）。处理整数值会超出该范围的 Live UI 对象时，应把 Type 特性设为 Float，把 Unit Style 特性设为 Int。

Range/Enum list

用于整数或浮点数据类型时，该字段用于指定参数的最小值与最大值。
用于枚举列表（Enum）数据类型时，该字段包含以空格分隔的枚举取值列表（若列表项中含有空格或特殊字符，名称应当用双引号括起来）。

None
Unipolar
Bipolar
Additive
Absolute

Clip Modulation Range list

该参数仅在 Absolute 调制模式下使用。它指定定义所用的取值范围。

Initial Enable int

勾选后（设为 1），该 UI 对象可以存储一个初始化值。该值通过 Initial 特性设置（见下）。

Initial list

设置 Initial Enable 特性勾选后所要存储并使用的初始值。

设置显示取值时所用的单位样式。单位样式取值有：Int：显示整数值
Float：显示浮点值
Time：以毫秒（ms）显示时间值
Hertz：显示频率值（Hz/kHz）。
deciBel：显示响度（dB）
%：百分比
Pan：显示 Left/Right 取值
Semitones：显示音级数（st）
MIDI：显示与 MIDI 音符号对应的音高
Custom：显示自定义数据类型
Native：默认为浮点值

Custom Units symbol

设置 'Custom' 单位样式要用的单位（见上文 "Unit Style"）。自定义单位串可以是简单符号（例如 "Harmonic(s)"），这种情况下参数的取值会按其 'Native' 显示模式显示，后面跟上该符号（例如 Int 型参数显示 "12 Harmonic(s)"，Float 型参数显示 "12.54 Harmonic(s)"）。若想进一步控制显示出来的数值部分，可以使用 sprintf 风格的字符串（例如 "%0.2f Bogon(s)"，它会显示 ".87 Bogons" 这样的值）。

Exponent float

设为 1. 以外的值时，参数的输入与输出取值会按本列输入的系数进行指数缩放。

Steps int

参数的最小值与最大值之间可用的步数。例如，若参数的取值范围是 0.-64.，把 Steps 设为 4，则用户只能把参数设为 0、21.33、42.66 和 64。

Control Surface Button Mode symbol

当参数用 live.banks 对象分配时，控制面板按钮的行为。目前可用的模式有：
Toggle：在最小值与最大值之间切换（默认）
Trigger：先输出最大值，紧接着输出最小值
Cycle：在可用的枚举取值之间循环

Parameter Visibility int

对于可自动化的参数（Int、Float、Enum），'Stored Only' 会禁用自动化，不过参数取值仍会存进预设。'Hidden' 会让参数的取值在存储和调取数据时被忽略。不可自动化的参数（Blob）默认为 'Stored Only'，如有需要可以设为 'Hidden'。'Visible' 和 'Visible (Not Stored)' 可见性模式会把参数暴露给 Live，但不支持自动化。实际效果是，它们对 Push（以及其他控制面板）可见，但不会出现在 Live 的自动化视图中。'Visible' 模式还会让 Live 把参数取值存入预设并随 set 一起保存，以便日后恢复。'Visible (Not Stored)' 不存储取值（对瞬时控件很有用）。注意这些模式只适用于 Float、Int 和 Enum 参数类型。使用这些 'Visible' 模式时，对象的 inspector 中会多出一个参数特性：'Undo When Visible'。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Undo When Visible int

使用 'Visible' 模式时（见 'Parameter Visibility'），对象的 inspector 中会出现该特性。它默认开启，但禁用后，Visible 参数对 Live 的 Undo 系统不可见。

Update Limit (ms) int

限制由自动化触发的取值的速度。

Defer Automation Output int

延迟由自动化触发的取值。

消息

bang

ubutton 对象可以以两种模式之一运行。当 ubutton 处于按钮模式（默认模式）时，它响应入口中的 bang：短暂高亮，并从左出口送出一个 bang。当 ubutton 处于切换模式时，入口中的 bang 会使它变为（并保持）高亮，并从右出口送出一个 bang；或者，若它已经高亮，则变为不高亮，并从左出口送出一个 bang。

int

若 ubutton 正在等待某个特定的数值（它的 Stay-on Value）且传入数值与之匹配，按钮会高亮，但不会送出任何内容。若传入数值与 ubutton 正在等待的数值不匹配，按钮会变为不高亮（或保持该状态）。若 ubutton 的 Stay-on Value 为 0，int 与 bang 相同。

参数：

  • input [int]

float

转换为 int。

参数：

  • input [float]

anything

被转换为 bang。

参数：

  • input [list]

(mouse)

在 "button" 模式下，用鼠标点击 ubutton 会在按住鼠标期间保持高亮：鼠标键按下时从右出口送出一个 bang，鼠标键释放时再从左出口送出另一个 bang。在 "toggle" 模式下，鼠标点击的行为与 bang 相同。点击鼠标时，若光标位于 ubutton 对象的矩形内部，ubutton 会向右出口送出 1，否则送出 0。鼠标键释放时也会发送这些消息。当对象处于 "Track Mouse While Dragging" 模式时，点击后按住鼠标键期间会连续发送这些消息。

set

若 ubutton 处于切换模式，set 1 会置位 ubutton 对象的切换（使其高亮），set 0 会清除 ubutton 对象的切换（使其不高亮）。set 的其他整数参数会把该数值发给 ubutton，用于与它的 Stay-on Value 比较，而不会产生任何输出。

参数：

  • input [int]

输出

bang

第一个出口：在按钮模式下（Stay-on Value 为 0），任意输入都会使 ubutton 闪烁，并从左出口送出一个 bang。鼠标键释放时，也会从左出口送出一个 bang。

若 ubutton 对象处于切换模式且已经高亮，任意输入都会使 ubutton 变为不高亮，并从它的左出口送出一个 bang。

bang

第二个出口：在按钮模式下（Stay-on Value 为 0），鼠标点击会在鼠标键按下时送出一个 bang。

若对象处于切换模式，任意输入都会使 ubutton 变为高亮，并从该出口送出一个 bang。若它已经高亮，则变为不高亮，且不送出任何 bang。

int

右出口：鼠标键被点击并释放时，会向该出口送出 1，前提是光标位于 ubutton 对象的矩形区域内。若用 Inspector 或 dragtrack 消息启用了 "Track Mouse While Dragging" 选项，则会输出 0，只要鼠标键按住期间光标移出了 ubutton 对象的矩形区域。

list

第三个出口：鼠标键被点击并释放时，ubutton 对象会送出一个由两个数字组成的列表，它们指定光标位置的坐标，表示为相对于 ubutton 对象矩形左上角的偏移量（单位为像素）。若用 Inspector 或 dragtrack 消息启用了 "Track Mouse While Dragging" 选项，则鼠标移动时会持续报告新坐标，直到鼠标键被释放。
