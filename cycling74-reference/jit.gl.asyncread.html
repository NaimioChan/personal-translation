Jitter

jit.gl.asyncread

从 OpenGL 帧缓冲读回

描述

使用像素缓冲对象（PBO）在高帧率下对 OpenGL 上下文进行异步读取。性能提升来自并行使用两个像素缓冲对象，把读取操作的开销分摊到一段时间上，同时不会像使用朴素方法时那样阻塞其他渲染命令的执行。

讨论

该 OB3D 对象可选地接受一个参数：绘制上下文的名称。它可以是 jit.world 或 jit.pworld 对象的具名实例，也可以是 jit.gl.node 子上下文。该值也可以通过 OB3D 的 drawto 特性设置。若未给出参数，对象会被隐式加入当前补丁中找到的第一个有效绘制上下文或子上下文，或者沿补丁层级向上搜索找到的第一个有效绘制上下文或子上下文。

参数

无。

特性

adapt [int]

让读回纹理的维度自适应输入纹理的维度（默认值 = 1）。

dim [2 ints]

读回纹理的维度，在 adapt = 0 时使用（默认值 = 640 480）。

matrixoutput [int]

输出帧缓冲（OpenGL 渲染上下文）的一份副本。输出矩阵的维度会适应窗口的大小。

mode [symbol]

设置读取模式（默认值 = interleaved）。
可选值：

'interleaved'（ 把整个帧读入每个内部缓冲区，每隔一帧切换缓冲区。在 interleaved 模式下，读回会延迟一帧。）
'split'（ 分两趟读取单个帧，输出是并发的。）

out_name [symbol] 只读

返回内部帧缓冲（OpenGL 渲染上下文）的名称。

texture [symbol]

设置要读回的纹理的名称。若未设置，则在 drawto 上下文上执行读回。

OB3D 特性

automatic [int]

自动渲染标志（默认值 = 1）该标志置位时，关联的 jit.gl.render 对象收到 bang 消息时即进行渲染

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

name [symbol]

实例名称（默认值 = UID）
