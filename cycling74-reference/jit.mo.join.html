jit.mo

jit.mo.join

组合 jit.mo 数据流并输出多通道矩阵

描述

组合 jit.mo 数据流并输出多通道矩阵。会自动连接到 jit.world 来驱动动画。各入口可以加入多个 jit.mo/matrix 输入以实现叠加控制。

参数

Inlet Count [number] 可选

设置入口的数量与输出的 planecount。

Dimension [number] 可选

设置输出矩阵以及任何挂接的 jit.mo.func 对象的维度（元素个数）。jit.mo 对象只支持 dimcount 为 1 的矩阵。

特性

fixed_delta [float64]

用于驱动函数动画的固定帧增量时间（默认值 = 0.0）。非零时，动画会用该值来计算输出，而不用距上次更新以来的增量时间。当需要以固定速率动画、而不受实际更新速率影响时，这会很有用。

interval [time]

动画间隔（默认值 = 0 ms）。该特性使用 Max 时间格式语法，因此间隔可以是固定值，也可以与速度相关。设为非零值时，speed 特性不再可由用户设置，而会根据间隔值自动设置。

scale [float64]

输出乘数（默认值 = 1.0）。

enable [long]

启用动画（默认值 = 1）。这会影响任何相连的 jit.mo.func 对象

speed [float64]

动画速度（默认值 = 1.）。缩放所有相连 jit.mo.func 对象的动画速度

name [symbol]

对象名称（默认值 = UID）。
