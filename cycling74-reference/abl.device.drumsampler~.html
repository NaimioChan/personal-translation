Ableton DSP

abl.device.drumsampler~

Drum sampler

描述

A monophonic sampler with various effect processors.

参数

buffer-name [symbol] 可选

Initial buffer~ from which to read.

buffer-name [symbol] 可选

Initial buffer~ from which to read.

特性

attack [float]

Sets the time needed to travel from the initial level to the peak level in seconds. [0.0001, 20.]

cutoff [float]

Sets the filter cutoff frequency in Hz. [30., 22000.]

decay [float]

Sets the amount of time in seconds for the envelope to travel from the peak level to zero. [0.001, 60.]

detune [float]

Sets the global detune amount in cents. [-0.5, 0.5]

eightbitdecay [float]

Sets the decay time for the internal low-pass filter of the 8-bit effect. [0.01, 5.]

eightbitrate [float]

Sets the sample rate to be used to play back the sample. [1000., 30000.]

envtype [int]

Sets the envelope mode
Possible values:

0 = 'ASR' ( Attack-Sustain-Release )
A gated envelope which releases after the note finishes

1 = 'AHD' ( Attack-Hold-Decay )
A triggered envelope which decays after a set hold time

filter [int]

Enable or disable the filter section

filtertype [int]

Sets the filter type
Possible values:

0 = 'Lowpass 12dB'
1 = 'Lowpass 24dB'
2 = 'Highpass 24dB'
3 = 'Peak'

fm [float]

Sets the amount of frequency modulation applied to the sample. [0., 1.]

fmfreq [float]

Sets the frequency used to modulate the sample's pitch. Note that the frequency will be adjusted based on the global pitch controls and the MIDI note played. [10., 4500.]

fx [int]

Enable or disable playback effects.

fxtype [int]

Sets the type of playback effect.
Possible values:

0 = 'Stretch'
1 = 'Loop'
2 = 'Pitch Envelope'
3 = 'Punch'
4 = '8-Bit'
5 = 'FM'
6 = 'Ring Mod'
7 = 'SubOsc'
8 = 'Noise'

gain [float]

Sets the sample gain in dB. [-70., 24.]

hold [float]

Sets the amount of time in seconds that the amplitude will be kept at the peak level after reaching the attack time. This has no effect when the envelope mode is set to gate. [0.001, 60.]

length [float]

Sets the length of the sample region that is played, calculated as a percentage of the sample's length. [0., 1.]

looplength [float]

Sets the length of the loop. Note that the loop length will be adjusted based on the global pitch controls and the MIDI note played. [0.01, 0.5]

loopoffset [float]

Sets the loop start point in relation to the sample start point. Note that the loop offset will be adjusted based on the global pitch controls and MIDI note played. [0., 1.]

mod [float]

Sets the modulation amount. [-1., 1.]

moddst [int]

Sets the modulation target/destination.
Possible values:

0 = 'Filter Cutoff'
1 = 'Attack'
2 = 'Hold'
3 = 'Decay'
4 = 'FX1'
5 = 'FX2'

modsrc [int]

Sets the modulation source.
Possible values:

0 = 'Velocity'
1 = 'Slide'

noise [float]

Sets the level of the noise oscillator. Note that the oscillator's envelope uses the global attack and decay settings. [0., 1.]

noisecolor [float]

Sets the frequency used to filter the noise oscillator. Note that the frequency will be adjusted based on the global pitch controls and the MIDI note played. [180., 15000.]

pan [float]

Sets the global panning. [-1., 1.]

peak [float]

Sets the peak gain in dB for the peak filter. [-12., 12.]

pitchenv [float]

Sets the amount of pitch modulation applied to the sample. Positive or negative values can be used, resulting in higher or lower pitch, respectively. [-1., 1.]

pitchenvdecay [float]

Sets the time required for the pitch to go back to the base value as determined by the pitch controls. [0.005, 2.]

punch [float]

Sets the amount of ducking applied to the sample. [0., 1.]

punchrelease [float]

Sets the time in seconds for the gain reduction to fall back to zero after the initial trigger. [0.06, 1.]

res [float]

Sets the filter resonance for the lowpass or highpass filter. [0., 1.]

rm [float]

Sets the amount of ring modulation applied to the sample. [0., 1.]

rmfreq [float]

Sets the frequency used to modulate the sample's amplitude. Low values create a tremolo effect while high values add typical ring modulation artifacts. Note that the frequency will be adjusted based on the global pitch controls and the MIDI note played. [1., 5000.]

start [float]

Sets the sample start point, calculated as a percentage of the sample length. [0., 1.]

stretchfactor [float]

Sets the amount of time-stretching as a factor of the original playback speed. [1., 20.]

stretchgrain [float]

Sets the the size of the grain (in seconds) used to time-stretch the sample. [0.005, 0.3]

subosc [float]

Sets the level of the sub oscillator. Note that the oscillator's envelope uses the global attack and decay settings. [0., 1.]

suboscfreq [float]

Sets the sub oscillator frequency. Note that the frequency will be adjusted based on the global pitch controls and the MIDI note played. [30., 120.]

transpose [float]

Sets the global transposition amount in semitones. [-48., 48.]

vel [float]

Sets how much the volume will be modulated by incoming MIDI note velocity. [0., 1.]

volume [float]

Sets the global volume in dB. [-36., 36.]

ins [symbol]

声明额外的入口，用于以事件速率或信号速率控制 float 类型的特性。已映射到入口的已声明特性将被忽略。该特性只能在对象实例化时设置。
