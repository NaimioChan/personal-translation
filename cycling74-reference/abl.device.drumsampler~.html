Ableton DSP

abl.device.drumsampler~

鼓采样器

描述

一种带多种效果处理器的单音采样器。

参数

buffer-name [symbol] 可选

要从其读取的初始 buffer~。

buffer-name [symbol] 可选

要从其读取的初始 buffer~。

特性

attack [float]

设置从初始电平行进到峰值电平所需的时间，单位为秒。[0.0001, 20.]

cutoff [float]

设置滤波器截止频率，单位为 Hz。[30., 22000.]

decay [float]

设置包络从峰值电平行进到零所需的时间，单位为秒。[0.001, 60.]

detune [float]

设置全局失谐量，单位为音分。[-0.5, 0.5]

eightbitdecay [float]

设置 8 位效果内部低通滤波器的衰减时间。[0.01, 5.]

eightbitrate [float]

设置用于播放该采样的采样率。[1000., 30000.]

envtype [int]

设置包络模式
可选值：

0 = 'ASR' ( Attack-Sustain-Release )
音符结束后释放的门控包络

1 = 'AHD' ( Attack-Hold-Decay )
在设定的保持时间之后衰减的触发式包络

filter [int]

启用或禁用滤波器段

filtertype [int]

设置滤波器类型
可选值：

0 = 'Lowpass 12dB'
1 = 'Lowpass 24dB'
2 = 'Highpass 24dB'
3 = 'Peak'

fm [float]

设置施加到采样上的频率调制量。[0., 1.]

fmfreq [float]

设置用于调制采样音高的频率。注意该频率会根据全局音高控制和所演奏的 MIDI 音符进行调整。[10., 4500.]

fx [int]

启用或禁用播放效果。

fxtype [int]

设置播放效果的类型。
可选值：

0 = 'Stretch'
1 = 'Loop'
2 = 'Pitch Envelope'
3 = 'Punch'
4 = '8-Bit'
5 = 'FM'
6 = 'Ring Mod'
7 = 'SubOsc'
8 = 'Noise'

gain [float]

设置采样增益，单位为 dB。[-70., 24.]

hold [float]

设置幅度在到达起音时间后保持于峰值电平的时间长度，单位为秒。包络模式设为 gate 时此项不起作用。[0.001, 60.]

length [float]

设置所播放采样区域的长度，以采样长度的百分比计算。[0., 1.]

looplength [float]

设置循环的长度。注意循环长度会根据全局音高控制和所演奏的 MIDI 音符进行调整。[0.01, 0.5]

loopoffset [float]

设置相对于采样起始点的循环起始点。注意循环偏移会根据全局音高控制和所演奏的 MIDI 音符进行调整。[0., 1.]

mod [float]

设置调制量。[-1., 1.]

moddst [int]

设置调制的目标/目的地。
可选值：

0 = 'Filter Cutoff'
1 = 'Attack'
2 = 'Hold'
3 = 'Decay'
4 = 'FX1'
5 = 'FX2'

modsrc [int]

设置调制源。
可选值：

0 = 'Velocity'
1 = 'Slide'

noise [float]

设置噪声振荡器的电平。注意该振荡器的包络使用全局的起音与衰减设置。[0., 1.]

noisecolor [float]

设置用于对噪声振荡器进行滤波的频率。注意该频率会根据全局音高控制和所演奏的 MIDI 音符进行调整。[180., 15000.]

pan [float]

设置全局声像。[-1., 1.]

peak [float]

设置峰值滤波器的峰值增益，单位为 dB。[-12., 12.]

pitchenv [float]

设置施加到采样上的音高调制量。可以使用正值或负值，分别得到更高或更低的音高。[-1., 1.]

pitchenvdecay [float]

设置音高回到由音高控制所确定的基础取值所需的时间。[0.005, 2.]

punch [float]

设置施加到采样上的闪避量。[0., 1.]

punchrelease [float]

设置初始触发之后增益衰减回落到零所需的时间，单位为秒。[0.06, 1.]

res [float]

设置低通或高通滤波器的滤波器谐振。[0., 1.]

rm [float]

设置施加到采样上的环形调制量。[0., 1.]

rmfreq [float]

设置用于调制采样幅度的频率。取值较低时会产生震音效果，取值较高时会添加典型的环形调制伪影。注意该频率会根据全局音高控制和所演奏的 MIDI 音符进行调整。[1., 5000.]

start [float]

设置采样起始点，以采样长度的百分比计算。[0., 1.]

stretchfactor [float]

设置时间拉伸量，作为原始播放速率的倍数。[1., 20.]

stretchgrain [float]

设置用于对采样进行时间拉伸的颗粒大小（单位为秒）。[0.005, 0.3]

subosc [float]

设置子振荡器的电平。注意该振荡器的包络使用全局的起音与衰减设置。[0., 1.]

suboscfreq [float]

设置子振荡器频率。注意该频率会根据全局音高控制和所演奏的 MIDI 音符进行调整。[30., 120.]

transpose [float]

设置全局移调量，单位为半音。[-48., 48.]

vel [float]

设置音量受传入 MIDI 音符力度调制的程度。[0., 1.]

volume [float]

设置全局音量，单位为 dB。[-36., 36.]

ins [symbol]

声明额外的入口，用于以事件速率或信号速率控制 float 类型的特性。已映射到入口的已声明特性将被忽略。该特性只能在对象实例化时设置。
