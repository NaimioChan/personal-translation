Jitter FX

jit.fx.co.negate

Negation blending effect

描述

Blends negated inputs together.

特性

bypass [int]

旁路效果处理标志（默认值 = 0）。启用后，输入不经处理直接送到输出。

adapt [int] : 1

使输出维度自适应输入（默认值 = 1）。启用后，输出维度将与最左侧输入的维度一致。

amount [4 floats]

每个通道的混合量（默认值 = 0 0 0 0）。混合值为 0. 时，输出值等同于左侧输入；值为 1.0 时，输出值等同于右侧输入

dim [2 ints]

输出纹理的维度。启用 adapt 后，会按最左侧输入自动设置。

OB3D 特性

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。
