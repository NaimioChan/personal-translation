Ableton DSP

abl.dsp.saturator~

饱和器

描述

一种波形整形饱和效果。

参数

drive [number] 可选

输入驱动

gain [number] 可选

输出增益

特性

curve [int]

选择固定曲线模式。在 Analog Clip 与 Digital Clip 模式下，信号会被完全且立即削波。Soft Sine、Medium Curve 与 Hard Curve 模式会在不同程度上柔化削波。Sinoid Fold 模式适合用于特殊效果。
可选值：

0 = 'Analog Clip'
1 = 'Soft Sine'
2 = 'Medium Curve'
3 = 'Hard Curve'
4 = 'Sinoid Fold'
5 = 'Digital Clip'
6 = 'Bass Shaper'

dcblock [int]

启用或禁用直流阻断。

drive [float]

以 dB 为单位设置输入信号在饱和之前的增益。[-36., 36.]

gain [float]

以 dB 为单位设置波形整形之后的输出增益。[-70.6, 0.]

mix [float]

设置输出信号的干/湿比 [0., 1.]

oversample [int]

启用或禁用过采样。

post_clip [int]

设置波形整形之后的削波模式。
可选值：

0 = 'No Clip'
1 = 'Soft Clip'
2 = 'Hard Clip'

bassthreshold [float]

设置 Bass Shaper 曲线的阈值。输入信号低于阈值时曲线保持线性，但信号一旦超过阈值就开始平滑削波。低阈值取值对低音信号效果最好，尤其是在与高驱动取值组合时。[-50., 0.]

ins [symbol]

声明额外的入口，用于以事件速率或信号速率控制 float 类型的特性。已映射到入口的已声明特性将被忽略。该特性只能在对象实例化时设置。
