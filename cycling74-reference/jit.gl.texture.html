jit.gl.texture

Create OpenGL textures

描述

Creates OpenGL textures - buffers of image data used in drawing 3D geometry. jit.gl.texture is similar to jit.matrix except that textures reside on the graphics card.

讨论

该 OB3D 对象可选地接受一个参数：绘图上下文的名称。它可以是 jit.world 或 jit.pworld 对象的具名实例，也可以是 jit.gl.node 子上下文。该值也可以通过 OB3D 的 drawto 特性设置。若未给出参数，对象会被隐式加入当前补丁中找到的第一个有效绘图上下文或子上下文，或者沿补丁层级向上搜索找到的第一个有效绘图上下文或子上下文。

特性

adapt [int]

Enable adapt to input (default = 1). When enabled the texture output dimensions will match the input dimensions.

anisotropy [int]

Anisotropic filter width (default = 0). Anisotropic filtering is an advanced filtering technique that takes multiple samples and blends the results together. Using anisotropy requires rectangle mode disabled.

autoclear [int]

Auto-clear texture during capture

autoscale [int]

Auto-scale texture coordinates

autotype [symbol] 只读

Returns the actual texture type used when type is auto (adapting to input).

bordercolor [4 floats]

Texture border color

colormode [symbol]

Sets the color format of the texture (default = auto). The colormode determines the number of planes and the internal GPU format used for storing the texture data. It also determines the swizzling used when sampling in a shader. When set to auto, the colormode is forced to 4 plane RGBA. Changing the colormode will recreate the texture on the GPU.
Possible values:

'auto' ( Automatic colormode (rgba) )
Force color mode to 4 plane RGBA.

'alpha' ( Single channel alpha )
Single plane texture storing alpha values. When sampled in a shader, returns (0, 0, 0, value) — the value appears only in the alpha channel with RGB set to zero.

'depth' ( Single channel depth )
Unused legacy option. When sampled in a shader, returns (value, value, value, 1.0) — the value is broadcast to RGB with alpha set to 1.

'intensity' ( Single channel intensity )
Single plane texture storing intensity values. When sampled in a shader, the value is broadcast to all four channels (value, value, value, value).

'luminance' ( Single channel luminance )
Single plane texture storing luminance values. When sampled in a shader, returns (value, value, value, 1.0) — the value is broadcast to RGB with alpha set to 1.

'lumalpha' ( Two channel luminance and alpha )
Two plane texture storing luminance and alpha values. When sampled in a shader, returns (lum, lum, lum, alpha) — the luminance value is broadcast to RGB.

'rgb' ( Three channel RGB )
Three plane texture storing red, green, and blue color values.

'argb' ( Four channel RGBA )
Four plane texture storing red, green, blue, and alpha color values.

'uyvy' ( YCbCr 4:2:2 video )
Four plane texture using YCbCr 4:2:2 encoding for video data.

'srgb' ( Three channel sRGB )
Three plane texture storing red, green, and blue values in the sRGB color space. The GPU automatically converts from sRGB to linear color space when the texture is sampled, enabling correct gamma-aware rendering.

'srgba' ( Four channel sRGB with alpha )
Four plane texture storing red, green, blue, and alpha values with RGB in the sRGB color space. The GPU automatically converts RGB from sRGB to linear color space when sampled, while the alpha channel remains linear.

Possible values:

'checker'

dim [3 ints]

The texture dimensions when adapt is disabled (default = 256 256 0)

dstdimend [3 ints]

Matrix destination dimension end position. Used when submitting a subtexture via the subtex_matrix message.

dstdimstart [3 ints]

Matrix destination dimension start position. Used when submitting a subtexture via the subtex_matrix message.

erase_color [4 floats]

Capture erase color

file [symbol]

Image or file to load

filter [symbol]

Set the texture filter mode (default = linear). This controls the magnification filter used when a texture is rendered at a size larger than its native resolution. The filter determines how a texture's pixels, or texels, are interpolated to fill the larger screen space.
Possible values:

'none' ( No filtering applied (same as nearest) )
'nearest' ( Uses the color of the single nearest pixel )
'linear' ( Calculates a weighted average of the four closest texels )

flip [int]

Flip texture

level [int]

Mipmap Level

mipmap [symbol]

Enable mipmap interpolation (default = none). Mipmap interpolation is used for minification filtering (meaning the area of the fragment in texture space is larger than a texel). Using mipmap interpolation requires rectangle mode disabled.
Possible values:

'none'
'nearest'
'linear'
'bilinear'
'trilinear'

rectangle [int]

Enable texture rectangle mode (default = 1). When enabled the internal GL texture is treated as a rectangular texture, and must be referenced using sampler2DRect and sampled using texture2DRect when sampled from a GLSL shader. When disabled the texture dimensions are upsampled to the nearest power of two value, and must be referenced and sampled using sampler2D and texture2D. Certain texture attributes and GLSL effects require rectangle mode disabled.

thru [int]

Enable thru mode (default = 1). When the flag is set, texture output is sent whenever input is received.

slice [int]

3D Texture Slice

srcdimend [3 ints]

Matrix source dimension end position. Used when submitting a subtexture via the subtex_matrix message.

srcdimstart [3 ints]

Matrix source dimension start position. Used when submitting a subtexture via the subtex_matrix message.

type [symbol]

The texture data type (default = auto). When type is auto the type is set by the input texture or matrix type. If the texture is the target of a capture operation, auto defaults to char.
Possible values:

'auto' ( Adapt to input data type )
'char' ( 8bit unsigned byte )
'long' ( 32bit integer )
'half' ( 16bit float )
'float' ( 32bit float )
'float16' ( 16bit float )
'float32' ( 32bit float )

usedstdim [int]

Enable matrix destination dimension

usesrcdim [int]

Enable matrix source dimension

wrap [3 symbols]

Texture wrap mode
Possible values:

'clamp'
'repeat'
'clampedge'
'clampborder'
'mirroredrepeat'

OB3D 特性

automatic [int]

自动渲染标志（默认值 = 1）该标志置位时，关联的 jit.gl.render 对象收到 bang 消息时即进行渲染

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

name [symbol]

实例名称（默认值 = UID）
