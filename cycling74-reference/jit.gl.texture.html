jit.gl.texture

创建 OpenGL 纹理

描述

创建 OpenGL 纹理——绘制 3D 几何体时使用的图像数据缓冲区。jit.gl.texture 与 jit.matrix 类似，区别在于纹理驻留在显卡上。

讨论

该 OB3D 对象可选地接受一个参数：绘制上下文的名称。它可以是 jit.world 或 jit.pworld 对象的具名实例，也可以是 jit.gl.node 子上下文。该值也可以通过 OB3D 的 drawto 特性设置。若未给出参数，对象会被隐式加入当前补丁中找到的第一个有效绘制上下文或子上下文，或者沿补丁层级向上搜索找到的第一个有效绘制上下文或子上下文。

特性

adapt [int]

启用对输入的自适应（默认值 = 1）。启用后，纹理输出维度将与输入维度一致。

anisotropy [int]

各向异性过滤宽度（默认值 = 0）。各向异性过滤是一种高级过滤技术，它会取多个采样点并把结果混合在一起。使用各向异性需要禁用 rectangle 模式。

autoclear [int]

捕获期间自动清除纹理

autoscale [int]

自动缩放纹理坐标

autotype [symbol] 只读

返回 type 为 auto（自适应输入）时实际使用的纹理类型。

bordercolor [4 floats]

纹理边框颜色

colormode [symbol]

设置纹理的颜色格式（默认值 = auto）。colormode 决定通道数以及存储纹理数据所用的内部 GPU 格式。它还决定在着色器中取样时所用的分量重排。设为 auto 时，colormode 被强制为 4 通道 RGBA。更改 colormode 会在 GPU 上重建该纹理。
可选值：

'auto'（ 自动 colormode（rgba） ）
强制颜色模式为 4 通道 RGBA。

'alpha'（ 单通道 alpha ）
存储 alpha 取值的单通道纹理。在着色器中取样时返回 (0, 0, 0, value)——该取值只出现在 Alpha 通道中，RGB 设为零。

'depth'（ 单通道深度 ）
未使用的遗留选项。在着色器中取样时返回 (value, value, value, 1.0)——该取值被广播到 RGB，alpha 设为 1。

'intensity'（ 单通道强度 ）
存储强度取值的单通道纹理。在着色器中取样时，该取值被广播到全部四个通道 (value, value, value, value)。

'luminance'（ 单通道亮度 ）
存储亮度取值的单通道纹理。在着色器中取样时返回 (value, value, value, 1.0)——该取值被广播到 RGB，alpha 设为 1。

'lumalpha'（ 双通道亮度和 alpha ）
存储亮度和 alpha 取值的双通道纹理。在着色器中取样时返回 (lum, lum, lum, alpha)——亮度取值被广播到 RGB。

'rgb'（ 三通道 RGB ）
存储红、绿、蓝颜色取值的三通道纹理。

'argb'（ 四通道 RGBA ）
存储红、绿、蓝和 alpha 颜色取值的四通道纹理。

'uyvy'（ YCbCr 4:2:2 视频 ）
使用 YCbCr 4:2:2 编码的视频数据四通道纹理。

'srgb'（ 三通道 sRGB ）
以 sRGB 色彩空间存储红、绿、蓝取值的三通道纹理。取样该纹理时，GPU 会自动从 sRGB 转换到线性色彩空间，从而实现正确的 gamma 感知渲染。

'srgba'（ 带 alpha 的四通道 sRGB ）
存储红、绿、蓝和 alpha 取值的四通道纹理，其中 RGB 位于 sRGB 色彩空间。取样时 GPU 会自动把 RGB 从 sRGB 转换到线性色彩空间，而 Alpha 通道保持线性。

compare_func [symbol]

阴影映射比较函数
可选值：

'lequal'
'gequal'
'less'
'greater'
'equal'
'notequal'
'always'
'never'

compare_mode [symbol]

阴影映射比较模式
可选值：

'none'
'compare_r_to_texture'

defaultimage [symbol]

纹理默认图像
可选值：

'checker'
'black'
'white'

dim [3 ints]

adapt 被禁用时的纹理维度（默认值 = 256 256 0）

dstdimend [3 ints]

矩阵目标维度的结束位置。通过 subtex_matrix 消息提交子纹理时使用。

dstdimstart [3 ints]

矩阵目标维度的起始位置。通过 subtex_matrix 消息提交子纹理时使用。

erase_color [4 floats]

捕获擦除颜色

file [symbol]

要加载的图像或文件

filter [symbol]

设置纹理过滤模式（默认值 = linear）。它控制纹理以大于其原生分辨率的尺寸渲染时所用的放大过滤器。该过滤器决定纹理的像素（即 texel）如何插值以填满更大的屏幕空间。
可选值：

'none'（ 不施加过滤（与 nearest 相同） ）
'nearest'（ 使用最邻近的单个像素的颜色 ）
'linear'（ 计算最邻近四个 texel 的加权平均 ）

flip [int]

翻转纹理

level [int]

Mipmap 级别

mipmap [symbol]

启用 mipmap 插值（默认值 = none）。mipmap 插值用于缩小过滤（即片元在纹理空间中的面积大于一个 texel）。使用 mipmap 插值需要禁用 rectangle 模式。
可选值：

'none'
'nearest'
'linear'
'bilinear'
'trilinear'

rectangle [int]

启用纹理矩形模式（默认值 = 1）。启用时，内部 GL 纹理被当作矩形纹理处理，从 GLSL 着色器中取样时必须用 sampler2DRect 引用、用 texture2DRect 取样。禁用时，纹理维度会被升采样到最接近的 2 的幂数值，并且必须用 sampler2D 和 texture2D 引用和取样。某些纹理特性和 GLSL 效果要求禁用 rectangle 模式。

thru [int]

启用 thru 模式（默认值 = 1）。该标志置位时，只要收到输入就会送出纹理输出。

slice [int]

3D 纹理分片

srcdimend [3 ints]

矩阵源维度的结束位置。通过 subtex_matrix 消息提交子纹理时使用。

srcdimstart [3 ints]

矩阵源维度的起始位置。通过 subtex_matrix 消息提交子纹理时使用。

type [symbol]

纹理数据类型（默认值 = auto）。当 type 为 auto 时，类型由输入纹理或矩阵的类型设定。若该纹理是捕获操作的目标，auto 默认为 char。
可选值：

'auto'（ 自适应输入数据类型 ）
'char'（ 8 位无符号字节 ）
'long'（ 32 位整数 ）
'half'（ 16 位浮点数 ）
'float'（ 32 位浮点数 ）
'float16'（ 16 位浮点数 ）
'float32'（ 32 位浮点数 ）

usedstdim [int]

启用矩阵目标维度

usesrcdim [int]

启用矩阵源维度

wrap [3 symbols]

纹理环绕模式
可选值：

'clamp'
'repeat'
'clampedge'
'clampborder'
'mirroredrepeat'

OB3D 特性

automatic [int]

自动渲染标志（默认值 = 1）该标志置位时，关联的 jit.gl.render 对象收到 bang 消息时即进行渲染

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

layer [int]

对象层号（默认值 = 0）在自动模式下，层号决定渲染顺序（由低到高）。同一层中的对象无法保证哪个先被渲染。

name [symbol]

实例名称（默认值 = UID）
