jit.linden

Lindenmayer 字符串展开（L-system）

描述

jit.linden 对象会把传入的 1 维、单通道 char 矩阵解释为一个 Lindenmayer 系统（L-system）。

讨论

L-system 以 Aristid Lindenmayer（1925-1989）命名，它们基于一种解释型文法模型：其中定义了语法，用于把传入字符串中的单个元素替换为替换字符串。这类模型（称为产生式规则，或简称为产生式）可以依赖上下文。L-system 还支持多种分支方式（这里只支持一个维度的分支，不过分支可以嵌套）。一般来说，L-system 经过连续的产生式（或文法的世代）会变得更大（而不是更小）；对象所用 Jitter 矩阵的大小决定了字符串的最大长度，所以即使公理（起始字符串）非常小，也建议使用较大的矩阵。

jit.linden 对象把传入矩阵当作 ASCII 处理，某些取值被保留用于表示通配符（默认是 *）与分支（默认是 [ 与 ]）。它们可以通过 wildcard、leftbranch 与 rightbranch 特性设置。

ignore 与 production 特性的参数应当是 ASCII 字符的列表，例如：

ignore F C A 告诉 jit.linden 对象：在产生式匹配期间检查上下文时，忽略 ASCII 字符 F、C 与 A。

通常被忽略的符号是那些描述地理空间信息的字符（例如海龟绘图），它们不包含在产生式的文法中。

production * F * +F[F] 告诉对象：取输入矩阵中出现的每一处 ASCII 字符 F，把它替换为字符串 +F[F]。结果输出字符串会因此变长，所以以 F 为公理（作为起点）的 L-system 前四个世代会像这样：

+F[F]

++F[F][+F[F]]

+++F[F][+F[F]][++F[F][+F[F]]]

通过添加多个产生式，或把上下文匹配引入 L-system 文法，可以创建更复杂的模型。例如：

消息 production G F * +F 指示 jit.linden 对象：仅当 F 前面的字符是 G 时，才把 F 的取值替换为 +F。否则，F 只会原样回显到输出字符串中。如果你给 jit.linden 的消息是：

production G F * +F * G * G-

就定义了多条产生式。F 像上面的例子那样被替换，但字符 G 现在也会被替换为 G-。最多可以向 jit.linden 发送 50 条产生式，格式为 [left_context] [strict_predecessor] [right_context] [successor_string]。前驱符号以及左、右上下文都必须是单个字符（尽管并非所有 L-system 解释器都如此要求）。后继（即替换字符串）可以任意长。

通常，jit.linden 对象的输出随后会由一个对象来解释，该对象扫描字符串并把各个符号解读为命令。jit.turtle 对象把 L-system 解释为海龟绘图，因此 F、+ 和 - 这类字符就有了特殊含义。你可以很方便地用 jit.iter 对象（或用暂存的 jit.matrix 对象，靠 getcell 消息轮询）在 Max 中访问 Lindenmayer 字符串。然后你可以针对某些 ASCII 取值使用 select 对象，并用这些取值生成你想要的任意图形或声音数据。Jitter 发行版中名为 'Lindenmayer Examples' 的示例补丁给出了在 Max/Jitter 中用 L-system 生成 2-D 图形的示例。

关于矩阵运算符的更多内容

Jitter MOP

既然矩阵是 Jitter 的核心，大多数 Jitter 对象属于矩阵运算符这一类也就不奇怪了。每个矩阵运算符都有若干个矩阵输入和若干个矩阵输出。矩阵输入按从左到右的顺序用 "in"、"in2"、"in3" 等名称称呼，矩阵输出用 "out"、"out2"、"out3" 等名称称呼，即除最左边第一个输入和最左边第一个输出分别只叫 "in" 和 "out" 之外，其余名称都由输入/输出编号后缀而来。我们把输入或输出的名称称为 "I/O-name"。

矩阵输入和输出在内部通常各自持有保存信息的矩阵。这是必要的，因为 Jitter 是异步框架（也就是说，各个矩阵并不会同时到达所有输入）。矩阵输入和输出的若干方面可以用命令 [I/O-name] 加上下列后缀之一来设置："_dim" 设置指定 I/O 矩阵的维度，"_type" 设置指定矩阵的类型，"_planecount" 设置指定矩阵的通道数，"_name" 设置指定矩阵的名称。有一种特殊情况没有任何内部矩阵，就是第一个输入 "in"。这是因为该特殊输入实际上触发矩阵运算符的计算，所以不像其他输入那样需要缓存到计算发生为止。因此没有机制可以设置 "in" 的 dim、planecount、type 或 name。

矩阵运算符接受我们称为「matrix args」的参数，即 [planecount (int)] [ type (symbol)] [dim (int list)]。若给出了这些参数，adapt 特性会被关闭，否则会被打开。若 adapt 模式打开，则每当第一个输入收到矩阵时，就相当于把 dim、planecount 和 type 特性设置为该输入矩阵的对应值。若其他输入和输出链接到这些特性，它们所链接的特性也会随之改变。adapt 模式打开时哪些输入和输出会链接到哪些特性，请查阅「MOP」表。最左侧的输入不适用该规则，因此该行所有列都标记为 "n/a"。

jit.matrix 对象是一个具名矩阵，可用于矩阵数据的存储与取出、重采样，以及矩阵类型与 planecount 转换等操作。

MOP 参数

planecount [int] 可选

显式设置输出以及右侧各输入的通道数。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

type [symbol] 可选

显式设置输出以及右侧各输入的矩阵类型。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

dimensions [list] 可选

显式设置输出以及右侧各输入的矩阵维度。若不给出，矩阵运算符通常会自适应左侧输入矩阵的特性，特殊情况下的运算符除外。

MOP 特性

adapt [int]

矩阵自适应标志（若给出了矩阵参数则默认值为 0，否则为 1）。该标志置位时，jit.matrix 对象会自适应输入矩阵的 planecount、type 和 dimensions。

[in/out]_dim [32 ints]

矩阵数据的维度（默认值 = 1 1）

[in/out]_name [symbol]

矩阵输入或输出的名称（默认值 = UID）

[in/out]_planecount [int]

矩阵输入或输出数据的通道数。除特殊情况外，该值等于 planecount。

[in/out]_type [symbol]

输入或输出矩阵的数据类型。除特殊情况外，该值等于 type。

outputmode [int]

输出模式（默认值 = 1（计算并输出矩阵））
0 = 无输出（不计算）
1 = 计算并输出矩阵
2 = 透传输入（不计算）
3 = 透传输出（不计算）

type [int]

矩阵数据类型（默认值 = char
支持的数据类型有 char、long、float32 和 float64。

MOP 消息

等价于 outputmatrix 消息。

exportattrs

以 XML 格式导出对象当前的特性取值。若未指定文件名，会打开文件对话框让你选择文件。

getattributes

从对象的右出口送出一串列表，描述对象的特性，每条特性一行。每行的形式为 attribute attribute-name get get-value set foo set-value data-type(s) number-of-values。

getstate

从对象的右出口送出一串列表，描述对象的状态，每条特性一行。每行的形式为 attribute-name attribute-value1 attribute-value2... attribute-valueN。

importattrs

导入以 XML 格式指定的特性来设置对象的特性。若未指定文件名，会打开文件对话框让你选择文件。

参数：

  • filename [symbol]

jit_matrix

处理具名矩阵的输入。若该消息在左入口收到，通常会触发输出。若该消息在其他入口收到，数据通常会被缓存，直到左入口收到 jit_matrix 消息。

参数：

  • matrix-name [symbol]

outputmatrix

把矩阵从左出口送出。

summary

从对象最右出口送出一串列表，描述对象及其特性和消息。第一行的形式为 summary objectname object-name。第二、三行用 summary (matrixinputcount/matrixoutletcount) number-of-(inlets/outlets) 的形式给出对象的入口和出口数量。第四行用 summary matrixoutput descriptor planelink planelink-value typelink typelink-value dimlink dimlink-value types data-type(s) 的形式描述 matrixoutput。随后逐条列出对象的每个特性，每条特性一行。每行的形式为 summary attribute attribute-name attribute-value1 attribute-value2 ... attribute-valueN。

特性

boundmode [int]

产生式匹配的起始单元格（0 或 1）（默认值 = 1）
可选值：

0 = 'Start at Cell 0'
1 = 'Start at Cell 1'

ignore [128 symbols]

上下文匹配时要忽略的字符

leftbranch [int]

在 Lindenmayer 字符串中被解读为分支起点的字符值（默认值 = 91（ascii '['））

production [200 symbols]

一个按 left_context strict_predecessor right_context successor_string ... 格式给出的符号列表，用于定义该 L-system 的产生式规则（默认值 = none）

rightbranch [int]

在 Lindenmayer 字符串中被解读为分支起点的字符值（默认值 = 93（ascii ']'））

wildcard [int]

在 Lindenmayer 字符串中被解读为通配符的字符值（默认值 = 42（ascii '*'））
