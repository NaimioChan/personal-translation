Jitter FX

jit.fx.crt

CRT 监视器模拟

描述

模拟老旧 CRT 监视器的视觉特性。

特性

bypass [int] >= 9.0.0

旁路效果处理标志（默认值 = 0）。启用后，输入不经处理直接送到输出。

aberation_amount [float]

彩色通道像差效果的强度（默认值 = 0.5）。

adapt [int] : 1

使输出维度自适应输入（默认值 = 1）。启用后，输出维度将与最左侧输入的维度一致。

dim [2 ints]

输出纹理的维度。启用 adapt 时，它会自动设为最左侧的输入。启用 adapt 时，它会自动设为最左侧的输入。

filter [symbol]

过滤模式
可选值：

'none'
'nearest'
'linear'

grille_amount [float]

荫栅效果的强度（默认值 = 0.1）

grille_scale [2 floats]

荫栅模式沿各轴的比例（默认值 = 0.15 0.15）。

interference_amount [float]

水平干扰失真的强度（默认值 = 0.2）。

noise_amount [float]

添加的图像噪声量（默认值 = 0.03）。

roll_line_amount [float]

滚动线条失真的强度（默认值 = 0.3）。

roll_speed [float]

滚动线条移动的速度（默认值 = 1）。

scan_line_strength [float]

扫描行效果的强度（默认值 = 8）。

vignette_amount [float]

暗角开始可见的半径（默认值 = 0.6）。

vignette_intensity [float]

暗角效果的强度（默认值 = 0.4）。

warp_amount [float]

鱼眼（桶形）畸变量（默认值 = 0.1）。

OB3D 特性

drawto [symbol]

用于绘制的具名绘制上下文（默认值 = none）具名绘制上下文是 jit.window、jit.pwindow 或 jit.matrix 对象的具名实例，并且有 jit.gl.render 对象的一个实例与之关联。

enable [int]

启用标志（默认值 = 1）该标志置位时，绘图被启用。

通用对象框特性

下面是所有对象共有的特性列表。若要修改基于对象框的对象的这些特性，需要在特性名前面加上 sendbox 一词，或者使用对象的 Inspector。

annotation [symbol]

设置鼠标移到对象上时在 Clue 窗口中显示的文本。

background [int] : 0

把对象加入或移出补丁的背景层。background 1 把对象加入背景层，background 0 把它移出。背景层中的对象显示在默认前景层所有对象的后面。

color [4 floats]

设置对象框轮廓的颜色。

fontface [int]

设置对象使用的字形，可选项有：

plain
bold
italic
bold italic
可选值：

0 = 'regular'
1 = 'bold'
2 = 'italic'
3 = 'bold italic'

fontname [symbol]

设置对象的字体。

fontsize [float]

设置对象的字体大小（单位：磅）。
可选值：

'8'
'9'
'10'
'11'
'12'
'13'
'14'
'16'
'18'
'20'
'24'
'30'
'36'
'48'
'64'
'72'

hidden [int] : 0

切换补丁锁定后对象是否隐藏。

hint [symbol]

设置补丁锁定后鼠标移到对象上时作为弹出提示显示的文本。

ignoreclick [int] : 0

切换补丁锁定后对象是否忽略鼠标点击。

jspainterfile [symbol]

可以为界面对象指定一个包含绘制代码的 JavaScript 文件，以覆盖它的默认外观。该文件必须位于搜索路径中。

patching_rect [4 floats] : 0. 0. 100. 0.

别名：patching_position, patching_size

设置对象在补丁窗口中的位置和大小。

position [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置，大小保持不变。

presentation [int] : 0

设置对象是否属于补丁的演示模式。

presentation_rect [4 floats] : 0. 0. 0. 0.

别名：presentation_position, presentation_size

设置对象在补丁演示模式中的 x、y 位置与宽度、高度，编辑位置保持不变。

rect [4 floats] 只写

同时设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的 x、y 位置与宽度、高度。

size [2 floats] 只写

设置对象在编辑模式与演示模式（若对象属于补丁的演示模式）下的宽度和高度，位置保持不变。

textcolor [4 floats]

以 RGBA 格式设置对象文字的颜色。

textjustification [int]

设置对象文字的对齐方式。
可选值：

0 = 'left'
1 = 'center'
2 = 'right'

valuepopup [int] : 0

对于保存单个数值的对象，启用 valuepopup 后，鼠标移到对象上或用鼠标改动该值时，会在弹出提示中显示对象的当前值。

valuepopuplabel [int] : 0

设置值弹出提示中文字标签的来源。
可选值：

0 = 'None'
1 = 'Hint'
2 = 'Scripting Name'
3 = 'Parameter Long Name'
4 = 'Parameter Short Name'

varname [symbol]

设置对象的脚本名，可在 pattr、发往 thispatcher 的脚本消息以及 js 对象中用这个名字来寻址该对象。

消息

OB3D 消息

bang

等价于 draw 消息。

draw

在具名的绘制目标中绘制该对象。若支持 matrixoutput 特性且其设为 1，几何矩阵会从对象的左出口送出。

drawraw

等价于 draw，且 inherit_all 特性设为 1。

drawimmediate

等价于 draw，但忽略任何可能的渲染器设置

jit_gl_texture

把 texture-name 指定的纹理绑定到该对象。等价于把 texture 特性设为 texture-name。

参数：

  • texture-name [symbol]
