mc.apply~

把函数应用到多通道信号

描述

mc.apply~ 对象接受与 line~ 格式相同的断点函数，并把它施加到多通道信号的通道空间上。每个通道包含该函数在 X 维度上均匀划分出的一个采样点。此外，mc.apply~ 最多可存储 64 个函数，这些函数由 mc.function 编辑，你可以用信号输入调取它们并连续插值。

参数

channels [int] 可选

设置多通道信号中输出通道的数量。默认值为 1。

特性

chans [int]

设置多通道信号中输出通道的数量。当 chans 作为键入型参数设置，或在音频关闭时设置，改动会立即生效。若在音频开启时改动 chans，改动会在下次重启音频时生效。

functions [int]

设置所存储函数的数量。该特性只能作为键入型参数设置；对象创建之后无法再改动。

ramptime [float]

以毫秒为单位设置输出两次变化之间的斜坡时间。注意，用信号输入在函数之间驱动连续插值时，过大的斜坡时间取值可能导致不可预期的行为。

消息

int

左入口：设置要输出的函数号（从 0 开始）；只有在左入口未连接信号时才有效。
中间入口：设置断点函数的初始 Y 值（在时间 0 处）。不过在收到列表之前，函数不会改变。
右入口：设置将被随后从中间入口收到的断点 list 消息修改的函数号。

float

左入口：设置要输出的函数号（从 0 开始）；只有在左入口未连接信号时才有效。带小数部分的 float 会在两个函数之间插值。
中间入口：设置断点函数的初始 Y 值（在时间 0 处）。不过在收到列表之前，函数不会改变。
右入口：设置将被随后从中间入口收到的断点 list 消息修改的函数号。

list

中间入口：以 line~ 格式给出的断点列表（由 function 对象输出）为 mc.apply~ 定义了一个函数，供它施加到输出通道的空间上。该列表应由交替出现的取值、时间对组成。函数施加时，起点（在 0 处）映射到第一个输出通道，终点映射到最后一个输出通道。

signal

指定要输出的已存储函数的索引，其中 0 表示第一个函数。带小数部分的数字会在函数之间插值，因此 0.5 会位于第一个与第二个已存储函数的中点。向 mc.apply~ 的 inlet 入口送入斜坡，就能在两个函数之间连续变形。
