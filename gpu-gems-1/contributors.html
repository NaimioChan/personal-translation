非茗的翻译文档库

撰稿人

Curtis Beeson 五年多前从 SGI 转到 NVIDIA 演示团队，负责 NVIDIA 演示引擎的美术流程、对象模型和 DirectX 渲染器。他在卡内基梅隆大学读书时开始做 3D，为头戴显示器生成可回放的环境，分辨率高到足以让用户合法致盲。Curtis 专攻 NVIDIA 演示团队场景图 API 的美术流程与对象模型——同时克制住向市场部门管理的黑暗诱惑投降的冲动。

Kevin Bjorke 在开发者技术团队工作，开发和推广下一代美术工具与娱乐内容，尤其关注可编程着色硬件所固有的可能性。加入 NVIDIA 之前，他在电影、电视和游戏行业广泛工作，为 Final Fantasy: The Spirits Within 和 The Animatrix 监督开发与影像制作；在 Toy Story 和 A Bug's Life 中承担大量技术指导与布局动画工作；在几乎每一个商业平台上开发游戏；制作主题公园游乐项目；为过多的电视广告做动画；还为日间电视脱口秀节目安排档期。他读过几所大学，最终从加州艺术学院电影学院毕业。过去十年，Kevin 一直是 SIGGRAPH、GDC 及类似会议的常客演讲者。

Rod Bogart 在 Pacific Data Images 做了三年软件工程师，1995 年加入 Industrial Light & Magic（ILM）。他早期在摄像机跟踪方面的工作发表在 Graphics Gems II 上。在 ILM，Rod 开发了交互式合成工具的核心引擎，并主持了 ILM 其他图像处理和图像查看技术的大部分设计与实现。

Ian Buck 正在斯坦福大学图形实验室攻读计算机科学博士学位，研究 GPU 的通用计算模型。他的研究聚焦于图形硬件的编程语言设计，以及映射到图形硬件架构的通用计算应用。Ian 于 1999 年在普林斯顿大学获得计算机科学学士学位（B.S.E.），并获得了斯坦福工学院和 NVIDIA 的奖学金。

Michael Bunnell 毕业于南卫理公会大学，获得计算机科学和电气工程学位。他为 Macintosh、Atari ST 和 Apple IIGS 编写了 Megamax C 编译器，之后参与创办了如今名为 LynuxWorks 的公司。在做了九年实时操作系统之后，他转到 Silicon Graphics，专注于图像处理以及视频与图形软件。接着他在 Gigapixel 工作，然后去了 3dfx，现在他在 NVIDIA 工作——有趣的是，他又在做编译器了，这次是着色器编译器。

Cem Cebenoyan 是开发者技术团队的软件工程师。他平日研究图形技术，帮助游戏开发者充分发挥图形硬件的性能。他在历届游戏开发者大会上就角色动画、图形性能和非真实感渲染做过演讲。加入 NVIDIA 之前，Cem 是佐治亚理工学院图形、可视化与可用性实验室的学生/研究助理。

Joe Demers 在卡内基梅隆大学获得学士学位，在南加州大学获得硕士学位。他参与开发了 Nendo——Nichimen Graphics 出品的一个简单但强大的 3D 建模与绘画软件包——以及 NVIDIA 的众多演示，他自 1999 年起在 NVIDIA 工作。

Eugene d'Eon 最近在滑铁卢大学完成应用数学与计算机科学的学士学位。他目前住在加利福尼亚，在 NVIDIA 演示团队工作。偶尔能在深夜的办公室里看到他弹钢琴。

Sim Dietrich 管理 NVIDIA 美国开发者技术团队。Sim 为 Game Programming Gems 1 和 Game Programming Gems 2 撰写过章节，并担任 Gems 2 图形显示部分的编辑。Sim 是 CgFX 工作的关键贡献者，首次把实时着色器带入 3ds max、Maya 和 Softimage|XSI。Sim 的兴趣包括新的阴影技术，以及通过 Cg 和 CgFX 这类工作改进图形工作流。

William Donnelly 是安大略省滑铁卢大学数学与计算机科学的本科生。他曾在 Okino Computer Graphics 实习，为 NuGraf 光线追踪器编写扩展；也曾在 NVIDIA 实习，为 GeForce FX 制作实时图形演示。他八岁时发现自己搭乐高积木不是可行的职业道路，梦想就此破灭，从那以后他就注定要做计算机图形。

Randima（Randy）Fernando 从八岁起就热爱计算机图形。他在 NVIDIA 开发者技术团队工作，帮助开发者学会利用最新的 GPU 技术。Randy 拥有康奈尔大学的计算机科学学士学位和计算机图形硕士学位。他在 SIGGRAPH 发表过论文，并与 Mark Kilgard 合著了 The Cg Tutorial: The Definitive Guide to Programmable Real-Time Graphics。

Mark Finch 拥有佐治亚理工学院的物理学学士学位和北卡罗来纳大学教堂山分校的计算机科学硕士学位。他的职业图形工作始于为星球大战计划做图像处理和渲染，但很快转向游戏编程，他觉得这同样有挑战性，而且更有建设性。他目前是 Cyan Uru 项目的图形程序员。

Philipp Gerasimov 是俄罗斯的 3D 程序员和游戏设计师。他目前参与创建 RightMark 3D，这是 iXBT 的一个开源 3D 硬件基准测试。

Steve Glanville 于 1977 年在加州大学伯克利分校获得计算机科学博士学位。1978 年，他创办 Silicon Valley Software 并担任总裁 15 年，期间开发了 C 和 FORTRAN 编译器。在参加了太多届 SIGGRAPH 之后，他终于在 1995 年转向图形，开始开发 OpenGL 驱动。然而他的过去最终还是找上了他：他现在是 NVIDIA Cg 语言的主要设计者和实现者之一。

Simon Green 是 NVIDIA 开发者技术团队的工程师。Simon 在英国雷丁大学获得计算机科学学位后，在电子游戏行业工作了两年，随后移居美国，为 Silicon Graphics 工作。他在游戏开发者大会和苹果全球开发者大会上做过演讲。他的兴趣包括 OpenGL、元胞自动机、基于图像的渲染和模拟合成器。在 NVIDIA，他花时间琢磨各种新奇有趣的办法来折腾图形硬件。

在骑骆驼穿越撒哈拉和在巴西海岸闲躺之余，Juan Guardado 喜欢为电脑游戏行业贡献图形技术。他从麦吉尔大学计算机工程专业本科毕业后加入 Matrox Graphics，其工作最终促成了硬件加速置换贴图的开发。他现在在 NVIDIA 英国开发者技术团队工作。他在业界活动上做过多次演讲，包括 GDC（美国和欧洲），并在 ShaderX 和 Gamasutra 在线杂志上发表过文章。

Charles Hansen 于 1981 年在孟菲斯州立大学获得计算机科学学士学位，1987 年在犹他大学获得计算机科学博士学位。他目前是犹他大学计算机科学副教授。1989 到 1997 年，他是洛斯阿拉莫斯国家实验室高级计算实验室（ACL）的技术人员，在 ACL 组建并领导了可视化工作。1987 和 1988 年，他是法国 INRIA Rocquencourt 的 Bourse Chateaubriand 博士后研究员。他的研究兴趣包括大规模科学可视化和计算机图形。

Mark Harris 于 1998 年在圣母大学获得学士学位，2003 年在北卡罗来纳大学教堂山分校获得计算机科学博士学位。在 UNC，Mark 的研究涵盖计算机图形的多个方向，包括实时云模拟与渲染、GPU 通用计算、全局光照、非真实感渲染和虚拟环境。读研期间，Mark 曾在 Intel、iROCK Games 和 NVIDIA 短期工作。Mark 现在在 NVIDIA 英国开发者技术团队工作。

Drew Hess 是 Industrial Light & Magic 软件研发部的软件开发人员。上辈子他是 Intel 公司 IA-64 架构团队的成员。Drew 在伊利诺伊大学厄巴纳-香槟分校获得计算机工程学士学位，在斯坦福大学获得计算机科学硕士学位。

Milan Ikits 是犹他大学计算学院的博士候选人，也是科学计算与成像研究所的研究助理。他目前的研究兴趣在计算机图形、科学可视化、沉浸式环境和人机交互领域。他于 1997 年在布达佩斯技术与经济大学获得计算机科学文凭。Milan 是流行的 OpenGL Extension Wrangler 库（GLEW）的作者。

Greg James 成长在一个 3D 图形电影和电脑都敞开摆在家里、随意可用的环境中，难怪他小小年纪就迷上了图形。用体面的数学和科学来治他的尝试都失败了，但他确实在 1995 年拿到了物理学学士学位和工作室艺术辅修。幸运的是，Greg 在 NVIDIA 的开发者社区拓展项目中找到了安全的环境，在那里他帮助自己和他人应对各自的痴迷。他为许多游戏开发和贡献过视觉效果，其中包括 Morrowind 的反射水面动画、Tron 2.0 的辉光，以及一个尚未公布作品的体积半透明效果。他的成果出现在多种计算机图形和物理出版物上，他对物理与计算机图形的结合尤其兴奋。

Frank Jargstorff 是开发者技术团队的软件工程师。他开发数字内容创作工具，并帮助 DCC 公司把新技术集成到产品中。加入 NVIDIA 之前，他在 IBM、CoCreate 和 Fraunhofer Research 工作，课题从流式 3D 到大型机操作系统都有。Frank 于 1997 年在德国图宾根大学获得计算机科学学位。

Alexandre Jean Claude 目前在 Softimage 担任渲染与管线团队负责人。过去几年，他专注于游戏开发管线和硬件渲染技术。他毕业于魁北克大学蒙特利尔分校计算机科学专业。

Florian Kainz 于 1995 年加入 Industrial Light & Magic（ILM），成为研发组成员。在目前计算机图形首席工程师的职位上，他领导负责 ILM 内部计算机动画系统核心架构的团队。Kainz 参与开发了粒子、毛发和隐式曲面渲染器，以及一个构成容错分布式批处理系统基础的网络协议。Kainz 是 OpenEXR 文件格式的作者之一。加入 ILM 之前，Kainz 在德国慕尼黑的 Steiner Film 和新加坡的 Twenty-Five Frames 做软件工程师，编写图像处理和 3D 渲染软件。他于 1992 年在德国慕尼黑工业大学获得计算机科学学位。

Joe Kniss 于 1999 年在爱达荷州立大学获得学士学位，2002 年在犹他大学获得计算机科学硕士学位。他目前在犹他大学攻读计算机科学博士，是科学计算与成像研究所的成员。他的研究兴趣包括计算机图形、参与介质中的光传输、人机交互和沉浸式环境。

Simon Kozlov 于 2003 年 6 月毕业于新西伯利亚国立大学，专业是物理与计算机科学。自 2001 年起，Simon 在俄罗斯游戏开发商 SoftLab-NSK 工作。他当前的项目是卡车模拟游戏 Rig 'n' Roll。

Aaron Lefohn 是加州大学戴维斯分校计算机科学系的博士生，也是 Pixar Animation Studios 的图形软件工程师。他的研究兴趣包括用图形硬件做通用计算、真实感渲染和基于物理的动画。Aaron 于 2003 年在犹他大学获得计算机科学硕士学位，2001 年在犹他大学获得理论化学硕士学位，1997 年在惠特曼学院获得化学学士学位。Aaron 是美国国家科学基金会计算机科学研究生奖学金获得者。

Jörn Loviscach 在 1993 年获得数学物理博士学位之前，就在大众计算机杂志上发表了大量关于编程和电子音乐的文章。后来他在几家计算机杂志工作，成为德国计算机杂志 c't 的副主编。他在这个职位上待了三年，2000 年接受不来梅应用科学大学（Hochschule Bremen）的教授职位，现在在那里教授并研究计算机图形。

Stephen Marshall 曾在 Sony Pictures Imageworks 做软件工程师，目前是特效技术指导。加入 Imageworks 之前，Stephen 是 Engineering Animation 软件部和诉讼动画部的开发人员。

Chris Maughan 在图形硬件行业工作了 10 年。他的职业生涯始于为一家创业公司做视频数字化产品，随后转到 3Dlabs，与 Microsoft 合作编写了 Windows 95 上的第一个 OpenGL 设备驱动。之后 Chris 开发了公司的 DirectX 驱动，在那里待了五年才离开加入 NVIDIA。在 NVIDIA，他在开发者技术团队工作，专注于为游戏开发者提供工具和示例软件。Chris 在英格兰北部的约克家中工作，与妻子 Stacey 住在一起。他仍在琢磨自己到底做对了什么，才得到了这个姑娘、这份工作和这个地点。

David McAllister 自 2000 年起担任 NVIDIA 的计算机图形架构师。他于 2002 年在北卡罗来纳大学教堂山分校获得计算机科学博士学位，研究基于图像的渲染、反射率测量与表示以及图形硬件。1997 年夏天他在惠普参与 PixelFlow 图形超级计算机的工作。David 于 1989 到 1996 年在 Evans & Sutherland 工作，1995 年在犹他大学获得学士学位。David 住在犹他州盐湖城。

Morgan McGuire 领导布朗大学的游戏研究组。他的博士研究课题是游戏的实时全局光照模型。他拥有麻省理工学院和布朗大学的硕士学位，并且是 graphics3d.com 上开源 G3D 库的项目负责人。

Hubert Nguyen 是 NVIDIA 演示团队的软件工程师。他花时间寻找能展示 NVIDIA 最新 GPU 特性的新奇效果。他在历届游戏开发者大会上就制作 NVIDIA 演示所用的技术做过演讲。加入 NVIDIA 之前，Hubert 是 3dfx Interactive 的工程师，那是 Voodoo 显卡的创造者。在 3dfx 之前，Hubert 在 Cryo Interactive（法国巴黎）的 R&D 部门工作。Hubert 参与欧洲 demoscene 时开始开发 3D 图形程序。他拥有计算机科学学士学位。

John O'Rorke 从六岁起就开始做游戏。高中时，他放学后在惠普的固件部门工作，之后进入 DigiPen 理工学院。他目前是 Monolith Productions 的引擎架构师，参与过 Aliens vs. Predator 2、Tron 2.0、No One Lives Forever 2: A Spy in H.A.R.M.'s Way，目前正在为未来产品开发引擎技术。

Fabio Pellacini 出生于意大利，人生的前 24 年都在那里度过。这期间，他从帕尔马大学获得物理学 Laurea 学位，并在 Milestone 工作了一年，构建物理引擎。此后，他决定到美国追寻对计算机图形的兴趣，在康奈尔大学获得计算机图形博士学位，并发表了几篇论文（其中四篇幸运地被 SIGGRAPH 接收）。如今他把时间花在 Pixar Animation Studios 一间昏暗的办公室里，为工作室设计和实现下一代光照技术。

Kurt Pelzer 是 Piranha Bytes 的高级软件工程师，参与过 PC 游戏 Gothic、畅销的 Gothic II（分别在 2001 和 2002 年被评为德国「年度 RPG」）以及资料片 Gothic II: The Night of the Raven。此前，他是 Codecult 的高级程序员，基于 Codecult 的高端 3D 引擎 Codecreatures 开发了多个实时仿真和技术演示（例如为 SIEMENS AG 做的上海 TRANSRAPID 轨道仿真，以及广为人知的 Codecreatures Benchmark Pro）。他在 ShaderX 2 和 Game Programming Gems 4 上发表过文章。

Ken Perlin 是纽约大学计算机科学系教授，领导媒体研究实验室和高级技术中心。他因过程化纹理算法（广泛用于游戏和电影）获得奥斯卡奖，还获得过纽约市长科学与技术卓越奖、授予纽约大学理科杰出教师的 Sokol 奖，以及美国国家科学基金会总统青年研究员奖。Ken 在纽约大学获得计算机科学博士学位，在哈佛大学获得理论数学学士学位。他曾在 R/GA 和 Mathematical Applications Group, Inc. 领导软件开发，并参与过包括 Tron 在内的多部电影。他是纽约软件产业协会董事会成员。

Matt Pharr 是 NVIDIA 的技术人员，在 Cg 团队处理与高质量交互式图形、可编程着色和语言特性相关的问题。此前，他是开发离线渲染软件的 Exluna 的联合创始人，并研究图形硬件的高级着色算法。他曾是斯坦福大学图形实验室的博士生，研究渲染的系统问题和渲染的理论基础，就这些课题发表了一系列 SIGGRAPH 论文。他与 Greg Humphreys 合著了 Physically-Based Rendering: From Theory to Implementation 一书，该书将于 2004 年出版。

Fabio Policarpo 毕业于里约热内卢的 UFF 联邦大学，为经典和实时计算机图形撰写过书籍和应用。Fabio 与 Alan Watt 合著了 The Computer Image、3D Games Volume 1 和 3D Games Volume 2（均由 Addison-Wesley 出版）。

Tim Purcell 正在斯坦福大学完成计算机科学博士学业。他于 1998 年在犹他大学获得计算机科学学士学位，2001 年在斯坦福大学获得计算机科学硕士学位。他是美国国家科学基金会研究生研究奖学金获得者和 NVIDIA 奖学金获得者。他目前的研究兴趣包括流编程、光线追踪，以及利用 GPU 做通用计算。

Daniel Sánchez-Crespo 是西班牙和欧洲游戏研究领域的领军人物之一。他的学术生涯始于 1997 年，在西班牙巴塞罗那的加泰罗尼亚理工大学做用户界面与虚拟现实方向的研究员。到 2001 年，他在庞培法布拉大学创办了欧洲第一个电子游戏创作硕士学位，至今仍在那里任教并担任该学位的负责人。他写了三本书，最近一本是 Core Techniques and Algorithms in Game Programming，由 New Riders/Prentice-Hall 出版。他最新的冒险是 Novarama，一家着眼于面向大众的新娱乐形式的游戏开发工作室，最近被评为西班牙 2003 年第三大创新企业。

Dean Sekulic 与几位最好的朋友于 1993 年创办了 Croteam，就在他意识到做电脑游戏比玩游戏更有意思之后不久。过去几年，他专攻声音与视觉的编码。他还在 1996 年毕业于萨格勒布大学商业信息学与计算机设计专业；运气好的话，他希望在接下来的一两百年里继续做电脑游戏编程。

John Spitzer 是 NVIDIA 欧洲开发者技术总监，负责为 3D 软件开发社区监督工具、技术、美术和教学材料的开发。John 每天都与游戏开发者合作，评估他们游戏中的技术，并协助实现高级视觉效果。John 参与过多个与 3D 图形相关的行业标准委员会，包括 OpenGL 架构评审委员会（ARB），并且是 SPEC OpenGL 性能表征组织（SPECopc）的创始成员和主席。在 SPECopc 任职期间，John 定义、设计并实现了行业标准的 SPECglperf 基准测试。John 每年在许多开发者教育活动上演讲，主题从性能优化到高级着色技术。John 拥有莱斯大学的计算机科学学士和硕士学位。

Jos Stam 是 Alias Systems 的研究科学家。他拥有多伦多大学的计算机科学博士学位，对计算机图形的大多数领域都有兴趣。他是 SIGGRAPH 及其他会议的常客。他最出色的研究在基于物理的动画、渲染、纹理映射和细分曲面领域。

Marc Stevens 拥有布朗大学的计算机科学硕士学位，在图形行业有超过 12 年的经验。Marc 目前受雇于 Softimage/AVID，过去九年在软件开发部门担任过多个职位。他是 Softimage|XSI 的主要架构师之一，现在是 Softimage 研发与特别项目总监。

Thilaka Sumanaweera 从 1980 年代末起先后玩 GL 和 OpenGL，在计算机视觉、图像处理和医学成像领域开发从 2D 到 4D 的应用。他于 1992 年在斯坦福大学获得电气工程博士学位，随后加入斯坦福放射学系的放射科学实验室，做博士后和研究助理，开发 CT/MRI 图像融合和图像引导神经外科手术。他目前是 Siemens Medical Solutions USA, Inc. 超声部的研究员，拥有多项医学成像与可视化技术的专利，并在医学期刊上大量发表。

Kiril Vidimce 是 Pixar 研发（Research & Development）组的图形软件工程师，正在开发他们的下一代渲染器。此前，他被关在密西西比州立大学可视化实验室里，在 David Banks 教授的指导下做 3D 图形并发表论文。Kiril 的工作发表在 SIGGRAPH、IEEE Visualization、IEEE Computer Graphics & Applications 和 Graphics Interfaces 上。在业余时间以及论文截稿之间，他还完成了计算机科学和数学的学士学位，并在 SGI、SRI 和 Caltech 实习。他原籍马其顿首都及最大城市斯科普里，现居加利福尼亚州旧金山。
