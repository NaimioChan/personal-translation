第四部分：图像处理

大多数人想到 GPU 的能力时，关注的都是纯三维应用，可我们实际在显示器上看到的画面是二维的。可编程像素着色器为个人计算机带来了前所未有的图像处理能力，扩展了我们在二维和三维开发上的手段。

平面设计师和插画师早已在静态图像照片编辑软件中使用复杂的控制项，但这类程序一次只能处理一幅图片。最新的 GPU 能以交互速率完成这些过去很慢的操作，使我们能把复杂合成与色彩控制应用的完整能力用于静止图像与版式之外，也用于全动态视频和游戏画面。过去需要整套专用设备才能完成的复杂视频调色，如今在笔记本电脑上就能做完。

理解色彩空间是图像处理的一个方面，无论我们是把二维图像映射成新的二维图像，还是把三维场景渲染到屏幕上。同样重要的是理解：尺寸和形状各异的图像在操作过程中如何被滤波，才能得到平滑、快速的结果。GPU 能执行与基于 CPU 的图像处理工具相同的滤波算法，而且还能调用新的硬件加速方法。

在第 21 章「实时辉光」中，Greg James 与 John O'Rorke 给出了一个例子，说明如何用二维图像处理增强三维游戏体验。他们展示了通过添加辉光这类二维光照效果，少量图像处理就能彻底改变三维影像的感觉与玩法。一旦你明白这些效果是怎么做出来的，可能就再也无法忍受没有它们的 3D 影像。

在第 22 章「色彩控制」中，我把游戏中图像处理的讨论扩展到技术与艺术性色彩控制的用途和方法，包括把动态影像送入和送出非常规色彩空间，以及快速为任何场景（二维或三维）加上精细的调色。如今我们在印刷品和电视上看到的颜色几乎全都经过色彩控制。开发者应当能够理解并在自己的游戏引擎中使用同样的工具。

在第 23 章「景深：技术综述」中，Joe Demers 讲述了如何用 GPU 操作实时生成景深效果。遵循几条简单的滤波规则，开发者就能在三维模型上模拟真实相机对焦、胶片饱和等复杂效果。

第 24 章「高质量滤波」把图像滤波与效果推广到任意尺寸的图像，将滤波核与解析计算的概念应用于二维和三维抗锯齿问题。值得注意的是，我们看到一些「经典」的抗锯齿和滤波问题，在 GPU 上恰恰最适合用 CPU 方案通常无法获得的硬件加速来解决。

Matt Pharr 在第 25 章「用纹理贴图快速估计滤波宽度」中描述了一种二维空间纹理化的不寻常应用。通过巧妙地处理纹理运算的结果，他能求出复杂函数的局部偏导数，即使所用的硬件配置并不直接支持这些运算。

在第 26 章「OpenEXR 图像文件格式」中，Florian Kainz、Rod Bogart 与 Drew Hess 这些 Industrial Light & Magic（ILM）的人介绍了 OpenEXR 标准——一种正在迅速普及到电影计算机影像顶尖层次的新型高动态范围图像格式。对想要开拓基于图像的光照新天地的开发者来说，OpenEXR 是关键工具；ILM 团队展示了他们如何利用 GPU 的处理速度，让 OpenEXR 成为 ILM 日常可用的工具——不只用于三维工作，也用于图像采集、合成与回放——同样是实时的。

当然，要应用这些技术，开发者必须管理图像处理任务。在第 27 章「图像处理框架」中，Frank Jargstorff 提出了一个灵活、适用于多种应用的二维图像处理方案。这个框架甚至可以扩展为混合 GPU 与 CPU 操作，而对游戏、照片应用和视频应用的开发者来说都相当透明。
