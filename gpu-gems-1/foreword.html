序

现在是在计算机图形领域工作的绝佳时机。过去五年，GPU 技术以惊人的方式和爆发式的速度向前推进。这五年里，以每秒像素数衡量的渲染速率大约每六个月翻一番。两倍固然足够让人兴奋，但更令人兴奋的是复利式的奇迹。五年意味着性能翻倍十次——也就是 2 的 10 次方，一千倍！

不仅性能提升了，在同一时期，计算质量和图形编程的灵活性也在稳步提高。五年前，PC 和图形工作站上装的是图形加速器，而不是图形处理器（GPU）。言下之意是，图形加速器做的就是这件事：加速图形。而且，加速器这个词暗示计算机执行的渲染操作与以前完全相同，只是更快。随着图形加速器被 GPU 取代，我们放弃了图形加速的旧概念。我们进步到图形处理，接受了处理器能够实现新的图形算法和效果这一理念。

我们已经进入可编程 GPU 的时代。此前二十年没有显著变化的图形硬件管线，被拆解为各个硬连线组件，再用可编程的并行流水线处理器重新搭建起来。在硬连线管线中，三角形顶点被变换和光照，三角形被光栅化，像素按漫反射光照、镜面反射指数、雾混合和帧缓冲混合来着色。在可编程管线中，这些操作每一个都被抽象为相应的内存访问和数学运算。程序员仍然可以编写一个与硬连线管线算出相同结果的程序（事实上，这样的程序常常是学生程序员为可编程处理器写的第一个程序！），但由此带来的机会远不止于此。

快速、可编程 GPU 的第一批效应是微妙的。借助一千倍的性能提升，以前困难的图形问题变得容易处理得多。离线渲染技术对交互式应用变得更实用。历史上，蛮力一直是流行的算法思路；仅仅把图形问题改造成能在 GPU 上运行的形式，就是蛮力的一种不加修饰的应用——它能用，但把机会留在了桌上。再往前，算法开发变得更有意思。图形程序员现在可以试验在较慢的单线程串行处理器（如 CPU）上不实用的新算法和新技术。GPU 的并行流处理特性，加上灵活性和可编程性，使新算法得以开发，也鼓励试验。任何计算量大的问题——不只是图形——只要能利用大规模并行、更大的内存带宽和几何级数的性能增长，都是 GPU 实现的好候选。作为一个行业，我们仍在学习哪些问题最能从 GPU 方案中受益。

可编程 GPU 革命的真正受益者是计算机图形算法设计者、研究者、应用开发者，最终是终端用户或消费者——玩家、电影观众等等。GPU Gems 是一本适时的书，因为 GPU 编程领域年轻而充满活力，许多开发者一次又一次地重新发明同样的技术。本卷既包含把已知技术直接应用到更适合 GPU 执行的结构上的做法，也包含此前不可能实现的创新算法和效果。

在 GPU 编程历史的这个时刻，许多问题仍未解决，许多挑战仍未应对。因此，GPU Gems 第一卷是迄今为止所开展工作的各种方法与实例的汇编，而不是一本可直接插入应用的成品效果菜谱。这本合集将让程序员从已经取得的激动人心的进展中受益，也将让明天的开发者站在巨人的肩膀上——那些 GPU 编程的先驱。接下来的创新步伐，由你来迈出！
