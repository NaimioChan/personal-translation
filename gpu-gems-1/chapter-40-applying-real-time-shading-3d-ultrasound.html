第 40 章　把实时着色用于三维超声可视化

Thilaka Sumanaweera
Siemens Medical Solutions USA, Inc.

现代可编程 GPU 的强大算力可以被有效利用来可视化三维医学数据，从而有可能更快、更有效地诊断疾病。例如，心肌功能和唇裂等胎儿异常都可以通过对超声数据做体绘制来可视化。本章介绍一种用 GPU 的顶点处理器和片元处理器对随时间变化的三维医学超声体积——也就是四维体积——做体绘制的技术。我们用三维投影纹理映射对超声数据做体绘制。文中给出使用真实胎儿超声数据的结果。

40.1 背景

体绘制是一种可视化三维体积数据集的技术，这些数据由计算机断层扫描（CT）、磁共振成像（MRI）和三维超声等医学成像技术产生。体绘制也用于石油勘探领域，对体积数据做可视化。

可视化体积数据集很有挑战性。人类虽然非常擅长观看和理解二维图像，但多数人难以想象三维体积数据集。在体积医学成像技术发明之前，平面二维 X 光片在诊断医学成像领域占统治地位。放射科医生习惯于相当熟练地观看和理解二维 X 光片。体积成像技术发明后，放射科医生需要观看的二维图像数量猛增，因为每个体积现在都包含一系列二维图像或切片。人们很快意识到需要一种更直观的方式来可视化体积数据，这促成了体绘制的发展。

自 20 世纪 80 年代末以来，CT 和 MRI 等医学成像模态一直受益于体绘制这种可视化体积数据的技术。CT 和 MRI 数据在三维笛卡尔网格中采集，如图 40-1a 所示。而超声数据更复杂，因为超声数据通常在非笛卡尔网格中采集，例如图 40-1b 所示的声学网格。因此，CT 和 MRI 的体绘制比超声数据的体绘制简单。

假设你想对自己身体某部位做一次三维超声扫描。在诊所里，超声技师先把超声换能器放在你的皮肤上。换能器本质上是一根天线，对约 1 MHz 或更高频率的声波敏感。它向体内发出人耳听不见的声脉冲，并像雷达那样接收回声。也像雷达一样，超声体积通常在随深入体内而发散的网格中采集。为了让你对超声图像的性质有个概念，图 40-2 显示了一幅胎儿二维超声图像。你可以想象该超声体积的三维版本：一个截棱锥或锥体，与图 40-1b 类似。

三维超声数据由超声扫描仪采集，并以三维数组形式存于其本地内存。这个三维数组中变化最快的索引对应离换能器的距离，称为距离（range）方向（见图 40-1b）。次快的索引对应换能器的方位角方向。最慢的索引对应换能器的仰角方向。

超声数据也可以是四维的，在三个空间方向和时间方向上采集。你可能在产科诊所见过采集胎儿面部图像的四维超声。对胎儿面部成像这类应用，每秒所需的体积数远少于对人体心脏成像这类应用所需的体积数。这是因为心脏运动很快，为了充分显示心脏运动，我们需要在每个心动周期内采集并体绘制若干个三维体积。

所幸，NVIDIA 的 GeForce FX 和 Quadro FX 等现代 GPU 中的可编程顶点与片元处理器近来提供了手段，能以可视化人体心脏所需的速率，对在非笛卡尔网格中采集的四维超声数据做体绘制。对四维超声数据做体绘制已有多种技术。本章详细介绍其中一种。

40.2 引言

三维网格数据集（如 CT、MRI 和超声数据）可以用纹理映射做体绘制。已有多种技术。综述可参见本书第 39 章「体绘制技术」以及 Hadwiger et al. 2002。本章使用三维纹理。我们先回顾如何用纹理对笛卡尔网格中的 CT、MRI 这类数据做体绘制。示例 OpenGL 程序 VolumeRenderCartesian.cpp（收在本书的 CD 和网站上）演示如何用笛卡尔网格做体绘制。这里不详述该程序，但先过一遍基本要点。

40.2.1 笛卡尔网格数据的体绘制

图 40-3 展示了用三维纹理对笛卡尔数据做体绘制的要点。数据先用 glTexImage3D 作为三维纹理载入显存。然后启用 alpha 混合，对一系列均垂直于观察方向的切平面做纹理映射，从离观察者最远的切平面开始，逐步推向离观察者最近的切平面。记住，所有切平面都平行于计算机屏幕。我们把与计算机屏幕关联的坐标系称为切平面空间。数据集可以相对计算机屏幕旋转。我们把与数据集关联的坐标系称为数据集空间。

对切平面做纹理映射时，可以用两种不同的方式指定：外包矩形和相交多边形。

外包矩形

使用外包矩形是对切平面做纹理映射最直接的方式。示例程序 VolumeRenderCartesian.cpp 采用这种技术。该方法从后到前绘制一系列外包数据集范围的四边形。可以把四边形顶点的坐标存入显存，以便快速访问、快速渲染。唯一要记住的是，必须启用两种方式之一来抑制对原始数据体积之外区域做纹理映射（即任一纹理坐标 (s, t, r) 小于 0.0 或大于 1.0 时）。有三种做法：（a）使用裁剪平面；（b）用 GL_CLAMP_TO_BORDER_ARB 环绕纹理坐标，并把边框颜色设为黑色；（c）用 GL_CLAMP_TO_EDGE 环绕纹理坐标，并让边界处的数据值为 0，如下所示：

相交多边形

这种方法稍复杂，需要求出给定切平面与数据立方体相交的多边形。可以让 CPU 或 GPU（用顶点程序）来算。求出相交多边形的顶点后，就可以对该多边形做纹理映射。从片元程序的角度看，这种做法更快，因为只访问数据立方体内部的片元。不过从光栅化器的角度看，要求更高，因为需要光栅化更多三角形。此外，每当观察者相对数据集空间改变观察方向，程序都要重新计算多边形。若用 CPU 重新计算多边形，还需要在渲染前把多边形顶点上传到 GPU，这可能很耗时。

示例程序 VolumeRenderCartesian.cpp 用外包矩形配合裁剪平面来渲染切平面。图 40-4 显示了 VolumeRenderCartesian.cpp 程序生成的一幅 CT 数据集体绘制图像。运行该程序时，你可以旋转、缩放并逐层浏览体积。把键盘焦点放在图形窗口上时按「h」键可查看帮助。该可视化所用的数据集为 256x256x256 体素。

40.2.2 金字塔网格数据的体绘制

下面考察在金字塔网格中采集的数据的体绘制。有好几种网格具有随深入体内而发散的性质，包括金字塔网格、圆锥网格、球面网格和圆柱网格。为简单起见，本章使用金字塔网格，因为正如后文所见，它适合 GPU 擅长的那类线性处理。此外，图 40-1b 和图 40-2 所示的其他类型网格，也可以沿距离方向重采样超声数据后变换为金字塔网格，而不失一般性。

为便于解释，先看两个二维情形：（a）笛卡尔网格和（b）金字塔网格，如图 40-5 所示。对每个二维网格，我们在每个网格点采集一个超声数据样本，构成二维数据数组。一般超声图像的网格点要多得多，这里只看 5x5 的网格。图 40-5a 所示的笛卡尔网格中，对应常数 s 的竖线称为超声线。换能器位于 r = 0.0 平面上。超声扫描仪从左到右依次发射每条超声线，并在每个网格点采样，从而收集一幅二维图像。纹理坐标 (s, r) 对应换能器的方位角方向和距离方向。

图 40-5b 所示的金字塔网格中，所有超声线交于一点 O，称为顶点。换能器的范围 AB 称为孔径尺寸。本章使用归一化孔径尺寸的概念：a = AB/R，其中 R 是金字塔的高（0 ≤ R ≤ 1.0）。角 AOB 称为顶角，记为 2q。可以把金字塔网格看作与笛卡尔网格等价，只是 s 坐标随 r 坐标线性缩放。这可以借助投影纹理映射轻松实现，后文会讨论。

切平面如前所述用一系列外包矩形指定。这些矩形的尺寸选择为完全包住金字塔网格。示例 OpenGL 程序 VolumeRenderPyramid.cpp、顶点程序 VolumeRenderPyramidV.cg 和片元程序 VolumeRenderPyramidF.cg 用与前面 VolumeRenderCartesian.cpp 相同的 CT 数据集演示我们的算法。此外还有该片元程序的汇编版本 VolumeRenderPyramidF.ocg。下面我们来考察顶点程序和片元程序。

顶点程序

下面逐行讲解代码清单 40-1 所示的顶点程序。该顶点程序的输入是变量 Position，含顶点坐标。十个 uniform 变量——ZoomFactor、Pyramid、ClipPlane0-5、ModelView 和 ModelViewProj——也是该程序的输入。ZoomFactor 含用于缩放的缩放值。Pyramid 含描述金字塔网格几何的两个参数：Pyramid.x 是换能器的归一化孔径尺寸 a，Pyramid.y 是顶角一半的正切的两倍，即 2 tan 。ClipPlane0 到 ClipPlane5 含六个裁剪平面的方程。ModelView 和 ModelViewProj 分别含数据集空间中的模型视图矩阵，以及模型视图矩阵与切平面空间投影矩阵相乘后的结果。

示例 40-1. VolumeRenderPyramidV.cg

void VertexProgram(in float4 Position
                   : POSITION, out float4 hPosition
                   : POSITION, out float4 hTex0
                   : TEX0, out float hClip0
                   : CLP0, out float hClip1
                   : CLP1, out float hClip2
                   : CLP2, out float hClip3
                   : CLP3, out float hClip4
                   : CLP4, out float hClip5
                   : CLP5, uniform float4 ZoomFactor, uniform float4 Pyramid,
                     uniform float4 ClipPlane0, uniform float4 ClipPlane1,
                     uniform float4 ClipPlane2, uniform float4 ClipPlane3,
                     uniform float4 ClipPlane4, uniform float4 ClipPlane5,
                     uniform float4x4 ModelView, uniform float4x4 ModelViewProj)
{
  // 计算裁剪空间位置
  hPosition = mul(ModelViewProj, Position);
  // 从位置坐标中除去缩放因子
  Position = Position * ZoomFactor;
  // 用笛卡尔网格计算纹理坐标
  hTex0 = mul(ModelView, Position);
  // 保存原始纹理坐标
  float4 hTex0_Orig = hTex0 - float4(0.5, 0.5, 0.0, 0.0);
  // 计算金字塔网格中纹理坐标的
  // 缩放系数
  hTex0.w = Pyramid.x + hTex0.z * Pyramid.y;
  // 针对纹理坐标的偏移做调整
  hTex0.x = hTex0.x - 0.5 + 0.5 * hTex0.w;
  hTex0.y = hTex0.y - 0.5 + 0.5 * hTex0.w;
  // 裁剪金字塔体积
  hClip0 = dot(hTex0_Orig, ClipPlane0);
  hClip1 = dot(hTex0_Orig, ClipPlane1);
  hClip2 = dot(hTex0_Orig, ClipPlane2);
  hClip3 = dot(hTex0_Orig, ClipPlane3);
  hClip4 = dot(hTex0_Orig, ClipPlane4);
  hClip5 = dot(hTex0_Orig, ClipPlane5);
}

该顶点程序的输出是顶点的裁剪空间位置 hPosition、纹理坐标 hTex0，以及裁剪距离 CLP0 到 CLP5。

第一行计算顶点的裁剪空间位置；第二行去掉 OpenGL 程序对位置坐标施加的任何缩放；第三行模仿 OpenGL 的 glTexGen 函数，计算笛卡尔坐标系的纹理坐标。第 4 行把纹理坐标的原始内容（仅在 s 和 t 方向偏移 0.5）存入 hTex0_Orig 备用。接下来是有意思的部分。第 5 行计算对给定 r 坐标时 s 和 t 纹理坐标所需的拉伸或缩放量。第 6、7 行平移 s 和 t 纹理坐标的原点，使片元程序中对 s、t 纹理坐标的缩放围绕金字塔的中心轴进行。第 8–13 行计算包围金字塔体积的六个平面的裁剪值。含小于零裁剪值的片元不会被绘制到帧缓冲。

片元程序

代码清单 40-2 的片元程序接着顶点程序的工作往下做。输入 inTex 是含纹理坐标的变量。还有两个 uniform 输入：USTexture 和 ColorMap。USTexture 含描述三维超声体积的三维纹理。ColorMap 是颜色映射表，含不透明度加权传递函数和不透明度函数。输出 sColor0 含片元颜色。

第一行把 r 坐标与缩放值预乘；第二行用投影纹理映射在三维超声体积中查找纹理值；第三行做一维颜色映射查找，按超声数据值生成渲染用的颜色。

示例 40-2. VolumeRenderPyramidF.cg

void FragmentProgram(in float4 inTex
                     : TEXCOORD0, out float4 sColor0
                     : COLOR0, const uniform sampler3D USTexture,
                       const uniform sampler1D ColorMap)
{
  // 将 'r' 坐标预乘该缩放系数
  inTex.z = inTex.z * inTex.w;
  // 投影式 3D 纹理查找
  float val = tex3Dproj(USTexture, inTex);
  // 颜色表查找
  sColor0 = tex1D(ColorMap, val);
}

40.4 结论

GPU 已经发展到可以对三维超声成像所需的快速速率做体绘制的地步。我们描述了如何用投影纹理映射对金字塔网格做到这一点。以此为框架，还可以纳入着色模型，并用预积分体绘制（Engel et al. 2001）等技术减少摩尔纹瑕疵，代价是损失一些帧率。

注意，公式 6 和公式 7 可以直接在片元程序中实现，而不使用投影纹理映射。这种做法比本章采用的做法慢。这是因为典型的体绘制应用受填充率限制，而实现公式 6 和公式 7 需要求 r 的倒数，这会增加语句，因而运行更慢。

还要注意，我们本可以把传递函数而非不透明度加权传递函数提供给片元程序，并在片元程序内把不透明度值与颜色 sColor0 相乘来生成不透明度加权颜色。这样做可以减少量化瑕疵，代价是帧率，因为需要多加一条语句。
