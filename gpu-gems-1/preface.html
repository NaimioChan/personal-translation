非茗的翻译文档库

前言

本书是一本内容广博、注重实用的实时计算机图形文集，汇聚了工业界与学术界专家的知识与经验。GPU Gems 沿用已有的优秀「Gems」系列图书的风格，采用短章文集的形式。不过，它有几项关键特点，使其对当今试图驾驭图形处理器（GPU）日益增长能力的开发者而言独特而有价值。

首先，本书紧扣实时可编程图形，特别是与 GPU 相关的技术。每一章都经过仔细挑选，给出对计算机游戏等交互式应用直接有用的思路与技术。各章重在提供洞见与理解，而不是专注于底层 API 调用或特定的数学技巧。此外，每章都配有大量彩色插图和图像，用以说明并强调关键概念。最后，撰稿人的经验与多样性帮助读者获得宽广的理解，也让他们有信心：这些建议来自本领域的专家。

NVIDIA 最宝贵的资产是人：他们集体专业能力的深度与质量催生了 GPU Gems 最初的构想。手边有如此丰富的知识与专长，我们觉得，那些带来近期实时图形诸多进展的团队的思考与洞见，足以成就一本极有教益的书。于是我们以内部征集的方式启动了项目。

我们有幸与来自领先游戏开发公司、工具开发商、电影制片厂和学术机构的人共事，他们正在塑造实时计算机图形的未来，我们也希望突出他们在 GPU Gems 中的实际贡献。因此，一次范围更广的公开征集让我们把大量才华与清新的视角汇聚到本卷中。

无论你是在制作新效果、设计图形引擎架构，还是在榨取最后一点性能，我们都希望本书能提供有价值的指引，让你少走作者们在自己项目中走过的弯路。参与 GPU Gems 的所有人都希望它能帮助你采纳新思路，把项目带向更高的图形真实感水平。

目标读者

本书为中级和高级读者提供对其项目有帮助的实用信息。GPU Gems 不停留在高级着色的基础知识，而是探讨如何通过揭开复杂效果与高级 GPU 编程的神秘面纱，把现有项目推得更远。随着实时着色语言的快速演进，实时图形开发者可用的算法比以往任何时候都多。通过汇总并传播本书中的信息，我们的目标是让高质量、高性能的图形更容易为更广的读者所掌握，包括游戏开发者、技术总监、教授和学生。

试用示例

本书许多章节都附有代码示例，让内容更具体。作者们可自由选用着色语言，因此代码示例分别使用 DirectX 9 的高级着色语言（HLSL）或 Cg——在本项目进行期间，这是广泛使用的仅有的两种高级着色语言。书中几乎所有内容都可以套用到这两种语言，也可以套用到后来出现的语言，例如 OpenGL 着色语言。代码示例随书附带的 CD 提供，并尽可能附有独立可运行的示例，方便你整合或试验各种示例。更新的示例代码以及其他补充材料可在本书网站获取：http://developer.nvidia.com/GPUGems/ 。
