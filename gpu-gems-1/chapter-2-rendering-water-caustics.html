第 2 章　水面焦散的渲染

2.1 引言

水与光相互作用的方式有种催眠般的魔力：微妙的反折射，光弯折后在海底形成摇曳焦散的样子，以及海面无穷变化的外观。见图 2-1。这些现象及其复杂性吸引了物理学界的许多研究者，近年来也吸引了计算机图形学界的。模拟和渲染逼真的水，和模拟火焰一样，是一项迷人的任务。要在交互帧率下取得好效果并不容易，因此常常必须采取有创意的做法。

光线从曲面反射或折射，因而只聚焦在接收面的某些区域，就形成焦散。本章讲解一种由美学驱动、实时渲染水下焦散的方法。我们这种纯美学驱动的方法干脆不考虑真实感。结果是一个好看的场景，但可能没有正确模拟该环境的物理。正如本章所展示的，我们方法的结果看起来相当逼真，而且该方法在大多数图形硬件上都容易实现。这种简化的做法在许多与分形相关的学科中被证明非常成功，例如山脉和云的渲染或树木建模。

本章的目的是介绍一种实时渲染焦散的新技术，从物理基础讲到实现细节。因为该技术是过程化的，它非常适合用高级着色语言实现。

2.2 计算焦散

精确计算水下焦散是一个复杂的过程：涉及数以百万计的单个光子，发生大量相互作用。要正确模拟，我们必须从光源（例如海面场景中的太阳）发射光子开始。这些光子中有一部分最终撞上海面，被反射或折射。先撇开反射不谈，看看透射的光子如何按斯涅尔定律折射，该定律指出：

光子一旦弯折，就在水中前进，强度随深度增加而衰减。最终，其中一些光子会击中海底，把它照亮。由于海面起伏，从不同路径进入水中的光子可能照亮海底的同一区域。每当这种情况发生，我们就看到一个由光聚集在焦散中形成的亮斑，类似于透镜聚焦光线的方式。

从仿真的角度看，焦散通常用正向或反向光线追踪来计算。在正向光线追踪中，光子从光源发出，在场景中被跟踪，其贡献在底面的离散区域上累加。这种做法的毛病在于，许多光子根本不会撞上海面，而真正撞上的那些里，极少真正对焦散的形成有贡献。因此这是蛮力方法，即使借助空间细分做了一些加速也是如此。

反向光线追踪的方向相反。它从海底出发，按时间倒序反向追踪光线，试图计算给定点上所有入射光照之和。理想情况下，这可以通过求解该点上方所有来光的半球积分来实现。但出于实际考虑，积分结果要靠蒙特卡洛采样来求解。于是，以采样点为中心，向半球各个方向发出一束候选光线。击中其他物体（如鲸、船或石头）的射线被丢弃。反之，击中海面的射线肯定来自外部，因此是好的候选。于是它们必须用斯涅尔定律的逆形式折射。这些剩下的射线必须在空气中传播，以检验每条假设的射线究竟真的来自光源，还是仅仅是一个错误的假设。同样，只有真正击中光源的射线对焦散有贡献，其余射线都作为错误假设被丢弃。

因此两种方法代价都很高：只有极小一部分计算时间真正对最终结果有贡献。在商业焦散处理器中，有用射线与总射线之比通常在 1% 到 5% 之间。

实时焦散最早由 Jos Stam 探索（Stam 1996）。Stam 的方法是用波动理论计算一张动态的焦散纹理，从而可以用它照亮底面。这张纹理与物体的基础纹理做相加混合，给出漂亮而有说服力的外观，如图 2-3 所示。

Lasse Staff Jensen 和 Robert Golias 在他们出色的 Gamasutra 论文中探索了另一种有意思的方法（Jensen and Golias 2001）。该论文不仅涵盖焦散，还给出完整的水面动画与渲染框架。平台基于快速傅里叶变换（FFT）做波函数建模。在此基础上，他们的方法处理反射、折射和焦散，力求每一项都达到物理准确的模型。因此，Jensen 和 Golias 处理焦散的办法试图模拟真实过程，也就不足为奇了：从太阳向波浪网格的每个顶点追踪射线，这些射线按斯涅尔定律折射，从而产生新的射线。

2.3 我们的方法

我们用来模拟水下焦散的算法，只是上一节所述反向蒙特卡洛光线追踪思路的简化。我们对焦散的合适候选作了一些激进的假设，只计算到达射线的一个子集。因此该方法计算代价很低，产生的东西虽然在物理上「不正确」，却在观感和行为上与真实焦散非常相似。整体效果看起来很有说服力，而焦散带来的出色画质让实现它是值得的。

首先，我们假定是在赤道正午计算焦散。这意味着太阳正在我们正上方。为了算法的需要，我们要算出太阳圆盘在天空中所占的角度。太阳距地球 1.47 亿到 1.52 亿公里，具体取决于一年中的时节；其直径为 142 万公里，因此太阳圆盘的角度为 0.53 度，如图 2-4 所示。

我们作的第二个假设是：海底由从所关注点正上方竖直射来的光线照亮。水的透明度为每直线米 77% 到 80%，因此每米有 20% 到 23% 的入射光被介质吸收，用于加热水体。从逻辑上说，这意味着当光线从进入水中到击中海底所走的距离最短时，最容易形成焦散。因此焦散对垂直射线最强，对侧向进入水中的射线则不那么明显。这是一个激进的假设，但它是算法成功的关键。

于是我们的算法如下。我们从海底开始，就在画完底面之后。然后用第二遍相加混合渲染，把焦散叠加在上面。为此，我们建一个与波浪网格粒度相同的网格，按顶点用焦散值着色：0 表示没有光照，1 表示一束高度聚焦的光击中了海底。为了构建这个光照，我们使用反向光线追踪：对网格的每个顶点，把它垂直投影，直到抵达正上方的那一点波面。然后用有限差分计算该点处波浪的法线。有了这个向量和法线，再用斯涅尔定律（水的折射率为 1.33），我们可以生成次级射线，从波面射入空中。这些射线是把光照带到海底的潜在候选。为检验它们，我们计算每条射线与竖直方向的夹角。因为太阳圆盘非常遥远，我们可以直接用这个夹角作为光照的度量：越接近竖直，从该方向进入海洋的光就越多，如图 2-5 所示。

2.4 用 OpenGL 实现

该算法最初的实现就是普通的 OpenGL 代码，唯一的例外是使用了多遍纹理。第一遍把海底作为常规的带纹理四边形渲染。然后，用一张精细网格再次绘制同一底面，该网格用我们的焦散生成器逐顶点照亮，如图 2-6b 所示。对精细网格的每个顶点，我们竖直发射一条射线，让它与海面相交，用斯涅尔定律生成弯折后的射线，再用该射线做射线-四边形测试，以索引纹理图，如图 2-6a 所示。最终，这个操作与一遍平面环境映射并没有很大不同。第三遍也是最后一遍，用我们的波形生成器渲染海浪。这些三角形会用平面环境贴图贴图，从而在它们上面得到漂亮的天空反射。其他效果，例如菲涅尔方程，可以在此之上实现。

该技术的伪代码如下：

  1. 绘制海底。
  2. 对细网格中的每个顶点：
    1. 发射一条竖直射线。
    2. 让射线与海洋网格相交。
    3. 用斯涅尔定律的逆形式计算折射射线。
    4. 用折射射线计算「太阳」贴图的纹理坐标。
    5. 把纹理坐标应用到更精细网格的顶点上。
  3. 渲染海面。

2.5 用高级着色语言实现

完全在 GPU 上实现这项技术，可以获得更好的画质并提升性能。像 Microsoft 的 HLSL 或 NVIDIA 的 Cg 这样的高级着色语言，让我们可以用类 C 语法迅速把这些计算搬到 GPU 上。事实上，之前在基础 OpenGL 实现中于 CPU 上执行的同一个波函数，只是通过一个 include 文件被直接复制进像素和顶点着色器，仅做了少量修改以适应这些高级语言中基于向量的结构。

逐像素而非逐顶点计算焦散，提升了整体画质，并使效果与几何复杂度解耦。把该技术移植到 GPU 像素着色器时考虑过两种做法，两者都用波函数的偏导数生成法线，而不像原始方法那样依赖有限差分。

第一种方法利用了这样一个事实：过程化纹理可以在屏幕空间渲染，从而在只有一小部分像素可见时节省渲染时间。不幸的是，这也意味着当大量像素可见时，每个像素都要做大量工作，即便增加的细节可能并不明显。有时这么大的工作量会把帧率拖慢到不可接受的程度，所以需要另一种方法来克服这个限制。

第二种方法在纹理空间中渲染到固定分辨率的渲染目标。虽然在纹理空间中渲染有每帧保持恒定工作量的优点，但只渲染可见像素的好处就失去了。此外，也很难判断哪种渲染目标分辨率最适合当前场景，以至于当纹素与像素之比降得太低时，依赖纹理滤波可能会引入泄露真相的双线性滤波十字图案。

我们可以进一步优化算法，注意到用斯涅尔定律折射入射光线，与直接按沿波面法线从水面到底面的距离做环境映射，在视觉上差别很小。见图 2-7。结果是，竖直射线访问纹理中心，那里很亮；斜射的射线则产生逐渐衰减的光源。此外，在更大的深度处，环境贴图的相对尺寸——因而光源的相对尺寸——会缩小，产生更锐利的焦散，而焦散同样可以按距离衰减。注意，这种方法允许我们使用非均匀的底面，而这个可变的深度可以很容易地编码进顶点属性的一个标量分量。

示例 2-1. 波函数、波函数梯度与直线-平面截距方程的代码示例

// 焦散
// Copyright (c) NVIDIA Corporation. All rights reserved.
//
// 注意：
// 本着色器基于 Daniel Sanchez-Crespo（西班牙巴塞罗那
// Pompeu Fabra 大学）的原创工作。
#define VTXSIZE 0.01f
// 振幅
#define WAVESIZE 10.0f
// 频率
#define FACTOR 1.0f
#define SPEED 2.0f
#define OCTAVES 5
// 顶点引擎里使用的同一个波函数示例
float wave(float x, float y, float timer)
{
  float z = 0.0f;
  float octaves = OCTAVES;
  float factor = FACTOR;
  float d = sqrt(x * x + y * y);
  do
  {
    z -= factor * cos(timer * SPEED + (1 / factor) * x * y * WAVESIZE);
    factor = factor / 2;
    octaves--;
  } while (octaves > 0);
  return 2 * VTXSIZE * d * z;
} // 这是上面那个波函数的导数。
// 它返回 d(wave)/dx 与 d(wave)/dy 两个偏导数。
float2 gradwave(float x, float y, float timer)
{
  float dZx = 0.0f;
  float dZy = 0.0f;
  float octaves = OCTAVES;
  float factor = FACTOR;
  float d = sqrt(x * x + y * y);
  do
  {
    dZx +=
        d * sin(timer * SPEED + (1 / factor) * x * y * WAVESIZE) * y *
            WAVESIZE -
        factor * cos(timer * SPEED + (1 / factor) * x * y * WAVESIZE) * x / d;
    dZy +=
        d * sin(timer * SPEED + (1 / factor) * x * y * WAVESIZE) * x *
            WAVESIZE -
        factor * cos(timer * SPEED + (1 / factor) * x * y * WAVESIZE) * y / d;
    factor = factor / 2;
    octaves--;
  } while (octaves > 0);
  return float2(2 * VTXSIZE * dZx, 2 * VTXSIZE * dZy);
}
float3 line_plane_intercept(float3 lineP, float3 lineN, float3 planeN,
                            float planeD)
{
  // 未优化
  float distance = (planeD - dot(planeN, lineP)) / dot(lineN, planeN);
  // 优化版（假定 planeN 始终朝上）
  float distance = (planeD - lineP.z) / lineN.z;
  return lineP + lineN * distance;
}

算出截点之后，我们可以用它通过依赖纹理读取来取焦散光照图，然后把焦散贡献加到地面纹理上，如代码清单 2-2 所示。

示例 2-2. 最终渲染遍的代码示例，展示依赖纹理读取操作

float4 main(VS_OUTPUT vert, uniform sampler2D LightMap
            : register(s0), uniform sampler2D GroundMap
            : register(s1), uniform float Timer)
    : COLOR
{
  // 由波函数的梯度生成法线（直线方向），
  // 并与水面求交。
  // 我们用屏幕空间 z 来衰减该效果，以避免走样。
  float2 dxdy = gradwave(vert.Position.x, vert.Position.y, Timer);
  float3 intercept = line_plane_intercept(
      vert.Position.xyz, float3(dxdy, saturate(vert.Position.w)),
      float3(0, 0, 1), -0.8);
  // 输出
  float4 colour;
  colour.rgb = (float3)tex2D(LightMap, intercept.xy * 0.8);
  colour.rgb += (float3)tex2D(GroundMap, vert.uv);
  colour.a = 1;
  return colour;
}

2.6 结论

本章描述的效果展示了如何升级并增强一个经典算法，以利用基于着色器的技术。随着着色处理能力提升，完整的蒙特卡洛方法最终会完全在图形硬件上运行，计算物理正确的焦散将成为现实。

要获得完整且赏心悦目的水下渲染模型，另一个值得研究的效果是曙暮光条。这个效果也称为体积光，看起来像可见的光束，由水下粒子的反射造成。
