第 31 章　使用 FX Composer

Christopher Maughan
NVIDIA

本章对 FX Composer 作基本介绍。FX Composer 收录在本书附带的 CD 中（也可在本书网站上找到）。FX Composer 让你用 .fx 文件创建高级着色效果；.fx 文件是对 Direct3D 图形 API 状态的文本描述，任何使用 D3DX 效果框架的 Direct3D 应用都能载入它。效果文件包含渲染状态、纹理状态、顶点和像素着色器以及参数。FX Composer 可用于创建这些文件，并把它们显示在导入的模型上。我们还提供了其他工具，让基于 .fx 文件的开发尽可能高效。

31.1 入门

我们建议安装 DirectX 9 的「2003 夏季更新」版本，以便随附的所有 .fx 文件都能运行。FX Composer 安装程序会装好其他所需的一切，其中包括许多示例媒体文件，它们位于 FX Composer 主安装目录下的「MEDIA」目录中。为获得最佳效果，请使用支持 DirectX 9 的较新显卡。图 31-1 显示 FX Composer 运行时的情形，其中载入了一个模型并应用了材质。

FX Composer 从底层开始就是为做成一个有用的着色器开发工具而设计的。它的设计尽可能灵活，同时提供若干高级特性来提升效率。你可以用 FX Composer 查看着色器示例与工程，开发自己的 .fx 文件集合，或者借助先进的芯片性能剖析功能来分析与改进着色器库的性能。我们希望 FX Composer 会成为你工具链中有价值的一环，也一直努力让这个应用尽可能可扩展，以契合你的需要。如果你要做的不仅仅是创建着色器，如果你对几何数据有特殊需求，或者你想用 FX Composer 导入自己应用的数据格式，这都不成问题。我们打算提供完整的 SDK，让插件能完全访问 FX Composer 引擎的所有功能。事实上，FX Composer 的许多功能本身就是插件，例如场景导入器。

下面简要概述 FX Composer 1 版的 IDE。我们逐个介绍各个组件，以模块化的方式引出程序的全部特性。这类概述能帮助你在上手用 FX Composer 构建效果之前，先对每个组件的能力有所体会。本章末尾我们会载入一个简单工程，展示各部分如何配合起来。此外，FX Composer 还附带一份完整的用户指南，可获取更深入的使用说明。

31.1.1 材质面板

在这里可以载入 .fx 文件，并在把它们应用到场景各部分之前先行预览。事实上，你可能想把图 31-2 所示的材质面板当作那个着色器开发窗口：它能改变材质尺寸，是查看效果而不必直接把效果应用到场景的快捷方式。因此，材质面板实际上就是一个材质调色板。每个材质代表效果文件的一个实例，带有一组独有的参数。多个材质可以引用同一个 .fx 文件，但参数各不相同；这样你就能载入同一类型的多个材质，再分别调整它们的颜色和纹理，以匹配场景中的模型。

最初材质面板里只有一个简单材质：一个基本光照示例。注意你可以选中该材质、旋转它、改变它的尺寸等等。每个材质实际上都是一个微型的 3D 视图，能让人体会效果在真实情境中的样子。起初这看起来可能有点不寻常，因为许多 CAD 应用只显示静态的 2D 材质；但效果往往依赖光照变化和凹凸贴图，所以我们的 3D 版本让查看材质容易得多。

要为材质对象选择不同的预览形状，右键点击材质，在弹出菜单中选择 Objects。目前可以创建茶壶、球体、立方体等对象。任何人都能编写形状插件，FX Composer 引擎在这里支持任意类型的几何体。删除材质和新建材质都很容易；新建材质之后，可以在属性面板中更改它指定的效果文件。不过更快的方式是用 File...Open Material 直接从 .fx 文件载入材质。

有些材质可能以红色线框或蓝色线框显示。这些是特殊的显示模式：红色表示效果文件无效，蓝色表示效果无法在图形设备上运行。有了这些显示模式，就可以方便地点击有问题的材质，把它调到编辑器中修复。

选中材质时，材质面板中它的预览周围会出现红色轮廓。选中当前场景的一部分时，与该部分关联的所有材质周围会出现蓝色轮廓。这样就能方便地从场景中的对象找到面板里的材质。

31.1.2 场景图面板

图 31-3 所示的场景图面板以树状形式提供对当前场景的访问。在这里可以看到场景中有哪些对象、查看它们的属性并选中它们。FX Composer 中的大多数对象都能从场景图面板中选中，这往往是复杂场景里查找对象的有用手段。配合属性面板，你可以操控场景中的任何对象。例如，在图 31-3 的场景图面板所表示的场景里，有一个默认聚光灯。沿场景图树向下导航，找到该光源对象，然后右键点击它并选择 Properties 来更改其属性。属性面板此时会显示该光源的信息，你可以改变光源颜色或它的其他任何参数。

图 31-3 还显示了几个 GeoPipe 对象。GeoPipe 是 FX Composer 中承载几何体的节点。从图中展开的 GeoPipe 可以看出，它包含为这个节点构建几何数据的那些对象。球体 GeoPipe 中的第一项是 Sphere 插件，它往管线中添加多边形以构成球体形状。右键点击并选中该插件，属性面板就会显示可编辑的属性，例如环数和半径。编辑这些属性即可改变球体。另一个管线对象是 MeshMender。它放在这里是为了从球体生成切线空间向量。在 GeoPipe 中，数据沿管道向下流动，直到末端被渲染。MeshMender 目前没有可编辑的参数。GeoPipes 由导入器插件和 FX Composer 根据创建的形状构建。它们可以包含多个阶段。借助计划在将来推出的 FX Composer SDK，还可以创建更多管线对象。

31.1.3 编辑器窗口

图 31-4 所示的编辑器用于修改和创建 .fx 效果文件。语法高亮用不同颜色显示关键字，使着色器源码更易阅读。针对 Direct3D 设备状态的内置 IntelliSense 会在你编辑 .fx 文件时给出关键字建议。例如，如果你在 .fx 文件中键入 Direct3D 渲染状态 fillmode，编辑器会建议以下三个选项：

  • Solid
  • Wireframe
  • Point

它们分别对应 D3DFILL_SOLID、D3DFILL_WIREFRAME 和 D3DFILL_POINT，会被设置到渲染状态 D3DRS_FILLMODE 中。

编辑器还提供书签、查找和撤销/重做功能。撤销/重做会记住所有编辑，允许你一直撤销回开始编辑该文件的那一点。书签提供了跳转到着色器中关键位置的快捷方式，用工具栏上的 Find 框则能方便地在当前文件中搜索文本串。

窗口顶部的标签页可以在多个 .fx 文件之间快速切换。在材质面板中选中新材质，会自动把关联的 .fx 文件调到编辑器中。你对文件所做的任何修改，都会在按下工具栏上的 Compile 按钮后更新所有关联材质。构建过程的全部信息输出到日志面板和任务面板；点击任务面板中的错误，会自动在编辑器中高亮对应的文件和位置。这样就能方便地定位并修复语法错误。

31.1.4 着色器性能面板

查看某个效果文件生成的像素与顶点着色器汇编代码往往很有用。图 31-5 所示的着色器性能面板显示当前选中的材质着色器。面板提供四个下拉框。第一个选择要查询的技术，第二个选择通道，第三个选择该通道的顶点或像素着色器。在查看像素着色器时，可以用第四个下拉框查看调度信息。在这里可以看到着色器在任何受支持的 GPU 配置上的表现。着色器后面会附上芯片相关的信息列表，并给出效率摘要。这样就可以针对最佳性能调整相关的 .fx 文件。图 31-5 显示的是一个效果文件在 GeForce FX 5900 芯片上的调度情况。

将来我们会为着色器性能面板增加对新设备的支持，让这个工具在判断着色器代码于所有 NVIDIA 芯片上的性能时更有用。

31.1.5 属性面板

图 31-6 所示的 FX Composer 属性面板让用户能通过美术友好的界面调整各种参数。选中材质时，属性面板会列出关联 .fx 文件的参数。修改这些参数可以改变效果的外观，比如编辑某个颜色或浮点值。图 31-6 显示的是一个名为「check3d」的材质的属性。属性面板知道这些值应显示为颜色，是因为 .fx 文件的作者指定了参数的 UIType 为 color。这些颜色在面板中有可读的名称，是因为作者还添加了注解来标明每种颜色的 UIName。这些以及其他 .fx 文件的标记细节在 FX Composer 用户指南中有说明。

注意图 31-6 中 lightPos 属性旁边附带一个小图标。点击该图标会弹出图 31-7 所示的参数对话框，让你把场景中的对象连接到属性上。这个对话框之所以可用，是因为 .fx 文件中为该参数提供了 UIOBJECT = POINTLIGHT 注解。图 31-7 所示的参数对话框可以切换光源选项，并详细说明当前所选选项下该参数值的计算方式。当前值也会一并显示。从对话框可以看出，光源位置目前是用场景中名为「Default Spot Light」的光源计算出来的。你也可以用这个对话框把参数与场景「断开」，改为手动编辑。

除了材质的属性，属性面板也会显示对象的属性：如果选中了球体之类的对象，面板就允许更改球体的尺寸与剖分。编辑球体属性时，可以看到它在主显示窗口中改变大小。同样，选中纹理会显示该纹理的信息，但一般来说纹理目前无法从属性面板修改——它们是通过效果文件的注解设定的。除了修改着色器中的值，你还可以把当前场景的组件赋给面板中的属性。例如当你有某个光源、需要着色器始终包含当前光源位置时，就会想这么做。

因此属性面板是一个依上下文而变的 FX Composer 参数编辑器，能编辑颜色值、数值、向量和矩阵。对于向量和矩阵，属性面板提供滑块和编辑器；其他控件则视所编辑属性的要求出现。注意并非所有属性都可编辑；不可编辑的会以灰色显示。FX Composer 中的典型工作流程是：先选中要修改的对象，再用属性面板改动它。数值总是在当前关键帧上修改，并在合适时跨场景的其他关键帧插值。属性面板是修改 FX Composer 中信息的关键组件，而且它始终是实时的：场景中的对象移动时，面板中对应的值会同步变化。

31.1.6 场景面板

场景面板包含当前场景的几何体与已应用的材质。在这个窗口里，你可以选中导入模型的一部分并为它们应用材质。初始场景是一个带单个光源的简单球体；光源位于左上方。面板提供了调整整个场景与单个对象的控件。所有这些选项都在右键弹出菜单中。

图 31-8 显示了一个示例场景面板。注意几何对象的包围范围用蓝色显示，场景的包围范围用红色显示，选中的形状由小白点标出。此外我们打开了「Show Transform」选项，以便可视化对象的平移。在这个场景中，它表现为一条从世界中心连到左上角光源的线。在带蒙皮角色的场景中，这些线表示骨骼的平移。

FX Composer 支持简单的形状插件，让用户提供自己的对象用于简单的测试场景；这些对象也能用在材质面板中。鼠标右键总能从这类形状快速搭建场景，让用户方便地在不同类型几何体上测试着色器。几何数据也可以用随附的 .x 文件与 .nvb 文件导入插件导入。开发者可以为自定义场景格式添加自己的导入插件。图 31-8 中的场景就是从 .nvb 文件导入的。

用场景窗口顶部的按钮，用户可以操作场景。其中有摄像机运动（Pan/Dolly/Rotate）和对象运动（Translate/Scale/Rotate）按钮，作用于场景中选中的对象。如果场景包含动画数据，工具栏上的 Play 按钮可以播放，窗口中的计数器显示当前播放到的关键帧。要查看单个场景对象的属性，右键点击它们并选择 Properties，通常会在属性面板中带出可用的控件。就连场景背景也有自己的属性，可以查看场景范围并修改背景颜色等选项。右键菜单还可用于选择和删除场景项，以及创建点光源、聚光灯和方向光等对象，再用属性面板把它们连接到场景中的材质上。

31.1.7 纹理面板

选中材质时，纹理面板会显示与该材质关联的所有纹理。它们可能是从文件载入的纹理、由 .fx 文件中函数生成的过程化纹理，或者是渲染目标。图 31-9 显示了一个渲染目标示例，材质来自 glow.fx 文件。把该材质载入材质面板并选中后，就能在纹理面板中看到 blur 纹理。此时在材质面板中旋转辉光材质，就会看到 blur 纹理实时更新。因此你可以方便地查看着色效果正在生成的纹理，必要时调试算法。点击纹理面板工具栏上的保存图标，会把纹理以其原生格式存成 .dds 文件。这个特性让你能从效果文件的着色器生成纹理。工具栏上的其他按钮可改变纹理的查看尺寸，其中包括「actual size」，它可能很大，但对检查像素精度很有用。

31.1.8 任务面板

任务面板（启动时藏在日志面板下面）列出当前的错误和警告。见图 31-10。错误可能来自对 .fx 文件的不正确编辑，或者纹理之类资源载入失败。警告给出更笼统的提示，例如可能指出某个效果无法使用，因为当前图形硬件不支持它；也可能指出 .fx 文件中发现了可疑的语法，比如无法识别的语义或可能是拼写错误的注解。

当任务面板中显示的错误源于着色器编译问题时，你可以用鼠标选中该错误，FX Composer 编辑器会自动载入相应的 .fx 文件并用红色高亮该错误。编译之后 .fx 文件中的第一个错误会自动在任务面板中为你高亮。

31.1.9 日志面板

工程与材质载入之类的信息性事件详情显示在日志面板中，如图 31-11 所示。在这里可以跟踪构建进度、.x 文件之类模型的载入情况，以及 FX Composer 当前正在做什么。

31.2 示例工程

现在你已熟悉 FX Composer 的基本面板和窗口，试着载入一个示例工程。示例媒体位于 FX Composer 目录下名为「MEDIA」的文件夹中。在 MEDIA 下面会找到一个「fxcomposer」目录，其中包含示例工程。FX Composer 工程文件使用 .fxcomposer 扩展名，包含几何体、材质、纹理和其他元素——也就是把场景载入应用并用材质查看所需的全部内容。

FX Composer 附带一个名为「alien_gooch.fxcomposer」的示例工程。选择 File...Load Project 即可载入。载入后的 FX Composer 应用窗口的一部分如图 31-12 所示。

在这里可以看到该外星人带有一个默认黄色材质的效果，并具有逐像素镜面高光。在材质面板中我们选中了该材质，并用属性面板把颜色改成了绿色。我们还将动画播放到第 10 帧，外星人正悄悄穿过地面。

要给外星人应用另一个材质，我们可以右键点击材质面板（或使用 File 菜单）打开一个新材质。材质打开后，选中外星人以应用新效果，然后双击新材质即可应用。额外的模型可以用 File 菜单上的 Import Scene 命令独立于 .fxcomposer 文件导入。目前 FX Composer 可以导入 .x 与 .nvb 文件。场景准备好要发给另一位 FX Composer 用户时，可以选择 File...Save Project，按你当前的设置原样保存工作区。重新载入这个工作区，就会恢复到你上次保存时的场景。
