第 14 章　透视阴影贴图：使用与养护

Simon Kozlov

14.1 引言

阴影生成一直是实时 3D 图形中的大问题。对现代 GPU 来说，判断一个点是否在阴影中并不是件简单的事，尤其是因为 GPU 是用光栅化多边形而不是射线追踪的方式工作的。

今天的阴影应当是完全动态的。场景中几乎每个物体都应该投射并接收阴影，应该有自阴影，每个物体都应该有软阴影。只有两种算法能满足这些要求：阴影体（或模板阴影）和阴影贴图。

阴影体与阴影贴图两种算法的差别，归根到底是 物体空间 与 图像空间 的差别：

  • 物体空间阴影算法，例如阴影体，通过构造代表阴影遮挡物的多边形结构来工作，这意味着我们总能得到像素级准确但很硬的阴影。这种方法无法处理没有多边形结构的物体，例如经过 alpha 测试修改的几何体或置换贴图的几何体。此外，绘制阴影体需要大量填充率，这使得在密集场景中难以对每个物体都使用它，尤其是有多个光源时。
  • 图像空间阴影算法 能处理任何物体改动（只要我们能渲染一个物体，就能得到它的阴影），但受走样困扰。走样常出现在光源较宽或全方向的大场景中。问题在于阴影贴图所用的投影变换会改变阴影贴图纹素在屏幕上的大小，使靠近相机的纹素变得非常大。结果，我们必须使用极大的阴影贴图（屏幕分辨率的四倍或更大）才能获得好的质量。尽管如此，在复杂场景中阴影贴图仍比阴影体快得多。

透视阴影贴图（PSM）由 Stamminger 和 Drettakis（2002）在 SIGGRAPH 2002 上提出，它试图在 投影后空间 中使用阴影贴图来消除走样——在那个空间里，所有近处的物体都比远处的物体大。但原始算法很难使用，因为它只在某些情况下效果好。

所提出的 PSM 算法最显著的三个问题如下：

  • 当光源位于相机后方时，要用「虚拟相机」把所有潜在的投影物保持在虚拟相机视锥内。这导致阴影质量变差。
  • 阴影质量严重依赖光源在相机空间中的位置。
  • 原始论文没有讨论偏移（bias）问题。偏移对 PSM 是个问题，因为纹素面积是非均匀分布的，这意味着偏移不能再是常数，而应取决于纹素的位置。

这几个问题将在下一节讨论。本章聚焦于平行光（因为它们的走样问题更大），但所有思路和算法都可以轻松用于其他类型的光源（适当处会给出细节）。此外，我们还讨论通过滤波和模糊图像来提高阴影贴图质量的技巧。

总的来说，本章描述了可以提高 PSM 使用效果的技术和方法。不过，其中大部分思路仍需根据你的具体需求做调整。

14.2 PSM 算法的问题

14.2.1 虚拟相机

先看看这个问题的本质。通常的投影变换会把相机后方的物体移到投影后空间中无穷平面的另一侧。然而，如果光源也在相机后方，这些物体就是潜在的投影物，应当被绘制进阴影贴图。

在图 14-1 的透视变换中，射线上各点的顺序发生了变化。原始 PSM 论文的作者提出把视图相机「虚拟地」向后滑动，把潜在的投影物保持在视锥内，如图 14-2 所示，这样我们就能按常规方式使用 PSM。

虚拟相机的问题

但在实践中，使用虚拟相机导致阴影质量很差。「虚拟」滑动大大降低了有效阴影贴图的分辨率，使靠近真实相机的物体变小，最终阴影贴图里留下大量未使用的空间。此外，对于相机后方体积较大的投影物，我们可能不得不把相机往后移很多。图 14-3 展示了即便只滑动一点，质量变化有多么剧烈。

另一个问题是如何最小化实际的「后退距离」，因为这样才能最大化图像质量。这要求我们分析场景、找出潜在的投影物等等。当然，我们可以用包围体、场景层次组织之类的技术，但它们会造成明显的 CPU 开销。而且，当一个物体不再是潜在投影物时，阴影质量总会有突变。此时后退距离瞬间改变，阴影质量也随之突然改变。

虚拟相机问题的解决方案

我们针对这个虚拟相机问题提出一个方案：对光源矩阵使用一种特殊的投影变换。事实上，投影后空间允许一些在世界空间中做不到的投影技巧。事实证明，我们可以构造一个能「看到无穷远之外」的特殊投影矩阵。

反向投影矩阵唯一的缺点是我们需要更好的阴影贴图深度值精度，因为我们使用了很大的 z 值范围。不过在合理的情形下，24 位定点深度值就够了。

不过虚拟相机仍可能有用，因为阴影质量取决于相机近平面的位置。投影后 z 的公式为：

可以看到，Q 非常接近 1，只要 Z n 远小于 Z f（这是典型情况）它就不会明显变化。这就是为什么必须大幅改变近平面和远平面才能影响 Q 值，而这通常做不到。与此同时，近平面取值对投影后空间影响很大。例如，当 Z n = 1 米（m）时，近平面的世界空间之后第一米就占掉投影后空间单位立方体的一半。就此而言，如果把 Z n 改为 2 m，我们就能把 z 值分辨率实际提高一倍，从而提升阴影质量。这意味着我们应该想尽办法让 Z n 取最大值。

原始 PSM 文章提出的完美做法是回读深度缓冲，扫描每个像素，为每一帧求出可能的最大 Z n。可惜这个方法相当昂贵：需要回读大量显存，造成额外的 CPU/GPU 停顿，而且对 swizzle 过的分层深度缓冲效果不好。所以我们应当用另一种（可能精度较低的）方法为 PSM 渲染找一个合适的近平面值。

为 PSM 渲染寻找合适近平面值的其他方法可以包括各种 CPU 场景分析：

  • 基于粗略包围体计算的方法（稍后在「光源相机」一节简要描述）。
  • 用碰撞检测系统估计到最近物体的距离。
  • 用低多边形数的细节层次做额外的软件场景渲染，这也可用于遮挡剔除。
  • 针对特定应用、基于场景结构特征做精细分析。例如，对于相机路径固定的情形，可以为每一帧预计算近平面值。

这些方法都试图提高实际的近平面值，但我们也可以「虚拟地」提高它。思路与旧的虚拟相机相同，但有一点区别。当我们把相机向后滑动时，我们同时 提高 近平面值，使原始相机与虚拟相机的近平面四边形保持在同一平面上。见图 14-6。

当我们把虚拟相机向后滑动时，改善了 z 值的分辨率。但这会使近处物体的 x 和 y 值分布变差，从而在近处和远处之间平衡阴影质量。由于投影后空间中 z 值分布极不规则，且受近平面值影响很大，没有这种「虚拟」后滑就无法取得这种平衡。常见的毛病是阴影在相机附近看起来很好、在远处物体上质量很差，这正是阴影贴图纹素面积分布不均衡的典型结果。

14.2.2 光源相机

PSM 的另一个问题在于阴影质量依赖光源与相机位置之间的关系。光源垂直向下并且是平行光时，走样问题完全消失；但当光线朝向相机、接近正面照射时，阴影贴图会出现明显的走样。

我们试图把整个单位立方体装进单张阴影贴图纹理，所以必须把光源的视场角做得足够大以容纳整个立方体。这反过来意味着靠近近平面的物体得不到足够的纹理采样。见图 14-7。

光源离单位立方体越近，质量越差。众所周知，

所以对于 Z n = 1、Z f = 4000 的大型室外场景，Q = 1.0002，这意味着光源极其接近单位立方体。Zf /Zn 的比值通常大于 50，对应 Q = 1.02，已经足够接近，会带来问题。

把整个单位立方体装进单张阴影贴图纹理总是会有问题。两个方案各解决其中一部分：单位立方体裁剪 只把光源相机对准单位立方体中必要的部分，立方体贴图 方案则用多张纹理存储深度信息。

单位立方体裁剪

这个优化依据的事实是：我们只需要实际物体上的阴影贴图信息，而这些物体占据的体积通常远小于整个视锥体积（尤其是靠近远平面处）。因此，如果我们调整光源相机只包含真实物体（而不是整个单位立方体），就能得到更好的质量。当然，我们应该用简化的场景结构（例如包围体）来调整相机。

立方体裁剪在原始 PSM 文章中提到了，但它把场景中所有物体都考虑在内，既包括视锥内的投影物，也包括视锥外为构造虚拟相机而考虑的潜在投影物。既然我们不再需要虚拟相机，就可以把光源相机只聚焦于 阴影接收者，这样更高效。见图 14-8。不过，我们仍应在投影后空间中为光源相机选择近、远裁剪面的值，以把所有投影物纳入阴影贴图。但这不影响阴影质量，因为它不改变纹素面积分布。

由于这些包围体远处的部分在投影后空间中大幅收缩，即使光源靠近场景其余部分，光源相机的视场角也不会变得很大。

实践中，用粗略的包围体就能保持足够好的质量——我们只需大致指出场景中我们关心的那部分。在室外场景中，这是景观上物体的近似高度；在室内场景中，这是当前房间的包围体，诸如此类。

在建立一组大致描述场景的包围体之后，我们希望把聚焦于场景中阴影接收者的光源相机计算算法形式化。事实上，光源相机由位置、方向、上向量和投影参数给定，其中大部分是预先确定的：

  • 我们不能改变位置：它是光源在投影后空间中的位置，仅此而已。
  • 实践中，上向量不会显著改变质量，所以我们可以选任何合理的值。
  • 投影参数完全由视图矩阵决定。

所以最有意思的是基于包围体选择光源相机的方向。提出的算法如下：

  1. 计算构造实体几何运算的顶点列表，其中 B i 是第 i 个包围体，F 是我们在当前帧看到的每个投影物包围体对应的视锥，所有这些运算都在视图相机空间中完成。然后把这些顶点变换到投影后空间。这一步之后，我们就得到了光源相机应该「看到」的所有点。（顺便说，我们应该基于这些点求出好的近平面值，因为回读深度缓冲不是好办法。）
  2. 找出一个光源相机。如我们所知，这意味着找出最佳的光源相机方向，因为给定方向后其他参数都很容易算。我们提出用最小圆锥的轴线来近似最优方向，该圆锥以光源为中心并包含列表中的所有点。为点集寻找最优圆锥的算法在线性时间内完成，它类似于在线性时间内为点集寻找最小包围球的算法（Gartner 1999）。

这样，我们就能在线性时间内找到最优光源相机，时间与包围体数量有关，而包围体数量不会很大，因为我们只需要场景结构的粗略信息。

这个算法对大型室外场景中的平行光很有效。阴影质量几乎与光源角度无关，只在光线朝向相机时略有下降。图 14-9 展示了使用单位立方体裁剪与不使用的差别。

使用立方体贴图

虽然立方体裁剪在某些情况下有效，但另一些时候难以使用。例如，我们可能有一个填得很满的单位立方体（这很常见），或者我们根本不想使用包围体。此外，立方体裁剪对点光源无效。

更通用的方法是使用立方体贴图纹理做阴影贴图。大部分光源在投影后空间中变成点光源，用立方体贴图做点光源的阴影贴图很自然。但在投影后空间中情况略有变化，我们应当以不同方式使用立方体贴图，因为我们只需要存储单位立方体的信息。

提出的方案是使用单位立方体中相对光源背向的那些面，作为立方体贴图面纹理的承载平台。

对于投影后空间中的平行光源，立方体贴图看起来如图 14-10 所示。

所用立方体贴图面的数量（三到五个不等）取决于光源的位置。当光源靠近场景其余部分并朝向相机时，我们使用最多的面数，因此需要额外的纹理资源。对于位于单位立方体之外的其他类型光源，情况类似。

对于位于单位立方体内部的点光源，我们应当使用全部六个立方体贴图面，但它们仍然聚焦于单位立方体的各个面。见图 14-11。

可以说我们构造了一个「中心被移位的立方体贴图」，它与普通立方体贴图相似，只是纹理坐标上加了一个常量向量。换句话说，立方体贴图的纹理坐标是投影后空间中的顶点位置减去光源位置：

纹理坐标 = 顶点位置 - 光源位置

通过选择单位立方体的面作为立方体贴图的平台，我们让纹理面积按屏幕大小成比例分配，并确保阴影质量不依赖光源和相机的位置。事实上，投影后空间中的纹素大小处于一个有保证的范围内，所以它在屏幕上的投影只取决于它被投影到的平面。这个投影不会把纹素拉伸太多，因此屏幕上的纹素大小也在有保证的范围内。

渲染阴影贴图时顶点着色器和像素着色器都相对短小，真正要紧的是后台缓冲和深度阴影贴图缓冲的纯填充率。所以，绘制单张阴影贴图与绘制总纹理尺寸相同的立方体贴图几乎没有差别（前提是有良好的遮挡剔除）。在总纹理尺寸相同时，立方体贴图方案的质量更好。差别在于渲染目标切换的开销，以及在顶点和像素着色器中计算立方体贴图纹理坐标的额外指令。

由于深度纹理不能是立方体贴图，我们可以改用颜色纹理，把深度值打包进颜色通道。做法很多，也有许多依赖具体实现的技巧，但描述它们超出本章范围。

另一种可能是用多重纹理来模拟这种立方体贴图方案，把每个立方体贴图面变成一张独立纹理（这种情况下深度纹理很合适）。我们在顶点着色器中构造几套纹理坐标，在像素着色器中与阴影结果相乘。棘手之处在于如何管理场景中物体上的这些纹理，因为每个物体很少需要全部六个面。

14.2.3 偏移

如前所述，均匀阴影贴图中常用的常量偏移不能用于 PSM，因为 z 值和纹素面积分布会随光源位置和场景中点的不同而大幅变化。

如果你打算使用深度纹理，可以试试用 z 斜率缩放的偏移来做偏移处理。它通常足以修掉瑕疵，尤其是当极远处的物体不在相机范围内时。然而有些显卡不支持深度纹理（在 DirectX 中，只有 NVIDIA 显卡支持深度纹理），而且深度纹理不能是立方体贴图。在这些情况下，你需要另一种更通用的算法来计算偏移。另一个难点是 z 斜率缩放的偏移很难模拟和调整，因为它需要额外数据——例如当前三角形的顶点坐标——传入像素着色器，还要做一些计算，这完全不稳健。

不管怎样，我们来看看为什么不能再使用常量偏移。考虑这两种情形：光源靠近单位立方体，以及光源远离单位立方体。见图 14-13。

问题在于，Z f /Z n 这一比值决定阴影贴图中 z 值的分布，而它在这两种情形下差别很大。所以常量偏移在世界空间和投影后空间中意味着完全不同的实际偏移：针对第一种光源位置调整好的常量偏移，对第二个光源就不正确，反之亦然。与此同时，Z f /Z n 变化很大，因为取决于光源和相机在世界空间中的相对位置，光源可能靠近单位立方体，也可能很远（甚至到无穷远）。

即使光源位置固定，有时我们也找不到合适的常量作为偏移。偏移应当取决于点的位置——因为投影变换放大了近处物体、缩小了远处物体——所以偏移在相机附近应更小，对远处物体应更大。图 14-14 展示了这种情况下使用常量偏移的典型瑕疵。

简而言之，提出的方案是在世界空间做偏移（而不去分析双投影矩阵的结果），再把这个世界空间的偏移变换到投影后空间。算出的值依赖双投影，对任意光源和相机位置都正确。这些操作可以很容易地在顶点着色器中完成。此外，这个世界空间的偏移值应当按世界空间中的纹素大小缩放，以应对纹素面积非均匀分布造成的瑕疵。

14.3 改善阴影贴图的技巧

阴影贴图相对于阴影体的优势，在于它有可能在「在阴影中」和「不在阴影中」的采样之间产生颜色渐变，从而模拟软阴影。这种阴影「柔和度」并不取决于到遮挡物的距离、光源大小等等，但它仍然在世界空间中起作用。另一方面，模糊模板阴影更困难，尽管 Assarsson 等（2003）取得了显著进展。

本节介绍对阴影贴图做滤波和模糊的方法，以制造一种虚假的阴影柔和感，其模糊范围恒定，但看起来仍然不错。

14.3.1 滤波

大多数阴影贴图滤波方法都基于 percentage-closer filtering（PCF）原理。各方法的唯一差别在于硬件允许我们怎么用它。NVIDIA 深度纹理在与深度值比较之后执行 PCF；在其他硬件上，我们必须从最近的纹素取若干采样并对结果取平均（这才是真正的 PCF）。一般来说，深度纹理滤波比手动四次采样的 PCF 技术更高效。（PCF 需要大约八次采样才能达到相当的质量。）此外，使用深度纹理滤波并不排斥 PCF，所以我们可以取若干次滤波后的采样来进一步提高阴影质量。

在 PSM 上使用 PCF 与在标准阴影贴图上使用并无不同：用相邻纹素的采样做滤波。在 GPU 上，这通过把纹理坐标在各方向偏移一个纹素来实现。关于 PCF 的更详细讨论，见第 11 章「阴影贴图抗锯齿」。

四次采样 PCF 的着色器伪代码见代码清单 14-3 和 14-4。

这些技巧能改善阴影质量，但掩盖不了严重的走样问题。例如，如果很多屏幕像素映射到一个阴影贴图纹素，就会看到大片的阶梯状瑕疵，即使它们被稍微模糊过。图 14-16 展示了未做任何滤波的走样阴影，图 14-17 展示了 PCF 如何帮助改善阴影质量，但无法完全消除走样瑕疵。

14.3.2 模糊

从投影阴影我们了解到，最好的模糊结果往往来自先渲染到较小分辨率的纹理并用像素着色器模糊，然后把这个结果纹理反复送回模糊像素着色器若干次（称为 ping-pong rendering）。阴影贴图和投影阴影是类似的技术，为什么我们不能用这个方法？答案是：阴影贴图不是黑白图像；它是一堆深度值，而「模糊深度贴图」没有意义。

实际上，建议的做法是把阴影贴图渲染中的颜色部分（几乎不花额外代价）当作投影纹理用于某些物体。例如，假设我们有一个室外景观场景，我们希望地面上有高质量的模糊阴影，因为地面阴影最显眼。

  1. 在渲染深度阴影贴图之前，把颜色缓冲清零为 1。渲染过程中，除地形之外的每个物体都向颜色缓冲写入 0；地形则写入 1。整张阴影贴图渲染完成后，地形未受阴影之处为 1，受阴影之处为 0。参见图 14-18。
  2. 用简单的模糊像素着色器分多遍把这张图（即图 14-18 中的那张）做大幅度模糊。例如，用简单的两遍高斯模糊就能得到不错的结果。（对远处物体，你可能需要调整模糊半径。）这一步之后，我们就得到一张高质量的模糊纹理，如图 14-19 所示。
  3. 在用阴影渲染场景时，地形改用模糊后的纹理渲染，而不是阴影贴图；其余物体都用阴影贴图的深度部分渲染。参见图 14-20。

质量上的差别非常显著。

当然，这个方法不只用于景观，也适用于任何不需要自阴影的物体（例如地板、墙、地面平面等等）。幸运的是，正是在这些区域，阴影最显眼、走样问题也最明显。因为我们有多个颜色通道，可以同时对多个物体的阴影做模糊：

  • 使用深度纹理时，颜色缓冲完全空闲，所以我们可以把四个通道都用于四个物体。
  • 对于浮点纹理，一个通道存储深度信息，所以有三个通道可用于模糊。
  • 对于定点纹理，深度通常存在红色和绿色通道中，所以我们只有两个空闲通道。

这样我们就能在地面、地板、墙壁等上面得到漂亮的模糊阴影，同时在其他物体上保留所有其他阴影（用 PCF 模糊，并带有正确的自阴影）。
