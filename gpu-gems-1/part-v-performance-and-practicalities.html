第五部分：性能与实践

随着 GPU 日益复杂，把 GPU 高效地融入应用可能变得棘手。本书的这一部分从多个角度讨论着色器管理与集成，并概述影响集成决策的图形性能特征。

在第 28 章「图形管线性能」中，Cem Cebenoyan 概述了现代图形管线，其中包括催生本书许多技术的可编程管线。他在这一章里描述了检测 GPU 管线瓶颈的流程，并针对若干瓶颈给出了可行的对策。

Croteam 的 Dean Sekulic 讨论强大却常被误用的遮挡查询功能，见第 29 章「高效遮挡剔除」。遮挡查询让 GPU 返回一个物体在屏幕上会占多少像素。如果因 z 测试或模板测试，该物体一个像素都不占，就可以跳过它。但由于 CPU 与 GPU 是解耦的，遮挡查询不能像单线程函数调用那样发起，否则大部分乃至全部性能收益都会丧失。因此 Dean 讨论了几种方法，确保 GPU 遮挡查询的结果能被快速高效地用上。

在第 30 章「FX Composer 的设计」中，Christopher Maughan 讨论了一个强大的着色器创作工具。FX Composer 1.0 为着色器作者提供完整的 IDE，还提供可供美术调整着色器属性的 GUI。Chris 描述了该工具的设计层面，让人得以了解前沿的着色器集成。

第 31 章「使用 FX Composer」同样出自 Christopher Maughan 之手，深入 FX Composer 的使用细节，包括着色器创作、搭建简单场景，以及把着色器应用到物体上。这一章对着色器创作与工具使用都是很好的入门。

在第 32 章「着色器接口简介」中，Matt Pharr 介绍了着色器对象，它借助着色器接口的概念简化着色器向应用的集成。把着色器片段指定为带明确接口的对象，就能在运行时自动高效地组合这些片段，同时提升灵活性与性能。

第 33 章「把制作级 RenderMan 着色器转为实时」，Stephen Marshall（Sony Pictures Imageworks）讲述了如何改造 RenderMan 风格的离线着色器，并在面向 GPU 的制作管线中加以利用。离线着色器是围绕 CPU 的优势与限制写的；只有按现代 GPU 的思路重新审视着色器，才能拿到最大幅度的速度收益。

Cinema 4D 是另一个现代的支持着色器的创作工具。Jörn Loviscach 在第 34 章「把硬件着色集成进 Cinema 4D」中讨论了他如何集成 GPU 着色器，以尽可能贴近地模拟既有的 CPU 着色管线。Jörn 给出了一个有说服力的例子，说明如何把 GPU 能力无缝地加入更为传统的既有工作流。

尽管 GPU 一年比一年更灵活、更强大，但要让全部内容创作的渲染任务都由显卡承担，恐怕还需要相当长的时间。在第 35 章「在实时应用中利用高质量软件渲染效果」中，Alexandre Jean Claude 与 Marc Stevens 讨论了如何在利用 GPU 着色器算力的同时，保留成熟的既有软件渲染与建模管线的灵活性。

最后，John O'Rorke 关于着色器集成的一章——第 36 章「把着色器集成进应用」——聚焦于 DirectX 的 .fx 文件格式及其用法。John 演示了如何使用 .fx 文件的语义与注解等特性，这些特性使着色器集成更为简单。他最后给出了若干定制与扩展 .fx 文件的想法，包括着色器继承。
