第六部分：超越三角形

图形处理器不再只用于处理图形。完全可编程、支持浮点数学运算的图形处理单元（GPU）的出现，使它们也能用于许多更通用的计算。事实上，今天的研究者正在以 GPU 最初设计者从未想象过的方式使用它们。

本书这一部分介绍 GPU 的若干非传统应用，从物理仿真到立体图像渲染。其中有些应用也许在今天的硬件上还不常用，但它们让我们看到图形处理器在将来可能如何被使用。

第 37 章「GPU 计算工具箱」，作者 Ian Buck 与 Tim Purcell，介绍 GPU 上的通用计算，并描述若干可用于在 GPU 上实现通用算法的编程原语。即使你原本不知道自己的 GPU 可以被编程来排序和搜索数组，这一章也会告诉你该怎么做。

第 38 章「GPU 上的快速流体动力学仿真」，作者 Mark J. Harris，详细描述如何实现完全在 GPU 上运行的、物理上准确的流体仿真。物理建模本质上是一个并行问题，因此很适合 GPU 的并行处理能力。随着图形硬件变得更快、更并行、更灵活，我们会看到越来越多类型的物理仿真迁移到 GPU 上。许多物理仿真的最终输出就是图形，所以把计算留在显示设备附近是合理的。

这一部分还包含两章关于体渲染的内容。1991 年，Jim Kajiya 曾有一句著名的预言：「十年之后，一切渲染都将是体渲染。」这个预言并未成真，但对于无法用多边形几何体描述的数据的可视化，体渲染无疑仍有优势。随着纹理内存变得更便宜、着色能力增强，体渲染会越来越普及。第 39 章「体渲染技术」，作者 Milan Ikits、Joe Kniss、Aaron Lefohn 与 Charles Hansen，对体渲染作了很好的概述。第 40 章「把实时着色应用于三维超声可视化」，作者 Thilaka Sumanaweera，描述了用体渲染来渲染超声数据时出现的一些实际问题。

第 41 章「实时立体图」，作者 Fabio Policarpo，讲解如何用 GPU 生成单图像随机点立体图（SIRD）。这类图像之所以有趣，是因为它们证明了人类视觉系统可以纯粹依靠匹配立体图像中的特征来推断深度，即使纹理、透视等其他深度线索全部缺失。Bela Julesz 在 20 世纪 60 年代发明随机点立体图时，大概从未想到有可能实时生成动态三维场景的立体图。

最后，第 42 章「变形器」，Eugene d'Eon 把若干技术纳入他所称的「变形器」，从而推广了动画的概念。借助这一定义，他发展出一种用雅可比矩阵求顶点法线的标准方法，从而不必再用有限差分来推导梯度向量。

这一部分会让你感受到 GPU 在电子游戏常规领域之外的应用，我们希望它能启发你找到自己的方式来使用和折腾硬件。
