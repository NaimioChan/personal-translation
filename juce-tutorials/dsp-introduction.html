DSP 入门

探索数字信号处理与音频缓冲区操作的领域。了解 JUCE DSP 模块的基础知识，以及如何在自己的音频应用和插件中运用它的类。

难度：高级
平台：Windows、macOS、Linux
插件格式：VST、AU、Standalone
类：dsp::ProcessorChain, dsp::Gain, dsp::Oscillator, dsp::LadderFilter, dsp::Reverb

本项目需要支持 C++14 特性的编译器。较新版本的 Xcode 和 Visual Studio 均包含这一支持。

什么是 DSP？

数字信号处理涉及对数字数据进行操作，以对信号执行某些运算。在数字音频处理中，我们可以在不同的域中处理音频数据：

  • 时域：一维信号，其分析是相对于时间进行的。
  • 空间域：多维信号，其分析是相对于某个空间进行的。
  • 频域：一个特定的域，用频率来表示时间或空间。

快速傅里叶变换（FFT）

时域或空间域的信号可以通过使用称为傅里叶变换的变换公式转换为频域。这种变换函数的一种常见高效实现是快速傅里叶变换（FFT），你可能会在 JUCE DSP 模块中遇到它。

FFT 使我们能够把音频信号分解为各个频率，并表示其中每个频率的幅度和相位信息。使用它的逆函数，我们可以把信号还原到原来的域，因此它在处理单个频率成分（例如滤波）时非常有用。

有限/无限脉冲响应（FIR/IIR）

dsp 中有两种主要的数字滤波器设计：

  • 有限脉冲响应滤波器（FIR）：一种稳定的设计，它把每个输出采样作为其先前输入采样的函数来处理。FIR 滤波器可以是线性相位的，通常更易于设计，但效率低于 IIR 滤波器。
  • 无限脉冲响应滤波器（IIR）：一种可能不稳定的设计，它把每个输出采样作为其先前输入和输出采样的函数来处理。IIR 滤波器使用先前的输出采样，从而产生内部反馈，设计起来更难，但可能比 FIR 滤波器更高效。

在这些滤波器设计中，有许多不同的传递函数，它们决定了滤波器的锐度以及在过渡频率处出现的纹波量。其中许多设计受模拟滤波器启发，不同的传递函数试图模仿不同的模拟对应物。

你可以在 JUCE DSP 模块中找到的一些传递函数包括：

  • FIR 传递函数：Window、Kaiser、Transition、Least Squares、Half-Band Equiripple。
  • IIR 传递函数：Butterworth、Chebyshev type 1、Chebyshev type 2、Elliptic、Half-Band Polyphase Allpass。

如果你对这些滤波器设计感兴趣，可以在网上找到大量更深入探讨这一主题的资源，但就本教程的目的而言，我们已经涵盖了入门所需的基础之外的内容。

信号处理的生命周期

与 AudioProcessor 及其 prepareToPlay() 和 getNextAudioBlock() 函数的音频应用生命周期类似，我们必须实现派生自 MPESynthesiser 的 AudioEngine 类的 prepare() 和 renderNextBlock() 函数。

每个 dsp 处理器还必须实现以下方法，以确保正常工作：

  • prepare()：在处理开始前调用，用于设置采样率和块大小。
  • process()：处理处理上下文中提供的输入和输出缓冲区。
  • reset()：重置处理器的内部状态，必要时带平滑处理。

处理器链

DSP 模块中一个方便的模板类是 juce::dsp::ProcessorChain，它允许我们通过依次自动调用 prepare()、process() 和 reset() 方法，把不同的处理串联起来。

我们像这样把处理器声明为模板类型：

juce::dsp::ProcessorChain<juce::dsp::Oscillator<Type>, juce::dsp::Gain<Type>> processorChain;

然后我们就可以直接在 processorChain 实例上应用所有处理。

掌握了 dsp 模块工作原理的一些基础知识，让我们开始处理一些信号吧！

创建振荡器

在 CustomOscillator 类中，按自上而下的顺序定义一个包含 juce::dsp::Oscillator 和 juce::dsp::Gain 处理器的 juce::dsp::ProcessorChain [1]。我们希望增益处理影响振荡器的输出，以便能够削减输出的电平。同时定义一个带有处理器索引的枚举 [2]，以便之后能通过索引清晰地引用相应的处理。

enum {
    oscIndex,
    gainIndex // [2]
};
juce::dsp::ProcessorChain<juce::dsp::Oscillator<Type>, juce::dsp::Gain<Type>> processorChain; // [1]
};

在 prepare() 函数中，依次调用处理器链中每个处理器的 prepare 函数 [3]。

void prepare (const juce::dsp::ProcessSpec& spec)
{
    processorChain.prepare (spec); // [3]
}

在 reset() 函数中，依次调用处理器链中每个处理器的 reset 函数 [4]。

void reset() noexcept
{
    processorChain.reset(); // [4]
}

现在我们要定义振荡器用来生成音频信号的周期函数。作为一个简单的例子，我们从正弦波开始。

在构造函数中，通过提供处理的索引并使用 processorChain.get<>() 方法获取 Oscillator 的引用 [5]。让我们用 lambda 函数和 std::sin 函数来初始化振荡器，为它提供正弦波 [6]。

查找表会根据所提供的离散点数量来近似计算开销较大的算术运算。在我们的例子中，使用 128 个点。

public:
//==============================================================================
CustomOscillator()
{
    auto& osc = processorChain.template get<oscIndex>(); // [5]
    osc.initialise ([] (Type x) { return std::sin (x); }, 128); // [6]
}

要设置振荡器的频率，我们需要像上一步那样再次获取它的引用，并在其上调用 setFrequency() 方法 [7]。

void setFrequency (Type newValue, bool force = false)
{
    auto& osc = processorChain.template get<oscIndex>();
    osc.setFrequency (newValue, force); // [7]
}

对增益处理器及其 setGainLinear() 方法也是同样的过程 [8]。

void setLevel (Type newValue)
{
    auto& gain = processorChain.template get<gainIndex>();
    gain.setGainLinear (newValue); // [8]
}

在 process() 函数中，我们可以依次调用处理器链中每个处理器的 process 函数 [9]。

template <typename ProcessContext>
void process (const ProcessContext& context) noexcept
{
    processorChain.process (context); // [9]
}

如果在 CustomOscillator 类中实现上述更改后运行这段代码，我们应该能听到一个使用 JUCE DSP 模块的简单正弦波合成器。

更改振荡器波形

让我们把振荡器波形改为锯齿波，让合成器更有趣一些。

由于我们无法使用 std 版本的锯齿波函数，需要使用 jmap 函数手动进行值映射。为此，把 -Pi .. Pi 之间的范围映射到 -1 .. 1，从而提供从 -1 到 1 的线性斜坡。由于锯齿波只有 2 个断点，我们只需向查找表提供 2 个离散点。

public:
//==============================================================================
CustomOscillator()
{
    auto& osc = processorChain.template get<oscIndex>();
    osc.initialise ([] (Type x) {
        return juce::jmap (x,
            Type (-juce::MathConstants<double>::pi),
            Type (juce::MathConstants<double>::pi),
            Type (-1),
            Type (1));
    },
        2);
}

运行程序应该会给我们一个不同的、更具侵略性的声音。

练习：用三角波或方波波形初始化振荡器，听听它的声音。你能实现一个白噪声振荡器吗？

添加第二个振荡器

大多数模拟合成器都有多个振荡器，而获得更厚实声音的一个常见技巧是添加一个频率略微失谐的第二个振荡器。所以我们通过修改 Voice 类来试试。

向处理器链添加第二个 CustomOscillator 模板类型 [1]，并在枚举中添加其对应的索引 [2]。

private:
//==============================================================================
juce::HeapBlock<char> heapBlock;
juce::dsp::AudioBlock<float> tempBlock;
enum {
    osc1Index,
    osc2Index, // [2]
    masterGainIndex
};
juce::dsp::ProcessorChain<CustomOscillator<float>, CustomOscillator<float>, juce::dsp::Gain<float>> processorChain; // [1]
//...
};

在 noteStarted() 函数中，让我们把第二个振荡器的频率设置为当前演奏的音符，并将其音高提高 1% [3]。我们可以让力度与第一个振荡器保持同一水平 [4]。

void noteStarted() override
{
    auto velocity = getCurrentlyPlayingNote().noteOnVelocity.asUnsignedFloat();
    auto freqHz = (float) getCurrentlyPlayingNote().getFrequencyInHertz();
    processorChain.get<osc1Index>().setFrequency (freqHz, true);
    processorChain.get<osc1Index>().setLevel (velocity);
    processorChain.get<osc2Index>().setFrequency (freqHz * 1.01f, true); // [3]
    processorChain.get<osc2Index>().setLevel (velocity); // [4]
}

在 notePitchbendChanged() 函数中，让我们确保应用弯音时失谐的频率保持不变 [5]。

void notePitchbendChanged() override
{
    auto freqHz = (float) getCurrentlyPlayingNote().getFrequencyInHertz();
    processorChain.get<osc1Index>().setFrequency (freqHz);
    processorChain.get<osc2Index>().setFrequency (freqHz * 1.01f); // [5]
}

让我们运行程序，听听它听起来怎么样。

练习：添加第三个振荡器，其频率降低 1%。声音会变得更厚实吗？

添加梯形滤波器

让我们为合成器引入一种滤波器设计。梯形滤波器处理器受 Moog 合成器中一种著名模拟设计的启发，这也是我们将在项目中使用的。到目前为止，你应该已经熟悉向处理器链添加处理器的操作了。

在 Voice 类中，把 juce::dsp::LadderFilter 添加到处理器链 [1]，并把其对应的索引添加到枚举 [2]。

juce::HeapBlock<char> heapBlock;
juce::dsp::AudioBlock<float> tempBlock;
enum {
    osc1Index,
    osc2Index,
    filterIndex, // [2]
    masterGainIndex
};
juce::dsp::ProcessorChain<CustomOscillator<float>, CustomOscillator<float>, juce::dsp::LadderFilter<float>, juce::dsp::Gain<float>> processorChain; // [1]

如前所述，获取滤波器处理器的引用，把其截止频率设为 1kHz [3]，谐振设为 0.7 [4]。

Voice()
{
    auto& masterGain = processorChain.get<masterGainIndex>();
    masterGain.setGainLinear (0.7f);
    auto& filter = processorChain.get<filterIndex>();
    filter.setCutoffFrequencyHz (1000.0f); // [3]
    filter.setResonance (0.7f); // [4]

现在信号的高频应被衰减，声音更加沉闷。

练习：尝试不同的谐振值和截止频率，听听输出。目前滤波器是衰减为 12dB/octave 的低通滤波器。你能把它做成衰减为 24dB/octave 的高通滤波器吗？

用 LFO 调制信号

现在我们越来越接近经典的模拟合成器声音了，还能有什么呢？当然是调制 LFO。

低频振荡器作为控制信号，作用于我们想要调制的另一个参数。它的频率通常非常低，低于人耳听觉范围，因此我们不应该像前面的振荡器那样把该振荡器添加到处理器链中。这一次，把新的 Oscillator 声明为 Voice 类中的普通成员变量 [1]。

static constexpr size_t lfoUpdateRate = 100;
size_t lfoUpdateCounter = lfoUpdateRate;
juce::dsp::Oscillator<float> lfo; // [1]

为了对梯形滤波器的截止频率产生缓慢而平滑的调制变化，在 Voice 构造函数中把 LFO 初始化为正弦波 [2]，速率为 3Hz [3]。

lfo.initialise ([] (float x) { return std::sin (x); }, 128);
lfo.setFrequency (3.0f);
}

由于我们不需要像音频处理采样率那样频繁地更新 LFO，在 prepare() 函数中用采样率除以 LFO 更新率来设置 LFO 的采样率 [4]。在这种情况下，我们决定以低一百倍的频率更新 LFO。

void prepare (const juce::dsp::ProcessSpec& spec)
{
    tempBlock = juce::dsp::AudioBlock<float> (heapBlock, spec.numChannels, spec.maximumBlockSize);
    processorChain.prepare (spec);
    lfo.prepare ({ spec.sampleRate / lfoUpdateRate, spec.maximumBlockSize, spec.numChannels }); // [4]
}

在下面的 for() 循环中，我们每 100 个采样才修改一次截止频率。首先调用 processSample() 函数在 LFO 上处理单个采样 [5]，然后将其返回值映射到所需的调制范围 [6]。在这种情况下，我们希望把截止频率从 100Hz 调制到 2kHz。最后，把新的截止频率应用到梯形滤波器 [7]。

void renderNextBlock (juce::AudioBuffer<float>& outputBuffer, int startSample, int numSamples) override
{
    auto output = tempBlock.getSubBlock (0, (size_t) numSamples);
    output.clear();
    for (size_t pos = 0; pos < (size_t) numSamples;)
    {
        auto max = juce::jmin ((size_t) numSamples - pos, lfoUpdateCounter);
        auto block = output.getSubBlock (pos, max);
        juce::dsp::ProcessContextReplacing<float> context (block);
        processorChain.process (context);
        pos += max;
        lfoUpdateCounter -= max;
        if (lfoUpdateCounter == 0)
        {
            lfoUpdateCounter = lfoUpdateRate;
            auto lfoOut = lfo.processSample (0.0f); // [5]
            auto curoffFreqHz = juce::jmap (lfoOut, -1.0f, 1.0f, 100.0f, 2000.0f); // [6]
            processorChain.get<filterIndex>().setCutoffFrequencyHz (curoffFreqHz); // [7]
        }
    }
    juce::dsp::AudioBlock<float> (outputBuffer)
        .getSubBlock ((size_t) startSample, (size_t) numSamples)
        .add (tempBlock);
}

你现在应该能听到类似 UFO 的警报声。

练习：尝试调制不同的参数，例如滤波器谐振或振荡器频率。

添加简单的混响

目前，如果我们演奏合成器，你可能已经注意到声音非常干，所以我们添加一个简单的混响来为信号增加深度。为了把混响应用到整个合成器声音，在 AudioEngine 类中创建一个效果链，并把 juce::dsp::Reverb 模板类型连同其索引 [2] 一起添加到效果链 [1]。

enum {
    reverbIndex // [2]
};
juce::dsp::ProcessorChain<juce::dsp::Reverb> fxChain; // [1]
};

在处理器链上调用 prepare() 函数 [3]。

void prepare (const juce::dsp::ProcessSpec& spec) noexcept
{
    setCurrentPlaybackSampleRate (spec.sampleRate);
    for (auto* v : voices)
        dynamic_cast<Voice*> (v)->prepare (spec);
    fxChain.prepare (spec); // [3]
}

为了处理效果链，我们需要从 AudioBuffer 中获取正确的 AudioBlock，以便把上下文传递给处理链。首先，把 AudioBuffer 转换为可用的 AudioBlock [4]，并使用 getSubBlock() 方法引用要操作的采样中正确的部分 [5]。现在我们可以从这个 AudioBlock 获取处理上下文 [6]，并用它处理效果链 [7]。

void renderNextSubBlock (juce::AudioBuffer<float>& outputAudio, int startSample, int numSamples) override
{
    MPESynthesiser::renderNextSubBlock (outputAudio, startSample, numSamples);
    auto block = juce::dsp::AudioBlock<float> (outputAudio); // [4]
    auto blockToUse = block.getSubBlock ((size_t) startSample, (size_t) numSamples); // [5]
    auto contextToUse = juce::dsp::ProcessContextReplacing<float> (blockToUse); // [6]
    fxChain.process (contextToUse); // [7]
}

合成器现在应该在信号末尾添加了平滑的混响尾音。

这个修改版本代码的源代码可以在演示项目的 DSPIntroductionTutorial_02.h 文件中找到。
