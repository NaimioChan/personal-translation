单选按钮与复选框

使用单选按钮和复选框为应用程序添加可选择的选项。

难度：初级
平台：Windows、macOS、Linux、iOS、Android
类：ToggleButton、Button、Label、String

单选按钮与复选框

本教程探讨如何使用 Button 类创建开关式选项。通常你会使用 ToggleButton 类来实现这一点，但如上所述，任何按钮都可以设置为切换型按钮。标准的 ToggleButton 组件由一段文本和文本左侧的一个「气泡」组成，气泡中可能带有一个勾号，也可能没有。（如果你愿意，可以使用 LookAndFeel 类自定义这种外观。）这两种状态可以在上一节的截图中看到。

在 MainContentComponent 构造函数中，「male」和「female」按钮的设置如下：

addAndMakeVisible (maleButton);
addAndMakeVisible (femaleButton);
maleButton.onClick = [this] { updateToggleState (&maleButton, "Male"); };
femaleButton.onClick = [this] { updateToggleState (&femaleButton, "Female"); };

你可以看到，ToggleButton 对象的配置方式与 TextButton 对象相同（参见教程：监听器与广播器）。要使这两个切换按钮互斥，我们需要将它们添加到同一个「单选组」中。这样在任何时刻只允许其中一个按钮被打开（而打开另一个按钮则会把原来的那个关闭）。单选组 ID 是一个非零整数，用于标识必须互斥的那组按钮。除此之外，所有具有相同单选组 ID 的按钮都必须是同一个父组件的子组件，才能使其生效。（如果按钮位于不同的父组件或不同的窗口中，你需要自行实现这种互斥行为。）

在本例中，我们使用一个枚举值（GenderButtons）作为单选组 ID：

enum RadioButtonIds {
    GenderButtons = 1001
};

然后我们使用 Button::setRadioGroupId() 函数来设置单选组 ID。

maleButton.setRadioGroupId (GenderButtons);
femaleButton.setRadioGroupId (GenderButtons);

注意，setRadioGroupId() 函数是 Button 类的成员，而不仅是 ToggleButton 类的成员。任何按钮都可以成为单选组的一部分，但只有当该按钮被设置为可切换开/关（而不是仅仅拦截点击事件）时，这样做才可能有意义。

另外三个 ToggleButton 对象在配置时没有添加到单选组中：

addAndMakeVisible (sportButton);
addAndMakeVisible (artButton);
addAndMakeVisible (filmButton);
sportButton.onClick = [this] { updateToggleState (&sportButton, "Sport"); };
artButton.onClick = [this] { updateToggleState (&artButton, "Art"); };
filmButton.onClick = [this] { updateToggleState (&filmButton, "Film"); };

通过以零作为参数调用 Button::setRadioGroupId() 函数，可以将 Button 对象从单选组中移除。

添加一些额外的 ToggleButton 对象，当然你可以轻松添加更多爱好。但你也可以在性别类别下添加更多选项，例如「不愿透露」或「其他」。

使用其他按钮作为切换按钮

如上所暗示，任何按钮都可以用作切换按钮。为了说明这一点，让我们把演示项目中所有的 ToggleButton 对象转换为 TextButton 对象。这里我们显然需要做的是将成员变量的类型更改为 TextButton 类：

juce::Label genderLabel { {}, "I identify my gender as..." };
juce::ToggleButton maleButton { "Male" },
    femaleButton { "Female" };
juce::Label hobbiesLabel { {}, "My hobbies are..." };
juce::ToggleButton sportButton { "Sport" },
    artButton { "Art" },
    filmButton { "Film" };
//==============================================================================
JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (MainContentComponent)
};

但为了让按钮可以通过鼠标点击进行切换，我们需要调用 Button::setClickingTogglesState() 函数。为此，在 MainContentComponent 构造函数中的任意位置添加以下代码：

maleButton.setClickingTogglesState (true);
femaleButton.setClickingTogglesState (true);
sportButton.setClickingTogglesState (true);
artButton.setClickingTogglesState (true);
filmButton.setClickingTogglesState (true);

使用文本显示按钮的切换状态

在某些情况下，你可能还想根据按钮的切换状态更改显示的文本。为此，你只需在 updateToggleState() 函数中调用 Button::setButtonText() 函数。要尝试这一点，请按如下方式修改 updateToggleState() 函数：

void updateToggleState (juce::Button* button, juce::String name)
{
    auto state = button->getToggleState();
    juce::String stateString = state ? "ON" : "OFF";
    juce::String selectedString = state ? " (selected)" : "";
    juce::Logger::outputDebugString (name + " Button changed to " + stateString);
    button->setButtonText (name + selectedString);
}

在本例中，如果按钮处于打开状态，我们只需在常规按钮文本后附加「(selected)」文本。

这种技术对这里展示的 TextButton 组件和 ToggleButton 组件都适用。

小结

在本教程中，我们介绍了复选框和单选按钮风格控件的用法。特别是，你应该能够在自己的应用中完成以下操作：

  • 使用 ToggleButton 对象并响应状态变化。
  • 根据 ToggleButton 对象的状态更改其文本。
  • 将 ToggleButton 对象分组以形成「单选组」，使得组内任何时刻只有一个按钮可以处于开启状态。
  • 使用其他 Button 组件作为切换按钮。
