控制音频电平

本教程展示如何处理音频以改变其输出电平。这是通过处理底层的音频采样数据实现的。

难度：中级
平台：Windows、macOS、Linux
类：AudioAppComponent, Random, AudioSourceChannelInfo, AudioBuffer, Slider

以乘法实现电平控制

查看代码时，你可能会注意到我们的 MainContentComponent 类并未继承 Slider::Listener 类。实际上，我们是在 getNextAudioBlock() 函数被调用时立即获取滑块的值：

void getNextAudioBlock (const juce::AudioSourceChannelInfo& bufferToFill) override
{
    auto level = (float) levelSlider.getValue();

这种技术在这样简单的应用中可以接受，但在更复杂的应用中，你几乎肯定想用另一种技术。更好的做法是把控制音频处理系统的值存放在应用的「数据模型」中，而不是仅仅依赖 UI 控件来存储这些值。

虽然调用 Slider::getValue() 是可以接受的（即便在 getNextAudioBlock() 函数中），但你绝不能调用 Slider::setValue()，尤其是在 getNextAudioBlock() 函数中。因为这段代码运行在音频线程上。你不能从音频线程做任何改变 UI 对象状态的事情，不过查询 UI 对象的状态是可以的，只要确信这些查询没有副作用。

为了按滑块指定的电平生成白噪声，我们需要做一些基本的算术运算。Random::nextFloat() 函数总是生成 0.0 到 1.0 之间的值。如果把它画成音频波形，大致如下所示：

一种简单的做法是先把噪声缩放，使其始终落在 -1.0 到 1.0 之间。为此，我们可以乘以 2.0 再减去 1.0。这样得到的信号如下所示：

在 getNextAudioBlock() 函数中，代码实现如下：

void getNextAudioBlock (const juce::AudioSourceChannelInfo& bufferToFill) override
{
    auto level = (float) levelSlider.getValue();
    for (auto channel = 0; channel < bufferToFill.buffer->getNumChannels(); ++channel)
    {
        auto* buffer = bufferToFill.buffer->getWritePointer (channel, bufferToFill.startSample);
        for (auto sample = 0; sample < bufferToFill.numSamples; ++sample)
        {
            auto noise = random.nextFloat() * 2.0f - 1.0f;
            buffer[sample] = noise * level;
        }
    }
}

一处小优化

减少算术运算的次数常常是 DSP 的目标。在这个例子中，我们可以省去每个采样的一次乘法运算。为此，我们可以先把 0.0 到 1.0 之间的值乘以所需输出电平的两倍。假设我们希望电平为 0.25。如果把随机值乘以 0.5，就会得到类似这样的结果：

最后，我们需要对随机值做偏移，使其以零为中心。为此，我们减去等于所乘值一半的数值。这当然就是原来的电平值。最终结果大致如下：

这可以在 getNextAudioBlock() 函数中用代码实现，你会看到现在每个采样少了一次乘法运算：

void getNextAudioBlock (const juce::AudioSourceChannelInfo& bufferToFill) override
{
    auto level = (float) levelSlider.getValue();
    auto levelScale = level * 2.0f;
    for (auto channel = 0; channel < bufferToFill.buffer->getNumChannels(); ++channel)
    {
        auto* buffer = bufferToFill.buffer->getWritePointer (channel, bufferToFill.startSample);
        for (auto sample = 0; sample < bufferToFill.numSamples; ++sample)
            buffer[sample] = random.nextFloat() * levelScale - level;
    }
}

这个修订版本的代码可以在演示项目的 SynthLevelControlTutorial_02.h 文件中找到。

这个实现还剩下一个问题：电平只在每个生成的音频块中更新为一个新的常量值。在这个例子中听不出来（因为源声音是白噪声）。如果把它用于大多数音频内容，这种技术就会引入音频瑕疵。这是因为电平值可能在每个音频块之间相当突然地跳变，而不是在音频块内部平滑变化。避免这些瑕疵（例如电平变化时可听见的爆裂声）的技术在其他教程中探讨（参见教程：构建正弦波合成器）。

练习： 在用户界面中添加第二个滑块。用第一个滑块控制左声道的电平，用第二个滑块控制右声道的电平。
