创建 MIDI 数据

本教程介绍 MidiMessage 类，它用于表示 MIDI 数据。同时还会介绍 MidiBuffer 类，用于处理 MIDI 消息的缓冲区。

难度：初级
平台：Windows、macOS、Linux、iOS、Android
类：MidiMessage、MidiBuffer、Time、Timer

准备工作

本教程假定你已经熟悉 MIDI 的一般知识。你还应该熟悉 JUCE 按钮和滑块的使用（参见教程：Slider 类和教程：监听器与广播器）。

在此处下载本教程的演示项目：PIP | ZIP 。解压项目，在 Projucer 中打开第一个头文件。

如果你在这一步需要帮助，参见教程：Projucer 第 1 部分：Projucer 入门。

MidiMessage 类

本教程演示创建若干 MIDI 消息类型所需的代码，也包含解析大多数 MIDI 消息类型的代码。一般来说，MidiMessage 类包含一系列 static 成员函数，用于创建 MidiMessage 对象（例如用于创建音符开消息的 MidiMessage::noteOn() 函数）。此外还有一系列用于查询和访问 MidiMessage 对象的成员函数（例如 MidiMessage::isNoteOn() 和 MidiMessage::getNoteNumber() 函数）。

创建 MidiMessage 对象

看看 MidiMessage 类的公有静态成员函数。这里列出了创建各种类型 MIDI 消息的全部函数。你也可以用单个字节或原始数据创建 MidiMessage 对象，但这些数据必须是符合 MIDI 规范的有效 MIDI 消息。（如果在调试版本中创建了无效的 MidiMessage 对象，会触发断言。）

MidiMessage 对象通常应作为局部变量或成员变量保存，并按值传递。

要创建音符开消息，使用 MidiMessage::noteOn() 函数。它需要 MIDI 通道（编号 1 .. 16 ）、音符编号（0 .. 127 ）和力度（以 uint8 值 0 .. 127 表示）。力度也可以用 float 值表示，内部会将其转换为 0 .. 127（四舍五入到最接近的整数）。

力度为零的音符开实际上就是音符关消息，因此音符开的力度范围是 1 .. 127 （这使得音符开的最小浮点力度约为 0.004f ）。另外还有 MidiMessage::noteOff() 函数专门用于创建音符关消息，它还允许你指定音符关力度（某些合成器会识别这个值）。

在演示项目中，我们创建一个力度为 100 的音符开消息，音符编号取决于点击的是哪个按钮：

void setNoteNumber (int noteNumber)
{
    auto message = juce::MidiMessage::noteOn (midiChannel, noteNumber, (juce::uint8) 100);
    message.setTimeStamp (juce::Time::getMillisecondCounterHiRes() * 0.001 - startTime);
    addMessageToList (message);
}

注意，noteNumber 值由某个按钮设置，并传给 setNoteNumber() 函数。我们还需要把值 100 强制转换为 uint8 类型。如果不这样做，编译器就无法确定该调用 MidiMessage::noteOn() 函数的哪个版本。

设置 MidiMessage 的时间戳是可选的，但它对于跟踪事件生成或接收的时间非常有用。默认时间戳为零，并且时间戳的时间单位没有定义。一般来说，由应用程序决定使用什么时间单位。在这个简单的例子中，我们使用秒作为单位，通过 Time::getMillisecondCounterHiRes() 函数获取当前时间并乘以 0.001（再减去应用程序启动的时间，使其相对于该时间点）。

音量滑块用于创建连续控制器（CC）消息。CC7 是音量控制变化消息：

volumeSlider.onValueChange = [this] {
    auto message = juce::MidiMessage::controllerEvent (midiChannel, 7, (int) volumeSlider.getValue());
    message.setTimeStamp (juce::Time::getMillisecondCounterHiRes() * 0.001 - startTime);
    addMessageToList (message);
};

解析 MidiMessage 对象

我们的 addMessageToList() 函数解析时间戳和 MIDI 消息，以便在界面的消息列表中显示：

void addMessageToList (const juce::MidiMessage& message)
{
    auto time = message.getTimeStamp();
    auto hours = ((int) (time / 3600.0)) % 24;
    auto minutes = ((int) (time / 60.0)) % 60;
    auto seconds = ((int) time) % 60;
    auto millis = ((int) (time * 1000.0)) % 1000;
    auto timecode = juce::String::formatted ("%02d:%02d:%02d.%03d",
        hours,
        minutes,
        seconds,
        millis);
    logMessage (timecode + " - " + getMidiMessageDescription (message));
}

getMidiMessageDescription() 函数实际上会解析 MIDI 数据，得到消息的可读描述。

static juce::String getMidiMessageDescription (const juce::MidiMessage& m)
{
    if (m.isNoteOn())
        return "Note on " + juce::MidiMessage::getMidiNoteName (m.getNoteNumber(), true, true, 3);
    if (m.isNoteOff())
        return "Note off " + juce::MidiMessage::getMidiNoteName (m.getNoteNumber(), true, true, 3);
    if (m.isProgramChange())
        return "Program change " + juce::String (m.getProgramChangeNumber());
    if (m.isPitchWheel())
        return "Pitch wheel " + juce::String (m.getPitchWheelValue());
    if (m.isAftertouch())
        return "After touch " + juce::MidiMessage::getMidiNoteName (m.getNoteNumber(), true, true, 3) + ": " + juce::String (m.getAfterTouchValue());
    if (m.isChannelPressure())
        return "Channel pressure " + juce::String (m.getChannelPressureValue());
    if (m.isAllNotesOff())
        return "All notes off";
    if (m.isAllSoundOff())
        return "All sound off";
    if (m.isMetaEvent())
        return "Meta event";
    if (m.isController())
    {
        juce::String name (juce::MidiMessage::getControllerName (m.getControllerNumber()));
        if (name.isEmpty())
            name = "[" + juce::String (m.getControllerNumber()) + "]";
        return "Controller " + name + ": " + juce::String (m.getControllerValue());
    }
    return juce::String::toHexString (m.getRawData(), m.getRawDataSize());
}

同样的功能已经可以通过成员函数 [MidiMessage::getDescription()](https://docs.juce.com/master/classMidiMessage.html#a868d95a096fad999de5ba11f9a2f6340 “以字符串形式返回 MIDI 消息的人类可读描述，例如“Note On C#3 Veloci…””）获得。这里我们没有使用现成的实现，而是自己实现，以演示如何处理不同类型的 MIDI 消息。

这个函数试图解析所有类型的 MIDI 消息（尽管到目前为止我们只看了创建音符开消息和控制器消息）。下面是你应该采用的访问 MidiMessage 对象中数据的方法：

  • 确定 MIDI 消息的类型（使用以「is」开头的函数之一）；然后
  • 使用合适的函数访问该类型的 MIDI 消息。

只有当消息是系统消息（例如系统独占消息）时，才会执行到这个函数的最后一行。你可以使用 MidiMessage::getRawData() 访问任何消息的原始数据，但大多数情况下，使用内置的那一组函数更容易（也更易读）。

对错误类型的消息使用 MidiMessage 的数据访问函数会导致错误。例如，MidiMessage::getNoteNumber() 函数会从任何 MidiMessage 对象返回一个值，但这并不能确认该消息是音符开还是音符关消息。你必须先用 MidiMessage::isNoteOn()、MidiMessage::isNoteOff() 或 MidiMessage::isNoteOnOrOff() 之一进行检查。

练习：修改 getMidiMessageDescription() 函数，让它列出音符开消息的力度。查阅 API 参考，找出应该使用哪个函数。

MidiBuffer 类

演示应用程序的一个问题是它不创建音符关消息。我们只是在创建用于打击乐音色的 MIDI 消息，所以这看起来不算大问题。但不为音符开消息创建对应的音符关消息是不好的做法（对于持续发声的音色，这会导致卡音）。

我们可以在 setNoteNumber() 函数中紧跟音符开消息之后添加一个音符关消息：

auto message = juce::MidiMessage::noteOn (1, noteNumber, (uint8) 100);
message.setTimeStamp (juce::Time::getMillisecondCounterHiRes() * 0.001 - startTime);
addMessageToList (message);
auto messageOff = juce::MidiMessage::noteOff (message.getChannel(), message.getNoteNumber());
messageOff.setTimeStamp (juce::Time::getMillisecondCounterHiRes() * 0.001 - startTime);
addMessageToList (messageOff);

我们甚至可以修改音符关消息的时间戳（例如设为音符开消息之后 0.1 秒），但这不会改变消息被投递到列表的时间：

auto message = juce::MidiMessage::noteOn (1, noteNumber, (uint8) 100);
message.setTimeStamp (juce::Time::getMillisecondCounterHiRes() * 0.001 - startTime);
addMessageToList (message);
auto messageOff = juce::MidiMessage::noteOff (message.getChannel(), message.getNoteNumber());
messageOff.setTimeStamp (message.getTimeStamp() + 0.1);
addMessageToList (messageOff);

MidiBuffer 类提供了根据时间戳遍历 MIDI 消息缓冲区的函数。为了演示这一点，我们将搭建一个简单的调度系统：把带有特定时间戳的 MidiMessage 对象添加到 MidiBuffer 对象中，然后用一个 Timer 对象定期检查是否有 MIDI 消息到了该投递的时间。

Timer 类不适合高精度定时。这里用它只是为了保持示例简单，让所有函数调用都发生在消息线程上。如果需要更可靠的定时，应该使用其他线程（大多数情况下，音频线程适合把 MidiBuffer 对象渲染成音频）。

给我们的 MainContentComponent 类添加一些成员：

juce::MidiBuffer midiBuffer; // [1]
double sampleRate = 44100.0; // [2]
int previousSampleNumber = 0; // [3]
  • [1]：MidiBuffer 对象本身。
  • [2]：MidiBuffer 类以采样作为 MIDI 消息时间戳的单位。虽然我们不生成音频，但仍需要选一个值作为采样率。我们用这个成员保存采样率。（这里用 44,100，因为这是常见值。）
  • [3]：我们需要跟踪在 MidiBuffer 中已经处理到哪个时间戳。我们用这个成员以采样为单位保存该时间戳。

向 MidiBuffer 对象添加 MIDI 消息

我们不再把 MIDI 消息直接添加到消息列表，而是把它们添加到 MidiBuffer 对象中。添加下面这个函数，它会调用 MidiBuffer::addEvent() 函数：

void addMessageToBuffer (const juce::MidiMessage& message)
{
    auto timestamp = message.getTimeStamp();
    auto sampleNumber = (int) (timestamp * sampleRate);
    midiBuffer.addEvent (message, sampleNumber);
}

现在修改 setNoteNumber() 函数和 Slider::onValueChange 辅助对象，让它们使用这个函数。这样我们就能把 MIDI 消息事件安排到未来：

void setNoteNumber (int noteNumber)
{
    auto message = juce::MidiMessage::noteOn (1, noteNumber, (juce::uint8) 100);
    message.setTimeStamp (juce::Time::getMillisecondCounterHiRes() * 0.001 - startTime);
    addMessageToBuffer (message);
    auto messageOff = juce::MidiMessage::noteOff (message.getChannel(), message.getNoteNumber());
    messageOff.setTimeStamp (message.getTimeStamp() + 0.1);
    addMessageToBuffer (messageOff);
}
volumeSlider.onValueChange = [this] {
    auto message = juce::MidiMessage::controllerEvent (10, 7, (int) volumeSlider.getValue());
    message.setTimeStamp (juce::Time::getMillisecondCounterHiRes() * 0.001 - startTime);
    addMessageToBuffer (message);
};

遍历 MidiBuffer 对象

要从缓冲区读取消息，需要实现我们的定时器。把 Timer 类添加为基类：

class MainContentComponent : public juce::Component,
                             private juce::Timer
{

并实现 Timer::timerCallback() 函数：

void timerCallback() override
{
    auto currentTime = juce::Time::getMillisecondCounterHiRes() * 0.001 - startTime;
    auto currentSampleNumber = (int) (currentTime * sampleRate); // [4]
    for (const auto metadata : midiBuffer) // [5]
    {
        if (metadata.samplePosition > currentSampleNumber) // [6]
            break;
        auto message = metadata.getMessage();
        message.setTimeStamp (metadata.samplePosition / sampleRate); // [7]
        addMessageToList (message);
    }
    midiBuffer.clear (previousSampleNumber, currentSampleNumber - previousSampleNumber); // [8]
    previousSampleNumber = currentSampleNumber; // [9]
}
  • [4]：计算当前时间对应的采样数。
  • [5]：遍历缓冲区中的消息。
  • [6]：如果最近从 MidiBuffer 对象取出的 MIDI 消息的时间戳位于未来，说明处理已经结束，退出 while() 循环。
  • [7]：取出的 MidiMessage 对象的时间戳是以采样数为基准的。我们把它重置为以秒为基准的时间戳体系，这样无需修改 addMessageToList() 函数就能与之配合。
  • [8]：MidiBuffer::clear() 函数会从缓冲区中清除时间戳落在某个范围内的 MIDI 消息。我们用它删除刚刚处理过的消息。
  • [9]：记录本次函数执行的时间，供下次调用 timerCallback() 函数时使用。

最后，需要在 MainContentComponent 构造函数中启动定时器：

setSize (800, 300);
startTimer (1);
}

这些修改的代码可以在演示项目的 MidiMessageTutorial_02.h 文件中找到。

小结

本教程介绍了 MidiMessage 类和 MidiBuffer 类。读完本教程后，你应该能够：

  • 创建特定类型的 MidiMessage 对象——音符开、音符关、连续控制器（控制变化）等等。
  • 解析 MidiMessage 对象，判断其类型并从中获取有用的数据。
  • 把 MIDI 消息存入 MidiBuffer 对象。
  • 根据时间戳遍历 MidiBuffer 对象中的 MIDI 消息。
