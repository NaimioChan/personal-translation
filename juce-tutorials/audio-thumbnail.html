绘制音频波形

本教程介绍如何使用 AudioThumbnail 类来显示音频波形。它提供了一种简便的方式，让你可以在音频应用中绘制任意数量的波形。

难度：中级
平台：Windows、macOS、Linux
类：AudioThumbnail, AudioThumbnailCache, AudioFormatReader, ChangeListener

准备工作

本教程是教程：构建音频播放器的后续内容，你应该先阅读并理解那篇教程。它还假定你熟悉 Graphics 类，以及在组件中执行绘制的 Component::paint() 函数（参见教程：Graphics 类）。

绘制音频波形（尤其是长文件）通常需要以某种格式存储音频数据的低分辨率版本，使波形的绘制既高效，对用户来说也清晰。AudioThumbnail 类会为你处理这个低分辨率版本，并在需要时创建和更新它。

设置 AudioThumbnail

首先要强调的一点是，AudioThumbnail 类并不是 Component 类的子类。AudioThumbnail 类用于在 paint() 函数中完成另一个 Component 对象的音频波形绘制。下面的代码展示了如何在教程：构建音频播放器的演示项目基础上添加这一功能。

额外的对象

在 MainContentComponent 类中，我们需要添加两个成员：一个 AudioThumbnailCache 对象和一个 AudioThumbnail 对象。AudioThumbnailCache 类用于缓存一个或多个音频文件所需的低分辨率版本。举例来说，这意味着如果我们关闭一个文件、打开一个新文件，然后再回头打开第一个文件，AudioThumbnailCache 中仍然保存着第一个文件的低分辨率版本，无需重新扫描和计算数据。另一个有用的特性是，AudioThumbnailCache 对象可以在 AudioThumbnail 类的不同实例之间共享

juce::TextButton openButton;
juce::TextButton playButton;
juce::TextButton stopButton;
std::unique_ptr<juce::FileChooser> chooser;
juce::AudioFormatManager formatManager; // [3]
std::unique_ptr<juce::AudioFormatReaderSource> readerSource;
juce::AudioTransportSource transportSource;
TransportState state;
juce::AudioThumbnailCache thumbnailCache; // [1]
juce::AudioThumbnail thumbnail; // [2]
JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (MainContentComponent)
};

如果使用这样静态分配的对象，那么 AudioThumbnailCache 对象 [1] 必须列在 AudioThumbnail 对象 [2] 之前，因为它会作为参数传给 AudioThumbnail 的构造函数。出于同样的原因，AudioFormatManager 对象 [3] 也必须列在 AudioThumbnail 对象之前。

初始化对象

在 MainContentComponent 构造函数的初始化列表中，我们这样设置这些对象：

MainContentComponent()
    : state (Stopped),
      thumbnailCache (5), // [4]
      thumbnail (512, formatManager, thumbnailCache) // [5]
{
  • [4]：AudioThumbnailCache 对象在构造时必须指定要存储的缩略图数量。
  • [5]：AudioThumbnail 对象本身在构造时，需要告诉它用多少个源采样来生成一个缩略图采样。这决定了低分辨率版本的分辨率。另外两个参数是上面讨论过的 AudioFormatManager 和 AudioThumbnailCache 对象。

AudioThumbnail 类也是一种 ChangeBroadcaster 类。我们可以注册为变更监听器 [6]（在 MainContentComponent 的构造函数中）。当 AudioThumbnail 对象发生变化、需要我们更新波形绘制时，就会收到这些变更通知。

thumbnail.addChangeListener (this); // [6]

响应变更

在 changeListenerCallback() 函数中，我们需要判断变更是由 AudioTransportSource 对象还是 AudioThumbnail 对象广播的：

void changeListenerCallback (juce::ChangeBroadcaster* source) override
{
    if (source == &transportSource)
        transportSourceChanged();
    if (source == &thumbnail)
        thumbnailChanged();
}

transportSourceChanged() 函数只包含我们原先用于响应 AudioTransportSource 对象变更的代码：

void transportSourceChanged()
{
    changeState (transportSource.isPlaying() ? Playing : Stopped);
}

如果发生变化的是 AudioThumbnail 对象，我们就调用 Component::repaint() 函数。这样在下一次屏幕绘制操作时就会调用我们的 paint() 函数：

void thumbnailChanged()
{
    repaint();
}

打开文件

成功打开声音文件后，我们还需要把该文件传给 AudioThumbnail 对象 [7]，方式是把它放进一个 FileInputSource 对象。

void openButtonClicked()
{
    chooser = std::make_unique<juce::FileChooser> ("Select a Wave file to play...",
        juce::File {},
        "*.wav");
    auto chooserFlags = juce::FileBrowserComponent::openMode
                        | juce::FileBrowserComponent::canSelectFiles;
    chooser->launchAsync (chooserFlags, [this] (const juce::FileChooser& fc) {
        auto file = fc.getResult();
        if (file != juce::File {})
        {
            auto* reader = formatManager.createReaderFor (file);
            if (reader != nullptr)
            {
                auto newSource = std::make_unique<juce::AudioFormatReaderSource> (reader, true);
                transportSource.setSource (newSource.get(), 0, nullptr, reader->sampleRate);
                playButton.setEnabled (true);
                thumbnail.setSource (new juce::FileInputSource (file)); // [7]
                readerSource.reset (newSource.release());
            }
        }
    });
}

执行绘制

在 paint() 函数中，我们首先计算要绘制的矩形区域。然后检查 AudioThumbnail 对象包含多少个声道，以此判断是否已加载文件：

void paint (juce::Graphics& g) override
{
    juce::Rectangle<int> thumbnailBounds (10, 100, getWidth() - 20, getHeight() - 120);
    if (thumbnail.getNumChannels() == 0)
        paintIfNoFileLoaded (g, thumbnailBounds);
    else
        paintIfFileLoaded (g, thumbnailBounds);
}

如果没有加载文件，我们就显示 No File Loaded 消息，绘制方式是调用 paintIfNoFileLoaded() 函数并传入 Graphics 对象和边界矩形：

void paintIfNoFileLoaded (juce::Graphics& g, const juce::Rectangle<int>& thumbnailBounds)
{
    g.setColour (juce::Colours::darkgrey);
    g.fillRect (thumbnailBounds);
    g.setColour (juce::Colours::white);
    g.drawFittedText ("No File Loaded", thumbnailBounds, juce::Justification::centred, 1);
}

接下来才是关键部分。如果确实加载了文件，我们就可以绘制波形：

void paintIfFileLoaded (juce::Graphics& g, const juce::Rectangle<int>& thumbnailBounds)
{
    g.setColour (juce::Colours::white);
    g.fillRect (thumbnailBounds);
    g.setColour (juce::Colours::red); // [8]
    thumbnail.drawChannels (g, // [9]
        thumbnailBounds,
        0.0, // start time
        thumbnail.getTotalLength(), // end time
        1.0f); // vertical zoom
}
  • [8]：注意我们为 Graphics 对象设置了当前颜色。AudioThumbnail 对象绘制波形时使用的颜色就由此决定。
  • [9]：我们调用 AudioThumbnail::drawChannels() 函数，传入用于绘制的 Graphics 对象、要绘制到的矩形、开始和结束时间（以秒为单位）以及垂直缩放系数。这里我们使用 AudioThumbnail::getTotalLength() 函数获取文件时长，以便绘制整个文件。（我们也可以从 AudioTransportSource 对象用 AudioTransportSource::getLengthInSeconds() 函数获取长度，得到相同的结果。）

以上涵盖了使用 AudioThumbnail 对象的所有基本要点。

练习：在实践中，你常常只想显示声音文件的某些区域。从 AudioThumbnail::drawChannels() 函数应该可以清楚看出，用 JUCE 实现这一点有多么简单。试着修改代码，只显示文件中的某个特定区域。

添加时间位置标记

本节将带你为显示区域添加一条竖线，用来显示文件播放的当前时间位置。

添加定时器

首先，我们需要把 Timer 类加入基类列表 [10]：

class MainContentComponent : public juce::AudioAppComponent,
                             public juce::ChangeListener,
                             private juce::Timer // [10]
{
public:

然后让定时器回调重绘我们的组件。注意这段代码要加到 private 区段，因为你会注意到我们是以私有方式继承 Timer 类的：

void timerCallback() override
{
    repaint();
}

在 MainContentComponent 构造函数中，我们需要启动定时器 [11]——每 40 毫秒一次就足够了：

startTimer (40); // [11]
}

练习： 实际上，你可以推迟启动定时器，等到文件成功打开后再启动。
