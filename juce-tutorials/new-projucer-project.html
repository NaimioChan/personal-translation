Projucer 第 1 部分：Projucer 入门

本教程介绍如何安装 JUCE，以及如何使用 Projucer 创建一个新的跨平台 JUCE 项目。你还会学到如何把项目导出到 Xcode 或 Visual Studio 这类 IDE，以便开发、运行和调试你的 JUCE 应用程序。

难度：初级
平台：Windows、macOS、Linux、iOS、Android

准备工作

下载 JUCE。解压 JUCE 文件夹，把它放到电脑上的某个位置，放在用户主目录里比较方便。

进入刚刚安装的 JUCE 文件夹，启动其中的 Projucer。

新建项目窗口

第一次启动 Projucer 时，你会看到新建项目窗口。（之后也可以通过 Projucer 主菜单中的 New Project… 再次打开它。）

选择项目类型

在窗口左侧选择你要创建的项目类型。

对于每种项目类型，Projucer 都会生成全部项目文件，并添加适当的少量代码把所有内容搭建起来。这样，项目创建完成后，你就可以立即开始开发实际功能。

如果你是第一次接触 JUCE，不知道从哪里入手，可以选择 GUI 应用程序——它会为你把桌面端和移动端应用所需的基础都配置好。

下面列出当前支持的所有项目类型。

项目类型 说明
Application/Blank 创建一个空白的 JUCE 应用程序。
Application/GUI 创建一个带空应用程序窗口的最小 JUCE 应用程序。你可以从这里开始，使用 JUCE 提供的各种类添加更多功能，比如更多 GUI 组件。
Application/Audio 创建一个最小 JUCE 应用程序，与 Application/GUI 类似，但会自动添加音频输入输出所需的所有设置代码。可用于游戏、多媒体应用等众多场景。
Application/Console JUCE 也很适合开发完全没有 GUI 的命令行应用程序。使用此项目类型即可创建这样的应用。
Application/Animated 创建一个绘制动态图形显示的应用。例如，你可以从这里开始制作动画移动应用。
Application/OpenGL 创建一个空白 JUCE 应用程序，与 Application/GUI 类似，但增加了 OpenGL 支持，可绘制 3D 模型导入、GLSL 着色器等功能。
Plug-In/Basic 创建一个基础音频插件。支持 VST、AudioUnit 和 AAX 插件格式的代码都会自动添加。视你的环境而定，此项目类型可能需要一些额外的准备步骤才能正常工作。详见教程：创建一个基础音频/MIDI 插件，第 1 部分：项目搭建。
Library/Static、Library/Dynamic 此项目类型适合创建构建在 JUCE 之上的可复用软件库。Projucer 支持创建静态链接和动态链接的库。

此外还有许多示例项目，可以作为项目的另一个起点。它们位于 JUCE/examples 子文件夹中，点击 Open Example 标签页即可浏览。

你并不受所选项目类型的限制；例如，即使选择了 Application/GUI，之后仍然可以添加动画和 OpenGL。不过，你无法轻易把 Application 转换成一个库或音频插件。

创建新项目

选择好合适的项目类型后，可以在窗口右侧填写一些额外的项目设置：

  • Project Name – 在这里为你的应用取一个名字。
  • Modules – JUCE 框架的代码按模块组织。在这里可以选择项目中包含哪些模块，下方的区域则可以指定之前安装的 JUCE 文件夹内 modules 子文件夹的位置。
  • Exporters – 在这里选择用哪些原生 IDE 来构建和调试你的应用。这也决定了你的应用将支持哪些桌面和移动平台。别担心，这不是最终决定——借助 Projucer，之后仍可添加更多平台和 IDE。

Projucer 目前为下列 IDE、构建系统和平台提供导出器：

目标操作系统 支持的构建系统
macOS Xcode
Windows Visual Studio、Code::Blocks
Linux Makefile、Code::Blocks
iOS Xcode
Android Android Studio
  • File Creation Options – 视项目类型而定，此字段会提供一些自动生成代码的选项。如果你刚接触 JUCE，通常默认选项就是最好的选择，它会自动生成所有需要的内容，让你快速上手。
  • 检查完所有设置后，点击 Create Project… 按钮，在指定位置生成项目。

导出项目并在原生 IDE 中打开

项目创建完成后，可以直接从 Projucer 启动原生 IDE 并打开你的项目。使用靠近顶部的按钮：

现在你已经打开了 IDE（Xcode、Visual Studio 等），可以编译并运行你的 JUCE 应用，开始写代码了！

使用之前，你需要先在电脑上安装好相应的原生 IDE 或构建系统。某些平台可能还需要安装额外的依赖项，例如为 Android 开发就需要安装 Android SDK。

所有导出目标（即原生 IDE 项目）都会在你创建 Projucer 项目时生成，此后每次在 Projucer 中保存都会同步更新。你可以随时创建新的导出目标，为项目添加对更多 IDE 和平台的支持。相关内容和 Projucer 项目的更多管理功能，请参阅教程：Projucer 第 2 部分：管理 Projucer 项目。

打开已有项目

要打开已有的 Projucer 项目，可以双击项目文件夹中的 .jucer 文件，或者在向导中点击 Open Existing Project。（也可以从 Projucer 主菜单进入 Open…。）

打开 PIP 文件

在学习其他 JUCE 教程时，你可能会遇到 Projucer Instant Project（PIP）文件。它们本质上是扩展名为 .h 的头文件，向 Projucer 提供元数据，以便从单个文件自动创建带有正确模块和导出器的项目。

打开 PIP 文件的方式类似：从 Projucer 主菜单的 Open… 对话框中选择该文件，或者直接把它拖放到 Projucer 界面窗口上。

小结

读完本教程后，你应该能够：

  • 安装 JUCE。
  • 使用 Projucer 创建新项目。
  • 把项目导出到原生 IDE，例如 OSX 上的 Xcode 或 Windows 上的 Visual Studio。
  • 在目标平台的原生 IDE 中编译、运行和调试应用。
  • 在 Projucer 中打开已有项目和 PIP 文件。
