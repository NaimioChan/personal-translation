几何动画

在你的JUCE应用程序中创建简单的动画。使用AnimatedAppComponent类让静态的几何形状动起来。

难度：初级
平台：Windows、macOS、Linux、iOS、Android
类：AnimatedAppComponent、Path、Point

入门

在此处下载本教程的示例项目：PIP | ZIP。解压项目并在Projucer中打开第一个头文件。

如果你在这一步需要帮助，请参阅教程：Projucer第1部分：Projucer入门。

示例项目

完成后，示例项目会在屏幕上显示一段连续平滑的鱼动画，它由多个Path和Point对象组成。

这里给出的代码与JUCE示例中的AnimationAppExample大致相似。

AnimatedAppComponent类

在创建简单的动画JUCE应用程序时，一个很有用的可继承类是AnimatedAppComponent类。正如AudioAppComponent或OpenGLAppComponent类分别对音频应用程序和OpenGL应用程序有用一样，AnimatedAppComponent提供了对制作动画有益的函数，即：

  • setFramesPerSecond()：此函数允许我们在应用程序一开始就设置FPS，使动画尽可能平滑地运行。调用时，它还会以给定的频率启动重绘过程。
  • update()：此函数以setFramesPerSecond()函数设置的速率被调用，动画参数的逐步推进就在这里执行。
  • getFrameCounter()：返回自动画开始以来按所定义的FPS速率调用update()函数的总次数。这在用于计算动画的周期性数学函数中很有用。
  • getMillisecondsSinceLastUpdate()：另一个有用的函数，返回自上次调用update()函数以来经过的时间（毫秒），以便创建计时准确、不受帧率影响的动画。

通过将这些函数与父类Component的paint()函数一起使用，我们就可以开始创建简单的动画了。

为圆形制作动画

正如我们在MainContentComponent类中所见，MainContentComponent继承自AnimatedAppComponent。

创建动画的第一步是设置动画的帧率。我们在MainContentComponent构造函数中这样做 [1]，调用setFramesPerSecond()函数：

MainContentComponent()
{
    setSize (800, 600);
    setFramesPerSecond (60); // [1]
}

这里我们把FPS设为60，这会在内部以60Hz的频率调用定时器，让动画每秒更新60次。这大致相当于大多数屏幕的刷新率，会带来平滑的动画。

让我们从让一个简单的圆形做圆周运动开始。在paint()函数中，首先通过调用Graphics类的setColour()函数设置绘制圆形所用的颜色 [2]。接着定义形状将遵循的圆形路径的半径 [3]，如下所示：

void paint (juce::Graphics& g) override
{
    //...
    g.setColour (getLookAndFeel().findColour (Slider::thumbColourId)); // [2]
    int radius = 150; // [3]
    juce::Point<float> p (getWidth() / 2.0f + 1.0f * radius,
        getHeight() / 2.0f + 1.0f * radius); // [4]
    g.fillEllipse (p.x, p.y, 30.0f, 30.0f); // [5]
}

然后创建一个Point，表示形状中心在给定时间帧的位置 [4]。这里，为了创建圆周运动，首先用屏幕的宽度和高度除以二求出屏幕中心。然后给形状的x和y坐标都加上半径值来偏移它们。

最后，通过fillEllipse()函数，以上面定义的Point坐标和30的直径作为参数，绘制实际的圆形。

你能猜到如果现在运行应用程序，圆形会怎样吗？没错，圆形会被静态地绘制在屏幕右下角，因为坐标系从左上角开始，圆形只是被半径值推向了相反的方向，如下所示：

让我们修改Point的声明来创建真正的运动。

void paint (juce::Graphics& g) override
{
    // (Our component is opaque, so we must completely fill the background with a solid colour)
    g.fillAll (getLookAndFeel().findColour (juce::ResizableWindow::backgroundColourId));
    g.setColour (getLookAndFeel().findColour (juce::Slider::thumbColourId));
    int radius = 150;
    juce::Point<float> p ((float) getWidth() / 2.0f + 1.0f * (float) radius * std::sin ((float) getFrameCounter() * 0.04f),
        (float) getHeight() / 2.0f + 1.0f * (float) radius * std::cos ((float) getFrameCounter() * 0.04f));
    g.fillEllipse (p.x, p.y, 30.0f, 30.0f);
}

这里我们使用getFrameCounter()函数获取自动画开始以来的帧计数，并用它的值通过正弦和余弦函数分别计算宽度和高度方向上-1 .. 1之间的值。对帧计数乘以0.04这一标量控制周期函数交替的速度，从而形成圆周运动。

如果现在运行应用程序，我们应该能看到圆周运动出现。

这个修改版本代码的源代码可以在示例项目的AnimationTutorial_02.h文件中找到。

为路径制作动画

接下来，我们不画圆形，而是让一条线沿圆形路径运动。

使用与上一节相同的代码基础，我们将创建多个Point对象，并沿这些点创建一条Path，而不是只有一个动画的Point。按如下方式修改paint()函数：

void paint (juce::Graphics& g) override
{
    // (Our component is opaque, so we must completely fill the background with a solid colour)
    g.fillAll (getLookAndFeel().findColour (juce::ResizableWindow::backgroundColourId));
    g.setColour (getLookAndFeel().findColour (juce::Slider::thumbColourId));
    auto numberOfDots = 15; // [1]
    juce::Path spinePath; // [2]
    for (auto i = 0; i < numberOfDots; ++i) // [3]
    {
        int radius = 150;
        juce::Point<float> p ((float) getWidth() / 2.0f + 1.0f * (float) radius * std::sin ((float) getFrameCounter() * 0.04f + (float) i * 0.12f),
            (float) getHeight() / 2.0f + 1.0f * (float) radius * std::cos ((float) getFrameCounter() * 0.04f + (float) i * 0.12f));
        if (i == 0)
            spinePath.startNewSubPath (p); // if this is the first point, start a new path..
        else
            spinePath.lineTo (p); // ...otherwise add the next point
    }
    // draw an outline around the path that we have created
    g.strokePath (spinePath, juce::PathStrokeType (4.0f)); // [4]
}
  • [1]：首先定义沿路径要创建的点数。
  • [2]：接着创建一个Path对象，用来绘制连接这些点的线。
  • [3]：现在对每个点，像之前一样创建相同的Point对象，但这一次我们要为循环中的每次后续迭代偏移动画。注意在圆周运动中每两个点之间增加了0.12的偏移。如果迭代是第一次，我们通过在Path对象上调用startNewSubPath()函数创建一个新的子路径，否则就把当前点连接到Path上先前定义的点。
  • [4]：最后，沿这些Point对象为创建的Path绘制轮廓。

运行应用程序，我们可以看到一条以圆形方式绘制的线。

为鱼制作动画

让我们做点更有趣的，用目前创建的Path和Point对象来为一条鱼制作动画。

为了显示沿圆形路径实际绘制的点并创建鱼的身体，我们在for循环中添加一行，通过fillEllipse()函数绘制圆形，并为线上的每个点指定递增的宽度和高度 [1]，如下所示：

void paint (juce::Graphics& g) override
{
    //...
    g.setColour (getLookAndFeel().findColour (juce::Slider::thumbColourId));
    auto fishLength = 15;
    juce::Path spinePath;
    for (auto i = 0; i < fishLength; ++i)
    {
        int radius = 150;
        juce::Point<float> p (getWidth() / 2.0f + 1.0f * radius * std::sin (getFrameCounter() * 0.04f + i * 0.12f),
            getHeight() / 2.0f + 1.0f * radius * std::cos (getFrameCounter() * 0.04f + i * 0.12f));
        // draw the circles along the fish
        g.fillEllipse (p.x - i, p.y - i, 2.0f + 2.0f * i, 2.0f + 2.0f * i); // [1]
        if (i == 0)
            spinePath.startNewSubPath (p); // if this is the first point, start a new path..
        else
            spinePath.lineTo (p); // ...otherwise add the next point
    }
    // draw an outline around the path that we have created
    g.strokePath (spinePath, juce::PathStrokeType (4.0f));
}

现在运行应用程序，我们应该会看到某个开始像鱼的东西，但它的行为还不像鱼。

那么让我们稍微改变它的动画，以模仿鱼的运动。

void paint (juce::Graphics& g) override
{
    //...
    for (auto i = 0; i < fishLength; ++i)
    {
        auto radius = 100 + 10 * std::sin (getFrameCounter() * 0.1f + i * 0.5f); // [2]
        juce::Point<float> p (getWidth() / 2.0f + 1.0f * radius * std::sin (getFrameCounter() * 0.04f + i * 0.12f),
            getHeight() / 2.0f + 1.0f * radius * std::cos (getFrameCounter() * 0.04f + i * 0.12f));
        //...
    }
    //...
}

这里我们使用正弦函数对圆的半径施加调制，并使用相同的getFrameCounter()函数配合一个标量以及线上每个点略微不同的偏移 [2]。运行应用程序，这应该会给我们一种蛇一样的运动。

运动看起来很有说服力，但显得有点单调，因为它相当快地重复自身，没有惊喜，而且仍在最初的圆形轨迹上。

void paint (juce::Graphics& g) override
{
    //...
    for (auto i = 0; i < fishLength; ++i)
    {
        auto radius = 100 + 10 * std::sin (getFrameCounter() * 0.1f + i * 0.5f);
        juce::Point<float> p (getWidth() / 2.0f + 1.5f * radius * std::sin (getFrameCounter() * 0.02f + i * 0.12f),
            getHeight() / 2.0f + 1.0f * radius * std::cos (getFrameCounter() * 0.04f + i * 0.12f)); // [3]
        //...
    }
    //...
}

如果我们在创建Point时偏移正弦和余弦函数的速率，并为半径的宽度和高度提供不同的比例 [3]，我们可以得到更有说服力的结果。

最后再运行一次应用程序，注意运动随机性的改善。
