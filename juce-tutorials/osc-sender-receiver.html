在应用中实现 OSC 协议

学习如何利用 Open Sound Control 协议通过网络连接多个应用程序。在应用程序之间发送和接收交互数据。

难度：中级
平台：Windows、macOS、Linux、iOS、Android
类：OSCSender、OSCReceiver、OSCReceiver::Listener、OSCReceiver::ListenerWithOSCAddress、OSCMessage、OSCBundle

入门

本教程附带了若干演示项目。这些项目的下载链接会在教程的相关章节中提供。

如果你在每一节的这一步需要帮助，请参阅教程：Projucer 第 1 部分：Projucer 入门。

演示项目

本教程提供的演示项目展示了 OSC 交互所需的几个不同应用程序。概括来说，这些应用程序是：

  • OSC Sender：发送器应用程序包含一个旋钮，并向外发送信息到其他实例。
  • OSC Receiver：接收器应用程序连接到发送器实例，接收信息以进行处理和显示。
  • OSC Monitor：监视器应用程序也连接到发送器实例，但会以更精确的方式监视并记录交互。

为了让本教程正常运行，同一时间只应打开一个发送器和一个接收器/监视器应用程序。 这里展示的代码与 JUCE Examples 中的 OSC 演示应用大致相似。

完成后，OSC 发送器应用程序会显示一个旋钮，启动后我们可以与之交互：

OSC 发送器实现

我们先从实现发送器应用程序开始。

在 MainContentComponent 类中，首先像这样为该应用程序声明私有成员变量：

juce::Slider rotaryKnob; // [1]
juce::OSCSender sender; // [2]
JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (MainContentComponent)
};

添加一个 Slider 对象以捕获用户交互 [1]，以及一个 OSCSender 对象以便稍后连接到接收器 [2]。

在类构造函数中，设置滑块参数并尝试连接网络，如下所示：

MainContentComponent()
{
    rotaryKnob.setRange (0.0, 1.0);
    rotaryKnob.setSliderStyle (juce::Slider::RotaryVerticalDrag);
    rotaryKnob.setTextBoxStyle (juce::Slider::TextBoxBelow, true, 150, 25);
    rotaryKnob.setBounds (10, 10, 180, 180);
    addAndMakeVisible (rotaryKnob); // [3]
// specify here where to send OSC messages to: host URL and UDP port number
if (!sender.connect ("127.0.0.1", 9001)) // [4]
    showConnectionErrorMessage ("Error: could not connect to UDP port 9001.");
setSize (200, 200);
}
  • [3]：设置滑块的范围、样式和边界，并将该 Component 添加到此类的。
  • [4]：这里我们通过调用 OSCSender 对象上的 connect() 函数，尝试连接到 UDP 端口号 9001 上的 localhost 或 IP 地址“127.0.0.1”。如果连接失败，我们会调用稍后声明的私有函数 showConnectionErrorMessage() 向用户显示错误消息。

就本教程而言，我们连接到开发机器的本地网络，使用一个任意的端口号，稍后在接收器中会指定该端口号。

接下来，为 Slider 对象实现 Slider::onValueChange 回调，以便像这样将 OSC 消息发送到接收器应用程序：

rotaryKnob.onValueChange = [this] {
    // create and send an OSC message with an address and a float value:
    if (!sender.send ("/juce/rotaryknob", (float) rotaryKnob.getValue()))
        showConnectionErrorMessage ("Error: could not send OSC message.");
};

在 lambda 函数中，使用 OSCSender 对象上的 send() 函数，以地址和旋钮值发送 OSC 消息 [5]。此处提供的地址“/juce/rotaryknob”让我们稍后能在接收器中对消息进行分类。如果消息发送失败，我们会调用同一个辅助函数 showConnectionErrorMessage() 来显示错误。

我们通过使用函数 AlertWindow::showMessageBoxAsync() 异步地在对话框中显示错误文本来实现该函数：

void showConnectionErrorMessage (const juce::String& messageText)
{
    juce::AlertWindow::showMessageBoxAsync (juce::AlertWindow::WarningIcon,
        "Connection error",
        messageText,
        "OK");
}

发送器实现现在完成了。

这一修改版代码的源代码可以在演示项目的 OSCSenderTutorial_02.h 文件中找到。

OSC 接收器实现

要实现接收器，只需在 MainContentComponent 类中声明一个 Slider 对象，以反映通过发送器旋钮所做的更改：

//==============================================================================
juce::Slider rotaryKnob;
JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (MainContentComponent)
};

与发送器应用程序中将 OSCSender 对象声明为成员不同，这次我们继承自 OSCReceiver，将 MainContentComponent 实现为子类 [1]：

class MainContentComponent : public juce::Component,
                             private juce::OSCReceiver, // [1]
                             private juce::OSCReceiver::ListenerWithOSCAddress<juce::OSCReceiver::MessageLoopCallback> // [2]
{
public:

此外，我们还需要继承自 OSCReceiver::ListenerWithOSCAddress<OSCReceiver::MessageLoopCallback>，以便在收到消息时接收回调 [2]。

在类构造函数中，为 Slider 对象设置与发送器应用程序相同的参数：

MainContentComponent()
{
    rotaryKnob.setRange (0.0, 1.0);
    rotaryKnob.setSliderStyle (juce::Slider::RotaryVerticalDrag);
    rotaryKnob.setTextBoxStyle (juce::Slider::TextBoxBelow, true, 150, 25);
    rotaryKnob.setBounds (10, 10, 180, 180);
    rotaryKnob.setInterceptsMouseClicks (false, false);
    addAndMakeVisible (rotaryKnob);
    // specify here on which UDP port number to receive incoming OSC messages
    if (!connect (9001)) // [3]
        showConnectionErrorMessage ("Error: could not connect to UDP port 9001.");
    // tell the component to listen for OSC messages matching this address:
    addListener (this, "/juce/rotaryknob"); // [4]
    setSize (200, 200);
}

作为 OSCReceiver 的子类，直接连接到正确的端口号以接收消息 [3]，并通过提供要监听的地址，将此类注册为自身的监听器 [4]。

确保端口号和 OSC 地址与发送器应用程序一致。

当收到 OSCMessage 对象时，会调用 oscMessageReceived() 回调函数：

void oscMessageReceived (const juce::OSCMessage& message) override
{
    if (message.size() == 1 && message[0].isFloat32()) // [5]
        rotaryKnob.setValue (juce::jlimit (0.0f, 10.0f, message[0].getFloat32())); // [6]
}

重写此函数时，首先检查消息的大小和值类型 [5]。然后通过确保范围符合 Slider 范围来设置旋钮的值 [6]。

实现与发送器应用程序相同的错误记录函数，以防连接失败：

void showConnectionErrorMessage (const juce::String& messageText)
{
    juce::AlertWindow::showMessageBoxAsync (juce::AlertWindow::WarningIcon,
        "Connection error",
        messageText,
        "OK");
}

现在，当两个应用程序都启动后，你应该能够通过移动发送器旋钮来控制接收器旋钮。

这一修改版代码的源代码可以在演示项目的 OSCReceiverTutorial_02.h 文件中找到。

OSC 监视器实现

我们来实现另一种类型的接收器，将 OSCMessage 对象显示为文本。

在 MainContentComponent 类中，可以看到该类继承自 OSCReceiver::Listener 类 [1]。注意我们没有继承 OSCReceiver::ListenerWithOSCAddress，因为我们想要接收发送的所有消息，而不论地址为何：

class MainContentComponent : public juce::Component,
                             private juce::OSCReceiver::Listener<juce::OSCReceiver::MessageLoopCallback> // [1]
{
public:

将 OSCLogListBox 和 OSCReceiver 对象声明为私有成员变量 [2]，并定义一个临时 int 变量来存储端口号 [3]，如下所示：

OSCLogListBox oscLogListBox; // [2]
juce::OSCReceiver oscReceiver;
int currentPortNumber = -1; // [3]

在构造函数中，如下设置相应的参数：

MainContentComponent()
{
oscLogListBox.setBounds (0, 60, 700, 340); // [4]
addAndMakeVisible (oscLogListBox);
oscReceiver.addListener (this); // [5]
oscReceiver.registerFormatErrorHandler ([this] (const char* data, int dataSize) // [6]
    {
        oscLogListBox.addInvalidOSCPacket (data, dataSize);
    });
setSize (700, 400);
}
  • [4]：设置 OSCLogListBox 的边界并使该 Component 可见。
  • [5]：将此添加为 OSCReceiver 对象的监听器以接收回调。
  • [6]：通过使用 lambda 函数，在 OSCReceiver 上安装自定义的错误处理格式。这里我们将解析失败的数据指针及其大小提供给 OSCLogListBox 对象。

当在监视器应用程序的用户界面上点击按钮时，我们会调用下一步实现的相应函数。

如果用户点击“connect”按钮，它应根据应用程序状态进行连接/断开 [7]。此外，每次按下“connect”按钮时，我们都会调用 updateConnectionStatusLabel() 辅助函数 [8]，如下所示：

void connectButtonClicked()
{
    if (!isConnected()) // [7]
        connect();
    else
        disconnect();
    updateConnectionStatusLabel(); // [8]
}

要更新状态标签，只需根据连接状态更改文本和颜色，如下所述：

void updateConnectionStatusLabel()
{
    juce::String text = "Status: ";
    if (isConnected())
        text += "Connected to UDP port " + juce::String (currentPortNumber);
    else
        text += "Disconnected";
    auto textColour = isConnected() ? juce::Colours::green : juce::Colours::red;

为了确定连接状态，我们检查端口号是否已从其默认值 -1 改变：

bool isConnected() const
{
    return currentPortNumber != -1;
}

否则，当用户按下“clear”按钮时，只需向 OSCLogListBox 发送清除指令并重置屏幕日志：

void clearButtonClicked()
{
    oscLogListBox.clear();
}

要连接到发送器应用程序，我们来实现 connect() 函数：

void connect()
{
    auto portToConnect = portNumberField.getText().getIntValue(); // [9]
    if (!isValidOscPort (portToConnect)) // [10]
    {
        handleInvalidPortNumberEntered();
        return;
    }
    if (oscReceiver.connect (portToConnect)) // [11]
    {
        currentPortNumber = portToConnect;
        connectButton.setButtonText ("Disconnect");
    }
    else // [12]
    {
        handleConnectError (portToConnect);
    }
}
  • [9]：将端口号文本转换为 int 值并存储在临时变量中。
  • [10]：如果端口号无效，我们使用 handleInvalidPortNumberEntered() 辅助函数显示错误消息。
  • [11]：否则，这意味着端口号有效，我们可以尝试连接。如果连接成功，我们将临时端口号变量更新为正确的值，并更改“connect”按钮的文本。
  • [12]：如果连接失败，调用相应的 handleConnectError() 辅助函数来显示错误。

为了验证端口号是否有效，检查其范围是否在 1 .. 65535 之内（含边界）：

bool isValidOscPort (int port) const
{
    return port > 0 && port < 65536;
}

要断开与网络的连接，检查断开是否成功，如果成功，将端口号重置为 -1 并更改“connect”按钮的文本 [13]。否则，调用 handleDisconnectError() 辅助函数 [14]：

void disconnect()
{
    if (oscReceiver.disconnect()) // [13]
    {
        currentPortNumber = -1;
        connectButton.setButtonText ("Connect");
    }
    else
    {
        handleDisconnectError(); // [14]
    }
}

当收到 OSCMessage 时，会调用以下回调函数，我们将消息内容传递给 OSCLogListBox：

void oscMessageReceived (const juce::OSCMessage& message) override
{
    oscLogListBox.addOSCMessage (message);
}

如果收到 OSCBundle，则会调用另一个回调函数，我们将 bundle 的内容传递给 OSCLogListBox：

void oscBundleReceived (const juce::OSCBundle& bundle) override
{
    oscLogListBox.addOSCBundle (bundle);
}

通过为每种错误类型显示消息框来完成实现：

//==============================================================================
void handleConnectError (int failedPort)
{
    juce::AlertWindow::showMessageBoxAsync (juce::AlertWindow::WarningIcon,
        "OSC Connection error",
        "Error: could not connect to port " + juce::String (failedPort),
        "OK");
}
//==============================================================================
void handleDisconnectError()
{
    juce::AlertWindow::showMessageBoxAsync (juce::AlertWindow::WarningIcon,
        "Unknown error",
        "An unknown error occured while trying to disconnect from UDP port.",
        "OK");
}
//==============================================================================
void handleInvalidPortNumberEntered()
{
    juce::AlertWindow::showMessageBoxAsync (juce::AlertWindow::WarningIcon,
        "Invalid port number",
        "Error: you have entered an invalid UDP port number.",
        "OK");
}

总结

在本教程中，我们学习了如何实现 OSC 协议以在应用程序实例之间发送信息。具体来说，我们：

  • 在发送器应用程序中使用旋钮发送了 OSC 消息。
  • 连接到接收器应用程序并处理了相应的消息。
  • 使用监视器应用程序以详细方式显示了 OSC 交互。
