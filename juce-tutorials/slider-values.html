Slider 类

本教程介绍 Slider 类，展示如何响应滑块的移动，以及如何从滑块获取数值。本教程还介绍了一些用滑块显示数值的基本自定义技巧。

难度：初级
平台：Windows、macOS、Linux、iOS、Android
类：Slider、Slider::Listener、Label

本教程是教程：监听器与广播器的后续内容，你应该先阅读并理解那篇教程。

JUCE Slider 类。

本教程展示如何创建滑块、配置它们的范围、监听数值变化，以及以编程方式更新滑块数值。你会注意到，在演示应用程序运行时，两个滑块都包含一个文本框，这个文本框中还包含频率（Hz，赫兹）和时长（s，秒）的单位。

添加滑块

滑块已作为私有成员添加到我们的 MainContentComponent 类中：

private:
    juce::Slider frequencySlider;
    juce::Label frequencyLabel;
    juce::Slider durationSlider;
    juce::Label durationLabel;
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (MainContentComponent)
};

注意我们还为每个 Slider 对象添加了一个 Label 对象。这些标签用于在滑块左侧显示 Frequency 和 Duration 文本。紧挨滑块控件左侧、显示当前滑块数值的方框，实际上是 Slider 对象的一部分。

我们还将 Slider::Listener 类添加为基类，这样我们就可以注册我们的类来接收滑块变化

class MainContentComponent : public juce::Component,
                             public juce::Slider::Listener
{
public:

在我们的 MainContentComponent 构造函数中，我们将滑块添加为子组件（参见教程：父组件与子组件），使它们可见，并配置滑块可以表示的数值范围。首先我们配置 frequencySlider 成员：

MainContentComponent()
{
    addAndMakeVisible (frequencySlider);
    frequencySlider.setRange (50, 5000.0); // [1]
    frequencySlider.setTextValueSuffix (" Hz"); // [2]
    frequencySlider.addListener (this); // [3]
  • [1]：使用 Slider::setRange() 函数设置滑块的范围。
  • [2]：我们为滑块文本框中显示的文本添加后缀，以显示数值的单位。
  • [3]：我们将 MainContentComponent 对象添加为滑块的监听器。

相应的标签设置如下：

addAndMakeVisible (frequencyLabel);
frequencyLabel.setText ("Frequency", juce::dontSendNotification);
frequencyLabel.attachToComponent (&frequencySlider, true); // [4]

Label::attachToComponent() 函数 [4] 对于将标签放置到另一个组件旁边非常有用。第二个参数 true 将标签定位在另一个组件的左侧（false 则会将其定位在上方）。正如我们稍后将看到的，这样我们就不必在 MainContentComponent::resized() 函数中手动定位标签。

durationSlider 和 durationLabel 成员也以类似方式设置，但这个滑块的范围被设置为 frequencySlider 成员范围的倒数：

addAndMakeVisible (durationSlider);
durationSlider.setRange (1.0 / frequencySlider.getMaximum(),
    1.0 / frequencySlider.getMinimum());
durationSlider.setTextValueSuffix (" s");
durationSlider.addListener (this);
addAndMakeVisible (durationLabel);
durationLabel.setText ("Duration", juce::dontSendNotification);
durationLabel.attachToComponent (&durationSlider, true);

定位滑块

滑块在 MainContentComponent::resized() 函数中定位。由于我们使用 Label::attachToComponent() 函数将标签附加到滑块上，这些标签会自动定位在滑块的左侧。

void resized() override
{
    auto sliderLeft = 120;
    frequencySlider.setBounds (sliderLeft, 20, getWidth() - sliderLeft - 10, 20);
    durationSlider.setBounds (sliderLeft, 50, getWidth() - sliderLeft - 10, 20);
}

响应滑块变化

以下代码使滑块的监听器响应滑块数值的变化。

void sliderValueChanged (juce::Slider* slider) override
{
    if (slider == &frequencySlider)
        durationSlider.setValue (1.0 / frequencySlider.getValue(), juce::dontSendNotification);
    else if (slider == &durationSlider)
        frequencySlider.setValue (1.0 / durationSlider.getValue(), juce::dontSendNotification);
}

这是 Slider::Listener::sliderValueChanged() 函数，如果我们将 Slider::Listener 添加为基类，就必须重写它。这里我们只是调用 Slider::setValue() 函数，将一个滑块的倒数传给另一个滑块。我们还告诉滑块不要广播它的变化。这是因为在诸如此类两个滑块相互依赖的情况下，有可能出现无限的反馈循环。dontSendNotification 值打破了这一潜在循环。假设算术是准确的，并且两个方向的转换产生完全相同的结果，那么这应该是不需要的。这是因为只有当数值确实发生变化时，滑块才会向其监听器广播。（在此类情况下，如果转换中存在轻微的舍入误差，就可能出现问题。）你可以尝试省略 dontSendNotification 值，这会导致默认行为，即滑块会广播变化。在你自己的应用程序中针对特定用例，你确实需要仔细考虑是否使用 dontSendNotification。

设置初始值

在构造函数中，frequencySlider 滑块被设为数值 500。这反过来会导致 durationSlider 滑块更新，因为这次我们省略了 dontSendNotification 值：

frequencySlider.setValue (500.0); // [5]

一些自定义

我们可以在这里添加几个简单的自定义，使界面更有效。

让文本框更宽

特别是 durationSlider 滑块的文本框，需要许多位数才能令人满意地显示其数值。为此我们可以使用 Slider::setTextBoxStyle() 函数。将以下两行代码添加到 MainContentComponent 构造函数中：

frequencySlider.setTextBoxStyle (juce::Slider::TextBoxLeft, false, 160, frequencySlider.getTextBoxHeight());
durationSlider.setTextBoxStyle (juce::Slider::TextBoxLeft, false, 160, durationSlider.getTextBoxHeight());

这在每种情况下都将文本框设为 160 像素宽（但通过使用 Slider::getTextBoxHeight() 函数保持高度不变）。

倾斜滑块数值

默认情况下，滑块轨道是线性的，也就是说滑块的数值与滑块拇指沿轨道的位置成正比。从操作界面可以明显看出，这感觉并不太对。我们可以调整滑块的倾斜度，使滑块轨道变为对数式。为此我们可以使用 Slider::setSkewFactorFromMidPoint() 函数。在配置完滑块之后，将以下两行代码添加到 MainContentComponent 构造函数中试试看：

frequencySlider.setSkewFactorFromMidPoint (500);
durationSlider.setSkewFactorFromMidPoint (0.002);

这会将 frequencySlider 滑块轨道的中点设为数值 500，将 durationSlider 滑块的中点设为 0.002。实际上，现在两个滑块看起来会以相同的幅度但相反的方向移动。像这样的非线性滑块轨道很适合时间和频率之类的参数，因为我们通常希望对较小的数值进行更精细的控制，而对较大的数值需要较少的精细控制。

本节完成的代码可以在本教程演示项目的 SliderValuesTutorial_02.h 文件中找到。

练习：尝试为 Slider::setSkewFactorFromMidPoint() 函数的调用使用不同的值，并尝试不同的文本框大小。查看 Slider 类的 API 参考，并尝试一些其他自定义。

简化 Slider 回调

我们可以使用最新 C++ 标准中的 Lambda 函数来简化滑块回调，而不必像本教程所示那样使用监听器与广播器范式。这对于不需要复杂实现的简单回调尤其有效。

首先，让我们移除对 Slider::Listener 类的继承，并像这样恢复 MainContentComponent 类的定义：

class MainContentComponent : public juce::Component
{
public:

然后，不再将 MainContentComponent 添加为 Slider 的监听器，而是像下面这样将一个 Lambda 函数赋值给 Slider::onValueChange 辅助对象：

MainContentComponent()
{
    addAndMakeVisible (frequencySlider);
    frequencySlider.setRange (50, 5000.0);
    frequencySlider.setTextValueSuffix (" Hz");
    frequencySlider.onValueChange = [this] { durationSlider.setValue (1.0 / frequencySlider.getValue(), juce::dontSendNotification); };
    addAndMakeVisible (frequencyLabel);
    frequencyLabel.setText ("Frequency", juce::dontSendNotification);
    frequencyLabel.attachToComponent (&frequencySlider, true);
    addAndMakeVisible (durationSlider);
    durationSlider.setRange (1.0 / frequencySlider.getMaximum(),
        1.0 / frequencySlider.getMinimum());
    durationSlider.setTextValueSuffix (" s");
    durationSlider.onValueChange = [this] { frequencySlider.setValue (1.0 / durationSlider.getValue(), juce::dontSendNotification); };

这告诉 Slider 对象，当用户更改 Slider 的数值时应调用哪个函数。

代码的实现可以在本教程演示项目的 SliderValuesTutorial_03.h 文件中找到。
