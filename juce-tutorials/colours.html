JUCE 中的颜色

以多种方式在应用程序中指定并应用颜色。

难度：初级
平台：Windows、macOS、Linux、iOS、Android
类：Colour、Colours、LookAndFeel

准备工作

在此下载本教程的演示项目：PIP | ZIP。解压项目，然后在 Projucer 中打开第一个头文件。

如果你需要这一步的帮助，请参阅教程：Projucer 第 1 部分：Projucer 入门。

演示项目显示了一些子组件，并执行一些简单的绘制命令，用来演示在 JUCE 中如何指定颜色并将其应用到组件。应用程序应该与下面的截图类似：

本教程的第一部分更一般地讨论颜色的指定。这通过修改演示应用程序中 paint() 函数里的绘制代码来演示。教程的第二部分展示如何为内置组件类型（如标签、滑块等）的元素指定颜色。

颜色与一般绘制操作

JUCE 使用红、绿、蓝和 alpha（透明度）值来指定颜色。这当然是计算领域中广泛使用的颜色指定方法，但所有实现都略有不同。特别是，JUCE 提供了一些有用的颜色操作方法，可以帮助你为应用程序保持一致的调色板。首先，让我们看看演示应用程序中的 paint() 函数：

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::lightgreen);
    g.setColour (juce::Colours::orange);
    auto centralArea = getLocalBounds().toFloat().reduced (10.0f);
    g.drawRoundedRectangle (centralArea, 5.0f, 3.0f);
    juce::Array<juce::Colour> colours { juce::Colours::red, juce::Colours::green, juce::Colours::blue };
    auto colourBarArea = centralArea.reduced (4.0f).withHeight (20.0f);
    auto colourArea = colourBarArea.withWidth (colourBarArea.getWidth() / (float) colours.size());
    for (auto colour : colours)
    {
        g.setColour (colour);
        g.fillRect (colourArea);
        colourArea.translate (colourArea.getWidth(), 0.0f);
    }
}

第一行用单一颜色填充整个图形上下文（也就是整个组件的边界）：

g.fillAll (juce::Colours::lightgreen);

下一行设置给定图形上下文后续绘制操作所使用的颜色。

g.setColour (juce::Colours::orange);

然后我们定义一个略微内缩的矩形，并使用当前颜色绘制一个圆角矩形作为边框：

auto centralArea = getLocalBounds().toFloat().reduced (10.0f);
g.drawRoundedRectangle (centralArea, 5.0f, 3.0f);

接下来，我们建立一个颜色数组，用来绘制一排不同颜色的矩形。

juce::Array<juce::Colour> colours { juce::Colours::red, juce::Colours::green, juce::Colours::blue };

要绘制这一排彩色矩形，我们首先定义它们将放置的区域：

auto colourBarArea = centralArea.reduced (4.0f).withHeight (20.0f);

然后我们定义第一个彩色矩形的区域。它将是 colourBarArea 矩形总宽度按我们使用的颜色数量均分后的一份：

auto colourArea = colourBarArea.withWidth (colourBarArea.getWidth() / colours.size());

最后，我们遍历颜色数组，用指定的颜色填充矩形，并把 colourArea 矩形向右移动，以便进行下一次迭代：

for (auto colour : colours)
{
    g.setColour (colour);
    g.fillRect (colourArea);
    colourArea.translate (colourArea.getWidth(), 0.0f);
}

在接下来的几个示例中，我们将通过更改添加到 colours 数组中的颜色，演示一些指定颜色的方法。

按名称指定颜色

如演示项目和上面的代码所示，在 JUCE 中可以使用 Colours 命名空间中的一些常量来指定颜色。

查看 Colours 命名空间的 API 文档以获取完整列表，其中大多是标准 HTML 颜色。

除了 Colours 命名空间中的常量，你还可以使用 Colours::findColourForName() 函数，通过字符串查找所需的颜色名称。例如，我们可以用下面的代码来填充 colours 数组，得到同样的红、绿、蓝三种颜色：

auto defaultColour = Colours::black;
juce::Array<juce::Colour> colours { juce::Colours::findColourForName ("red", defaultColour),
    juce::Colours::findColourForName ("green", defaultColour),
    juce::Colours::findColourForName ("blue", defaultColour) };

我们需要提供一个默认颜色（这里我们只使用黑色），以防按名称查找颜色失败。

Colours::findColourForName() 函数执行不区分大小写的搜索，并会去掉字符串开头和结尾的空白，但不会去掉字符串内部的空格。例如，尽管颜色在内部以全小写字符串存储，下面的代码仍会按预期工作：

auto defaultColour = juce::Colours::black;
juce::Array<juce::Colour> colours { juce::Colours::findColourForName ("DarkRed", defaultColour),
    juce::Colours::findColourForName ("DarkGreen", defaultColour),
    juce::Colours::findColourForName ("DarkBlue", defaultColour) };

这会生成以下颜色：

但在颜色名称中包含空格会失败，在我们的例子中每种情况都会返回黑色：

auto defaultColour = Colours::black;
juce::Array<juce::Colour> colours { juce::Colours::findColourForName ("Dark Red", defaultColour),
    juce::Colours::findColourForName ("Dark Green", defaultColour),
    juce::Colours::findColourForName ("Dark Blue", defaultColour) };

在这些情况下，编写符合自己需要的函数很直接。例如，你可以编写一个从字符串中删除所有空格的函数：

static juce::String removeSpaces (const juce::String& text)
{
    return text.removeCharacters (" ");
}

并在向 Colours::findColourForName() 函数传入字符串时使用它：

auto defaultColour = juce::Colours::black;
juce::Array<juce::Colour> colours { juce::Colours::findColourForName (removeSpaces ("Dark Red"), defaultColour),
    juce::Colours::findColourForName (removeSpaces ("Dark Green"), defaultColour),
    juce::Colours::findColourForName (removeSpaces ("Dark Blue"), defaultColour) };

通过数值指定颜色

Colours 也可以使用原始的红、绿、蓝和 alpha 值来指定。这里你可以使用 0.0-1.0 范围内的浮点值，或 0-255 之间的整数（类型为 uint8）来创建 Colour 对象。使用整数，我们可以如下创建同样的红、绿、蓝三种颜色：

juce::Array<juce::Colour> colours { juce::Colour (255, 0, 0), // red
    juce::Colour (0, 128, 0), // green
    juce::Colour (0, 0, 255) }; // blue

标准的「绿色」在颜色的绿色分量上并不是最大值 255。

在这种情况下省略 alpha 值会把 alpha 值设为最大值（255），使颜色完全不透明。

我们也可以使用单个十六进制值来指定颜色。在这种情况下，颜色值各元素的顺序是：alpha、红、绿、蓝：

juce::Array<juce::Colour> colours { juce::Colour (0xffff0000), // red
    juce::Colour (0xff008000), // green
    juce::Colour (0xff0000ff) }; // blue

在这种情况下我们必须指定 alpha 值，否则它会被设为零（因而完全透明）。

我们也可以使用 Colour::fromFloatRGBA() 函数来使用浮点值：

juce::Array<juce::Colour> colours { juce::Colour::fromFloatRGBA (1.0f, 0.0f, 0.0f, 1.0f), // red
    juce::Colour::fromFloatRGBA (0.0f, 0.5f, 0.0f, 1.0f), // green
    juce::Colour::fromFloatRGBA (0.0f, 0.0f, 1.0f, 1.0f) }; // blue

整数值 128 大约相当于浮点值 0.501961。因此这里的绿色与上一个例子并不完全相同，但对于本演示来说 0.5 已经足够接近。

尝试不同的颜色值，并通过运行应用程序查看结果。你并不局限于向 colours 数组添加三种颜色，可以使用任意数量的颜色（大于或等于一）。

色相、饱和度和亮度

Colour 对象也可以从色相、饱和度和亮度值初始化。这是一种生成具有某些共同感知特性的不同颜色的方法。

例如，我们可以用下面的代码创建一系列深浅不同的红色：

juce::Array<juce::Colour> colours { juce::Colour::fromHSV (0.0f, // hue
                                        0.5f, // saturation
                                        0.3f, // brightness
                                        1.0f), // alpha
    juce::Colour::fromHSV (0.0f, 0.5f, 0.5f, 1.0f),
    juce::Colour::fromHSV (0.0f, 0.5f, 0.7f, 1.0f) };

这里每种颜色的色相、饱和度和 alpha 值都是恒定的（色相 0.0f 应生成被感知为「红色」的颜色）。结果如下面的截图所示：

我们也可以从 Colour 对象获取色相、饱和度和亮度值。例如，如果我们想要一系列不同亮度的紫色，可以使用下面的代码：

auto purpleHue = juce::Colours::purple.getHue();
juce::Array<juce::Colour> colours { juce::Colour::fromHSV (purpleHue, 0.5f, 0.3f, 1.0f),
    juce::Colour::fromHSV (purpleHue, 0.5f, 0.5f, 1.0f),
    juce::Colour::fromHSV (purpleHue, 0.5f, 0.7f, 1.0f) };

操作颜色值

我们也可以使用已有的颜色来创建新颜色。例如，要制作比现有颜色稍亮或稍暗的颜色，我们可以分别使用 Colour::brighter() 或 Colour::darker() 函数：

auto baseColour = juce::Colours::orange;
juce::Array<juce::Colour> colours { baseColour.darker(),
    baseColour,
    baseColour.brighter() };

或者你可以使用 Colour::interpolatedWith() 函数在两种颜色之间混合：

auto colour1 = juce::Colours::red;
auto colour2 = juce::Colours::purple;
juce::Array<juce::Colour> colours { colour1,
    colour1.interpolatedWith (colour2, 0.5f),
    colour2 };

结果如下面的截图所示：

给定一种颜色，你可以使用 Colour::contrasting() 函数创建另一种在另一种颜色上清晰可见的颜色。这让你可以通过参数指定对比度的大小：

auto baseColour = juce::Colours::darkcyan;
juce::Array<juce::Colour> colours { baseColour,
    baseColour.contrasting (0.5f) };

你甚至可以创建一种与另外两种颜色都形成对比的颜色：

auto colour1 = juce;:Colours::lightblue;
auto colour2 = juce;:Colours::darkred;
juce::Array<juce::Colour> colours { colour1,
    juce::Colour::contrasting (colour1, colour2),
    colour2 };

还可以执行各种其他操作，例如使用 Colour::overlaidWith() 函数在考虑叠加颜色 alpha 通道的情况下混合两种颜色。

指定组件颜色

上一节探讨了在使用组件的 paint() 函数执行自己的绘制操作时颜色的使用。要自定义内置组件（如滑块、标签等）的颜色，你需要使用 Component::setColour() 或 LookAndFeel::setColour() 函数。

本质上，每个内置的 Component 子类都包含一个 enum，列出该组件中可以有特定颜色的各个元素。其中每一项称为一个颜色 ID。（这些颜色 ID 的取值在整个 JUCE 库中是唯一的。）例如，Label 类的颜色 ID 如下（来自 Label::ColourIds）：

  • Label::backgroundColourId：用于填充标签的背景颜色。
  • Label::textColourId：文字的颜色。
  • Label::outlineColourId：用于在标签周围绘制边框的可选颜色。

将其保持透明即可不显示轮廓。

  • Label::backgroundWhenEditingColourId：标签正在编辑时的背景颜色。
  • Label::textWhenEditingColourId：标签正在编辑时的文字颜色。
  • Label::outlineWhenEditingColourId：标签正在编辑时的可选边框颜色。

让我们试着更改其中一些颜色。如果你查看 MainContentComponent 构造函数，会看到添加为子组件的一个 Label、一个 TextEditor、一个 TextButton 和两个 Slider 对象。如下所示添加 [1] 这一行，把标签的文字颜色改为黑色：

设置观感颜色

应用程序或应用程序的某些部分为所有同类型组件要求相同的调色板，这是很常见的。你可能在上一节的练习中发现，为了让两个滑块具有相同的外观，需要对它们重复调用 Component::setColour() 函数。LookAndFeel 类的一个用途就是提供一个统一指定这些颜色的位置。为了说明这一点，把 MainContentComponent 构造函数恢复为如下所示的原始状态：

MainContentComponent()
{
    label.setEditable (true);
    addAndMakeVisible (label);
    textEditor.setText ("This is a text editor.");
    addAndMakeVisible (textEditor);
    textButton.setClickingTogglesState (true);
    addAndMakeVisible (textButton);
    addAndMakeVisible (slider1);
    addAndMakeVisible (slider2);
    setSize (600, 210);
}

现在添加下面这一行 [2]，设置两个滑块手柄的颜色：

//...
getLookAndFeel().setColour (juce::Slider::thumbColourId, juce::Colours::red); // [2]
addAndMakeVisible (slider1);
addAndMakeVisible (slider2);
//...

自定义观感颜色

你也可以从某个 LookAndFeel 类（LookAndFeel_V1、LookAndFeel_V2、LookAndFeel_V3 或 LookAndFeel_V4）派生出子类，并在其构造函数中自定义特定颜色。为此，你可以把下面的类添加为我们的 MainContentComponent 类的嵌套类：

class CustomLookAndFeel : public juce::LookAndFeel_V4
{
public:
    CustomLookAndFeel()
    {
        setColour (juce::Slider::thumbColourId, juce::Colours::red);
    }
};

把这个类的实例添加到我们的私有成员部分 [3]：

private:
    CustomLookAndFeel lf; // [3]
    juce::Label label { {}, "This is some label text." };

并在 MainContentComponent 类的构造函数中设置它使用这个观感 [4]：

MainContentComponent()
{
    setLookAndFeel (&lf); // [4]
    label.setEditable (true);

本小节修改后的代码可以在演示项目的 ColoursTutorial_02.h 文件中找到。

在 CustomLookAndFeel 构造函数中自定义更多颜色。

小结

在本教程中，我们了解了以下可以在你自己的应用程序中使用的内容：

  • 如何使用 Colour 类和 Colours 命名空间在 JUCE 中指定颜色。
  • 在执行绘制操作时，在组件的 paint() 函数中使用颜色。
  • 使用颜色 ID 为内置组件的元素指定颜色。
  • 使用 LookAndFeel 类在应用程序的部分范围或整个应用程序中指定颜色。
