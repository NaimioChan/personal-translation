Android 入门

本教程介绍如何使用 Android Studio 创建基于 JUCE 的项目。

难度：初级
平台：Android

入门

在本教程中，我们将安装并配置使用 Android Studio 应用程序构建基于 JUCE 的应用程序所需的工具。

安装工具与开发套件

在创建面向 Android 的 JUCE 应用程序之前，我们需要一些标准工具、Android SDK 以及 Android NDK（Native Development Kit）。

安装 Android Studio

从以下网址下载 Android Studio：https://developer.android.com/sdk/index.html

下载文件相当大，因此可能需要一些时间（在 macOS 和 Windows 上约为 700MB）。这仅是初始下载，之后还有更多项目需要安装。请做好整个流程耗时较长的准备。下载完成后，请按照“Installing Android Studio”页面上给出的全部说明操作，该页面应在你开始下载后出现。

视操作系统而定，你可能需要将 JDK（Java Development Kit）更新至 7.0 或更高版本。如有必要，系统会提示你安装：在安装过程中（Windows 上），或在首次启动 Android Studio 时（Mac OS X 上）。

执行 Android Studio 的标准安装。在 Windows 上通过安装程序完成，而在 Mac OS X 上，你需要在首次打开 Android Studio 时完成安装。如下方截图所示。

即使在多台实体 Android 设备上测试，使用虚拟设备测试也很有用，因此在出现提示时请选择该选项。

持续点击完成安装过程（点击 Next），直至结束。

安装额外的 SDK

Android Studio 本身已安装完成，现在我们还需要一些额外工具。在 Welcome to Android Studio 窗口中，点击右下角的 Configure 按钮。

然后点击 SDK Manager 按钮。

如果你需要其他 SDK 平台，可以在 SDK Platforms 选项卡中选择所需的平台。目前使用默认值即可。

我们还需要另一项内容，即 Android NDK。它对 JUCE 在 Android 上运行至关重要，因为它提供了用于编写 Android 应用程序的 C/C++ API。你应确保已安装 CMake（构建应用所需）以及用于调试 C/C++ 代码的 LLDB。注意，这些可能已经安装。要安装它们，请在 SDK Manager 中选择 SDK Tools 选项卡，选中相应项目并按下 Apply，如下方截图所示：

确保你的系统（Windows 或 Mac OS X）上至少选中了上方截图中显示为选中的那些项目。如果愿意，安装更多项目也没有问题。完成后点击 Apply 按钮。

使用 Projucer

现在 Android Studio、Android SDK 和 Android NDK 都已安装，我们可以配置 Projucer，让它为我们创建基于 JUCE 的 Android Studio 项目。（如果你不熟悉 Projucer，可以参考 教程：Projucer 第 1 部分：Projucer 入门。）为此，我们需要知道 Android SDK（以及 NDK）的安装位置。

Android SDK 的位置显示在 SDK Manager 窗口的顶部。路径大致如下（其中“username”是你的用户名）：

  • C:\Users\username\AppData\Local\Android\sdk（Windows）
  • /Users/username/Library/Android/sdk（Mac OS X）

从 SDK Manager 窗口将该路径复制到剪贴板（Mac OS X 上为“CMD-C”，Windows 上为“Ctrl-C”）

打开 Projucer 应用程序，导航到菜单项 Projucer > Global Search Paths…。将路径（Mac OS X 上为“CMD-V”，Windows 上为“Ctrl-V”）粘贴到 Android SDK 字段中。按下“Return”后，文本应以白色显示。如下方截图所示：

如果找不到 SDK，或 SDK 未正确安装，Projucer 会将你输入的路径显示为红色。

NDK 位于 SDK 内的 ndk-bundle 目录中。路径大致如下：

  • C:\Users\username\AppData\Local\Android\sdk\ndk-bundle（Windows）
  • /Users/username/Library/Android/sdk/ndk-bundle（Mac OS X）

将附加了 ndk-bundle 目录的 SDK 路径输入到 Global Search Paths 窗口中的 Android NDK 字段。

同样，如果路径正确且 NDK 安装正确，它应显示为白色（否则显示为红色）。

创建 Projucer 项目

现在创建一个新项目。导航到菜单项 File > New Project…。选择 GUI Application 项目类型，为项目选择位置，并确保勾选 Android 目标平台。如下方截图所示：

点击 Create… 按钮。

除非你之前安装了所有 Android SDK，否则需要更改 Projucer 项目中支持的最低 SDK 版本。在左侧栏中选择 Android 导出器，找到 Minimum SDK Version 字段。我们建议输入 23 到 27 之间的值，如下方截图所示：

修改应用程序代码

为了让应用在 Android 设备的屏幕布局上表现良好，你可以对应用程序代码做一处小改动。在 Projucer 中选择 Files 选项卡并选择 Main.cpp。按如下方式更新 MainWindow 构造函数：

//...
MainWindow (juce::String name) : DocumentWindow (name,
                                     juce::Colours::lightgrey,
                                     DocumentWindow::allButtons)
{
    setUsingNativeTitleBar (true);
    setContentOwned (new MainContentComponent(), true);
    setFullScreen (true); // set to fullscreen rather than call centreWithSize()
    setVisible (true);
}
//...

这会使应用程序以全屏方式运行，而不是在窗口内运行（桌面平台上的常规做法）。

在 Android Studio 中打开

现在你可以点击 Projucer 中的 Save Project and Open in IDE… 按钮，在 Android Studio 中打开该项目。Android Studio 应会打开并显示此窗口：

点击 OK 按钮，项目应会导入并打开。如果项目编译失败，请按照说明安装所需的额外 SDK。你可能需要安装较旧版本的 SDK 才能编译该项目。现在你应该能够在 Android Studio 中运行该项目。点击“run”按钮：

Android Studio 会询问你要使用哪台设备。由于这是首次启动该应用，你需要创建虚拟设备来运行它。点击 Create New Virtual Device 按钮设置新设备，并选择你想要的设备。现在你应已拥有虚拟设备，可以在列表中选择它并点击 OK 按钮。（如果你有通过 USB 连接的 Android 设备，也应会在该窗口中看到它。）如下方截图所示：

应用程序现在应会在设备上启动！它看起来大致如下方截图（图中设备已旋转为横向）：

要旋转虚拟设备，使用“Control-F11”逆时针旋转，使用“Control-F12”顺时针旋转。（在 Mac OS X 上你还需要按住“fn”键。）

小结

本教程涵盖了以下主题：

  • 下载并安装 Android Studio。
  • 下载 Android SDK 和 Android NDK。
  • 为 Android Studio 创建 Projucer 项目。
  • 在 Android Studio 中打开 Projucer 生成的项目。
  • 在虚拟（或真实）设备上运行项目。
