使用 FlexBox 与 Grid 实现响应式 GUI 布局

使用 FlexBox 和 Grid 类构建可在不同屏幕尺寸和方向下工作的响应式 GUI 布局。

难度：中级
平台：Windows、macOS、Linux、iOS、Android
类：FlexBox、FlexItem、Grid、GridItem

FlexBox 与 Grid 布局系统

FlexBox 和 Grid 类深受 CSS Web 开发中所用响应式布局实践的启发。如果你以前设计过响应式网站，应该熟悉本节所述的布局系统。

使用 FlexBox 时，我们首先需要把布局方向定义为水平或垂直，之后每次计算都会基于这个方向执行。我们称这个方向为主轴，其垂直对应方向称为交叉轴。基于这一信息，以下属性会如下影响布局：

  • 主轴对齐影响项目沿主轴的位置。
  • 交叉轴对齐影响项目沿交叉轴的位置。
  • 换行在项目于主轴上溢出时执行，方法是向交叉轴溢出。

容器内的项目由 FlexItem 类定义，它有三个影响其动态缩放的弹性属性：

  • flex-grow 定义项目在需要时增长的能力。
  • flex-shrink 定义项目在需要时收缩的能力。
  • flex-basis 定义项目在动态缩放之前的默认尺寸。

作为一个二维布局系统，Grid 同时作用于行轴和列轴。与 FlexBox 类似，以下属性会如下影响布局：

  • 行轴对齐影响项目沿行轴的位置。
  • 列轴对齐影响项目沿列轴的位置。
  • 换行可以在项目于行或列上溢出时执行。

GridItem 对象包含在 Grid 中，它具有影响其尺寸的有用属性：

  • 边距可以为特定项目提供间隙。
  • Span 可以把项目扩展为填满多个网格单元格。

现在我们知道了特定属性会如何影响这些布局系统，可以开始在演示项目中实施这些更改。

使用 FlexItem 和 GridItem 对象

让我们先替换 RightSidePanel::resized() 方法中的按钮布局，改用 FlexBox：

void resized() override
{
    juce::FlexBox fb; // [1]
    fb.flexWrap = juce::FlexBox::Wrap::wrap; // [2]
    fb.justifyContent = juce::FlexBox::JustifyContent::center; // [3]
    fb.alignContent = juce::FlexBox::AlignContent::center; // [4]
    for (auto* b : buttons) // [5]
        fb.items.add (juce::FlexItem (*b).withMinWidth (50.0f).withMinHeight (50.0f));
    fb.performLayout (getLocalBounds()); // [6]
}
  • [1]：我们创建一个 FlexBox 对象。
  • [2]：我们可以指定在溢出时是否希望对象换行。
  • [3]：我们把内容对齐到边界的中心。
  • [4]：我们把内容的对齐方式指定为中心。
  • [5]：我们遍历 TextButton 组件，把它们作为 FlexItem 对象添加到 FlexBox 对象的 items 数组。FlexItem 可以像这里一样被约束，我们设置了按钮的最小宽度和高度。我们也可以分别使用 withMaxWidth() 和 withMaxHeight() 方法设置其最大宽度和高度。
  • [6]：我们对 FlexItem 对象执行布局逻辑，方法是把边界指定给 performLayout() 方法。

至于左侧面板上的旋转滑块布局，我们相应地调整 LeftSidePanel::resized() 方法：

void resized() override
{
    //==============================================================================
    juce::FlexBox knobBox;
    knobBox.flexWrap = juce::FlexBox::Wrap::wrap;
    knobBox.justifyContent = juce::FlexBox::JustifyContent::spaceBetween; // [1]
    for (auto* k : knobs)
        knobBox.items.add (juce::FlexItem (*k).withMinHeight (50.0f).withMinWidth (50.0f).withFlex (1)); // [2]
    //==============================================================================
    juce::FlexBox fb; // [3]
    fb.flexDirection = juce::FlexBox::Direction::column;
    fb.items.add (juce::FlexItem (knobBox).withFlex (2.5)); // [4]
    fb.performLayout (getLocalBounds());
}
  • [1]：这次我们通过指定 JustifyContent::spaceBetween 属性来让项目分散排列。
  • [2]：旋钮以同样的方式添加到 items 数组，并附加 flex-grow 值 1 。flex-grow 因子决定项目应占用的容器内空间量。
  • [3]：创建另一个 FlexBox 作为先前创建的 FlexItem 对象的容器，并用 Direction::column 属性设置弹性布局的主轴。
  • [4]：先前定义的 FlexBox 作为一个 FlexItem 添加到容器 FlexBox 中，flex-grow 因子为 2.5 。

嵌套 FlexBox 对象让我们可以通过把较小的组件组封装在一起，轻松创建复杂的响应式布局。

最后，我们可以在 MainPanel::resized() 方法中让主面板的滑块响应方向变化：

void resized() override
{
    auto isPortrait = getLocalBounds().getHeight() > getLocalBounds().getWidth(); // [1]
    juce::FlexBox fb;
    fb.flexDirection = isPortrait ? juce::FlexBox::Direction::column // [2]
                                  : juce::FlexBox::Direction::row;
    for (auto* s : sliders)
    {
        s->setSliderStyle (isPortrait ? juce::Slider::SliderStyle::LinearHorizontal // [3]
                                      : juce::Slider::SliderStyle::LinearVertical);
        fb.items.add (juce::FlexItem (*s).withFlex (0, 1, isPortrait ? (float) getHeight() / 5.0f // [4]
                                                                     : (float) getWidth() / 5.0f));
    }
    fb.performLayout (getLocalBounds());
}
  • [1]：首先，我们通过检查宽度和高度来确定设备处于纵向还是横向。
  • [2]：接下来，我们可以相应地决定主轴方向并设置相应的属性。
  • [3]：同样，我们设置与设备方向匹配的滑块样式。
  • [4]：把滑块添加到 items 数组时，我们通过在流动方向上确定每个滑块的比例来提供 flex-basis。

滑块现在会适应设备方向并相应地调整方向。

最后，我们也可以把面板的整体布局系统改为使用 flex：

void resized() override
{
    juce::FlexBox fb;
    juce::FlexItem left ((float) getWidth() / 4.0f, (float) getHeight(), leftPanel);
    juce::FlexItem right ((float) getWidth() / 4.0f, (float) getHeight(), rightPanel);
    juce::FlexItem main ((float) getWidth() / 2.0f, (float) getHeight(), mainPanel);
    fb.items.addArray ({ left, main, right });
    fb.performLayout (getLocalBounds());
}

让我们试着改用 Grid 类来实现最后一部分代码。这里我们创建一个 Grid 对象来执行布局操作，就像 flex 一样：

void resized() override
{
    juce::Grid grid;
    using Track = juce::Grid::TrackInfo;
    using Fr = juce::Grid::Fr;
    grid.templateRows = { Track (Fr (1)) };
    grid.templateColumns = { Track (Fr (1)), Track (Fr (2)), Track (Fr (1)) };
    grid.items = { juce::GridItem (leftPanel), juce::GridItem (mainPanel), juce::GridItem (rightPanel) };
    grid.performLayout (getLocalBounds());
}

不过，我们不是在各个 FlexItem 对象上指定 flex-grow、flex-shrink 和 flex-basis 值，而是在这个例子中用 TrackInfo 对象在 Grid 对象上设置行数和列数。约束可以分别使用 _fr 和 _px 后缀以分数或像素指定。在这个例子中，我们定义一个 1 行 3 列的网格，其中中间列占用的空间是其他列的两倍。

JUCE 中的像素不等同于物理像素。内部计算会根据屏幕 DPI 分辨率转换像素密度。

这个修改版本代码的源代码可以在演示项目的 FlexBoxGridTutorial_03.h 文件中找到。

FlexBox 与 Grid 类的优缺点

在许多情况下，这两个类中的任一个都可以用来创建响应式布局。但在某些场景下，其中一个更合适，有时甚至对解决某些布局约束是必要的。

FlexBox 类的一些优点：

  • 适合布局需要主轴方向的组件。
  • 内容换行、方向和缩放都很容易指定。
  • 可以容纳在交叉轴上未对齐的内容。

Grid 类的一些优点：

  • 适合行列对齐的二维网格型布局。
  • 组件的比例可以以分数或像素指定。
  • 可以容纳跨多行或多列的内容。
