添加插件参数

为音频插件添加参数，以便在你的数字音频工作站中进行控制和自动化。学习如何使用音频参数处理音频，并为这些参数创建用户界面。

难度：初级
平台：Windows、macOS、Linux
类：AudioParameterFloat、AudioParameterBool、GenericAudioProcessorEditor

入门

在此处下载本教程的演示项目：PIP | ZIP 。解压该项目，并在 Projucer 中打开第一个头文件。

如果你在这一步需要帮助，请参阅教程：Projucer 第 1 部分：Projucer 入门。

你还应该知道如何使用 JUCE 构建音频插件，并将其加载到你偏好的音频宿主（也称为数字音频工作站——DAW）中。入门介绍请参阅教程：创建基本的音频/MIDI 插件，第 1 部分：设置。

演示项目

演示项目基于 JUCE/examples/Plugins 目录中的 GainPlugin 项目。该插件使用单个参数来改变输入信号的增益。

增益处理器

TutorialProcessor 类中的大部分代码与使用 Audio Plug-In 项目模板时 Projucer 生成的代码相同。为简单起见，我们将处理器代码打包到单个 .h 文件中，而不是拆分到 .cpp 和 .h 文件中。

配置参数

在你的处理器中，应该为每个参数存储音频参数成员。在我们的例子中只有一个：

private:
//==============================================================================
juce::AudioParameterFloat* gain;
//==============================================================================
JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (TutorialProcessor)
};

处理器应在其构造函数中分配并添加插件所需的参数。在这个简单的例子中，我们只需要设置一个参数：

TutorialProcessor()
{
    addParameter (gain = new juce::AudioParameterFloat ("gain", // parameterID
                      "Gain", // parameter name
                      0.0f, // minimum value
                      1.0f, // maximum value
                      0.5f)); // default value
}

基类（AudioProcessor）取得参数对象的所有权，这就是我们在派生处理器类中使用裸指针存储参数的原因。这样做是安全的，因为你可以确定基类会在派生类之后被析构。除此之外，你还可以假定处理器的编辑器组件会在处理器对象之前被删除。

参数 ID应该是该参数的唯一标识符。可以把它想成变量名；它可以包含字母数字字符和下划线，但不能包含空格。参数名称是将显示在屏幕上的名称。

除此之外，AudioParameterFloat 类允许你指定该参数可以表示的取值范围。AudioParameterFloat 类还有一个替代构造函数，允许你改用 NormalisableRange<float> 对象。JUCE 将所有参数值存储在 [0, 1] 范围内，因为这是某些目标插件 API 的限制。我们可以将上面所示的代码改写为：

addParameter (gain = new juce::AudioParameterFloat ("gain", // parameter ID
                  "Gain", // parameter name
                  juce::NormalisableRange<float> (0.0f, 1.0f), // parameter range
                  0.5f)); // default value

在我们的例子中这似乎有点多余（因为参数范围已经在 [0, 1] 之内了！），但使用 NormalisableRange<float> 对象还允许你指定偏斜因子。如果你的插件需要使用表示频率或时间特性的参数，这一点尤其有用，因为这些参数通常最好用非线性映射来表示。

AudioParameterFloat 类还有额外的可选 lambda 函数，可以指定用于在数值与文本之间相互转换。如果你想将参数值显示为字符串，或允许用户输入数值，这一点尤其有用。

执行增益处理

参数创建并添加之后，你的插件就可以与这些参数对象交互。在我们的例子中，我们只是在 TutorialProcessor::processBlock() 函数中获取增益值：

void processBlock (juce::AudioSampleBuffer& buffer, juce::MidiBuffer&) override
{
    buffer.applyGain (*gain);
}

AudioSampleBuffer::applyGain() 函数将我们的增益值应用到缓冲区中所有通道的所有采样上。

这说明了使用音频参数类时应遵循的惯用法：对参数指针解引用以获取参数值。在这个例子中，由于我们使用的是 AudioParameterFloat ，因此得到的是一个 float。

其他 AudioParameterXXX 类的工作方式类似：

  • AudioParameterInt 类处理整数。
  • AudioParameterBool 类处理布尔值。
  • AudioParameterChoice 类处理表示文本选项的字符串数组。

存储与读取参数

除了提供处理音频的例程之外，你还需要提供将插件的整个状态存储到内存块中以及从中读取的方法。这应包括所有参数的当前值，但如有需要也可以包含其他状态信息（例如，如果你的插件要处理文件，它可能会存储文件路径）。

我们这个简单的增益插件只有一样东西需要保存：增益值本身。存储它非常简单，只需以二进制格式写入这个浮点值：

void getStateInformation (juce::MemoryBlock& destData) override
{
    juce::MemoryOutputStream (destData, true).writeFloat (*gain);
}

当插件需要存储其状态时，会调用 AudioProcessor::getStateInformation() 回调。例如，当用户保存其 DAW 项目或保存预设（在某些 DAW 中）时就会发生这种情况。我们可以将任何内容放入传递给该函数的 MemoryBlock 对象中。

AudioProcessor::setStateInformation() 函数需要做相反的事情：它应从某个内存位置读取数据并恢复插件的状态：

void setStateInformation (const void* data, int sizeInBytes) override
{
    *gain = juce::MemoryInputStream (data, static_cast<size_t> (sizeInBytes), false).readFloat();
}

练习：尝试将增益参数存储为字符串，而不是二进制格式。

改进增益处理器

我们可以对这个增益处理器做一些改进：

  • 改变增益会导致信号出现不连续，如果增益被快速调制，就会听到细小的咔嗒声。
  • 使用 XML 存储插件状态更为方便。

平滑增益变化

使用 AudioSampleBuffer 类，我们可以轻松地在缓冲区的整个块大小上执行渐变增益变化。为此，我们需要存储上一个音频回调中的增益参数值。首先，向 TutorialProcessor 类添加一个成员变量 [1]：

private:
//==============================================================================
juce::AudioParameterFloat* gain;
float previousGain; // [1]
//==============================================================================
JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (TutorialProcessor)
};

然后，确保在 TutorialProcessor::preparePlay() 函数中初始化该值：

void prepareToPlay (double, int) override
{
    previousGain = *gain;
}

最后，修改 TutorialProcessor::processBlock() 函数以执行增益渐变：

void processBlock (juce::AudioSampleBuffer& buffer, juce::MidiBuffer&) override
{
    auto currentGain = gain->get();
    if (juce::approximatelyEqual (currentGain, previousGain))
    {
        buffer.applyGain (currentGain);
    }
    else
    {
        buffer.applyGainRamp (0, buffer.getNumSamples(), previousGain, currentGain);
        previousGain = currentGain;
    }
}

你可以看到，如果值没有变化，我们只需应用一个恒定增益。如果值发生了变化，我们就应用增益渐变，然后更新 previousGain 值以供下次使用。

该插件修改版本的源代码可在演示项目的 AudioParameterTutorial_02.h 文件中找到。

练习：修改平滑算法，使其与处理块大小无关。

使用 XML 存储处理器状态

以二进制格式存储插件状态会占用更少的内存和存储空间。然而，使用 XML 或 JSON 这样的格式通常更为方便。这使调试更容易，也简化了让所存储的状态信息与插件未来版本兼容的工作。特别是，XML 使以下操作变得容易：

  • 将信息块中未找到的参数设置为默认值
  • 在信息块中包含版本信息，以帮助处理插件不同版本之间的向前和向后兼容性

要将增益插件的状态存储为 XML，我们可以这样做：

void getStateInformation (juce::MemoryBlock& destData) override
{
    std::unique_ptr<juce::XmlElement> xml (new juce::XmlElement ("ParamTutorial"));
    xml->setAttribute ("gain", (double) *gain);
    copyXmlToBinary (*xml, destData);
}

AudioProcessor::copyXmlToBinary() 函数是一个方便的辅助函数，用于将 XML 转换为二进制数据块。要读取状态，我们可以做相反的操作：

void setStateInformation (const void* data, int sizeInBytes) override
{
    std::unique_ptr<juce::XmlElement> xmlState (getXmlFromBinary (data, sizeInBytes));
    if (xmlState.get() != nullptr)
        if (xmlState->hasTagName ("ParamTutorial"))
            *gain = (float) xmlState->getDoubleAttribute ("gain", 1.0);
}

其中 AudioProcessor::getXmlFromBinary() 函数将由 AudioProcessor::copyXmlToBinary() 函数创建的二进制数据转换回 XML。

重要的是，你可以看到这里进行了错误检查。如果信息块不是 XML，那么该函数将不做任何事。它还会检查标签名“ParamTutorial”，只有在找到该名称时才继续。如果未找到增益参数，增益值也会默认为 1.0。添加版本信息只需为此添加另一个属性。之后，更多的错误检查将让你能够处理不同版本的状态信息。

该插件修改版本的源代码可在演示项目的 AudioParameterTutorial_03.h 文件中找到。

添加相位反转参数

让我们为增益插件添加一个相位反转参数！

添加布尔参数

首先，向 TutorialProcessor 类添加一个 AudioParameterBool* 成员 [2]：

private:
//==============================================================================
juce::AudioParameterFloat* gain;
juce::AudioParameterBool* invertPhase; // [2]
float previousGain;
//==============================================================================
JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (TutorialProcessor)
};

然后我们需要在 TutorialProcessor 构造函数中分配并添加该参数 [3]：

TutorialProcessor()
{
    addParameter (gain = new juce::AudioParameterFloat ("gain", "Gain", 0.0f, 1.0f, 0.5f));
    addParameter (invertPhase = new juce::AudioParameterBool ("invertPhase", "Invert Phase", false)); // [3]
}

当然，布尔参数没有可指定的范围，只有一个默认值。我们需要更新 TutorialProcessor::getStateInformation() 函数 [4]：

void getStateInformation (juce::MemoryBlock& destData) override
{
    std::unique_ptr<juce::XmlElement> xml (new juce::XmlElement ("ParamTutorial"));
    xml->setAttribute ("gain", (double) *gain);
    xml->setAttribute ("invertPhase", *invertPhase); // [4]
    copyXmlToBinary (*xml, destData);
}

以及 TutorialProcessor::setStateInformation() 函数 [5]：

void setStateInformation (const void* data, int sizeInBytes) override
{
    std::unique_ptr<juce::XmlElement> xmlState (getXmlFromBinary (data, sizeInBytes));
    if (xmlState.get() != nullptr)
    {
        if (xmlState->hasTagName ("ParamTutorial"))
        {
            *gain = (float) xmlState->getDoubleAttribute ("gain", 1.0);
            *invertPhase = xmlState->getBoolAttribute ("invertPhase", false); // [5]
        }
    }
}

我们还需要添加音频处理代码：

void processBlock (juce::AudioSampleBuffer& buffer, juce::MidiBuffer&) override
{
    auto phase = *invertPhase ? -1.0f : 1.0f; // [6]
    auto currentGain = *gain * phase; // [7]
    if (juce::approximatelyEqual (currentGain, previousGain))
    {
        buffer.applyGain (currentGain);
    }
    else
    {
        buffer.applyGainRamp (0, buffer.getNumSamples(), previousGain, currentGain);
        previousGain = currentGain;
    }
}

请注意这里：

  • [6]：我们根据 invertPhase 参数的状态选择 +1 或 -1。
  • [7]：我们将其乘以 gain 参数的值。
  • 该函数中其余代码（包括平滑技术）保持不变。

最后，需要在 TutorialProcessor::prepareToPlay() 函数中初始化 previousGain 值：

void prepareToPlay (double, int) override
{
    auto phase = *invertPhase ? -1.0f : 1.0f;
    previousGain = *gain * phase;
}

总结

在本教程中，我们学习了如何在 AudioProcessor 类中使用音频参数。我们特别探讨了：

  • 创建 AudioParameterFloat 对象来表示处理器的可变参数。
  • 使用 AudioParameterFloat 对象中的值来控制音频处理。
  • 在处理器的状态信息中存储和读取参数数据。
  • 使用 AudioParameterBool 对象来表示处于开启或关闭状态的参数。
