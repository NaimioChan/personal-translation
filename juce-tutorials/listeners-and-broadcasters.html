监听器与广播器

本教程介绍 JUCE 中的一个关键概念：监听器与广播器系统。我们通过实现响应按钮点击的简单操作来了解它。

难度：初级
平台：Windows、macOS、Linux、iOS、Android
类：Button、TextButton、Button::Listener、Time

入门

在此处下载本教程的演示项目：PIP | ZIP。解压项目并在 Projucer 中打开第一个头文件。

如果你需要这一步的帮助，请参阅教程：Projucer 第 1 部分：Projucer 入门。

配置界面

MainContentComponent 类由两个子组件组成：一个 TextButton 对象和一个 Label 对象。TextButton 对象可以显示一个包含特定文本的按钮，而 Label 对象可以显示一段文本。

TextButton 类实现了按钮的一种类型。JUCE 中提供了许多类型的 Button 类。更多信息请参阅 ToggleButton、ShapeButton、ImageButton、DrawableButton 和 ArrowButton 类的 API 参考文档。

MainContentComponent 类的声明如下：

class MainContentComponent : public juce::Component
{
public:
    //==============================================================================
    MainContentComponent()
    {
        // ...
    }
    ~MainContentComponent()
    {
        // ...
    }
    void resized() override
    {
        // ...
    }
private:
    juce::TextButton checkTheTimeButton;
    juce::Label timeLabel;
    //==============================================================================
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (MainContentComponent)
};

按钮和标签被添加到 MainContentComponent 对象中，并在 MainContentComponent 构造函数中设为可见：

MainContentComponent()
{
    addAndMakeVisible (checkTheTimeButton);
    checkTheTimeButton.setButtonText ("Check the time...");
    addAndMakeVisible (timeLabel);
    timeLabel.setColour (juce::Label::backgroundColourId, juce::Colours::black);
    timeLabel.setColour (juce::Label::textColourId, juce::Colours::white);
    timeLabel.setJustificationType (juce::Justification::centred);
    setSize (600, 110);
}

这里我们设置按钮文本，并为标签配置特定的外观。这样标签会在黑色背景上显示白色文本。默认情况下，标签不显示任何文本。

添加监听器基类

在 JUCE 中，按钮、滑块以及许多其他可能需要将自身状态变化告知其他对象的控件，都属于广播器对象。为了响应广播器对象的变化，其他类需要成为该类广播器的监听器。监听器还需要注册到至少一个该类型的特定广播器对象。（JUCE 中的广播器-监听器系统遵循观察者模式。）许多广播器对象包含一个嵌套的 Listener 类，我们可以从中继承，从而成为该类广播器的监听器。例如，Button 类为此包含一个嵌套类 Button::Listener。

Button::Listener 类可用于监听任何不同的按钮类型，包括此处所示的 TextButton 类的实例。

要使用 Button::Listener 类，我们需要将它添加为基类。在我们的例子中，需要将 Button::Listener 类添加为 MainContentComponent 类的基类 [1]：

class MainContentComponent : public juce::Component,
                             public juce::Button::Listener // [1]
{
public:

自定义类可以通过同样的方式添加更多监听器基类，从而成为不同类型广播器的监听器。

声明监听器的回调

通常每个监听器类至少有一个纯虚函数。当广播器对象需要广播其变化时，这个函数将作为回调被调用。我们必须重写它，代码才能编译，我们也才能使用它。

监听器类通常还包含其他可以被重写的虚函数，但它们是可选的，因为需要的场合较少。有关示例，请参阅 Slider::Listener 类的文档。

Button::Listener 类中的纯虚函数是 Button::Listener::buttonClicked() 函数。我们需要在 MainContentComponent 类中添加它的声明 [2]，如下所示：

MainContentComponent()
{
    // ...
}
~MainContentComponent()
{
    // ...
}
void resized() override
{
    // ...
}
void buttonClicked (juce::Button* button) override // [2]
{
}
// ...

实现监听器回调

现在，让我们实现 MainContentComponent::buttonClicked() 函数。这里，我们收到一个指向已广播变化的对象的指针。然后我们可以将此指针与其他对象比较，以确定是哪个对象：

void buttonClicked (juce::Button* button) override // [2]
{
    if (button == &checkTheTimeButton) // [3]
    {
        auto currentTime = juce::Time::getCurrentTime(); // [4]
        auto includeDate = true;
        auto includeTime = true;
        auto currentTimeString = currentTime.toString (includeDate, includeTime); // [5]
        timeLabel.setText (currentTimeString, juce::dontSendNotification); // [6]
    }
}
  • [3]：这里我们将传给函数的指针与按钮的地址进行比较，看是否匹配。即使像这里一样只有一个按钮，你也应该这样做。将传给函数的基类 Button 指针与 Button 子类（如此处所示的 TextButton 类）的实例进行比较是安全的。
  • [4]：这里使用 Time 类从操作系统获取当前时间。
  • [5]：这里将 Time 对象转换为可读的字符串。两个 bool 值允许对输出做一些自定义（更多信息请参阅 Time::toString() 函数的文档）。
  • [6]：这里我们更新标签中显示的文本。

dontSendNotification 参数 [7] 阻止标签将此变化广播给它的监听器（如果它有任何监听器的话）。（Label 对象可以拥有监听器，因为它们也可用于编辑文本。）在这种情况下，我们知道它不可能有任何监听器（因为它是我们自己的私有成员），但明确指定是好习惯。

注册为广播器的监听器

为了接收广播的消息，我们需要将监听器对象注册到一个或多个广播器对象。在这种情况下，我们需要注册到 TextButton 对象。通常，这会在监听器子类的构造函数中完成 [7]：

MainContentComponent()
{
    addAndMakeVisible (checkTheTimeButton);
    checkTheTimeButton.setButtonText ("Check the time...");
    checkTheTimeButton.addListener (this); // [7]

大多数广播器对象都有用于此目的的 addListener() 函数（ChangeBroadcaster 对象是个例外，它改用 ChangeBroadcaster::addChangeListener() 函数）。

取消注册为广播器的监听器

广播器也会有一个 removeListener() 函数。例如，参见 Button::removeListener() 函数。由于我们的按钮由执行监听的同一个类拥有，我们并不真的需要移除监听器，因为按钮会与监听器同时销毁。为完整起见，我们可以将它添加到析构函数中：

~MainContentComponent()
{
    checkTheTimeButton.removeListener (this);
}

如果你设置更复杂的广播器-监听器系统，适当地移除监听器很重要。

简化 Button 回调

我们可以使用最新 C++ 标准中的 Lambda 函数来简化按钮回调，而不必像本教程所示那样使用监听器与广播器范式。这对于不需要复杂实现的简单回调尤其有效。

首先，让我们移除对 Button::Listener 类的继承，并像这样恢复 MainContentComponent 类的定义：

class MainContentComponent : public juce::Component
{
public:

然后，不再将 MainContentComponent 添加为 Button 的监听器，而是像下面这样将一个 Lambda 函数赋值给 Button::onClick 辅助对象 [8]：

MainContentComponent()
{
    addAndMakeVisible (checkTheTimeButton);
    checkTheTimeButton.setButtonText ("Check the time...");
    checkTheTimeButton.onClick = [this] { checkTime(); }; // [8]

这告诉 Button 对象，当用户点击 Button 时应调用哪个函数。

最后，将回调函数重命名为 checkTime() [9]，并移除检查 Button 对象指针的 if() 语句，因为我们不再需要检查是哪个 Button 调用了该函数：

void checkTime() // [9]
{
    auto currentTime = juce::Time::getCurrentTime();
    auto includeDate = true;
    auto includeTime = true;
    auto currentTimeString = currentTime.toString (includeDate, includeTime);
    timeLabel.setText (currentTimeString, juce::dontSendNotification);
}

代码的实现可以在本教程演示项目的 ListenersAndBroadcastersTutorial_04.h 文件中找到。

总结

在本教程中，我们介绍了 JUCE 中广播器-监听器系统的基础知识。虽然本教程聚焦于按钮，但同样的技术可以应用于 JUCE 代码的许多领域。我们特别学习了：

  • 如何使用 Time 类访问当前时间。
  • 如何使用 Lambda 函数简化回调。
