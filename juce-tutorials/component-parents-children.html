父组件与子组件

本教程介绍 Component 类的层级特性：一个组件可以包含一个或多个嵌套的子组件。这是在 JUCE 中布局用户界面的关键。

难度：初级
平台：Windows、macOS、Linux、iOS、Android
类：Component、Path、Colours

Component 类的层级结构

大多数用户界面由若干元素组成，例如文本、按钮、滑块、菜单等。例如，下面的截图显示了 AudioDeviceSelectorComponent 类（它用于控制音频硬件设置，更多信息请参阅教程：AudioDeviceManager 类）。其中包含一个按钮、若干标签、若干菜单（组合框）、若干单选按钮，以及一个音频电平指示器。

有些单个用户界面元素也会把其他用户界面元素组合起来，形成更有用的控件。例如，JUCE 的 Slider 类不仅可以包含滑块本身，还可以包含一个显示滑块当前值的文本框。如下面的截图所示：

在这些情况下，把各个元素分离到层级中的不同部分，会更容易设计界面的布局（以及响应用户交互）。有些组件可能使用自己的 paint() 函数来绘制自身。另一些组件可能只是包含其他组件。还有些组件可能既包含其他组件，又执行一些绘制。设计上的选择相当灵活。

MainContentComponent 类

在本教程中，MainContentComponent 类以成员的形式包含另一个组件类的实例。这就是 SceneComponent 类，它负责绘制实际的场景。查看项目中的 MainContentComponent 类。一个 SceneComponent 对象被添加为私有成员：

private:
    SceneComponent scene;
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (MainContentComponent)
};

添加子组件

在 MainContentComponent 构造函数中，这个 SceneComponent 对象被添加为子组件，而 MainContentComponent 对象成为它的父组件。

一个子组件在同一时间只能有一个父组件。如果需要，你可以把子组件从其父组件中移除，然后再添加到另一个父组件中。

为了让子组件显示出来，还需要让它可见。这两个步骤可以分开进行，但在 JUCE 中常见的做法是用 Component::addAndMakeVisible() 函数一步完成这两个操作：

MainContentComponent()
{
    addAndMakeVisible (scene);
    setSize (600, 400);
}

设置子组件的边界

虽然我们的 MainContentComponent 类在构造时设置了自己的尺寸，但许多组件对象最初尺寸为零。调用 Component::setSize() 函数会进而触发对我们 MainContentComponent::resized() 函数的调用。这里是设置任何子组件尺寸和位置的好地方：

void resized() override
{
    scene.setBounds (0, 0, getWidth(), getHeight());
}

这里的关键点是，调用 SceneComponent::setBounds() 函数时的坐标是相对于其父组件的（在本例中是我们的 MainContentComponent 对象）。这意味着父组件的左上角是点 (0, 0)，子组件将以此点为参照来定位其左上角。实际上，我们的 SceneComponent 对象填满了 MainContentComponent 对象的整个内容区域。另一种写法是使用 Component::getLocalBounds() 函数。它返回一个 Rectangle 对象，表示调用它的组件的边界。这样得到的矩形位置为 (0, 0)，尺寸为其宽度和高度。这个 Rectangle 对象随后可以传给 SceneComponent::setBounds() 函数。另一种写法的代码如下：

void resized() override
{
    scene.setBounds (getLocalBounds());
}

本教程的下一节将按照这个 SceneComponent 对象的结构展开。

子组件的位置可能超出父组件的边界，但父组件边界之外的一切都不会被绘制。如果你看不到自己的组件，请确认边界已正确设置（例如，在父组件的 resized() 函数中）。

场景

SceneComponent 类会执行一些自己的绘制，并包含两个子组件（分别表示地板和房子）。SceneComponent 的声明如下：

class SceneComponent : public juce::Component
{
    // ...
private:
    FloorComponent floor;
    HouseComponent house;
    //==============================================================================
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (SceneComponent)
};

FloorComponent 和 HouseComponent 对象在构造函数中被添加并设为可见：

SceneComponent()
{
    addAndMakeVisible (floor);
    addAndMakeVisible (house);
}

为了绘制天空，我们在 SceneComponent::paint() 函数中用浅蓝色填充整个组件。

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::lightblue);
}

地板和房子的边界在 SceneComponent::resized() 函数中定位：

void resized() override
{
    floor.setBounds (10, 297, 580, 5);
    house.setBounds (300, 70, 200, 220);
}

组件先绘制自身，然后子组件绘制在其上。如果需要在子组件之上绘制，可以重写 Component::paintOverChildren() 函数。子组件按照添加到父组件的顺序绘制。之后可以使用 Component::toFront()、Component::toBack()、Component::toBehind() 或 Component::setAlwaysOnTop() 函数调整这个顺序

让我们看看地板和房子在各自的类中是如何绘制的。

地板

地板被绘制为一条绿色的水平线（如同教程：Graphics 类中那样），粗细为五个像素，在组件内垂直居中，并横跨整个宽度。以下是 FloorComponent::paint() 函数（来自 FloorComponent 类）：

void paint (juce::Graphics& g) override
{
    g.setColour (juce::Colours::green);
    g.drawLine (0.0f, (float) getHeight() / 2.0f, (float) getWidth(), (float) getHeight() / 2.0f, 5.0f);
}

房子

房子本身不执行任何自己的绘制（它没有 paint() 函数），而是在 HouseComponent 类中由另外两个组件（表示房子的墙和屋顶）组成：

class HouseComponent : public juce::Component
{
    // ...
private:
    WallComponent wall;
    RoofComponent roof;
    //==============================================================================
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (HouseComponent)
};

WallComponent 和 RoofComponent 对象在构造函数中被添加并设为可见：

HouseComponent()
{
    addAndMakeVisible (wall);
    addAndMakeVisible (roof);
}

它们在 HouseComponent::resized() 函数中按比例定位：

void resized() override
{
    auto separation = juce::jlimit (2, 10, getHeight() / 20); // [1]
    roof.setBounds (0, 0, getWidth(), (int) (getHeight() * 0.2) - separation / 2); // [2]
    wall.setBounds (0, (int) (getHeight() * 0.20) + separation / 2, getWidth(), (int) (getHeight() * 0.80) - separation); // [3]
}
  • [1]：首先我们计算屋顶与墙之间的间隔。我们让它为房子高度的 1⁄20，但不要小于 2 像素——使用 jlimit() 函数。这样即使高度很小，屋顶和墙之间也总会有间隙。当高度较大时，间隙与高度保持比例关系。
  • [2]：屋顶被设为房子的整个宽度以及房子高度的 1/5。这个值会做调整以计入间隔。
  • [3]：墙位于屋顶下方，占据房子高度的 4/5。这也会做调整以计入间隔。

墙

WallComponent 类很简单。它只是在 WallComponent::paint() 函数中用棋盘格图案填充自身（来自 WallComponent 类）：

void paint (juce::Graphics& g) override
{
    g.fillCheckerBoard (getLocalBounds().toFloat(), 30, 10, juce::Colours::sandybrown, juce::Colours::saddlebrown);
}

屋顶

RoofComponent 类使用 Path 对象在 RoofComponent::paint() 函数中绘制一个三角形：

void paint (juce::Graphics& g) override
{
    g.setColour (juce::Colours::red);
    juce::Path roof;
    roof.addTriangle (0.0f, (float) getHeight(), (float) getWidth(), (float) getHeight(), (float) getWidth() / 2.0f, 0.0f);
    g.fillPath (roof);
}

如果我们把 RoofComponent 对象的宽度称为 w、高度称为 h，那么构成三角形的三个点是：(0, h)、(w, h)、(w/2。

添加太阳

让我们给场景添加一个太阳。SunComponent 类中为你提供了若干空函数，我们稍后会向其中添加一些代码。

首先，我们需要对 SceneComponent 类做一些修改。把一个 SunComponent 类的实例添加到私有部分 [4]：

private:
    FloorComponent floor;
    HouseComponent house;
    SunComponent sun; // [4]
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (SceneComponent)
};

然后我们需要添加太阳并使其可见 [5]：

SceneComponent()
{
    addAndMakeVisible (floor);
    addAndMakeVisible (house);
    addAndMakeVisible (sun); // [5]
}

并把太阳定位到右上角 [6]：

void resized() override
{
    floor.setBounds (10, 297, 580, 5);
    house.setBounds (300, 70, 200, 220);
    sun.setBounds (530, 10, 60, 60); // [6]
}

我们需要把绘制代码添加到 SunComponent::paint() 函数中（在 SunComponent 类中）：

void paint (juce::Graphics& g) override
{
    g.setColour (juce::Colours::yellow);
    auto lineThickness = 3.0f;
    g.drawEllipse (lineThickness * 0.5f,
        lineThickness * 0.5f,
        (float) getWidth() - lineThickness * 2,
        (float) getHeight() - lineThickness * 2,
        lineThickness);
}

注意，我们需要把椭圆稍微放在组件边界之内。这应该取决于线宽。这是因为正好落在指定坐标上的是线条的中心。例如，如果我们在组件的边缘上画一条线，那么线宽的一半会落在组件边界之外。看看下面的截图，了解如果我们不稍微调整椭圆的位置和尺寸会发生什么。

另一种解决办法是使用 Component::setPaintingIsUnclipped() 函数，允许组件绘制到其边界之外。请务必阅读 API 文档，因为使用这个函数有一些注意事项。

复用组件

Component 类所用坐标系的主要好处之一是，绘制始终相对于组件的左上角进行。把绘制封装到单独的类中的另一个好处是，它可以很容易地被复用。

例如，我们可以轻松地向 SceneComponent 类再添加一栋房子 [7]：

private:
    FloorComponent floor;
    HouseComponent house;
    HouseComponent smallHouse; // [7]
    SunComponent sun;
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (SceneComponent)
};

然后在 SceneComponent 构造函数中添加它并使其可见 [8]：

SceneComponent()
{
    addAndMakeVisible (floor);
    addAndMakeVisible (house);
    addAndMakeVisible (smallHouse); // [8]
    addAndMakeVisible (sun);
}

并在 SceneComponent::resized() 函数中为它定位 [9]：

void resized() override
{
    floor.setBounds (10, 297, 580, 5);
    house.setBounds (300, 70, 200, 220);
    smallHouse.setBounds (50, 50, 50, 50); // [9]
    sun.setBounds (530, 10, 60, 60);
}

小结

在本教程中，我们介绍了 Component 类所使用的父子层级体系。具体来说，我们学到了：

  • 如何使用 Component::addAndMakeVisible() 函数把子组件添加到其他组件中。
  • 如何相对于父组件定位子组件并设置其尺寸。
  • 组件可以执行自己的绘制、包含执行绘制的子组件，或者两者兼有。
  • 组件先执行自己的绘制，然后子组件按照添加到父组件的顺序绘制。
  • 绘制通常被裁剪到组件的边界内。
