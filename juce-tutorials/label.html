Label 类

本教程介绍 Label 类，它是一个用于显示文本的组件。Label 组件也可以设为可编辑，因此它对于显示文本和简单的文本输入非常有用。

难度：初级
平台：Windows、macOS、Linux、iOS、Android
类：Label、TextEditor、Font、Colours

入门

在此处下载本教程的演示项目：PIP | ZIP。解压项目并在 Projucer 中打开第一个头文件。

如果你需要这一步的帮助，请参阅教程：Projucer 第 1 部分：Projucer 入门。

显示文本

本教程涵盖 Label 类的大部分主要功能。标签最基本的特性是它显示一些文本！虽然你可以在组件的 paint() 函数中绘制自己的文本（参见教程：Graphics 类），但通常使用 Label 对象（某些情况下使用 TextEditor 对象）来管理文本布局要方便得多。

如你所料，Label 对象中的文本可以以任何字体、字号、粗体、斜体等显示。文本还可以在组件边界内左对齐、右对齐、居中、顶部、底部对齐，以及使用各种其他选项。

Label 类只能包含一段使用相同字体、字号和对齐方式的文本。要以不同样式显示多段文本（就像你在文字处理应用程序中看到的那样），请参阅 TextEditor 类。TextEditor 类还可以包含水平和垂直滚动条，以显示大量文本。

如果组件的边界太小，无法显示所请求的全部文本，那么 Label 类会尝试几种方法使文本适应。首先，它会把字体的字形变得稍窄一些。如果字形太窄，文本将无法阅读，因此超过一定程度它就会放弃。在这种情况下，它会截断文本，在末尾显示省略号（…）以表明已执行此操作。你现在就可以在文本输入标签中输入文本「The quick brown fox jumps over the lazy dog」来试试。实际上，你可以从本页复制这段文本（在 Mac OS X 上按「CMD-C」复制，在 Windows 上按「Ctrl-C」复制），然后使用键盘快捷键将其粘贴到标签中（在 Mac OS X 上按「CMD-V」粘贴，在 Windows 上按「Ctrl-V」粘贴）。这一功能是内置的，你无需添加任何代码！

结果应该类似于这样：

原始文本刚好能放下，但在水平方向上被稍微压扁了。大写版本会稍宽一些，因为大写字形通常比小写字形更宽。Label 类判断大写版本太宽，无法在水平方向压扁文本的同时保持其可读性。在这种情况下，它在「LAZY」中的「L」处截断了文本，并添加了省略号。

你可以使用每个 Label 对象的 Label::setMinimumHorizontalScale() 函数来更改文本缩放的幅度。使用值 1.0f 将禁用缩放。你可以使用 Font::getHeight() 函数测量特定字体中单行所需的高度。要测量整个字符串在单行中显示所需的宽度，可以使用 Font::getStringWidth() 函数。

基本标签配置

在 MainContentComponent 构造函数中，应用程序中的每个标签都被配置。首先我们设置标题，使用 16 磅粗体字体、它应包含的文本、文本的颜色，并将文本居中对齐。

将标签添加到父组件：

addAndMakeVisible (titleLabel);

设置标签的字体：

titleLabel.setFont (juce::Font (16.0f, juce::Font::bold));

设置标签中显示的文本：

titleLabel.setText ("Click in the white box to enter some text...", juce::dontSendNotification);

设置标签文本的颜色：

titleLabel.setColour (juce::Label::textColourId, juce::Colours::lightgreen);

对齐标签文本的显示：

titleLabel.setJustificationType (juce::Justification::centred);

Justification::centred 值在垂直和水平轴上都居中文本。查看 Justification 类以了解更多选项。

将标签附加到另一个组件

顾名思义，Label 组件常被用作另一个组件的标签。在这种情况下，Label 对象可以附加到另一个组件。一旦标签被附加，就只需定位拥有者组件。被附加的标签会跟随其拥有者在父组件中移动。在我们的例子中，我们希望 inputLabel 对象（显示 Text input: 文本）附加到 inputText 对象。[Label::attachToComponent()](https://docs.juce.com/master/classLabel.html#a3c2397c0da1249f9e27e2279e0f2d4eb “使此标签「粘附」到另一个组件。”) 函数的第二个参数说明标签应附加到拥有者的左侧还是上方。true 参数表示应附加到左侧：

addAndMakeVisible (inputLabel);
inputLabel.setText ("Text input:", juce::dontSendNotification);
inputLabel.attachToComponent (&inputText, true);
inputLabel.setColour (juce::Label::textColourId, juce::Colours::orange);
inputLabel.setJustificationType (juce::Justification::right);

用于显示大写文本的标签也以类似方式设置：

addAndMakeVisible (uppercaseLabel);
uppercaseLabel.setText ("Uppercase:", juce::dontSendNotification);
uppercaseLabel.attachToComponent (&uppercaseText, true);
uppercaseLabel.setColour (juce::Label::textColourId, juce::Colours::orange);
uppercaseLabel.setJustificationType (juce::Justification::right);
addAndMakeVisible (uppercaseText);
uppercaseText.setColour (juce::Label::backgroundColourId, juce::Colours::darkblue);

在 resized() 函数中，我们只需定位五个标签中的三个：

void resized() override
{
    titleLabel.setBounds (10, 10, getWidth() - 20, 30);
    inputText.setBounds (100, 50, getWidth() - 110, 20);
    uppercaseText.setBounds (100, 80, getWidth() - 110, 20);
}

使标签可编辑

我们在 MainContentComponent 构造函数中设置的最后一个标签是可编辑的文本字段。

addAndMakeVisible (inputText);
inputText.setEditable (true);
inputText.setColour (juce::Label::backgroundColourId, juce::Colours::darkblue);
inputText.onTextChange = [this] { uppercaseText.setText (inputText.getText().toUpperCase(), juce::dontSendNotification); };

使用 Label::setEditable() 函数将标签设为可编辑时，默认行为是单击时显示编辑器。标签也可以改为双击时编辑。如果用户在输入一些文本后点击标签之外的区域，那么即使不按「Return」键，输入也会被确认。如果你愿意，也可以更改这一点，确保用户必须按「Return」键才能确认数据输入。更多信息请参阅此函数的 API 参考。

练习：向界面添加一个按钮，并用它清空文本输入标签。（参见教程：监听器与广播器。）

响应变化

这个 Lambda 函数是 Label::onTextChange 辅助对象的回调。这里我们获取输入的文本，使用 String 类将其转换为大写，并设置 uppercaseText 标签的文本。

inputText.onTextChange = [this] { uppercaseText.setText (inputText.getText().toUpperCase(), dontSendNotification); };

在调用 Label::setText() 时，我们可以使用 sendNotification 而不是 dontSendNotification。除了用户从用户界面更改文本之外，这还会让标签的监听器收到变化通知（前提是文本与其当前内容不同）。

练习：再添加一个标签，用于显示以小写形式输入的文本。

其他自定义

还可以进行一些其他自定义。特别是标签可以显示多行文本。你可能还想自定义可编辑标签的编辑器。

显示多行文本

虽然 TextEditor 类对于大量文本更为灵活，但 Label 类可以显示多行文本。为此，你只需确保组件的高度足够大，能够显示不止一行文本。

为了说明这一点，将以下成员添加到 MainContentComponent 类中：

juce::Label infoLabel;

并将以下代码添加到 MainContentComponent 构造函数中：

addAndMakeVisible (infoLabel);
juce::String infoText;
infoText << "This simple application takes some text input from the user, ";
infoText << "converts it to uppercase, and displays this in another label. ";
infoText << "The application demonstrates a number of useful features of the Label class.";
infoLabel.setText (infoText, juce::dontSendNotification);
infoLabel.setColour (juce::Label::backgroundColourId, juce::Colours::darkblue);

最后，在 resized() 函数中设置 infoLabel 组件的边界：

infoLabel.setBounds (10, 110, getWidth() - 20, getHeight() - 120);

如果你在前面的练习中添加了按钮和另一个标签，可能需要稍微调整边界。

更改编辑器外观

一些编辑器特性可以通过 Label 类本身设置。创建编辑器时，Label 类会将字体样式和颜色复制到编辑器。一些 Label::ColourIds 值与编辑器有关。例如，要更改标签编辑时的边框，你可以为 Component::setColour() 函数使用 Label::outlineWhenEditingColourId 值：

addAndMakeVisible (inputText);
inputText.setEditable (true);
inputText.setColour (juce::Label::backgroundColourId, juce::Colours::darkblue);
inputText.setColour (juce::Label::outlineWhenEditingColourId, juce::Colours::orangered);

其他自定义可以通过实现 Label::onEditorShow 辅助对象来实现。例如，你可以像这样在编辑时让文本变为斜体：

inputText.onEditorShow = [this] {
    auto* editor = inputText.getCurrentTextEditor();
    auto editorFont = editor->getFont();
    editorFont.setItalic (true);
    editor->setFont (editorFont);
};

在实践中——尤其是对于大型应用程序——你可能会使用 LookAndFeel 类来自定义所有组件的外观，以保持应用程序内的一致性。

总结

本教程考察了 Label 类。虽然它非常易于使用，但有许多有用的特性使其功能强大。我们涵盖了：

  • 更改标签中显示文本的字体。
  • 更改标签中显示文本的颜色。
  • 将标签用作简单的文本编辑器并自定义其外观。
  • 显示多行文本。
