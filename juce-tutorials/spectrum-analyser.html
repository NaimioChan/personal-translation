实时可视化信号频率

学习如何使用 DSP 模块的 FFT 类，把输入的音频数据显示为频谱分析器。理解使用窗函数的好处。

难度：中级
平台：Windows、macOS、Linux
类：dsp::FFT, dsp::WindowingFunction, Decibels

窗函数

正如教程：快速傅里叶变换中所见，快速傅里叶变换让我们能够把时间域信号转换为频域，以便处理某个信号的各个频率成分。

然而，傅里叶变换的一个局限是，当它在有限时间间隔内应用时（例如音频应用的音频缓冲区块中），这种变换会表现出所谓的频谱泄漏，即在该频率的两侧开始出现新的频率成分。这是因为信号的采样部分可能没有落在波形的自然周期上，实际上相当于对信号做了截断。

在分析两个频率相近、幅度也相近的正弦波，以及两个频率相差较大、幅度也相差较大的正弦波时，频谱泄漏尤其成问题。当正弦波的频率和幅度都很接近时，泄漏会使它们彼此难以区分。另一方面，如果正弦波的频率和幅度相差很远，最强成分的泄漏会掩盖最弱成分的存在。

为了减小频谱泄漏的影响，我们可以在执行傅里叶变换之前对信号应用窗函数，而根据窗函数类型的不同，对输出的影响也会不同。下面是 JUCE DSP 模块中可用的一些窗函数及其特性：

  • 矩形窗：动态范围最低，分辨率最高。相当于不加窗。
  • Hamming：动态范围一般，分辨率良好。通常用于窄带应用。
  • Hann：动态范围良好，分辨率一般。通常用于窄带应用。
  • Blackman：动态范围最高，分辨率最低。通常用于宽带应用。

处理音频数据

目前我们的应用既不显示也不处理任何输入的音频信号，所以让我们从实现 FFT 开始。

FFT 初始化

在 AnalyserComponent 类中，首先声明一个枚举作为公有成员，为 FFT 实现定义有用的常量：

enum {
    fftOrder = 11, // [1]
    fftSize = 1 << fftOrder, // [2]
    scopeSize = 512 // [3]
};
  • [1]：FFT 阶数指定了 FFT 窗口的大小，它要处理的点数等于 2 的阶数次方。这里我们使用 11 阶，将产生一个 2 ^ 11 = 2048 点的 FFT。
  • [2]：要计算对应的 FFT 大小，我们使用左移位运算符，得到 2048，即二进制数 100000000000。
  • [3]：我们还将频谱可视化表示中的点数设为 512 的示波器尺寸。

接下来，声明 FFT 实现所需的私有成员变量，如下所示：

private:
    juce::dsp::FFT forwardFFT; // [4]
    juce::dsp::WindowingFunction<float> window; // [5]
    float fifo[fftSize]; // [6]
    float fftData[2 * fftSize]; // [7]
    int fifoIndex = 0; // [8]
    bool nextFFTBlockReady = false; // [9]
    float scopeData[scopeSize]; // [10]
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (AnalyserComponent)
};
  • [4]：声明一个 dsp::FFT 对象，用于执行正向 FFT。
  • [5]：同时声明一个 dsp::WindowingFunction 对象，用于对信号应用窗函数。
  • [6]：大小为 2048 的 fifo 浮点数组将保存输入的音频采样数据。
  • [7]：大小为 4096 的 fftData 浮点数组将保存 FFT 计算的结果。
  • [8]：这个临时索引记录 fifo 中的采样数量。
  • [9]：这个临时布尔值告诉我们下一个 FFT 块是否已准备好被渲染。
  • [10]：大小为 512 的 scopeData 浮点数组将保存要在屏幕上显示的点。

现在，在我们的构造函数成员初始化列表中初始化这些变量，如下所示：

AnalyserComponent()
    : forwardFFT (fftOrder),
      window (fftSize, juce::dsp::WindowingFunction<float>::hann)
{

此时必须用正确的阶数显式初始化 FFT 对象，并且可以选择窗函数。这里我们决定使用 Hann 函数，但你也可以随意选择其他的。

在重写的 getNextAudioBlock() 函数中，我们简单地把当前音频缓冲区块中包含的所有采样推入 fifo，以便稍后处理：

void getNextAudioBlock (const juce::AudioSourceChannelInfo& bufferToFill) override
{
    if (bufferToFill.buffer->getNumChannels() > 0)
    {
        auto* channelData = bufferToFill.buffer->getReadPointer (0, bufferToFill.startSample);
        for (auto i = 0; i < bufferToFill.numSamples; ++i)
            pushNextSampleIntoFifo (channelData[i]);
    }
}

要把采样推入 fifo，请按下面的描述实现 pushNextSampleIntoFifo() 函数：

void pushNextSampleIntoFifo (float sample) noexcept
{
    // if the fifo contains enough data, set a flag to say
    // that the next frame should now be rendered..
    if (fifoIndex == fftSize) // [11]
    {
        if (!nextFFTBlockReady) // [12]
        {
            juce::zeromem (fftData, sizeof (fftData));
            memcpy (fftData, fifo, sizeof (fifo));
            nextFFTBlockReady = true;
        }
        fifoIndex = 0;
    }
    fifo[fifoIndex++] = sample; // [12]
}
  • [11]：如果 fifo 中已有足够的数据（这里是 2048 个采样），我们就可以把数据复制到 fftData 数组，交给 FFT 处理。我们还设置一个标志，表示下一帧现在应该被渲染，并总是把索引重置为 0，以便重新开始填充 fifo。
  • [12]：每次调用这个函数时，都会有一个采样被存入 fifo，索引随之递增。

现在 fifo 数据占据了 FFT 输入数组的前半部分，可以处理并显示了。

显示分析器

在 drawNextFrameOfSpectrum() 函数中，按下面的说明插入帧绘制实现：

void drawNextFrameOfSpectrum()
{
    // first apply a windowing function to our data
    window.multiplyWithWindowingTable (fftData, fftSize); // [1]
    // then render our FFT data..
    forwardFFT.performFrequencyOnlyForwardTransform (fftData); // [2]
    auto mindB = -100.0f;
    auto maxdB = 0.0f;
    for (int i = 0; i < scopeSize; ++i) // [3]
    {
        auto skewedProportionX = 1.0f - std::exp (std::log (1.0f - (float) i / (float) scopeSize) * 0.2f);
        auto fftDataIndex = juce::jlimit (0, fftSize / 2, (int) (skewedProportionX * (float) fftSize * 0.5f));
        auto level = juce::jmap (juce::jlimit (mindB, maxdB, juce::Decibels::gainToDecibels (fftData[fftDataIndex]) - juce::Decibels::gainToDecibels ((float) fftSize)),
            mindB,
            maxdB,
            0.0f,
            1.0f);
        scopeData[i] = level; // [4]
    }
}
  • [1]：首先，对输入数据应用窗函数，方法是调用 window 对象上的 multiplyWithWindowingTable() 函数，并把数据作为参数传入。
  • [2]：然后，使用 FFT 对象上的 performFrequencyOnlyForwardTransform() 函数、以 fftData 数组作为参数来渲染 FFT 数据。
  • [3]：现在，在遍历示波器宽度上每个点的 for 循环中，按期望的最小和最大分贝值成比例地计算电平。为此，我们首先需要对 x 轴做倾斜变换，使用对数刻度来更好地表示频率。然后我们可以把这个缩放因子用于取得正确的数组索引，并用幅度值把它映射到 0.0 .. 1.0 的范围。
  • [4]：最后，用正确的幅度设置相应的点，为绘制过程做好准备。

使用定时器回调函数更新分析器，仅当下一个 FFT 块就绪时调用 drawNextFrameOfSpectrum()，重置标志，并使用 repaint() 函数更新 GUI：

void timerCallback() override
{
    if (nextFFTBlockReady)
    {
        drawNextFrameOfSpectrum();
        nextFFTBlockReady = false;
        repaint();
    }
}

最后一步，paint() 回调会在发起 repaint() 请求时调用我们的辅助函数 drawFrame()，帧可以按如下方式绘制：

void drawFrame (juce::Graphics& g)
{
    for (int i = 1; i < scopeSize; ++i)
    {
        auto width = getLocalBounds().getWidth();
        auto height = getLocalBounds().getHeight();
        g.drawLine ({ (float) juce::jmap (i - 1, 0, scopeSize - 1, 0, width),
            juce::jmap (scopeData[i - 1], 0.0f, 1.0f, (float) height, 0.0f),
            (float) juce::jmap (i, 0, scopeSize - 1, 0, width),
            juce::jmap (scopeData[i], 0.0f, 1.0f, (float) height, 0.0f) });
    }
}

这里，对于数组中除第一个点之外的每个点，我们通过把示波器的尺寸映射到屏幕边界的尺寸，在前一个点和当前点之间画一条线。
