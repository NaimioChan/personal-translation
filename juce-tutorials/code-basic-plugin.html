创建一个基础音频/MIDI 插件，第 2 部分（编写插件代码）

本教程接续教程：创建一个基础音频/MIDI 插件，第 1 部分：项目搭建，将带你从一个干净的项目出发，最终得到一个功能完整（虽然相当简单）的插件，它能够响应传入的 MIDI 音符。

难度：中级
平台：Windows、macOS、Linux
插件格式：VST、VST3、AU、Standalone
类：AudioProcessorEditor、AudioProcessor、Slider、MidiMessage、MidiBuffer

准备工作

启动 Projucer，创建一个名为 TutorialPlugin 的新音频插件项目。如果你不记得怎么操作，请参阅教程：Projucer 第 1 部分：Projucer 入门。

整体认识

新建的音频插件项目包含两个主要的类：PluginProcessor 负责音频和 MIDI 的输入输出以及处理逻辑，PluginEditor 负责屏幕上的各种 GUI 控件或可视化显示。

在这两者之间传递信息时，最好把处理器看作编辑器的父级。插件处理器只有一个，而编辑器可以创建多个。每个编辑器都持有对处理器的引用，因此它可以编辑或访问音频线程中的信息和参数。编辑器的职责是在这个处理器线程上设置和获取信息，而不是反过来。

我们要在 PluginProcessor.cpp 文件中修改的主要函数是 processBlock() 方法。它负责接收并向插件输出音频和 MIDI 数据。我们要在 PluginEditor.cpp 文件中修改的主要函数是构造函数，我们在其中初始化并设置窗口和 GUI 对象，另外还有 paint() 方法，我们可以在其中绘制额外的控件和自定义 GUI 组件。

编辑器构造函数目前只有一个方法调用——setSize (400, 300)——它设置插件窗口的大小。让我们为这个简单的应用做一个 (200, 200) 的较小窗口。

TutorialPluginAudioProcessorEditor::TutorialPluginAudioProcessorEditor (TutorialPluginAudioProcessor& p)
    : AudioProcessorEditor (&p), audioProcessor (p)
{
    // This is where our plugin’s editor size is set.
    setSize (200, 200);
}

创建一个简单的 GUI 控件

我们将创建一个滑块对象，用来改变传入的 MIDI 消息的音量。

在编辑器的头文件中新建一个 Slider 对象，名为 midiVolume [1]：

class TutorialPluginAudioProcessorEditor : public juce::AudioProcessorEditor
{
public:
    TutorialPluginAudioProcessorEditor (TutorialPluginAudioProcessor&);
    ~TutorialPluginAudioProcessorEditor();
    //===================================================================
    void paint (juce::Graphics&) override;
    void resized() override;
private:
    // This reference is provided as a quick way for your editor to
    // access the processor object that created it.
    TutorialPluginAudioProcessor& audioProcessor;
    juce::Slider midiVolume; // [1]
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (TutorialPluginAudioProcessorEditor)
};

AudioProcessorEditor 在音频插件中扮演的角色，与主内容组件在独立应用中所扮演的角色相同。参见教程：主组件。

我们可以在编辑器构造函数中用各种函数设置这个滑块的属性。我们还必须调用 addAndMakeVisible (&midiVolume)，把滑块附加到编辑器上。滑块有许多不同的样式和参数，可以在你自己的项目中试用和试验。在本教程中，请调整滑块参数，使编辑器构造函数看起来像这样：

TutorialPluginAudioProcessorEditor::TutorialPluginAudioProcessorEditor (TutorialPluginAudioProcessor& p)
    : AudioProcessorEditor (&p), audioProcessor (p)
{
    // This is where our plugin’s editor size is set.
    setSize (200, 200);
    // these define the parameters of our slider object
    midiVolume.setSliderStyle (juce::Slider::LinearBarVertical);
    midiVolume.setRange (0.0, 127.0, 1.0);
    midiVolume.setTextBoxStyle (juce::Slider::NoTextBox, false, 90, 0);
    midiVolume.setPopupDisplayEnabled (true, false, this);
    midiVolume.setTextValueSuffix (" Volume");
    midiVolume.setValue (1.0);
    // this function adds the slider to the editor
    addAndMakeVisible (&midiVolume);
}

JUCE 窗口有一个名为 resized() 的方法，它会在窗口初始化时被调用一次，此后每当用户改变窗口大小时（如果启用了调整大小）也会被调用。这是设置滑块（以及其他 GUI 组件）大小和位置的好地方，这样它们就可以相对于窗口边界进行定位。

void TutorialPluginAudioProcessorEditor::resized()
{
    // sets the position and size of the slider with arguments (x, y, width, height)
    midiVolume.setBounds (40, 30, 20, getHeight() - 60);
}

我们再把 paint() 函数中的 "Hello World" 文本改成 "Midi Volume"，并把它移到顶部。所有自定义形状和 GUI 元素都在这个函数中绘制到窗口上。

void TutorialPluginAudioProcessorEditor::paint (juce::Graphics& g)
{
    // fill the whole window white
    g.fillAll (juce::Colours::white);
    // set the current drawing colour to black
    g.setColour (juce::Colours::black);
    // set the font size and draw text to the screen
    g.setFont (15.0f);
    g.drawFittedText ("Midi Volume", 0, 0, getWidth(), 30, juce::Justification::centred, 1);
}

你可以进一步了解组件及其 paint() 和 resized() 方法，详见教程：Graphics 类和教程：父组件与子组件。

把控制信息传递给处理器类

我们现在有了一个可以调节的控件，但它实际上什么也没有控制。我们需要拦截传入的 MIDI 数据，用滑块的音量替换音符开启的音量，而这要在处理器中完成。为了让滑块的值能够在处理器线程上控制 MIDI 效果，我们需要在处理器线程上新建一个变量，供滑块修改。

在处理器类的头文件中新建一个名为 noteOnVel 的公有 float 变量。这就是我们将用滑块来设置的变量。

public:
float noteOnVel;

每当滑块发生变化时，我们都需要设置这个值。为此我们使用滑块监听器回调函数。任何类都可以继承滑块监听器功能，但就本教程而言，我们会把这一功能添加到编辑器类中。

关于监听器更深入的说明，请参阅教程：监听器与广播器。

添加继承 [2] 和默认回调函数 [3]，让编辑器类看起来像这样：

class TutorialPluginAudioProcessorEditor : public juce::AudioProcessorEditor,
                                           private juce::Slider::Listener // [2]
{
public:
    TutorialPluginAudioProcessorEditor (TutorialPluginAudioProcessor&);
    ~TutorialPluginAudioProcessorEditor();
    //==================================================================
    // This is just a standard Juce paint method...
    void paint (juce::Graphics& g) override;
    void resized() override;
private:
    void sliderValueChanged (juce::Slider* slider) override; // [3]
    //==================================================================
    // This reference is provided as a quick way for your editor to
    // access the processor object that created it.
    TutorialPluginAudioProcessor& audioProcessor;
    juce::Slider midiVolume;
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (TutorialPluginAudioProcessorEditor)
};

现在我们在编辑器构造函数中为音量滑块添加滑块监听器：

TutorialPluginAudioProcessorEditor::TutorialPluginAudioProcessorEditor (TutorialPluginAudioProcessor& p)
    : AudioProcessorEditor (&p), audioProcessor (p)
{
    // ...
    // add the listener to the slider
    midiVolume.addListener (this);
}

……然后插入监听器函数，用它设置处理器的公有音量变量：

void TutorialPluginAudioProcessorEditor::sliderValueChanged (juce::Slider* slider)
{
    audioProcessor.noteOnVel = midiVolume.getValue();
}

现在我们有了一个滑块，可以控制处理器类中的变量。接下来我们需要用这个处理器变量来改变 MIDI 数据。

修改 MIDI 音符

处理器类中的 processBlock() 方法会实时接收并产生 MIDI 缓冲区和音频缓冲区。我们将遍历 MIDI 缓冲区，拦截 noteOn 类型的信号，并把它们的力度设置为我们滑块的值。

所有 MIDI 消息都会经过这个函数。要在消息经过时修改 MIDI，我们新建一个 MidiBuffer 对象，命名为 processedMidi，把修改后的 MIDI 信号追加到这个新缓冲区，最后再与原始缓冲区交换（这样可以避免直接修改带来的问题）。删除 processBlock() 方法中现有的代码（这些代码处理音频缓冲区，本教程用不到），替换为下面的代码。

void TutorialPluginAudioProcessor::processBlock (juce::AudioBuffer<float>& buffer, juce::MidiBuffer& midiMessages)
{
    buffer.clear();
    juce::MidiBuffer processedMidi;
    for (const auto metadata : midiMessages)
    {
        auto message = metadata.getMessage();
        const auto time = metadata.samplePosition;
        if (message.isNoteOn())
        {
            message = juce::MidiMessage::noteOn (message.getChannel(),
                message.getNoteNumber(),
                (juce::uint8) noteOnVel);
        }
        processedMidi.addEvent (message, time);
    }
    midiMessages.swapWith (processedMidi);
}

在宿主环境中运行插件，你会看到所有经过我们插件的 MIDI 音符开启信号，其力度值都变成了用滑块设定的值。上面的 if() 语句同样可以用来修改其他类型的传入 MIDI 信号，并对它们施加各种变换和效果。借助这些方法，你可以构建更复杂的效果和 GUI。
