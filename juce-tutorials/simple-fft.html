快速傅里叶变换

时间域或空间域的信号可以通过一种称为傅里叶变换的变换公式转换为频域。这种变换函数的一种常见高效实现是快速傅里叶变换（Fast Fourier Transform，FFT），它包含在 JUCE DSP 模块中，我们将在本教程中使用它。

FFT 让我们能够把音频信号分解为它的各个频率，并给出每个频率的幅度和相位信息。使用它的逆函数，我们可以把信号还原到原来的域，这使得它在处理单个频率成分（例如滤波）时非常有用。

由于本教程只涉及显示音频数据而不进行实际的输出处理，我们关注的是正向 FFT 而不是逆向 FFT。

处理音频数据

目前我们的应用既不显示也不处理任何输入的音频信号，所以让我们从实现 FFT 开始。

FFT 初始化

在 SpectrogramComponent 类中，首先为 FFT 实现定义一些有用的常量：

static constexpr auto fftOrder = 10; // [1]
static constexpr auto fftSize = 1 << fftOrder; // [2]
private:
  • [1]：FFT 阶数指定了 FFT 窗口的大小，它要处理的点数等于 2 的阶数次方。这里我们使用 10 阶，将产生一个 2 ^ 10 = 1024 点的 FFT。
  • [2]：要计算对应的 FFT 大小，我们使用左移位运算符，得到 1024，即二进制数 10000000000。

接下来，声明 FFT 实现所需的私有成员变量，如下所示：

juce::dsp::FFT forwardFFT; // [3]
juce::Image spectrogramImage;
std::array<float, fftSize> fifo; // [4]
std::array<float, fftSize * 2> fftData; // [5]
int fifoIndex = 0; // [6]
bool nextFFTBlockReady = false; // [7]
JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (SpectrogramComponent)
};
  • [3]：声明一个 dsp::FFT 对象，用于执行正向 FFT。
  • [4]：大小为 1024 的 fifo 浮点数组将保存输入的音频采样数据。
  • [5]：大小为 2048 的 fftData 浮点数组将保存 FFT 计算的结果。
  • [6]：这个临时索引记录 fifo 中的采样数量。
  • [7]：这个临时布尔值告诉我们下一个 FFT 块是否已准备好被渲染。

现在，在我们的构造函数成员初始化列表中初始化这些变量，如下所示：

SpectrogramComponent()
    : forwardFFT (fftOrder),
      spectrogramImage (juce::Image::RGB, 512, 512, true)
{

此时必须用正确的阶数显式初始化 FFT 对象。

在重写的 getNextAudioBlock() 函数中，我们简单地把当前音频缓冲区块中包含的所有采样推入 fifo，以便稍后处理：

void getNextAudioBlock (const juce::AudioSourceChannelInfo& bufferToFill) override
{
    if (bufferToFill.buffer->getNumChannels() > 0)
    {
        auto* channelData = bufferToFill.buffer->getReadPointer (0, bufferToFill.startSample);
        for (auto i = 0; i < bufferToFill.numSamples; ++i)
            pushNextSampleIntoFifo (channelData[i]);
    }
}

要把采样推入 fifo，请按下面的描述实现 pushNextSampleIntoFifo() 函数：

void pushNextSampleIntoFifo (float sample) noexcept
{
    // if the fifo contains enough data, set a flag to say
    // that the next line should now be rendered..
    if (fifoIndex == fftSize) // [8]
    {
        if (!nextFFTBlockReady) // [9]
        {
            std::fill (fftData.begin(), fftData.end(), 0.0f);
            std::copy (fifo.begin(), fifo.end(), fftData.begin());
            nextFFTBlockReady = true;
        }
        fifoIndex = 0;
    }
    fifo[(size_t) fifoIndex++] = sample; // [9]
}
  • [8]：如果 fifo 中已有足够的数据（这里是 1024 个采样），我们就可以把数据复制到 fftData 数组，交给 FFT 处理。我们还设置一个标志，表示下一行现在应该被渲染，并总是把索引重置为 0，以便重新开始填充 fifo。
  • [9]：每次调用这个函数时，都会有一个采样被存入 fifo，索引随之递增。

现在 fifo 数据占据了 FFT 输入数组的前半部分，可以处理并显示了。

显示频谱图

在 drawNextLineOfSpectrogram() 函数中，按下面的说明插入像素绘制实现：

void drawNextLineOfSpectrogram()
{
    auto rightHandEdge = spectrogramImage.getWidth() - 1;
    auto imageHeight = spectrogramImage.getHeight();
    // first, shuffle our image leftwards by 1 pixel..
    spectrogramImage.moveImageSection (0, 0, 1, 0, rightHandEdge, imageHeight); // [1]
    // then render our FFT data..
    forwardFFT.performFrequencyOnlyForwardTransform (fftData.data()); // [2]
    // find the range of values produced, so we can scale our rendering to
    // show up the detail clearly
    auto maxLevel = juce::FloatVectorOperations::findMinAndMax (fftData.data(), fftSize / 2); // [3]
    juce::Image::BitmapData bitmap { spectrogramImage, rightHandEdge, 0, 1, imageHeight, juce::Image::BitmapData::writeOnly }; // [4]
    for (auto y = 1; y < imageHeight; ++y) // [5]
    {
        auto skewedProportionY = 1.0f - std::exp (std::log ((float) y / (float) imageHeight) * 0.2f);
        auto fftDataIndex = (size_t) juce::jlimit (0, fftSize / 2, (int) (skewedProportionY * fftSize / 2));
        auto level = juce::jmap (fftData[fftDataIndex], 0.0f, juce::jmax (maxLevel.getEnd(), 1e-5f), 0.0f, 1.0f);
        bitmap.setPixelColour (0, y, juce::Colour::fromHSV (level, 1.0f, level, 1.0f)); // [6]
    }
}
  • [1]：首先，使用 Image 对象上的 moveImageSection() 函数把图像向左移动 1 个像素。把图像区域指定为整个宽度减 1 个像素、整个高度。
  • [2]：然后，使用 FFT 对象上的 performFrequencyOnlyForwardTransform() 函数、以 fftData 数组作为参数来渲染 FFT 数据。
  • [3]：找出产生的数值范围，以便缩放渲染结果，清楚地显示出细节。我们可以使用 FloatVectorOperations::findMinAndMax() 函数来完成这一点。
  • [4]：创建一个 BitmapData 实例，指向频谱图图像最右侧的一列像素。在读取或写入图像中的多个像素时，可以使用 BitmapData 实例在内部缓冲像素值，一次性读取或写入全部像素。这种方法通常比使用 Image 的成员函数访问单个像素更快。
  • [5]：现在，在遍历频谱图高度上每个像素的 for 循环中，按采样集成比例地计算电平。为此，我们首先需要对 y 轴做倾斜变换，使用对数刻度来更好地表示频率。然后我们可以把这个缩放因子用于取得正确的数组索引，并用幅度值把它映射到 0.0 .. 1.0 的范围。
  • [6]：最后，用正确的颜色设置相应的像素，以显示 FFT 数据。

最后一步，使用定时器回调函数更新频谱图，仅当下一个 FFT 块就绪时调用 drawNextLineOfSpectrogram()，重置标志，并使用 repaint() 函数更新 GUI：

void timerCallback() override
{
    if (nextFFTBlockReady)
    {
        drawNextLineOfSpectrogram();
        nextFFTBlockReady = false;
        repaint();
    }
}
