ComboBox 类

本教程介绍 ComboBox 类，它是一个用于向用户显示项目列表的组件。可以动态修改 ComboBox 对象的内容，它也可以用于文本输入。

难度：初级
平台：Windows、macOS、Linux、iOS、Android
类：ComboBox、Label、Font、Colour、Colours

入门

在此处下载本教程的演示项目：PIP | ZIP。解压项目并在 Projucer 中打开第一个头文件。

如果你需要这一步的帮助，请参阅教程：Projucer 第 1 部分：Projucer 入门。

演示项目

演示项目在窗口顶部的一个 Label 组件中显示一段文本（参见教程：Label 类）。一个 ComboBox 组件包含 Plain、Bold 和 Italic 这三个项目。用户可以选择其中一项来更改标签中文本的样式。

ComboBox 类

本教程介绍 ComboBox 类的许多功能。ComboBox 组件包含一个文本字符串列表。每个文本字符串都与一个 ID 编号（一个 int 值）相关联。你可以通过以下方式查询当前选中了哪个项目：

  • 使用 ComboBox::getSelectedId() 函数获取当前选中的 ID；或
  • 使用 ComboBox::getText() 函数请求当前显示的文本。

ComboBox 类也是一个广播器。要监听变化，你可以注册一个 ComboBox::Listener 类（参见教程：监听器与广播器），或者使用 Lambda 函数配合 ComboBox::onChange 辅助对象。

让我们查看演示项目。在我们的 MainContentComponent 类中有四个私有成员：

juce::Label textLabel { {}, "The quick brown fox jumps over the lazy dog." };
juce::Font textFont { 12.0f };
juce::ComboBox styleMenu;

Label 和 Font 对象在构造函数中配置：

MainContentComponent()
{
    addAndMakeVisible (textLabel);
    textLabel.setFont (textFont);

添加项目

可以使用 ComboBox::addItem() 函数一次一个地向 ComboBox 对象添加项目。这里我们分别以 ID 编号 1、2 和 3 添加「Plain」「Bold」和「Italic」项目：

// add items to the combo-box
addAndMakeVisible (styleMenu);
styleMenu.addItem ("Plain", 1);
styleMenu.addItem ("Bold", 2);
styleMenu.addItem ("Italic", 3);
styleMenu.onChange = [this] { styleMenuChanged(); };
styleMenu.setSelectedId (1);
setSize (400, 200);
}

响应变化

我们本可以将 MainContentComponent 对象注册为监听器，以便在用户在应用程序中更改 styleMenu 这个 ComboBox 对象时收到通知。但在本例中，我们实现 ComboBox::onChange 辅助对象来直接调用 styleMenuChanged() 函数：

styleMenu.onChange = [this] { styleMenuChanged(); };

styleMenuChanged() 函数处理对 styleMenu 对象的更改：

void styleMenuChanged()
{
    switch (styleMenu.getSelectedId())
    {
        case 1:
            textFont.setStyleFlags (juce::Font::plain);
            break;
        case 2:
            textFont.setStyleFlags (juce::Font::bold);
            break;
        case 3:
            textFont.setStyleFlags (juce::Font::italic);
            break;
        default:
            break;
    }
    textLabel.setFont (textFont);
}

你可以看到，我们根据用户的选择适当地设置了 textFont 这个 Font 对象。然后我们使用该字体来更新 textLabel 这个 Label 对象的字体。

使用项目 ID 编号

你可以使用任何整数作为项目 ID，零除外。零有特殊含义。它用于表示没有选中任何项目（要么尚未选择项目，要么 ComboBox 对象正在显示其他自定义文本）。

当项目数量较少时，在代码中使用 1、2 和 3 这样的简单数字很容易管理。但随着你进一步开发应用，这会很快变得难以管理。在我们的例子中，使用 enum 会更清晰。让我们为样式添加一个私有 enum：

enum FontStyles {
    stylePlain = 1,
    styleBold,
    styleItalic,
    numberOfStyles
};

然后我们可以在设置 ComboBox 对象时使用这些值：

addAndMakeVisible (styleMenu);
// add items to the combo-box
styleMenu.addItem ("Plain", 1);
styleMenu.addItem ("Bold", 2);
styleMenu.addItem ("Italic", 3);
styleMenu.onChange = [this] { styleMenuChanged(); };
styleMenu.setSelectedId (stylePlain);

以及在我们的 styleMenuChanged() 函数中：

void styleMenuChanged()
{
    switch (styleMenu.getSelectedId())
    {
        case stylePlain:
            textFont.setStyleFlags (juce::Font::plain);
            break;
        case styleBold:
            textFont.setStyleFlags (juce::Font::bold);
            break;
        case styleItalic:
            textFont.setStyleFlags (juce::Font::italic);
            break;
    }
    textLabel.setFont (textFont);
}

至少这使代码的可读性大大提高。

使用 ID 编号的其他常见策略包括：

  • 使用数组存储与组合框中项目相关的数据。你可以将 ID 用作数组的索引，但你要么需要让索引 0 空着，要么使用偏移量。例如，你的 ID 可以从 100 开始（100、101、102 等）。ID 100 将对应数组中的索引 0，之后你可以通过加上或减去 100 轻松地在 ID 和索引之间转换。
  • 为应用中的每个组合框使用不同范围内的不同整数批次。例如，你可以为一个组合框使用 ID 100、101、102……，为另一个使用 200、201、202……，依此类推。
  • 使用项目文本的哈希值。你可以使用 String::hashCode() 获取字符串很可能唯一的哈希码。但要注意，这可能返回零（对空字符串使用该函数会返回零的哈希码）。

分区与分隔线

组合框中的项目列表可以包含分隔线和分区标题。这在很长的列表中尤其有用。让我们向应用添加一个用于更改文本颜色的组合框。首先，让我们为颜色添加另一个 enum：

enum TextColours {
    black = 1,
    white,
    red,
    darkred,
    indianred,
    green,
    darkgreen,
    lightgreen,
    blue,
    darkblue,
    lightblue,
    numberOfColours
};

以及向我们的 MainContentComponent 类添加一个新成员：

juce::Label textLabel { {}, "The quick brown fox jumps over the lazy dog." };
juce::Font textFont { 12.0f };
juce::ComboBox styleMenu;
juce::ComboBox coloursMenu;

在 MainContentComponent 构造函数中，我们需要添加代码来设置新的组合框。这里我们介绍两个新函数：ComboBox::addSeparator() 和 ComboBox::addSectionHeading()：

addAndMakeVisible (coloursMenu);
coloursMenu.addItem ("Black", black);
coloursMenu.addItem ("White", white);
coloursMenu.addSeparator();
coloursMenu.addSectionHeading ("Reds");
coloursMenu.addItem ("Red", red);
coloursMenu.addItem ("Dark Red", darkred);
coloursMenu.addItem ("Indian Red", indianred);
coloursMenu.addSeparator();
coloursMenu.addSectionHeading ("Greens");
coloursMenu.addItem ("Green", green);
coloursMenu.addItem ("Dark Green", darkgreen);
coloursMenu.addItem ("Light Green", lightgreen);
coloursMenu.addSeparator();
coloursMenu.addSectionHeading ("Blues");
coloursMenu.addItem ("Blue", blue);
coloursMenu.addItem ("Dark Blue", darkblue);
coloursMenu.addItem ("Light Blue", lightblue);
coloursMenu.onChange = [this] { coloursMenuChanged(); };
coloursMenu.setSelectedId (black);
coloursMenu.setEditableText (true);
setSize (400, 200);
}

你可以使用不带分区标题的分隔线，也可以使用不带分隔线的分区标题，但它们搭配使用效果很好。

分隔线和分区标题无法被选中，也没有关联的 ID 编号。

我们需要实现一个新函数来处理对 coloursMenu 对象的更改：

void coloursMenuChanged()
{
    juce::Colour textColour;
    switch (coloursMenu.getSelectedId())
    {
        case black:
            textColour = Colours::black;
            break;
        case white:
            textColour = Colours::white;
            break;
        case red:
            textColour = Colours::red;
            break;
        case darkred:
            textColour = Colours::darkred;
            break;
        case indianred:
            textColour = Colours::indianred;
            break;
        case green:
            textColour = Colours::green;
            break;
        case darkgreen:
            textColour = Colours::darkgreen;
            break;
        case lightgreen:
            textColour = Colours::lightgreen;
            break;
        case blue:
            textColour = Colours::blue;
            break;
        case darkblue:
            textColour = Colours::darkblue;
            break;
        case lightblue:
            textColour = Colours::lightblue;
            break;
    }
    textLabel.setColour (juce::Label::textColourId, textColour);
}

别忘了在 resized() 函数中设置 coloursMenu 对象的边界：

void resized() override
{
    textLabel.setBounds (10, 10, getWidth() - 20, 20);
    styleMenu.setBounds (10, 40, getWidth() - 20, 20);
    coloursMenu.setBounds (10, 70, getWidth() - 20, 20);
}

文本输入

组合框的默认行为是只允许用户选择列出的项目。但是，你可以让组合框可编辑，从而允许用户输入其他文本。在 MainContentComponent 构造函数中，让我们把 coloursMenu 对象设为可编辑：

coloursMenu.setEditableText (true);

现在让我们添加一个函数，它从 coloursMenu 对象获取文本，并将该文本视为十六进制颜色代码。颜色代码采用 ARGB 格式（例如，“ff888888”将是一种不透明的中灰色）：

juce::Colour handleColourText()
{
    auto menuText = coloursMenu.getText();
    auto valueFromHex = (juce::uint32) menuText.getHexValue32();

    coloursMenu.setText (juce::String::toHexString ((int) valueFromHex));

    return juce::Colour (valueFromHex);
}

注意，我们先将字符串转换为十六进制值，然后再转换回字符串，并设置组合框的文本。这是一种过滤所输入文本的简单方法。

更精细的输入文本过滤方法是实现一个派生自 ComboBox 类的自定义类。然后你可以重写其 Label::Listener::editorShown() 虚函数来自定义其文本编辑器。你可以使用 TextEditor::setInputFilter() 函数，通过 TextEditor::InputFilter 对象在文本出现于屏幕之前就对其进行过滤。

在我们的 coloursMenuChanged() 函数中，我们需要更新 switch..case，在 default 分支中调用 handleColourText() 函数：

void coloursMenuChanged()
{
    juce::Colour textColour;

    switch (coloursMenu.getSelectedId())
    {
        case black:      textColour = juce::Colours::black;      break;
        case white:      textColour = juce::Colours::white;      break;
        case red:        textColour = juce::Colours::red;        break;
        case darkred:    textColour = juce::Colours::darkred;    break;
        case indianred:  textColour = juce::Colours::indianred;  break;
        case green:      textColour = juce::Colours::green;      break;
        case darkgreen:  textColour = juce::Colours::darkgreen;  break;
        case lightgreen: textColour = juce::Colours::lightgreen; break;
        case blue:       textColour = juce::Colours::blue;       break;
        case darkblue:   textColour = juce::Colours::darkblue;   break;
        case lightblue:  textColour = juce::Colours::lightblue;  break;
        default:         textColour = handleColourText();        break;
    }

    textLabel.setColour (juce::Label::textColourId, textColour);
}

运行应用程序，你应该能够以六位十六进制格式（RGB）输入自定义颜色。

练习：修改代码，将任意自定义十六进制颜色添加到 coloursMenu 组合框中，以便用户在需要时可以再次选择这些项目。

禁用和启用项目

组合框中的项目可以被禁用和启用（当然，它们默认是启用的）。禁用后它们仍然可见，但会显示为灰色。

让我们更改代码，使得在选择粗体样式时无法选择任何较浅的颜色（以及白色）。首先，让我们添加一个函数，使用 ComboBox::setItemEnabled() 函数来禁用或启用较浅的颜色：

void setLightColoursEnabled (const bool shouldBeEnabled)
{
    coloursMenu.setItemEnabled (white,      shouldBeEnabled);
    coloursMenu.setItemEnabled (indianred,  shouldBeEnabled);
    coloursMenu.setItemEnabled (lightgreen, shouldBeEnabled);
    coloursMenu.setItemEnabled (lightblue,  shouldBeEnabled);
}

现在让我们重构 styleMenuChanged() 函数，并使用 setLightColoursEnabled() 函数：

void styleMenuChanged()
{
    switch (styleMenu.getSelectedId())
    {
        case stylePlain:  setStylePlain();  break;
        case styleBold:   setStyleBold();   break;
        case styleItalic: setStyleItalic(); break;
    }

    textLabel.setFont (textFont);
}

注意，在 setStyleBold() 函数中我们禁用了较浅的颜色，而在其他情况下需要启用它们。

运行应用程序，你现在应该看到，当选择 Bold 样式时，较浅的颜色被禁用。

练习：这里的一个问题是，你可以先选择一种较浅的颜色，然后选择粗体样式。修改代码，使得当用户选择 Bold 样式时，如果选中了某种较浅的颜色，就将颜色改回 black。
