Point、Line 与 Rectangle 类

使用 Point、Line 和 Rectangle 类来简化你的几何计算。

难度：初级
平台：Windows、macOS、Linux、iOS、Android
类：Point、Line、Rectangle、Path、Random、Range

我们将研究绘制直线和矩形的不同方法，以及 Point、Line 和 Rectangle 类如何简化你在 JUCE 中对绘图操作（以及组件位置）的思考方式。

Rectangle 基础

大量的图形绘制和组件布局代码都需要处理矩形。本教程从绘制一个简单的填充方块开始。现在我们来看看 Point、Line 和 Rectangle 类如何帮助我们完成绘图操作。我们也可以把这些技巧应用到子组件的定位上（在你的 Component::resized() 函数中）。我们在 paint() 函数中的起始代码如下：

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::darkgrey);
    g.setColour (juce::Colours::orange);
    g.fillRect (10, 10, 40, 40);
}

这里我们直接把矩形的边界以单独的整数形式传给 Graphics::fillRect() 函数：

g.fillRect (10, // x
    10, // y
    40, // width
    40); // height

虽然这很直观，但如果把边界指定为一个 Rectangle 对象，对矩形进行各种操作就会容易得多。

使用 Rectangle 和 Point 类

用 Rectangle 对象替换这些单独的坐标、宽度和高度值很容易，如下所示 [1]：

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::darkgrey);
    juce::Rectangle<int> area (10, 10, 40, 40); // [1]
    g.setColour (juce::Colours::orange);
    g.fillRect (area);
}

虽然这是绘制方块的一种非常相似的方式，但现在我们可以非常轻松地在组件边界内移动这个方块，同时保持其原始尺寸。如你所见，Rectangle 类是一个模板类。在这个例子中我们使用 int 模板参数。在 JUCE 绘图代码中，我们通常会使用 Rectangle<int> 或 Rectangle<float> 对象。Point 和 Line 类也是模板类，同样我们通常使用 int 或 float 模板参数。

还有其他创建矩形的方式。例如，我们可能有两个点，想把它们用作矩形的两个角，而不是指定宽度和高度。我们可以使用 Point 类和另一个 Rectangle 构造函数：

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::darkgrey);
    g.setColour (juce::Colours::orange);
    juce::Rectangle<int> area (juce::Point<int> (10, 10),
        juce::Point<int> (50, 50));
    g.fillRect (area);
}

这种技巧的一大好处是我们可以指定任意两个点。这些点不必代表矩形的左上角和右下角。因此，下面这种写法是等价的：

juce::Rectangle<int> area (juce::Point<int> (10, 50),
    juce::Point<int> (50, 10));

使用 Point 和 Path 类

事实上，使用 Path 对象，我们可以用定义每个角的四个点来指定一个矩形：

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::darkgrey);
    g.setColour (juce::Colours::orange);
    juce::Path path;
    path.startNewSubPath (juce::Point<float> (10, 10));
    path.lineTo (juce::Point<float> (50, 10));
    path.lineTo (juce::Point<float> (50, 50));
    path.lineTo (juce::Point<float> (10, 50));
    path.closeSubPath();
    g.fillPath (path);
}

在这种情况下我们需要使用 Point<float> 类，因为 Path 类要求我们这样做。不过我们可以使用 Point<int>::toFloat() 和 Point<float>::toInt() 函数在两种点类型之间转换。

练习：尝试修改路径中的点，创建其他四边形形状。

我们也可以直接把矩形添加到路径中：

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::darkgrey);
    g.setColour (juce::Colours::orange);
    juce::Path path;
    juce::Rectangle<float> area (10, 10, 40, 40);
    path.addRectangle (area);
    g.fillPath (path);
}

在这个例子中我们本可以使用 Rectangle<int> 对象，因为 Path 类会替我们把它转换成浮点版本。

测试点是否在矩形内

Rectangle 对象的另一个有用特性是它可以测试是否包含指定的点。为了试验这一点，我们让组件在每次鼠标点击时重绘自身。为此，添加以下函数：

void mouseDown (const juce::MouseEvent&) override
{
    repaint();
}

现在我们来写 paint() 函数，让它随机生成一个矩形和一个点。然后它会绘制这个矩形，再绘制一个围绕该点的小矩形。这个小矩形会根据随机生成的点是否位于大矩形内而以不同的颜色绘制。我们的 paint() 函数应像之前一样开始，但我们要生成一些随机值，所以也缓存一下系统 Random 对象的引用。

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::darkgrey);
    g.setColour (juce::Colours::orange);
    auto& random = juce::Random::getSystemRandom();

现在我们来创建随机矩形。添加以下代码：

juce::Range<int> rectRange (20, getWidth() / 2);
juce::Rectangle<int> rectArea (random.nextInt (rectRange),
    random.nextInt (rectRange),
    random.nextInt (rectRange),
    random.nextInt (rectRange));
g.drawRect (rectArea, 2);

我们用 Range 对象限制矩形每个元素随机值的范围。我们还以 2 点的粗细绘制（而不是填充）矩形。要绘制较小的矩形，我们需要另一个 Rectangle 对象。如果只给 Rectangle 构造函数传两个参数，它会创建一个位于 (0, 0)、具有指定宽度和高度的 Rectangle 对象（按此顺序）。添加这一行：

juce::Rectangle<int> pointArea (10, 10);

现在我们来随机生成一个点，并把 pointArea 矩形的中心定位到该点。添加以下代码：

juce::Point<int> point (random.nextInt (juce::Range<int> (0, getWidth())),
    random.nextInt (juce::Range<int> (0, getHeight())));
pointArea.setCentre (point);

这展示了 Rectangle 类的另一个有用特性：如果需要，我们可以定位它的中心。有时这比把矩形的位置视为其左上角更可取。现在我们可以使用 Rectangle::contains() 函数来判断 point 对象是否位于 rectArea 对象的边界内。添加以下代码：

g.setColour (rectArea.contains (point) ? juce::Colours::limegreen
                                       : juce::Colours::cornflowerblue);
g.fillRect (pointArea);

处理直线

绘制和处理直线同样直观。以下代码绘制一条对角线：

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::darkgrey);
    g.setColour (juce::Colours::orange);
    juce::Line<float> line (juce::Point<float> (10, 10),
        juce::Point<float> (50, 50));
    g.drawLine (line, 2.0f);
}

直线交点

Line 类也可以执行直线相交测试。为了试验这一点，我们将生成若干随机直线，然后在任何这些直线与其他直线相交的位置绘制一个圆。首先，让我们设置好带背景的 paint() 函数，并准备生成一些随机数：

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::darkgrey);
    g.setColour (juce::Colours::orange);
    auto& random = juce::Random::getSystemRandom();

现在我们来生成随机直线，不仅绘制它们，还把它们存储在一个数组中。添加以下代码：

juce::Range<int> lineRange (0, getWidth());
juce::Array<juce::Line<float>> lines;
auto numLines = 10;
for (auto i = 0; i < numLines; ++i)
{
    juce::Line<float> line ((float) random.nextInt (lineRange),
        (float) random.nextInt (lineRange),
        (float) random.nextInt (lineRange),
        (float) random.nextInt (lineRange));
    lines.add (line);
    g.drawLine (line, 2.0f);
}

然后我们改变颜色，并准备一个方块作为绘制圆的边界。添加：

g.setColour (juce::Colours::palegreen);
juce::Rectangle<float> pointArea (8, 8);

最后，我们遍历直线数组，使用 Line::intersects() 函数检查与其他直线的交点。然后我们把 pointArea 矩形的中心移到这个点并绘制一个圆。为此，添加以下代码：

for (auto lineI : lines)
{
    for (auto lineJ : lines)
    {
        if (lines.indexOf (lineI) != lines.indexOf (lineJ))
        {
            juce::Point<float> intersection;
            if (lineI.intersects (lineJ, intersection)) // [2]
            {
                pointArea.setCentre (intersection);
                g.fillEllipse (pointArea);
            }
        }
    }
}
}

检查交点的这段代码 [2] 调用了 Line::intersects() 函数。它不仅在实际相交时返回 true，还会在 intersection 参数中返回它们相交的点。

现在运行应用程序。如果你保留了响应鼠标点击而重绘的代码，那么可以通过点击组件来生成新的直线组。

这个示例的代码可以在演示项目的 PointLineRectangleTutorial_03.h 文件中找到。

如果我们不检查 bool 这一 Line::intersects() 函数的返回值，或者改用 Line::getIntersection()，那么点会被绘制在直线向两端无限延长后将会相交的位置。例如，看以下代码：

//..
if (lines.indexOf (lineI) != lines.indexOf (lineJ))
{
    juce::Point<float> intersection;
    pointArea.setCentre (lineI.getIntersection (lineJ));
    g.fillEllipse (pointArea);
}
//..

练习：这个示例代码中最后的 for() 循环很简单，但并不理想。问题在于它把每条直线与其他每条直线检查了两次。请重写这段代码，使它只检查每一对直线一次。作为重写的一部分，你应该能够去掉 if (lines.indexOf (lineI) != lines.indexOf (lineJ)) 语句。

操作矩形

现在我们来看一些可以执行的更多矩形操作。在开始之前，让我们添加一个生成随机颜色的简单函数（参见教程：Random 类），因为在接下来的示例中我们会多次用到它：

static juce::Colour getRandomColour()
{
    auto& random = juce::Random::getSystemRandom();
    return juce::Colour ((juce::uint8) random.nextInt (256),
        (juce::uint8) random.nextInt (256),
        (juce::uint8) random.nextInt (256));
}

现在，让我们通过使用 Rectangle 类来扩展绘制矩形的代码：以对角线模式绘制十个方块，并使用随机生成的颜色：

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::darkgrey);
    juce::Rectangle<int> area (10, 10, 40, 40);
    auto numSquares = 10;
    for (auto i = 0; i < numSquares; ++i)
    {
        g.setColour (getRandomColour());
        g.fillRect (area);
        area.translate (30, 30); // [3]
    }
}

Rectangle::translate() 函数 [3] 按提供的水平和垂直偏移量移动给定的矩形。结果应该看起来像下面的截图：

下面是对该代码的扩展，它在下次绘制操作之前调整矩形的大小。除此之外，平移量被设置为等于矩形的宽度和高度。

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::darkgrey);
    juce::Rectangle<int> area (10, 10, 40, 40);
    auto& random = juce::Random::getSystemRandom();
    auto numSquares = 10;
    for (auto i = 0; i < numSquares; ++i)
    {
        g.setColour (getRandomColour());
        g.fillRect (area);
        area.translate (area.getWidth(), area.getHeight()); // [4]
        area.setSize (random.nextInt (juce::Range<int> (20, 40)), // width
            random.nextInt (juce::Range<int> (20, 40))); // height
    }
}

这会使矩形在角处「相连」，如下面的截图所示：

作为使用 Rectangle::translate() 函数的替代方案，我们也可以用加法把点「加」到矩形上来平移它们。这意味着我们可以把上面的 [4] 替换为下面这一行：

area += juce::Point<int> (area.getWidth(), area.getHeight());

矩形相交

如果有相互重叠的矩形，我们可以使用 Rectangle::getIntersection() 函数确定相交区域。在下面的示例中，我们计算序列中当前矩形与下一个矩形之间的相交矩形。为清楚起见，我们为序列中的每个矩形绘制轮廓，并通过把它们绘制为填充矩形来高亮相交区域。

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::darkgrey);
    juce::Rectangle<int> area (10, 10, 40, 40);
    auto& random = juce::Random::getSystemRandom();
    juce::Range<int> rectRandomRange (20, 40);
    auto numSquares = 10;
    for (auto i = 0; i < numSquares; ++i)
    {
        auto nextArea = area + juce::Point<int> (random.nextInt (rectRandomRange), // [5]
                            random.nextInt (rectRandomRange));
        g.setColour (getRandomColour());
        g.fillRect (area.getIntersection (nextArea)); // [6]
        g.setColour (getRandomColour());
        g.drawRect (area, 2); // [7]
        area = nextArea;
    }
}

注意我们用 + 运算符来偏移矩形 [5]。我们还在绘制矩形轮廓 [7] 之前先填充相交区域 [6]。这会导致最后一个相交区域在没有其最终对应矩形的情况下被绘制出来。

这个最终示例的代码可以在演示项目的 PointLineRectangleTutorial_04.h 文件中找到。

总结

在本教程中，我们介绍了模板类 Point、Line 和 Rectangle。特别是，我们涵盖了以下技巧：

  • 创建和操作 Rectangle 对象，并在绘图代码中使用它们。
  • 从角点或通过两个矩形的相交来创建 Rectangle 对象。
  • 创建包含矩形的 Path 对象。
  • 创建 Line 对象、绘制直线，并找出直线相交的点。
