应用程序窗口

本教程演示如何创建一个带有应用程序窗口的最小应用，以及如何自定义该窗口的大小和外观。这对任何 JUCE GUI 应用都至关重要。

难度：初级
平台：Windows、macOS、Linux
类：JUCEApplication, DocumentWindow, ResizableWindow

准备工作

启动 Projucer，创建一个名为 MainWindowTutorial 的新 GUI 应用项目。在 Files to Auto-Generate: 字段中，确保选中 Create a Main.cpp file only。

如果这一步需要帮助，请参阅教程：Projucer 第 1 部分：Projucer 入门。

修改 MainWindowTutorialApplication 类，在其中加入下面的 MainWindow 类：

//==============================================================================
class MainWindowTutorialApplication : public juce::JUCEApplication
{
public:
    //...
    //==============================================================================
    class MainWindow : public juce::DocumentWindow
    {
    public:
        MainWindow (juce::String name) : DocumentWindow (name,
                                             juce::Colours::lightgrey,
                                             DocumentWindow::allButtons)
        {
            centreWithSize (300, 200);
            setVisible (true);
        }
        void closeButtonPressed() override
        {
            juce::JUCEApplication::getInstance()->systemRequestedQuit();
        }
    private:
        JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (MainWindow)
    };
private:
    std::unique_ptr<MainWindow> mainWindow;
};

在 initialise() 函数中添加下面这行：

void initialise (const juce::String& commandLine) override
{
    mainWindow.reset (new MainWindow (getApplicationName()));
}

最后，在 shutdown() 函数中添加下面这行：

void shutdown() override
{
    mainWindow = nullptr;
}

演示项目

演示项目是一个非常精简的 JUCE 应用，只有一个源文件：Main.cpp。它所做的只是创建并显示一个空的应用程序窗口。运行应用时应该会打开这个窗口：

你可以拖动这个窗口，最大化、最小化它，也可以关闭它来退出 JUCE 应用。

这个应用中的 C++ 代码差不多是一个可运行应用所需的最少代码量。应用类本身（派生自 JUCEApplication 类）会在后面的教程中介绍。目前，这个应用真正做的事情只是应用 MainWindowTutorialApplication::initialise() 函数中的那一行代码：

void initialise (const juce::String& commandLine) override
{
    mainWindow.reset (new MainWindow (getApplicationName()));
}

它创建了 MainWindow 类的一个新实例，从而使应用程序窗口显示出来。

你放进应用 initialise() 函数中的任何代码，都会在应用启动时立即执行。

主窗口的实现

MainWindow 类

现在来看看这个 MainWindow 类的实现。它派生自 JUCE 的 DocumentWindow 类，这是一个可调整大小的窗口，带有标题栏以及最大化、最小化和关闭按钮。这些正是你期望从应用程序窗口看到的全部元素。

一般来说，实现应用中不同组件的方式就是这样：创建一个新类，继承自提供所需功能的合适 JUCE 基类。然后在这个新类中，在基类的基础上添加你自己的自定义功能。

MainWindow 构造函数定义如下：

MainWindow (juce::String name) : DocumentWindow (name,
                                     juce::Colours::lightgrey,
                                     DocumentWindow::allButtons)
{
    centreWithSize (300, 200);
    setVisible (true);
}

首先初始化基类（DocumentWindow），它需要三个参数：

  • 将在标题栏中显示的窗口名称。
  • 窗口的背景颜色。
  • 标题栏角落应显示哪些按钮。

查看 Main.cpp 中的代码，你可能会注意到第一个参数实际上是由应用的 initialise() 函数传给 MainWindow 构造函数的。它就是应用的名称（也是创建项目时由 The Projucer 自动生成的信息的一部分，连同应用的版本号以及其他一些内容）。

练习：尝试更改应用标题栏中显示的字符串。

设置背景颜色

接下来的两个参数，即背景颜色和按钮，直接在 MainWindow 构造函数中设置。大多数常用颜色在 JUCE 中都有预定义常量，可以像本例中这样直接使用。因此，你可以用例如 Colours::red 或 Colours::blue 常量替换 Colours::lightgrey 常量，从而快速更改整个应用窗口的背景颜色。当然，也可以定义自己的自定义颜色。有关 JUCE 中颜色的更详细介绍，请参阅教程：JUCE 中的颜色。

使用位掩码参数指定按钮

传给 DocumentWindow 基类构造函数的第三个参数是 DocumentWindow::allButtons 常量。它表示标题栏中应显示全部三个默认按钮（最大化、最小化和关闭）。你可以使用 enum DocumentWindow::TitleBarButtons 中定义的以下其他常量来更改这一属性：

  • DocumentWindow::minimiseButton
  • DocumentWindow::maximiseButton
  • DocumentWindow::closeButton

使用 C++ 运算符 |（按位或运算符），你可以定义这三个可能按钮的任意其他组合。例如，要只显示关闭和最小化按钮，可以这样写：

MainWindow (juce::String name) : DocumentWindow (name,
                                     juce::Colours::lightgrey,
                                     DocumentWindow::closeButton | DocumentWindow::minimiseButton)
{
    centreWithSize (300, 200);
    setVisible (true);
}

这种向函数传递一组标志组合的做法称为位掩码，在 JUCE 的许多其他地方也能见到。

设置窗口大小

创建 MainWindow 对象时，会执行构造函数的主体。第一条语句调用 Component::centreWithSize() 函数来设置窗口的位置和大小。第二条语句调用 Component::setVisible() 函数，要让窗口在创建后显示出来，这一调用总是必需的。

使用 Component::centreWithSize() 函数，你可以以像素为单位指定窗口的初始宽度和高度。该函数会把大小设为指定值，然后相对于其父组件将组件居中。DocumentWindow 类派生自 TopLevelWindow 类，后者没有父组件，因此它会相对于整个屏幕居中。

你可能希望为窗口指定其他位置。在这种情况下，Component::setBounds() 函数提供了更多选项。要试一试，请把包含 centreWithSize() 函数调用的那一行改成：

setBounds (50, 50, 800, 600);

这会把大小设为 800 x 600 像素，并把窗口放在更靠近屏幕左上角的位置（距屏幕边缘 50 像素）。

练习：使用 Component::setBoundsRelative() 函数，相对于屏幕大小（而不是绝对像素）来设置位置和大小。

你可以在教程：父组件和子组件中进一步了解大小、边界和位置。

其他自定义选项

让窗口可调整大小

JUCE 的 DocumentWindow 类本身继承自 ResizableWindow 类。这个基类增加了让用户调整窗口大小的功能。可以通过 ResizableWindow::setResizable() 函数启用它。

在 MainWindow 构造函数中添加下面这行：

setResizable (true, true);

查看 ResizableWindow::setResizable() 函数的文档，了解它的两个布尔参数的含义。第一个参数决定窗口是否可调整大小。第二个参数让你在右下角添加一个用于调整窗口大小的手柄。如果这个参数为 false，则改为通过用鼠标拖动窗口的任意边缘来调整窗口大小。

使用原生标题栏

到目前为止，我们一直为应用的主窗口使用 JUCE 观感。它的主要优势是在每个桌面操作系统（Windows、Mac OS X 和 Linux）上外观和行为都完全一致。

不过，JUCE 的 DocumentWindow 类允许窗口使用你所运行操作系统的典型原生窗口外观。这通过 DocumentWindow::setUsingNativeTitleBar() 函数实现。在 MainWindow 构造函数中添加下面这行：

setUsingNativeTitleBar (true);

对大多数应用来说，原生观感是主应用窗口更好的选择，因为这是用户通常期望原生应用具有的更熟悉的观感。

更多自定义选项

练习：查看 DocumentWindow 和 ResizableWindow 类的文档。尝试使用本教程未涉及的其他函数，它们可以自定义应用窗口的其他方面。

小结

在本教程中，我们介绍了如何设置基本 JUCE 应用主窗口的行为，例如：调整其大小、使其可调整大小、设置其标题和外观，以及定义标题栏中应出现哪些按钮。我们还介绍了如何切换到原生标题栏，让窗口在所运行的操作系统上更像原生窗口。

备注

  • 以后你可能会想构建更复杂的应用，由多个不同的窗口组成。你可以用同样的技术控制每一个窗口的行为。
