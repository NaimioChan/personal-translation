将 UndoManager 与 ValueTree 配合使用

在你的应用程序中实现撤销/重做操作。使用 UndoableAction 对象轻松恢复之前的中间状态，并了解如何将可撤销操作分组为事务。

难度：中级
平台：Windows、macOS、Linux
类：UndoManager、UndoableAction、ValueTree、TreeView、TreeViewItem

入门

本教程假定你已基本了解 ValueTree 对象，相关内容在教程：ValueTree 类中有所说明。如果你还没有读过，应该先阅读那篇教程。

在此处下载本教程的演示项目：PIP | ZIP 。解压该项目，并在 Projucer 中打开第一个头文件。

如果你在这一步需要帮助，请参阅教程：Projucer 第 1 部分：Projucer 入门。

目前，我们可以拖放 ValueTree 节点并更改数据结构的层级。我们也可以展开和折叠子节点，但无法撤销和重做所做的更改。让我们尝试使用 UndoManager 类来实现该功能。

添加撤销/重做按钮

让我们首先向用户界面添加两个 TextButton 对象，以实现撤销和重做功能。你应该熟悉 lambda 函数，如果你在这些步骤上需要帮助，可以参考教程：监听器与广播器。

在 MainContentComponent 类中，为每个按钮声明 TextButton 变量 [1]：

juce::TreeView tree;
juce::TextButton undoButton, redoButton; // [1]
std::unique_ptr<ValueTreeItem> rootItem;

在构造函数的成员初始化列表中，为 TextButton 对象设置文本 [2]：

MainContentComponent()
    : undoButton ("Undo"),
      redoButton ("Redo") // [2]
{

最后，让按钮可见 [3]，并准备要分配给 Button::onClick 辅助对象的 lambda 函数 [4]：

//...
addAndMakeVisible (undoButton);
addAndMakeVisible (redoButton); // [3]
undoButton.onClick = [this] {};
redoButton.onClick = [this] {}; // [4]
setSize (600, 400);

然后我们可以在 resized() 方法中设置按钮的边界：

void resized() override
{
    // This is called when the MainContentComponent is resized.
    // If you add any child components, this is where you should
    // update their positions.
    auto r = getLocalBounds();
    auto buttons = r.removeFromBottom (20);
    undoButton.setBounds (buttons.removeFromLeft (100));
    redoButton.setBounds (buttons.removeFromLeft (100));
    tree.setBounds (r);
}

将 UndoManager 实例作为参数传递

由于 ValueTree 类会自动处理撤销/重做行为，我们只需将 UndoManager 实例作为参数传递，以注册 UndoableAction 对象。为此，首先声明一个 UndoManager 类的实例 [1]：

juce::UndoManager undoManager; // [1]

然后分配按钮被点击时要调用的函数，以处理相应的撤销/重做行为。在 lambda 函数中，分别调用 UndoManager::undo() 和 UndoManager::redo()，如下所示：

addAndMakeVisible (undoButton);
addAndMakeVisible (redoButton); // [3]
undoButton.onClick = [this] { undoManager.undo(); };
redoButton.onClick = [this] { undoManager.redo(); }; // [4]
setSize (600, 400);

在 ValueTreeItem 类中，我们也保留对 UndoManager 实例的引用 [2]：

private:
    juce::ValueTree tree;
    juce::UndoManager& undoManager; // [2]

在类构造函数的成员初始化列表中，赋值 UndoManager 引用 [3]：

ValueTreeItem (const juce::ValueTree& v, juce::UndoManager& um)
    : tree (v), undoManager (um) // [3]
{

每当递归创建 ValueTreeItem 的子项时，我们都需要传递 UndoManager 实例 [4]：

void refreshSubItems()
{
    clearSubItems();
    for (auto i = 0; i < tree.getNumChildren(); ++i)
        addSubItem (new ValueTreeItem (tree.getChild (i), undoManager)); // [4]
}

现在，我们可以通过传递 UndoManager 实例 [5]，在 MainContentComponent 类中实例化根 ValueTreeItem：

tree.setDefaultOpenness (true);
tree.setMultiSelectEnabled (true);
rootItem.reset (new ValueTreeItem (createRootValueTree(), undoManager)); // [5]
tree.setRootItem (rootItem.get());

现在有三个不同的方法需要更新，以注册我们在 TreeView 上执行的更改。

void itemDropped (const juce::DragAndDropTarget::SourceDetails&, int insertIndex) override
{
    juce::OwnedArray<juce::ValueTree> selectedTrees;
    getSelectedTreeViewItems (*getOwnerView(), selectedTrees);
    moveItems (*getOwnerView(), selectedTrees, tree, insertIndex, undoManager); // [1]
}

v.getParent().removeChild (v, &undoManager); // [2]
newParent.addChild (v, insertIndex, &undoManager); // [3]
  • [1]：每当条目被拖放时，将 undoManager 传递给处理移动的静态函数。
  • [2]：我们需要从先前的父节点中移除子节点，并将该操作注册到 undoManager。
  • [3]：然后我们可以将子节点添加到新的父节点，并将新操作注册到 undoManager。

通过将 undoManager 引用传递给 ValueTree 函数 addChild() 和 removeChild()，我们让 UndoManager 替我们执行 UndoableAction，方式是在底层调用 perform() 函数。我们将在未来的教程中介绍 UndoableAction 对象。

练习：分别在 Label 组件中显示已存储的撤销和重做操作的描述，位置在各自的 TextButton 对象旁边，使用 getUndoDescription() 和 getRedoDescription() 函数。

将事件作为事务处理

UndoManager 的另一个有用特性是能够将多个操作组合成单个撤销/重做事务。通过在 undoManager 实例上调用 beginNewTransaction() 函数，所有对 perform() 函数的调用都会由 UndoManager 组合在一起，直到下一次 beginNewTransaction() 调用。

作为一个例子，让我们创建一个 Timer，定期调用 beginNewTransaction() 函数，并将操作组作为事务存储起来。在 MainContentComponent 中，继承 Timer 类以接收定时器回调 [1]：

class MainContentComponent : public juce::Component,
                             public juce::DragAndDropContainer,
                             private juce::Timer // [1]
{
public:

在相应的头文件中声明回调函数 [2]：

void timerCallback() override // [2]
{
    undoManager.beginNewTransaction(); // [4]
}

在构造函数中按所需的间隔（以毫秒为单位）启动定时器，该间隔用于分隔各次事务调用 [3]：

startTimer (500); // [3]
}

最后，我们可以在定时器回调 [4] 中调用 beginNewTransaction() 函数，作用在 UndoManager 上：

void timerCallback() override // [2]
{
    undoManager.beginNewTransaction(); // [4]
}

练习：不使用定时器来分隔操作组，而是每五次撤销/重做操作实现一次事务。

这个修改版本的源代码可以在演示项目的 UndoManagerTutorial_02.h 文件中找到。

小结

完成本教程后，你已经学会了如何恢复应用程序的先前状态。具体来说，我们：

  • 将 UndoableAction 对象存储到 UndoManager 对象中。
  • 将 UndoManager 实例作为参数传递给 ValueTree 访问函数。
  • 将撤销/重做操作组作为事务处理。
