构建 MIDI 合成器

本教程实现一个响应 MIDI 输入的复音正弦波合成器。它用到了Synthesiser类及相关类。

难度：中级
平台：Windows、macOS、Linux
类：Synthesiser, SynthesiserVoice, SynthesiserSound, AudioSource, MidiMessageCollector

准备工作

你应该熟悉如何在 JUCE 中处理 MIDI 输入，以及如何生成正弦波。参见教程：处理 MIDI 事件和教程：构建正弦波合成器。

在此处下载本教程的演示项目：PIP | ZIP。解压该项目，并在 Projucer 中打开第一个头文件。

如果你需要这一步的帮助，请参阅教程：Projucer 第 1 部分：Projucer 入门。

演示项目

演示项目呈现一个屏幕键盘，可用于演奏一个简单的正弦波合成器。

使用电脑键盘上的按键可以控制屏幕键盘（用 A、S、D、F 等键控制 C、D、E、F 等音符）。这使你能够以复音方式演奏合成器。

Synthesiser 类

本教程使用 JUCE 的Synthesiser类实现一个复音合成器。这向你展示了在自己的应用中用自定义音色定制合成器所需的全部基本要素。要让这一切工作起来需要多个类，除了我们标准的 MainContentComponent 类之外，还有：

  • SynthAudioSource：它实现了一个名为 SynthAudioSource 的自定义AudioSource类，其中包含Synthesiser类本身。它输出合成器的全部音频。
  • SineWaveVoice：这是一个名为 SineWaveVoice 的自定义SynthesiserVoice类。声部类负责渲染合成器的一个声部，并在Synthesiser对象中把它与其他正在发声的声部混合。声部类的单个实例渲染一个声部。
  • SineWaveSound：它包含一个名为 SineWaveSound 的自定义SynthesiserSound类。音色类实际上是对可以作为声部创建的音色的描述。例如，它可能包含采样器声部的采样数据，或波表合成器的波表数据。

设置键盘

我们的 MainContentComponent 类包含以下数据成员。

juce::MidiKeyboardState keyboardState;
SynthAudioSource synthAudioSource;
juce::MidiKeyboardComponent keyboardComponent;
JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (MainContentComponent)
};

synthAudioSource 和 keyboardComponent 成员在 MainContentComponent 构造函数中初始化。

MainContentComponent()
    : synthAudioSource (keyboardState),
      keyboardComponent (keyboardState, juce::MidiKeyboardComponent::horizontalKeyboard)
{
    addAndMakeVisible (keyboardComponent);
    setAudioChannels (0, 2);
    setSize (600, 160);
    startTimer (400);
}

有关更多信息，参见教程：处理 MIDI 事件中的 MidiKeyboardComponent 类。

为了能够用电脑键盘演奏屏幕键盘，我们在应用启动后立即获取键盘焦点。为此我们使用一个在 400 毫秒后触发的简单定时器：

void timerCallback() override
{
    keyboardComponent.grabKeyboardFocus();
    stopTimer();
}

AudioAppComponent 函数

应用使用AudioAppComponent搭建一个简单的音频应用（最基本的应用参见教程：构建白噪声发生器）。三个必需的纯虚函数只是调用我们自定义AudioSource类中对应的函数：

void prepareToPlay (int samplesPerBlockExpected, double sampleRate) override
{
    synthAudioSource.prepareToPlay (samplesPerBlockExpected, sampleRate);
}
void getNextAudioBlock (const juce::AudioSourceChannelInfo& bufferToFill) override
{
    synthAudioSource.getNextAudioBlock (bufferToFill);
}
void releaseResources() override
{
    synthAudioSource.releaseResources();
}

SynthAudioSource 类

SynthAudioSource 类做的工作稍多一些：

class SynthAudioSource : public juce::AudioSource
{
public:
    SynthAudioSource (juce::MidiKeyboardState& keyState)
        : keyboardState (keyState)
    {
        for (auto i = 0; i < 4; ++i) // [1]
            synth.addVoice (new SineWaveVoice());
        synth.addSound (new SineWaveSound()); // [2]
    }
    void setUsingSineWaveSound()
    {
        synth.clearSounds();
    }
    void prepareToPlay (int /*samplesPerBlockExpected*/, double sampleRate) override
    {
        synth.setCurrentPlaybackSampleRate (sampleRate); // [3]
    }
    void releaseResources() override {}
    void getNextAudioBlock (const juce::AudioSourceChannelInfo& bufferToFill) override
    {
        bufferToFill.clearActiveBufferRegion();
        juce::MidiBuffer incomingMidi;
        keyboardState.processNextMidiBuffer (incomingMidi, bufferToFill.startSample, bufferToFill.numSamples, true); // [4]
        synth.renderNextBlock (*bufferToFill.buffer, incomingMidi, bufferToFill.startSample, bufferToFill.numSamples); // [5]
    }
private:
    juce::MidiKeyboardState& keyboardState;
    juce::Synthesiser synth;
};
  • [1]：我们向合成器添加一些声部。添加的声部数量决定了合成器的复音数。
  • [2]：我们添加音色，让合成器知道它可以演奏哪些音色。
  • [3]：合成器需要知道音频输出的采样率。
  • [4]：在 getNextAudioBlock() 函数中，我们从MidiKeyboardState对象取出 MIDI 数据缓冲区。
  • [5]：这些 MIDI 缓冲区被传递给合成器，合成器将利用音符开、音符关消息（以及其他 MIDI 通道声音消息）的时间戳来渲染各个声部。

SynthesiserVoice对象必须添加到一个且仅一个Synthesiser对象中。Synthesiser对象负责管理这些声部的生命周期。

SynthesiserSound对象可以在多个Synthesiser对象之间共享，如果你愿意的话。SynthesiserSound类是一种ReferenceCountedObject类，因此SynthesiserSound对象的生命周期是自动管理的。

如果你需要保存指向SynthesiserSound对象的指针，应该把它存放在 YourSoundClass::Ptr 变量中，这样内存管理才能正常工作。

SineWaveSound 类

我们的音色类非常简单，甚至不需要包含任何数据。它只需要报告这个音色是否应在特定的 MIDI 通道以及该通道上的特定音符或音符范围上演奏。在我们的简单情况下，它对这两个函数都只返回 true：appliesToNote() 和 appliesToChannel()。如上所述，音色类可能正是你存储创建音色所需数据（例如波表）的地方。

struct SineWaveSound : public juce::SynthesiserSound
{
    SineWaveSound() {}
    bool appliesToNote (int) override { return true; }
    bool appliesToChannel (int) override { return true; }
};

正弦波声部状态

SineWaveVoice 类稍微复杂一些。它需要维护合成器其中一个声部的状态。对于我们的正弦波，需要这些数据成员：

private:
    double currentAngle = 0.0, angleDelta = 0.0, level = 0.0, tailOff = 0.0;
};

前三个成员的信息参见教程：构建正弦波合成器。tailOff 成员用于给每个声部的振幅包络一个稍柔和的释放。这使每个声部在结尾处轻微淡出，而不是突然停止。

检查可以演奏哪个音色

SynthesiserVoice::canPlaySound() 函数必须被重写，以返回该声部能否演奏某个音色。在这个情况下我们本可以直接返回 true，但我们的示例演示了如何用 dynamic_cast 检查传入的音色类的类型。

bool canPlaySound (juce::SynthesiserSound* sound) override
{
    return dynamic_cast<SineWaveSound*> (sound) != nullptr;
}

启动声部

声部由拥有它的合成器调用我们的 SynthesiserVoice::startNote() 函数来启动，这个函数我们必须重写：

void startNote (int midiNoteNumber, float velocity, juce::SynthesiserSound*, int /*currentPitchWheelPosition*/) override
{
    currentAngle = 0.0;
    level = velocity * 0.15;
    tailOff = 0.0;
    auto cyclesPerSecond = juce::MidiMessage::getMidiNoteInHertz (midiNoteNumber);
    auto cyclesPerSample = cyclesPerSecond / getSampleRate();
    angleDelta = cyclesPerSample * 2.0 * juce::MathConstants<double>::pi;
}

同样，其中大部分内容你应该已经从教程：构建正弦波合成器中熟悉了。tailOff 值在每个声部开始时设为零。我们还用 MIDI 音符开事件的力度来控制声部的电平。

渲染声部

SynthesiserVoice::renderNextBlock() 函数必须被重写以生成音频。

void renderNextBlock (juce::AudioSampleBuffer& outputBuffer, int startSample, int numSamples) override
{
    if (angleDelta != 0.0)
    {
        if (tailOff > 0.0) // [7]
        {
            while (--numSamples >= 0)
            {
                auto currentSample = (float) (std::sin (currentAngle) * level * tailOff);
                for (auto i = outputBuffer.getNumChannels(); --i >= 0;)
                    outputBuffer.addSample (i, startSample, currentSample);
                currentAngle += angleDelta;
                ++startSample;
                tailOff *= 0.99; // [8]
                if (tailOff <= 0.005)
                {
                    clearCurrentNote(); // [9]
                    angleDelta = 0.0;
                    break;
                }
            }
        }
        else
        {
            while (--numSamples >= 0) // [6]
            {
                auto currentSample = (float) (std::sin (currentAngle) * level);
                for (auto i = outputBuffer.getNumChannels(); --i >= 0;)
                    outputBuffer.addSample (i, startSample, currentSample);
                currentAngle += angleDelta;
                ++startSample;
            }
        }
    }
}
  • [6]：这个循环用于声部的正常状态，即按键被按住的期间。注意我们使用了 AudioSampleBuffer::addSample() 函数，它把 currentSample 值与索引 startSample 处已有的值混合。这是因为合成器会遍历所有声部。每个声部都有责任把自己的输出与缓冲区当前的内容混合。
  • [7]：按键释放后，tailOff 值会大于零。可以看到合成算法是类似的。
  • [8]：我们使用简单的指数衰减包络形状。
  • [9]：当 tailOff 值很小时，我们判定该声部已结束。此时我们必须调用 SynthesiserVoice::clearCurrentNote() 函数，以便声部被重置并可供再次使用。

注意 startSample 参数非常重要。合成器很可能在某个输出块的中间调用 renderNextBlock() 函数。这是因为音符可能从任意采样开始。这些开始时间基于接收到的 MIDI 数据的时间戳。

停止声部

声部由拥有它的合成器调用我们的 SynthesiserVoice::stopNote() 函数来停止，这个函数我们必须重写：

void stopNote (float /*velocity*/, bool allowTailOff) override
{
    if (allowTailOff)
    {
        if (tailOff == 0.0)
            tailOff = 1.0;
    }
    else
    {
        clearCurrentNote();
        angleDelta = 0.0;
    }
}

它可能包含来自 MIDI 音符关消息的力度信息，但在许多情况下我们可以忽略它。我们可能被要求立即停止声部，此时我们直接调用 SynthesiserVoice::clearCurrentNote() 函数。在正常情况下，合成器会让我们的声部自然结束。在我们的情况下，我们使用简单的拖尾包络。我们通过把 tailOff 成员设为 1.0 来触发拖尾。

练习：尝试给声部添加较慢的起音，使它们不会突然开始。

添加外部 MIDI 输入

让我们添加功能，使外部 MIDI 源也能控制我们的合成器，而不只是屏幕键盘。

你大概需要在 macOS、Windows 或 Linux 这样的桌面平台上尝试，而不是在移动平台上。

为 SynthAudioSource 提供 MIDI 输入

首先把一个MidiMessageCollector对象添加为 SynthAudioSource 类的成员。它提供了一个可以发送 MIDI 消息、并且 SynthAudioSource 类可以使用这些消息的地方：

juce::MidiMessageCollector midiCollector;
};

为了处理 MIDI 数据的时间戳，MidiMessageCollector类需要知道音频采样率。在 SynthAudioSource::prepareToPlay() 函数中设置它 [10]：

void prepareToPlay (int /*samplesPerBlockExpected*/, double sampleRate) override
{
    synth.setCurrentPlaybackSampleRate (sampleRate);
    midiCollector.reset (sampleRate); // [10]
}

然后你可以用 MidiMessageCollector::removeNextBlockOfMessages() 函数为每个音频块取出 MIDI 消息 [11]：

void getNextAudioBlock (const juce::AudioSourceChannelInfo& bufferToFill) override
{
    bufferToFill.clearActiveBufferRegion();
    juce::MidiBuffer incomingMidi;
    midiCollector.removeNextBlockOfMessages (incomingMidi, bufferToFill.numSamples); // [11]
    keyboardState.processNextMidiBuffer (incomingMidi, bufferToFill.startSample, bufferToFill.numSamples, true);
    synth.renderNextBlock (*bufferToFill.buffer, incomingMidi, bufferToFill.startSample, bufferToFill.numSamples);
}

我们需要从 SynthAudioSource 类外部访问这个MidiMessageCollector对象，所以给 SynthAudioSource 类添加一个访问器，如下所示：

juce::MidiMessageCollector* getMidiCollector()
{
    return &midiCollector;
}

在我们的 MainContentComponent 类中，我们会把这个MidiMessageCollector对象作为MidiInputCallback对象添加到应用的AudioDeviceManager对象上。

列出 MIDI 输入

为了向用户呈现 MIDI 输入设备列表，我们将使用教程：处理 MIDI 事件中的一些代码。给 MainContentComponent 类添加一些成员：

juce::ComboBox midiInputList;
juce::Label midiInputListLabel;
int lastInputIndex = 0;

然后把以下代码添加到 MainContentComponent 构造函数中。

addAndMakeVisible (midiInputListLabel);
midiInputListLabel.setText ("MIDI Input:", juce::dontSendNotification);
midiInputListLabel.attachToComponent (&midiInputList, true);
auto midiInputs = juce::MidiInput::getAvailableDevices();
addAndMakeVisible (midiInputList);
midiInputList.setTextWhenNoChoicesAvailable ("No MIDI Inputs Enabled");
juce::StringArray midiInputNames;
for (auto input : midiInputs)
    midiInputNames.add (input.name);
midiInputList.addItemList (midiInputNames, 1);
midiInputList.onChange = [this] { setMidiInput (midiInputList.getSelectedItemIndex()); };
for (auto input : midiInputs)
{
    if (deviceManager.isMidiInputDeviceEnabled (input.identifier))
    {
        setMidiInput (midiInputs.indexOf (input));
        break;
    }
}
if (midiInputList.getSelectedId() == 0)
    setMidiInput (0);

添加上面代码中调用的 setMidiInput() 函数：

void setMidiInput (int index)
{
    auto list = juce::MidiInput::getAvailableDevices();
    deviceManager.removeMidiInputDeviceCallback (list[lastInputIndex].identifier,
        synthAudioSource.getMidiCollector()); // [12]
    auto newInput = list[index];
    if (!deviceManager.isMidiInputDeviceEnabled (newInput.identifier))
        deviceManager.setMidiInputDeviceEnabled (newInput.identifier, true);
    deviceManager.addMidiInputDeviceCallback (newInput.identifier, synthAudioSource.getMidiCollector()); // [13]
    midiInputList.setSelectedId (index + 1, juce::dontSendNotification);
    lastInputIndex = index;
}

注意，我们把 SynthAudioSource 对象中的MidiMessageCollector对象作为MidiInputCallback对象 [13] 添加到指定的 MIDI 输入设备上。如果用户通过组合框改变了所选设备，我们还需要为之前选中的 MIDI 输入设备移除先前的MidiInputCallback对象 [12]。

我们需要在 resized() 函数中定位这个ComboBox对象，并调整MidiKeyboardComponent对象的位置：

void resized() override
{
    midiInputList.setBounds (200, 10, getWidth() - 210, 20);
    keyboardComponent.setBounds (10, 40, getWidth() - 20, getHeight() - 50);
}

小结

本教程介绍了Synthesiser类。读完本教程后，你应该能够：

  • 设置Synthesiser类，把它放在AudioSource子类中，用于生成音频。
  • 创建合适的SynthesiserVoice和SynthesiserSound类，并把它们添加到Synthesiser对象中。
  • 把来自屏幕键盘和外部 MIDI 源的 MIDI 消息发送到Synthesiser对象。
