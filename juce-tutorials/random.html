Random 类

本教程介绍使用Random类生成随机数。Random生成的随机数在各种场合都很有用，包括游戏、密码学和音频。

难度：初级
平台：Windows、macOS、Linux、iOS、Android
类：Random、Range、BigInteger、Colour

入门

在此处下载本教程的演示项目：PIP | ZIP。解压该项目，并在Projucer中打开第一个头文件。

如果你需要这一步的帮助，请参阅教程：Projucer第1部分：Projucer入门。

演示项目

演示项目搭建了一个简单的文本控制台，我们可以在其中显示各种操作的结果。这让我们能够在本教程中演示Random类的一些特性。

在其默认配置下，演示项目显示一系列100个随机生成的32位整数。这些值应大致均匀分布在-2,147,483,648 .. 2,147,483,647范围内。当然，这些值并非真正随机。由于它们由计算机生成，因此是伪随机的。对于大多数用途，Random对象已经足够随机，但对于某些关键或专业应用，你可能需要使用更复杂的技术。

测试代码

在本教程中，我们将修改演示项目的部分代码，以演示Random类的不同特性。所有讨论的代码都在MainComponent类中。实际上，一开始的许多改动都将针对runExample()函数。

void runExample()
{
    logMessage ("------------------------- START --------------------------");
    for (auto iteration = 0; iteration < 100; ++iteration)
    {
        auto randomInt = juce::Random::getSystemRandom().nextInt();
        logMessage (juce::String (randomInt));
    }
    logMessage ("----------------------- FINISHED -------------------------");
}

这里我们使用Random::getSystemRandom()函数访问一个共享的（全局的）Random对象。我们用这个系统Random对象调用Random::nextInt()函数来生成随机数。在大多数情况下，使用这个系统随机对象生成所有随机数是令人满意的。在某些情况下，有必要创建自己的Random类实例。这通常出现在你生成的值是在另一个线程上生成的时候——参见教程：构建白噪声发生器。如果两个（或更多）线程试图访问系统Random对象，那么序列可能会被破坏，并可能导致问题。

限制范围

你几乎肯定希望限制Random类生成的值范围。虽然这可以用简单的算术完成，但Random类让它变得更加容易。

设置最大值

要设置最大值，只需像这样给Random::nextInt()传入一个整数：

auto randomInt = juce::Random::getSystemRandom().nextInt (6);

这会将最大值设置为所传参数减一。在本例中，值的范围是0 .. 5。在这种情况下，把参数理解为可能结果的数量可能更容易。使用6作为最大值意味着有6种可能的结果。这就像掷骰子，只是骰子的面是0 .. 5而不是1 .. 6！

设置最小值和最大值

当然，要生成1 .. 6范围内的值，我们可以像这样加1：

auto randomInt = juce::Random::getSystemRandom().nextInt (6) + 1;

但是，Random类可以通过传入一个Range对象为我们处理这件事

auto randomInt = juce::Random::getSystemRandom().nextInt (juce::Range<int> (1, 7));

最大值仍然需要比我们希望Random对象能够生成的最大值大1。最小值是包含的，最大值是不包含的。

其他数值类型

在上面的例子中，生成的值都在32位整数的范围内。Random类可以生成64位整数值，甚至可以使用BigInteger类生成任意大的整数。

更大的整数

要生成64位整数，请使用Random::nextInt64()函数：

auto randomInt = juce::Random::getSystemRandom().nextInt64();

这会生成−9,223,372,036,854,775,808 .. 9,223,372,036,854,775,807范围内的整数。要为64位整数指定更小的范围，你需要自己进行算术运算。

要生成任意大的整数，请使用Random::nextLargeNumber()函数。它返回一个BigInteger对象，并接受单个BigInteger对象作为参数来指示最大值（同样，最大值是不包含的）：

void runExample()
{
    logMessage ("------------------------- START --------------------------");
    juce::BigInteger maximumValue;
    maximumValue.setBit (256);
    for (auto iteration = 0; iteration < 100; ++iteration)
    {
        auto randomInt = juce::Random::getSystemRandom().nextLargeNumber (maximumValue);
        logMessage (randomInt.toString (10));
    }
    logMessage ("----------------------- FINISHED -------------------------");
}

这里，我们通过在maximumValue这个BigInteger对象中设置第256位，创建了一个非常大的最大值2^256^。输出是一些非常大的随机生成的整数。例如：

浮点值

Random类也可以生成浮点值：

void runExample()
{
    logMessage ("------------------------- START --------------------------");
    for (auto iteration = 0; iteration < 100; ++iteration)
    {
        auto randomValue = juce::Random::getSystemRandom().nextFloat();
        logMessage (juce::String (randomValue));
    }
    logMessage ("----------------------- FINISHED -------------------------");
}

它还可以生成double值：

auto randomValue = juce::Random::getSystemRandom().nextDouble();

在这两种情况下，返回的值都在0.0 .. 1.0范围内。要生成不同的范围，你需要自己进行算术运算（示例参见教程：构建白噪声发生器）。你可以为此使用jmap()函数。

可视化数值

将生成的随机值可视化，而不是查看一长串数字，可能会很有用。如果你需要一组非均匀分布的随机值，这尤其有用。这也可以创造出一些有趣的图案。

随机矩形位置

将MainContentComponent改为以下简单代码：

class MainContentComponent : public juce::Component
{
public:
    MainContentComponent()
    {
        setSize (600, 600);
    }
    ~MainContentComponent() {}
    void paint (juce::Graphics& g) override
    {
        g.fillAll (juce::Colours::black);
        g.setColour (juce::Colours::orange);
        auto& random = juce::Random::getSystemRandom();
        juce::Rectangle<int> rect (0, 0, 20, 20);
        for (auto i = 0; i < 100; ++i)
        {
            rect.setCentre (random.nextInt (getWidth()), random.nextInt (getHeight()));
            g.drawRect (rect);
        }
    }
private:
    //==============================================================================
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (MainContentComponent)
};

随机矩形大小

要随机化矩形的大小，我们可以这样做：

void paint (Graphics& g) override
{
    g.fillAll (juce::Colours::black);
    g.setColour (juce::Colours::orange);
    auto& random = juce::Random::getSystemRandom();
    juce::Rectangle<int> rect (0, 0, 20, 20);
    for (auto i = 0; i < 100; ++i)
    {
        rect.setSize (random.nextInt (getWidth() / 4), random.nextInt (getHeight() / 4));
        rect.setCentre (random.nextInt (getWidth()), random.nextInt (getHeight()));
        g.drawRect (rect);
    }
}

要让每次生成的都是正方形，我们可以这样做：

for (auto i = 0; i < 100; ++i)
{
    auto size = random.nextInt (jmin (getWidth(), getHeight()) / 4);
    rect.setSize (size, size);
    rect.setCentre (random.nextInt (getWidth()), random.nextInt (getHeight()));
    g.drawRect (rect);
}

随机颜色

Colours也可以随机化，但要使用随机化创建搭配良好的颜色则要棘手一些。例如，下面的代码为每个矩形生成一个新的随机颜色。但这个颜色可能是任何颜色：

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::black);
    auto& random = juce::Random::getSystemRandom();
    juce::Rectangle<int> rect (0, 0, 20, 20);
    for (auto i = 0; i < 100; ++i)
    {
        juce::Colour colour (random.nextInt (256),
            random.nextInt (256),
            random.nextInt (256));
        g.setColour (colour);
        rect.setCentre (random.nextInt (getWidth()), random.nextInt (getHeight()));
        g.drawRect (rect);
    }
}

这应该看起来像这样：

要用简单的方法限制颜色，我们可以只随机化一两个元素（红、绿或蓝）并限制值的范围：

juce::Colour colour (random.nextInt (juce::Range<int> (100, 256)),
    random.nextInt (juce::Range<int> (50, 200)),
    200);
g.setColour (colour);

这会产生粉色和紫色调：

更具体地说，你可以使用色相、饱和度和亮度来生成颜色。例如，橙色大约在色相30°（或在0 .. 1范围内为0.083）。如果我们在0.05 .. 0.15范围内生成随机色相，这些应该都是不同色调的橙色。

for (auto i = 0; i < 100; ++i)
{
    auto hue = juce::jmap (random.nextFloat(), 0.05f, 0.15f);
    g.setColour (juce::Colour::fromHSV (hue, 0.9f, 0.9f, 1.0f));
    rect.setCentre (random.nextInt (getWidth()), random.nextInt (getHeight()));
    g.drawRect (rect);
}

练习：尝试生成其他搭配良好的随机颜色集合。

从数组中随机选择

你可以使用数组从一组特定的颜色中随机选择：

class MainContentComponent : public Component
{
public:
    MainContentComponent()
    {
        colours.add (juce::Colours::white);
        colours.add (juce::Colours::orange);
        colours.add (juce::Colours::lightgreen);
        setSize (400, 400);
    }
    ~MainContentComponent() {}
    void paint (juce::Graphics& g) override
    {
        g.fillAll (juce::Colours::black);
        auto& random = Random::getSystemRandom();
        juce::Rectangle<float> rect (0.0f, 0.0f, 5.0f, 5.0f);
        for (auto i = 0; i < 1000; ++i)
        {
            g.setColour (colours[random.nextInt (colours.size())]);
            rect.setCentre ((float) random.nextInt (getWidth()),
                (float) random.nextInt (getHeight()));
            g.drawEllipse (rect, 1.0f);
        }
    }
private:
    juce::Array<Colour> colours;
    //==============================================================================
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (MainContentComponent)
};

这里我们把各项存储在数组中。要随机选择一项，我们根据数组大小生成一个随机值。然后我们使用这个值作为数组的索引。

其他分布

到目前为止，本教程中生成的所有随机数都在最小值和最大值之间均匀分布。虽然这不是一篇关于统计学的教程，但了解一些简单方法可以让某些随机生成的值比其他值更容易出现，这可能很有用。这在游戏、计算机生成艺术以及生成式声音和音乐中都有应用。

在下面的代码中，我们生成1,000个均匀分布在整个窗口中的圆形：

void paint (juce::Graphics& g) override
{
    g.fillAll (juce::Colours::black);
    g.setColour (juce::Colours::orange);
    auto& random = juce::Random::getSystemRandom();
    juce::Rectangle<float> rect (0.0f, 0.0f, 5.0f, 5.0f);
    for (auto i = 0; i < 1000; ++i)
    {
        rect.setCentre ((float) random.nextInt (getWidth()),
            (float) random.nextInt (getHeight()));
        g.drawEllipse (rect, 1.0f);
    }
}

从图像中可以看到，圆形大致均匀分布。

线性分布是指范围一端的值比其他值更可能出现。范围各处的值越靠近范围的另一端，出现的可能性越小。这两点之间的概率以线性方式变化。实现这一点的一个简单方法是根据另一个随机值的结果生成一个随机值。在下面的例子中，我们为圆形的x和y坐标都生成线性分布的值。

for (auto i = 0; i < 1000; ++i)
{
    auto x = random.nextInt (random.nextInt (Range<int> (1, getWidth())));
    auto y = random.nextInt (random.nextInt (Range<int> (1, getHeight())));
    rect.setCentre (x, y);
    g.drawEllipse (rect, 1.0f);
}

这里你可以看到，我们生成一个随机值，然后将结果传给Random::nextInt()函数以生成最终值。

我们不能把零作为最大值传给Random::nextInt()函数，因此必须确保第一个随机数的最小值为1。

结果应该看起来像这样：

由于接近零的值更可能出现，圆形看起来集中在左上角附近。要把圆形集中到中心，我们可以像这样修改代码：

auto centreX = getWidth() / 2;
auto centreY = getHeight() / 2;
for (auto i = 0; i < 1000; ++i)
{
    auto x0 = random.nextInt (juce::Range<int> (1, getWidth() / 2));
    auto x = random.nextInt (juce::Range<int> (centreX - x0, centreX + x0));
    auto y0 = random.nextInt (juce::Range<int> (1, getHeight() / 2));
    auto y = random.nextInt (juce::Range<int> (centreY - y0, centreY + y0));
    rect.setCentre (x, y);
    g.drawEllipse (rect, 1.0f);
}

加权分布

在某些情况下，你可能想专门为某些结果的概率加权。让我们用之前的例子，从数组中的三种颜色中随机选择。假设我们希望白色最可能出现，橙色次之，绿色比橙色更不可能。我们可以按下表定义概率：

颜色 概率

白色 70% 橙色 25% 绿色 5%

我们可以在代码中添加一个额外的权重数组，其中权重的索引与颜色的索引相对应：

class MainContentComponent : public juce::Component
{
public:
    MainContentComponent()
    {
        colours.add (juce::Colours::white);
        weights.add (0.7f);
        colours.add (juce::Colours::orange);
        weights.add (0.25f);
        colours.add (juce::Colours::lightgreen);
        weights.add (0.05f);
        setSize (400, 400);
    }
    void paint (juce::Graphics& g) override
    {
        g.fillAll (juce::Colours::black);
        juce::Random random;
        juce::Rectangle<float> rect (0.0f, 0.0f, 5.0f, 5.0f);
        auto sumOfWeights = sumFloatArray (weights); // [1]
        for (auto i = 0; i < 1000; ++i)
        {
            g.setColour (colourAtQuantile (random.nextFloat() * sumOfWeights)); // [2]
            rect.setCentre ((float) random.nextInt (getWidth()),
                (float) random.nextInt (getHeight()));
            g.drawEllipse (rect, 1.0f);
        }
    }
private:
    static float sumFloatArray (const juce::Array<float>& values)
    {
        auto sum = 0.0f;
        for (auto value : values)
            sum += value;
        return sum;
    }
    static int indexOfQuantile (const juce::Array<float>& weights, float quantile)
    {
        auto runningTotal = 0.0f; // [4]
        for (auto weight : weights)
        {
            runningTotal += weight;
            if (quantile < runningTotal) // [5]
                return weights.indexOf (weight);
        }
        return -1;
    }
    juce::Colour colourAtQuantile (float quantile) const // [3]
    {
        auto index = indexOfQuantile (weights, quantile);
        return index < 0 ? juce::Colours::transparentBlack : colours[index];
    }
    //==============================================================================
    juce::Array<juce::Colour> colours;
    juce::Array<float> weights;
    //==============================================================================
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (MainContentComponent)
};

它的工作方式如下：

  • [1]：要生成随机数，首先取权重之和。在本例中，我们知道权重之和为1.0，但使用这种技术，权重并不需要总和为1.0。
  • [2]：然后在0 .. sum范围内生成一个随机数。
  • [3]：colourAtQuantile()函数使用这个值来找到颜色。
  • [4]：这是通过在遍历权重数组时保持权重的运行总和来实现的。
  • [5]：当运行总和超过随机生成的值时，我们就找到了颜色。
