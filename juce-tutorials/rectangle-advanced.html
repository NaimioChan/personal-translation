进阶 GUI 布局技巧

用一种简单而强大的技巧来布局你的组件，它将产出优雅且错误更少的代码。该技巧涉及以不同方式多次细分组件矩形，用你的内容填满整个组件。

难度：中级
平台：Windows、macOS、Linux、iOS、Android
类：Rectangle、TextButton、Colours

准备工作

在此处下载本教程的演示项目：PIP | ZIP 。解压该项目并在 Projucer 中打开第一个头文件。

如果你在这一步需要帮助，请参阅教程：Projucer 第 1 部分：Projucer 入门。

演示项目

演示项目使用少量按钮组件，并把它们布局在父组件中。在这个例子中我们只是用按钮作为占位符，但它们可以是任何类型的 JUCE 组件。当你在 IDE 中构建并运行该应用程序时，主窗口应该看起来像下面的截图。

Rectangle 布局

在这个简单的应用程序中，主窗口里有几个区域：

  • 一个页眉区域，可能包含标题或工具栏。
  • 一个页脚区域，可能包含关于该应用程序的一些其他信息。
  • 一个侧边栏，可能包含一系列区块或其他内容。
  • 在窗口的其余部分列出的若干内容项。

这些都在 MainContentComponent 构造函数中添加（参见教程：父子组件和教程：JUCE 中的颜色）：

MainContentComponent()
{
    header.setColour (juce::TextButton::buttonColourId, juce::Colours::cornflowerblue);
    header.setButtonText ("Header");
    addAndMakeVisible (header);
    footer.setColour (juce::TextButton::buttonColourId, juce::Colours::cornflowerblue);
    footer.setButtonText ("Footer");
    addAndMakeVisible (footer);
    sidebar.setColour (juce::TextButton::buttonColourId, juce::Colours::grey);
    sidebar.setButtonText ("Sidebar");
    addAndMakeVisible (sidebar);
    limeContent.setColour (juce::TextButton::buttonColourId, juce::Colours::lime);
    addAndMakeVisible (limeContent);
    grapefruitContent.setColour (juce::TextButton::buttonColourId, juce::Colours::yellowgreen);
    addAndMakeVisible (grapefruitContent);
    lemonContent.setColour (juce::TextButton::buttonColourId, juce::Colours::yellow);
    addAndMakeVisible (lemonContent);
    orangeContent.setColour (juce::TextButton::buttonColourId, juce::Colours::orange);
    addAndMakeVisible (orangeContent);
    setSize (400, 400);
}

实际的布局通常通过重写 Component::resized() 来完成。

传统的布局方式

传统上，你会通过计算各个位置和尺寸来布局组件，并小心确保它们总是加总为正确的总尺寸。即使只是布局窗口主要部分的彩色按钮也会变得繁琐，而且很容易出错。要布局四个等大的按钮，我们可能会这样做：

//...
limeContent.setBounds (0, 0, 200, 24);
grapefruitContent.setBounds (0, 24, 200, 24);
lemonContent.setBounds (0, 48, 200, 24);
orangeContent.setBounds (0, 72, 200, 24);
//...

（在写本教程时，我把最后的 orangeContent 组件两次放错了位置，从而证明了我自己的观点！）

至少在你本可以把编码精力集中在更重要的事情上时，这些计算是很耗时的！一旦你熟悉了这种技巧，Rectangle 类提供了一些简单而强大的特性，可以让组件布局工作更灵活，在某些方面也更容易。这涉及把主矩形细分为越来越小的子矩形。

通过细分矩形进行布局

通过把主矩形细分为越来越小的部分来布局组件，看起来可能与传统方法等价。但它有许多好处：

  • 它鼓励你在代码中使用更少的魔法数字（硬编码值），这些数字会让你日后修改和维护布局更困难。
  • 在许多情况下，只需重新排列代码顺序就能修改布局，而不必更改任何数值！
  • 确保精确填满可用空间要容易得多，而不必发现布局超出了父组件或没有完全填满它。
  • 处理可调整大小的组件，以及为某些必须有最小尺寸的区域制定规则，都更容易。

演示应用程序中 MainContentComponent::resized() 函数的代码如下：

void resized() override
{
    auto area = getLocalBounds();
    auto headerFooterHeight = 36;
    header.setBounds (area.removeFromTop (headerFooterHeight));
    footer.setBounds (area.removeFromBottom (headerFooterHeight));
    auto sidebarWidth = 80;
    sidebar.setBounds (area.removeFromLeft (sidebarWidth)); // [2]
    auto contentItemHeight = 24;
    orangeContent.setBounds (area.removeFromTop (contentItemHeight));
    limeContent.setBounds (area.removeFromTop (contentItemHeight)); // [1]
    grapefruitContent.setBounds (area.removeFromTop (contentItemHeight));
    lemonContent.setBounds (area.removeFromTop (contentItemHeight));
}

让我们详细看看这个函数的前几行。首先我们用 Component::getLocalBounds() 函数获取正在布局的组件的本地边界。它总是返回一个位于 (0, 0)、宽度和高度与组件相同的矩形：

auto area = getLocalBounds();

这就是我们要细分以布局子组件的矩形。我们的第一次细分是布局页眉：

header.setBounds (area.removeFromTop (headerFooterHeight));

这里我们取代表整个组件的矩形，并实际上创建两个矩形。Rectangle::removeFromTop() 函数返回一个位于原矩形位置、宽度相同、但高度仅为参数所请求高度的矩形。在这个例子中，我们请求一个高 36 像素的矩形。这个函数做的另一件事是修改原矩形，移除我们刚刚返回的矩形。本质上，它在距顶部 36 像素处切割矩形，返回上面的矩形，并把原矩形修改为等于下面的矩形。

单独来看，它会是这样的：

第二次细分是布局页脚：

footer.setBounds (area.removeFromBottom (headerFooterHeight));

Rectangle::removeFromBottom() 函数与 Rectangle::removeFromTop() 函数相同，只是它从主矩形的底部移除一个矩形并保留上面的矩形。此时，我们的组件看起来像这样：

  • 然后我们从剩余矩形的左侧移除 80 像素来创建侧边栏。
  • 然后我们使用 Rectangle::removeFromTop() 函数多次细分剩余的矩形。

最后我们得到完全布局好的组件。

重新排列项目

如前所述，用这种技巧重新排列项目非常容易。例如，我们只需在 resized() 函数中先列出橙色内容，就能把它移到顶部 [1]：

auto contentItemHeight = 24;
orangeContent.setBounds (area.removeFromTop (contentItemHeight));
limeContent.setBounds (area.removeFromTop (contentItemHeight)); // [1]
grapefruitContent.setBounds (area.removeFromTop (contentItemHeight));
lemonContent.setBounds (area.removeFromTop (contentItemHeight));

这看起来像这样：

对于固定数量的组件，这种方法显然更优雅。在渲染可变内容时它甚至更有用。

我们不能仅通过重新排列项目就把侧边栏移到右侧，但这只需使用 Rectangle::removeFromRight() 函数而不是 Rectangle::removeFromLeft() [2]：

auto sidebarWidth = 80;
sidebar.setBounds (area.removeFromLeft (sidebarWidth)); // [2]

调整组件大小

这种方法还免费带给我们的另一件事是：调整大小通常「就是能用」。下面是组件变宽但变矮的样子：

如果我们希望部分或全部布局按比例变化，那也很容易纳入代码。例如，我们可能希望侧边栏始终占总宽度的四分之一：

sidebar.setBounds (area.removeFromRight (area.getWidth() / 4));

如果你试试这个，会发现有一个有用的下限。在这种方法中也很容易纳入这一点。试试下面这个，它把侧边栏宽度设为总宽度的四分之一，但把 80 像素作为下限：

sidebar.setBounds (area.removeFromRight (juce::jmax (80, area.getWidth() / 4)));

练习：再创建几个不同颜色的按钮，并把它们水平排列，添加到 orangeContent 、limeContent 、grapefruitContent 和 lemonContent 组件下方的区域。让它们填满整个剩余宽度。

其他情形

到此为止的示例中，我们一直继续细分剩余的矩形，以定位序列中的下一个组件。有些情况下你需要存储其中一个子矩形，然后改为细分它。

例如，要在我们的示例中把项目放在内部列表中，也就是侧边栏里，我们需要临时存储侧边栏矩形，然后再细分它。为了说明这一点，向演示项目添加三个组件 [3]、[4] 和 [5]：

private:
juce::TextButton header;
juce::TextButton sidebar;
juce::TextButton sideItemA; // [3]
juce::TextButton sideItemB; // [4]
juce::TextButton sideItemC; // [5]
juce::TextButton limeContent;
juce::TextButton grapefruitContent;
juce::TextButton lemonContent;
juce::TextButton orangeContent;
juce::TextButton footer;

然后在构造函数中配置它们，同时移除侧边栏按钮上的文字 [7]：

//...
sidebar.setColour (juce::TextButton::buttonColourId, juce::Colours::grey);
// [7]
addAndMakeVisible (sidebar);
sideItemA.setColour (juce::TextButton::buttonColourId, juce::Colours::maroon);
sideItemB.setColour (juce::TextButton::buttonColourId, juce::Colours::maroon);
sideItemC.setColour (juce::TextButton::buttonColourId, juce::Colours::maroon);
sideItemA.setButtonText ("Item A");
sideItemB.setButtonText ("Item B");
sideItemC.setButtonText ("Item C");
addAndMakeVisible (sideItemA);
addAndMakeVisible (sideItemB);
addAndMakeVisible (sideItemC);
//...

最后，把 resized() 函数改成以下内容：

void resized() override
{
    auto area = getLocalBounds();
    auto headerFooterHeight = 36;
    header.setBounds (area.removeFromTop (headerFooterHeight));
    footer.setBounds (area.removeFromBottom (headerFooterHeight));
    auto sideBarArea = area.removeFromRight (juce::jmax (80, area.getWidth() / 4));
    sidebar.setBounds (sideBarArea);
    auto sideItemHeight = 40;
    auto sideItemMargin = 5;
    sideItemA.setBounds (sideBarArea.removeFromTop (sideItemHeight).reduced (sideItemMargin));
    sideItemB.setBounds (sideBarArea.removeFromTop (sideItemHeight).reduced (sideItemMargin));
    sideItemC.setBounds (sideBarArea.removeFromTop (sideItemHeight).reduced (sideItemMargin));
    auto contentItemHeight = 24;
    orangeContent.setBounds (area.removeFromTop (contentItemHeight));
    limeContent.setBounds (area.removeFromTop (contentItemHeight));
    grapefruitContent.setBounds (area.removeFromTop (contentItemHeight));
    lemonContent.setBounds (area.removeFromTop (contentItemHeight));
}

还要注意 Rectangle::reduced() 函数的使用，它让矩形的边缘内缩，实际上是把矩形放在边距之内。构建并运行应用程序，它现在应该看起来像这样。

总结

在本教程中，我们探索了 Rectangle 类中一组特定函数在细分矩形方面的用法。特别是，我们看到了使用这种技巧来布局组件。我们可以：

  • 用更优雅的代码布局组件。
  • 减少布局代码中魔法数字的使用。
  • 以最小的代码改动来改变布局位置以及组件的布局顺序。
