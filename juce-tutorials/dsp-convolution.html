通过波形整形与卷积添加失真

通过对声音进行波形整形来创建谐波失真，为合成器声音增添颗粒感。了解卷积的基础知识，以从脉冲响应中提取其包含的声音特性。

难度：高级
平台：Windows、macOS、Linux
插件格式：VST、AU、Standalone
类：dsp::ProcessorChain, dsp::Gain, dsp::Oscillator, dsp::Convolution, dsp::WaveShaper, dsp::Reverb, dsp::ProcessorDuplicator

本项目需要支持 C++14 特性的编译器。较新版本的 Xcode 和 Visual Studio 均包含这一支持。

简介

在本教程中，我们介绍两个新的 DSP 概念，它们能以不同的方式处理信号：波形整形和卷积。

让我们先定义这些 DSP 术语。

什么是波形整形？

波形整形是通过对原始信号施加传递函数，把某个信号塑造成另一个不同信号的过程。例如，通过对一个简单的正弦波施加数学函数，可以把它塑造成不同的波形。

波形整形器可以通过施加某种传递函数为原始信号添加谐波成分，从而有效地产生失真。你可能知道，例如方波和三角波本质上就是添加了奇次谐波的正弦波，而锯齿波是奇次和偶次谐波结合的正弦波。

了解了这一点，制造失真的一种方法是让正弦波的形状更接近方波。那么，我们如何用传递函数实现这一点呢？

例如，考虑一个简单的正弦波 sin(x)，它可以绘制如下：

通过对正弦波施加符号函数（signum）传递函数——一个本质上输出输入数字符号的函数——我们得到 sgn(sin(x))，它完美地表示方波，如下所示：

然而，这种完美的波形会带来问题，因为曲线上的硬边缘会产生一种被称为硬削波的刺耳失真。这种波形也「过于完美」，无法在模拟域中重现，因此听起来不像大多数模拟合成器产生的方波。

为了创造一种更柔和的失真（称为软削波），我们可以使用双曲正切传递函数 tanh(sin(x))，它输出的信号看起来几乎像正弦波，但曲线更圆润，如下所示：

然后，为了达到类似方波的形状，我们可以在施加传递函数 tanh(n*sin(x)) 之前把信号推入削波，本质上把钟形的顶部截断成边缘柔和的方波，如下所示：

如你所见，波形整形的可能性可以是无穷无尽的，因为任何类型的传递函数都可以施加到输入信号上。

在 JUCE 中，你可以使用 DSP 模块中包含的 dsp::WaveShaper 类来执行波形整形。

什么是卷积？

卷积在于通过使用描述某个空间特性的预先录制的脉冲响应，来模拟该空间的混响特性。这一过程允许我们通过卷积（本质上是把每个数据采样与脉冲响应采样相乘，以生成组合输出）把任何类型的声学轮廓施加到输入信号上。

脉冲响应是通过在要刻画的空间中录制短脉冲而生成的音频文件，但它们不一定需要是真实的物理空间。例如，我们可以通过让脉冲经过箱体并录制其效果来捕捉吉他放大器的轮廓，如下所示：

集成波形整形器

在 Distortion 类中，添加一个以 juce::dsp::WaveShaper 处理器作为模板参数的 juce::dsp::ProcessorChain [1]。同时定义一个带有处理器索引的枚举 [2]，以便之后能通过索引清晰地引用相应的处理。

private:
//==============================================================================
enum {
    waveshaperIndex // [2]
};
juce::dsp::ProcessorChain<juce::dsp::WaveShaper<Type>> processorChain; // [1]
};

在 reset() 函数中，调用处理器链中波形整形器的 reset 函数 [3]。

void reset() noexcept
{
    processorChain.reset(); // [3]
}

在 prepare() 函数中，调用处理器链中波形整形器的 prepare 函数 [4]。

void prepare (const juce::dsp::ProcessSpec& spec)
{
    processorChain.prepare (spec); // [4]
}

现在我们要定义波形整形器用来塑造输入信号的传递函数。如本教程简介部分所述，我们先从一个硬削波函数开始。

在构造函数中，通过提供处理的索引并使用 processorChain.get<>() 方法获取 WaveShaper 的引用 [5]。让我们用 lambda 函数来初始化波形整形器，把值限制在 -0.1 .. 0.1 的范围内 [6]。

public:
//==============================================================================
Distortion()
{
    auto& waveshaper = processorChain.template get<waveshaperIndex>(); // [5]
    waveshaper.functionToUse = [] (Type x) {
        return juce::jlimit (Type (-0.1), Type (0.1), x); // [6]
    };
}

在 process() 函数中，我们可以调用处理器链中波形整形器的 process 函数 [7]。

template <typename ProcessContext>
void process (const ProcessContext& context) noexcept
{
    processorChain.process (context); // [7]
}

如果在 Distortion 类中实现上述更改后运行这段代码，我们应该能听到波形整形器对振荡器信号的影响。

练习：通过把值限制在 -0.5 .. 0.5 之间，改变传递函数中限制的程度。你听出声音的差别了吗？

更改传递函数

让我们把传递函数改为双曲正切，使波形整形器的削波更柔和一些。

向处理器链添加两个 juce::dsp::Gain 处理器，把 juce::dsp::WaveShaper 夹在它们之间 [1]，并把对应的索引作为前置增益 [2] 和后置增益 [3] 添加到枚举中。它们将允许我们调整进入波形整形器的信号电平，并控制从其中出来的电平，从而影响传递函数的行为。

private:
//==============================================================================
enum {
    preGainIndex, // [2]
    waveshaperIndex,
    postGainIndex // [3]
};
juce::dsp::ProcessorChain<juce::dsp::Gain<Type>, juce::dsp::WaveShaper<Type>, juce::dsp::Gain<Type>> processorChain; // [1]
};

在构造函数中，如本教程简介所述，把传递函数改为双曲正切 [4]：

public:
//==============================================================================
Distortion()
{
    auto& waveshaper = processorChain.template get<waveshaperIndex>();
    waveshaper.functionToUse = [] (Type x) {
        return std::tanh (x); // [4]
    };
    auto& preGain = processorChain.template get<preGainIndex>(); // [5]
    preGain.setGainDecibels (30.0f); // [6]
    auto& postGain = processorChain.template get<postGainIndex>(); // [7]
    postGain.setGainDecibels (-20.0f); // [8]
}

这里我们还获取了前置增益处理器的引用 [5]，并把进入波形整形器的信号提升 30dB [6]。然后我们获取后置增益处理器的引用 [7]，并把来自波形整形器的电平削减 20dB [8]。

运行程序应该会给我们一个不同的失真声音。

练习：把波形整形器中使用的传递函数改为符号函数。你听出声音的差别了吗？

调整滤波器

你可能已经注意到的一点是，当用波形整形器对低频内容进行失真处理时，失真的声音很快就会变得浑浊。我们可以在用波形整形器处理信号之前引入一个高通滤波器来缓解这个问题。

添加一个以 juce::dsp::IIR::Filter 和 juce::dsp::IIR::Coefficients 类作为模板参数的 juce::dsp::ProcessorDuplicator [1]，以便轻松地把单声道滤波器转换为多声道版本。为了简化过长的类名，我们使用「using」关键字给出更短的名称，并在枚举中添加对应的索引 [2]。

private:
//==============================================================================
enum {
    filterIndex, // [2]
    preGainIndex,
    waveshaperIndex,
    postGainIndex
};
using Filter = juce::dsp::IIR::Filter<Type>;
using FilterCoefs = juce::dsp::IIR::Coefficients<Type>;
juce::dsp::ProcessorChain<juce::dsp::ProcessorDuplicator<Filter, FilterCoefs>,
    juce::dsp::Gain<Type>,
    juce::dsp::WaveShaper<Type>,
    juce::dsp::Gain<Type>>
    processorChain;
};

在 prepare() 函数中，获取滤波器处理器的引用 [3]，并调用 makeFirstOrderHighPass() 函数把高通滤波器的截止频率指定为 1kHz [4]：

void prepare (const juce::dsp::ProcessSpec& spec)
{
    auto& filter = processorChain.template get<filterIndex>(); // [3]
    filter.state = FilterCoefs::makeFirstOrderHighPass (spec.sampleRate, 1000.0f); // [4]
    processorChain.prepare (spec);
}

现在信号的较低频率应被衰减，声音更清晰。

练习：在波形整形之前尝试不同类型的滤波器，并注意失真信号的谐波成分如何变化。

实现箱体模拟器

让我们使用卷积来模拟吉他箱体，为我们的声音增添更多特色。

在 CabSimulator 类中，向处理器链添加一个 juce::dsp::Convolution 处理器 [1]，并在枚举中添加其对应的索引 [2]。

private:
//==============================================================================
enum {
    convolutionIndex // [2]
};
juce::dsp::ProcessorChain<juce::dsp::Convolution> processorChain;
};

在 reset() 函数中，调用处理器链中卷积器的 reset 函数 [3]。

void reset() noexcept
{
    processorChain.reset(); // [3]
}

在 prepare() 函数中，调用处理器链中卷积器的 prepare 函数 [4]。

void prepare (const juce::dsp::ProcessSpec& spec)
{
    processorChain.prepare (spec); // [4]
}

现在我们要指定卷积器用来对输入信号进行混响的脉冲响应。如本教程简介部分所述，让我们用项目 Resources 文件夹中包含的吉他放大器脉冲响应来加载卷积处理器。

在构造函数中，通过提供处理的索引并使用 processorChain.get<>() 方法获取 Convolution 处理器的引用 [5]。让我们通过从 Resources 文件夹加载音频文件，用吉他放大器脉冲响应初始化卷积器 [6]。

CabSimulator()
{
    auto dir = juce::File::getCurrentWorkingDirectory();
    int numTries = 0;
    while (!dir.getChildFile ("Resources").exists() && numTries++ < 15)
        dir = dir.getParentDirectory();
    auto& convolution = processorChain.template get<convolutionIndex>(); // [5]
    convolution.loadImpulseResponse (dir.getChildFile ("Resources").getChildFile ("guitar_amp.wav"),
        juce::dsp::Convolution::Stereo::yes,
        juce::dsp::Convolution::Trim::no,
        1024); // [6]
}

请确保「guitar_amp.wav」文件存在于项目的 Resources 文件夹中。

在 process() 函数中，我们可以调用处理器链中卷积器的 process 函数 [7]。

template <typename ProcessContext>
void process (const ProcessContext& context) noexcept
{
    processorChain.process (context); // [7]
}

在 Distortion 类中，移除增益削减，或把其电平设为 0dB 衰减 [8]，因为信号在我们的信号链中失真之后发生的卷积过程中会自然衰减：

public:
//==============================================================================
Distortion()
{
    auto& waveshaper = processorChain.template get<waveshaperIndex>();
    waveshaper.functionToUse = [] (Type x) {
        return std::tanh (x);
    };
    auto& preGain = processorChain.template get<preGainIndex>();
    preGain.setGainDecibels (30.0f);
    auto& postGain = processorChain.template get<postGainIndex>();
    postGain.setGainDecibels (0.0f); // [8]
}

让我们运行程序，听听它听起来怎么样。

练习：加载 Resources 文件夹中包含的盒式录音机脉冲响应，注意卷积后的声音发生了多么剧烈的变化。

这个修改版本代码的源代码可以在演示项目的 DSPConvolutionTutorial_02.h 文件中找到。
