TableListBox 类

将表格融入你的 JUCE 用户界面。显示从 XML 文件加载的数据，并自定义表格的格式。

难度：中级
平台：Windows、macOS、Linux
类：TableListBox、TableListBoxModel、ListBox、ListBoxModel、TableHeaderComponent、XmlDocument、XmlElement

入门

在此处下载本教程的演示项目：PIP | ZIP。解压项目并在 Projucer 中打开第一个头文件。

如果使用本项目的 PIP 版本，请确保将 Resources 文件夹复制到生成的 Projucer 项目中。

如果你需要这一步的帮助，请参阅教程：Projucer 第 1 部分：Projucer 入门。

演示项目

演示项目显示一个从 XML 文件加载的表格，其中包含有关 JUCE 模块的信息。表格可以按你选择的列进行排序，某些条目可以编辑，列可以隐藏。

ListBox 类

在 JUCE 中允许我们显示表格的基础 Component 类称为 ListBox 类。ListBox 的行为由 ListBoxModel 类管理，它描述了要显示的数据模型。这对于在可滚动的视口中显示项目列表很有用，但为了将其变成带有描述各列的表头的正式表格，我们可以分别使用 TableListBox 和 TableListBoxModel 类。这些类封装了与其对应类相同的行为，但改为融入了 TableHeaderComponent 的功能来显示列标题。

在实现 TableListBox 并继承 TableListBoxModel 时，有几个函数需要重写，即：

  • getNumRows()：需要返回表格中当前的行数。
  • paintRowBackground()：使用提供的 Graphics 上下文，我们必须绘制由行号指定的行的背景。
  • paintCell()：使用提供的 Graphics 上下文，我们必须绘制由行号和列号指定的单元格。
  • refreshComponentForCell()：我们可以选择性地重写此方法，以在表格中创建和更新自定义组件。
  • getColumnAutoSizeWidth()：当对列宽使用自动调整大小时，此方法可以选择性地指定列如何调整自身大小。
  • sortOrderChanged()：如果使用自定义排序顺序，我们可以选择性地指定列如何重新排序。

还有其他函数可以选择性地重写以获得额外功能，但在本教程中我们将实现这里介绍的这些函数。

从 XML 读取数据

让我们首先从 XML 文档加载要在表格中呈现的数据。

在项目的 Resources 文件夹中，你可以找到一个名为 TableData.xml 的文件，其中包含供本教程使用的示例数据，格式如下：

<TABLE_DATA>
<HEADERS>
<COLUMN columnId="1" name="ID" width="50"/>
//...
</HEADERS>
<DATA>
<ITEM ID="01" Module="juce_module" Name="JUCE example classes" Version="5.2.0" License="ISC" Groups="2" Dependencies="1" Description="..." Select="0"/>
//...
</DATA>
</TABLE_DATA>

这里我们用 TABLE_DATA 标签封装整个文件，表头和实际数据分别使用 HEADERS 和 DATA 标签分隔。列由单独的 COLUMN 标签定义，行由 ITEM 标签定义，并使用属性表示该条目每一列的内容。

本项目中代码的实现是针对这种文件结构定制的，但你可以随意修改 XML 标签。

在 TableTutorialComponent 类中，我们定义了一个指针，用于将文件内容临时存储在一个 XmlElement 成员变量中，另外还定义了两个 XmlElement，分别用于列内容和行内容，如下所示：

class TableTutorialComponent : public juce::Component,
                               public juce::TableListBoxModel
{
std::unique_ptr<juce::XmlElement> tutorialData;
juce::XmlElement* columnList = nullptr;
juce::XmlElement* dataList = nullptr;

在类的构造函数中，我们启动一个 FileChooser 来选择要显示的数据文件。当 FileChooser 完成时，它会调用 callback lambda 函数，将文件内容加载到我们的 XmlElement 对象中 [1]。数据从 XML 文件加载完成后，我们可以使用 for() 循环和 XmlElement::getChildIterator 遍历列标题，并使用 addColumn() 函数 [2] 指定表头，如下所示：

TableTutorialComponent()
{
    const auto callback = [this] (const juce::FileChooser& chooser) {
loadData (chooser.getResult()); // [1]
if (columnList != nullptr)
{
    for (auto* columnXml : columnList->getChildIterator())
    {
        table.getHeader().addColumn (columnXml->getStringAttribute ("name"), // [2]
            columnXml->getIntAttribute ("columnId"),
            columnXml->getIntAttribute ("width"),
            50,
            400,
            juce::TableHeaderComponent::defaultFlags);
    }
}

此函数指定列的名称、宽度和 ID，以及定义列的可排序性和可调整大小的属性标志。

在构造函数中调用的 loadData() 辅助函数里，我们首先找到 Resources 目录和要加载的 XML 文件，并使用 parse() 函数 [3] 解析这个 File 对象。然后我们可以通过遍历 XML 结构并使用 getChildByName() 函数 [4] 找到相应的标签，从临时的 XmlElement 中获取行和列。这里是调用数据 XmlElement 的 getNumChildElements() [5] 来设置行数的好地方，如下所示：

void loadData (juce::File tableFile)
{
    if (tableFile == juce::File() || !tableFile.exists())
        return;
    tutorialData = juce::XmlDocument::parse (tableFile); // [3]
    dataList = tutorialData->getChildByName ("DATA");
    columnList = tutorialData->getChildByName ("HEADERS"); // [4]
    numRows = dataList->getNumChildElements(); // [5]
}

请确保选择本教程资源中提供的「TableData.xml」文件。

让我们再定义一个名为 getAttributeNameForColumnId() 的辅助函数，它根据列的 ID 返回列的名称，这将在后面派上用场：

juce::String getAttributeNameForColumnId (const int columnId) const
{
    for (auto* columnXml : columnList->getChildIterator())
    {
        if (columnXml->getIntAttribute ("columnId") == columnId)
            return columnXml->getStringAttribute ("name");
    }
    return {};
}

这里我们遍历子 XML 元素，找到匹配的列 ID，以便返回其 name 属性。

自定义单元格组件

TableListBox 可以在其单元格中容纳除文本之外的自定义组件。在以下各节中，我们将探讨如何将 ToggleButton 融入其中一列，以及如何融入一个监听用户输入的可编辑 Label。

可编辑标签

在 EditableTextCustomComponent 类中，我们首先继承 Label 类，以便在用户双击时将其设置为可编辑：

class EditableTextCustomComponent : public juce::Label
{
public:
    EditableTextCustomComponent (TableTutorialComponent& td)
        : owner (td)
    {
        setEditable (false, true, false);
    }
private:
    TableTutorialComponent & owner;
    int row, columnId;
    juce::Colour textColour;
};

这里我们还记录了该对象显示在哪个行和列，以及指向实际表格的引用。

当用户与 Label 交互时，我们必须扩展通常的 mouseDown() 功能，以处理表格中的多选。这是通过在表格上调用 selectRowsBasedOnModifierKeys() 并传入修饰键作为参数来实现的。注意，这里我们仍然需要调用基类函数，以同时保留原有的行为：

void mouseDown (const juce::MouseEvent& event) override
{
    owner.table.selectRowsBasedOnModifierKeys (row, event.mods, false);
    Label::mouseDown (event);
}

当用户编辑 Label 中的文本时，我们会从 textWasEdited() 函数收到回调，并调用稍后在 TableTutorialComponent 类中定义的辅助函数 setText()，将更改保存到相应的 XmlElement 对象中，如下所示：

void textWasEdited() override
{
    owner.setText (columnId, row, getText());
}

以下函数在创建或更新 EditableTextCustomComponent 对象时由 TableListBoxModel 调用，它使用后面定义的 getText() 辅助函数设置行、列以及从 XmlElement 中获取的显示文本：

void setRowAndColumn (const int newRow, const int newColumn)
{
    row = newRow;
    columnId = newColumn;
    setText (owner.getText (columnId, row), juce::dontSendNotification);
}

getText() 和 setText() 辅助函数的定义如下：

juce::String getText (const int columnNumber, const int rowNumber) const
{
    return dataList->getChildElement (rowNumber)->getStringAttribute (getAttributeNameForColumnId (columnNumber));
}

这里我们根据行号和列号，在 XmlElement 包含的子元素中找到文本。

void setText (const int columnNumber, const int rowNumber, const juce::String& newText)
{
    const auto& columnName = table.getHeader().getColumnName (columnNumber);
    dataList->getChildElement (rowNumber)->setAttribute (columnName, newText);
}

这里我们根据行号和列号，将文本存储到 XmlElement 包含的子元素中。

可选按钮

在 SelectionColumnCustomComponent 类中，我们首先继承 Component 类，以便将一个 ToggleButton 设置为其子 Component，并指定用户与其交互时要调用的回调函数：

class SelectionColumnCustomComponent : public Component
{
public:
    SelectionColumnCustomComponent (TableTutorialComponent& td)
        : owner (td)
    {
        addAndMakeVisible (toggleButton);
        toggleButton.onClick = [this] { owner.setSelection (row, (int) toggleButton.getToggleState()); };
    }
private:
    TableTutorialComponent & owner;
    juce::ToggleButton toggleButton;
    int row, columnId;
};

这里我们还记录了该对象显示在哪个行和列，以及指向实际表格的引用。该 lambda 函数调用稍后在 TableTutorialComponent 中定义的辅助函数 setSelection()，用于设置按钮的切换状态。

void resized() override
{
    toggleButton.setBoundsInset (juce::BorderSize<int> (2));
}

resized() 函数设置 ToggleButton 对象的边界。

以下函数在创建或更新 SelectionColumnCustomComponent 对象时由 TableListBoxModel 调用，它使用后面定义的 getSelection() 辅助函数设置行、列以及从 XmlElement 中获取的切换状态：

void setRowAndColumn (int newRow, int newColumn)
{
    row = newRow;
    columnId = newColumn;
    toggleButton.setToggleState ((bool) owner.getSelection (row), juce::dontSendNotification);
}

getSelection() 和 setSelection() 辅助函数的定义如下：

int getSelection (const int rowNumber) const
{
    return dataList->getChildElement (rowNumber)->getIntAttribute ("Select");
}

这里我们根据行号和列号，在 XmlElement 包含的子元素中找到切换状态。

void setSelection (const int rowNumber, const int newSelection)
{
    dataList->getChildElement (rowNumber)->setAttribute ("Select", newSelection);
}

这里我们根据行号和列号，将切换状态存储到 XmlElement 包含的子元素中。

对数据排序

为了让表格能够基于选定的列对元素排序，我们必须定义一个比较器类，它可以作为模板类传入，供 XmlElement 对象的 sortChildElements() 函数使用。

我们将这个类命名为 TutorialDataSorter，它记录要排序的 XmlElement 属性名称以及排序算法的升序或降序方向，如下所示：

class TutorialDataSorter
{
public:
    TutorialDataSorter (const juce::String& attributeToSortBy, bool forwards)
        : attributeToSort (attributeToSortBy),
          direction (forwards ? 1 : -1)
    {
    }
private:
    juce::String attributeToSort;
    int direction;
};

为了让 sortChildElements() 函数将 TutorialDataSorter 识别为有效的比较器，我们必须声明一个名为 compareElements() 的函数，它接受两个 XmlElement 对象并以 int 返回顺序。

该函数需要返回：

  • 如果第一个排在第二个之前，则返回负值。
  • 如果两个对象相等，则返回 0。
  • 如果第二个排在第一个之前，则返回正值。 
int compareElements (juce::XmlElement* first, juce::XmlElement* second) const
{
    auto result = first->getStringAttribute (attributeToSort)
                      .compareNatural (second->getStringAttribute (attributeToSort)); // [1]
    if (result == 0)
        result = first->getStringAttribute ("ID")
                     .compareNatural (second->getStringAttribute ("ID")); // [2]
    return direction * result; // [3]
}

因此，在上面的函数中，我们使用 String 类的 compareNatural() 方法比较两个 XmlElement 的字符串属性，该方法按照相同的规则返回一个 int [1]。如果两个字符串在相关属性上相等，那么我们比较这两个元素的 ID 列 [2]。最后，如果排序方向相反，我们需要反转结果 [3]。

设置模型

让我们通过实现 TableListBoxModel 把所有部分组合起来。

我们首先在 TableTutorialComponent 类中继承 TableListBoxModel 类，如下所示：

class TableTutorialComponent : public juce::Component,
                               public juce::TableListBoxModel
{
private:
    juce::TableListBox table { {}, this };
    juce::Font font { 14.0f };
    std::unique_ptr<juce::XmlElement> tutorialData;
    juce::XmlElement* columnList = nullptr;
    juce::XmlElement* dataList = nullptr;
    int numRows = 0;

这里我们定义了一个 TableListBox 成员变量，并将此类设置为其 TableListBoxModel，这意味着在这种情形下我们的模型类实际上持有表格本身。我们还按照模型的要求记录表格中的行数。

在类的构造函数中，我们将 TableListBox 添加为子 Component [1]。我们还可以指定表格外观的属性，例如轮廓颜色及其粗细 [2]。

addAndMakeVisible (table); // [1]
table.setColour (juce::ListBox::outlineColourId, juce::Colours::grey); // [2]
table.setOutlineThickness (1);
table.getHeader().setSortColumnId (1, true); // [3]
table.setMultipleSelectionEnabled (true); // [4]

排序用的列和列的可见性通过在表格的 TableHeaderComponent 上调用相应函数来设置 [3]，我们还允许在表格上进行多选 [4]。

第一个要重写的函数是 getNumRows() 函数，它返回保存行数的成员变量。此函数对于模型正确更新表格是必需的：

int getNumRows() override
{
    return numRows;
}

paintRowBackground() 函数的实现方式是先找到一种与表格默认背景色相配的交替颜色：

void paintRowBackground (juce::Graphics& g, int rowNumber, int /*width*/, int /*height*/, bool rowIsSelected) override
{
    auto alternateColour = getLookAndFeel().findColour (juce::ListBox::backgroundColourId).interpolatedWith (getLookAndFeel().findColour (juce::ListBox::textColourId), 0.03f);
    if (rowIsSelected)
        g.fillAll (juce::Colours::lightblue);
    else if (rowNumber % 2)
        g.fillAll (alternateColour);
}

如果该行被选中，则将该行填充为浅蓝色，否则我们用这种交替颜色绘制每隔一行的背景。

为了用内容填充单元格，我们按如下方式重写 paintCell() 函数：

void paintCell (juce::Graphics& g, int rowNumber, int columnId, int width, int height, bool rowIsSelected) override
{
    g.setColour (rowIsSelected ? juce::Colours::darkblue : getLookAndFeel().findColour (juce::ListBox::textColourId)); // [5]
    g.setFont (font);
    if (auto* rowElement = dataList->getChildElement (rowNumber))
    {
        auto text = rowElement->getStringAttribute (getAttributeNameForColumnId (columnId));
        g.drawText (text, 2, 0, width - 4, height, juce::Justification::centredLeft, true); // [6]
    }
    g.setColour (getLookAndFeel().findColour (juce::ListBox::backgroundColourId));
    g.fillRect (width - 1, 0, 1, height); // [7]
}
  • [5]：首先，我们根据行是否被选中为文本选择合适的颜色，并设置字体大小。
  • [6]：如果 XmlElement 对象中存在子行元素，我们从该行获取正确的列，并用 XmlElement 中相应的文本填充单元格。
  • [7]：最后，我们用默认背景色在单元格右侧绘制分隔线。 
void sortOrderChanged (int newSortColumnId, bool isForwards) override
{
    if (newSortColumnId != 0)
    {
        TutorialDataSorter sorter (getAttributeNameForColumnId (newSortColumnId), isForwards);
        dataList->sortChildElements (sorter);
        table.updateContent();
    }
}

当用户请求更改排序顺序时，会调用 sortOrderChanged() 回调函数；如果排序列有效，我们就用正确的属性和方向实例化一个 TutorialDataSorter 对象。然后我们可以将该对象传给 XmlElement 的 sortChildElements() 函数，并通过在表格上调用 updateContent() 强制刷新表格。

refreshComponentForCell() 函数是实例化和更新自定义单元格组件的地方，如下所示：

Component* refreshComponentForCell (int rowNumber, int columnId, bool /*isRowSelected*/, Component* existingComponentToUpdate) override
{
    if (columnId == 9) // [8]
    {
        auto* selectionBox = static_cast<SelectionColumnCustomComponent*> (existingComponentToUpdate);
        if (selectionBox == nullptr)
            selectionBox = new SelectionColumnCustomComponent (*this);
        selectionBox->setRowAndColumn (rowNumber, columnId);
        return selectionBox;
    }
    if (columnId == 8) // [9]
    {
        auto* textLabel = static_cast<EditableTextCustomComponent*> (existingComponentToUpdate);
        if (textLabel == nullptr)
            textLabel = new EditableTextCustomComponent (*this);
        textLabel->setRowAndColumn (rowNumber, columnId);
        return textLabel;
    }
    jassert (existingComponentToUpdate == nullptr);
    return nullptr; // [10]
}
  • [8]：如果该函数是在选择单元格正确的「Select」列上调用，那么我们检查该单元格中是否已存在 SelectionColumnCustomComponent。如果不存在，我们就实例化一个新实例，并通过调用其 setRowAndColumn() 函数更新其内容，然后返回该 Component。
  • [9]：如果该函数是在文本编辑器单元格正确的「Description」列上调用，那么我们检查该单元格中是否已存在 EditableTextCustomComponent。如果不存在，我们就实例化一个新实例，并通过调用其 setRowAndColumn() 函数更新其内容，然后返回该 Component。
  • [10]：否则，这意味着该函数是在常规列上调用，该单元格的自定义 Component 对象应该不存在。

最后，TableListBox 提供了一个不错的功能，即可以根据下文 getColumnAutoSizeWidth() 函数中定义的自动行为调整列的大小：

int getColumnAutoSizeWidth (int columnId) override
{
    if (columnId == 9)
        return 50;
    int widest = 32;
    for (auto i = getNumRows(); --i >= 0;)
    {
        if (auto* rowElement = dataList->getChildElement (i))
        {
            auto text = rowElement->getStringAttribute (getAttributeNameForColumnId (columnId));
            widest = juce::jmax (widest, font.getStringWidth (text));
        }
    }
    return widest + 8;
}

这里我们决定检查某一列中的所有元素，并获取单元格中最宽的文本。然后我们返回加上一些内边距的宽度，或者如果该列恰好是带有自定义 ToggleButton 的「Select」列，则返回固定宽度。
