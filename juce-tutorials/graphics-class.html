Graphics 类

本教程介绍如何使用 Graphics 对象绘制文本、线条和几何图形。这是用 JUCE 进行绘制的基础。

难度：初级
平台：Windows、macOS、Linux、iOS、Android
类：Component, Graphics, Font, Colours, Path

准备工作

演示项目

本教程的演示项目包含一个主应用程序窗口和一个主组件。你应该已经从之前的教程中熟悉了这些内容：教程：应用程序窗口和教程：主组件。

你已经知道，主组件的外观（事实上，任何其他 Component 也是如此！）由它的 paint() 函数的实现决定。这里的演示项目从上一篇教程（教程：主组件）结束的地方继续。paint() 函数的实现最初如下所示：

void paint (juce::Graphics& g)
{
    g.fillAll (juce::Colours::lightblue);
    g.setColour (juce::Colours::darkblue);
    g.setFont (14.0f);
    g.drawText ("Hello, World!", getLocalBounds(), juce::Justification::centred, true);
}

如果现在编译并运行应用，你应该会看到窗口具有浅蓝色背景，并且文本 Hello, World! 绘制在其上，位于窗口中央。

接下来，我们将添加一些代码，使用 Graphics 类在 MainComponent 对象中绘制更多图形。这是一个非常强大的类，在以后的教程中我们会经常使用它来实现不同 JUCE 组件的自定义视觉外观。

Graphics 类

我们再来看一下 paint 函数。记住，paint() 函数是一个回调，在需要把你的 Component 渲染到屏幕上时由操作系统调用——你绝不应该自己调用这个函数。

注意，这个回调的参数传入的是一个 Graphics 实例的引用。这个 Graphics 对象由底层框架提供。它是图形上下文，你可以用它渲染任何图形元素：文本、线条、形状、颜色、渐变等等。本教程将探讨其中的一些内容。

Graphics 类通常只在 paint() 回调中使用。一般情况下，除了在图像上绘制之外，你不应在其他任何地方使用它。

渲染文本

设置字体

我们先继续处理文本。下面这行

g.setFont (20.0f);

为后续那一行（使用该字体绘制文本 Hello, World!）把字号设为 20 像素。但如果我们不仅想改变字号，还想使用另一种字体以及粗体或斜体呢？又该如何改变文本的位置？

实际上，Graphics::setFont() 函数还有另一个版本，它接受一个 Font 对象，而不只是一个决定大小的 float。你可以这样创建一个新的 Font 对象：

juce::Font mainComponentFont ("Times New Roman", 20.0f, juce::Font::italic);

因为我们在主组件中使用这个字体，所以选择了描述性的变量名 mainComponentFont。

Font 构造函数的第一个参数决定字体（typeface），第二个是字号，第三个是字体样式。这里我们选择斜体作为样式。字体样式实际上是可按位掩码使用的标志（参见教程：应用程序窗口），因此你可以像这样组合它们：

juce::Font mainComponentFont ("Times New Roman", 20.0f, juce::Font::bold | juce::Font::italic);

如果再次编译并运行应用，你应该会看到字体已经改变。

为字体使用计算机上实际未安装的字体，是 JUCE 应用中字体无法正常工作的一个非常常见原因。

除了先创建一个命名的 Font 对象、然后在下一行用 Graphics::setFont() 函数设置它之外，你也可以把这两件事写成一条语句：

g.setFont (juce::Font ("Times New Roman", 20.0f, juce::Font::italic));

不过，把语句分开并使用命名变量，通常会让代码更易读、更易维护。（在现代编译器中，引入这样一个额外变量不会影响性能。）

设置位置

现在我们来改变文本的位置。在此过程中，我们将了解 JUCE 中如何处理定位。

简单的方法是直接改变文本相对于整个组件的对齐方式，例如把 Justification::centred 值改为其他可能的值，比如 Justification::topLeft 值。（你也可以查看其他可能的 Justification::Flags 值。）不过，另一种非常强大的方法是显式定义大小和位置。Graphics::drawText() 函数还有采用这种方法的另一个版本。把以 g.drawText() 调用开头的那一行改成：

g.drawText ("Hello, World!", 20, 40, 200, 40, juce::Justification::centred, true);

这告诉 Graphics 对象把文本渲染到一个宽 200 像素、高 40 像素的区域中，该区域位于从主组件左上角向右 20 像素、向下 40 像素处。

请记住：JUCE 中的坐标始终从当前组件的左上角量起，该点即 (0, 0)。坐标可以写成 int 或 float 数值。用于指定图形元素或子组件的位置时，该元素会被摆放成使其左上角出现在给定位置。

最后，Graphics::drawText() 函数的最后一个参数是一个 bool 标志，它决定当文本无法容纳在给定宽度内时，是显示省略号（…），还是直接把文本截断。

练习：把文本框的宽度从 200 改为更小的值，观察省略号标志的作用。

Graphics::drawText() 函数适合渲染单行文本。对于多行文本，它还提供了其他函数，例如 Graphics::drawMultiLineText() 和 Graphics::drawFittedText()。

渲染几何图形

在这一节中，我们继续使用 Graphics 类绘制一些几何图形。

绘制线条

在 paint() 函数的末尾添加以下行：

g.setColour (juce::Colours::green);
g.drawLine (10, 300, 590, 300, 5);

这会在窗口中绘制一条 5 像素宽的绿色水平线，从 (10, 300) 开始，到 (590, 300) 结束。注意，每当你想用与上一次不同的颜色绘制几何图形时，都必须在绘制前调用 Graphics::setColour() 函数。

当然，你也可以通过指定其他坐标来绘制斜线。事实上，JUCE 还支持亚像素坐标（位置可以使用 float 值）。如果位置落在物理屏幕像素之间，JUCE 会对绘制应用抗锯齿。

练习：探索其他类型的线条。你能想出如何绘制虚线或箭头吗？提示：查看 Graphics 类的文档。

绘制矩形

使用 Graphics 对象绘制矩形相当直接。在 paint() 函数体中加入以下代码：

g.setColour (juce::Colours::sandybrown);
g.drawRect (300, 120, 200, 170);

这会渲染一个棕色矩形，宽 200 像素、高 170 像素，其左上角位于 (300, 120)。

可选的第五个参数让你指定线条粗细：

g.setColour (juce::Colours::sandybrown);
g.drawRect (300, 120, 200, 170, 3);

如果想要填充的矩形，请改用 Graphics::fillRect() 函数：

g.setColour (juce::Colours::sandybrown);
g.fillRect (300, 120, 200, 170);

除了分别给出位置、宽度和高度，还有一个更方便的类来表示矩形：Rectangle 类。Graphics::drawRect() 函数也有一个版本接受这样的 Rectangle 实例来指定矩形的位置：

juce::Rectangle<int> house (300, 120, 200, 170);
g.setColour (juce::Colours::sandybrown);
g.fillRect (house);

这个非常方便的 Rectangle 类将在以后的教程中探讨。

练习：弄清如何绘制圆角矩形。然后，再试着绘制一个填充的圆角矩形。

你不必用纯色填充矩形。也可以使用颜色渐变或其他几种图案之一。让我们想象这个棕色矩形代表一座房子。我们可以用棋盘格图案填充它，从而添加类似砖块的纹理。使用以下代码绘制这个矩形：

juce::Rectangle<float> house (300, 120, 200, 170);
g.fillCheckerBoard (house, 30, 10, juce::Colours::sandybrown, juce::Colours::saddlebrown);

绘制圆形

我们来看看 Graphics 类如何绘制圆形和椭圆。请看 Graphics::drawEllipse() 和 Graphics::fillEllipse() 函数。它们的工作方式与 Graphics::drawRect() 和 Graphics::fillRect() 函数完全相同。

让我们给这幅小风景加一个太阳。以下代码会在窗口的右上区域绘制一个直径 60 像素的圆形：

g.setColour (juce::Colours::yellow);
g.drawEllipse (530, 10, 60, 60, 3);

注意，给定的位置 (530, 10) 并不是把圆心放在该位置。与其他所有图形元素一样，对象会被摆放成使其外接矩形的左上角位于给定位置。

你也可以显式使用组件的边界来计算位置，例如：

g.setColour (juce::Colours::yellow);
g.drawEllipse (getWidth() - 70, 10, 60, 60, 3);

练习：为 Graphics::drawEllipse() 函数编写一个包装函数，以便更方便地绘制圆形。该函数应接受一个点的坐标和一个半径，然后以该点为圆心、以给定半径绘制圆形。

绘制其他多边形

最后，让我们给房子加一个屋顶。这将是一个红色三角形。

你会发现 Graphics 类中并没有名为 drawTriangle() 或 drawPolygon() 的函数。为此，我们必须采用更通用的方法。

看看 Path 类。它本质上处理任意一组相连的点。在这个例子中，我们需要一个由三个点构成的三角形。例如，我们可以使用 (300, 110)、(500, 110)、(400, 70) 这三个点，使屋顶三角形位于房子矩形之上。

我们的红色屋顶在 JUCE 代码中是这样的：

g.setColour (juce::Colours::red);
Path roof;
roof.addTriangle (300, 110, 500, 110, 400, 70);
g.fillPath (roof);

小结

在本教程中，我们展示了如何在 Component 类的 paint() 回调中使用 Graphics 对象，在组件内部进行绘制。你现在应熟悉：

  • 渲染和格式化文本。
  • 绘制线条。
  • 绘制几何图形，例如矩形、圆形和多边形。

你现在还应知道，Graphics 对象是由底层框架提供的绘图上下文，不应在 paint() 回调之外使用。

备注

Graphics 类的图形渲染功能比本教程讨论的更多。特别是，你可以用它把图像（来自图像文件）绘制到屏幕上。使用 Path 类还能做更多事情。Graphics 类的其他一些特性包括颜色渐变、透明层和变换。其中一些将在以后的教程中介绍。
