自定义应用程序的观感

自定义应用程序中基础控件的绘制方式。通过绘制你自己的按钮、滑块和其他组件，为应用程序制作自定义皮肤。

难度：初级
平台：Windows、macOS、Linux、iOS、Android
类：LookAndFeel、Slider、Button、Path、AffineTransform

准备工作

在此下载本教程的演示项目：PIP | ZIP。解压项目，然后在 Projucer 中打开第一个头文件。

如果你需要这一步的帮助，请参阅教程：Projucer 第 1 部分：Projucer 入门。

演示项目

演示项目使用 JUCE 标准观感创建了一个包含两个按钮和两个旋转滑块的 GUI：

LookAndFeel 类是在 JUCE 中创建自定义 GUI 的基础。使用 LookAndFeel 类，你可以进行简单的自定义，例如更改某些组件的默认颜色。但你也可以自定义许多类型组件的绘制。例如，这让你可以创建具有自定义外观的按钮和滑块。

自定义颜色

当 LookAndFeel 对象应用到某个组件时，它也会应用到该组件及其子组件（参见教程：父组件与子组件），除非子组件被专门指定了不同的观感。

使用观感系统可以做的一件事是为标准 JUCE 组件的元素覆盖特定颜色（参见教程：JUCE 中的颜色。）例如，如果在 MainContentComponent 构造函数中添加下面这一行，那么两个旋钮都会变成红色：

getLookAndFeel().setColour (juce::Slider::thumbColourId, juce::Colours::red);

效果应该与下面的截图类似：

要把两个旋钮设置成不同的样子，我们可以新建一个 LookAndFeel 实例，并只把它应用到其中一个旋钮。首先添加一个 LookAndFeel_V4 对象作为成员 [1]（这是实现 JUCE 默认观感的类）。

private:
    juce::LookAndFeel_V4 otherLookAndFeel; // [1]
    juce::Slider dial1;
    juce::Slider dial2;
    juce::TextButton button1;
    juce::TextButton button2;

LookAndFeel 必须始终在使用它的控件和组件之前声明！否则它们会在仍被这些类使用时就被析构。

然后把我们刚刚在构造函数中添加的那行代码改成这样：

otherLookAndFeel.setColour (juce::Slider::thumbColourId, juce::Colours::red);

让我们只对第一个旋钮使用这个观感。把下面这行代码添加到 MainContentComponent 构造函数中：

dial1.setLookAndFeel (&otherLookAndFeel);

现在这应该会创建一个如下面截图所示的 UI：

当然，在这个简单的例子中，与直接在滑块对象上设置 Slider::thumbColourId 颜色相比，这种做法并没有带来好处。但你的应用可能会为不同用途使用多个滑块，你可能希望某一用途的滑块使用一组颜色，而其他用途的滑块使用不同的颜色组。只要每个滑块都分配了与其类型相适应的观感，这种做法就允许你全局更改这些颜色。

一旦我们开始自定义实际的绘制代码，这种做法的好处就更明显了。特别是，我们需要创建一个自定义的观感类。

自定义观感

要自定义某些组件的绘制，我们需要创建一个继承自 LookAndFeel 类的新类。如果直接继承 LookAndFeel 类本身，那么你需要实现所有纯虚函数。继承已经定义了所有这些函数的某个类要实用得多。这样你只需重写自己需要的那些函数。让我们创建一个简单的自定义观感，与默认观感相比只定义了这一处颜色更改。

首先，从构造函数中删除我们之前添加的这一行：

otherLookAndFeel.setColour (juce::Slider::thumbColourId, juce::Colours::red);

现在，添加我们的新类，它继承自 LookAndFeel_V4 类，放在 MainContentComponent 类之前：

class OtherLookAndFeel : public juce::LookAndFeel_V4
{
public:
    OtherLookAndFeel()
    {
        setColour (juce::Slider::thumbColourId, juce::Colours::red);
    }

在运行这段代码之前，把 otherLookAndFeel 成员的类名改为 OtherLookAndFeel [2]：

private:
OtherLookAndFeel otherLookAndFeel; // [2]
juce::Slider dial1;
juce::Slider dial2;
juce::TextButton button1;
juce::TextButton button2;

构建并运行应用程序，结果应该与之前的截图完全相同。

自定义绘制

LookAndFeel 类中有许多针对许多不同类型组件的函数。为特定组件类型指定的函数很容易找到，因为它们都声明在相关组件类中名为 LookAndFeelMethods 的嵌套类里。

自定义滑块

例如，看看 JUCE API 文档中的 Slider::LookAndFeelMethods。在这个列表中你会注意到一个名为 Slider::LookAndFeelMethods::drawRotarySlider() 的函数。

让我们在 OtherLookAndFeel 类中重写它。把声明添加到类中：

void drawRotarySlider (juce::Graphics& g, int x, int y, int width, int height, float sliderPos, const float rotaryStartAngle, const float rotaryEndAngle, juce::Slider&) override

可以看到，我们被传入以下数据：

  • g：Graphics 上下文。
  • x：应绘制旋转滑块的矩形左上角的 x 坐标。
  • y：应绘制旋转滑块的矩形左上角的 y 坐标。
  • width：应绘制旋转滑块的矩形的宽度。
  • height：应绘制旋转滑块的矩形的高度。
  • sliderPos：滑块的位置，表示为 0..1 范围内的比例（这与滑块实际的值范围无关）。
  • rotaryStartAngle：旋钮旋转的起始角度（单位为弧度）。
  • rotaryEndAngle：旋钮旋转的结束角度（单位为弧度）。
  • slider：Slider 对象本身。

x、y、width 和 height 参数已经考虑了滑块可能使用的任何文本框的尺寸和位置。这就是为什么我们可以直接访问滑块的位置和尺寸并使用这些值。

现在我们来编写函数体，绘制一个简单的旋钮：它只是一个填充的圆，外加一条表示旋钮指针的线。首先，我们需要一些临时变量，以便基于传入的值进行计算：

auto radius = (float) juce::jmin (width / 2, height / 2) - 4.0f;
auto centreX = (float) x + (float) width * 0.5f;
auto centreY = (float) y + (float) height * 0.5f;
auto rx = centreX - radius;
auto ry = centreY - radius;
auto rw = radius * 2.0f;
auto angle = rotaryStartAngle + sliderPos * (rotaryEndAngle - rotaryStartAngle);

可以看到，最后的 angle 变量包含旋钮应指向的角度。

现在添加代码来填充旋钮的颜色并绘制轮廓：

// fill
g.setColour (juce::Colours::orange);
g.fillEllipse (rx, ry, rw, rw);
// outline
g.setColour (juce::Colours::red);
g.drawEllipse (rx, ry, rw, rw, 1.0f);

要绘制指针本身，首先我们使用一个 Path 对象，然后将其平移并按所需角度旋转到位：

juce::Path p;
auto pointerLength = radius * 0.33f;
auto pointerThickness = 2.0f;
p.addRectangle (-pointerThickness * 0.5f, -radius, pointerThickness, pointerLength);
p.applyTransform (juce::AffineTransform::rotation (angle).translated (centreX, centreY));

然后填充这个路径来绘制指针：

// pointer
g.setColour (juce::Colours::yellow);
g.fillPath (p);

本节完整的代码可以在本教程演示项目的 LookAndFeelCustomisationTutorial_02.h 文件中找到。

练习：修改指针的绘制。你可以尝试不同的长度、稍微粗一些但带圆角的矩形，或者绘制一个箭头。

这里只向你展示了对 Slider 观感方法中某一个方法的简单自定义。但这个原理同样适用于其他方法。创建其他自定义的最佳做法或许是查看 LookAndFeel_V4 或 LookAndFeel_V3 类中已有的实现，并以此作为你自己代码的基础。

LookAndFeel_V4 类继承自 LookAndFeel_V3 类，有些方法并没有在 LookAndFeel_V4 类中重新定义。

自定义按钮

让我们看看如何自定义按钮。首先，在其构造函数中使用下面这一行，把我们的 OtherLookAndFeel 类设置为整个 MainContentComponent 的观感：

setLookAndFeel (&otherLookAndFeel);

我们还要确保 LookAndFeel 对象在关闭时不再被 MainContentComponent 使用，方法是在其析构函数中提供下面这一行：

~MainContentComponent() override
{
    setLookAndFeel (nullptr);
}

这当然意味着我们的两个旋钮都会呈现上一节中自定义的外观。现在让我们添加 Button::LookAndFeelMethods::drawButtonBackground() 函数声明：

void drawButtonBackground (juce::Graphics& g, juce::Button& button, const juce::Colour& backgroundColour, bool, bool isButtonDown) override

这里，我们被传入以下数据：

  • g：Graphics 上下文。
  • button：Button 对象本身。
  • backgroundColour：应使用的基础背景颜色（它是根据按钮的切换状态从 LookAndFeel 颜色中选出的）。
  • isMouseOverButton：鼠标指针是否位于按钮的边界内。
  • isButtonDown：鼠标按键是否按下。

现在，让我们添加函数体，制作一个非常简单的按钮背景：它只是用背景颜色填充按钮矩形：

auto buttonArea = button.getLocalBounds();
g.setColour (backgroundColour);
g.fillRect (buttonArea);

如果你构建并运行，效果应该与下面的截图类似：

如果你与之交互，会注意到按钮在视觉上并不响应鼠标指针的交互。让我们实现一个简单的阴影效果。把 drawButtonBackground() 函数改成这样：

auto buttonArea = button.getLocalBounds();
auto edge = 4;
buttonArea.removeFromLeft (edge);
buttonArea.removeFromTop (edge);
// shadow
g.setColour (juce::Colours::darkgrey.withAlpha (0.5f));
g.fillRect (buttonArea);
auto offset = isButtonDown ? -edge / 2 : -edge;
buttonArea.translate (offset, offset);
g.setColour (backgroundColour);
g.fillRect (buttonArea);

现在点击按钮时，按钮看起来会移动。可惜文字保持静止，所以我们需要重写 Button::LookAndFeelMethods::drawButtonText() 函数，让效果更可信。为了编写这个函数，我们先复制 LookAndFeel_V2 类中的代码，并把它添加到我们的 OtherLookAndFeel 类中：

void drawButtonText (juce::Graphics& g, juce::TextButton& button, bool isMouseOverButton, bool isButtonDown) override
{
    auto font = getTextButtonFont (button, button.getHeight());
    g.setFont (font);
    g.setColour (button.findColour (button.getToggleState() ? juce::TextButton::textColourOnId
                                                            : juce::TextButton::textColourOffId)
                     .withMultipliedAlpha (button.isEnabled() ? 1.0f : 0.5f));
    auto yIndent = juce::jmin (4, button.proportionOfHeight (0.3f));
    auto cornerSize = juce::jmin (button.getHeight(), button.getWidth()) / 2;
    auto fontHeight = juce::roundToInt (font.getHeight() * 0.6f);
    auto leftIndent = juce::jmin (fontHeight, 2 + cornerSize / (button.isConnectedOnLeft() ? 4 : 2));
    auto rightIndent = juce::jmin (fontHeight, 2 + cornerSize / (button.isConnectedOnRight() ? 4 : 2));
    auto textWidth = button.getWidth() - leftIndent - rightIndent;
    if (textWidth > 0)
        g.drawFittedText (button.getButtonText(),
            leftIndent,
            yIndent,
            textWidth,
            button.getHeight() - yIndent * 2,
            juce::Justification::centred,
            2);
}

我们只需更改绘制文字的偏移量，使其与 drawButtonBackground() 函数中表现出的移动相匹配。只需要更改最后几行：

auto textWidth = button.getWidth() - leftIndent - rightIndent;
auto edge = 4;
auto offset = isButtonDown ? edge / 2 : 0;
if (textWidth > 0)
    g.drawFittedText (button.getButtonText(),
        leftIndent + offset,
        yIndent + offset,
        textWidth,
        button.getHeight() - yIndent * 2 - edge,
        juce::Justification::centred,
        2);
}

练习：为按钮的绘制添加一些变化，以响应鼠标指针位于按钮之上。例如，你可以稍微调整背景颜色、更改阴影颜色，或者细微地改变矩形尺寸或位置。

小结

在本教程中，我们介绍了使用 LookAndFeel 类自定义 JUCE 组件观感的概念。具体来说，你现在应该能够：

  • 在默认观感中自定义颜色。
  • 创建一个新的观感类。
  • 自定义滑块和按钮的绘制代码。
  • 找到其他组件的观感方法，从而可以自定义任何 JUCE 组件。
