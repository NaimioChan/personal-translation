文件读取

打开并读取文本文件和二进制文件中的数据。

难度：初级
平台：Windows、macOS、Linux
类：File、FileInputStream、FilenameComponent、TextEditor、String、MemoryBlock

JUCE中的文件

本教程说明使用JUCE读取文件的基本技术。文件是跨平台开发中需要小心处理的一个方面，因为不同操作系统上的文件系统有时工作方式差异很大。作为使用JUCE的开发者，你无法完全避免这些问题，但JUCE让不同平台上的体验更加一致，并且当它发现你的代码做了可能导致问题的操作时，通常会在调试构建中触发断言。

File类

JUCE中的File类表示文件或目录的绝对路径（无论它是否实际存在）。创建File对象最简单的方法是传入一个包含绝对路径的String。例如，在macOS、Linux或Android上，以下是一个绝对路径：

juce::File path ("/path/to/file.txt");

但File类提供了操作路径的方法，例如请求相对于父目录的子文件、获取父目录等等。例如，上面的代码可以使用File::getChildFile()函数像这样重写：

juce::File path (File ("/path").getChildFile ("to").getChildFile ("file.txt"));

在这个例子中代码变得更冗长，但在实际场景中，通常需要从同一目录访问多个文件。因此，将父目录存储在一个File对象中，并在需要时请求子文件是合理的。

在Windows上，等效的绝对路径可能是：

juce::File path ("C:\path\to\file.txt");

处理子目录和父目录在每个平台上都是相同的。JUCE处理平台差异（例如路径分隔符）。

FilenameComponent类

在本教程中，我们将使用FilenameComponent对象，让用户通过标准操作系统窗口选择文件。我们可以给FilenameComponent对象附加一个监听器（参见教程：监听器与广播器），当文件改变时，我们可以将当前选择的文件作为File对象获取。

FilenameComponent对象显示一个包含绝对路径的文本框。它还提供一个按钮，让用户从操作系统中选择文件。还有一个包含最近使用文件列表的下拉菜单。这在使用过程中会自动填充，但也可以手动添加这些最近使用的文件（例如，硬编码到你的应用程序中或来自首选项文件）。

正如我们稍后将看到的，FilenameComponent构造函数有相当多的参数——而且它没有默认构造函数。在这种情况下，将子组件存储在std::uniqueptr对象中通常更容易。（因为这意味着它们不必在构造函数的类初始化列表中初始化。）我们还需要一个TextEditor组件，用来显示文件的内容。TextEditor类确实有默认构造函数，但为了保持一致，我们把两个组件对象都存储在std::unique_ptr对象中：

std::unique_ptr<juce::FilenameComponent> fileComp;
std::unique_ptr<juce::TextEditor> textContent;

在我们的MainContentComponent构造函数中，我们分配一个新的FilenameComponent对象，并用一些适合打开文件的设置初始化它（因为FilenameComponent类也可以用于选择保存文件的位置）。在这个构造函数中，我们可以提供一个希望能够选择的文件后缀列表（例如"*.txt;*.foo"）。我们也可以强制指定后缀（这对保存文件更有用）。在这两个参数中，我们传入空字符串，这意味着不会执行任何过滤。其他参数不言自明，定义了我们希望FilenameComponent对象表现的其他方式（参见代码中的注释）：

MainContentComponent()
{
    fileComp.reset (new juce::FilenameComponent ("fileComp",
        {}, // current file
        false, // can edit file name,
        false, // is directory,
        false, // is for saving,
        {}, // browser wildcard suffix,
        {}, // enforced suffix,
        "Select file to open")); // text when nothing selected
    addAndMakeVisible (fileComp.get());
    fileComp->addListener (this);

在FilenameComponentListener回调中，我们获取当前选择的文件并传给我们的readFile()函数：

void filenameComponentChanged (juce::FilenameComponent* fileComponentThatHasChanged) override
{
    if (fileComponentThatHasChanged == fileComp.get())
        readFile (fileComp->getCurrentFile());
}

在接下来的每个示例中，readFile()函数将以不同方式读取所选文件。但我们需要一个地方来显示结果，所以我们也在MainContentComponent构造函数中设置了一个TextEditor组件：

textContent.reset (new juce::TextEditor());
addAndMakeVisible (textContent.get());
textContent->setMultiLine (true);
textContent->setReadOnly (true);
textContent->setCaretVisible (false);
setSize (600, 400);
}

将整个文件读入字符串

虽然File类主要设计用于存储和操作文件路径，但有几个便捷函数能以非常简单的方式读取文件。例如，File::loadFileAsString()函数正如其名：它将整个文件读入一个String对象。当然，如果所选文件不是文本文件，那么结果可能无法理解（不过JUCE不会崩溃）。该函数可以检测并读取UTF-8和UTF-16格式：

void readFile (const juce::File& fileToRead)
{
    if (!fileToRead.existsAsFile()) // [1]
        return;
    auto fileText = fileToRead.loadFileAsString();
    textContent->setText (fileText);
}

注意我们检查了所选文件是否实际存在[1]。由于我们是从操作系统选择文件，这不应该失败，但在处理文件时进行这类检查是良好的做法。运行应用并加载演示项目Resources目录中提供的juce.txt文本文件。结果将如下面的截图所示：

还有一个等效的函数——File::loadFileAsData()——用于将整个文件读入MemoryBlock对象。

逐行读取文件

要更好地控制文件读取过程，你需要使用FileInputStream对象。一种方法是通过向FileInputStream的构造函数传入表示要读取文件的File对象来构造该对象[2]。

FileInputStream类是InputStream类的子类，它是读取数据的流的基类。

添加以下代码：

void readFile (const juce::File& fileToRead)
{
    if (!fileToRead.existsAsFile())
        return; // file doesn't exist
    juce::FileInputStream inputStream (fileToRead); // [2]
    if (!inputStream.openedOk())
        return; // failed to open

我们将逐行读取文件，但还要检测以“*”字符开头的行。然后我们用不同的字体格式化这些行，将这些行用作其他文本的标题。添加以下代码：

textContent->clear();
auto normalFont = textContent->getFont();
auto titleFont = normalFont.withHeight (normalFont.getHeight() * 1.5f).boldened();
juce::String asterix ("*");

下一部分是在while()循环中从inputStream对象读取数据，直到流被耗尽[3]。添加这段代码：

while (!inputStream.isExhausted()) // [3]
{
    auto line = inputStream.readNextLine();
    if (line.startsWith (asterix))
    {
        line = line.removeCharacters (asterix);
        textContent->setFont (titleFont);
    }
    else
    {
        textContent->setFont (normalFont);
    }
    // append the text to the textContent
    textContent->insertTextAtCaret (line + juce::newLine);
}
}

你可以看到，这段代码：

  • 使用InputStream::readNextLine()函数读取一行，
  • 检查该行是否以“*”开头，
  • 相应地设置textContent对象的字体，
  • 如有必要，移除任何“*”字符，并且
  • 将该行文本追加到textContent对象。

逐字节读取文件

InputStream以及FileInputStream类也有以更小片段读取文件的函数，甚至可以一次读取一个字节。为了说明这一点，让我们加载一个文本文件，并用不同的颜色显示每个单词。首先让我们添加一个生成随机颜色的函数。添加这个函数，它生成随机颜色，但将亮度限制在指定的最小值（这是为了确保颜色在黑色背景上可见）：

static juce::Colour getRandomColour (float minBrightness)
{
    auto& random = juce::Random::getSystemRandom();
    juce::Colour colour ((juce::uint8) random.nextInt (256),
        (juce::uint8) random.nextInt (256),
        (juce::uint8) random.nextInt (256));
    return colour.getBrightness() >= minBrightness ? colour
                                                   : colour.withBrightness (minBrightness);
}

现在让我们添加一个从FileInputStream对象读取数据直到遇到空格字符的函数。它将返回直到并包括空格的文本。它使用MemoryBlock类创建一个小内存缓冲区，然后使用InputStream::readByte()函数从inputStream对象一次读取一个字节：

static juce::String readUpToNextSpace (juce::FileInputStream& inputStream)
{
    juce::MemoryBlock buffer (256);
    auto* data = static_cast<char*> (buffer.getData());
    size_t i = 0;
    while ((data[i] = inputStream.readByte()) != 0 && i < buffer.getSize())
        if (data[i++] == ' ')
            break;
    return juce::String::fromUTF8 (data, (int) i); // [4]
}

String::fromUTF8()[4]函数尝试将原始二进制数据转换为String对象。

最后，在我们的readFile()函数中，我们使用readUpToNextSpace函数从文本文件中读取单词，直到流被耗尽。添加以下代码：

void readFile (const juce::File& fileToRead)
{
    if (!fileToRead.existsAsFile())
        return; // file doesn't exist
    juce::FileInputStream inputStream (fileToRead);
    if (!inputStream.openedOk())
        return; // failed to open
    textContent->clear();
    while (!inputStream.isExhausted())
    {
        auto nextWord = readUpToNextSpace (inputStream);
        textContent->setColour (juce::TextEditor::textColourId, getRandomColour (0.75f));
        textContent->insertTextAtCaret (nextWord);
    }
}

创建FileInputStream对象的另一种方法是使用File::createInputStream()函数。该函数在堆上返回一个FileInputStream对象，使用new运算符分配。这意味着在你完成后释放该对象非常重要。理想情况下，你应该为此使用std::unique_ptr对象。这里的一个细微差别是，如果文件流打开失败，File::createInputStream()函数将返回nullptr值。以下代码展示了在这种情况下你应该使用的典型模式：

void readFile (const juce::File& fileToRead)
{
    if (!fileToRead.existsAsFile())
        return; // file doesn't exist
    if (std::unique_ptr<juce::FileInputStream> inputStream { fileToRead.createInputStream() })
    {
        textContent->clear();
        while (!inputStream->isExhausted())
        {
            auto nextWord = readUpToNextSpace (*inputStream);
            textContent->setColour (juce::TextEditor::textColourId, getRandomColour (0.75f));
            textContent->insertTextAtCaret (nextWord);
        }
    }
}

练习：你可能会注意到，某些行末尾单词的颜色与下一行开头单词的颜色相同。这是因为我们只把空格字符作为分隔符来查找。修改代码，同时查找换行、回车和制表符。（这些字符是'\n'、'\r'和'\t'。）

读取二进制数据

在本教程中，我们研究了从文件中读取字符串数据。除了从文件读取单个字节外，InputStream类还包含读取其他基本类型的函数。例如：

  • InputStream::readInt()——从流中读取一个int（32位）。
  • InputStream::readShort()——从流中读取一个short（16位）整数。
  • InputStream::readFloat()——从流中读取一个float（32位）。

这些都使用小端字节序读取多字节值。要以大端值读取它们，有替代版本——例如，InputStream::readIntBigEndian()函数。你还可以使用InputStream::read()或InputStream::readIntoMemoryBlock()函数从流中读取一块数据。

如果你需要读取现有的二进制格式文件，或者确实需要将数据存储为二进制，这些函数很有用。在大多数情况下，使用XML（通过XmlDocument和XmlElement类）或JSON（通过将数据存储在var对象中）来存储和读取数据可能更可取。

小结

本教程通过以各种方式读取文本文件，介绍了使用JUCE的简单文件读取技术。特别是你应该能够：

  • 使用FilenameComponent和FilenameComponentListener存储文件路径，并为用户提供选择文件的方法。
  • 将文件的全部内容读入String对象。
  • 使用适当的InputStream函数以更小的片段读取文件。
