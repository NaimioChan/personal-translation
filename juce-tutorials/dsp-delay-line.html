简介

在本教程中，我们介绍两个新的 DSP 概念，它们能以不同的方式处理信号：延迟线和物理建模。

让我们先定义这些 DSP 术语。

什么是延迟线？

延迟线是 DSP 中的一个基础工具，可用于广泛的应用，包括混响空间模拟、声音合成、滤波器实现以及经典的基于时间的效果，如延迟、合唱、相位器和镶边。

从根本上说，延迟线非常简单，它允许我们把某个信号延迟若干个采样。通过使用多条延迟线，并在不同时间间隔把各自的信号重新相加，我们可以创造出目前存在的绝大多数数字信号处理。

在模拟域中，延迟线通过引入实际的物理延长（例如弹簧）来延迟波的传播。在数字域中，延迟线通常使用一种称为环形缓冲区的数据结构来实现。

环形缓冲区本质上可以实现为一个数组，其索引环绕自身，从而创建一个与采样缓冲区块大小相匹配的环形数据结构。这使我们能够存储前一个块中包含的所有采样，以便在当前块中访问，随后这些采样会被当前采样块覆盖，供下一次迭代使用。

在本教程中，我们将研究把环形缓冲区作为实现延迟线的方式。

什么是物理建模？

物理建模指一种依靠数学和物理模型来生成声音的合成方法。与其他合成技术不同，它不以任何采样作为起点，而是通过对材料的研究，专注于声音在物理意义上如何产生。

其中一种模型称为数字波导，它基于声波在管或管道中传播的物理模型。这些波在边界处的反射可以使用延迟线高效地计算，因此用这种模型可以生成许多乐器（如弦乐器）的声音。

波导弦模型

简而言之，波导弦模型建立在这一概念之上：振动的弦可以用两列沿相反方向传播并在两个端点反弹的波来建模。这两列波相加后的组合最终模拟了拨弦的理想运动，它们可以用两条延迟线实现：一条前向延迟线和一条后向延迟线。

然而，这个理想的弦模型永远不会在当前状态下静止，因为没有考虑阻尼。因此，当波在边界处改变方向且极性反转时，我们可以引入一个阻尼因子来减小波的位移。

在这个模型中还要考虑的其他变量是：应该在何处拨弦，以及应该从何处拾取振动弦的声音。因此，我们必须整合一个拨弦位置（两列波将从该处传播）和一个拾音位置，就像你在空间中的特定位置聆听声音一样。

最后但同样重要的是，物理弦中会出现一种自然现象：高频比低频衰减得更快。这可以通过简单地在边界的一端添加一个低通滤波器来轻松整合到我们的模型中，以模拟这种衰减时间的差异。

在本教程中，我们将使用延迟线来实现这个数字波导模型，以模拟在相连弦的边界处反射的波的拨弦。

实现延迟线

让我们先用 vector 把一条简单的延迟线实现为环形缓冲区。

在 DelayLine 类中，已经定义了几个不言自明的辅助函数以方便实现，例如 size() 和 resize() 方法、一个 clear() 函数，以及一个检索缓冲区中最近最少使用的采样的 back() 函数。

我们首先实现 push() 函数，它通过覆盖最近最少添加的采样来添加一个新采样 [1]，并通过按环形缓冲区的大小环绕索引来更新最近最少使用的索引变量 [2]：

void push (Type valueToAdd) noexcept
{
    rawData[leastRecentIndex] = valueToAdd; // [1]
    leastRecentIndex = leastRecentIndex == 0 ? size() - 1 : leastRecentIndex - 1; // [2]
}

然后我们完成 get() 函数，返回位于函数参数所指定偏移处的采样，同时确保索引环绕 vector [3]。注意这里我们确保延迟不超过缓冲区的大小。

Type get (size_t delayInSamples) const noexcept
{
    jassert (delayInSamples >= 0 && delayInSamples < size());
    return rawData[(leastRecentIndex + 1 + delayInSamples) % size()]; // [3]
}

接下来，我们填充 set() 函数，对函数参数所指定偏移处的采样赋值，同时确保索引环绕 vector [4]。这里同样确保延迟不超过缓冲区的大小。

void set (size_t delayInSamples, Type newValue) noexcept
{
    jassert (delayInSamples >= 0 && delayInSamples < size());
    rawData[(leastRecentIndex + 1 + delayInSamples) % size()] = newValue; // [4]
}

这样我们就完成了简单延迟线的实现。

集成延迟效果

实现了基本的延迟线类后，让我们把一个立体声延迟效果集成到信号链中。

在 Delay 类中，有多个参数可以调整以改变延迟效果的行为，包括各个声道的延迟时间、允许的最大延迟时间、效果的干/湿电平以及反馈量。

使用这些参数和延迟线的实现，我们可以按需创建各种各样的延迟效果，但让我们先从构造函数中定义的默认参数开始：

{
public:
    //==============================================================================
    Delay()
    {
        setMaxDelayTime (2.0f);
        setDelayTime (0, 0.7f);
        setDelayTime (1, 0.5f);
        setWetLevel (0.8f);
        setFeedback (0.5f);
    }

这些辅助函数主要设置相应的成员变量来存储参数，但其中一些还需要调整数据结构的大小，以适应参数的变化。

其中一个例子是下面定义的 setMaxDelayTime() 函数，它调用 updateDelayLineSize() 辅助函数 [1]：

void setMaxDelayTime (Type newValue)
{
    jassert (newValue > Type (0));
    maxDelayTime = newValue;
    updateDelayLineSize(); // [1]
}

完成下面的函数，它通过调整 vector 的大小 [2]，确保所有延迟线的环形缓冲区都足够大，能够容纳直到最大延迟时间的任何延迟时间：

void updateDelayLineSize()
{
    auto delayLineSizeSamples = (size_t) std::ceil (maxDelayTime * sampleRate);
    for (auto& dline : delayLines)
        dline.resize (delayLineSizeSamples); // [2]
}

另一个值得注意的情况是各声道的 setDelayTime() 函数，其中参数变化会如下调用 updateDelayTime() 辅助函数 [3]：

void setDelayTime (size_t channel, Type newValue)
{
    if (channel >= getNumChannels())
    {
        jassertfalse;
        return;
    }
    jassert (newValue >= Type (0));
    delayTimes[channel] = newValue;
    updateDelayTime(); // [3]
}

实现这个辅助函数，它根据新的参数变化重新计算所有声道的以采样为单位的延迟时间 [4]：

void updateDelayTime() noexcept
{
    for (size_t ch = 0; ch < maxNumChannels; ++ch)
        delayTimesSample[ch] = (size_t) juce::roundToInt (delayTimes[ch] * sampleRate);
}

在 reset() 函数中，我们重置每个声道的滤波器 [5]（我们将在本教程的下一节中使用它），并清除延迟线中残留的任何旧采样 [6]：

void reset() noexcept
{
    for (auto& f : filters)
        f.reset(); // [5]
    for (auto& dline : delayLines)
        dline.clear(); // [6]
}

在 prepare() 函数中，我们确保延迟线的大小 [7] 和以采样为单位的延迟时间 [8] 仍然正确（以防采样率在采样块之间发生了变化），并暂时用一个低通滤波器初始化滤波器 [9]：

void prepare (const juce::dsp::ProcessSpec& spec)
{
    jassert (spec.numChannels <= maxNumChannels);
    sampleRate = (Type) spec.sampleRate;
    updateDelayLineSize(); // [7]
    updateDelayTime(); // [8]
    filterCoefs = juce::dsp::IIR::Coefficients<Type>::makeFirstOrderLowPass (sampleRate, Type (1e3)); // [9]
    for (auto& f : filters)
    {
        f.prepare (spec);
        f.coefficients = filterCoefs;
    }
}

现在让我们处理 process() 函数，真正实现延迟效果：

template <typename ProcessContext>
void process (const ProcessContext& context) noexcept
{
    auto& inputBlock = context.getInputBlock();
    auto& outputBlock = context.getOutputBlock();
    auto numSamples = outputBlock.getNumSamples();
    auto numChannels = outputBlock.getNumChannels();
    jassert (inputBlock.getNumSamples() == numSamples);
    jassert (inputBlock.getNumChannels() == numChannels);
    for (size_t ch = 0; ch < numChannels; ++ch)
    {
        auto* input = inputBlock.getChannelPointer (ch);
        auto* output = outputBlock.getChannelPointer (ch);
        auto& dline = delayLines[ch];
        auto delayTime = delayTimesSample[ch];
        auto& filter = filters[ch];
        for (size_t i = 0; i < numSamples; ++i)
        {
            auto delayedSample = dline.get (delayTime); // [10]
            auto inputSample = input[i]; // [11]
            auto dlineInputSample = std::tanh (inputSample + feedback * delayedSample); // [12]
            dline.push (dlineInputSample); // [13]
            auto outputSample = inputSample + wetLevel * delayedSample; // [14]
            output[i] = outputSample; // [15]
        }
    }
}
  • [10]：首先，对于每个声道缓冲区块中的每个采样，从对应的延迟线中取出延迟采样。
  • [11]：然后从输入块中获取当前采样。
  • [12]：接下来，用 std::tanh() 把输入采样与按反馈参数加权的延迟线输出混合，计算要推入延迟线的采样。双曲正切函数使我们能够平滑地组合两个信号，而不会对求和后的采样造成削波，并提供自然的衰减。
  • [13]：然后我们把上一步计算出的采样推入延迟线。
  • [14]：最后，把输入采样与按干/湿参数加权的延迟线输出混合，计算出输出采样。
  • [15]：然后把该采样赋值到输出块。

如果在 Delay 类中实现上述更改后运行这段代码，我们应该能听到振荡器信号上的延迟效果。

对延迟效果进行滤波

大多数延迟效果在信号重复和衰减时会对信号进行滤波，以提供更逼真的声音，就像自然界中发生的那样。所以让我们对延迟的声音施加一些滤波。

这可以很容易地实现，只需在 Delay 类的 process() 函数中更改一行，如下所示：

template <typename ProcessContext>
void process (const ProcessContext& context) noexcept
{
    //...
    for (size_t ch = 0; ch < numChannels; ++ch)
    {
        //...
        for (size_t i = 0; i < numSamples; ++i)
        {
            auto delayedSample = filter.processSample (dline.get (delayTime)); // [1]
            auto inputSample = input[i];
            auto dlineInputSample = std::tanh (inputSample + feedback * delayedSample);
            dline.push (dlineInputSample);
            auto outputSample = inputSample + wetLevel * delayedSample;
            output[i] = outputSample;
        }
    }
}

这里我们只需把来自延迟线的延迟采样传给滤波器对象，并在其上调用 processSample() 函数 [1]。

在 prepare() 函数中，通过替换系数并调用 makeFirstOrderHighPass() 函数 [2]，把滤波器类型改为高通滤波器，如下所示：

void prepare (const juce::dsp::ProcessSpec& spec)
{
    //...
    filterCoefs = juce::dsp::IIR::Coefficients<Type>::makeFirstOrderHighPass (sampleRate, Type (1e3)); // [2]
    //...
}

集成波导弦模型

由于我们已方便地为延迟效果实现了延迟线，我们可以使用同一个类、同样的数据结构来集成波导弦模型。

在 WaveguideString 类中，有多个参数可以调整以改变弦模型的行为，包括触发位置、拾音位置以及弦阻尼的衰减时间。

默认参数在构造函数中定义，它们进而设置相应的成员变量，如下所示：

public:
//==============================================================================
WaveguideString()
{
    setTriggerPosition (Type (0.2));
    setPickupPosition (Type (0.8));
    setDecayTime (Type (0.5));
}

这些辅助函数还会调用 updateParameters() 函数，该函数初始化各种变量，例如延迟线的大小、相对于延迟线的拾音索引、相对于前向延迟线的触发索引、滤波器系数，以及基于衰减时间的衰减系数。

如下所述添加这个辅助函数的实现：

void updateParameters()
{
    auto length = (size_t) juce::roundToInt (sampleRateHz / freqHz); // [1]
    forwardDelayLine.resize (length);
    backwardDelayLine.resize (length);
    forwardPickupIndex = (size_t) juce::roundToInt (jmap (pickupPos, Type (0), Type (length / 2 - 1))); // [2]
    backwardPickupIndex = length - 1 - forwardPickupIndex;
    forwardTriggerIndex = (size_t) juce::roundToInt (jmap (triggerPos, Type (0), Type (length / 2 - 1))); // [3]
    filter.coefficients = juce::dsp::IIR::Coefficients<Type>::makeFirstOrderLowPass (sampleRateHz, 4 * freqHz); // [4]
    decayCoef = juce::jmap (decayTime, std::pow (Type (0.999), Type (length)), std::pow (Type (0.99999), Type (length))); // [5]
    reset();
}
  • [1]：首先，我们把延迟线的大小调整为采样率除以所演奏音符的基频。这源于这样一个事实：基频等于采样频率除以循环中所需的采样数。
  • [2]：接下来，我们把 0.0 .. 1.0 范围内的变量映射到 0 到延迟线长度一半的范围，从而得到前向延迟线上拾音位置的索引。这是为了容纳完整的周期，其中包括行波的两个方向以及极性翻转。后向延迟线上拾音位置的索引则通过取前向索引的相反值来计算。
  • [3]：前向延迟线上触发位置的索引以同样的方式从 0.0 .. 1.0 范围映射到 0 到延迟线长度一半的范围。
  • [4]：然后，模拟衰减行为的低通滤波器的系数被设置为比基频高四倍的频率。
  • [5]：最后，通过把 0.0 .. 1.0 范围映射到 0.999^length 到 0.99999^length 的范围，由衰减时间计算出衰减系数。这会产生接近 1 的值，描绘了物理振动弦上实际发生的极小阻尼。

在 reset() 函数中，我们重置延迟线，以清除残留的任何旧采样：

void reset() noexcept
{
    forwardDelayLine.clear();
    backwardDelayLine.clear();
}

在 prepare() 函数中，我们创建一个临时音频块，稍后将用于处理 [6]，并通过再次调用 updateParameters() 函数 [7]，确保参数仍然正确（以防采样率在采样块之间发生了变化）：

void prepare (const juce::dsp::ProcessSpec& spec)
{
    sampleRateHz = (Type) spec.sampleRate;
    tempBlock = juce::dsp::AudioBlock<float> (heapBlock, spec.numChannels, spec.maximumBlockSize); // [6]
    filter.prepare (spec);
    updateParameters(); // [7]
}

为了触发拨弦引起的弦激励，我们必须设置由两条延迟线表示的两列波的初始位移。

为此，在 trigger() 函数中，首先在从延迟线起点到触发位置索引所包含的采样之间迭代，通过把索引映射到递增的值（最大达到音符力度的一半）来计算每个采样的值，并把它们按相反方向赋值到延迟线 [8]。对触发位置索引到延迟线末端之间包含的采样做同样的处理，值从音符力度的一半递减 [9]。

void trigger (Type velocity) noexcept
{
    jassert (velocity >= Type (0) && velocity <= Type (1));
    for (size_t i = 0; i <= forwardTriggerIndex; ++i) // [8]
    {
        auto value = juce::jmap (Type (i), Type (0), Type (forwardTriggerIndex), Type (0), velocity / 2);
        forwardDelayLine.set (i, value);
        backwardDelayLine.set (getDelayLineLength() - 1 - i, value);
    }
    for (size_t i = forwardTriggerIndex; i < getDelayLineLength(); ++i) // [9]
    {
        auto value = juce::jmap (Type (i), Type (forwardTriggerIndex), Type (getDelayLineLength() - 1), velocity / 2, Type (0));
        forwardDelayLine.set (i, value);
        backwardDelayLine.set (getDelayLineLength() - 1 - i, value);
    }
}

为了在一个缓冲区块中生成所有采样，我们声明一个只返回一次采样生成迭代的辅助函数，如下所示：

Type processSample() noexcept
{
    auto forwardOut = forwardDelayLine.back(); // [10]
    auto backwardOut = backwardDelayLine.back(); // [11]
    forwardDelayLine.push (-backwardOut); // [12]
    backwardDelayLine.push (-decayCoef * filter.processSample (forwardOut)); // [13]
    return forwardDelayLine.get (forwardPickupIndex) + backwardDelayLine.get (backwardPickupIndex); // [14]
}
  • [10]：首先，我们通过调用前面声明的 back() 函数，从前向延迟线的环形缓冲区中取出最近最少使用的采样。
  • [11]：我们对后向延迟线的最近最少使用的采样做同样的处理。
  • [12]：接下来，我们必须通过反转极性，把这个位于后向延迟线边界处的最后一个采样推入前向延迟线。
  • [13]：然后，我们对另一条延迟线做同样的处理，但这一次先用低通滤波器对采样滤波，并乘以衰减系数以施加阻尼，然后再反转极性并把采样推入环形缓冲区。
  • [14]：最后，我们通过对两条延迟线在各自拾音索引处的信号求和，返回从拾音位置录制的采样。

在 process() 函数中，只需通过调用 processSample() 辅助函数处理缓冲区块中的所有采样，并把值赋给之前创建的临时块 [15]。然后把采样复制到音频块的所有声道 [16]，并把临时块的内容连同输入块中包含的原始内容一起添加到输出块 [17]。

template <typename ProcessContext>
void process (const ProcessContext& context) noexcept
{
    auto&& outBlock = context.getOutputBlock();
    auto numSamples = outBlock.getNumSamples();
    auto* dst = tempBlock.getChannelPointer (0);
    for (size_t i = 0; i < numSamples; ++i) // [15]
        dst[i] = processSample();
    for (size_t ch = 1; ch < tempBlock.getNumChannels(); ++ch) // [16]
        juce::FloatVectorOperations::copy (tempBlock.getChannelPointer (ch),
            tempBlock.getChannelPointer (0),
            (int) numSamples);
    outBlock.copyFrom (context.getInputBlock()).add (tempBlock.getSubBlock (0, outBlock.getNumSamples()));
}

    masterGainIndex
};
juce::dsp::ProcessorChain<CustomOscillator<float>, WaveguideString<float>, juce::dsp::Gain<float>> processorChain; // [18]
};

在 noteStarted() 函数中，移除设置振荡器电平的那一行，因为我们将使用波导弦模型来生成声音。从处理器链中获取弦模型的引用 [20]，把弦的基频设置为所演奏音符的频率 [21]，并用音符力度调用 trigger() 函数来触发拨弦 [22]。

void noteStarted() override
{
    auto velocity = getCurrentlyPlayingNote().noteOnVelocity.asUnsignedFloat();
    auto freqHz = (float) getCurrentlyPlayingNote().getFrequencyInHertz();
    processorChain.get<oscIndex>().setFrequency (freqHz, true);
    // processorChain.get<oscIndex>().setLevel (velocity);
    auto& stringModel = processorChain.get<stringIndex>(); // [20]
    stringModel.setFrequency (freqHz); // [21]
    stringModel.trigger (velocity); // [22]
}
