波表合成

用波表优化你的合成器振荡器。使用波表管理正弦波振荡器的状态，并把数据写入音频输出。

难度：中级
平台：Windows、macOS、Linux
类：AudioBuffer, AudioAppComponent, Random, MathConstants

波表

波表合成是一种使用查找表的合成方法，查找表中预先填入了周期波形，用于生成振荡器，从而不必为每个计算出的采样生成相同的波形。波表用你选择的周期波形初始化，并且可以指定这些波形的分辨率。在获取要输出的正确采样值时，如果表中的采样数与音频缓冲区块中的采样数及其对应的请求频率不匹配，就通过在两个波表采样之间插值来求得该值。

举个例子，假设我们要从波表中查找正弦波。我们首先会为一个正弦波周期创建波表，例如分辨率为 128 个采样点。然后对于缓冲区块中的每个采样，我们可以结合采样率、要演奏的请求频率、波表的分辨率以及波形当前的相位或角度，计算出正确的插值采样，从而取得正弦波采样值。

在深入波表之前，我们先从一个简单的正弦波振荡器实现开始。

正弦波振荡器

本节内容在教程：构建正弦波合成器中有更详细的讲解，如果你需要这些步骤的帮助，请先参阅该教程。

在 SineOscillator 类中，我们维护两个成员变量，分别存储波形周期中当前的角度或相位，以及根据频率和采样率在每个周期之间需要递增的角度增量：

class SineOscillator
{
public:
    SineOscillator() {}
    //...
private:
    float currentAngle = 0.0f, angleDelta = 0.0f;
};

setFrequency() 函数让我们能够计算角度增量：先把频率除以采样率，再把结果乘以 2pi，即一个周期以弧度表示的长度：

void setFrequency (float frequency, float sampleRate)
{
    auto cyclesPerSample = frequency / sampleRate;
    angleDelta = cyclesPerSample * juce::MathConstants<float>::twoPi;
}

getNextSample() 函数由AudioSource的 getNextAudioBlock() 函数对缓冲区中的每个采样调用，用于从振荡器取得采样值。这里我们用 std::sin() 函数计算采样值，把当前角度作为参数传入，并通过调用后面定义的辅助函数 updateAngle() 更新当前角度：

forcedinline float getNextSample() noexcept
{
    auto currentSample = std::sin (currentAngle);
    updateAngle();
    return currentSample;
}

角度的更新方式是：用在设置频率时先前算出的角度增量递增当前角度，并在角度超过 2pi 时把该值回绕：

forcedinline void updateAngle() noexcept
{
    currentAngle += angleDelta;
    if (currentAngle >= juce::MathConstants<float>::twoPi)
        currentAngle -= juce::MathConstants<float>::twoPi;
}

现在我们转到 MainContentComponent 类的实现。

我们用一个私有成员变量维护输出的总电平，另一个维护振荡器数组，如下所示：

class MainContentComponent : public juce::AudioAppComponent,
                             public juce::Timer
{
    //...
private:
    //...
    float level = 0.0f;
    juce::OwnedArray<SineOscillator> oscillators;
    //...
};

在 prepareToPlay() 函数中，我们必须初始化振荡器，并根据采样率设置它们要演奏的频率，如下所示：

void prepareToPlay (int, double sampleRate) override
{
    auto numberOfOscillators = 200; // [1]
    for (auto i = 0; i < numberOfOscillators; ++i)
    {
        auto* oscillator = new SineOscillator(); // [2]
        auto midiNote = juce::Random::getSystemRandom().nextDouble() * 36.0 + 48.0; // [3]
        auto frequency = 440.0 * pow (2.0, (midiNote - 69.0) / 12.0); // [4]
        oscillator->setFrequency ((float) frequency, (float) sampleRate); // [5]
        oscillators.add (oscillator);
    }
    level = 0.25f / (float) numberOfOscillators; // [6]
}
  • [1]：首先我们定义大量振荡器，以评估这样的数量带来的 CPU 负载。
  • [2]：对于每个振荡器，我们实例化一个新的 SineOscillator 对象，它生成一个正弦波声部。
  • [3]：我们还用Random类随机选择一个 MIDI 音符：把可能的最低音符上移 4 个八度，并从该最低音符起定义一个 3 个八度的范围。
  • [4]：为了计算该 MIDI 音符的频率，我们用一个简单的数学公式求出与 A440 频率相乘的系数。由于已知 A440 的 MIDI 音符编号是 69，用该 MIDI 音符减去 69 就得到与 A440 的半音距离，然后把它代入以下公式：440 * 2 ^ (d / 12)
  • [5]：然后，我们把频率和采样率作为参数传给 setFrequency() 函数，设置振荡器的频率。我们还会把该振荡器加入振荡器数组。
  • [6]：最后，我们用一个较小的增益值除以振荡器数量来定义输出电平，以免把如此大量的振荡器采样相加时信号削波。

在 getNextAudioBlock() 函数中，我们只是把所有振荡器的采样相加，并把结果写入输出缓冲区，如下所示：

void getNextAudioBlock (const juce::AudioSourceChannelInfo& bufferToFill) override
{
    auto* leftBuffer = bufferToFill.buffer->getWritePointer (0, bufferToFill.startSample); // [7]
    auto* rightBuffer = bufferToFill.buffer->getWritePointer (1, bufferToFill.startSample);
    bufferToFill.clearActiveBufferRegion();
    for (auto oscillatorIndex = 0; oscillatorIndex < oscillators.size(); ++oscillatorIndex)
    {
        auto* oscillator = oscillators.getUnchecked (oscillatorIndex); // [8]
        for (auto sample = 0; sample < bufferToFill.numSamples; ++sample)
        {
            auto levelSample = oscillator->getNextSample() * level; // [9]
            leftBuffer[sample] += levelSample; // [10]
            rightBuffer[sample] += levelSample;
        }
    }
}
  • [7]：首先，我们取得左右声道的指针，用于写入输出缓冲区。
  • [8]：对于数组中的每个振荡器，我们取得指向该振荡器实例的指针。
  • [9]：然后对于音频采样缓冲区中的每个采样，我们取得正弦波采样，并用 level 变量调整增益。
  • [10]：最后，我们可以把这个采样值加到左右声道的采样上，并与其他振荡器的信号相加。

如果现在运行应用，我们应该能听到由叠加正弦波构成的随机噪声。

练习：不要生成随机的 MIDI 音符，而是找出某个和弦的 MIDI 音符，并从该和弦中生成随机音符。

波表振荡器

让我们把振荡器的实现改为波表合成方法。

在 MainContentComponent 类中，添加一个 AudioSampleBuffer 成员变量，用于保存我们单个正弦波周期的波表值 [1]。我们还用位移运算符把波表分辨率定义为一个 128 采样的常量 [2]：

private:
    juce::Label cpuUsageLabel;
    juce::Label cpuUsageText;
    const unsigned int tableSize = 1 << 7; // [2]
    float level = 0.0f;
    juce::AudioSampleBuffer sineTable; // [1]
    juce::OwnedArray<WavetableOscillator> oscillators;
    JUCE_DECLARE_NON_COPYABLE_WITH_LEAK_DETECTOR (MainContentComponent)
};

定义一个新函数 createWavetable()，它将在 MainContentComponent 构造函数中、开始音频处理之前被调用。

void createWavetable()
{
    sineTable.setSize (1, (int) tableSize);
    auto* samples = sineTable.getWritePointer (0); // [3]
    auto angleDelta = juce::MathConstants<double>::twoPi / (double) (tableSize - 1); // [4]
    auto currentAngle = 0.0;
    for (unsigned int i = 0; i < tableSize; ++i)
    {
        auto sample = std::sin (currentAngle); // [5]
        samples[i] = (float) sample;
        currentAngle += angleDelta;
    }
}
  • [3]：在这个函数中，通过调用 setSize() 方法初始化 AudioSampleBuffer，指定我们只需要一个声道，且采样数等于表大小，在我们的情况下分辨率是 128。然后取得该单声道缓冲区的写指针。
  • [4]：接下来，与前一部分类似地计算角度增量，但这次使用表大小，因此是用完整的 2pi 周期除以 127。
  • [5]：现在，对波表中的每个点，用 std::sin() 函数取得正弦波值，把该值赋给缓冲区采样，并按增量值递增当前角度。

在 MainContentComponent 构造函数中添加这个函数调用，如下所示：

MainContentComponent()
{
    cpuUsageLabel.setText ("CPU Usage", juce::dontSendNotification);
    cpuUsageText.setJustificationType (juce::Justification::right);
    addAndMakeVisible (cpuUsageLabel);
    addAndMakeVisible (cpuUsageText);
    createWavetable();
    setSize (400, 200);
    setAudioChannels (0, 2); // no inputs, two outputs
    startTimer (50);
}

现在波表应该包含一个完整正弦波周期的 128 个采样。

在 prepareToPlay() 函数的 for() 循环中，把下面这一行改为实例化 WavetableOscillator 对象，而不是 SineOscillator 对象：

for (auto i = 0; i < numberOfOscillators; ++i)
{
    auto* oscillator = new WavetableOscillator (sineTable);

这个构造函数把用于生成声音的波表作为参数，因此要相应地新建一个 WavetableOscillator 类，如下所示：

class WavetableOscillator
{
public:
    WavetableOscillator (const juce::AudioSampleBuffer& wavetableToUse)
        : wavetable (wavetableToUse)
    {
        jassert (wavetable.getNumChannels() == 1);
    }
private:
    const juce::AudioSampleBuffer& wavetable;
    float currentIndex = 0.0f, tableDelta = 0.0f;
};

不要维护波形周期的当前角度和角度增量，而是定义两个成员变量，分别存储当前的波表索引和波表的角度增量。另外，定义一个 AudioSampleBuffer 变量，用于保存要使用的波表的引用。

setFrequency() 函数（属于 WavetableOscillator 类）与之前实现的版本相当相似，区别在于角度增量是用波表大小计算的，而不是用 2pi 弧度的完整周期，如下所示：

void setFrequency (float frequency, float sampleRate)
{
    auto tableSizeOverSampleRate = (float) wavetable.getNumSamples() / sampleRate;
    tableDelta = frequency * tableSizeOverSampleRate;
}

getNextSample() 函数就是进行波表值之间插值、以取得正确采样值的地方。

forcedinline float getNextSample() noexcept
{
    auto tableSize = (unsigned int) wavetable.getNumSamples();
    auto index0 = (unsigned int) currentIndex; // [6]
    auto index1 = index0 == (tableSize - 1) ? (unsigned int) 0 : index0 + 1;
    auto frac = currentIndex - (float) index0; // [7]
    auto* table = wavetable.getReadPointer (0); // [8]
    auto value0 = table[index0];
    auto value1 = table[index1];
    auto currentSample = value0 + frac * (value1 - value0); // [9]
    if ((currentIndex += tableDelta) > (float) tableSize) // [10]
        currentIndex -= (float) tableSize;
    return currentSample;
}
  • [6]：首先，暂时保存波表中夹住我们要取的采样值的两个索引。如果较高的索引超出波表大小，就把该值回绕到表的开头。
  • [7]：接下来，用实际当前采样减去截断后的较低索引，计算出两个索引之间的插值分数。这应该给出一个介于 0 .. 1 之间的值，用来定义该分数。
  • [8]：然后取得指向 AudioSampleBuffer 的指针，读取这两个索引处的值并暂时保存。
  • [9]：然后用标准插值公式和先前算出的分数值取得插值后的采样值。
  • [10]：最后，递增表的角度增量，并在该值超过表大小时把它回绕。

运行应用时，这个实现应该给我们相同的输出声音。

练习：修改振荡器的数量，观察 CPU 占用的变化。

这个修改版代码的源代码可以在演示项目的 WavetableSynthTutorial_02.h 文件中找到。

回绕波表

如果你仔细观察了前面的代码，可能会注意到我们的波表中缺少一个值。最后一个值被跳过了，因为它回绕到了第一个值，而这两个值恰好相同。所以我们现在来修正它。

在 WavetableOscillator 构造函数中，把表大小变量赋值为波表分辨率减一，并相应地定义该成员变量，如下所示：

class WavetableOscillator
{
public:
    WavetableOscillator (const juce::AudioSampleBuffer& wavetableToUse)
        : wavetable (wavetableToUse),
          tableSize (wavetable.getNumSamples() - 1)
    {
        jassert (wavetable.getNumChannels() == 1);
    }
private:
    const juce::AudioSampleBuffer& wavetable;
    const int tableSize;
    float currentIndex = 0.0f, tableDelta = 0.0f;
};

setFrequency() 函数需要改用这个变量来更新，注意表的角度增量会稍微小一些：

void setFrequency (float frequency, float sampleRate)
{
    auto tableSizeOverSampleRate = (float) tableSize / sampleRate;
    tableDelta = frequency * tableSizeOverSampleRate;
}

getNextSample() 函数基本保持不变，只是我们不再需要对较高的索引做回绕，因为下一步我们会增大表的尺寸：

forcedinline float getNextSample() noexcept
{
    auto index0 = (unsigned int) currentIndex;
    auto index1 = index0 + 1;

这里与之前不同，我们把分辨率设得比定义值大 1，并把最后一个采样设为与第一个采样相同：

void createWavetable()
{
    sineTable.setSize (1, (int) tableSize + 1);
    auto* samples = sineTable.getWritePointer (0);
samples[tableSize] = samples[0];
}

这使我们能够减少处理调用中的回绕条件，并把这份负载转移到 createWavetable() 函数上，而该函数只在应用启动时调用一次。

结果听起来应该与前一节相同，但注意 CPU 占用略有下降。

练习：你能找到进一步优化这段代码的方法吗？DSP 中的每个算术运算都会影响性能，所以你应该尽量消除尽可能多的运算。

选择谐波

与其输出随机的正弦波声音，不如通过显式设置谐波来创建一个和谐的正弦波。

修改 createWavetable() 函数，把谐波合成到正弦波的波表采样中，如下所示：

void createWavetable()
{
    sineTable.setSize (1, (int) tableSize + 1);
    sineTable.clear();
    auto* samples = sineTable.getWritePointer (0);
    int harmonics[] = { 1, 3, 5, 6, 7, 9, 13, 15 };
    float harmonicWeights[] = { 0.5f, 0.1f, 0.05f, 0.125f, 0.09f, 0.005f, 0.002f, 0.001f }; // [1]
    jassert (juce::numElementsInArray (harmonics) == juce::numElementsInArray (harmonicWeights));
    for (auto harmonic = 0; harmonic < juce::numElementsInArray (harmonics); ++harmonic)
    {
        auto angleDelta = juce::MathConstants<double>::twoPi / (double) (tableSize - 1) * harmonics[harmonic]; // [2]
        auto currentAngle = 0.0;
        for (unsigned int i = 0; i < tableSize; ++i)
        {
            auto sample = std::sin (currentAngle);
            samples[i] += (float) sample * harmonicWeights[harmonic]; // [3]
            currentAngle += angleDelta;
        }
    }
    samples[tableSize] = samples[0];
}
  • [1]：定义两个数组，分别描述奇次谐波的序号及其对应的权重。
  • [2]：对每个谐波，用完整的 2pi 周期乘以谐波次数再除以表大小，计算出角度增量。这实际上是把生成的频率乘以谐波次数。
  • [3]：对表中的每个采样，从当前角度取得正弦值，用对应的谐波权重调整增益后把该值加到缓冲区中已有的采样上，并按增量值递增当前角度。

说明

本教程探讨了如何从正弦波创建波表，但基本上你可以存储任何类型的周期波形，只要第一个采样与最后一个采样相同。

小结

本教程中，我们学习了如何实现波表合成器。具体来说，我们：

  • 把正弦波振荡器转换为波表振荡器。

  • 把同一振荡器的随机谐波写入音频输出。
  • 通过选择谐波及其权重创建了和谐的声音。
