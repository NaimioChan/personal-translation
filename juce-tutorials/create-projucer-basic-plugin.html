创建一个基础音频/MIDI 插件，第 1 部分（项目搭建）

本教程将帮助你配置好计算机，并创建一个用 JUCE 开发音频插件（VST3 和 AudioUnit）的 Projucer 项目。最终，我们会得到一个会显示「Hello, World!」的音频插件，它可以被加载到 Cubase 或 REAPER 之类的 VST3 宿主中。

难度：中级
平台：Windows、macOS、Linux
插件格式：VST3、AU、Standalone

准备工作

下载 JUCE。解压 JUCE 文件夹，并把它放到计算机上的某个位置。用户主文件夹是个方便的选择。

启动 Projucer 应用，它位于你的 JUCE 文件夹中。

如果你还不熟悉 Projucer，请先阅读教程：Projucer 第 1 部分：Projucer 入门。

下载并安装插件依赖项

VST3 和 AudioUnit

创建 VST3 和 AU（仅 macOS）插件所需的所有文件都随 JUCE 一起打包提供（只要你在使用较新版本的 JUCE）。

用 Projucer 创建音频插件项目

要用 JUCE 创建音频插件，请在 Projucer 中新建一个项目，并选择 Audio Plug-In 作为项目类型。如果你不知道怎么做，请参阅教程：Projucer 第 1 部分：Projucer 入门。

在新项目的 Projucer 配置设置中，你可以修改项目设置，例如想导出哪些插件类型，以及插件是否接收或产生 MIDI 音符（此外还有很多其他选项）。这些设置随时都可以修改。

在本教程中我们要创建一个 VST3 插件，所以请确保在「Plugin Formats」字段中勾选了 VST3 设置。然后在下面的「Plugin Characteristics」字段中勾选 Plugin MIDI input 和 Plugin MIDI output。

配置就这些！现在点击 Save Project and Open in IDE…，你的新项目就会打开。点击构建按钮，确认插件能够构建成功、所有内容都已正确配置。

设置插件调试环境（可选）

构建插件时的挑战之一就是测试。幸运的是，JUCE 通过内置的插件宿主让这件事变得简单。要访问该宿主，请转到 extras/AudioPluginHost/，用 Projucer 打开其中的 .jucer 文件。点击 Save Project and Open in IDE…。然后在你的 IDE 中构建该项目以生成二进制文件（在 Mac OS X 上你可以在 extras/AudioPluginHost/Builds/MacOSX/build 找到它）。

运行该应用，你就会看到如下所示的图形化节点编辑器：

按下「Cmd-P」（或者转到 Options > Edit the List of Available Plug-ins…）即可更新系统中的插件列表（每个项目只需做一次）。点击弹出窗口底部的选项按钮，然后点击 Scan for new or updated VST3 plug-ins…。在 macOS 上，JUCE 音频插件会被自动复制到 ~/Library/Audio/Plug-Ins/VST3，宿主应用会自动搜索该文件夹，所以你无需手动指定查找位置——直接点击 Scan 即可。在 Windows 上，你需要手动把构建好的 VST3 从项目的构建文件夹复制到 VST3 安装文件夹，通常为 C:\Program Files\Common Files\VST3。

扫描完成后，回到节点编辑器并右键点击，然后从上下文菜单中选择你的插件（默认情况下它位于名为「yourcompany」的公司下——你可以在 Projucer 中修改这个名称）。连接各节点，使 MIDI 输入节点和 Audio Input 节点接入你插件的输入，并让插件的音频输出接入 Audio Output 节点。

双击你的插件即可启动 GUI。默认插件什么都不做，只显示 Hello world。

你可以选择 Options > Change the Audio Device Settings…，确保所有输入和输出都连接到正确的位置。按 File > Save 保存，方便以后轻松恢复这份配置。

以这种方式使用时，插件宿主为你提供了一个非常简单的插件测试环境，但我们还能做更多事情。我们可以配置宿主，以便对插件进行单步调试。在 macOS 上要做到这一点，请回到 Xcode 中的插件项目，点击 Product > Scheme > Edit Scheme…，然后在 Run 下从 Executable 下拉框中选择 Other…，并定位到 Plugin Host.app。确保勾选了 Debug executable。在 Windows 的 Visual Studio 中，你应当打开 VST3 构建目标的属性页，选择「Debugging」窗格，然后在「Command」字段中设置 AudioPluginHost 可执行文件的路径。

现在当你构建并运行插件时，宿主会自动启动；当插件在宿主中加载后，你就可以设置断点并进行单步调试了。

后续步骤

现在你已经准备好，可以编写一个真正处理音频的音频插件了。请继续阅读教程：创建一个基础音频/MIDI 插件，第 2 部分：编写插件代码。

说明

要构建 AAX 插件（用于 Pro Tools），你需要联系 Avid 获取开发者许可证，才能访问他们的 SDK。如果你确实获得了 AAX SDK 的访问权限，你会注意到 Projucer 的 Global Preferences 窗口中有一个可以设置的路径。

小结

读完本教程后，你应该能够：

  • 安装音频插件开发所需的依赖项，
  • 为 JUCE 音频插件创建 Projucer 项目，
  • 搭建音频插件开发的调试环境。
