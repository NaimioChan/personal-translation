Pgbrown

几何布朗运动模式

Pbrown : Pattern : AbstractFunction : Object

参见：BrownNoise、Pbrown

说明

返回一个行为类似几何布朗运动的流。

类方法

Pgbrown.new(lo: 0.0, hi: 1.0, step: 0.125, length: inf)

来自父类：Pbrown

参数：

lo

值的下边界。

hi

值的上边界。

step

每步的最大乘法因子（omega）——分布为 xrand2。

length

产生的值的数量。

实例方法

未文档化的实例方法

.calcNext(cur, step)

(
var a, b;
a = Pgbrown(0.0, 1.0, 0.2, inf);
b = a.asStream;
7.do({ b.next.postln });

)
