SCImageKernel

与 SCImage 配合使用的内核类

参见：SCImage、SCImageFilter

说明

// very experimental :)

目前该类表示 CoreImage CIKernel，你可以将其应用于 SCImage。Kernel 语言是 OpenGL 着色语言的一个子集。关于 Kernel 语言的更多信息可以在这里找到：http://developer.apple.com/documentation/GraphicsImaging/Reference/CIKernelLangRef/Introduction/chapter_1_section_1.html

以及这里：http://developer.apple.com/documentation/GraphicsImaging/Reference/CIKernelLangRef/chapter_2_section_1.html#//apple_ref/doc/uid/TP40004397-CH206-TPXREF101

这里是 Kernel 语言对象与 SuperCollider 对象之间的转换表

内核语言对象

SuperCollider 对象

sampler

SCImage

__color

Color

float

Number

vec2、vec3、vec4

Array

__table

SCImage（基本上就是 __table 修饰符，只是使用 Images 作为数据提供者 - LUT）

类方法

.new

创建一个新的 SCImageKernel

参数：

shader

可选。着色器代码字符串。默认为 nil

values

可选。与着色器字符串中定义的 kernel proc 函数匹配的值。默认为 nil

bounds

可选。目前未使用。默认为 nil

实例方法

.shader

获取或设置 shader 字符串。

.values

获取或设置 values 数组。设置时，values 数组中的对象索引必须与主 kernel vec4 routine 中定义的参数声明顺序一致。更多信息见 示例。

.isValid

用于判断着色器的所有参数是否都已设置的非常基本的验证。

.compile

编译 SCImageKernel 对象（并缓存它）。

注意： 首次渲染时，内核对象总是先被编译。如果你计划之后更改着色器字符串，必须显式编译它才能使其生效。

示例

/**** 核函数 ****/
// 非常实验性
// 颜色反转着色器示例
(
a = SCImage.new(SCDoc.helpSourceDir +/+ "images/vduck2.jpg"); // 获取图像
k = SCImageKernel.new;
k.shader_("

vec4    invertPixel(vec4 pix) {
    return vec4(1.0 - pix.r, 1.0 - pix.g, 1.0 - pix.b, pix.a);
}

kernel vec4 _invertColor(sampler source)
{
    vec4 pixel;
    pixel = sample(source, samplerCoord(source));
    unpremultiply(pixel);
    return unpremultiply(invertPixel(pixel));
}
");

// 参数顺序应保持在数组中
// 这里我们只需要 "sampler" 参数，根据转换表它应该是一个 SCImage
// Kernel 函数的签名通常是 'kernel vec4'
// 当然你也可以在 shader 中添加其他函数
k.values_([a]);

k.isValid.postln; // 是否可行
a.applyKernel(k);

w = a.plot(freeOnClose: true);
)


(
// 另一个 APPLE KERNEL 示例 - 原始示例参见 CoreImage 编程指南
a = SCImage.new(SCDoc.helpSourceDir +/+ "images/vduck2.jpg"); // 获取图像
k = SCImageKernel.new;
k.shader_("
vec2 testVec(float x, float y)
{
    return vec2(x, y);
}

kernel vec4 testKernelFromApple(sampler src, __color color, float distance, float slope)
{
    vec4     t;
    float    d;
    d = destCoord().y * slope + distance;
    t = unpremultiply(sample(src, samplerCoord(src)));
    t = (t - d*color) / (1.0-d);
    return premultiply(t);
}
");

// 如 Apple 示例中所述
// distance - min: 0.0 max: 1.0
// slope - min: -0.01 max: 0.01
k.values_(
    [
    a,        // 参数 0：SCImage
    Color.white,    // 参数 1：颜色
    0.5,         // 参数 2：距离
    -0.002        // 参数 3：斜率
    ]
);

a.applyKernel(k);

w = a.plot(freeOnClose: true);
)




(
// 好的，一个更好的彩色内核
a = SCImage.new(600@600); // 获取图像
k = SCImageKernel.new;

k.shader_(
// 来自 toneburst.com 的着色器/内核
// 为基于 VBO 的 3D 高度场生成球面和平面位移映射。
// http://machinesdontcare.wordpress.com
"
const float PI = 3.14159265359;
const float TWOPI = 6.28318530718;

kernel vec4 _heightMap(sampler image, vec3 scale)
{
    vec2 xyNorm = samplerCoord(image) / samplerSize(image);
    float u = xyNorm.x * PI;
    float v = xyNorm.y * TWOPI;
    vec3 spherical;
    spherical.r = cos(v) * sin(u);
    spherical.g = sin(v) * sin(u);
    spherical.b = cos(u);

    spherical.r = (spherical.r * 0.5 + 0.5) * scale.x;
    spherical.g = (spherical.g * 0.5 + 0.5) * scale.y;
    spherical.b = (spherical.b * 0.5 + 0.5) * scale.z;

    return vec4(spherical, 1.0);
}
");

k.values_([a, [1.0, 1.0, 1.0]]);

// k.isValid; // 它是否有效
a.applyKernel(k);
// .flatten; // 确保采用位图表示，这样内核就不会在每次渲染调用时都被应用 - 取消注释并重新调整绘图窗口大小即可看到差异。

w = a.plot(freeOnClose: true);
)
