Marks

（信息来自 EmacsWiki）

set-mark-command（`C-SPC'）

一个并非所有人都知道的实用特性是：如果用通用参数来调用它，会发生什么：‘C-u C-SPC’。通过跳转到保存在缓冲区本地标记环中的位置，这是回到之前编辑位置的简便方法。重复调用将在标记环中循环。

如果使用 TransientMarkMode 且希望设置标记但之后不想看到区域高亮，可以使用 ‘C-SPC C-g’ 设置标记，然后将其停用。

pop-global-mark（`C-x C-SPC'）

除了每个缓冲区自有的普通标记环之外，Emacs 还有一个全局标记环。它记录了你最近在其中设置标记的一系列缓冲区，因此你可以回到那些缓冲区。

设置标记始终会在当前缓冲区的标记环上产生一个条目。如果自上次设置标记以来你已切换过缓冲区，那么新的标记位置也会在全局标记环上产生一个条目。结果是，全局标记环记录了你曾处于的一系列缓冲区，并且对于每个缓冲区，记录了你设置标记的位置。

‘C-x C-SPC’（‘pop-global-mark’）跳转到全局标记环中最新条目的缓冲区及位置。它还会轮转该环，因此连续使用 ‘C-x C-SPC’ 会将您带到越来越早的缓冲区。

自定义 Emacs 的行为

你可以通过将内容放入 Emacs 的启动文件来自定义 Emacs 的行为。该文件是 ~/.emacs。你可以在其中定义选项，例如：

(custom-set-variables
 '(case-fold-search t)
 '(global-font-lock-mode t nil (font-lock))
 '(sclang-runtime-directory "~/SuperCollider/")
 '(show-paren-mode t nil (paren))
 '(transient-mark-mode t)
)

nil 表示选项关闭，t 或 1 表示选项开启。

'(sclang-eval-line-forward nil)

自定义 w3m

通常 w3m 使用方向键在超链接之间跳转。对于浏览 SC 帮助文件来说这不太有用。

(eval-after-load "w3m"
 '(progn
 (define-key w3m-mode-map [left] 'backward-char)
 (define-key w3m-mode-map [right] 'forward-char)
 (define-key w3m-mode-map [up] 'previous-line)
 (define-key w3m-mode-map [down] 'next-line)
 (setq w3m-auto-show 1)
 ))

(defun scroll-up-half ()
  "Scroll up half a page."
  (interactive)
  (scroll-up (/ (window-height) 2))
  )

(defun scroll-down-half ()
  "Scroll down half a page."
  (interactive)
  (scroll-down (/ (window-height) 2))
  )
(global-set-key [(mouse-5)] 'scroll-up-half)
(global-set-key [(mouse-4)] 'scroll-down-half)

最近文件菜单

Recentf 是一个次要模式，它会构建一个最近打开文件的列表。该列表会在 Emacs 会话之间自动保存。然后你可以通过菜单访问这个列表。将以下内容放入你的 `~/.emacs' 中：

(require 'recentf)
(recentf-mode 1)

要添加用于打开最近文件的快捷键（C-x C-r），还需添加以下代码：

(defun recentf-open-files-compl ()
  (interactive)
  (let* ((all-files recentf-list)
    (tocpl (mapcar (function
       (lambda (x) (cons (file-name-nondirectory x) x))) all-files))
    (prompt (append '("File name: ") tocpl))
    (fname (completing-read (car prompt) (cdr prompt) nil nil)))
    (find-file (cdr (assoc-ignore-representation fname tocpl)))))

(global-set-key "\C-x\C-r" 'recentf-open-files-compl)
