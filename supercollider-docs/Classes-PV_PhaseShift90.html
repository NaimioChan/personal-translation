PV_PhaseShift90

将相位偏移 90 度。

PV_MagSquared : PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

另请参阅：FFT、IFFT、PV_PhaseShift、PV_PhaseShift270、PV_Diffuser

说明

将所有频点的相位偏移 90 度。

类方法

PV_PhaseShift90.new(buffer)

来自父类：PV_MagSquared

参数：

buffer

FFT 缓冲区。

实例方法

示例

s.boot;

(
{ |out = 0, bufnum = 0|
    var in, fft, fft2, shifted;
    in = SinOsc.ar(500, 0, 0.1);
    fft = FFT(LocalBuf(2048), in);
    fft2 = FFT(LocalBuf(2048), in);
    shifted = PV_PhaseShift90(fft);
    Out.ar(out, [IFFT(fft2), IFFT(shifted)]);
}.scope
)
