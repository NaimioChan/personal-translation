CompositeView

包含其他视图的视图。

另请参见：FlowView、FlowLayout

说明

注意： 在 Qt GUI 中，每个视图都可以作为其他视图的父视图，因此 CompositeView 重定向到与 View 相同的类——你可以等价地使用后者。

CompositeView 可以作为其他视图的父视图，同时它本身又是 Window 或另一个 CompositeView 的子视图。除此之外，它没有自己的特殊方法。

注意： 在 Cocoa GUI 中，此视图接受按键操作，但不接受鼠标点击或拖动。

示例

坐标系

容器使用相对坐标，即视图相对于容器的左上角放置。

(
w = Window.new;

c = CompositeView(w, Rect(50, 0, 300, 300));
a = Slider2D(c, Rect(0, 0, 100, 100)); // 实际显示在 (50, 0)
b = Slider2D(c, Rect(100, 100, 100, 100));

c.background = Color.rand;

w.front;
)

c.bounds_(Rect(100, 0, 300, 300)); // 内容会调整，因为坐标是相对的
c.resize_(6); // 内容会调整，因为坐标是相对的

按键事件冒泡

如果视图本身未定义按键动作，按键动作会“冒泡”到父视图。在以下示例中，a 和 b 本身没有 keyDown 动作，因此按键事件被传递给父视图 c，它定义了 key down 动作。d 的父视图是 SCTopView，它没有 key down 动作。另请参阅 View。

( // 点击不同的视图，并在键盘上按键。

w = Window.new;

c = CompositeView(w, Rect(0, 0, 200, 200)).background_(Color.grey.alpha_(0.3));

a = Slider2D(c, Rect(0, 0, 100, 100)).background_(Color.rand);
b = Slider2D(c, Rect(100, 100, 100, 100)).background_(Color.rand);

w.front;

c.keyDownAction = {
    "keydown bubbled up to c".postln;
};

// d 位于窗口 w 上，而不是复合视图 c 上
d = Slider2D(w, Rect(200, 200, 100, 100));
d.background = Color.black;
)

Decorators

可以设置一个“装饰器”对象来处理布局管理。添加到 CompositeView 的所有视图现在都将由该装饰器放置。目前唯一存在的是 FlowLayout。你可以使用 ContainerView 的 addFlowLayout 方法作为将 FlowLayout 指定给装饰器的快捷方式。

(
a = Window.new;

b = CompositeView(a, Rect(0, 0, 500, 500));
b.decorator = FlowLayout(b.bounds);
// b.addFlowLayout; // 为方便起见，你也可以这样写

// 向 b 添加视图会自动使用装饰器
// 无需使用 parent.decorator.place
c = Slider2D(b, Rect(0, 0, 100, 100)); // 大小很重要
d = Slider2D(b, Rect(0, 0, 100, 100)); // origin 不

a.front;
)

你还可以在 VLayoutView、HLayoutView 或将 FlowLayout 作为其装饰器的视图中，将空复合视图用作间隔。

(
a = Window.new;
b = CompositeView(a, Rect(0, 0, 500, 500));

b.decorator = FlowLayout(Rect(0, 0, 500, 500));

Slider2D(b, Rect(0, 0, 100, 100)).background_(Color.rand);
CompositeView(b, Rect(0, 0, 70, 100)); // 仅用于间距
Slider2D(b, Rect(0, 0, 100, 100)).background_(Color.rand);
Slider2D(b, Rect(0, 0, 100, 100)).background_(Color.rand);

b.decorator.nextLine;

Slider2D(b, Rect(0, 0, 100, 100)).background_(Color.rand);
Slider2D(b, Rect(0, 0, 100, 100)).background_(Color.rand);
CompositeView(b, Rect(0, 0, 70, 100)); // 仅用于间距
Slider2D(b, Rect(0, 0, 100, 100)).background_(Color.rand);

a.front;
)

隐藏 / 交换

你可以将 CompositeView 相互堆叠，并使用一个按钮只显示其中之一：

(
var colors = [Color.blue, Color.red, Color.green];
a = Window.new;
q = 3;

b = Button(a, Rect(0, 0, 160, 20));

b.states = Array.fill(q, { |i|
    [i.asString, Color.white, colors.wrapAt(i)]
});

b.action = { |butt|
    p.visible = false;
    p = c.at(butt.value);
    p.visible = true;
};

c = Array.fill(q, { |i|
    b = CompositeView(a, Rect(0, 25, 300, 300));
    b.background = colors[i].alpha_(0.2);
    b.visible = false;
    b;
});

5.do{ |i| Slider(c[0], Rect(10, i * 30 + 10, 150, 25)).value_(1.0.rand) };
5.do{ |i| Slider(c[1], Rect(i * 30 + 10, 10, 25, 150)).value_(1.0.rand) };
Slider2D(c[2], Rect(10, 10, 155, 150)).x_(1.0.rand).y_(1.0.rand);

p = c.at(0); // 上一个
p.visible = true; // 显示第一个

a.front;
)

嵌套示例

在此示例中，StaticText 接受鼠标点击，因为容器视图无法做到：

(
w = Window.new.front;
v = CompositeView.new(w, w.view.bounds.insetBy(10)).background_(Color.rand);
v.decorator = FlowLayout(v.bounds);

l = "SUPERCOLLIDER".scramble;
t = Array.fill(9, { |i| var n, r, q;
    n = CompositeView.new(v, Rect(20, 20, 121, 121)).background_(Color.rand);
    q = StaticText(n, n.bounds.moveTo(0, 0).insetBy(25)).string_(l[i]).align_(\center);
    q.enabled = true;
    q.font = Font("Geneva", 10);
    q.background_(Color.rand);
    q.mouseDownAction = {
        n.background_(Color.rand);
        q.font = q.font.size_(5 + q.font.size + 7 % 60)
    };
});
)
