HelpBrowser

浏览 SuperCollider 帮助文档

另请参阅：SCDoc

说明

HelpBrowser 是一个 GUI 帮助浏览器，可让你浏览 SuperCollider 的文档。它与 SCDoc 耦合，以便即时渲染 HTML 帮助文件。

SuperCollider 中有两种不同的帮助浏览器：内置于 SCIDE 的帮助浏览器，以及这个用 sclang 的 GUI 功能实现的 HelpBrowser 类。两者都使用相同的底层 Qt WebEngine 浏览器实现。

由于 Qt WebEngine 依赖体积庞大且在某些系统上难以安装，sclang 有可能在没有 WebView 支持的情况下构建（编译时使用 CMake 标志 -DSC_USE_QTWEBENGINE=OFF）。如果是这样，尝试调用这个类将抛出错误。

键盘快捷键

与 SCIDE 内置的帮助浏览器不同，HelpBrowser 提供了类似 vim 的键盘导航快捷键，以及若干额外特性，可提升偏好键盘交互的用户的工作流程效率。

类方法

.instance

单例 HelpBrowser 实例。

.new

用给定的主页 URL 创建一个新的 HelpBrowser 实例。

.defaultHomeUrl

获取或设置默认的主页 URL。

.openNewWindows

获取或设置“在新窗口中打开”切换的默认值。

.goTo

使用单例实例或新窗口转到 url，取决于 openNewWindows 设置。

.openHelpFor

在单例 HelpBrowser 实例中打开给定文本对应的帮助页面。

.openSearchPage

在单例 HelpBrowser 实例中打开带有给定文本的帮助搜索页面。

.openBrowsePage

在单例 HelpBrowser 实例中打开类别浏览器页面。

参数：

category

一个可选的 String，用于从指定类别开始，例如 "UGens>Filters"

.openHelpForMethod

打开指定方法的帮助。

参数：

method

一个 Method

实例方法

.homeUrl

获取或设置主目录 URL。

.window

此 HelpBrowser 的 GUI 窗口。

讨论：

主要在需要显示浏览器时有用：

HelpBrowser.instance.window.front;

.goTo

转到指定的 URL。如果该 URL 指向 SCDoc: *helpTargetDir 下的文件，则会在需要时按需渲染。

.goHome

转到主页 URL。

.goBack

返回。

.goForward

向前翻。
