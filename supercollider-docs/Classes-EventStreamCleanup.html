EventStreamCleanup

用于收集流内部状态相关信息的辅助类，这些信息需要被释放

Object

说明

由 Pmono 或 Pfx 等对象创建的事件流是特殊的：当它们开始时，会创建一些状态（例如一个新的 synth），该状态在整个流期间持续存在，或至少持续多个事件。当这样的流结束时，它会释放这些状态。然而，还有其他流可能随时停止其输入流（例如 Pfindur 或 Pdef）。此时，嵌入在输入流层次结构中的任何流的状态都必须由它们释放。EventStreamCleanup 收集清理函数，并可以在流被切断时运行它们。

注意： 因此，所有能结束子模式（以及相应的流）的事件模式都必须使用 EventStreamCleanup。

一些可能停止输入流并更新 EventStreamCleanup 的模式示例：

  • Pbindf（当它的某个参数流结束时，会停止其事件流）
  • Pfin（在若干事件后停止流）
  • Pfindur（在特定经过时间后停止流）
  • Pdef（当被新的流替换时停止流）
  • Pset（当其参数流结束时停止其事件流）
  • Pswitch1（在固定数量的项目之后或其中一个流结束时停止所有输入流。不是 Pswitch，后者会完全嵌入每个输入流）

一些创建跨多个事件持续存在的状态的模式示例。它们还通过 EventStreamCleanup 释放该状态：

  • Pmono（启动一个合成器并随时间控制它）
  • Pfx（启动一个效果 Synth，并让子流的信号通过它）
  • Pproto（初始化资源并使其保持可用）
  • Pspawner（调度流，并在一段时间后释放它们）
// 将模式包裹在停止条件中
(
f = { |pat, condition|
    Prout { |inval|
        var stream = pat.asStream;
        var cleanup = EventStreamCleanup.new;
        var outval;
        while {
            outval = stream.next(inval);
            outval.notNil and: { condition.value(outval) }
        } {
            cleanup.update(outval);
            inval = outval.yield;
        };
        cleanup.exit(inval);
    }

};
p = Plazy { Pmono(\default, \note, Pgeom(rrand(1, 1.5), rrand(1.05, 2), inf), \harmonic, [0.78, 1, 1.2], \dur, 1/rrand(4, 7), \amp, 0.4) };
x = f.(p, { |outval| outval[\note] < 20 }); // 始终在 20 处停止
Pn(x).play; // 循环它。
);

类方法

EventStreamCleanup.new

创建一个新实例。

实例方法

.addFunction(event, function)

添加一个新的清理函数，当流在下游某处被结束时会调用该函数。仅在创建需要释放资源的模式（例如 Pmono 或 Pfx）中调用。

参数：

event

向下游传递的输出事件，它向任何结束流的模式传达释放资源所需执行的操作。它必须在 update 之后被 yield！

function

用于清理时调用的函数。例如 { group.free }。

返回值：

一个 CallOnce，它最多执行一次清理 function。如果需要在 EventStreamCleanup 的控制之外执行清理，则应使用返回的 CallOnce 而不是原始的 function，以便其他引用者得知清理已执行。

.update(event)

对于每个新事件，必须更新清理逻辑以从上游的任何输入流接收信息。此方法由所有可能提前停止的流调用（例如 Pmono 或 Pfindur）。

参数：

event

输入流的 outevent。它必须在 update 之后被 yield！

.exit(event, freeNodes: true)

运行随时间收集的所有函数，并向事件添加适当的信息，以备其作为 inevent 被传递。

参数：

event

传递到外部流的 inevent

freeNodes

内部使用。

返回值：

一个事件。在 embedInStream 中，必须返回此事件（^cleanup.exit(inevent)）

.functions

.functions = value

一组清理函数。

.clear

清空清理函数，但不求值它们。

.terminate(freeNodes: true)

运行随时间收集的所有函数，而不向事件添加信息。

参数：

freeNodes

内部使用。

示例

// 来自类库的一些代码

// 这里有一个可以在若干步之后从外部结束该流的 pattern
Pfin : FilterPattern {
    var <>count;
    *new { |count, pattern|
        ^super.new(pattern).count_(count)
    }
    storeArgs { ^[count, pattern] }

    embedInStream { |event|
        var inevent;
        var stream = pattern.asStream;
        var cleanup = EventStreamCleanup.new;
        count.value(event).do({
            inevent = stream.next(event) ?? { ^event };
            cleanup.update(inevent);
            event = inevent.yield;
        });
        ^cleanup.exit(event)
    }
}

// 这里有一个添加资源的 pattern：一个供事件播放的 bus

Pbus : FilterPattern {
    var <>numChannels, <>rate, <>dur = 2.0, <>fadeTime;

    *new { |pattern, dur = 2.0, fadeTime = 0.02, numChannels = 2, rate = \audio|
        ^super.new(pattern).dur_(dur).numChannels_(numChannels).rate_(rate).fadeTime_(fadeTime)
    }

    storeArgs { ^[pattern, dur, fadeTime, numChannels, rate] }

    embedInStream { |inevent|
        var server, groupID, linkID, bus, ingroup, cleanup;
        var patterns, event, freeBus, stream, cleanupEvent;

        cleanup = EventStreamCleanup.new;
        server = inevent[\server] ?? { Server.default };
        groupID = server.nextNodeID;
        linkID = server.nextNodeID;
        ingroup = inevent[\group];

        // 可以为此使用一个特殊的事件类型：
        if(rate == \audio) {
            bus = server.audioBusAllocator.alloc(numChannels);
            freeBus = { server.audioBusAllocator.free(bus) };
        } {
            bus = server.controlBusAllocator.alloc(numChannels);
            freeBus = { server.controlBusAllocator.free(bus) };
        };

        CmdPeriod.doOnce(freeBus);

        event = inevent.copy;
        event[\addAction] = 0; // \addToHead
        event[\type] = \group;
        event[\delta] = 0;
        event[\id] = groupID;
        event[\group] = ingroup;
        event.yield;

        inevent = event = inevent.copy;

        event[\type] = \on;
        event[\group] = groupID;
        event[\addAction] = 3; // \addBefore
        event[\delta] = 0;
        event[\id] = linkID;
        event[\fadeTime] = fadeTime;
        event[\instrument] = format("system_link_%_%", rate, numChannels);
        event[\in] = bus;
        event[\msgFunc] = #{ |out, in, fadeTime, gate = 1|
            [\out, out, \in, in, \fadeTime, fadeTime, \gate, gate, \doneAction, 3]
        };

        cleanupEvent = (type: \off, parent: event, fadeTime: fadeTime.abs, hasGate: true, gate: 0);

        cleanup.addFunction(event, { |flag|
            if(flag) { defer ({ cleanupEvent.play }, dur) };
        });

        cleanup.addFunction(event, { defer({ freeBus.value }, fadeTime.abs + dur) });

        // doneAction = 3;
        // 移除并释放此 synth 及前一个节点
        // （即该组）。
        inevent = event.yield;

        // 现在嵌入该模式
        stream = Pchain(pattern, (group: groupID, out: bus)).asStream;
        loop {
            event = stream.next(inevent) ?? { ^cleanup.exit(inevent) };
            cleanup.update(event);
            inevent = event.yield;
        }
    }
}
