Slew

转换速率限制器。

Filter : PureUGen : UGen : AbstractFunction : Object

另请参见：Slope、Ramp、Lag、VarLag

说明

限制输入信号的斜率。斜率以每秒单位数表示。

若要平滑控制信号，请查看 Lag 和 VarLag

类方法

Slew.ar(in: 0.0, up: 1.0, dn: 1.0, mul: 1.0, add: 0.0)

Slew.kr(in: 0.0, up: 1.0, dn: 1.0, mul: 1.0, add: 0.0)

参数：

in

输入信号。

up

每秒单位内的最大上升斜率。

dn

每秒单位数表示的最大下降斜率。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

(
{
    z = LFPulse.ar(800);
    [z, Slew.ar(z, 4000, 4000)]
}.plot)



Has the effect of removing transients and higher frequencies.
(
{

    z = Saw.ar(800, mul: 0.2);
    Slew.ar(z, 400, 400)

}.play
)
