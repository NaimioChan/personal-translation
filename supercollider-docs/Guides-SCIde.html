SuperCollider IDE

跨平台 SuperCollider 编程环境指南

SuperCollider IDE 是一个新的跨平台编程环境，专为 SuperCollider 开发，并在 3.6 版本中引入。

它易于上手使用、便于操作，并为经验丰富的 SuperCollider 程序员点缀了强大的功能。它也非常可定制。

它在 macOS、Linux 和 Windows 7 上运行效果相同，外观几乎一样。（Windows XP 上的问题仍待解决。）

Overview

注意： 在本文档中，Ctrl 表示 Linux 和 Windows 平台上用于键盘快捷键的修饰键。在 macOS 上，请改用 Cmd。

这是一张标注截图，描述了 IDE 的各个组成部分。点击此处查看原始尺寸版本。

核心组件

标题栏

显示当前会话名称（参见 Sessions），以及当前文档的文件名。

代码编辑器

编辑器占据中心位置。你将在这里花费大部分时间编写代码。在代码编辑器部分阅读更多内容。

文档标签页

编辑器上方有一系列标签页，每个打开的文档对应一个标签。点击某个标签页将在编辑器中显示相关文档。可以拖放标签页以更改它们的顺序。

工具面板

这里显示了与代码编辑相关的各种工具。该面板最初是隐藏的，只有在激活其中一个工具时才会显示。你可以通过菜单 View > Tool Panels 以及使用键盘快捷键来激活每个可用的工具。以下是工具列表：

  • 查找（Ctrl+F）- 在当前文档中查找文本。
  • 替换（Ctrl+R）- 在当前文档中查找并替换文本。
  • 转到行（Ctrl+L）——按行号跳转到当前文档的特定行。
  • 命令行（Ctrl+E）——像在终端中一样编写并求值单行代码。
状态栏

包含解释器和声音服务器的状态信息。同时显示与 IDE 相关的任何偶发通知。

Docklets

在上述中心区域周围，有停靠区域，其中显示称为停靠面板的各种其他面板。它们之所以这样命名，是因为它们可以在停靠区域中移动到不同位置，甚至可以被取消停靠以浮动在主窗口上方，而且它们也可以被隐藏。你可以通过菜单 View > Docklets 显示或隐藏每个可用的停靠面板。

以下是可用 docklet 的列表：

帮助浏览器

显示并浏览帮助页面。

Post 窗口

显示解释器的响应：代码求值的结果以及各种通知、警告、错误等……

文档列表

打开文档的列表；当打开很多文档时，这比 Document 标签页更方便。

可以通过拖放停靠面板自身的标题栏将其移动到不同区域。共有四个停靠区域，分别位于屏幕的四条边缘：左、右、上、下。.

docklet 可以处于四种不同状态：

  • 停靠 - 你可以将停靠面板拖放到任一停靠区域，既可以并排放置，也可以相互叠放。在后一种情况下，会出现小标签，允许你在特定区域中切换可见的停靠面板。某些停靠面板受到限制，只能放置在部分区域中。
  • 取消停靠 - 将 docklet 拖放到任何停靠区域之外，它就会保持独立并始终位于主窗口之上。你也可以通过点击 docklet 左上角的菜单来取消停靠。
  • 分离 - 使用通过单击停靠小窗口左上角而打开的菜单，可以将其分离。分离后的停靠小窗口的行为就像普通窗口一样：它可以被最小化和最大化，主窗口可以提升到它的前面，它会出现在操作系统任务栏中，等等。
  • Hidden - 停靠小部件可以通过单击其左上角可访问的菜单、关闭分离的停靠小部件的窗口，或使用主窗口菜单 View > Docklets 来隐藏。要显示隐藏的停靠小部件，请使用相同的主窗口菜单。

获取帮助

所有帮助选项均可通过主菜单中的 Help 访问。

键盘快捷键 Ctrl+D（如 Documentation 中所述）是获取帮助最便捷的方式。它会使 Help Browser 跳转到与光标周围文本相关的帮助页面：

  • 如果光标位于类或方法名上，将显示其文档。
  • 如果光标处的文本没有匹配的类或方法，将显示该文本的帮助搜索结果。
  • 无论如何，如果 Help Browser 之前被隐藏，它将会显示出来。

Ctrl+D 快捷键在 IDE 的多个位置均可用：编辑器、命令行、Post 窗口或帮助浏览器本身。它将始终使用光标周围的文本或选中的文本（如果有）来搜索帮助。

如果你想直接转到某个特定的帮助页面，请使用 Ctrl+Shift+D 快捷键，它会弹出一个框，你可以在其中输入类名、方法名或任意文本，然后按 Return 获取相关帮助。

帮助浏览器的标题栏中有控件，可用于导航到帮助主页、在历史记录中后退和前进，以及重新加载当前页面。

当帮助浏览器获得焦点时使用 Ctrl+F 快捷键，会直接定位到 Find 字段，你可以用它搜索当前帮助页面中的文本。

启动系统

没有两个关键组件，就没有 SuperCollider 的乐趣：

语言解释器

…就是解释并执行你的 SuperCollider 代码的东西。它会在 IDE 启动时自动启动。然而，它实际上与 IDE 是分开的，因此你可以通过 Language 菜单随意停止和重新启动它。当解释器正在运行时，状态栏中标记为 "Interpreter" 的框会以绿色字母显示 "Active"。

音频服务器

……正是它让你的 SuperCollider 代码发出声音。音频服务器未运行时，你仍可运行 SuperCollider 代码，但不会发出任何声音。与解释器不同，音频服务器不会自动启动。要启动它，可使用 Ctrl+B 快捷键，或使用 Language 菜单。注意，必须先运行语言解释器才能启动音频服务器。音频服务器运行时，状态栏中标记为 "Server" 的方框将以绿色数字显示状态。

当然，一旦解释器和音频服务器运行起来，其中最有趣的部分就是求值代码。使用 Ctrl+Return 快捷键来求值当前行、区域或选区。有关更多信息，请参见 Evaluating code。

当你想停止正在运行的代码时，请使用 Ctrl+. 快捷键（Ctrl+句点）。更多相关内容见 Evaluating code 一节的末尾。

大多数情况下，无需重启解释器。不过，如果你不小心执行了会进入无限循环且无法暂停的代码，或者解释器直接崩溃并自行停止，那么重启解释器会非常有用。在这种情况下，请使用语言菜单重启解释器。

当你的类库发生更改时，无论是因为安装或移除了某个 Quark，还是仅仅修改了某个类文件，你都需要重新编译类库以使更改生效。你可以通过 Ctrl+Shift+L 快捷键快速完成，或者通过 Language 菜单完成。

代码编辑器

求值代码

要执行代码，请使用以下键盘命令之一：

Ctrl+Return

最常用的“智能”代码求值：

  • 通常，当前行（光标所在处）将被求值。
  • 如果光标位于某个区域内，则整个区域都会被求值。有关区域的说明请参见下文。
  • 如果选中了某些代码，则会对所选内容进行求值。
Shift+Return

对当前行或选区（如果有）求值。使用此功能可以对区域内的单行求值，而无需选中它。

区域让求值较大段代码变得快速简便。区域由括号包围；要被视为区域，每个括号必须是所在行上唯一的字符。

(
Pbind(
    \degree, Pseries(0, 1, 8),
    \dur, 0.25
).play;
)

如果光标位于最外层括号之间的任意位置，按 Ctrl+Return 将自动求值括号内的全部内容，从 Pbind 开始，到 play; 结束。

要快速求值一段代码，你还可以双击任意括号（圆括号、方括号或花括号），这会选中该括号与另一个匹配括号之间的全部内容，从而可以快速对其求值。

要停止任何正在运行的代码，请使用 Ctrl+. 快捷键（Ctrl+句点）。这将停止所有在时钟上排程的代码，以及音频服务器上的所有声音进程。

注意： 如果某些代码进入没有暂停的无限循环，使用 Ctrl+. 将无法帮助停止它。在这种情况下，你需要重启解释器（参见 启动系统）。

自动缩进

编辑器会在你输入时根据开括号和闭括号自动缩进各行，从而为你提供帮助。每新增一行时，如果上一行有开括号，缩进就会增加。当你继续输入闭括号时，缩进会减少，以与匹配的开括号对齐。

如果某段代码的缩进混乱，你可以选中它并按 Tab 键，它会根据周围的括号自动缩进。对于当前行，即使不选中也可以使用此功能。

你可以按 Shift+Tab 在代码中的任意位置手动插入一级缩进。

缩进可以使用制表符或空格，你可以通过主菜单选项 Edit > Use Spaces for Indentation 快速切换。更多缩进选项可在 IDE 偏好设置对话框中找到。

自动补全

当你输入时，编辑器会尝试查找你代码可能的延续，并弹出一个建议列表，这样你就可以快速插入其中一个，而不必输入整个文本。这称为自动补全，是帮助你更快、更少错误地编写代码的一大助力。

一般来说，这适用于类名和方法名。以下是编辑器可以自动补全的内容：

  • 类名

    Sin<...>

    当你已经输入了类名的至少 3 个字母时，会显示以这些字母开头的类列表。

  • 方法名跟在类名之后

    Array.<...>

    在类名后输入一个点时，将显示该类的方法列表。

  • 字面量和内置项之后的方法名

    123.<...>
currentEnvironment.<...>

    当你在字面量（数字、字符串、符号等）或内置对象（currentEnvironment、thisProcess 等）之后输入一个点号时，将显示其所属类的实例方法列表。

  • 变量名之后的方法名

    value.lin<...>

    当你在变量之后输入一个点号和 3 个字母时，将显示所有以这些字母开头的类的所有方法列表（因为变量的类未知）。

自动补全菜单弹出后，你可以使用方向键或 Page Up 和 Page Down 来选择条目，然后按 Return 将其插入代码中。如果你继续输入，选项列表会进一步筛选以匹配已输入的文本。

请注意，当输入的文本与某个自动补全选项完全匹配时，自动补全菜单会消失。这是有意为之的帮助：当你可能不需要它时，菜单会尽量让开。

如果没有显示自动补全菜单，你可以使用 Ctrl+Space 显示它，只要有任何可用的自动补全选项。你随时可以按 Escape 关闭菜单。

方法调用辅助

当编写方法的参数时，编辑器会帮助你，向你显示该方法的完整参数列表及其默认值，只要它能够准确判断出是哪个方法。这称为方法调用辅助。它帮助你准确了解正在输入哪个参数，并减少查阅文档的需要。

当你在方法名后键入左括号时，辅助功能即被激活，此时会弹出一个包含参数的框。然而，如果该方法所属的类未知，则会先显示一个实现该方法的类的菜单，在你使用方向键或 Page Up 和 Page Down 键选择其中一个类并按 Return 后，包含参数的框便会弹出。

因此，例如在以下情况下，方法调用辅助会立即弹出：

SinOsc.ar(
123.forBy(

……而在以下情况下，你需要先选择一个类，因为该类未知：

min(
x.play(
[1,2,3].inject(

如果未显示方法调用辅助，你可以将光标置于参数两侧的括号之间，并使用 Ctrl+Shift+Space 激活它。你始终可以按 Escape 将其关闭。

工具面板

所有工具面板均已列出，可通过主菜单 View > Tool Panels 激活。要关闭当前显示的面板，请按 Escape。

查找与替换

快捷键：查找：Ctrl+F / 替换：Ctrl+R

查找面板用于在当前打开的文档中查找文本。一旦你开始在查找字段中输入，就会搜索所输入的文本，并高亮显示结果。第一个找到的结果也会被选中。按回车键可以逐个跳转到所有结果。

注意每当搜索文本发生变化时，状态栏都会报告搜索结果的数量。

如果你在代码编辑器中选中了一些文本并调用 Find 快捷方式，Find 字段将填入所选内容。

Replace 面板是 Find 面板的扩展：它增加了另一个字段，你可以在其中输入文本以替换搜索结果。在 Replace 字段中按 Return 键，当前搜索结果将被替换，并选中下一个结果。

使用 Replace All 按钮替换所有搜索结果。注意状态栏如何报告替换次数。

你可以通过点击 Find/Replace 面板右上角的按钮来访问更多搜索选项。选项包括：

  • Match Case - 使搜索区分大小写。
  • 正则表达式 - 将搜索文本视为正则表达式。详情见下文。
  • 全词匹配 - 仅搜索完整的词；即搜索结果左侧和右侧的字符不能是字母或数字。

正则表达式是一种强大的方式，用于搜索与模式匹配的文本，而不是精确的字符序列。启用此选项后，替换支持反向引用，即在替换文本中重用所找到模式的部分内容。

我们在此不深入正则表达式的细节。要了解更多，我们想向你推荐一个优秀的在线教程：http://www.regular-expressions.info/quickstart.html

Go-To-Line

快捷键：Ctrl+L

使用转到行工具，你可以按行号快速跳转到当前文档中的某一行。只需输入行号并按 Return。

命令行

快捷键：Ctrl+E

有时，你需要求值一个不需要保存到文档中的临时表达式。命令行提供了一个单行文本字段，你可以在其中输入 SuperCollider 表达式，然后按 Return 键对其求值。

使用上、下方向键在已求值表达式的历史中浏览。按上方向键会移至较旧的表达式，按下方向键则会回到较新的表达式。

类库导航

通常，能够直接跳转到文件中实现特定类或方法的位置，或查找使用某个类或方法名称的所有位置，是非常有用的。IDE 提供了实现这一目标的实用方法。

查找实现

当文本光标位于某个方法或类名上时，Ctrl+I 快捷键会打开一个对话框，列出该方法或类的所有实现位置。选中其中一项并按 Return 键，IDE 将打开对应文件并将文本光标定位到您要查找的位置。

注意，Ctrl+I 快捷键在 IDE 的多个位置都可以使用，凡是可能存在代码的地方：编辑器、命令行、后窗或帮助浏览器。它始终会使用光标周围的文本或选中的文本（如果有）来查找名称匹配的方法或类。

对话框中的列表按如下方式构成：

  • 如果你查找的是某个类名，则会列出该类及其所有方法，包括其父类的方法。
  • 如果你查找某个方法名，将列出所有类中具有该名称的所有方法。
  • 如果没有完全匹配名称的类或方法，将显示部分匹配项

你可以使用对话框顶部的文本字段直接搜索方法或类。只需输入一些文本并按 Return。

Ctrl+Shift+I 快捷键会打开空白对话框，无论文本光标位于何处。

查找参考文献

Ctrl+U 快捷键会打开一个与上述类似的对话框，不同之处在于它会列出特定名称的方法或类被使用的位置。注意，它只搜索类库中的类文件，而不搜索常规代码文件。

正如上面描述的 Ctrl+I 快捷键，Ctrl+U 在 IDE 中任何可能存在代码的地方都可以使用。

Ctrl+Shift+U 快捷键会打开空白对话框，无论文本光标位于何处。

Sessions

会话会保存退出时 IDE 的状态，因此下次使用时，你可以自动恢复相同的已打开文档和 docklets 布局。

要将当前状态保存为新会话，请使用“Session > Save Session As...”菜单操作。系统将提示你为新会话输入名称。

要打开已保存的会话，请使用“Session > Open Session...”菜单，其中包含所有已保存的会话。

要开始一个新的未保存会话，请使用 "Session > New Session" 菜单操作。

你可以通过使用 Ctrl+Shift+Q 快捷键弹出的所有会话列表快速切换活动会话。

更多选项（包括移除已保存的会话）可在通过“Session > Manage Sessions...”菜单操作访问的会话管理对话框中找到。

默认情况下，IDE 启动时会使用关闭前使用的上次会话，但你可以在 IDE 配置对话框中更改此行为。

各种便捷快捷键

聚焦 Post 窗口：Ctrl+P

将焦点切换到 Post Window。然后你可以使用方向键和 Page Up / Page Down 滚动查看解释器的输出。按 Tab 键返回代码编辑器。

清除 Post 窗口：Ctrl+Shift+P

清除 Post Window 的内容。

放大/缩小字体：Ctrl++ / Ctrl+-

放大或缩小代码编辑器、后置窗口或帮助浏览器中的字体。

Customization

许多自定义选项可在 IDE 配置对话框中找到，可通过“Edit > Preferences”菜单操作访问。

选项包括：字体、代码颜色、键盘快捷键……
