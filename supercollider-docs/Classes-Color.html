Color

一个存储颜色值的对象

Object

另请参阅：Object

说明

一个在实例变量中存储红色、绿色、蓝色和 alpha 值的对象，并提供大量类和实例方法来创建和操作这些值。

类方法

Color.new(red: 0.0, green: 0.0, blue: 0.0, alpha: 1.0)

使用浮点值创建新实例。

参数：

red

一个介于 0 和 1 之间的 Float 实例。

green

一个介于 0 和 1 之间的 Float 实例。

blue

一个介于 0 和 1 之间的 Float 实例。

alpha

一个介于 0 和 1 之间的 Float 实例。

Color.new255(red: 0, green: 0, blue: 0, alpha: 255)

从 0 到 255 之间的 8 位整数值创建一个新实例。

参数：

red

一个介于 0 和 255 之间的 Integer 实例。

green

一个介于 0 和 255 之间的 Integer。

blue

一个介于 0 和 255 之间的 Integer。

alpha

一个介于 0 和 255 之间的 Integer。

Color.fromArray(array)

与 Color.new(*array) 相同。

参数：

array

Array 的一个实例。1-4 个介于 0 和 1 之间的值。参见 *new。

Color.fromHexString(string)

从十六进制颜色字符串创建新实例。

参数：

string

一个 String。

讨论：

该字符串应为 6 个字符的 web 颜色，或 3 个字符的 CSS 样式颜色。前面的 # 是可选的。

Color.fromHexString("#FF6600");

Color.black

没有比这更暗的了。

Color.white

没有比这更轻的了。

Color.clear

没有比这更清晰的了。

Color.gray(gray: 0.5, alpha: 1.0)

美式灰度。

参数：

gray

以 Float 表示，取值介于 0（黑）与 1（白）之间的灰度。

alpha

介于 0 和 1 之间的灰色透明度，类型为 Float。

Color.grey(grey: 0.5, alpha: 1.0)

英式灰色调。

参数：

grey

以 Float 表示，取值介于 0（黑）与 1（白）之间的灰度。

alpha

介于 0 和 1 之间的灰色透明度，类型为 Float。

Color.red(val: 1.0, alpha: 1.0)

Color.green(val: 1.0, alpha: 1.0)

Color.blue(val: 1.0, alpha: 1.0)

Color.cyan(val: 1.0, alpha: 1.0)

Color.magenta(val: 1.0, alpha: 1.0)

Color.yellow(val: 1.0, alpha: 1.0)

创建一个新的红色、绿色、蓝色、青色、品红色或黄色 Color。

参数：

val

Float 的一个实例，介于 0 和 1 之间，其中 1 是明亮、完全饱和的颜色，0 是黑色。

alpha

透明度介于 0 和 1 之间，类型为 Float。

Color.rand(lo: 0.3, hi: 0.9)

一个随机 RGB 颜色，颜色在 lo 和 hi 之间随机选择。参见 *new。

参数：

lo

一个介于 0 和 1 之间的 Float 实例。

hi

一个介于 0 和 1 之间的 Float 实例。

Color.hsv(hue, sat, val, alpha: 1)

将 hsv 和 alpha 值映射到 0 到 1 之间的 rgb。

参数：

hue

介于 0 和 0.999 之间的 Float。

sat

介于 0 和 1 之间的 Float。

val

介于 0 和 1 之间的 Float。

alpha

介于 0 和 1 之间的 Float。

实例方法

.red = value

.green

.green = value

.blue

.blue = value

.alpha

.alpha = value

获取/设置实例变量 red、green、blue 或 alpha 之一。

返回值：

一个介于 0 和 1 之间的 Float 实例。

.hexString

返回一个 String，其中包含一个以 # 开头的 6 字符 Web 颜色代码。

Color(1.0, 0.4).hexString;

==(that)

二元运算符。

// 返回 true
Color.new255(0, 0, 255, 255) == Color.new(0, 0, 1, 1)

.scaleByAlpha

返回一个 Color，其中 red、green 和 blue 按 alpha 值缩放，且 alpha 设为 1。

// 返回 true：
Color(1, 0.5, 1, 0.5).scaleByAlpha == Color(0.5, 0.25, 0.5, 1)

.blend(that, blend: 0.5)

对两个 Color 的 red、green、blue 和 alpha 值进行插值，在第一个和第二个之间进行线性加权。

参数：

that

第二个 Color。

blend

0 表示仅此，而 1 表示仅彼。

.vary(val: 0.1, lo: 0.3, hi: 0.9, alphaVal: 0)

返回 Color 的随机变体。

参数：

val

以该量改变 RGB 值 ±

lo

在此处低裁剪 RGB 变化。

hi

在此处对 RGB 变化进行高值截断。

alphaVal

将 alpha 值变化 +/- 此量，并将其裁剪在 0 和 1 之间。

.complementary

返回补色。

// 返回 true：
Color(1, 0.5, 1, 0.5).complementary == Color(0.0, 0.5, 0.0, 0.5)

.asHSV

返回一个数组 [hue, saturation, value, alpha]，其值为 0 到 1 之间。

.asArray

.setStroke

与 Pen 配合使用。将 Pen 的 stroke 设为此值。

.setFill

与 Pen 配合使用。将 Pen 的 fill 设为此值。

.set

与 Pen 配合使用。将 Pen 的 stroke 和 fill 设为此值。

.round(val: 0.01)

对颜色进行舍入。

示例

(
w = Window.new.front;
w.view.background_(Color.white);
w.drawFunc = {
    // 设置颜色
    Pen.translate(200, 200);
    30.do{
        Pen.width = 3.0.rand;
        Color.blue(rrand(0.0, 1), rrand(0.0, 0.5)).setStroke;
        Color.red(rrand(0.0, 1), rrand(0.0, 0.5)).setFill;
        Pen.addAnnularWedge(
            0@0,
            rrand(10, 50),
            rrand(51, 100),
            2pi.rand,
            2pi.rand
        );
        Pen.perform([\stroke, \fill].choose);
    }
};
w.refresh;
)
