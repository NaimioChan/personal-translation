Modulo.

.modSeaside(aNumber)

3.14 之前的版本对负整数模数具有意外行为的取模；参见 Integer: -modSeaside。对浮点操作数调用 modSeaside 将回退到 mod 行为。

Iteration

.for(endValue, function)

对从该值到 endval（含端点）的数字以步长 1 调用 function。

参数：

endValue

一个 Number。

function

一个 Function，接收两个参数：第一个是从 this 到参数 endval 的一个数字，第二个是从零到迭代次数减一的一个数字。

.forBy(endValue, stepValue, function)

参数：

一个 Number。

stepValue

一个 Number。

function

一个 Function，它接收两个参数，第一个是从 this 到 endval 之间的数，第二个是从零到迭代次数减一之间的数。

.forSeries(second, last, function)
