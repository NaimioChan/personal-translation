实例方法

.isOpen

返回文件是否已打开。打开请求可能失败，例如找不到文件。此方法可让你测试打开调用是否成功。

.pos =

来自父类：IOStream

返回当前文件位置

参数：

(offset)

以字节为单位的偏移量。

(origin)

以下 Integer 之一：

0

从文件开头查找。

1

从文件当前位置开始查找。

2

从文件末尾开始定位。

.write(item)

向文件写入一个项。

参数：

item

以下之一：

Float
Integer
Char
Color
Symbol

将 Symbol 的名称作为 C 字符串写出。

RawArray

将任意 RawArray 中的字节以大端序写入。

.getLine(maxSize: 1024)

读取并返回一个 String，最多读到下一个换行符或 1023 个字符中较小者。

.getChar

读取一个字节并作为 Char 返回。

.getInt8

读取一个字节并以 Integer 返回。

.getInt16

读取两个字节并作为 Integer 返回。

.getInt32

读取四个字节并作为 Integer 返回。

.getFloat

读取四个字节并作为 Float 返回。

.getDouble

读取八个字节并作为 Float 返回。

.getPascalString

将下一个字节读取为无符号整数 N，然后读取后续 N 个字节，并将它们作为 String 返回。

.putChar(aChar)

将一个 Char 写为一个字节。

.putInt8(anInteger)

将一个 Integer 写入为一个字节。即一个介于 -128 和 127 之间的有符号 Integer 值。

.putInt16(anInteger)

将一个 Integer 写为两个字节。

.putInt32(anInteger)

将一个 Integer 写入为四个字节。

.putFloat(aFloat)

将一个 Float 写为四个字节。

.putDouble(aFloat)

将一个 Float 写为八个字节。

.putString(aString)

写入一个以 null 结尾的 String。

.putPascalString(aString)

写入 aString，并在其前面写上一个单字节表示的长度。如果 aString 超过 255 个字符，则抛出错误。

.putString0(aString)

写入 aString，后跟一个零字节，如同以 null 结尾的 C 字符串。
