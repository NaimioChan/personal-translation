PV_JensenAndersen

用于起音检测的 FFT 特征检测器。

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

参见：PV_HainsworthFoote

说明

用于起音检测的 FFT 特征检测器，基于 Jensen, K. & Andersen, T. H. (2003). Real-time Beat Estimation Using Feature Extraction. In Proceedings of the Computer Music Modeling and Retrieval Symposium, Lecture Notes in Computer Science. Springer Verlag. 中描述的工作。

取特征的一阶导数。threshold 可能需要设置得较低以捕捉变化。

类方法

PV_JensenAndersen.ar(buffer, propsc: 0.25, prophfe: 0.25, prophfc: 0.25, propsf: 0.25, threshold: 1.0, waittime: 0.04)

参数：

buffer

FFT 缓冲区。

propsc

频谱质心特征的比例。

prophfe

高频能量特征的比例。

prophfc

高频内容特征的比例。

propsf

频谱通量特征的比例。

threshold

允许检测的阈值电平。

waittime

如果触发，则在下一个帧能够引发另一次 spot 之前的最小等待时间（有助于在强信号上停止多次检测）。

实例方法

示例

(
SynthDef(\fftod, { |out|
    var source1, detect, chain;
    source1 = SoundIn.ar(0);
    chain = FFT(LocalBuf(2048), source1);
    detect = PV_JensenAndersen.ar(chain, threshold: MouseX.kr(0.1, 1.0));
    Out.ar(out, SinOsc.ar([440, 445], 0, Decay.ar(0.1 * detect, 0.1)));
}).play(s);
)
