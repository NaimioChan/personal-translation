循环 / 重复

重复内容

loop

repeat

创建一个对象，其行为类似于一个流，在有限（或无限）次数内返回数值。

有关实现类的完整列表，请参见 Methods: loop 和 Methods: repeat

Function: -loop

无限重复该函数。

    f = { 3.yield };
    x = Routine({ f.loop });
    10.do({ x.next.postln })
Object: -repeat (n)

重复以产生该对象

    x = 5;
    y = x.repeat(6);
    y.nextN(8);
Pattern: -repeat (n)
    x = Prand([1, 2]).repeat(6).asStream;
    x.nextN(8);
Pattern: -loop
    x = Prand([1, 2]).loop.asStream;
    x.nextN(8);
Stream: -repeat (n)

重复嵌入该流

    x = Routine({ 3.do({ arg i; i.yield }) }).repeat(6);
    x.nextN(8);
Stream: -loop

重复嵌入该流

    x = Routine({ 3.do({ arg i; i.yield }) }).loop;
    x.nextN(8);
