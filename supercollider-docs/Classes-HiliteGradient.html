HiliteGradient

外部颜色与内部颜色之间的线性颜色渐变

另请参阅：Color、Gradient

说明

外部颜色与内部颜色之间的线性颜色渐变。

注意： Qt GUI 中尚不支持使用 HiliteGradient。当使用 HiliteGradient 代替 Color 时，将改用平均渐变颜色。

类方法

.new

参数：

color1

一个 Color 实例。

color2

一个 Color 实例。

direction

\h 或 \v，分别表示水平和垂直。默认值为 \v。

steps

渐变的精度。默认值为 64。

frac

渐变的中心。默认值为 0.33，即在垂直渐变中偏离中心偏向顶部。

实例方法

示例

// 基本用法
(
w = Window.new.front;
v = CompositeView(w, Rect(50, 50, 200, 50));
v.background = HiliteGradient(Color.gray, Color.white);
)

// 更改方向和分辨率
(
w = Window.new.front;
w.view.background = HiliteGradient(Color.red, Color.white, \h, 12, 0.5);
)

// 几乎察觉不到的变化也可以很悦耳
(
w = Window.new.front;
v = CompositeView(w, Rect(50, 50, 300, 300));
c = Color.rand;
d = c.vary(0.15);
v.background = HiliteGradient(c, d, \v);
[c, d].postln
)

(
var w, k, c, d, e, c1, c2, f, g;
w = Window.new.front;
k = Slider2D(w, Rect(50, 50, 300, 300));
f = {
    c = Color.rand;
    d = c.vary(0.5);
    e = d.vary(0.5);
};
g = {
    c1 = d.hueBlend(e, k.y).round(0.01);
    c2 = c.hueBlend(e, k.x).round(0.01);
    k.background = HiliteGradient(c1, c2, \v)
};
f.value; g.value;
k.action = g;
k.mouseUpAction = { [c1, c2].postln };
k.keyDownAction = f; // 按键获取新颜色
)
