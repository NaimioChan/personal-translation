CallOnce

执行一个函数（至多）一次

Thunk : AbstractFunction : Object

参见：EventStreamCleanup

说明

与不接受参数的 Thunk 不同，CallOnce 确实允许将参数传递给它所包装的函数，但该函数至多执行一次。CallOnce 也可以通过调用 clear 来“取消”，而无需执行所包装的函数，即使之后调用了 CallOnce 的 value。

CallOnce 的一般约定是：第一次调用之后对该函数的任何调用，所做的工作应当与第一次调用相同或更少（清理工作）。因此，后续调用完全是多余的，可以直接返回第一次调用的结果，即使后续调用中的参数发生了变化。典型用例：如果清理函数以 releaseResource: false 参数被调用，例如因为资源已经被 CmdPeriod 释放，那么就假定该清理函数之后不会再以 releaseResource: true 参数被调用。

由于它（至多）执行其函数一次，因此 CallOnce 并不是用于带参数函数的通用函数记忆化工具。

基本示例（更多内容见页面末尾）：

c = CallOnce { |flag| if(flag) { "woking...".postln; "done:" + flag } };
c.value(true);  // -> done: true（并输出 "woking..."）
c.value(false); // -> done: true（未发布任何内容）

类方法

CallOnce.new(function)

来自父类：Thunk

参数：

function

一个通常执行某些清理工作并可能返回所需值的函数。该函数被包装在 CallOnce 中以便稍后执行。

实例方法

.clear

来自父类：Thunk

取消 CallOnce，意味着后续对 value 的调用将完全不执行所包装的函数。

返回值：

the CallOnce。

.didEvaluate

来自父类：Thunk

报告该 CallOnce 是否被视为已求值。

返回值：

如果之前既未调用 clear 也未调用 value，则为 false；否则为 true。

.value( ... args, ... kwargs)

如果之前调用过 clear，则 value 调用没有副作用。否则，在第一次调用 value 时，CallOnce 包装的函数会以传给 value 的参数求值，且该求值结果会存储为 CallOnce 的结果，用于应答之后所有对 value 的调用。

参数：

... args

调用被包装函数时使用的参数（如果发生调用）。如果 didEvaluate 已经返回 true（在当前调用 value 之前），那么当前的 args 无关紧要，因为被包装函数不再被调用。

kwargs

用于关键字参数的键值对数组。参见 Function: -value。

返回值：

  • 如果在调用 value 之前对 CallOnce 调用了 clear，则为 nil，否则
  • 该值由函数（被 CallOnce 包装）在首次调用 CallOnce 的 value 时计算得出

示例

r = 1; // 某些资源
c = CallOnce {  r = r - 1; postln("Resource is now released:" + r); r };
c.didEvaluate; // -> false
c.value;       // -> 0（并输出 "Resource is now released: 0"）
c.didEvaluate; // -> true
c.value;       // -> 0（但不输出任何内容）
c.clear;       // 即使现在处于 "cancelled" 状态
c.value;       // -> 0；计算出的值被保留

c = CallOnce { "not called".postln }
c.didEvaluate; // -> false
c.clear;       // "取消"清理操作
c.didEvaluate; // -> true
c.value;       // -> nil

// 与参数一起使用
(
r = 1; // 某些资源
c = CallOnce { |releaseResource|
    if(releaseResource) {
        r = r - 1; "Resource is now released:" + r
    } {
        "nothing to do"
    }
};
)
d = c.copy // 保存起来供以后使用，独立的执行状态

// 正确使用序列（非递增的清理工作序列）：
c.value(true);
c.value(true);
c.value(false);
r; // -> 0

d.didEvaluate; // -> false（复制尚未求值）

// 语义不正确（违反约定）的使用序列
d.value(false) // -> 无需处理
d.value(true)  // -> 无需处理
