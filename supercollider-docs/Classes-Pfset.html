Pfset

在求值所提供的模式之前，将一个环境插入到事件原型中

FuncFilterPattern : FilterPattern : Pattern : AbstractFunction : Object

参见：Pset

说明

适合设置默认值或加载服务器对象。

类方法

Pfset.new(func, pattern, cleanupFunc)

参数：

func

使用环境变量语法（例如 ~x = 0）将值存储到内部环境中。在运行提供的模式之前，这些值会被复制到事件原型中。

pattern

一个事件模式（例如 Pbind）。

cleanupFunc

可选。当模式停止时，或当所提供的模式用尽数值时，将求值的函数。例如，如果你在初始化函数中加载了一个 Buffer，就可以在 cleanupFunc 中释放它。

实例方法

未文档化的实例方法

.cleanupFunc

.cleanupFunc = value

.embedInStream(inevent)

示例

(
var a, b;
a = Pfset({
    ~legato = 0.3;
    ~detune = rrand(0, 30);
}, Pbind(\dur, 0.5));
x = a.asStream;
9.do({ x.next(Event.new).postln });
)

Pfset 不会覆盖内层模式放入事件中的值：

(
var a, b;
a = Pfset({
    ~dur = 0.3;
}, Pbind(\dur, 0.5));
x = a.asStream;
9.do({ x.next(Event.new).postln });
)

声音示例

(
SynthDef(\sinegrain,
    { |out = 0, freq = 440, sustain = 0.02|
        var env;
        env = EnvGen.kr(Env.perc(0.001, sustain), 1, doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env * 0.1))
    }).add;
)

(
a = Pbind(\dur, 0.5, \instrument, \sinegrain, \x, Pfunc { rrand(500, 600) });
a = Pfset({ ~freq = { ~x.postln * 2 }; ~legato = 3 }, a);
a.play;
)
