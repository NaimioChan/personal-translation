MIDIFunc

用于传入 MIDI 消息的快速响应器

AbstractResponderFunc : Object

另请参见：MIDI、MIDIdef

子类：MIDIdef

说明

MIDIFunc（及其子类 MIDIdef）注册一个或多个函数来响应传入的 MIDI 消息。它的许多方法继承自其父类 AbstractResponderFunc。

关于持久化的重要说明

MIDIFunc（及其子类 MIDIdef，与所有其他 AbstractResponderFunc 一样）在按下 Cmd/ctrl-. 时会被移除。要覆盖此行为，请使用 AbstractResponderFunc: -permanent 方法。

类方法

MIDIFunc.defaultDispatchers

MIDIFunc.defaultDispatchers = value

获取或设置一个 IdentityDictionary，其中包含用于不同类型 MIDIFunc 的默认派发器对象（如果向 *new 传入 nil 作为派发器参数，得到的就是这些对象）。这些对象将决定其注册的 MIDIFunc 中是否有任何一个应当响应传入的 MIDI 消息。该字典应具有键 [\noteOn, \noteOff, \control, \polytouch, \touch, \program, \bend]，并为每种消息类型提供相应 AbstractDispatcher 子类的值。默认情况下，前四种消息类型为 MIDIMessageDispatcher 的实例，后三种为 MIDIMessageDispatcherNV 的实例。

返回值：

getter 返回一个 IdentityDictionary。

MIDIFunc.new(func, msgNum, chan, msgType, srcID, argTemplate, dispatcher)

创建一个新的、已启用的 MIDIFunc。通常应使用下面某个针对特定消息类型的便捷方法，而不是直接使用此方法。

参数：

func

一个 Function 或类似对象，用于响应传入的消息。当为 noteOn、noteOff、control 和 polytouch 消息求值时，会向它传递参数 val、num、chan 和 src，分别对应消息值（例如力度、控制值等）、消息编号（例如音符编号）、MIDI 通道和 MIDI 源 uid。对于 touch、program change 和 bend 消息，只会传递 val、chan 和 src。有关其他 msgType 所传递参数的信息，请参见下面的便捷方法。

msgNum

一个 Integer，表示此 MIDIFunc 的 MIDI 消息编号（音符编号、控制器编号或音色编号）。这可以是一个数组。若为 nil，则 MIDIFunc 将响应所有可能消息编号的消息。

chan

一个 Integer，表示此 MIDIFunc 的 MIDI 通道号。它可以是一个数组。若为 nil，则 MIDIFunc 会响应所有通道上收到的消息。

msgType

一个 Symbol，指示此 MIDIFunc 应响应哪种 MIDI 消息。取值为 \noteOn、\noteOff、\control、\touch、\polytouch、\bend、\program、\sysex、\mtcQF、\smpte、\songPosition、\songSelect、\tuneRequest、\midiClock、\sysrt、\tick、\start、\continue、\stop、\activeSense 或 \reset 之一。

srcID

一个 Integer，对应 MIDI 输入的 uid。（参见 Using MIDI: MIDIFunc and MIDIdef: Filtering based on device or message data。）若为 nil，则该 MIDIFunc 将响应来自所有来源的消息。

argTemplate

一个可选的 Integer 或 Function（或响应方法 Methods: matchItem 的对象），用于匹配传入 MIDI 消息的值（例如力度、控制值、音色号等）。如果是 Function，将以消息值作为参数对其求值，并应返回一个 Boolean，表示该消息是否匹配以及此 MIDIFunc 是否应响应。

dispatcher

一个可选的、属于 AbstractDispatcher 相应子类的实例。可用于实现自定义的分发。通常不需要这样做。

返回值：

MIDIFunc 的新实例。

MIDI 时间码四分帧

1

歌曲位置

2

歌曲选择

3

调音请求

6

MIDI 时钟

8

Tick

9

Start

10

Continue

11

Stop

12

活动检测

14

Reset

15

返回值：

Debugging

MIDIFunc.trace(bool: true)

一个便捷方法，用于转储所有传入的 MIDI 消息。

参数：

bool

一个 Boolean，指示转储是开启还是关闭。

实例方法

.chan

获取此 MIDIFunc 的 MIDI 通道号。

返回值：

一个 Integer。

.msgNum

获取此 MIDIFunc 的 MIDI 消息号。

返回值：

一个 Integer。

.msgType

获取此 MIDIFunc 的消息类型。

返回值：

一个 Symbol；取值为 \noteOn、\noteOff、\control、\touch、\polytouch、\bend、\program、\sysex、\mtcQF、\smpte、\songPosition、\songSelect、\tuneRequest、\midiClock、\sysrt、\tick、\start、\continue、\stop、\activeSense 或 \reset 之一。

.argTemplate

获取此 MIDIFunc 的 argTemplate。

返回值：

一个 Integer 或 Function（或响应方法 Methods: matchItem 的对象），用于匹配传入 MIDI 消息的值。（例如力度、控制值、音色号等）。

.learn(learnVal: false)

训练这个 MIDIFunc 使其响应其类型的下一条消息。创建时传入的参数（例如 chan、srcID、msgNum 等）将把训练过滤为下一条匹配的已接收消息。

参数：

learnVal

一个 Boolean，表示响应者是否应学习特定值。例如，如果与 control change MIDIFunc 一起使用，该对象将学习匹配下一个特定的 control change 值。如果与 note on MIDIFunc 一起使用，则只会匹配特定力度。默认值为 false。

示例

MIDIIn.connectAll

a = MIDIFunc.cc({ |...args| args.postln }, 1); // 匹配 cc 1
a.free; // cleanup

b = MIDIFunc.cc({ |...args| args.postln }, 1, 1); // 匹配 cc1，通道 1
b.free; // cleanup

c = MIDIFunc.cc({ |...args| args.postln }, (1..10)); // match cc 1-10
c.free; // cleanup

n = MIDIFunc.noteOn({ |...args| args.postln }); // 匹配任意 noteOn
n.free; // cleanup

MIDIIn.doNoteOnAction(1, 1, 64, 64); // 伪造一个音符开事件
MIDIIn.doControlAction(1, 1, 1, 64); // 伪造一个 cc
MIDIIn.doControlAction(1, 1, 9, 64);
MIDIIn.doControlAction(1, 10, 1, 64);
