IFFT

逆快速傅里叶变换

WidthFirstUGen : UGen : AbstractFunction : Object

另见：FFT、FFT Overview

说明

逆快速傅里叶变换将频率内容转换为信号。

快速傅里叶变换分析信号的频率内容。IFFT UGen 将这些频域信息转换回时域音频数据。最常见的情况是将其用作一个过程的结尾，该过程从 FFT 开始，随后使用 PV（相位声码器）UGen 进行频域处理，最后进行 IFFT。

类方法

IFFT.new(buffer, wintype: 0, winsize: 0)

IFFT.ar(buffer, wintype: 0, winsize: 0)

IFFT.kr(buffer, wintype: 0, winsize: 0)

返回由 FFT 频域信号链转换得到的时间域信号。*new 方法等同于 *ar 消息，返回音频速率信号。

参数：

buffer

最初来自 FFT UGen 的 FFT“链”信号，可能经过其他 PV UGen。

wintype

定义数据如何加窗：

-1

矩形加窗，简单但通常不推荐；

0

（默认）正弦窗，通常推荐用于相位声码器工作；

1

Hann 窗，通常推荐用于分析工作。

-1

矩形加窗，简单但通常不推荐；

0

（默认）正弦窗，通常推荐用于相位声码器工作；

1

Hann 窗，通常推荐用于分析工作。

winsize

可用于补偿零填充，方式与 FFT UGen 相同。

返回值：

时域音频信号。

讨论：

IFFT UGen 就地转换 FFT 数据（在原始 FFT 缓冲区中），并对结果进行重叠相加，以在其输出处产生连续信号。

实例方法

示例

// 不做任何修改，将 FFT 链（频域信号）转换回音频（时域信号）
(
{   var in, chain;
    in = WhiteNoise.ar;
    chain = FFT(LocalBuf(2048), in);
    IFFT.ar(chain) * -20.dbamp // 逆 FFT
}.play;
)
