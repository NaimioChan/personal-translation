NdefParamGui

显示 nodeproxy 的设置

另请参阅：EZText、NdefGui、EnvirGui

说明

NdefParamGui 显示 nodeproxy 的所有设置和映射，因此用户可以灵活地更改它们。单个数字使用 EZSlider 显示，其他内容则显示为 EZText（文本框）。其主要用途是在 NdefGui 中。

它从 EnvirGui 继承了一些有用的方法。

类方法

Creation

.new

创建一个新的 NdefParamGui

// 简单示例 - 另见 NdefGui！

g = NdefParamGui.new(nil, 5);    // 空的有 5 个槽位
g.parent.alwaysOnTop_(true);
g.object_(Ndef(\a));        // 放入一个 nodeproxy
Ndef(\a, { |freq = 300, amp = 0.2| SinOsc.ar(freq) * amp ! 2 }).play;
Ndef(\a).set(\freq, 200);    // 添加一个设置
Ndef(\a);
g.object_(nil);            // 不放入任何内容

g.object_(Ndef(\a));         // 放入一个 nodeproxy
Ndef(\a).set(\amp, 0.125);    // 添加一个设置
Ndef(\a, { |freq = 300, amp = 0.2| SinOsc.ar(freq) * amp });
Ndef(\a).set(\freq, 234);    // 添加一个设置

Ndef(\a).play
Ndef(\lfo, { LFNoise0.kr([12, 8], 200).sum + 500 });
Ndef(\a).map(\freq, Ndef(\lfo)); // 映射的代理会被显示

g.useRanger = false;

// 多通道控件显示在 EZText 中
g.putSpec(\freqs, \freq);
Ndef(\a, { |freqs = #[300, 303], pan, amp = 0.2| SinOsc.ar(freqs).sum * amp });
Ndef(\a).play
Ndef(\a).setn(\freqs, [300, 350])
Ndef(\a).setn(\freqs, [330, 350])
Ndef(\a).set(\harm, 123)

Ndef(\a).nodeMap.clear

Ndef(\lfos, { LFNoise0.kr([12, 8], 200) + 500 });
Ndef(\a).map(\freqs, Ndef(\lfos))

g.parent.close

参数：

object

要显示其设置的 nodeproxy。

numItems

要显示的项数。如果给定了 envir 且没有 num，则 num 为 envir.size。

parent

要显示在其中的父视图；如果未给出，则创建一个新窗口。

bounds

要显示的边界；如果未给出，则计算边界。

makeSkip

是否创建 skipjack 来管理 envirgui 更新的标志。默认为 true。

options

附加信息列表，例如关于可选按钮的标志。

实例方法

.name

如果在其自己的窗口中，则设置该窗口的名称

g.name = "Yoohoo";
