另见：00_入门教程

在我开始关于 SuperCollider 的讲座之前，大家可能首先想了解我关于 SuperCollider 的背景。

我七年前开始使用 SuperCollider。我有一个学生，他对以 ProTools 这类软件无法做到的方式处理录音很感兴趣。我给了他一个 SuperCollider 1 的演示版。他研究了一天后，建议我也应该研究一下。七年过去了，我至今仍在研究它（虽然现在已经是 SuperCollider 3 了）。

如今我知道，SuperCollider 在我作曲或制作音乐时，能帮助我验证自己提出的假设。SuperCollider 具有挑战性，因为它要求你为了制作音乐而去学习编程。尤其是我认为 SuperCollider 是一个极佳的工具，因为使用它需要一种基于实验与开发的艺术家式方法。

在这三场讲座中，我想向大家介绍的内容目标很简单。我将尽可能向大家展示一个思考 SuperCollider 的框架。这个框架将涉及编程以及音乐相关的美学与哲学。此外，我还将介绍我用 SuperCollider 制作的两个大型项目示例。明天要讨论的第一个项目是 Robot in Residence，它使用 SuperCollider 来控制一个包含乐高机器人、聊天机器人以及音频与视频合成的网络化系统。
