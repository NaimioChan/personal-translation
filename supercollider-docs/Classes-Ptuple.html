Ptuple

将流列表组合为列表流

ListPattern : Pattern : AbstractFunction : Object

参见：Ppar

说明

在每次迭代中，Ptuple 返回一个元组（数组），组合列表中各模式的输出。当任一模式返回 nil 时，Ptuple 结束该次“重复”并重新启动所有流。

类方法

Ptuple.new(list, repeats: 1)

来自父类：ListPattern

参数：

list

一个由模式组成的 Array。

repeats

一个 Integer 或 inf。

实例方法

未文档化的实例方法

.embedInStream(inval)

示例

(
var a, b;
a = Pseq([1, 2, 3], inf);
b = Pseq([65, 76], inf);
c = Ptuple([a, a, b], inf);
x = c.asStream;
8.do({ x.next.postln });
)


(
var a, b;
a = Pseq([1, 2, 3], inf);
b = Pseq([65, 76], 3); // 3 个周期后停止
c = Ptuple([a, a, b], 4); // 4 个周期后停止
x = c.asStream;
8.do({ x.next.postln });
)
