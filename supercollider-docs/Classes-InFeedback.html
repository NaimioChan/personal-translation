InFeedback

从总线读取具有当前或一个周期前时间戳的信号。

AbstractIn : MultiOutUGen : UGen : AbstractFunction : Object

另请参见：In、LagIn、LocalIn

说明

当各种输出 UGen（Out、OffsetOut、XOut）向总线写入数据时，它们会将数据与当前周期的任何数据混合，但会覆盖上一周期的任何数据。（ReplaceOut 则无论何时都会覆盖所有数据。）因此，取决于节点顺序以及哪些 synth 正在向该总线写入，给定总线上的数据在读取时可能来自当前周期，也可能已是一个周期前的旧数据。In.ar 会检查其读入的任何数据的时间戳，并将上一周期的任何数据置零（供该节点内部使用；数据仍保留在总线上）。这对音频数据来说没问题，因为它可以避免反馈，但对于控制数据而言，能够读取节点顺序中任意位置的数据是很有用的。因此 In.kr 也会读取早于当前周期的数据。

在某些情况下，我们可能还想在当前节点顺序中稍后的节点读取音频。这正是 InFeedback 的用途。它引入的延迟为一个块大小，在默认块大小和采样率下约等于 0.0014 秒。（请参阅下面的谐振器示例以了解其影响。）

输出 UGen 的可变混合与覆写行为可能使执行顺序至关重要。（并非双关。）例如，对于如下节点顺序，Synth 2 中的 InFeedback UGen 将只会接收到来自 Synth 1 的数据（→ = 写出；← = 读入）：

  • Synth1 → busA（该 synth 在到达 Synth2 之前覆盖了 Synth3 的输出）
  • Synth2（带 InFeedback）← busA
  • Synth3 → busA

如果 Synth1 被移到 Synth2 之后，那么 Synth2 的 InFeedback 将接收到 Synth1 和 Synth3 输出的混合信号。如果 Synth2 排在 Synth1 和 Synth3 之后，情况也是如此。在这两种情况下，来自 Synth1 和 Synth3 的数据都会具有相同的时间戳（无论是当前周期还是上一周期），因此不会有任何数据被覆盖。

因此，通常有用的是为反馈分配一个单独的总线。通过以下安排，无论 Synth1 在节点顺序中的位置如何，Synth2 都会接收来自 Synth3 的数据：

  • Synth1 → busA
  • Synth2（带 InFeedback）← busB
  • Synth3 → busB + busA

下面的第二个示例演示了此问题。

类方法

InFeedback.ar(bus: 0, numChannels: 1)

参数：

bus

要读取的总线索引。

numChannels

要读入的通道数（即相邻总线）。默认值为 1。你不能通过在 SynthDef 中将其赋值给参数来调制此数字。

实例方法

示例

音频反馈调制：

(
SynthDef("help-InFeedback", { |out = 0, in = 0|
    var input, sound;
        input = InFeedback.ar(in, 1);
        sound = SinOsc.ar(input * 1300 + 300, 0, 0.4);
        Out.ar(out, sound);

}).play;
)

这展示了节点如何从一条正在被其后的 synth 写入的总线读取音频：

(
SynthDef("help-InFeedback", { |out = 0, in = 0|
    Out.ar(out,
        InFeedback.ar(in, 1)
    );
}).add;
SynthDef("help-SinOsc", { |out = 0, freq = 440|
    Out.ar(out, SinOsc.ar(freq, 0, 0.1))
}).add;
)

x = Bus.audio(s, 1);

// 从总线 n 读取并播放到总线 0（静音）
a = Synth("help-InFeedback", [\in, x.index, \out, 0]);

// 现在在此 synth 之后播放一个 synth，输出到总线 x
b = Synth.after(a, "help-SinOsc", [\out, x.index]);

// 在 a 之前添加另一个合成器，它也写入总线 x
// 现在你听不到 b 了，因为它的数据是一个周期之前的，并且被 c 覆盖了
c = Synth.before(a, "help-SinOsc", [\out, x.index, \freq, 800]);

// 释放 c 后又能听到 b
c.free;
x.free;

a.free; b.free;

SynthDef("testRes", {

play = InFeedback.ar(10, 1); // 10 是反馈通道

OffsetOut.ar(10, DelayC.ar(imp + (play * 0.995), 1,
    440.reciprocal - ControlRate.ir.reciprocal)); // 减去块大小

OffsetOut.ar(0, play);

}).play(s);
