通用收集器

从无到有逐步构建集合的方法

你可以通过点击方法名来查看哪些类实现了特定方法。

有许多方法可以增量地构建（或缩减）像数组或事件这样的集合。Nil 通过创建一个集合来响应，因此变量不需要初始化。Nil 只是“基础”（默认情况），其余部分由此引导。

add

返回一个包含该值的数组。这使得在添加到变量时无需初始化。

x = nil;
x = x.add(8);  // 返回一个数组
x = x.add(7); // 追加到数组

addAll

返回包含所有值的数组。这样在添加到变量时就无需初始化。

x = nil;
x = x.addAll([0, 2, 1, 2]);  // 返回一个数组
x = x.addAll(7); // 单个对象被转换为数组并追加

remove

对于 nil，它只返回 nil。这样在从变量中移除并再次添加时就不需要初始化。

x = nil;
x.remove(1); // 保持为 nil，返回 nil
x = x.addAll([0, 2, 1]);  // 返回一个数组
x.remove(1); // 返回 1
x;

++

返回包含所有值的数组。这样在添加到变量时就无需初始化。

x = nil;
x = x ++ [7, 8, 9]; // 返回接收者
x = x ++ [3, 0, 1, 2]; // 添加到数组

注意： 请注意，与 addAll 不同，第二个操作数必须是集合才能以这种方式运作。

addFunc

返回一个函数或一个 FunctionList。此方法用于向已有函数中添加多个函数。

f = nil;
f = f.addFunc { "----------****".scramble };
f = f.addFunc { 1.0.rand };
f.value;

// addFunc 的一个典型用例是你需要向已有的函数添加功能。
(
w = Window("move me", Rect(300, 300, 600, 40)).front; w.addFlowLayout;
a = Slider(w, Rect(0, 0, 580, 30));
a.action = a.action.addFunc { "I am moved".postln };
)
a.action = a.action.addFunc { "I am so very moved".postln };
a.addFuncTo(\action, { "Now, I am finally really moved".postln }); // 更短的替代方案

removeFunc

此方法用于从已有函数中移除多个函数。对于 Nil，它只返回自身。

f = { 1.0.rand };
g = { "you have produced a random value".postln };
f = f.addFunc(g);
f.value;
f.removeFunc(g);
f.value;

transformEvent

此方法用于操作作为参数通过系统传递的事件。

// 对于 Nil：原样返回参数（一个事件）。
nil.transformEvent((x: 8));
// 对于 Dictionary（因此也对于 Event）：添加到参数中。
(y: 100, z: 1).transformEvent((x: 8));
// 对于 Association：将关联添加到事件中
(\a -> \x).transformEvent((x: 8));
// 对于 Function：使用该函数接收事件作为参数。
{ |event| event.use { ~x = ~x + 1 }; event }.transformEvent((x: 8));
