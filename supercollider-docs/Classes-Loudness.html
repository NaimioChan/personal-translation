Loudness

以 sones 为单位提取瞬时响度

UGen : AbstractFunction : Object

参见：BeatTrack, MFCC, Onsets, Pitch, KeyTrack

说明

一个感知响度函数，以 sones 为单位输出响度；这是 MP3 感知模型的一种变体，在 ERB 频带中对激励求和。它模拟简单的频谱掩蔽和时间掩蔽，并在 ERB 频带中进行等响曲线校正以获得 phons（相对 dB），然后进行 phon 到 sone 的变换。最终输出通常在 0 到 64 sones 范围内，不过对于特定的合成刺激也可能出现更高的值。

注意： 研究说明：此 UGen 是感知编码与 Zwicker 及 Glasberg/Moore/Stone 响度模型的非正式并置。

类方法

Loudness.kr(chain, smask: 0.25, tmask: 1)

参数：

chain

[fft] 要跟踪的音频输入，已由 FFT UGen 预先分析；有关预期的 FFT 大小，请参阅下面的示例。

smask

[sk] 频谱掩蔽参数：在 ERB 频带内，较低频段会掩蔽较高频段的功率，每个频段的功率衰减（泄漏积分乘数）为 smask。

tmask

[sk] 时间掩蔽参数：在 ERB 频带中通过的 phon 电平是新测量值与先前值减去 tmask phons 后的最大值。

实例方法

示例

// 假设跳数为 fftsize 的一半，可以

d = Buffer.read(s, ExampleFiles.child);

// 分析响度并轮询结果
(
{
    var in = PlayBuf.ar(1, d, BufRateScale.kr(d), 1, 0, 1);
    var chain = FFT(LocalBuf(1024).clear, in);  // 对于采样率 44100 和 48000
    // var chain = FFT(LocalBuf(2048).clear, in);  // 用于采样率 88200 和 96000
    var loudness = Loudness.kr(chain).poll(50);
    Pan2.ar(in)
}.play
)
