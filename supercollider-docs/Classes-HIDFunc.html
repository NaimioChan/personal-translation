HIDFunc

用于接收来自人机接口设备（HID）传入数据的快速响应器

AbstractResponderFunc : Object

另请参见：HID、HIDdef、HIDProto、HIDElementProto、OSCFunc、MIDIFunc、Working with HID

子类：HIDdef

说明

人类输入设备可用作制作音乐的控制器。此类以类似于 OSCFunc 和 MIDIFunc 的方式为你提供对它们的访问。

HIDFunc（及其子类 HIDdef）注册一个或多个函数，以响应传入的 HID 消息。它的许多方法继承自其父类 AbstractResponderFunc。

注意： 默认情况下，HIDFuncs 会在 Cmd-. 时被移除。可以使用 fix 或 permanent 方法之一来覆盖此行为。

这一 SuperCollider 的 HID 访问实现的开发由 SuperCollider 社区和 BEK，Bergen Elektronisk Kunst，挪威卑尔根资助，http://www.bek.no

类方法

HIDFunc.defaultDispatchers

HIDFunc.defaultDispatchers = value

获取或设置一个 IdentityDictionary，其中包含不同类型 HIDFunc 的默认分发器对象（这些就是当你在 *new 中把 nil 作为分发器参数传入时得到的东西）。这些对象将决定其已注册的 HIDFunc 中是否有任何一个应响应传入的 HID 消息。该字典应具有键 [\usage, \usageID, \device, \proto, \element]，以及每种消息类型对应的 AbstractDispatcher 的适当子类作为值。默认情况下，这些值分别会是 HIDUsageDispatcher、HIDElementProtoDispatcher、HIDDeviceDispatcher、HIDElementProtoDispatcher 和 HIDElementDispatcher 的实例。

返回值：

getter 返回一个 IdentityDictionary。

HIDFunc.usage(func, elUsageName, devUsageName, deviceInfo, argTemplate, argTemplateType, dispatcher)

一个便捷方法，用于根据控件的 usage 名称来过滤传入的 HID 值。例如，摇杆 X 轴的名称或鼠标水平移动的名称是 \X。这些 usage 名称由制造商标准化，并根据来自设备的信息在 usage 表中查找。如果你有一个已打开的 HID 设备，可以用以下方式查找可用的 usages：~hid.postUsages。

参数：

func

一个 Function 或类似对象，它将响应传入的消息。它将接收……

elUsageName

要查找的用法名称。可以是单个用法名称，也可以是用法名称的数组。若为 nil，则匹配任何用法。

devUsageName

要查找的设备用途名称，例如 \GamePad 或 \Mouse。如果留空，HIDFunc 将匹配任何设备。

deviceInfo

一个 IdentityDictionary 或 HIDProto，用于对设备进行更详细的过滤。

argTemplate

这应该是一个实现了 matchItem 方法的对象。根据 argTemplateType，它将被传入待匹配元素的值的 rawValue。

argTemplateType

如果 argTemplateType 为 \rawValue（默认值），则匹配基于元素的输入原始值进行（不按照逻辑最小值与最大值进行映射）。否则，匹配按照映射后的值进行。

dispatcher

一个可选的、AbstractDispatcher 相应子类的实例。可用于实现自定义的分发。通常不需要这样做。此类 HIDFunc 的默认值为 HIDUsageDispatcher

返回值：

HIDFunc 的一个新实例，它响应特定的元素用途和设备类型。

HIDFunc.device(func, elUsageName, deviceName, deviceInfo, argTemplate, argTemplateType, dispatcher)

一个便捷方法，用于根据设备名称过滤传入的 HID 值。此类型的 HIDFunc 与 HIDFunc.usage 的不同之处在于，它专门按设备名称而非设备用途进行过滤，其他参数则相同。

参数：

func

一个 Function 或类似对象，它将响应传入的消息。它将接收……

elUsageName

要查找的用法名称。可以是一个用法名称，也可以是用法名称的数组。

deviceName

要查找的设备名称，注意这必须与设备返回的字符串完全匹配。你可以在设备列表中查找此字符串：HID.postAvailable

deviceInfo

一个 IdentityDictionary 或 HIDProto，用于对设备进行更详细的过滤。

argTemplate

这应该是一个实现了 matchItem 方法的对象。根据 argTemplateType，它将被传入待匹配元素的值的 rawValue。

argTemplateType

如果 argTemplateType 为 \rawValue（默认值），则匹配基于元素的输入原始值进行（不按照逻辑最小值与最大值进行映射）。否则，匹配按照映射后的值进行。

dispatcher

AbstractDispatcher 的合适子类的一个可选实例。可用于实现自定义分派。通常不需要这样做。这种 HIDFunc 的默认值是 HIDDeviceDispatcher

返回值：

HIDFunc 的一个新实例，它响应特定设备的特定元素用法。

HIDFunc.usageID(func, elUsageID, elPageID, deviceName, deviceInfo, argTemplate, argTemplateType, dispatcher)

一个便捷方法，用于根据传入的 HID 值的控制用法编号来筛选该值。如果设备使用的是非标准用法编号，则可以使用此方法来查找它。控制的用法由其用法 ID 和用法页的组合完全确定。

参数：

func

一个 Function 或类似对象，它将响应传入的消息。它将被传入……用法

elUsageID

要查找的用法 id（一个 Integer）。它可以是单个用法 id，也可以是用法 id 的数组。如果为 nil，则匹配任意用法 id。

elPageID

要查找的用法页面的 id（一个 Integer）。可以是一个页面 id，也可以是页面 id 的数组。

deviceName

由于此类 HIDFunc 用于非标准化控件，你可以按特定的设备名称进行过滤，而不是按一般用途过滤，类似于 HIDFunc.device

deviceInfo

一个 IdentityDictionary 或 HIDProto，用于对设备进行更详细的过滤。

argTemplate

这应该是一个实现了 matchItem 方法的对象。根据 argTemplateType，它将被传入待匹配元素的值的 rawValue。

argTemplateType

如果 argTemplateType 为 \rawValue（默认值），则匹配基于元素的输入原始值进行（不按照逻辑最小值与最大值进行映射）。否则，匹配按照映射后的值进行。

dispatcher

一个可选的 AbstractDispatcher 相应子类的实例。可用于实现自定义的分发。通常不需要这样做。此类 HIDFunc 的默认值为 HIDElementProtoDispatcher

返回值：

HIDFunc 的一个新实例，它响应特定设备的特定元素用法 id。

HIDFunc.proto(func, protoElement, deviceInfo, argTemplate, argTemplateType, dispatcher)

一种便捷方法，用于根据元素（HIDElementProto）的匹配模板来过滤传入的 HID 值。如果你有多个应匹配的元素条件，那么可以使用此方法来查找它。

参数：

func

一个 Function 或类似对象，它将响应传入的消息。它将被传入……用法

protoElement

要查找的用法的 id（一个 Integer）。可以是一个用法 id，也可以是用法 id 的数组。

deviceInfo

一个 IdentityDictionary 或 HIDProto，用于对设备进行更详细的过滤。

argTemplate

这应该是一个实现了 matchItem 方法的对象。根据 argTemplateType，它将被传入待匹配元素的值的 rawValue。

argTemplateType

如果 argTemplateType 为 \rawValue（默认值），则匹配基于元素的输入原始值进行（不按照逻辑最小值与最大值进行映射）。否则，匹配按照映射后的值进行。

dispatcher

一个可选的 AbstractDispatcher 相应子类的实例。可用于实现自定义的分发。通常不需要这样做。此类 HIDFunc 的默认值为 HIDElementProtoDispatcher

返回值：

HIDFunc 的一个新实例，它响应特定的原型元素。

HIDFunc.element(func, elID, deviceName, deviceInfo, argTemplate, argTemplateType, dispatcher)

一个便利方法，用于根据传入 HID 值元素的索引来过滤该值。如果设备使用的是非标准配置，或者你想直接访问键盘元素，则可以使用此方法查找它。请注意，元素索引在不同操作系统上不一定相同（即它可能在 Linux、macOS 和 Windows 之间有所不同）。

参数：

func

一个 Function 或类似对象，它将响应传入的消息。它将接收……

elID

要查找的元素的 id（一个 Integer）。这可以是一个元素 id，也可以是一个元素 id 的数组。

deviceName

由于此类 HIDFunc 用于非标准化元素，你可以按特定的设备名称进行过滤，而不是按一般用途过滤，类似于 HIDFunc.device

deviceInfo

一个 IdentityDictionary 或 HIDProto，用于对设备进行更详细的过滤。

argTemplate

这应该是一个实现了 matchItem 方法的对象。根据 argTemplateType，它将被传入待匹配元素的值的 rawValue。

argTemplateType

如果 argTemplateType 为 \rawValue（默认值），则匹配基于元素的输入原始值进行（不按照逻辑最小值与最大值进行映射）。否则，匹配按照映射后的值进行。

dispatcher

一个可选的、适当的 AbstractDispatcher 子类实例。这可用于实现自定义分派。通常不需要这样做。此类 HIDFunc 的默认值为 HIDElementDispatcher

返回值：

HIDFunc 的一个新实例，它响应特定设备的特定元素 id。

Debugging

HIDFunc.trace(bool: true)

一个便捷方法，可转储所有传入的 HID 消息。

参数：

bool

一个 Boolean，指示转储是开启还是关闭。

一个 HIDProto 实例，描述用于匹配设备的模板。

这应该是一个实现了 matchItem 方法的对象。根据 argTemplateType，它将被传入待匹配元素的值的 rawValue。

示例

对于下面这里的全部示例，你需要先初始化一个 HID 设备（另见 Working with HID）。下面的示例应可与标准 USB 鼠标配合使用。

HID.findAvailable; // 检查连接了哪些设备
HID.postAvailable; // 列出可用设备
~myhid = HID.open(1103, 53251); // 为你要打开的设备调整这一行！

基于用途过滤

// 过滤来自鼠标 x 轴的所有事件
a = HIDFunc.usage({ |...args| args.postln }, \X, \Mouse);
// 再次禁用该函数：
a.free;

// 过滤来自鼠标的所有事件
a = HIDFunc.usage({ |...args| args.postln }, nil, \Mouse);
// 再次禁用该函数：
a.free;

// 过滤来自 X 轴的所有事件（可能来自鼠标、操纵杆或游戏手柄）
a = HIDFunc.usage({ |...args| args.postln }, \X);
// 再次禁用该函数：
a.free;

// 过滤所有来自 X 轴或 Y 轴的事件（可能来自鼠标、摇杆或游戏手柄）
a = HIDFunc.usage({ |...args| args.postln }, [\X, \Y]);
// 再次禁用该函数：
a.free;


// argTemplate 的用法：匹配 rawValue（这是默认行为）

// 仅在值低于零时响应：
a = HIDFunc.usage({ |...args| args.postln }, [\X, \Y], argTemplate: { |val| val < 0 });
a.free;

// 仅在 rawvalue == -1 时匹配
a = HIDFunc.usage({ |...args| args.postln }, [\X, \Y], argTemplate: -1);
a.free;

// 仅当 rawvalue 为 [-3, -2, -1] 之一时匹配
a = HIDFunc.usage({ |...args| args.postln }, [\X, \Y], argTemplate: [-3, -2, -1]);
a.free;

// argTemplate 的用法：当缩放后的值小于 0.5 时进行匹配
a = HIDFunc.usage({ |...args| args.postln }, [\X, \Y], argTemplate: { |val| val < 0.5 }, argTemplateType: \value);
a.free;


// 使用 deviceInfo 而不是 deviceUsage（你可以添加更多设备规格来匹配）
a = HIDFunc.usage({ |...args| args.postln }, \X, deviceInfo: (usageName: \Mouse));
a.free;

a = HIDFunc.usage({ |...args| args.postln }, nil, deviceInfo: (usageName: \Mouse));
a.free;

基于 usage ID 过滤

// 按用途页 1 上的用途 ID 48 过滤
a = HIDFunc.usageID({ |...args| args.postln }, 48, 1);
a.free;

// 在 usage 页面 1 上按 usage ID 48 或 49 过滤
a = HIDFunc.usageID({ |...args| args.postln }, [48, 49], 1);
a.free;

// 按 usage 页 1 上的任意 usage ID 过滤
a = HIDFunc.usageID({ |...args| args.postln }, nil, 1);
a.free;

// 按用法页 1 上的用法 ID 48 过滤，设备的名称是空字符串（在那里填入你的鼠标名称）。
a = HIDFunc.usageID({ |...args| args.postln }, 48, 1, "");
a.free;

// 按用法页 1 上的用法 ID 48 过滤，设备的路径为 "/dev/hidraw2"（请根据要匹配的设备调整此路径）
a = HIDFunc.usageID({ |...args| args.postln }, 48, 1, deviceInfo: (path: "/dev/hidraw2")  );
a.free;

基于设备过滤

// 筛选名称为 "" 的设备，以及 usage 为 \X 的元素。
a = HIDFunc.device({ |...args| args.postln }, \X, "");
a.free;

基于一个原型元素进行过滤

// 创建一个 usageName 为 \X 的原型元素
c = HIDElementProto.new.usageName_(\X);
a = HIDFunc.proto({ |...args| args.postln }, c);
a.free;

基于元素 ID 进行过滤

// 筛选元素 id 为 6 的元素：
a = HIDFunc.element({ |...args| args.postln }, 6);
a.free;
