PV_RectComb2

在频谱中制造间隙。

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

另请参见：FFT、IFFT、PV_RectComb

说明

在两个输入之间交替分块的分频段。

类方法

PV_RectComb2.new(bufferA, bufferB, numTeeth: 0.0, phase: 0.0, width: 0.5)

参数：

bufferA

FFT 缓冲区 A。

bufferB

FFT 缓冲区 B。

numTeeth

梳状滤波器的齿数。

phase

梳状脉冲的起始相位。

width

梳状滤波器的脉冲宽度。

实例方法

示例

s.boot;
b = Buffer.read(s, ExampleFiles.child);

var exBuf;
Dialog.getPaths({ |paths| // 获取第二个声音文件；
