Ppar

并行嵌入事件流

ListPattern : Pattern : AbstractFunction : Object

另请参阅：Ptpar、Pgpar、Pbus、Pgroup

子类：Pgpar、Ptpar

说明

嵌入多个事件流，使它们构成一个按时间顺序包含所有事件的单一输出流。当一个流结束时，其他流会进一步嵌入，直到所有流都结束。

类方法

Ppar.new(list, repeats: 1)

来自父类：ListPattern

参数：

list

模式或流的列表。

repeats

将整个模式重复 n 次。

实例方法

未文档化的实例方法

.embedInStream(inval)

.initStreams(priorityQ)

示例

// 查看结果事件中的 delta 值
(
var a, b, c, t;
a = Pbind(\x, Pseq([1, 2, 3, 4]), \dur, 1);
b = Pbind(\x, Pseq([10, 20, 30, 40]), \dur, 0.4);
c = Ppar([a, b]);
t = c.asStream;
20.do({ t.next(Event.default).postln });
)

// 声音示例
(
var a, b;
a = Pbind(\note, Pseq([7, 4, 0], 4), \dur, Pseq([1, 0.5, 1.5], inf));
b = Pbind(\note, Pseq([5, 10, 12], 4), \dur, 1);
Ppar([a, b]).play;
)
