ProxyMixer

proxyspace 或 Ndef.all 的混音控制

另请参阅：ProxySpace、Ndef、JITGui、NdefGui、MonitorGui、NdefParamGui

说明

ProxyMixer 提供了用于处理和编辑 proxyspace 中的节点代理及其监视器的控件（跨平台图形）。它取代了先前的 ProxyMixer 类。对于 Ndef，请使用 NdefMixer。

概述：JITLib

// 第一个示例：
(
p = ProxySpace.push(s.boot, p);
"abcde".do { |k| p[k.asSymbol].ar };
m = ProxyMixer(p, 8);
m.parent.alwaysOnTop_(true); // 在 IDE 前方显示混音器
)

p.do(_.play(0));
m.object_(nil);
m.object_(p);

// 如果你安装了 JITLibExtensions，可以试试用 ProxyMeter 查看 proxy 的电平：
if (\ProxyMeter.asClass.notNil) { ProxyMeter.addMixer(m) };


"abcdefghijk".do { |k| p[k.asSymbol].ar };

"lmnopqrtuvw".do { |k| p[k.asSymbol].kr };

"abcdefghijk".do { |k, i|
    p[k.asSymbol].playN(vol: 0.8 - (0.1 * i));
    p[k.asSymbol].source = {
        VarSaw.ar((i + 1 * 100) + [-1, 1])
        * LFSaw.ar((i + 1 * 0.25));
    };
};

Creation

.new

参数：

obj

numItems

可以显示多少个 ar 和 kr 代理

parent

默认为 nil，因此会自动创建窗口。如果提供了父级，ProxyMixer 将显示在其中。

bounds

窗口边界 - 默认为 nil，因此会自行确定其大小。

makeSkip

是否创建 skipjack 的标志

options

附加设置 - 当前未提供。

.small

类似 *new，但为小屏幕尺寸创建一个 proxyMixer。

code::

// 创建一个 proxyspace 和 5 个 ar 代理，以及一个混音器来显示它们
(
p = ProxySpace.push(s.boot, p);
"abcde".do { |k| p[k.asSymbol].ar };
m = ProxyMixer(p, 8);
p.do(_.play(0));
)

m.object_(nil); // 无对象
m.object_(p);   // 代理空间

// 如果你安装了 JITLibExtensions，可以试试用 ProxyMeter 查看 proxy 的电平：
if (\ProxyMeter.asClass.notNil) { ProxyMeter.addMixer(m) };

    // 创建过多的 ar 代理，得到一个滚动条
"abcdefghijk".do { |k| p[k.asSymbol].ar };

    // 创建过多的 kr 代理，得到一个滚动条
"lmnopqrtuvw".do { |k| p[k.asSymbol].kr };

p.stop;
    // 播放其中一些
m.arNames.scramble.keep(5).do { |k| p[k.asSymbol].playN };

    // 左上角菜单设置将显示哪些 proxy。

        // existingProxies：即使是空代理也会显示
~test.ar;

(        // activeProxies：代理存活时才会出现
~test = { |freq = 250, intv = 19, timescale = 1, curve = 0, loopnode = 0|
    var env = EnvGen.kr(
        Env({ 1.0.rand2 }!11, { 1.0.rand }!10, curve, releaseNode: 9, loopNode: loopnode),
        timeScale: timescale);
    var pitch = (env * [1, 0.33, -1] * intv).midiratio * freq;
    Splay.ar(Formant.ar(pitch, pitch.scramble * 2, pitch.scramble)) * 0.1;
};
)
~test.lag(\freq, 4);

        // playingProxies：只显示真正在播放的。
~test.playN(vol: 1);

// 切换回活跃的 proxy……
        // reduce 按钮会移除所有未在播放、
        // 且未被其他 proxy 用作源的 proxy：
~otto = { |dens = 12| Dust.ar(dens) };

~otto.clear;        // 将其移除
p.reduce;

        // doc 和 docSel 将当前 proxyspace 作为代码发布
p.document;

        // ProxyMixer 有三种预设宽度：
m.switchSize(0);    // 仅 ar 区域
m.switchSize(1);    // ar + kr
m.switchSize(2);    // ar + kr + 编辑区域

        // 用一个小型 ProxyMixer 试试：
l = ProxyMixer.small(p, 8);
l.switchSize(0, true);    // 仅 ar 区域
l.switchSize(1, true);    // ar + kr
l.switchSize(2, true);    // ar + 编辑区

        // Record 打开一个实用程序窗口 RecordProxyMixer。
        // 这需要 JITLibExtensions quark。

    // 一个代理及其监视器的控制行是一个
    // ProxyMonitorGui，因此完整细节请参见 ProxyMonitorGui.help。

    // 它显示当前音量，
~test.vol_(0.05);
~test.vol_(0.1);

    // 代理名称；play/stop/end 控制：
~test.playN;        // playN as is
~test.stop;        // stop
~test.end;        // option-点击 stop：结束监听器和代理本身。
~test.playN(vol: 0);    // 按住 Option 点击播放：以零音量开始播放。

~test.playNDialog;  // 按住 shift 点击播放/停止：从代码设置多通道输出


s.scope(8);
~test.playN(4);    // 设置 proxy 的第一个输出通道：
~test.playN(0);

// 可以移动滑块与 nameView 之间的边界：

n.enableNameResize(true);    // 现在试着点击并拖动那个边框

n.setNameLeftBorder(200);   // 或通过代码设置

    //    paus/rsum 切换暂停和恢复：
~test.pause;
~test.resume;

    // send 按钮会重新发送代理，
    // option 点击 send 会重建代理
    // （例如用于在客户端状态中查找）
~test.send;
~test.send;
~test.rebuild;
~test.rebuild;


    // ed 按钮将此代理发送到编辑器 - 见下文

        // kr 代理显示在中间
~lfo = { SinOsc.kr(2) };
~lfnoyz0 = { |lofreq = 0.5, mul = 1, add| LFDNoise0.kr(lofreq, mul, add) };

        // 编辑器区域是一个 NodeProxyEditor
        // 打开它并设置一些参数
m.switchSize(2);
m.editGui.object_(~test);
~test.set(\freq, exprand(80, 1250));    // 设置 ~tests 参数
~test.set(\intv, 1.0.linrand);

    //    如果你为参数范围声明全局 spec，
    //    它们可以在编辑器中使​​用：
m.editGui.paramGui.specs.clear;

Spec.add(\intv, [0, 36, \lin]);
Spec.add(\timescale, [0.001, 10, \exp]);
Spec.add(\loopnode, [0, 7, \lin, 1]);
Spec.add(\curve, [-10, 10]);

m.editGui.object_(~test);

        // 你可以将 kr 代理映射到控制参数；
~test.map(\intv, ~lfnoyz0);
~test.unmap(\intv);
        // 这也可以通过拖动 kr 代理名称来实现
        // 即参数名称左侧的字段。


p.reduce(method: \clear);

p.clean;

p.clear;
