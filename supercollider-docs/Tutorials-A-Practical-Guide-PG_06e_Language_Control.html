模式指南 06e：语言控制

模仿某些语言端控制结构的模式

另请参见：Pattern Guide 06d: Parallel Patterns、Pattern Guide 06f: Server Control

语言控制方法

有些模式模仿语言风格的控制方法：条件分支（Pif）、循环（Pwhile）和错误清理（Pprotect）。

Pif(condition, iftrue, iffalse, default)

评估一个模式条件，该条件返回 true 或 false。然后，从 true 或 false 分支中取出一个值，再返回去重新评估该条件。当 true 或 false 分支停止产生值（返回 nil）时，默认值或模式就会起作用。如果未给出默认值，则 Pif 在任一分支返回 nil 时把控制权交还给父级。

p = Pbind(
    \degree, Pwhite(0, 11, inf),
        // 奇数音阶度数获得更短的节奏值
    \dur, Pif(Pkey(\degree).odd, 0.25, 0.5)
).play;

p.stop;
Pseed(randSeed, pattern)

随机数生成器依赖于种子值；设置特定的种子会产生可重复的伪随机数流。Pseed 在嵌入 pattern 之前设置随机种子，从而有效地在 pattern 开始时重新启动随机数生成器。

p = Pbind(
        // 随机种子在创建 Pattern 对象时生成一次
        // 因此每当此 pattern 对象播放时都会使用相同的随机种子
    \degree, Pseed(0x7FFFFFFF.rand, Pseries({ rrand(-7, 0) }, Pwhite(1, 3, inf), { rrand(4, 10) })),
    \dur, 0.25
);

q = p.play;    // 使用一个种子
q.stop;

r = p.play;    // 使用相同的种子
r.stop;

// 重新执行 p = Pbind... 种子将会不同
Pprotect(pattern, func)

与 protect 错误处理方法类似，如果在从模式获取下一个值时发生错误，该函数将在错误中断执行之前被求值。

Ptrace(pattern, key, printStream, prefix)

为便于调试，Ptrace 会打印每个返回值。你的模式真的在做你期望的事吗？它会告诉你。Ptrace 由 trace 消息自动创建：aPattern.trace(key, printStream, prefix) --> Ptrace(aPattern, key, printStream, prefix)。

Pwhile(func, pattern)

与 while 类似：只要函数求值为 true，模式就被嵌入。该函数在开始时检查一次，此后在模式结束时检查。如果应用于无限模式，则不会循环，因为模式永远不会交回控制权。

// Pwhile 和 Ptrace
(
~go = true;
p = Pwhile({ ~go }, Pbind(
    \degree, Pseries({ rrand(-7, 0) }, Pwhite(1, 3, inf), { rrand(4, 10) })
        .trace(prefix: "degree: "),
    \dur, 0.25
)).play;
)

~go = false;    // 当 Pbind 结束时将停止整个 pattern
