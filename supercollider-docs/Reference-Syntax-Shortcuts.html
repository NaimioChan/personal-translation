Introduction

此文件展示了编译器中的若干语法等价形式。

由于存在多种语法等价形式，某些表达式可以用许多不同的方式书写。以下所有写法都做同样的事情，并编译为相同的代码。

// 新参数语法

(1..10).collect({ |n| n.squared });  // 接收者语法
collect((1..10), { |n| n.squared }); // 函数调用语法
(1..10).collect { |n| n.squared };   // 带尾随块参数的接收者语法
collect ((1..10)) { |n| n.squared }; // 带尾随块参数的函数调用语法
(1..10) collect: { |n| n.squared };  // 二元运算符语法


// 旧参数语法

(1..10).collect({ arg n; n.squared });  // 接收者语法
collect((1..10), { arg n; n.squared }); // 函数调用语法
(1..10).collect { arg n; n.squared };   // 带尾随块参数的接收者语法
collect ((1..10)) { arg n; n.squared }; // 带尾随块参数的函数调用语法
(1..10) collect: { arg n; n.squared };  // 二元运算符语法


// 部分应用语法

(1..10).collect(_.squared);   // 接收者语法
collect((1..10), _.squared);  // 函数调用语法
(1..10) collect: _.squared;   // 二元运算符语法

你甚至可以开始展开 (1..10) 的等价形式，它实际上是 series(1, nil, 10) 的简写。这也可以写作 1.series(nil,10)。这样就在上面 13 种变体的基础上又增加了 26 种变体。

定义函数和类

定义中更短的参数列表

而不是写成：

你可以写：

{ arg x; x < 2 }

{ |x| x < 2 }

{ arg x = 123; x < 2 }

{ |x = 123| x < 2 }

{ arg x = 10.rand; x < 2 }

{ |x = (10.rand)| x < 2 } or {|x(10.rand)| x < 2 }

注意： 使用新的 || 语法时，如果默认值不是字面量，则需要用括号括起来。

部分应用

而不是写成：

你可以写：

{ |x| object.msg(a, x, b) }

object.msg(a, _, b)

{ |x,y| object.msg(a, x, y) }

object.msg(a, _, _)

{ |x| a + x }

a + _

{ |x| [a, b, x] }

[a, b, _]

{ |x| (a: x) }

(a: _)

注意： _ 能够捕获的周围表达式的范围存在一些限制。详情请参见 Partial Application。

定义实例变量访问器方法

而不是写成：

你可以写：

Thing { var x;
    x { ^x }
    x_ { arg z; x = z; }
}
Thing { var <>x; }

发送消息、调用 Function 以及实例化对象

函数调用与接收者记法

而不是写成：

你可以写：

f(x, y)

x.f(y)

f(g(x))

x.g.f

调用 'value' 方法

而不是写成：

你可以写：

f.value(x)

f.(x)

实例化对象

而不是写成：

你可以写：

Point.new(3, 4)

Point(3, 4)

调用实例变量 setter 方法

而不是写成：

你可以写：

p.x_(y)

p.x = y 或 x(p) = y

调用 performList

而不是写成：

你可以写：

object.performList(\method, a, b, array)

object.method(a, b, *array)

将块移出参数列表（尾随块参数）

而不是写成：

你可以写：

if (x < 3, { \abc }, { \def })

if (x < 3) { \abc } { \def }

z.do({ |x| x.play })

z.do { |x| x.play }

while({ a < b }, { a = a * 2 })

while { a < b } { a = a * 2 }

Pfunc({ rrand(3, 6) })

Pfunc { rrand(3, 6) }

注意： 尾随参数必须是字面块。其他任何表达式都不能用作尾随参数，即使它的求值结果是一个 Function。例如，你不能将变量名用作尾随参数，即使该变量已被赋予一个 Function。将选择器用作中缀二元运算符（下一节将讨论）可以构造出视觉上相似的结构，这种结构确实允许任意表达式作为操作数，但这些二元运算符结构在技术上没有尾随参数。( var f = { |n| (2**n) + (3**n) }; collect((1..5), f); // 有效 (1..5).collect(f); // 有效 (1..5) collect: f; // 有效（选择器作为二元运算符） ) (1..5).collect f; // 语法错误（非块作为尾随参数） collect((1..5)) f; // 语法错误（同上） 当这种语法限制产生影响时，一个相当常见的情况是：使用 _ 语法的部分应用是一个求值为 Function 的表达式，但它不是字面块。因此：do(6) _.postln // 语法错误 6.do _.postln // 语法错误 do(6, _.postln) // 有效 6.do(_.postln) // 有效 6 do: _.postln // 有效

使用选择器（方法名）作为二元运算符

而不是写成：

你可以写：

div(x, y)

x div: y

警告： 在各种调用语法形式之间切换时，必须注意：作为二元运算符的选择器与大多数其他二元运算符具有相同的优先级，但优先级低于接收者点号表示法（.）。因此，将接收者语法（点号）替换为写作二元运算符的选择器，可能会改变某些表达式的结果，如下所示：4 + 5.div(2) // -> 6 4 + 5 div: 2 // -> 4 // 这是两个点号的从左到右应用， // 其中第一个带有一个尾随块参数。 (1..3).collect { |x| x + 1 }.bubble // -> [ [ 2, 3, 4 ] ] // 这是一个选择器二元运算符（"collect:"）， // 应用于两个参数，其中第二个参数是 // 将 "bubble"（通过点号语法）应用于一个函数的结果。 (1..3) collect: { |x| x + 1 }.bubble // -> [ [ a Function ], [ a Function ], [ a Function ] ] // 使用显式括号改变上述优先级 ((1..3) collect: { |x| x + 1 }).bubble // -> [ [ 2, 3, 4 ] ] // 或者统一使用选择器作为二元运算符 (1..3) collect: { |x| x + 1 } bubble: 0

像 + 这样的原生中缀运算符也可以写成（更长的）函数调用形式，例如：

infix:

函数调用：

1 + 2

(+)(1, 2)

后一种形式通常不是一种简写，除非有人想动态改变运算符的副词，例如 +++ 的副词，因为中缀表示法中的副词被解释为字面量。

(
var a = (_+_) ! [3, 3]; // -> [ [ 0, 1, 2 ], [ 1, 2, 3 ], [ 2, 3, 4 ] ]
(0..2) collect: (+++)(a, 99, _) flatten: 3; // 迭代副词
)
(0..2) collect: (a +++._ 99) flatten: 3;    // 语法错误
(
var a = (_+_) ! [3, 3];
(0..2) collect: {|v| a +++.v 99} flatten: 3 // 使用字面副词 \v
)

Collections

创建一个集合

而不是写成：

你可以写：

Set.new.add(3).add(4).add(5)

Set[3, 4, 5]

Array[3, 4, 5]

[3, 4, 5]

索引元素

而不是写成：

你可以写：

z.at(i)

z[i]

z.put(i, y)

z[i] = y

访问数组的子范围

而不是写成：

你可以写：

a.copyRange(4, 8)

a[4..8]

a.copyToEnd(4)

a[4..]

a.copyFromStart(4)

a[..4]

创建等差数列

而不是写成：

你可以写：

Array.series(16, 1, 1) 或 series(1, nil, 16)

(1..16)

Array.series(6, 1, 2) 或 series(1, 3, 11)

(1, 3..11)

创建迭代的 Routine 也有类似的语法：

而不是写成：

你可以写：

seriesIter(1, 3, 11)

(:1, 3..11)

注意： SuperCollider 也支持 List Comprehensions。

作为一个简单（非组合）的示例，以下列出前 10 个质数的方式是等价的：

(:1..) select: _.isPrime nextN: 10;
{: x, x <- (1..), x.isPrime }.nextN(10);

创建事件

而不是写成：

你可以写：

Event[\a -> 1, \b -> 2]

(a: 1, b: 2)

使用键值对创建数组

而不是写成：

你可以写：

[\a, 1, \b, 2]

[a: 1, b: 2]

其他快捷方式

多重赋值

而不是写成：

你可以写：

x = z.at(0); y = z.at(1);

# x, y = z;

访问环境变量

而不是写成：

你可以写：

'myName'.envirGet

~myName

'myName'.envirPut(9)

~myName = 9

Symbols 的简写

而不是写成：

你可以写：

'mySymbol'

\mySymbol

注意： 该简写只接受可放在单引号内的符号的一个子集。详情请参阅 Literals: Symbols。

创建 Ref

而不是写成：

你可以写：

Ref.new(thing)

`thing
