Class.initClass

来自父类：Object

当 SuperCollider 启动时，就在它编译完库之后，它会从 Object 开始向下初始化所有类，即对子类进行深度优先遍历。

此方法可在任何需要初始化类变量或其他资源的类中重载。

注意： 每个类都会被初始化一次，因此每个类的 initClass 在初始化阶段恰好被调用一次。

Class.initClassTree(aClass)

用于 *initClass，以确保在使用 aClass 之前完成其初始化。必要时，它会递归初始化 aClass 所依赖的所有类。

在某些情况下，需要先初始化另一个类及其资源，然后才能初始化你自己的类。这可以通过以下方式实现：

YourClass {
    *initClass {
        // 在继续之前初始化 OtherClass
        Class.initClassTree(OtherClass);

        ..

        // 使用 OtherClass

        ..
    }

    ..

}

诸如 SynthDef 之类的预初始化数据应推迟到 StartUp 中处理

YourClass {
    *initClass {
        StartUp.add {
            ..
        }
    }

    ..

}

实例方法

.browse: METHOD NOT FOUND!

为此类打开一个图形浏览器。显示方法、参数、变量、子类，并有按钮可导航到父类、源代码、帮助文件等。

.findMethod(methodName)

按名称查找所引用的 Method。如果未找到，则返回 nil。

.findRespondingMethodFor(methodName)

同上，但会沿类树向上查找以判断该方法是否继承自父类。如果未找到，则返回 nil。

.dumpAllMethods

来自扩展 /usr/local/share/SuperCollider/SCClassLibrary/DefaultLibrary/dumpFullInterface.sc

打印此类的实例所响应的所有实例方法，包括继承的方法。this.class.dumpAllMethods 将打印此类所响应的所有类方法。

.dumpByteCodes(methodName)

转储所命名方法的字节码。

.dumpClassSubtree

发布所有继承自该类的类的树。

.dumpInterface

张贴此 Class 定义的所有方法及其参数。

.dumpFullInterface

来自扩展 /usr/local/share/SuperCollider/SCClassLibrary/DefaultLibrary/dumpFullInterface.sc

打印此类的所有类和实例方法（即在当前类中定义的方法以及从父类继承的方法）。

.help

如果此类的帮助文件存在，则打开它。

.helpFilePath

返回此类的帮助文件路径，以 String 形式。

.helpFileForMethod(methodSymbol)

来自扩展 /usr/local/share/SuperCollider/SCClassLibrary/DefaultLibrary/dumpFullInterface.sc

打开响应方法所在类的帮助文件。

Array.helpFileForMethod('select'); // 这将打开 Collection 帮助文件
