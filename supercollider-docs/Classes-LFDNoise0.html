LFDNoise0

动态步进噪声

LFNoise0 : UGen : AbstractFunction : Object

参见：LFClipNoise、LFDClipNoise、LFDNoise1、LFDNoise3、LFNoise0、LFNoise1、LFNoise2

说明

与 LFNoise0 类似，它按照 freq 参数给定的速率生成随机值，但有两个区别：

  • 无时间量化
  • 从低频值快速恢复1

如果你不需要非常高或非常低的频率，或者使用固定频率，LFNoise0 更高效。

类方法

LFDNoise0.ar(freq: 500.0, mul: 1.0, add: 0.0)

来自父类：LFNoise0

LFDNoise0.kr(freq: 500.0, mul: 1.0, add: 0.0)

来自父类：LFNoise0

参数：

freq

生成随机值的近似速率。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

// 试试快速晃动鼠标；
// LFNoise 经常看起来卡住，LFDNoise 则平滑变化。

{ LFNoise0.ar(MouseX.kr(0.1, 1000, 1), 0.1) }.play

{ LFDNoise0.ar(MouseX.kr(0.1, 1000, 1), 0.1) }.play

// 在频率上升前静音 2 秒

{ LFNoise0.ar(XLine.kr(0.5, 10000, 3), 0.1) }.scope;

{ LFDNoise0.ar(XLine.kr(0.5, 10000, 3), 0.1) }.scope;


// LFNoise 在高频时会对时间步进行量化，LFDNoise 则不会：

{ LFNoise0.ar(XLine.kr(1000, 20000, 10), 0.1) }.scope;

{ LFDNoise0.ar(XLine.kr(1000, 20000, 10), 0.1) }.scope;

{ LFNoise2.ar(1000, 0.25) }.play;

[1] - LFNoise0、LFNoise1 和 LFNoise2 会量化到采样率整数除法的最接近值，并且它们仅在调度时轮询 freq 参数；因此当频率变得非常低时，它们常常看起来像挂起。
