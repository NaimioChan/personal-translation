以时间作为求值基础的模式

基于时间的模式

这里的“基于时间的模式”是指将时间作为其计算一部分的值模式。事件模式在时钟上播放时自然是时间驱动的。（技术上可以从事件流请求事件而不在 EventStreamPlayer 中运行它，但这不是典型用法。）

这些模式中的大多数都通过在模式嵌入值流的那一刻记住时钟的当前时间来工作。那么，用于计算的时间值就是求值时刻的时钟时间减去起始时间——也就是模式开始嵌入以来经过的拍数。如果模式被多次嵌入，起始时间也会重置，以便模式从头重新开始。

没有什么能阻止在调度上下文之外使用这些模式。在本文档中，该上下文是在时钟上播放的事件模式，但由这些模式生成的流也可以用于调度的例程或函数中。只有调度上下文才能确保值请求的精确时序。

Ptime(repeats)

返回自嵌入以来经过的时间量。这个模式的一个巧妙用法是在一定时间后停止值流/模式。

这个 Pif 模式使用 Ptime 在请求第一个值之后正好 4 拍内从 true 分支获取值。之后条件将变为 false，Pif 回到 false 分支，即 nil。这会导致流停止。（这类似于事件模式的 Pfindur，但 Pif/Ptime 对值模式也同样有效。）

// 这是一个非常有用的技巧：类似 Pfindur，但用于值模式
(
p = Pbind(
    \degree, Pif(Ptime(inf) < 4.0, Pwhite(-4, 11, inf)),
    \dur, 0.25
).play;
)
Pstep(levels, durs, repeats)

为其对应的时长重复一个电平值，然后移动到下一个。

Pseg(levels, durs, curves, repeats)

与 Pstep 类似，但它会插值到下一个值，而不是在持续时间结束时突然步进。默认情况下插值是线性的，但可以使用任何包络段曲线。levels、durs 和 curves 应当是模式。

// curve 为 5——曲线看起来是这样的，先上升后下降
Env(#[0, 1, 0], #[1, 1], 5).plot;

(
p = Pbind(
        // 使用 \note 是因为 Pseg 会给出分数音符编号
        // 不能使用 \degree，因为它对非整数的处理方式不同
    \note, Pseg(
        Pwhite(-7, 19, inf),    // 半音音高编号
            // 自然音级数字的替代版本
            // PdegreeToKey 执行与 \degree --> \note 相同的转换
//        PdegreeToKey(Pwhite(-4, 11, inf), Pkey(\scale), 12),
        Pwhite(1, 4, inf) * 0.5,
        5, inf),
    \dur, 0.125
).play;
)

p.stop;

将包络用作模式

Env 支持流协议：asStream 将 Env 转换为流，并且可以使用 next 从中获取定时值。包络流返回包络在经过时间处应有的值，其方式与 .at(time) 返回包络在指定时间处的值相同。

e = Env.linen(1, 1, 1);
e.at(2);    // == 1
e.at(2.5);    // == 0.5

// 打印包络值
r = fork {
    var stream = e.asStream;
    12.do({
        stream.next.postln;
        0.25.wait;
    });
};

// 使用包络将音符从左到右再返回地声像
p = Pbind(
    \degree, Pwhite(-4, 11, 32),
    \pan, Env(#[-1, 1, -1], #[2, 2], \sin),
    \dur, 0.125
).play;

p.stop;

releaseNode 和 loopNode 这两个包络参数不会生效，因为它们只有在与带门控的 EnvGen 配合使用的 Synth 中才有意义。

当包络结束时，流将无限期保持最终电平。Pif(Ptime(inf) < totalTime, Env(...)) 技巧可以让它改为停止。

// 使用包络将音符从左到右再返回进行声像处理
// 播放一个周期
(
p = Pbind(
        // 改为 inf：我们不需要确切知道需要多少事件
    \degree, Pwhite(-4, 11, inf),
    \pan, Pif(Ptime(inf) <= 4.0, Env(#[-1, 1, -1], #[2, 2], \sin)),
    \dur, 0.125
).play;
)

p.stop;

// 要让包络持续循环，将 Pif 包裹在 Pn 内
(
p = Pbind(
    \degree, Pwhite(-4, 11, inf),
    \pan, Pn(Pif(Ptime(inf) <= 4.0, Env(#[-1, 1, -1], #[2, 2], \sin)), inf),
    \dur, 0.125
).play;
)

p.stop;
