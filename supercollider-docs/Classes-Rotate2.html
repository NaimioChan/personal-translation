Rotate2

旋转声场。

MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：BiPanB2、DecodeB2、PanB、PanB2

说明

Rotate2 可用于围绕轴旋转 ambisonic B-format 声场。Rotate2 进行等功率旋转，因此它也能很好地作用于立体声。它接受两个音频输入（x、y）和一个角度控制（pos）。它输出两个声道（x、y）。它计算如下：

xout = cos(angle) * xin + sin(angle) * yin;
yout = cos(angle) * yin - sin(angle) * xin;

其中 angle = pos * pi，因此 -1 变为 -pi，+1 变为 +pi。这允许你使用 LFSaw 围绕圆进行连续旋转。

类方法

Rotate2.ar(x, y, pos: 0.0)

Rotate2.kr(x, y, pos: 0.0)

参数：

x

输入信号 X。

y

输入信号 Y。

pos

绕圆圈旋转的角度，从 -1 到 +1。-1 为 180 度，-0.5 为左，0 为前，+0.5 为右，+1 为后。

实例方法

示例

(
{
    var w, x, y, p, q, a, b, c, d;

    p = WhiteNoise.ar(0.05); // source
    q = LFSaw.ar(200, 0, 0.03)+LFSaw.ar(200.37, 0, 0.03)+LFSaw.ar(201, 0, 0.03);

    // 在圆的两侧对两个信号进行 B-format 编码
    #w, x, y = PanB2.ar(p, -0.5) + PanB2.ar(q, 0.5);

    #x, y = Rotate2.ar(x, y, MouseX.kr(-1, 1));

    // B-format 解码为四声道
    #a, b, c, d = DecodeB2.ar(4, w, x, y);

    [a, b, d, c] // 重新排序为我的扬声器布局：Lf Rf Lr Rr
}.play;
)



// 立体声的旋转：
(
{
    // 通过 lfo 旋转
    var x, y;
    x = PinkNoise.ar(0.4);
    y = LFTri.ar(800) * LFPulse.kr(3, 0, 0.3, 0.2);
    #x, y = Rotate2.ar(x, y, LFSaw.kr(0.1));
    [x, y]
}.play;
)

{
    // 通过鼠标旋转
    var x, y;
    x = Mix.fill(4, { LFSaw.ar(200 + 2.0.rand2, 0, 0.1) });
    y = SinOsc.ar(900) * LFPulse.kr(3, 0, 0.3, 0.2);
    #x, y = Rotate2.ar(x, y, MouseX.kr(0, 2));
    [x, y]
}.play;


// 绕 Z 轴旋转 B-format：

wout = win;
zout = zin;
#xout, yout = Rotate2.ar(xin, yin, pos);

// 绕 Y 轴旋转 B-format：

wout = win;
yout = yin;
#xout, zout = Rotate2.ar(xin, zin, pos);

// 绕 X 轴旋转 B-format：

wout = win;
xout = xin;
#yout, zout = Rotate2.ar(yin, zin, pos);
