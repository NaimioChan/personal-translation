04. 函数及其他功能

SuperCollider 入门

另请参阅：00. Getting Started With SC

警告： 如果你使用的是耳机或外接扬声器，建议在播放以下示例之前先将音量调低，然后再调到舒适的水平。原始合成音调有时听起来会比音乐以及我们通常聆听的其他形式的音频更响。

从 SC 获取声音最简单的方法是使用 play 函数。在确保服务器已启动后，运行下面的简单示例。

当你听够了，按 Ctrl-.（macOS 上为 Cmd-.）停止声音。这将始终停止 SC 中所有正在运行的进程和声音。你会经常用到它，所以要牢记在心。

{ [SinOsc.ar(440, 0, 0.2), SinOsc.ar(442, 0, 0.2)] }.play;

不太鼓舞人心？别担心，我们才刚刚开始，这只是一个演示 Functions 与声音的简单示例。下面我们会稍微拆解一下。

不过在开始之前，让我们先大致了解一下 Function。

函数只是一段可复用的代码。通过将代码括在花括号中来定义函数：{ }。下面是一个示例：

f = { "Function evaluated".postln };

花括号内的内容就是每次重用、或“调用”、或“求值”该函数时将执行的内容。注意它的写法像一个等式，即 f = {...}。这并不是数学意义上的等式，而是所谓的“赋值”。基本上，它让我可以为所创建的函数命名，方法是将其存储在一个名为 f 的变量中。变量是一个名称，代表一个可以存放各种东西的槽位，例如函数、数字、列表等。逐行执行下面的代码，并观察 post 窗口：

f = { "Function evaluated".postln };
f;

两次都应该输出 'a Function'。现在，每当我们想引用我们的 Function 时，只需使用字母 f 即可。事实上，这正是它可复用的原因！否则我们每次都需要重新输入这个 Function。

函数也可以跨越多行。双击第一行以确保括号之间的所有内容都被选中（花括号内的所有代码，但也包括 f =）：

(
f = {
    "Starting Function evaluation".postln;
    "Finishing Function evaluation".postln
};
)
f;

那么我们如何复用它呢？逐行执行以下代码，并观察 post 窗口：

f = { "Function evaluated".postln };
f.value;
f.value;
f.value;

我们的 Function 是一个对象（即一个做某事或表示某事物的东西），我们已经定义并存储在变量 f 中。写着 '.value' 的那段代码表示立即求值此函数。这是一个向对象发送消息的例子。这遵循语法 someObject.someMessage。点必须放在中间。

现在，接下来的这一点有点棘手。在给定的对象中，每条消息都会调用（调用意味着执行）一个特定的方法。不同类型的对象可能拥有同名的方法，因而以不同方式响应同一条消息。再慢慢读一遍，因为这相当重要：

不同类型的对象可能具有同名的方法，因此会以不同的方式响应相同的消息。

有趣之处在于，实际的方法在功能上可能不同，但只要它们实现了具有该名称的方法，它们在你的代码中就可以互换使用。

一个很好的例子是 "value"。SC 中的所有对象都会响应消息 "value"。当你“调用”一个方法时，它总是会“返回”某些内容。当你在 Function 上调用 "value" 方法时，它会求值并返回其最后一行代码的结果。下面的 Function 示例将返回最后一行（5）的结果：

(
f = {
    "Evaluating...".postln;
    2 + 3
};
f.value;
)

方法常常只是返回对象本身。大多数对象以及消息 "value" 就是这种情况。下面的例子演示了这一点。（// 右侧的所有内容都是"注释"，这意味着 SC 会直接忽略它。注释常用于为将来的读者在复杂或令人困惑的代码片段上留下说明）

f = 3;              // 创建一个变量并为其赋一个数字作为值
f.value;            // Post 窗口显示：3，即该数字返回自身
f.value;            // f 没有改变，所以 post 窗口再次显示 3

f = { 3.0.rand };  // 将变量赋值为一个 Function
f.value;            // 3.0.rand 返回一个从 0.0 到 3.0（不含）的随机值。
f.value;            // 另一个随机值
f.value;            // 又一个随机值

通过使用 "value" 方法，函数和其他对象可以在你的代码中互换使用。这是多态的一个例子，多态是所谓面向对象编程（OOP）的强大特性之一。多态意味着，如果不同对象响应相同的消息，它们就可以互换使用。稍后会详细介绍。

函数也可以拥有所谓的参数。这些是在函数被求值时传入函数的值。下面的示例演示了这是如何工作的。执行之前，看看你能否猜出结果会是什么。

(
f = { arg a, b;
    a - b
};
f.value(5, 3);
)

参数在 Function 的开头使用关键字 'arg' 声明。之后你就可以像变量一样引用它们。当你对 Function 调用 value 时，可以按顺序将参数放在括号中传入：someFunc.value(arg1, arg2)。这对任何接受参数的方法都是一样的，而不仅仅是 value。

你可以使用所谓的关键字参数来指定不同的顺序：

(
f = { arg a, b;
    a / b               // '/' 表示除法
};
f.value(10, 2);         // 常规风格
f.value(b: 2, a: 10);   // 关键字风格
)

如果你愿意，可以混合使用常规风格和关键字风格，但常规参数必须放在前面：

(
f = { arg a, b, c, d;
    (a + b) * c - d
};
f.value(2, c:3, b:4, d: 1); // (2 + 4) * 3 - 1
)

（请注意，SC 没有运算符优先级，即数学运算按从左到右的顺序进行，除法和乘法不会先计算。要强制指定顺序，请使用括号。例如 4 + (2* 8) ）

有时为参数设置默认值很有用。可以这样做：

(
f = { arg a, b = 2;
    a + b
};
f.value(2);             // 2 + 2
)

默认值必须是所谓的字面量。字面量基本上是数字、字符串、符号（后面会详细介绍）或它们的集合。如果这不能完全说得通也不必担心，随着我们继续下去会越来越清晰。

还有一种指定参数的方式，就是把它们括在两条竖线之间。（在大多数键盘上竖线符号是 Shift-\ ）下面两个函数是等价的：

(
f = { arg a, b;
    a + b
};
g = { |a, b|
    a + b
};
f.value(2, 2);
g.value(2, 2);
)

为什么会有两种不同的写法？嗯，有些人更喜欢第二种写法，认为它是一种快捷方式。SC 有许多这样的语法快捷方式，可以让编写代码稍微快一些。无论如何，你都会遇到这两种形式，因此需要了解它们。

你也可以在 Function 中使用变量。这些变量需要在 Function 的开头、紧跟参数之后，使用关键字 'var' 来声明。

(
f = { arg a, b;
    var firstResult, finalResult;
    firstResult = a + b;
    finalResult = firstResult * 2;
    finalResult
};
f.value(2, 3);    // this will return (2 + 3) * 2 = 10
)

变量名和参数名可以由字母和数字组成，但必须以小写字母开头，且不能包含空格。

变量只在所谓的其作用域内有效。在 Function 中声明的变量的作用域就是该 Function，即两个花括号之间的区域。一次执行一个：

(
f = {
    var foo;
    foo = 3;
    foo
};
f.value;
foo;            // 这会导致错误，因为 "foo" 只在 f 内有效。
)

你也可以在你一次性执行的任何代码块（即通过全选来执行）的顶部声明变量。在这种情况下，该代码块就是变量的作用域。执行这个代码块（在括号中），然后执行最后一行。

(
var myFunc;
myFunc = { |input| input.postln };
myFunc.value("foo");    // 参数是一个字符串
myFunc.value("bar");
)

myFunc;            // 抛出错误

你可能想知道为什么我们不需要声明像 f 这样的变量，以及为什么即使逐行执行代码（即具有全局作用域）它们也保留其值。字母 a 到 z 被称为解释器变量。它们在启动 SC 时已预先声明，并具有无限制的或“全局”的作用域。这使得它们对于快速测试或示例很有用。你已经遇到过其中一个，即变量“s”，回想一下，它默认指本地主机服务器。

通过参数，我们可以看到多态如何工作的一个示例：

(
f = { arg a;
  a.value + 3        // 对 a 调用 "value"；多态在等着你！
};
)
f.value(3);          // a.value 为 3，因此返回 3 + 3 = 6
g = { 3.0.rand };
f.value(g);          // 这里的参数是一个 Function。a.value 会求值 3.0.rand
f.value(g);          // 再试一次，结果不同

开始看到这可能有用的地方了吗？
