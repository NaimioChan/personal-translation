Dreset

需求速率重置

DUGen : UGen : AbstractFunction : Object

说明

需求 ugen 的重置可以通过消费需求链的 Demand 或 Duty UGen 的重置输入“从外部”控制。Dreset 允许在内部重置链的子集。

类方法

Dreset.new(in, reset: 0.0)

参数：

in

一个需求 UGen，产生被传递的值

reset

一个 demand 或任何其他 UGen。当从非正变为正时，它会重置第一个参数。

实例方法

示例

(
{
    var a, freq;
    a = Dreset(Dseries(0, 2, inf), Drand([0, 0, 0, 1], inf));
    freq = Duty.kr(1/MouseX.kr(1, 40, 1), 0, a) * 30 + 340;
    SinOsc.ar(freq) * 0.1
}.play;
)

// 鼠标按钮按下时重置
(
{
    var a, freq;
    a = Dreset(Dseries(0, 2, inf), MouseButton.kr);
    freq = Duty.kr(1/MouseX.kr(1, 40, 1), 0, a) * 30 + 340;
    SinOsc.ar(freq) * 0.1
}.play;
)

// 音频速率
(
{
    var a, nmax = 90;
    a = { Dreset(Dseries(0, 1, inf), Drand(0 ! nmax ++ 1, inf)) } ! 2;
    Duty.ar(SampleDur.ir, 0, a) * (0.1 / nmax)
}.play;
)
