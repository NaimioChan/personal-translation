Pdrop

跳过（丢弃）模式中的前 n 个事件

FilterPattern : Pattern : AbstractFunction : Object

另请参阅：Pclutch

说明

从模式中跳过初始的（count）个事件。

类方法

Pdrop.new(count, pattern)

从流中丢弃 pattern 的 count 个元素。
