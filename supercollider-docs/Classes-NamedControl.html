NamedControl

对控制的命名引用

Object

另请参见：ControlName、Control

说明

NamedControl 直接将 ControlName 和 Control UGen 便捷地组合在一起。此外，这使其即使存在多个相同的控件也是安全的（见下面的例子）。

有语法快捷方式可从名称生成 NamedControls：

\name.ar(values, lags, spec)
\name.kr(values, lags, fixedLag, spec)
\name.ir(values, lags, spec)
\name.tr(values, lags, spec)

类方法

NamedControl.ar(name, values, lags, spec)

用给定的名称和默认值添加一个新的 AudioControl 实例。如果给出了 lags，则对其应用一个 Lag UGen。

讨论：

\symbol.ar(values, lags, spec) 是同义词。

NamedControl.kr(name, values, lags, fixedLag: false, spec)

添加一个具有给定名称和默认值的新 Control（kr）实例。如果给定了滞后，则对其应用一个 Lag UGen。如果将 fixedLag 设为 true，则创建一个 LagControl（此时滞后无法被调制，但所需的 UGen 更少）。

讨论：

\symbol.kr(values, lags, fixedLag, spec) 是同义词。

NamedControl.ir(name, values, lags, spec)

添加一个新的具有给定名称和默认值的 Control (ir) 实例。如果给定了 lags，则对其应用一个 Lag UGen。

讨论：

\symbol.ir(values, lags, spec) 是同义词。

NamedControl.tr(name, values, lags, spec)

添加一个具有给定名称和默认值的新 TrigControl 实例。如果给出了 lags，则对其应用一个 Lag UGen。

讨论：

\symbol.tr(values, lags, spec) 是同义词。

NamedControl.new(name, values, rate, lags, fixedLag: false, spec)

使用给定的速率、名称和默认值添加一个新实例。如果给出了 lags，则对其应用一个 Lag UGen。如果 fixedLag 设为 true，则创建一个 LagControl（此时 lags 无法被调制，但所需的 UGen 更少）。

示例

// 使用 NamedControl 创建若干个多声道 control：

a = { SinOsc.ar(NamedControl.kr(\freq, [300, 330, 370], [1, 0.3, 0.02])).sum * 0.1 }.play;
a.setn(\freq, [700, 705, 890]);
a.setn(\freq, [0, 2, 5].midiratio * 400);

// 同义：
a = { SinOsc.ar(\freq.kr([300, 330, 370], [1, 0.3, 0.02])).sum * 0.1 }.play;

同名多次使用

相同的控件无法使用不同的默认值和滞后值。可以将它们保存到变量中以避免重复代码。

// 同名变量的多次使用：
a = { SinOsc.ar(\freq.kr(440, 1.0)) + Saw.ar(\freq.kr(440, 1.0) * 0.5) * 0.1 }.play;

a.set(\freq, 1220);
a.set(\freq, 120);

// 使用不同的滞后值：
a = { SinOsc.ar(\freq.kr(440).lag(3.5)) + Saw.ar(\freq.kr(440).lag(0.05) * 0.5) * 0.1 }.play;

a.set(\freq, 1220);
a.set(\freq, 120);

// 将控件保存到变量：
(
a = {
    var freq = \freq.kr(440);
    SinOsc.ar(freq.lag(3.5)) + Saw.ar(freq.lag(0.05) * 0.5) * 0.1;
}.play;
)

a.set(\freq, 1220);
a.set(\freq, 120);

与直接使用 Controls 的对比

在使用函数将 UGen 组合为更复杂的 SynthDef 时，可能无法知道哪些 ControlNames 已被其他对象占用。NamedControl 允许复用已有的控制名。

// 比较这个：
(
a = {
    var x, y;
    x = NamedControl.kr(\freq, 440).lag(3.5);
    y = NamedControl.kr(\freq, 440).lag(1);
    SinOsc.ar([x, y] * [2, 1.2]) * 0.1
}.play;
)

a.set(\freq, 1220);
a.set(\freq, 120);

// 到此：
(
a = {
    var x, y;
    x = Control.names([\freq]).kr(440).lag(3.5);
    y = Control.names([\freq]).kr(440).lag(1); // 设置时会挂起
    SinOsc.ar([x, y] * [2, 1.2]) * 0.1
}.play;
)

a.set(\freq, 1220);
a.set(\freq, 120);

使用带函数的字典来构建 SynthDef

这是一个使用包含函数的字典的基本示例，这些函数可以组合起来构建 SynthDef。

(
q = ();
q.makeEnv = { |q, env, doneAction = 0| EnvGen.kr(env, NamedControl.kr(\gate, 1), doneAction: doneAction) };
q.chooseNoise = { [{ PinkNoise.ar }, { WhiteNoise.ar }, { LFNoise2.ar(Rand(100, 1000)) }].choose.value };
q.filterInput = { |q, in| [
    { BPF.ar(in * 15, NamedControl.kr(\freq, 800), 0.2) },
    { RHPF.ar(in, NamedControl.kr(\freq, 800, 0.2), 0.2) }
    ].choose.value
};
)

// 测试包络：
a = { SinOsc.ar(440) * q.makeEnv(Env.asr, 2) * 0.1 }.play;
a.set(\gate, -3); // 3 秒内释放

// 单声道：
a = { q.chooseNoise * q.makeEnv(Env.asr, 2) }.play;
a.set(\gate, -3); // 3 秒内释放

a = { q.filterInput(q.chooseNoise) * q.makeEnv(Env.asr, 2) }.play;
a.set(\freq, 1000); // 设置滤波器频率
a.set(\gate, -3); // 3 秒内释放

(
a = {
    var channels = Array.fill(8, {
        q.filterInput(q.chooseNoise) * q.makeEnv(Env.asr, 2)
    });
    Splay.ar(channels);

}.play;
)
a.set(\freq, 6000); // 设置滤波器频率
a.set(\gate, -3); // 3 秒内释放
