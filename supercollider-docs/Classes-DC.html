DC

创建一个恒定振幅信号

PureMultiOutUGen : MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：LeakDC

说明

此 UGen 仅输出你给它的初始值。

类方法

DC.ar(in: 0.0)

DC.kr(in: 0.0)

参数：

in

要输出的常量值，不可调制，在初始化时设置

实例方法

示例

// 不会起作用（输出为 0.5*0.0），这就是我们需要 DC UGen 的原因！
{ 0.5 }.play

// 恒为零
{ DC.ar(0.0) }.play;


// 直流偏移；开始和结束时会有咔嗒声
{ DC.ar(0.5) + SinOsc.ar(440, 0, 0.1) }.play;


// 测试 - 注意在 LeakDC 适应并抑制偏移之前的瞬态
{ LeakDC.ar(DC.ar(0.5)) }.play;


// 显示示波器
