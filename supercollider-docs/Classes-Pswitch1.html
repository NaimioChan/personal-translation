Pswitch1

根据索引模式将值嵌入列表

Pswitch : Pattern : AbstractFunction : Object

另请参阅：Pswitch

类方法

Pswitch1.new(list, which: 0)

来自父类：Pswitch

Pswitch1 通过一个索引流（which）从 list 中选择元素并将它们嵌入流中。如果元素本身就是一个模式，则它为每个索引只嵌入该模式的一个值，从而在列表中的所有模式之间切换。

(
var a, b;
a = Pseq([1, 2, 3], inf);
b = Pseq([65, 76], inf);
c = Pswitch1([a, b, 800], Pseq([2, 2, 0, 1], inf));
x = c.asStream;
24.do({ x.next.postln });
)

        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain, 0.2), doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env))
    }).add;
)

b = Pseq([0, 0, 0, 4, 0]+64, inf);
