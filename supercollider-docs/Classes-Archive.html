Archive

将对象存储到文件

LibraryBase : MultiLevelIdentityDictionary : Collection : Object

另请参见：Library、Object、LibraryBase

说明

归档可以将任意对象写入磁盘，并再次从文件中读取。因此可以恢复复杂的对象结构。将对象以编译字符串的形式写入文件通常更具可读性，但无法反映对象的内部结构。

只有一个全局实例：Archive.global，它会自动初始化。

类方法

Archive.global

Archive.global = obj

设置或获取全局归档实例

Archive.archiveDir

Archive.archiveDir = value

设置或获取归档文件写入的目录。默认值：Platform.userAppSupportDir。

Archive.write(filename)

立即写入全局归档。此操作在 SuperCollider 退出时自动调用。默认文件名为“/archive.sctxar”

Archive.read(filename)

立即读取全局归档。当 SuperCollider 重新编译或启动时会自动调用此操作。默认文件名为 "/archive.sctxar"

实例方法

示例

// 为各种对象创建一个存储位置：
q = (); // Event

q[\a_long_array] = Array.rand(128, 0.0, 1.0);
q[\pi_squared] = pi * pi;
q[\favourite_sound] = { { SinOsc.ar([300, 330]).sum * LFPulse.kr(2 + [0, 0.01]) * 0.1 }.play };
q[\same_long_array] = q[\a_long_array]; // 同一个对象可能出现多次

Archive.global.put(\myData, q);


Archive.global.at(\myData).postcs;

// 重新编译后：
s.boot;

q = Archive.global.at(\myData);
q.postcs;
q[\favourite_sound].value;
