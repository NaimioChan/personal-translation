File

用于读写文件的类

UnixFILE : IOStream : Stream : AbstractFunction : Object

参见：FileReader

说明

用于读写文件的类。不是声音文件。

类方法

File.new(pathName, mode)

创建一个 File 实例并打开该文件。如果打开失败，isOpen 将返回 false。

参数：

pathName

一个包含要打开文件的路径名的 String。

mode

一个 String，指示以下模式之一：

"r"

打开文件以供读取。文件必须存在。

"w"

创建一个用于写入的空文件。如果同名文件已存在，其内容将被擦除，该文件将被视为新的空文件。

"a"

追加到文件。写入操作在文件末尾追加数据。如果文件不存在则创建该文件。

"rb"、"wb"、"ab"

同上，但数据为二进制

"r+"

打开一个文件用于更新，既可读取也可写入。文件必须存在。

"w+"

创建一个用于读写的空文件。如果同名文件已存在，则其内容会被擦除，该文件将作为新的空文件处理。

"a+"

以读取和追加方式打开文件。所有写入操作都在文件末尾执行，从而保护先前的内容不被覆盖。可以使用 seek 方法将内部指针重新定位到文件中任意位置进行读取，但写入操作会将其移回文件末尾。如果文件不存在，则创建该文件。

"rb+"、"wb+"、"ab+"

同上，但数据为二进制

File.open(pathName, mode)

与 *new 相同，但名称更直观。

File.getcwd

POSIX 标准的 'get current working directory'。

// 示例；
File.getcwd;

File.use(pathName, mode, function)

打开文件，以该文件为参数求值函数，然后再次关闭文件。如果处理失败，则关闭文件并抛出错误。

File.readAllString(pathName)

打开给定路径的文件，调用 -readAllString，并返回字符串。无论过程成功还是失败，文件始终会被关闭。

// 写入文件
File.use("~/test.txt".standardizePath, "w", { |f| f.write("The green fox fell into the blue lake") });

// 再读一遍
File.readAllString("~/test.txt".standardizePath);

File.readAllSignal(pathName)

打开给定路径的文件，调用 -readAllSignal，并返回信号。无论过程成功还是失败，文件始终会被关闭。

File.readAllStringHTML(pathName)

打开给定路径的文件，调用 -readAllStringHTML，并返回字符串。无论过程成功还是失败，文件都会始终被关闭。

File.readAllStringRTF(pathName)

打开给定路径的文件，调用 -readAllStringRTF，并返回字符串。无论过程成功还是失败，文件都始终会被关闭。

文件系统工具

File.exists(pathName)

回答该路径下是否存在文件。

注意： 某些文件系统（如 macOS 使用的文件系统）不区分大小写。在此类系统上，即使文件实际名为 "Foo"，此方法对 "fOo" 也会返回 true。有关解决方法，请参见下方的 *existsCaseSensitive。

返回值：

一个 Boolean

File.existsCaseSensitive(pathName)

与 *exists 类似，但在不区分大小写的文件系统上确保最后一个路径组件的大小写敏感性。在区分大小写的系统上，它会回退到使用 exists。

注意： 这比普通的 exists 方法慢，因此只在确实需要时才使用它。

File.systemIsCaseSensitive

返回文件系统是否区分大小写。

File.mkdir(pathName)

在路径处创建目录，包括任何缺失的父目录。

返回值：

一个 Boolean，如下所示：

  • true -- 已在 path 处创建新目录。
  • false —— 在 path 处已存在一个目录；未创建新目录。

File.delete(pathName)

删除该路径下的文件。仅用于正当用途，切勿用于恶意目的。

返回值：

一个 Boolean，如下所示：

  • true -- 你可以假定该路径已不存在。（要么它曾存在并被删除，要么它本就不存在且仍然不存在。）
  • false —— 文件无法被删除（可能是权限错误）。你的代码应假定该路径仍然存在。

File.deleteAll(pathName)

删除该路径下的文件及所有子项。仅用于正当用途，切勿用于恶意目的。

返回值：

一个 Boolean，如下所示：

  • true -- 至少有一个文件被删除。
  • false -- 未删除任何文件。

如果删除失败，将抛出一个 PrimitiveFailedError 对象。

File.realpath(pathName)

跟随符号链接（以及 macOS 上的别名）和任何父目录引用（如 ".."），并返回真实的绝对路径。

返回值：

一个 String，如果路径不存在则为 nil。

File.copy(pathNameFrom, pathNameTo)

复制文件、符号链接或目录。如果 pathNameTo 已存在，此方法将失败。

符号链接按符号链接复制（重新创建）。

File.type(pathName)

获取文件类型，为 \error, \not_found, \regular, \directory, \symlink, \block, \character, \fifo, \socket, \unknown 之一

返回值：

一个 Symbol

File.fileSize(pathName)

获取文件大小（以字节为单位）。

返回值：

一个 Integer

File.mtime(pathName)

获取自 Epoch 起的最后修改时间（以秒为单位）。

返回值：

一个 Integer

文件系统工具中的错误处理

如果上述文件系统原语之一失败，在大多数情况下会抛出一个 PrimitiveFailedError 对象：

File.mkdir("/usr/oh-no-you-cant");
ERROR: Primitive '_FileMkDir' failed.
caught exception 'boost::filesystem::create_directory: Permission denied: "/usr/oh-no-you-cant"' in primitive in method Meta_File:mkdir

方法 Function: -try 和 Function: -protect 可以检测并处理这些错误。详见 Understanding errors。

目前，File: *copy、File: *fileSize、File: *mkdir、File: *mtime 和 File: *type 在失败时会抛出错误。（File: *delete 不会抛出错误，而是返回一个 Boolean。）

实例方法

.open(pathName, mode)

打开文件。文件在创建时会自动打开，因此仅当你要反复关闭和打开同一个文件对象时才需要调用此方法。

注意： 使用标准文件对话框保存文件时，可以选择“隐藏扩展名”并将其保存为 RTF。打开该文件时，必须指定真实的文件名："filename.rtf"，即使在文件加载对话框或 Finder 中看不到该扩展名。

.close

关闭文件。

.readAllString

将整个文件读取为 String。

.readAllStringHTML

将整个文件作为 String 读取，并去除 HTML 标签。

.readAllStringRTF

将整个文件读取为 String，并去除 RTF 格式。

.readAllSignal

将整个文件读取为一个 Signal，其中每四个字节的数据块被解释为一个 32 位浮点采样。

.seek(offset: 0, origin: 0)

将读/写指针移动到文件中的给定位置，其中 offset 是以字节为单位给出的位置，origin 是 offset 的参照点：

0

偏移量从文件开头算起

1

offset 相对于文件中的当前位置

2

偏移量从文件末尾算起

.pos

.pos = toPos

设置或返回文件中的当前位置（以字节为单位）。当用作设置器时，此方法是 seek(0, value) 的快捷方式。因此设置 pos 会将当前文件位置从文件开头移动到给定位置。该值会被裁剪，使其位于 0（含）与文件长度（不含）之间。

.length

返回当前文件大小（以字节为单位）。

示例

// 向文件写入一些字符串：
(
var f, g;
f = File("~/test.txt".standardizePath, "w");
f.write("Does this work?\n is this thing on ?\n");
f.close;
)

// 再读一次：
(
g = File("~/test.txt".standardizePath, "r");
g.readAllString.postln;
g.close;
)

// 用 File.use 尝试上面的操作：

File.use("~/test.txt".standardizePath, "w", { |f| f.write("Doesn't this work?\n is this thing really on ?\n") });
File.use("~/test.txt".standardizePath, "r", { |f| f.readAllString.postln });


// 更多文件写入/读取示例：
(
var h, k;
h = File("~/test.dat".standardizePath, "wb");
h.inspect;
h.write(FloatArray[1.1, 2.2, 3.3, pi, 3.sqrt]);
h.close;

k = File("~/test.dat".standardizePath, "rb");
(k.length div: 4).do({ k.getFloat.postln });
k.close;
)


(
var f, g;
f = File("~/test.txt".standardizePath, "w");
100.do({ f.putChar([$a, $b, $c, $d, $e, $\n].choose) });
f.close;

g = File("~/test.txt".standardizePath, "r");
g.readAllString.postln;
g.close;

g = File("~/test.txt".standardizePath, "r");
g.getLine(1024).postln;
"*".postln;
g.getLine(1024).postln;
"**".postln;
g.getLine(1024).postln;
"***".postln;
g.getLine(1024).postln;
"****".postln;
g.close;
)

(
// var f, g;
f = File("~/test.dat".standardizePath, "wb");
f.inspect;
100.do({ f.putFloat(1.0.rand) });

f.inspect;
f.close;

g = File("~/test.dat".standardizePath, "rb");
100.do({
    g.getFloat.postln;
});
g.inspect;
g.close;
)

(
// var f, g;
f = File("~/test.dat".standardizePath, "r");
f.inspect;
f.close;
)
