PV_ConformalMap

复平面起音。

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

另请参阅：FFT、IFFT

说明

应用共形映射

z → (z - a) / (1 - za*)

到相位声码器频段 z，其值由 UGen 的 real 和 imag 输入给出。

对复平面进行变换，使输出充满相位声码器伪影，但可能在音乐上很有趣。通常保持

|a| < 1

但你当然可以尝试更大的值来让它变得非常嘈杂。

a = 0

应基本原样返回输入。

参见 http://mathworld.wolfram.com/ConformalMapping.html。

类方法

PV_ConformalMap.new(buffer, areal: 0.0, aimag: 0.0)

参数：

buffer

FFT 缓冲区。

areal

a 的实部。

aimag

a 的虚部。

实例方法

示例

// 探索该效果

(
SynthDef("conformer2", { |out|
    var in, chain, sound;
    in = Mix.ar(LFSaw.ar(SinOsc.kr(Array.rand(3, 0.1, 0.5), 0, 10, [1, 1.1, 1.5, 1.78, 2.45, 6.7]*220), 0, 0.3));
    chain = FFT(LocalBuf(2048), in);
    chain = PV_ConformalMap(chain, MouseX.kr(0.01, 2.0, 'exponential'), MouseY.kr(0.01, 10.0, 'exponential'));
    sound = IFFT(chain);

    Out.ar(out, Pan2.ar(CombN.ar(sound, 0.1, 0.1, 10, 0.5, sound), 0, 0.3));
}).add;
)

a = Synth("conformer2")
a.free

// 声音输入：使用耳机以防止反馈
(
SynthDef("conformer1", { |out|
    var in, chain;
    in = SoundIn.ar(0, 0.5);
    chain = FFT(LocalBuf(1024), in);
    chain = PV_ConformalMap(chain, MouseX.kr(-1.0, 1.0), MouseY.kr(-1.0, 1.0));
    Out.ar(out, Pan2.ar(IFFT(chain), 0));
}).add;
)

a = Synth("conformer1")
a.free
