LFNoise0

阶跃噪声

UGen : AbstractFunction : Object

另请参见：LFClipNoise、LFDClipNoise、LFDNoise0、LFDNoise1、LFDNoise3、LFNoise1、LFNoise2

子类：LFClipNoise、LFDClipNoise、LFDNoise0、LFDNoise1、

说明

以采样率除以 freq 参数后最接近的整数商所给定的速率生成随机值。

类方法

LFNoise0.ar(freq: 500.0, mul: 1.0, add: 0.0)

LFNoise0.kr(freq: 500.0, mul: 1.0, add: 0.0)

参数：

freq

生成随机值的近似速率。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

{ LFNoise0.ar(1000, 0.25) }.play;

// 调制频率

{ LFNoise0.ar(XLine.kr(1000, 10000, 10), 0.25) }.play;

// 作为频率调制器
(
{ SinOsc.ar(
        LFNoise0.ar(4, 400, 450),
        0, 0.2
    )
}.play;
)

// freq 是起始点的速率
{ var freq = 1000; [LFNoise0.ar(freq), Impulse.ar(freq)] }.plot
