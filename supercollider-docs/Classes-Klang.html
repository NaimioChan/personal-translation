Klang

正弦振荡器组

UGen : AbstractFunction : Object

另请参阅：Klank、DynKlang

说明

Klang 是一组固定频率的正弦振荡器。Klang 比创建单独的振荡器更高效，但灵活性较低。

类方法

Klang.ar(specificationsArrayRef, freqscale: 1.0, freqoffset: 0.0)

参数：

specificationsArrayRef

一个指向由三个 Array 组成的 Array 的 Ref：

frequencies:

振荡器频率的数组。

amplitudes:

一个振荡器振幅的数组，或 nil。如果为 nil，则振幅默认为 1.0。

phases:

初始相位数组，或 nil。如果为 nil，则相位默认为 0.0。

freqscale

在初始化时与所有频率相乘的比例因子。

freqoffset

在初始化时添加到所有频率的偏移量。

讨论：

specificationsArrayRef 中的参数在启动后无法更改。如需可调制但效率较低的版本，请参见 DynKlang。

实例方法

示例

play({ Klang.ar(`[[800, 1000, 1200], [0.3, 0.3, 0.3], [pi, pi, pi]], 1, 0) * 0.4 });

play({ Klang.ar(`[[800, 1000, 1200], nil, nil], 1, 0) * 0.25 });

play({ Klang.ar(`[Array.rand(12, 600.0, 1000.0), nil, nil], 1, 0) * 0.05 });



(
{
loop({
    play({
        Pan2.ar(Klang.ar(`[Array.rand(12, 200.0, 2000.0), nil, nil], 1, 0), 1.0.rand)
             * EnvGen.kr(Env.sine(4), 1, 0.02, doneAction: Done.freeSelf);
    });
    2.wait;
})
}.fork;
)

// 多声道扩展：

(
{
loop({
    play({
        var nPartials = 12, nChans = 5, n = nPartials * nChans;
        Splay.ar(Klang.ar(`[{ { rrand(200.0, 2000.0) } ! nPartials } ! nChans, nil, nil], 1, 0))
             * EnvGen.kr(Env.sine(4), 1, 0.02, doneAction: Done.freeSelf);
    });
    2.wait;
})
}.fork;
)
