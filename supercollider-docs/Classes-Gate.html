Gate

门控或保持。

Latch : UGen : AbstractFunction : Object

另请参阅：Latch

说明

当 gate 为正时允许输入信号值通过，否则保持最后一个值。

类方法

Gate.ar(in: 0.0, trig: 0.0)

来自父类：Latch

Gate.kr(in: 0.0, trig: 0.0)

来自父类：Latch

参数：

in

输入信号。

trig

Gate - 可以是任何信号。当其为非正时，输出保持固定。

实例方法

示例

s.boot;
// 使用控制速率，以免直流信号冲击你的音箱
{ Gate.kr(WhiteNoise.kr(1, 0), LFPulse.kr(1.333, 0.5)) }.scope(zoom: 20);
