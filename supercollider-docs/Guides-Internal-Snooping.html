内部窥探（内省）

探索 SuperCollider

你可以检查类库的许多内部结构以及其他数据结构。这对于研究和调试目的很有用。

注意： 此处提到的键盘快捷键仅适用于标准 SuperCollider IDE。

类定义、实现与引用

查找实现

选择任意方法名（例如 play），然后选择菜单项 Language>Look up Implementation，会打开一个窗口，显示该方法的所有实现及其参数。选择其中一个类和方法（例如 Sample:play）并按回车键，会打开该类定义中该方法的位置。注意，这里只显示实现，不表示继承关系。

（参见 Keyboard Shortcuts）

查找参考文献

选择任意文本（例如 Window 或 asStream）后，选择菜单项 Language>Look up References 将打开一个窗口，显示所选文本的所有引用，即它在类库中被使用的每一处。注意，这不会找到以特殊字节码（如 'value'）编译的方法调用。

（参见 Keyboard Shortcuts）

图形化类浏览器

SC 有一个图形化的类浏览器，会显示所有方法、参数、子类、实例变量和类变量。使用浏览器的按钮，你可以轻松导航到该类的父类、子类、类源代码、方法源代码、帮助文件（如果有）、检查引用或方法实现。

SequenceableCollection.browse;

探查类

// 打印为此类定义的所有实例方法
Collection.dumpInterface;

// 打印为此类定义的所有类方法
Collection.class.dumpInterface;



// 打印此类的实例响应的所有实例方法
Collection.methods.collect(_.name);

// 输出该类响应的所有类方法
// 包括继承的方法
Collection.class.methods.collect(_.name);

// 打印该类响应的所有实例方法和类方法
// 包括继承的方法
Collection.dumpFullInterface;

// 打印此类别及其超类别的实例方法，按字母顺序排列
// 还显示该方法是从哪个类别继承的
// 不包括 Object 或 Class 方法
// 对于类别方法，请使用 Meta_Collection.dumpMethodList
Collection.dumpMethodList;

// 转储该类的所有子类
Collection.dumpClassSubtree;

// 按字母顺序转储所有子类
Collection.dumpSubclassList;

// 转储此类的所有实例变量名
Server.instVarNames.dump;

// 转储此类的所有类变量名
Server.classVarNames.dump;

// 定义此类的文件的路径
// 注意，其他文件中可能还有此类的扩展
Server.filenameSymbol.postln;

(
// 打印所有名称以 'F' 开头的类
Class.allClasses.do { | class |
    if (class.name.asString.beginsWith("F")) {
        class.name.postln
    }
}
)

(
// 查找并打印系统中定义的所有类变量名
Class.allClasses.do { | class |
    if (class.classVarNames.notNil) {
        // classVarNames 是一个 Symbol 数组
        class.classVarNames.do { | varname |
            (class.name.asString ++ " " ++ varname.asString).postln
        }
    }
}
)

(
// 查找并打印所有包含 "ascii" 的方法
Class.allClasses.do { | class |
       class.methods.do { | sel |
               if(sel.name.asString.find("ascii").notNil) {
                    (class.name.asString + "-" + sel.name).postln
            }
    }
}
)

探查方法

// 该类是否实现了此方法？
Collection.findMethod('select');
// -> Collection:select

// 这个类不会
Array.findMethod('select');
// -> nil

// 但超类可能实现了它，所以
// 沿类树向上检查
Array.findRespondingMethodFor('select');
// -> Collection:select


// 查找一个方法对象，并输出其参数名和
// 局部变量名
Collection.findMethod('select').dump;
Collection.findMethod('select').argNames.dump;
Collection.findMethod('select').varNames.dump;
// -> nil // 没有任何 varNames


// 转储其代码。主要用于调试编译器。
Collection.findMethod('select').dumpByteCodes;

// 上述内容的较短版本
Collection.dumpByteCodes('select');


{ 1 + 2 }.dump;              // 这是一个 Function
{ 1 + 2 }.def.dump;          // 转储其 FunctionDef
{ 1 + 2 }.asCompileString;   // 显示其实现
{ 1 + 2 }.def.dumpByteCodes; // 转储其代码。

在 GUI 窗口中窥探

(
// 创建一些窗口来窥探
5.do { | i |
    var w, b;
    w = Window.new("snoop " ++ i.asString,
        Rect.new( 200 + 400.rand, 69 + 300.rand, 172, 90 ));
    w.front;
    b = Button.new( w, Rect.new( 23, 28, 127, 25 ));
    b.states = [["BLAM-O", Color.red]];
}
)

Window.allWindows.dump;    // 列出所有打开的窗口

// 更有帮助一些，输出它们的名称
Window.allWindows.collect { | w | w.name }.postln;

(
// 更改所有已打开窗口的背景颜色
Window.allWindows.do { | window |
    window.view.background = Color.new(0.5 + 0.5.rand, 0.5 + 0.5.rand, 0.5 + 0.5.rand);
}
)

Window.closeAll; // 关闭所有窗口

监视服务器

关于服务器相关探查的大量信息可在 Server 帮助文件的“Information and debugging”部分找到。

一些示例

s.boot;

f = { PinkNoise.ar(0.1) * SinOsc.ar }; // 一个函数
x = f.play;

// 查看服务器上的所有节点
s.queryAllNodes;

// 解析后的内容
s.dumpOSC(1);
x.free;
x = f.play;

// 十六进制内容
// 状态消息未被过滤
s.dumpOSC(2);
x.free;
x = f.play;

// 关闭
s.dumpOSC(0);

窥探解释器

在解释器中求值文本时，变量 'this' 始终指向解释器。

// 显示所有解释器变量 a-z 的值
this.dump;

// 将所有变量 a-z 设为 nil
this.clearAll;


// 将一些文本编译为 Function
g = this.compile("(1 + 2).postln");
g.postln;   // g 是一个 Function
g.value;    // 求值 g

// 解释一些文本
this.interpret("(1 + 2).postln");

// 解释一些文本并打印结果
this.interpretPrint("1 + 2");
