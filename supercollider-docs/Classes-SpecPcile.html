SpecPcile

查找 FFT 幅度谱的百分位数

UGen : AbstractFunction : Object

参见：SpecCentroid， SpecFlatness

说明

给定一个 FFT 链，这会计算频谱的累积分布，并输出对应于所需百分位的频率值。

例如，要找到 90% 的频谱能量位于其下方的频率，你需要的是 90 百分位数，这意味着 fraction 的值应为 0.9。90 百分位数或 95 百分位数常被用作 频谱滚降 的度量。

可选的第三个参数 interpolate（ir）指定是否应使用插值来尝试使百分位频率估计更准确，代价是略微更高的 CPU 使用率。将其设为 1 以启用。

可选的第四个参数是 binout（ir），指定是输出 bin 编号而不是频率（默认为 0，设为 1 以启用）。如果启用了 interpolate，则对 bin 编号执行线性插值。

类方法

SpecPcile.kr(buffer, fraction: 0.5, interpolate: 0, binout: 0)

参数：

buffer

一个 FFT 链。

fraction

interpolate

binout

实例方法

示例

// 带滤波白噪声的简单演示，并尝试推断截止频率。
// 移动鼠标。
(
{
    var in, chain, realcutoff, estcutoff;
    realcutoff = MouseX.kr(0.00001, 22050);
    in = LPF.ar(WhiteNoise.ar, realcutoff);
    chain = FFT(LocalBuf(2048), in);
    estcutoff = Lag.kr(SpecPcile.kr(chain, 0.9), 1);
    realcutoff.poll(Impulse.kr(1), "real cutoff");
    estcutoff.poll(Impulse.kr(1), "estimated cutoff");
    Out.kr(0, estcutoff * 22050.0.reciprocal);
    Out.ar(0, in);
}.scope;
)

// 音频输入 - 尝试不同的元音/长辅音声音，看看会输出什么。
// 具体来说，从 "ssss" 变到 "aaaa" 再变到 "wwww"。
(
{
    var in, chain, perc;
    in = SoundIn.ar([0, 1]).mean;
    chain = FFT(LocalBuf(2048), in);
    // Out.ar(0, in * 0.1);
    perc = SpecPcile.kr(chain, 0.5);
    Out.kr(0, perc * 22050.0.reciprocal);
    Out.ar(1, LPF.ar(WhiteNoise.ar, perc)); // 输出到右声道
}.scope;
)
