RLPF

一个谐振低通滤波器。

Filter : PureUGen : UGen : AbstractFunction : Object

另见：Formlet、RHPF、Resonz、Ringz

子类：RHPF

说明

一个谐振低通滤波器。

类方法

RLPF.ar(in: 0.0, freq: 440.0, rq: 1.0, mul: 1.0, add: 0.0)

RLPF.kr(in: 0.0, freq: 440.0, rq: 1.0, mul: 1.0, add: 0.0)

参数：

in

输入信号。

freq

截止频率，单位为赫兹。警告：由于其实现方式的特性，接近 0 的频率值可能导致故障和/或极其响亮的音频伪影！

rq

Q 的倒数（bandwidth / cutoffFreq）。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

{ RLPF.ar(Saw.ar(200, 0.1), SinOsc.ar(XLine.kr(0.7, 300, 20), 0, 3600, 4000), 0.2) }.play;


(
{ var ctl = RLPF.ar(Saw.ar(5, 0.1), 25, 0.03);
    SinOsc.ar(ctl * 200 + 400) * 0.1;
}.play;
)


(
{ var ctl = RLPF.ar(Saw.ar(5, 0.1), MouseX.kr(2, 200, 1), MouseY.kr(0.01, 1, 1));
    SinOsc.ar(ctl * 200 + 400) * 0.1;
}.play;
)
