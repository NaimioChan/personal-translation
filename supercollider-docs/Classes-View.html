View

GUI 的基本可见元素

说明

View 类是所有视图类的父类。

视图（View）是图形用户界面所组成的基本可见元素。它在屏幕上占据一个矩形空间，在其中绘制自身以显示某些数据或指示用户与程序之间的交互模式。视图接收用户生成的键盘和鼠标事件，并通过控制程序的行为来响应它们。它们还显示有关程序状态及其所操作数据的信息。

类方法

.new

创建 View 的新实例，并使其成为另一个 View 或 Window 的子级，从而有效地将其置于父级的视觉空间中。如果父级上安装了 decorator，它将管理新 View 的位置。

注意： 'parent' 参数可以省略，此时视图在被显示时将作为独立窗口显示。'bounds' 参数可以省略，此时视图将以其首选尺寸在位置 (0,0) 处创建。如果给定了父级并且其上安装了布局，则布局将管理此视图的位置和大小，并且 'bounds' 参数将不起作用。

参数：

parent

新 View 将成为其子级的 View 或 Window 实例。

bounds

一个用于描述新 View 的大小和位置的 Rect 或 Point。如果给定的是一个 Point，则其坐标将表示视图的大小，而视图的位置将为 (0,0)。位置是相对于父视图的左上角来度量的。

.globalKeyDownAction

一个可设置的类变量，包含一个对象（例如 Function 或 FunctionList 的实例）；每当按下按键时，无论键盘焦点如何，都会对该对象求值（即调用其 value 方法）。另请参见 -addAction。

当 action 对象被求值时，会向它传递以下参数：view、char、modifiers、unicode、keycode、key。

.globalKeyUpAction

一个可设置的类变量，包含一个对象（例如 Function 或 FunctionList 的实例），每当按键释放时都会对其进行求值（即调用其 value 方法），与键盘焦点无关。另请参见 -addAction。

当 action 对象被求值时，会向它传递以下参数：view、char、modifiers、unicode、keycode。

.currentDrag

一个类变量，保存当前拖拽的内容。它由 beginDrag 设置。

.currentDragString

一个类变量，以 "compile string" 形式保存当前拖拽的内容。它由 beginDrag 设置。

Visibility

.visible

获取或设置视图是否可见。

使子视图不可见意味着从包含它的布局的角度来看，它不占据任何空间，因此布局会将视图可见时所占据的空间分配给其他视图。当视图再次变为可见时，它会被重新分配相同的空间。

若该视图没有父视图，将其设为 true 的效果与 -front 相同，设为 false 则关闭窗口而不销毁它。

参数：

一个表示视图可见性的 Boolean。

.front

如果该视图没有父视图，则将其作为窗口显示在屏幕上（效果等同于将 -visible 设为 true），否则不起作用。

.minimize

如果该视图是窗口，则将其隐藏（仅保留在 dock/taskbar/etc. 中）。

.unminimize

如果视图是一个窗口，则在最小化后恢复其之前的状态。

.fullScreen

如果该视图是窗口，则全屏显示它。

.endFullScreen

如果视图是窗口，则在以全屏显示后恢复其先前的状态。

.alwaysOnTop

如果视图是窗口，获取或设置它是否应始终位于其他窗口之上。

参数：

boolean

一个 Boolean，表明视图是否应始终保持在最上层。

.focusColor

获取或设置用于在视图中显示键盘焦点的颜色。

参数：

一个 Color。

.palette

获取或设置视图所使用的调色板。

设置调色板时，只有已在调色板上设置的颜色才会生效，其他颜色将继承自父视图的调色板。另请参见 QPalette: -hasColor。

获取调色板时，每次都会返回视图调色板的新副本。因此，如果你想更改视图的调色板，必须将更改后的调色板重新设置到视图上：

    w = Window().front.layout_(HLayout(a = Slider()));
    a.action = { |a|
        a.palette = a.palette.buttonText_(if(a.value > 0.5){ Color.red }{ Color.green });
    };
    a.valueAction = 0.0;

因此，为了动态修改视图的调色板，如果可能的话，保留一个调色板实例来操作会更高效。请注意，这也比使用 Slider: -knobColor 之类的方法更高效，因为它们在内部使用的正是上述方法：

    w = Window().front.layout_(HLayout(a = Slider()));
    p = QPalette();
    a.action = { |a|
        a.palette = p.buttonText_(if(a.value > 0.5){ Color.red }{ Color.green });
    };
    a.valueAction = 0.0;

有关调色板工作原理的详细说明，请参见 QPalette。

参数：

一个 QPalette。

一般操作

.action

获取或设置视图的默认动作，即当用户以基本方式与视图交互时（例如点击 Button、选择 ListView 项等）要评估的对象。

参数：

func

要设置为默认动作的任意对象，通常是 Function 或 FunctionList。求值时，会将视图作为参数传入。

.doAction

求值默认的 action。

.addAction

.removeAction

将 'func' 添加/移除到由 'selector' 所确定变量中的对象列表。如果 'selector' 不是数组或列表，它将变成数组或列表，包含先前的对象和 'func'。

这对于向已有操作函数的现有框架添加功能很有用。

参数：

func

要作为动作添加的任意对象，通常是一个 Function。

selector

一个 Symbol，包含 'func' 将被添加到的动作变量的名称。换言之，'add' 方法将在该变量上被调用；默认是 \action，但该视图的任何其他（合理的）实例变量或类变量也可以工作（例如 \globalKeyDownAction 或 \mouseUpAction 或 \onClose 等）。参见下面的其他动作变量。

按键和鼠标事件处理

鼠标和键盘事件均可传播到父视图。事件处理的工作方式不同：默认情况下，在求值鼠标或键盘动作后，控制权返回到视图的 C++ 实现，如果该处未实现对该特定鼠标或键盘事件的响应，则它传播到父视图。

如果你希望控制事件是否传播，可以从操作中返回 true 或 false。true 表示你已经响应了该事件，传播将停止；false 表示你对事件不感兴趣，事件将继续传播。不过，返回 true 或 false 都会完全绕过视图的 C++ 实现，因此它将没有机会以其标准行为响应事件。请谨慎使用此功能。

鼠标操作

使用下面的方法设置或获取视图响应鼠标交互的动作。视图必须启用后鼠标动作才能生效。

注意： 鼠标操作受事件传播的影响。详情请参阅 按键与鼠标事件处理。

当鼠标动作对象被求值时，会按顺序从以下列表中向其传递一个或多个参数：

  • view - 视图
  • x - x 坐标
  • y - y 坐标
  • modifiers - 一个按位或的整数，表示生效的修饰键。有关这些键的列表，请参阅 Modifier Keys。
  • buttonNumber - 0 表示左键，1 表示右键，2 表示中键，等等。
  • clickCount - 系统点击时间限制内的点击次数。至少为 1。

.mouseDownAction

当在视图上按下鼠标按钮时要评估的对象。

求值时传入以下参数：view, x, y, modifiers, buttonNumber, clickCount。关于这些参数的说明，参见 Mouse actions。

求值的返回值控制事件向父视图的传播。详情参见 Key and mouse event processing。

.mouseUpAction

在视图上按下鼠标按钮后释放时要计算的对象。

求值时传入以下参数：view, x, y, modifiers, buttonNumber。有关参数的说明，请参见 Mouse actions。

求值的返回值控制事件向父视图的传播。详情参见 Key and mouse event processing。

.mouseMoveAction

在视图上按下鼠标按钮后，鼠标指针每次移动时将被求值的对象。

求值时传入以下参数：view, x, y, modifiers。有关参数的说明，请参见 Mouse actions。

求值的返回值控制事件向父视图的传播。详情参见 Key and mouse event processing。

.mouseOverAction

当鼠标指针在未按下鼠标按钮的情况下移动到视图上时要计算的对象。

求值时传入以下参数：view、x、y。有关参数的说明，请参见 鼠标动作。

仅当所属 Window 的 Window: -acceptsMouseOver（或顶层 View 的 -acceptsMouseOver）为 true 时，该对象才会被求值。

求值的返回值控制事件向父视图的传播。详情参见 Key and mouse event processing。

.mouseWheelAction

当鼠标指针位于视图上并使用鼠标滚轮时要被求值的对象。

求值时传递以下参数：view, x, y, modifiers, xDelta, yDelta。有关这些参数的说明，请参见 Mouse actions。

xDelta 和 yDelta 参数分别表示水平和垂直方向上的旋转。其值以度为单位（通常每 15 度发生一个事件），可为正值或负值，具体取决于旋转方向。

求值的返回值控制事件向父视图的传播。详情参见 Key and mouse event processing。

.mouseEnterAction

当鼠标指针进入视图时要评估的对象。

按键动作

当视图拥有键盘焦点时，使用以下方法设置或获取视图响应键盘交互的动作。

注意： 按键动作受事件传播影响。详见 按键与鼠标事件处理。

当键动作对象被求值时，会按该顺序向其传递以下列表中的一个或多个参数：

  • view - 视图。

  • char - 与该键关联的字符（Char），可能不可打印。字符序列（例如 é）会作为两个字符传入，第一个是空白（），第二个是未修改的字符（e）。这也会因键盘所设置的国家/地区而异。

    注意： 仅传递具有 ASCII 码的字符。非 ASCII 按键（Ctrl/Alt/Cmd/Shift 修饰键、方向键和其他控制序列）将传递 ASCII 码为 0 的 Char。（Ctrl 字符确实有 ASCII 码，并作为 Char 传递。Ctrl 键本身也会触发按键动作，但 ASCII 码为 0。）一个有用的测试是 Char: -isPrint。

  • modifiers - 一个整数按位或的结果，表示当前生效的修饰键。你可以使用 C 按位与运算符检查各个标志设置。有关这些标志的列表，请参见 Modifier Keys。
  • unicode - 与传入的 'char' 关联的整数 unicode 编号。

  • keycode - 硬件相关的键码，用于指示物理按键。该值因机器而异，但可用于利用计算机键盘构建音乐界面。

    警告： Function 键修饰符与另一个键组合时可能会改变后者的键码。

  • key - 一个整数，表示一个键，对应 Qt C++ API 的 “Key” 枚举。比较此值是检查按下了哪个键的最可靠方式。有关可能值的列表，请参见：http://qt-project.org/doc/qt-4.8/qt.html#Key-enum。

.keyDownAction

按键时被求值的对象。

求值时传递以下参数：view, char, modifiers, unicode, keycode, key。有关参数的说明，请参阅按键操作。

求值的返回值控制事件向父视图的传播。详情参见 Key and mouse event processing。

如果未设置 keyDownAction，则会改为调用 -defaultKeyDownAction，其返回值控制事件传播。

// 打开一个新文档，输出传入 keydownAction 函数的参数。
(
Document("test arguments").keyDownAction = { |doc, char, mod, unicode, keycode, key|
    [doc, char, mod, unicode, keycode, key].postln
};
)

求值时传递以下参数：view, char, modifiers, unicode, keycode, key。有关参数的说明，请参阅按键操作。

求值的返回值控制事件向父视图的传播。详情参见 Key and mouse event processing。

若未设置 keyUpAction，则改为调用 -defaultKeyUpAction，其返回值控制事件的传播。

拖放

使用以下方法来定义或覆盖视图处理拖放操作的方式。

.beginDragAction

设置或获取在启动拖放操作时被求值的对象。

在求值时，将传递以下参数：view、x、y。该视图期望返回一个对象，该对象将成为拖放操作的数据主体。返回 nil 将阻止拖放操作开始。

如果此变量为 nil（默认值），则改为调用视图的 -defaultGetDrag 方法。

.canReceiveDragHandler

设置或获取当拖放操作进行期间鼠标指针移动到视图上时所求值的对象。

在求值时，将传入以下参数：view, x, y。该视图期望检查拖放数据，并返回一个布尔值，表明该视图能否使用这些数据。如果返回 true，则数据可以放置到该视图上；否则，拖放事件将不会被该视图处理。

如果此变量为 nil（默认值），则改为调用视图的 -defaultCanReceiveDrag 方法。

.receiveDragHandler

设置或获取在此视图上完成拖放操作时被求值的对象。

求值时，将传递以下参数：view, x, y。预期会以某种方式将 drag&drop data 应用于该视图。

如果此变量为 nil（默认值），则改为调用视图的 -defaultReceiveDrag 方法。

.dragLabel

设置或获取拖放操作期间鼠标指针所显示的文本。预期在处理操作开始时设置，即在 -beginDragAction 或 -defaultGetDrag 中设置。

参数：

包含要显示的文本的 String。

上下文菜单

这些方法用于向 View 添加上下文菜单和快捷键支持。

(
View().layout_(HLayout(
    ~text = StaticText().string_("Right-click me").minWidth_(100)
)).front;

~text.setContextMenuActions(
    MenuAction("Red", { ~text.background = Color.red }),
    MenuAction("Green", { ~text.background = Color.green }),
    MenuAction("Blue", { ~text.background = Color.blue })
)
)

.setContextMenuActions

设置应出现在此视图上下文菜单中的 MenuAction。这会隐式调用 View: -enableContextMenu。

参数：

一个或多个 MenuAction 的列表。当通过右键单击调用此 View 的上下文菜单时，将显示这些操作。此外，这些操作的快捷键将在此 View 的上下文中处于活动状态。调用此方法时不传入任何操作将移除所有上下文菜单。

.enableContextMenu

为此 View 启用上下文菜单支持。如果为 true 且已附加动作，则右键单击会显示上下文菜单。此属性可启用和禁用 View 的上下文菜单支持，而无需移除已附加的动作。

参数：

一个 Boolean

.insertMenuAction

将一个 MenuAction 插入所附操作的列表中。

参数：

action

要添加的 MenuAction。

addBefore

一个 MenuAction 或整数索引值。该动作将被插入到列表中此项的前面。默认情况下，动作被插入到列表末尾。

.removeMenuAction

从附加动作列表中移除一个 MenuAction。

参数：

action

要添加的 MenuAction。

.removeAllMenuActions

从视图中移除所有 MenuAction。

.enableContextMenu

为此 View 启用上下文菜单支持。如果为 true 且已附加动作，则右键单击会显示上下文菜单。此属性可启用和禁用 View 的上下文菜单支持，而无需移除已附加的动作。

参数：

一个 Boolean

Handlers

注意： 较旧的教程可能建议通过子类化 View 来重写这些方法。不要这样做。应使用组合，而非继承。将 View 作为你自定义视图类的一个属性。

以下方法是按键按下和释放事件的默认处理函数。

.defaultKeyDownAction

当按键被按下且 -keyDownAction 为 nil 时调用的方法。子类化它以定义你自己的按键功能。

有关参数说明，参见 Key actions。

返回值控制事件向父视图的传播。详情参见 Key and mouse event processing。

.defaultKeyUpAction

释放按键且 -keyUpAction 为 nil 时调用的方法。子类化它以在按键释放时定义你自己的功能。

有关参数说明，参见 Key actions。

返回值控制事件向父视图的传播。详情参见 Key and mouse event processing。

.keyDown

处理按键事件的响应。首先求值 *globalKeyDownAction。

注意： 此方法直接触发动作并返回，转发动作的返回值。详细说明请参见 Key actions。

有关参数说明，参见 Key actions。

返回值：

一个布尔值，说明事件是否已被处理（分别表示不会或将会传播到父视图），或返回视图，此时让 Qt 视图实现处理该事件。

.keyUp

处理按键释放事件的响应。将 -keyTyped 设为 'char'，求值 *globalKeyUpAction，然后调用 -handleKeyUpBubbling。

注意： 此方法直接触发动作并返回，转发动作的返回值。详细说明请参见 Key actions。

有关参数说明，参见 Key actions。

返回值：

一个布尔值，说明事件是否已被处理（分别表示不会或将会传播到父视图），或返回视图，此时让 Qt 视图实现处理该事件。

.keyModifiersChanged

处理对修饰键按下或释放事件的响应。调用 -handleKeyModifiersChangedBubbling。

注意： 修饰键按下或释放事件也会产生一个普通的按键按下或释放事件，而不会调用 -handleKeyModifiersChangedBubbling，正是对这些事件的处理决定了是否向父级传播。

有关参数说明，参见 Key actions。

.keyTyped

一个实例变量，包含刚刚键入的键（在其释放之后）。

.mouseDown

处理对鼠标按钮按下事件的响应。求值 -mouseDownAction。

关于参数的解释，请参见 Mouse actions。

.mouseUp

处理对鼠标按钮释放事件的响应。对 -mouseDownAction 求值。

关于参数的解释，请参见 Mouse actions。

.mouseMove

处理在视图上按下鼠标按钮后鼠标指针移动的响应。求值 -mouseMoveAction。

关于参数的解释，请参见 Mouse actions。

.mouseOver

处理鼠标指针在视图上移动且未按下鼠标按钮时的响应。会求值 -mouseOverAction。

仅当所属 Window 的 Window: -acceptsMouseOver（或顶层 View 的 -acceptsMouseOver）为 true 时才会调用此方法。

关于参数的解释，请参见 Mouse actions。

.mouseEnter

处理鼠标指针进入视图时的响应。求值 -mouseEnterAction。

.mouseLeave

处理鼠标指针离开视图的响应。执行 -mouseLeaveAction。

返回值：

要设置为 *currentDrag 的对象。如果返回 nil，则拖放操作不会开始。

注意： 尚未实现

.beginDrag

处理拖放操作的启动。求值 -beginDragAction，若前者为 nil 则调用 -defaultGetDrag，然后将返回的对象存入 *currentDrag，并将解释为 "compile string" 的对象存入 *currentDragString。返回 *currentDrag 是否不为 nil。

参数：

鼠标指针当前的水平位置。

y

.canReceiveDrag

处理视图能否接受当前拖放数据的求值。求值 -canReceiveDragHandler，如果前者为 nil，则调用 -defaultCanReceiveDrag，然后转发返回值。

参数：

x

鼠标指针当前的水平位置。

y

鼠标指针当前的垂直位置。

返回值：

一个布尔值，表示当前拖放内容是否可以放置在该视图上。

.receiveDrag

处理拖放操作的结束。求值 -receiveDragHandler，若前者为 nil 则调用 -defaultReceiveDrag，然后将 *currentDrag 和 *currentDragString 设为 nil。

参数：

x

鼠标指针当前的水平位置。

y

鼠标指针当前的垂直位置。
