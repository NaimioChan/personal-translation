HIDUsage

用于从 HID 用途表读取用途信息的辅助类

Object

参见：HID、HIDElement、HIDCollection、Working with HID

说明

HID 功能由 USB HID 标准用法表描述。每个元素和集合都有一个用法页和索引，描述其提供的控制类型。此类允许根据从设备读取的索引查询用法和页的名称。此类主要由其他 HID 类内部使用。

类方法

HIDUsage.getUsageDescription(usagePage, usage)

获取 HID 用法元素或集合的标准用法名称和页面名称。

参数：

usagePage

用法页编号

usage

用法索引

返回值：

包含 pageName 和 usageName 的数组

HIDUsage.hutDirectory

HIDUsage.hutDirectory = value

存储包含 HID 用法表的 yaml 文件的目录。

HIDUsage.readHUTFile(yamlfile)

读取并解析 HID usage 表文件。由 getUsageDescription 调用，以读取 usage 表。

参数：

yamlfile

包含特定用法表的 yaml 文件的文件名，相对于 hutDirectory。

返回值：

一个表示该表的 IdentityDictionary

HIDUsage.getUsageIds(usageName)

从 usageName 中获取 usage id 和 page id。

参数：

usageName

用法名称

返回值：

包含页面 id 和用途 id 的数组

HIDUsage.idsToName(page, usage)

获取 HID 用法元素或集合的标准用法名称和页面名称。

参数：

page

用法页 ID

usage

使用 id

返回值：

用法名称

HIDUsage.usageIDsToName

包含页面 id、用法 id 到用法名称映射的 MultiLevelIdentityDictionary。

HIDUsage.usageNameToIDs

包含 usageNames 到页面 id 和 usage id 映射的 IdentityDictionary。

实例方法

示例

获取用途页为 1 且用途索引为 5 的集合或元素的用途描述

HIDUsage.getUsageDescription(1, 5);
