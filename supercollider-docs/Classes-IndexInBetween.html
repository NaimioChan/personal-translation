IndexInBetween

查找缓冲区中输入信号位于两个值之间的（最低）点

Index : PureUGen : UGen : AbstractFunction : Object

另请参阅：Index、IndexL、SequenceableCollection: -indexInBetween

说明

查找 Buffer 中输入信号位于两个值之间的（最低）位置，并返回索引。索引的小数部分适合用于在缓冲区槽值之间进行线性插值。

例如，如果缓冲区包含 [3, 21, 25, 26] 且输入值为 22，则输出为 1.25，因为值 22 位于索引 1 和索引 2 处存储的值之间，且实际上位于该区间四分之一处。

IndexInBetween 是 IndexL 的补充。

类方法

IndexInBetween.ar(bufnum, in: 0.0, mul: 1.0, add: 0.0)

来自父类：Index

IndexInBetween.kr(bufnum, in: 0.0, mul: 1.0, add: 0.0)

来自父类：Index

参数：

bufnum

缓冲区的索引。

in

输入信号。

实例方法

示例

(
// 自动调音。
{
    var index, in, autotuned, f0, fdiff;
    var scale = ([0, 1, 3, 4, 7, 11, 12] + 70).midicps;
    var buffer = scale.as(LocalBuf);
    in = Pulse.ar(MouseX.kr(scale.minItem, scale.maxItem)) * 0.1;
    f0 = Pitch.kr(in).at(0);
    index = IndexInBetween.kr(buffer, f0);
    fdiff = index.frac * (Index.kr(buffer, index + 1) - Index.kr(buffer, index));
    autotuned = PitchShift.ar(in, 0.1, 1 - (fdiff / f0), 0.01, 0.01);
    RLPF.ar(autotuned, [2000, 5000], 0.3)
}.play;
)
