Magnitude

线性连续统中的可比较值

Object

子类：Association、Char、Date、Number

说明

量值表示沿线性连续统的值，可以相互比较。

类方法

实例方法

<(aMagnitude)

返回值：

一个 Boolean，表示接收者是否小于 aMagnitude。

<=(aMagnitude)

返回值：

一个 Boolean，表示接收者是否小于或等于 aMagnitude。

>(aMagnitude)

返回值：

一个 Boolean，表示接收者是否大于 aMagnitude。

>=(aMagnitude)

返回值：

一个 Boolean，表示接收者是否大于等于 aMagnitude。

.min(aMagnitude)

返回值：

接收者与 aMagnitude 的最小值。

.max(aMagnitude)

返回值：

接收者与 aMagnitude 的最大值。

.clip(lo, hi)

如果接收者小于 minVal 则返回 minVal，否则如果接收者大于 maxVal 则返回 maxVal，否则返回接收者。

.inclusivelyBetween(lo, hi)

返回值：

接收者是否大于或等于 minVal 且小于或等于 maxVal。

.exclusivelyBetween(lo, hi)

返回值：

接收者是否大于 minVal 且小于 maxVal。
