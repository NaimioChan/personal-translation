Warp

用于数值输入映射的形状规范

Object

另请参阅：ControlSpec、Spec

子类：CurveWarp、DbFaderWarp、ExponentialWarp、FaderWarp、

说明

Warp 的子类规定了从输入（一个数字）到输出（另一个数字）的转换。这是一个抽象类——已有的形状有线性、指数、正弦、余弦、分贝、曲线（这类似于包络中的曲线，另请参见 Env）。

Warp 内部由 ControlSpec 创建。通常它们由消息 asWarp 创建，该消息可被符号和数字理解。Warp 拥有一个 Spec，用于指定输入和输出值的特定范围。

// 创建一个新的 warp：
a = \exp.asWarp;
a = -4.asWarp; // 一个曲线扭曲；

实例方法

.map(value)

将一个 0 到 1 之间的值映射并约束到输出域。

.unmap(value)

在输出域中转换为 0 到 1 之间的值。

g = -3.asWarp;
g.map(0.5);
g.unmap(0.9);

// 前向和反向翻译应当完全相同：
g.unmap(g.map(0.5));
