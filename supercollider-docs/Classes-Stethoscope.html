Stethoscope

示波器

参见：ScopeView、FreqScope

说明

Stethoscope 提供一个完整的示波器 GUI。它显示一个窗口，其中包含用于绘制总线的 ScopeView 以及一个用于配置绘制并在各总线之间进行选择的界面。

通过消息 .scope 创建

多个类提供了便捷的 'scope' 方法，用于创建 Stethoscope 来显示其数据。例如参见：Server: -scope、Bus: -scope、Function: -scope。

类方法

.new

创建一个 Stethoscope，可以作为窗口，或放置在给定的父视图上。

参数：

server

一个有效的 Server（本地服务器或内部服务器），或 nil，此时使用 Server.default。

numChannels

一个整数。默认值为 2。

index

偏移索引。一个 Integer。默认为 nil。

bufsize

分析缓冲区的大小。默认值为 4096。另请参见 -bufsize。

zoom

所显示波形的水平放大倍数。默认为 1。另请参见 -xZoom。

rate

\audio 或 \control。默认为 \audio。

view

可选的父视图。默认值为 nil。若为 nil，则会在其自己的 Window 中打开。

bufnum

要分析的 Buffer 的 id 编号。默认值为 nil。如果为 nil，则分配一个大小为 bufSize 的 Buffer。

讨论：示例：

s.boot
{ SinOsc.ar([330, 440], 0, 0.4) }.play;
Stethoscope(s, 2);

.isValidServer

测试 Stethoscope 是否可以在给定服务器上运行（任何本地服务器。参见 Server: -isLocal）。

参数：

一个 Server。

返回值：

一个布尔值。

.ugenScopes

返回正在运行的 ugen 作用域数组。

s.boot
{ [SinOsc.ar.scope, WhiteNoise.ar(0.5).scope]*0.1 }.scope(2);
Stethoscope.ugenScopes; // 返回 ugen 示波器

.tileBounds

一个实用方法，由 UGen: -scope 用于平铺示波器窗口。

返回值：

一个 Rect。

实例方法

Data

.server

示波器所操作的服务器。

.rate

是要操作音频总线还是控制总线。

参数：

两个符号之一：\audio 或 \control。

.index

要示波的 busy 起始索引。

参数：

一个 Integer。

.numChannels

要示波的相邻总线数量（从 -index 开始）。

参数：

一个 Integer。

.bufsize

定义允许的最大 -cycle。

.cycle

注意： 仅在 Qt GUI 中可用

精确的作用域周期，以信号帧为单位。与模拟示波器中称为扫描速度的参数互为倒数。它在示波器运行时可以动态调整。

来自示波信号的数据会累积到缓冲区中，直到达到 cycle 数量的帧，此时缓冲会立即重新开始。视图会反复显示整个缓冲区；如果绘图太慢而无法跟上传入数据的速度，它可能会跳过一个周期，但周期边界相对于信号永远不会发生偏移。

如果你正在对周期信号进行示波，将 cycle 设置为与信号周期匹配，可使波形锁定在原位。

Display

.window

示波器的（父）Window。

.bounds

窗口的位置和大小。位置相对于屏幕左下角。

参数：

一个 Rect，或任何响应 .asRect 方法的对象。小于 264 的宽度将被更改为 264，即最小宽度。

返回值：

一个 Rect。

s.scope.bounds_(Rect(100, 200, 500, 600));
s.scope.bounds_([100, 200, 500, 600]);
s.scope.bounds_(Size(500, 600));
s.scope.bounds_(Rect(0, 0, 500, 600));
s.scope.bounds_(500@600);

.size

设置示波器窗口的宽度和高度。

参数：

一个 Integer（窗口为正方形）。

.toggleSize

在小尺寸和大尺寸之间切换。

.zoom

-xZoom 的同义词。

.xZoom

将显示的波形按给定因子水平放大。

这将 -cycle 设置为 1024 * xZoom.reciprocal。

参数：

一个 Float。

.yZoom

将显示的波形垂直放大到给定的倍数。

参数：

一个 Float。

.style

绘图样式：

  • 0 = 各声道垂直间隔
  • 1 = 声道叠加
  • 2 = 李萨如图形；每一对通道用于二维绘图（作为 x 和 y 坐标的流）。

参数：

上述整数之一。

Operation

.run

启动示波器（如果尚未运行）。

.quit

关闭窗口，并清理所有使用过的 synth 和缓冲区。

Convenience

.setProperties

一次性设置多个属性：-numChannels、-index、-bufsize、-zoom 和 -rate。

示例

一个逐步示例

s.boot;
(
{
    SinOsc.ar([225, 450, 900], 0, 0.2)
    + LPF.ar(
        LFPulse.ar(226 * [1, 2, 5], [0, 0.1, 0.1], 0.2, 0.2),
        MouseX.kr(20, 10000, 1)
        )
}.scope;
)

// server.scope 只会更改显式给出的属性：

s.scope(numChannels: 5);
s.scope(index: 12);
s.scope(zoom: 4);
s.scope(index: 0);

s.scopeWindow.size = 600;
s.scopeWindow.size = 222;

// 限定总线作用域：

a = Bus.audio(s, 4);
{ WhiteNoise.ar(0.2.dup(4)) }.play(s, a);

a.scope;

c = Bus.control(s, 3);
{ WhiteNoise.kr(1.dup(4) * MouseX.kr) }.play(s, c);

c.scope;

// 注意，对控制速率总线进行示波会显示块大小插值（这是由于
// ScopeOut.kr 尚不可用这一事实。）

多通道 Lissajou 图

(
{ 
    var f = { |l,h| SinOsc.kr(0.1, {pi.rand}).range(l, h) } ;
    Pulse.ar({ f.(20, 1000) }!6, { f.(0.0, 1) }!6, { f.(0.0, 1.0) }!6) 
}.play;
)

c = s.scope;
c.numChannels = 6;
c.scopeView.waveColors = [Color.red, Color.red, Color.cyan, Color.cyan, Color.white, Color.white];
c.style = 2;

嵌入使用

你可以传入自己的视图以向其添加听诊器：

w = Window.new("my own scope", Rect(20, 20, 400, 500));
w.view.decorator = FlowLayout(w.view.bounds);
c = Stethoscope.new(s, view: w.view);
w.onClose = { c.free }; // 别忘了这个
w.front;
