SCDocHTMLRenderer

将 SCDoc 标记文本渲染为 HTML

Object

另请参见：SCDoc、Writing Help、SCDoc Syntax、SCDoc Styling

说明

此类是 SCDoc 帮助系统的一部分，负责将解析后的文档树渲染为 HTML 输出。

在正常情况下你不需要直接使用这个类，SCDoc 默认使用这个类来渲染帮助文件。

关于 CSS 样式，请参阅 SCDoc Styling。

类方法

SCDocHTMLRenderer.renderOnStream(stream, doc, root)

将解析后的文档以 HTML 形式渲染到给定的流上。

参数：

stream

一个流，例如一个 File 实例。

doc

一个 SCDocEntry 的实例

root

一个 SCDocNode 的实例

SCDocHTMLRenderer.renderToFile(filename, doc, root)

打开一个文件并将其传递给 *renderOnStream

SCDocHTMLRenderer.htmlForLink(link, escape: true)

为给定的 scdoc 链接创建 html 字符串。

参数：

link

一个 scdoc 链接，例如 "Classes/SinOsc" 之类的文档键、URL，或指向随帮助一同安装的其他文件的链接。

escape

一个布尔值，用于设置是否转义特殊字符。

返回值：

一个 String

内部使用。

返回值：

一个 String，表示 Method 的参数（含默认值）。

CSS 样式

渲染后的 HTML 从 scdoc.css 读取全局样式，但如果存在，还会读取 frontend.css 和 custom.css（按此顺序），以便特定前端和用户能够覆盖 CSS。

因此，若要自定义 CSS，用户可以在其 SCDoc: *helpTargetDir 中，或在任意 HelpSource 目录的根目录下（例如在 YourExtension/HelpSource/custom.css 中）创建一个 custom.css。
