matchItem

测试对象是否满足某个约束

由以下类实现：Object、Collection、Nil、Function

matchItem(item)

matchItem(item) 可以传递给不同的对象，这些对象充当约束。可以设想更多对象来实现 matchItem 以扩展该接口。

另请参阅：Dictionary: -matchAt。

Object-matchItem

测试 item 是否与 object 相同。

a = [1, 2, 3, "wort", "1", [pi, 2pi]];
a.any { |x| x.matchItem(3) }; // true
a.any { |x| x.matchItem(5) }; // false
a.any { |x| x.matchItem("wort") }; // false，因为 "wort" == "wort" 但不完全相同。

Collection-matchItem

测试 item 是否包含在 collection 中。

a = [1, 2, 3, "wort", "1", [pi, 2pi]];
a.any { |x| x.matchItem(pi) }; // true

Nil-matchItem

返回 true（Nil 充当“万能牌”，可替代任何值）。

a = [nil, 1, 2, 3, "wort", "1", [pi, 2pi]];
a.any { |x| x.matchItem(10000.rand) }; // 始终为真

Function-matchItem

通过将 item 传递给一个应返回 Boolean 的函数来测试它。

a = [10, 20, 30, { |item| item.isPrime }];
a.any { |x| x.matchItem(3) }; // true
a.any { |x| x.matchItem(4) }; // false
a.any { |x| x.matchItem(10) }; // true
