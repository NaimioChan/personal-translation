AbstractFunction

一个响应一组表示数学函数的消息的对象

Object

参见：UGen、Pattern、Function、Operators

子类：AbstractOpPlug，BinaryOpFunction，BusPlug，Function，

说明

AbstractFunction 是一个对象，它响应一组表示数学函数的消息。子类重写一个较小的消息集合来响应这些数学函数。

它为那些不直接计算值、而是组合用于计算的结构（惰性求值）的函数提供了一种机制。

Function、Pattern、Stream 和 UGen 是 AbstractFunction 的子类。例如，如果你将两个 UGen 相乘，接收者会返回一个类 BinaryOpUGen 的新实例作为响应，该实例将这两个操作数作为输入。

{ var a, b; a = LFSaw.ar(220); b = LFPulse.ar(1442); [a, b, a * b] }.plot;

关于常见运算符的概述，请参见 Operators，具体示例另请参见 Function、UGen、Pattern 等。要查看哪些类实现了某个特定方法，请在生成的 Methods 概述中查找该方法。

二元消息

以下消息返回一个表示延迟二元运算的对象，即两个对象之间的运算。例如，将两个函数相加会得到一个新函数，调用该函数时，会把两个操作数的求值结果相加。

以下所有消息都会向接收者发送 composeBinaryOp 消息，并将二元消息选择器和第二个操作数作为参数。参见：BinaryOpFunction。

示例：

// 添加两个函数：
x = { |x| x + 1000 } + { |x| x * 100 };
// 求值结果，传入一个参数
x.value(2); // posts 1202

// 任一操作数都可以是另一个对象
// 将一个数字和一个函数相加：
x = 1871 + { |x| x * 12 };
x.value(12);

// 关键字参数会传递给每个操作数：
x = { |t, u| t + 1 } * { |t, u| u - 1 };
x.(t:2, u: 10) // 3 * 9
// 添加两个 UGen
{ SinOsc.ar(440, 0, 0.2) + PinkNoise.ar(0.1); }.play
// 添加两个 Pattern
(Pseq([1, 2, 3, 4]) + Prand([0, 0.1, -0.1], inf)).asStream.nextN(5);
// 添加两个 NodeProxy 代理
Ndef(\x, { SinOsc.ar(440, 0, 0.2) });
Ndef(\y, { PinkNoise.ar(0.1) });
Ndef(\z, Ndef(\x) + Ndef(\y)).play;

函数组合

组合运算符 <> 用于执行函数链式调用（函数组合），其中 f·g = f(g(x))。请注意，像 Pattern 或 UGen 这样的不同子类拥有各自类似于 AbstractFunction 本身的组合方案。

// compose 一个将返回随机长度数组的函数
a = { |n| { 16.rand } ! n } <> { rrand(4, 8) };
a.value;
// 从 a 组合出一个只选择奇数值的函数
b = { |x| x.select(_.odd) } <> a;
b.value;

// 调用参数会传递给第一个（最右侧的）函数：
a = { |n| { 16.rand } ! n } <> { |n| n + 2 };
a.value(3);

注意： 比较运算符 <、<=、> 和 >= 会自动执行函数组合，如上例中的 * 一样。相等比较有两种可能的含义：比较对象此刻的现状，或一个复合运算符，它将在未来对操作数求值并检查这些结果的相等性。两者在不同时刻都需要，并由不同的运算符支持：== 用于立即的相等检查（总是返回布尔结果），或 |==| 用于稍后执行的“惰性”相等运算符。

f = { 2.rand };  // 一个函数

// 急切（立即）相等
// false：函数本身与 '1' 不相同
g = (f == 1);

g.value;  // 仍为假

// 惰性相等
g = (f |==| 1);  // 一个 BinaryOpFunction

g.value;  // true 或 false，取决于 f 的结果
