UnaryOpStream

由一元运算符修改的流

Stream : AbstractFunction : Object

参见：BinaryOpStream、NAryOpStream

说明

UnaryOpStream 是在对 Stream 进行一元数学运算时创建的。它被定义为通过返回对流的 next 值进行数学运算的结果来响应 next。它通过重置该 Stream 来响应 reset。
