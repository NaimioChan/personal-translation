Literals

具有直接语法表示的值

另请参见：Number、Integer、Float、SimpleNumber、String、Array、Symbol

字面量是具有直接语法表示的值。以下各节描述了可以表示的字面量类型。

Numbers

Integers

整数是任意一串数字，前面可选带一个负号：

-13
666
2112
96

它们也可以用带 0x 前缀的十六进制表示，字母可以是大写或小写：

0xa    // 10
-0xd   // -13
0x29A  // 666
0x840  // 2112
0x60   // 96

Floats

浮点数（float），即浮点数字，由一个或多个十进制数字、一个小数点以及一个或多个十进制数字组成。小数点两侧都必须有数字。在 SuperCollider 中，浮点数始终为 64 位，FloatArray 中除外。

浮点数示例：

0.39
98.6
1.0
-0.5

也支持指数记法：

1.2e4
1E-4

关键字 pi 也可以单独使用，或附加到浮点数或整数后以创建浮点常量：

pi
2pi
0.5pi
-0.25pi

关键字 inf 表示无穷大，也被视为 Float 的一个实例。

inf   // 以及更多！
-inf

Radix

数字也可以用 10 以外的基数书写，最高可达 36 进制。基数以 10 进制指定，后跟字母 'r'，再后跟用字符 0-9 和 A-Z（或 a-z）表示 0 到 35 的数字值、以该基数书写的数值。例如，你可以如下书写十六进制数字：

16rF // 15
16ra9 // 169
36rZIGZAG // 2147341480

二进制数可以按如下方式书写：

2r01101011

浮点值也可以以任意进制指定。不过，对于大于 10 的进制，小数点之后只能使用大写字母。这样可消除歧义：如果允许小写字母，36rA.bitNot 可能是一次函数调用，也可能表示 36rA.BITNOT == 10.320080118934。

12r4a.abc // wrong
12r4a.ABC // works
12r4A.ABC // better

以 0x 标记的十六进制数只能表示为整数。

音级

用整数作为音阶度数时，支持通过在后面添加后缀 s 表示升号、b 表示降号来使用变音记号。变音记号用浮点值表示。

2s == 2.1  // 音阶第二级，升号
2b == 1.9  // 音阶第二级，降音
2ss == 2.2 // 音阶二级，重升
2bb == 1.8 // 音级二级，重降

最多四个：

2ssss == 2.4
2bbbb == 1.6

使用负的音阶度数时会反转：

-2s == -1.9
-2b == -2.1
-2ss == -1.8
-2bb == -2.2

变音记号还可以指定最多 499 音分的偏差：

2b50 == 1.95 // 音级二，低五十音分
2s204 == 2.204 // 音阶第二级，偏高 204 音分

Characters

字符前面带有一个美元符号：

$A
$B
$C
$.
$$

与 C 和 Java 一样，反斜杠（'\'）是转义字符。转义有两个主要用途。第一，将不可打印字符插入 String。第二，允许在内容中包含 String 或 Symbol 的分隔符。对于 String，双引号表示 String 字面量的开始和结束。要在字符串中间放入双引号，必须暂停双引号的正常含义（“转义”），如 "He repeated, \"Madam, I'm Adam,\" only this time he had said it backward."。

在所有情况下，作为转义字符的 \ 都不会出现在 String 或 Symbol 中。这是 Windows 文件路径中常见的混淆来源：例如，"C:\Users\Somebody\SuperCollider" 会被转换为 C:UsersSomebodySuperCollider。在 String 或 Symbol 中表示字面反斜杠的方式是使用双反斜杠："C:\\Users\\Somebody\\SuperCollider"。（但请注意，无论平台如何，都最好使用正斜杠来书写文件路径："C:/Users/Somebody/SuperCollider"。

以下是 SuperCollider 中可识别的转义字符。任何其他字符前的反斜杠只会产生该字符。

$\t  // 制表符（水平制表）
$\f  // 换页符
$\v  // 垂直制表符
$\n  // 换行符（换行）
$\r  // return
$\\  // 反斜杠`

符号与字符串

Symbols

符号可以用两种方式书写。一种方法是将内容放在单引号内。符号内可以使用任何可打印字符，但非空白的空白字符（\f, \n, \r, \t, \v）除外。符号内的任何单引号都必须转义（\'）。

'x'
'aiff'
'BigSwiftyAndAssoc'
'nowhere here'
'somewhere there'
'.+o*o+.'
'\'symbol_within_a_symbol\''

第二种表示符号的方式是在单词前加反斜杠。只有当符号由单个单词组成（由字母数字和/或下划线字符组成的序列）时，这种写法才合法。

\x
\aiff
\Big_Swifty_And_Assoc
\not really a symbol  // 非法

Strings

字符串用双引号书写：

"This is a string."

如果两个或多个字符串在词法上相邻，则它们合并为一个更大的字符串：

a = "st" "ri" "ng"
a.size // 6

字符串可以跨越多行。换行字符会成为字符串的一部分：

a = "st
ri
ng
"
a.size // 9

SuperCollider IDE 使用 UTF-8 来解码和显示字符串。有关更多信息，请参阅 String: Character encodings。

字符串字面量最多可包含 8188 个字符（字节）。由于字符串操作，字符串对象可以更大。

// 人为生成一个长字符串
a = String.fill(9000, { "abcdefghijklmnopqrstuvwxyz".choose });

// 用引号将其包裹以使其成为字面量
a = "\"" ++ a ++ "\"";

// 解释字面量
b = a.interpret;

b.size;  // 8188 and NOT 9000

Identifiers

方法名和变量名以小写字母开头，后跟零个或多个字母数字或下划线字符。

var abc, z123, trigger_func;
var 1var; // 不合法
var _hmm; // 不合法
var hmm_; // 虽然这是合法的，但应避免这样做，因为 setter 函数在
          // SuperCollider 通常以下划线结尾。

类名

类名始终以大写字母开头，后跟零个或多个字母数字或下划线字符。

Object
Point
Synth
SinOsc
Pan2
MyClass_LikesUnderscores // legal
MyClass_ // 合法，但应避免

特殊值

类 True、False 和 Nil 的单例实例可以用关键字 true、false 和 nil 表示。

x = true;
y = false;
z = nil;

Arrays

Array 的字面量在编译时创建，书写方式是在数组前加 #，如下所示：

#[1, 2, 'abc', "def", 4]

字面量数组必须按原样使用，且不得在运行时更改。

在字面量数组中，名称被解释为符号。在常规数组中则不是这样，其中名称被解释为变量名：

#[foo, bar]     // 这是合法的；一个符号数组
[foo, bar]      // 仅当 foo 和 bar 已声明为变量时，这才是合法的

数组和其他集合也可以动态创建，这在 Collection 中有说明。使用字面量 Array 比每次需要时动态构建数组更快。

当嵌套字面量数组时，只有最外层的字面量数组需要 '#' 字符。

#[[1, 2, 3], [4, 5, 6]]

字面量数组可用于常量表之类的事物，例如音名：

(
// 构建音符名称表
var table = ();
value {
    var semitones = [0, 2, 4, 5, 7, 9, 11];
    var naturalNoteNames = ["c", "d", "e", "f", "g", "a", "b"];

    (0..9).do {|o|
        naturalNoteNames.do {|c, i|
            var n = (o + 1) * 12 + semitones[i];
            table[(c ++ o).asSymbol] = n;
            table[(c ++ "s"  ++ o).asSymbol] = n + 1;
            table[(c ++ "ss" ++ o).asSymbol] = n + 2;
            table[(c ++ "b"  ++ o).asSymbol] = n - 1;
            table[(c ++ "bb" ++ o).asSymbol] = n - 2;
        };
    };
};

// 将音名转换为 MIDI 键
table.atAll(#[c4, e4, gs4, c5, e5, gs5, c6])
)

编译器限制

如果这些字面量被用作独立对象，那么单个函数中的字面量数量没有理论上的限制。（当然，仍然存在系统内存和处理器的实际限制，因为需要跟踪所有这些对象。）

以下是一类特殊的字面量，称为选择器。

  • 类名
  • 方法名
  • 函数定义（用花括号 { } 括起）

这里有四个选择器：SinOsc、ar、play 以及包含 SinOsc 的整个函数。

{ SinOsc.ar(440, 0, 0.1) }.play;

单个函数最多只能包含 256 个选择器。如果超过此限制，将打印编译器错误：

ERROR: Selector table too big: too many classes, method selectors or function definitions in this function. Simplify the function.

注意： 提交用于交互执行的代码首先会被编译成一个函数。一个非常大的代码块，跨越数千行，如果没有将任务分解为更小的函数，就可能触及这一限制。一般来说，如果代码具有合理的模块化结构，由小型函数处理问题中定义明确的部分，则更易于维护。此错误消息表明，代码对于松散或“扁平”的代码结构而言已经变得过于复杂。

什么算作“在函数内部”？

选择器只计入当前正在编译的函数定义。

{ x.foo };

{ x.bar };

两个函数都恰好包含一个选择器。它们是独立的函数。在一个函数中使用 "foo" 不会影响另一个函数中选择器的数量。

{
    var f = { |n|
        if(n > 1) { n * f.value(n-1) } { 1 }
    };

    f.value(10);
}.value;

外层函数只包含选择器 value。其他选择器——>、*、-——属于内层函数定义，不影响外层函数的选择器数量。

因此，一种可能简便的变通方法是将一大块代码拆分为若干个依次求值的函数：

{
    ... a bunch of code ...
}.value;

{
    ... a bunch of code ...
}.value;

{
    ... a bunch of code ...
}.value;
