1) 在多个客户端下使用 ProxySpace，并具有独立的总线空间

注意： 如果只有一个客户端使用远程服务器，则只有步骤 (a) 和步骤 (d) 相关。此时可以省略 clientID 参数。

开始之前

记得同步你的系统时钟。这可以通过以下方式完成：

在 macOS 中

SystemPreferences>Date&Time：将 "Set Date & Time automatically" 设置为 true。

在 Linux 中

设置 ntp 时钟

本地时间服务器比 Apple 时间服务器更好。如果无法同步时间，可以将服务器延迟设为 nil。但这会破坏模式的功能。

a) 启动（远程）服务器并创建本地模型

s = Server("serverName", NetAddr(hostname, port));
s.options.maxLogins = 16; // 或网络中的最大参与者数量
s.boot; // 你不能直接启动远程服务器实例，但这里会初始化所需的一切
serverName

可以是任意名称

hostname

是一个 IP 地址，或者如果你有名称解析，则是一个网络名称

port

服务器监听的端口。默认是 57110

参见 Server

b) 从每个客户端初始化默认节点并将 notify 设为 true：

s.boot; // 这将初始化树并启动通知

// 如有需要，可以创建服务器窗口：
s.makeWindow;

c) 现在从服务器创建一个 ProxySpace：

p = ProxySpace.push(s);
