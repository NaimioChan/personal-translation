LevelComp

Splay 和 SplayAz 的电平补偿逻辑

Object

另请参阅：Splay、SplayAz、混音与声像时的电平补偿

说明

混音和声像多声道信号通常需要在混音和声像时进行电平补偿。LevelComp 为此提供了一种逻辑，Splay 和 SplayAz UGen 内部使用了该逻辑。通过 Splay/Az 的 levelComp 参数，它会根据输入通道数计算一个应用于输入信号的电平补偿因子。

类方法

LevelComp.new(levelComp, rate, n)

根据 levelComp 参数和待混合的通道数计算缩放因子。

参数：

levelComp

一个标志或数值：

  • true：等功率电平补偿（默认）
  • false：关闭 / 无电平变化，

  • 介于 0.0 和 1.0 之间的浮点数：levelComp 因子的平滑调节：

    • 0.0 为无 -> 因子 1
    • 0.5 为等功率 -> 因子 (1/n).squared
    • 1.0 为等幅 -> 因子 (1/n)

rate

要计算的速率 - \audio 或 \control。

n

被混合和缩放的通道数。

返回值：

用于乘以输出信号的 levelComp 因子。

实例方法

示例

Splay 和 SplayAz 通过 levelComp 参数在内部使用 LevelComp，并从 Splay/Az 获取速率和声道数。

以下是 levelComp 用法变体的概述：

// 默认是等功率补偿：level / (numchans.sqrt)
Splay.ar(ins, spread, level, center); // 默认值为 true
// 为清晰起见显式写出
Splay.ar(ins, spread, level, center, levelComp: true);
// 或者对浮点电平 comp 做等功率处理
Splay.ar(ins, spread, level, center, levelComp: 0.5); //

// 通过等幅压缩获得最大峰值安全度：level / numchans
Splay.ar(ins, spread, level, center, levelComp: 1);
// 或者手动计算：
Splay.ar(ins, spread, level / ins.size, center, levelComp: false);

// 无补偿，仅手动调整电平
Splay.ar(ins, spread, level, center, levelComp: false);
Splay.ar(ins, spread, level, center, levelComp: 0);

// levelComp 以浮点数表示：level / (numchans ** levelComp)，
// 因此 0.0 表示不补偿：level / 1；
//    0.5 表示等功率：level / (numchans.sqrt)
//    1.0 表示等幅度：level / (numchans)
// 可用于例如在等功率和等幅度之间进行调节：
Splay.ar(ins, spread, level, center, levelComp: 0.75);

电平补偿选项的讨论与演示：

我们以等功率补偿开始测试：在不同声道数量下使用 Splay 进行混音/声像处理时，总和后的电平最多会升高多少？

s.meter;
s.scope;

// 在 0.1（-20 dB）电平下合成 2 个测试信号，首先在单独的声道上
(
{ var n = 2, level = 0.1, spread = 1, pan = 0;
    LFPulse.ar({ 100.exprand(2000) } ! n).range(-1, 1) * level
}.play;
)

// 现在使用 Splay 混合/声像这两个信号，level 设为 0.1（-20dB）
(
x = { |spread = 1, level = 0.1, center = 0|
    var n = 2;
    var snd = LFPulse.ar({ 100.exprand(2000) } ! n).range(-1, 1);
    var stereo = Splay.ar(snd, spread, level, center);
    Peak.ar(stereo, Impulse.kr(2)).ampdb.poll(2);
    stereo
}.play;
)

// 当我们设置完整的声像展开，声像居中时：
// 这两个信号是离散的，一个在左一个在右
// 我们看到基于能量的 levelComp 被应用（1/2.sqrt）.ampdb = -3
x.set(\spread, 1, \center, 0); // -20 - 3 = -23dB

// 无扩散，声像居中：
// 每个信号在移向中心时会衰减 3dB（来自声像函数）
// 两个信号在每个声道上混合，因此我们得到 -20 dB
x.set(\spread, 0, \center, 0); //  -20dB

// 无扩散，完全右声道声像：
// 信号完全混合在右声道（+6 dB）
x.set(\spread, 0, \center, 1); // -23 + 6 = -17db

用 20 个声道并采用等功率补偿（即 levelComp 为 true 时得到的效果）尝试同样的示例，可以看到合成后的总和电平要高得多：

(
x = { |spread = 1, level = 0.1, center = 0|
    var n = 20;
    var snd = Splay.ar(LFPulse.ar({ 100.exprand(2000) } ! n).range(-1, 1),
        spread, level, center);
    Peak.ar(snd, 0.01, 1).ampdb.poll(1);
    snd
}.play;
)

// 在完全展开时，电平 -20，声像居中：
// 峰值在 -11 db 处更高
x.set(\spread, 1, \center, 0);
// 没有扩散，即全部声像居中，略微提高到 -10
x.set(\spread, 0, \center, 0);
// 最坏情况：无扩展，声像完全左：-8db
x.set(\spread, 0, \center, -1); // -8

最后，以下是 20、200 和 2000 通道在等功率情况下的理论最坏情况：响 13、23 和 33 dB！

// 绘制 0.01 秒，并轮询以获得精确的 amp 读数
{ Splay.ar(DC.ar(1!20), 0, 1, 0.999).ampdb.poll }.plot;
{ Splay.ar(DC.ar(1!200), 0, 1, 0.999).ampdb.poll }.plot; // 200: 23 db louder
{ Splay.ar(DC.ar(1!2000), 0, 1, 0.999).ampdb.poll }.plot; // 2000: 33 db louder

因此，为了获得最大的峰值安全性，请使用 levelComp: 1（或等效地，设置 levelComp: false，并显式将 level 设为 1/n，即除以通道数来进行幅度补偿）。

这样电平就可预期地保持不变，与要混合的通道数无关。

{ n = 2; Splay.ar(DC.ar(1!n), 1, 1, 0, levelComp: 1).ampdb.poll }.plot; // 两者均为 -6 db
{ n = 2; Splay.ar(DC.ar(1!n), 1, 1/n, 0, levelComp: false).ampdb.poll }.plot;
{ n = 2; Splay.ar(DC.ar(1!n), 0, 1, 0, levelComp: 1).ampdb.poll }.plot; // 两者均为 -3 db
{ n = 2; Splay.ar(DC.ar(1!n), 0, 1, 0.99, levelComp: 1).ampdb.poll }.plot; // 0 db

// 对于所有测试的 n 值，这些现在都是相同的：
{ n = 20; Splay.ar(DC.ar(1!n), 1, 1, 0, levelComp: 1).ampdb.poll }.plot; // -4 db
{ n = 20; Splay.ar(DC.ar(1!n), 0, 1, 0, levelComp: 1).ampdb.poll }.plot; // -3 db
{ n = 20; Splay.ar(DC.ar(1!n), 0, 1, 0.99, levelComp: 1).ampdb.poll }.plot; // 右侧为 0 db

{ n = 200; Splay.ar(DC.ar(1!n), 1, 1, 0, levelComp: 1).ampdb.poll }.plot; // -4 db
{ n = 200; Splay.ar(DC.ar(1!n), 0, 1, 0, levelComp: 1).ampdb.poll }.plot; // -3 db
{ n = 200; Splay.ar(DC.ar(1!n), 0, 1, 0.99, levelComp: 1).ampdb.poll }.plot; // 右侧为 0 db

{ n = 2000; Splay.ar(DC.ar(1!n), 1, 1, 0, levelComp: 1).ampdb.poll }.plot; // -4 db
{ n = 2000; Splay.ar(DC.ar(1!n), 0, 1, 0, levelComp: 1).ampdb.poll }.plot; // -3 db
{ n = 2000; Splay.ar(DC.ar(1!n), 0, 1, 0.99, levelComp: 1).ampdb.poll }.plot; // 右侧为 0 db
