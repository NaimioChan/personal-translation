Pair

类 LISP 的双元素单元

Collection : Object

说明

注意： 实现不完整。类似功能参见 J concepts in SC。

大多数方法继承自父类。

类方法

Pair.new(linkDown, linkAcross)

返回新实例。

Pair.newFrom(collection)

将集合（例如数组的数组）转换为对。

实例方法

.size

返回跨接时的大小。

.depth

返回向下链接时的大小。

.do(function)

迭代这两个元素。

.traverse(function)

与以下相同：-depthFirstPreOrderTraversal

.depthFirstPreOrderTraversal(function)

遍历数据结构时先沿第一个链接向下，再横向遍历（参见 示例）。

.depthFirstPostOrderTraversal(function)

从下往上遍历数据结构（参见示例）。

未文档化的实例方法

.add

.linkAcross

.linkAcross = value

.linkDown

.linkDown = value

.remove

示例

a = Pair(Pair(Pair(1, 2), 4), Pair(5, 6));

a.size;
a.depth;
a.do { |x| x.postln };
a.traverse { |x| x.postln };
a.depthFirstPreOrderTraversal { |x| x.postln };
a.depthFirstPostOrderTraversal { |x| x.postln };


// 替代实例化：

Pair.newFrom([1, [2, [[4, 5], 6]]]);

[1, [2, [[4, 5], 6]]].as(Pair); // equivalent.
