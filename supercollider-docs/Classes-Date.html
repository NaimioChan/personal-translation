Date

描述时间中某一刻的对象

Magnitude : Object

类方法

Date.new(year, month, day, hour, minute, second, dayOfWeek, rawSeconds)

用给定的属性创建一个新的 Date（除 rawSeconds 为 Float 外，其余均为 Integer 值）。这些参数同时也是 Date 对象实例变量的名称。

构造函数按以下方式之一初始化实例（按优先级顺序）：

  1. 如果调用 Date.new 时不带任何参数，它将返回当前时间，与调用 *localtime 相同。

    // 以下等价，它们返回 "now"（在调用时）：
Date.new;
Date.localtime;

  2. 如果指定了 rawSeconds 参数，则无论其他属性（year、month、day、hour、minute、second、dayOfWeek）是否为 nil，都会用该参数设置（覆盖）它们。

    (
var d = Date.new.postln;
var e = Date(rawSeconds: d.rawSeconds); // 用相同的时间创建一个新的 Date
d == e; // true
)

  3. 最典型的用法是从年/月/日以及可能的时/分/秒创建 Date。所有这些属性（年份除外）都有默认值（month = 1，day = 1，hour = 0，minute = 0，second = 0）。rawSeconds 根据其他属性计算得出。年份没有默认值——如果没有提供年份，将抛出错误。

    Date(1969, 7, 20, 20, 18); // -> Sun Jul 20 20:18:00 1969
Date(2016); // -> Fri Jan  1 00:00:00 2016
d = Date(2010, day: 15, minute: 30); // -> Fri Jan 15 00:30:00 2010
[d.asString, d.dayOfWeek, d.rawSeconds]; // dayOfWeek 和 rawSeconds 已计算

    注意： 在 Windows 上，创建早于 Unix 纪元（即 1970 年 1 月 1 日之前）的 Date 会失败。

可以指定带有“超出范围”值的日期，这些值会被解析到有效范围内——这允许执行简单的日期偏移计算（参见下面的示例）。

(
// 可以执行简单的日期/时间偏移：
("One hundred days before Christmas:" + Date(2010, 12, 25 - 100).format("%B %d")).postln;

// 无效日期会被“修正”
Date(2017, 2, 29).postln; // 3月1日：2017年不是闰年！
)

注意： dayOfWeek 参数总是会被计算。如果指定了它，其值将被覆盖（它仅出于向后兼容的原因而保留为构造参数）。// 指定 dayOfWeek 参数没有意义（但也没有害处），// 因为它总是会被计算：Date(2017, 10, 31, dayOfWeek: 0).dayOfWeek; // 计算为 2（星期二），而不是 0（星期日）

Date.fromString(string, format)

根据日期/时间字符串创建一个新的 Date 对象，该字符串会按照提供的格式字符串进行解析。

Date.fromString("2017-10-25 [13:25:55]", "%Y-%m-%d [%H:%M:%S]");
Date.fromString("1981.9.30 @ 17:33", "%Y.%m.%d @ %H:%M");

(
// 通过字符串往返，使用 "stamp"
var stampString = Date(2013, 5, 25, 10, 9, 8).stamp;
var d = Date.fromString(stampString, "%y%m%d_%H%M%S");
(stampString + "-->" + d).postln;
)

参数：

string

要解析的日期/时间字符串，例如 "2017-10-25 13:25:55"。

format

用于解析日期字符串的格式。注意，支持的输入格式与 -format（输出）方法的格式略有不同。特别是，某些“组合”格式（如 %F 或 %T）不支持用于输入，必须将其展开（"%F" -> "%Y-%m-%d" 以及 "%T" -> "%H:%M:%S"）。支持的输入格式标志完整列表可在此处找到。

要解析上面的示例字符串，应使用 "%Y-%m-%d %H:%M:%S"。

Date.getDate

从系统获取当前日期并据此创建一个日期对象。

(
var a = Date.getDate;
a.rawSeconds.postln;
a.dayOfWeek.postln;
a
)

Date.localtime

从系统获取当前本地时间并据此创建一个日期对象。

Date.gmtime

从系统获取当前格林尼治标准时间（GMT）并据此创建一个日期对象。

Date.seed

获取当前日期并返回一个适合用于随机数生成器种子的值。另请参阅 randomSeed。

(
var a = Date.seed;
thisThread.randSeed = a;
20.do { [1, 0].choose.post }; "".postln;
thisThread.randSeed = a;
25.do { [1, 0].choose.post }; "".postln;
)

实例方法

.rawSeconds

.rawSeconds = value

获取或设置接收者的原始时间（以秒为单位，相对于 1970 年 1 月 1 日的“纪元”）。

如果修改此属性，其他属性将不会更新。请参阅 -resolve 处的说明——没有 "resolveFromRawSeconds" 方法，但你可以通过将 rawSeconds 作为参数传递给 *new 来生成一个新的自洽的 Date 实例。

注意： 此值在不同机器之间不可移植，因为底层时间函数的实现方式存在差异，并且存在时区差异。要在不同次运行之间以及不同平台上保存/恢复 Date 值，建议不要使用 rawSeconds 值。相反，你应该将 Date 序列化为字符串，例如：

(
var savedDateStr = Date.localtime.format("%Y%m%d_%H%M%S").postcs;
var loadedDate = Date.fromString(savedDateStr, "%Y%m%d_%H%M%S").postln;
)

.localtime

将接收者的时间设置为当前本地时间。

.gmtime

将接收者的时间设为当前 Greenwich Mean Time (GMT)。

.dayStamp

获取一个包含年、月、日的字符串，格式为 YYMMDD。

.hourStamp

获取格式为 H:M:S 的字符串。

.secStamp

获取包含秒数的字符串。

.stamp

获取格式为 YYMMDD_HHMMSS 的字符串。

.asSortableString

获取可按字母顺序排序的标准数据库格式的字符串。

.asctime

获取格式为 WeekdayName MonthName Time Year 的字符串。

.asString

返回 asctime。

.resolve

解析 Date 对象中的任何不一致之处，根据需要更新所有字段（特别是 dayOfWeek 和 rawSeconds）。

如果修改了实例属性（year、month、day、hour、minute、second），Date 将处于不一致状态——其 rawSeconds 不会反映这些修改，并且这些属性可能会超出“正常”范围（month: 1-12, day:1-31, hour: 0-23, minute/second: 0-59）。此外，使用字符串转换方法可能会得到奇怪的结果。调用 resolve 方法会将一切恢复到一致状态。

// 可以执行简单的日期/时间偏移：
d = Date(2017, 9, 30, 10, 30); // -> Sat Sep 30 10:30:00 2017
[d.dayOfWeek, d.rawSeconds]; // -> [6, 1506760200]
d.hour = d.hour - 13; // -> Sat Sep 30 -03:30:00 2017
d.month = d.month + 4; // -> Sat ??? 30 -03:30:00 2017
d.minute = d.minute + 200; // -> Sat ??? 30 -03:230:00 2017
d.rawSeconds; // 没有变化：仍然是 1506760200

// 现在将所有内容解析回合理的范围，并应用偏移量：
d.resolve; // -> Tue Jan 30 00:50:00 2018
[d.dayOfWeek, d.rawSeconds]; // -> [2, 1517269800]

注意： 没有 "resolveFromRawSeconds" 方法。如果修改 rawSeconds 属性，其它属性不会随之改变。如果想向反方向“resolve”，只需使用 rawSeconds 创建一个新的 Date 对象：d = Date(1999, 12, 31); // -> Fri Dec 31 00:00:00 1999 d.rawSeconds; // -> 946594800 // 增加 100 万秒（约 11.6 天） d.rawSeconds = d.rawSeconds + 1e6; // 仍然显示 -> Fri Dec 31 00:00:00 1999 d.rawSeconds; // -> 947594800 // rawSeconds 变了，但其它属性没有变化 // 如果我们调用 d.resolve，那么 rawSeconds 会被重置以匹配所有 // 其它属性。所以在这种情况下，当我们想从 // rawSeconds “resolve”时，只需创建一个新的 Date 对象： d = Date(rawSeconds: d.rawSeconds); // -> Tue Jan 11 13:46:40 2000

.format(format)

获取具有给定格式的日期字符串。字符 % 会被相应的值替换，该值由紧随其后的字母推导得出。

Date.getDate.format("Today is %A. It is around %I o'clock (%p), in %B.");
Date.getDate.format("%d/%m/%Y %H:%M");  // DD/MM/YYYY hh:mm

讨论：

格式列表可在此处找到：http://www.opengroup.org/onlinepubs/009695399/functions/strftime.html

%a

替换为区域设置的缩写星期名。[ tm_wday]

%A

替换为区域设置的全天星期名称。[ tm_wday]

%b

替换为区域设置中的缩写月份名称。[ tm_mon]

%B

被区域设置的完整月份名称替换。[ tm_mon]

%c

替换为区域设置对应的日期和时间表示。

%C

替换为年份除以 100 并截断为整数所得的十进制数 [00,99]。[tm_year]

%d

替换为月份中的日期，以十进制数表示 [01,31]。[ tm_mday]

%D

等同于 %m / %d / %y。[ tm_mon, tm_mday, tm_year]

%e

被替换为以十进制数字 [1,31] 表示的月份中的日期；一位数字前面有一个空格。[ tm_mday]

%F

等价于 %Y - %m - %d（ISO 8601:2000 标准日期格式）。[ tm_year, tm_mon, tm_mday]

%g

替换为基于周的年份的最后 2 位数字（见下文），以十进制数表示 [00,99]。[ tm_year, tm_wday, tm_yday]

%G

替换为基于周的年（见下文），以十进制数表示（例如 1977）。[ tm_year, tm_wday, tm_yday]

%h

等效于 %b。[ tm_mon]

%H

替换为小时（24 小时制），为十进制数 [00,23]。[ tm_hour]

%I

替换为小时（12 小时制），为十进制数 [01,12]。[ tm_hour]

%j

替换为一年中的天数，以十进制数表示 [001,366]。[ tm_yday]

%m

替换为月份，以十进制数表示 [01,12]。[ tm_mon]

%M

替换为十进制数字表示的分钟 [00,59]。[ tm_min]

%n

替换为 <newline>。

%p

替换为区域设置中 a.m. 或 p.m. 的等价形式 [ tm_hour]

%r

替换为上午和下午表示法中的时间；在 POSIX locale 中，这应等同于 %I :%M :%S%p。[ tm_hour, tm_min, tm_sec]

%R

替换为 24 小时记法的时间（%H : %M）。[ tm_hour, tm_min]

%S

替换为十进制数字表示的秒 [00,60]。[ tm_sec]

%t

替换为 <tab>。

%T

替换为时间（ %H : %M : %S）。[ tm_hour, tm_min, tm_sec]

%u

替换为以十进制数字表示的星期几 [1,7]，其中 1 表示星期一。[ tm_wday]

%U

替换为一年中的周数，以十进制数表示 [00,53]。一月的第一个星期日为第 1 周的第一天；在此之前的新年中的天数属于第 0 周。[ tm_year, tm_wday, tm_yday]

%V

替换为一年中的周数（以星期一为一周的第一天），以十进制数表示 [01,53]。如果包含 1 月 1 日的那一周在新年中有四天或更多天，则视为第 1 周。否则，它是上一年的最后一周，而下一周是第 1 周。1 月 4 日和 1 月的第一个星期四始终在第 1 周。[ tm_year, tm_wday, tm_yday]

%w

替换为以十进制数字表示的星期几 [0,6]，其中 0 表示星期日。[ tm_wday]

%W

替换为一年中的周数，以十进制数表示 [00,53]。一月的第一个星期一为第 1 周的第一天；在此之前的新年中的天数属于第 0 周。[ tm_year, tm_wday, tm_yday]

%x

替换为当前区域设置下适当的日期表示。

%X

替换为当前区域设置下适当的时间表示。

%y

用年份的最后两位十进制数替换 [00,99]。 [ tm_year]

%Y

替换为年份，以十进制数表示（例如 1997）。[ tm_year]

%z

替换为 ISO 8601:2000 标准格式中相对于 UTC 的偏移量（+hhmm 或 -hhmm），如果无法确定时区则不使用任何字符。例如，"-0430" 表示比 UTC 落后 4 小时 30 分钟（格林威治以西）。如果 tm_isdst 为零，则使用标准时间偏移量。如果 tm_isdst 大于零，则使用夏令时偏移量。如果 tm_isdst 为负，则不返回任何字符。[ tm_isdst]

%Z

由时区名称或缩写替换，或如果不存在时区信息则不使用字节替换。[ tm_isdst]

%%

替换为 %。

如果某个转换规范与上述任何一项都不对应，其行为是未定义的。

<(other)

<=(other)

>(other)

>=(other)

基于 rawSeconds 比较两个 Date。

Date(1999, 12, 31, 23, 59, 59) < Date(2000, 1, 1, 0, 0, 0);
Date(1999, 12, 31, 23, 59, 59) <= Date(2000, 1, 1, 0, 0, -1);
Date(2005, 1, 1) > Date(2004, 1, 2);
Date(2005, 2, 13) >= Date(2005, 2, 13);

==(other)

!=(other)

基于其 rawSeconds 测试两个 Date 是否相等/不相等。

Date(2016, 11, 4) == Date(2016, 10, 4 + 31);
Date(2016) != Date(2017);
