PeakFollower

跟踪峰值信号幅度。

UGen : AbstractFunction : Object

参见：Peak

说明

输出输入端接收信号的峰值幅度。如果电平低于最大值，则电平按 decay 中给定的因子衰减。

在内部，使用信号的绝对值，以防止在存在负直流偏移时低估峰值。要获取信号的实际最小值和最大值，请使用 RunningMin 和 RunningMax UGen。

类方法

PeakFollower.ar(in: 0.0, decay: 0.999)

PeakFollower.kr(in: 0.0, decay: 0.999)

参数：

in

输入信号。

decay

衰减系数。

实例方法

示例

s.boot;

// 无衰减
(
{
    SinOsc.ar(
            PeakFollower.ar(Dust.ar(20, Line.kr(0, 1, 4)), 1.0) * 1500 + 200,
            0, 0.2
    )

}.play;
)

// 轻微衰减
(
{
    SinOsc.ar(
            PeakFollower.ar(Dust.ar(20, Line.kr(0, 1, 4)), 0.999) * 1500 + 200,
            0, 0.2
    )

}.play;
)

// 鼠标 x 控制衰减，中心
(
{
    var decay;
    decay = MouseX.kr(0.99, 1.00001).min(1.0);
    SinOsc.ar(
            PeakFollower.ar(Dust.ar(20), decay) * 1500 + 200,
            0, 0.2
    );

}.play;
)




// 跟随正弦 LFO，衰减由鼠标 x 控制
(
{
    var decay;
    decay = MouseX.kr(0, 1.1).min(1.0);
    SinOsc.ar(
            PeakFollower.kr(SinOsc.kr(0.2), decay) * 200 + 500,
            0, 0.2
    )

}.play;
)
