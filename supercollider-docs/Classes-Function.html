Function

实现一个函数

AbstractFunction : Object

另见：Functions、AbstractFunction、FunctionDef

本文档涉及 Function 对象的使用。关于更通用的语法介绍和文档，请参阅 Functions。

说明

Function 是对一个 FunctionDef 及其定义上下文 Frame 的引用。当你的代码中遇到 FunctionDef 时，它会作为一个 Function 被压入栈中。可以使用 'value' 方法对 Function 求值。

由于继承自 AbstractFunction，Function 通过创建新的 Function 来响应数学运算。

// example
(
var a, b, c;
a = { [100, 200, 300].choose };    // 一个 Function
b = { 10.rand + 1 };    // 另一个 Function
c = a + b;     // c 是一个 Function。
c.value.postln;    // 对 c 求值并打印结果
)

关于函数组合的示例，请参见 AbstractFunction: Function Composition。

由于函数是如此重要的概念，这里给出一些来自相关编程语言的示例，其中函数是一等对象：

// 返回第一个参数本身：
{ |x| x }.value(1) // SuperCollider
[:x | x ] value: 1 // Smalltalk
((lambda (x) x) 1) // Lisp

Evaluation

.value( ... args)

求值该 Function 所引用的 FunctionDef。该 Function 会接收给定的参数。

 // 表达同一内容的另一种方式：
{ |a, b| a * b }.value(3, 10);
{ |a, b| a * b }.value(a: 3, b: 10); // 关键字参数
{ |a, b| a * b }.(3, 10); // 简写语法：可以省略“value”。

调用时可以省略默认参数：

{ |a=3, b=10| a * b }.value; // 仅使用默认参数
{ |a=3, b=10| a * b }.value(2); // 只设置第一个参数 (a)
{ |a=3, b=10| a * b }.value(b: 100); // 在不设置第一个参数的情况下设置第二个参数 (b)

与运算符组合的函数会将关键字参数分配到各个操作数。

f = { |a, b=1| a ** b } * { |a, c = 0| a + c };
f.value(1); // b 和 c 的默认参数
f.value(1, b:2); // 显式指定 a（另一个函数会警告）
(b:2.5).use { f.valueEnvir(2) } // 要避免警告，你可以使用 valueEnvir（见下文）

.valueArray( ... args)

对 Function 所引用的 FunctionDef 求值。如果最后一个参数是数组或列表，则将其解包并追加到 Function 的其他参数（如果有）之后。如果最后一个参数不是数组或列表，则与 'value' 方法相同。

{ |a, b, c| ((a * b) + c).postln }.valueArray([3, 10, 7]);

{ |a, b, c, d| [a, b, c, d].postln }.valueArray([1, 2, 3]);

{ |a, b, c, d| [a, b, c, d].postln }.valueArray(9, [1, 2, 3]);

{ |a, b, c, d| [a, b, c, d].postln }.valueArray(9, 10, [1, 2, 3]);

一个常见的语法捷径：

{ |a, b, c| ((a * b) + c).postln }.value(*[3, 10, 7]);

.valueEnvir( ... args)

与上面的 value 相同。未提供的参数名会从当前 Environment 中查找。

(
Environment.use({
~a = 3;
~b = 10;
{ |a, b| (a * b).postln }.valueEnvir;
});
)

// 或者使用 Event 在语法上更简短：

(a:3, b:10).use { { |a, b| (a * b).postln }.valueEnvir };

.valueArrayEnvir( ... args)

对 Function 所引用的 FunctionDef 求值。如果最后一个参数是 Array 或 List，则将其解包并追加到 Function 的其他参数（如果有）之后。如果最后一个参数不是 Array 或 List，则这与 'value' 方法相同。未提供的参数名会在当前 Environment 中查找。

.valueWithEnvir(envir)

使用所提供的环境中的参数对函数求值。这比 valueEnvir 稍快，而且不需要替换 currentEnvironment。

(
e = Environment.make({ ~a = 3; ~b = 10 });
{ |a, b| (a * b) }.valueWithEnvir(e);
)

对于 Function，此方法与 valueArray(arglist) 行为相同。它用于 Functions 及其他对象在行为上应不同于 value 的场合，例如 Environment 的对象原型实现中。

a = { |a, b, c| postf("% plus % plus % is %\n", a, b, c, a + b + c); "" };

.loop

重复此函数。与 Task 和 Clocks 一起使用很有用。

t = Task({ { "I'm loopy".postln; 1.wait }.loop });
t.start;
t.stop;

.defer(delta)

在 AppClock 上按 delta 秒延迟该 Function 的求值。

这等价于 AppClock.sched(0, function)，除非 delta 为 nil。在这种情况下，仅当当前代码不在 AppClock 上运行时才调度该函数，否则该函数会被立即求值。

{ "2 seconds have passed.".postln }.defer(2);

(
{ "chicken".postln }.defer(0); // 在 AppClock 上调度
{ "egg".postln }.defer // 立即求值
)

(
fork { // 在 TempoClock 上调度
    { "chicken".postln }.defer // 在 AppClock 上调度
};
{ "egg".postln }.defer // 立即求值
)

.dup(n: 2)

返回一个数组，由对该函数进行 n 次求值的结果组成。

x = { 4.rand }.dup(4);

!(n)

等价于 dup(n)

.choose

求值该函数。这使其对 SequenceableCollection、Bag 和 Set 具有多态性。

[{ 100.rand }, [20, 30, 40]].collect(_.choose);

.bench(print: true)

返回此函数求值所花费的时间量。print 是一个布尔值，指示是否发布结果。默认值为 true。

{ 1000000.do({ 1.0.rand }) }.bench;

.fork(clock, quant, stackSize)

返回一个以接收者作为其函数的 Routine，并在 TempoClock 中播放它。

{ 4.do({ "Threading...".postln; 1.wait }) }.fork;

.forkIfNeeded(clock, quant, stackSize)

如果需要，创建一个新的 Routine 来在其中求值该函数；如果该消息已经在例程中被调用，则它仅对其进行求值。

f = { 4.do({ "Threading...".postln; 1.wait }) };
f.forkIfNeeded;
{ "we are now in a routine".postln; 1.wait; f.forkIfNeeded }.fork;

.block

从循环中跳出。以函数作为参数调用接收者，该函数会从方法块中返回。要退出循环，请对传入的函数调用 .value。你可以向该函数传值，该值将从块方法中返回。

block { |break|
    100.do { |i|
        i.postln;
        if (i == 7) { break.value(999) }
    };
}

.thunk

返回一个 Thunk，即一个未求值的值，可用于计算

x = thunk { 4.rand };
x.value;
x.value;

.flop

返回一个函数，当用嵌套参数对其求值时，它会通过对接收者函数按每个通道求值来进行多通道扩展。翻转后的函数的行为类似于 Lisp 等语言中的 "map" 函数。新函数始终返回一个数组。

// if 的多通道扩展，此处用于防止除零：
f = { |a, b| if(b != 0) { a / b } { 0 } }.flop;
f.value([1, 2, 3, 4], [0, 10, 1000]); //  -> [0, 0.2, 0.003, 0]
f.value(2, 4); // [0.5]（始终返回一个数组）

// 字符串不会展开
f = { |a, b| a + b }.flop;
f.("hello", ["world", "algorithm"]); // -> [hello world, hello algorithm]
f.("hello", "world"); // -> [hello world]

.flop1

与 flop 相同，但仅当参数中也包含数组时才返回数组。可用于实现 多通道扩展。

// if 的多通道扩展，此处用于防止除零：
f = { |a, b| if(b != 0) { a / b } { 0 } }.flop1;
f.value([1, 2, 3, 4], [0, 10, 1000]); //  -> [0, 0.2, 0.003, 0]
f.value([2], 4); // -> [0.5]
f.value(2, 4); // -> 0.5

// 字符串不会像在 flop 中那样展开
f = { |a, b| a + b }.flop1;
f.("hello", ["world", "algorithm"]); // -> [hello world, hello algorithm]
f.("hello", "world"); // -> hello world

.envirFlop

此方法为向后兼容而保留。请改用 flop。

.inEnvir(envir)

返回一个“环境安全”的函数。详见 Environment。注意，返回的函数不接受关键字参数。

e = (a: "get it", b: "didn't");
f = { ~b + ~a + "..." }.inEnvir(e);
f.value;

f = { |how = "", end = "..."| how + ~b + ~a + end }.inEnvir(e); // 不支持关键字参数
f.value(how: "really"); // 警告：在函数调用中未找到关键字参数 'how'（参见 inEnvirWithArgs）。



// 一个用例：defer 通常在调用环境中调用
// 打印 nil，因为 ~a 是从 topEnvironment 读取的，而不是 e
e = (a: "got it", f: { { ~a.postln }.defer(0.5) });
e.use { e.f };

// 打印 "got it"，因为 { ~a.postln } 现在已绑定到 e 环境中
e = (a: "got it", f: { { ~a.postln }.inEnvir.defer(0.5) });
e.use { e.f };

.inEnvirWithArgs(envir)

与 inEnvir 类似，但返回一个接受关键字参数的函数。构建此函数会调用解释器，效率低于 inEnvir

e = (a: "get it", b: "didn't");
f = { |how = "", end = "..."| how + ~b + ~a + end }.inEnvirWithArgs(e);
f.value(how: "I really", end: "done!");

.case( ... cases)

Function 实现了 case 方法，允许对多个 case 进行条件求值。由于接收者代表第一个 case，因此可以简单地写成测试函数与对应求值函数的配对。与 Object-switch 不同，这是内联的，因此与嵌套 if 语句一样高效。

(
var i, x, z;
z = [0, 1, 1.1, 1.3, 1.5, 2];
i = z.choose;
x = case
    { i == 1 }   { \no }
    { i == 1.1 } { \wrong }
    { i == 1.3 } { \wrong }
    { i == 1.5 } { \wrong }
    { i == 2 }   { \wrong }
    { i == 0 }   { \true };
x.postln;
)

对于以下两个方法，接收者自身内部的 return ^ 无法被捕获。由接收者调用的方法中的返回是可以的。

有关如何处理异常的更多信息，另请参见 Exception Handling Examples 和 Exception。

.try(handler)

执行接收者。若抛出异常，则以该错误为参数执行 catch 函数处理程序。处理程序本身可根据需要重新抛出该错误。

.protect(handler)

执行接收者。清理函数处理器会以错误作为参数执行，如果没有错误则为 nil。该错误仍然继续生效。

.awake(beats, seconds, clock)

当调度时间到达时，由调度该函数的 Clock 调用此方法。它调用 -value，并将调度时间（以拍为单位）作为参数传入。

参数：

调度时间，以拍为单位。这等于当前逻辑时间（Thread: -beats）。

seconds

对象被调度所在的时钟。

返回值：

// 每 2 秒运行一次
AppClock.play({ "And again".postln; 2 });

Audio

.play(target, outbus: 0, fadeTime: 0.02, addAction: 'addToHead', args)

来自扩展 /usr/local/share/SuperCollider/SCClassLibrary/Common/Control/asDefName.sc

从该函数返回的 UGen 播放一个 Synth。该函数的参数会成为之后可设置的控制。

其工作方式如下：play 将 UGen 包装在 SynthDef 中并发送到目标。当此异步命令完成时，它会根据此定义创建一个 synth。

参数：

target

一个 Node、Server 或 Nil。Server 会被转换为该服务器的默认组。Nil 会被转换为默认 Server 的默认组。

outbus

确定输出通道的总线编号。这等价于 Out.ar(outbus, signal)。默认值为 0。

fadeTime

合成器起音和释音的交叉淡变时间。默认为 0.02 秒，刚好足以避免咔嗒声。

addAction

合成器的添加动作。有效 addActions 列表参见 Synth

args

一个键值对数组，包含启动合成器时使用的控制名称和控制值。

注意： 在此过程中会添加一些 UGen。一个 Out UGen，用于将音频播放到前几个音频总线。如果函数返回一个 Out UGen，则省略此项。一个带有 \gate 控制的包络，用于释放和交叉淡化。如果函数提供了自己的可释放包络，则省略此项。

x = { |freq = 440| SinOsc.ar(freq, 0, 0.3) }.play; // 这返回一个 Synth 对象：
x.set(\freq, 880); // 注意你可以设置 freq 参数
x.defName; // 生成的 SynthDef 的名称
x.release(4); // 在 4 秒内淡出

许多示例使用了 Function.play 语法。请注意，在 SynthDef 中重用此类代码需要添加一个 Out ugen。

// 以下两行产生等效的结果
{ SinOsc.ar(440, 0, 0.3) }.play(fadeTime: 0.0);
SynthDef(\help_FuncPlay, { Out.ar(0, SinOsc.ar(440, 0, 0.3)) }).play;

对于简短示例和快速测试，Function.play 通常比 SynthDef.play 更方便。后者确实有一些额外的选项，例如控制的 lagtimes 等。在重用和最大灵活性更为重要的情况下，SynthDef 及其各种方法通常是更好的选择。

{ FSinOsc.ar(440, 0, 0.3) }.scope(1)

bufsize

.plot: METHOD NOT FOUND!

注意： 关于绘图的通用参考，请参见 plot

异步计算此函数输出的以秒为单位的时长，并在 GUI 窗口中绘制。与 play 和 scope 不同，它不能与显式 Out UGen 一起工作，因此你的函数应返回一个 UGen 或它们的数组。绘图将实时计算。

要绘制的函数的持续时间（秒）。默认为 0.01。

拾取信号所在的服务器、synth 或组。参见 asTarget。

bounds

一个 Rect 或 Point 的实例，指示绘图窗口的边界。

minval

绘图中的最小值。若未指定，则使用信号的最小值。

maxval

绘图中的最大值。若未指定，则使用信号的最大值。

separately

如果设置为 true，对于多通道信号使用独立的数值显示范围，除非已指定 minval 或 maxval。

parent

可以传入一个 Window 或 View——此时绘图嵌入其中。否则将创建一个新的 Window。

(
var w = Window("The parent of a plotter").front;
{ SinOsc.ar }.plot(0.01, parent: w)
)

.asBuffer(duration: 0.01, target, action, fadeTime: 0)

异步计算此函数输出的时长（秒）并将结果返回在一个具有相应声道数的 Buffer 中。此方法立即返回一个缓冲区，该缓冲区需要 duration 秒才能异步填满数据。随后会调用 action 函数。

参数：

duration

要绘制的函数的持续时间（秒）。默认为 0.01。

target

该 synth 或组在此之后运行 synth（参见 asTarget）。默认为 Server.default 的默认组。

action

当缓冲区被填充时调用的函数。缓冲区作为参数传递给它。

fadeTime

淡入和淡出时间，以秒为单位。仅当大于零时，才会对信号应用包络以避免咔嗒声（默认值：0）。

讨论：

// 录制缓冲区
b = { Blip.ar(XLine.kr(10000, 4, 3) * [1, 1.2], 20) * 0.1 }.asBuffer(3, fadeTime: 0.1)
b.plot; // 3 秒后，你就能看到它。
// 回放声音文件
{ PlayBuf.ar(b.numChannels, b, LFNoise2.kr(2 ! 8).exprange(0.15, 1), loop: 1).sum }.play;

.loadToFloatArray(duration: 0.01, target, action)

将一个 UGen 函数写入文件，然后将其加载到 FloatArray 中。

参数：

duration

以秒为单位的记录数据量

target

一个服务器、synth 或组，用于放置播放该函数的 synth

action

写入完成时要调用的函数。

// 从合成器音频中获取一些数据
{ SinOsc.ar + GrayNoise.ar(0.1) }.loadToFloatArray(0.01, action: { |array| a = array });
a.postln;
a.plot;

// 将其放在其他某个节点之后：
z = { WhiteNoise.ar * 0.1 }.play; // 播放一些噪声
{ BPF.ar(In.ar(0), 7000, 0.01) * 10 }.loadToFloatArray(0.01, z, action: { |array| a = array });
a.postln;

.getToFloatArray(duration: 0.01, target, action, wait: 0.01, timeout: 3)

使用一系列 getn 消息将函数的音频值流式传输到客户端，并将结果放入 FloatArray。

参数：

duration

以秒为单位的记录数据量

target

一个服务器、synth 或组，用于放置播放该函数的 synth

action

写入完成时要调用的函数。

wait

发送 getn 消息之间等待的时间量，以秒为单位。较长的等待时间更安全。默认值为 0.01 秒，在正常情况下似乎可靠。不建议设置为 0。

讨论：

a.plot;

.belaScope(scopeChannel, target, numChannels, outbus: 0, fadeTime: 0.02, addAction: 'addToHead', args)

参数：

scopeChannel

Bela 示波器开始进行示波显示的通道。这必须是一个非负数，且在示波开始后无法更改。

target

一个 Node、Server 或 Nil。Server 会被转换为该服务器的默认组。Nil 会被转换为默认 Server 的默认组。

注意： 此 Function 的播放目标必须位于支持 BelaScope 的服务器上

numChannels

要显示的通道数量，来自此 Function 的输出通道。默认为此 Function 的输出通道。

outbus

fadeTime

addAction

args

参见 Function: -scope

返回值：

与 Function: -play 类似，一个 Synth 会播放此函数。当该 synth 被释放时，其监视器也会被释放。
