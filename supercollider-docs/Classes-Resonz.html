Resonz

谐振滤波器。

Filter : PureUGen : UGen : AbstractFunction : Object

另请参阅：Formlet、RHPF、RLPF、Ringz

说明

这与 Ringz 相同，只是它在 0 dB 处具有恒定增益，而非恒定裙边。

它是一个双极点谐振滤波器，零点位于

z = ±1

基于 K. Steiglitz, "A Note on Constant-Gain Digital Resonators", Computer Music Journal, vol 18, no. 4, pp. 8-10, Winter 1994。

类方法

Resonz.ar(in: 0.0, freq: 440.0, bwr: 1.0, mul: 1.0, add: 0.0)

Resonz.kr(in: 0.0, freq: 440.0, bwr: 1.0, mul: 1.0, add: 0.0)

参数：

in

输入信号。

freq

共振频率，单位为赫兹。警告：由于其实现方式的特性，接近 0 的频率值可能导致故障和/或极其响亮的音频伪影！

bwr

带宽比（Q 的倒数）。rq = bandwidth / centerFreq。

使用 Q 的倒数而不是 Q，因为这样可以节省单元生成器内部的一次除法运算。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

{ Resonz.ar(WhiteNoise.ar(0.5), 2000, 0.1) }.play

// 调制频率
{ Resonz.ar(WhiteNoise.ar(0.5), XLine.kr(1000, 8000, 10), 0.05) }.play

// 调制带宽
{ Resonz.ar(WhiteNoise.ar(0.5), 2000, XLine.kr(1, 0.001, 8)) }.play

// 以相反方向调制带宽
{ Resonz.ar(WhiteNoise.ar(0.5), 2000, XLine.kr(0.001, 1, 8)) }.play
