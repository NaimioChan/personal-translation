FreqScopeView

频率分析视图

另请参阅：FreqScope

说明

FreqScopeView 显示指定音频总线的频谱。

注意： 执行 command-period 后，示波器将保持活动状态。要将其关闭，你必须使用 'active' 方法。非常重要：当父窗口关闭时，你必须运行 kill() 以避免出现问题。它还会释放示波器分配的缓冲区并停止 FFT 分析 Synth。因此：( w = Window("My Analyzer", Rect(0, 0, 511, 300)); f = FreqScopeView(w, w.view.bounds); w.onClose_({ f.kill }); // 你必须包含此内容 w.front; )

类方法

.new

参数：

parent

父视图。

bounds

Rect 的一个实例，或一个 Point，表示 width@height。

server

要在示波器中显示的服务器。

讨论：

Example:

// 启动服务器
s.boot;

// 在窗口中创建分析器
(
w = Window("My Analyzer", Rect(0, 0, 511, 300)); // 宽度应为 511
f = FreqScopeView(w, w.view.bounds);
f.active_(true); // 首次打开它；

w.onClose_({ f.kill }); // 你必须拥有这个
w.front;
{ SinOsc.ar([500, 1000], 0, 0.25).mean.dup }.play(s); // 启动两个正弦波
)

.response

创建一个特殊频率响应模式的示波器。它使用基于 FFT 的频谱除法来估算某个效果的频率响应，前提是假设从 bus1 的信号经过某个线性时不变过程变换为 bus2 处的信号。

参数：

parent

父视图。

bounds

Rect 的一个实例，或一个 Point，表示 width@height。

bus1

找到 "pre" 信号所在的总线。

bus2

找到 "post" 信号的总线。

freqMode

线性 (0) 或对数 (1) 频率模式。默认为 1。

讨论：

Example:

s.boot

// 基本用法。试试这些。每一个都会打开一个新窗口
// 左右移动鼠标以测试不同范围内的响应
LPF.scopeResponse
HPF.scopeResponse
MoogFF.scopeResponse
BBandPass.scopeResponse
BLowShelf.scopeResponse // 默认情况下 BLowShelf 不会造成太大影响
Resonz.scopeResponse
BRF.scopeResponse
Integrator.scopeResponse
Median.scopeResponse // 非线性，因此有趣

// 自定义参数以获得信息更丰富的 scoping
{ |in| MoogFF.ar(in, freq: MouseX.kr(10, 10000, 1),
gain: MouseY.kr(4, 0)) }.scopeResponse

子类化与内部方法

以下方法通常不直接使用，或由原语调用。程序员仍可按需调用或重写这些方法。

实例方法

.kill

非常重要。必须在父窗口关闭时运行此操作以避免出现问题。它还会释放作用域分配的缓冲区并停止 FFT 分析 synth。

.active

打开或关闭示波器。

参数：

bool

Boolean 的实例。

.freqMode

参数：

mode

0 = 线性，1 = 对数。

.inBus

要监听的总线。

参数：

num

一个音频 Bus 编号。

.dbRange

获取/设置振幅范围。

参数：

db

一个 Number。

.special

使用用户指定的 SynthDef 将示波器置于特殊模式。请注意，只能使用非常特定的 SynthDef，即派生自 \freqScope0 或 \freqScope1 SynthDef 的那些。大多数用户不需要直接使用此方法，但可以用它在示波器中提供自定义分析。

参数：

defname

要使用的 SynthDef 名称。

extraArgs

你可能希望传递给 synth 的额外参数。

实例变量

.server

被频率作用域的服务器

.synth

运行 freqscope 分析的 synth

.scope

显示正在运行的分析的示波器视图

.scopebuf

示波器使用的缓冲区

示例

// 启动服务器
s.boot;

// 在窗口中创建分析器
(
w = Window("My Analyzer", Rect(0, 0, 511, 300)); // 宽度应为 511
f = FreqScopeView(w, w.view.bounds);
f.active_(true); // 首次打开它；

w.onClose_({ f.kill }); // 你必须拥有这个
w.front;
{ SinOsc.ar([500, 1000], 0, 0.25).mean.dup }.play(s); // 启动两个正弦波
)

f.freqMode_(1); // 改为对数刻度以便我们能看到它们
f.inBus_(1); // 查看总线 1
f.dbRange_(200); // 扩展振幅范围
f.active_(false); // 关闭示波器（观察 CPU）
f.active_(true); // 重新打开它

// 现在按 command-period。示波器仍在运行。

{ Mix.ar(SinOsc.ar([500, 1200, 3000, 9000, 12000], 0, [0.2, 0.1, 0.05, 0.03, 0.01])) }.play(s); // 重新启动一些正弦波

// 关闭窗口并终止 scope。
