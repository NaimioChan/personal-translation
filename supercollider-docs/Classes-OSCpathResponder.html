OSCpathResponder

客户端网络响应器

OSCresponder : Object

另见：OSCFunc、OSCdef、OSC 通信、OSCresponderNode

说明

注意： 此类已弃用，并将在 SC 的未来版本中移除。请改用 OSCFunc 和 OSCdef。与旧的响应器类相比，它们更快、更安全，参数顺序也更合理，并且支持模式匹配和自定义监听端口。使用较旧的类 OSCresponder、OSCresponderNode 和 OSCpathResponder 可能不安全，因为用户代码和类代码中的响应器可能会意外地相互覆盖。路径匹配的替代方案参见 OSCFunc 和 OSCDef 的 template 参数（见下面的示例）。

注册一个函数，在收到具有特定路径的命令时被调用。

其他向 SuperCollider 发送消息的应用程序应区分是向服务器还是向语言发送消息。服务器消息记录在 Server Command Reference 中，应发送到服务器的端口——s.addr.port——默认是 57110。发送到服务器的消息不会被语言中的任何 OSCresponder 处理。

应由 OSCresponder 处理的外部客户端消息必须发送到语言端口，默认情况下为 57120。使用 NetAddr.langPort 来确认 SuperCollider 语言正在监听哪个端口。

更多细节参见 OSC Communication。

命令路径

OSC 命令有时会包含额外参数以指定正确的响应者。

例如 /tr 命令，它由服务器上的 SendTrig UGen 生成，会创建一个由 [/tr, nodeID, triggerID, value] 组成的 OSC 数据包。这个数组实际上指定了值的来源：[/tr, nodeID, triggerID]。我们将该数组称为命令路径。

要为特定触发器创建 OSCpathResponder，只需将 cmdName 参数替换为完整的命令路径。

路径默认值

命令路径数组的任意元素都可以设为 nil，以创建一个能处理多个命令路径的响应者。

例如，设置 commandpath：['/tr', nil, triggerID] 会创建一个响应器，它响应来自任何 Synth 的 /tr 消息，但只针对特定的 triggerID。

类方法

OSCpathResponder.new(addr, cmdPath, action)

参数：

addr

一个 NetAddr 实例，通常从你的服务器获取：server-addr。地址为 nil 时将响应来自任何位置的消息。

cmdPath

命令路径，例如 ['\c_set', bus index]。

action

一个 Function，当从 addr 接收到该名称的 cmd 时会被求值。参数：time、theResponder、message

注意： OSCresponderNode 在系统进程中求值其函数。为了访问应用程序进程（例如进行 GUI 访问），请在动作函数内使用 { ... }.defer，例如 { |time, resp, msg| { gui.value_(msg[3]) }.defer }

示例

s.boot;

(
    var commandpath, response, aSynth, nodeID, triggerID;
    triggerID = 1;
    aSynth = { |freq = 1, triggerID = 1|
        SendTrig.kr(SinOsc.kr(freq), triggerID, 666)
    }.play;
    nodeID = aSynth.nodeID;
    commandpath = ['/tr', nodeID, triggerID];
    response = { |time, responder, message| message.postln };

    o = OSCpathResponder(s.addr, commandpath, response);
    o.add;
)

// 开启和关闭：
o.remove;
o.add;


// 现在可以用 OSCFunc 方便高效地实现这一点。
// argTemplate 类似于 OSCpathResponder 的 "path"，但不包含 OSC 路径本身。
(
    var commandpath, response, aSynth, nodeID, triggerID;
    triggerID = 1;
    aSynth = { |freq = 1, triggerID = 1|
        SendTrig.kr(SinOsc.kr(freq), triggerID, 666)
    }.play;
    nodeID = aSynth.nodeID;
    commandpath = [nodeID, triggerID];
    response = { |message| message.postln };

    o = OSCFunc(response, '/tr', s.addr, argTemplate: commandpath);

)

// OSCFunc 通过 cmd-Period 移除。
// 为了以编程方式开启和关闭它：
o.remove;
o.add;
