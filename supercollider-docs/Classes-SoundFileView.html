SoundFileView

声音文件显示

参见：SoundFile

说明

一个具有众多选项的声音文件查看器。

使用 Shift + 右键 + 鼠标上移/下移进行缩放；

使用右键 + 鼠标左键/右键进行滚动。

.read

'block' 参数没有效果；显示分辨率是无限的。

节段的大小，以帧为单位。

closeFile

doneAction

.readFile

读取一个已打开的 SoundFile 实例的一部分，并将其显示在视图中。对于大文件，你可能更想使用 readWithTask 方法。

'block' 参数没有效果；显示分辨率是无限的。

参数：

一个打开的 SoundFile 实例。

该段的起始位置，以帧为单位。

frames

节段的大小，以帧为单位。

block

closeFile

如果为 true，则在读取后关闭 SoundFile。

doneAction

文件读取完成时调用的 Function。

.readWithTask

异步（在后台）读取 -soundfile 的一段，并在此过程中更新 -readProgress。如果 showProgress 参数为 true，则会打开一个 SoundFileViewProgressWindow 来显示进度。

'block' 参数没有效果；显示分辨率是无限的。'showProgress' 参数没有效果；视图始终在自身内部显示读取进度。

参数：

startFrame

该段的起始位置，以帧为单位。

frames

节段的大小，以帧为单位。

block

块大小 - 显示的视觉分辨率。形式为 2**n 的 Integer。

doneAction

一个可选函数，在完成时求值。

showProgress

是否打开进度窗口。默认为 true。

.readFileWithTask

异步（在后台）读取打开的 SoundFile 实例的一部分，同时更新 -readProgress。如果 showProgress 参数为 true，将打开一个 SoundFileViewProgressWindow 来显示进度。

'block' 参数没有效果；显示分辨率是无限的。'showProgress' 参数没有效果；视图始终在自身内部显示读取进度。

参数：

一个打开的 SoundFile 实例。

startFrame

该段的起始位置，以帧为单位。

frames

节段的大小，以帧为单位。

block

块大小 - 显示的视觉分辨率。形式为 2**n 的 Integer。

doneAction

一个可选函数，在完成时求值。

showProgress

是否打开进度窗口。默认为 true。

.data

设置自定义数据而非声音文件。这只是一个 setter；无法获取该数据。如果你需要访问该数据，必须将其保存在你自己的变量中。

设置此属性假定 1 个声道和 44100 Hz 的采样率。如果需要更多控制，请改用 -setData。

一个 Float 数组；多通道数据应交织存放。

参数：

块大小——显示的视觉分辨率。形式为 2**n 的整数。（自移植到 QT 以来，'block' 参数不再有任何效果；显示分辨率是无限的）。

一个整数。

一个整数。

一个整数。

一个 Integer。

一个 Integer。

用另一段数据覆盖一段显示数据。此方法可在调用 -alloc 或 -setData 之后使用，但不能在视图正显示声音文件时使用。

参数：

开始覆盖的帧位置；一个 Integer。

Navigation

.viewFrames

视图中当前可见的帧数。

.zoom

相对于当前缩放按系数缩放。

参数：

一个 Float。

.zoomToFrac

缩放到特定刻度。

参数：

一个 Float。

.zoomAllOut

缩放到当前选区。

.zoomSelection

缩放到特定选区。

参数：

选择的索引；一个 0 到 63 之间的 Integer。

.xZoom

视图中显示的音频秒数。例如，要缩小 2 倍，请使用 view.xZoom = dataDuration / 2。（你需要自行跟踪数据时长。）

返回值：

一个 Float，表示显示的音频秒数。

.yZoom

垂直缩放。默认的 yZoom = 1 将 ±1.0 设为视图的顶部和底部。若 yZoom = 2，视图覆盖数值范围的 ±0.5。

返回值：

一个 Float 缩放因子。

.yOffset

垂直偏移。默认的 yOffset = 0 将 0.0 值置于通道视图的中间，而 yOffset = 1 将 0.0 置于视图顶部，yOffset = -1 将 0.0 置于视图底部。此操作在 -yZoom 因子之后执行（因此不受其缩放影响）。

返回值：

一个 Float 偏移量。

.spacing

±1.0 值范围之外的垂直空间与通道完整高度之间的比例。默认的 spacing = 0.1 使顶部和底部空间合计为 0.1 * height（两者各占其中一半），而 ±1.0 值范围占据 0.9 * height。该值会被裁剪到 0.0 到 1.0 的范围之内。

返回值：

一个 Float 缩放因子。

.scrollPos

视图的滚动位置，以总滚动范围的比例表示。总滚动范围为 totalDuration - xZoom。

返回值：

一个 0.0 到 1.0 范围内的 Float。

.scrollTo

滚动到总滚动范围的一个比例位置。总滚动范围为 totalDuration - xZoom。

参数：

一个 0.0 到 1.0 范围内的 Float。

.scroll

按可见范围的比例滚动。

参数：

一个 Float。

.scrollToStart

滚动到开头。

.scrollToEnd

滚动到末尾。

添加滚动条

在 SoundFileView 中直接用鼠标缩放和滚动可能并不直观。（大多数用户不会想到右键单击并按住 Shift 键！）你可以添加一个 RangeSlider 充当滚动条。

Notes:

  • 如果用户按住 Shift 右键单击，跟踪 SoundFileView 显示变化的唯一方法是使用鼠标动作：View: -mouseDownAction 和 View: -mouseUpAction 可获知按下了哪个按钮，View: -mouseMoveAction 可读取新的滚动和缩放值。
  • SoundFileView: -xZoom 以秒为单位，而范围滑块被归一化到 0-1 范围。因此 xZoom == slider.range * duration，且 slider.range == xZoom / duration。
  • SoundFileView: -scrollPos 被归一化到“总滚动范围”，其中 1.0 表示完全滚动到右侧。我们必须减去显示区域：slider.lo = sfv.scrollPos / (1 - slider.size)，并做一些调整以避免除以 0。
p = ExampleFiles.child;
f = SoundFile.openRead(p);
f.readData(d = Signal.newClear(f.numFrames * f.numChannels));
f.close;

(
var w = Window("test", Rect(700, 200, 600, 300)),
sfv, sfZoom, mouseButton,
dur = d.size / f.sampleRate / f.numChannels;

w.layout = VLayout(
    sfv = SoundFileView(),
    sfZoom = RangeSlider().orientation_(\horizontal)
);

sfZoom.lo_(0).range_(1)
.action_({ |view|
    var divisor, rangeStart;
    rangeStart = view.lo;
    divisor = 1 - sfZoom.range;
    if(divisor < 0.0001) {
        rangeStart = 0;
        divisor = 1;
    };
    sfv.xZoom_(sfZoom.range * dur)
    .scrollTo(rangeStart / divisor)
});

sfv.setData(d, startFrame: 0, channels: f.numChannels, samplerate: f.sampleRate);

sfv.mouseDownAction_({ |view, x, y, mod, buttonNumber|
    mouseButton = buttonNumber;
})
.mouseUpAction_({ |view, x, y, mod|
    mouseButton = nil;
})
.mouseMoveAction_({ |view, x, y, mod|
    var rangeSize, rangeStart;
    if(mouseButton == 1) {
        rangeSize = view.xZoom / dur;
        rangeStart = view.scrollPos * (1 - rangeSize);
        sfZoom.lo_(rangeStart).range_(rangeSize);
    };
});

w.front;
)
