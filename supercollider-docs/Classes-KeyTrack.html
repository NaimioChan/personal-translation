KeyTrack

按键跟踪器

UGen : AbstractFunction : Object

参见：BeatTrack, Loudness, MFCC, Onsets, Pitch

说明

一个基于 FFT 各 bin 能量音级轮廓（pitch class profile）的（12TET 大调/小调）调性跟踪器，并将其与所有移调的大调和小调音阶模板进行匹配。它假定 A 音为 440 Hz 的协奏音高参考。输出为 0-11 表示 C 大调到 B 大调，12-23 表示 C 小调到 B 小调。

类方法

KeyTrack.kr(chain, keydecay: 2.0, chromaleak: 0.5)

参数：

chain

[fft] 要跟踪的音频输入。必须已由 4096 大小的 FFT 预先分析。除下文所述外，其他 FFT 大小均无效。

keydecay

[sk] 窗口对最终键判决的影响衰减 40dB（至其原始值的 0.01）所需的秒数。

chromaleak

[sk] 每一帧中，色度值被设为前一值乘以 chromadecay。0.0 会使每一帧都重新开始，不保留记忆。

    rootnote = if(key < 12, key, key-12) + 60;

    sympath = SinOsc.ar((rootnote + chord).midicps, 0, 0.4).mean;

    Pan2.ar(in, -0.5) + Pan2.ar(sympath, 0.5)
}.play

/*
研究笔记：
参见 MIREX2006 音频调性跟踪竞赛以及 Emilia Gomez 的博士论文《音乐音频信号的调性描述》

以下代码用于创建该 UGen 的数据集，并将作为扩展的基础

需要为 44100 和 48000 各准备一组频段数据

KeyTrack 计算，需要为每个半音音调构建 FFT 频段数组和权重。
更高分辨率，4096 FFT，避开低八度，那里太杂乱

60*6*2 个输出数组
*/

(
var fftN, fftBins, binsize;
var midinotes;
var sr;
var wtlist, binlist;

sr = 48000; // 44100;

fftN = 4096;
fftBins = fftN.div(2);
binsize = sr / fftN;

midinotes = (33..92); // 60 notes, 55 Hz up to 1661.2187903198 Hz

wtlist = List[];
binlist = List[];

// 每个音符有六个谐波位置
midinotes.do{ |note|
    var freq, whichbin, lowerbin, prop;

    freq = note.midicps;

    6.do{ |j|
        var partialfreq, partialamp;

        partialamp = 1.0 / (j + 1);
        partialfreq = freq * (j + 1);

        whichbin = partialfreq / binsize;
        lowerbin = whichbin.asInteger;
        prop = 1.0 - (whichbin - lowerbin);

        binlist.add(lowerbin).add(lowerbin + 1);
        wtlist.add(prop * partialamp).add((1.0 - prop) * partialamp);

    };

};


Post << (binlist) << nl<< nl;

Post << (wtlist) << nl<< nl;

binlist.size.postln;
wtlist.size.postln;
)
