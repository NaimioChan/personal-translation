EZPopUpMenu

一个包装类，包含一个标签和一个带逐项操作的 popUpMenu

另请参阅：PopUpMenu

说明

EZPopUpMenu 是一个包装类，它创建一个（可选的）标签和一个 popUpMenu。它包含逐项操作以及全局操作，两者都在选择某一项时求值。还包括用于插入和删除菜单项的便捷方法。如果 parent 为 nil，则 EZPopUpMenu 会创建自己的窗口。有关所有选项，请参见 EZGui 和 EZLists。

关于 EZPopUpMenu 的一些重要问题

EZPopUpMenu 的便捷方法要求 items 数组是由标签和函数组成的关联数组，而不像 PopUpMenu 中那样，items 只是简单字符串组成的数组。如果 label 为 nil，则不会创建 staticText。

类方法

.new

参数：

parentView

父视图或窗口。如果父视图为 nil，则 EZPopUpMenu 会创建自己的 Window，并且如果 bounds 是一个 Point，会方便地将其放置在屏幕上。如果 bounds 是一个 Rect，则该 Rect 决定窗口 bounds。

bounds

Rect 或 Point 的实例。默认值为 160@22。

label

标签。默认值为 nil。如果为 nil，则不创建 StaticText。

items

默认值为 nil。一个数组，包含多个关联 ['label' -> { |menuObj| value }, ]。或者一个数组，包含多个符号（如果你只使用 globalAction）。

globalAction

除条目函数 { |menuObj| value } 之外还要执行的全局函数。

initVal

菜单的初始值，即选中的索引。默认值为 0。

initAction

Boolean 的实例。在创建菜单时于 initVal 处执行该动作，并额外执行 globalAction。默认值为 false。

labelWidth

默认值为 80。

labelHeight

默认值为 20。如果布局为 \horz，则不使用。

layout

\vert 或 \horz。默认为 \horz。

gap

一个 Point。默认情况下，视图会尝试获取其父视图的 gap，否则默认为 2@2。设置此项会覆盖这些默认值。

margin

一个 Point。这将对 view 的子视图所占用的边界进行内缩。

讨论：

(
w = Window.new.front;
w.view.decorator = FlowLayout(w.view.bounds);
g = EZPopUpMenu.new(
    w,
    230@22,
    "A PopUpMenu: ",
    [
        \item0 ->{ |a| ("this is item 0 of " ++ a).postln },
        \item1 ->{ |a| ("this is item 1 of " ++ a).postln },
        \item2 ->{ |a| ("this is item 2 of " ++ a).postln },
    ],
    globalAction: { |a| ("this is a global action of "++a.asString).postln },
    initVal: 1,
    initAction: true,
    labelWidth: 120,
    labelHeight: 20,
    layout: \horz,
    gap: 2@2
);
)

// 或者更简单的语法：
(
w = Window.new.front;
w.view.decorator = FlowLayout(w.view.bounds);
g = EZPopUpMenu.new(w, 200@22, "Menu: ");
g.addItem(\item0, { |a| ("this is item 0 of " ++ a).postln });
g.addItem(\item1, { |a| ("this is item 1 of " ++ a).postln });
g.addItem(\item2, { |a| ("this is item 2 of " ++ a).postln });
g.value = 0;
)

实例方法

更改外观

.setColors

参数：

stringBackground

一个 Color 的实例。标签和单位视图的 background。

stringColor

Color 的实例。标签视图与单位视图的 stringColor。

menuBackground

一个 Color 的实例。菜单的 background。

menuStringColor

一个 Color 的实例。菜单的 stringColor。

background

一个 Color 的实例。列表视图的 background。

.font

设置所有视图使用的 Font。

参数：

font

Font 的一个实例。

示例

// 把几个例子一起试一下
(

// 许多菜单
// 继承父级的装饰间隙

(
w = Window.new("oscillators", Rect(200, 500, 200, 160)).front;
w.view.decorator = FlowLayout(w.view.bounds).gap_(2@2);
5.do{ |i|
    g = EZPopUpMenu.new(w, 190@22, "Oscillator % : ".format(i+1));
    g.addItem(\off, { "off".postln });
    g.addItem(\sine, { "sine".postln });
    g.addItem(\saw, { "saw".postln });
    g.addItem(\pulse, { "pulse".postln });
    g.setColors(Color.grey, Color.white);
    g.value = 0;
};
w.bounds = w.bounds.moveBy(300, 60);
);


// 如果 parentView 为 nil，则创建自己的窗口：
(
g = EZPopUpMenu.new(nil, 250@22, " Select : ");
g.addItem(\item0, { "this is item 0".postln });
g.addItem(\item1, { "this is item 1".postln });
g.addItem(\item2, { "this is item 2".postln });
g.setColors(Color.grey, Color.white);
g.value = 0;

);

// 垂直布局：
(
g = EZPopUpMenu.new(nil, 200@42, " Choose", layout: \vert);
g.addItem(\item0, { "this is item 0".postln });
g.addItem(\item1, { "this is item 1".postln });
g.addItem(\item2, { "this is item 2".postln });
g.setColors(Color.grey, Color.white);
g.window.bounds = g.window.bounds.moveBy(300, -200);
g.value = 0;
);

// 未创建 labelView，因此设置窗口标题；
(
g = EZPopUpMenu.new(bounds: 180@22); // 无标签
g.addItem(\item0, { "this is item 0".postln });
g.addItem(\item1, { "this is item 1".postln });
g.addItem(\item2, { "this is item 2".postln });
g.value = 0;
g.window.name = " choose item";
g.window.bounds = g.window.bounds.moveBy(0, -200);
);
)
// insertItem;

(
g = EZPopUpMenu.new(nil, 200@22, "Menu:");
g.addItem(\item0, { "this is item 0".postln });
g.addItem(\item1, { "this is item 1".postln });
g.addItem(\item2, { "this is item 2".postln });
g.addItem(\item4, { "this is item 4".postln });
g.value = 0;
);

g.insertItem(3, \item3, { "this is item 3".postln });


// 移除条目 ;

(
w = Window.new.front;
w.view.decorator = FlowLayout(w.view.bounds);
g = EZPopUpMenu.new(w, 200@22, "Menu:");
g.addItem(\item0, { "this is item 0".postln });
g.addItem(\item1, { "this is item 1".postln });
g.addItem(\item2, { "this is item 2".postln });
g.addItem(\item4, { "this is item 4".postln });
g.insertItem(3, \item3, { "this is item 3".postln });
g.value = 0;
)

g. removeItemAt(0);



// 替换条目;
(
g = EZPopUpMenu.new(nil, 200@22, "List:");
g.addItem(\item0, { "this is item 0".postln });
g.addItem(\item1, { "this is item 1".postln });
g.addItem(\item2, { "this is item 2".postln });
g.addItem(\item3, { "this is item 3".postln });
)

g.replaceItemAt(2, \item2_replaced, { "this is item 2 replaced".postln });
