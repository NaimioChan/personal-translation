实际考虑

使用你自己的乐器

(
SynthDef(\help_SPE7_BerlinB, { arg i_out=0, freq = 80, amp = 0.2, pan=0;
    var out, a, b;
    amp = Decay2.kr(Impulse.kr(0), 0.05, 8, amp);
    out = RLPF.ar(
        LFPulse.ar(freq, 0, SinOsc.kr(0.12,[0,0.5pi],0.48,0.5), amp),
        freq * SinOsc.kr(0.21,0,4,8),
        0.07
    );
    #a, b = out;
    DetectSilence.ar(a, 0.0001, doneAction: Done.freeSelf);
    Out.ar(i_out, Mix.ar(PanAz.ar(4, [a, b], [pan, pan+1])));
}).add;

SynthDef(\help_SPE7_CFString1, { arg i_out, freq = 360, gate = 1, pan, amp=0.1;
    var out, eg, fc, osc, a, b, w;
    fc = LinExp.kr(LFNoise1.kr(Rand(0.25,0.4)), -1,1,500,2000);
    osc = Mix.fill(8, { LFSaw.ar(freq * [Rand(0.99,1.01),Rand(0.99,1.01)], 0, amp) }).distort * 0.2;
    eg = EnvGen.kr(Env.asr(1,1,1), gate, doneAction: Done.freeSelf);
    out = eg * RLPF.ar(osc, fc, 0.1);
    #a, b = out;
    Out.ar(i_out, Mix.ar(PanAz.ar(4, [a, b], [pan, pan+0.3])));
}).add;
)

Pattern: -play 为你创建一个 EventStreamPlayer，并且还提供一个默认的 protoEvent。如果你使用自己的事件模型，只需将自己的 protoEvent 传给 play 方法。

(
Pbind(
    \instrument, Prand([\help_SPE7_BerlinB, \help_SPE7_CFString1],inf),
    \degree, Pseq([0,1,2,4,6,3,4,8],inf),
    \dur, 0.8,
    \octave, 3,
    \amp, 0.03
).play; // 这将返回一个 EventStreamPlayer
)

定义自己的消息绑定

默认事件原型使用 msgFunc 来确定要传递给服务器的绑定。已存储在 SynthDescLib（“合成器描述库”）中的 SynthDef 会自动构造 msgFunc。默认事件会在你选择的 SynthDescLib 中查找乐器名称（使用 \synthLib 键）。通常只使用全局 SynthDescLib；如果 \synthLib 为空，则默认使用全局库。

你不应该发送或加载计划与模式一起使用的 synthdef。相反，应将它们存储在 SynthDescLib 中。

// 将 .scsyndef 文件保存到磁盘（类似 .load），并将描述添加到全局库中
SynthDef(...).store;

// 将描述添加到全局库；不保存文件（类似 .send）
SynthDef(...).add;

如果你不这样做，非默认绑定将被忽略。在这种情况下，你可以手动提供自定义的 msgFunc。下面是一个示例：

(
SynthDef(\help_SPE4_CFString2, { arg i_out, freq = 360, gate = 1, pan, amp=0.1, dorkarg=1;
    var out, eg, fc, osc, a, b, w;
    fc = LinExp.kr(LFNoise1.kr(Rand(0.25,0.4)), -1,1,500,2000);
    osc = Mix.fill(8, { LFSaw.ar(freq * [Rand(0.99,1.01),Rand(0.99,1.01)], 0, amp * dorkarg ) }).distort * 0.2;
    eg = EnvGen.kr(Env.asr(1,1,1), gate, doneAction: Done.freeSelf);
    out = eg * RLPF.ar(osc, fc, 0.1);
    #a, b = out;
    Out.ar(i_out, Mix.ar(PanAz.ar(4, [a, b], [pan, pan+0.3])));
}).send(s);    // 将 .send(s) 改为 .add
)

如你所见，我已将 dorkarg 添加到前面 SynthDef 的参数列表中。

(
Pbind(
    \instrument, \help_SPE4_CFString2,
    \degree, Pseq([0,1,2,4,6,3,4,8],inf),
    \dur, 0.4,
    \octave, 3,
    \amp, 0.03,
    \dorkarg, Pseq([1,0,1],inf) // 每隔一个音符静音 - 不起作用
).play;
)

dorkarg 被忽略，因为 SynthDef 未被正确 .add，因此事件原型不知道 dorkarg 是重要的。

你也可以提供一个\msgFunc，其中包含dorkarg：

(
Pbind(
    \instrument, \help_SPE4_CFString2,
    \degree, Pseq([0,1,2,4,6,3,4,8],inf),
    \dur, 0.4,
    \octave, 3,
    \amp, 0.03,
    \dorkarg, Pseq([1,0,1],inf), // 每隔一个音符静音——现在可以了
    \msgFunc, { arg out = 0, freq = 440, amp = 0.1, pan = 0, vol = 1,
            dorkarg = 1;
        [\out, out, \freq, freq, \amp, amp, \pan, pan, \vol, vol,
            \dorkarg, dorkarg];
    }
).play;
)

但这相当笨拙。强烈建议养成对所有打算与模式一起使用的 SynthDef 使用 .add 的习惯。

如果你将使用未指定的绑定，另一种选择当然是以适当的 msgFunc 作为默认值定义一个事件。请查看 Event 的源码，这很简单，而且比每次传入 msgFunc 更简洁。

实时操作 EventStreamPlayer

(
p = Pbind(
    \degree, Pwhite(0,12),
    \dur, 0.2,
    \instrument, \help_SPE4_CFString2
);
// e 是一个 EventStreamPlayer
e = p.play;
)

(
// 你可以在任意时刻更改流
e.stream = Pbind(
    \degree, Pseq([0,1,2,4,6,3,4,8],inf),
    \dur, Prand([0.2,0.4,0.8],inf),
    \amp, 0.05,
    \octave, 5,
    \instrument, \help_SPE7_BerlinB, // 你也可以使用符号
    \ctranspose, 0
).asStream;
)

(
e.stream = Pbind(
    [\degree, \dur], Pseq(
        [
            Pseq([[0,0.1],[2,0.1],[3,0.1],[4,0.1],[5,0.8]],2),
            Ptuple([Pxrand([6,7,8,9],4), 0.4]),
            Ptuple([Pseq([9,8,7,6,5,4,3,2]), 0.2])
        ], inf
    ),
    \amp, 0.05,
    \octave, 5,
    \instrument, \help_SPE7_CFString1
).asStream;
)

以下方法是可行的，因为 EventStreamPlayer 是一个 PauseStream：

e.mute;        // 继续播放，但将音符替换为休止符

e.unmute;

e.reset;    // 重置流。

e.pause;    // 将从暂停处继续。

e.resume;

e.stop;        // 将在继续前重置。

e.resume;
