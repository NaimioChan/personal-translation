MIDIMessageDispatcherNV

MIDIFunc 和 MIDIdef 的默认调度器，设置为响应 touch、program 和 bend 消息。

MIDIMessageDispatcher : AbstractWrappingDispatcher : AbstractDispatcher : Object

参见：MIDIFunc、MIDIdef、AbstractWrappingDispatcher、AbstractDispatcher、MIDIMessageDispatcher、AbstractMessageMatcher、MIDIFuncSrcMessageMatcher、MIDIFuncChanMessageMatcher、MIDIFuncChanArrayMessageMatcher、MIDIFuncSrcMessageMatcherNV、MIDIFuncBothMessageMatcher、MIDIFuncBothCAMessageMatcher、MIDI

说明

MIDIMessageDispatcherNV 用于将传入的 MIDI 触控、音色和弯音消息分派到匹配的函数。通常用户不应直接创建此类的实例或向其发送消息。

类方法

实例方法

.getKeysForFuncProxy(funcProxy)

获取 responder 函数存储在此 dispatcher 的活动字典中的键。这些键将是 MIDI 通道。

参数：

funcProxy

应返回其键的 MIDIFunc 或 MIDIdef。

返回值：

一个 Array，包含 funcProxy 的通道编号，类型为 Integer。

.value(src, chan, val)

尝试将传入的 MIDI 消息与此 dispatcher 的 responder 函数进行匹配，并对所有匹配项求值其函数。

参数：

src

MIDI 消息来源的 UID，为 Integer 类型。

chan

MIDI 消息的通道号，为 Integer 类型。注意其范围应为 0-15。

val

MIDI 消息的消息值（例如 velocity 等），为一个 Integer。注意其应在 0-127 范围内。

.wrapFunc(funcProxy)

在需要时于内部被调用，以将函数包装到消息匹配器对象中。

参数：

funcProxy

要包装其函数的 MIDIFunc 或 MIDIdef 实例。
