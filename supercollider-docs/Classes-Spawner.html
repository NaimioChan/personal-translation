Spawner

一个 Spawner

Pattern : AbstractFunction : Object

参见：Pspawner

说明

可以启动子模式。在 Pspawner 内作为参数使用。在 PriorityQueue 中跟踪子模式。

类方法

Spawner.new(func, stackSize: 64)

参数：

func

stackSize

实例方法

.par(pattern, delta: 0)

开始一个与例程并行的事件流。如果 delta 非零，则模式将在 now 之后经过该数量的拍后开始，前提是 now + delta 晚于 Spawner 将生成的下一个事件。

参数：

pattern

一个 Pattern。

delta

拍数。

返回值：

来自 pattern 的流。

.seq(pattern)

开始一个事件流。在事件完成之前不返回。

参数：

pattern

一个 Pattern。

.wait(dur)

等待若干秒，然后返回。

参数：

dur

以秒为单位的数值。

.suspend(stream)

停止一个流。

参数：

stream

底层 PriorityQueue 的索引。

返回值：

已停止的流，若未找到该流则为 nil。

.suspendAll

停止所有子流。
