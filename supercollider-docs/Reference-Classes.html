Classes

解释类

参见：Class、赋值语句、对象入门、消息、多态、编写类

SuperCollider 中的所有对象都是某个类的成员，类描述了对象的数据和接口。类名必须以大写字母开头。类名是 SC 语言中唯一的全局值。由于类本身也是对象，类名标识符的值就是代表该类的对象。

关于类、对象和消息概念的介绍，请参见对象简介。

实例变量

对象的数据包含在其实例变量中。实例变量有两种：命名实例变量和索引实例变量。每个对象都包含其自身实例变量的一份独立副本。

有些类的实例完全没有实例变量，而是具有一个原子值。其实例由一个原子值构成的类有 Integer、Float、Symbol、True、False、Nil、Char、Color。

实例变量声明列表出现在类定义的左花括号之后，并以保留字 var 开头。列表中的实例变量名可以使用等号初始化为默认字面值。未显式初始化的实例变量将被设置为 nil。不可变的实例变量由保留字 const 定义。

实例变量只能从类自身的方法中直接访问和更改。实例变量可以通过向类中添加 getter 和 setter 消息来暴露给客户端。getter 消息是与变量同名的消息，当发送给接收者时返回该变量的值。setter 消息是变量名后附加下划线的消息，它将实例变量的值设置为消息参数的值。

getter 和 setter 方法可在实例变量的声明中定义。为实例变量创建 getter 消息的方法是在变量名之前输入小于号 <。创建 setter 消息的方法是在变量名之前输入大于号 >。如果两者同时出现，则必须按 <> 的顺序出现。

var a, <b, >c, <>d;
a

没有 getter 或 setter。

b

有 getter 但没有 setter。

c

仅有一个设置器。

d

同时具有 getter 和 setter。

Point {
    // x 和 y 是实例变量，它们同时具有 getter 和 setter 方法
    // 并且默认值为零。
    var <>x = 0, <>y = 0;
    ...
}

p = Point.new;
p.x_(5);        // 发送 setter 消息将 x 设为 5
p.y_(7);        // 发送 setter 消息将 y 设为 7
p.x = 5;        // 使用 setter 赋值发送 setter 消息
p.y = 7;        // 使用 setter 赋值发送 setter 消息
a = p.x;        // 发送 x 的 getter 消息
b = p.y;        // 发送 y 的 getter 消息

类变量

类变量是类中所有对象共享的值。类变量声明列表以保留字 classvar 开头，并且可以与实例变量声明列表交错出现。类变量和实例变量一样，只能由类的方法直接访问。类变量也可以使用小于号 < 和大于号 > 符号为它们创建取值方法和赋值方法。

实例方法

类的接口中的消息由该类的方法实现。当向一个对象发送消息时，接收者所属类中名称与该消息选择器匹配的方法会被执行。

方法定义位于类中的类变量和实例变量声明之后。

方法定义在语法上与 FunctionDef 类似。方法定义以消息选择器开头。消息选择器必须是一个标识符或一个二元运算符。方法的参数和变量声明与 FunctionDef 中的语法相同。然而，方法有一个隐式的第一个参数，名为 this，它是消息的接收者。变量 this 可以像方法中的任何其他参数和变量一样被引用。你不能给 this 赋值。

类方法

类方法是实现发送给类对象的消息的方法。一个常见的例子是消息 new，它被发送给类对象以创建该类的新实例。类方法名在消息选择器前带有一个星号 *。

确定对象的类

Object 定义了方法 isKindOf：

anObject.isKindOf(aClass)

如果对象属于该类或其子类之一，则返回 true。

要判断一个对象是否确切为 aClass 类型（而非其子类之一），请使用 class 实例变量和同一性等号：

anObject.class === aClass
