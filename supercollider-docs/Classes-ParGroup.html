ParGroup

服务器上并行组节点的客户端表示

AbstractGroup : Node : Object

说明

并行组是服务器端的节点容器，其工作方式与 Group 类似，但对所含节点没有顺序约束。这意味着在并行架构上，并行组的元素可以并发执行。

类方法

在服务器上立即实例化创建

ParGroup.new(target, addAction: 'addToHead')

来自父类：AbstractGroup

创建并返回一个组。

参数：

target

此组的 target。如果 target 不是组或 Synth，它将按如下方式转换：如果是服务器，则转换为该服务器的 default_group。如果是 nil，则转换为默认服务器的 default_group。

addAction

以下符号之一：

\addToHead

（默认）添加到由 target 指定的组的头部

\addToTail

添加到由 target 指定的组的尾部

\addAfter

紧接在目标之后按其服务器节点顺序添加

\addBefore

在其服务器的节点顺序中紧挨着目标之前添加

\addReplace

替换目标并占据其在服务器节点顺序中的位置

注意：Synth 不是 \addToHead 和 \addToTail 的有效目标。

\addToHead

（默认）添加到由 target 指定的组的头部

\addToTail

添加到由 target 指定的组的尾部

\addAfter

紧接在目标之后按其服务器节点顺序添加

\addBefore

在其服务器的节点顺序中紧挨着目标之前添加

\addReplace

替换目标并占据其在服务器节点顺序中的位置

讨论：

s.boot;
g = Group.new; // 在默认 Server 的默认 group 头部添加一个 Group
h = Group.new(g, \addAfter);
s.queryAllNodes; // 注意默认组（ID 1）内的 Group
g.free; h.free;

添加操作的便捷方法

以下便捷方法对应于上述添加操作：

ParGroup.after(aNode)

来自父类：AbstractGroup

创建一个 Group 并返回它，将其紧接在 aNode 之后添加。

ParGroup.before(aNode)

来自父类：AbstractGroup

创建一个 Group 并立即将其添加到 aNode 之前。

ParGroup.head(aGroup)

来自父类：AbstractGroup

创建并返回一个 Group。如果 aGroup 是一个 Group，则将其添加到该组的头部。如果它是一个 Server，则将其添加到该服务器的 default_group 的头部。如果它为 nil，则将其添加到默认 Server 的 default_group 的头部。

ParGroup.tail(aGroup)

来自父类：AbstractGroup

创建并返回一个 Group。如果 aGroup 是一个 Group，则将其添加到该组的尾部。如果它是一个 Server，则将其添加到该服务器的 default_group 的尾部。如果它为 nil，则将其添加到默认 Server 的 default_group 的尾部。

ParGroup.replace(nodeToReplace)

来自父类：AbstractGroup

创建一个 Group 并返回它，用它替换 nodeToReplace，在其服务器的节点顺序中占据其位置。

不在服务器上实例化的创建

与 Groups 类似，可以在不立即在服务器中创建并行组的情况下创建 ParGroup 对象。

ParGroup.basicNew(server, nodeID)

来自父类：Node

创建并返回一个 ParGroup 对象，而不在服务器上创建组节点。（此方法继承自 Node，此处仅为方便而记录。）

参数：

server

可选的 Server 实例。如果为 nil，则默认为默认服务器。

nodeID

可选的节点 ID 编号。如果未提供，服务器会通过其 NodeIDAllocator 生成一个。通常你不需要提供 ID。

讨论：

详细讨论请参考 Group: *basicNew。

实例方法

示例

fork {
    p = ParGroup.new;
    loop {
        (
            degree: rrand(0.0, 12.0).round(1/4),
            group: p,
            db: rrand(-30, -25),
            pan: rrand(-1.0, 1.0)
        ).play;
        0.2.wait;
    }
}
