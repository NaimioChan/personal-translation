BufSamples

缓冲区中当前的采样数。

BufInfoUGenBase : UGen : AbstractFunction : Object

参见：BufChannels、BufDur、BufFrames、BufRateScale、BufSampleRate

说明

返回当前已分配的采样数。采样与帧不同（请与 BufFrames 比较）；一帧包含缓冲区各声道中的采样。只有单声道缓冲区的采样才与帧相同。

samples = frames * numChannels

类方法

BufSamples.kr(bufnum)

来自父类：BufInfoUGenBase

BufSamples.ir(bufnum)

来自父类：BufInfoUGenBase

参数：

bufnum

缓冲区索引。

讨论：

警告： .ir 方法并不是最安全的选择。由于缓冲区随时可能被重新分配，使用 .ir 不会跟踪这些变化。

实例方法

示例

// 例如；此 buffer 是单声道，所以采样数等于帧数
b = Buffer.read(s, ExampleFiles.child);

// 使用相位器进行索引
{ BufRd.ar(1, b, Phasor.ar(0, BufRateScale.kr(b), 0, BufSamples.kr(b))) }.play;

// 手动索引
{ BufRd.ar(1, b, K2A.ar(MouseX.kr(0, BufSamples.kr(b)))) }.play;

b.free;
