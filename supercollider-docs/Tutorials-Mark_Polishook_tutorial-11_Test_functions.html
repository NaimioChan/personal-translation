函数与 .scope 消息

试听合成过程的一个简单方法是在函数中测试它们。为此，请向函数追加一个 .scope 或 .play 消息。.scope 消息仅适用于内部服务器，它会显示声波的视觉表示。

////////////////////////////////////////////////////////////////////////////////////////////////////

启动（打开）服务器

s.boot;

运行这个示例，并查看示波器窗口。

// 在函数中测试合成过程
(
    {
        SinOsc.ar([440.067, 441.013], 0, 1)
        *
        SinOsc.ar([111, 109], 0, 0.2)
    }.scope;
)

////////////////////////////////////////////////////////////////////////////////////////////////////

代码可以从测试函数转移到 synthdef 中。在下面的示例中，函数（上方）的代码是 Out ugen 的第二个参数。

(
SynthDef("ringMod", {
    Out.ar(
        0,
        SinOsc.ar([440.067, 441.013], 0, 1)
        *
        SinOsc.ar([111, 109], 0, 0.2)
    )
}).add;
)

Synth("ringMod")

多通道扩展

用数组在任意参数（控件）槽中把 ugen 扩展为两个声道。

{ Saw.ar([500, 933], 0.1) }.scope;

另一种（更长的）写法是

{ [ Saw.ar(500, 0.1), Saw.ar(933, 0.1)] }.scope;

通过向数组添加值，将 ugen 扩展为三个通道。

{ Saw.ar([500, 933, 2033], 0.1) }.scope;

// 4 个声道

{ Saw.ar([500, 933, 2033, 895], 0.1) }.scope;
