PdefGui

一行用于 Pdef 的编辑控件，以及可选的其 envir

参见：PdefAllGui、TdefGui、TdefAllGui、EnvirGui

说明

一个显示 Pdef 的名称、播放状态、源状态和 envir 状态的 gui。可选地，其 envir 也可以被编辑。

第一个示例

g = PdefGui();            // 创建 PdefGui
g.object = Pdef(\a);        // 显示 Pdef 何时被放入
Pdef(\a, Pbind(\note, 12));     // 显示它是否有源
Pdef(\a).play;             // 显示正在播放、已停止或已结束，以及是否可暂停
Pdef(\a).set(\dur, 0.25);     // 显示 Pdef 是否有环境
g.close;

g = PdefGui(Pdef(\a), 3);    // 带有用于 3 个项目的 envirgui
Pdef(\a).set(\lofreq, [1, 10], \str, "someString", \oops, \oneSymbolTooMany);
Pdef(\a).clear;
Pdef(\a).envir.clear;
g.close;

(                // 将其放入现有窗口——边距为 0@0
w = Window("my win", Rect(200, 200, 300, 200)).front;
w.addFlowLayout;
PdefGui(Pdef(\a), 0, w);
PdefGui(Pdef(\a), 3, w);
)

GUI 元素的详细信息

名称按钮

选中时，按删除键将删除其 Pdef。

播放/停止按钮

指示 Pdef 是否正在播放：

" >"

如果已停止，

" _"

如果正在播放且处于活动状态，

" |"

如果正在播放，但流已结束。

暂停/恢复按钮

仅当可以暂停或恢复 Pdef 时可见，即在其播放时。

"paus"

在可以暂停时显示，

"rsum"

在可以恢复时显示。

src 按钮

打开一个文档以编辑 Pdef 的源代码（函数）。

green

存在一个源，

white

源为 nil。

env 按钮

打开一个文档来编辑 Pdef 的环境，在这里可以保存 Pdef 使用的所有变量以便于访问。

green

该 Pdef 有一个 envir，

white

envir 为 nil。

类方法

创建方法

.new

创建一个新的 JITGui，它将监视一个对象并显示其状态。

参数：

object

要监视的对象

numItems

要使用的显示项数量，例如用于文本的字段数量，或用于单数值参数的 EZSlider 数量。

parent

用于显示的父视图。如果为 nil，则创建一个新窗口；parent 也可以是一个已存在的窗口或复合视图。

bounds

用于显示 JITGui 的期望尺寸和位置。可以是 nil、Point 或 Rect。JITGui 知道自己的最小尺寸（minSize），如果 bounds 为 nil，则使用 minSize。如果 bounds 是 Point 或 Rect，它将被设置为至少 minSize。使用 rect 还可以提供显示位置。如果是 point，则显示的尺寸为 bounds 与 minSize 中的最大值。

makeSkip

是否创建 skipjack 的标志。

options

附加信息列表，例如关于可选按钮的标志。（这在某些子类中使用）

实例方法

.object

一个 Pdef，或 nil

.numItems

envirGui 中的项数

.parent

父视图

.bounds

-zone 的边界

.zone

显示 PdefGui 所在的 CompositeView

.nameBut

.playBut

.pauseBut

.srcBut

.envBut

按钮

.envirGui

Pdef 的 envir 的 gui - 如果 numItems 为 0 则为 nil。

.object

将一个对象放入 GUI。

.moveTo

（如果 jitGui 位于其自身的窗口中）

将其移动到某个具体位置。

.clear

（如果 jitGui 位于其自身的窗口中）

将 PdefGui 的对象设为 nil

.close

（如果 jitGui 位于其自身的窗口中）

并关闭其窗口。

内部方法

.srcString

一个可重建该 Pdef 的 compileString。

// 假设上面的 g 仍然存在
g.srcString;

.editString

一个在 edKey 处重建 Pdef 环境（envir）的 compileString。

.editStrings

一个 compileString，用于在 edKeys 处重建 Pdef 的环境。

参数：

edKeys

默认值为 nil。

// 假设上面的 g 仍然存在
g.editString;
Pdef(\a).set(\foo, \bar);
g.editString(\foo);

g.editStrings;

.getUsedKeys

envir 中正在使用的键

g.getUsedKeys;

.openDoc

在某个位置打开一个包含一些字符串的文档

g.openDoc(g.editStrings);

.makeEnvirGui

在 zone 内创建一个 envirGui —— 内部调用。

示例

Pdef(\a, Pbind(\freq, Prand((1..16) * 55, inf)));
Pdef(\a).play;
t = PdefGui(Pdef(\a), 4);
Pdef(\a).set(\dur, 0.125, \amp, 0.05);

Pdef(\a).stop;
Pdef(\a).play;
Pdef(\a).pause;
Pdef(\a).resume;

t.object_(nil);
t.object_(Pdef(\a));

(
w = Window("put it in a selfmade window").front;
w.addFlowLayout;
w.view.decorator.shift(50, 50);
PdefGui(Pdef(\a), 12, w);
)

Pdef(\b, Pbind(\note, Pxrand((0..7), inf), \dur, 0.125));
Pdef(\b).play;
PdefGui(Pdef(\b));

    // 查看所有 Pdef：
PdefAllGui(16);
