DetectIndex

在缓冲区中搜索值

Index : PureUGen : UGen : AbstractFunction : Object

说明

在缓冲区中线性搜索某个值（即从开头遍历缓冲区中的帧，检查浮点数是否相等），并返回该值首次出现的索引。如果未找到该值，则返回 -1。每当检测到 in 参数发生变化时，对象都会执行一次搜索；bufnum 参数的变化不会触发搜索。变化检测以选定的速率（ar 或 kr）进行。

类方法

DetectIndex.ar(bufnum, in: 0.0, mul: 1.0, add: 0.0)

来自父类：Index

DetectIndex.kr(bufnum, in: 0.0, mul: 1.0, add: 0.0)

来自父类：Index

参数：

bufnum

缓冲区的索引

in

输入信号。

返回值：

value 首次出现的索引，如果未找到 value 则为 -1。

实例方法

示例

(
var max = 300;
t = Array.series(max, 0, 1).curdle(0.06).scramble.flat;
b = Buffer(s, t.size, 1);

// 分配并设置这些值
s.listSendMsg(b.allocMsg(b.setnMsg(0, t)));


{
    var index, in, out, f0, fdiff;
    var bufnum = b;
    var input;
    input = MouseX.kr(0, max).round(1); // 四舍五入到整数
    index = DetectIndex.kr(bufnum, input);
    index.poll;
    SinOsc.ar(index.linexp(0, max, 200, 700)) * 0.1
}.play;
)

b.free;
