Synth 定义文件格式

SC 合成服务器使用的 Synth Definition 文件格式说明

参见：SynthDef

Synth 定义文件由 synth 服务器读取，定义 unit generator 的集合及其连接。这些文件目前由 SuperCollider 语言应用程序写入，但理论上可以由任何程序写入。这样的程序需要了解 SC 的 unit generator 及其特性，例如输入和输出的数量以及可用的计算速率。写入这些文件的代码是开放的，可在 SuperCollider 语言应用中获取。

在当前 SuperCollider 3.6 开发版本中，有两种版本的 SynthDef：

  • SynthDef - 原始的 SynthDef 文件格式，与使用早期版本 SuperCollider 保存的 .scsyndef 文件向后兼容。
  • SynthDef2 - 一个修订版本，扩展了 SynthDef 的能力。

本文档描述 SynthDef2 的格式。有关 SynthDef 和 SynthDef2 之间的差异，请参阅 原始 SynthDef 格式。

基本类型

所有数据以大端序存储。除非另有说明，所有整数均为有符号数。所有数据均为紧凑打包，无填充或对齐。

int32

一个 32 位整数。

int16

一个 16 位整数。

int8

一个 8 位整数。

float32

一个 32 位 IEEE 浮点数。

pstring

一个 pascal 格式字符串：一个字节（无符号 int8）给出长度，后跟该长度的字节。

文件格式

一个 synth-definition-file 是：

  • int32 - 四字节文件类型 ID，包含 ASCII 字符："SCgf"
  • int32 - 文件版本，当前为 2。
  • int16 - 此文件中合成器定义的数目 (D)。
  • [ synth-definition ] * D

一个 synth-definition 是：

  • pstring - synth 定义的名称
  • int32 - 常量数量 (K)
  • [float32] * K - 常量值
  • int32 - 参数数量 (P)
  • [float32] * P - 初始参数值
  • int32 - 参数名称数量（N）
  • [ param-name ] * N
  • int32 - 单元生成器数量（U）
  • [ ugen-spec ] * U
  • int16 - 变体数量 (V)
  • [ variant-spec ] * V

param-name 是：

  • pstring - 参数的名称
  • int32 - 它在参数数组中的索引

ugen-spec 的定义是：

  • pstring - SC 单元发生器类的名称
  • int8 - 计算速率
  • int32 - 输入数量 (I)
  • int32 - 输出数量（O）
  • int16 - 特殊索引
  • [ input-spec ] * I
  • [ output-spec ] * O

input-spec 是：

  • int32 - 单元生成器的索引，或常量则为 -1

  • if (unit generator index == -1) :

    • int32 - 常量索引

  • else :

    • int32 - 单元生成器输出的索引

一个 output-spec 是：

  • int8 - 计算速率

一个 variant-spec 是：

  • pstring - 变体的名称
  • [float32] * P - 变体初始参数值

原始 SynthDef 格式

原始 SynthDef 格式的不同之处在于以下各项为 int16 而非 int32。

注意： 以下列表描述了 SynthDef 与 SynthDef2 之间的变化。它并非对原始 SynthDef 文件格式的完整描述。

  • int32 - 文件版本，当前为 1。（对于新格式，此为 2。）

  • 一个 synth-definition 是：

    • int16 - 常量数量 (K)
    • int16 - 参数数量 (P)
    • int16 - 参数名称数量（N）
    • int16 - 单元生成器数量（U）

  • 参数名是：

    • int16 - 它在参数数组中的索引

  • ugen-spec 是：

    • int16 - 输入数量 (I)
    • int16 - 输出数量（O）

  • input-spec 是：

    • int16 - 单元生成器的索引，或常量则为 -1
    • int16 - 常量索引
    • int16 - 单元生成器输出的索引

Glossary

计算速率

计算执行的速率。共有三个速率，编号为 0、1、2，如下所示：

0 = 标量速率

仅在初始化时计算一个采样。

1 = 控制速率

每个控制周期计算一个采样。

2 = 音频速率

为音频输出的每个采样计算一个采样。

输出有自己的计算速率。这使得 MultiOutUGen 可以拥有不同速率的输出。单输出 unit generator 的计算速率应与其输出一致。

constant

一个用作单元生成器输入的单个浮点值。

parameter

一个可以使用服务器命令 /s.new、/n.set、/n.setn、/n.fill、/n.map 从外部控制的值。

参数名

一个字符串，用于命名参数数组中的索引。这样即使在不同的 Synth 中，'freq' 或 'pan' 等语义值存在于各自参数数组的不同偏移处，也可以引用相同的语义值。

特殊索引

某些单元生成器会将此值用于特殊目的。例如，UnaryOpUGen 和 BinaryOpUGen 用它来指示执行哪个运算符。如果未使用，则应将其设为零。

synth

一组一起执行的单元生成器。synth 是一种节点。

synth 定义

用于创建 synth 的规格说明。

单元生成器

一个基本的信号处理模块，带有输入和输出。unit generators 连接在一起构成 synths。

Notes

单元生成器按它们将被执行的顺序列出。输入必须引用常量或之前的单元生成器。不允许反馈环路。反馈必须通过延迟线或通过总线来实现。

为获得最高效率：

单元生成器应按能够高效复用连接缓冲区的顺序排列，这意味着对图进行深度优先拓扑排序比广度优先更可取。

常量表中不应有重复值。
