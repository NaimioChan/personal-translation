AppClock

运行在主应用线程上的时钟

Clock : Object

另请参阅：SystemClock、TempoClock

说明

SystemClock 更精确，但无法调用 GUI 原语。

你需要使用 SystemClock 来获得准确/符合音乐性的调度。

有关时钟如何运作的一般说明，请参见 Clock。

类方法

AppClock.sched(delta, item)

你返回的浮点数指定了重新调度该函数的增量。返回 nil 将阻止任务被重新调度。

(
AppClock.sched(0.0, { |time|
    ["AppClock has been playing for ", time].postln;
    rrand(0.1, 0.9);
});
)
(
t = Main.elapsedTime;
"It is now % seconds after the computer booted.".format(t).postln;
AppClock.sched(2.0, { "It is now % sec later".format(Main.elapsedTime - t).postln; nil })
)

AppClock.schedAbs(time, item)

调度一个任务在特定时间执行。由于 AppClock 并非用于高精度调度，因此该时间是近似的。

当调度时间到达时，会调用该任务的 awake 方法。如果该方法返回一个数字，任务将被重新调度，时间为上一次调度时间加上返回的值。

另请参见：Clock: Scheduling、Object: -awake。

(
t = Main.elapsedTime;
"It is now % seconds after the computer booted.".format(t).postln;
AppClock.schedAbs(t + 1.0, { "It is now % sec later".format(Main.elapsedTime - t).postln; nil })
)

AppClock.clear

清除 AppClock 的调度器以停止它。

AppClock.clear;

AppClock.play(task)

来自父类：Clock

Routine（或 Task）产生一个浮点值，指示 AppClock 在恢复 Routine 之前等待的增量（秒）。

(
var w, r;
w = Window.new("trem", Rect(512, 256, 360, 130));
w.front;
r = Routine({ |appClockTime|
    ["AppClock has been playing for secs:", appClockTime].postln;
    60.do({ |i|
        0.05.yield;
        w.bounds = w.bounds.moveBy(10.rand2, 10.rand2);
        w.alpha = cos(i*0.1pi)*0.5+0.5;
    });
    1.yield;
    w.close;
});
AppClock.play(r);
)

AppClock.tick

AppClock.tick 由 SuperCollider 语言解释器定期调用。它会更新 Scheduler 并导致任何已调度的任务被执行。你绝不应自己调用此方法。
