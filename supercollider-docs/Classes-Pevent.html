Pevent

为事件流提供一个 inval。

Pattern : AbstractFunction : Object

另请参阅：Pkey、Pchain

此模式主要用于两种情况：

直接使用事件模式作为流
a = Pbind(\note, Prand([1, 2, 3], inf)).asStream;
a.next; // 返回 nil
a = Pevent(Pbind(\note, Prand([1, 2, 3], inf))).asStream;
a.next; // 返回一个事件
在处理之前设置一些默认值
Pevent(Pbind(\harmonic, Pseq([24, 25, 29, 30], inf)), (octave: 3, dur: 0.2)).trace.play;

Pevent 是 Pchain 的一种更简单的形式，因此这些是等价的：

Pevent(pattern, event)
Pchain(pattern, event)
pattern <> event

与 Pchain 不同，Pevent 在未提供时会使用 Event: *default。

类方法

Pevent.new(pattern, event)

参数：

pattern

返回或修改事件的模式或流。

event

一个包含要嵌入对象的 event。若未提供，则使用 Event: *default。
