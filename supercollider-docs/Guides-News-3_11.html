SC 3.11 中的新闻摘要

新功能 - 支持 Ableton Link。参见 sclang: Added

文档改进（#4759、#4732、#4744、#4697、#4326、#4673、#4610、#4515、#4389、#4355、#4333、#4222、#4198、#4144、#4123、#4148、#4140、#4080、#4078、#4057、#4016、#4027、#3925、#3953、#3954、#3912、#3929）

常规：新增

为基于 cookiecutter 的插件开发添加了 NOVA_SIMD 构建选项（#4354）

常规：已更改

将 RPi 和 BeagleBone 的 README 文件移入主仓库。（#4639）

构建系统中版本号编号的处理方式已经改革。这主要影响构建，但也需要对类库进行更改（见 class library: deprecated）（#4706）

scel 已更新（#4712、#4700）

scvim 已更新（#4197）

CONTRIBUTING.md 和 DEVELOPING.md 已更新并移至 wiki（#4503、#4297、#4028）

README_LINUX.md 已更新（#4397、#4159）

问题模板已更新（#4271）

拉取请求模板已更新（#4272）

macOS 构建现在要求 >= 10.10。文档和 travis 构建已更新以反映这一点（#4068）

常规：修复

修复了 macOS 上 supernova 的链接问题（#4764）

修复了使用系统 boost 或 yaml-cpp 时的构建问题（#4185）

scsynth 和 supernova：已添加

macOS：为 scsynth 和 supernova 添加了 cocoa 事件循环，以便未来进行 VST 集成工作（#4499）

为插件接口添加了缺失的无缓冲区别名标志（#4356）

scsynth 和 supernova：已更改

替换了时钟使用的魔数（#4714）

supernova 现在在异步请求中对 OSC 消息具有更确定的排序（#4460）

scsynth 和 supernova：已修复

修复了 scsynth 和 supernova 预处理器指令的问题（修复了 (#4504) 中提出的问题）(#4784)

修复了使用 JACK 时时钟抖动的问题（#4599）

修复了 Windows 不会防范非规格化数（denormals）的问题，该问题会导致 CPU 占用过高 (#4504)

修复了在 macOS 上使用 portaudio 时 coreaudio 无法对音频流进行重采样的问题（#4477）

修复了一个错误的 include，该错误曾导致 supernova 在某些情况下无法编译（#4018）

UGen：已修复

修复了 EnvGen 上 Done 标志的问题（#4789）

修复了 EnvGen 对非门控包络进行门控的问题（#4436）

sclang：已添加

Ableton Link 支持来了！查看 LinkClock 类以获取更多信息。（#4331、#4340、#4337）

添加 PortAudio 绑定以允许在 Windows 上列出音频设备（#4742）。

sclang：已修复

修复了重新编译类库时 TCP 连接未正确关闭的问题（#4518）

修复了 LanguageConfig 有时存储到错误位置的问题（#4680）

修复了若干与垃圾回收相关的问题，这些问题有时会使解释器变得不稳定（#4192）

类库：新增

新增 Platform.architecture 以允许检测系统架构（#4524）

添加了 File.deleteAll，以便删除给定路径内的所有文件——用于善，而非恶（#3921）

新增了更灵活的方式来修改与 SynthDef 参数相关的 ControlSpec（#3814）

添加了在 Windows 上通过 ServerOptions.inDevices、ServerOptions.outDevices 和 ServerOptions.devices 列出音频设备的支持（#4742）

向默认 Event 原型添加了 'composite' 事件类型（#4441）

新增了 SequenceableCollection:unixCmdGetStdOut，用于捕获外部程序的标准输出（#3539）

添加了 String.parseJSON 和 String.parseJSONFile 作为 parseYAML 的别名（#3956）

向 UnitTest 添加了 debug 方法（#3623）

类库：已更改

改进 Ndef 参数的拖拽功能（#4093）

Collection:== 已优化为在判断同一性时提前退出，并由子类继承（#3962）

作为版本重构的一部分，Main.versionAtMost 和 Main.versionAtLeast 现在接受第三个参数用于指定微调级别（例如现在可以检查 3.10.4）(#4706)

一些 UnitTest 现在打印更少的换行符，并且内联警告已修复（#4716）

NodeProxy:set 现在可与任意对象一起使用（#4090）

UnitTest 方法现在彼此隔离（#3836）

增加了与服务器建立 TCP 连接的最大尝试次数（#4481）

PlotView.plotColors 已弃用（#4678）。请改用 plotColor。

Object.asInt 已弃用（#4089）。请改用 Object.asInteger。

修复了 NamedControl 在某些情况下会错误地将 name 转换为 String 的问题（#4761）。
