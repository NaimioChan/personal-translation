GVerb

双通道混响

MultiOutUGen : UGen : AbstractFunction : Object

参见：FreeVerb、FreeVerb2

说明

一个双声道混响 UGen，基于 Juhana Sadeharju（kouhia at nic.funet.fi）的 "GVerb" LADSPA 效果。

已知问题

  • 当合成器被实例化且所有延迟线被清零时，会出现较大的 CPU 峰值。
  • roomsize 的变化会导致音高偏移和噪声。

类方法

GVerb.ar(in, roomsize: 10, revtime: 3, damping: 0.5, inputbw: 0.5, spread: 15, drylevel: 1, earlyreflevel: 0.7, taillevel: 0.5, maxroomsize: 300, mul: 1, add: 0)

参数：

in

单声道输入。

roomsize

单位为平方米。

revtime

以秒为单位。

damping

0 到 1，高频滚降，0 完全衰减混响信号，1 完全不衰减。

inputbw

0 到 1，与阻尼控制相同，但作用于输入信号。

spread

对混响信号的立体声扩散和扩散度进行控制。

drylevel

干信号量。

earlyreflevel

早期反射电平量。

taillevel

尾音电平量。

maxroomsize

用于设置延迟线的大小。默认值为 roomsize + 1。

mul

add

实例方法

示例

(
SynthDef(\test, { |out, roomsize, revtime, damping, inputbw, spread = 15, drylevel, earlylevel,
    taillevel|

    var a = Resonz.ar(
        Array.fill(4, { Dust.ar(2) }),
        1760 * [1, 2, 4, 8],
        0.01
    ).sum * 10;

    //    var a = SoundIn.ar(0);
    //    var a = PlayBuf.ar(1, 0);

    Out.ar(out,
        GVerb.ar(
            a,
            roomsize,
            revtime,
            damping,
            inputbw,
            spread,
            drylevel.dbamp,
            earlylevel.dbamp,
            taillevel.dbamp,
            roomsize, 0.3)
        + a
    )
}).add
)
