Qt GUI 中的新特性

Qt GUI 新特性与差异概述

本文档面向已经熟悉 SuperCollider 中图形用户界面编程的读者。如果你刚接触这一主题，建议先阅读GUI 简介。

为便于本指南说明，让我们切换到 Qt GUI：

GUI.qt

视图层级

每个视图都可以是一个窗口

每个视图都可以单独作为窗口显示，而无需使用 Window 类。因此，Window 中存在的多数方法在 View 中也同样存在。

例如，你可以使用 View: -front 方法显示任意视图，而无需将其嵌入 Window 或另一个容器视图中。因此，在构建视图时省略 'parent' 参数是有效的——任何没有父视图的视图都可以作为窗口显示：

(
x = SoundFileView().front;
x.load(ExampleFiles.child);
)

每个视图都可以是容器

每个视图都可以包含其他视图（即作为它们的父视图）。因此，如果你想将多个视图组合在一起，只需使用一个 View 作为容器：

(
v=View(bounds:300@300);
5.do { |i|
    Slider(v).moveTo(i * 25 + 10, 10);
};
v.front;
)

布局管理

Qt 布局系统让你无需关心像素——它会自动管理父视图中子视图的大小和位置。

固有视图尺寸

你可能已经注意到，在上面的示例中，除了省略 parent 参数之外，我们在构造视图时有时也省略了 bounds 参数。这是可行的，因为视图具有内在定义的偏好尺寸和最小尺寸。更多解释请参阅 Layout Management: Intrinsic view sizes。

布局类

一组布局类允许你将其中一个与父视图和若干子视图关联，它会根据子视图的尺寸偏好和约束自动管理子视图的位置和尺寸。当你调整窗口大小时，它也会动态地进行管理：

(
w = Window.new(bounds:Rect(100,100,300,80)).layout_(
    VLayout (
        HLayout(
            Button().states_([["Super"]]),
            TextField().string_("Collider")
        ),
        Button().states_([["SuperCollider"]])
    )
).front;
)

详细说明请参见 布局管理 指南。

颜色管理

调色板

Qt 具有调色板的概念——一个供视图在绘制自身时选取颜色的集合。它由 QPalette 类表示，并可通过 View: -palette 在视图上设置。

默认情况下，窗口会获得全局调色板（ QtGUI: *palette ），并且子视图会从父视图继承该调色板。因此，除非在某个特定子视图上覆盖了调色板，否则更改父视图的调色板也会影响其子视图。你可以通过更改全局调色板轻松改变整个 GUI 的外观。

预定义调色板

有两个预定义调色板（QPalette: *light 和 QPalette: *dark），你还可以访问操作系统的原生调色板（QPalette: *system）：

尝试用下面的代码更改全局调色板；如果你启用了 Qt GUI，这也会影响此窗口：

QtGUI.palette = QPalette.dark;

QtGUI.palette = QPalette.light;

QtGUI.palette = QPalette.system;

视图动作与钩子

鼠标和按键事件传播

除了按键事件，鼠标事件也可以传播到父视图。

此外，在 Qt 中对事件传播的控制方式有所不同。详细说明请参见 View：按键和鼠标事件处理。

此外，你可以使用 View: -acceptsMouse 让视图对鼠标事件透明，这会把所有鼠标事件转发给下方的视图，无论它们是否处于父子关系中。

(
var win, parent, child, sibling1, sibling2;
win = Window(bounds:Rect(30,30,300,300));
parent = Slider2D(win, win.bounds.moveTo(0,0).insetBy(50,50));

// 默认情况下，StaticText 会将鼠标点击传递给父级：
child = StaticText(parent, Rect(100,-50,150,150))
    .align_(\bottomLeft)
    .string_("\npropagate\nto\nSlider2D")
    .background_(Color.red.alpha_(0.4));

// 这个 StaticText 不是 Slider2D 的子节点，因此会将鼠标
// 点击传播到窗口：
sibling1 = StaticText(win, Rect(0,0,150,150))
    .align_(\topLeft)
    .string_("propagate\nto\nWindow")
    .background_(Color.cyan.alpha_(0.4));

// 这个 StaticText 不是 Slider2D 的子对象，但为鼠标事件做了透明处理：
sibling2 = StaticText(win, Rect(150,150,150,150))
    .align_(\bottomRight)
    .string_("ignore")
    .background_(Color.green.alpha_(0.4))
    .acceptsMouse_(false);
win.view.mouseDownAction = { win.background = Color.red(0.6) };
win.view.mouseUpAction = { win.view.palette = QPalette() };
win.front;
)

扩展的鼠标交互

许多 Qt 视图已经实现了某种形式的鼠标滚轮交互。例如，你可以使用鼠标滚轮滚动 ScrollView、ListView 和 TreeView。你也可以使用鼠标滚轮改变 Slider 或 Knob 的值。此外，你可以使用 View: -mouseWheelAction 为鼠标滚轮事件分配你自己的动作：

当鼠标进入或离开视图时，还会触发另外两个便捷的新鼠标动作：View: -mouseEnterAction 和 View: -mouseLeaveAction：。

(
var val = 1.0;
t=StaticText(bounds:Rect(30,30,100,100))
    .font_(Font(size:25))
    .align_(\center)
    .string_(val.asString)
    .stringColor_(Color.red)
    .background_(Color.black)
    .front;
t.mouseEnterAction = { t.background = Color.white };
t.mouseLeaveAction = { t.background = Color.black };
t.mouseWheelAction = { |v,x,y,mod,dx,dy|
    if(dy > 0) { val = val + 0.05 } { val = val - 0.05 };
    val = val.clip(0,2).round(0.01);
    t.string = val.asString;
    t.stringColor = Color.red(val);
};
)

位置和大小变化的钩子

由于视图可以被布局自动重新定位和调整大小，或者由用户调整（如果是窗口的话），使用 View: -onMove 和 View: -onResize 让你的视图响应这些变化可能会很方便。

(
var view, update;
update = { |v|
    var bounds = v.bounds;
    v.string = "%@%\n%x%".format(
        bounds.left,
        bounds.top,
        bounds.height,
        bounds.width
    );
};

x = StaticText(bounds:Rect(100,100,200,200)).align_(\center).font_(Font(size:25));
x.onMove = update;
x.onResize = update;
update.(x);

x.front;
)

Enhancements

Stethoscope

Qt 带来了 Stethoscope 的新实现，它使用共享内存，允许在任何本地服务器上高效地监测总线。

各个类（如 Server、Bus、Function 等）中所有“scope”方法都已接入这一新实现，因此你无需自行实例化 Stethoscope。

Server.local.scope;

SoundFileView

SoundFileView 具有无限显示分辨率。这意味着你可以始终放大波形，直到看到单个声音帧。

它还提供了便捷的鼠标交互用于缩放和滚动：

  • shift + 右键 + 鼠标松开/按下 = 缩放
  • 右键 + 鼠标左键/右键 = 滚动
(
var x = SoundFileView().front;
x.load(ExampleFiles.child);
)

除了显示声音文件，你也可以分配空数量的显示帧，然后用数据逐部分填充以进行显示（参见 SoundFileView: -alloc 和 SoundFileView: -set 的文档）。例如，这可以实现对录制到缓冲区的高效监控。

(
var v, s;
v = SoundFileView().front;
s = Signal.sineFill(1000, 1.0/[1,2,3,4]);
v.alloc(5000, samplerate: 500);
3.do { |i| v.set( i * 2000, s * (1/(i+1)) ) };
)

EnvelopeView

EnvelopeView 提供两种不同的显示样式：除了节点绘制为内部带标签的矩形的传统样式外，它还可以将节点绘制为小圆点，标签位于其旁。参见 EnvelopeView: -style。

(
var w, e, m;
e = EnvelopeView()
    .value_([[0,0.4,0.6,1.0],[0,0.7,0.5,0.56]])
    .strings_(["alpha", "beta", "gamma", "delta"])
    .thumbWidth_(60)
    .style_(\dots);
m = PopUpMenu()
    .items_(["Dot Style", "Rect Style"])
    .action_({e.style = m.value});
w = Window()
    .layout_(VLayout(m,e))
    .front;
)

你可以在时间轴上强制实施严格的节点顺序。在这种情况下，节点不能移动到前一个节点之前，或后一个节点之后。参见 EnvelopeView: -keepHorizontalOrder 及下面的示例。

你还可以控制节点选择在移动时的行为：它既可以保持形状刚性地移动，并在遇到视图边缘或其他节点时完全阻止移动，也可以根据障碍物调整其形状，从而允许那些未被单独阻挡的节点移动。参见 EnvelopeView: -elasticSelection 及以下示例。

示例：尝试选择多个节点（按住 Shift 键单击它们）并移动它们，然后使用菜单切换选择的行为方式，并重复操作：

(
var w, e, m;
e = EnvelopeView()
    .value_([
        [0, 0.1, 0.3, 0.4, 0.55, 0.7, 1.0],
        [0, 1.0, 0.7, 0.3, 0.5, 0.2, 0]
    ])
    .keepHorizontalOrder_(true)
    .elasticSelection_(true)
    .front;
m = PopUpMenu()
    .items_(["Elastic Selection", "Rigid Selection"])
    .action_({e.elasticSelection = m.value == 0});
w = Window()
    .layout_(VLayout(m,e))
    .front;
)

ScrollView

ScrollView 允许用任意视图替换画布，该画布用于容纳其子视图。这提供了极大的灵活性，包括使用布局来管理子视图。相关说明请参见 ScrollView: -canvas，以及这个示例。

新视图

TreeView

TreeView 是显示一组项目的视图组（包括 ListView 和 PopUpMenu）的一个强大补充。它以分层方式显示组织好的项目，类似于文件系统浏览器。

与仅将项目排列在一列中的 ListView 不同，TreeView 可以由 多个列 组成：每个项目占据一行，并且每列可以包含一个文本值。列还具有 带标签的表头。

此外，项的每个数据字段还可以包含另一个视图，这为项之间的交互提供了巨大的潜力。

WebView

WebView 是网页浏览的核心组件。它也在 Cocoa GUI 中实现，但我们仍在此处列出。

它是一个显示网页的视图，其 Web 技术支持可与广泛使用的桌面 Web 浏览器相媲美。

注意： 目前显示多媒体内容可能存在一些问题。

(
w = WebView(bounds: Window.screenBounds.insetBy(100,40))
    .url_("http://supercollider.sourceforge.net/")
    .front;
)
