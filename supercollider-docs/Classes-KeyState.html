KeyState

响应按键的状态

UGen : AbstractFunction : Object

另请参见：MouseButton、MouseX、MouseY

说明

响应按键状态。

注意： 注意，此 UGen 不会阻止正常的键入。因此，在使用 KeyState 时，选择 GUI 窗口而不是 SC 文档可能会有帮助，因为后者会因任何按键而改变。

警告： 此 UGen 在 Linux 用户使用 Wayland 时无法工作，因为 Wayland 协议不允许捕获全局键盘或鼠标状态。该 UGen 将返回常量值 0.0。更多信息见 https://github.com/supercollider/supercollider/issues/4544

警告： MacOS 用户需要将 SuperCollider 应用添加到“隐私与安全性”偏好设置中的输入监控组，才能捕获所有按键。参见 https://support.apple.com/en-us/guide/mac-help/mchl4cedafb6/mac

类方法

KeyState.kr(keycode: 0, minval: 0, maxval: 1, lag: 0.2)

参数：

keycode

要检查的按键的 keycode 值。这对应于传入 SCViews 的 keyDownActions 的 keycode 值。参见下面的示例。

minval

当按键未按下时输出的值。

maxval

按键按下时要输出的值。

lag

滞后系数。

实例方法

示例

s.boot;

// 执行下面的代码以找出某个键的键码
// 你按下的任何键的字符和键码都会打印在 post 窗口中
(
w = Window.new("I catch keystrokes");
w.view.keyDownAction = { |view, char, modifiers, unicode, keycode|  [char, keycode].postln };
w.front;
)

// 然后执行这个，再按 'j' 键
(
w.front; // 可以安全输入的东西
{ SinOsc.ar(800, 0, KeyState.kr(38, 0, 0.1)) }.play;
)
