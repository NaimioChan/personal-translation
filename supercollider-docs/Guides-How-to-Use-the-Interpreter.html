如何使用解释器

运行代码的基础教程

本文档在按键命令方面针对 macOS（SCapp）特定，但其原则适用于所有平台。其他编辑器中的按键命令请参见帮助文件 Keyboard Shortcuts。有关 emacs 的 sclang 接口，另请参见 Emacs Editor 的专门文档。

你可以通过点击某一行的任意位置并按 'Enter' 键来执行该行中的任意单行表达式。注意，'Enter' 键与 'Return' 键并不相同。如果你没有 enter 键，可以使用 ctrl-Return、Ctrl-c、fn-Return（部分 Mac 上）或 Shift-Return。

在听到任何示例之前，你需要先启动默认服务器。按照惯例，默认服务器被赋值给解释器变量 's'。（启动时默认将是 localhost 服务器。）你可以通过按下 localhost 服务器窗口上的 'Boot' 按钮来启动服务器应用程序，也可以用代码来实现：

// 将光标放在行上然后按 'enter'，一次执行一行这些代码

s.boot; // 这会启动默认的 Server。请观察 post 窗口和 server 窗口以查看结果

// 完成后执行此操作以发出声音
{ FSinOsc.ar(800, 0, 0.1) }.play;

（按住 Cmd（Apple 键）然后按句点键以停止上面启动的声音。）

在帮助文件中，所有可执行片段均以 Monaco 字体书写。

如果表达式有多行，你可以在输入 'Enter' 之前选中所有行。

// 选中以下全部 9 行并按 'Enter'：
w = Window.new("Fading").front;
r = Routine({
    200.do({|i|
        w.view.background = Color.blue(val: 1, alpha: 1 - (i * 0.005));
        0.005.wait;
    });
    w.close;
});
AppClock.play(r);

有些示例确实需要逐行执行，或者某些行需要先执行。到目前为止，最常见的情况是启动服务器应用，就像我们在页面顶部所做的那样。在服务器完成启动之前，任何产生声音的代码都不会工作。

不过，应用自带的大多数示例都会在执行时同属一组的代码行两侧加上圆括号。（这是您在自己的代码中应遵循的约定。）这样您就能双击左圆括号右侧，选中整个表达式，然后按 'enter' 键。

(
// ^^^^^^^^ 双击此行上方 ^^^^^^^^
play({
// 三个补丁合一……
n = 5;    // 字符串数量
b = [    // 可能的脉冲激励行为数组
        { Impulse.ar(2 + 0.2.rand, 0.3) }, // 缓慢相位
        { Dust.ar(0.5, 0.3) },    // "风铃"
        { Impulse.ar(SinOsc.kr(0.05+0.1.rand, 2pi.rand, 5, 5.2), 0.3) } // races
    ].choose;    // 随机选择一个用于所有声部
Mix.new(
    Array.fill(n, {    // n 个随机调谐到 MIDI 键 60-90 的字符串
        var delayTime;
        // 根据随机音符计算延迟
        delayTime = 1 / (60 + 30.rand).midicps;
        Pan2.ar(
            LeakDC.ar(    // 移除直流累积
                CombL.ar(    // 用作弦谐振器
                    Decay.ar(    // 噪声的衰减包络
                        b.value,// 实例化一个激励器
                        0.04,    // 激励的衰减时间
                        PinkNoise.ar(0.2)),// 用包络乘以噪声
                    delayTime,     // 最大延迟时间
                    delayTime,    // 实际延迟时间
                    4)),         // 弦的衰减时间
            1.0.rand2 // 随机声像位置
        )
    }))
})
)

再次按 Cmd-. 来停止声音。这将随时停止所有音频（并释放服务器上的所有节点）。

完成后，你可以按 localhost 服务器窗口上的 'Quit' 按钮来退出服务器应用，或执行以下代码来退出：

s.quit;
