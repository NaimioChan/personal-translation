07. 混合起来

SuperCollider 入门

另请参阅：00. Getting Started With SC

我们已经看到乘法会改变某个东西的电平，但把 UGen 混合在一起又会怎样呢？这同样很简单。我们只需要加法：

{ PinkNoise.ar(0.2) + SinOsc.ar(440, 0, 0.2) + Saw.ar(660, 0.2) }.play;

Saw 是另一种振荡器，其波形看起来像锯齿。注意我们为 mul 使用了一个较小的值，从而确保最终输出在 -1 到 1 之间而不会削波。

还有一个方便的类叫做 Mix，它可以把一个声道数组混合成单个声道，或者把一个由声道数组组成的数组混合成单个声道数组。请观察 post 窗口以查看 Mix 的结果。

// 一个声道
{ Mix.new([SinOsc.ar(440, 0, 0.2), Saw.ar(660, 0.2)]).postln }.play;

// 合并两个立体声数组
(
{
    var a, b;
    a = [SinOsc.ar(440, 0, 0.2), Saw.ar(662, 0.2)];
    b = [SinOsc.ar(442, 0, 0.2), Saw.ar(660, 0.2)];
    Mix([a, b]).postln;
}.play;
)

在第一种情况下，我们得到一个 'BinaryOpUGen'（在此情况下，这意味着两个 UGen 相加），而在第二种情况下，我们得到一个包含两个 BinaryOpUGen 的数组。

注意，在第一个示例中我们使用 Mix.new(...)，而在第二个示例中使用 Mix(...)。后者是前者的简写形式。'new' 是创建新对象最常见的类方法。某些情况下，对象有多个用于创建对象的类方法，例如 UGen 的 'ar' 和 'kr' 方法。（不过，Mix 实际上只是一个“便捷”类，并不会真正创建 Mix 对象，它只是返回其求和结果，即一个 BinaryOpUGen 或由它们组成的 Array。）

Mix 还有一个名为 fill 的类方法，它接受两个参数。第一个是数字，它决定第二个参数（一个 Function）将被求值多少次。求值的结果将被求和。感到困惑？看看下面的例子：

(
    var n = 8;
    { Mix.fill(n, { SinOsc.ar(500 + 500.0.rand, 0, 1 / n) }) }.play;
)

该函数将被求值 n 次，每次创建一个频率从 500 到 1000 Hz 随机的 SinOsc（500 加上 0 到 500 之间的一个随机数）。每个 SinOsc 的 mul 参数被设为 1 / n，从而确保总振幅不会超出 -1 和 1。只需改变 n 的值，你就可以得到截然不同数量的 SinOsc！（试试看！）这种方法使这段代码极其灵活且可复用。

每次求值 Function 时，都会将迄今为止的求值次数作为参数传递给它。因此，如果 'n' 为 8，Function 将按顺序依次接收到从 0 到 7 递增的值。通过在我们的 Function 内声明一个参数，就可以使用这个值。

// 查看 post 窗口以获取频率和索引
(
    var n = 8;
    {
        Mix.fill(n, { arg index;
            var freq;
            index.postln;
            freq = 440 + index;
            freq.postln;
            SinOsc.ar(freq , 0, 1 / n)
        })
    }.play;
)

通过将加法与乘法（或者实际上几乎任何你能想到的数学过程！）与 Mix 之类的类相结合，我们就拥有了将多声道声源组合成复杂混音和子混音所需的工具。
