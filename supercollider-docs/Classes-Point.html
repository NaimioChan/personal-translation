Point

笛卡尔点

Object

参见：Polar、Complex

子类：PointArray

说明

定义笛卡尔平面上的一个点。

类方法

Point.new(x: 0, y: 0)

定义一个新点。

未文档化的类方法

Point.big(x, y)

实例方法

Accessing

.x

.x = value

获取或设置 x 坐标值。

.y

.y = value

获取或设置 y 坐标值。

.set(argX: 0, argY: 0)

设置点 x 和 y 的值。

Testing

==(aPoint)

返回一个布尔值，表示接收者是否等于该参数。

.hash

返回接收者的哈希值。

Math

+(delta)

Addition.

-(delta)

Subtraction.

*(scale)

Multiplication.

/(scale)

Division.

.translate(delta)

按 Point 相加。

.scale(scale)

与 Point 相乘。

.rotate(angle)

绕原点按以弧度给出的角度旋转。

.abs

点的绝对值。

.rho

返回接收者的极坐标半径。

.theta

返回接收者的极坐标角度。

.dist(aPoint)

返回从接收者到 aPoint 的距离。

.transpose

返回 x 和 y 坐标互换后的 Point。

.round(quant)

将坐标值四舍五入到 quantum 的倍数。

.trunc(quant)

将坐标值截断为 quantum 的倍数。
