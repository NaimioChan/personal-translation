LinPan2

双通道线性声像。

Pan2 : MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：Balance2、Pan2、Pan4、PanAz

说明

双声道线性声像器。当信号从左侧（或右侧）向中央移动时，使用从 1（左或右）到 0.5（中央）的直线进行衰减，在中间产生 6dB 的衰减。线性声像器的一个固有问题在于信号在中央时感知音量会下降。Pan2 通过取线性缩放因子的平方根来解决此问题，该因子从 1（左或右）变化到中央的 0.5.sqrt（约等于 0.707），即约 3dB 的衰减。这就是等功率声像。LinPan2 听起来比 Pan2 更像 Rhodes 颤音。

类方法

LinPan2.ar(in, pos: 0.0, level: 1.0)

来自父类：Pan2

LinPan2.kr(in, pos: 0.0, level: 1.0)

来自父类：Pan2

参数：

in

输入信号。

pos

声像位置，-1 为左，+1 为右。

level

一个控制速率电平输入。

实例方法

示例

// 听听区别，LinPan 在中间有轻微的下沉（是的，很微妙）……
{ LinPan2.ar(SinOsc.ar(440), Line.kr(-1, 1, 5)) }.play;

// ……而 Pan2 更平滑
{ Pan2.ar(SinOsc.ar(440), Line.kr(-1, 1, 5)) }.play;

// 其他示例
{ LinPan2.ar(PinkNoise.ar(0.4), FSinOsc.kr(2)) }.play;

{ LinPan2.ar(FSinOsc.ar(800, 0, 0.1), FSinOsc.kr(3)) }.play;
