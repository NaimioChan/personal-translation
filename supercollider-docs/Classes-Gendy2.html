Gendy2

动态随机合成生成器。

UGen : AbstractFunction : Object

另请参阅：Gendy1、Gendy3

说明

背景请参阅 Gendy1 帮助文件。此 GENDYN 变体更接近 Hoffmann, Peter. (2000) The New GENDYN Program. Computer Music Journal 24:2, pp 31-38 中提出的版本。

注意： 随机游走针对的是幅度和时间增量，而非直接的幅度和时间。幅度步进随机游走使用 Lehmer 风格的数字生成器，其参数可访问。

SuperCollider 实现由 Nick Collins 完成

类方法

Gendy2.ar(ampdist: 1, durdist: 1, adparam: 1.0, ddparam: 1.0, minfreq: 440, maxfreq: 660, ampscale: 0.5, durscale: 0.5, initCPs: 12, knum, a: 1.17, c: 0.31, mul: 1.0, add: 0.0)

Gendy2.kr(ampdist: 1, durdist: 1, adparam: 1.0, ddparam: 1.0, minfreq: 20, maxfreq: 1000, ampscale: 0.5, durscale: 0.5, initCPs: 12, knum, a: 1.17, c: 0.31, mul: 1.0, add: 0.0)

参数：

ampdist

控制点振幅下一次扰动所使用的概率分布选项。

这些分布（改编自《Formalized Music》中的 GENDYN 程序）：

0:

LINEAR.

1:

CAUCHY.

2:

LOGIST.

3:

HYPERBCOS.

4:

ARCSINE.

5:

EXPON.

6:

SINUS.

在此实现中，sinus（Xenakis 的命名）取自第三方振荡器的采样。参见下面的示例。

0:

LINEAR.

1:

CAUCHY.

2:

LOGIST.

3:

HYPERBCOS.

4:

ARCSINE.

5:

EXPON.

6:

SINUS.

durdist

用于扰动当前控制点间时长的分布选择。

adparam

幅度概率分布形状的参数，要求值在 0.0001 到 1 的范围内（代码中有安全检查，所以如果你想调制也不用太担心！）。

ddparam

一个用于控制时长概率分布形状的参数，要求取值在 0.0001 到 1 之间。

minfreq

Gendy1 振荡器允许的最小振荡频率，因此给出持续时间所允许取的最大周期。

maxfreq

Gendy1 振荡器允许的最大振荡频率，因此给出持续时间所允许采用的最短周期。

ampscale

通常为 0.0 到 1.0，是分布中振幅增量值的乘数。ampscale 为 1.0 时，振幅变化允许 -1 到 1 的完整范围。

durscale

通常为 0.0 到 1.0，是分布中时长 delta 值的乘数。ampscale 为 1.0 时允许时长变化达到 -1 到 1 的完整范围。

initCPs

初始化内存中的控制点数量。Xenakis 指定为 12。这将是振荡器每个周期的控制点数量，不过振荡器的周期会因时长分布而不断变化。

knum

当前使用的控制点数量，允许调制。

a

由 Xenakis 扰动的 Lehmer 随机数生成器的参数，如

((old*a)+c)%1.0

c

用于受 Xenakis 扰动的 Lehmer 随机数生成器的参数。

mul

输出将乘以该值。

add

此值将被添加到输出中。

讨论：

除 initCPs 仅在初始化时使用外，所有参数都可以在控制率下进行调制。

实例方法

示例

警告： 如果你有大量 CP 且频率很快，CPU 开销会大幅增加，因为每个采样都会发生新的 CP 移动！

// LOUD! 默认参数类似更粗糙的 Gendy1
{ Pan2.ar(Gendy2.ar) }.play

// 干扰随机数生成的优势 - 产生周期性
{ Pan2.ar(Gendy2.ar(a: MouseX.kr(0.0, 1.0), c: MouseY.kr(0.0, 1.0))) }.play

(
{ 
    Pan2.ar(
        Normalizer.ar(
            RLPF.ar(
                RLPF.ar(
                    Gendy2.ar(
                        a: SinOsc.kr(0.4, 0, 0.05, 0.05), 
                        c: SinOsc.kr(0.3, 0, 0.1, 0.5)
                    ), MouseX.kr(10, 10000, 'exponential'), 0.05
                ), MouseY.kr(10, 10000, 'exponential'), 0.05
            ), 0.9
        ), Lag.kr(LFNoise0.kr(1), 0.5)
    )
}.play
)



{ Pan2.ar(Gendy2.ar(3, 5, 1.0, 1.0, 50, 1000, MouseX.kr(0.05, 1), MouseY.kr(0.05, 1), 15, 0.05, 0.51, mul: 0.5)) }.play


// 播放我
{ Pan2.ar(RLPF.ar(Gendy2.ar(1, 3, minfreq: 20, maxfreq: MouseX.kr(100, 1000), durscale: 0.0, initCPs: 4), 500, 0.3, 0.2), 0.0) }.play


// 1 CP = 随机噪声效果
{ Pan2.ar(Gendy2.ar(initCPs: 1)) }.play

// 2 个 CP = 突然变成一个振荡器（虽然这里是一个快速调制的振荡器）
{ Pan2.ar(Gendy2.ar(initCPs: 2)) }.play


// 用作 LFO
(
{ Pan2.ar(SinOsc.ar(Gendy2.kr(2, 1, SinOsc.kr(0.1, 0, 0.49, 0.51), SinOsc.kr(0.13, 0, 0.49, 0.51),
3.4, 3.5, SinOsc.kr(0.17, 0, 0.49, 0.51), SinOsc.kr(0.19, 0, 0.49, 0.51), 10, 10, mul: 50, add: 350), 0, 0.3), 0.0) }.play
)

// 非常愤怒的黄蜂
{ Pan2.ar(Gendy2.ar(0, 0, SinOsc.kr(0.1, 0, 0.1, 0.9), 1.0, 50, 1000, 1, 0.005, 12, 12, 0.2, 0.2, 0.2), 0.0) }.play


// 调制分布
// 音高变化，因为分布改变了持续时间结构和频谱
{ Pan2.ar(Gendy2.ar(MouseX.kr(0, 7), MouseY.kr(0, 7), mul: 0.2), 0.0) }.play


// 调制 CP 的数量
{ Pan2.ar(Gendy2.ar(knum: MouseX.kr(1, 13), mul: 0.2), 0.0) }.play


( // Gendy1 进入 Gendy2……伴随着卡通般的副作用
{ Pan2.ar(Gendy2.ar(maxfreq: Gendy1.kr(5, 4, 0.3, 0.7, 0.1, MouseY.kr(0.1, 10),
    1.0, 1.0, 5, 5, 500, 600), knum: MouseX.kr(1, 13), mul: 0.2), 0.0) }.play
)

// 使用 SINUS 跟踪任意振荡器并从中获取 CP 位置，使用 adparam 和 ddparam 作为采样输入
{ Pan2.ar(Gendy2.ar(6, 6, LFPulse.kr(100, 0, 0.4, 1.0), SinOsc.kr(30, 0, 0.5), mul: 0.2), 0.0) }.play


( // 尤其尝试靠近角落的位置
{ Pan2.ar(Gendy2.ar(6, 6, LFPulse.kr(MouseX.kr(0, 200), 0, 0.4, 1.0),
    SinOsc.kr(MouseY.kr(0, 200), 0, 0.5), mul: 0.2), 0.0) }.play
)

// 纹理——呼啸的风？
(
{
    Mix.fill(10, {
        var freq = rrand(130, 160.3);
        
        Pan2.ar(
            SinOsc.ar(
                Gendy2.ar(
                    6.rand, 6.rand, SinOsc.kr(0.1, 0, 0.49, 0.51), SinOsc.kr(0.13, 0, 0.49, 0.51),
                    freq, freq, SinOsc.kr(0.17, 0, 0.49, 0.51), SinOsc.kr(0.19, 0, 0.49, 0.51),
                    12, 12, 0.4.rand, 0.4.rand, 200, 400
                ), 0, 0.1
            ), 1.0.rand2
        )
    });
}.play
)

// 小心！鼠标移到最右侧会导致声音爆响
(
{ 
    Pan2.ar(
        CombN.ar(
            Resonz.ar(
                Gendy2.ar(2, 3, minfreq: 1, maxfreq: MouseX.kr(10, 700), initCPs: 100),
                MouseY.kr(50, 1000), 0.1
            ),        
            0.1, 0.1, 5, 0.16
        ),
        0.0
    )
}.play
)

// storm
(
{
    var n;
    n = 15;
    
    0.5 * Mix.fill(n, {
        var freq, numcps;
        
        freq = rrand(130, 160.3);
        numcps = rrand(2, 20);
        Pan2.ar(
            Gendy2.ar(
                6.rand, 6.rand, 10.0.rand, 10.0.rand, freq, freq*exprand(1.0, 2.0),
                10.0.rand, 10.0.rand, numcps, 
                SinOsc.kr(exprand(0.02, 0.2), 0, numcps/2, numcps/2),
                10.0.rand, 10.0.rand, 0.5/(n.sqrt)
            ), 
            1.0.rand2
        )
    })
}.play
)

// 另一个流量时刻
(
{
    var n;
    n = 10;
    
    Resonz.ar(
        Mix.fill(n, {
            var freq, numcps;
            
            freq = rrand(50, 560.3);
            numcps = rrand(2, 20);
            Pan2.ar(
                Gendy2.ar(
                    6.rand, 6.rand, 1.0.rand, 1.0.rand, freq, freq,
                    1.0.rand, 1.0.rand, numcps, 
                    SinOsc.kr(exprand(0.02, 0.2), 0, numcps/2, numcps/2), 
                    0.5/(n.sqrt)
                ), 
                1.0.rand2
            )
        }), 
        MouseX.kr(100, 2000), MouseY.kr(0.01, 1.0), 0.3
    )
}.play
)
