16. 使用模式进行音序编排

SuperCollider 入门

另请参阅：00. Getting Started With SC

上一节演示了如何使用数据例程来生成合成参数序列。然而，用显式 yield 编写例程并不是一种很方便的语法。由于这是创建计算机音乐的重要部分，我们确实需要一种更简单的方法。

模式极大地简化了数据流的使用。模式本质上是一个流的工厂。模式对象包含你希望从流中输出的数据，而模式的类型决定了数据的流式传输方式。

例如，我们用这个例程输出 MIDI 音符编号，来演奏《Over the Rainbow》中的几个乐句。

(
r = Routine({
    [60, 72, 71, 67, 69, 71, 72, 60, 69, 67].do({ |midi| midi.yield });
});
)

while { (m = r.next).notNil } { m.postln };

使用模式，我们可以表达流返回相同值这一概念，而且更清晰简洁。因为我们不必显式写出 yield，模式中没有任何东西会分散对数据（数据才是作曲中真正关注的对象）的注意力。

Pseq（Pattern-sequence，模式序列）的意思很简单：按顺序逐个吐出数组中的值，重复次数由第二个参数指定（此处仅一次）。

p = Pseq([60, 72, 71, 67, 69, 71, 72, 60, 69, 67], 1);
r = p.asStream;
while { (m = r.next).notNil } { m.postln };

注意 Pseq 本身不可流化，但当你对它调用 asStream 时，它会创建一个流（Routine）。然后这个例程可以像任何其他例程一样使用——用于读取流值的 while 循环对两者完全相同，尽管它们的写法不同。

因此，'Over the Rainbow' 示例可以重写，且更加简洁：

(
var midi, dur;
midi = Pseq([60, 72, 71, 67, 69, 71, 72, 60, 69, 67], 1).asStream;
dur = Pseq([2, 2, 1, 0.5, 0.5, 1, 1, 2, 2, 3], 1).asStream;

SynthDef(\smooth, { |out, freq = 440, sustain = 1, amp = 0.5|
    var sig;
    sig = SinOsc.ar(freq, 0, amp) * EnvGen.kr(Env.linen(0.05, sustain, 0.1), doneAction: Done.freeSelf);
    Out.ar(out, sig ! 2)
}).add;

r = Task({
    var delta;
    while {
        delta = dur.next;
        delta.notNil
    } {
        Synth(\smooth, [freq: midi.next.midicps, sustain: delta]);
        delta.yield;
    }
}).play(quant: TempoClock.default.beats + 1.0);
)

模式还能做什么？

SuperCollider 的模式库很庞大（超过 120 个类，不包括扩展库），显然超出了教程深入覆盖的范围。但有些模式你会反复用到。

许多模式接受值的列表并以某种顺序返回它们。

Pseq(list, repeats, offset)

按顺序返回列表的值

Pshuf(list, repeats)

将列表打乱为随机顺序

Prand(list, repeats)

从列表的值中随机选择

Pxrand(list, repeats)

随机选择，但绝不连续两次返回同一个列表项

Pwrand(list, weights, repeats)

类似 Prand，但根据概率/权重列表选择值

其他模式会根据各种参数生成值。除了这些基本模式之外，还有一整套随机数生成器可以产生特定的分布，以及混沌函数。

Pseries(start, step, length)

等差数列，例如 1、2、3、4、5

Pgeom(start, grow, length)

等比数列，例如 1、2、4、8、16

Pwhite(lo, hi, length)

随机数生成器，使用 rrand(lo, hi) —— 均匀分布

Pexprand(lo, hi, length)

随机数生成器，使用 exprand(lo, hi) —— 指数分布

其他模式修改值模式的输出。这些被称为 FilterPatterns。

Pn(pattern, repeats)

将模式重复 repeats 所指示的次数

Pdup(n, pattern)

将模式中的各个值重复 n 次。n 本身也可以是一个数值模式。

你可以在其他模式内部使用模式。这里，我们在逐渐增大的范围内生成随机数。随机数生成器的上限是一个流，它从 0.01 开始，然后依次变为 0.02、0.03，依此类推，正如绘图所清晰显示的。

p = Pwhite(0.0, Pseries(0.01, 0.01, inf), 100).asStream;
    // .all 会从流中拉取直到返回 nil
    // 显然，对于 'inf' 长度的流你不想这样做！
p.all.plot;

或者，再举一个例子，如果你想要随机排列一组数字，使得所有数字都出现之后才选择新的顺序，可以使用 Pn 来重复 Pshuf。

p = Pn(Pshuf([1, 2, 3, 4, 5], 1), inf).asStream;
p.nextN(15);    // 从模式的流中获取 15 个值

这只是一个初步示例，旨在展示使用模式所能获得的灵活性。与任何丰富且可适应的结构一样，最好的方法是从简单的情况开始，然后逐步扩展到更复杂的设置。

用模式演奏音符：Pbind

模式不仅可以为音符生成数据，还能直接演奏音符。再次以《Over the Rainbow》为例。

(
SynthDef(\smooth, { |out, freq = 440, sustain = 1, amp = 0.5|
    var sig;
    sig = SinOsc.ar(freq, 0, amp) * EnvGen.kr(Env.linen(0.05, sustain, 0.1), doneAction: Done.freeSelf);
    Out.ar(out, sig ! 2)
}).add;
)

(
p = Pbind(
        // 每个音符要使用的 SynthDef 名称
    \instrument, \smooth,
        // MIDI 音符编号——自动转换为 Hz
    \midinote, Pseq([60, 72, 71, 67, 69, 71, 72, 60, 69, 67], 1),
        // 节奏值
    \dur, Pseq([2, 2, 1, 0.5, 0.5, 1, 1, 2, 2, 3], 1)
).play;
)

首先要注意的是语法多么简短、精炼而清晰。没有任何多余的东西；它把你的全部注意力集中在应该播放的内容上，并尽量减少程序逻辑带来的干扰。

Streams 文档详细解释了这一切的工作原理。高层概述如下：

- Pbind 模式生成 Event 对象，这些对象包含描述音符应如何发声的名称和值。

- 它通过读取 'name, pattern' 对，依次从每个模式流中获取值，并将这些值添加到结果事件中来实现这一点。

- 然后事件被播放。它根据事件原型内编码的一组默认值和规则来解释这些值，并执行相应的动作。默认动作是在服务器上播放一个新的 synth。你可以从默认事件原型中定义的其他几种动作中选择，这些动作在 Streams 系列帮助文件中有文档说明。

- 要播放 synth，事件需要知道将哪些值作为参数传递给服务器。SuperCollider 可以使用 add 方法将 synthdef 的信息存储到一个 synthdef 描述库中。

- 事件中的 delta 值告诉 SuperCollider 在播放下一个事件之前等待多长时间。

入门教程无法涵盖所有可能性。学习一组核心的模式类很重要；Practical Guide to Patterns 帮助文件系列是更全面的介绍。模式操作，以及组合或嵌套模式的方式，几乎为每一种作曲需求开辟了领域。

例如，我们可以通过从一组 Pbind 序列中随机选择来生成一条有节奏的（但不一定是节拍的）bassline。（其中一些将使用 Pmono，它是 Pbind 的一种变体，旨在播放单声部 synth 线条。）虽然这是一段较大的代码，但其结构相当简单，并且汇集了序列教程中介绍的若干概念。注意，play 的 quant 参数用于让几个不同的序列在节拍上保持在一起。

不要被贝斯线模式吓到。在更高的层面上，它可以简化为 Pxrand([a, b, c, d], inf)，它只是随机选取各项，且不会连续两次重复同一个项。恰好每个项都是一个播放一系列音符的事件模式，但这对于 Pxrand 来说无关紧要。它只是选取一个项，将其完整播放到结束，然后再选取下一个，如此反复。从这个角度看，该模式是对选取乐句这一想法的优雅表达。其代码表示与音乐构思之间的对应关系十分直接。

(
SynthDef(\bass, { |out, freq = 440, gate = 1, amp = 0.5, slideTime = 0.17, ffreq = 1100, width = 0.15,
        detune = 1.005, preamp = 4|
    var sig, env;
    env = Env.adsr(0.01, 0.3, 0.4, 0.1);
    freq = Lag.kr(freq, slideTime);
    sig = Mix(VarSaw.ar([freq, freq * detune], 0, width, preamp)).distort * amp
        * EnvGen.kr(env, gate, doneAction: Done.freeSelf);
    sig = LPF.ar(sig, ffreq);
    Out.ar(out, sig ! 2)
}).add;

TempoClock.default.tempo = 132/60;

p = Pxrand([
    Pbind(
        \instrument, \bass,
        \midinote, 36,
        \dur, Pseq([0.75, 0.25, 0.25, 0.25, 0.5], 1),
        \legato, Pseq([0.9, 0.3, 0.3, 0.3, 0.3], 1),
        \amp, 0.5, \detune, 1.005
    ),
    Pmono(\bass,
        \midinote, Pseq([36, 48, 36], 1),
        \dur, Pseq([0.25, 0.25, 0.5], 1),
        \amp, 0.5, \detune, 1.005
    ),
    Pmono(\bass,
        \midinote, Pseq([36, 42, 41, 33], 1),
        \dur, Pseq([0.25, 0.25, 0.25, 0.75], 1),
        \amp, 0.5, \detune, 1.005
    ),
    Pmono(\bass,
        \midinote, Pseq([36, 39, 36, 42], 1),
        \dur, Pseq([0.25, 0.5, 0.25, 0.5], 1),
        \amp, 0.5, \detune, 1.005
    )
], inf).play(quant: 1);
)

// 非常俗气，但谁能抗拒呢？
(
SynthDef(\kik, { |out, preamp = 1, amp = 1|
    var freq = EnvGen.kr(Env([400, 66], [0.08], -3)),
        sig = SinOsc.ar(freq, 0.5pi, preamp).distort * amp
            * EnvGen.kr(Env([0, 1, 0.8, 0], [0.01, 0.1, 0.2]), doneAction: Done.freeSelf);
    Out.ar(out, sig ! 2);
}).add;

// 在你演奏之前：
// 你预期 '\delta, 1' 会做什么？
k = Pbind(\instrument, \kik, \delta, 1, \preamp, 4.5, \amp, 0.32).play(quant: 1);
)

p.stop;
k.stop;
