PatternConductor

用于播放模式的简单交互式控件

Object

另请参阅：Pattern

说明

PatternConductor 提供简单的交互式控制（支持播放、暂停、恢复、停止）来播放模式，很像 Pattern: -play。不过，PatternConductor 会创建自己的时钟，并直接控制发声音符的释放以及由模式发起的音符。

类方法

未文档化的类方法

PatternConductor.new(patterns, event, quant)

实例方法

.tempo

.tempo = temp

设置 PatternConductor 的速度

.play

播放该模式。会创建一个 TempoClock，其速度设为 PatternConductor 的速度，并使用该时钟播放模式。如果 quant 非零，则在指定的量化处与 TempoClock.default 同步。

.pause(pauseTempo)

暂停模式，无限持续音符。随后调用 -resume 将恢复到原始速度（因此音符将按计划结束）。随后调用 -play 将切断任何正在发声的音符并以原始速度恢复播放。

.stop(stopTempo)

可根据 tempo 的值截断或缩短正在发声的音符。如果 stopTempo 为 nil，则所有音符立即截断。否则，音符在指定的 tempo 处结束。

示例

(
// 一个带有长音符的 pattern
p = Pbind(
    \freq, Pwhite(0, log(32)).exp.round(1) * 36.midicps,
    \detune, Pfunc({ |ev| ev[\freq]  * rand(0.01) }),
    \sustain, Pwhite(log(0.1), log(20)).exp,
    \dur, Prand([0.1, 0.1, 0.1, 0.1, 0.2, 1, 2], inf),
    \db, Pstep(Pseq([-20, -30, -25, -30], inf), 0.2)
);

// 在 TempoClock.default 上运行的不相关 cluster pattern
Pbind(\dur, 2, \midinote, Pseq([(48..60)], 20), \db, -30).play;

// 创建一个指挥器
a = PatternConductor(p, quant: 2);
a.play;
)


// 现在逐行尝试一些交互控制选项：
a.quant = 0;
a.pause;
a.resume;
a.stop;
a.play;
a.pause;
a.play;
a.stop(1000);
