GrainFM

使用频率调制正弦音进行颗粒合成

MultiOutUGen : UGen : AbstractFunction : Object

另请参见：GrainIn、GrainSin、GrainBuf

类方法

GrainFM.ar(numChannels: 1, trigger: 0, dur: 1, carfreq: 440, modfreq: 200, index: 1, pan: 0, envbufnum: -1, maxGrains: 512, mul: 1, add: 0)

参数：

numChannels

要输出的通道数。如果为 1，则返回单声道并忽略声像。必须是非零正整数。这在编译 SynthDef 时固定，因此不能赋值给 SynthDef 参数。

trigger

一个 kr 或 ar 触发器，用于启动新的颗粒。如果是 ar，则在 synth 启动之后的颗粒是采样精确的。

dur

颗粒的大小（以秒为单位）。

carfreq

颗粒发生器内部振荡器的载波频率

modfreq

颗粒生成器内部振荡器的调制频率

index

调制索引

pan

决定将输出声像定位到何处。

  • 如果 numChannels = 1，则不进行声像处理。
  • 如果 numChannels = 2，声像处理类似于 Pan2。
  • 如果 numChannels > 2，则声像处理与 PanAz 相同。

envbufnum

包含用于颗粒包络的信号所在的缓冲区编号。-1 使用内置的 Hann 包络。

maxGrains

在给定时间可使用的最大重叠颗粒数。此值在 UGen 初始化时设定，无法修改。默认为 512。将其设置得更低可更高效地使用内存。

警告： 上述参数是新增的（SC 3.3.1 之后），有可能破坏在 <= 3.3.1 中编写的代码。该参数位于 mul 槽之前，你可能需要更新代码以适应该差异。

mul

add

讨论：

除 numChannels 和 trigger 之外的所有参数都在颗粒创建时被轮询。

实例方法

示例

s.boot;

(
var winenv;
// 自定义包络
winenv = Env([0, 1, 0], [0.5, 0.5], [8, -8]);
z = Buffer.sendCollection(s, winenv.discretize, 1);

SynthDef(\fm_grain_test, { |out, gate = 1, amp = 1, envbuf|
    var pan, env, freqdev;
    // 使用鼠标 x 控制声像
    pan = MouseX.kr(-1, 1);
    // 使用 WhiteNoise 和鼠标 y 来控制偏离中心音高的程度
    freqdev = WhiteNoise.kr(MouseY.kr(0, 400));
    env = EnvGen.kr(
        Env([0, 1, 0], [1, 1], \sin, 1),
        gate,
        levelScale: amp,
        doneAction: Done.freeSelf);
    Out.ar(out,
        GrainFM.ar(2, Impulse.kr(10), 0.1, 440 + freqdev, 200, LFNoise1.kr.range(1, 10),
            pan, envbuf) * env)
}).add;

)

// 使用内置包络
x = Synth(\fm_grain_test, [\envbuf, -1])

// 切换到自定义包络
x.set(\envbuf, z)
x.set(\envbuf, -1);

x.set(\gate, 0);
