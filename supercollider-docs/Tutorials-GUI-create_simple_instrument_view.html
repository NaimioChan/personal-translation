GUI：将乐器与 View 连接

创建一个与 Synth 交互的视图，Layouts 入门

另请参阅：GUI：创建窗口、GUI：使用基本组件组合视图

GUI 教程

此帮助文件是 GUI 教程 的一部分。

这是 SuperCollider GUI 系统初学者介绍的第二部分。第一部分介绍创建窗口，第三部分讨论使用基本 GUI 组件组合视图。

本教程是关于什么的？

这是一个教程，帮助你开始使用 SuperCollider 的 GUI 系统来创建视图并使它们与 Synth 交互。

它涵盖以下主题：

  • 从 midi 音符列表创建键盘
  • 创建一个音量滑块和一个时长滑块
  • 使用布局系统，使控件以网格模式排列

Setup

你需要启动服务器并为其添加一个SynthDef，我们将在本教程中使用它。

SynthDef 是一个带有打击包络的简单正弦波。

我们将控制 Synth 的频率、音量和时长。

// 确保服务器已启动：
s.boot;
// 将我们的 SynthDef 添加到服务器：
(
SynthDef(\instrView, { |out = 0, amp = 0.25, freq = 440, dur = 1.0|
    var snd, env;

    env = EnvGen.kr(Env.perc(dur * 0.01, dur * 0.99), doneAction: Done.freeSelf);
    snd = SinOsc.ar(freq, mul: amp);
    snd = snd * env;
    snd = snd!2;

    Out.ar(out, snd);
}).add;
)

你可以使用以下代码试用该 Synth：

Synth(\instrView)

我们将从以下代码开始，它尚未连接到我们的 synth，因此还不会产生任何声音：

(
var window = Window();
var layout = HLayout();
var button = Button();

button.string_("Play");

window.layout_(layout);
layout.add(button);

window.front;
)

如果这段代码对你来说难以理解，你可以在 GUI: Create a Window 中找到更多关于它的解释。

连接按钮

所以我们从一个简单的按钮开始，遗憾的是，到目前为止它并不太有用。要连接它，你需要为其 'action' 方法分配一个函数。

(
var window = Window();
var layout = HLayout();
var button = Button();
button.string_("Play");

button.action_({
    // 这是按钮将触发的函数主体
    Synth(\instrView);
    "ting".postln;
});

window.layout_(layout);
layout.add(button);
window.front;
)

由于我们已经知道了播放 synth 的命令，我们只需配置按钮，使其在被按下时求值该命令。它还会向控制台发送一条消息，这在调试时可能很有用。

一次添加多个按钮

我们现在有一个键盘了，但并不是一个很好的键盘！它只有一个键……我想说这可能已经足够了，但这相当不寻常。

那么让我们添加第二个键：

(
var window = Window();
var layout = HLayout();
var button = Button();
var button2 = Button();

button.string_("Play");
button.action_({ Synth(\instrView); });

button2.string_("Play 2");
button2.action_({ Synth(\instrView); });

window.layout_(layout);

layout.add(button);
layout.add(button2);

window.front;
)

如你所见，布局已自动安排好一切。

但是复制粘贴不是添加按键的好方法。相反，我们可以直接让 SC 创建一个按钮 8 次：

(
var window = Window();
var layout = HLayout();
var numberOfButtons = 8;

// 8 次……
numberOfButtons.do({
    // ……创建一个按钮……
    var button = Button();
    // ...分配其函数...
    button.action_({ Synth(\instrView); });
    // ...并将其添加到布局中。
    layout.add(button);
});

window.layout_(layout);
window.front;
)

这些按钮感觉太小了。这是因为 Button 的默认最大高度很低。我们可以通过重新赋值来改变它：

(
var window = Window();
var layout = HLayout();
var numberOfButtons = 8;

numberOfButtons.do({

    // 更改此属性
    var button = Button()
    .maxHeight_(200);

    button.action_({ Synth(\instrView); });
    layout.add(button);
});

window.layout_(layout);
window.front;
)

所以我们现在有 8 个按钮，但它们发出的声音全都一样。在我看来这算不上什么进展。

我们可以通过修改 Synth 的参数来改变其参数：

Synth(\instrView, [\freq, 660]);

我们只需在创建按钮的循环内部引入这一操作。但无需让 SC 执行 8 次，而是对一个频率集合执行此操作。

我们可以将一组 MIDI 音符转换为频率，并将它们映射到按钮上：

(
var window = Window();
var layout = HLayout();
// 以频率形式获取 C 大调音阶，使用 MIDI 记谱：
var frequencies = [60, 62, 64, 65, 67, 69, 71, 72].midicps;

// 对于每个频率...
frequencies.do({ |frequency|

    // ...这个特定的按钮...
    var button = Button()
    .maxHeight_(200);

    // ……将使用这个特定频率。
    button.action_({
        Synth(\instrView, [\freq, frequency]);
    });

    layout.add(button);
});

window.layout_(layout);
window.front;
)

HLayout 和 VLayout 如何工作

现在我们有了键盘，我们想给视图实现一个音量滑块。我们可以通过在布局中插入一个 Slider 来实现：

(
var window = Window();
var layout = HLayout();
var frequencies = [60, 62, 64, 65, 67, 69, 71, 72].midicps;

// 创建滑块
var slider = Slider();

frequencies.do({ |frequency|
    var button = Button()
    .maxHeight_(200);
    button.action_({ Synth(\instrView, [\freq, frequency]); });
    layout.add(button);
});

// 将其添加到布局内部
layout.add(slider);

window.layout_(layout);
window.front;
)

音量滑块现在出现在钢琴的右侧，就像它是一个琴键一样。这是因为它与琴键处于相同的布局中。

目前，Window 只包含一个 HLayout。

HLayout 将 Window 水平分割，就像是一系列连续的列。

它会将这些视图从左到右逐个分配到这些列中。

这就是为什么 Slider 被一直推到右侧。通过这种划分，你可以向左侧、右侧以及列之间添加内容。

但你无法垂直排列视图。为此，你需要创建一个 VLayout，而它反过来又无法水平排列视图。要在 Window 中混合水平和垂直分割，你需要将一些布局插入到其他布局内部。

让我们看一个关于布局层级的例子。在阅读之前执行以下代码，以对其工作方式获得直观认识：

(
var window = Window();
var firstLayout = VLayout();
var secondLayout = HLayout();

var topButton = Button().string_("top").maxHeight_(200);

var leftButton = Button().string_("left").maxHeight_(200);
var rightButton = Button().string_("right").maxHeight_(200);

// 窗口垂直划分，使用 VLayout：
window.layout_(firstLayout);

// 我们正在相加两个对象，这会把窗口分成两部分：

// 这将覆盖窗口的顶部区域：
firstLayout.add(topButton);

// 这会覆盖窗口的底部：
firstLayout.add(secondLayout);

// 屏幕底部是一个 HLayout，因此它被水平细分
// 为两部分，因为我们添加了两个对象：
secondLayout.add(leftButton);
secondLayout.add(rightButton);

window.front;
)

窗口首先被垂直划分，然后窗口的底部被水平划分。这意味着有 3 个位置，由 3 个按钮占据。可能需要一些时间才能习惯这种逻辑。

回到连接滑块

让我们调整之前的代码，将滑块放置在钢琴上方：

(
var window = Window();
var windowLayout = VLayout();
var pianoLayout = HLayout();

var frequencies = [60, 62, 64, 65, 67, 69, 71, 72].midicps;

var volumeSlider = Slider();

frequencies.do({ |frequency|
    var button = Button()
    .maxHeight_(200);
    button.action_({ Synth(\instrView, [\freq, frequency]); });
    // 水平分割，'钢琴布局'
    pianoLayout.add(button);
});

// 垂直分割，'window' 布局
windowLayout.add(volumeSlider);
windowLayout.add(pianoLayout);

window.layout_(windowLayout);
window.front;
)

滑块把一切都挤坏了！这是因为它不在正确的方向上。我们可以用 .orientation 方法修复这个问题。然后我们还可以用 .maxHeight 减小它的最大高度，这样它占用的空间就更少：

(
var window = Window();
var windowLayout = VLayout();
var pianoLayout = HLayout();
var frequencies = [60, 62, 64, 65, 67, 69, 71, 72].midicps;

// 滑块设置
var volumeSlider = Slider()
.orientation_(\horizontal)
.maxHeight_(60);

frequencies.do({ |frequency|
    var button = Button()
    .maxHeight_(200);
    button.action_({ Synth(\instrView, [\freq, frequency]); });
    pianoLayout.add(button);
});

windowLayout.add(volumeSlider);
windowLayout.add(pianoLayout);
window.layout_(windowLayout);
window.front;
)

到目前为止，我们更改了它的图形属性，但滑块没有任何 action。现在是时候连接它了：

(
var window = Window();
var windowLayout = VLayout();
var pianoLayout = HLayout();
var frequencies = [60, 62, 64, 65, 67, 69, 71, 72].midicps;

// 创建一个变量来存储音量
var volume = 0.1;

var volumeSlider = Slider()
.orientation_(\horizontal)
.maxHeight_(60)
// 让滑块从正确的值开始
.value_(volume);

// 当滑块移动时，更新 volume 变量
volumeSlider.action = {
    volume = volumeSlider.value;
};

frequencies.do({ |frequency|
    var button = Button()
    .maxHeight_(200);
    button.action_({
        // 使用 volume 变量
        // 在按键时
        // 修改 Synth 的参数
        Synth(\instrView, [
            \freq, frequency,
            \amp, volume
        ]);

    });
    pianoLayout.add(button);
});

windowLayout.add(volumeSlider);
windowLayout.add(pianoLayout);
window.layout_(windowLayout);
window.front;
)

在这种情况下，Slider 的 action 函数会将滑块的值赋给一个名为 volume 的变量。当按下“钢琴”上的某个键时，它还会检查这个变量，以便在求值 Synth 命令时传入正确的音量作为参数。

但滑块是如何知道 volume 参数期望什么值的呢？其实它并不知道。我们只是碰巧走运：滑块的值范围在 0 到 1 之间，而这恰好是 volume 的正确设置。

将 Slider 调整为正确的值（映射）

但如果我们想控制其他范围呢？我们可以使用 .linlin 或 .linexp 将滑块值（介于 0 和 1 之间）映射到 0.1 和 2 之间的值。我们将使用这个新值来控制打击包络的持续时间：

(
var window = Window();
var windowLayout = VLayout();

var pianoLayout = HLayout();
var frequencies = [60, 62, 64, 65, 67, 69, 71, 72].midicps;

var volume = 0.1;
var volumeSlider = Slider()
.orientation_(\horizontal)
.maxHeight_(60)
.value_(volume)
.action_({ volume = volumeSlider.value; });

var dur = 1;
var durMin = 0.1;
var durMax = 2;
var durSlider = Slider()
.orientation_(\horizontal)
.maxHeight_(60)
.action_({
    dur = durSlider.value;
    // linlin 将一个值
    // 从一个线性范围
    // 映射到另一个线性范围
    dur = dur.linlin(
        0, 1,
        durMin, durMax
    );
});

frequencies.do({ |frequency|
    var button = Button()
    .maxHeight_(200);
    button.action_({
        Synth(\instrView, [
            \freq, frequency,
            \amp, volume,
            \dur, dur,
        ]);

    });
    pianoLayout.add(button);
});

windowLayout.add(volumeSlider);
windowLayout.add(durSlider);
windowLayout.add(pianoLayout);
window.layout_(windowLayout);
window.front;
)

或者，我们可以使用 ControlSpec 来做同样的事情：

var dur = 1;
var durMin = 0.1;
var durMax = 2;
var durSlider = Slider()
.orientation_(\horizontal)
.maxHeight_(60)
.action_({ dur = ControlSpec(durMin, durMax, \lin).map(durSlider.value); });

添加文本，并指定视图比例

最后要做的是为控件添加标签。记住键盘的功能很容易，但滑块若能有一些提示会更好。我们将为此使用 StaticText，配置它的字符串和它的对齐方式。

(
var window = Window();
var windowLayout = VLayout();
var pianoLayout = HLayout();
var frequencies = [60, 62, 64, 65, 67, 69, 71, 72].midicps;

var volume = 0.1;
var volumeSlider = Slider()
.orientation_(\horizontal)
.maxHeight_(60)
.value_(volume)
.action_({ volume = volumeSlider.value; });
// 创建文本，并赋值一个字符串
var volumeText = StaticText()
.string_("Volume")
.align_(\center);

var dur = 1;
var durMin = 0.1;
var durMax = 2;
var durSlider = Slider()
.orientation_(\horizontal)
.maxHeight_(60)
.value_(dur.linlin(durMin, durMax, 0, 1))
.action_({
    dur = durSlider.value;
    dur = dur.linlin(0, 1, durMin, durMax);
});
// 这里
var durText = StaticText()
.string_("Duration")
.align_(\center);

frequencies.do({ |frequency|
    var button = Button()
    .maxHeight_(200);
    button.action_({
        Synth(\instrView, [
            \freq, frequency,
            \amp, volume,
            \dur, dur,
        ]);

    });
    pianoLayout.add(button);
});

// 在音量滑块之前插入音量文本：
windowLayout.add(volumeText, 1);
windowLayout.add(volumeSlider, 3);
// 将时长文本插入到时长滑块之前，
// 音量滑块之后：
windowLayout.add(durText, 1);
windowLayout.add(durSlider, 3);

windowLayout.add(pianoLayout, 8);
window.layout_(windowLayout);
window.front;
)

你可以看到，在布局内添加视图时，我还指定了一个数字。这被称为为视图分配“拉伸”：

windowLayout.add(volumeSlider, stretch: 3);

拉伸数定义了视图相对于布局内所有视图拉伸总和的比率。在我们的示例中，键盘的大小与其他视图相同，因为键盘的拉伸值为 8，而所有其他视图的拉伸值之和也是 8。

这意味着 stretch 为 3 的视图将比 stretch 为 1 的视图大 3 倍。stretch 为 6 的视图将比 stretch 为 2 的视图大 3 倍，比 stretch 为 1 的视图大 6 倍。

注意，使用 stretch 时也会考虑视图的最小和最大尺寸，这可能会影响视图的实际比例。
