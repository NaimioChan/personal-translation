ProxyMonitorGui

控制 nodeproxy 及其监视器的顶层

参见：ProxyMixer、NodeProxyEditor

说明

是一个用于控制 nodeproxy 顶层及其监视器的 GUI。例如它用于 ProxyMixer 和 NodeProxyEditor 中，并且是跨平台的。

类方法

实例方法

示例

s.boot;

    // 创建一个代理空间和一个测试代理
(
s.scope(8);
p = ProxySpace.push;

~test = { |freq = 1000, dens = 5, amp = 1, lev = 3|
    var freqline = { exprand(0.3, 3) } ! 3 * XLine.kr(0.125, 1, 2);
    Ringz.ar(Dust.ar(dens ! 3, dens.reciprocal.sqrt), freq * freqline, 0.1)
};
~test.playN(0, vol: 0.1);
)

    // 创建一个 ProxyMonitorGui
z = ProxyMonitorGui();

    // 在 proxy 之间切换：拖动视图显示 proxy 键
z.proxy = ~otto12345;    // 在 macOS 上最多约 9 个字母
z.proxy = ~test;        // 如果 proxy 是音频则使音频控件可用
z.proxy = nil;
z.proxy = ~otto; ~otto.kr;    //
z.proxy = ~test;



    // 配置变体

    // 更粗胖
ProxyMonitorGui(~test, bounds: 300@30);

    // 将其放入现有窗口：
ProxyMonitorGui(~test, Window("ProxyMonitor", Rect(200, 200, 400, 100)).front);

ProxyMonitorGui(~test, Window("ProxyMonitor").front, bounds: 350@40);

ProxyMonitorGui(~test, Window("ProxyMonitor").front, bounds: Rect(20, 20, 360, 20));


    // 以 dB 显示电平 - 默认关闭
ProxyMonitorGui(~test, showLevel: true, showPlayN: false);

    // 没有 multichan out 按钮 - 则使用 proxy.play。true = 默认使用 playN。
ProxyMonitorGui(~test, showPlayN: false);

    // 是否显示代理名称。默认开启。
ProxyMonitorGui(~test, showName: false);

    // 显示 proxy 的暂停和发送按钮 - 默认 true
ProxyMonitorGui(~test, showPauseSend: true, showPlayN: false);


    // 关闭 SkipJack 视图更新 - 更新默认开启。
ProxyMonitorGui(~test, makeWatcher: false);

    // minimal:
ProxyMonitorGui.new(~test, bounds: 300@40, showPlayN: false, showPauseSend: false);


    // GUI 函数：

ProxyMonitorGui(~test);
    // 左侧滑块是音量
~test.vol_(0.1);
~test.vol_(0.25);

~test.stop;    // 播放 / 停止按钮：
~test.playN;    //
~test.end;    // alt-stop 会完全结束该代理。
~test.playN(vol: 0);    // alt-playN 以音量 0 开始。

    // 数字框设置第一个输出通道
    // 当你想要从相邻通道播放时。
~test.playN(0);
~test.out_(1);

    // 输出到多个通道播放
~test.playN([0, 2, 5]);
~test.playN([1, 2, 5]);
    // 它旁边的开关会切换按钮以显示不同的输出形状：
    // ("-<" 表示多个输出，"-=" 表示直接相邻的输出。
    // 点击该按钮会打开一个编辑对话框：
~test.playNDialog;

~test.out_(0);

    // 暂停按钮暂停和恢复
~test.pause;
~test.resume;

    // snd 按钮会按编译后的形式重新发送代理的声音，
~test.send;
    // 或者使用 option-点击，它会重建代理的声音函数，
    // 例如语言中的普通随机数或查找会被重新生成。
~test.rebuild;


//    ProxyMonitorGui 的外观取自 GUI.skin，所以你可以在那里自定义它，
//    或者传入你自己的外观：

ProxyMonitorGui(skin: <your look here>)

y = ProxyMonitorGui(~test);
