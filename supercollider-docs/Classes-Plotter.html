Plotter

在窗口或视图上绘制数值数据

另请参阅：plot

说明

在 Window 或 UserView 上绘制最多三维的数据。

键盘快捷键

当绘图窗口获得焦点时，可使用以下键盘快捷键来更改显示：

+ / -

垂直缩放

=

比较绘图通道

n

切换归一化显示 (0..1) / (-1..1)，或适配范围

s

切换叠加（参见：superpose）

m

切换绘图模式（参见：Plotter: -plotMode）

e

切换编辑（参见：Plotter: -editMode）

g

切换水平（定义域）网格

G

切换垂直（值域）网格

p

打印曲线

ctrl-+ / -

缩放字体

alt-click

发送值

方法扩展

Plotter 通过方法扩展其他类。要查看哪些类实现了 plot，请参阅 Methods: plot

plot(args)

// 绘制数组
[1, 6, 2, -5, 2].plot;
(0..100).normalize(0, 8pi).sin.plot;

// 嵌套数组
{ (0..100).normalize(0, 15.0.rand).sin }.dup(3).plot;
{ { (0..17).normalize(0, 15.0.rand).sin }.dup(4) }.dup(3).plot;

// UGen 函数
{ SinOsc.ar([700, 357]) * SinOsc.ar([400, 476]) * 0.2 }.plot;

// Buffer
{ var b = Buffer.read(s, ExampleFiles.sinedPink); s.sync; b.plot }.fork(AppClock);

// Env
Env.perc(0.4, 0.6).plot;

plotGraph(n, from, to, ...)

{ |x| sin(x) }.plotGraph(300, 0, 2*pi);
{ |x| sin(1/x) * x }.plotGraph(from: 0.0001, to: 0.2);

类方法

.new

参数：

name

绘图窗口标题。

bounds

窗口边界（一个Rect）。

parent

可以传入一个 Window / View——那么绘图将嵌入其中。否则将创建一个新的 Window。

讨论：

实例方法

嵌入到另一个视图中

.makeWindow

在新窗口中或在给定的复合视图中打开给定的绘图器。

请参见 嵌入另一个 View 或 GUI 示例。

参数：

argParent

可以传入一个 Window 或 View——此时绘图嵌入其中。否则将创建一个新的 Window。

argBounds

窗口边界（一个Rect）。

绘图属性

.plotMode

获取/设置数据显示的样式。对于多通道数据，这可以是一个包含不同模式的数组。可用模式：

\points

将数据点绘制为中间带点的圆形

\dots

将数据点绘制为实心圆

\lines, \linear

线条连接数据点

\plines

线条连接数据点，也通过 \points 标记

\dlines

线条连接数据点，同时用 \dots 标记

\stems

从零到数据点的 PCM 风格垂直线

\pstems

从零到数据点的垂直线，也由 \points 标记

\dstems

从零到数据点的垂直线，也用 \dots 标记

\filled

填充波形下方的区域，并假定信号为双极性（填充至零交叉点）

\pfilled

\filled，也由 \points 标记

\dfilled

\filled，也由 \dots 标记

\levels

从该数据点延伸覆盖整个采样间隔的采样保持风格水平线

\steps

"阶梯插值"：\levels 通过垂直线连接

\bars

填充条形图

参数：

modes

一个 Symbol 或一个由 Symbol 组成的 Array。

如果 modes.size < numChannels，绘图将围绕 modes 数组 环绕。

返回值：

一个由Symbol组成的Array，除非只指定了一种模式，或者多通道绘图的所有模式都相同，此时返回单个Symbol。

讨论：

p = (0..20).scramble.plot;
p.plotMode = \points;
p.plotMode = \plines;
p.plotMode = \steps;

/* 预览可用的模式 */
(
s.waitForBoot{
    var modeList = [
        \points, \dots, \levels, \steps,
        \lines, \plines, \dlines,
        \stems, \pstems, \dstems,
        \filled, \dfilled, \pfilled, \bars,
    ];
    modeList.clump((modeList.size/2).ceil).do{ |modes, i|
        var frq = 1000, w = 600, h = 800;
        p = {
            LFSaw.ar(frq) ! modes.size
        }.plot(2.25 * frq.reciprocal);

        0.25.wait; // 让 Plotter 用数据更新
        p.plotMode_(modes);
        p.axisLabelX_(modes.collect(_.asString));
        p.setProperties(\labelFont, (Font().size_(15)));
        p.parent.bounds_(Rect(0, 0, w, h).left_(w*i));
    };
}
)

/* 混合模式 */
(
d = 4.collect({ |i| 100.collect({ |j| sinPi(1+i.squared*j * 50.reciprocal) }) });
p = d.plot;
p.plotColor_([Color.red, Color.cyan, Color.green, Color.blue]);
p.plotMode_([\steps, \linear, \plines, \points]);
p.superpose_(true);
)

.plotColor

设置或获取数据绘图的颜色。

参数：

colors

这可以是用于多通道数据的 Array，元素为 Color；也可以是单个 Color，映射到所有通道。

如果 colors.size < numChannels，绘图将环绕颜色数组。

返回值：

一个由 Array 组成的 Color，除非只指定了一种颜色，或多个通道绘图的全部颜色都相同，此时返回一个 Color。

讨论：

// 为通道着色
(
d = 4.collect({ |i|
    100.collect({ |j|
        sinPi(1+i.squared*j * 50.reciprocal)
    })
});
d.plot.plotColor_([Color.red, Color.cyan, Color.green, Color.blue]);
)

// 使用 'filled' plotMode 来显示相位关系
(
var freq = 100;
{ LFPar.ar(freq * [1, 1.5, 2.25]) }.plot
.plotMode_(\filled)
.plotColor_(
    [\red, \green, \blue].collect{ |col|
        Color.perform(col).alpha_(0.2)
    }
).superpose_(true);
)

.superpose

如果为 true，绘图器会将各通道叠加显示在单个图上。（键盘快捷键：s）

a = { (0..30).scramble }.dup(2).plot;
a.superpose = true;

.axisLabelX

获取/设置 x 轴的标签。可以是 String 或 String 的 Array，或者是 nil 以移除标签。参见下面的 Axis labels 示例。

.axisLabelY

获取/设置 y 轴的标签。可以是 String 或 String 的 Array，或 nil 以移除标签。参见下面的 Axis labels 示例。

.showUnits

获取/设置是否将对应的 ControlSpec: -units 显示为标签。-unitLocation 的状态决定单位是显示为轴标签还是附加到刻度标签上。

参数：

bool

一个 Boolean。

讨论：

当启用 showUnits 时，仅当 axisLabelX/Y 或网格的 labelAppendString 属性为 nil、为空、或此前已设置为显示 spec 单位时，轴或刻度标签才会被更新以显示单位——也就是说，showUnits 不会覆盖已显式设置的标签。

参见下方的 Unit labels 示例。

.unitLocation

获取/设置显示 Spec 的 ControlSpec: -units 所使用的标签类型。

请参阅 -showUnits 中的讨论，了解与 location 处已有标签的交互，以及下面 Unit labels 的示例。

参数：

location

一个 Symbol，\axis 或 \ticks，分别用于将单位显示为轴标签或附加到每个刻度标签之后。

.setProperties

设置所有绘图视图的属性。默认值取自 GUI.skins.at(\plot);

警告： 在可能的情况下，最好使用 Plotter 的实例方法来设置 Plot 属性，以确保在使用 -superpose 时行为正确。

参数：

... 对

符号、值对的列表。支持的属性：

  • font
  • fontColor
  • gridColorX
  • gridColorY
  • plotColor（一个 Array）
  • backgroundColor
  • gridLinePattern
  • gridLineSmoothing（Boolean）
  • labelX
  • labelY
  • gridOnX (Boolean)
  • gridOnY (Boolean)

讨论：

Example:

(
a = { (0..30).scramble }.dup(2).plot;
a.setProperties(
  \fontColor, Color.yellow,
  \plotColor, Color.magenta,
  \backgroundColor, Color.black,
  \gridColorX, Color.green,
  \gridColorY, Color.green,
  \labelX, "Frames",
  \labelFontColor, Color.magenta
);
);

GUI.skins.at(\plot); // 默认值

.plots

返回值：

一个由 Array 组成的 Plot 数组。

网格属性

.setGridProperties

设置所有 Plots 使用的 DrawGridX 或 DrawGridY 的一个或多个属性。

参数：

axis

一个 Symbol，表示你正在修改其网格的轴：\x 或 \y。

... propertyPairs

要更改的属性及其新值，以连续参数的形式列为键值对。属性键是一个 Symbol。

可以使用 DrawGridX 或 DrawGridY 的任意 setter。以下是一部分有用的属性：

\labelAnchor

一个 Symbol，表示标签边界 Rect 上锚定到网格线与轴基线交点处的点。\center、\top、\bottom、\left、\right、\topLeft、\topRight、\bottomLeft、\bottomRight、\leftTop、\rightTop、\leftBottom、\rightBottom。

\labelOffset

一个 Point，描述 \labelAnchor 相对于网格线与轴底部交点处的偏移。x 和 y 维度的正方向分别为向右和向下。

\labelAlign

文本在其边界 Rect 内的对齐方式：\left、\center 或 \right。

\constrainLabelExtents

一个布尔值，指定轴两端的刻度标签是被网格边界约束还是可以延伸到网格边界之外。

\drawBaseLine

一个布尔值，表示是否在该轴的最小范围处绘制一条线。

\drawBoundingLines

一个 Boolean，表示是否在此轴范围的两端绘制线条。

\drawBoundingRect

一个布尔值，表示是否在网格区域的边界周围绘制 Rect。

\labelAppendString

要附加到所有轴刻度标签的字符串。

\tickSpacing

设置每个轴网格线（"刻度"）之间的最小间距。详情请参见 DrawGrid: -tickSpacing。

\numTicks

设置每个坐标轴的近似网格线（“刻度”）数量。详见 DrawGrid: -numTicks。

\font

用于刻度标签的字体（包括字号）。

\fontColor

刻度标签的颜色。

\gridColor

坐标轴网格线的颜色。

属性 \drawBaseLine、\drawBoundingLines 或 \drawBoundingRect 是互斥的——将其中任意一个设为 true 会使另外两个设为 false。在 Plotter 的上下文中，在一个轴上设置 \drawBoundingRect 为 true 与在两个轴上设置 \drawBoundingLines 为 true 的外观效果相同。

\labelAnchor

一个 Symbol，表示标签边界 Rect 上锚定到网格线与轴基线交点处的点。\center、\top、\bottom、\left、\right、\topLeft、\topRight、\bottomLeft、\bottomRight、\leftTop、\rightTop、\leftBottom、\rightBottom。

\labelOffset

一个 Point，描述 \labelAnchor 相对于网格线与轴底部交点处的偏移。x 和 y 维度的正方向分别为向右和向下。

\labelAlign

文本在其边界 Rect 内的对齐方式：\left、\center 或 \right。

\constrainLabelExtents

一个布尔值，指定轴两端的刻度标签是被网格边界约束还是可以延伸到网格边界之外。

\drawBaseLine

一个布尔值，表示是否在该轴的最小范围处绘制一条线。

\drawBoundingLines

一个 Boolean，表示是否在此轴范围的两端绘制线条。

\drawBoundingRect

一个布尔值，表示是否在网格区域的边界周围绘制 Rect。

\labelAppendString

要附加到所有轴刻度标签的字符串。

\tickSpacing

设置每个轴网格线（"刻度"）之间的最小间距。详情请参见 DrawGrid: -tickSpacing。

\numTicks

设置每个坐标轴的近似网格线（“刻度”）数量。详见 DrawGrid: -numTicks。

\font

用于刻度标签的字体（包括字号）。

\fontColor

刻度标签的颜色。

\gridColor

坐标轴网格线的颜色。

讨论：

这是一个便捷方法，用于将所有Plot的网格属性设置为相同的值。示例：

(
var plotter = [10, 34, 167].collect({ |freq|
    101.collect{ |i| sin((i/1000) * 2pi * freq) }
}).plot;
plotter.setGridProperties(\x,
    \labelAnchor, \topLeft,
    \labelAlign, \left,
    \labelOffset, 1 @ 5,
    \labelAppendString, " samp"
).setGridProperties(\y,
    \labelAnchor, \right,
    \labelAlign, \right,
    \labelOffset, -5 @ 0,
    \constrainLabelExtents, false
)
)

要分别设置每个 Plot 上网格的属性，请遍历各个 plot：

(
var plotter, labelAnchors;
plotter = [10, 34, 167].collect({ |freq|
    101.collect{ |i| sin((i/1000) * 2pi * freq) }
}).plot;

labelAnchors = [\topLeft, \top, \bottomLeft];

plotter.plots.do{ |plot, i|
    plot.drawGrid.x
    .labelAnchor_(labelAnchors[i])
    .constrainLabelExtents_(true);
};
plotter.updatePlotBounds;
)

.getGridProperty

获取网格属性的值。可用属性列表参见 -setGridProperties。

参数：

axis

一个 Symbol，表示你正在修改其网格的轴：\x 或 \y。

property

属性名称，为一个 Symbol。

讨论：

作为一种便捷方法，getGridProperty 假定所有 Plot 的属性都相同（就像通过 -setGridProperties 设置时那样），因此返回单个值。或者，可以通过遍历各绘图来收集各个绘图网格的属性：

( // 检查每个 DrawGridX 的 \labelAnchor
var plotter  = [10, 34, 167].collect({ |freq|
    101.collect{ |i| sin((i/1000) * 2pi * freq) }
}).plot;

plotter.plots.collect({ |plot|
    plot.drawGrid.x.labelAnchor
}).postln;
)

.drawGridBoundingRect

设置是否在网格边界周围绘制 Rect。设置为 false 会禁用所有边界网格线（包括“基础”线）。

参数：

bool

一个 Boolean。

讨论：

在某些情况下，网格的 GridLines 不会落在其 spec 范围的最小值或最大值上。使用 -drawGridBaseLines 或 -drawGridBoundingRect 将分别使网格线出现在网格的下端（"base"）或网格的两端。

.drawGridBaseLines

设置是否在网格轴的下边界绘制线条。设置为 false 会禁用任何边界网格线（包括边界 Rect）。另请参阅 -drawGridBoundingRect 中的讨论。

参数：

bool

一个 Boolean。

数据显示属性

.specs

设置或获取 y 轴（陪域）的 spec。

a = { (40..3000).scramble }.dup(2).plot;
a.specs = \freq.asSpec;

另请参阅下方的显式域和坐标轴规格示例。

.domainSpecs

设置或获取 x 轴（域）的 spec。

a = { (40..300).scramble }.dup(2).plot;
a.domainSpecs = \freq.asSpec;

另请参阅下方的显式域和坐标轴规格示例。

讨论：

设置 Plotter 的 -value 时，默认的 domainSpecs 是范围 [0, value.size-1]（即值的索引）内的线性规格。因此，除非你已显式设置 -domain 值，否则你的值将显示为在 minval 与 maxval 之间均匀采样。

如果设置了新的 -value，你将需要更新你的 domainSpecs。

.domain

设置/获取数据点的 x 轴位置。domainArray 的大小必须与 -value 数组的大小相等，即为每个数据点指定一个域值。

(
var data, domain, plot;
domain = 25.collect({ rrand(0, 50) }).sort;
data = domain.linlin(0, 50, 0, 1);

plot = data.plot.plotMode_(\points);
plot.domainSpecs_([0, 50].asSpec);
plot.domain_(domain);
)

另请参阅下方的显式域和坐标轴规格示例。

讨论：

域值被映射到 -domainSpecs 的范围内，因此不必均匀分布。如果 -domain 被设为 nil，则你的值将显示为在 -domainSpecs 的 minval 与 maxval 之间均匀采样。

目前，对于多通道数据图，假定所有通道的数据共享同一个 -domain。即 domainArray 必须是秩为 1 的 Array。

如果设置了新的 -value，你需要更新你的 -domain。

.resolution

设置数据点之间的最小像素数（默认值：1）

// 更改绘图分辨率（x 轴）
p = 5000.collect({ |i| sinPi(i * 0.0025) }).plot;
p.resolution_(5).refresh;  // 5px
p.resolution_(10).refresh;
p.resolution_(50).refresh; // 欠采样
p.resolution_(1).refresh;  // 默认

绘制数据

.value

返回或设置数据值。数据可以是最高 3 维的数值数组。

a = [1, 4, 2, 7, 4].dup(2).plot;
a.value;

.setValue

设置数据值，并通过附加参数决定绘图如何更新。

参数：

arrays

要绘制的数据数组。数据可以是最高 3 维的数值数组。

findSpecs

一个 Boolean。如果为 true（默认值），则绘图区域的边界会自动确定。如果为 false，则沿用之前的边界。

refresh

一个 Boolean。如果为 true（默认值），则立即刷新视图。

separately

一个 Boolean。若为 true（默认值），则每组数据的最小值和最大值将被分别计算，并在每个绘图中分别显示。若为 false，则每个绘图在 y 轴上的范围将相同。

minval

（可选）y 轴上显示的最小值。

maxval

（可选）y 轴上显示的最大值。

defaultRange

（可选）当数据的最大值和最小值相同时，y 轴的默认范围。

.findSpecs

如果为 true，则自动从新数据（使用最小值和最大值）派生规格。默认值：true。

.data

对当前内部数据的引用（形状深度最多为 3）。

编辑模式

.editMode

如果编辑模式设为 true，则可以通过光标编辑数据。

a = (0..20).plot;
a.editMode = true; // 现在通过点击绘图来编辑数据..
a.value; // 更新后的值

.editFunc

提供一个在编辑数据时求值的函数。该函数调用时带有以下参数：plotter、plotIndex、index、val、x、y。

讨论：

Example:

(
a = { (0..10).scramble.normalize }.dup(2).plot;
a.editMode = true;
a.editFunc = { |...args| args.postln };
)

// 将 plotter 用作控制界面
(
a = { (0..10).scramble.normalize(300, 400) }.dup.plot;
a.specs = \freq; a.plotMode = \bars;
a.editMode = true;
x = {
    var phase = SinOsc.ar(\rate.kr(a.value[1]));
    SinOsc.ar(\freq.kr(a.value[0]), phase).mean * 0.1
}.play;
a.editFunc = { |plotter, plotIndex, i, val|
    x.setn(\freq, a.value[0]);
    x.setn(\rate, a.value[1]);
};
a.parent.onClose = { x.release };
)

.cursorPos

返回值：

最后一个 cursorPos（一个 Point）。

示例

(
a = Plotter("the plot", Rect(600, 30, 600, 400));
a.value = (0..100).normalize(0, 8pi).sin;
)

a.value = { |i| (0..90) % (i + 12) + ((0..90) % (i + 2 * 1)) }.dup(3);
a.value = (0..12).squared;
a.plotMode = \points;
a.plotMode = \levels;
a.plotMode = \plines;

a.domainSpecs = [[0, 115, \lin, 1]];

a.parent.close; // 关闭窗口
a.makeWindow; a.updatePlotBounds; // 再次打开它

a.value = { (0..70).scramble }.dup(3);
a.plotMode = \linear;
a.value = { |i| (0..2000).normalize(0, 4pi + i).sin } ! 4; // 大量数值，测试效率
a.value = { |i| (0..10000).normalize(0, 8pi + i).sin } ! 3; // 大量数值，测试效率
a.value = { (0..140).scramble } ! 7;

a.value = { |i| (0..90).normalize(0, 8pi + (i*2pi)).sin } ! 2 * [400, 560] + 700;
a.value = { |i| (_ + 2.0.rand).dup(100).normalize(0, 8pi + i).sin } ! 2 * 400 + 700;


// 单值的多声道扩展
a.value = { |i| (_ + 2.0.rand).dup(100).normalize(0, 8pi + i).sin *.t [1, 2, 3] } ! 2 * 400 + 700;
a.value = { |i| (0..10) **.t [1, 1.2, 1.3, 1.5] * (3.5 ** i) }.dup(3);

a.parent.bounds = Rect(400, 100, 500, 700);
a.parent.bounds = Rect(600, 30, 500, 300);

a.superpose = true;
a.value = { |i| (0..20) * (3.5 ** i) }.dup(5);
a.superpose = false;

(
var ys, xs; // ys：数据，xs：域位置
var rs = 0, plt2;

// xs 是在 2pi 范围内的采样点

// 样本位置，归一化
xs = 50.collect({ rrand(0.05, 1) }).normalizeSum;
xs.do{ |me, i| xs[i] = me + rs; rs = rs + me };

// 强制起点/终点落在 0/2pi
xs[0] = 0;
xs[xs.size-1] = 1;

// 将这些点缩放到 2pi 范围
xs = xs * 2pi;

// ys 是正弦波在采样点处的值
ys = sin(xs);

// 当以均匀采样显示时，
// 不均匀采样变得明显
ys.plot("original data plot, uniform domain", [100, 100, 385, 285].asRect);

// 生成第二个图，其 domainSpec 被指定：
// 我们看到一个平滑的正弦周期开始
// 于 0 并结束于 2pi
plt2 = ys.plot("resampled domain", [100+400, 100, 385, 285].asRect);

// 域值将绘制的点放置在它们实际
// 采样正弦波的位置，从而在视觉上
// 重建它。
plt2.domain = xs;

// 这些值被放置在 domainSpec 内
// 因此我们可以在图的两侧留出边距。
plt2.domainSpecs_(([-0.5pi, 2.5pi]).asSpec);
)

单位标签

网格规格的单位以标签形式显示，可以是轴标签或附加在刻度标签之后。单位标签不会覆盖已有标签，并且可以完全禁用。

( // 默认情况下单位显示在坐标轴标签中
p = (4 ** (-1.5, -1.25 .. 0)).plot;
p.specs = \delay.asSpec.minval_(0.1);
p.domainSpecs = [0, 10, \lin, 0, 0, "xUnits"].asSpec;
p.setGridProperties(\y, \constrainLabelExtents, false);
p.setGridProperties(\x, \constrainLabelExtents, true);
)

p.showUnits = false;      // 隐藏单位
p.unitLocation = \ticks;  // 将单位移到刻度标签
p.showUnits = true;       // 显示单位
p.axisLabelX = "X LABEL"; // 设置轴标签
p.unitLocation = \axis;   // 将单位移动到坐标轴
// ... x 轴标签没有被覆盖
p.axisLabelX = nil        // 移除 x 轴标签
p.unitLocation = \axis;   // 再次将单位设置为坐标轴
// ... 单位现在显示在 x 轴上

// 自定义 Y 轴标签
p.setGridProperties(\y, \labelAppendString, " y");
// 将单位移到刻度标签
p.unitLocation = \ticks;
// ... y 轴刻度标签不会被覆盖
// 现在移除 y 轴刻度标签字符串
p.setGridProperties(\y, \labelAppendString, nil);
// 再次将单位设置为刻度标签
p.unitLocation = \ticks;
// ……单位现在出现在 y 轴刻度标签上
