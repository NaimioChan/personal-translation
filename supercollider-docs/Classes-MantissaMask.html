MantissaMask

降低精度。

UGen : AbstractFunction : Object

说明

屏蔽浮点采样值尾数中的某些位。这会引入量化噪声，但比线性量化信号要轻微。

类方法

MantissaMask.ar(in: 0.0, bits: 3, mul: 1.0, add: 0.0)

MantissaMask.kr(in: 0.0, bits: 3, mul: 1.0, add: 0.0)

参数：

in

输入信号。

bits

要保留的尾数位数。一个从 0 到 23 的数字。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

// 仅保留尾数的 3 位。
{ MantissaMask.ar(SinOsc.ar(SinOsc.kr(0.2, 0, 400, 500), 0, 0.4), 3) }.play

// 原始版本
{ SinOsc.ar(SinOsc.kr(0.2, 0, 400, 500), 0, 0.4) }.play

// 差异。
(
{
    var in;
    in = SinOsc.ar(SinOsc.kr(0.2, 0, 400, 500), 0, 0.4);
    in - MantissaMask.ar(in, 3)
}.play
)


// 保留 7 位尾数。
// 这使得浮点数的低 16 位变为零。
{ MantissaMask.ar(SinOsc.ar(SinOsc.kr(0.2, 0, 400, 500), 0, 0.4), 7) }.play

// 原始版本
{ SinOsc.ar(SinOsc.kr(0.2, 0, 400, 500), 0, 0.4) }.play

// 差异。
(
{
    var in;
    in = SinOsc.ar(SinOsc.kr(0.2, 0, 400, 500), 0, 0.4);
    in - MantissaMask.ar(in, 7)
}.play
)
