控件（通常）是参数

使用控件（它们最常被定义为 ugenGraphFunc 中的参数）向 synth 提供信息，可以在创建时和/或运行之后提供。为参数提供默认值可使代码更易读，并防止用户错误（例如忘记为参数提供值）。

(
// 3 个参数（控件）带默认值
SynthDef(
    "withControls",
    { arg freq = 440, beatFreq = 1, mul = 0.22;
    Out.ar(
        0,
        SinOsc.ar([freq, freq+beatFreq], 0, mul)
    )
}).add;
)

// 数组中的项在创建时传递给 Synth 中的控件
z = Synth("withControls", [\freq, 440, \beatFreq, 1, \mul, 0.1]);

// 在合成器运行后评估此行以重置其控件
z.set(\freq, 700, \beatFreq, 2, \mul, 0.2);

////////////////////////////////////////////////////////////////////////////////////////////////////

在作为参数传给 synth 的数组中写入控制名称和相应的值。控制名称可以以符号形式给出（在 SuperCollider 系统内唯一的名称）。

Synth("withControls", [\freq, 440, \beatFreq, 0.5, \mul, 0.1]);

或作为字符串（字符数组）

Synth("withControls", ["freq", 440, "beatFreq", 0.5, "mul", 0.1]);

无论哪种方式，模式都是

[ controlName, value, controlName, value, controlName, value]。

参见 SuperCollider 帮助系统中的 Symbol 和 String 文件。

////////////////////////////////////////////////////////////////////////////////////////////////////

向 synth 传递控制的第三种方式是作为

Synth("withControls", [0, 440, 1, 1, 2, 0.1]);

在这种情况下，模式是

[ controlIndex, value, controlIndex, value, controlIndex]。

调整控件

使用 .set 消息在 synth 运行时改变控件的值。

(
SynthDef("resetMyControls", { arg freq = 440, mul = 0.22;
    Out.ar(
        0,
        SinOsc.ar([freq, freq+1], 0, mul)
    )
}).add;
)

~aSynth = Synth("resetMyControls", [\freq, 440, \mul, 0.06]);
~aSynth.set(\freq, 600, \mul, 0.25);

环境变量

上一示例中 aSynth 前面的 '~' 字符定义了一个环境变量。使用环境变量的一个优点是它不必像下面这样显式声明，

var aSynth; // 不带 '~' 的变量必须先声明！！

更准确地说，~ 字符会将一个名为 'aSynth' 的变量放入一个被称为 currentEnvironment 的对象的实例中。更多信息请参阅 SuperCollider 帮助系统中的 Environment 文档。

在这种用法中，~aSynth 的作用类似于其他编程语言中的全局变量。按严格定义，它并不完全是全局的，但在 SuperCollider 中可以这样使用。

延迟时间

使用滞后时间数组来声明从一个控制值平滑滑变到另一个控制值所需的时间。将滞后时间写入数组，并放置在 synthdef 中的 ugenGraphFunc 之后，如下所示

(
SynthDef("controlsWithLags", { arg freq1 = 440, freq2 = 443, mul = 0.12;
    Out.ar(
        0,
        SinOsc.ar([freq1, freq2], 0, mul)
    )
}, [4, 5]).add;
)

~aSynth = Synth("controlsWithLags", [\freq1, 550, \freq2, 344, \mul, 0.1]);
~aSynth.set(\freq1, 600, \freq2, 701, \mul, 0.05);

SynthDef 模板

滞后时间数组意味着带有两个组件的 synthdef 模板（在07_SynthDefs中讨论过）

// 一个包含两个组件的 synthdef 模板
SynthDef(
    "aSynth",                // 第一个参数是名称
    { .... i am a ugenGraphFunc ... }    // 第二个参数是一个 ugenGraphFunc
)

可以修改为包含三个组成部分。

// 为 synthdef 重新定义的模板 _带有 lagtimes 数组
// lagtime 数组的类定义将其称为 'rates'
SynthDef(
    "aSynth",                // name
    { .... i am a ugenGraphFunc ... },    // ugenGraphFunc
    [ ... lagTimes ... ]            // rates
)
