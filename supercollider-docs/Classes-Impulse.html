Impulse

脉冲振荡器。

PureUGen : UGen : AbstractFunction : Object

参见：Blip

说明

输出非带限的单采样脉冲。

类方法

Impulse.ar(freq: 440.0, phase: 0.0, mul: 1.0, add: 0.0)

Impulse.kr(freq: 440.0, phase: 0.0, mul: 1.0, add: 0.0)

参数：

freq

频率，单位为赫兹。freq 可以为负。

phase

以周期为单位的相位偏移（0..1）。保持在此范围内会带来轻微的效率优势，不过也支持此范围之外的相位偏移，并会在内部进行环绕处理。

mul

输出将乘以该值。

add

此值将被添加到输出中。

讨论：

Impulse 将在第一个采样上输出 1.0（假设没有相位偏移）。

如果初始 freq = 0，则在第一个采样上输出单个脉冲，随后保持静音，直到频率发生变化。

(freq, phase) 支持的速率组合为 (a,a)、(a,k)、(a,i)、(k,k)、(k,i)、(i,k)、(i,i)。

Impulse 基于一个环绕相位器：相位在每一帧推进，如果相位超出范围并在该帧内被环绕，则输出一个脉冲。

在内部，phase偏移值会被应用并包裹到范围内，然后再应用相位增量（由freq决定）。在此相位增量之后，检查触发条件。因此，触发脉冲的是相位增量（freq），而不是相位偏移。

例如，如果你想通过设置 freq: 0 并直接调制 phase 偏移来创建脉冲序列，Impulse 将不支持这一点。但是，你可以使用 Phasor 的 rate 参数通过相位调制来生成脉冲序列，如下所示：

(
{
    var f = 1000;
    HPZ1.ar(HPZ1.ar(
        Phasor.ar(rate: f * SampleDur.ir)
    )) > 1e-5
}.plot(0.005).plotMode_(\dstems)
)
