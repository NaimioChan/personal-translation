NodeEvent

Event 的类 synth 和类 group 接口

参见：Event

说明

方法 Event: -synth 和 Event: -group 将接收者的父事件设置为特殊的 event，这些 event 复制了 Synth 和 Group 对象的功能。这些对象遵循 pattern 的命名约定（即 groups 和 addActions 是整数 ID），并且具有与 Pattern-play 创建的 EventStreamPlayers 相同的 stop/play/pause/resume 接口。因此，它们可以在控制方案和 GUI 中与 pattern 互换使用。

以下示例创建一个 nodeID = 2 的组，并在其中播放一个 synth。

g = (id: 2).group;
g.play;
a = (group: 2).synth;
a.play;
g.release;
g.stop;

Interface

play

启动 synth 或 group，返回 this.delta

stop

如果 ev[\hasGate] == true 则将 gate 设为 0，否则释放该节点

pause

禁用该节点

resume

重新启用该节点

set( key, value)

将 key 标识的控制值设为 value

split

返回一个事件数组，每个由接收者指定的 synth 或 group 对应一个事件

map(key, busID)

将 control 映射到 control 总线

before(nodeID)

移动到紧邻 nodeID 之前

after(nodeID)

移动到 nodeID 之后紧接的位置

headOf(nodeID)

立即移动到 nodeID 的头部

tailOf(nodeID)

立即移动到 nodeID 的尾部

多通道扩展

除 ~server、~latency 和 ~instrument 之外，事件中的任何键都可以以数组为值，并遵循多通道扩展的标准规则。

示例

// 下面是一个使用它的简单示例：

// 定义一个多 Group 事件
g = (id: [2,3,4,5,6], group: 0, addAction: 1).group;
g.play; // play it

// 创建一个 Synth 事件
b = ( freq: [500,510], group: [2,3]).synth;
b.play;

b.set(\freq,[1000,1006]);

g.release;

b.play;
h = g.split;    // 拆分为单个组事件
c = b.split;    // 以及 synth 事件
c[0].set(\freq,700);
c[1].set(\freq,400);

h[0].stop;
h[1].stop;

g.stop;
