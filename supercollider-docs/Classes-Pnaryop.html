Pnaryop

n 元运算符模式

Pattern : AbstractFunction : Object

另请参阅：Pbinop、Punop、NAryOpFunction

子类：PdegreeToKey

说明

返回一个流，该流将 n 元运算符应用于接收者的流值，并接受 n-1 个流作为参数。通常，这是将 n 元运算符（即具有多个参数的方法）应用于模式的结果。

n 元运算符的示例有：blend、linlin、linexp、explin、expexp、clip、fold、wrap。

类方法

Pnaryop.new(operator, a, arglist)

参数：

operator

要应用的操作符

a

一个模式（或兼容的模式输入）

arglist

一个模式列表（或兼容的模式输入）

(
var a;
a = Pnaryop(\wrap, Pseries(0, 1, 12), [3, 7]);
a.asStream.all;

// 这与以下相同：

var a;
a = Pseries(0, 1, 12).wrap(3, 7);
a.asStream.all;

)
