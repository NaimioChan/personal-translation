CmdPeriod

注册在按下 Cmd-. 时要清除的对象

AbstractSystemAction : Object

参见：ShutDown、ServerQuit

说明

CmdPeriod 允许你注册对象，以便在用户按下 Cmd-. 时执行操作。这些对象必须实现一个名为 -cmdPeriod 的方法，该方法执行必要的任务。（你可以在自定义类中添加这样的方法。）请注意，由于 Function 将 -cmdPeriod 实现为 -value 的同义词，因此可以注册任何函数（以及因此任何任意代码）在按下 Cmd-. 时求值。

类方法

CmdPeriod.add(object)

来自父类：AbstractSystemAction

注册一个对象，使其在按下 Cmd-. 时被清除。该对象将保持注册状态，直到被显式移除，因此它会响应后续的 Cmd-. 按键。

CmdPeriod.remove(object)

来自父类：AbstractSystemAction

移除先前注册的对象。

CmdPeriod.removeAll

来自父类：AbstractSystemAction

移除所有已注册的对象。

CmdPeriod.doOnce(object)

注册一个对象，使其被求值一次，然后取消注册。

CmdPeriod.objects

CmdPeriod.objects = value

获取或设置当 CmdPeriod 被求值时调用的对象列表。

CmdPeriod.era

自启动以来 CmdPeriod 被调用的次数。

实例方法

示例

(
f = { "foo".postln };
g = { "bar".postln };
CmdPeriod.add(f);
CmdPeriod.add(g);
)

// 现在按下 Cmd-。

CmdPeriod.remove(g);

// 现在按 Cmd-. 只有 f 执行

CmdPeriod.remove(f); // 必须显式清理


// 现在按下 Cmd-。

CmdPeriod.add(g); // 一个对象只添加一次。
CmdPeriod.add(g); // 一个对象只添加一次。


// 现在按下 Cmd-。

// 再次移除它。
CmdPeriod.remove(g);


// 注意，通常你希望在函数被求值后自动移除它
// 而不是

f = { "foo".postln; CmdPeriod.remove(f) };
CmdPeriod.add(f);

// 你可以这样写：

CmdPeriod.doOnce { "foo".postln }

// 一个典型示例：
(
w = Window.new("close on cmd-.").front;
CmdPeriod.doOnce { w.close };
)


// 在某些情况下，你可能需要将函数延迟一小段时间
a = { Synth(\default) };
a.value;
CmdPeriod.add({ { a.value }.defer(0.01) });

// 全部移除
CmdPeriod.removeAll
