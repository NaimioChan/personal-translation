OSCMessagePatternDispatcher

OSCFunc 和 OSCdef 的默认模式匹配调度器。

OSCMessageDispatcher : AbstractWrappingDispatcher : AbstractDispatcher : Object

另请参阅：OSCFunc、OSCdef、AbstractWrappingDispatcher、AbstractDispatcher、AbstractMessageMatcher、OSCMessageDispatcher、OSCFuncAddrMessageMatcher、OSCFuncRecvPortMessageMatcher、OSCFuncBothMessageMatcher、OSC Communication

说明

OSCMessageDispatcher 使用模式匹配将传入的 OSC 消息分派给匹配的函数，以检查传入消息的地址模式中的正则表达式通配符是否匹配此分派器的某个 OSCFunc 的路径。通常用户不应直接创建此类实例或向其发送消息。有关 OSC 模式匹配的详细信息，请参见 http://opensoundcontrol.org/spec-1_0

类方法

实例方法

.value(msg, time, addr, recvPort)

尝试将传入的 OSC 消息与此调度器的响应函数进行匹配，并对所有匹配项求值其函数。

参数：

msg

OSC 消息以 Array 形式表示，格式为 [OSCAddress, other args]。

time

一个 Float，指示收到传入消息的时间。

addr

一个NetAddr，指示消息的来源。

recvPort

一个 Integer，表示接收消息的端口。

.typeKey

返回 'OSC unmatched'。

返回值：

一个 Symbol。
