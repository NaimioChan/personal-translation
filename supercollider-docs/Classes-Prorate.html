Prorate

按比例划分流

FilterPattern : Pattern : AbstractFunction : Object

另请参阅：Pattern

类方法

Prorate.new(proportion, pattern: 1)

参数：

proportion

一个模式，返回数字（将模式分成对）或大小为 n 的数组，用于将输入拆分为 n 部分。

pattern

一个数值模式。

实例方法

未文档化的实例方法

.embedInStream(inval)

.proportion

.proportion = value

示例

// 将 1 分成各种比例
(
a = Prorate(Pseq([0.35, 0.5, 0.8]), 1);
x = a.asStream;
x.nextN(8)
)

// 将模式分成各种比例
(
a = Prorate(Pseq([0.35, 0.5, 0.8]), Prand([20, 1], inf));
x = a.asStream;
x.nextN(8)
)


// 将 1 分成若干部分
(
a = Prorate(Pseq([[1, 2], [5, 7], [4, 8, 9]]).collect(_.normalizeSum), 1);
x = a.asStream;
x.nextN(8)
)
