Pfunc

函数模式

Pattern : AbstractFunction : Object

参见：Pfuncn、FuncStream

说明

返回一个 Stream，它从 nextFunc 返回各个值。若要返回模式，请参见 Plazy。

类方法

Pfunc.new(nextFunc, resetFunc)

参数：

nextFunc

流函数。在事件流中，nextFunc 接收当前 Event 作为参数，更一般地，接收传递给流的 next 调用的参数。

resetFunc

当流被重置时调用的函数。resetFunc 不接收任何参数。

实例方法

未文档化的实例方法

.asStream

.nextFunc

.nextFunc = value

.resetFunc

.resetFunc = value

示例

数值流示例

(
var a, x;
a = Pfunc({ exprand(0.1, 2.0) + #[1, 2, 3, 6].choose }, { \reset.postln });
x = a.asStream;
x.nextN(20).postln;
x.reset;
)

// 并将参数传递给 nextFunc
(
x = Pfunc({ |inval| (10 ** inval.value) * rrand(1, 9) }).asStream;
[2, 3, 2].do { |i| x.next(i).postln };
x.nextN(5, (:0..)).postln;
)

事件流（声音）示例：

(
SynthDef(\help_sinegrain,
    { |out = 0, freq = 440, sustain = 0.05|
        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain, 0.2), doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env))
    }).add;
)

(
var a;
a = Pfunc({ exprand(0.1, 0.3) + #[1, 2, 3, 6, 7].choose }).asStream;
{
    a.do { |val|
        Synth(\help_sinegrain, [\freq, val * 100 + 300]);
        0.02.wait;
    }
}.fork;
)

播放 Event 时，如果设置了 \freq，则忽略 \degree（由于 Event.default 机制）。在 Patterns 链中，可以使用 Pfunc 从 Event 流中删除某个键；这甚至可以在 Pbind 内部完成。

q = Pbind(\freq, 300, \dur, Pn(0.3, 2));
q.trace.play;

// 对输入流进行声音上无效果的修改
p = Pbind(\degree, 6) <> q;
p.trace.play;

// 取而代之
p = Pbind(\degree, 6) <> Pfunc { |ev| ev.freq = nil } <> q;
p.trace.play;

// 或者
p = Pbind(\degree, Pfunc { |ev| ev.freq = nil; 6 }) <> q;
p.trace.play;

// 在 Pbind 对中把某个键设为 nil 就会结束该流
p = Pbind(\freq, nil, \degree, 6) <> q;
p.trace.play; // 静音，因为它不输出任何事件
