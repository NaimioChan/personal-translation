CheckBadValues

测试无穷大、非数值和次正规数

UGen : AbstractFunction : Object

说明

这个 UGen 检测无穷大、NaN（非数字）和非规格化数。如果检测到其中一种，它会发布警告。其输出如下：0 = 正常浮点数，1 = NaN，2 = 无穷大，3 = 非规格化数。

类方法

CheckBadValues.ar(in: 0.0, id: 0, post: 2)

CheckBadValues.kr(in: 0.0, id: 0, post: 2)

参数：

in

其输出将被测试的 UGen。

id

用于标识此 UGen 的 id 编号。默认值为 0。

post

三种后置模式之一：

  • 0 = 不发布；
  • 1 = 对每个坏值输出一行；
  • 2 = 仅在浮点分类发生变化时发布一行（例如，normal -> NaN 以及反之）

默认的 post 模式为 2。post 模式 1 为向后兼容而保留；请注意它会生成大量输出。

实例方法

示例

{ CheckBadValues.kr(SinOsc.ar); 0 }.play // 这里没有问题

{ CheckBadValues.kr(1 / 0, 1).poll; 0 }.play // 检查无穷大

x = { |test = -1| CheckBadValues.kr(test); 0 }.play // 检查 NaN
x.set(\test, -1.sqrt);

// 不要 post，而是对输出做一些处理
(
x = { |freq = 440|
    var good;
    good = BinaryOpUGen('==', CheckBadValues.kr(freq, 0, 0), 0);
    SinOsc.ar(freq, 0, 0.1) * good // 如果 freq 不正确则静音输出
}.play;
)
x.set(\freq, -1.sqrt);

// UGen 方法 checkBadValues 会直通输入以便快速测试
{ SinOsc.ar(440, 0, 0.1).checkBadValues }.play
