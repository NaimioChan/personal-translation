BufAllpassL

基于缓冲区的全通延迟线，带线性插值。

BufCombN : UGen : AbstractFunction : Object

另请参见：BufAllpassC、BufAllpassN、AllpassL

说明

带线性插值的全通延迟线，使用缓冲区作为其内部存储器。另请参见 BufAllpassN，它不使用插值，以及 BufAllpassC，它使用三次插值。三次插值的计算开销比线性插值更大，但更精确。

类方法

BufAllpassL.ar(buf: 0, in: 0.0, delaytime: 0.2, decaytime: 1.0, mul: 1.0, add: 0.0)

来自父类：BufCombN

参数：

buf

缓冲区编号。

in

输入信号。

delaytime

延迟时间，单位为秒。

decaytime

回声衰减 60 分贝所需的时间。如果此时间为负，则反馈系数将为负，从而只强调低一个八度的奇次谐波。

讨论：

警告： 出于效率原因，有效缓冲区大小被限制为不超过其的前一个 2 的幂。因此，如果分配了 44100 个采样，最大延迟将是 32768 个采样。

实例方法

示例

// 分配缓冲区
b = Buffer.alloc(s, 44100, 1);

// 由于全通延迟作为谐振器对
// 稳态声音没有可听效果……

{ BufAllpassC.ar(b.bufnum, WhiteNoise.ar(0.1), XLine.kr(0.0001, 0.01, 20), 0.2) }.play;

// ……这些示例将输入加到效果声音上，并比较各种变体，以便你能听到
// 相位梳的效果：

(
{
    z = WhiteNoise.ar(0.2);
    z + BufAllpassN.ar(b.bufnum, z, XLine.kr(0.0001, 0.01, 20), 0.2)
}.play)

(
{
    z = WhiteNoise.ar(0.2);
    z + BufAllpassL.ar(b.bufnum, z, XLine.kr(0.0001, 0.01, 20), 0.2)
}.play)

(
{
    z = WhiteNoise.ar(0.2);
    z + BufAllpassC.ar(b.bufnum, z, XLine.kr(0.0001, 0.01, 20), 0.2)
}.play)

// 用作回声 - 听起来与 Comb 并无太大区别，
// 但它会立即输出输入信号（反相），
// 且回声的振幅较低。
{ BufAllpassL.ar(b.bufnum, Decay.ar(Dust.ar(1, 0.5), 0.2, WhiteNoise.ar), 0.2, 3) }.play;
