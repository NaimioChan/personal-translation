Ppatlace

交织流

Pseq : ListPattern : Pattern : AbstractFunction : Object

另请参阅：Place

说明

与 Place 类似，但列表是流或模式的数组。每个流的结果将依次输出。

p = Ppatlace([Pwhite(1, 5, 5), Pgeom(10, 1.01, 10)], inf);
x = p.asStream;

请注意，Ppatlace 具有无限次重复，但生成的流是有限的，因为成员流都是有限的。当第一个流（Pwhite）结束时，它会被跳过，你只会看到第二个流，直到它停止。

即使只有一个成员流是无限的，并且 Ppatlace 具有无限重复，Ppatlace 流也会是无限的。

// Ppatlace 作为音高序列：

(
SynthDef(\help_sinegrain,
    { |out = 0, freq = 440, sustain = 0.05|
        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain, 0.2), doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env))
    }).add;
)


// 交错两个流
(
var c = Ppatlace([
        Pseq([0, 0, 0, 0, 8, 0, 8], inf),
        Pseries(1, 1, 32)
    ], inf) + 67;
x = c.asStream;

Routine({
    loop({
        Synth(\help_sinegrain, [\freq, x.next.midicps, \dur, 0.2]);
        0.17.wait;
    })
}).play;
)




// 一个更复杂的示例：

c = Ppatlace([
    Pxrand([
        Pseq(#[0, -2, -3, -5, -7], 1), Pwhite(-12, 4, 3), Pshuf(#[0, -2, -3, -5, -7], 1)

    Pxrand([
        Pseq(#[0, 2, 4, 5, 7], 1), Pwhite(-4, 12, 3), Pshuf(#[0, 2, 4, 5, 7], 1)

)
