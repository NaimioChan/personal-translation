SoundIn

从硬件输入读取音频

Object

参见：In、ServerOptions

子类：AudioIn

说明

SoundIn 是一个便捷的 UGen，用于从你的电脑或声卡输入读取音频。它是一个封装 UGen，基于 In，它对索引进行偏移，使得无论存在多少个输入，0 始终对应第一个输入。

注意： 在基于 Intel 的 Mac 上，读取内置麦克风或输入可能需要在 AudioMIDI Setup 中创建一个聚合设备。"open -a 'Audio MIDI Setup'".unixCmd; // execute this to launch it

类方法

SoundIn.ar(bus: 0, mul: 1.0, add: 0.0)

参数：

bus

要读取的通道（或通道数组）。这些通道从 0 开始，对应第一个音频输入。

mul

add

未文档化的类方法

SoundIn.channelOffset

实例方法

示例

// 世界上最昂贵的跳线（使用耳机以避免反馈）
{ SoundIn.ar(0) }.play;

// 立体声版本
{ SoundIn.ar([0, 1]) }.play;

// 示波器输入；静音输出
{ Amplitude.kr(SoundIn.ar(0)) }.scope;
