BeatTrack

自相关节拍跟踪器

MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：BeatTrack2

说明

基于自相关的节拍跟踪器；1 其底层模型假定为 4/4 拍，但它应能适用于任何等时节拍结构，不过会偏向 100-120 bpm；从这个意义上说，快速的 7/8 拍可能无法被跟踪。有四个 k-rate 输出，分别是在所确定节拍基础上的四分音符、八分音符和十六分音符级别的脉冲，以及当前检测到的速度。请注意，如果要跟踪的音乐带有摇摆感，十六分音符输出未必有多大意义；它只是作为便利而提供。

此节拍跟踪器通过加权函数偏向中速范围来确定节拍。它不测定小节层级，只确定 tactus。它的反应也较慢，使用 6 秒的时间窗口进行自相关操作。不要期望达到人类音乐家水平的预测跟踪能力。

另一方面，它不知疲倦、相对通用（尽管显然最擅长处理没有太多表情速度变化的瞬态 4/4 重型素材），并且可以作为比人类明显更快的计算机处理的基础。

类方法

BeatTrack.kr(chain, lock: 0)

参数：

chain

[fft] 要跟踪的音频输入，已经过 FFT UGen 处理；对于 44100 和 48000 采样率，预期的 FFT 大小为 1024，对于两倍于这些值的采样率，则为 2048。不支持其他采样率。

lock

[sk] 如果此参数大于 0.5，跟踪器将锁定在其当前周期性上并从当前相位继续。虽然它会更新模型的相位和周期，但在 lock 回到 0.5 以下之前，这不会反映在输出中。

返回值：

四个 k-rate 输出：

#quarternotetick, eighthnotetick, sixteenthnotetick, tempo = BeatTrack.kr(chain, 0)

实例方法

示例

// 这是一首一分钟的流行歌曲；你应该加载类似的东西来测试
d = Buffer.read(s, "/Volumes/data/stevebeattrack/samples/100.wav");


// 你也可以在 48000 下测试，它应该能正常工作
(
a = SynthDef(\help_beattrack, { |out, vol = 1.0, beepvol = 1.0, lock = 0|
    var in, fft, resample;
    var trackb, trackh, trackq, tempo;
    var bsound, hsound, qsound, beep;

    in = PlayBuf.ar(1, d, BufRateScale.kr(d), 1, 0, 1);
    // in = SoundIn.ar(0);

    fft = FFT(LocalBuf(1024), in); // 对于采样率 44100 和 48000

    #trackb, trackh, trackq, tempo = BeatTrack.kr(fft, lock);

    beep = SinOsc.ar(1000, 0.0, Decay.kr(trackb, 0.1));

    Out.ar(out, Pan2.ar((vol * in) + (beepvol * beep), 0.0))

}).play
)

a.set(\vol, 0.0);
a.set(\vol, 1.0);

a.set(\beepvol, 1.0);
a.set(\beepvol, 0.0);

a.set(\lock, 1); // 从当前相位/周期解刚性固定它
a.set(\lock, 0); // 取消固定，回到跟踪

跟踪音频输入（试着拍一段节拍或用口技打拍子，但请留出最多 6 秒以让跟踪开始），并在四分音符、八分音符和十六分音符处生成内容：

(
SynthDef(\help_beattrack2, { |out|
    var trackb, trackh, trackq, tempo;
    var source;
    var bsound, hsound, qsound;

    source = SoundIn.ar(0);

    #trackb, trackh, trackq, tempo = BeatTrack.kr(FFT(LocalBuf(1024)));

    bsound = Pan2.ar(LPF.ar(WhiteNoise.ar * Decay.kr(trackb, 0.05), 1000), 0.0);

    hsound = Pan2.ar(BPF.ar(WhiteNoise.ar * Decay.kr(trackh, 0.05), 3000, 0.66), -0.5);

    qsound = Pan2.ar(HPF.ar(WhiteNoise.ar * Decay.kr(trackq, 0.05), 5000), 0.5);

    Out.ar(out, bsound + hsound + qsound);
}).play;
)

[1] - 研究说明：此 UGen 是对以下工作的衍生实现：Davies, M. E. P. and Plumbley, M. D. Beat Tracking With A Two State Model. Proceedings of the IEEE International Conference on Acoustics, Speech and Signal Processing (ICASSP 2005), Philadelphia, USA, March 19-23, 2005。该 UGen 由 Nick Collins 在其博士研究期间为节拍跟踪研究而转换，使用了 Matthew Davies 的 MATLAB 模型的原始 C 实现。它最初作为 BBCut2 的一部分以 AutoTrack 之名出现，现在已被加入核心，以增强 SuperCollider 的实时机器监听选项。
