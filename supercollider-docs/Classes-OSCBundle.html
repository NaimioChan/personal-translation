OSCBundle

网络 bundle 对象

Object

另请参阅：OSC Communication

子类：MixedBundle

说明

一个 bundle 对象，允许为异步进程添加准备消息。如果不需要此功能，可以改用列表对象。

类方法

实例方法

.add(msg)

向该 bundle 添加一条 osc 消息。

.addAll(mgs)

向 bundle 添加一个 osc 消息数组。

.addPrepare(msg)

添加一条准备 osc 消息，该消息在发送 bundle 之前发送。

.send(server, time, timeOfRequest)

将 bundle 发送到服务器。如果给出了准备消息，则发送它们，进程等待接收它们，然后发送 bundle。

.schedSend(server, clock, quant)

与 send 类似，但发送会同步到给定时钟的下一个拍点。

参数：

server

一个 Server。

clock

一个 TempoClock。

quant

可以是一对值：[quant, offset]。

示例

// 创建一个新的空实例
a = OSCBundle.new;

// 一个需要发送到服务器的 synthdef，一个异步操作，
// 即我们必须等待它完成。
x = SynthDef("test", { OffsetOut.ar(0, BPF.ar(Impulse.ar(4) * 10, Rand(9000, 1000), 0.1)) });
// 这就是使用 addPrepare 的原因。
a.addPrepare(["/d_recv", x.asBytes]);
// add 用于同步操作，例如启动合成器。
a.add(["/s_new", "test", -1]);

// 现在该 bundle 已将同步 bundle 与异步 bundle 分开：
a.messages;
a.preparationMessages;

// 这可以简单地发送 - bundle 会处理服务器客户端的通信，
// 比如等待 synthdef 加载完成。合成器会在准备工作
// 完成后启动。

s.boot; // 启动服务器
a.send(s);

s.freeAll; // 释放服务器上的所有节点

// 定时发送：合成器在下一拍启动。

a.schedSend(s, TempoClock.default, 1);
a.schedSend(s, TempoClock.default, 1);
a.schedSend(s, TempoClock.default, 1);

s.freeAll; // 释放服务器上的所有节点

// 该 bundle 一次可以包含若干 preparation 消息和消息。
// preparationMessages 会先被发送，只有当它们全部完成后，
// 其他 bundle 才会被发送。
// 如果没有专门分配的缓冲区/节点 ID，该 bundle 也可以被复用。
