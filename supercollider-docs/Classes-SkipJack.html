SkipJack

一个用于在 cmd-period 后仍能存活的背景任务的工具

Object

参见：CmdPeriod

说明

SkipJack 是一个用于在后台重复运行函数的工具，可在 cmd-period 后继续存活。

一个典型的用法是使用一个窗口，每隔一段时间显示某些对象的状态。（在某些情况下，这比在每次更改时更新 GUI 更好。如果更改发生得很快，你就不会因为 GUI 更新而让 CPU 过载。）

但当你需要一个周期性函数在后台运行，并且即使用户按下 cmd-period 也不会消失时，SkipJack 就很有用。

类方法

SkipJack.new(updateFunc, dt: 0.2, stopTest: false, name: "anon", clock, autostart: true)

参数：

updateFunc

一个在后台重复执行的 Function。

dt

重复的时间间隔。它也可以是一个流或一个返回数字的函数。

stopTest

用于判断是否立即停止该任务的测试。通常是一个 Function。

name

此 skipjack 的名称。用于发布信息以及在 *stop 类方法中使用。

clock

播放该任务的时钟。默认是 AppClock，因此 SkipJack 可以调用 GUI 原语。如果需要更精确的时序，可以自行提供时钟，并仅在必要时使用 defer。

autostart

为 true（默认值）时，SkipJack 在创建时自动启动。

SkipJack.stop(name)

按名称停止 skipjack。

SkipJack.stopAll

停止所有 skipjack。

SkipJack.defaultClock

默认时钟（AppClock）

SkipJack.verbose

SkipJack.verbose = value

为 true 时，SkipJack 在启动、停止或重启时发布消息。

SkipJack.all

所有 skipjack 的全局集合。

实例方法

.dt

.dt = value

获取或设置时间间隔。

.task

包裹 updateFunc 的内部 Routine。

.name

此 skipjack 的名称。

.stopTest

.stopTest = value

当前的 stopTest。（参见 *new 中的参数）

.start

启动此 skipjack。

.play

与 start 相同

.stop

停止此 skipjack。

.clock

.clock =

获取或设置所使用的时钟。这仅在 skipjack 重新启动时才会更新。

.updateFunc

由 *new 的参数设置的 updateFunc

示例

简单示例：

w = SkipJack({ "watch...".postln }, 0.5, name: "test");
SkipJack.verbose = true;    // 记录停止/唤醒日志

w.stop;
w.start;

//     现在尝试用 cmd-. 停止：SkipJack 总会自行重启。
thisProcess.stop;

w.stop;

使用 stopTest：

a = 5;
w = SkipJack({ "watch...".postln }, 0.5, { a == 10 }, "test");
a = 10;    // 满足 stopTest

典型用法：SkipJack 会不时更新一个显示某些对象状态的窗口。

(
d = (a: 12, b: 24);
d.win = Window("dict", Rect(0, 0, 200, 60)).front;
d.views = [\a, \b].collect { |name, i|
    StaticText(d.win, Rect(i * 100, 0, 96, 20))
        .background_(Color.yellow).align_(0).string_(name);
};
w = SkipJack({
        "...".postln;
        [\a, \b].do { |name, i|
            d.views[i].string_(name ++ ":" + d[name])
        }
    },
    0.5,
    { d.win.isClosed },
    "showdict"
);
)

d.a = 123;      // 更新应被显示
d.b = \otto;
d.win.close;    // 窗口关闭时，SkipJack 停止。

如果你需要清除不可达的 skipjack：

SkipJack({ "unreachable, unkillable...".postln }, name: "jack");

SkipJack.stopAll        // 执行此操作以停止全部；

SkipJack.stop("jack");  // 通过名称访问它并停止
