ProxySpace

服务器上引用的环境

LazyEnvir : EnvironmentRedirect : Object

参见：NodeProxy、ProxyMixer、JITLib

说明

通常，代理是某物的占位符。节点代理是在服务器上播放、写入有限数量总线（例如 Synth 或事件流）的某物的占位符。NodeProxy 对象可以在播放时被替换和重新组合。它们也可用于构建一个较大的结构，该结构在之后被使用和修改。概览：JITLib

访问时，ProxySpace 返回一个 NodeProxy。一个类似但不带环境的类：Ndef

更多示例参见：ProxySpace examples、jitlib_basic_concepts_01

GUI 概览请参见 ProxyMixer。许多相关方法请参见 NodeProxy。

第一个示例

s.boot;

p = ProxySpace.new;
p.fadeTime = 2; // fadeTime 指定交叉淡化
p[\out].play; // 通过硬件输出监视一个空占位符
// 设置其源
p[\out] = { SinOsc.ar([350, 351.3], 0, 0.2) };
p[\out] = { Pulse.ar([350, 351.3] / 4, 0.4) * 0.2 };
p[\out] = Pbind(\dur, 0.03, \freq, Pbrown(0, 1, 0.1, inf).linexp(0, 1, 200, 350));

// 将一个代理路由到另一个代理：
p[\out] = { Ringz.ar(p[\in].ar, [350, 351.3] * 8, 0.2) * 4 };
p[\in] = { Impulse.ar([5, 7]/2, [0, 0.5]) };

p.clear(3); // 3 秒后清除

类方法

Creation

ProxySpace.new(server, name, clock)

参数：

server

一个 Server 对象。请注意，在远程计算机上时钟必须同步。

name

一个 Symbol。如果给出了名称，则代理空间会被存储到 ProxySpace.all 中该名称下。

clock

对于基于事件或节拍同步的播放，请使用 TempoClock。

ProxySpace.push(server, name, clock)

用一个新的 ProxySpace 替换 currentEnvironment，并清除当前的 currentEnvironment（如果它是一个 ProxySpace），以避免代理空间堆积。

要在保留当前 ProxySpace 的同时移动到另一个 ProxySpace，请使用 pop，然后 push 一个新的。要拥有多个层级的 proxy space，请使用 .new.push;

ProxySpace.pop

来自父类：EnvironmentRedirect

恢复之前的 currentEnvironment

ProxySpace.clearAll

清除所有已注册的空间

实例方法

播放与访问

.play(key: 'out', out: 0, numChannels: 2)

返回一个在该 key 处播放 NodeProxy 的组。

参数：

key

一个 Symbol

out

输出通道偏移

numChannels

播放此数量的声道。

.record(key, path, headerFormat: "aiff", sampleFormat: "int16")

返回一个 RecNodeProxy，它记录该键处的 NodeProxy。

.ar(key: 'out', numChannels, offset: 0)

.kr(key: 'out', numChannels, offset: 0)

返回一个 NodeProxy 输出，用于播放该键处的 NodeProxy，以便在用作节点代理输入的函数中使用

.wakeUp

在沒有运行中的服务器的情况下创建 proxyspace 时，可以使用此方法。要运行它（在内部这也会由 -play 完成）。

.fadeTime

.fadeTime = dt

设置所有代理的淡入淡出时间以及默认淡入淡出时间

.clock

.clock = aClock

设置所有代理以及默认时钟的时钟。

.quant

.quant = val

设置所有代理以及默认量化的量化。

.free(fadeTime)

释放所有 proxy（即也释放组，但不停止监视器）

.release(fadeTime)

释放所有代理（即保持组继续运行）

.stop(fadeTime)

停止所有代理（仅停止监视器，不停止 Synth）

.end(fadeTime)

结束所有 proxy（释放并停止监视器）

.clear(fadeTime)

清除所有代理并从环境中移除它们。这会释放所有总线。如果给出了 fadeTime，则先淡出，再清除。

.add

将 ProxySpace 添加到仓库（需要名称）

.remove

从仓库中移除 ProxySpace

设置源

rate 和 numChannels 的 NodeProxy 是惰性方式确定的，依据是首次放入此环境的对象（见帮助文件）。一旦创建，就只能设置为一个函数，该函数返回相同的速率，并且通道数等于或小于初始通道数。详情请参见 the_lazy_proxy。

.put(key, obj)

来自父类：LazyEnvir

获取 key 处的 NodeProxy（如果不存在，则返回一个新的），并将其源设置为 obj。关于其工作原理，另请参见 LazyEnvir 和 NodeProxy。

.at(key)

来自父类：LazyEnvir

返回该键处的代理源对象。

垃圾回收

.clean(excluding)

释放并移除所有不需要的代理，以便播放通过 'exclude' 传入的代理。如果未传入任何代理，则所有正在监视（使用 .play 消息）的代理及其父级等都会被保留。

.reduce(excluding, method: 'end')

释放所有不需要的代理，以便播放通过 'to' 传入的代理。如果没有传入任何代理，则保留所有被监视（通过 play 消息）的代理及其父级等。

制作副本

.copy

将环境复制到一个新环境中，每个代理也会被一并复制（参见：NodeProxy: -copy）。同时还会包含决定 ProxySpace 行为的实例变量，例如 server、fadeTime、quant、reshaping（这在 copyState 方法中发生）。

p = ProxySpace.push(s.boot);
p.reshaping = \elastic;
~out.play;
~out = { Blip.ar(~freq, ~numharm) };
~freq = 70;
~numharm = { MouseX.kr(2, 100, 1) };

q = p.copy; p.pop; q.push;

q.reshaping.postln; // 也有弹性
~out.play;
~freq = { MouseY.kr(2, 1000, 1) * [1, 1.2] };

p.end; q.end;

编写代码

.document(keys, onlyAudibleOutput: false, includeSettings: true)

来自扩展 /usr/local/share/SuperCollider/SCClassLibrary/JITLib/ProxySpace/extStoreOn.sc

用当前 proxyspace 状态创建一个新文档。这不允许将函数作为代理源打开。参见：jitlib_asCompileString。

参数：

keys

用于记录 proxy 子集的键列表

onlyAudibleOutput

一个布尔值。

includeSettings

一个布尔值。

.asCode

来自扩展 /usr/local/share/SuperCollider/SCClassLibrary/JITLib/ProxySpace/extStoreOn.sc

如果 proxyspace 可全局访问，则会发布一个可访问它的代码字符串。

p = ProxySpace.push(s.boot);
p.reshaping = \elastic;
p.asCode;
p.pop;

Ndef(\x); // 为默认服务器初始化一个 Ndef proxyspace
Ndef.all[\localhost]; // 访问该代理空间
Ndef.all[\localhost].asCode; // 作为有效代码发布

示例

// ProxySpace 返回 NodeProxy 的实例：
a = NodeProxy(s)     is equivalent to ~a;
a.source = ...        is equivalent to ~a = ...
a[3] = ...        is equivalent to ~a[3] = ...

// 这两个表达式等价：
~out = something;
currentEnvironment.put(\out, something);
// 示例

p = ProxySpace.push(s.boot); // 将 ProxySpace 用作当前环境。

~out.play;

~out = { SinOsc.ar([400, 407] * 0.9, 0, 0.2) };

~out = { SinOsc.ar([400, 437] * 0.9, 0, 0.2) * LFPulse.kr([1, 1.3]) };

~out = { SinOsc.ar([400, 437] * 0.9, 0, 0.2) * ~x.kr(2) };

~x = { LFPulse.kr([1, 1.3] * MouseX.kr(1, 30, 1)) };

~out = { SinOsc.ar([400, 437] * Lag.kr(0.1 + ~x, 0.3), 0, 0.2) * ~x };

p.fadeTime = 5;

~out = { SinOsc.ar([400, 437] * 1.1, 0, 0.2) * ~x.kr(2) };

p.clear(8); // 在 8 秒内结束并清除所有内容。


p.pop; // 移出。
