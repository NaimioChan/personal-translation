颜色角色

调色板中颜色角色的列表及其含义

调色板（参见 QPalette）由分配给三个颜色组内各种颜色角色的颜色组成（参见 颜色组）。以下是用于表示颜色角色的可能符号及其含义的列表。

Role

Meaning

'window'

窗口背景。视图也可以使用此角色，例如用来推导其边框的颜色。它也是 StaticText 的背景。

'windowText'

位于 'window' 顶部的文本，例如在 StaticText 中。

'button'

所有类似按钮的东西。例如 Button 的背景，以及 Slider 的滑块。

'buttonText'

'button' 上的文本。

'brightText'

可用于按下 Button 上的文本。

'base'

显示大量文本的视图的背景（TextView、ListView 等）。

'baseText'

位于 'base' 之上的文本。

'alternateBase'

ListView 可以为行使用交替的背景颜色。

'toolTipBase'

工具提示的背景。

'toolTipText'

工具提示的文本。

'highlight'

用于指示选中状态，如 ListView 等中。

'highlightText'

选中的文本 / 项。

'link'

网页上链接的默认颜色。

'linkVisited'

网页上已访问链接的默认颜色。

此外，以下角色用于创建 3D 效果：

Role

Meaning

'light'

比 'button' 更浅。

'midlight'

在 'button' 和 'light' 之间。

'middark'

介于 'button' 与 'dark' 之间。

'dark'

比 'button' 更暗。

'shadow'

一种非常暗的颜色。
