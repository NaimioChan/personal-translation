CustomViewAction

一个可以包含 View 的 MenuAction。

参见：MenuAction、Menu、ToolBar、MainMenu

说明

CustomViewAction 是一种 MenuAction，它包含一个 View 而非图标或文本。这样可以将交互式组件嵌入到 Menu 或 ToolBar 中。

(
~view = View().layout_(HLayout(
    ToolBar(
        MenuAction("Min", { ~slider.value = 0 }),
        MenuAction("Max", { ~slider.value = 1 }),
        CustomViewAction(
            ~slider = Slider().orientation_(\horizontal)
        ),
        Menu(
            MenuAction("Randomize", { ~multi.value = 4.collect({ 1.0.rand }) }),
            CustomViewAction(
                ~multi = MultiSliderView().drawLines_(true).elasticMode_(true).value_([0, 1, 0, 1])
            )
        ).title_("Submenu")
    ).minWidth_(400)
)).front;
)

类方法

.new

创建一个新的 CustomViewAction

参数：

一个 View。

当此项目被选中时要执行的 Function。

注意： 在某些情况下，CustomViewAction 包含的 View 会吸收鼠标点击，导致难以选中此菜单项（从而触发该动作）。

实例方法

.defaultView

设置附加到此 CustomViewAction 的 View。

参数：

一个 View。
