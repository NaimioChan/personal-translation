Cookbook：音序基础

播放预定义的音符序列

以下是演奏同一著名赋格主题的三种不同方式。

第一种是暴力法，按顺序机械地列出所有音阶级数。第二种和第三种识别出 A 持续音点，并使用交织操作在变化的音符之间插入持续音音符。

该示例演示了使用 \scale 和 \root 事件键来定义调性。Root = 2 表示 D，音阶定义了一种自然小调调式。音级序列还使用了变化音。从整数音级中减去 0.1 会使音高降低一个半音；加上 0.1 则升高一个半音。-0.9 比 -1 高 0.1；主音以下的自然小调音级是降 7 音，再升高一个半音就是导音。

(
TempoClock.default.tempo = 84/60;

p = Pbind(
    \scale, #[0, 2, 3, 5, 7, 8, 10],
    \root, 2,
    \degree, Pseq(#[rest, 4, 3, 4, 2, 4, 1, 4, 0, 4, -0.9, 4, 0, 4, 1, 4, 2, 4,
        -3, 4, -1.9, 4, -0.9, 4, 0, 4, -0.9, 4, 0, 4, 1, 4, 2], 1),
    \dur, 0.25
).play;
)

(
p = Pbind(
    \scale, #[0, 2, 3, 5, 7, 8, 10],
    \root, 2,
    \degree, Place([#[rest, 3, 2, 1, 0, -0.9, 0, 1, 2, -3, -1.9, -0.9, 0, -0.9, 0, 1, 2],
        (4 ! 16) ++ \rest], 17),
    \dur, 0.25
).play;
)

(
p = Pbind(
    \scale, #[0, 2, 3, 5, 7, 8, 10],
    \root, 2,
    \degree, Ppatlace([Pseq(#[rest, 3, 2, 1, 0, -0.9, 0, 1, 2, -3, -1.9, -0.9, 0, -0.9, 0, 1, 2], 1),
        Pn(4, 16)], inf),
    \dur, 0.25
).play;
)

"多声道"扩展

在 SynthDef 中，将数组用作 UGen 的输入会将 UGen 扩展为 UGen 数组（参见 Multichannel Expansion）。在模式中也会发生类似的情况。通常发送给 Synth 节点的值应该是单个数字，但如果它是数组，模式会扩展事件以产生多个 synth 节点，而不仅仅是一个。

\degree 模式将一组和弦音程应用到一个始终位于顶部的旋律上。它是一个复合模式，Pseries(...) + Prand(...)，其中 Pseries 返回单个数字，Prand 返回一个数组。与常规数学运算一样，数字加数组得到数组。如果当前 Pseries 值为 7，Prand 返回 [0, -3, -5]，则结果为 [7, 4, 2]，你会听到一个第一转位的 C 大三和弦。

(
p = Pbind(
    \degree, Pseries(7, Pwhite(1, 3, inf) * Prand(#[-1, 1], inf), inf).fold(0, 14)
        + Prand(#[[0, -2, -4], [0, -3, -5], [0, -2, -5], [0, -1, -4]], inf),
    \dur, Pwrand(#[1, 0.5], #[0.8, 0.2], inf)
).play;
)

p.stop;

使用自定义 SynthDef（包括无音高的 SynthDef）

模式具有支持多种音高组织方式的特殊功能，但这些功能完全是可选的。这里我们播放一个完全没有频率参数的 SynthDef。

注意使用 add 来准备 SynthDef。没有它，大多数 SynthDef 输入将无法被识别，模式也不会向它们发送值。

值得注意的是，该模式以拍为单位运行，其实际时长（以秒计）取决于时钟的速度。而 SynthDef 始终以秒为单位度量时间。本示例将时钟设为每秒 1 拍以简化处理。不过，如果速度需要设为其他值，应将 \time 键除以该速度：

    \time, Pkey(\delta) / Pfunc { thisThread.clock.tempo },
(
b = Buffer.read(s, ExampleFiles.child);

SynthDef(\stretchedFragments, { |out, bufnum, start, time = 1, stretch = 1, amp = 1, attack = 0.01, decay = 0.05|
    var sig = PlayBuf.ar(1, bufnum, rate: stretch.reciprocal, startPos: start), eg;
    sig = PitchShift.ar(sig, pitchRatio: stretch);
    eg = EnvGen.kr(Env.linen(attack, time, decay), sig.abs > 0, doneAction: Done.freeSelf);
    Out.ar(out, (sig * eg) ! 2)
}).add; // 注意 add！没有它，参数将无法工作
)

(
TempoClock.default.tempo = 1;

p = Pbind(
    \instrument, \stretchedFragments,
    \bufnum, b,
    \start, Pwhite(0, (b.numFrames * 0.7).asInteger, inf),
    \delta, Pexprand(0.2, 1.5, inf),
    \time, Pkey(\delta),
    \stretch, Pexprand(1.0, 4.0, inf),
    \amp, 0.5,
    \attack, 0.1,
    \decay, 0.2
).play;
)

p.stop;
b.free;    // 保持整洁！记得清理你的 Buffer
