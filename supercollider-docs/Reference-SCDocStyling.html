SCDoc 样式

帮助系统 CSS 样式自定义与主题

另请参阅：Writing Help、SCDoc、SCDocHTMLRenderer

渲染出的 HTML 文档从 scdoc.css 读取全局样式，但如果存在，也会（按此顺序）读取 frontend.css 和 custom.css。这是为了支持特定的前端，并允许用户覆盖 CSS。

因此，若要自定义 CSS，用户可以在其 SCDoc: *helpTargetDir 中，或在任意 HelpSource 目录的根目录下（例如在 YourExtension/HelpSource/custom.css 中）创建一个 custom.css。

// 打开 HelpTargetDir 查看这些 css 文件
SCDoc.helpTargetDir.openOS

Colors

颜色被定义为 CSS 变量，因此用户只需在其 custom.css 中覆盖相关变量即可更改任意颜色。随后这些变量被用于设置文档所有其他 css 文件中的任意颜色。

此处不报告具体变量，请参考默认 CSS 主题以了解所有变量的名称和默认值。

// 打开默认主题
(SCDoc.helpTargetDir +/+ "themes" +/+ "default.css").openDocument

// 将默认主题复制到 'custom.css' 作为起点
File.copy(
    SCDoc.helpTargetDir +/+ "themes" +/+ "default.css",
    SCDoc.helpTargetDir +/+ "custom.css"
)

// 打开包含所有主题的目录
(SCDoc.helpTargetDir +/+ "themes").openOS;

themes 目录还包含一个 README.md，其中更详细地介绍了主题如何被应用并存储到客户端，以及如何开发主题。

Themes

分布在 HelpTargetDir/themes 中的 CSS 主题仅用于匹配 ScIDE 的 UI 主题。目前没有动态修改 CSS 主题或添加自定义主题的实现，因此对于任何自定义，建议按上述说明编写一个 custom.css 文件
