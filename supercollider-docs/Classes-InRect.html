InRect

测试一个点是否位于给定矩形内。

UGen : AbstractFunction : Object

另请参阅：InRange、Schmidt

说明

一对信号 x 和 y 被视为 2-D 中的一个点 (x, y)；如果它们落在矩形边界内，则该 UGen 输出 1；否则输出 0。

类方法

InRect.ar(x, y, rect)

InRect.kr(x: 0.0, y: 0.0, rect)

参数：

x

X 分量信号。如果 InRect 以音频速率运行，x 也必须是音频速率。

y

Y 分量信号。如果 InRect 以音频速率运行，y 也必须是音频速率。

rect

一个定义要监控的矩形区域的 Rect；请注意，Rect 使用屏幕坐标，因此顶部小于底部。该 Rect 创建一次后无法调制。

实例方法

示例

// 当两个正弦振荡器都处于区域 x = 0.0 到 0.5、y = 0.5 到 1.0 时，我们将听到锯齿波
(
{
    InRect.ar(
        SinOsc.ar(1), SinOsc.ar(1.3), Rect(0, 0.5, 0.5, 0.5)
    ) * LFSaw.ar(44, 0, 0.1)
}.play
)

// 立体声效果
(
{
    InRect.ar(
        LFNoise0.ar([140, 141]), LFNoise0.ar(143), Rect(0, 0, 0.5, 1)
    ).lag(0.1) * LFSaw.ar(SinOsc.ar(10, 0, 5, 400), 0, 0.1)
}.play
)

// 对于 Rect，按 left、'top'、width、height 来创建；
r = Rect(0, 0, 1, 1)

r.left
r.top
r.right
r.bottom
