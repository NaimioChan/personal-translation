減算合成とフィルターの使用

減算合成の基本的な考え方はコーヒーをいれることに似ています。つまり、最終的に必要ない成分をフィルターを通じて取り除くということです。

通过向 Filter 类发送 .dumpClassSubtree 消息，可以获得 SuperCollider 3 中几乎全部滤波器的列表。

Filter.dumpClassSubtree;

  • Filter - 滤波器 UGen 的基类

    • BEQSuite - B 均衡套件的基类

      • BAllPass - 全通滤波器
      • BBandPass - 带通滤波器
      • BBandStop - 带阻滤波器
      • BHiPass - 12db/oct 滚降 - 二阶谐振高通滤波器
      • BHiShelf - 高架滤波器
      • BLowPass - 12db/oct 滚降 - 二阶谐振低通滤波器
      • BLowShelf - 低架
      • BPeakEQ - 参数均衡器

    • BPF - 二阶巴特沃斯带通滤波器。

      • BRF - 二阶巴特沃斯带阻滤波器。
    • Changed - 当值发生变化时触发
    • Decay - 指数衰减
    • Decay2 - 指数衰减
    • Delay1 - 单采样延迟。
    • Delay2 - 两个采样延迟。
    • DetectSilence - 检测输入何时低于振幅阈值
    • FOS - 一阶滤波器节。
    • Formlet - 类 FOF 滤波器。
    • FreeVerb - 混响
    • Integrator - 一个泄漏积分器。

    • LPF - 二阶巴特沃斯低通滤波器

      • HPF - 二阶巴特沃斯高通滤波器。

    • LPZ1 - 两点平均滤波器

      • HPZ1 - 两点差分滤波器

    • LPZ2 - 两个零点固定低通

      • BPZ2 - 双零点固定中通。

      • HPZ2 - 双零点固定中频切除。

    • Lag - 指数滞后

      • Lag2 - 指数滞后
      • Lag3 - 指数滞后

      • Lag2UD - 指数滞后
      • Lag3UD - 指数滞后

使用 LPF（低通滤波器）从输入源中减去高频成分。

(
SynthDef("subtractive", {
    Out.ar(
        0,
        LPF.ar(
            Pulse.ar(440, 0.5, 0.1),    // フィルターをかけるソース
            Line.kr(8000, 660, 6)        // フィルターの周波数をLineでコントロールする
        )
    )
}).add;
)

Synth("subtractive")

////////////////////////////////////////////////////////////////////////////////////////////////////

RLFP（谐振低通滤波器）常用于去除高频成分并强调滤波器的（截止点）频率。

(
SynthDef("passLowFreqs2", {
    Out.ar(
        0,
        RLPF.ar(
            Saw.ar([220, 221] + LFNoise0.kr(1, 100, 200), 0.2),
            [LFNoise0.kr(4, 600, 2400), LFNoise0.kr(3, 600, 2400)],
            0.1
        )
    )
}).add;
)

Synth("passLowFreqs2")

////////////////////////////////////////////////////////////////////////////////////////////////////

Rezonz 是非常、非常、非常强大的滤波器。用于强调特定的频段。

カットオフが非常にシャープなためにノイズをピッチに変えてしまいます。

(
SynthDef("noiseToPitch", { arg out = 0, mul = 1;
    Out.ar(
        out,
        Resonz.ar(
            WhiteNoise.ar(mul),
            LFNoise0.kr(4, 110, 660),
            [0.005, 0.005]
        )
    )
}).add;
)

(
// 左右のチャンネルをアクティブ化する
Synth("noiseToPitch", [\out, 0\mul, 1]);
Synth("noiseToPitch", [\out, 1, \mul, 1]);
)
