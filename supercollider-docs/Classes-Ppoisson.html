Ppoisson

遵循泊松分布的随机值（正整数值）

Pattern : AbstractFunction : Object

参见：Pgauss

类方法

Ppoisson.new(mean: 1, length: inf)

参数：

mean

分布的均值。

length

产生的值的数量。

(
var a, c, w;
a = Ppoisson(1.0, inf);
c = a.asStream.nextN(500);
w = Window.new("Ppoisson", Rect(10, 10, 540, 800));
// 绘制数值
c.plot(bounds: Rect(10, 10, 520, 380), discrete: true, parent: w);
// 值的直方图

)
