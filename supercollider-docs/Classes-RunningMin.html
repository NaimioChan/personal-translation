RunningMin

跟踪最小电平。

Peak : UGen : AbstractFunction : Object

参见：RunningMax、RunningSum

说明

输出在输入处接收到的最小值。当复位输入处发生触发时，最小输出值会被复位为当前值。

类方法

RunningMin.ar(in: 0.0, trig: 0.0)

来自父类：Peak

RunningMin.kr(in: 0.0, trig: 0.0)

来自父类：Peak

参数：

in

输入信号。

trig

将输出值重置为当前输入值。当信号从非正变为正时触发。

实例方法

示例

(
{
    SinOsc.ar(
            RunningMin.ar(Dust.ar(20), Impulse.ar(0.4)) * 500 + 200,
            0, 0.2
    )

}.play;
)

// 跟随一个正弦 lfo，重置速率由鼠标 x 控制
(
{
    SinOsc.ar(
            RunningMin.kr(SinOsc.kr(0.2), Impulse.kr(MouseX.kr(0.01, 2, 1))) * 500 + 200,
            0, 0.2
    )

}.play;
)
