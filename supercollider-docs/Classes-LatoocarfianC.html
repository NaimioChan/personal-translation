LatoocarfianC

Latoocarfian 混沌生成器

LatoocarfianN : ChaosGen : UGen : AbstractFunction : Object

另请参阅：LatoocarfianN、LatoocarfianL

说明

一个基于 Clifford Pickover 的著作 Chaos In Wonderland 第 26 页所给函数的立方插值声音生成器。该函数为：

    x(n+1) = sin(b * y(n)) + c * sin(b * x(n))
    y(n+1) = sin(a * x(n)) + d * sin(a * y(n))

根据 Pickover 的说法，参数 a 和 b 应处于 -3 到 +3 的范围内，参数 c 和 d 应处于 0.5 到 1.5 的范围内。视给定的参数而定，该函数可以产生连续的混沌输出、收敛到单一数值（静音）或在循环中振荡（音调）。

sclang 代码转换：

注意： 该 UGen 是实验性的，当前未优化，因此相当耗费 CPU。

示例

{ LatoocarfianC.ar(MouseX.kr(20, SampleRate.ir)) * 0.2 }.play(s);

    SampleRate.ir/4,
    LFNoise2.kr(2, 1.5, 1.5),
    LFNoise2.kr(2, 1.5, 1.5),
