FreeVerb2

双通道混响

MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：FreeVerb、GVerb

说明

基于 faust 实验编写。

类方法

FreeVerb2.ar(in, in2, mix: 0.33, room: 0.5, damp: 0.5, mul: 1.0, add: 0.0)

参数：

in

输入信号通道 1。

in2

输入信号通道 2。

mix

干/湿平衡。范围 0..1。

room

房间大小。范围 0..1。

damp

混响高频阻尼。范围 0..1。

mul

add

讨论：

有效参数范围为 0 到 1。超出此范围的值会被 UGen 裁剪。

实例方法

示例

s.boot;

// FreeVerb2 - 演示合成器定义
(
SynthDef(\FreeVerb2x2, { |out, mix = 0.25, room = 0.15, damp = 0.5, amp = 1.0|
    var signal;

    signal = In.ar(out, 2);

    ReplaceOut.ar(out,
        FreeVerb2.ar( // FreeVerb2 - 真立体声 UGen
            signal[0], // 左声道
            signal[1], // 右声道
            mix, room, damp, amp
        )
    ); // 参数与 FreeVerb 1 声道版本相同

}).add;
)

// 双声道源
(
a = SynthDef(\src2x2, { |out|
    Out.ar(out,
        Decay.ar(Impulse.ar(1), 0.25, LFCub.ar(1200, 0, 0.1)) ! 2
        +
        Pan2.ar(
            Decay.ar(Impulse.ar(1, pi), 0.1, WhiteNoise.ar(0.1)),
            LFNoise1.kr(0.5).range(-1, 1)
        )
    )
}).play
)

// 踩下底鼓
z = Synth(\FreeVerb2x2, [\outbus, 0], addAction: \addToTail)
// 试用一些设置
z.set(\room, 0.7)
z.set(\mix, 0.33)
z.set(\damp, 0.9)

// 静音
[a, z].do(_.free)
