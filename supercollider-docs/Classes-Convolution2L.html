Convolution2L

带线性插值的实时卷积器

UGen : AbstractFunction : Object

另请参见：Convolution、Convolution2、Convolution3、StereoConvolution2L

说明

使用固定核的严格卷积，可通过触发信号更新核。缓冲区更改时会在其间进行线性交叉淡化。

参见 Steven W Smith, The Scientist and Engineer's Guide to Digital Signal Processing: chapter 18 - http://www.dspguide.com/ch18.htm

类方法

Convolution2L.ar(in, kernel, trigger: 0, framesize: 2048, crossfade: 1, mul: 1.0, add: 0.0)

参数：

in

处理目标

kernel

固定 kernel 的缓冲区索引，可与触发组合进行调制

trigger

在从 <=0 变为 >0 时更新内核

framesize

FFT 帧的大小，必须是 2 的幂（512、1024、2048、4096 是常用选择）。卷积在内部使用该数值的两倍。请注意，随着幂次提高，卷积的运行开销会逐渐增大！可用的最大值为 2^16 = 16384。（此上限是 SC 源代码中定义的 "SC_FFT_MAXSIZE" 的一半。）比这更大的卷积可以使用 PartConv 完成。

crossfade

进行交叉淡化的周期数。默认值为 1。必须为整数。

mul

add

实例方法

示例

// 分配三个缓冲区
(
b = Buffer.alloc(s, 2048);
c = Buffer.alloc(s, 2048);
d = Buffer.alloc(s, 2048);

b.zero;
c.zero;
d.zero;
)

(
50.do { |it| c.set(20 * it + 10, 1.0.rand) };
3.do { |it| b.set(400 * it + 100, 1) };
20.do { |it| d.set(40 * it + 20, 1) };
)
(
SynthDef(\conv_test, { |out, kernel, t_trig = 0|
    var input = Impulse.ar(1);
    var framesize = 2048; // 必须是 2 的幂
    var result = Convolution2L.ar(input, kernel, t_trig, framesize, 1, 0.5);
    Out.ar(out, result);
}).add
)

x = Synth(\conv_test, [\kernel, b]);

// 更改缓冲区编号：
x.set(\kernel, c);
x.set(\t_trig, 1); // 在此触发之后，更改将生效。
x.set(\kernel, d);
x.set(\t_trig, 1); // 在此触发之后，更改将生效。

d.zero;
40.do { |it| d.set(20 * it + 10, 1) }; // 改变缓冲区的内容
x.set(\t_trig, 1); // 在此触发之后，更改将生效。

x.set(\kernel, b);
x.set(\t_trig, 1); // 在此触发之后，更改将生效。

x.free;
// 更长的交叉淡化
(
SynthDef(\conv_test2, { |out, kernel, t_trig = 0|
    var input = Impulse.ar(1);
    var framesize = 2048; // 必须是 2 的幂
    var result = Convolution2L.ar(input, kernel, t_trig, 2048, 5, 0.5);
    Out.ar(out, result);
}).add
)

x = Synth(\conv_test2, [\kernel, b]);

// 更改缓冲区编号：
x.set(\kernel, c);
x.set(\t_trig, 1); // 在此触发之后，更改将生效。
x.set(\kernel, d);
x.set(\t_trig, 1); // 在此触发之后，更改将生效。

d.zero;

40.do { |it| d.set(20 * it + 10, 1) }; // 改变缓冲区的内容

x.set(\t_trig, 1); // 在此触发之后，更改将生效。

x.set(\kernel, b);
x.set(\t_trig, 1); // 在此触发之后，更改将生效。

x.free;
// 下一个示例

b = Buffer.read(s, ExampleFiles.child);

(
{
    var input = SoundIn.ar(0);
    var framesize = 2048; // 必须是 2 的幂
    Convolution2L.ar(input, b, 0, 512, 1, 0.5);
}.play
)
// 另一个示例

(
// 帧大小必须是 2 的幂——Convolution2 会将 FFT 大小调整为该值的两倍
// 目前最大为 a = 8192，对应 FFT 大小 16384
a = 2048;
// 内核缓冲区
g = Buffer.alloc(s, a, 1);
)

(
g.set(0, 1.0);
100.do { |i| g.set(a.rand, (i + 1).reciprocal) };
)

(
// 随机脉冲响应
{
    var input, inputAmp, threshhold, gate;

    input = SoundIn.ar(0);
    inputAmp = Amplitude.kr(input);
    threshhold = 0.02;    // 噪声门限阈值
    gate = Lag.kr(inputAmp > threshhold, 0.01);

    Convolution2L.ar(input * gate, g, 0, a, 1, 0.5);
}.play
)

g.free;
// 最后一个例子
(
b = Buffer.alloc(s, 512, 1);
b.sine1(1.0/[1, 2, 3, 4, 5, 6], true, true, true);
)

(
{
    var input = SoundIn.ar(0);
    var framesize = 512;
    Convolution2L.ar(input, b, 0, framesize, 1, 0.5);
}.play
)

b.free;
