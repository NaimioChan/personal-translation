Score

定时 OSC 命令的乐谱

Object

参见：非实时合成 (NRT)

说明

Score 封装了一个带定时 OSC 命令的列表，并提供了使用它的一些方法，还支持为非实时合成创建二进制 OSC 文件。更多细节请参阅 Non-Realtime Synthesis (NRT)。

该列表应采用以下格式，时间按升序排列。允许使用 Bundle。

[
[beat1, [OSCcmd1]],
[beat2, [OSCcmd2], [OSCcmd3]],
...
[beat_n, [OSCcmdn]],
[beatToEndNRT, [\c_set, 0, 0]] // finish
]

对于 NRT 合成，最后一个事件应为哑事件，此后合成将停止。因此，重要的是该事件的时间安排要能让先前的事件完成。

Score 调度默认使用 TempoClock。若需要，可设置 TempoClock.default.tempo = 1（每分钟 60 拍），以便用秒来表示乐谱事件。

类方法

Score.new(list)

返回一个带有所提供列表的新 Score 对象。

参数：

list

可以是 Array、List 或类似对象。

Score.newFromFile(path)

与 *new 相同，但从文本文件中读取列表。

参数：

path

一个 String，指示文件的路径。该文件必须包含有效的 SC 表达式。

Score.play(list, server)

与 *new 相同，但会立即播放它。（另见下面的实例方法。）

参数：

list

该列表。

server

如果未提供值，它将在默认 Server 上播放。

Score.playFromFile(path, server)

与 *play 相同，但从文件读取列表。

Score.write(list, oscFilePath, clock)

一个便捷方法，用于创建供 NRT 合成使用的二进制 OSC 文件。不会创建实例。

参数：

list

该列表。

oscFilePath

一个包含所需 OSC 文件路径的 String。

clock

使用 clock 作为速度基准。若 clock 为 nil，则使用 TempoClock.default。

Score.writeFromFile(path, oscFilePath, clock)

与 *write 相同，但从文件读取列表。

参数：

path

指向包含列表的文件的路径。

oscFilePath

一个包含所需 OSC 文件路径的 String。

clock

使用 clock 作为速度基准。若 clock 为 nil，则使用 TempoClock.default。

Score.recordNRT(list, oscFilePath, outputFilePath, inputFilePath, sampleRate: 44100, headerFormat: "AIFF", sampleFormat: "int16", options, completionString: "", duration, action)

一个在非实时环境中合成 list 的便捷方法。该方法将 OSC 文件写入 oscFilePath（如有需要，你必须自行清理），然后启动一个服务器应用来合成它。关于有效的 headerFormats 和 sampleFormats 的详细信息，请参见 SoundFile。使用 TempoClock.default 作为速度基准。不返回实例。

参数：

list

该列表。

oscFilePath

二进制 OSC 文件将被写入的路径。

outputFilePath

生成的音频文件的路径。

inputFilePath

输入声音文件的可选路径。

sampleRate

合成将发生的采样率。

headerFormat

输出文件的头格式。默认为 'AIFF'。

sampleFormat

输出文件的采样格式。默认值为 'int16'。

options

ServerOptions 的一个实例。如果未提供，将使用默认 Server 的选项。

completionString

duration

action

一个在 NRT 服务器完成其乐谱渲染后求值的函数。

实例方法

.play(server, clock, quant: 0.0)

在 server 上播放该列表，使用 clock 作为速度基准，并将开始时间量化到 quant。若 server 为 nil，则在默认服务器上播放。若 clock 为 nil，则为 TempoClock.default。若 quant 为 0，则为 now。

.stop

停止播放。

.write(oscFilePath, clock)

从该列表创建一个用于 NRT 合成的二进制 OSC 文件。使用 clock 作为速度基准。若 clock 为 nil，则为 TempoClock.default。

.score

.score = value

获取或设置列表。

.add(bundle)

将 bundle 添加到列表中。

.addSystemSynthDefs

有些代码需要若干假定已存在于服务器上的 SynthDef（SystemSynthDefs）。以实时模式启动服务器时，它们会被自动发送。在非实时模式下，则需要将它们显式添加到乐谱中：

x = Score.new;
x.addSystemSynthDefs;
x.score

.sort

按乐谱时间顺序排序。当你不确定数据包顺序时，建议在 recordNRT 或 write 之前执行此操作。

.recordNRT(oscFilePath, outputFilePath, inputFilePath, sampleRate: 44100, headerFormat: "AIFF", sampleFormat: "int16", options, completionString: "", duration, action)

以非实时方式合成乐谱。有关参数的详细信息，请参见上面的 *recordNRT。

.saveToFile(path)

将乐谱列表保存为文本文件到 path。

示例

NRT 示例

// 一个示例 synthDef
// 这里我们使用 store 而非 add，以将编译后的 synthdef 存储到 Platform.defaultTempDir +/+ "synthdefs/"
// 并使其可供 NRT 服务器使用
(
SynthDef("helpscore", { |out, freq = 440|
    Out.ar(out,
        SinOsc.ar(freq, 0, 0.2) * Line.kr(1, 0, 0.5, doneAction: Done.freeSelf)
    )
}).store;
)

// 写入一个样本文件用于测试
(
var f, g;
TempoClock.default.tempo = 1;
g = [
    [0.1, [\s_new, \helpscore, 1000, 0, 0, \freq, 440]],
    [0.2, [\s_new, \helpscore, 1001, 0, 0, \freq, 660]],
    [0.3, [\s_new, \helpscore, 1002, 0, 0, \freq, 220]],
    [1, [\c_set, 0, 0]] // finish
    ];
f = File(Platform.defaultTempDir +/+ "score-test", "w");
f.write(g.asCompileString);
f.close;
)

// 将其转换为用于 NRT 的二进制 OSC 文件
Score.writeFromFile(Platform.defaultTempDir +/+ "score-test", Platform.defaultTempDir +/+ "test.osc");

从命令行可以在构建目录中渲染该文件：

scsynth -N test.osc _ test.aif 44100 AIFF int16 -o 1

Score 还提供了更直接地完成所有这些操作的方法：

(
var f, o;
g = [
    [0.1, [\s_new, \helpscore, 1000, 0, 0, \freq, 440]],
    [0.2, [\s_new, \helpscore, 1001, 0, 0, \freq, 660],
        [\s_new, \helpscore, 1002, 0, 0, \freq, 880]],
    [0.3, [\s_new, \helpscore, 1003, 0, 0, \freq, 220]],
    [1, [\c_set, 0, 0]] // finish
    ];
o = ServerOptions.new.numOutputBusChannels = 1; // mono output
Score.recordNRT(g, Platform.defaultTempDir +/+ "help-oscFile", Platform.defaultTempDir +/+ "helpNRT.aiff", options: o); // 合成
)

从模式创建 Score

(
SynthDef("helpscore", { |out, freq = 440|
    Out.ar(out,
        SinOsc.ar(freq, 0, 0.2) * Line.kr(1, 0, 0.5, doneAction: Done.freeSelf)
    )
}).store;
)

// new pattern
(
p = Pbind(
    \instrument, \helpscore,
    \dur, Prand([0.3, 0.5], inf),
    \freq, Prand([200, 300, 500], inf)
);
)

// 从该 pattern 生成一个乐谱，长度为 4 拍
z = p.asScore(4.0);
z.score.postcs;
z.play;

// 直接将模式渲染到声音文件：
// 将模式渲染为 wav（4 拍）
p.render(Platform.defaultTempDir +/+ "asScore-Help.wav", 4.0);
