NdefGui

NodeProxy 或 Ndef 的 GUI

另请参阅：JITGui、MonitorGui、NdefParamGui、NdefMixer、ProxyMixer

说明

NdefGui 为处理和编辑 NodeProxy 或 Ndef 及其监视器提供控件。NdefGui 取代了 NodeProxyEditor。它提供：

  • 用于数值设置的滑块
  • kr 代理到参数的映射
  • 用于播放 / 监听的可选控件

NodeProxy 和 Ndef 都实现了 .gui 消息，该消息会返回该 NodeProxy 对应的 NdefGui。概述：JITLib。

(
s.boot;
Ndef(\a, { |freq = 300, dens = 20, amp = 0.1, pan|
    Pan2.ar(Ringz.ar(Dust.ar(dens, amp / (dens.max(1).sqrt)), freq, 0.2), pan)
}).gui;
)

注意，当为参数非常多的 Ndef 创建 NdefGui 时，它创建的滑块可能多于窗口或屏幕所能容纳的数量。这种情况下，最好为 numItems 设置一个合理的最大值：

// 一个带有 100 个控制参数的 Ndef
Ndef(\1, {
    SinOsc.ar(freq: 100.collect{|i|
        "freq%".format(i).asSymbol.kr(100, spec: Spec.specs[\freq])
    })
});

// 这会创建 100 个 paramViews，通常无法放入 GUI 窗口：
g = Ndef(\1).gui;
g.paramGui.paramViews.size;
// 用合理的 max 参数视图数量创建 NdefGui 是可行的，
// 并且可以让你滚动：
g = Ndef(\1).gui(30);

类方法

Creation

.new

参数：

object

要显示和编辑的 nodeproxy，或 nil。

numItems

要提供的参数滑块或文本视图的数量。默认值为 0。

parent

要显示 NdefGui 的父视图。如果为 nil，则创建一个窗口。

bounds

视图（或窗口）将显示的范围。

makeSkip

一个标志，表示是否创建并启动一个 SkipJack 用于自动更新。

options

一个符号数组，用于指定要显示内容的选项。见下方列表。

可在 *new 中使用的预设选项列表：

.big

用于大型 NdefGui 的两行控件，通常位于其自己的窗口中

.full

用于非常大的 NdefGui 的两行控件

.audio

用于 ar 代理，在 ProxyMixer 左侧使用

.audioSm

对于 ar 代理，用于 ProxyMixer.small 的左侧

.control

用于 kr 代理，在 ProxyMixer 中间部分使用

类变量

.buttonSizes

用于不同 GUI 元素尺寸的字典。

.buttonFuncs

用于制作不同按钮的查找字典。

.makeButFuncs

不是类变量，而是初始化 buttonFuncs 的方法。

示例

    // 一些准备工作——创建一个 ar 和一个 kr 的 nodeproxy。
s.boot;
(
Ndef(\lfo, { |lofreq| SinOsc.kr(lofreq) });
Ndef(\a, { |freq = 300, dens = 20, amp = 0.1, pan|
    Pan2.ar(Ringz.ar(Dust.ar(dens, amp / (dens.max(1).sqrt)), freq, 0.2), pan)
});
)

    // 创建一个 NdefGui。默认情况下，它启用了大量选项。
n = NdefGui.new;
n.object_(Ndef(\lfo));
Ndef(\lfo).set(\lofreq, 12);

n.object_(Ndef(\a));
Ndef(\a).set(\freq, 120);

一些配置选项

// numItems - 用于设置参数的滑块
n = NdefGui(Ndef(\a), 8);

// 提供了 4 组配置：
n = NdefGui(Ndef(\a), 0, options: NdefGui.control);
n = NdefGui(Ndef(\a), 0, options: NdefGui.audio);
n = NdefGui(Ndef(\a), 0, options: NdefGui.big);
n = NdefGui(Ndef(\a), 0, options: NdefGui.full);


NdefGui.control;    // 用于 ProxyMixer/NdefMixer 中的控制代理
// -> [\name, \pausR, \sendR, \poll, \ed]

NdefGui.audio;        // 用于 ProxyMixer/NdefMixer 中的音频代理
// -> [\monitor, \playN, \name, \pausR, \sendR, \ed]

NdefGui.big;        // 用于 ProxyMixer/NdefMixer 中的大型 NdefGui
// -> [\name, \type, \CLR, \reset, \scope, \doc, \end, \fade, \monitor, \playN, \pausR, \sendR, \poll]

// 全部
NdefGui.full;
// -> [\name, \type, \CLR, \reset, \scope, \doc, \end, \fade, \rip, \monitor, \playN, \pausR, \sendR, \poll, \ed]
/*
    // 可选元素为：
    \name        用于 proxy 名称的 dragboth
    \type        用于 proxy 类型的视图（ir、ar + numChans、kr + numChans）
    \CLR         清除 proxy 的按钮
    \reset        重置 proxy nodemap 的按钮
    \scope        对 proxy 进行示波显示的按钮
    \doc            将 proxy 记录为代码的按钮
    \end            结束 proxy 的按钮
    \fade        用于设置 proxy 淡入淡出时间的 EZNumber

    \monitor        用于音频 proxy 的 MonitorGui
    \playN        用于编辑 playN 设置的按钮（位于 MonitorGui 内）

    \rip        (^)    在 proxy 上打开新编辑器的按钮（用于 ProxyMixer/NdefMixer）

    \pausR        切换 proxy 暂停/恢复的按钮
    \sendR        重新发送的按钮；alt-点击 会要求 proxy 重新构建
    \poll        轮询 proxy

    * 预置存储位于 JITLibExtensions 中，参见 ProxyPreset / NdefPreset

*/

//     添加你自己的函数以添加你自己的元素，例如：
NdefGui.buttonSizes.put(\zoink, 60);
NdefGui.buttonFuncs.put(\zoink, { |ndgui| Button(ndgui.zone, 60@20).states_([["zoink"]]).action_({ ndgui.object.zoink }) });

n = NdefGui(Ndef(\a), 4, options: NdefGui.big ++ [\zoink]);


// 创建一个并观察各元素如何变化
n = NdefGui(Ndef(\a), 4, options: NdefGui.big);

Ndef(\a).stop;
Ndef(\a).play;
Ndef(\a).vol_(0.3);
Ndef(\a).stop;

Ndef(\a).playN([2, 5]);   // 在 outNumberBox 上无法完整显示
Ndef(\a).playN([2, 5], vol: 0.34);


// 与 ProxyMixer 中一样，左侧
n = NdefGui(Ndef(\a), options: NdefGui.audio);

// 如同 ProxyMixer 控制区中那样
n = NdefGui(Ndef(\a), 4, options: NdefGui.control);

// NdefGui 默认值
n = NdefGui(options: NdefGui.big);

// 以及一些更多
n = NdefGui(bounds: 400@20, options: NdefGui.full);

// 放入窗口中——则不会添加边距
(
w = Window().front;
w.addFlowLayout;
n = NdefGui(Ndef(\a), 4, w, options: NdefGui.big);
)

Ndef(\a).set(\freq, 220)
