ListView

一个显示文本项列表的视图。

说明

一个显示文本项列表的视图，允许根据 -selectionMode 选择其中一项或多项。

在默认选择模式（单项选择）下，单击某一项会选中它，按向上或向下箭头键会分别将选择移动到上一项或下一项。其他选择模式允许更复杂的交互。

当前项与已选中项的概念有所不同。在默认选择模式下，它们始终相同，但在其他模式下则不然。

类方法

实例方法

Data

.items

视图所显示的项列表。

参数：

一个由 Strings 组成的 Array，每个 String 定义表示某项的文本。

.clear

移除所有项。

.value

当前项的索引，当没有当前项时为 nil。注意，当 -selection 允许选择多个项时，这可能与 -selectionMode 不同。

参数：

一个整数或 nil。

.valueAction

设置 -value 并触发 -action。

.selection

所有选中索引的数组。设置选择时，可以使用数组或单个整数。

注意：当 -selectionMode 允许选择多个项目时，这可能与 -value 不同。在单项选择模式下设置选择时，只有最后一个索引会保持被选中状态。

Appearance

.colors

各项的背景颜色。

参数：

一个 Color 数组，每个条目对应一个 Color。

.stringColor

用于显示所有未选中项全部文本的颜色。

参数：

一个 Color。

.selectedStringColor

用于显示选中项文本的颜色。

参数：

一个 Color。

.hiliteColor

用于指示选中项的颜色（除其文本颜色之外）。

参数：

一个 Color。

Interaction

.selectionMode

允许的项目选择模式，根据下表：

Value

Meaning

\none

无法选择任何项。

\single

一次只能选择单个项。

\multi

可以选中多个项目。单击某项目时会切换其选中状态。

\extended

可以选择多个项，按住 Ctrl 键可单独选择，按住 Shift 键可批量选择。

\contiguous

按住 Shift 键可以选中多个相邻项目。

参数：

上表中所列 Symbols 之一。

Actions

.action

每当用户更改当前项时求值的动作对象，即当 -value 因 GUI 交互而改变时。

.selectionAction

每当 -selection 变化时被求值的动作对象。

.enterKeyAction

每当用户按下 Enter（Return）键时求值的 action 对象。

.defaultKeyDownAction

实现按键的默认效果如下：

Key

Effect

space

选择下一项并触发动作

r

触发 enterKeyAction

n

触发 enterKeyAction

一个数字

触发 enterKeyAction

上箭头

选择上一项并触发操作

向下箭头

选择下一项并触发动作

向左箭头

选择上一项并触发操作

右箭头

选择下一项并触发动作

拖放

.defaultGetDrag

返回值：

该 -value。

.defaultCanReceiveDrag

返回值：

如果当前拖动数据是数字，则为 true。

.defaultReceiveDrag

将 -valueAction 设置为当前拖拽数据。

示例

基本示例

(
w = Window.new.front;

v = ListView(w, Rect(10, 10, 120, 70))
    .items_(["SinOsc", "Saw", "LFSaw", "WhiteNoise", "PinkNoise", "BrownNoise", "Osc"])
    .background_(Color.clear)
    .hiliteColor_(Color.green(alpha: 0.6))
    .action_({ |sbs|
        [sbs.value, v.items[sbs.value]].postln; // .value 返回整数
   });
)
