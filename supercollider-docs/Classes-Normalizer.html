Normalizer

压平动态。

UGen : AbstractFunction : Object

参见：Amplitude、Compander、CompanderD、Limiter

子类：Limiter

说明

将输入幅度归一化到给定电平。Normalizer 不会像 Compander 那样过冲，但它需要前瞻音频。因此存在等于 dur 参数值两倍的延迟。

类方法

Normalizer.ar(in: 0.0, level: 1.0, dur: 0.01)

参数：

in

要处理的信号。

level

用于归一化输入的峰值输出振幅电平。

dur

也称为 lookAheadTime。缓冲区延迟时间。较短的时间会产生更小的延迟和更快的瞬态响应时间，但可能引入幅度调制伪影。此参数无法被调制。

实例方法

示例

(
// 要处理的示例信号
Synth.play({
    var z;
    z = Decay2.ar(
        Impulse.ar(8, LFSaw.kr(0.25, -0.6, 0.7)),
        0.001, 0.3, FSinOsc.ar(500));
}, 0.8)
)

(
Synth.play({
    var z;
    z = Decay2.ar(
        Impulse.ar(8, LFSaw.kr(0.25, -0.6, 0.7)),
        0.001, 0.3, FSinOsc.ar(500));
    [z, Normalizer.ar(z, 0.4, 0.01)]
}, 0.5)
)
