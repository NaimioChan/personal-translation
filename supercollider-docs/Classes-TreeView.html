TreeView

显示带列的项目树的视图

说明

一种显示项目层次结构的视图。它分为行和列：每行代表一个项目，每列代表项目的不同数据字段。

这些条目在代码中由 TreeViewItem 的实例表示，由各种 TreeView 方法返回。顶层条目通过 TreeView 接口添加，而子条目通过 TreeViewItem 接口添加，该接口还允许在创建条目后对其做更细致的操作。

可以使用 -sort 对项目进行可视化排序，或者在启用 -canSort 时点击某一列标题进行排序。

每个条目都可以在其各个数据字段中容纳其他视图，从而实现丰富的图形交互。请参阅 TreeViewItem: -setView。

类方法

实例方法

Data

.columns

获取或设置列数（数据字段）及其名称。当设置的列数小于当前列数时，多余的列将被移除，从而移除存储在这些列中的所有数据。

参数：

用于列名的字符串数组。

.numColumns

列（数据字段）的总数。

.addItem

追加一个新的顶层项。

参数：

strings

一个字符串数组（或 nil），每个对应一个数据字段的文本。

返回值：

表示新项的 TreeViewItem 实例。

.insertItem

在 index 处插入一个新的顶层项。

参数：

index

插入该项的位置。

strings

一个字符串数组（或 nil），每个对应一个数据字段的文本。

返回值：

表示新项的 TreeViewItem 实例。

.removeItem

移除给定的 item。移除该项后，对相关 TreeViewItems 的任何使用都将无效。

参数：

一个 TreeViewItem 实例。

.numItems

项目的总数。

.clear

移除所有项。

.currentItem

获取或设置当前选中的项。

参数：

一个 TreeViewItem 实例。

返回值：

一个 TreeViewItem 实例，若无当前项则为 nil。

.itemAt

index 处的项。

.childAt

-itemAt 的别名，为兼容 TreeViewItem 而提供。

.addChild

-addItem 的别名，为兼容 TreeViewItem 而提供。

.insertChild

是 -addChild 的别名，为兼容 TreeViewItem 而提供。

Appearance

.sort

按 column 中的数据对项排序。无论 -canSort 如何，这都会生效。

注意： 排序不会影响各项的逻辑顺序，只会影响它们的显示方式。

参数：

column

用于排序的整数列索引。

descending

以降序还是升序排序。默认为升序。

.columnWidth

参数：

column

列的整数索引

返回值：

列的整数宽度（像素）。如果 column 不在 0..(numColumns-1) 范围内，则返回 -1。

.setColumnWidth

设置列的宽度。最右侧的列必须至少延伸到 TreeView 的右边界。

参数：

column

要修改的列的整数索引

width

整数宽度（像素）

Interaction

.canSort

用户是否可以通过点击列标题对项目进行排序。

当设置为 true 时，项目将立即根据当前排序列进行排序。当为 true 时，视图还会自动对新项目进行排序。

默认值为 false。

另见：-sort。

Actions

.itemPressedAction

在项上按下鼠标按钮时要评估的对象，将此视图作为参数传递。

.onItemChanged

每当当前项发生变化时要被求值的对象，会将此视图作为参数传入。

示例

(
var t = TreeView().front;
t.columns_(["a", "b", "c", "d"]);
t.addItem(["A1", "B1", "C1", "D1"]);
t.addItem(["A2", "B2", "C2"]);
t.addItem(["A3", "B3"]);
t.addItem(["A4"]);
)


// 排序示例
(
var names = ["black", "white", "red", "green", "blue", "cyan", "magenta", "yellow"];
var colors = names.collect{ |str| Color.perform(str.asSymbol) };
var window, tree, popup;
window = Window.new("TreeView example - RGBA colors").front;
window.view.layout_(VLayout(
    tree = TreeView()
));
tree.columns_(["Index", "Name", "Int", "Hex"]);
tree.font = Font.defaultMonoFace;
tree.setColumnWidth(0, 60);
tree.setColumnWidth(2, 130);
names.do{ |str, i|
    var intString = "% % % %".format(*(colors[i].asArray*255).asInteger);
    tree.addItem([i, str, intString, colors[i].hexString]);
};
tree.numItems.do{ |i|
    var c = [Color.clear, colors[i], Color.clear, Color.clear];
    tree.itemAt(i).colors_(c).textColors_(Color.grey);
};
tree.onItemChanged_({ |view|
    view.currentItem.strings.postln;
});
tree.canSort = true;
)
