UserView

使用 Pen 自定义绘制的视图

参见：Pen

说明

一个空视图，你可以使用 Pen 类在其上绘制。

该视图自身仅显示而不做任何事，但允许你定义它将如何绘制，并期望你使用鼠标、键盘以及拖放动作来定义其完整的交互模式。

要定义视图的绘制方式，请将 -drawFunc 变量设置为一个 Function，在其中可以使用 Pen 类来绘制图形基元，例如线、矩形、椭圆、曲线以及文本。

该类提供了创建动画的便捷机制，即按固定时间间隔自动重绘自身。参见本文档的 Animation 一节。

有关使用此视图的指南，请参阅 GUI 入门：自定义视图。

注意： 旧教程可能会建议子类化 UserView。不要这样做。使用组合，而非继承。将 UserView 作为自定义视图类的一个属性。

类方法

实例方法

Drawing

.drawFunc

设置当视图被要求重绘自身时要执行的 Function。例如，这可能发生在视图被隐藏后再次显示、被调整大小、另一视图移动到其上方，或调用 View: -refresh 方法之后。

在该 Function 中，你可以使用 Pen 类在视图的边界内绘制。传递给 Pen 方法的所用坐标均相对于视图的左上角。不允许在该 Function 之外使用 Pen。

求值时，会将此视图作为参数传递给该 Function。

参数：

一个函数。

.background

设置用于填充视图整个区域的背景色，该区域位于 -drawFunc 中绘制内容的下方。你可以随时设置背景，甚至在 drawFunc 内部也可以，但该函数中绘制的任何内容将始终显示在背景之上。

参数：

一个 Color。

.drawingEnabled

视图重绘自身时是否调用 -drawFunc。注意，无论此变量如何，-background 都会被绘制。

默认值为 true。

参数：

一个布尔值。

.clearOnRefresh

视图在被重绘之前是否应清除在 -drawFunc 中完成的最后一次绘制。

如果为 false，视图在每次重绘时会持续绘制在所有先前绘制内容之上，直到调用 -clearDrawing。

默认值为 true。

参数：

一个布尔值。

.clearDrawing

如果 -clearOnRefresh 为 false，你可以调用此方法手动清除迄今为止在 -drawFunc 中完成的任何绘制。

Animation

.animate

视图是否应按固定时间间隔（帧率）在内部自行重绘。有关调整该间隔的方式，请参见 -frameRate。

默认值为 false。

参数：

一个布尔值。

.frameRate

当 -animate 为 true 时，视图定期重绘自身的时间间隔。你可以通过设置此变量来更改所需的帧率。

默认帧率为 60fps。

注意： 获取此变量的值将返回平均实际帧率。如果它低于上述设置的期望帧率，则意味着视图尝试以该帧率重绘自身但未能成功。原因通常可能是 -drawFunc 中定义的绘图对系统而言计算量过大。

参数：

fps

一个定义动画帧之间间隔的 Float，单位为帧每秒。

.frame

在 -animate 为 true 时绘制的帧数；每次重绘视图时它都会增加 1。

如果动画停止后再次启动（通过将 animate 设为 false，然后再设为 true），帧计数会重新开始。

返回值：

一个 Integer。

Actions

UserView 本身不响应用户的任何交互。你可以使用鼠标和键盘动作完全自行定义交互模式。详细说明请参见 Actions and Hooks。

请注意，UserView 没有默认的交互模式，因此如果你不自行实现，View: -action 将永远不会被触发。

示例

《GUI 简介》中包含一个带有详细说明如何使用 UserView 的示例。下面还有更多示例。

基本用法

调整窗口大小或在 UserView 上点击以刷新绘制：

(
w = Window.new;
v = UserView(w, w.view.bounds.insetBy(50, 50));
v.resize = 5;
v.background_(Color.rand);
v.drawFunc = { |uview|
        Pen.moveTo(0@uview.bounds.height.rand);
        Pen.lineTo(uview.bounds.width@uview.bounds.height.rand);
        Pen.stroke;
    };
v.mouseDownAction = { v.refresh };
w.front;
)

坐标相对于 UserView。尝试调整窗口大小：

(
var func;

func = { |me|
    Pen.use{
        10.do{
            Color.red(rrand(0.0, 1), rrand(0.0, 0.5)).set;
            Pen.addArc((400.exprand(2))@(100.rand), rrand(10, 100), 2pi.rand, pi);
            Pen.perform([\stroke, \fill].choose);
        }
    }
};

w = Window.new("DrawFunc Examples").front;
w.view.background_(Color.white);

3.do{ |i|
    v = UserView(w, Rect(20+(i*120), 100, 100, 100))
        .drawFunc_(func);
    v.resize = 3; // 即使视图在调整大小时移动，func 坐标仍然有效
    v.background_(Color.rand);
};

w.refresh;
)

响应鼠标点击和移动

使用鼠标动作，你可以让 UserView 根据鼠标交互改变其绘制方式。下面的示例序列将引导你了解各种可能性。

在以下示例中，在每个绘制出的方块上点击并移动鼠标，会以不同方式重绘它们。查看解释器输出中的发布信息，你可以在鼠标操作中使用这些信息。

// 拖动一些圆圈
(
var w, r, u;
var clicked, relativeWhere;
r = { Rect(300.rand, 300.rand, 110, 110) } ! 4;

w = Window.new.front;
u = UserView(w, Rect(0, 0, 400, 400));
u.drawFunc = {
    r.do { |x, i|
        Pen.addOval(x); // wie addRect
        Pen.color = Color.hsv(0.9 * (1/(i+1)), 0.6, 1);
        Pen.draw;
    };
};
u.mouseDownAction = { |v, x, y|
    r.do { |rect, i|
        if(rect.contains(Point(x, y))) {
            clicked = i;
            relativeWhere = Point(x, y) - rect.origin;
        };
    };
};

u.mouseMoveAction = { |v, x, y|
    var rect;
    if(clicked.notNil) {
        rect = r.at(clicked);
        r.put(clicked, rect.origin = Point(x, y) - relativeWhere);
        w.refresh;
    }
};

u.mouseUpAction = {
    clicked = nil;
}
)
// 绘制一些随机形状
(
var drawFunc, mouseDownFunc, mouseUpFunc, mouseMoveFunc, sat = 0, startX;

drawFunc = { |me|
    Pen.use{
        10.do{
            Color.red(rrand(0.0, 1), rrand(0.3, 0.8)).set;
            Pen.addArc((400.exprand(2))@(100.rand), rrand(10, 50), 2pi.rand, pi);
            Pen.perform([\stroke, \fill].choose);
        }
    }
};

mouseDownFunc = { |me, x, y, mod|
    startX = x;
    postf("begin path: x=% realtive mouse coordinates:%\n", startX, x@y);
};

mouseUpFunc = { |me, x, y, mod|
    postf("end path: (startX-x)==% mouse coordinates:%\n", (startX-x), x@y);
};

mouseMoveFunc = { |me, x, y, mod|
    sat = ((startX-x)/100);
    (x@y).postln;
    me.refresh;
};

w = Window.new.front;
w.view.background_(Color.white);
3.do{ |i|
    v = UserView(w, Rect(20+(i*120), 100, 100, 100));
    v.background_(Color.rand);
    v.drawFunc = drawFunc;
    v.mouseDownAction = mouseDownFunc;
    v.mouseUpAction = mouseUpFunc;
    v.mouseMoveAction = mouseMoveFunc;
};
w.refresh;
)

以下示例使用 -clearOnRefresh 选项来防止 UserView 在重绘时清除其内容。在每个方块内点击并移动鼠标，会在彼此之上绘制越来越多的弧线。

(
var func, views;

func = { |me|
    Pen.use{
        1.do{
            Color(
                rrand(0.0, 1),
                rrand(0.0, 0.2),
                rrand(0.0, 0.8),
                rrand(0.4, 0.8)
            ).set;
            Pen.addArc((400.exprand(2))@(100.rand), rrand(10, 50), 2pi.rand, pi);
            Pen.perform([\stroke, \fill].choose);
        }
    }
};

w = Window.new("DrawFunc Examples").front;
w.view.background_(Color.white);
views = { |i|
    v = UserView(w, Rect(20+(i*120), 100, 100, 100));
    v.background = Color.rand;
    v.drawFunc = func;
    v.mouseMoveAction = { |me| me.refresh };
    v.clearOnRefresh_(false);
} ! 3;
w.refresh;
)

下面的示例使用 -clearOnRefresh 选项在重绘时保留旧内容，使你能够通过在视图上单击并拖动来绘制一条跟随鼠标光标的线。

它还使用鼠标位置来计算线条的颜色。

(
var w, txt, lines, points, drawLine;

drawLine = { |points, bounds|
    var p0;
    points.do { |p, i|
        if(i == 0){
            p0 = p;
        }{
            Pen.moveTo(p0);
            Pen.lineTo(p);
            Color(
                (p.x/bounds.width).clip(0, 1),
                1.0-(p.x/bounds.width).clip(0, 1),
                (p.y/bounds.height).clip(0, 1)
            ).set;
            Pen.stroke;
            p0 = p;
        }
    };
};

w = Window("draw on me", Rect(128, 64, 340, 360));

v = UserView(w, w.view.bounds)
    .clearOnRefresh_(false)
    .mouseDownAction_({ |v, x, y|
        points = [x@y];
    })
    .mouseMoveAction_({ |v, x, y|
        points = points.add(x@y);
        v.refresh;
    })
    .mouseUpAction_({ |v, x, y|
        points = points.add(x@y);
        lines = lines.add(points);
        points = nil;
        v.refresh;
    })
    .background_(Color.white)
    .drawFunc_{ |me|
        var r = me.bounds;

        Pen.use {
            Pen.width = 1;
            Color.black.set;

            lines.do { |linePoints|
                drawLine.value(linePoints, r);
            };
            lines = nil;

            drawLine.value(points, r);
            if(points.size > 0) { points = [points.last] };
        };
    };

w.front;
)

Animation

以下是一个带有鼠标交互的动画。在视图中单击并拖动以移动旋转对象的中心。

(
var width = 400, height = 400, mx = 0, my = 0, pt, r;

w = Window("animation and mouse interaction", Rect(100, 200, width, height), false);

u = UserView(w, Rect(0, 0, width, height));
u.background = Color.black;
u.animate = true; // 为此视图添加动画

// 预先分配数据，用于优化：
pt = Point();
r = Rect();

u.drawFunc = {
    Pen.fillColor = Color.green;
    Pen.stringAtPoint(u.frameRate.asString, Point(10, 10)); // 显示帧率
    Pen.stringAtPoint(u.frame.asString, Point(10, 30)); // 显示帧计数器
    Pen.color = Color.white;
    pt.x = mx;
    pt.y = my;
    100.do{ |i|
        Pen.moveTo(pt);
        pt.x = sin(u.frame*0.04.neg+i)*(5*i)+mx; // 使用 .frame 驱动动画
        pt.y = cos(u.frame*0.05+i)*(5*i)+my;
        r.left = pt.x;
        r.top = pt.y;
        r.width = i;
        r.height = i;
        Pen.lineTo(pt);
        Pen.fillStroke;
        Pen.addOval(r);
        Pen.fillStroke;
    };
};
u.mouseDownAction = { |v, x, y|
    mx = x;
    my = y;
};
u.mouseMoveAction = u.mouseDownAction;
w.front;
)

u.animate = false; // 动画可以暂停和恢复
u.animate = true;
w.close; // 停止动画

一个简单的球体动画：

(
var width = 400, height = 400, xspeed = 3, yspeed = 2, x = width*0.5, y = height*0.5;
w = Window("ball", Rect(100, 200, width, height));
u = UserView(w, Rect(0, 0, width, height));
u.background = Color.black;
u.animate = true;
u.drawFunc = {
    if(x<0 or: { x>width }, { xspeed = 0-xspeed });
    if(y<0 or: { y>height }, { yspeed = 0-yspeed });
    x = x+xspeed;
    y = y+yspeed;
    Pen.fillColor = Color.white;
    Pen.fillOval(Rect.aboutPoint(Point(x, y), 8, 8));
};
w.front;
)

( // 在运行时替换上面的 drawFunc
u.drawFunc = {
    Pen.fillColor = Color.red;
    Pen.fillOval(Rect(200, 200, sin(u.frame*0.031)*200, sin(u.frame*0.044)*200));
    Pen.fillOval(Rect(200, 200, sin(u.frame*0.052)*200, sin(u.frame*0.065)*200));
    Pen.fillOval(Rect(200, 200, sin(u.frame*0.073)*200, sin(u.frame*0.086)*200));
}
)

// 关闭窗口以停止
w.close;

一种充分利用 -clearOnRefresh 选项在重绘时保留旧内容的动画。

(
var width = 640, height = 480, w, theta = 0, drawFunc;
w = Window("trails", Rect(128, 64, width, height), false);
drawFunc = { |view|
    var x = 20 * sin(theta), y = 42 * cos(theta);
    theta = theta + 0.01;
    // 绘制一个填满屏幕的半透明矩形：
    Pen.fillColor_(Color.red(0.2, 0.1));
    Pen.fillRect(Rect(0, 0, width, height));
    Pen.strokeColor_(Color.white);
    Pen.translate(width * 0.5, height * 0.5);
    6.do { |i|
        Pen.rotate(theta * (1 - (i / 6)));
        Pen.scale(0.7 + (i * 0.4), 0.4 + (i * 0.5));
        Pen.strokeOval(Rect.aboutPoint(Point(x, y), 60, 40));
    };
};
x = UserView(w, Rect(10, 10, width - 20, height - 20))
    .canFocus_(false)
    .drawFunc_(drawFunc)
    .clearOnRefresh_(false);

w.front;
x.animate = true
)
