LPF

二阶 Butterworth 低通滤波器

Filter : PureUGen : UGen : AbstractFunction : Object

参见：BPF， BRF， HPF

子类：HPF

说明

二阶低通滤波器。

类方法

LPF.ar(in: 0.0, freq: 440.0, mul: 1.0, add: 0.0)

LPF.kr(in: 0.0, freq: 440.0, mul: 1.0, add: 0.0)

参数：

in

输入信号。

freq

截止频率，单位为赫兹。警告：由于其实现方式的特性，接近 0 的频率值可能导致故障和/或极其响亮的音频伪影！

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

{ LPF.ar(Saw.ar(200, 0.1), SinOsc.kr(XLine.kr(0.7, 300, 20), 0, 3600, 4000)) }.play;

// kr:
(
{ var ctl = LPF.kr(LFPulse.kr(8), SinOsc.kr(XLine.kr(1, 30, 5)) + 2);
    SinOsc.ar(ctl * 200 + 400)
}.play;
)

(
{ var ctl = LPF.kr(LFPulse.kr(8), MouseX.kr(2, 50, 1));
    SinOsc.ar(ctl * 200 + 400)
}.play;
)
