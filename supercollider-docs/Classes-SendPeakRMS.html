SendPeakRMS

跟踪信号的峰值和功率，用于 GUI 应用程序。

UGen : AbstractFunction : Object

另请参见：Peak、PeakFollower、OSCFunc

说明

SendPeakRMS 单元生成器计算信号的峰值和功率，并将计算出的值发送回客户端。它不产生任何输出。

类方法

SendPeakRMS.ar(sig, replyRate: 20.0, peakLag: 3, cmdName: '/reply', replyID: -1)

SendPeakRMS.kr(sig, replyRate: 20.0, peakLag: 3, cmdName: '/reply', replyID: -1)

与其他单元生成器不同，ar 和 kr 方法指定的不是计算速率，而是粒度。当 SendPeakRMS UGen 以 kr 实例化时，回复速率会被量化为控制速率块。

参数：

sig

输入信号。

replyRate

浮点数或整数。指定每秒发送给客户端的回复数量。

peakLag

浮点数或整数。应用于峰值值的滞后时间。此选项通常用于 GUI VU 表。

cmdName

Symbol 或 String。回复消息的地址模式。

replyID

整数 ID（类似于 SendTrig）。

实例方法

示例

(
{
    SendPeakRMS.kr(Dust.ar(20), 20, 3, "/replyAddress")
}.play;
)

(
o = OSCFunc({ |msg|
    "peak: %, rms: %".format(msg[3], msg[4]).postln
}, '/replyAddress');
)
o.free;
