SC 中的 J 概念

借用自 J 的概念概述

J 编程语言是 APL 的后继者（参见 http://www.jsoftware.com）。这些语言专为处理数据数组而设计，能够隐式地表达复杂的迭代概念。

以下是一些借用或受 J 启发的概念。思考多维数组既可能令人费解，也可能拓展思维。理解这些示例中发生的事情可能需要付出一些努力。

填充数组

iota 用计数器填充数组

z = Array.iota(2, 3, 3);
z.rank; // 3 维
z.shape; // 给出各维度的大小
z = z.reshape(3, 2, 3); // reshape 改变数组的维度
z.rank; // 3 维
z.shape;

填充多维数组

// 2 维
Array.fill([3,3], { 1.0.rand.round(0.01) });
Array.fill([2,3], {|i,j| i@j });

// 3 维
Array.fill([2, 2, 2], { 1.0.rand.round(0.01) });
Array.fill([2, 3, 4], {|i,j,k| [i, j, k].join });

// 上述内容的简短变体：
{|i,j,k| [i, j, k].join } ! [2, 3, 4];

// 更多维度
Array.fill([2, 2, 4, 2], {|...args| args.join });

创建数组

使用 dup 创建数组

(1..4) dup: 3;
100.rand dup: 10;
{100.rand} dup: 10;
{100.rand} dup: 3 dup: 4;
{{100.rand} dup: 3} dup: 4;
{|i| i.squared} dup: 10;
{|i| i.nthPrime} dup: 10;
{ |i, j, k| i * j } dup: [5, 5]; // 多维 dup

! 是 dup 的缩写

(1..4) ! 3;
100.rand ! 10;
{100.rand} ! 10;
{100.rand} ! 3 ! 4;
{{100.rand} ! 3} ! 4;
{|i| i.squared} ! 10;
{|i| i.nthPrime} ! 10;
{ |i, j| i * j } ! [5, 5];

实现相同功能的其他方法：

// 部分应用
_.squared ! 10;
_.nthPrime ! 10;

// 对列表进行操作
(0..9).squared;
(0..9).nthPrime;

运算符副词

副词是传递给二元运算符的第三个参数，用于修改它们如何遍历 SequenceableCollection 或 Stream。更多信息请参阅 Adverbs for Binary Operators 帮助文件。

[10, 20, 30, 40, 50] + [1, 2, 3]; // normal
[10, 20, 30, 40, 50] +.f [1, 2, 3]; // folded
[10, 20, 30, 40, 50] +.s [1, 2, 3]; // shorter
[10, 20, 30, 40, 50] +.x [1, 2, 3]; // cross
[10, 20, 30, 40, 50] +.t [1, 2, 3]; // table

运算符深度

J 有一个称为动词秩（verb rank）的概念，它可能过于复杂，难以在 SC 中理解和实现，但运算符深度与之类似且更简单。可以为二元运算符指定一个运算深度。负深度表示迭代相反的操作数。通过示例更容易理解这些内容。目前无法将副词与深度组合使用。

z = Array.iota(3,3);
y = [100, 200, 300];
z + y;
z +.0 y; // 与上面相同。y 加到 z 的每一行
z +.1 y; // y 加到 z 的每一列
z +.2 y; // y 加到 z 的每个元素上
z +.-1 y; // z 加到 y 的每个元素上

deepCollect

deepCollect 在数组的不同维度或深度上操作一个函数。

z = Array.iota(3, 2, 3);
f = {|item| item.reverse };
z.deepCollect(0, f);
z.deepCollect(1, f);
z.deepCollect(2, f);

f = {|item| item.dupEach };
z.deepCollect(0, f);
z.deepCollect(1, f);
z.deepCollect(2, f);

多维数组的各个部分

slice 可以获取多维数组的各个部分。nil 会获取某个维度的所有索引。

z = Array.iota(4, 5);
z.slice(nil, (1..3));
z.slice(2, (1..3));
z.slice((2..3), (0..2));
z.slice((1..3), 3);
z.slice(2, 3);

z = Array.iota(3, 3, 3);
z.slice([0,1], [1,2], [0,2]);
z.slice(nil, nil, [0,2]);
z.slice(1);
z.slice(nil, 1);
z.slice(nil, nil, 1);
z.slice(nil, 2, 1);
z.slice(nil, 1, (1..2));
z.slice(1, [0,1]);
z.flop;

排序顺序

生成随机数组：

z = {100.rand}.dup(10);

order 返回一个索引数组，表示该数组排序后的顺序：

o = z.order;
y = z[o]; // 使用顺序作为索引返回排序后的数组

对 order 调用 order 会返回一个索引数组，该数组将排序后的数组还原为原始的乱序顺序：

p = o.order;
x = y[p];

Bubbling

bubbling 将一项包裹在单元素数组中。它以 depth 和 levels 作为参数。

z = Array.iota(4,4);
z.bubble;
z.bubble(1);
z.bubble(2);
z.bubble(0,2);
z.bubble(1,2);
z.bubble(2,2);

类似地，unbubble 在数组仅包含单个元素时将其解包。

5.unbubble;
[5].unbubble;
[[5]].unbubble;
[[5]].unbubble(0,2);
[4,5].unbubble;
[[4],[5]].unbubble;
[[4],[5]].unbubble(1);
z.bubble.unbubble;
z.bubble(1).unbubble(1);
z.bubble(2).unbubble(2);

使用 +++ 运算符进行层叠

+++ 运算符从第二个列表中取出每一项，并将其追加到第一个列表中对应项之后。如果第二个列表较短，则会循环回绕。

z = Array.iota(5,2);
z +++ [77,88,99];
z +++ [[77,88,99]];
z +++ [[[77,88,99]]];
z +++ [ [[77]],[[88]],[[99]] ];
// 等同于：
z +++ [77,88,99].bubble;
z +++ [77,88,99].bubble(0,2);
z +++ [77,88,99].bubble(1,2);

z +++ [11,22,33].pyramidg;
z +++ [11,22,33].pyramidg.bubble;
z +++ [[11,22,33].pyramidg];
z +++ [[[11,22,33].pyramidg]];


(
z = (1..4);
10.do {|i|
    z.pyramid(i+1).postln;
    z.pyramidg(i+1).postln;
    "".postln;
};
)

reshapeLike

reshapeLike 允许你按照与另一个嵌套数组相同的方式重构一个嵌套数组。

a = [[10,20],[30, 40, 50], 60, 70, [80, 90]];
b = [[1, 2, [3, 4], [[5], 6], 7], 8, [[9]]];
a.reshapeLike(b);
b.reshapeLike(a);

如果长度不同，默认行为是环绕：

a = [[10,20],[30, 40, 50]];
b = [[1, 2, [3, 4], [[5], 6], 7], 8, [[9]]];
a.reshapeLike(b);

但你可以指定其他索引运算符：

a.reshapeLike(b, \foldAt);

a.reshapeLike(b, \clipAt);

a.reshapeLike(b, \at);

测量维度和大小

maxSizeAtDepth 允许你检查给定深度维度上的最大数组大小

[[1, 2, 3], [[41, 52], 5, 6], 1, 2, 3].maxSizeAtDepth(2);
[[1, 2, 3], [[41, 52], 5, 6], 1, 2, 3].maxSizeAtDepth(1);
[[1, 2, 3], [[41, 52], 5, 6], 1, 2, 3].maxSizeAtDepth(0);
(0..3).collect([[1, 2, 3], [[41, 52], 5, 6], 1, 2, 3].maxSizeAtDepth(_)) // 每个维度的最大尺寸

反转维度

flopDeep 允许你用任意深度的维度来反转最外层维度。这类似于 flop，后者对二维数组执行相同的操作。

[[1, 2, 3], [[41, 52], 5, 6]].flopDeep(2);
[[1, 2, 3], [[41, 52], 5, 6]].flopDeep(1);
[[1, 2, 3], [[41, 52], 5, 6]].flopDeep(0);
[[1, 2, 3], [[41, 52], 5, 6]].flopDeep; // 无参数时，从最深层级翻转

[[[10, 100, 1000], 2, 3], [[41, 52], 5, 6]].flopDeep(2); // 较短的数组会循环
[].flopDeep(1); // 结果总是高一个维度。
[[]].flopDeep(4);

allTuples

allTuples 将生成子数组的所有组合

[[1, 2, 3], [4, 5], 6].allTuples;
[[1, 2, 3], [4, 5, 6, 7], [8, 9]].allTuples;
