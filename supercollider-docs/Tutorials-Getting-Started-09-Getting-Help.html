类与方法

到目前为止，我们已经学习了足够的面向对象编程理论，知道了有类（它是对象的模板）和实例（它是根据这些模板创建出来的对象）。我们还有类方法和实例方法，它们可以接受参数。类方法执行诸如创建实例之类的操作（以及一些不需要实际实例的便捷函数），而实例方法则控制和操作实例。此外还有实例变量，它是每个实例特有的数据，以及类变量，它是所有实例共有的数据。

回想一下，代码中任何以大写字母开头的内容都是类。大多数类都有帮助文件。如果你通过双击选中一个类，然后按 Cmd - d（即按住 Cmd 键并按 d 键），如果该类的帮助文件存在，它就会打开。（如果不存在，你将得到主帮助窗口。）用下面的示例试一试：

SinOsc

你应该已经得到一个窗口，其中包含该类的简要描述及其作用、一些方法的列表以及对其参数的说明。（请记住 'mul' 和 'add' 通常不作解释。）

其下是该类的一些实际示例。这些示例对于清楚说明该类究竟做什么非常有用，并且可以作为你自己工作的起点。最好将它们剪切并粘贴到新窗口中，然后尝试修改它们。（请记住，SC 不会阻止你保存任何修改过的文件，包括本教程！）这是一种很好的学习方式。

你可能想知道如何访问 Function 和 Array 的帮助文件，因为它们在代码中经常以 {...} 和 [...] 的形式出现。它们也是有名称的类，因此通过输入以下内容，你也可以选中它们并按 Cmd-?。

Function
Array

有些方法也有帮助文件，此外还有若干关于一般主题的帮助文件。其中大部分都列在主帮助窗口中。

语法快捷方式

还记得 Mix(...) 与 Mix.new(...) 的例子吗？SC 有许多这样的简写形式或替代语法。一个常见的例子是函数式记法与接收者记法之间的区别。这意味着记法 someObject.someMethod(anArg) 等价于 someMethod(someObject, anArg)。这里有一个具体例子。下面两者所做的完全相同：

{ SinOsc.ar(440, 0, 0.2) }.play;

play({ SinOsc.ar(440, 0, 0.2) });

你会在 SC 的文档中看到许多其他语法快捷方式的例子。如果你看到不认识的内容，一个很好的查阅之处是Syntax Shortcuts，其中给出了这些快捷方式中大多数的示例。

窥探等。

建议练习

回顾前面教程中的示例，并尝试打开所用各个类的帮助文件。试一试这些示例，如果你愿意，也可以打开这些示例中使用的任何不熟悉的类的帮助文件。习惯使用 Cmd-d，你会经常用到它。:-)
