Warp1

用时间指针扭曲缓冲区

MultiOutUGen : UGen : AbstractFunction : Object

说明

灵感来自 Chad Kirby 的 SuperCollider2 Warp1 类，而该类又受到 Richard Karpen 为 CSound 编写的 sndwarp 的启发。一个粒度时间拉伸器和变调器。

类方法

Warp1.ar(numChannels: 1, bufnum: 0, pointer: 0, freqScale: 1, windowSize: 0.2, envbufnum: -1, overlaps: 8, windowRandRatio: 0.0, interp: 1, mul: 1, add: 0)

参数：

numChannels

bufnum 中使用的声音文件的声道数。必须为非零正整数。此值在编译 SynthDef 时固定，因此不能赋值给 SynthDef 参数。

bufnum

单声道声音文件的缓冲区编号。

pointer

缓冲区中的位置。值应介于 0 和 1 之间，0 表示缓冲区的开头，1 表示结尾。

freqScale

频率偏移量。1.0 为正常，0.5 为降低一个八度，2.0 为升高一个八度。负值表示倒放声音文件。

windowSize

每个颗粒窗口的大小。

envbufnum

包含用于颗粒包络的信号缓冲区编号。-1 使用内置的 Hanning 包络。

overlaps

重叠窗口的数量。

windowRandRatio

窗函数的随机程度。必须介于 0（无随机性）到 1.0（实际上可能过于随机）之间

interp

用于音高偏移颗粒的插值方法。1 = 不插值。2 = 线性。4 = 三次插值（计算量更大）。

mul

add

实例方法

示例

s.boot;

(
b = Buffer.read(s, ExampleFiles.apollo11);
x = { |envbuf = -1|
    var pointer, pitch;
    // pointer - 在 15 秒内从声音文件的开头移动到结尾
    pointer = LFSaw.ar(1/15).range(0, 1);
    // 用 MouseX 控制音高
    pitch = MouseX.kr(0.5, 2);
    Warp1.ar(
        numChannels: 1,
        bufnum: b,
        pointer: pointer,
        freqScale: pitch,
        windowSize: 0.1,
        envbufnum: envbuf,
        overlaps: 8,
        windowRandRatio: 0.1,
        interp: 2
    )
}.play

)


(
// 一个自定义包络——不是非常好，但你能听出它和
// 默认包络之间的区别
var winenv = Env([0, 1, 0], [0.5, 0.5], [8, -8]);
z = Buffer.sendCollection(s, winenv.discretize, 1);
x.set(\envbuf, z);
)

// 默认为 -1
x.set(\envbuf, -1);

// 释放并结束
x.relase; z.free;
(
b.free;
b = Buffer.read(s, ExampleFiles.apollo11);
{
    var pointer = Phasor.ar(0, SampleDur.ir / BufDur.ir(b) * XLine.kr(1, 0.25, 20));
    var sound = Warp1.ar(1, b, pointer, 1, 0.3, -1, 16, Line.kr(0, 1, 40), 4);
    Pan2.ar(sound, pointer * 2 - 1, 0.25)
}.play
)
b.free;
