部分应用

通过部分应用创建 Functions

另请参阅：Functions

部分应用是一种通过仅向方法传递部分参数来创建函数的方式。_ 字符代表缺失的参数，并成为所创建函数的一个参数。它仅适用于单个方法、列表或字典调用，不适用于更复杂的嵌套表达式。

例如：

f = _ + 2;

f 现在是一个单参数函数。

f.value(7); // 返回 9

它等价于写成：

f = {|x| x + 2 };

（除了没有声明名为 'x' 的变量）

g = Point(_, _);

g 是一个接受两个参数的函数。

g.value(3, 4);

以下是在 collect 消息中使用它的一些示例。每个示例下方都写有等价的函数。

(1..8).collect(_.isPrime);
(1..8).collect {|x| x.isPrime };

(1..8).collect(_.hash);
(1..8).collect {|x| x.hash };

(1..8).collect([\a, \b, _]);
(1..8).collect {|x| [\a, \b, x] };

(1..8).collect((a:_));
(1..8).collect {|x| (a:x) };

(1..8).collect(Polar(_, pi));
(1..8).collect {|x| Polar(x, pi) };

(1..8).collect((1.._));
(1..8).collect {|x| (1..x) };
f = (a:_, b:_); // f 是一个双参数函数
g = f.(_, 5);   // g 是 f 的部分应用
g.(7);          // 获取答案

// 等价于以下写法：
f = {|x, y| (a:x, b:y) }
g = {|z| f.(z, 5) };
g.value(7);

一个你不能做的示例：

(1..8).collect( Point(100 * _, 50) ); // 嵌套表达式将无法工作。
// 只有 * 被部分应用，周围的表达式不会。

(1..8).collect {|x| Point(100 * x, 50) }; // 为此需要使用函数。
