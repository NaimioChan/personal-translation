NodeProxy

服务器上的一个引用

BusPlug : AbstractFunction : Object

参见：ProxySpace

子类：Ndef

说明

一般来说，代理是某个事物的占位符。节点代理是在服务器上播放的某个事物的占位符，并写入有限数量的总线（通常是一个 synth，但也可以是生成 synth 的事件流）。NodeProxy 对象可以在播放时被替换和重新组合。它们也可用于构建一个更大的结构，供后续使用和修改。概述：JITLib。

NodeProxy 在 ProxySpace 内部使用，并且是 Ndef 的父类，便于轻松访问和组合大量占位符。

节点代理的图形编辑器：NdefGui。

注意： NodeProxy 在私有总线上播放。如果你想听到输出，请使用 -play 和 -stop。要释放内部播放器并停止监听：-end。完全移除所有内部设置：-clear

第一个示例

s.boot;

a = NodeProxy.new.play; // 播放到硬件输出。
a.fadeTime = 2; // fadeTime 指定交叉淡化
// 设置源
a.source = { SinOsc.ar([350, 351.3], 0, 0.2) };
a.source = { Pulse.ar([350, 351.3] / 4, 0.4) * 0.2 };
a.source = Pbind(\dur, 0.03, \freq, Pbrown(0, 1, 0.1, inf).linexp(0, 1, 200, 350));

b = NodeProxy.new;
a.source = { Ringz.ar(b.ar, [350, 351.3] * 8, 0.2) * 4 };
b.source = { Impulse.ar([5, 7]/2, [0, 0.5]) };

a.clear(3); // 3 秒后清除
b.clear(3);

类方法

Creation

NodeProxy.new(server, rate, numChannels, inputs)

返回 NodeProxy 的新实例。

// 新建节点代理
a = NodeProxy(s, \audio, 4);
a.numChannels;
a.clear; // 移除总线。
a.numChannels; // nil.

参数：

server

用于运行并分配总线的服务器（默认：Server.default）

rate

如果给定，代理将初始化为此速率

numChannels

如果给定，代理将被初始化为该数量的通道

inputs

如果给定，proxy 将使用给定的输入作为后续槽位上的对象进行初始化。

NodeProxy.audio(server, numChannels)

来自父类：BusPlug

在给定服务器上创建一个新的音频速率实例。

NodeProxy.control(server, numChannels)

来自父类：BusPlug

在给定服务器上创建一个新的控制率实例。

NodeProxy.for(bus)

来自父类：BusPlug

使用给定的 Bus 创建一个实例。

访问类变量

NodeProxy.defaultNumAudio

NodeProxy.defaultNumAudio = value

来自父类：BusPlug

以音频速率初始化且未指定具体数量时默认的声道数（默认值：2）。

NodeProxy.defaultNumControl

NodeProxy.defaultNumControl = value

来自父类：BusPlug

在控制率下初始化且未指定具体数量时使用的默认通道数（默认值：1）。

NodeProxy.defaultFadeTime

所有实例默认都有的、连续源替换之间的重叠时间。每个实例都有自己的值，可通过 fadeTime_ 设置。

实例方法

监听输出

.play(out, numChannels, group, multi: false, vol, fadeTime, addAction)

来自父类：BusPlug

从具有若干声道的总线索引播放到另一个具有若干声道的索引，在 Group 内（即目标组或服务器）。

参数：

out

总线索引

numChannels

要输出的通道数。如果 BusPlug 为中性，或重塑为弹性，则将其初始化为该数量。如果该数量超过可用通道数，则进行环绕。如果未指定该数量，且重塑为弹性，则会自动扩展。

group

用于播放监视器 synth 的目标 Group 或 Server。

multi

保留旧的播放链接并添加新的链接

vol

用于监听的总体音量

fadeTime

淡入 / 淡出时间

addAction

在节点树中何处播放监听 synth

.playN(outs, amps, ins, vol, fadeTime, group, addAction)

来自父类：BusPlug

在非连续通道上播放。参见：Monitor 和 playN

参数：

outs

目标声道数组（或单个值）

amps

每个通道的振幅数组（或单个值）

ins

总线内源声道偏移量的数组（或单个值）

vol

总音量（乘以 amps）

fadeTime

用于淡入 / 淡出的 fadeTimes 数组（或单个值）

group

用于播放监视器 synth 的目标 Group 或 Server。

addAction

在节点树中何处播放监听 synth

.stop(fadeTime, reset: false)

来自父类：BusPlug

停止播放公共通道。

参数：

fadeTime

此动作的衰减时间

reset

如果设置为 true，则重置所有监控状态。否则保留之前的播放参数。

.end(fadeTime, reset: false)

释放 synth 并停止播放。

参数：

fadeTime

此操作的交叉淡入淡出时间。

reset

如果设置为 true，则重置所有监控状态。否则保留之前的播放参数。

嵌入与组合代理

.ar(numChannels, offset: 0, clip: 'wrap')

来自父类：BusPlug

.kr(numChannels, offset: 0, clip: 'wrap')

来自父类：BusPlug

返回一个指向我的输出的 numChannels 的链接。如果未初始化，则创建一个匹配的总线。通常，ar 默认为立体声，kr 默认为单声道。这可以在 classvars 中设置：*defaultNumAudio、*defaultNumControl

为保持一致，当未给出 numChannels 时，它始终返回信号数组。要使其成为单个 ugen 输出，请使用 numChannels = 1。另见：InBus。

参数：

numChannels

返回的通道数。如果接收者是中性的或重塑是弹性的，则将其初始化为此数字。如果这多于可用的通道，则使用 clip 行为（见下文）。如果设置为 1，它将返回一个 InBus 的实例，否则返回一个包含一个或多个 InBus 实例的 Array。

offset

读取具有比 numChannels 更多通道的总线时的通道偏移，在相邻通道之间交叉淡化。

clip

如果设为 'wrap'，超出范围的通道将环绕；如果设为 'clip'，则重复最后一个通道。

<--(proxy)

用法：proxyA <-- proxyB。将 proxyA 的源设置为 proxyB，并播放 proxyA。如果 proxyB 正在播放，则将其淡出。这在以下情况下很方便：

b = NodeProxy.new.play;
b.source = { PinkNoise.ar(0.2.dup) };
// 现在我想通过一个新的 proxy 来过滤 b。
a = NodeProxy.new;
a <-- b; a.source = { HPF.ar(b.ar, 7000) };
a.source = { HPF.ar(b.ar, 3000) }; // 更改源
a.clear; b.clear;

<<>(proxy, key: 'in')

链式调用。用法：proxyA <<> proxyB <<> proxyC <<> ...。将 proxyC 的源映射到 proxyB 的 \in 参数，并将 proxyB 映射到 proxyA 的 in 参数。

a = NodeProxy.new.play;
a.source = { RLPF.ar(\in.ar(0!2), [4600, 7000], 0.1) };
b = NodeProxy.new.source_ { Impulse.ar([5, 7] / 2) };
a <<> b;

<>>(proxy, key: 'in')

上述的反向操作。用法：proxyA <>> proxyB <>> proxyC <>> ...。

设置源

NodeProxy 维护若干槽位，这些槽位可以作为源并在同一总线上混合。默认源是槽位 0。所有对象都可以在运行过程中交换，也可以在此之前和之后交换。通常，源会立即激活。如果要“安静地”交换源，将节点代理设为睡眠（awake = false），或使用消息 prime()。

请参阅 Supported sources 部分下的列表

.source

.source = obj

通过 proxy 播放一个新的 synth，并释放/移除任何旧的 synth。

a = NodeProxy(s);
a.play;
a.source = { Pulse.ar(130, Saw.kr(0.3)) * 0.1 }; // 在运行时修改此行

参数：

obj

可以是受支持的输入之一（参见 Supported sources）

注意： 设置重塑后（例如设为 \elastic），设置源会改变代理的通道数。这意味着其总线会改变，从中读取信号的子代理也可能随之改变。参见 Routing 中的示例。

Routing

信号可以在任意数量的节点代理之间路由。

另见：BusPlug: -ar、BusPlug: -value、重塑。

这里有一个简单示例，使用 Ndef（NodeProxy 的工作方式类似）：

Ndef(\maus, { MouseX.kr });
Ndef(\haus, { Pan2.ar(Blip.ar(Ndef.kr(\maus, 1) * 70), SinOsc.kr(Ndef.ar(\maus, 1) * 5)) }).play;

注意： 如果你不指定声道数，像 Ndef.kr(\maus) 这样的表达式将返回一个数组。随后，例如被 Pan2 UGen 使用时，你可能会收到消息：WARNING: Synth output should be a flat array. 如果你希望输出确实是单声道，请显式写为：Ndef.kr(\maus, 1)

使用弹性重塑时，如果你在路由中省略通道数，可以使用父级来扩展子级：

Ndef(\maus, { MouseX.kr });
Ndef(\haus, { Blip.ar(Ndef.kr(\maus) * 70) }).play;
Ndef(\haus).reshaping = \elastic;
Ndef(\maus).reshaping = \elastic;
Ndef(\maus, { LFNoise0.kr(1 ! 8) + 1 }); // 现在可以听到 8 个并行的音频通道。

保留参数

如果给定的 UGen 函数中不存在三个参数，则会自动指定它们。你可以覆盖它们的使用：[\out, \gate, \fadeTime]

自定义包络

如果传递给代理的 UGen 函数有自己的包络，并且该包络可以释放 synth，则节点代理使用此包络而不是创建自己的包络。如果你提供了 fadeTime 参数，则将使用代理的 fadeTime。

Ndef(\sound).fadeTime = 3;
(
Ndef(\sound, { |fadeTime = 1, gate = 1|
    var e = Env.adsr(fadeTime, 0.01, 0.4, fadeTime).ar(2, gate);
    SinOsc.ar(100 + (e * 700), SinOsc.ar(208) * (1 - e) * 6) * e * 0.1
}).play
)

制作副本

.copy

复制隐藏的内部状态，使新代理独立于旧代理，但会保留对源对象的引用。渲染后的 SynthDef 会被缓存，因此该方法比直接将同一函数赋给新代理更高效。按照设计，监视器会被复制，但不会运行（请使用 play 以相同配置启动它）。

a = NodeProxy(s);
a.source = { |freq = 444| Blip.ar(freq * [1, 1.03], 200) * 0.1 };
a.play;
a.set(\freq, 555);
b = a.copy;
b.play;
b.set(\freq, 222);

注意： 如果需要，你也可以复制代理的一部分，例如 Monitor（通常将输出送回硬件总线）和 NodeMap，后者维护映射和设置作用域。

s.scope(4);
a = NodeProxy(s);
a.source = { |freq = 234| Blip.ar(freq * [1, 1.03], 20) * 0.5 };
a.playN([0, 1, 3], [0.04, 0.3, 0.1], vol: 1); // 一些复杂的路由
a.set(\freq, 123);

b = NodeProxy(s);
b.source = { |freq = 1000| SinOsc.ar(freq * 3 * { { rrand(0.9, 1.1) }.dup(8) }.dup(2)).mean * 0.5 };
b.monitor = a.monitor.copy;
b.nodeMap = a.nodeMap.copy;
b.play;
a.stop;

.copyState(proxy)

将一个代理的内部设置复制到另一个代理。旧状态会被清除。

参数：

proxy

其内部状态被复制的 proxy。

Reshaping

.reshaping

.reshaping = value

来自父类：BusPlug

决定添加新源时的行为。当前选项：

nil

初始化后保持相同总线——这是默认设置

\elastic

发生变化时，按需收缩和扩展，替换总线。监视器和子代理会被调整。

\expanding

发生变化时，仅根据需要增长，替换总线。监视器代理和子代理会被调整。

a = NodeProxy(s);
a.reshaping = \elastic;
a.play(0, 2); // 播放立体声
a.source = { BPF.ar(Dust.ar(8 ! 8), (0..5).nthPrime * 300, 0.01) * 20 };
a.numChannels; // 8

.mold(numChannels, rate, argReshaping, fadeTime)

将代理调整到给定的速率 / numChannels。如果有任何子代理具有弹性 -reshaping，它们也会相应调整。

a = NodeProxy(s);
a.play;
a.source = { BPF.ar(Impulse.ar({ rrand(1.0, 2.0) } ! a.numChannels), (0..5).nthPrime * 300, 0.01) * 20 };
a.numChannels; // 2
a.mold(8);
a.numChannels; // 8

设置或更改源的其他方式

.prime(obj)

设置源但不启动 synth。之后可使用 -send 启动它。正在运行的 synth 会被释放，且若 proxy 仍处于中性状态则将其初始化。

.add(obj, channelOffset: 0, extraArgs, now: true)

在当前源的基础上添加新源

.removeAt(index, fadeTime)

移除索引 i 处的对象及其 synth（如果存在）。如果未提供索引，则全部移除。

.removeLast(fadeTime)

如果存在，移除最后一个对象及其 synth。

.put(index, obj, channelOffset: 0, extraArgs, now: true)

按索引设置源。对象可以插入到任意索引处，只有索引的顺序是相关的。在内部，NodeProxy 使用 Order 来访问源。

参数：

index

对象应放置在内部顺序中的位置。如果为 -1，则释放所有对象

obj

有效的源（参见 Supported sources）。

channelOffset

在多通道设置下，当对象的 numChannels 小于代理时，设置此项会很有用

extraArgs

可直接随对象发送的参数（非缓存）

now

如果设置为 false，则只准备源而不启动对象（参见 -prime）

// put 可以与数组索引语法一起使用：
a = NodeProxy.new.play;
a[0] = { SinOsc.ar(Rand(200, 899)) * 0.1.dup };
a[2] = { SinOsc.ar(Rand(200, 899)) * 0.1.dup };
a.sources.do(_.postcs);
// 使用多个索引扩展为多个对象
a[0..5] = { SinOsc.ar(Rand(200, 899)) * 0.1.dup };
a.sources.do(_.postcs);
a.send; // 交换 synth，将源作为定义使用
a.clear;

控制正在运行的进程

.pause

暂停所有对象并将 proxy 设置为暂停

.resume

如果已暂停，则启动所有对象

.rebuild

从源代码重新构建所有 SynthDef。

.orderNodes( ... proxies)

将此组到最后一个组的顺序进行排列。当对外部输入进行过滤以最小化延迟时，这一点可能很重要。注意，如果提供了 -parentGroup，则节点必须位于同一个 parentGroup 中。

释放与清理

.free(fadeTime, freeGroup: true)

释放所有正在运行的 synth 和该组。如果有模式正在播放，则停止它们。

参数：

fadeTime

此动作的衰减时间

freeGroup

一个布尔值

.release(fadeTime)

释放正在运行的 Synth。如果有模式正在播放，则停止它们。

参数：

fadeTime

此动作的衰减时间

.clear(fadeTime: 0)

将所有内容重置为 nil，使 rate/numChannels 失效

参数：

fadeTime

如果给出了 fadeTime，则先淡出，然后清除。

.schedAfterFade(func)

在 fadeTime 和服务器延迟过去之后调用一个函数。如果代理指定了 quant 值，则在 quant 网格上的下一个时间点之后 fadeTime + latency 秒求值该函数；否则，淡出延迟立即开始。

参数：

func

要在适当时机调用的函数

访问实例变量

.sources

.sources = list

返回所有源的数组

.source

.source = obj

返回第一个源。

.server

来自父类：BusPlug

节点代理的服务器（一个 Server）。

.bus

.bus = inBus

来自父类：BusPlug

节点代理的私有总线（一个 Bus）。因为它有私有总线，所以无法直接听到——通过（.play 或 playN）监听会将其路由到硬件输出通道。

.rate

来自父类：BusPlug

总线速率（默认值：nil）。速率和通道数量由实例创建时（.control/.audio）确定，或通过从第一个源进行惰性初始化来确定（参见 the_lazy_proxy）

.numChannels

来自父类：BusPlug

总线 numChannels（默认值：nil）

.isNeutral

来自父类：BusPlug

如果 proxy 没有已初始化的 bus，则为 true。

.group

.group = inGroup

节点代理的组（一个 Group）。它由代理维护，作为放置所有 synth 的上下文。

.parentGroup

.parentGroup = node

来自父类：BusPlug

访问 parentGroup（默认值：nil），将其设置后可将代理的组运行在另一个组中。该组必须在外部进行维护（保持播放等）。

.clock

.clock = value

一个时钟，可设置为适应不同的计时方案，例如按拍准确替换源。

.quant

.quant = value

一个 quant 值，用于指定对源进行量化的替换。与 SuperCollider 中 quant 的一般用法兼容。

按 quant 重新发送并调整以同步代理。

.monitor

.monitor = value

来自父类：BusPlug

访问 Monitor 对象，它回放该代理私有总线的输出。

.loaded

如果该对象已在服务器上初始化（例如已存储 synthDef），则返回 true。

.paused

如果进程已暂停，则返回 true。

.awake = value

若设为 false（默认值：true），更改源不会立即启动新的 synth。当 synth 由 -spawn 触发，且声音的改变不应重复发送时，这很有用。

.fadeTime

.fadeTime = dur

设置交叉淡化时间。参见：jitlib_fading 。

设置 synth 控件

.set( ... args)

.map( ... args)

.setn( ... args)

NodeProxy 的行为类似于其 NodeMap，并且与 Synth 非常相似。

注意： 现在 map、setn、mapn 和 xmap 方法只是为了向后兼容而存在。所有操作都由 set 完成。

a = NodeProxy(s); a.play;
a.source = { Splay.ar(Blip.ar(\freq.kr(18 ! 4))) * 0.2 };
a.set(\freq, [1, 3, 56, 13]);
a.source = { Splay.ar(SinOsc.ar(LFSaw.ar(\freq.kr(18 ! 4)) * 250 + 400)) * 0.2 };
b = NodeProxy(s); b.source = { MouseX.kr(0, 3) *  [1, 3, 56, 13] };
a.set(\freq, b);
a.clear; b.clear;

参数：

... args

一个由成对元素组成的数组：key, value, key, value, ...

唯一键（一个 Symbol）指定要设置的控件名称。

对于 value，可以指定任何响应 "asControlInput" 的对象，特别是：

number

将控件设置为该数字

数字数组

将后续控制通道设置为相应的值

节点代理

将后续控制通道映射到对应的代理输出通道

.seti( ... args)

设置数组化控件的一部分，类似于 Synth: -seti。

参数：

... args

由 name、index、value 构成的三元组序列。

name

数组化控制的名称

index

数组中的索引

value

要设置的新值，可以是一个数组，用于设置一段元素范围。

讨论：

// 5 声道 NodeProxy，为方便起见在 Ndef 中初始化
(
Ndef(\sin).mold(5, \audio, \elastic);
Ndef(\sin)[0] = {
    SinOsc.ar(
        \freq.kr([200, 201, 202, 204, 205]),
        SinOsc.kr(\phase.kr([0, 0, 0, 0, 0])).range(0, 2pi)
    )
}
)

// 输出混音器：混合降为 2 个声道并将声道分布到声像上
(
Ndef(\out).mold(2, \audio, \elastic);
Ndef(\out)[0] = {
    // 5 通道输入
    Splay.ar(\in.ar(0!5), level: \amp.kr(0.3))
}
)

// 将 Ndef(\sin) 路由通过 Ndef(\out)
(
Ndef(\out) <<> Ndef(\sin);
Ndef(\out).play;
)

// 在第四通道中改变频率和相位
Ndef(\sin).seti(\freq, 3, 137, \phase, 1, 11)

// 第 1 个通道 310hz，第 3 个 207hz
Ndef(\sin).seti(\freq, [0, 2], [310, 207])

// 索引超出范围，参数数组长度不同
// 34 % 5 => 4, 12 % 5 => 2, 56 % 5 => 1
Ndef(\sin).seti(\freq, [34, 12, 56], [376, 199])
Ndef(\sin).getKeysValues // -> [[freq, [310, 376, 199, 137, 376]]]

Ndef.clear(10)

.unset( ... keys)

.unmap( ... keys)

移除指定的设置并取消映射或取消设置 synth。

.xset( ... args)

以交叉淡入到新设置的方式执行 set/map。交叉淡入时间为 NodeProxy 的 -fadeTime。

.lag( ... args)

设置这些参数的滞后值（与 -setRates 相同）。要移除这些设置，请使用：lag(\key1, nil, key2, nil, ...)

.setRates( ... args)

设置 synthDef 参数的默认速率（\tr、\ir、数值）。速率为 nil 则移除该设置。

.controlNames(except, addNodeMap: true)

返回所有槽的 ControlName 对象，除了此列表中的名称（默认：[\out, \i_out, \gate, \fadeTime]，这些名称在内部使用）。当节点代理接收到某个给定键的 set 时，相应 ControlName 的 defaultValue 包含被传入的对象，该对象可以是任何类型的对象。

.controlKeys(except, noInternalKeys: true)

返回所有槽中所有控件名对象的键（符号），但不包括此列表中列出的名称。（默认：无）。

参数：

except

名称列表

noInternalKeys

如果 noInternalKeys 为 true（默认值：true），则忽略键 [\out, \i_out, \gate, \fadeTime] 。

.getKeysValues(keys, except, withDefaults: true, noInternalKeys: true)

从 NodeMap（设置）和默认参数中获取所有键值对。

.controlKeysValues(keys, except)

获取默认参数中的所有键值对。

.findControlName(key)

在源对象中搜索给定的控制名符号，并返回该 ControlName。

.specs

从 SynthDef 元数据中获取 specs 数组。注意，对于具有多个源的 NodeProxy，结果将是一个包含所有源 SynthDef 的 specs 的字典。

~p.specs.postln;

显式地将 synth 发送到服务器

通常，进程（通常是 synth）在其各自的源被添加到代理时启动。然而，进程也可以重新启动，或者代理可以在休眠状态下使用，然后进程可以被显式启动。

.send(extraArgs, index, freeLast: true)

发送一个新的 synth 而不释放旧的。如果源是流或模式，则启动一个新的。

参数：

extraArgs

用于设置 synth 的参数。参数列表仅应用于该 synth。此处指定的参数会覆盖节点映射中的设置，但不会改动它们。

index

向哪个槽位发送新的 synth。如果为 nil，则使用全部。（默认：nil）

freeLast

是否释放该索引处的最后一个 synth（默认：true）

.sendAll(extraArgs, freeLast: true)

发送所有 synth，或重启所有对象。

参数：

extraArgs

用于设置合成器的参数。参数列表仅应用于该合成器。

freeLast

是否释放该索引处的最后一个 synth（默认：true）

.sendEach(extraArgs, freeLast: true)

与 send 类似，只是分别对各个对象进行迭代。

.wakeUp

在代理未被任何输出使用（.play 或 .ar/.kr）之前，它不会在服务器上运行。你可以唤醒它以强制其播放。通常不需要这样做。

支持的源

NodeProxy

通过读取另一个 NodeProxy 的总线来播放。

Function

被解释为 ugen 函数，并播放一个 Synth，类似于 Function.play。

SimpleNumber

将此值连续写入总线，覆盖先前的总线值。

数字的 Array

连续将值写入总线，覆盖之前的总线值。

Bus

读取总线上的信号。

SynthDef

使用该 SynthDef 播放一个 Synth。

Symbol

使用此名称的 SynthDef 播放一个 Synth。

Pattern

作为事件模式播放（使用 Pbind 或其他事件模式）。

Stream

作为事件流播放（返回事件的流）。

nil

Nil 会移除所有对象。

Pdef、EventPatternProxy

像流一样播放。

Task

已播放，未分配输出。

Tdef

像 Task 一样播放

Event

像在模式中一样播放。

关联（NodeProxy 角色）：
(\filter -> func)

过滤先前的输入（带后置控制）

(\filterIn -> func)

过滤先前的输入（使用 pre 控制）

(\set -> 事件模式)

使用模式的 event 键来设置控件

(\setbus -> 事件模式)

用事件模式设置总线。总线值为每个事件的 \value 键。

(\setsrc -> 事件模式)

用事件模式设置 source。source 为事件的 \source 键。

(\control -> 数组或数字)

准备好一种按索引设置值的高效方式

(\mix -> func)

混合音频

关键库：
AbstractPlayer

在单独的总线中启动，并映射到此总线

Instr

转换为播放器并启动
