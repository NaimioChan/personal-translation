PV_MagFreeze

冻结幅度。

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

说明

当 freeze > 0 时，将幅度冻结在当前水平。

类方法

PV_MagFreeze.new(buffer, freeze: 0.0)

参数：

buffer

FFT 缓冲区。

freeze

如果 > 0，则幅度冻结在当前水平。

实例方法

示例

s.boot;
b = Buffer.read(s, ExampleFiles.child);


(
SynthDef("help-magFreeze", { |out = 0|
    var in, chain;
    in = SinOsc.ar(LFNoise1.kr(5.2, 250, 400));
    chain = FFT(LocalBuf(2048), in);
    // 进出冻结状态
    chain = PV_MagFreeze(chain, SinOsc.kr(0.2));
    Out.ar(out, 0.1 * IFFT(chain).dup);
}).play(s);

)

(
// 用 MouseY 触发
SynthDef("help-magFreeze2", { |out = 0, soundBufnum = 2|
    var in, chain;
    in = PlayBuf.ar(1, soundBufnum, BufRateScale.kr(soundBufnum), loop: 1);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_MagFreeze(chain, MouseY.kr > 0.5);
    Out.ar(out, 0.1 * IFFT(chain).dup);
}).play(s, [\soundBufnum, b]);
)

b.free
