Pulse

带限脉冲波。

UGen : AbstractFunction : Object

另请参阅：LFPulse

说明

带脉冲宽度调制的带限脉冲波发生器。

类方法

Pulse.ar(freq: 440.0, width: 0.5, mul: 1.0, add: 0.0)

Pulse.kr(freq: 440.0, width: 0.5, mul: 1.0, add: 0.0)

参数：

freq

频率，单位为赫兹。

width

脉冲宽度比，从零到一。0.5 产生方波。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

// 调制频率
{ Pulse.ar(XLine.kr(40, 4000, 6), 0.1, 0.2) }.play;

// 调制脉冲宽度
{ Pulse.ar(200, SinOsc.kr(0.2).range(0.01, 0.99), 0.2) }.play;

// 两个带限方波通过一个谐振低通滤波器
{ RLPF.ar(Pulse.ar([100, 250], 0.5, 0.1), XLine.kr(8000, 400, 5), 0.05) }.play;
