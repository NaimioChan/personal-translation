Pexprand

服从指数分布的随机值

Pwhite : Pattern : AbstractFunction : Object

参见：Pkey

类方法

Pexprand.new(lo: 0.0001, hi: 1.0, length: inf)

注意： lo 和 hi 都应为正数或都为负数（它们的范围不应跨越 0）。

参数：

lo

值的下边界。

hi

值的上界

length

产生的值的数量。

实例方法

未文档化的实例方法

.embedInStream(inval)

示例

(
var a;
a = Pexprand.new(0.0001, 1, inf);
c = a.asStream.nextN(500);
// 绘制数值
c.plot(bounds: Rect(10, 10, 520, 380), discrete: true, parent: w);
// 值的直方图
c.histo(500).plot(bounds: Rect(10, 410, 520, 380), parent: w);
)

// 声音示例
(
SynthDef(\help_sinegrain,
    { |out = 0, freq = 440, sustain = 0.05|
        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain, 0.2), doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env))
    }).add;
)


(
var a;
a = Pexprand(0.0001, 1.0, inf).asStream;
{
    loop {
        Synth(\help_sinegrain, [\freq, a.next * 600 + 300]);
        0.02.wait;
    }
}.fork;
)
