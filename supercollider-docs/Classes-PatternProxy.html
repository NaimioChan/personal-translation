PatternProxy

流引用

Pattern : AbstractFunction : Object

另请参阅：Pdefn

子类：Pdefn、TaskProxy

说明

保持对一个流的引用，该流可在播放时被替换。因此多个流可被处理而不会产生依赖关系。

类方法

PatternProxy.new(source)

用模式（源）创建一个新实例。该模式应为值模式（参见 Pdefn）。

关于事件模式代理，请参阅：EventPatternProxy。可以传入一个函数来代替模式，从而创建一个例程。

PatternProxy.default

默认源，如果未指定则使用它。默认值为 1.0（不是 0.0，是为了对时长安全）

PatternProxy.defaultQuant

PatternProxy.defaultQuant = value

设置该类的默认量化值。（默认值：nil）

PatternProxy.defaultValue

默认返回值，如果未给出源。默认为 1.0（不是 0.0 是为了对时长安全）。这用于 -endless。

实例方法

.asStream

从此模式返回一个 Stream。一个模式代理可用于产生任意数量的独立流。

a = PatternProxy.new;
a.source = Pgeom(1, Pwhite(1.01, 1.2), inf);
b = a.asStream; c = a.asStream;

b.next;
b.next;
b.next;

c.next; // c 独立于 b
c.next;

a.source = Pgeom([1, 2, 3], Pwhite(1.01, 1.2), inf); // 替换源

b.next;
c.next;

.embedInStream(inval, embed: true, default)

给定一个 Stream（例如 Routine），在继续之前在代理中从模式产生所有值。一个模式代理可用于为任意数量的独立流产生值。

参数：

inval

inval 被传入所有子流，可用于从外部控制它们的行为。

embed

有关说明，请参见 Object: -streamArg。

default

用于替换源模式中 nil 输出的替代值。一个用例是 -endless。

a = PatternProxy.new;
a.source = Pgeom(1, Pwhite(1.01, 1.2), 4);
r = Routine { loop { 2.yield; 3.yield; a.embedInStream } };
r.nextN(12); // 来自 r 的下 12 个值
a.source = Pgeom([1, 2, 3], Pwhite(1.01, 1.2), inf); // 替换源
r.nextN(12); // 来自 r 的下 12 个值

.source

.source = obj

设置源。如果给定了量化，则将此变更调度到下一个拍点

.clear

将源设为 nil

.quant

.quant = val

设置或获取量化值

.condition

.condition = value

提供一个条件，当插入新模式时依据该条件切换模式。流的值和一个计数会被传入该函数。方法 count_(n) 简单地计数到 n，然后切换模式。

.embedInStream(inval, embed: true, default)

就像任何模式一样，它嵌入到流中

为子类实现的方法

PatternProxy 为其子类 Pdefn / Pdef / Tdef 实现了一些方法，这些方法对 PatternProxy 和 TaskProxy 没有用处。

.envir

.envir = value

为代理提供默认环境。如果给出，它会被用作例程函数的环境。首次设置时，例程模式会被重建。

.set( ... args)

在环境中设置参数。如果没有环境，则会创建它并重建模式。

.endless(default)

返回一个 Prout，它无限地播放代理，将 nil 替换为 默认值 (1)。这允许创建一直空闲直到插入新模式（pattern）的流。
