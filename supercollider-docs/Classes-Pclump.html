Pclump

一种模式，接受另一个模式并将其值分组为数组。

FilterPattern : Pattern : AbstractFunction : Object

另见：SequenceableCollection: -clump

子类：Pflatten

说明

将源模式分组为大小由 n 给定的数组。类似于 SequenceableCollection: -clump。

例如，如果源模式有 5 个元素，而你选择的分组大小为 2，则新模式将返回两个包含 2 个元素的数组，以及最后一个包含 1 个元素的数组。

类方法

Pclump.new(n, pattern)

参数：

n

一个整数，或一个返回整数的模式。这个整数将决定下一个 clump 的大小。

pattern

要过滤的模式。

示例

// 这将给你序列：[1, 2] [3] nil
// 注意，最后一个分组只是模式的剩余部分（在本例中为 [3]）。
x = Pclump(2, Pseq([1, 2, 3], 1)).asStream;
x.next;
x.next;
x.next;

播放一些随机和弦：

Pbind(

  \dur, 1).play
