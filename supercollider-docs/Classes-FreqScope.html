FreqScope

频谱可视化器

另请参阅：FreqScopeView

说明

FreqScope 显示指定音频总线的频谱。在按下 command-period 后，示波器仍保持活动状态。要将其关闭，必须点击关闭 'Power' 按钮或关闭窗口。

面板命令：

Power

打开和关闭示波器。这对于在显示上冻结信号或节省 CPU 很有用。

BusIn

要分析的音频总线。

FrqScl

确定 x 轴上频率的映射方式。可以是线性（lin）或对数（log）。对数方式为每个音乐八度等间距。

dbCut

确定 y 轴上显示的最低分贝。

类方法

.new

参数：

width

默认值为 512。

height

默认值为 300。

busNum

要监听的音频 Bus 的编号。

scopeColor

Color 的一个实例。示波器的绘制颜色。

bgColor

Color 的一个实例。示波器的背景颜色。

server

要在示波器上显示其总线的服务器。

讨论：

Example:

s.boot;

// 创建一个新的分析器
FreqScope.new(400, 200, 0, server: s);

// 基本正弦
{ SinOsc.ar(2000, 0, 0.25) }.play(s);

// 随机锯齿波
{ RLPF.ar(Saw.ar(110, 0.2), LFNoise2.kr(1, 1e4, 1e4), LFNoise2.kr(1, 0.2, 0.22)) }.play(s);

// 调制相位
{ SinOsc.ar(800, SinOsc.ar(XLine.kr(20, 8000, 10), 0, 2pi), 0.25) }.play(s);

// 所有谐波
{ Blip.ar(200, Line.kr(1, 100, 10), 0.2) }.play(s);
