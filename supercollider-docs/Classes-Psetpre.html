Psetpre

在事件被向上传递之前设置其中某个键的值

FilterPattern : Pattern : AbstractFunction : Object

另请参阅：Pset、Psetp

子类：Paddpre、Pmulpre

说明

在事件被传递到流之前，在事件中设置一个值。要在值被传递到流之后设置它，请使用 Pset。

(
var a, b;
a = Psetpre(\freq, 801, Pbind(\dur, 0.5));
x = a.asStream;
9.do({ x.next(Event.new).postln });
)

类方法

Psetpre.new(name, value, pattern)

参数：

name

该键

value

可以是模式或流。当传入的流结束时，结果流也随之结束。

pattern

该模式

实例方法

未文档化的实例方法

.embedInStream(event)

.filterEvent(event, val)

.name

.name = value

.value

.value = value

示例

// Psetpre 不会覆盖传入的值：

(
var a, b;
a = Psetpre(\freq, 801, Pbind(\freq, 108));
x = a.asStream;
9.do({ x.next(Event.new).postln });
)


(
var a, b;
a = Psetpre(\freq, Pseq([401, 801], 2), Pbind(\dur, 0.5));
x = a.asStream;
9.do({ x.next(Event.new).postln });
)


// 声音示例

(
SynthDef(\sinegrain,
    { |out = 0, freq = 440, sustain = 0.02|
        var env;
        env = EnvGen.kr(Env.perc(0.001, sustain), 1, doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env * 0.1))
    }).add;
)

(
a = Pbind(\dur, 0.5, \instrument, \sinegrain);
a = Psetpre(\freq, Pseq([500, 600, 700], inf), a);
a = Psetpre(\legato, Pseq([0.01, 1], inf), a);
a.play;
)
