Association

关联两个对象

Magnitude : Object

说明

将键与值关联起来。关联可以通过 -> 运算符创建，该运算符定义在类 Object 中。

关联在 Dictionary 内部使用。

类方法

Association.new(key, value)

在两个对象之间创建一个关联。

(
x = 'name' -> 100;
x.postln;
)

参数：

key

任意对象

value

任意对象

实例方法

Accessing

.key

.key = value

键对象。

.value

.value = value

值对象。

Testing

==(anAssociation)

比较两个 Association 的键。

<(anAssociation)

比较两个 Association 的键。

.hash

计算 Association 的哈希值。

写入流

.printOn(stream)

将字符串表示写入流。

.storeOn(stream)

将可编译的字符串表示写入流。

示例

// 关联可以很好地将命名数据按顺序存储：
(
a = [\x -> 700, \y -> 200, \z -> 900];

fork {
    a.do { |assoc|
        assoc.key.postln;
        assoc.value.postln;
        (freq: assoc.value).play;
        2.wait;
    }
};
)
