PV_Diffuser

随机相位偏移。

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

参见：FFT、IFFT、PV_PhaseShift、PV_PhaseShift90、PV_PhaseShift270

说明

为每个 bin 添加不同的常量随机相位偏移。被触发时，它会选择一组新的随机相位。

类方法

PV_Diffuser.new(buffer, trig: 0.0)

参数：

buffer

FFT 缓冲区。

trig

一个触发器，用于选择一组新的随机值。

实例方法

示例

(
// 用 MouseY 越过屏幕中心来触发
{
    var in, chain;
    in = Mix.ar(SinOsc.ar(200 * (1..10), 0, Array.fill(10, { rrand(0.1, 0.2) })));
    chain = FFT(LocalBuf(2048), in);
    chain = PV_Diffuser(chain, MouseY.kr > 0.5);
    0.5 * IFFT(chain).dup;
}.play
);
