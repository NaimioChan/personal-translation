WebView

网页显示与浏览器

说明

WebView 显示网页并提供所有标准浏览功能。

由于 Qt WebEngine 依赖体积庞大且在某些系统上难以安装，sclang 有可能在没有 WebView 支持的情况下构建（编译时使用 CMake 标志 -DSC_USE_QTWEBENGINE=OFF）。如果是这样，尝试调用这个类将抛出错误。

类方法

.clearCache

清除所有浏览器实例的缓存。

.setUrlHandler

设置或清除用于处理特定 URL 前缀的函数（如 mail://)

参数：

prefix

URL 前缀。对于 mail:///，请使用字符串 "mail"（不要附加 "://"）

function

当任何 WebView 加载带有此前缀的 URL 时要执行的函数。第一个参数是 URL。

实例方法

Navigation

.url

获取当前 URL，或导航到新的 URL。这相当于在浏览器的 URL 框中输入 URL。

.navigate

导航到一个 url。这等同于点击页面上的链接——调用 navigate 后，back 会返回到上一页。

.back

导航到历史记录中的上一页。

.forward

在历史记录中导航到下一页。

.findText

在当前页面上查找并选择给定文本的下一个实例。当给定文本发生变化时，搜索会重新开始。

参数：

要查找的文本；一个 String。

是否反向搜索；一个 Boolean。

一个函数，在操作完成时调用。如果找到文本，则向该函数传递 true，否则传递 false。

.triggerPageAction

在当前页面上触发一个动作。可用的动作包括：reload、select all、copy、undo、redo（参见 QWebPageAction）

参数：

一个 QWebPageAction。

一个 Boolean，用于启用或禁用该动作（仅适用于部分动作）。

Data

.setHtml

设置视图中显示的 HTML。

参数：

一个 String。

一个 URL。浏览器会将其解释为当前页面位置。

.setContent

设置 web 视图的原始内容。可用于显示二进制数据，例如图片 / 影片文件。

参数：

包含数据的 Int8Array。

一个 mime 类型，形如 "image/jpeg"

一个 URL。浏览器会将其解释为当前页面位置。

.setAttribute

为视图设置一个 QWebAttribute。属性可以影响行为，例如缓存、自动加载图像、文件 URL 访问等。

参数：

一个 QWebAttribute。

一个布尔值。

.testAttribute

检查 QWebAttribute 的启用状态。

参数：

一个 QWebAttribute。

返回值：

一个布尔值。

.resetAttribute

重置 QWebAttribute 的启用状态。

参数：

一个 QWebAttribute。

.toPlainText

将页面转换为纯文本。

参数：

一个回调函数。当操作完成时，以结果纯文本字符串作为参数调用。

.toHtml

获取当前页面的 HTML。

参数：

一个回调函数。操作完成时，以生成的 HTML 字符串作为参数调用。

.title

当前页面的标题。

返回值：

一个 String。

.requestedUrl

当前页面请求的 url。

返回值：

一个 String。

.selectedText

当前选中的文本。

返回值：

一个 String。

行为与外观

.audioMuted

获取或设置视图的音频静音设置；

参数：

一个布尔值。

.contentsSize

获取当前内容的大小。

返回值：

一个 Point

.scrollPosition

获取或设置当前页面的滚动位置。

返回值：

一个 Point

.hasSelection

返回页面是否有文本选区。

返回值：

一个布尔值。

.enterInterpretsSelection

在选中某些文本时按下 Ctrl+Return 或 Ctrl+Enter 是否应将所选内容作为 SuperCollider 代码进行求值。

参数：

一个布尔值。

.setFontFamily

设置特定的字体族以替代 CSS 指定的通用字体族。

参数：

要分配字体的 CSS 通用字体族；是 QWebFontFamily 之一

要分配给通用族的字体族名称；一个 String。

.zoom

获取或设置页面的缩放级别。

参数：

一个 Number，其中 1.0 为默认缩放。

.editable

获取或设置整个网页是否可编辑。

参数：

一个布尔值。

.pageBackgroundColor

获取或设置网页的默认背景颜色。

参数：

一个 Color。

Actions

.onAudioMutedChanged

设置当视图的静音设置已改变时被求值的对象。

.onRecentlyAudibleChanged

设置当页面开始或停止播放音频时要被求值的对象。

.onContentsSizeChanged

设置当视图的内容尺寸已改变时被求值的对象

.onScrollPositionChanged

设置当页面上滚动位置发生变化时要被求值的对象。

.onSelectionChanged

设置页面上的文本选择发生变化时要被求值的对象。

.onJavaScriptMsg

设置当发布 javascript 控制台消息时要求值的对象。

.onLinkHovered

设置当鼠标滚过链接时要计算的对象。

.onTitleChanged

设置当所显示页面的标题改变时求值的对象。

.onUrlChanged

设置当所显示页面的 url 改变时要评估的对象。

.onLoadProgress

设置要随加载进度更新而被求值的对象。

.onLoadStarted

设置页面加载开始时被求值的对象。

.onLoadFinished

设置页面成功加载后求值的对象，将视图作为参数传入。

.onLoadFailed

设置当页面加载失败时要评估的对象，并将视图作为参数传入。

.overrideNavigation

当为 true 时，页面导航请求将不被处理。与 onLinkActivated 组合使用以提供自定义导航行为。

.onLinkActivated

设置当用户触发链接时要被求值的对象。参数为：一个 URL、一个 QWebPageNavigationType、一个布尔值（页面是否在当前视图中打开）。

当此项设置为非 nil 时，WebView 将完全停止处理被点击的链接。将其设置为 nil 将恢复 WebView 的链接处理。注意：对于点击链接时的特殊行为，在大多数情况下使用 setUrlHandler 要好得多。

.onReloadTriggered

设置每当请求重新加载页面时要计算的对象，将视图和要重新加载的 URL（作为 String）作为参数传递。

JavaScript

.runJavaScript

在当前页面的上下文中计算给定的 JavaScript 代码。

参数：

一个 String。

执行完成时要调用的函数，其结果作为第一个参数。

注意： javascript 代码可以正确地返回 Numbers、Strings 和 Arrays，但目前它无法将 javascript Objects 传递给 sclang。不过，可以使用 JSON 序列化来实现这一点：

// 从 javascript 向 sclang 传递一个嵌套对象：
WebView().runJavaScript("JSON.stringify({ a: [1,2,3], b: { ba: 1, bb: 'yeah' } })"){ |res| res.parseJSON.postln }

示例

// 一个简单的网页浏览器
(
var browser, webview, reloadStop, prev, next, urlBox, go;

webview = WebView()
    .minSize_(300@200);
reloadStop = Button()
    .states_([["※"], ["◙"]])
    .fixedSize_(36@28);
prev = Button()
    .states_([["⇦"]])
    .fixedSize_(36@28);
next = Button()
    .states_([["⇨"]])
    .fixedSize_(36@28);
urlBox = TextField()
    .minWidth_(100);
go = Button()
    .states_([["⌘"]])
    .fixedSize_(36@28);

reloadStop.action = {
    |v|
    if (v.value == 1) {
        webview.reload(true);
    } {
        webview.stop;
    }
};

prev.action = { webview.back };
next.action = { webview.forward };
urlBox.action = { webview.url = urlBox.string };
go.action = { webview.url = urlBox.string };

webview.onUrlChanged = {
    |view, url|
    urlBox.string = url;
};

webview.onLoadStarted = {
    reloadStop.value = 1;
    urlBox.background = Color.grey(0.4);
};

webview.onLoadFinished = {
    reloadStop.value = 0;
    urlBox.background = Color.grey(0.2);
};

webview.onLoadFailed = {
    reloadStop.value = 0;
    urlBox.background = Color.red(1, 0.2);
};

browser = View(bounds: 900@700).layout_(VLayout(
    HLayout(
        prev, reloadStop, next,
        urlBox,
        go
    ),
    webview
));

browser.front;

urlBox.valueAction = "http://supercollider.github.io/"
)
