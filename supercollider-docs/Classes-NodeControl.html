NodeControl

在对象中封装一个节点和一个索引。

Object

说明

该对象可由客户端持有，并可在不必另外存储节点输入位置细节的情况下设置其值。

类方法

NodeControl.new(node, index)

参数：

node

要封装的节点

index

要封装的索引

实例方法

.value

.value = aval

来自父类：Object

示例

d = SynthDef("help-NodeControl", { |out = 0, freq = 400|
    Out.ar(out,
         SinOsc.ar(freq, 0, 0.5)
    )
});
y = d.play; // 合成器

c = NodeControl(y, 1);

c.value = 500;

c.value = 300;
