EventStreamPlayer

由二元运算符组合的两个流

PauseStream : Stream : AbstractFunction : Object

另请参阅：Event、Pbind

说明

EventStreamPlayer 由基于 Event 的模式使用。

EventStreamPlayer 持有一个返回一系列 Event 的流，以及一个 protoEvent。每次调用 next 时，它复制 protoEvent，将该副本传递给流，并对返回的 Event 调用 play。

有关 EventStreamPlayer 的更多信息，请参阅 Understanding Streams, Patterns and Events - Part 4

EventStreamPlayer 使用与 Task 相同的控制方法和状态通知。

类方法

EventStreamPlayer.new(stream, event)

注意： 你无需显式创建 EventStreamPlayers，当你调用 Pattern: -play 时它们会为你创建。

实例方法

.play(argClock, doReset: false, quant)

参数：

argClock

（可选）覆盖 Task.new 中分配的时钟。

doReset

如果为 true，任务将从头开始。默认值为 false（任务将从上次停止处继续）。

quant

参见 Quant 帮助文件。

.start(argClock, quant)

来自父类：PauseStream

从头重新启动任务。

.resume(argClock, quant)

来自父类：PauseStream

从任务中断处恢复。

.pause

来自父类：PauseStream

立即停止播放。

.stop

立即停止播放。（暂停和停止具有相同的实现。）

.reset

将流设置为下次播放时从头重新开始。

.reschedule(argClock, quant)

来自父类：PauseStream

在不停止的情况下，将 Task 切换到不同的时钟或不同的时间。完整文档请参见 Routine: -reschedule。

注意： 目前不支持在模式内部重新调度 EventStreamPlayer。
