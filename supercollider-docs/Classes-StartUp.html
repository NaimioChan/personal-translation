StartUp

注册在启动完成后求值的函数

AbstractSystemAction : Object

参见：ShutDown、ServerBoot、ServerTree、CmdPeriod

说明

StartUp 注册函数，以便在库编译完成之后、启动文件运行之后执行操作。例如，它用于在类文件的 initClass 函数中创建 SynthDef，以便让启动脚本可以自定义 synthdef 目录。

如果对象已注册，则必须实现 doOnStartUp。否则可以使用函数。

类方法

StartUp.add(object)

来自父类：AbstractSystemAction

注册一个对象或函数，在启动完成后进行求值。

StartUp.defer(object)

注册一个对象或函数，使其在启动完成后被求值；如果启动已经完成，则立即求值。

StartUp.remove(object)

来自父类：AbstractSystemAction

移除先前注册的对象。

StartUp.run

按顺序调用对象。

示例

    }
