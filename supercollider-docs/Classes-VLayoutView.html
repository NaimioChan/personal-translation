VLayoutView

一个垂直排列其子项的容器视图

参见：HLayoutView、CompositeView

说明

注意： 在 Qt GUI 中，此类已被一组专门的布局类取代，因此已过时；这些布局类更易于使用且更灵活。有关此类的等价物，请参见 VLayout；有关 Qt 布局系统的总体说明，请参见 Layout Management。

VLayoutView 可以作为其他视图的父视图，它会自动将子视图按垂直顺序排列，并将它们的宽度扩展至自身边界。只有子视图的高度是相关的。

在排列其子视图时，VLayoutView 会考虑它们的 'minHeight' 和 'maxHeight' 属性值。当子视图的 resize 模式设为 4、5 或 6 时，这很有用。参见下面的示例。

VLayoutView 从其父类继承了一些有用的格式化方法。

注意： VLayoutView 主要用于对控件进行分组和放置。虽然可以将其设置为接受按键，但它不接受鼠标点击或拖动。

示例

(
q = 10;
w = Window.new;

v = VLayoutView(w, Rect(10, 10, 300, 300));

Array.fill(q, { |i|
    Slider(v, Rect(0, 0, 75, 20)).value_(i / q)
});

w.front
)

// 显示视图的区域。
v.background_(Color.rand) // 滑块会自动展开到最佳宽度

拉伸布局视图；滑块高度固定：

(
q = 10;
w = Window.new;

v = VLayoutView(w, Rect(10, 10, 300, 300));
v.background_(Color.rand);
v.resize = 5; // 弹性
Array.fill(q, { |i|
    var s;
    s = Slider(v, Rect(0, 0, 55, 20)); // 在此处 bounds.width 无关紧要。它们会扩展到最优宽度
    s.value = i / q;
    s
});
StaticText(v, Rect(0, 0, 55, 20)).background_(Color.rand).string_("Some Example Text").align_(\center);
w.front
)

拉伸布局视图及其内容；如果所有内容都是弹性的，则内容的高度会被完美均分。在此示例中，StaticText 不是弹性的，以保持其高度。

(
q = 10;
w = Window.new;

v = VLayoutView(w, Rect(10, 10, 300, 300));
v.background_(Color.rand);
v.resize = 5; // 弹性
Array.fill(q, { |i|
    var s;
    s = Slider(v, Rect(0, 0, 75, 20));
    s.resize = 5; // 弹性
    s.value = i / q;
    s
});
StaticText(v, Rect(0, 0, 55, 40))
    .background_(Color.rand).string_("Some Example Text")
    .align_(\center);

w.front
)

混合拉伸模式：

(
q = 5;
w = Window.new;

v = VLayoutView(w, Rect(10, 10, 300, 300));
v.resize = 5; // 弹性
v.background_(Color.grey);
Array.fill(q, { |i|
    var s;
    s = Slider(v, Rect(0, 0, 75, 20)).background_(Color.rand);
    s.value = i / 5;
    if(i < 2, {
        s.resize = 5; // 一些弹性
        s.setProperty(\minHeight, 20);
    }, {
        s.resize = 1; // 部分非弹性
    });
    s
});
StaticText(v, Rect(0, 0, 55, 20)).background_(Color.rand).string_("Some Example Text").align_(\center);

w.front
)

设置最小高度；注意，如果布局视图的高度小于所有内容的总高度，当你尝试用鼠标处理它们时，这些东西可能会消失：

(
q = 5;
w = Window.new;

v = VLayoutView(w, Rect(10, 10, 300, 300));
v.resize = 5; // 弹性
v.background_(Color.grey);
Array.fill(q, { |i|
    var s;
    s = Slider(v, Rect(0, 0, 75, 20)).background_(Color.blue.alpha_(0.2));
    s.value = i / 5;
    s.resize = 5;
    s.setProperty(\minHeight, 20);
    s.setProperty(\maxHeight, 40);
    s
});
w.front
)

Spacing:

(
q = 10;
w = Window.new;

v = VLayoutView(w, Rect(10, 10, 300, 300));
v.setProperty(\spacing, 0);

Array.fill(q, {
    Slider(v, Rect(0, 0, 75, 20))
});

w.front
)

嵌套：组合使用 VLayoutView 和 HLayoutView：

(
q = 10;
w = Window.new("nesting", Rect(30, 30, 400, 700));

v = VLayoutView(w, Rect(10, 10, 300, 600));

v.background = Color.rand;

Array.fill(q, { |i|
    Slider(v, Rect(0, 0, 75, 20)).value_(i / q)
});

StaticText(v, Rect(0, 0, 55, 20)).background_(Color.rand).string_("Some Example Text").align_(\center);

h = HLayoutView(v, Rect(10, 10, 300, 300));

Array.fill(q, { |i|
    Slider(h, Rect(0, 0, 20, 70)).value_(i / q)
});
h.background = Color.rand;

w.front
)
