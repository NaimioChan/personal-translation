InTrig

每当总线被设置时生成一个触发。

AbstractIn : MultiOutUGen : UGen : AbstractFunction : Object

说明

每当总线被“触碰”，即其值被设置时（使用 "/c_set" 等），将生成单个脉冲触发。其幅度为总线被设置的值。

如果总线被同步设置，则不会生成触发。

类方法

InTrig.kr(bus: 0, numChannels: 1)

参数：

bus

要读取的总线索引。

numChannels

要读取的通道数（即相邻的总线）。你不能通过在 SynthDef 中将其赋值给参数来调制这个数字。

实例方法

示例

s = Server.local;
b = Bus.control(s, 1);

SynthDef("help-InTrig", { |out = 0, busnum = 0|
    var inTrig;
    inTrig = InTrig.kr(busnum);
    Out.ar(out,
        EnvGen.kr(Env.perc, gate: inTrig, levelScale: inTrig) * SinOsc.ar
    )
}).play(s, [\out, 0, \busnum, b.index]);


b.set(1.0);

b.value = 1.0;

b.value = 0.2;

b.value = 0.1;

与 In 示例进行比较。
