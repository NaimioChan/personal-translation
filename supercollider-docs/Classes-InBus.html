InBus

从总线返回一段通道范围，与节点顺序无关

UGen : AbstractFunction : Object

另见：In、XIn、InFeedback、XInFeedback

说明

InBus 为总线上的信号提供了一个简单的接口，可在相邻值之间交叉淡化。

(
b = Bus.control(s, 9); // 九通道控制速率
b.setn([244, 737, 20, 271, 382, 172, 4, 2399, 251]);
{
    var index = MouseX.kr(0, 30);
    Blip.ar(InBus.ar(b, 2, index, \wrap)) * 0.1
}.play;
)

类方法

InBus.ar(bus, numChannels, offset: 0, clip)

InBus.kr(bus, numChannels, offset: 0, clip)

返回一个具有相应速率的新的实例。如果总线速率不匹配，信号会被转换。多通道参数会展开。

参数：

bus

一个 Bus 的实例

numChannels

输出通道数

offset

总线中起始索引的偏移量。

clip

如果将 clip 设置为 'wrap'，则总线中的索引不会被裁剪到最后一个总线通道，而是会环绕。

返回值：

一个 UGen 输出，通常是 UGens 的数组，或者如果参数是数组，则为数组的数组。
