Gendy1

动态随机合成生成器。

UGen : AbstractFunction : Object

另请参阅：Gendy2、Gendy3

说明

由 Iannis Xenakis 构思的动态随机合成生成器的一种实现，描述于 Formalized Music (1992, Stuyvesant, NY: Pendragon Press) 第 9 章（第 246-254 页）以及第 13 章和第 14 章（第 289-322 页）。

书中的 BASIC 程序由 Marie-Helene Serra 编写，因此我认为也应当提及她的贡献。

程序代码已作调整，以避免概率分布函数中出现无穷大。

分布在 C 中是硬编码的，但有一个选项可以从连续控制器输入中采样新的振幅或时间断点。

技术说明

如第 13 章所述，X 的方案允许周期中的 12 个段随每个新周期依次被修改。然而，周期可以作为各段时长的总和而变化，如图 1 所示。我们可以为 n 个（通常为 12 个）点建立某种记忆，甚至只是依次改变单个点的纵坐标和时长。因此我们有多种可选方案。其中一种方案固定周期 T，只在周期内移动 (ti, Ei)。另一种方案记忆 12 个段，但允许连续修改点间间隔和幅度。还有一种方案只保留一个点，并基于概率分布对其幅度和时长进行随机游走。在此实现中，我允许用户初始化一定数量的记忆点，具体数量由用户决定。要将周期限制为不变，必须将速率变化设为零（dscale = 0）。

SuperCollider 实现由 Nick Collins 完成。

类方法

Gendy1.ar(ampdist: 1, durdist: 1, adparam: 1.0, ddparam: 1.0, minfreq: 440, maxfreq: 660, ampscale: 0.5, durscale: 0.5, initCPs: 12, knum, mul: 1.0, add: 0.0)

Gendy1.kr(ampdist: 1, durdist: 1, adparam: 1.0, ddparam: 1.0, minfreq: 20, maxfreq: 1000, ampscale: 0.5, durscale: 0.5, initCPs: 12, knum, mul: 1.0, add: 0.0)

参数：

ampdist

控制点振幅下一次扰动所使用的概率分布选项。

这些分布（改编自《Formalized Music》中的 GENDYN 程序）：

0:

LINEAR.

1:

CAUCHY.

2:

LOGIST.

3:

HYPERBCOS.

4:

ARCSINE.

5:

EXPON.

6:

SINUS.

在此实现中，sinus（Xenakis 的命名）取自第三方振荡器的采样。参见下面的示例。

0:

LINEAR.

1:

CAUCHY.

2:

LOGIST.

3:

HYPERBCOS.

4:

ARCSINE.

5:

EXPON.

6:

SINUS.

durdist

用于扰动当前控制点间时长的分布选择。

adparam

幅度概率分布形状的参数，要求值在 0.0001 到 1 的范围内（代码中有安全检查，所以如果你想调制也不用太担心！）。

ddparam

一个用于控制时长概率分布形状的参数，要求取值在 0.0001 到 1 之间。

minfreq

Gendy1 振荡器允许的最小振荡频率，因此给出持续时间所允许取的最大周期。

maxfreq

Gendy1 振荡器允许的最大振荡频率，因此给出持续时间所允许采用的最短周期。

ampscale

通常为 0.0 到 1.0，是分布中振幅增量值的乘数。ampscale 为 1.0 时，振幅变化允许 -1 到 1 的完整范围。

durscale

通常为 0.0 到 1.0，是分布中时长 delta 值的乘数。ampscale 为 1.0 时允许时长变化达到 -1 到 1 的完整范围。

initCPs

初始化内存中的控制点数量。Xenakis 指定为 12。这将是振荡器每个周期的控制点数量，不过振荡器的周期会因时长分布而不断变化。

knum

当前使用的控制点数量，允许调制。

mul

add

讨论：

除 initCPs 仅在初始化时使用外，所有参数都可以在控制率下进行调制。

实例方法

示例

警告： 如果你有大量 CP 且频率很快，CPU 开销会大幅增加，因为每个采样都会发生新的 CP 移动！

// 默认值
{ Pan2.ar(Gendy1.ar) }.play

// 游走的低音/电力线
{ Pan2.ar(Gendy1.ar(1, 1, 1.0, 1.0, 30, 100, 0.3, 0.05, 5)) }.play

// 播放我
{ Pan2.ar(RLPF.ar(Gendy1.ar(2, 3, minfreq: 20, maxfreq: MouseX.kr(100, 1000), durscale: 0.0, initCPs: 40), 500, 0.3, 0.2), 0.0) }.play

// 尖叫！——注意保护你的耳朵！
(
{
    var mx, my;

    mx = MouseX.kr(220, 440);
    my = MouseY.kr(0.0, 1.0);

    Pan2.ar(Gendy1.ar(2, 3, 1, 1, minfreq: mx, maxfreq: 8*mx, ampscale: my, durscale: my, initCPs: 7, mul: 0.3), 0.0)
}.play
)


// 1 CP = 随机噪声效果
{ Pan2.ar(Gendy1.ar(initCPs: 1)) }.play

// 2 个 CP = 突然变成一个振荡器（虽然这里是一个快速调制的振荡器）
{ Pan2.ar(Gendy1.ar(initCPs: 2)) }.play


// 用作 LFO
(
{
    Pan2.ar(
        SinOsc.ar(
            Gendy1.kr(2, 4,
                SinOsc.kr(0.1, 0, 0.49, 0.51),
                SinOsc.kr(0.13, 0, 0.49, 0.51),
                3.4, 3.5,
                SinOsc.kr(0.17, 0, 0.49, 0.51),
                SinOsc.kr(0.19, 0, 0.49, 0.51),
                10, 10, 50, 350),
        0, 0.3),
    0.0)
}.play
)

// wasp
{ Pan2.ar(Gendy1.ar(0, 0, SinOsc.kr(0.1, 0, 0.1, 0.9), 1.0, 50, 1000, 1, 0.005, 12, 12, 0.2), 0.0) }.play


// 调制分布
// 音高变化，因为分布改变了持续时间结构和频谱
{ Pan2.ar(Gendy1.ar(MouseX.kr(0, 7), MouseY.kr(0, 7), mul: 0.2), 0.0) }.play


// 调制 CP 的数量
{ Pan2.ar(Gendy1.ar(knum: MouseX.kr(1, 13), mul: 0.2), 0.0) }.play

// Gendy 进入 Gendy……伴随着卡通般的副作用
    (
        {
            Pan2.ar(Gendy1.ar(
                maxfreq: Gendy1.kr(5, 4, 0.3, 0.7, 0.1, MouseY.kr(0.1, 10), 1.0, 1.0, 5, 5, 500, 600),
                knum: MouseX.kr(1, 13), mul: 0.2), 0.0)
        }.play
    )

// 使用 SINUS 跟踪任意振荡器并从中获取 CP 位置，使用 adparam 和 ddparam 作为采样输入
{ Pan2.ar(Gendy1.ar(6, 6, LFPulse.kr(100, 0, 0.4, 1.0), SinOsc.kr(30, 0, 0.5), mul: 0.2), 0.0) }.play


// 尤其尝试靠近角落的位置
    (
        { 
            Pan2.ar(Gendy1.ar(6, 6, LFPulse.kr(MouseX.kr(0, 200), 0, 0.4, 1.0),
            SinOsc.kr(MouseY.kr(0, 200), 0, 0.5), mul: 0.2), 0.0)
        }.play
    )

// 质感
    (
        {
            Mix.fill(10, {
                var freq = rrand(130, 160.3);
                Pan2.ar(SinOsc.ar(Gendy1.ar(6.rand, 6.rand, SinOsc.kr(0.1, 0, 0.49, 0.51),
                    SinOsc.kr(0.13, 0, 0.49, 0.51), freq, freq, SinOsc.kr(0.17, 0, 0.49, 0.51),
                    SinOsc.kr(0.19, 0, 0.49, 0.51), 12, 12, 200, 400), 0, 0.1), 1.0.rand2)
            })
        }.play
    )

// 哇啊啊啊啊——也试试 durscale 10.0 和 0.0
    (
        {
            Pan2.ar(
                CombN.ar(
                    Resonz.ar(
                        Gendy1.ar(2, 3, minfreq: 1, maxfreq: MouseX.kr(10, 700), durscale: 0.1, initCPs: 10),
                        MouseY.kr(50, 1000), 0.1),
                    0.1, 0.1, 5, 0.6
                ),
                0.0)
        }.play
    )

// 过度
    (
        {
            var n = 10;
            Mix.fill(n, {
                var freq, numcps;

                freq = rrand(130, 160.3);
                numcps = rrand(2, 20);
                Pan2.ar(
                    Gendy1.ar(
                        6.rand, 6.rand, 1.0.rand, 1.0.rand, freq, freq, 1.0.rand, 1.0.rand, numcps,
                        SinOsc.kr(exprand(0.02, 0.2), 0, numcps/2, numcps/2), 0.5 / (n.sqrt)
                    ),
                    1.0.rand2
                )
            })
        }.play
    )

// 另一个流量时刻
    (
        {
            var n;
            n = 10;

            Resonz.ar(
                Mix.fill(n, {
                    var freq, numcps;

                    freq = rrand(50, 560.3);
                    numcps = rrand(2, 20);
                    Pan2.ar(Gendy1.ar(6.rand, 6.rand, 1.0.rand, 1.0.rand, freq, freq, 1.0.rand, 1.0.rand, numcps,
                        SinOsc.kr(exprand(0.02, 0.2), 0, numcps/2, numcps/2), 0.5/(n.sqrt)), 1.0.rand2)
                }),
                MouseX.kr(100, 2000),
                MouseY.kr(0.01, 1.0)
            )
        }.play
    )

    (
        {
            var n = 15;


            Resonz.ar(
                Mix.fill(n, {
                    var freq, numcps;

                    freq = rrand(330, 460.3);
                    numcps = rrand(2, 20);
                    Pan2.ar(
                        Gendy1.ar(
                            6.rand, 6.rand, 1.0.rand, 1.0.rand, freq,
                            MouseX.kr(freq, 2*freq), 1.0.rand, 1.0.rand, numcps,
                            SinOsc.kr(exprand(0.02, 0.2), 0, numcps/2, numcps/2), 0.5/(n.sqrt)
                        ),
                        1.0.rand2
                    )
                }),
                MouseX.kr(100, 2000), MouseY.kr(0.01, 1.0)
            )

        }.play;
    )
