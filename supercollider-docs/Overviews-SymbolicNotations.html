逻辑或

当函数作为第二个操作数时，这些运算符会执行短路求值（即，仅当函数的结果会影响运算结果时才执行该函数）。建议这样做以提高速度。

使用 and: 和 or: 时，第二参数函数会被内联。如果使用 && 或 ||，则不会进行内联，性能会较慢。

a = 1;

a == 1 and: { "second condition".postln; [true, false].choose }
second condition
true

a == 1 or: { "second condition".postln; [true, false].choose }
true

a != 1 and: { "second condition".postln; [true, false].choose }
false

a != 1 or: { "second condition".postln; [true, false].choose }
second condition
true

在这种情况下，如果 a 为 nil，第二个条件将导致错误，因为 nil 无法理解加法。a.notNil 是一种保护措施，以确保第二个条件有意义。

a = nil;
a.notNil and: { "second condition".postln; (a = a+1) < 5 }
false

a = 10;
a.notNil and: { "second condition".postln; (a = a+1) < 5 }
second condition
false

IOStream 运算符

stream << object

将对象表示为字符串并添加到流中。常见用法是与 Post 类一起使用，将输出写入 post 窗口。

条件执行运算符

object ? object

nil 检查（无 .value）

object ?? function

nil 检查（.value，函数被内联）如果对象为 nil，则使用第二个表达式的值；否则，将使用第一个对象。

a = [nil, 5];

10.do({ (a.choose ? 20.rand).postln });
10.do({ (a.choose ?? { 20.rand }).postln });

通常推荐使用 ?? { }。? 总是会求值第二个表达式，即使其值不会被使用。?? 则有条件地求值函数（仅在需要时）。如果函数未定义任何变量，函数将被内联以提高速度。

在对象的缺失需要创建一个新对象时尤其有用。在此示例中，如果对象已经传入，则绝不能创建新的 Slider，这一点至关重要。

f = { |slider, parent|
    slider = slider ?? { Slider.new(parent, Rect(0, 0, 100, 20)) };
    slider.value_(0);
};

如果函数内的第一行改为

slider = slider ? Slider.new(parent, Rect(0, 0, 100, 20));

即使不需要或未使用，也会创建一个新的滑块。

object !? function

如果对象不为 nil，则执行函数。

a = [10, nil].choose;
a !? { "ran func".postln };
// 等价于：
if (a.notNil) { "ran func".postln };

当某个操作要求变量不为空时使用。

f = { |a| a + 5 };
f.value
// 错误：nil 不理解 +

f = { |a| a !? { a+5 } };
f.value
nil // 无错误
f.value(2)
7

杂项运算符

object ! number

与 object.dup(number) 相同

15 ! 5
[ 15, 15, 15, 15, 15 ]

如果对象是一个函数，其行为类似于 Array.fill(number, function)。

{ 10.rand } ! 5
[ 8, 9, 3, 8, 0 ]
object -> object

创建一个 Association，用于字典。

expression <! expression

第二个表达式的旁路值。此运算符对两个表达式求值，并返回第一个的值。

a = 0;
0

// a 被递增了两次，但返回值（1）
// 来自第一次递增（0 + 1）
(a = a + 1) <! (a = a + 1)
1

a    // a 的值反映两次增量
2
function <> function

函数复合运算符。该运算符返回一个新函数，它先求值第二个函数，并将结果传递给第一个函数。

f = { |a| a * 5 } <> {|a| a + 2 };
f.(10);
60                  // == (10+2) * 5

作为参数的数组会沿链传递：

f.([10, 75, 512]);
[ 60, 385, 2570 ]   // == ([10, 75, 512]+2) * 5

类和实例变量访问

在类定义内部（参见 编写类）：

{
    classvar <a,    // 定义一个带有 getter 方法的类变量（用于外部访问）
             >b,    // 定义一个带有 setter 方法的类变量
             <>c;   // 定义一个同时带有 getter 和 setter 方法的类变量

    var      <a,    // 定义一个带有 getter 方法的实例变量（用于外部访问）
             >b,    // 定义一个带有 setter 方法的实例变量
             <>c;   // 定义一个同时具有 getter 和 setter 方法的实例变量

    // 方法放在这里 ...
}

这些记法不适用于在方法内定义的变量。

^someExpression

在方法定义中：将表达式的值返回给调用者

instVar_ { }

为实例变量定义一个 setter

myObject.instVar = x;

调用 setter：(myObject.instVar_(x); x)

数组序列与索引

(a..b)

生成一个由从 a 到 b 的连续整数组成的数组

(a, b..c)

例如：(1, 3..9) 生成 [1, 3, 5, 7, 9]

(..b)

生成一个从 0 到 b 的数组

(a..)

不合法（未给出端点）

a[i..j]

与 a.copySeries(i, j) 相同（参见 ArrayedCollection: -copySeries）

a[i, j..k]

例如：a[1, 3..9] 获取数组元素 1、3、5、7、9

a[..j]

与 a.copySeries(0, j) 相同

a[j..]

与 a.copySeries(i, a.size-1) 相同（这没问题——Array 是有限的）

~

访问环境变量

~abc

编译为 \abc.envirGet

~abc = value

编译为 \abc.envirPut(value)
