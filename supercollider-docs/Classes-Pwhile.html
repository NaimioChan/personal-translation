Pwhile

当条件成立时，重复嵌入流

FuncFilterPattern : FilterPattern : Pattern : AbstractFunction : Object

说明

反复 嵌入 一个 Stream，只要 func 的结果为 true。

类方法

Pwhile.new(func, pattern)

来自父类：FuncFilterPattern

参数：

func

流函数。在事件流中接收当前 Event 作为参数。

pattern

一个 Pattern。

实例方法

未文档化的实例方法

.embedInStream(event)

示例

(
z = true;
a = Pwhile({ z }, Pseq(#[1, 2, 3]));
x = a.asStream;
);

7.do({ x.next.postln }); // 当 z == true 时，值被嵌入
z = false; // 将 z 设为 false
x.next; // 流的其余部分仍被嵌入
x.next;
x.next; // 但之后它就没有继续了。
x.next;
x.next;
x.next;
