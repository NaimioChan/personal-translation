1个、唯一的1个UGen

最简单的合成过程就是只运行一个 UGen。例如，

{ Saw.ar(500, 0.1) }.scope;

または

{ Formlet.ar(Saw.ar(22), 400, 0.01, 0.11, 0.022) }.scope

です。

SuperCollider 针对各种 UGen 的帮助文档大多会给出这样的示例。

////////////////////////////////////////////////////////////////////////////////////////////////////

マルチ・チャンネルへの拡張

通过向任意参数（控制）槽提供数组，可以将单个 UGen 扩展为 2 个声道。

{ Saw.ar([500, 933], 0.1) }.scope;

同じことを他の（長い）書き方で書くと次の様になります。

{ [ Saw.ar(500, 0.1), Saw.ar(933, 0.1)] }.scope;

////////////////////////////////////////////////////////////////////////////////////////////////////

UnaryOpUGenの探求

通过向 UGen 发送消息，可以生成许多合成过程。在 SuperCollider 帮助系统的 UnaryOps 文件夹中，有许多关于单目运算的帮助文件。

////////////////////////////////////////////////////////////////////////////////////////////////////

これを

{ SinOsc.ar(500, 0, 0.5) }.scope;

次のものと比較してみて下さい。

{ SinOsc.ar(500, 0, 0.5).distort }.scope;

.distort 消息（发送给 UGen 的消息）是一元运算。你会听到 .distort 消息正在调制 SinOsc UGen 的输出。这会由此产生更多的分音。

////////////////////////////////////////////////////////////////////////////////////////////////////

質問：.distortメッセージはどこから来ているのでしょうか？

答案：它定义在 AbstractFunction 中。UGen 类是 AbstractFunction 的子类。原则上，定义在 AbstractFunction 中的所有方法都应该适用于 UGen。

以下のものを

{ SinOsc.ar(500, 0, 0.5) }.scope;

次のものと比較してみて下さい。

// .cubedは単項演算の一つ
{ SinOsc.ar(500, 0, 0.5).cubed }.scope;

////////////////////////////////////////////////////////////////////////////////////////////////////
