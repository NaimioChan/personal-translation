3.7 版本新特性

SC 3.7 新闻摘要

另请参见：3.6 版本新特性、3.5 版本新特性、调试技巧

除了此处描述的新功能和变更之外，还有许多缺陷修复和有趣的改进，完整列表可在 CHANGELOG.md 中找到。

SuperCollider IDE

  • Recording、scope 和服务器检查的菜单项
  • 从 sclang 修改和查询 IDE 文档
  • 对 Atom 文本编辑器的支持
  • 带自动补全的集成帮助
  • 自动保存功能

SuperCollider 语言

  • 改进了 Quark 系统，并新增了许多有趣的新 Quark。
  • TempoClock: -beats 可以被设置。
  • 键值对接口，请参阅 Key Value Pairs
  • 重构了 JITLib，参见 3.7 中的 JITLib 变更（特别是动态通道扩展）。
  • QuartzComposerView

外部接口

有一套全新的 HID（人机接口设备）实现：参见 Working with HID，它可跨平台工作（目前支持 Linux 和 macOS）。这使 GeneralHID 接口被弃用。此外，LID 接口也已更新，以匹配新 HID 实现的 API。

新方法与类

  • Collection: -collectCopy、Collection: -collectInPlace
  • SimpleNumber: -lcm 和 SimpleNumber: -gcd 对负值和零具有一致的解读。
  • Dictionary: -embedInStream 可以在字典内部自定义。
  • Server: *remote 创建一个新的 Server 实例，对应运行在单独机器上的服务器应用程序。

已弃用的类和方法

  • TuningInfo
  • ScaleInfo
  • Proutine（请改用 Prout）
  • 文档样式 api - 设置 postColor 背景等
  • Date-bootTime
  • Platform-getMouseCoords（请改用 GUI.cursorPosition）

SuperCollider 服务器

除 UDP 外，现在还支持 TCP 协议。

当把 Synth 的控件映射到总线时，其通道数被限制为控制通道的数量，从而避免映射的“溢出”。

新 UGen 列表

  • NodeID（返回当前节点 id 的 UGen）
  • Dconst

改进或修正的行为

  • LinXFade2（正确的淡化方向）
  • LFPulse（当 width = 0.5 时，返回的 0 与 1 数量完全相等）
  • TrigControl 现在与 synth 顺序无关，与 Control 类似。
  • TRand、TExpRand、TIRand（可以在音频速率下运行）
  • Env: *new 接受新的 step2 形状，该形状会在形状末尾步进到一个值
  • UGen: -curvelin 现在是 UGen: -lincurve 的逆运算
  • Server: -record 能正确关闭短文件
  • 在需求 UGen 的组合中：PV_Copy 的实例会在必要时自动添加以进行并行处理

更多运算符在 sclang 和 scserver 上以统一方式工作

以下运算符已作为 UGen 添加，其工作方式与 sclang 中相同：

一元运算符

rand、rand2、linrand、bilinrand、sum3rand、coin

二元运算符

lcm、gcd、rrand、exprand

参见 Operators

已知问题

尽管已有很大改进，且 3.6 中的许多 bug 已被修复，但仍有许多已知问题。完整列表见：https://github.com/supercollider/supercollider/issues/

请随时将您发现的新问题添加到 issue tracker，或在 mailing list 上提及它们
