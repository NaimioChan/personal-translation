MultiLevelIdentityDictionary

字典树

Collection : Object

参见：IdentityDictionary

子类：LibraryBase

说明

一个 IdentityDictionaries 树。树中的地址通过一系列键来指定。Library 是其最有用的子类。

类方法

未文档化的类方法

实例方法

.at( ... path)

检索一个叶节点，如果未找到则为 nil。

.put( ... path)

将项作为叶节点放置，内部根据需要创建新分支以容纳键列表。

.choose( ... start)

在每一层选择一个分支，沿树向下直到选中一个叶子。通过使用参数 key1, key2 ... keyN，可以从树内的某个地址开始，沿树向下直到选中一个叶子。

.putTree( ... items)

一种以类似于树本身组织方式的语法将对象插入树中的方法。

// 伪代码：
putTree(key1, [
    key2a, item1-2a,
    key2b, item1-2b,
    [
        key3, item1-3
    ] // etc...
]);

.removeAt( ... path)

仅移除由路径定位的项。

.removeEmptyAt( ... path)

移除由路径定位的项。这可能会使该项的父字典变为空。在这种情况下，它将移除父项并继续沿链向上，沿途移除空字典。这较慢但更干净。

示例

// removeAt 与 removeEmptyAt 之间差异的示例

m = MultiLevelIdentityDictionary.new;
m.put(\a, \b, \c, 1);

m.removeAt(\a, \b, \c);
m    // 注意，\a 和 \b 字典保留

m.put(\a, \b, \c, 2);
m.removeEmptyAt(\a, \b, \c);
m    // 现在整个 MultiLevelIdentityDictionary 为空
