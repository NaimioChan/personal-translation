SCImage

图像组件

参见：SCImageFilter、SCImageKernel

说明

SCImage 是 macOS SuperCollider 客户端的图像组件。SCImage 目前是多种模型的包装器：你可以将其用于位图操作、为自定义 UI 嵌入图像，以及进行更高级的图像处理，例如应用滤镜和核，二者均由 CoreImage 框架提供。

SCImage 目前支持读取大多数格式，包括 tiff、bmp、gif、jpeg、png、tga...等等。但写入时仅支持 SCImage.formats 中的格式。

注意： GUI 问题：由于它仅适用于 macOS，请务必在任何 SCImage.call 之前调用 GUI.cocoa

类方法

.new

创建一个新的 SCImage 实例。此处的 multiple 表示多个参数。

参数：

multiple

可以是……

  • 用于创建宽和高均为 size 倍数的空图像的数字

    i = SCImage.new(400);        // 创建一个 400x400 像素的 SCimage。
i.dump;
i.free;

i = SCImage.new(400, 200);    // 创建一个 400x200 像素的 SCimage。
i.dump;
i.free;

  • 用于创建空图像的点，其宽度为 multiple.x，高度为 multiple.y

    i = SCImage.new(400@200);    // 创建一个 400x200 像素的 SCimage。
i.dump;
i.free;

  • 用于从本地文件或 URL（http://、ftp://、file:///）创建图像的字符串

    //    路径字符串
i = SCImage.new("/Library/Desktop Pictures/Ripples Blue.jpg");
[i.width, i.height].postln;
i.plot;
i.free;
//    URL 字符串 - http:// 或 ftp:// - 阻塞直到图像下载完成
i = SCImage.new("http://www.google.com/intl/en_ALL/images/logo.gif");
i.plot;
i.url;
i.free;

.color

创建一个用指定颜色填充的新 SCImage 实例。

i = SCImage.color(400, 200, Color.blue(0.9, 0.1));
i.plot(freeOnClose: true);

参数：

args

多个参数。最后一个参数应为有效的 Color

.open

从位于 path 的本地文件创建一个新的 SCImage 实例。

(
i = SCImage.open("/Library/Desktop Pictures/Ripples Blue.jpg");
i.plot(freeOnClose: true);
i.url.postln;
)

.openURL

从指定 URL path 处的有效图像创建一个新的 SCImage 实例。

i = SCImage.openURL("file:///Library/Desktop%20Pictures/Ripples%20Blue.jpg");
i.url;
w = i.plot(freeOnClose: true);

.fromImage

从另一个 SCImage 创建一个新的 SCImage 实例。

i = SCImage.new(SCDoc.helpSourceDir +/+ "images/vduck2.jpg");
j = SCImage.fromImage(i);
i.dump;
j.dump;
[i, j].do(_.plot);
[i, j].do(_.free);

.fromWindow

从 SCWindow 的一部分创建新的 SCImage。这可用于捕获窗口或特定的 SCView。

// WINDOW 示例：
// 首先创建一个窗口并在其中绘制
(
    w = SCWindow.new;
    w.front; // 注释掉此行以复制离屏窗口
    w.view.background_(Color.white);
    w.drawFunc = {
        SCPen.translate(100, 100);
        10.do{
            // 设置颜色
            SCPen.color = Color.blue(rrand(0.0, 1), rrand(0.0, 0.5));
            SCPen.addWedge((100.rand)@(100.rand), rrand(10, 100), 2pi.rand, 2pi.rand);
            SCPen.perform([\stroke, \fill].choose);
        }
    };
    w.refresh;
)

// 然后抓取窗口
(
    i = SCImage.fromWindow(w);
    w.close;
    i.plot(freeOnClose: true);
)

// VIEW Capture 示例：
// 首先创建一个窗口并在其中添加一些视图
(
    w = SCWindow.new.front;
    b = [10, 80].asSpec;
    c = SCNumberBox(w, Rect(20, 20, 60, 40));
    a = SCSlider(w, Rect(20, 80, 100, 40))
        .focusColor_(Color.red(alpha: 0.2))
        .action_({
            c.value_(b.map(a.value).round(0.01))
    // 对浮点数取整，使其适合 SCNumberBox
            });
)

// 然后抓取窗口
(
    i = SCImage.fromWindow(w, a.bounds);
    w.close;
    i.plot(freeOnClose: true);
)

参数：

window

SCWindow 对象。

rect

可选。要在 SCWindow 内捕获的受限矩形区域。默认情况下，它是窗口大小。

commons / 通用属性

.width

返回或设置接收者的宽度

.height

返回或设置接收者的高度

设置接收者的大小

返回接收者的边界。

释放接收者。如果你想自己管理和回收资源，此方法很有用。否则你不需要调用此方法，因为每个对象都会被自动垃圾回收。

.scalesWhenResized

用于告知或设置接收者是否应在执行调整大小操作时更新其位图表示以进行缩放的标志

(
    i = SCImage.new("/Library/Desktop Pictures/Ripples Blue.jpg");
    i.bounds.postln; // 获取维度
    w = i.plot;
)

// 改变图像的大小
(
    i.scalesWhenResized_(true);
    i.setSize(400, 400 / (i.width / i.height));
    a = i.plot;
)
(
a.close; w.close; i.free;
)

.url

返回或设置接收者的 url。仅当在创建时提供了 url 时才返回，否则返回 nil。设置可用于不同目的，但请尽量提供一个有效的 url，因为它用于将镜像归档为对象。

i = SCImage.new("http://www.google.com/intl/en_ALL/images/logo.gif");
i.url;
i.plot;
i.free;

.accelerated

若为 true，接收者当前使用 CoreImage 模型，可能将其数据缓存在 GPU 上；若为 false，则使用位图模型。设置此项可切换表示方式。

警告： 除非你完全清楚自己在做什么，否则绝不应直接使用此方法。因为 SCImage 会在内部切换并自行管理各表示之间的同步。

.interpolation

获取或设置渲染图像时使用的插值级别——当 SCImage 被加速时，它没有效果。有关有效值范围，请参阅 *interpolations。

(
i = SCImage.new(SCDoc.helpSourceDir +/+ "images/vduck2.jpg");
w = i.plot;
i.interpolation;            // 获取图像的当前插值模式
)

(
i.interpolation = 'none';        // 尝试不同的插值模式
w.refresh;
)

(
i.interpolation = 'low';
w.refresh;
)

(
i.interpolation = 1;            // 与 'low' 相同
w.refresh;
)

(
i.interpolation = 'high';
w.refresh;
)

(
i.interpolation = 'default';
w.refresh;
)

(
i.accelerated_(true);
i.interpolation = 'none'; // 在 coreimage 加速图像上不起作用
w.refresh;
)

i.free;

用于指示 SCWindow 在关闭时是否应释放 SCImage 的标志。

将接收者设为当前图形上下文。因此你可以在其中使用 SCPen 进行绘制。

恢复图形上下文状态。接收者不再是当前图形上下文。

(

    j.lockFocus;

        SCPen.translate(100, 100);

            SCPen.color = Color.green(rrand(0.0, 1), rrand(0.0, 0.5));

                (100.rand)@(100.rand),
                rrand(10, 50),
                rrand(51, 100),
                2pi.rand,
                2pi.rand
            );
            SCPen.perform([\stroke, \fill].choose);
        };

    j.unlockFocus;
)

j.plot;
j.write("~/Desktop/my_drawing.png"); // 写入图像
j.free;

.drawStringAtPoint

在 SCImage 中*正确*地渲染 String :) // to fix to have a compliant interface

(
    var width, height, tgHeight, ratio, str, font, color, strb, targetWidth = 400, shadowColor, run = true;
    shadowColor = Color.black;

    color = Color.gray(0.8);
    str = "I Love Pixels";
    font = Font("Monaco", 10);
    strb = str.bounds(font);
    width = strb.width;
    height = strb.height;
    ratio = height / width;
    i = SCImage(width@(height));
    i.draw({ |bb|
        SCPen.smoothing_(false);
        i.drawStringAtPoint(str, 0@0, font, color);
    });
    i.interpolation_(\none);
    tgHeight = targetWidth * ratio;
    w = SCWindow.new("", Rect(400, 400, 450, 150)).drawFunc_({
        SCPen.setShadow(2@2, 0.4, color: Color.red);
        i.drawInRect(Rect(5, 5, targetWidth, tgHeight));
    });

    w.view.background_(Color.white);
    w.onClose_({ run = false; i.free });
    w.front;
)

.drawAtPoint

在当前图形上下文中渲染图像或其一部分。

(
    var operation = 'sourceOver', fraction = 1.0, i, w;

    i = SCImage.new(
    //    "http://supercollider.sourceforge.net/theme/sc01/icon.supercollider.gif"
    //    SCDoc.helpSourceDir +/+ "images/duck_alpha.png"
        SCDoc.helpSourceDir +/+ "images/Swamp.png"
    );

    w = SCWindow.new("SCImage", Rect(120, 400, 360, 180)).front;

    SCSlider.new(w, Rect(10, 150, 150, 16))
        .value_(1.0)
        .action_({ |sl|
            fraction = sl.value;
            w.refresh;
        });

    SCPopUpMenu.new(w, Rect(170, 150, 100, 16))
        .items_(SCImage.compositingOperations.collect({ |i| i.asString }))
        .value_(2)
        .action_({ |pm|
            operation = SCImage.compositingOperations.at(pm.value);
            w.refresh;
        });

    w.onClose_({ i.free }); // 窗口关闭时释放图像

    w.drawFunc_({

        i.drawAtPoint(10@10, nil, operation, fraction);

    });
)

实例方法 / 访问和设置像素

.setPixel

填充位于 x @ y 的像素。

i = SCImage.color(60, 60, Color.blue(0.1, 0.1));
w = i.plot;
i.setPixel([255, 0, 0, 255].asRGBA, 0, 0); // 设置红色
w.refresh;
("pixel at 0 @ 0:"+i.getPixel(0, 0).rgbaArray).postln;
i.free;

参数：

rgbaInteger

一个 32 位 Integer，包含以 8 位 RGBA 打包的颜色信息

.getPixel

以 RGBA 整数形式获取 x @ y 处的像素值

// 一个关于如何用 SCImage 操作像素的简单示例
b = Int32Array[
    Integer.fromRGBA(255, 0, 0, 255), // red
    Integer.fromRGBA(0, 255, 0, 255), // green
    Integer.fromRGBA(0, 0, 255, 255), // blue
    Integer.fromRGBA(255, 0, 255, 255) // purple
];

b[0].red; // 255 参见 Integer.red
b[0].green; // 0 参见 Integer.green
b[0].blue; // 0 参见 Integer.blue
b[0].alpha; // 255 见 Integer.alpha

a = SCImage.new(b.size@1).pixels_(b).interpolation_(\none);
a.plot;


// 设置 + 获取
a.setPixel([255, 0, 255, 128].asRGBA /* 从 0-255 整数 rgba 值创建一个 Integer*/, 0, 0).plot;
p = a.getPixel(0, 0);

p.red; // 255
p.green; // 0
p.blue; // 255
p.alpha; // 128

// 现在看另一个重要的例子
a.setPixel([255, 0, 255, 0].asRGBA, 1, 0).plot; // 清除颜色 -> alpha 为 0
p = a.getPixel(1, 0);

p.red; // 你期望得到 255，但得到的是 0 ？？？原因 = SCImage 内部使用的是预乘颜色分量值
// 意味着所有 Red、Green 和 Blue 分量都已预乘 alpha
// 如果 alpha 为 0，则所有分量返回 0。

p.green; // 0
p.blue; // 0
p.alpha; // 0

p = a.getColor(1, 0); // 更显式 —— 但这里也一样

.setColor

用指定的 color 填充位于 x @ y 的像素。

.getColor

以 Color 形式获取 x @ y 处的像素值。

.pixels

获取或设置接收者的所有像素。

注意： 注意：返回的数组是一个大小为 receiver.width * receiver.height 的 Int32Array，其中包含所有像素值（32 位整数）。

参数：

array

一个大小为 receiver.width * receiver.height 的 Int32Array，包含所有像素值作为 32bit Integer

.loadPixels

将接收者的所有像素加载到一个数组中。如果你打算频繁获取像素数据，调用此函数比调用 -pixels 更好也更快（因为它不会每次都分配新数组！）

// 一次执行一行
i = SCImage.new(
    // "http://supercollider.sourceforge.net/theme/sc01/icon.supercollider.gif"
    SCDoc.helpSourceDir +/+ "images/icon.supercollider.png"
);

// 首先获取像素
p = i.pixels;

// 做一些修改 - 这里进行反转
i.invert;

// 直接在我的数组中重新加载——不需要再次调用 i.pixels
i.loadPixels(p);
i.free;
p;

参数：

array

将被填充的数组。应为大小为 receiver.width * receiver.height 的 Int32Array。

region

目标矩形区域。（默认 nil，表示完整尺寸）

start

数组的起始索引。

.setPixels

设置接收者特定部分中的像素。

(
    i = SCImage.new(20@20);
    i.pixels_(
        Int32Array.fill(i.width * i.height, {
            Integer.fromRGBA(255.rand, 127.rand, 255.rand, 255)
        })
    );
    // i.interpolation_(\none); // 取消注释以查看差异
    w = i.plot(freeOnClose: true);
    i.pixels.postln;
)

(
    i = SCImage.color(50@50, Color.white);
    i.setPixels(
        Int32Array.fill(20*20, { Integer.fromRGBA(255.rand, 127.rand, 255.rand, 255) }),
        Rect(10, 10, 20, 20)
    );
    i.interpolation_(\none); // 取消注释以查看差异
    w = i.plot(freeOnClose: true);
    i.pixels.postln;
)

参数：

array

一个大小为 rect.width * rect.height 的 Int32Array，包含所有像素值作为 32 位整数

rect

一个矩形，定义接收者中要更新的部分。默认情况下 rect 为 nil，表示完整图像大小。

start

数组起始索引。

SCImageFilter 支持的实例方法 / 属性

更多信息请参见 SCImageFilter

.applyFilters

对图像应用一个 SCImageFilter 数组。这应视为原地操作，即操作后 SCImage 会被改变。

// ******** 内置 CoreImage 生成器 ********
// 生成器不是滤波器，它们实际上会创建图像，但不需要输入图像
// 你只需创建一个新尺寸的图像
// ** 简单随机滤波器 **
(
f = SCImageFilter.new(\CIRandomGenerator);
a = SCImage.new(500@500);
a.applyFilters(f);
w = a.plot(freeOnClose: true, background: Color.black);
a.bounds.postln;
)

// ** StarShine 示例 **
(
var width = 500, height = 500, centerVector;

centerVector = [width*0.5, height*0.5];
a = SCImage.new(500@500);
f = SCImageFilter.new(\CIStarShineGenerator);

f.center_(centerVector);
f.radius_(width*0.05);
f.color_(Color.blue);
f.crossWidth_(2.0);
f.crossAngle_(0.0);
f.crossOpacity_(-4.0);

a.applyFilters(f);
w = a.plot(freeOnClose: true, background: Color.gray); // 更改背景以查看
)


// ** Starshine + Pixellate + ZoomBlur **
(
var width = 500, height = 500, centerVector;

centerVector = [width*0.5, height*0.5];
a = SCImage.new(500@500);

f = SCImageFilter.new(\CIStarShineGenerator);
g = SCImageFilter.new(\CIPixellate);
h = SCImageFilter.new(\CIZoomBlur);

f.center_(centerVector);
f.radius_(width*0.05);
f.color_(Color.blue);
f.crossWidth_(2.0);
f.crossAngle_(0.0);
f.crossOpacity_(-4.0);
g.center_(centerVector);
h.center_(centerVector);
h.amount_(50);

a.applyFilters([f, g, h]);
w = a.plot(freeOnClose: true, background: Color.black);
)

参数：

filters

要应用的 SCImageFilter 或 SCImageFilter 数组

crop

最终使用的裁剪区域。这可能是为了扩展边界所需要的，因为某些 SCImageFilter / CoreImageFilters 需要设置更宽的区域（才能被正确应用），或者可能会创建一个巨大的图像。将 crop 设为 nil 则不设置裁剪区域。如果经过滤的 SCImage 当前最大尺寸为 4096 / 4096，任何更大的尺寸都将被裁剪。默认情况下，crop 被约束在接收者边界内。

region

将滤波器约束到 SCImage 中特定区域的选项。

.filteredWith

返回一个新的 SCImage，即用 SCImageFilter 数组过滤后的接收者副本。参数与 -applyFilters 相同（region 除外）。

注意： 注意：你有责任释放新创建的 SCImage！！！

.filters

filters 是保存附加到接收者的 SCImageFilter 数组的实例变量。这便于在外部应用滤镜并更改 SCImageFilter 的属性。参见 -addFilter、-removeFilter

参见 SCImageFilter 了解如何使用 filters 数组的示例。

.addFilter

你还可以将滤波器附加到接收者上，以实现实时变化的操作。在这种情况下，接收者会在每次渲染前创建一个缓存以维护其先前的状态，从而允许你使用滤波器而无需就地应用它们。该缓存由接收者直接管理。你可以向接收者添加多个滤波器，数组中的第一个滤波器在渲染链中最先应用。

参见 SCImageFilter 了解如何使用 addFilter 的示例。

参数：

filter

在渲染图像之前应用的 SCImageFilter

.removeFilter

参见 SCImageFilter 中关于如何使用 removeFilter 的示例。

参数：

filter

要从渲染链中移除的 SCImageFilter。

.flatten

如果 -filters 的大小不为零，此方法将原地应用所有这些滤镜。如果图像是加速的，此方法会强制接收者采用位图表示。

3

4

5

水平平铺、垂直平铺

6

固定到右侧，垂直平铺

7

固定到左侧，固定到底部

8

水平平铺，固定到底部

9

固定到右侧，固定到底部

10

fit

11

center，center（缩放）

12

居中，固定到顶部

13

居中，固定到底部

14

固定为左、居中

15
