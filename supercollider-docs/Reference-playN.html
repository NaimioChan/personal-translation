playN

将音频分配到多个非相邻通道

另请参阅：Monitor、Bus、NodeProxy、Ndef、ProxySpace

playN

playN 是 Monitor 和 NodeProxy 的多声道播放方法（另请参见：ProxySpace、Ndef），支持在非相邻声道上播放代理输出；有点类似于分离器/线路混音器。

// 示例

s.boot;

p = ProxySpace.push;
s.scope(8);

    // 一个 3 通道测试声音
~test3 = { SinOsc.ar([2, 3, 5] * 100) * 0.2 };

    // 比较：从 3 个相邻声道播放
~test3.play(3);
~test3.play(6);

~test3.stop;
~test3.play;    // play 会记住旧的（系列）输出设置；


    // outs
~test3.playN([2, 4,7]) // 将 playN 输出到 3 个非相邻声道

    // 设置输出、振幅和音量：
(
~test3.playN(
    outs: [2,3,5],
    amps: [0.5, 0.25, 0.125],
    vol: 1
);
)
~test3.vol_(2);

~test3.stop;
~test3.playN;    // 记住最后的状态。

        // 如果使用了 playN，可以在播放时设置 outs。
        // 注意：这在 .play 方法下不能可靠工作！
~test3.monitor.outs_([3,2,1]);

        // 在播放时设置振幅。
        // 注意：这不适用于 play 方法！
~test3.monitor.amps_(1/[1, 2, 3]).vol_(1);
~test3.playN;
~test3.monitor.outs_([2, 4, 7]);


    // 也可以将一个通道扩展到多个通道，并给定幅度：
(
~test3.playN(
    outs: [1, 3, [5,6,7]],
    amps: [0.5, 0.25, [0.125,0.25, 0.5]],
    vol: 2
);
)

~test3.stop;
~test3.playN;

        // 关闭时进行更改：
~test3.stop;
~test3.monitor.outs_([2, 4, [5,6,3]]);
~test3.monitor.amps_(1/[1, 2, [3,2,1]]);
~test3.playN;

        // 编辑这些参数最舒适的方式是使用文本文件：
~test3.playNDialog;


    // 输出映射可以在使用 playN 之前准备好：
~test3.clear;

~test3 = { SinOsc.ar([2, 3, 5] * 100) * 0.2 };

~test3.vol_(0.5);        // vol 已经可以设置

    // 输出和振幅需要先创建监视器；
~test3.initMonitor;

~test3.monitor.outs_([3, 5, 6]);

~test3.monitor.amps_([1, 2, 3]);

~test3.playN;

~test3.end;
~test3.clear;

p.clean;
p.pop;
