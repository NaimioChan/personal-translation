Error

所有 Error 的父类

Exception : Object

子类：MethodError

说明

Error 及其子类将 SuperCollider 程序中可能出现的不同类型的错误划分为不同的类，以便能够以不同方式向用户报告。

在任何必须向用户报告错误且必须停止执行的地方，都必须创建并抛出一个错误对象。

(
var file, path = "betcha-this-file-doesnt-exist.txt";
if((file = File(path, "r")).isOpen) {
    "File is % bytes long.\n".postf(file.length);
    file.close;
} {
    Error("File % could not be opened.".format(path)).throw;
};
)

为了向后兼容，.die() 会为你创建错误。

"Keyboard not found. Press F1 to Resume.".die;

抛出错误对象使调用者有机会捕获该错误，并可能从中恢复。有关此内容的更多信息，请参见 Exception 帮助文件。

错误层次结构

主库中存在以下错误类。

  • Error
  • DeprecatedError：此方法已不再支持。
  • MethodError：在方法内部发生的一般性错误。
  • DoesNotUnderstandError：接收者不理解该方法名。
  • BinaryOpFailureError：二元运算符无法与这些操作数类一起工作。
  • ImmutableError：试图修改不可变对象。
  • MustBeBooleanError：测试（在 if 或 while 中）返回了非布尔值。
  • NotYetImplementedError：方法名存在，但尚未实现。
  • OutOfContextReturnError：由 ^ 执行的方法返回发生在方法之外。
  • PrimitiveFailedError：在 primitive 内部发生了错误。
  • ShouldNotImplementError：你在一个本不应实现该方法的类上调用了该方法。
  • SubclassResponsibilityError：你在抽象类上调用了某个方法。
