Frame

栈帧

Object

说明

帧用于包含活动函数的参数、变量和其他信息。

没有实例变量或方法。

由于 Frame 通常创建在栈上，允许访问它们太危险了。可能会产生悬空指针。

帧实例对用户不可访问。

对于错误处理例程，可以将 Frame 中的相关信息转移到 DebugFrame 对象中，从而可以安全地检查。

    this.getBackTrace.inspect
