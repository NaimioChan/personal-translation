MIDIFuncSrcMessageMatcherNV

根据消息来源将传入的 MIDI 消息匹配到响应函数

MIDIFuncSrcMessageMatcher : AbstractMessageMatcher : Object

参见：AbstractMessageMatcher、MIDIFuncSrcMessageMatcher、MIDIFuncChanMessageMatcher、MIDIFuncChanArrayMessageMatcher、MIDIFuncBothMessageMatcher、MIDIFuncBothCAMessageMatcher

说明

它由 MIDIMessageDispatcherNV 使用，以利用消息来源将传入的 MIDI 消息匹配到 MIDIFunc 或 MIDIdef 的实例。此类是私有的，通常用户不需要直接访问其实例。

类方法

实例方法

.value(num, chan, testSrc)

检查消息是否匹配，若匹配则求值 func。

参数：

num

MIDI 消息的消息编号（例如音符编号等），为一个 Integer。注意这应在 0-127 的范围内。

chan

MIDI 消息的通道号，为 Integer 类型。注意其范围应为 0-15。

testSrc

MIDI 消息来源的 UID，为 Integer 类型。
