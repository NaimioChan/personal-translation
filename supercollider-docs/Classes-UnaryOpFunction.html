UnaryOpFunction

表示对函数的单目操作

AbstractFunction : Object

另请参见：UnaryOpStream、Punop、BinaryOpFunction、NAryOpFunction、Operators

子类：UnaryOpFunctionProxy

说明

对函数而不是数字进行操作时，得到的结果不是计算的结果，而是表示该计算的结构。

类方法

未文档化的类方法

示例

a = 2.sqrt; // 结果是二的平方根（近似浮点数）。
a = { b }.sqrt; // 结果是一个 UnaryOpFunction
b = 2;
a.value; // 现在它被求值，并计算出了结果
b = 9;
a.value; // 再次，使用不同的值。
