LorenzL

Lorenz 混沌生成器

ChaosGen : UGen : AbstractFunction : Object

说明

爱德华·N·洛伦兹在研究大气数学模型时发现的一种奇异吸引子。该系统由三个常微分方程组成：

    x' = s * (y - x)
    y' = x * (r - z) - y
    z' = x * y - b * z

时间步长 h 决定 ODE 的求值速率。较高的值会提高速率，但会导致更多的不稳定性。安全的选择是默认值 0.05。

实例方法

示例

// 改变频率
{ LorenzL.ar(MouseX.kr(20, SampleRate.ir)) * 0.3 }.play(s);
// 随机调制参数
(
{ LorenzL.ar(
    SampleRate.ir,
    LFNoise0.kr(1, 2, 10),
    LFNoise0.kr(1, 20, 38),
    LFNoise0.kr(1, 1.5, 2)
) * 0.2 }.play(s);
)
// 作为频率控制
{ SinOsc.ar(Lag.ar(LorenzL.ar(MouseX.kr(1, 200)), 3e-3)*800+900)*0.4 }.play(s);
