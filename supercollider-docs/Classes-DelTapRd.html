DelTapRd

从 DelTapWr UGen 中取出延迟线

UGen : AbstractFunction : Object

另请参阅：DelTapWr

说明

从 DelTapWr UGen 中抽取延迟线。

注意： 如果你同时运行 DelTapRd.ar 和 DelTapWr.ar，请记住它们以等于服务器块大小的块进行读写。如果延迟时间大于缓冲区大小减去一个块，则写入头和读取头可能会以非预期的方式相互干扰。如果发生这种情况，请使用稍大一些的缓冲区。

类方法

DelTapRd.ar(buffer, phase, delTime, interp: 1, mul: 1, add: 0)

DelTapRd.kr(buffer, phase, delTime, interp: 1, mul: 1, add: 0)

参数：

buffer

DelTapWr 已写入信号的缓冲区。最大延迟时间取决于缓冲区大小。

phase

DelTapWr UGen 的当前相位。这是 DelTapWr 的输出。

delTime

延迟时间，单位为秒。

interp

要使用的插值类型。1 表示无插值，2 表示线性插值，4 表示三次插值。（数字一、二和四对应计算每种插值类型所需的连续采样数。）此参数的任何其他值都会静默地默认为无插值。

mul

add
