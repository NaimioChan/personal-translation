EZRanger

一个包装类，包含标签、范围滑块和数字框

另请参阅：EZGui、StaticText、RangeSlider、NumberBox

说明

EZRanger 是一个包装类，它创建一个（可选的） StaticText，以及一个 RangeSlider 和一个 NumberBox。如果父级为 nil，那么 EZRanger 将创建自己的窗口。更多选项参见 EZGui。

滚动与方向键

EZRanger 的数字框默认可以滚动，使用 ControlSpec 的步长。如果 ControlSpec 的 step 被设为 0 或未设置，则在创建视图时会根据 spec 的 minval 和 maxval 值来推测步进和滚动行为。与常规 NumberBox 的 step 变量不同，controlSpec.step 也是数字框可能的最小增量。默认情况下，按住 shift 键修饰键可以按 controlSpec.step 的 100 倍步进，而按住 ctrl 键则为 controlSpec.step 的 10 倍。由于 alt 键会得到最小步长的 0.1 倍，因此默认被禁用，但可以通过将 numberView.alt_step 设为任意值来改变这一点。相应地，可以根据需要自定义其他修饰键。这也会影响滑块的箭头键。

类方法

.new

参数：

parent

父视图或窗口。如果 parent 为 nil，则 EZRanger 会创建自己的 Window；如果 bounds 是一个 Point，则会将其方便地放置在屏幕上。如果 bounds 是一个 Rect，则该 Rect 决定窗口的 bounds。

bounds

Rect 或 Point 的实例。默认值为 160@20。

label

标签。默认值为 nil。如果为 nil，则不创建 StaticText。

controlSpec

用于缩放该值的 ControlSpec。

action

当值改变时调用的 Function。该函数以 EZRanger 实例作为其参数传入。

initVal

Array 的一个实例 [lo, hi]。如果为 nil，则使用 ControlSpec 的默认值。

initAction

一个 Boolean，指示在设置初始值时是否应调用 action 函数。默认值为 false。

labelWidth

标签的像素宽度。默认值为 60。

numberWidth

数字框的像素宽度。默认值为 45。

unitWidth

单位标签的像素宽度。默认值为 0。如果为 0，则不创建 unitLabel。

labelHeight

默认值为 20；

layout

\vert、\line2 或 \horz。默认是 \horz。

gap

一个 Point。默认情况下，视图会尝试获取其父视图的间距，否则默认为 2@2。设置此项会覆盖上述行为。

margin

一个 Point。这将对 view 的子视图所占用的边界进行内缩。

讨论：

(
w = Window.new.front;
g = EZRanger(w, 400@16, " test  ", \freq, { |v| v.value.postln }, [50, 2000], unitWidth: 30)
)

// 最简单版本，没有父视图，因此创建一个窗口
(
EZRanger(nil, 400@16, " test  ", \freq, { |v| v.value.postln }, [50, 2000])
)

包含的视图可通过 EZRanger 实例变量访问：rangeSlider、hiBox、loBox、unitView、labelView。

实例方法

访问实例变量与类变量

.unitView

单位标签。仅当 unitWidth 被设置为 > 0 时出现。

.controlSpec

一个用于缩放数值的 ControlSpec 实例。

.loBox

lo 值 NumberBox。

.action

设置/获取一个 Function 或 FunctionList，在值变化时求值。第一个参数将是 EZRanger。

.rangeSlider

RangeSlider View

.lo

设置/获取低值。

.hi

设置/获取高值

.hiBox

hi 值 NumberBox。

.round

对数值框中的值进行舍入。

执行某些任务（可选）

.doAction

在当前索引处执行该操作以及全局操作。

.value

获取/设置 lo 和 hi 值。

参数：

vals

Array 的一个实例 [lo, hi]。

.valueAction

在索引值处设置值并执行动作，同时执行全局动作。

参数：

vals

Array 的一个实例 [lo, hi]。

更改外观

.setColors

参数：

stringBackground

一个 Color 的实例。标签和单位视图的 background。

stringColor

Color 的实例。标签视图与单位视图的 stringColor。

sliderColor

一个 Color 实例。滑块 background。

numBackground

Color 的一个实例。number view 的 background。

numStringColor

Color 的一个实例。数字视图的 stringColor。

numNormalColor

Color 的一个实例。数字视图的 normalColor。

numTypingColor

Color 的一个实例。数字视图的 typingColor。

knobColor

一个 Color 的实例。滑块视图的 knobColor。

background

一个 Color 的实例。外层视图的 background。

.font

设置所有视图使用的字体。

参数：

font

Font 的一个实例。

(    // 用于探索合成思路的示例：
p = ProxySpace.push(s.boot);

q = q ? ();
q.freqRange = [200, 2000];
q.ampRange = [0.1, 1];
q.ringRange = [0.1, 10];
q.numRange = [3, 30];

q.soundfunc = { |dens = 5|
    Splay.ar(
        Array.fill(exprand(q.numRange[0], q.numRange[1]).asInteger, {
            Ringz.ar(
                Dust.ar(dens),
                exprand(q.freqRange[0], q.freqRange[1]),
                exprand(q.ringRange[0], q.ringRange[1]),
                exprand(q.ampRange[0], q.ampRange[1])
            )
        })
    ).distort
};
)
~plong.play;

~plong.fadeTime = 3;
~plong = q[\soundfunc];

(
w = Window("cow herd").front;
w.view.decorator_(FlowLayout(w.bounds.copy.moveTo(0, 0)));

Spec.add(\ring, [0.03, 30, \exp]);
Spec.add(\num, [3, 30, \exp, 1]);

EZRanger(w, 390@20, "numRange", \num, { |sl| q.numRange = sl.value }, labelWidth: 65)
    .round_(1);

EZRanger(w, 390@20, "freqRange", \freq, { |sl| q.freqRange = sl.value }, q.freqRange, labelWidth: 65)
    .round_(0.1);
EZRanger(w, 390@20, "ringRange", \ring, { |sl| q.ringRange = sl.value }, q.ringRange, labelWidth: 65)
    .round_(0.0001);
EZRanger(w, 390@20, "ampRange", \amp, { |sl| q.ampRange = sl.value }, q.ampRange, labelWidth: 65)
    .round_(0.0001);
Button(w, 190@20).states_([[\newSound]]).action_({ ~plong = q[\soundfunc] });
)
