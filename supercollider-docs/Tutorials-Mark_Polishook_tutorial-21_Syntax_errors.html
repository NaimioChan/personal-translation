语法与文法

在实际运行程序之前，SuperCollider 会检查代码以确保语法和文法正确。例如，程序中的所有变量名和/或关键字是否拼写正确？语句是否以分号结尾？

如果发现语法或文法错误，SuperCollider 会向 post 窗口写入一条通知。此类消息具有描述性但很简略。

* ERROR: Parse error
   in file 'selected text'
   line 1 char 2 :
  4,
-----------------------------------
* ERROR: Command line parse failed
nil

常见错误

  1. 类名或变量名拼写错误
  2. 变量在声明之前被使用
  3. 缺少括号、方括号或花括号，或者使用在了错误的上下文中
  4. 缺少必需的逗号或分号，或使用不当

////////////////////////////////////////////////////////////////////////////////////////////////////

SuperCollider 编辑菜单中的两个有用命令：

  1. "Go to Line ..." 会将你带到所选的行号。当错误消息指出问题所在的行号时，请使用此功能。
  2. "查找" 用于搜索单词或短语。使用 "查找" 来定位在错误消息中已标识的代码，或替换所有拼写错误的单词的实例。
