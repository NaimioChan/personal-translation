HID 权限

详细说明如何配置计算机以设置访问 HID 的权限

另请参见：Working with HID、HID

在 Linux 上

你需要使用 udev 设置正确的权限，在文件夹 /etc/udev/rules.d/ 中创建一个文件，并将其命名为（例如）90-hidraw-permissions.rules

在文件中，你需要这一行：

KERNEL=="hidraw*", SUBSYSTEM=="hidraw", MODE="0664", GROUP="plugdev"

这将为系统中位于 plugdev 组的用户授予 hidraw 设备的读写权限。

要检查你是否属于该组，请在终端中执行命令 groups。

添加 udev 规则文件后，你可以拔插设备后再访问它。

你可以（以 root 身份）从终端使用以下命令手动更改权限：

sudo chmod 664 /dev/hidraw*
sudo chgrp plugdev /dev/hidraw*

用以下方式检查权限：

"ls /dev/hidraw* -lah".unixCmd;
