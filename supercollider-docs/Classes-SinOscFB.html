SinOscFB

反馈 FM 振荡器

PureUGen : UGen : AbstractFunction : Object

另请参见：SinOsc、FSinOsc、PMOsc

说明

SinOscFB 是一个带相位调制反馈的正弦振荡器；其输出会接回相位输入。基本上，这允许在正弦波和锯齿状波之间进行调制。过度调制会导致混沌振荡。如果你想模拟反馈式 FM 合成器，它可能会很有用。

请注意：SinOscFB 的频率可以在控制率下进行调制。当尝试以音频率调制 SinOscFB 的频率时，你会注意到在较高频率调制频率下会出现可听的伪影。这是因为 SinOscFB 仅每个控制周期（默认长度为 64 个采样）更新一次传入的频率调制值，而不是像例如 SinOsc 那样在每个采样上更新。

类方法

SinOscFB.ar(freq: 440.0, feedback: 0.0, mul: 1.0, add: 0.0)

SinOscFB.kr(freq: 440.0, feedback: 0.0, mul: 1.0, add: 0.0)

参数：

freq

正弦振荡器的基频，单位为赫兹。

feedback

第二个参数是相位反馈的幅度，单位为弧度。

mul

输出将乘以该值。

add

该值将在任何乘法运算之后加到输出上。

实例方法

示例

{ SinOscFB.ar(440, MouseX.kr(0, 4))*0.1 }.play


{ SinOscFB.ar(MouseY.kr(10, 1000, 'exponential'), MouseX.kr(0.5pi, pi))*0.1 }.play


{ SinOscFB.ar(100*SinOscFB.ar(MouseY.kr(1, 1000, 'exponential'))+200, MouseX.kr(0.5pi, pi))*0.1 }.play


// 观察波形
{ SinOscFB.ar([400, 301], MouseX.kr(0, 4), 0.3) }.scope;
