History

保留已解释代码行的历史记录

Object

另请参阅：Archive

说明

History 会在代码字符串被求值时将它们全部存储起来，以便复用先前编写的代码、将代码转发给其他演奏者，或存储、重现、编辑和分析实时编码演出。它把每个被求值的代码字符串记录到 History 的单例实例 History.current 中。

首批示例：

History.clear.end;     // 如有需要，先清除 History
History.start;         // 开始录制，打开日志文件

// 逐行执行这些代码，作为一小段演出历史
1 + 2;
p = ProxySpace.push(s.boot);
~a = { Dust.ar([1, 1] * 30) * 0.3 };
~a.play;
~a.end(3);

History.started; // 现在开启了吗？

// 停止记录历史并结束日志记录。
History.end;
History.started;

History.document;      // 用当前历史记录创建文档
History.showLogFolder; // 打开写入日志的文件夹。
History.showLogFile;   // 按写入时的原样打开当前日志文件。


// 创建一个 gui 窗口，以便随意访问代码历史行，
// 例如用于演出中的代码复用、改编、分享等：
g = History.makeWin;
// 指定左下角位置，以及 textview 中的行数
g = History.makeWin(0@20, 5);

// 逐行回放录制的历史记录
History.play(0);


// 历史记录甚至可以用 CmdPeriod 记录和回放停止。
// 一次运行一行：
History.clear.start;
1 + 2;
2 + 3;
s.boot;
(dur: inf).play;

CmdPeriod.run; // 或者按停止键命令，Cmd-. 或 ctrl-.
3 + 4; // 继续录制到历史记录中
4 + 5;
History.end;

// 重放历史，包括 CmdPeriod，并持续重放历史。
History.play;

类方法

注意： 许多类方法会被重定向到 History 的特权实例 History.current。其目的是提供简单的代码用户接口。

History.start

开始将解释代码添加到（当前）历史记录中。

History.end

结束向（当前）历史添加解释代码。

History.started

布尔值，表示 History 是否已启动。

History.document: METHOD NOT FOUND!

在新文档中发布历史记录（作为 story）。文档标题是一个按如下格式化的字符串："%Y-%m-%d-%Hh%M-History"。

History.current

History.current = value

当前的 History 实例

History.lines

History.lineShorts

History.current 中当前记录的行。lineShorts 是用于显示的缩短字符串副本。

History.makeWin: METHOD NOT FOUND!

为 History.current 创建一个 HistoryGui。参数：where 指定设置 HistoryGui 窗口左上角位置的点，参数：numItems 为 textview 中的行数

Configuration

History.keepsLog

History.keepsLog = value

获取并设置是否将 History 记录到文件的标志。

History.verbose

History.verbose = value

获取并设置是否从 History 操作发布调试消息的标志。

History.recordLocally

History.recordLocally = value

获取并设置标志以打开和关闭本地代码评估的录制

History.localOff

History.localOn

用于开启和关闭本地代码求值录制的便捷方法

History.forwardFunc

History.forwardFunc = value

一个对传入的新行运行的函数，可用于通过网络发送代码。有关网络代码历史的示例，请参阅 Utopia quark。

保存和加载历史日志

History.showLogFolder

打开存储日志文件的文件夹

History.showLogFile

打开当前日志文件

History.saveCS(path, forward: false)

将历史记录存储为单个 compileString。

History.loadCS(path, forward: false)

从（compilestring）文件加载历史记录。

History.saveStory(path)

按历史顺序作为单独的代码片段存储到文件中。

History.loadStory(path)

从 story 格式的文件中读取历史记录到 current。

History.rewrite(path, open: true)

根据历史记录写出格式正确的代码文件。

参数：

path

文件名是原始名称加上 "_rewritten." 后缀。

open

如果 open 为 true（默认值：true），则打开一个显示该字符串的文本窗口。

History.readFromDoc(path)

从用 .rewrite 创建的代码文件中读取历史记录

编辑历史

History.clear

从（当前）历史记录中移除所有项。

History.enter(lineStr, id: 'me')

手动向（当前）历史记录添加一个条目。

History.drop(num)

从历史记录中丢弃最新的 num 行。如果 n 为负数，则丢弃最旧的 n 行。

History.keep(num)

仅保留历史记录中最新的 num 行。如果 n 为负数，则保留最旧的 n 行。

History.removeAt(index)

删除特定行

History.removeLast

从历史记录中删除最后一行

重复历史

重放历史可以有不同用途：A. 重建，例如尽可能贴近地重做一段编码步骤的历史，或尽可能贴近地重放一整场演出；此时所有错误都很重要，应当逐个处理。B. 实验性现场演出，例如以非线性顺序重放录制的网络现场编程演出片段；此时错误会更频繁地出现，因为当前状态并不总是符合某一行所需的条件。因此，人们可能更倾向于选择能继续运行的健壮性。

History.ignoreErrors

History.ignoreErrors = value

全局标志，决定通过 History 求值代码行时是忽略错误还是停止并抛出错误。

History.eval(codeString, ignoreError)

求值 codeString，并可选地使用 ignoreError 覆盖全局 ignoreErrors 标志。

History.ignoreErrors = true;
History.eval("2 + 1").postln; // 正确的代码，因此仅被求值
History.eval("2 + qwe"); 123; // 编译错误，但会继续执行并输出 123
History.eval("1.blonk"); 123; // 运行时错误，继续执行 -> 输出 123
History.eval("1.blonk", false); 123; // 抛出错误并停止，其后的代码永远不会执行。

History.evalLineAt(index)

在 History.current.lines 中评估索引处的行

History.play(start: 0, end, verbose: true)

从起始行到结束行回放当前历史记录，默认详细模式。

History.stop

停止当前的历史播放。

实例方法

.makeCurrent

示例

// 与第一个示例相同：
History.clear.end;      // 清除以重新开始
History.start;          // 开始录制，打开日志文件

// 逐行执行这些行
1 + 2;
p = ProxySpace.push(s.boot);
~a = { Dust.ar([1, 1] * 30) * 0.3 };
~a.play;
~a.end;

History.end; // History.end 也会结束日志记录。


History.document; // 创建一个包含所有更改的文档
History.showLogFile; // 按原样打开写入的日志文件。

g = History.makeWin(0@20); // 创建一个 GUI 窗口，放在你喜欢的位置
g = History.makeWin(0@20, 5); // textview 中的行数

History.play;                  // 默认按行输出
History.play(verbose: false);  // 直接执行，不输出

// 继续录制
History.start;

// 再输入 5 行
10 + 200;
p.push;
~b = { |freq = 500| LFDNoise3.ar(freq.dup(2)) * 0.2 };
~b.play;
~b.set(\freq, 1000);
~b.end(2);

History.end;

// 将当前历史记录保存到文件。
History.saveCS("~/Desktop/TestHist.scd");
h = History.new.loadCS("~/Desktop/TestHist.scd");
h.lines.printcsAll; "";

// 许多 History 方法被重定向到 History.current：

// History.current 是新代码行总是进入的位置。
h = History.current;
h.lines.printcsAll; "";

// lineshorts 用于 GUI 显示：
h.lineShorts.printcsAll; "";

// 手工创建一个简单条目。
History.enter("2 + 2");
h.lines.printcsAll; "";

// 可以编辑历史记录：
History.drop(-1); // 丢弃最旧的记忆
History.drop(1); // 丢弃最新的记忆

h.keep(9); h.lines.printAll; "";
h.drop(3); h.lines.printAll; "";
h.removeLast;       h.lines.printAll; "";
h.removeAt([3, 4]); h.lines.printAll; "";

// 更多示例
History.clear.start;

1 + 2; // 代码行会被存储

(nil + 2).postln; // 错误行会被忽略

// 仅含注释的行会保留，空行不会：
History.enter("// comment only");
History.enter(" ");


// 保存和加载为文本文件

History.saveCS; // 保存为 compilestring 以便重新加载。

// 按名称保存，按正向时间顺序。
History.saveCS("~/Desktop/testHist.scd", forward: true);

// 从文件重新加载
h = History.new.loadCS("~/Desktop/testHist.scd", forward: true);
h.lines.postcs; "";

// 保存为人类可读/可手动播放的故事
// 按历史顺序将所有内容写入带时间戳的文件：
History.saveStory;

// ……使用给定的文件名。
History.saveStory("~/Desktop/myTestStory.scd");

// 从故事格式文件加载
History.loadStory("~/Desktop/myTestStory.scd");

Document.open("~/Desktop/myTestStory.scd");    // story 文件是人类可读的。


// 各种内部机制
// 手动创建一个新的 History 实例：
h = History([
    [0, \me, "1+2"],
    [1.234, \me, "q = q ? ();"],
    [3, \me, "\"History\".postln"]]);
h.lines.printcsAll; "";
h.lineShorts.printcsAll; "";

h.play; // 播放回来
h.stop;


// 字符串格式化工具
h.storyString;
History.formatTime(1234.56);
History.unformatTime("0:20:34.56");

(
History.prettyString("

/* 移除代码字符串开头和结尾的换行符 ... */

").postcs;
)

// 将一行转换为 n 个字符的短字符串以便 GUI 显示
History.shorten(h.lines.first.postcs, 60).postcs;


// 在网络设置中，可以关闭本地录音并依赖远程录音：
History.recordLocally
History.localOff
History.recordLocally
History.localOn
History.recordLocally


// 默认情况下，历史记录总是记录在这里（如果文件夹不存在则创建它）：
History.logFolder;
History.showLogFolder;
History.logPath;
History.showLogFile; // 当前的日志文件……
// todo: 可选地，应该能够关闭日志记录？

// 过滤行，按键和/或搜索字符串获取所有行的子集：

// 获取特定键的索引
h = History([[0, \me, "a = 1+2"], [1, \me, "3+5"], [1.234, \you, "q = q ? ();"], [3, \they, "\"The-story ==== \".postln"]]);
h.keys;
h.matchKeys(\me);
h.matchKeys(\you);
h.matchKeys(\they);
h.matchKeys;        // 若无测试则为 nil
h.matchKeys(\all);  // 所有键匹配
h.matchKeys([\me, \they])
h.matchKeys(\isidor) // 如果此键未找到对应行，则为空数组

h.matchString("The-s");
h.matchString("q");
h.matchString("1+");
h.matchString("the-Story", false); // ignoreCase 默认为 false
h.matchString("the-Story", true); // 忽略大小写

h.indicesFor([\me, \they], "=");    // 由 \me 或 \her 所写且包含 "=" 的行的索引；

// 搜索只是一个界面/访问功能，
// 所以请继续阅读 HistoryGui 帮助……
h.makeWin;

HistoryGui.help;
