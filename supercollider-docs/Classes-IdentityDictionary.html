IdentityDictionary

将键映射到值的关联集合

Dictionary : Set : Collection : Object

参见：Environment、Event、Object Prototyping

子类：Environment、NodeMap

说明

IdentityDictionary 是一种将键映射到值的关联集合。键和值可以是任意对象，但对于键，通常使用 Symbol。

IdentityDictionary 可用于实现原型对象（Object Prototyping），这些对象的行为类似于其方法可在运行时编程的对象。

通常，子类 Event 被用作 IdentityDictionary，因为有一种语法快捷方式：

a = (); // 返回一个新的 Event。
a.put(\foo, 2.718);
a.at(\foo);

注意： 只有当键是相同的对象时才匹配。（即 === 返回 true。在 Dictionary 中，键值相等即匹配。这使得 IdentityDictionary 比 Dictionary 更快。）Dictionary 的内容是无序的。你不得依赖 Dictionary 中条目的顺序。

IdentityDictionary 常用于为特定类的实例分配名称。例如，代理类（Pdef、Pdefn、Tdef、Ndef）以及 NodeWatcher 都拥有名为 all 的类变量，它们以 IdentityDictionaries 实现。

'parent' 和 'proto' 变量

IdentityDictionary 有三个层级的内容：字典本身、一个 proto 和一个 parent。proto 和 parent 主要是为 IdentityDictionary 的子类 Event 而存在，它使用 parent 来存储事件播放时将使用的动作函数。用户可以将额外的默认值放入 proto。

在字典中查找键时，首先检查字典本身。如果在该层级未找到该键，则查找 proto，如果仍未找到，则查找父级。

这些额外层级用于常见的、默认的值，它们应当在许多字典实例中保持一致。

  • 在 post 该字典时，不会显示 proto 和 parent 的值。
  • 复制 IdentityDictionary 会将指向 parent 和 proto 的引用传递到副本中。这是引用而非复制：更改副本的 parent 也会影响原件的 parent。这是出于效率考虑。
  • 迭代操作（Dictionary: -do、Dictionary: -keysValuesDo）只涉及主层级的值。
  • Dictionary: -collect、Dictionary: -select 和 Dictionary: -reject 会返回新的字典。parent 和 proto 在新结果中会原样保留，但——与 do 一样——它们不会在迭代中被处理，并且与 copy 一样，它们是相同的引用。
// 'b' 未被发送
e = IdentityDictionary(8,
    parent: IdentityDictionary[\b -> 10]
).put(\a, 5);
-> IdentityDictionary[(a -> 5)]

// 但 'b' 仍然存在
e[\a] + e[\b]
-> 15

// 迭代仅触及 'a'
e.keysValuesDo { |key, value| [key, value].postln };
-> [a, 5]

// 'collect' 也是一种迭代，且不会触及父级
g = e.collect { |x| x * 5 };
-> IdentityDictionary[(a -> 25)]
g[\b]
-> 10

// 父对象也会被复制一份
g = e.copy;
g[\b]

// 但它是按引用：'e' 和 'g' 有相同的父级
g.parent[\b] = 20;
e[\b]
-> 20

类方法

IdentityDictionary.new(n: 8, proto, parent, know: false)

-parent 和 -proto 实例变量允许额外的 IdentityDictionary 提供默认值。确定某个键的值的优先级顺序是：IdentityDictionary、其原型、其父级。

当实例变量 -know 为 True 时，IdentityDictionary 通过查找选择器并以该字典为参数求值结果，来响应未知消息。例如：

a = IdentityDictionary(know: true);
a.put(\foo, { |x, y| "--".postln; ("x:" ++ x).postln;  ("y:" ++ y).postln; y.squared });
a.foo(-10.01);

警告： 只有尚未成为 IdentityDictionary（或其父类）实例方法的键才能以这种方式使用。例如，键 "free" 将无法工作，因为它已在 Object 中实现。这意味着类扩展（参见：Writing Classes）可能会破坏代码。建议在方法名中使用下划线以降低这种可能性。

在子类 Event 中，"know" 默认为 true，因此它可以立即用于原型对象。在这种情况下，传递给函数的第一个参数始终是字典/事件本身（这里用 "self" 表示）。

a = (some_value: 7, fuzzy_plus: { |self, a, b| a + b * rrand(0.9, 1.1) });
a.some_value; // 返回 7
a.some_value = 8; // 将其设为 8
a.fuzzy_plus(7, 4);

实例方法

.know

.know = value

如果设为 true，字典会将方法调用解释为查找。这允许你实现对象原型（见上文）。

.putGet(key, value)

将 key 设为 newValue，返回 key 之前的值。

a = (z: 100);
x = a.putGet(\z, -1); // x is now 100

.includesKey(key)

如果键存在于字典中，则返回 true

(j:8).includesKey(\j) // true

.findKeyForValue(argValue)

返回给定值对应的键（会返回找到的第一个，因此可能有歧义）。

(j:8, k: 9).findKeyForValue(8); // 返回 \j

如果经常需要这种反向查找，为了提高效率，你可以考虑改用 TwoWayIdentityDictionary。

.proto

.proto = value

.parent

.parent = value

两个实例变量 proto 和 parent 可持有字典，用于查找当前字典中所有没有值的键。首先查找 proto，然后查找 parent。换言之：proto 覆盖 parent。这允许你构建具有复杂默认值或多重继承的系统。

x = (freq: 30);
a = (amp: 1).parent_(x);
a.at(\freq); // 返回 30
a.proto_((freq: 20));
a.at(\freq); // 返回 20
y = (i: -1);
b.parent_(y);
a.at(\i); // 返回 -1
a.cs;

x = (freq: 30);
a = (amp: 1).parent_(x);
y = (freq: 300);
b = (amp: 0.5).parent_(y);
a.parent_(b);
a.at(\freq); // 返回 300
a.cs;

.insertParent(newParent, insertionDepth: 0, reverseInsertionDepth: inf)

将一个字典插入到接收者的父级链中（而不是替换父级）。

参数：

newParent

添加到父链中的字典

insertionDepth

新父级插入的层级。零（默认值）表示正上方，Inf 表示父级链的顶端。

reverseInsertionDepth

如果新的父字典本身也有父字典，此参数指定原始父字典在新父链中的位置。零表示紧邻其上方，Inf（默认值）表示位于链的顶部。

垃圾回收

.freezeAsParent

为优化垃圾回收器负载，对象可以被冻结并变为不可变。此方法创建一个新字典，并将冻结实例作为其父类，以便在不丢失此优化的情况下覆盖所有内容。
