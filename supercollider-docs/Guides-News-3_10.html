3.10 中的新特性

所有适合 .postln 的新闻

已知问题

FileDialog 可能会挂起——目前我们只能在 KDE 上复现，但其他操作系统也可能受影响。

在 Windows 和 Linux 上，在帮助浏览器（而非编辑器）中用 Ctrl+Enter 运行代码只会求值当前行。

QtWebEngine 是 SCLang 和 SCIDE 的硬依赖，在某些环境中难以安装或无法安装。目前正在努力使其成为可选组件，但这无法在 3.10 之前完成。

常规：新增

构建系统中新增了 NO_X11 选项，以便可以省略需要 X 服务器的服务器插件，例如 MouseX。

常规：已更改

由于 Qt 用 QtWebEngine 取代了 QtWebKit，sclang 和 scide 长期以来一直停留在 Qt 5.5 上。它们已升级以兼容 Qt 5.7+。我们建议使用最新版本的 Qt。此变更的影响包括：

  • sclang 和 scide 现在基于 Visual Studio 2015 及更高版本构建。（此前，Windows 用户必须获取如今已十分古老的 Visual Studio 2013。）
  • UserView 现在支持 Retina/HiDPI 显示。
  • Linux 上略有不同的构建过程。参见 README。

最低要求版本现为 CMake 3.5，而非 CMake 2.8。

scel（emacs 包）现在是一个子模块。

常规：修复

Windows 上 Unicode 路径的许多问题已在 3.9 中修复。少数涉及声音文件的遗留情况仍然存在，现已修复：

  • supernova 的声音文件后端、缓冲区管理器和插件加载
  • scsynth 中的 NRT 模式
  • scsynth 中的 /b_read 系列命令
  • sclang GUI 中的 SoundFileView

修复了使用 CMake 选项 SYSTEM_YAMLCPP=on 时的构建失败。

修复了在 Linux 上将 CMAKE_INSTALL_PREFIX 设置为用户主目录时出现误导性弃用警告的问题。

修复了在某些情况下 macOS 上 CMAKE_PREFIX_PATH 错误地默认为 /usr/local/ 的问题。

scsynth 和 supernova：已添加

supernova 现在具有延迟补偿。

scsynth 和 supernova：已修复

scsynth 的延迟补偿存在数学错误，导致延迟翻倍。现已修复。

为了与 scsynth 保持一致，supernova 不再要求 /b_allocReadChannel 的最后一个参数。

各位稍等，这里快速休息一下。得去喝杯早晨的茶！好了，我们回来了。

修复了 supernova 部分错误消息中缺失的换行符。

修复了 supernova 的 /s_getn 中的错误。

修复 supernova 对 /g_queryTree 的响应，使其与 scsynth 一致。

UGen：已修复

修复了 Convolution2L 中的咔嗒声。

sclang：已添加

Qt GUI 现在支持菜单。参见 Menu、MenuAction、ToolBar 和 MainMenu 的帮助文件。

为来自 Boost 库的 100 多个特殊数学函数（gamma 函数、Bessel 函数、椭圆积分等）添加了包装器。

SerialPort 现在可在 Windows 上工作。

FileDialog 和 Dialog 现在支持 "path" 参数，用于指定对话框出现时的默认目录。

QTreeView 有一个新方法：setColumnWidth。

sclang：已更改

破坏性变更：Float:asString 现在始终生成小数点，因此 3.0.asString 现在为 "3.0"，而不再是 "3"。

破坏性变更： 在 Function:asBuffer、Function:loadToFloatArray 和 Function:plot 中，server 参数已改为 target，现在允许相对于组或节点生成绘图 synth，而不仅仅是相对于服务器。

破坏性变更：File:mkdir 现在返回一个布尔值，表示操作是否成功。此前，它返回的是 File 对象。

现在 ScrollView 在 Linux 和 Windows 上总是显示滚动条，这是针对滚动轮使用方式的一种非常奇怪的依赖关系所做的临时变通方案。

sclang：已移除

从构建系统中移除了一些未使用的 Qt 依赖。

sclang：已修复

破坏性变更：修复了 SimpleNumber:expexp 中长期存在的数学错误。

修复了未使用 Qt 构建时 sclang 的极端 CPU 占用问题。

在 Windows 上，扩展安装的目录在 3.9 中被意外更改。现已还原。

修复了目标存在时调用 File.copy 导致的崩溃。

修复了两个 Array:lace 问题：当任一元素为空数组时崩溃，以及未提供长度参数且任一元素不是数组时报错。

Integer:forBy 在步长为 0 或绝对值小于 1 的浮点值时会令 sclang 冻结的特定条件。

修复了 FunctionDef:dumpByteCodes 中一些不正确的输出。

修复了 Node:release 在负的 release 时间下卡住的问题，负值现在等同于 0。

修复了 == 在 Signal 对象上随机返回错误结果的问题。

类库：新增

UnitTest.passVerbosity 允许更改测试失败报告的详细程度。有关更多信息，请参阅 UnitTest 帮助文件。

新增 UGen 方法 .snap 和 .softRound。

Node:query 新增了一个 action 参数，允许指定回调函数。

.degrad 和 .raddeg 现在已为 UGen 实现。

类库：已更改

SerialPort.devices 模式匹配的默认行为已改进，可在 macOS 和 Linux 上匹配更多种类的设备。

已从 Color.fromHexString 和 History.unformatTime 中移除对 .interpret 的内部调用，从而同时提高了性能和安全性。

类库：已弃用

SerialPort.cleanupAll 已弃用。

为 SerialPort.new 提供整数索引已弃用。

类库：修复

BufWr.ar 不再允许其输入信号为控制速率，否则会导致服务器读取垃圾内存。

如果同时发送多个查询消息，Buffer:query 会返回错误结果。此问题已修复。

修复了路径拼接方法（如 +/+、withTrailingSlash 和 withoutTrailingSlash）中的脆弱性问题。

修复了某些模式类在重复次数传入 0 时的错误。

修复了 Event.addEventType 忽略 parentEvent 参数的问题。

修复了 Pkey 被跳过的问题，原因是默认重复次数为 nil 而非 inf。

修复了在未使用 Qt 构建 sclang 时，关于不存在类的扩展的一些无害但恼人的错误。

ProxySpace:linkDoc 曾经失效——切换文档并不会真正切换 ProxySpace。现在已修复。

如果录音路径不存在，Recorder:prepareForRecord 会产生错误。现在如果该目录不存在，它会创建该目录。

修复了在 ServerOptions:ugensPluginPath 中提供多个路径时的错误。

修复了 HelpBrowser（指该类，而非 IDE 帮助浏览器）自链接被点击时无法触发帮助文件渲染以来一直不可用的问题。

修复了 EnvGate 中的一些错误：当 fadeTime 是常量而非 UGen 输入时抛出错误，以及 i_level 未按文档所述运行。

修复了重启 supernova 时偶尔出现的挂起问题。

修复了 quarks GUI 中 "Check for updates" 按钮引起的令人困惑的用户反馈。

Buffer 方法确保出站 OSC 消息中的缓冲区编号为整数。这修复了 supernova 中的错误，supernova 对缓冲区编号类型比 scsynth 更严格。

修复了 quarks GUI 中 "Check for updates" 按钮引起的令人困惑的用户反馈。

修正了 fold2、wrap2 和 excess 方法中缺失的默认参数，以与 Collection 中的 SimpleNumber 保持一致。

修复了 OSCFunc 及相关功能中不正确的模板匹配行为。

修复了“Message 'extension' not understood”错误，该错误曾导致 Image 无法工作。

IDE & SCDoc：已添加

IDE 拥有更漂亮的默认主题。旧主题仍以 "classic" 存在。

IDE 现在能正确高亮音阶度数文字量，如 4s。

IDE & SCDoc：已更改

IDE 拥有更漂亮的默认主题。旧主题仍以 "classic" 存在。

IDE 现在在所有平台上拥有统一的外观，其配色方案会自适应以匹配编辑器主题。

SCDoc 目录和菜单栏再次重新设计。

对 IDE 外观的各种调整：更美观的标签页、更好的边框颜色。

IDE & SCDoc：已修复

启动 IDE 时，分离的停靠面板有时会变得无响应。此问题已修复。

帮助浏览器中的语法颜色现在与 IDE 一致。

现在一次只能打开一个偏好设置窗口。

恢复会话时，固定标签页的顺序被反转的问题已修复。
