OrderedIdentitySet

按标识判断的集合

IdentitySet : Set : Collection : Object

另请参阅：IdentitySet、List、Dictionary

说明

OrderedIdentitySet 是一个对象集合，其中没有两个对象是同一个对象（即“完全相同”）。它的大多数方法都是继承而来的。（参见 Collection 和 Set 类）。与 IdentitySet 不同，OrderedIdentitySet 的内容是有序的。

类方法

实例方法

.do(function)

对 OrderedIdentitySet 中的每个项求值 function。你可以依赖项的顺序。该函数被传入两个参数，即项和一个整数索引。

OrderedIdentitySet[1, 2, 3, 300].do { |item, i| item.postln };
