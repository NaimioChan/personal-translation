Lag

指数滞后

Filter : PureUGen : UGen : AbstractFunction : Object

另请参见：Lag2、Lag3、VarLag、LagUD

子类：Lag2、Lag3、Ramp

说明

这本质上与 OnePole 相同，区别在于不直接提供系数，而是根据 60 dB 的滞后时间计算得出。这一时间是滤波器收敛到某个值的 0.01% 以内所需的时间。它适合用于平滑控制信号。

关于线性及其他替代方案，请参见 VarLag。

类方法

Lag.ar(in: 0.0, lagTime: 0.1, mul: 1.0, add: 0.0)

Lag.kr(in: 0.0, lagTime: 0.1, mul: 1.0, add: 0.0)

参数：

in

输入信号。

lagTime

60 dB 滞后时间（秒）。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

(
// 用于滞后音高
{
    SinOsc.ar(                              // 正弦波
        Lag.kr(                             // 滞后调制器
            LFPulse.kr(4, 0, 0.5, 50, 400), // 频率调制器
            Line.kr(0, 1, 15)               // 调制滞后时间
        ),
        0,                                  // phase
        0.3                                 // 正弦振幅
    )
}.play
)
