03. 启动引擎

SuperCollider 入门

另请参阅：00. Getting Started With SC

在发出任何声音之前，我们需要启动或“引导”（boot）服务器应用程序。最简单的方法是使用快捷键 Ctrl-B（macOS 上为 Cmd-B）。此外还有一个“Boot Server”的 Server 菜单项。

请注意，窗口底部黑色视图上的白色字体已变为绿色。这表明服务器正在运行。该视图还提供了一些关于 CPU 使用率的信息，以及其他一些目前可能还不太清楚的内容。稍后将详细介绍它们。

另外请查看 post 窗口，SC 已在那里向你提供了一些信息，并告知你它已成功启动。例如：

Booting server 'localhost' on address 127.0.0.1:57110.
Number of Devices: 2
   0 : "Built-in Microph"
   1 : "Built-in Output"

"Built-in Microph" Input Device
   Streams: 1
      0  channels 2

"Built-in Output" Output Device
   Streams: 1
      0  channels 2

SC_AudioDriver: sample rate = 44100.000000, driver's block size = 512
SuperCollider 3 server ready.
Requested notification messages from server 'localhost'
localhost: server process's maxLogins (1) matches with my options.
localhost: keeping clientID (0) as confirmed by server process.
Shared memory server interface initialized

如果由于某种原因启动失败，应该会打印有关所发生错误的信息。如果发生这种情况，请向社区寻求帮助：https://supercollider.github.io#community

默认情况下，你可以在代码中使用字母 s 来引用 localhost 服务器。你可以像这样发送消息来启动和停止它：

s.quit;
s.boot;

尝试一下这个，然后让服务器保持运行。文档中的许多示例在开头都有 s.boot，但一般来说，在使用任何生成音频或以其他方式访问服务器的示例之前，应确保服务器正在运行。通常，本教程中的示例都假定服务器正在运行。

你也可以用文本 Server.default 引用默认服务器，例如：

Server.default.boot;
