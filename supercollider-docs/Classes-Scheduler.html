Scheduler

调度函数以便将来求值

Object

说明

Scheduler 可用于调度和重新调度函数，使其在特定时间点求值。Scheduler 的时间需要手动推进。在大多数情况下，你可能更想改用 Clock（例如 TempoClock、SystemClock、AppClock），由它为你处理时间的推进。

类方法

Scheduler.new(clock, drift: false, recursive: true)

参数：

clock

一个时钟，如 SystemClock。

drift

如果为 true，-sched 将相对于当前绝对时间（Main.elapsedTime）来调度任务，否则相对于调度器的当前逻辑时间（-seconds）。

recursive

设置 -recursive。

实例方法

.play(task)

立即调度该任务。等价于 sched(0, task)。

.sched(delta, item)

以相对于当前时间的 delta 秒调度该任务，当前时间由构造函数的 drift 参数定义。

无论任务被安排在什么时间，它只会在下次设置 -seconds 时被唤醒。

.schedAbs(time, item)

将任务调度到绝对时间 time（以秒为单位）。

.advance(delta)

将当前逻辑时间前进 delta 秒。效果与设置 -seconds 相同。

.seconds

.seconds = newSeconds

调度器的当前逻辑时间。

设置新的时间将唤醒（求值）在该时间内调度的任何任务；返回新时间的任务将被相应地重新调度。

.isEmpty

返回调度队列是否为空。

.clear

清空调度队列

.queue

返回值：

内部用作调度队列的 PriorityQueue 实例。

.recursive

.recursive = value

如果唤醒项目导致新项目被调度，但其中一些已经过期（在当前时间或更早被调度），此变量决定这些项目是否也会在同一次对 -seconds 的调用中被唤醒。

示例

a = Scheduler(SystemClock);

a.sched(3, { "now it is 3 seconds.".postln; nil });
a.sched(5, { "now it is 5 seconds.".postln; nil });
a.sched(1, { "now it is 1 second.".postln; nil });

a.advance(0.5);
a.advance(0.5);
a.advance(2);
a.advance(2);

// beats、seconds 和 clock 被传入 task 函数：
a.sched(1, { |beats, secs, clock| [beats, secs, clock].postln });
a.advance(1);

// 调度是相对于“现在”的：
a.sched(3, { "now it was 3 seconds.".postln });
a.sched(5, { "now it was 5 seconds.".postln });
a.sched(1, { "now it was 1 second.".postln });

a.advance(0.5);
a.advance(0.5);
a.advance(2);
a.advance(2);

// 播放一个 Routine 或 task：
a.play(Routine { 5.do { |i| i.postln; 1.yield } });
a.advance(0.9);
// 调度任务
