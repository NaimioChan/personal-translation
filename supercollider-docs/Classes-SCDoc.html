SCDoc

帮助系统主类

Object

另请参阅：SCDoc Syntax、Writing Help、SCDocHTMLRenderer、SCDocNode、SCDocEntry

说明

SCDoc 管理 SuperCollider 文档系统。

它使用解析以 SCDoc 标记语言编写的帮助文件，并将其渲染为人类可读的文档。

编写帮助文档的指南可在此处找到：Writing Help。

类方法

文档索引

SCDoc.indexAllDocuments(clearCache: false)

索引系统中的所有文档和未文档化的类，并将它们放入 SCDoc.documents 字典。如果在 Routine 中运行，此方法会偶尔让出执行权。

如果你添加了新文档并希望在不重启 SuperCollider 的情况下查看更改，请运行此方法。

参数：

clearCache

如果为 true，即使 schelp 源文件不比目标文件新，也强制重新渲染文件。这还会通过 SCDoc: *refreshStaticFiles 刷新所有静态文件。

讨论：

这将花费几秒钟，并且会在查看任何帮助之前自动执行一次。你可以考虑将其放入你的 startup.scd 文件中，以避免以后决定查看帮助文件时出现此延迟。

SCDoc.documents

已索引文档的字典。其键是相对于 Help 文件夹的路径（不含扩展名），例如 Classes/SinOsc 或 Reference/SCDocSyntax。其值是 SCDocEntry 的实例。

SCDoc.didIndexDocuments

一个布尔值，指示本次会话中是否已调用过 SCDoc.indexAllDocuments。

SCDoc.helpSourceDir

SCDoc.helpSourceDir = path

获取/设置帮助源文件的系统级目录。默认值为 Platform.classLibraryDir.dirname +/+ "HelpSource"，通常不应由用户更改。

SCDoc.helpSourceDirs

获取 HelpSource 文件夹的列表，包括扩展和 quark（除非它们被排除在库编译之外，例如通过 LanguageConfig: *excludeDefaultPaths）

讨论：

该函数在 LanguageConfig: *includePaths 下递归搜索所有名为 "HelpSource" 的文件夹，并包含系统级的 helpSourceDir。除非 LanguageConfig: *excludeDefaultPaths 开启，否则还会搜索 Platform.userExtensionDir 和 Platform.systemExtensionDir。

SCDoc.findHelpFile(str)

查找给定字符串的帮助。尝试智能处理。

返回值：

给定字符串的帮助 URL

SCDoc.verbosity = value

SCDoc.renderAll(includeExtensions: true)

渲染所有帮助文件。主要在你想要渲染所有帮助以便放到网上或类似用途时有用。

参数：

includeExtensions

如果为 false，则跳过 quarks、插件和其他扩展。

SCDoc.refreshStaticFiles

将 SCDoc: *helpSourceDirs 中的所有非 schelp 文件复制（并替换）到 SCDoc: *helpTargetDir。仅应由用户出于开发或调试目的调用。

这将由以下调用

  • SCDoc: *indexAllDocuments 如果在调用时传入 clearCache=true，或者 SCDoc: *checkVersion 检测到 SCDoc: *version 的版本号有变动
  • SCDoc: *renderAll

SCDoc.prepareHelpForURL(url)

通过检查文件是否需要从 schelp 源渲染，或者是否需要执行其他操作，为给定 URL 准备帮助。用作包装器，以即时渲染和处理帮助文件。

参数：

url

要准备的 url。如果它不是 *helpTargetDir 内的本地文件，那么它将直接原样传递该 url。

返回值：

URL，若文件未找到则为 nil。

解析器节点树输出

SCDoc 解析器输出一棵 SCDocNode 树

节点反映了输入中的标签，但并非一一对应。节点树中加入了更详细的结构，以便于渲染。

Example:

DOCUMENT

  • HEADER

    • TITLE "SinOsc"
    • 摘要 "Interpolating sine wavetable oscillator"

    • RELATED

      • STRING "Classes/FSinOsc"
      • STRING "Classes/SinOscFB"

    • CATEGORIES

      • 字符串 "UGens>Generators>Deterministic"
      • STRING "UGens>Oscillators"

  • BODY

    • DESCRIPTION

      • PROSE

        • TEXT "A paragraph with "
        • LINK "Classes/Osc##a link"
        • TEXT " to another document."

      • PROSE

        • TEXT "Another paragraph with "
        • STRONG "strong words"
        • TEXT " in it."

    • CLASSMETHODS

      • PROSE

        • TEXT "Some text..."

      • CMETHOD

        • METHODNAMES

          • 字符串 "ar"
          • 字符串 "kr"

        • METHODBODY

          • PROSE

            • TEXT "Some text..."

          • ARGUMENTS

            • ARGUMENT "freq"

              • PROSE

                • TEXT "Frequency in hertz"

            • 参数 "phase"

              • PROSE

                • 文本 "Phase modulation"

    • EXAMPLES

      • PROSE

        • 文本 "Here are some examples:"

      • CODEBLOCK

        "{ SinOsc.ar(200, 0, 0.5) }.play;
// 调制频率
{ SinOsc.ar(XLine.kr(2000, 200), 0, 0.5) }.play;
// 调制频率
{ SinOsc.ar(SinOsc.ar(XLine.kr(1, 1000, 9), 0, 200, 800), 0, 0.25) }.play;
// 调制相位
{ SinOsc.ar(800, SinOsc.ar(XLine.kr(1, 1000, 9), 0, 2pi), 0.25) }.play;"

    • SECTION "另一个小节"

      • PROSE

        • TEXT "Some text..."
