QtGUI

Qt GUI 的顶层控件

说明

QtGUI 为 Qt GUI 绑定提供顶层控制以及一些平台级功能。

类方法

.availableStyles

返回此平台上所有可用样式的数组。供 -style 使用。

.cursorPosition

以 Point 形式获取光标的当前位置。

.debugLevel

获取或设置来自 "QtCollider" 代码的调试输出的详细级别。SuperCollider 必须以调试模式构建才会出现消息。有效值为 -1（无）、0（仅警告，默认）、1（大多数消息）和 2（详细）。超出此范围的值会被有效截断。

.focusView

获取当前获得焦点的视图。

.palette

获取或设置用于 GUI 显示的 QPalette。

.selectedText

获取当前聚焦视图中选中的文本。如果不存在这样的字符串，则返回空字符串。

在内部，如果 selectedText 方法可用，则首先调用它；否则，如果 selectedString 方法可用，则调用它。否则返回空字符串。

.stringBounds

返回一个 Rect，表示能够容纳以给定字体渲染的给定字符串的最小矩形尺寸。

QtGUI.stringBounds("hellooo", Font(Font.defaultSansFace, 100))

参数：

aString

要渲染的 String。

aFont

Font 的一个实例。

.style

获取或设置当前的 GUI 风格。给定的风格必须是 String 或 Symbol，其名称是 -availableStyles 返回的样式之一。
