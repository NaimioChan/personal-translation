Formant

共振峰振荡器

PureUGen : UGen : AbstractFunction : Object

说明

在给定基频下围绕共振峰频率生成一组谐波。

类方法

Formant.ar(fundfreq: 440.0, formfreq: 1760.0, bwfreq: 880.0, mul: 1.0, add: 0.0)

参数：

fundfreq

基频，单位为赫兹。（控制速率）

formfreq

共振峰频率，单位为赫兹。（控制速率）

bwfreq

脉冲宽度频率，单位为赫兹。控制共振峰的带宽。（控制速率）

必须大于或等于 fundfreq。

mul

add

讨论：

频率输入仅在控制率下读取，因此如果你使用音频率 UGen 作为输入，它只会在每个音频合成块的开始处被采样。

实例方法

示例

// 调制基频，共振峰频率保持恒定
{ Formant.ar(XLine.kr(400, 1000, 8), 2000, 800, 0.125) }.play

// 调制共振峰频率，基频保持恒定
{ Formant.ar(200, XLine.kr(400, 4000, 8), 200, 0.125) }.play

// 调制宽度频率，其他频率保持不变
{ Formant.ar(400, 2000, XLine.kr(800, 8000, 8), 0.125) }.play
