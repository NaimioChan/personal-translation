DynKlank

谐振器组。

UGen : AbstractFunction : Object

另请参见：Klang、DynKlang、Klank

说明

DynKlank 是一组频率谐振器，可用于模拟物体的共振模式。每个模式给定一个振铃时间，即该模式衰减 60 dB 所需的时间。

与 Klank 不同，DynKlank 中的所有参数都可以在启动后实时更改。

注意： 所得信号的幅度取决于服务器的采样率。详情请参见 Ringz: 与采样率的交互。

类方法

DynKlank.ar(specificationsArrayRef, input, freqscale: 1.0, freqoffset: 0.0, decayscale: 1.0)

DynKlank.kr(specificationsArrayRef, input, freqscale: 1.0, freqoffset: 0.0, decayscale: 1.0)

参数：

specificationsArrayRef

一个指向包含三个数组的数组的 Ref：[frequencies, amplitudes, ringtimes]

frequencies:

滤波器频率的数组。

amplitudes:

滤波器幅度数组，或 nil。如果为 nil，则幅度默认为 1.0。

ring 次数：

各滤波器的 60 dB 衰减时间数组。

所有子数组（若非 nil）应具有相同长度。

input

谐振滤波器组的激励输入。

freqscale

在初始化时与所有频率相乘的比例因子。

freqoffset

在初始化时添加到所有频率的偏移量。

decayscale

在初始化时乘以所有环形时间的缩放因子。

实例方法

示例

四个谐振器，每个的最大振幅为 1.0，响铃时间为 1 秒，不同的激励源且不缩放：

注意： 注意参数数组开括号前的 ` 符号！另见 Multichannel Expansion

{ DynKlank.ar(`[[800, 1071, 1153, 1723], nil, [1, 1, 1, 1]], Impulse.ar(2, 0, 0.1)) }.play;

{ DynKlank.ar(`[[800, 1071, 1353, 1723], nil, [1, 1, 1, 1]], Dust.ar(8, 0.1)) }.play;

{ DynKlank.ar(`[[800, 1071, 1353, 1723], nil, [1, 1, 1, 1]], PinkNoise.ar(0.007)) }.play;

{ DynKlank.ar(`[[200, 671, 1153, 1723], nil, [1, 1, 1, 1]], PinkNoise.ar([0.007, 0.007])) }.play;

实时改变参数：

(
// 用鼠标改变 freqs 和 ringtimes
{    var freqs, ringtimes;
    freqs = [800, 1071, 1153, 1723] * MouseX.kr(0.5, 2, 1);
    ringtimes = [1, 1, 1, 1] * MouseY.kr(0.1, 10, 1);
    DynKlank.ar(`[freqs, nil, ringtimes], Impulse.ar(2, 0, 0.1))
}.play;
)

(
// 稍后从外部设置它们：
SynthDef('help-dynKlank', { |out|
    var freqs, ringtimes, signal;
    freqs = Control.names([\freqs]).kr([800, 1071, 1153, 1723]);
    ringtimes = Control.names([\ringtimes]).kr([1, 1, 1, 1]);
    signal = DynKlank.ar(`[freqs, nil, ringtimes], Impulse.ar(2, 0, 0.1));
    Out.ar(out, signal);
}).add;
)

a = Synth('help-dynKlank');

a.setn(\freqs, Array.rand(4, 500, 2000));
a.setn(\ringtimes, Array.rand(4, 0.2, 4));
a.setn(\ringtimes, Array.rand(4, 0.02, 0.4));

// 直接用字面量数组创建多声道控制器：
(
SynthDef('help-dynKlank', { |out,
    freqs (#[100, 200, 300, 400]),
    amps (#[1, 0.3, 0.2, 0.05]),
    rings (#[1, 1, 1, 2])|

    Out.ar(out, DynKlank.ar(`[freqs, amps, rings], WhiteNoise.ar * 0.001))
}).add
)

a = Synth('help-dynKlank');

a.setn(\freqs, Array.rand(4, 500, 2000));
a.setn(\amps, Array.exprand(4, 0.01, 1));

{ Out.kr(102, MouseX.kr(1, 2) * Array.rand(4, 500, 2000)) }.play;
a.mapn(\freqs, 102, 4);
