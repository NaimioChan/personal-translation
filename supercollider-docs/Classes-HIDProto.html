HIDProto

用于与 HIDFunc 匹配的原型 HID 设备

Object

另请参见：HIDFunc、HIDdef、HIDElementProto、HID、HIDInfo、Working with HID

说明

人类输入设备可以用作制作音乐的控制器。此类可与 HIDFunc 或 HIDdef 结合使用，将传入消息与特定的 HID 设备进行匹配。

HIDProto 拥有所有用于指定 HID 设备的变量。你指定的这些变量越多，在过滤传入的 HID 数据时需要匹配的条件就越多。

类方法

HIDProto.new

创建 HIDProto 的新实例。

HIDProto.newType(uName, pName)

根据设备的 usage 和 usagePage 创建一个新的 HIDProto 实例。

参数：

uName

用法 id 的名称

pName

用法页面 id 的名称

返回值：

一个 HIDProto

HIDProto.newProduct(pName, vName)

根据产品信息创建 HIDProto 的新实例。

参数：

pName

要匹配的产品名称。

vName

要匹配的供应商名称。

返回值：

一个 HIDProto

HIDProto.newFromDict(dict)

基于 IdentityDictionary 和一组要匹配的参数，创建一个新的 HIDProto 实例。

参数：

dict

一个 IdentityDictionary，包含一组要匹配的参数。字典中的键应为 HIDProto 的实例变量之一。

返回值：

一个 HIDProto

实例方法

可用于匹配设备的实例变量

.id

.id = value

应匹配的设备 id。这取决于 HID 设备的打开顺序。

.productName

.productName = value

要匹配的产品名称（另请参见 HIDInfo）。

.vendorName

.vendorName = value

要匹配的厂商名称（另请参阅 HIDInfo）。

.productID

.productID = value

要匹配的产品 id（另请参见 HIDInfo）。

.vendorID

.vendorID = value

要匹配的 vendor id（另见 HIDInfo）。

.interfaceNumber

.interfaceNumber = value

要匹配的接口编号（另请参见 HIDInfo）。

.releaseNumber

.releaseNumber = value

要匹配的版本号（另请参见 HIDInfo）。

.serialNumber

.serialNumber = value

要匹配的序列号（另请参见 HIDInfo）。

.path

.path = value

要匹配的路径（另见 HIDInfo）。

.usage

.usage = value

要匹配的设备的 usage ID（另见 HIDInfo）。

.usagePage

.usagePage = value

要匹配的设备的 usage page ID（另请参见 HIDInfo）。

.usageName

.usageName = value

要匹配的设备的用法名称（另见 HIDInfo）。

.pageName

.pageName = value

要匹配的设备的页面名称（另见 HIDInfo）。

要匹配的方法

.matches(hid)

将参数与模板进行匹配。

参数：

hid

HID 的一个实例。

返回值：

一个布尔值，指示传入的 HID 是否匹配模板

.shouldMatch

过滤时应匹配的变量

返回值：

带有变量名的 Set。

添加匹配参数的方法

.addTypeMatch(uName, pName)

添加设备的使用名称和使用页面名称的匹配项。

参数：

uName

要匹配的使用名称

pName

要匹配的页面名称

.addProductMatch(pName, vName)

为设备的 product name 和 vendor name 添加匹配项。

参数：

pName

要匹配的产品名称

vName

要匹配的供应商名称

.addDictionaryMatch(dict)

添加一个带有用于匹配的参数集的 IdentityDictionary。字典中的键应为 HIDProto 的实例变量之一。

参数：

dict

一个包含一组待匹配参数的 IdentityDictionary。

示例

b = HIDProto.newFromDict((path: "/dev/hidraw2"));

a = HIDFunc.usage({ |...args| args.postln }, \X, deviceInfo: b);
a.free

b = HIDProto.newType(\Mouse, \GenericDesktop);

a = HIDFunc.usage({ |...args| args.postln }, \X, deviceInfo: b);
a.free;

b = HIDProto.newProduct("USB Mouse", "Logitech");

a = HIDFunc.usage({ |...args| args.postln }, \X, deviceInfo: b);
a.free;
