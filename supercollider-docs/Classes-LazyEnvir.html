LazyEnvir

惰性环境

EnvironmentRedirect : Object

另请参阅：Maybe、Fdef、Environment、ProxySpace、JITLib

子类：ProxySpace

说明

具有延迟求值和默认值的环境。

因此，可以对尚不存在的对象进行计算，之后再为其赋值。默认情况下，LazyEnvir 返回 Maybe 的实例。另请参见 Fdef。

注意： put 方法被视为透明的并隐式创建占位符，而所有其他方法（如 at、collect、do 等）都会传递该占位符。要获取对象本身，请使用 .source；要将其归约为一个值，请使用：value

e = LazyEnvir.new;
e.use { ~x = ~y + ~z };
e.at(\x);
e.at(\x).source; // 源是一个二元运算（对占位符进行加法）
e.use { ~y = 5; ~z = 7 };
e.at(\x).value; // 值为 12

类方法

实例方法

.put(key, obj)

设置键处引用的值。

.at(key)

返回对 key 处对象的引用。

l = LazyEnvir.push;

// 默认对象在访问时创建
~a;
~a.value; // 默认为 nil

// 对占位符的操作
(
~c = ~a + ~b;

~c.value; // 不会失败，而是返回 nil
)

// 变量可以稍后赋值
(
~a = 800;
~b = { 1.0.rand };

~c.value;
)

// 变量之后可以交换
(
~b = { 1000.rand };
~c.value;
)

.copy

将环境复制到新环境中，每个占位符也会被一并复制。

.localPut(key, obj)

.localRemoveAt(key)

直接设置该键的值。此方法主要在内部使用。

.proxyClass

.proxyClass = value

通过提供类名（Symbol）来指定环境使用的占位对象。默认是 Maybe。任何响应 source、source_ 和 clear 方法的对象都可以作为占位符。

// 使用 LazyEnvir 创建模式空间

a = LazyEnvir.new;
a.proxyClass = \PatternProxy;

a.push;

~x = Pseq([1, 2, 30], 1);
~y = Pseq([~x], inf);

z = ~y.asStream;

z.next;
z.next;
z.next;
~x = Pseq([100, 2, 300], 1);
z.next;
z.next;
z.next;

a.pop;

.removeAt(key)

从环境中移除占位符并清除它。

.makeProxy

返回一个新的占位符对象。此对象在内部使用，可被重写以实现其他惰性环境。
