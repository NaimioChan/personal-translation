Pbind

通过将键绑定到值，将多个值模式组合成一个事件流

Pattern : AbstractFunction : Object

另请参阅：Pattern、Event、Pmono、Rest

说明

Pbind 将多个值流合并为一个事件流。每个值流被分配给结果事件流中的一个或多个键。它以不同的模式来指定一个 Events 流，这些模式被绑定到 Event 中的不同键上。绑定到键上的模式被称为值模式，而 Pbind 本身被称为事件模式。

Pbind 中使用的键通常由 Event 的默认机制以及将要播放的 SynthDef 所定义的控件决定。（关于两者与 Pbind 的关系的简要讨论，请参见下文 SynthDef 和 Event。）

类方法

Pbind.new( ... pairs, ... kwargs)

Pbind 的参数是键和模式的交替序列。

Pbind(\note, Pseq([0, 4, 7]), \amp, 0.1, \dur, 0.2).play

消息 new 将关键字参数转换为键值对，因此我们可以这样写：

Pbind(note: Pseq([0, 4, 7]), amp: 0.1, dur: 0.2).play

模式也可以绑定到键数组。在这种情况下，模式必须指定一个序列，其元素是数组，且每个数组至少包含与键数量相同的元素。

Pbind([\note, \amp], Pseq([[0, 0.05],  [4, 0.5],  [7, 0.1]]), dur: 0.2).play

实例方法

.patternpairs

.patternpairs = value

已定义的键值对，将符号映射到值模式。

Pbind(x:7, y:Pseq([1, 2, 3])).patternpairs

.embedInStream(inevent)

在Stream（例如Routine）内部，继续之前，先产出此模式中的所有事件。一个模式可用于为任意数量的独立流生成值。

参数：

inevent

一个事件，它被传入所有子流，并由这些子流用于生成输出事件。

a = Pbind(note: Pseq([0, 4, 7]), amp: 0.1, dur: 0.2);
r = Routine { |inevent| (note:9, dur: 1).yield;  a.embedInStream(inevent);  };
r.nextN(5, (x:7)); // 传入一个事件以获取 r 接下来的 5 个值，\x 的值为 7 会被传递通过 Pbind 流

示例

(
a = Pbind(
    x:    Pseq([1, 2, 3]),
    y:    Prand([100, 300, 200], inf),
    zzz:  99
);
x = a.asStream;
)

x.next(()); // 传入一个事件 ()
x.next(());
x.next(());
x.next(()); // end: nil
// 声音示例

// 使用默认的合成器定义
Pbind(
    freq: Prand([300, 500, 231.2, 399.2], inf),
    dur:  0.1
).play;

Pbind(
    freq: Prand([300, 500, 231.2, 399.2], inf),
    dur:  Prand([0.1, 0.3], inf)
).play;

Pbind(
    freq: Prand([1, 1.2, 2, 2.5, 3, 4], inf) * 200,
    dur:  0.1
).play;

键可以像上面那样指定为关键字参数，也可以指定为作为参数提供的模式的键序列。此外，当提供键的数组时，该模式将被解包为两个流（见下面的示例）。然而，这在使用关键字参数时不起作用，因此必须放在它们之前。由于历史原因，你更可能看到的是模式的键序列而不是关键字参数。

// 这两者都做同样的事情。
Pbind(a: Pseq([1, 2, 3]), dur: 1).trace.play
Pbind(\a, Pseq([1, 2, 3]), \dur, 1).trace.play

SynthDef 和事件

Pbind 中使用的键由所使用的 SynthDef 以及 Event 提供的广泛默认机制的结构决定。本节对两者进行简要回顾。

SynthDef 为单元生成器的互连赋予一个名称，以便作为 synth 在服务器上运行。它还为 synth 的控制输入赋予控制名称。在下面的示例中，SynthDef \test 具有控制输入 out、freq、amp、nharms、pan 和 gate。

SynthDef(\test, { |out, freq = 440, amp = 0.1, nharms = 10, pan = 0, gate = 1|
    var audio = Blip.ar(freq, nharms, amp);
    var env = Linen.kr(gate, doneAction: Done.freeSelf);
    OffsetOut.ar(out, Pan2.ar(audio, pan, env));
}).add;

SynthDef 需要下载到将要运行它的服务器上。使用 .add 而不是 .send 以确保使用此 SynthDef 的任何模式都拥有关于可用控制输入的信息（参见 SynthDesc）。或者，可以使用 .store 将 SynthDef 保存到磁盘并将 SynthDesc 添加到库中。

Event 是一个 Dictionary，它指定了响应 play 时要执行的动作以及响应 delta 时要返回的时间增量。事件可以写成括号内的一系列键值对。空括号创建一个空事件。

默认情况下，事件在服务器上播放 synth。此类音符事件使用以下键：

乐器（\default）

要播放的 synthdef

变体（nil，可选）

要使用的变体控件默认值集合（参见 SynthDef）

服务器（Server.default）

播放 synth 的服务器

组（1）

新 synth 的，或新 synth 被置于其前或后的那个 synth

addAction (0)

合成器相对于由 group 指定的目标的位置方式

0

组头

1

组尾

2

组之前（可以是 Synth）

3

组之后（可能是一个 Synth）

delta（函数）

事件序列中到下一事件之前的时间，通常通过 dur 间接指定

当 Event 被播放时，它会创建一个 OSC 命令来播放一个 synth。它使用分配给 instrument 的名称来选择要播放的 SynthDef。SynthDef 的控制名（在其 SynthDesc 中找到）会在事件中查找，并将相应的值包含在命令中。

播放 synth 是 Event 执行的常规动作。默认的事件结构定义了若干其他事件类型，可执行各种各样的服务器动作。有关事件类型的列表，请参见 Event 帮助文件。

有许多惯用的名称通常用于标识合成器中的控件。

out

输出总线索引

in

输入总线索引（用于滤波器、调制器等）

gate

包络门控（不是电平！）- 应默认为 1.0，释放时删除 synth

trig

包络门（不是电平！）—— 应默认为 1.0，释放时不会删除 synth

pan

声像位置

bufnum

缓冲区编号（用于使用 PlayBuf、DiskIn 等的 synth）

sustain

synth 的持续时间

amp

Synth 的振幅

freq

合成器的基准音高

Event 为其中一些控件实现了分层指定方案。在下面的列表中，第一个且最左侧的名称为实际控件名，下方缩进的名称是更抽象的指定控件的方式。

delta

直到下一个事件的时间。通常由以下决定：

dur

事件序列中到下一事件的时间

stretch

缩放事件的时间（即 stretch == 2 => 时长加倍）

sustain

Synth 的持续时间，通常（在拉伸的时间单位中）由以下决定：

legato

Synth 的持续时间与事件持续时间之比

amp

synth 振幅（通常范围为 0 到 1），通常由

db

振幅（分贝）

detunedFreq

synth 的实际“音高”，由以下决定：

freq + detune;

freq 由以下确定：

(midinote + ctranspose).midicps * harmonic;

midinote 由以下确定：

(note + gtranspose + root)/stepsPerOctave * octave * 12;

note 由以下确定：

(degree + mtranspose).degreeToKey(scale, stepsPerOctave)

播放方法

虽然 play 方法实际上定义在类 Pattern 中，但在此处回顾它是有用的：

play (clock, protoEvent, quant)

返回一个 EventStreamPlayer。

clock

调度 EventStreamPlayer 的时钟，默认为 TempoClock.default。改变图形的模式必须使用 AppClock。

protoEvent

由 Pbind 修改的初始事件，默认为 Event.default。

quant

clock 使用的量化值。当为一个数字时，模式将从该数字的下一个偶数倍处开始。也可以是一个 Quant，它指定量化、该量化内的时间位置以及一个 timingOffset。详见 Quant。

使用 EventStreamPlayer 进行实时控制

EventStreamPlayer 通过 mute、unmute、stop、play 和 reset 提供实时控制。

(
SynthDef(\cfstring1, { |i_out, freq = 360, gate = 1, pan, amp = 0.1|
    var out, eg, fc, osc, a, b, w;
    fc = LinExp.kr(LFNoise1.kr(Rand(0.25, 0.4)), -1, 1, 500, 2000);
    osc = Mix.fill(8, { LFSaw.ar(freq * [Rand(0.99, 1.01), Rand(0.99, 1.01)], 0, amp) }).distort * 0.2;
    eg = EnvGen.kr(Env.asr(1, 1, 1), gate, doneAction: Done.freeSelf);
    out = eg * RLPF.ar(osc, fc, 0.1);
    #a, b = out;
    Out.ar(i_out, Mix.ar(PanAz.ar(4, [a, b], [pan, pan+0.3])));
}).add;

e = Pbind(
    \degree, Pseq((0..12), inf),
    \dur, 0.2,
    \instrument, \cfstring1
).play; // 返回一个 EventStream
)

( // 一个交互式会话
e.stop
e.play
e.reset

e.mute; // 继续播放，但将音符替换为休止符

e.unmute;

e.reset; // 重置流。
e.reset; // 重置流。
e.reset; // 重置流。
e.reset; // 重置流。

e.pause; // 将从暂停处继续。

e.play;

e.stop; // 将在继续前重置。

e.play;
)

多声道扩展

如果我们为 any 参数提供数组，则 synth 节点将自动复制以处理额外的参数。

对此唯一的例外是：\instrument 和 \dur。关于通用 schema，另见：Multichannel Expansion。

// 当我们为 'root' 参数提供数组时，应听到一个和弦。
// synth def 定义在上面
(
Pbind(
    \instrument, \acid, \dur, Pseq([0.25, 0.5, 0.25], inf),
    \root, [-24, -17], // expand root
    \degree, Pseq([0, 3, 5, 7, 9, 11, 5, 1], inf),
    \pan, Pfunc { 1.0.rand2 },
    \cut, Pxrand([1000, 500, 2000, 300], inf),
    \rez, Pfunc { 0.7.rand + 0.3 },
    \amp, 0.2).play;
);

// 多个数组并行相关，较短的数组会循环：
(
Pbind(
    \instrument, \acid,
    \dur, Pseq([0.25, 0.5, 0.25], inf),
    \root, [-24, -17], // 展开根节点 ...
    \degree, Pseq([0, 3, 5, 7, 9, 11, 5, 1], inf) + [0, 6, 9], // ... 并扩展音级
    \pan, Pfunc { 1.0.rand2 },
    \cut, Pxrand([1000, 500, 2000, 300], inf),
    \rez, Pfunc { 0.7.rand + 0.3 },
    \amp, 0.2).play;
);

注意： 在 Pbind 中，不能有模式数组，只能有返回数组的模式。

// 所以这不会展开：
Pbind(\degree, [Pseq([0, 2, 3], inf), Pseq([2, 4, 5, 6], inf)]).play;

// 但这样会：
Pbind(\degree, Pseq([[0, 2], [2, 4], [3, 5], [0, 6]], inf)).play;
// 将模式数组转换为返回数组的模式，使用 Ptuple：
a = [Pseq([1, 2, 3], inf), Prand([100, 299, 399], inf), Pseries(0, 6, inf)];
b = Ptuple(a);
b.asStream.nextN(8)
Pbind(\degree, Ptuple([Pseq([0, 2, 3], inf), Pseq([2, 4, 5, 6], inf)])).play;
// 示例：不使用 \degree, [p1, p2]，而是写成 \degree, Ptuple([p1, p2])
(
Pdef(\x,
    Pbind(
        \instrument, \test,
        \legato, 0.2,
        \degree, Ptuple([0, Pwalk(Scale.hijaz.degrees, Prand([1, -1], inf))]),
        \scale, Scale.hijaz,
        \strum, 0.05
    )
).play;
)

发送到效果

可以通过将 'out' 参数设置为所需 efx 的输入总线来实现对效果处理器的赋值。还必须创建效果 Synth。Synth.new 是实现此目的的一种方式。

(
// efx synthdef- 注意延迟和 pbind 的时机。:-P
SynthDef(\pbindefx, { |out, in, time1 = 0.25, time2 = 0.5|
    var audio, efx;
    audio = In.ar([20, 21], 2);
    efx = CombN.ar(audio, 0.5, [time1, time2], 10, 1, audio);
    Out.ar(out, efx);
}).add;

// 创建效果合成器
a = Synth.after(1, \pbindefx);

// 如果你不喜欢这个节拍，改成 0.4、0.24
// a.set(\time1, 0.4, \time2, 0.24);

SynthDef(\acid, { |out, freq = 1000, gate = 1, pan = 0, cut = 4000, rez = 0.8, amp = 1|
    Out.ar(out,
        Pan2.ar(
            RLPF.ar(
                Pulse.ar(freq, 0.05),
            cut, rez),
        pan) * EnvGen.kr(Env.linen(0.02, 1, 0.3), gate, amp, doneAction: Done.freeSelf);
    )
}).add;
)
