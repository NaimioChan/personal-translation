Delay2

两个采样延迟。

Filter : PureUGen : UGen : AbstractFunction : Object

另请参阅：Delay1、TDelay

说明

将输入延迟两个采样。

类方法

Delay2.ar(in: 0.0, mul: 1.0, add: 0.0, x1: 0.0, x2: 0.0)

Delay2.kr(in: 0.0, mul: 1.0, add: 0.0, x1, x2)

参数：

in

输入信号。

mul

输出将乘以该值。

add

此值将被添加到输出中。

x1

紧接在延迟输入信号之前的采样，即第二个输出采样。这可以是一个数值或一个 UGen。

x2

比延迟输入信号早两个采样的样本，也就是第一个输出采样。这可以是数值或 UGen。

注意： 以音频速率运行时，x1 和 x2 默认为 0.0，即“静音”先于延迟输入。以控制速率运行时，默认值设为 in 的第一个采样，即第一个输入采样在延迟期间被保持。

讨论：

输出序列为：

out[0] = in[-2] = x2
out[1] = in[-1] = x1
out[2] = in[0]

对于音频速率信号，延迟为一帧音频；对于控制速率信号，延迟为一个控制周期。

为什么 x1 和 x2 的默认值会根据 UGen 的速率而不同？

在音频速率下，遵循模拟延迟模型——输入信号之前是静音（零）。在控制速率下，以零开头不太合适，因为控制信号通常是直流或其他非零均值信号（例如频率或增益控制信号）。

实例方法

示例

(
{
    var z = Dust.ar(1000);
    // [ 原始，从原始中减去延迟 ]
    [z, z - Delay2.ar(z)]
}.plot(0.01)
)

// 使用 x1 和 x2 参数使延迟正弦波连续
(
{
    var freq = 1000;
    var phaseStep = 2pi * freq / s.sampleRate;
    var sine = SinOsc.ar(freq);
    [
        // 默认值：延迟前的静音
        Delay2.ar(sine),
        // 重建预延迟采样
        Delay2.ar(sine,
            x1: phaseStep.sin.neg,
            x2: (2 * phaseStep).sin.neg
        )
    ]
}.plot(0.001).plotMode_(\points)
)
