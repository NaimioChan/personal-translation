GridLines

AbstractGridLines 的工厂类

另请参阅：AbstractGridLines、LinearGridLines、ExponentialGridLines、DrawGrid、ControlSpec、Plotter、plot

说明

GridLines 是一个工厂类，针对给定的 ControlSpec 返回 AbstractGridLines 的相应子类，例如分别针对线性或指数规格返回 LinearGridLines 或 ExponentialGridLines。有关示例以及修改其行为的信息，请参阅这些帮助文件。

类方法

.new

参数：

spec

一个 ControlSpec，定义最小值和最大值、warp 和 step。

返回值：

AbstractGridLines 的子类，例如 LinearGridLines 或 ExponentialGridLines。
