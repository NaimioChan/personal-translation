Platform

处理跨平台差异

Object

子类：UnixPlatform

说明

Platform 类（连同其子类）处理不同操作系统（mac/linux/windows/...）之间的差异，以简化 SuperCollider 的跨平台方面。

Platform 是一个抽象类，封装了各种与平台相关的常量和属性，例如目录、原始功能和启动文件。平台对象可通过主进程实例的 platform 方法访问：

thisProcess.platform

当前实现的平台包括：OSXPlatform、LinuxPlatform、WindowsPlatform、UnixPlatform。

类方法

Platforms 类的大多数方法只是 thisProcess.platform.method 的包装。

平台名称及平台相关操作

Platform.case( ... cases)

根据当前平台（名称）执行操作，就像 Object:switch: 一样

Platform.case(
    \osx,       { "OSX".postln },
    \linux,     { "Linux".postln },
    \windows,   { "Windows".postln }
);

Platform.ideName

返回一个 String，表示该语言认为自己运行在哪个 IDE 中。（通常这由 sclang 可执行文件的 "-i" 选项决定。）这在 sclang 启动时确定，无法动态更改。

这样做的主要目的是根据所用 IDE 将文件夹包含到类搜索路径中或从其中排除：例如，如果 ideName 的值是 "scapp"，那么名为 "scide_scapp" 的文件夹会被包含，而所有其他以 "scide_" 开头的文件夹都会被排除。其默认值为 "none"。

正在使用的已知 IDE 名称有 "scapp"（Mac 上的 SuperCollider.app）、"scvim"（vim）、"scel"（emacs）。也可以使用其他名称。

Platform.architecture

一个 Symbol，命名此版本 SuperCollider 所构建的目标架构。返回 'AArch32'（32 位 ARM）、'AArch64'（64 位 ARM，在 ARMv8 中引入）、'Itanium64'、'i386'、'x86_64'、'PowerPC' 之一，若架构无法识别则返回 'unknown'。

系统命令

.killAll(cmdLineArgs, force: true)

终止 cmdLineArgs 定义的所有进程。

参数：

cmdLineArgs

一个包含一个或多个进程名的字符串。

force

如果为 true（默认值），将强制关闭进程，在 *nix 上使用 killall -KILL，在 Windows 上使用 taskkill /f。

// 例如终止所有可能正在运行的服务器（scsynth 或 supernova）
thisProcess.platform.killAll("scsynth supernova");

.killProcessByID(pid, force: true, subprocesses: true)

终止由进程 ID 标识的单个进程。

参数：

pid

要终止的进程的 pid 整数。

force

如果为 true（默认值），进程将被强制关闭，在 *nix 上使用 kill -KILL，在 Windows 上使用 taskkill /f。

subprocesses

如果为 true（默认值），进程的子进程也将被关闭；当进程是一个启动了子进程的 shell 时（例如使用 String -unixCmd 时），这很有用

// 从命令行启动一个 server 程序用于测试
~pid = unixCmd(Server.program + s.options.asOptionsString(57100));
// 通过 pid 只终止那个服务器程序：
thisProcess.platform.killProcessByID(~pid);

Features

特性是抽象符号，可由扩展作者声明，并可在用户代码中于运行时检查。除显式声明的特性外，类和原语名称也被隐式声明。

.declareFeature(aFeature)

声明 aSymbol 为运行时中存在的特性。类名和原语名不能声明为特性。

.hasFeature(symbol)

如果运行时系统中存在特性 aSymbol，则返回 true。aSymbol 可以指代显式声明的特性以及类和原语名称。

thisProcess.platform.hasFeature(\Object);
thisProcess.platform.hasFeature('_myFuncyPrimitive');

thisProcess.platform.declareFeature('superCrazyCompositionSystem');
thisProcess.platform.hasFeature('superCrazyCompositionSystem');

.when(features, ifFunction, elseFunction)

如果所有特性都存在，则计算 ifFunction，否则计算 elseFunction。

thisProcess.platform.when(#[\Document, \Window], { "yeehah!".postln });
