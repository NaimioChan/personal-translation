3.9 版本新特性

SC 3.9 新闻摘要

参见：3.8 更新内容、3.7 更新内容

我们自豪地宣布 SuperCollider 3.9.0 的到来！很抱歉进度落后如此之多；我们希望您在这里发现的改进足以弥补这一点。在 3.9.0 中，坚定的贡献者们修复了 SuperCollider 一些主要的跨平台兼容性难题，解决了 IDE 和语言中长期存在的问题，并在各方面添加了新功能并修复了 bug。

非常感谢所有为本版本做出贡献的人：adcxyz、awson、bagong、brianlheim、cappelnord、carlocapocasa、crucialfelix、danstowell、defaultxr、dyfer、elifieldsteel、gagnonlg、ghost、gusano、jamshark70、jd-m、jleben、jmckernon、joshpar、jreus、LFSaw、llloret、LucaDanieli、Magicking、miguel-negrao、muellmusik、patrickdupuis、porres、privong、redFrik、samaaron、scztt、simdax、smoge、smrg-lm、snappizz、telephon、thormagnusson、tiagomoraismorgado88、timsutton、vivid-synth、vividsnow、yurivict，以及 SC 社区中以 GitHub 参与之外的方式提供帮助的许多其他人。

已知问题

打开 s.makeGui 后，IDE 服务器状态显示会在几秒后变为黄色。这不会造成任何可用性问题。

在 Web 浏览器中只打印 SCDoc 生成的 HTML 文件的前几页。

在通过历史记录导航时，帮助浏览器不会记住文档中最后打开的位置，而是直接跳到文件顶部。

Supernova 从 "Extensions/plugins" 而不是 "Extensions" 加载插件。

LevelIndicator.style() 已损坏，会导致令人困惑的警告消息。

File.copy 在目标文件已存在时会使解释器崩溃。

在 Windows 上，SerialPort 不可用。

在 Windows 上，Supernova 不可用。

在 Windows 上，命令行 sclang 解释器不可用。

常规：新增

由于合并了一个积极维护的分支，scvim 获得了大量增强。

现在可以在 Windows 上使用 MSYS2 工具链构建 SuperCollider，特别感谢 @awson 和 @bagong。

得益于 @shamazmazum 和 @yurivict，SuperCollider 现在可以在 FreeBSD 上构建。

已添加关于使用 SuperCollider 创建 macOS 独立应用程序的详细文档，感谢 @adcxyz。

得益于 @adcxyz，对多个 sclang 客户端连接到同一服务器的支持得到了极大改进。

仓库中已添加 CODE_OF_CONDUCT.md 和 CONTRIBUTING.md。

SC 立方体标志的高分辨率栅格版本已添加到顶层 icons/ 目录，以及一个适合视网膜屏幕的 .icns 文件。

常规：已更改

破坏性变更：插件接口中的 sc_gcd 现在遵循 gcd(n, 0) == n，而不再是 gcd(n, 0) == abs(n)。这也会影响方法 SimpleNumber:gcd。

macOS 的 plist 文件现在为 Version String 和 Shortened Version String 都显示完整版本号。

常规：修复

构建系统中的一个拼写错误导致 -msse 编译器标志无法为 gcc 和 clang 正确设置。这*可能*修复了部分用户一直在 scsynth 中遇到的非规格化数问题。

修复了当定义了过多类时 scel 中的字体化中断问题。

修复了在 FreeBSD、GCC 7 以及更新版本 Boost 上的构建失败问题。

scsynth 和 supernova：已添加

scsynth 和 supernova 现在支持 /version 命令，它会以 /version.reply program major minor patch branch commit 形式的消息进行回复。完整细节请参阅服务器命令参考。

scsynth 和 supernova：已更改

在 macOS 上，如果 scsynth 的输入和输出设备采样率不匹配，会抛出错误且服务器无法启动。将输入通道数设为 0（命令行中的 -i 0 和 sclang 中的 s.options.numInputBusChannels = 0）现在可以绕过此错误。

在 scsynth 中为 TCP 通信禁用了 Nagle 算法。Nagle 算法以延迟为代价提高带宽，这在 SuperCollider 场景中并不理想。supernova 和 sclang 均已将其关闭。

scsynth 和 supernova：已修复

/b_read 和 /b_readChannel 消息曾间歇性无法读取声音文件，主要影响 Buffer.cueSoundFile。此问题已修复。

UGen：已添加

新增的 UGen Sanitize 可将无穷大、NaN 和次正规数替换为另一个信号，默认替换为零。

DetectSilence 的 doneAction 参数现在可以被调制。

UnaryOpUGen 现在支持按位取反运算符 bitNot。此前它只会静默失败。

UGens：变更

重大变更： 服务器插件的应用二进制接口（ABI）已发生变化。这会产生重要影响：为 SuperCollider 3.8 编译的插件二进制文件将无法在 SuperCollider 3.9 上工作，反之亦然。请重新编译你的插件。

破坏性变更： 带有控制率系数输入的 FOS.ar 会错误地将其系数初始化为 0，并在第一个控制周期内渐变到正确值。此问题已修复。要恢复旧行为，请将每个系数乘以 Line.ar(0, 1, ControlDur.ir)。

UGen：已弃用

Donce 是一个没有明确用途的需求率 UGen，现已弃用。它最有可能被用于电子 donce 音乐的制作中。

UGen：已修复

人们发现若干 UGen 存在严重的初始化缺陷，这些 UGen 会输出初始的垃圾内存采样。如果存在缺陷的 UGen 的输出被馈送到某些滤波器 UGen（如 LPF 或 Delay1）中，就可能产生音频爆炸。这些缺陷已被修复，涉及 BeatTrack、BeatTrack2、CoinGate、Convolution、Convolution2、Convolution2L、Convolution3、DetectSilence、DiskIn、DiskOut、IFFT、KeyTrack、LFGauss、PartConv、PV_JensenAndersen、PV_HainsworthFoote、RunningSum、StereoConvolution2L 和 Unpack1FFT。

修复了 TGrains 忽略 amp 参数的 bug。

Dibrown 不再忽略 length 参数。

Pitch 不再忽略 median 参数。

修复了 Windows 上 DiskIOUGens 的构建错误。

修复了当有总线映射到 AudioControl 但没有任何内容播放到该总线时，它输出垃圾数据的问题。

修复了 PanAz.ar 在音频速率输入信号和位置下的数学错误。

sclang：已添加

已为 sclang 的词法分析器、解析器和编译器添加了回归测试。这将使今后修复这些组件变得更加容易。

sclang：已更改

破坏性变更：sclang 的可嵌套多行注释存在一些错误。特别是，有时 sclang 的词法分析器会错误地处理 /* 和 */ 的重叠组合，例如 */*/ 会被解释为 */ /* */。此问题已修复。

MIDI 端口最大数量已从 16 增加到 128。

启动时输出的 "NumPrimitives = #" 改为 "Found # primitives"。

sclang：已移除

移除了错误打印中调用栈输出里一些无用的内存地址。

移除了语言启动时意外保留的一些调试输出。

sclang：已修复

修复了在 Windows 上如果用户名包含非 ASCII 字符时帮助文件无法打开的问题。

修复了非 ASCII 字符破坏 Visual Studio 调试器的问题。

修复了当选择器是一个数组且其第一个元素不是 Symbol 时，Object:perform 中的崩溃，例如 0.perform([0])。

thisProcess.nowExecutingPath 不再被 Routine:stop 破坏。

当选择大小为零时，TextView:selectedString_ 现在可以正常工作。

修复了当方法或类/实例变量命名为 "none" 时的崩溃问题。

原语中发生的异常即使被 try-catch 包裹，也不再打印不可避免的错误消息。

修复了当 Dictionary:keysValuesArrayDo 以 nil 作为参数调用时的崩溃问题。

修复了 WebView:onLinkActivated 处理程序无法触发的问题。

修复了从 unixCmd 的 action 中启动时固定 GUI 对象无法显示的问题。不过你仍然需要使用 { }.defer。

修复了 QImage:getColor 对绿色通道始终返回零的问题。

类库：新增

UnitTest quark 已被并入主仓库。

为 CollStream 添加了 rewind 方法。

为方便使用，向 File 添加了四个新的类方法：readAllString、readAllSignal、readAllStringHTML、readAllStringRTF。

Pstep 接受数组作为时长参数。

来自扩展的帮助文件现在会显示一个标牌以提高可见性。

为与其他 Platform 类方法保持一致，可以使用 Platform.recordingsDir 代替 thisProcess.platform.recordingsDir。

SequenceableCollection 新增了两个实例方法：flatten2 和 flatBelow。此外，flatten 现在更快了。

~callback 函数现在可用于所有 Event 类型，而不仅仅是 "on" 事件。

事件类型现在包含 parentEvent，用于提供默认值。

为 done 动作引入了新的别名，例如 Done.freeSelf == 2，以提高可读性。有关详细信息，请参见 Done 帮助文件。

新增类 Recorder，可独立于 Server 对象进行录制。

SequenceableCollection:reduce 支持副词参数。

recordingsDir 方法已直接添加到 Platform，它会透明地调用 thisProcess.platform.recordingsDir。

新增了 View:-resizeToBounds、View:-resizeToHint 和 Window:-resizeToHint，以便更轻松地强制 View 和 Window 自动调整大小。

Maybe 现在支持集合方法 at、atAll、put、putAll、add、addAll。

BusPlug:-play 现在可以接受一个 Bus 对象。

帮助文件中的面包屑链接现在为层级中的每个节点提供单独的链接，并且具有多个类别的页面在类别之间带有分隔符。

SoundFile:*openWrite 现在接受额外的参数。

Symbol 新增了两个实例方法：isBinaryOp 和 isIdentifier。

新增了三个便捷方法：View:resizeToBounds、View:resizeToHint 和 Window:resizeToHint。

新增 Collection:asEvent，便于转换为 Event。

DeprecatedError 现在会显示已弃用方法的文件路径。

向 SimpleNumber 添加了两个新方法：snap 和 softRound。

ReadableNodeIDAllocator 提供了 PowerOfTwoAllocator 的一个新的可选替代方案，在多客户端设置下，它以对人类更易读的方式分配节点 ID。

已向 Server 对象添加了新的“booted”阶段，该阶段表示服务器已启动但可能尚未运行，可通过 Server:hasBooted 和 Server.allBootedServers 访问。

类库：已更改

破坏性变更：模式系统中的休止符已重构。不再使用 isRest 事件属性；如果事件的某个属性是 Rest 对象，则该事件被视为休止符。你必须使用 Rest 的实例，而不是 rest 类本身——现在已弃用使用 Rest 而非 Rest() 的做法。

破坏性变更：修复了 Dictionary:== 仅比较两个字典的值而不比较键的问题。

破坏性变更：修复了 Pen.quadCurveTo 错误地使用三次贝塞尔曲线而非二次贝塞尔曲线原语的问题。要恢复旧行为，请将 Pen.quadCurveTo 改为 Pen.curveTo。

破坏性变更：便捷实例方法 Env:kr 和 Env:ar 的原 mul 和 add 参数已重命名为 levelScale 和 levelBias，因为它们的行为与典型的 mul 和 add 参数不同。

Collection:processRest 返回处理后的集合，而不是原始集合。

MIDI 端口的最大数量已增加。

现在尝试将控制速率信号用作 Hasher.ar 的输入会导致错误。

如果没有需要清理的内容，则抑制“Cleaning up temp synthdefs...”这条发布消息。

为了与 Out 和 ReplaceOut 保持一致，LocalOut 和 XOut 现在会正确校验其输入，检查通道数是否非零。

Pattern:fin 的参数默认值为 1，以与 Object:fin 保持一致。

Complex:reciprocal 现在更快了。

Buffer:write 接受浮点参数，并将其截断为整数。

集合类型之间的转换方法已得到改进并记录。

clientID 现在受到保护，在服务器运行时不会被更改。

类库：已弃用

OSCresponder、OSCresponderNode 和 OSCpathResponder 现在会发出弃用消息，并将在至少一年后被移除。请改用 OSCFunc 或 OSCdef。

Speech 已被弃用，并将在 3.10 中移除。原因是其音频输出独立于服务器（严重限制了在作品中的使用），它依赖于专有的 macOS API，没有跨平台兼容性的前景，而且它过于小众，不值得纳入核心库。

WiiMote 相关类（WiiMote、WiiMoteIRObject、WiiCalibrationInfo、WiiMoteGUI、WiiRemoteGUI、WiiNunchukGUI）已废弃。它们从未达到稳定状态，多年来无人维护、无人使用。

AudioIn 已弃用，并将在未来某个版本中移除。它仅为向后兼容 SC2 而提供，因此其弃用早已势在必行。请改用 SoundIn。

SplayZ 已被弃用很长时间，但它终于进入了"官方"弃用轨道，并将在 3.10 中移除。请改用 SplayAz。

TDuty_old 已被弃用很长时间，但现在会发出警告，并将在 3.10 中移除。请改用 TDuty。

Watcher 是 SkipJack 的旧别名，为向后兼容而提供。它已被正式弃用，并将在 3.10 中移除。

Server:recordNode 已弃用。请改用 Recorder:recordNode（例如 s.recorder.recordNode）。

Server.set 类变量已弃用。请改用 Server.all。

SimpleNumber:quantize 已弃用。请改用 SimpleNumber:snap。

Server:userSpecifiedClientID 已弃用。请改用 Server:clientID。

类库：已移除

移除了与 Image 相关的非功能性存根方法和类：类 ImageFilter 和 ImageKernel，以及 Image 实例方法 lockFocus、unlockFocus、applyFilters、filters、filteredWith、addFilter、removeFilter、flatten、invert、crop、applyKernel。

Module 是一个用于 Synth 序列化的未维护且未使用的类，已被移到一个 quark 中。

移除了 Object、String、Method 和 Quark 的 openHelpFile 实例方法。这些方法自 3.8 起已废弃。

移除了 String:openTextFile 和 Symbol:openTextFile。请改用 String:openDocument 和 Symbol:openTextFile。这些方法自 3.8 起已废弃。

类库：修复

Buffer 和 Bus 中的许多实例方法没有正确检查对象是否已被释放，并且会作用于缓冲区 #0 或总线 #0（这对 free 实例方法尤其危险）。它们现在会防范这种情况并抛出错误。

useRanger 选项在 EnvirGui 中于 3.7 版本失效。此问题已修复。

IdentityDictionary 的 collect、select 和 reject 方法会保留对 parent 和 proto 对象的引用。

在 Linux 上，某些 MIDI 方法会产生方法覆盖警告。这些警告已被消除。

第一次重复时，Pn 的 "key" 参数未被正确设置。此问题已修复。

修复了在 CompositeView 对象内使用 DragSource 时的错误。

修复了定义名称过长的 SynthDef 时解释器崩溃的问题。更具体地说，UnixFILE:putPascalString 和 CollStream:putPascalString 的输入现在会被验证。

解释器能更好地处理服务器崩溃。

时间显示以及“start recording”、“pause recording”和“stop recording”菜单项现在能更好地与正在运行的 Server:record、Server:pauseRecording 和 Server:stopRecording 配合。

Server:makeGui 和 Server:makeWindow 在 3.8 中损坏了——窗口中的字段变为空白。它们现已恢复正常工作。

修复了 NodeProxy:-clear 的计时错误。

SoundFileView 能正确显示其网格，且不会在选择框上方绘制网格。

macOS 的 plist 文件现在为 Version String 和 Shortened Version String 都显示完整版本号。

修复了因未调用 Object:primitiveFailed 而导致错误消息被意外静默的实例。

修复了通过 setTempoAtSec 设置速度时 TempoClock 状态可能不一致的问题。

修复了在使用 MIDIFunc.sysex 且 srcID 较大时出现的内存峰值问题。

修复了 SCDoc 中链接里的空格有时被渲染为 %20 的问题。

修复了 Function:plot 在调用方法时服务器未启动的情况下显示空图表的问题。

修复了 Collection:asAssociations 和 Collection:asPairs 中元素丢失的明显错误。

修复了 NodeProxy 在使用外部服务器时的 bug。

History 现在在 Windows 上输出正确的时间戳。

修复了重启服务器时固定音量控制无法持久化的问题。

修复了 SimpleNumber:asTimeString 在带 "precision" 参数时产生无意义结果的问题。

现在可以更改 Server:clientID，允许多个客户端连接到同一服务器。

History 和 HistoryGui 已清理。

修复了涉及 Server.initTree 的重复节点 ID。

修复了使用过多控件时 supernova 崩溃的问题。

Volume 现在在实例化或销毁时遵循滞后时间。

IDE & SCDoc：已添加

Documents 停靠栏中的条目可以重新排序，文档标签页会自动重新排序以反映这一点。

"Edit > Preferences > Editor > Display" 新增了一个选项，可将制表符替换为一个下拉菜单，其条目按字母顺序排列。这在某些演出场景下可使导航更容易。

IDE & SCDoc：已更改

服务器操作此前位于“Language”菜单中，现已移至它们自己的“Server”菜单。

在“查找和替换”功能的状态栏中，将“occurrences”改为“matches”。

对文档的外观和体验进行了许多细微改进。

IDE & SCDoc：已修复

修复了当某个文档包含格式错误的 copymethod 命令时 SCDoc 拒绝继续索引任何文档的问题。

某些 Linux 系统在自动补全工具提示中的字体颜色不可读。该问题已被（最终）修复。

修复了 Document:selectedString_ 无效的 bug。

新标签页现在插入到当前标签页的右侧，而不是一直插入到末尾。

帮助浏览器现在具有用于后退和前进导航的键盘快捷键。这些快捷键依赖于操作系统，由 Qt 提供。

修复了帮助查看器中“在页面中查找...”功能会跳过每隔一个匹配项的问题。

修复了 HTML 复选框出现在帮助查看器左上角的问题。

修复了 macOS 中标签页的右键菜单出现在错误位置的问题。
