IODesc

SynthDesc 输入或输出的描述

Object

参见：SynthDesc

说明

IODesc 描述 SynthDesc 的输入或输出，由 SynthDesc: -outputs 和 SynthDesc: -inputs 返回

实例方法

.rate = value

UGen
