LanguageConfig

访问和修改解释器配置

Object

说明

LanguageConfig 类提供对解释器配置的访问。

类方法

LanguageConfig.store(file)

将当前配置存储到文件。如果无法打开配置文件或写入失败，则抛出错误。

参数：

file

要存储的配置文件的路径。如果该值为 nil，则默认为当前使用的配置文件，如 IDE 首选项中所指定，或由 sclang -l "/path/to/sclang_conf.yaml" 参数指定。默认情况下为 Platform.userConfigDir +/+ "sclang_conf.yaml"

库路径处理

语言配置机制提供了一种为类库添加或排除特定路径的方法。

注意： 在配置文件被保存并重新编译类库之前，对类库路径的更改不会产生任何效果。

LanguageConfig.includePaths

返回类库包含路径。

LanguageConfig.addIncludePath(aPath)

添加新的类库包含路径。

LanguageConfig.removeIncludePath(aPath)

从类库包含路径中移除路径。

LanguageConfig.excludePaths

返回类库排除路径。

LanguageConfig.addExcludePath(aPath)

添加新的类库排除路径。

LanguageConfig.removeExcludePath(aPath)

从类库排除路径中移除路径。

LanguageConfig.currentPath

返回当前配置文件路径。

LanguageConfig.excludeDefaultPaths

LanguageConfig.excludeDefaultPaths = aBoolean

获取或设置是否包含默认类库路径。

注意： 如果 sclang 以 -a 启动，则排除类库路径并忽略此值。默认的类库路径是 Platform.classLibraryDir，以及系统和用户扩展目录。

编译器警告

LanguageConfig.postInlineWarnings

LanguageConfig.postInlineWarnings = aBoolean

获取或设置编译器标志，即当 FunctionDef 无法内联时是否应发布警告。

LanguageConfig.postInlineWarnings_(true) // warn
if(0.5.coin) { var x; x = 10.rand; x + 1 } { 10 };
LanguageConfig.postInlineWarnings_(false) // 忽略它。
if(0.5.coin) { var x; x = 10.rand; x + 1 } { 10 };

实例方法

配置文件格式

配置文件以 YAML 格式存储，包含一个字典。该字典的语义如下表所示：

includePaths

类库路径列表。

excludePaths

要从类库文件中排除的路径列表（覆盖 includePaths）。

postInlineWarnings

用于发布关于缺失内联机会的警告的布尔标志。
