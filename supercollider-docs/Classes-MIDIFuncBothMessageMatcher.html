MIDIFuncBothMessageMatcher

根据消息通道和来源将传入的 MIDI 消息匹配到响应函数

AbstractMessageMatcher : Object

参见：AbstractMessageMatcher、MIDIFuncSrcMessageMatcher、MIDIFuncChanMessageMatcher、MIDIFuncChanArrayMessageMatcher、MIDIFuncSrcMessageMatcherNV、MIDIFuncBothCAMessageMatcher

说明

该类由 MIDIMessageDispatcher 使用，通过消息来源和 MIDI 通道将传入的 MIDI 消息与 MIDIFunc 或 MIDIdef 的实例进行匹配。该类是私有的，通常用户不应直接访问其实例。

类方法

MIDIFuncBothMessageMatcher.new(chan, srcID, func)

创建新实例。

参数：

chan

(在此描述参数)

srcID

要测试的 MIDI 源的 UID，以 Integer 形式表示。

func

找到匹配时要计算的 Function。

返回值：

一个 MIDIFuncBothMessageMatcher。

实例方法

.value(value, num, testChan, testSrc)

检查消息是否匹配，若匹配则求值 func。

参数：

value

MIDI 消息的消息值（例如 velocity 等），为一个 Integer。注意其应在 0-127 范围内。

num

MIDI 消息的消息编号（例如音符编号等），为一个 Integer。注意这应在 0-127 的范围内。

testChan

MIDI 消息的通道号，为 Integer 类型。注意其范围应为 0-15。

testSrc

MIDI 消息来源的 UID，为 Integer 类型。
