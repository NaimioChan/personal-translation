シンセシス

我们知道，SuperCollider 在合成定义和合成调度方面遵循客户端／服务器模型。现在让我们聚焦于合成定义，也就是探究如何为在服务器上执行而构建合成引擎。

このことをするに当たって、考えるべきことが3つあります。

首先，需要了解面向对象编程的基本事项。此外，还需要对 SuperCollider 语言的语法和句法有一定了解。原则上，这类知识可以轻松掌握。为此需要做的是阅读 SuperCollider 的文档并学习一些示例。

第二，还需要数字信号处理方面的知识。原则上，掌握这些知识也很简单。所需要的只是一本好书，比如 Curtis Roads 的《Computer Music Tutorial（译作：计算机音乐——历史·技术·艺术）》。

第三，我们需要知道我们最终想在音乐和美学上达成什么。为了获得这种认识，我们必须提出问题。这类问题例如有以下这些：为什么作为艺术家要使用 SuperCollider 这样的工具？我们想通过创作的音乐和艺术表达什么？
