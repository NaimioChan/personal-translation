Psync

同步并限制模式的持续时间

FilterPattern : Pattern : AbstractFunction : Object

另请参阅：Pfindur

说明

Psync 的行为有些类似于 Pfindur——它有一个 maxdur 参数，用于限制事件流的总时长。

区别在于，如果事件模式在达到 maxdur 之前自行停止会发生什么。如果事件模式的总持续时间短于给定的最大持续时间：

  • Pfindur 直接结束：不再进行时间操作。
  • Psync 会插入一个休止，使总时长向上取整到给定 quant 的最近倍数。

Pbind 的自然时长

Pfindur(16, Pbind(....))行为

Psync(Pbind(....), 4, 16) 行为

6 拍

Pfindur 只播放 6 拍

Psync 向上取整到 8 拍（添加两拍休止）

18 拍

Pfindur 在 16 拍后截断

Psync 在 16 拍后截断

maxdur 可以省略。如果 Pbind 自行停止，其余部分将根据 quant 插入，但总时长不受限制。

类方法

Psync.new(pattern, quant, maxdur, tolerance: 0.001, mindur: 0)

参数：

pattern

一个返回事件的模式。

quant

总时长的取整因子（实际上相当于“小节长度”）

maxdur

最大持续时间

tolerance

流必须超过 maxdur 才会被结束的阈值。

mindur

保证总时长不小于给定限制，与 quant 值无关。

示例

(
SynthDef(\help_sinegrain,
    { |out = 0, freq = 440, sustain = 0.05, pan|
        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain, 0.3), doneAction: Done.freeSelf);
        Out.ar(out, Pan2.ar(SinOsc.ar(freq, 0, env), pan))
    }).add;
)

(
// 一个固定时长的 pattern：

f = Pbind(
    \dur, 0.5,
    \degree, Pn(4, 1),
    \instrument, \help_sinegrain
);

// 此模式具有不确定的长度：
a = Prand([
    Pbind(
        \dur, Pseq([0.02, 0.002, 0.1, 0.1], 2),
        \degree, Pseq([9, 7, 5], inf),
        \instrument, \help_sinegrain
    ),
    Pbind(
        \dur, Pseq([1, 0.35], 2),
        \degree, Pseq([0, [2b, 5b]], inf),
        \instrument, \help_sinegrain
    ),
    Pbind(
        \dur, Pseq([0.15, 0.25, 1.3], 2),
        \degree, Pseq([2b, 4, 5b], inf),
        \instrument, \help_sinegrain
    )
]);
)

Pseq([f, f, a, a], inf).play; // 播放一个序列


// Psync 允许相对于节拍网格限制 stream 的持续时间

b = Psync(a, 1, 1); // 创建一个恰好为 1 拍元素的序列
Pseq([f, f, b, b], inf).play;


b = Psync(a, 1, 2); // 创建一个元素长度为 1 或 2 拍的序列
Pseq([f, f, b, b], inf).play;

(
b = Psync(a, 2);    // 创建一个元素序列，最少 2 拍，
            // 但上限未确定
Ppar([
    Pseq([f, f, b, b], inf), // 序列
    Pbind(\instrument, \help_sinegrain, \freq, 1000, \sustain, 0.01, \dur, 2) // 节拍器
]).play;
)
