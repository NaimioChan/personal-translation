HistoryGui

History 对象的 GUI

另请参阅：History

说明

HistoryGui 允许在 History 发生时轻松访问它：可以阅读最近的行、它们被写入的时间以及写入者；可以按文本字符串和作者姓名进行搜索；还可以快速抓取代码行以便重写。除了记录即时编程会话之外，所有这些在实时代码表演中都很有用。例如参见 powerbooks_unplugged 开发的系统，位于名为 Republic 的 Quark 中。

GUI 元素详解：

按钮起始/结束

如果 gui.history 为当前项，则启动并结束 History。

按钮 all/filt

开启/关闭滤波。

弹出全部/...

选择要搜索的名称键（在网络环境下有用）

TextView

允许输入搜索字符串。

按钮 top/keep

设置 ListView 是保持在顶行，还是持续跟随所选行的模式。

ListView

显示所有 lineShorts，或显示过滤后的 lineShorts；在 ListView 中选中它们会使它们出现在 post-doc 窗口中。

第一个示例：

(
// 创建一段简短历史
h = History([
    [0, \me, "1+2"],
    [1, \me, "3+5"], [1.234, \you, "q = q ? ();"],
    [3, \they, "\"The story\".speak"]
]);
// 为它创建一个 GUI
g = h.makeWin(0@20);
// 查找或创建一个用于代码行显示的文本窗口
// （称为 'doc'，因为在 pre-Qt 时代它是一个 Document）
g.findDoc;
// 在文档窗口的 h.lines 中索引 2 处发布行
g.postDoc(2);
)

类方法

.docHeight

获取和设置由 HistoryGui 打开的文本窗口的高度

.docTitle

获取并设置由 HistoryGui 打开的文本窗口的标题

.new

创建一个新的 HistoryGui

参数：

object

历史记录

numItems

上方 TextView 中的行数

parent

用于放置新 HistoryGui 的父窗口或视图

bounds

新建 HistoryGui 的边界，受其 minSize 约束。

makeSkip

是否创建 HistoryGui 的 skipjack 的标志。

options

为 HistoryGui 设置的选项（继承自 JITGui）。

实例方法

views

.textV

top：所选行的 TextView

.startBut

.filtBut

.keyPop

.filTextV

.topBut

按钮、弹出菜单和 TextView 所在的行

.listV

用于历史行的 ListView

.resetViews

重置所有视图

.showLineAt

在 TextView 中显示 History.lines 中该索引处的行。

'doc'-related

.doc

由 HistoryGui 创建的外部文本窗口，用于显示代码行。这仍然被称为 doc，因为在 pre-Qt 时代它曾是一个 Document。

.findDoc

查找并打开一个可复用的文本窗口，或新建一个

.docFlag

获取或设置要使用的文档策略符号：\sameDoc 尝试复用单个文本窗口，\newDoc 总是新建一个（并跟踪旧文档）

.oldDocs

先前打开的文本窗口（文档）列表

.postDoc

在 History 中找到索引处的代码行，并将其发布到文本窗口

.setDocStr

设置当前 textwindow 的字符串

.rip

用当前选中的行创建一个新的文本窗口

filtering

.filtering

表示过滤是否开启的标志

.filterOn

.filterOff

便捷的启用/禁用方法

.filters

用于过滤的键和字符串片段。例如 ['all', "+"] 获取所有来源中包含字符串 "+" 的行。

.filterLines

对历史行应用过滤

.filteredIndices

当前已过滤行的索引

.filteredShorts

当前用于 GUI 显示的已过滤短行

method:.setKeyFilter 设置要过滤的键，并执行过滤

.setStrFilter

设置要过滤的字符串，并执行过滤

.stickMode

stickMode 0 表示顶部，即在新行到来时选择顶部；stickMode 1 表示保持，即在新行到来后保持当前行被选中。

示例

(
// 创建一段简短历史
h = History([
    [0, \me, "1+2"],
    [1, \me, "3+5"], [1.234, \you, "q = q ? ();"],
    [3, \they, "\"The story\".speak"]
]);
// 为它创建一个 GUI
g = h.makeWin(0@20);
// 查找或创建一个用于代码行显示的文本窗口
// （称为 'doc'，因为在 pre-Qt 时代它是一个 Document）
g.findDoc;
// 在文档窗口的 h.lines 中索引 2 处发布行
g.postDoc(2);
)

h.document;

// 展示滤波器如何工作：

g.filtering; // 滤波器是否开启？
g.filterOff; // off 的简写
g.filterOn;  // and on

// 过滤按键查找行
// 以及代码行中的字符串：
g.filters.postcs;

g.setKeyFilter(\all);
g.setKeyFilter(\me);
g.setStrFilter("");
g.setStrFilter("3");

g.filters.postcs;

// 内部状态缓存在 HistoryGui 中：
g.filteredIndices;
g.filteredShorts;
