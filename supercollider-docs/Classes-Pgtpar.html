Pgtpar

并行嵌入事件流，并将每个放入各自的组中，带有时间偏移

Pgpar : Ppar : ListPattern : Pattern : AbstractFunction : Object

另请参阅：Pgpar、Ptpar、Pbus、Pgroup

说明

类似于 Pgpar，但带有额外的时间偏移。

类方法

Pgtpar.new(list, repeats: 1)

来自父类：ListPattern

参数：

list

时间和模式或流的成对列表：[time, pat, time, pat ..]。

注意： 时间以拍为单位，取决于所用 TempoClock 的速度。

repeats

将整个模式重复 n 次。

示例

// synthdef
(
SynthDef(\help_sinegrain,
    { |out = 0, freq = 440, sustain = 0.05|
        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain, 0.2), doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env))
}).add;
)

// 具有不同起始时间的模式
(
x = Pbind(
    \instrument, \help_sinegrain,
    \degree, Pseq(#[0, 5, 4, 2, 1, 1, 3], inf),
    \dur, Pseq(#[0.25, 0.5, 1.0], inf),
    \scale, #[0, 3, 5, 9, 10]
);
a = Pbus(Pgtpar([0.0, x, 1.5, x, 2.25, x])).play;
)
s.plotTree;
a.stop;
