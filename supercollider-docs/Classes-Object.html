Object

所有对象的抽象父类

另请参阅：Class、Introduction to Objects、Classes

子类：AbstractDispatcher、AbstractFunction、AbstractMDPlugin、AbstractMessageMatcher、

说明

Object 是所有其他类的根类。所有对象都是 Object 类的间接实例。我们把消息发送到的对象称为“接收者”：receiver.method(argument)。

类方法

Object.readArchive(pathname)

从文本归档中读入一个对象。

(
a = Array.fill(100, { 100.rand });
a.writeArchive(PathName.tmp ++ "myArray");
b = Object.readArchive(PathName.tmp ++ "myArray");
a == b; // true
)

/////////

// 闭包 Function
(
f = { 1 + 2 };
f.writeArchive(PathName.tmp ++ "myFunc"); // 成功
)
// 打开 Function
(
var num;
num = 2;
f = { num + 2 };
f.writeArchive(PathName.tmp ++ "myFunc"); // fails
)

参数：

pathname

一个包含归档文件路径的 String。

Object.new(maxSize: 0)

创建一个新实例。任何 Object 的新实例的创建实际上都在此方法中发生（或通过 newCopyArgs），当它被子类调用时。参见 Writing Classes。

Object.newCopyArgs( ... args, ... kwargs)

创建一个新实例，并按变量定义的顺序将参数复制到实例变量中。

重要的是，父类构造函数不会被调用，而是将值直接放入父类的实例变量中。

MyClass {
    var a, b, c;
    // 将把 arg1、arg2、arg3 复制到变量 a、b、c。
    *new { |arg1, arg2, arg3| ^super.newCopyArgs(arg1, arg2, arg3) }
    *newKw { |arg1| ^super.newCopyArgs(arg1, c: 10) }
    value { ^[a, b, c] }
}
MyClass.new(1, 2, 3).value() == [1, 2, 3];
MyClass.newKw(1).value() == [1, nil, 10];

继承示例。

Base {
    var a, b, c;
    *new { ^\didNotCallBase } // 这永远不会被调用
}

Derived : Base {
    var d, e, f;
    *new { |d, e, f| ^super.newCopyArgs(1, 2, 3, d, e, f) }
    *newKw { |d, e, f| ^super.newCopyArgs(c: 3, d: d, e: e, f: f) }
    value { ^[a, b, c, d, e, f] }
}

Derived.new(10, 11, 12).value() == [1, 2, 3, 10, 11, 12];
Derived.newKw(10, 11, 12).value() == [nil, nil, 3, 10, 11, 12];

返回一个布尔值，指示接收者是否是 aClass 的直接或间接实例。在代码中使用此消息必须受到质疑，因为它通常表明错过了利用对象多态性的机会。

5.isKindOf(String); // false

返回一个布尔值，表示接收者是否为 aClass 的直接实例。在代码中使用此消息几乎总是设计错误。

5.isMemberOf(Number); // false
5.isMemberOf(Integer); // true

Accessing

.size

不同的类对此消息的响应不同。Object 总是返回 0。

.rank

返回值所具有的维数。单个值（标量）的秩为零。有关此方法有用的情况，请参见 ArrayedCollection: -rank。

.shape

对于多维数组，返回一个数组，元素为每个连续维度上的元素数量，参见 ArrayedCollection: -shape。对于标量值（大多数对象）返回 nil。

Copying

.copy

制作接收者的副本。此消息的实现取决于对象的类。在 Object 类中，copy 调用 shallowCopy。

.shallowCopy

创建对象的副本。副本的具名和索引实例变量引用与接收者相同的对象。

.deepCopy

递归复制该对象以及实例变量中包含的所有对象，并沿结构向下依次进行。此方法适用于循环图。

.copyImmutable

如果对象是不可变的，则返回浅拷贝，否则返回接收者。

参数：

pathname

包含结果文件路径的 String。

相等性与同一性

==(obj)

回答接收者是否等于 anotherObject。相等的定义取决于接收者的类。Object 中的默认实现是回答这两个对象是否相同。

注意： 每当在类中重写 == 时，也应重写 hash。

5.0 == 5; // true
5.0 === 5; // false
a = [1, 2, 3]; b = [1, 2, 3];
a == b; // equal
a === b; // 不相同
"worth trying" == "worth trying"; // equal

===(obj)

回答接收者是否与 anotherObject 是完全相同的对象。

5.0 === 5; // false
"worth trying" === "worth trying"; // 不相同
'worth trying' === 'worth trying'; // 相同（符号是唯一的）

!=(obj)

回答接收者是否不等于另一个对象。Object 中的默认实现是判断两个操作数的 '==' 并对此结果取反。（见下文）。

!==(obj)

回答接收者是否与另一个对象不相同。

|==|(that)

一个惰性相等运算符。对于典型的对象类型，|==| 的行为与 Object: -== 相同。对于 AbstractFunction 及其子类（包括 Pattern 和 UGen），它不会立即执行相等性检查，而是组合一个相等操作，在求值所得函数或流时执行。

1 |==| 1  // true

Pseq([1], inf) == 1  // false（因为 "a Pseq" 不等于 1）

Pseq([1], inf) |==| 1  // 一个 Pbinop

(Pseq([1], inf) |==| 1).asStream.next  // Pbinop 求值为 true

|!=|(that)

一个惰性不等运算符，定义为 not(this |==| that)。参见 Object: -|==|。

.fuzzyEqual(that, precision: 1.0)

返回两个对象在给定精度下的相等程度。被比较的对象必须支持 .max、减法和除法。

5.0.fuzzyEqual(5.0, 0.5);  // 1.0 - 完全相等
5.25.fuzzyEqual(5.0, 0.5); // 0.5 - 50% equality
4.75.fuzzyEqual(5.0, 0.5); // 0.5 - 50% equality
5.9.fuzzyEqual(5.0, 0.5);  // 0.0 - 无相等

通过检查返回的相等程度是否高于 0.0，在你的精度阈值内解析为布尔值。

(
// 笛卡尔坐标到极坐标再返回，累积精度误差
var x = 3.0, y = 5.0;
var hypot = hypot(y, x);
var angle = atan2(y, x);
var polar = Polar(hypot, angle);
var xFromPolar = polar.asPoint.x;
var equalWithin = 1e-5;
postf(
    "Exactly equal? %\n"
    "Fuzzily equal? %\n",
    x == xFromPolar,
    fuzzyEqual(x, xFromPolar, equalWithin) > 0
);
[x, xFromPolar]
)

返回值：

一个 Float，范围从 0.0 到 1.0。

.compareObject(that, instVarNames)

测试两个（属于同一类的）对象在某一方面是否相同：如果两者的 instVarNames 相等，则返回 true。如果未给出任何名称，则测试所有实例变量（另见：-instVarHash）

a = Pseq([1, 2, 3], inf); b = Pseq([100, 200, 300], inf);
a.compareObject(b, [\repeats]); // true
a.compareObject(b, [\list]); // false

.hash

返回一个用于索引哈希表的代码。Dictionary 和 Set 及其子类使用它来实现快速的对象查找。通过 == 判断相等的对象应具有相同的哈希值。每当在类中重写 == 时，也应重写 hash。

a = "worth trying"; b = "worth trying";
a.hash;
b.hash;

.identityHash

返回一个用于索引哈希表的代码。此方法由原语实现，且不可被覆盖。=== 相同的对象应具有相同的哈希值。

a = "worth trying"; b = "worth trying";
a.identityHash;
b.identityHash;

.instVarHash(instVarNames)

返回该对象实例变量和对象类的组合哈希值。如果未给出任何实例变量，则测试所有实例变量（另见：-compareObject）。

a = Pseq([1, 2, 3], inf); b = Pseq([100, 200, 300], inf);

a.instVarHash([\repeats]); // same
b.instVarHash([\repeats]);

a.instVarHash([\list]); // 不同
b.instVarHash([\list]);

a = Pseq([1, 2, 3], inf); b = Prand([1, 2, 3], inf);
a.instVarHash([\list]); // 不同
b.instVarHash([\list]);

Testing

.isNil

返回一个布尔值，指示接收者是否为 nil。

.notNil

返回一个布尔值，指示接收者是否不为 nil。

.isNumber

返回一个 Boolean，指示接收者是否为 Number 的实例。

.isInteger

返回一个布尔值，指示接收者是否为 Integer 的实例。

.isFloat

返回一个布尔值，指示接收者是否为 Float 的实例。

?(obj)

如果接收者为 nil，则返回 anObject，否则返回接收者。

??(obj)

如果接收者为 nil，则对 Function 求值并返回结果。

!?(obj)

如果接收者不为 nil，则对 Function 求值，将接收者作为参数传入并返回结果，否则返回 nil。

注意： 如果该函数不包含变量或参数，则会被内联。

讨论：

此方法允许构建对对象执行的操作链（可能跨多个方法），而无需检查该对象是否为 nil。执行完所有期望的操作后，可以使用 -?? 检查结果是否为 nil，并在这种情况下提供一个默认值。

示例：

x !? (_ * 3) ?? { "It was a nil, so I give a default value".postln; Point(1, 1) }

当 x = nil 时，结果将是：

It was a nil, so I give a default value
Point(1, 1)

但如果 x = Point(3, 4)，结果将是：

Point(9, 12)

嵌套的 nil 检查：

(
x = nil;
y = Point(3, 4);
z = Point(5, 6);
x !? { |x| y !? { |y| z !? { |z|  x.rho * y.rho * z.rho } } }
)

结果为 nil

(
x = Point(1, 2);
y = Point(3, 4);
z = Point(5, 6);
x !? { |x| y !? { |y| z !? {  |z| x.rho * y.rho * z.rho } } }
)

结果为 87.321245982865

.pointsTo(obj)

如果接收者直接引用了 obj，则返回 true。

a = 9;
b = [1, a, 6, 8];
c = [1, b, 5];
c.pointsTo(b); // true
c.pointsTo(a); // false

.mutable

如果接收者可变更则返回 true。

a = #[1, 2, 3]; b = [1, 2, 3];
a.mutable; // false
b.mutable; // true

.frozen

如果接收者已冻结则返回 true。

.switch( ... cases)

Object 实现了一个 switch 方法，允许使用多个分支进行条件求值。这些分支实现为测试对象对（使用 if this == test.value 进行测试）以及若为真则求值的对应函数。为了使 switch 能够内联（从而与嵌套 if 语句一样高效），匹配值必须是字面量整数、浮点数、字符、符号，并且函数不得含有变量或参数。

讨论：

(
var x, z;
z = [0, 1, 1.1, 1.3, 1.5, 2];
switch (z.choose.postln,
    1,   { \no },
    1.1, { \wrong },
    1.3, { \wrong },
    1.5, { \wrong },
    2,   { \wrong },
    0,   { \true }
).postln;
)

or:

(
var x, z;
z = [0, 1, 1.1, 1.3, 1.5, 2];
x = switch (z.choose)
    { 1 }   { \no }
    { 1.1 } { \wrong }
    { 1.3 } { \wrong }
    { 1.5 } { \wrong }
    { 2 }   { \wrong }
    { 0 }   { \true };
x.postln;
)

Messaging

方法可以不直接发送给对象，而是仅通过一个方法选择器（一个 Symbol）来调用。其他参数可以通过直接传递、或从环境中提供来传入。如果不知道接收者是否实现了该方法，tryPerform 只会在其实现时发送。消息 superPerform、superPerformList 和 superPerformArgs 调用父类的方法。

.perform(selector ... args)

选择器参数必须是一个 Symbol。将选择器指定的方法连同给定参数发送给接收者。

如果第一个参数是 Array 或 List，此方法的行为类似于 performMsg。但是，不建议这样使用，而应当使用 performMsg。

.performList( ... args, ... kwargs)

selector 参数必须是 Symbol。将 selector 命名的方法连同给定参数发送给接收者。如果最后一个参数是 List 或 Array，则其元素会被解包并作为参数传递。

a = { |a, b, c| postf("% plus % plus % is %\n", a, b, c, a + b + c); "" };
a.performList(\value, [1, 2, 3]);

.performArgs(selector, args, kwargs)

与 -perform 类似，但允许你传入一个键值数组作为关键字参数。在 -doesNotUnderstand 以及其他可能接受多种关键字参数的地方很有用。

参数：

selector

方法名称的 Symbol。

args

参数的数组。

kwargs

一个由关键字-参数对组成的 Array。

Example

x.performArgs(\foo, [1, 2], [\bar, 10]);
// 等价于……
x.foo(1, 2, bar: 10);

.functionPerformList( ... args, ... kwargs)

以选择器和参数列表调用该函数。此方法的存在是为了在 Method 和 Function 之间提供统一的接口。

.performMsg(msg)

该参数必须是 List 或 Array，其第一个元素是表示方法选择器的 Symbol。其余元素被解包并作为参数传递给由该选择器命名的方法。

a = { |a, b, c| postf("% plus % plus % is %\n", a, b, c, a + b + c); "" };
a.performMsg([\value, 1, 2, 3]);

.performWithEnvir(selector, envir)

参数：

selector

表示方法选择器的 Symbol。

envir

其余参数从环境中获取，并作为参数传递给由选择器命名的方法。

讨论：

a = { |a, b, c| postf("% plus % plus % is %\n", a, b, c, a + b + c); "" };
a.performWithEnvir(\value, (a: 1, c: 3, d: 4, b: 2));

.performKeyValuePairs(selector, pairs)

参数：

selector

表示方法选择器的 Symbol。

pairs

包含键值对的数组或列表。

讨论：

a = { |a, b, c| postf("% plus % plus % is %\n", a, b, c, a + b + c); "" };
a.performKeyValuePairs(\value, [\a, 1, \b, 2, \c, 3, \d, 4]);

.tryPerform( ... args, ... kwargs)

与 'perform' 类似，但 tryPerform 仅在接收者理解该方法名时才将方法传递给接收者。如果接收者未实现该方法，则结果为 nil。注意，这不会像 'try' 那样捕获错误（参见 Exception）。如果接收者确实有匹配的方法，但该方法抛出错误，执行将停止。但是，'tryPerform' 比 'try' 更快。

(a: 1, b: 2, c: 3).tryPerform(\keysValuesDo, { |key, value| [key, value].postln });

// Set 不理解 keysValuesDo —— 结果为 nil
Set[1, 2, 3].tryPerform(\keysValuesDo, { |key, value| [key, value].postln });

// 错误发生在 keysValuesDo 内部——错误被抛出以停止执行
(a: 1, b: 2, c: 3).tryPerform(\keysValuesDo, { |key, value| [key, value].flippityblargh });

// 关键字参数会被传递下去
[1, 2, 3, 4].tryPerform(\pyramid, patternType: 1)

.superPerform( ... args, ... kwargs)

与 perform 类似，superPerform 调用一个方法，但它在父类上调用该方法。selector：表示方法选择器的 Symbol。args：方法参数。

.superPerformList( ... args, ... kwargs)

与 performList 类似，superPerformList 调用一个方法，但它是在父类上调用该方法。selector：表示方法选择器的 Symbol。args：方法参数。如果最后一个参数是 List 或 Array，则其元素会被解包并作为参数传入。

.superPerformArgs(selector, args, kwargs)

与 performLArgs 类似，superPerformArgs 调用一个方法，但它是在父类上调用该方法。selector：一个表示方法选择器的 Symbol。args：方法参数。kwargs：关键字参数，以键值对形式传递。

.multiChannelPerform(selector ... args)

执行选择器并进行多通道扩展。另请参阅：多通道扩展。

参数：

selector

表示方法选择器的 Symbol。

... args

方法参数，如果其中包含数组，则会对每个子元素多次调用该方法。

讨论：

a = { |a, b, c| format("% plus % times % is %", a, b, c, a + b * c).quote };
a.multiChannelPerform(\value, [1, 10, 100, 1000], [2, 7, 9], [3, 7]);

["foo", "bar"].multiChannelPerform('++', ["l", "bro", "t"]);

Dependancy

.addDependant(dependant)

将 aDependant 添加到接收者的依赖者列表中。

.removeDependant(dependant)

从接收者的依赖列表中移除 aDependant。

通知接收者的依赖对象接收者已发生变化。进行更改的对象应作为 theChanger 传入。

接收者所依赖的对象已发生变化。theChanged 是发生变化的对象，theChanger 是做出该变化的对象。

错误支持

Object 实现了许多会抛出 Error 实例的方法。许多方法（例如 doesNotUnderstand）是“私有”的，通常不需要在用户代码中直接调用。其他方法（如下文所记载的方法）可用于面向对象设计（例如定义将在子类中实现的抽象接口）和方法废弃等目的。保留关键字 thisMethod 可用于引用所在的方法。另请参见 Method 和 Function（用于异常处理）。

.doesNotUnderstand(selector ... args, ... kwargs)

参数：

selector

被调用的方法。

... args

一个由参数组成的 Array。

kwargs

一个由关键字参数对组成的 Array。

.throw

将接收者作为 Exception 抛出，该异常可能被任何外围 Function 捕获并处理，也可能不会被捕获处理。

.subclassResponsibility(method)

抛出 SubclassResponsibilityError。用于表明该方法应在接收者的所有子类中定义。

讨论：

someMethod {
    this.subclassResponsibility(thisMethod);
}

.shouldNotImplement(method)

抛出 ShouldNotImplementError。用于表明该继承方法不应在接收者中定义或使用。

.deprecated(method, alternateMethod)

抛出一个 DeprecatedError。用它来表示所在的方法已被更好的方法取代（可能位于另一个类中），并且很可能在未来被移除。与其他错误不同，DeprecatedError 仅在 Error.debug == true 时才会中止执行。在所有情况下，它都会发布一条警告，指明该方法已废弃以及推荐的替代方法。

讨论：

foo {
    this.deprecated(thisMethod, ThisOrSomeOtherObject.findMethod(\foo);
    ... // 除非 Error.debug == true，否则此方法的执行将继续
}

// 对于类方法：
*bar {
    this.deprecated(thisMethod, OtherClass.class.findMethod(\bar));
    ...
}

"hello".postcs; "hello".postcs; "";

.dump

将接收者的详细底层表示打印到 post 窗口。任何对象都理解此方法（这意味着元类、类及其实例）。请注意，在 List 类中，此方法会转储该列表的内部数组。

Meta_Object.dump // 类 Object 的元类
Object.dump      // 名为 Object 的类
Object.new.dump  // Object 类的一个实例

讨论：

  • 详细的低层信息因接收者而异。

  • 某些实例对象，尤其是唯一对象，会返回被转储对象的类名和值（必要时还有更多数据）：

    Float
    1.0.dump

    64 位版本的 SuperCollider 返回：

       Float 1.000000   00000000 3FF00000
-> 1.0

    详情请参阅 Float: -dump

    Integer
    1.dump
       Integer 1
-> 1
    Char
    $1.dump
       Character 49 '1'
-> 1

    Character 与 '1' 之间的整数是该字符的 ASCII 值。

    Symbol
    \1.dump
       Symbol '1'
-> 1

  • 某些实例会返回更详细的信息，例如

    • 虚拟内存中的地址（以 0x 为前缀的十六进制数），
    • 垃圾回收器颜色（gc），
    • 数据格式类型（fmt），
    • 来自垃圾回收器的不可变性、终结和健全性信息标志（flg），
    • size class（集合），
    • 依此类推（第二行及后续行上的信息因实例所属的类而异）

    带有该实例的类名：

    Array
    [1, 2].dump;
    Instance of Array {    (0x1552c9558, gc=78, fmt=01, flg=00, set=02)
  indexed slots [2]
      0 : Integer 1
      1 : Integer 2
}
-> [1, 2]
    List
    List[1, 2].dump;
    List's array:
Instance of Array {    (0x13b3cb5b8, gc=6C, fmt=01, flg=00, set=02)
  indexed slots [2]
      0 : Integer 1

    size : Integer 2

Iteration

.do(function)

Object 以自身作为参数求值该函数，并返回结果。不同的类对此消息的响应方式不同。

讨论：

f = { |x, i| [x, i].postln };
[1, 2, 3].do(f); // Array.do
10.do(f); // Integer.do
($Q).do(f); // Object.do

.generate(function, state)

Object 通过发送给接收者的 do 消息进行迭代。此方法供列表推导内部使用。

.dup(n: 2)

将接收者复制 n 次，返回包含 n 个副本的数组。不同类对此消息的响应方式不同。可使用快捷方式 "!" 代替。

讨论：

8.dup(10);
8 ! 10; // 同上
x = [[1], [2], [3]].dup(5);
x[0] === x[1]; // false：复制接收者。
x[0][0] === x[1][0] // true：不深拷贝接收者
{ 1.0.rand }.dup(5) // 其他对象对 dup 的响应不同

Scheduling

.awake(beats, seconds, clock)

此方法由调度该对象的 Clock 在其调度时间到达时调用。它调用 -next，并将调度时间（以拍为单位）作为参数传入。

参数：

beats

调度时间，以拍为单位。这等于当前逻辑时间（Thread: -beats）。

seconds

调度时间，以秒为单位。它等于当前逻辑时间（Thread: -seconds）。

clock

对象被调度所在的时钟。

流支持

.next

不做任何事；仅返回对象本身。

.reset

不做任何事；仅返回对象本身。

例程支持

对象支持 Stream 的基本接口，对以下消息仅返回自身：next、reset、stop、free、clear、removedFromScheduler、asStream。

.yield

必须从 Routine 内部调用。将控制权让给调用线程。接收者是传递给调用线程方法的结果。yield 的结果将是下次调用时传递给 Routine 的 next 方法的值。

.yieldAndReset(reset: true)

必须从 Routine 内部调用。将控制权让给调用线程。接收者是传递给调用线程方法的结果。Routine 被重置，以便下次调用时从头开始。yieldAndReset 在 Routine 内永远不会返回。

.alwaysYield

必须从 Routine 内部调用。将控制权让给调用线程。接收者是传递给调用线程方法的结果。Routine 在后续调用时将始终 yield 接收者，直到它被重置。alwaysYield 在 Routine 内永远不会返回。

.embedInStream

产出接收者

.idle(val)

在例程中，返回数值（即接收者），直到此时间结束。（另请参见 Routine: -play）时间相对于该线程的时钟来测量。

a = Routine { 1.yield; 0.idle(3); 400.yield };
fork { loop { a.next.postln; 0.5.wait } };

.iter

返回一个 OneShotStream，其返回值为接收者。

a = 9.iter;
a.nextN(4);

.cyc(n: inf)

将接收者嵌入流中 n 次（默认：inf），每次都会重置它。

a = 9.cyc(2);
a.nextN(4);

.fin(n: 1)

仅对接收者调用 next n 次（默认值：1），并产生结果。

a = (10..0).iter.fin(2);
a.nextN(4);

.repeat(repeats: inf)

使用 Pn 反复将接收者嵌入流中（因此可同样用于模式和其他对象）

a = (0..3).iter.repeat(2);
a.nextN(9)

.loop

将接收者无限期地嵌入流中

a = (0..3).iter.loop;
a.nextN(9)

.nextN(n, inval)

返回一个数组，其中包含调用 -next 给定次数所得的结果

参数：

n

消息调用次数

inval

传递给下一条消息的参数

Routine { inf.do { |i| i.rand.yield } }.nextN(8)

.streamArg(embed: false)

取决于传递给流的对象，对象的行为会有所不同：它可能被嵌入到流中，或直接用作流。

此方法允许在两种行为之间切换。为提高效率，子类 Pattern 和 Stream 简单地将此方法实现为 "asStream"。

参数：

embed

如果设为 true，该对象会将自身嵌入流中（因此只返回一次）。如果设为 false，它会永远返回自身。为简单起见，子类实现此方法时不带此开关。

// 嵌入一个事件
a = (z: 77);
b = Pset(\y, 8, a.streamArg(true)).asStream;
c = Pset(\y, 8, a.streamArg(false)).asStream;
b.nextN(3, ()); // 到此结束
c.nextN(3, ()); // 循环

// 嵌入一个模式
a = Pbind(\note, Pseq([1, 2]));
b = Pset(\y, 8, a.streamArg(true)).asStream;
c = Pset(\y, 8, a.streamArg(false)).asStream;
b.nextN(3, ()); // 到此结束
c.nextN(3, ()); // 这也会结束
