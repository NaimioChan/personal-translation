Lag2

指数滞后

Lag : Filter : PureUGen : UGen : AbstractFunction : Object

另请参阅：Lag、Lag3、Ramp、Lag2UD

说明

Lag2 等价于 Lag.kr(Lag.kr(in, time), time)，因此产生更平滑的过渡。这节省了 CPU，因为你只需计算一次衰减因子而非两次。详情参见 Lag。

类方法

Lag2.ar(in: 0.0, lagTime: 0.1, mul: 1.0, add: 0.0)

来自父类：Lag

Lag2.kr(in: 0.0, lagTime: 0.1, mul: 1.0, add: 0.0)

来自父类：Lag

参数：

in

输入信号。

lagTime

60 dB 滞后时间（秒）。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

(
// 用于滞后音高
{
    SinOsc.ar(        // 正弦波
        Lag2.kr(            // 滞后调制器
            LFPulse.kr(4, 0, 0.5, 50, 400),    // 频率调制器
            Line.kr(0, 1, 15)                // 调制滞后时间
        ),
        0,    // phase
        0.3    // 正弦振幅
    )
}.play
)
