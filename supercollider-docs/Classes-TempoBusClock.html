TempoBusClock

一个将其速度与服务器同步的时钟

TempoClock : Clock : Object

参见：TempoClock

类方法

TempoBusClock.new(control, tempo, beats, seconds)

返回一个新实例。

参数：

control

可以是任何响应消息 set(key, val, ...) 的对象，例如 Synth 或 NodeProxy。控制键集为 "tempo"。除此之外，TempoBusClock 的工作方式与 TempoClock 完全相同。

tempo

参见 TempoClock

beats

参见 TempoClock

seconds

参见 TempoClock

示例

(
a = { |tempo = 1| Ringz.ar(Impulse.ar(tempo), [501, 500], 1/tempo) }.play;
t = TempoBusClock(a);
Task { loop { "klink".postln; 1.wait } }.play(t);
);

t.tempo = 1.3;
t.tempo = 0.5;
t.tempo = 1.0;


// 在 ProxySpace 中，可以将 TempoBusClock 与 ~tempo NodeProxy 一起添加：

p = ProxySpace.push(s);
p.makeTempoClock;
p.clock; // 现在 ProxySpace 的时钟是一个 TempoBusClock

~out.play;
~out = { Ringz.ar(Impulse.ar(~tempo.kr), [501, 500], 1/~tempo.kr) * 0.3 };
p.clock.tempo = 1.3;

// 模式与任务已同步：

~out2.play;
~out2 = Pbind(\dur, 1, \note, Pwhite(0, 7, inf));

p.clock.tempo = 3;
p.clock.tempo = 1;
