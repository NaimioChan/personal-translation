LinRand

偏斜随机数生成器。

UGen : AbstractFunction : Object

另请参阅：ExpRand、IRand、NRand、Rand、TExpRand、TIRand、TRand

说明

生成一个从 lo 到 hi 的线性分布随机浮点值，若 minmax < 0 则偏向 lo，否则偏向 hi。

类方法

LinRand.new(lo: 0.0, hi: 1.0, minmax: 0)

参数：

lo

输出范围的下限。

hi

输出范围的上限。

minmax

如果 minmax < 0，则输出偏向 lo，否则偏向 hi。

实例方法

示例

(
SynthDef("help-LinRand", { |out = 0, minmax = 1|
    Out.ar(out,
        FSinOsc.ar(
            LinRand(200.0, 10000.0, minmax),
            0, Line.kr(0.2, 0, 0.01, doneAction: Done.freeSelf))
    )
}).add;
)

// 向高方向
(
Routine({
    loop({
        Synth.new("help-LinRand"); 0.04.wait;
    })
}).play;
)

// 朝向 lo（目前还不能那样工作）
(
Routine({
    loop({
        Synth.new("help-LinRand", [\minmax, -1]); 0.04.wait;
    })
}).play;
)
