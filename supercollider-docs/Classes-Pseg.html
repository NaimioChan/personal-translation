Pseg

值的定时嵌入

Pstep : Pattern : AbstractFunction : Object

另请参阅：Ptime、Pstep、Env

说明

Pseg 使用与 Env 相同的参数，将时间函数定义为断点包络。这些模式可用于描述速度或动态变化，独立于表达它们的节奏模式（pattern）。

类方法

Pseg.new(levels, durs: 1, curves: 'lin', repeats: 1)

参数：

levels

一个返回各电平值的 Pattern。第一个电平是包络的初始值，其后所有值都是插值得到的。

durs

一个以拍为单位返回各段时长的 Pattern。

curves

一个 Symbol、Float 或由它们构成的 Array。决定各段落的形状。

repeats

一个数字。

可能的值为：

\step

平坦段。

\linear

\lin

线性段，即默认值。

\exponential

\exp

自然指数增长与衰减。在这种情况下，所有电平都必须非零且符号相同。

\sine

\sin

正弦 S 形分段。

\welch

\wel

形状像 Welch 窗两侧的正弦段。

\squared

\sqr

平方段。

\cubed

\cub

三次方段。

一个 Float

所有段的曲率值。0 表示线性，正数和负数使段向上和向下弯曲。

符号或浮点数的数组

每个段的曲率值。
