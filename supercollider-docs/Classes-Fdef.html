Fdef

惰性函数代理

Maybe : Ref : AbstractFunction : Object

另请参见：Maybe、LazyEnvir、Pdef、Tdef、Pdefn、Ndef

说明

Fdef 是函数的占位符。Fdef 允许在函数使用期间动态替换这些函数。

另请参阅：Maybe 和 JITLib 概述。

类方法

Fdef.new(key, val)

参数：

key

如果不存在具有此名称的实例，则创建一个新实例，否则返回现有实例。

val

如果给定了 Function，则用新函数替换旧函数。

未文档化的类方法

Fdef.all

Fdef.all = value

实例方法

示例

Fdef(\x, { 8 + 9 });

Fdef(\y, Fdef(\x) - 3);

Fdef(\y).value;

Fdef(\x, 3);

Fdef(\y).value;

Fdef(\x, { |x = 0| x });


Fdef(\x).value(8);

Fdef(\y).value(8);


z = Fdef(\x) * Fdef(\y) + { 1.0.rand };

z.value;
z.value(400);
// 声音示例
(
s.boot;
SynthDef("gpdef",
    { |out = 0, freq = 440, sustain = 0.05, amp = 0.1|
        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain), doneAction: Done.freeSelf) * amp;
        Out.ar(out, SinOsc.ar(freq, 0, env))
    }).add;
)

// 派生一个线程来播放一些声音
(
Fdef(\freq, 440);
Fdef(\dur, 0.2);

fork {
    loop {
        s.sendMsg("/s_new", "gpdef", -1, 1, 1, \freq, Fdef(\freq).value);
        Fdef(\dur).value.wait;
    }
};
)
