PartConv

实时分区卷积

UGen : AbstractFunction : Object

另请参见：Convolution、Convolution2、Convolution2L、Convolution3

说明

分区卷积。必须提供各种额外的缓冲区。

仅支持单声道脉冲响应！如果输入为多声道，则需要独立的 PartConv，每个声道一个。

但妙处在于：脉冲响应可以任意大（CPU 负载随 IR 大小增加。基于 fftsize 选择存在各种权衡，因为 FFT 更稀少但更大。此插件使用分摊（amortisation）来分散处理并避免尖峰）。

归一化因子难以预料；卷积会将输入的多个副本叠加在自身上，因此很容易过载。

类方法

PartConv.ar(in, fftsize, irbufnum, mul: 1.0, add: 0.0)

参数：

in

处理目标。

fftsize

频谱卷积的分区大小（分区大小的两倍）。你必须确保块大小能整除分区大小，并且每个分区至少有两个块（以便进行摊销）。

irbufnum

为脉冲响应的每个分区准备的频谱缓冲区。

mul

add

未文档化的类方法

PartConv.calcBufSize(fftsize, irbuffer)

PartConv.calcNumPartitions(fftsize, irbuffer)

实例方法

示例

// 准备工作；本质上是分配一个脉冲响应缓冲区，然后
// 遵循特殊的缓冲区准备步骤来设置插件所需的数据。
// 提供了不同的选项（已注释掉），用于从声音文件加载脉冲响应。
(

 // 4096 在我的机器上也能工作；1024 太频繁且摊销被过度推进，8192 则 FFT 负载更高
~fftsize = 2048;

s.waitForBoot {

    {
        var ir, irbuffer, bufsize;

        // // MONO ONLY
        // 预先存在的脉冲响应声音文件
        // （也可以使用任何通用声音文件来实现交叉合成效果）
        // irbuffer = Buffer.read(s, "/Volumes/data/audio/ir/ir2.wav");

        // 合成可敬的 'Dan Stowell' 脉冲响应

        ir = [1] ++ 0.dup(100) ++ (
            (1, 0.99998 .. 0)
            .collect { |f|
                f = f.squared.squared;
                f = if(f.coin) { 0 }{ f.squared };
                f = if(0.5.coin) { 0 - f } { f }
            } * 0.1
        );
        ir = ir.normalizeSum;

        irbuffer = Buffer.loadCollection(s, ir);

        s.sync;

        bufsize = PartConv.calcBufSize(~fftsize, irbuffer);

        // ~numpartitions = PartConv.calcNumPartitions(~fftsize, irbuffer);

        ~irspectrum = Buffer.alloc(s, bufsize, 1);
        ~irspectrum.preparePartConv(irbuffer, ~fftsize);

        s.sync;

        irbuffer.free; // 不再需要时域数据，只需要频谱版本
    }.fork;

}
)



~target = Buffer.read(s, ExampleFiles.child);

(
{
    var input = PlayBuf.ar(1, ~target, loop: 1);
    PartConv.ar(input, ~fftsize, ~irspectrum.bufnum, 0.5)
}.play
)


// 与实时输入进行卷积
(
{
    var input = SoundIn.ar(0);
    PartConv.ar(input, ~fftsize, ~irspectrum.bufnum)
}.play
)


// 应该能取回原始脉冲响应（每四秒一次）
(
{
    var input = Impulse.ar(0.25);
    PartConv.ar(input, ~fftsize, ~irspectrum.bufnum)
}.play
)


// 只在完成示例后释放缓冲区
// 如果你在 PartConv 仍在运行时释放，服务器不会崩溃，但 PartConv 输出会突然降为零
(
~irspectrum.free;
~target.free;
currentEnvironment.clear;
)
