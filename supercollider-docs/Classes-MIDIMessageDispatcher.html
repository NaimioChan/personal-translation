MIDIMessageDispatcher

MIDIFunc 和 MIDIdef 的默认调度器，设置为响应 noteOn、noteOff、control 和 polytouch 消息。

AbstractWrappingDispatcher : AbstractDispatcher : Object

参见：MIDIFunc、MIDIdef、AbstractWrappingDispatcher、AbstractDispatcher、MIDIMessageDispatcherNV、AbstractMessageMatcher、MIDIFuncSrcMessageMatcher、MIDIFuncChanMessageMatcher、MIDIFuncChanArrayMessageMatcher、MIDIFuncSrcMessageMatcherNV、MIDIFuncBothMessageMatcher、MIDIFuncBothCAMessageMatcher、MIDI

子类：MIDIMessageDispatcherNV、MIDISysDataDispatcher、MIDISysexDispatcher

说明

MIDIMessageDispatcher 用于将传入的 MIDI noteOn、noteOff、control 和 polytouch 消息分派给匹配的函数。通常用户不应直接创建或向此类的实例发送消息。

类方法

MIDIMessageDispatcher.new(messageType)

创建一个新实例。

参数：

messageType

一个 Symbol，指示消息类型，为 \noteOn、\noteOff、\control 或 \polytouch 之一。

返回值：

一个新的 MIDIMessageDispatcher。

实例方法

.messageType = value

获取该分发器的消息类型，为 \noteOn、\noteOff、\control 或 \polytouch 之一。

返回值：

一个 Symbol。

.getKeysForFuncProxy(funcProxy)

获取响应器函数的函数在此调度器的活动字典中所存储的键。这些键将是 MIDI 消息编号。

参数：

funcProxy

应返回其键的 MIDIFunc 或 MIDIdef。

返回值：

一个 Array，包含 funcProxy 的消息编号，类型为 Integer。

.value(src, chan, num, val)

尝试将传入的 MIDI 消息与此 dispatcher 的 responder 函数进行匹配，并对所有匹配项求值其函数。

参数：

src

MIDI 消息来源的 UID，为 Integer 类型。

chan

MIDI 消息的通道号，为 Integer 类型。注意其范围应为 0-15。

num

MIDI 消息的消息编号（例如音符编号等），为一个 Integer。注意这应在 0-127 的范围内。

val

MIDI 消息的消息值（例如 velocity 等），为一个 Integer。注意其应在 0-127 范围内。

.register

将此调度器添加到 MIDIIn 中合适的接收钩子上。

.unregister

将此分派器从 MIDIIn 中相应的接收钩子中移除。

.wrapFunc(funcProxy)

在需要时于内部被调用，以将函数包装到消息匹配器对象中。

参数：

funcProxy

要包装其函数的 MIDIFunc 或 MIDIdef 实例。

.typeKey

获取一个键，指示此分派器响应何种类型的消息，形式为：('MIDI ' ++ messageType).asSymbol。

返回值：

一个 Symbol。
