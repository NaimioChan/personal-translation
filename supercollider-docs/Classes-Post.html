Post

将文本发布到 post 窗口

Object

说明

Post 类是一个流目的地。它的主要用途是有时可以使代码更易读，并使执行略微更高效。

Post <<< a << " " <<< b << " " <<< c << " " <<< d << Char.nl;

vs

(a.asCompileString + b.asCompileString + c.asCompileString + d.asCompileString).postln;

警告： << 也表示对象左移。

类方法

Post.<<(item)

以字符串形式发布

Post << "string";

Post.<<<(item)

作为编译字符串发送

Post <<< "string";

Post.comma

打印一个逗号

Post.comma;

Post.space

打印一个空格

Post.space;

Post.nl

打印换行符

Post.nl;

Post.ff

打印字符 $\f

Post.ff;

Post.tab

打印一个制表符

Post.tab;

未文档化的类方法

Post.<<*(collection)

Post.<<<*(collection)

Post.close

Post.formats

Post.formats = value

Post.put(item)

Post.putAll(aCollection)

实例方法

示例

a = "a string";
b = 'a symbol';
c = 4;
d = [1, 2, 3, 4, a, b];

// 以字符串形式发布
Post << a << Char.nl;
// 作为编译字符串发布
Post <<< a << Char.nl;

// 以字符串形式发布
Post << d << Char.nl;
// 作为编译字符串发布
Post <<< d << Char.nl;

// 这等价于：
d.postln;
// or
d.asCompileString.postln;
