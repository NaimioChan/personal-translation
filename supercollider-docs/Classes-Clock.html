Clock

时钟的抽象父类

Object

参见：AppClock、SystemClock、TempoClock

子类：AppClock、SystemClock、TempoClock

说明

Clock 是一个抽象类：它只定义了一组所有时钟都应实现的抽象方法。具体实现请参见其子类：SystemClock、TempoClock、AppClock。

Scheduling

Clock 负责跟踪时间，并允许将 任务 调度到未来的某个时间（例如使用 sched、schedAbs 或 play 方法）。任务可以是任意 Object。当任务被调度的时间到达时，该任务被唤醒，即求值其 awake 方法。如果该方法返回一个数字，则任务会自动重新调度，新时间为上次调度时间加上返回值（以 beats 为单位）。

实用任务

不同类的对象可以通过拥有自己的 awake 方法实现，在响应被时钟调度时做出不同的行为。所有类都继承的 Object: -awake 方法只是调用同一对象的 next 方法，同时转发 beats 参数以及返回值，因此子类可以实现其中任意一个，就时钟调度而言效果相同。1

可在时钟上调度的有用对象示例：

  • Function: -awake 方法的实现方式是调用函数自身的 Function: -value 方法，从而有效地运行函数内的代码。
  • Routine: -awake 会调用自身的 Routine: -next，进而启动或恢复该例程的函数。
  • Stream 的一些子类的 next 方法除了返回流中的新值之外，还会做一些有用的事情。

调度与线程

每当一个任务被唤醒时，它的 awake 方法会在 主线程 的上下文中被调用。就在那之前，主线程的 逻辑时间 被设置为唤醒任务的调度时间，其 时钟 被设置为调度时钟。但请注意，如果该任务是 Routine，它随后会立即启动或恢复其 Function，并将自身设置为 当前线程。
