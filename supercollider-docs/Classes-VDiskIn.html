VDiskIn

以可变速率从文件流式输入音频

MultiOutUGen : UGen : AbstractFunction : Object

另请参见：PlayBuf、BufRd、DiskIn

说明

从磁盘连续播放较长的声音文件。这需要一个预加载了一个缓冲区大小的声音的缓冲区。

类方法

VDiskIn.ar(numChannels, bufnum, rate: 1, loop: 0, sendID: 0)

参数：

numChannels

通道数。必须是非零正整数。此值在编译 SynthDef 时固定，因此不能赋值给 SynthDef 参数。

bufnum

缓冲区编号

注意： Buffer 的 numFrames 必须是 2 的幂，建议至少为 65536——最好是 131072 或 262144。较小的缓冲区大小意味着更频繁的磁盘访问，这可能导致故障。

rate

控制播放速率。低于 4 的值可能没有问题，但值越高，磁盘活动越多，出现问题的可能性也越大。

警告： 速率确实有实际限制。必须满足以下条件：rate < Buffer 的大小 / (2 * s.options.blockSize)，例如使用典型默认值时，为 32768 / (2 * 64) = 256。

如果速率过高，UGen 将不会执行，并发布警告。

loop

如果 loop 设为 1，声音文件将循环播放。

sendID

如果给出了 sendID，则 UGen 每次重新加载缓冲区时都会发送一条 OSC 消息，其中包含此 ID 和相对于 Synth 起始点的帧索引：['/diskin', nodeID, sendID, frame]。进入文件的真实帧索引由读取初始缓冲区数据时给定的 startFrame 决定，使用 Buffer: -cueSoundFile 或 Buffer: -read。VDiskIn 无法访问用于提示缓冲区的帧索引。因此，OSC 发送的帧索引在 synth 节点开始时始终为 0。用户负责加上提示点：cueStartFrame + msg[3]。

讨论：

此 UGen 在播放完成时会设置 'done' 标志。

实例方法

示例

b = Buffer.cueSoundFile(s, ExampleFiles.apollo11, 0, 1);

x = { VDiskIn.ar(1, b, LFNoise2.kr(0.2).range(0.5, 2), loop: 1) }.play;

b.close;

// 再次
// 注意同名的实例方法，但参数不同
b.cueSoundFile(ExampleFiles.apollo11, 0);

x.free; b.close; b.free;


// 立即 cue 并播放
(
SynthDef("help-VDiskin", { |out, bufnum = 0|
    Out.ar(out, VDiskIn.ar(1, bufnum, MouseX.kr(0.5, 2.0)));
}).add;
)
(
x = Synth.basicNew("help-VDiskin");
m = { |buf| x.addToHeadMsg(nil, [\bufnum, buf]) };

b = Buffer.cueSoundFile(s, ExampleFiles.apollo11, 0, 1, completionMessage: m);
)

x.free; b.close; b.free;    // 清理



// 发送回文件位置。
// 注意：
// 该 ugen 对循环一无所知（应用取模）。
// 如果你加载另一个文件，需要释放缓冲区并重新分配它（见下文）

b = Buffer.cueSoundFile(s, ExampleFiles.apollo11, 0, 1, bufferSize: 4096);
c = SoundFile(ExampleFiles.apollo11).info;
x = { VDiskIn.ar(1, b, LFNoise2.kr(0.2).range(0.2, 0.9), 1, sendID: 14) }.play;

// 注册以接收此消息

(
o = OSCFunc({ |msg|
    var sendID = msg[2];
    var index = msg[3];
    msg.postln;
    "id: % pos: % frames (% sec)\n"
        .postf(sendID, index % c.numFrames, (index % c.numFrames / c.sampleRate));
}, '/diskin', s.addr)
);

x.free; b.close; b.free; o.free; // 最终清理

OSC 消息风格中的相同示例，请参阅 Node Messaging

// 分配一个磁盘 I/O 缓冲区
s.sendMsg("/b_alloc", 0, 65536, 1);

// 为此缓冲区打开一个输入文件，并保持打开
s.sendMsg("/b_read", 0, ExampleFiles.apollo11, 0, 65536, 0, 1);

// 创建 diskin 节点
s.sendMsg("/s_new", "help-VDiskin", x = s.nextNodeID, 1, 1);

s.sendMsg("/b_close", 0); // 关闭文件（非常重要！）


// 再次
// d 无需重新分配，Synth 仍在读取
s.sendMsg("/b_read", 0, ExampleFiles.apollo11, 0, 0, 0, 1);

s.sendMsg("/n_free", x); // 停止读取

s.sendMsg("/b_close", 0); // 关闭文件。

s.sendMsg("/b_free", 0); // 释放缓冲区
