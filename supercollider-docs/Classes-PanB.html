PanB

Ambisonic B-format 声像器。

MultiOutUGen : UGen : AbstractFunction : Object

另请参见：BiPanB2、DecodeB2、PanB2、Rotate2

说明

Ambisonic B 格式声像器。输出声道依次为 W、X、Y、Z。

类方法

PanB.ar(in, azimuth: 0, elevation: 0, gain: 1)

PanB.kr(in, azimuth: 0, elevation: 0, gain: 1)

参数：

in

输入信号。

azimuth

方位角，单位为弧度，-π 到 +π。

elevation

仰角，以弧度为单位，-0.5π 到 +0.5π。

gain

一个控制速率电平输入。

实例方法

示例

// 在立体声设置下，你只会听到前两个声道。
play({
    #w, x, y, z = PanB.ar(WhiteNoise.ar, LFSaw.kr(0.5, pi), FSinOsc.kr(0.31, 0.5pi), 0.3);
    // 解码为 4 个声道
    DecodeB2.ar(4, w, x, y, 0.5);
});
