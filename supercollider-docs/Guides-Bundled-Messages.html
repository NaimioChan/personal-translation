捆绑的服务器消息

发送 OSC 消息包

另请参阅：Scheduling and Server timing

在使用 Synth/Node/Group 这些 sclang 对象时，经常需要构造 bundle 来一起发送消息。例如，当你想要启动一个应当立即映射到某些总线的 synth，或者需要确保两个 synth 精确同步启动时。

处理这个问题的最简单方式是通过 Server 的自动打包支持。这允许你打开一个 bundle，所有 osc 消息都会被收集到其中，直到该 bundle 被发送。有关 makeBundle 参数的详细信息，请参见 Server。

s.boot;
(
// 向服务器发送合成器定义
SynthDef("tpulse", { arg out=0,freq=700,sawFreq=440.0;
    Out.ar(out, SyncSaw.ar(freq,  sawFreq,0.1) )
}).send(s);
)

// 下面包含的函数中生成的所有 OSC 命令将被添加到一个 bundle 中，
// 并在 2 秒后同时执行。
(
s.makeBundle(2.0, {
    x = Synth.new("tpulse");
    a = Bus.control.set(440);
    x.map(\freq, a);
});
)
x.free;

// 不要发送
(
b = s.makeBundle(false, {
    x = { PinkNoise.ar(0.1) * In.kr(0, 1); }.play;
});
)
// 现在将 b 作为预先存在的 bundle 传递，并同步启动两个合成器
(
s.makeBundle(nil, { // nil 会尽快执行
    y = { SinOsc.kr(0.2).abs }.play(x, 0, 0, \addBefore); // 正弦包络
}, b);
)
x.free; y.free;

要使用服务器的默认延迟发送 bundle，请使用消息 bind：

(
s.bind {
    SynthDef("tpulse2", { arg out=0, freq=700, sawFreq=440.0;
        Out.ar(out, Pan2.ar(SyncSaw.ar(freq,  sawFreq, 0.1), SinOsc.kr(8)) )
    }).send(s);
    s.sync; // 等待 synthdef 加载完成
    x = Synth.new("tpulse2");
    a = Bus.control.set(440);
    x.map(\freq, a);
};
)

a.free; x.free;

除此之外，还有许多方法会返回 OSC 消息，这些消息可以添加到 bundle 中。这些方法在 Node、Synth 和 Group 的帮助文件中有详细说明。

s.boot;
b = List.new;
c = Bus.control(s, 1).set(660);
x = Synth.basicNew("default", s); // 创建但不发送
b.add(x.newMsg);
b.add(x.mapMsg(\freq, c));
b.postln; // 这是它的样子
s.listSendBundle(1.0, b); // 1 秒后执行
c.set(440);
s.queryAllNodes;
x.free;
