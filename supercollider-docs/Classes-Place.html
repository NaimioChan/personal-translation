Place

子数组的交错嵌入

Pseq : ListPattern : Pattern : AbstractFunction : Object

参见：Ppatlace

说明

返回列表中的元素。如果某个元素本身是数组，那么它第一次出现时嵌入其第一个元素，第二次出现时嵌入第二个元素……第 n 次出现时嵌入第 n 个元素。
