LFPulse

脉冲振荡器

PureUGen : UGen : AbstractFunction : Object

另请参阅：LFSaw

说明

一个非带限脉冲振荡器。输出高值为一，低值为零。

类方法

LFPulse.ar(freq: 440.0, iphase: 0.0, width: 0.5, mul: 1.0, add: 0.0)

LFPulse.kr(freq: 440.0, iphase: 0.0, width: 0.5, mul: 1.0, add: 0.0)

参数：

freq

频率，单位为赫兹

iphase

初始相位偏移，以周期为单位 (0..1)

width

脉冲宽度占空比，从零到一。

mul

add

实例方法

示例

一个绘图：

{ LFPulse.ar(Line.kr(100, 800, 0.1)) }.plot(0.1);

50 Hz 波形：

{ LFPulse.ar(50) * 0.1 }.play;

调制频率：

{ LFPulse.ar(XLine.kr(1, 200, 10), 0, 0.2, 0.1) }.play;

幅度调制：

{ LFPulse.kr(XLine.kr(1, 200, 10), 0, 0.2) * SinOsc.ar(440) * 0.1 }.play;

同时用作振荡器和 LFO：

{ LFPulse.ar(LFPulse.kr(3, 0, 0.3, 200, 200), 0, 0.2, 0.1) }.play;

scope:

{ LFPulse.ar(500, 0, MouseX.kr, 0.5) }.scope;

与带限 Pulse UGen 比较：

(
{
    [
        Pulse.ar(100, 0.3, 0.5),

    ] * 0.2
