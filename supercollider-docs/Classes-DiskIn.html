DiskIn

从文件流式输入音频。

MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：PlayBuf、VDiskIn、DiskOut

说明

从磁盘连续播放较长的声音文件。这需要一个预加载了一个缓冲区大小的声音的缓冲区。

DiskIn 无法改变播放速率。关于带速率控制的磁盘流式 UGen，请参见 VDiskIn。

类方法

DiskIn.ar(numChannels, bufnum, loop: 0)

参数：

numChannels

通道数。必须与缓冲区中的通道数相匹配。必须是非零正整数。此值在编译 SynthDef 时固定，因此不能赋值给 SynthDef 参数。

bufnum

缓冲区编号

注意： Buffer 的 numFrames 必须是 2 的幂，建议至少为 65536——最好是 131072 或 262144。较小的缓冲区大小意味着更频繁的磁盘访问，这可能导致故障。

loop

如果设为 1，声音文件将循环播放。

注意： 如果缓冲区的帧数大于声音文件，则第一次循环与后续循环迭代之间会出现明显的间隙。在这种情况下，请选择更小的缓冲区大小，或改用 PlayBuf

讨论：

此 UGen 在播放完成时会设置 'done' 标志。

实例方法

示例

s.boot; // 启动服务器

// 下面的示例将使用这个 synthdef
(
SynthDef("help-Diskin", { |out, bufnum = 0|
    Out.ar(out, DiskIn.ar(1, bufnum));
}).add
)

常规用法（配合 Buffer；“对象风格”）

b = Buffer.cueSoundFile(s, ExampleFiles.apollo11, 0, 1);

x = { DiskIn.ar(1, b.bufnum) }.play;

b.close;

// 再次
// 注意同名的实例方法，但参数不同
b.cueSoundFile(ExampleFiles.apollo11, 0);

x.free; b.close; b.free;



// 循环播放它（为了更好地循环请使用 PlayBuf！）
(
p = ExampleFiles.apollo11;
a = SoundFile.new;
a.openRead(p);
d = a.numFrames/s.sampleRate; // 获取时长
a.close; // 不要忘记
b = Buffer.cueSoundFile(s, p, 0, 1);
f = { DiskIn.ar(1, b.bufnum) };
x = f.play;
r = Routine({
    loop({ d.wait; x.free; x = f.play; b.close(b.cueSoundFileMsg(p, 0)) });
}).play)
r.stop; x.free; b.close; b.free; // 你需要完成所有这些才能正确清理



// 立即 cue 并播放
(
SynthDef("help-Diskin", { |out, bufnum = 0|
    Out.ar(out, DiskIn.ar(1, bufnum));
}).add;
)

(
x = Synth.basicNew("help-Diskin");
m = { |buf| x.addToHeadMsg(nil, [\bufnum, buf.bufnum]) };

b = Buffer.cueSoundFile(s, ExampleFiles.apollo11, 0, 1, completionMessage: m);

)

OSC 消息风格

// 分配一个磁盘 I/O 缓冲区
s.sendMsg("/b_alloc", 0, 65536, 1);

// 为此缓冲区打开一个输入文件，并保持打开
s.sendMsg("/b_read", 0, ExampleFiles.apollo11, 0, 65536, 0, 1);

// 创建 diskin 节点
s.sendMsg("/s_new", "help-Diskin", x = s.nextNodeID, 1, 1);

s.sendMsg("/b_close", 0); // 关闭文件（非常重要！）


// 再次
// d 无需重新分配，Synth 仍在读取
s.sendMsg("/b_read", 0, ExampleFiles.apollo11, 0, 0, 0, 1);

s.sendMsg("/n_free", x); // 停止读取

s.sendMsg("/b_close", 0); // 关闭文件。

s.sendMsg("/b_free", 0); // 释放缓冲区
