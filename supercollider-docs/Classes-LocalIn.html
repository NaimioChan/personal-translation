LocalIn

定义并读取合成器本地的总线。

AbstractIn : MultiOutUGen : UGen : AbstractFunction : Object

参见：LocalOut

说明

LocalIn 定义的是局部于所属 synth 的总线。这些总线类似于全局总线，但如果你想实现一个使用反馈处理循环的自包含效果，它们会更方便。

每个 SynthDef 只能有一个音频速率和一个控制速率的 LocalIn。可以使用 LocalOut 将音频写入总线。

警告： 写入 LocalOut 的音频在下一次循环之前不会被相应的 LocalIn 读取，即在一个块大小的采样之后。因此，当使用 LocalIn 创建延迟时间短于音高阈值（即 < 0.05 秒或 > 20Hz）的反馈延迟，或需要采样精确对齐时，务必考虑这一额外延迟。参见下面的谐振器示例。

类方法

LocalIn.ar(numChannels: 1, default: 0.0)

LocalIn.kr(numChannels: 1, default: 0.0)

参数：

numChannels

要读取的通道数（即相邻的总线）。你不能通过在 SynthDef 中将其赋值给参数来调制这个数字。

default

一次性写入总线的初始值，以便在通过 LocalOut 覆盖它之前可以使用。可以传入一个数组，为每个通道指定不同的值。

实例方法

示例

(
{
    var source, local;

    source = Decay.ar(Impulse.ar(0.3), 0.1) * WhiteNoise.ar(0.2);
    local = LocalIn.ar(2) + [source, 0]; // 读取反馈，加到源上
    local = DelayN.ar(local, 0.2, 0.2); // 延迟声音

    // 反转声道以产生乒乓效果，并施加衰减因子
    LocalOut.ar(local.reverse * 0.8);

    local
}.play;
)

(
{
    var local, in;

    in = Mix.fill(12, {
        Pan2.ar(
            Decay2.ar(Dust.ar(0.05), 0.1, 0.5, 0.1)
                * FSinOsc.ar(IRand(36, 84).midicps).cubed.max(0),
            Rand(-1, 1))
    });
    in = in + Pan2.ar(Decay2.ar(Dust.ar(0.03), 0.04, 0.3) * BrownNoise.ar, 0);

    4.do { in = AllpassN.ar(in, 0.03, { Rand(0.005, 0.02) }.dup, 1) };

    local = LocalIn.ar(2) * 0.98;
    local = OnePole.ar(local, 0.5);

    local = Rotate2.ar(local[0], local[1], 0.23);
    local = AllpassN.ar(local, 0.05, { Rand(0.01, 0.05) }.dup, 2);

    local = DelayN.ar(local, 0.3, [0.19, 0.26]);
    local = AllpassN.ar(local, 0.05, { Rand(0.03, 0.15) }.dup, 2);

    local = LeakDC.ar(local);
    local = local + in;

    LocalOut.ar(local);

    local

}.play;
)

(
{
    var local, in, amp;

    in = SoundIn.ar([0, 1]);

    amp = Amplitude.kr(Mix.ar(in));
    in = in * (amp > 0.02); // 噪声门

    local = LocalIn.ar(2);
    local = OnePole.ar(local, 0.4);
    local = OnePole.ar(local, -0.08);

    local = Rotate2.ar(local[0], local[1], 0.2);

    local = DelayN.ar(local, 0.25, 0.25);

    local = LeakDC.ar(local);
    local = ((local + in) * 1.25).softclip;

    LocalOut.ar(local);
    local * 0.1;
}.play;
)

// 谐振器，必须减去 blockSize 才能正确调音
(
{
    var in, imp, sound;

    in = LocalIn.ar(1);
    imp = Impulse.ar(1);
    sound = DelayC.ar(imp + (in * 0.995), 1, 440.reciprocal - ControlRate.ir.reciprocal);
    LocalOut.ar(sound); // 用于反馈
    in
}.play;

// 比较音高
