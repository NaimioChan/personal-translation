基础实时编码技术

不使用 JITLib 的基本实时编码技术（“对象风格”）

更多内容即将推出..

使用一个简单的环境。这看起来与 ProxySpace 一样，但工作方式不同。关于差异，请参见 jitlib_basic_concepts_01 和 jitlib_basic_concepts_02。

d = (); // 创建一个新环境
d.push; // 将其推至当前值

// 此 synthdef 可以动态更改，但 synth 不会
// 因此改变。使用表达式 [1] 来替换给定的 synth
(
SynthDef(\x, { |out, freq = 440|
    Out.ar(out,
        Ringz.ar(Dust.ar(40), freq, 0.1)
    )
}).send(s)
)

// 发送第一个 synth：
~s1 = Synth(\x);

// [1]
// 现在你可以尝试这些代码行，以及上面的 synth def
~s1 = Synth.replace(~s1, \x, [\freq, 3000]);
~s1.set(\freq, 4000);

// 添加一个总线：

~b1 = Bus.control(s);
~b1.set(350);
~s1.map(\freq, ~b1);

// 将总线设置为不同的值：

~b1.set(100);
~b1.xline(800, 5);

~s3 = { Out.kr(~b1, MouseX.kr(300, 900, 1)) }; // 在运行中动态添加一些鼠标控制
~s3.free; // 再次移除它。



// 完成：

~b1.free;
d.clear;
d.pop;
