FSinOsc

快速正弦振荡器。

UGen : AbstractFunction : Object

另请参阅：SinOsc、SinOscFB

说明

非常快速的 sine 波发生器（每个输出采样仅需 2 条 PowerPC 指令！）使用振铃滤波器实现。它生成的 sine 波比查表振荡器干净得多，而且快得多。然而，波的幅度会随频率变化。一般来说，提高频率时幅度会下降，降低频率时幅度会上升。

警告： 在当前实现中，如果频率被某些交替信号调制，幅度可能会发散。

类方法

FSinOsc.ar(freq: 440.0, iphase: 0.0, mul: 1.0, add: 0.0)

FSinOsc.kr(freq: 440.0, iphase: 0.0, mul: 1.0, add: 0.0)

参数：

freq

频率，单位为赫兹。

注意： 虽然接受音频速率频率输入，但频率目前仅在内部以控制速率更新。

iphase

初始相位偏移。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

{ FSinOsc.ar(800) * 0.2 }.play;

{ FSinOsc.ar(XLine.kr(200, 4000, 1)) * 0.2 }.play;

// 末尾时振幅衰减
{ FSinOsc.ar(FSinOsc.ar(XLine.kr(4, 401, 8), 0.0, 200, 800)) * 0.2 }.play;
