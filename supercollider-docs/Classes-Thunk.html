Thunk

未求值的值

AbstractFunction : Object

子类：CallOnce、UGenThunk

说明

Thunk 意为“think 的过去式”，可用于某项计算可能需要在稍后某个时间点执行、也可能不需要，而其值会被多次使用的情况。这是惰性求值的一个例子，可用于避免不必要的计算并使状态不可变。

类方法

Thunk.new(function)

参数：

function

返回所需值的某个函数

实例方法

.value

返回该值。如果计算已完成，则使用先前的值，否则进行计算。

未文档化的实例方法

.clear

.didEvaluate

.valueArray

.valueArrayEnvir

.valueEnvir

示例

// 例如，随机值将只产生一个实例：
a = Thunk({ \done.postln; rrand(2.0, 8.0) });
a.value; // 发布 "done"
a.value;
// 它是一个 AbstractFunction，因此可以用于数学运算：

a = Thunk({ rrand(2.0, 8.0) });
b = a * 5 / (a - 1);
b.value;
// 惰性求值

a = Thunk({ \done1.postln; Array.fill(10000, { |i| i + 6 % 5 * i / 2 }) }); // 一些计算。
b = Thunk({ \done2.postln; Array.fill(10000, { |i| i + 5 % 6 * i / 3 }) }); // 一些其他计算。
c = [a, b].choose + 700;
(c * c * c).value; // 计算在这里进行，且仅进行一次。

// 与函数比较：

a = { \done1.postln; Array.fill(10000, { |i| i + 6 % 5 * i / 2 }) }; // 一些计算。
b = { \done2.postln; Array.fill(10000, { |i| i + 5 % 6 * i / 3 }) }; // 一些其他计算。
c = [a, b].choose + 700;
(c * c * c).value; // 计算在这里进行，但进行 3 次（针对每个 c）
