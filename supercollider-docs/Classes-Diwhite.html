Diwhite

Demand 速率白噪声随机生成器。

Dwhite : DUGen : UGen : AbstractFunction : Object

另请参阅：Dwhite、Demand、Duty、TDuty

说明

Dwhite 返回 lo 与 hi 之间连续范围内的数字。Diwhite 返回整数值。

参数可以是数字或任何其他 UGen。

参见 Pwhite、WhiteNoise 了解结构上相关的等价物。

类方法

Diwhite.new(lo: 0.0, hi: 1.0, length: inf)

来自父类：Dwhite

参数：

lo

最小值。

hi

最大值。

length

要创建的值的数量。

实例方法

示例

(
{
    var a, freq, trig;
    a = Diwhite(0, 15, inf);
    trig = Impulse.kr(MouseX.kr(1, 40, 1));
    freq = Demand.kr(trig, 0, a) * 30 + 340;
    SinOsc.ar(freq) * 0.1

}.play;
)
