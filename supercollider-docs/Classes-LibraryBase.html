LibraryBase

抽象全局存储类

MultiLevelIdentityDictionary : Collection : Object

子类：Archive、Library

说明

Library 和 Archive 的基类

只有一个全局实例：Archive.global 或 Library.global，它在子类中自动初始化。

子类责任

LibraryBase.clear

清空字典

LibraryBase.at( ... args)

通过键路径访问字典。键可以是任意对象，但通常是 Symbol。

LibraryBase.put( ... args)

在字典中按路径存储对象，路径以键的列表给出，要存储的对象作为最后一个参数。键可以是任意对象，但通常是 Symbol。

LibraryBase.atList(args)

按路径访问字典，路径以键的列表给出。键可以是任意对象，但通常是 Symbol。
