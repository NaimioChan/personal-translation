混音和声像时的电平补偿

在 SC 中混音和平移时的电平平衡

另请参阅：Pan2、PanAz、Splay、SplayAz、LevelComp

Considerations

多通道扩展 是 SuperCollider 的关键特性之一，它使探索复杂的复音合成和空间化变得容易。对这些信号进行混音和声像处理通常涉及从一定数量的输入通道转换到不同数量的输出通道，而有意义地调整信号幅度电平需要考虑两个方面：

1. 技术安全性：新信号的最大幅度会是多少？在最坏情况下，它们是否会使音频硬件削波（超过 +-1.0）？

2. 感知响度：相对于其他存在的信号，新信号应该有多响？

为了平衡这些方面，了解待混音/声像处理的信号会有帮助。SC 中的大多数 UGen 产生的信号振幅为 1.0，因此我们在这里的讨论中将使用该值。

相位相关程度：各个信号的瞬时峰值在时间上对齐的可能性有多大？两种边界情况分别是完全同相：所有声道上的信号相同，因此峰值始终对齐；以及完全随机相位：所有声道上都是不同的噪声信号，此时峰值在统计上极不可能对齐。大多数音乐信号都介于这两个极端之间，即在一定程度上相位相关。

等幅补偿是高度相关信号的安全选择：将总和除以通道数；等功率补偿通常用于弱相关信号，因为它通过将总和除以通道数的平方根来保持声能恒定。由于大多数音乐信号介于两个极端之间，因此在有疑问时，针对具体情况加以考虑和测试是合理的。

在声学文献中，此电平补偿因子称为 p 值 [1]，它可以推广如下：

~levelCompFactor = { |numChans=2, p_value=1|
    numChans ** p_value.clip(0, 1).neg
};
~levelCompFactor.value(2, 1); // 等幅，乘以 1/n
~levelCompFactor.value(2, 0.5); // 等功率，乘以 1/n 的平方根
~levelCompFactor.value(2, 0); // 保持满电平，不做电平缩放

以下是 Mixing 和 Panning 常见情况的一些示例。

将 M 个声道混合为 1 个

下混为单声道是展示不同电平补偿方法的最简单情形。用于此目的的 UGen 或函数有 Mix、sum、mean。

s.meter; s.scope;

n = 10;
// 10 个通道到 1 个，完全相干同相信号：
{ (SinOsc.ar ! n) }.plot;
{ (SinOsc.ar ! n).sum }.plot;       // sum : +-10
// 等幅：除以通道数 -> 峰值 1
{ (SinOsc.ar ! n).sum / n }.plot;   // sum
{ Mix.ar(SinOsc.ar ! n) / n }.plot; // 与 Mix.ar 相同
{ (SinOsc.ar ! n).mean }.plot;      // 均值直接除以 n！

// 10 个声道到 1 个，与 100Hz 共享根音准相干：
{ SinOsc.ar((1..n) * 100, 0.5pi) }.plot(0.05);

// 因为峰值恰好重合（相位偏移 0.5pi），
// 我们必须除以 n 以保持在 +-1 范围内：
{ SinOsc.ar((1..n) * 100, 0.5pi).sum / n }.plot(0.05);
{ SinOsc.ar((1..n) * 100, 0.5pi).sum / n }.play;

// 在同一范围内的随机频率下，信号的一致性较低
{ SinOsc.ar({ rrand(100.0, 1000.0).postln }! n, 0.5pi).sum / n }.play;

// 非常随机的相位信号
{ PinkNoise.ar(1 ! n) }.play;

// 比较单通道 ...
{ PinkNoise.ar }.play;

// 使用 n 到 1 的混音并进行等功率补偿：
// 音量相当相似，可能会削波，但非常罕见
{ PinkNoise.ar({ 1 } ! n).sum / n.sqrt }.play;

将 1 个声道声像定位到 2 个

Pan2 使用等功率声像：当声像位于中心时，两个信号均为 0.7，即 -3 dB

{ Pan2.ar(DC.ar(1), Line.kr(-1, 1, 0.1)) }.plot(0.1);
// 声像移动时响度似乎保持不变
{ Pan2.ar(PinkNoise.ar(0.2), SinOsc.kr(0.3)) }.play;

LinPan2 使用等幅声像：在中间时，两个信号均为 0.5。

{ LinPan2.ar(DC.ar(1), Line.kr(-1, 1, 0.1)) }.plot(0.1);
// 在中心位置时响度似乎略有下降
{ LinPan2.ar(PinkNoise.ar(0.2), SinOsc.kr(0.3)) }.play;

将 1 个声道声像定位到 N 个

PanAz 使用等功率声像定位，因此在默认宽度为 2 时，它保持能量恒定，与 Pan2 类似。

{ PanAz.ar(4, DC.ar(1), Line.kr(-1, 1, 0.1), orientation: 0) }.plot(0.1);

// 宽度越大，重叠越大，整体能量上升，
// 因此可能需要为更大的宽度补偿振幅
{ PanAz.ar(4, DC.ar(1), Line.kr(-1, 1, 0.1), width: 4, orientation: 0) }.plot(0.1);

将 M 个通道混音/声像定位到 2 个通道

Splay 使用 Pan2 将输入通道数组混合为立体声，并提供 3 种电平补偿选项：

s.meter; s.scope;

// levelComp 默认为 true，即等功率 -
// 为向后兼容而保持此方式。
{ Splay.ar(Saw.ar([20, 30, 50]), 1, levelComp: true) }.scope;
// 可以关闭 levelComp 以另行设置电平：
{ Splay.ar(Saw.ar([20, 30, 50]), level: 0.6, levelComp: false) }.scope;

// levelComp 可以是一个数字，介于 0.0 -> 无压缩，
// 和 1.0 -> 等幅压缩之间，其中 0.5 为等功率，
// 这允许通过指数手动进行微调：
{ Splay.ar(Saw.ar([100, 150, 250]), levelComp: 0.5) }.scope;

// 当 spread 设置得较低时，电平和峰值会升高；
// 最坏的情况是将所有输入声像定位到单个声道：
{ Splay.ar(Saw.ar([100, 150, 250]), spread: 0, center: 1, levelComp: 0.5) }.scope;

请注意，此 levelComp 因子会随通道数缩放，因此在试验改变通道数时，将其调到 0.5 到 1.0 之间效果会很好。

将 M 个通道混音/声像定位到 N 个通道

SplayAz 使用 PanAz 将 M 个输入通道的数组混合为 N 个输出；它有 3 个电平补偿选项：

s.meter; s.scope;

n = 10;
// levelComp 默认为 true，即等功率：
{ SplayAz.ar(4, Saw.ar({ exprand(100, 500) }! n), 1, levelComp: true) }.scope;
// levelComp 可以关闭以手动/凭听觉补偿：
{ SplayAz.ar(4, Saw.ar({ exprand(100, 500) }! n), level: (1/n).sqrt, levelComp: false) }.scope;

// 与 Splay 中一样，levelComp 可以是 0.0 到 1.0 之间的数字：0.0 -> 不补偿，
// 1.0 -> 等幅补偿，0.5 为等功率。
// 这允许通过 levelComp 指数手动微调：
// 需要 SplayAz 上的 PR
{ SplayAz.ar(4, Saw.ar({ exprand(100, 500) }! n), level: 0.5, levelComp: 0.7) }.scope;

// 当将 spread 设置得较低时，单个通道上的电平会升高：
{ SplayAz.ar(4, Saw.ar({ exprand(100, 500) }! n), level: 0.5, spread: 0, orientation: 0) }.scope;

// 最坏情况：全部声像到同一输出通道会增大：
{ SplayAz.ar(4, Saw.ar({ exprand(100, 500) }! n), level: 0.5) }.scope;

// 当 width 值较高时，整体输出电平也会上升，
// 因为每个通道被导向更多通道：
{ SplayAz.ar(4, Saw.ar({ exprand(100, 500) }! n), level: 0.5, width: 4) }.scope;
