PMOsc

相位调制振荡器对。

Object

说明

相位调制正弦振荡器对。

类方法

PMOsc.ar(carfreq, modfreq, pmindex: 0.0, modphase: 0.0, mul: 1.0, add: 0.0)

PMOsc.kr(carfreq, modfreq, pmindex: 0.0, modphase: 0.0, mul: 1.0, add: 0.0)

参数：

carfreq

载波频率，单位为每秒周期数。

modfreq

调制器频率，单位为每秒周期数。

pmindex

调制指数，表示调制器偏移与调制器频率之比。较高的值通常会产生更密集的频谱。

modphase

调制器相位的调制输入，单位为弧度。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

play({ PMOsc.ar(Line.kr(600, 900, 5), 600, 3, 0, 0.1) }); // 调制载波频率

play({ PMOsc.ar(300, Line.kr(600, 900, 5), 3, 0, 0.1) }); // 调制调制器频率

play({ PMOsc.ar(300, 550, Line.ar(0, 20, 8), 0, 0.1) }); // 调制索引
