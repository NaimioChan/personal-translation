PathName

文件和目录路径工具

Object

另请参阅：File、String

说明

PathName 是用于操作文件名和路径的工具类。它期望一个文件路径，并允许你访问该文件路径的各个部分。

注意： SC 中大多数操作文件的类通常期望路径是 String，而不是 PathName 的实例。使用 .fullPath 将 PathName 转换为大多数情况下所期望的 String。

类方法

PathName.new(path: "")

参数：

path

一个 String，通常包含一个或多个 / 作为文件夹分隔的典型标志。~ 将按照 String: -standardizePath 转换为你的完整主目录地址。

PathName.new("MyDisk/SC 2.2.8 f/Sounds/FunkyChicken");

PathName.tmp

PathName.tmp = value

获取或设置全局临时目录为 String。这被 Buffer 等使用。默认情况下这是 Platform.defaultTempDir。

实例方法

.fileName

只返回文件本身的名称，即完整路径中最后一个斜杠之后的所有内容。

(
var myPath;
myPath = PathName.new("MyDisk/SC 2.2.8 f/Sounds/FunkyChicken");
myPath.fileName.postln;
)

.fileNameWithoutExtension

返回文件本身的名称，不含文件扩展名。

.extension

返回文件扩展名，即 -fileName 中最后一个句点之后的全部内容。

.pathOnly

返回直至文件名本身为止的完整路径；即直到最后一个斜杠（含）为止的所有内容。例如将多个文件存放在同一文件夹中时，这很方便。

(
var myPath;
myPath = PathName.new("MyDisk/SC 2.2.8 f/Sounds/FunkyChicken");
myPath.pathOnly.postln;
)

.isAbsolutePath

.asAbsolutePath

.isRelativePath

.asRelativePath(relativeTo)

你必须已正确初始化 scroot 类变量，才能知道它是相对于什么！

.folderName

仅返回文件所在文件夹的名称；即倒数第二个和最后一个斜杠之间的所有内容。

(
var myPath;
myPath = PathName.new("MyDisk/SC 2.2.8 f/Sounds/FunkyChicken");
myPath.folderName.postln;
)

.fullPath

返回 PathName 包含的完整路径名。

(
var myPath;
myPath = PathName.new("MyDisk/SC 2.2.8 f/Sounds/FunkyChicken");
myPath.fullPath.postln;
)

.entries

返回由该路径所表示文件夹内的所有文件+文件夹的列表。

(
var myPath;
myPath = PathName.new("./");
myPath.entries.postln;
)

.files

返回此路径所表示文件夹中所有文件的列表。

(
var myPath;
myPath = PathName.new("./");
myPath.files.postln;
)

.folders

返回该路径所表示文件夹的所有子文件夹列表。

(
var myPath;
myPath = PathName.new("./");
myPath.folders.postln;
)

.isFile

返回一个 Boolean，指示该路径是否表示文件（而非文件夹）。

(
var myPath;
myPath = PathName.new("./");
myPath.isFile.postln;
)

.isFolder

返回一个 Boolean，指示该路径是否表示文件夹（而非文件）。

(
var myPath;
myPath = PathName.new("./");
myPath.isFolder.postln;
)

.filesDo(func)

遍历路径名中找到的所有文件，包括子文件夹中的文件。

(
var myPath;
myPath = PathName.new("./");
myPath.filesDo{ |afile| afile.postln };
)

.allFolders

返回 pathname 自身包含的所有文件夹名称的列表。

(
var myPath;
myPath = PathName.new("MyDisk/SC 2.2.8 f/Sounds/FunkyChicken");
myPath.allFolders.postln;
)

.diskName

如果 path 是绝对路径，返回磁盘名称；否则返回空字符串。

(
var myPath;
myPath = PathName.new("MyDisk/SC 2.2.8 f/Sounds/FunkyChicken");
myPath.diskName.postln;
)

( // 注意开头处的 /
var myPath;
myPath = PathName.new("/MyDisk/SC 2.2.8 f/Sounds/FunkyChicken");
myPath.diskName.postln;
)

+/+(path)

路径连接运算符——有助于避免不必要地重复斜杠。

(PathName("/somewhere") +/+ PathName("over/the/rainbow")).postln;
(PathName("/somewhere") +/+ PathName("/over/the/rainbow")).postln;

.endNumber

返回 PathName 末尾的数字。如果没有数字则返回零。

PathName("floating1").endNumber.postln;
PathName("floating").endNumber.postln;

.noEndNumbers

返回去掉末尾所有数字的 -fullPath。

PathName("floating1").noEndNumbers.postln;
PathName("floating").noEndNumbers.postln;

.nextName

通过在 PathName 末尾递增数字，或在没有数字时添加一个数字，为文件生成一个合理的下一个名称。这对于以连续名称录制文件很有用，例如，当你不想用当前名称覆盖现有文件时，可用于生成新的文件名。

PathName("floating34").nextName.postln;
PathName("floating").nextName.postln;
PathName("floating12_3A4X_56.7").nextName.postln;

示例

下面是一个使用许多实例方法的示例。只需选择任意文件即可查看其路径的所有部分。

(
FileDialog.new(
    { |ok, path|
    var myPathName;
    if (ok,
        {
            myPathName = PathName.new(path);

            "New PathName object:  ".postc;
            myPathName.postln;

            "fileName only:        ".postc;
            myPathName.fileName.postln;

            "path up to file only: ".postc;
            myPathName.pathOnly.postln;

            "folder Name:          ".postc;
            myPathName.folderName.postln;
        }
    )
    }
)
)

选择一个声音文件放入库中，使用其文件夹名和文件名。

(
FileDialog.new(
    { |ok, path|
    var myPathName, myFile;
    if (ok,
        {
            myPathName = PathName.new(path);

            // 从磁盘读取你的文件，例如一个 soundFile/

            myFile = SoundFile.new;
            if (myFile.openRead(path),
                {
                    Library.put(
                        [myPathName.folderName.asSymbol, myPathName.fileName.asSymbol],
                        myFile);
                    ("Check Library.global" + myPathName.folderName + "please.").postln;
                },
                { ("Could not read soundfile" + path ++ ".").postln }
            );
            myFile.close;
        }
    )
    }
)
)

将三个表保存在同一文件夹中。注意：对话框中选定的文件名会被忽略！文件始终命名为 table1、table2、table3。

(
var table1, table2, table3;

table1 = Wavetable.sineFill(1024, [1, 2, 3]);
table2 = Signal.newClear.asWavetable;
table3 = Wavetable.sineFill(1024, Array.rand(64, 0.0, 1.0));

FileDialog.new(
    { |ok, path|
    var myPathName, myPathOnly;
    if (ok,
        {
            myPathName = PathName.new(path);
            myPathOnly = myPathName.pathOnly;
            ("writing files tables1-3 to"+myPathOnly).postln;
            table1.write(myPathOnly ++ "table1");
            table2.write(myPathOnly ++ "table2");
            table3.write(myPathOnly ++ "table3");
        }
    )
    }
)
)
