NetAddr

网络地址

Object

另请参阅：OSCFunc

子类：BundleNetAddr

类方法

NetAddr.new(hostname, port)

创建新的网络地址。

注意： 要在内部发送消息，使用回环 IP："127.0.0.1"

参数：

hostname

一个 String，可以是 IP 地址（如 "192.168.34.56"）或主机名如 "otherHost.local"。

port

端口号，如 57110。

NetAddr.fromIP(addr, port)

使用整数 IP 编号创建新的网络地址。

NetAddr.langPort

获取 sclang 当前正在监听的端口（重新编译后可能会改变）。

NetAddr.localIP(network)

以 String 形式获取本地 IP 地址。

参数：

network

一个可选的 IP 字符串，用于选择特定网络。如果你的机器连接到多个网络，这可能很有必要。通常，你会使用路由器的 IP 地址，但它实际上可以是该网络内的任何地址。

NetAddr.localEndPoint(port, network)

获取一个带有本地 IP 地址和用户提供端口号的 NetAddr。

参数：

port

端口号。如果省略，则使用 sclang 端口。

network

可选的 IP 字符串，用于选择特定的网络。另请参阅 *localIP。

NetAddr.localAddr

获取一个与 localhost 以及 sclang 正在监听的端口相对应的 NetAddr。

NetAddr.disconnectAll

关闭所有 TCP 连接。

NetAddr.broadcastFlag

NetAddr.broadcastFlag = flag: true

获取或设置广播标志（是否可以发送广播消息）。

NetAddr.localIPs(family: 'all')

获取此计算机上的所有本地 IP 地址（NIC）。

参数：

family

一个符号，用于指定所需的地址族。

all

所有地址

ipv4

仅 IPv4 地址

ipv6

仅 IPv6 地址

all

所有地址

ipv4

仅 IPv4 地址

ipv6

仅 IPv6 地址

返回值：

一个 Array，包含所需地址族的所有本地 IP 地址。

NetAddr.matchLangIP(ipstring)

测试一个 IP 地址是否与任何本地 IP 地址匹配。另请参见 *localIPs。

参数：

ipstring

一个用于测试的 String，包含点分十进制表示法形式的 IP 地址（例如 "192.168.34.56"）。

返回值：

一个 Boolean，指示是否找到了匹配项。

NetAddr.connections

返回值：

一个 IdentityDictionary 的副本，包含所有打开的 TCP 连接。

实例方法

.sendMsg( ... args)

将参数列表转换为 OSC 消息，并在不带时间戳的情况下发送到 NetAddr。第一个参数是 OSC 地址，其余参数是 OSC 消息中的参数。如果省略 OSC 地址开头的 "/"，会自动补上一个。关于 sclang 对象如何转换为 OSC 消息的技术细节，请参见 OSC Communication 帮助文件。

n = NetAddr("localhost", 12345);
n = s.addr;

// 示例：发送符号、整数和一个浮点数
n.sendMsg('/s_new', \default, 2000, 0, s.defaultGroup.nodeID, \freq, 60.midicps);

// 初始正斜杠可以省略
n.sendMsg(\n_set, 2000, \gate, 0);

// 使用 performList 语法，你可以用数组来存储 OSC 消息
~msg = [\n_set, 2000, \gate, 0];
n.sendMsg(*~msg);

.sendBundle(time ... args)

向 addr 发送带时间戳的 bundle。

.sendRaw(rawArray)

向 addr 发送不带时间戳的原始消息。

.connect(disconnectHandler)

打开 TCP 连接。

参数：

disconnectHandler

当连接被关闭时调用（由客户端或服务器关闭）。

.disconnect

关闭 TCP 连接。

.ip

返回 IP 号（为 String）。

n = NetAddr("localhost", 57110);
n.ip;

.isLocal

测试此 NetAddr 的 ip 号是否与本机某个网卡的 ip 号或回环地址匹配。

返回值：

一个 Boolean。

示例

n = NetAddr("127.0.0.1", 57120); // 57120 是 sclang 的默认端口
r = OSCFunc({ |msg, time| [time, msg].postln }, '/good/news', n);

n.sendMsg("/good/news", "you", "not you");
n.sendMsg("/good/news", 1, 1.3, 77);


n.sendBundle(0.2, ["/good/news", 1, 1.3, 77]);

r.free;
n.disconnect;

// 注意，具有相同端口和 IP 的不同 NetAddr 对象是独立的。

r = OSCFunc({ "message arrived".postln }, '/x');

n = NetAddr("127.0.0.1", 57120);
n.sendMsg("/x")


u = NetAddr("127.0.0.1", 57120);
u.sendMsg("/x");

n.disconnect

u.sendMsg("/x");

r.free;
u.disconnect;
