Accessing

尽管可以更改定义 FunctionDef 的各个数组中的值，但不应这样做，除非你想让程序崩溃。

.code

获取字节码数组。

{ |a = 9, b = 10, c| a + b }.def.code;

.sourceCode

获取源代码字符串。

{ |a = 9, b = 10, c| a + b }.def.sourceCode.postcs;

.numArgs

返回函数的参数数量（元数）。

{ |a = 9, b = 10, c| a + b }.def.numArgs; // 3

.numVars

返回函数体中的变量数量。

(
{ |x|
    var y, z;
    x + y + z
}.def.numVars; // 2
)

.varArgs

返回函数是否具有省略号参数。

{ |a, b ... c| a + b * c }.def.varArgs; // true
{ |a, b, c| a + b * c }.def.varArgs; // false

.hasKwArgs

返回函数是否具有可变关键字参数

{ |a, b, c| a + b * c }.def.hasKwArgs; // false
{ |a, b ... c| a + b * c }.def.hasKwArgs; // false
{ |a ... b, c| a * b }.def.hasVarArgs; // true

.varArgsValue

返回函数具有多少组可变参数。0 表示没有，1 表示省略号参数，2 表示关键字参数。

{ |a, b, c| a + b * c }.def.varArgsValue; // 0
{ |a, b ... c| a + b * c }.def.varArgsValue; // 1
{ |a ... b, c| a * b }.def.varArgsValue; // 1

.hasVarArgs

返回函数是否具有任意类型的可变参数

{ |a, b, c| a + b * c }.def.hasVarArgs; // false
{ |a, b ... c| a + b * c }.def.hasVarArgs; // true
{ |a ... b, c| a * b }.def.hasVarArgs; // true

.context

获取所在的 FunctionDef 或 Method。

.findReferences(aSymbol, references)

返回对给定 symbol 的所有引用的列表。

.argNames

获取参数名称的 Symbol 数组。

{ |a = 9, b = 10, c| a + b }.def.argNames;

.prototypeFrame

获取参数和临时变量的默认值数组。

{ |a = 9, b = 10, c| a + b }.def.prototypeFrame;

.varNames

获取局部变量名符号的数组。

{ |a = 9, b = 10, c| var x = 9; a + b + x }.def.varNames;

.argumentString(withDefaultValues: true, withEllipsis: false, asArray: false)

返回一个包含所有参数名及其默认值的字符串，用于嵌入到字符串中。如果没有参数，则返回 nil。

{ |a = 9, b = 10, c| a + b }.def.argumentString; // "a = 9, b = 10, c"
{ "nothing to see here" }.def.argumentString; // nil

参数：

withDefaultValues

如果设置为 false，则不追加默认值

 // "a, b, c"
{ |a = 9, b = 10, c| a + b }.def.argumentString(withDefaultValues: false);

withEllipsis

如果设置为 true，则追加省略号字符（" ... "）

// "a = 9, b = 10 ... c"
{ |a = 9, b = 10 ... c| a + b }.def.argumentString(withEllipsis: true);
// "a = 9, b = 10, c"
{ |a = 9, b = 10 ... c| a + b }.def.argumentString(withEllipsis: false);

asArray

如果设为 true，则返回表示所有参数的数组对应的字符串。其他参数设为 false。

// "[a, b] ++ c"
{ |a = 9, b = 10 ... c| a + b }.def.argumentString(asArray: true);

.makeEnvirFromArgs

获取局部变量名符号的数组。

{ |a = 9, b = 10, c| a + b }.def.makeEnvirFromArgs;

生成字符串

.makeFuncModifierString(modifier)

返回一个字符串，该字符串可被解释为用于新函数的代码，该函数从接收者中提取参数。这可用于构建一个卫生宏，该宏返回带有有效关键字参数的函数，而不是像 { |...args| func.valueArray(args) } 那样仅匿名转发参数。

实现示例参见 Function: flop（如下所示）。

参数：

modifier

一个函数，表示所有参数数组的字符串被传递给它。它应返回一个可被解释的字符串。

// 基本用法
f = { |x, y| x.squared + y.squared }; // 一个函数
a = f.def.makeFuncModifierString({ |argString| "%.scramble".format(argString) });
a.interpret.value(4, 5)

// 作为宏使用：像 flop 中那样的多通道扩展
f = { |x, y = 1| if(x > 0) { 1 } { 0 } * y }; // 某个函数
// 生成一个函数体，其中有一个自由但尚未定义的变量 "func"
// -> "{ |x, y = 1| ([x, y]).flop.collect { |x| func.valueArray(x) } }"
a = f.def.makeFuncModifierString({ |str| str ++ ".flop.collect { |x| func.valueArray(x) }" });
// 将该主体包装成一个以 "func" 为参数的函数，并返回上面的函数
// 现在我们有了一个函数的有效代码：
// -> "{ |func| { |x, y = 1| [x, y].flop.collect { |x| func.valueArray(x) } } }"
b = "{ |func| % }".format(a);
// 将代码解释为函数
g = b.interpret;
// 将函数 f 传给 g，g 返回一个来自 a 的函数，其中 "func" 绑定到 f
h = g.value(f);
// 我们现在可以用 h 代替 f，但所有参数都经过多声道扩展：
f.([1, 0], [6, 7]); // 无法工作
h.([1, 0], [6, 7]); // [6, 0]
// 而新函数支持相同的关键字参数：
h.(x: (-2..2), y: (-2..2));

// 该方法 "flop" 中的函数实现了此功能
h = f.flop;
h.([1, 0], [6, 7]); // [6, 0]
