Select

从输入数组中选择输出。

PureUGen : UGen : AbstractFunction : Object

参见：SelectX、SelectXFocus、LinSelectX

说明

输出从输入数组中选择。

注意： 所有 UGen 都在持续运行。如果每个输入都耗费大量 CPU，这可能不是最高效的方式。

注意，该数组在编写 SynthDef 时是固定的，整个数组被嵌入到 SynthDef 文件本身中。对于小数组，这比从缓冲区读取更高效。

类方法

Select.ar(which, array)

Select.kr(which, array)

参数：

which

Integer index

array

信号的输入数组

实例方法

示例

(
SynthDef("help-Select", { |out = 0|

    var a, cycle;
    a = [
            SinOsc.ar,
            Saw.ar,
            Pulse.ar
        ];
    cycle = a.size  * 0.5;
    Out.ar(out,
        Select.ar(LFSaw.kr(1.0, 0.0, cycle, cycle), a) * 0.2
    )
}).play;

)

// 此处用作音序器：
(
SynthDef("help-Select-2", { |out = 0|

    var a, s, cycle;
    a = Array.fill(32, { rrand(30, 80) }).midicps;
    a.postln;
    cycle = a.size  * 0.5;

    s = Saw.ar(
            Select.kr(
                LFSaw.kr(1.0, 0.0, cycle, cycle),
                a
            ),
            0.2
    );
    Out.ar(out, s)
}).play;
)
