ContiguousBlock

表示一个整数地址范围

Object

另请参阅：ContiguousBlockAllocator

说明

ContiguousBlock 是由 ContiguousBlockAllocator 使用的一段地址范围（通常为 >= 0 的整数）。ContiguousBlockAllocator 在 Server 中用于管理缓冲区编号和音频/控制总线索引。

ContiguousBlock(10, 2) 跨越地址索引 10 和 11。

此外，ContiguousBlock 可被标记为已使用或空闲。参见 -used。

类方法

ContiguousBlock.new(start, size)

返回一个新实例。

参数：

start

块的起始地址。

size

start 之后要覆盖的地址数量。应至少为 1。

实例方法

.start

块的起始地址。

.size

块中覆盖的地址数量。

.address

start 的同义词。

返回值：

块的起始地址。

.lastAddress

此块中涵盖的最后一个地址：ContiguousBlock(10, 2).lastAddress 返回 11。

.nextAddress

紧接此块之后的起始地址。ContiguousBlock(10, 2).lastAddress 返回 12，因为紧跟此块之后的相邻块必须从地址 12 开始。

.used

.used = value

布尔值。true 表示该块正在使用中，false 表示该块可用。

.adjoins(block)

如果此块与参数接触或重叠，则回答 true；如果两个块之间存在间隙，则回答 false。

参数：

block

第二个 ContiguousBlock。

返回值：

Boolean.

Operations

.join(block)

给定两个相邻的块，将它们合并为单个块。如果这些块不相邻，则结果为 nil。

参数：

block

第二个 ContiguousBlock。

返回值：

一个新的 ContiguousBlock，横跨两个输入块的全部范围。

.split(span)

将一个 ContiguousBlock 分成两个新块。

参数：

span

第一个新块的大小。接收者块大小的剩余部分将被分配给第二个块。

返回值：

有三种返回情况：

接收者的大小 > 跨度

返回一个包含两个 ContiguousBlock 的数组，将原始地址空间进行划分。

接收者的大小 == span

返回一个数组，其中包含原始（相同的）块和用于第二个分区的 nil。

接收者的大小 < 跨度

返回 nil，因为原始地址空间无法被分割得比它自身更大。

示例

c = ContiguousBlock(10, 2);
d = ContiguousBlock(6, 3);
e = ContiguousBlock(6, 4);
f = ContiguousBlock(12, 1);
g = ContiguousBlock(14, 5);
h = ContiguousBlock(11, 4);


// .adjoins

c.adjoins(d)  // false: 6-8 then 10-11
c.adjoins(e)  // true: 6-9, 10-11
c.adjoins(f)  // true: 10-11, 12
c.adjoins(g)  // false: 10-11. 14-18
c.adjoins(h)  // true: overlap (10-11, 11-14)


// .join

// join 10-11 to 6-9, new block is 6-11
c.join(e)  // ContiguousBlock(6, 6, false)

c.join(d)  // nil，因为它们不相邻


// .split

// g 跨度为 14-18
// split(2) 第一份得到 14-15
// 第二份得到 16-18
g.split(2)  // [ContiguousBlock(14, 2, false), ContiguousBlock(16, 3, false)]

c.split(2)  // [ContiguousBlock(10, 2, false), nil]

f.split(2)  // 为 nil，因为 'f' 不够大
