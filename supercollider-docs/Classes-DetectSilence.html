DetectSilence

检测输入何时低于幅度阈值

Filter : PureUGen : UGen : AbstractFunction : Object

说明

当输入信号的绝对值在给定时间窗口内始终低于阈值时，输出 1。否则输出 0。如果输出从 0 变为 1，同时也会对 doneAction 求值。

// 在 Decay 已经足够安静并持续足够长时间后，这会释放
{ var signal = Decay.ar(Impulse.ar(0), 2, PinkNoise.ar(0.2)); DetectSilence.ar(signal, doneAction: Done.freeSelf); signal }.play;

如果输入信号在合成器持续时间的开始处从静音开始，那么 DetectSilence 将无限期等待，直到出现第一个声音后才开始监测静音。为避免输入可能一直为零而造成的挂起静音，你可以向其输入添加一个 Impulse.ar(0)。

DetectSilence 不区分带直流偏置的信号和响亮的信号。如果你的信号有直流偏置，应该用 LeakDC 包裹它。

警告： 对于多声道输入，DetectSilence 可能会很棘手！见下文。

类方法

DetectSilence.ar(in: 0.0, amp: 0.0001, time: 0.1, doneAction: 0)

DetectSilence.kr(in: 0.0, amp: 0.0001, time: 0.1, doneAction: 0)

参数：

in

输入信号。

amp

当输入低于此值足够长时间后，求值

doneAction 。

time

输入必须低于该阈值的最短持续时间

在此触发之前的 amp。

doneAction

一个表示 doneAction 的整数。参见

Done 以获取更多细节。

返回值：

如果检测到静音，此 UGen 输出 1，否则输出 0。

DetectSilence 与多个输入

向 DetectSilence 馈送多个输入时要小心，因为多通道扩展可能导致混乱的行为。这段代码

DetectSilence.ar([left, right] + Impulse.ar(0), doneAction: 2)

生成 两个 DetectSilences，当左声道或右声道变为静音时，外层 Synth 会自行释放。（Impulse.ar(0) 用于确保 DetectSilence 立即开始检测静音，而不是等待非静音出现。）

通常你希望同时检测两路输入的静音，那么有什么好办法把那个 OR 变成 AND 呢？解决方案不是把 (left + right) / 2.sqrt 相加，因为该求和可能存在相位抵消。相反，应使用 DetectSilence 的输出而非其 doneAction，并用 FreeSelf 来执行释放。回想一下，DetectSilence 在检测到静音时输出 1，否则输出 0。将多个 DetectSilence 的输出相乘，仅当所有 DetectSilence 都为 1 时才返回 1。因此，下面是当 left 和 right 首次同时静音时释放 Synth 的正确方案：

FreeSelf.kr(DetectSilence.ar([left, right] + Impulse.ar(0)).product)

也可以使用全波整流混合信号，以避免相位抵消问题（[left, right].abs.sum / 2.sqrt）。
