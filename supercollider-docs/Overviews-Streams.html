Pattern

模式类帮助文件

特定类

ListPatterns

  • ListPattern - 持有列表的抽象类

    • Pdfsm - 确定性有限状态机
    • Pfpar - （未文档化的类）
    • Pfsm - 有限状态机

    • Ppar - 并行嵌入事件流

      • Pgpar - 并行嵌入事件流并将每个放入其自己的组中

        • Pgtpar - 并行嵌入事件流，并将每个事件流放入各自的组中，带有时间偏移
      • Ptpar - 以时间偏移并行嵌入事件流
    • Prand - 从列表中随机选取值嵌入

    • Pseq - 按顺序嵌入列表中的值

      • Place - 子数组的交错嵌入
      • Ppatlace - 交错流
      • Pser - 按顺序将值嵌入列表
    • Pshuf - 按固定但随机的顺序依次嵌入列表中的值
    • Pslide - 在一个值列表上滑动并嵌入它们
    • Ptuple - 将一组流组合成一个由列表组成的流
    • Pwalk - 在嵌入的值列表上进行的一维随机游走
    • Pwrand - 嵌入从列表中随机选取的值
    • Pxrand - 嵌入从列表中随机选取的值

FilterPatterns

  • FilterPattern - 持有待修改模式的抽象类

    • FuncFilterPattern - 使用函数过滤模式的抽象类

      • Pcollect - 将函数应用于模式
      • Pfset - 在求值所提供的模式之前，将环境插入到事件原型中
      • Preject - 通过拒绝特定值来过滤源模式。
      • Pselect - 过滤源模式返回的值。
      • Pwhile - 当条件成立时，重复嵌入流

    • PAbstractGroup - （未记录类）

      • Pgroup - 启动一个新的组，并在该组中播放模式
      • PparGroup - 启动一个新的 ParGroup 并在该组中播放模式
    • Pavaroh - 对事件流应用升序和降序音阶
    • Pbindf - 通过将键绑定到值，将多个值模式绑定到一个现有事件流
    • Pbus - 通过将模式限制到一条总线来隔离该模式

    • Pclump - 一个模式，它接收另一个模式并将其值分组为数组。

      • Pflatten -（未文档化的类）
    • Pclutch - 采样并保持一个模式
    • Pconst - 约束值模式的求和
    • Pdiff - 返回所包含模式的当前值与先前值之间的差值
    • Pdrop - 跳过（丢弃）模式中的前 n 个事件

    • Pdup - 重复输入流的值

      • PdurStutter - 将一个值分割为 n 个相等的细分
      • Psubdivide - 将一个值划分为 n 个相等的细分

    • PfadeIn - 将事件模式淡入

      • PfadeOut - 使事件模式淡出

    • Pfin - 限制嵌入流中的事件数量

      • Pfinval - 限制嵌入流中的项目数量
    • PfinQuant -（未文档化的类）
    • Pfindur - 限制嵌入在流中的事件的总时长

    • Pfx - 向给定事件流的 synth 添加一个效果 synth

      • Pfxb - 为给定事件流中的 synth 添加一个效果 synth
    • Plag - （未文档化的类）
    • Plambda - 为封闭的流创建作用域（命名空间）

    • Pn - 重复嵌入一个模式

      • Pgate - 一种门控流，仅当特定事件键为真时才推进。
    • Pplayer - （未文档化的类）
    • Pprotect - 当线程中发生错误时求值一个函数
    • Prewrite - 用于自相似结构的 L-system 模式
    • Prorate - 按比例划分流
    • Pseed - 在子模式中设置随机种子

    • Pset - 设置某个键值的事件模式

      • Padd - 将值加到事件流中某个键的值上
      • Pmul - 与事件流中某个键的值相乘

      • Psetp - 设置某个键值的事件模式

        • Paddp - 将模式的每个值加到事件流中某个键的值上
        • Pmulp - 将模式中的每个值与事件流中某个键的值相乘

    • Psetpre - 在事件向上传递之前设置其中一个键的值

      • Paddpre - 将某个键的现有值进行累加的事件模式
      • Pmulpre - 在事件流中某个键的值被向上传递之前，与其相乘
    • Pspawn - 根据事件模式中的参数生成子模式

    • Pstretch - （未文档化的类）

      • Pstretchp -（未文档化的类）
    • Pstutter - 重复输入流的值

    • Psym - 使用符号模式来嵌入 Pdef

      • Pnsym - 使用符号模式嵌入 Pdefn

        • Pnsym1 - （未文档化的类）
      • Psym1 - （未文档化的类）
      • Ptsym - （未文档化的类）
    • Psync - 同步并限制模式时长
    • Ptrace - 打印出流的结果
    • Pwrap - 通过环绕来约束输出值的范围
