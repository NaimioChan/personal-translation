sclang 启动文件

类库编译完成后，解释器会查找位于 Platform.userConfigDir +/+ "startup.scd" 的文件，如果该文件存在，就执行其中的任何代码（这发生在 Main: -startup 内）。通过在此位置创建一个文件，你可以进行用户特定的自定义。

Linux

~/.config/SuperCollider/startup.scd，依据 xdg base directory 规范

macOS

~/Library/Application Support/SuperCollider/startup.scd

Windows

C:\\SuperCollider\\startup.scd（或类似路径，取决于 SuperCollider 的安装位置）

一个常见的例子是更改本地服务器和内部服务器的选项：

// 将以下代码放入该文件将导致在启动时
// 进行这些修改（另见：ServerOptions）

Server.local.options.numOutputBusChannels = 4;    // 更改输入和输出通道数
Server.local.options.numInputBusChannels = 4;
Server.internal.options.numOutputBusChannels = 4;
Server.internal.options.numInputBusChannels = 4;

Server.local.options.device = "Built-in Audio";    // 使用特定的声卡
Server.local.options.device = "MOTU Traveler";
Server.local.options.device = "TASCAM US-122";
Server.local.options.device = "Jack Router";
Server.local.options.device = nil;                // 使用系统默认声卡

Server.local.options.blockSize = 128; // 增加块大小（默认值为 64）
Server.internal.options.blockSize = 128;

Server.local.options.sampleRate = 96000; // 提高采样率（如果你的硬件支持）
Server.internal.options.sampleRate = 96000;
Server.internal.options.sampleRate = nil;    // 使用声卡当前选定的采样率

// 将标准归档路径更改为自定义路径：
Archive.archiveDir = "~/scwork".standardizePath;

// 将插孔端口连接到音频通道
"SC_JACK_DEFAULT_INPUTS".setenv("system");
"SC_JACK_DEFAULT_OUTPUTS".setenv("system");

当然，该文件必须只包含有效的 SC 表达式。
