Ptpar

并行嵌入事件流，带时间偏移

Ppar : ListPattern : Pattern : AbstractFunction : Object

参见：Ppar

说明

嵌入多个事件流，使它们组成一个单一的输出流，其中所有事件都按时间顺序排列，并为每个流提供一个全局 offset。当一个流结束时，其他流会进一步嵌入，直到所有流都结束。

类方法

Ptpar.new(list, repeats: 1)

来自父类：ListPattern

参数：

list

时间和模式的成对列表：[time, pat, time, pat ..]。

注意： 时间以拍为单位，取决于所用 TempoClock 的速度。

repeats

将整个模式重复 n 次。

实例方法

未文档化的实例方法

.initStreams(priorityQ)

示例

// 查看结果事件中的 delta 值
(
var a, b, c, t;
a = Pbind(\x, Pseq([1, 2, 3, 4]), \dur, 1);
b = Pbind(\x, Pseq([10, 20, 30, 40]), \dur, 0.4);
c = Ptpar([0.0, a, 1.3, b]);
t = c.asStream;
20.do({ t.next(Event.default).postln });
)

// 声音示例
(
var a, b;
a = Pbind(\note, Pseq([7, 4, 0], 4), \dur, Pseq([1, 0.5, 1.5], inf));
b = Pbind(\note, Pseq([5, 10, 12], 4), \dur, 1);
Ptpar([0.0, a, 1.3, b]).play;
)
