UnitTestScript

运行测试脚本

UnitTest : Object

另请参见：UnitTest、UnitTestResult

说明

为了确保方法正常工作，可以实现一个测试来保证正确的行为。

编写测试来阐明对象应如何响应是一种常见做法，从长远来看它可以避免不一致。

测试脚本就是简单的纯文本文件，以 _unittest.scd 结尾，并会被解释执行。脚本可以位于类路径中某个类的旁边，或位于其下一层文件夹中。如果它们返回一个函数，则会传入 UnitTestScript，从而可以调用 assert 等方法（参见 UnitTest）

UnitTestScript 模拟了 Method 的部分行为，以与 UnitTest 兼容。

示例

示例脚本

注意： 这应位于文件 myUnitTest_unittest.scd 中

{ |test|
    "Kant test".postln;
    "5 + 7 = ".post;
    (5 + 7).postln;
    test.assertEquals(5 + 7, 12, "five plus seven should always be twelve");
}

只运行测试脚本：

UnitTestScript.run;

这些脚本可在 GUI 中的 UnitTestScript 类下找到：

UnitTest.gui
