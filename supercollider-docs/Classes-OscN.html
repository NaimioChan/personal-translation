OscN

非插值波表振荡器。

PureUGen : UGen : AbstractFunction : Object

另请参阅：COsc、Osc、VOsc、VOsc3

说明

具有频率和相位调制输入的非插值波表查找振荡器。通常最好使用插值振荡器 Osc。

类方法

OscN.ar(bufnum, freq: 440.0, phase: 0.0, mul: 1.0, add: 0.0)

OscN.kr(bufnum, freq: 440.0, phase: 0.0, mul: 1.0, add: 0.0)

参数：

bufnum

缓冲区索引。缓冲区大小必须是 2 的幂。缓冲区不应使用 Wavetable 格式填充（b_gen 命令应将 wavetable 标志设为 false）。原始信号（未经 asWavetable 转换）可以保存到磁盘并加载到缓冲区中。

freq

频率，单位为赫兹。

phase

相位偏移或调制器，以弧度为单位。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

// 将下面的示例与插值 Osc 示例进行比较。

(
s = Server.local;
b.sine1(1.0/[1, 2, 3, 4, 5, 6], true, false, true);
b = Buffer.alloc(s, 512, 1);

SynthDef("help-OscN", { |out = 0, bufnum = 0|
    Out.ar(out,
        OscN.ar(bufnum, 500, 0, 0.5)
    )
}).play(s, [0, 0, 1, b.bufnum]);

)
b.free;



(
// 非插值——会有明显的伪影
// 调制 freq

s = Server.local;
b.sine1(1.0/[1, 2, 3, 4, 5, 6].squared, true, false, true);
b = Buffer.alloc(s, 512, 1);

SynthDef("help-OscN", { |out = 0, bufnum = 0|
    Out.ar(out,
        OscN.ar(bufnum, XLine.kr(2000, 200), 0, 0.5)
    )
}).play(s, [\out, 0, \bufnum, b.bufnum]);

)
b.free;

(
// 听起来与 Osc 示例非常不同
s = Server.local;
b = Buffer.alloc(s, 512, 1);
b.sine1([1.0], true, true, true);

SynthDef("help-OscN", { |out = 0, bufnum = 0|
    Out.ar(out,
        OscN.ar(bufnum,
            OscN.ar(bufnum,
                XLine.kr(1, 1000, 9),
                0,
                200,
                800),
            0,
            0.25)
    )
}).play(s, [\out, 0, \bufnum, b.bufnum]);

)
b.free;

(
// 调制相位
s = Server.local;
b = Buffer.alloc(s, 512, 1);
b.sine1([1.0], true, true, true);

SynthDef("help-OscN", { |out = 0, bufnum = 0|
    Out.ar(out,
        OscN.ar(bufnum,
                800,
                OscN.ar(bufnum,
                        XLine.kr(20, 8000, 10),
                        0,
                        2pi),
                0.25)
    )
}).play(s, [\out, 0, \bufnum, b.bufnum]);
)
b.free;


(
// 在缓冲区播放时更改它
s = Server.local;
b = Buffer.alloc(s, 4096, 1);
b.sine1(1.0/[1, 2, 3, 4, 5, 6], true, true, true);

SynthDef("help-OscN", { |out = 0, bufnum = 0|
    Out.ar(out,
        OscN.ar(bufnum, [80, 80.2], 0, 0.2)
    )
}).play(s, [\out, 0, \bufnum, b.bufnum]);
)

(
Routine({
    var n = 32;
    50.do({
        b.sine1(Array.rand(n, 0, 1).cubed, true, true, true);
        0.25.wait;
    });
}).play;
)
b.free;
