AbstractResponderFunc

响应器函数对象的抽象父类

Object

另请参见：OSCFunc、OSCdef、MIDIFunc、MIDIdef、AbstractDispatcher

子类：HIDFunc、MIDIFunc、OSCFunc

说明

AbstractResponderFunc 是响应器函数的抽象父类；响应器函数是注册一个或多个函数以响应某类输入的类。它提供了一些通用功能，例如内省。它的两个主要子类是 OSCFunc 和 MIDIFunc。默认情况下，响应器函数在 Cmd-. 之后不会继续存在（见下文 -permanent）。

实例会注册到一个调度器（AbstractDispatcher 子类的实例），该调度器实际上会将传入的消息分发给实例的 Function。

类方法

AbstractResponderFunc.allFuncProxies

获取此类的所有具体子类的当前实例，按类型排序。

返回值：

一个 IdentityDictionary。

AbstractResponderFunc.allEnabled

与上述所有 funcProxy 相同，但仅返回当前正在监听输入的实例。

返回值：

一个 IdentityDictionary。

AbstractResponderFunc.allDisabled

与上述所有 allFuncProxies 相同，但只返回当前未在监听输入的实例。

返回值：

一个 IdentityDictionary。

实例方法

.func

获取或设置此对象的响应函数。

返回值：

获取器返回一个 Function 或类似对象。

.srcID

获取此对象的源码。

返回值：

返回类型取决于子类。对于 OSCFunc 将是 NetAddr，对于 MIDIFunc 则是 UID。此值可以为 nil，表示该对象将响应任何来源。

.enabled

检查此对象当前是否正在响应传入的消息。

返回值：

一个 Boolean。

.dispatcher

设置此对象的调度器。这是将传入消息与响应函数进行匹配的对象。实例可以使用自定义调度器以支持任意的匹配方案。

返回值：

一个合适的 AbstractDispatcher 子类的实例。（返回类型取决于子类。）

.permanent

.permanent = bool

获取或设置当用户执行 Cmd-. 时该响应器函数是否保留。若为 false，它将被禁用并从全局列表中移除。默认为 false。

参数：

bool

一个 Boolean，指示此对象是否为永久性的。

返回值：

getter 返回一个 Boolean。

.enable

启用此对象以接收传入消息。这在创建时会自动完成。

.disable

阻止此对象接收传入消息。

.add(newFunc)

向函数列表添加一个新函数，当此对象收到传入消息时将执行该函数。

参数：

newFunc

要添加的一个 Function 或类似对象。

.remove(removeFunc)

从此对象接收到传入消息时将执行的函数列表中移除一个函数。

参数：

removeFunc

要移除的 Function。

.gui

打开特定于子类的 GUI。（尚未实现）

返回值：

GUI 对象。

.oneShot

指示此对象应只执行一次，然后释放自身。

.fix

-permanent 的同义词

.free

禁用此对象并将其从全局列表中移除。当你不再使用此对象时，应执行此操作。

.clear

从此对象的函数列表中移除所有活动函数。

示例

参见 OSCFunc 和 MIDIFunc。
