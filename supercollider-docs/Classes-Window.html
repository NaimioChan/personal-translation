Window

视图的顶层容器

说明

Window 是 GUI 最基本的元素。它在屏幕上占据一个矩形空间，其他 GUI 元素（View）在其中显示。

通过将窗口传递给视图的构造函数，可将子视图添加到窗口中。参见 View: *new。

注意： 窗口、视图和容器之间没有区别；View 可以直接显示在屏幕上，也可以包含其他视图。因此，对于 Window 的视觉描述以及其他 GUI 工具包中大多数 Window 专属的方法，也适用于 Qt 中的 View 并成为其一部分，因而被其所有子类共享。在 Qt GUI 中提供 Window 类既是为了兼容性也是为了便利：例如，与 View 不同，Window 默认会创建在屏幕中央，并且可以使用其构造函数参数方便地控制各个方面。

Window 通常在其顶端边缘绘制一个栏，用于显示窗口标题，你可以在构造函数中设置该标题，或使用 -name。

类方法

.new

创建一个新的 Window 实例。你需要对其调用 -front 才能使其可见。

参数：

name

用于在标题栏中显示文本的 String。默认值为 'panel'。

bounds

一个 Rect，指定窗口的位置和大小。大小不包括边框和标题栏。位置从屏幕左下角开始测量（这与 View: -bounds 不同）。默认大小为 400x400，位置为 128x64，但在 Qt 中窗口默认位于屏幕中央。

resizable

一个布尔值，表示此窗口是否可由用户调整大小。默认为 true。

border

一个布尔值，表示此窗口是否有边框。无边框窗口没有标题栏，因此只能在代码中关闭。默认为 true。

scroll

一个布尔值，指示此窗口在其内容超出边界时是否会添加滚动条。如果设置为 true，则对于包含的视图，将忽略 View: -resize 设置。默认值为 false。

.allWindows

所有现有 Window 实例的数组。

.closeAll

对所有现有 Window 实例调用 -close。

.initAction

每当实例化新 Window 时求值的默认动作对象。

.screenBounds

返回一个以像素为单位的屏幕大小的 Rect

.availableBounds

返回一个 Rect，描述窗口实际可占据的屏幕区域（即排除 Mac 程序坞、任务栏或类似元素）。

实例方法

视图层级

.view

当创建一个 Window 时，它会创建一个容器视图，可通过此方法访问，该视图占据窗口的整个区域，并将作为子控件的实际父级。

返回值：

一个 View。

.asView

等价于 -view

.currentSheet

注意： 仅在 Cocoa GUI 中

returns: 附加到此窗口的当前模态表单（如果存在）。参见 "SCModalSheet".help。

Visibility

.front

在屏幕上显示窗口（这与将 -visible 设置为 true 的效果相同）。

.minimize

隐藏窗口，仅在其在 dock、任务栏等中的表示中保留它。

.unminimize

在窗口被最小化后恢复其先前状态。

.fullScreen

将窗口显示为全屏。

.endFullScreen

在显示为全屏后恢复窗口的先前状态。

.alwaysOnTop

窗口是否应始终停留在其他窗口之上，即使它不是活动窗口。

参数：

一个布尔值。

.visible

窗口是否可见。

将其设置为 true 与 -front 效果相同，将其设置为 false 会关闭窗口但不销毁它。

参数：

一个布尔值。

.close

关闭并销毁窗口。

.isClosed

返回值：

一个 Boolean，表示视图是否已关闭。

Geometry

.bounds

窗口的位置和大小。位置相对于屏幕左下角。

参数：

一个被解释为 as Rect 的 Rect 或 Point。

返回值：

一个 Rect。

.setTopLeftBounds

一个便捷方法，与 -bounds 不同，它通过从屏幕左上角测量位置来设置 bounds，并在垂直方向上偏移 menuSpacer。

参数：

rect

一个 Rect。

menuSpacer

以像素为单位的整数数量。

.setInnerExtent

调整窗口大小，保持其位置不变。

这等价于在 -view 上调用 View: -resizeTo。

参数：

w

以像素为单位的整数宽度。

h

以像素为单位的整数高度。

.sizeHint

重定向到View: -sizeHint的-view。

.minSizeHint

重定向到 View: -minSizeHint（属于 -view）。

.addFlowLayout

一个便捷方法，将 -view 的 decorator 设置为 FlowLayout 的新实例。参见 FlowLayout 获取示例。

参数：

margin

一个 Point，描述 FlowLayout 的 margin。

gap

一个 Point，描述 FlowLayout 的 gap。

返回值：

新的 FlowLayout 实例。

.layout

重定向到 -view 的 View: -layout。

Appearance

.name

窗口的标题。

参数：

一个 String。

.background

窗口的背景颜色。

参数：

一个 Color。

.alpha

窗口的透明度。

参数：

一个介于 0.0（不可见）和 1.0（不透明）之间的 Float。

.refresh

重绘窗口及其所有子元素。

Interaction

.userCanClose

用户是否可以关闭窗口。默认为 true。

参数：

一个布尔值。

.acceptsClickThrough

窗口不在最前面时是否接收点击。默认值为 true。

参数：

一个布尔值。

.acceptsMouseOver

窗口及其所有子视图是否接收鼠标悬停事件。默认值为 false。

另请参见：View: -acceptsMouseOver 和 View: -mouseOverAction。

参数：

一个布尔值。

动作与钩子

.drawFunc

与 UserView 一样，可以为窗口提供一个 Function，每当窗口被要求重绘自身时对其求值，因此你可以使用 Pen 类在窗口上绘制。参见 UserView: -drawFunc 了解说明。

参数：

一个函数。

.toFrontAction

当窗口变为活动窗口时求值的 action 对象。

.endFrontAction

当窗口不再是活动窗口时求值的动作对象。

.onClose

窗口关闭时要执行的动作对象。

.addToOnClose

向 -onClose 添加一个对象，如果当前值还不是数组，则将其包装为 Array。

.removeFromOnClose

从 -onClose 中移除一个对象，如果后者是一个数组。

示例

添加视图

(
var w;
w = Window("my name is... panel", Rect(128, 64, 340, 360));

32.do({ |i|
    b = Button(w, Rect(rrand(20, 300), rrand(20, 300), 75, 24));
    b.states = [["Start "++i, Color.black, Color.rand],
        ["Stop "++i, Color.white, Color.red]];
});
w.front;
)

使用 Decorator

(
var w;
w = Window("my name is... panel", Rect(128, 64, 340, 360));

w.view.decorator = FlowLayout(w.view.bounds);
// w.addFlowLayout; // 你也可以写这一行来代替上面那行

w.view.background = Color(0.6, 0.8, 0.8);
32.do({ |i|
    b = Button(w, Rect(rrand(20, 300), rrand(20, 300), 75, 24));
    b.states = [["Start "++i, Color.black, Color.rand],
        ["Stop "++i, Color.white, Color.red]];
});

w.front;
)

设置边界

// 使用 screenbounds 从顶部进行精确定位
(
x = Window.new("test", Rect(100, Window.screenBounds.height-180, 300, 100)); x.front;
)

// bounds.top 指的是窗口的底边，
// 从屏幕底部测量。与 View 中不同。
x.bounds_(Rect(100, 400, 300, 300));

无边框窗口

w = Window.new(border: false).front; // 无法手动关闭
w.close; // 所以在代码中关闭它

带滚动条的窗口

(
w = Window(scroll: true); // 必须在创建窗口时设置此项
c = Slider2D(w, Rect(0, 0, 1500, 300));
d = Slider(w, Rect(0, 310, 20, 300));
c.background = Color.grey.alpha = 0.6;
d.background = Color.grey.alpha = 0.6;
w.front;
)

onClose

(
x = Window.new.front;
x.alpha = 0.8;
x.onClose_({ y = Synth.new(\default) }); // 关闭窗口，合成器便会播放
)
x.close;
y.free;

使用布局

布局用于自动组织视图尺寸。参见：Layout Management。

注意： 仅在 Cocoa GUI 中

// 创建一个窗口和一个布局
(
w = Window(bounds: Rect(700, 200, 200, 200));
h = HLayout();
v = VLayout(h);
w.layout =  v;
w.front;
w.alwaysOnTop = true;
)

// 逐步添加视图

v.add(k = Slider());
h.add(Slider());
h.add(Slider());
k.orientation = \horizontal;


h.add(g = VLayout(), 2, \left);
g.add(TextView());
g.add(TextView().string_("sand and hand"));

v.add(Button());
v.add(Button());
v.add(Button());
g.add(Button());

g.margins = [1, 1, 1, 1];
h.margins = [1, 1, 1, 1] * 23;
v.margins = [1, 1, 1, 1] * 5;

h.add(g = VLayout(), 1, \left);
g.add(g = HLayout(), 1, \left);
5.do { g.add(Slider().orientation_(\vertical)) };

使用 Pen 在 Window 上绘图

(
var w, much = 0.02, string, synth;

w = Window.new("gui", Rect(100, 100, 300, 500)).front;
w.view.background_(Color.new255(153, 255, 102).vary);

string = "gui ".dup(24).join;

w.drawFunc = Routine {
    var i = 0;
    var size = 40;
    var func = { |i, j| sin(i * 0.07 + (j * 0.0023) + 1.5pi) * much + 1 };
    var scale;
    var font = Font("Helvetica", 40).boldVariant;
    loop {
        i = i + 1;
        Pen.font = font;
        string.do { |char, j|

            scale = func.value(i, j).dup(6);

            Pen.fillColor = Color.new255(0, 120, 120).vary;
            Pen.matrix = scale * #[1, 0, 0, 1, 1, 0];
            Pen.stringAtPoint(char.asString,
                ((size * (j % 9)) - 10) @ (size * (j div: 9))
            );
        };
        0.yield // 停在这里，返回一些不重要的东西
   }
};

{ while { w.isClosed.not } { w.refresh; 0.04.wait } }.fork(AppClock);

w.front;

)
