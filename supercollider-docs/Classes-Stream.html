Stream

Stream 是定义流的类的父类

AbstractFunction : Object

参见：Routine、FuncStream、EventStreamPlayer

子类：BinaryOpStream、BinaryOpXStream、CleanupStream、EmbedOnce、

说明

Stream 是一个抽象类，不直接使用。以下内容尝试记录 Stream 在音乐生成中使用的一些方面。

Overview

流表示通过重复的 next 消息逐步获取的一系列值。流可以通过 reset 消息重新启动。（并非所有流实际上都实现了 reset 语义。）

类 Object 定义了 next 以返回对象自身。因此，每个对象都可以被视为一个流，而大多数对象只是流式返回自身。

在 SuperCollider 中，流主要用于处理文本和生成音乐。

FuncStream(nextFunction, resetFunction)

Function 定义了一个由该 Function 本身构成的流，而 FuncStream 定义了一个由对其 nextFunction 的求值构成的流。

// 示例 1：Function 与 FuncStream 的对比
(
    f = { 33.rand };
    x = FuncStream(f);
    10.do({ [f.next, x.next].postln });
)
// 示例 2：reset 函数
(
    f = { 33.rand };
    x = FuncStream(f, { thisThread.randSeed_(345) });
    x.reset;
    10.do({ [f.next, x.next].postln });
    x.reset;
    10.do({ [f.next, x.next].postln });
)

Routine(nextFunction, stacksize)

在 FuncStream 中，nextFunction 会为流中的每个元素运行至完成。在 Routine 中，nextFunction 通过 yield 返回值，并在（收到 next 消息时）从 yield 之后的表达式处恢复执行。这使得函数定义中的一系列表达式可以表示一系列不同的事件，就像一份乐谱。

// example
(
    x = Routine({
        1.yield;
        2.yield;
        3.yield;
    });
    4.do({ x.next.postln });
)

一旦 nextFunction 执行完毕，例程就只是反复 yield nil。控制结构（例如 do 或 while）可以在 nextFunction 内使用，其方式类似于乐谱中的反复记号。

// example
(
    x = Routine({
        4.do({
            [1, 2, 3, 4].do({ |i| i.yield });
        });
    });
    17.do({ x.next.postln });
)

播放流

因为流对 value 消息的响应类似于函数，所以它们可以用作调度任务。

// 比较：
// 一个函数，返回 0.5
(
SystemClock.sched(0.0,
    { "***".postln; 0.5 }
);
)

// 一个流，返回 0.5 和 0.1
(
SystemClock.sched(0.0,
    Routine({ loop {
        "***".postln; 0.5.yield;
        "_*_".postln; 0.1.yield;
    } });
);
)

// 这就是为什么 'wait' 对数字的作用与 'yield' 相同
(
SystemClock.sched(0.0,
    Routine({ loop {
        "***".postln; 0.5.wait;
        "_*_".postln; 0.1.wait;
    } });
);
)

返回数字的流可以直接通过 play 消息播放。

// 在下一拍播放，偏移量为 0.4
(
Routine({ loop {
    "***".postln; 0.5.wait;
    "_*_".postln; 0.1.wait;
} }).play(quant: [1, 0.4]);
)

返回 Events 的流需要被包装在 EventStreamPlayer 中。Event 的 delta（也可以通过 dur 设置）被用作调度节拍值：

// 在下一拍播放，偏移量为 0.4
(
Routine({ loop {
    "///".postln; (delta: 0.5).yield;
    "_/_".postln; (delta: 0.1).wait;
} }).asEventStreamPlayer.play;
)

Iteration

方法 -do 通过迭代流的全部内容来有效地“播放”流。

以下消息通过以某种方式过滤另一个流来创建流：-collect、-reject、-select、-dot、-interlace、-appendStream、-embedInStream、-trace。

复合流

例程可以相互嵌入，使用 -embedInStream：

// example
(
x = Routine({
    2.do({
        [1, 2, 3, 4].do({ |i| i.yield });
    });
});
y = Routine({
    100.yield;
    30.yield;
    x.embedInStream;
    440.yield;
    1910.yield;
});
17.do({ y.next.postln });
)

例程可以像流一样被连接：

(
x = Routine({
    2.do({
        [1, 2, 3, 4].do({ |i| i.yield });
    });
});
y = Routine({
    100.yield;
    30.yield;
});
z = x ++ y;
17.do({ z.next.postln });
)

例程可以用组合运算符 <> 进行组合

(
x = Routine({ |inval|
    2.do({
        [1, 2, 3, 4].do({ |i|
            if(inval.isNil) { nil.alwaysYield };
            inval = (i * inval).yield;
        });
    });
});
y = Routine({
    100.yield;
    30.yield;
    4.do { 1.0.rand.yield };
});
z = x <> y;
17.do({ z.value.postln }); // 在此处调用 .value，因为这是一个函数。
)

复合流可以定义为使用一元和二元消息对流的组合。

一元消息

流支持 AbstractFunction 中定义的大多数一元消息：

(
a = Routine({ 20.do({ 33.rand.yield }) });
b = Routine({ [-100, 00, 300, 400].do({ |v| v.yield }) });

c = b.neg; // 定义一个复合流

// 枚举并执行所有的一元消息：
[
    \neg, \reciprocal, \bitNot, \abs, \asFloat, \asInteger, \ceil,
    \floor, \frac, \sign, \squared, \cubed, \sqrt, \exp, \midicps,
    \cpsmidi, \midiratio, \ratiomidi, \ampdb, \dbamp, \octcps,
    \cpsoct, \log, \log2, \log10, \sin, \cos, \tan, \asin, \acos, \atan,
    \sinh, \cosh, \tanh, \rand, \rand2, \linrand, \bilinrand, \sum3rand,
    \distort, \softclip, \coin, \even, \odd, \isPositive, \isNegative,
    \isStrictlyPositive
]
.do({ |msg|
    postf("\n msg: % \n", msg);
    b.reset.perform(msg).do({ |v| v.post; " ".post });
});
nil;
)

二元消息

流支持 AbstractFunction 中定义的以下二元消息：

(
a = Routine({ 20.do({ 33.rand.yield }) });
b = Routine({ [-100, 00, 300, 400].do({ |v| v.yield }) });
[
    '+', '-', '*', '/', \div, '%', '**', 
    '<', '<=', '>', '>=', '&', '|', \min, \max,
    \bitXor, \lcm, \gcd, \round, \trunc, \atan2,
    \hypot, '>>', '+>>', \ring1, \ring2, \ring3, \ring4,
    \difsqr, \sumsqr, \sqrdif, \absdif, \amclip,
    \scaleneg, \clip2, \excess, '<!', \rrand, \exprand
]
.do({ |msg|
    postf("\n msg: % \n", msg);
    b.reset.perform(msg).do({ |v| v.post; " ".post });
});
nil;
)

类方法

实例方法

.play(clock, quant)

返回数字的流可以直接用play消息播放。返回事件的流需要包装在 EventStreamPlayer 中。参见 -asEventStreamPlayer。

参数：

clock

一个时钟。默认为 TempoClock。

quant

要么是一个数字 n（量化到 n 拍），要么是一个数组 [n, m]（量化到 n 拍，偏移量为 m）。

.do(function, inval)

迭代直到遇到 nil。

警告： 对无尽头流应用 do 会锁死解释器！

.collect(argCollectFunc)

无限迭代。

.reject(function)

仅返回 function.value(element) 为 false 的那些元素。

.select(function)

仅返回那些 function.value(element) 为真的元素。

.dot(function, stream)

对每个元素返回 function.value(this.next, stream.next)。

.interlace(function, stream)

对此的每个元素迭代流的全部内容。使用函数合并这些值。

.appendStream(stream)

在其后追加流返回 nil。与 ++ 相同

.embedInStream(inval)

在调用它的任何 Stream 定义中迭代所有这些内容。

.trace(key, printStream, prefix: "")

打印流的结果，同时返回原始值。

参数：

key

在流式传输事件时，仅发布此键。

printStream

对此流调用 printOn（默认：Post）。

prefix

添加到打印输出中以分隔不同流的字符串。
