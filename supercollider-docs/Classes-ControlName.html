ControlName

用于存储 SynthDef 控制信息的对象（内部使用）

Object

参见：SynthDesc、SynthDef

说明

有关显式创建控制名称的信息，请参阅：NamedControl、Control

返回值：

.index = value

控制的索引。

返回值：

.rate

.rate = value

控制的速率。

返回值：

一个 Symbol，如 'audio' 或 'control'

.defaultValue

.defaultValue = value

此控件的默认值。对于多通道控件，将是一个 Array。

.numChannels

通道数。

返回值：

一个 Integer

.spec

.spec = spec

该控制的 ControlSpec。若设置，它会被添加到当前 SynthDef 的 specs 元数据中。

(
d = SynthDef(\tone, { |out = 0, freq = 200|
    var sig;

    freq.spec = ControlSpec(20, 20000);
    sig = SinOsc.ar(freq);

    Out.ar(out, sig);
}).add;
)

d.specs.freq.postln;

a = SynthDescLib.global; // SynthDesc 的全局库
