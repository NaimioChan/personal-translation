SinOsc

插值正弦波表振荡器。

PureUGen : UGen : AbstractFunction : Object

另请参见：Osc、FSinOsc、SinOscFB、PMOsc、Klang

说明

生成正弦波。使用带线性插值的波表查找振荡器。提供频率调制和相位调制，用于音频速率调制。从技术上讲，SinOsc 与 Osc 使用相同的实现，只是其波表固定为由 8192 个样本构成的正弦波。

其他正弦波振荡器

  • FSinOsc – 快速正弦波振荡器
  • SinOscFB – 带相位反馈的正弦波
  • PMOsc – 相位调制正弦振荡器
  • Klang – 正弦波振荡器组
  • DynKlang – 可调制的正弦波振荡器组

类方法

SinOsc.ar(freq: 440.0, phase: 0.0, mul: 1.0, add: 0.0)

SinOsc.kr(freq: 440.0, phase: 0.0, mul: 1.0, add: 0.0)

参数：

freq

频率，单位为赫兹。以音频速率采样。

phase

相位以弧度表示。以音频速率采样。

注意： 相位值应处于 +-8pi 范围内。如果您的相位值更大，则只需使用 .mod(2pi) 对其进行环绕。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

// 创建一个 200 Hz 的音频速率正弦波，
// 起始相位为 0，振幅为 0.5
{ SinOsc.ar(200, 0, 0.5) }.play;

// 用指数斜坡调制频率
{ SinOsc.ar(XLine.kr(2000, 200), 0, 0.5) }.play;

// 更复杂的频率调制
{ SinOsc.ar(SinOsc.ar(XLine.kr(1, 1000, 9), 0, 200, 800), 0, 0.25) }.play;

// 相位调制（另见 PMOsc）
{ SinOsc.ar(800, SinOsc.ar(XLine.kr(1, 1000, 9), 0, 2pi), 0.25) }.play;
