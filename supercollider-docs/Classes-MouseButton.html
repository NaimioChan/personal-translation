MouseButton

鼠标按键 UGen。

UGen : AbstractFunction : Object

另请参阅：KeyState、MouseX、MouseY

说明

鼠标按键 UGen。

警告： 此 UGen 在 Linux 用户使用 Wayland 时无法工作，因为 Wayland 协议不允许捕获全局键盘或鼠标状态。该 UGen 将返回常量值 0.0。更多信息见 https://github.com/supercollider/supercollider/issues/4544

类方法

MouseButton.kr(minval: 0, maxval: 1, lag: 0.2)

参数：

minval

按钮未按下时的值。

maxval

按钮按下时的值。

lag

滞后因子。

实例方法

未文档化的实例方法

示例

{ SinOsc.ar(MouseButton.kr(400, 440, 0.1), 0, 0.1) }.play;
{ SinOsc.ar(MouseButton.kr(400, 740, 2), 0, 0.1) }.play;

(
SynthDef(\mousexyb, { |out = 0|
    var mousex, mousey, mousebutton;
    mousex = MouseX.kr(500, 1000); // 这将决定声音的频率（最小值、最大值、warp、lag）
    mousey = MouseY.kr(0, 0.3); // 这将决定声音的幅度
    mousebutton = MouseButton.kr(0, 1, 2); // 这将会打开或关闭声音（最小值、最大值、滞后）
    Out.ar(out, SinOsc.ar(mousex, 0, mousey) * mousebutton);
}).add
)

x = Synth.new(\mousexyb);
x.free;
