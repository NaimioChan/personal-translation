TExpRand

触发式指数随机数生成器。

UGen : AbstractFunction : Object

参见：ExpRand、IRand、LinRand、NRand、Rand、TIRand、TRand

说明

每次触发信号从非正值变为正值时，生成一个从 lo 到 hi 指数分布的随机浮点值 lo 和 hi 必须具有相同的符号且非零。

类方法

TExpRand.ar(lo: 0.01, hi: 1.0, trig: 0.0)

TExpRand.kr(lo: 0.01, hi: 1.0, trig: 0.0)

参数：

lo

输出范围的下限。

hi

输出范围的上限。

trig

触发信号。触发信号可以是任意信号。当信号从非正变为正时，触发发生。

实例方法

示例

(
{
    var trig = Dust.kr(10);
    SinOsc.ar(
            TExpRand.kr(300.0, 3000.0, trig)
        ) * 0.1
}.play;
)

(
{
    var trig = Dust.ar(MouseX.kr(1, 8000, 1));
    SinOsc.ar(
            TExpRand.ar(300.0, 3000.0, trig)
        ) * 0.1
}.play;
)
