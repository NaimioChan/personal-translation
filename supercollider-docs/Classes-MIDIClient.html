MIDIClient

对计算机上 MIDI 的基本访问

Object

另请参阅：MIDIIn、MIDIOut、MIDIFunc、MIDIdef、MIDI、Using MIDI、MIDIEndPoint

说明

MIDIClient 是提供访问计算机上 MIDI 子系统的核心类。

有关在 SC 中使用 MIDI 的实际注意事项和技巧，请参阅 Using MIDI 帮助文件。

类方法

MIDIClient.init(inports, outports, verbose: true)

初始化 MIDIClient，检查有哪些可用的 MIDI 源和目的地，并按需打开尽可能多的连接。

参数：

inports

要打开的 MIDI 输入连接数；如果为 nil，则打开与 MIDI 源数量相同的输入端口。

outports

要打开的 MIDI 输出连接数；如果为 nil，则打开与 MIDI 目标数量相同的输出端口。

verbose

一个标志，指示是否发布已找到的 MIDI 源和目的地。默认值为 true。

MIDIClient.initialized

一个标志，指示 MIDIClient 是否已初始化。

MIDIClient.disposeClient

清理 MIDIClient。使用此方法后，你必须重新初始化 MIDIClient 才能再次使用 MIDI。

MIDIClient.list

刷新可用源和目标的列表。如果在 MIDIClient 初始化之后才连接 MIDI 设备，则只有运行此方法后才能看到它。

MIDIClient.sources

可用的 MIDI 源列表，包括 SuperCollider 自身的源。

返回值：

一个 List，包含 MIDIEndPoints

MIDIClient.externalSources

来自扩展 /usr/local/share/SuperCollider/SCClassLibrary/Platform/linux/SystemOverwrites/extMIDIOut.sc

可用的 MIDI 源列表，不包括 SuperCollider 自身的源。仅在 Linux 上，sources 与 externalSources 的列表会有所不同。

返回值：

一个 List，包含 MIDIEndPoints

MIDIClient.destinations

可用 MIDI 目标列表，包括 SuperCollider 自身的目标。

返回值：

一个 List，包含 MIDIEndPoints

MIDIClient.externalDestinations

来自扩展 /usr/local/share/SuperCollider/SCClassLibrary/Platform/linux/SystemOverwrites/extMIDIOut.sc

可用的 MIDI 目标列表，不包括 SuperCollider 自身的目标。只有在 Linux 上，destinations 和 externalDestinations 的列表才会有所不同。

返回值：

一个 List，包含 MIDIEndPoints

MIDIClient.restart

重启 MIDIClient。

MIDIClient.myinports

SuperCollider 创建的输入端口数量。这主要用于在 Linux 平台上了解相关信息。

MIDIClient.myoutports

SuperCollider 创建的输出端口数量。这主要用于在 Linux 平台上了解相关信息。

MIDIClient.getClientID

来自扩展 /usr/local/share/SuperCollider/SCClassLibrary/Platform/linux/SystemOverwrites/extMIDIOut.sc

仅限 Linux。获取 MIDIClient 在 ALSA 子系统中定义所用的客户端 ID。可用于判断某个端口属于此客户端还是另一个客户端。

在非 Linux 系统上，它会发布一条警告并返回 nil。

实例方法

示例

这是 Linux 专用代码。该函数负责初始化 MIDIClient，检测名为 SE25 的 MIDI 设备并将其连接到 SuperCollider 的端口 0。

(
~connect_midi_devices = { |device, name|
    // 初始化或刷新 MIDIClient 端点
    if(MIDIClient.initialized == false) {
        MIDIClient.init;
    } {
        MIDIClient.list;
    };

    MIDIClient.sources.do({ |endPoint|
        if(device.notNil and: { name.notNil } and: { endPoint.device == device } and: { endPoint.name == name }) {
            // 捕获已连接时抛出的异常
            try {
                // 将 SuperCollider 输出端口 0 连接到 MIDI 设备
                MIDIOut.connect(0, endPoint.uid);
            };
            try {
                // 在端口 0 将 MIDI 设备连接到 SuperCollider
                MIDIIn.connect(0, endPoint.uid);
            }
        }
    })

}
)

~connect_midi_devices.("SE25", "SE25 MIDI 1"); // 立即测试
