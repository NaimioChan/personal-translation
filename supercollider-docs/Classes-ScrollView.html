ScrollView

可以滚动其内容的容器视图

参见：CompositeView

说明

一个容器视图，允许用户在内容超出视图边界时滚动浏览内容。

画布

该视图将子视图放置到一个画布上，画布随后可以滚动。子视图的位置始终相对于画布，因此不受滚动影响。

画布的大小始终等于所有子视图的集体边界，并且当子视图被添加、移动、调整大小和移除时，会自动调整。如果你希望将其设置为特定大小，可以这样做：首先放置一个所需大小的 CompositeView（或其他容器），然后将所有其他视图放入该容器中。

不过，也可以替换 canvas，改用任何其他视图（例如直接用 View），这样就可以在它上面安装一个 layout。这种情况下，若 layout 的内容允许，canvas 会填满 ScrollView 的整个可见区域；若 layout 的内容需要，则占据更大的区域。实际上，内容会随 ScrollView 一起改变大小，除非它们的大小约束不允许；而如果 -autohidesScrollers 为 true，则只有当内容无法在滚动条方向上缩得足够小时才会显示滚动条。进一步说明见 -canvas。

Restrictions

注意： 子元素的 View: -resize 模式会被忽略。不应直接在 ScrollView 上使用 FlowLayout 之类的装饰器，而应仅在其内部放置的容器视图上使用。

类方法

实例方法

Geometry

.canvas

返回承载子视图的当前画布，或用另一个画布替换它。

默认情况下，canvas 是 QObject 的子类，因此不允许进行视图所具有的那类操作。不过，它只能被 View 的子类替换，这极大地扩展了可能性，包括在 canvas 上使用布局。

新画布将始终随 ScrollView 调整大小，只要其尺寸约束允许。一个完全忽略其子视图的普通 View 可以自由调整大小，因此由于滚动条是根据画布尺寸激活的，滚动将永远无法进行。为防止这种情况，你可以使用 View: -minSize 及类似方法对其施加显式尺寸约束，或者在其上安装布局，该布局会将子视图的尺寸约束转发给它。

参见下面的示例。

一旦画布被替换，以 ScrollView 为父级构建的新视图将成为画布视图的子级，这等同于以画布为父级构建它们，或将它们插入到画布上安装的布局中。

警告： 替换画布将移除并销毁放置在先前画布上的所有视图！

.innerBounds

返回与画布尺寸对应的矩形，或 ScrollView 背景的可视区域，以较大者为准。该矩形的位置始终为 0@0。

关于画布尺寸，请参见上面的讨论。

返回值：

一个 Rect。

.visibleOrigin

获取画布上对应于其最左上方可见点的位置，或移动画布，以便在可能的情况下将给定点置于可见边界左上角。

参数：

一个 Point。

Behavior

.autohidesScrollers

设置或获取当内容在滚动条方向上未超出视图边界时，视图是否隐藏其中一个或另一个滚动条。

如果 -hasHorizontalScroller 或 -hasVerticalScroller 被设为 false，则相应的滚动条将始终隐藏，与此策略无关。

默认为 true。

.hasHorizontalScroller

设置或获取视图是否具有水平滚动条。如果为 true，若 -autohidesScrollers 允许，滚动条仍可能被隐藏；但如果为 false，滚动条将永远不会显示。

默认为 true。

.hasVerticalScroller

设置或获取该视图是否具有垂直滚动条。如果为 true，若 -autohidesScrollers 允许，滚动条仍可能被隐藏；然而，如果为 false，则滚动条将永远不会显示。

默认为 true。

Appearance

.hasBorder

设置或获取视图是否绘制其边框。

默认为 true。

Actions

.action

设置或获取当用户移动滚动条时，或当设置 -visibleOrigin 时要被求值的对象。

示例

画布上的布局管理

通过将 ScrollView 的画布替换为一个 View，并在其上安装布局，内容将扩展至 ScrollView 的边缘，仅在必要时才超出边缘。

(
var scroll = ScrollView(bounds: Rect(0, 0, 300, 300).center_(Window.availableBounds.center));
var canvas = View();
var layout;
var i = 0;

var makeEntry = {
    var view = View().background_(Color.rand).layout_(
        HLayout(
            TextField().string_(("This is entry number " + i.asString)),
            Button().states_([["Delete"]]).action_({ view.remove; i = i - 1 })
        )
    );
    i = i + 1;
    view;
};

layout = VLayout();
layout.add (View().background_(Color.black).layout_(
    HLayout(
        Button().states_([["Add"]]).action_({ layout.insert(makeEntry.(), i) }),
        nil // 拉伸剩余空白空间
    )
));

canvas.layout = layout;
10.do { canvas.layout.add(makeEntry.()) };
canvas.layout.add(nil); // 拉伸剩余空白空间

scroll.canvas = canvas;
scroll.front;
)

强制画布尺寸

(
w = Window.new;

b = ScrollView(w, Rect(0, 0, 300, 300)).hasBorder_(true);
c = CompositeView(b, Rect(0, 0, 500, 500)); // 'canvas' 有这么大
c.decorator = FlowLayout(c.bounds); // 现在我们可以使用装饰器

Slider2D(c, Rect(0, 0, 240, 240));
Slider2D(c, Rect(0, 0, 240, 240));
Slider2D(c, Rect(0, 0, 240, 240));

c.decorator.nextLine;
w.front;
)

“标尺”，使用动作函数

(
var drawFunc;
w = Window.new;

a = ScrollView(w, Rect(40, 40, 300, 300));
b = ScrollView(w, Rect(0, 40, 40, 300)).hasHorizontalScroller_(false).hasVerticalScroller_(false);
c = ScrollView(w, Rect(40, 0, 300, 40)).hasHorizontalScroller_(false).hasVerticalScroller_(false);
b.background = Color.grey;
c.background = Color.grey;

d = UserView(a, Rect(0, 0, 620, 620));
e = UserView(b, Rect(0, 0, 40, 630));
f = UserView(c, Rect(0, 0, 630, 40));

a.action = { var origin;
    origin = a.visibleOrigin;
    b.visibleOrigin = 0@(origin.y);
    c.visibleOrigin = (origin.x)@0;
};

drawFunc = {
    30.do({ |i|
        (i+1).asString.drawAtPoint((i+1 * 20)@0, Font("Courier", 9), Color.black);
    });
};

d.drawFunc = {
    Pen.use({
        Pen.translate(0, 5);
        drawFunc.value;
    });
    Pen.translate(15, 0).rotate(0.5pi);
    drawFunc.value;
};

e.drawFunc = {
    Pen.translate(40, 0).rotate(0.5pi);
    drawFunc.value;
};

f.drawFunc = {
    Pen.translate(0, 25);
    drawFunc.value;
};

w.front;
)
