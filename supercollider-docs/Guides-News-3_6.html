语言端新闻

更具信息性的语法错误

解析器现在会发布语法错误的详细信息，例如：

[1,2,%,4];
123;

输出以下错误消息：

ERROR: syntax error, unexpected BINOP, expecting ']'
  in file 'selected text'
  line 1 char 6:

  [1,2,%,4];
       ^
  123;
-----------------------------------
ERROR: Command line parse failed

移除旧语法

#(a:1) 曾是有效语法，但会产生无意义的结果。现在这会导致语法错误。

YAML/JSON 解析器

String: -parseYAML 和 String: -parseYAMLFile 可用于解析 YAML 或 JSON。

SynthDef 对加法项的优化

当 SynthDef 被编译时，独立的加法 UGen 会通过新的 Sum3 和 Sum4 UGen 合并。

SynthDef 的基本死代码消除

构建 synthdef 的过程现在会执行一次简单的死代码消除，移除所有没有后继的 PureUGen 实例。

区分大小写的 String 比较

字符串比较运算符（==, !=, <=, >=, >, <）现在区分大小写。

"Foo" == "fOo"; // false

SplayAz 错误修复

SplayAz 的定位功能曾存在问题。为了修复该行为，spread 和 center 参数的语义已被更改。

数组原语遵循可变性

数组原语现在遵循对象可变性：向不可变对象写入现在会失败，并且使用 add、addAll、insert、extend、growClear 和 overwrite 修改不可变对象将返回一个新分配的对象。
