BufDur

缓冲区中声音文件的当前时长。

BufInfoUGenBase : UGen : AbstractFunction : Object

另见：BufChannels、BufFrames、BufRateScale、BufSampleRate、BufSamples

说明

获取声音文件的当前时长。

类方法

BufDur.kr(bufnum)

来自父类：BufInfoUGenBase

BufDur.ir(bufnum)

来自父类：BufInfoUGenBase

参数：

bufnum

缓冲区索引。

返回值：

当前时长。

讨论：

警告： .ir 方法并不是最安全的选择。由于缓冲区随时可能被重新分配，使用 .ir 不会跟踪这些变化。

实例方法

示例

b = Buffer.read(s, ExampleFiles.child);

{ BufRd.ar(1, b, Sweep.ar(Impulse.ar(BufDur.kr(b).reciprocal), BufSampleRate.kr(b))) }.play;

b.free
