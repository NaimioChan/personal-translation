BiPanB2

二维 Ambisonic B-format 声像器。

MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：DecodeB2、PanB、PanB2、Rotate2

说明

将双声道信号编码为二维 ambisonic B-format。这会将两个声道置于二维 ambisonic 声场的相反两极。这是将立体声映射到声场的一种方式。它等效于：

PanB2(inA, azimuth, gain) + PanB2(inB, azimuth + 1, gain)

类方法

BiPanB2.ar(inA, inB, azimuth, gain: 1)

BiPanB2.kr(inA, inB, azimuth, gain: 1)

参数：

inA

输入信号 A

inB

输入信号 B。

azimuth

围绕圆周的位置，从 -1 到 +1。

-1 表示后方，-0.5 表示左侧，0 表示前方，+0.5 表示右侧，+1 表示后方。

gain

振幅控制。

实例方法

示例

(
{
    var w, x, y, p, q, a, b, c, d;

    p = LFSaw.ar(200);
    q = LFSaw.ar(301);

    // B-format 编码
    #w, x, y = BiPanB2.ar(p, q, MouseX.kr(-1, 1), 0.1);

    // B-format 解码为四声道
    #a, b, c, d = DecodeB2.ar(4, w, x, y);

    [a, b, d, c] // 重新排序为我的扬声器布局：Lf Rf Lr Rr
}.play;
)
