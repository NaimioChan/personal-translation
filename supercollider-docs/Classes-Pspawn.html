Pspawn

根据事件模式中的参数生成子模式

FilterPattern : Pattern : AbstractFunction : Object

参见：Pspawner、Spawner

说明

Pspawn 是 Pspawner 的基于模式的版本。Pspawner 使用 Routine 风格的函数来确定何时以及如何将子模式生成到结果流中，而 Pspawn 使用事件模式来确定要采取的操作。

建议阅读 Pspawner 帮助文件，以熟悉模式生成功能。

注意： 重要提示：Pspawn 涉及两种事件：父事件，指定要嵌入的模式、如何嵌入（并行或顺序）以及等待多久进行下一个动作；子事件，产生最终音符（或在服务器上执行其他动作）。

其中，只有子事件在播放期间被返回到事件流播放器。父事件严格用于内部，以控制生成行为。父、子事件流不会混合在一起。因此，模式组合（Pchain）与并行化（Ppar）无需特殊处理即可使用。用户需要自行判断应当对父流还是子流作进一步操作，并把该操作放在正确的位置。如果要影响子流，应包裹整个 Pspawn；对于父流，则应放在 Pspawn 内部。（参见下方示例。）

Pspawn 使用父模式中的以下项：

method

在 spawner 对象上调用的动作。目前支持：wait、seq、par、suspendAll。

delta

等待到下一个动作的时间。

dict

如果 'pattern' 以符号形式给出（见下文），则这是用于查找该模式的字典。如果未指定，则使用 Pdef 集合。

pattern

如果 'method' 为 seq 或 par，则根据以下规则，这是一个要嵌入的模式或函数。

事件中的 'pattern'

结果行为

一个 Function：{ ... }

该函数应返回一个模式；此模式会被生成。

指向模式的一个 Ref：`Pbind(...)

被引用的模式被生成。

一个 Symbol：\scaleUp

该模式在事件的 'dict' 中查找。

使用引用保护模式不被嵌入

通常，当一个模式出现在另一个模式内部时，子模式会嵌入到主输出流中。它不会作为模式本身对外部世界可见；只有它的值会出现。

Pseq([Pwhite(0, 9, 5), Pwhite(10, 19, 5)], 1).asStream.all;

使用 Pspawn 时，子模式必须直接返回到事件中。为此，每个这样的模式都应包装在 Ref 中：

Pseq([`Pwhite(0, 9, 5), `Pwhite(10, 19, 5)], 1).asStream.all;

提示：Pfunc 是包装模式的另一种好方法，因为它只是返回其结果值，而无需进一步嵌入。参见第一个示例。

类方法

Pspawn.new(pattern, spawnProtoEvent)

参数：

pattern

一个事件模式（通常是 Pbind），封装了所需的生成行为。此事件中的参数如下所述。

spawnProtoEvent

用于对模式求值的事件原型。适合提供应应用于所有生成（父）事件的默认值。

示例

// 播放重叠的大调音阶，上下行
(
p = Pspawn(Pbind(
        // Pfunc 返回的 Pbind 不会被嵌入，只是被放置到 event 中
        // 因此，它可以被 spawn
    \pattern, Pfunc { Pbind(\degree, Pseries(rrand(0, 10), #[-1, 1].choose, rrand(4, 10)), \dur, 0.125) },
    \delta, Pwhite(1, 5, inf) * 0.125,
    \method, \par
)).play;
)

p.stop;


// 同上，使用模式字典，并同时改变 dur 节奏
(
var    patternChoices = (
    up: { Pbind(\degree, Pseries(rrand(-4, 5), 1, rrand(4, 10)), \dur, 0.125) },
    down: { Pbind(\degree, Pseries(rrand(4, 11), -1, rrand(4, 10)), \dur, 0.125 * 4/3) }
);

p = Pspawn(Pbind(
    \pattern, Prand([\up, \down], inf),
    \delta, Pwhite(1, 5, inf) * 0.125,
    \method, \par
), (dict: patternChoices)).play;
)

p.stop;


// 使用 pattern 组合（也许有些多余）来构建父事件
(
var    patternChoices = (
    up: { Pbind(\degree, Pseries(rrand(-4, 5), 1, rrand(4, 10)), \dur, 0.125) },
    down: { Pbind(\degree, Pseries(rrand(4, 11), -1, rrand(4, 10)), \dur, 0.125 * 4/3) }
);

p = Pspawn(Pchain(
    Pbind(
        \pattern, Prand([\up, \down], inf),
        \method, \par
    ),
    Pbind(
        \delta, Pwhite(1, 5, inf) * 0.125
    )
), (dict: patternChoices)).play;
)

p.stop;


// 在左声道播放平行音阶，在右声道播放顺序排列的音阶
// 这意味着将子流并行化（Ppar）；因此 Ppar 包围了一对 Pspawn

// \pan 的处理很有意思：\pan 需要是 patternChoices 各项的属性
// 它不是生成事件的属性
// 为了复用 patternChoices，Pspawns 用 Pbindf 包装基础模式，从而添加新的值
(
var    patternChoices = (
    up: { Pbind(\degree, Pseries(rrand(-4, 5), 1, rrand(4, 10)), \dur, 0.125) },
    down: { Pbind(\degree, Pseries(rrand(4, 11), -1, rrand(4, 10)), \dur, 0.125 * 4/3) }
);

p = Ppar([
    Pspawn(Pbind(
            // 中间值
        \patternKey, Prand([\up, \down], inf),
            // 在此处选择模式并应用声像
        \pattern, Pfunc { |ev| Pbindf(ev.dict[ev.patternKey].value, \pan, -1) },
        \delta, Pwhite(1, 5, inf) * 0.125,
        \method, \par
    ), (dict: patternChoices)),
    Pspawn(Pbind(
        \patternKey, Prand([\up, \down], inf),
        \pattern, Pfunc { |ev| Pbindf(ev.dict[ev.patternKey].value, \pan, 1) },
        \delta, Pwhite(1, 5, inf) * 0.125,
        \method, \seq
    ), (dict: patternChoices)),
]).play;
)

p.stop;
