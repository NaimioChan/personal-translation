TouchResponder

允许注册函数以响应 MIDI 触后事件

MIDIResponder : Object

另请参阅：MIDIFunc、MIDIdef、MIDIResponder、CCResponder

子类：BendResponder

说明

注意： SC 3.5 新增了 MIDIFunc 和 MIDIdef 类。它们速度更快，旨在提供更方便、更合乎逻辑且更一致的接口，与 OSCFunc 和 OSCdef 共享共同的设计。它们还支持所有 MIDI 消息类型。

类方法

TouchResponder.new(function, src, chan, value, install: true, swallowEvent: false)

参数：

function

一个要计算的 Function。传递给该函数的参数是：src、chan、value。

src

src 编号可以是系统 UID（从 MIDIClient.sources[index].uid 获得），也可以是源在 MIDIClient.sources 数组中的索引。nil 匹配所有。

chan

一个介于 0 和 15 之间的 Integer，用于选择要匹配的 MIDI 通道。nil 匹配所有通道。也可以是一个 Function，它将被求值以确定匹配。例如：{ |val| val < 2 }

value

一个介于 0 和 127 之间的 Integer，用于筛选值。nil 匹配所有值。也可以是一个 Function，它将被求值以确定匹配。例如：{ |val| val < 50 }

install

如果为 true，则自动安装响应器，使其处于活动状态并准备好响应。如果为 false，则它将处于非活动状态。

swallowEvent

若为 true，则如果匹配到该 midi 事件，就停止测试任何进一步的响应器。请注意，这样做会阻止此类型的任何其他响应器进行响应，包括在类中后台添加的响应器。另请注意，此功能对响应器的添加顺序敏感。

实例方法

.learn

等待下一条触后消息，将 self 重置以匹配 src、chan。

(
c = TouchResponder({ |src, chan, value|
        [src, chan, value].postln;
    });
    c.learn; // 等待第一个触摸消息
)
