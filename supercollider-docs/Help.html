入门概述

SuperCollider 是一个用于音频合成与算法作曲的跨平台环境，供从事声音工作的音乐家、艺术家和研究者使用。它可以安装并运行于 Linux、macOS 和 Windows，以及诸如 Raspberry Pi 或 Bela 等微型计算机上。SuperCollider 最初由 James McCartney 开发，现在作为自由软件以 GNU 通用公共许可证发布。它由一个活跃而热心的社区维护和开发。

SuperCollider 由三个主要组件组成：

• scsynth — 一个以服务器形式实现的实时音频引擎。

默认服务器是 scsynth。SuperCollider 还包含一个名为 supernova 的 scsynth 替代实现，它支持多线程，以充分发挥多核 CPU 的潜力。

• sclang —— 一种基于文本的编程语言和解释器，作为服务器的客户端。

sclang 控制服务器上的音频合成进程，并提供一个用于现场编程的交互式编程环境、一个用于创建模式的广泛库，以及一个来自各种文化的音阶和调式库。在 sclang 中创建随时间展开的进程非常直接。它还提供了图形用户界面（GUI）的所有基本特性，可用于创建自定义用户界面、数据可视化和动画。借助对 MIDI、OSC、HID 和串行端口的支持，sclang 可以轻松地与本地和网络硬件及软件进行交互。

尽管 sclang 是服务器的原生语言和客户端，但也存在其他编程语言的若干客户端实现，例如 Python（通过 Supriya API）、JavaScript、Haskell 或 Scala。

• ScIDE — 一个专为 SuperCollider 设计的编辑器，带有集成帮助系统。

SuperCollider 集成开发环境（IDE）让你开箱即用，即刻开始编写代码。社区成员也维护了 sclang 与其他流行 IDE 的集成。支持编辑器的完整列表可在 https://github.com/supercollider/supercollider/wiki/Systems-interfacing-with-SC#editors 获取。

服务器与客户端通过 Open Sound Control（OSC）进行通信，这使得 SuperCollider 既可以在一台机器上运行，也可以在多台机器上通过网络运行。得益于这种客户端/服务器架构，多个客户端可以连接并控制服务器上发生的事情。用户还可以通过使用 Node Messaging 协议，用任何支持 OSC 的程序直接控制音频服务器。

SuperCollider 附带了一个广泛的 Unit Generator 库——它们是音频合成网络的构建块。用户可以选择用 sc3-plugins UGen 套件来扩展这个核心库。此外，还有许多用户开发的语言扩展，称为 Quarks，可进一步扩展 SuperCollider 的功能。可以在发行版 repository 中浏览 Quarks，用户可以在那里提交自己的 Quarks 以供分发。
