Collections

Collection 子类的层次概览

另请参阅：Collection

SuperCollider 拥有丰富的 Collection 子类层级结构，详见下文。给定类的子类相对于该类缩进（子列表）。标为“abstract”的类不供直接使用，但树中较低层级的类可能会从它们继承方法。因此，查阅树中更高层级类的帮助文件以获取可用方法的完整列表非常重要。

Hierarchy

  • Collection - 所有集合的抽象父类

    • Array2D - 二维数组

    • Bag - 无序的对象集合

      • IdentityBag - 依据同一性判断的 Bag
    • Interval - 整数范围

    • MultiLevelIdentityDictionary - 字典树

      • LibraryBase - 抽象全局存储类

        • Archive - 将对象存储到文件
        • Library - 将对象保存在中心位置
    • Pair - 类 LISP 的双元素单元
    • Range - （未文档化的类）

    • SequenceableCollection - 可索引集合的抽象父类

      • ArrayedCollection - 固定最大大小的集合的抽象父类

        • Array - 固定大小集合

        • RawArray - 保存原始数据值的数组的抽象父类

          • DoubleArray - 一个 64 位双精度浮点数数组

          • FloatArray - 32 位单精度浮点数数组

            • Signal - 采样音频缓冲区
            • Wavetable - 波表格式的采样音频缓冲区
          • Int16Array - 索引槽均为同一类型的数组
          • Int32Array - 索引槽均为同一类型的数组
          • Int8Array - 一种数组，其索引槽均为同一类型
          • String - Char 的数组
          • SymbolArray - 索引槽全部为同一类型的数组
      • LinkedList - 双向链表

      • List - 可变大小的项目列表

        • SortedList - 一种集合，其元素按有序顺序保存。

      • Order - 带数字索引的元素顺序

        • SparseArray - 更高效地存储重复值的数组
      • RingBuffer - 固定大小的环形缓冲区

    • Set - 基于相等性的集合

      • Dictionary - 将键映射到值的关联集合

        • IdentityDictionary - 将键映射到值的关联集合

          • Environment - 一个可作为函数“命名空间”的字典

            • Event - 表示一个动作的环境

          • NodeMap - 存储控制值和总线映射

            • ProxyNodeMap - 存储 NodeProxy 的控制值和总线映射

      • IdentitySet - 根据同一性构成的集合

        • OrderedIdentitySet - 根据同一性构成的集合

    • TwoWayIdentityDictionary - 将键映射到值并可反向映射的关联集合

      • ObjectTable - 将对象与 ID 关联

Notes

List

是一个可扩展的 SequenceableCollection（可与 ArrayedCollection 和 Array 比较）。

Array

比 List 更高效。

SparseArray

是一个针对元素间存在巨大间隔的情况进行优化的元素数组。

TwoWayIdentityDictionary

类似于 IdentityDictionary，允许按键和值轻松搜索。在反向查找时比 IdentityDictionary 更快，但内存开销更大。

Environment

是一个 IdentityDictionary，其中总有一个是当前生效的；对于创建持久变量集合很有用。

Event

是一个将音乐参数名称映射到其值的字典。

IdentitySet

是一个无序的、元素互不相同的对象集合（与 Set 比较）。
