softSet

有条件地设置代理参数值

参见：softVol_、softPut

说明

softSet 是 NodeProxy 和 Ndef 的扩展方法，仅在两种情况下设置 nodeproxy 参数值：

  • 如果新值足够接近当前参数值；
  • 或者，如果设置控制器知道先前的值并将其一并发送。这里的想法是，如果控制器知道它执行了上一次的值更改，它就有权立即跳转。

典型用途是切换到预设，然后使用推子盒，并避免可能发生的控制器突然跳变（软接管）。

softSet(param, val, within = 0.025, mapped=false, lastVal, spec)

参数：

param

要设置的参数名称

val

要设置 param 的值（可以是已映射或未映射的）

within

集合被接受时的归一化范围 - 默认为 0.025

lastVal

控件先前设置的值 - 参见最后的示例。

mapped

一个标志，表示 val 是映射的（在 param.asSpec 范围内）还是未映射的（0.0-1.0）

spec

可以传入一个 ControlSpec。如果为 nil，则使用 param.asSpec。

注意： 如果未给出 spec，softSet 仅允许设置。

示例

Ndef(\test, { |freq=200| Splay.ar(SinOsc.ar(freq * Array.rand(12, 0.95, 1.05))) });
Ndef(\test).play(vol: 0.1);

Ndef(\test).gui(4)

Ndef(\test).set(\freq, 300);

        // 3 midi steps == 0.02362;
Ndef(\test).softSet(\freq, 320, 0.03); // ok
Ndef(\test).softSet(\freq, 280, 0.03); // ok
Ndef(\test).softSet(\freq, 200, 0.03); // 如果跳变过大则返回 false

Ndef(\test).set(\freq, 600);

    // softSet 可能有风险——如果控制器移动得太快，可能会丢失一个参数。
    // 所以，如果我们知道最后一个值（例如因为同一个控制器
    // 知道自己已设置成该值），那么跳变是没问题的：
Ndef(\test).softSet(\freq, 330, 0.03, lastVal: 630);

Ndef(\test).softSet(\freq, rrand(300, 350), 0.01);    // 有时是，有时不是


    // 使用未映射的、即归一化的值来设置：

Ndef(\test).set(\freq, 600);    // ok
Ndef(\test).softSet(\freq, 0.5, 0.05, mapped: false);    // ok
Ndef(\test).softSet(\freq, 0.45, 0.03, mapped: false);    // 不，太大了
Ndef(\test).softSet(\freq, 0.3, 0.03, mapped: false, lastVal: 0.5);    // 但如果 lastVal 接近就没问题


    // softSet 的示例，softSet 知道 lastVal，
    // softVol_ 和 softVol_ 知道 lastVol：
(
w = Window("softSet, softVol", Rect(500, 200, 400, 240)).front;
w.view.addFlowLayout;
NdefGui(Ndef(\test), 2, w);

    // 如果摆动太快可能会失去控制
EZSlider(w, 340@30, \softSet, \freq, { |sl|
    Ndef(\test).softSet(\freq, sl.value, 0.05)
});

    // 知道它处于控制之中
EZSlider(w, 340@30, \knowsLast, \freq, Routine { |sl|
    var newVal, lastVal;
    loop {
        newVal = sl.value;
        Ndef(\test).softSet(\freq, newVal, 0.05, lastVal: lastVal);
        lastVal = newVal;
        \dummy.yield;
    }
});

    // 音量同理——不太安全
EZSlider(w, 340@30, \softVol, \amp, { |sl|
    Ndef(\test).softVol_(sl.value, 0.05)
});
    // safer
EZSlider(w, 340@30, \knowLastV, \amp, Routine { |sl|
    var newVal, lastVal;
    loop {
        newVal = sl.value;
        Ndef(\test).softVol_(sl.value, 0.05, lastVal: lastVal);
        lastVal = newVal;
        \dummy.yield;
    }
});
)
