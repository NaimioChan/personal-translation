UGen 之旅

SuperCollider 中的信号处理

参见：浏览：UGen

1. 可用 Unit Generator 之旅。

SuperCollider 有超过 250 个 unit generator。如果算上一元和二元运算符，则超过 300 个。本次导览涵盖了许多，但并非全部。

单元生成器的类别：

  • 来源：周期性、非周期性
  • filters
  • distortion
  • panning
  • reverbs
  • 延迟与缓冲区 UGen
  • 粒度合成
  • 控制：包络、触发器、计数器、门、滞后、衰减
  • spectral
2. 技巧
  • 人工空间 - 去相关、拍频、延迟。
  • 串行与并行结构。

注意：分类浏览器中有一个 UGen 分类，它提供了另一种有用的方式来概览可用的 UGen，包括本文撰写之后新增的那些。

VOsc - 多波表交叉淡化振荡器

参数：缓冲区编号、频率、相位、mul、add

(
// 分配表 80 到 87
8.do {|i| s.sendMsg(\b_alloc, 80+i, 1024); };
)

(
// 填充表 80 到 87
8.do({|i|
    var n, a;
    // 生成谐波振幅数组
    n = (i+1)**2; // num harmonics for each table: [1,4,9,16,25,36,49,64]
    a = {|j| ((n-j)/n).squared }.dup(n);
    // 填充表格
    s.listSendMsg([\b_gen, 80+i, \sine1, 7] ++ a);
});
)

{ VOsc.ar(MouseX.kr(80,87), 120, 0, 0.3) }.scope(1, zoom:4);

(
// 分配并填充表 80 到 87
8.do({|i|
    // 生成谐波振幅数组
    a = {1.0.rand2.cubed }.dup((i+1)*4);
    // 填充表格
    s.listSendMsg([\b_gen, 80+i, \sine1, 7] ++ a);
});
)
