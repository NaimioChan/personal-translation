Timer

返回自上次触发以来的时间。

UGen : AbstractFunction : Object

说明

被触发时，Timer 测量自上次触发以来经过的时间（以秒为单位），并将该时间值作为常量输出。其输出在下一次触发之前不会变化。初始值为 0。

如果你需要自上次触发以来的时间，且该时间持续更新，请参见 Sweep。

类方法

Timer.ar(trig: 0.0)

Timer.kr(trig: 0.0)

参数：

trig

当 trig 信号从非正变为正时，触发一个触发。

实例方法

示例

// 使用 timer 调制正弦频率：触发越慢频率越高
(
{ var trig;
    trig = Impulse.kr(MouseX.kr(0.5, 20, 1));
    SinOsc.ar(Timer.kr(trig) * 500 + 500, 0, 0.2)
}.play;
)
