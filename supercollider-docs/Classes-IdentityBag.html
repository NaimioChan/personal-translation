IdentityBag

按标识判断的 Bag

Bag : Collection : Object

说明

IdentityBag 是一个无序的对象集合。在某些语言中，它被称为计数集合。Bag 会记录对象被插入的次数，并要求对象被移除相同的次数。即使对象已被多次添加到 Bag 中，Bag 中也只有一个该对象的实例（测试依据是同一性）。

IdentityBag 的内容是无序的。不得依赖集合中元素的顺序。

类方法

实例方法

添加与移除

.add(item, count: 1)

来自父类：Bag

将 anObject 添加到 Bag。一个 Bag 可以包含同一对象的多个条目。

IdentityBag[1, 2, 3].add(4);
IdentityBag[1, 2, 3].add(3);
IdentityBag["abc", "def", "ghi"].add("jkl");
IdentityBag["abc", "def", "ghi"].add("def");

.remove(item, count: 1)

来自父类：Bag

从 IdentityBag 中移除 anObject。

IdentityBag[1, 2, 3].remove(3);

.contents

来自父类：Bag

返回以成对形式（obj -> numberOfObjects）存储对象的字典。

IdentityBag[\a, \b, \c, \c].contents;

Iteration

.do(function)

来自父类：Bag

对 IdentityBag 中的每一项求函数值。该函数接收两个参数，即该项和一个整数索引。

IdentityBag[1, 2, 3, 300].do({ |item, i| item.postln });

Bag 与 IdentityBag 之间的区别

// 两个字符串相等，但不完全相同
"something" == "something"; // true
"something" === "something" // false

a = Bag.new;
a.add("something");
a.add("something");
a.contents; // bag 中实际上只有一个对象

a = IdentityBag.new;
a.add("something");
a.add("something");
a.contents; // 袋中有两个对象
