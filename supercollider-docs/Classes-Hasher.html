Hasher

使用哈希函数打乱的值。

UGen : AbstractFunction : Object

说明

根据哈希函数为每个输入值返回一个从 -1 到 +1 的唯一输出值。相同的输入值将始终产生相同的输出值。输入不必在 -1 到 +1 的范围内。

类方法

Hasher.ar(in: 0.0, mul: 1.0, add: 0.0)

Hasher.kr(in: 0.0, mul: 1.0, add: 0.0)

参数：

in

输入信号。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

{ Hasher.ar(Line.ar(0, 1, 1), 0.2) }.play;

// 即使给输入加上很小的量，也可能产生非常不同的输出。比较下面两个示例：
(
{
    SinOsc.ar(
        Hasher.kr(MouseX.kr(0, 10).round(1), 300, 500)
    ) * 0.1
}.play;
)

(
{
    SinOsc.ar(
        Hasher.kr(MouseX.kr(0, 10).round(1) + 0.0001, 300, 500)
    ) * 0.1
}.play;
)

// 不移动鼠标时输出保持不变。
(
{
    SinOsc.ar(
        Hasher.kr(MouseX.kr(0, 10), 300, 500)
    ) * 0.1
}.play;
)
