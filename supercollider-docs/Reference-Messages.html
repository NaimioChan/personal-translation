Messages

方法调用，向对象发送消息

另请参见：Classes、Class、Object、Introduction to Objects、Polymorphism

Introduction

在面向对象语言中，发送消息是完成任务的方式。一条消息由消息选择器（用于命名操作类型）、接收者（消息发送的目标）以及有时给出的参数列表（提供与该操作相关的附加信息）组成。消息总是返回一个结果。结果的类型取决于消息的类型。在默认情况下，返回值就是接收者本身。

消息可以使用二元运算符、函数式记法或接收者记法来编写。

二元运算符消息

二元运算符选择符是由合法二元运算符字符列表中的任意字符组成的字符串：

! @ % & * - + = | < > ? /

一个例外是，任何运算符都不能以 // 或 /* 开头，它们是注释分隔符。

二元运算符表达式由两个表达式及它们之间的二元运算符组成。

1 + 2        // 一与二之和
a - b        // a 与 b 的差
x < 0.0        // 判断 x 是否小于零

二元运算符也可以是后跟冒号的标识符。

10 rrand: 100

运算符优先级

没有。所有二元运算符具有相同的优先级，并且从左到右结合。例如，表达式：

a * b + c * d

等价于：

((a * b) + c) * d

而非：

(a * b) + (c * d)

因此，通常更好的风格是给表达式加上完整的括号。

函数式记法消息

消息选择器位于括号参数列表之前。列表中的第一个参数实际上是接收者。

sin(x)      // x 的正弦
max(a, b)   // a 与 b 的最大值

接收者记法消息

函数式记法中的方法调用可以通过将接收者放在方法名之前并后跟一个点来转换为接收者记法，如下所示。

max(a, b)

// 等价于：

a.max(b)

// and

sin(x)

// 等价于：

x.sin

另一个示例：

g(f(a, b), c)

// 等价于：

g(a.f(b), c)

// 等价于：

f(a, b).g(c)

// 等价于：

a.f(b).g(c)

默认参数值

调用函数或方法时，传递的参数可以多于或少于其声明接受的参数。如果传入的参数较少，未传入的参数会设置为方法或函数定义中给定的默认值，否则设置为 nil。如果传入的参数过多，多余参数会根据函数或方法是否有省略号参数（在 Functions 中说明）而被收集到 Array 中或被忽略。以零个参数调用方法或函数时，可以省略括号：

// x 被声明为接受两个参数 a 和 b，分别默认为 1 和 2。
// 它返回它们的和。此语法将在函数部分解释。
x = { arg a=1, b=2; a + b };

z = x.value;            // z 被设为 3。（a 默认为 1，b 默认为 2）
z = x.value(10);        // z 设为 12。（a 为 10，b 默认为 2）
z = x.value(10, 5);     // z is set to 15. (a is 10, b is 5)
z = x.value(10, 5, 9);  // z 被设为 15。（a 是 10，b 是 5，9 被忽略）

关键字参数

方法的参数可以通过方法定义中声明时使用的名称来指定。此类参数称为关键字参数。除接收者 this 外，任何参数都可以作为关键字参数传递。关键字参数必须位于任何普通（又称位置）参数之后，并且可以按任意顺序指定。如果指定了某个关键字但没有匹配的参数，则该关键字会被忽略，并会打印一条警告。可以通过进行以下调用在全局范围内关闭此警告：

keywordWarnings(false)

如果关键字参数和位置参数指定了同一个参数，则关键字参数值会覆盖位置参数值。

例如 SinOsc 类的 ar 类方法按此顺序接收名为 freq、phase、mul 和 add 的参数。以下所有写法都是对该方法的合法调用。

SinOsc.ar(800, pi, 0.2, 0); // 所有常规参数：freq、phase、mul、add

// freq = 800，mul = 0.2，其他参数使用默认值。
SinOsc.ar(800, mul: 0.2);

// freq = 800, phase = pi, mul = 0.2, add 获取其默认值零。
SinOsc.ar(phase: pi, mul: 0.2, freq: 800);

// 关键字值 1200 覆盖位置参数值 800
SinOsc.ar(800, freq: 1200);
SinOsc.ar(zorg: 999); // 无效关键字会打印警告

使用 'value' 消息时，Function 的参数也可以通过关键字参数来指定。

// 函数参数可通过关键字指定。
{ arg a=1, b=2, c=3; [a, b, c].postln }.value(b: 7, c: 8);

在使用 'perform' 方法时，你也可以使用关键字参数。

SinOsc.perform('ar', phase: pi, mul: 0.2, freq: 800);

使用关键字参数的开销

使用关键字参数时，进行匹配会产生运行时开销，这是你需要注意的。当速度不是关键因素时，这种开销换来的便利是值得的。
