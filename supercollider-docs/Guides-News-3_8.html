3.8 版本新特性

SC 3.8 新闻摘要

另见：3.7 中的新特性、3.6 中的新特性、3.5 中的新特性、调试技巧

3.8 版新功能较少，主要包含大量小型错误修复。详情请参见 CHANGELOG.md。

SuperCollider IDE

  • 现在鼠标中键可关闭标签页。
  • 新增菜单项 Language > Quarks，用于启动 Quarks.gui。

SuperCollider 语言

  • 新方法：Function: -plotAudio、Bus: -plotAudio。
  • 现在更容易将自定义视图（特别是 SCViewHolder 的子类）插入布局中。
  • 新方法：TreeView: -addChild、TreeView: -insertChild 和 TreeView: -childAt，这些别名方法是为了与 TreeViewItem 保持对称而提供的。

SuperCollider 服务器

  • scsynth 新增了一个命令行选项 -B，允许绑定到特定地址。
  • VOsc 支持音频速率的 phasein 参数。
  • TGrains 支持将 numChannels 设为 1。

API 变更

  • 默认音频总线的数量已从 128 增加到 1024。
  • TGrains、GrainBuf、GrainSin、GrainFM 和 GrainIn 现在在 numChannels 为 2 且 pan 超出范围 [-1, 1] 时具有统一的声像行为。
  • 已从 PathName 弃用若干旧方法：*fromOS9、foldersWithoutCVS、isCVS、foldersWithoutSVN、isSVN、filesDoNoCVS、filesDoNoSVN、streamTreeNoCVS。
  • 在 SoundFileView 的以下方法中，参数 "startframe" 已被重命名为 "startFrame"，"aSoundFile" 已被重命名为 "soundFile"：loadFile、setData、readFile、read、readFileWithTask、readWithTask。

已知问题

尽管已有很大改进，且 3.7 中的许多 bug 已被修复，但仍有许多已知问题。完整列表见：https://github.com/supercollider/supercollider/issues/

请随时将您发现的新问题添加到 issue tracker，或在 mailing list 上提及它们
