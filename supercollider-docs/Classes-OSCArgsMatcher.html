OSCArgsMatcher

在求值 Function 之前测试特定的 OSC 参数

AbstractMessageMatcher : Object

另请参阅：OSCFunc、OSC 通信

说明

OSCArgMatcher 将参数模板与 Function 或类似对象进行匹配。当其 value 方法被调用时，如果其模板中的所有参数都通过 matchItem 测试，则对函数求值。这被 OSCMessageDispatcher 和 OSCMessagePatternDispatcher 用于使用发送者地址将传入的 OSC 消息匹配到 OSCFunc 或 OSCdef 的实例。此类是私有的，通常用户不应直接访问实例。

类方法

OSCArgsMatcher.new(argTemplate, func)

创建一个新的 OSCArgsMatcher

参数：

argTemplate

一个数组，包含用于判断传入参数是否匹配的模板。对于每个你想测试的参数，可以包含一个常量（用于精确匹配）、nil（表示所有可能的值和类型都将匹配），或一个函数来测试传入参数（示例参见 matchItem）。这些条目应与传入 OSC 消息中的条目顺序相同，从索引 1 开始。（索引 0 是 OSC 地址。）

func

一个 Function 或类似对象，它将响应传入的消息。求值时，它会被传入参数 msg、time、addr 和 recvPort，分别对应该消息（以 Array 形式表示为 [OSCAddress, ...otherArgs]）、消息发送的时间、对应发送方 IP 地址的 NetAddr，以及对应接收该消息端口的 Integer。

实例方法

.value(testMsg, time, addr, recvPort)

测试传入消息的参数是否匹配，若匹配则对该对象的函数求值。在正常使用中（在 OSCFunc 内），这是在幕后完成的。

参数：

testMsg

一种 Array，形式为 [OSCAddress, …msgArgs]。

time

消息被发送的时间，以 Float 表示。

addr

一个 NetAddr，对应发送者的 IP 地址。

recvPort

一个 Integer，对应于接收消息所用的端口。

示例

// 基础示例（独立使用）
m = OSCArgsMatcher([1, nil, 2], { 'matches!'.postln });
m.value(['/myAddress', 1, 3, 2], 0.0, NetAddr.localAddr, NetAddr.langPort); // 匹配！
