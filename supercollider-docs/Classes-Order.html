Order

带有数字索引的元素顺序

SequenceableCollection : Collection : Object

参见：SparseArray

子类：SparseArray

说明

按顺序保存元素，并允许将元素放入任意槽位，而无需分配大型数组。

注意： -put 和 -at 比在 IdentityDictionary / PriorityQueue 中更慢，-do 更快。

类方法

Order.new(size: 8)

创建一个新顺序。

g = Order.new;
g.put(7, 100); // 在索引 7 处放置一个值（100）
g.clear; // empty

Order.newFromIndices(array, indices)

根据给定的项和索引创建一个新的顺序。

实例方法

.doRange(function, from: 0, to)

遍历该 order 条目的一个范围。
