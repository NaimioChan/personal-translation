Mix

对通道数组求和。

Object

说明

Mix 会将一个声道数组混合为单个声道，或将一个由声道数组组成的数组混合为单个声道数组。更多信息可在 Multichannel Expansion 下找到。

注意： 请注意，SC2 中的 Mix.ar 和 Mix.kr 等价于 SC3 中的 Mix.new，而 Mix.arFill 和 Mix.krFill 等价于 Mix.fill。

类方法

Mix.new(array)

参数：

array

声道或数组的数组。

Mix.fill(n, function)

参数：

n

要创建的数组的大小。

function

数组填充函数。

返回值：

返回：一个新创建的 UGen 。

未文档化的类方法

Mix.ar(array)

Mix.arFill(n, function)

Mix.kr(array)

Mix.krFill(n, function)

实例方法

示例

s.boot;

{ Mix.new([PinkNoise.ar(0.1), FSinOsc.ar(801, 0.1), LFSaw.ar(40, 0.1)]) }.play

(
play({
    Mix.new(Array.fill(8, { SinOsc.ar(500 + 500.0.rand, 0, 0.05) }));
}))

(
play({
    Mix.fill(8, { SinOsc.ar(500 + 500.0.rand, 0, 0.05) });
}))
