LIDGui

LID 的 GUI

参见：LID

说明

该类为 LID 设备创建一个简单的 GUI。

类方法

.new

创建一个新的 GUI。

参数：

device

一个 LID 实例，用于为其创建 GUI。

实例方法

.win

LIDGui 所在的窗口。

.device

此 GUI 所对应的设备。

示例

LID.findAvailable;
LID.postAvailable; // 选择你想打开的那个，并在下一行填写 vendor 和 product id：
d = LID.open(2, 10); // trackpoint

g = LIDGui.new(d);

// 或使用快捷方法：
g = d.makeGui;
