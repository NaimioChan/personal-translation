DoesNotUnderstandError

调用未知方法名时抛出的错误

MethodError : Error : Exception : Object

另请参阅：Error

子类：BinaryOpFailureError

说明

此错误通常在接收者上调用不存在的方法时产生。用户通常不会自己构造此对象。该对象有几个获取器（getter），可用于进一步了解导致该错误的调用。

此方法会报告回溯，以及基于编辑距离的最佳猜测建议替换项。

类方法

DoesNotUnderstandError.new(receiver, selector, args, keywordArgumentPairs)

构造一个新的 DoesNotUnderstandError，并根据接收者的类和选择子的内容选择一个可能的建议替换。

参数：

receiver

调用该方法时所作用的对象。

selector

未理解的方法名。

args

传递给未知方法的参数。

keywordArgumentPairs

传递给 DoesNotUnderstandError 的关键字参数。

实例方法

.selector

.selector = value

返回值：

传递给 new 的选择器。通常是未被理解的方法名。

.args

.args = value

返回值：

传递给 new 的参数。通常是一个传递给未知方法的参数数组。

.suggestedCorrection

返回值：

如果有一个接收者能够理解、且与未知方法名相似的方法，则返回与之对应的 Method 对象。否则返回 nil。

.errorString

返回值：

以 String 形式简短表示该错误，若找到替换建议则一并给出。

.reportError

打印该错误的详细说明，包括回溯以及建议的替代方案（如果找到）。
