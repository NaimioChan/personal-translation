HilbertFIR

对输入信号应用希尔伯特变换。

UGen : AbstractFunction : Object

参见：Hilbert、FreqShift

说明

返回两个通道：原始信号以及该信号经过 90 度（0.5 pi 弧度）相移后的副本。HilbertFIR 输出两个通道，包含输入信号和变换后的信号。HilbertFIR 使用 FFT 和 90 度相移来变换信号，产生的延迟等于用于 FFT 的缓冲区大小除以采样率。Hilbert UGen 的延迟较小，但会在频谱的高八度产生失真。

类方法

HilbertFIR.ar(in, buffer)

参数：

in

要变换的输入信号。

buffer

用于 FFT 间处理的缓冲区。大小为 1024 或 2048 时效果最佳。1024 可给出可接受的结果（尽管略显生硬），2048 则平滑得多，但会产生更多延迟。

s.boot;
s.scope;
a = { HilbertFIR.ar(SinOsc.ar(100) * -20.dbamp, LocalBuf(2048)) }.play;
a.release;
