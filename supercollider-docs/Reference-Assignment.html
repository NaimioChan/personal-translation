赋值语句

为变量赋值

单次赋值

单次赋值将右侧表达式的值赋给左侧的变量。单次赋值的形式为：

<variable> = <an expression>

examples:

x = [1, 2, 3, 4].rotate(1);
c = a + b;

变量可以在任何时候赋值，包括在声明期间。

(
// 声明中的赋值
var one = 1;
var two = 2;
var four = two + 2;

// 重新赋值
two = two + one;
two = "and now for something completely different"
two = nil;

)

在某些情况下，链式重新赋值很有用：

(
{
    var sig;
    sig = SinOsc.ar(LFNoise0.kr(10).exprange(1, 1000));
    sig = SinOsc.ar(310, sig * 3);
    sig = SinOsc.ar(230, sig * 0.4);
    sig * 0.2
}.play
)

多重赋值

多重赋值语句将右侧表达式的结果（一个 Collection）的元素赋值给左侧的变量列表。多重赋值语句前面带有符号 #。如果左侧最后一个变量前面有三个点，那么集合的整个剩余部分都会赋值给该变量。省略号之前必须至少有一个变量名。

多重赋值的形式是：

# <list of variables> = <expression>

-- 或 --

# <list of variables> ... <variable> = <expression>

examples:

# a, b, c = [1, 2, 3, 4, 5, 6]; // 之后 a=1, b=2, c=3

# a, b ... c = [1, 2, 3, 4, 5, 6]; // afterwards a=1, b=2, c = [3, 4, 5, 6]

# ... a = [1, 2, 3, 4, 5, 6]; // ILLEGAL, just use:    a = [1, 2, 3, 4, 5, 6];

多重赋值通过 'at' 方法和 'copyToEnd' 方法实现。右侧表达式可以返回任何响应这些消息的对象。

实例变量赋值

设置实例变量值的基本语法是使用该变量的 setter 方法，即变量名后加下划线。

point.x_(5); // 将点的 x 坐标设为 5

另一种语法是使用实例变量赋值。

point.x = 5;

这种赋值形式会被编译器转换为第一种形式。两种语法是等价的。

对 ArrayedCollection 或 List 的序列赋值

有一种特殊语法可用于对 ArrayedCollection 或 List 中的一段值范围进行赋值。

a = (0,10..200);
a[5..10] = 1;  // 以 1 为步长递增

a = (0,10..200);
a[7,9..13] = 1; // 任意步长的序列

a = (0,10..200);
a[..5] = 1;  // 从零到 n

a = (0,10..200);
a[12..] = 1;  // 从 n 到数组末尾

a = (0,10..200);
a[1,3..] = 1;  // 将序列追加到数组末尾
