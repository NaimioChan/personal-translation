PlazyEnvir

从函数实例化新模式

Plazy : Pattern : AbstractFunction : Object

另请参阅：Plazy、PlazyEnvirN、Pfunc

子类：PlazyEnvirN

说明

求值一个返回模式的函数，并将其嵌入到流中。与 Plazy 不同，该函数使用流传入的环境进行求值。

类方法

PlazyEnvir.new(func)

来自父类：Plazy

参数：

func

一个返回模式或任何其他有效模式输入的 Function。

实例方法

未文档化的实例方法

.embedInStream(inval)

.passEvent

.passEvent = value

示例

(
a = PlazyEnvir({ |a = 0, b = 1| Pshuf([a, a, b], 2) }); // a, b 默认为 0, 1
x = Pn(a, inf).asStream;

10.do { x.next.postln }; Post.nl;
e = (a: 100);
10.do { x.next(e).postln }; Post.nl;
e = (a: 100, b: 200);
10.do { x.next(e).postln };
)


// PlazyEnvir 用于生成 Pbind：

(
SynthDef(\help_sinegrain,
    { |out = 0, freq = 440, sustain = 0.05, pan = 0|
        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain, 0.2), doneAction: Done.freeSelf);
        Out.ar(out, Pan2.ar(SinOsc.ar(freq, 0, env), pan))
    }).add;

a = PlazyEnvir({ |g = 0, h = 0, dur = 1|
    postf("g: %, h: %, dur: %\n", g, h, dur);
    Pbind(
        \instrument, \help_sinegrain,
        \dur, dur,
        \degree, Pseq([g, g, h, g, h], 2)
    )
});
)

// 不同变体
(a <> (g: 0, h: 3, dur: 0.2)).play; // 单流
(a <> (g: [0, 4], h: [3, -1], dur: 0.2)).play; // 相同的时长，两个流

有关组合运算符 <> 的更多信息，请参见：Pchain。

某些参数（如 duration）在 Pbind 中不能以数组形式使用。完整的并行展开请参见 PlazyEnvirN。
