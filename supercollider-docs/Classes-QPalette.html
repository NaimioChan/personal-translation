QPalette

GUI 使用的颜色集合

说明

QPalette 是 GUI 系统用于绘制视图的一组颜色。这些颜色被组织成三个颜色组（active、inactive 和 disabled），根据所绘制视图的状态使用，每个组包含一个分配给各个颜色角色（window、windowText、button、buttonText 等）的颜色，用于绘制视图的不同元素。详见颜色角色和颜色组。

可以使用 QtGUI: *palette 为整个 GUI 分配调色板，或使用 View: -palette 为特定视图分配调色板。除非显式地为视图分配调色板，否则视图将从其父级继承调色板，并最终继承 QtGUI 的调色板。此外，在视图上设置调色板时，它会与继承的调色板合并，仅覆盖调色板上显式设置的那些颜色（参见 -hasColor）。因此，分配一个新的未修改的调色板会将所有颜色重置为继承的颜色。

还有两个预定义调色板，可通过 *light 和 *dark 访问。启动时默认将浅色调色板分配给 QtGUI。如果你希望使用与所在平台原生配色方案相匹配的调色板，可通过 *system 访问该调色板。

如果你想设计自己的调色板，最方便的方法是使用 *auto，它仅根据两种颜色自动推导出调色板，然后你可以按需修改细节。

注意，在 Qt GUI 中，视图的大多数与颜色相关的方法（如 Window: -background、Slider: -knobColor 等）实际上修改的是视图的调色板。

类方法

.new

实例化一个新的调色板，等价于分配给 QtGUI 的全局调色板。所有颜色都被视为未设置（参见 -hasColor）。

.auto

实例化一个新的调色板，其 'button' 和 'window' 颜色角色的颜色自动从给定颜色派生。所有颜色都被视为已设置（参见 -hasColor）。

参数：

buttonColor

分配给按钮角色的 Color。

windowColor

分配给窗口角色的 Color。

.light

使用浅色系的预定义调色板。所有颜色都被视为已设置（参见 -hasColor）。

.dark

一个使用深色的预定义调色板。所有颜色都被视为已设置（参见 -hasColor）。

.system

系统原生调色板。所有颜色都被视为已设置（参见 -hasColor）。

实例方法

.color

返回分配给颜色组内某个颜色角色的颜色。

参数：

role

一个符号，属于 Color 角色。

group

一个属于 Color groups 的符号，或 nil（此时使用当前颜色组）。

.setColor

为颜色组内的某个颜色角色分配颜色。

参数：

color

一个 Color。

role

一个符号，属于 Color 角色。

group

Color groups 中的一个符号，或 nil，在这种情况下颜色将被分配给所有组。

.hasColor

是否已在此 QPalette 实例上设置属于某个颜色角色和颜色组的颜色。

在视图上设置调色板时，只有此方法返回 true 的颜色会被更改，其他颜色将从父视图（如果此视图没有父视图，则为 QtGUI）继承。

参数：

role

一个符号，属于 Color 角色。

group

颜色组中的一个符号。

.window

用于获取或设置 'window' 角色颜色的便捷方法。

.windowText

用于获取或设置 'windowText' 角色颜色的便捷方法。

.button

用于获取或设置 'button' 角色颜色的便捷方法。

.buttonText

用于获取或设置 'buttonText' 角色颜色的便捷方法。

.base

用于获取或设置“base”角色颜色的便捷方法。

.baseText

用于获取或设置 'baseText' 角色颜色的便捷方法。

.highlight

获取或设置 'highlight' 角色颜色的便捷方法。

.highlightText

获取或设置 'highlightText' 角色颜色的便捷方法。
