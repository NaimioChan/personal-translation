GbmanN

Gingerbreadman 映射混沌生成器

ChaosGen : UGen : AbstractFunction : Object

另请参阅：GbmanL

子类：GbmanL

说明

一个基于差分方程的非插值声音发生器：

        x(n+1) = 1 - y(n) + |x(n)|
        y(n+1) = x(n)

系统的行为仅取决于其初始条件。

sclang 代码转换：

(
var xi = 1.2, yi = 2.1, size = 64;
plot(size.collect { var x; xi = 1 - yi + abs(x = xi); yi = x; xi });
)

参考：Devaney, R. L. "The Gingerbreadman." Algorithm 3, 15-16, Jan. 1992.

GbmanN.ar(freq: 22050, xi: 1.2, yi: 2.1, mul: 1, add: 0)

实例方法

示例

// 默认初始参数
{ GbmanN.ar(MouseX.kr(20, SampleRate.ir)) * 0.1 }.play(s);

// 更改初始参数
{ GbmanN.ar(MouseX.kr(20, SampleRate.ir), -0.7, -2.7) * 0.1 }.play(s);

// 等待中……
{ GbmanN.ar(MouseX.kr(20, SampleRate.ir), 1.2, 2.0002) * 0.1 }.play(s);

// 作为频率控制
{ SinOsc.ar(GbmanN.ar(40)*400+500)*0.4 }.play(s);
