DigitalIO

读取或写入数字引脚的数据

UGen : AbstractFunction : Object

另请参见：AnalogIn、AnalogOut、DigitalIn、DigitalOut

说明

从数字引脚读取或向数字引脚写入数字数据。此 UGen 的引脚号可以调制，其 I/O 模式也可以调制，从而允许将引脚置于三态。

注意： 此 UGen 仅在 Bela 上运行。

注意： 如果你不需要更改引脚模式或引脚，则应使用 UGen DigitalIn 或 DigitalOut

类方法

DigitalIO.ar(digitalPin: 0, output: 0, pinMode: 0, mul: 1.0, add: 0.0)

当数字引脚为输入时，此 UGen 的输出始终是最后读取的值。

参数：

digitalPin

要写入的数字引脚编号。引脚编号从 0 开始。此值可在音频速率下调制。

output

要写入引脚的值——当参数大于 0 时该值为 1，否则为 0。此值可以按音频速率调制。

pinMode

要写入引脚的值——当该参数小于 0.5 时，引脚为输入，否则为输出。此值可在音频速率下调制。

mul

add

DigitalIO.kr(digitalPin: 0, output: 0, pinMode: 0, mul: 1.0, add: 0.0)

当数字引脚为输入时，此 UGen 的输出始终是最后读取的值。

参数：

digitalPin

要写入的数字引脚编号。引脚编号从 0 开始。

output

要写入引脚的值——当参数大于 0 时该值为 1，否则为 0。

pinMode

要写入引脚的数值——当该参数小于 0.5 时，该引脚为输入，否则为输出。

mul

add
