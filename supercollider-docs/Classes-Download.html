Download

从远程 URL 获取文件

参见：File

说明

Download 允许你从指定的 URL 下载文件

类方法

.new

创建并启动一个新的 Download。

参数：

requestedURL

一个包含要下载文件的 URL 的 String。

localPath

一个 String，包含用于保存下载文件的本地路径。

finishedFunc

下载完成后要执行的 Function。

errorFunc

当下载因错误而失败时要执行的 Function。

progressFunc

一个用于处理下载进度的 Function。此 Function 将接收两个参数：已接收的字节数和总字节数。

返回值：

一个新的下载。

.cancelAll

取消所有活动下载。

实例方法

.cancel

取消下载。

.errorFunc

获取或设置错误 Function。

.finishedFunc

获取或设置下载完成的 Function。

.progressFunc

获取或设置下载进度的 Function。

示例

(
var url = "https://scottwilson.ca/files/flame.mp3";
var localPath = Platform.defaultTempDir +/+ url.split($/).last;

d = Download(
    url,
    localPath,
    {
        "downloaded to %".format(localPath).postln;
    },
    {
        "error".postln;
    },
    { |receivedBytes, totalBytes|
        "Downloaded %\\%".format((receivedBytes/totalBytes*100.0).round(1e-2)).postln;
    },
);
)

d.cancel; // 取消此操作
