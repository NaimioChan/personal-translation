PV_BinShift

平移并拉伸 bin 位置。

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

另请参见：FFT、IFFT、PV_MagShift

说明

平移和缩放各 bin 的位置。可用作非常粗略的移频器/频率缩放器。

类方法

PV_BinShift.new(buffer, stretch: 1.0, shift: 0.0, interp: 0)

参数：

buffer

FFT 缓冲区。

stretch

按因子缩放 bin 位置。

shift

为 bin 位置添加偏移。

interp

设为 0（默认）表示不插值，或设为 1 表示在频段之间进行线性插值。

实例方法

示例

s.boot;

(
c = Buffer.read(s, ExampleFiles.child);
)

(
SynthDef("help-binStretch", { |out = 0|
    var in, chain;
    in = LFSaw.ar(200, 0, 0.2);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_BinShift(chain, MouseX.kr(0.25, 4, \exponential));
    Out.ar(out, 0.5 * IFFT(chain).dup);
}).play;
)

(
SynthDef("help-binStretch2", { |out = 0, soundBufnum = 2|
    var in, chain;
    in = PlayBuf.ar(1, soundBufnum, BufRateScale.kr(soundBufnum), loop: 1);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_BinShift(chain, MouseX.kr(0.25, 4, \exponential));
    Out.ar(out, 0.5 * IFFT(chain).dup);
}).play(s, [\out, 0, \soundBufnum, c.bufnum]);
)

(
SynthDef("help-binShift", { |out = 0, bufnum = 0|
    var in, chain;
    in = LFSaw.ar(200, 0, 0.2);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_BinShift(chain, 1, MouseX.kr(-128, 128));
    Out.ar(out, 0.5 * IFFT(chain).dup);
}).play;
)

(
SynthDef("help-binShift2", { |out = 0, soundBufnum = 2|
    var in, chain;
    in = PlayBuf.ar(1, soundBufnum, BufRateScale.kr(soundBufnum), loop: 1);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_BinShift(chain, 1, MouseX.kr(-128, 128));
    Out.ar(out, 0.5 * IFFT(chain).dup);
}).play(s, [\out, 0, \soundBufnum, c.bufnum]);
)
