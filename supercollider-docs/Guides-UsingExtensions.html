使用扩展

参见：Writing Unit Generators、Using Quarks、Writing Classes

SC 支持对其类库、文档和服务器 UGen 插件进行扩展。扩展应打包为包含这三者的单个文件夹（便于添加或移除），或任意组合，然后可将其放入平台特定的扩展目录中以被包含。

平台特定目录

只需将扩展复制到以下位置即可安装扩展。针对每个用户和系统范围的扩展有不同的目录，后者适用于所有用户。可以通过运行 Platform.userExtensionDir 和 Platform.systemExtensionDir 获取这些位置。

典型的用户特定扩展目录：

macOS

~/Library/Application Support/SuperCollider/Extensions/

Linux

~/.local/share/SuperCollider/Extensions/

Windows

%LOCALAPPDATA%/SuperCollider/Extensions/

典型的系统级扩展目录：

macOS

/Library/Application Support/SuperCollider/Extensions/

Linux

/usr/share/SuperCollider/Extensions/

Windows

%PROGRAMDATA%/SuperCollider/Extensions/

扩展文件夹应如何组织

类文件和 UGen 插件通过其文件扩展名来识别。任何放置在名为 ignore/（不区分大小写）的文件夹中的内容，在编译类库或加载插件时都将被忽略。

以下是一个示例文件夹布局：

MyExtension

  • classes

    • myClass.sc
    • myUGens.sc

  • plugins

    • myUGenPlugins.scx

  • HelpSource

    • Classes

      • MyClass.schelp
      • MyUGen1.schelp
      • MyUGen2.schelp

    • Guides

      • MyExtensionGuide.schelp
