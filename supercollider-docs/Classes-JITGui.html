JITGui

即时接口的父类

说明

JITLib 中实现的 synth、task 和 pattern 的代理非常灵活。拥有表示其可变状态的 gui 有助于理解正在发生的事情，尤其是在同时使用多个代理时。JITGui 遵循下面描述的特殊策略。

另请参阅

类方法

Creation

.new

创建一个新的 JITGui，用于监视某个对象并显示其状态。

g = JITGui.new(nil, 0);        // 创建一个 JITGui
g.object = 123;                // 其对象显示为 asCompileString
g.object = (key: \otto);     // 如果对象理解 .key，则 key 会作为名称显示
g.object = Pseq([1, 2, 3], inf);
g.close;

参数：

object

要监视的对象

numItems

要使用的显示项数量，例如文本显示使用多少个字段，或单数值参数使用多少个滑块。

parent

用于显示的父视图。如果为 nil，则创建一个新窗口；parent 也可以是一个已存在的窗口或复合视图。

bounds

用于显示 JITGui 的期望尺寸和位置。可以为 nil、一个 Point 或一个 Rect。JITGui 知道自己的最小尺寸（minSize），如果 bounds 为 nil，则使用 minSize。如果 bounds 是一个 Point 或 Rect，它将被设置为至少 minSize。使用 Rect 时还可以提供显示位置。如果是 Point，则显示的尺寸是 bounds 和 minSize 中的最大值。

makeSkip

一个是否创建 skipjack 的标志。（如果 GUI 位于独立窗口中，通常会使用一个；如果 JITGui 是更大 GUI 的一部分，则该 GUI 可能负责更新。）

options

附加信息列表，例如关于可选按钮的标志。（这用于某些子类中。）

JITGuis 如何工作

JITGui 通过以适当的间隔（skipjack.dt）调用其（gui 的）-getState 方法来监视其对象的状态。它将对象的新状态与存储在 -prevState 中的先前状态进行比较。当有内容发生变化时，只更新相关的 gui 元素。

将其与模型-视图-控制器（MVC）进行比较：

  • MVC 要求对象在所有状态可能改变的地方调用 .changed，以便通知其依赖者；JITGui 则不需要。
  • MVC 会立即更新依赖者，而 JITGui 的更新可能更慢。对于 GUI，设置非常快速的变化（例如参数自动化）可能产生一些 CPU 负载；使用 JITGui 时，更惰性的显示限制了这一最坏情况下的负载。
  • 只有 JITGui 知道其对象，因此无需处理依赖管理。

1 - 子类应实现的方法

你可以通过在类中实现以下方法的相应变体，非常高效地为 JITGui 编写自己的子类。有关这些方法的示例，参见 TdefGui、EnvirGui、NdefGui。

.setDefaults

用于计算 jitGui 区域所需的屏幕大小。应根据 -numItems 和选项来确定区域大小。此外，可在此处设置 -defPos（默认显示 jitGui 的位置），并可能对所使用的皮肤进行修改。

.accepts

测试 obj 是否能在特定类型的 JITGui 中显示。JITGui 的子类是为特定对象（例如 Pdef）创建的，因此它们应测试 obj 是否为正确的类型。

.makeViews

在区域内创建 jitGui 的所有视图。

2 - 用于更新 JITGui，覆盖这些方法

.getState

向对象询问其将要显示的所有当前状态方面。

.checkUpdate

用 -prevState 获取对象的当前状态，将其与 prevState 比较，更新所有需要更改的 gui 元素，并将新状态存为 prevState。此方法在 skipJack 中调用。

3 - 如果需要，你可能想要覆写的更多方法

.calcBounds

如何计算用于显示该区域的边界

.makeWindow

未指定父窗口时如何创建窗口

.makeZone

如何在父窗口或视图中初始化该区域

.getName

一种为对象生成名称的方法。

.winName

用于为 JITGui 窗口生成名称的方法。

.makeScroller

某些对象要显示的元素可能多于 gui 具有的槽位，例如一个 ProxySpace 的代理数量可能多于混音器的 numItems。此时，只显示 -numItems 个元素，其余元素可通过 -scroller 滚动查看——即槽位元素旁边的 EZScroller。makeScroller 方法应知道在区域中何处放置滚动条。

    // 通常只使用 JITGui 的子类，
    // 所以这里只是一些基本用法和布局测试
