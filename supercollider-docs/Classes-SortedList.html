SortedList

其元素保持排序顺序的 Collection。

List : SequenceableCollection : Collection : Object

类方法

SortedList.new(size: 8, function)

创建一个 SortedList，其初始容量由 size 给定，比较函数由 function 指定。该 SortedList 可以多次包含相等/相同的元素。

实例方法

.add(item)

在 SortedList 中的正确位置添加一项。

SortedList[1, 2, 5, 6].add(4).postln;

.addAll(aCollection)

将集合中的所有项添加到 SortedList 中。

SortedList[1, 2, 5, 6].addAll([0, 3, 4, 7]).postln;
