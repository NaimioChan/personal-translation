Duty

从需求率 UGen 获取需求结果。

UGen : AbstractFunction : Object

另请参阅：Demand、TDuty

子类：TDuty

说明

列表中的每个 UGen 都会被要求提供一个值，并根据一个时长值流进行输出。列表中的单元生成器应为 'demand' 速率。

当 reset 输入有触发时，列表中的 demand rate UGen 和 duration 会被重置。reset 输入也可以是一个 demand UGen，提供重置时间的流。

类方法

Duty.ar(dur: 1.0, reset: 0.0, level: 1.0, doneAction: 0)

Duty.kr(dur: 1.0, reset: 0.0, level: 1.0, doneAction: 0)

参数：

dur

时间值。可以是 demand UGen 或任意信号。经过该时长后获取下一层级。

reset

触发或重置时间值。触发时重置 UGen 列表和持续时间 UGen。重置输入也可以是一个需求 UGen，提供一个重置时间流。

level

提供输出值的 Demand UGen。

doneAction

当持续时间流结束时求值的 doneAction。参见

Done 以获取更多细节。

将 UGen 作为音频振荡器来 Demand：

(
    {
        var a, n = 5, m = 64;
        a = {
            var x;
            x = { 0.2.rand2 } ! m;
            x = x ++ ({  Drand({ 0.2.rand2 } ! n) } ! m.rand);
            Dseq(x.scramble, inf)
        } ! n;
        Duty.ar(
                MouseX.kr(1, 125, 1) * SampleDur.ir * [1, 1.02],
                0,
                Dswitch1(a, MouseY.kr(0, n-1))
            )

    }.play;
)

单采样反馈：一个 lin cong 算法：

(
b = Buffer.alloc(s, 1);
{
var x, y, rate, a, c, m;
    rate = MouseX.kr(100, SampleRate.ir);
    a = 1.1;
    c = 0.13;
    m = 1.0;
    x = Dbufrd(b); // 从缓冲区读取
    x = x * a + c % m;
    y = Dbufwr(x, b); // 写入缓冲区
    Duty.ar(1 / rate, 0, y) * 0.1;
}.play;
)
