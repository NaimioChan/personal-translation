NRand

均匀分布之和。

UGen : AbstractFunction : Object

另请参阅：ExpRand、IRand、LinRand、Rand、TExpRand、TIRand、TRand

说明

生成单个随机浮点值，其值为 n 个从 lo 到 hi 的均匀分布之和。

类方法

NRand.new(lo: 0.0, hi: 1.0, n: 0)

参数：

lo

输出范围的下限。

hi

输出范围的上限。

n

n = 1:

均匀分布 - 与 Rand 相同。

n = 2:

三角分布。

n = 3:

平滑隆起。

随着 n 增大，分布收敛于高斯分布。

n = 1:

均匀分布 - 与 Rand 相同。

n = 2:

三角分布。

n = 3:

平滑隆起。

实例方法

示例

(
SynthDef("help-NRand", { |out = 0, n = 0|
    Out.ar(out,
        FSinOsc.ar(
            NRand(1200.0, 4000.0, n),
            0, Line.kr(0.2, 0, 0.01, doneAction: Done.freeSelf))
    )
}).add;
)

(
n = 0;
Routine({
    inf.do({ |i|
        Synth.new("help-NRand", [\n, n]); 0.05.wait;
    })
}).play;
)

n = 1;
n = 2;
n = 4;
