ObjectTable

将对象与 ID 关联

TwoWayIdentityDictionary : Collection : Object

说明

ObjectTable 用于将 id 与对象关联起来。这对于通过 Open Sound Control 在远程系统上引用对象很有用。

类方法

ObjectTable.add(obj)

将一个对象放入主 ObjectTable 并生成一个 Integer id。

参数：

obj

要放入表中的对象。

ObjectTable.put(key, obj)

将对象放入主 ObjectTable 中指定的键下。

参数：

key

一个 Symbol。

obj

要放入表中的对象。

ObjectTable.at(id)

获取主 ObjectTable 中的一个对象。

参数：

id

一个 Integer 或 Symbol。

ObjectTable.getID(obj)

获取表中对象的 ID。

参数：

obj

表中的一个对象。
