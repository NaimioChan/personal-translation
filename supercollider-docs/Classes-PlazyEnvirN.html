PlazyEnvirN

从函数实例化新模式并对它们进行多通道扩展

PlazyEnvir : Plazy : Pattern : AbstractFunction : Object

另请参阅：Plazy、PlazyEnvir、Pfunc

说明

求值一个返回模式的函数，并将其嵌入到流中。

  • 与 Plazy 不同，函数使用流传入的环境进行求值。
  • 与 PlazyEnvir 不同，如果函数参数接收到多个通道，PlayzEnvirN 会扩展成多个并行模式。这仅适用于事件流。

类方法

PlazyEnvirN.new(func)

参数：

func

一个返回模式或任何其他有效模式输入的 Function。

(
f = { |g = 0, h = 0, dur = 1|
    Pbind(\degree, Pseq([g, g, h, g, h], 2), \dur, Pseries(dur, 0.1))
};
// 比较：
a = Pchain(PlazyEnvirN(f), (g: [1, 2], h: 3, dur: 0.2)).trace(\degree).asStream;
c = Pchain(Plazy(f), (g: [1, 2], h: 3, dur: 0.2)).asStream;
)

a.nextN(4);
c.nextN(4); // 没有度数，因为流已结束

示例

(
SynthDef(\help_sinegrain,
    { |out = 0, freq = 440, sustain = 0.05, pan = 0|
        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain, 0.2), doneAction: Done.freeSelf);
        Out.ar(out, Pan2.ar(SinOsc.ar(freq, 0, env), pan))
    }).add;

a = PlazyEnvirN({ |g = 0, h = 0, dur = 1|
    postf("g: %, h: %, dur: %\n", g, h, dur);

    Pbind(
        \instrument, \help_sinegrain,
        \dur, dur,
        \degree, Pseq([g, g, h, g, h], 2)
    )
});
)

// 不同变体
(a <> (g: 0, h: 3, dur: 0.2)).play; // 单流
(a <> (g: [0, 4], h: [3, -1], dur: 0.2)).play; // 相同的时长，两个流
(a <> (g: [0, 4], h: [3, -1], dur: [0.2, 0.3])).play; // 不同时长，两个流

有关组合运算符 <> 的更多信息，请参见：Pchain。
