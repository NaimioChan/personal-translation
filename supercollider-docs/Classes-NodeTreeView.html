NodeTreeView

显示服务器端节点树

参见：Server、ServerTree

说明

NodeTreeView 显示服务器上的节点树。

类方法

.new

参数：

server

要显示其节点树的服务器。

bounds

一个 Rect，或任何响应 .asRect 方法的对象。

parent

NodeTreeView 所放置的 View 或 Window。

实例方法

.close

关闭接收者。

示例

// 启动分配给变量 s 的本地服务器:
s.boot;

// 播放一个重复模式，每 0.4 秒触发一个新的 synth：
x = Pn((dur: 0.4, midinote: 69, amp: 0.1)).play;

// 创建一个 NodeTreeView 实例并赋值给变量 a：
a = NodeTreeView(s)

// 开始为赋值给变量 a 的 NodeTreeView 实例绘制节点：
a.start // 绘图间隔：0.5 秒（默认）

// 创建额外的 NodeTreeView 实例：
b = NodeTreeView(s)
c = NodeTreeView(s, Rect(400, 50, 300, 400)) // 此实例将被调整大小。

// 创建一个启用了即时绘图的 NodeTreeView 实例：
d = NodeTreeView(s, Rect(600, 50, 400, 400)).start(2) // 当分配给变量 a 的 NodeTreeView 正在运行时，2 秒的绘图间隔将不会被应用。

// 关闭赋值给变量 b 的 NodeTreeView 实例：
b.close

// 停止分配给变量 a 的 NodeTreeView 实例的绘图进程：
a.stop

// 关闭多个 NodeTreeView 实例（分别赋值给变量 a 和 c）：
[a, c].do { |v| v.close }

// 打开一个 plotTree 窗口：
s.plotTree // 这也会改变分配给变量 d 的 NodeTreeView 实例的间隔，因为目前这个类只有一个 updater。

// 停止分配给变量 d 的 NodeTreeView 实例的绘图进程：
d.stop

// 停止 pattern 的播放：
x.stop

// 关闭赋值给变量 d 的 NodeTreeView 实例：
d.close
