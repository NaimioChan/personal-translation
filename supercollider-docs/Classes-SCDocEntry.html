SCDocEntry

一个 SCDoc 文档索引条目

Object

另请参阅：SCDoc

说明

此类由 SCDoc 用于表示帮助文件索引中的文档。

所表示的文档可以是真实的 .schelp 文件，也可以是为未记录类自动生成的存根。

类方法

SCDocEntry.new(node, path)

创建并初始化一个新实例。

参数：

node

一个 SCDocNode 实例。不必是完整解析的文档，因为只使用头部标签、方法和关键字。（参见 SCDoc: *parseFileMetaData）。

path

用于文档键的 String，例如 "Classes/SinOsc"。

SCDocEntry.newUndocClass(name)

为一个未文档化的类创建并初始化一个新实例。

参数：

name

未记录类的名称

实例方法

文档属性

.path

.path = value

用于文档键的 String，例如 "Reference/SCDocSyntax"。

.title

.title = value

文档标题。对于类参考文档，应等于类名。

.summary

.summary = value

文档摘要。

.categories

.categories = value

文档类别。一个由 String 组成的 Array。

.related

.related = value

相关文档链接。一个字符串的 Array。

.keywords

.keywords = value

文档中列出的关键字。一个由字符串组成的 Array。

.fullPath

.fullPath = value

此文档的 .schelp 文件的完整路径（如果有）。

.mtime

.mtime = value

.schelp 文件的修改时间（如果有）。

.destPath

渲染目标路径。

.docmethods

.docmethods = value

已记录的方法，但不是类方法或实例方法。由字符串组成的数组。

.additions

.additions = value

此文档的文档附加列表（*.ext.schelp）。是一个由 Strings 组成的 Array。

.isExtension

.isExtension = value

如果此文档是扩展（不属于主库），则为 true。一个 Boolean

.isClassDoc

.isClassDoc = value

如果此文档是类文档则为真。一个布尔值

类文档

这些方法和属性仅用于类文档。

.klass

.klass = value

所记录的 Class。

.isUndocumentedClass

.isUndocumentedClass = value

如果此类无文档（意味着没有 .schelp 文件），则为 true。一个 Boolean

.doccmethods

.doccmethods = value

已文档化的类方法列表。

.docimethods

.docimethods = value

已记录实例方法的列表。

.privcmethods

.privcmethods = value

私有类方法的列表。

.privimethods

.privimethods = value

私有实例方法列表。

.undoccmethods

.undoccmethods = value

未记录的类方法列表。

.undocimethods

.undocimethods = value

未文档化实例方法的列表。

.makeMethodList

返回所有非私有方法的字符串列表，前缀为 xy，其中 x 对于已记录的方法为 _，对于未记录的方法为 ?，y 对于类方法为 *，对于实例方法为 -，对于其他/通用方法为 .。

.redirect

.redirect = value

保存实现类的类变量的名称。例如供 GUI 重定向系统使用。

.implKlass

.implKlass = value

实现它的 Class（如果已设置 redirect）。

.implements

.implements = value

正在实现的 Class。例如，QButton 的条目将此设置为 Button

.toJSON(stream)

将此文档条目的一种表示形式以 JSON 写入 Stream。用于将文档条目导出到HTML 帮助浏览器中使用的 javascript。

参数：

stream

一个 Stream。
