MidEQ

参数化滤波器。

Filter : PureUGen : UGen : AbstractFunction : Object

说明

衰减或增强某个频段。

类方法

MidEQ.ar(in: 0.0, freq: 440.0, rq: 1.0, db: 0.0, mul: 1.0, add: 0.0)

MidEQ.kr(in: 0.0, freq: 440.0, rq: 1.0, db: 0.0, mul: 1.0, add: 0.0)

参数：

in

输入信号。

freq

频段的中心频率，单位为赫兹。

rq

Q 的倒数（bandwidth / cutoffFreq）。

db

频段的提升量（db > 0）或衰减量（db < 0）。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

// 作为 wahwah 的混音器参数均衡
{ MidEQ.ar(Saw.ar(200, 0.2), FSinOsc.kr(1, 0, 24, 84).midicps, 0.3, 12) }.play


// 陷波滤波器
(
{ var in;
  in = PinkNoise.ar(0.2) + SinOsc.ar(600, 0, 0.1);
  MidEQ.ar(in, SinOsc.kr(0.2, 0.5pi) * 2 + 600, 0.01, -24)
}.play
)

/////
// 首先启动 synth
(
x = { |freq = 400, db = 0, rq = 0.1|
     var in;
     in =  SinOsc.ar([400, 420], 0, 0.4);
     MidEQ.ar(in, freq, Lag.kr(rq, 0.3), db)
    }.play
)

// 现在调节其参数，听听滤波器如何影响两个
// 彼此非常接近的频率

x.set(\db, -12)
x.set(\rq, 0.1)
x.set(\rq, 0.03)
x.set(\freq, 410)
x.set(\freq, 420)
x.set(\freq, 400)
x.set(\freq, 500)
