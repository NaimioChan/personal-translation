Wrap

将信号环绕到给定阈值之外。

InRange : UGen : AbstractFunction : Object

参见：Clip、Fold

说明

这与 BinaryOpUGen 的 wrap2 不同之处在于它允许设置低阈值和高阈值。

类方法

Wrap.ar(in, lo: 0.0, hi: 1.0)

来自父类：InRange

Wrap.kr(in: 0.0, lo: 0.0, hi: 1.0)

来自父类：InRange

参数：

in

要环绕的信号。

lo

回绕的低阈值。

hi

环绕的高阈值。

实例方法

示例

s.boot;

{ Wrap.ar(SinOsc.ar(440, 0, 0.2), -0.15, 0.15) }.scope;
