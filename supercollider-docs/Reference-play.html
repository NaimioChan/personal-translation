play

启动一个进程

play

play 消息在 sc 中很常用。不同的对象以各种方式响应它，但其简单的含义是：启动一个进程。它通常也由贡献库中的对象实现。

play 通常返回正在播放的对象，该对象可能与接收消息的对象不同。

相反：stop

时钟、例程、流和模式

有关实现了 play 的类的完整列表，请参见 Methods: play

clock.play (stream)

返回：时钟

(
r = Routine.new({ "...playing".postln; 1.wait; "ok, that was it".postln });
SystemClock.play(r);
)

参见 Clock: *play

routine.play (clock)

返回：该例程

Routine.new({ "...playing".postln; 1.wait; "ok, that was it".postln }).play;

参见 Routine: -play

stream.play (clock)

返回：流

流将循环直到返回 nil

FuncStream({ "ok, that was it".postln; 1 }).play;

参见 FuncStream: -play

pausestream.play (clock) / task.play (clock)

返回：流

a = PauseStream.new(FuncStream.new({ "ok, that was it".postln; 1 }));
a.play;
a.stop;
a.play;
a.stop;

a = Task.new({ loop({ "ok, that was it".postln; 1.wait; }) });
a.play;
a.stop;

参见 Stream: -play 和 Task: -play

pattern.play (clock, protoEvent)

返回：一个 EventStreamPlayer

(
Pseq([
    Pbind(\freq, Pn(500, 1)),
    Pbind(\dur, Pn(0.1, 1))
], 2).play;
)

参见 Pattern: -play

在服务器上从 SynthDef 播放单个 Synth

以下两条 play 消息都会导致写入一个 SynthDef，将其发送到服务器并在那里用它启动一个 synth。

注意： 在此过程中会添加一些 UGen。一个 Out UGen 用于将音频播放到第一个音频总线。如果函数返回一个 Out UGen，则省略此项。一个带有 gate 控制的包络，用于释放和交叉淡变。如果函数提供了自己的可释放包络，则省略此项。另请注意，它们不应在快速运行的自动化进程中使用，因为有更高效的替代方案（参见 SynthDefs versus Synths）

function.play (target, outbus, fadeTime, addAction, args)

返回：一个 Synth

outbus

在哪个总线上播放（默认：0）

fadeTime

释放时淡出的时间（默认值：0.02）

addAction

在何处添加节点（默认为 \addToHead）

args

启动 synth 时要设置的控制

参见 Function: -play

a = { PinkNoise.ar([0.1, 0.1]) }.play;
a.release;

// 设置参数
a = { |freq = 500| HPF.ar(PinkNoise.ar([1, 1] * 0.4), freq) }.play;
a.set(\freq, 1000)
a.release;

// 通过 play: 传递参数
a = { |freq = 500| HPF.ar(PinkNoise.ar([1, 1] * 0.4), freq) }.play(args: [\freq, 10000]);

// 注意你可以使用 Out ugens，但并非必须
{ Out.ar(1, PinkNoise.ar(0.1)) }.play;
{ XOut.ar(0, MouseX.kr(0,1), PinkNoise.ar(0.1*[1,1])) }.play; // 鼠标 x 控制电平

synthDef.play (target, args, addAction)

返回：一个 Synth

请注意，你需要一个 out ugen 才能听到结果。帮助文件中关于如何写入总线的示例：Out / ReplaceOut / XOut / OffsetOut

尽管如此，synth 也可以在任何写入活动都没有的情况下运行：（例如参见 SendTrig）

某些操作在内部提供了一个输出 ugen：例如参见 function.play，它会输出到由传给 .play 的参数中提供的总线编号。

(
x = SynthDef(\test, { arg out, amp=0.1;
    var sound;
    sound = PinkNoise.ar(amp * [1,1]);
    Out.ar(out, sound);
}).play;
)

//设置合成器
x.set(\amp, 0.2);
//释放 synth
x.free;

参见 SynthDef: -play

注意： Synth.play(function) 是同义词，用于与 sc2 向后兼容
