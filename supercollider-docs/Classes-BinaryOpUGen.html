BinaryOpUGen

对输入 UGen 的值应用二元运算

BasicOpUGen : UGen : AbstractFunction : Object

另见：UnaryOpUGen，BinaryOpFunction，Pbinop，Operators

说明

BinaryOpUGens 是对 UGen 应用二元运算符的结果。

(SinOsc.ar(200) * ClipNoise.ar).dump;
(SinOsc.ar(200).thresh(0.5)).dump;

上文在各自使用二元运算符 * 和 thresh 时都会实例化一个 BinaryOpUGen。不要将这些运算符本身（它们都是方法）与由此产生的 BinaryOpUGen（它是个对象）相混淆。一元和二元运算符定义在 UGen 的父类 AbstractFunction 中，该类会作为运算的结果创建 BinaryOpUGen。

当对 UGen 而非数字进行运算时，得到的结果不是计算的结果，而是一个表示该计算的结构。关于数字上的即时运算，参见例如 SimpleNumber。

有关常见运算符的概述，请参见 Operators。

类方法

BinaryOpUGen.new(selector, a, b)

返回一个新实例，该实例通常将操作符 selector 应用于 UGen a 和 b，当对 UGen 应用操作符时，会隐式调用此方法。

参数：

selector

二元运算符的选择器符号

a

左操作数

b

右操作数

返回值：

BinaryOpUGen 的新实例

示例

a = WhiteNoise.ar; // 一个白噪声
b = a + 2; // 一个 BinaryOpUGen。
b.operator; // +

// 声音示例
(
{
    var a = LFSaw.ar(300);
    var b = LFSaw.ar(329.1);
    a % b * 0.1
}.play;
)

比较运算符

运算符 >, >=, <, <= 对触发特别有用。不应将它们与在条件语句中的用法混淆。比较：

if(1 > 0) { "1 is greater than 0".postln }; // > 返回一个布尔值

with

// 触发一个包络
(
{
    var trig;
    trig = SinOsc.ar(1) > 0.1;
    EnvGen.kr(Env.perc, trig, doneAction: Done.none) * SinOsc.ar(440, 0, 0.1)
}.play
) // > 输出 0 或 1

更多细节请参见 Operators 或 AbstractFunction 中这些运算符的实现。

由于相等运算符（==）用于区分包括 UGen 在内的对象，因此不能通过应用运算来创建 BinaryOpUGen。相反，要在两个信号相同时每次获取触发值（而不是仅仅判断两个 UGen 是否相同），可以直接实例化一个 BinaryOpUGen：

(
{
    var a = SinOsc.ar(1).round(0.1);
    var b = SinOsc.ar(1.2).round(0.1);
    BinaryOpUGen('==', a, b) * 0.1
}.play;
)
