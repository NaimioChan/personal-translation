PV_BrickWall

零个频段。

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

另请参阅：FFT、IFFT

说明

清除截止点以上或以下的频段。

类方法

PV_BrickWall.new(buffer, wipe: 0.0)

参数：

buffer

FFT 缓冲区。

wipe

范围可以在 -1 到 +1 之间。

如果 wipe == 0，则没有效果。

如果 wipe > 0，则它像高通滤波器一样工作，从底部向上清除频段。

如果 wipe < 0，则其作用类似于低通滤波器，从顶部向下清除频段。

实例方法

示例

s.boot;

(
{
    var in, chain;
    in = WhiteNoise.ar(0.2);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_BrickWall(chain, SinOsc.kr(0.1));
    IFFT(chain);
}.play
)
