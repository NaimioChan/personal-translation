EnvGate

单例淡入淡出包络

Object

另请参阅：EnvGen

说明

一个便捷类，用于组合 fadeTime 和 gate 参数的包络生成器。

类方法

EnvGate.new(i_level: 1, gate, fadeTime, doneAction: 2, curve: 'sin')

返回一个 EnvGen。

参数：

i_level

包络的初始电平（若设为 1，则从打开状态开始）

gate

一个门限输入。若为 nil，EnvGate 会创建一个名为 'gate' 的 NamedControl

fadeTime

同时用于起音和衰减时间的输入。如果为 nil，EnvGate 会创建一个名为 'fadeTime' 的 NamedControl（默认时间：0.02）

doneAction

EnvGen 的 doneAction

curve

包络曲线

实例方法

示例

a = { LPF.ar(Saw.ar(200), 600) * EnvGate.new }.play;
a.set(\fadeTime, 2);
a.release;

// 等同于：
a.set(\gate, 0);

// 多个 env 门可以共存于一个 synth def 中。
(
a = {
    var sound1 = LPF.ar(Saw.ar(80), 600) * EnvGate.new;
    var sound2 = RLPF.ar(Saw.ar(200) * 0.5, 6000 * EnvGate.new + 60, 0.1) * EnvGate.new;
    sound1 + sound2
}.play;
)
a.set(\fadeTime, 5);
a.release;
