Method

实现作用于类实例的操作的代码。

FunctionDef : Object

另请参阅：Class

说明

方法是对 Class 的实例进行操作集合中的一部分代码。

相关关键词

thisMethod

全局伪变量 thisMethod 总是求值为类定义中所属的 Method，非常类似于 thisFunction。在该上下文之外执行时，它返回 Interpreter: -functionCompileContext，即所有解释执行代码所在的方法。

// 如果以下代码作为类库的一部分被编译：
SomeClass {
    methodThatPostsItself {
        thisMethod.postln;
    }
}

// 然后运行这个会输出
// "SomeClass:methodThatPostsItself"
a = SomeClass.new;
a.methodThatPostsItself;

thisMethod 常用于向抛出错误的方法传递信息。例如，Nil.new 的实现是：

*new { ^this.shouldNotImplement(thisMethod) }

另请参阅：thisFunction。
