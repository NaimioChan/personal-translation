TextField

显示可编辑文本的视图

说明

显示可编辑文本的视图。

类方法

实例方法

Data

.string

视图中显示的文本。

参数：

一个 String。

.object

如果 -setBoth 为 true，则设置此变量时也会将 -string 设置为按 as String 解释的值。

参数：

任意对象，通常是以字符串形式显示时有意义的对象，例如 Float。

.setBoth

一个变量，表示设置 -object 时是否也会设置 -string。

参数：

一个布尔值。

.value

获取的内容与 -string 相同，但设置时还会将 -string 设为按 as String 解释的值，而不论 -setBoth 标志如何。

参数：

任意对象，通常是以字符串形式显示时有意义的对象，例如 Float。

.valueAction

设置 -value 并触发 -action。

Appearance

.align

显示文本的对齐方式。可能的值参见 Alignment。

.font

用于显示文本的字体。

参数：

一个 Font。

.stringColor

用于显示文本的颜色。

参数：

一个 Color。

.background

设置此变量会用给定颜色为文本下方的字段内部着色。

参数：

一个 Color。

Actions

.action

每当用户更改文本时求值的行为对象。

拖放

.defaultGetDrag

返回值：

显示的 -string。

.defaultCanReceiveDrag

返回值：

始终为 true。

.defaultReceiveDrag

将 -valueAction 设置为当前拖拽数据。

示例

(
w = Window.new.front;
a = TextField(w, Rect(10, 10, 150, 20));
a.string = "hi there";
a.action = { |field| field.value.postln };
)

// 不执行该动作
a.value = "yo";
a.string = "oy";

a.valueAction_("this is not a pipe"); // 如果值已改变则执行操作
a.doAction; // 以文本字段的内容为参数求值该 action

a.background_(Color.grey);
a.stringColor_(Color.white);
a.align_(\center);
