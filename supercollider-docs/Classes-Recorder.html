Recorder

将音频写入硬盘

Object

另请参阅：Server、DiskOut、非实时合成 (NRT)

说明

Recorder 允许你将音频写入硬盘，从给定总线和一定数量的声道读取，并与给定节点相关联。Server 有一个实例，也可以通过 ScIDE 访问。你可以直接使用服务器来录制其输出。

(
{ SinOsc.ar(
    SinOsc.ar(
        XLine.kr(1, 100, 5)).exprange(*XLine.kr([20, 800], [7000, 200], 10)
    )
   ) * 0.1

}.play;
s.record(duration: 10);
)

此功能也可通过服务器窗口上的录制按钮使用。按一次会调用 record，再按一次会调用 stopRecording（见下文）。这样做时，创建的文件将位于你的 recordings 文件夹中，并以当前日期和时间命名。recordings 文件夹的默认位置因平台而异。设置此变量可以更改默认位置。

// 查找录音写入的位置
thisProcess.platform.recordingsDir

注意： 默认情况下，record 会在服务器的默认组之后创建录制 synth，并使用 In.ar。因此，如果你在录制 synth 之后添加节点，它们的输出将不会被捕获。要避免这种情况，可以使用 Node 对象（它们以默认节点作为目标），或者（在使用消息风格时）使用目标 nodeID 1.s.sendMsg("/s_new", "default", s.nextNodeID, 1, 1);

关于此主题的更多细节，请参见 Order of execution、Default Group 和 Node Messaging。

有关各种样本格式和头格式的信息，请参见 SoundFile。并非所有样本格式和头格式都相互兼容。请注意，输出文件的采样率将与服务器应用的采样率相同。这可以通过服务器的 ServerOptions 进行设置。

类方法

Recorder.new(server)

为给定的服务器创建一个新实例。

参数：

server

实例方法

.prepareForRecord(path, numChannels)

为录制服务器输出分配必要的缓冲区等。（参见下方的 record。）

参数：

path

一个 String，表示输出文件的路径和名称。如果目录不存在，会为你创建。（但请注意，如果因任何原因创建失败，录音也会失败。）

numChannels

要录制的输出通道数。

讨论：

如果你不指定路径，则会在你的录音文件夹（参见上面关于此的说明）中创建一个名为 SC_thisDateAndTime 的文件。对文件头或采样格式、或对声道数的更改必须在调用此方法之前完成。

.record(path, bus, numChannels, node, duration)

开始或恢复录制输出。

参数：

path

这是可选的，会被传递给 prepareForRecord（见上）。

bus

总线（Bus 对象或整数总线索引），即开始计数通道数的偏移量。你可以录制任意数量的相邻总线通道。

numChannels

要录制的输出通道数。

node

紧接着要录制的 Node。默认情况下，这是默认组 1。

duration

如果设置，则将录音限制为给定的时间（以秒为单位）。

注意： 录音会在缓冲区分配完成后开始，并经过通常极短网络延迟后开始。它将持续精确的 duration 时长，误差可低至一个服务器块大小（64 个采样）。若要精确安排录音的起始点，请先调用 -prepareForRecord，然后在一个 bundle 中调用 -record（参见 Server: -bind 和 Server: -sync）。

讨论：

如果你尚未先调用 prepareForRecord（见上文），则会为你调用它（但这会使真正开始录制前略有延迟）。

r = Recorder(s);
{ GVerb.ar(Dust.ar(4)) }.play; // 在总线 64 上播放
r.record(numChannels: 2);
r.stopRecording;

.pauseRecording

暂停录音。可通过再次执行 record 或调用 resumeRecording 来恢复。

.resumeRecording

重新开始录制。

.stopRecording

停止录制，关闭文件，并释放相关资源。

讨论：

录制完成后必须调用此方法，否则输出文件将无法使用。录制时按 Cmd-. 具有相同的效果。

.filePrefix

.filePrefix = value

用作录制时路径前缀的字符串。可用于区分多个录制器的输出。默认值为 "SC_"。

.numChannels

.numChannels = value

在使用此录音器时始终使用的声音文件通道数，除非在 -record 方法中指定了不同的值。未设置时，使用 Server: -recChannels。

.recHeaderFormat

.recHeaderFormat = value

获取/设置输出文件的头部格式（字符串）。默认值为 "wav"。必须在 prepareForRecord 之前调用。

.recSampleFormat

.recSampleFormat = value

获取/设置输出文件的采样格式（字符串）。默认为 "float"。必须在 prepareForRecord 之前调用。

.recBufSize

.recBufSize = value

获取/设置用于 DiskOut UGen 的 Buffer 的大小。该值必须是 2 的幂。默认值为 sampleRate.nextPowerOfTwo，或比一秒更长的第一个 2 的幂的采样数。必须在 prepareForRecord 之前调用。

.isRecording

如果正在录制过程中则返回 true

.paused

若记录已暂停则返回 true

.duration

返回我们到目前为止已录制的秒数

.path

返回当前录制的路径

.numFrames

返回录制缓冲区的帧数

.notifyServer

.notifyServer = value

若设为 true，它会向服务器实例发送 changed 通知。这由 Server 类内部使用。

.server

要录制的服务器

示例

// 要录制的内容
(
SynthDef("bubbles", { |out|
    var f, sound;
    f = LFSaw.kr(0.4, 0, 24, LFSaw.kr([8, 7.23], 0, 3, 80)).midicps; // 滑音函数
    sound = CombN.ar(SinOsc.ar(f, 0, 0.04), 0.2, 0.2, 4); // 回声正弦波
    Out.ar(out, sound);
}).add;

SynthDef("tpulse", { |out = 0, freq = 700, sawFreq = 440.0|
    Out.ar(out, SyncSaw.ar(freq, sawFreq, 0.1))
}).add;

)

x = Synth.new("bubbles");

s.prepareForRecord; // 如果你想在精确的时间点开始录音，必须先调用这个。

s.record; // 开始录音。也可以直接调用它，如果精确的起始时刻并不重要的话。

s.pauseRecording; // 可暂停

s.record // start again

s.stopRecording; // 这会关闭文件并释放 buffer 录音节点等

x.free; // 停止合成器

// 查看你的录音文件夹，你会找到一个以该日期和时间命名的文件
// 将位置设置为你的主文件夹（将 user 改为你的用户名）
thisProcess.platform.recordingsDir = "/home/user/";

// 实例化 Recorder
r = Recorder.new(s);

// 录制到一个 flac 文件
r.recHeaderFormat = "flac";

// 默认的 'float' 与 flac 不兼容。设置为 24bit：
r.recSampleFormat = "int24";

// 为文件设置非常明显的前缀
r.filePrefix = "SuperCollider_";

// 开始录制：
r.record;

// 停止录制
r.stopRecording;
