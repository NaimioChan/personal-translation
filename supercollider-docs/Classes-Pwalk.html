Pwalk

在嵌入的值列表上进行一维随机游走

ListPattern : Pattern : AbstractFunction : Object

参见：Pbrown

类方法

Pwalk.new(list, stepPattern, directionPattern: 1, startPos: 0)

参数：

list

要遍历的项。

stepPattern

返回将用于递增 list 中索引的整数。

directionPattern

用于确定边界处的行为。当索引跨越边界时，下一个方向取自该流：1 表示按原样使用 stepPattern，-1 表示反向进行。常见的模式：

1

总是环绕到另一个边界。

Pseq([1, -1], inf)

先向前，再向后，然后再向前。

startPos

在列表中的起始位置。

示例

(
a = Pwalk(
    Array.series(20, 0, 1),        // 整数，0-19
        // 向任一方向步进至多 2，偏向正值
    Pwrand([-2, -1, 0, 1, 2], [0.05, 0.1, 0.15, 1, 0.1].normalizeSum, inf),
        // 在边界处反转方向
    Pseq([1, -1], inf),
    10);    // 从中间开始
x = a.asStream;
)

200.do({ x.next.post; ", ".post });

b = a.copy.directionPattern_(1);    // 这个总是会循环回绕
x = b.asStream;

200.do({ x.next.post; ", ".post });



// 非随机游走：进行上下琶音的简便方法
s.boot;
(
a = Pwalk(
    [60, 64, 67, 72, 76, 79, 84].midicps,    // C major
    Pseq([1], inf),
    Pseq([1, -1], inf),    // 在两端折返
    0);
x = a.asStream;

SynthDef(\help_walk, { |out, freq|
    Out.ar(out, Saw.ar([freq, freq+1], 0.5) * EnvGen.kr(Env.perc(0.01, 0.1), doneAction: Done.freeSelf))
}).add;
)

(
r = Task({
    {
        Synth.new(\help_walk, [\freq, x.next]);
        0.1.wait;
    }.loop;
}).play(SystemClock);
)

r.stop;
