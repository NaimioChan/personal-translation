PV_HainsworthFoote

FFT 起始检测器。

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

另请参阅：PV_JensenAndersen

说明

基于 Hainsworth, S. (2003) Techniques for the Automated Analysis of Musical Audio. PhD, University of Cambridge engineering dept. 中所述工作实现的 FFT 起音检测器。特别参见第 128 页。Hainsworth 度量是对 Kullback Liebler 距离的一种修改。

起音检测器具有检测频谱变化的通用能力，因此除了明显的瞬态冲击外，它可能还具备一定的跟踪和弦变化的能力，但不能保证它不会被频率调制伪影所混淆。

Hainsworth 度量本身就能给出不错的结果，但在某些情况下 Foote 可能有用：实验性。

类方法

PV_HainsworthFoote.ar(buffer, proph: 0.0, propf: 0.0, threshold: 1.0, waittime: 0.04)

参数：

buffer

FFT 缓冲区。

proph

要使用的 Hainsworth 度量检测信号强度。

propf

使用 Foote 度量的检测信号强度。Foote 度量归一化为 (0..1)。

threshold

允许检测的阈值保持电平。

waittime

如果触发，则在下一个帧能够引发另一次 spot 之前的最小等待时间（有助于在强信号上停止多次检测）。

实例方法

示例

// 只是低阈值的 Hainsworth 度量
(
SynthDef(\fftod, { |out|
    var source1, detect;
    source1 = SoundIn.ar(0);
    detect = PV_HainsworthFoote.ar(FFT(LocalBuf(2048), source1), 1.0, 0.0);
    Out.ar(out, SinOsc.ar([440, 445], 0, Decay.ar(0.1 * detect, 0.1)));
}).play(s);
)


// 捕捉音符转换
(
SynthDef(\fftod, { |out|
    var source1, detect;
    source1 = LFSaw.ar(LFNoise0.kr(1, 90, 400), 0, 0.5);
    detect = PV_HainsworthFoote.ar(FFT(LocalBuf(2048), source1), 1.0, 0.0, 0.9, 0.5);
    Out.ar(out, Pan2.ar(source1, -1.0) + Pan2.ar(SinOsc.ar(440, 0, Decay.ar(0.1 * detect, 0.1)), 1.0));
}).play(s);
)



// Foote solo - 阈值超过 1.0 时永不触发，阈值由鼠标控制
(
SynthDef(\fftod, { |out|
    var source1, detect;
    source1 = SoundIn.ar(0);
    detect = PV_HainsworthFoote.ar(FFT(LocalBuf(2048), source1), 0.0, 1.0, MouseX.kr(0.0, 1.1), 0.02);
    Out.ar(out, Pan2.ar(source1, -1.0) + Pan2.ar(SinOsc.ar(440, 0, Decay.ar(0.1 * detect, 0.1)), 1.0));
}).play(s);
)


// 与 Amplitude UGen 比较
(
SynthDef(\fftod, { |out|
        var source1, detect;
        source1 = SoundIn.ar(0);
        detect = Amplitude.ar(source1) > MouseX.kr(0.0, 1.1);
        Out.ar(out, Pan2.ar(source1, -1.0) + Pan2.ar(SinOsc.ar(440, 0, Decay.ar(0.1 * detect, 0.1)), 1.0));
    }).play(s);
)
