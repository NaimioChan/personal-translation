模式指南食谱 04：发送 MIDI

在模式控制下向 MIDI 设备发送音符

参见：Pattern Guide Cookbook 03: External Control、Pattern Guide Cookbook 05: Using Samples

使用模式发送 MIDI 输出

发送 MIDI 是 MIDIOut 类和 \midi 事件类型的工作。创建 MIDIOut 用于与硬件设备通信；播放事件时提供 MIDI 通道。MIDIOut 的 newByName 使识别设备更加容易。

\midi 事件类型支持以下命令，通过事件中的 \midicmd 键选择：\allNotesOff, \bend, \control, \noteOff, \noteOn, \polyTouch, \program, \smpte, \songPtr, \sysex, \touch。默认为 \noteOn。当播放一个音符（noteOn）时，默认情况下会在该音符的延音时间之后发送相应的 noteOff 消息。

如果你想同步由 MIDI 设备播放的事件和由 SuperCollider 服务器播放的事件，MIDIOut 对象的延迟必须与服务器延迟匹配。你可以随时设置延迟以影响所有未来事件。

MIDIClient.init;    // 如果尚未完成

(
    // 在此处替换为你自己的设备
var    mOut = MIDIOut.newByName("FastLane USB", "Port A").latency_(Server.default.latency);

p = Pbind(
    \type, \midi,
        // 这一行是可选的，因为 noteOn 是默认值
        // 这里只是将其显式写出
    \midicmd, \noteOn,
    \midiout, mOut,    // 必须在此处提供 MIDI 目标
    \chan, 0,
        // degree 被转换为 midinote，而不仅仅是频率
    \degree, Pwhite(-7, 12, inf),
    \dur, Pwrand([0.25, Pn(0.125, 2)], #[0.8, 0.2], inf),
    \legato, sin(Ptime(inf) * 0.5).linexp(-1, 1, 1/3, 3),
    \amp, Pexprand(0.5, 1.0, inf)
).play(quant: 1);
)

p.stop;
