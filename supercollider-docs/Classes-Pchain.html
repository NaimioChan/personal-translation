Pchain

将值从流传递到流

Pattern : AbstractFunction : Object

参见：Pbindf

说明

Pchain(pattern1, pattern2, ... patternN)

pattern1 <- pattern2 <- ...patternN

pattern2 的流产生的值被用作 pattern1 的流的 inval。因此 pattern1 覆盖（或过滤）pattern2 的输出，依此类推。这等价于组合模式：pattern1 <> pattern2 <> ... patternN

类方法

Pchain.new( ... patterns)

参数：

... 模式

要链接起来的模式。

实例方法

<>(aPattern)

向链中添加另一个模式。

未文档化的实例方法

.embedInStream(inval)

.patterns

.patterns = value

示例

(
Pchain(
    Pbind(\detune, Pseq([-30, 0, 40], inf), \dur, Prand([0.2, 0.4], inf)),
    Pbind(\degree, Pseq([1, 2, 3], inf), \dur, 1)
).trace.play;
)


// 事件也可以直接使用：
(
Pchain(
    Pbind(\degree, Pseq([1, 2, 3], inf)),
    (detune: [0, 4])
).trace.play;
)

// 组合一些更复杂的模式：
(
var a, b;
a = Prand([
    Pbind(\degree, Pseq([0, 1, 3, 5, 6])),
    Pbind(\dur, Pshuf([0.4, 0.3, 0.3]), \degree, Pseq([3, -1]))
], inf);
b = Prand([
    Pbind(\ctranspose, Pn(1, 4)),
    Pbind(\mtranspose, Pn(2, 7))
], inf);
c = Prand([
    Pbind(\detune, Pfuncn({ [0, 10.0].rand }, 5), \legato, 0.2, \dur, 0.2),
    Pbind(\legato, Pseq([0.2, 0.5, 1.5], 2), \dur, 0.3)
], inf);
Pchain(a, b, c).trace.play;
)

模式组合

模式 <> 模式 <> 模式

// 隐式地，当组合操作符 <> 作用于 pattern 时，会返回一个 Pchain。
// 因此 a <> b 会创建 Pchain(a, b)。
// 如上所示，在 Pchain(a, b) 中，a 指定（并覆盖）b：b 是 a 的输入。

// 上面的示例等价于：

(Pbind(\degree, Pseq([1, 2, 3], inf)) <> (detune: [0, 4])).trace.play;

(
a = Pbind(\degree, Pseq([1, 2, 3], inf), \dur, Prand([0.2, 0.4], inf));
b = Pbind(\detune, Pseq([-30, 0, [0, 40]], inf), \dur, 0.1);
c = b <> a;
c.play; // 可以看到 a 的 \dur 键被 b 覆盖
)

// 值流也可以组合
(
a = Pfunc { |x| x + 1.33 };
b = Pfunc { |x| x * 3 };
c = Pseries(1, 2, inf);
)

// 发布复合流中的一些值：

t = (a <> b).asStream;
10.do { t.value(10).postln };

t = (a <> b <> c).asStream;
10.do { t.value(10).postln };

t = (b <> c <> a).asStream;
10.do { t.value(10).postln };
