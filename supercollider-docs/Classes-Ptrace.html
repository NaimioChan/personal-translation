Ptrace

打印流的结果

FilterPattern : Pattern : AbstractFunction : Object

另请参见：Stream、FilterPattern

说明

打印流的结果，同时返回原始值。

追踪模式最常用的方法是直接在模式上使用 .trace 方法，如下所示：

Pbind(\degree, Pwhite(0, 10)).trace.play

类方法

Ptrace.new(pattern, key, printStream, prefix: "")

参数：

pattern

对此流调用 printOn（默认：Post）。

key

在流式传输事件时，仅发布此键。

printStream

(在此描述参数)

prefix

添加到打印输出中以分隔不同流的字符串。

返回值：

原始值

实例方法

.storeArgs

.embedInStream(inval)

参数：

inval

.key

.key = value

示例

(
// 一个播放随机音级的事件模式
p = Pbind(\dur, 0.125, \degree, Pwhite(0, 10));

// 使用 trace 查看音阶级的值
Ptrace(p, \degree, prefix: "Current scale degree: ").play
)
