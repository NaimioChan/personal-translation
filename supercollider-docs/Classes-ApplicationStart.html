ApplicationStart

注册在应用程序启动时要执行的函数

参见：StartUp、ServerBoot

说明

仅在 macOS 的 SuperCollider.app 中可用。

ApplicationStart 允许你注册函数或对象，使其仅在应用程序启动时执行操作。这些函数将最后被求值；在库编译完成、启动文件已运行且 StartUp 动作已被求值之后。

另请参见 StartUp，了解每次重新编译 ClassLibrary 时都会求值的函数。

类方法

.add

注册一个对象或函数。对象将在应用程序启动时收到 doOnApplcationStart 消息。函数将被求值。

.remove

移除之前注册的函数。

.run

按顺序求值函数或对象。

实例方法

示例

SomeStartClass {
    *initClass {
        ApplicationStart.add {
            // 当应用启动后要做的事情……
        }
    }
}

// or...
SomeStartClass {
    *initClass {
        ApplicationStart.add(this);
    }
    *doOnApplicationStart { "something started".postln }
}
