例程与时钟

使用时钟来创建自动化的、算法化的调度。时钟"播放"的对象包括例程、任务和模式。

要了解时钟如何“播放”例程，首先检查函数在例程中如何工作。

例程的第一个参数（通常也是唯一参数）是一个函数。

// 例程的模板
Routine({ ".... code within curly braces is a function .... "});

在函数（位于例程中）中对表达式发送 .yield 消息会返回一个值。

r = Routine({ "hello, world".yield.postln });

// 要执行一个 routine，发送 .next 消息
// 它会把附加了 .yield 消息的表达式的值“交出”
r.next;

求值（再次）

r.next;

上面的例程在第二次求值时返回 nil。这是因为一旦例程 "yield"，并且如果 .yield 消息之后没有额外的代码，例程就结束了、完成了、做完了——除非它收到 reset 消息。然后它可以重新开始。

r.next;        // 返回 nil
r.reset;    // 重置例程
r.next;        // 成功了！

////////////////////////////////////////////////////////////////////////////////////////////////////

(
r = Routine({
    "hello, world".yield;
    "what a world".yield;
    "i am a world".yield;
});
)

前三个 .next 消息返回一个字符串。第四个 .next 消息返回 nil。

r.next;    // 返回一个字符串
r.next;    // 返回一个字符串
r.next;    // 返回一个字符串
r.next;    // 返回 nil

重置例程。

r.reset;

r.next;
r.next;
r.next;
r.next;

////////////////////////////////////////////////////////////////////////////////////////////////////

在例程中使用 .do 消息来构成循环。

(
r = Routine({

    // 设置代码
    var array;
    array = [ "hello, world", "what a world", "i am a world" ];

    // 循环
    3.do({ array.choose.yield })

});
)

比例程中循环允许的次数多求值一次例程。

4.do({ r.next.postln });

该例程返回了三个字符串，随后是 nil。

调度例程

重写该例程，使其包含一个 .wait 消息。

(
r = Routine({

    var array;
    array = [ "hello, world", "what a world", "i am a world" ];

    3.do({
        1.wait;         // 暂停 1 秒
        array.choose.postln;
    })

});
)

然后“播放”该例程，例如，向它发送 .play 消息。

r.play;

向例程附加 .reset 消息，以便它可以重新开始。

r.reset.play;

时钟与 .play 的便利性

当例程收到 .play 消息时，例程的控制权会被转交给一个时钟。时钟以 .wait 消息的接收者作为时间单位来调度（“播放”）该例程。

SuperCollider 有三个时钟，每个时钟都有一个帮助文件。

SystemClock        // 最精确的
AppClock        // 用于 GUI
TempoClock        // 以拍为单位进行调度

.play 消息是一种便捷方式，允许编写

r.reset.play;        // 在播放前重置例程

而不是

SystemClock.play(r)

用例程调度 synth

将 synth 包含在例程中。常见的情况是，例程中 synth 所使用的 synthdef 应当带有一个包络，其 doneAction 参数设为 2（以便在包络播放完毕后释放 synth 所需的内存）。

(
// 定义一个 SYNTHDEF
SynthDef("fm2", {
    arg bus = 0, freq = 440, carPartial = 1, modPartial = 1, index = 3, mul = 0.2, ts = 1;

    // 索引值通常在 0 到 24 之间
    // carPartial :: modPartial => car/mod 比率

    var mod;
    var car;

    mod = SinOsc.ar(
        freq * modPartial,
        0,
        freq * index * LFNoise1.kr(5.reciprocal).abs
    );

    car = SinOsc.ar(
        (freq * carPartial) + mod,
        0,
        mul
    );

    Out.ar(
        bus,
        car * EnvGen.kr(Env.sine(1), doneAction: Done.freeSelf, timeScale: ts)
    )
}).add;
)

(
// 定义一个例程
r = Routine({

    12.do({
        Synth(
            "fm2",
            [
                \bus, 2.rand, \freq, 400.0.rrand(1200),
                \carPartial, 0.5.rrand(2), \ts, 0.5.rrand(11)
            ]
        );
        s.queryAllNodes;
        "".postln.postln.postln.postln.postln;
        2.wait;
    })
});
)

// 播放该例程
r.reset.play;

通过运行在例程之外的效果处理在例程中生成的 Synth。

(
// 定义一个 SYNTHDEF
SynthDef("echoplex", {
    ReplaceOut.ar(
        0,
        CombN.ar(
            In.ar(0, 1),
            0.35,
            [Rand(0.05, 0.3), Rand(0.05, 0.3)],
            // 每次创建 synth 时生成随机值
            7,
            0.5
        )
    )
}).add;

// 定义组以控制执行顺序
// 将一个 ~source 组附加到根节点的头部，并
// 将一个 ~effects 组附加到根节点的尾部
~source = Group.head(s);
~effect = Group.tail(s);

// 定义一个例程
r = Routine({

    // loop 与 inf.do 相同，例如，创建一个永远运行的无限循环
    loop({
        Synth.head(    // 将 synth 附加到 ~source 组的头部
            ~source,
            "fm2",
            [
                \outbus, 0, \freq, 400.0.rrand(1200), \modPartial, 0.3.rrand(2.0),
                \carPartial, 0.5.rrand(11), \ts, 0.1.rrand(0.2)]
        );
        s.queryAllNodes;
        2.wait;
    })
});

// 开启效果
Synth.head(~effect, "echoplex");
Synth.tail(~effect, "echoplex");
)
// 播放该例程
r.reset.play;
