GUI：创建窗口

如何创建一个窗口，插入控件，并将键盘输入映射到它上面，使用 SuperCollider。

另见：GUI：将乐器与 View 连接，GUI：用基本组件组合视图

GUI 教程

此帮助文件是 GUI 教程 的一部分。

这是 SuperCollider GUI 系统初学者入门的第一部分。第二部分介绍将 Synth 与 GUI 界面对接，第三部分则讨论用基本 GUI 组件组合视图。

创建和操作 Window

要在 SuperCollider 中创建一个 Window，只需执行以下代码：

(
var win = Window();
win.front;
)

第一条命令创建窗口，第二条命令告诉图形系统显示它。

你可以在创建时直接自定义其名称、位置和大小：

(
var window = Window("My window", Rect(100, 100, 600, 200));

window.front;
)

你也可以切换其全屏模式：

(
var window = Window();
window.fullScreen;
window.front;
)

如果你执行了前面的例子，你可能已经注意到关闭它可能很困难，因为它不显示其顶部菜单，也不响应键盘输入。要关闭 SuperCollider 使用代码创建的每个窗口，只需执行以下命令：

Window.closeAll;

如果你将窗口存储在全局变量中，也可以直接关闭它：

~window.close;

一旦关闭，你需要重新创建它，因为它已被完全删除。

注意： 以下代码在开发图形界面时很有用：( var window = Window(); CmdPeriod.doOnce({ window.close; }); window.front; ) 每次按下 ctrl + shift + .，如果当前正在创建的窗口仍然打开，它就会关闭该窗口，从而防止开发过程中窗口不断累积。

插入和定位视图

创建窗口后，你可以直接将一个 View 添加到其中，方法是在创建 View 时将窗口作为 parent 参数传入：

(
var window = Window();
var button = Button(window);
button.string_("Click me!");
window.front;
)

这样做时，你需要负责将你的 View 设置在正确的位置和大小：

(
var window = Window();
var button = Button(
    window,
    Rect(100, 100, 200, 200)
);
button.string_("Click me!");
window.front;
)

如果你希望在调整窗口大小时使用自动定位和自动调整大小，则应使用 Layout：

(
var window = Window();

var layout = HLayout();

var button = Button(window);
button.string_("Click me!");

// 将布局分配给窗口
window.layout_(layout);
// 然后将 View 添加到布局中
layout.add(button);

window.front;
)

关于这种组织方法的更多信息，请参阅 Layout。布局系统也将在本系列的下一篇教程中讨论。

注意： 将 StackLayout 添加为 Window 的主布局，可以轻松地在不同 View 之间切换，换言之，在不同界面之间切换。

键盘输入

Window “继承”了 UserView 的 action 系统。它可以响应鼠标和键盘事件。有关更多信息，请参阅 UserView 帮助文件。

使用键盘与窗口交互的另一种方式（可能更可取）是将一个函数赋给 View.globalKeyDownAction。

每当接收到键盘输入时，View.globalKeyDownAction 都会被执行（无论当前焦点如何），并且允许采取动作来响应该键盘事件，例如关闭窗口：

(
var window = Window();
var fullScreenActive = false;

View.globalKeyDownAction = { |view, char, mod, unicode, keycode, key|

    switch(keycode)

    // 如果键码是 65307（ESC）：关闭窗口
    { 65307 } { window.close; }

    // 如果键码为 102 (f)：切换全屏 开 / 关
    { 102 } {
        fullScreenActive = fullScreenActive.not;
        if(fullScreenActive)
        { window.fullScreen; }
        { window.endFullScreen; };
    };
};

window.front;
)

注意： 将 FunctionList 与 View.globalKeyDownAction 一起使用，可以逐步构建键盘输入响应：( var window = Window(); View.globalKeyDownAction = FunctionList(); View.globalKeyDownAction.addFunc({ |view, char, mod, unicode, keycode, key| switch(keycode) // 如果 keycode 是 65307，即 ESC，则关闭窗口 { 65307 } { window.close; }; }); window.front; )

就是这样！
