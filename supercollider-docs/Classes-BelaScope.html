BelaScope

Bela 的示波器接口

Object

说明

注意： 此 UGen 仅在 Bela 上工作

允许在 Bela 内置的 Oscilloscope 上对信号进行示波显示，可通过 Bela 的 Web 界面访问。无需直接与这个类交互，因为 UGen、数组、总线、函数和服务器都可以通过其 .belaScope() 方法进行示波显示。

Setup

使用 BelaScope 需要：

  • 运行在 Bela 上的 Server 实例（本地或远程）。
  • 对于 Bela 的服务器，应将 ServerOptions.belaMaxScopeChannels 设置为 > 0。它表示在该服务器上可进行示波的最大通道数，并会影响资源分配。如果设置为 <= 0，服务器将不会实例化任何 Scope 对象，并且任何从 sclang 实例化 BelaScope 的尝试都会抛出错误。

Usage

一旦使用 options.belaMaxScopeChannels > 0 启动 Bela 服务器，就可以使用 UGens 和 Busses 的 .belaScope() 方法对其进行示波显示。参见以下示例。

类方法

BelaScope.scope(channelOffset, signals)

将 UGen 数据数组发送到 Bela 的示波器。

参数：

channelOffset

Bela 示波器开始进行示波显示的通道。这必须是一个非负数，且在示波开始后无法更改。

signals

要示波显示的 UGen 数组

返回值：

作为参数传入的 signals 数组。这使得在信号处理链中可以透明地使用 .belaScope()

{ BelaScope.scope(0, SinOsc.ar) }.play;
// 使用 UGen::belaScope() 快捷方法的相同写法：
{ SinOsc.ar().belaScope(0) }.play

// 在链中的透明用法：
// 在 .range 前后限定 LFNoise0 的作用域，同时仍用它来调制 SinOsc
{ SinOsc.ar(LFNoise0.kr(10).belaScope(0).range(20, 100).belaScope(1)) }.play

BelaScope.monitorBus(channelOffset, busindex, numChannels, target, rate: 'audio')

在 Bela 的示波器上示波一条总线

参数：

channelOffset

Bela 示波器开始进行示波显示的通道。这必须是一个非负数，且在示波开始后无法更改。

busindex

要示波的音频总线索引

numChannels

要示波的总线通道数

target

Bela 的 SuperCollider 服务器，或该服务器上的任意节点。总线在该目标之后被监控，或者若将服务器作为目标提供，则在该服务器的 RootNode 之后被监控。

rate

一个符号。默认值为 \audio。其他任何值都将使用控制速率。

返回值：

用于监视总线的 Synth。

// 在 Bela Oscilloscope 的通道 3 上示波音频总线 4 的 2 个通道
BelaScope.monitorBus(3, 4, 2, ~belaServer)
// 使用 Server::belaScope() 快捷方法实现相同效果：
~belaServer.belaScope(3, 4, 2)
// 使用 Bus::belaScope() 快捷方法的相同写法
Bus(\audio, 4, 2, ~belaServer).belaScope(3)

示例

~belaServer = Server.remote(\Bela, NetAddr("192.168.6.2", 57110));

// UGens：用法类似 .poll
// 用示波器显示 LFNoise0，同时仍用它来调制 SinOsc
{ var freq = LFNoise0.kr.range(20, 2000); SinOsc.ar(freq.belaScope(0)) }.play(~belaServer)

// 对一个 UGen 数组进行作用域：
{ var freq = LFNoise0.kr.range(20, 2000) ! 4; SinOsc.ar(freq.belaScope(0)) }.play(~belaServer)

// Bus：在 Bela Oscilloscope 的通道 4 上，从总线编号 10 开始对 3 个通道进行示波
b = Bus(\audio, 10, 6, ~belaServer);
{ SinOsc.ar }.play(~belaServer, outbus: b);
b.belaScope(4);

// Server：用法类似 .scope
// 在 Bela 的 Oscilloscope 通道 2 上示波器显示总线 10 和 11
~belaServer.belaScope(2, 10, 2)
// 在 Bela 的示波器通道 0 上示波主输出总线
~belaServer.belaScope

// 函数：用法类似 .scope
// 播放并示波一个多输出函数；示波从 BelaScope 通道 4 开始
{ SinOsc.ar(LFNoise0.ar([1, 2, 3]).exprange(20, 20000)) * LFNoise1.ar([1, 2, 3]).exprange(0.001, 0.1) }.belaScope(4, ~belaServer)
