TRand

触发随机数生成器。

UGen : AbstractFunction : Object

另请参阅：ExpRand、IRand、LinRand、NRand、Rand、TExpRand、TIRand

说明

每次触发信号从非正值变为正值时，在从 lo 到 hi 的均匀分布中生成一个随机浮点值。

类方法

TRand.ar(lo: 0.0, hi: 1.0, trig: 0.0)

TRand.kr(lo: 0.0, hi: 1.0, trig: 0.0)

参数：

lo

输出范围的下限。

hi

输出范围的上限。

trig

触发信号。触发信号可以是任意信号。当信号从非正变为正时，触发发生。

实例方法

示例

(
{
    var trig = Dust.kr(10);
    SinOsc.ar(
            TRand.kr(300, 3000, trig)
        ) * 0.1
}.play;
)

(
{
    var trig = Dust.ar(MouseX.kr(1, 8000, 1));
    SinOsc.ar(
            TRand.ar(300, 3000, trig)
        ) * 0.1
}.play;
)
