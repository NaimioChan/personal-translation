SystemSynthDefs

假定已存在于服务器上的 SynthDef

Object

另请参阅：Server、SynthDef

说明

启动之后，这个 SynthDef 集合会被发送到服务器。这些 SynthDef 用于诸如路由音频和写入总线等目的，参见 Event 和 NodeProxy。这些 SynthDef 会在 StartUp 时自动实例化。对于非实时合成，必须显式添加它们，参见 Score: -addSystemSynthDefs。

在匿名播放函数（Function: -play）时，临时 SynthDef 名称也由该类生成。

类方法

系统 SynthDef

SystemSynthDefs.numChannels

SystemSynthDefs.numChannels = value

SystemSynthDefs 类会生成具有不同声道数的 SynthDef，声道数根据需要选择。该类变量指定最大声道数。

SystemSynthDefs.synthDefs

SystemSynthDefs.synthDefs = value

生成的非临时 synthDef 列表。

SystemSynthDefs.synthDefs.do { |x| x.name.postln }; // 输出 SynthDef 的名称

临时 SynthDef 名称

SystemSynthDefs.generateTempName

返回一个新的临时名称

SystemSynthDefs.generateTempName

SystemSynthDefs.tempNamePrefix

SystemSynthDefs.tempNamePrefix = value

一个前缀名称，可用于区分 Synth 与其他名称以避免冲突。

a = { SinOsc.ar * 0.01 }.play;
a.defName; // 前缀为 'temp__'，后跟一个数字

SystemSynthDefs.maxTempDefNames

SystemSynthDefs.maxTempDefNames = value

添加到 tempNamePrefix 的数字的最大计数
