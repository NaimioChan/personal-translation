the_lazy_proxy

惰性代理

另请参阅：JITLib、NodeProxy、ProxySpace

类 NodeProxy（以及 BusPlug）使用惰性求值方案，从分配给它的第一个有意义的输入推导出合适的速率和 numChannels。基本信息请参见 NodeProxy 和 ProxySpace 帮助文件。因此，只要未设置源，该代理就是中性的：

p = ProxySpace.push;
~x.isNeutral;

一旦第一次设置了源，它就从该输入推导出它的总线参数

~x = { Array.fill(14, { SinOsc.kr(1.0.rand, 0, 100) }) }; //~x 现在是 14 通道控制速率
~x;

为了重置这些属性，使用 clear：

~x.clear;
//注意此时不应有其他 proxy 从 ~x 读取：
//为简单起见，nodeproxy 目前不关心其子节点，只关心其父节点。

为了快速初始化，也可以使用 defineBus：

~x.defineBus(\control, 5);
// 或者用另一种方式：
~x.kr(5)

当其他代理从中读取时，这些属性也会被设置：

~x = { LFPulse.kr * ~b.kr(7) }; //kr / ar 的第一个参数是默认的通道数

如果没有传入通道数，则使用默认值：

~test.ar; // 2
~krtest.kr; // 1

默认值可在类 NodeProxy 中设置：

NodeProxy.defaultNumAudio = 3;
NodeProxy.defaultNumControl = 13;

~test3.ar; // 3
~krtest3.kr; // 13

// 将它们设回：
NodeProxy.defaultNumAudio = 2;
NodeProxy.defaultNumControl = 1;

同样，如果使用代理作为映射源，则假定为控制速率：

~u;
~x.map(\zzz, ~u);
~u;

当执行一元或二元运算时，使用最高的 rate / numChannels 来初始化所有未初始化的代理：

~x.clear;
~x.defineBus(\control, 5);
~x = ~e + ~f;

~x.clear; ~e.clear; ~f.clear;
~e.defineBus(\audio, 1);
~x = ~e + ~f.squared + ~r;
~x;

~x.clear; ~e.clear; ~f.clear;
~e.defineBus(\audio, 3);
~x = ~e;

如果将 rate-1 代理用作 rate-2 输入，则会转换速率，并按通常的多通道扩展模式扩展通道：

~f.defineBus(\control);
~f.ar(2);

~f.defineBus(\audio);
~f.kr(2);

// 如果传入的通道数更少，它只使用前 n 个通道
~f.defineBus(\audio, 8);
~f.ar(2);

可以将偏移量作为第二个参数传给 ar/kr

//调制偏移：
p = ProxySpace.push(s.boot);

~out.play;
~src = { SinOsc.ar(Array.rand(5, 400, 500.0), SinOsc.ar(Array.exprand(5, 2.1, 500.0)), 0.1) };
~out = { ~src.ar(1, MouseX.kr(0, 5)) };
~out = { Mix(~src.ar(3, MouseX.kr(0, 5))) }; //包装偏移量会相应地移动
