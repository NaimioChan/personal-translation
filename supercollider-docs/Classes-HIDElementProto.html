HIDElementProto

用于与 HIDFunc 匹配的原型 HID 元素

Object

参见：HIDFunc、HIDdef、HIDProto、HID、HIDElement、HIDInfo、Working with HID

说明

人类输入设备可以用作制作音乐的控制器。此类可与 HIDFunc 或 HIDdef 结合使用，将传入消息与特定的 HID 设备进行匹配。

HIDElementProto 拥有指定 HID 元素的所有变量。你指定的这些变量越多，在过滤传入的 HID 数据时需要匹配的就越多。

类方法

HIDElementProto.new

创建 HIDElementProto 的新实例。

HIDElementProto.newType(uName, pName)

根据元素的 usage id 和 usage page id 创建一个新的 HIDElementProto 实例。

参数：

uName

要匹配的使用 ID 名称

pName

要匹配的用途页名称

返回值：

一个 HIDElementProto

HIDElementProto.newTypeID(uID, pID)

根据元素的 usage id 和 usage page id 创建一个新的 HIDElementProto 实例。

参数：

uID

要匹配的用法 ID

pID

要匹配的用法页面 ID

返回值：

一个 HIDElementProto

HIDElementProto.newFromDict(dict)

根据带有待匹配参数集的 IdentityDictionary 创建 HIDElementProto 的新实例。

参数：

dict

一个 IdentityDictionary，包含一组要匹配的参数。字典中的键应为 HIDElementProto 的实例变量之一。

返回值：

一个 HIDElementProto

实例方法

可用于匹配设备的实例变量

.id

.id = argid

应匹配的元素索引。此索引可能因操作系统而异（另请参见 HIDElement）。

.usageName

.usageName = argup

要匹配的元素的使用名称（另请参阅 HIDElement）。

.pageName

.pageName = argup

要匹配的元素的用法页名称（另见 HIDElement）。

.usage

.usage = argu

要匹配的元素的用法索引（另见 HIDElement）。

.usagePage

.usagePage = argup

要匹配元素的使用页索引（另请参见 HIDElement）。

.usageMin

.usageMin = argup

要匹配的元素的最小 usage 索引（另请参见 HIDElement）。

.usageMax

.usageMax = argup

要匹配的元素的最大 usage 索引（另请参见 HIDElement）。

.type

.type = argio

要匹配的元素类型（另见 HIDElement）。

.typeSpec

.typeSpec = argup

要匹配的元素的 typeSpec（另请参见 HIDElement）。

.ioType

.ioType = argio

要匹配的元素的 IO 类型——输入（1）、输出（2）或特性（3）（另见 HIDElement）。

.iotypeName

.iotypeName = argup

要匹配的元素的 IO 类型——\input、\output 或 \feature（另见 HIDElement）。

要匹配的方法

.matches(ele)

将参数与模板进行匹配。

参数：

ele

一个 HIDElement 实例

返回值：

一个布尔值，指示传入的 HID 是否匹配模板

.shouldMatch

过滤时应匹配的变量

返回值：

带有变量名的 Set。

添加匹配参数的方法

.addTypeMatch(uName, pName)

为元素的 usage name 和 usage page name 添加匹配项。

参数：

uName

要匹配的使用名称

pName

要匹配的页面名称

.addTypeIDMatch(uID, pID)

为元素的 usage id 和 usage page id 添加匹配项。

参数：

uID

要匹配的使用 id

pID

要匹配的使用页面 id

.addDictionaryMatch(dict)

添加一个带有一组参数用于匹配的 IdentityDictionary。该字典中的键应为 HIDElementProto 的实例变量之一。

参数：

dict

一个包含一组待匹配参数的 IdentityDictionary。

示例

// 创建一个 usageName 为 \X 的原型元素
c = HIDElementProto.new.usageName_(\X);
a = HIDFunc.proto({ |...args| args.postln }, c);
a.free;
