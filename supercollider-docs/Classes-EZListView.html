EZListView

一个包装类，包含一个标签以及一个带逐项操作的 listView

另请参阅：ListView

说明

EZListView 是一个封装类，它会创建一个（可选的）标签和一个 listView。它包含逐项动作以及全局动作，二者都在选中某项时求值。还包含用于插入和删除列表项的便捷方法。如果 parent 为 nil，EZListView 会创建自己的窗口。所有选项参见 EZGui 和 EZLists。

关于 EZListView 的一些重要问题

EZListView 的便捷方法要求 items 数组是由标签和函数组成的关联数组，而不像 ListView 中那样，items 只是简单的字符串数组。如果 label 为 nil，则不会创建 staticText。

类方法

创建 / 类方法

.new

参数：

parentView

父视图或窗口。如果父级为 nil，则 EZListView 会创建自己的 Window，并且如果 bounds 是 Point，会将其方便地放置在屏幕上。如果 bounds 是 Rect，则该 Rect 决定窗口的 bounds。

bounds

Rect 或 Point 的实例。默认值为 160@200。

label

标签。默认值为 nil。如果为 nil，则不创建 StaticText。

items

默认值为 nil。一个由 Association 组成的 Array ['label' -> { |listObj| value }, ]。或者是一个 Symbol 组成的 Array（如果你只使用 globalAction）。

globalAction

除条目函数 { |listObj| value } 之外还要执行的全局函数。

initVal

List 的初始值，即选中的索引。默认值为 0。

initAction

Boolean 的实例。在创建列表时于 initVal 处执行该动作，并额外执行 globalAction。默认值为 false。

labelWidth

默认值为 80。如果布局为 \vert，则不使用。

labelHeight

默认值为 20。如果布局为 \horz，则不使用。

layout

\vert 或 \horz。默认为 \vert。

gap

一个 Point。默认情况下，视图会尝试获取其父视图的间距，否则默认为 2@2。设置此项会覆盖上述行为。

margin

一个 Point。这将对 view 的子视图所占用的边界进行内缩。

讨论：

Example:

(
// 默认使用垂直布局
w = Window.new.front;
w.view.decorator = FlowLayout(w.view.bounds);
g = EZListView.new(w,
    230@230,
    "An ListView:",
    [
        \item0 ->{ |a| ("this is item 0 of " ++ a).postln },
        \item1 ->{ |a| ("this is item 1 of " ++ a).postln },
        \item2 ->{ |a| ("this is item 2 of " ++ a).postln },
    ],
    globalAction: { |a| ("this is a global action of "++a.asString).postln },
    initVal: 2,
    initAction: true,
    labelWidth: 120,
    labelHeight: 16,
    layout: \vert,
    gap: 2@2
    );

)

// 或者使用更简单的语法（使用装饰器间隙设置）：
(
w = Window.new.front;
w.view.decorator = FlowLayout(w.view.bounds);
g = EZListView.new(w, 200@230, " List:");
g.addItem(\item0, { |a| ("this is item 0 of " ++ a).postln });
g.addItem(\item1, { |a| ("this is item 1 of " ++ a).postln });
g.addItem(\item2, { |a| ("this is item 2 of " ++ a).postln });
g.setColors(Color.grey, Color.white);
)

更改外观

.setColors

参数：

stringBackground

一个 Color 的实例。标签和单位视图的 background。

stringColor

Color 的实例。标签视图与单位视图的 stringColor。

listBackground

一个 Color 的实例。列表视图的 background。

listStringColor

一个 Color 的实例。列表视图的 stringColor。

selectedStringColor

一个 Color 的实例。listView 的 selectedStringColor。

hiliteColor

一个 Color 的实例。列表视图的 hiliteColor。

background

一个 Color 的实例。列表视图的 background。

.font

设置所有视图使用的 Font。

参数：

font

Font 的一个实例。

示例

若父对象为 nil 则创建自己的窗口：

(
g = EZListView.new(label: " My PopUp List: ");
g.addItem(\item0, { "this is item 0".postln });
g.addItem(\item1, { "this is item 1".postln });
g.addItem(\item2, { "this is item 2".postln });
g.setColors(Color.grey, Color.white);
)

水平布局：

(
g = EZListView.new(nil, 205@180, "Choose One: ", layout: \horz);
10.do{ |i| g.addItem("item"++i.asString, { ("this is item" ++i.asString).postln }) };
g.setColors(Color.grey, Color.white);
)

未创建 labelView，因此设置窗口标题：

(
g = EZListView.new(bounds: 200@230); // 无标签
12.do{ |i| g.addItem("item"++i.asString, { ("this is item" ++i.asString).postln }) };
g.view.parent.findWindow.name = " choose item";
)

插入项：

(
g = EZListView.new(nil, 200@200, "List:");
g.addItem(\item0, { "this is item 0".postln });
g.addItem(\item1, { "this is item 1".postln });
g.addItem(\item2, { "this is item 2".postln });
g.addItem(\item4, { "this is item 4".postln });
)

g.insertItem(3, \item3, { "this is item 3".postln });

移除项：

(
g = EZListView.new(nil, 200@200, "List:");
g.addItem(\item0, { "this is item 0".postln });
g.addItem(\item1, { "this is item 1".postln });
g.addItem(\item2, { "this is item 2".postln });
g.addItem(\item4, { "this is item 4".postln });
g.insertItem(3, \item3, { "this is item 3".postln });
)

g.removeItemAt(1);

替换项：

(
g = EZListView.new(nil, 200@200, "List:");
g.addItem(\item0, { "this is item 0".postln });
g.addItem(\item1, { "this is item 1".postln });
g.addItem(\item2, { "this is item 2".postln });
g.addItem(\item3, { "this is item 3".postln });
)

g.replaceItemAt(2, \item2_replaced, { "this is item 2 replaced".postln });
