MoogFF

Moog VCF 实现，由 Federico Fontana 设计

Filter : PureUGen : UGen : AbstractFunction : Object

另请参阅：RLPF、LPF

说明

Moog VCF（滤波器）的数字实现。1 2

类方法

MoogFF.ar(in, freq: 100, gain: 2, reset: 0, mul: 1, add: 0)

MoogFF.kr(in, freq: 100, gain: 2, reset: 0, mul: 1, add: 0)

参数：

in

输入信号。

freq

截止频率。

gain

滤波器谐振增益，介于零和 4 之间。

reset

当大于零时，这将在计算块开始时重置数字滤波器的状态。

mul

add

实例方法

示例

s.boot;
// 用鼠标演奏……
x = { MoogFF.ar(WhiteNoise.ar(01.1), MouseY.kr(100, 10000, 1), MouseX.kr(0, 4)) }.play(s);
x.free;

// 嗯，脉动感
(
x = {
    MoogFF.ar(
        Pulse.ar([40, 121], [0.3, 0.7]),
        SinOsc.kr(LFNoise0.kr(0.42).range(0.001, 2.2)).range(30, 4200),
        0.83 * 4) }.play(s);
)
x.free;

[1] - 此滤波器的设计在会议论文 Fontana, F. (2007) Preserving the Digital Structure of the Moog VCF 中描述。见 Proc. ICMC07, Copenhagen, 25-31 August 2007。

[2] - 原始 Java 代码由 F. Fontana 创建 - 2007 年 8 月 - federico.fontana@univr.it 由 Dan Stowell 移植到 C++ 以供 SuperCollider 使用
