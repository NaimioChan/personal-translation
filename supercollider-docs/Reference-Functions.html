Functions

lambda 表达式

参见：Function、AbstractFunction、FunctionDef

Introduction

Function 是一个表达式，它定义了当收到 value 消息时要执行的操作。在函数式语言中，函数被称为 lambda 表达式。函数定义包含在花括号 {} 中。参数声明（如果有）跟在开括号之后。变量声明跟在参数声明之后。表达式跟在声明之后。

{ |a, b, c|
    var d;
    d = a * b;
    c + d
}

函数在代码中出现时不会被立即求值，它们本身就是可以被传递的对象。

函数对象可以通过向其传递 value 消息或其简写 .() 以及参数列表来进行求值。

求值时，函数对象返回其表达式的最终值。

f = { |a, b| a + b };
f.value(4, 5).postln;
f.(4, 5).postln; // 同上
f.(10, 200).postln;

空 Function 对象在求值时返回 nil 值。

{}.value.postln;

参数也可以通过名称提供。

f = { |a, b| a + b };
f.(a: 10, b: 2) // 12

f.(b: 3, a: 10) // 13，关键字顺序无关紧要
f.(3, b: 4) // 7，'a' 始终是第一个参数

f.(3, a: 4) // 错误：位置 0 处有重复关键字 'a'。

f.(a: 3) // 错误：二元运算符 '+' 失败，b 为 'nil'，你不能将数字与 'nil' 相加

函数可以被认为是一台能够按需执行任务的机器，例如计算器。计算器可以接收输入（参数）并输出一个值，即所执行运算的结果。函数定义则可以视为计算器的构建过程：一旦构建完成，计算器在被要求工作之前不做任何事（通过向函数传递 value 方法）。下图描绘了一个空函数、无输出的输入、无输入的输出，以及同时具有输入和输出的一般情况。

Arguments

参数列表紧跟在函数定义的开花括号之后。参数列表要么以保留字 arg 开头，要么包含在两个竖线之间。如果函数不接受参数，则可以省略参数列表。

列表中的参数名可以使用以下语法形式初始化为默认值。未显式初始化的参数，如果没有为其传入值，则会被设为 nil。

"arg" 风格，默认值是一个字面量：{ arg x = 1; .... } [1]

"arg" 风格，默认值是一个表达式：{ arg x = 10.rand; ... } [2]

"arg" 风格，默认值是一个字面量，但你希望将其当作表达式处理：{ arg x = (2); ... } [2]

管道风格，默认值为字面量：{ |x = 1| ... } [1]

管道风格，默认值是一个表达式：{ |x = (10.rand)| ... } [2]

通常参数可以初始化为字面量或表达式，但对于 Function: -play 或 SynthDef: -play，它们只能初始化为字面量。

// 这样可以：

{ arg a = Array.geom(4, 100, 3); a * 4 }.value;

// 这不是：

{ arg freq = Array.geom(4, 100, 3); Mix(SinOsc.ar(freq, 0, 0.1)) }.play; // 静音

// 但这是：
{ arg freq =  #[ 100, 300, 900, 2700 ]; Mix(SinOsc.ar(freq, 0, 0.1)) }.play; // 产生声音！

更多信息请参见 Literals。

可变参数

可变参数是函数接收未知数量参数或关键字参数的方式。可变参数有两种：第一种用于位置参数，第二种用于关键字参数。它们由普通参数之后的省略号标记，并以逗号分隔。

第一个变量参数（位置参数）会在一个 Array 中捕获所有剩余参数

f = { |a ... args| "a: %, args: %".format(a, args) };

f.(1, 2, 3) // a: 1, args: [2, 3]
f.(1) // a: 1, args: []
f.(a: 1) // a: 1, args: []

// 捕获所有参数
g = { |...args| "args: %".format(args) };

g.(1, 2, 3) // args: [1, 2, 3]
g.() // args: []

第二个变量参数会捕获所有关键字参数。它将这些参数放入一个由键值对组成的 Array 中。

f = { |...args, kwargs| "args: %, kwargs: %".format(args, kwargs) };

f.(1, 2, 3) // args: [1, 2, 3], kwargs: []

f.(a: 10) // args: [], kwargs: [a, 10]

f.(1, 2, 3, meow: 10, woof: 20) // args: [1, 2, 3], kwargs: [meow, 10, woof, 20]

变量关键字参数的使用通常与 Object: -performArgs 搭配。

虽然你可以为可变参数取任意名称，但它们始终指向未被匹配的位置参数和关键字参数，因此通常最好将它们命名为 args 和 kwargs。

即使变量参数在调用处具有相同的名称，你也不能重新赋值它们（见下面的示例）。

f = { |...args, kwargs| "args: %, kwargs: %".format(args, kwargs) };
f.(args: 10, kwargs: 20) // args: [], kwargs: [args: 10, kwargs: 20]

f = { |...a, b| "a: %, b: %".format(a, b) };
f.(a: 10, b: 20) // a: [], b: [a: 10, b: 20]

[1] 字面量参数默认值

作为字面量的参数默认值会作为 FunctionDef 的一部分存储。运行时传入的参数——包括 nil——总是覆盖默认值：

f = { |x = 1| x };
f.(2);  // 输出 2

f.();   // 输出 1

f.(nil);  // 输出 nil

[2] 表达式参数默认值

由于表达式是在函数被调用时才求值，因此它们无法存储在 FunctionDef 中。仅当传入的值为 nil 时，它们才会被执行。

f = { |x = (10.rand)| x };
f.value(100);  // 输出 100

f.value;   // 打印一个 0-9 的数字

f.(nil);   // 打印一个 0-9 的数字！

这意味着你可以使用表达式风格来定义不能被 nil 覆盖的默认值。

f = { |x = (3)| x };
f.(nil);   // 输出 3

注意：如果参数列表写在 || 管道符内，那么将参数初始化为表达式时需要使用括号。

(
var abc = 2;
{ arg x = abc+1; x }   // OK
)

(
var abc = 2;
{ |x = abc+1| x }
)
ERROR: Parse error
   in file 'selected text'
   line 1 char 10:
  { |x = abc•+1| x }
-----------------------------------
ERROR: Command line parse failed

(
var abc = 2;
{ |x = (abc+1)| x }   // OK
)

(
var abc = 2;
{ |x (abc+1)| x }   // 在 || 中，如果有 ()，则可以省略 =
)

这是因为管道字符同时也用作二元运算符。如果不加括号，像下面这样的表达式就会产生歧义：

{ |a, b, c = a | b | c }

以下产生相同的函数定义。表达式风格的默认值只是后者的快捷语法。

{ arg x = 10.rand; x };

{    arg x;
    x ?? { x = 10.rand };
    x
};

Variables

参数声明之后是变量声明。这些声明可以按任意顺序排列。变量列表以保留字 var 开头。如有必要，可以有多个 var 声明列表。变量可以像参数一样初始化为默认值。变量声明列表不能包含省略号。

var level=0, slope=1, curve=1;
