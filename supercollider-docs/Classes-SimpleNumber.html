.softRound(resolution: 1.0, margin: 0.05, strength: 1.0)

将值舍入到 resolution 的倍数。通过使用 margin 和 strength，你可以控制哪些值将被舍入，以及舍入多少。

从概念上讲，这等同于 DAW/MIDI 音序器中的 MIDI 量化。特别是它允许在接近 resolution 值的范围内存在一定的松散度。

注意：此方法要求值 >= 0。

参数：

resolution

将此值舍入到 resolution 的倍数。例如，如果选择 1，则所有值都将舍入到最接近的整数。

margin

位于 resolution 的倍数 ±margin 范围内的值将保持原样。

例如，如果你选择的分辨率值为 0.5、边距为 0.01，那么值 0.501 和 0.499 将保持原样，但值 0.502 将变为 0.5。

这应该是一个介于 0 和 resolution 之间的值。

strength

确定此数值将被改变的程度。

如果 strength 为 1，此函数将返回最接近的分辨率。如果为 0，则此数值保持不变。

例如，如果分辨率为 1 且强度为 0.5，那么值 0.6 会变成 0.8。

讨论：

((0..10) / 5).collect { |num| [num, num.softRound(1, 0, 1)] };
((0..10) / 5).collect { |num| [num, num.softRound(1, 0.3, 1)] };
((0..10) / 5).collect { |num| [num, num.softRound(1, 0, 0.5)] };

.snap(resolution: 1.0, margin: 0.05, strength: 1.0)

将距 resolution 为 margin 距离内的值舍入为 resolution 的倍数。通过使用 margin 和 strength，你可以控制何时舍入这些值以及舍入的程度。

从概念上讲，这相当于图形程序中的“吸附”。与网格线距离在一定范围内（margin）的值会被吸附到网格线上。所有其他值保持不变。

注意：此方法要求值 >= 0。

参数：

resolution

将此值吸附到 resolution 的倍数。例如，如果你选择 1，则所有值都将四舍五入到最接近的整数。

margin

只有与 resolution 值的倍数相差超过 ±margin 的值才会被改变。小于 margin 的值将保持不变。

例如，如果你选择的分辨率值为 0.5、边距为 0.01，那么值 0.501 和 0.499 将被吸附到 0.5，但值 0.502 将保持不变。

这应该是一个介于 0 和 resolution 之间的值。

strength

确定此数值将被改变的程度。

如果 strength 为 1，此函数将返回最接近的分辨率。如果为 0，则此数值保持不变。

例如，如果分辨率为 1 且强度为 0.5，那么值 0.6 会变成 0.8。

讨论：

((0..10) / 5).collect { |num| [num, num.snap(1, 0, 1)] };
((0..10) / 5).collect { |num| [num, num.snap(1, 0.3, 1)] };
((0..10) / 5).collect { |num| [num, num.snap(1, 0, 0.5)] };

.series(second, last)

生成一个从 this 经过 second 到 last 的等差数列。

如果 second 为 nil，则它是朝 last 方向的一个幅度步长（1 或 -1）。

series(5, 7, 10);
series(5, nil, 10);
(5, 7 .. 10)

这在快捷方式中使用：

(0..100);
(1, 3 .. 17)

返回值：

一个 Array。

讨论：

如果步长不能整除序列的范围，最后一个值可能不会包含在结果中。

.seriesIter(second, last)

创建一个 Routine，它从 this 开始，以 second 为步长，迭代到 last 的等差数列。

由于这是一个惰性操作，last 可以是 inf，从而生成无限的序列。如果未指定，last 将根据步进方向为 inf 或 -inf。

r = seriesIter(0, 5, 52);
r.nextN(8);
r.nextN(8); // 到达 'last'，然后变为 nil

r = seriesIter(0, 5); // last = inf
r.nextN(8); // 反复运行

另请参见 -series 和 List Comprehensions。

返回值：

一个 Routine。

.gaussCurve(a: 1.0, b: 0.0, c: 1.0)

将接收者映射到高斯函数上。

使用公式：

a * -exp((this - b).squared / (2 * c.squared))

其中 a 是分布幅度，b 是均值（通常记作 mu），方差为 c.squared（sigma^2）。

该方法默认为“标准正态分布”：均值为零，峰值幅度和方差均为 1.0（a = 1.0, b = 0.0, c = 1.0）。

(0..1000).normalize(-10, 10).collect { |num| num.gaussCurve }.plot;

Jacobi 椭圆函数

与所有椭圆函数一样，这些函数可以通过多种方式参数化：

  • 以参数 m 表示。
  • 根据椭圆模数 k，其中 m = k^2。
  • 根据模角 α，其中 m = sin2α。

此实现将椭圆模数 k 作为参数。此外，变量 u 用于表示振幅 φ。所有函数都将椭圆模数作为第一个参数——这是为了与 Elliptic Integrals 保持一致。
