Git

git 接口

Object

另请参阅：Quarks、Quark

说明

一个通往 git 工具链的接口。有关 git 的更多信息，参见 http://git.io。

类方法

Git.new(localPath)

创建一个新的 Git 实例，指向一个已存在的本地 git 仓库。

参数：

localPath

git 仓库的路径。

Git.isGit(localPath)

如果本地目录是 git 仓库，则返回 true。

参数：

localPath

Git.checkForGit

如果系统上找到 git 工具链，则返回 true。

实例方法

info

返回值：

.remote

.url

.url = value

返回值：

它找到的第一个 remote 的 url。

.remoteAsHttpUrl

检测远程 URI 是否以 "git@" 或 "git:" 开头，并将其重塑为有效的 "https" URI。否则，返回未更改的远程地址。

// git 风格的远程 URI 会被转换为 https
Git().url_("git@github.com:foo/bar.git").remoteAsHttpUrl;
Git().url_("https://github.com/foo/bar").remoteAsHttpUrl;
Git().url_("git@foo.net:foo/bar.git").remoteAsHttpUrl;

// http 和 https 保持不变
Git().url_("https://foo.org/bar").remoteAsHttpUrl;
Git().url_("http://foo.org/bar").remoteAsHttpUrl;

// 未知的 URI 样式保持原样
Git().url_("fooBar").remoteAsHttpUrl;

返回值：

用于 http 和 https 请求的远程 URI。

示例

// 创建一个指向 Quark 目录的 Git
g = Git(Quarks.all.choose.localPath);

// 或者，提供本地 git 仓库的路径名：
g = Git("/path/to/local/repo");

// 获取所有可用标签
g.tags;

// 返回本地路径
g.localPath;

// 返回 URL
g.url;
