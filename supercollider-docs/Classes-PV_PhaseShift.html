PV_PhaseShift

相移。

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

参见：FFT、IFFT、PV_PhaseShift90、PV_PhaseShift270、PV_Diffuser

说明

移动所有频段的相位。

类方法

PV_PhaseShift.new(buffer, shift, integrate: 0)

参数：

buffer

FFT 缓冲区。

shift

相位偏移，单位为弧度。

integrate

如果大于零，则在各次调用之间累积相移（用于累积相移）。

实例方法

示例

s.boot;

(
SynthDef("help-phaseShift", { |out = 0|
        var in, chain;
        in = SinOsc.ar(500);
        chain = FFT(LocalBuf(2048), in);
        chain = PV_PhaseShift(chain, LFNoise2.kr(1, 180, 180));
        Out.ar(out, 0.1 * IFFT(chain).dup);
}).play(s);
)
