ServerOptions

封装 Server 的命令行及其他选项

Object

另请参见：Server、Server Architecture、Server Command Reference、Audio device selection

子类：BelaServerOptions

说明

ServerOptions 将服务器应用的各种选项封装在一个对象中。这使得用相同的选项启动多个服务器，或归档不同的选项集等操作变得很方便。每个 Server 在创建时如果没有将 ServerOptions 实例作为 options 参数传入，都会为其创建一个 ServerOptions 实例。（例如，启动时创建的 local 和 internal 服务器就是这种情况。）

Server 的 ServerOptions 实例存储在其 options 实例变量中，可通过相应的 getter 和 setter 方法访问。

注意：ServerOptions 的实例变量会在服务器应用启动时转换为命令行参数。因此，必须重新启动正在运行的 Server 才能使更改生效。此外，还有一些命令行选项目前未被封装在 ServerOptions 中。详见 Server Architecture。

类方法

ServerOptions.new

创建并返回 ServerOptions 的新实例。

ServerOptions.devices

返回一个字符串数组，列出系统当前可用的音频设备。

ServerOptions.inDevices

返回一个字符串数组，列出系统当前可用的、具有输入通道的音频设备。

ServerOptions.outDevices

返回一个字符串数组，列出系统当前可用的、具有输出通道的音频设备。

注意： 如果 SuperCollider 使用 JACK 后端编译（Linux 上默认如此），上述三个方法均不可用。关于选择音频设备的更多信息，另请参阅音频设备选择。

实例方法

选项

.blockSize

.blockSize = value

一个控制周期内的采样数。默认为 64。

.device

.device = dev

一个 String，用于选择作为输入和输出使用的声音设备。默认值 nil 将使用系统的默认输入和输出设备。更多详情请参见 Audio device selection。

.inDevice

.inDevice = value

一个字符串，用于选择输入声音设备。默认值 nil 将使用系统的默认输入设备。详见 音频设备选择。

.outDevice

.outDevice = value

一个字符串，允许你选择一个输出声音设备。默认值 nil 将使用系统的默认输出设备。详情请参见 音频设备选择。

.hardwareBufferSize

.hardwareBufferSize = value

首选的硬件缓冲区大小。若为非空（non-nil），服务器应用将尝试设置硬件缓冲区的帧大小。并非所有大小都有效。详情请参阅你的音频硬件文档。默认值为 nil。

.initialNodeID

.initialNodeID = value

默认情况下，客户端中的 Server 对象从 1000 开始分配节点 ID，将 0-999 保留给“永久”节点。你可以在此处更改此默认值。

.inputStreamsEnabled

.inputStreamsEnabled = value

一个 String，用于关闭音频设备上你不感兴趣的输入流。例如，如果该字符串为 "01100"，则只启用设备上的第二个和第三个输入流。关闭流可以减少 CPU 负载。默认值为 nil。

.loadDefs

.loadDefs = value

一个布尔值，指示是否在启动时加载 synthdefs/ 中（或环境变量 SC_SYNTHDEF_PATH 中设置的任何位置）的 synth 定义。默认值为 true。

.maxNodes

.maxNodes = value

节点的最大数量。默认值为 1024。

.maxSynthDefs

.maxSynthDefs = value

synthdef 的最大数量。默认值为 1024。

.memSize

.memSize = value

分配给服务器的实时内存量，单位为千字节。此内存用于分配 synth 以及 unit generator 自身分配的任何内存（例如在不使用缓冲区的延迟 ugen 的情况下，如 CombN），并且与用于缓冲区的内存分开。将此值设置得太低是“exception in real time: alloc failed”错误的常见原因。默认值为 8192。

.numAudioBusChannels

.numAudioBusChannels = numChannels: 1024

音频速率总线的数量，包含输入和输出总线。默认值为 1024。

.numBuffers

.numBuffers = value

可用的全局采样缓冲区数量。（参见 Buffer。）默认值为 1024。

.numControlBusChannels

.numControlBusChannels = value

内部控制速率总线的数量。默认值为 16384。

.numInputBusChannels

.numInputBusChannels = numChannels: 2

音频输入总线通道的数量。这不必与硬件输入的数量相对应。默认值为 2。

.numOutputBusChannels

.numOutputBusChannels = numChannels: 2

音频输出总线通道数。这不必与硬件输出数量相对应（例如，在录音情况下这很有用）。默认值为 2。

.numRGens

.numRGens = value

可播种随机数生成器的数量。默认是 64。

.numWireBufs

.numWireBufs = value

分配给互连 unit generator 的最大缓冲区数量。（不要与由 Buffer 表示的全局采样缓冲区混淆。）这设定了运行时可以加载的 SynthDef 的复杂度上限。如果在启动时加载了更复杂的 def，此值会自动增大，但此后若不重新启动则无法再增大。默认值为 64。

.outputStreamsEnabled

.outputStreamsEnabled = value

一个 String，用于关闭音频设备上你不感兴趣的输出流。例如，如果该字符串为 "11000"，则只启用设备上的前两个输出流。关闭流可以减少 CPU 负载。

.protocol

.protocol = value

表示通信协议的 Symbol。为 \udp 或 \tcp。默认值为 \udp。

.bindAddress

.bindAddress = value

服务器 TCP 或 UDP 套接字正在监听的 IP 地址。默认值为 "127.0.0.1"，表示仅监听主机上的 OSC 消息。

警告： 在 SuperCollider 3.10.3 之前，此项被设置为 "0.0.0.0"（监听所有网络接口）。然而，这是一个危险的默认配置——对于大多数在连接 WiFi 的笔记本电脑上工作的用户来说，这意味着你本地网络上的任何人都可以向服务器发送 OSC 消息。只有在你运行联网的服务器/客户端，并且你的网络配置正确时，"0.0.0.0" 才是有用的，也才是安全的。在 SuperCollider 3.12 之前，supernova 监听所有网络接口并忽略 bindAddress 选项。在后续版本中，其行为与 scsynth 相同。

.remoteControlVolume

.remoteControlVolume = value

一个布尔值，指示此服务器是否应允许远程设置其音量。默认值为 false。

.sampleRate

.sampleRate = value

首选采样率。若非 nil，服务器应用程序将尝试设置硬件的采样率。硬件必须支持你所选择的采样率。

注意： 在 Windows 上，为 ASIO 设备将 sampleRate 保留为 nil 很可能导致将硬件设置为以 44100 Hz 运行。

.verbosity

.verbosity = value

控制服务器消息的详细程度。值为 0 是正常行为。-1 抑制信息性消息。-2 抑制信息性消息和许多错误消息，以及来自 Poll 的消息。默认值为 0。

.zeroConf

.zeroConf = value

布尔指示，表示服务器是否应使用零配置网络发布其端口，以方便网络交互。默认值为 true；如果服务器启动时出现无法接受的延迟（沙滩球），可以尝试将其设为 false。

.ugenPluginsPath

.ugenPluginsPath = value

一个路径或路径数组。如果非 nil，则不会在标准路径中搜索插件。这对应于选项 "-U"。

.restrictedPath

.restrictedPath = value

允许你限制服务器在运行时被允许读/写文件的系统路径。nil 值（默认值）表示无限制。否则，将其设置为表示单个路径的字符串。

.threads

.threads = value

由 supernova 生成的音频线程数。对于 scsynth 此值被忽略。如果为 nil 或 0，则每个 CPU 核心使用一个线程。默认为 nil。

.threadPinning

.threadPinning = value

启用/禁用线程绑定。对于 scsynth，此值会被忽略。线程绑定强制每个线程仅在特定的 CPU 核心上运行。取决于系统，这可能带来更好或更差的性能。默认值为 nil，表示该值由 Supernova 选择。（在撰写本文时，它在 Linux 上默认启用，在 macOS 和 Windows 上默认禁用。）

.useSystemClock

.useSystemClock = value

告诉 supernova 是与驱动器的采样时钟同步，还是与系统时钟同步。

注意： scsynth 始终使用系统时钟，此值会被忽略。

  • true（默认）——使用系统时钟。带时间戳的消息在长时间会话中会保持一致的延迟，但可能并非完全样本精确。
  • false -- 使用采样时钟。这有助于支持采样精确的调度；但是，来自 SuperCollider 语言的消息延迟会随着时间的推移而漂移。

.memoryLocking

.memoryLocking = value

一个布尔值，指示服务器是否应尝试将其内存锁定到物理 RAM 中。默认为 false。

.maxLogins

.maxLogins = logins

一个 Integer，表示可以同时从服务器接收通知的客户端的最大数量。使用 TCP 时，这也是同时连接的最大数量。语言也使用它来划分 Nodes、Buffers 或 Busses 的范围。在多客户端情况下，你需要将其设置为至少是你希望允许的客户端数量。每个客户端上的 Server 实例中此值必须相同。默认值为 1。最大值为 32。

.safetyClipThreshold

.safetyClipThreshold = value

注意： 仅限 MacOS

一个 Float，表示输出值被削波的安全阈值。这在 macOS 上是必要的，因为设置较低的系统音量并不能阻止大于 +/- 1 的输出值听起来极其响亮，而这可能因失误而发生，例如向滤波器发送负系数时。使用此阈值时，值会在写入硬件输出总线之前被削波，这不会影响录音。但是，如果信号高于阈值，并且声音通过第三方软件路由到其他应用，则信号会受到影响。默认阈值为 1.26（约 2 dB），以保护一些耳朵，同时仍保留一些余量。将 safetyClipThreshold 设置为 inf、0 或负值，会完全禁用削波。

示例

// 获取默认服务器的选项

o = Server.default.options;

// 输出输出通道数量

o.numOutputBusChannels.postln;

// 将它们设为新数字

o.numOutputBusChannels = 6; // 下次启动时, 这将生效

// 指定一个设备

o.device = "MOTU Traveler";     // 使用特定的声卡
o.device = nil;            // 使用系统默认声卡

// 最后，启动服务器

Server.default.boot;
// 或者，如果服务器已在运行，则重启它
Server.default.reboot;


// ServerOptions 与多服务器

// 为以下内容创建一个新的 ServerOptions 实例

p = ServerOptions.new;

// 将内存大小设置为默认值的两倍

p.memSize = 4096;

// 使用 o 作为选项在本地机器上创建一个新的 Server

t = Server(\Local2, NetAddr("127.0.0.1", 57111), p);
t.makeWindow;
t.boot;
t.quit;
