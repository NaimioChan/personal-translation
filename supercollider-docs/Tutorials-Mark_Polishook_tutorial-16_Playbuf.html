将合成过程分解为完成小型明确任务的部分，有助于模块化设计和组件复用（即面向对象编程的信条）。

(
// 从磁盘读取声音文件
b = Buffer.read(s, ExampleFiles.child);

// 单声道的 samplePlayer……仅一个通道
SynthDef("aMonoSamplePlayer", { arg bus = 0, bufnum = 0, rateScale = 1;
    Out.ar(
        bus,
        PlayBuf.ar(
            1,
            bufnum,
            BufRateScale.kr(bufnum) * rateScale
        )
        *
        EnvGen.kr(Env.sine(BufDur.kr(bufnum)))
    )
}).add;
)

(
// 测试 synthdef……它能工作吗？（是的，没问题。它在左声道播放）
Synth("aMonoSamplePlayer", [\bus, 0, \bufNum, b]);
)


(
// 组件重用的一个简单示例……使用 \bus 参数将从
// 同一 synthdef 构建的 synth 分配到不同通道
// 在这种情况下，在 2 个通道上播放 1 通道的声音文件
// 每个通道使用不同的播放速率使效果更明显
Synth("aMonoSamplePlayer", [\bus, 0, \bufNum, b, \rateScale, 0.99]);
Synth("aMonoSamplePlayer", [\bus, 1, \bufNum, b, \rateScale, 1.01]);
)

Information

如上一个例子所示，BufRateScale 和 BufDur 这两个 ugen 控制 PlayBuf 播放声音文件的速率以及施加于 playbuf 的包络长度。

BufRateScale 和 BufDur 属于继承自 InfoUGenBase 或 BufInfoUGenBase 的一族 ugen。

要查看此类 UGen 的完整列表，请执行

InfoUGenBase.dumpClassSubtree;

它返回

InfoUGenBase
[
  NumRunningSynths
  NumBuffers
  ControlDur
  NumControlBuses
  SubsampleOffset
  RadiansPerSample
  SampleDur
  ControlRate
  NumInputBuses
  NumAudioBuses
  SampleRate
  NumOutputBuses
]
InfoUGenBase

Evaluate

BufInfoUGenBase.dumpClassSubtree;

并且它返回

BufInfoUGenBase
[
  BufChannels
  BufSampleRate
  BufRateScale
  BufFrames
  BufDur
  BufSamples
]
BufInfoUGenBase

循环一个采样

下一个示例使用三个 synthdef 构成一条链。第一个 synthdef 是一个循环播放缓冲区的采样播放器。第二个 synthdef 对其输入进行环形调制。第三个 synthdef 应用低通滤波器。

(
// 读取声音文件
b = Buffer.read(s, ExampleFiles.child);

// 定义一个样本播放器，它将循环播放一个声音文件
SynthDef("aLoopingSamplePlayer", { arg outBus = 0, bufnum = 0, rateScale = 1, mul = 1;
    Out.ar(
        outBus,
        PlayBuf.ar(
            1,
            bufnum,
            BufRateScale.kr(bufnum) * rateScale + LFNoise1.kr(2.reciprocal, 0.05),
            loop: 1    // 反复播放声音文件而不停止
        )
        *
        mul
    )
}).add;

// 对音频源应用振幅调制
SynthDef("ampMod", { arg inBus = 0, outBus = 0, modFreq = 1;
    Out.ar(
        outBus,
        [    // In.ar ugen 从音频总线读取
            In.ar(inBus, 1) * SinOsc.kr(modFreq),
            In.ar(inBus, 1) * SinOsc.kr(modFreq - 0.02)
        ]
    )
}).add;

// 对音频源应用低通滤波器
SynthDef("aLowPassFilter", { arg inBus = 0, outBus = 0, freq = 300, freqDev = 50, boost = 1;
    Out.ar(
        outBus,
        RLPF.ar(
            In.ar(inBus, 2),
            Lag.kr(LFNoise0.kr(1, freqDev, freq), 1),
            0.2
        )
        *
        boost
        *
        LFPulse.kr(1, [0.25, 0.75], [0.5, 0.45])
        +
        In.ar(inBus, 2)
    )
}).add;
)

// 定义 2 个组，一个用于源素材，另一个用于效果
(
~source = Group.head(s);
~effect = Group.tail(~s);
)

(
// 将 samplePlayer 添加到源组
~theSource = Synth.head(
    ~source,
    "aLoopingSamplePlayer", [\outBus, 3, \bufNum, b, \rateScale, 1, \mul, 0.051]);
// 在效果组的头部添加一个振幅调制合成器
~fx1 = Synth.head(
    ~effect,
    "ampMod", [\inBus, 3, \outBus, 5, \modFreq, 1]);
// 为效果组的尾部添加滤波
~fx2 = Synth.tail(
    ~effect,
    "aLowPassFilter", [\inBus, 5, \outBus, 0, \boost, 5])
)

// 检查节点
(
s.queryAllNodes;
)
// 示意图

    RootNode
    |
  default_node
      /\
     /  \
~source  ~effects    // ~source 和 ~effects 是组
 |        |      \
 |        |       \
 synth    synth    synth
// 更改参数（控制）值会影响音色
(
 ~theSource.set(\rateScale, 0.95.rrand(1.05), \mul, 0.051.rrand(0.07));
 ~fx1.set(\modFreq, 800.0.rrand(1200));
 ~fx2.set(\freq, 500.rrand(700), \freqDev, 180.rrand(210), \boost, 7);
)
