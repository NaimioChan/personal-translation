FuncStream

函数的流

Stream : AbstractFunction : Object

另请参阅：Pfunc

说明

FuncStream 是描述流的最基本方式之一：它有一个函数，在每个下一个流值被请求时调用。

// 创建一个返回随机数的流
a = FuncStream({ 1.0.rand });
a.next;

它使用 Function: -inEnvir 将函数调用静态绑定到创建 FuncStream 时所处的环境。

a = Environment.use { ~x = 100; FuncStream({ ~x + 8 }) };
~x = 0;
a.next; // 返回 108，而非 8。

类方法

FuncStream.new(nextFunc, resetFunc)

返回一个新的流对象。

(
var func, reset, count = 0;
func = { count = count + 2.rand };
reset = { count = 0 };
a = FuncStream(func, reset);
)

a.next;
a.nextN(80).plot;
a.reset;
a.next; // 重新开始。

参数：

nextFunc

在每次下一个时被调用的函数

resetFunc

重置时调用的函数

实例方法

.next(inval)

参数：

inval

通过调用函数返回下一个值。inval 作为参数传递给该函数。

.reset

如果已定义，则调用重置函数。

.envir

.envir = value

获取或设置函数所绑定的环境。

.nextFunc

.nextFunc = value

获取或设置 -next 上被调用的函数。

.resetFunc

.resetFunc = value

获取或设置 -reset 上调用的函数。

示例

(
// 创建 16 个不同的序列
a = {
    var diff = [2, 4, 5].choose * [1, -1].choose;
    var val = 0;
    var stream = FuncStream({
        // 下一个函数
        val = val + diff;
        if(abs(val) > 30) { stream.reset };
        val
    }, {
        // 重置函数
        val = 0
    });
    stream
}.dup(16);

// 将它们作为并行音符播放
fork {
    loop {
        (
            note: a.collect { |f| f.next.postln },
            sustain: 0.1
        ).play;

        // 重置一个随机选择的 FuncStream
        a.choose.reset;
        0.16.wait;
    }
}
)
