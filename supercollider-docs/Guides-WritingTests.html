编写测试

开始编写单元测试

参见：SCDoc Syntax、SCDoc

要编写、使用和开发 UnitTest，你需要

  • 安装 SuperCollider 的源代码版本
  • 将你的环境更改为仅包含核心库功能
  • 运行 UnitTests

安装 SuperCollider 的源代码版本

从 github 下载或克隆 SuperCollider：https://github.com/supercollider/supercollider.不需要从源代码编译 SuperCollider，你可以改用预编译的二进制文件，并在你的环境中包含相关文件夹（SCClassLibrary, HelpSource, testsuite/classlibrary）。参见下面的示例。

将你的环境更改为仅包含核心库功能

为了模拟标准的 SuperCollider 安装，请确保你只安装了类库。

最佳实践是创建一个单独的 .yaml 配置文件，与默认配置文件并列存放。你可以在 IDE 的首选项中交互式地执行此操作（Preferences>Interpreter），也可以通过编程方式执行

~sclangConf = "SCLANG_CONF".getenv;
LanguageConfig.addIncludePath(~scSourceDir +/+ "testsuite/classlibrary");
+   LanguageConfig.addExcludePath(~scSourceDir +/+ "testsuite/classlibrary/server");
+   LanguageConfig.addExcludePath(Quarks.folder +/+ "UnitTesting/tests");
+   postf("Writing configuration to %\n", ~sclangConf);
+   LanguageConfig.store(~sclangConf);

Organisation

核心类 UnitTest 位于目录 1 中。UnitTests 放入相应的并行目录 2。与服务器相关的测试放入 `server` 子目录 3。UnitTests 应使用 assert 和 assertFloat 4. 查看现有的 UnitTests 以了解什么是好的 UnitTests 5. UnitTest 设置 8. 运行 UnitTests，可以自动运行（UnitTest.runAll）、交互式运行（UnitTEst.gui），或按类单独运行（MyClass.test / TestMyClass.run << 同义词）
