Char

ASCII 字符

Magnitude : Object

另请参阅：String

说明

以有符号 8 位整数（-128 到 127）表示的 ASCII 字符。有效的 ASCII 值在 0-127 范围内。字符可以用 $ 符号作为字面量书写。例如：$a、$b、$c。某些特殊字符可以使用转义序列表示为字面量（例如，$\n 表示换行）。更多信息请参见 Literals: Characters。

字符可以由 Integers 通过 Integer: -asAscii 和 Integer: -asDigit 方法创建。

请注意，虽然 Char 不支持 ASCII 之外的编码——例如 UTF-8 和 UTF-16 等多字节编码，或完整的 Latin-1（ISO 8859-1）字符集——但值为负的 Char 是完全合法的，并且可以在使用这些编码的字符串中串联在一起。

SuperCollider IDE 使用 UTF-8 来解码和显示字符串。更多信息请参见 String。

实例方法

conversion

.hash

返回值：

接收者的哈希值。

.ascii

返回值：

一个 Char 的整数 ASCII 值。

.digit

返回值：

对于字符 $0 到 $9 是 0 到 9 的整数值，对于字符 $a 到 $z 或 $A 到 $Z 是 10 到 35 的值。

.asAscii

返回值：

对象本身。

.asUnicode

返回值：

对象本身。

.toUpper

返回值：

字符的大写版本。非字母字符返回其本身。

.toLower

返回值：

一个字符的小写版本。非字母字符返回其本身。

Testing

.isAlpha

返回值：

该字符是否为字母字符。

.isAlphaNum

返回值：

该字符是否为字母或数字字符。

.isPrint

返回值：

该字符是否可打印。

.isPunct

返回值：

该字符是否为标点字符。

.isControl

返回值：

若该字符是控制字符则为 true。

.isSpace

返回值：

如果该字符是空白字符，则为 true，包括 [$ , $\f, $\n, $\r, $\t, $\v] 中的任意一个。

.isDecDigit

返回值：

若该字符是十进制数字 $0 到 $9，则为 true。

.isFileSafe

返回值：

如果该字符可安全用于文件名则为 true。排除路径分隔符 / 和 :

讨论：

 for(0, 255, { |i|
    var a;
    [i, a = i.asAscii, a.isAlphaNum, a.isPrint, a.isPunct, a.isControl].postln;
});

.isLower

返回值：

如果字符是小写字母则为 true。

.isUpper

返回值：

如果字符是大写字母则为 true。

.isPathSeparator

返回值：

如果该字符是平台特定的路径分隔符之一则为 true。

.isVowel

返回值：

如果该字符是元音则为 true。
