LinCongN

线性同余混沌生成器

ChaosGen : UGen : AbstractFunction : Object

参见：LinCongL、LinCongC

子类：LinCongC、LinCongL

说明

基于差分方程的非插值声音发生器：

        x(n+1) = (a * x(n) + c) % m

输出信号自动缩放到 [-1, 1] 范围。

sclang 代码转换：

(
var a = 1.1, c = 0.13, m = 1, xi = 0, size = 64;
plot(size.collect { xi = (a * xi + c) % m });
)

类方法

LinCongN.ar(freq: 22050, a: 1.1, c: 0.13, m: 1.0, xi: 0, mul: 1.0, add: 0.0)

参数：

freq

以赫兹为单位的迭代频率

a

乘数数量

c

增量值

m

模数数量

xi

x 的初始值

mul

add

未文档化的类方法

LinCongN.equation

实例方法

示例

// 默认初始参数
{ LinCongN.ar(MouseX.kr(20, SampleRate.ir)) * 0.2 }.play(s);
// 随机调制参数
(
{ LinCongN.ar(
    LFNoise2.kr(1, 1e4, 1e4),
    LFNoise2.kr(0.1, 0.5, 1.4),
    LFNoise2.kr(0.1, 0.1, 0.1),
    LFNoise2.kr(0.1)
) * 0.2 }.play(s);
)
// 作为频率控制...
(
{
SinOsc.ar(
    LinCongN.ar(
        40,
        LFNoise2.kr(0.1, 0.1, 1),
        LFNoise2.kr(0.1, 0.1, 0.1),
        LFNoise2.kr(0.1),
        0, 500, 600
    )
) * 0.4 }.play(s);
)
