Dconst

将需求率流约束为给定的总和

DUGen : UGen : AbstractFunction : Object

说明

Pconst 的需求率类似物。它从子需求流中输出值，直到这些值的总和达到或超过给定的总和。最后一个值将被截断，以便 Dconst 输出值的总和与总和完全一致。

类方法

Dconst.new(sum, in, tolerance: 0.001)

参数：

sum

要达到的和。它可以是一个数字、demand UGen 或任何其他 UGen。当 Dconst 实例重置时，会取一个值作为和，并且在下次重置之前无法对其进行调制。

in

一个 demand-rate 流，提供输出值。

tolerance

由于浮点舍入误差，仅在输出的运行总和等于所需总和时才停止是不安全的。tolerance 是运行总和可以接近以停止输出的程度：abs(runningsum - sum) <= tolerance。

返回值：

一个需求率流。

实例方法

示例

// 0.5 秒的随机时长快速音符
// 然后 0.5 秒的单个音符
(
a = {
    var freq = Duty.kr(
        Dseq([
            Dconst(0.5, Dwhite(0.05, 0.08, inf)),
            0.5
        ], inf),
        0,
        // 弥补 Dexprand 缺失的变通方法
        Dwhite(0, 1, inf).linexp(0, 1, 200, 600)
    );
    VarSaw.ar(Lag.kr(freq, 0.02), 0, 0.3, 0.1).dup
}.play;
)

a.free;
