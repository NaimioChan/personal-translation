Polymorphism

不同类以不同方式响应同一消息的能力

另请参阅：消息、类、对象入门

Introduction

多态是指不同类能够以不同方式响应同一消息的能力。一条消息通常具有某种内在含义，而每个类都有责任以适合该含义的方式作出响应。

例如，value 消息表示“给我这个对象的有效值”。

value 方法由这些类（以及其他类）实现：

函数：

this.value(args)

Object :

this.value()

Ref：

this.value

让我们看看这些类如何实现 value 消息。

Object

以下是 Object 类中的 value 方法：

value { ^this }

它只是返回自身。由于所有类都继承自类 Object，这意味着除非某个类重写了 value，否则对象对 value 的响应就是返回自身。

5.postln;            // 自我发布
5.value.postln;        // 值返回自身
'a symbol'.postln;
'a symbol'.value.postln;
[1,2,3].value.postln;
//etc...

Function

在类 Function 中，value 方法是一个原语：

value { arg ... args;
    _FunctionValue
    // 求值带参数的函数
    ^this.primitiveFailed
}

_FunctionValue 是一个 C 代码原语，因此仅通过查看它无法知道它的作用。不过，它的作用是求值该函数并返回结果。

{ 5.squared }.postln;            // 输出 Function 的实例
{ 5.squared }.value.postln;        // 发布 25

Ref

Ref 类提供了一种创建对象间接引用的方法。它可用于按引用传递值。Ref 对象有一个名为 value 的实例变量。value 方法返回实例变量 value 的值。以下是 Ref 类定义的一部分：

Ref : AbstractFunction
{
    var <>value;

    *new { arg thing; ^super.new.value_(thing) }
    set { arg thing; value = thing }
    get { ^value }
    dereference { ^value }
    asRef { ^this }

    // 像流一样运作
    next { ^value }

    printOn { arg stream;
        stream << "`(" << value << ")";
    }
    storeOn { arg stream;
        stream << "`(" <<< value << ")";
    }
}

以下是它的响应方式：

Ref.new(123).postln;
Ref.new(123).value.postln;

Ref 还实现了一个名为 dereference 的消息，这是多态的另一个好例子。正如在 Ref 中所实现的，dereference 只返回 value 实例变量，这与 value 方法所做的没有区别。那么为什么需要它呢？这可以通过其他类如何响应 dereference 来解释。dereference 消息的意思是“移除任何包含你的 Ref”。在 Object 类中，dereference 返回对象本身，同样就像 value 消息一样。区别在于没有其他类重写此方法。因此对 Function 的 dereference 仍然是 Function。

Object :

this.dereference()

Ref：

this.dereference()

5.value.postln;
{ 5.squared }.value.postln;
Ref.new(123).value.postln;

5.dereference.postln;
{ 5.squared }.dereference.postln;
Ref.new(123).dereference.postln;

Play

多态的另一个例子是 play。许多不同类型的对象都知道如何播放自身。

Function

{ PinkNoise.ar(0.1) }.play;

AppClock

(
var w, r;
w = Window.new("trem", Rect(512, 256, 360, 130));
w.front;
r = Routine({ arg appClockTime;
    ["AppClock has been playing for secs:",appClockTime].postln;
    60.do({ arg i;
        0.05.yield;
        w.bounds = w.bounds.moveBy(10.rand2, 10.rand2);
        w.alpha = cos(i*0.1pi)*0.5+0.5;
    });
    1.yield;
    w.close;
});
AppClock.play(r);
)

SynthDef

(
x = SynthDef("Help-SynthDef", { arg out=0;
    Out.ar(out, PinkNoise.ar(0.1))
}).play;
)

Pattern

Pbind(\degree, Pseq([0, 1, 2, 3],inf)).play;

Conclusion

多态允许你编写不假设对象实现细节的代码，而是请求对象“做我想做的事”，并由对象做出适当的响应。
