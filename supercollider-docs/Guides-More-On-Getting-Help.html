下面列出了一些用于查找文档和功能的技巧。注意：如果下面使用的一些术语（例如类、方法、继承等）对你来说不清楚，你可能需要阅读术语表和浏览：语言帮助文件以了解其中一些概念的详细信息。在某个时候阅读一篇关于面向对象编程的通用教程也可能有用，阅读关于 Smalltalk 的 FAQ 等也可能有用。Smalltalk 是 SuperCollider 语言设计所基于的通用面向对象编程语言。它的语法与 SC 不同，但在概念上它有很多共同之处。

注意：请务必查看本页底部的 Further Info 部分。

Basics

正如你可能已经了解到的，选中任意文本并按 Cmd-d 会打开相应的帮助文件。通常帮助文件要么与概念相关，要么记录特定的类。在 SC 语言中，类名以大写字母开头。试着对下面的内容按 Cmd-d（双击第一个单词；两个斜杠之后的内容是注释）：

Class // 这是一个类

方法以小写字母开头，语言中的许多其他内容也是如此。

play // 在此处按 Cmd-d 将打开一个帮助文件，详细说明此方法的不同实现

此外，还有许多帮助文件解释了重要的概念。请参阅类别浏览器和搜索页面。

许多文档包含指向其他帮助文件的超文本链接。单击链接可打开相应的帮助文件。

注意，许多有用的方法会将信息打印到“post window”。除非你显式地更改过它（参见 Window 菜单），否则这就是你启动时打开的窗口。按 Cmd-\ 会将当前的 post window 带到前面。

追踪信息

执行以下内容

HelpBrowser.openBrowsePage;

将打开一个"帮助浏览器"页面，其中按主题分类列出所有帮助文件。（等同于按下 Shift-Cmd-D）

Browse: Undocumented classes 列出了所有没有帮助文件的类。这是开始查找可能已经实现的功能的好地方。即使某个类没有编写帮助文件，它也会有一个自动生成的存根，列出方法及其参数，以及一个用于编写真正帮助文件的帮助模板。

查看类定义（选择任意类并按 Cmd-j 打开其类定义文件）可以帮助你弄清楚未记录的方法的作用。

Array // 在此处尝试 Cmd-j

由于许多方法使用了其他类，你可能需要在其他类定义或帮助文件中继续查找。

对任何类执行 dumpInterface 方法将列出其类方法和实例方法及其参数（如果有）。

Array.dumpInterface; // 查看 post 窗口（启动 SC 时打开的那个窗口）

请注意，由于 SuperCollider 语言是面向对象的，许多类会从类层次结构中更靠上的位置继承方法。（Collection 的众多子类就是一个很好的例子。更多细节请参阅 Collections 概述。）记录一个类所响应的每一个继承方法既不可行也冗余，因此能够追踪文档和方法定义非常重要。

对任意类调用 dumpFullInterface 方法，会列出该类所响应的所有类方法和实例方法，并按实现这些方法的类进行排序。其中会包含继承来的方法。在子类中被重写的方法会列在该子类之下。

Array.dumpFullInterface;

这可能包含大量信息，因此 dumpAllMethods 或 class.dumpAllMethods 将分别只显示实例方法和类方法。

Array.class.dumpAllMethods; // 仅包含此对象响应的类方法（包括继承的方法）
Array.dumpAllMethods;         // 仅实例方法（包括继承的方法）

还有一个图形化的类浏览器，可以显示所有方法、参数、子类、实例变量和类变量。使用浏览器的按钮，你可以轻松导航到类的父类、子类、类源代码、方法源代码、帮助文件（如果有的话），查看引用或方法的实现。

SequenceableCollection.browse;

选择任意方法并按下 Cmd-y，将打开一个窗口，其中列出实现该方法的所有类。（关于为何不同的类可能实现同名方法，详见 Polymorphism 帮助文件。）

select // 在这个方法上试试

类似地，选中任意文本并键入 shift-cmd-y 将打开一个窗口，显示所选文本的所有引用，即它在类库中出现的每一处。（这不会找到以特殊字节码编译的方法调用，如 'value'。）

// 在这些上尝试
asStream
Window

在生成的窗口中，选择任意类和方法并按 Cmd-j 将带你到该类定义中对应的方法定义处。例如，尝试在上一示例生成的窗口中选择 Pattern-select。注意 SC 支持在单独的文件中定义方法，因此一个类的方法可能定义在不止一处。如果你对下面的内容尝试 Cmd-j，你会看到它将打开一个名为 dumpFullInterface.sc 的文件，而不是名为 Class.sc 的文件（它的主类定义文件）。+ Class {.... 语法表示这些是额外的方法。

Class-dumpFullInterface

如果你知道某个类响应某条特定消息，可以使用 findRespondingMethod 找出它从哪个类继承了相应的方法。

Array.findRespondingMethodFor('select'); // 你可以在 post 窗口中对结果按 Cmd-j

同样地，helpFileForMethod 将打开响应方法所定义在的类的帮助文件（如果该帮助文件存在）。请注意，这并不保证该方法在其中有文档记录。如上所述，一些文档并不完整，并且某些方法是“私有”的或不打算供一般使用的。

Array.helpFileForMethod('select'); // 这将打开 Collection 帮助文件；向下滚动到 select

一般来说，到处查看是了解事物工作原理的好方法。有关如何查看“底层”的更多高级信息，请参阅 Internal Snooping (Introspection)。
