HIDdef

HID 响应参考定义

HIDFunc : AbstractResponderFunc : Object

另请参见：HID，HIDFunc，OSCdef，MIDIdef，Working with HID

说明

HIDdef 为其父类 HIDFunc 的功能提供一个全局引用。本质上，它将自身存储在一个全局字典中的某个键下，从而允许随时替换。大多数方法继承自其父类。

类方法

HIDdef.all

获取所有 HIDdef 的全局字典。

返回值：

一个 IdentityDictionary

HIDdef.freeAll

清除并停用全局集合中的所有 HIDdef。

HIDdef.new(key, func)

访问现有的 HIDdef。这是访问由以下方法之一创建的 HIDdef 的快捷方式，并允许更改其函数或对其调用 free。

参数：

key

在全局集合中存储此 HIDdef 所用的键。通常这是一个 Symbol。

func

一个 Function 或类似对象，它将响应传入的消息。它将接收……

HIDdef.usage(key, func, elUsageName, devUsageName, deviceInfo, argTemplate, argTemplateType, dispatcher)

创建一个新的、已启用的 HIDdef。如果此键处已存在 HIDdef，其参数将被所提供的参数替换（传入 nil 的参数将使用旧值）。

一个便捷方法，用于根据控件的 usage 名称来过滤传入的 HID 值。例如，摇杆 X 轴的名称或鼠标水平移动的名称是 \X。这些 usage 名称由制造商标准化，并根据来自设备的信息在 usage 表中查找。如果你有一个已打开的 HID 设备，可以用以下方式查找可用的 usages：~hid.postUsages。

参数：

key

在全局集合中存储此 HIDdef 所用的键。通常这是一个 Symbol。

func

一个 Function 或类似对象，它将响应传入的消息。它将接收……

elUsageName

要查找的用法名称。可以是一个用法名称，也可以是用法名称的数组。

devUsageName

要查找的设备用途名称，例如 \GamePad 或 \Mouse。如果留空，HIDdef 将匹配任何设备。

deviceInfo

一个 IdentityDictionary，对设备进行更详细的过滤。

argTemplate

这应该是一个实现了 matchItem 方法的对象。根据 argTemplateType，它将被传入待匹配元素的值的 rawValue。

argTemplateType

如果 argTemplateType 为 \rawValue（默认值），则匹配基于元素的输入原始值进行（不按照逻辑最小值与最大值进行映射）。否则，匹配按照映射后的值进行。

dispatcher

一个可选的、AbstractDispatcher 的适当子类实例。它可用于实现自定义分派。通常不需要此项。此类 HIDdef 的默认值为 HIDUsageDispatcher

返回值：

HIDdef 的新实例，它响应特定的元素用法和设备类型。

HIDdef.device(key, func, elUsageName, deviceName, deviceInfo, argTemplate, argTemplateType, dispatcher)

创建一个新的、已启用的 HIDdef。如果此键处已存在 HIDdef，其参数将被所提供的参数替换（传入 nil 的参数将使用旧值）。

一个便捷方法，根据设备名称过滤传入的 HID 值。这种 HIDdef 与 HIDdef.usage 的不同之处在于，它具体按设备名称过滤，而不是按设备用途过滤，其余参数相同。

参数：

key

在全局集合中存储此 HIDdef 所用的键。通常这是一个 Symbol。

func

一个 Function 或类似对象，它将响应传入的消息。它将接收……

elUsageName

要查找的用法名称。可以是一个用法名称，也可以是用法名称的数组。

deviceName

要查找的设备名称，注意这必须与设备返回的字符串完全匹配。你可以在设备列表中查找此字符串：HID.postAvailable

deviceInfo

一个 IdentityDictionary，对设备进行更详细的过滤。

argTemplate

这应该是一个实现了 matchItem 方法的对象。根据 argTemplateType，它将被传入待匹配元素的值的 rawValue。

argTemplateType

如果 argTemplateType 为 \rawValue（默认值），则匹配基于元素的输入原始值进行（不按照逻辑最小值与最大值进行映射）。否则，匹配按照映射后的值进行。

dispatcher

一个可选的、AbstractDispatcher 相应子类的实例。可用于实现自定义的分发。通常不需要这样做。此类 HIDdef 的默认值为 HIDDeviceDispatcher

返回值：

HIDdef 的新实例，它响应特定设备的特定元素用法。

HIDdef.usageID(key, func, elUsageID, elPageID, deviceName, deviceInfo, argTemplate, argTemplateType, dispatcher)

创建一个新的、已启用的 HIDdef。如果此键处已存在 HIDdef，其参数将被所提供的参数替换（传入 nil 的参数将使用旧值）。

一个便捷方法，用于根据传入的 HID 值的控制用法编号来筛选该值。如果设备使用的是非标准用法编号，则可以使用此方法来查找它。控制的用法由其用法 ID 和用法页的组合完全确定。

参数：

key

在全局集合中存储此 HIDdef 所用的键。通常这是一个 Symbol。

func

一个 Function 或类似对象，它将响应传入的消息。它将被传入……用法

elUsageID

要查找的用法的 id（一个 Integer）。可以是一个用法 id，也可以是用法 id 的数组。

elPageID

要查找的用法页面的 id（一个 Integer）。可以是一个页面 id，也可以是页面 id 的数组。

deviceName

由于这种类型的 HIDdef 面向非标准化控件，因此可以按特定设备名称进行筛选，而不是按一般用途筛选，类似于 HIDdef.device

deviceInfo

一个 IdentityDictionary，对设备进行更详细的过滤。

argTemplate

这应该是一个实现了 matchItem 方法的对象。根据 argTemplateType，它将被传入待匹配元素的值的 rawValue。

argTemplateType

如果 argTemplateType 为 \rawValue（默认值），则匹配基于元素的输入原始值进行（不按照逻辑最小值与最大值进行映射）。否则，匹配按照映射后的值进行。

dispatcher

一个可选的、AbstractDispatcher 相应子类的实例。这可用于允许自定义分发。通常不需要这样做。此类 HIDdef 的默认值为 HIDElementProtoDispatcher

返回值：

HIDdef 的一个新实例，它响应特定设备的特定元素使用 id。

HIDdef.proto(key, func, protoElement, deviceInfo, argTemplate, argTemplateType, dispatcher)

创建一个新的、已启用的 HIDdef。如果此键处已存在 HIDdef，其参数将被所提供的参数替换（传入 nil 的参数将使用旧值）。

一种便捷方法，用于根据元素（HIDElementProto）的匹配模板来过滤传入的 HID 值。如果你有多个应匹配的元素条件，那么可以使用此方法来查找它。

参数：

key

在全局集合中存储此 HIDdef 所用的键。通常这是一个 Symbol。

func

一个 Function 或类似对象，它将响应传入的消息。它将被传入……用法

protoElement

要查找的用法的 id（一个 Integer）。可以是一个用法 id，也可以是用法 id 的数组。

deviceInfo

一个 IdentityDictionary，对设备进行更详细的过滤。

argTemplate

这应该是一个实现了 matchItem 方法的对象。根据 argTemplateType，它将被传入待匹配元素的值的 rawValue。

argTemplateType

如果 argTemplateType 为 \rawValue（默认值），则匹配基于元素的输入原始值进行（不按照逻辑最小值与最大值进行映射）。否则，匹配按照映射后的值进行。

dispatcher

一个可选的、AbstractDispatcher 相应子类的实例。这可用于允许自定义分发。通常不需要这样做。此类 HIDdef 的默认值为 HIDElementProtoDispatcher

返回值：

HIDdef 的一个新实例，它响应特定的原型元素。

HIDdef.element(key, func, elID, deviceName, deviceInfo, argTemplate, argTemplateType, dispatcher)

创建一个新的、已启用的 HIDdef。如果此键处已存在 HIDdef，其参数将被所提供的参数替换（传入 nil 的参数将使用旧值）。

一个便利方法，用于根据传入 HID 值元素的索引来过滤该值。如果设备使用的是非标准配置，或者你想直接访问键盘元素，则可以使用此方法查找它。请注意，元素索引在不同操作系统上不一定相同（即它可能在 Linux、macOS 和 Windows 之间有所不同）。

参数：

key

在全局集合中存储此 HIDdef 所用的键。通常这是一个 Symbol。

func

一个 Function 或类似对象，它将响应传入的消息。它将接收……

elID

要查找的元素的 id（一个 Integer）。这可以是一个元素 id，也可以是一个元素 id 的数组。

deviceName

由于这种类型的 HIDdef 面向非标准化元素，因此可以按特定设备名称进行筛选，而不是按一般用途筛选，类似于 HIDdef.device

deviceInfo

一个 IdentityDictionary，对设备进行更详细的过滤。

argTemplate

这应该是一个实现了 matchItem 方法的对象。根据 argTemplateType，它将被传入待匹配元素的值的 rawValue。

argTemplateType

如果 argTemplateType 为 \rawValue（默认值），则匹配基于元素的输入原始值进行（不按照逻辑最小值与最大值进行映射）。否则，匹配按照映射后的值进行。

dispatcher

AbstractDispatcher 的合适子类的一个可选实例。可用于实现自定义分派。通常不需要这样做。这种 HIDdef 的默认值是 HIDElementDispatcher

返回值：

HIDdef 的新实例，它响应特定设备的特定元素 id。

实例方法

.key

获取此 HIDdef 的 key。

返回值：

通常是一个 Symbol。

.free

从全局集合中清除此 HIDdef 并将其停用。

示例

对于下面这里的全部示例，你需要先初始化一个 HID 设备（另见 Working with HID）。下面的示例应可与标准 USB 鼠标配合使用。

HID.findAvailable; // 检查连接了哪些设备
HID.postAvailable; // 列出可用设备
~myhid = HID.open(1103, 53251); // 为你要打开的设备调整这一行！

基于用途过滤

// 过滤来自鼠标 x 轴的所有事件
HIDdef.usage(\example, { |...args| args.postln }, \X, \Mouse);

// 过滤来自鼠标的所有事件
HIDdef.usage(\example, { |...args| args.postln }, nil, \Mouse);

// 过滤来自 X 轴的所有事件（可能来自鼠标、操纵杆或游戏手柄）
HIDdef.usage(\example, { |...args| args.postln }, \X);

// 过滤所有来自 X 轴或 Y 轴的事件（可能来自鼠标、摇杆或游戏手柄）
HIDdef.usage(\example, { |...args| args.postln }, [\X, \Y]);

// argTemplate 的用法：匹配 rawValue（这是默认行为）

// 仅在值低于零时响应：
HIDdef.usage(\example, { |...args| args.postln }, [\X, \Y], argTemplate: { |val| val < 0 });

// 仅在 rawvalue == -1 时匹配
HIDdef.usage(\example, { |...args| args.postln }, [\X, \Y], argTemplate: -1);

// 仅当 rawvalue 为 [-3, -2, -1] 之一时匹配
HIDdef.usage(\example, { |...args| args.postln }, [\X, \Y], argTemplate: [-3, -2, -1]);

// argTemplate 的用法：当缩放后的值小于 0.5 时进行匹配
HIDdef.usage(\example, { |...args| args.postln }, [\X, \Y], argTemplate: { |val| val < 0.5 }, argTemplateType: \value);

// 使用 deviceInfo 而不是 deviceUsage（你可以添加更多设备规格来匹配）
HIDdef.usage(\example, { |...args| args.postln }, \X, deviceInfo: (usageName: \Mouse));

HIDdef.usage(\example, { |...args| args.postln }, nil, deviceInfo: (usageName: \Mouse));

HIDdef(\example).free;

基于 usage ID 过滤

// 按用途页 1 上的用途 ID 48 过滤
HIDdef.usageID(\example2, { |...args| args.postln }, 48, 1);

// 在 usage 页面 1 上按 usage ID 48 或 49 过滤
HIDdef.usageID(\example2, { |...args| args.postln }, [48, 49], 1);

// 按 usage 页 1 上的任意 usage ID 过滤
HIDdef.usageID(\example2, { |...args| args.postln }, nil, 1);

// 按用法页 1 上的用法 ID 48 过滤，设备的名称是空字符串（在那里填入你的鼠标名称）。
HIDdef.usageID(\example2, { |...args| args.postln }, 48, 1, "");

// 按用法页 1 上的用法 ID 48 过滤，设备的路径为 "/dev/hidraw2"（请根据要匹配的设备调整此路径）
HIDdef.usageID(\example2, { |...args| args.postln }, 48, 1, deviceInfo: (path: "/dev/hidraw2")  );

HIDdef(\example2).free;

基于设备过滤

// 筛选名称为 "" 的设备，以及 usage 为 \X 的元素。
HIDdef.device(\example3, { |...args| args.postln }, \X, "");
HIDdef(\example3).free;

基于一个原型元素进行过滤

// 创建一个 usageName 为 \X 的原型元素
c = HIDElementProto.new.usageName_(\X);
HIDdef.proto(\example4, { |...args| args.postln }, c);
HIDdef(\example4).free;

基于元素 ID 进行过滤

// 筛选元素 id 为 6 的元素：
HIDdef.element(\example5, { |...args| args.postln }, 6);
HIDdef(\example5).free;
