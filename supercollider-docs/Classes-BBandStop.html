BBandStop

带阻滤波器

BEQSuite : Filter : PureUGen : UGen : AbstractFunction : Object

另请参阅：SOS、BLowPass、BLowPass4、BHiPass、BHiPass4、BPeakEQ、BLowShelf、BHiShelf、BBandPass、BAllPass

说明

B 均衡套件基于二阶节（SOS）双二阶 UGen。

注意： Biquad 系数计算会带来一定的 CPU 开销。这些插件 UGen 包含优化，使得只有当滤波器参数之一发生变化时才会更新系数。这可能导致 CPU 性能出现尖峰，在使用多个此类单元时应加以考虑。

类方法

BBandStop.ar(in, freq: 1200.0, bw: 1.0, mul: 1.0, add: 0.0)

参数：

in

待处理的输入信号。

freq

中心频率。警告：由于其实现方式的特性，接近 0 的频率值可能导致故障和/或极其响亮的音频伪影！

bw

在 -3 dB 频率之间的带宽（以八度为单位）。

mul

add

未文档化的类方法

BBandStop.sc(dummy, freq: 1200.0, bw: 1.0)

s.boot;

z = {

    SoundIn.ar([0, 1]),
    MouseX.kr(20, 20000, \exponential),

    0.5); // mul
}.play)
z.release;

(
z = {
BBandStop.ar(
    WhiteNoise.ar ! 2,

    0.1); // mul
}.play)
z.release;
