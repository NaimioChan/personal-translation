PingPong

立体声乒乓延迟。

Object

参见：SinOsc

说明

在两个输出之间弹跳声音……就像乒乓球一样。PingPong 实际上是基于 RecordBuf 和 PlayBuf 构建的复合体。

类方法

PingPong.ar(bufnum: 0, inputs, delayTime, feedback: 0.7, rotate: 1)

参数：

bufnum

多通道缓冲区的第一个索引。

inputs

一个音频输入数组，大小与你的缓冲区相同。

delayTime

延迟时间，单位为秒。

feedback

反馈系数。

rotate

它会将 inputArray 旋转一步（左 → 右，右 → 左）。旋转 0（或 2）将导致 inputArray 不发生旋转。你不能通过将其赋值给 SynthDef 中的控制来调制此数字。

实例方法

示例

(
s = Server.local;
s.waitForBoot({

b = Buffer.alloc(s, 44100 * 2, 2);

SynthDef("help-PingPong", { |out = 0, bufnum = 0, feedback = 0.5, delayTime = 0.2|
    var left, right;
    left = Decay2.ar(Impulse.ar(0.7, 0.25), 0.01, 0.25,
        SinOsc.ar(SinOsc.kr(3.7, 0, 200, 500)));
    right = Decay2.ar(Impulse.ar(0.5, 0.25), 0.01, 0.25,
        Resonz.ar(PinkNoise.ar(4), SinOsc.kr(2.7, 0, 1000, 2500), 0.2));

    Out.ar(out,
        PingPong.ar(bufnum, [left, right], delayTime, feedback, 1)
    )
}).play(s, [\out, 0, \bufnum, b.bufnum, \feedback, 0.5, \delayTime, 0.1]);

})
)

b.free;
