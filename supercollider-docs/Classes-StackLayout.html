StackLayout

将视图堆叠在一起的布局

另请参阅：HLayout、VLayout、GridLayout、Layout Management

说明

StackLayout 管理多个堆叠在同一空间中的视图。它有两种模式：它可以切换可见的视图，隐藏其他视图，或者可以保持所有视图可见，切换位于顶层的视图。

第二种模式例如适用于用一个 UserView 覆盖某个视图，然后你可以在其上绘制附加信息。如果你仍希望能用鼠标与下方的视图交互，可以通过 View: -acceptsMouse 让上方的视图忽略鼠标。参见下面的示例。

视图可以在构造时立即添加到布局中，也可以在之后添加或插入。要移除视图，只需调用 View: -remove。

你可以使用 -index 更改当前视图（可见的/位于顶层的视图），而 -count 会告诉你布局管理了多少个视图。

要在两种模式之间切换，请使用 -mode。

注意： 与其他布局不同，StackLayout 不能包含另一个布局，只能包含 View 的子类。

类方法

.new

创建一个 StackLayout，并用作为参数给出的项填充它。第一个视图成为当前视图，即可见并位于其他视图之上。

参数：

... 视图

一系列视图。与其他布局不同，StackLayout 不能包含另一个布局。

讨论：

在下面的示例中，按钮将在三个文本编辑区域之间切换：

(
var stack;
w = Window().layout_(VLayout(
    Button().states_([["One"], ["Two"], ["Three"]]).action_({ |b| stack.index = b.value }),
    stack = StackLayout(
        TextView().string_("This is a chunk of text..."),
        TextView().string_("...and this is another..."),
        TextView().string_("...and another.")
    );
)).front;
)

实例方法

.add

在最后一个索引处添加一个视图。这不会影响当前的 -index。

参数：

view

一个 View。

.insert

在指定索引处插入一个视图。这不会影响当前的 -index。

参数：

view

一个 View。

index

一个整数。若它小于 0 或大于 -count，视图将始终被插入为最后一个。

.count

由该布局管理的视图数量。

.index

设置或获取当前视图的索引。当前视图会被置于其他视图之上，并且如果 -mode 为 0，则所有其他视图都会被隐藏。

.mode

设置或获取当前模式：在模式 0 中，布局仅显示当前视图；在模式 1 中，布局显示所有视图。在两种模式中，当前视图都将置于其他视图之上。

参见：-index。

参数：

value

0 或 1。除了整数之外，也可以使用符号 \stackOne 或 \stackAll。

返回值：

0 或 1。

示例

用 UserView 叠加 TextView 以在其上进行额外绘制，同时仍允许与文本交互：

(
var text, canvas;
text = TextView().string_("Hello world!").keyDownAction_({ canvas.refresh });
canvas = UserView().acceptsMouse_(false).drawFunc_({
    var b = canvas.bounds();
    var str = text.string;
    Pen.translate(b.center.x, b.center.y);
    Pen.fillColor = text.palette.baseText.alpha_(0.1);
    str.do { |c|
        var x = 40.0.rand + 10.0;
        var r = c.asString.bounds.center_(0@0);
        Pen.push;
        Pen.rotate(1.0.rand);
        Pen.translate(rand2(-0.3, 0.3) * b.width, rand2(-0.3, 0.3) * b.width);
        Pen.scale(x, x);
        Pen.stringCenteredIn(c.asString, r);
        Pen.pop;
    }
}).refresh;
w = Window().layout_(StackLayout(canvas, text).mode_(\stackAll)).front;
)
