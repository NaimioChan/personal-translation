Boolean

其实例表示逻辑值的抽象类

Object

参见：控制结构

子类：False、True

说明

Boolean 是 True 和 False 的父类，后两者是具体的实现。在代码中，True 和 False 由字面值 true 和 false 表示。

实例方法

.xor(bool)

返回值：

接收者与另一个 Boolean 的异或。

.and

如果接收者为 true，则返回 function 的求值结果。如果接收者为 false，则不求值 function，该消息返回 false。

.or

若接收者为 false，则返回 function 的求值结果。若接收者为 true，则不对 function 求值，消息返回 true。

&&

返回值：

如果接收者为 true 且 aBoolean 为 true，则为 true。

||

返回值：

如果接收者为 true 或 aBoolean 为 true 则返回 true。

.nand

返回值：

除非两个操作数都为 true，否则为 true（Sheffer 竖线）

.not

返回值：

如果接收者为 false 则为 true，如果接收者为 true 则为 false。

.if

如果接收者为 true，则返回 trueFunc 的求值结果。如果接收者为 false，则返回 falseFunc 的求值结果。

.asInteger

.binaryValue

返回值：

如果接收者为 true 则为 1，如果接收者为 false 则为 0。

.asBoolean

.booleanValue

返回值：

接收者。SimpleNumber 也能理解相同的消息，并可用于将其转换为布尔值。

.keywordWarnings

开启/关闭在未找到关键字参数时的警告
