Scale

表示一个音阶

Object

参见：Tuning

子类：ScaleAD

说明

Scale 支持任意的八度划分和比率，并且（结合 Tuning）能够以多种方式生成音高信息，包括作为 Pattern 的输入。

s.boot;

a = Scale.major;
a.degrees;        // [0, 2, 4, 5, 7, 9, 11]
a.semitones;        // [0, 2, 4, 5, 7, 9, 11]
a.cents;        // [0, 200, 300, 500, 700, 900, 1100]
a.ratios;        // [1, 1.1224620483089, 1.2599210498937, 1.3348398541685, etc.]

Pbind(\scale, a, \degree, Pseq((0..7) ++ (6..0) ++ [\rest], 1), \dur, 0.25).play;

// 使用非标准调音
a.tuning_(\just);
a.degrees;        // 无变化；音级与调律无关
a.semitones;        // [0, 2.0391000173077, 3.1564128700055, 4.9804499913461, etc.]
a.ratios.collect(_.round(0.001));    // [1, 1.125, 1.2, 1.333, 1.5, 1.667, 1.875]

Pbind(\scale, a, \degree, Pseq((0..7) ++ (6..0) ++ [\rest], 1), \dur, 0.25).play;

Creation

*major、*minor、*dorian、*chromatic、*todi、*hijaz、*partch_o1 等。

从存储在实例变量 "all" 中的库创建一个音阶。每个音阶都附带一个合适的默认 Tuning，但可在创建时指定替代调律：

Scale.phrygian(\pythagorean)

如果调音尺寸与音阶的 -pitchesPerOctave 不匹配，将抛出警告，音阶将使用其默认调音。

要获取可用音阶的完整列表，请执行

Scale.directory

类方法

Scale.all

音阶仓库，可向其中添加新音阶。

Scale.all.put(\catastrophic, Scale([0, 0.01, 0.04, 11.2]));
Scale.at(\catastrophic); // 访问音阶

Scale.at(key)

从音阶库访问。

Scale.all.put(\catastrophic, Scale([0, 0.01, 0.04, 11.2]));
Scale.at(\ionian);
Scale.newFromKey(\ionian); // 访问音阶的副本以进行修改

Scale.choose(size: 7, pitchesPerOctave: 12)

从库中创建一个随机音阶，可根据需要受大小和 pitchsPerOctave 约束。

Scale.choose;        // 可以是任何值
Scale.choose(7);    // 在其默认调律下将是一个七音音阶（可以是任何音阶）
Scale.choose(7, 12);    // 将是一个十二音调律（通常是 ET!2）中的七音音阶

// 随机十二音调律中的随机七音音阶
a = Scale.choose(7, 12).tuning_(Tuning.choose(12));
a.tuning.name;

Scale.new(degrees: 'ionian', pitchesPerOctave, tuning, name: "Unknown Scale")

从零创建一个 Scale。degrees 应当是一个 Integer 数组或音阶名称。如果 pitchesPerOctave 为 nil，将根据 degrees 推测最合适的数值。tuning 可以是一个 Tuning 的实例或一个符号；如果为 nil，将使用 pitchesPerOctave 的等音律。如果 Scale 在下降时应与上升时演奏不同，请指定 descDegrees；否则它应为 nil。

Scale.new(#[0, 1, 3, 6, 8, 10, 11], name: "My ET12");        // 将处于 ET12 中
Scale.new(#[0, 3, 7, 10, 15, 19, 22], name: "My Quarter-Tone");    // 将处于 ET24 中
Scale.new(#[0, 6, 17, 21, 30, 39], 43, \partch, "My Partch");

Scale.chromatic(tuning: 'et12')

返回特定调律的半音音阶。

实例方法

.tuning

.tuning = inTuning

设置或获取 Scale 的音律。

参数：

inTuning

可以是 Tuning 的实例，或与库调律匹配的符号。

.semitones

返回一个已调音的半音值数组。-as(Array) 等价；-as(List) 将其作为列表返回，等等。

.cents

返回一个经过调律的音分数组。

.ratios

返回一个调律后的比率数组。

.as(class)

转换。例如 as(Array)、as(List) 和 as(LocalBuf)，这对服务器端工作很有用。

(
r = {
    var scale = Scale.choose.postln;
    SinOsc.ar(
        (
            DegreeToKey.kr(
                scale.as(LocalBuf),
                MouseX.kr(0, 15), // 鼠标索引到音阶
                scale.stepsPerOctave,
                1, // mul = 1
                60 // 偏移 72 个音符
            )
            + LFNoise1.kr([3, 3], 0.04) // 添加一些低频立体声失谐
        ).midicps, // 将 MIDI 音符转换为赫兹
        0,
        0.25
    )
}.play;
)

r.free;

.size

返回音阶的长度。

Scale.ionian.size; // 7
Scale.minorPentatonic.size; // 5
Scale.ajam.size; // 7
Scale.partch_o1.size; // 6

.pitchesPerOctave

返回调音所取自的音级集合的大小。

Scale.ionian.pitchesPerOctave; // 12
Scale.minorPentatonic.pitchesPerOctave; // 12
Scale.ajam.pitchesPerOctave; // 24——这是一个四分音音阶
Scale.partch_o1.pitchesPerOctave; // 43

.stepsPerOctave

通常为 12，但如果当前调律具有拉伸或压缩的八度，则可能不同。degreeToKey 需要此值。

Scale.new((0..14), 15, tuning: \wcAlpha).stepsPerOctave;    // ~ 11.7
Scale.new(#[0, 3, 6, 9, 12], 13, tuning: \bp).stepsPerOctave;    // ~ 19.02

但请注意：

Scale.ajam.stepsPerOctave;    // 12 -- 四分之一音音阶具有正常的八度

.at(index)

.wrapAt(index)

这些访问由 semitones 生成的数组。

a = Scale.major;
a.wrapAt(4);    // 7
a.wrapAt(5);    // 9
a.wrapAt(6);    // 11
a.wrapAt(7);    // 0

.degreeToFreq(degree, rootFreq, octave)

返回基于当前调音和 rootFreq 参数的频率。

Scale.major.degreeToFreq(2, 60.midicps, 1);        // 659.25511...
Scale.major(\just).degreeToFreq(2, 60.midicps, 1);    // 654.06391...

.degreeToRatio(degree, octave: 0)

基于当前调律返回一个比率。

Scale.major.degreeToRatio(2, 1).round(0.001);        // 2.52
Scale.major(\just).degreeToRatio(2, 1).round(0.001);    // 2.5

示例

(
s.waitForBoot({
    a = Scale.ionian;

    p = Pbind(
        \degree, Pseq([0, 1, 2, 3, 4, 5, 6, 7, 6, 5, 4, 3, 2, 1, 0, \rest], inf),
        \scale, Pfunc({ a }, inf),
        \dur, 0.25
    );

    q = p.play;
})
)

// 改变音阶
a = Scale.phrygian;

// 更改调律
a.tuning_(\just);

// 也可以在创建时设置调律
a = Scale.ionian(\pythagorean);

// 如果你使用的调律每八度音高数错误，
// 你会收到警告，并且音阶将恢复为默认调律
a.tuning_(\partch);

// 随机音阶
(
a = Scale.choose(7, 12);
[a.name, a.tuning.name].postln;
)

(
// 或者创建你自己的任意音阶和调律
a = Scale.new(
    #[0, 2, 4, 5, 7, 9, 10],
    12,
    Tuning.new([0, 0.8, 2.1, 3, 4.05, 5.2, 6, 6.75, 8.3, 9, 10.08, 11.5]),
    "Custom"
);
)

// 调音有其自己的类
t = Tuning.werckmeister;

a = Scale.lydian(t);

q.stop;

// 获取信息
a.name;
a.degrees;
a.semitones;
a.ratios;

a.tuning.name;
a.tuning.semitones;
a.tuning.ratios;
// 对于上行/下行音阶，请使用 Pavaroh
(
Pbind(\note, Pavaroh(
    Pseq([0, 1, 2, 3, 4, 5, 6, 7, 6, 5, 4, 3, 2, 1, 0, \rest], 2),
        Scale.melodicMinor,
        Scale.melodicMinorDesc
    ),
    \dur, 0.25
).play;
)
// 注意根音高并不存储在 Scale 中（正因如此，它严格来说应该叫 Mode）
// 而是在播放时提供：

// A 的调
Pbind(
    \degree, Pseq((0..7), inf), // 你的旋律在此处
    \scale, Scale.major, // 你的音阶放在这里
    \root, -3 // 相对于 60.midicps 的半音数，所以这是 A
).play;
