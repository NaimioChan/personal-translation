Pfindur

限制嵌入在流中的事件的总持续时间

FilterPattern : Pattern : AbstractFunction : Object

另请参见：Pfinval、Pfin、Pconst

类方法

Pfindur.new(dur, pattern, tolerance: 0.001)

将 pattern 的元素嵌入到流中，直到持续时间足够接近 dur。

参数：

dur

以拍为单位的持续时间，超过该时间后流应结束，由事件键 dur 或 delta 推导得出。最后一个事件的 delta 会被调整，使总持续时间符合该值。如果流短于 dur，可以使用 filler（见下文）来填补空缺。

pattern

要截短的模式。这应该是一个事件模式（返回事件流）。

tolerance

测量总时长的容差，以避免抖动

        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain, 0.2), doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env))
    }).add;
)

(
var c;
c = Pbind(
    \dur, Prand([1, 0.02, 0.2], inf),
    \instrument, \help_sinegrain,
    \degree, Pseries(0, 1, inf),
    \octave, 6
);

Pn(
    Pfindur(1, c)
).play;
)
