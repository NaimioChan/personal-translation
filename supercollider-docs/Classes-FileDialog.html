FileDialog

用于打开文件、保存文件、选择目录对话框的操作系统接口

另请参阅：Dialog、File

说明

这是用于标准操作系统模态文件对话框的接口，用于打开文件、保存文件和选择目录。

Dialog 具有构建在 FileDialog 之上的函数，可能更便于使用。但是，只有 FileDialog 才能选择目录。

类方法

.new

创建并显示对话框。

参数：

okFunc

当用户点击 "Open" 或 "Save" 时求值的处理函数。该函数接收的参数根据 stripResult 的值而不同。默认情况下（stripResult: false），okFunc 会接收到一个包含所选路径的数组。否则，路径将作为单独的参数传入，每条路径一个参数。

cancelFunc

用户点击“Cancel”时求值的处理函数。不接收参数。

fileMode

确定对话框类型的整数。

这些值直接对应 Qt 类中 QFileDialog::FileMode 的值。

  • 0 文件名，无论其是否存在。
  • 1 单个现有文件的名称。
  • 2 目录的名称。文件和目录都会显示。
  • 3 零个或多个现有文件的名称。

0 或 3 表示用户可以输入新的文件名。

acceptMode

一个整数，决定该对话框用于打开文件还是保存文件。注意，这实际上并不会打开或保存文件；你需要自行在 okFunc 中完成这些操作。它只影响对话框的外观。

这些值直接对应于 Qt 类中 QFileDialog::AcceptMode 的值。

  • 0 开始
  • 1 Saving

stripResult

一个布尔值。如果为 true，选中的路径会作为参数逐个传递给 okFunc。否则，它们会作为一个数组在单个参数中传递（默认值）。

  • false：okFunc(paths)
  • true: okFunc(path1, path2, path3)

path

一个字符串。对话框将初始显示此路径的内容。默认值为当前用户的主目录。

返回值：

一个 FileDialog

实例方法

示例

// 默认情况下，选中的路径会作为数组传递给 okFunc。
(
FileDialog({ |paths|
    postln("Selected path:" + paths[0]);
    }, {
    postln("Dialog was cancelled. Try again.");
    });
)

// 你可以通过传入 `stripResult: true` 来改变这一点
(
FileDialog({ |path|
    postln("Selected path:" + path);
    }, {
    postln("Dialog was cancelled. Try again.");
    }, stripResult: true);
)

// 传入 `fileMode: 3` 可以选择多个文件。
(
FileDialog({ |paths|
    postln("Selected paths:");
    paths.do(_.postln);
    }, fileMode: 3);
)

// 传入 `fileMode: 0` 可以选择任意类型的文件。
// 你可以通过传入 `path: "/some/path/"` 将对话框的起始目录设置为非主目录
(
FileDialog({ |path|
    postln("Selected file:" + path);
    postln("File type is:" + File.type(path)) },
    fileMode: 0,
    stripResult: true,
    path: Platform.userAppSupportDir);
)
