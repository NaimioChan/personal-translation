Slope

信号斜率

Filter : PureUGen : UGen : AbstractFunction : Object

说明

测量信号每秒的变化率。实现的公式为：

out[i] = (in[i] - in[i-1]) * sampling_rate

类方法

Slope.ar(in: 0.0, mul: 1.0, add: 0.0)

Slope.kr(in: 0.0, mul: 1.0, add: 0.0)

参数：

in

要测量的输入信号。

mul

add

实例方法

示例

(
{
    var a, b, c, scale;
    a = LFNoise2.ar(2000);  // 二次噪声
    b = Slope.ar(a);        // 一阶导数产生线段
    c = Slope.ar(b);        // 二阶导数产生恒定段
    scale = 0.0002; // 需要缩放回 +/- 1.0
    [a, b * scale, c * scale.squared]
}.plot
)

关于 Slope 的另一个示例，请参见 AbstractFunction: -hypot。
