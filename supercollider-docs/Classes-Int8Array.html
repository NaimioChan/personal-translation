Int8Array

一个索引槽位均为同一类型的数组

RawArray : ArrayedCollection : SequenceableCollection : Collection : Object

参见：FloatArray、Int16Array、Int32Array、DoubleArray、SymbolArray

说明

这些类实现的数组，其索引槽位均为同一类型。

  • Int8Array - 8 位整数
  • Int16Array - 16 位整数
  • Int32Array - 32 位整数
  • FloatArray - 32 位浮点数
  • DoubleArray - 64 位浮点数
  • SymbolArray - 符号

注意： Int8Array 中元素的溢出行为未定义。当操作结果超出返回类型（在本例中为 8 位有符号整数）所支持的值范围时，就会发生这种情况。

.parseOSC

尝试将字节解释为 OSC 消息或 OSC 包。失败时抛出异常。另请参见 Array: -asRawOSC。

// OSC 消息：
Int8Array[ 47, 115, 95, 110, 101, 119, 0, 0, 44, 115, 105, 105, 105, 115, 105, 0, 100, 101, 102, 97, 117, 108, 116, 0, -1, -1, -1, -1, 0, 0, 0, 1, 0, 0, 0, 1, 102, 114, 101, 113, 0, 0, 0, 0, 0, 0, 7, -87 ].parseOSC;
// OSC bundle：
Int8Array[ 35, 98, 117, 110, 100, 108, 101, 0, 0, 0, 0, 0, 25, -103, -103, -103, 0, 0, 0, 48, 47, 115, 95, 110, 101, 119, 0, 0, 44, 115, 105, 105, 105, 115, 105, 0, 100, 101, 102, 97, 117, 108, 116, 0, -1, -1, -1, -1, 0, 0, 0, 1, 0, 0, 0, 1, 102, 114, 101, 113, 0, 0, 0, 0, 0, 0, 7, -87 ].parseOSC;
// 不是 OSC 消息或 bundle：
Int8Array[ 98, 111, 103, 117, 115 ].parseOSC;
