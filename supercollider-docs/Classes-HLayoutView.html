HLayoutView

水平排列其子视图的容器视图

参见：VLayoutView， CompositeView

说明

注意： 在 Qt GUI 中，此类已被一组专门的布局类取代，因此已过时；这些布局类更易于使用且更灵活。有关此类的等价物，请参见 HLayout；有关 Qt 布局系统的总体说明，请参见 Layout Management。

HLayoutView 可以作为其他视图的父视图，它会自动将子视图按水平顺序排列，并将它们的高度扩展到自身的边界。只有子视图的宽度是相关的。

在排列子视图时，HLayoutView 会考虑子视图的 'minWidth' 和 'maxWidth' 属性值。当子视图的 resize 模式设置为 2、5 或 8 时，这很有用。参见下面的示例。

HLayoutView 从其父类继承了一些有用的格式化方法。

注意： HLayoutView 主要用于对控件进行分组和放置。虽然可以将其设置为接受按键，但它不接受鼠标点击或拖动。

示例

子视图高度自动填充 HLayoutView：

(
q = 10;
w = Window.new;

h = HLayoutView(w, Rect(0, 0, 300, 300));

Array.fill(q, { |i|
    Slider(h, Rect(0, 0, 20, 75)).value_(i / q)
});
h.background_(Color.rand);

w.front
)

拉伸布局视图；Slider 高度自动填充 View：

(
q = 8;
w = Window.new;

h = HLayoutView(w, Rect(0, 0, 300, 300));
h.background = Color.rand;
h.resize = 5; // 弹性

Array.fill(q, { |i|
    var s;
    s = Slider(h, Rect(0, 0, 20, 75)).background_(Color.grey.alpha_(0.4));
    s.value = i / q;
    s
});
StaticText(h, Rect(0, 0, 105, 20)).background_(Color.rand).string_(" Some Example\n Text");
w.front
)

拉伸布局视图及其内容；如果所有内容都是弹性的，则内容的宽度会被完美均分。在此示例中，StaticText 不是弹性的，以保持其宽度：

(

)

在 contents 上设置 minWidth；请注意，如果布局视图的宽度小于所有 contents 的组合宽度，当你尝试用鼠标操作它们时，它们可能会消失：

(
q = 5;
w = Window.new;

h = HLayoutView(w, Rect(0, 0, 300, 300));
h.background = Color.rand;
h.resize = 5; // 弹性

Array.fill(q, { |i|
    var s;
    s = Slider(h, Rect(0, 0, 20, 75));
    s.value = i / 5;
    if(i < 2, {
        s.resize = 5; // 一些弹性
        s.setProperty(\minWidth, 20);
    }, {
        s.resize = 1; // 部分非弹性
    });
    s
});
StaticText(h, Rect(0, 0, 105, 20)).background_(Color.rand).string_(" Some Example\n Text");

w.front
)
