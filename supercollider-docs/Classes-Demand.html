Demand

从需求率 UGen 获取需求结果。

MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：Duty、TDuty

说明

当 trig 输入处有触发时，列表中的每个 UGen 都会被要求提供一个值并输出。列表中的单元生成器应为 'demand' 速率。

当 reset 输入处有触发时，列表中的需求率 UGen 会被重置。

类方法

Demand.ar(trig, reset, demandUGens)

Demand.kr(trig, reset, demandUGens)

参数：

trig

触发。可以是任意信号。当信号从非正变为正时，就会发生触发。

reset

触发。被触发时重置 UGen 列表。

demandUGens

要从中获取值的需求率 UGen 列表。当最短的流结束时，此 ugen 将设置 'done' 标志。

讨论：

按照设计，重置触发只会重置需求 UGen；它不会重置 Demand 输出的值。Demand 会继续保持其值，直到需求下一个值，此时其输出值将是列表中预期的第一个项。要在收到重置触发时跳转到起始值，可以将两个触发相加（+）：

(
a = { |t_trig, t_reset|
    var    d = Demand.kr(t_trig + t_reset, t_reset, Dseries(0, 1, inf));
    d.poll(t_trig + t_reset);
    0.0;
}.play
)
a.set(\t_trig, 1); // 执行几次——demand 值每次应增加 1
a.set(\t_reset, 1);    // 立即回到 0

一个 demand ugen 表示单个值流，因此嵌入同一个 ugen 两次会调用该流两次。要隔离一个 demand ugen，请使用函数：

{
var a, b, t = Impulse.kr(2);
a = { Dseq([1, 2, 3, 4, 5], inf) } * 100;
b = a + 1;
Demand.kr(t, 0, [a, b]).poll(t)
}.play

实例方法

示例

// 示例

(
{
    var trig, seq, freq;
    trig = Impulse.kr(24);
    seq = Drand([Dseq((1..5).mirror1, 1), Drand((4..10), 8)], 2000);
    freq = Demand.kr(trig, 0, seq * 100);
    SinOsc.ar(freq + [0, 0.7]).cubed.cubed.scaleneg(MouseX.kr(-1, 1)) * 0.1;
}.play;
)

(
{
    var trig, seq, freq;
    trig = Impulse.kr(12);
    seq = Drand([Dseq((1..5).mirror1, 1), Drand((4..10), 8)], 2000) * Drand([1, 2, 4, 8], 2000);
    freq = Demand.kr(trig, 0, seq * 100);
    SinOsc.ar(freq + [0, 0.7]).cubed.cubed.scaleneg(MouseX.kr(-1, 1)) * 0.1;
}.play;
)

)

{

)

    var freq, trig, reset, seq1, seq2;
