Set

按相等性判断的集合

Collection : Object

另请参阅：IdentitySet、List、Dictionary

子类：Dictionary、IdentitySet

说明

Set 是对象的集合，其中任意两个对象都不相等。它的大部分方法继承自 Collection。Set 的内容是无序的。你不能依赖集合中元素的顺序。若需要有序集合，请参见 OrderedIdentitySet。

实例方法

添加与移除

.add(item)

向 Set 添加一个 Object。与 Set 中已有对象相等的对象将不会被添加。

Set[1, 2, 3].add(4).postln;
Set[1, 2, 3].add(3).postln;
Set["abc", "def", "ghi"].add("jkl").postln;
Set["abc", "def", "ghi"].add("def").postln;

.remove(item)

从 Set 中移除一个 Object。元素按相等性检查（而非同一性）。

Set[1, 2, 3].remove(3).postln;

Testing

.includes(item)

如果指定项在 Set 中存在，则返回 true。元素的比较基于相等性（而非同一性）。

Set[1, 2, 3].includes(2).postln;

.findMatch(item)

如果该项存在于集合中则返回该项。否则返回 nil。元素按相等性（而非同一性）检查。

Set[1, 2, 3].findMatch(3).postln;

Iteration

.do(function)

对 Set 中的每个元素执行函数。向该函数传递两个参数：元素和一个整数索引。

Set[1, 2, 3, 300].do({ |item, i| item.postln });

.keyAt(index)

返回内部 index 处的对象。此索引不确定。

设置特定操作

.sect(that)

&(that)

返回此集合与 that 的集合论交集。该函数会查找同时出现在两个集合中的对象，并返回包含这些对象的新集合。元素按相等性（而非同一性）检查。

a = Set[1, 2, 3]; b = Set[2, 3, 4, 5];
sect(a, b);
a & b // 更短的语法

.union(that)

|(that)

返回此集合与 that 的集合论并集。该函数将两个集合合并为一个，且不含重复项。元素按相等性检查（而非同一性）。

a = Set[1, 2, 3]; b = Set[2, 3, 4, 5];
union(a, b);
a | b // 更短的语法

.difference(that)

-(that)

返回所有是此集合的元素但不是 that 的元素所组成的集合。元素按相等性（而非同一性）检查。

a = Set[1, 2, 3]; b = Set[2, 3, 4, 5];
difference(a, b);
a - b // 更短的语法

.symmetricDifference(that)

--(that)

返回所有不是此集合和 that 共有元素的项所组成的集合。元素按相等性（而非同一性）检查。

a = Set[1, 2, 3]; b = Set[2, 3, 4, 5];
symmetricDifference(a, b);
a -- b // 更短的语法

.isSubsetOf(that)

如果此集合的所有元素也是 that 的元素，则返回 true。元素按相等性检查（而非同一性）。由于 Set 是无序集合，此比较中顺序无关紧要。

a = Set[1, 2, 3, 4];
Set[1, 2].isSubsetOf(a); // true
Set[1, 5].isSubsetOf(a); // false

示例

a = Set[1, 2, 3, 4];
b = a.powerset; // 所有部分的集合
a.isSubsetOf(b); // false：没有任何集合是自身的元素。
b.asArray.reduce(\union) == a; // true 部分可能不包含原始的其它元素
b.asArray.reduce(\difference).isEmpty; // true.
// 你可以使用 Set 高效地从数组中去除重复项：

a = [1, 2, 3, 4, 3, 5, 5, 2, 2, 1];
a.as(Set);        // 转换为集合
a.as(Set).as(Array);    // 并转换回来
