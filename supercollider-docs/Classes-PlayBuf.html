PlayBuf

采样回放振荡器。

MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：RecordBuf、DiskIn、BufRd

说明

播放驻留在内存中的采样。

类方法

PlayBuf.ar(numChannels, bufnum: 0, rate: 1.0, trigger: 1.0, startPos: 0.0, loop: 0.0, doneAction: 0)

PlayBuf.kr(numChannels, bufnum: 0, rate: 1.0, trigger: 1.0, startPos: 0.0, loop: 0.0, doneAction: 0)

参数：

numChannels

缓冲区将具有的声道数。这必须是一个固定整数。SynthDef 的架构在编译后无法更改。

bufnum

要使用的缓冲区索引。

注意： 如果你提供的 bufnum 对应的缓冲区声道数与此 PlayBuf 中指定的声道数不同，它会发布一条警告并输出它所能输出的声道。

rate

1.0 是服务器的采样率，2.0 是升高一个八度，0.5 是降低一个八度，-1.0 是反向的正常速率……等等。插值为三次插值。

trigger

触发会导致跳转到 startPos。当信号从负值变为正值时会发生触发。

startPos

开始播放的采样帧。

loop

1 表示真，0 表示假。这是可调制的。

doneAction

一个整数，表示缓冲区播放完毕时要执行的动作。这可用于释放所在的 Synth 等。详情请参见 Done。doneAction 仅在 loop 为 0 时才进行求值。

实例方法

示例

s.boot // 如有需要，启动服务器

// 将整个声音读入内存

// ExampleFiles 帮助定位示例中使用的音频文件
p = ExampleFiles.child;
// 查看路径以了解位置和路径的格式
p.postln;
// 将文件读入缓冲区
b = Buffer.read(s, p); // 记得稍后释放缓冲区。

SynthDef(\help_PlayBuf, { |out = 0, bufnum = 0|
    Out.ar(out,
        PlayBuf.ar(1, bufnum, BufRateScale.kr(bufnum), doneAction: Done.freeSelf)
    )
}).play(s, [\out, 0, \bufnum, b]);

在上面的示例中，请注意 doneAction: Done.freeSelf 如何使 Synth 在缓冲区到达末尾时自行释放。

再次注意，SynthDef 的通道数必须固定。它不能随所使用的缓冲区而变化。

// loop 为 true
SynthDef(\help_PlayBuf, { |out = 0, bufnum = 0|
    Out.ar(out,
        PlayBuf.ar(1, bufnum, BufRateScale.kr(bufnum), loop: 1.0)
    )
}).play(s, [\out, 0, \bufnum, b]);


// 在每个脉冲上触发一次
SynthDef(\help_PlayBuf, { |out = 0, bufnum = 0|
    var trig;
    trig = Impulse.kr(2.0);
    Out.ar(out,
        PlayBuf.ar(1, bufnum, BufRateScale.kr(bufnum), trig, 0, 0)
    )
}).play(s, [\out, 0, \bufnum, b]);


// 在每个脉冲上触发一次
SynthDef(\help_PlayBuf, { |out = 0, bufnum = 0|
    var trig;
    trig = Impulse.kr(XLine.kr(0.1, 100, 30));
    Out.ar(out,
        PlayBuf.ar(1, bufnum, BufRateScale.kr(bufnum), trig, 5000, 0)
    )
}).play(s, [\out, 0, \bufnum, b]);


// 用鼠标控制触发速率和起始位置
SynthDef(\help_PlayBuf, { |out = 0, bufnum = 0|
    var trig;
    trig = Impulse.kr(MouseY.kr(0.5, 200, 1));
    Out.ar(out,
        PlayBuf.ar(1, bufnum, BufRateScale.kr(bufnum), trig, MouseX.kr(0, BufFrames.kr(bufnum)), 1)
    )
}).play(s, [\out, 0, \bufnum, b]);


// 加速音高
SynthDef(\help_PlayBuf, { |out = 0, bufnum = 0|
    var rate;
    rate = XLine.kr(0.1, 100, 60);
    Out.ar(out,
        PlayBuf.ar(1, bufnum, BufRateScale.kr(bufnum)*rate, 1.0, 0.0, 1.0)
    )
}).play(s, [\out, 0, \bufnum, b]);


// 播放速率的正弦波控制。负速率向后播放
SynthDef(\help_PlayBuf, { |out = 0, bufnum = 0|
    var rate;
    rate = FSinOsc.kr(XLine.kr(0.2, 8, 30), 0, 3, 0.6);
    Out.ar(out,
        PlayBuf.ar(1, bufnum, BufRateScale.kr(bufnum) * rate, 1, 0, 1)
    )
}).play(s, [\out, 0, \bufnum, b]);


// 围绕声音之字形移动
SynthDef(\help_PlayBuf, { |out = 0, bufnum = 0|
    var rate;
    rate = LFNoise2.kr(XLine.kr(1, 20, 60), 2);
    Out.ar(out,
        PlayBuf.ar(1, bufnum, BufRateScale.kr(bufnum) * rate, 1, 0, 1)
    )
}).play(s, [\out, 0, \bufnum, b]);

b.free;
