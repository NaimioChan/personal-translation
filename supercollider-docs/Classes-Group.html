Group

服务器上组节点的客户端表示

AbstractGroup : Node : Object

子类：RootNode

说明

组是服务器上组节点的客户端表示，组节点是组织为链表的其他节点的集合。组内的节点可以一起控制，并且可以同时是 Synth 和其他组。因此，组对于一次性控制多个节点很有用，当用作目标时，对于控制执行顺序非常有帮助。（有关此主题的更多详细信息，请参阅执行顺序）。

有关客户端对象与服务器节点之间关键区别的更多内容，请参见 Client vs Server。有关不使用对象创建节点的信息，请参见 Node Messaging。

注意：Group 是 Node 的子类，因此它许多最有用、最重要的方法都记录在 Node 帮助文件中。更多信息请参阅该文件。

RootNode 和默认组

当服务器启动时，存在一个 ID 为 0 的顶层组，它定义了树的根。这由 Group 的一个子类表示：RootNode。

sclang 有“默认组”的概念，它在服务器启动时被自动创建。此组是所有 Node 的默认外层组，即未指定组时使用的组。通常，应在 Server 的默认组中创建新的 Node，而不是在其 RootNode 中。多客户端设置中，每个客户端可能有不同的默认组。详情参见 Default Group、Server 和 RootNode。

Bundling

下面的部分方法有两个版本：常规版本会立即将对应消息发送到服务器，另一个版本则将消息返回为 Array，以便加入 bundle。也可以利用 Server 的自动打包功能捕获常规方法生成的消息。详情请参阅 Server 和 Bundled Server Messages。

类方法

在服务器上立即实例化创建

Group.new(target, addAction: 'addToHead')

来自父类：AbstractGroup

创建并返回一个组。

参数：

target

此组的 target。如果 target 不是组或 Synth，它将按如下方式转换：如果是服务器，则转换为该服务器的 default_group。如果是 nil，则转换为默认服务器的 default_group。

addAction

以下符号之一：

\addToHead

（默认）添加到由 target 指定的组的头部

\addToTail

添加到由 target 指定的组的尾部

\addAfter

紧接在目标之后按其服务器节点顺序添加

\addBefore

在其服务器的节点顺序中紧挨着目标之前添加

\addReplace

替换目标并占据其在服务器节点顺序中的位置

注意：Synth 不是 \addToHead 和 \addToTail 的有效目标。

\addToHead

（默认）添加到由 target 指定的组的头部

\addToTail

添加到由 target 指定的组的尾部

\addAfter

紧接在目标之后按其服务器节点顺序添加

\addBefore

在其服务器的节点顺序中紧挨着目标之前添加

\addReplace

替换目标并占据其在服务器节点顺序中的位置

讨论：

s.boot;
g = Group.new; // 在默认 Server 的默认 group 头部添加一个 Group
h = Group.new(g, \addAfter);
s.queryAllNodes; // 注意默认组（ID 1）内的 Group
g.free; h.free;

添加操作的便捷方法

以下便捷方法对应于上述添加操作：

Group.after(aNode)

来自父类：AbstractGroup

创建一个 Group 并返回它，将其紧接在 aNode 之后添加。

Group.before(aNode)

来自父类：AbstractGroup

创建一个 Group 并立即将其添加到 aNode 之前。

Group.head(aGroup)

来自父类：AbstractGroup

创建并返回一个 Group。如果 aGroup 是一个 Group，则将其添加到该组的头部。如果它是一个 Server，则将其添加到该服务器的 default_group 的头部。如果它为 nil，则将其添加到默认 Server 的 default_group 的头部。

Group.tail(aGroup)

来自父类：AbstractGroup

创建并返回一个 Group。如果 aGroup 是一个 Group，则将其添加到该组的尾部。如果它是一个 Server，则将其添加到该服务器的 default_group 的尾部。如果它为 nil，则将其添加到默认 Server 的 default_group 的尾部。

Group.replace(nodeToReplace)

来自父类：AbstractGroup

创建一个 Group 并返回它，用它替换 nodeToReplace，在其服务器的节点顺序中占据其位置。

不在服务器上实例化的创建

为了在 message bundle 中使用，也可以在客户端应用中创建一个 Group 对象，而不立即在服务器上创建组节点。完成后，可以调用方法创建要添加到 bundle 的 message，当发送到服务器时，将实例化该组或执行其他操作。（参见下面的 Control。）

Group.basicNew(server, nodeID)

来自父类：Node

创建并返回一个 Group 对象，而不在服务器上创建组节点。（此方法继承自 Node，此处仅为方便而记录。）

参数：

server

可选的 Server 实例。如果为 nil，则默认为默认服务器。

nodeID

可选的节点 ID 编号。如果未提供，服务器会通过其 NodeIDAllocator 生成一个。通常你不需要提供 ID。

讨论：

s.boot;
g = Group.basicNew(s); // 创建但不发送
s.sendBundle(nil, g.newMsg); // 现在发送一条消息；在 s 的默认组头部创建
s.queryAllNodes;
g.free;

创建之后，使用实例方法 newMsg, addToHeadMsg, addToTailMsg, addBeforeMsg, addAfterMsg, addReplaceMsg 在服务器上实例化此 synth。参见下方的实例方法。

实例方法

不在服务器上实例化的创建

使用类方法 basicNew 创建一个 Synth，而不在服务器上实例化它。然后使用以下实例方法：

.newMsg(target, addAction: 'addToHead')

来自父类：AbstractGroup

返回一条可被捆绑的 g_new 类型的消息。当发送到服务器时，此消息将实例化此组。如果 target 为 nil，则默认为创建此 Group 时在 *basicNew 中指定的 Server 的 default_group。默认的 addAction 为 \addToHead。（有关 addAction 的详细信息，参见上文 *new。

.addToHeadMsg(aGroup)

来自父类：AbstractGroup

返回一条类型为 g_new 的消息，该消息可以被捆绑。当发送到服务器时，此消息将实例化此组。如果 aGroup 是一个 Group，它将被添加到该组的头部。如果为 nil，它将被添加到此 Group 所属服务器的 default_group 的头部（如调用 *basicNew 时所指定）。

.addToTailMsg(aGroup)

来自父类：AbstractGroup

返回一条类型为 g_new 的消息，该消息可以被捆绑。当发送到服务器时，此消息将实例化此组。如果 aGroup 是一个 Group，它将被添加到该组的尾部。如果为 nil，它将被添加到此 Group 所属服务器的 default_group 的尾部（如调用 *basicNew 时所指定）。

.addBeforeMsg(aNode)

来自父类：AbstractGroup

返回一个 g_new 类型的消息，可进行捆绑。当发送到服务器时，该消息会紧接在 aNode 之前实例化此组。

.addAfterMsg(aNode)

来自父类：AbstractGroup

返回一条类型为 g_new 的消息，该消息可以打包。当发送到服务器时，此消息将在此组紧接着 aNode 之后实例化。

.addReplaceMsg(nodeToReplace)

来自父类：AbstractGroup

返回一个类型为 g_new 的消息，该消息可以被捆绑发送。当发送到服务器时，此消息将实例化该组，在服务器的节点顺序中替换 nodeToReplace。

控制与内省

关于控制 Group 的更多方法（set、map 等），参见 Node 帮助文件。

.moveNodeToHead(aNode)

来自父类：AbstractGroup

.moveNodeToHeadMsg(aNode)

来自父类：AbstractGroup

将 aNode 移到该组的头部

.moveNodeToTail(aNode)

来自父类：AbstractGroup

.moveNodeToTailMsg(aNode)

来自父类：AbstractGroup

将 aNode 移到该组的尾部

.freeAll

来自父类：AbstractGroup

.freeAllMsg

来自父类：AbstractGroup

释放此组中的所有节点，但不释放此组本身。

.deepFree

来自父类：AbstractGroup

.deepFreeMsg

来自父类：AbstractGroup

释放该组中的所有 Synth，以及任何包含的组中的所有 Synth，但不释放此组或其任何包含的组。

.dumpTree(postControls: false)

来自父类：AbstractGroup

发布此组节点子树的表示。（发送一条类型为 g_dumpTree 的消息。）如果 postControls 为 true，那么此组中包含的任何 synth 的当前 Control（参数）值也会一并发布。默认值为 false。

.queryTree

来自父类：AbstractGroup

向服务器查询一条描述此组的节点子树的消息。（发送类型为 g_queryTree 的消息。）此回复会作为参数传递给 action 函数。有关回复结构的信息，请参阅 Server Command Reference 中的 g_queryTree 或下面的示例。

示例

s.boot;

(
SynthDef("help-Group-moto-rev", { |out = 0, freq = 100, ffreq = 120|
    var x;
    x = RLPF.ar(LFPulse.ar(SinOsc.kr(0.2, 0, 10, freq), [0, 0.1], 0.1),
        ffreq, 0.1).clip2(0.4);
    Out.ar(out, x);
}).add;


SynthDef("help-Group-wah", { |out, rate = 1.5, cfreq = 1400, mfreq = 1200, rq = 0.1|
    var zin, zout, q;

    zin = In.ar(out, 2);
    cfreq = Lag3.kr(cfreq, 0.1);
    mfreq = Lag3.kr(mfreq, 0.1);
    q   = Ramp.kr(rq, 0.1);
    zout = RLPF.ar(zin, LFNoise1.kr(rate, mfreq, cfreq), q, 10).distort
        * 0.15;

    // 用效果处理后的版本替换传入的 bus
    ReplaceOut.ar(out, zout);

}).add;
)

g = Group.new;

(
l = Array.fill(3, {
    // 每个 synth 的随机频率，添加到 g 的头部
    Synth("help-Group-moto-rev", ["out", 0, "freq", rrand(10, 120)], g, \addToHead);
});
)

// 将 g 中所有节点里匹配 "ffreq" 的所有控件设为 90
g.set("ffreq", 300);

g.set("freq", 80);

// 由于我们将 Synth 存储在 Array 中，我们也可以单独控制它们
(
r = Routine({
    inf.do({
        l.do({ |node|
            node.set("freq", rrand(10, 120));
            1.0.wait;
        });
    })
});

r.play;
)

// g 也位于一个组中。因为我们没有指定，所以它是默认 Server 的默认组（ID 1）
g.group.inspect;

// 让一个 wah 在 g 之后执行，与 g 在同一个组中。
x = Synth.after(g, "help-Group-wah", ["out", 0]);

// 现在转储我的树以确认
g.dumpTree;

x.free;

// 释放 g 中的所有节点，但不包括 g 本身
g.freeAll;

// 别忘了 Routine 仍在运行……
r.stop;

// 哦，把 l 设为 nil，以便 Synths 和 Array 可以被垃圾回收
l = nil;

// 而我仍在服务器上，只是我的子节点被释放了
g.query;

// 这次不需要各个 synth 对象
(
3.do({
    // 每个 synth 的随机频率，添加到 g 的头部
    Synth("help-Group-moto-rev", ["out", 0, "freq", rrand(10, 1200)], g, \addToHead);
});
)

// 现在查询我的树并发布它的图（复制了 dumpTree）
// 消息格式为 ['/g_querytree.reply', node1-ID, numChildren, defName, child1-ID, numChildren, ...]
(
g.queryTree({ |msg|
    var i = 1, tabs = 0, dumpFunc;
    ("NODE TREE Group" + msg[1]).postln;
    if(msg[2] > 0, {
        dumpFunc = { |numChildren|
            tabs = tabs + 1;
            numChildren.do({
                i = i + 3;
                tabs.do({ "   ".post });
                msg[i].post;
                (" " ++ msg[i + 2]).postln;
                if(msg[i + 1] > 0, { dumpFunc.value(msg[i + 1]) });
            });
            tabs = tabs - 1;
        };
        dumpFunc.value(msg[2]);
    });
});
)

// 终止我及我的子节点
g.free;

// 看，我走了
g.query;
