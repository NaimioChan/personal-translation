SpecCentroid

频谱质心

UGen : AbstractFunction : Object

参见：SpecFlatness、SpecPcile

说明

给定一个 FFT 链，这会测量频谱质心，即加权平均频率，或频谱的“质量中心”。（直流被忽略。）

这可以作为信号感知亮度的有用指标。

类方法

SpecCentroid.kr(buffer)

参数：

buffer

一个 FFT 链。

实例方法

示例

Blip 振荡器非常适合演示这一点，因为谐波数量可以直接操控：随着谐波数量增加，质心会被推得更高。在示例中，左右方向改变谐波数量，而上下方向改变基频；请注意这两者对质心的不同影响。

s.boot;
b = Buffer.alloc(s, 2048, 1);
(
x = {
    var in, chain, freq, rq, centroid;

    // freq = LFPar.kr(0.3).exprange(100, 1000);
    freq = MouseY.kr(1000, 100, 1);
    in = Blip.ar(freq, MouseX.kr(1, 100, 1));
    chain = FFT(LocalBuf(2048), in);
    centroid = SpecCentroid.kr(chain);
    centroid.poll(10);
    in.dup * 0.1

}.play
)

x.free;
