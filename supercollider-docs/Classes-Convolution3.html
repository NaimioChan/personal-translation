Convolution3

基于时间的卷积器。

UGen : AbstractFunction : Object

另请参阅：Convolution、Convolution2、Convolution2L

说明

使用固定核进行严格卷积，该核可通过触发信号更新。卷积在时域中执行。

注意： 在时域中进行卷积效率极低，可能只适用于非常短的核尺寸，或控制速率信号。参见 Convolution2 和 Convolution2L 以了解更高效的卷积 UGen。

类方法

Convolution3.ar(in, kernel, trigger: 0, framesize: 2048, mul: 1.0, add: 0.0)

Convolution3.kr(in, kernel, trigger: 0, framesize: 2048, mul: 1.0, add: 0.0)

参数：

in

处理目标

kernel

固定 kernel 的缓冲区索引，可与触发组合进行调制

trigger

在从 <=0 变为 >0 时更新内核

framesize

包含内核的缓冲区的最大大小

mul

add
