TwoPole

双极点滤波器。

Filter : PureUGen : UGen : AbstractFunction : Object

另请参阅：TwoZero

子类：APF、TwoZero

说明

一个双极点滤波器。这提供了对极点位置设置的较低级访问。对于一般用途，Resonz 更好。

类方法

TwoPole.ar(in: 0.0, freq: 440.0, radius: 0.8, mul: 1.0, add: 0.0)

TwoPole.kr(in: 0.0, freq: 440.0, radius: 0.8, mul: 1.0, add: 0.0)

参数：

in

输入信号。

freq

极点角频率。

radius

极点半径。应在 0 到 +1 之间。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

{ TwoPole.ar(WhiteNoise.ar(0.005), 2000, 0.95) }.play

{ TwoPole.ar(WhiteNoise.ar(0.005), XLine.kr(800, 8000, 8), 0.95) }.play

{ TwoPole.ar(WhiteNoise.ar(0.005), MouseX.kr(800, 8000, 1), 0.95) }.play
