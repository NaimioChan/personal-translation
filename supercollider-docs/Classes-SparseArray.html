SparseArray

更高效地存储重复值的数组

Order : SequenceableCollection : Collection : Object

说明

稀疏数组是一种数据结构，其行为与 Array 完全相同。但是，数据在内存中的表示方式不同，这使得在存储许多值相同的超大数组时效率要高得多。

例如，考虑一个由一百万个零组成的数组，末尾附加一个 1；SparseArray 会将零作为默认值存储，从而压缩该数组，只显式存储那个不同的单一值，因此内存使用要经济得多。

使用 SparseArray 的优势通常出现在创建包含数百万个槽位的集合时。

类方法

SparseArray.newClear(size, default)

创建一个指定 size 的新 SparseArray，每个槽位的值为 default。

g = SparseArray.newClear(20, 3);
g.postcs;

参数：

size

所需数组中的槽数。注意，槽并非显式创建，因此创建速度与数组大小无关。

default

默认值，即所有槽位最初应取的值。

SparseArray.reduceArray(array, default)

创建一个新的 SparseArray，保存与 array 相同的数据。

a = [4, 7, 4, 4, 4, 4, 4, 4, 9, 9, 8];
g = SparseArray.reduceArray(a, 4);
g.postcs;

参数：

array

任意 ArrayedCollection。

default

默认值，即所有槽位最初都应取的值。为获得最佳内存效率，你应提供集合中最常见的值。

实例方法

.put(index, obj)

来自父类：Order

将值放在所需的索引处。其工作方式与所有 ArrayedCollection 类型完全相同。在幕后，该类将确保紧凑表示（决定是显式还是隐式地存储该值）。

g = SparseArray.newClear(10, 3);
g.put(4, \horse);
g.put(6, [4, 5, 6]);
g[1] = \hello; // 常见紧凑记法

.at(index)

获取索引处的值。

g = SparseArray.newClear(20, 3);
g.put(4, \horse);
g.at(4);
g[4];

.asArray

转换为普通的 Array。

g = SparseArray.newClear(20, 3);
g.postcs;
g.asArray;

示例

这里我们比较 Array 与 SparseArray 的速度。

// 让我们创建一个标准数组，规模较大，但其中只隐藏了几个不寻常的值
(
{
    a = { 10 }.dup(1000000);
    a[551] = 77;
    a[8722] = \foo;
}.bench
)
// 现在一个由完全相同数据构成的 SparseArray
(
{
    b = SparseArray.newClear(a.size, 10);
    b[551] = 77;
    b[8722] = \foo;
}.bench
)

// 或者你也可以从现有数组创建 SparseArray，
// 尽管这通常不如从头开始高效，
// 因为 Array 需要被直接扫描。
(
{
    b = SparseArray.reduceArray(a, 10);
}.bench
)

// 访问：
{ 1000.do{ a[a.size.rand] == 60.rand } }.bench
{ 1000.do{ b[b.size.rand] == 60.rand } }.bench
// 设置：
{ 1000.do{ a[a.size.rand] = 60.rand } }.bench
{ 1000.do{ b[b.size.rand] = 60.rand } }.bench
