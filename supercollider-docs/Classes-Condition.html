Condition

阻塞线程的执行

Object

类方法

Condition.new(test: false)

创建一个新实例，设置 test 变量。

实例方法

.test

.test = value

回答该条件是否会阻塞（布尔值）。

.wait

等待条件为真并被信号通知。这仅在 Routine 中有效。此方法会产生一个符号（\hang），以便时钟不会重新调度该 Routine。

c = Condition(false); fork { 0.5.wait; "started ...".postln; c.wait;  "... and finished.".postln };
c.test = true;
c.signal;

.hang(value: 'hang')

等待 value 时间，无论测试结果如何。这仅在 Routine 中有效。该方法会产生一个符号（\hang），这样时钟就不会重新调度该 Routine。

c = Condition.new; fork { 0.5.wait; "started ...".postln; c.hang;  "... and finished.".postln };
c.unhang;

.signal

如果 -test 为 true，则重新调度被阻塞的线程。

.unhang

恢复线程。

示例

(
c = Condition.new(false);

Routine {
    1.wait;
    "waited for 1 second".postln;
    1.wait;
    "waited for another second, now waiting for you ... ".postln;
    c.wait;
    "the condition has stopped waiting.".postln;
    1.wait;
    "waited for another second".postln;
    "waiting for you ... ".postln;
        c.test = false;
        c.wait;
    "the condition has stopped waiting.".postln;
    1.wait;
    "the end".postln;
}.play;
)

// 继续
(
c.test = true;
c.signal;
)

// 一个典型用法是一个可以在特定条件下暂停的例程：
(
c = Condition.new;
fork { loop { 1.wait; "going".postln; c.wait } };
)
c.test = true; c.signal;
c.test = false;
// 相同，使用 hang

(
c = Condition.new;

Routine {
    1.wait;
    "waited for 1 second".postln;
    1.wait;
    "waited for another second, now waiting for you ... ".postln;
    c.hang;
    "the condition has stopped waiting.".postln;
    1.wait;
    "waited for another second".postln;
    "waiting for you ... ".postln;
    c.hang;
    "the condition has stopped waiting.".postln;
}.play;
)

// 继续
c.unhang;

等待 Synth 结束（waitForFree）隐式地使用一个 Condition：

(
SynthDef(\help, { |out|
    var mod = LFNoise2.kr(ExpRand(0.5, 2)) * 0.5;
    var snd =  mod * Blip.ar(Rand(200, 800) * (mod + 1));
    Out.ar(out, snd);
    FreeSelf.kr(mod < 0); // 当振幅低于 0 时释放 synth。
}).add;
)

(
fork {
    10.do {
        "started a synth".postln;
        Synth(\help).waitForFree;
        "This one ended. Wait a second, I will start the next one.".postln;
        1.wait;
    };
    "This is it.".postln;
}
);
