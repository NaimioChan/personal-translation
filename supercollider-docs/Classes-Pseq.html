Pseq

将值依次嵌入列表

ListPattern : Pattern : AbstractFunction : Object

参见：Pser

子类：Place、Ppatlace、Pser

说明

在值列表上循环。repeats 变量给出重复整个列表的次数。

类方法

未文档化的类方法

Pseq.new(list, repeats: 1, offset: 0)

实例方法

未文档化的实例方法

.embedInStream(inval)

.offset

.offset = value

示例

(
var a, b;
a = Pseq([1, 2, 3], 2);    // 重复两次
b = a.asStream;
7.do({ b.next.postln });
)

Pseq 还有一个 offset 参数，用于给出列表中的起始偏移量。

(
var a, b;
a = Pseq([1, 2, 3, 4], 3, 2);    // 重复 3 次，偏移 2
b = a.asStream;
13.do({ b.next.postln });
)

你可以为 repeats 变量传入一个函数，该函数在流创建时求值。

(
var a, b;
a = Pseq([1, 2], { rrand(1, 3) });    // 重复 1、2 或 3 次
b = a.asStream;
7.do({ b.next.postln });
)

如果为 repeats 变量指定值 inf，则它将无限重复。

(
var a, b;
a = Pseq([1, 2, 3], inf);    // 无限重复
b = a.asStream;
10.do({ b.next.postln });
)

Pseq 用作音高序列：

(
SynthDef(\help_sinegrain,
    { |out = 0, freq = 440, sustain = 0.05|
        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain, 0.2), doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env))
    }).add;
)

(
a = Pseq(#[60, 61, 63, 65, 72], inf).asStream;
Routine({
    loop({
        Synth(\help_sinegrain, [\freq, a.next.midicps]);
        0.2.wait;
    })
}).play;
)
