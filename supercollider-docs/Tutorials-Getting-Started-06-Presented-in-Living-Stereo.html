好的，但我们第一个未简化的例子呢？记住：

{ [SinOsc.ar(440, 0, 0.2), SinOsc.ar(442, 0, 0.2)] }.play;

这里也有两个 SinOsc，但排列方式不同，位于两个方括号 [] 之间，中间用逗号分隔。正如花括号表示 Function，方括号定义了一种叫做 Array 的东西。Array 是 Collection 的一种，（你猜对了）它是对象的集合。集合本身也是对象，并且大多数类型的集合可以容纳任何类型的对象，混合在一起，包括其他集合！SC 中有许多不同类型的 Collection，你将会了解到它们是 SC 最强大的特性之一。

Array 是 Collection 的一种特殊类型：一种有序的、最大大小有限的集合。你可以像上面那样，通过将对象放在两个方括号之间并用逗号分隔来创建一个 Array。你可以使用 'at' 方法获取 Array 的不同元素，该方法接受一个索引作为参数。索引对应 Array 中对象的顺序，并从 0 开始。

a = ["foo", "bar"];    // "foo" 位于索引 0；"bar" 位于索引 1
a.at(0);
a.at(1);
a.at(2);        // 返回 "nil"，因为索引 2 处没有对象

// 有时你会看到 at 的简写形式：
a[0];            // 等同于 a.at(0);

除了用于保存对象集合之外，数组在 SC 中还有一种特殊用途：它们被用来实现多声道音频！如果你的 Function 返回一个 UGen 数组（请记住 Function 返回其最后一行代码的结果），那么输出将是多个声道。声道数量取决于数组的大小，每个声道将对应数组中的一个元素。因此在我们的示例中：

{ [SinOsc.ar(440, 0, 0.2), SinOsc.ar(442, 0, 0.2)] }.play;

最终得到的是立体声输出，左声道是一个 440Hz 的 SinOsc，右声道是一个 442Hz 的 SinOsc。我们还可以通过更大的数组获得更多声道的输出。

现在请仔细看，因为接下来这一点涉及一点小手法，但展示了 SC 让事物变得高度可互换的另一种方式。由于两个 SinOsc 的 phase 和 mul 参数相同，我们可以把示例的代码改写成这样：

{ SinOsc.ar([440, 442], 0, 0.2) }.play;

我们已将频率参数替换为数组。这引发了所谓的“多通道扩展”，意思是如果你将数组插入 UGen 的某个参数，你会得到该 UGen 的数组而非单个 UGen。现在考虑这个：

(
{ var freq;
    freq = [[660, 880], [440, 660], 1320, 880].choose;
    SinOsc.ar(freq, 0, 0.2);
}.play;
)

尝试多次执行它，会得到不同的结果。'choose' 只是一个从 Array 中随机选取一个元素的方法。在这个例子中，结果可能是一个单独的数字，也可能是另一个 Array。如果是后者，你会得到立体声输出；如果是前者，则是单声道输出。这类做法可以让你的代码非常灵活。

但如果你想对某个声音做“声像”处理，在声道之间交叉淡化呢？SC 有多种 UGen 能以不同方式实现这一点，但现在我只介绍其中一个：Pan2。Pan2 接收一个输入和一个位置作为参数，返回一个包含两个元素的数组，即左声道和右声道（或第一声道和第二声道）。位置参数取值在 -1（左）到 1（右）之间。看看这个例子：

{ Pan2.ar(PinkNoise.ar(0.2), SinOsc.kr(0.5)) }.play;

这里使用 SinOsc 来控制位置（记住它输出的值从 -1 到 1，即从左到右），但使用了一个不同的 UGen 作为 Pan2 的输入，即所谓的 PinkNoise。这只是一种噪声生成器，它只有一个参数：mul。当然，你也可以为 position 参数使用固定值。

{ Pan2.ar(PinkNoise.ar(0.2), -0.3) }.play; // 稍微向左
