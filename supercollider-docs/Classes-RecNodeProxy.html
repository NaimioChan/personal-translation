RecNodeProxy

一个可录制的 NodeProxy

参见：NodeProxy

说明

这也是由 NodeProxy 创建的，或由一个 Ndef 通过消息 record 创建。

类方法

.new

参见父类

.audio

参见父类

.newFrom

实例化一个监听 in 代理的新代理。

实例方法

.open

打开新文件并在服务器上初始化缓冲区

.record

启动录音 synth。

参数：

paused

如果 paused 为 false，则立即开始录制。

clock

可选 - 用于调度录音的时钟……

quant

... 如果给定了非 nil 的 quant。

.close

停止录音，关闭文件

.isRecording

检查当前是否正在录音

.wakeUp

直到该代理不被任何输出（.play 或 .ar/.kr）使用之前，它不会在服务器上运行。你可以唤醒它以强制其播放。

示例

s.boot;

a = RecNodeProxy.audio(s, 2);
a.source = { SinOsc.ar([400, 500], 0, 0.1) };
a.play; // monitor;
a.open("xproxySpace.aif");
a.record(false);

a.source = { SinOsc.ar([400, 700], 0, 0.1) };
a.source = { SinOsc.ar([410, 510], 0, 0.1) };
a.source = { SinOsc.ar([LFNoise1.kr(80, 100, 300), 500], 0, 0.1) };

// 停止录音并关闭文件
a.close;

// monitor off
a.stop;

从某个总线录制

从现有节点代理创建实例

b = NodeProxy.audio(s, 2);
b.play; // listen to b
b.source = { SinOsc.ar([400, 500], 0, 0.1) }; // 播放一些内容

r = RecNodeProxy.newFrom(b);
r.open("recproxy514.aif"); // 打开文件
r.record; // 启动录制器（暂停）

r.unpause; // 开始录制

b.source = { SinOsc.ar([430, 500], 0, 0.1) };
b.source = { SinOsc.ar([410, 510], 0, 0.1) };
b.source = { SinOsc.ar([LFNoise1.kr(80, 100, 300), 500], 0, 0.1) };
r.pause;
b.source = { WhiteNoise.ar(0.01) };
r.unpause;
r.pause;


// 停止录音并关闭文件
r.close;
b.stop; // 停止监听 b

再次从已存在的节点代理创建实例

b = NodeProxy.audio(s, 2);
