IRand

单整数随机数生成器。

UGen : AbstractFunction : Object

另请参阅：ExpRand、LinRand、NRand、Rand、TExpRand、TIRand、TRand

说明

在 lo 到 hi 的均匀分布中生成一个随机整数值。它在 SynthDef 首次开始播放时生成该值，并在 synth 存在的整个期间保持固定。

类方法

IRand.new(lo: 0, hi: 127)

参数：

lo

输出范围的下限。

hi

输出范围的上限。

实例方法

示例

(
SynthDef("help-IRand", {
    Out.ar(
        IRand(0, 1), // 在 0 和 1 之间的随机声道上播放
        FSinOsc.ar(500,
            0, Line.kr(0.2, 0, 0.1, doneAction: Done.freeSelf))
    )
}).add;
)

(
Routine({
    16.do({
        Synth.new("help-IRand"); 0.5.wait;
    })
}).play;
)
