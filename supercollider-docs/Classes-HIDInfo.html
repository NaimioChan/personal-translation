HIDInfo

此类包含有关 HID 设备的基本信息，以便访问并打开它。

Object

另请参阅：HID、使用 HID

说明

此类包含有关 HID 设备的基本信息，以便访问并打开该设备。此类主要用于内部，用户很少直接访问。

此类由从设备读取的信息填充，表示设备的某些内部信息。

类方法

实例方法

.open

打开此 HIDInfo 所描述的设备

返回值：

一个 HID - 设备

.postInfo

以人类可读的方式发布 HIDInfo

.path

设备的路径，这是由操作系统定义的路径，因此在不同平台上并不相同，但它是区分具有相同供应商 ID 和产品 ID 的设备所必需的。

.vendorID

设备的供应商 ID，这是由设备自身编码的数字，并且在各个平台上保持一致。

.productID

设备的 product ID，这是由设备本身编码的数字，且在各平台上保持一致。

.vendorName

设备的供应商名称，这是由设备自身编码的字符串，并且在不同平台上相同。

.productName

设备的产物名称，这是由设备自身编码的字符串，跨平台相同。

.serialNumber

设备的序列号。这取决于操作系统，例如在 Linux 上不会设置。

.releaseNumber

设备的发布编号，这是由设备自身编码的数字，在各平台上相同。

.interfaceNumber

设备的接口类型，可以是代表 USB、蓝牙等的索引。

.usage

获取此集合的使用索引。

返回值：

一个 Number ——此集合的用法索引

.usagePage

检索此集合的用法页索引。

返回值：

一个 Number - 使用页索引

.usageName

获取此集合的用途名称。该名称通过用途页面索引从标准化的 HID 用途表中查找。

返回值：

一个 String —— 用法名称

.pageName

检索此集合的页面名称。该名称使用 usage page 索引从标准化的 HID usage 表中查找。

返回值：

一个 String - 使用页名称
