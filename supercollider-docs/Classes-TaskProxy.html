TaskProxy

事件流引用

PatternProxy : Pattern : AbstractFunction : Object

参见：Tdef

子类：EventPatternProxy、Tdef

说明

保留一个可替换的任务（时间模式）的引用，该任务在播放时可以被替换。当旧流结束且新流被设置时，它会继续播放，并将变更调度到节拍上。

类方法

TaskProxy.new(source)

来自父类：PatternProxy

用函数（源）创建一个新实例。源应当是一个 例程函数（参见 Tdef）或一个时间值的模式。

TaskProxy.default

默认源（如果未提供）。默认是一个以 1.0 拍等待时间做空操作的循环。

TaskProxy.defaultQuant

TaskProxy.defaultQuant = value

设置该类的默认量化值。（默认值：1.0）。可以是一对 [quant, offset]

实例方法

.source

.source = obj

来自父类：PatternProxy

设置源。如果给定了量化，则将此更改调度到下一个节拍。该对象是一个例程函数，会以受保护的方式求值，因此失败时会通知代理它已停止。该对象也可以是一个时间值的模式。

.clear

来自父类：PatternProxy

将源设为 nil

.clock

.clock = value

来自父类：PatternProxy

获取或设置实例的默认时钟，在没有指定其他时钟时由 -play 使用。默认为 TempoClock.default。

.quant

.quant = val

来自父类：PatternProxy

获取或设置量化值。可以是一对 [quant, offset]

.condition

.condition = value

来自父类：PatternProxy

提供一个条件，当插入新模式时依据该条件切换模式。流的值和一个计数会被传入该函数。方法 count_(n) 简单地计数到 n，然后切换模式。

.reset

来自父类：PatternProxy

立即切换模式。（可通过此方式消除卡住的条件）

.envir

.envir = value

来自父类：PatternProxy

为代理提供默认环境。如果给出，它会被用作例程函数的环境。首次设置时，例程模式会被重建。

.set( ... args)

来自父类：PatternProxy

设置环境中的参数。如果没有，则创建它并重建例程模式。

.endless(default)

来自父类：PatternProxy

返回一个 Prout，它无限期播放代理，将 nil 替换为 default 值（1 秒等待时间）。这允许创建空闲等待直到插入新模式为止的流。

a) 将其用作流引用

.source

.source = obj

来自父类：PatternProxy

设置例程函数 / 模式（内部由 *new(key, obj) 完成）

.embedInStream(inval, embed: true, default)

来自父类：PatternProxy

就像任何流一样，它嵌入到流中

b) 将其用作 EventStreamPlayer

.play(argClock, doReset: false, quant)

启动 TaskProxy 并创建一个播放器。如果要播放多个实例，请使用 .playOnce(clock, protoEvent, quant)

参数：

argClock

要使用的时钟。若为 nil，则使用此实例的 -clock，其又默认为 TempoClock.default。

doReset

一个 Boolean

quant

可以是一个 [quant, phase] 数组

.stop

停止播放器

.player

当前的播放器（如果 TaskProxy 只是被用在其他流中，则为 nil）

.pause

.resume(clock, quant)

.reset

来自父类：PatternProxy

执行播放器方法

.isPlaying

如果 TaskProxy 正在运行，则返回 true。如果某个 TaskProxy 正在播放且其流结束，它将在有新的流被分配给它时，尽快安排该流进行播放。

示例

a) 使用 TaskProxy 作为播放器

// 创建一个空的 Tdef 并播放它。
x = TaskProxy.new;
x.play;


x.source = { loop { "ggggggggggggggggg9999ggg999ggg999gg".scramble.postln; 0.5.wait } };


x.source = { loop { "---------////----------------------".scramble.postln; 0.25.wait } };
x.source = { loop { thisThread.seconds.postln; 1.wait } };
x.source = { loop { thisThread.seconds.postln; 1.01.wait } };

TempoClock.default.tempo = 2;

x.source = { "the end".postln };
x.source = { "one more".postln };
x.source = { 10.do { "ten more".scramble.postln; 0.25.wait } };
x.source = { loop { "many more".scramble.postln; 0.25.wait } };

TempoClock.default.tempo = 1;

x.stop;
x.play;
x.stop;
// 声音示例

(
// 加载 synthdef
s.boot;
SynthDef("pdef_grainlet",
    { |out = 0, freq = 440, sustain = 0.05|
        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain, 0.3), doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env))
    }).add;
)
x.play;

(
x.source = {
    loop {
        s.sendMsg("/s_new", "pdef_grainlet", -1, 0, 0, \freq, rrand(600, 640));
        0.1.wait;
    }
}
)

(
x.source = {
    var x;
    x = Pseries(300, 20, 100).loop.asStream;
    loop {
        s.sendMsg("/s_new", "pdef_grainlet", -1, 0, 0, \freq, x.next);
        0.05.wait;
    }
}
)

(
x.source = {
    var x;
    x = Plazy { Pseries(300 + 300.rand, 10 + 30.rand, 10 + 30.rand) }.loop.asStream;
    loop {
        s.sendMsg("/s_new", "pdef_grainlet", -1, 0, 0, \freq, x.next);
        0.05.wait;
    }
}
)

// 节拍器
(
y = TaskProxy {
    loop { s.sendMsg("/s_new", "pdef_grainlet", -1, 0, 0, \freq, 1500); 1.wait }
};
y.play;
)

// 播放一次结束流
(
x.source = {
    var x, dt;
    dt = [0.1, 0.125, 0.05].choose;
    x = Plazy { Pseries(1300 + 300.rand, 110 + 130.rand, 16) }.asStream;
    x.do { |item|
        s.sendMsg("/s_new", "pdef_grainlet", -1, 0, 0, \freq, item);
        dt.wait;
    }
}
)

... and so on ...

x.stop;
y.stop;

b) 将 TaskProxy 嵌入其他 Task / Routine

(
#a, c = { TaskProxy.new } ! 2;
a.source = { "one".postln; 1.wait; "two".postln };
c.source = { var z; z = Synth(\default); 0.5.wait; z.release };
r = Task {
    "counting...".postln;
    2.wait;
    a.embedInStream;
    1.wait;
    c.embedInStream;
    "done.".postln;
};
)

r.play; // 播放流

c.source = { var z; z = Synth(\default, [\freq, 300]); 1.5.wait; z.release }; // 更改定义

r.reset;
r.play;

// 当然，TaskProxy 可以在其他 Tdef 中使用：
(
b = TaskProxy.new;
b.source = {
    "counting...".postln;
    2.wait;
    a.embedInStream;
    1.wait;
    c.embedInStream;
    "done.".postln;
};
)
b.playOnce;

// 如果想把流分支到单独的线程中，就使用 asStream。
(
Routine {
    c.asStream.play;
    0.1.wait;
    c.asStream.play;
    0.1.wait;
    a.asStream.play;

}.play;
)
