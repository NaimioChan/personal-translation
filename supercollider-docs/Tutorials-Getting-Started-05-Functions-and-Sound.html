05. 函数与声音

SuperCollider 入门

另请参阅：00. Getting Started With SC

那么函数和声音呢？

技术细节可能已经让你感到厌倦了，所以让我们回到制造声音上来——我想这毕竟是你读这篇文章的原因。不过请相信我，所有这些工作日后都会有回报，而且信不信由你，我们已经（至少是顺带地）覆盖了这门语言相当一部分的基础知识。

让我们回到声音示例，或者更确切地说是它稍微简化的版本。确认 localhost 服务器正在运行，执行下面的代码，然后在听够之后按下 Cmd-.。

{ SinOsc.ar(440, 0, 0.2) }.play;

在这个例子中，我们通过将一些代码括在花括号中创建了一个 Function，然后在该 Function 上调用了方法 'play'。对 Function 而言，'play' 意味着对其求值并在服务器上播放结果。如果你不指定服务器，你将得到默认服务器，你记得它存储在变量 's' 中，并在启动时被设置为 localhost 服务器。

我们没有将 Function 存储在变量中，因此它无法被复用。（好吧，实际上你只需再次执行同一行代码即可，但你明白我的意思……）在使用 Function-play 时经常如此，因为它是一种快速产生声音的便捷方式，常用于测试目的。还有其他复用 Function 来产生声音的方式，通常更好也更高效，我们将会看到。

让我们看看花括号之间是什么。我们取一个叫 'SinOsc' 的东西，向它发送 ar 消息，并附带几个参数。事实证明，SinOsc 是所谓类的一个例子。要理解类是什么，我们需要对 OOP 和对象有更多了解。

简而言之，对象就是某些数据，即某些信息，以及一组你可以对该数据执行的操作。你可能拥有许多相同类型的不同对象。这些被称为实例。类型本身是对象的类。例如，我们可能有一个名为 Student 的类，以及它的几个实例：Bob、Dave 和 Sue。这三者都将拥有相同类型的数据，例如它们可能有一个名为 gpa 的数据。然而，每项数据的值可能不同。它们也将拥有相同的方法来操作数据。例如，它们可能有一个名为 calculateGPA 或类似名称的方法。

对象的类定义了它的数据集（即所谓的实例变量）和方法。此外，它还可以定义一些其他方法，这些方法只由你发送给类本身，以及一些供其所有实例使用的数据。这些被称为类方法和类变量。

所有类都以大写字母开头，因此在代码中很容易识别它们。

类是用来创建对象的。它们就像模板。你通过类方法来完成这件事，例如 'new'，或者在我们上面的 SinOsc 类的例子中，是 'ar'。这类方法返回一个对象，即一个实例，而参数会影响其数据将是什么以及它将如何表现。现在再来看一下所讨论的示例：

SinOsc.ar(440, 0, 0.2)

这告诉 SinOsc 类创建自身的一个实例。所有 SinOsc 都是所谓单位生成器（unit generator）或 UGen 的示例。这些是产生音频或控制信号的对象。SinOsc 是一个正弦波振荡器。这意味着它将产生一个由单一频率组成的信号。其波形图看起来像这样：

这个波形循环，产生输出信号。'ar' 表示让实例以音频速率运行。SuperCollider 以样本组为单位计算音频，这些样本组称为块。音频速率意味着该 UGen 会为块中的每个样本计算一个值。还有另一种方法 'kr'，表示控制速率。这意味着为每个样本块计算一个单一值。这可以节省大量计算能力，对于（你猜对了）控制其他 UGen 的信号来说完全够用，但对于合成音频信号来说细节不够精细。

示例中给 SinOsc-ar 的三个参数决定了所生成实例的一些特性。我碰巧知道这些参数分别是频率、相位和 mul。（稍后我们会说明我是怎么知道的。）频率就是振荡器的频率，单位为赫兹（Hz），即每秒周期数（cps）。相位指的是波形从其周期的哪个位置开始。对于 SinOsc（并非所有 UGen 都是如此），相位以弧度给出。如果你不知道弧度是什么，不用担心，只需知道它是 0 到 2 * pi 之间的一个值。（如果你真的想了解更多细节，可以查阅三角学教材。）因此，如果我们创建一个相位为 (pi * 0.5)、即处于其周期四分之一处的 SinOsc，波形看起来会是这样：

那么 'mul' 呢？Mul 是一个特殊参数，几乎所有 UGen 都有。它如此普遍，以至于通常甚至不会在文档中解释。它只是表示一个值或信号，UGen 的输出将与之相乘。结果表明，在音频信号的情况下，这会影响信号的幅度，或者说它的响度。大多数 UGen 的默认 mul 为 1，这意味着信号将在 1 和 -1 之间振荡。这是一个很好的默认值，因为任何更大的值都会导致削波和失真。mul 为 0 将实际上静音，就像音量旋钮被完全调低一样。

明白了吗？还有另一个类似的参数叫做 'add'（在文档中通常也没有解释），它（你猜对了）是添加到输出信号中的东西。这对于控制信号之类的东西非常有用。'add' 的默认值为 0，这就是为什么我们不需要为它指定任何东西。

好的，考虑到所有这些，让我们带着注释来回顾我们的示例：

(
{             // 打开 Function
    SinOsc.ar(    // 创建一个音频速率 SinOsc
        440,     // 440 Hz 的频率，或调音 A
        0,     // 初始相位为 0，或周期的起点
        0.2)     // mul of 0.2
}.play;            // 关闭 Function 并在其上调用 'play'
)

函数和 UGen 的更多乐趣

这是多态性的另一个例子，也展示了它的强大之处。在创建 UGen 的 Function 时，许多参数不必使用固定值，实际上可以使用其他 UGen！下面是一个演示此点的例子：

(
{ var ampOsc;
    ampOsc = SinOsc.kr(0.5, 1.5pi, 0.5, 0.5);
    SinOsc.ar(440, 0, ampOsc);
}.play;
)

试试这个。（同样，使用 Cmd-. 停止声音。）

我们在这里做的是把第一个 SinOsc（一个控制速率的 SinOsc！）接入第二个 SinOsc 的 mul 参数。因此它的输出会被第二个 SinOsc 的输出所乘。现在让我们看看第一个 SinOsc 的参数。

频率设置为 0.5 cps，仔细想想这意味着它每 2 秒完成一个周期。（1 / 0.5 = 2）

mul 和 add 都设为 0.5。想一想那会有什么效果。如果默认情况下 SinOsc 在 1 和 -1 之间变化，那么 mul 为 0.5 会将其缩放到 0.5 和 -0.5 之间。再加上 0.5 就使其变为 0 到 1 之间，这对 mul 来说是个相当好的范围！

相位为 1.5pi（也就是说 1.5 * pi）表示在其周期的 3/4 处，如果你看上面的第一张图，会看到那是最低点，或者在这种情况下是 0。因此 ampOsc SinOsc 的波形将如下所示：

最终我们得到的是一个会平缓淡入淡出的 SinOsc。移动相位只是意味着我们从安静开始并淡入。我们实际上是把 ampOsc 用作所谓的幅度包络。还有其他方法可以做同样的事情，其中一些更简单，但这演示了原理。

以这种方式将 UGen 组合在一起是在 SC 中制造声音的基本方法。要了解 SC 中提供的各种类型的 UGen 概览，请参见 Browse: UGens 或 Tour of UGens。
