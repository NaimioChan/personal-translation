跟踪进程

在 SC 中追踪进程

另请参阅：调试技巧

运行中的系统里发生了什么？在 SC 中，各种方法有助于在不同层级获取进程信息：服务器端和客户端（在 sclang 中）。

跟踪 sclang 进程

为了更清楚地了解由诸如任务之类的进程所创建的对象，或者仅仅通过求值一小段代码所创建的对象，可以在代码中的任何位置插入诸如 postln 和 postcs 之类的消息。

计算 n 个后续平方的和

var n = 8, x = 0;
(1..n).do { |num| x = x + num.squared };
x

我们这样做时会发生什么？

var n = 8, x = 0;
(1..n).do { |num| x = x + num.squared.postln; };
x

或更详细地说：

var n = 8, x = 0;
(1..n).do { |num| [\before, x].postln; x = x + num.squared; [\after, x].postln;};
x

当发布多个值时，一些更详细的发布可能有用。postf 格式化字符串并为 % 字符插入值。这里需要单独的语句。

var n = 8, x = 0;
(1..n).do { |num| x = x + num.squared; "num: % num-squared: % new x: %\n".postf(num, num.squared, x) };
x

在某些情况下，postln 只会输出部分数据，或输出简化表示。

// n 乘以 200 个随机数
// 只会在 123 之后加上……等等……
var n = 3;
(1..n).do { |num| { 1000.rand }.dup(200).postln };

输出编译字符串，即重新创建接收者（此处为数组）所需的代码

var n = 3;
(1..n).do { |num| { num.rand }.dup(200).postcs };

流、任务与例程

在流、任务和例程中，这同样有效：

fork {
    var n = 14;
    (1..n).do { |num|
        { num.rand }.dup(200).postcs;
        1.wait;
    };
}
fork {
    var str = Routine { |in| 10.do { in = in.rand.yield } };
    12.0.do { |i|
        str.next(i).postln;
        0.5.wait;
    };
}

用于创建一个模式，一旦被使用便会发布其值，可以使用消息 trace（其返回一个 Ptrace）

a = Pseq([1, 4, 1, Pwhite(0, 6, 3), 100, 39], inf).trace(prefix: "value: ");
b = a.asStream;
b.next;
b.next;
b.next;
b.next;

在运行中的流中：

Pbind(
    \degree, Pseq([1, 4, 1, Pwhite(0, 6, 3), 100, 39], inf).trace(prefix: "value: "),
    \dur, 0.2
).play

仅发布事件的一个槽位

Pbind(
    \degree, Pseq([1, 4, 1, Pwhite(0, 6, 3), 100, 39], inf),
    \dur, 0.2
).trace(\degree).play

同时多个槽位：

Pbind(
    \degree, Pseq([1, 4, 1, Pwhite(0, 6, 3), 100, 39], inf),
    \dur, Pwhite(0.2, 0.4, inf)
).trace([\degree, \dur], prefix: ["degree ", "dur "]).play

跟踪服务器进程

对 UGen 使用 postln 或 post 只会返回该 UGen，而不会返回它在运行中的 synth 里产生的值。poll 消息会创建一个 Poll UGen，当给定时间值时它会按固定间隔发布，或作为对触发的响应发布（参见 Poll 帮助文件）

// postln 只返回 UGen 本身（此处为 MulAdd）
{ SinOsc.ar(SinOsc.kr(0.2, 0, 300, 400).postln) * 0.1 }.play;

// poll 追踪数值
{ SinOsc.ar(SinOsc.kr(0.2, 0, 300, 400).poll) * 0.1 }.play;

// 使用标签：
{ SinOsc.ar(SinOsc.kr(0.2, 0, 300, 400).poll(label: "freq")) * 0.1 }.play;

对于 demand ugens，poll 不起作用——这些 ugens 由 Demand 或 Duty UGen 按特定间隔调用。消息 dpoll 会创建一个 Dpoll ugen，当它们被调用时进行发布（参见 Dpoll 帮助文件）

{ SinOsc.ar(Duty.kr(0.5, 0, (Dseries(0, 1, inf) * 200 + 300).dpoll)) * 0.1 }.play;

{ SinOsc.ar(Duty.kr(0.5, 0, (Dseries(0, 1, inf) * 200 + 300).dpoll(label: "freq"))) * 0.1 }.play;

示波器窗口可以提供有关正在进行的声的有价值信息（参见 Stethoscope 帮助）：

{ SinOsc.ar(SinOsc.kr(0.2, 0, 300, 400)) * 0.1 }.scope;

FreqScope 窗口可用于观察输出的频谱：

// 创建一个新的分析器
FreqScope.new;

{ SinOsc.ar(SinOsc.ar(0.2, 0, 3000, 4000)) * 0.1 }.play;
{ SinOsc.ar(SinOsc.ar((1..4) * 0.02, 0, 3000, 4000)).sum * 0.1 }.play;
