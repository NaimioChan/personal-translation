Filter

滤波器 UGens 的基类

PureUGen : UGen : AbstractFunction : Object

子类：BEQSuite、BPF、Changed、Decay、

说明

“Filter” 是一个抽象类——换句话说，是一个不直接使用的类。请改用它的某个子类。许多常见的滤波器都继承自这个抽象类，包括 LPF、HPF、MoogFF、Ringz、Integrator、Median、LeakDC……以及更多。

Filter 类还提供了一种简单的方法来可视化应用滤波器后的频率效果，参见下面的 scopeResponse。
