ParamView

显示 JITLib 进程的一个参数

参见：JITGui、JITLib

说明

ParamView 显示参数值，并根据值的情况切换表示形式：单个数字用 EZSlider 显示，一对数字用 EZRanger 显示，其他任何内容则以代码形式显示在 EZText 上。

首批示例：

w = Window("test", Rect(20, 820, 400, 100)).front;
w.addFlowLayout;
~pv = ParamView(w, Rect(20, 20, 360, 20));
~pv2 = ParamView(w, Rect(20, 20, 360, 40));

// 目前尚不能正常工作
~pv.bounds_(Rect(4, 4, 300, 40));

~pv.dump
~pv.viewType_(0); // EZNumber
~pv.viewType_(1); // EZRanger
~pv.viewType_(2); // EZText

~pv.label_(\freq);
~pv.spec_(\freq);  // 需要 EZSlider 的规格


~pv.value_(200);
~pv.value_(2000);
// 切换到 EZRanger
~pv.value_([200, 2000]);
// 3 个数字 -> 切换为 EZText
~pv.value_([20, 200, 2000]);
// 其他任何内容 -> EZText
~pv.value_(\blonk);
~pv.action = { |pv| pv.value.postcs };

类方法

.new

用以下内容创建新的 ParamView

参数：

parent

父窗口或视图

bounds

视图的边界

label

用于显示的标签

spec

该值的 controlspec

action

值变化时执行的动作

initVal

初始值

initAction

一个布尔值，表示是否在初始化时执行该操作。

实例方法

.label

获取和设置视图的标签

.spec

获取并设置视图的控制规格

.action

获取并设置 paramview 的动作

.ezviews

.slider

.ranger

.textview

ParamView 在其间切换的 3 个 ezview

.currview

这些当前显示的视图

.value

获取并设置值

.valueAction

获取并设置值并执行动作

.doAction

执行视图的动作

.viewType

获取和设置视图的类型：0 为单个数字 -> EZSlider，1 为一对数字 -> EZRanger，2 为其他任何情况

.valueType

为给定值确定 viewType

.background

获取和设置背景颜色
