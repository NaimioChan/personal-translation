BinaryOpStream

由二元运算符组合的两个流

Stream : AbstractFunction : Object

另请参见：UnaryOpStream、NAryOpStream

说明

BinaryOpStream 是对一对 Stream 执行二元数学运算的结果。它被定义为响应 next，返回两个流各自的 next 值进行数学运算的结果。它响应 reset，重置两个 Stream。
