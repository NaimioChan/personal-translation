softVol_

有条件地设置 nodeproxy 的 vol

另请参阅：softSet、softPut

说明

NodeProxy 的扩展方法，用于有条件地设置 vol。

softVol

setter.

参数：

val

要设置的音量值

within

集合被接受时的归一化范围

pause

一个标志，表示当音量为 0 时是否暂停节点代理。它会先等待 0.2 秒让音量降下来。

lastVal

控制器已设置的先前值 - 可以是

spec

可以传入一个 ControlSpec。如果为 nil，则使用 \amp.asSpec。

示例

Ndef(\test, { |freq=200| Splay.ar(SinOsc.ar(freq * Array.rand(12, 0.95, 1.05))) });
Ndef(\test).play(vol: 0.1);

    // softSet 的示例，softSet 知道 lastVal，
    // softVol_ 和 softVol_ 知道 lastVol：

w.view.addFlowLayout;

    // 音量同理——不太安全

    // safer
EZSlider(w, 340@30, \knowLastV, \amp, Routine { |sl|
    var newVal, lastVal;
    loop {
        newVal = sl.value;
        Ndef(\test).softVol_(sl.value, 0.05, lastVal: lastVal);
        lastVal = newVal;
        \dummy.yield;
    }
});
