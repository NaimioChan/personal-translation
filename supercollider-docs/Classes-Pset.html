Pset

设置某个键值的事件模式

FilterPattern : Pattern : AbstractFunction : Object

另请参阅：Pbindf、Psetp

子类：Padd、Pmul、Psetp

说明

Pset 在事件流中设置一个值。它的作用类似于 Pbindf 中的一个键。

(
var a, b;
a = Pset(\freq, 801, Pbind(\dur, 0.5));
x = a.asStream;
9.do({ x.next(Event.new).postln });
)

类方法

Pset.new(name, value, pattern)

参数：

name

该键。

value

可以是模式或流。当传入的流结束时，结果流也随之结束。

pattern

该模式。

实例方法

未文档化的实例方法

.embedInStream(event)

.filterEvent(event, val)

.name = value

.value

示例

// Pset 覆盖传入的值：

(
var a, b;
a = Pset(\freq, 801, Pbind(\freq, 108));
x = a.asStream;
9.do({ x.next(Event.new).postln });
)


(
var a, b;
a = Pset(\freq, Pseq([401, 801], 2), Pbind(\dur, 0.5));
x = a.asStream;
9.do({ x.next(Event.new).postln });
)


// 声音示例

(
SynthDef(\sinegrain,
    { |out = 0, freq = 440, sustain = 0.02|
        var env;
        env = EnvGen.kr(Env.perc(0.001, sustain), 1, doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env * 0.1))
    }).add;
)

(
a = Pbind(\dur, 0.5, \instrument, \sinegrain);
a = Pset(\freq, Pseq([500, 600, 700], inf), a);
a = Pset(\legato, Pseq([0.01, 1], inf), a);
a.play;
)
