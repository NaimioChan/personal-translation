HIDElement

描述 HID 设备元素的类

Object

另请参阅：HID、Working with HID、HIDCollection、HIDUsage

说明

HIDElement 描述 HID 设备的一个元素或控件。当你打开设备时，会为该设备自动创建这些元素。用户与元素的唯一交互是查询元素的属性（使用 .postElement）、查询 value 或 rawValue，或者设置值、设置 repeat 属性，或设置当新数据到来时要执行的 action。

类方法

实例方法

.action

.action = value

设置或获取接收到元素数据时要执行的动作。该函数将传入以下参数：值（映射在 0 到 1 之间）和原始值。

.value

.value = val

设置或获取元素的值。设置仅对输出元素有意义。

参数：

val

要发送到设备的原始值

.repeat

.repeat = rp

默认情况下，除非数据发生变化，否则不会更新来自设备的元素数据。然而对于某些元素，你可能希望即使数据未变化也能收到更新，例如鼠标的滚轮。

参数：

rp

一个用于开启或关闭重复的 Boolean

.rawValue

元素的原始值。

.logicalValue

元素的逻辑值。原则上与 value 相同。

.physicalValue

元素的物理值。这可由原始值和设备的转换规范计算得出：物理最小值、物理最大值、单位和单位指数。转换的工作方式在 USB HID 标准文档中描述。

注意： 后端尚未实现该转换。

.arrayValue

元素的数组值。此值仅对可以表示多种用途的元素（例如来自键盘的元素）有意义。在这种情况下，它表示被按下的键，通过将该数字加到元素的 usage 上，即可得知该键具有什么功能。

注意： 来自键盘的值会以两种方式解析：首先按它们传入时的元素形式，其次仅以传入数据中的用法和值（开或关）来解析。

元素的属性

.postElement(prefix: "")

将元素的易于人类阅读的描述发布到 post 窗口。

.id

此元素的索引。此索引可能因操作系统而异。

.device

.device = dev

获取此元素所属的设备。

注意： 不要将其设置为用户！

返回值：

HID 的一个实例

.collection

获取此元素所属的集合索引。

.usage

获取此集合的使用索引。

返回值：

一个 Number —— 此元素的使用索引

.usagePage

获取此元素的使用页索引。

返回值：

一个 Number - 使用页索引

.usageName

获取此元素的使用名称。该名称通过使用页索引从标准化的 HID 使用表中查找。

返回值：

一个 String —— 用法名称

.pageName

检索此元素的页面名称。该名称通过使用 usage page 索引从标准化的 HID 使用表中查找。

返回值：

一个 String - 使用页名称

.type

描述元素类型的字节。

返回值：

描述元素类型的数字。

.typeSpec

元素的类型，从类型字节解码得到。

返回值：

一个包含描述元素类型字符串的数组。

.ioType

元素类型，输入 (1)、输出 (2) 或特征 (3)

返回值：

一个表示 ioType 的 Number

.iotypeName

元素的类型，为 \input、\output 或 \feature 之一

返回值：

一个表示类型的 Symbol

.logicalMin

预期范围的最小值。该值由设备报告。将元素的原始值映射到逻辑最小值与最大值之间以获得元素的值。

.logicalMax

预期范围的最大值。该值由设备报告。将元素的原始值映射到逻辑最小值与最大值之间以获得元素的值。

.physicalMin

从物理意义上预期的范围最小值。这由设备报告。例如，对于 hat switch，物理范围可能是 hat switch 所指的方向（以度为单位）。

.physicalMax

在物理意义上预期范围的最大值。这是由设备报告的。例如，对于帽形开关，物理范围可能是帽形开关所指的方向（以度为单位）。

.unit

物理范围单位的索引。

.unitExponent

物理范围的指数。

.usageMin

预期使用范围的最小值。由设备报告。仅对报告数组值的元素有意义。

.usageMax

预期使用范围的最大值。由设备报告。仅对报告数组值的元素有意义。

.getUsages(usageDict)

此方法用于获取该元素产生的所有 usage 的字典。大多数情况下一个元素只有一个 usage，但在数组元素的情况下，它会有多个用途（对于键盘，一个元素代表一次按键，但它们可以是各种不同的键）。

.reportID

此元素接收数据的报告 ID。这是一个底层的设备特定标识符

.reportSize

此元素接收数据时的报告大小（以位为单位）。这是一个低级的设备特定标识符

.reportIndex

此元素接收数据所用的报告索引。这是一个低层的设备特定标识符

示例

HID.findAvailable; // 查找可用设备
HID.postAvailable; // 输出可用设备
~myhid = HID.open(1103, 53251); // 打开设备
~myhid.postElements; // 发布可用元素
// 为第二个元素设置动作：
~myhid.elements[1].action = { |...args| args.postln };
