TWChoose

从多个输入中随机选择一个

Object

另请参阅：TChoose

说明

在从输入数组接收到触发时随机选择一个输出。

此选择的 weights 由 weights 数组确定。

如果将 normalize 设为 1，则在使用固定值时权重会被持续归一化（这会带来额外开销），此时可以使用 normalizeSum 方法来归一化这些值。

TWChoose 是 TWindex 和 Select 的组合。

类方法

TWChoose.ar(trig, array, weights, normalize: 0)

TWChoose.kr(trig, array, weights, normalize: 0)

参数：

trig

array

weights

normalize

实例方法

示例

(
{
    var a;
    a = [
            SinOsc.ar,
            Saw.ar,
            Pulse.ar
        ];
    TWChoose.ar(Dust.ar(MouseX.kr(1, 1000, 1)), a, [0.99, 0.05, 0.05].normalizeSum) * 0.2

}.play;
)

注意： 所有 ugens 都在持续运行。如果每个输入都耗费大量 cpu，这可能不是最高效的方式。
