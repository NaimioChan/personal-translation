GridLayout

一种在网格中组织视图的布局

另请参见：HLayout、VLayout、StackLayout、布局管理

说明

GridLayout 将其空间分配到一个由行和列组成的网格中，其中每个项可以占据一个或多个单元格。

你可以使用 *rows 和 *columns 以两种方式构造布局。在前一种构造方法中，你按行传入条目数组，而在后一种构造方法中则按列传入。条目也可以在之后使用 -add 和 -addSpanning 添加。若要移除某个条目，对于视图只需使用 View: -remove，对于视图或布局则使用 QObject: -destroy。

可以在同一个单元格中添加多个视图。最后添加的视图将位于最顶层。不过，为此使用 StackLayout 很可能更方便。

布局会自动管理网格尺寸：你可以在任意行和单元格编号处添加项目。当添加或移除项目时，网格会根据最后一个被占用的行和列重新调整。

微调

每个项都可以在布局构造时或之后使用 -setAlignment 指定一个对齐方式。此时项将最多获得其默认大小（如果可用，参见：View: -sizeHint），并根据指定的对齐方式在其单元格内对齐。

每一行或每一列都可以使用 -setRowStretch 和 -setColumnStretch 分配一个拉伸因子。原本会获得相等空间的行或列，将按照其拉伸因子的相对比例进行分配。

每一行或每一列还可以使用 -setMinRowHeight 和 -setMinColumnWidth 分配一个最小尺寸，以覆盖由所含视图施加的尺寸约束。

除了使用 Layout: -spacing 调整单元格之间的间距外，你还可以使用 -hSpacing 和 -vSpacing 分别控制行与行之间以及列与列之间的间距。

留出空白空间

你可以通过不向单元格中放置任何项目来保留任何空单元格，或者在构造时使用 nil 代替视图或其他布局。但请注意，空单元格将始终被视为可自由拉伸，并且不会对空间分布施加任何约束。

类方法

.rows

创建一个 GridLayout，并用作为参数给出的项目数组填充每一行。

参数：

... rows

每个参数都是一个由项目组成的数组，用于构成连续的一行。项目可以是 view、另一个 layout，或者是表示空单元格的 nil。

讨论：

你可以通过将项包装进一个数组，并在其后跟上若干对 (\rows, number) 和/或 (\columns, number)，使该项跨越多个单元格。你还可以在该项之后跟一对 (\align, alignment) 来为其指定对齐方式。\rows、\columns 和 \align 可分别缩写为 \r、\c 和 \a。可能的对齐值参见 Alignment。

将键值对放入数组的简化语法在这里很方便（参见 语法快捷方式：使用键值对创建数组 及下面的示例）。

Example:

(
w = Window().layout_(GridLayout.rows(
    [Slider2D(), Slider2D(), [Slider(), rows: 2]],
    [Slider2D(), Slider2D()],
    [[Slider().orientation_(\horizontal), columns: 2]]
)).front;
)

.columns

创建一个 GridLayout，并用作为参数给出的项目数组填充每一列。

参数：

... cols

每个参数都是一个 Array，其中的项组成连续的列。项可以是 view、另一个 layout，或 nil 表示空单元格。

讨论：

要使某个项跨多个单元格，或者为其指定对齐方式，适用与 *rows 相同的说明。

实例方法

.add

在指定行和列的单元格中添加一项。

参数：

item

该项可以是一个 视图 或另一个 布局。

row

行索引。

column

列索引。

align

表示对齐方式的符号，或 nil。可能的值请参阅 Alignment。

.addSpanning

将一项添加到网格中，使其占据多个单元格。

参数：

item

该项可以是一个 视图 或另一个 布局。

row

行索引。

column

列索引。

rowSpan

在垂直方向上占用的单元格数量。

columnSpan

在水平方向上占用的单元格数量。

align

表示对齐方式的符号，或 nil。可能的值请参阅 Alignment。

.hSpacing

列之间的间距，以整数像素数表示。

.vSpacing

行之间的间距，以整数像素数表示。

.setRowStretch

设置行的拉伸因子。默认情况下行的拉伸因子为 0。如果为某行分配了更大的因子，行将根据其因子的相对比例重新分配空间。

参数：

row

行的索引。

factor

一个 Integer。

.setColumnStretch

设置列的拉伸因子。默认情况下列的拉伸因子为 0。若为某列分配更大的因子，各列将按其因子相对比例重新分配空间。

参数：

column

列的索引。

factor

一个 Integer。

.setAlignment

设置由布局管理的项的对齐方式。

参数：

item

由此布局管理的视图或布局，或一个 Point，其 x 表示项的列索引，y 表示行索引。

align

表示对齐方式的符号。可能的值请参见 Alignment。

.minRowHeight

获取分配给某一行的最小高度。

参数：

row

行的索引。

.setMinRowHeight

设置行的最小高度。

参数：

row

行的索引。

height

以像素为单位的整数数量。

.minColumnWidth

获取分配给某列的最小宽度。

参数：

column

列的索引。

.setMinColumnWidth

设置列的最小宽度。

参数：

column

列的索引。

width

以像素为单位的整数数量。
