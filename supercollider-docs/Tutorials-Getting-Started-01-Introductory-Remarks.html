SuperCollider 入门

以下文本旨在作为 SuperCollider 3 的入门介绍，这是一种用于声音合成和数字信号处理（DSP）的面向对象语言。本教程不要求具备计算机科学背景，但假定你对计算机及其操作系统有基本了解，并具备声学和数字音频的基础知识。（这里我假定 frequency 和 sample 这样的词不会引起任何混淆。）

本教程是从 macOS 的视角编写的，但其中大部分内容也应适用于 Linux 和 Windows。具体有所不同的部分主要与 GUI（图形用户界面）方面有关。

我必须承认，本教程在有限意义上才算是“由”我编写。在编写过程中，我自由地参考了由多人编写的通用文档。本文档并不打算取代那些（通常更为详细的）资料，并不断引导读者参阅它们以获取更多信息。

按键组合

在本文中，你会看到类似 "Ctrl-Enter" 和 "Cmd-Enter" 的文本。这些是组合键。它们的意思是：按住第一个键，然后按下第二个键（同时仍按住第一个键）。

例如："Ctrl-Enter" 是 "Ctrl" 键和 "Enter" 键的组合键。它的意思是：按住 "Ctrl" 键，然后在保持 "Ctrl" 键按下的同时，按下 "Enter" 键。当两个键同时按下后，你可以松开两个键。

"Ctrl" 是大多数 Windows 和 Linux 计算机上的一个键。Mac 计算机也有 "Ctrl" 键，但当同一指令给出多个按键组合时，以 "Cmd" 开头的组合是供 Mac 用户使用的。"Cmd" 是 "command" 的缩写，即带有 "⌘" 的键。

对于包含 3 个或更多按键的组合键，请按住除最后一个键之外的所有键，然后按最后一个键。例如，"Ctrl-Shift-P" 表示：先按住 "Ctrl" 和 "Shift" 键，然后在仍按住 "Ctrl" 和 "Shift" 的情况下按 "P" 键。

代码示例

正文中的代码示例使用不同的字体：

{ [SinOsc.ar(440, 0, 0.2), SinOsc.ar(442, 0, 0.2)] }.play;

这是计算机语言文档中的常见惯例，SC 的文档中也始终遵循这一惯例。你在代码中看到的不同颜色只是为了让内容更清晰，对代码的功能没有任何影响。

建议你把代码示例复制到另一个窗口并尝试修改它们。这是学习一门新计算机语言的经典方法！SC 允许你修改原始教程文档，但如果你这样做，应注意不要保存它们（例如在关闭它们时若弹出提示）。在修改之前先把内容复制到新文档中是最安全的。
