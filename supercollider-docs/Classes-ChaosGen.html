ChaosGen

引发混沌的 UGen

UGen : AbstractFunction : Object

子类：CuspN、FBSineN、GbmanN、HenonN、

说明

"ChaosGen" 是一个抽象类——换句话说，是一个不直接使用的类。而应使用它的某个子类。各种类都继承自这个抽象类，包括 HenonN、LinCongL、LatoocarfianL、GbmanL、CuspL、StandardL 等等。

这些混沌 UGen 通常各自代表一组确定性方程，可以采用不同的起始参数。这些方程定义了一个系统，其随时间的演化对初始条件高度敏感，并且可以表现出极其复杂的行为。

要了解更多，请从这里开始：http://en.wikipedia.org/wiki/Chaos_theory

要查看所有派生自 ChaosGen 类的类，请运行以下行：

ChaosGen.allSubclasses.do(_.postln)
