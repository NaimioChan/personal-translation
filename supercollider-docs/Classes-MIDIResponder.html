MIDIResponder

注册多个函数，在 MIDI 事件发生时求值

Object

另请参阅：MIDIFunc、MIDIdef、MIDIIn、MIDI、Using MIDI

子类：CCResponder、NoteOnResponder、ProgramChangeResponder、TouchResponder

说明

注意： SC 3.5 新增了 MIDIFunc 和 MIDIdef 类。它们速度更快，旨在提供更方便、更合乎逻辑且更一致的接口，与 OSCFunc 和 OSCdef 共享共同的设计。它们还支持所有 MIDI 消息类型。

MIDIResponder 是一个抽象类。其子类允许注册函数以响应 MIDI 事件。

请在此阅读通用帮助文件，然后查看各个帮助文件。

function

当传入的 MIDI 事件与响应者匹配时要执行的函数。该函数接受参数 src、chan、A、B（对于 Bend、ProgramChange 和 Touch 则为：src、chan、value）。

src

如果给定一个数字，响应器将仅对来自此端口传入的消息触发。该数字可以是系统 UID（从 MIDIClient.sources[index].uid 获取）或索引本身。如果为 nil，响应器将匹配任何端口。

chan

要匹配的 MIDI 通道。

num

要匹配的控制或音符编号。

value

要匹配的值。

veloc

要匹配的速度。

install

如果为 true，则自动安装响应器，使其处于活动状态并准备好响应。如果为 false，则它将处于非活动状态。

swallowEvent

如果为 true，则一旦匹配到该 midi 事件，就停止测试任何后续响应器。例如，如果一个 CCResponder 匹配了 port、chan 和 num，并且 swallowEvent 被设为 true，那么就不会再向其他 CCResponder 提供响应该事件的机会。该事件被“吞掉”了。默认情况下此为 false。请注意，这样做会阻止该类型的任何其他响应器进行响应，包括在类中于幕后添加的响应器。另请注意，此功能对响应器的添加顺序敏感。

任何匹配的值可以是以下之一：

Nil

匹配任何内容。例如，如果 chan 为 nil，则响应任何 MIDI 通道。

Integer

仅匹配此特定数字。

Array

匹配数组中的任意项。任何类型的 Collection 都可以在此使用。

Function

以传入的值作为参数对函数进行求值。该函数应返回 true 或 false。

例如，以下示例将只响应来自任意端口、仅通道 2 和 7、仅偶数音符编号以及仅力度值大于 50 的 note on 消息。

NoteOnResponder({ |src, chan, num, vel| [src, chan, num, vel].postln },
    nil,    // 任意端口
    [2, 7],    // 仅限 MIDI 通道 2 或 7
    (0, 2..126),    // 这是一个偶数数组。也可以写成 { |num| num.even } 或 _.even
    { |vel| vel > 50 });    // 速度大于 50

MIDIResponder 会自动用 1 个标准设备初始化 MIDIClient。这意味着你第一次安装任何 MIDIResponder 时，它会确保 MIDI 已被初始化。如果你有更多设备或特定设置，只需在使用任何 MIDIResponder 之前自行初始化 MIDIClient。

Removal

只需在响应者上调用 .remove。

c = CCResponder({ ... }, num: 1);    // 响应任意调制轮

c.remove;        // 停止此响应器

或者移除某个特定类的所有实例：

CCResponder.removeAll
NoteOnResponder.removeAll
NoteOffResponder.removeAll
BendResponder.removeAll
TouchResponder.removeAll
ProgramChange.removeAll

或移除所有类中的所有 midi 响应器：

MIDIResponder.removeAll
