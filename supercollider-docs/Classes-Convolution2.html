Convolution2

实时固定内核卷积器。

UGen : AbstractFunction : Object

另请参阅：Convolution、Convolution2L、Convolution3

说明

使用固定核进行严格卷积，可通过触发信号更新该核。

在内部，该单元使用 FFT 来加速计算，这意味着 (a) 你必须指定“framesize”，并且 (b) 如果核长于该 framesize，其末尾部分将被忽略。

另请参见 Steven W. Smith 的 http://www.dspguide.com/ch18.htm。

类方法

Convolution2.ar(in, kernel, trigger: 0, framesize: 2048, mul: 1.0, add: 0.0)

参数：

in

处理目标。

kernel

固定核的缓冲区索引，可以与触发组合进行调制。其大小必须 <= framesize。

trigger

在从非正值变为正值时更新内核。

framesize

FFT 帧的大小，必须是 2 的幂（512、1024、2048、4096 是常用选择）。卷积在内部使用该数值的两倍。请注意，随着幂次提高，卷积的运行开销会逐渐增大！可用的最大值为 2^16 = 16384。（此上限是 SC 源代码中定义的 "SC_FFT_MAXSIZE" 的一半。）比这更大的卷积可以使用 PartConv 完成。

mul

add

不必像第一个例子那样自己触发内核更新，你可以改用 UGen 触发信号来完成。在下一个例子中，我们使用两个 Convolution2 UGen 来连续、平滑地改变脉冲响应：RecordBuf 每隔 trigPeriod 秒录制一次随机频率的 Saw 振荡器。录制结束后紧接着（trigPeriod 借助 TDelay UGen 被延迟了缓冲区时长 BufDur），两个卷积 UGen 交替更新各自的内核（使用两个触发器 convTrigs）。在内核更新的频率上，交叉淡化器 XFade2 在 conv1 与 conv2 之间移动，它使用一个频率为触发频率一半的三角振荡器 LFTri 作为声像输入。结果就是 Dust 脉冲获得不断变化的频谱染色：

b = Buffer.alloc(s, 2048, 1, _.zeroMsg);
(
x = { |i_kernel, density = 100, trigPeriod = 5.0, cutOff = 1000, minFreq = 200, maxFreq = 2000|
    var input, trigFreq, recTrig, irSig, convTrig, convTrigs, bufFrames, conv1, conv2;
    
    input = LPF.ar(Dust2.ar(density), cutOff);
    trigFreq = trigPeriod.reciprocal;
    recTrig = Impulse.kr(trigFreq);
    irSig = Saw.ar(TExpRand.kr(minFreq, maxFreq, recTrig), 0.4);
    RecordBuf.ar(irSig, i_kernel, recTrig, loop: 0, trigger: recTrig);
    
    convTrig = TDelay.kr(recTrig, BufDur.ir(i_kernel));
    // 将更新拆分到两个触发上。 
    // 注意 [1, 0] 会创建 MultiChannel 扩展！
    convTrigs = PulseDivider.kr(convTrig, 2, [1, 0]);
    
    bufFrames = BufFrames.ir(i_kernel);
    // create the two alternatingly updated convolution ugens
    #conv1, conv2 = Convolution2.ar(input, i_kernel, convTrigs, bufFrames);
    
    XFade2.ar(conv1, conv2, LFTri.kr(trigFreq * 0.5, 1)) ! 2;
    
}.play(s, [\i_kernel, b]);
)

x.set(\trigPeriod, 0.1);    // 快速变化
x.set(\trigPeriod, 10.0);    // 缓慢变化
x.free;    // 删除 synth
