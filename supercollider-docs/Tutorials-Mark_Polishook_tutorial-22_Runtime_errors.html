运行时错误

运行时错误发生在程序执行期间。

常见错误

  1. 一个对象收到了一条它无法理解的消息
  2. 无法执行二元运算（加法、减法、乘法等）
  3. 条件（布尔）测试中出现 true 或 false 以外的值
  4. 文件无法打开（原语失败）

未初始化的变量（二元运算失败）

这里，变量 a 被初始化为一个整数，而变量 b 未被初始化。将 a（整数 10）乘以 b（nil，即 SuperCollider 用于未初始化数据的值）将产生运行时错误。

(
var a = 10;    // a 已声明并初始化
var b;        // b 已声明但未初始化，因此默认为 nil

t = Task({

    4.do({ arg item, i;

        if(i != 3)
            { i.postln }         // 如果 i 不等于 3，则打印 i 的值
            { (a * b).postln };    // 当 i 等于 3 时，执行 a * b
                        // ... 如果 b 为 nil，这会是个问题
        1.wait;

    })

});
t.start;
)

////////////////////////////////////////////////////////////////////////////////////////////////////

打印输出显示，代码一直成功运行到索引 i 达到 3 时，此时执行了 * b。ERROR、RECEIVER、ARGS 和 CALL STACK 标题描述了该问题。

if(x==4) { "this is ok"};

f.length;
