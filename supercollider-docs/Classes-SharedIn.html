SharedIn

从共享控制总线读取。

AbstractIn : MultiOutUGen : UGen : AbstractFunction : Object

参见：SharedOut

说明

警告： SharedIn 已被废弃。通过 Bus: -getSynchronous 和 Bus: -setSynchronous 可以同步访问本地服务器上的总线。

从内部服务器与 SC 客户端之间共享的控制总线读取。仅限控制速率。从客户端写入共享控制总线是同步的。当不使用内部服务器时，请使用节点参数或 Bus 的 set 方法（或消息传递风格的 /c_set）。

类方法

SharedIn.kr(bus: 0, numChannels: 1)

参数：

bus

要读取的共享控制总线的索引。

numChannels

要读取的通道数（即相邻的总线）。默认值为 1。你不能通过在 SynthDef 中将其赋值给参数来调制此数字。

实例方法

示例

(
// 仅适用于内部服务器
s = Server.internal;
s.boot;
)

(
SynthDef("help-SharedIn1", {
    Out.ar(0, SinOsc.ar(Lag.kr(SharedIn.kr(0, 1), 0.01), 0, 0.2));
}).add;
SynthDef("help-SharedIn2", {
    Out.ar(1, SinOsc.ar(Lag.kr(SharedIn.kr(0, 1), 0.01, 1.5), 0, 0.2));
}).add;
)

(
s.setSharedControl(0, 300); // 一个初始值
s.sendMsg(\s_new, "help-SharedIn1", x = s.nextNodeID, 0, 1);
s.sendMsg(\s_new, "help-SharedIn2", y = s.nextNodeID, 0, 1);

Routine({
    30.do({
        s.setSharedControl(0, 300 * (10.rand + 1));
        0.2.wait;
    });
    s.sendMsg(\n_free, x);
    s.sendMsg(\n_free, y);
}).play;
)


s.quit;
