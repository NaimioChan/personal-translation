如何使用模式控制 midi 事件

关于 midi 命令以及如何将它们与 Pbind 等一起使用的概述。

本文档简要概述了 Event 的 midievent 部分中可用的一些常用 midi 命令及其提供的参数。

要在诸如 Pbind 的事件模式中使用它们，你需要先初始化一个 MIDI 输出设备。

// 这会发布可用 MIDI 设备的列表
// 记下它们的名称和总线名称，并在下一步中使用它们
MIDIClient.init;

// 使用名称和总线名称初始化一个 midi 输出（见上文）
// 例如：
m = MIDIOut.newByName("IAC Driver", "Bus 1");

在下面的示例中，假定你已初始化了一个 MIDI 输出。

注意： SuperCollider 中的所有 midi 编号都是从 0 开始索引的。也就是说，在大多数设备上称为 "midi channel 1" 的，在 SuperCollider 中实际上是 midi channel 0，反之亦然。

现在，在 Pbind 中使用它：

p = Pbind(
    // 这些键是所有 MIDI 命令共有的
    \type, \midi,
    \midiout, m,
    \midicmd, \noteOn, // 选择要使用的命令

    \chan, 0,
    // degree 被转换为 midinote，而不仅仅是频率
    \degree, Pwhite(-7, 12, inf),
    \dur, Pwrand([0.25, Pn(0.125, 2)], #[0.8, 0.2], inf),
    \legato, sin(Ptime(inf) * 0.5).linexp(-1, 1, 1/3, 3),
    \amp, Pexprand(0.5, 1.0, inf)
).play(quant: 1);
)

p.stop;

\noteOn 和 \noteOff

最常见的 midi 命令是 \noteOn 和 \noteOff。它们用于演奏音符。当你使用 \noteOn 命令时，\noteOff 会在音符时值结束后自动发送。

p = Pbind(
    // 这些键是所有 MIDI 命令共有的
    \type, \midi,
    \midiout, m,
    \midicmd, \noteOn, // 选择要使用的命令

    \chan, 0,
    // degree 被转换为 midinote，而不仅仅是频率
    \degree, Pwhite(-7, 12, inf),
    \dur, Pseq([1,2,0.5], inf),
    // amp 被转换为 velocity
    \amp, Pexprand(0.5, 1.0, inf)
).play(quant: 1);
)

p.stop;

控制变化

发送控制变化消息。

p = Pbind(
    // 这些键是所有 MIDI 命令共有的
    \type, \midi,
    \midiout, m,
    \midicmd, \control,

    \chan, 0,
    \ctlNum, 0, // cc 编号
    \control, Pwhite(0, 127, inf), // cc 值
    \dur, Pseq([1,2,0.5], inf),

).play(quant: 1);
)

p.stop;

\polyTouch

p = Pbind(
    // 这些键是所有 MIDI 命令共有的
    \type, \midi,
    \midiout, m,
    \midicmd, \polyTouch,

    \chan, 0,
    \midinote, Pwhite(0, 127, inf), // 音符号
    \polyTouch, Pwhite(0, 127, inf), // 压力值
    \dur, Pseq([1,2,0.5], inf),

).play(quant: 1);
)

p = Pbind(

\touch

发送触后消息。

p = Pbind(
    // 这些键是所有 MIDI 命令共有的
    \type, \midi,
    \midiout, m,
    \midicmd, \touch,

    \chan, 0,
    \touch, Pwhite(0, 127, inf), // 压力值
    \dur, Pseq([1,2,0.5], inf),

).play(quant: 1);
)

\bend

p = Pbind(
    // 这些键是所有 MIDI 命令共有的
    \type, \midi,
    \midiout, m,
    \midicmd, \bend,

    \chan, 0,
    \bend, Pwhite(0, 8191, inf), // bend 值

\sysex

发送一条 sysex 消息。

p = Pbind(
    // 这些键是所有 MIDI 命令共有的
    \type, \midi,
    \midiout, m,
    \midicmd, \sysex,

    \sysex, Int8Array[0xF0, 0x7D, 0x00, 0x00, 0x04, 0x01, 0x60, 0x00, 0xF7], // sysex 消息
    \dur, 8,

).play(quant: 1);
)
