TWindex

触发的 windex。

UGen : AbstractFunction : Object

说明

当触发时，返回一个随机索引值，以 array 作为概率列表。默认情况下，概率列表的总和应为 1.0；当 normalize 标志设置为 1 时，值会由 UGen 进行归一化（效率较低）。

类方法

TWindex.ar(in, array, normalize: 0)

TWindex.kr(in, array, normalize: 0)

参数：

in

触发信号。触发信号可以是任意信号。当信号从非正变为正时，触发发生。

array

概率列表。（注意：这些应仅为控制速率。）

normalize

控制是否对概率值进行归一化。（仅限控制速率。）

实例方法

示例

// 假设为归一化值
(
a = SynthDef("help-TWindex", { |out, w1 = 0.0, w2 = 0.5, w3 = 0.5|
    var trig = Impulse.kr(6);
    var index = TWindex.kr(trig, [w1, w2, w3]);
    Out.ar(out,
        SinOsc.ar(
            Select.kr(index, [400, 500, 600]),
            0, 0.2
        )
    )
}).play;
)

a.setn(0, [0, 0, 1].normalizeSum);
a.setn(0, [1, 1, 1].normalizeSum);
a.setn(0, [1, 0, 1].normalizeSum);


// 调制概率值
(

a = SynthDef("help-TWindex", { |out, w1 = 0.0, w2 = 0.5|
    var trig = Impulse.kr(6);
    var index = TWindex.kr(
        trig,
        [w1, w2, SinOsc.kr(0.3, 0, 0.5, 0.5)], // 调制概率
        1 // 进行归一化
    );

    Out.ar(out,
        SinOsc.ar(
            Select.kr(index, [400, 500, 600]),
            0, 0.2
        )
    )
}).play;

)

a.setn(0, [0, 0]);
a.setn(0, [1, 1]);
a.setn(0, [1, 0]);
a.setn(0, [0, 1]);
