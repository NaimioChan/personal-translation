LFCub

由两段三次曲线构成的类正弦形状

LFSaw : PureUGen : UGen : AbstractFunction : Object

另见：LFPar、LFPulse、LFSaw、LFTri

说明

由两段三次曲线构成的正弦状波形。比 LFPar 更平滑。

类方法

LFCub.ar(freq: 440.0, iphase: 0.0, mul: 1.0, add: 0.0)

来自父类：LFSaw

LFCub.kr(freq: 440.0, iphase: 0.0, mul: 1.0, add: 0.0)

来自父类：LFSaw

参数：

freq

频率，单位为赫兹。

iphase

初始相位偏移。出于效率考虑，该值范围为 0 到 2。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

{ LFCub.ar(LFCub.kr(LFCub.kr(0.2, 0, 8, 10), 0, 400, 800), 0, 0.1) }.play
{ LFCub.ar(LFCub.kr(0.2, 0, 400, 800), 0, 0.1) }.play
{ LFCub.ar(800, 0, 0.1) }.play
{ LFCub.ar(XLine.kr(100, 8000, 30), 0, 0.1) }.play

// 比较：
