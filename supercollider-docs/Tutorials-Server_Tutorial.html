服务器教程

涵盖许多概念的简短教程

要学习本教程，你应该阅读

服务器架构

and

服务器命令参考。

SuperCollider 由三个独立的部分组成：声音合成器（音频服务器）、编程语言（以及语言解释器）和代码编辑器（集成开发环境，简称 IDE）。

服务器既可以运行在语言应用程序内部（“内部服务器”），也可以作为同一台机器上的独立程序运行（“本地服务器”），还可以通过 网络连接运行在不同的计算机上。语言应用程序使用 Open Sound Control 协议的一个子集向服务器发送命令消息。

启动服务器

为了运行声音，我们需要启动一个正在运行的服务器。启动服务器最简单的方法是在 IDE 编辑器窗口底部的服务器状态字段上点击，在弹出的菜单中点击 "Boot Server"。或者点击相应服务器窗口中的 "Start Server" 按钮。对于你创建的任何服务器对象，可以通过 s.makeWindow（例如对默认服务器）获得该窗口（见下文）。但有时以编程方式启动服务器也很有用。为此，我们需要获取或创建一个服务器对象，并告诉它 "boot"。有两个预定义的服务器：internal 和 local。

内部服务器与 SuperCollider 应用程序运行在同一进程中。它是程序本身的内部组成部分。

// 将解释器变量 i 设置为内部服务器对象。
i = Server.internal;

非常重要：必须执行这一行，变量 'i' 才会被设置。具体机制因平台而异。macOS 的标准做法是将光标置于该行任意位置，然后按小键盘上的“Enter”键。按主回车键不会执行代码！这使你能够编写多行代码片段。要执行多行代码块，请选中该块并按“Enter”。为方便起见，可将代码块括在圆括号中，然后在任一侧圆括号内双击即可选中整个块。有关其他编辑器（如 Linux 或 Windows 上）的说明，请查阅该平台特定的文档。其他编辑器中的按键命令另请参阅帮助文件 Keyboard Shortcuts。如果没有 Enter 键，则可以使用 Ctrl-Return、Ctrl-C、Fn-Return（某些 Mac 上）或 Shift-Return。

本地服务器与 SuperCollider 应用程序运行在同一台机器上，但它是一个单独的程序，即 'scsynth'（或 'supernova'）。

注意： 默认情况下，解释器变量 s 在启动时被设置为本地服务器。有关更多信息，请参阅 Server 帮助文件。

// 将解释器变量 s 设置为本地服务器对象。
s = Server.local;    // s 在 SuperCollider 启动时被设置为 Server.default

要启动服务器，你向它发送 boot 消息。

s.boot;

要退出服务器，向其发送 quit 消息。

s.quit;

我们也可以创建一个要运行的服务器。要创建服务器对象，我们需要提供服务器的 IP 地址和一个端口号。端口号在某种程度上是任意的，但它们不应与 telnet、ftp、http 等常见协议冲突。IP 地址 127.0.0.1 被定义为表示本地主机。这是在你自己的机器上运行服务器时应使用的 IP 地址。

// 创建另一个服务器对象，它将在本地主机上使用端口 #58009 运行
m = Server(\myServer, NetAddr("127.0.0.1", 58009));

m.boot; //启动服务器

m.quit; // 退出服务器

无法在远程机器上启动服务器，但如果已有一台正在运行，或者你知道有一台正在运行，就可以向它发送消息。你使用运行服务器的机器的 IP 地址及其正在使用的端口来创建服务器对象。

// 创建一个服务器对象，用于与运行在
// 远程机器上的服务器通信，该机器 IP 地址为 192.168.0.47，使用端口 #57110
r = Server(\myServer, NetAddr("192.168.0.47", 57110));

发声

（注意：本教程使用 Server Command Reference 中描述的原始 OSC 命令，而不是 Synth 和 Group 类。有关使用 Synth 的一些更简单的方法，也请参阅这些帮助文件。本教程解释 Synth 和 SynthDef 的基本底层设计。）

现在让我们制作一些音频。

启动服务器：

s.boot;

创建一个 SynthDef。SynthDef 是对要在服务器上运行的信号处理模块的描述。它可以从服务器的音频总线读取音频、从控制总线读取控制信号，并将控制信号或音频写回总线。这里我们将创建一个正弦振荡器，并将其发送到音频总线零。

(
SynthDef("sine", { arg freq=800;
    var osc;
    osc = SinOsc.ar(freq, 0, 0.1); // 800 Hz 正弦振荡器
    Out.ar(0, osc); // 将输出发送到音频总线零。
}).writeDefFile; // 将 def 写入磁盘的默认目录 synthdefs/
)

将 SynthDef 发送到服务器。

s.sendSynthDef("sine");

启动声音。/s_new 命令会创建一个新的 Synth，它是 "sine" SynthDef 的一个实例。在服务器上运行的每个 synth 都需要有唯一的 ID。最简单且最安全的方法是从服务器的 NodeIDAllocator 获取一个 ID。这会自动允许 ID 被重用，并防止与你自己的节点以及为视觉作用域和录制等目的自动创建的节点发生冲突。每个 synth 都需要安装在一个 Group 中。我们将其安装在组 1 中，这是默认组。还有一个组 0，称为 RootNode，它包含默认组，但通常最好不要使用它，因为这样做可能会导致与上述自动创建的节点发生执行顺序问题。（更多细节请参见 Default Group、RootNode 和 Order of execution 帮助文件。）

s.sendMsg("/s_new", "sine", x = s.nextNodeID, 1, 1);

停止声音。

s.sendMsg("/n_free", x);

停止服务器。

s.quit;

SynthDef 有三个方法，它们会自动发送 def：load 将其写入磁盘，send 则发送它而不写入磁盘。后者可用于避免磁盘杂乱，但仅限于不超过一定复杂度的 SynthDef。

最普遍有用且推荐的是使用 add 方法，它仅在无法发送时才发送或写入磁盘，并且会发送到 SynthDefLib 中列出的所有服务器（可以通过 SynthDescLib.global.addServer(server) 添加服务器）。

(
SynthDef("sine", { arg freq=800;
    var osc;
    osc = SinOsc.ar(freq, 0, 0.1); // 800 Hz 正弦振荡器
    Out.ar(0, osc); // 将输出发送到音频总线零。
}).add;
)


(
SynthDef("sine", { arg freq=800;
    var osc;
    osc = SinOsc.ar(freq, 0, 0.1); // 800 Hz 正弦振荡器
    Out.ar(0, osc); // 将输出发送到音频总线零。
}).load(s); // 写入磁盘并发送
)

(
SynthDef("sine", { arg freq=800;
    var osc;
    osc = SinOsc.ar(freq, 0, 0.1); // 800 Hz 正弦振荡器
    Out.ar(0, osc); // 将输出发送到音频总线零。
}).send(s); // 发送而不写入
)

使用参数

在创建 synth 时能够指定其参数是很有用的。这里向 sine SynthDef 添加了一个 frequency 参数，以便我们可以创建它

s.boot;

(
SynthDef("sine", { arg freq;
    var osc;
    osc = SinOsc.ar(freq, 0, 0.1); // 800 Hz 正弦振荡器
    Out.ar(0, osc); // 将输出发送到音频总线零。
}).add;
)

播放一个 900 Hz 的正弦波。

s.sendMsg("/s_new", "sine", x = s.nextNodeID, 1, 1, "freq", 900);

s.sendMsg("/n_free", x);

播放一个 1000 Hz 正弦波。

s.sendMsg("/s_new", "sine", y = s.nextNodeID, 1, 1, "freq", 1000);

s.sendMsg("/n_free", y);

同时播放三个声部

(
s.sendMsg("/s_new", "sine", x = s.nextNodeID, 1, 1, "freq", 800);
s.sendMsg("/s_new", "sine", y = s.nextNodeID, 1, 1, "freq", 1001);
s.sendMsg("/s_new", "sine", z = s.nextNodeID, 1, 1, "freq", 1202);
)

(
s.sendMsg("/n_free", x);
s.sendMsg("/n_free", y);
s.sendMsg("/n_free", z);
)

使用 bundle 同时播放三个声部。Bundle 允许你发送带有时间戳的多条消息。bundle 中的消息将被调度在一起执行。sendBundle 的时间参数是一个相对于当前线程逻辑时间的未来偏移量。

(
s.sendBundle(0.2,
    ["/s_new", "sine", x = s.nextNodeID, 1, 1, "freq", 800],
    ["/s_new", "sine", y = s.nextNodeID, 1, 1, "freq", 1001],
    ["/s_new", "sine", z = s.nextNodeID, 1, 1, "freq", 1202]);
s.sendBundle(1.2, ["/n_free", x],["/n_free", y],["/n_free", z]);
)

控制 Synth

你可以发送消息来更新 Synth 参数的值。

播放一个 900 Hz 的正弦波。

s.sendMsg("/s_new", "sine", x = s.nextNodeID, 1, 1, "freq", 900);

使用 /n_set 命令更改频率。您需要发送节点 ID、参数名和值。

s.sendMsg("/n_set", x, "freq", 800);

s.sendMsg("/n_set", x, "freq", 700);

s.sendMsg("/n_free", x);

动态添加效果

你可以动态地添加和移除效果器来处理另一个 synth。为此，效果器必须添加在被处理的节点之后。

(
// 定义一个噪声脉冲
SynthDef("tish", { arg freq = 1200, rate = 2;
    var osc, trg;
    trg = Decay2.ar(Impulse.ar(rate,0,0.3), 0.01, 0.3);
    osc = {WhiteNoise.ar(trg)}.dup;
    Out.ar(0, osc); // 将输出发送到音频总线零。
}).add;
)

(
// 定义一个回声效果
SynthDef("echo", { arg delay = 0.2, decay = 4;
    var in;
    in = In.ar(0,2);
    // 使用 ReplaceOut 覆盖总线之前的内容。
    ReplaceOut.ar(0, CombN.ar(in, 0.5, delay, decay, 1, in));
}).add;
)

// 启动脉冲
s.sendMsg("/s_new", "tish", x = s.nextNodeID, 1, 1, \freq, 200, \rate, 1.2);

// 添加一个效果
s.sendMsg("/s_new", "echo", y = s.nextNodeID, 1, 1);

// 停止效果
s.sendMsg("/n_free", y);

// 添加一个效果（time has come today.. hey!）
s.sendMsg("/s_new", "echo", z = s.nextNodeID, 1, 1, \delay, 0.1, \decay, 4);

// 停止效果
s.sendMsg("/n_free", z);

// 停止脉冲
s.sendMsg("/n_free", x);

这样可行的原因是我们将效果添加到了另一个节点之后。有时你需要使用组或 /n_after 来确保效果被添加在它应当处理的节点之后。

将参数映射到控制总线

(
// 定义一个控件
SynthDef("line", { arg i_bus=10, i_start=1000, i_end=500, i_time=1;
    ReplaceOut.kr(i_bus, Line.kr(i_start, i_end, i_time, doneAction: Done.freeSelf));
}).add
)

播放一个 900 Hz 的正弦波。

s.sendMsg("/s_new", "sine", x = s.nextNodeID, 1, 1, "freq", 900);

将一个频率值放到控制总线上。

s.sendMsg("/c_set", 10, x);

将节点的 freq 参数映射为从控制总线 #10 读取。

s.sendMsg("/n_map", x, \freq, 10);

更改控制总线上的值。

s.sendMsg("/c_set", 10, 1200);

启动一个写入总线 #10 的控制进程。EnvGen 的 doneAction 将在该节点完成时自动释放它。

s.sendMsg("/s_new", "line", s.nextNodeID, 0, 1);

释放节点。

s.sendMsg("/n_free", x);

使用例程进行序列编排

(
var space, offset, timer, saw, envsaw, sampler, delay;

SynthDef("saw", { arg out=100, pan=0, trig=0.0, freq=500, amp=1, cutoff=10000, rezz=1;
    freq = Lag.kr(freq,0.1);
    Out.ar(out,Pan2.ar(RLPF.ar(Saw.ar([freq,freq*2],amp),cutoff,rezz),
        pan));
}).add;

SynthDef("envsaw",{ arg out=100, pan=0, sustain=0.5, freq=500, amp=1, cutoff=10000, rezz=1;
    var env;
    env = EnvGen.kr(Env.perc(0.01, sustain, 0.2), doneAction: Done.none, gate:amp);
    Out.ar(out,Pan2.ar(RLPF.ar(Saw.ar(Lag.kr(freq,0.1),env),cutoff,rezz)*amp,
        pan));
}).add;

SynthDef("delay", { arg out=0, delay = 0.4, decay = 14;
    var in;
    in = In.ar(out,2);
    Out.ar(out, CombN.ar(in, 0.5, delay, decay, 1, in));
}).add;

SynthDef("sampler",{ arg sample, trig=1,rate=1.0,out=0,bufnum=0,pan=0,amp=1, sustain=0.25;
    var env;
    env = EnvGen.kr(Env.perc(0.001, sustain, 0.001), doneAction: Done.freeSelf);
    Out.ar(out,
        Pan2.ar(
        PlayBuf.ar(1,bufnum,rate,InTrig.kr(trig),0,0)*amp,
            pan);
    )
}).add;

Tempo.bpm = 120;
timer = BeatSched.new;
offset = Tempo.tempo.reciprocal;

space = Buffer.read(s, ExampleFiles.child);

saw = Synth("saw");
delay = Synth.after(saw,"delay", [\decay, 20]);

timer.sched(0,{
    var r;
    r = Routine({ var wait, freq, cutoff,rezz;
        wait = Pseq([2],inf).asStream;
        freq = Pseq([30,40,42,40],inf).asStream;
        cutoff = Pfunc({500.rand2+1000}).asStream;
        rezz = 0.5;
        inf.do({
            saw.set("freq", freq.next.midicps, "cutoff", cutoff.next, "rezz", rezz, "amp", 0.1, "out", 0);
            (wait.next*offset).wait
        });
    });
    timer.sched(0, r);
});

timer.sched(0,{
    var r;
    r=Routine({ var wait, rate;
        wait = Pseq([0.25],inf).asStream;
        rate = Pfunc({0.5.rand}).asStream;
        inf.do({
            Synth.before(delay, "sampler", [\bufnum, space, \trig, 1, \amp,0.1, \rate, rate.next, \sustain,         wait.next]);
            (wait.next*offset).wait});});
        timer.sched(0,r);
});

)

使用模式进行序列编排

(
//伤感的情绪化电子音乐示例……
Tempo.bpm = 120;
SynthDef("patternefx_Ex", { arg out, in;
    var audio, efx;
    audio = In.ar([20,21],2);
    efx=CombN.ar(audio, 0.5, [0.24,0.4], 2, 1);
    Out.ar([0,1], audio+efx);
    }).add;

Synth.new("patternefx_Ex");

SynthDef("pattern_Ex", { arg out, freq = 1000, gate = 1, pan = 0, cut = 4000, rez = 0.8, amp = 1;
    Out.ar(out,
        Pan2.ar(
            RLPF.ar(
                Pulse.ar(freq,0.05),
            cut, rez),
        pan) * EnvGen.kr(Env.linen(0.01, 1, 0.3), gate, amp, doneAction: Done.freeSelf);
    )
    }).add;

SynthDef("bass_Ex", { arg out, freq = 1000, gate = 1, pan = 0, cut = 4000, rez = 0.8, amp = 1;
    Out.ar(out,
        Pan2.ar(
            RLPF.ar(
                SinOsc.ar(freq,0.05),
            cut, rez),
        pan) * EnvGen.kr(Env.linen(0.01, 1, 0.3), gate, amp, doneAction: Done.freeSelf);
    )
    }).add;

SynthDescLib.global.read;


Pseq([

Ptpar([
0,Pbind(\instrument,\pattern_Ex, \out, 20, \dur,Pseq([2],16), \root,[-24,-17], \degree,Pseq([0,3,5,7,9,11,5,1],2),     \pan,1,\cut,Pxrand([1000,500,2000,300],16), \rez,Pfunc({0.7.rand +0.3}), \amp,0.12),

0.5,Pbind(\instrument,\pattern_Ex, \out, 20, \dur,Pseq([Pseq([2],15),1.5],1), \root,-12, \degree,Pseq([0,3,5,7,9,11,5,1],2), \pan,-1,\cut,2000, \rez,0.6, \amp,0.1);
]),

Ptpar([
0,Pbind(\instrument,\pattern_Ex, \out, 20, \dur,2, \root,[-24,-17], \degree,Pseq([0,3,5,7,9,11,5,1],inf),     \pan,1,\cut,Pxrand([1000,500,2000,300],inf), \rez,Pfunc({0.7.rand +0.3}), \amp,0.12),

0,Pbind(\instrument,\bass_Ex, \dur,1, \root,-24, \degree,Pseq([0],inf), \pan,0, \cut,128, \rez,0.1, \amp,0.3),

0.5,Pbind(\instrument,\pattern_Ex, \out, 20, \dur,2, \root,-12, \degree,Pseq([0,3,5,7,9,11,5,1],inf), \pan,-1,\cut,2000, \rez,0.6, \amp,0.1);
]);


]).play;

)
