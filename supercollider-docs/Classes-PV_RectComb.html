PV_RectComb

在频谱中制造间隙。

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

另请参阅：FFT、IFFT、PV_RectComb2

说明

在频谱中制造一系列间隙。

类方法

PV_RectComb.new(buffer, numTeeth: 0.0, phase: 0.0, width: 0.5)

参数：

buffer

FFT 缓冲区。

numTeeth

梳状滤波器的齿数。

phase

梳状脉冲的起始相位。

width

梳状滤波器的脉冲宽度。

实例方法

示例

(
{
    var sig, chain;
    sig = WhiteNoise.ar(0.2);
    chain = FFT(LocalBuf(2048), sig);
    chain = PV_RectComb(chain, 8, LFTri.kr(0.097, 0, 0.4, 0.5),
    LFTri.kr(0.24, 0, -0.5, 0.5));
    IFFT(chain).dup
}.play;
)

(
{
    var sig, chain;
    sig = WhiteNoise.ar(0.2);
    chain = FFT(LocalBuf(2048), sig);
    chain = PV_RectComb(chain, MouseX.kr(0, 32), MouseY.kr, 0.2);
    IFFT(chain).dup
}.play;
)
