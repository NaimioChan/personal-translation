IdentitySet

按标识判断的集合

Set : Collection : Object

另请参阅：List、Dictionary

子类：OrderedIdentitySet

说明

IdentitySet 是一个对象集合，其中任意两个对象都不是同一个对象（即“完全相同”）。它的大部分方法都是继承来的（参见 Collection 和 Set 类）。IdentitySet 的内容是无序的。你不得依赖 IdentitySet 中元素的顺序。若要使用有序集合，请参见 OrderedIdentitySet。

IdentitySets 比 Sets 更快，因为测试同一性比测试相等性快得多。不同的类可能以不同方式实现相等性，但同一性只需通过比较对象地址即可确定。这使得 IdentitySet 的某些方法可以用快速原语来实现。

类方法

实例方法

添加与移除

.add(item)

来自父类：Set

将 anObject 添加到 IdentitySet 中。与 IdentitySet 中已有对象相等的对象将不会被添加。

IdentitySet[1, 2, 3].add(4);
IdentitySet[1, 2, 3].add(3);
// 两个字符串相等但不完全相同
IdentitySet["abc", "def", "ghi"].add("def");
// 如果 symbols 相等，则保证它们是相同的
IdentitySet['abc', 'def', 'ghi'].add('def');
IdentitySet['abc', 'def', 'ghi'].add('jkl');

.remove(item)

来自父类：Set

从 IdentitySet 中移除 anObject。

IdentitySet[1, 2, 3].remove(3);

Iteration

.do(function)

来自父类：Set

对 IdentitySet 中的每一项求值函数。你不得依赖各项的顺序。该函数会接收两个参数：项与一个整数索引。

IdentitySet[1, 2, 3, 300].do { |item, i| item.postln };

查找一个元素

.findMatch(item)

来自父类：Set

如果该项在集合中，则返回该项，否则返回 nil。

a = IdentitySet[1, 2, 3, 300];
a.findMatch(1);
a.findMatch(1.5);

.scanFor(argKey)

示例

// scanFor 效率相当高。比较以下基准测试：

// 数组索引与身份集合查找的比较
(
f = { |n = 4|
    var x, y, i;
    x = (0..n);
    y = x.as(IdentitySet);
    i = x.choose;
    bench { 100.do { x[i] } };
    bench { 100.do { y.scanFor(i) } };
}
);

f.(4)
f.(8)
f.(100)
f.(10000)
// 你可以使用 IdentitySet 高效地从数组中移除相同的重复项：

(
var e, f, g, h;
e = "such"; f = "fallacy"; g = "is"; h = "common";
a = [e, e, f, g, e, h, e];
);
a.as(IdentitySet);    // 转换为集合
a.as(Set).as(Array);    // 并转换回来

// 注意以下行为有所不同：
a = ["such", "such", "fallacy", "is", "such", "common", "such"]
a.as(IdentitySet);    // 转换为集合。所有元素仍然在这里。
            // 不同的字符串可能看起来相同，但却是不同的对象。

// 要移除等值（equals）而非同一（identicals），请使用 Set：
a.as(Set);
