jitlib_fading

淡入淡出包络生成与交叉淡化

另请参阅：JITLib

NodeProxy （ ProxySynthDef ）会在你的定义函数中查找内部包络，以判断是否需要淡入淡出包络。如果没有其他内部方式可以释放 Synth，则

  • a) 创建一个淡入淡出包络（音频 / 控制速率输出）
  • b) 合成器被直接释放，没有淡出（标量输出或 doneAction 1）
  • c) 如果你为 ugenGraph 函数提供了 gate 参数和 doneAction 2，这应当是该 Synth 的淡出包络
  • d) 如果使用了 synthdef 名称，则假定为情况 c)

……因此在大多数情况下，无需过多担心，只要注意这两点，如果想使用自释放的 synth 或不同的输出 ugen：

  • e) 自行负责：如果该函数创建的 ugengraph 可以通过 trigger 或其他方式释放，则它等待此动作，而不是由节点代理释放 synth。
  • f) 使用 'out' 参数拥有自己的输出通道：名为 'out' 的 control ugen 被设置为该 proxy 的输出通道号。
p = ProxySpace.push(s.boot);

~out.play;

// 注意，直接使用 ProxySynthDef 时也可以使用此功能：

d = ProxySynthDef("test", { arg freq=440; SinOsc.ar(freq) }).send(s);
s.sendMsg("/s_new", "test", 1980, 1, 1, \freq, 340);
s.sendMsg("/n_set", 1980, \freq, 240);
s.sendMsg("/n_set", 1980, \fadeTime, 4);
s.sendMsg("/n_set", 1980, \gate, 0);

a) 自动淡入淡出包络生成

// 没有内部包络和音频/控制速率输出
(
~out = { PinkNoise.ar([1,1]*0.1) };
)

(
~kout = { PinkNoise.kr([1,1]*0.1) };
)

b) 自动释放而非交叉淡化

// 内部包络无法释放 synth，当分配新函数时
// synth 会被释放。
(
~out = { arg t_trig; EnvGen.kr(Env.asr, t_trig) * PinkNoise.ar([1,1]) };
)
~out.group.set(\t_trig, 1);

(
~out = { arg t_trig; EnvGen.kr(Env.asr, t_trig) * SinOsc.ar([1,1]*400) };
)
~out.group.set(\t_trig, 1);


// 对于标量输出也不会创建淡入淡出包络，但 synth 会被释放（不带淡出）
(
~out = { Out.ar(0, SinOsc.ar(Rand(440,550),0,0.2)) };
)

c) 自定义淡出包络

// 当提供 gate 参数，且 env 可以释放 synth 时，此包络
// 应为 synth 的淡出包络：不会创建额外的淡出 env。

~out = { arg gate=1; EnvGen.kr(Env.asr, gate, doneAction: Done.freeSelf) * 0.2 * SinOsc.ar([1,1]*Rand(440,550)) };


// 如果你想使用代理的 fadeTime，应提供一个 fadeTime 参数：

~out = { arg gate=1, fadeTime = 0.1; EnvGen.kr(Env.asr(fadeTime, 1, fadeTime), gate, doneAction: Done.freeSelf) * 0.2 * SinOsc.ar([1,1] * Rand(440, 550)) };

d) SynthDef 名称分配

// 如果使用符号作为输入，服务器上 def 的 defname 应该
// 代表一个具有 gate、out 输入并能自行释放的 SynthDef。
(
~out = \default;
)

// 这是此类用法的最小必需参数（类似于 Pbind）
(
SynthDef("test", { arg gate=1, out;
    Out.ar(out, Formant.ar(300, 200, 10) * EnvGen.kr(Env.asr, gate, doneAction: Done.freeSelf))
}).send(s);
)

// 你也可以提供一个 fadeTime 参数，它由 proxy 设置：
(
SynthDef("test", { arg gate=1, out, fadeTime=1;
    Out.ar(out,
        Formant.ar(Rand(20,40), 600, 10, 0.2)
        * EnvGen.kr(Env.asr(fadeTime,1,fadeTime), gate, doneAction: Done.freeSelf)
    )
}).send(s);
)

~out = \test;
~out.fadeTime = 3;

注意： 使用符号时，通道数由你自己负责，因为符号不携带通道信息！（在所有其他情况下，通道数会被包装或扩展以匹配代理）

// 如果 synthdef 具有固定时长的包络，则不会使用代理的 fadeTime
(
SynthDef("test", { arg gate=1, out;
    Out.ar(out,
        Formant.ar(Rand(20,40), 600, 10, 0.6)
        * EnvGen.kr(Env.perc, gate, doneAction: Done.freeSelf)
    )
}).send(s);
)

~out = \test;

e) 自己的自由责任

//内部包络可以释放 synth，不会创建额外的淡出包络：
(
~out = { arg t_trig; EnvGen.kr(Env.asr, t_trig, doneAction: Done.freeSelf) * PinkNoise.ar([1,1]) };
)
~out.group.set(\t_trig, 1); //end it

~out.send; //启动一个新合成器
~out.group.set(\t_trig, 1); //再次结束


// 如果有一个 ugen 可以释放 synth，也不会创建额外的淡出包络，
// 但它假设 synth 会自行释放，因此如果分配了新函数，它
// 不会被释放。
(
~out = { arg t_trig;
    FreeSelf.kr(t_trig);
    PinkNoise.ar([1,1]*0.3);
};
)
~out.group.set(\t_trig, 1);

f) 自身输出责任

// 参数名 'out' 可用于通过右声道输出。
// 当然，使用这个可能会因声道数错误
// 或故意的 hack 而出现问题。

//左扬声器
(
~out = { arg out;
    OffsetOut.ar(out, Impulse.ar(10,0,0.1))
}
)

//两个扬声器
(
~out = { arg out;
    OffsetOut.ar(out, Impulse.ar([10, 10],0,0.1))
}
)

//这会播放到另一个相邻的总线上：这是一个可能的混淆来源。
(
~out = { arg out;
    OffsetOut.ar(out, Impulse.ar([10, 10, 10],0,0.1))
}
)
