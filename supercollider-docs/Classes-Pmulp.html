Pmulp

将模式中的每个值与事件流中某个键的值相乘

Psetp : Pset : FilterPattern : Pattern : AbstractFunction : Object

另请参阅：Pmul、Paddp

说明

向事件模式或流中的命名值添加一个值，直到其结束。用新值重复此操作，直到值流结束。

类方法

Pmulp.new(name, value, pattern)

来自父类：Pset

参数：

name

事件模式或流中要相乘的命名值。

value

要与之相乘的值、模式、流或数组。当此传入流结束时，结果流也随之结束。

pattern

在其中对新值进行相乘的事件模式或流。

实例方法

(
var a, b;
a = Pmulp(\freq, Pseq([2, 3, pi], inf), Pbind(\freq, Pseq([100, 200, 300])));

// 声音示例

        Out.ar(out, SinOsc.ar(freq, 0, env * 0.1))
    }).add;
