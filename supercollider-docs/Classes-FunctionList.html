FunctionList

将多个函数组合为一个的函数

AbstractFunction : Object

说明

FunctionList 是一种函数，它将多个函数组合成一个。这样就能把若干函数当作一个来透明处理，并在之后追加新函数。这些函数按照它们在 FunctionList 数组中各自的顺序求值，默认顺序即它们被添加进该数组的顺序。

基本介绍请参阅 Functions 帮助文件。

a = FunctionList.new;
fork { loop { 0.7.wait; a.value.postln } };
a.addFunc({ 800.rand });
a.addFunc({ "another".scramble });

类方法

FunctionList.new(functions)

创建一个新实例。

参数：

functions

一个由函数或对象组成的数组

实例方法

.array

.array = value

设置/获取 FunctionList 的数组。可以直接向该数组添加新函数，例如：

x = FunctionList(...some functions);
x.array = x.array.insert(2, aFunction);

.addFunc( ... functions)

此消息用于能够向 Object、Function 或 FunctionList 添加内容。nil.addFunc 返回一个函数，如果参数中只传入一个函数。function.addFunc 则返回一个 FunctionList。

.removeFunc(function)

从列表中移除一个函数。

返回值：

当只剩下一个函数时的最后一个函数，或者当最后一个函数被移除时为 nil。

讨论：

addFunc 和 removeFunc 已为 Nil、Object 和 FunctionList 实现

nil.addFunc(f) // 返回 f
obj.addFunc(f) // 返回 FunctionList([obj, f])
nil.removeFunc(f) // 返回 nil
obj.removeFunc(f) // 如果 f === obj 则返回 nil，否则返回 obj

示例

// example

a = nil;
a = a.addFunc { |x = "", y = ""| "this % is an % example\n".postf(x, y); 1 };
a.postln;
a = a.addFunc { |x = "", y = ""| "there is no % that is %\n".postf(x, y); 2 };
a.value;
a.value("text", "extraordinary well written")
a.valueArray(["x", "y"]);
// Function:do 与 FunctionList:do（相同）
a.do { |x| x.value };
{ 4 }.do { |x| x.value.postln }

(
().use {
    ~x = "array";
    ~y = "ominous";
    a.valueEnvir;
    a.valueEnvir("list");
}
)
// 移除一个函数
x = { "removal test".postln };
a.addFunc(x);
a.value;
a = a.removeFunc(x);
a.value;

// 数学
a = nil;
a = a.addFunc({ 1.0.rand }).addFunc({ [0, 1].choose });
a = a.squared.linexp(0, 1, 1.0, 500);

a.value;
// 与函数多通道扩展的兼容性
a = nil;
a = a.addFunc { |x = 0| if(x > 0) { 7 } { 1000.rand } };
a = a.addFunc { |x = 0| if(x < 0) { 17 } { -1000.rand } };
a.value

a = a.flop;
a.value
a.value([-1, 1])
a.value(x:[-1, 1]); // kwargs
