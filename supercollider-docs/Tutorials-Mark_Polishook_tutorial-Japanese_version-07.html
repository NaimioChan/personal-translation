何时使用一个 SynthDef……何时使用两个或更多 SynthDef

在许多合成过程中，简单情况下可以只用单个 SynthDef 定义。更复杂的情况下，最好编写多个 SynthDef，让它们在组中作为组件协同工作。

////////////////////////////////////////////////////////////////////////////////////////////////////

関数と.scopeメッセージ

尝试简单合成过程的一种简单方法是在函数中执行它，这比定义 SynthDef 并在 Synth 中将其用作引擎更简单。以这种方式开发代码时，你可以在之后的某个时间点将代码从测试函数转换为 SynthDef。

实际上，.play 和 .scope 消息可以发送给函数，这样做会使此方法变得有用。因为 .scope 消息会在函数内执行该代码，并将所定义 synth 过程生成的波形显示为可视化表示。

但是，.scope 消息只能对内部服务器起作用。也就是说，要使用它，必须开启内部服务器。要手动完成此操作，请按下内部服务器的 boot 按钮，或者以代码方式执行以下操作。

s.boot;

////////////////////////////////////////////////////////////////////////////////////////////////////

この例を実行してスコープ・ウィンドウに注目して下さい。

(
{
    SinOsc.ar([440.067, 441.013], 0, 1)
    *
    SinOsc.ar([111, 109], 0, 0.2)
}.scope;
)

////////////////////////////////////////////////////////////////////////////////////////////////////

これは同じシンセシスのプロセスをSnythDefとして表現したものです。以下に示す様に、上の例で関数の中に書かれているコードが、単にそのままOutの第２アーギュメントになっているということに注目して下さい。

(
SynthDef("ringMod", {
    Out.ar(
        0,
        SinOsc.ar([440.067, 441.013], 0, 1) * SinOsc.ar([111, 109], 0, 0.2)
    )
}).add;
)

Synth("ringMod")
