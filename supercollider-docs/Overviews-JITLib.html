Just In Time 编程库概述

Introduction

“乘客对出租车司机说：带我去 37 号。到了那里我会告诉你街道名。”1

免责声明：实际上并不存在时间；然而，守时是你个人的责任。

即时编程（或称：对话式编程、现场编程2 、动态编程、交互式编程）是一种将编程活动纳入程序运行过程的范式。在这里，程序并非先被制作出来、之后再用于生产的工具，而是一个描述与对话的动态构建过程。编写代码成为音乐或实验实践中不可分割的一部分。

作为一种动态编程语言，SuperCollider 提供了多种修改运行中程序的可能性——这个库对它们进行了扩展、统一和发展，主要通过提供抽象的占位符（称为代理）来实现，这些代理可用于计算并在运行时修改。

Overview

JITLib 由若干占位符（服务器端和客户端代理）以及访问方案3 组成。这两个方面对应于包含与引用，取决于它们的上下文——在这里，占位符就像角色，具有特定行为，并可由特定对象来履行。了解这种占位符的三个方面是有用的：某一组元素可以作为它们的源，它们可以在一组上下文中使用，并且如果没有给定源，则有一个默认源。

常用类：Tdef（用于任务）、ProxySpace、NodeProxy 和 Ndef（用于 synth）、Pdef 和 Pdefn（用于模式）。

注意： 关于一些近期更改，参见：JITLib Changes in 3.7

不同类与技术的概览

  • Defs：一种访问方式或风格是 def 类（Pdef、Ndef 等）。它以特定方式将符号绑定到一个对象：

    Pdef(\name)        //返回代理
    Pdef(\name, object)    //设置源并返回代理

    其余行为取决于其用途。

    客户端侧：Pdef、Pdefn、Tdef、Pbindef、Psym、Pnsym、Fdef

    服务器端：Ndef

  • 环境：另一种方式是，对于服务器端的 NodeProxy，可以使用按需返回占位符的环境：

    ProxySpace.push
    ~out = { ...}

    helpfile：ProxySpace 用于与其他环境配合使用，参见 jitlib_basic_concepts_02

  • 更低层次的代理：也有不使用访问方案而直接访问的方式：NodeProxy、TaskProxy 等提供了它。在内部，前者使用这些作为基类。

    语言端：PatternProxy、EventPatternProxy、TaskProxy、PbindProxy、Pdict

    服务器端：NodeProxy

  • 历史：为了记录所有文本更改，History 提供了导航和代码记忆功能。
  • 多通道系统：Monitor（内部使用）具有 playN 方法。

  • GUI：概览与混音器：ProxyMixer、TdefAllGui、PdefAllGui、NdefMixer

    （供单独使用：TdefGui、PdefGui、MonitorGui、NdefGui、NdefParamGui）

Networking

  • 在远程和本地网络中，得益于 sc-architecture 节点代理，任何服务器上都可以使用节点代理，只要它能通知客户端并具有正确初始化的默认节点。

    注意应设置登录次数或客户端 id。

        s.options.maxLogins = 16; // 一个最多包含 16 台服务器的合奏
