Dunique

为多个需求流返回相同的唯一值序列

UGen : AbstractFunction : Object

另请参见：Demand、Drand、Dser、Duty、Dxrand、TDuty

说明

一个 demand UGen 代表单一的状态序列。当被多个 demand 流使用时，它只会为每个流输出每第 n 个值。将 demand UGen 包装在 Dunique 中可保证所有流接收到相同的值。

// 如果不采取任何措施，需求 ugen 的值将分布在多个序列之间：
{ var x = Dseq([0, 1, 2, 3, 4, 5], inf); { Demand.ar(Impulse.ar(1/rrand(0.001, 0.0015)), 0, x) } ! 3 }.plot;

// 使用 Dunique 时，每个序列都遍历相同的值
{ var x = Dunique(Dseq([0, 1, 2, 3, 4, 5], inf)); { Demand.ar(Impulse.ar(1/rrand(0.001, 0.0015)), 0, x) } ! 3 }.plot;

// 随机值也将完全相同
{ var x = Dunique(Drand([0, 1, 2, 3, 4, 5], inf)); { Demand.ar(Impulse.ar(1/rrand(0.001, 0.0015)), 0, x) } ! 3 }.plot;

类方法

Dunique.new(source, maxBufferSize: 1024, protected: true)

返回一个新实例。

参数：

source

要在其他多个 UGen 中复用的 demand UGen。

maxBufferSize

当 protected 为 false 时值缓冲区的最大大小。超过 maxBufferSize 后，值将循环。

protected

此 ugen 存在一些限制：如果某个副本的调用速度远快于最慢的副本，缓冲区可能会溢出。为了防止这种缓冲区溢出，只能依赖向上计数到无穷大。使用 32 位浮点数时，只有 16777216 个事件能被正确回放。当 protected 为 true 时，这两个限制会通过结束序列来捕获（默认值：true）。将此参数设为 false（或零）即可忽略这一限制（例如通过适当调整缓冲区大小）。

// 为了演示，故意将缓冲区设得很小：
{ var x = Dunique(Drand([0, 1, 2, 3, 4, 5], inf), 20); { Duty.ar(0.5e-4 + 0.001.rand, 0, x, doneAction: Done.freeSelf) } ! 3 }.plot;
