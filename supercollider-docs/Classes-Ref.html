Ref

对某个值的引用

AbstractFunction : Object

子类：Maybe、RefCopy

说明

Ref 持有一个对象，该对象可以通过消息 value 和 value_(obj) 来获取和修改。反引号 ` 是一个一元运算符，等价于调用 Ref.new(obj)。

Ref 最常用于防止 SynthDef 和 Pattern 中的多通道扩展（参见 Klank 的示例）。Ref 还可用于简化 EventStreams 中使用的例程的编码（参见 Prout 的示例）。

x = Ref(nil);
z = obj.method(x);        // 方法将某些内容放入引用中
x.value.doSomething;    // 获取值并使用它

Ref 也用作引用设备，以保护某些需要 Arrays 的 UGens 免受多通道扩展的影响。

.dereference

返回该值。此消息也在 Object 类中定义，在那里它只返回接收者。因此 anything.dereference 会移除 Ref（如果存在的话）。这与 value 消息略有不同，因为 value 还会使函数自行求值，而 dereference 不会。

.asRef

返回接收者。在 Object 类中，此消息定义为创建该对象的 Ref。

Ref 的典型用法：

阻止多通道扩展

关于 SynthDefs 中多通道扩展的详细信息，请参阅 Multichannel Expansion。

Refs 会阻止 SynthDef 中的多通道扩展，因此下面的数组定义的是一个 Klank UGen 而不是三个。

{ Klank.ar(`[[800, 1071, 1153, 1723], nil, [1, 1, 1, 1]], Impulse.ar(2, 0, 0.1)) }.play;

在 Events 和 Patterns 中，Refs 不能被可靠地用于抑制多声道扩展。相反，有必要将值数组包含在另一个数组中：

(
    SynthDef(\multi, { |out, freq = #[100, 200, 300], amp = 0.1, pan = 0, sustain = 1|
        var audio, env;
        env = EnvGen.kr(Env.perc(0.01, sustain), doneAction: Done.freeSelf);
        audio = Mix(Saw.ar(freq));
        audio = Pan2.ar(audio * env, pan, amp);
        OffsetOut.ar(out, audio)
    }).add;

    (instrument: \multi, freq: [[500, 501, 700]], sustain: 2).play

)
(
    Pbind(*[
        instrument: \multi,
        freq:     Prand([
                        [[100, 141, 103]],
                        [[100, 310, 190]],
                        [[100, 100.1, 110]],
                ], inf),
        dur: 0.2,
        sustain: 0.3
    ]).play;
)

multichannelExpandRef

此方法在接收多维数组的 UGen 的输入上被内部调用，例如 Klank，并且即使在那些情况下也允许正确的多声道扩展。对于 SequenceableCollection，这将返回集合本身，假定它已经包含若干 Ref。

参数：

rank

列表展开的深度。例如 Klank spec 的 rank 为 2。

`([[[100, 200], 500], nil, [[[0.01, 0.3], 0.8]]]).multichannelExpandRef(2);
[`[[100, 200], nil, [0.2, 0.8]], `[[130, 202], nil, [0.2, 0.5]]].multichannelExpandRef(2);
