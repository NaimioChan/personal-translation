NdefMixerOld

给定服务器上所有 Ndef 的混合控制

参见：NdefMixer

说明

更多细节见：ProxyMixer

类方法

Creation

.new

为给定服务器返回一个新窗口。

// 为其他服务器设置 ndef 混音器
n = NdefMixer(\internal);
n = NdefMixer(\localhost);
n = NdefMixer(\trala);        // 失败，没有这样的服务器

参数：

server

服务器对象（Server）或服务器名称（Symbol）

nProxies

一个 Integer。

title

一个 String。

bounds

一个 Rect。

实例方法

.proxyspace

返回 proxyspace。

示例

n = NdefMixer(s);        // 用于默认服务器
// 创建一个新代理
(
Ndef(\a, {
    Pan2.ar(
        Ringz.ar(
            Impulse.ar(exprand(0.5, 4)),
            exprand(300, 3000),
            0.02
        ),
    1.0.rand2,
    0.2)
})
);



n.proxyspace;

Ndef(\duster, { Dust.kr(4) });

Ndef(\a).ar;
Ndef(\a).fadeTime = 2;
Ndef(\a).end;
