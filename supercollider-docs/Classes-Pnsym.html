Pnsym

使用符号模式来嵌入 Pdefn

Psym : FilterPattern : Pattern : AbstractFunction : Object

另请参阅：Pdefn

子类：Pnsym1

说明

关于事件模式，请参见 Psym。概述：JITLib。

类方法

Pnsym.new(pattern, dict)

来自父类：Psym

参数：

pattern

一个返回符号或字符的模式。数组会被转换为并行模式（Ptuple）。

dict

用于查找的字典。默认情况下为 Pdefn.all，因此可以按名称嵌入 Pdefn。

实例方法

.dict

.dict = value

来自父类：Psym

设置要使用的字典。

未文档化的实例方法

.lookupClass

示例

(
// 加载 synthdef
s.boot;
SynthDef("gpdef",
    { |out = 0, freq = 440, sustain = 0.05, amp = 0.1, pan|
        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain), doneAction: Done.freeSelf) * amp;
        Out.ar(out, Pan2.ar(SinOsc.ar(freq, 0, env), pan))
    }).add;
)

Pdefn(\x, Pn(1, 3));
Pdefn(\y, Prand([5, 9, 1], 2));
Pdefn(\z, Pdefn(\y) * 2);

(
Pdef(\play,
    Pbind(
        \instrument, \gpdef,
        \harmonic, Pnsym(Pseq([\x, \x, Prand([\x, \y]), [\z, \y], \y], inf)).trace,
        \dur, 0.2, \note, 10
    )
).play;
)

// 更改根音模式：
Pdefn(\x, Pn(2, 3));
Pdefn(\x, Pseq([1, 3, 1, 2, 1, 4, 5]));
Pdefn(\x, Pseq([1, 3, 1, 2, [1, 3], 4, 5]));
