LeastChange

输出变化最小

MostChange : UGen : AbstractFunction : Object

参见：MostChange、LastValue

说明

给定两个输入 a 和 b，令 da[t] = abs(a[t] - a[t - 1]) 且 db[t] = abs(b[t] - b[t - 1])。如果 da[t] 较小，则输出 a[t]；如果 db[t] 较小，则输出 b[t]。如果 da[t] == db[t]，则使用上一次所使用的那个输入（假设输出的第一个样本使用 a）。

类方法

LeastChange.ar(a: 0.0, b: 0.0)

来自父类：MostChange

LeastChange.kr(a: 0.0, b: 0.0)

来自父类：MostChange

参数：

a

输入信号 A。

b

输入信号 B。

实例方法

示例

(
d = { |amp = 1.0|
    var in1, in2;
    in1 = LFNoise0.ar(800, amp);
    in2 = SinOsc.ar(800);
    LeastChange.ar(in1, in2) * 0.1;
}.play;
)

d.set(\amp, 0.1);
d.set(\amp, 0);
d.set(\amp, 3);
d.free;

变化最小的控件用作输出：

(
d = { |freq = 440|
    var internalFreq;
    internalFreq = LFNoise0.ar(0.3, 300, 800);
    SinOsc.ar(
        LeastChange.kr(freq, internalFreq) // 两种变化来源：一个外部，一个内部
    ) * 0.1
}.play
);

d.set(\freq, 800);
d.set(\freq, 900);
d.free;
