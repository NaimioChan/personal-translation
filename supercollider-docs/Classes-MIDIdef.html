MIDIdef

MIDI 响应参考定义

MIDIFunc : AbstractResponderFunc : Object

参见：MIDI、MIDIFunc

说明

MIDIdef 为其父类 MIDIFunc 的功能提供了一个全局引用。本质上，它把自己存储在一个全局字典中的某个键下，从而允许随时替换。大多数方法继承自其父类。

关于持久化的重要说明

MIDIFunc（及其子类 MIDIdef，与所有其他 AbstractResponderFunc 一样）在按下 Cmd/ctrl-. 时会被移除。要覆盖此行为，请使用 AbstractResponderFunc: -permanent 方法。

类方法

MIDIdef.all

MIDIdef.all = value

获取所有 MIDIdef 的全局字典。

返回值：

一个 IdentityDictionary。

MIDIdef.new(key, func, msgNum, chan, msgType, srcID, argTemplate, dispatcher)

创建一个新的、已启用的 MIDIdef。如果该键处已存在 MIDIdef，其参数将被所提供的参数替换（传入 nil 的参数将使用旧值）。通常应使用下面某个针对消息类型的便捷方法，而不是直接使用此方法。

参数：

key

在全局集合中存储此 OSCdef 所用的键。通常这是一个 Symbol。

func

一个 Function 或类似对象，用于响应传入的消息。当为 noteOn、noteOff、control 和 polytouch 消息求值时，会向它传递参数 val、num、chan 和 src，分别对应消息值（例如力度、控制值等）、消息编号（例如音符编号）、MIDI 通道和 MIDI 源 uid。对于 touch、program change 和 bend 消息，只会传递 val、chan 和 src。有关其他 msgType 所传递参数的信息，请参见下面的便捷方法。

msgNum

一个 Integer，指示此 MIDIdef 的 MIDI 消息编号（音符号、控制器号或音色号）。它可以是一个数组。如果为 nil，则 MIDIdef 将响应所有可能消息编号的消息。

chan

一个 Integer，表示此 MIDIdef 的 MIDI 通道号。可以是数组。若为 nil，则 MIDIdef 会响应所有通道上收到的消息。

msgType

一个 Symbol，指示此 MIDIdef 应响应哪种 MIDI 消息。取值为 \noteOn、\noteOff、\control、\touch、\polytouch、\bend、\program、\sysex、\mtcQF、\smpte、\songPosition、\songSelect、\tuneRequest、\midiClock、\sysrt、\tick、\start、\continue、\stop、\activeSense 或 \reset 之一。

srcID

一个 Integer，对应 MIDI 输入的 uid。（参见 Using MIDI: MIDIFunc and MIDIdef: Filtering based on device or message data。）如果为 nil，则 MIDIdef 将响应从所有来源接收到的消息。

argTemplate

一个可选的 Integer 或 Function（或响应方法 Methods: matchItem 的对象），用于匹配传入 MIDI 消息的值。（例如力度、控制值、程序号等）。如果是 Function，它将以消息值作为参数进行求值，并应返回一个 Boolean，指示该消息是否匹配以及此 MIDIdef 是否应响应。

dispatcher

一个可选的、属于 AbstractDispatcher 相应子类的实例。可用于实现自定义的分发。通常不需要这样做。

返回值：

一个 MIDIdef 实例。

MIDIdef.freeAll

清除并停用全局集合中的所有 MIDIdef。

系统通用

注意：由于 SC 底层的低层 MIDI 实现，没有通用的 msgType 和用于 System Common 消息的便捷方法。相反，它们与 System Realtime 一起归入下面的 *sysrt。

MIDIdef.smpte(key, func, srcID, argTemplate, dispatcher)

一个便捷方法，用于创建响应 MIDI smpte 消息的新 MIDIdef。参数说明见 *new。响应的 func 会被传入参数 seconds、framerate、dropframe 和 srcID。（dropframe 是一个 Boolean）。

返回值：

一个响应 MIDI smpte 消息的新 MIDIdef 实例。

MIDIdef.mtcQuarterFrame(key, func, srcID, argTemplate, dispatcher)

一个便捷方法，用于创建新的 MIDIdef，它响应 MIDI Time Code Quarter Frame 消息。请注意，上面的 *smpte 方法会自动将 quarter frame 组装成时间码。参数说明见 *new。响应的 func 将接收参数 data、srcID 和 pieceNumber。你需要手动将每 8 条消息组装成 smpte。

返回值：

MIDIdef 的一个新实例，用于响应 MIDI Time Code Quarter Frame 消息。

MIDIdef.songPosition(key, func, srcID, argTemplate, dispatcher)

一个便捷方法，用于创建一个响应 MIDI song position 消息的新 MIDIdef。参数说明参见 *new。响应的 func 将被传入参数 position 和 srcID。

返回值：

MIDIdef 的一个新实例，它响应 MIDI 歌曲位置消息。

系统实时

MIDIdef.sysrt(key, func, index, srcID, argTemplate, dispatcher)

一个便捷方法，用于创建新的 MIDIdef，它对 MIDI System Realtime 和 System Common 消息进行通用响应。请注意，上文和下文中的针对特定消息的方法在大多数情况下可能更方便。请注意，这不包括 MIDI Time Code Quarter Frame 消息（sysrt index 1）。关于这些，请参见 *mtcQuarterFrame 和 *smpte。参数说明请参见 *new。响应的 func 将接收到参数 data（可能为 nil）、srcID 和 index。Index 表示消息类型如下：

MIDI 时间码四分帧

1

歌曲位置

2

歌曲选择

3

调音请求

6

MIDI 时钟

8

Tick

9

Start

10

Continue

11

Stop

12

活动检测

14

Reset

15

返回值：

MIDIdef 的新实例，响应 MIDI System Realtime 消息。

实例方法

.key

获取此 MIDIdef 的键。

返回值：

通常是一个 Symbol。

.free

从全局集合中清除此 MIDIdef 并使其失效。

示例

MIDIIn.connectAll
MIDIdef.cc(\test1, { |...args| args.postln }, 1); // 匹配 cc 1
MIDIdef.cc(\test2, { |...args| args.postln }, 1, 1); // 匹配 cc1，通道 1
MIDIdef.cc(\test3, { |...args| args.postln }, (1..10)); // match cc 1-10
MIDIdef.noteOn(\test4, { |...args| args.postln }); // 匹配任意 noteOn

MIDIIn.doNoteOnAction(1, 1, 64, 64); // 伪造一个音符开事件
MIDIIn.doControlAction(1, 1, 1, 64); // 伪造一个 cc
MIDIIn.doControlAction(1, 1, 9, 64);
MIDIIn.doControlAction(1, 10, 1, 64);

MIDIdef(\test1).free; // 释放一个 def
MIDIdef.freeAll;      // 释放所有已注册的 MIDIdef
