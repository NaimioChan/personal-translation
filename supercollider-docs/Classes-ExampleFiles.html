ExampleFiles

SuperCollider 自带示例声音的快捷方式

Object

另请参阅：Buffer、SoundFile、File、PathName

说明

提供随 SuperCollider 捆绑的示例文件路径的快捷方式，这些文件位于 Platform: *resourceDir。

// 而不是编写
Platform.resourceDir +/+ "sounds" +/+ "a11wlk01-44_1.aiff";
// 可以这样写
ExampleFiles.apollo11;

类方法

ExampleFiles.apollo11

来自阿波罗 11 号登月计划的一段无线电录音，其中 Bruce McCandless 说 "Columbia, this is Houston. Over."。更多信息请参见 https://www.nasa.gov/history/alsj/a11/a11.mobility.html 中标记 110:25:41 处（似乎是第三次重复，尽管音高不匹配）。

Filename

a11wlk01-44_1.aiff

Channels

1

Samplerate

44100 Hz

Format

pcm_s16be

Duration

00:00:02.44

返回值：

a11wlk01-44_1.aiff 的完整路径，类型为 String

讨论：

趣闻时间：尽管该文件以当前形式由 Scott Wilson 于 2004-07-11 通过提交 bc9a4d4fd8cdccd2b1c787010c776176c7993d2c 引入，但其作为 11025 Hz 单声道文件的原始版本至少可以追溯到 2002-09-28，由 James McCartney 通过提交 f30d769ab6b8eb1f36027ed3a400efd3b829f43a 引入。

这可以视为 SuperCollider 的“Hello world”音频示例。

ExampleFiles.sinedPink

一个非常短的立体声采样，其第一个声道包含 10 个周期的 440Hz SinOsc，第二个声道包含 PinkNoise。
