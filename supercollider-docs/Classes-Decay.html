Decay

指数衰减

Filter : PureUGen : UGen : AbstractFunction : Object

另请参阅：Decay2、Integrator

说明

一种积分滤波器，如果给它一个冲激，它会产生一个指数衰减的包络。Decay 本质上与 Integrator 相同，但不是直接指定积分系数，而是根据 decayTime 计算得出——即输入信号衰减 60 dB 所需的时间，或衰减到其值的 99.9% 所需的时间。

类方法

Decay.ar(in: 0.0, decayTime: 1.0, mul: 1.0, add: 0.0)

Decay.kr(in: 0.0, decayTime: 1.0, mul: 1.0, add: 0.0)

参数：

in

输入信号。

decayTime

输入信号衰减 60 dB 所需的时间。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

// 绘制指数衰减包络
(
var t60 = 0.1; // 衰减时间
plot({ Decay.ar(Impulse.ar(0), t60) }, t60);
)
// 用作包络发生器
(
play({
    Decay.ar(
        in: Impulse.ar(XLine.kr(5,50,10), 0.25),
        decayTime: 0.2,
        mul: FSinOsc.ar(300)
    )
})
)

正如前例中所听到的，当 Decay 用作调制器时，其立即起始会导致不连续和可听见的咔哒声。这可以在波形中看到：

(
plot({
    Decay.ar(
        in: Impulse.ar(50),
        decayTime: 0.015,
        mul: FSinOsc.ar(370)
    )
}, 0.1, bounds: Rect(50,50,1200,400))
)

Decay2 允许进行起始控制，如下所示：

(
var t60, riseScale, riseFac, normFac;

t60 = 0.3; // 衰减时间

// Decay2 的起始控制和归一化因子
// （更多信息见 Decay2 帮助文档）
riseScale = 0.3;
riseFac = riseScale / (2 - riseScale);
normFac = riseFac.pow(riseFac / (riseFac - 1)) / (1 - riseFac);

// 比较 Decay（蓝色）和 Decay2（红色）
plot({
    var imp = Impulse.ar(0);
    [
        Decay.ar(imp, t60),
        Decay2.ar(imp,
            attackTime: t60 * riseFac,
            decayTime: t60,
            mul: normFac
        )
    ]
}, duration: t60/2)
.plotColor_([Color.blue, Color.red])
.superpose_(true)
)
