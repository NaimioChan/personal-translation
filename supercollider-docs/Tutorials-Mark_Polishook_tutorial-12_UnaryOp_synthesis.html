一元消息

某些合成过程可以用一元消息（不带参数的消息）来启动。

////////////////////////////////////////////////////////////////////////////////////////////////////

例如，比较

{ SinOsc.ar(500, 0, 0.5) }.scope;

to

{ SinOsc.ar(500, 0, 0.5).distort }.scope;

.distort 消息调制 SinOsc 以产生更多分音。

////////////////////////////////////////////////////////////////////////////////////////////////////

问：.distort 消息来自哪里？

答：它定义在 AbstractFunction 类中。UGen 类是 AbstractFunction 类的子类。其思路是所有类都继承其父类中定义的方法；因此所有 ugen 都继承自 AbstractFunction）。

Compare

{ SinOsc.ar(500, 0, 0.5) }.scope;

to

// .cubed 是一元运算
{ SinOsc.ar(500, 0, 0.5).cubed }.scope;
