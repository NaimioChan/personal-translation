网络与客户端/服务器

SuperCollider 3 使用客户端/服务器模型来跨网络运行。这意味着用户编写客户端程序，请求服务器做某件事，即请求服务。此类请求既可在一台计算机上本地发生，也可远程分布在两台或多台计算机之间。只要计算机连接在同一网络上，它们是在同一房间还是相隔世界各地都没有区别。

SuperCollider 中的客户端程序通常指定合成定义（如何产生特定声音）和合成调度（何时产生特定声音）。反过来，SuperCollider 服务器（或多个服务器）根据客户端指令合成音频。

总结一下，客户端请求；服务器响应。

客户端/服务器示例

////////////////////////////////////////////////////////////////////////////////////////////////////
// 示例 1 - 逐行执行，每次一行
// 定义一个合成过程并向服务器发起客户端请求
////////////////////////////////////////////////////////////////////////////////////////////////////

// 定义一个带名称和地址的服务器
s = Server("aServer", NetAddr("127.0.0.1", 56789));        // "localhost" is a synonym for an ip of                                                 // "127.0.0.1"
// 启动服务器
s.boot;

// 定义一个合成引擎
SynthDef("sine", { Out.ar(0, SinOsc.ar(440, 0, 0.2)) }).send(s);

// 调度（运行）合成
s.sendMsg("s_new", "sine", n = s.nextNodeID, 0, 1);

// 停止该合成器（删除它）
s.sendMsg("/n_free", n);

// （可选）停止服务器
s.quit;
////////////////////////////////////////////////////////////////////////////////////////////////////
// 示例 2
// 与上述相同，只是在网络上的 2 台计算机上
////////////////////////////////////////////////////////////////////////////////////////////////////

// 定义一个（远程）服务器；它代表互联网上"某处"的一台计算机"
// ip 地址必须有效，并且无论服务器位于何处，它都必须正在运行
// 服务器无法远程启动，例如，一台机器上的程序无法启动另一台机器上的服务器
// 此示例假设远程机器上的服务器是从
// SuperCollider 内部启动的，而不是从终端启动的
s = Server("aServer", NetAddr("... an ip number ...", 56789));

// 定义一个合成引擎……与上一个示例完全相同
SynthDef("sine", { Out.ar(0, SinOsc.ar(440, 0, 0.2)) }).send(s);

// 调度合成 ... 与上一个示例完全相同
s.sendMsg("s_new", "sine", n = s.nextNodeID, 0, 1);

// 停止该合成器（删除它）
s.sendMsg("/n_free", n);
////////////////////////////////////////////////////////////////////////////////////////////////////
// 示例 3
// 客户端/服务器在同一台计算机上 vs. 客户端服务器在两台计算机上
// 前面不带注释的示例
// 它们完全相同，除了
//    在单台计算机上运行的示例显式启动服务器
//    在两台计算机上的示例 _假定服务器“在某处”互联网上已启动
////////////////////////////////////////////////////////////////////////////////////////////////////

// 在一台计算机上
s = Server("aServer", NetAddr("localhost", 56789));
s.boot;
SynthDef("sine", { Out.ar(0, SinOsc.ar(440, 0, 0.2)) }).send(s);
s.sendMsg("s_new", "sine", n = s.nextNodeID, 0, 1);
s.sendMsg("/n_free", n);

vs.

// 在两台计算机上……服务器必须有一个有效的 IP 地址
s = Server("aServer", NetAddr("... an ip number ...", 56789));
SynthDef("sine", { Out.ar(0, SinOsc.ar(440, 0, 0.2)) }).send(s);
s.sendMsg("s_new", "sine", n = s.nextNodeID, 0, 1);
s.sendMsg("/n_free", n);

本地主机和内部服务器

前面的示例定义了服务器对象。但在大多数情况下，这并不是必需的，因为 SuperCollider 在启动时会定义两个这样的对象：localhost 和 internal 服务器。它们由屏幕底部的窗口表示。每个窗口都有一个启动按钮，用于启动各自的服务器。

有关更多信息，请参见 SuperCollider 帮助系统中的 Client vs Server、Server、ServerOptions 和 Server Tutorial 文档。
