PopUpMenu

一个显示可从下拉菜单中选择的文本项的视图。

说明

点击时，此视图会打开一个包含若干文本项的菜单，然后关闭该菜单，并在选中某一项后显示该项。

类方法

实例方法

Data

.items

当视图被点击时在菜单中显示的项列表。

参数：

字符串或符号的数组。

.clear

移除所有项。

.item

当前选中的项。

返回值：

一个 String。

.value

当前选中项的索引。

参数：

一个整数，或 nil 表示没有选中项。

.valueAction

设置 -value 并触发 -action。

参数：

一个整数，或 nil 表示没有选中项。

Appearance

.stringColor

用于显示文本的颜色。

参数：

一个 Color。

.background

设置此变量会用给定颜色为文本下方的视图区域着色。

参数：

一个 Color。

Interaction

.allowsReselection

确定在选择已选中的项时是否触发该动作。默认值为 false。

参数：

一个布尔值。

Actions

.action

每当用户更改菜单中的选中项时求值的动作对象。有关自定义，请参见 -allowsReselection。

拖放

.defaultGetDrag

返回值：

该 -value。

.defaultCanReceiveDrag

返回值：

如果当前拖动数据是数字，则为 true。

.defaultReceiveDrag

将 -valueAction 设置为当前拖拽数据。

示例

基本示例

(
w = Window.new("The Eightfold Path").front;
m = PopUpMenu(w, Rect(10, 10, 180, 20));

m.items = [
 "right view", "right thinking", "right mindfulness", "right speech",
 "right action", "right diligence", "right concentration", "right livelihood"
];

m.background_(Color.green(0.7));  // 仅改变显示项的外观
m.stringColor_(Color.white);   // 仅改变显示项的外观
m.font_(Font("Courier", 13));   // 仅改变显示项的外观
m.action = { |menu|
 [menu.value, menu.item].postln;
};
)

m.value;   // 返回当前项的索引；
m.item;    // 返回当前项的 String 或 Symbol

m.value_(2);  // 改变显示的项，但不执行该动作
m.valueAction_(3); // 执行该动作。

声音示例

播放不同的函数：

(
s.waitForBoot({
    var w, menu, snd, funcs, b;
    
    w = Window.new.front;
    menu = PopUpMenu(w, Rect(10, 10, 90, 20))
    .items_(["Sine", "Saw", "Noise", "Pulse"]);
    
    funcs = [
        { SinOsc.ar(440, 0, 0.3) },
        { Saw.ar(440, 0.3) },
        { WhiteNoise.ar(0.3) },
        { Pulse.ar(440, 0.2, 0.3) }
    ];
    
    b = Button(w, Rect(110, 10, 180, 20))
    .states_([["play", Color.black, Color.green]])
    .mouseDownAction_({
        snd = funcs.at(menu.value).play;
    })
    .action_({ |butt, mod|
        snd.release;
    });
    
    w.front;
    
    p = CmdPeriod.add({ b.value_(0) }); // 按下 Cmd-period 时将按钮设为 0
    w.onClose_{ snd.release; CmdPeriod.removeAll }; // 窗口关闭时进行清理
    
})
)
