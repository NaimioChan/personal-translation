EZText

标签、文本字段和值的包装类

参见：StaticText、TextField

说明

EZText 是一个包装类，它创建一个（可选的）StaticText 和一个 TextField。其值以 compileString 形式显示在文本字段中供编辑。

关于 EZText 的一些重要问题

如果父级为 nil，则 EZText 会创建自己的窗口。更多选项见EZGui。

类方法

创建 / 类方法

.new

参数：

parent

父视图或窗口。如果 parent 为 nil，则 EZText 会创建自己的 Window，并且如果 bounds 是一个 Point，会将其方便地放置在屏幕上。如果 bounds 是一个 Rect，则该 Rect 决定窗口的边界。

bounds

Rect 或 Point 的实例。默认值为 160@20。

label

标签。默认值为 nil。如果为 nil，则不创建 StaticText。

action

当值改变时调用的 Function。该函数以 EZText 实例作为其参数传入。

initVal

用于初始化 EZText 的值。

initAction

一个 Boolean，指示在设置初始值时是否应调用动作函数。默认值为 false。

labelWidth

标签的像素宽度。默认值为 60。在 \horz 布局中，如果你指定了 textWidth，那么 labelWidth 会被忽略，并被设置为 bounds.width - textWidth。

textWidth

数字框的像素宽度。默认值为 45。在 \vert 布局中，textWidth 默认为 bounds.width。

labelHeight

默认值为 20。

layout

\vert 或 \horz。默认为 \horz；\vert 是两行版本。

gap

一个 Point。默认情况下，视图会尝试获取其父视图的间距，否则默认为 2@2。设置此项会覆盖上述行为。

margin

一个 Point。这将对 view 的子视图所占用的边界进行内缩。

讨论：

Example:

(
w = Window("EZText", Rect(300, 300, 260, 60)).front;
g = EZText(w,          // parent
            250@50,     // bounds
            "testing",  // label
            { |ez| (ez.value.asString ++" is the value of " ++ ez).postln }, // action
            [1, 2, 3],  // initValue
            true        // initAction
);
g.setColors(Color.grey, Color.white);
);

// 最简单版本，没有父视图，因此创建一个窗口
(
    g = EZText(label:" test ");
    g.action_({ |ez| (ez.value.asString ++" is the value of " ++ ez).postln });
);

(
    g = EZText(bounds: Rect(100, 200, 150, 50), label:" test ", layout: \vert);
    g.action_({ |ez| (ez.value.asString ++" is the value of " ++ ez).postln });
);

包含的视图可通过 EZText 实例变量访问：labelView、textField。

实例方法

.textField

返回 textField。

.action

一个 Function，在值改变时求值。典型用法是输入一个新值，并通过按求值快捷键来执行它。该函数的第一个参数将是 EZText。

.value

获取/设置 ezText 的值。不执行该操作。

参数：

inval

任意对象。

.valueAction

设置该值并执行该操作。

参数：

val

任意对象。

.doAction

执行该动作。

.enabled

设置/获取文本字段是否启用。

参数：

bool

Boolean 的一个实例。默认为 true。

更改外观

.setColors

参数：

stringBackground

一个 Color 的实例。标签和单位视图的 background。

stringColor

Color 的实例。标签视图与单位视图的 stringColor。

textBackground

一个 Color 的实例。textField 的 background。

textStringColor

一个 Color 的实例。textField 的 stringColor。

textNormalColor

Color 的一个实例。textField 的 normalColor。

textTypingColor

Color 的一个实例。textField 的 typingColor。

background

一个 Color 的实例。外层视图的 background。

.font

设置所有视图使用的字体。

参数：

font

Font 的一个实例。

示例

// 最简版本
(        // 基本用法
        w = Window("ez", Rect(300, 300, 300, 50)).front;
        g = EZText(w, 290@40, " test  ", textWidth: 220, layout: \horz);
        g.setColors(Color.grey, Color.white);
);


// 一个窗口上有许多 textField
(
w = Window.new.front;
w.view.decorator = FlowLayout(w.view.bounds);
w.view.decorator.gap = 2@2;

40.do{
        g = EZText(w, 170@16, " test  ", textWidth: 120, layout: \horz);
        g.setColors(Color.grey, Color.white, Color.grey(0.8));
};
);


// 点击这些括号以查看三种变体
(

m = nil;
m = 2@2;        // 注释以取消边距

/////////////////
/// 布局 \horz

(        // 带标签
        g = EZText(nil, 170@20, " freq  ", textWidth: 120, layout: \horz, margin: m);
        g.setColors(Color.grey, Color.white, background: Color.grey(0.7));
        g.window.bounds = g.window.bounds.moveBy(-180, 50);
);

(        // 无标签。使用窗口名称作为标签
        g = EZText(nil, 120@20, layout: \horz, margin: m);
        g.setColors(Color.grey, Color.white, background: Color.grey(0.7));
        g.window.bounds = g.window.bounds.moveBy(-180, -90);
        g.window.name = "Freq";
);

/////////////////
/// 布局 \vert

(        // 所有功能
        g = EZText(nil, 120@60, " freq  ", textWidth: 120, layout: \vert, margin: m);
        g.setColors(Color.grey, Color.white, background: Color.grey(0.7));
        g.window.bounds = g.window.bounds.moveBy(100, 50);
);

)



// 最简单的声音示例
(
Tdef(\text).set(\note, [0, 2, 7], \dur, { [0.1, 0.2].choose });

w = Window("EZTexts", Rect(200, 400, 304, 120)).front;
w.addFlowLayout;

TdefGui(Tdef(\text), 0, w);
Tdef(\text).envir.keysValuesDo { |k, v|
    EZText(w, Rect(0, 0, 300, 40), k, { |ez|
        Tdef(\text).envir.put(*[k, ez.value].postcs);
    }, v);
};

Tdef(\text, { |ev|
    var mydur;
    loop {
        mydur = ev.dur;
        (note: ev.note, dur: mydur).postln.play;
        mydur.wait;
    }
}).play;
)

// 在 dur 和 note 字段中输入这些或类似的函数并求值：

{ [0.1, 0.2, 0.3].choose }
{ [0, 2, 7, 10].scramble.keep(rrand(0, 4)) }
