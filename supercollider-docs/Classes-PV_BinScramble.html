PV_BinScramble

打乱频段。

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

说明

随机化 bin 的顺序。触发时会选择一个新的随机顺序。

类方法

PV_BinScramble.new(buffer, wipe: 0.0, width: 0.2, trig: 0.0)

参数：

buffer

FFT 缓冲区。

wipe

当 wipe 从 0 移动到 1 时，会打乱更多的 bin。

width

一个从 0 到 1 的值，指示频谱中分 bin 相对于其原始位置的最大随机距离。

trig

一个触发器，用于选择新的随机排序。

实例方法

示例

s.boot;
b = Buffer.read(s, ExampleFiles.child);

(
// 用 MouseY 触发
SynthDef("help-binScramble", { |out = 0, soundBufnum = 2|
    var in, chain;
    in = PlayBuf.ar(1, soundBufnum, BufRateScale.kr(soundBufnum), loop: 1);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_BinScramble(chain, MouseX.kr, 0.1, MouseY.kr > 0.5);
    Out.ar(out, 0.1 * IFFT(chain).dup);
}).play(s, [\soundBufnum, b]);
)
