T2K

音频速率触发到控制速率触发的转换器

A2K : PureUGen : UGen : AbstractFunction : Object

参见：T2A、K2A、A2K

说明

将音频速率触发转换为控制速率触发，使用每个控制周期内输入中的最大触发电平。

类方法

T2K.kr(in: 0.0)

来自父类：A2K

参数：

in

一个音频速率输入信号。

讨论：

注意： 在 UGen 图初始化期间，T2K 只有在第一个音频速率输入帧上收到触发时才会产生触发。在第一个帧之后、但在第一个块内收到的任何触发，在初始化时都不会被看到。因此，下游 UGen 也不会收到那个被遗漏的触发，这可能会影响它们的初始化状态。然而，一旦 Synth 开始运行，T2K 就会按预期触发。

实例方法

示例

// 这不起作用：
(
{
    var trig = Dust.ar(4);
    Trig.kr(trig, 0.1) * SinOsc.ar(800) * 0.1
}.play;
)

// this works:
(
{
    var trig = T2K.kr(Dust.ar(4));
    Trig.kr(trig, 0.1) * SinOsc.ar(800) * 0.1
}.play;
)
