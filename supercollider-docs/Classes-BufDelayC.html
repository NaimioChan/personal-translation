BufDelayC

基于缓冲区的简单延迟线，带三次插值。

BufDelayN : UGen : AbstractFunction : Object

另请参见：BufDelayL、BufDelayN、DelayC

说明

使用三次插值的简单延迟线，其内部存储使用一个缓冲区。另见 BufDelayN（不使用插值）和 BufDelayL（使用线性插值）。三次插值比线性插值计算开销更大，但更精确。

类方法

BufDelayC.ar(buf: 0, in: 0.0, delaytime: 0.2, mul: 1.0, add: 0.0)

来自父类：BufDelayN

BufDelayC.kr(buf: 0, in: 0.0, delaytime: 0.2, mul: 1.0, add: 0.0)

来自父类：BufDelayN

参数：

buf

缓冲区编号。

注意： 提供给任何 BufDelay 单元的缓冲区必须是单通道的。如果你想延迟多通道信号，必须提供与输入通道数相同数量的独立（单通道）缓冲区。

in

输入信号。

delaytime

延迟时间，单位为秒。

讨论：

警告： 出于效率原因，有效缓冲区大小被限制为不超过其的前一个 2 的幂。因此，如果分配了 44100 个采样，最大延迟将是 32768 个采样。

实例方法

示例

// 分配缓冲区
b = Buffer.alloc(s, 44100, 1);

(
// Dust 随机触发 Decay，为 WhiteNoise 输入源
// 创建指数衰减包络
{
z = Decay.ar(Dust.ar(1, 0.5), 0.3, WhiteNoise.ar);
BufDelayC.ar(b.bufnum, z, 0.2, 1, z); // 输入通过 add 输入与延迟混合
}.play
)

b.free;


// 多声道

// 两个声道，两个缓冲区
b = Buffer.allocConsecutive(2, s, 32768, 1);

a = { |bufs = #[0, 1]|
    var sig = SinOsc.ar([440, 880]) * Decay2.kr(Impulse.kr([2, 4]), 0.01, 0.15);
    sig + BufDelayC.ar(bufs, sig, delaytime: 0.125)
}.play(args: [bufs: b]);

a.free;
b.do(_.free);
