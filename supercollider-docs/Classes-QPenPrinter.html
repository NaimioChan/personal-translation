QPenPrinter

QPen PDF 导出与矢量图形打印

参见：Pen

说明

QPenPrinter 允许 Pen 在打印机设备上进行操作。通过将打印机设备用作 "print to file"，可将图形导出为 PDF。

类方法

.new

创建一个新的 QPenPrinter 对象。

返回值：

QPenPrinter 的一个实例

.print

用于显示打印对话框并打印的便捷函数。

参数：

printFunc

当用户按下 "Print" 时要计算的 Function，以 printer 对象作为 Pen 绘制目标。参见下文 -print 中的 aPrintFunc。

cancelFunc

一个可选的 Function，在用户按下"Cancel"时求值。

实例方法

Printing

.showDialog

显示一个打印对话框，允许用户配置打印机对象。此操作是异步的，方法会立即返回。当用户按下“打印”按钮时，会以该 QPenPrinter 对象作为参数调用 aOkFunc。

参数：

aOkFunc

一个 Function，当用户按下“Print”时求值。

aCancelFunc

一个可选的 Function，在用户按下"Cancel"时求值。

.print

此方法执行实际的打印或 PDF 导出。它以打印机对象作为 Pen 绘制目标来求值 aPrintFunc。此 QPenPrinter 对象作为参数传入。

所有常规的 Pen 命令都可以在该函数内使用。

参数：

aPrintFunc

一个要被执行以绘制图形的 Function。

讨论：

如果在未先配置 printer 对象的情况下调用此方法，它将使用默认设置在默认打印机上打印。

此方法通常从上面 -showDialog 的 aOkFunc 内部调用。在 showDialog 配置过一次 printer 之后，可以多次调用此方法来复用上一次的 printer 配置。

位于 (0@0) 的点将与 -pageRect 的原点重合，后者按页边距进行了偏移。因此你不需要平移 Pen。

.newPage

开始一个新页面。通常在 -print 的 aPrintFunc 内部调用。

Properties

.paperRect

获取纸张边界。

返回值：

一个 Rect

.pageRect

获取页面边界，即可打印区域，由于边距通常小于 -paperRect。

返回值：

一个 Rect

讨论：

Rect 的原点相对于纸张，并且由于边距会是非零值。

.pageSize

以 Size 形式获取页面大小。

返回值：

一个 Size

讨论：

如果已知图形的边界，可用于缩放图形以适应页面：

x = penPrinter.pageSize.width / bounds.width;
Pen.scale(x, x);
// ... 在此处绘制内容 ...

页面范围

以下方法返回用户选择的页码范围。页码从 1 开始。当两个方法都返回 0 时，表示“打印所有页面”。

.fromPage

获取起始页。

返回值：

一个 Integer

.toPage

获取结束页。

返回值：

一个 Integer

示例

简单用法：

QPenPrinter.print {
    // 第一页
    Pen.moveTo(100@100);
    Pen.lineTo(300@300);
    Pen.stroke;

    // second page
    p.newPage;
    Pen.addRect(p.pageSize.asRect);
    Pen.stroke;
}

保留 QPenPrinter 对象以保存配置状态：

p = QPenPrinter();

下面的代码随后可以多次调用：

p.showDialog {
    p.print {
        // 第一页
        Pen.moveTo(100@100);
        Pen.lineTo(300@300);
        Pen.stroke;

        // second page
        p.newPage;
        Pen.addRect(p.pageSize.asRect);
        Pen.stroke;
    }
} {
    "Printing cancelled!".postln;
};
