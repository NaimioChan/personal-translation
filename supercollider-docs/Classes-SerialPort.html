SerialPort

串口接口

Object

此类提供对串口通信的基本支持。端口通过 *new 打开，通过 -close 关闭。

每个 SerialPort 对象使用 8KB 的内部缓冲区，并在数据可用时立即读取。如果未从缓冲区中读出数据且缓冲区已满，则传入的字节将被丢弃。使用 -rxErrors 获取已丢弃字节数的计数。

由于它不断轮询端口以获取可用数据，SerialPort 对象几乎能立即得知端口已丢失。发生这种情况时，它会调用 -doneAction 回调并将自身标记为已关闭。

类方法

SerialPort.new(port, baudrate: 9600, databits: 8, stopbit: true, parity, crtscts: false, xonxoff: false, exclusive: false)

创建并打开端口。若创建失败则抛出异常；这可能是因为端口不存在、端口无法打开，或设置无效。

参数：

port

一个 String，表示要打开的端口。（允许使用 Integer 作为 *devices 中的索引，但这种方式已弃用。）

baudrate

整数波特率，通常在 [4800..230400] 范围内。

databits

每个字符的位数。通常为 8，但可以是任意整数。

stopbit

一个 Boolean，指示使用两个停止位（true）还是一个停止位（false）。

parity

端口使用偶校验、奇校验还是无校验。传入 'even'、'odd' 或 nil（表示无校验）。

crtscts

一个 Boolean，指示是否使用硬件流控制（RTS/CTS 信号）。

xonxoff

一个 Boolean，表示是否使用软件流控制（XON/XOFF 信号）。

exclusive

一个 Boolean，指示是否以独占方式打开设备。此选项在 Windows 上未实现。

讨论：

crtscts 和 xonxoff 不能同时为 true；如果两者都设置，*new 将抛出错误。

SerialPort.devices

获取一个以 Strings 表示的可用设备数组。在 macOS 和 Linux 上，该列表是通过对 /dev/ 目录中的文件应用若干正则表达式规则获得的。在 Windows 上，则是通过注册表键获得的。匹配规则的设计与 Arduino IDE 的规则完全相同。

为向后兼容，如果 SerialPort.devicePattern 不为 nil，则返回 SerialPort.devicePattern.pathMatch 而非默认行为。

SerialPort.devices;

SerialPort.listDevices

打印可用设备列表，每行一个。是 SerialPort.devices.do(_.postln) 的简写。

SerialPort.listDevices;

SerialPort.devicePattern

SerialPort.devicePattern = value

如果设置为非 nil 值，SerialPort.devicePattern 将改为返回 SerialPort.devicePattern.patchMatch。也就是说，这个类变量的值被用作文件 glob。

这是一个遗留特性，不再推荐使用。仅靠文件通配不足以捕获一般的可能串口路径集合，而且这种程度的定制对 SerialPort.devices 来说并不必要。如果你需要细化 SerialPort.devices 返回的结果，最好自己进行匹配或过滤。

SerialPort.closeAll

对所有端口调用 -close。

SerialPort.cleanupAll

已弃用；请改用 *closeAll。

实例方法

.isOpen

此对象是否表示有效的串口连接。

.next

从设备读取一个字节。非阻塞读取。

.read

从设备读取一个字节。阻塞读取。

.rxErrors

自上次查询以来的 RX（接收）错误数。当内部缓冲区完全满时会发生 RX 错误。每次调用此方法时，该计数都会重置为 0。

.put(byte, timeout: 0.005)

向设备写入一个字节。总是阻塞。

参数：

byte

一个 Integer 或 Char。只能写入 0 到 2**databits - 1 范围内的值。如果将超出该范围的值传给 put，则只会使用最低位。

timeout

未使用，已弃用。

返回值：

一个 Boolean，表示写入是否成功。

.putAll(bytes, timeout: 0.005)

向设备写入多个字节。

参数：

bytes

集合可以是 Int8Array 或 String。

timeout

未使用，已弃用。

.doneAction

.doneAction = value

一个 Function，当端口被关闭时（可能是意外关闭，例如由于硬件故障或意外断开连接）会被求值。例如，这允许你制定一个备份方案并激活它（例如为你的算法使用伪造的输入数据，或尝试重新打开设备）。默认情况下，它会发布一条消息，内容为 "SerialPort X was closed"。

.close

关闭端口。

示例

(
p = SerialPort(
    "/dev/tty.usbserial-181",
    baudrate: 9600,
    crtscts: true);
)

// 从设备读取一个字节

p.next; // 不阻塞
fork { p.read.postln }; // 可能会挂起 thisThread - 应在 routine 中调用

// 向设备写入一个字节

fork { p.put(42) }; // 可能会挂起 thisThread - 应在 routine 中调用

// 向设备写入多个字节

fork { p.putAll("whaddayawant") };
fork { p.putAll(Int8Array[13, 10]) };

p.doneAction = { "my serial port got closed".postln }

p.close; // 关闭端口

SerialPort.closeAll; // 关闭所有端口

Arduino 写入示例

首先加载示例 Examples/Communication/Dimmer。参见 http://www.arduino.cc/en/Tutorial/Dimmer。

注意： 在 SuperCollider 中打开端口之前，务必确保 Arduino 应用程序中的串行监视器已关闭。

(
p = SerialPort(
    "/dev/tty.usbserial-A800crTT",    // 编辑以匹配你的端口。SerialPort.listDevices
    baudrate: 9600,    // 检查 baudrate 是否与 arduino sketch 中相同
    crtscts: true);
)

// 发送串行数据 - 慢速脉动
(
r = Routine({
    inf.do{ |i|
        p.put(i.fold(0, 100).linexp(0, 100, 1, 255).asInteger.postln);
        0.02.wait;
    };
}).play;
)

r.stop;
p.close;

Arduino 读取示例

首先加载 sketch Examples/Communication/Graph。参见 http://www.arduino.cc/en/Tutorial/Graph。

注意： 在 SuperCollider 中打开端口之前，务必确保 Arduino 应用程序中的串行监视器已关闭。

(
p = SerialPort(
    "/dev/tty.usbserial-A800crTT",    // 编辑以匹配你的端口。SerialPort.listDevices
    baudrate: 9600,    // 检查 baudrate 是否与 arduino sketch 中相同
    crtscts: true);
)

// 读取从 Arduino 的 Serial.println 发送的 10bit 串行数据
(
r = Routine({
    var byte, str, res;
    99999.do{ |i|
        if(p.read == 10, {
            str = "";
            while({ byte = p.read; byte != 13 }, {
                str = str++byte.asAscii;
            });
            res = str.asInteger;
            ("read value:"+res).postln;
        });
    };
}).play;
)

r.stop;
p.close;
