SCDocNode

一个 SCDoc 解析后的文档节点

Object

另请参阅：SCDoc

说明

此类由 SCDoc 内部使用，用于表示解析器返回的已解析文档树中的一个节点。它有一个 id 符号、可选的文本和可选的子节点。

类方法

SCDocNode.new(maxSize: 0)

来自父类：Object

创建一个新节点

实例方法

.id

.id = value

节点 ID。一个 Symbol

.text

.text = value

与此节点关联的文本。一个字符串或 nil。

.children

.children = value

此节点的子节点。一个 Array 或 nil。

.merge(root2)

将另一个文档节点树与此文档节点树合并。用于文档添加（*.ext.schelp）

参数：

root2

另一个 SCDocNode 实例。

.findChild(id)

查找此节点中具有指定 id 的第一个子节点。

参数：

id

一个 Symbol
