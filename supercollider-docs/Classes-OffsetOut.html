OffsetOut

以采样精确的时序将信号写入总线。

Out : AbstractOut : UGen : AbstractFunction : Object

另请参见：Out、ReplaceOut、XOut

说明

将信号输出到总线，总线内的采样偏移被精确保持；也就是说，如果 synth 被安排在一个控制周期中途开始，OffsetOut 会通过缓冲输出并延迟到 synth 被安排的确切时间来保持正确的偏移。

要实现子采样精度，请参见 SubsampleOffset

注意： 注意，如果合成器有输入，它会以正常时间进入，然后在你的合成器中混合，随后随输出一起延迟。因此你不应将 OffsetOut 用于效果或门控。

有关总线及其使用方式的更多信息，请参阅 Server Architecture 和 Bus 帮助文件。

类方法

OffsetOut.ar(bus, channelsArray)

来自父类：Out

参数：

bus

要写入的总线索引。编号最小的总线写入音频硬件。

channelsArray

用于写出的通道数组或单个输出。一旦 SynthDef 构建完成，就无法更改其大小。

实例方法

示例

(
SynthDef("help-OffsetOut",
    { |out = 0, freq = 440, dur = 0.05|
        var env;
        env = EnvGen.kr(Env.perc(0.01, dur, 0.2), doneAction: Done.freeSelf);
        OffsetOut.ar(out, SinOsc.ar(freq, 0, env))
}).send(s);

SynthDef("help-Out",
    { |out = 0, freq = 440, dur = 0.05|
        var env;
        env = EnvGen.kr(Env.perc(0.01, dur, 0.2), doneAction: Done.freeSelf);
        // 与 Out 比较：
        Out.ar(out, SinOsc.ar(freq, 0, env))
}).send(s);
)


// 它们是同步的
(
Routine({
    loop {
        s.sendBundle(0.2, ["/s_new", "help-OffsetOut", -1]);
        0.01.wait;
    }
}).play;
)

// 这些不太可靠地同步，并放置在块大小的倍数处。
(
Routine({
    loop {
        s.sendBundle(0.2, ["/s_new", "help-Out", -1]);
        0.01.wait;
    }
}).play;
)



SynthDef("trig1", {
    var gate, tone;
    gate = Trig1.ar(1.0, t);
    tone = In.ar(10, 1); // 音调正常进入
    // 但随后会被 OffsetOut 延迟
    OffsetOut.ar(0,
        tone * EnvGen.ar(
                Env([0, 0.1, 0.1, 0], [0.01, 1.0, 0.01], [-4, 4], 2),
                gate, doneAction: Done.freeSelf
            )
    )
})
