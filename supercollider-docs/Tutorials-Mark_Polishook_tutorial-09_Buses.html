09_Buses

Mark Polishook 教程

另见：00_入门教程

默认情况下，SuperCollider 有 1024 条用于音频信号的总线和 16,384 条用于控制信号的总线。这些总线是数组中的元素，SuperCollider 用它们来表示音频速率和控制速率的数据。

////////////////////////////////////////////////////////////////////////////////////////////////////

// 音频总线（通道）的数组
[ channel0, channel1, channel2, channel3, channel4, ... , ..., ..., etc., ... channel127 ]

// 控制总线（通道）的数组
[ channel0, channel1, channel2, channel3, channel4, ... , ..., ..., etc., ... channel4095 ]

将音频放入总线

在音频速率下使用 Out ugen 将数据放入音频总线。

(
SynthDef("dataForABus", {
    Out.ar(
        0,        // 将 1 个通道的音频写入总线 0
        Saw.ar(100, 0.1)
    )
}).add;
)

Synth("dataForABus");

一个 SynthDef 浏览器

(
SynthDescLib.global.read;
SynthDescLib.global.browse;
)

在通道 0 上显示 1 个通道的输出。

从总线获取音频

向 In ugen 发送 .ar 消息以从音频总线获取数据。

(
SynthDef("dataFromABus", {
    Out.ar(
        0,
        [    // 左声道从一条音频总线获取输入
            In.ar(0, 1),
            SinOsc.ar(440, 0.2)
        ]
    )
}).add;
)

(
Synth("dataForABus");    // 在通道 0 上合成一个锯齿波
Synth("dataFromABus");    // 在通道 1 上将其与正弦波配对
)

控制速率总线

使用 In.kr 和 Out.kr 读取或写入控制总线。
