StandardL

标准映射混沌生成器

StandardN : ChaosGen : UGen : AbstractFunction : Object

参见：StandardN

说明

一种基于差分方程的线性插值声音发生器：

    x(n+1) = (x(n) + y(n+1)) % 2pi
    y(n+1) = (y(n) + k * sin(x(n))) % 2pi

标准映射是由等离子体物理学家 Boris Chirikov 发现的柱面上的一种保面积映射。

sclang 代码转换：

(
var k = 1, xi = 0.5, yi = 0, size = 64;
plot(size.collect { yi = yi + (k * sin(xi)) % 2pi; xi = (xi + yi) % 2pi; xi - pi * 0.3183098861837907 });
)

类方法

StandardL.ar(freq: 22050, k: 1.0, xi: 0.5, yi: 0, mul: 1.0, add: 0.0)

来自父类：StandardN

参数：

freq

以赫兹为单位的迭代频率

k

扰动量

xi

x 的初始值

yi

y 的初始值

实例方法

示例

// 改变频率
{ StandardL.ar(MouseX.kr(20, SampleRate.ir)) * 0.3 }.play(s);
// 鼠标控制的参数
{ StandardL.ar(SampleRate.ir/2, MouseX.kr(0.9, 4)) * 0.3 }.play(s);
// 作为频率控制
{ SinOsc.ar(StandardL.ar(40, MouseX.kr(0.9, 4))*800+900)*0.4 }.play(s);
