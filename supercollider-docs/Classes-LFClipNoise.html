LFClipNoise

削波噪声

LFNoise0 : UGen : AbstractFunction : Object

另请参见：LFDClipNoise、LFDNoise0、LFDNoise1、LFDNoise3、LFNoise0、LFNoise1、LFNoise2

说明

以采样率除以 freq 参数所得最近整数商的速率随机生成 -1 或 +1 的值。这对你的扬声器来说可能相当吃力！

类方法

LFClipNoise.ar(freq: 500.0, mul: 1.0, add: 0.0)

来自父类：LFNoise0

LFClipNoise.kr(freq: 500.0, mul: 1.0, add: 0.0)

来自父类：LFNoise0

参数：

freq

生成随机值的近似速率。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

(
SynthDef("help-LFClipNoise", { |out = 0|
    Out.ar(out,
        LFClipNoise.ar(1000, 0.25)
    )
}).play;
)

// 调制频率
(
SynthDef("help-LFClipNoise", { |out = 0|
    Out.ar(out,
        LFClipNoise.ar(XLine.kr(1000, 10000, 10), 0.25)
    )
}).play;
)

// 用作频率控制
(
SynthDef("help-LFClipNoise", { |out = 0|
    Out.ar(out,
        SinOsc.ar(
            LFClipNoise.ar(4, 200, 600),
            0, 0.2
        )
    )
}).play;
)
