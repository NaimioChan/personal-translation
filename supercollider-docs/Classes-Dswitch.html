Dswitch

用于嵌入不同输入的需求速率生成器

Dswitch1 : DUGen : UGen : AbstractFunction : Object

另请参阅：Demand、Dswitch1

说明

用于嵌入不同输入的 demand rate 生成器。与 Dswitch1 不同，Dswitch 会先嵌入输入 demand ugen 的所有项，然后再查找下一个索引。

类方法

Dswitch.new(list, index)

来自父类：Dswitch1

参数：

list

值或其他 ugens 的数组

index

返回哪个输入

讨论：

结构相关：Pswitch

实例方法

示例

(
    {
        var d, trig;
        d = Dswitch([
            Dwhite(3, 4, 2),
            Dwhite(0, 1, 2),
            Dseq([1, 1, 1, 0], 2)
        ], Dseq([0, 1, 2, 1, 0], 2));

        trig = Impulse.kr(4);

        SinOsc.ar(
            Demand.kr(trig, 0, d).poll(trig)
            * 300 + 400
        )
        * 0.1 ! 2
    }.play;
);

// 与 Dswitch1 比较：

(
    {
        var d, trig;
        d = Dswitch1([
            Dwhite(3, 4, 2),
            Dwhite(0, 1, 2),
            Dseq([1, 1, 1, 0], 2)
        ], Dseq([0, 1, 2, 1, 0], 2));

        trig = Impulse.kr(4);

        SinOsc.ar(
            Demand.kr(trig, 0, d).poll(trig)
            * 300 + 400
        )
        * 0.1 ! 2
    }.play;
);
