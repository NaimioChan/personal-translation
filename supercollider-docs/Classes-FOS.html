FOS

一阶滤波器节。

Filter : PureUGen : UGen : AbstractFunction : Object

参见：SOS

说明

标准一阶滤波器节。滤波器系数直接给出，而非由系统计算。公式等价于：

out(i) = (a0 * in(i)) + (a1 * in(i-1)) + (b1 * out(i-1))

类方法

FOS.ar(in: 0.0, a0: 0.0, a1: 0.0, b1: 0.0, mul: 1.0, add: 0.0)

FOS.kr(in: 0.0, a0: 0.0, a1: 0.0, b1: 0.0, mul: 1.0, add: 0.0)

参数：

in

信号输入。

a0

参见上面的公式。

a1

参见上面的公式。

b1

参见上面的公式。

mul

add

实例方法

示例

(
// 与 OnePole 相同
{    var x;
    x = LFTri.ar(0.4, 0, 0.99);
    FOS.ar(LFSaw.ar(200, 0, 0.2), 1 - x.abs, 0.0, x)
}.play;
)

(
// 与 OneZero 相同
{    var x;
    x = LFTri.ar(0.4, 0, 0.99);
    FOS.ar(LFSaw.ar(200, 0, 0.2), 1 - x.abs, x, 0.0)
}.play;
)

(
// 与 OnePole 相同，kr
{    var x, ctl;
    x = LFTri.kr(0.2, 0, 0.99);
    ctl = FOS.kr(LFSaw.kr(8, 0, 0.2), 1 - x.abs, 0.0, x);
    LFTri.ar(ctl * 200 + 500);
}.play;
)
