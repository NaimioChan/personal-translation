Tap

单次抽头进入延迟线

UGen : AbstractFunction : Object

另请参阅：MultiTap、PlayBuf

说明

Tap UGen 允许在延迟处对缓冲区进行一次采样。

Tap 内部使用 PlayBuf UGen

类方法

Tap.ar(bufnum: 0, numChannels: 1, delaytime: 0.2)

参数：

bufnum

要使用的缓冲区索引

numChannels

缓冲区的通道数

delaytime

抽头延迟；无法被调制

实例方法

示例

// 创建一个缓冲区。
b = Buffer.alloc(s, s.sampleRate, 1); // 足够容纳一秒的单声道音频

// 用 BufWr 写入 Buffer，用两个 Tap 读取，每只耳朵各一个！
(
SynthDef(\helpTap, { |out, bufnum|
    var source, capture;

    source = SoundIn.ar(0); // 使用耳机以避免反馈
    capture = BufWr.ar(source, bufnum, Phasor.ar(0, 1, 0, BufFrames.ir(bufnum), 1));

    Out.ar(out, Tap.ar(bufnum, 1, [0.1, 0.9])); // 多声道扩展，因此每只耳朵一个 tap
}).add;
)

x = Synth(\helpTap, [\bufnum, b]);

x.free;
