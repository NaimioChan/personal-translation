GUI：教程介绍

GUI 教程概览

About

SuperCollider 的语言 sclang 提供了一些专门用于创建图形用户界面 (GUI) 的类，允许你创建自己的图形界面。

在底层架构中，GUI 类是使用专为此目的而设的第三方库创建的，该库称为 Qt。Qt 受到最常见操作系统的支持，从而支持跨平台开发。默认 IDE scide 即基于 Qt。

本教程系列的目标是在 sclang 范围内提供 GUI 操作的基础知识。它旨在让初学者也能理解，并遵循循序渐进的进程，配有示例说明。

教程组织

  • 1. GUI: Create a Window：窗口创建基础。
  • 2. GUI：将乐器与 View 对接：将 Synth 与界面（键盘和音量滑块）对接，并介绍布局系统。
  • 3. GUI：用基本组件组合视图：关于组合视图的文档示例：带可编辑文本的滑块、标签系统以及最小化系统。
  • A. GUI：你可能想知道的事：关于 GUI 使用的各种警告和提示。
