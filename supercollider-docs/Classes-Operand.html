Operand

数学运算的幂等包装

AbstractFunction : Object

参见：AbstractFunction、Maybe、Ref、Rest

子类：Rest

说明

如果你需要确保数学运算始终返回包装在特定对象中的结果，可以使用 Operand 或从其派生子类。一些实用示例，请参阅其子类 Rest。如果你需要保留嵌套运算，请使用 Maybe。

其创建是幂等的，即 Operand(Operand(x)) == Operand(x)。

// 一个操作数就是一个操作数就是一个操作数
Operand(Operand(Operand(1))) - 1 == 0
// 数学运算
a = Operand(2);
b = Operand([1, 2, 3]);
c = a + b * a; // Operand([6, 8, 10])
c.value; // [6, 8, 10]

类方法

Operand.new(value)

参数：

value

返回 Operand 的新实例，使用任意对象作为值。

a = Operand(1) + 7; // 返回 Operand(8)

// *new 方法是幂等的：
Operand(Operand(Operand(1))) == Operator(1)

实例方法

.value

.value = value

设置或返回当前值。

a = Operand(2) ** 8;
a.value; // 256
a.value = 78;
a.value; // 78

==(obj)

参数：

obj

如果两个 Operand 的值相等，则它们相等。

Operand(1) == Operand(1);
Operand(1) + 2 == Operand(3);

.hash(obj)

具有相同值的两个实例返回相同的哈希值。

Set[Operand(1), Operand(1)] == Set[Operand(1)] // true

.dereferenceOperand

调用此方法以避免嵌套。你可以在子类中重写它，以对结果值执行操作。Operand(Operand(1)) // Operand(1)。

示例

// 你可以创建一个总是将值转换为整数的类：

IntegerOperand : Operand {
    dereferenceOperand {
        ^value.asInteger
    }
}

// 那么你会得到：
IntegerOperand(1) + pi == IntegerOperand(4)
