Help

SuperCollider 有一个内置的帮助系统。要查看主帮助页面，请按 cmd-d（无需先选择任何内容）。在该页面中，点击带下划线的主题。另一个有用的文档是 更多关于获取帮助。

通常，类（首字母大写的词，如 SinOsc、Array、Nil 等）都有帮助文件。选中类名并按 Cmd-d。如果存在帮助文件，它将会打开。

类定义、消息实现以及 Find 命令

要查看类定义的源代码，请选中类名并输入 cmd-j

要查看一个或多个类如何实现某条消息，请选中该消息名并按 cmd-y。

使用通过 Edit 菜单提供的 Find 和 Find Next 命令，在最前面的文档中搜索文本

grep

在终端中（位于 Applications->Utilities 文件夹）使用 grep 来搜索给定单词或短语的所有出现位置。例如，要查看所有使用 LFSaw 类的文档，请（在终端应用程序中）执行

grep -r LFSaw /Applications/SuperCollider

由于终端应用程序中的行会根据窗口大小而不是通过增强可读性的方案来换行，因此将 grep 结果写入文件可能更容易，例如

// 根据需要更改路径的名称（即 '>' 符号后面的参数
grep -r LFSaw /Applications/SuperCollider/ > /Users/yourHomeDirectory/Desktop/grep_results
