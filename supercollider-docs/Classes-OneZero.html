OneZero

单零点滤波器。

OnePole : Filter : PureUGen : UGen : AbstractFunction : Object

另请参阅：OnePole

说明

单零点滤波器。实现以下公式：

out(i) = ((1 - abs(coef)) * in(i)) + (coef * in(i-1)).

类方法

OneZero.ar(in: 0.0, coef: 0.5, mul: 1.0, add: 0.0)

来自父类：OnePole

OneZero.kr(in: 0.0, coef: 0.5, mul: 1.0, add: 0.0)

来自父类：OnePole

参数：

in

输入信号。

coef

前馈系数。

+0.5 构成一个两点平均滤波器（另请参阅 LPZ1）。

-0.5 构成微分器（另请参见 HPZ1）。

+1 产生单个采样的延迟（另见 Delay1）。

-1 会产生一个反相的单个采样延迟。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

{ OneZero.ar(WhiteNoise.ar(0.5), 0.5) }.play

{ OneZero.ar(WhiteNoise.ar(0.5), -0.5) }.play

{ OneZero.ar(WhiteNoise.ar(0.5), Line.kr(-0.5, 0.5, 10)) }.play
