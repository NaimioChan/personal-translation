Operators

常见的一元和二元运算符

另请参阅：二元运算符的副词

SuperCollider 支持运算符重载。因此运算符可应用于各种不同的对象：Number、UGen、Collection 等等。当运算符应用于 UGen 时，通过 AbstractFunction 的方法，会生成 BinaryOpUGen 或 UnaryOpUGen。

以下列出了若干类所实现的部分常见一元和二元运算符。详情及其他运算符请参阅具体类。

你可以通过点击方法名来查看哪些类实现了特定的运算符。

二元运算符

由字母组成的二元运算符可以使用三种不同的语法：

operator(a, b)

a operator: b

a.operator(b)

由符号组成的运算符写法如下：

a + b

Arithmetics

+

Addition.

-

Subtraction.

*

Multiplication.

/

Division.

%

Modulo.

注意： 使用向下取整除法。在 SC 3.14 之前，整数取模在负模数下会表现出意外行为；请参见 Integer: -modSeaside。

**

幂运算。与 pow 相同。

pow

Exponentiation.

注意： 当与产生负信号的 UGen 一起使用时，此函数扩展了通常的幂运算定义，并返回 neg(neg(a) ** b)。这允许对负信号值进行非整数指数的幂运算。

lcm

最小公倍数。此定义扩展了通常的定义，如果任一操作数为负数，则返回负数。这使其与格论解释及其幂等性、交换律、结合律、吸收律保持一致。

借鉴编程语言 J 的示例（参见：SC 中的 J 概念），lcm 类似于逻辑与（另请参见：http://www.jsoftware.com/papers/eem/gcd.htm）。

lcm(4, 6);
lcm(1, 1); // and
lcm(1624, 26);
lcm(1624, -26);
lcm(-1624, -26);
lcm(513, gcd(513, 44)) // 吸收律 -> 513。
(
{
    var mx = MouseX.kr(-20, 20);
    var my = MouseY.kr(-20, 20);
    SinOsc.ar(SinOsc.kr(0.3) * 20 lcm: [mx, my] * 30 + 500) * 0.1
}.play;
)

gcd

最大公约数。此定义扩展了通常的定义，并且在两个操作数均为负数时返回负数。这使其与格论解释及其幂等律、交换律、结合律、吸收律保持一致。

在此解释中，"greater" 意味着 "可被整除"，因此 gcd(-1, -1) 返回一个负数。这是使整个系统保持一致所必需的（算术基本定律、幂等律和吸收律将会失效）。参见下面的示例。

参照编程语言 J 的示例（参见：SC 中的 J 概念），gcd 类似于逻辑 或（另请参见：http://www.jsoftware.com/papers/eem/gcd.htm）。

gcd(4, 6);
gcd(0, 1); // or
gcd(1024, 256);
gcd(1024, -256);
gcd(-1024, -256); // 这里的 "greater" 意思是 "可被整除"，所以这返回一个负数。
gcd(-1024, lcm(-1024, 256)) // 吸收律 -> -1024。
gcd(66, 54) * lcm(66, 54) == (66 * 54); // true
(
{
    var mx = MouseX.kr(-200, 200);
    var my = MouseY.kr(-200, 200);
    SinOsc.ar(SinOsc.kr(0.3) * 20 gcd: [mx, my] * 30 + 500) * 0.1
}.play;
)

以下是负数处理方式的概述：

lcm(4, 6) // -> 12。"least multiple" 解释为 Z 中的最小值
lcm(4, -6) // -> -12 "least multiple" 解释为 Z 中的最小值
lcm(-4, -6) // -> -12 "least multiple" 解释为 Z 中的最小值

gcd(4, 6) // -> 2 "最大除数" 解释为 Z 中的最高值
gcd(4, -6) // -> 2 "最大除数" 被解释为 Z 中的最高值
gcd(-4, -6) // -> -2 "最大除数" 在 Z 中被解释为 *逆元*。这是唯一必要的非对称性。

// 此 synth 没有输出。它只检查输入的振幅，并寻找从 < 0.2

hypot

Hypotenuse。返回 a 和 b 的平方和的平方根。或者等价地，返回从原点到点 (x, y) 的距离。

讨论：

在此示例中，hypot 用于根据距离计算多普勒频移音高和振幅。

(
{
    var x, y, distance, velocity, pitchRatio, amplitude;
    // 物体在 6 秒内移动 200 米（=120kph），从听者
    // 身边 10 米处经过
    x = 10;
    y = LFSaw.kr(1/6, 0, 100);
    distance = hypot(x, y);
    velocity = Slope.kr(distance);
    pitchRatio = (344 - velocity) / 344;  // 声速为 344 米/秒
    amplitude = 10 / distance.squared;
    FSinOsc.ar(1000 * pitchRatio, 0, amplitude)
}.play)

下一个示例使用距离来调制延迟线。

(
{
    var x, y, distance, velocity, pitchRatio, amplitude, motorSound;
    // 物体在 6 秒内移动 200 米（=120kph），从听者
    // 身边 10 米处经过
    x = 10;
    y = LFSaw.kr(1/6, 0, 100);
    distance = hypot(x, y);
    amplitude = 40 / distance.squared;
    motorSound = RLPF.ar(FSinOsc.ar(200, 0, LFPulse.ar(31.3, 0, 0.4)), 400, 0.3);
    DelayL.ar(motorSound, 110/344, distance/344, amplitude)
}.play)

hypotApx

斜边近似。返回 x 与 y 的平方和的平方根的近似值。

讨论：

使用的公式是：

abs(x) + abs(y) - ((sqrt(2) - 1) * min(abs(x), abs(y)))

hypotApx 用于实现 Complex 方法 magnitudeApx。这不应被用于模拟多普勒频移，因为它是不连续的。请使用 hypot。

参见 hypot、atan2。

atan2

返回 y/x 的反正切。

讨论：

好的，现在我们可以通过使用 atan2 求出声源的方位角或方向角，为 hypot 多普勒示例添加声像。假设扬声器位于 +/- 45 度，并将方向裁剪到这些角度之间。

(
{
    var x, y, distance, velocity, pitchRatio, amplitude, azimuth, panValue;
    // 物体在 6 秒内移动 200 米（=120kph），从听者
    // 身边 10 米处经过
    x = 10;
    y = LFSaw.kr(1/6, 0, 100);
    distance = hypot(x, y);
    velocity = Slope.kr(distance);
    pitchRatio = (344 - velocity) / 344;  // 声速为 344 米/秒
    amplitude = 10 / distance.squared;
    azimuth = atan2(y, x); // 方位角（弧度）
    panValue = (azimuth / 0.5pi).clip2(1);
    Pan2.ar(FSinOsc.ar(1000 * pitchRatio), panValue, amplitude)
}.play)

(
{
    var x, y, distance, velocity, pitchRatio, amplitude, motorSound,
            azimuth, panValue;
    // 物体在 6 秒内移动 200 米（=120kph），从听者
    // 身边 10 米处经过
    x = 10;
    y = LFSaw.kr(1/6, 0, 100);
    distance = hypot(x, y);
    amplitude = 40 / distance.squared;
    motorSound = RLPF.ar(FSinOsc.ar(200, 0, LFPulse.ar(31.3, 0, 0.4)), 400, 0.3);
    azimuth = atan2(y, x); // 方位角（弧度）
    panValue = (azimuth / 0.5pi).clip2(1); // 从方位角为 Pan2 生成一个值
    Pan2.ar(DelayL.ar(motorSound, 110/344, distance/344), panValue, amplitude)
}.play)

ring1

环形调制加上第一个源。

讨论：

返回 ((a*b) + a) 的值。这比使用单独的乘法与加法 unit generator 更高效。

参见 *、ring1、ring2、ring3、ring4。

{ (FSinOsc.ar(800) ring1: FSinOsc.ar(XLine.kr(200,500,5))) * 0.125 }.play;

与以下相同：

(
{
    var a, b;
    a = FSinOsc.ar(800);
    b = FSinOsc.ar(XLine.kr(200,500,5));
    ((a * b) + a) * 0.125
}.play)

普通环形调制：

(
{
    var a, b;
    a = FSinOsc.ar(800);
    b = FSinOsc.ar(XLine.kr(200,500,5));
    (a * b) * 0.125
}.play)
