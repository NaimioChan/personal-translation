ルーチンとクロック

时钟提供了在 SuperCollider 中生成自动算法调度的机制。时钟负责播放例程、任务和模式。

パターンとタスクはルーチンから作られます。

ルーチンに対する最初のアーギュメント（そして通常は唯一のアーギュメント）は関数です。

これが関数の一例です。

// 関数を実行するには.valueメッセージを送る
f = { "hello, world" };
f.value;

这是在例程中放置函数的写法。通过发送 .yield 消息来对函数中的表达式求值。

r = Routine({ "hello, world".yield.postln });

ルーチンを実行するには、評価して下さい。

// ルーチンを評価するには、.nextメッセージを送る
r.next;

もう一度やってみましょう。

r.next;

这表明一旦例程"yield"（让出），除非函数中还有更多代码或收到 reset 消息，否则它就会结束。

r.reset;
r.next;

////////////////////////////////////////////////////////////////////////////////////////////////////

在这个引用中，当向例程发送 .next 消息时，会依次传递三个表达式（字符串）。例如，发送 next 消息时，传递一个字符串；再发送 next 消息时，又传递一个字符串，依此类推。

(
r = Routine({
    "hello, world".yield;
    "what a world".yield;
    "i am a world".yield;
});
)

上面示例中最后的 .next 消息将返回 nil。一旦最后的表达式被传递，例程在重置之前将始终返回 nil。

r.next;
r.next;
r.next;
r.next;

////////////////////////////////////////////////////////////////////////////////////////////////////

用 .do 消息重写这个例程，就会创建一个循环。

(
r = Routine({

    var array;
    array = [ "hello, world", "what a world", "i am a world" ];

    3.do({ array.choose.yield })

});
)

如果把这个 do loop 执行得比例程中的循环还多一次，就会像前面的例子一样，返回三个字符串和 nil。

4.do({ r.next.postln });

////////////////////////////////////////////////////////////////////////////////////////////////////

接下来，将本例程改写为包含 .wait 消息的形式。.wait 消息会让“播放”该例程的时钟暂停，暂停时间由该数字指定的秒数决定。

(
r = Routine({

    var array;
    array = [ "hello, world", "what a world", "i am a world" ];

    3.do({ 1.wait; array.choose.postln })

});
)

如以下代码所示，向例程添加 .reset 消息。这样，例程就总是可以重新启动。然后，随时钟一起播放该例程。

以下代码展示了 SuperCollider 在调度事件时使用的三种时钟。

SystemClock.play(r.reset);        // 最も正確
AppClock.play(r.reset);            // GUIで使用する
TempoClock.new.play(r.reset);    // 主に拍でスケジューリングするために使われる

////////////////////////////////////////////////////////////////////////////////////////////////////

或者，可以省略该过程，此时将默认使用 TempoClock。

r.reset.play;

////////////////////////////////////////////////////////////////////////////////////////////////////

ルーチンを用いたシンセシスのスケジューリング

在例程中放入一个 Synth。确保 Synth 中的 SynthDef 一定带有包络，并将该包络的 doneAction 参数设为 2。这样，在包络结束后，该 Synth 所需的内存将被释放。

(
SynthDef("fm2", {
    arg bus = 0, freq = 440, carPartial = 1, modPartial = 1, index = 3, mul = 0.2, ts = 1;

    // 索引值通常从 0 到 24
    // carPartial :: modPartial => 载波/调制比

    var mod;
    var car;

    mod = SinOsc.ar(
        freq * modPartial,
        0,
        freq * index * LFNoise1.kr(5.reciprocal).abs
    );

    car = SinOsc.ar(
        (freq * carPartial) + mod,
        0,
        mul
    );

    Out.ar(
        bus,
        car * EnvGen.kr(Env.sine(1), doneAction: Done.freeSelf, timeScale: ts)
    )
}).add;
)

(
r = Routine({

    12.do({
        Synth("fm2", [\freq, 400.0.rrand(1200), \carPartial, 0.5.rrand(2), \ts, 0.1.rrand(4)]);
        2.wait;
    })
});
)
r.reset.play;

////////////////////////////////////////////////////////////////////////////////////////////////////

ルーチンの中で引き起こされたシンセを、ルーチンの外側で実行するエコー・エフェクト・ユニットを通してプレイします。

(
SynthDef("echoplex", {
    ReplaceOut.ar(
        0,
        CombN.ar(
            In.ar(0, 1),
            0.35,
            [Rand(0.05, 0.3), Rand(0.05, 0.3)],
            // シンセが生成されるたびにランダムな値を生成する
            7,
            0.5
        )
    )
}).add;

// ~sourceグループをルートノードの先頭に追加し、~effectsグループをる−とノードの最後に追加する
~source = Group.head(s);
~effect = Group.tail(s);

r = Routine({

    // ループはinf.doと同じ。例えば、永遠に実行される無限ループを生成する。
    loop({
        Synth.head(    // ~sourceグループの先頭にシンセを追加する
            ~source,
            "fm2",
            [
                \outbus, 0, \freq, 400.0.rrand(1200), \modPartial, 0.3.rrand(2.0),
                \carPartial, 0.5.rrand(11), \ts, 0.1.rrand(0.2)]
        );
        2.wait;
    })
});
// 2つのechoplexesーこれらを~effectsグループの先頭に順に追加する
Synth.head(~effect, "echoplex");
Synth.head(~effect, "echoplex");
)
// ルーチンをプレイする
r.reset.play;
