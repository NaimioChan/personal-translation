FloatArray

一个由 32 位单精度浮点数组成的数组

RawArray : ArrayedCollection : SequenceableCollection : Collection : Object

参见：DoubleArray、Signal

子类：Signal、Wavetable

说明

一个由 32 位单精度浮点数组成的数组。

注意，尽管名称中含有 "Float"，FloatArray 并不保存 SuperCollider 双精度 floats 序列，而是保存 32 位（单精度）浮点数。如需 64 位浮点数的原始数组，请使用 DoubleArray。

FloatArray 及其子类 Signal 常用于在 SuperCollider 中保存音频数据。由于几乎所有音频都具有 16 位或 24 位精度，为此使用双精度浮点数会浪费空间。换句话说，FloatArray 用于存储大量较低精度的数据，但不适用于高精度的数学运算。

SuperCollider 中 RawArray 类型的完整列表为：

  • Int8Array - 8 位整数
  • Int16Array - 16 位整数
  • Int32Array - 32 位整数
  • FloatArray - 32 位浮点数
  • DoubleArray - 64 位浮点数
  • SymbolArray - 符号

注意： FloatArray 中元素的溢出/下溢行为是未定义的，但通常分别为 inf/-inf。只要操作结果超出返回类型（此处为 32 位浮点数）支持的值范围，就会发生这种情况。参见 Float 中的说明。
