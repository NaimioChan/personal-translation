Compander

压缩器、扩展器、限制器、门、闪避器

UGen : AbstractFunction : Object

另请参阅：Normalizer、CompanderD、Limiter

说明

通用（硬拐点）动态处理器。

类方法

Compander.ar(in: 0.0, control: 0.0, thresh: 0.5, slopeBelow: 1.0, slopeAbove: 1.0, clampTime: 0.01, relaxTime: 0.1, mul: 1.0, add: 0.0)

参数：

in

要压缩 / 扩展 / 门控的信号。

control

其振幅决定施加到输入信号上的增益的信号。通常与 in 相同（用于标准门控或压缩），但在闪避时应该不同。

thresh

通常在 0 到 1 之间。控制信号的幅度阈值，用于确定 slopeBelow 与 slopeAbove 之间的断点。控制信号幅度使用 RMS 计算。

slopeBelow

当控制信号幅度低于 thresh 时，所应用的幅度曲线的斜率。若大于 1.0，则控制信号越柔和，幅度下降得越快；当控制信号幅度接近 0 时，输出应恰好为零——因此可实现噪声门控。小于 1.0 的值是可能的，但这意味着极低电平的控制信号会导致输入信号被放大，从而抬高本底噪声。

slopeAbove

当控制信号幅度高于 thresh 时施加的幅度曲线斜率。值 < 1.0 实现压缩（较响的信号被衰减），而值 > 1.0 实现扩展（较响的信号被变得更响）。值为 1/3 时实现 3:1 的压缩。

clampTime

在控制信号高于 thresh 后，振幅调整完全生效所需的时间（单位：秒）。通常是一个约 10ms（0.01）的小值，常设为低至 2ms（0.002）。

relaxTime

幅度调整释放所需的时间（以秒为单位）（控制信号低于 thresh）。通常比 clampTime 更长；取决于输入和控制信号，将两个时间都设置得太短会导致（可能是不想要的）伪影。

mul

输出将乘以该值。

add

添加到输出的值。

讨论：

更深入的说明请参见例如 http://en.wikipedia.org/wiki/Audio_level_compression。

实例方法

示例

干净信号（供参考）

(
{
    Decay2.ar(
        Impulse.ar(8, 0, LFSaw.kr(0.3, 1, -0.3, 0.3)),
        0.001,
        0.3
    )
    * Mix.ar(Pulse.ar([80, 81], 0.3))
}.play;
)

噪声门

(
{
    var z;

    // 信号（干净）
    z = Decay2.ar(
        Impulse.ar(8, 0, LFSaw.kr(0.3, 1, -0.3, 0.3)),
        0.001,
        0.3
    )
    * Mix.ar(Pulse.ar([80, 81], 0.3));

    // 应用门限（鼠标 x 设置阈值）
    Compander.ar(z, z,
        thresh: MouseX.kr(0.001, 1),
        slopeBelow: 10,
        slopeAbove:  1,
        clampTime:   0.01,
        relaxTime:   0.01
    )
}.play;
)

Compressor

(
{
    var z;

    // 信号（干净）
    z = Decay2.ar(
        Impulse.ar(8, 0, LFSaw.kr(0.3, 1, -0.3, 0.3)),
        0.001,
        0.3
    )
    * Mix.ar(Pulse.ar([80, 81], 0.3));

    // 应用压缩（鼠标 x 设置压缩量）
    Compander.ar(z, z,
        thresh: MouseX.kr(0.01, 1),
        slopeBelow: 1,
        slopeAbove: 0.5,
        clampTime:  0.01,
        relaxTime:  0.01
    )
}.play;
)

Limiter

(
{
    var z;

    // 信号（干净）
    z = Decay2.ar(
        Impulse.ar(8, 0, LFSaw.kr(0.3, 1, -0.3, 0.3)),
        0.001,
        0.3
    )
    * Mix.ar(Pulse.ar([80, 81], 0.3));


    // 应用限制器（鼠标 x 设置量）
    Compander.ar(z, z,
        thresh: MouseX.kr(0.01, 1),
        slopeBelow: 1,
        slopeAbove: 0.1,
        clampTime:  0.01,
        relaxTime:  0.01
    )
}.play;
)

Sustainer

(
// 注意由于缺少前瞻导致信号开头的爆音
{
    var z;

    // 信号（干净）
    z = Decay2.ar(
        Impulse.ar(8, 0, LFSaw.kr(0.3, 1, -0.3, 0.3)),
        0.001,
        0.3
    )
    * Mix.ar(Pulse.ar([80, 81], 0.3));

    // 应用延音器
    Compander.ar(z, z,
        thresh: MouseX.kr(0.1, 1),
        slopeBelow: 0.1,
        slopeAbove: 1,
        clampTime:  0.01,
        relaxTime:  0.01
    ) * 0.1
}.play;
)
