VarLag

可变形状滞后

Filter : PureUGen : UGen : AbstractFunction : Object

参见：Lag、Ramp、Slew

说明

与 Lag 类似，但使用其他曲线形状而非指数曲线。输入发生变化后，将经过指定的时间才能达到新值。适用于平滑控制（非音频）信号。

警告： VarLag.ar 目前接受音频速率输入，但底层实现将该输入按控制速率处理。因此实际上，VarLag 输入的“采样率”是 ControlRate.ir 或 server.sampleRate / server.options.blockSize，而馈入 VarLag 的最大安全频率是它的一半。VarLag 目前对于全带宽的音频速率信号不会产生正确结果。使用 VarLag.ar 风险自负。

类方法

VarLag.ar(in: 0.0, time: 0.1, curvature: 0, warp: 5, start, mul: 1.0, add: 0.0)

VarLag.kr(in: 0.0, time: 0.1, curvature: 0, warp: 5, start, mul: 1.0, add: 0.0)

参数：

in

输入信号。

time

延迟时间，以秒为单位。

curvature

如果 warp 输入为 5（默认值），则控制曲率。0 表示线性，正数和负数使线段向上和向下弯曲。

warp

确定形状。可能的值有：

\step

平坦段

\linear

\lin

线性段，默认值

\exponential

\exp

自然指数增长与衰减。在这种情况下，所有电平都必须非零且符号相同。

\sine

\sin

正弦 S 形段。

\welch

\wel

形状像 Welch 窗两侧的正弦段。

\squared

\sqr

平方段

\cubed

\cub

三次方段

上述所有值都将忽略 curvature 输入。

注意： 当从外部控制此项时，使用 Env.shapeNumber(symbol) 获取每个形状对应的数值。

\step

平坦段

\linear

\lin

线性段，默认值

\exponential

\exp

自然指数增长与衰减。在这种情况下，所有电平都必须非零且符号相同。

\sine

\sin

正弦 S 形段。

\welch

\wel

形状像 Welch 窗两侧的正弦段。

\squared

\sqr

平方段

\cubed

\cub

三次方段

start

初始值。若未指定，则与输入信号相同。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

(
// 用于滞后音高
{
    SinOsc.ar(                              // 正弦波
        VarLag.kr(                            // 滞后调制器
            LFPulse.kr(1).range(100, 400),   // 频率调制器
            0.2,                            // 延迟时间
            Line.kr(-8, 8, 15, doneAction: Done.freeSelf) // 调制形状
        ),
        0,                                  // 正弦相位
        0.3                                 // 正弦振幅
    )
}.play
)
(
x = play { |amp = 0, time = 0, curve = 0, warp = 5|
    PinkNoise.ar(VarLag.kr(amp, time, curve, warp) ! 2)
}
)

x.set(\amp, 1, \time, 5, \warp, Env.shapeNumber(\sin)) // S 形曲线上扬
x.set(\amp, 0, \time, 1, \warp, Env.shapeNumber(\lin)) // linear down

x.set(\amp, 1, \time, 2, \warp, 5, \curve, 7); // 慢速曲率
x.set(\amp, 0, \time, 0);

x.set(\amp, 1, \time, 2, \warp, 5, \curve, -7); // 快速曲率
x.set(\amp, 0, \time, 0);

x.free;
