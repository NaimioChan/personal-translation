plot

在图中绘制数据

说明

plot 方法提供了在 GUI 窗口中绘制数据的能力。该方法在 ArrayedCollection 类中实现，但为了方便起见，其他类也可使用，包括 Function、Bus、Env、Buffer、SoundFile、Wavetable。

plot

所有参数都是可选的。

注意： 可用的参数因对象而异。以下列表仅用于说明可能的参数。

参数：

name

用作 GUI 窗口标题的名称。

bounds

一个 Rect，提供 GUI 位置的坐标。

discrete

绘图默认为折线图。将其设为 true 可显示为柱状图。

numChannels

数组所代表的交错通道数。对于 Buffer，此参数不可用，因为它会被自动填充。

minval

显示范围的最小值。对于 Buffer，默认值为 -1，但可以更改。

maxval

显示范围的最大值。对于 Buffer，默认值为 +1，但可以更改。

separately

在多通道绘图中寻找合适的显示范围时，对所有通道一起进行此操作，或保持它们各自独立。

parent

默认情况下，绘图被放置在一个新的 GUI 窗口中。此参数可用于指定一个现有的 GUI 容器，将绘图发送到其中。

labels

默认情况下，标签出现在绘图区的左上角，根据鼠标位置显示数据读数。将此参数设为 false 可阻止其显示。

讨论：

如果 minval 和/或 maxval 被设置为 nil（这是默认值，Buffer 除外），它们将根据数据集的最小值和/或最大值自动计算。对于多通道数据，minval 和 maxval 可以是数组，为每个通道分别指定范围（包括使用 nil，此时最小值/最大值将针对特定通道而不是整个数据集来计算）。当接收者包含 nil 项时，绘图会因错误而失败。

当窗口获得焦点时按下键盘上的 E 键 可切换锁定状态，此时窗口可用于编辑数据。

示例

注意： 请参阅上面链接的某些类以获取更多示例

// Arrays
[5, 6, 7, 6.5, 4.5, 3.5].plot("Some data")
[5, 6, 7, 6.5, 4.5, 3.5].plot("Some data, in stereo", numChannels:2)
[5, 6, 7, 6.5, 4.5, 3.5].plot("Some data, in stereo", numChannels:2, discrete: true)

{ |i| { |j| j + 1 * (i + 1) % 6 }.dup(100) }.dup(5).plot("Some 2-d data");

// 3 声道交错数据
b = [{1.0.rand}.dup(50), { 20.0.rand - 30 }.dup(50),{ 10.0.rand }.dup(50)].lace(150);
b.plot(numChannels:3); // 常见重缩放
b.plot(numChannels:3, separately: false);
b.plot(numChannels:3, minval: [nil, -100, nil], maxval: [nil, nil, 10]); // 多声道范围参数

// 包络
Env.adsr(0.4, 0.4, 0.8, 0.9).plot

// 缓冲区
s.boot;
b = Buffer.read(s, ExampleFiles.child);
b.plot; // +-1 range
b.plot(minval: nil, maxval: nil); // 自动范围
b.plot(minval: 0, maxval: nil); // 半自动范围

// UGen 函数
{ LFDNoise3.ar(XLine.ar(1000, 100, 0.1) ! 3) }.plot(0.1);
