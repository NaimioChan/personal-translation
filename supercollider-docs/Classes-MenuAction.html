MenuAction

一个单独菜单或工具栏项，在点击时执行一个动作。

另请参阅：Menu、ToolBar、MainMenu

说明

MenuAction 表示单个动作，它可以占据多个 Menu 或 ToolBar，并在激活时求值一个函数。添加到菜单时，它们显示为菜单项。添加到工具栏时，它们显示为按钮。

类方法

.new

创建一个新的 Action。注意，一个 action 可以占据多个菜单和工具栏。

参数：

string

动作的名称。如果添加到菜单中，这将是其显示名称。

function

当动作被激活时要执行的函数。

.separator

表示菜单或工具栏分隔符的动作。这些不可选择或点击。

参数：

string

分隔符的标签。这些标签并不总是可见，取决于你的操作系统和上下文。

实例方法

.string

表示操作名称的字符串。当放置在菜单中时用作文本，如果没有图标，也在工具栏上使用。

参数：

一个 String

.menu

一个菜单。如果存在，此动作将作为子菜单，或当放置在工具栏上时作为弹出菜单。

参数：

一个 Menu

.shortcut

表示触发此操作的键盘快捷键的字符串。当操作附加到 ToolBar 上，或者作为 View 的上下文菜单的一部分时（参见 View: -setContextMenuActions），键盘快捷键可用。快捷键字符串的形式如 "Ctrl+M"、"Shift+Alt+space" 等。更多信息请参见 https://doc.qt.io/qt-5/qkeysequence.html#details。

参数：

一个 String

.checked

指示该 action 是选中还是未选中状态。

参数：

一个布尔值。

.toolTip

悬停在菜单项/按钮上时显示的字符串。

参数：

一个 String

.separator

指示该 action 是否为分隔符。

参数：

一个布尔值。

.iconVisible

指示此操作对应的图标是否可见。

参数：

一个布尔值。

.checkable

指示此操作显示一个复选框并且是可勾选的。

参数：

一个 Boolean

.enabled

表示该操作已启用；否则将变灰并且不可交互。

参数：

一个 Boolean

.icon

与该操作关联的 Image——将在菜单和工具栏中显示于操作名称旁边。

参数：

一个 Image

.font

用于显示动作名称的字体。请注意，特殊字体是否显示可能取决于操作系统和上下文（例如系统菜单、上下文菜单、工具栏）。例如，OSX 应用程序菜单会遵循斜体字体，但不会遵循字体族本身。

参数：

一个 Font

Events

菜单动作会广播多种事件，可以通过标准的 Object: -addDependant 调用进行注册。菜单广播的事件：

  • \changed（当某个 actions 属性发生变化时发出）
  • \triggered（在动作被点击 / 激活时发出——值为一个布尔值，表示该动作是否被选中）
  • \hovered
  • \toggled

事件示例

(
m = Menu(
    a = MenuAction("Option A"),
    b = MenuAction("Option B")
).title_("Event Example");
f = {
    |action, what, value|
    "MenuAction '%' sent event %, value = %".format(action.string, "\\" ++ what, value).postln;
    if (what == \hovered) { "Hovering over: %".format(action).postln };
    if (what == \triggered) { "Action triggered: %".format(value).postln; m.destroy };
};
a.addDependant(f);
b.addDependant(f);
m.onClose_({ a.removeDependant(f); b.removeDependant(f) }).front;
)

示例

简单的可勾选菜单项

(
~view = View().layout_(HLayout(
    Button()
        .states_([["Options..."]])
        .action_({ ~menu.front })
));
~menu = Menu(
    MenuAction("enabled")
        .checkable_(true)
        .action_({
            |a, enabled|
            if (enabled) {
                "Enabled".postln;
                ~view.background = Color.green(1, 0.5);
            } {
                "Disabled".postln;
                ~view.background = Color.clear;
            }
        })
);
~view.front;
)

动作帮助字符串

(
~view = View(bounds: 300@100).layout_(VLayout(
    Button()
        .states_([["Options..."]])
        .action_({ ~menu.front }),
    ~text = TextView()
));

~menu = Menu (
    MenuAction("Option A").toolTip_("I like option A..."),
    MenuAction("Option B").toolTip_("But option B is better..."),
    MenuAction("Option C").toolTip_("No one really likes C."),
);

~actionFunc = {
    |obj, what, action|
    if (what == \hovered) {
        ~text.string = action.toolTip
    };
    if (what == \aboutToHide) {
        ~text.string = ""
    }
};
~menu.addDependant(~actionFunc);
~view.onClose_({ ~menu.removeDependant(~actionFunc) }).front;

)

一个更复杂的示例

(
s.waitForBoot {
    ~startIcon = Image(40).draw({
        Pen.fillColor = Color.green;
        Pen.moveTo(5@5);
        Pen.lineTo(35@20);
        Pen.lineTo(5@35);
        Pen.lineTo(5@5);
        Pen.fill;
    });
    ~stopIcon = Image(40).draw({
        Pen.fillColor = Color.red;
        Pen.fillRect(Rect(10, 10, 20, 20));
    });

    ~startAction = MenuAction("start")
                    .action_({ ~playSynth.() })
                    .icon_(~startIcon)
                    .toolTip_("Start playing synth.")
                    .shortcut_("space")
                    .font_(Font(bold: true, size: 18));
    ~stopAction = MenuAction("stop")
                    .action_({ ~stopSynth.() })
                    .icon_(~stopIcon)
                    .toolTip_("Stop the synth.")
                    .enabled_(false)
                    .shortcut_(".")
                    .font_(Font(bold: true, size: 18));
    ~playing = MenuAction("playing")
                    .enabled_(false)
                    .checkable_(true)
                    .checked_(false);

    ~view = View(bounds: 300@200).layout_(VLayout(
        ToolBar(~startAction, ~stopAction, MenuAction.separator, ~playing).focus,
        nil,
        Button().states_([["Options..."]]).action_({
            Menu(~startAction, ~stopAction, MenuAction.separator, ~playing).front;
        })
    ));
    ~view.onClose_({ ~stopSynth.() });

    ~synth = nil;
    ~playSynth = {
        if (~synth.isNil) {
            ~synth = { SinOsc.ar(440) * 0.1 }.play;

            ~startAction.enabled = false;
            ~stopAction.enabled = true;
            ~playing.checked = true;

            ~synth.onFree({
                ~synth = nil;
                {
                    ~playing.checked = false;
                    ~startAction.enabled = true;
                    ~stopAction.enabled = false;
                }.defer
            })
        }
    };

    ~stopSynth = {
        ~synth !? { ~synth.free };
    };

    ~view.front;

}
)
