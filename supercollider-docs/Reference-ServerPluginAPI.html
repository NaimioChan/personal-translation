输入速率

这四个常量标识 SuperCollider 中输入的计算速率。

calc_ScalarRate

初始速率。在语言中通常称为 ".ir"。

calc_BufRate

控制速率。在语言中通常称为 ".kr"。

calc_FullRate

音频速率。在语言中通常称为 ".ar"。

calc_DemandRate

需求率。

UGen 基础

这些辅助宏假定局部作用域中存在一个名为 unit 的 ugen 对象。

IN(index)

在给定索引处作为 float* 的单个音频速率输入块。索引 0 是 ugen 的第一个输入，索引 1 是第二个输入，依此类推。

IN0(index)

在给定索引处作为浮点数的单个控制率输入采样。

OUT(index)

在给定索引处作为 float* 的单个音频速率输出块。

OUT0(index)

在给定索引处作为浮点数的单个控制率输入采样。

INRATE(index)

获取给定输入索引的速率。该速率将是四种速率之一。

INBUFLENGTH(index)

获取给定输入索引的块大小。

SAMPLERATE

服务器的采样率，单位为赫兹。

SAMPLEDUR

服务器的采样周期，以秒为单位。

BUFLENGTH

音频缓冲区的长度（以采样为单位，即一个控制周期内的采样数）。

BUFRATE

服务器的控制速率，单位为赫兹。

BUFDUR

服务器的控制周期，以秒为单位。

FULLRATE
FULLBUFLENGTH

Buffers

GET_BUF

检索缓冲区的推荐方式。取此 UGen 的第一个输入并将其用作缓冲区编号。这会将若干变量转储到局部作用域中：

  • buf - 指向 SndBuf 实例的指针
  • bufData - 来自缓冲区的原始浮点数据
  • bufChannels - 缓冲区中的通道数
  • bufSamples - 缓冲区中的采样数
  • bufFrames - 缓冲区中的帧数

缓冲区使用 LOCK_SNDBUF 宏进行锁定。缓冲区锁定操作特定于 supernova，在 vanilla scsynth 中不起任何作用。

GET_BUF_SHARED

与 GET_BUF 类似，但缓冲区使用 LOCK_SNDBUF_SHARED 加锁。

SIMPLE_GET_BUF

与 GET_BUF 类似，但只创建 buf 变量，不锁定缓冲区。

SIMPLE_GET_BUF_EXCLUSIVE

类似 SIMPLE_GET_BUF，但使用 LOCK_SNDBUF 锁定缓冲区。

SIMPLE_GET_BUF_SHARED

与 SIMPLE_GET_BUF 类似，但使用 LOCK_SNDBUF_SHARED 锁定缓冲区。

以下宏用于 supernova。它们在 scsynth 中仍然存在，但不会产生效果。

ACQUIRE_BUS_AUDIO(index)
ACQUIRE_BUS_AUDIO_SHARED(index)
RELEASE_BUS_AUDIO(index)
RELEASE_BUS_AUDIO_SHARED(index)
LOCK_SNDBUF(buf)
LOCK_SNDBUF_SHARED(buf)
LOCK_SNDBUF2(buf1, buf2)
LOCK_SNDBUF2_SHARED(buf1, buf2)
LOCK_SNDBUF2_EXCLUSIVE_SHARED(buf1, buf2)
LOCK_SNDBUF2_SHARED_EXCLUSIVE(buf1, buf2)
ACQUIRE_SNDBUF(buf)
ACQUIRE_SNDBUF_SHARED(buf)
RELEASE_SNDBUF(buf)
RELEASE_SNDBUF_SHARED(buf)
ACQUIRE_BUS_CONTROL(index)
RELEASE_BUS_CONTROL(index)

RGen

RGen 是一个伪随机数生成器 API。大多数 ugen 开发者对为自己的 RGen 设置种子不感兴趣，更愿意从 SuperCollider 提供的全局 RGen 实例中取用。这可以通过以下代码获取：

RGen& rgen = *unit->mParent->mRGen;
uint32 RGen::trand()

返回均匀分布的随机 32 位整数。

double RGen::drand()

返回一个在 [0,1) 内均匀分布的随机双精度浮点数。

float RGen::frand()

在 [0,1) 内的随机浮点数。

float RGen::frand0()

在 [1,2) 内的随机浮点数。

float RGen::frand2()

[-1,1) 范围内的随机浮点数。

float RGen::frand8()

[-0.125,0.125) 内的随机浮点数。

float RGen::fcoin()

要么 -1，要么 +1。

float RGen::flinrand()

在 [0,1) 内线性分布的随机浮点数，偏向 0 端。

float RGen::fbilinrand()

在 (-1,1) 范围内双线性分布的随机浮点数，偏向于 0。

float RGen::fsum3rand()

对高斯分布的粗略但快速的近似。结果始终在 (-1,1) 范围内。方差为 1/6，标准差为 0.41。1

int32 RGen::irand(int32 scale)

[0,scale) 内的随机整数。

int32 RGen::irand2(int32 scale)

[-scale,+scale] 内的随机整数。

int32 RGen::ilinrand(int32 scale)

在 [0,scale) 范围内线性分布的随机整数，偏向 0 端。

int32 RGen::ibilinrand(int32 scale)

在 (-scale,scale) 内双线性分布的随机整数，偏向于 0。

double RGen::linrand()

线性分布的随机双精度数，位于 [0,1) 区间，偏向 0 端。

double RGen::bilinrand()

在 (-1,1) 内双线性分布的随机双精度数，偏向于 0。

double RGen::exprandrng(double lo, double hi)

在 [lo,hi) 范围内呈指数分布的随机双精度浮点数。

double RGen::exprand(double scale)
double RGen::biexprand(double scale)
double RGen::exprand(double scale)
double RGen::sum3rand(double scale)

RGen::fsum3rand 的 Double 版本。

展开宏

本节中的宏是遗留特性。它们出现在 SuperCollider 的许多内置 ugen 中，旨在为标准的 for (int i = 0; i < inNumSamples; i++) { out[i] = in[i] } 循环提供更高效的替代方案。这些效率节省在现代系统上可以忽略不计，不建议使用这些宏，尤其是它们会使调试变得困难。

LOOP(length, stmt)

执行代码 stmt，共 length 次。

LOOP1(length, stmt)

LOOP 的更快替代方案，假定 length > 0，从而节省一条分支指令。

LooP(length) stmt

LOOP/LOOP1 的替代方案，对调试器更友好。循环体位于对 LooP 的调用之后。

ZIN(index)

与 IN 类似，但会从指针中减去 1，以修正使用 LOOP 和 ZXP 时的 off-by-one 错误。

ZOUT(index)

与 OUT 相同，但会从指针中减去 1，以修正使用 LOOP 和 ZXP 时出现的差一错误。

ZIN0(index)

IN0 的别名。

ZOUT0(index)

OUT0 的别名。

ZXP(z)

前置递增并解引用 z。

ZX(z)

解引用 z。

PZ(z)

前置递增 z。

ZP(z)

不做任何事。

ZOFF

返回 1。

[1] - 公式为 (rand() + rand() + rand() - 1.5) * 2/3，技术上是一种平移并拉伸的三阶 Irwin-Hall 分布。
