Balance2

立体声信号平衡器

MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：LinPan2、Pan2、Pan4、PanAz

说明

等功率声像平衡两个声道。通过从左（pos = -1）声像到右（pos = 1），你将左声道的电平从 1 递减到 0，取线性缩放因子的平方根；同时使用相同的曲线将右声道的电平从 0 递增到 1。在中间位置（pos = 0）时，两个声道的电平均为 0.5.sqrt（约等于 0.707 或 -3dB）。Balance2 的输出仍然是立体声信号。

类方法

Balance2.ar(left, right, pos: 0.0, level: 1.0)

Balance2.kr(left, right, pos: 0.0, level: 1.0)

参数：

left

输入立体声信号的通道 1

right

输入立体声信号的通道 2

pos

声像位置，-1 为左，+1 为右

level

一个控制速率电平输入。

实例方法

示例

// 立体声信号，两个声道均为 0dB
{ [SinOsc.ar(440), SinOsc.ar(440)] }.play

// 对立体声信号使用 Balance 并将位置参数设为 0，声音实际上相同，但两个声道均为 -3dB
{ Balance2.ar(SinOsc.ar(440), SinOsc.ar(440), 0) }.play

// 声像从左到右扫过
{ Balance2.ar(SinOsc.ar(440), SinOsc.ar(1000), Line.kr(-1, 1, 5)) }.play

// 其他示例
{ Balance2.ar(LFSaw.ar(44), Pulse.ar(33), FSinOsc.kr(0.5), 0.1) }.play;
{ var source; source = SinOsc.ar([440, 550]); Balance2.ar(source[0], source[1], LFNoise0.kr(4), 0.3) }.play;
