DebugNodeWatcher

监视服务器地址以获取调试相关消息

BasicNodeWatcher : AbstractNodeWatcher : Object

参见：Server Command Reference、Node、NodeWatcher

说明

当从服务器收到这些消息时输出：n_go n_end n_off n_on

调试时，查看每个节点的开始和结束可能很有用。它不需要注册，会对每条消息做出反应。
