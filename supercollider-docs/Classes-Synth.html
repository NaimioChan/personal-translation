Synth

服务器上 synth 节点的客户端表示

Node : Object

参见：Node、SynthDef

说明

Synth 是服务器上合成节点的客户端侧表示。一个 Synth 表示单个发声单元。它的行为定义在 SynthDef 中，其中指定了使用哪些 UGen 以及它们如何连接在一起。它还指定了 Synth 将拥有的输入和输出。因此，SynthDef 是一种固定模式，Synth 基于它构建。（尽管如此，一个给定的 SynthDef 仍能提供惊人的多样性。）有关 SynthDef、其构造方式以及如何将它们发送到服务器的更多细节，请参见 SynthDef 帮助文件。

关于客户端对象与服务器节点之间这一重要区别的更多内容，请参见Client vs Server。关于不使用对象创建节点的信息，请参见Node Messaging。

执行顺序

在创建相互交互的 Synth 时，执行顺序是一个关键问题。

    sound ->  filter

如果声音要经过滤波器，则执行滤波的 synth 在执行顺序上必须位于作为其输入的 synth 之后。计算机必须先计算一个缓冲区的声音，然后才能继续计算该声音经过滤波后的版本的一个缓冲区。

synth 节点之间的实际互连是通过 bus 实现的。详见 Bus 和 Server Architecture。

关于这一重要主题的更详细讨论，请参阅 Order of execution 帮助文件。

Bundling

下面的部分方法有两个版本：常规版本会立即将对应消息发送到服务器，另一个版本则将消息返回为 Array，以便加入 bundle。也可以利用 Server 的自动打包功能捕获常规方法生成的消息。详情请参阅 Server 和 Bundled Server Messages。

类方法

Synth 是 Node 的子类，因此其许多最有用和最重要的方法记录在 Node 帮助文件中。

在服务器上立即实例化创建

Synth.new(defName, args, target, addAction: 'addToHead')

创建一个新的 Synth 对象并返回，同时立即在服务器上启动对应的 synth 节点。

参数：

defName

一个 String 或 Symbol，指定在创建 Synth 时要使用的 SynthDef 名称。

args

一个可选的 Array，用于指定 SynthDef 参数（控件）的初始值。这些值以控件名称或索引与值成对指定。如果使用名称，可以用 String 或 Symbol 指定。例如 [\frequency, 440, \amplitude, 1, ...]。值为数组的项使用 OSC 数组类型标签（$[ 和 $]）发送。这些值将被赋值给后续的控件。

target

这个 Synth 的目标。如果 target 不是 Group 或 Synth，将按如下方式转换：如果它是 Server，将被转换为该服务器的 Default Group。如果它是 nil，则转换为默认 Server 的 default_group。如果它是整数，则相对于具有该 id 的组创建。

addAction

以下符号之一：

\addToHead

（默认）添加到由 target 指定的组的头部

\addToTail

添加到由 target 指定的组的尾部

\addAfter

紧接在目标之后按其服务器节点顺序添加

\addBefore

在其服务器的节点顺序中紧挨着目标之前添加

\addReplace

替换目标并占据其在服务器节点顺序中的位置

注意：Synth 不是 \addToHead 和 \addToTail 的有效目标。

讨论：

s.boot;
// 在默认 Server 的默认组头部创建一个 Synth
// 基于 SynthDef "default"
x = Synth.new("default");
s.queryAllNodes; // 注意默认组（ID 1）
x.free;

// 使用数组化控制
// 先运行此块以创建 SynthDef
(
SynthDef("help-synth", { |freq = #[440, 450, 460], out = 0|
    Out.ar(out, Mix(SinOsc.ar(freq, 0, 0.1)));
}).add;
)

// 然后稍后这样
x = Synth("help-synth", [freq: [500, 501, 510]]);

x = Synth("help-synth", [freq: [500, 501, 510]]);
x.set(\freq, [1, 2, 3] * 400 + [1, 2, 3], \out, 1);
x.set(\freq, [3] * 400 + [1, 2, 3], \out, 1);
x.free;

Synth.newPaused(defName, args, target, addAction: 'addToHead')

与上面的 new 相同，但创建一个暂停的节点。可以通过在其上调用 run 来启动。

s.boot;
x = Synth.newPaused("default");
s.queryAllNodes; // 看，我在这里
x.run; // true 为默认值
x.run(false); // 再次暂停我
x.free;

Synth.grain(defName, args, target, addAction: 'addToHead')

一个便捷方法，它会创建一个节点 ID 为 -1 的 synth 节点。这种节点创建后无法接收消息。因此该方法不创建对象，并返回 nil。关于其参数的详细信息，请参见上文的 new。

返回值：

nil

添加操作的便捷方法

以下便捷方法对应于 Synth.new 的添加操作：

Synth.after(aNode, defName, args)

创建一个 Synth 并返回它，将其紧接在 aNode 之后添加。

Synth.before(aNode, defName, args)

创建一个 Synth 并返回，将其紧接在 aNode 之前添加。

Synth.head(aGroup, defName, args)

创建并返回一个 Synth。如果 aGroup 是一个 Group，则将其添加到该组的头部。如果它是一个 Server，则将其添加到该服务器的 Default Group 的头部。如果它为 nil，则将其添加到默认服务器的 default_group 的头部。如果它是一个整数，则相对于具有该 id 的组创建它。

Synth.tail(aGroup, defName, args)

创建并返回一个 Synth。如果 aGroup 是一个 Group，则将其添加到该组的尾部。如果它是一个 Server，则将其添加到该服务器的 Default Group 的尾部。如果它为 nil，则将其添加到默认服务器的 default_group 的尾部。如果它是一个整数，则相对于具有该 id 的组创建它。

Synth.replace(nodeToReplace, defName, args, sameID: false)

创建一个 Synth 并返回它，用其替换 nodeToReplace，在服务器的节点顺序中占据其位置。

不在服务器上实例化的创建

为了在消息包中使用，也可以在客户端应用中创建 Synth 对象，而不立即在服务器上创建 synth 节点。完成后，可以调用方法创建要添加到包中的消息，这些消息发送到服务器时将实例化该 synth。

Synth.basicNew(defName, server, nodeID)

创建并返回一个 Synth 对象，而不在服务器上创建 synth 节点。

参数：

defName

一个 String 或 Symbol，指定在创建 Synth 时要使用的 SynthDef 名称。

server

可选的 Server 实例。如果为 nil，则默认为默认服务器。

nodeID

可选的节点 ID 编号。如果未提供，服务器会通过其 NodeIDAllocator 生成一个。通常你不需要提供 ID。

讨论：

s.boot;
x = Synth.basicNew("default", s); // 创建但不发送
s.sendBundle(nil, x.newMsg); // 现在发送一条消息；在 s 的默认组头部创建
s.queryAllNodes;
x.free;

创建之后，使用实例方法 newMsg, addToHeadMsg, addToTailMsg, addBeforeMsg, addAfterMsg, addReplaceMsg 在服务器上实例化此 synth。参见下方的实例方法。

实例方法

Synth 是 Node 的子类，因此其许多最有用和最重要的方法记录在 Node 帮助文件中。

.defName

.defName = value

返回值：

此 Synth 的 SynthDef 名称。

不在服务器上实例化的创建

使用类方法 basicNew 创建一个 Synth，而不在服务器上实例化它。然后使用以下实例方法：

.newMsg(target, args, addAction: 'addToHead')

有关 addActions 和 args 的详细信息，参见上面的 *new。

返回值：

一种类型为 s_new、可被捆绑的消息。发送到服务器时，该消息将实例化此 synth。如果 target 为 nil，则默认为创建此 Synth 时在 *basicNew 中指定的 Server 的 default_group。默认的 addAction 为 \addToHead。

.addToHeadMsg(aGroup, args)

参数详情见上面的 *new。

返回值：

一条类型为 s_new 的消息，可以被捆绑。当发送到服务器时，该消息将实例化此 synth。如果 aGroup 是一个 Group，它将被添加到该组的头部。如果为 nil，它将被添加到此 Synth 所属服务器的 default_group 的头部（如调用 *basicNew 时所指定）。

.addToTailMsg(aGroup, args)

参数详情见上面的 *new。

返回值：

一条类型为 s_new 的消息，可以被捆绑。当发送到服务器时，该消息将实例化此 synth。如果 aGroup 是一个 Group，它将被添加到该组的尾部。如果为 nil，它将被添加到此 Synth 所属服务器的 default_group 的尾部（如调用 *basicNew 时所指定）。

.addBeforeMsg(aNode, args)

参数详情见上面的 *new。

返回值：

一条 s_new 类型的消息，可被打包。发送到服务器时，此消息将立即在 aNode 之前实例化该 synth。

.addAfterMsg(aNode, args)

参数详情见上面的 *new。

返回值：

一条类型为 s_new 的消息，可以被捆绑。当发送到服务器时，此消息将立即在 aNode 之后实例化此 synth。

.addReplaceMsg(nodeToReplace, args)

参数详情见上面的 *new。

返回值：

一条可被捆绑的 s_new 类型消息。发送到服务器时，该消息将实例化该 synth，并替换服务器节点顺序中的 nodeToReplace。

Control

关于控制 Synth 的更多方法（set、map 等），参见 Node 帮助文件。

.get(index, action)

.getMsg(index)

向服务器查询 Control（参数）的当前值。

参数：

index

控件名称或索引

(action)

一个 Function，在收到回复时将以作为参数传入的值对其进行求值。

讨论：

s.boot;
(
SynthDef("help-Synth-get", { |out, freq = 440|
    Out.ar(out, SinOsc.ar(freq, 0, 0.1));
}).add;
)
x = Synth("help-Synth-get");
x.set(\freq, 220 + 440.rand);
x.get(\freq, { |value| ("freq is now:" + value + "Hz").postln });
x.free;

.getn(index, count, action)

.getnMsg(index, count)

向服务器查询一段连续范围内的 Control（参数）的当前值。

参数：

index

控件名称或索引

count

从 index 开始查询的顺序控制的数量。

(action)

一个 Function，收到回复时会以包含所传值的 Array 作为参数对其求值。

.set( ... args)

来自父类：Node

设置一个或多个 Control 的值。

讨论：

Example:

x.set(\freq, 440, \amp, 0.5)

.seti( ... args)

设置数组控件的一部分。

参数：

... args

由 name、index、value 构成的三元组序列。

name

数组化控制的名称

index

数组中的索引

value

要设置的新值，可以是一个数组，用于设置一段元素范围。

讨论：

注意： synthdef 必须被 .add，以便它存储在 SynthDescLib 中。

Example:

(
s.waitForBoot({
    SynthDef(\helpSeti, { |out, freqs = #[100, 150, 200, 250]|
        Out.ar(out, SinOsc.ar(freqs.poll, 0, 0.1).sum ! 2)
    }).add;
    s.sync;
    x = Synth(\helpSeti);
})
)
x.seti(\freqs, 2, 600); // 仅设置第三个元素
x.seti(\freqs, 1, [400, 410]); // 设置第二个和第三个元素
x.free;

示例

s.boot;
(
// 向服务器发送合成器定义
SynthDef("tpulse", { |out = 0, freq = 700, sawFreq = 440.0|
    Out.ar(out, SyncSaw.ar(freq, sawFreq, 0.1));
}).add;
)

// 这里 *new 的默认值将导致在默认 Server 的默认组的头部创建一个 Synth。
// 这将使用 SynthDef 的默认参数；
y = Synth.new("tpulse");
y.free;

// 同样的操作显式完成
y = Synth.new("tpulse", nil, s, \addToHead);
y.free;

// 带一些参数
y = Synth.new("tpulse", [\freq, 350, \sawFreq, 220]);
y.free;

// 创建一个新的 synth
y = Synth("tpulse");

// pause
y.run(false);

y.run(true);

// 通过参数名设置一个 control
y.set("freq", 200);

// or by index
y.set(2, 100.0);

// 调制输出到总线编号 1（右扬声器）
y.set(0, 1);

//  一条消息中包含多个 set 命令
y.set("out", 0, "freq", 300);

// 从服务器释放该 synth
y.free;

Filtering

(
// 首先收集一些用于播放的内容
SynthDef("moto-rev", { |out = 0|
    var x;
    x = RLPF.ar(LFPulse.ar(SinOsc.kr(0.2, 0, 10, 21), [0, 0.1], 0.1),
        100, 0.1).clip2(0.4);
    Out.ar(out, x);
}).add;

SynthDef("bubbles", { |out = 0|
    var f, zout;
    f = LFSaw.kr(0.4, 0, 24, LFSaw.kr([8, 7.23], 0, 3, 80)).midicps;
    zout = CombN.ar(SinOsc.ar(f, 0, 0.04), 0.2, 0.2, 4); // 回声正弦波
    Out.ar(out, zout);
}).add;


SynthDef("rlpf", { |out = 0, ffreq = 600, rq = 0.1|
    ReplaceOut.ar(out, RLPF.ar(In.ar(out), ffreq, rq))
}).add;


SynthDef("wah", { |out, rate = 1.5, cfreq = 1400, mfreq = 1200, rq = 0.1|
    var zin, zout;

    zin = In.ar(out, 2);
    cfreq = Lag3.kr(cfreq, 0.1);
    mfreq = Lag3.kr(mfreq, 0.1);
    rq   = Ramp.kr(rq, 0.1);
    zout = RLPF.ar(zin, LFNoise1.kr(rate, mfreq, cfreq), rq, 10).distort
                    * 0.15;

    // 用效果处理后的版本替换传入的 bus
    ReplaceOut.ar(out, zout);

}).add;

SynthDef("modulate", { |out = 0, freq = 1, center = 440, plusMinus = 110|
    Out.kr(out, SinOsc.kr(freq, 0, plusMinus, center));
}).add;
)

// 一次执行一个

// y 在总线 0 上播放
y = Synth("moto-rev", ["out", 0]);

// z 正在从 bus 0 读取并替换它；它必须在 y *之后*
z = Synth.after(y, "wah", ["out", 0]);

// 停止 wah 效果
z.run(false);

// 恢复哇音效果
z.run(true);

// 在此之后添加一个 rlpf，读写同一个总线
x = Synth.after(z, "rlpf", ["out", 0]);

// 在 x 之后再创建一个 rlpf
t = Synth.after(x, "rlpf", ["out", 0]);

x.set("ffreq", 400);

x.set(\ffreq, 800); // Symbol 也可用于控制名

// 现在让我们调制 x 的 ffreq 参数
// 首先获取一个控制总线
b = Bus.control(s, 1);

// 现在是调制器，在 x *之前*
m = Synth.before(x, "modulate", [\out, b]);

// 现在将 x 的 ffreq 映射到 b
x.map("ffreq", b);

m.set("freq", 4, "plusMinus", 20);

x.free;
z.free;
m.free;

// 现在在 y 之后放置另一个 synth，在同一总线上
// they 都写入该总线，叠加它们的输出
r = Synth.after(y, "bubbles", ["out", 0]);

y.free;

r.free;

// 看看 Server 窗口
// 仍然看到 4 个 UGen 和 1 个 synth 吗？
// 你听不到我，但别忘了释放我
t.free;
