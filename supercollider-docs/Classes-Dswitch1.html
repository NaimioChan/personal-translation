Dswitch1

用于在输入之间切换的需求率生成器。

DUGen : UGen : AbstractFunction : Object

另见：Demand、Duty、TDuty、Dswitch

子类：Dswitch

说明

用于在输入之间切换的需求率生成器。

结构上相关的等价物请参见 Pswitch1。

类方法

Dswitch1.new(list, index)

参数：

list

值或其他 UGen 的数组。

index

要返回的输入。

实例方法

示例

(
{
    var a, freq, trig;
    a = Dswitch1([1, 3, MouseY.kr(1, 15), 2, Dwhite(0, 3, 2)], MouseX.kr(0, 4));
    trig = Impulse.kr(3);
    freq = Demand.kr(trig, 0, a) * 30 + 340;
    SinOsc.ar(freq) * 0.1

}.play;
)

(
{
    var a, freq, trig;
    a = Dswitch1({ |i| Dseq((0..i*3), inf) } ! 5, MouseX.kr(0, 4));
    trig = Impulse.kr(6);
    freq = Demand.kr(trig, 0, a) * 30 + 340;
    SinOsc.ar(freq) * 0.1

}.play;
)
