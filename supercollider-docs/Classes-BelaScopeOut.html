BelaScopeOut

Bela 的示波器接口

AbstractOut : UGen : AbstractFunction : Object

说明

注意： 此 UGen 仅在 Bela 上工作

此 UGen 将音频信号发送到 Bela Oscilloscope，类似于 /Classes/Out 写入总线的方式。它可以直接使用，也可以通过 UGen: -belaScope、Array: -belaScope、Bus: -belaScope、Function: -belaScope 和 Server: -belaScope 便捷函数使用。

类方法

BelaScopeOut.ar(offset: 0, channelsArray)

参数：

offset

Bela 示波器开始写入的通道。此参数仅在构造时读取，因此不可调制。

channelsArray

要示波的 UGen 数组。
