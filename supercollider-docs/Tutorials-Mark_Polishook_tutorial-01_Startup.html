开始

导航到 SuperCollider 所在的文件夹（目录），双击它（红白相间的气球图标）。将打开一个未命名的文档，其中文本如下

init_OSC
compiling class library..
    NumPrimitives = 548
    compiling dir: '/Applications/SuperCollider3/SCClassLibrary'
    pass 1 done
    Method Table Size 3091264 bytes
    Number of Method Selectors 2880
    Number of Classes 1744
    Number of Symbols 6926
    Byte Code Size 129989
    compiled 299 files in 1.61 seconds
compile done
prGetHostByName hostname 127.0.0.1 addr 2130706433
RESULT = 256
Class tree inited in 0.09 seconds

出现在屏幕左上角。该文档充当“Post Window”，之所以这样称呼，是因为 SuperCollider 用它来“发布”通知。

另外两个窗口

屏幕底部还有两个窗口。一个叫做 "localhost server"，另一个叫做 "internal server"。点击 localhost 服务器上的 "boot" 按钮。按钮黑色框中的 "localhost" 字样变为红色，按钮上的 "Boot" 字样变为 "Quit"。更多文本，例如

booting 57110
SC_AudioDriver: numSamples=512, sampleRate=44100.000000
start   UseSeparateIO?: 0
PublishPortToRendezvous 0 57110
SuperCollider 3 server ready..
notification is on

将打印到 post 窗口。localhost 服务器现在已可使用。如果你愿意，可以用同样的方式激活内部服务器。

工作区窗口

使用 File->Open... 或 cmd-o 打开现有 SC 文档。使用 File->New 或 cmd-n 创建新文档。

SuperCollider 文档的文件名通常带有 .scd 后缀；不过，SuperCollider 也能读写富文本格式（.rtf）以及其他几种格式的文档。
