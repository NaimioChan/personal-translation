EnvironmentRedirect

环境重定向的基类。

Object

参见：Environment

子类：LazyEnvir

说明

EnvironmentRedirect 的行为类似于一个 Environment，它会重定向访问（put(key, val)，或 ~key）和赋值（at(key)，或 ~key = val）。它被用作 LazyEnvir 和 ProxySpace 等类的基础。

类方法

EnvironmentRedirect.new(envir)

创建新的环境重定向，如果传入了 envir，则将其用作基础。

.envir

返回或替换源环境

e = LazyEnvir.new;
e.put(\x, 9);
e.envir; // 查看 envir 本身：对于 LazyEnvir，它包含 Maybe 实例作为占位符

.linkDoc(doc)

将环境链接到当前文档，使其仅在一个文档处于焦点时作为 currentEnvironment。参见：Document: -envir

参数：

doc

要链接到的文档，默认为当前文档（Document: *current）。如果该文档具有焦点或未给出文档，则立即压入环境。

.unlinkDoc(doc)

将环境取消链接到当前文档，使其仅当某个文档处于焦点时才作为 currentEnvironment。参见：Document: -envir

参数：

doc

要从中取消链接的文档，默认为当前文档（Document: *current）。如果该文档具有焦点或未指定文档，则立即弹出环境。

.dispatch

.dispatch = disp

当环境被修改时调用的函数或对象。键和被修改的对象作为参数传入。当对象从环境中移除时，dispatch 会以该对象的键和 nil 被调用。注意，仅在移除的对象确实存在时，才会在移除时调用 dispatch。

e = LazyEnvir.new;
e.dispatch = { |key, val| "new values:".postln; [key, val].postln };
e.put(\x, 9);
e.removeAt(\x); // 同时运行 dispatch，val 为 nil
e.removeAt(\y); // \y 不在 e 中：未调用 dispatch

网络与转发分配

EnvironmentRedirect 及其子类可用于分派赋值，例如通过网络。为此，可以提供分派函数——参见 JITLibExtensions quark 中的 Public。以下本地方法可用于避免递归更新：

.localPut(key, obj)

与 put 类似，但不调用分派函数。

.localRemoveAt(key)

与 removeAt 类似，但不调用调度函数。
