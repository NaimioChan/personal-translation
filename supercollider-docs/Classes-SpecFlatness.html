SpecFlatness

频谱平坦度测量

UGen : AbstractFunction : Object

参见：SpecCentroid、SpecPcile

说明

给定一个 FFT 链，这会计算频谱平坦度度量，定义为功率谱的几何平均值除以其算术平均值。该度量对于纯正弦波约为 0，对于白噪声约为 1。

该度量按线性方式计算。对于某些应用，你可能希望将值转换为分贝刻度——此类转换的示例如下所示。

类方法

SpecFlatness.kr(buffer)

参数：

buffer

一个 FFT 链。

实例方法

示例

s.boot;

(
{ // 示例 - 用鼠标改变白噪声和纯音之间的混合比例
    var in, chain, flat, flatdb, flatdbsquish;

    in = XFade2.ar(WhiteNoise.ar, SinOsc.ar, MouseX.kr(-1, 1));
    chain = FFT(LocalBuf(2048), in);
    Out.ar(0, in * 0.1);

    flat = SpecFlatness.kr(chain);

    flatdb = 10 * flat.log; // 转换为分贝
    flatdbsquish = LinLin.kr(flatdb, -45, -1.6, 0, 1).max(-10); // 大致将 dB 重新缩放到 0...1。

    flat.poll(10, "flatness: ");
    flatdb.poll(10, "flatness (db): ");

    [flat, flatdbsquish]
}.scope;
)

(
{ // 现在用你自己的声音试试
    var in, chain;
    in = SoundIn.ar([0, 1]).mean;
    chain = FFT(LocalBuf(2048), in);
    Out.kr(0, [in, SpecFlatness.kr(chain).poll(1, "flatness: ")]);
}.scope;
)
