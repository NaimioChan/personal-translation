08. 作用域与绘图

SuperCollider 入门

另请参阅：00. Getting Started With SC

探查一些绘图

Function 还有两个其他有用的音频相关方法。第一个你已经看到过一些结果，Function-plot：

{ PinkNoise.ar(0.2) + SinOsc.ar(440, 0, 0.2) + Saw.ar(660, 0.2) }.plot;

这会绘制该 Function 输出所产生的信号图。你可以指定一些参数，例如时长。默认值为 0.01 秒，但你可以将其设置为任意值。

{ PinkNoise.ar(0.2) + SinOsc.ar(440, 0, 0.2) + Saw.ar(660, 0.2) }.plot(1);

这对于检查发生了什么，以及确认你是否得到了预期的输出很有用。

第二种方法，即 Function 作用域，显示 Function 输出的类似示波器的显示。

那么让我们来示波一些音频：

{ PinkNoise.ar(0.2) + SinOsc.ar(440, 0, 0.2) + Saw.ar(660, 0.2) }.scope;

这应该会打开一个类似这样的窗口：

这也适用于多个声道：

{ [SinOsc.ar(440, 0, 0.2), SinOsc.ar(442, 0, 0.2)] }.scope;

Scope 还有一个 zoom 参数。值越大越“缩小”。

{ [SinOsc.ar(440, 0, 0.2), SinOsc.ar(442, 0, 0.2)] }.scope(zoom: 10);

与 Function-plot 类似，Function-scope 可用于测试目的，并查看你是否真的得到了你所期望的结果。

按需示波

你也可以随时通过调用 'scope' 来示波显示服务器的输出。

{ [SinOsc.ar(440, 0, 0.2), SinOsc.ar(442, 0, 0.2)] }.play;
s.scope;

你也可以通过点击服务器窗口并按 's' 键来完成同样的操作。

Function、Server、Stethoscope

建议练习

尝试对前面章节中的一些 Function 示例以及你自己创建的一些 Function 进行示波和绘图实验。尝试使用不同的 duration 或 zoom 值进行实验。
