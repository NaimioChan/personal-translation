MainMenu

sclang 应用程序级菜单的管理器

另请参阅：MenuAction、ToolBar、MainMenu

说明

此类允许控制 sclang 应用级菜单中显示的项。应用级菜单可能因平台而异而不存在——特别是 macOS 和某些 Linux 窗口管理器有该菜单，而 Windows 则没有。在没有此功能的平台上，此类中的方法不会执行任何操作。

注意： 这是 sclang 应用程序的菜单，而非 IDE 的菜单。

警告： 该类的行为在 3.10.2 版本中发生了变化。与 3.10.0 和 3.10.1 版本一样，用于控制进程和服务器的菜单项将不会默认添加和更新。这些菜单项仍可通过调用 initBuiltInMenus 来创建。此行为在未来的版本中可能再次改变。

(
~testTone = MenuAction("Test Tone", {
    { SinOsc.ar(400) * 0.1 }.play;
});

MainMenu.register(~testTone, "Tests");
)

MainMenu.unregister(~testTone); // 移除

类方法

.initBuiltInMenus

在主 "SuperCollider" 菜单下初始化菜单项，启用进程和服务器监控与控制：

  • 停止 - 与 Cmd/Ctrl-Period 相同
  • 服务器 - 一个子菜单，列出可用的服务器，并带有控制每个服务器的菜单项。默认服务器会被标注，在此菜单中选择某个服务器的名称会将其设为默认服务器。
  • 退出 - 退出 sclang 进程

.register

向主应用程序菜单注册一个 MenuAction。该菜单项将在应用程序的整个生命周期内存在，或直到对该动作调用 .unregister 为止。

参数：

action

一个 MenuAction。

menu

一个 String，表示包含该操作的顶级菜单的名称。

group

一个可选字符串。动作将被放置在菜单中与同一组的其他成员一起的区域，并与其他组的项之间用分隔符隔开。

讨论：

MainMenu.register 提供了一种注册全局菜单项的简便方法，有助于避免干扰其他 SuperCollider 组件注册的菜单。

如果要为个人使用注册菜单，请将注册调用添加到你的 startup.scd 文件中。这样可以确保菜单在启动时自动创建。

如果你正在为 Quark 或其他打算分发的组件注册菜单动作，请务必礼貌且慎重地考虑在哪里注册这些动作。

尽可能避免创建新的顶层菜单——相反，请尝试使用以下规范菜单之一来注册你的动作。将你的动作添加到组中，以确保你不会与另一个组件的动作冲突：

  • File
  • Edit
  • Server
  • Quarks
  • Help

如果为 Quark 注册菜单项，请考虑将其注册为 Quarks 菜单的子菜单。这可以很容易地通过 *registerQuarkMenu 方法完成。

.registerQuarkMenu

用于注册与某个 Quark 相关的功能菜单的便捷方法。它将作为主 Quarks 菜单下的子菜单出现。

参数：

quarkName

一个 String，quark 的名称

menu

一个 Menu，即一个菜单。

.unregister

移除先前注册的 MenuAction。

注意： 动态地添加和移除菜单项通常会带来干扰和困惑。如果你要注册一个只是偶尔可用的菜单项，请考虑用 menuAction.enabled = false; 将其禁用，而不是将其移除。

参数：

一个 MenuAction。

.otherMenus

要追加到主应用程序菜单集中的菜单列表。

警告： 这旨在用于独立的 SuperCollider 应用程序，不应在正常 SC 使用期间用于注册菜单。

.add

向 otherMenus 添加一个菜单。

参数：

menu

一个 Menu。

.remove

将菜单移除到 otherMenus。

参数：

menu

一个 Menu。

.insert

在给定索引处将菜单插入 otherMenus。

参数：

index

索引。一个 Integer。

menu

一个 Menu。

.clear

清除 otherMenus。主应用程序菜单不受影响。

参数：

menu

一个 Menu。

.applicationMenu

SuperCollider 主应用程序菜单。

警告： 这旨在用于独立的 SuperCollider 应用程序，不应在正常 SC 使用期间用于注册菜单。

实例方法

示例

(
~show = MenuAction("Show Window", {
    ~window ?? {
        ~window = TextView().string_("Here it goes!").minSize_(300@200);
        ~window.onClose = { ~window = nil };
        ~window.front;
    }
});
~hide = MenuAction("Hide Window", {
    ~window !? {
        ~window.close();
        ~window = nil;
    }
});

MainMenu.register(Menu(~show, ~hide).title_("My Quark"), "Quarks", "My Quark")
)
