LIDInfo

LID 的辅助类，用于保存关于 LID 设备的信息。

Object

参见：LID

说明

此类包含有关 LID 设备的基本信息，以便访问并打开该设备。此类主要用于内部，用户很少直接访问。

此类由从设备读取的信息填充，表示设备的某些内部信息。

类方法

实例方法

.open

打开此 LIDInfo 所描述的设备

返回值：

一个 LID - 设备

.postInfo

以人类可读的方式发布 LIDInfo

.findArgs

一个参数数组，可以传入 LID.findBy 以查找此设备。

.name

设备名称，由设备自身报告。

.vendorID

设备的供应商 ID，这是由设备自身编码的数字。

.productID

设备的 product ID，这是由设备自身编码的数字。

.path

.path = value

设备的路径，这是由操作系统定义的路径，对于区分具有相同供应商和产品 ID 的设备至关重要。

.version

该设备的版本号。

.physical

设备的物理位置，由操作系统定义。

.unique

设备的唯一标识符，由操作系统定义。

.bustype

此设备的 bustype
