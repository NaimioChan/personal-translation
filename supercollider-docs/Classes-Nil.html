Nil

表示未初始化的数据

Object

说明

Nil 有一个名为 nil 的单一实例，用于表示未初始化的数据、错误的值或终止值，例如流的结束。

注意： 请注意，Nil 是一个类，而不是特殊值 nil。比较 Nil 和 nil 将返回 false。在正常使用中，你不需要直接使用这个类：使用 nilNil.isNil; // false Nil == nil; // false Nil === nil; // false

.isNil

返回 true，因为这是 nil。在类 Object 中，此消息被定义为返回 false。

[1, 2, nil, 3].collect(_.isNil);

.notNil

返回 false。在类 Object 中此消息返回 true。

[1, 2, nil, 3].collect(_.notNil);

?(obj)

返回第一个非 nil 的参数。由于此参数确实为 nil，因此返回 anObject。在类 Object 中，? 被定义为返回接收者。

[1, 2, nil, 3].collect { |x| x ? -1 }; // 用 -1 替换 nil

??(obj)

若接收者为 nil，则求值该函数并返回结果。由于这 IS nil，因此求值该函数并返回结果。在类 Object 中，?? 被定义为返回接收者。

[nil, 2, nil, 3].collect { |x| x ?? { 100.rand } }; // 用随机数替换 nil

Dependancy

Dependancy 协议（参见类 Object）的所有消息在类 Nil 中定义为不做任何事。这消除了在发送依赖消息时检查 nil 的需要。

其他方法

类 Nil 中定义了许多其他消息，它们什么都不做。这消除了检查 nil 的需要。

通用收集器

有许多方法可以应用于 nil，这样变量就无需初始化。Nil 只是用于引导其余一切的“基础”（默认情况）。

.add(value)

返回一个包含该值的数组。这使得在添加到变量时无需初始化。

x = nil;
x = x.add(8);  // 返回一个数组
x = x.add(7); // 追加到数组

.addAll(array)

返回包含所有值的数组。这样在添加到变量时就无需初始化。

x = nil;
x = x.addAll([0, 2, 1, 2]);  // 返回一个数组
x = x.addAll(7); // 单个对象会被转换

.remove

对于 nil，它只返回 nil。这样在从变量中移除并再次添加时就不需要初始化。

x = nil;
x.remove(1); // 保持为 nil，返回 nil
x = x.addAll([0, 2, 1, 2]);  // 返回一个数组
x.remove(1); // 返回 1
x;

++(array)

返回包含所有值的数组。这样在添加到变量时就无需初始化。

x = nil;
x = x ++ [7, 8, 9]; // 返回接收者
x = x ++ [3, 0, 1, 2]; // 添加到数组

.addFunc( ... functions)

返回一个函数或一个 FunctionList。此方法用于向已有函数中添加多个函数。

f = nil;
f = f.addFunc { "----------****".scramble };
f = f.addFunc { 1.0.rand };
f.value;

.removeFunc

此方法用于从已有函数中移除多个函数。对于 Nil，它只返回自身。

f = { 1.0.rand };
g = { "you have produced a random value".postln };
f = f.addFunc(g);
f.value;
f.removeFunc(g);
f.value;

.transformEvent(event)

此方法用于操作作为参数通过系统传递的事件。

// 对于 Nil：原样返回参数（一个事件）。
nil.transformEvent((x: 8));
// 对于 Dictionary（因此也对于 Event）：添加到参数中。
(y: 100, z: 1).transformEvent((x: 8));
// 对于 Association：将关联添加到事件中
(\a -> \x).transformEvent((x: 8));
// 对于 Function：使用该函数接收事件作为参数。
{ |event| event.use { ~x = ~x + 1 }; event }.transformEvent((x: 8));
