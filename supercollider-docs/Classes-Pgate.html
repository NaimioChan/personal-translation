Pgate

一种门控流，仅当特定事件键为 true 时才推进。

Pn : FilterPattern : Pattern : AbstractFunction : Object

另见：Pn

说明

每当 key 为 true 时，Pgate 推进其子模式。Pgate 必须在 Event 模式内使用。你可以手动设置 key，或使用 Pn。

类方法

Pgate.new(pattern, repeats: inf, key)

参数：

pattern

要过滤的源模式。

repeats

将包含的模式重复 repeats 次。

key

Pgate 仅当其所属事件的 key 设置为 true 时，才会返回源模式中的下一个值。否则，它将一直返回相同的值。这允许对流产生门控效果。

实例方法

.embedInStream(event)

示例

// 使用 \step 来随机改变八度
(
Pbind(
    \degree, Pseq((0..7), inf),
    \step, Pseq([false, false, false, true, false, true, false], inf),
    \octave, Pgate(Pwhite(3, 7), inf, \step),
    \dur, 0.2
).play
)
// Pn 每次重复其子模式时推进 Pgate
(
Pbind(
    \degree, Pn(Pseq((0..7)), inf, \step),
    \mtranspose, Pgate(Pwhite(0, 5), inf, \step),
    \dur, 0.2
).play
)


// 两个不同的 Pgate 以两个不同的速率推进
(
Pbind(

    \scale,    Scale.minor,
    \foo, Pn(Pseq((0..2)), inf, \step1),
    \degree, Pn(Pseq((0..7).mirror), inf, \step),
    \ctranspose, Pgate(Pwhite(0, 5), inf, \step) + Pgate(Pseq([0, 7, 0, -7], inf), inf, \step1),
    \dur, 0.2
).play
)
