EnvirGui

显示环境的内容以便编辑

另请参阅：EZText、TdefGui、PdefGui

说明

EnvirGui 显示环境的所有键和值，因此可以灵活地更改它们。单个数字用 EZSlider 显示，成对的数字用 EZRanger 显示，其他任何内容则显示为 EZText（一个文本字段）。

类方法

Creation

.new

创建一个新的 EnvirGui NdefParamGui

// 简单示例
g = EnvirGui.new(nil, 5);    // 空的有 5 个槽位
g.parent.alwaysOnTop_(true);
g.object_((a: 1, b: \werty, freq: [500, 2000]));    // 放入一些东西
g.envir.put(\karl1, \otto1);                // 再来一个
g.envir.put(\caesar, \julius);                // 再来一个

g.envir.putAll((b: -12, r: 1, s: 2, t: 3, u: 4, v: 5))

g.object_((x: 2));    // 放入另一个对象

g.envir.putAll((b: -12, r: 1, s: 2, t: 3, u: 4, v: 5))

g.envir.removeAt(\b)
g.envir.removeAt(\r)
g.envir.removeAt(\s)
g.envir.removeAt(\t)
g.envir.removeAt(\u)
g.envir.removeAt(\v)
g.close;

参数：

object

要显示的环境

numItems

要显示的项数。如果给定了 envir 且没有 num，则 num 为 envir.size。

parent

要显示在其中的父视图；如果未给出，则创建一个新窗口。

bounds

要显示的边界；如果未给出，则计算边界。

makeSkip

标志是否创建一个 skipjack 来管理 envirgui 的更新。

options

配置选项

实例方法

实例变量

.numItems

显示多少个环境项

.envir

显示的环境变量 - 实际上是 object 的别名。

.zone

envirgui 为自身构建的复合视图

.paramViews

显示值的 paramViews：

  • 单个数字显示在 EZSlider 中，
  • 数字对将显示在 EZRanger 中，
  • 所有其他值在 EZText 中显示为 compileString。

详情请参阅 ParamView。

.specs

此 envirgui 的 paramViews 用于显示数值参数范围所用的规格的局部字典。详情请参见 -getSpec 方法。

.editKeys

字典中当前显示项的键。

.keysRotation

如果 envir 的大小超过 numItems，显示的键可以轮换：例如在 5 个 paramViews 上显示 10 个键时，keysRotation 为 0 表示显示键 (0..4)，keysRotation 为 2 表示显示键 (2..6)，等等。

如果选项中要求，则显示 gui 元素

.knowBut

.parentBut

部分方法

.object

设置要显示的环境

参数：

obj

可以为 nil、字典、环境或事件。

g = EnvirGui((freq: 120, \amp: 0.2, \pan: -0.5), 12, nil, bounds: Rect(20, 400, 220, 100));
g.object_((a: 1, b: [2, 3], c: \symbol, d: [4, 5, 6], f: { "boing".postln }))

.envir

与 object_(obj) 相同

.name

如果在其自己的窗口中，则设置该窗口的名称

g.name_("Yoohoo");

.getSpec

编辑时，数值参数需要控制规格来确定 GUI 上的范围。这些规格可以在 EnvirGui 中局部设置，否则将查找全局规格。如果该参数名不存在局部或全局规格，getSpec 会为其做出可用的猜测。（使用 JITLibExtensions 时，还可以查找附加到对象（例如 proxy）上的规格。）

// 内联示例
g = EnvirGui.new; g.parent.alwaysOnTop_(true);
g.getSpec(\freq, 400);        // \freq 作为全局 spec 存在，因此使用它
g.object_((freq: 150));

g.getSpec(\iFrek, 500);        // 没有全局 spec，所以新建一个：
                // 从 val * 0.05 到 val * 20 的指数；
g.specs;            // 并保留在这里
g.envir.put(\iFrek, 500);

参数：

key

要为其查找 spec 的参数名

value

该参数的当前值，用于推测 spec。

.putSpec

为给定键添加一个 spec，或者（如果它是全局键）用局部 spec 覆盖全局 spec：

// 设置期望的范围并进行 warp：
g.putSpec(\iFrek, [10, 1000, \exp]);
g.putSpec(\freq, [10, 1000, \exp]);
g.specs;
g.putSpec(\freq, \freq);

// 对象变化时 spec 会被记住
g.putSpec(\freq, [10, 1000, \exp]);
g.object_((freq: 200, iFrek: 20));

// 切换对象时如有需要，手动清除 specs
g.specs.clear; g.object_((freq: 200, iFrek: 20));

g.close

具有技术名称的键可在显示时替换为更清晰的名称：方法 replaceKeys 用于要替换的当前键列表

.addReplaceKey

添加要替换的键及其替换键

.removeReplaceKey

移除替换器键

.showKeyFor

show

e = (longFreq: 123, amp: 0.25);
g = EnvirGui(e); g.parent.alwaysOnTop_(true);

g.editKeys;
g.addReplaceKey(\longFreq, \freq1, [50, 500, \exp]);
g.viewForParam(\longFreq).visible_(false);
g.viewForParam(\freq1).visible_(true);

e.put(\z, 345);
e.put(\a, 34);

g.replaceKeys
g.removeReplaceKey(\longFreq)

.highlight

按颜色和可选前缀高亮给定索引处的 paramview

g.highlight(0);
g.highlight(0, ">>_");
g.highlight(0, ">>_", Color.green(1, 0.6));

.unhighlight

移除索引处的高亮 g.unhighlight(0);
