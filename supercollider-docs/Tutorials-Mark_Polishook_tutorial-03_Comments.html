Comments

注释是描述性说明，旨在供人阅读但被计算机忽略。程序员使用注释来标注代码如何工作或做什么。也有这样的情况：有些人发现先写注释再填充匹配的代码来编写程序很有帮助。

////////////////////////////////////////////////////////////////////////////////////////////////////

要在 SuperCollider 中写注释，可以在文本前加上

//

如同

// 直到行末的所有内容都是注释

或在之间的一行或多行上放置文本

/* and */

如同

/*

这
是
一条
注释

 */

如果（当）求值时，注释将返回 nil，这是 SuperCollider 用于未初始化数据的值。

////////////////////////////////////////////////////////////////////////////////////////////////////

使用 Format->Syntax Colorize（或 cmd-'）对注释进行语法着色。
