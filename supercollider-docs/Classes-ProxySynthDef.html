ProxySynthDef

包装 ugen 图的 synth def

SynthDef : Object

参见：NodeProxy

说明

（由 NodeProxy 内部使用）

内部工作原理参见 jitlib_fading

类方法

ProxySynthDef.new(name, func, rates, prependArgs, makeFadeEnv: true, channelOffset: 0, chanConstraint, rateConstraint)

参数：

name

如同在 SynthDef 中那样。todo：添加变体。

func

如同在 SynthDef 中那样。todo：添加变体。

rates

如同在 SynthDef 中那样。todo：添加变体。

prependArgs

如同在 SynthDef 中那样。todo：添加变体。

makeFadeEnv

若为 true，则构造一个推子包络并添加 gate 和 fadeTime 控件

channelOffset

添加到输出编号上的常量偏移

chanConstraint

synthdef 的最大 numChannels。若 ugenfunc 返回更大的数组，则将其环绕

rateConstraint

一个符号，如 \audio、\control 或 \scalar。

ProxySynthDef.sampleAccurate

ProxySynthDef.sampleAccurate = value

如果设置为 true，则始终使用 OffsetOut（默认：false）

示例

a = ProxySynthDef("xtest", { SinOsc.ar(400) * 0.1 });

a.add;

x = Synth("xtest");
