BPZ2

两个零点固定中通。

LPZ2 : Filter : PureUGen : UGen : AbstractFunction : Object

参见：BRZ2、HPZ2、LPZ2

说明

一种特殊情况的固定滤波器。实现以下公式：

out(i) = 0.5 * (in(i) - in(i - 2)).

此滤波器会切除 0 Hz 和奈奎斯特频率。

类方法

BPZ2.ar(in: 0.0, mul: 1.0, add: 0.0)

来自父类：LPZ2

BPZ2.kr(in: 0.0, mul: 1.0, add: 0.0)

来自父类：LPZ2

参数：

in

输入信号。

实例方法

示例

// 比较：

{ WhiteNoise.ar(0.25) }.play;

{ BPZ2.ar(WhiteNoise.ar(0.25)) }.play;
