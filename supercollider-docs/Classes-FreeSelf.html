FreeSelf

触发时，释放所属的 synth。

UGen : AbstractFunction : Object

另请参阅：PauseSelf、Free

说明

当输入信号从非正变为正时，释放所属的 synth。

类方法

FreeSelf.kr(in)

参数：

in

输入信号。

实例方法

未文档化的实例方法

.canFreeSynth

来自扩展 /usr/local/share/SuperCollider/SCClassLibrary/Common/Audio/canFreeSynth.sc

示例

(
SynthDef("freeSelf-help", { |out, t_trig|
    FreeSelf.kr(t_trig);
    Out.ar(out, SinOsc.ar(400, 0, 0.2));
}).add;
)

s.sendMsg("/s_new", "freeSelf-help", 1731);
s.sendMsg("/n_set", 1731, \t_trig, 1);

// 一个单脉冲 SynthDef：

(
SynthDef("dirac", { |out, amp = 0.1|
    var u;
    u = Impulse.ar(1);
    FreeSelf.kr(u);
    Out.ar(out, u * amp);
        // 在用于释放后再乘以 amp，这样 amp = 0
        // 不会导致合成器堆积。
}).add;
)

(
Task {
    loop({
        fork {
            exprand(34, 156).do { |i|
                i = i + 1;
                s.sendMsg("/s_new", "dirac", -1, 0, 0, \amp, 1 / i);
                (0.006 * i).wait;
            };
        };
        1.wait;
    })
} .play;
)
