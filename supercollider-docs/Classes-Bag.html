Bag

对象的无序集合

Collection : Object

另请参阅：IdentityBag、Set

子类：IdentityBag

说明

Bag 是一种无序的对象集合。在某些语言中它被称为计数集合。Bag 会记录对象被插入的次数，并要求对象被移除相同的次数。即使一个对象被多次添加到 Bag 中，Bag 中也只有一个该对象的实例（判断依据是相等性）

Bag 的大多数方法继承自 Collection。Bag 的内容是无序的。你不能依赖集合中各项的顺序。

类方法

Bag.new(n: 4)

创建一个具有 n 个对象初始容量的 Bag。

实例方法

.contents

返回以成对形式（obj -> numberOfObjects）存储对象的字典。

Bag["a", "b", "c", "c"].contents;

返回值：

Dictionary

.itemCount(item)

统计 item 的数量。

Bag[1, 2, 2, 3, 300, 2].itemCount(2);

添加与移除

.add(item, count: 1)

向 Bag 中添加一个对象。一个 Bag 可以包含同一对象的多个条目。

Bag[1, 2, 3].add(4).postln;

Bag[1, 2, 3].add(3).postln;

Bag["abc", "def", "ghi"].add("jkl").postln;

Bag["abc", "def", "ghi"].add("def").postln;

.remove(item, count: 1)

从 Bag 中移除对象。

Bag[1, 2, 3].remove(3).postln;

Iteration

.do(function)

对 Bag 中的每一项求值 function。该函数会传入两个参数：项和一个整数索引。

Bag[1, 2, 3, 300].do({ |item, i| item.postln });

Bag[1, 2, 2, 3, 300].do({ |item, i| item.postln });

参数：

function

传给函数的参数：item、i

.countsDo(function)

对 Bag 中的每个唯一项及其计数求值 function。该函数传入两个参数：该项、该项在 Bag 中的数量，以及一个整数索引。

Bag[1, 2, 3, 300].countsDo({ |item, count, i| [item, count].postln });

Bag[1, 2, 2, 3, 300].countsDo({ |item, count, i| [item, count].postln });

Testing

.includes(item)

回答对象是否包含在 Bag 中。

Bag[1, 2, 3, 4].includes(3);

返回值：

Boolean

示例

Bag 与 IdentityBag 的区别：

// 两个字符串相等，但不完全相同
"something" == "something"; // true
"something" === "something" // false

a = Bag.new;
a.add("something");
a.add("something");
a.contents; // bag 中实际上只有一个对象

a = IdentityBag.new;
a.add("something");
a.add("something");
a.contents; // 袋中有两个对象
