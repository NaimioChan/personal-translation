PulseDivider

脉冲分频器。

UGen : AbstractFunction : Object

说明

每当在其输入处接收到一定数量的触发时，输出一个脉冲。

类方法

PulseDivider.ar(trig: 0.0, div: 2.0, start: 0.0)

PulseDivider.kr(trig: 0.0, div: 2.0, start: 0.0)

参数：

trig

Trigger。Trigger 可以是任何信号。当信号从非正变为正时，触发发生。

div

在输出一个脉冲之前要计数的触发次数。

start

触发器计数的起始值。它允许你从计数中间的某个位置开始。如果 start 为负数，则会在输出第一次被触发时加上相应数量的计数。

实例方法

示例

SynthDef("help-PulseDivider", { |out = 0|
    var p, a, b;
    p = Impulse.ar(8);
    a = SinOsc.ar(1200, 0, Decay2.ar(p, 0.005, 0.1));
    b = SinOsc.ar(600, 0, Decay2.ar(PulseDivider.ar(p, 4), 0.005, 0.5));

    Out.ar(out, (a + b) * 0.4)
}).play;
