DoubleArray

一个 64 位双精度浮点数数组

RawArray : ArrayedCollection : SequenceableCollection : Collection : Object

另请参阅：FloatArray、Signal

说明

一个由 64 位双精度浮点数组成的数组。

请注意，尽管名称中没有“Float”，DoubleArray 实际上保存的是一段 SuperCollider 双精度 floats 序列。若需要 32 位浮点数的原始数组，请使用 FloatArray。

FloatArray 及其子类 Signal 常用于在 SuperCollider 中保存音频数据。由于几乎所有音频都是 16 位或 24 位精度，为此使用双精度浮点数会浪费空间。换言之，音频使用 FloatArray，精确的数学运算使用 DoubleArray。

SuperCollider 中 RawArray 类型的完整列表为：

  • Int8Array - 8 位整数
  • Int16Array - 16 位整数
  • Int32Array - 32 位整数
  • FloatArray - 32 位浮点数
  • DoubleArray - 64 位浮点数
  • SymbolArray - 符号

注意： DoubleArray 中元素的溢出/下溢行为未定义，但通常分别为 inf/-inf。当运算结果超出返回类型（此例中为 64 位浮点数）所支持的值范围时就会发生。参见 Float 中的说明。
