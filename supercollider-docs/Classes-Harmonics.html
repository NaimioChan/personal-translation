Harmonics

在服务器上用谐波填充缓冲区的便捷工厂

Object

说明

Harmonics 对象是便捷的工厂，用于创建数组，这些数组在服务器上通过 b_gen sine 填充命令来填充缓冲区。

类方法

Harmonics.new(size: 32)

创建一个大小为 size 的新 Harmonics 数组。在应用实例方法之前，不会为您填充任何内容。

a = Harmonics.new(16);    // 仅返回一个指定大小的 Harmonics 实例

实例方法
