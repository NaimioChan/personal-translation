UnaryOpUGen

对输入 ugen 的值应用一元运算

BasicOpUGen : UGen : AbstractFunction : Object

另请参见：BinaryOpUGen、UnaryOpFunction、Punop、Operators

说明

UnaryOpUGen 是对 UGen 应用一元运算符的结果。

(SinOsc.ar(200).abs).dump;
(LFSaw.ar(200).sin).dump;

正如这里给出的示例所示，你通常不需要自己实例化 UnaryOpUGen。

一元和二元运算符定义在 UGen 的父类 AbstractFunction 中，该运算的结果会创建 BinaryOpUGen。

有关常见运算符的概述，请参见 Operators。

类方法

UnaryOpUGen.new(selector, a)

返回一个新实例，将操作符 selector 应用于 ugen a

参数：

selector

一元运算符的选择器符号

a

operand

实例方法

未文档化的实例方法

.optimizeGraph

示例

a = WhiteNoise.ar; // 一个白噪声
b = a.squared; // 一个 UnaryOpUGen。
b.operator; // 平方

// 声音示例

{ var a = LFSaw.ar(300).range(0, 2pi); a.sin * 0.1 }.play;

// 绘制 "abs" 一元运算符（通过服务器）：

{ SinOsc.ar(300).abs }.plot
