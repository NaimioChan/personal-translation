FoldIndex

用信号索引表。

Index : PureUGen : UGen : AbstractFunction : Object

另请参阅：Index、Shaper

说明

输入信号值被截断为整数值，并用作表的索引。超出范围的索引值会被折叠到有效范围内。

类方法

FoldIndex.ar(bufnum, in: 0.0, mul: 1.0, add: 0.0)

来自父类：Index

FoldIndex.kr(bufnum, in: 0.0, mul: 1.0, add: 0.0)

来自父类：Index

参数：

bufnum

缓冲区索引。

in

输入信号。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

// 索引到表中
(
{
    var buf = LocalBuf.newFrom([200, 300, 400, 500, 600, 800]);
    var freq = FoldIndex.kr(buf, MouseX.kr(0, BufFrames.ir(buf) * 3));
    SinOsc.ar(freq) * 0.1
}.play;
)

// 使用全局缓冲区的相同做法
(
t = [200, 300, 400, 500, 600, 800];
b = Buffer(s, t.size, 1);

// 分配并设置这些值
s.listSendMsg(b.allocMsg(b.setnMsg(0, t)).postln);

SynthDef(\help_Index, { |out = 0, bufnum = 0|
    Out.ar(out,
        SinOsc.ar(
            FoldIndex.kr(
                bufnum,
                MouseX.kr(0, BufFrames.ir(bufnum) * 3)
            ),
            0,
            0.5
        )
    )
}).play(s, [\bufnum, b.bufnum]);
)
