PriorityQueue

优先队列数据结构

Object

说明

PriorityQueue 实现了一种优先队列数据结构，用于构建调度器。它允许你在任意时间放入条目，并按时间顺序弹出它们。

类方法

实例方法

.put(time, item)

在给定时间将元素放入队列。

.topPriority

返回队列中最早项的时间。

.pop

返回队列中最早的项目。

.clear

清空队列。

.isEmpty

返回一个表示队列是否为空的 Boolean。

.notEmpty

返回一个 Boolean，表示队列是否非空。

.removeValue(value)

从队列中移除所有 value 实例。
