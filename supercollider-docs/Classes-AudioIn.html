AudioIn

读取音频输入。

SoundIn : Object

另请参阅：In、SoundIn

说明

从声音输入硬件读取音频。

注意： 此功能是为与 SC2 代码向后兼容而提供的。正常使用请用 SoundIn，它的总线编号从 0 开始，因为 AudioIn 可能会在将来某个时候被弃用并移除。

类方法

AudioIn.ar(channel: 0, mul: 1.0, add: 0.0)

参数：

channel

要读取的输入通道号。通道号从 1 开始。

mul

add

未文档化的类方法

AudioIn.channelOffset

实例方法

示例

将输入连接到输出

// 将输入连接到输出

// 注意反馈

(
ServerOptions.inDevices.postln;    //  列出可用的音频输入设备
s.meter;    // 显示电平表用于监听
SynthDef(\helpAudioIn, { |out|
    var input = AudioIn.ar(1); // 第一个输入
    // 延迟输出以抑制反馈，以防配置了麦克风：
    Out.ar(out, CombN.ar(input * -25.dbamp, 0.5, 0.5, 0.001))
}).play
)
