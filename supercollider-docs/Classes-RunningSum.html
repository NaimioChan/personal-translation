RunningSum

对 n 帧进行累加求和

UGen : AbstractFunction : Object

说明

对用户指定数量的采样进行累加求和，适用于运行 RMS 功率加窗。

类方法

RunningSum.ar(in, numsamp: 40)

RunningSum.kr(in, numsamp: 40)

参数：

in

输入信号

numsamp

用于计算滑动总和所取的采样数（仅初始化时生效，不可调制。默认：40）

未文档化的类方法

RunningSum.rms(in, numsamp: 40)

实例方法

示例

// 当然会失真——需要缩放
{ RunningSum.ar(SoundIn.ar) }.play

// 对 x 个样本的运行平均值
(
{
    var x = 100;
    RunningSum.ar(LFSaw.ar, x) * (x.reciprocal)
 }.play
)
// RMS 功率
(
{
    var input, numsamp;

    input = LFSaw.ar;
    numsamp = 30;

    (RunningSum.ar(input.squared, numsamp) / numsamp).sqrt
}.play
)
// 类中的快捷方式
{ RunningSum.rms(SoundIn.ar) }.play
// play around
(
{
    var input, numsamp, power;
    numsamp = 500;
    input = SoundIn.ar;
    power = MouseX.kr(0.1, 4);

    (RunningSum.ar(input ** power, numsamp)/numsamp) ** (power.reciprocal)
}.play
)
