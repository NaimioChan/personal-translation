Tdef

任务引用定义

TaskProxy : PatternProxy : Pattern : AbstractFunction : Object

另请参阅：TaskProxy、Task、Routine

说明

Tdef 按键注册任务。对已注册任务的所有访问都经由该键通过 Tdef 类进行。已注册的任务可以在播放时替换为其他任务。旧任务及其替代任务可以自动交叉淡化，且替代时间可以量化。

Tdef 提供了其父类 TaskProxy 的接口。Tdef 保留对任务（时间模式）的引用，该任务可在播放时被替换。当旧的流结束并设置了新的流时，它继续播放，并按节拍调度这些变化。一个 Tdef 可以在不同地方的多个任务中使用。任务定义 Tdef 中的变化会传播到所有任务。

Tdef(key)    // 返回该实例
Tdef(key, func)    // 定义任务并返回实例，类似 Pdef 和 Ndef。

所有当前 Tdef 的图形概览：TdefAllGui。概览：JITLib

第一个示例

Tdef(\x, { loop { 0.5.wait; "aaaaaaaaaaaaaazz".scramble.postln } }).play;
Tdef(\x, { loop { 0.125.wait; "aazz".scramble.postln } });
Tdef(\x, { loop { 0.5.wait; (note: 14.rand).play } });
Tdef(\x, { loop { 0.5.wait; (note: 14.rand + [0, 3, 6, 7].keep(4.rand)).play } });
Tdef(\x).stop;
Tdef(\x).play;
Tdef(\x).clear;

类方法

Tdef.all

Tdef.all = value

一个包含所有代理的全局 IdentityDictionary。

Creation

Tdef.new(key, item)

将任务存储在全局字典中的 key 下，用新的函数替换其例程函数。

使用 *new(key) 可以访问该键处的模式（如果未给出，则创建一个默认任务）

参数：

key

代理的标识符。通常它是一个 Symbol。该键会透明地访问全局 IdentityDictionary。

item

用于（重新）定义代理源的对象。如果为 nil，则返回未经修改的代理。

Tdef.default

来自父类：TaskProxy

默认源，如果未提供源时使用。默认任务有一个函数，以 1.0 拍为步长等待且不做任何事。

Tdef.removeAll

来自父类：PatternProxy

从全局字典（*all）中移除所有代理

Tdef.clear

来自父类：PatternProxy

清除所有代理，将其源设置为静音。

Tdef.all

Tdef.all = value

设置或返回存储所有实例的环境（IdentityDictionary）。

Tdef.defaultQuant

Tdef.defaultQuant = value

来自父类：TaskProxy

为新实例设置默认量化（默认值：1.0）。可以是一个数组 [quant, phase, timingOffset, outset]

实例方法

更改定义 / 设置源

一个 Tdef 可以在不同位置拥有许多任务。任务定义中 Tdef 的更改会传播到所有任务。该更改不必立即生效——有一套方案来安排更改何时生效：quant 和 clock（与其他地方一样）以及一个 condition。

.quant

.quant = val

来自父类：PatternProxy

设置用于节拍精确调度的量化时间。

.clock

.clock = value

来自父类：PatternProxy

获取或设置实例的默认时钟，在没有指定其他时钟时由 -play 使用。默认为 TempoClock.default。

参数：

(val)

可以是数组 [quant, phase, timingOffset, outset]，或仅 [quant, phase] 等。

.condition

.condition = value

来自父类：PatternProxy

提供在插入新模式时切换模式的条件。流值和计数值会被传入该函数。

.count(n: 1)

来自父类：PatternProxy

创建并更新条件，该条件简单地计数到 n，然后切换模式

.reset

来自父类：PatternProxy

立即切换任务（可以通过此方式绕过卡住的条件）。

.envir

.envir = value

来自父类：PatternProxy

为 Tdef 设置环境（一个 Event）。它作为第一个参数传入 Task 函数。

.set( ... args)

来自父类：PatternProxy

在默认事件中设置参数。如果没有默认事件，则创建它并重建任务例程。

.clear

来自父类：PatternProxy

将源设为 nil

.endless(default)

来自父类：PatternProxy

返回一个 Prout，它无休止地播放该 task，将 nil 替换为 default 值 1。这样可以创建在新模式插入之前一直空闲的流。

作为流引用的 Tdef

单个 Tdef 可以作为多个任务的定义。这些方法展示了如何从一个实例派生出独立的例程。即使它们在不同的上下文中运行，它们的定义仍然可以被更改。

.fork(clock, quant, event)

来自父类：TaskProxy

并行播放一个独立任务。

参数：

clock

用于播放分叉任务的时钟

quant

可以是一个 [quant, phase, offset] 数组，或一个 Quant 值。

event

要传入分叉任务的事件

.embed(val)

来自父类：PatternProxy

将一个值（通常是 Event）传入 task 函数，并将 Tdef 嵌入到流中。

.embedInStream(inval, embed: true, default)

来自父类：PatternProxy

就像任何模式一样，它嵌入到流中

作为 EventStreamPlayer 的 Tdef

对于现场编程，每个 Tdef 还可控制一个播放一个 task 的实例。这是一个 PauseStream，可通过实例变量 -player 访问。

.play(argClock, doReset: false, quant)

来自父类：TaskProxy

启动 Tdef 并创建一个播放器。

参数：

argClock

用于播放 Tdef 的时钟。如果为 nil，则使用实例的 -clock，其又默认为 TempoClock.default。

doReset

一个标志，表示如果任务已在播放是否重置

quant

可以是 [quant, phase, offset] 的数组，或一个 Quant 值。

.stop

来自父类：TaskProxy

停止播放器

.player

来自父类：TaskProxy

返回当前播放器（如果 Tdef 仅在其他流中使用，则为 nil）

.pause

来自父类：TaskProxy

.resume(clock, quant)

来自父类：TaskProxy

.reset

来自父类：PatternProxy

在 player 上执行此方法。

.isPlaying

来自父类：TaskProxy

如果 player 正在运行则返回 true。如果某个 Tdef 正在播放且其流结束，它将会安排一个流来播放，一旦有新的流被分配给它。如果它被 stop 停止，则不会如此。

示例

Tdef 作为 Task 播放器

Tdef(\x).play; // 创建一个空的 Tdef 并播放它。

Tdef(\x, { loop({ "ggggggggggggggggg9999ggg999ggg999gg".scramble.postln; 0.5.wait }) });


Tdef(\x, { loop({ "---------////----------------------".scramble.postln; 0.25.wait }) });
Tdef(\x, { loop({ thisThread.seconds.postln; 1.wait }) });
Tdef(\x, { loop({ thisThread.seconds.postln; 1.01.wait }) });

TempoClock.default.tempo = 2;

Tdef(\x, { "the end".postln });
Tdef(\x, { "one more".postln });
Tdef(\x, { 10.do({ "ten more".scramble.postln; 0.25.wait }) });
Tdef(\x, { loop({ "lots more".scramble.postln; 0.25.wait }) });

TempoClock.default.tempo = 1;

Tdef(\x).stop;
Tdef(\x).play;

Tdef(\x).clear;
// 声音示例

(
// 加载 synthdef
s.boot;
SynthDef(\pdef_grainlet,
    { |out = 0, freq = 440, sustain = 0.05|
        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain, 0.3), doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env))
    }).add;
)
Tdef(\x).play;

(
Tdef(\x, {
    loop({
        s.sendMsg("/s_new", "pdef_grainlet", -1, 0, 0, \freq, rrand(600, 640));
        0.1.wait;
    })
})
)

(
Tdef(\x, {
    var x;
    x = Pseries(300, 20, 100).loop.asStream;
    loop({
        s.sendMsg("/s_new", "pdef_grainlet", -1, 0, 0, \freq, x.next);
        0.05.wait;
    })
})
)

(
Tdef(\x, {
    var x;
    x = Plazy({ Pseries(300 + 300.rand, 10 + 30.rand, 10 + 30.rand) }).loop.asStream;
    loop({
        s.sendMsg("/s_new", "pdef_grainlet", -1, 0, 0, \freq, x.next);
        0.05.wait;
    })
})
)

// 节拍器
Tdef(\y, { loop({ s.sendMsg("/s_new", "pdef_grainlet", -1, 0, 0, \freq, 1500); 1.wait }) }).play;

// 播放一次结束流
(
Tdef(\x, {
    var x, dt;
    dt = [0.1, 0.125, 0.05].choose;
    x = Plazy({ Pseries(1300 + 300.rand, 110 + 130.rand, 16) }).asStream;
    x.do({ |item|
        s.sendMsg("/s_new", "pdef_grainlet", -1, 0, 0, \freq, item);
        dt.wait;
    })
})
)

// ... and so on ...

Tdef(\x).stop;
Tdef.removeAll;

嵌入并分叉：在其他 Task / Routine 中的 Tdef

// embed 在 task 中按顺序播放 tdefs。
(
Tdef(\a, { "one".postln; 1.wait; "two".postln });
Tdef(\c, { var z; z = Synth(\default); 0.5.wait; z.release });
r = Task({
    "counting...".postln;
    2.wait;
    Tdef(\a).embed;
    1.wait;
    Tdef(\c).embed;
    "done.".postln;
});
)

r.play; // 播放流

Tdef(\c, { var z; z = Synth(\default, [\freq, 300]); 1.5.wait; z.release }); // 更改定义

r.reset;
r.play;

// 当然，Tdef 可以在其他 Tdef 中使用：
(
Tdef(\a, { 10.do { |i| (" a: " + i).postln; 0.3.wait } });
Tdef(\b, { 15.do { |i| ("\t\t b: " + i).postln; 0.2.wait } });
Tdef(\c, { 5.do { |i| ("\t\t\t\t c: " + i).postln; 0.5.wait } });

Tdef(\d, {
    "embed - sequence.".postln;
    1.wait;
    Tdef(\a).embed;
    1.wait;
    Tdef(\b).embed;
    1.wait;
    Tdef(\c).embed;

    "done.".postln;
});
)
Tdef(\d).play;

// 要在其独立的线程中启动 tdef，从而分支到并行线程，
// 可以使用 .fork 或 .playOnce
(
Tdef(\a, { 10.do { |i| (" a: " + i).postln; 0.3.wait } });
Tdef(\b, { 15.do { |i| ("\t\t b: " + i).postln; 0.2.wait } });
Tdef(\c, { 5.do { |i| ("\t\t\t\t c: " + i).postln; 0.5.wait } });

Tdef(\d, {
    "fork - parallel.".postln;
    1.wait;
    Tdef(\a).fork;
    1.wait;
    Tdef(\b).fork;
    1.wait;
    Tdef(\c).fork;

    "done.".postln;
});
)

作为时间模式的 Tdef

与其使用 Pdefn 表示时间值，使用 Tdef 可能会很有用。当改变其源时，它会使值的流与其时钟保持同步。

(
// 加载 synthdef
s.boot;
SynthDef("pdef_grainlet",
    { |out = 0, freq = 440, sustain = 0.05|
        var env;
        env = EnvGen.kr(Env.perc(0.01, sustain, 0.3), doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env))
    }).add;
)



Tdef(\z, Pseq([1, 1, 1, 0.5, 0.5], inf));

(
Pset(\instrument, \pdef_grainlet,
    Ppar([
        Pbind(
            \dur, Tdef(\z),
            \note, Pseq([1, 3, 2, 1, 0], inf),
            \x, Pfunc { TempoClock.default.elapsedBeats.postln } // 输出起始时间
        ),
        Pbind(
            \dur, 4, // 参考节拍
            \sustain, 0.1,
            \note, 8
        )
    ])
).play(quant: 1);
)


Tdef(\z, Prand([1, 1, 0.23, 0.5, 0.5], inf)); // 交换时间模式
Tdef(\z, Pseq([1, 1, 1, 1], inf)); // 模式保持同步。
Tdef(\z, Pseq([1, 1, 1, 0.5, 0.5], inf)); // 但顺序可能不同。
                    // 为避免这种情况，将 quant 设置为适当的值。
