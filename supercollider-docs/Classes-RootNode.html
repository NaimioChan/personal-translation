RootNode

服务器上的持久根组

Group : AbstractGroup : Node : Object

另请参见：Group、Default Group

说明

RootNode 是 nodeID 为 0 的组，它始终存在于每个服务器上，并表示该服务器节点树的根。

它始终在播放，始终在运行，无法被释放，也无法移动到任何地方。

使用缓存，以便每个 Server 始终只有一个 RootNode。

s = Server.local;

a = RootNode(s);
b = RootNode(s);

a === b; // 相同的对象

向服务器发送 "/s_new" 消息时，目标 0 就是此对象所表示的内容。

s.sendMsg("/s_new", "default", -1, 0, 0); // 最后一个参数是目标 id

重要提示：一般而言，除非有特定理由，否则不应将节点添加到 RootNode。相反，应将节点添加到 default_group。这提供了已知的基本节点顺序，并保护了 Server.record、Server.scope 等功能。default group 是所有新节点的默认目标，因此在使用对象风格时，除非明确指定，否则节点通常不会被添加到 RootNode。有关更多信息，请参见默认组。
