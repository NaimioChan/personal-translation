RangeSlider

一个由可滑动可扩展手柄组成的视图

说明

一种视图，允许设置两个介于 0 和 1 之间的数值，由可移动且可延伸的柄的两端表示。它可以具有水平或垂直方向，即柄移动和延伸的方向。

在范围的任一端拖动鼠标指针会单独移动该端。在范围中间拖动会移动整个范围而不改变其大小。

类方法

.new

创建新的 RangeSlider 时，其 -orientation 由初始尺寸决定：如果宽度大于高度，则方向为水平，否则为垂直。

实例方法

Data

.lo

范围的下限。

如果你尝试将其设置得高于当前的 -hi，则会改为设置 -hi，并且 -lo 将变为原来的 -hi。

设置 -lo 时，该值将始终被裁剪到 0 到 1 之间的范围。

参数：

一个 0 到 1 之间的浮点数。

.hi

范围的高端。如果你试图将其设置得低于当前 -lo，则会改为设置 -lo，而 -hi 将变为旧的 -lo。

设置 -hi 时，该值将始终被裁剪到 0 到 1 之间的范围。

参数：

一个 0 到 1 之间的浮点数。

.activeLo

将 -lo 设置为该参数并触发 -action。

.activeHi

将 -hi 设置为该参数并触发 -action。

.range

-hi 与 -lo 之间的差值。设置 -range 会将 -hi 设为 -lo + -range。

.activeRange

将 -range 设为该参数并触发 -action。

.setSpan

分别将 -lo 和 -hi 设为各参数。

.setSpanActive

调用 -setSpan，转发参数，并触发 -action。

.setDeviation

根据 -lo 和 -hi 的偏差和平均值（而非绝对值）来设置它们。

参数：

deviation

一个 Float，确定 -lo 和 -hi 相对于其平均值的绝对偏差。

average

一个 Float，决定 -lo 与 -hi 的平均值。

.increment

将 -lo 和 -hi 都增加 -step 乘以 'factor' 的值。

参数：

factor

一个 Float。

.decrement

将 -lo 和 -hi 都减少 -step 乘以 'factor' 的值。

参数：

factor

一个 Float。

Appearance

.orientation

RangeSlider 的方向——手柄移动和可延伸的方向。默认值取决于创建时视图的大小。

参数：

两个 Symbol 之一：\horizontal 或 \vertical。

.knobColor

手柄的颜色。

参数：

一个 Color。

Interaction

.step

调用 -increment 或 -decrement 时，或按下相关按键时，范围将变化的量。

参数：

一个 Float。

.pixelStep

如果手柄移动一个像素，范围将改变的绝对量。

返回值：

一个 Float。

.shift_scale

在按住 Shift 键的同时通过键盘递增或递减范围时，-step 所乘以的因子。

参数：

一个 Float。

.ctrl_scale

在按住 Ctrl 键的同时通过键盘递增或递减范围时，-step 所乘以的因子。

参数：

一个 Float。

.alt_scale

按住 Alt 键时用键盘递增或递减范围时，-step 所乘以的因子。

参数：

一个 Float。

Actions

.action

当用户更改手柄的位置或大小时求值的动作对象。

.defaultKeyDownAction

实现按键的默认效果如下：

Key

Effect

a

lo_(0)、hi_(1)，并触发动作

n

lo_(0)、hi_(0)，并触发动作

x

lo_(1)、hi_(1)，并触发动作

c

lo_(0.5)、hi_(0.5)，并触发操作

上箭头

increment

向下箭头

decrement

右箭头

increment

向左箭头

decrement

拖放

.defaultGetDrag

返回值：

一个 Point，其 x 和 y 坐标分别设置为 -lo 和 -hi。

.defaultCanReceiveDrag

返回值：

如果当前拖拽数据是 Point，则为 true。

.defaultReceiveDrag

分别将 -lo 和 -hi 设置为作为当前拖拽数据存储的 Point 的两个坐标，并触发 -action。

示例

基础示例

(
w = Window.new.front;
a = RangeSlider(w, Rect(20, 80, 120, 30))
    .lo_(0.2)
    .range_(0.4)
    .action_({ |slider|
        [\sliderLOW, slider.lo, \sliderHI, slider.hi].postln;
    });
)
(
w = Window.new.front;
a = RangeSlider(w, Rect(20, 80, 120, 30))
    .lo_(0.2)
    .hi_(0.8)
    .action_({ |slider|
        b.activeLo_(slider.lo); // 这将触发 b 的动作（并设置其值）
        b.hi_(slider.hi);
    });
b = RangeSlider(w, Rect(220, 80, 20, 130))
    .lo_(0.2)
    .hi_(0.8)
    .knobColor_(HiliteGradient(Color.grey, Color.white, \h))
    .action_({ |slider|
        [\sliderLOW, slider.lo, \sliderHI, slider.hi].postln;
    });
)

setDeviation 的用法

(
w = Window("setDeviation", Rect(300, 300, 300, 150));
a = RangeSlider(w, Rect(10, 10, 200, 30))
    .lo_(0)
    .hi_(1);
b = Slider(w, Rect(10, 50, 200, 30))
    .action_(
        { |me|
            a.setDeviation(c.value, b.value);
        });
c = Slider(w, Rect(10, 100, 200, 30))
    .action_(
        { |me|
            a.setDeviation(c.value, b.value);
        }
    );
c.valueAction = 0.2;
w.front;
)

声音示例

塑造带通滤波器。

在 Cocoa GUI 中，按住 Ctrl 键可移动整个范围；在其他 GUI 工具包中，只需在范围内单击并拖动它即可。

(
s.waitForBoot({
    a = { |freq = 1800, bw = 0.2|
        var r;
        BBandPass.ar(WhiteNoise.ar(0.3), freq, bw);
    }.play;

    w = Window("2DSlider", Rect(100, Window.screenBounds.height-400, 400, 50));
    t = RangeSlider(w, Rect(10, 10, 380, 30))
            .lo_(0.4)
            .hi_(0.6)
            .action_({ |sl|
                a.set(\freq, 1800*(sl.lo+sl.lo)+10, \bw, (sl.hi-sl.lo).abs+0.01);
            });
    t.doAction;

    w.front;
    CmdPeriod.doOnce({ w.close });
})
)
