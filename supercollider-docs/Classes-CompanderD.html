CompanderD

压缩器、扩展器、限制器、门、闪避器。

UGen : AbstractFunction : Object

另请参阅：Amplitude、Compander、Normalizer、Limiter

说明

CompanderD 将信号直接传递到控制输入，但会为处理输入增加一个延迟，以便增益钳制的滞后不会滞后于输入声音的起音。

类方法

CompanderD.ar(in: 0.0, thresh: 0.5, slopeBelow: 1.0, slopeAbove: 1.0, clampTime: 0.01, relaxTime: 0.01, mul: 1.0, add: 0.0)

参数：

in

要压缩 / 扩展 / 门控的信号。

thresh

控制信号幅度阈值，用于确定 slopeBelow 与 slopeAbove 之间的分界点。通常为 0..1。控制信号幅度使用 RMS 计算。

slopeBelow

阈值以下振幅曲线的斜率。如果此斜率 > 1.0，则控制信号越弱，振幅下降得越快；当控制信号接近 0 振幅时，输出应恰好为零——因此形成噪声门控。小于 1.0 的值也是可能的，但这意味着极低电平的控制信号会导致输入信号被放大，从而抬高噪声底。

slopeAbove

同样，但位于阈值之上。小于 1.0 的值实现压缩（较响的信号被衰减）；大于 1.0 则得到扩展（较响的信号变得更响）。对于 3:1 压缩，此处应使用 1/3 的值。

clampTime

振幅调整完全生效所需的时间。这通常相当小，不会超过 10 毫秒太多（默认值）。我经常把它设得低至 2 毫秒（0.002）。

relaxTime

振幅调整释放所需的时间。通常比 clampTime 稍长；如果两个时间都太短，可能会产生一些（可能是不想要的）伪影。

mul

输出将乘以该值。

add

此值将被添加到输出中。
