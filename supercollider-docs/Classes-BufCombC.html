BufCombC

基于缓冲区的梳状延迟线，带三次插值。

BufCombN : UGen : AbstractFunction : Object

另请参阅：BufCombL、BufCombN、CombC

说明

使用三次插值并使用缓冲区作为其内部存储器的梳状延迟线。另请参阅不使用插值的 BufCombN，以及使用线性插值的 BufCombL。三次插值比线性插值计算开销更大，但更精确。

类方法

BufCombC.ar(buf: 0, in: 0.0, delaytime: 0.2, decaytime: 1.0, mul: 1.0, add: 0.0)

来自父类：BufCombN

参数：

buf

缓冲区编号。

in

输入信号。

delaytime

延迟时间，单位为秒。

decaytime

回声衰减 60 分贝所需的时间。如果此时间为负，则反馈系数将为负，从而只强调低一个八度的奇次谐波。

讨论：

警告： 出于效率原因，有效缓冲区大小被限制为不超过其的前一个 2 的幂。因此，如果分配了 44100 个采样，最大延迟将是 32768 个采样。

实例方法

示例

// 这些例子对比各变体，以便你能听出插值的差异

// 分配缓冲区
b = Buffer.alloc(s, 44100, 1);

// Comb 用作谐振器。共振基频等于
// 延迟时间的倒数。
{ BufCombN.ar(b.bufnum, WhiteNoise.ar(0.01), XLine.kr(0.0001, 0.01, 20), 0.2) }.play;

{ BufCombL.ar(b.bufnum, WhiteNoise.ar(0.01), XLine.kr(0.0001, 0.01, 20), 0.2) }.play;

{ BufCombC.ar(b.bufnum, WhiteNoise.ar(0.01), XLine.kr(0.0001, 0.01, 20), 0.2) }.play;

// 使用负反馈：
{ BufCombN.ar(b.bufnum, WhiteNoise.ar(0.01), XLine.kr(0.0001, 0.01, 20), -0.2) }.play;

{ BufCombL.ar(b.bufnum, WhiteNoise.ar(0.01), XLine.kr(0.0001, 0.01, 20), -0.2) }.play;

{ BufCombC.ar(b.bufnum, WhiteNoise.ar(0.01), XLine.kr(0.0001, 0.01, 20), -0.2) }.play;

// 用作回声。
{ BufCombC.ar(b.bufnum, Decay.ar(Dust.ar(1, 0.5), 0.2, WhiteNoise.ar), 0.2, 3) }.play;
