PV_MagAbove

通过高于阈值的频段。

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

另请参见：FFT、IFFT、PV_LocalMax、PV_MagBelow、PV_MagClip

子类：PV_LocalMax、PV_MagBelow、PV_MagClip

说明

仅通过幅度高于阈值的频段。

类方法

PV_MagAbove.new(buffer, threshold: 0.0)

参数：

buffer

FFT 缓冲区。

threshold

幅度阈值。

实例方法

示例

s.boot;
b = Buffer.read(s, ExampleFiles.child);


(
SynthDef("help-magAbove", { |out = 0|
    var in, chain;
    in = SinOsc.ar(SinOsc.kr(SinOsc.kr(0.08, 0, 6, 6.2).squared, 0, 100, 800));
    // in = WhiteNoise.ar(0.2);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_MagAbove(chain, 310);
    Out.ar(out, 0.1 * IFFT(chain).dup);
}).play(s);
)

(
SynthDef("help-magAbove2", { |out = 0|
    var in, chain;
    in = WhiteNoise.ar(0.2);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_MagAbove(chain, MouseX.kr(0, 10));
    Out.ar(out, 0.1 * IFFT(chain).dup);
}).play(s);
)

(
SynthDef("help-magAbove3", { |out = 0, soundBufnum = 2|
    var in, chain;
    in = PlayBuf.ar(1, soundBufnum, BufRateScale.kr(soundBufnum), loop: 1);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_MagAbove(chain, MouseX.kr(0, 310));
    Out.ar(out, 0.1 * IFFT(chain).dup);
}).play(s, [\soundBufnum, b]);
)
