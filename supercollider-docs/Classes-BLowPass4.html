BLowPass4

24db/oct 滚降 - 四阶谐振低通滤波器 [1]

Object

另请参阅：SOS、BLowPass、BHiPass、BHiPass4、BPeakEQ、BLowShelf、BHiShelf、BBandPass、BBandStop、BAllPass

说明

B 均衡套件基于二阶节（SOS）双二阶 UGen。

注意： Biquad 系数计算会带来一定的 CPU 开销。这些插件 UGen 包含优化，使得只有当滤波器参数之一发生变化时才会更新系数。这可能导致 CPU 性能出现尖峰，在使用多个此类单元时应加以考虑。

[1] 这是一个复合伪 UGen。BLowPass4 由 2 个 SOS 节级联而成。

类方法

BLowPass4.ar(in, freq: 1200.0, rq: 1.0, mul: 1.0, add: 0.0)

参数：

in

待处理的输入信号。

freq

截止频率。警告：由于其实现方式的特性，接近 0 的频率值可能导致故障和/或极其响亮的音频伪影！

rq

Q 的倒数。bandwidth / cutoffFreq。

mul

add

实例方法

示例

s.boot;
(
z = {
    BLowPass4.ar(
        SoundIn.ar([0, 1]),
        MouseX.kr(10, 20000, \exponential), // 截止频率。
        MouseY.kr(0.1, 1.0, \linear), // rq - 补偿 2 个双二阶节。
        0.5); // mul
}.play)
z.release;
