Pcollect

对模式应用一个函数

FuncFilterPattern : FilterPattern : Pattern : AbstractFunction : Object

另请参阅：Pselect、Preject

说明

通过将每个值传给函数来修改它。这是模式库中相当于 Collection: -collect 的用法。

类方法

Pcollect.new(func, pattern)

来自父类：FuncFilterPattern

参数：

func

一个 Function。从 pattern 接收值。

pattern

一个 Pattern。

实例方法

未文档化的实例方法

.asStream

.embedInStream(inval)

示例

(
a = Pcollect({ |item| item * 3 }, Pseq(#[1, 2, 3], inf));
x = a.asStream;
9.do({ x.next.postln });
)

当传递给模式时，消息 collect 返回一个 Pcollect。请注意，由于模式被转换为 Stream（更确切地说，是 FuncStream），因此每次传递消息 next 时，collect 函数都会针对一个项进行求值。

(
a = Pseq(#[1, 2, 3], inf).collect({ |item| item * 3 });
a.postln;

x = a.asStream;
9.do({ x.next.postln });
)
