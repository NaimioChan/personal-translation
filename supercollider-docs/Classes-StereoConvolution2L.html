StereoConvolution2L

带线性插值的立体声实时卷积器

MultiOutUGen : UGen : AbstractFunction : Object

参见：Convolution、Convolution2L

说明

使用固定核的严格卷积，可通过触发信号更新核。缓冲区更改时会在其间进行线性交叉淡化。

与 Convolution2L 类似，但与两个缓冲区进行卷积并输出立体声信号。与使用两个 Convolution2L 副本相比，这每周期可节省一次 FFT 变换。

有用的应用可能包括立体声混响或 HRTF 卷积。

参见 Steven W Smith，The Scientist and Engineer's Guide to Digital Signal Processing，第 18 章：http://www.dspguide.com/ch18.htm

类方法

StereoConvolution2L.ar(in, kernelL, kernelR, trigger: 0, framesize: 2048, crossfade: 1, mul: 1.0, add: 0.0)

参数：

in

处理目标。

kernelL

左声道固定内核的缓冲区索引，可与触发信号组合进行调制。

kernelR

右声道固定内核的缓冲区索引，可与触发结合进行调制。

trigger

当值从 <= 0 变为 > 0 时更新内核。

framesize

FFT 帧的大小，必须是 2 的幂（512、1024、2048、4096 是常用选择）。卷积在内部使用该数值的两倍。请注意，随着幂次提高，卷积的运行开销会逐渐增大！可用的最大值为 2^16 = 16384。（此上限是 SC 源代码中定义的 "SC_FFT_MAXSIZE" 的一半。）比这更大的卷积可以使用 PartConv 完成。

crossfade

进行交叉淡化的周期数。默认值为 1。必须为整数。

mul

add

实例方法

示例

(
// 分配三个缓冲区
b = Buffer.alloc(s, 2048);
c = Buffer.alloc(s, 2048);
d = Buffer.alloc(s, 2048);

b.zero;
c.zero;
d.zero;
)

(
50.do({ |it| c.set(20 * it + 10, 1.0.rand) });
3.do({ |it| b.set(400 * it + 100, 1) });
20.do({ |it| d.set(40 * it + 20, 1) });
)


(
SynthDef(\conv_test, { |out, kernel1, kernel2, t_trig = 0|
    var input, result, framesize;
    framesize = 2048; // 必须是 2 的幂
    input = Impulse.ar(1);
    result = StereoConvolution2L.ar(input, kernel1, kernel2, t_trig, framesize, 1, 0.5);
    Out.ar(out, result);
}).add
)


x = Synth(\conv_test, [\kernel1, b, \kernel2, c]);

// 更改缓冲区编号：
x.set(\kernel1, d);
x.set(\t_trig, 1); // 在此触发之后，更改将生效。
x.set(\kernel2, d);
x.set(\t_trig, 1); // 在此触发之后，更改将生效。

d.zero;
40.do({ |it| d.set(20 * it + 10, 1) }); // 改变缓冲区的内容
x.set(\t_trig, 1); // 在此触发之后，更改将生效。

x.set(\kernel1, b);
x.set(\t_trig, 1); // 在此触发之后，更改将生效。

x.free;
