Maybe

引用透明的代理对象

Ref : AbstractFunction : Object

另请参阅：Fdef、JITLib

子类：Fdef

说明

Maybe 对象可以包含 nil 或某个其他对象，并允许在尚不知道这个其他对象的情况下构建计算。如果计算失败——由于循环或尚未定义的对象——Maybe 返回 nil。

Maybe 这个名称源自编程语言 Haskell，在那里它表示一种类似的实体。另请参阅：Fdef

注意： Maybe 对象会以对象的形式惰性构造操作，而不是立即执行该操作。以当前形式，其实现必然仍不完整：它仅限于 AbstractFunction 实现的算术运算以及以下集合方法：put, addAll, add, putAll, atAll。你可以根据自己的需要，按照以下模式来扩展 Maybe：// 将 "myMethod" 替换为你的方法名 + Maybe { myMethod { |...args, kwargs| ^this.composeNAryOp(\myMethod, args, kwargs) } }

类方法

Maybe.new(thing)

来自父类：Ref

创建一个新实例

参数：

thing

一个对象或 nil。

a = Maybe.new;
b = Maybe(a + 6);
b.value; // => nil
a.value = 1;
b.value; // => 7

实例方法

.source

.source = obj

返回或设置所包含的对象

a = Maybe.new;
a.source = 5;
a.source // 5

.value

.value = value

设置所包含的对象，或返回源，或返回所包含对象的值（如果它是 Maybe）。如果存在递归，则返回 nil。

a = Maybe.new;
a.source = 5;
a.value; // 5
a.source = { [1, 2, 3].rotate };
a.value; // [3, 2, 1]
a.source = a; // 故意制造递归
a.value; // nil
Maybe.verbose = true;
a.value; // 发出警告并返回 nil

.apply( ... args, ... kwargs)

返回该值，或者如果它是 Maybe，则返回所包含对象的值。该方法允许递归，从而可以进行递归计算。

a = Maybe({ |a, b| a + b });
[1, 2, 3, 4].reduce(a); // 返回 10。reduce 调用应用于第一个参数并传入接收者

.clear

将源设置为 nil

.doesNotUnderstand(selector ... args, ... kwargs)

（由任何 Maybe 不理解的消息调用。）

返回一个组合函数，在评估时返回该值。

a = Maybe.new;
a.respondsTo(\flop) // false: 也许构造一个占位符代替
b = Maybe(a.flop);
b.value; // => nil
a.value = [1, 2, [2, 3]];
b.value;    // => [[1, 2, 2], [1, 2, 3]]

<>(that)

将接收者与第一个参数组合。

a = Maybe({ |x| x + 1 });
b = Maybe();
c = a <> b;
c.value(1); // nil，尚未指定
b.source = { |x| x * 2 };
c.value(1);  // 1 * 2 + 1 = 3

.o( ... args)

将接收者与所有参数组合在一起

a = Array.fill(8, { |i| var k = (1/(i+1)).rand; Maybe({ |x| x * k }) });
b = o(Maybe({ |x| x }), *a);
b.value(1);
