NumChannels

确保输出通道的数量

Object

说明

确保输出具有所声明的声道数，无论输入声道数是多少。

类方法

NumChannels.ar(input, numChannels: 2, mixdown: true)

参数：

input

音频信号

numChannels

一个整数

mixdown

true/false，表示是要混音还是仅使用第一个通道

讨论：

单声道输入被复制。多声道被合并，如果 mixdown 为 true 则混合为单声道，否则使用第一个声道。

实例方法

示例

(
{
    NumChannels.ar(
        SinOsc.ar(100, 0, 0.2), // 1 变为 2
        2)
}.play
)

(
{
    NumChannels.ar(
        SinOsc.ar([100, 200, 300], 0, 0.2), // 3 变为 2
        2)
}.play
)

(
{
    NumChannels.ar(
        SinOsc.ar([100, 200, 300, 100], 0, 0.2), // 4 变为 2

        2)
}.play
)
