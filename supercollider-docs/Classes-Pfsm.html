Pfsm

有限状态机

ListPattern : Pattern : AbstractFunction : Object

另请参阅：Pdfsm

说明

每个状态由一个项和一个整数数组组成，该数组包含可能的下一个状态的索引。初始状态从入口状态数组中随机选取。返回所选状态的项，然后从其可能的下一个状态数组中选取下一个状态。当选中结束状态时，流结束。

示例

list:

[

[ 条目状态 ]，
项，[ 下一状态 ]，
项，[ 下一状态 ]，
...
结束项（或 nil），nil
]

后续状态：nil 为终止状态
