14. 调度事件

SuperCollider 入门

另请参阅：00. Getting Started With SC

音乐是随时间发生的，要制作有效的音乐，就必须控制事情发生的时机。在 SuperCollider 中，这是通过时钟上调度来实现的。

Clocks

SuperCollider 中的时钟有两个主要功能。它知道当前的时间，也知道事情应该在什么时间发生，以便它能够在恰当的时间唤醒它们。

音乐序列通常使用 TempoClock，因为你可以改变它的速度，而且它还能感知拍号变化。还存在另外两种时钟：SystemClock，始终以秒为单位运行；以及 AppClock，同样以秒为单位运行，但系统优先级较低（因此更适合图形更新以及其他非时间关键的活动）。

Scheduling

调度意味着告诉时钟在未来某个时间执行某件事。因此，你需要有待调度的事物，以及一个表示时间的数字。

让 SuperCollider 在 5 秒后说你好。

SystemClock.sched(5, { "hello".postln });

请注意，当你这样做时，'SystemClock' 会立即打印。每次在 SuperCollider 中运行某些内容时，它都必须立即返回一个值；该方法的返回值就是时钟。然而，在返回之前，时钟会“记住”该函数，以及你希望它在 5 秒后运行。果然，'hello' 准时出现在 post 窗口中。{ "hello".postln } 是一个异步操作：它在代码块已经返回之后才运行。

sched 执行相对调度。函数实际运行的时间比 .sched 调用发生的时间晚 x 秒（对于 TempoClock 则为拍）。如果你知道时钟上的当前时间，也可以调度到精确的时间点。schedAbs 处理绝对调度。

(
var timeNow = TempoClock.default.beats;
"Time is now: ".post; timeNow.postln;
"Scheduling for: ".post; (timeNow + 5).postln;
TempoClock.default.schedAbs(timeNow + 5,
    { "Time is later: ".post; thisThread.clock.beats.postln; nil });
)

请注意，我们已经改用 TempoClock，因为它是最常用的。虽然只有一个 SystemClock，但按需可以有许多以不同速度运行的 TempoClock。有一个 TempoClock 是默认的，通过 TempoClock.default 访问——我们将始终使用它。（为省去输入，你可能希望将一个 TempoClock 赋值给变量，例如 t = TempoClock.default。）

为了好玩，改变速度并再次运行最后一个示例：

(
var timeNow;
TempoClock.default.tempo = 2;    // 每秒 2 拍，即 120 BPM
timeNow = TempoClock.default.beats;
"Time is now: ".post; timeNow.postln;
"Scheduling for: ".post; (timeNow + 5).postln;
TempoClock.default.schedAbs(timeNow + 5,
    { "Time is later: ".post; thisThread.clock.beats.postln; nil });
)

注意，“Time is later” 消息在较短的延迟后出现，但两个时间之间的差值仍然是 5。

现在几点了？

在已调度的函数内部，你可能想知道是哪个时钟在运行该函数。thisThread.clock 会告诉你这一点——现在不必担心它是如何知道的，只需知道你可以用它来查明即可。

一旦你知道了时钟，就可以使用 beats 来找出当前时间：

SystemClock.beats;
TempoClock.default.beats;
AppClock.beats;
thisThread.clock.beats;

你可以调度什么？

假设我们单独调度 "hello"。

TempoClock.default.sched(5, "hello");

什么也不会发生。这是因为 "hello" 只是一个值——它不会做任何事。这个教训在于：调度那些会执行某些动作的对象才是有意义的。

Caution

如果调度一个返回数字的函数，时钟会将该数字视为再次运行该函数之前的时间量。

// 触发很多次（但看起来应该只触发一次）
TempoClock.default.sched(1, { rrand(1, 3).postln; });

这将永远持续下去，直到你用 cmd-. 停止它。

如果你希望该函数只运行一次，请确保在函数末尾加上 'nil'：

// 触发一次
TempoClock.default.sched(1, { rrand(1, 3).postln; nil });

很容易误返回一个数字，从而在本想要一次性操作时得到一个持续的活动。

如果该数字恰好为 0 或负数，情况会更糟。函数将立即再次运行。而且，如果该数字始终为 0，就会产生一个无限循环，可能使 SuperCollider 卡死。

这不应让你对调度望而却步——在使用更频繁的 Routine 和 Task 中，这种情况不太会发生。但你应该对此有所了解。
