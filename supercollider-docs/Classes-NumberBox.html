NumberBox

显示可修改数值的视图。

说明

一种显示数值的视图，允许通过键入数值来修改它，并使用键盘或鼠标对其进行递增或递减。

使用键盘时，每按一次方向键，值将按 -step 定义的数量改变。

鼠标滚动通过在视图内按下鼠标按钮并垂直拖动鼠标来执行。值将根据鼠标光标的移动而变化，步长由 -scroll_step 定义。

默认情况下，在递增或递减值时按住 Shift、Ctrl 或 Alt 键，会分别将步长乘以 100、10 或 0.1，不过你可以通过设置 -shift_scale、-ctrl_scale 或 -alt_scale 来自定义。可以通过修改 -scroll 变量来启用或禁用滚动。

类方法

实例方法

Data

.value

0 到 1 之间的数值。

参数：

一个 Float。

.valueAction

将 -value 设为该参数并触发 -action。

.increment

将值增加 -step 乘以 'factor'。

参数：

factor

任意数字。

.decrement

将值减少 -step 乘以 'factor'。

参数：

factor

任意数字。

.string

要代替数值显示的文本。在此之后设置 -value 将再次显示该值。

参数：

一个 String。

.object

如果 -setBoth 为 true，则设置此变量时也会将 -string 设置为该参数 as String 解释后的值。

参数：

任意对象，通常是以字符串形式显示时有意义的对象，例如 Float。

.setBoth

一个变量，表示设置 -object 时是否也会设置 -string。

参数：

一个布尔值。

数据限制

.clipLo

允许的最低数值。尝试设置更低的值会将其裁剪到此值。

参数：

一个 Float。

.clipHi

允许的最高数值。尝试设置更高的值会将其裁剪到此值。

参数：

一个 Float。

.minDecimals

显示的最少小数位数。如果该值用更少的小数位即可完全描述，则会追加零直至达到此位数。

参数：

一个 Integer。

.maxDecimals

显示的最大小数位数。该值将始终舍入到此小数位数。

参数：

一个 Integer。

.decimals

将 -minDecimals 和 -maxDecimals 都设置为该参数。

参数：

一个 Integer。

Appearance

.align

所显示值的对齐方式。可能的值参见 Alignment。

.stringColor

在用户交互首次更改数值之前用于显示该值的颜色。

参数：

一个 Color。

.normalColor

用于显示输入完成后的值的颜色。

参数：

一个 Color。

.typingColor

用于显示正在输入时的值的颜色。

参数：

一个 Color。

Interaction

.step

当调用 -increment 或 -decrement 时，或按下相关键时，值将改变的量。

参数：

一个 Float。

.scroll_step

使用鼠标滚动时值将改变的量。

参数：

一个 Float。

.shift_scale

当按住 Shift 键并使用键盘或鼠标递增或递减值时，-step 或 -scroll_step 所乘的因子。

参数：

一个 Float。

.ctrl_scale

当按住 Ctrl 键并使用键盘或鼠标递增或递减值时，-step 或 -scroll_step 所乘的因子。

参数：

一个 Float。

.alt_scale

在使用键盘或鼠标递增或递减值时，按住 Alt 键时 -step 或 -scroll_step 所乘以的因子。

参数：

一个 Float。

Actions

.action

当用户通过与视图交互而改变值时，所求值的动作对象。

.defaultKeyDownAction

任何代表可作为浮点数表示一部分的字符的按键都将启动该值的编辑。按 Return（或 Enter）将结束编辑并将键入的值存储为 Float。

示例

基本示例

(
    w = Window("NumberBox Example", Rect(100, 500, 400, 120));
    b =     NumberBox(w, Rect(150, 10, 100, 20));
    b.value = rrand(1, 15);
    b.action = { |numb| numb.value.postln };
    w.front
)
// 每次尝试一个
b.value = rrand(1, 15) ;     // 设置值但不执行动作
b.valueAction_(5);      // 设置该值并执行动作
b.step_(0.1);           // 更改方向键的增量/减量大小
b.scroll_step = 10;    // 更改 mosueScrolling 的增量/减量大小

b.background_(Color.grey);          // 更改框的背景色
b.typingColor_(Color(0.3, 1, 0.3));   // 更改框的输入颜色
b.normalColor_(Color.white);        // 更改盒子的正常颜色。直到下一次值变化才会改变

b.stringColor = Color.red;
b.align = \center;

b.increment; // 按步长递增或递减
b.decrement;

声音示例

使用方向键按步长更改正在播放的 synth 的频率：

(
s.waitForBoot({

    n = { |freq = 220|
        var out;
        out = SinOsc.ar(freq, 0, 0.2);
        8.do{ out = AllpassN.ar(out, 0.2, 0.02+0.20.rand, 8) };
        out;
    }.play;

    w = Window("Use arrow keys to change the frequency by steps", Rect(100, 500, 500, 120));
    b = NumberBox(w, Rect(200, 10, 100, 20));
    b.value = 220;
    b.action = { |numb| n.set(\freq, numb.value) };
    b.step = 55; // 让步长成为频率的一小部分
    b.focus;
    w.front;

    CmdPeriod.doOnce({ w.close });

});
)
