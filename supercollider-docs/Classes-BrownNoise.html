BrownNoise

布朗噪声。

WhiteNoise : UGen : AbstractFunction : Object

参见：ClipNoise、GrayNoise、PinkNoise、WhiteNoise

说明

生成功率谱按每倍频程 6 dB 衰减的噪声。

类方法

BrownNoise.ar(mul: 1.0, add: 0.0)

来自父类：WhiteNoise

BrownNoise.kr(mul: 1.0, add: 0.0)

来自父类：WhiteNoise

参数：

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

compare:

{ BrownNoise.ar(0.1) }.play;
{ WhiteNoise.ar(0.1) }.play;

作为频率调制器的布朗噪声：

{ SinOsc.ar(BrownNoise.ar(100, 200)) * 0.1 }.play;

滤波后的布朗噪声：

{ BPF.ar(BrownNoise.ar(0.1.dup), MouseX.kr(40, 17000, 1), 0.2) }.play;
