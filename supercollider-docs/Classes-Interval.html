Interval

整数范围

Collection : Object

说明

Interval 是一个从起始值到结束值、按某个步长取值的整数范围。

类方法

Interval.new(start, end, step: 1)

创建一个新的 Interval。

Interval(10, 30, 4);
10 to: 30; // 创建步长为 1 的区间的消息

实例方法

.start

.start = value

区间的起始值。

.end

.end = value

区间的结束值。

.step

.step = value

间隔的步长值。

.size

返回区间中的项数。

Interval(10, 30, 4).size.postln;

.at(index)

返回区间中索引对应的项。

Interval(10, 30, 4).at(3).postln;

.do(function)

对区间内的每一项求值函数。该函数接收两个参数：项和一个整数索引。

Interval(10, 30, 4).do({ |item, i| item.postln });
