Pstutter

重复输入流的值

FilterPattern : Pattern : AbstractFunction : Object

参见：Pdup、Pn、Pattern: -dup

注意： 建议改用 Pdup。保留此类是为了向后兼容。

警告： Pstutter 将返回 Pdup

说明

将每个元素重复 n 次。

(
var a, b;
a = Pstutter(2, Pwhite(-1.0, 1.0));
x = a.asStream;
8.do { x.next.postln };
)

这也是对 Pattern: -dup 的响应

类方法

Pstutter.new(n, pattern)

参数：

n

每个新元素的重复次数。n 可以是模式，因此每次迭代的次数可以变化。

pattern

要重复的模式。

返回值：

Pdup

实例方法

未文档化的实例方法

.n = value

示例

// 第一个参数也可以是模式：
(
var a, b;
a = Pstutter(Prand([1, 2, 5], inf), Pwhite(-1.0, 1.0)); // 重复一次、两次或五次
x = a.asStream;
20.do { x.next.postln };
)

// 使用事件模式：
(
SynthDef(\help_sinegrain,
    { |out = 0, freq = 440, sustain = 0.05|
        var env;
        env = Env.perc(0.01, sustain, 0.2).kr(doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0.5pi, env))
    }).add;
)

(
a = Pbind(
    \instrument, \help_sinegrain,
    \note, Pxrand([0, 5, 7, 9], inf),
    \dur, 0.05,
    \sustain, 0.1
);
Pstutter(Pseq([1, 2, 3, 4], inf), a).trace.play;
)


// Pstutter 用作音高序列

(
c = Pstutter(3, Pxrand([1, 2, 3], inf) * 4 + 65);
x = c.asStream;
Routine {
    loop {
        Synth(\help_sinegrain, [\freq, x.next.midicps]);
        0.12.wait;
    }
}.play;
)


// 粉红噪声的 Voss 算法
// 注意 pattern.stutter(n) 是 Pstutter(n, pattern) 的同义词
a = Pwhite();
c = (2 ** (0..10)).sum { |n| a.stutter(n) };
c.asStream.nextN(1000).plot


// Voss-McCartney 算法：实时使用的平衡计算
a = Pwhite();
c = (2 ** (0..10)).sum { |n| a.stutter(n.div(2).fin(1)) ++ a.stutter(n) };
c.asStream.nextN(1000).plot
