AbstractServerAction

为服务器注册要执行的操作

AbstractSystemAction : Object

另请参见：Server、ServerBoot、ServerTree、ServerQuit

子类：ServerBoot、ServerQuit、ServerTree

说明

这是一个抽象父类，用于像 ServerQuit 这样的单例，它提供了一个位置，用于注册函数和对象，以响应服务器中某些事件发生时应触发的动作。无需直接调用 AbstractServerAction。

注意： 在 Linux 和 Windows 上不能完全正常工作。在这些系统上将计算机设置为睡眠会导致动作被调用。截至目前在 Linux 上，JACK 无法在睡眠后继续存活，但它目前仍然表现正常。

类方法

AbstractServerAction.functionSelector

子类为将此法作为接口实现的对象返回特定的函数选择器。选择器为：

  • doOnServerBoot - ServerBoot
  • doOnServerQuit - ServerQuit
  • doOnServerTree - ServerTree

不是用于向服务器注册，但类似的是：

  • doOnCmdPeriod - CmdPeriod
  • doOnStartUp - StartUp
  • doOnShutDown - ShutDown

AbstractServerAction.add(object, server)

为注册表添加动作或对象。

参数：

object

可以是一个要被求值的 Function（服务器作为第一个参数传入），或者是一个 Object，它实现了由 -functionSelector 返回的消息。一个对象只注册一次，因此多次添加不会导致多次调用。

server

要注册到的服务器。如果传入符号 \default，则对当前默认服务器调用该动作。如果传入符号 \all，则对所有当前服务器调用该动作。如果 server 为 nil，则将其添加到 \all。

AbstractServerAction.remove(object, server)

从注册表中移除一个项或对象。如果 server 为 nil，则从 所有 键中移除。

AbstractServerAction.removeServer(server)

移除为给定服务器注册的所有项。

实例方法

示例

// 服务器启动
s.boot;
f = { |server| "------------The server '%' has booted.------------\n".postf(server) };
ServerBoot.add(f, \default);
s.quit; // 退出服务器并观察输出
s.boot;
ServerBoot.remove(f, \default); // 再次移除它
s.quit;
s.boot; // 无后置处理。
ServerBoot.add(f, Server.internal);
Server.internal.quit;
Server.internal.boot;
ServerBoot.removeAll; // 全部清除
// 服务器退出
s.boot;
f = { |server| "------------The server '%' has quit.------------\n".postf(server) };
ServerQuit.add(f, \default);
s.quit; // 退出服务器并观察输出
s.boot;
ServerQuit.remove(f, \default); // 再次移除它
s.quit; // 无后置处理。
ServerQuit.add(f, Server.internal);
Server.internal.boot;
Server.internal.quit;
ServerQuit.removeAll; // 全部清除
// 服务器树
s.quit;
f = { |server| "-------The server '%' has initialised tree.-------\n".postf(server) };
g = { |server| 10.do { Group(server).postln } };
ServerBoot.add(f, \default);
ServerTree.add(g, \default);
s.boot; // 启动服务器，并观察各个 action 按顺序求值
// "cmd-period"（或等效操作）会重新发送各组。

ServerBoot.removeAll; // 全部清除
ServerTree.removeAll; // 全部清除
