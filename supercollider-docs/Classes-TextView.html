TextView

显示可编辑格式化文本的视图

说明

TextView 由一个可输入和编辑多行文本的区域组成。

使用视图的方法，可以对文本进行格式化：不同的字体和文本颜色可以应用于文本的各个部分。文本还可以通过编程方式插入、移除和选择。

该视图可以打开文本文档，并从中加载纯文本以及HTML格式的文本，尽管它无法将文本保存回文件。不过，你可以使用 -string 方法获取视图的内容，然后自行实现保存功能，但无论视图内容采用何种格式，-string 方法都只会返回纯文本。

类方法

实例方法

文本与格式

.open

打开 path 处的文件并从中加载文本。

文件可以是纯文本或 HTML（在 Cocoa GUI 中也可以是 RTF）格式。但请注意，不支持在视图中保存格式化文本。

如果从文件加载文本成功，它将替换视图中的任何当前内容。

参数：

path

一个 String。

.string

视图显示的完整内容，以纯文本表示。

设置此变量将替换视图的任何当前内容。

参数：

一个 String。

.setString

在 start 位置插入 string，替换后面 size 个字符。如果 size 为 0，则插入文本而不删除任何字符。

参数：

string

一个 String —— 要插入的文本。

start

文本中的整数位置，以字符为单位。

size

要替换的字符的整数数量。

.currentLine

文本光标所在行的纯文本。

Formatting

TextView 支持文本字体和颜色，并可以对 sclang 代码进行语法着色。

注意： 当字符串改变时格式会被重置。

(
var text = "Tous ces nombres paraissent bien concrets";
t = TextView(bounds: Rect(300, 400));
t.string = text;
t.front;
fork {
    loop {
        2.0.rand.wait;
        defer {
            t.setFont(Font("Times", rrand(12, 48)), rand(text.size - 1), rrand(3, 17));
            t.setStringColor(Color.rand, rand(text.size - 1), rrand(3, 17));

        }
    }
};
)

.setFont

将 font 应用到 start 位置之后的 size 个字符。

参数：

font

应用于所需文本范围的 Font。

start

文本中的整数位置，以字符为单位。

size

一个整数数量的字符。

.setStringColor

将 color 应用到 start 位置之后的 size 个字符。

参数：

color

要应用到目标文本范围的 Color。

start

文本中的整数位置，以字符为单位。

size

一个整数数量的字符。

.syntaxColorize

根据 SuperCollider 语言语法高亮方案，为视图的全部内容中的文本应用颜色。

(
t = TextView(bounds: Rect(300, 400));
t.string = this.cmdLine;
t.syntaxColorize;
t.front;
)

文本选择

.selectedString

当前选区中包含的纯文本。

获取此变量时，若没有选区，则返回文本光标所在的整行（等价于 -currentLine）。

设置此变量将用参数替换选区中的文本，如果没有选区则不做任何操作。

参数：

一个 String。

返回值：

一个 String。

.selectionStart

选区的起始位置。如果没有选中文本，此变量表示光标位置。

返回值：

文本中的整数位置，以字符为单位。

.selectionSize

当前选择的大小。

返回值：

以 Integer 表示字符数——如果没有选中文本则为 0。

.select

注意： 在 Cocoa GUI 中不可用。

选择 start 位置之后的 size 个字符。光标将停留在新选区的末尾。

参数：

start

文本中的整数位置，以字符为单位。

size

一个整数数量的字符。

Appearance

.font

整个文本的默认字体。此字体适用于所有未使用 -setFont 应用字体的文本。

参数：

一个 Font。

.stringColor

整个文本的默认颜色。此颜色适用于所有未使用 -setStringColor 应用颜色的文本。

注意： 调用 stringColor_ 不会影响光标的颜色。设置深色背景（使用 background_）和浅色文本颜色会使光标保持深色。建议通过将 TextView 的调色板设置为 QPalette 的实例来设置背景和字符串颜色。( t = TextView(nil, Rect(800, 50, 500, 400)) .string_("Some text") .palette_(QPalette.dark) // set all colors here .front; )

.tabWidth

制表符显示时的宽度。

Interaction

.editable

视图的内容是否可编辑，即用户是否可以键入和删除文本。

参数：

一个布尔值。

.enterInterpretsSelection

当按下 Ctrl/Cmd/Shift + Enter 键组合时，选区是否将被解释并作为 SuperCollider 代码调用。

默认为 false。

参数：

一个布尔值。

.usesTabToFocusNextView

Tab 键是否会切换焦点到下一个视图（如同其他视图的常规行为），而不是在文本中插入制表符。

默认为 false。

参数：

一个布尔值。

.hasHorizontalScroller

是否显示水平滚动条。

请注意，如果 -autohidesScrollers 为 true，则即使此变量被设置为 true，滚动条也可能被隐藏。由于当一行到达视图边缘时 TextView 通常会将文本换行到下一行，因此除非 -autohidesScrollers 为 false，否则水平滚动条可能永远不会显示。

默认为 true。

参数：

一个布尔值。

.hasVerticalScroller

是否显示垂直滚动条。

请注意，如果 -autohidesScrollers 为 true，那么即使此变量被设置为 true，滚动条也可能被隐藏。

默认为 true。

参数：

一个布尔值。

.autohidesScrollers

当滚动条没有用途时（即内容在滚动条方向上不可滚动），是否自动隐藏每个滚动条。

如果 -hasHorizontalScroller 或 -hasVerticalScroller 为 false，则相应的滚动条将始终隐藏，与此变量无关。

默认为 true。

参数：

一个布尔值。

拖放

注意： TextView 的默认拖放行为未在标准 SC 方法中定义，而是在视图实现中定义（-defaultGetDrag 除外）。它可能可以通过添加你自己的处理器来覆盖（参见 View: Drag and drop），也可能不能，取决于所使用的 GUI kit。

从 TextView 拖动时，会将选中的文本以 String 形式作为拖拽数据；而放置时会接受任意对象，并将其作为 String 插入到放置位置。

您也可以将文件从 SuperCollider 外部拖放到 TextView 上，它会在放置位置插入这些文件的 URL。

.defaultGetDrag

返回值：

-selectedString。

示例

(
w = Window.new("Text View Example", Rect(100, Window.screenBounds.height-400, 520, 300)).front;
t = TextView(w.asView, Rect(10, 10, 500, 200))
    .focus(true);
)

// 使用你刚创建的 Window，依次尝试这些，并测试文本视图如何响应
t.mouseUpAction_{ |it, x, y, modifiers, buttonNumber| [x, y].postln };
t.autohidesScrollers_(false);
t.hasVerticalScroller_(false);
t.hasVerticalScroller_(true);
t.hasHorizontalScroller_(false);
t.hasHorizontalScroller_(true);
t.autohidesScrollers_(true);

t.open("Help/GUI/Main-GUI/Button.html"); // 加载 HTML 文件

// 选择性编辑和格式化
t.setStringColor (Color.red, 5, 5);
t.setFont (Font("Courier", 12), 5, 10);
t.setString ("\nA replacement String\n", 12, 6);

// 与这些会改变一切的方法比较
t.font_(Font("Courier", 14));
t.stringColor_(Color.blue);
