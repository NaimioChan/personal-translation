StreamClutch

缓冲流式值

Stream : AbstractFunction : Object

参见：Routine、FuncStream、EventStreamPlayer

类方法

StreamClutch.new(pattern, connected: true)

参数：

pattern

要缓冲的模式或流。

connected

如果为 true，则每次调用 next 时都会调用下一个流值。如果为 false，则返回最后一个值。
