Array2D

二维数组

Collection : Object

另请参阅：Array

说明

表示一个二维数据数组。行数和列数是固定的。

注意： 可以使用“数组的数组”来实现类似的行为——请参见本页底部的示例以进行比较。

类方法

Array2D.new(rows: 1, cols: 1)

创建指定大小的数组。

a = Array2D.new(3, 4);
a[2, 2] = 1;
a.postln

Array2D.fromArray(rows, cols, array)

从提供的数组构建一个 Array2D。

a = Array2D.fromArray(3, 4, [9, 8, 7, 6, 5, 4, 3, 2, 1, 2, 3, 4]);
a[2, 2] = 1;
a.postln

实例方法

.at(row, col)

从数组中获取值。

a.at(2, 3);
a[2, 3];

.put(row, col, val)

将值放入数组。

a.put(2, 3, 72);
a[2, 3] = 72;

.colsDo(func)

遍历各列。每个列都会依次传递给 func。

a.colsDo(_.postln);

.rowsDo(func)

遍历各行。每一行将依次传递给 func。

a.rowsDo(_.postln);

.colAt(ci)

检索单个列。

a.colAt(2);

.rowAt(ri)

检索单行。

a.rowAt(2);

.asArray

返回包含这些元素的扁平数组。

a.postln;
a.asArray.postln;

返回值：

Array

示例

// "a" 是一个数组的数组
a = { { 100.0.rand }.dup(100) }.dup(100);
// "b" 是一个等价的 Array2D，使用 "fromArray" 类方法创建
b = Array2D.fromArray(100, 100, a.flat);

// 访问
a[15][22]
b[15, 22]

// 速度比较 1：随机访问
bench { 100.do(a[100.rand][100.rand]) }
bench { 100.do(b[100.rand, 100.rand]) }

// 速度比较 2：迭代
bench { 100.do(a.do { |row| row.do { |item| item * 2 } }) }
bench { 100.do(b.do { |item| item * 2 }) }
