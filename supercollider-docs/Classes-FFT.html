FFT

快速傅里叶变换

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

另请参阅：IFFT、FFT 概述

说明

快速傅里叶变换分析信号的频率内容，这对于音频分析或频域声音处理（相位声码器）很有用。

注意： FFT 和 IFFT UGen 需要一个缓冲区来存储频域数据。该缓冲区必须恰好只有一个声道。绝不支持多声道缓冲区。要对多声道信号进行 FFT 处理，请提供一个单声道缓冲区数组，每个声道对应一个缓冲区。然后，FFT/IFFT 将执行多声道扩展，以分别处理每个声道。// NO: 该缓冲区有两个声道——这样不行 fft = FFT(LocalBuf(2048, 2), aStereoSignal); // YES: 使用两个单声道缓冲区的数组 fft = FFT(Array.fill(2, { LocalBuf(2048, 1) }), aStereoSignal); // 等效快捷写法： // LocalBuf 进行多声道扩展，从而使 FFT 也进行扩展 fft = FFT(LocalBuf(2048.dup(2), 1), aStereoSignal); 另请参见FFT 概述：使用 FFT UGen 进行多声道扩展。

类方法

FFT.new(buffer, in: 0.0, hop: 0.5, wintype: 0, active: 1, winsize: 0)

参数：

buffer

用于存储频谱数据的缓冲区。缓冲区的大小必须对应 2 的幂。此处 LocalBuf 很有用，因为进程不应在 synth 之间共享数据。（注意：大多数 PV UGen 会原地操作此数据。并行处理请使用 PV_Copy。）

in

要分析的信号。信号的速率决定了读取输入的速率。

hop

从一个 FFT 分析帧的开头到下一个分析帧开头的偏移量，以分析帧大小的倍数衡量。该值可以在 1.0 到接近（但大于）0.0 的值之间，默认值为 0.5（意味着每帧与前/后帧有 50% 的重叠）。

wintype

定义数据如何加窗：

-1

矩形加窗，简单但通常不推荐；

0

（默认）正弦窗，通常推荐用于相位声码器工作；

1

Hann 窗，通常推荐用于分析工作。

-1

矩形加窗，简单但通常不推荐；

0

（默认）正弦窗，通常推荐用于相位声码器工作；

1

Hann 窗，通常推荐用于分析工作。

active

一个简单的控制，用于启用（>0）或停用（<=0）FFT 分析。这主要用于仅在特定时刻而非持续进行分析的信号分析过程

winsize

加窗的音频帧通常与缓冲区大小相同。如果你希望 FFT 进行零填充，可以指定小于实际缓冲区大小的窗口大小（例如窗口大小为 1024，缓冲区大小为 2048）。两个值仍必须是二的幂。将其保留为默认值零以不进行零填充。

返回值：

FFT 链

讨论：

只有前两个参数是必需的。其余参数允许针对特殊情况进行自定义 FFT 分析。

FFT 使用一个本地缓冲区来保存缓冲的音频。缓冲区大小必须是控制块大小的整数倍，并且是 2 的幂。

请注意，对于相位声码器用途，将 hop 或 wintype 设置从默认值改为其他值时，与 IFFT 结合使用通常会由于加窗伪影而产生不自然的声音。（hop 为 0.25 配合 Hann 窗，对于相位声码器工作可能是一种有用的组合。）

示例

(
{
    var in, chain;
    in = WhiteNoise.ar(0.1);
    chain = FFT(LocalBuf(2048), in);
    IFFT(chain) // 逆 FFT
}.play;
)

// 检查它，我们可以看到该链是一个 FFT：
(
{
    var in, chain;
    in = WhiteNoise.ar(0.1);
    chain = FFT(LocalBuf(2048), in);
    chain.inspect; 
    IFFT(chain) // 逆 FFT
}.play;
)

(
{
    var in, chain;
    in = SinOsc.ar(SinOsc.kr(SinOsc.kr(0.08, 0, 6, 6.2).squared, 0, 100, 800));
    chain = FFT(LocalBuf(2048), in);
    IFFT(chain)
}.play;
)

(
{
    var in, chain;
    in = SinOsc.ar(SinOsc.kr(SinOsc.kr(0.08, 0, 6, 6.2).squared, 0, 100, 800));
    // in = WhiteNoise.ar(0.2);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_MagAbove(chain, 310);
    0.5 * IFFT(chain);
}.play;
)

(
{
    var in, chain;
    in = WhiteNoise.ar(0.2);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_BrickWall(chain, SinOsc.kr(0.1));
    IFFT(chain)
}.play;
)

(
{
    var in, chain;
    in = WhiteNoise.ar(0.8);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_RandComb(chain, 0.95, Impulse.kr(0.4));
    IFFT(chain)
}.play;
)

(
{
    var in, chain;
    in = WhiteNoise.ar(0.2);
    chain = FFT(LocalBuf(2048), in);
    chain = PV_RectComb(chain, 8, LFTri.kr(0.097, 0, 0.4, 0.5),
        LFTri.kr(0.24, 0, -0.5, 0.5));
    IFFT(chain)
}.play;
)

(
{
    var in, chain;
    in = SinOsc.ar(LFNoise1.kr(5.2, 250, 400));
    chain = FFT(LocalBuf(2048), in);
    // 进出冻结状态
    chain = PV_MagFreeze(chain, SinOsc.kr(0.2));
    0.5 * IFFT(chain);
}.play;
)


// 立体声示例：

(
{
    var in, chain;
    in = SinOsc.ar(LFNoise1.kr([5.2, 3.3], 250, 400));
    chain = FFT({ LocalBuf(2048) } ! 2, in); // 我们需要两个缓冲区用于立体声输入。
    // 进出冻结状态
    chain = PV_MagFreeze(chain, SinOsc.kr([0.2, 0.3]));
    0.5 * IFFT(chain);
}.play;
)
