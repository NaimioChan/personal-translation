VarSaw

可变占空比锯齿波

PureUGen : UGen : AbstractFunction : Object

另请参阅：Saw、SyncSaw、LFSaw

说明

占空比可变的锯齿-三角波振荡器。

类方法

VarSaw.ar(freq: 440.0, iphase: 0.0, width: 0.5, mul: 1.0, add: 0.0)

VarSaw.kr(freq: 440.0, iphase: 0.0, width: 0.5, mul: 1.0, add: 0.0)

参数：

freq

频率，单位为赫兹。仅支持正频率。

警告： VarSaw 若频率超过采样率（对于控制率，即 s.sampleRate / s.options.blockSize），将超出范围。

iphase

初始相位偏移，单位为周期。[0..1]

width

占空比，表示波形在周期中达到峰值的位置。例如，当宽度为 0, 0.5, 或 1.0 时，波形将分别在周期的开头、中间或末尾达到峰值。[0..1]（内部裁剪到 [0.001..0.999]）

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

// 观察不同的占空比宽度
{ VarSaw.ar(1000, 0, [0, 0.5, 1]) }.plot

(
play({
    VarSaw.ar(
        LFPulse.kr(3, 0, 0.3, 200, 200),
        0,
        LFTri.kr(1.0).range(0, 1), // width
        0.1)
});
)

play({ VarSaw.ar(LFPulse.kr(3, 0, 0.3, 200, 200), 0, 0.2, 0.1) });

// 比较：

play({ LFPulse.ar(LFPulse.kr(3, 0, 0.3, 200, 200), 0, 0.2, 0.1) });
