BusPlug

总线上的监听器

AbstractFunction : Object

另见：Bus，Monitor，InBus，NodeProxy，Ndef

子类：NodeProxy

说明

BusPlug 表示一个私有 Bus 上的监听器，使得向多个声道播放变得容易。它主要用作 NodeProxy 的父类，但也可以用于一般的声道路由。大多数方法记录在 NodeProxy 帮助文件中。

s.boot;
z = Bus.control(s, 16);
z.setn({ |i| (i * 5).nthPrime } ! 16 * 5 + 100);
a = BusPlug.for(z);
{ Splay.ar(SinOsc.ar(a.kr(3, MouseX.kr(0, 25)))) * 0.1 }.play; // 选择性地播放 16 个声道中的 3 个，调制偏移量

类方法

BusPlug.new(server)

在给定服务器上创建一个新的（中性）实例。

BusPlug.for(bus)

使用给定的 Bus 创建一个实例。

BusPlug.audio(server, numChannels)

在给定服务器上创建一个新的音频速率实例。

BusPlug.control(server, numChannels)

在给定服务器上创建一个新的控制率实例。

BusPlug.defaultNumAudio

BusPlug.defaultNumAudio = value

以音频速率初始化且未指定具体数量时默认的声道数（默认值：2）。

BusPlug.defaultNumControl

BusPlug.defaultNumControl = value

在控制率下初始化且未指定具体数量时使用的默认通道数（默认值：1）。

BusPlug.defaultReshaping

BusPlug.defaultReshaping = value

BusPlug 及其子类 NodeProxy 的默认重塑行为。参见：-reshaping

实例方法

.server

返回 BusPlug 所运行的服务器。

.clear

释放总线，结束监视。

制作副本

.copy

复制隐藏的内部状态，使新的 BusPlug 独立于旧的那个，并在新的 Bus 上运行。按照设计，Monitor 会被复制，但不会运行（使用 play 以相同配置启动它）。如有需要，你也可以仅复制 Monitor（参见：NodeProxy: -copy）。

.copyState(proxy)

将一个代理的内部设置复制到另一个代理中。旧状态被清除，总线被释放。

参数：

proxy

其内部状态被复制的对象。

.reshaping

.reshaping = value

决定调用 -initBus 时的行为。当前选项：

  • nil 一旦初始化，保持同一总线 - 这是默认值
  • \static 与 nil 相同，但允许你在实例中覆盖默认值
  • \elastic 在变化时按需缩小和增长，替换总线。监视会相应调整。
  • \expanding 在发生变化时，仅根据需要增长，替换 bus。Monitoring 会被调整。

在 UGen 图和模式中

.ar(numChannels, offset: 0, clip: 'wrap')

.kr(numChannels, offset: 0, clip: 'wrap')

返回一个指向我的输出的 numChannels 的链接。如果未初始化，则创建一个匹配的总线。通常，ar 默认为立体声，kr 默认为单声道。这可以在 classvars 中设置：*defaultNumAudio、*defaultNumControl

为保持一致，当未给出 numChannels 时，它始终返回信号数组。要使其成为单个 ugen 输出，请使用 numChannels = 1。另见：InBus。

参数：

numChannels

返回的通道数。如果接收者是中性的或重塑是弹性的，则将其初始化为此数字。如果这多于可用的通道，则使用 clip 行为（见下文）。如果设置为 1，它将返回一个 InBus 的实例，否则返回一个包含一个或多个 InBus 实例的 Array。

offset

读取具有比 numChannels 更多通道的总线时的通道偏移，在相邻通道之间交叉淡化。

clip

如果设为 'wrap'，超出范围的通道将环绕；如果设为 'clip'，则重复最后一个通道。

.asUGenInput

返回要从 BusPlug 总线（一个 InBus UGen）读取的相应输出

b = BusPlug.new;
{ Blip.ar(b + 5) }.play;
b.bus.set(12);

.embedInStream(inval)

返回总线的 map 参数；如果总线有多个通道，则返回一个 map 参数的数组。

b = BusPlug.new;
x = Pbind(\z, b).asStream;
x.next(()); // 返回总线的 map 参数
b.defineBus(\audio, 3);
x.next(()); // 返回音频速率总线的 map 参数

.asControlInput

返回总线的 map 参数，与 -embedInStream 相同

监控与路由

.isPlaying

如果服务器正在运行且总线不为 nil，则返回 true。NodeProxy 中，如果组正在播放，则返回 true。

.isMonitoring

如果监听正在播放则返回 true

.play(out, numChannels, group, multi: false, vol, fadeTime, addAction)

从具有若干声道的总线索引播放到另一个具有若干声道的索引，在 Group 内（即目标组或服务器）。

参数：

out

总线索引

numChannels

要输出的通道数。如果 BusPlug 为中性，或重塑为弹性，则将其初始化为该数量。如果该数量超过可用通道数，则进行环绕。如果未指定该数量，且重塑为弹性，则会自动扩展。

group

用于播放监视器 synth 的目标 Group 或 Server。

multi

保留旧的播放链接并添加新的链接

vol

用于监听的总体音量

fadeTime

淡入 / 淡出时间

addAction

在节点树中何处播放监听 synth

.playN(outs, amps, ins, vol, fadeTime, group, addAction)

在非连续通道上播放。参见：Monitor 和 playN

参数：

outs

目标声道数组（或单个值）

amps

每个通道的振幅数组（或单个值）

ins

总线内源声道偏移量的数组（或单个值）

vol

总音量（乘以 amps）

fadeTime

用于淡入 / 淡出的 fadeTimes 数组（或单个值）

group

用于播放监视器 synth 的目标 Group 或 Server。

addAction

在节点树中何处播放监听 synth

.stop(fadeTime, reset: false)

停止播放公共通道。

参数：

fadeTime

此动作的衰减时间

reset

如果设置为 true，则重置所有监控状态。否则保留之前的播放参数。

.monitor

.monitor = value

返回当前监视器（参见 Monitor）

总线变化

这些方法数量稍多，因为它们对于实现 NodeProxy 的行为很重要。在正常使用中，-bus 和 -initBus 方法通常就足够了。

注意： 创建新总线时，旧总线会被释放。

.isNeutral

如果到目前为止未初始化任何总线则返回 true。

.bus

.bus = inBus

设置或获取总线。如果 BusPlug 监视器正在播放，则重启监视器以正确播放新的总线。

.setBus(inBus)

通过传入一个 Bus 来设置总线对象。

注意： 你必须显式地停止并播放

.defineBus(rate: 'audio', numChannels)

为 BusPlug 创建一个具有给定速率和通道数的新总线。

.initBus(rate, numChannels)

仅在必要时创建新总线。这取决于当前总线和 -reshaping 模式。

返回值：

布尔值（成功时为 true）。

示例

// 用作 control 总线监听器

s.boot;
z = Bus.control(s, 16);
a = BusPlug.for(z);

m = { Mix(SinOsc.ar(a.kr(16), 0, 0.1)) }.play;

z.setn(Array.rand(16, 300, 320).put(16.rand, rrand(500, 1000)));
z.setn(Array.rand(16, 300, 320).put(16.rand, rrand(500, 1000)));
z.setn(Array.rand(16, 300, 320).put(16.rand, rrand(500, 1000)));

m.free;


m = { SinOsc.ar(a.kr(2, MouseX.kr(0, 19)), 0, 0.1) }.play; // 调制通道偏移

z.setn(Array.rand(16, 300, 1320).put(16.rand, rrand(500, 1000)));


m.free; z.free;

// 用作音频监听

p = BusPlug.audio(s, 2);
d = { Out.ar(p.index, PinkNoise.ar([0.1, 0.1])) }.play;


p.play; // 监听 p 中播放的任何内容（执行顺序无关紧要）



d.free;
d = { Out.ar(p.index, PinkNoise.ar([0.1, 0.1])) }.play;

p.stop;
p.play;

// p 也可以播放到另一条总线：

p.stop;
p.play(12);

// 监听该总线以进行测试：
x = { InFeedback.ar(12, 2) }.play;
x.free;
