Knob

旋转控制器视图

另请参阅：Slider、Slider2D

说明

Knob 以旋转方式显示从 0.0 到 1.0 的值，并允许通过圆形或线性鼠标运动来控制它。

它还会显示该值相对于 0.0 或 0.5 的偏差，你可以通过 -centered 选择。

要在鼠标交互模式之间切换，请使用 -mode。

交互时值的变化量可以使用 -step、-keystep、-shift_scale、-ctrl_scale 和 -alt_scale 进行微调

类方法

.defaultMode

新建 Knob 的默认 -mode。

实例方法

Data

.value

显示值。

参数：

范围在 0.0 到 1.0 之间的一个数字。

.valueAction

设置该值并触发 -action。

.increment

将值增加 -keystep 乘以参数所得的量。

参数：

一个 Number。

.decrement

将值减少 -keystep 乘以参数所得的量。

参数：

zoom

一个 Number。

Interaction

.mode

在视图上点击后，值受鼠标移动控制的方式：

  • \round - 值按圆周运动变化
  • \horiz - 值遵循水平方向上的线性运动
  • \vert - 值跟随垂直方向的线性移动

默认为 \round。

参数：

上面列出的符号之一。

.keystep

在按下相关按键时值递增/递减的量。

默认为 0.01；

参数：

一个 Number。

.step

在 'horizontal' 和 'vertical' 模式下使用鼠标时值递增/递减的量。

参数：

一个 Number。

.shift_scale

在按住 Shift 键进行鼠标或键盘交互时，-step 或 -keystep 所乘以的因子。

参数：

一个 Float。

.ctrl_scale

在按住 Ctrl 键进行鼠标或键盘交互时，-step 或 -keystep 所乘以的因子。

参数：

一个 Float。

.alt_scale

在按住 Alt 键进行鼠标或键盘交互时，-step 或 -keystep 所乘以的系数。

参数：

一个 Float。

Appearance

.centered

值的偏差是相对于 0.0 还是 0.5 显示（例如在声像控制器中）；

参数：

一个布尔值。

.color

Knob 用于绘制以下元素的颜色：

  • 主旋钮颜色
  • 值指示器
  • 偏差指示器
  • 偏差指示器的背景

参数：

一个包含四种颜色的数组，顺序如上所列。

拖放

.defaultGetDrag

返回值：

该 -value。

.defaultCanReceiveDrag

返回值：

如果当前拖动数据是 Number，则为 true。

.defaultReceiveDrag

将 -valueAction 设置为当前拖拽数据。

示例

基本示例

(
var window, size = 32; // 尝试不同的尺寸 - 从 15 到 200 或更大!
window = Window.new("Knob", Rect(640, 630, 270, 70)).front;
k = Knob.new(window, Rect(20, 10, size, size));
k.action_({ |v, x, y, m| postf("action func called: %\n", v.value) });
// k.color[1] = Color.gray(alpha: 0);
)

k.value
k.value = 0.25
k.valueAction = 0.125

// modes
k.mode = \vert;
k.mode = \horiz;
k.mode = \round; // 默认

k.visible
k.visible = false
k.visible = true
k.enabled = false
k.enabled_(true)
k.canFocus = false
k.canFocus = true

比较鼠标模式

(
var view = View().layout_(

        VLayout(Knob().mode_(\vert), StaticText().string_("vert")),
        VLayout(Knob().mode_(\horiz), StaticText().string_("horiz"))
    )
);
view.front;
)

居中模式

Center 模式适用于声像或均衡增益控制等。

(
var window;
k = Knob.new(window, Rect(20, 10, 36, 36));
window = Window.new("Pan Knob", Rect(640, 630, 270, 70)).front;
k.action_({ |v, x, y, m| \pan.asSpec.map(v.value).postln })
//  .mode_(\horiz)
    .centered_(false)
    .value_(\pan.asSpec.unmap(0)); // 0.5
// k.color[1] = Color.gray(alpha: 0);
)
k.centered
k.centered = true
k.centered = false

step

-step 仅影响 'horiz' 和 'vert' 模式：

(
var window, midispec;
k = Knob.new(window, Rect(20, 10, 32, 32));
midispec = [0, 127, 'linear', 1].asSpec;
window = Window.new("step Knob", Rect(640, 630, 270, 70)).front;
k.action_({ |v, x, y, m| midispec.map(v.value).postln })
       .value_(midispec.unmap(0));

k.mode = \vert;

)
k.step
k.step = 10/127 // 以 10 为步长

k.mode = \horiz;
k.mode = \round;

mouseOverAction

(
var size = 28;
w = Window.new("Knobs", Rect(250, 500, 270, 70));
w.acceptsMouseOver = true; // 在父窗口中必须为 true！
w.view.decorator = FlowLayout(w.view.bounds);
h = StaticText(w, 150 @ 10);
w.view.decorator.nextLine;
k = Array(8);
8.do({ |item, i|
    var knob;
    knob = Knob.new(w, size @ size)
        .action_({ |v, x, y, m| h.string = "val: " ++ v.value.asString })
        .mouseOverAction_({ |v, x, y| h.string = "val: " ++ v.value.asString });

    k = k.add(knob);
});
w.front
)
k[4].value

拖放

(
var w, txt, size = 36;
w = Window.new("Knobs", Rect(400, 400, 250, 100)).front;
w.acceptsMouseOver = true;
w.view.decorator = FlowLayout(w.view.bounds).gap_(10 @ 10).margin_(10 @10);
txt = StaticText(w, 200 @ 14);
w.view.decorator.nextLine;

k = Knob(w, size @ size);
k.action = { |v, x, y|  v.value.postln; txt.string_("value: " ++ v.value) };
k.mouseOverAction = { |v| txt.string_("value: " ++ v.value) };

j = Knob(w, size @ size);
j.action = { |v, x, y|  j.value.postln; txt.string_("value: " ++ v.value) };
j.mouseOverAction = { txt.string_("value: " ++ j.value) };

n = NumberBox(w, 100 @ 20);
// n.setProperty(\boxColor, Color.grey(alpha: 0.0));
n.value = 0.0;
)

// 自定义拖放方法
k.canReceiveDragHandler
k.canReceiveDragHandler = false; // 不接受拖放

k.canReceiveDragHandler = { View.currentDrag.isFloat }; // 仅在拖动为浮点数时接受

k.receiveDragHandler = { ("value dropped in: " ++ View.currentDrag).postln }

k.receiveDragHandler = { k.valueAction = View.currentDrag.clip(0.0, 1.0) }

k.beginDragAction = { ("drag out -> " ++ k.value).postln }

k.beginDragAction = { k.value.asFloat }
