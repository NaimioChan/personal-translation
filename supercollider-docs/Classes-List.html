List

可变大小项的列表

SequenceableCollection : Collection : Object

另请参阅：Array

子类：SortedList

说明

List 是 SequenceableCollection 的子类，其大小可以无限增长。虽然它不是 Array 或其父类 ArrayedCollection 的子类，但它在实现中使用了 Array，并且在许多情况下可以与 Array 互换使用。（List 实现了许多与 Array 相同的方法。）

List 的许多方法继承自 SequenceableCollection 或 Collection，并在这些帮助文件中进行了说明。

SuperCollider 中数组的大小限制与列表的灵活性

数组具有固定的最大大小。超出该大小添加元素时，会创建一个新的 Array 并返回。为了能够使用它，可以将持有旧数组的变量重新赋值为新数组。因此，在 Array 中添加新元素的惯用方式是：

x = x.add(i);

Example:

// 创建一个大小为 3 的新空集合：
x = Array.new(3); 
y = Array.new(3); 
z = List.new(3);

// 尝试向数组和列表添加 7 个项。
// 如果数组超过 maxSize，它只会
// 增长到内部指定的最大大小。
( 
7.do { |i|
    x.add(i);
    y = y.add(i); // 每次添加时重新赋值数组 y
    z.add(i);
};
)

// 尝试访问第 5 项：
x.at(4); // -> nil（越界）
y.at(4); // -> 4
z.at(4); // -> 4

// x 只增长到大小 4
x.postln; // -> [ 0, 1, 2, 3 ]
y.postln; // -> [ 0, 1, 2, 3, 4, 5, 6 ]
z.postln; // -> List[ 0, 1, 2, 3, 4, 5, 6 ]

List 没有大小限制，因此更灵活，但开销略高：

(
// 创建一个大小为 3 的新空 List
x = List.new(3);

x.postln; // -> List[ ]

// 将数字 0 到 4 添加到 List
5.do({ |i| x.add(i) });

// 列表已就地修改，每添加一项
x.postln; // -> List[ 0, 1, 2, 3, 4 ]
)

类方法

List.new(size: 8)

创建一个 List，其初始容量由 size 给定。

List.newClear(size: 0)

创建一个 List，初始容量由 size 指定，槽位填充为 nil。

List.copyInstance(aList)

通过复制 aList 的数组变量来创建一个 List。

List.newUsing(anArray)

使用 anArray 创建一个 List。

实例方法

.asArray

基于此 List 返回一个新的 Array。

.array

.array = value

返回该 List 的 Array，允许直接对其操作。这仅在 List 或其父类中未实现的特殊操作时才需要。

(
x = List[1, 2, 3];
x.array.add("foo");
x.postln;
)

.array

.array = value

设置 List 的 Array。

.at(i)

返回位于 index 处的项。参见 SequenceableCollection: Indexing。. 接受单个索引或索引数组，在后一种情况下返回元素数组。Array 是其语法快捷方式。

x = List[1, 2, 3] //-> [1, 2, 3]

// 获取索引 1 处的值：
x.at(1) //-> 2
// 等价的简写语法：
x[1] //-> 2

// 索引也可以从数组中获取（返回的不是列表，而是数组）：
y = [0, 0, 2, 2, 1] //-> [0, 0, 2, 2, 1]
x[y]; //-> [1, 1, 3, 3, 2]

(
var pitches =  [43.0, 55.0, 58.86, 57.42, 67.0];
fork {
    pitches.size.do{ |i|
        {
            var freq = pitches[i].midicps;
            var env = Env.perc.ar(Done.freeSelf);
            SinOsc.ar(freq) * 0.1 * env
        }.play;
        0.2.wait
    }
}
)

.clipAt(i)

与 -at 类似，但通过将超出集合边界的值裁剪到边界内，保证任何 index 值都是有效的。大于 size - 1 的值会被裁剪到最后一个索引，小于 0（负数）的值会被裁剪到 0。当传入一个索引数组时，返回一个新的 Array，其中包含指定位置处的元素。SequenceableCollection: -|@| 是它的语法快捷方式。

a = List[1, 2, 3]
a.clipAt(2) // 与在……处相同
a.clipAt(3) // clips
a.clipAt([-1, 3, 1]) // 索引数组（返回的不是 list，而是 array）
a|@|3 //语法快捷方式

.wrapAt(i)

与 -at 类似，但通过对超出集合边界范围的索引值进行回绕，保证任何索引值都有效。如果索引超过 size - 1，它会回绕到 0。同样，如果索引小于 0（负数），它会从集合末尾回绕来访问元素。this.wrapAt(index) 等价于 this.at(index mod: size)，确保索引始终在集合的有效范围内。索引也可以是索引数组，用于提取指定的元素。SequenceableCollection: -@@ 是它的语法快捷方式。

a = List[1, 2, 3]
a.wrapAt(2) // 与在……处相同
a.wrapAt(3) // wraps
a.wrapAt([-1, 3, 1]) // 索引数组（返回的不是 list，而是 array）
a@@3 //语法快捷方式

(
var pitches =  [43.0, 55.0, 58.86, 57.42, 67.0];
fork {
    32.do{ |i|
        {
            var freq = pitches.wrapAt(i).midicps;
            var env = Env.perc.ar(Done.freeSelf);
            SinOsc.ar(freq) * 0.1 * env
        }.play;
        0.2.wait
    }
}
)

.foldAt(i)

与 -at 类似，但通过将集合边界之外的值反射回来，保证任何 index 值都有效。大于 size - 1 的值会朝较小的索引方向反射回来。类似地，如果索引低于 0（负数），则朝相反方向折叠。这会在集合边界内为任何索引创建对称映射。索引也可以是一个索引数组，用于提取指定的元素。SequenceableCollection: -@|@ 是其语法快捷方式。

a = List[1, 2, 3]
a.foldAt(2) // 与在……处相同
a.foldAt(3) // 折返
a.foldAt([-1, 3, 1]) // 索引数组（返回的不是 list，而是 array）
a@|@3 //语法快捷方式

(
var pitches =  [43.0, 55.0, 58.86, 57.42, 67.0];
fork {
    32.do{ |i|
        {
            var freq = pitches.foldAt(i).midicps;
            var env = Env.perc.ar(Done.freeSelf);
            SinOsc.ar(freq) * 0.1 * env
        }.play;
        0.2.wait
    }
}
)

.put(i, item)

将 item 放在 index 处，替换原有内容。参见 SequenceableCollection: Indexing。

.clipPut(i, item)

与 -put 相同，但 index 大于 List 实例大小减一的值将被裁剪为 size - 1，即最后一个索引。

.wrapPut(i, item)

与 -put 相同，但 index 大于 List 实例大小减一的值会回绕到 0。

.foldPut(i, item)

与 -put 相同，但 index 的值大于 List 实例大小减一时会折返。

.add(item)

将 item 添加到 List 的末尾。

.addFirst(item)

将item插入到列表的开头。

.insert(index, item)

将 item 插入到 List 的内容中的指定 index 处。

x = List[1, 2, 3, 4]; // -> List[1, 2, 3, 4]
x.insert(0, 999); // -> List[999, 1, 2, 3, 4]
x; // -> List[999, 1, 2, 3, 4]

.boundedInsert(index, item)

与 -insert 相同，但在插入 item 之前移除接收者的最后一个元素。这会改变接收者但保持其大小不变。

x = List[1, 2, 3, 4]; // -> List[1, 2, 3, 4]
x.boundedInsert(1, 999); // -> List[1, 999, 2, 3]
x; // -> List[1, 999, 2, 3]
x.boundedInsert(20, \a); // -> List[1, 999, 2, a]
x.boundedInsert(-2, \b); // -> List[b, 1, 999, 2]

.pop

移除并返回 List 的最后一个元素。

.grow(sizeIncrease)

将 List 的大小增加 sizeIncrease 个槽位。

.removeAt(index)

移除并返回 index 处的项，缩小 List 的大小。参见 SequenceableCollection: Indexing。

y = List[1, 2, 3];
y.removeAt(1);
y.postln;

.fill(item)

将该项插入接收者的内容中，可能返回一个新的集合。

注意： 它与 Collection 的 *fill 之间的区别。

(
var z;
z = List[1, 2, 3, 4];
z.fill(4).postln;
z.fill([1, 2, 3, 4]).postln;
)

.do(function)

按顺序遍历元素，对每个元素调用该函数。函数被传入两个参数：元素和索引。

List['a', 'b', 'c'].do({ |item, i| [i, item].postln });

.reverseDo(function)

按相反顺序遍历元素，对每个元素调用该函数。该函数接收两个参数：元素和索引。

List['a', 'b', 'c'].reverseDo({ |item, i| [i, item].postln });

.pairsDo(function)

对 List 中每对后续元素调用函数。该函数接收这两个元素和一个索引。

List[1, 2, 3, 4, 5, 6].pairsDo({ |a, b| [a, b].postln });

.copyRange(start, end)

返回一个新的 List，它是接收者从 start 到 end 的索引槽的副本。参见 SequenceableCollection: Indexing。

(
var y, z;
z = List[1, 2, 3, 4, 5];
y = z.copyRange(1, 3);
z.postln;
y.postln;
)

.copySeries(first, second, last)

返回一个新的 List，由从 first 开始的值组成，然后以 first 和 second 之间的距离为步长，直到 last。参见 SequenceableCollection: Indexing。。

(
var y, z;
z = List[1, 2, 3, 4, 5, 6];
y = z.copySeries(0, 2, 5);
y.postln;
)

.putSeries(first, second, last, value)

将 value 放在从 first 开始的每个索引处，然后以 first 和 second 之间的距离为步长，直到 last。参见 SequenceableCollection: Indexing。。

(
var y, z;
z = List[1, 2, 3, 4, 5, 6];
y = z.putSeries(0, 2, 5, "foo");
y.postln;
)

.reverse

返回一个新 List，其元素顺序相反。

(
var y, z;
z = List[1, 2, 3, 4];
y = z.reverse;
z.postln;
y.postln;
)

.scramble

返回一个元素已被打乱的新 List。接收者保持不变。

List[1, 2, 3, 4, 5, 6].scramble.postln;

.mirror

返回一个新的 List，它是将接收者变为回文后的结果。接收者本身不变。

List[1, 2, 3, 4].mirror.postln;

.mirror1

返回一个新的 List，它是将接收者变为回文并移除最后一个元素后的结果。如果该列表将被循环重复，这会很有用，第一个元素不会被播放两次。接收者保持不变。

List[1, 2, 3, 4].mirror1.postln;

.mirror2

返回一个新的 List，它是接收者与其自身反转的拼接。中心元素被重复。接收者保持不变。

List[1, 2, 3, 4].mirror2.postln;

.stutter(n: 2)

返回一个新列表，其元素重复 n 次。接收者保持不变。

注意： 建议改用 dupEach。此方法保留是为了向后兼容。

List[1, 2, 3].stutter(2).postln;

.dupEach(n: 2)

返回一个新列表，其元素重复 n 次。接收者保持不变。

List[1, 2, 3].dupEach(2).postln;

.rotate(n: 1)

返回一个新 List，其元素按旋转后的顺序排列。负的 n 值向左旋转，正的 n 值向右旋转。接收者保持不变。

List[1, 2, 3, 4, 5].rotate(1).postln;
List[1, 2, 3, 4, 5].rotate(-1).postln;
List[1, 2, 3, 4, 5].rotate(3).postln;

.pyramid(patternType: 1)

返回一个新的 List，其元素已通过 10 种“计数”算法之一重新排序。算法编号为 1 到 10。运行示例以查看这些算法。

List[1, 2, 3, 4].pyramid(1).postln;

(
10.do({ |i|
    List[1, 2, 3, 4].pyramid(i + 1).postcs;
});
)

.lace(length)

返回一个新的 List，其元素是接收者子集合中元素交错排列的序列，最多到 length 大小。接收者保持不变。

(
x = List[[1, 2, 3], 6, List["foo", 'bar']];
y = x.lace(12);
x.postln;
y.postln;
)

.permute(nthPermutation)

返回一个新的 List，其元素为接收者元素的第 nthPermutation 个排列。接收者保持不变。

(
x = List[1, 2, 3];
6.do({ |i| x.permute(i).postln });
)

.wrapExtend(length)

返回一个新的 List，其元素是接收者的重复序列，直至大小 length。接收者保持不变。

(
x = List[1, 2, 3, "foo", 'bar'];
y = x.wrapExtend(9);
x.postln;
y.postln;
)

.foldExtend(length)

与 -wrapExtend 相同，但序列会在列表元素上折返。

(
x = List[1, 2, "foo"];
y = x.foldExtend(9);
x.postln;
y.postln;
)

.slide(windowLength: 3, stepSize: 1)

返回一个新的 List，其元素是接收者中重复的子序列。演示比解释更容易。

List[1, 2, 3, 4, 5, 6].slide(3, 1).postcs;
List[1, 2, 3, 4, 5, 6].slide(3, 2).postcs;
List[1, 2, 3, 4, 5, 6].slide(4, 1).postcs;

.dump

转储 List 的 Array。

.clear

用一个新的空 Array 替换该 List 的 Array。
