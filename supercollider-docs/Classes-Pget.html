Pget

在 Plambda 的作用域（命名空间）内获取一个值

Pattern : AbstractFunction : Object

另请参阅：Plambda、Plet

说明

Pget 用于获取 Plet 的值。Plet/Pget 用于在 Plambda 内部的各个模式之间共享数据。

类方法

Pget.new(key, default, repeats: 1)

参数：

key

变量名

default

若没有由配对的 Plet 定义，则使用默认值

repeats

实例方法

.default

.default = value

.storeArgs

.key

.key = value

.repeats

.repeats = value

.embedInStream(inval)

参数：

inval

示例

(
    /*

    两个模式并行播放， 
    彼此之间共享数据

    */

    // 一个演奏随机音阶级数的旋律
    a = Pbind(
        \dur, 0.125, 
        \octave, 4,
        \degree, Plet(\melody, pattern: Pwhite(0, 7))
    );

    // 低音部分，音阶取自上面定义的 \melody 变量 
    b = Pbind(
        \dur, 0.5, 
        \octave, 3,
        \degree, Pget(\melody, default: 1, repeats: inf).trace
    );

    // 并行播放这些 pattern
    Plambda(
        Ppar([a, b], inf)
    ).play;
)
