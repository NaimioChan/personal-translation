NotificationCenter

让对象发出通知

Object

参见：SimpleController、NodeWatcher

说明

在某些情况下，让一个对象在收到来自另一个给定对象的预定义消息时执行特定函数可能很有用。例如，GUI 元素可能希望在服务器对象的状态发生变化时更新自身状态。这类情况包括：在加载新 synthdef 时更新 synthdef 数量，在某个 Synth 所控制的 Synth 开始运行或被释放时更新控制 GUI 元素的启用/禁用状态，等等。NotificationCenter 使得可以向任何对象（称为 observer）添加这样的自定义函数，并在另一个对象（称为 subject）发出由符号（称为 message）标识的通知时执行它。

NotificationPattern 提供的实现是被称为观察者模式的常见 OOP 模式的一种变体，它提供了一种让对象灵活地将消息广播到感兴趣的接收者对象的方式。该模式定义了对象之间的一对多依赖关系，使得当一个对象改变状态时，所有依赖它的对象都会被自动通知和更新。（参见：https://www.gofpatterns.com/behavioral-design-patterns/behavioral-patterns/observer-pattern.php 和 https://en.wikipedia.org/wiki/Observer_pattern). 通知其依赖者的对象称为主题，而依赖者称为观察者。

该模式在 SuperCollider 中的原始实现涉及三个步骤：

  1. 主体通过以下方式添加依赖者：subject.addDependant(observer)
  2. 当主体想要通知其观察者（依赖者）它已发生变化时，它使用 changed 方法：subject.changed(<optional arguments>...)
  3. 方法 changed 获取 subject 的依赖者列表，并遍历每个观察者，向其发送 update 消息：observer.changed(subject, <optional arguments>...)

然后每个观察者对象可以根据 update 方法中包含的代码以及从主题接收到的参数，决定如何响应主题广播的变化。

上述实现使用简单，因为它只需要将每个观察者注册到目标主体。然而它受到限制，因为观察者要执行的动作被编码在 update 方法中。这使得根据主体、观察者以及随 changed 消息作为参数发送的消息来选择执行不同动作的编码变得复杂。NotificationCenter 类提供了一种方式，根据主体以及随主体广播的方法一起作为参数发送的符号，告诉每个观察者要执行什么动作。因此，要让观察者在从主体接收到消息符号时执行某个动作，必须指定以下 4 个对象：

  1. 主体（除 nil 外的任何类型的对象）
  2. 消息（一个符号）
  3. 观察者（除 nil 外的任意类型对象）
  4. 要执行的动作（一个 Function）

使用 NotificationCenter 类，可通过以下代码创建主体与观察者之间的连接，以响应消息执行操作：

NotificationCenter.register(subject, message, observer, action)

要通知观察者某个主题已发生变化，NotificationCenter 必须调用 notify 方法：

NotificationCenter.notify(subject, message, <optional arguments>...);

任何已注册为发出通知的主体的观察者的对象，都将执行与该通知消息所关联的动作。因此，当观察者对象从其注册的对象那里接收到相应的消息时，就可以让该观察者对象执行指定的动作。

类方法

NotificationCenter.notify(object, message, args)

该对象发出消息，也可以传递额外参数。

NotificationCenter.register(object, message, listener, action)

感兴趣的客户端可以为对象/消息通知注册动作函数。每个对象/消息通知，一个监听者只能注册一个动作。

NotificationCenter.unregister(object, message, listener)

移除注册。

NotificationCenter.registerOneShot(object, message, listener, action)

在通知已发出并处理后，自动注销。

NotificationCenter.registrationExists(object, message, listener)

仅确认注册是否已存在。

实例方法

Example

当 Server 启动或退出时，它会通知其观察者，向它们发送消息 \newAllocators：

NotificationCenter.notify(server, \newAllocators)

因此，任何希望在服务器启动或退出时执行动作的对象，都可以使用 NotificationCenter 通过以下代码注册该动作：

// 使用默认服务器作为主题，符号作为观察者：
NotificationCenter.register(Server.default, \newAllocators, \yourself, {
    // 在此处替换为更有意义的内容：
    "symbol yourself was notified newAllocators by default server".postln;
});
