Psetp

设置某个键值的事件模式

Pset : FilterPattern : Pattern : AbstractFunction : Object

另请参阅：Pbindf、Pset

子类：Paddp、Pmulp

说明

在事件流中设置一个值直到其结束，然后用新值重复此操作，直到值流结束。

类方法

Psetp.new(name, value, pattern)

来自父类：Pset

参数：

name

value

可以是模式、流或数组。当该传入流结束时，生成的流也随之结束。

pattern

实例方法

未文档化的实例方法

.embedInStream(event)

示例

(
var a, b;
a = Psetp(\freq, Pseq([801, 1008], inf), Pbind(\dur, Pseq([0.5, 0.111, 0.22])));
x = a.asStream;
9.do({ x.next(Event.new).postln });
)

// Psetp 覆盖传入的值：

(
var a, b;
a = Psetp(\freq, 801, Pbind(\freq, 108));
x = a.asStream;
9.do({ x.next(Event.new).postln });
)


// 声音示例

(
SynthDef(\sinegrain,
    { |out = 0, freq = 440, sustain = 0.02|
        var env;
        env = EnvGen.kr(Env.perc(0.001, sustain), 1, doneAction: Done.freeSelf);
        Out.ar(out, SinOsc.ar(freq, 0, env * 0.1))
    }).add;
)

(
a = Pbind(\dur, Pseq([0.5, 0.3, 0.1]), \instrument, \sinegrain);
a = Psetp(\freq, Pseq([500, 600, 700], inf), a);
a.play;
)
