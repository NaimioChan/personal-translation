ReadableNodeIDAllocator

一个带有可读所有权的 nodeID 分配器

Object

参见：Server， 多客户端设置

说明

在多客户端设置中，了解哪个客户端在共享服务器上创建了哪些 nodeID 很有用。ReadableNodeIDAllocator 通过使用基于 clientID 的十进制前缀来提供该功能。

// 默认服务器使用 ReadableNodeIDAllocator
s.nodeAllocator;
s.nodeAllocator.userID; // 其 userID 为
s.clientID

// 它创建了这个 defaultGroup 1
s.defaultGroup;
s.defaultGroupID;
// 临时节点从 1000 开始……
3.do { s.nextNodeID.postln };


// 创建一个具有不同 clientID 的虚拟服务器
r = Server(\remote4, s.addr, s.options, clientID: 4);
// defaultGroup 以 400000 ... 前缀开头，并以 1 结尾
r.defaultGroup;
r.defaultGroupID;
// 临时节点从 400001000 开始……
3.do { r.nextNodeID.postln };

类方法

ReadableNodeIDAllocator.new(clientID: 0, lowestTempID: 1000, numClients: 32)

为给定的 clientID、最低临时 id 的偏移量创建一个新实例，以及

参数：

clientID

要为其创建偏移/前缀的 clientID

lowestTempID

最低临时 id 的偏移量

numClients

要为其拆分数字范围的客户端数量

// 创建一个 id 为 11 的分配器
a = ReadableNodeIDAllocator(11, 1000, 12);
// 以 1100000 ... 前缀开头
3.do { a.alloc.postln };

实例方法

.clientID

要为其创建偏移/前缀的 clientID

.numClients

要为其拆分数字范围的客户端数量

.lowestTempID

临时 nodeID 的起始偏移量

.idOffset

nodeID 范围的起始偏移量

.maxPermID

最高的永久 nodeID

.numIDs

分配器回绕之前的 ID 数量

.alloc

分配下一个临时 nodeID

.allocPerm

分配下一个永久 nodeID

.freePerm(id)

释放永久 nodeID

参数：

id

.isPerm(num)

测试 num 是否在分配器的永久编号范围内

参数：

num

.reset

将分配器重置为初始状态
