随机种子

随机生成器种子

另请参阅：Randomness、RandSeed、Pseed、Thread

Introduction

sclang 中的每个 Thread 都有一个（伪）随机数生成器，负责该线程内的所有随机化操作。每个随机数生成器都有自己的种子（起始点），值序列由该种子生成。可以设置此种子，之后该随机数生成器（严格确定性）会再次产生完全相同的数字。

为了节省磁盘空间，你可以通过一个可以记录在笔记本上的整数来重现任意随机数据序列。

randSeed

// 每个线程，也包括 Routine，都有一个随机生成器种子：
(
r = Routine({
    loop({#[1,2,3,4,5].choose.yield })
});
r.randSeed = 1923;
)

// 使用例程填充数组
Array.fill(7, r);

// 将随机生成器种子设置回我们最初的种子
r.randSeed = 1923;

// 使该数组完全相同
Array.fill(7, r);

继承种子

当创建一个例程时，它会从父线程（thisThread）继承其随机数生成器。如果没有设置特定的 randSeed（通常情况），那么同一个随机数生成器对象会同时为父线程和子线程提供数字（一个随机数流，在两者之间分配）。

父线程是创建新 Routine 那一刻正在生效的那个 Routine。如果那一刻没有 Routine 正在求值，那么父线程就是 sclang 进程主 Thread。默认情况下，所有 Routine 都从主线程继承随机数生成器。

那么，要为整个应用程序设置主随机种子，请在任何 Routine 的上下文之外求值 thisThread.randSeed = yourSeed，如下例所示。

thisThread.randSeed = 1923;

// 创建一个返回 Routine 的函数

r = { Routine({
    loop({#[1,2,3,4,5].choose.yield })
}) };

Array.fill(7, r.value);

// 重置种子
thisThread.randSeed = 1923;

Array.fill(7, r.value);

当你在例程上设置 randSeed 时，该例程会切换到它自己的随机数生成器，独立于任何其他生成器。随后，在此例程内创建的例程将继承其唯一的随机数生成器。

(
thisThread.randSeed = 1000;
TempoClock.sched(0, { 1000.rand.debug("main RNG"); 1 });

fork {
    2.1.wait;
    thisThread.randSeed = 1000;
    loop { 1000.rand.debug("routine RNG"); 1.wait }
};
)

main RNG: 592 // sequence is 592, 876, 614, 236...
main RNG: 876
main RNG: 614
routine RNG: 592 // sequence is 592, 876...
main RNG: 236
routine RNG: 876

请注意，这种继承只在创建新 Routine 的那一刻发生。对子 Routine 调用 next 或 play 并不会覆盖该 Routine 的随机数生成器。

音频示例

// 使用种子来完全重现一个声音：
(
SynthDef(\help_randomSeed, { arg out=0, freq=440;
    Out.ar(out,
        Line.kr(1, 0, 0.3, doneAction: Done.freeSelf) *
        Resonz.ar(
            Dust2.ar([10, 10], 270) + WhiteNoise.ar(4),
        freq, 0.01)
    )
}).send(s);

SynthDef(\help_setRandomSeed, { arg seed=1956, tbus=0.0;
        RandSeed.kr(tbus, seed);
}).send(s);
)

// 运行一个 patch
(
x = Synth(\help_setRandomSeed);
r = Routine({
    loop({
        Synth(\help_randomSeed, [\freq, rrand(440, 700)]);
        0.25.wait;
    })
}).play;
)


// 创建一个重置任务

(
d = 1250;// seed
t = Task({
    loop({
        x.set(\seed, d, \tbus, 1.0); r.randSeed = d;
        0.1.wait;
        x.set(\tbus, 0.0);
        1.9.wait;
    })
});
)

// 声音开始循环
t.start;

d = 1251; // 不同的循环
d = 1925;


// 声音又变得像随机一样，对任何东西都不感兴趣。
t.stop;
