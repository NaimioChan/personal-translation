LIDSlot

处理传入的 LID 数据。

Object

参见：LID

子类：LIDAbsSlot、LIDKeySlot、LIDLedSlot、LIDMscSlot，

说明

类方法

LIDSlot.slotTypeStrings

一个将 evtTypes 映射到描述性字符串的 IdentityDictionary。

实例方法

.postInfo

以美观、易读的方式发布槽的属性。

.debug

.debug = onoff

打开或关闭此槽的调试发布。

.action

.action = value

为此槽设置动作。

.value

获取此槽的当前值，按其 spec 映射。

.spec

用于映射此槽值的 ControlSpec。

.rawValue

.rawValue = inValue

获取 rawValue；该方法的设置器由原语 LID.prHandleEvent 调用，不应由用户调用。

.next

在模式中使用 LIDSlot 的便捷方法；这将调用该槽的值。

.createBus(server)

在服务器上创建一个总线。在服务器上，该槽位的值将自动被设置为这条总线。

参数：

server

在其上创建总线并将值转发到的服务器。默认情况下这是 Server.default

.bus

此 slot 的值映射到的服务器上的总线。

.freeBus

在服务器上释放该总线，并移除转发该值的动作。

.kr

JITLib 支持访问 NodeProxy 中的总线。如果总线尚不存在，则会创建它。

.device

此 slot 所属的设备。

.type

这是该槽的类型。

.code

该槽位的 eventCode。

.key

.key = value

此槽在设备规格中已知的键。

示例

LID.findAvailable;
LID.postAvailable; // 选择你想打开的那个，并在下一行填写 vendor 和 product id：
d = LID.open(2, 10); // trackpoint

s.boot;

d.slot(2, 1).createBus;

Ndef(\checkbus, { d.slot(2, 1).kr.poll });

d.slot(2, 1).freeBus;

Ndef(\checkbus).clear;
