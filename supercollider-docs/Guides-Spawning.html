"Spawning" 和 "TSpawning"

缺少 Spawn 和 TSpawn UGen 及其各种便捷类

在 SC2 中，Spawn 和 TSpawn 是两个最强大且最常用的 UGen。在 SC3 中，所有内容都在其中生成的顶层 Synth 这一概念不再有效。合成始终在运行（至少只要服务器在运行），并且可以即时创建新的 Synth。这种安排比 SC2 带来了更大的灵活性，但需要稍微不同的方法。

在 SC3 中，只需执行代码块即可随时创建 Synth。

// 执行此操作
(
x = SynthDef("Help-SynthDef", { arg out = 0;
    Out.ar(out, PinkNoise.ar(0.1))
}).play; // SynthDef-play 返回一个 Synth 对象。
)

// 然后执行此操作
(
SynthDef("help-Rand", { arg out = 0;
    Out.ar(
        out,
        FSinOsc.ar(
            Rand(200.0, 400.0), // 频率在 200 到 400 Hz 之间
            0, Line.kr(0.2, 0, 1, doneAction: Done.freeSelf) // 自我释放
        )
    )
}).play(s);
)

x.free;

时钟，例如 SystemClock，提供了一种在未来任意时间点调度任务的方法。这类似于 SC2 中的 Synth.sched。

(
SystemClock.sched(2.0, {
    "2.0 seconds later".postln; // 这可以是任何代码，包括创建 Synth
    nil // 这意味着不要重复
});
)

在 SC3 中，基于时间的事件序列可以用 Routine 实现。产生数值的 Routine 可以使用时钟进行调度：

(
var w, r;

w = Window.new("trem", Rect(512, 256, 360, 130));
w.front;

r = Routine({ arg time;
    60.do({ arg i;
        0.05.yield; // 等待 0.05 秒
        {
            w.bounds = w.bounds.moveBy(10.rand2, 10.rand2);
            w.alpha = cos(i*0.1pi)*0.5+0.5;
        }.defer;
    });
    1.yield; // 关闭 w 前等待 1 秒
    w.close;
});

SystemClock.play(r);
)

请注意，此实现避免了 SC2 方法中一个较为奇怪的方面：即使不涉及音频，也需要启动一个 Synth 来调度基于时间的行为。

SystemClock 和 AppClock（一个精度较低、可以调用 Cocoa 原语的版本）都只有类方法。因此不需要创建它们的实例。如果你需要一个可单独操作的时钟（例如操作不同事件序列的速度），可以使用 TempoClock。

下面展示了一个简单的 SC2 Spawn 示例，随后是其转换为 SC3 风格代码的版本。

// 这在 SC3 中不会执行
(
Synth.play({
    Spawn.ar(
        { EnvGen.ar(Env.perc) * SinOsc.ar(440,0,0.1) },
        1, // 一个声道
        1 // 每秒一个新事件
    )
})
)

// SC3 中的同一示例（将执行）
s.boot;
(
SynthDef("help-EnvGen",{ arg out = 0;
    Out.ar(
        out,
        EnvGen.kr(Env.perc,1.0,doneAction: Done.freeSelf) * SinOsc.ar(440,0,0.1)
    )
}).send(s);
)

(
r = Routine.new({ { Synth.new("help-EnvGen"); 1.yield; }.loop }); // 每秒循环一次
SystemClock.play(r);
)

注意，上面的示例使用了预编译的 SynthDef。与 SC2 风格的 Spawning 相比，这样在创建 Synth 时 CPU 峰值更低。如有必要，也可以动态创建 SynthDef，但通过参数或诸如 Rand 和 TRand 之类的 UGen 就能实现大量变化。更多细节参见 SuperCollider 3 versus SuperCollider 2: SynthDefsVsSynths 一节。

// 即时生成 SynthDef
s.boot;
(
t = TempoClock.new;
r = Routine.new({
    10.do({
        // 可以用参数而不是新的 def 来实现，但这里是为了说明问题
        SynthDef("help-EnvGen" ++ i, { arg out = 0;
            Out.ar(
                out,
                EnvGen.kr(Env.perc, 1.0, doneAction: Done.freeSelf)
                * SinOsc.ar(100 + (100 * t.elapsedBeats), 0, 0.1)
            )
        }).play(s);
        1.yield;
    });
}).play(t); // 注意另一种语法：Routine.play(aClock)
)

请注意播放 Routine 的另一种语法。aClock.play(aRoutine) 与 aRoutine.play(aClock) 在功能上是等价的。两者分别在不同方面带来或多或少的便利，例如向 Routine 或 Clock 发送消息。（更详细的讨论请参见 play 帮助文件。）例如：

(
// 这个、那个以及其他
r = Routine.new({var i = 0; { ("this: " ++ i).postln; i = i + 1; 1.yield; }.loop });
q = Routine.new({var i = 0; { ("that: " ++ i).postln; i = i + 1; 1.yield; }.loop });
t = Routine.new({var i = 0; { ("the other: " ++ i).postln; i = i + 1; 1.yield; }.loop });
)

SystemClock.play(r);    // 启动这个
SystemClock.play(q);    // 启动那个
SystemClock.play(t);    // 启动另一个

r.stop;            // 停止这个，但不停止那个或另一个
q.reset;        // 在播放时重置它

c = TempoClock.new;    // 创建一个 TempoClock
r.reset;        // 必须重置它，因为它已停止
c.play(r);        // 在新的时钟中播放此内容；从头开始
c.tempo = 16;        // 提高这个的速度

SystemClock.clear;    // 清除 SystemClock 中调度的所有内容；这样那个和其他
            // 但不是这个

c.clear;        // 清除 c 中所有已调度内容，即此内容
c.play(r);        // 由于它没有被停止，我们不必重置它
            // 并且它会从上次中断处继续

c.stop;            // 停止 c，销毁其调度器，并释放其 OS 线程

为方便起见，可暂停的调度可以用 Task 实现。Task.new 接受两个参数，一个函数和一个时钟，并创建自己的 Routine。如果不指定时钟，它会为你创建一个 TempoClock。由于不必显式创建 Clock 或 Routine，使用 Task 可以使代码稍微更紧凑。

(
t = Task.new({
    inf.do({ arg i;
        i.postln;
        0.5.wait
    });
});
)

t.start;        // 启动它
t.stop;            // 停止它
t.start;        // 从头重新开始
t.reset;        // 即时重置
t.stop;            // 再次停止
t.resume;        // 从上次中断处重新开始
t.clock.tempo = 0.25;    // 获取 Task 的时钟并改变速度。这之所以有效，是因为
            // 默认是 TempoClock。
t.pause;        // 与 t.stop 相同

TSpawn 的功能可以用 SendTrig 和 OSCFunc 来复现。有关它们的参数和功能的详细信息，请参阅各自的帮助文件。

s.boot;
(
// 这个 Synth 将向客户端应用发送一个触发
SynthDef("help-SendTrig", {
    SendTrig.kr(
        Dust.kr(1.0), // 触发可以是任何东西，例如 Amplitude.kr(SoundIn.ar(0) > 0.5)
        0, 0.9
    );
}).send(s);
)

(
// 这在客户端接收触发，并在服务器上“生成”一个新的 Synth
OSCFunc({
    SynthDef("help-EnvGen", { arg out = 0;
        Out.ar(
            out,
            EnvGen.kr(Env.perc, 1.0, doneAction: Done.freeSelf)
            * SinOsc.ar(440, 0, 0.1)
        )
    }).play(s);
}, '/tr', s.addr);

// 开始“生成”
Synth("help-SendTrig");
)
