Document

编辑器专用的文本文档编辑

参见：EmacsDocument、ScelDocument

说明

Document 类表示文本编辑环境上下文中的文本文档。你可以使用该类以编程方式创建、修改和查询这些文档。

Document 曾经是一个抽象类，这意味着它本身并不提供全部功能，而是依靠子类来补全功能。其中一个这样的子类就是 CocoaDocument。尽管 CocoaDocument 仅适用于 macOS，且接口是临时拼凑的，但它拥有许多附加特性，比如代码动画和富文本。

在 SuperCollider 3.6 中，Document 发生了一些变化，现在“抽象类”的描述只部分正确。SuperCollider IDE 提供了它自己的 Document 类版本。Emacs 编辑器仍然提供 ScelDocument（它链接到 EmacsDocument）作为 Document 的子类。作为 Document 历史的不幸副产品，SCIDE 的 Document 与 Emacs 的 ScelDocument 在 API 上存在不一致。本帮助文件描述的是 SCIDE 的版本。

SuperCollider 的未来版本将致力于修复这些 API 不一致之处，并恢复 CocoaDocument 的功能。

设置环境

默认情况下，envir 被设为当前的 Environment。不过，你也可以让它使用自己的 Environment。因此，例如，如果你在当前 Environment 中设置了 Environment 变量 ~myVar = 12，你便可以创建一个新的 Document 窗口，在其中该 Environment 变量未被设置。

类方法

.new

参数：

title

String 或 Symbol 的实例。

string

String 的一个实例。文档的内容。

envir

Environment 的一个实例。供文档窗口的解释器使用的 Environment。默认情况下，它被设置为当前的 Environment。

讨论：

Document.new("this is the title", "this is the text");

.open

从路径打开文档。

参数：

path

文档的文件系统路径。一个 String 的实例。

selectionStart

文件内容光标选择的起始位置。

selectionLength

文件内容的光标选择长度。

envir

Environment 的一个实例。供文档窗口的解释器使用的 Environment。默认情况下，它被设置为当前的 Environment。

讨论：

另请参阅下方的 Document: save。

Document.open("README", 292, 253); // 注意打开文档中选中的文本

.openDocuments

返回所有打开文档的数组。

d = Document.openDocuments.do{ |doc| doc.name.postln };

.hasEditedDocuments

如果存在已编辑的 Document，则返回 true。

.closeAll

警告： 关闭所有打开的 Document，无论是否已编辑。

参数：

leavePostWindowOpen

Boolean 的实例。

.closeAllUnedited

关闭所有未编辑的 Document。

参数：

leavePostWindowOpen

Boolean 的实例。

.current

获取/设置当前 Document。

参数：

value

一个 Document。

讨论：

Document.current.name.postln; // 打印 "Document.html"

.allDocuments

返回所有文档。

.globalKeyDownAction

获取/设置按键时执行的全局动作。

参数：

action

Function 或 FunctionList 的实例。

.globalKeyUpAction

获取/设置按键释放时要执行的全局动作。

参数：

action

Function 或 FunctionList 的实例。

.initAction

获取/设置 A 在打开或创建 Document 时要执行的动作。

参数：

action

Function 或 FunctionList 的实例。

.autoRun

如果 autoRun 设置为 true，以注释 /*RUN*/ 开头的文档将在打开后立即执行，并且在类库重新编译且该文档已在 IDE 中打开时也会执行。

参数：

value

一个 Boolean 的实例。默认值为 true。

.implementationClass

处理 Documents 的编辑器实现特定类。

参数：

value

用于实现 Document 的类。

路径实用工具

用于处理文档（如 SuperCollider 代码文件）的实用工具和设置。默认情况下，文档目录是 SuperCollider 的应用程序目录。

.dir

获取/设置默认文档目录。默认值取决于 *implementationClass。

参数：

path

目录的文件系统路径。一个 String 的实例。

讨论：

在 Main-startUp 中，你可以将其设置为更实用的目录：

Document.dir = "~/Documents/SuperCollider";

.standardizePath

参数：

p

目录的文件系统路径。一个 String 的实例。

讨论：

如果它是相对路径，则相对于你的文档目录将其展开为绝对路径。展开路径中的波浪号（你的主目录），解析符号链接（但不解析别名）。还会从 Mac OS 9 路径格式进行转换。更复杂的需求请参见 PathName。

Document.standardizePath("~/"); // 这将打印你的主目录

Document.standardizePath(":Patches:newfoots:fastRuckAndTuck");
// 返回：/Volumes/Macintosh HD/Users/cruxxial/Documents/SC3docs/Patches/newfoots/fastRuckAndTuck

Document.standardizePath("~/Documents/SC3docs/Patches/newfoots/fastRuckAndTuck");
// 返回：Patches/newfoots/fastRuckAndTuck

Document.standardizePath("Patches/newfoots/fastRuckAndTuck")
// 返回：Patches/newfoots/fastRuckAndTuck

.abrevPath

如果路径位于 Document.dir 内，则返回相对于 Document.dir 的路径。

参数：

path

目录的文件系统路径。一个 String 的实例。

控制文档

.close

关闭文档。

(
Task({
    var doc;
    doc = Document("background", "closing in 2 seconds");
    2.wait;
    doc.close;
}).play(AppClock);
)

.save

保存此文档。

参数：

docPath

一个可选的 String 实例，指示保存 Document 的路径。如果未提供路径，则使用当前路径（如果之前已保存或读取过）。成功保存后，此 Document 的路径将在需要时更新。另请参见上文的 Document: *open。

d = Document.new("testSave", "foo");
d.save(Platform.defaultTempDir ++ "foo.scd"); // 保存在临时目录中
d.string_("foobar", 0, 3);
d.save; // 保存到之前的路径
d.string_("save as now", 0, 6);
d.save(Platform.defaultTempDir ++ "savedAs.scd");
d.path;

参数：

Function 或 FunctionList 的实例。传递给该函数的参数为：document、x、y、modifiers、buttonNumber。

讨论：

(

// 为此文档添加鼠标操作：
// 示例：简单按钮：
// 当你在 17 前面点击时，将启动一个 SinOsc；
s.waitForBoot({
    Document.current.mouseUpAction_({ |doc|
        var char;
        char = doc.rangeText(doc.selectionStart, 2);
        if(char == "17", {
            { EnvGen.kr(Env.perc, doneAction: Done.freeSelf) * SinOsc.ar([600, 720, 300].choose, 0, 0.5) }.play;
        });
        if(char == "23", {
            { EnvGen.kr(Env.perc, doneAction: Done.freeSelf) * PinkNoise.ar(0.2) }.play;
        });
    })
});
)

在此测试并点击数字前面的位置：17 和 23。

Document.current.mouseUpAction = nil; // 清除 mouseUpAction

.getText

从文档中获取一段文本。同步操作。文本直接返回。

参数：

start

一个整数，表示要访问的起始位置。

range

一个 Integer，表示要获取的字符数。-1 表示获取到文档末尾。

.getTextAsync

从文档中获取一段文本。异步。文本作为参数传递给 action 函数。

注意： 目前在 Windows 上，-getText 和 -string 可能不可靠。建议 Windows 用户暂时使用 -getTextAsync。

参数：

action

在请求完成后要执行的一个函数。它会被传入一个参数，即用于所获取内容的 String。

start

一个整数，表示要访问的起始位置。

range

一个 Integer，表示要获取的字符数。-1 表示获取到文档末尾。

示例

(
var doc;
doc = Document("", "||");

Task({
    1000.do({
        0.08.wait;
    })
}).play(AppClock);

Task({
    100.do({
        1.01.wait
    })
}).play(AppClock);

Task({
    100.do({
        1.01.wait;
        doc.selectedString_(["\"\n#", "||", "-", "--"].choose);
    })
}).play(AppClock);

Task({
    var co, mul;
    co = 0.1;
    mul = 1.02;
    100.do({
        0.16.wait;
        co = co * mul;
        if(co > 0.99, { co = 0.1 });
    });
    doc.close;
}).play(AppClock)
)

TBT（基于时间的文本）的简单实现 http://tbt.dyne.org/?info=download

// record: 输入一些文本
(
var time = Main.elapsedTime;
a = List.new;
r = Routine { |char|
loop {
    a = a.add([char, Main.elapsedTime - time]);
    char = 0.yield;
}
};

Document.new("type some text")
    .keyDownAction = { |doc, key| r.value(key) ; time = Main.elapsedTime };
)

// 按时回放文本
(
d = Document.new("type some text");
fork({
    a.do { |pair|
        d.string = d.string ++ pair[0];
        pair[1].wait;
    }
}, AppClock)
)
