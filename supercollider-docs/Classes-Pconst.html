Pconst

约束值模式的总和

FilterPattern : Pattern : AbstractFunction : Object

另请参见：Pfindur、Pfin、Pfinval

说明

与 Pfindur 类似，但直接对值进行操作。

注意： 如果直接或间接地将其用于音符长度参数，请小心！差异可能非常小，而且由于 EnvGen 中针对极短延音时间的 bug，这可能导致僵尸节点。

类方法

Pconst.new(sum, pattern, tolerance: 0.001)

将 pattern 的元素嵌入流中，直到总和足够接近 sum。此时，将指定总和与实际运行总和之间的差值嵌入。
