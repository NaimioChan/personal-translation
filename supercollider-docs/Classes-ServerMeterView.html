ServerMeterView

显示输入/输出电平的 GUI 部件

另请参见：ScopeView、FreqScopeView、ServerMeter

说明

ServerMeterView 是一个模块化小部件，用于显示服务器上输入/输出的音量电平。ServerMeterView 可以像按钮或滑块一样嵌入到你自定义的图形用户界面中。

注意： 如果你在寻找无需从头构建自己的 GUI 的快速输入/输出电平显示，请参见 ServerMeter 和 Server: -meter

类方法

.height

获取标准 ServerMeterView 控件的高度（以像素为单位）

返回值：

一个 Integer

.getWidth

获取具有给定输入和输出数量的 ServerMeterView 部件的像素宽度

参数：

numIns

用于计算宽度的输入数量

numOuts

用于计算宽度的输出数量

server

服务器

返回值：

一个 Integer

.new

创建一个新的 ServerMeterView 实例

参数：

aserver

其输入/输出将被监视的 Server

parent

父级 View 或 Window，新的 ServerMeterView 将嵌入其中。

leftUp

新的 ServerMeterView 在父容器中的放置位置。leftUp 必须是一个 Point，用于描述新的 ServerMeterView 左上角应放置的位置。

numIns

要监视的输入数量

numOuts

要监听的输出数量

返回值：

一个新的 ServerMeterView

实例方法

.view

获取用于构建 ServerMeterView 控件各个元素的 CompositeView

返回值：

一个 CompositeView

.remove

将此 ServerMeterView 从其父视图（如果有）中移除，然后销毁它。一旦调用此方法，你就不能再使用此 ServerMeterView。

.start

启用输入/输出的监听

返回值：

这个 ServerMeterView

.stop

禁用输入/输出监听

返回值：

这个 ServerMeterView

示例

简单用法

// 创建一个窗口并在其中嵌入 ServerMeterView。
w = Window.new("Server Levels");
ServerMeterView.new(s, w, 0@0, 2, 2);
w.front; // 显示窗口

一个更复杂的示例

// 制作一个 GUI 来监控同时运行的两个服务器
s = Server.local;
q = Server.internal;
s.boot; q.boot; // 稍等片刻，等待服务器启动

// 创建一个足够大的窗口以容纳 2 个 ServerMeterView
r = Rect(0, 0, ServerMeterView.getWidth(2, 2) * 2, ServerMeterView.height)
w = Window.new("Local | Internal", r);

// 创建一个 ServerMeterView 来监视每个服务器的输入/输出
ServerMeterView.new(s, w, Point(0, 0), 2, 2);
ServerMeterView.new(q, w, Point(ServerMeterView.getWidth(2, 2), 0), 2, 2);
w.front; // 显示窗口
