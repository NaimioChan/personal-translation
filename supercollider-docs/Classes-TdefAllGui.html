TdefAllGui

查看所有 Tdef 及其状态

另请参阅：TdefGui、PdefGui、PdefAllGui

说明

TdefAllGui 使用 TdefGui 视图来显示所有 Tdef，或一个选择。

概述：JITLib

类方法

Creation

.new

参数：

numItems

可显示的最大 Pdef 数量。

parent

用于显示的父视图。如果为 nil，则创建一个新窗口；parent 也可以是一个已存在的窗口或复合视图。

bounds

用于显示 JITGui 的期望尺寸和位置。可以为 nil、一个 Point 或一个 Rect。JITGui 知道自己的最小尺寸（minSize），如果 bounds 为 nil，则使用 minSize。如果 bounds 是一个 Point 或 Rect，它将被设置为至少 minSize。使用 Rect 时还可以提供显示位置。如果是 Point，则显示的尺寸是 bounds 和 minSize 中的最大值。

makeSkip

///// 尚未完成，但在列表中

是否创建 skipjack 的标志。

options

///// 尚未完成，但在列表中

PdefAllGui 的唯一选项将是 [\makeEdit]。添加一个“front” PdefGui，同时也显示 front Pdef 的 envir。

实例方法

示例

(
Tdef(\a, { |e| 100.do { |i| i.postln; 0.5.wait } });
Tdef(\b, { |e| 100.do { |i| Tdef(\a).set(\otto, 8.rand); exprand(0.1, 3.0).wait } });
t = TdefAllGui(8);
)

    // 如果你有太多 Tdef，可以用 ezscroller 来选择
"abcdefghijk".do { |ch| Tdef(ch.asSymbol) };

    // 你还可以过滤出你看到的内容：
Tdef(\a_otti);
Tdef(\a_hannerl);
Tdef(\a_dede);

    // 或更好地从 GUI 进行
t.filtering_(true);
t.prefix_("a_");

    // 如果前缀是 ""，它将过滤任何包含 "_" 的内容。
t.prefix_("");
t.filtering_(false);
