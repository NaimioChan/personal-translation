EnvelopeView

带节点和连接的可配置视图

另请参见：MultiSliderView、SCEnvelopeEdit

说明

一个能以 x/y 坐标图形式显示节点、连接线、交叉连接、节点标记和标签的视图。这些项的所有值都存储在数组中。虽然此视图通常用于制作可编辑的包络界面，但它也能用来绘制非常复杂的互连图。

你可以让该视图使用 Env 通过 -setEnv 来显示。但请注意，该视图操作的是 Env 对象数据的副本，因此通过视图移动节点不会影响原来的 Env。

你还可以使用 -value 定义具有 x 和 y 值数组的节点，并使用 -connect 定义连接。

Appearance

该视图支持两种显示样式：默认样式将节点绘制为小圆点，标签绘制在节点旁边；另一种样式将节点绘制为圆角矩形，标签绘制在内部。参见 -style。

每个节点的标签可以使用 -strings 和 -setString 设置。

Interaction

可以使用鼠标选择和移动节点。按住 Shift 单击节点会将其添加到选择中。

你也可以用键盘移动选中的节点并更改选择。按方向键将移动选中的节点（只要 -step 大于 0）。按住 Alt 的同时按左方向键或右方向键将选择上一个或下一个节点，按住 Shift 将把选择范围向左或向右扩展。其他 GUI 套件可能有所不同。

-keepHorizontalOrder 允许你强制节点在水平方向上的顺序与其索引顺序相匹配。在这种情况下，节点向左和向右的移动将受到其相邻节点位置的限制。当 EnvelopeView 用于显示 Env 时，这尤其有用。

-elasticSelection 决定在移动多个节点时，如果其中任何节点遇到障碍（视图边界或相邻节点），是整体全部阻止移动，还是只阻止那些单独的节点。

节点选择也可以通过编程方式使用 -index、-selectIndex 和 -deselectIndex 进行更改。当前节点可以使用 -x 和 -y 以编程方式移动。

类方法

实例方法

Data

.setEnv

设置一个由视图显示的 Env。视图将从 Env 对象中提取数据以显示（时间、值和曲线类型）。

在调用此方法之前存在的任何节点都将被移除。

参数：

一个 Env。

.value

value 获取节点位置，返回一个格式如下方 Argument 的数组。value_(anArray) 设置节点位置，若节点不存在则创建它们。

如果已经存在节点，且其数量与参数中 x/y 对的数量不同，则将添加或移除节点（按创建顺序反向），直到数量匹配，然后应用新值。

参数：

一个包含另外两个数组的数组，其中一个包含新节点的水平位置，另一个包含垂直位置。值必须在 0 与 1 之间。例如：[[x1, x2, x3, ...], [y1, y2, y3, ...]]

.valueAction

将 -value 设置为参数并触发 -action。

.x

当前节点的水平位置。

参数：

一个 0 到 1 之间的浮点数。

.y

当前节点的垂直位置。

参数：

一个 0 到 1 之间的浮点数。

.currentvalue

-y 的同义词。

.curves

节点之间连接形状。有关描述形状的有效对象，请参见下文。

如果给定单个形状，它将应用于所有现有节点。如果给定形状数组，则其每个元素将按索引顺序应用于一个现有节点。

应用于节点的连接曲线形状将决定从该节点起始的连接的形状。如果没有使用 -connect 创建任何连接，则连接的起始节点是索引较小的那个。但如果有此类连接，则其起始节点是作为第一个参数传递给 -connect 的节点。

参数：

用于描述形状的有效对象列在 Env: *new 中。参数可以是单个值，也可以是这些值的数组。

.strings

节点的标签。

注意： 为了使标签可见，你可能需要确保 -strokeColor 与 -fillColor 形成对比（取决于视图绘制节点和标签的方式）。

参数：

一个 String 数组。

.setString

设置给定索引处节点的标签。

注意： 为了使标签可见，你可能需要确保 -strokeColor 与 -fillColor 形成对比（取决于视图绘制节点和标签的方式）。

参数：

index

节点的索引。

string

一个 String。

.setFillColor

设置用于绘制给定索引处节点内部的颜色。

参数：

index

一个 Integer。

color

一个 Color。

.setThumbWidth

设置给定索引处节点的宽度。

注意： 为兼容现有代码，这会将 -style 设置为 'rects'。

参数：

index

一个 Integer。

width

一个 Integer。

.setThumbHeight

设置给定索引处节点的高度。

注意： 为兼容现有代码，这会将 -style 设置为 'rects'。

参数：

index

一个 Integer。

height

一个 Integer。

.setThumbSize

将给定索引处节点的宽度和高度都设置为 size。

参数：

index

一个 Integer。

size

一个 Integer。

.connect

移除设置 -value 时创建的所有连接，然后从第一个参数中给定索引处的节点向第二个参数中给定各索引处的每个节点创建新连接。

参数：

source

一个 Integer——作为所有新连接一端的节点索引。

targets

一个整数数组——节点索引，每个索引将成为所创建的新连接的第二端。

.selection

返回所有已选节点索引的数组。

Appearance

.style

以下绘图样式之一：

  • 'dots' - 节点被绘制为一个小圆点，位于指示鼠标敏感区域的大圆内。标签绘制在圆点旁边（参见 -setString）。此样式始终以相等的宽度和高度绘制节点，如果节点尺寸不同，将使用较小的尺寸（它绝不会绘制椭圆）。
  • 'rects' - 节点绘制为圆角矩形。标签绘制在矩形的边界内。

注意： 为了与现有代码兼容，调用 -thumbWidth、-thumbHeight、-setThumbWidth 或 -setThumbHeight 中的任何一个都会自动将样式切换为 'rects'。之后你仍然可以设置不同的样式。

参数：

符号之一：\dots 或 \rects。或者，分别为每种样式使用整数 0 或 1。

返回值：

一个 0 或 1 的整数。

.drawLines

是否绘制节点之间的连接。

参数：

一个布尔值。

.drawRects

是否绘制节点

参数：

一个布尔值。

.gridOn

是否绘制网格。

参数：

一个布尔值。

.grid

网格的分辨率。

参数：

一个 Point，其 x 和 y 分别对应于水平轴和垂直轴上的网格间距。如果两者之一为 0，则该轴上的网格将不会被绘制。

.thumbWidth

设置所有节点的宽度。

注意： 为兼容现有代码，这会将 -style 设置为 'rects'。

参数：

一个 Integer。

.thumbHeight

设置所有节点的高度。

注意： 为兼容现有代码，这会将 -style 设置为 'rects'。

参数：

一个 Integer。

.thumbSize

将 -thumbWidth 和 -thumbHeight 都设置为该参数。

.strokeColor

用于绘制连接和节点标签的颜色。

参数：

一个 Color。

.fillColor

用于绘制节点的默认颜色。如果已使用 -setFillColor 设置了特定节点的颜色，则该颜色优先。

参数：

一个 Color。

.selectionColor

节点被选中时的颜色。

参数：

一个 Color。

.gridColor

网格的颜色。

参数：

一个 Color。

.colors

分别将 -strokeColor 和 -fillColor 设置为对应的参数。

Interaction

.index

当前节点的索引，即受 -x 和 -y 方法影响的节点。

这是索引最低的选中节点，如果没有选择则为 -1。

参数：

一个 Integer。

.lastIndex

最后选中的节点，无论当前选择状态如何；如果尚未选中任何节点，则为 -1。

.selectIndex

选择给定索引处的节点并将其设为当前节点，即 -currentvalue 将与该节点相关。作为特殊情况，如果参数为 -1，则所有节点都将被取消选择。

参数：

一个 Integer。

.deselectIndex

取消选中给定索引处的节点。

注意： 在 Cocoa GUI 中不可用。

参数：

一个 Integer。

.editable

是否有任何节点可编辑。

参数：

一个布尔值。

.setEditable

设置给定索引处的节点是否可编辑。无论如何，除非 -editable 为 true，否则没有任何节点会是可编辑的。

参数：

index

一个 Integer。

flag

一个布尔值。

.step

使节点吸附（即量化）到该参数最近的倍数。除非此值大于 0，否则节点将无法使用键盘移动。

参数：

一个 Float。

.keepHorizontalOrder

节点在水平轴上的位置是否应受其紧邻节点（按索引顺序）的限制。

将其设为 true 将立即修改现有节点的位置以匹配该顺序。

参数：

一个布尔值。

.elasticSelection

当使用鼠标或键盘移动所选内容时，所选内容中节点的相对位置是否可以改变，以便适应障碍物（视图边界，或者当 -keepHorizontalOrder 为 true 时，相邻节点）。

如果为 false，遇到障碍物时多个节点的移动将整体被阻止，否则只有个别节点会在其障碍物处被阻止。

参数：

一个布尔值。

Actions

.action

用户移动节点时求值的行为对象。

.metaAction

当用户在按下 Ctrl 键的同时移动节点时求值的动作对象。

.defaultKeyDownAction

实现按键时的默认行为。

默认行为定义在视图的 C++ 实现中，而不是此方法中。关于如何覆盖该行为的说明，请参见 View: Key and mouse event processing。

拖放

.defaultGetDrag

返回值：

该 -value。

.defaultCanReceiveDrag

返回值：

对任何拖动数据都为真，但数据格式应与 -value 相同。

.defaultReceiveDrag

若拖拽数据为可接受的形式（参见上文的 -defaultCanReceiveDrag），则使用该数据设置 -value。

示例

用作包络视图

(
// 使用 shift 点击来保持节点处于选中状态
w = Window("envelope", Rect(150, Window.screenBounds.height - 250, 250, 100)).front;
w.view.decorator = FlowLayout(w.view.bounds);

b = EnvelopeView(w, Rect(0, 0, 230, 80))
    .drawLines_(true)
    .selectionColor_(Color.red)
    .drawRects_(true)
    .resize_(5)
    .step_(0.05)
    .action_({ |b| [b.index, b.value].postln })
    .thumbSize_(5)
    .value_([[0.0, 0.1, 0.5, 1.0], [0.1, 1.0, 0.8, 0.0]]);
w.front;
)

// 显示网格
b.grid = Point(0.2, 0.2);
b.gridOn_(true);

// 显示 Env
b.setEnv(Env.asr(0.5, 1, 0.2));

// 使第一个点不可移动
(
b.setEditable(0, false);
)

按住 Shift 点击以选择/取消选择点

(
w = Window("envelope", Rect(150, Window.screenBounds.height - 250, 400, 150)).front;
w.view.decorator = FlowLayout(w.view.bounds);

b = EnvelopeView(w, Rect(0, 0, 350, 100))
    .thumbSize_(5)
    .drawLines_(true)
    .fillColor_(Color.green)
    .selectionColor_(Color.red)
    .drawRects_(true)
    .value_([(0.0, 0.1 .. 1.0), (0.0, 0.1 .. 1.0)])
    .setEditable(0, false);
)

(
r = Routine({
    var j = 0;
    20.do({ |i|
        b.selectIndex((b.size - 1).rand.abs);
        0.1.wait;
        b.x_(1.0.rand.abs);
        b.y_(1.0.rand.abs);
    });
    b.selectIndex(-1);
});
AppClock.play(r);
)

显示包含字符串的方框：

(
a = Window("text-boxes", Rect(200, 450, 450, 450));
a.view.decorator = FlowLayout(a.view.bounds);

b = EnvelopeView(a, Rect(0, 0, 440, 440))
    .thumbWidth_(60.0)
    .thumbHeight_(15.0)
    .drawLines_(true)
    .drawRects_(true)
    .selectionColor_(Color.red)
    .value_([[0.1, 0.4, 0.5, 0.3], [0.1, 0.2, 0.9, 0.7]]);
4.do({ |i|
    b.setString(i, ["this", "is", "so much", "fun"].at(i));
    b.setFillColor(i, [Color.yellow, Color.white, Color.green].choose);
});
a.front;
)

(
b.connect(3, [2.0, 0.0, 1.0]); // 文本对象可以连接
b.connect(0, [2.0, 3.0, 1.0]);
)
