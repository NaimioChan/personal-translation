EnvGen

包络发生器

UGen : AbstractFunction : Object

另请参见：Linen、Env

说明

播放折点包络。包络是 Env 类的实例。当 EnvGen 被触发时，以及在新包络段开始时，会轮询包络以及 levelScale、levelBias 和 timeScale 的参数。所有值在每个段的持续时间内保持不变。

{ PinkNoise.ar(EnvGen.kr(Env.perc, doneAction: Done.freeSelf)) }.play

类方法

EnvGen.ar(envelope, gate: 1.0, levelScale: 1.0, levelBias: 0.0, timeScale: 1.0, doneAction: 0)

EnvGen.kr(envelope, gate: 1.0, levelScale: 1.0, levelBias: 0.0, timeScale: 1.0, doneAction: 0)

参数：

envelope

一个 Env 实例，或一个 Control 数组。（关于如何使用，参见 Control 及下面的示例。）

当 EnvGen 被触发时以及在新包络段开始时，会对包络进行轮询。Env 的输入可以是其他 UGen。

gate

这会触发包络，并在 > 0 期间保持其打开。如果 Env 是固定长度的（例如 Env.linen、Env.perc），gate 参数会被用作简单的触发器。如果它是延音包络（例如 Env.adsr、Env.asr），则包络会保持打开，直到 gate 变为 0，此时它会被释放。

如果 gate < 0，则以时间 -1.0 - gate 强制释放。参见下方的强制释放。

levelScale

断点的电平值会乘以该值。该值可以被调制，但只会在新包络段的起始处采样。

levelBias

该值作为偏移量加到断点的电平上。该值可以被调制，但只会在新包络段的起始处采样。

timeScale

各段的时长会乘以该值。该值可以被调制，但只会在新包络段的起始处采样。

doneAction

一个整数，表示当包络播放结束时执行的操作。这可用于释放包含它的 synth 等。更多细节请参见 Done。

讨论：

注意： 段的实际最短持续时间并非零，而是音频速率下的一个采样步长和控制速率下的一个块。当两个层数不同的包络的总持续时间相同时，可能导致不同步。同样，在调制时间时，新时间只会在当前段结束时更新——这可能导致两个具有调制时间的包络不同步。

// 作为振幅包络
(
{
    var env = Env([0, 1, 0.5, 1, 0], [0.01, 0.5, 0.02, 0.5]);
    SinOsc.ar(470) * EnvGen.kr(env, doneAction: Done.freeSelf)
}.play
)

// 作为振幅和调制包络
(
{
    var env = Env([0, 1, 0.5, 0.8, 0, 1.2, 0], [0.01, 0.5, 0.02, 0.5, 0.2, 0.5]);
    var gate = Impulse.kr(MouseX.kr(0.2, 3), 0.5);
    var gen = EnvGen.kr(env, gate);
    SinOsc.ar(270, SinOsc.ar(gen * 473)) * gen * 0.2
}.play
)
// EnvGen 在传入多通道包络时会进行多通道扩展
(
{
    SinOsc.ar(
        EnvGen.kr(
            Env.circle([0, 1, 0, (2..4), 0, LFNoise1.kr(0.1 ! 5) * 10, 0], [0.01, 0.6])
        )
        * 240 + 300
    ).sum * 0.2
}.play;
)

// 由 Dust 重新触发的包络
(
{
    var env = Env([0.0, 0.5, 0.0, 1.0, 0.9, 0.0], [0.05, 0.1, 0.01, 1.0, 1.5], -4);
    var envgen = EnvGen.ar(env, Dust.ar(1));
    SinOsc.ar(
        envgen * 1000 + 440
    ) * envgen * 0.1
}.play
);

// 两个声道
(
{
    var env = Env([0.0, [-0.2, 0.5], 0.0, 1.0, [-0.4, 0.9], 0.0], [0.05, 0.1, 0.01, 1.0, 1.5], -4);
    var envgen = EnvGen.ar(env, Dust.ar([1, 1]));
    SinOsc.ar(
        envgen * 440 + 550
    ) * envgen * 0.1
}.play
);

// SynthDef 中的包络可用于限制 synth 的生命周期（doneAction: Done.freeSelf）

(
SynthDef(\env_help, { |out, gate = 0, freq = 440|
    var z;
    z = EnvGen.kr(Env.perc, doneAction: Done.freeSelf) * SinOsc.ar(freq, 0, 0.1);
    Out.ar(out, z)
}).add;
)

(
fork {
    10.do {
        Synth(\env_help);
        0.2.rand.wait;
    }
}
)


// 使用门控包络来门控声音：
(
SynthDef(\env_help, { |out, gate = 0, freq = 440, doneAction = 0|
    var z = EnvGen.kr(Env.adsr, gate, doneAction: doneAction) * SinOsc.ar(freq, 0, 0.1);
    Out.ar(out, z)
}).add;
)

a = Synth(\env_help);


// 打开
a.set(\gate, 1);

// 关闭
a.set(\gate, 0);

// gate 被设成什么值无关紧要，只要它 > 0
a.set(\gate, 2);

a.set(\doneAction, 2, \gate, 0); // 将 doneAction 设置为二，让 synth 自行释放

a.free; // 或者，直接释放它。

为每个新 synth 指定一个包络

(
SynthDef(\help_Env_newClear, { |out = 0|
    var env, envctl;
    // 创建一个空的 4 段包络
    env = Env.newClear(4);
    // 创建一个控制参数数组
    envctl = \env.kr(env.asArray);
    Out.ar(out,
        SinOsc.ar(EnvGen.kr(envctl, \gate.tr), 0, 0.3) // gate 控件是一个触发器
    );
}).add;
)

Synth(\help_Env_newClear, [\gate, 1, \env, Env([700, 900, 900, 800], [1, 1, 1], \exp)]); // 3 个段

// 重置然后再次播放：
Synth(\help_Env_newClear, [\gate, 1, \env, Env({ rrand(60, 70).midicps } ! 4, [1, 1, 1], \exp)]);

// 同样内容写成事件形式：
(instrument: \help_Env_newClear, gate: 1, env: Env({ rrand(60, 70).midicps } ! 4, [1, 1, 1], \exp)).play;

强制释放

如果将 EnvGen 的门限设为 -1 或更低，则包络会立即截断。截断所需的时间为低于 -1 的量，其中 -1 表示尽可能快，-1.5 表示在 0.5 秒内截断，依此类推。截断的形状和最终值从 Env 的最后一个节点读取。

(
SynthDef(\stealMe, { |out, gate = 1|
    Out.ar(out, { BrownNoise.ar }.dup * EnvGen.kr(Env.asr, gate, doneAction: Done.freeSelf))
}).add;
)

a = Synth(\stealMe);
a.release(3); //  // 3 秒内截止

// OSC 数据的结构如下：
s.sendMsg(\s_new, \stealMe, 1001, 1, 0);
s.sendMsg(\n_set, 1001, \gate, -1.1); // 在 0.1 秒内截止

如果 synthDef 有一个名为 "gate" 的参数，可以使用 Node 的便捷方法：node.release(releaseTime)

d = { |gate = 1| { BrownNoise.ar }.dup * EnvGen.kr(Env.asr, gate, doneAction: Done.freeSelf) }.play;
d.release(3);

强制释放会忽略多节点释放阶段，始终执行单节点释放，从 Env 的最后一个节点读取曲线和结束值，并覆盖其时长。

(
// 一个具有多节点释放阶段的 Synth
d = { |gate = 1|
    var env = Env([0, 1, 0, 0.5, 0], 0.5, -4, releaseNode: 1);
    { BrownNoise.ar }.dup * EnvGen.kr(env, gate, doneAction: Done.freeSelf)
}.play;
)
// 2 秒后强制释放：
// 结束值 (0) 和形状 (-4) 从包络的最后一个节点读取，节点 2 和 3 被跳过
d.release(2);

// 没有 releaseTime：常规释放阶段，如 env 中所定义（3 个节点）
d.release();

滤波器截止频率调制和初始包络电平

当使用包络来调制滤波器的截止频率/中心频率时，在较高共振设置下，较短的起音时间可能会产生音量尖峰。如果不希望出现此效果，并且滤波器的起音始终位于 Synth 的开头（播放模式时通常如此），则可以通过将包络的初始电平设置得更接近较短起音时间（低于约 0.05 秒）的目标电平来避免该伪影。

下面的例子展示了如何在 SynthDef 中实现这一点：0 到 0.05 秒之间的 attack 时间会产生介于 1.0（attack 时间 = 0 表示无 attack）与 0.0 之间的初始包络值。如果 attack 时间大于 0.05 秒，包络将从 0.0 开始。（包络介于 0.0 与 1.0 之间，并被映射到有效的频率范围。）

要听到（可能很响亮的）短起音伪影，请将 var envInit 行改为 var envInit = 0;。

(
a = Bus.control(s, 1);

Slider(nil, Rect(800, 200, 200, 25))
.action_({ |view| a.set(view.value.lincurve(0, 1, 0, 0.12, 4)) })
.front
.onClose_({ p.stop; a.free });

SynthDef(\test, { |out = 0, freq = 100, ffreq = 500, rq = 0.25, modFactor = 12, atk = 0, dcy = 0.12|
    // 改为 'envInit = 0' 以听到短起音伪影
    // 警告：envInit = 0 可能非常响
    var envInit = atk.linlin(0, 0.05, 1, 0);
    var filtEg = EnvGen.kr(Env([envInit, 1, 0], [atk, dcy], -4));
    var ampEg = EnvGen.ar(Env.linen(0.001, 0.2, 0.1), doneAction: 2);
    var sig = Saw.ar(freq);
    ffreq = ffreq * (1 + (filtEg * modFactor));
    sig = BLowPass4.ar(sig, ffreq, rq) * ampEg;
    Out.ar(out, (sig * 0.1).dup)
}).add;

p = Pbind(
    \instrument, \test,
    \freq, 100,
    \atk, a.asMap
).play;
)

以上仅适用于初始值。如果在 Synth 中间重新触发短促的起音，那么包络无法为重新起音调整低值（因为包络的初始值仅在 Synth 开始时使用一次，之后不再改动）。在这种情况下，请稍微延迟打开振幅包络以避免伪影。

(
Slider(nil, Rect(800, 200, 200, 25))
.action_({ |view| z.set(\atk, view.value.lincurve(0, 1, 0, 0.12, 4)) })
.front
.onClose_({ z.free });

z = SynthDef(\test, { |out = 0, freq = 100, ffreq = 500, rq = 0.25, modFactor = 12, atk = 0, dcy = 0.12|
    var trig = Impulse.kr(1);
    var filtEg = EnvGen.kr(Env([0, 1, 0], [atk, dcy], -4), trig);
    var ampEnvDelay = max(0, (0.05 - atk) * 0.1);
    var ampEg = EnvGen.ar(Env.linen(0.001, 0.2, 0.1), TDelay.kr(trig, ampEnvDelay));
    var sig = Saw.ar(freq);
    ffreq = ffreq * (1 + (filtEg * modFactor));
    sig = BLowPass4.ar(sig, ffreq, rq) * ampEg;
    Out.ar(out, (sig * 0.1).dup)
}).play;
)

注意： 这些伪影在 2024 年秋季之后的 SuperCollider 版本（3.14.x）中更为明显。在较早的版本中，EnvGen 的初始值位于第一段的中点，从而减小了初始起音的斜率。迁移到较新 SC 版本的代码可能需要采用上述调整之一。

更多示例

有关 a = Synth(\sine, [freq: f.asMap]); 行中使用的控制总线映射的更多信息，参见 Node: -map 和 Bus: -asMap。

// 播放过程中修改 Env
(
SynthDef(\env, { |i_outbus = 0|
    var env, envctl;

    // 制作一个假的 8 段包络
    env = Env.newClear(8);

    // 创建一个控制参数数组
    envctl = \env.kr(env.asArray);

    ReplaceOut.kr(i_outbus, EnvGen.kr(envctl, doneAction: Done.freeSelf));
}).add;
)

(
SynthDef(\sine, { |out, freq = 440|
    Out.ar(out, SinOsc.ar(freq, 0, 0.2));
}).add;
)

f = Bus.control(s, 1);
f.set(800);

// 使用 f 的控制总线值作为频率
// 即把控制 *映射* 为从总线读取
a = Synth(\sine, [freq: f.asMap]);

Synth(\env, [i_outbus: f, env: Env([700, 900, 900, 800], [1, 1, 1]*0.4, \exp)]);

Synth(\env, [i_outbus: f, env: Env([1000, 1000, 800, 1000, 900, 1000], [1, 1, 1, 1, 1]*0.3, \step)]);

a.free;
f.free;
