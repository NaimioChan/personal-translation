LFSaw

锯齿波振荡器

PureUGen : UGen : AbstractFunction : Object

另请参见：LFCub、LFPar、LFPulse、LFTri、Saw

子类：LFCub、LFPar、LFTri

说明

一个非带限锯齿波振荡器。输出范围为 -1 到 +1。

类方法

LFSaw.ar(freq: 440.0, iphase: 0.0, mul: 1.0, add: 0.0)

LFSaw.kr(freq: 440.0, iphase: 0.0, mul: 1.0, add: 0.0)

参数：

freq

频率，单位为赫兹。

iphase

初始相位偏移。出于效率考虑，该值范围为 0 到 2。

注意： 输入 "1" 以获得 0 弧度的初始相位。值为 0 会使周期从 pi 弧度开始。参见下面的示例。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

{ LFSaw.ar(500, 1, 0.1) }.play

// 既用作振荡器，也用作低频振荡器（LFO）：
{ LFSaw.ar(LFSaw.kr(4, 0, 200, 400), 0, 0.1) }.play

显示初始相位参数的特殊行为：

 // 三个通道，三个相位
{ LFSaw.ar(20, [0, 1, 2]) }.plot(0.1)
