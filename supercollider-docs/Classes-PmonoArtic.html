PmonoArtic

部分单音事件流

Pmono : Pattern : AbstractFunction : Object

另请参阅：Pbind、Pmono

说明

与 Pmono 类似，PmonoArtic 一次演奏一个 synth（其中连续的事件会更改现有 synth 节点的参数）。不过，PmonoArtic 允许事件重新发音，并支持在单声部乐句中间使用断奏。

如果事件指定的 'sustain' 值短于事件 delta，则意味着 Synth 不应持续到下一个事件。在这种情况下，节点将根据 'sustain' 被释放，下一个事件将启动一个新的 Synth。

如果 sustain >= delta，则 synth 将完整播放，并且其参数会发生变化（就像 Pmono 一样）。

由于 sustain 计算为 ~dur * ~legato，这意味着 ~legato < 1.0 会导致重新发音，而 ~legato >= 1.0 会导致连音。

示例

// 这个 SynthDef 的起音比默认的更硬，能更清晰地展示重新发音。
(
SynthDef(\sawpulse, { |out, freq = 440, gate = 0.5, plfofreq = 6, mw = 0, ffreq = 2000, rq = 0.3, freqlag = 0.05, amp = 1|
    var sig, plfo, fcurve;
    plfo = SinOsc.kr(plfofreq, mul: mw, add: 1);
    freq = Lag.kr(freq, freqlag) * plfo;
    fcurve = EnvGen.kr(Env.adsr(0, 0.3, 0.1, 20), gate);
    fcurve = (fcurve - 1).madd(0.7, 1) * ffreq;
    sig = Mix.ar([Pulse.ar(freq, 0.9), Saw.ar(freq*1.007)]);
    sig = RLPF.ar(sig, fcurve, rq)
        * EnvGen.kr(Env.adsr(0.04, 0.2, 0.6, 0.1), gate, doneAction: Done.freeSelf)
        * amp;
    Out.ar(out, sig ! 2)
}).add;
)

p = PmonoArtic(\sawpulse, \dur, 0.2, \freq, Pwhite(1, 8) * 100, \legato, Pwrand(#[0.5, 1.0], #[0.1, 0.9], inf)).play;

p.stop;
