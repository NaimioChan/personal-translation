Vibrato

Vibrato 振荡器模拟缓慢的频率调制。

PureUGen : UGen : AbstractFunction : Object

说明

颤音是一种缓慢的频率调制。可以想象歌唱者在基频附近系统性的音高偏离，或小提琴手的手指在指板上位置晃动，轻微地绷紧和放松琴弦来为音高增添光泽。在某个音上建立颤音之前通常还有一段延迟。这个 UGen 对这些过程进行建模；通过设置更极端的设置，你可以回到 FM 合成的音色。你还可以在颤音速率和颤音大小（调制深度）中加入一些噪声，以形成更真实的运动模式。

颤音输出是基于平方包络形状的波形，该包络有四个阶段，分别标记 0.0 到 1.0、1.0 到 0.0、0.0 到 -1.0 以及 -1.0 回到 0.0。颤音速率决定了你穿过这些阶段的速度。

类方法

Vibrato.ar(freq: 440.0, rate: 6, depth: 0.02, delay: 0.0, onset: 0.0, rateVariation: 0.04, depthVariation: 0.1, iphase: 0.0, trig: 0.0)

Vibrato.kr(freq: 440.0, rate: 6, depth: 0.02, delay: 0.0, onset: 0.0, rateVariation: 0.04, depthVariation: 0.1, iphase: 0.0, trig: 0.0)

参数：

freq

基频，单位为赫兹。如果 Vibrato UGen 以音频速率运行，则此值不能是常量，而必须是实际的音频速率 UGen（参见下面的示例）

rate

颤音速率，即摆动速度，单位为赫兹。请注意，如果将其设置为较低的值（并且肯定设置为 0.0 时），你可能永远无法恢复颤音，因为速率输入仅在周期结束时才会被检查。

depth

基频周围颤音频率偏移的大小，作为基频的比例。0.02 = 基频的 2%。

delay

颤音建立前的延迟秒数（例如，歌手通常会先起音，然后稳定地加入颤音）。

onset

从初始延迟时间之后开始，从无颤音过渡到完全颤音的时间，以秒为单位。

rateVariation

速率上的噪声，表示为速率的一个比例；每个颤音周期可改变一次。

depthVariation

调制深度上的噪声，以深度的比例表示；每个颤音周期可改变一次。该噪声在一个周期内独立地影响颤音形状的上升部分和下降部分。

iphase

颤音调制的初始相位，允许从基频之上或之下开始，而不是从基频上开始。

trig

如果从 trig <= 0 过渡到 trig > 0，则重新开始。

实例方法

示例

// 1 Hz 的颤音，注意使用了 DC.ar UGen；常量 400.0 不起作用
{ SinOsc.ar(Vibrato.ar(DC.ar(400.0), 1, 0.02)) }.play

// 对比：k-rate 频率输入可以是常量
{ SinOsc.ar(Vibrato.kr(400.0, 1, 0.02)) }.play

// control 速率和 rateVariation
{ SinOsc.ar(Vibrato.ar(DC.ar(400.0), MouseX.kr(2.0, 100.0), 0.1, 1.0, 1.0, MouseY.kr(0.0, 1.0), 0.1)) }.play

// 控制 depth 和 depthVariation
{ SinOsc.ar(Vibrato.ar(DC.ar(400.0), LFNoise1.kr(1, 3, 7), MouseX.kr(0.0, 1.0), 1.0, 1.0, MouseY.kr(0.0, 1.0), 0.1)) }.play
