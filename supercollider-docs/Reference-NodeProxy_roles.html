NodeProxy 角色

NodeProxy 中的角色

另请参阅：NodeProxy、Ndef、ProxySpace

与副词（参见J concepts in SC）类似，角色允许指定 NodeProxy 的源如何被使用。角色是 Symbol 与新代理源对象之间的关联。

下面的示例同样可用于 Ndef 以及在 ProxySpace 中。

// 因此，以下表达式的行为是等价的：

a = NodeProxy(s);
a[0] = ...

ProxySpace.push(s);
~a[0] = ...

Ndef(\a, ...)

现有角色

\set -> 事件模式

用类型为 \set 的事件模式设置代理控件。旧值会保留，只覆盖显式提供的值。

a = NodeProxy(s);
a[0] = { |freq = 440, dt=0.1, rate=2| Ringz.ar(Impulse.ar(rate * [1, 1.2]), freq, dt)*0.1 };
a.play;
(
a[1] = \set -> Pbind(
    \dur, Prand([1, 0.5], inf),
    \freq, Pwhite(200.0, 1000, inf),
    \rate, Pdup(4, Prand([1, 3, 6, 10], inf)),
    \dt, Pwhite(0.01, 0.1, inf)
)
);
// 同时修改源：
a[0] = { |freq = 440, dt=0.1, rate=2| Ringz.ar(Dust.ar(rate * 10.dup), freq, dt)*0.1 };

a.nodeMap.postln; // 这些值未在节点映射中设置。
a.clear(3);
\pset -> 事件模式

将所有代理控件设置为事件数据

a = NodeProxy(s);
a[0] = { |freq = 440, dt=0.1, rate=2| Ringz.ar(Impulse.ar(rate * [1, 1.2]), freq, dt)*0.1 };
a.play;

(
a[1] = \pset -> Pbind(
    \dur, Prand([1, 0.5], inf),
    \freq, Pwhite(200.0, 1000, inf).round(30),
    \rate, Pdup(4, Prand([1, 3, 6, 10], inf)),
    \dt, Pwhite(0.01, 0.1, inf) + 1
)
);

a.nodeMap.postln; // 这些值设置在节点映射中。
\xset -> 事件模式

使用 synth 交叉淡化将所有 proxy 控件设置为事件数据（参见 -xset）。

a = NodeProxy(s);
a[0] = { |freq = 440, dt=0.1, rate=2| Ringz.ar(Impulse.ar(rate * [1, 1.2]), freq, dt)*0.1 };
a.play;

(
a[1] = \xset -> Pbind(
    \dur, Prand([1, 0.5], inf),
    \freq, Pwhite(200.0, 1000, inf).round(30),
    \rate, Pdup(4, Prand([1, 3, 6, 10], inf)),
    \dt, Pwhite(0.01, 0.1, inf) + 1
)
);

a.fadeTime = 2;
// 同时修改源：
a[0] = { |freq = 440, dt=0.1, rate=2| Ringz.ar(Dust.ar(rate * 10.dup), freq, dt)*0.1 };

a.clear(3);
\seti -> 事件模式

用类型为 \set 的事件模式为多通道代理的每个通道设置代理控制。与其他角色不同，它必须分别应用于代理的每个通道。

// 5 声道 NodeProxy
a = NodeProxy.audio(s).mold(5);
// 输出将是立体声
b = NodeProxy.audio(s).play;

(
a[0] = {
    Blip.ar(
        \freq.kr([200, 201, 202, 204, 205]),
        \harms.kr([100, 100, 100, 100, 100])
    )
};

b[0] = {
    // 将 5 声道输入混合为立体声声像
    Splay.ar(\in.ar([0, 0, 0, 0, 0]), level: \amp.kr(0.7))
};
)

// 将 a 输出路由到 b 输入
b <<> a;

// 应用角色
(
a.numChannels.do { |i|
    // a[0] 保存着源！
    a[i+1] = \seti -> Pbind(
        \freq, Prand(#[62, 64, 67, 70, 72].midicps, inf),
        \harms, Pexprand(50, 1000),
        \dur, Prand(#[0.1, 0.2, 0.4], inf),
        // channelOffset 是一个偏移量，而不是通道索引
        \channelOffset, i
    )
}
)

// 再次移除角色
// 可以一次性全部移除，也可以逐个移除
a.numChannels.do { |i| a[i+1] = nil };

a.clear; b.clear;
\setbus -> 事件模式

用类型为 \c_set 的事件模式设置代理总线

a = NodeProxy(s);
b = NodeProxy(s).play;
b[0] = { SinOsc.ar(a.kr(4)).sum * 0.2 };
(
a[0] = \setbus -> Pbind(
    \dur, Prand([1, 0.5], inf),
    \value, Pfunc { var z = rrand(300, 4000); [300, 400, z, z + 30.rand2] }
)
);
// 与此同时修改另一个源：
b[0] = { Pulse.ar(a.ar(4)).sum * 0.2 };

a.clear; b.clear;
\setsrc -> 事件模式

用任意对象在下一个索引处设置 proxy 源，由模式控制。请注意，下一个索引处（在下面的示例中为索引 1）的任何现有源都会被该过程覆盖。

a = NodeProxy(s);
a.play;
(
a[0] = \setsrc -> Pbind(
    \dur, Prand([1, 0.5, 2], inf),
    \source, Prand ([
        { SinOsc.ar(SinOsc.ar({5.rand}.dup + 4) * 50 + 400 + 50.rand) * 0.1 },
        { SinOsc.ar(LFSaw.ar({5.rand}.dup + 4) * 50 + 400 + 50.rand) * 0.1},
        { LFSaw.ar(SinOsc.ar({5.rand}.dup + 4) * 50 + 400 + 50.rand) * 0.1 },
        { LFSaw.ar(LFSaw.ar({5.rand}.dup + 4) * 50 + 400 + 50.rand) * 0.1 }
    ], inf)
)
);

a.clear(3);
\filter -> function

在代理自己的总线上过滤音频，使用第一个参数传入声音。该函数是任何有效的 UGen 函数，可以是控制速率或音频速率。默认控制为 wet++index，其中 index 是代理的槽位（默认为 0），在下面的示例中，控制为 \wet1，它在传入声源与效果（wet）信号输出之间进行交叉淡化。

a = NodeProxy(s).play;
a[0] = { RLPF.ar(Dust2.ar(5!2), LFNoise2.kr(2!2).exprange(200, 5000), 0.05) };
a[1] = \filter -> { |in| CombL.ar(in, 0.2, LFNoise2.kr(0.5!2).exprange(0.01, 0.2), 3) };

a.set(\wet1, 0.2); // 将干/湿混合电平设置为更少的梳状滤波器
a.set(\wet1, 0.0); // wet 0 表示全干 - 立即切断梳状滤波器。

a.clear(3);
\filterIn -> 函数

与 \filter 类似，但 \wet 控件现在设置的是滤波器输入电平，而不是其输出电平。这使得基于时间的特效（如延迟、梳状滤波器、具有长余音时间的滤波器）即使输入已经关闭也能继续发声。

a = NodeProxy(s).play;
a[0] = { RLPF.ar(Dust2.ar(5!2), LFNoise2.kr(2!2).exprange(200, 5000), 0.05) };
a[1] = \filterIn -> { |in| CombL.ar(in, 0.2, LFNoise2.kr(0.5!2).exprange(0.01, 0.2), 3) };


a.set(\wet1, 0.5); // 将混合电平设置为更少的效果信号
// wet 0 表示全干 - 输入关闭，但梳状衰减仍然可闻。
a.set(\wet1, 0.0);

a.clear(3);
\mix -> 函数

将函数中的 UGen 混合进来。

a = NodeProxy(s);
a[0] = { PinkNoise.ar(0.1.dup) };
a.play;
a[1] = \mix -> { Dust.ar(30.dup) };
a.set(\mix1, 0.2);
a.clear(3);

添加新角色

角色可以在运行时动态添加。它们保存在 AbstractPlayControl 中的一个字典（buildMethods）里。另一个字典（proxyControlClasses）为给定键提供包装类。

这里有一个新角色，允许你借助事件模式设置控制率节点代理。新值位于名为 \value 的键中。

// 添加新角色：
(
AbstractPlayControl.proxyControlClasses.put(\stream, PatternControl);
AbstractPlayControl.buildMethods.put(\stream,
    #{ arg pattern, proxy, channelOffset=0, index;
        Pbindf(
            pattern,
            \type, \bus,
            \id, Pfunc { proxy.group.nodeID },
            \array, Pkey(\value),
            \out, Pfunc { proxy.index }
        ).buildForProxy( proxy, channelOffset, index )
});
)


// test:
a = NodeProxy.control(s);
a.source = \stream -> Pbind(\value, Pseq([1, 2, 3], inf), \dur, 1.5).trace;

b = NodeProxy(s);
b.source = { SinOsc.ar([340, 440] * a.kr) * 0.1 };
b.play;

a.source = \stream -> Pbind(\value, Pseq([1, 2, 3], inf) + Pwhite(0.0, 0.2, inf), \dur, 0.05);
b.source = { SinOsc.ar([5.6, 10.3] ** a.kr + 300) * 0.1 };
