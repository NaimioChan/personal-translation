Float

64 位浮点数

SimpleNumber : Number : Magnitude : Object

说明

一个 64 位双精度浮点数。Float 的大部分行为继承自其父类 SimpleNumber。

// 生成 10 个介于 0 和 1 之间的随机浮点数
{ 1.0.rand }.dup(10)

// 毕达哥拉斯逗号
// 表示为用整数计算得到的浮点数
(
var apotome = (3 ** 7) / (2 ** 11);
var limma =   (2 ** 8) / (3 ** 5);

apotome / limma
)

注意，尽管名字如此，FloatArray 只保存 32 位（单精度）浮点数。若要使用 64 位浮点数的原始数组，请使用 DoubleArray。

注意： Float 的溢出/下溢行为是未定义的，但通常分别为 inf/-inf，因为大多数 CPU 都很好地遵循 IEEE-754 浮点数标准。然而，溢出/下溢行为通常仍交由硬件处理，因此可能因系统而异。每当操作的结果超出返回类型（在此情况下为 64 位浮点数）所支持的数值范围时，就会发生这种（溢出/下溢）。

使用 Float 替代 Integer

在 SuperCollider 中，Float 的宽度为 64 位。由于 Integer 是 32 位的，因此它只能捕获 -2147483648（-2^31）到 2147483647（2^31 - 1）范围内的整数。

因此，在某些情况下，即使只需要整数，使用浮点数进行计算也可能很有用。你可以在 ± 9007199254740992 范围内使用 64 位浮点数进行整数计算，约为 ±2^53。有时还可以更进一步（参见下面的示例）。

// 比较阶乘：
f = { |x| if(x < 2) { x } { x * f.(x - 1) } };
f.(14); // 整数
f.(18) // 整数溢出：-898433024
f.(18.0) // 浮点数没问题。
// 检查相邻阶乘之间的比率：
f.(18.0) / f.(17.0) == 18 // true
// 18 已经是 64 位浮点数能表示的最大阶乘（< 2^53）
{ :x, x<-(1.0..40), f.(x) < (2 ** 53) }.all.last

这里有一个算法的经典示例：

// 欧几里得算法
(
g = { |a, b|
    if(b == 0) {
        a
    } {
        g.(b, mod(a, b))
    }
}
)

// 检查是否为 2 的幂

x = 2147483647 * 3;
g.(x, 3); // 错误，返回 1
x = 2147483647.0 * 3;
g.(x, 3); // 正确，返回 3

x = 2007199254740992.0 * 3;
g.(x, 3); // 正确，返回 3
x = 9007199254740992.0 * 3;
g.(x, 3); // 恰好仍然正确，但最好不要依赖它……

测试 64 位浮点数的极限（2^53）

a = 2 ** 53 - 1
b = a + 1;
c = a + 2;
b - a // correct (1)
c - a // 错误（也是 1）


// 能算到多高取决于计算方式：
// 这里我们将两个相邻的数相除
// 直到 f.(170) 都是正确的，约为 7.25e+306。
f = { |x| if(x < 2) { x } { x * f.(x - 1) } };
{ :x, x<-(1.0..180), f.(x) / f.(x - 1) == x }.all.last
