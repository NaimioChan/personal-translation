Prewrite

用于自相似结构的 L-system 模式

FilterPattern : Pattern : AbstractFunction : Object

参见：Pfsm

说明

用于自相似结构的 Lindenmayer 系统模式。其字典（或事件）将一个元素映射到一个子元素数组。该算法以 pattern 中的值为起点，迭代地（深入 levels 层）用元素数组替换元素。

类方法

Prewrite.new(pattern, dict, levels: 1)

参数：

pattern

起始值

dict

一个字典或一个事件。

levels

层数

IdentityDictionary[
    elem1 -> [otherElements],
    elem2 -> [otherElements],
    elem2 -> [otherElements]
]

示例

这些示例使用 () 作为 Event 的快捷方式。

// 一首生成式歌曲
(
// 音级向上进行
Pdef(\a, Pbind(\dur, 0.25, \degree, Pseq((0..3))));

// 音级下行
Pdef(\b, Pbind(\dur, 0.25, \degree, Pseq((3..0))));

// 随机音阶度数
Pdef(\c, Pbind(\dur, 0.125, \degree, Pwhite(0, 10, 8)));

// 使用 L-system 组合出一系列键
// Psym 随后会从全局 Pdef 字典中检索这些模式
// 查看 post window 以了解哪些正在播放
Psym(
    Prewrite(\a, // 从模式 \a 开始
        (
            \a: #[\a, \b],
            \b: #[\c, \a],
            \c: #[\a, \b]
    ), 4).trace
).play
)

// 检查 L-system 以查看它生成的数据
(
a = Prewrite(0, // 从 0 开始
    (
        0: #[2, 0],
        1: #[0, 0, 1],
        2: #[1, 0, 1]
), 4);
x = a.asStream;
30.do({ x.next.postln });
)
