SuperCollider 中的一些占位符

另请参阅：JITLib、jitlib_basic_concepts_02

本帮助文件解释了使用 SuperCollider 与代理空间进行交互式编程的一些基本概念。

什么是代理？

代理（proxy）是一个占位符，常用于对尚不存在的事物进行操作。例如，OutputProxy 用于表示 ugen 的多个输出，即使最终只创建一个 ugen。任何对象都可以具有代理行为（例如它可以将函数调用委托给不同的对象），但特别是函数和引用可以用作操作数，同时保持其引用特性。

另请参阅：OutputProxy、Function、Ref

延伸阅读：NodeProxy、ProxySpace、Ndef

使用 Ref 作为代理

// 参考示例

// 创建一个新的 Ref 对象
y = `(nil);

// 你可以开始用 y 进行计算，即使它的值尚未给出：
z = y + 10; // 返回一个函数

// 现在可以设置源：
y.value = 34;

// 现在可以求值函数 z。
z.value


// 没有引用时同样的写法不起作用：

y = nil; // 先清空 y

z = y + 10; // 这会失败。

// 数组也不提供这种指称性：

y = [nil]; // 包含 nil 作为元素的数组

z = y + 10; // 这会失败。

// 没有足够默认值的环境也有同样的问题：

currentEnvironment.postln; // 一个环境
~x; // 访问环境：其中没有存储任何内容：nil
~x = 9; // 存储一些内容
~x;     // 现在 9 已存储
~x + 100; // 用它计算

currentEnvironment.postln; // 值存储在环境中

~y + ~x; // 导致错误：~y 为 nil。
~y = -90; // set ~y

~y + ~x; // 这样可以。

使用 Function 作为代理

// 函数也可以起到相同的作用

y = nil; // 先清空 y
z = { y } + 10;    // 这不会失败，而是会创建一个新函数，该函数
        // 在 y 被设为 34 之后求值它也不会失败。

y = 34;
z.value;

另请参见客户端侧的代理，如 Tdef、Pdefn、Pdef、Fdef

NodeProxy、ProxySpace、Ndef

对于交互式编程而言，能够在使用某物之前先引用它是很有用的——这使求值顺序更加灵活，并允许将决定推迟到稍后的时刻。通常需要做一些准备工作——如上述，必须先创建一个引用。在其他情况下，这种准备并不足够，例如，如果想要对服务器上正在运行的进程的信号应用数学运算。

注意： 凡是给出使用 Ndef 的示例，同样适用于 ProxySpace 和 NodeProxy：Ndef(\x, 5); 与 ProxySpace 中的 ~x = 5; 以及 a = NodeProxy.new; a.source = 5; 相同

// 启动服务器
s.boot;

// 服务器上的两个代理。计算速率为音频速率，通道数为 2
y = NodeProxy.audio(s, 2);
z = NodeProxy.audio(s, 2);

// 在计算中使用它们
z.play;
z.source = y.sin * 0.2;


// 现在设置其源。
y.source = { Saw.ar([300, 301], 4*pi) };

// 源可以是多种类型，其中一种是数字：
y.source = 0.0;

// 发布源代码
y.source;

// 结束它们，释放它们的总线编号
y.clear;
z.clear;

为了提供一种创建节点代理的简单方式，可以使用代理空间。因此上面的内容读起来是这样的：

p = ProxySpace.push(s.boot); // 将 proxy space 存储在 p 中，以便轻松访问。
~z.play;


~z = ~y.sin * 0.2;


~y = { Saw.ar([300, 301], 4*pi) };


// 清空空间（所有代理）
p.clear;

// 移出 proxyspace。
p.pop;

另一种非常常见的访问节点代理的方式是 Ndef（这与上面相同，只是用 Ndef 编写）：

Ndef(\z).play;

Ndef(\z, Ndef(\y).sin * 0.2);

Ndef(\y, { Saw.ar([300, 301], 4 * pi) });

Ndef.clear;

类 Ndef 在内部使用 ProxySpace 来存储其占位符。
