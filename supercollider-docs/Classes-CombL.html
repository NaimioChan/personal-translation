CombL

带线性插值的梳状延迟线。

CombN : PureUGen : UGen : AbstractFunction : Object

另请参见：CombC、CombN、BufCombL

说明

带线性插值的梳状延迟线。另请参阅 CombN（不使用插值）和 CombC（使用三次插值）。三次插值的计算开销比线性插值更大，但更精确。

反馈系数由方程 fb == 0.001 ** (delay / decay.abs) * decay.sign 给出，其中 0.001 为 -60 dBFS。

类方法

CombL.ar(in: 0.0, maxdelaytime: 0.2, delaytime: 0.2, decaytime: 1.0, mul: 1.0, add: 0.0)

来自父类：CombN

CombL.kr(in: 0.0, maxdelaytime: 0.2, delaytime: 0.2, decaytime: 1.0, mul: 1.0, add: 0.0)

来自父类：CombN

参数：

in

输入信号。

maxdelaytime

最大延迟时间，单位为秒。用于初始化延迟缓冲区大小。

delaytime

延迟时间，单位为秒。

decaytime

回声衰减 60 分贝所需的时间。如果此时间为负，则反馈系数将为负，从而只强调低一个八度的奇次谐波。

较长的衰减时间对直流偏置敏感，因此如果这是个问题，请使用 LeakDC。

允许无限的衰减时间。衰减时间为 inf 时反馈系数为 1，衰减时间为 -inf 时反馈系数为 -1。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

// 这些例子对比各变体，以便你能听出插值的差异

// Comb 用作谐振器。共振基频等于
// 延迟时间的倒数。
{ CombN.ar(WhiteNoise.ar(0.01), 0.01, XLine.kr(0.0001, 0.01, 20), 0.2) }.play;

{ CombL.ar(WhiteNoise.ar(0.01), 0.01, XLine.kr(0.0001, 0.01, 20), 0.2) }.play;

{ CombC.ar(WhiteNoise.ar(0.01), 0.01, XLine.kr(0.0001, 0.01, 20), 0.2) }.play;

// 使用负反馈：
{ CombN.ar(WhiteNoise.ar(0.01), 0.01, XLine.kr(0.0001, 0.01, 20), -0.2) }.play;

{ CombL.ar(WhiteNoise.ar(0.01), 0.01, XLine.kr(0.0001, 0.01, 20), -0.2) }.play;

{ CombC.ar(WhiteNoise.ar(0.01), 0.01, XLine.kr(0.0001, 0.01, 20), -0.2) }.play;

// 用作回声。
{ CombL.ar(Decay.ar(Dust.ar(1, 0.5), 0.2, WhiteNoise.ar), 0.2, 0.2, 3) }.play;
