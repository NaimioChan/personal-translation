PanAz

方位角声像器

MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：Balance2、LinPan2、Pan2、Pan4

说明

多声道等功率声像器。

类方法

PanAz.ar(numChans, in, pos: 0.0, level: 1.0, width: 2.0, orientation: 0.5)

PanAz.kr(numChans, in, pos: 0.0, level: 1.0, width: 2.0, orientation: 0.5)

参数：

numChans

输出通道数。必须是非零正整数。这在编译 SynthDef 时固定，因此不能赋值给 SynthDef 参数。

in

输入信号。

pos

声像位置（kr 或 ar）。声道在 pos 中按 2.0 的周期均匀分布，其中 0.0 等于声道零，2.0/numChans 等于声道 1，4.0/numChans 等于声道 2，依此类推。

因此，如果使用从 -1 到 +1 的双极锯齿波来调制 pos，所有声道将被循环声像定位。

level

一个控制速率电平输入。

width

声像包络的宽度。名义上为 2.0，即在相邻扬声器对之间进行声像定位。大于 2 的值会使声像扩散到更多扬声器上。小于 1 的值会在扬声器之间留下静音间隙。该值取绝对值，因为负值没有意义（宽度 -1 与宽度 1 相同）。

orientation

如果前方是跨越多边形的顶点，则应为 0。第一个扬声器将正对前方。如果前方平分跨越多边形的一条边，则应为 0.5。此时第一个扬声器将是中心左侧的那个。

实例方法

示例

五声道环形声像，第一个声道位于左侧

(
{
    PanAz.ar(
        numChans: 5,
        in: ClipNoise.ar(0.1),
        pos: LFSaw.kr(MouseX.kr(0.2, 8, 'exponential')),
        level: 0.5,
        width: 3,
        orientation: 0.5
    );
}.scope
)

与 Pan2 的比较

尽管有某种相似性，Pan2 和具有 2 个声道的 PanAz 行为不同。

// PanAz 的一个完整周期：从 -1 到 1
{ PanAz.ar(2, DC.ar(1), Line.ar(-1, 1, 0.1), orientation: 0) }.plot(0.1)
// 与 Pan2 比较
{ Pan2.ar(DC.ar(1), Line.ar(-1, 1, 0.1)) }.plot(0.1)
// 要为 Pan2 创建一个完整周期，从 1 移动到 -1 再回到 1
{ Pan2.ar(DC.ar(1), EnvGen.ar(Env([1, -1, 1], [0.05, 0.05]))) }.plot(0.1)

在同一个绘图窗口中：

(
{
    [
        PanAz.ar(2, DC.ar(1), Line.ar(-1, 1, 0.1), orientation: 0),
        Pan2.ar(DC.ar(1), Line.ar(-1, 1, 0.1)),
        Pan2.ar(DC.ar(1), EnvGen.ar(Env([1, -1, 1], [0.05, 0.05])))
    ].flat;
}.plot(0.1)
)

换句话说，虽然 Pan2 需要将 2 从通道 0 的位置更改为 1

{ Pan2.ar(DC.ar(1), Line.ar(-1, 1, 0.1)) }.plot(0.1)
// 我们需要在 PanAz 中位置变化 1：
{ PanAz.ar(2, DC.ar(1), Line.ar(0, 1, 0.1), orientation: 0) }.plot(0.1)

在一个绘图窗口中：

(
{
    [
        Pan2.ar(DC.ar(1), Line.ar(-1, 1, 0.1)),
        PanAz.ar(2, DC.ar(1), Line.ar(0, 1, 0.1), orientation: 0)
    ].flat
}.plot(0.1)
)
