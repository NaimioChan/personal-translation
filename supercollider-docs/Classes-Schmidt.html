Schmidt

施密特触发器。

InRange : UGen : AbstractFunction : Object

参见：InRange、InRect

说明

如果 in > hi，输出 1。如果 in < lo，输出 0。否则，重复输出的上一个采样值，初始化时假定为 0。用 sclang 风格的伪代码表示：

out[i] = if(in[i] < lo[i]) {
    0
} {
    if(in[i] > hi[i]) {
        1
   } {
        out[i-1]
   }
};

类方法

Schmidt.ar(in, lo: 0.0, hi: 1.0)

来自父类：InRange

Schmidt.kr(in: 0.0, lo: 0.0, hi: 1.0)

来自父类：InRange

参数：

in

待测试的信号。

lo

低阈值。

hi

高阈值。

实例方法

示例

s.boot;

{ Schmidt.kr(SinOsc.kr(1, 0, 0.2), -0.15, 0.15) }.scope; // 查看触发器

{ Schmidt.kr(MouseX.kr(0, 1), 0.2, 0.8) }.scope; // 用光标试试

// 阈值八度跳变
(
{
    var in = LFNoise1.kr(3);
    var octave = Schmidt.kr(in, -0.15, 0.15) + 1;
    SinOsc.ar(in * 200 + 500 * octave, 0, 0.1)
}.scope;
)
