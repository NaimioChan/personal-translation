默认事件中的音高与节奏转换

使用默认事件原型时，音高和节奏可以在 Pbind 中根据音乐需求在不同的层级上进行指定。默认事件原型包含将更高层抽象转换为对合成有用的物理参数的逻辑。

下面的描述从实际会使用的结束值开始，随后是计算中用到的其他值：例如，\delta 基于 \dur 和 \stretch。为计算项提供另一个值即可绕过这些计算。如果你的模式直接指定了 \delta，则 \dur 和 \stretch 会被忽略。

另请注意，并没有义务使用这些构造。默认事件原型并不意在将某一种音高或节奏模型强加于其他模型之上；它只是提供这些选项，如果它们适合你的任务，你可以使用；如果你的任务需要完全不同的东西，你也可以忽略或覆盖它们。

时间转换

节奏基于 \delta 和 \sustain 事件键。这两个键都可以由更高级的抽象计算得出：\dur、\stretch 和 \legato。

delta

直到下一个事件的拍数。你可以直接给出 delta 模式，或者默认事件原型可以根据其他值替你计算出来：

dur

此事件的持续时间。

stretch

时长的乘数：delta = dur * stretch。

sustain

保持此音符多少拍。在 \sustain 拍之后，将向 synth 节点发送一条释放消息，将其 gate 控制设为 0。你的 SynthDef 应基于持续包络在 EnvGen 中使用 gate（参见 Env），并且 EnvGen 应具有一个 doneAction（ Done ），以便在结束时释放 synth。你可以直接给出 sustain 模式，或让默认事件原型根据以下内容为你计算：

legato

合成器应持续的时长占事件时长的一部分。1.0 表示该合成器将恰好在下一个开始时释放；0.5 表示后半段时长为休止。大于 1.0 的值会产生重叠的音符。sustain = dur * legato * stretch。

音高转换

默认事件中的音高处理功能丰富，有大量选项。要使用事件，不必理解所有这些选项。正如示例所示，即使只指定 \degree，演奏音符的模式也能产生合理的结果。其他参数允许你控制事件如何从 \degree 转换为最终传递给新 Synth 的频率。默认事件原型为所有这些参数都包含了合理的默认值。

从最高抽象层级向下：

\degree

表示一个音阶度数。小数音阶度数支持临时记号：给整数音阶度数加 0.1 会使对应的半音音高编号升高一个半音，减 0.1 则会降低半音音高编号。0.2 会升高或降低两个半音，依此类推。

\note

是一个半音音高索引，根据 \degree 基于 \scale 和调式移调（\mtranspose，用于升高或降低音高的音阶级数）计算得出。\note 以十二平均律为单位，每个八度可包含任意数量的步（\stepsPerOctave）。

\midinote

是 \note 的 12ET 转换，移调到正确的 \octave 并应用音阶移调（\gtranspose，以 stepsPerOctave 为单位给出）。如果 \stepsPerOctave 不是 12，则非 12ET 单位会被缩放为每八度 12 个 \midinote 单位。

\freq

由 \midinote 经 midicps 计算得出。会附加一个以 12ET 为单位的半音移调（\ctranspose）。

大多数演奏音符的 SynthDef 使用 freq 作为参数。如果需要，它们也可以使用 midinote、note 甚至 degree。

简化为经验法则：

  • 如果你的素材围绕音阶或调式组织，请使用 \degree。

    • 如果音阶具有不同的上行和下行模式，请在 Pbind 中使用 \note，并配合滤波模式 Pavaroh。
  • 如果你的素材是以八度的等分（不一定是 12 等分）来组织的，请使用 \note（以及 \stepsPerOctave 用于 12 音以外的等律）。
  • 如果你的素材围绕 MIDI 音符编号（或十二平均律）组织，\midinote 也同样适用。
  • 如果你希望直接以 Hz 给出频率，请使用 \freq。

以下是对音高系统所有元素的完整描述。可随意使用你感兴趣的部分，忽略其余部分。

freq

频率，单位为 Hz。可以直接给出，或根据以下内容计算。音高可以在多个层次中的任意一个上表达。一次只需使用一个。例如，如果你以音阶级数表示音高，则音符、MIDI 音符和频率值会自动为你计算。

ctranspose

半音移调，以 12ET 为单位。加到 midinote 上。

midinote

MIDI 音符编号；12 个 MIDI 音符 = 一个八度。如有需要，可以是小数。基于以下计算：

root

音阶根音，以 12ET MIDI 音符增量给出。

octave

\note = 0 对应的八度编号。默认值为 5，将音符 0 映射到 MIDI 音符 60。

stepsPerOctave

多少个 \note 单位映射到一个八度。支持非 12ET 音律。

gtranspose

非十二平均律移调，以 \note 为单位。加到 note 上。

note

音符号，以八度的任意划分表示。0 是音阶的根音。基于以下计算：

degree

音级。

scale

音阶度数到半音的映射。例如，大调是 [0, 2, 4, 5, 7, 9, 11]。

stepsPerOctave

（同上。）

mtranspose

模态移调；加到音级上。

另请参阅 Scale 类，其中包含音阶配置的存储库，以及非十二平均律调音的可能性。

(
// 用 19TET 半音阶近似大调音阶
p = Pbind(
    \scale, #[0, 3, 6, 8, 11, 14, 17],
    \stepsPerOctave, 19,
    \degree, Pwhite(0, 7, inf),
    \dur, 0.125,
    \legato, Pexprand(0.2, 6.0, inf)
).play;
)

p.stop;

振幅转换

最后，你可以用 \db 或 \amp 指定振幅。如果以 \db 给出，则振幅将使用 .dbamp 自动计算。
