Slider

由滑动手柄组成的视图。

说明

一种允许通过移动滑动手柄来设置数值的视图。它可以具有水平或垂直方向，即手柄移动的方向。

类方法

.new

创建新的 Slider 时，其 -orientation 由初始尺寸决定：如果宽度大于高度，则方向为水平，否则为垂直。

实例方法

Data

.value

介于 0 和 1 之间的数值，由手柄在凹槽内的位置表示。

参数：

一个 Float。

.valueAction

设置 -value 并触发 -action。

.increment

将值增加 -step 乘以 'factor'。

参数：

factor

任意数字。

.decrement

将值减少 -step 乘以 'factor'。

参数：

factor

任意数字。

Appearance

.orientation

Slider 的方向——即手柄移动的方向。默认值取决于创建时视图的大小。

参数：

两个 Symbol 之一：\horizontal 或 \vertical。

.thumbSize

手柄的尺寸——其宽度或高度，取决于 -orientation。

参数：

以像素为单位的整数数量。

.background

背景颜色。

参数：

一个 Color。

.knobColor

手柄的颜色。

参数：

一个 Color。

Interaction

.step

当调用 -increment 或 -decrement 时，或按下相关键时，值将改变的量。

参数：

一个 Float。

.pixelStep

如果手柄移动一个像素，值将改变的绝对量。

返回值：

一个 Float。

.shift_scale

当按下 Shift 键并用键盘递增或递减数值时，-step 所乘以的因子。

参数：

一个 Float。

.ctrl_scale

在按住 Ctrl 键的同时通过键盘递增或递减值时，-step 所乘以的因子。

参数：

一个 Float。

.alt_scale

按住 Alt 键时用键盘递增或递减值时，-step 所乘以的因子。

参数：

一个 Float。

Actions

.action

每当用户移动手柄时求值的行为对象。

.defaultKeyDownAction

实现按键的默认效果如下：

Effect

r

valueAction_(1.0.rand)

n

valueAction_(0)

x

valueAction_(1)

c

valueAction_(0.5)

]

increment

[

decrement

上箭头

increment

向下箭头

decrement

右箭头

increment

向左箭头

decrement

拖放

.defaultGetDrag

返回值：

该 -value。

.defaultCanReceiveDrag

返回值：

如果当前拖动数据是数字，则为 true。

.defaultReceiveDrag

将 -valueAction 设置为当前拖拽数据。

示例

在 NumberBox 中显示滑块值

(
w = Window.new.front;
c = NumberBox(w, Rect(20, 20, 150, 20));
a = Slider(w, Rect(20, 60, 150, 20))
    .action_({
        c.value_(a.value)
        });
a.action.value;
)

( // 更改边界使其变为垂直
w = Window.new.front;
c = NumberBox(w, Rect(20, 20, 150, 20));
a = Slider(w, Rect(200, 60, 20, 150))
    .action_({
        c.value_(a.value)
    });
a.action.value;
)

使用 Spec 对输出范围进行舍入和映射

(
w = Window.new.front;
b = ControlSpec(-50, 50, \linear, 0.01); // 最小值、最大值、映射、步进
c = StaticText(w, Rect(20, 20, 150, 20)).align_(\center).background_(Color.rand);
a = Slider(w, Rect(20, 50, 150, 20))
    .focusColor_(Color.red(alpha: 0.2))
    .background_(Color.rand)
    .value_(0.5)
    .action_({
        c.string_(b.map(a.value).asString)
        // 对浮点数取整，使其能放入 NumberBox
        });
a.action.value;
)

更改滑块的步长，通过 PopUpMenu 选择

(
w = Window.new.front;
a = ["0", "0.0625", "0.125", "0.25", "0.5", "1"];
b = Slider(w, Rect(20, 100, 100, 20))
    .action_({
        c.value_(b.value)
        }).background_(Color.rand);
d = PopUpMenu(w, Rect(20, 60, 100, 20))
    .items_(a)
    .action_({
        b.step_((a.at(d.value)).asFloat);
    });
StaticText(w, Rect(130, 60, 100, 20)).string_("change step");
c = NumberBox(w, Rect(20, 20, 100, 20));
)

使用滑块视图接受按键操作

( // 选中滑块，输入一些内容，然后观察 post 窗口
w = Window.new;
c = Slider(w, Rect(0, 0, 100, 30));
c.keyDownAction = { |view, char, modifiers, unicode, keycode|
    [char, modifiers, unicode, keycode].postln
};
w.front;
)

通过 addAction 方法为视图添加功能

这对于向已有 action 函数的现有框架添加内容很有用。

(
w = Window.new("A Slider");
a = Slider.new(w, Rect(40, 10, 300, 30));
w.front
);

// 现在逐步给滑块添加一些动作
a.addAction({ |sl| sl.value.postln });
a.addAction({ |sl| w.view.background = Color.green(sl.value) });
a.addAction({ |sl| sl.background = Color.red(1 - sl.value) });

// 添加和移除一个动作：
f = { |sl| "--------*******-------".postln };
a.addAction(f);
a.removeAction(f);

// 或者全部删除，当然
a.action = nil;

使用 Slider 触发声音

(
s.waitForBoot({

    SynthDef(\pluck, { |out, freq = 55|
        Out.ar(out,
            Pluck.ar(WhiteNoise.ar(0.06),
                EnvGen.kr(Env.perc(0, 4), 1.0, doneAction: Done.freeSelf),
                freq.reciprocal,
                freq.reciprocal,
                10,
                coef: 0.1)
        );
    }).add;


    w = Window.new("Hold arrow keys to trigger sound",
        Rect(300, Window.screenBounds.height - 300, 400, 100)).front;
    a = Slider(w, Rect(50, 20, 300, 40)).value_(0.5).step_(0.05).focus
    .action_({
        // 用变化的频率触发一个合成器
        Synth(\pluck, [\freq, 55 + (1100 * a.value)]);
        w.view.background_(Gradient(Color.rand, Color.rand));
    })
});
)

更改 Window 的背景颜色

(
w = Window("RGB fader", Rect(100, 500, 400, 400))
    .front;
f = { w.view.background_(Color.new(r.value, g.value, b.value, 1)) };
r = Slider(w, Rect(100, 140, 200, 20))
    .value_(0.5)
    .action_({ f.value });
g = Slider(w, Rect(100, 170, 200, 20))
    .value_(0.5)
    .action_({ f.value });
b = Slider(w, Rect(100, 200, 200, 20))
    .value_(0.5)
    .action_({ f.value });
f.value;
);
