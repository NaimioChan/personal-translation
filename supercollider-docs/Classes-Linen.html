Linen

简单线性包络发生器。

UGen : AbstractFunction : Object

另请参阅：EnvGen

说明

简单线性包络发生器。

类方法

Linen.kr(gate: 1.0, attackTime: 0.01, susLevel: 1.0, releaseTime: 1.0, doneAction: 0)

参数：

gate

这会触发包络，并在 > 0 期间保持其打开。

如果 gate < 0，则以时间 -1.0 - gate 强制释放。参见 EnvGen: Forced release。

attackTime

起音部分的时长。

susLevel

延音部分的电平。

releaseTime

释音部分的时长。

doneAction

一个整数，表示包络结束时执行的动作。详见 Done。

实例方法

未文档化的实例方法

.canFreeSynth

来自扩展 /usr/local/share/SuperCollider/SCClassLibrary/Common/Audio/canFreeSynth.sc

示例

// 已触发
(
SynthDef("help-Linen", { |out = 0|
    Out.ar(out,
        Linen.kr(Impulse.kr(2), 0.01, 0.6, 1.0, doneAction: Done.none) * SinOsc.ar(440, 0, 0.1)
    )
}).play;
)

// 播放一次并结束 synth
(
SynthDef("help-Linen", { |out = 0|
    Out.ar(out,
        Linen.kr(Impulse.kr(0), 0.01, 0.6, 1.0, doneAction: Done.freeSelf) * SinOsc.ar(440, 0, 0.1)
    )
}).play;
)

// 播放一次并保持
(
x = SynthDef("help-Linen", { |gate = 1, out = 0| // 使用 gate 参数进行释放
    Out.ar(out,
        Linen.kr(gate, 0.01, 0.6, 1.0, doneAction: Done.freeSelf) * SinOsc.ar(440, 0, 0.1)
    )
}).play;
)
x.release(4); // 更改释放时间

// 更长的门，可传入持续时间
(
SynthDef("help-Linen", { |out = 0, dur = 0.1|
    var gate;
    gate = Trig.kr(1.0, dur);
    Out.ar(out,
        Linen.kr(gate, 0.01, 0.6, 1.0, doneAction: Done.freeSelf) * SinOsc.ar(440, 0, 0.1)
    )
}).play(nil, [\out, 0, \dur, 2.0]);
)



// 在下面用于改变 releaseTime 的 Routine 中
(
SynthDef("help-Linen", { |out = 0, freq = 440, attackTime = 0.01, susLevel = 0.6, releaseTime = 0.1|
    Out.ar(out,
        Linen.kr(Impulse.kr(0), attackTime, susLevel, releaseTime, doneAction: Done.freeSelf)
            * SinOsc.ar(freq, 0, 0.1)
    )
}).add;
)

(
// debussey sleeping through math class
x = Pbrown(0.01, 2.0, 0.2, inf).asStream;
Routine({
    loop({
        Synth.grain("help-Linen", [\freq, (rrand(20, 50) * 2).midicps, \releaseTime, x.next]);
        0.25.wait;
    })
}).play(TempoClock.default)
)





(
SynthDef("help-Linen", { |out = 0|
    Out.ar(out,

        Linen.kr(Impulse.kr(2),
            0.01,
            // 延音电平在触发时轮询
            FSinOsc.kr(0.1).range(0, 1),
            1.0,
            doneAction: Done.none)

            * SinOsc.ar(440, 0, 0.1)
    )
}).play;
)
