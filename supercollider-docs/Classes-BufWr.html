BufWr

缓冲区写入振荡器。

UGen : AbstractFunction : Object

另请参阅：BufRd

说明

在索引处写入缓冲区。

注意： BufWr（与 BufRd 不同）不进行多声道扩展，因为输入是一个数组。

类方法

BufWr.ar(inputArray, bufnum: 0, phase: 0.0, loop: 1.0)

BufWr.kr(inputArray, bufnum: 0, phase: 0.0, loop: 1.0)

参数：

inputArray

输入 UGens（channelArray）。

bufnum

要使用的缓冲区索引。

phase

可调制的缓冲区索引（必须是音频速率）。

警告： phase 参数仅为寻址 2**24 个采样（在 44100Hz 下约 6.3 分钟）提供精度

loop

1 表示真，0 表示假。这是可调制的。

实例方法

示例

(
// 分配一个缓冲区用于写入
s = Server.local;
s.sendMsg("/b_alloc", 0, 44100 * 2);
)


// 用 BufWr 写入缓冲区
(
y = { |rate = 1|
    var in;
    in = SinOsc.ar(LFNoise1.kr(2, 300, 400), 0, 0.1);
    BufWr.ar(in, 0, Phasor.ar(0, BufRateScale.kr(0) * rate, 0, BufFrames.kr(0)));
    0.0 // quiet
}.play;
)

// 用 BufRd 读取它
(
x = { |rate = 1|
    BufRd.ar(1, 0, Phasor.ar(0, BufRateScale.kr(0) * rate, 0, BufFrames.kr(0)))
}.play(s);
)



x.set(\rate, 5);
y.set(\rate, 2.0.rand);
x.set(\rate, 2);
