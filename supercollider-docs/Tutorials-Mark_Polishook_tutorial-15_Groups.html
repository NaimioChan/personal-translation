最简单的合成过程使用单个 ugen。

{ Saw.ar(500, 0.1) }.scope;

or

{ Formlet.ar(Saw.ar(22), 400, 0.01, 0.11, 0.022) }.scope

大多数 UGens 的 SuperCollider 帮助文档都展示了其他此类示例。

浏览：UGen

////////////////////////////////////////////////////////////////////////////////////////////////////

许多合成过程由于使用了不止几个 ugen，通常最好拆分为各个组成部分。这可以使代码模块化、可复用且更易读。

Group 类是指定节点集合的手段，它提供了一种机制来同时控制多个 synth。

组是链表

组的重要技术特征是，它们包含的节点是链表中的项。链表是一种数据结构，便于对节点进行排序和重新排序。链表中的第一项是“头”，最后一项是“尾”。

组通过其头部和尾部机制，允许按顺序放置 synth，使一个 synth 可验证地在另一个之前执行，例如头部 synth 在尾部 synth 之前运行。在将源音频通过效果（如混响或滤波器）发送时，能够对 synth 排序是至关重要的。

组的另一个特性是它们允许 synth 从单一控制点接收消息，例如，发送给组的一条消息会到达属于该组的所有节点。

节点、链表、树

有关 SuperCollider 中节点定义的说明，请参阅 服务器架构 文档，或者到 Wikipedia 上查看关于节点、链表和树的通用讨论。

RootNode 与 default_group

默认情况下，localhost 和内部服务器各自在启动时带有两个预定义的组：RootNode 和 Default Group（参见它们的帮助文件）。要查看这一点，请启动 localhost 服务器，然后求值

s.queryAllNodes;

接下来的两行

Group(0)
        Group(1)

将出现在记录窗口中。

Group(0) 是根节点组，Group(1) 是 default_group。Group(1) 被缩进以表明它从 Group(0) 分支出来。

////////////////////////////////////////////////////////////////////////////////////////////////////

新 Synth 默认附加到 default_group 的头部。

// 首先，求值一个 synthdef
(
SynthDef("ringModulation", {
    Out.ar(
        0,
        Mix.ar(
            SinOsc.ar([440.067, 441.013], 0, 1)
            *
            SinOsc.ar([111, 109], 0, 0.2)
        )
    )
}).add;
)

// 第二，创建一个合成器
(
Synth("ringModulation");
)

// 第 3 步，告诉服务器列出其节点
(
s.queryAllNodes;
)
Group(0)
        Group(1)
                Synth 1003

将出现在 transcript 窗口中。它显示 Group(0) 作为根节点，Group(1) 作为分支 default_node，Synth 1003（或类似的编号）作为附加到 default_node 的叶节点。

Rootnode - Group(0)
      |
      |
default_node - Group(1)
      /
     /
Synth 1003

////////////////////////////////////////////////////////////////////////////////////////////////////

一个包含两个 synth 的示例。

// 首先，求值一个 synthdef
(
SynthDef("pitchFromNoise", { arg out = 0;
    Out.ar(
        out,
        Resonz.ar(
            WhiteNoise.ar(15),
            LFNoise0.kr(2, 110, 660),
            0.005
        )
    )
}).add;
)

// 第二步，创建 2 个合成器
(
Synth("ringModulation");
Synth("pitchFromNoise", [\out, 1]);
)

// 第 3 步，告诉服务器列出其节点
(
s.queryAllNodes;
)

记录窗口中的打印输出

Group(0)
        Group(1)
                Synth 1005
                Synth 1004

表明 Group(0) 是根节点，Group(1) 是 default_node。

Synth 1005 和 1004（或类似的编号）是附加到 default_node 的叶节点。Synth 1005 在列表中排在第一位，这是因为节点默认附加到列表头部的方式：首先对 Synth 1004（即“ringModulation” synth）进行求值并附加到 Group(1) 的头部。然后对 Synth 1005（即“pitchFromNoise” synth）进行求值并放置在列表头部（在 Synth 1004 之前）。

    Rootnode - Group(0)
      |
      |
 default_node - Group(1)
      /     \
     /       \
Synth 1005  Synth 1004
(head)        (tail)

////////////////////////////////////////////////////////////////////////////////////////////////////

确保服务器上的节点顺序正确是用户的责任。因此，下面两个 synth 必须按照给定的顺序求值——因为第一个 synth 是第二个 synth 的源素材，后者是一个处理其输入的滤波器。

(
SynthDef("firstNode-source", {
    Out.ar(
        0,
        Saw.ar([200, 201], 0.05)
    )
}).add;

SynthDef("secondNode-filter", {
    ReplaceOut.ar(
        0,
        LPF.ar(
            In.ar(0, 2),
            Lag.kr(
                LFNoise0.kr([4, 4.001], 500, 1000),
                0.1
            )
        )
    )
}).add;
)

// 先求值 "secondNode-filter"
// "firstNode-source" 将放在 default_node 的头部
(
Synth("secondNode-filter");
Synth("firstNode-source");
)

(
s.queryAllNodes;
)

////////////////////////////////////////////////////////////////////////////////////////////////////

或者，使用 .head 和 .tail 消息将节点附加到 default_group）。

(
Synth.head(s, "firstNode-source");
Synth.tail(s, "secondNode-filter");
)

(
s.queryAllNodes;
)

////////////////////////////////////////////////////////////////////////////////////////////////////

或者，将 synth 分配到组。

(
~source = Group.head(s);    // 将组附加到 default_node 的头部
~effect = Group.tail(s);    // 将组附加到 default_node 的尾部
)

(
// 将 synth 添加到相应的组中
Synth.head(~effect, "secondNode-filter");
Synth.head(~source, "firstNode-source");
)

其思路是先将组按所需顺序附加到 default_group。然后可以按任意顺序求值这些 synth，只要它们被附加到适当的组即可。

// 运行代码以查看节点示意图
(
s.queryAllNodes;
)

////////////////////////////////////////////////////////////////////////////////////////////////////

为组中的所有 synth 设置一个控制。

// 下面的每个 synthdef 都有一个用于振幅的控制（mul）
(
// 构建 3 个 synthdef 和一个 group
SynthDef("synthNumber1", { arg mul = 0.2;
    Out.ar(
        0,
        BrownNoise.ar(mul) * LFNoise0.kr([1, 1.01])
    )
    }, [0.1]).add;
SynthDef("synthNumber2", { arg mul = 0.2;
    Out.ar(
        0,
        WhiteNoise.ar(mul) * LFNoise1.kr([2.99, 3])
    )
    }, [0.1]).add;
SynthDef("synthNumber3", { arg mul = 0.2;
    Out.ar(
        0,
        PinkNoise.ar(mul) * LFNoise2.kr([0.79, 0.67])
    )
}, [0.1]).add;
)

(
// 创建一个组
~myGroup = Group.new;
)

(
// 附加 3 个合成器
Synth.head(~myGroup, "synthNumber1");
Synth.head(~myGroup, "synthNumber2");
Synth.head(~myGroup, "synthNumber3");
)

// 设置组中 3 个合成器各自的 \mul 控制
~myGroup.set(\mul, 0.01.rrand(0.2))

// 执行以查看节点的示意图
(
s.queryAllNodes;
)
