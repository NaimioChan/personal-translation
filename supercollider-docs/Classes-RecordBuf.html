RecordBuf

录制或叠加录制到缓冲区。

UGen : AbstractFunction : Object

另请参阅：PlayBuf

说明

将输入录制到 Buffer 中。

如果 recLevel 为 1.0 且 preLevel 为 0.0，则新的输入会覆盖旧数据。如果两者都为 1.0，则新数据会添加到现有数据中。（任何其他设置也是有效的。）

注意： SynthDef 的通道数必须是固定的，不能根据你使用哪个缓冲区而变化。

类方法

RecordBuf.ar(inputArray, bufnum: 0, offset: 0.0, recLevel: 1.0, preLevel: 0.0, run: 1.0, loop: 1.0, trigger: 1.0, doneAction: 0)

RecordBuf.kr(inputArray, bufnum: 0, offset: 0.0, recLevel: 1.0, preLevel: 0.0, run: 1.0, loop: 1.0, trigger: 1.0, doneAction: 0)

参数：

inputArray

输入通道的数组。

bufnum

要使用的缓冲区索引。

offset

缓冲区中以采样为单位的偏移量。

recLevel

在与现有数据混合之前乘以输入的值。

preLevel

在与输入混合之前，与缓冲区中现有数据相乘的值。

run

如果为零，则停止录制，否则继续录制。

loop

如果为零则不循环，否则循环。此参数可调制。

trigger

触发会使播放位置跳转到 Buffer 的开头。当信号从负值变为正值时，就会发生触发。

doneAction

一个整数，表示缓冲区录制完成后要执行的操作。这可用于释放所属的 Synth 等。详情请参阅 Done。doneAction 仅在 loop 为 0 时才会被求值。

实例方法

示例

// 按顺序执行以下操作
(
// 分配一个 Buffer
s = Server.local;
b = Buffer.alloc(s, 44100 * 4.0, 1); // 一个 4 秒的单声道 Buffer
)

// 录制四秒
(
SynthDef(\help_RecordBuf, { |out = 0, bufnum = 0|
    var formant;
    formant = Formant.ar(XLine.kr(400, 1000, 4), 2000, 800, 0.125);
    RecordBuf.ar(formant, bufnum, doneAction: Done.freeSelf, loop: 0);
}).play(s, [\out, 0, \bufnum, b]);
)

// 播放回来
(
SynthDef(\help_RecordBuf_playback, { |out = 0, bufnum = 0|
    var playbuf;
    playbuf = PlayBuf.ar(1, bufnum);
    FreeSelfWhenDone.kr(playbuf); // 当 PlayBuf 结束时释放 synth
    Out.ar(out, playbuf);
}).play(s, [\out, 0, \bufnum, b]);
)

// 叠录
(
SynthDef(\help_RecordBuf_overdub, { |out = 0, bufnum = 0|
    var formant;
    formant = Formant.ar(XLine.kr(200, 1000, 4), 2000, 800, 0.125);
    // 与现有数据等量混合
    RecordBuf.ar(formant, bufnum, 0, 0.3, 0.5, doneAction: Done.freeSelf, loop: 0);
}).play(s, [\out, 0, \bufnum, b]);
)

// 播放叠加录制后的版本
Synth.new(\help_RecordBuf_playback, [\out, 0, \bufnum, b], s);

// 将缓冲区的内容写入文件（更多选项见 Buffer）
(
b.write(sampleFormat: 'int16');
thisProcess.platform.recordingsDir +/+ "SC_" ++ Date.localtime.stamp ++ ".aiff"; // 生成的路径
)

b.close; b.free; // cleanup
