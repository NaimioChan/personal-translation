Pif

基于模式的条件表达式

Pattern : AbstractFunction : Object

参见：Pwhile

类方法

Pif.new(condition, iftrue, iffalse, default)

参数：

condition

返回 Boolean 值的模式或流。

iftrue

如果 Boolean 为真，则对该流求值。

iffalse

如果 Boolean 为 false，则对该流求值。

default

如果 "iftrue" 或 "iffalse" 在任何时候返回 nil，则返回此值（不是流）。
