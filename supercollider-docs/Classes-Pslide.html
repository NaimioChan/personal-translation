Pslide

遍历一个值列表并嵌入它们

ListPattern : Pattern : AbstractFunction : Object

参见：Ptuple

类方法

Pslide.new(list, repeats: 1, len: 3, step: 1, start: 0, wrapAtEnd: true)

参数：

list

repeats

段数。

len

每个分段的长度。

step

每段起点相对前一段的步进量。step 可以为负。

start

从哪个索引开始。

wrapAtEnd

如果为 true（默认值），当索引超出开头或结尾时会回绕。如果为 false，则当模式遇到 nil 元素或超出列表边界时停止。
