Osc

插值波表振荡器。

PureUGen : UGen : AbstractFunction : Object

另请参见：COsc, OscN, VOsc, VOsc3, Wavetable

说明

带频率和相位调制输入的线性插值波表查找振荡器。

该振荡器需要一个填充了波表格式信号的缓冲区。这会将 Signal 预处理为 Oscillator 可以高效使用的形式。缓冲区大小必须是 2 的幂。

这可以通过创建一个 Buffer 对象并向其发送 "b_gen" 消息之一（Buffer: -sine1、Buffer: -sine2、Buffer: -sine3）并将 wavetable 标志设置为 true 来实现。

这也可以通过创建一个 Signal 对象并向其发送 'asWavetable' 消息来实现，从而创建所需格式的 Wavetable 对象。然后，可以使用 Buffer: *sendCollection 或 Buffer: *loadCollection 方法将波表数据传输到服务器。

类方法

Osc.ar(bufnum, freq: 440.0, phase: 0.0, mul: 1.0, add: 0.0)

Osc.kr(bufnum, freq: 440.0, phase: 0.0, mul: 1.0, add: 0.0)

参数：

bufnum

缓冲区索引。

freq

频率，单位为赫兹。

phase

以弧度表示的相位偏移或调制器。（注意：相位值应处于 +-8pi 范围内。如果你的相位值更大，只需使用 .mod(2pi) 对其进行环绕即可。）

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

(
s = Server.local;
b = Buffer.alloc(s, 512, 1);
b.sine1(1.0/[1, 2, 3, 4, 5, 6], true, true, true);

SynthDef("help-Osc", { |out = 0, bufnum = 0|
    Out.ar(out,
        Osc.ar(bufnum, 200, 0, 0.5)
    )
}).play(s, [\out, 0, \bufnum, b.bufnum]);
)

(
s = Server.local;
b = Buffer.alloc(s, 512, 1);
b.sine1(1.0/[1, 2, 3, 4, 5, 6], true, true, true);

SynthDef("help-Osc", { |out = 0, bufnum = 0|
    Out.ar(out,
        Osc.ar(bufnum, XLine.kr(2000, 200), 0, 0.5) // 调制频率
    )
}).play(s, [\out, 0, \bufnum, b.bufnum]);
)


(
s = Server.local;
b = Buffer.alloc(s, 512, 1);
b.sine1([1.0], true, true, true);

SynthDef("help-Osc", { |out = 0, bufnum = 0|
    Out.ar(out,
        Osc.ar(bufnum,
            Osc.ar(bufnum,
                XLine.kr(1, 1000, 9),
                0,
                200,
                800),
            0,
            0.25)
    )
}).play(s, [\out, 0, \bufnum, b.bufnum]);
)


(
// 调制相位
s = Server.local;
b = Buffer.alloc(s, 512, 1);
b.sine1([1.0], true, true, true);

SynthDef("help-Osc", { |out = 0, bufnum = 0|
    Out.ar(out,
        Osc.ar(bufnum,
                800,
                Osc.ar(bufnum,
                        XLine.kr(20, 8000, 10),
                        0,
                        2pi),
                0.25)
    )
}).play(s, [\out, 0, \bufnum, b.bufnum]);
)

// 在缓冲区播放时更改它
s = Server.local;

b.sine1(1.0/[1, 2, 3, 4, 5, 6], true, true, true);

SynthDef("help-Osc", { |out = 0, bufnum = 0|
    Out.ar(out,

    )
}).play(s, [\out, 0, \bufnum, b.bufnum]);
)
