RandSeed

设置 Synth 的随机生成器种子。

WidthFirstUGen : UGen : AbstractFunction : Object

参见：RandID

说明

当触发信号从非正变为正时，合成器的随机生成器种子会重置为给定值。所有使用相同随机数生成器的合成器会再次重现相同的数字序列。

有关设置 randgen id 的信息，请参见 RandID UGen；客户端侧的等效功能请参见 Random Seed。

类方法

RandSeed.kr(trig: 0.0, seed: 56789)

RandSeed.ir(trig: 0.0, seed: 56789)

参数：

trig

触发信号。触发信号可以是任意信号。当信号从非正变为正时，触发发生。

seed

随机种子。

未文档化的类方法

RandSeed.ar(trig: 0.0, seed: 56789)

实例方法

示例

// 启动噪声片段

(
{
var noise, filterfreq;
noise = WhiteNoise.ar(0.05 ! 2) + Dust2.ar(70 ! 2);
filterfreq = LFNoise1.kr(3, 5500, 6000);
Resonz.ar(noise * 5, filterfreq, 0.5) + (noise * 0.5)
}.play;
)

// 以可变速率重置种子
(
x = { |seed = 1956|
        RandSeed.kr(Impulse.kr(MouseX.kr(0.1, 100)), seed);
}.play;
)



x.set(\seed, 2001);
x.set(\seed, 1798);
x.set(\seed, 1902);


// 上面可以看到，LFNoise1 的声音并不能被精确重现（滤波器频率）
// 这是由于噪声 ugen 的内部相位与
// 种子设置速率之间的干扰导致的。

// 解决方案是启动一个新的 synth：

(
SynthDef("pseudorandom", { |out, sustain = 1, seed = 1967, id = 0|
    var noise, filterfreq;
    RandID.ir(id);
    RandSeed.ir(1, seed);


    noise = WhiteNoise.ar(0.05 ! 2) + Dust2.ar(70 ! 2);
    filterfreq = LFNoise1.kr(3, 5500, 6000);

    Out.ar(out,
        Resonz.ar(noise * 5, filterfreq, 0.5) + (noise * 0.5)
        *
        Line.kr(1, 0, sustain, doneAction: Done.freeSelf)
    )

}).add;
)

// 完全相同的音效被重现
(
fork {
    loop {
        Synth("pseudorandom");
        1.1.wait; // 等待比 sustain 稍长一点，这样声音就不会重叠
    }
}
)

// 改变随机种子会改变声音：

(
fork {
    (1902..2005).do { |seed|
        seed.postln;
        3.do {
            Synth("pseudorandom", [\seed, seed]);
            1.1.wait;
        }
    }
}
)

// cd 跳过器
(
fork {
    (1902..2005).do { |seed|
        seed.postln;
        rrand(4, 10).do {
            Synth("pseudorandom", [\seed, seed, \sustain, 0.05]);
            0.06.wait;
        }
    }
}
)

// 如果声音重叠，这就不再按预期工作了
// 声音会有所不同。

(
fork {
    loop {
        Synth("pseudorandom");
        0.8.wait; // 而不是 1.1
    }
}
)

// rand id 可用于限制每个声音对种子的重置：

(
fork {
    var id = 0;
    (1902..2005).do { |seed|
        seed.postln;
        3.do {
            Synth("pseudorandom", [\seed, seed, \id, id]);
            id = id + 1 % 16; // 有 16 种不同的随机生成器
            0.8.wait;
        }
    }
}
)
