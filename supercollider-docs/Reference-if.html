if

条件执行

参见：控制结构

if

example

if ( [false, true].choose,                // 布尔表达式（随机选择一个）
    { "expression was true".postln },    // true 函数
    { "expression was false".postln }    // false 函数
)

(
var a = 1, z;
z = if (a < 5, { 100 },{ 200 });
z.postln;
)

UGen 也可以使用 if

条件 ugen 为 0 / 1

(
    {
        if( LFNoise1.kr(1.0,0.5,0.5) , SinOsc.ar, Saw.ar )
    }.play
)
