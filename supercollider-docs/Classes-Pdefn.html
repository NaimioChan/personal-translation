Pdefn

非事件流引用定义

PatternProxy : Pattern : AbstractFunction : Object

参见：Pdef

说明

Pdefn 为其父类 PatternProxy 提供了一个接口，保留对可在播放时被替换的流的引用。一个模式可以在不同位置用于多个流中。模式定义的更改会传播到所有流。

Pdef 和 Pdefn 使用各自独立的全局集合。

Pdefn(key)    // 返回该实例
Pdefn(key, pat)    // 定义模式并返回实例，类似 Pdef、Tdef 和 Ndef。

它与 PatternProxy 非常相似。

Pdefn 可用于全局存储值模式（对于事件模式，请参见 Pdef）。概述：JITLib

第一个示例

s.boot;

Pdefn(\x, Pbrown(0, 6, 0.1, inf));
Pbind(\note, Pdefn(\x), \dur, 0.3).play;
Pbind(\note, Pdefn(\x), \dur, 0.1, \ctranspose, 15).play;
// 现在更改定义
Pdefn(\x, Pseq([0, 3, 5, 7, 9, 11], inf));
Pdefn(\x, Pseq([0, 3, 3, 7], inf) + Pseq([0, [0, 3], [0, 5, 7]], inf));

类方法

Pdefn.all

Pdefn.all = value

一个包含所有代理的全局 IdentityDictionary。

Creation

Pdefn.new(key, item)

将模式存储在键下的全局字典中，并用新模式替换其模式。如果模式是一个函数，Pdefn 会使用该函数创建一个 Prout，并在给定 envir 的情况下传入它（见下文）。

使用 *new(key) 可以访问该键处的模式（如果未给出，则创建一个默认的静音事件）

参数：

key

代理的标识符。通常它是一个 Symbol。该键会透明地访问全局 IdentityDictionary。

item

用于（重新）定义代理源的对象。如果为 nil，则返回未经修改的代理。

// pattern 作为参数
Pdefn(\x, Pseq([1, 2, 5, 6, 7], inf));
Pdefn(\x); // 省略第二个参数，我们可以访问代理
Pdefn(\x).asStream.nextN(20); // ... 播放一个事件流
Pdefn(\x).source.postcs; // ... 并检查事件模式本身。


// 函数作为参数，每次调用时创建一个新模式
Pdefn(\x, { Pseq({ 10.rand } ! 8) });
Pn(Pdefn(\x)).asStream.nextN(16);

// 该函数在传入事件中作为当前环境被调用，因此可以传递参数：
Pdef(\stut, { Pdup(~dup ? 1, ~pattern) }); // 这里我们使用 Pdef（不是 Pdefn！）
Pdefn(\y, Pdef(\stut) <> (pattern: Pdefn(\x), dup: Pseq([2, 2, 4, 3], inf))).asStream.nextN(16);

Pdefn.default

来自父类：PatternProxy

默认源，如果未指定则为默认值。默认是一个返回 1.0 的模式（此处为 1 而非 0，以避免在用作时长模式时发生死锁。从某种意义上说，1 和 0 一样通用）。

Pdefn.removeAll

来自父类：PatternProxy

从全局字典（*all）中移除所有代理

Pdefn.clear

来自父类：PatternProxy

清除所有代理，将其源设置为静音。

Pdefn.all

Pdefn.all = value

设置或返回存储所有 Pdefn 的环境（IdentityDictionary）。

示例

表达式中的 Pdefn

Pdefn(\c, Pdefn(\a) + Pdefn(\b));

t = Pdefn(\c).asStream; // 从 Pdefn(\c) 创建流

t.value; // Pdefn 的默认值为 1，因此它是一个良好的时间值默认值。

Pdefn(\a, 100); // （重新）将 Pdefn(\a) 定义为 100

t.value;

Pdefn(\b, Pseq([1, 2, 3], inf)); // （重新）将 Pdefn(\b) 定义为 Pseq([1, 2, 3], inf)

3.do { t.value.postln };

Pdefn(\c, Pdefn(\a) * Pdefn(\b) - Pdefn(\a)); // (重新)定义 Pdefn(\c)

8.do { t.value.postln };

Pdefn(\a, Prand([1, 4, 2], inf)); // (重新)定义 Pdefn(\a)

在其他模式中嵌入 Pdefn

Pdefn(\x, Pseq([1, 2, 3], inf));

x = Pseq([0, 0, Pdefn(\x)], inf).asStream;

t = Task({ loop({ x.next.postln; 0.3.wait }) }).play;


Pdefn(\x, Pseq([55, 66, 77], inf));
Pdefn(\x, Pseq([55, 66, 77], 1));

t.stop;

Timing

定义何时更改？

若设置了 quant，则更新在下一个节拍或所指定的时刻进行：

Pdefn(\deg).quant = 4;
Pdefn(\deg, Pn(Pseries(0, 1, 8), inf));

Pdefn(\deg).quant = nil; // 再次立即激活

(
Pdefn(\deg, {
    loop {
    5.do { |i|
        #[1, 3, 4].choose.yield;
        #[5, 0, 12].choose.yield;
        #[14, 3, 4].choose.do { |j| (i % j).postln.yield };
    }
    }
})
)

更新条件

为了能够在某个条件下切换到新的模式，可以把实例变量 condition 设为一个返回布尔值的函数。值和一个计数索引会被传给该函数。该条件始终对插入的下一个模式有效。对于卡住的条件，可以使用 reset 消息。

由于向上计数（例如“每第 n 个事件，可能发生一次交换”）是一项常见任务，因此有一个专门的方法，称为 count(n)。

z = Pbind(\degree, Pdefn(\x, \), \dur, 0.25).play;
Pdefn(\x, Pseq((0..5), inf)).condition_({ |val, i| i.postln % 6 == 0 });
Pdefn(\x, Pseq((7..0), inf)).condition_({ |val, i| i.postln % 8 == 0 });


// 上述等同于：
Pdefn(\x, Pseq((7..0), inf)).count(8);

// 重置以立即更改：
Pdefn(\x).reset;

Pdefn(\x).stop;

（内部）环境

// set() 创建一个局部环境，覆盖外部的 currentEnvironment

Pdefn(\z).set(\a, 1, \b, 5);
(
Pdefn(\z, { |e|
    loop { yield((e.a + e.b) + 0.1.rand.round(0.01)) }
})
); // [1]

t = Pdefn(\z).asStream;

t.nextN(3);

(
Pdefn(\z, { |e|
    // (e.a + e.b) + 0.1.rand.round(0.01) 1
    Pseq([1, 2, e.a], 1)
})
);

Pdefn(\z, Pseq([1, 2, 3], 1));

e = Pdefn(\z).envir


Pdefn(\z).set(\a, 3);

t.next;

Pdefn(\z).set(\a, Pseq([1, 2, 3], inf));

t.reset;
t.nextN(3);

Pdefn(\z).envir; // 发布环境变量



// 如果你想同时继续使用 currentEnvironment，
// 请将 currentEnvironment 赋值给 envir 的 parent（或 proto）字段
// （当然，这不应是一个 proxy space。）

Pdefn(\z).envir.parent = currentEnvironment;
~a = 9;
~b = 10;

t.nextN(3);
