NAryOpFunction

表示对函数的 n 元操作

AbstractFunction : Object

参见：BinaryOpFunction、UnaryOpFunction、NAryOpStream、Pnaryop、Operators

子类：NAryOpFunctionProxy

说明

对函数而不是数字进行操作时，得到的结果不是计算的结果，而是表示该计算的结构。

示例

// example
a = 0.8.linexp(0, 1, 40, 20000); // 将 (0..1) 以指数方式映射到人类听觉频率范围
a = { b }.linexp(0, 1, 40, 20000); // 结果是 a NAryOpFunction
b = 0.1;
a.value; // 现在它被求值，并计算出了结果
b = 0.5;
a.value; // 再次，使用不同的值。
// 声音示例
(
var a = { 1.0.rand };
var b = a.linexp(0, 1, 40, 20000);
fork {
    15.do {
        (instrument: \default, freq: b.value).play;
        0.3.wait;
    }
}
)
