Pselect

过滤源模式返回的值。

FuncFilterPattern : FilterPattern : Pattern : AbstractFunction : Object

参见：Pcollect、Preject、Collection: -select

说明

此模式将使用提供的函数 func 过滤源模式。

源模式的值将被传给 func。只有当 func 返回 true 时，Pselect 才会返回该值。

这是模式库中与 select 对应的模式。

类方法

Pselect.new(func, pattern)

来自父类：FuncFilterPattern

参数：

func

一个 Function，接受一个参数（pattern 的下一个值）并返回一个布尔值。

pattern

源 Pattern。

实例方法

示例

(
var a, b;

9.do({ x.next.postln });

当 select 消息被传递给模式时，返回一个 Pselect。

(
var a, b;
a = Pseq(#[1, 2, 3], inf).select({ |item| item != 2 });
a.postln;
x = a.asStream;
9.do({ x.next.postln });
)
