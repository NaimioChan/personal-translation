PulseCount

脉冲计数器。

UGen : AbstractFunction : Object

另请参阅：Stepper

子类：SetResetFF

说明

每个触发都会递增一个计数器，该计数器作为信号输出。

类方法

PulseCount.ar(trig: 0.0, reset: 0.0)

PulseCount.kr(trig: 0.0, reset: 0.0)

参数：

trig

Trigger。Trigger 可以是任何信号。当信号从非正变为正时，触发发生。

reset

触发时将计数器重置为零。

实例方法

示例

SynthDef("help-PulseCount", { |out = 0|
    Out.ar(out,
        SinOsc.ar(
            PulseCount.ar(Impulse.ar(10), Impulse.ar(0.4)) * 200,
            0, 0.05
        )
    )
}).play;
