DiskOut

录制到磁盘上的声音文件。

UGen : AbstractFunction : Object

另请参见：RecordBuf、DiskIn、VDiskIn

说明

录制到磁盘上的声音文件。使用 Buffer。

关于录制到内存中的缓冲区，请参见 RecordBuf。

磁盘录制流程

录制到磁盘涉及多个步骤，应按正确的顺序执行。Server: -record 会为你执行这些步骤。要显式使用 DiskOut 录制任意总线，请确保执行以下操作：

  1. 定义一个 DiskOut SynthDef，如下例所示。

  2. 为录音分配一个缓冲区。

    • 缓冲区大小应为 2 的幂。
    • 建议使用至少一秒的时长：s.sampleRate.nextPowerOfTwo。
    • 不要在 SynthDef 内部分配缓冲区。
    • 将缓冲区保存在变量中。
  3. 使用 Buffer: -write 指定文件路径和录制格式，并将 leaveOpen 标志设为 true。这是设置文件路径和录制格式的唯一方法。
  4. 创建一个 Synth 节点来运行 DiskOut UGen。
  5. 录制完成后，停止 DiskOut synth。
  6. 关闭缓冲区：b.close。此步骤会更新所录制文件的音频头。若不执行此步骤，文件将无法使用。
  7. 释放缓冲区：b.free。

这些步骤在 Examples 部分中进行了说明。通常只需要“对象风格”方法。（“消息传递风格”作为历史参考提供，但在典型使用中并不需要。）

类方法

DiskOut.ar(bufnum, channelsArray)

参数：

bufnum

要写入的缓冲区编号（通过 /b-write 或 Buffer.write 准备）

注意： Buffer 的 numFrames 必须是 2 的幂，建议至少为 65536——最好是 131072 或 262144。较小的缓冲区大小意味着更频繁的磁盘访问，这可能导致故障。

channelsArray

要写入文件的通道数组。

注意： 缓冲区中的声道数必须与 channelsArray 相同，否则 DiskOut 会静默失败（并且不会向你的文件写入任何内容）。

返回值：

写入磁盘的帧数。

实例方法

示例

s.boot; // 启动服务器
(
// 要录制的内容
SynthDef("bubbles", { |out|
    var f, zout;
    f = LFSaw.kr(0.4, 0, 24, LFSaw.kr([8, 7.23], 0, 3, 80)).midicps; // 滑音函数
    zout = CombN.ar(SinOsc.ar(f, 0, 0.04), 0.2, 0.2, 4); // 回声正弦波
    Out.ar(out, zout)
}).add;

// 这将录制到磁盘
SynthDef("help-Diskout", { |bufnum|
    DiskOut.ar(bufnum, In.ar(0, 2));
}).add;

// 这将回放它
SynthDef("help-Diskin-2chan", { |out, bufnum = 0|
    Out.ar(out, DiskIn.ar(2, bufnum))
}).add;
)

对象风格

// 启动一些东西来录制
x = Synth("bubbles");

// 分配一个磁盘 I/O 缓冲区
b = Buffer.alloc(s, 65536, 2);

// 为此 buffer 创建一个输出文件，保持其打开状态
b.write("~/diskouttest.wav".standardizePath, "wav", "int16", 0, 0, true);
// 创建 diskout 节点；确保它位于源之后
d = Synth.tail(nil, "help-Diskout", ["bufnum", b]);
// 停止录制
d.free;
// 停止气泡
x.free;
// 关闭缓冲区和声音文件
b.close;
// 释放缓冲区
b.free;

// 播放回来
(
x = Synth.basicNew("help-Diskin-2chan");
m = { |buf| x.addToHeadMsg(nil, [\bufnum, buf]) };

b = Buffer.cueSoundFile(s, "~/diskouttest.wav".standardizePath, 0, 2, completionMessage: m);
)
x.free; b.close; b.free; // cleanup

消息传递风格

// 同样的事情用消息风格（开销更小，但没有对象的便利性）完成
// 这与消息风格示例做的事情没有不同。
// 如果以下任何内容让你困惑，请坚持使用对象风格
// 并忽略这一部分。

// 启动一些东西来录制
s.sendMsg("/s_new", "bubbles", 2003, 1, 1);

// 分配一个磁盘 I/O 缓冲区
s.sendMsg("/b_alloc", 0, 65536, 2); // 缓冲区编号为 0

// 为此 buffer 创建一个输出文件，保持其打开状态
s.sendMsg("/b_write", 0, "~/diskouttest.wav".standardizePath, "wav", "int16", 0, 0, 1);

// 创建 diskout 节点
s.sendMsg("/s_new", "help-Diskout", 2004, 3, 2003, "bufnum", 0);

s.sendMsg("/n_free", 2004); // 停止录制
s.sendMsg("/n_free", 2003); // 停止气泡

s.sendMsg("/b_close", 0); // 关闭文件。
s.sendMsg("/b_free", 0);
