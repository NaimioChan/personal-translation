LinkedList

双向链表

SequenceableCollection : Collection : Object

说明

LinkedList 实现了一个双向链表。

大多数方法继承自父类。

类方法

实例方法

.addFirst(obj)

将一项添加到列表的头部。

.add(obj)

将一项添加到列表的尾部。

.remove(obj)

从列表中移除一个项。

.pop

移除并返回列表中的最后一项。

.popFirst

移除并返回列表中的第一个元素。

.first

返回列表中的第一个元素。

.last

返回列表中的最后一项。

.at(index)

返回列表中给定索引处的项。这需要对列表进行扫描，因此为 O(n)。

.put(index, item)

将条目放到列表中的给定索引处。这需要扫描列表，因此复杂度为 O(n)。

.removeAt(index)

移除并返回列表中给定索引处的项。这需要扫描列表，因此为 O(n)。
