Node

Synth 和 Group 的抽象父类

Object

参见：Server Architecture、Synth、Group、RootNode

子类：AbstractGroup、Synth

说明

此类是 Synth 和 Group 的抽象父类，它们表示服务器上的 synth 节点和组节点。节点对象不会被显式创建，但 Synth 和 Group 是子类，并继承下面记录的方法。

已释放的节点与节点状态

你使用 free 或 release 方法显式释放的节点，其 group 实例变量会被设为 nil。然而，在一定时间后自动释放的节点（例如由 doneAction 为 2 的 EnvGen 释放）则不会如此。这使得类的实现保持简单和轻量。

要跟踪某个 Node 的当前状态，你可以将其注册到一个 NodeWatcher 实例，方法是在该 Node 实例上调用 register，或是在 NodeWatcher 单例上调用。这将启用两个变量，isPlaying 和 isRunning，你可以用它们来进行检查。

Bundling

下面的许多方法有两个版本：常规版本会立即将对应消息发送到服务器，另一个版本则将消息返回为 Array，以便加入 bundle。也可以利用 Server 的自动打包功能捕获常规方法生成的消息。详情请参阅 Server 和 Bundled Server Messages。

讨论：

节点命令

下面所列方法的 OSC 等价形式参见 Server Command Reference 中的 Node Commands 一节。

.free(sendFlag: true)

.freeMsg

停止此 Node 并在服务器上将其从父组中释放。一旦 Node 被释放，就无法重新启动它。

参数：

(sendFlag)

一个布尔值，表示是否应发送 free 消息。若为 false，则不会向此 Node 的服务器发送 n_free 消息，但其 isPlaying 和 isRunning 变量将被设为 false。sendFlag 的默认值为 true。

讨论：

如果此 Node 是一个 Group，这将释放该 Group 内的所有 Node。

s.boot;
x = Synth("default");
x.free;

.run(flag: true)

.runMsg(flag: true)

根据布尔值设置此 Node 的运行状态。False 将暂停节点而不释放它。默认为 true。

讨论：

如果此 Node 是一个 Group，这将设置该 Group 内所有 Node 的运行状态。

s.boot;
(
x = SynthDef("help-node-set", { |freq = 440, out = 0|
    Out.ar(out, SinOsc.ar(freq, 0, 0.1))
}).play
)
x.run(false);
x.run; // 默认值为 true
x.free;

.set( ... args)

.setMsg( ... args)

将此节点中的控制设为指定值。

讨论：

Controls 在 SynthDef 中定义为参数或 Control 的实例。此处使用符号、字符串或索引来指定，并与值成对列出。如果此 Node 是一个 Group，则将设置该 Group 内的所有 Node。

s.boot;
(
x = SynthDef("help-node-set", { |freq = 440, out = 0|
    Out.ar(out, SinOsc.ar(freq, 0, 0.1))
}).play
)
x.set(\freq, 880, \out, 1); // 两对
x.set(0, 660, 1, 0); // freq 是第一个参数，所以它的索引是 0。out 是索引 1。
x.free;

值为数组时会使用 OSC 数组类型标签（$[ 和 $]）发送。这些值将按照 setn 的方式分配给后续的控制。

s.boot;
(
x = SynthDef("help-node-set", { |freq = #[440, 450, 460], out = 0|
    Out.ar(out, Mix(SinOsc.ar(freq, 0, 0.1)))
}).play
)
x.set(\freq, [1, 2, 3] * 400 + [1, 2, 3], \out, 1); // 两对
x.set(\freq, [3] * 400 + [1, 2, 3], \out, 1); // 两对
x.set(0, [660, 680, 720], 1, 0); // freq 是第一个参数，所以它的索引是 0。out 是索引 1。
x.free;

.setn( ... args)

.setnMsg( ... args)

将此 Node 中连续的控件范围设置为指定值。

讨论：

Controls 在 SynthDef 中定义为参数（args）或 Control 的实例。此处使用符号、字符串或索引来指定它们，并以数组值成对列出。如果此 Node 是一个 Group，则将为该 Group 内的所有 Node 设置。

s.boot;
(
x = SynthDef("help-node-setn", {
    arg out, freq1 = 440, freq2 = 440, freq3 = 440, amp1 = 0.05, amp2 = 0.05, amp3 = 0.05;
    Out.ar(out, Mix(SinOsc.ar([freq1, freq2, freq3], 0, [amp1, amp2, amp3])))
}).play;
)
// 从 \freq1 开始设置 3 个控制，并从 \amp1 开始设置 3 个控制
x.setn(\freq1, [440, 880, 441], \amp1, [0.3, 0.1, 0.3]);
x.free;

.fill(controlName, numControls, value ... args)

.fillMsg(controlName, numControls, value ... args)

将此 Node 中的连续控制段范围设置为单个值。

讨论：

控制项在 SynthDef 中定义为参数或 Control 的实例。此处使用符号、字符串或索引来指定它们，并按每三个一组列出，同时附带一个整数表示要设置的控制项数量，以及要设置的值。如果此节点是组，则将填充组内所有节点。

.map( ... args)

.mapMsg( ... args)

将此节点中的控件映射为从控制速率或音频速率的总线读取。

讨论：

控制项在 SynthDef 中定义为参数，或者作为 Control 或其子类的实例。此处使用符号、字符串或索引来指定它们，并与 Bus 对象成对列出。所映射的连续控制项数量对应于该 Bus 的通道数。

如果此 Node 是一个 Group，则此操作将映射该 Group 内的所有 Node。

注意，使用 mapMsg 时，如果你混用音频总线和控制率总线，你将得到一个包含两条消息的 Array，而不是单条消息。整数总线索引被假定为指代控制总线。要将控制映射到音频总线，必须使用 Bus 对象。

s.boot;
(
b = Bus.control(s, 1); b.set(880);
c = Bus.control(s, 1);    c.set(884);
x = SynthDef("help-Node-map", { |out, freq1 = 440, freq2 = 440|
    Out.ar(out, SinOsc.ar([freq1, freq2], 0, 0.1));
}).play
)
x.map(\freq1, b, \freq2, c);
x.free; b.free; c.free;

// 同上，但使用多通道 Bus 和 Control
(
b = Bus.control(s, 2);
b.set(880, 884);
x = SynthDef("help-Node-map2", { |out, freqs = #[440, 440]|
    Out.ar(out, SinOsc.ar(freqs, 0, 0.1));
}).play
)

x.map(\freqs, b);
x.free; b.free;

.mapn( ... args)

.mapnMsg( ... args)

将此 Node 中连续的控件范围映射到从控制速率总线读取。

讨论：

这与上面的 map 类似，但你要指定要映射的连续 Controls 的数量。如果此 Node 是一个 Group，则会映射该 Group 内的所有 Node。

.release(releaseTime)

.releaseMsg(releaseTime)

此方法使接收者在指定的时间后释放。这是一个便捷方法，它假定 Synth 包含一个包络生成器（EnvGen、Linen 或类似的 UGen），运行持续包络（参见 Env: Sustained Envelope Creation Methods），并且此包络的 gate 参数设置为名为 \gate 的控件。

参数：

releaseTime

节点释放所用的时间，以秒为单位。如果设置为 <= 0 的值，合成器将立即释放。值为 nil 将导致合成器使用其包络的正常释放阶段进行释放。

注意： 提供 releaseTime != nil 不会触发常规释放，而是触发一种称为强制释放的不同行为。这一差异对于具有多节点释放阶段的包络尤为重要，即其 releaseNode 不是最后一个节点的包络。参见 EnvGen: Forced release。

讨论：

如果接收者是一个 Group，组内的所有节点都将被释放。

x = { |gate = 1| BrownNoise.ar(0.5) * EnvGen.kr(Env.cutoff(1), gate, doneAction: Done.freeSelf) }.play;
x.release(5); // 覆盖 Env 指定的 1 秒释放时间

.query(action)

向服务器发送一条 n_query 消息，服务器将回复一条包含有关此节点及其在服务器节点树中位置的信息的消息。

参数：

action

一个可选的 Function，将被调用。如果节点是 Synth，该函数将接受参数 serverCmd, nodeID, parent, prev, next, isGroup。如果节点是 Group，该函数将接受参数 serverCmd, nodeID, parent, prev, next, isGroup, head, tail。在此处提供函数将绕过 query 的正常行为，即通常的节点信息将不会被发送。

讨论：

此信息将打印到 post 窗口。（另请参见 Server 的 queryAllNodes 方法。）“parent”表示 Node 所属的组。如果“prev”或“next”等于 -1，则分别表示在所属组中该节点之前或之后没有其他节点。

g = Group.new;
x = Synth.head(g, "default");
x.query;
g.query;
s.queryAllNodes; // 注意 RootNode（ID 0）和默认 Group（ID 1）
x.free; g.free;

.trace

使一个 synth 在一个控制周期内将其各 unit generator 的输入和输出值打印到 post 窗口。使一个 group 在一个控制周期内打印该组中每个节点的节点 ID 和名称。

g = Group.new;
x = Synth.head(g, \default);
x.trace;
g.trace;
x.free; g.free;

.register(assumePlaying: false)

在 NodeWatcher 对象中注册该节点。

讨论：

这将启用两个变量：isPlaying 和 isRunning，你可以用它们来进行检查。

(
b = s.makeBundle(false, {
    a = Group.new(s); // 创建节点对象
    a.register // 在服务器上创建之前注册
})
)

a.isPlaying;
s.listSendBundle(nil, b); // 在服务器上启动节点
a.isPlaying;
a.isRunning;
a.run(false);
a.isRunning;
s.freeAll; // 释放所有节点
a.isPlaying;
a.isRunning;

更改执行顺序

以下方法可用于更改 Node 在执行顺序中的位置。有关这一重要主题的更多信息，请参阅 Order of execution 帮助文件。有关这些方法的 OSC 等价形式，请参阅 Server Command Reference。

.moveAfter(aNode)

.moveAfterMsg(aNode)

将此 Node 移动到 aNode 之后。注意：此方法封装的 OSC 消息 n_after 允许已释放的节点作为目标。这样，可以尝试一系列移动，最后一个成功的移动生效。因此，如果目标或此节点已被释放，此方法将静默失败。如果需要检查，你可以用 NodeWatcher 注册相关节点。

.moveBefore(aNode)

.moveBeforeMsg(aNode)

将此 Node 移动到 aNode 的正前方。注意：此方法所封装的 OSC 消息 n_before 允许已释放的节点作为目标。这样，人们可以尝试一系列移动，以最后一次成功的移动生效。因此，如果目标或此节点已经被释放，此方法将静默失败。如果需要检查，可以用 NodeWatcher 注册相关节点。

.moveToHead(aGroup)

.moveToHeadMsg(aGroup)

如果 aGroup 是一个 Group，则此方法会将此 Node 移动到该 Group 的头部。如果为 nil，则将此 Node 移动到其服务器的 default_group 的头部。

.moveToTail(aGroup)

.moveToTailMsg(aGroup)

如果 aGroup 是一个 Group，则此方法会将此 Node 移动到该 Group 的尾部。如果为 nil，则将此 Node 移动到其服务器的 default_group 的尾部。

.printOn(stream)

.hash

返回值：

server.hash bitXor: nodeID.hash

==(that)

返回值：

如果此 Node 和 aNode 具有相同的 nodeID 和相同的 Server 对象，则为 true，否则返回 false。

讨论：

在某些情况下，即使此方法返回 true，此 Node 和 aNode 也可能不是同一个对象。

g = Group.basicNew(s, 1); // s 的默认组
h = Group.basicNew(s, 1); // 再次
g == h;     // true
g === h;    // false

.onFree(func)

此 Node 被释放时求值的函数。

讨论：

{ PinkNoise.ar(1) * Line.kr(1, 0, 2, doneAction: Done.freeSelf) }.play.onFree { "done".postln };

.waitForFree

等待该 Node 被释放。应在 Routine 或类似上下文中使用。

讨论：

(
fork {
    { SinOsc.ar(440 ! 2) * Line.kr(0, 1, 5, doneAction: Done.freeSelf) }.play.waitForFree;
    { PinkNoise.ar(1) * Line.kr(1, 0, 2, doneAction: Done.freeSelf) }.play.onFree { "done".postln };
}
)
(
SynthDef(\help, { |out|
    var mod = LFNoise2.kr(Rand(1, 6)) * 0.2;
    var snd = mod * Blip.ar(Rand(200, 800) * (mod + 1));
    Out.ar(out, snd);
    FreeSelf.kr(mod < 0);
}).add;
)

(
fork {
    10.do {
        "started a synth".postln;
        Synth(\help).waitForFree;
        "This one ended. Wait a second, I will start the next one.".postln;
        1.wait;
    };
    "This is it.".postln;
}
);
