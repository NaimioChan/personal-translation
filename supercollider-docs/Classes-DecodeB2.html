DecodeB2

2D Ambisonic B-format 解码器。

MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：BiPanB2、PanB、PanB2、Rotate2

说明

将一个二维环绕声 B-format 信号解码到一组按正多边形排列的扬声器。输出将按顺时针顺序排列。第一个扬声器的位置是居中或中心偏左。

类方法

DecodeB2.ar(numChans, w, x, y, orientation: 0.5)

DecodeB2.kr(numChans, w, x, y, orientation: 0.5)

参数：

numChans

输出扬声器数量。通常为 4 到 8。必须是非零正整数。此值在编译 SynthDef 时固定，因此不能赋值给 SynthDef 参数。

w

B-format 信号。

x

B-format 信号。

y

B-format 信号。

orientation

如果前方是多边形的一个顶点，则应为零。第一个扬声器将位于正前方。如果前方平分多边形的一条边，则应为 0.5。此时第一个扬声器将是中心偏左的那个。

返回值：

一个通道数组，每个扬声器对应一个通道。

实例方法

示例

(
{
    var w, x, y, p, a, b, c, d;

    p = PinkNoise.ar; // source

    // B-format 编码
    #w, x, y = PanB2.ar(p, MouseX.kr(-1, 1), 0.1);

    // B-format 解码为四声道
    #a, b, c, d = DecodeB2.ar(4, w, x, y);

    [a, b, d, c] // 重新排序为我的扬声器布局：Lf Rf Lr Rr
}.play;
)
