DragBoth

一个简单的拖放源与接收者

另请参见：DragSink、DragSource

说明

DragSource、DragSink 和 DragBoth 是一组视图类，旨在作为简单易用的拖放源和拖放目标。它们在图形上表示为简单的矩形，其特点是无需按住 Cmd/Ctrl 键即可开始拖动。

与 StaticText 类似，它们可以在 -object 变量中存储任意内容，并使用 Object: -asString 显示它。你可以使用 -string 单独设置显示的文本，并且如果将 -setBoth 设为 false，就可以使其与内容保持独立。

DragBoth 具体而言，接受任何被拖放的数据，并将其存入 -object 变量，同时将该变量作为用于拖动的数据提供。

参见：View: Drag and drop 了解拖放机制的一般说明。

类方法

实例方法

.defaultGetDrag

返回值：

该 -object。

.defaultCanReceiveDrag

返回值：

始终为真。

.defaultReceiveDrag

将 -object 设置为当前拖拽的数据。

示例

(
w = Window.new.front;
w.addFlowLayout;
// 在拖拽源中存储各种类型的对象

// 字符串源
a = DragBoth(w, Rect(10, 10, 150, 20)).align_(\center).background_(Color.rand);
a.object = "drag us around";

a = DragBoth(w, Rect(10, 10, 150, 20)).align_(\center).background_(Color.rand);
a.object = "SUPERCOLLIDER";

8.do{
a = DragBoth(w, Rect(10, 10, 150, 20)).align_(\center).background_(Color.rand);
a.receiveDragHandler = { |obj| obj.object = View.currentDrag.scramble };
}
)
