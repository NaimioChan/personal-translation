Pkey

访问事件流中的一个键

Pattern : AbstractFunction : Object

参见：Penvir

说明

Pkey 简化了对正由 Pbind 或其他事件模式处理的事件中值的反向访问。

类方法

Pkey.new(key, repeats)

参数：

key

要读取的事件变量名称。

repeats

完成之前返回的项数。使用默认值 nil 会使流无限。

实例方法

未文档化的实例方法

.asStream

.embedInStream(inval)

.key

.key = value

.repeats

.repeats = value

示例

// 因此 \b 在每个事件中应取 \a 值的两倍：
p = Pbind(\a, Pwhite(1, 10, inf), \b, Pkey(\a) * 2).asStream;


p.next(())    // 对于 Pbind，即使为空也必须传入默认事件

('a': 10, 'b': 20)
('a': 2, 'b': 4)
('a': 5, 'b': 10)
('a': 4, 'b': 8)
('a': 2, 'b': 4)

// 注意：要检查 Pkey 的结果是否 /等于/ 另一个值，
// 请务必使用 |==|
p = Pbind(
    \a, Pseries(1, 1, inf),
    \b, Pif(
        Pkey(\a) == 2,
        "equals 2",
        "nope"
    )
).asStream;

p.next(());  // 'b' 始终是 "nope"

p = Pbind(
    \a, Pseries(1, 1, inf),
    \b, Pif(
        Pkey(\a) |==| 2,
        "equals 2",
        "nope"
    )
).asStream;

p.next(());  // 'b' 符合预期
