OSCdef

OSC 响应参考定义

OSCFunc : AbstractResponderFunc : Object

另请参阅：OSC Communication、OSCFunc、NetAddr

说明

OSCdef 提供了对其父类 OSCFunc 功能的全局引用。实质上，它将自己存储在一个全局字典的某个键下，从而允许随时替换。大多数方法继承自其父类。

类方法

OSCdef.all

获取所有 OSCdef 的全局字典。

返回值：

一个 IdentityDictionary。

OSCdef.new(key, func, path, srcID, recvPort, argTemplate, dispatcher)

创建一个新的、已启用的 OSCdef。如果此键处已存在 OSCdef，其参数将被所提供的参数替换（传入 nil 的参数将使用旧值）。

参数：

key

在全局集合中存储此 OSCdef 所用的键。通常这是一个 Symbol。

func

一个 Function 或类似对象，将响应传入的消息。在求值时，将向它传递以下参数：

msg

消息，形式为 [OSC 地址, args1, arg2, ...] 的数组

time

接收时间（对于消息）/ OSC bundle 的时间戳（如果消息位于 bundle 中）

addr

与发送方 IP 地址对应的 NetAddr

recvPort

与接收消息的端口对应的整数。

msg

消息，形式为 [OSC 地址, args1, arg2, ...] 的数组

time

接收时间（对于消息）/ OSC bundle 的时间戳（如果消息位于 bundle 中）

addr

与发送方 IP 地址对应的 NetAddr

recvPort

与接收消息的端口对应的整数。

path

一个 Symbol，指示此对象 OSC 地址的路径。请注意 OSCdef 要求符合 OSC 规范的地址。如果路径不以 / 开头，将自动添加一个。

srcID

一个可选的 NetAddr 实例，表示发送者的 IP 地址。如果设置此对象，它将只响应来自该来源的消息。

recvPort

一个可选的 Integer，指示接收消息所用的端口。若设置此项，该对象将只响应在该端口上接收到的消息。此方法会调用 Main: -openUDPPort 以确保该端口已打开。

argTemplate

一个可选的 Array，由 Integer 或 Function 的实例（或响应方法 Methods: matchItem 的对象）组成，用于匹配传入 OSC 消息的参数。如果是 Function，则会将对应的消息参数作为参数对其求值，并且应返回一个 Boolean，指示该参数是否匹配以及此 OSCdef 是否应响应（前提是所有其他参数都匹配）。模板值为 nil 将匹配任何传入的参数值。

dispatcher

一个可选的、属于 AbstractDispatcher 相应子类的实例。可用于实现自定义的分发。通常不需要这样做。

返回值：

OSCdef 的一个实例。

OSCdef.newMatching(key, func, path, srcID, recvPort, argTemplate)

一个便捷方法，用于创建一个新的、已启用的 OSCdef，其调度器会对传入的 OSC 消息执行模式匹配，以查看它们的地址模式是否匹配此对象的路径。

参数：

key

在全局集合中存储此 OSCdef 所用的键。通常这是一个 Symbol。

func

一个 Function 或类似对象，它将响应传入的消息。求值时，它会被传入参数 msg、time、addr 和 recvPort，分别对应于作为 Array [OSC 地址, args1, arg2, ...] 的消息、消息发送的时间、对应于发送方 IP 地址的 NetAddr，以及对应于接收消息端口的 Integer。

path

一个 Symbol，表示该对象 OSC 地址的路径。注意，OSCdef 要求地址符合 OSC 规范。如果路径不以 / 开头，会自动添加一个。模式匹配将应用于所有传入消息，以检查它们是否匹配此地址。注意，根据 OSC 规范，正则表达式通配符仅允许出现在传入消息的地址模式中。因此 path 不应包含通配符。有关 OSC 模式匹配的更多细节，请参见 http://opensoundcontrol.org/spec-1_0

srcID

一个可选的 NetAddr 实例，表示发送者的 IP 地址。如果设置此对象，它将只响应来自该来源的消息。

recvPort

一个可选的 Integer，指示接收消息所用的端口。

argTemplate

一个可选的 Array，由 Integer 或 Function 的实例（或响应方法 Methods: matchItem 的对象）组成，用于匹配传入 OSC 消息的参数。如果是 Function，则会将对应的消息参数作为参数对其求值，并且应返回一个 Boolean，指示该参数是否匹配以及此 OSCFunc 是否应响应（前提是所有其他参数都匹配）。模板值为 nil 将匹配任何传入的参数值。

返回值：

OSCdef 的一个实例。

OSCdef.freeAll

清除并停用全局集合中的所有 OSCdef。

实例方法

.key

获取此 OSCdef 的 key。

返回值：

通常是一个 Symbol。

.free

将此 OSCdef 从全局集合中清除并停用它。

示例

n = NetAddr("127.0.0.1", 57120); // 本地机器

OSCdef(\test, { |msg, time, addr, recvPort| \unmatching.postln }, '/chat', n); // 定义风格
OSCdef.newMatching(\test2, { |msg, time, addr, recvPort| \matching.postln }, '/chat', n); // 路径匹配
OSCdef(\test3, { |msg, time, addr, recvPort| \oneShot.postln }, '/chat', n).oneShot; // 仅一次


m = NetAddr("127.0.0.1", 57120); // 回环

m.sendMsg("/chat", "Hello App 1");
m.sendMsg("/chat", "Hello App 1"); // 一次性已消失
m.sendMsg("/ch?t", "Hello App 1");
m.sendMsg("/*", "Hello App 1");
m.sendMsg("/chit", "Hello App 1"); // 无

// 内省

AbstractResponderFunc.allFuncProxies
AbstractResponderFunc.allEnabled
OSCdef(\test).disable;
AbstractResponderFunc.allDisabled

// 更改函数
OSCdef(\test).enable;
OSCdef(\test, { |msg, time, addr, recvPort| 'Changed Unmatching'.postln }, '/chat', n); // 在键 \test 处替换
m.sendMsg("/chat", "Hello App 1");
OSCdef(\test).add(f = { \foo.postln }); // 添加另一个函数
m.sendMsg("/chat", "Hello App 1");
OSCdef(\test).clear; // 移除所有函数
m.sendMsg("/chat", "Hello App 1");
OSCdef(\test).free;  // 注销 OSCdef


//////// 使用 argTemplate 进行更精细的匹配

s.boot;
x = Synth(\default);
OSCdef(\watchForXEnd, { 'ended!'.postln }, '/n_end', s.addr, nil, [x.nodeID]).oneShot;
x.release(3);

// 传入 nil 的参数将沿用旧值。虽然这便于只替换 OSCdef 的某些部分（例如函数），但这也意味着你必须释放并重新创建 OSCdef 才能移除某些部分。

OSCdef(\argtest, { |msg ... args| msg[1].postln }, '/hey', argTemplate: ['you']);
m.sendMsg("/hey", "you"); // oscdef 会响应
m.sendMsg("/hey", "there"); // oscdef 将不会响应，被 argTemplate 过滤掉

OSCdef(\argtest, argTemplate: nil); // 这没有效果
m.sendMsg("/hey", "you"); // oscdef 会响应
m.sendMsg("/hey", "there"); // oscdef 不会响应，仍会被 argTemplate 过滤掉

OSCdef(\argtest).free; // 为了摆脱 argTemplate，请释放 def...
OSCdef(\argtest, { |msg ... args| msg[1].postln }, '/hey'); // ……并重新创建它。
m.sendMsg("/hey", "you"); // oscdef 会响应
m.sendMsg("/hey", "there"); // oscdef 会响应

传入 bundle 中的定时

time 参数表示消息发送的时间，加上（如果给出）添加到 bundle 的延迟：

(
OSCdef(\x, { |msg, time|
    "reception time: %\nscheduling time: %\ndelta: %\n\n".postf(Main.elapsedTime, time, time - Main.elapsedTime)
}, \time);

n = NetAddr("127.0.0.1", 57120);
)

(
n.sendBundle(0.0, [\time]);
n.sendBundle(1.0, [\time]);
)
