PitchShift

时域变调器。

UGen : AbstractFunction : Object

说明

一个时域颗粒移调器。颗粒具有三角振幅包络，重叠比为 4:1，并对缓冲区使用线性插值。

类方法

PitchShift.ar(in: 0.0, windowSize: 0.2, pitchRatio: 1.0, pitchDispersion: 0.0, timeDispersion: 0.0, mul: 1.0, add: 0.0)

参数：

in

输入信号。

windowSize

颗粒窗口的大小，单位为秒。此值无法被调制。最小值为 3 个采样周期。如果提供更小的值，将被向上舍入到最小值。

pitchRatio

音高偏移的比率。必须从 0 到 4。

pitchDispersion

音高相对于……的最大随机偏差

pitchRatio 。

timeDispersion

从零到 timeDispersion 秒的随机偏移量会被加到每个颗粒的延迟上。使用一定的分散可以缓解因颗粒均匀放置而产生的强烈梳状滤波效应。它本身也可以作为一种效果。timeDispersion 不能大于 windowSize。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

(
play({
    z = Blip.ar(800, 6, 0.1);
    PitchShift.ar(z, 0.02, Line.kr(0.1, 4, 20), 0, 0.0001)
}))

(
// 音高移动输入 - 使用耳机以防止反馈。
play({
    PitchShift.ar(
        SoundIn.ar([0, 1]),    // 立体声音频输入
        0.1,             // 颗粒大小
        MouseX.kr(0, 2),    // 鼠标 x 控制变调比率
        0,                 // 音高离散度
        0.004            // 时间弥散
    )
}))

(
// 使用 PitchShift 对输入进行颗粒化处理 - 请戴耳机以防止反馈。
// 左上角是正常播放。x = 音高分散度，y = 时间分散度
var grainSize;
grainSize = 0.5;
play({
    PitchShift.ar(
        SoundIn.ar([0, 1]),
        grainSize,
        1,                        // 标称音高比率 = 1
        MouseX.kr(0, 1),             // 音高离散度
        MouseY.kr(0, grainSize)    // 时间弥散
    )
}))
