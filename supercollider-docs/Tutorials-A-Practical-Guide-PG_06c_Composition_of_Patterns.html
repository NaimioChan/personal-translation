模式指南 06c：模式的组合

让多个事件模式作为一个整体运作

另见：Pattern Guide 06b: Time Based Patterns、Pattern Guide 06d: Parallel Patterns

向基础事件模式添加值（即“模式组合”）

使用模式的一种方式是将所有内容预先写入模式中。这具有清晰易懂的优点。另一种方式是通过创建更小、更简单的模式并将其结果组合成具有来自所有组件模式的键和值的单一事件，从而实现行为的模块化。

这与计算机科学中的“函数组合”概念有关，其中复杂的计算可以不是写成一个单一的大函数，而是写成几个较小的函数，然后将它们链接成一个单一函数。由于 Function 在 SuperCollider 中是普通对象，因此很容易对一个函数执行操作并返回一个组合函数（之后可以像任何其他函数一样使用）。http://en.wikipedia.org/wiki/Function_composition_(computer_science)

在数学中，· 运算符表示函数复合。

f(x) = x + 1
g(x) = x * 2

g · f = g(f(x)) = (x + 1) * 2

g · f 表示先求值 f，然后将其结果传给 g。· 运算符在 SuperCollider 中写作 <>。

f = { |x| x + 1 };
g = { |x| x * 2 };

h = (g <> f);
--> a Function

h.value(1);
--> 4    // == (1+1) * 2

(f <> g).value(1)
--> 3    // == (1*2) + 1

// g · f == g(f(x)) -- 先计算 f，然后将其结果传递给 g
g.value(f.value(1));
--> 4

事件模式可以类似地组合。

Pbindf(pattern, pairs)

向已有的 Pbind 风格模式添加新的键值对。Pbindf(Pbind(\a, patternA), \b, patternB, \c, patternC) 与 Pbind(\a, patternA, \b, patternB, \c, patternC) 得到相同的结果。

Pchain(patterns)

Chains 将 Pbind 风格的模式串联在一起，使它们所有的键值对都进入同一个事件。例如，如果你的代码一部分创建了 Pbind 实例 a = Pbind(\a, patternA)，另一部分创建了 b = Pbind(\b, patternB, \c, patternC)，你可以用 Pchain(b, a) 将 \b 和 \c 追加到 \a 的结果中。子模式按相反顺序求值，这与函数复合的记法一致。

为音乐目的，你可以让代码的一部分创建一个定义节奏的模式，另一部分定义音高素材，然后用 Pchain 将它们组合起来。

~rhythm = Pbind(
    \dur, Pwrand(#[0.125, 0.25, 0.5], #[0.3, 0.5, 0.2], inf),
    \legato, Pwrand(#[0.1, 0.6, 1.01], #[0.1, 0.3, 0.6], inf)
);
~melody = Pbind(
    \degree, Pwhite(-4, 11, inf)
);

p = Pchain(~melody, ~rhythm).play;
p.stop;

这本身对算法作曲就有很好的潜力。将 EventPatternProxy 引入其中，使得可以即时地换入换出不同的旋律和节奏组件，而没有任何中断。我们甚至可以改变模式的类型（Pbind、Pmono、PmonoArtic）而不产生不良影响。

~rhythm = EventPatternProxy(Pbind(
    \dur, Pwrand(#[0.125, 0.25, 0.5], #[0.3, 0.5, 0.2], inf),
    \legato, Pwrand(#[0.1, 0.6, 1.01], #[0.1, 0.3, 0.6], inf)
));

~melody = EventPatternProxy(Pbind(
    \degree, Pwhite(-4, 11, inf)
));

p = Pchain(~melody, ~rhythm).play;

~melody.source = PmonoArtic(\default, \degree, Pseries(4, Prand(#[-1, 1], inf), inf).fold(-4, 11));

~melody.source = Pbind(\degree, Pseries(4, Pwrand(#[-2, -1, 1, 2], #[0.3, 0.2, 0.2, 0.3], inf), inf).fold(-4, 11));

p.stop;

Pset 及其同类

一组模式类允许覆盖单个事件键，或者执行一次加法或乘法。Pkey 与 Pchain 或 Pbindf 这些“模式组合”类结合使用时，可以完成下列各类能做的所有事情（不过在某些情况下这种替代写法可能更方便）。

Pset(name, value, pattern)

从模式中获取一个事件，然后将值模式中的下一个值放入 name 键。如果源模式为同一个 name 指定了值，源中的值将被新值替换。

Padd(name, value, pattern)

获取下一个事件后，将 name 的值替换为其现有值加上 value 中的下一个数字。

Pmul(name, value, pattern)

获取下一个事件后，将 name 的值替换为其现有值乘以 value 中的下一个数字。

这些模式保留在库中主要是为了向后兼容，因为它们的行为可以很容易地使用 Pbindf 来复现。

Pset(name, value, pattern)

Pbindf(pattern, name, value)

Padd(name, value, pattern)

Pbindf(pattern, name, Pkey(name) + value)

Pmul(name, value, pattern)

Pbindf(pattern, name, Pkey(name) * value)

模式 Psetpre、Paddpre 和 Pmulpre 反转了求值顺序。Pchain 能够复制此功能。

Psetpre(name, value, pattern)

获取下一个值并将其放入事件原型中，然后再求值模式。

Psetpre(name, value, pattern)

Pchain(pattern, Pbind(name, value))

Paddpre(name, value, pattern)

Pchain(pattern, Pbind(name, Pkey(name) + value))

Pmulpre 类似。

第三组——Psetp、Paddp、Pmulp——行为略有不同，会嵌套模式求值。
