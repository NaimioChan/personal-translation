MonitorGui

显示并控制一个 Monitor

另请参阅：NodeProxy、Ndef、JITGui、NdefGui

说明

MonitorGui 显示 NodeProxy 的 Monitor 的状态。它用于 NdefGui、ProxyMixer 和 NdefMixer 中。

第一批示例

s.boot;
Ndef(\a).ar;
Ndef(\k).kr;

    // 创建一个功能齐全的 MonitorGui
m = MonitorGui.new(bounds: 500@40, options: [\name, \level, \fade]);

    // 当它有 kr 代理时，它是可见的，但被禁用
m.object_(Ndef(\k));
    // 使用 ar 代理时，它被启用
m.object_(Ndef(\a));


    // 显示其播放状态
Ndef(\a).play
    // 以及音量
Ndef(\a).vol_(0.25);

    // 注意：按住 Shift 点击播放按钮会打开 playN 对话框！

Ndef(\a).stop;
Ndef(\a).play(0);

类方法

Creation

.new

g = MonitorGui(Ndef(\a));    // 精简版
(
w = Window.new.front;
w.addFlowLayout;
g = MonitorGui(Ndef(\a), w, 300@40);

    // bounds
MonitorGui.new(Ndef(\a), bounds: Rect(100, 100, 400, 30))
MonitorGui.new(Ndef(\a), bounds: 400@24)

    // 级别名称和数值
MonitorGui.new(Ndef(\a), options: [\level])

    // 一个 nameView 和一个 fadeTime 设置框
MonitorGui.new(Ndef(\a), options: [\name, \fade])

    // 全部
MonitorGui.new(Ndef(\a), options: [\level, \name, \fade])

参数：

object

将显示其监视状态的 nodeproxy，或 nil。

parent

用于显示 MonitorGui 的父视图。如果为 nil，则创建一个窗口。

bounds

视图（或窗口）将显示的范围。

makeSkip

一个标志，表示是否创建并启动一个 SkipJack 用于自动更新。

options

一个符号数组，用于指定要显示内容的选项。

类变量

.lastOutBus

允许的最高 outbus 编号。默认值为 99。

实例方法

实例变量

.config

关于显示内容的一些信息

.ampSl

用于 Monitor 音量的 EZSlider

.playBut

一个播放按钮。Shift 单击会打开一个对话框，用于通过代码进行 playN 输出路由

.setOutBox

用于设置输出路由的数字框

.fadeBox

一个用于设置监视器 fadeTime 的数字框。

部分方法

创建各种 gui 元素：

.makeViews

.makeVol

.makeNameView

.makePlayOut

.makeFade

标准 JITGui 方法：

.setDefaults

创建默认布局尺寸

.accepts

接受 nil 或 NodeProxy

.getState

获取对象的当前状态

.checkUpdate

比较之前的状态与当前状态，并更新 GUI 元素。
