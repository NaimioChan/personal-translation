ControlSpec

数值输入规格

Spec : Object

参见：Warp

说明

最初的、也是最常见的规格（参见 Spec）。ControlSpec 被 GUI 滑块和旋钮用来指定控件的范围和曲线。ControlSpec 可以以多种方式使用，将线性 0..1 范围映射到你想要的范围并映射回来。

创建 ControlSpec 最常见的方式是通过

anObject.asSpec // 该对象可以是数组或符号

类方法

ControlSpec.new(minval: 0.0, maxval: 1.0, warp: 'lin', step: 0.0, default, units, grid)

参数：

minval

范围的最小值。

maxval

范围的最大值。

warp

一个 Warp、一个符号（例如 \lin 或 \exponential：默认值为 \lin），或者其它在接收 .asWarp 消息时返回 Warp 的对象。CurveWarp 由一个数字定义。

step

可能的最小增量。

default

默认值。

units

单位，例如 "hz"。某些 GUI 将其用作单位标签。

grid

未文档化的类方法

ControlSpec.newFrom(similar)

实例方法

.map(value)

将介于 0 和 1 之间的 value 映射并约束到 minval 和 maxval 之间的范围。

.unmap(value)

将介于 minval 和 maxval 之间的 value 映射并约束到 0 和 1 之间的范围。

g = ControlSpec(0.01, 2000, \exp, 0.1, 220, "Hz");
g.map(0.5); // convert from [0..1] to [0.01..2000]
g.unmap(1000); // convert from [0.01..2000] to [0..1]

// 正向和反向翻译应几乎相同：
g.unmap(g.map(0.5));

.clipLo

maxval 与 minval 中较小的那个。

.clipHi

maxval 和 minval 中较大的一个。

.constrain(value)

返回 value.asFloat.clip(clipLo, clipHi).round(step)。

.range

返回 maxval - minval。

.guessNumberStep

用于 EZ GUI 类，在未指定 step 时推测一个合理的值。

.gridClass

返回与当前 spec 对应的 AbstractGridLines 子类，特别是其 warp 行为。

.grid

.grid = value

获取/设置一个 AbstractGridLines 子类的实例，该实例描述当前规格的范围和扭曲行为，例如供 DrawGrid 在 Plotter 中绘制网格时使用。

示例

g = ControlSpec(0.01, 2000, \exp, 0.1, 220, "Hz");

// 或者作为替代

[0.001, 2000, \exp, 0.1, 220, "hz"].asSpec;

// 或将其添加到 ControlSpec.specs IdentityDictionary 中：

ControlSpec.specs[\myFreq] = ControlSpec(0.01, 2000, \exp, 0.01, 440, units: "Hz");

// 创建一个频率规格，指数范围从 20 到 20000，
// 给它设置 30 (Hz) 的舍入
a = \freq.asSpec;
a.step = 100;

// 等价于：
a = [20, 20000, 'exp', 100, 440].asSpec;
a.dump;

a.constrain(800); // 确保它在范围内并对其进行取整。
a.constrain(803); // 确保它在范围内并对其进行取整。

a.map(0.5);
a.map(0.0); // 返回最小值
a.map(1.5); // 超出区域：裁剪，返回最大值

a.unmap(4000);
a.unmap(22.0);
// 与包络类似，CurveWarp 由数字创建：

a = [0, 1, -4].asSpec;
a.map(0.5);
a.unmap(0.99);
a.map((0..10).normalize).plot;

// 查看不同的分布：
(
var invals = (0..10).normalize;
(-4..4).do { |curve|
    var a = [0, 1, curve].asSpec;
    a.map(invals).plot;
}
);
// 使用 spec 设置滑块：
(
var w, c, d;
w = Window.new("control", Rect(128, 64, 340, 160));
w.front;
c = Slider.new(w, Rect(10, 10, 300, 30));
d = StaticText.new(w, Rect(10, 40, 300, 30));
c.action = {
    d.string = "unmapped value"
    + c.value.round(0.01)
    + "......"
    + "mapped value"
    + a.map(c.value)
};
)
// ControlSpec-map 也可用于映射 ugens
(
var spec;
spec = [100, 18000, \exp].asSpec;
{
    var freq, osc;
    osc = SinOsc.kr(0.1).range(0, 1);
    freq = spec.map(osc);

    freq.dump; // BinaryOpUGen

    SinOsc.ar(
        freq.poll
    )
}.play
)
