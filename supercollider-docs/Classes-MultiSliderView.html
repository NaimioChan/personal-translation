MultiSliderView

显示滑块数组的视图

说明

MultiSliderView 显示一组值的集合，每个值由并排放置的其中一个滑块的位置表示。

在视图中点击时，鼠标指针下方的滑块的值将被设置。每当按住鼠标按键移动鼠标时，鼠标指针当前下方的滑块将被调整。

最后被修改的滑块被视为当前滑块，即 -index 方法将返回其索引，而 -currentValue 与其值相关。

当前滑块也被视为选中的滑块。通过修改 -selectionSize，可以将选择扩展到多个滑块。每当不同的滑块成为当前滑块时，选择大小会收缩回 1。请注意，只有当 -showIndex 为 true 时，选择才会在视觉上显示出来。

类方法

.new

新建的 MultiSliderView 为空，没有任何列。必须设置 -size 或 -value 才能创建一些列。

因此，如果你想要特定数量的滑块，最好指定 -size 并将 -elasticMode 设为 1。这样你会得到一个 MultiSliderView，它在 bounds.width 上分布 -size 数量的滑块，其中滑块宽度最大为 -indexThumbSize（默认 12），并且 -gap 会相应地调整。

实例方法

Data

.size

滑块的数量。

设置 -size 时，如果新数量大于当前数量，将以值 0 添加新的滑块。反之，新数量以内的滑块值将被保留，其余滑块将被移除。

注意： 在 Cocoa GUI 中： 在视图已绘制之后或已设置 -value 数组之后更改 -size 会导致意外结果。相反，如果你需要更改视图的内容，应更改 -value。

参数：

一个 Integer。

.value

将滑块的值设置为参数各元素的值。

注意： 如果参数中的元素数量与 -size 不匹配，则先使 -size 匹配，再应用新值。

参数：

一个 Float 数组。

.valueAction

设置 -value 并触发 -action。

.reference

用于对数值进行可视化表示的参考值。每个滑块的默认值为 0。

参数：

一个 Float 数组。

.index

当前滑块的索引，即选区中的第一个。

参数：

一个 Integer。

.selectionSize

选择中的滑块数量（从 -index 开始）。

.currentvalue

-index 处滑块的值

参数：

一个 Float。

Display

.indexIsHorizontal

视图的方向：若为 true，滑块按水平顺序显示，否则按垂直顺序显示。

参数：

一个布尔值。

.elasticMode

如果启用（设为 1），则从 -startIndex 到最后一个滑块将被分布以占据视图的整个区域。-gap 变量将被忽略。每个滑块在索引方向上的大小最大为 -indexThumbSize，或者更小以便所有滑块都能放入视图中。

参数：

0（禁用）或 1（启用）。

.gap

当 -elasticMode 禁用时，滑块之间的间距（以像素为单位）。

参数：

一个 Integer。

.indexThumbSize

滑块在索引方向上的大小，以像素为单位。如果启用了 -elasticMode，这将是最大尺寸，但实际尺寸可能更小，以便所有滑块都能容纳在视图中。

参数：

一个 Integer。

.valueThumbSize

滑块手柄沿值方向的尺寸（以像素为单位，若绘制）。

参数：

一个 Integer。

.thumbSize

将 -indexThumbSize 和 -valueThumbSize 都设置为该参数。

.startIndex

显示在视图左边缘或上边缘（分别取决于 -indexIsHorizontal 为 true 还是 false）的滑块索引。索引小于此值的滑块将不可见。

参数：

一个 Integer。

Appearance

.showIndex

滑块选择是否以视觉方式指示。

参数：

一个布尔值。

.drawRects

是否绘制滑块。

参数：

一个布尔值。

.drawLines

是否绘制一条连接表示滑块 values 的点的线，以及一条连接表示 references 的点的线。

参数：

一个布尔值。

.isFilled

如果为 true，滑块在 -reference 与 -value 之间的区域将被着色，连接参考点与值点的线所界定的区域也将被着色。

参数：

一个布尔值。

.strokeColor

用于绘制 -drawLines 中所描述线条的颜色。

参数：

一个 Color。

.fillColor

用于可视化 -isFilled 中所述区域的颜色。

参数：

一个 Color。

.colors

分别将 -strokeColor 和 -fillColor 设置为这两个参数。

Interaction

.editable

这些值是否可以使用鼠标或键盘编辑。

参数：

一个布尔值。

.readOnly

与 -editable 相反。

参数：

一个布尔值。

.step

如果参数大于 0，则使 MultiSliderView 将值量化为该参数的最接近倍数。

Actions

.action

每当用户更改滑块值时求值的动作对象。

.metaAction

当用户按住 Ctrl 键更改滑块的值时将被求值的动作对象。

.defaultKeyDownAction

实现按键的默认效果如下：

Key

Effect

上箭头

将 -currentValue 增加 -step

向下箭头

将 -currentValue 减少 -step

右箭头

将 -index 增加 1

向左箭头

将 -index 减少 1

拖放

.defaultGetDrag

返回值：

a) 如果 -selectionSize 为 0，则返回 -value。

b) 如果 -selectionSize > 1，则返回一个数组，其中包含选择中索引处的值。

如果 -reference 不为 nil，返回一个包含 (a) 或 (b) 的数组，以及一个对应参考值的数组：[[values], [references]]。

.defaultCanReceiveDrag

返回值：

对任何拖动数据都为 true，但数据应当是值的数组（[values]），或者是包含一个值数组和一个对应引用值数组的数组（[[values], [references]]）。

.defaultReceiveDrag

如果拖拽数据属于可接受的形式之一（参见上文的 -defaultCanReceiveDrag），则使用该数据设置 -value（以及 -reference）。

示例

基本示例

(
n = 20;
w = Window.new.front;
m = MultiSliderView(w, Rect(10, 10, n*13+2, 100)); // 默认 thumbWidth 为 13
m.value = Array.fill(n, { |v| v*0.05 }); // 设置值时，size 会自动设置
m.action = { |q|
    q.value.postln;
};
)

交互式示例

逐一介绍所有图形选项：

(
n = 40;

w = Window("MultiSlider Options", Rect(200, Window.screenBounds.height-550, 600, 450));
f = {
    w.view.decorator = FlowLayout(w.view.bounds, 10@10, 10@2);
    m = MultiSliderView(w, Rect(0, 0, 580, 200)); // 默认 thumbWidth 为 13
    m.value = Array.fill(n, { |v| 0.5+((0.3*v).sin*0.25) });
    m.action = { |q|q.value.postln };
    
    StaticText(w, 380@18).string_("indexThumbSize or thumbSize");
    Slider(w, 580@10).action_({ |sl| m.indexThumbSize = sl.value*24 }).value_(0.5);
    StaticText(w, 380@18).string_("valueThumbSize");
    Slider(w, 580@10).action_({ |sl| m.valueThumbSize = sl.value*24 }).value_(0.5);
    StaticText(w, 580@18).string_("xOffset or gap");
    Slider(w, 580@10).action_({ |sl| m.xOffset = sl.value*50 });
    StaticText(w, 580@18).string_("startIndex");
    Slider(w, 580@10).action_({ |sl| m.startIndex = sl.value *m.size });
    
    CompositeView(w, 580@10); // spacer
    Button(w, 100@20).states_([["RESET", Color.red]])
        .action_({ w.view.removeAll; f.value });
    h = StaticText(w, 450@18).string_("").stringColor_(Color.yellow);
    Button(w, 100@20).states_([["elasticMode = 0"], ["elasticMode = 1", Color.white]])
        .action_({ |b| m.elasticMode = b.value });
    Button(w, 160@20).states_([["indexIsHorizontal = false"], ["indexIsHorizontal = true", Color.white]])
        .action_({ |b| m.indexIsHorizontal = b.value.booleanValue }).value_(1);
    Button(w, 120@20).states_([["isFilled = false"], ["isFilled = true", Color.white]])
        .action_({ |b| m.isFilled = b.value.booleanValue });
    Button(w, 120@20).states_([["drawRects = false"], ["drawRects = true", Color.white]])
        .action_({ |b| m.drawRects = b.value.booleanValue }).valueAction_(1);
    Button(w, 100@20).states_([["drawLines = false"], ["drawLines = true", Color.white]])
        .action_({ |b| m.drawLines = b.value.booleanValue });
    Button(w, 160@20).states_([["readOnly = false"], ["readOnly = true", Color.white]])
        .action_({ |b| m.readOnly = b.value.booleanValue });
    Button(w, 120@20).states_([["showIndex = false"], ["showIndex = true", Color.white]])
        .action_({ |b| m.showIndex = b.value.booleanValue });
    Button(w, 120@20).states_([["reference = nil"], ["reference filled", Color.white], ["reference random", Color.yellow]])
        .action_({ |b| 
            b.value.booleanValue.if({
                (b.value > 1).if(
                    { m.reference = Array.fill(n, { 1.0.rand }) },
                    { m.reference = Array.fill(m.size, { 0.5 }) }
                );
            }, { 
                q = m.value; m.reference = []; h.string = "reference can't be returned to nil presently. please hit RESET." 
            })
        });
    Button(w, 180@20).states_([["fillColor = Color.rand"]]).action_({ m.fillColor = Color.rand });
    Button(w, 180@20).states_([["strokeColor = Color.rand"]]).action_({ m.strokeColor = Color.rand });
    Button(w, 180@20).states_([["background = Color.rand"]]).action_({ m.background = Color.rand });
};
f.value;
w.front;
)

显示声音文件

(
// 按住 shift 可扩展选区
// 作为 waveView 使用：在视图上拖动会返回索引
// 如果 showIndex(false)，视图不会刷新（更快）；
// 否则你可以按住 shift 拖动来进行选区。
var size, file, maxval, minval;
size = 640;
a = Window("test", Rect(200, 140, 650, 150));
a.view.decorator = FlowLayout(a.view.bounds);
b = MultiSliderView(a, Rect(0, 0, size, 50));
b.readOnly_(true);
a.view.decorator.nextLine;

d = Array.new;
c = FloatArray.newClear(65493);

r = Slider(a, Rect(0, 0, size, 12));
r.action = { |ex| b.gap = (ex.value * 4) + 1 };

file = SoundFile.new;
file.openRead(ExampleFiles.child);
file.numFrames.postln;
file.readData(c);
// file.inspect;
file.close;
minval = 0;
maxval = 0;
f = Array.new;
d = Array.new;
c.do({ |fi, i|
    if(fi < minval, { minval = fi });
    if(fi > maxval, { maxval = fi });

    // f.postln;
    if(i % 256 == 0, {
        d = d.add((1 + maxval) * 0.5);
        f = f.add((1 + minval) * 0.5);

        minval = 0;
        maxval = 0;
    });
});

b.reference_(d); // 这用于绘制表格的上半部分
b.value_(f);

r = Slider(a, Rect(0, 0, size, 12));
r.action = { |ex| b.startIndex = ex.value *f.size };

// b.enabled_(false);
b.action = { |xb| ("index: " ++ xb.index).postln };
b.drawLines_(true);
b.drawRects_(false);
b.isFilled_(true);
b.selectionSize_(10);
b.index_(10);
b.thumbSize_(1);
b.gap_(0);
b.colors_(Color.black, Color.blue(1.0, 1.0));
b.showIndex_(true);
a.front;

)

用作音序器

(
var size;
size = 12;
s.waitForBoot({
    n = { |freq = 330| SinOsc.ar(freq, 0, 0.2) }.play;
    
    w = Window("test", Rect(200, 450, 10 + (size * 17), 10 + (size * 17)));
    w.view.decorator = FlowLayout(w.view.bounds);
    b = MultiSliderView(w, Rect(0, 0, size * 17, size * 17));
    b.value_(Array.fill(size, { |i| i/size }));
    b.background_(Color.rand);
    b.action = { |xb|
        n.set(\freq, 330+(1100*xb.value.at(xb.index)));
        ("index: " ++ xb.index ++" value: " ++ xb.value.at(xb.index)).postln };
    b.elasticMode_(1); // 使方块均匀适配
    b.showIndex = true; // 光标模式
    b.readOnly = true;
    w.front;
    
    r = Routine({
        0.1.wait;
        30.do({ |i|
            b.index_(i%size);
            
            b.doAction;
            0.1.wait;
        });
        
        20.do({ |i|
            b.index_(b.size.rand);
            b.doAction;
            [0.1, 0.2].choose.wait;
        });
        1.wait;
        n.free;
        { w.close }.defer;
    });
    AppClock.play(r);
});
)
