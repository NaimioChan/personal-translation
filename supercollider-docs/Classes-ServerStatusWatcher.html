ServerStatusWatcher

观察并更新服务器状态

Object

另请参阅：Server

说明

一个通过管理状态请求和更新来观察 Server 对象的对象。ServerStatusWatcher 是客户端服务器实现的细节，用户不需要直接使用它。可以通过 Server: -statusWatcher 访问 Server 的状态监视器。

类方法

ServerStatusWatcher.new(server)

创建一个新的 ServerStatusWatcher。

参数：

server

Server 的一个实例。

返回值：

构造的 ServerStatusWatcher。
