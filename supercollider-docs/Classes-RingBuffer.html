RingBuffer

固定大小环形缓冲区

SequenceableCollection : Collection : Object

参见：LinkedList

说明

一个保存固定大小集合的循环缓冲区。可用作队列。

类方法

RingBuffer.new(size, collectionClass)

创建一个新的缓冲区。

参数：

size

初始大小。该集合将能够容纳比此数字少一的值。

collectionClass

默认为 Array 类。

实例方法

.array

集合。

.readPos

当前读取位置。

.writePos

当前写入位置。

.maxSize

最大容量。

.size

-readable 的别名。

.readable

可读项的数量。

.writable

可写项的数量。

.add(value)

增加值并递增 -writePos。如果无法写入任何项，则不做任何操作。

.pop

返回下一个可读项并增加 -readPos。如果无法读取任何项，则返回 nil。

.overwrite(value)

将值加入并通过覆盖最旧的可读项来增加 -writePos。

.do(function)

遍历当前可读取的条目。

示例

r = RingBuffer(4);
r.add(\one);
r.add(\two);
r.add(\three);
r.readable;
r.do{ |x| x.postln };


r = RingBuffer(12, Int16Array);
r.writable.do{ |i| r.add(i + 1 * 100) };
r.array;
r.readable;  // 11
r.writable;  // 0 = full
r.pop;
r.pop;
r.pop;
r.readable;  // 8
r.writable;  // 3
