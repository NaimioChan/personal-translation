MultiTap

多抽头延迟。

Object

参见：Tap

说明

这是一个包装器，使用 RecordBuf 和 PlayBuf 创建多抽头延迟线。

注意： RecordBuf.ar 和 PlayBuf.ar 逐块运行。如果延迟时间大于缓冲区大小减去服务器的块大小，写入头和读取头可能会以非预期的方式相互干扰。如果发生这种情况，请使用稍大一点的缓冲区。

类方法

MultiTap.ar(timesArray, levelsArray, in: 0.0, mul: 1.0, add: 0.0, bufnum)

参数：

timesArray

一个指向以秒为单位的延迟时间数组的 Ref。

levelsArray

指向振幅数组的 Ref。

in

输入信号。

mul

输出将乘以该值。

add

此值将被添加到输出中。

bufnum

用于延迟的缓冲区编号。其长度必须至少与最长的抽头时间一样长。

实例方法

示例

s.boot;
b = Buffer.alloc(s, s.sampleRate);
(
{
    MultiTap.ar(`[0.1, 0.2, 0.3, 0.4], `[0.1, 0.2, 0.4, 0.8],
        Decay.ar(Dust.ar(2), 0.1, PinkNoise.ar), bufnum: b.bufnum)
}.play
)
