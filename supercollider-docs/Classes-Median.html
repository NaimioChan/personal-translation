Median

中值滤波器。

Filter : PureUGen : UGen : AbstractFunction : Object

说明

返回最近 length 个输入点的中位数。这种非线性滤波器擅长降低信号中的脉冲噪声。

类方法

Median.ar(length: 3, in: 0.0, mul: 1.0, add: 0.0)

Median.kr(length: 3, in: 0.0, mul: 1.0, add: 0.0)

参数：

length

用于查找中位数的输入点数量。必须是 1 到 31 之间的奇数。如果 length 为 1，则 Median 没有效果。

in

输入信号。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

// 带脉冲噪声的信号。
{ Saw.ar(500, 0.1) + Dust2.ar(100, 0.9) }.play;

// 应用中值滤波后
{ Median.ar(3, Saw.ar(500, 0.1) + Dust2.ar(100, 0.9)) }.play;

// 可为更长时长的噪声增大中值长度。

// 具有更长脉冲噪声的信号。
{ Saw.ar(500, 0.1) + LPZ1.ar(Dust2.ar(100, 0.9)) }.play;

// 长度 3 在这里没有帮助，因为脉冲有 2 个采样点长。
{ Median.ar(3, Saw.ar(500, 0.1) + LPZ1.ar(Dust2.ar(100, 0.9))) }.play;

// 长度为 5 效果更好
{ Median.ar(5, Saw.ar(500, 0.1) + LPZ1.ar(Dust2.ar(100, 0.9))) }.play;

// 长 Median 滤波器开始削掉波形的峰值
(
{
    x = SinOsc.ar(1000, 0, 0.2);
    [x, Median.ar(31, x)]
}.play;
)

// 另一个降噪应用：

Synth.play({ WhiteNoise.ar(0.1) + SinOsc.ar(800, 0, 0.1) });

// 对高频噪声使用中值滤波器
Synth.play({ Median.ar(31, WhiteNoise.ar(0.1) + SinOsc.ar(800, 0, 0.1)) });

(
// 使用 LeakDC 处理低频噪声
Synth.play({
    LeakDC.ar(Median.ar(31, WhiteNoise.ar(0.1) + SinOsc.ar(800, 0, 0.1)), 0.9)
});
)
