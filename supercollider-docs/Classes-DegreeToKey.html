DegreeToKey

将信号转换为模态音高。

PureUGen : UGen : AbstractFunction : Object

说明

输入信号值被截断为整数值，并用作八度重复音高值表中的索引。索引在表中循环，并随之移动八度。

类方法

DegreeToKey.ar(bufnum, in: 0.0, octave: 12.0, mul: 1.0, add: 0.0)

DegreeToKey.kr(bufnum, in: 0.0, octave: 12.0, mul: 1.0, add: 0.0)

参数：

bufnum

包含每个音阶度数步进的缓冲区索引。

in

输入信号。

octave

音阶中每八度的步数。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

(
// 调式空间
// 鼠标 x 控制 dorian 调式中的离散音高
var scale, buffer;
scale = FloatArray[0, 2, 3.2, 5, 7, 9, 10]; // 多利亚音阶
buffer = Buffer.alloc(s, scale.size, 1, { |b| b.setnMsg(0, scale) });

play({
    var mix;

    mix =

    // 主音
    SinOsc.ar(
        (
            DegreeToKey.kr(
                buffer.bufnum,
                MouseX.kr(0, 15),        // 鼠标索引到音阶
                12,                    // 每八度 12 个音
                1,                    // mul = 1
                72                    // 偏移 72 个音符
            )
            + LFNoise1.kr([3, 3], 0.04)    // 添加一些低频立体声失谐
        ).midicps,                        // 将 MIDI 音符转换为赫兹
        0,
        0.1)

    // 持续音五度
    + RLPF.ar(LFPulse.ar([48, 55].midicps, 0.15),
        SinOsc.kr(0.1, 0, 10, 72).midicps, 0.1, 0.1);

    // 添加一些 70 年代欧洲太空摇滚回声
    CombN.ar(mix, 0.31, 0.31, 2, 1, mix)
})
)
