Volume

合成服务器的全局音量模型

Object

说明

由 Server 内部使用。当 volume 值不为 0 dB 或处于静音状态时，服务器的 volume 对象会创建一个 synth，用于按给定声道数控制主输出上的音量。为了与该服务器上的远程客户端共享这个 volume synth，volume 拥有自己的组，固定 nodeID 为 2，而该 synth（存在时）使用固定 nodeID 3。

类方法

Volume.new(server, startBus: 0, numChannels, min: -90, max: 6, persist: false)

为给定服务器创建并返回一个新的 Volume 实例，范围从 startBus 起跨越 numChans（通常为服务器的输出总线通道数）。

参数：

server

一个服务器

startBus

起始总线

numChannels

通道数

min

最小音量（分贝）

max

最小音量（分贝）

persist

是否持久化重置

实例方法

.mute

静音输出

.unmute

取消输出静音

.volume

.volume = aVolume

设置音量（以 db 为单位）

.lag

.lag = aLagTime

设置抑制音量变化的滞后时间

.setVolumeRange(argMin, argMax)

设置音量范围

.gui(window, bounds)

创建音量 GUI。
