MIDI

关于 MIDI

另请参阅：Using MIDI、MIDIFunc、MIDIdef

实际用法概述

从 Using MIDI 帮助文件开始。

接收 MIDI 输入

MIDIFunc 和 MIDIdef 是接收 MIDI 音符开/关、控制器、弯音、触后、复音触后和音色切换消息的标准且推荐的方式。

注意： 重要：在接收 MIDI 之前，需要告知 SuperCollider 连接到 MIDI 子系统并连接到可用设备。MIDIClient.init; MIDIIn.connectAll; 你需要在启动 SuperCollider 或重新编译类库后执行一次。

有一些现成的例子直接使用 MIDIIn 类来接收 MIDI。这不推荐用于正常使用。例外是 sysex（系统独占）和 sysrt（MIDI 时钟）消息，目前仅由 MIDIIn 支持。参见下面的例子。

发送 MIDI 输出

详情请参阅 MIDIOut 帮助文件。

MIDI 类摘要

MIDIClient

该类连接到操作系统的 MIDI 层，并获取可用 MIDI 源和目标的列表。关于硬件的信息以 MIDIEndPoint 对象的形式存储在 MIDIClient.sources 和 MIDIClient.destinations 中。必须先初始化 MIDIClient，才能接收 MIDI。参见上面的说明。

MIDIFunc

接收最常见 MIDI 消息的最佳方式：音符开/关、控制器、弯音、触后、复音触后和音色切换。

MIDIdef

与 MIDIFunc 相关，此类按名称将多个 MIDIFunc 对象保存在全局存储中。对现场或交互式使用尤其有帮助。

MIDIOut

支持 MIDI 输出到硬件端口或应用程序间 MIDI 总线。

MIDIEndPoint

表示由操作系统发布的 MIDI 端口。它包含设备名称、端口名称和唯一标识符（uid）。

MIDIIn

最低层的 MIDI 输入类。MIDIFunc 和 MIDIdef 使用此类，因此你不必直接使用它。强烈建议避免直接使用此类。

示例

MIDI 输入：

(
MIDIClient.init;
MIDIIn.connectAll;
m = MIDIFunc.noteOn({ |vel, num|
    "note % @ velocity %\n".postf(num, vel);
});
)

// 完成时
m.free;

MIDI 输出：

(
MIDIClient.init;
m = MIDIOut(0, MIDIClient.destinations.at(0).uid);
m.noteOn(0, 60, 60);
)

接收系统独占消息：

~sysexFunc = { |uid, data|
    // 'data' 以 8 位整数保存 sysex 数据包
};
MIDIIn.addFuncTo(\sysex, ~sysexFunc);

// 完成时
MIDIIn.removeFuncFrom(\sysex, ~sysexFunc);
