AllpassN

无插值的 Schroeder 全通延迟线。

CombN : PureUGen : UGen : AbstractFunction : Object

另请参阅：AllpassC、AllpassL、BufAllpassN

说明

Schroeder 全通滤波器由以下差分方程给出

s(t) = x(t) + k * s(t - D)
y(t) = -k * s(t) + s(t - D)

其中 x(t) 是输入信号，y(t) 是输出信号，D 是延迟时间，k 是全通系数。

在该 UGen 中，k 的计算方式为 k == 0.001 ** (delay / decay.abs) * decay.sign（0.001 即 -60 dBFS）。

该 UGen 将延迟时间量化为最近的采样周期，如果对延迟时间进行调制，将产生混叠伪影。如果这些是不希望出现的特性，那么 CPU 开销更大的替代方案是使用线性插值的 AllpassL，以及使用三次插值的 AllpassC。

类方法

AllpassN.ar(in: 0.0, maxdelaytime: 0.2, delaytime: 0.2, decaytime: 1.0, mul: 1.0, add: 0.0)

来自父类：CombN

AllpassN.kr(in: 0.0, maxdelaytime: 0.2, delaytime: 0.2, decaytime: 1.0, mul: 1.0, add: 0.0)

来自父类：CombN

参数：

in

输入信号。

maxdelaytime

最大延迟时间，单位为秒。用于初始化延迟缓冲区大小。

delaytime

延迟时间，单位为秒。

decaytime

回声衰减 60 分贝所需的时间。如果该时间为负，则反馈系数将为负，从而只强调低一个八度的奇次谐波。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

// 由于全通延迟作为谐振器对
// 稳态声音没有可听效果……

{ AllpassN.ar(WhiteNoise.ar(0.1), 0.01, XLine.kr(0.0001, 0.01, 20), 0.2) }.play;

// ……这些示例将输入加到效果声音上，并比较各种变体，以便你能听到
// 相位梳的效果：

(
{
    z = WhiteNoise.ar(0.2);
    z + AllpassN.ar(z, 0.01, XLine.kr(0.0001, 0.01, 20), 0.2)
}.play)

(
{
    z = WhiteNoise.ar(0.2);
    z + AllpassL.ar(z, 0.01, XLine.kr(0.0001, 0.01, 20), 0.2)
}.play)

(
{
    z = WhiteNoise.ar(0.2);
    z + AllpassC.ar(z, 0.01, XLine.kr(0.0001, 0.01, 20), 0.2)
}.play)

// 用作回声 - 听起来与 Comb 并无太大区别，
// 但它会立即输出输入信号（反相），
// 且回声的振幅较低。
{ AllpassN.ar(Decay.ar(Dust.ar(1, 0.5), 0.2, WhiteNoise.ar), 0.2, 0.2, 3) }.play;
