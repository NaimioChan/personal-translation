说明

SuperCollider 目前支持三个操作系统平台：macOS、UNIX（Linux 和 FreeBSD）以及 Windows（有一些限制）。

警告： 重定向系统已被弃用，请直接使用视图类。如果你发现使用旧 GUI Kits 前缀的旧代码（例如 CocoaGUI 的 SCWindow），请尝试去掉前缀，改为 Window、Button 等。Qt 前缀 Q（例如 QWindow 中的 Q）会自动转换为 Window；不过直接写 Window 是更好的风格。

不再需要在 GUI 方案之间切换，因为 Qt 在所有平台上都运行良好。不过，你仍然可以通过以下方式获取可用的方案：

GUI.schemes;

有关历史 GUI 类及其重定向的完整列表，请参见 List of GUI classes。

.qt

将 QtGUI 设为当前方案并返回它。随后对 GUI 的 GUI 对象调用都委托给 Qt。返回当前（Qt）方案。

.fromID

更改当前方案并返回新方案。

参数：

id

一个 Symbol。要使用的方案的标识符。

.current

返回当前方案。这对于那些在实例化时希望存储当时方案的的对象很有用，以便在以后的方法调用中能够始终使用相同的方案。

注意： 调用者不应对返回对象的性质（类）作任何假设，以便实际实现（一个 Event）将来可以更改。

.get

返回给定标识符的方案。不切换当前方案。

参数：

id

一个 Symbol。要检索的方案的标识符，例如通过调用 aScheme.id 返回的值。

.set

更改当前方案。

参数：

aScheme

一个 Symbol 的实例。用作当前方案的方案。

.use

执行一个函数体，临时设置当前 GUI 方案。这在视图的动作函数内部很有用，以便使该函数使用最初用于该动作所属视图的 GUI 方案，即使期间已切换了方案。

参数：

aScheme

函数执行期间使用的方案。

func

Function 的一个实例。

.useID

与 use 相同，但使用方案的 id 作为第一个参数。

参数：

id

函数执行期间使用的 scheme 的 id。

func

要执行的主体。

.add

注册一个新的方案。这通常由外部库在其启动过程中调用。如果存在具有相同标识符（scheme.id）的方案，则会被覆盖。

参数：

aScheme

要添加的方案。

.doesNotUnderstand

所有方法调用都映射到当前方案，因此例如可以使用 GUI.button，它会委托给当前方案的 button 关联。

参数：

selector

... args

.setSkin

参数：

skinName

.scheme

一个类变量。返回当前方案。

.schemes

一个类变量。返回已注册方案的 IdentityDictionary。

.skin

一个类变量。返回当前皮肤。

.skins

一个类变量。返回已注册皮肤的 IdentityDictionary。
