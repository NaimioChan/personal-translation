Quarks.install(name, refspec)

将执行 hooks \preInstall 和 \postInstall（如果已定义）。

参数：

name

目录中列出的 quark 的名称，或 git 仓库的 URL，或要安装的文件夹路径（绝对路径或相对于当前工作目录的路径）。

refspec

可选的 git refspec。默认情况下会安装最新版本。您也可以选择指定一个标签：“tags/1.0.0”，一个 sha 提交：“15e6ea822a18d06b286c3f10918f83b8d797d939”、“HEAD”、nil（默认值）

this

Quarks.addFolder(path)

参数：

path

除了默认的 downloaded-quarks 之外，还要添加包含 quark 的文件夹，以便在安装菜单中提供。这些可以是私有 quark、克隆的工作副本，或你手动下载 quark 的文件夹。

注意： 该参数应为一个目录路径，该目录包含 quark 目录。它不应是某个孤立的 quark 目录本身。不鼓励用户将 quark 目录分散在孤立位置。

返回值：

this

Quarks.checkForUpdates(done, quarkAction)

扫描所有已下载的 git 仓库 quark 并下载任何更新。这使用 git fetch；更新将被获取，但不会应用到工作副本（即，环境中不会出现可见变化）。此后，仓库将能识别新的分支和版本标签。

每个 quark 将耗时数秒。在每次单独的 quark 更新期间，SC 解释器将无响应。

参数：

done

（可选）在所有 quark 检查完毕后要执行的函数。

quarkAction

（可选）在检查每个单独的 quark 之前要执行的函数。该函数接收 Quark 对象作为参数，因此你可以用它来，例如，打印 quark 名称并在 post 窗口中持续更新状态：Quarks.checkForUpdates(quarkAction: { |quark| "Updating %\n".postf(quark.name) });。

参数：

（布尔值）强制获取。默认情况下每会话获取一次。要再次获取，请重新编译类库，或调用 Quarks.fetchDirectory(true) 强制获取。

返回值：

this
