控制结构

流控制

另请参阅：Boolean

SuperCollider 中的控制结构通过消息发送实现。以下是一些可用的控制结构。关于表达式的各种书写方式，请参阅 Syntax Shortcuts。

基本控制结构

if

条件执行通过 if 消息实现。if 消息被发送给一个表达式，该表达式必须返回一个 Boolean 值。

此外，它接受两个参数：一个在表达式为真时执行的函数，以及另一个可选的、在表达式为假时执行的函数。if 消息返回所执行函数的值。如果不存在 falseFunc 且表达式为假，则 if 消息的结果为 nil。

讨论：

Syntax

if(expr) { true body } { false body };

// 交替
if(expr, trueFunc, falseFunc);

// 可行但更难阅读，因此不推荐
expr.if (trueFunc, falseFunc);

示例

(
if([false, true].choose) {
    "expression was true".postln  // true 函数
} {
    "expression was false".postln  // false 函数
};
)

(
var a = 1, z;
z = if(a < 5) { 100 } { 200 };
z.postln;
)

(
var x;
if(x.isNil) { x = 99 };
x.postln;
)

while

while 消息实现了循环的条件执行。如果 testFunc 在求值时返回 true，则对 loopFunc 求值并重复该过程。一旦 testFunc 返回 false，循环便终止。

讨论：

Syntax

while { testFunc body } { loopFunc body };

// 交替
while({ testFunc body }, { loopFunc body });

// 可行但更难阅读，因此不推荐
{ testFunc body }.while({ loopFunc body });

Example

(
i = 0;
while { i < 5 } { i = i + 1; "boing".postln };
)

如果 testFunc 和 loopFunc 中不包含变量声明，while 表达式也会被编译器优化。

for

for 消息实现了对整数序列的迭代，从起始值到结束值，每次递增一。每次迭代都会对一个函数求值，并将迭代的数值作为参数传入。

讨论：

Syntax

for(startValue, endValue) { loop body }

// 交替
for(startValue, endValue, function)

// 可行但更难阅读，因此不推荐
startValue.for ( endValue, function )

Example

for(3, 7) { arg i; i.postln };  // 打印值 3 到 7

forBy

forBy 选择器实现对整数序列以可变步长进行迭代。每次迭代都会对一个函数求值，并将迭代得到的数值作为参数传给该函数。

讨论：

Syntax

forBy(startValue, endValue, stepValue) { loop body };

forBy(startValue, endValue, stepValue, function);

// 可行但更难阅读，因此不推荐
startValue.forBy(endValue, stepValue, function);

Example

forBy(0, 8, 2) { arg i; i.postln };  // 以步长 2 打印 0 到 8 的值

do

do 用于迭代 Collection。正整数也响应 do，从零迭代到其值。集合会迭代，对其中包含的每个对象调用该函数。其他类型的对象响应 do 时会将自身传递给函数一次。调用函数时带两个参数：项和迭代计数器。

讨论：

Syntax

collection.do { loop body };

// 交替
collection.do(function)

// 交替出现，很少见
do(collection, function)
do(collection) { loop body };

Example

[ 1, 2, "abc", (3@4) ].do { arg item, i; [i, item].postln; };

5.do { arg item; item.postln }; // 从零迭代到四

"you".do { arg item; item.postln }; // String 是字符的集合

'they'.do { arg item; item.postln }; // Symbol 是单个项目

(8..20).do { arg item; item.postln }; // 从八迭代到二十

(8,10..20).do { arg item; item.postln }; // 从八迭代到二十，步长为二

Routine {
    var i = 10;
    while { i > 0 } {
        i.yield;
        i = i - 5.0.rand
    }
}.do { arg item; item.postln };  // 'do' 应用于 Routine

注意： 语法 (8..20).do 使用了一种优化，以避免生成仅用于迭代的数组（该数组随后会被丢弃）。(8..20).do { |item| item.postln } 的返回值是 8，即起始值。然而，如果 do 被写为中缀二元运算符，如 (8..20) do: { |item| item.postln }，那么它会先以数组形式生成该序列，然后再调用 Array:do。这样做的一个副作用是：只有在 do 被写为方法调用时，才可以在例程中对无限序列使用 do。如果它被写为二元运算符，你会得到“wrong type”错误，因为数组必须是有限的。// OK: 'do' 是方法调用 r = Routine { (8 .. ).do { |i| i.yield; }; }; r.next; -> 8 -> 9 等等。// ERROR: 'do' 是运算符 r = Routine { (8 .. ) do: { |i| i.yield; }; }; r.next; ERROR: Primitive '_SimpleNumberSeries' failed. Wrong type。

switch

Object 实现了一个 switch 方法，允许使用多个条件分支进行条件求值。这些分支以测试对象（用 if this == test.value 进行测试）和相应函数成对实现，条件为真时则对函数求值。

如果测试对象全部是 Float、Integer、Symbol、Char、nil、false、true，且函数没有变量或参数声明，则 switch 语句会被内联。内联的 switch 使用哈希查找（比嵌套 if 语句更快），因此应该非常快，并可扩展到任意数量的子句。

注意： 按定义，哈希查找意味着测试同一性而非相等性：未内联的 switch 结构会测试 ==，而内联的结构会测试 ===。请参见示例。一个推论是应避免使用字符串：switch(text) { "abc" } { ... } 可能不会匹配，即使 text == "abc" 也是如此。应优先使用符号。

注意： 浮点数有时可能看起来相等，但它们的二进制表示略有不同：(2/3) == (1 - (1/3)) 为 false。因此应避免在 switch 结构中使用浮点数。

讨论：

Syntax

switch(value)
{ testvalue1 } { truebody1 }
{ testvalue2 } { truebody2 }
{ testvalue3 } { truebody3 }
{ testvalue4 } { truebody4 }
...
{ defaultbody }; // defaultbody 可以省略。

switch(value,
        testvalue1, trueFunction1,
        testvalue2, trueFunction2,
        ...
        testvalueN, trueFunctionN,
        defaultFunction // defaultFunction 可以省略
);

示例

(
var x = 0; //也可尝试 1
switch(x, 0, { "hello" }, 1, { "goodbye" })
)

(
var x = 0; //也可尝试 1
switch(x) { 0 } { "hello" } { 1 } { "goodbye" };
)

(
var x, z;
z = [0, 1, 1.1, 1.3, 1.5, 2];
switch (z.choose.postln,
    1,   { \no },
    1.1, { \wrong },
    1.3, { \wrong },
    1.5, { \wrong },
    2,   { \wrong },
    0,   { \true }
).postln;
)

or:

(
var x, z;
z = [0, 1, 1.1, 1.3, 1.5, 2];
x = switch(z.choose)
    {1}   { \no }
    {1.1} { \wrong }
    {1.3} { \wrong }
    {1.5} { \wrong }
    {2}   { \wrong }
    {0}   { \true };
x.postln;
)

内联与非内联比较：

(
switch(1.0)
    { 1 } { "yes" }
    { "no" }
)

-> no

恒等比较 1.0 === 1 的结果为 false：虽然 1.0 和 1 表示相同的数值，但一个是浮点数，另一个是整数，因此它们不可能相同。

(
// 'var x' 阻止内联
switch(1.0)
    { 1 } { var x; "yes" }
    { "no" }
)

WARNING: Float:switch is unsafe, rounding via Float:asInteger:switch
-> yes

case

Function 实现了一个 case 方法，允许使用多个条件进行条件求值。由于接收者代表第一个条件，因此可以简单地写成测试函数与对应的求值为真时执行的函数配对的形式。case 是内联的，因此与嵌套的 if 语句一样高效。

讨论：

Syntax

case
    { testFunction1 } { trueFunction1 }
    { testFunction2 } { trueFunction2 }
    ...
    { defaultFunction }; // defaultFunction 可以省略。

case(
    { testFunction1 }, { trueFunction1 },
    { testFunction2 }, { trueFunction2 },
    ...
    { defaultFunction } // defaultFunction 可以省略。
);

Example

(
var i, x, z;
z = [0, 1, 1.1, 1.3, 1.5, 2];
i = z.choose;
x = case
    { i == 1 }   { \no }
    { i == 1.1 } { \wrong }
    { i == 1.3 } { \wrong }
    { i == 1.5 } { \wrong }
    { i == 2 }   { \wrong }
    { i == 0 }   { \true };
x.postln;
)

or

(
var i, x, z;
z = [0, 1, 2];
i = z.choose;
x = case(
    { i == 2 }, { \wrong },
    { i == 0 }, { \true },
    { \defaultFunction }
);
[i, x].postln;
)

try

Function 实现了 try 方法，允许捕获代码抛出的异常并运行异常处理器。更多信息参见 Exception。

讨论：

Example

try {
    ...code... 
} { |error|
    ...exception handler...
};

protect

Function 实现了 protect 方法，可以保护代码免受代码抛出的异常影响。它与 try 的区别在于异常处理代码总是会运行，即使没有异常。如果发生异常，它会在异常处理块运行后被重新抛出。更多信息请参见 Exception。

讨论：

Example

file = File(path, "r");
protect {
    // 在此处处理该文件，这可能会导致错误
} {
    file.close;
};

其他控制结构

使用函数，可以像上面那样定义许多控制结构。在类 Collection: Iteration 中，还定义了许多用于迭代遍历 Collection 的消息。

内联优化

如果函数中不包含变量声明，if、while、switch 和 case 表达式会被编译器优化（即内联）。该优化会从函数中提取代码，并使用更高效的跳转语句：

(
{
    if(6 == 9) {
        "hello".postln;
    } {
        "world".postln;
    }
}.def.dumpByteCodes
)
