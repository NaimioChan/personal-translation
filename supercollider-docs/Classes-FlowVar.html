FlowVar

一个占位符，访问时暂停线程，直到该占位符有值

Object

另请参阅：Ref、Thunk、Condition、Routine

说明

(
a = FlowVar.new;
fork {
    "I am waiting, please enter a value ...".postln;
    a.value.postln;
    "...... ok, done.".postln;
}
)

// 稍后再设置该值。然后我们可以继续……
a.value = 2;

类方法

FlowVar.new(inVal: 'unbound')

返回一个新实例，

参数：

inVal

如果此处给出了值，FlowVar 将不会阻塞执行。

实例方法

.value

.value = inVal

设置绑定到 FlowVar 的值。

getter 返回绑定到 FlowVar 的值。如果值尚不可用，则挂起执行（这要求该方法从 Routine 或类似线程中调用）。

参数：

inVal

任意对象。
