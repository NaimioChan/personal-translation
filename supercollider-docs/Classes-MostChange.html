MostChange

输出变化最大。

UGen : AbstractFunction : Object

另请参见：LeastChange、LastValue

子类：LeastChange

说明

给定两个输入 a 和 b，令 da[t] = abs(a[t] - a[t - 1]) 且 db[t] = abs(b[t] - b[t - 1])。如果 da[t] 较大，则输出 a[t]；如果 db[t] 较大，则输出 b[t]。如果 da[t] == db[t]，则使用上次所用的那个输入（对于输出的第一个采样，假定使用 a）。

类方法

MostChange.ar(a: 0.0, b: 0.0)

MostChange.kr(a: 0.0, b: 0.0)

参数：

a

输入信号 A。

b

输入信号 B。

实例方法

示例

(
d = SynthDef("help-MostChange", { |out, amp = 1.0|
    var sound, in1, in2;
    in1 = LFNoise1.ar(800, amp);
    in2 = SinOsc.ar(800);
    sound = MostChange.ar(in1, in2) * 0.1;
    Out.ar(out, sound)
}).play;
)

d.set(\amp, 0.1);
d.set(\amp, 0);
d.set(\amp, 3);
d.free;

// 变化最大的控件用于输出：

(
d = SynthDef("help-MostChange", { |out, freq = 440|
    var sound, internalFreq;
    internalFreq = LFNoise0.ar(0.3, 300, 800);
    sound = SinOsc.ar(
            MostChange.kr(freq, internalFreq)
    );
    Out.ar(out, sound * 0.1)
}).play;
)

d.set(\freq, 800);
d.set(\freq, 800); // 没有变化
d.set(\freq, 900);
d.free;
