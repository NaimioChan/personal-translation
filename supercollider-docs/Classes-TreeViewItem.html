TreeViewItem

TreeView 中的一项

说明

TreeViewItem 的实例表示 TreeView 中的一个项。可能有多个实例表示同一个项，例如在多次调用 TreeView: -currentItem 之后。

类方法

实例方法

.index

返回值：

此项在其同级项中的整数位置。

.parent

返回值：

一个表示父项的新 TreeViewItem 实例。

.childAt

返回值：

一个新的 TreeViewItem 实例，表示位于 index 处的子项。

.addChild

向此项追加一个新的子项。

参数：

strings

一个字符串数组（或 nil），每个对应一个数据字段的文本。

返回值：

表示新项的 TreeViewItem 实例。

.insertChild

在 index 处向此项插入一个新的子项。

参数：

index

插入子项的位置。

strings

一个字符串数组（或 nil），每个对应一个数据字段的文本。

返回值：

表示新项的 TreeViewItem 实例。

.strings

数据字段中的文本。

参数：

strings

一个字符串数组（或 nil），每个对应一个数据字段的文本。

.setString

设置给定数据字段中的文本。

参数：

column

数据字段的整数索引。

string

一个 String 或 nil。

.colors

数据字段的背景颜色。

参数：

colors

一个 Color 数组，每个元素对应一个数据字段的颜色。

.setColor

设置给定数据字段的背景颜色。

参数：

column

数据字段的整数索引。

color

一个 Color。

.textColors

数据字段的文本颜色。

参数：

textColors

一个 Color 数组，每个元素对应一个数据字段的颜色。

.setTextColor

设置给定数据字段的文本颜色。

参数：

column

数据字段的整数索引。

color

一个 Color。

.setView

将另一个视图放入给定的数据字段。一次只能将一个视图放入数据字段。若已存在视图，它将被移除并销毁。

如果由于调用 TreeView: -columns 导致数据字段数量减少，则被移除的数据字段中包含的视图也将被移除并销毁。

参数：

column

数据字段的整数索引。

view

一个 View。

.removeView

从给定数据字段中移除该视图（如果有）。

参数：

column

数据字段的整数索引。

.view

给定数据字段中的视图。

参数：

column

数据字段的整数索引。

==

实现两个 TreeViewItem 实例之间的相等比较。如果两个实例表示 TreeView 中的同一项，则它们相等。

返回值：

一个布尔值。

.isNull

该项是否无效。移除某项后，所有相关的 TreeViewItem 实例都将变为无效。

返回值：

一个布尔值。

示例

(
t = TreeView().front;
t.columns_(["one", "two", "three"]);
t.addItem(["Alice", "Anna", "Anders"]);
t.addItem(["Bob", "Beatrice", "Benny"]);
t.addItem(["Cleo", "Conrad", "Cecilia"]);
)

i = t.itemAt(1);  // get an item

i.setString(1, "Hans");
i.setColor(1, Color.red);
i.setTextColor(1, Color.white);

i.addChild(["Bengt", "Bodil", "Ben"]);
i.strings;
i.childAt(0).strings;
