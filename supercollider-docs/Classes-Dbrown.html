Dbrown

需求率布朗运动生成器。

DUGen : UGen : AbstractFunction : Object

另见：Dibrown、Demand、Duty、TDuty

子类：Dibrown

说明

Dbrown 返回 lo 和 hi 之间连续范围内的数字，Dibrown 返回整数值。

参数可以是数字或任何其他 UGen。

参见 Pbrown、BrownNoise 了解结构上相关的等价物。

类方法

Dbrown.new(lo: 0.0, hi: 1.0, step: 0.01, length: inf)

参数：

lo

最小值。

hi

最大值。

step

每个新值的最大步长。

length

要创建的值的数量。使用 inf 表示无限数量。

实例方法

示例

(
{
    var a, freq, trig;
    a = Dbrown(0, 15, 1, inf);
    trig = Impulse.kr(MouseX.kr(1, 40, 1));
    freq = Demand.kr(trig, 0, a) * 30 + 340;
    SinOsc.ar(freq) * 0.1

}.play;
)
