EZGui

EZ 控件包装器的抽象父类

参见：EZListView、EZPopUpMenu、EZSlider、EZNumber、EZRanger、EZKnob

说明

用户通常不会直接创建 EZGui 的实例，而只是通过其子类来使用它。它为各种 EZ 控件包装器提供了基本机制。它还为 EZ GUI 类提供了标准，新的 EZ 类应当继承 EZGUI，以帮助保持一致的用户界面。

类方法

实例方法

访问实例变量

.view

返回外层的 CompositeView。

.bounds

返回所在 CompositeView 的边界。

.label

设置/获取其标签。如果最初没有创建标签视图，则会添加该标签视图。

参数：

string

一个 String 的实例。

.window

如果你使用了 popUp 窗口函数，则返回该窗口。

访问 GUI 选项

.alwaysOnTop

如果存在弹出窗口，则使其始终位于最上层。

参数：

bool

一个 Boolean 的实例。默认值为 false。

.visible

设置/获取组件视图是否可见。

参数：

bool

一个 Boolean 的实例。默认为 true。

.enabled

设置/获取列表是否启用。

参数：

bool

一个 Boolean 的实例。默认为 true。

.onClose

设置/获取 view 或 window 的 onClose 函数，具体取决于 EZ view 是否使用了弹出窗口。

参数：

func

Function 或 FunctionList 的一个实例。

.font

参数：

font

Font 的一个实例。

Subclassing

EZGui 为大多数 EZ 类提供了标准和基础的工具。如果你创建一个新的 EZ 类，那么应子类化 EZGui，并重写必要的方法。如果你的类只有一个标签和一个控件，那么很可能你不需要重写任何内容，只需编写新的和 init 类方法即可。请参阅 EZGui 的现有子类以获取示例。你可能还需要重写以下内容：

.widget

返回活动控件。子类通常会引用它或忽略它，例如：

MyEZClass{
    myOtherMethods{ }
    ....
    listView{ ^widget }
}

.action

获取/设置 EZ 类实例的动作。

参数：

func

Function 或 FunctionList 的一个实例。

.value

获取/设置 widget 的值。不执行该动作。

参数：

val

一个整数。

.valueAction

获取/设置该部件的值。执行 do 动作。

参数：

val

一个整数。

.doAction

执行 this.action.value(this)。

内部工具

.prSubViewBounds

这会计算子视图和间隙的边界。它返回一个 Rect 数组，该数组取决于有多少个子视图。如果子类有多个部件，则会覆盖此方法。

.prMakeView

由 init 调用。返回 [view, bounds]。容器要么是外层 Container，要么是带容器的弹出窗口。

.prSetViewParams

仅由部分子类定义。根据 layout 的状态设置所有视图的 resize 和 align。

.prMakeMarginGap

在所有子类的 init 方法中调用。设置 view 的边距和间隙。默认情况下，它尝试获取其父项的间隙，否则默认为 2@2。设置 argGap 会覆盖这些值。
