TDelay

触发延迟。

Trig1 : UGen : AbstractFunction : Object

说明

将触发器延迟给定时间。在输入触发器与其延迟输出之间到达的任何触发器都会被忽略。

类方法

TDelay.ar(in: 0.0, dur: 0.1)

来自父类：Trig1

TDelay.kr(in: 0.0, dur: 0.1)

来自父类：Trig1

参数：

in

输入触发信号。

dur

延迟时间，单位为秒。

实例方法

示例

(
{
    z = Impulse.ar(2);
    [z * 0.1, ToggleFF.ar(TDelay.ar(z, 0.5)) * SinOsc.ar(mul: 0.1)]
}.scope)
