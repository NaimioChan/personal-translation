Array

固定大小集合

ArrayedCollection : SequenceableCollection : Collection : Object

另请参阅：字面量、List

说明

数组是 ArrayedCollection，其槽位可包含任意对象。数组有固定的最大大小，超过该大小便无法增长。对于可扩展的数组，请使用 List 类。

字面量数组可以在编译时创建，并且非常高效。相关信息请参见 Literals。

关于处理多维数组，有特定的方法，相关内容在帮助文件 J concepts in SC 中介绍。

注意： 对于数组，add 方法可能返回也可能不返回同一个数组对象。如果有空间，它会将参数添加到接收者，否则返回一个添加了参数的新数组对象。因此，对数组使用 add 的正确做法是始终将结果赋值如下：z = z.add(obj); 这样可以高效利用资源，只在需要时扩展数组。List 类在内部管理数组，在许多情况下更合适。

可以使用 a.put(2, obj) 将项放入已有的槽位，并通过 a.at(2) 或 a[2] 访问。

注意： 数组使用从 0 开始的索引，即第一个元素通过索引 0 访问。因此，在 a.put(2, obj)、a.at(2) 和 a[2] 中，索引 2 指的是第三个元素。

参见 ArrayedCollection 以了解主要方法：at、put、clipAt、wrapAt 等。

类方法

Array.new(maxSize: 0)

来自父类：Object

创建一个大小为 0 的新数组，该数组可以增长到固定大小。

参数：

maxSize

数组的最大大小。

Array.newClear(indexedSize: 0)

来自父类：ArrayedCollection

创建一个新数组，所有槽位都填充为 nil。

参数：

indexedSize

数组的大小。

Array.with( ... args)

创建一个新的 Array，其槽位由给定参数填充。这与 ArrayedCollection 中的方法相同，但在此处重新实现以提高效率。

Array.with(7, 'eight', 9).postln;

Array.fill(size, function)

来自父类：Collection

创建给定大小的集合，其元素由对给定函数求值确定。该函数以索引作为参数传入。

Array.fill(4, { |i| i * 2 });
Bag.fill(14, { |i| i.rand });

参数：

size

返回的集合的大小。若为 nil，则返回空集合。若给定大小数组，则结果集合具有相应的维度（参见：*fillND).

Array.fill([2, 2, 3], { |i, j, k|  i * 100 + (j * 10) + k });

function

为每个新元素调用的函数——索引作为第一个参数传入。该函数可以是任何响应消息 "value" 的对象。

Array.fill(10, { |i| 2 ** i });
Array.fill(10, Pxrand([0, 1, 2], inf).iter);
Array.fill(10, 7); // 不响应新值的对象只是被重复添加。

Array.fill2D(rows, cols, function)

来自父类：Collection

创建给定大小的二维 Collection。其中的元素由对所提供函数的求值决定。该函数以行索引和列索引作为参数传入。参见 J concepts in SC

Array.fill2D(2, 4, 0);
Array.fill2D(3, 4, { |r, c| r*c+c });

Array.fillND(dimensions, function, args: [])

来自父类：Collection

创建一个 N 维的 Collection，其中 N 是数组 dimensions 的大小。各项由对所提供函数的求值确定。该函数接收 N 个索引作为参数。参见 J concepts in SC

Array.fillND([4, 4], { |a, b| a+b });                // 2D
Array.fillND([4, 4, 4], { |a, b, c| a+b*c });        // 3D
Array.fillND([1, 2, 3, 4], { |a, b, c, d| b+d });    // 4D

Array.newFrom(aCollection)

来自父类：Collection

从另一个集合创建一个新集合。这支持方法 "as" 的接口。

Array.newFrom(Set[4, 2, 1]);
Set.newFrom(Array[4, 2, 1]);
[1, 2, 3, 4, 3, 2].as(Set); // as(someClass) 调用 someClass.newFrom(this)

实例方法

.at(index)

来自父类：ArrayedCollection

返回位于 index 处的项，该索引为从 0 开始的整数（或浮点数）。

x = [1, 2, 3];
x.at(2); // 返回 3
x[2];    // 等效的简写语法

index 还可以是一个索引的 Array，用于提取指定的元素：

x = [10, 20, 30];

x.at([-1, 0, 1, 2, 3]); // returns [nil, 10, 20, 30, nil]
x.at((-1..3));          // 相同，作为范围
x[(-1..3)];             // 同上

y = [0, 0, 2, 2, 1];
x[y];                   // returns [10, 10, 30, 30, 20]

也支持浮点索引，行为如下：

  • 正的浮点数索引会被向下取整到最接近的较小整数。
  • 范围 (-1, 0) 内的负浮点索引会返回第一个项，即 this.at(0)。
  • 越界索引（<= -1 或 >= this.size）返回 nil。
x = [10, 20];

x.at(-1);   // 返回 nil
x.at(-0.9); // 返回 10
x.at(-0.1); // 返回 10
x.at(-0);   // 返回 10
x.at(0);    // 返回 10
x.at(1.1);  // 返回 20
x.at(1.9);  // 返回 20
x.at(2);    // 返回 nil

一个声音示例：

(
var pitches =  [43.0, 55.0, 58.86, 57.42, 67.0];
fork {
    pitches.size.do{ |i|
        {
            var freq = pitches[i].midicps;
            var env = Env.perc.ar(Done.freeSelf);
            SinOsc.ar(freq) * 0.1 * env
        }.play;
        0.2.wait
    }
}
)

.put(index, item)

来自父类：ArrayedCollection

将 item 放在从 0 开始的 index 处，替换原有内容。index 可以是索引数组。如果使用浮点数作为索引，它将被截断。

Example:

x = [1, 2, 3];
y = x.put(0, 150); // -> [150, 2, 3]
z = x.put([0, 1], 150); // [150, 150, 3]

.insert(index, item)

来自父类：ArrayedCollection

将项插入到接收者内容的指定索引处，该索引是从 0 开始的整数。此方法可能返回一个新的 ArrayedCollection。因此，你应始终将 insert 的结果赋给一个变量——绝不要依赖 add 来改变接收者。

// 在这种情况下，会返回一个新对象，  
// 因为添加新项会超过固定的最大大小 4， 
// 该大小在数组 z 实例化时设定， 
// 之后无法更改。
// （默认情况下，以 1 到 4 之间的大小初始化的数组 
// 会保留最大大小 4）：
z = [1, 2, 3, 4]; // -> [1, 2, 3, 4]
y = z.insert(1, 999); // -> [1, 999, 2, 3, 4]
z // -> [1, 2, 3, 4]
y // -> [1, 999, 2, 3, 4]
(z == y) // -> false
(z === y) // -> false

// 在这种情况下，返回同一个对象 
// 因为新的元素数量不超过 
// 实例化时的元素数量：
z = [1, 2, 3]; // -> [1, 2, 3]
y = z.insert(1, 999); // -> [1, 999, 2, 3]
z; // -> [1, 999, 2, 3]
y; // -> [1, 999, 2, 3]
(z == y); // -> true
(z === y); // -> true

.boundedInsert(index, item)

来自父类：ArrayedCollection

改变接收者但保持其大小不变，因此与 .insert 不同，无需重新赋值 .boundedInsert 的结果。

// .boundedInsert 从不返回新对象  
// 因为插入新项永远不会超过 maxSize。  
z = [1, 2, 3, 4];            // -> [1, 2, 3, 4]
y = z.boundedInsert(1, 999); // -> [1, 999, 2, 3]
z;                           // -> [1, 999, 2, 3]
y;                           // -> [1, 999, 2, 3]
z == y;                      // -> true
(z === y);                   // -> true
y = y.boundedInsert(20, \a); // -> [1, 999, 2, a]
z = z.boundedInsert(-2, \b); // -> [b, 1, 999, 2]

.clipAt(index)

来自父类：ArrayedCollection

类似于 -at，但通过将超出集合边界之外的值裁剪掉，保证任何 index 值都有效。大于 size - 1 的值会被裁剪到最后一个索引，小于 0（负数）的值会被裁剪到 0。index 也可以是一个索引数组，用于提取指定的元素。SequenceableCollection: -|@| 是其语法简写。

a = [1, 2, 3]
a.clipAt(2) // 与在……处相同
a.clipAt(3) // clips
a.clipAt([-1, 3, 1]) // 索引数组
a|@|3 //语法快捷方式

.wrapAt(index)

来自父类：ArrayedCollection

与 -at 类似，但通过对超出集合边界范围的索引值进行回绕，保证任何索引值都有效。如果索引超过 size - 1，它会回绕到 0。同样，如果索引小于 0（负数），它会从集合末尾回绕来访问元素。this.wrapAt(index) 等价于 this.at(index mod: size)，确保索引始终在集合的有效范围内。索引也可以是索引数组，用于提取指定的元素。SequenceableCollection: -@@ 是它的语法快捷方式。

a = [1, 2, 3]
a.wrapAt(2) // 与在……处相同
a.wrapAt(3) // wraps
a.wrapAt([-1, 3, 1]) // 索引数组
a@@3 //语法快捷方式

(
var pitches =  [43.0, 55.0, 58.86, 57.42, 67.0];
fork {
    32.do{ |i|
        {
            var freq = pitches.wrapAt(i).midicps;
            var env = Env.perc.ar(Done.freeSelf);
            SinOsc.ar(freq) * 0.1 * env
        }.play;
        0.2.wait
    }
}
)

.foldAt(index)

来自父类：ArrayedCollection

与 -at 类似，但通过将集合边界之外的值反射回来，保证任何 index 值都有效。大于 size - 1 的值会朝较小的索引方向反射回来。类似地，如果索引低于 0（负数），则朝相反方向折叠。这会在集合边界内为任何索引创建对称映射。索引也可以是一个索引数组，用于提取指定的元素。SequenceableCollection: -@|@ 是其语法快捷方式。

a = [1, 2, 3]
a.foldAt(2) // 与在……处相同
a.foldAt(3) // 折返
a.foldAt([-1, 3, 1]) // 索引数组
a@|@3 //语法快捷方式

(
var pitches =  [43.0, 55.0, 58.86, 57.42, 67.0];
fork {
    32.do{ |i|
        {
            var freq = pitches.foldAt(i).midicps;
            var env = Env.perc.ar(Done.freeSelf);
            SinOsc.ar(freq) * 0.1 * env
        }.play;
        0.2.wait
    }
}
)

.clipPut(index, item)

来自父类：ArrayedCollection

与 -put 相同，但当 index 的值大于 ArrayedCollection 实例大小减一时，将被裁剪为 size - 1，即最后一个索引。

.wrapPut(index, item)

来自父类：ArrayedCollection

与 -put 相同，但若 index 的值大于 ArrayedCollection 实例大小减一，则会回绕到 0。

.foldPut(index, item)

来自父类：ArrayedCollection

与 -put 相同，但若 index 的值大于 ArrayedCollection 实例大小减一，则会被折回。

.swap(i, j)

来自父类：ArrayedCollection

交换索引 i 和 j 处的值，两者均指定为从 0 开始的整数。

[1, 2, 3].swap(0, 2).postln;

.replace(find, replace)

来自父类：ArrayedCollection

返回一个新数组，其中若干元素已被替换为其他元素。元素按相等性（而不是按身份）进行检查。

a = (0..10) ++ (0..10);
a.replace([4, 5, 6], 100);
a.replace([4, 5, 6], [1734, 1985, 1860]);

此方法由 String 继承：

a = "hello world";
a.replace("world", "word");

++(anArray)

来自父类：ArrayedCollection

将两个集合的内容连接成一个新的 ArrayedCollection。

(
var y, z;
z = [1, 2, 3, 4];
y = z ++ [7, 8, 9];
z.postln;
y.postln;
)

.add(item)

来自父类：ArrayedCollection

如果还有空间，则向 ArrayedCollection 添加一项。此方法可能返回一个新的 ArrayedCollection。因此，应始终将 add 的结果赋值给变量 —— 绝不要依赖 add 更改接收者。

(
// z 和 y 是同一个对象
var y, z;
z = [1, 2, 3];
y = z.add(4);
z.postln;
y.postln;
)

(
// 在这种情况下会返回一个新对象
var y, z;
z = [1, 2, 3, 4];
y = z.add(5);
z.postln;
y.postln;
)

.addAll(aCollection)

来自父类：ArrayedCollection

将 aCollection 的所有元素添加到接收者的内容中。此方法可能返回一个新的 ArrayedCollection。因此，你应始终将 addAll 的结果赋给一个变量——绝不要依赖 add 改变接收者。

(
// 在这种情况下会返回一个新对象
var y, z;
z = [1, 2, 3, 4];
y = z.addAll([7, 8, 9]);
z.postln;
y.postln;
)

.addFirst(item)

来自父类：ArrayedCollection

将条目插入到接收者的内容之前，可能返回一个新的集合。

(
// 在这种情况下会返回一个新对象
var y, z;
z = [1, 2, 3, 4];
y = z.addFirst(999);
z.postln;
y.postln;
)

.removeAt(index)

来自父类：ArrayedCollection

移除并返回位于 index 处的项，该索引以从 0 开始的整数或浮点数指定，同时缩小 ArrayedCollection 的大小。

y = [1, 2, 3, 4];

y.removeAt(1);
y.postln; // returns [1, 3, 4]

y.removeAt(0.5)
y.postln; // returns [3, 4]

.collect(function)

来自父类：Collection

返回一个新的集合，由对集合中每个元素求值函数所得的结果组成。该函数传入两个参数：元素和一个整数索引。示例请参见 Collection 帮助文件。

.do(function)

来自父类：ArrayedCollection

按顺序遍历元素，对每个元素调用该函数。函数被传入两个参数：元素和索引。

['a', 'b', 'c'].do({ |item, i| [i, item].postln });

.reverseDo(function)

来自父类：ArrayedCollection

按相反顺序遍历元素，对每个元素调用该函数。该函数接收两个参数：元素和索引。

['a', 'b', 'c'].reverseDo({ |item, i| [i, item].postln });

.deepCollect(depth: 1, function, index: 0, rank: 0)

来自父类：ArrayedCollection

与 -collect 相同，但可以深入子数组，直到指定的 depth。

a = [99, [4, 6, 5], [[32]]];
a.deepCollect(1, { |item| item.isArray }).postln;
a.deepCollect(2, { |item| item.isArray }).postln;
a.deepCollect(3, { |item| item.isArray }).postln;

.reshape( ... shape)

来自父类：ArrayedCollection

对于多维数组，按照每个维度所需的元素数量重新排列数据。如有需要，可以使用 Array: -wrapExtend 扩展数据。这将始终返回一个矩形数组，参见 -isRectangular。

a = [4, 7, 6, 8];
a.reshape(2, 2);
a.reshape(2, 3);

.windex

来自父类：ArrayedCollection

将数组解释为一个概率列表，其总和应为 1.0，并根据这些概率返回一个随机索引值。随机索引取自接收者的索引，从 0 开始。

(
Array.fill(10, {
    [0.1, 0.6, 0.3].windex;
}).postln;
)

.size

来自父类：ArrayedCollection

返回 ArrayedCollection 的元素数量。

.normalize(min: 0.0, max: 1.0)

来自父类：ArrayedCollection

返回一个新数组，接收者中的各项被归一化到 min 和 max 之间。

[1, 2, 3].normalize;            // 默认最小值 = 0，最大值 = 1
[1, 2, 3].normalize(-20, 10);

.normalizeSum

来自父类：ArrayedCollection

返回由以下运算得到的 Array：

(this / this.sum)

使数组的总和为 1.0。

这对于配合 windex 或 wchoose 使用很有用。

[1, 2, 3].normalizeSum.postln;

.plot: METHOD NOT FOUND!

在 GUI 窗口中绘制值。详情请参阅 plot。当接收者包含 nil 项时，绘图会因错误而失败。

.reverse

返回一个元素顺序反转的新 Array。接收者保持不变。

x = [1, 2, 3];
z = x.reverse;
x.postln;
z.postln;

.scramble

返回一个元素已被打乱的新 Array。接收者保持不变。

[1, 2, 3, 4, 5, 6].scramble.postln;

.mirror

返回一个新的 Array，它是接收者构成的回文。接收者本身不变。

[1, 2, 3, 4].mirror.postln;

.mirror1

返回一个新的 Array，它是将接收者变成回文并去掉最后一个元素后的结果。如果该列表将被循环重复，这很有用，因为第一个元素不会被播放两次。接收者保持不变。如果接收者是单元素数组，则返回其副本。

[1, 2, 3, 4].mirror1.postln;

.mirror2

返回一个新的 Array，它是接收者与其自身反转的拼接。中心元素被重复。接收者保持不变。

[1, 2, 3, 4].mirror2.postln;

重复次数。

.dupEach(n: 2)

返回一个元素重复 n 次的新 Array。接收者保持不变。

.rotate(n: 1)

返回一个元素按旋转顺序排列的新 Array。接收者保持不变。

[1, 2, 3, 4, 5].rotate(1).postln;
[1, 2, 3, 4, 5].rotate(-1).postln;

.pyramid(patternType: 1)

返回一个新数组，其元素已通过 10 种“计数”算法之一重新排序。运行示例以查看这些算法。

10.do({ |i|
    [1, 2, 3, 4].pyramid(i + 1).postcs;
});

参数：

patternType

选择计数算法。算法编号为 1 到 10。

.pyramidg(patternType: 1)

与 pyramid 类似，但将结果值分组保存在子数组中。

// 比较：
[1, 2, 3, 4].pyramid(1).postln;
[1, 2, 3, 4].pyramidg(1).postln;

.sputter(probability: 0.25, maxlen: 100)

返回一个长度为 maxlen 的新 Array，其中的项部分重复（按给定概率随机选择）。

// 比较：

参数：

probability

重复的概率。

maxlen

新 Array 的长度。

[[1, 2, 3, 4, 5], [10, 20, 30], [5, 6]].allTuples;

.wrapExtend(length)

返回一个新数组，其元素是接收者的重复序列，直到长度达到 size。接收者保持不变。

x = [1, 2, 3, "foo", 'bar'];
y = x.wrapExtend(9);
x.postln;
y.postln;

.foldExtend(length)

与 wrapExtend 相同，但序列会折回到列表元素上。

x = [1, 2, "foo"];
y = x.foldExtend(9);
x.postln;
y.postln;

.clipExtend(length)

与 wrapExtend 相同，但序列会“裁切”（返回其最后一个元素）而不是环绕。

x = [1, 2, "foo"];
y = x.clipExtend(9);
x.postln;
y.postln;

返回一个新的 Array，其元素是接收者中重复的子序列。演示比解释更容易。

[1, 2, 3, 4, 5, 6].slide(4, 1).postcs;

将数组的值向右移动 n 步（n 为正）或向左移动（n 为负），丢弃多余部分并用零填充空位。

[1, 2, 3, 4, 5, 6].shift(3).postln;

.fork(join, clock, quant: 0.0, stackSize: 64)

用于例程（Routine）内部，接受一个由函数组成的数组，并从中创建子例程。子例程在外部例程继续执行的同时被播放。join 参数表示在多少个子例程完成后，外部例程才被允许继续执行。默认情况下，这发生在所有子例程完成之后。

// 一个由例程函数组成的数组：
(
a = [
    { 1.wait; \done_one.postln },
    { 0.5.wait; \done_two.postln },
    { 0.2.wait; \done_three.postln }
];
)
// join after 0
(
Routine {
    "join = 0.".postcln;
    a.fork(0); \doneAll.postln;
}.play;
)
// join after 1
(
Routine {
    "join = 1.".postcln;
    a.fork(1); \doneAll.postln;
}.play;
)
// 最终连接
(
Routine {
    "join = a.size (default).".postcln;
    a.fork; \doneAll.postln;
}.play;
)
