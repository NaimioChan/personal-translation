对象原型化

编写运行时“类”

参见：IdentityDictionary

如果不重新编译语言，就无法创建或编辑类……但如果你确实需要这样做呢？

对象原型是一种中间方案，让你可以在运行时构建类似类的结构。它通过利用类 IdentityDictionary（通常使用其子类 Event）以及特殊方法 Object: -doesNotUnderstand 来工作。虽然这种方法存在一些奇特之处，但它极其强大。

实例变量（成员）

类似实例变量的东西可以通过仅向 IdentityDictionary 添加键来创建

a = (meow: 10)
a.meow // 10
a.meow = 20;
a.meow // 20;

与普通类不同，你可以在运行时创建新的实例变量。

a = (meow: 10)
a.woof = 4;
a.woof // 4
a.meow // 10

Methods

通过将函数赋值给某个键，你可以像调用普通实例方法一样调用该函数。

然而，IdentityDictionary 作为第一个参数传入该函数。通常，我们将这个参数称为 self，因为它所起的作用类似于关键字 this。

a = ( speak: { |self, adverb| "I say '%' %.".format(self.word, adverb) } );
a.word = "meow";
a.speak(adverb: "loudly") // 我大声说“喵”。

Functions: Variable Arguments 也适用。

a = ( speak: {|self... words, kwargs| "I say '%' %.".format(words, kwargs.asDict[\adverb]) } );

a.speak("meow", "woof", adverb: "loudly") // 我大声说 "[meow, woof]"。

Constructors

没有直接的方法来模拟构造函数，但这不成问题，因为我们可以简单地创建一个返回 IdentityDictionary 的函数。

(
var makeSpeaker = { |word|
    (
        word: word,
        speak: { |self, adverb| "I say \"%\" %.".format(self.word, adverb) }
    )
};

var cat = makeSpeaker.("meow");
var dog = makeSpeaker.("woof");

cat.speak("loudly").postln; // 我大声说“喵”。
dog.speak("quietly").postln; // 我轻声说“汪”。
)

私有实例变量（成员）

这些可以在构造函数内部作为普通变量实现，但是，你不会把它们添加到字典中。

(
var makeSpeaker = {
    var secretWords = "I'm a cat";
    (
        assign_secret: { |self, secret| secretWords = secret },
        speak_secrets: { |self| "My secret is \"%\".".format(secretWords.value) }
    )
};

var p1 = makeSpeaker.();

p1.speak_secrets().postln; // 我的秘密是 "I'm a cat"。
p1.assign_secret("I'm a dog");
p1.speak_secrets().postln; // 我的秘密是 "I'm a dog"。
)

Dangers

与类相比有两个缺点。

第一点是，任何键（包括 'methods'）都可以随时被覆盖。本质上，使 IdentityDictionary 强大的特性，也使其脆弱且容易被破坏。避免这一错误的唯一方法是在向对象原型添加键时保持警惕。

第二个缺点是，你不能拥有与 Event 或任何父类中的方法同名的键，否则会调用真实类的方法，而不是你编写的伪方法。

a = (numChannels: 10)
a.numChannels // 1

如上所示，人们期望返回的值是 10，但实际调用的是 Object: -numChannels，并返回了值 1。

有两种方法可以缓解这一问题。其一，在 snake case 中使用更长的键或名称，而不是 pascal case：即 names_written_like_this，而非 ratherThanNamesWrittenLikeThis，因为 SuperCollider 只使用后者。

两个，赋值在括号之外，此时会生成警告。

a = ();
a.numChannels = 30; // 警告：……

Inheritance

这是通过 IdentityDictionary: -'parent' 和 'proto' 变量 实现的。从技术上讲，这可以用于做比继承更多的事情，但这里只展示继承。

这是通过将 parent 赋给另一个字典来查找其中的键实现的。

a = (word: "meow" );
b = (speak: {|self| "I say \"%\".".format(self.word) } );
b.parent = a; // 将 'a' 指定为父节点。
b.speak // 我说 "喵"。

这类似于 Javascript 和其他原型语言的工作方式。
