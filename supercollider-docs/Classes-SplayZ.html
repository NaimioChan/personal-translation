SplayZ

将一个通道数组散布到一个通道环上

Object

参见：PanAz、SplayAz

说明

SplayZ 将一个声道数组散布到一个环形声道上。提供可选的 spread 和 center 控件，以及 levelComp(ensation)（等功率）。numChans 和 orientation 与 PanAz 中相同。

警告： 注意 - SplayZ 已弃用，因为其几何结构不正确。仅为向后兼容而保留 - 请将你的 patch 调整为由 SplayAz 替代！行为对比请参见 SplayAz 帮助文件。

实例方法

示例

(
x = { |spread = 1, level = 0.2, width = 2, center = 0.0|
 SplayZ.ar(
  4,
  SinOsc.ar({ |i| LFNoise2.kr(rrand(10, 20), 200, i + 3 * 100) } ! 10),
  spread,
  level,
  width,
  center
 );
}.scope;
)

x.set(\spread, 1,   \center, 0);  // 完整 n 声道
x.set(\spread, 0.5, \center, -0.25); // 较窄
x.set(\spread, 0, \center, 0);  // 单声道居中（取决于方向，参见 PanAz）
x.set(\spread, 0, \center, -0.25); //
x.set(\spread, 0.0, \center, 0.5); // 单声道, 但将 1 旋转到更高的通道
x.set(\spread, 0.5, \center, 0.5); // 分布到更高的声道
x.set(\spread, 0,   \center, -0.25); // 全部优先
x.set(\spread, 1,   \center, 0);  // 完整 n 声道

x.free;

 // 使用 arFill 编写的相同示例：
(
x = { |spread = 1, level = 0.5, width = 2, center = 0.0|
 SplayZ.arFill(
  4,
  10,
  { |i| SinOsc.ar(LFNoise2.kr(rrand(10, 20), 200, i + 3 * 100)) },
  spread,
  level,
  width,
  center
 );
}.scope;
)

 // 或使用鼠标控制
(
x = { var src;
 src = SinOsc.ar({ |i| LFNoise2.kr(rrand(10, 20), 200, i * 100 + 400) } ! 10);
 SplayZ.ar(4, src, MouseY.kr(1, 0), 0.2, center: MouseX.kr(-1, 1));
}.scope;
)
