LinuxPlatform

Linux 平台特定方法

UnixPlatform : Platform : Object

说明

此类仅在 Linux 上可用，实现 Linux 平台特定的方法。

Jack 的环境变量

除其他功能外，该类使得可以在 Linux 操作系统中设置一些环境变量，以便在启动时自动连接 Jack Audio Server。

有关此内容的更多信息，请参见 音频设备选择：Linux。

类方法

设置或查找终端模拟器

LinuxPlatform.runInTerminalCmd

LinuxPlatform.runInTerminalCmd = value

获取或设置在执行 String: -runInTerminal 时用于调用终端模拟器的首选命令。

如果为 nil（这是默认值），则首次调用 runInTerminal 时，sclang 会搜索系统上安装的受支持的终端模拟器（参见 *getTerminalEmulatorCmd）。

注意： 此设置不会跨会话保留

参数：

(value)

一个字符串，其中必须包含两个%。例如：

LinuxPlatform.runInTerminalCmd = "xterm -T % -e %"

第一个 "%" 是窗口标题的占位符，第二个是实际要执行的命令的占位符。请参阅你的终端模拟器的文档以找到合适的命令行标志。

LinuxPlatform.getTerminalEmulatorCmd

扫描系统以查找受支持的终端模拟器。此方法同步运行，在搜索时可能会阻塞其他已调度的操作。如果你依赖 String: -runInTerminal，建议在开始调度 Pattern 或 Routine 之前运行此方法，或手动设置 *runInTerminalCmd。

返回值：

调用终端模拟器的命令，用作 LinuxPlatform: *runInTerminalCmd
