Integer

32 位整数

SimpleNumber : Number : Magnitude : Object

说明

一个 32 位整数。Integer 的大部分行为继承自其父类 SimpleNumber。

注意： 整数可以表示范围从 -2147483648 (-2^31) 到 2147483647 (2^31 - 1) 的值。整数的溢出行为是未定义的。每当操作结果无法容纳在返回类型所支持的值范围内时（在此情况下为 32 位有符号整数），就会发生这种情况。对于更大的数字（最多 ±2^53），请考虑使用 64 位 Float。

.modSeaside(aNumber, adverb)

3.14 之前版本的取模运算，对负整数模数具有意外行为。

对于小于负除数的被除数，modSeaside 会将得到的余数拉到除数之下。因此它让零保留在零线上作为峰值。与通常的 mod 一样，所有更大的被除数都得到大于零的余数。

(..-9).mod(-3);
// returns [0, -1, -2, 0, -1, -2, 0, -1, -2, 0]
(..-9).modSeaside(-3);
// returns [0, 2, 1, 0, -4, -5, 0, -4, -5, 0]

// plot
(-25..25).modSeaside(-5).plot.plotMode_(\steps);

// modSeaside
Pbind(\note, modSeaside(Pseries(-15, 1, 25), -5), \dur, 0.2).play;

// 使用不同除数的 modSeaside
Pbind(\note, modSeaside(Pseries(-15, 1, 25), [3, -4, -5]), \dur, 0.2).play;

// mod
Pbind(\note, mod(Pseries(-15, 1, 25), -5), \dur, 0.2).play;

// 使用不同的除数取模
Pbind(\note, mod(Pseries(-15, 1, 25), [3, -4, -5]), \dur, 0.2).play;

.clip(lo, hi)

返回值：

  • 接收者，如果其位于 lo 与 hi 之间
  • 如果接收者小于 lo，则为 lo
  • 如果接收者大于 hi，则为 hi

仅当 lo 和 hi 均为 Integer 时，结果才是 Integer。

讨论：

4.clip(2, 5); // 返回 4
0.clip(2, 5); // 返回 2
7.clip(2, 5); // 返回 5

.factorial

返回值：

接收者的阶乘，以整数形式返回。对于 > 12 的数字会溢出并抛出错误。此类情况下可以使用浮点阶乘（参见：SimpleNumber: -factorial）。

讨论：

12.factorial
23.0.factorial // 对于更大的阶乘，请使用浮点数。

范围限制

.clip(lo, hi)

如果 lo <= this <= hi，则返回 this，否则返回最近的边界：如果 this < lo 则返回 lo，如果 this > hi 则返回 hi。

参数：

lo

裁剪的低阈值。

hi

裁剪的高阈值。

.fold(lo, hi)

将此折叠到 [lo, hi]。

参数：

lo

折叠的低阈值。

hi

折叠的高阈值。

.wrap(lo, hi)

将 [lo, hi] 包裹在其中，使其落入范围内。等价于 (this % (hi - lo + 1)) + lo。请注意，此行为与 Float: -wrap 不同。

参数：

lo

回绕的低阈值（含）。

hi

环绕的高阈值（包含）。
