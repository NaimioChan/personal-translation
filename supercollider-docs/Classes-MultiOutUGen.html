MultiOutUGen

所有具有多个输出的 UGen 的父类

UGen : AbstractFunction : Object

参见：OutputProxy

子类：AbstractIn、AudioControl、Balance2、BeatTrack，

说明

这是所有具有多个输出的 UGen 的父类。MultiOutUGen 会创建多输出所需的 OutputProxy UGen。

类方法

未文档化的类方法

实例方法

.initOutputs(numChannels, rate)

为输出创建 OutputProxy 数组。

参数：

numChannels

输出数量。必须是非零的正整数。这在编译 SynthDef 时是固定的，因此不能赋值给 SynthDef 参数。

rate

OutputProxy 的速率。
