Rest

表示事件模式中的休止。

Operand : AbstractFunction : Object

参见：Pbind、Event、AbstractFunction

说明

Rest 可用于事件模式中，以表示生成的事件应为休止（即静音）。例如，它应用于属于 Pbind 的某个子模式中。

// 什么都不做持续 2 秒
(note: Rest(), dur: 2).play;

// 在模式中穿插停顿
Pbind(\note, Pseq([0, 4, 7, 11], inf), \dur, Pseq([2, 1, Rest(1)], inf) / 5).play;

在事件模式中表达休止

Rest 类允许在任何流中表示休止，不仅限于频率或事件类型。此外，使用 duration 参数（见下面的 *new 方法），休止可以嵌入到持续时间流中。也就是说，休止可以当作节奏规格的一部分来处理，而不是音高规格的一部分。

注意： 自 SuperCollider 3.9 起，Rest 的行为已变得更加直观。请注意，现在必须使用 Rest() —— 直接将 Rest 用作类的快捷方式不再受支持。

Usage

  • Event: -isRest 会检查事件中的每个条目是否满足休止的条件：它可能是 Rest 实例、Rest 类，或符号 \ 与 \r 中的任意一个。如果任一条目满足条件，该事件将被视为休止，播放时不会执行任何操作。
  • 如果 Pbind 子模式产生一个 Rest 对象，该 Rest 会直接放入事件中。这是与 3.8 相比的行为变化。
  • 如果 Rest 对象有一个值，它将响应数学运算：Rest(1) * 2 == Rest(2)。

类方法

除 *new 之外，Rest 的所有方法都是私有的，不应直接使用。

Rest.new(value: 1)

创建一个 Rest 实例，其值将用于生成的 rest 事件。

参数：

value

Rest 实例的数值，用于数学运算。注意，对于大多数 Event 键，Rest 的值会被忽略（假定该 Event 对 .play 不做任何响应）。如果 Rest 出现在节奏键（dur 或 delta）中，则该数字表示到下一个事件的时间。因此，数值型 Rest 常用于时长——但并没有要求 Rest 的值必须是时长。

讨论：

a = Rest(6);
b = a * 2; // 返回 Rest(12)
b = 2 * a; // 相同
b.value; // 返回 12

一个休止的剩余部分始终是休止。这种幂等性由 Rest 的父类 Operand 实现。

Rest(Rest(1)) // 返回 Rest(1)

实例方法

.isRest

返回 true

.unwrapBoolean

返回值。

讨论：

此方法实现以下行为。

Rest(6) + 1 // Rest(7)
Rest(true) // true

这使比较可以正常工作：

Rest(6) < 7 // true，而不是 Rest(true)
a = Pseq([1, 2, 1, 3, Rest(1), 2, Rest(3)], inf); // 例如作为时值模式
b = a.collect { |x| if(x > 2) { x / 2 } { x } };
b.asStream.nextN(8)

示例

在音高流中使用 Rest 实例

(
Pbind(
    \degree, Pif(
        0.1.loop.coin,
        Pseq([Rest(), 7], inf), // 每一秒都是一个休止
        Pseries(0, 1, inf).fold(-7, 7)
    ),
    \dur, 0.125
).play
)

在时长流中使用 Rest 实例

(
Pbind(
    \degree, Pseries(0, 1, inf).fold(-7, 7),
    \dur, Pseq([Pn(0.125, { rrand(3, 6) }), Rest(0.25)], inf)
).play
)

Rest 的替代方案

除了 Rest 之外，事件中的休止还可以用另外两种方式指定（旧式用法）。

  • 可以在任何频率流中指定一个 Symbol（在 degree、note、midinote 或 freq 键下）。此规则的例外是控制总线映射符号，以 'c' 开头后跟数字。常用的典型符号包括 \rest、\r 和空符号 \。

    (
p = Pbind(
    \degree, Pseq([
        0, 1, 2, 0, 0, 1, 2, 0,
        2, 3, 4, \rest, 2, 3, 4, \rest
    ]),
    \dur, 0.25
).play;
)

  • 该事件的 \type 可以设置为 \rest。

    (
p = Pbind(
    \degree, Pseries(0, 1, inf).fold(-7, 7),
    \dur, 0.125,
    \type, Pwrand([\note, \rest], [0.9, 0.1], inf)
).play;
)

p.stop;
