Pen

绘制自定义图形

参见：QPenPrinter

说明

一个允许你在 UserView 或 Window 上绘制自定义图形的类。

以下方法必须在 Window: -drawFunc 或 UserView: -drawFunc 函数内调用，并且只有在窗口或视图刷新后才会可见。每次调用 Window: -refresh 或 UserView: -refresh 都会通过执行当前定义的函数来“覆盖”之前的所有绘制，除非 UserView: -clearOnRefresh 被设置为 false

类方法

构造路径

以下方法定义路径。你需要调用 *stroke 或 *fill 来实际绘制它们。

.moveTo

将 Pen 移动到指定点。

参数：

point

一个 Point 的实例

.lineTo

从当前位置到 point 绘制一条线（定义一条路径）。

参数：

point

一个 Point 的实例

.line

从 p1 到 p2 绘制一条线（定义一条路径）。当前位置将变为 p2。

参数：

p1

一个 Point 的实例

p2

一个 Point 的实例

从当前位置向 point 绘制一条三次贝塞尔曲线。cpoint1 和 cpoint2 是决定曲线曲率的控制点。

参数：

endPoint

一个 Point 的实例

cPoint1

一个 Point 的实例

cPoint2

一个 Point 的实例

.quadCurveTo

从当前位置到 point 绘制一条二次贝塞尔曲线。cpoint 是决定曲线曲率的控制点。

参数：

endPoint

一个 Point 的实例

cPoint

一个 Point 的实例

.arcTo

使用半径和切点绘制圆弧。

参数：

point1

第一条切线段的终点。其起点为当前位置。一个 Point 实例

point2

第二条切线的终点。其起点为 point1。一个 Point 的实例

radius

弧的半径。

讨论：

example:

(
var w = Window("arcTo", Rect(100, 200, 300, 300)).front;
var r = 15;
w.drawFunc = { |v|
    Pen.fillColor = Color.blue;
    Pen.strokeColor = Color.red;
    Pen.moveTo(150@150);
    Pen.arcTo(200@150, 200@225, r);
    Pen.arcTo(200@225, 100@225, r);
    Pen.arcTo(100@225, 100@150, r);
    Pen.arcTo(100@150, 150@150, r);
    Pen.lineTo(150@150);
    Pen.fillStroke;
};
)

.addArc

围绕 Point center 绘制一段弧，半径为 radius 像素。startAngle 和 arcAngle 分别指起始角度和弧的跨度，单位为弧度 [0..2pi]。

讨论：

example:

(
w = Window.new.front;
w.view.background_(Color.white);
w.drawFunc = {
    Pen.translate(100, 100);
    10.do{
        // 设置颜色
        Pen.color = Color.red(rrand(0.0, 1), rrand(0.0, 0.5));
        Pen.addArc((100.rand)@(100.rand), rrand(10, 100), 2pi.rand, pi);
        Pen.perform([\stroke, \fill].choose);
   }
};
w.refresh;
)

.addWedge

在 Point center 周围绘制一个楔形，半径为 radius 像素。startAngle 和 sweepLength 分别指起始角度和弧的跨度，单位为弧度 [0..2pi]。

讨论：

example:

(
w = Window.new.front;
w.view.background_(Color.white);
w.drawFunc = {
    Pen.translate(100, 100);
    10.do{
        // 设置颜色
        Pen.color = Color.blue(rrand(0.0, 1), rrand(0.0, 0.5));
        Pen.addWedge((100.rand)@(100.rand), rrand(10, 100), 2pi.rand, 2pi.rand);
        Pen.perform([\stroke, \fill].choose);
    }
};
w.refresh;
)

.addAnnularWedge

围绕 Point center 绘制一个环形楔形，从 innerRadius 到 outerRadius，以像素为单位。startAngle 和 sweepLength 分别指起始角度和弧的跨度，以弧度 [0..2pi] 为单位。

讨论：

example:

(
w = Window.new.front;
w.view.background_(Color.white);
w.drawFunc = {
    Pen.translate(100, 100);
    1000.do{
        // 设置颜色

        Pen.addAnnularWedge(
            (100.rand)@(100.rand),
            rrand(10, 50),
            rrand(51, 100),
            2pi.rand,
            2pi.rand
        );
        Pen.perform([\stroke, \fill].choose);
    }
};
w.refresh;
)

图形状态方法

以下命令变换图形状态，即它们会影响所有后续的绘图命令。这些变换是累积的，即每个命令应用于先前的图形状态，而不是原始状态。

.translate

平移坐标系，使其原点移动 x、y

讨论：

example:

(
w = Window.new.front;
w.view.background_(Color.white);
w.drawFunc = {
    Pen.strokeColor = Color.blue;
    Pen.translate(200, 100); // 0@0 is now 200@100
    Pen.moveTo(0@0);
    Pen.lineTo(50@100);
    Pen.lineTo(100@100);
    Pen.lineTo(0@150);
    Pen.lineTo(-100@100);
    Pen.lineTo(-50@100);
    Pen.lineTo(0@0);
    Pen.stroke
};
w.refresh;
)

累积平移：

(
w = Window.new.front;
w.view.background_(Color.clear);
w.drawFunc = {
    Pen.strokeColor = Color.black;
    35.do { // 绘制 35 条线
        Pen.moveTo(0@0);
        Pen.lineTo(50@350);
        Pen.translate(10, 0); // 每次向右移动 10
        Pen.stroke
    }
};
w.refresh;
)

绘制函数，然后恢复到之前的图形状态。这使您可以在不显式恢复以回到“正常”状态的情况下，对图形状态进行复杂的变换。

            Pen.stroke;

    Pen.line(10@120, 300@120);
    Pen.stroke;

            Pen.rotate(0.1pi);

            Pen.fillColor = Color.yellow(1, 0.5);
            Pen.scale(0.8, 0.8);
            Pen.rotate(0.1pi);

Animation

使用随机种子来“存储”数据。通过每次重置种子，会为每个“帧”生成相同的随机值和形状。然后只需简单地递增 phase 变量，就可以对这些值施加累积旋转等操作。

(
// 作者：James McCartney
var w, h = 700, v = 700, seed, run = true, phase = 0;
w = Window("wedge", Rect(40, 40, h, v), false);
w.view.background = Color.rand(0, 0.3);
w.onClose = { run = false }; // 关闭时停止该线程
w.front;
// 为随机生成器存储一个初始种子值
seed = Date.seed;
w.drawFunc = {
    Pen.width = 2;
    Pen.use {
        // 暂时重置此线程的种子
        thisThread.randSeed = Date.seed;
        // 现在有很小的概率出现新种子或背景色
        if (0.006.coin) { seed = Date.seed };
        if (0.02.coin) { w.view.background = Color.rand(0, 0.3) };
        // 要么恢复到存储的 seed，要么设置新的 seed
        thisThread.randSeed = seed;
        // 如果种子未改变，下面的随机值每次都会相同
        // 只有相位值发生了前进
        Pen.translate(h/2, v/2);
        // 旋转整幅图像
        // 负的随机值向一个方向旋转，正值向另一个方向
        Pen.rotate(phase * 1.0.rand2);
        // 用正弦模式缩放旋转后的 y 轴
        Pen.scale(1, 0.3 * sin(phase * 1.0.rand2 + 2pi.rand) + 0.5);
        // 创建随机数量的环形楔形
        rrand(6, 24).do {
            Pen.color = Color.rand(0.0, 1.0).alpha_(rrand(0.1, 0.7));
            Pen.beginPath;
            Pen.addAnnularWedge(Point(0, 0), a = rrand(60, 300), a + 50.rand2, 2pi.rand
                + (phase * 2.0.rand2), 2pi.rand);
            if (0.5.coin) { Pen.stroke }{ Pen.fill };
        };
    };
};

// fork 一个线程每秒更新 20 次，并每次推进相位
{ while { run } { w.refresh; 0.05.wait; phase = phase + 0.01pi } }.fork(AppClock)

)
(
var w, phase = 0, seed = Date.seed, run = true;
w = Window("my name is... panel", Rect(128, 64, 800, 800));
w.view.background = Color.blue(0.4);
w.onClose = { run = false };
w.front;
w.drawFunc = {
    Pen.use {
        if (0.02.coin) { seed = Date.seed };
        thisThread.randSeed = seed;
        Pen.strokeColor = Color.white;
        200.do {
            var a = 4.rand;
            var b = 24.rand;
            var r1 = 230 + (50 * a);
            var a1 = 2pi / 24 * b + phase;
            var r2 = 230 + (50 * (a + 1.rand2).fold(0, 3));
            var a2 = 2pi / 24 * (b + (3.rand2)).wrap(0, 23) + phase;
            Pen.width = 0.2 + 1.0.linrand;
