Dictionary

将键映射到值的关联集合

Set : Collection : Object

另请参阅：Environment、Event

子类：IdentityDictionary

说明

Dictionary 是一种将键映射到值的关联集合。如果两个键 相等，则它们匹配。（即 == 返回 true。）

Dictionary 的内容是无序的。你绝不能依赖 Dictionary 中条目的顺序。你只能依赖键的相等性。例如，符号和字符串都可以用作键，因为匹配是通过相等性（==）而非同一性（===）完成的。关于同一性匹配（此时字符串不能用作键），请参阅：IdentityDictionary 和 Event。

注意： 将 nil 设为值会从 Dictionary 中删除该键。这意味着 nil 本身不能用作 Dictionary 的值。

d = Dictionary();
d.put(\a, 440);
d.keys; // Set[\a]
d.put(\a, nil); // 移除值 440
d.keys; // Set[]

类方法

Dictionary.new(n: 8)

创建一个具有 n 个键值映射初始容量的字典。

Dictionary.newFrom(aCollection)

从另一个集合创建一个新的 Dictionary。

d = Dictionary.newFrom([\a, 1, \b, 2, \c, 4]);

参数：

aCollection

任何响应 keysValuesDo 的对象（通常是 List 或 Array）。

讨论：

也可以从 Association 的数组创建一个新的 Dictionary：

Dictionary.with(*[\a->1, \b->2, \c->3])

或者来自单个 Association，如下所示：

d = Dictionary[\a -> 1];

实例方法

添加与移除

.add(anAssociation)

将 anAssociation 添加到 Dictionary。如果键值对已存在于 Dictionary 中，则键的值将被替换。

(
d = Dictionary.new;
d.add(\monkey -> 0).postln;
d.add(\robot -> 1).postln;    // 将 robot 添加为值为 1 的键
d.add(\monkey -> 2).postln;    // 将键 monkey 的值替换为 2
)

.put(key, value)

关联两个对象并将它们添加到 Dictionary 中。

d = Dictionary.new;
d.put("abc", 10);

// 使用事件：
d = ();
d.put("abc", 10);

参数：

key

与对象关联的键。这可以是任何对象，但通常是 Symbol。

value

一个对象

.removeAt(key)

从 Dictionary 中移除该键及其关联的值。

d = Dictionary[\monkey -> 99];
d.removeAt(\monkey);

.putAll( ... dictionaries)

将每个参数的所有项添加到字典中。

d = Dictionary.new;
d.putAll(Dictionary[\hello -> 9, \whello -> "world"], Dictionary["abd" -> 6]);

参数：

... 字典

任何响应 keysValuesDo 的对象（通常是 Dictionary）。

.putPairs(args)

将所有项添加到字典中，成对地将它们用作键和值。

d = Dictionary.new;
d.putPairs([\hello, 10, \whello, "lord", "abc", 7]);

Accessing

.at(key)

访问与键关联的值。

d = Dictionary[\robot -> 99];
d.at(\robot);    // 获取与 key 关联的值
d[\robot];    // 不同的语法，相同的行为
d.at(\monkey);    // 键不存在：返回 Nil

.atFail(key, function)

访问与该键关联的值。如果该键不存在，则返回 function 的结果。

.keys(species)

返回包含所有键的 Set。

d = Dictionary.newFrom([\hello, 9, \whello, "world"]);
d.keys;

.values

返回包含所有值的 List。

d = Dictionary.newFrom([\hello, 9, \whello, "world"]);
d.values;

.atAll(keys)

来自父类：Collection

返回一个数组，包含给定键的所有值。

d = Dictionary.newFrom([\hello, 9, \whello, "world", \z, 99, \c, 0.33]);
d.atAll([\hello, \z, \hello, \c, \whello]);

.getPairs(args)

返回一个包含所有键值对（成对排列）的 Array。

讨论：

d = Dictionary.newFrom([\hello, 9, \whello, 77, \z, 99]);
d.getPairs;

注意，与 -asPairs 不同，getPairs 在 Dictionary 为空时会返回 nil。

d = Dictionary.new;
d.getPairs;

.associationAt(key)

访问具有给定键的 Association。元素按相等性（不是按身份）进行检查。

d = Dictionary["robot" -> 99];
d.associationAt("robot");    // 获取与 key 关联的值

.findKeyForValue(argValue)

尝试查找给定值并返回其键。元素按相等性（而非同一性）检查。

d = Dictionary.newFrom([\hello, 1, \whello, 77]);
d.findKeyForValue(1);

.matchAt(key)

字典的键被用作条件，用于匹配任意项。参见：matchItem 返回关联的值，如果没有键匹配该项则返回 nil。

注意： 如果某个项匹配多个条件，返回的值是不确定的。这是因为字典是无序集合。用户有责任确保各条件互斥。

  • 如果键是一个对象，则该项将按身份匹配（如果 key === item，则返回该值）。
  • 如果键是一个集合，则当该项包含在该集合中时进行匹配。
  • 如果键是一个函数，则以该项为参数对该函数求值，若函数返回 true 则该项匹配。
(
d = Dictionary.newFrom([
    0, \zero,
    \abc, \alpha,
    [1, 2, 3, 5, 8, 13, 21], \fibonacci,
    { |x| try { x.even } }, \even // 需要 try，因为参数可能不是数字
    ]);
);

d.matchAt(0)    // 同时匹配 'zero' 和 'even'，其中任一都可能被返回
d.matchAt(1)
d.matchAt(2)    // 同时匹配 'fibonacci' 和 'even'，可能返回其中任意一个
d.matchAt(4)
d.matchAt(\abc)

.trueAt(key)

如果该项在键处的 booleanValue 为 true，则返回 True，否则返回 false。

// 使用二进制值等价物
d = (x:1, y:0);
d.trueAt(\x)   // true
d.trueAt(\y)   // false
d.trueAt(\foo) // false

// 其他类型的对象
d = (num: 23.7, yes:true, no:false, sym:\foo);
d.trueAt(\num) // true
d.trueAt(\yes) // true
d.trueAt(\no)  // false
d.trueAt(\sym) // false
d.trueAt(\bar) // false（d[\bar] 为 nil）

.falseAt(key)

如果该项在键处的 booleanValue 为 false，则返回 True，否则返回 true。示例参见 -trueAt。

Testing

.includes(item1)

如果指定的项作为值存储在 Dictionary 中，则返回 true。元素按相等性检查（而非同一性）。关于同一性匹配，请参见子类：IdentityDictionary 或 Event。

var d = Dictionary.newFrom([\a, "hey", \b, "hello"]);
d.includes("hey").postln; // -> true

.includesKey(key)

如果指定项作为键存储在 Dictionary 中，则返回 true。按相等性（而非同一性）检查元素。对于同一性匹配，请参见子类：IdentityDictionary 或 Event。

var d = Dictionary.newFrom(["hey", 1, "hello", 2]);
d.includesKey("hey").postln; // -> true

Iteration/Enumeration

大多数迭代方法的工作方式与其父类 Dictionary 类似，参见例如 Collection。

.do(function)

.collect(function)

.reject(function)

.select(function)

// do、collect、reject、select
d = Dictionary[\a -> "hello", \b -> "robot", \c -> [1, 2, 3]];
d.do { |item, i| [item, i].postln };
d.collect { |item| item + 100 };
d.reject { |item| item.size > 4 };
d.select { |item| item.size > 4 };

.keysValuesDo(function)

遍历关联，并对每个关联计算函数，将键和值作为参数传入。

d = Dictionary[\a -> "hello", \b -> "robot", \c -> [1, 2, 3]];
d.keysValuesDo { |key, value| postln("the key: " ++ key ++ " the value: " ++ value) };

.keysValuesChange(function)

遍历各个关联，并对每个关联求值函数，把键和值作为参数传入。用函数的返回值替换对应的值（类似于 -collect，但会就地修改字典）。

d = Dictionary[\a -> "hello", \b -> "robot", \c -> [1, 2, 3]];
d.keysValuesChange { |key, value| "the key: " ++ key ++ " the value: " ++ value };
d;

.keysDo(function)

遍历各个关联，并对每个关联求值该函数，将键作为参数传入。

d = Dictionary[\a -> "hello", \b -> "robot", \c -> [1, 2, 3]];
d.keysDo { |key| postln("the key: " ++ key) };

.associationsDo(function)

遍历关联，并为每个关联求值该函数。

d = Dictionary[\a -> "hello", \b -> "robot", \c -> [1, 2, 3]];
d.associationsDo { |assoc| postln("the association: " ++ assoc) };

.pairsDo(function)

遍历关联，并对每个关联求值函数，将键和值作为参数传入。等同于 -keysValuesDo

.invert

返回一个新字典，所有值与键互换。

d = Dictionary[\a -> "hello", \b -> "robot", \c -> [1, 2, 3]];
d.invert;

其他实例方法

.order(func)

返回一个键的数组，其顺序与该字典中值的顺序相对应。

d = Dictionary[\a -> 5, \b -> 7, \c -> 1, \d -> 0];
d.order;
d.atAll(d.order);    // 按顺序返回各项

.powerset

返回所有子集的集合：这里是一个包含所有子字典的数组。

d = Dictionary[\a -> 5, \b -> 7, \c -> 1, \d -> 0];
d.powerset;

.merge(that, func, fill: true)

通过对每个值应用一个函数，将两个字典合并为一个新字典。如果 fill 为 true（默认值：true），则其中一个字典中缺失的值将保持原样。

d = Dictionary[\a -> 5, \b -> 7, \d -> 0];
e = Dictionary[\a -> 3, \b -> -3, \c -> 1];
merge(d, e, { |a, b| a + b });
merge(d, e, { |a, b| a + b }, false);

参数：

that

另一个字典。

func

一个 Function。

fill

一个 Boolean。

.blend(that, blend: 0.5, fill: true, specs)

通过插值每个值将两个字典混合成一个新的字典。如果 fill 为 true（默认值：true），则其中一个字典中缺失的值会保持原样。

d = Dictionary[\a -> 5, \b -> 7, \d -> 0];
e = Dictionary[\a -> 3, \b -> -3, \c -> 1];
blend(d, e, 0.3);
blend(d, e, 0.3, false);

d = Dictionary[\a -> 500, \b -> 0.001];
e = Dictionary[\a -> 300, \b -> 0.1];
blend(d, e, 0.3, specs: (a: \freq, b: \rq));

参数：

that

另一个字典。

blend

混合比例，为一个介于 0.0 和 1.0 之间的 Float。

fill

一个 Boolean。

specs

一个 Spec 字典，在混合之前分别应用于每一项。

.asSortedArray

返回按键值对排序的数组中的值。按键排序。

d = Dictionary[\a -> 5, \b -> 7, \c -> 1, \d -> 0];
d.asSortedArray;

.asDict(mergeFunc, class)

如果未传入任何参数，则返回自身。这是 Key Value Pairs 接口的一部分。

参数：

mergeFunc

此参数未被使用，存在的目的是使该方法与 Collection: -asDict 兼容。

class

如果给定，则转换为的目标字典类（通过 newFrom 完成转换）。

.asPairs(class)

以交替的键值对数组形式返回值，例如 [\freq, 1848, \amp, 0.2]。这是 Key Value Pairs 接口的一部分。

参数：

class

要返回的集合的类。默认情况下为 Array。

讨论：

d = Dictionary[\a -> 5, \b -> 7, \c -> 1, \d -> 0];
d.asPairs;

注意，与 -getPairs 不同，asPairs 在 Dictionary 为空时将返回一个空 Array。

d = Dictionary.new;
d.asPairs;

.asKeyValuePairs

参见 -asPairs。

.embedInStream(event)

参数：

event

inval，通常出现在事件流中。另请参见 Event。

如果事件不为 nil，则产生一个副本，添加接收者事件的所有元素（这不会改变接收者）。如果为 nil，则返回接收者。

由于这个模式主要用于事件的上下文，以下代码示例使用子类 Event 的快捷方式，而不是 Dictionary。

a = (note: 2);
b = (note: [3, 5]);
Pseq([a, b]).play;

如果给出了键 "embedInStream"，则改用此函数。通过这种方式可以轻松配置事件的行为。

参数 event（接收者）和 inevent（inevent）被传递给该函数。

注意： 在无限模式中，必须在函数中调用 yield 或 embedInStream，否则它将永远循环。

(
a = (
    pattern: Pbind(\note, Pgeom(1, 1.1, { 20.rand }), \dur, 0.05),
    embedInStream: { |event, inevent| event[\pattern].embedInStream(inevent) }
);
b = (note: [3, 5]);
c = (freq: 402, dur: 0.3);
Prand([a, b, c], inf).trace.play;
)

// 在播放时更改事件
c[\freq] = [900, 1002, 1102];
c[\freq] = [200, 101, 1102];

用于字典的生成器：

(
d = (
    a: 5, b: 7, c: 1,
    rout: Routine { |inval|
        inf.do { |i|
            var event = d.copy.put(\count, i);
            inval = event.embedInStream(inval);
        }
    }
);
)

// 绘制新值
d.rout.((z: 999));
d.rout.((z: 1, a: 0));
d.rout.(());

Overview

Dictionary、IdentityDictionary、Environment 和 Event 之间的区别

通常，子类 Event 被用作 IdentityDictionary，因为有一种语法快捷方式：

a = (foo: 7);    // 返回一个新的 Event。
a.put(\foo, 2.718);
a.at(\foo);
a[\foo] = 3.5;    // put 的不同语法

Event、Environment 和 IdentityDictionary 与 Dictionary 的主要区别在于，键被视为相同（===）的对象（参见 IdentityDictionary），而不是相等（==）的对象。因此，这些子类在进行索引时也更快。除此之外，这些子类只添加了特定的功能。

// 字符串和 symbol 的初步同一性和相等性
"hello" == "hello";    // 正确，但是
"hello" === "hello";    // false。然而：
\hello === \hello;    // true

// 对比：Dictionary 只会存储一个 "hello"
Dictionary["hello" -> 0, "hello" -> 1]; // Dictionary[(hello -> 1)]
// 而 Event 会同时存储两者为 "hello"，因为它们不相同
("hello": 0, "hello": 1); // ("hello": 1, "hello": 0)

// 对于以符号为键的情况，Dictionary 和 Event 表现出相同的行为：
Dictionary[\hello -> 1, \hello -> 0]; // Dictionary[(hello -> 0)]
(\hello: 1, \hello: 0); // ('hello': 0)
