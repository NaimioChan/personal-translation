バスにオーディオを乗せる

默认情况下，SuperCollider 拥有 1024 个音频总线。总线作为数组中的元素存在。

////////////////////////////////////////////////////////////////////////////////////////////////////

// 音频总线（通道）的数组 [ channel0, channel1, channel2, channel3, channel4, ... , ..., ..., etc., ... channel127 ]

////////////////////////////////////////////////////////////////////////////////////////////////////

要将数据送入音频总线，需要使用以音频速率运行的 Out 这个 ugen。

(
SynthDef("dataForABus", {
    Out.ar(
        0,        // 1チャンネル分のオーディオをバス0に書き込む
        Saw.ar(100, 0.1)
    )
}).add;
)

Synth("dataForABus");

如 SynthDef 浏览器所示，

(
// 評価してみて下さい
SynthDescLib.global.read;
SynthDescLib.global.browse;
)

この例は（1チャンネル分の）オーディオ出力をチャンネル0に乗せます。

////////////////////////////////////////////////////////////////////////////////////////////////////

バスからオーディオを取得する

要从音频总线获取数据，请向名为 In 的 ugen 发送 .ar 消息。

(
SynthDef("dataFromABus", {
    Out.ar(
        0,
        [    //　左チャンネルはオーディオ・バスから入力を得る
            In.ar(0, 1),
            SinOsc.ar(440, 0.2),
        ]
    )
}).add;
)

(
Synth("dataForABus");    // チャンネル0にノコギリ波をシンセサイズする
Synth("dataFromABus");    // それをチャンネル1のサイン波で変調する
)

////////////////////////////////////////////////////////////////////////////////////////////////////

さらに詳しくは、SuperColliderのヘルプ・システムでOutとInを参照して下さい。

////////////////////////////////////////////////////////////////////////////////////////////////////
