Pbindf

通过将键绑定到值，将多个值模式绑定到一个现有的事件流

FilterPattern : Pattern : AbstractFunction : Object

另请参阅：Pattern、Event、Pbind、Pchain

说明

Pbindf 将多个值流添加到现有的事件流中。每个值流被分配给结果事件流中的一个或多个键，覆盖来自输入流的任何值。

绑定到键的模式称为值模式，而 Pbindf 本身称为事件模式。

类方法

Pbindf.new(pattern ... pairs)

Pbindf 的参数是初始模式，后跟交替出现的键和模式序列。模式也可以绑定到一个键数组。在这种情况下，该模式必须指定一个序列，其元素是数组，且元素个数至少与键的数量相同。
