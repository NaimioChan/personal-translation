DelayL

带线性插值的简单延迟线。

DelayN : PureUGen : UGen : AbstractFunction : Object

另请参阅：DelayC、DelayN、BufDelayL

说明

使用线性插值的简单延迟线。另请参阅 DelayN（不使用插值）和 DelayC（使用三次插值）。三次插值的计算开销大于线性插值，但更精确。

术语“delay”在电子音乐中常用来指带反馈的延迟线。如果你要找的是那种，请尝试 CombL。

类方法

DelayL.ar(in: 0.0, maxdelaytime: 0.2, delaytime: 0.2, mul: 1.0, add: 0.0)

来自父类：DelayN

DelayL.kr(in: 0.0, maxdelaytime: 0.2, delaytime: 0.2, mul: 1.0, add: 0.0)

来自父类：DelayN

参数：

in

输入信号。

maxdelaytime

最大延迟时间，单位为秒。用于初始化延迟缓冲区大小。

delaytime

延迟时间，单位为秒。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

(
// Dust 随机触发 Decay，为 WhiteNoise 输入源
// 创建指数衰减包络
{
z = Decay.ar(Dust.ar(1, 0.5), 0.3, WhiteNoise.ar);
DelayL.ar(z, 0.2, 0.2, 1, z); // 输入通过 add 输入与延迟混合
}.play
)

(
// 递归应用 delay。
{
z = Decay2.ar(Dust.ar(1, 0.5), 0.01, 0.1, Saw.ar(100 + [0, 1]));
5.do { |i| z = DelayL.ar(RLPF.ar(z, Rand(100, 3000), 0.03), 1, 1 / (2**i), 1, z * 0.5) };
z
}.play
)
