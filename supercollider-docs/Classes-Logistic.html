Logistic

混沌噪声函数

UGen : AbstractFunction : Object

另请参见：Crackle、LatoocarfianN

说明

基于 logistic 映射的噪声发生器：

y = chaosParam * y * (1.0 - y)

类方法

Logistic.ar(chaosParam: 3.0, freq: 1000.0, init: 0.5, mul: 1.0, add: 0.0)

Logistic.kr(chaosParam: 3.0, freq: 1000.0, init: 0.5, mul: 1.0, add: 0.0)

参数：

chaosParam

混沌函数的一个参数，有用值范围为 0.0 到 4.0。混沌从 3.57 开始出现。如果你不想让 UGen 崩溃，请不要使用此范围之外的值。

freq

计算频率；如果超过采样率，则被钳制为采样率

init

上式中 y 的初始值

mul

输出将乘以该值。

add

此值将被添加到输出中。

讨论：

对于 chaosParam 的正常值，y 将保持在 0.0 到 1.0 的范围内。这会导致直流偏移，并在停止 Synth 时可能引起爆音。对于输出，你可能希望将此 UGen 与 LeakDC 组合，或通过 mul 和 add 在 0.0 附近重新缩放：请参阅下面的示例。

实例方法

示例

// 默认值
{ Logistic.ar }.play

// 混沌起始
{ Logistic.ar(Line.kr(3.55, 3.6, 5), 1000) }.play

// 通过 Mouse 探索
{ Logistic.ar(MouseX.kr(3, 3.99), MouseY.kr(10, 10000, 'exponential'), 0.25, 0.5) }.play
