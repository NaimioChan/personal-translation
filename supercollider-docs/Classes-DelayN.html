DelayN

无插值的简单延迟线。

PureUGen : UGen : AbstractFunction : Object

另请参见：Delay1、Delay2、DelayC、DelayL、BufDelayN

子类：DelayC、DelayL

说明

无插值的简单延迟线。另请参见使用线性插值的 DelayL，以及使用三次插值的 DelayC。

如果你调制延迟时间，此 UGen 将产生混叠伪影，延迟时间也会被量化到最近的采样周期。如果这些属性不可取，请使用 DelayL 或 DelayC。但如果你的延迟时间是固定的，且不需要亚采样精度，那么这是 CPU 效率最高的选择，且不会损失质量。

术语“delay”在电子音乐中常用来指带反馈的延迟线。如果你要找的是那种，请尝试 CombN。

类方法

DelayN.ar(in: 0.0, maxdelaytime: 0.2, delaytime: 0.2, mul: 1.0, add: 0.0)

DelayN.kr(in: 0.0, maxdelaytime: 0.2, delaytime: 0.2, mul: 1.0, add: 0.0)

参数：

in

输入信号。

maxdelaytime

最大延迟时间，单位为秒，用于初始化延迟缓冲区大小。

delaytime

延迟时间，单位为秒。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

(
// Dust 随机触发 Decay，为 WhiteNoise 输入源
// 创建指数衰减包络
{
z = Decay.ar(Dust.ar(1, 0.5), 0.3, WhiteNoise.ar);
DelayN.ar(z, 0.2, 0.2, 1, z); // 输入通过 add 输入与延迟混合
}.play
)

(
// 递归应用 delay。
{
z = Decay2.ar(Dust.ar(1, 0.5), 0.01, 0.1, Saw.ar(100 + [0, 1]));
5.do { |i| z = DelayN.ar(RLPF.ar(z, Rand(100, 3000), 0.03), 1, 1 / (2**i), 1, z * 0.5) };
z
}.play
)
