PageLayout

一个带有 FlowView 的 Window，用于 ObjectGui 的 MVC 模型

另请参见：ObjectGui, FlowView, Window, NotificationCenter

说明

此类封装了创建 Window、添加 FlowView（带有 FlowLayout 的 CompositeView）的常见任务。它还通过注册控制器来支持 MVC 模型，当 Window 关闭时这些控制器会被移除（发送 .remove 消息）。此外，它还可以调整自身大小以适应内容。

类方法

.new

创建一个带有 FlowView 的 Window。PageLayout 对象可以像 Window 或像 View 一样使用。

参数：

title

窗口标题

bounds

边界或 nil。默认值 nil 会将窗口调整为整个屏幕大小。使用 .resizeToFit 将窗口缩小到内容大小。

margin

FlowLayout 边距。

background

背景颜色

scroll

布尔值：是否添加滚动条。

front

boolean：是否立即显示窗口并将其置于最前。默认为 true。你也可以选择先将视图添加到窗口，然后再将其置前，这对于大型且缓慢的 GUI 很有用

返回值：

一个 PageLayout

.removeOnClose

注册一个对象，通常是 ObjectGui 的子类或一个 Updater，以便当 Window 关闭时，将向其发送 .remove 消息。这将导致该对象释放其对 Model 的依赖。这意味着 ObjectGui（或其他控制器对象）将停止接收更新消息，并停止尝试更新刚刚随 Window 一起关闭的 View。这还意味着，如果不存在指向 Model 的链接，且不再有任何持有指向控制器对象的链接的 View，那么该控制器现在不再被引用，并将被垃圾回收。

参数：

dependant

关闭窗口时希望被发送 .remove 的对象

返回值：

self

.resizeToFit

调整顶层 FlowView 的尺寸以适合其内容，然后调整 Window 的尺寸以适合该 FlowView。

参数：

reflow

布尔值：FlowView 可以在边界已更改或视图已被移除的情况下重新布局其所有子视图。这会针对更新后的边界将它们逐一放回原位。因此，这可能导致整体边界变小，之后窗口会被缩小。

center

布尔值：调整大小后，将窗口重新居中到屏幕。

返回值：

self
