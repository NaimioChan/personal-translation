Layout

所有 GUI 布局的父类

另请参见：HLayout、VLayout、GridLayout、StackLayout、Layout Management

说明

Layout 是所有布局的抽象父类。任何布局都可以通过视图的 'layout' 设置方法安装到视图上。关于所有布局共同的操作细节，请参见 Layout Management。

类方法

实例方法

.spacing

托管视图之间留下的空白像素量。

参数：

spacing

一个表示以像素为单位的间距的整数。

.margins

父视图边缘与被管理子视图之间留下的空白像素量。

参数：

margins

一个包含四个整数的数组，按以下顺序定义边距：左边距、上边距、右边距、下边距；或一个包含两个整数的数组，分别应用于左/右边距和上/下边距；或一个单个整数应用于所有边距。

示例

w = Window.new;
w.layout = HLayout(TextView().string_("One"), TextView().string_("Two"));
w.layout.spacing = 20;
w.layout.margins = [10, 30, 10, 30];
w.front;
