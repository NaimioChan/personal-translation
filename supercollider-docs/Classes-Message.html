Message

发送给对象的消息

Object

参见：MethodQuote

说明

发送给对象的消息，稍后求值。

类方法

Message.new(receiver, selector, args)

参数：

receiver

消息的接收者

selector

要调用的方法

args

调用的参数

实例方法

.receiver

.receiver = value

消息转发到的对象

.selector

.selector = value

要调用的方法

.args

.args = value

调用的参数

.value( ... moreArgs)

将该消息发送给接收者，并用这些参数调用选择器

参数：

... moreArgs

示例

// 一个对象
a = 36


// 发送给对象的消息
m = Message(a, \sqrt)

// 投递消息
m.value
// -> 6

// 一条缺少参数的消息
m = Message(a, '+')

// 用参数求值
m.value(6)
// -> 42

m.value(-13)
// -> 23
