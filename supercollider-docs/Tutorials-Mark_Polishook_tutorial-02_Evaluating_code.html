本文档在键位命令方面是 macOS（SCapp）特有的，不过其原理适用于所有平台。关于其他编辑器中的键位命令，请参阅帮助文件 Keyboard Shortcuts。

合成声音

要运行（求值）一行代码，例如

{ SinOsc.ar([400, 401], 0, 0.1) * Saw.ar([11, 33], 1) * EnvGen.kr(Env.sine(10)) }.play

首先确保 localhost 服务器已启动。然后将光标放在该行（如上所示）的任意位置并按 <enter>。如果你没有 enter 键，则可以使用 ctrl-Return、Ctrl-c、fn-Return（在某些 Mac 上）或 Shift-Return。服务器将合成音频以及类似下面这样的文本

Synth("-613784702" : 1000)

将出现在 post 窗口中。

按 command-period（cmd-.）停止合成。

////////////////////////////////////////////////////////////////////////////////////////////////////

要运行多行代码，请选中所有行并按 <enter>。

为便于选择，包含多行的示例通常被放在一对括号中。在这种情况下，可单击顶部括号的右侧或底部括号的左侧来选择文本。或者，将光标置于顶部括号右侧或底部括号左侧，然后按 cmd-shift-b。

然后按回车键（运行示例）。

(
{
    RLPF.ar(
        in: Saw.ar([100, 102], 0.15),
        freq: Lag.kr(LFNoise0.kr(4, 700, 1100), 0.1),
        rq: 0.05
    )
}.play
)

服务器将合成音频和文本，大致如下所示

Synth("-393573063" : 1000)

将出现在 post 窗口中。

按 command-period（cmd-.）停止合成。

示波声音

要示波显示你正在合成的任何内容（创建波形的图形显示）：

  1. 确保服务器正在运行（按下启动按钮）

  2. 如上所述评估你的代码。

    例如，运行

    { SinOsc.ar([400, 401], 0, 0.5) * Saw.ar([11, 33], 0.5) }.play

  3. 然后求值

    s.scope(2)

    这将产生一个标题为 "stethoscope" 的窗口。

作为步骤 2 到 4 的快捷方式，直接将 scope 消息发送给示例。

{ SinOsc.ar([400, 401], 0, 0.5) * Saw.ar([11, 33], 0.5) }.scope(2)

按 cmd-. 停止声音合成。

录制声音

localhost 和内部服务器窗口的最右侧都有按钮，用于激活录音。要录音，请选择一个默认服务器。你所选默认服务器上的按钮最初会显示“record”，按下它即可开始录音。

运行以下代码行以查看你的声音文件保存到了哪里……

thisProcess.platform.recordingsDir;
