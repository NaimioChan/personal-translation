Monitor

总线之间的连接

Object

另请参见：playN、NodeProxy、Bus

说明

一个用于在总线之间进行监视或交叉链接的通用类。它支持多通道扩展以及设置之间的交叉淡化。它为将连续通道播放到其他连续总线（-play）以及更复杂的路由（例如拆分、散布等到多个通道（-playN））提供了优化。Monitor 使用现有的 SystemSynthDefs 集合来完成此操作。

{ Out.ar(87, SinOsc.ar(MouseX.kr(240, 1000, 1) * [1, 2, 3], 0, 0.2)) }.play; // 在通道 87、88 和 89 上播放三个正弦音
x = Monitor.new; // 创建一个新的监视器
x.play(fromIndex: 87, fromNumChannels: 3, toIndex: 0, toNumChannels: 2); // 将它们回放到立体声硬件声道

类方法

实例方法

.play(fromIndex, fromNumChannels: 2, toIndex, toNumChannels, target, multi: false, volume, fadeTime, addAction)

从具有若干通道的总线索引播放到另一个具有若干通道的索引，在目标组或服务器内。

参数：

fromIndex

要读取的总线索引

fromNumChannels

要读取的声道数。

toIndex

要写入的总线索引。

toNumChannels

要写入的通道数。如果此数字大于或小于 fromNumChannels，则环绕。如果没有给出，则使用 fromNumChannels。

target

将 Synth 发送到哪里（默认：server 默认组）

multi

保留旧的链接并添加新的链接：这允许你一层层地添加，否则会释放之前的映射（默认为 false）。

volume

监听时的音量

fadeTime

指定淡入和淡出时间

addAction

相对于目标放置监视器组的位置。

s.boot;
s.scope(16);

{ Out.ar(87, SinOsc.ar(MouseX.kr(40, 10000, 1) * [1, 2, 3], 0, 0.2)) }.play;
x = Monitor.new;
x.play(87, 3, 1, 2);
x.out = 0;
x.stop(3.0);
x.play(87, 1, 0, 1); // in > out : 现在向下混合（环绕）
x.play(89, 1, 0, 2); // in < out：现在分配到 2 个声道
x.stop;

// 多次播放
x.play(87, 1, 0, 2, multi: true);
x.play(88, 1, 0, 2, multi: true);
x.play(89, 1, 0, 2, multi: true);
x.stop;

.playN(out, amp, in, vol, fadeTime, target, addAction, multi: false)

从一个总线索引数组播放到另一个总线索引数组，带有幅度数组，位于目标组或服务器内。

注意： 参数 out、amp 和 in 可以是嵌套数组。另请参见 playN。三个参数 out、amp 和 in 如果大小不同将会循环环绕，如下所示：[[0, 1], [0.1], [3, 4, 5]].flop

参数：

out

目标声道数组。

amp

每个通道的振幅数组

in

源声道数组

vol

振幅的全局缩放值

fadeTime

指定淡入和淡出时间

target

在哪里播放（默认：服务器默认组）

addAction

相对于目标放置监视器组的位置。

multi

保留旧链接并添加新链接：这允许你逐层添加，否则会释放之前的映射（默认为 false）。

// 示例：参数为 // outs, amps, ins, vol, fadeTime

{ Out.ar(87, SinOsc.ar(MouseX.kr(40, 10000, 1) * [1, 2, 3], 0, 0.2)) }.play;
x = Monitor.new;

(
x.playN(
    [0, 1, 4],             // 输出到这些输出
    [0.1, 0.4, 0.3],     // 使用这些音量
    [87, 88, 89]        // 来自这些输入
);
)
(
x.playN(
    [0, [1, 3, 2], 4],         // outs can be nested: 87 -> 0, 88 -> [1, 3, 2], 89 -> 4
    [0.1, [0.4, 0.2, 0.1], 0.3],    // with nested volumes 0.1, [0.4, 0.2, 0.1], and 0.3
    [87, 88, 89]);             // 从这些输入读取
)
// 还可以设置全局音量和淡入淡出时间
x.playN(vol: 0.0, fadeTime: 4);

.stop(argFadeTime)

在 fadeTime 内停止。

注意： 这会保留所有设置，因此下次使用 play 时，它将以相同的配置播放，仅覆盖所提供的值。

{ Out.ar(87, SinOsc.ar(MouseX.kr(340, 1000, 1) * [1, 2, 3], 0, 0.2)) }.play;
x = Monitor.new.play(87, 3, 0, fadeTime: 3);
x.stop;
x.play;

参数：

argFadeTime

使所有路由 synth 淡出的时间。

.clear(argFadeTime)

在 fadeTime 内停止。

注意： 与 stop 不同，这会移除所有设置。

.vol

.vol = val

设置音量。

{ Out.ar(87, SinOsc.ar(MouseX.kr(340, 1000, 1) * [1, 2, 3], 0, 0.2)) }.play;
x = Monitor.new.play(87, 3, 0, fadeTime: 3);
x.vol = 0.3;
x.stop;

.out

.out = index

设置或获取第一个输出索引。

.outs

.outs = indices

设置或获取输出总线索引数组。

.ins

设置或获取输入总线索引的数组。

.amps

.amps = values

设置振幅数组。

.fadeTimes

.fadeTimes = values

设置或获取 fadeTimes 数组。

.fadeTime

.fadeTime = val

为下一次过渡（可能是停止或新的播放）设置单个 fadeTime。

.isPlaying

如果组仍在播放，则返回 true。

.group

返回所有映射 Synth 运行所在的组。

.numChannels

返回输入通道的数量。

.copy

返回接收者的一个副本，具有相同的通道设置，但不运行。你可以通过向它发送 -play 消息使用这些设置来运行它，并传入你想要的任何修改。

.playToBundle(bundle, fromIndex, fromNumChannels, toIndex, toNumChannels, inGroup, multi: false, volume, argFadeTime, addAction)

将所有正在播放的 osc 消息添加到一个 bundle 中，该 bundle 作为参数传入。bundle 对象应实现 .add 方法。
