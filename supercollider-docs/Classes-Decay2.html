Decay2

指数衰减

Filter : PureUGen : UGen : AbstractFunction : Object

另请参阅：Decay、Integrator

说明

与 Decay 类似的积分滤波器，但起始时间和衰减时间均可指定。

Decay2.ar(in, attackTime, decayTime)

等价于：

Decay.ar(in, decayTime) - Decay.ar(in, attackTime)

要精确控制 Decay2 的起音、衰减和电平，请参见下面的 Onset control and normalizing the envelope of Decay2 和 Calculating rise time and maximum rise time of Decay2。

类方法

Decay2.ar(in: 0.0, attackTime: 0.01, decayTime: 1.0, mul: 1.0, add: 0.0)

Decay2.kr(in: 0.0, attackTime: 0.01, decayTime: 1.0, mul: 1.0, add: 0.0)

参数：

in

输入信号。

attackTime

60 dB 起音时间，单位为秒。

decayTime

以秒为单位的 60 dB 衰减时间。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

// 用作包络
play{ Decay2.ar(Impulse.ar(XLine.kr(1,50,20), 0.25), 0.01, 0.2, FSinOsc.ar(600)) };
// 与 Decay 比较
play{ Decay.ar(Impulse.ar(XLine.kr(1,50,20), 0.25), 0.2, FSinOsc.ar(600), 0) };

由于 Decay2 等价于两个 Decay 的差值，交换 attackTime 和 decayTime 会反转包络：

(
plot({
    var attack = 0.001, decay = 0.01;
    var imp = Impulse.ar(0);
    [
        Decay2.ar(imp, attack, decay),
        Decay2.ar(imp, decay, attack)
    ]
}, duration: 0.01).superpose_(true)
)

Decay2 的起始控制与包络归一化

将 Decay2 参数化以使其峰值为 1.0，并能够控制何时达到峰值，这可能很有用。以下示例对 Decay2 的包络进行归一化，并提供一个参数 riseScale，用于将起始点提前或延后。

riseScale 值为 0.0 时，起音时间仅为一个采样，非常尖锐，几乎等同于 Decay。值略小于 1.0（不能等于 1.0）时，将生成尽可能晚的起音时间，约为 decayTime 的 15%。

(
var t60, riseScale, riseFac, normFac;

// 近似 60 dB 衰减时间
// （实际 t60 会随 riseScale 增加）
t60 = 0.01;

// 缩放上升时间（< 1.0）
riseScale = 0.1;

// 计算归一化因子
riseFac = riseScale / (2 - riseScale);
normFac = riseFac.pow(riseFac / (riseFac - 1)) / (1 - riseFac);

// 绘制并与 Decay 比较
plot({
    var imp = Impulse.ar(0);
    [
        Decay.ar(imp, t60),
        Decay2.ar(imp,
            attackTime: t60 * riseFac,
            decayTime: t60,
            mul: normFac
        )
    ]
}, duration: t60)
.plotColor_([Color.blue, Color.red])
.superpose_(true)
)

在上一示例中，请注意 t60 是“近似”的，因为虽然衰减的速率会收敛到相应衰减时间的速率，但随着 riseScale 增大，冲激响应实际衰减到 -60 dB 的时间会延迟。在分贝刻度上观察冲激响应时，随着 riseScale 值增大，这一现象会变得明显。

(
var t60, riseScale, riseFac, normFac;

t60 = 0.01;
riseScale = [0.0, 0.2, 0.5, 0.9];
riseFac = riseScale / (2 - riseScale);
normFac = riseFac.pow(riseFac / (riseFac - 1)) / (1 - riseFac);

// 以 dB 绘制以检查衰减时间
plot(
    {
        Decay2.ar(Impulse.ar(0),
            attackTime: t60 * riseFac,
            decayTime: t60,
            mul: normFac
        ).ampdb.max(-120) // 转为 dB，截断 -inf
    },
    duration: t60, minval: -60
).superpose_(true)
.axisLabelY_("dB")
.axisLabelX_("Time (s)")
)

计算 Decay2 的上升时间和最大上升时间

可能的最长上升时间被限制为 decayTime 的约 15%。此最大上升时间，以及给定 riseScale 因子时的精确上升时间，可计算如下：

(
var t60, riseScale, riseFac, riseTime, maxRiseTime;

t60 = 0.3; // 衰减时间
riseScale = 0.1;

riseFac = riseScale / (2 - riseScale);
maxRiseTime = t60 * 60.dbamp.log.reciprocal;
riseTime = maxRiseTime * (riseFac * riseFac.log) / (riseFac - 1);

postf(
    "For decayTime = % sec, the max possible rise time is % sec.\n"
    "When riseScale = %, the rise time is % sec.\n",
    *round([t60, maxRiseTime, riseScale, riseTime], 0.001)
);""
)
