Ringz

振铃滤波器。

Filter : PureUGen : UGen : AbstractFunction : Object

另请参阅：Formlet、RHPF、RLPF、Resonz

说明

这与 Resonz 相同，区别在于它是恒定裙边增益滤波器，这意味着峰值增益取决于 Q 的值。此外，与 Resonz 中的共振参数不同，带宽以 60dB 环形衰减时间来指定。一个 Ringz 等效于 Klank UGen 的一个分量。

类方法

Ringz.ar(in: 0.0, freq: 440.0, decaytime: 1.0, mul: 1.0, add: 0.0)

Ringz.kr(in: 0.0, freq: 440.0, decaytime: 1.0, mul: 1.0, add: 0.0)

参数：

in

输入信号。

freq

以赫兹为单位的共振频率。

decaytime

滤波器的 60 dB 衰减时间。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

{ Ringz.ar(Dust.ar(3, 0.3), 2000, 2) }.play

{ Ringz.ar(WhiteNoise.ar(0.005), 2000, 0.5) }.play

// 调制频率
{ Ringz.ar(WhiteNoise.ar(0.005), XLine.kr(100, 3000, 10), 0.5) }.play

{ Ringz.ar(Impulse.ar(6, 0, 0.3), XLine.kr(100, 3000, 10), 0.5) }.play

// 调制环形时间
{ Ringz.ar(Impulse.ar(6, 0, 0.3), 2000, XLine.kr(4, 0.04, 8)) }.play

// 以相反方向调制环形时间
{ Ringz.ar(Impulse.ar(6, 0, 0.3), 2000, XLine.kr(0.04, 4, 8)) }.play

(
{
    var exciter;
    exciter = WhiteNoise.ar(0.001);
    Mix.arFill(10, {
        Ringz.ar(exciter,
        XLine.kr(exprand(100.0, 5000.0), exprand(100.0, 5000.0), 20),
        0.5)
    })
}.play
)

与采样率的交互

Ringz（以及基于它的 UGen：Klank、DynKlank 和 Formlet）对于输入端的脉冲是“采样率无关”的。也就是说，给定单采样脉冲，不同采样率下的输出信号应具有相同的频率和幅度。

此设计有一个副作用：如果输入不是由脉冲组成，输出幅度将与采样率成正比。

(
a = {
    // 矩形脉冲激励器（确定性输入）
    var exc = EnvGen.ar(Env([1, 1, 0], [0.01, 0], \lin)),
    sig = Ringz.ar(exc, 440, decaytime: 0.2),
    rms = sqrt(Integrator.ar(sig.squared) * (0.2 / SampleRate.ir)),
    end = DetectSilence.ar(sig, doneAction: 2);
    rms.poll(end);
    Silent.ar(1)
}.play;
)

在 44.1 kHz 下，这会打印出 RMS 振幅 1.0758。在 88.2 kHz 下，振幅翻倍。

模态合成（模拟被敲击表面的振动模式）将短促、衰减的噪声突发馈入 Ringz 风格的谐振器。这是一个常见的用例，确实受此振幅效果影响。

如果你需要结果在不同采样率下保持兼容，请确保适当地缩放音量：如果 sig 是 Ringz、Klank 或 Formlet 信号，请使用 sig * (originalSampleRate / SampleRate.ir)，并在 originalSampleRate 的位置替换为正确的值。
