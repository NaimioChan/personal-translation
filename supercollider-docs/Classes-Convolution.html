Convolution

实时卷积器。

UGen : AbstractFunction : Object

另见：Convolution2、Convolution2L、Convolution3

说明

两个连续变化输入的严格卷积。另请参阅 Convolution2，它对于可通过触发消息更改的固定内核情况是一种 CPU 成本更低的替代方案。

另请参见 Steven W. Smith 的 http://www.dspguide.com/ch18.htm。

类方法

Convolution.ar(in, kernel, framesize: 512, mul: 1.0, add: 0.0)

参数：

in

处理目标。

kernel

处理内核。

framesize

FFT 帧的大小，必须是 2 的幂（512、1024、2048、4096 是常用选择）。卷积在内部使用该数值的两倍。请注意，随着幂次提高，卷积的运行开销会逐渐增大！可用的最大值为 2^16 = 16384。（此上限是 SC 源代码中定义的 "SC_FFT_MAXSIZE" 的一半。）比这更大的卷积可以使用 PartConv 完成。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

(

{
    var input, kernel;

    input = SoundIn.ar(0);
    kernel = Mix.ar(LFSaw.ar([300, 500, 800, 1000] * MouseX.kr(1.0, 2.0), 0, 1.0));

    // 帧大小必须是 2 的幂
    Convolution.ar(input, kernel, 1024, 0.5)
}.play;

)

(
// 帧大小必须是 2 的幂——Convolution 会将 FFT 大小调整为该值的两倍
// 目前最大为 a = 8192，对应 FFT 大小 16384

a = 2048;
s = Server.local;

// 内核缓冲区
g = Buffer.alloc(s, a, 1);
)

(

// 随机脉冲响应

g.set(0, 1.0);

100.do({ |i| g.set(a.rand, 1.0.rand) });


{
    var input, kernel;

    input = SoundIn.ar(0);
    kernel = PlayBuf.ar(1, g.bufnum, BufRateScale.kr(g.bufnum), 1, 0, 1);

    Convolution.ar(input, kernel, 2 * a, 0.5)
}.play;

)
