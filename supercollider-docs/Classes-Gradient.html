Gradient

两种颜色之间的线性颜色渐变

参见：Color、HiliteGradient

说明

注意： 尚不支持使用 Gradient。当使用 Gradient 代替 Color 时，将改为使用渐变的平均颜色。

类方法

.new

参数：

color1

一个 Color 的实例。

color2

一个 Color 的实例。

direction

\h 或 \v，分别表示水平和垂直。默认值为 \h。

steps

渐变的精度。默认值为 64。

实例方法

.at

获取位置 pos 处的颜色，通常为 0 到 1 之间的值。at(0) 为 color1，at(1) 为 color2。

参数：

pos

示例

// 基本用法
(
w = Window.new.front;
w.view.background = Gradient(Color.yellow, Color.white);
)

// 更改方向和分辨率
(
w = Window.new.front;
w.view.background = Gradient(Color.red, Color.white, \v, 5);
)

// 几乎察觉不到的变化也可以很悦耳
(
w = Window.new.front;
v = CompositeView(w, Rect(50, 50, 300, 300));
c = Color.rand;
d = c.vary(0.15);
v.background = Gradient(c, d, \v);
[c, d].postln
)

(
var w, k, c, d, e, c1, c2, f, g;
w = Window.new.front;
k = Slider2D(w, Rect(50, 50, 300, 300));
f = {
    c = Color.rand;
    d = c.vary(0.5);
    e = d.vary(0.5);
};
g = {
    c1 = d.hueBlend(e, k.y).round(0.01);
    c2 = c.hueBlend(e, k.x).round(0.01);
    k.background = Gradient(c1, c2, \v)
};
f.value; g.value;
k.action = g;
k.mouseUpAction = { [c1, c2].postln };
k.keyDownAction = f; // 按键获取新颜色
)

// 一个间接使用 gradient 来更新窗口颜色的示例
(
w = Window.new.front;
g = Gradient(Color.red, Color.green);
Task{
    (0, 0.01 .. 1).do{ |pos|
        w.view.background = g.at(pos);
        0.01.wait;
    };
}.play(AppClock)
)
