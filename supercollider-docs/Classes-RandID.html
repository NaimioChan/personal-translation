RandID

设置该 synth 的随机生成器 ID。

WidthFirstUGen : UGen : AbstractFunction : Object

参见：RandSeed

说明

选择此 synth 使用的随机数生成器。所有使用同一生成器的 synth 在再次设置相同种子时会重现相同的数字序列。

类方法

RandID.kr(id: 0)

RandID.ir(id: 0)

参数：

id

随机数生成器 ID。

实例方法

示例

// 启动一个噪声 patch 并设置生成器的 id
(
SynthDef("help-RandID", { |out = 0, id = 1|
    RandID.ir(id);
    Out.ar(out,
        WhiteNoise.ar(0.05) + Dust2.ar(70)
    )
}).add;
)

// 以可变速率重置我的 rgen 的种子
(
SynthDef("help-RandSeed", { |seed = 1910, id = 1|
        RandID.kr(id);
        RandSeed.kr(Impulse.kr(FSinOsc.kr(0.2, 0, 10, 11)), seed);
}).add;

)

// 在左右声道上启动两个噪声合成器，使用不同的 randgen id
a = Synth("help-RandID", [\out, 0, \id, 1]);
b = Synth("help-RandID", [\out, 1, \id, 2]);

// 重置 randgen 1 的种子
x = Synth("help-RandSeed", [\id, 1]);

// 将目标 randgen 更改为 2（影响右声道）
x.set(\id, 2);
