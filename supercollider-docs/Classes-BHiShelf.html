BHiShelf

Hi Shelf

BEQSuite : Filter : PureUGen : UGen : AbstractFunction : Object

另请参阅：SOS、BLowPass、BLowPass4、BHiPass、BHiPass4、BPeakEQ、BLowShelf、BBandPass、BBandStop、BAllPass

说明

B 均衡套件基于二阶节（SOS）双二阶 UGen。

注意： Biquad 系数计算会带来一定的 CPU 开销。这些插件 UGen 包含优化，使得只有当滤波器参数之一发生变化时才会更新系数。这可能导致 CPU 性能出现尖峰，在使用多个此类单元时应加以考虑。

类方法

BHiShelf.ar(in, freq: 1200.0, rs: 1.0, db: 0.0, mul: 1.0, add: 0.0)

参数：

in

待处理的输入信号。

freq

警告：由于其实现方式的特性，接近 0 的频率值可能导致故障和/或极其响亮的音频伪影！中心频率。

rs

S 的倒数。搁架提升/衰减斜率。当 S = 1 时，搁架斜率尽可能陡，同时在整个频率范围内保持增益单调递增或递减。对于固定的 freq/SampleRate.ir 和 db，以 dB/倍频程为单位的搁架斜率在所有其他 S 值下保持与 S 成正比。

db

增益。以 dB 为单位提升/削减中心频率。

mul

add

未文档化的类方法

BHiShelf.sc(dummy, freq: 120.0, rs: 1.0, db: 0.0)

实例方法

示例

s.boot;
(
z = { // 随意调整增强/削减
BHiShelf.ar(
    SoundIn.ar([0, 1]),
    MouseX.kr(2200, 18000, \exponential),
    1.0, // rs
    MouseY.kr(18.0, -18.0, \linear),
    0.5); // mul
}.play)
z.release;

(
z = { // 玩弄 rs
BHiShelf.ar(
    SoundIn.ar([0, 1]),
    MouseX.kr(2200, 18000, \exponential),
    MouseY.kr(0.1, 1.0, \linear), // rs
    6, // db
    0.5); // mul
}.play)
z.release;
