Lag2UD

指数滞后

LagUD : Filter : PureUGen : UGen : AbstractFunction : Object

参见：Lag、Lag2、Lag3、LagUD、Lag3UD

说明

Lag2 等价于 Lag.kr(Lag.kr(in, time), time)，因此过渡更加平滑。这节省了 CPU，因为你只需计算一次衰减因子而不是两次。更多细节参见 Lag。

类方法

Lag2UD.ar(in: 0.0, lagTimeU: 0.1, lagTimeD: 0.1, mul: 1.0, add: 0.0)

来自父类：LagUD

Lag2UD.kr(in: 0.0, lagTimeU: 0.1, lagTimeD: 0.1, mul: 1.0, add: 0.0)

来自父类：LagUD

参数：

in

输入信号。

lagTimeU

上升信号的 60 dB 滞后时间，单位为秒。

lagTimeD

下降信号的 60 dB 滞后时间（以秒为单位）。

实例方法

示例

// 用于滞后音高
(
SynthDef(\lag2ud_help, { |out, freq = 300, lagup = 1, lagdown = 5|
    Out.ar(out,
        SinOsc.ar( // 正弦波
            Lag2UD.kr( // 滞后频率
                freq,
                lagup,
                lagdown
            ),
            0, // phase
            0.2 // 正弦振幅
        )
    );
}).add;
)

x = Synth(\lag2ud_help); // 创建合成器

x.set(\freq, 500); // 将频率设为更高的值（耗时 1 秒）
x.set(\freq, 100); // 将频率设为更低的值（耗时 5 秒）
x.free;
