GrayNoise

位翻转噪声

WhiteNoise : UGen : AbstractFunction : Object

参见：BrownNoise、ClipNoise、PinkNoise、WhiteNoise

说明

产生由字中随机比特翻转所导致的噪声。1

这种噪声的 RMS 电平相对于其峰峰值较高。频谱偏向较低频率。

灰噪声没有像粉红噪声和白噪声那样的标准定义。虽然 GrayNoise 生成比特翻转噪声，但“grey/gray noise”一词也可能指按照感知等响度曲线整形的噪声。2

类方法

GrayNoise.ar(mul: 1.0, add: 0.0)

来自父类：WhiteNoise

GrayNoise.kr(mul: 1.0, add: 0.0)

来自父类：WhiteNoise

参数：

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

(
SynthDef("help-GrayNoise", { |out = 0|
    Out.ar(out,
        GrayNoise.ar(-20.dbamp)
    )
}).play;
)

[1] - 通过 X_0 = 1; X_{n+1} = X_n ⊕ z 生成，其中 ⊕ 是按位异或，z 是一个恰好含有一个非零位的 32 位二进制数；该非零位的位置是一个均匀随机变量。

[2] - 参见 Joseph Wisniewski 1996 年的 usenet 消息，它似乎为维基百科上关于 Grey noise 和 Colors of noise 的文章提供了信息。请注意，比特翻转版本的 gray noise 在对此 usenet 消息的回复中被提及。
