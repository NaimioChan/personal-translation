3.5 版本新特性

SC 3.5 新闻摘要

语言端新闻

Qt GUI

一个新的跨平台 GUI 工具包，旨在取代 Cocoa 并作为 SwingOSC 的替代方案。更多信息请参阅 What's new in Qt GUI。

SCDoc

新的帮助系统提供一致的文档、良好的内省能力以及简便的搜索和浏览。

帮助文件用一种标记语言编写，该语言随后被解析并用于生成 HTML 文件，这些文件通过新的 WebView 部件在 HelpBrowser 中显示。

参见 SCDoc、SCDoc Syntax、Writing Help。

此外还有一个新方法 Help: *methodArgs，返回方法参数及默认值的可读字符串。示例：Help.methodArgs("SinOsc.ar")

在 SuperCollider 3.5.2 版本中，SCDoc 已被重写，解析器现在用 C++ 实现，以提高速度和稳定性。语法变得更加严格，如果文档中有错误，它会抛出错误或警告。参见 Writing Help: News in SC 3.5.2 了解一些需要牢记的重要变更。

OSC 与 MIDI 响应器

新的 OSCFunc 和 MIDIFunc 为旧的 OSCresponderNode 和 NoteOnResponder 等提供了更好的替代方案。

OSCFunc 可以在任意端口接收，而不仅是主 NetAddr.langPort。

启动文件的新位置

sclang 启动文件已移至 Platform.userConfigDir +/+ "startup.scd"。旧的平台特定启动文件位置已被弃用。新的启动文件为纯文本，不支持 rtf。

语言配置文件

仅限 Linux 的库配置文件已被弃用。它被一个跨平台的语言配置文件所取代，该文件位于 Platform.userConfigDir +/+ "sclang_conf.yaml"。可通过 LanguageConfig 类对其进行配置。

Sced3

GEdit 插件 sced 已更新以支持 GEdit 版本 3。

WiiMote

WiiMote.discover 现在会返回设备对象，失败时返回 nil。

模式中的 Bus-asMap

现在允许在模式中的 \freq 及类似项中使用 Bus-asMap 符号。

对类库覆盖发出警告

当扩展覆盖主类库中的方法时会发布警告，除非这些扩展被放在名为“SystemOverwrites”的子文件夹中。

文件系统工具

新的跨平台文件系统实用工具：File: *copy、File: *mtime、File: *mkdir、File: *realpath、File: *type、File: *fileSize

String-openTextFile

String: -openTextFile 现在也可在无 Document 支持的前端上使用。它会回退到 String: -openOS，以使用该文件类型的默认应用程序打开文件。

可选的尾随逗号

数组中的尾随逗号早已被允许：[1,2,3,]，但现在在 Event 构造和消息参数中也允许使用：

(a:1, b:2, c:3,);

Pbind(
    \foo, 1,
    \bar, 2,
);

myFunc.value(1, 2, 3,);

各类错误修复

许多 bug 已被修复，例如：String 正则表达式原语、SequenceableCollection 的多通道包装器、CoinGate.ar、T2K、WiiMote、SynthDesc。

解释器性能改进

sclang 现在使用 token threading1，而不是用一个巨大的 switch 语句来进行字节码分发。

PriorityQueue 稳定顺序

PriorityQueue 现在提供稳定的堆顺序：相同时间值的项将具有 FIFO 顺序。

绘图改进

plot 已改为使用 Plotter 类，该类此前由 plot2 方法使用。plot2 已被弃用，旧行为仍可通过 plotOld 方法获得，但这些方法同样已被弃用。

UI 已弃用

UI 类已被弃用。其功能现由 ShutDown 和 OnError 类提供。

Panner 和 XFade 类已弃用

内部使用的 Panner 和 XFade 类现已弃用。UGen 最好显式实现 checkInputs。

DIRECTORY 之外的 Quark 文件

现在允许 *.quark 文件位于 quark 本身内部，而不是在 DIRECTORY 中。这使得手动安装的 quark 可以轻松地由 Quarks: *gui 管理

新错误标记

错误消息中的错误标记现在改用 ^^^ 字符加下划线，而不再使用非跨平台的圆点字符（•）。

例如，代码 [a, %%&&**, b] 的结果为：

  line 1 char 10:

  [a, %%&&**, b]
      ^^^^^^

服务器端新闻

按位运算

按位运算符 &（and）、|（or）、xor:（xor）、<<（左移）和 >>（右移）现在在服务器端的音频和控制信号上受支持。示例：

// 8 位魔法
(
play {
    var t = PulseCount.ar(Impulse.ar(8e3));
    HPF.ar(
        (
            ((t * 15) & (t >> 5)) |
            ((t * 5)  & (t >> [3, 4])) |
            ((t * 2)  & (t >> 9)) |
            ((t * 8)  & (t >> 11))
            - 3 % 256
        ) / 127-1 * 3
        , 20
    ).tanh
}
)

VarLag UGen

新的 VarLag UGen 提供与 Lag 相同的功能，但支持线性及其他曲线。

DelTapWr/DelTapRd UGen

新的 DelTapRd 和 DelTapWr UGen 可用于轻松实现多抽头延迟。

Node-onFree

新增方法 Node: -onFree，在节点播放完成时运行一个函数。

LocalIn 初始值

LocalIn 现在有一个用于初始值的输入。

释放时关闭缓冲区

/b_free 如果声音文件已打开也会释放它（如同 /b_close）

更多完成标志

Demand、VDiskIn 和 DiskIn 现在会设置 done 标志（供 Done 或 FreeSelfWhenDone 使用）

共享内存服务器接口

引入了与服务器之间的共享内存接口。这使得本地客户端可以进行示波显示并同步访问控制总线。

HPF/RHPF 内部精度

HPF 和 RHPF 的递归滤波器环路已改为双精度，以避免量化噪声。依赖该量化噪声的作品可以使用 sc3-plugins 中提供的 GlitchUGens，它们实现了旧的行为。

插件入口点

插件应使用 PluginLoad 宏作为入口点，而不是实现 load 函数。这样可以进行 ABI 版本检查，并确保入口点函数从共享库中正确导出。详情请参阅 Writing Unit Generators。

新 FFT 插件 API

引入了面向服务器插件的新 FFT API：这简化了以跨平台方式编写 FFT UGen 的工作，因为不再需要外部 FFT 库。

Supernova

scsynth 的多处理器实现。合成图的并行性通过 ParGroup 类暴露给用户。Supernova 目前仅支持 Linux。macOS/Windows 二进制版本中不提供。要在 ParGroup 内播放模式，可以使用 PparGroup。Scsynth 用组来模拟并行组。

插件必须经过修改，在访问总线或缓冲区时获取自旋锁。详情见 Writing Unit Generators。
