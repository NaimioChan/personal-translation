K2A

控制速率到音频速率转换器。

PureUGen : UGen : AbstractFunction : Object

参见：A2K

子类：T2A

说明

为了能够将控制率 UGen 播放到音频率 UGen 中，有时必须转换速率。K2A 通过线性插值进行转换。

类方法

K2A.ar(in: 0.0)

参数：

in

输入信号。

实例方法

示例

{ K2A.ar(WhiteNoise.kr(0.3)) }.scope;


// 比较：
(
{
    [
        K2A.ar(WhiteNoise.kr(0.3)),
        WhiteNoise.ar(0.3)
    ]
}.scope;
)

(
{
    var freq, blockSize, sampleRate;
    blockSize = s.options.blockSize; // 通常为 64
    sampleRate = s.sampleRate;
    freq = MouseX.kr(0.1, 40, 1) / blockSize * sampleRate;
    [
        K2A.ar(LFNoise0.kr(freq)),
        LFNoise0.ar(freq)
    ] * 0.3
}.scope;
)
