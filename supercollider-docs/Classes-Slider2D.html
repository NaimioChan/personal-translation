Slider2D

带有可在两个维度上移动的手柄的视图。

说明

一个视图，允许设置由可在二维中移动的手柄的水平位置和垂直位置所表示的两个数值。

这些值始终处于 0 到 1 之间的范围内。使用 ControlSpec 及其 -map 和 -unmap 方法，可以轻松地按需缩放输出和输入值。

-step 变量决定在使用键盘控制手柄时值的变化量。默认情况下，按住 Shift、Ctrl 或 Alt 键会分别将此量乘以 100、10 或 0.1，不过你可以通过设置 -shift_scale、-ctrl_scale 或 -alt_scale 来自定义。

拖放会给出并接受一个 Point，其两个坐标分别代表 Slider2D 的两个值。

类方法

实例方法

Data

.x

由手柄的水平位置所表示的值。它始终会被裁剪到 0 到 1 之间的范围。

参数：

一个 Float。

.y

由手柄垂直位置表示的值。它始终会被裁剪到 0 到 1 之间的范围。

参数：

一个 Float。

.activex

设置 -x 并触发 -action。

.activey

设置 -y 并触发 -action。

.setXY

将 -x 和 -y 设置为这两个参数。

.setXYActive

将 -x 和 -y 设置为这两个参数，并触发 -action。

.incrementX

将 -x 增加 -step 乘以 factor。

.decrementX

将 -x 减少 -step 乘以 factor。

.incrementY

将 -y 增加 -step 乘以 factor。

.decrementY

将 -y 减少 -step 乘以 factor。

Appearance

.knobColor

手柄的颜色。

参数：

一个 Color。

.thumbSize

手柄的大小。

参数：

以像素为单位的整数数量。

Interaction

.step

-x 或 -y 在递增或递减时，或按下相关按键时，将会变化的量。

参数：

一个 Float。

.pixelStepX

如果手柄水平移动一个像素，-x 将改变的绝对量。

返回值：

一个 Float。

.pixelStepY

如果手柄垂直移动一个像素，-y 将改变的绝对量。

返回值：

一个 Float。

.shift_scale

当按下 Shift 键并用键盘递增或递减数值时，-step 所乘以的因子。

参数：

一个 Float。

.ctrl_scale

当按下 Ctrl 键并用键盘递增或递减数值时，-step 所乘以的因子。

参数：

一个 Float。

.alt_scale

在按住 Alt 键的同时通过键盘递增或递减值时，-step 所乘以的因子。

参数：

一个 Float。

.action

当用户更改手柄的位置或大小时求值的动作对象。

拖放

.defaultGetDrag

返回值：

一个 -x 和 -y 分别设置为 x 和 y 坐标的 Point。

.defaultCanReceiveDrag

返回值：

如果当前拖拽数据是 Point，则为 true。

.defaultReceiveDrag

分别将 -x 和 -y 设置为当前拖拽数据中存储的 Point 的两个坐标，并触发 -action。

示例

(
w = Window("Slider2D", Rect(100, 100, 140, 140));
t = Slider2D(w, Rect(20, 20, 80, 80))
        .x_(0.5) // x 的初始位置
        .y_(1)   // y 的初始位置
        .action_({ |sl|
            [\sliderX, sl.x, \sliderY, sl.y].postln;
        });
w.front;
)

t.x        // 获取 x 位置
t.x_(0.25) // 设置 x 位置

拖放点

(
w = Window("Slider2D", Rect(100, 100, 500, 300));
w.view.decorator = FlowLayout(w.view.bounds);
t = Slider2D(w, Rect(20, 20, 280, 280))
        .x_(0.5) // x 的初始位置
        .y_(1)   // y 的初始位置
        .background_(Color.rand)
        .action_({ |sl|
            [\sliderX, sl.x, \sliderY, sl.y].postln;
        });
t.step_(0.01);

n = CompositeView.new(w, 200@300);
n.decorator = FlowLayout(n.bounds);

v = { |i| DragBoth.new(n, Rect(0, i * 20, 200, 20)).background_(Color.rand).align_(\center) }.dup(5);

StaticText.new(n, 200@150).string_("hold down cmd and drag points from the slider to the drag slots, or reverse").stringColor_(Color.white);

w.front;
)

塑造声音

(
s.waitForBoot({
    a = { |mod = 0.05, index = 0.05|
            var r, out, out2;
            r = Saw.ar(8, 0.03);
            out = PMOsc.ar(
                440,
                660 * mod, 3 * index, 0,
                Lag.ar(r, 0.01, 1));
            [out, Delay1.ar(out)];
    }.play;

    w = Window("Slider2D", Rect(100, Window.screenBounds.height - 400, 300, 300));
    w.view.decorator = FlowLayout(w.view.bounds);
    t = Slider2D(w, Rect(0, 0, 292, 292))
            .y_(0.05)
            .x_(0.05)
            .background_(Color.rand)
            .knobColor_(Color.rand)
            .action_({ |sl|
                a.set(\mod, sl.x, \index, sl.y);
            });
    w.front;
    CmdPeriod.doOnce({ w.close });
})
)
