PV_ChainUGen

用于操作 FFT 链的 UGen 的基类

WidthFirstUGen : UGen : AbstractFunction : Object

子类：FFT、FFTTrigger、PV_BinScramble、PV_BinShift，

说明

PV_ChainUGen 是一个抽象类，不直接使用，只使用它的子类。它表示相位声码器 UGen——即对 FFT 产生的频域信号应用某种变换的 UGen。

它涵盖所有输出为 FFT 链的单元生成器。这就是为什么 FFT 属于该组，而 IFFT 不属于该组——IFFT UGen 输出的是普通的时域音频。

关于使用这些 unit generator 的更多信息，请参见 FFT Overview。

类方法

实例方法

.fftSize

返回 FFT 链缓冲区的大小。

(
{
    var chain = FFT(LocalBuf(1024));
    chain.fftSize.poll;
    0.0
}.play;
)

.pvcalc(numframes, func, frombin: 0, tobin, zeroothers: 0)

pvcalc 将一个函数应用于 FFT 链的频域数据。关于效率方面的讨论，请参见下面的 -pvcollect。另请参见下面的 -pvcalc2 以及 UnpackFFT。

chain = chain.pvcalc(numframes, func, frombin, tobin, zeroothers)

参数：

numframes

要处理的 FFT 帧数

func

该函数接收两个数组作为输入（magnitude 和 phase），并返回结果数组对 [magnitude, phase]。

// 示例函数
{ |magnitudes, phases|
    [mags.reverse, phases.reverse] // 例如倒置频谱
}

frombin

范围起点（可选）

tobin

范围结束（可选）

zeroothers

如果设置为 1，则正在处理的范围之外的 bin 会被静音。

.pvcalc2(chain2, numframes, func, frombin: 0, tobin, zeroothers: 0)

方法 pvcalc2 与 -pvcalc 类似，但可以组合两条 FFT 链。

chain = chain.pvcalc2(chain2, numframes, func, frombin, tobin, zeroothers)

参数：

chain2

第二个 FFT 链。

numframes

要处理的 FFT 帧数

func

该函数接受四个数组作为输入（magnitudes1、phases1、magnitudes2、phases2），并返回一对结果数组 [magnitude, phase]。

// 示例函数
{ |magnitudes1, phases1, magnitudes2, phases2|
    [magnitudes1, phases2] // 例如使用其中一个的幅度，和另一个的相位
}

frombin

范围起点（可选）

tobin

范围结束（可选）

zeroothers

如果设置为 1，则正在处理的范围之外的 bin 会被静音。

.pvcollect(numframes, func, frombin: 0, tobin, zeroothers: 0)

对 FFT 链的每个 bin 分别进行处理，具体做法是对 FFT 链的每个 bin 应用一个函数。

chain = chain.pvcollect(numframes, func, frombin, tobin, zeroothers)

参数：

numframes

要处理的 FFT 帧数

func

处理每个 bin 的函数。它应是一个以 magnitude, phase, bin, index 为输入并返回结果数组 [magnitude, phase] 的函数。

// 示例函数
{ |magnitude, phase, bin, index|
    // 在一定程度上随机化幅度（信号更嘈杂）
    [magnitude * (5.0.rand2.dbamp), phase]
}

bin 是整数频点编号，从 0 开始表示 DC，而 index 是迭代编号，始终从 0 开始。你可以选择忽略相位，只返回单个（幅度）值，此时假定相位保持不变。

frombin

范围起点（可选）

tobin

范围结束（可选）

zeroothers

如果设置为 1，则正在处理的范围之外的 bin 会被静音。

讨论：

请注意，根据你的使用方式，此过程可能相对 CPU 开销较大。使用 pvcollect（或其组件 UnpackFFT 和 PackFFT）通常不如使用单个 "PV_" 单元生成器来处理 FFT 链高效，因为它涉及创建相当大的需求率单元生成器图。

如果你希望减少使用此方法带来的 CPU 影响，请尝试以下操作：

  • 使用 frombin 和 tobin 参数来限制参与计算的 FFT 频段数量。通常较低的 FFT 频段包含最响亮和/或最相关的信息，因此忽略较高频段时你的效果听起来可能非常相似（可以不对它们处理，或将 zeroothers 参数设为 1 将其丢弃，这会产生频域带通滤波器效果）。
  • 使用更小的 FFT 缓冲区大小。
  • 尽可能避免在计算函数内部创建 ugen。例如，如果在函数内部指定，像 LFPar.kr(0.5, 0, 1) 这样的确定性 ugen 会为每个 bin 复制一次，尽管其输出始终相同。请在计算函数外部定义它，然后通过变量名引用。
  • 避免无用的计算！例如，取消注释上文中所有不同的行会浪费精力，因为许多值会被计算但不被使用。这无法在编译期间优化掉。这一点尤其重要，因为所有计算都会重复（每个 bin 一次），因此可能对效率产生显著影响。
  • 如果你发现自己在 FFT 链上连续多次调用 pvcollect，绝对应该尝试将处理合并到单个 pvcollect 函数中，以避免不必要的解包-再打包-再解包-再打包。

示例

pvcalc

// 一个声音文件
c.free; c = Buffer.read(s, ExampleFiles.child);

(
{
    var in, chain, v;
    in = PlayBuf.ar(1, c, BufRateScale.kr(c), loop: 1);
    chain = FFT(LocalBuf(1024), in);

    chain = chain.pvcalc(1024, { |mags, phases|
//////// 尝试依次取消注释这些行并重新运行合成器：
        [mags * { 1.5.rand }.dup(mags.size), phases + { pi.rand }.dup(phases.size)]; // 任意滤波器，任意相移
        // [mags.reverse, phases.reverse]; // 上下翻转！
        // [mags.differentiate, phases.differentiate]; // 沿频率轴求导
        // [mags[30..] ++ mags[..30], phases[30..] ++ phases[..30]]; // ".rotate" 不能直接使用，但这样是等价的
    }, frombin: 0, tobin: 250, zeroothers: 0);

    0.5 * IFFT(chain).dup
}.play
)

pvcalc2

c.free; c = Buffer.read(s, ExampleFiles.child);

(
x = {
    var fftsize = 1024;
    var in, chain, in2, chain2, out;
    in = PlayBuf.ar(1, c, BufRateScale.kr(c), loop: 1);
    chain = FFT(LocalBuf(fftsize), in);

    // JMcC 潺潺溪流
    in2 = ({
        RHPF.ar(OnePole.ar(BrownNoise.ar, 0.99), LPF.ar(BrownNoise.ar, 14)
            * 400 + 500, 0.03, 0.003) }!2)
            + ({ RHPF.ar(OnePole.ar(BrownNoise.ar, 0.99), LPF.ar(BrownNoise.ar, 20)
            * 800 + 1000, 0.03, 0.005) }!2
        ) * 4;
    chain2 = FFT(LocalBuf(fftsize), in2);

    chain = chain.pvcalc2(chain2, fftsize, { |mags, phases, mags2, phases2|
        [
            mags * mags2 / 10,
            phases2 + phases
        ]
    }, frombin: 0, tobin: 125, zeroothers: 0);

    out = IFFT(chain);
    0.5 * out.dup
}.play
)

//////// 依次尝试取消注释这些行并重新运行合成器：
        // mag；

        // [mag, phase].sqrt；

    }, frombin: 0, tobin: 250, zeroothers: 0);
