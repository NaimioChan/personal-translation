Pbindef

增量事件模式引用定义

Pdef : EventPatternProxy : TaskProxy : PatternProxy : Pattern : AbstractFunction : Object

另请参阅：Pdef、Pbind

说明

Pbindef 保留对 Pbind 的引用，其中单个键可以被替换，结合了 PbindProxy 和 Pdef。当旧流结束并设置了新流时，它会继续播放，并按节拍安排更改。

与 Pdef 的不同之处在于，它允许逐步更改 Pbind 的基本模式（patternpairs）——也包括 Pdef 内已存在的 Pbind。

Pbindef 和 Pdef 使用相同的全局集合，而 Pdef 和 Pdefn 使用各自独立的集合。

Pbindef 从 Pdef 继承大多数方法。概览：JITLib

Pbindef(\x, \note, Pseq([0, 7, 9]), \dur, 0.2).play;

它也支持关键字参数语法：

Pbindef(\x, note: Pseq([0, 7, 9]), dur: 0.2).play;

类方法

Pbindef.new(key ... pairs, ... kwargs)

将模式存储到 Pdef 的全局字典中，键为 key。如果该 key 已存在 Pdef，则用新模式替换其模式。如果该 key 已存在 Pbindef，则仅设置参数，或添加一个新的（整个模式被替换）。

使用 *new(key) 可以访问该 key 处的模式（若不存在，则会创建一个默认模式）。参见 Pdef。

示例

(
    SynthDef(\Pdefhelp, { |out, freq, sustain = 1, amp = 1, pan|
        var env, u = 1;
        env = EnvGen.ar(Env.perc(0.01, sustain), 1, doneAction: Done.freeSelf);
        5.do { var d; d = exprand(0.01, 1); u = SinOsc.ar(d * 300, u, rrand(0.1, 1.2) * d, 1) };
        Out.ar(out, Pan2.ar(SinOsc.ar(u + 1 * freq, 0, amp * env), pan));
    }).add;
)


Pbindef(\a, instrument: \Pdefhelp).play;
Pbindef(\a, degree: Pseq([0, 2, 5b, 1b], inf));
Pbindef(\a, dur: 0.1);
Pbindef(\a, degree: Pseq([1b, 5, 3, 1b, 6, 2, 5, 0, 3, 0, 2], inf));
Pbindef(\a, legato: Prand([1.0, 2.4, 0.2], inf), mtranspose: -3);
Pbindef(\a, mtranspose: nil); // 移除键

Pbindef(\a, degree: Pseq([1, 2, 3, 4, 5, 6], 1));
Pbindef(\a, degree: Pseq([1, 2, 3, 4, 5, 6], 3), dur: 0.02);
Pbindef(\a, degree: Pseq([1, 2, 3, 4, 5, 6], 3), dur: 0.1);

// 除此之外，Pbindef 的行为与 Pdef 相同：

Pbindef(\a).quant = 0.0;
Pbindef(\a, degree: Pseq([1, 2, 3, 4, 5, 6], 1));

Pbindef(\a).stop;
Pbindef(\a, degree: Pseq([1, 2, 3, 4, 5, 6], 1)); // 现在不会恢复

Pbindef(\a).playOnce; // 播放单个实例
Pseq([Pbindef(\a), Pdef(\a)]).play; // 此处相同（Pdef(\a) 与 Pbindef 是相同的 pattern）

Pbindef(\a) === Pdef(\a) // 完全相同。



// 已存在的 Pdef 可以被增量修改

Pdef(\x, Pbind(\instrument, \Pdefhelp, dur: 0.3));
Pdef(\x).play;

Pbindef(\x, degree: 7.rand + 1);
Pbindef(\x, degree: Pseq([0, 7, 3, 7, 4], inf), dur: Pn(Pseries(0.2, -0.02, 10)));
Pbindef(\x, \stretch, 2);

Pdef(\x).stop;
