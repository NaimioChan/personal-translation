NodeMap

存储控制值和总线映射

IdentityDictionary : Dictionary : Set : Collection : Object

参见：Bus

子类：ProxyNodeMap

说明

用于独立于特定节点存储控制值和总线映射的对象。

a = NodeMap.new;
a.set(\freq, [446, 662], \amp, 0.2, \out, Bus.audio(s));
a.asOSCArgArray;

类方法

实例方法

.set( ... args)

设置节点的参数

.unset( ... keys)

移除设置

.unmap( ... keys)

移除映射

.at(key)

来自父类：IdentityDictionary

返回该键处的设置。

.sendToNode(node, latency)

通过发送 bundle 将设置应用于节点

.send(server, nodeID, latency)

通过发送 bundle 将设置应用于节点

.addToBundle(bundle, target)

将我所有的消息添加到该 bundle

.addToEvent(event)

将所有值添加到事件中

.asOSCArgArray

返回 OSC 消息的参数。

.unmapArgsToBundle(bundle, target, keys)

返回用于取消映射任何已映射控件的 OSC 消息参数。

.setMsg(target)

返回用于设置 synth 的 OSC 消息

参数：

target

用作 nodeID 以进行设置的组、synth 或服务器。

.get(key)

为向后兼容而保留。

.clear

移除所有设置并清除缓存

示例

s.boot;

(
SynthDef("modsine",
    { |out, freq = 320, amp = 0.2|
        Out.ar(out, SinOsc.ar(freq, 0, amp));
    }).add;
SynthDef("lfo",
    { |out, rate = 2|
        Out.kr(out, LFPulse.kr(rate, 0, 0.1, 0.2))
    }).add;
)

// 启动节点
(
b = Bus.control(s, 1);
x = Synth("modsine");
y = Synth.before(x, "lfo", [\out, b]);
)

// 创建一些节点映射
(
h = NodeMap.new;
h.set(\freq, 800);
h.map(\amp, b);

k = NodeMap.new;
k.set(\freq, 400);
k.unmap(\amp);
)

// 应用映射

h.sendToNode(x); // 首次创建新 bundle 时
k.sendToNode(x);

h.sendToNode(x); // 第二次使用缓存时
k.sendToNode(x);

h.set(\freq, 600);

h.sendToNode(x); // 当值被更改时，会生成一个新的 bundle

// 全部释放
x.free; b.free; y.free;
