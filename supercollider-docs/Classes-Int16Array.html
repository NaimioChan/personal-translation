Int16Array

一个索引槽位均为同一类型的数组

RawArray : ArrayedCollection : SequenceableCollection : Collection : Object

参见：FloatArray、Int8Array、Int32Array、DoubleArray、SymbolArray

说明

这些类实现的数组，其索引槽位均为同一类型。

  • Int8Array - 8 位整数
  • Int16Array - 16 位整数
  • Int32Array - 32 位整数
  • FloatArray - 32 位浮点数
  • DoubleArray - 64 位浮点数
  • SymbolArray - 符号

注意： Int16Array 中元素的溢出行为是未定义的。每当运算结果超出返回类型（在此情况下为 16 位有符号整数）所支持的值范围时，就会发生这种情况。
