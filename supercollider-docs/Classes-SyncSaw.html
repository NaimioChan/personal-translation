SyncSaw

硬同步锯齿波。

PureUGen : UGen : AbstractFunction : Object

另请参见：Saw、VarSaw、LFSaw

说明

硬同步到基频的锯齿波。这会产生类似于移动共振峰或脉冲宽度调制的效果。当同步振荡器完成一个周期时，锯齿波振荡器的相位被重置。这不是带限波形，因此可能会产生混叠。

类方法

SyncSaw.ar(syncFreq: 440.0, sawFreq: 440.0, mul: 1.0, add: 0.0)

SyncSaw.kr(syncFreq: 440.0, sawFreq: 440.0, mul: 1.0, add: 0.0)

参数：

syncFreq

基频的频率。

sawFreq

同步锯齿波的频率。应始终大于 syncFreq。

警告： SyncSaw 若频率超过采样率（控制率下为 s.sampleRate / s.options.blockSize），将超出范围。

mul

输出将乘以该值。

add

此值将被添加到输出中。

实例方法

示例

{ SyncSaw.ar(100, Line.kr(100, 800, 12), 0.1) }.play;


(
plot { [
    SyncSaw.ar(800, 1200),
    Impulse.ar(800) // 以显示同步速率
] }
)

(
plot { [
    SyncSaw.ar(800, Line.kr(800, 1600, 0.01)), // 调制锯齿波频率
    Impulse.ar(800) // 以显示同步速率
] }
)

// 对 saw 进行示波：聚焦在示波窗口时按 's' 来比较声道
(
scope {
    var freq = 400;
    [
    SyncSaw.ar(freq, freq * MouseX.kr(1, 3)), // 调制锯齿波频率
    Impulse.ar(freq) // 以显示同步速率
] * 0.3 }
)
