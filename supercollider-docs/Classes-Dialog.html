Dialog

显示各种系统对话框

另请参阅：FileDialog、File

说明

这个类允许显示各种系统对话框。*openPanel 会显示一个用于选择要打开文件的对话框，*savePanel 会显示一个用于选择或创建要保存到的文件的对话框。

此处的方法是基于 FileDialog 构建的便捷函数。

类方法

.openPanel

显示一个对话框，用于选择要打开的现有文件（或选择多个文件）。它不对文件做任何处理，只是将所选文件名传递给给定的结果处理函数。

参数：

okFunc

按下 OK 时求值的对象。根据 multipleSelection 参数，其参数要么是作为 String 传入的单个文件名，要么是用于多个选中项的 Strings 数组。路径将始终是绝对路径。

cancelFunc

按下 Cancel 时要计算的对象。

multipleSelection

一个布尔值，指示是否可以选中多个文件。

path

一个字符串。对话框将初始显示此路径的内容。默认值为当前用户的主目录。

讨论：

Example:

(
Dialog.openPanel({ |path|
    path.postln;
}, {
    "cancelled".postln;
});
)

.savePanel

显示一个用于选择或创建要保存到的文件的对话框。它不会对所选文件执行任何操作，也不会创建任何文件；它只是将所选文件名传递给给定的结果处理函数。

参数：

okFunc

按下 OK 时要计算的对象。所选文件名（作为绝对路径）作为 String 参数传入。如果文件已存在，将要求用户确认。

cancelFunc

按下 Cancel 时要计算的对象。

path

一个字符串。对话框将初始显示此路径的内容。默认值为当前用户的主目录。

讨论：

Example:

(
Dialog.savePanel({ |path|
    path.postln;
}, {
    "cancelled".postln;
});
)

.getPaths

注意： 已弃用。请改用 *openPanel。

实现与 *openPanel 相同的功能，只是最后一个参数名称不同且默认为 true。
