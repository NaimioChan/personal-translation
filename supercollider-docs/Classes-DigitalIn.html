DigitalIn

从数字输入读取数据

UGen : AbstractFunction : Object

另请参见：AnalogIn、AnalogOut、DigitalOut、DigitalIO

说明

从数字传感器输入（例如：按钮或触发输入）读取数字数据。

注意： 此 UGen 仅在 Bela 上运行。

注意： 如果你想调制引脚编号，应使用 UGen DigitalIO

类方法

DigitalIn.ar(digitalPin: 0, mul: 1.0, add: 0.0)

参数：

digitalPin

要读取的数字引脚编号。引脚编号从 0 开始。该值不可调制。

mul

add
