二元运算符的副词

修改二元运算符的行为

另请参阅：SequenceableCollection、Stream

副词是传递给二元运算符的第三个参数，用于修改其在 SequenceableCollection 或 Stream 上的迭代方式。副词的理念取自 J 编程语言，它是 APL 的后继语言。

副词与 SequenceableCollection

通常当你像这样将两个数组相加时：

[10, 20, 30, 40, 50] + [1, 2, 3]

你会得到这个结果：

[ 11, 22, 33, 41, 52 ]

创建一个新数组，其长度为较长数组的长度，并且通过回绕索引将每个数组中的项相加。

使用副词可以改变这一行为。副词是符号，跟在二元运算符之后的 '.'（点）后面。副词可应用于所有二元运算符。

副词 's'

第一个副词是 's'，意为 'short'。加法操作现在返回两个数组中较短的那个。

[10, 20, 30, 40, 50] +.s [1, 2, 3]

returns:

[ 11, 22, 33 ]

副词 'f'

另一个副词是 'f'，它使用折叠索引而不是环绕索引：

[10, 20, 30, 40, 50] +.f [1, 2, 3]

returns:

[ 11, 22, 33, 42, 51 ]

副词 't'

表副词 't' 会生成一个数组的数组，其中第一个数组中的每一项被加到整个第二个数组上，并将结果数组收集起来。

[10, 20, 30, 40, 50] +.t [1, 2, 3]

returns:

[ [ 11, 12, 13 ], [ 21, 22, 23 ], [ 31, 32, 33 ], [ 41, 42, 43 ], [ 51, 52, 53 ] ]

副词 'x'

交叉副词 'x' 类似于 table，不同之处在于结果是扁平数组：

[10, 20, 30, 40, 50] +.x [1, 2, 3]

returns:

[ 11, 12, 13, 21, 22, 23, 31, 32, 33, 41, 42, 43, 51, 52, 53 ]

副词与流

目前为流定义了一个副词。这就是交叉副词 'x'。

通常，当你像这样添加两个流时：

p = (Pseq([10, 20]) + Pseq([1, 2, 3])).asStream;
Array.fill(3, { p.next });

你会得到：

[ 11, 22, nil ]

各项按顺序配对，当最早的流结束时，该流也随之结束。

cross 副词允许将第一个流中的每一项与第二个流中的每一项配对。

p = (Pseq([10, 20]) +.x Pseq([1, 2, 3])).asStream;
Array.fill(7, { p.next });

结果是：

[ 11, 12, 13, 21, 22, 23, nil ]

你可以将这些串联起来。左侧流操作数中的每一项都会被右侧流操作数“装饰”。

p = (Pseq([100, 200]) +.x Pseq([10, 20, 30]) +.x Pseq([1, 2, 3, 4])).asStream;
Array.fill(25, { p.next });

[ 111, 112, 113, 114, 121, 122, 123, 124, 131, 132, 133, 134,
  211, 212, 213, 214, 221, 222, 223, 224, 231, 232, 233, 234, nil ]

声音示例：

Pbind(\dur, 0.17, \degree, Pwhite(0, 6) +.x Pseq([[0, 2, 4], 1, [0, 2], 3])).trace.play
