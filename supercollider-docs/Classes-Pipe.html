Pipe

将 stdin 管道连接到 UNIX shell 命令，或从该命令管道输出 stdout

UnixFILE : IOStream : Stream : AbstractFunction : Object

参见：UnixFILE

说明

将标准输入管道连接到 UNIX shell 命令，或将标准输出从该命令管道传出。Pipe 将该 shell 命令视作一个 UnixFILE，完成时返回 nil。访问方法的详细信息参见 UnixFILE。必须显式关闭 Pipe。不要依赖垃圾回收器替你完成这件事！

类方法

Pipe.new(commandLine, mode)

参数：

commandLine

表示有效 shell 命令的 String。

mode

一个表示模式的 String。有效模式为 "w"（管道连接到 stdin）和 "r"（从 stdout 管道读取）。

Pipe.argv(args, mode)

参数：

args

一个包含字符串的 SequenceableCollection，其中第一个字符串是要运行的可执行文件的路径，所有其他字符串作为参数传递给该可执行文件。此方法直接启动进程，而不使用 shell。

mode

一个表示模式的 String。有效模式为 "w"（管道连接到 stdin）和 "r"（从 stdout 管道读取）。

Pipe.call(command, onSuccess, onError, maxLineLength: 4096)

实例方法

.open(commandLine, mode)

打开文件。

参数：

commandLine

传递给 popen 的命令行 String。

mode

传递给 popen 的 String，因此应为以下之一："r"、"w"

.openArgv(args, mode)

打开文件。

参数：

args

一个包含字符串的 SequenceableCollection，其中第一个字符串是要运行的可执行文件的路径，所有其他字符串作为参数传递给该可执行文件。此方法直接启动进程，而不使用 shell。

mode

传递给 popen 的 String，因此应为以下之一："r"、"w"

.close

关闭管道，等待命令完成。必须在 Pipe 对象被垃圾回收之前显式执行此操作。

返回值：

命令的退出状态（一个 Integer）。

示例

// 将 ls 的标准输出通过管道传入
(
var p, l;
p = Pipe.new("ls -l", "r");            // 以长格式列出目录内容
l = p.getLine;                    // 获取第一行
while({ l.notNil }, { l.postln; l = p.getLine });    // 发布直到 l = nil
p.close;                    // 关闭管道以避免恼人的堆积
)

不使用 shell：

// 将 ls 的标准输出通过管道传入
(
var p, l;
p = Pipe.argv(["ls", "-l"], "r");            // 以长格式列出目录内容
l = p.getLine;                    // 获取第一行
while({ l.notNil }, { l.postln; l = p.getLine });    // 发布直到 l = nil
p.close;                    // 关闭管道以避免恼人的堆积
)

(
var p, l;
p = Pipe.new("ping -c10 sourceforge.net", "r");    // 以长格式列出目录内容
