DrawGrid

在 UserView 上绘制网格线以进行绘图

另请参见：plot、AbstractGridLines、GridLines、Plotter、UserView

说明

DrawGrid 用于在 UserView 上绘制 GridLines 及其标签。它特别被 Plotter 用于在图表上绘制网格线，但也可用于向任何 UserView 添加网格线，例如在滑块或其他 GUI 元素后面。

其在 UserView 中的基本用法见下方示例。

注意，DrawGrid 不持有对 UserView 的任何引用，而是打算在其 -draw 方法中调用 -drawFunc 的 UserView。它只需要知道在什么边界内绘制网格线，以及水平和垂直的 GridLines 是什么。

类方法

.new

参数：

bounds

一个 Point 或 Rect，描述网格在父视图中的大小和位置（不包含任何标签）。

horzGrid

用于 x 轴的网格线对象，通过 GridLines 或 ControlSpec: -grid 方法实例化，或为 nil（结果为无网格线）。

vertGrid

用于 y 轴的网格线对象，参见 horzGrid。

返回值：

一个 DrawGrid。

讨论：

horizGrid 和 vertGrid 的 warp 行为基于分配给每个轴的网格线对象所使用的 ControlSpec 的 warp 行为。

多个 DrawGrid 可用于在单个 UserView 上绘制网格。

如果你想预览对该 DrawGrid 的修改，请参见 -preview。参见下面的示例。

实例方法

.draw

这会绘制到当前活动的 UserView 上。此方法意在从某个 UserView 的 -drawFunc 内部调用。

返回值：

nil

讨论：

请参见下面关于其在 UserView 中的基本用法的示例，包括在外层视图调整大小时如何管理其边界。

.horzGrid

设置 x 轴网格线。

参数：

g

一个 AbstractGridLines 子类，通过 GridLines 或 ControlSpec: -grid 方法实例化，或为 nil（导致没有网格线）。

返回值：

Self.

.vertGrid

设置 y 轴网格线。

参数：

g

一个 AbstractGridLines 子类，通过 GridLines 或 ControlSpec: -grid 方法实例化，或为 nil（导致没有网格线）。

返回值：

Self.

.bounds

获取/设置描述网格范围的边界（不包括任何标签）。

参数：

b

一个 Rect。

返回值：

一个 Rect。

.font

获取/设置网格线标签所使用的字体。

参数：

f

一个 Font。

返回值：

一个 Font。

.fontColor

获取/设置字体颜色。

参数：

c

一个 Color。

返回值：

一个 Color。

.gridColors

设置各轴网格线的颜色。

参数：

colors

一个包含两种颜色的 Array，分别用于 x 和 y 网格线。

返回值：

Self.

.opacity

获取/设置不透明度。

返回值：

一个 Float。

.smoothing

一个 Boolean，用于开启/关闭抗锯齿。请参阅 Pen: *smoothing。

返回值：

一个 Boolean。

.linePattern

设置线条虚线样式。value 应为 FloatArray，其中的值指定交替的虚线与空隙的长度。例如，FloatArray[10.0, 3.0, 5.0, 3.0]，表示长度为 10.0 和 5.0 像素的虚线，由 3.0 像素的空隙分隔。参见 Pen: *lineDash。

返回值：

Self.

.x

一个绘制 x（水平）轴的 DrawGridX 对象。通常你不需要设置此项。

返回值：

一个 DrawGridX。

.y

一个 DrawGridY 对象，用于绘制 y（垂直）轴。通常你不需要设置此项。

返回值：

一个 DrawGridY。

.numTicks

为每个轴设置近似的网格线（"刻度"）数量。如果设置，刻度数量固定，且 numTicks 优先于 -tickSpacing。如果为 nil，网格线数量随视图大小变化，受 tickSpacing 约束。默认值：nil。

参见下方的示例。

参数：

x

x 轴的网格线（“刻度”）的近似数量。

y

y 轴的近似网格线数量。

讨论：

所得的刻度数量是近似值，因为 AbstractGridLines: -niceNum 中的底层算法会根据数据范围和所请求的 numTicks 尝试为网格线寻找合适的值。你可以用以下代码片段观察 GridLines:-niceNum 的行为：

(
g = GridLines([0, 200].asSpec);
"requested / returned".postln;
(0, 3 .. 21).do({ |ntck|
  "% / %\n".postf(ntck, g.niceNum(ntck, true))
})
)

.tickSpacing

设置每个轴的网格线（"刻度"）之间的最小间距。网格线数量将随视图大小而变化，但间距不会小于此 tickSpacing，从而允许你控制网格线的密度。但是，如果 -numTicks 不为 nil，则它优先于 tickSpacing。

参见下方的示例。

参数：

x

x 轴上网格线（"ticks"）之间的最小间距（像素，默认值：64）。

y

y 轴上网格线之间的最小间距（像素，默认值：64）。

.preview

通过创建一个窗口来预览此 DrawGrid 对象，窗口中的视图会显示 DrawGrid 的当前状态。

d = DrawGrid(nil, \freq.asSpec.grid, \amp.asSpec.grid);
d.linePattern_(FloatArray[10.0, 5.0, 2.0, 5.0]);
d.preview;

如果修改了 DrawGrid，你可以 -refresh 返回的 UserView 以查看其更新后的状态，或者直接再次调用 -preview 来更新视图（如果 Window 已关闭，则重新创建预览）。参见下方的示例。

返回值：

一个 UserView，用于绘制此 DrawGrid。

.copy

安全地复制此对象及其工作成员。

返回值：

一个新的 DrawGrid。

示例

在 UserView 中的基本用法

(
w = Window.new.front;
u = UserView(w, w.bounds.size.asRect);

// 规格定义了其首选网格系统
x = \lofreq.asSpec.grid; // x 网格线
y = \amp.asSpec.grid;    // y 网格线
i = 40;                  // 网格内边距

d = DrawGrid(u.bounds.size.asRect.insetBy(i), x, y);

u.drawFunc = { d.draw };
u.resize_(5);
u.onResize = { |u|
    d.bounds = u.bounds.size.asRect.insetBy(i)
};
)

测试与修改

要预览你的 GridLines 的外观与风格，你可以使用 -preview 方法渲染你的 DrawGrid：

(
x = [0, 10].asSpec.units_("sec");
y = [0, 1].asSpec.units_("amp");
d = DrawGrid((500@250).asRect, x.grid, y.grid);

// 在测试之前设置其属性
d.x.tickSpacing_(25);
d.linePattern_(FloatArray[10.0, 5.0, 2.0, 5.0]);

// 生成预览
~testView = d.preview;
)

使用 DrawGrid 的便捷方法设置网格的属性，然后刷新视图：

d.tickSpacing_(50, 25).linePattern_(FloatArray[1.0]);
~testView.refresh;

或者再次调用 .preview，它将刷新现有的视图：

d.linePattern_(FloatArray[10.0, 5.0, 2.0, 5.0]).preview;

各个 x 和 y 网格的属性也可以单独访问和修改：

// 分别修改每个轴上的网格线数量
d.x.tickSpacing_(18); // x 刻度的固定（最大）*密度*
d.y.numTicks_(8);     // y 轴的固定 *数量* 刻度（近似）
d.preview;            // 刷新测试视图

d.y.numTicks_(nil);   // numTicks = nil：自动，遵循 -tickSpacing
d.preview;
