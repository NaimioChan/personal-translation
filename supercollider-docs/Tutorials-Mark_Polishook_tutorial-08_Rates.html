08_Rates

Mark Polishook 教程

另见：00_入门教程

音频速率

发送 .ar 消息的 UGen 默认以音频速率运行，即每秒 44,100 个采样。当 UGen 属于将被听到的音频链的一部分时，向其发送 .ar 消息。

SinOsc.ar(440, 0, 1);

控制率

附加了 .kr 消息的 UGen 以控制速率运行。

SinOsc.kr(440, 0, 1);

默认情况下，控制速率 UGen 每产生六十四个由音频速率 UGen 生成的样本值，就生成一个样本值。因此，控制速率 UGen 使用的资源比其音频速率对应物更少，计算开销也更低。

使用控制速率 UGen 作为调制器，即作为塑造音频信号的信号。

////////////////////////////////////////////////////////////////////////////////////////////////////

在这里，控制速率 SinOsc 调制音频速率 Pulse 波的频率。

(
SynthDef("anExample", {
    Out.ar(
        0,
        Pulse.ar(
            [220, 221.5] + SinOsc.kr([7, 8], 0, 7), // 控制速率可以节省 CPU 周期
            0.35,
            0.02
        )
    )
}).add;
)

Synth("anExample")

输入 command-period（cmd-.）以停止合成。
