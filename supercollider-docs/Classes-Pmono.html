Pmono

单声道事件流

Pattern : AbstractFunction : Object

参见：Pbind、PmonoArtic

子类：PmonoArtic

说明

播放一个 Synth 实例。模式对定义了该单个 synth 控件的变化。该节点在进入 Pmono 时创建，并在 Pmono 终止时释放。在整个模式持续期间只有一个节点，它会贯穿每个事件持续发声。如果单声部乐句需要在某些音符之间使用断奏音符或重新发音，请参见 PmonoArtic。

如果 event[\id] 不为 nil，Pmono 只是将其模式变化定向到该节点，而不会创建额外的 synth。

示例

p = Pmono(\default, \dur, 0.2, \freq, Pwhite(1, 8) * 100).play

p.stop

// 支持多通道扩展：
p = Pmono(\default, \dur, 0.2, \freq, Pwhite(1, 8) * 100, \detune, [0, 2, 5, 1]).play

p.stop


// 以下示例将在 5 秒后结束
// 或者你可以更早地用 stop 消息停止它
(
p = Pfindur(5,
    Pset(\detune, Pwhite(0, 1.0) * [0, 1, 3, 7],
        Ppar([
            Pmono(\default, \dur, 0.2, \freq, Pwhite(1, 8) * 100),
            Pmono(\default, \dur, 0.1, \freq, Pwhite(1, 8) * 300)
        ])
    )
).play;
)
p.stop;

一种相关方法

一种相关的方法是自行实例化一个 Synth，然后通过使用 "type" 为 \set 的 Event 来设置其值，如下所示。用户负责确保 Synth 的创建与模式执行之间的正确同步。

// 首先我们创建一个可控制的对象
x = { |freq = 440, amp = 0.6| MoogFF.ar(PinkNoise.ar(amp), freq).dup }.play;

// 在以下 pattern 中，前两个键是产生单音行为的关键：
(
p = Pbind(
    \type, \set,    // 这告诉它我们将要设置一个已有节点的参数……
    \id, x.nodeID,    // ...这告诉它我们将设置谁的参数
    \args, #[\freq, \amp], // 这告诉它要设置哪些参数
    \freq, Pwhite(100, 1000),
    \dur, 0.2,
    \amp, Pseq((1, 0.99 .. 0.1), inf)
).play;
)

p.stop
x.free

有关 \set 事件类型的更多细节，请参阅《Practical Guide To Patterns》第 8 章 事件类型与参数 中的描述。

SynthDef 变体支持

SynthDef 允许定义备用的默认值集合（参见 SynthDef 帮助中的“Variants”）。大多数事件模式（如 Pbind）使用输出事件中的 variant 键来指定变体。（注意，变体始终是可选的。）在 Pmono 中，机制不同，因为 SynthDef 名称（包括变体后缀）必须在求值第一个事件之前已知。因此，变体后缀在 Pmono 的第一个参数中提供：

Pmono('synthDefName.variant', pairs...)
