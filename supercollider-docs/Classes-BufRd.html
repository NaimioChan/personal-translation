BufRd

缓冲区读取振荡器。

MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：BufWr

说明

读取缓冲区在某个索引处的内容。

与 PlayBuf 相比：PlayBuf 自行播放整个缓冲区，而 BufRd 仅通过相位输入移动其读取点，因此没有音高输入。BufRd 具有可变插值。

类方法

BufRd.ar(numChannels, bufnum: 0, phase: 0.0, loop: 1.0, interpolation: 2)

BufRd.kr(numChannels, bufnum: 0, phase: 0.0, loop: 1.0, interpolation: 2)

参数：

numChannels

缓冲区将具有的声道数。这必须是一个固定整数。SynthDef 的架构在编译后无法更改。

注意： 如果你提供的缓冲区的 bufnum 其 numChannels 与你在 BufRd 中指定的不同，它将发布一条警告并输出它能够输出的声道。

bufnum

要使用的缓冲区索引。

phase

可音频速率调制的缓冲区索引。

警告： phase 参数仅能为寻址 2**24 个采样（在 44100Hz 下约 6.3 分钟）提供精度。

loop

1 表示真，0 表示假。这是可调制的。

interpolation

1 表示不插值，2 表示线性插值，4 表示三次插值。（数字一、二和四对应于计算每种插值类型所需的连续采样数。）该参数的任何其他值都会静默地默认为不插值。

实例方法

示例

(
// 将整个声音读入内存
s = Server.local;
// 注意：不是*那个* columbia，是第一个
b = Buffer.read(s, ExampleFiles.child);
)

// 使用任意 AUDIO 速率 ugen 作为索引生成器

{ BufRd.ar(1, b, SinOsc.ar(0.1) * BufFrames.ir(b)) }.play;
{ BufRd.ar(1, b, LFNoise1.ar(1) * BufFrames.ir(b)) }.play;
{ BufRd.ar(1, b, LFNoise1.ar(10) * BufFrames.ir(b)) }.play;
{ BufRd.ar(1, b, LFTri.ar(0.1) + LFTri.ar(0.23) * BufFrames.ir(b)) }.play;
// 原始时长
{ BufRd.ar(1, b, LFSaw.ar(BufDur.ir(b).reciprocal).range(0, BufFrames.ir(b))) }.play;


// 将 phasor 索引用作文件索引

{ BufRd.ar(1, b, Phasor.ar(0, BufRateScale.kr(b), 0, BufFrames.kr(b))) }.play;


// 更改速率和插值
(
x = { |rate = 1, inter = 2|
    BufRd.ar(1, b, Phasor.ar(0, BufRateScale.kr(b) * rate, 0, BufFrames.kr(b)), 1, inter)
}.play;
)

x.set(\rate, 0.9);
x.set(\rate, 0.6);
x.set(\inter, 1);
x.set(\inter, 0);


// 用 BufWr 写入缓冲区
(
y = { |rate = 1|
    var in;
    in = SinOsc.ar(LFNoise1.kr(2, 300, 400), 0, 0.1);
    BufWr.ar(in, b, Phasor.ar(0, BufRateScale.kr(b) * rate, 0, BufFrames.kr(b)));
    0.0 // quiet
}.play;
)

// 用 BufRd 读取它
(
x = { |rate = 1|
    BufRd.ar(1, b, Phasor.ar(0, BufRateScale.kr(b) * rate, 0, BufFrames.kr(b)))
}.play;
)



x.set(\rate, 5);
y.set(\rate, 2.0.rand);
x.set(\rate, 2);

b.free
