Filtering

减法合成的基本思路类似于制作咖啡：某些东西经过过滤器，以去除最终产物中不需要的成分。

.dumpClassSubtree 消息

获取 SuperCollider 3 中的 ugen 滤波器列表，方法是向 Filter 类发送 .dumpClassSubtree 消息，如下所示

Filter.dumpClassSubtree;

（ Object.dumpClassSubtree 打印所有 SuperCollider 类）

////////////////////////////////////////////////////////////////////////////////////////////////////

使用 LPF（低通滤波器）从输入源中减去高频成分。

(
SynthDef("subtractive", { arg out;
    Out.ar(
        out,
        LPF.ar(
            Pulse.ar(440, 0.5, 0.1),    // 待滤波的源信号
            Line.kr(8000, 660, 6)        // 用一条线控制滤波器频率
        )
    )
}).add;
)

Synth("subtractive")

////////////////////////////////////////////////////////////////////////////////////////////////////

RLPF，一个谐振低通滤波器，移除高频内容并强调截止频率。

(
SynthDef("passLowFreqs2", { arg out;
    Out.ar(
        out,
        RLPF.ar(
            Saw.ar([220, 221] + LFNoise0.kr(1, 100, 200), 0.2),
            [LFNoise0.kr(4, 600, 2400), LFNoise0.kr(3, 600, 2400)],
            0.1
        )
    )
}).add;
)

Synth("passLowFreqs2")

////////////////////////////////////////////////////////////////////////////////////////////////////

Resonz 是一个非常、非常、非常强的滤波器。用它来强调某个频带。

用陡峭的截止频率将噪声转变为音高。

(
SynthDef("noiseToPitch", { arg out = 0, mul = 1;
    Out.ar(
        out,
        Resonz.ar(
            WhiteNoise.ar(mul),
            LFNoise0.kr(4, 110, 660),
            [0.005, 0.005]
        )
    )
}).add;
)

(
// 激活左右声道
Synth("noiseToPitch", [\out, 0, \mul, 1]);
Synth("noiseToPitch", [\out, 1, \mul, 1]);
)
