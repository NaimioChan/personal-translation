jitlib_asCompileString

JITLib 中的 asCompileString

{ 10 + 6 * ~harry }.asCompileString;

许多对象理解 .storeOn，这是一种发布其字符串的方法，该字符串是编译重现它们所必需的。有时人们想要存储代理空间的某种配置，如果所使用的所有函数都是闭包函数，则可以做到这一点。

// 一个示例，说明 ProxySpace 如何记录其当前状态：

p = ProxySpace.push(s);


(
~ctl1 = {
    var z = 1;
    4.do { |i| z = z * SinOsc.kr(i.sqrt, i+[0,0.2]) };
    z
};

~ctl2[0] = { LFNoise2.kr([20,20],20) };
~ctl2[1] = {
    LFNoise2.kr([20,20],20) * LFNoise0.kr([20,20],20)
};

~out = {
    SinOsc.ar(~freq.kr, 0, 0.1)
};

~freq[0] = { ~ctl1.kr(2) + ~ctl2.kr(2) + 400 };
~freq[5] = ~ctl1.wrap2(~ctl2) * ~ctl1 / (~ctl2 + ~ctl1);

~pat = Pbind(\freq, Pfunc({ 1.2.rand }));
~z = 9;
~out.set(\freq, 760, \ffreq, 20);
)

p.asCompileString;

// document 消息创建一个新文档，并将代码发布到其中

p.document;        // 记录所有内容
p.document([\out]);     // 记录 ~out 的所有依赖项
p.document([\ctl1]);    // 记录 ~ctl1 的所有依赖项

Ndef 和 NodeProxy 也可以将其完整状态存储为代码字符串：

// 带 source 的 Ndef
Ndef(\x, { Saw.ar(\freq.kr(234), 0.1) });
Ndef(\x).asCode;
// 返回：
"Ndef('x', { Saw.ar(\freq.kr(234), 0.1) });
"

// 带源和设置的 Ndef
Ndef(\a,  { Saw.ar(\freq.kr, 0.1) }).set(\freq, 123);
Ndef(\a).asCode;
// 返回：
"(
Ndef('a', { Saw.ar(\freq.kr, 0.1) });
Ndef('a').set('freq', 123);
);
"

// 匿名 nodeproxy——返回带有解释器变量 "a = ..." 的示例代码
z = NodeProxy.new.source = { DC.ar };
z.asCode
// 返回：
"a = NodeProxy.new.source_({ DC.ar });"

// 位于已推入的 proxyspace 中的 nodeproxy，该 proxyspace 也在播放
p = ProxySpace.push(s);
~x = { Saw.ar(\freq.kr(234), 0.1) };
~x.play;
~x.asCode;
// 返回假定存在已推送的 proxyspace 的代码：
"(
~x = { Saw.ar(\freq.kr(234), 0.1) };
~x.play;
);
"
~x.end.clear;
p.pop; p.clear;
