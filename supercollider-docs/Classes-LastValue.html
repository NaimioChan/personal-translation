LastValue

输出输入改变之前的最后一个值

UGen : AbstractFunction : Object

参见：LeastChange、MostChange

说明

输出输入变化超过阈值之前的最后一个值。

类方法

LastValue.ar(in: 0.0, diff: 0.01)

LastValue.kr(in: 0.0, diff: 0.01)

参数：

in

输入信号。

diff

差值阈值。

实例方法

示例

d = { |freq = 440| SinOsc.ar(LastValue.ar(freq, 20), 0, 0.2) }.play;

d.set(\freq, 400);
d.set(\freq, 200);
d.set(\freq, 670);
d.set(\freq, 680);
d.set(\freq, 695);
d.free;

返回当前值与最后一次更改值之间的差值：

(
d = { |out = 0, val = 1|
    SinOsc.ar(
            abs(val - LastValue.kr(val)) * 400 + 200,
            0, 0.2
    )
}.play;
)

d.set(\val, 3);
d.set(\val, 2);
d.set(\val, 0.2);
d.set(\val, 1);
d.set(\val, 2);
d.free;
