Penvir

在将模式嵌入流时使用环境

Pattern : AbstractFunction : Object

参见：Pkey

类方法

Penvir.new(envir, pattern, independent: true)

参数：

envir

包含要嵌入对象的环境。

pattern

模式或流，通常是 Pfunc、Prout。

independent

如果为 true，流可以写入环境而不影响从此模式创建的其他流。如果为 false，流将写入一个公共命名空间。

示例

(
x = (a: 8);
y = Penvir(
    x,
    Pfunc { ~a * 2 }
);

)
