SetResetFF

置位-复位触发器。

PulseCount : UGen : AbstractFunction : Object

参见：ToggleFF

说明

当 trig 输入接收到触发时，输出被设为 1.0；当 reset 输入接收到触发时，输出被设为 0.0。一旦触发器被设为零或一，同一输入中的后续触发便不再有任何效果。其用途之一是让某个引发性事件导致某事发生，直到你将其重置。

如果两个输入同时收到触发，reset 输入优先。输出将为 0。参见下面的示例。

类方法

SetResetFF.ar(trig: 0.0, reset: 0.0)

来自父类：PulseCount

SetResetFF.kr(trig: 0.0, reset: 0.0)

来自父类：PulseCount

参数：

trig

将输出设为 1 的触发。触发可以是任意信号。当信号从非正变为正时，会产生一次触发。

reset

将输出设为 0 的触发。触发可以是任意信号。当信号从非正变为正时，会产生一次触发。

示例

(
play({
    a = Dust.ar(5); // 设置触发器
    b = Dust.ar(5); // 重置触发器
    SetResetFF.ar(a, b) * BrownNoise.ar(0.2);

}))

同时触发

此处，'reset' 的触发频率是 'trig' 的两倍。由于 'trig' 总是被 'reset' 匹配，因此输出为 0。（如果 'trig' 优先，你将得到占空比为 50% 的脉冲波。）

a = { SetResetFF.kr(Impulse.kr(50), Impulse.kr(100)) }.plot(duration: 0.1);

你可以通过反转输入来反转此行为，使 SetResetFF 的触发频率是复位的两倍。这会产生一个初始为 0、在周期中途切换为 1 的信号：先复位，再触发。要使其变为先触发，再复位，请反转相位：1 - SetResetFF。

a = { 1 - SetResetFF.kr(Impulse.kr(100), Impulse.kr(50)) }.plot(duration: 0.1);
