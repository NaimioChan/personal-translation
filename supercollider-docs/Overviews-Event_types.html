事件类型

Event 可以“播放”的不同方式

参见：Event

Event 通过求值事件中的 ~play 来响应 play 消息，而 ~play 的默认行为由 ~type 的值决定。1

a = (play: { ~word.scramble.postln }, word: "hello word");
a.play;

a = (type: \note, freq: [1310, 1321]); // 通过指定类型来选择播放函数
a.play;

可以使用 *addEventType 轻松扩展 eventTypes 集合：

Event.addEventType(\test, { "Your word is: ".post; ~word.scramble.postln });
(type: \test, word: "annahme").play;

当前存在的事件类型：

注意： 本文档不完整。

note

在服务器上实例化一个 synth，并指定参数，随后将其释放。SynthDef 的选择通过 \instrument 键指定。此事件类型即 Event.default 返回的内容。

(degree: [0, 5, 7, 11]).play;

实际播放此事件类型：

(type: \note, degree: [0, 5, 7, 11], instrument: \default).play;

set

用于设置某些已在运行的节点的参数。

a = (degree: 3, sustain: 40).play;
fork { 10.do { (type: \set, id: a[\id], \degree: [0, 5, 8, 11].choose).play; 0.3.wait } };

（另见：Pmono 帮助文件中的说明）

group

创建新组，可选参数：

~id

节点 ID，或节点对象

~group

外层组 id 或对象

~addAction / ~lag / ~timingOffset

决定组如何以及何时被创建

Example:

(type: \group, id: 2).play                    // 创建一个 nodeID 为 2 的组
(type: \note, freq: 500, group: 2).play        // 在该组中播放一个合成器
midi

将音符参数发送到 MIDI 设备参数：

~midicmd

一个 Symbol，用于要发出的 MIDI 命令

~midiout

一个 MIDIOut 对象

~chan

MIDI 通道号（0-15）

有关可用 midicmd 的详细信息，请参见 Pattern Guide 08: Event Types and Parameters: MIDI output。

on

播放 synth，必须指定 ~id

off

释放 synth（若无 gate 则 free）

kill

释放 synth

rest

在指定时间内不做任何事

composite

执行任意数量的事件类型，以 ~types 给出

MIDIClient.init;
m = MIDIOut(0);

// 应同时播放一个 synth *和* 一个外部 MIDI 音符
(type: \composite, types: [\note, \midi], midiout: m, degree: 0, dur: 3).play;
bus

将 ~array 写入从 ~out 开始的控制总线

audioBus

分配 ~channels 个连续音频总线

controlBus

分配 ~channels 个连续的控制总线

alloc

用 ~numframes 和 ~numchannels 分配 ~bufnum

allocRead

从 ~path 加载文件，从 ~firstFileFrame 开始，读取 ~numFrames 个采样帧

cue

为 DiskIn 提示一个文件，带有 ~bufferSize 帧

free

释放 ~bufnum

gen

发送 ~gencmd 到 ~bufnum

load

将 ~filename 从 ~frame 开始加载到 ~bufnum

read
table

将 ~amps 直接加载到缓冲区

sine1

从 ~amps 生成缓冲区

sine2

从 ~freqs、~amps 生成缓冲区

sine3

从 ~freqs、~amps、~phases 生成缓冲区

cheby

根据 ~amps 生成一个波形缓冲区

setProperties

对于 ~args 中每个在 Event 中具有非 nil 值的键，向 ~receiver 发送 setter 消息。

tree

创建一个组的树。~tree 可以是一个节点 ID 数组，并且可以包含指向进一步嵌套数组的关联。

phrase

它不再通过 ~instrument 从 SynthDef 播放单个 synth，而是查找一个 Pdef 并播放一组声音。

某些事件类型在内部使用，例如：

monoNote

由 Pmono 使用

monoSet

由 Pmono 使用

monoOff

由 Pmono 使用

[1] - 要了解事件类型通常是如何被调用的，下面是 Event 类中定义的 ~play 默认定义的一个略微简化的版本：{ ~eventTypes[~type].value(server); } 该函数使用 ~type 的值从 ~eventTypes 中持有的 Dictionary 里选择一个函数。
