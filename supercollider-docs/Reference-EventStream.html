事件流

一个在被调用时返回 Event 的 Stream

参见：Stream、Event

事件流是一个普通的 Stream，在被调用时返回事件。（参见 Event 类）。通常，事件流需要传入一个事件，往往使用默认事件：

t = Pbind(\x, Pseq([1, 2, 3])).asStream; // Pbind，例如创建一个流
t.next(Event.default);
t.next(Event.default);

事件流不能直接用时钟播放，因为它返回的是事件而不是时间值。因此，需要使用 EventStreamPlayer，它会将事件替换为相应的时间值。

可以使用 Pevent 将流包装在事件中：

t = Pevent(Pbind(\x, Pseq([1,2,3])), Event.default).asStream;
t.next;
t.next;
