String

字符数组

RawArray : ArrayedCollection : SequenceableCollection : Collection : Object

参见：Char

说明

String 表示一个由 Char 组成的数组。

字符串可以使用双引号直接书写：

"my string".class

一串字符串字面量将被连接在一起：

x = "hel" "lo";
y = "this is a\n"
    "multiline\n"
    "string";

反斜杠是转义字符。参见 Literals: Characters。

字符编码

请注意，虽然 Char 不支持 ASCII 之外的编码——例如 UTF-8 和 UTF-16 等多字节编码，或完整的 Latin-1（ISO 8859-1）字符集——但值为负的 Char 是完全合法的，并且可以在使用这些编码的字符串中串联在一起。

SuperCollider IDE 使用 UTF-8（ASCII 的超集）来解码和显示字符串，这意味着字符串 "🎹🙄🎻😂🎚️🎛️🎤😍" 可以在编辑器中书写、在 post window 中发布，并在大多数情况下像任何其他字符串一样被处理。然而，由于非 ASCII 的 UTF-8 字符由两个或更多字节组成，而 SuperCollider String 的成员是单比特的 Char，因此大小和索引的概念可能不符合直觉。例如，上面字符串的“size”是 38，而不是 8，其第一个索引的值是 -16，这根本不是有效的 ASCII 值，而是钢琴键盘 emoji（🎹）的 UTF-8 值 0xF09F8EB9 的第一个字节的有符号 8 位表示。

实例方法

访问字符

@(index)

来自父类：Collection

.at(index)

来自父类：ArrayedCollection

字符串对 .at 的响应方式与其他带索引的集合类似。每个元素是一个 Char。

"ABCDEFG".at(2)

.ascii

返回由 String 的各字符的 ASCII 值组成的 Array。

"wertvoll".ascii // [119, 101, 114, 116, 118, 111, 108, 108]

注意，如果字符串包含多字节 UTF-8 字符，此数组的长度将不等于可见字符数，也不一定是有效的 7 位 ASCII 值数组。

// "笑哭脸" 是 Unicode 码位 U+1F602，在 UTF-8 中编码为十六进制值 0xF09F9882
a = "😂";

// 尽管这是一个 UTF-8 字符，但它必须存储为 4 个 Char，因为每个 Char 只能容纳 1 个字节
a.size // 4 (!)
a.ascii // [-16, -97, -104, -126]

// "wrap(0, 255)" 将这些数字转换为它们的无符号 8 位值
b = a.ascii.wrap(0, 255) // [240, 159, 152, 130]

// 如果我们用十六进制表示这些值，就和上面的 UTF-8 一样：0xF09F9882
b.collect(_.asHexString(2)) // [F0, 9F, 98, 82]

比较字符串

.compare(aString, ignoreCase: false)

返回一个小于、等于或大于零的整数，取决于接收者应排在参数之前、等于参数还是应排在参数之后。这是区分大小写的比较。

<(aString)

返回一个 Boolean，表示接收者是否应排在参数之前。

"same" < "samf"

>(aString)

返回一个 Boolean，表示接收者是否应排在参数之后。

"same" > "samf"

<=(aString)

返回一个 Boolean，表示接收者是否应排在参数之前，包括相同字符串的情况。

"same" <= "same"
"same" <= "samf"

>=(aString)

返回一个 Boolean，表示接收者是否应排在参数之后，包括相同的字符串。

"same" >= "same"
"same" >= "samf"

==(aString)

返回一个 Boolean，表示两个 String 是否相等。

注意： 此方法（现在）区分大小写！

"same" == "same"
"same" == "Same"; // false

!=(aString)

返回两个 String 是否不相等的 Boolean。

"same" != "same"; // false
"same" != "Same";

模糊字符串比较

使用模糊比较时，字符串不需要完全匹配——我们可以计算出它们的相似程度，并据此做出判断。此行为继承自 SequenceableCollection: -editDistance，并在那里有完整文档，但这里给出一个示例：

"hello".editDistance("hallo"); // 1（替换）
"hello".editDistance("hell"); // 1（删除）
"hello".editDistance("helloo"); // 1（添加）
"hello".editDistance("hllo"); // 1 (removal)
"hello".editDistance("haldo"); // 2（替换）

连接字符串

++(anObject)

返回两个字符串的拼接。

"hello" ++ "word"

+(anObject)

返回两个字符串的拼接，中间用一个空格分隔。

"hello" + "word"

+/+(path)

将 this 与 path 拼接，作为主机操作系统上文件系统路径的组成部分。字符串会合并以避免重复的路径分隔符。

如果 this 以路径分隔符结尾且 path 以路径分隔符开头，则丢弃 path 中的分隔符。如果任一侧有路径分隔符，其效果等同于使用 ++。如果两侧都没有路径分隔符，则添加平台首选的分隔符（Windows 上为 '\'，其他平台为 '/'）。

返回 this 和 path 拼接后的结果。如果 path 是 PathName，则结果为 PathName；否则为 String。

注意： 不要在 URL 或其他期望正斜杠的场景中使用 +/+。+/+ 只应与文件系统路径一起使用，此时它会解析为正斜杠或反斜杠，具体取决于操作系统的要求。

参数：

path

任何可以转换为字符串的对象。通常为 String、Symbol 或 PathName。

// 在 Windows 上，这会生成 "foo\\bar"；在其他平台上，生成 "foo/bar"
"foo" +/+ "bar"

// 在所有平台上，这里都会产生 "foo/bar"：+/+ 优先使用现有的分隔符
"foo/" +/+ "bar"
"foo" +/+ "/bar"
"foo/" +/+ "/bar"

// 在 Windows 上，这会生成 "foo\\bar"；在其他平台上，则为 "foo/\\bar"
"foo" +/+ "\\bar"

// 连接一个符号也是可以的
"foo" +/+ 'bar'

正则表达式

String 类提供对 boost 库正则表达式函数的访问。Boost 默认使用 Perl 设置。（目前没有可覆盖正则表达式风格的钩子。）语法细节可参见 https://www.boost.org/doc/libs/1_69_0/libs/regex/doc/html/boost_regex/syntax/perl_syntax.html。

请仔细注意参数顺序：

  • regexp.matchRegexp(stringToSearch)
  • stringToSearch.findRegexp(regexp)（findAllRegexp 和 findRegexpAt 类似）。

findRegexp 遵循 String: -find 建立的模式，其中接收者是要搜索的字符串。matchRegexp 遵循 matchItem 的模式，其中接收者是要匹配的模式，第一个参数是要测试的对象。这是常见的混淆来源，但它基于这一先例。

.matchRegexp(string, start: 0, end)

Perl 正则表达式匹配（参见 String: Regular expressions）。如果接收者（正则表达式模式）与传入的字符串匹配，则返回 true。start 是在字符串中开始搜索的偏移量（默认：0），end 是停止的位置。

注意： 这是 regexp.matchRegexp(stringToSearch)，而不是反过来！参见上文：String: Regular expressions。

"c".matchRegexp("abcdefg", 2, 5); // true：子字符串存在
"c".matchRegexp("abcdefg", 4, 5); // false：子字符串不存在

"behaviou?r".matchRegexp("behavior"); // true：字符可能存在也可能不存在
"behaviou?r".matchRegexp("behaviour"); // true：字符可能存在也可能不存在
"behaviou?r".matchRegexp("behavir"); // false：但其余部分不匹配
"behavi(ou)?r".matchRegexp("behavir"); // true：括号中的子字符串可能存在，也可能不存在
"b.h.v.r".matchRegexp("behavor"); // true
"b.h.v.r".matchRegexp("behaviiiiir"); // false：点号代表恰好一个字符
"b.h.vi*r".matchRegexp("behaviiiiir"); // true: (kleene) star 表示其前面任意数量（包括零个）的字符
"b.h.vi*r".matchRegexp("behavuuuur"); // false
"(a|u)nd".matchRegexp("und"); // true
"(a|u)nd".matchRegexp("and"); // true
"[a-c]nd".matchRegexp("ind"); // false
"[a-c]nd".matchRegexp("bnd"); // true：a 和 c 之间的任何内容
"[a-c]*nd".matchRegexp("accacaccacand"); //  true：a、b、c 的任意组合，或都不选。
"[xtz]+nd".matchRegexp("xnd"); // true：x、t、z 的任意组合

.replaceRegexp(regex, with)

此方法用于替换部分文本。

参数：

regex

一个 perl 正则表达式（参见 String: Regular expressions），用于匹配调用者。

with

用于替换所找到的正则表达式的 String。

返回值：

一个 String。

// 移除数字
"g8et t8ho9se 3num5b89ers ou06t o8f h12er56e!".replaceRegexp("[0-9]", "")
-> get those numbers out of here!

// 移除大写字母
"HelLO WoRlD".replaceRegexp("(\\\w)", "\\\L$1")
-> hello world

// 除非在单词开头，否则删除所有大写字母
"HelLO worLD! I weNT tO Paris yeSTErDay.".replaceRegexp("(\\\S)(\\\S*)", "$1\\\L$2")
-> Hello world! I went to Paris yesterday.

.findRegexp(regexp, offset: 0)

Perl 正则表达式搜索（参见 String: Regular expressions）。此方法穷尽搜索匹配项，并将其收集到一个对的数组中，格式为 [character index, matching string]。

“最左最长匹配”：与大多数正则表达式风格一样，* 和 + 是贪婪的；如果正则表达式的某一部分可能存在多个重叠匹配，匹配列表将只包含其中最靠左且最长的匹配。在 "foobar".findRegexp("o+") 中，"o+" 可能有三处匹配：索引 1（第二个字符）处的 "o"、索引 2 处的 "o"，以及索引 1 处的 "oo"。findRegexp 只会返回其中最后一个（"oo"），因为它从尽可能靠左的匹配位置开始，并且是该位置处尽可能长的匹配。

但请注意，用于分组的括号（“标记子表达式”或“捕获组”）会产生单独的结果："aaa".findRegexp("(a+)"); 似乎会产生重复的结果 [[0, aaa], [0, aaa]]，但这是因为第一个匹配对应括号，第二个对应 a+。

要更清楚地查看被标记的子表达式结果，请考虑：

"foobar".findRegexp("(o*)(bar)");
-> [[1, oobar], [1, oo], [3, bar]]

"oobar" 匹配整个正则表达式。"oo" 和 "bar" 分别匹配第一个和第二个括号内的子表达式。

"foobar".findRegexp("o*bar");
"32424 334 /**aaaaaa*/".findRegexp("/\\*\\*a*\\*/");
"aaaabaaa".findRegexp("a+");

返回值：

一个嵌套数组，其中每个子数组是一对，[character index, matching string]。如果没有匹配项，则返回空数组。

.findAllRegexp(string, offset: 0)

与 -findAll 类似，但使用正则表达式（参见 String: Regular expressions）。与 findRegexp 不同，它只返回匹配项的索引：string.findAllRegexp(regexp) 返回的结果与 string.findRegexp(regexp).flop.at(0) 相同。

"foobar".findAllRegexp("o*bar");
"32424 334 /**aaaaaa*/".findAllRegexp("/\\*\\*a*\\*/");
"foobar".findAllRegexp("(o*)(bar)");
"aaaabaaa".findAllRegexp("a+");

返回值：

指向所有可能匹配项的整数字符索引数组。

.findRegexpAt(regexp, offset: 0)

在给定偏移处匹配正则表达式（参见 String: Regular expressions），以数组形式返回匹配结果和匹配长度，如果不匹配则返回 nil。匹配必须恰好从该偏移处开始。

"foobaroob".findRegexpAt("o*b+", 0); // nil
"foobaroob".findRegexpAt("o*b+", 1); // [oob, 3]
"foobaroob".findRegexpAt("o*b+", 2); // [ob,  2]
"foobaroob".findRegexpAt("o*b+", 3); // [b,   1]
"foobaroob".findRegexpAt("o*b+", 4); // nil
"foobaroob".findRegexpAt("o*b+", 5); // nil
"foobaroob".findRegexpAt("o*b+", 6); // [oob, 3]
"foobaroob".findRegexpAt("o*b+", 7); // [ob,  2]

返回值：

如果在指定偏移量处找到匹配，则返回数组 [matching string, length]；如果偏移量不匹配，则返回 nil。

Unix 支持

在相关情况下，当前工作目录与 SuperCollider 应用程序所在位置相同，并且 shell 为 Bourne shell（sh）。请注意，cwd 以及 shell 本身都不会持久保留：

"export FISH=mackerel".unixCmd;
"echo $FISH".unixCmd;

然而可以执行复杂命令：

在 os x 上还可以通过 osascript 调用 applescript：

如果需要环境变量持久化，可以使用 -setenv。

注意： 尽管该方法名为 'unixCmd'，它在 Windows 中确实有效。不过，字符串必须是 DOS 命令：例如 "dir" 而不是 "ls"。

.unixCmd(action, postOutput: true)

异步执行操作系统命令，使用标准 shell（*nix 上为 sh，Windows 上为 cmd）。

如果你想在不使用 shell 的情况下运行命令，请使用 SequenceableCollection: -unixCmd。

参数：

action

一个在进程退出时被调用的 Function。它接收两个参数：已退出进程的退出码和 pid。

postOutput

一个 Boolean，控制进程的输出是否显示在 post 窗口中。

返回值：

一个 Integer——运行该命令的 shell 的 pid，而非该命令本身的 pid（例外情况见下面的注释）。

要获取命令的实际 pid，请使用 SequenceableCollection: -unixCmd，它不使用 shell，并返回命令的实际 pid。

使用 Integer: -pidRunning 测试进程是否存活。

注意： 虽然底层系统调用将获取 shell 的 pid，但在以下情况下我们可能获得命令的实际 pid：在 *nix 系统上，如果命令使用 exec 运行，例如 "exec scsynth -u 57110".unixCmd;，这会使调用进程（shell）被新命令替换；特别是在 macOS 上，如果命令由单个可执行文件组成，macOS 似乎会通过不生成新的 shell 来优化该调用。过去的文档错误地声称此方法总是返回实际命令的 pid。请注意，exec 在 Windows 上不可用。

讨论：

Example:

"ls Help".unixCmd;
"echo one; sleep 1; echo two; sleep 1".unixCmd { |res, pid| [\done, res, pid].postln };

.unixCmdGetStdOut(maxLineLength: 1024)

与 -unixCmd 类似，区别在于进程的标准输出会被（同步地）返回，而不是发送到 post 窗口。

~listing = "ls Help".unixCmdGetStdOut; // Grab
~listing.reverse.as(Array).dupEach.join.postln; // 变形
