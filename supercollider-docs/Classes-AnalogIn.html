AnalogIn

从模拟输入读取数据

UGen : AbstractFunction : Object

参见：AnalogOut、DigitalIn、DigitalOut、DigitalIO

说明

读取连接到传感器（例如：电位器或 CV 输入）的直流耦合模拟输入。

注意： 此 UGen 仅在 Bela 上工作

类方法

AnalogIn.ar(analogPin: 0, mul: 1.0, add: 0.0)

参数：

analogPin

要读取的模拟引脚编号。引脚编号从 0 开始。此值可以在音频速率下调制。

mul

add

AnalogIn.kr(analogPin: 0, mul: 1.0, add: 0.0)

参数：

analogPin

要读取的模拟引脚编号。引脚编号从 0 开始。

mul

add

示例

// 调制正弦振荡器的频率

(
SynthDef("help-AnalogIn", { |out = 0|
    Out.ar(out,
      SinOsc.ar(AnalogIn.ar(0).exprange(200, 5000), 0, 0.1)
    )
}).play;
)
