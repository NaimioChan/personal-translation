LagUD

指数滞后

Filter : PureUGen : UGen : AbstractFunction : Object

参见：Lag、Lag2、Lag3、Lag2UD、Lag3UD

子类：Lag2UD、Lag3UD

说明

这基本上与 Lag 相同，区别在于你可以为信号上升和信号下降分别提供不同的 60 dB 时间。这对于平滑控制信号很有用，因为“淡入”应与“淡出”不同。

类方法

LagUD.ar(in: 0.0, lagTimeU: 0.1, lagTimeD: 0.1, mul: 1.0, add: 0.0)

LagUD.kr(in: 0.0, lagTimeU: 0.1, lagTimeD: 0.1, mul: 1.0, add: 0.0)

参数：

in

输入信号。

lagTimeU

上升信号的 60 dB 滞后时间，单位为秒。

lagTimeD

下降信号的 60 dB 滞后时间（以秒为单位）。

mul

add

实例方法

示例

// 用于滞后音高
(
SynthDef(\lagud_help, { |out, freq = 300, lagup = 1, lagdown = 5|
    Out.ar(out,
        SinOsc.ar( // 正弦波
            LagUD.kr( // 滞后频率
                freq,
                lagup,
                lagdown
            ),
            0, // phase
            0.2 // 正弦振幅
        )
    );
}).add;
)

x = Synth(\lagud_help); // 创建合成器
x.set(\freq, 500); // 将频率设为更高的值（耗时 1 秒）
x.set(\freq, 100); // 将频率设为更低的值（耗时 5 秒）
x.free;
