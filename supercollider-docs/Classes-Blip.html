Blip

带限脉冲振荡器。

UGen : AbstractFunction : Object

另请参阅：Impulse

说明

带限脉冲发生器。所有谐波具有相等的振幅。这相当于 MusicN 语言中的 'buzz'。

Synth-O-Matic（1990）有一个名为 blip 的脉冲发生器，因此这里用这个名字而不是 'buzz'。

与其他实现相比，它的改进之处在于：当谐波数量变化时，它会在一个控制周期内进行交叉淡化，因此不会有可听见的爆音。它还通过使用 1/sin 表（并对 1/0 采取特殊预防措施）消除了公式中的除法。查找表采用线性插值以获得更好的质量。

警告： 这种波形以其原始形式在高振幅或长时间下可能损害您的耳朵。

类方法

Blip.ar(freq: 440.0, numharm: 200.0, mul: 1.0, add: 0.0)

参数：

freq

频率，单位为赫兹。

numharm

谐波数量。如果会导致混叠，内部可能会降低此值。

mul

add

未文档化的类方法

Blip.kr(freq: 440.0, numharm: 200.0, mul: 1.0, add: 0.0)

实例方法

示例

// 调制频率
{ Blip.ar(XLine.kr(20000, 200, 6), 100, 0.2) }.play;

// 调制谐波数量
{ Blip.ar(200, Line.kr(1, 100, 20), 0.2) }.play;
