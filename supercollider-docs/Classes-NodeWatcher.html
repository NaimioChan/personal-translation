NodeWatcher

将 sc-lang 侧的节点对象通知其服务器侧状态

BasicNodeWatcher : AbstractNodeWatcher : Object

参见：Server Command Reference、Node、DebugNodeWatcher

说明

节点实例（Synth 和 Group）可以注册到 NodeWatcher。它监视服务器节点状态消息：n_go n_end n_off n_on

并相应地设置 Node 实例上的 isPlaying 和 isRunning 变量。结束的 Node 会在此时被注销。

在某些情况下，这可能是一项非常有价值的服务。使用独立对象来维护状态可使 Node 类的实现保持简单。请注意，服务器通知应处于开启状态。（这是默认设置。参见：aServer.notify）

// 最常见的用法：
NodeWatcher.register(aNode);

类方法

NodeWatcher.new(server)

来自父类：AbstractNodeWatcher

创建一个监听服务器地址的新实例

NodeWatcher.newFrom(server)

创建一个新实例，监听服务器的地址。如果已存在一个，则返回那一个。

NodeWatcher.register(node, assumePlaying: false)

参数：

node

可以是 Group 或 Synth。NodeWatcher 在内部创建。

assumePlaying

如果为 true，则节点的 isPlaying 字段被设为 true。

NodeWatcher.unregister(node)

从节点列表中移除该节点。节点被释放时也会发生此操作。

示例

(
b = s.makeBundle(false, {
    a = Group.new(s);    // 创建节点对象
    NodeWatcher.register(a); // 在服务器上创建之前注册
});
)
a.isPlaying;
s.listSendBundle(nil, b);    // 在服务器上启动节点
a.isPlaying;
a.isRunning;
a.run(false);
a.isRunning;
s.freeAll;    // 释放所有节点
a.isPlaying;
a.isRunning;
