MultiplexAnalogIn

从 Bela 板的模拟输入读取数据

UGen : AbstractFunction : Object

另请参见：AnalogIn、AnalogOut、DigitalIn、DigitalOut、DigitalIO

说明

从 Bela 板的多路复用模拟输入读取模拟数据，需搭配额外的 Multiplexer 板。

注意： 此 UGen 仅在 Bela 上工作

类方法

MultiplexAnalogIn.ar(analogPin: 0, muxChannel: 0, mul: 1.0, add: 0.0)

参数：

analogPin

要读取的模拟引脚编号。引脚编号从 0 开始。此值可以在音频速率下调制。

muxChannel

要读取的多路复用通道。引脚编号从 0 开始。此值可在音频速率下调制。

mul

add

MultiplexAnalogIn.kr(analogPin: 0, muxChannel: 0, mul: 1.0, add: 0.0)

参数：

analogPin

要读取的模拟引脚编号。引脚编号从 0 开始。

muxChannel

要读取的多路复用通道。引脚编号从 0 开始。

mul

add
