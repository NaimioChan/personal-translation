FFTTrigger

输出 FFT 链所需的信号，而不对信号执行 FFT

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

类方法

FFTTrigger.new(buffer, hop: 0.5, polar: 0.0)

参数：

buffer

用于为 FFT 使用而调节的缓冲区

hop

定时触发的跳数大小（默认为 0.5）

polar

一个标志。如果为 0.0，缓冲区将为复数数据做准备；如果 > 0.0，则设置极坐标数据。

实例方法

示例

// 提醒：这不是预期的典型用法！不过这样做也可以。
(
x = {
    var mags, phases, chain, sig;
    // 创建简单的起伏幅度
    mags = { FSinOsc.kr(ExpRand(0.1, 1)).range(0, 1) }.dup(100);
    // 然后给它们一个 "rolloff"，让声音不那么难听
    mags = mags  * ((1, 0.99 .. 0.01).squared);
    // 让我们以不同速率开启和关闭这些频段，我*确信*那听起来会很有趣
    mags = mags * { LFPulse.kr(2 ** IRand(-3, 5)).range(0, 1) }.dup(100);
    // 暂时忽略相位
    phases = 0.dup(100);
    chain = FFTTrigger(LocalBuf(512), 0.5);
    // 现在我们可以进行打包
    chain = PackFFT(chain, 512, [mags, phases].flop.flatten, 0, 99, 1);
    sig = IFFT(chain);
    sig.dup
}.play
)
x.free;
b.free;
