HIDCollection

描述 HID 设备中一组元素的类

Object

另请参阅：HID、Working with HID、HIDElement、HIDUsage

说明

HIDCollection 定义了 HID 设备低层级上的一组控件，即设备会报告这些组。访问它的主要用途是获取关于 HID 设备执行何种功能的信息，例如 GamePad、Joystick 或 Mouse。

此类由从设备读取的信息填充，表示设备的某些内部信息。

类方法

实例方法

.postCollection

将集合的可读描述发布到 post 窗口。

.usage

获取此集合的使用索引。

返回值：

一个 Number ——此集合的用法索引

.usagePage

检索此集合的用法页索引。

返回值：

一个 Number - 使用页索引

.usageName

获取此集合的用途名称。该名称通过用途页面索引从标准化的 HID 用途表中查找。

返回值：

一个 String —— 用法名称

.pageName

检索此集合的页面名称。该名称使用 usage page 索引从标准化的 HID usage 表中查找。

返回值：

一个 String - 使用页名称

.type

集合的类型。

返回值：

一个描述集合类型的数字。

.device

.device = value

获取此集合所属的设备。

注意： 不要将其设置为用户！

返回值：

HID 的一个实例

.id

此集合的索引

返回值：

一个 Number

.parent

此集合的父级索引。

返回值：

一个 Number

.numElements

此集合中的元素数量

返回值：

一个 Number

.firstElement

属于此集合的第一个元素。

返回值：

一个 Number——表示第一个元素的索引

.numCollections

此集合中（子）集合的数量

返回值：

一个 Number

.firstCollection

作为此集合一部分的第一个集合。

返回值：

一个 Number - 表示首个集合的索引
