CheckBox

一个在两种状态之间切换的视图。

说明

一个视图，点击时在两种状态之间切换，相应地显示或隐藏勾选标记。

类方法

实例方法

Data

.value

说明视图当前处于两种状态中的哪一种，false 表示未选中，true 表示已选中。默认为 false。

参数：

一个布尔值。

.valueAction

设置 -value 并触发 -action。

参数：

一个布尔值。

.string

显示在复选标记旁边的文本。

Actions

.action

每当用户切换状态时求值的行为对象。

拖放

.defaultGetDrag

返回值：

该 -value。

.defaultCanReceiveDrag

返回值：

如果当前拖拽数据是 Boolean 则为 true。

.defaultReceiveDrag

将 -valueAction 设置为当前拖拽数据。

示例

(
var w = Window().front;
var c = CheckBox(w, Rect(10, 10, 50, 50), "test");
c.action_{ |v| v.value.postln };
)
