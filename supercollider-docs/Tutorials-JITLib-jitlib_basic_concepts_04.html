NodeProxy 中的定时

另请参阅：JITLib、jitlib_basic_concepts_03

发生在 NodeProxy 上的变化，最重要的是设置其源，通常是在调用 put 方法时完成的（或者在 ProxySpace 中，通过赋值操作 =）。有时，希望相对于时钟对这些变化进行定时。

  • a) 时钟
  • b) 量化和偏移
  • c) 客户端与服务器速度
  • d) 采样精确输出

a) 时钟

一般来说，每个节点代理都可以有自己的时间基准，通常是一个速度时钟。时钟负责新函数插入的定时，默认在时钟的下一个拍点进行。

p = ProxySpace.push(s.boot);
~x.play; ~y.play;

// 这两个 synth 在它们被插入时启动：
~x = { Ringz.ar(Impulse.ar(1), 400, 0.05).dup };
~y = { Ringz.ar(Impulse.ar(1), 600, 0.05).dup };

// 添加一个公共时钟：
~x.clock = TempoClock.default; ~x.quant = 1.0;
~y.clock = TempoClock.default; ~y.quant = 1.0;

// 现在它们同步了
~x = { Ringz.ar(Impulse.ar(1), 400, 0.05).dup };
~y = { Ringz.ar(Impulse.ar(1), 600, 0.05).dup };

// 为简单起见，可以为整个 proxy space 提供一个 clock 和一个 quant：

p.clock = TempoClock.default; p.quant = 1.0;
~y = { Ringz.ar(Impulse.ar(1), 800, 0.05).dup };

~z.play;
~z = { Ringz.ar(Impulse.ar(1), [500, 514], 0.8).dup * 0.1};
~z = { Ringz.ar(Impulse.ar(1), exprand(300, 400 ! 2), 1.8).dup * 0.1 };
~z = { Ringz.ar(Impulse.ar(2), exprand(300, 3400 ! 2), 0.08).dup * 0.2 };
~z.end;

p.clear; // 全部清除。

事件序列

当向代理中插入新函数时，会构建 synthdef 并发送到服务器，服务器在完成时发回一条消息。然后代理等待下一个节拍来启动 synth。当将节点代理与模式一起使用时，模式使用时钟作为调度器来播放。

b) quant 与 offset

为了能够控制插入的偏移/量化点，可以使用 'quant' 实例变量，它既可以是一个数字，也可以是一个形如 [quant, offset] 的数组，就像在 pattern.play(quant) 中一样。

~z.play; ~y.play;
~z = { Ringz.ar(Impulse.ar(2), exprand(300, 3400 ! 2), 0.08).dup * 0.2 };
~y.quant = [1, 0.3]; // 偏移量为 0.3，量化为 1.0
~y = { Ringz.ar(Impulse.ar(1), 600, 0.05).dup };
~y.quant = [2, 1/3]; // 偏移量为 1/3，量化为 2.0
~y = { Ringz.ar(Impulse.ar(0.5), 600, 0.05).dup };

quant 和 offset 调度用于以下操作：play、put、removeAt、setNodeMap、wakeUp、rebuild（以及重建操作 lag、setRates、bus_）。有关 SC 中量化的更多信息，请参见 Quant。

c) 连接客户端与服务器速度

ProxySpace 有一个方法 ProxySpace: -makeTempoClock，它会创建一个 TempoBusClock 实例以及一个与之保持同步的节点代理（~tempo）。

p.makeTempoClock(2.0); // 创建一个新的 tempoclock，速度为 2 拍/秒
~y.play; ~x.play;
~y.quant = 1; // 将量化值设回 1，偏移量设为 0
~y = { Ringz.ar(Impulse.ar(~tempo.kr), 600, 0.05).dup }; // 脉冲使用速度
~x = Pbind(\instrument, \default, \freq, Pseq([300, 400], inf)); // pattern 使用 tempoclock

p.clock.tempo = 1.0; // 将速度设为 1
p.clock.tempo = 2.2; // 将速度设为 2.2

~x.free;
~y.free;

d) 采样精确输出

为提高效率，NodeProxy 使用普通的 Out UGen 写入其总线。如果需要采样精确的播放（OffsetOut），可以将 ProxySynthDef 类变量 ProxySynthDef: -sampleAccurate 设为 true。注意，对于来自外部源的音频直通，这会带来最多一个块（例如约 1 ms）的延迟。

// example

ProxySynthDef.sampleAccurate = false;

~x.play;

// 颗粒自行释放
~x = { SinOsc.ar(800) * EnvGen.ar(Env.perc(0.001, 0.03, 0.4), doneAction: Done.freeSelf) };


// 抖动音调。
(
r = Routine {
    loop {
        200.do { arg i;
            ~x.spawn;
            (0.005).wait;
        };
        1.wait;
    }
}.play;
)

ProxySynthDef.sampleAccurate = true;

// 稳定的音调，因为采样精确。

~x.rebuild;

r.stop;

p.clear; // 全部移除。
