ServerTree

注册在服务器上初始化基本组树时要执行的操作

AbstractServerAction : AbstractSystemAction : Object

参见：Server、ServerQuit、ServerBoot、CmdPeriod

说明

单例 ServerTree 提供了一个位置，用于注册函数和对象，以便在给定服务器启动时以及所有 synth 被释放时发生的事件。这是为了在服务器上初始化一个基本的组树。

用法参见 AbstractServerAction。
