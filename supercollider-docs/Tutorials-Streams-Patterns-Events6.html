并行模式

Ppar

Ppar 模式允许你合并多个事件流以并行播放。

Ppar 是一个 ListPattern，因此和大多数 ListPattern 一样，它接受两个参数：一个要并行播放的事件模式的 列表，以及一个 重复 次数。

Ppar 的子模式必须是事件模式。在 Ppar 中使用值模式是错误的，因为值模式不包含时长数据。

当 Ppar 的所有子模式都完成时，Ppar 就完成了。

(
Ppar([
    Pbind(\dur, 0.2, \midinote, Pseq([62, 65, 69, 72], inf)),
    Pbind(\dur, 0.4, \midinote, Pseq([50, 45], inf))
]).play
)


(
// Ppar 可以嵌套
Ppar([
    Pbind(
        \dur, Prand([0.2, 0.4, 0.6], inf),
        \midinote, Prand([72, 74, 76, 77, 79, 81], inf),
        \db, -26,
        \legato, 1.1
    ),
    Pseq([
        Pbind(\dur, 3.2, \freq, Pseq([\rest]) ),
        Prand([
            Ppar([
                Pbind(\dur, 0.2, \pan,  0.5, \midinote, Pseq([60, 64, 67, 64])),
                Pbind(\dur, 0.4, \pan, -0.5, \midinote, Pseq([48, 43]))
            ]),
            Ppar([
                Pbind(\dur, 0.2, \pan,  0.5, \midinote, Pseq([62, 65, 69, 65])),
                Pbind(\dur, 0.4, \pan, -0.5, \midinote, Pseq([50, 45]))
            ]),
            Ppar([
                Pbind(\dur, 0.2, \pan,  0.5, \midinote, Pseq([64, 67, 71, 67])),
                Pbind(\dur, 0.4, \pan, -0.5, \midinote, Pseq([52, 47]))
            ])
        ], 12)
    ], inf)
], inf).play;
)

Ptpar

Ppar 模式会同时启动其所有子模式。

Ptpar 模式在每个子模式之前包含一个起始时间参数，允许子模式在模式内以某个时间延迟启动。起始时间以拍为单位给出。

(
var makePattern, durpat;

durpat = Pseq([ Pgeom(0.05, 1.1, 24), Pgeom(0.5, 0.909, 24) ], 2);

makePattern = { arg note, db, pan;
    Pbind( \dur, durpat, \db, db, \pan, pan, \midinote, Pseq([note, note-4], inf) );
};

Ptpar([
    0.0, makePattern.value(53, -20, -0.9),
    2.0, makePattern.value(60, -23, -0.3),
    4.0, makePattern.value(67, -26,  0.3),
    6.0, makePattern.value(74, -29,  0.9)
], inf).play;
)

当 Ptpar 模式启动时，时间参数会被发送 value 消息，因此你可以使用函数来指定时间。

(
var makePattern, durpat;

durpat = Pseq([ Pgeom(0.05, 1.1, 24), Pgeom(0.5, 0.909, 24) ], 2);

makePattern = { arg note, db, pan;
    Pbind( \dur, durpat, \db, db, \pan, pan, \midinote, Pseq([note, note-4], inf) );
};

Ptpar([
    { 0.0 }, makePattern.value(53, -20, -0.9),
    { 8.0.rand }, makePattern.value(60, -23, -0.3),
    { 8.0.rand }, makePattern.value(67, -26,  0.3),
    { 8.0.rand }, makePattern.value(74, -29,  0.9)
], inf).play;
)

FilterPatterns 与转换

FilterPatterns 接受一个已有的模式并对其属性应用某种修改。

Padd、Pmul、Pset、Pstretch

有一种更简单的方式来编写第 5 部分中给出的调式移调示例。事实上，先前的示例是在设置 mtranspose 和 ctranspose 的值，这不是改变这些变量的最佳方式，因为这会抹除父模式对它们所做的任何修改。更好的做法是取这些属性的当前值，并为其加上一个值。

Padd 滤波器取属性的当前值并向其添加一个值。

(
// 调式移调
var pattern;

// 定义基本模式
pattern = Pbind(
    \dur, 0.15,
    \degree, Pseq([ Pshuf(#[-7,-3,0,2,4,7], 4), Pseq([0,1,2,3,4,5,6,7]) ], 1)
);

Pseq([
    pattern,        // 未移调
    Padd(\mtranspose, 1, pattern),    // 调式移调升高 1 度
    Padd(\mtranspose, 2, pattern)    // 调式移调升高 2 度
], inf).play
)

同样，Pmul 将属性的当前值乘以一个值。Pset 将属性设置为一个值。

为了正确处理时长，应使用 Pstretch。

(
// 使用 Pstretch 进行节拍拉伸
var pattern;

// 定义基本模式
pattern = Pbind(
    \dur, 0.15,
    \degree, Pseq([ Pshuf(#[-7,-3,0,2,4,7], 4), Pseq([0,1,2,3,4,5,6,7]) ], 1)
);

Pseq([
    pattern,        // normal
    Pstretch(0.5, pattern),    // 将时长拉伸为原来的 1/2
    Pstretch(2.0, pattern)    // 将时长拉伸 2 倍
], inf).play
)

Paddp、Pmulp、Psetp、Pstretchp

事实上，模态移调示例还有一个更短的版本。Paddp 读取一个模式以获取用于加到某个属性上的值，并在每次用新值修改后完整播放第二个模式一次。

(
// 调式移调
var pattern;

// 定义基本模式
pattern = Pbind(
    \dur, 0.15,
    \degree, Pseq([ Pshuf(#[-7,-3,0,2,4,7], 4), Pseq([0,1,2,3,4,5,6,7]) ], 1)
);

Paddp(
    \mtranspose,        // 要修改的属性
    Pseq([0,1,2], inf),    // 一个值模式，作为用于加到 mtranspose 的值来源
    pattern            // 要修改的模式
).play
)

嵌套修改：

(
// 调式移调
var pat1, pat2;

// 定义基本模式
pat1 = Pbind(
    \dur, 0.15,
    \degree, Pseq([ Pshuf(#[-7,-3,0,2,4,7], 4), Pseq([0,1,2,3,4,5,6,7]) ], 1)
);

pat2 = Paddp(
    \mtranspose,    // 要修改的属性
    Pseq([0,1,2]),    // 一个值模式，作为用于加到 mtranspose 的值来源
    Ppar([
        pat1,
        Padd(\mtranspose, -3, pat1),    // 下行四度
        Padd(\mtranspose, 2, pat1)    // 升高三度
    ])
);

Pseq([
    pat1,    // 未修改的模式
    pat2,    // 并行序列
    Pstretch(1.5, pat2)    // 并行序列拉伸 3/2
], inf).play
)

另一个使用 Paddp 的示例：

(
var chord;
chord = Prand([[53, 58, 64],[53, 60, 64],[57,60,65]]);
Paddp(\ctranspose, Prand([-1,0,2,4,5], inf),
    Ppar([
        Pbind(    // 旋律部分
            \dur, Prand([0.2, 0.4, 0.6], inf),
            \midinote, Pxrand([71, 72, 74, 76, 77, 79], 10),
            \db, -26,
            \legato, 1.1
        ),
        Pbind(    // 和声部分
            \pan, 0.4,
            \dur, Pseq([0.1, 0.5, 0.4, 0.6], 4),
            \midinote, Pseq([chord,\rest,chord,\rest], 4)
        ),
        Pbind(    // 低音部分
            \pan, -0.4,
            \dur, 0.4,
            \midinote, Pseq([38, 45, 38, 36], 4)
        )
    ])
).play
)


(
// 半音移调
var pattern;

// 定义基本模式
pattern = Pbind(
    \dur, 0.1,
    \degree, Pseq([0,1,2,3,4,5,6,7])
);

Paddp(
    \ctranspose,        // 要修改的属性
    Pseries(0,1,12),    // 一个值模式，作为与 ctranspose 相乘的值来源
    pattern            // 要修改的模式
).play
)


(
// 拍时间拉伸
var pattern;

// 定义基本模式
pattern = Pbind(
    \dur, 0.1,
    \degree, Pseq([0,1,2,3,4,5,6,7])
);

Pstretchp(
    Pseq([1,2,3], inf),    // 一个值模式，作为用于与 stretch 相乘的值来源
    pattern            // 要修改的模式
).play
)

Pbindf

Pbindf 与 Pbind 类似，区别在于它将所有绑定的符号合并到从子模式获取的事件中。它像 Pbind 一样以成对的方式接收相同的初始参数，并在最后一个参数中指定一个要修改的附加模式。

(
var pattern;
pattern = Pbind( \midinote, Pseq(#[60, 62, 64, 65, 67, 69, 71, 72]) );

Pseq([
    Pbindf(pattern, \legato, 0.1, \dur, 0.2),
    Pbindf(pattern, \legato, 1.0, \dur, 0.125),
    Pbindf(pattern, \legato, 2.0, \dur, 0.3)
], inf).play
)

模式可用作 Pbindf 的参数。

(
var pattern;
pattern = Pbind( \midinote, Pseq(#[60, 62, 64, 65, 67, 69, 71, 72, 74, 76, 77, 79]) );

Pseq([
    Pbindf(pattern,\legato, 0.1, \dur, Pgeom(0.3, 0.85, inf)),
    Pbindf(pattern,\legato, 1.0, \dur, Pseq([0.3, 0.15], inf)),
    Pbindf(pattern,\legato, 2.0, \dur, Pseq([0.2, 0.2, 0.4], inf))
], inf).play
)
