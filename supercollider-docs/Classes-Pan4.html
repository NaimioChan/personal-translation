Pan4

四声道等功率声像。

MultiOutUGen : UGen : AbstractFunction : Object

另请参阅：Balance2、LinPan2、Pan2、PanAz

说明

四声道等功率声像器。输出顺序为 LeftFront、RightFront、LeftBack、RightBack。

类方法

Pan4.ar(in, xpos: 0.0, ypos: 0.0, level: 1.0)

Pan4.kr(in, xpos: 0.0, ypos: 0.0, level: 1.0)

参数：

in

输入信号。

xpos

X 声像位置，从 -1 到 +1（从左到右）。

ypos

Y 声像位置，从 -1 到 +1（从后到前）。

level

一个控制速率电平输入。

实例方法

示例

// 在立体声设置下，你只会听到前面两个声道。

{ Pan4.ar(PinkNoise.ar, FSinOsc.kr(2), FSinOsc.kr(1.2), 0.3)) }.play;


{ Pan4.ar(PinkNoise.ar, -1,  0, 0.3) }.play; // 左对
{ Pan4.ar(PinkNoise.ar,  1,  0, 0.3) }.play; // 右侧一对
{ Pan4.ar(PinkNoise.ar,  0, -1, 0.3) }.play; // 后对
{ Pan4.ar(PinkNoise.ar,  0,  1, 0.3) }.play; // 前一对

{ Pan4.ar(PinkNoise.ar,  0,  0, 0.3) }.play; // center
