Ndef

节点代理定义

NodeProxy : BusPlug : AbstractFunction : Object

另请参阅：ProxySpace、Tdef

说明

Ndef 按键注册 synth。对已注册 synth 的所有访问都通过该键经由 Ndef 类进行。已注册的 synth 可以在播放时被其他 synth 替换。一个 synth 及其替换者可以自动交叉淡化，且替换时间可以被量化。

Ndef 是对代理的引用，是 ProxySpace 的替代方案。所有方法均继承自 NodeProxy。

Ndef(key)    // 返回该实例
Ndef(key, obj)    // 存储对象并返回实例，类似 Tdef 和 Pdef。

图形编辑器概览所有当前 Ndef：NdefMixer。总体概览：JITLib。

第一个示例

s.boot;

Ndef(\a).play; // 播放到硬件输出。
Ndef(\a).fadeTime = 2; // fadeTime 指定交叉淡化
// 设置源
Ndef(\a, { SinOsc.ar([350, 351.3], 0, 0.2) });
Ndef(\a, { Pulse.ar([350, 351.3] / 4, 0.4, 0.2) });
Ndef(\a, Pbind(\dur, 0.03, \freq, Pbrown(0, 1, 0.1, inf).linexp(0, 1, 200, 350)));

Ndef(\a, { Ringz.ar(Ndef.ar(\b), [350, 351.3] * 2, 0.4) });
Ndef(\b, { Impulse.ar([5, 7]/2, [0, 0.5], 0.15) });

Ndef.clear(3); // 3 秒后清除全部

类方法

Creation

Ndef.new(key, object)

返回一个新的节点代理并将其存储在一个全局 ProxySpace 中，以该键作为索引。如果那里已经有一个 Ndef，则用新对象替换它的对象。该对象可以是任何受支持的类，参见 NodeProxy: Supported sources 帮助。在内部，所有实例都保存在一个 ProxySpace 中。当源被设置时，会调用 EnvironmentRedirect: dispatch 函数。

参数：

key

代理的名称（通常是一个符号）。如果只给出键而没有对象，则返回代理对象：

Ndef(\x) // 获取 proxy

如果 key 是一个关联（association），它会被解释为 key -> 服务器名称。（顺序在 SC3.3 中已改变！）。如果未给出名称，则使用 Ndef 首次调用时的默认服务器。（要更改它，参见 *defaultServer）。

object

一个对象

Ndef(\x, { Dust.ar }); // 返回代理并设置源对象。

Ndef.ar(key, numChannels, offset: 0)

等价于 *new(key).ar(numChannels, offset)（参见 BusPlug: -ar）

Ndef.kr(key, numChannels, offset: 0)

等价于 *new(key).kr(numChannels, offset)（参见 BusPlug: -kr）

Ndef.clear(fadeTime)

清除 Ndef 类所有代理空间中的所有 Ndef

Ndef.clearDict(fadeTime)

清除所有 Ndef 并移除 Ndef 类的所有 proxyspace

Ndef.defaultServer

Ndef.defaultServer = value

设置默认服务器（默认值：Server.default）

Ndef.all

Ndef.all = value

返回所有服务器的字典，指向为每个服务器包含 Ndef 的代理空间。

Ndef.all;

Ndef.dictFor(server)

返回给定服务器的 proxyspace。

Ndef.dictFor(s);

实例方法

.proxyspace

返回此实例的 proxyspace

Ndef(\x).proxyspace

设置默认参数

每个 Ndef 背后，在所使用的每个服务器上都有一个单一的 ProxySpace 实例（通常只是默认服务器的那个）。这个 ProxySpace 为可设置的代理保留默认值。这可以通过以下方式完成：

// 设置默认量化
Ndef(\x).proxyspace.quant = 1.0;

以这种方式还可以设置的其他值为：clock, fadeTime, quant, reshaping, awake。

示例

s.boot;

Ndef(\sound).play;
Ndef(\sound).fadeTime = 1;
Ndef(\sound, { SinOsc.ar([600, 635], 0, SinOsc.kr(2).max(0) * 0.2) });
Ndef(\sound, { SinOsc.ar([600, 635] * 3, 0, SinOsc.kr(2 * 3).max(0) * 0.2) });
Ndef(\sound, { SinOsc.ar([600, 635] * 2, 0, SinOsc.kr(2 * 3).max(0) * 0.2) });
Ndef(\sound, Pbind(\dur, 0.17, \freq, Pfunc({ rrand(300, 700) })));

Ndef(\lfo, { LFNoise1.kr(3, 400, 800) });
Ndef(\sound).map(\freq, Ndef(\lfo));
Ndef(\sound, { |freq| SinOsc.ar([600, 635] + freq, 0, SinOsc.kr(2 * 3).max(0) * 0.2) });
Ndef(\lfo, { LFNoise1.kr(300, 400, 800) });

Ndef.clear; // 清除所有 Ndef

设置和映射参数

Ndef(\sound, { |freq = 56, numHarm = 10| Blip.ar(freq, numHarm, 30) * 0.2 }).play;
Ndef(\sound).set(\freq, 15);
Ndef(\sound).set(\freq, 15, \numHarm, 100);

Ndef(\sound).stop;

保留参数

如果给定的 UGen 函数中不存在三个参数，则会自动指定它们。你可以覆盖它们的使用：[\out, \gate, \fadeTime]

自定义包络

如果传递给代理的 UGen 函数有自己的包络，并且该包络可以释放 synth，则节点代理使用此包络而不是创建自己的包络。如果你提供了 fadeTime 参数，则将使用代理的 fadeTime。

Ndef(\sound).fadeTime = 3;
(
Ndef(\sound, { |fadeTime = 1, gate = 1|
    var e = Env.adsr(fadeTime, 0.01, 0.4, fadeTime).ar(2, gate);
    SinOsc.ar(100 + (e * 700), SinOsc.ar(208) * (1 - e) * 6) * e * 0.1
}).play
)

使用 <<> 运算符进行简单的音频路由

(
Ndef(\sound, {
    RHPF.ar(
        \in1.ar([0, 0]) * \in2.ar([0, 0]),
        \freq.kr(6000, 2),
        \rq.kr(0.2)
    ) * 7
}).play;
Ndef(\sound).fadeTime = 0.2;    // 避免刺耳的咔哒声
)

Ndef(\a, { SinOsc.ar(MouseX.kr(300, 1000, 1) * [1, 1.2], \phase.ar([0, 0]) * 0.2) });
Ndef(\b, { LFDNoise3.ar(MouseY.kr(3, 1000, 1) * [1, 1.2]) });
Ndef(\c, { LFTri.ar(MouseY.kr(3, 10, 1) * [1, 1.2]).max(0) });
Ndef(\a).fadeTime = 0.2;    // 再次避免刺耳的咔嗒声

Ndef(\sound) <<>.in1 Ndef(\a);
Ndef(\sound) <<>.in2 Ndef(\b);
Ndef(\sound) <<>.in2 Ndef(\c);
Ndef(\a) <<>.phase Ndef(\sound);
Ndef(\a) <<>.phase nil;    // unmap
Ndef.clear(3);        // 淡出并清除所有 Ndef

嵌入多声道模式，并行播放流

在 SuperCollider 中，控制多声道序列化流并独立控制滤波和节点顺序是一个困难的话题。然而，使用 Ndef（或其父类 NodeProxy 或 ProxySpace）可能提供一个方便的解决方案。

// 一个 SynthDef，实例化时产生单声道 grain
(
SynthDef(\grain, { |out = 0, freq = 300, amp = 0.3|
    OffsetOut.ar(out, Pulse.ar(freq) * EnvGen.kr(Env.perc, doneAction: Done.freeSelf) * amp)
}).add;
)

// 声道数量
~numChans = 5;

// Pattern 中的值可以通过多种方式设置
// 这里我们使用 control buses，除了 \dur，它
// 在并行播放的流中不接受 control bus
// 因此我们使用 PatternProxies
~durs = ~numChans.collect({ |i| PatternProxy(0.5 + (i/10)) });

// 其他参数也可以在 PatternProxy 中控制，
// 不过控制总线也很方便
~freqs = Bus.control(s, ~numChans);
~freqs.setn(Array.geom(~numChans, 300, 1.1));
~amps = Bus.control(s, ~numChans);
~amps.setn(0.2 ! ~numChans);

// Pattern：一个 Ppar 为每个声道持有一个 Pbind，
// 全部包装在一个 Pdef 中
(
Pdef(\ppar,
    Ppar({ |i|
        Pbind(
            \instrument, \grain,
            // 我们只设置单个通道
            \dur, ~durs[i],
            \freq, ~freqs.subBus(i).asMap,
            \amp, ~amps.subBus(i).asMap,
            // 该 Pattern 将播放到一个尚不知晓的私有总线
            // 我们只想确保偏移量正确
            \channelOffset, i,
        )
    } ! ~numChans)
)
)

// 初始化一个 Ndef，用 Pdef 作为它的源
// 确保通过调用 'mold' 将 Ndef 初始化为正确的通道数
Ndef(\ppar).mold(~numChans, \audio, \elastic);
Ndef(\ppar)[0] = Pdef(\ppar);

// 将来自 Ndef(\ppar) 的 5 声道音频混合下混为立体声
// Splay 会将声道分散到立体声全景中
// 可以使用耳机来清晰地识别效果
Ndef(\stereo, { Splay.ar(\in.ar(0 ! ~numChans)) });

// 连接这些 Ndef，使 Ndef(\ppar) 的输出馈入 Ndef(\stereo) 的输入
Ndef(\stereo) <<> Ndef(\ppar);
Ndef(\stereo).play;

// 更改时长
~durs.do({ |pp, i| pp.source = Pseq(Array.fib(5, i/10 + 0.1, i+1/5), inf) });
~durs.do({ |pp, i| pp.source = 0.5 + (i/10) });
~durs.do({ |pp| pp.source.postcs });

// 频率
~freqs.setn(Array.geom(~numChans, 250, 1.6));
~freqs.setn(Array.geom(~numChans, 300, 1.1));

// 添加一个滤波器 Ndef
(
Ndef(\filter, {
    HPF.ar(
        \in.ar(0 ! ~numChans),
        SinOsc.ar({ |i| 2 + i }  ! ~numChans) + 1 * \multFreq.kr(Array.geom(~numChans, 400, 2))
    )
}).mold(~numChans, \audio, \elastic);
)

// 设置 fadeTime 以实现平滑过渡，并将滤波器添加到链中
#[ppar, stereo, filter].do({ |k| Ndef(k).fadeTime_(3) });
Ndef(\stereo) <<> Ndef(\filter) <<> Ndef(\ppar);

// 设置滤波器参数，考虑 fadeTime
Ndef(\filter).xset(\multFreq, Array.rand(~numChans, 20, 10000));

Ndef.clear;
Pdef.clear;

制作副本

copy

由于 Ndef 是给定键的唯一实例，只能通过提供新键来复制它。另请参阅：NodeProxy: -copy。

Ndef(\x, { SinOsc.ar(Rand(500, 900)) * 0.1 }).play;
Ndef(\x).copy(\y);
Ndef(\y).play;

参数：

newKey

一个有效的新键，通常是一个 Symbol

Recursion

Ndef 可以递归使用。如下结构可以正常工作：

Ndef(\sound, { SinOsc.ar([600, 635], Ndef.ar(\sound), LFNoise1.kr(2).max(0) * 0.2) });
Ndef(\sound).play;
Ndef.clear;

这是因为存在反馈延迟（服务器的 block size），通常为 64 个采样，因此计算可以在其自身的输出上迭代。对于单样本反馈，参见：

(Platform.resourceDir +/+ "examples/demonstrations/single_sample_feedback.scd").openDocument;

使用不同的服务器

// 创建一个新的服务器
a = Server(\foo, NetAddr("127.0.0.1", 57123)).boot.makeWindow;
Ndef(\sound, { SinOsc.ar([600, 635]) * SinOsc.kr(2).max(0) * 0.2 }).play; // 在默认设备上播放
Ndef(\sound -> \foo, { SinOsc.ar([700, 745]) * SinOsc.kr(2).max(0) * 0.2 }).play; // 在 foo 上播放

// 清除定义
Ndef(\sound -> \foo).clear(3);
Ndef(\sound).clear(3);

a.dump;    // 显示新服务器的设置
a.quit;    // 终止新服务器
