Phasor

两个电平之间可重置的线性斜坡。

UGen : AbstractFunction : Object

说明

Phasor 是在起始值和结束值之间线性递增的斜坡。当其触发输入从非正变为正时，Phasor 的输出将跳转到其复位位置。到达斜坡末端后，Phasor 将回绕到其起始位置。

注意： 注意：由于 end 被定义为回绕点，其值实际上永远不会被输出。

注意： 如果希望 Phasor 输出一个频率为 freq、在 start 与 end 之间振荡的信号，则速率应为 (end - start) * freq / sr，其中 sr 是采样率。

Phasor 通常用作 BufRd 和 BufWr 的索引控制。

类方法

Phasor.ar(trig: 0.0, rate: 1.0, start: 0.0, end: 1.0, resetPos: 0.0)

Phasor.kr(trig: 0.0, rate: 1.0, start: 0.0, end: 1.0, resetPos: 0.0)

参数：

trig

触发时，跳转到 resetPos（默认值：0，等同于 start）。

rate

每个采样的变化量，即以 1 的速率，每个采样的值将比前一个采样大 1。

start

斜坡的起点。

end

斜坡的终点。

resetPos

收到触发器时要跳转到的值。

实例方法

示例

// 基础用法：在 'start' 和 'end' 之间 ramp
// 注意 ramp 结束于 9，而不是 10
{ Phasor.kr(0, 1, start: 0, end: 10) }.plot(0.03).plotMode_(\dlines)

// 在触发时：ramp 跳转到 'resetPos'，运行到 'end' 然后回绕到 'start'
// 注意 ramp 从 'resetPos' 开始，因为它在第一个采样时立即收到一个触发
(
{
    var trig = Impulse.kr(ControlRate.ir/5);
    var ramp = Phasor.kr(trig, 1, start: 0, end: 10, resetPos: 7);
    [ramp, trig * 10]
}.plot(0.03).plotMode_([\dlines, \dstems])
)


// phasor 控制正弦频率：结束频率与第二个正弦波匹配。

(
{ var trig, rate, x, sr;
    rate = MouseX.kr(0.2, 2, 1);
    trig = Impulse.ar(rate);
    sr = SampleRate.ir;
    x = Phasor.ar(trig, rate / sr);
    SinOsc.ar(
        [
            LinLin.kr(x, 0, 1, 600, 1000), // 将范围从 0..1 转换到 600..1000
            1000 // 恒定的第二频率
        ], 0, 0.2)

}.play;
)


// 两个 phasor 控制两个正弦频率：鼠标 y 控制第二个的 resetPos
(
{ var trig, rate, x, sr;
    rate = MouseX.kr(1, 200, 1);
    trig = Impulse.ar(rate);
    sr = SampleRate.ir;
    x = Phasor.ar(trig, rate / sr, 0, 1, [0, MouseY.kr(0, 1)]);
    SinOsc.ar(x * 500 + 500, 0, 0.2)
}.play;
)


// 使用相量索引到声音文件

// 分配一个带声音文件的缓冲区
b = Buffer.read(s, ExampleFiles.child);

// 简单播放（更多示例：见 BufRd）
// 这里的起点和终点定义为 0 和缓冲区中的帧数。
// 这意味着 Phasor 会在循环之前输出从 0 到 numFrames - 1 的值，
// 非常适合驱动 BufRd。（见上文注释）
{ BufRd.ar(1, b.bufnum, Phasor.ar(0, BufRateScale.kr(b.bufnum), 0, BufFrames.kr(b.bufnum))) }.play;


// 两个相位器控制两个声音文件位置：鼠标 y 控制第二个的 resetPos
(
{ var trig, rate, framesInBuffer;
    rate = MouseX.kr(0.1, 100, 1);
    trig = Impulse.ar(rate);
    framesInBuffer = BufFrames.kr(b.bufnum);
    x = Phasor.ar(trig, BufRateScale.kr(b.bufnum), 0, framesInBuffer,
        [0, MouseY.kr(0, framesInBuffer)]);
    BufRd.ar(1, b.bufnum, x);
}.play;
)
