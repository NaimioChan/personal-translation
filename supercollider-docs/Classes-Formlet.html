Formlet

类 FOF 滤波器。

Filter : PureUGen : UGen : AbstractFunction : Object

另请参见：RHPF、RLPF、Resonz、Ringz

说明

这是一个谐振滤波器，其冲激响应类似于在其上叠加了 Decay2 包络的正弦波。可以控制 attacktime 和 decaytime。

Formlet 等价于：

Ringz(in, freq, decaytime) - Ringz(in, freq, attacktime)

该滤波器相比 FOF 的巨大优势在于重叠颗粒的数量没有限制，因为颗粒只是滤波器的脉冲响应。

注意： 所得信号的幅度取决于服务器的采样率。详情请参见 Ringz: 与采样率的交互。

类方法

Formlet.ar(in: 0.0, freq: 440.0, attacktime: 1.0, decaytime: 1.0, mul: 1.0, add: 0.0)

Formlet.kr(in: 0.0, freq: 440.0, attacktime: 1.0, decaytime: 1.0, mul: 1.0, add: 0.0)

参数：

in

输入信号。

freq

以赫兹为单位的共振频率。

attacktime

60 dB 起音时间，单位为秒。

decaytime

以秒为单位的 60 dB 衰减时间。

mul

add

讨论：

请注意，如果 attacktime == decaytime，则信号相互抵消；如果 attacktime > decaytime，则冲激响应反转。

实例方法

示例

{ Formlet.ar(Impulse.ar(20, 0.5), 1000, 0.01, 0.1) }.play;

{ Formlet.ar(Blip.ar(XLine.kr(10, 400, 8), 1000, 0.1), 1000, 0.01, 0.1) }.play;

(
// 调制共振峰频率
{
    var in;
    in = Blip.ar(SinOsc.kr(5, 0, 20, 300), 1000, 0.1);
    Formlet.ar(in, XLine.kr(1500, 700, 8), 0.005, 0.04);
}.play;
)

(
// 鼠标控制频率和衰减时间。
{
    var in;
    in = Blip.ar(SinOsc.kr(5, 0, 20, 300), 1000, 0.1);
    Formlet.ar(in,
        0.005, MouseX.kr(0.01, 0.2, 1));
        MouseY.kr(700, 2000, 1),
}.play;
)

(
// 鼠标控制频率和衰减时间。
{
    var freq;
    freq = Formlet.kr(
        Dust.kr(10 ! 2),
        MouseY.kr(7, 200, 1),
        0.005, MouseX.kr(0.1, 2, 1)
    );
    SinOsc.ar(freq * 200 + [500, 600] - 100) * 0.2
}.play;
)
