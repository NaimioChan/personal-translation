Spec

输入数据类型规范

Object

参见：ControlSpec、Warp

子类：ControlSpec

说明

Spec 指定需要或允许何种输入，以及这些参数的范围。这是一个抽象类——最常见的子类是：ControlSpec。

ControlSpec 被 GUI 滑块和旋钮用于指定控件的范围和曲线。输入数据类型对函数、GUI 界面对象（滑块等）很有用，也可用于内省。

类 Spec 本身持有一个常见规格的全局 IdentityDictionary。存储规格时使用的名称随后可作为简写来引用规格：

\freq.asSpec

一些常用映射在 ControlSpec.initClass 中初始化。你可以按需添加或覆盖映射。crucial 库（以 quark 形式提供，见 Quarks）定义了许多额外的子类。参见文件 quarks/cruciallib/Instr/MoreSpecs.sc

类方法

Spec.add(name, args)

向全局 spec 字典添加一个 spec。该项将使用 .asSpec 转换为 spec。

示例

Spec.add(\helpExp, ControlSpec(0.01, 1.0, \exp));

// 数组将被转换为控制规格
Spec.add(\helpLin, [0, 1, \lin, 0.011, 0.01]);

// 将查找符号，使用现有的 \freq 规格来代替 \helpLin2
Spec.add(\helpLin2, \freq);

// 现有规格：
Spec.add(\helpLin, ControlSpec(0.ampdb, 1.ampdb, \db, units: " dB"));
