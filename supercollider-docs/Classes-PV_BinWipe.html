PV_BinWipe

合并来自两个输入的低频段和高频段。

PV_ChainUGen : WidthFirstUGen : UGen : AbstractFunction : Object

说明

从一个输入复制低频段，从另一个输入复制高频段。

类方法

PV_BinWipe.new(bufferA, bufferB, wipe: 0.0)

参数：

bufferA

FFT 缓冲区 A。

bufferB

FFT 缓冲区 B。

wipe

范围可以在 -1 到 +1 之间。

如果 wipe == 0，则输出与 bufferA 相同。

如果 wipe > 0，则从底部开始用 bufferB 中的 bin 替换。

如果 wipe < 0，则它开始从顶部向下用 bufferB 中的 bin 进行替换。

实例方法

示例

s.boot;
b = Buffer.read(s, ExampleFiles.child);

(
SynthDef("help-binWipe", { |out = 0|
    var inA, chainA, inB, chainB, chain;
    inA = WhiteNoise.ar(0.2);
    inB = LFSaw.ar(100, 0, 0.2);
    chainA = FFT(LocalBuf(2048), inA);
    chainB = FFT(LocalBuf(2048), inB);
    chain = PV_BinWipe(chainA, chainB, MouseX.kr(-1, 1));
    Out.ar(out, 0.1 * IFFT(chain).dup);
}).play(s);
)

(
SynthDef("help-binWipe2", { |out = 0, soundBufnum = 2|
    var inA, chainA, inB, chainB, chain;
    inA = WhiteNoise.ar(0.2);
    inB = PlayBuf.ar(1, soundBufnum, BufRateScale.kr(soundBufnum), loop: 1);
    chainA = FFT(LocalBuf(2048), inA);
    chainB = FFT(LocalBuf(2048), inB);
    chain = PV_BinWipe(chainA, chainB, MouseX.kr(-1, 1));
    Out.ar(out, 0.1 * IFFT(chain).dup);
}).play(s, [\soundBufnum, b]);
)
