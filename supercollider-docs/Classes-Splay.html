Splay

Splay 将一组通道展开到立体声场中

UGen : AbstractFunction : Object

另请参见：SplayAz、SplayZ、LevelComp、Level Compensation when Mixing and Panning

说明

Splay 将一组声道铺展到立体声场中。可选参数为 spread 和 center，以及等功率的 levelCompensation。立体声位置的公式为 ((0 .. (n - 1)) * (2 / (n - 1)) - 1) * spread + center

类方法

Splay.ar(inArray, spread: 1, level: 1, center: 0.0, levelComp: true)

Splay.kr(inArray, spread: 1, level: 1, center: 0.0, levelComp: true)

参数：

inArray

要分配到两个立体声对上的通道数组

spread

当 spread = 0 时，所有声道都位于中央；当 spread = 1 时，它们具有最大分布

level

所有通道的振幅乘数

center

移动分布的中心。

levelComp

一个标志或数值：

  • true：保持等功率，使整体响度保持不变。
  • false：关闭 / 无电平变化，

  • 介于 0.0 和 1.0 之间的浮点数：levelComp 因子的平滑调节：

    • 0.0 为无 -> 因子 1
    • 0.5 为等功率 -> 因子 (1/n).squared
    • 1.0 为等幅 -> 因子 (1/n)

Splay.arFill(n, function, spread: 1, level: 1, center: 0.0, levelComp: true)

类似于 Mix:arFill，此方法接受一个用于生成各通道的函数。计数索引会被传递给该函数。

参数：

n

通道数

function

返回各通道的函数

spread

当 spread = 0 时，所有声道都位于中央；当 spread = 1 时，它们具有最大分布

level

所有通道的振幅乘数

center

移动分布的中心。

levelComp

见上文

实例方法

示例

基本用法：

// 将 10 个声道的聲音 splay 到 2 个声道
(
x = { |spread = 1, level = 0.2, center = 0.0|
    var numchans = 10;
    Splay.ar(
        SinOsc.ar({ |i| LFNoise2.kr(1).exprange(200, 4000) } ! numchans),
        spread,
        level,
        center
        // 使用 levelComp 默认值 true
    );
}.play;
)

s.meter;
s.scope;

// 动态更改设置：

x.set(\spread, 1,   \center, 0);   // full stereo
x.set(\spread, 0.5, \center, 0);   // 较窄
x.set(\spread, 0,   \center, 0);   // mono center
x.set(\spread, 0.5, \center, 0.5); // 从中心向右扩散
x.set(\spread, 0,   \center, -1);  // 全部向左
x.set(\spread, 1,   \center, 0);   // full stereo

// 用 arFill 编写的类似示例：
(
x = { |spread = 1, level = 0.2, center = 0.0|
    var numchans = 10;
    Splay.arFill(numchans,
        { |i| SinOsc.ar(LFNoise2.kr(rrand(10, 20), 200, i + 3 * 100))  },
        spread,
        level,
        center
    );
}.play;
)

注意： levelComp 新版本接受多个输入选项：true、false，与之前一样用于粗略的等功率电平补偿，以及新添加的：0 到 1 之间的浮点数。这是为了提供更多电平补偿的选择，例如等最大幅度。

完整讨论请参见 LevelComp；这里是 levelComp 各变体的概述：

// 默认是等功率补偿：level / (numchans.sqrt)
Splay.ar(ins, spread, level, center); // 默认值为 true
// 为清晰起见显式写出
Splay.ar(ins, spread, level, center, levelComp: true);
// 或者对浮点电平 comp 做等功率处理
Splay.ar(ins, spread, level, center, levelComp: 0.5); //

// 通过等幅压缩获得最大峰值安全度：level / numchans
Splay.ar(ins, spread, level, center, levelComp: 1);
// 或者手动计算：
Splay.ar(ins, spread, level / ins.size, center, levelComp: false);

// 无补偿，仅手动调整电平
Splay.ar(ins, spread, level, center, levelComp: false);
Splay.ar(ins, spread, level, center, levelComp: 0);

// levelComp 以浮点数表示：level / numchans.pow(levelComp)，
// 因此 0.0 表示不补偿：level / 1；
//    0.5 表示等功率：level / (numchans.sqrt)
//    1.0 表示等幅度：level / (numchans)
// 可用于例如在等功率和等幅度之间进行调节：
Splay.ar(ins, spread, level, center, levelComp: 0.75);
