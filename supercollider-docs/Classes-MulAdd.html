MulAdd

对信号进行乘法和加法

UGen : AbstractFunction : Object

说明

将信号乘以 mul 并加上 add。此 UGen 非常高效（例如，它会执行各种优化检查）。它在整个 SuperCollider 中被大量用于在服务器上执行乘法和加法运算；事实上，许多 UGen 中的 mul 和 add 参数正是由它来“真正”执行的。

另请参阅 UGen 帮助文件中关于 mul 和 add 参数的讨论。

类方法

MulAdd.new(in, mul: 1.0, add: 0.0)

参数：

in

输入信号

mul

乘以该值

add

添加此值

讨论：

等同于：

in.madd(mul, add)

未文档化的类方法

MulAdd.canBeMulAdd(in, mul, add)

实例方法

示例

s.boot;

// SinOsc 的 mul 和 add 参数本身就使用 MulAdd！
// 这两个示例将创建完全相同的 synth 图：
x = { SinOsc.ar(440, 0, 0.1, 0.05) }.play(s);
x.trace; // 你应该会在跟踪中看到一个 "MulAdd"
x.free;

x = { MulAdd(SinOsc.ar(440, 0), 0.1, 0.05) }.play(s);
x.trace;
x.free;

// 事实上这也会产生相同的图形——分别的乘法和加法被优化为一个 MulAdd
x = { SinOsc.ar(440, 0) * 0.1 + 0.05 }.play(s);
x.trace;
x.free;

（注意："trace" 消息在 Node 的帮助文件中有描述。）
