模式指南食谱 06：乐句网络

通过短语网络进行序列编排，使用 PmonoArtic 来发音音符

参见：Pattern Guide Cookbook 05: Using Samples、Pattern Guide Cookbook 07: Rhythmic Variations

通过乐句网络进行序列编排

使用 PmonoArtic 表达音符

这里一举两得！

大多数传统合成器都有一种模式：在前一个音符仍在延音时演奏一个音符，会从一个音符滑音到另一个音符。PmonoArtic 模式根据事件的 sustain 值来实现这一点。delta 值是直到下一个事件的拍数；sustain 是直到音符释放的拍数。如果 sustain 短于 delta，音符应提前切断，下一个事件应产生一个新的 Synth。

该示例使用 Pfsm（有限状态机）以部分随机化的顺序排列一组预定义的乐句。每个乐句后面都跟着一个列表，指向可以合理地跟随当前乐句的乐句。也就是说，从乐句 1 到乐句 2 可能具有音乐意义，但从 1 到 3 则不然。为 1 适当地定义后继者可以确保不会做出无意义的转换。

这是一个很长的示例，但这只是因为其中包含许多乐句。结构非常简单：只是一组由 Pfsm 依次选择的乐句。

- 第三方扩展提醒：在本例中，下一个乐句的选择通过重复数组元素来显式加权，例如 #[1, 1, 1, 1, 2, 2, 3, 3, 4, 4, 5]。更优雅的方式是使用 MathLib quark 中的 WeighBag 类。

// 以下两者等价：
a = #[1, 1, 1, 1, 2, 2, 3, 3, 4, 4, 5];
({ a.choose } ! 100).histo(5, 1, 5);

a = WeighBag.with((1..5), #[4, 2, 2, 2, 1]);
({ a.wchoose } ! 100).histo(5, 1, 5);

// 这个 SynthDef 有强烈的起音，强调了发音
SynthDef(\sawpulse, { |out, freq = 440, gate = 0.5, plfofreq = 6, mw = 0, ffreq = 2000, rq = 0.3, freqlag = 0.05, amp = 1|
    var sig, plfo, fcurve;
    plfo = SinOsc.kr(plfofreq, mul:mw, add:1);
    freq = Lag.kr(freq, freqlag) * plfo;
    fcurve = EnvGen.kr(Env.adsr(0, 0.3, 0.1, 20), gate);
    fcurve = (fcurve - 1).madd(0.7, 1) * ffreq;
    sig = Mix.ar([Pulse.ar(freq, 0.9), Saw.ar(freq*1.007)]);
    sig = RLPF.ar(sig, fcurve, rq)
        * EnvGen.kr(Env.adsr(0.04, 0.2, 0.6, 0.1), gate, doneAction: Done.freeSelf)
        * amp;
    Out.ar(out, sig ! 2)
}).add;
)
