FlowLayout

一种自动换行视图内容的视图装饰器

另请参阅：SCContainerView、CompositeView

说明

FlowLayout 是一个装饰器，它自动将容器视图中的视图排成一行，并在剩余空间不足以容纳下一个视图时开始新的一行。Window 和 CompositeView 都有 addFlowLayout 方法，这些方法将 FlowLayout 分配给它们的视图装饰器并返回该装饰器。

类方法

.new

参数：

bounds

Rect 的一个实例。通常设置为 parent.bounds。

margin

一个 Point 实例。水平和垂直内边距，父视图的子视图放置在其中。

gap

Point 的一个实例。子视图之间的水平和垂直布局间距。

讨论：

Example:

(
w = Window.new.front;
// 改变间隙和边距来看看它们如何工作
w.view.decorator = FlowLayout(w.view.bounds, 10@10, 20@5);
16.do{ Slider2D(w.view, 80@80).background_(Color.rand) };
)

你也可以这样写：

(
w = Window.new.front;
w.addFlowLayout(10@10, 20@5); // 一个快捷方法，参见 SCContainerView
16.do{ Slider2D(w.view, 80@80).background_(Color.rand) };
)

实例方法

访问实例变量

.nextLine

强制装饰器开始新的一行：

(
w = Window.new;
q = w.addFlowLayout(10@10, 20@5);
Slider2D(w.view, 140@140).background_(Color.rand);
q.nextLine;
Slider2D(w.view, 140@140).background_(Color.rand);
w.front;
)

.indentedRemaining

返回一个 Rect 的实例。这是一个非常有用的方法，它告诉你当前行在下一行开始之前还剩多少空间。indentedRemaining 的高度就是 FlowLayout 中剩余的完整高度。

(
// 通常你只会使用 indentedRemaining 的宽度
w = Window.new;
w.view.decorator = d = FlowLayout.new(w.view.bounds, 10@10, 20@5);
Slider2D(w.view, 150@150).background_(Color.rand);
Slider2D(w.view, 150@150).background_(Color.rand);
Slider(w.view, d.indentedRemaining.width@150) // 将此视图完美适配到右侧 innerBounds
    .background_(Color.rand);
w.front;
)

与以下比较：

( // 这里第三个视图同时适应右侧和底部的 innerBounds
w = Window.new;
w.view.decorator = d = FlowLayout.new(w.view.bounds, 10@10, 20@5);
Slider2D(w.view, 140@140).background_(Color.rand);
Slider2D(w.view, 140@140).background_(Color.rand);
d.nextLine;
Slider2D(w.view, d.indentedRemaining).background_(Color.rand);
w.front;
)

.bounds

装饰器在父视图中放置子视图的外部边界。

参数：

b

一个 Rect 的实例。

.innerBounds

返回按 margin 内缩后的边界。

.gap

子视图之间的水平和垂直布局间隙。

参数：

arg1

一个 Point 的实例。

.margin

水平和垂直的内部边距，父视图的子视图放置在其中。

参数：

arg1

一个 Point 的实例。

子类化与内部方法

以下方法通常不直接使用，或由原语调用。程序员仍可按需调用或重写这些方法。

.left

获取当前的左缩进或手动设置它。

参数：

arg1

一个数字。

讨论：

(
w = Window.new;
w.view.decorator = d = FlowLayout.new(w.view.bounds, 10@10, 20@5);
Slider2D(w.view, 150@150).background_(Color.rand);
d.left_(220); // 手动设置新的缩进
Slider2D(w.view, 150@150).background_(Color.rand);
w.front;
)

.top

获取当前顶部缩进或手动设置它。

参数：

arg1

一个数字。

讨论：

(
w = Window.new;
w.view.decorator = d = FlowLayout.new(w.view.bounds, 10@10, 20@5);
Slider2D(w.view, 150@150).background_(Color.rand);
d.top_(50); // 手动设置新的缩进
Slider2D(w.view, 150@150).background_(Color.rand);
Slider2D(w.view, 150@150).background_(Color.rand);
w.front;
)

.shift

设置当前的左缩进和上缩进（见上文）。

.maxHeight

获取/设置当前位置子视图的最大高度。

参数：

arg1

一个数字。

讨论：

(
w = Window.new;
w.view.decorator = d = FlowLayout.new(w.view.bounds, 10@10, 20@5);
Slider2D(w.view, 100@160).background_(Color.rand);
Slider2D(w.view, 150@150).background_(Color.rand);
"first row maxHeight: " ++ d.maxHeight.postln;
Slider2D(w.view, 150@150).background_(Color.rand);
"second row maxHeight: " ++ d.maxHeight.postln;
w.front;
)

.maxRight

获取/设置当前位置中子视图的最大右边界。

参数：

arg1

一个数字。

讨论：

(
w = Window.new;
w.view.decorator = d = FlowLayout.new(w.view.bounds, 10@10, 20@5);
Slider2D(w.view, 100@160).background_(Color.rand);
"first row maxRight: " ++ d.maxRight.postln;
Slider2D(w.view, 150@150).background_(Color.rand);
Slider2D(w.view, 150@150).background_(Color.rand);
"second row maxRight: " ++ d.maxRight.postln;
w.front;
)

.currentBounds

获取一个 Rect，其 bounds.width 和 height = top + maxHeight。

讨论：

(
w = Window.new;
w.view.decorator = d = FlowLayout.new(w.view.bounds, 10@10, 10@5);
Slider2D(w.view, 100@160).background_(Color.rand);
d.currentBounds.postln;
Slider2D(w.view, 150@150).background_(Color.rand);
d.currentBounds.postln;
Slider2D(w.view, 150@150).background_(Color.rand);
d.currentBounds.postln;
w.front;
)

.used

获取实际使用的空间 Rect。

讨论：

(
w = Window.new;
w.view.decorator = d = FlowLayout.new(w.view.bounds, 10@10, 20@5);
Slider2D(w.view, 100@160).background_(Color.rand);
d.used.postln;
Slider2D(w.view, 150@150).background_(Color.rand);
d.used.postln;
Slider2D(w.view, 150@150).background_(Color.rand);
d.used.postln;
w.front;
)

.reset

将布局机制重置为 0,0。
