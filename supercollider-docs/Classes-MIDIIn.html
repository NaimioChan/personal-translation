MIDIIn

接收 MIDI 消息

Object

另请参阅：MIDIClient、MIDIOut、MIDIFunc、MIDIdef、MIDI、Using MIDI

说明

本文档解释 MIDI 硬件接口类 MIDIIn 的技术细节。

MIDIIn 是一个简单直接的接口。当 MIDI 事件进入 SuperCollider 时，MIDIIn 会求值简单的处理函数。

注意： 对于一般编程，用户不应直接使用 MIDIIn 类。请参阅 MIDIFunc 和 MIDIdef 类，以获得更高级的事件匹配和更灵活的事件处理器处理。

某些 MIDI 消息仅通过 MIDIIn 支持。这些是：sysex、sysrt、smpte。

有关在 SC 中使用 MIDI 的实际注意事项和技巧，请参阅 Using MIDI 帮助文件。

MIDIIn 类

MIDIIn 将从操作系统接收的 MIDI 输入链接到一组用户定义的函数。一次只能有一组 MIDI 输入处理函数处于活动状态，它们存储在以下类变量中：

noteOff、noteOn、polytouch、control、program、touch、bend、sysex、sysrt、smpte

这些函数接收的第一个参数是一个唯一标识符，用于指定数据来源。

类方法

MIDIIn.findPort(deviceName, portName)

按名称搜索已连接的 MIDIEndPoint。

// 列出已连接的输入：
MIDIClient.init;
MIDIClient.sources;

MIDIIn.addFuncTo(what, func)

添加一个 Function 或类似对象，每当收到特定的 MIDI 消息时就会对其求值。此方法优于下面的 setter，因为它不会覆盖任何现有函数。

参数：

what

一个 Symbol，指示要等待的消息类型，取值为 'noteOn'、'noteOff'、'polytouch'、'control'、'program'、'touch'、'bend'、'sysex'、'sysrt'、'smpte' 或 'invalid'（用于无效的 sysex 消息）之一。

func

当一个指定类型的消息被接收时将被求值的 Function 或类似对象。关于求值时传递的参数，参见下面的设置方法。

MIDIIn.removeFuncFrom(what, func)

从每当收到特定 MIDI 消息时要求值的对象列表中移除一个 Function 或类似对象。此方法优于下面的设置方法，因为它会将任何现有的函数保留在原位。

参数：

what

一个 Symbol，表示消息类型，取值为 'noteOn'、'noteOff'、'polytouch'、'control'、'program'、'touch'、'bend'、'sysex'、'sysrt'、'smpte' 或 'invalid'（用于无效的 sysex 消息）之一。

func

要移除的 Function 或类似对象。

MIDIIn.replaceFuncTo(what, func, newFunc)

将列表中待求值的 Function 或类似对象替换为另一个，以便在接收到特定 MIDI 消息时求值。此方法优于下面的设置方法，因为它不会覆盖任何已有函数。

参数：

what

一个 Symbol，指示要等待的消息类型，取值为 'noteOn'、'noteOff'、'polytouch'、'control'、'program'、'touch'、'bend'、'sysex'、'sysrt'、'smpte' 或 'invalid'（用于无效的 sysex 消息）之一。

func

要被替换的 Function 或类似对象。

newFunc

当一个指定类型的消息被接收时将被求值的 Function 或类似对象。关于求值时传递的参数，参见下面的设置方法。

MIDIIn.noteOnZeroAsNoteOff

MIDIIn.noteOnZeroAsNoteOff = value

默认情况下，此标志为 true，SuperCollider 会将速度为 0 的传入 MIDI noteOn 消息解释为 noteOff 消息。如果你不需要这种自动转换，可以将此标志设置为 false

MIDIIn.connectAll(verbose: true)

来自扩展 /usr/local/share/SuperCollider/SCClassLibrary/Platform/linux/SystemOverwrites/extMIDIOut.sc

连接到所有可能的 MIDI 输入。

参数：

verbose

若设为 true（默认），它将打印在 MIDIClient.init 中找到的端口。

MIDIIn.disconnectAll

断开与所有 MIDI 输入的连接。

示例

1 个端口的快速开始

(
MIDIIn.connect;    // 初始化一个单端口 MIDI 接口
// 注册函数：
~noteOff =     { |src, chan, num, vel|    [chan, num, vel / 127].postln };
~noteOn =     { |src, chan, num, vel|    [chan, num, vel / 127].postln };
~polytouch = { |src, chan, num, vel| [chan, num, vel / 127].postln };
~control =     { |src, chan, num, val|    [chan, num, val].postln };
~program =     { |src, chan, prog|        [chan, prog].postln };
~touch =     { |src, chan, pressure|    [chan, pressure].postln };
~bend =     { |src, chan, bend|        [chan, bend - 8192].postln };
~sysex =     { |src, sysex|            sysex.postln };
~sysrt =     { |src, chan, val|        [chan, val].postln };
~smpte =     { |src, chan, val|        [chan, val].postln };
MIDIIn.addFuncTo(\noteOn, ~noteOn);
MIDIIn.addFuncTo(\noteOff, ~noteOff);
MIDIIn.addFuncTo(\polytouch, ~polytouch);
MIDIIn.addFuncTo(\control, ~control);
MIDIIn.addFuncTo(\program, ~program);
MIDIIn.addFuncTo(\touch, ~touch);
MIDIIn.addFuncTo(\bend, ~bend);
MIDIIn.addFuncTo(\sysex, ~sysex);
MIDIIn.addFuncTo(\sysrt, ~sysrt);
MIDIIn.addFuncTo(\smpte, ~smpte);
)

// cleanup
(
MIDIIn.removeFuncFrom(\noteOn, ~noteOn);
MIDIIn.removeFuncFrom(\noteOff, ~noteOff);
MIDIIn.removeFuncFrom(\polytouch, ~polytouch);
MIDIIn.removeFuncFrom(\control, ~control);
MIDIIn.removeFuncFrom(\program, ~program);
MIDIIn.removeFuncFrom(\touch, ~touch);

)

带声音的示例

MIDIIn.connect;
s.boot;

(
SynthDef("sik-goo", { |out, freq = 440, formfreq = 100, gate = 0.0, bwfreq = 800|
    var x;
    x = Formant.ar(
        SinOsc.kr(0.02, 0, 10, freq),
        formfreq,
        bwfreq
    );
    x = EnvGen.kr(Env.adsr, gate, Latch.kr(gate, gate)) * x;
    Out.ar(out, x);
}).add;
)

x = Synth("sik-goo");

// 设置动作：
(
~noteOn = { |src, chan, num, vel|
    x.set(\freq, num.midicps / 4.0);
    x.set(\gate, vel / 200);
    x.set(\formfreq, vel / 127 * 1000);
};
MIDIIn.addFuncTo(\noteOn, ~noteOn);

~noteOff = { |src, chan, num, vel|
    x.set(\gate, 0.0);
};
MIDIIn.addFuncTo(\noteOff, ~noteOff);

~bend = { |src, chan, val|
    // (val * 0.048828125).postln;
    x.set(\bwfreq, val * 0.048828125);
};
MIDIIn.addFuncTo(\bend, ~bend);
)

// cleanup
MIDIIn.removeFuncFrom(\noteOn, ~noteOn);
MIDIIn.removeFuncFrom(\noteOff, ~noteOff);
MIDIIn.removeFuncFrom(\bend, ~bend);

写入总线而不是直接写入 synth

// 我使用了这个，在现场触发 synth 时获得了可接受的延迟。
// 实际延迟可能比 sc2 还低，但我用得还不够多，
// 还无法确定。
// Powerbook G4，512mb 内存。
// - matrix6k@somahq.com

s.boot;

(
SynthDef("moto-rev", { |out, ffreq = 100|
    var x;
    x = RLPF.ar(
        LFPulse.ar(
            SinOsc.kr(0.2, 0, 10, 21),
            [0, 0.1],
            0.1
        ),
        ffreq, 0.1
    ).clip2(0.4);
    Out.ar(out, x);
}).add;
)

b = Bus.control(s);

x = Synth("moto-rev");

// 将合成器的第一个输入（ffreq）映射为
// 从总线的输出索引读取
x.map(0, b);


MIDIIn.connect;
// 设置动作：
(
~noteOn = { |src, chan, num, vel|
    b.value = num.midicps.postln;
};
MIDIIn.addFuncTo(\noteOn, ~noteOn);

~control = { |src, chan, num, val|
    [chan, num, val].postln;
};
MIDIIn.addFuncTo(\control, ~control);

~bend = { |src, chan, val|
    val.postln;
};
MIDIIn.addFuncTo(\bend, ~bend);
)

// cleanup
x.free;
b.free;
MIDIIn.removeFuncFrom(\noteOn, ~noteOn);
MIDIIn.removeFuncFrom(\control, ~control);
MIDIIn.removeFuncFrom(\bend, ~bend);

两个声部的键盘分割

// pbend 到 cutoff，mod 到 rez，7 到 amp
// - matrix6k@somahq.com

s.boot;
(
SynthDef("funk", { |out, freq = 700, amp = 0.2, gate = 1, cutoff = 20000, rez = 1, lfospeed = 0|
    var e, x, env, range, filterfreq;
    e = Env.new([0, 0.1, 0.1, 0], [0, 0.1, 0.1], 'linear', 2);
    env = Env.adsr(0.3, 1, 1, 1);
    range = cutoff -1;
    filterfreq = SinOsc.kr(lfospeed, 0, range, cutoff).abs;
    x = RLPF.ar(Mix.ar([
            Mix.arFill(2, { Saw.ar(freq *2 + 0.2.rand2, amp) }),
            Mix.arFill(2, { Saw.ar(freq *4+ 0.2.rand2, amp) })
        ]),
        EnvGen.kr(env, gate)*filterfreq,
        rez);
    Out.ar(out, x * EnvGen.kr(e, gate, doneAction: Done.freeSelf))
}).add;

SynthDef("strings", { |out, freq = 700, amp = 0.2, gate = 1|
    var x, enve;
    enve = Env.new([0, 0.1, 0.1, 0], [2, 0.1, 1], 'linear', 2);
    x = RLPF.ar(Mix.ar([
            Mix.arFill(2, { Saw.ar(freq +2.rand2, 0.6) }),
            Mix.arFill(2, { Saw.ar(freq *0.5 + 2.rand2, 0.6) })
        ]),
        6000, 1);
    Out.ar(out, x * EnvGen.kr(enve, gate, doneAction: Done.freeSelf))
}).add;
)

(
var keys, cutspec, cutbus, rezspec, rezbus, lfospec, lfobus;
keys = Array.newClear(128);

MIDIClient.init;
MIDIIn.connect(0, MIDIClient.sources.at(0));

g = Group.new;

cutspec = ControlSpec(100, 10000, \linear, 0.001);
cutbus = Bus.new(\control, 1, 1, s);
cutbus.value = 10000;

rezspec = ControlSpec(1, 0, \linear, 0.001);
rezbus = Bus.new(\control, 2, 1, s);
rezbus.value = 1.0;

lfospec = ControlSpec(0, 50, \linear, 0.001);
lfobus = Bus.new(\control, 3, 1, s);

~control = { |src, chan, num, val|
    if(num == 1, {
        rezbus.value = rezspec.map(val/127.0);
    });
    if(num == 7, {
        lfobus.value = lfospec.map(val/127.0).postln;
    });
};
MIDIIn.addFuncTo(\control, ~control);

~bend = { |src, chan, val|
    cutbus.value = cutspec.map(val/16383.0);
};
MIDIIn.addFuncTo(\bend, ~bend);

~noteOn = { |src, chan, num, vel|
    var node;
    if(num < 60, {
        node = Synth.tail(g, "funk", [\freq, num.midicps, \amp, vel/255]);
        node.map("cutoff", 1, "rez", 2, "lfospeed", 3);
//        node = Synth.basicNew("funk", s);
//        s.sendBundle(nil,
//            node.addToTailMsg(g, [\freq, num.midicps, \amp, vel/255]),
//            node.mapMsg("cutoff", 1, "rez", 2, "lfospeed", 3)
//        );
        keys.put(num, node)
    }, {
        node = Synth.tail(g, "strings", [\freq, num.midicps, \amp, vel/255]);
        keys.put(num, node)
    });
};
MIDIIn.addFuncTo(\noteOn, ~noteOn);

~noteOff = { |src, chan, num, vel|
    var node;
    node = keys.at(num);
    if (node.notNil, {
        keys.put(num, nil);
        s.sendMsg("/n_set", node.nodeID, "gate", 0);
        // 或者 node.release
        // 然后释放它……或者让 NodeWatcher 来做
    });
};
MIDIIn.addFuncTo(\noteOff, ~noteOff);
)

// cleanup
MIDIIn.removeFuncFrom(\noteOn, ~noteOn);
MIDIIn.removeFuncFrom(\control, ~control);
MIDIIn.removeFuncFrom(\bend, ~bend);
