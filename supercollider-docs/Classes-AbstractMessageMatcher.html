AbstractMessageMatcher

将传入消息匹配到函数

Object

另请参见：AbstractResponderFunc、AbstractWrappingDispatcher

子类：HIDFuncDeviceProtoMatcher、HIDFuncElementProtoMatcher、HIDRawValueMatcher、HIDValueMatcher，

说明

AbstractMessageMatcher 子类的实例被 AbstractWrappingDispatcher 的子类使用，以将传入消息（即 OSC 或 MIDI）的多个参数匹配到 AbstractResponderFunc 子类的实例。此类及其子类是私有的，通常用户不需要直接处理它们。

类方法

实例方法

.func

.func = value

获取或设置此对象的响应 Function。

返回值：

一个 Function 或类似对象。

.value

对传入的消息求值以检查是否匹配。子类应重写此消息以接受适当的参数。如果找到匹配，此方法应调用此对象 func 的 value，并将消息作为适当的参数传入。

.valueArray(args)

与上面的 -value 相同，但参数以单个数组传递。需要此方法，以便子类可以在 FunctionList 中工作。

参数：

args

一个包含消息及相应参数的 Array。
