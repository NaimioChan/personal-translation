OSCFuncAddrMessageMatcher

根据发送者地址将传入消息匹配到响应函数

AbstractMessageMatcher : Object

另请参见：AbstractMessageMatcher、OSCFuncRecvPortMessageMatcher、OSCFuncBothMessageMatcher

说明

这由 OSCMessageDispatcher 和 OSCMessagePatternDispatcher 使用，通过发送者地址将传入的 OSC 消息匹配到 OSCFunc 或 OSCdef 的实例。此类是私有的，通常用户无需直接访问其实例。

类方法

OSCFuncAddrMessageMatcher.new(addr, func)

创建新实例。

参数：

addr

要尝试匹配的 NetAddr。

func

找到匹配时要计算的 Function。

返回值：

一个 OSCFuncAddrMessageMatcher。

实例方法

.value(msg, time, testAddr, recvPort)

检查消息是否匹配，若匹配则求值 func。

参数：

msg

OSC 消息以 Array 形式表示，格式为 [OSCAddress, other args]。

time

一个 Float，指示收到传入消息的时间。

testAddr

一个NetAddr，指示消息的来源。

recvPort

一个 Integer，表示接收消息的端口。
