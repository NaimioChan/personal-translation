Ball

弹跳物体的物理模型

UGen : AbstractFunction : Object

另请参阅：TBall、Spring

说明

Ball 模拟一个被振动表面反射的弹跳物体的路径。

类方法

Ball.ar(in: 0.0, g: 1, damp: 0, friction: 0.01)

Ball.kr(in: 0.0, g: 1, damp: 0, friction: 0.01)

参数：

in

调制表面电平

g

gravity

damp

撞击阻尼

friction

开始向表面吸引的接近距离

实例方法

示例

鼠标 x 控制电平的切换：

(
{
    var f, sf;
    sf = K2A.ar(MouseX.kr > 0.5) > 0;
    f = Ball.ar(sf, MouseY.kr(0.01, 20, 1), 0.01);
    f = f * 10 + 500;
    SinOsc.ar(f, 0, 0.2)
}.play;
)

鼠标 x 控制调制速率，鼠标 y 控制重力：

(
{
    var f, sf, g;
    sf = LFNoise0.ar(MouseX.kr(1, 100, 1));
    g = MouseY.kr(0.1, 10, 1);
    f = Ball.ar(sf, g, 0.01, 0.01);
    f = f * 140 + 500;
    SinOsc.ar(f, 0, 0.2)
}.play;
)

the general german police choir. 鼠标 x 控制阻尼，鼠标 y 控制重力：

(
{
    var f, sf, g;
    sf = LFPulse.ar(0.6, 0.2, 0.5);
    g = MouseY.kr(0.1, 10, 1);
    d = MouseX.kr(0.0001, 1, 1);
    f = Ball.ar(sf, g, d);
    f = f * 140 + 400;
    SinOsc.ar(f, 0, 0.2)
}.play;
)
