ServerMeter

显示输入/输出电平的图形反馈窗口

另请参阅：Stethoscope、FreqScope、ServerMeterView

说明

ServerMeter 是一个简单的图形显示，用于显示服务器上输入和输出的音量水平。

另请参阅：Server: -meter

类方法

.new

创建一个新的 ServerMeter。

参数：

server

你希望可视化其输入和输出的 Server。

numIns

要显示的输入数量（从第一个输入总线开始计数，类似于 SoundIn）

numOuts

你想要显示的输出数量（从总线 0 开始计数）

返回值：

对新创建的 ServerMeter 的引用

实例方法

.window

获取对此 ServerView 的窗口的引用

返回值：

一个 Window 引用

.meterView

获取此 ServerView 的 ServerMeterView 的引用

返回值：

一个 ServerMeterView 引用

注意： ServerMeter 在该 Window 内同时封装了一个 Window 和一个 ServerMeterView。有关 Window 和视图的更多信息，请参见 Introduction to GUI: Basic elements: Windows, views and containers

.position

ServerMeter 窗口的位置。该值应为 Point，例如 x@y，或能响应 .asPoint。例如：将位置设为 150@50 会把电平表窗口的左下角放置在距屏幕左边 150 像素、距屏幕底部 50 像素的位置。

示例

s = Server.internal; // 使用内部服务器
s.boot;

// 显示 4 个输入通道和主立体声输出
m = ServerMeter.new(s, 4, 2);

// 查询当前窗口位置
m.position  // -> Point(5.0, 277.0)

// 查询当前窗口边界
m.window.bounds

// 通过窗口左下角设置/获取 ServerMeter 的屏幕位置
m.position_(0@100);
m.position // -> Point(0.0, 100.0)

// 获取移动后的新窗口边界
m.window.bounds
