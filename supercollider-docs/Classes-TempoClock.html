TempoClock

基于速度的调度器

Clock : Object

另请参见：AppClock、SystemClock

子类：TempoBusClock

说明

TempoClock 是一个类似 SystemClock 的调度器，但它按每秒节拍数中的速度进行相对调度。

有关时钟如何运作的一般说明，请参见 Clock。

类方法

TempoClock.new(tempo, beats, seconds, queueSize: 256)

创建 TempoClock 的新实例。

参数：

tempo

初始 tempo。默认为 1。

beats

以拍为单位的时间，对应于由 seconds 参数给出的参考时间。默认为 0。

seconds

参考时间，以秒为单位，beats 参数对应于该时间。默认使用当前 Thread 的逻辑时间（参见 Thread: -seconds）。

queueSize

调度队列的存储大小。每个调度项占用 2 个计数空间，因此该大小除以 2 即为一次可调度的项目数量。另请参见 -queue。

讨论：

TempoClock 的创建就像它在 seconds 参数给定的时刻开始计拍，并以 beats 参数给定的起始量开始计数。因此，当前的拍数将等于该起始量加上根据给定速度从给定的秒参考时间起本应计得的拍数。

默认参数创建一个 TempoClock，它在当前逻辑时间从 0 开始计数拍子。

// 创建一个 TempoClock，从现在开始以 5 计数拍子。
(
t = TempoClock.new(2, 5);
"current beats:" + t.beats;
)

// 创建一个 TempoClock，就像它在 5 秒前从 0 开始计拍一样。
(
t = TempoClock.new(2, 0, thisThread.seconds - 5);
"current beats:" + t.beats;
)

TempoClock.default = value

TempoClock.default.beats // 自默认 TempoClock 启动以来的拍数

实例方法

.stop

销毁调度器并释放运行调度器的操作系统线程。

.clear(releaseNodes: true)

从调度队列中移除所有任务。

.isRunning

返回值：

一个 Boolean，若时钟处于活动状态则为 true，若时钟已停止则为 false。

.tempo

.tempo = newTempo

在当前逻辑时间下，设置或获取当前速度，单位为每秒拍数。

t = TempoClock.new;
t.tempo_(2.0); // 等价于 t.tempo = 2.0;
t.tempo;
t.tempo_(72/60) // 每分钟 72 拍
t.tempo;

.etempo = newTempo

设置或获取当前 已用时间 处的当前速度。

.permanent

.permanent = value

设置或获取一个 Boolean 值，指示时钟在 cmd-period 后是否继续存在。若为 false，时钟在 cmd-period 时停止（因而被移除）。若为 true，时钟在 cmd-period 后继续存在。默认为 false。

.beats

.beats = beats

获取或设置根据此时钟的当前逻辑时间（以拍为单位）。

当 获取 beats 时，如果此 clock 是当前 Thread 的关联 clock，则返回该 Thread 自身的以拍计的时间，否则返回该 Thread 的以秒计的时间按此 clock 换算成的拍数。

在将 beats 向未来更改之后，时钟将立即执行所有计划直到新时间为止的任务。同样，当将 beats 向过去更改时，已经计划的任务将被推迟，因此它们仍将在以拍数计的计划时间执行。

注意： 更改 beats 时，你只改变了时钟的时间概念，而不会改变当前 Thread 的逻辑时间，后者在 Thread 再次被调用之前保持不变。因此，如果此时钟是当前 Thread 的关联时钟，并且在更改后立即向此时钟询问以拍为单位的时间，你将看不到任何效果。然而，该效果在其他 Thread 上会立即可见。

(
t = TempoClock.new;

t.sched(3, {
    t.beats = 100;
    t.beats.postln; // 仍为 3
    nil
});
)

(
c = TempoClock.new;
fork {
    loop {
        c.beats.postln; // 更新，因为 ".wait" 会调用线程
        1.wait;
    }
};
)

c.beats = 100;

.schedAbs(beat, item)

安排一个任务在 beats 中的特定时间执行。

当调度时间到达时，会调用该任务的 awake 方法。如果该方法返回一个数字，任务将被重新调度，时间为上一次调度时间加上返回的值。

另请参见：Clock: Scheduling、Object: -awake。

.sched(delta, item)

安排一个任务在当前 Thread 的逻辑时间之后 delta 个拍执行。如果此时钟是当前 Thread 的关联时钟，则使用该 Thread 的拍数时间，否则根据此时钟的速度和起始时间将 Thread 的秒数时间转换为拍。

当调度时间到达时，会调用该任务的 awake 方法。如果该方法返回一个数字，任务将被重新调度，时间为上一次调度时间加上返回的值。

另请参见：Clock: Scheduling、Object: -awake。

.play(task, quant: 1)

在下一个拍点播放 task（一个函数），其中 quant 默认为 1。是 -schedAbs 的快捷方式；关于时间和 quant 的更多细节，请参见 -seconds 和 -nextTimeOnGrid。

t = TempoClock.default;
t.play({ |beats, time, clock| [beats, time, clock].postln });

.playNextBar(task)

使用 -schedAbs 在下一小节播放 task（一个函数）。

.queue

返回调度队列数组，形式为 [beat, function]。最大项目数由实例化时时钟的 queueSize 参数决定。默认的 queueSize 为 256，允许任意时刻队列中有 128 个函数。

.beatDur

返回当前整拍的时长（秒）。

.beatsPerBar

.beatsPerBar = newBeatsPerBar

获取或设置每小节的拍数。默认是 4。设置节拍计必须在同一时钟的调度线程内进行。被调度的函数以及正在播放的 Routine（或 Task）都在该时钟的线程上运行，因此这两者都是有效的。

设置 beatsPerBar 也会更新小节线引用（baseBarBeat）。请注意仅在一条小节线上调用 beatsPerBar_ only（如下方的 -nextBar）。

thisThread.clock 始终是当前时钟——因此，习惯性地写 thisThread.clock.beatsPerBar = /* number */ 可以保证拍号变更仅作用于当前时钟。

t = TempoClock.new;

t.beatsPerBar = 3;  // 错误！线程不正确

t.schedAbs(t.nextBar, { t.beatsPerBar_(3) });  // OK

t.beatsPerBar;  // 将在小节线之后反映

t.schedAbs(t.nextBar, { thisThread.clock.beatsPerBar_(4) });  // OK

(
r = Routine {
    // 通过寻址 "this" clock，
    // 我们始终在正确的位置改变节拍
    var clock = thisThread.clock;
    
    clock.beats.debug("start time");
    clock.timeToNextBeat(-1).wait;
    clock.beats.debug("barline");

    // 无需 'sched'
    // 因为 Routine 已在此时钟上
    // 翻转 3/4 -> 4/4 或 4/4 -> 3/4
    clock.beatsPerBar = 7 - clock.beatsPerBar;
    clock.beatsPerBar.debug("set meter to");

    0.01.wait;  // 必须位于小节线之后，以便 'timeToNextBeat'
    clock.timeToNextBeat(-1).wait;
    clock.beats.debug("next barline");
}.play;
)

.bar

返回当前小节。当前小节的拍子返回方法参见 -bars2beats。

.nextBar(beat)

返回下一个小节线处相对于 beat 参数的拍数。如果未提供 beat，则返回下一小节开始的拍。

.beatInBar

返回当前小节拍（以 Float 表示），与 -beatsPerBar 相关。取值范围为 0 到 < beatsPerBar。

.baseBar

返回 -beatsPerBar 最后一次更改所在的小节。如果自时钟创建以来 beatsPerBar 未曾更改，则返回 0。

.baseBarBeat

返回 -beatsPerBar 最后一次被更改时所处的拍。如果自时钟创建以来 beatsPerBar 未被更改过，则返回 0。

.beats2bars(beats)

以浮点数形式返回相对于 -baseBarBeat 的小节。

.bars2beats(bars)

返回相对于 -baseBar 的拍。

t = TempoClock.default;
t.bars2beats(t.bar) // 当前小节的重拍

.timeToNextBeat(quant: 1.0)

返回到下一拍的逻辑时间。默认情况下 quant 为 1，相对于 baseBarBeat，参见 -nextTimeOnGrid。

.nextTimeOnGrid(quant: 1, phase: 0, referenceBeat)

在默认值下，返回下一个完整拍。quant 默认为 1，phase 为 0。quant 相对于 -baseBarBeat，因此

t = TempoClock.default;
t.nextTimeOnGrid(t.beatsPerBar) == t.nextBar // => true

quant 和 phase 结合在一起可用于查找小节中的下一个第 n 拍，例如 nextTimeOnGrid(4, 2) 将返回小节（4 拍）中的下一个第 3 拍，而 nextBar-2 可能返回一个已过去的拍。

referenceBeat 可用于相对于任意拍来求值 quant 和 phase。通常不会指定参考拍（nil），此时将使用时钟当前的拍。

.elapsedBeats

返回以拍为单位的当前已过时间。这等价于 tempoClock.secs2beats(Main.elapsedTime)。通常更倾向于使用 -beats 而非 elapsedBeats，因为 beats 使用线程的逻辑时间。

.seconds

返回当前已用时间。（此方法继承自 Clock。）

.beats2secs(beats)

将绝对拍转换为绝对秒，返回时钟在给定拍处经过的时间。仅对当前速度下的时间有效。如果速度发生变化，未来计算的任何时间都会出错。

t = TempoClock.default;
t.beats2secs(t.beats) // 等同于 t.seconds
t.beats2secs(0) // 启动后多少秒出现了拍点 0？

.secs2beats(secs)

将绝对 秒转换为绝对拍数。仅对当前速度下的时间有效。如果速度发生变化，将来任何计算出的时间都会出错。

示例

t = TempoClock(1); // 创建一个 TempoClock

// 在下一个完整拍点调度一个事件
t.schedAbs(t.beats.ceil, { |beat, sec| [beat, sec].postln; 1 });

t.tempo = 2;
t.tempo = 4;
t.tempo = 0.5;
t.tempo = 1;

t.clear;

t.schedAbs(t.beats.ceil, { |beat, sec| [beat, sec].postln; 1 });

t.stop;
(
// 获取经过时间，向上取整到下一秒
v = Main.elapsedTime.ceil;

// 创建两个时钟，比例为 5:2，从时间 v 开始。
t = TempoClock(1, 0, v);
u = TempoClock(0.4, 0, v);

// 在每个时钟中，于第零拍启动两个函数。
t.schedAbs(0, { |beat, sec| [\t, beat, sec].postln; 1 });
u.schedAbs(0, { |beat, sec| [\u, beat, sec].postln; 1 });
)

(
u.tempo = u.tempo * 3;
t.tempo = t.tempo * 3;
)

(
u.tempo = u.tempo * 1/4;
t.tempo = t.tempo * 1/4;
)

(
t.stop;
u.stop;
)
(
// 获取经过时间，向上取整到下一秒
v = Main.elapsedTime.ceil;

// 创建两个时钟，起始时间为 v。
t = TempoClock(1, 0, v);
u = TempoClock(1, 0, v);

// 在每个时钟的第零拍启动两个函数。
// t 控制 u 的速度。它们应保持同步。
t.schedAbs(0, { |beat, sec| u.tempo = t.tempo * [1, 2, 3, 4, 5].choose; [\t, beat, sec].postln; 1 });
u.schedAbs(0, { |beat, sec| [\u, beat, sec].postln; 1 });
)

(
u.tempo = u.tempo * 3;
t.tempo = t.tempo * 3;
)

(
u.tempo = u.tempo * 1/4;
t.tempo = t.tempo * 1/4;
)

(
t.stop;
u.stop;
)
