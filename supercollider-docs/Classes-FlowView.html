FlowView

以 FlowLayout 作为装饰器的 CompositeView

另请参阅：FlowLayout、CompositeView

说明

从最简单的方面看，这是对此的惰性收缩：

w = GUI.window.new;
w.view.decorator = FlowLayout.new(w.bounds);
w.front;

FlowView 为此设置添加了一些功能。

(
f = FlowView.new;

GUI.slider.new(f, Rect(0, 0, 100, 100));
GUI.slider.new(f, Rect(0, 0, 100, 100));

// 此时 StartRow 将固定在 children 数组中的此位置
f.startRow;

GUI.slider.new(f, Rect(0, 0, 100, 100));
f.startRow;

GUI.slider.new(f, Rect(0, 0, 100, 100));
)

实例方法

.startRow

开始新的一行。

.indentedRemaining

从当前光标位置开始剩余的最大空间。

(
f = FlowView.new;

GUI.slider.new(f, Rect(0, 0, 100, 100));
GUI.slider.new(f, Rect(0, 0, 100, 100));

GUI.slider.new(f, f.indentedRemaining)
    .background = Color.blue(alpha: 0.2)
)

(
f = FlowView.new;

GUI.slider.new(f, Rect(0, 0, 100, 100));
GUI.slider.new(f, Rect(0, 0, 100, 100));

f.startRow; // 新行

GUI.slider.new(f, f.indentedRemaining)
    .background = Color.blue(alpha: 0.2)
)

(
f = FlowView.new;

GUI.slider.new(f, Rect(0, 0, 100, 100));
GUI.slider.new(f, Rect(0, 0, 100, 100));
GUI.slider.new(f, Rect(0, 0, 100, 100));
GUI.slider.new(f, Rect(0, 0, 100, 100));

GUI.slider.new(f, f.indentedRemaining)
    .background = Color.blue(alpha: 0.2)
)

.used

目前已使用的区域，向上取整到最近的矩形再加边距。

(
w = GUI.window.new;
w.front;
f = FlowView.new(w);
f.background = Color.blue(alpha: 0.1);

GUI.slider.new(f, Rect(0, 0, 100, 100));
GUI.slider.new(f, Rect(0, 0, 100, 100));

f.used.postln;

// 叠加
GUI.compositeView.new(w, f.used)
    .background = Color.red(alpha: 0.1);
)

(
w = GUI.window.new;
w.front;
f = FlowView.new(w);
f.background = Color.blue(alpha: 0.1);

GUI.slider.new(f, Rect(0, 0, 100, 100));
GUI.slider.new(f, Rect(0, 0, 100, 100));

f.startRow; // 新行

GUI.slider.new(f, Rect(0, 0, 100, 100));

f.used.postln;

// 叠加
GUI.compositeView.new(w, f.used)
    .background = Color.red(alpha: 0.1);
)

.flow

将子流视图插入当前视图。

(
f = FlowView.new;

GUI.slider.new(f, Rect(0, 0, 100, 100));

// 流中之流
g = f.flow({ |g|
    ActionButton(g, "a");
    GUI.slider.new(g, Rect(0, 0, 100, 100)).background_(Color.rand);
}).background_(Color.black); // 之后收缩以适应内容
)

参数：

func

(在此描述参数)

bounds

(在此描述参数)

.comp

将一个子复合视图插入当前视图。

(
f = FlowView.new;

GUI.slider.new(f, Rect(0, 0, 100, 100));

// SuperCollider 复合视图
g = f.comp({ |g|
    GUI.slider.new(g, Rect(50, 30, 50, 100)).background_(Color.rand);
    GUI.slider.new(g, Rect(120, 30, 50, 100)).background_(Color.rand);
}, Rect(0, 0, 200, 200)).background_(Color.black);

f.startRow;
"Back to flowing".gui(f);
)

参数：

func

(在此描述参数)

bounds

(在此描述参数)
