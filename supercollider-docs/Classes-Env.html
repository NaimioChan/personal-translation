Env

分段包络的规格

Object

另请参见：EnvGen、IEnvGen、Pseg

子类：Penv

说明

Env 是分段包络的规格说明。Env 既可在服务器端使用，通过在 SynthDef 中的 EnvGen 或 IEnvGen，也可在客户端使用，通过如下所述的 -at 和 -asStream 等方法。

Env 可以有任意数量的段，这些段可以停在某个特定值，或者在持续时循环若干段。它的段可以有多种形状。

包络被构想为一系列断点节点，每个节点有三个参数：一个电平、一个过渡时间和一个过渡曲线形状。这三个节点参数如下所述保存在独立的数组中。请注意，由于第一个节点表示包络的初始电平，它没有关联的过渡时间或曲线。

Env.new(levels: [0, 1, 0.9, 0], times: [0.1, 0.5, 1], curve: [-5, 0, -5]).plot;

在此包络中，有四个节点：

  • 第一个 node 是包络的初始电平：0
  • 第二个节点的级别为 1，并在 0.1 秒内到达
  • 第三个节点的级别为 0.9，并在 0.5 秒内到达
  • 第四个 node 的电平为 0，并在 1 秒内到达

重新触发包络时必须密切注意。从触发那一刻的当前值开始，包络将循环经过所有节点，第一个节点除外。第一个节点是包络的初始值，仅在初始触发之前输出。

(
{
    EnvGen.kr(
        Env(
            levels: [0, 0.1, 0.2, 0.3],
            times: [0.1, 0.1, 0.1],
            curve: 8
        ),
        gate: Impulse.kr(3)
    );
}.plot(duration: 1);
)

在上面的示例中，初始电平（0）从不重复。当重新触发时，包络从其当前值（此处为 0.3）移动到默认情况下第二个节点的值（0.1），然后继续经过后续节点。

注意： 在某些情况下，我们会处理控制点或断点。如果这些控制点带有相关联的 x 位置（比如在包络 GUI 中，参见 EnvelopeView），就必须将它们转换为点之间的时间差，才能作为 Env 对象中的节点使用。方法 *xyc 和 *pairs 可用于按点的方式指定包络。

// 合成器中的包络
(
{
    var env = Env([0, 1, 0.5, 1, 0], [0.01, 0.5, 0.02, 0.5]);
    SinOsc.ar(470) * EnvGen.kr(env, doneAction: Done.freeSelf)
}.play
)
// 一个用于控制模式中参数的包络
(
Pbind(
    \note, Env([0, 12, 6, 13, 0], [1, 5, 2, 10]),
    \dur, 0.1
).play
)

类方法

Env.new(levels: [0, 1, 0], times: [1, 1], curve: 'lin', releaseNode, loopNode, offset: 0)

创建一个新的包络规格。

参数：

levels

一个电平值数组。第一个值是包络的初始电平，当与 EnvGen 一起使用时，它会一直保持到 gate 打开为止。如果某个电平值是 UGen，则其值仅在包络到达该节点时才更新。当某个电平值本身是一个数组时，包络会返回多通道输出（相关讨论请见 Multichannel expansion）。

times

一个包含各段持续时间（以秒为单位）的数组。其元素个数应比 levels 少一个，但若长度更短，则通过循环回绕给定值来扩展该数组。

curve

一个 Symbol、Float，或由它们组成的数组。决定包络段形状。

可能的值为：

\step

平坦段（立即跳转到最终值）

\hold

平坦段（保持初始值，在段末跳变到最终值）

\linear

\lin

线性段，默认值

\exponential

\exp

自然指数增长与衰减。在这种情况下，各级别必须均非零且符号相同。

\sine

\sin

正弦 S 形分段。

\welch

\wel

形状像 Welch 窗两侧的正弦段。

\squared

\sqr

平方段

\cubed

\cub

三次方段

一个 Float

所有段的曲率值。0 表示线性，正数和负数使段向上和向下弯曲。

符号或浮点数的数组

每个段的曲率值。

\step

平坦段（立即跳转到最终值）

\hold

平坦段（保持初始值，在段末跳变到最终值）

\linear

\lin

线性段，默认值

\exponential

\exp

自然指数增长与衰减。在这种情况下，各级别必须均非零且符号相同。

\sine

\sin

正弦 S 形分段。

\welch

\wel

形状像 Welch 窗两侧的正弦段。

\squared

\sqr

平方段

\cubed

\cub

三次方段

一个 Float

所有段的曲率值。0 表示线性，正数和负数使段向上和向下弯曲。

符号或浮点数的数组

每个段的曲率值。

releaseNode

一个 Integer 或 nil。包络将在 releaseNode 处持续，直到被释放。

(
{
    EnvGen.kr(
        Env.new(
            levels: [0, 1, 0.5, 0],
            times: [0.01, 0.01, 0.01],
            releaseNode: 2 // 保持在 0.5 电平直到 gate 关闭
        ),
        gate: Trig.kr(Impulse.kr(3), dur: 0.3)
    );
}.plot(duration: 1);
)

在上面的示例中，释放节点被设为第三个节点，这意味着它将在 0.5 的水平上保持，直到被释放。然后包络将继续进行，直到到达其最后一个节点。

loopNode

一个 Integer 或 nil。创建一个循环节点段。你必须指定 releaseNode，loopNode 才会生效。循环节点是循环的初始节点，并且永远不会重复。

到达释放节点时，包络将在该节点的过渡时间内回退到循环节点之后的节点。

包络将循环，直到 EnvGen 的 gate 关闭；此时包络将从其当前位置移动到 releaseNode 之后的节点，经过该节点的过渡时间，并继续经过剩余的节点。

(
{
    var trig = Trig.kr(1, 1.4); // 门打开 1.4 秒
    var env = EnvGen.kr(
        Env(
            levels: [0.001, 1, 0.5, 0.9, 0.3, 0.7, 0],
            times:  [0.01, 0.05, 0.2,  0.15, 0.4, 0.1],
            curve:  [\exp,   5,  \sin, \exp, \lin, 0],
            releaseNode: 4, // loop at 0.3
            loopNode: 1 // 循环回到 0.5
        ), gate: trig
    );
    [trig, env]
}.plot(duration: 2)
)

在此示例中：

  • 包络的起始电平为 0.001
  • 循环回跳点在 levels[releaseNode]（0.3）处，在 times[loopNode] 秒内回跳到 levels[loopNode+1]（0.5）
  • 当 gate 关闭时（1.4 秒），包络继续到 levels[releaseNode+1]（0.7），在 times[releaseNode] 秒内，然后继续经过包络的其余部分

对于仅循环遍历其所有节点的包络，请参见 *circle。

offset

所有时间值的偏移量（仅适用于 IEnvGen）。

讨论：

(
{
    var env = Env([0.0, 0.5, 0.0, 1.0, 0.9, 0.0], [0.05, 0.1, 0.01, 1.0, 1.5], -4);
    var envgen = EnvGen.ar(env, doneAction: Done.freeSelf);
    env.plot;
    SinOsc.ar(
        envgen * 1000 + 440
    ) * envgen * 0.1
}.play
);

Env.newClear(numSegments: 8, numChannels: 1)

创建一个新的包络规范，具有 numSegments 和 numChannels，以便后续填充。

讨论：

当将 Env 参数作为参数传递给 Synth 时，这可能很有用。注意，段的最大数量是固定的，一旦嵌入到 SynthDef 中就无法更改。尝试设置段数超过此限制的 Env 可能会导致其他参数被意外设置。

(
SynthDef(\help_Env_newClear, { |out = 0, gate = 1|
    var env, envctl;
    // 创建一个空的 4 段包络
    env = Env.newClear(4);
    // 创建一个控制参数数组
    envctl = \env.kr(env.asArray);
    Out.ar(out, SinOsc.ar(EnvGen.kr(envctl, gate), 0) * -12.dbamp);
}).add;
)

Synth(\help_Env_newClear, [\env, Env([700, 900, 900, 800], [1, 1, 1], \exp)]); // 3 个段

// 重置然后再次播放：
Synth(\help_Env_newClear, [\env, Env({ rrand(60, 70).midicps } ! 4, [1, 1, 1], \exp)]);

// 同样内容写成事件形式：
(instrument: \help_Env_newClear, env: Env({ rrand(60, 70).midicps } ! 4, [1, 1, 1], \exp)).play;

持续包络创建方法

以下方法创建一些常用的、带有延音段的包络形状。它们通常用于 SynthDef 中，适用于启动 synth 时还无法确定它何时结束的情况。典型情形包括外部接口、midi 输入或快速变化的 TempoClock。

(
SynthDef(\env_help, { |out, gate = 1, amp = 0.1, release = 0.1|
    var env = Env.adsr(0.02, release, amp);
    var gen = EnvGen.kr(env, gate, doneAction: Done.freeSelf);
    Out.ar(out, PinkNoise.ar(1 ! 2) * gen)
}).add
);

a = Synth(\env_help);
b = Synth(\env_help, [\release, 2]);
a.set(\gate, 0); // 或者，你可以写 a.release；
b.set(\gate, 0);

Env.step(levels: [0, 1], times: [1, 1], releaseNode, loopNode, offset: 0)

创建一个新的包络规范，其中所有段都是水平线。给定 n 个时间值，只需提供 n 个电平，对应每个段的固定值。

参数：

levels

一个电平值数组。第一个值是包络的初始电平，当与 EnvGen 一起使用时，它会一直保持到 gate 打开为止。如果某个电平值是 UGen，则其值仅在包络到达该节点时才更新。当某个电平值本身是一个数组时，包络会返回多通道输出（相关讨论请见 Multichannel expansion）。

times

一个以秒为单位的各段时长数组。它应与 levels 数组大小相同。

releaseNode

一个 Integer 或 nil。包络将在释放节点处持续，直到被释放。

loopNode

一个 Integer 或 nil。如果不是 nil，输出将在这些节点之间循环：从循环节点开始，到释放节点之前的节点，然后回到循环节点，如此反复。注意，只有当包络被释放时才会过渡到释放节点。示例见下文。当发送门限信号时，输出会过渡到释放节点（如下所述），此时循环将被退出。

offset

所有时间值的偏移量（仅适用于 IEnvGen）。

讨论：

(
{
    var env = Env.step([0, 3, 5, 2, 7, 3, 0, 3, 4, 0], [0.5, 0.1, 0.2, 1.0, 1.5, 2, 0.2, 0.1, 0.2, 0.1]);
    var envgen = EnvGen.kr(env);
    var freq = (envgen + 60).midicps;
    SinOsc.ar(freq) * 0.1
}.play
);

sustainLevel

Env.circle(levels, times, curve: 'lin')

创建一个新的包络，当被 EnvGen 使用时，它会循环其各值。

要使已创建的包络变为循环，可以使用 -circle 实例方法，它接收循环时间和曲线作为参数。

参数：

levels

包络经过的各个电平。

times

包络中后续各电平之间的时间。最后一个值是循环回绕时间。times 数组的大小应与 levels 数组的大小相同。

curve

包络各段的曲率。最后一个值是循环回绕曲率。有效值参见 *new。curve 的数组大小应与 levels 数组的大小相同。

注意： 如果 times 或 curve 数组太短，它将通过循环环绕给定的值来扩展。如果只给出一个值，则该值适用于所有包络阶段。

讨论：

注意： 循环 Env 必须在用于构造 SynthDef 的函数内部实例化。如果在函数外部实例化（例如作为变量传入），它将无法工作。由于内部对循环行为的初始化，包络存在一个采样的延迟。

( // 使用 *circle 和 -circle 绘制包络
var loopBackTime = 0.06;
{ [
    EnvGen.kr(
        Env.circle([0.5, 1, 0.3], [0.01, 0.03, loopBackTime])
    ),
    EnvGen.kr(
        Env.new([0.5, 1, 0.3], [0.01, 0.03]).circle(loopBackTime)
    )
] }.plot(0.1 * 4 - 0.01).plotMode_(\dlines)
)

// 一个声音示例
{ SinOsc.ar(EnvGen.kr(Env.circle([0, 1, 0], [0.01, 0.5, 0.2])) * 440 + 200) * 0.2 }.play;

// 如果 times.size < levels.size，则时间会被重复
{ SinOsc.ar(EnvGen.kr(Env.circle([0, 1, 0, 2, 0, 1, 0], [0.01, 0.3])) * 440 + 200) * 0.2 }.play;

( // levels 的多通道扩展
{ SinOsc.ar(EnvGen.kr(Env.circle(
    [0, 1, 0, 0.5 * (1..4), 0, 2.sqrt/2 * (1..4), 0],
    [0.01, 0.3]
)) * 440 + 200).clump(2).collect(_.sum) * 0.2
}.scope;
)

多通道扩展

如果 levels、times 或 curves 中的某个值本身是一个数组，包络会在适当的地方扩展为多通道。这意味着当这样的包络传给 EnvGen 时，该 EnvGen 会扩展；当通过 -at 或 -asSignal 方法查询包络时，它会返回一个数组值。

(
{
    var env = Env([0.0, 0.5, 0.0, [1.0, 1.25, 1.5], 0.9, 0.0], [0.05, 0.1, 0.01, 1.0, 1.5], -4);
    var envgen = EnvGen.ar(env, doneAction: Done.freeSelf);
    SinOsc.ar(
        envgen * 1000 + 440
    ) * envgen * 0.1
}.play
);

(
{
    var env = Env([1, [1, 2, 3], 0.5, 0.5, [3, 2, 1], 2], [1, 1, 0.5, 1], [[\exp, \sin]]);
    env.plot;
    Splay.ar(SinOsc.ar(EnvGen.kr(env) * 400 + 600)) * 0.1
}.play;
);


(
{
    var levels = (1..30);
    var env = Env([1, levels, 0.5, levels / 2.5, 2], [1, 0.15, 1, 0.25, 0.1], \exp);
    Splay.ar(SinOsc.ar(EnvGen.kr(env) * 400 + 600)) * 0.1
}.play;
);


// 通过索引访问包络

e = Env([1, [1, 2, 3], 1], [1, 1], \exp);
e.at(0.5);
e.at(1.8);
e.at(2);

e = Env([1, 1, 1], [1, [1, 2, 3]], \exp);
e.at(0.5);
e.at(2);

.ar(doneAction: 0, gate: 1.0, timeScale: 1.0, levelScale: 1.0, levelBias: 0.0)

.kr(doneAction: 0, gate: 1.0, timeScale: 1.0, levelScale: 1.0, levelBias: 0.0)

此消息在 UGen 图中隐式地完成与使用 EnvGen 相同的工作，以提供便利。其参数顺序对应最常见的参数。

参数：

doneAction

一个整数，表示当包络播放结束时执行的操作。这可用于释放包含它的 synth 等。更多细节请参见 Done。

gate

这会触发包络，并在 > 0 期间保持其打开。如果 Env 是固定长度的（例如 Env.linen、Env.perc），gate 参数会被用作简单的触发器。如果它是延音包络（例如 Env.adsr、Env.asr），则包络会保持打开，直到 gate 变为 0，此时它会被释放。

如果 gate < 0，则以 -1.0 - gate 的时间强制释放。请参见 EnvGen: Forced release 示例。

timeScale

各段的时长会乘以该值。该值可以被调制，但只会在新包络段的起始处采样。

levelScale

断点的电平值会乘以该值。该值可以被调制，但只会在新包络段的起始处采样。

levelBias

该值作为偏移量加到断点的电平上。该值可以被调制，但只会在新包络段的起始处采样。

讨论：

{ Blip.ar(50, 200, Env.perc(1, 0.1, 0.2).kr(2)) }.play;
(
{
    Blip.ar(
        Env({ exprand(3, 2000.0) } ! 18, 0.2, \exp).kr,
        200,
        Env({ rrand(0.1, 0.2) } ! 18 ++ 0, 0.2).kr(2))
    }.play;
)

.circle(timeFromLastToFirst: 0.0, curve: 'lin')

将 Env 声明为循环，以便在与 EnvGen 一起使用时，Env 会循环播放。

你可以直接通过 *circle 类方法创建一个循环的 Env。

参数：

timeFromLastToFirst

从 Env 的最后一层循环回到第一层所需的时间。若未指定，循环时间为即时（一个采样）。

curve

连接 Env 最后一级和第一级的线段的曲率。可能的值与 *new 的 curves 参数相同。

讨论：

注意： 循环 Env 必须在用于构造 SynthDef 的函数内部实例化。如果在函数外部实例化（例如作为变量传入），它将无法工作。由于内部对循环行为的初始化，包络存在一个采样的延迟。

// 无参数：立即进行回环
{ EnvGen.kr(Env([0.1, 1, 0.5], [0.01, 0.03]).circle) }.plot(0.2).plotMode_(\dlines)

// 指定了循环时间与曲线
{ EnvGen.kr(Env([0.1, 1, 0.5], [0.01, 0.03]).circle(0.05, \sin)) }.plot(0.2).plotMode_(\dlines)

( // 循环频率调制
{
    SinOsc.ar(
        EnvGen.kr(
            Env(
                [6000, 700, 100], [1, 1], ['exp', 'lin']
            ).circle.postcs // 输出内部表示
        )
    ) * 0.1
    // 添加一个可听的节拍器
    + (SinOsc.ar(280) * Decay.ar(Impulse.ar(1), 0.05) * 0.5)
}.play;
)

( // 使用 MouseX 控制门限
{
    SinOsc.ar(
        EnvGen.kr(
            Env(
                [6000, 700, 100], [0.5, 0.5], ['exp', 'lin']
            ).circle(1).postcs,
            MouseX.kr > 0.5
        )
    ) * 0.1
    + (SinOsc.ar(280) * Decay.ar(Impulse.ar(1), 0.05) * 0.5)
}.play;
)

.at(time)

如果给定了循环节点，EnvGen 会输出循环节点与释放节点之间的节点（不包括释放节点本身），直到被释放：

// 和节点 1（lvl 0.1，dur 0.5）之间循环         // 直到 3.5 秒后被释放

Env.new([0, 1, 0], [0.5, 2], 'lin', 1, 0).test(3.5).plot;

// 更复杂的例子：释放节点是节点 3，循环节点是节点 1
Env.new([0.001, 1, 0.3, 0.8, 0.5, 0.8, 0], [2, 1, 1, 2, 3, 1] * 0.1, 'lin', 3, 1).test(3).plot;

// 这是生成的图：
(
e = Env.new([0.001, 1, 0.3, 0.8, 0.5, 0.8, 0], [2, 1, 1, 2, 3, 1] * 0.001, 'lin', 3, 1);
e.plot; { EnvGen.ar(e, Trig.ar(Impulse.ar(0), 10*0.001)) }.plot(0.02);
)

注意： 包络段（envelope segment）的起始电平始终是你当前所处的电平。例如，当 gate 被释放并且你跳转到 release 段时，电平不会跳转到 release 段起始处的电平，而是从当前所处的任意电平，在 release 段指定的持续时间内，变化到 release 段的目标电平。包络开头有一个额外的电平用于设置初始电平。之后，每个节点都是一个目标电平和一个持续时间，因此节点零的持续时间等于 times[0]，目标电平等于 levels[1]。循环会跳回 loop 节点。该段的终点就是该段的目标电平，而该段的持续时间就是电平从当前电平变化到目标电平所经过的时间。
