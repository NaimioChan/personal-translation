Unpack1FFT

从 FFT 链中解包单个值（幅度或相位）

UGen : AbstractFunction : Object

另请参阅：PackFFT、UnpackFFT、FFT Overview

Unpack1FFT(chain, bufsize, binindex, whichmeasure = 0)

说明

接收一条 FFT 链，并提取出单个标量值作为需求率流。要调用它，需要一个“需求者”（demander），它会在 FFT 链触发时触发——这通常通过 PackFFT 实现，但也可以使用 Demand 完成。

注意： 此 UGen 通常不直接使用。它的主要用途是作为 PV_ChainUGen: -pvcollect、PV_ChainUGen: -pvcalc 和 PV_ChainUGen: -pvcalc2 处理过程中的组件。你当然也可以单独使用它——下面的示例展示了具体用法。

类方法

Unpack1FFT.new(chain, bufsize, binindex, whichmeasure: 0)

参数：

chain

一条 FFT 链

bufsize

预期输入 FFT 帧的大小

binindex

要查询的 bin 的整数索引

whichmeasure

0 表示幅度，1 表示相位。这些参数均不可被调制。

讨论：

// 让我们提取直流分量——即 binindex 为零处的幅度。
(
{
    var sig, chain, stream, windowStarts, demand;
    var fftsize = 1024;

    sig = SinOsc.ar(LFDNoise3.kr(LFNoise0.kr(1) * 40 + 60) * 700 + 800);

    chain = FFT(LocalBuf(fftsize), sig);
    stream = Unpack1FFT(chain, bufsize: fftsize, binindex: 0, whichmeasure: 0);

    // 每次 FFT 窗口开始时，解包器都会返回一个新值
    windowStarts = chain > -1;
    demand = Demand.kr(windowStarts, 0, stream);
    demand.poll(windowStarts);

    sig * 0.05
}.play
)
