TwoWayIdentityDictionary

将键映射到值并可反向映射的关联集合

Collection : Object

参见：IdentityDictionary

子类：ObjectTable

说明

类似于 IdentityDictionary，但允许高效地从元素到键以及从键到元素进行查找。TwoWayIdentityDictionary 的内容是无序的。不得依赖于元素的顺序。

.getID(obj)

查找给定对象的键。如果 object 不是字典的元素，则返回 nil。

示例

a = TwoWayIdentityDictionary.new;
a.put(\test, 999);
a.put(["some", "strings"], 1200);
a.at(\test);
a.getID(999);
a.getID(1200);
a.getID(888); // nil
