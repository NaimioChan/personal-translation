UGen

所有 unit generator 的抽象父类

AbstractFunction : Object

另请参见：Browse: UGens、Tour of UGens、Unit Generators and Synths

子类：AbstractOut、Amplitude、AnalogIn、AnalogOut、

说明

UGen 表示带信号的计算。它们是服务器上 synth 定义的基本构建块，用于生成或处理音频信号和控制信号。UGen 的众多子类就是单元生成器的客户端表示，在构建 synth 定义时用于指定它们的参数（参见 SynthDef）。

Interface

所有 UGen 都响应以下一个或多个类方法：

  • ar(arg1, arg2, ...)
  • kr(arg1, arg2, ...)
  • ir(arg1, arg2, ...)

它们返回一个新的 UGen 实例，在音频/控制速率或仅在初始化时（ir）进行计算。某些 UGen，如 Rand，则使用 *new 方法。这些方法在子类中实现，其参数名称和含义视具体情况而定。

如果任何参数是数组，它们会返回一个 UGen 数组（参见：Multichannel Expansion）。如果参数与 ugen 之间的速率组合不被允许，调用这些方法将抛出错误。此方法会将 UGen 添加到当前 SynthDef 中，因此它只在 UGen 函数内部才能完全正常工作。

{ Blip.ar(Blip.kr(4, 5, 500, 60), 59, 0.1) }.play;

mul 和 add 参数的文档

大量 UGen 在其 *ar 和 *kr 方法中都接受 mul 和 add 参数。由于这些参数极为常见，因此并未在各个单独的帮助文件中进行通用说明。mul 和 add 简单地指一个常数或信号，用以乘以 UGen 的输出，以及一个常数或信号，用以加到 UGen 的输出上。（mul 在 add 之前发生。）因此在许多情况下，它们分别对应于对 UGen 信号幅度的缩放（mul 的情形）以及加上一个常数或直流偏移（add 的情形）。在大多数情况下，mul 和 add 的默认值分别为 1 和 0，且出于效率考虑，它们通常使用自动生成的 MulAdd UGen 来实现。另见下面的 range 和 madd 方法。

UGen.multiNew( ... args)

这些方法负责多通道扩展。它们为每个并行组合调用 *new1(rate, ...args)。大多数 *ar / *kr 方法会委托给 *multiNewList。

参数：

... args

第一个参数是 rate，然后是其余参数。(rate, ...args)

UGen.multiNewList(args)

参见 *multiNew。

参数：

args

一个数组，第一个参数是速率，然后是其余参数。([rate, ...args])

UGen.new1(rate ... args)

此方法返回 UGen 的单个实例，而不是多通道扩展的。每当需要新的单个实例时，它会在 multiNewList 内部被调用。

.poll(trig: 10, label, trigid: -1)

每隔 interval 秒轮询此 UGen 的输出，并发布结果。

参数：

trig

触发频率

label

用于标记输出的符号

trigid

数字 ID

讨论：

默认 trig 为 10，即转换为每秒 10 次触发（或每 0.1 秒一次）。有关轮询的更多信息，参见 Poll。

{ SinOsc.ar(LFNoise0.ar(2).range(420, 460).poll(label: \LFNoise), 0, 0.2) }.play;

// 多声道轮询：
(
{
    var freqs = SinOsc.ar([0.2, 0.3]).range(420, 460);
    freqs.poll(label: [\freq1, \freq2]);
    SinOsc.ar(freqs, 0, 0.2);
}.play;
)

.dpoll(label, run: 1, trigid: -1)

与 poll 类似，只是 dpoll 用于 Demand UGen。有关轮询的更多信息，请参见 Poll。

.range(lo: 0.0, hi: 1.0)

将此 UGen 的输出缩放到 lo 和 hi 范围内。

讨论：

请注意，range 期望使用默认输出范围，因此不应与 mul 和 add 参数一起使用。

{ SinOsc.ar(SinOsc.ar(0.3).range(440, 660), 0, 0.5) * 0.1 }.play;

.exprange(lo: 0.01, hi: 1.0)

将这个 UGen 的输出以指数方式映射到 lo 与 hi 的范围内，使用 LinExp UGen。

讨论：

lo 和 hi 都应为非零且符号相同。注意，exprange 期望使用默认的输出范围，因此不应与 mul 和 add 参数一起使用。

{ SinOsc.ar(SinOsc.ar(0.3).exprange(440, 6600), 0, 0.5) * 0.1 }.play;

.curverange(lo: 0.0, hi: 1.0, curve: -4)

将该 UGen 的输出缩放到 lo 与 hi 之间的范围内，并使用曲线因子 curve。

讨论：

注意 curverange 期望默认输出范围，因此不应与 mul 和 add 参数一起使用。

{ SinOsc.ar(SinOsc.ar(0.3).curverange(440, 660, -3), 0, 0.5) * 0.1 }.play;

.unipolar(mul: 1)

将此 UGen 的输出缩放到 (0..mul) 范围内（默认值为 1）。

讨论：

注意，unipolar 期望默认输出范围，因此不应与 mul 和 add 参数一起使用。

{ SinOsc.ar(300, 0, 0.5) * SinOsc.kr(2).unipolar * 0.1 }.play;

.bipolar(mul: 1)

将此 UGen 的输出缩放到 (-mul..mul) 范围内（默认为 1）。

讨论：

注意，bipolar 期望默认输出范围，因此不应与 mul 和 add 参数一起使用。

{ SinOsc.ar(500 + LFPulse.ar(4).bipolar(40), 0, 0.5) * 0.1 }.play;

将接收者包裹在 Fold UGen 中，将其输出折叠在 lo 和 hi 之间。

.lag(t1: 0.1, t2)

将接收者包装在 Lag UGen 中，以 t1 秒的滞后时间平滑其输出。如果给出第二个参数，则将其包装在 LagUD UGen 中。

.lag2(t1: 0.1, t2)

将接收者包装在 Lag2 UGen 中，以 t1 秒的延迟时间平滑其输出。若给出第二个参数，则将其包装在 Lag2UD UGen 中。

.lag3(t1: 0.1, t2)

将接收者包装在 Lag3 UGen 中，以 t1 秒的延迟时间平滑其输出。若给出第二个参数，则将其包装在 Lag3UD UGen 中。

.lagud(lagTimeU: 0.1, lagTimeD: 0.1)

将接收者包装在 LagUD UGen 中，通过 lagtimeU 和 lagtimeD 对其输出进行平滑。

.lag2ud(lagTimeU: 0.1, lagTimeD: 0.1)

将接收者包装在 Lag2UD UGen 中，通过 lagtimeU 和 lagtimeD 平滑其输出。

.lag3ud(lagTimeU: 0.1, lagTimeD: 0.1)

将接收者包装在 Lag3UD UGen 中，通过 lagtimeU 和 lagtimeD 平滑其输出。

.varlag(time: 0.1, curvature: 0, warp: 5, start)

将接收者包装在一个 VarLag UGen 中，按 time 秒对其输出进行平滑处理。

.slew(up: 1, down: 1)

将接收者包装在 Slew UGen 中，限制其输出的斜率。

.degreeToKey(scale, stepsPerOctave: 12)

将接收者包装在 DegreeToKey UGen 中。

.minNyquist

将接收者包装在 min BinaryOpUGen 中，从而输出接收者输出与奈奎斯特频率中的较小者。这可用于防止混叠。

.snap(resolution: 1.0, margin: 0.05, strength: 1.0)

包裹接收者，使其值在距离margin为resolution倍数的范围内四舍五入到resolution的倍数。通过使用margin和strength，你可以控制何时进行四舍五入以及四舍五入的程度。详情请参见SimpleNumber: -snap。

这可用于使控制信号（例如来自传感器的信号）"对齐"到既定分辨率。示例：

s.boot;
x = { SinOsc.ar((Line.kr(0, 10, 10).snap(1, 0.3, 1) + 60).poll.midicps, 0, -24.dbamp) }.play

.softRound(resolution: 1.0, margin: 0.05, strength: 1.0)

将接收者包装起来，使其值在距离 resolution 的倍数超过 margin 距离时被舍入到 resolution 的倍数。通过使用 margin 和 strength，你可以控制值何时被舍入以及舍入多少。更多细节请参见 SimpleNumber: -softRound。

.linlin(inMin, inMax, outMin, outMax, clip: 'minmax')

包装接收者，使线性输入范围映射到线性输出范围。

.bilin(inCenter, inMin, inMax, outCenter, outMin, outMax, clip: 'minmax')

将接收者从两个假定的线性输入范围 (inMin..inCenter) 和 (inCenter..inMax) 映射到两个线性输出范围 (outMin..outCenter) 和 (outCenter..outMax)。如果输入超出输入范围，以下行为由 clip 参数指定。

outCenter

outMin

outMax

.if(trueUGen, falseUGen)

当接收者输出 1 时输出 trueUGen，当接收者输出 0 时输出 falseUGen。若接收者输出 0 到 1 之间的值，则将播放两者的混合。

讨论：

其实现为：(this * (trueUGen - falseUGen)) + falseUGen)

注意，无论是否输出，trueUGen 和 falseUGen 都会被计算，因此这可能不是最高效的方法。

// 注意这两个示例中的语法不同
{ if(LFNoise1.kr(1.0, 0.5, 0.5), SinOsc.ar, Saw.ar) * 0.1 }.play;

{ Trig1.ar(Dust.ar(3), 0.2).lag(0.1).if(FSinOsc.ar(440), FSinOsc.ar(880)) * 0.1 }.play;

|==|(that)

当接收者和参数信号重合时，输出 1，表示真。注意由于浮点运算，这在许多情况下可能是有歧义的。需要特殊符号，因为 == 比较的是 UGen 对象，而不是它们产生的信号。

// 浮点相关性对 |==| 运算符的一个示例。
// 四舍五入后的信号会在某个点匹配，但直接信号则不会
(
{
    var a = Line.ar(0, 1, 0.008);
    var b = a |==| 0.5;
    var c = a.round(0.01) |==| 0.5;
    [a, Trig1.ar(b, 0.001), Trig1.ar(c, 0.001)]
}.plot
)
