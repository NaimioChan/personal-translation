模式指南 02：基础词汇

生成单值流的常见模式

另请参阅：Pattern Guide 01: Introduction、Pattern Guide 03: What Is Pbind

基本词汇：生成值

在了解模式真正强大的功能之前，我们需要先建立一个基本词汇表。我们将从一些单词开始，然后在下一个教程中进入短语。

其中一些模式将用 Pbind 构造来演示。这是后续内容的一次预览——使用模式来编排声音事件。现在还不用担心 Pbind 如何工作……一切都会适时揭晓。

让我们先从一些基本模式的快速参考开始。更完整的描述在此列表之后。这个列表乍看可能很长，但请将注意力集中在称为 "primary patterns" 的模式上。它们是最基本且最常用的。

同样，目的是开始学习模式的词汇——就像学习人类语言时学习新单词一样。你随时可以回头再看其余部分。

要了解这些模式中任何一个的更多信息，请选择类名并使用编辑器的帮助键打开其帮助文件。

快速参考

主要模式

Pseq(list, repeats, offset)

将整个列表播放 repeats 次。类似 list.do。

Prand(list, repeats)

从列表中随机选择项目（与 list.choose 相同）。

Pxrand(list, repeats)

随机选择，但绝不在紧邻的连续两次中重复同一项。

Pshuf(list, repeats)

以随机顺序打乱列表，并使用相同的随机顺序重复 times 次。类似 list.scramble。

Pwrand(list, weights, repeats)

根据加权概率随机选择（与 list.wchoose(weights) 相同）。

Pseries(start, step, length)

等差数列（加法）。

Pgeom(start, grow, length)

几何级数（乘法）。

Pwhite(lo, hi, length)

随机数，均匀分布（“白噪声”）。类似 rrand(lo, hi) 。

Pexprand(lo, hi, length)

随机数，指数分布。类似 exprand(lo, hi) 。

Pbrown(lo, hi, step, length)

布朗运动，算术刻度（加法）。

Pfunc(nextFunc, resetFunc)

从用户提供的函数获取流值。

Pfuncn(func, repeats)

从函数获取值，但在重复项之后停止。

Prout(routineFunc)

像例程一样使用该函数。该函数应使用 .yield 或 .embedInStream 返回值。

附加的 List 模式

Pser(list, repeats, offset)

按需多次遍历列表，但只输出重复的项。

Pslide(list, repeats, len, step, start, wrapAtEnd)

播放列表中重叠的片段。

Pwalk(list, stepPattern, directionPattern, startPos)

在列表上随机游走。

Place(list, repeats, offset)

交错主列表中出现的所有数组。

Ppatlace(list, repeats, offset)

将主列表中找到的所有模式交织在一起。

Ptuple(list, repeats)

将列表项收集到数组中作为返回值。

其他随机数生成器

Pgbrown(lo, hi, step, length)

布朗运动，几何尺度（乘法）。

Pbeta(lo, hi, prob1, prob2, length)

Beta 分布，其中 prob1 = α (alpha) 且 prob2 = β (beta)。

Pcauchy(mean, spread, length)

柯西分布。

Pgauss(mean, dev, length)

高斯（正态）分布。

Phprand(lo, hi, length)

返回两个均匀分布随机数中较大的一个。

Plprand(lo, hi, length)

返回两个等分布随机数中较小的那个。

Pmeanrand(lo, hi, length)

返回两个均匀分布随机数的平均值，即 (x + y) / 2。

Ppoisson(mean, length)

泊松分布。

Pprob(distribution, lo, hi, length, tableSize)

任意分布，基于概率表。

模式的功能性描述

列表模式

使用模式最显而易见的做法是给它一个值列表，并让它按顺序读出这些值。你有几种选择，它们对 repeats 参数的处理方式不同。

Pseq(list, repeats, offset)

将整个列表播放 repeats 次。

Pser(list, repeats, offset)

按需多次遍历列表，但只输出重复的项。

Pseq(#[1, 2, 3], 4).asStream.all;    // 12 项 = 4 次重复 * 3 项
Pser(#[1, 2, 3], 4).asStream.all;    // 仅 4 项

Pseq 是流式输出已知音高和节奏值的明显选择。

在播放诸如这样的 Pbind 模式之前，请确保服务器已启动。

s.boot;

(
p = Pbind(
    \degree, Pseq(#[0, 0, 4, 4, 5, 5, 4], 1),
    \dur, Pseq(#[0.5, 0.5, 0.5, 0.5, 0.5, 0.5, 1], 1)
).play;
)

要停止本文件中的示例，请使用“stop”键盘快捷键（macOS 上为 cmd-.，Windows 上为 alt-.，其他编辑器请查阅文档）。或者：

p.stop;

一个变体，Pslide，播放输入列表的重叠片段。

Pslide(list, repeats, len, step, start, wrapAtEnd)

播放列表中重叠的片段。

repeats

段数

len

每个段的长度

step

是每个段的起点相对于前一个段步进的距离。

start

从哪个索引开始。

wrapAtEnd

如果为 true（默认值），当索引超出开头或结尾时会回绕。如果为 false，则当模式遇到 nil 元素或超出列表边界时停止。

如果 step == 1，则第一个段位于 start，第二个段位于 start + 1，依此类推。

Pslide(#[1, 2, 3, 4, 5, 6, 7, 8], 10, 3, 1, 0, false).asStream.all;

// 或者，将各段显示为单独的数组
Pslide(#[1, 2, 3, 4, 5, 6, 7, 8], 10, 3, 1, 0, false).clump(3).asStream.all;

// Flock of Seagulls！
(
p = Pbind(
    \degree, Pslide((-6, -4 .. 12), 8, 3, 1, 0),
    \dur, Pseq(#[0.1, 0.1, 0.2], inf),
    \sustain, 0.15
).play;
)

随机顺序列表模式

Prand(list, repeats)

从列表中随机选择项目（与 list.choose 相同）。

// Prand：给定音阶度数（五声音阶），每个概率相等
(
p = Pbind(
    \degree, Prand([0, 1, 2, 4, 5], inf),
    \dur, 0.25
).play;
)
Pxrand(list, repeats)

随机选择，但绝不在紧邻的连续两次中重复同一项。

// Pxrand：与上面相同，但从不连续重复同一个音高
(
p = Pbind(
    \degree, Pxrand([0, 1, 2, 4, 5], inf),
    \dur, 0.25
).play;
)
Pshuf(list, repeats)

以随机顺序打乱列表，并使用相同的随机顺序重复 times 次。类似 list.scramble。

// Pshuf：随机排序一次并重复
(
p = Pbind(
    \degree, Pshuf([0, 1, 2, 4, 5], inf),
    \dur, 0.25
).play;
)
Pwrand(list, weights, repeats)

根据加权概率随机选择（与 list.wchoose(weights) 相同）。

// Pwrand：这些概率偏向于音阶级数中的三和弦音
(
p = Pbind(
    \degree, Pwrand((0..7), [4, 1, 3, 1, 3, 2, 1].normalizeSum, inf),
    \dur, 0.25
).play;
)
Pwalk(list, stepPattern, directionPattern, startPos)

在列表上进行随机游走。此模式稍复杂一些；详情请参阅其帮助文件。

交错取值并创建数组

这些是相反的操作：交错意味着拆分数组并将其合并为单值流，而数组也可以由单值流构成。

Place(list, repeats, offset)

依次从主数组项中的每一项取一个。难以解释，但更易于查看：

Place([0, [1, 2], [3, 4, 5]], 3).asStream.all;
--> [ 0, 1, 3, 0, 2, 4, 0, 1, 5 ]

如果把它变成一个矩阵并垂直读取，原始数组就清晰可见：

Place([0, [1, 2], [3, 4, 5]], 3).clump(3).do(_.postln);

[ 0, 1, 3 ]    // 最左列：来自第一个 Place 项的 0
[ 0, 2, 4 ]    // 第二列：从第二个 Place 项开始，在 1 和 2 之间交替
[ 0, 1, 5 ]    // 第三列：来自第三个 Place 项的 3、4、5
Ppatlace(list, repeats, offset)

按顺序从每个子模式中取一个值。

// Hanon 练习
(
p = Pbind(
    \degree, Ppatlace([
        Pseries(0, 1, 8),    // 第一、第三等音符
        Pseries(2, 1, 7)    // 第二、第四等音符
    ], inf),
    \dur, 0.25
).play;
)

这也是即将出现的内容的一个示例：模式可以嵌套。

Ptuple(list, repeats)

从数组中的每一项获取一个值，并将它们全部作为值数组返回。

// 和弦
// \degree 依次接收 [7, 9, 4]，然后 [6, 7, 4]，在服务器上扩展为和弦
(
p = Pbind(
    \degree, Ptuple([
        Pseries(7, -1, 8),
        Pseq([9, 7, 7, 7, 4, 4, 2, 2], 1),
        Pseq([4, 4, 4, 2, 2, 0, 0, -3], 1)
    ], 1),
    \dur, 1
).play;
)

算术级数和几何级数

现在，让我们转向用数学方式产生值的模式，而不使用预定义列表。

Pseries(start, step, length)

等差数列，依次将步长加到起始值上，返回共 length 项。

Pgeom(start, grow, length)

等比级数，依次将当前值乘以 grow。

// 使用 Pseries 表示音阶，使用 Pgeom 表示渐快
(
p = Pbind(
    \degree, Pseries(-7, 1, 15),
    \dur, Pgeom(0.5, 0.89140193218427, 15)
).play;
)

第三方扩展提醒：如果你想让一个算术级数或几何级数从某个数开始并在另一个特定数结束，步长/乘数必须根据端点和所需项目数计算得出。ddwPatterns quark 为 Pseries 和 Pgeom 都包含一个便捷方法 fromEndpoints，用于执行此计算。必须给出精确的重复次数，至少为二且小于无穷大。

p = Pgeom.fromEndpoints(0.5, 0.1, 15);    // 如果未安装 ddwPatterns 则报错
p.postcs;

Prints:

Pgeom(0.5, 0.89140193218427, 15)

随机数与概率分布

Pwhite(lo, hi, length)

生成具有均匀分布的长度随机数（“white”指白噪声）。

Pexprand(lo, hi, length)

相同，但随机数具有指数分布，偏向较小的数值。这适用于频率，也适用于时值（因为你需要更多短时值的音符来平衡长音符的权重）。

Pbrown(lo, hi, step, length)

布朗运动。每个值都在前一个值的基础上加上一个随机步长，其中步长在 -step 与 +step 之间均匀分布。

Pgbrown(lo, hi, step, length)

几何尺度上的布朗运动。每个值将随机步长因子乘到前一个值上。

Pbeta(lo, hi, prob1, prob2, length)

Beta 分布，其中 prob1 = α (alpha) 且 prob2 = β (beta)。

Pcauchy(mean, spread, length)

柯西分布。

Pgauss(mean, dev, length)

高斯（正态）分布。

Phprand(lo, hi, length)

返回两个均匀分布随机数中较大的一个。

Plprand(lo, hi, length)

返回两个等分布随机数中较小的那个。

Pmeanrand(lo, hi, length)

返回两个均匀分布随机数的平均值，即 (x + y) / 2。

Ppoisson(mean, length)

泊松分布。

Pprob(distribution, lo, hi, length, tableSize)

给定一个跨所需范围的相对概率数组（直方图），表示任意分布，生成与该分布对应的随机数。

要查看分布，可将其制作成直方图。

Pmeanrand(0.0, 1.0, inf).asStream.nextN(10000).histo(200, 0.0, 1.0).plot;

兜底模式

并非所有内容都预先编写为模式类。这些模式让你可以嵌入自定义逻辑。

Pfunc(nextFunc, resetFunc)

下一个值是求值 nextFunc 的返回值。如果对由该模式创建的流调用 .reset，则会对 resetFunc 求值。流将无限运行，直到 nextFunc 返回 nil。

Pfuncn(func, repeats)

与 Pfunc 一样，输出值来自对函数的求值。然而，Pfuncn 恰好返回指定重复次数的值，然后停止。默认重复次数为 1。

Prout(routineFunc)

在例程中使用 routineFunc。流的输出值就是该函数 .yields 的值。当 Prout 产出 nil 时结束。
