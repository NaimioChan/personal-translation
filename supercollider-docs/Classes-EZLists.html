EZLists

EZListView 和 EZPopUpMenu 的抽象父类

参见：EZListView、EZPopUpMenu

说明

用户通常不会直接创建 EZLists 的实例，而只是通过其子类来使用它。它为 EZListView 和 EZPopUpMenu 提供了基本机制。

类方法

.new

实例方法

构建和更改列表

.globalAction

设置/获取除项函数之外还要执行的全局函数：{ |listObj| value }。

.items

设置/获取一个 Array，其中包含标签和条目函数：['label' -> { |listObj| value }, ]。

讨论：

在菜单中，macOS 图形系统会为某些字符赋予特殊含义。参见 PopUpMenu；或者是一个 Symbol 组成的 Array（如果你只使用 globalAction）。Symbol 的 Array 会被转换为 Association 组成的数组，其中 Function 为空 ['label' -> { }, ]。

.item

返回值：

当前选择项的标签。

.itemFunc

返回值：

当前选中的条目函数。

.addItem

添加一个项。

参数：

name

String 或 Symbol 的实例。列表/菜单项的名称。

action

Function 的一个实例。

.insertItem

在索引位置插入一个列表/菜单项。

参数：

index

一个 Integer。插入项所在的索引。

name

String 或 Symbol 的实例。列表/菜单项的名称。

action

Function 的一个实例。

.replaceItemAt

替换索引位置处的列表/菜单项。

参数：

index

一个 Integer。插入项所在的索引。

name

String 或 Symbol 的实例。列表/菜单项的名称。默认为当前项标签。

action

一个 Function 的实例。默认值为当前项动作。

.removeItemAt

移除索引位置处的列表/菜单项。

参数：

index

一个 Integer。要移除项所在的索引。

.remove

从父视图中移除视图、标签以及列表/菜单。

访问值

.value

将列表/菜单的索引设置为 value。不执行该操作。

参数：

val

一个 Integer。

.valueAction

在索引值处设置值并执行动作，同时执行全局动作。

参数：

val

一个 Integer。

.doAction

在当前索引处执行该操作以及全局操作。

.initViews

由 init 调用并由所有子类重写。此处构建类特有的视图。
