SelectX

混合来自多个源的一个输出

Object

参见：Select、SelectXFocus、LinSelectX

子类：LinSelectX

说明

输出由输入数组混合而成，在两个相邻通道之间执行等功率交叉淡化。

类方法

SelectX.ar(which, array, wrap: 1)

SelectX.kr(which, array, wrap: 1)

参数：

which

array

wrap

wrap 尚不可用。

未文档化的类方法

SelectX.crossfadeClass

实例方法

示例

(
{
    var a;
    a = [
            SinOsc.ar,
            Saw.ar(300),
            Pulse.ar(230)
        ];

    SelectX.ar(MouseX.kr(0, 1) * a.size, a) * 0.2
}.play;
)

(
{
    var a;
    a = [
            SinOsc.kr(0.25),
            LFSaw.kr(10),
            LFPulse.kr(0.3)
        ];

    SinOsc.ar(SelectX.kr(MouseX.kr(0, 1) * a.size, a) * 300 + 400) * 0.2
}.play;
)

注意： 所有 UGen 都在持续运行。如果每个输入都消耗大量 CPU，这可能不是最高效的方式。数组在编写 SynthDef 时就已经固定，整个数组会嵌入到 SynthDef 文件本身中。对于小数组，这比从缓冲区读取更高效。

wrap 尚不可用。

（通过 adc）
