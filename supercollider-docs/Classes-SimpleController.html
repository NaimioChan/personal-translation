SimpleController

根据模型-视图-控制器（M-V-C）范式的控制器

Object

另请参阅：Object

说明

SimpleController 可以按照模型-视图-控制器（M-V-C）范式用作控制器。它提供了一个 IdentityDictionary 用于存放动作，当所附加的模型通过调用 changed 发送通知时，这些动作就会被调用。

类方法

SimpleController.new(model)

创建一个带有待观察模型的 SimpleController 实例。

参数：

model

任意类的对象

实例方法

.put(what, action)

参数：

what

注册一个动作，当模型调用 changed(what, moreArgs) 时调用该动作。

action

要注册的动作。

.remove

移除已注册的操作。

参数：

(action)

要移除的动作

未文档化的实例方法

.removeAt(what)

示例

(
var controller, model, view;

model = Ref(0.5);
controller = SimpleController(model);
controller.put(\value,
    { |theChanger, what, moreArgs|
        view.value_(theChanger.value);
    });

view = Slider(Window("slider", Rect(100, 100, 330, 38)).front, Rect(5, 5, 320, 20));
view.onClose_{ controller.remove };

// 运行一个 routine 来改变 model 的值：
r{
    100.do{
        model.value_(1.0.rand.postln).changed(\value);
        0.5.wait;
    }
}.play(AppClock)
)
