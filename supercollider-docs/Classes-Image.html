Image

图像组件

参见：View

说明

Image 支持在 SuperCollider GUI 中绘制图像。

类方法

.new

创建一个新的 Image 实例。此处的 "multiple" 表示多个参数。

参数：

multiple

以下任意一项：

  • 用于创建宽和高均为 size 倍数的空图像的数字

    i = Image.new(400);        // 创建一个 400x400 像素的 Image。
i.bounds;
i.free;

i = Image.new(400, 200);    // 创建一个 400x200 像素的 Image。
i.bounds;
i.free;

  • 用于创建空图像的点，其宽度为 multiple.x，高度为 multiple.y

    i = Image.new(400@200);    // 创建一个 400x200 像素的 Image。
i.bounds;
i.free;

  • 从本地文件创建图像的字符串

    //    路径字符串
i = Image.new(SCDoc.helpSourceDir +/+ "images/Swamp.png"); // 将路径添加到你的镜像中
[i.width, i.height].postln;
i.bounds;
i.plot;
i.free;

height

如果 multiple 是一个数字，则该参数表示新图像的高度。

.color

创建一个用指定颜色填充的新 Image 实例。

i = Image.color(400, 200, Color.blue(0.9, 0.1));
i.plot(freeOnClose: true);

参数：

... args

多个参数。最后一个参数应为有效的 Color

.open

从 path 处的本地文件创建一个新的 Image 实例。

(
i = Image.open(SCDoc.helpSourceDir +/+ "images/Swamp.png");
i.plot(freeOnClose: true);
i.url.postln;
)

.openSVG

从 path 处的本地 SVG 文件创建一个新的 Image 实例。

(
i = Image.openSVG(SCDoc.helpSourceDir +/+ "images/plugin.svg", 200@200);
i.plot(freeOnClose: true);
i.url.postln;
)

参数：

path

包含 SVG 文件路径的 String。

size

一个 Size。SVG 内容将被绘制到此尺寸的图像中。如果未提供，则使用 SVG 提供的建议尺寸。

i = Image.openURL(SCDoc.helpSourceDir +/+ "images/Swamp.png");

.fromImage

从另一个 Image 创建一个新的 Image 实例。

i = Image.new(SCDoc.helpSourceDir +/+ "images/Swamp.png");
j = Image.fromImage(i);
i.dump;
j.dump;
[i, j].do(_.plot);
[i, j].do(_.free);

.fromWindow

从 Window 的一部分创建新的 Image。这可用于捕获窗口或特定 View。

// WINDOW 示例：
// 首先创建一个窗口并在其中绘制
(
    w = Window.new;
    w.front; // 注释掉此行以复制离屏窗口
    w.view.background_(Color.white);
    w.drawHook = {
        Pen.translate(100, 100);
        10.do{
            // 设置颜色
            Pen.color = Color.blue(rrand(0.0, 1), rrand(0.0, 0.5));
            Pen.addWedge((100.rand)@(100.rand), rrand(10, 100), 2pi.rand, 2pi.rand);
            Pen.perform([\stroke, \fill].choose);
        }
    };
    w.refresh;
)

// 然后抓取窗口
(
    i = Image.fromWindow(w);
    w.close;
    i.plot(freeOnClose: true);
)

// VIEW Capture 示例：
// 首先创建一个窗口并在其中添加一些视图
(
    w = Window.new.front;
    b = [10, 80].asSpec;
    c = NumberBox(w, Rect(20, 20, 60, 40));
    a = Slider(w, Rect(20, 80, 100, 40))
        .focusColor_(Color.red(alpha: 0.2))
        .action_({
            c.value_(b.map(a.value).round(0.01))
    // 对浮点数取整，使其能放入 NumberBox
            });
)

// 然后抓取窗口
(
    i = Image.fromWindow(w, a.bounds);
    w.close;
    i.plot(freeOnClose: true);
)

参数：

window

Window 对象。

rect

可选。要在 Window 内捕获的约束矩形。默认情况下，它是窗口大小。

实例方法

commons / 通用属性

.width

返回或设置接收者的宽度

.height

返回或设置接收者的高度

.setSize

设置接收者的大小

.bounds

返回接收者的边界。

.free

释放接收者。如果你想自己管理和回收资源，此方法很有用。否则你不需要调用此方法，因为每个对象都会被自动垃圾回收。

.scalesWhenResized

用于告知或设置接收者是否应在执行调整大小操作时更新其位图表示以进行缩放的标志

(
i = Image.new(SCDoc.helpSourceDir +/+ "images/Swamp.png");
i.bounds.postln; // 获取维度
w = i.plot;
)

// 改变图像的大小
(
i.scalesWhenResized_(true);
i.setSize(400, (400 / (i.width / i.height)).asInteger);
a = i.plot;
)

(
a.close; w.close; i.free;
)

.url

返回或设置接收者的 url。仅当在创建时提供了 url 时才返回，否则返回 nil。设置可用于不同目的，但请尽量提供一个有效的 url，因为它用于将镜像归档为对象。

i = Image.new("http://www.google.com/intl/en_ALL/images/logo.gif");
i.url;
i.plot;
i.free;

.interpolation

获取或设置渲染图像时使用的插值级别——当图像加速时它不起作用。有效取值范围见 *interpolations。

(
i = Image.new(SCDoc.helpSourceDir +/+ "images/Swamp.png");
w = i.plot;
i.interpolation;            // 获取图像当前的插值模式
)

(
i.interpolation = 'fast';        // 尝试不同的插值模式
w.refresh;
)

(
i.interpolation = 'smooth';
w.refresh;
)

i.free;

参数：

path

保存它的位置

format

（可选）要使用的格式。支持的格式参见 Image.formats。如果为 nil，则根据路径扩展名获取格式。

quality

质量因子必须在 0 到 100 或 -1 的范围内。指定 0 以获得小的压缩文件，100 以获得大的未压缩文件，-1（默认值）以使用默认设置。

.plot

参数：

Window 的标题。可以为 nil。

bounds

Window 的边界。可能为 nil。

freeOnClose

一个标志，用于告知 Window 在关闭时是否应释放 Image。

background

应用于 Window 的额外背景。对于 alpha / 合成导致的伪影可能有用...

当鼠标位于图像的绘图窗口上时显示像素坐标。

.draw

在图像内部绘制的快捷方式。等价于：

  • aFunction

        Pen.translate(100, 100);

                rrand(51, 100),

                2pi.rand

)

//    图像上的字符串绘制支持

    j.draw({ |bounds|
        j.drawStringAtPoint("Hello, world!", 10@10, Font("Lucida Grande", 24), Color.black);

.drawStringAtPoint

在 Image 中 *正确* 渲染 String :) // to fix to have a compliant interface

(
    var width, height, tgHeight, ratio, str, font, color, strb, targetWidth = 400, shadowColor, run = true;
    shadowColor = Color.black;

    color = Color.gray(0.8);
    str = "I Love Pixels";
    font = Font("Monaco", 10);
    strb = str.bounds(font);
    width = strb.width;
    height = strb.height;
    ratio = height / width;
    i = Image(width@(height));
    i.draw({ |bb|
        Pen.smoothing_(false);
        i.drawStringAtPoint(str, 0@0, font, color);
    });
    i.interpolation_(\none);
    tgHeight = targetWidth * ratio;
    w = Window.new("", Rect(400, 400, 450, 150)).drawHook_({
        Pen.setShadow(2@2, 0.4, color: Color.red);
        i.drawInRect(Rect(5, 5, targetWidth, tgHeight));
    });

    w.view.background_(Color.white);
    w.onClose_({ run = false; i.free });
    w.front;
)

.drawAtPoint

在当前图形上下文中渲染图像或其一部分。

(
    var operation = 'sourceOver', fraction = 1.0, i, w;

    i = Image.new(
    //    "http://supercollider.sourceforge.net/theme/sc01/icon.supercollider.gif"
    //    SCDoc.helpSourceDir +/+ "images/duck_alpha.png"
        SCDoc.helpSourceDir +/+ "images/Swamp.png"
    );

    w = Window.new("Image", Rect(120, 400, 360, 180)).front;

    Slider.new(w, Rect(10, 150, 150, 16))
        .value_(1.0)
        .action_({ |sl|
            fraction = sl.value;
            w.refresh;
        });

    PopUpMenu.new(w, Rect(170, 150, 100, 16))
        .items_(Image.compositingOperations.collect({ |i| i.asString }))
        .value_(2)
        .action_({ |pm|
            operation = Image.compositingOperations.at(pm.value);
            w.refresh;
        });

    w.onClose_({ i.free }); // 窗口关闭时释放图像

    w.drawHook_({

        i.drawAtPoint(10@10, nil, operation, fraction);

    });
)

point

fraction

实例方法 / 访问和设置像素

.setPixel

填充位于 x @ y 的像素。

i = Image.color(60, 60, Color.blue(0.1, 0.1));
w = i.plot;
i.setPixel(Image.colorToPixel(Color.new(1, 0, 0, 1)), 0, 0); // 设置红色
w.refresh;
("pixel at 0 @ 0:"+Image.pixelToColor(i.getPixel(0, 0)).asArray).postln;
i.free;

参数：

rgbaInteger

一个 32 位 Integer，包含以 8 位 RGBA 打包的颜色信息

x

图像中像素的 x 位置

y

图像中像素的 y 位置

.getPixel

以 RGBA 整数形式获取 x @ y 处的像素值

// 使用 Image 操作像素的简单示例
(
b = Int32Array[
    Image.colorToPixel(Color.new255(255, 0, 0, 255)), // red
    Image.colorToPixel(Color.new255(0, 255, 0, 255)), // green
    Image.colorToPixel(Color.new255(0, 0, 255, 255)), // blue
    Image.colorToPixel(Color.new255(255, 0, 255, 255)) // purple
];
)

Image.pixelToColor(b[0]).red; // 1.0 参见 Color -red
Image.pixelToColor(b[0]).green; // 0.0 见 Color -green
Image.pixelToColor(b[0]).blue; // 0.0 参见 Color -blue
Image.pixelToColor(b[0]).alpha; // 1.0 见 Color -alpha

a = Image.new(b.size@1).pixels_(b).interpolation_(\fast);
a.plot;


// 设置 + 获取
a.setPixel(Image.colorToPixel(Color.new255(255, 0, 255, 128)) /* 从 0-255 整数 rgba 值创建一个 Integer*/, 0, 0).plot;
p = a.getPixel(0, 0);

Image.pixelToColor(p).red; // 1.0
Image.pixelToColor(p).green; // 0.0
Image.pixelToColor(p).blue; // 1.0
Image.pixelToColor(p).alpha; // ~0.5

// 现在看另一个重要的例子
a.setPixel(Image.colorToPixel(Color.new255(255, 0, 255, 0)), 1, 0).plot; // 清除颜色 -> alpha 为 0
p = a.getPixel(1, 0);

Image.pixelToColor(p).red; // 你期望得到 1.0，但得到的是 0.0 ？？？原因 = Image 内部使用的是预乘颜色分量值
// 意味着所有 Red、Green 和 Blue 分量都已预乘 alpha
// 如果 alpha 为 0，则所有分量返回 0。

Image.pixelToColor(p).green; // 0
Image.pixelToColor(p).blue; // 0
Image.pixelToColor(p).alpha; // 0

p = a.getColor(1, 0); // 更显式 —— 但这里也一样

数组起始索引。

.pixelRatio

获取/设置图像的像素比。

这不会影响图像的内容，只影响将图像绘制到 View 或另一个 Image 上时的解释方式。例如，在高 DPI 环境中，View 的像素比可能为 2。当绘制像素比为 1 的图像时，图像的每个像素将填充 View 的 2x2 区域。如果 Image 和 View 的像素比都为 2，则每个像素将与 View 中的像素保持 1:1。

默认情况下，所有 Image 的 pixelRatio 都为 1——这确保图像在普通 DPI 或高 DPI 视图上绘制时看起来相同。设置自定义（!= 1）的 pixelRatio 通常只应用于将特别渲染的高 DPI 图像绘制到已知为高 DPI 的 View 上。

注意，使用 Pen 绘制到 Image 时会考虑 pixelRatio——因此，对于 image.pixelRatio==1 的图像，宽度为 1 的线真实宽度为 1px；对于 image.pixelRatio==2 的图像，真实宽度为 2px。
