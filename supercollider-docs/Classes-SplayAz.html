SplayAz

将一个通道数组散布到一个通道环上

UGen : AbstractFunction : Object

另请参阅：Splay、PanAz、SelectXFocus、LevelComp、混音和声像时的电平补偿

说明

SplayAz 将一组声道扩展到一圈声道上。提供可选的 spread 和 center 控制，以及可调的电平补偿，可实现等功率和/或等幅度。numChans 和 orientation 与 PanAz 中相同。

{ SplayAz.ar(5, [SinOsc.ar, Saw.ar], 0, 1) }.plot;

类方法

SplayAz.ar(numChans: 4, inArray, spread: 1, level: 1, width: 2, center: 0.0, orientation: 0.5, levelComp: true)

SplayAz.kr(numChans: 4, inArray, spread: 1, level: 1, width: 2, center: 0.0, orientation: 0.5, levelComp: true)

每个输入在 pos 上以 2.0 为循环周期均匀分布，其中 0.0 对应声道零，2.0/numChans 对应声道 1，4.0/numChans 对应声道 2，依此类推。

输出范围内输入信号之间的距离由 spread 参数决定。

参数：

numChans

UGen 的输出通道数

inArray

输入信号（可以是单个 UGen 或数组）

spread

输入信号在输出中的间隔距离。如果为零，则所有内容都混合到中心位置（见下文）。

{ SplayAz.ar(6, [SinOsc.ar, Saw.ar(800)], spread: MouseX.kr(0, 1).poll) * 0.3 }.scope;

level

所有信号的缩放

width

每个信号分配到各通道的比例。

center

哪个通道将成为第一个通道

orientation

如果前方是多边形的一个顶点，则应为零。第一个扬声器将位于正前方。如果前方平分多边形的一条边，则应为 0.5。此时第一个扬声器将是中心偏左的那个。

levelComp

一个标志或数值：

  • true：保持等功率，使整体响度保持不变。
  • false：关闭 / 无电平变化，

  • 介于 0.0 和 1.0 之间的浮点数：levelComp 因子的平滑调节：

    • 0.0 为无 -> 因子 1
    • 0.5 为等功率 -> 因子 (1/n).squared
    • 1.0 为等幅 -> 因子 (1/n)

完整讨论见 LevelComp。

实例方法

示例

(
x = { |spread = 1, level = 0.2, width = 2, center = 0.0|
 SplayAz.ar(
  4,
  SinOsc.ar({ |i| LFNoise2.kr(rrand(10, 20), 200, i + 3 * 100) } ! 10),
  spread,
  level,
  width,
  center
 );
}.scope;
)

x.set(\spread, 1,   \center, 0);  // 完整 n 声道
x.set(\spread, 0.5, \center, -0.25); // 较窄
x.set(\spread, 0, \center, 0);  // 单声道居中（取决于方向，参见 PanAz）
x.set(\spread, 0, \center, -0.25); //
x.set(\spread, 0.0, \center, 0.5); // 单声道, 但将 1 旋转到更高的通道
x.set(\spread, 0.5, \center, 0.5); // 分布到更高的声道
x.set(\spread, 0,   \center, -0.25); // 全部在第一个通道上
x.set(\spread, 1,   \center, 0);  // 完整 n 声道

x.free;

 // 使用 arFill 编写的相同示例：
(
x = { |spread = 1, level = 0.5, width = 2, center = 0.0|
 SplayAz.arFill(
  4,
  10,
  { |i| SinOsc.ar(LFNoise2.kr(rrand(10, 20), 200, i + 3 * 100)) },
  spread,
  level,
  width,
  center
 );
}.scope;
)

 // 或使用鼠标控制
(
x = { var src;
 src = SinOsc.ar({ |i| LFNoise2.kr(rrand(10, 20), 200, i * 100 + 400) } ! 10);
 SplayAz.ar(4, src, MouseY.kr(1, 0), 0.2, center: MouseX.kr(-1, 1));
}.scope;
)

// 测试行为是否正确：
    // 仅在通道 0 上
{ SplayAz.ar(4, SinOsc.ar * 0.2, orientation: 0) }.scope;

    //  在声道 0、3 上，即围绕环形均等分布
{ SplayAz.ar(6, SinOsc.ar([2, 3] * 200) * 0.2, orientation: 0) }.scope;

    // 在 0、2、4 上均匀分布
{ SplayAz.ar(6, SinOsc.ar([2, 3, 5] * 200) * 0.2, orientation: 0) }.scope;


    // SplayZ 的错误行为：
        // 在通道 2 上播放，但应该在 0 上播放
{ SplayZ.ar(4, SinOsc.ar * 0.2, orientation: 0) }.scope;

    //  错误：两者都混入通道 2，
    // 因为声像值 [-1, 1] 在环形上是同一位置
{ SplayZ.ar(6, SinOsc.ar([2, 3] * 200) * 0.2, orientation: 0) }.scope;

    // 错误的均匀分布到 pan 值 [-1, 0, 1]，其输出到声道 2、0、2
{ SplayZ.ar(6, SinOsc.ar([2, 3, 5] * 200) * 0.2, orientation: 0) }.scope;
