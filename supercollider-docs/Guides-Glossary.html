Glossary

一些相关词汇的术语表

buffer

一个服务器端头部和 32 位浮点采样数据数组。缓冲区用于声音文件、延迟线、全局控制数组以及合成器间补丁点数组。由客户端类 Buffer 表示。

class

一组对象的状态和行为的描述。

client

SC 分为两个独立的应用程序：客户端和服务器。客户端是 SuperCollider 语言实现的地方，也是执行代码的地方。服务器实际合成音频，包含 Synth 和 Group 的节点树，并响应来自客户端的 Open Sound Control 消息。更多信息请参见 Client vs Server。

group

一个节点的链表。组提供了同时控制许多节点执行的方式。组是一种节点。通俗地说，可以将组理解为其他节点的有序分组，其中可能同时包括 synth 和其他组。由客户端类 Group 表示。

interface

对象响应的消息集合。

instance

由类描述的对象之一。

实例变量

对象内部状态的一部分

message

请求对象执行某项操作。

method

为实现某个类的消息所需操作的描述。

MIDI

一种用于在合成器之间发送音乐控制数据的协议。

node

节点树中的一点，由合成引擎按深度优先遍历顺序执行。节点有两种类型：Synth 和 Group。它们分别由客户端类 Synth 和 Group 及其抽象父类 Node 表示。节点树定义了 Synth 的执行顺序。

object

具有数据（表示对象的状态）以及一组可对该对象执行的操作的事物。

Open Sound Control

由 UCBerkeley 的 CNMAT 定义的一种用于控制合成器的协议。参见 http://opensoundcontrol.org/。SuperCollider 使用 OSC 消息通过 UDP 或 TCP 在客户端和服务器之间通信。

OSC

参见 Open Sound Control。

polymorphism

不同类型的对象对同一消息作出不同响应的能力。

protocol

一组实现特定类型行为的消息。

receiver

消息发送的目标对象。

server

SC 分为两个独立的应用程序：客户端和服务器。客户端是 SuperCollider 语言实现的地方，也是执行代码的地方。服务器实际合成音频，包含 Synth 和 Group 的节点树，并响应来自客户端的 Open Sound Control 消息。更多信息请参见 Client vs Server。

synth

一个声音处理模块，基于某个特定的 synth 定义。类似于其他系统中的 “voice”。Synths 通过数字来引用。由客户端类 Synth 表示。

synth 定义

用于创建新 synth 的定义。Synth 定义就像 synth 的模式或设计。类似于其他系统中的“乐器”。由客户端类 SynthDef 表示。

TCP

一种用于通过网络流式传输数据的协议。

UDP

一种在网络上发送数据报的协议。
