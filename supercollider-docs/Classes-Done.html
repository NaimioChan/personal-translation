Done

监视另一个 UGen 以查看其何时结束

UGen : AbstractFunction : Object

另见：UGen、FreeSelfWhenDone、PauseSelfWhenDone

说明

某些 UGen 在播放完成时会设置一个 'done' 标志。此 UGen 在被设置为跟踪某个特定 UGen 时，会回显该标志。

可被 Done 跟踪的 UGen 有：

  • PlayBuf
  • RecordBuf
  • Line
  • XLine
  • EnvGen
  • Linen
  • BufRd
  • BufWr
  • Dbufrd
  • Dbufwr
  • DiskIn
  • VDiskIn
  • Demand

实例方法

示例

'done' 标志可用于在同一 synth 中触发其他事情：

(
SynthDef("Done-help", { |out, t_trig|
    var line, a, b;

    line = Line.kr(1, 0, 1);

    a = SinOsc.ar(440, 0, 0.1*line); // 声音淡出
    b = WhiteNoise.ar(Done.kr(line)*0.1); // 噪声从行尾开始

    Out.ar(out, Pan2.ar(a+b));
}).add;
)

Synth("Done-help"); // 注意这个 synth 没有自己的 doneAction，因此你需要手动释放它

'done' 标志可用于触发当前 synth 的延迟释放，这仅靠 doneActions 是无法实现的：

play {
    var env = Line.kr(1, 0, 2);
    var sig = PinkNoise.ar(env);
    FreeSelf.kr(TDelay.kr(Done.kr(env), 3));
    GVerb.ar(sig, 70, 7);
}

Actions

许多 UGen 实现了 doneActions。当 UGen 完成时，这些动作允许可选地释放或暂停所属的 synth 及其他相关节点。你可以使用此类中的常量来命名 doneActions，这比单独使用数字代码更清晰。可用的 doneActions 如下：

name

value

description

none

0

UGen 结束时不做任何事

pauseSelf

1

暂停所属的 synth，但不释放它

freeSelf

2

释放所属的 synth

freeSelfAndPrev

3

同时释放此 synth 和前一个节点

freeSelfAndNext

4

同时释放此 synth 和后一个节点

freeSelfAndFreeAllInPrev

5

释放此 synth；如果前一个节点是组，则对其执行 g_freeAll，否则释放它

freeSelfAndFreeAllInNext

6

释放此 synth；如果后一个节点是组，则对其执行 g_freeAll，否则释放它

freeSelfToHead

7

释放此 synth 以及该组中所有在它之前的节点

freeSelfToTail

8

释放此 synth 以及该组中所有在它之后的节点

freeSelfPausePrev

9

释放此 synth 并暂停前一个节点

freeSelfPauseNext

10

释放此 synth 并暂停后一个节点

freeSelfAndDeepFreePrev

11

释放此 synth，若前一个节点是组，则对其执行 g_deepFree，否则直接释放它

freeSelfAndDeepFreeNext

12

释放此 synth，若后一个节点是组，则对其执行 g_deepFree，否则直接释放它

freeAllInGroup

13

释放此 synth 以及此组中的所有其他节点（之前和之后）

freeGroup

14

释放外层组及其中的所有节点（包括此 synth）

freeSelfResumeNext

15

释放此 synth 并恢复后续节点

有关 freeAll 和 deepFree 的信息，请参见 Group 和 Server Command Reference。

Alternatives

当某个 UGen 播放完毕后释放 synth 的另一种方法是使用 FreeSelfWhenDone，或将 FreeSelf 与 Done 结合使用。例如，这可用于延迟释放，让混响尾音逐渐淡出等。
