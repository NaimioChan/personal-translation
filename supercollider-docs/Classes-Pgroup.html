Pgroup

启动一个新的 Group 并在该组中播放模式

PAbstractGroup : FilterPattern : Pattern : AbstractFunction : Object

另请参阅：Group、Pbus

说明

当流结束时，组会被释放。组的 release 会延迟（默认 0.1 拍），直到最后一个音符释放之后。但是，Pgroup 并不知道合成器包络持续多长时间。你可以将拍数放入事件原型的 \groupReleaseTime 键来延长延迟时间：

Pgroup(...).play(protoEvent: Event.default.put(\groupReleaseTime, releaseLag));

实例方法

示例

p = Pbind(\degree, Prand((0..7), inf), \dur, 0.3, \legato, 0.2);

 // 监听节点结构的变化
s.waitForBoot({ s.plotTree });

// 一组
Pgroup(p).play;

// 两个嵌套组
Pgroup(Pgroup(p)).play;
Pgroup(Ppar([Pgroup(p), Pgroup(p)])).play;
