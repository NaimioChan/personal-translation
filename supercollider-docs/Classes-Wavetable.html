Wavetable

wavetable 格式的采样音频缓冲区

FloatArray : RawArray : ArrayedCollection : SequenceableCollection : Collection : Object

参见：Signal

说明

Wavetable 是一种采用特殊格式的 FloatArray，供 SuperCollider 的插值振荡器使用。Wavetable 不能通过 new 创建。

类方法

Wavetable.sineFill(size, amplitudes, phases)

用给定振幅和相位的正弦和填充给定大小的 Wavetable。该 Wavetable 将被归一化。

Wavetable.sineFill(512, 1.0/[1, 2, 3, 4, 5, 6]).plot;

参数：

size

必须是 2 的幂。

amplitudes

从基频开始的每个谐波的振幅数组。

phases

一个数组，包含从基频开始的每个谐波的相位（以弧度为单位）。

Wavetable.chebyFill(size, amplitudes, normalize: true, zeroOffset: false)

用给定幅度下的切比雪夫多项式之和填充给定大小的 Wavetable，以供 Shaper ugen 进行波形整形。

参数：

size

必须是 2 的幂加 1，最终的波表大小为下一个 2 的幂。

amplitudes

一个 Array，包含每个 Chebyshev 多项式的振幅，从 1 阶开始。

normalize

一个 Boolean，表示是否对生成的 Wavetable 进行归一化。如果 zeroOffset 参数为 true，则归一化按照传递函数的方式进行，使用 normalizeTransfer，否则只使用 normalize 使绝对峰值变为 1。默认值为 true。

zeroOffset

一个 Boolean，指示是否将每个多项式的中间部分偏移到零。如果为 true，那么当用作 waveshaper 时，零输入将始终产生零输出。如果为 false，则使用“原始”（未偏移的）Chebyshev 多项式。默认值为 false。

讨论：

注意： 在之前的版本中，chebyFill 总是对曲线进行偏移以确保中心值为零。zeroOffset 参数在 3.7 版本中加入，并且默认行为发生了改变，因此它不再进行偏移。

Wavetable.chebyFill(513, [1]).plot;

// 偏移以避免对零信号进行波形整形时的直流偏移
Wavetable.chebyFill(513, [0, 1], zeroOffset: true).plot;

// （未平移的）Chebyshev 多项式的归一化和（默认）
Wavetable.chebyFill(513, [0, 1, 0, 0, 0, 1], normalize: true, zeroOffset: false).plot;

Wavetable.chebyFill(513, [0, 0, 1]).plot;
Wavetable.chebyFill(513, [0.3, -0.8, 1.1]).plot;


// This waveshaping example uses two buffers, one with zero offset and
// the other not.
//
// 1. The offset version gives zero output (DC free) when waveshaping an
// input signal with amplitude of zero (e.g. DC.ar(0)).
//
// 2. The non-offset version makes better use of the full (-1 to 1) range
// when waveshaping a varying signal with amplitude near 1, but (if even
// Chebyshev polynomial degrees are used) will have a DC offset when
// waveshaping a signal with amplitude of zero.
//
// 3. Wrapping the non-offset Shaper in a LeakDC (the third signal in the
// example) cancels out any DC offsets (third version), while making full use
// of the -1 to 1 range.
(
s.waitForBoot({
    var amplitudes = [0, 1, 1, -2, 1];
    var wavs = [
        Wavetable.chebyFill(256+1, amplitudes, normalize: true, zeroOffset: true),
        Wavetable.chebyFill(256+1, amplitudes, normalize: true, zeroOffset: false)
    ];
    b = wavs.collect{ |wav| Buffer.loadCollection(s, wav) };
    s.sync;
    x = {
        var in = SinOsc.ar(100, 0, SinOsc.kr(0.1, 0, 0.5, 0.5));
        Shaper.ar(b, in) ++ LeakDC.ar(Shaper.ar(b[1], in))
    }.scope;
})
)
x.free; b.do(_.free); b = nil;

实例方法

.plot: METHOD NOT FOUND!

在窗口中绘制 Wavetable。参数不是必需的，如果未给出将使用默认值。

Wavetable.sineFill(512, [1]).plot("Table 1", Rect(50, 50, 150, 450));

参数：

name

一个 String，窗口的名称。

bounds

一个 Rect，给出窗口的边界。

minval

绘图中的最小值。默认为数据中的最高值。

maxval

绘图中的最大值。默认为数据中的最低值。

parent

可以传入一个 Window 或 View——此时绘图嵌入其中。否则将创建一个新的 Window。

(

Wavetable.sineFill(512, 1.0/[1, 2, 3, 4, 5, 6]).plot(parent: w);
w.front

.asSignal

将 Wavetable 转换为 Signal。

Wavetable.sineFill(512, [1]).asSignal.plot;

高级说明：波表格式

Signal: [a0, a1, a2...]
Wavetable: [2*a0-a1, a1-a0, 2*a1-a2, a2-a1, 2*a2-a3, a3-a2...]

这种奇怪的格式不是标准线性插值（整数 + 小数），而是（整数部分 -1）和（1+小数），这是由于底层 C 代码中用于整数到浮点转换的某些高效数学运算。
