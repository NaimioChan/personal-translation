Ppatmod

在将给定模式传入流之前对其进行修改

Pattern : AbstractFunction : Object

另请参阅：Plazy

类方法

Ppatmod.new(pattern, func, repeats)

参数：

pattern

该模式。

func

一个 Function，用于修改所包含的模式并将其嵌入流中。

repeats

重复次数。

a = Ppatmod(
