SoundFile

sclang 声音文件数据

Object

另请参阅：File、Buffer

说明

SoundFile 类用于在 sclang 客户端需要关于 SoundFile 的此类信息时检查其大小、格式、通道数等。Soundfile 数据可以被读取和修改。Soundfile 数据也可以增量读取和写入，因此只要代码设计得当，文件大小就没有限制。

在大多数情况下，你会希望向服务器发送命令，让它将 SoundFiles 直接加载到 Buffers 中。你不需要为此使用此类。参见 Buffer 帮助文件。

(
// ExampleFiles 帮助定位示例中使用的音频文件
p = ExampleFiles.child;
// 查看路径以了解位置和路径的格式
p.postln;

f = SoundFile.new;
f.openRead(p);
f.inspect;
f.close;
)

读取声音文件时，headerFormat、sampleFormat、numChannels 和 numFrames 变量将根据磁盘上的文件进行设置。

创建新的 SoundFile 时，默认格式为单声道、44.1 kHz、AIFF、浮点型。用户可以通过将所需的格式字符串传递给 SoundFile: *openWrite，或在使用 SoundFile: -headerFormat、SoundFile: -sampleFormat、SoundFile: -numChannels 和 SoundFile: -sampleRate before 调用 SoundFile: -openWrite 之前进行设置，来覆盖这些默认值。

类方法

SoundFile.new(pathName)

创建一个新的 SoundFile 实例。

SoundFile.writeArray(array, pathName, headerFormat, sampleFormat, sampleRate)

将一个数组（或嵌套数组）作为声音文件写入路径。

参数：

array

要写入的数据。对于单声道音频文件，可以是一个数字数组；对于多声道音频文件，可以是一个由数字数组组成的数组。不接受进一步嵌套的数组。请注意，SuperCollider 目前不支持非常大的数组，粗略地说，在 44100 的采样率下，时长超过 45 分钟的单声道声音文件会导致 SuperCollider 静默失败。

pathName

以 String 表示的路径。

headerFormat

参见 SoundFile: -headerFormat。

sampleFormat

参见 SoundFile: -sampleFormat。

sampleRate

一个数字，默认为 44100。

返回值：

成功时返回路径，失败时抛出异常。

SoundFile.openRead(pathName)

尝试打开给定路径处的音频文件。

参数：

pathName

声音文件的完整路径。使用 String: -standardizePath 来解析诸如 ~ 之类的家目录快捷方式。

返回值：

若成功则返回一个新的 SoundFile 实例，若文件打开失败则返回 nil。用户代码应在对 SoundFile 对象进行任何操作之前检查是否为 nil。

SoundFile.openWrite(pathName, headerFormat, sampleFormat, numChannels, sampleRate)

尝试在给定路径创建音频文件。注意没有 numFrames 参数：帧数是在将数据写入文件后计数的。

参数：

pathName

声音文件的完整路径。使用 String: -standardizePath 来解析诸如 ~ 之类的家目录快捷方式。

headerFormat

一个表示声音文件格式的字符串。有效字符串列于 SoundFile: -headerFormat。若未给出，则使用默认值 "AIFF"。

sampleFormat

用于指定采样格式的字符串。有效字符串列于 SoundFile: -sampleFormat。若未指定，则使用默认值 "float"。

numChannels

整数声道数（默认为 1）。

sampleRate

一个整数采样率（默认为 44100）。

返回值：

若成功则返回一个新的 SoundFile 实例，若文件打开失败则返回 nil。用户代码应在对 SoundFile 对象进行任何操作之前检查是否为 nil。

SoundFile.collect(path: "sounds/*")

返回一个 SoundFile 对象的 Array，其路径与模式匹配。（关联的文件会被关闭。这些对象可用于为播放缓冲区提供 cue）

SoundFile.collect("sounds/*").do { |f| f.path.postln };

SoundFile.use(path, function)

读取 SoundFile 的数据，求值该函数（将文件作为参数传入），然后再次关闭它。

SoundFile.use(ExampleFiles.child, { |f| f.inspect });

SoundFile.normalize(path, outPath, newHeaderFormat, newSampleFormat, startFrame: 0, numFrames, maxAmp: 1.0, linkChannels: true, chunkSize: 4194304, threaded: false)

将声音文件归一化到用户设定的电平。归一化后的音频将写入第二个文件。

使用这个类方法（SoundFile.normalize）会自动为你打开源文件。你也可以自己 -openRead SoundFile 并对其调用 -normalize。在这种情况下，由于文件已经打开，源路径被省略。

更多信息请参见实例方法 -normalize。

Playback

.cue(ev, playNow: false, closeWhenDone: false)

参数：

ev

65536

0

要播放的第一帧

lastFrame

nil

SynthDef(\diskIn2, { |out, amp = 1, bufnum, sustainTime, atk = 0, rel = 0, gate = 1|
    var sig = VDiskIn.ar(2, bufnum, BufRateScale.kr(bufnum));
    var gateEnv = EnvGen.kr(Env([1, 1, 0], [sustainTime-rel, 0]));
    var env = EnvGen.kr(Env.asr(atk, 1, rel), gate * gateEnv, doneAction: Done.freeSelf);
    Out.ar(out, sig * env * amp)
});

控件 sustainTime 基于 firstFrame 和 lastFrame 确定播放时长。控件 gate 允许提前终止播放

设置输出总线

哪个服务器

head/tail/before/after

amp:

amplitude

instrument:

nil

这是一个 Boolean，决定文件是否在提示后立即播放。

f = SoundFile.collect("sounds/*");

closeWhenDone

一个标志，指示播放结束后是否关闭缓冲区。默认值为 False。

Read/Write

.openRead(pathName)

读取文件头。返回一个 Boolean 表示读取是否成功。会设置 -numFrames、-numChannels 和 -sampleRate。 不会 设置 -headerFormat 和 -sampleFormat。

参数：

pathName

一个 String，指定要读取的文件的路径名。

.readData(rawArray)

将文件的采样数据读入你提供的原始数组中。你必须已经调用过 -openRead。

当到达 EOF 时，数组的大小将为 0。在遍历声音文件时，检查数组大小是一种有效的终止条件。示例参见方法 -channelPeaks。

参数：

rawArray

原始数组必须是 FloatArray。无论文件的采样格式如何，数组都会被填充为浮点值。对于整数格式，浮点值都将在 -1..1 范围内。

FloatArray 的大小决定了将要读取的单个采样（不是采样帧）的最大数量。如果文件中剩余的采样不足，则调用 readData 后数组的大小将小于原始大小。

.openWrite(pathName)

写入文件头。返回一个 Boolean 表示写入是否成功。

参数：

pathName

一个 String，指定要写入的文件的路径名。

.writeData(rawArray)

将 rawArray 写入文件的采样数据中。您必须已经调用了 -openWrite。

参数：

rawArray

原始数组必须是 FloatArray 或 Signal，且所有值均介于 -1 与 1 之间，以避免播放期间发生削波。

(
f = SoundFile.new.headerFormat_("AIFF").sampleFormat_("int16").numChannels_(1);
f.openWrite("sounds/sfwrite.aiff");
    // 锯齿波
b = Signal.sineFill(100, (1..20).reciprocal);
    // 写入多个周期（441 * 100 = 1 秒的量）
441.do({ f.writeData(b) });
f.close;
)

.isOpen

返回文件是否打开。

.close

关闭文件。

.duration

文件的时长，以秒为单位。

Normalizing

.normalize(outPath, newHeaderFormat, newSampleFormat, startFrame: 0, numFrames, maxAmp: 1.0, linkChannels: true, chunkSize: 4194304, threaded: false)

将声音文件归一化到用户设定的电平。归一化后的音频将写入第二个文件。

归一化器可用于将声音文件从一种采样格式转换为另一种（例如，将 SuperCollider 生成的浮点声音文件转换为适合在其他应用程序中使用的 int16 或 int24 声音文件）。

注意： 当归一化器工作时，不会向用户提供任何反馈。看起来 SuperCollider 像是挂起了，但操作最终会完成。你可以设置 threaded:true 来获得反馈，但完成时间会稍长一些。

参数：

outPath

目标文件的路径。

newHeaderFormat

新文件的所需头格式；如果未指定，将使用源文件的头格式。

newSampleFormat

新文件的所需样本格式；如果未指定，将使用源文件的样本格式。

startFrame

用于开始归一化的采样帧索引。

numFrames

要复制到目标文件中的采样帧数（默认 nil，即整个声音文件）。

maxAmp

期望的最大振幅。提供一个浮点数，或根据需要提供一个数组，为每个通道指定不同的级别。

linkChannels

一个 Boolean，指定所有通道是否应按相同的量进行缩放。默认为 true，表示峰值计算将基于任意通道中最大的样本。如果为 false，则每个通道的峰值将独立计算，且所有通道都将被缩放到 maxAmp（这会改变每个通道的相对响度）。

chunkSize

一次读取多少个采样（默认值为 4194304，即 16 MB）。

threaded

如果为 true，归一化在一个例程中运行，以便 SC 在处理时（间歇性地）能够响应。可防止 macOS 出现沙滩球。

.sampleFormat

.sampleFormat = value

一个 String，指示由 -openRead 读取、并将由 -openWrite 写入的样本数据的格式。libsndfile 决定哪种头格式支持哪种样本格式。此信息在 http://www.mega-nerd.com/libsndfile 中有详细说明。可能的样本格式有：

采样格式：

format

notes

支持的头部（部分列表）

"int8"、"int16"、"int24"、"int32"

整数格式

"AIFF"、"WAV"、"RF64"、"W64"、"CAF"、"FLAC"

"float"

浮点格式（不会在 0dB 以上削波）

"AIFF"、"WAV"、"RF64"、"W64"、"CAF"

"mulaw"、"alaw"

U-law 与 A-law 编码

"WAV"、"W64"

"vorbis"

"Vorbis" 压缩格式

"OGG"

"mp1"、"mp2"、"mp3"

MPEG Layer I、II 和 III 压缩格式

"MPEG"（见下方注释）

并非所有头格式都支持所有采样格式。

注意： 支持 MPEG 格式需要支持该格式的 libsndfile 库。该库已包含在 SuperCollider 的 macOS 和 Windows 发布版本 3.13 及更高版本中。然而，在使用系统安装的 libsndfile 的平台上（例如 Linux），或在本地构建 SC 时，MPEG 支持需要 libsndfile 版本 1.1.0 或更高，并且该库在构建时启用了 MPEG 功能。

目前无法在写入 OGG vorbis 和 MPEG 文件时控制质量（比特率）——使用的是 libsndfile 中设置的默认比特率。

示例

// 写入声音文件，长格式：
// 在调用 'openWrite' 之前设置格式变量
// 'openWrite' 返回的布尔值告诉你是否可以安全继续
(
f = SoundFile(PathName.tmp +/+ "sf-help.wav");
f.headerFormat = "WAV";
f.sampleFormat = "int16";
if(f.openWrite) {
    f.writeData(Signal.sineFill(1024, [1]));
    f.close;
} {
    "Failed to open %".format(f.path).warn;
};
)

// 或者，简写形式：类方法 'openWrite'
// 如果文件无法打开，f 为 nil
(
var p = PathName.tmp +/+ "sf-help.wav";
f = SoundFile.openWrite(p, "WAV", "int16");
if(f.notNil) {
    f.writeData(Signal.sineFill(1024, [1]));
    f.close;
} {
    "Failed to open %".format(p).warn;
};
)

// 读取文件
f = SoundFile.openRead(PathName.tmp +/+ "sf-help.wav");
f.sampleFormat;

// 要获取数据，请先创建 FloatArray 或 Signal
d = FloatArray.newClear(f.numFrames);
f.readData(d);
d.plot;
f.close;

s.boot;

// 它是真正的音频文件——服务器可以加载它
b = Buffer.read(s, PathName.tmp +/+ "sf-help.wav");

// 这是一个正弦波……
a = { (PlayBuf.ar(1, b, rate: 440 * 1024/44100, loop: 1) * 0.1).dup }.play;
a.free;

b.free;
File.delete(PathName.tmp +/+ "sf-help.wav");
