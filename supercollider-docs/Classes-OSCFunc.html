OSCFunc

用于接收传入 Open Sound Control 消息的快速响应器

AbstractResponderFunc : Object

参见：OSC 通信、OSCdef、NetAddr

子类：OSCdef

说明

OSCFunc（及其子类 OSCdef）注册一个或多个函数，以响应与指定 OSC 地址匹配的传入 OSC 消息。它的许多方法继承自其父类 AbstractResponderFunc。OSCFunc 支持对传入消息中的通配符等进行模式匹配。出于效率原因，你必须通过使用 *newMatching 方法创建 OSCFunc，或向 *new 传入一个匹配分派器，来指定该 OSCFunc 将采用模式匹配。关于 Open Sound Control 协议的详细信息，见 http://opensoundcontrol.org/spec-1_0.html

类方法

OSCFunc.defaultDispatcher

OSCFunc.defaultDispatcher = value

获取或设置 OSCFunc 的默认分派器对象（即当你将 nil 作为分派器参数传给 *new 时得到的东西）。该对象将决定其已注册的 OSCFunc 中是否有任何一个应响应传入的 OSC 消息。

返回值：

默认情况下，这将是一个 OSCMessageDispatcher，但也可以设置为 AbstractDispatcher 的相应子类的任意实例。

OSCFunc.defaultMatchingDispatcher

OSCFunc.defaultMatchingDispatcher = value

获取或设置 OSCFuncs 的默认匹配分派器对象（当使用 *newMatching 创建 OSCFunc 时得到的就是此对象）。该对象将使用模式匹配来决定其注册的 OSCFuncs 中是否有应响应传入 OSC 消息的对象。

返回值：

默认情况下，这将是一个 OSCMessagePatternDispatcher，但也可以将其设置为 AbstractDispatcher 某个合适子类的任意实例。

OSCFunc.new(func, path, srcID, recvPort, argTemplate, dispatcher)

创建一个新的、已启用的 OSCFunc。

参数：

func

一个 Function 或类似对象，将响应传入的消息。在求值时，将向它传递以下参数：

msg

消息，形式为 [OSC 地址, args1, arg2, ...] 的数组

time

接收时间（对于消息）/ 发送时间加上延迟（如果消息在 bundle 中）

addr

与发送方 IP 地址对应的 NetAddr

recvPort

与接收消息的端口对应的整数。

msg

消息，形式为 [OSC 地址, args1, arg2, ...] 的数组

time

接收时间（对于消息）/ 发送时间加上延迟（如果消息在 bundle 中）

addr

与发送方 IP 地址对应的 NetAddr

recvPort

与接收消息的端口对应的整数。

path

一个 Symbol，指示此对象的 OSC 地址路径。请注意，OSCFunc 要求符合 OSC 规范的地址。如果路径不以 / 开头，将自动添加一个。

srcID

一个可选的 NetAddr 实例，表示发送者的 IP 地址。如果设置此对象，它将只响应来自该来源的消息。

recvPort

一个可选的 Integer，指示接收消息所用的端口。若设置此项，该对象将只响应在该端口上接收到的消息。此方法会调用 Main: -openUDPPort 以确保该端口已打开。

argTemplate

一个可选的 Array，由 Integer 或 Function 的实例（或响应方法 Methods: matchItem 的对象）组成，用于匹配传入 OSC 消息的参数。如果是 Function，则会将对应的消息参数作为参数对其求值，并且应返回一个 Boolean，指示该参数是否匹配以及此 OSCFunc 是否应响应（前提是所有其他参数都匹配）。模板值为 nil 将匹配任何传入的参数值。

dispatcher

一个可选的、属于 AbstractDispatcher 相应子类的实例。可用于实现自定义的分发。通常不需要这样做。

返回值：

OSCFunc 的新实例。

OSCFunc.newMatching(func, path, srcID, recvPort, argTemplate)

一个便捷方法，用于创建一个新的、已启用的 OSCFunc，其调度器将对传入的 OSC 消息执行模式匹配，以判断它们的地址模式是否与此对象的路径匹配。

参数：

func

一个 Function 或类似对象，它将响应传入的消息。求值时，它会被传入参数 msg、time、addr 和 recvPort，分别对应作为 Array [OSCAddress, other args] 的消息、消息发送的时间、与发送者 IP 地址对应的 NetAddr，以及与接收消息所用端口对应的 Integer。

path

一个 Symbol，表示该对象 OSC 地址的路径。注意，OSCFunc 要求地址符合 OSC 规范。如果路径不以 / 开头，会自动添加一个。模式匹配将应用于所有传入消息，以检查它们是否匹配此地址。注意，根据 OSC 规范，正则表达式通配符仅允许出现在传入消息的地址模式中。因此 path 不应包含通配符。有关 OSC 模式匹配的更多细节，请参见 http://opensoundcontrol.org/spec-1_0

srcID

一个可选的 NetAddr 实例，表示发送者的 IP 地址。如果设置此对象，它将只响应来自该来源的消息。

recvPort

一个可选的 Integer，指示接收消息所用的端口。

argTemplate

一个可选的 Array，由 Integer 或 Function 的实例（或响应方法 Methods: matchItem 的对象）组成，用于匹配传入 OSC 消息的参数。如果是 Function，则会将对应的消息参数作为参数对其求值，并且应返回一个 Boolean，指示该参数是否匹配以及此 OSCFunc 是否应响应（前提是所有其他参数都匹配）。模板值为 nil 将匹配任何传入的参数值。

返回值：

OSCFunc 的新实例。

OSCFunc.trace(bool: true, hideStatusMsg: false)

一个便捷方法，用于转储所有传入的 OSC 消息。

参数：

bool

一个 Boolean，指示转储是开启还是关闭。

hideStatusMsg

一个 Boolean，指示服务器状态消息是否从转储中排除。

实例方法

.path

获取此 OSCFunc 的 OSC Address 路径。

返回值：

一个 String

.recvPort

获取此 OSCFunc 的接收端口。

返回值：

一个 Integer

示例

n = NetAddr("127.0.0.1", NetAddr.langPort); // 本地机器

OSCFunc.newMatching({ |msg, time, addr, recvPort| \matching.postln }, '/chat', n); // 路径匹配
OSCFunc({ |msg, time, addr, recvPort| \oneShot.postln }, '/chat', n).oneShot; // 仅一次
OSCdef(\test, { |msg, time, addr, recvPort| \unmatching.postln }, '/chat', n); // 定义风格

m = NetAddr("127.0.0.1", NetAddr.langPort); // 回环

m.sendMsg("/chat", "Hello App 1");
m.sendMsg("/chat", "Hello App 1"); // 一次性已消失
m.sendMsg("/ch?t", "Hello App 1");
m.sendMsg("/*", "Hello App 1");
m.sendMsg("/chit", "Hello App 1"); // 无

// 内省

AbstractResponderFunc.allFuncProxies
AbstractResponderFunc.allEnabled
OSCdef(\test).disable;
AbstractResponderFunc.allDisabled

// 更改函数
OSCdef(\test).enable;
OSCdef(\test, { |msg, time, addr, recvPort| 'Changed Unmatching'.postln }, '/chat', n); // 在键 \test 处替换
m.sendMsg("/chat", "Hello App 1");
OSCdef(\test).add(f = { \foo.postln }); // 添加另一个函数
m.sendMsg("/chat", "Hello App 1");
OSCdef(\test).clear; // 移除所有函数
m.sendMsg("/chat", "Hello App 1");

//////// 使用 argTemplate 进行更精细的匹配

s.boot;
x = Synth(\default);
OSCFunc({ 'ended!'.postln }, '/n_end', s.addr, nil, [x.nodeID]).oneShot;
x.release(3);
