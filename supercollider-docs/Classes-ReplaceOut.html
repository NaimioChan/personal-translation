ReplaceOut

将信号发送到总线，覆盖之前的内容。

Out : AbstractOut : UGen : AbstractFunction : Object

另见：OffsetOut、Out、XOut

说明

Out 将其输出加到给定的总线上，使其可供节点树中位于其后的所有节点使用（更多信息请参见 Synth 和 Order of execution）。ReplaceOut 会覆盖这些内容。这使其可用于处理。

有关总线及其使用方式的更多信息，请参阅 Server Architecture 和 Bus 帮助文件。

类方法

ReplaceOut.ar(bus, channelsArray)

来自父类：Out

ReplaceOut.kr(bus, channelsArray)

来自父类：Out

参数：

bus

要写入的总线索引。编号最小的总线写入音频硬件。

channelsArray

用于写出的通道数组或单个输出。一旦 SynthDef 构建完成，就无法更改其大小。

实例方法

示例

(
SynthDef("ReplaceOutHelp", { |out = 0, freq = 440|
    var source;
        source = SinOsc.ar(freq, 0, 0.1);

        // 写入总线, 替换之前的内容
        ReplaceOut.ar(out, source);

}).add;
)

// 每个 Synth 都会替换前一个的输出
x = Synth.tail(s, "ReplaceOutHelp", [\freq, 500]);
y = Synth.tail(s, "ReplaceOutHelp", [\freq, 600]);
z = Synth.tail(s, "ReplaceOutHelp", [\freq, 700]);

// 按相反顺序释放它们；较旧的 Synth 仍然存在。
z.free;
y.free;
x.free;
