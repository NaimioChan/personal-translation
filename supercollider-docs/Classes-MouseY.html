MouseY

光标跟踪 UGen。

MouseX : UGen : AbstractFunction : Object

另请参阅：KeyState、MouseButton、MouseX

说明

光标跟踪 UGen。

警告： 此 UGen 对使用 Wayland 的 Linux 用户不可用，因为 Wayland 协议不允许捕获全局的键盘或鼠标状态。该 UGen 将返回一个介于 0.0 和 1.0 之间的常量随机值。更多信息请参见 https://github.com/supercollider/supercollider/issues/4544

类方法

MouseY.kr(minval: 0, maxval: 1, warp: 0, lag: 0.2)

来自父类：MouseX

参数：

minval

对应于屏幕底边的值。

maxval

对应于屏幕顶边的值。

warp

映射曲线。0 为线性，1 为指数（例如用于 freq 或 times）。或者可以指定：'linear' 或 'exponential'。

lag

用于消除光标移动拉链效应的滞后因子。

实例方法

示例

{ SinOsc.ar(MouseY.kr(40, 10000, 1), 0, 0.1) }.play;
