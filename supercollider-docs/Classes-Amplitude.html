Amplitude

振幅跟随器

UGen : AbstractFunction : Object

说明

使用包络跟随算法跟踪信号的相对幅度。包络跟随器根据 attackTime 向上升的幅度收敛，根据 releaseTime 向下降的幅度收敛。参见 Examples 下的图。

类方法

Amplitude.ar(in: 0.0, attackTime: 0.01, releaseTime: 0.01, mul: 1.0, add: 0.0)

Amplitude.kr(in: 0.0, attackTime: 0.01, releaseTime: 0.01, mul: 1.0, add: 0.0)

参数：

in

输入信号

attackTime

跟随起音的 20dB 收敛时间。

releaseTime

后续衰减的 20dB 收敛时间。

mul

add

实例方法

示例

第一个示例生成一个图，将快速起音/释音与较慢的设置进行比较。绿线（快速设置）更快地接近振幅，但也会随波形振荡。蓝线（慢速设置）上升较慢，但振荡较少（测量更稳定）。

(
{
    // LFSaw 从 0 开始，能更好地体现起音时间
    var sig = LFSaw.ar(440);
    var amps = Amplitude.ar(
        sig,
        attackTime: [0.001, 0.01],
        releaseTime: [0.01, 0.2]
    );
    [sig] ++ amps
}.plot
.superpose_(true)
.plotColor_([Color.black, Color.green, Color.blue]);
)

(
// 使用输入振幅控制 SinOsc 频率
{
    SinOsc.ar(
            Amplitude.kr(
                        Blip.ar(3, 20) * LFNoise1.kr(0.1).range(0, 1),
                        MouseX.kr(0.001, 1, 1),
                        MouseY.kr(0.001, 1, 1),
                        1200,
                        400
            ),
            0, 0.3)
}.play;
)
// 使用输入振幅控制 Pulse 振幅——请使用耳机以防止反馈。
{ Pulse.ar(90, 0.3, Amplitude.kr(SoundIn.ar(0))) }.play;
(
// 使用输入振幅控制 SinOsc 频率——请使用耳机以防止反馈。
{
    SinOsc.ar(
            Amplitude.kr(
                        SoundIn.ar(0),
                        0.01,
                        0.01,
                        1200,
                        400
            ),
            0, 0.3)
}.play;
)
