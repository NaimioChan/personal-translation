DigitalOut

向数字输出写入数据

UGen : AbstractFunction : Object

另请参阅：AnalogIn、AnalogOut、DigitalIn、DigitalIO

说明

将数字数据写入数字输出（例如：LED 或触发/门限输出）。

注意： 此 UGen 仅在 Bela 上运行。

注意： 如果你想调制引脚编号，应使用 UGen DigitalIO

类方法

DigitalOut.ar(digitalPin: 0, output: 0, mul: 1.0, add: 0.0)

参数：

digitalPin

要写入的数字引脚编号。引脚编号从 0 开始。此值不可调制。

output

要写入引脚的值——当参数大于 0 时该值为 1，否则为 0。

mul

add

DigitalOut.kr(digitalPin: 0, output: 0, mul: 1.0, add: 0.0)

参数：

digitalPin

output

要写入引脚的值——当参数大于 0 时该值为 1，否则为 0。
