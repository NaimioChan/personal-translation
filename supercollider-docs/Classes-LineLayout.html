LineLayout

将视图沿一条线分布的布局的父类

另请参见：HLayout、VLayout、GridLayout、StackLayout、Layout Management

说明

这是 HLayout 和 VLayout 的抽象父类，它们分别将视图按水平线或垂直线分布。

微调

可以为每个项分配伸缩因子和对齐标志，以精细调整其大小和位置的管理方式。这可以在布局构造时完成，在添加或插入项时完成，也可以通过 -setStretch 和 -setAlignment 方法为已存在的项完成。

拉伸因子只影响布局方向（垂直或水平）上的分布。所有条目的拉伸因子默认为 0，因此只有它们自身的偏好会决定空间分布。一旦某个条目被赋予大于 0 的拉伸因子，空间将根据拉伸因子的比例重新分配。

留出空白空间

可以使用 nil 代替某项并结合 stretch 因子来插入任意拉伸因子的空白。类似地，可以使用整数代替某项来插入固定大小的空白。详见构造函数和-add。

类方法

.new

创建一个 HLayout 或 VLayout，并立即用作为参数给出的项填充它。（请注意，LineLayout 是抽象类，无法实例化，但 HLayout 和 VLayout 继承此构造函数。）

参数：

... 项

每个项可以是 view、layout、nil（表示可拉伸的空白空间）或 Integer（表示固定大小的空白空间）。

讨论：

你可以通过将某个项包装进一个数组，并在其后跟随成对的 ('stretch', factor) 和/或 ('align', alignment)，来为该项指定拉伸因子和/或对齐方式。'stretch' 和 'align' 可以缩写为 's' 和 'a'。将键值对放入数组的简化语法非常方便（参见 语法快捷方式：使用键值对创建数组，以及下面的示例）。有关可能的对齐方式取值，请参见 Alignment。

如果该项是可拉伸的空白空间（nil），对齐将不起作用；如果该项是固定大小的空白空间（Integer），则不受拉伸因子和对齐的影响。

Example:

(
w = Window.new;
w.layout = VLayout(
    [Button().states_([["Foo"]]), stretch: 1, align: \bottomLeft],
    20,
    [TextView().string_("Bar\nBar\nBar\n"), s: 3],
    [nil, s: 1]
);
w.front;
)

实例方法

.add

分别对于 HLayout 和 VLayout，将条目添加到行的右端或底端。

参数：

item

该项可以是视图、布局、Integer（指定空白区域的像素量）或 nil（用于可拉伸的空白区域）。

stretch

一个整数拉伸因子。

align

表达对齐方式的符号。可能的值参见 Alignment。

讨论：

如果该项是可拉伸空白（nil），则 align 参数不会产生任何效果；如果该项是固定大小的空白（一个 Integer），则 stretch 和 align 参数都不会产生任何效果。

.insert

在特定位置插入一个项。

参数：

item

该项可以是视图、布局、Integer（指定空白区域的像素量）或 nil（用于可拉伸的空白区域）。

index

在当前各项中插入新项的整数位置。如果 index 小于 0 或大于当前项数，新项将始终添加到行的末尾。

stretch

一个整数拉伸因子。

align

表达对齐方式的符号。可能的值参见 Alignment。

讨论：

如果该项是可拉伸空白（nil），则 align 参数不会产生任何效果；如果该项是固定大小的空白（一个 Integer），则 stretch 和 align 参数都不会产生任何效果。

.setStretch

设置布局中所含项的拉伸因子。

参数：

item

由该布局管理的视图或布局，或某项的 Integer 索引。

stretch

一个整数拉伸因子。

.setAlignment

设置布局中包含项的对齐方式。

参数：

item

由该布局管理的视图或布局，或某个项的 Integer 索引。

align

表达对齐方式的符号。可能的值参见 Alignment。

示例

尝试调整以下代码创建的窗口大小。

(
w = Window.new;
w.layout = VLayout(
    TextView().string_("Foo\nBar\nFoo\nBar\nFoo"),
    HLayout(
        Button().states_([["Foo"]]),
        [TextField().string_("Bar"), stretch: 1],
        [TextField().string_("BarBarBar"), stretch: 4]
    )
);
w.front;
)

对于滚动视图，我们需要将其画布设置为具有所需布局的 View。

(
var view = ScrollView();
view.canvas = View().layout_(VLayout(
    *(
        100.collect {
            Slider().orientation_(\horizontal).background_(Color.rand)
        }
    )
));
view.front;
)
