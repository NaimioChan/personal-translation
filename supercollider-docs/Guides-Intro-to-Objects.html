对象与消息

SuperCollider 语言是一种面向对象的语言。语言中的所有实体都是对象。对象是拥有数据（表示对象的状态）以及一组可对对象执行的操作的东西。所有对象都是某个类的实例，类描述了对象的结构及其操作。SuperCollider 中的对象包括数字、字符串、对象集合、单元生成器、波形采样、点、矩形、图形窗口、图形按钮、滑块等等。

对对象的操作通过消息来调用。消息是对一个对象（称为接收者）的请求，要求它执行其某项操作。执行操作的方式由该对象的类决定。不同类的对象可能以不同的方式实现同一条消息，每种方式都适合该对象的类。例如，所有对象都能理解 value 消息。许多对象在收到 value 时只是返回自身，但其他对象（如函数和流）会先对自己求值，然后返回求值结果。不同对象对同一消息做出不同反应的能力称为多态，这或许是面向对象编程中最重要的概念，因为它使对象的行为从对象使用者（客户端）的角度来看变得抽象。

一个对象所响应的消息集合称为它的接口。实现特定行为的一组消息称为协议。一个对象的接口可能包含多个协议，使该对象能够在多种不同的上下文中交互。例如，所有对象都实现了“依赖”协议，该协议允许对象通知其它依赖对象该对象已改变，并且依赖对象应执行任何必要的操作来更新自身。

对象的内部状态只能通过向它发送消息来改变。这使得对象的实现可以对客户端隐藏。其优点在于客户端不依赖于对象的实现，并且该实现可以在不改变客户端的情况下进行更改。

有关消息的更多信息，请参见 Messages。

类、实例变量、方法

对象的类包含该对象的数据和操作的描述。类还描述如何创建一个作为该类实例的对象。

对象的数据包含在其实例变量中。这些是描述对象状态的命名变量。实例变量的值本身也是对象。例如，类 Point 的实例具有名为 'x' 和 'y' 的实例变量，其中包含该 Point 的坐标值。

实例变量只能直接从类本身内部访问。类的作者可以决定通过向类添加 getter 和/或 setter 消息，将实例变量的访问暴露给客户端。

方法是针对特定类实现某条消息所需操作过程的描述。类中的方法说明了如何实现发送给其实例的消息。类为其实例响应的每条消息都包含一个方法定义。方法通常分为几个类别。有些方法查询接收者的某些属性。另一些方法要求接收者对其内部状态作出某些改变。还有一些方法可能要求接收者返回某个计算值。

关于实例变量、类变量以及实例方法和类方法的更多细节，请参见 类。

术语总结

object

具有数据（表示对象的状态）以及一组可对该对象执行的操作的事物。

message

请求对象执行某项操作。

receiver

消息发送的目标对象。

class

一组对象的状态和行为的描述。

interface

对象响应的消息集合。

protocol

一组实现特定类型行为的消息。

polymorphism

不同类型的对象对同一消息作出不同响应的能力。

method

为实现某个类的消息所需操作的描述。

instance

由类描述的对象之一。

实例变量

对象内部状态的一部分
