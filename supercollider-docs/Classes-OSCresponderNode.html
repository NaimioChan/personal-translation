OSCresponderNode

客户端网络响应器

OSCresponder : Object

参见：OSCFunc、OSCdef、OSC Communication、OSCpathResponder、NetAddr

说明

注意： 此类已废弃，并将在 SC 的未来版本中移除。请改用 OSCFunc 和 OSCdef。它们比旧版响应器类更快、更安全，参数顺序更合理，并且支持模式匹配和自定义监听端口。使用旧版类 OSCresponder、OSCresponderNode 和 OSCpathResponder 可能不安全，因为用户代码和类代码中的响应器可能会意外地相互覆盖。

注册一个函数，在从特定 OSC 地址接收到特定命令时调用。接口与 OSCresponder 相同，但允许多个 responder 响应同一个命令。

注意，OSCresponderNode 在系统进程中求值其函数。为了访问应用进程（例如进行 GUI 访问），请使用 { ... }.defer;

其他向 SuperCollider 发送消息的应用程序应区分发送给服务器还是发送给语言的消息。服务器消息记录在 Server Command Reference 中，应发送到服务器的端口 - s.addr.port - 默认值为 57110。发送到服务器的消息不会被语言中的任何 OSCresponder 处理。

应由 OSCresponder 处理的外部客户端消息必须发送到语言端口，默认情况下为 57120。使用 NetAddr.langPort 来确认 SuperCollider 语言正在监听哪个端口。

更多细节参见 OSC Communication。

示例

设置 OSCresponderNode 以监听远程应用程序

// 示例：两个 SuperCollider 应用程序通信

// 应用 1：
n = NetAddr("127.0.0.1", 57120); // url 应该是 app 2 所在计算机的 url（或 nil）

o = OSCresponderNode(n, '/chat', { |t, r, msg| ("time:" + t).postln; msg[1].postln }).add;

// 应用 2：
m = NetAddr("127.0.0.1", 57120); // url 应为应用 1 所在计算机的 url
m.sendMsg("/chat", "Hello App 1");

// 发送 bundle（含时间戳）
(
m.sendBundle(2.0, ["/chat", "Hello App 1"], ["/chat", "Hallo Wurld"]);
m.sendBundle(0.0, ["/chat", "Hello App 1"], ["/chat", "Hallo Wurld"]);
)

// 结束应用程序 1：
o.remove;

监听来自_任意_客户端的数据

// 同上，但我们将地址设为 nil，以便可以从任何地方接收
// 不需要 NetAddr，因为我们只是监听（而不发送）

o = OSCresponderNode(nil, '/test', { |t, r, msg| msg.postln }).add;
o.remove;

监听来自 _任意_ 客户端但来自特定主机的数据

// 同上，但我们使用端口为 nil 的 NetAddr，这样我们可以从特定主机接收，但来自任意端口

n = NetAddr("127.0.0.1", nil); // url 应为应用 2 所在计算机的 url
o = OSCresponderNode(n, '/test', { |t, r, msg| msg.postln }).add;
o.remove;

监听来自服务器的数据

// 来自 SendTrig 的示例

(
s.boot;
s.notify;
)

(
SynthDef("help-SendTrig", {
    SendTrig.kr(Dust.kr(1.0), 0, 0.9);
}).add;

// 注册以接收此消息
a = OSCresponderNode(s.addr, '/tr', { |time, responder, msg|
    [time, responder, msg].postln;
}).add;
b = OSCresponderNode(s.addr, '/tr', { |time, responder, msg|
    "this is another call".postln;
}).add;
)

x = Synth.new("help-SendTrig");
a.remove;
b.remove;
x.free;

监视特定内容

// 组消息结束

s.boot;

a = OSCresponderNode(s.addr, '/n_end', { |time, responder, msg|
    [time, responder, msg].postln;
    if(msg[1] == g.nodeID, {
        "g is dead !".postln;
        // g = Group.new;
    });
}).add;

g = Group.new;

g.free;

a.remove;

// 来自 crucial lib 中 ServerErrorGui 的示例

f = OSCresponderNode(s.addr, '/fail', { |time, responder, msg|
    {
        var mins, secs;
        mins = (time/60).round(1);
        secs = (time%60).round(0.1);
        if(secs<10, { secs = "0"++secs.asString }, { secs = secs.asString });
        // 将其放到 GUI 上
        // errors.label = "% % (%:%)".format(msg[1], msg[2], mins, secs);
        // errors.stringColor = Color.white;

    }.defer
});
f.add;
