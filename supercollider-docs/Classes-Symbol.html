Symbol

某个事物的唯一名称

Object

说明

符号（symbol）和 String 一样，是字符序列。与字符串不同，两个字符完全相同的符号会是完全相同的对象。符号针对反复重建同一符号进行了优化。在实践中，这意味着符号最适合用于仅在程序内部有意义的标识符或标签，而当你的字符确实作为文本数据处理时，应使用字符串。用符号来命名事物，用字符串进行输入和输出。

符号的常见用途包括符号常量值和 Dictionary 键。

符号在语法上表示为字面量，详见 Literals: Symbols。

创建 Symbol

符号可以通过在字符两侧加上单引号来书写（可包含空白字符）：

'foo bar'

或通过前置反斜杠（此时它不能包含空白字符）：

\foo

字符串可以转换为符号：

"arbeit".scramble.asSymbol;

Testing

.isClassName

回答该符号是否可以是一个类名。这并不表示该类存在。

\Array.isClassName;
\Bauxite.isClassName;

.isMetaClassName

回答该符号是否可以作为元类名。这并不说明该类是否存在。

\Meta_Array.isMetaClassName;

.isSetter

回答该符号是否带有末尾下划线。

'action_'.isSetter;

.isPrimitiveName

回答该符号是否为有效的原语名称

'_SymbolIsClassName'.isPrimitiveName;

.isPrefix(other)

回答该符号是否为另一个符号的前缀

'a'.isPrefix('all'); // true
'z'.isPrefix('all');  // false

.isIdentifier

如果 symbol 是有效的变量名，或者等价地，是两种最常见方法调用语法（foo.bar() 和 bar(foo)）中的有效方法名，则返回 true。有效标识符仅包含字母数字字符和下划线，且第一个字符必须是小写字母。

.isBinaryOp

如果该符号是有效的二元运算符则返回 true。有效的二元运算符仅包含符号 !@%&*-+=|<>?/，不以 '//' 或 '/*' 开头，且不是字符串 '='。

Environments

符号被用作在字典和环境中查找对象的键，但也可用于数组中。参见 IdentityDictionary、Environment、Event

a = ();
a.put(\commune, 1871);
a.at(\commune);

.envirPut(aValue)

使用接收者作为键将值放入当前环境

.envirGet

使用接收者作为键从当前环境中返回一个值

讨论：

\foo.envirPut(100);
\foo.envirGet;
\foo.envirPut(nil);

Math

Symbol 对所有的单目和双目数学运算都返回其自身。Number 或其他数学对象与 Symbol 之间的任何数学运算的结果都是返回该 Symbol。例如，这允许对包含休止符的音符列表执行运算时保留休止符。

Pseq([1, 3, \rest, 2, 4] + 8);

.applyTo(firstArg ... args)

将该符号用作方法选择器，并在 firstArg 上执行该消息，以 args 作为参数。这用于将函数与方法选择器混合使用（另见：Function）。

讨论：

'%'.applyTo(2553, 345);
['+', '-', '*', { |a, b| a.rand + b.rand }].choose.applyTo(2, 3);

Synthesis

在 SynthDef 和 UGen 函数内部，符号可用于便捷地指定不同速率和带延迟的控制输入（参见：NamedControl、ControlName 和 Control）。

.kr(val, lag, fixedLag: false, spec)

返回一个带默认值（val）的控制率 NamedControl 输入，如果提供，还带有滞后。如果 val 是数组，则控件将是多声道的。提供给 spec 参数的 ControlSpec 将被写入当前 synth 的 spec 元数据中。

讨论：

a = { SinOsc.ar(\freq.kr(440, 1.2)) }.play;
a.set(\freq, 330);
a.release;
a = { SinOsc.ar(\freq.kr([440, 460], 1.2)) }.play;
a.setn(\freq, [330, 367]);
a.release;

.ar(val, lag, spec)

返回一个音频速率 NamedControl 输入，带有默认值（val），若提供则还带有 lag。如果 val 是数组，则该控制将是多通道的。

.ir(val, spec)

返回一个具有默认值 (val) 的初始化速率 NamedControl 输入。如果 val 是数组，则该控件将是多通道的。

.tr(val, spec)

返回一个带有默认值（val）的 TrigControl 输入。如果 val 是数组，则该控件将是多通道的。

讨论：

a = { Ringz.ar(T2A.ar(\trig.tr), \freq.kr(500, 1), 0.8) }.play;
a.set(\freq, 330, \trig, 1);
a.set(\freq, 830, \trig, 1);
a.release;
