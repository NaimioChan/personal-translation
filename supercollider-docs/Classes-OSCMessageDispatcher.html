OSCMessageDispatcher

OSCFunc 和 OSCdef 的默认调度器类。

AbstractWrappingDispatcher : AbstractDispatcher : Object

另请参阅：OSCFunc、OSCdef、AbstractWrappingDispatcher、AbstractDispatcher、AbstractMessageMatcher、OSCMessagePatternDispatcher、OSCFuncAddrMessageMatcher、OSCFuncRecvPortMessageMatcher、OSCFuncBothMessageMatcher、OSC Communication

子类：OSCMessagePatternDispatcher

说明

OSCMessageDispatcher 将传入的 OSC 消息分发给匹配的函数。通常用户不必直接创建此类的实例或向其发送消息。

类方法

实例方法

.wrapFunc(funcProxy)

在需要时于内部被调用，以将函数包装到消息匹配器对象中。

参数：

funcProxy

OSCFunc 或 OSCdef 的实例，其函数将被包装。

.getKeysForFuncProxy(funcProxy)

获取响应者函数的函数存储在此分派器活动字典中所使用的键。这些键将是一个 OSC 路径。

参数：

funcProxy

应返回其键的 OSCFunc 或 OSCdef。

返回值：

一个 Array，包含 funcProxy 的路径（作为 Symbol）。

.value(msg, time, addr, recvPort)

尝试将传入的 OSC 消息与此调度器的响应函数进行匹配，并对所有匹配项求值其函数。

参数：

msg

OSC 消息以 Array 形式表示，格式为 [OSCAddress, other args]。

time

一个 Float，指示收到传入消息的时间。

addr

一个NetAddr，指示消息的来源。

recvPort

一个 Integer，表示接收消息的端口。

.register

将此 dispatcher 添加到 thisProcess.recvOSCfunc。

.unregister

将此 dispatcher 从 thisProcess.recvOSCfunc 中移除。

.typeKey

返回 'OSC unmatched'。

返回值：

一个 Symbol。
