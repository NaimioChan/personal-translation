作用域与闭包

变量的作用域

SuperCollider 具有嵌套的变量作用域。一个函数不仅可以引用它自己的参数和变量，还可以引用任何外层（定义）上下文中声明的参数和变量。

例如，下面在 makeCounter 中定义的函数可以访问 makeCounter 中声明的所有参数和变量。其他代码可以在稍后调用返回的函数，并且它可以访问和更新内部函数实例化时 makeCounter 中包含的值。

(
var makeCounter;
makeCounter = { arg curVal=0, stepVal=1;
     // 返回一个函数：
    {
        var temp;
        // temp 是此函数的局部变量，curVal 和 stepVal 在
        // 外层函数中，在此处被引用。
        temp = curVal;
        curVal = curVal + stepVal;
        temp                       // 返回结果
    }
};

// 每次调用 makeCounter 都会创建一组新的变量 curVal 和 stepVal：

x = makeCounter.value(10, 1);
z = makeCounter.value(99, 100);
)

x 和 z 是函数，它们引用变量 curVal 和 stepVal 的不同实例

x.value.postln; // 发布 10
x.value.postln; // 发布 11
z.value.postln; // 发布 99
z.value.postln; // posts 199
x.value.postln; // 发布 12
x.value.postln; // 发布 13
z.value.postln; // posts 299
z.value.postln; // posts 399

请注意，即便定义 curVal 和 stepVal 的函数已经执行完毕，它的变量仍然可以被在其上下文中定义的函数访问。这被称为词法闭包，即内部上下文可以捕获并访问外部上下文中定义的变量，即使外部上下文可能已经执行完毕。
