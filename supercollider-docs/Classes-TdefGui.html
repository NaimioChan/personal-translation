TdefGui

一行用于 Tdef 的编辑控件，以及可选的其 envir

参见：TdefAllGui、PdefGui、PdefAllGui、EnvirGui

说明

一个显示 Tdef 的名称、播放状态、源状态和 envir 状态的 gui。可选地，其 envir 也可以被编辑。

第一个示例

g = TdefGui();            // 创建 TdefGui
g.object = Tdef(\a);        // 显示 Tdef 何时被放入
Tdef(\a, { "boing".postln });     // 显示它是否有源
Tdef(\a).play;             // 显示正在播放、已停止或已结束，以及是否可暂停
Tdef(\a).set(\abc, 123);     // 显示 tdef 是否有环境

g = TdefGui(Tdef(\a), 3);    // 带有用于 3 个项目的 envirgui
Tdef(\a).set(\a, 12, \lofreq, [1, 10], \str, "someString", \oops, \oneSymbolTooMany);

(                // 将其放入现有窗口 - margin 变为 0@0
w = Window().front; w.addFlowLayout;
TdefGui(Tdef(\a), 0, w);
TdefGui(Tdef(\a), 3, w);
)

GUI 元素的详细信息

名称按钮

选中时，按删除键将删除其 Tdef。

播放/停止按钮

指示 tdef 是否正在播放：

" >"

如果已停止，

" _"

如果正在播放且处于活动状态，

" |"

如果正在播放，但流已结束。

暂停/恢复按钮

仅当可以暂停或恢复该 Tdef 时可见，即在其播放期间。

"paus"

在可以暂停时显示，

"rsum"

在可以恢复时显示。

src 按钮

打开一个文档以编辑 Tdef 的源代码（函数）。

green

存在一个源，

white

源为 nil。

env 按钮

click 打开一个文档以编辑 Tdef 的环境变量，option-click 打开一个新的 TdefGui，其中包含一个足够大的 EnvirGui 以容纳该 Tdef 的环境变量。

green

该 Tdef 有一个 envir，

white

envir 为 nil。

类方法

创建方法

.new

创建一个新的 JITGui，它将监视一个对象并显示其状态。

参数：

object

要监视的对象

numItems

要使用的显示项数量，例如用于文本的字段数量，或用于单数值参数的 EZSlider 数量。

parent

用于显示的父视图。如果为 nil，则创建一个新窗口；parent 也可以是一个已存在的窗口或复合视图。

bounds

用于显示 JITGui 的期望尺寸和位置。可以为 nil、一个 Point 或一个 Rect。JITGui 知道自己的最小尺寸（minSize），如果 bounds 为 nil，则使用 minSize。如果 bounds 是一个 Point 或 Rect，它将被设置为至少 minSize。使用 Rect 时还可以提供显示位置。如果是 Point，则显示的尺寸是 bounds 和 minSize 中的最大值。

makeSkip

一个表示是否创建 skipjack 的标志。如果将 TdefGui 用作更大的 gui 组合的一部分，可能希望一起对所有 TdefGui 调用 checkUpdate，而不是使用单独的 skipJack。

options

附加信息列表，例如关于可选按钮的标志。（这在某些子类中使用）

实例方法

.object

一个 Tdef，或 nil

.numItems

envirGui 中的项数

.parent

父视图

.bounds

-zone 的边界

.zone

显示 TdfGui 所在的 CompositeView

.nameBut

.playBut

.pauseBut

.srcBut

.envBut

按钮

.envirGui

Tdef 环境变量的 gui - 如果 numItems > 0。

.object

将一个对象放入 GUI。

.moveTo

（如果 jitGui 位于其自身的窗口中）

将其移动到某个具体位置。

.clear

（如果 jitGui 位于其自身的窗口中）

将 TdefGui 的对象设为 nil

.close

（如果 jitGui 位于其自身的窗口中）

并关闭其窗口。

内部方法

.srcString

一个可重建该 Tdef 的 compileString。

// 假设上面的 g 仍然存在
g.srcString;

.editString

一个在 edKey 处重建 Tdef 环境（envir）的 compileString。

.editStrings

一个 compileString，用于在 edKeys 处重建 Tdef 的环境。

参数：

edKeys

默认值为 nil。

// 假设上面的 g 仍然存在
g.editString;
Tdef(\a).set(\foo, \bar);
g.editString(\foo);

g.editStrings;

.getUsedKeys

envir 中正在使用的键

g.getUsedKeys;

.openDoc

在某个位置打开包含一些字符串的文档。与 src 按钮、env 按钮配合使用。

g.openDoc(g.editStrings);

.makeEnvirGui

在 zone 中创建 envirGui。

示例

(
Tdef(\a, { |e| 100.do { |i| i.postln; 0.5.wait } });
t = TdefGui(Tdef(\a), 4);
Tdef(\a).set(\freq, 200, \dur, 0.1, \otto, 12, \ann, 1234);
)

Tdef(\a).stop;
Tdef(\a).play;
Tdef(\a).pause;
Tdef(\a).resume;

t.object_(nil);
t.object_(Tdef(\a));

(
w = Window("put it in a selfmade window").front;
w.addFlowLayout;
w.view.decorator.shift(50, 50);
TdefGui(Tdef(\a), 12, w)
)

Tdef(\b, { |e| 100.do { |i| Tdef(\a).set(\otto, 8.rand); exprand(0.1, 3.0).wait } });
Tdef(\b).play;
TdefGui(Tdef(\b));

    // 查看所有 Tdef：
TdefAllGui(16);
