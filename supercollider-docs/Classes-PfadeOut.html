PfadeOut

将事件模式淡出

PfadeIn : FilterPattern : Pattern : AbstractFunction : Object

另请参阅：PfadeIn

类方法

PfadeOut.new(pattern, fadeTime: 1.0, holdTime: 0.0, tolerance: 0.0001)

来自父类：PfadeIn

参数：

pattern

要淡出的模式。必须是一个事件模式，用于播放带有 \amp 参数的 synth。

fadeTime

淡化所需的时间。

holdTime

tolerance

设置输入模式振幅时所用的已流逝时间舍入容差。

实例方法

.fadeTime

.fadeTime = value

来自父类：PfadeIn

获取或设置淡入淡出时间

.holdTime

.holdTime = value

来自父类：PfadeIn

获取或设置保持时间

.tolerance

.tolerance = value

来自父类：PfadeIn

获取或设置舍入内部时间时使用的容差。

.embedInStream(inval)

参数：

inval

.storeArgs

来自父类：PfadeIn

示例

(
// 创建一个你想淡出的 pattern
var pat = Pbind(\dur, 0.125, \degree, Pwhite(1, 10));

// 在 30 拍内淡出
pat = PfadeOut.new(pattern: pat, fadeTime: 30.0, holdTime: 1.0, tolerance: 0.0001);

// 播放它
pat.play;
)
