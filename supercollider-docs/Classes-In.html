In

从总线读取信号。

AbstractIn : MultiOutUGen : UGen : AbstractFunction : Object

参见：InFeedback、LagIn、SoundIn

说明

In.ar 和 In.kr 分别从音频总线和控制总线读取信号。（有关总线的详细信息，请参见 Busses 章节，该章节属于 Getting Started 教程系列。）

对于上一计算周期留在总线上的信号，In.ar 和 In.kr 的行为略有不同。

In.ar 可以访问当前计算周期内由位于节点树中较早位置的 Synth 节点生成的音频信号（参见执行顺序）。它不会读取上一个计算周期遗留在音频总线上的信号。如果 synth A 从音频总线 0 读取，synth B 写入音频总线 0，且 synth A 早于 synth B，则 synth A 中的 In.ar 将读取到 0（静音）。这是为了防止意外反馈。InFeedback 支持音频信号反馈。

In.kr 用于控制总线。控制信号可由服务器内的 Synth 节点生成，也可由客户端设置并期望其保持稳定。因此，In.kr 不区分"新"数据和"旧"数据：它总是读取总线上的当前值，无论该值是在本计算周期中较早生成的、从上一周期遗留的，还是由客户端设置的。

注意，使用 Bus 类来分配多通道总线，只是通过 Server 对象的总线分配器保留一系列相邻的总线索引。abus.index 只是返回这些索引中的第一个。

当将总线与 In 或 Out UGen 一起使用时，没有任何机制阻止你读取或写入更大的范围，或者硬编码到已分配的总线。你需要负责确保通道数匹配且没有冲突。有关总线及其使用方式的更多信息，请参阅 Server Architecture 和 Bus 帮助文件。

硬件输入总线紧接在硬件输出总线之后开始，可以使用 In.ar 从其中读取（更多细节参见 Server Architecture）。硬件输入和输出总线的数量可能因服务器选项而异。关于处理此问题的便捷包装类，请参见 SoundIn 。

类方法

In.ar(bus: 0, numChannels: 1)

In.kr(bus: 0, numChannels: 1)

参数：

bus

要读取的总线索引。

numChannels

要读取的通道数（即相邻的总线）。你不能通过在 SynthDef 中将其赋值给参数来调制这个数字。

实例方法

示例

从音频总线读取：

s.boot;

(
SynthDef("help-PinkNoise", { |out = 0|
    Out.ar(out, PinkNoise.ar(0.1))
}).add;

SynthDef("help-In", { |out = 0, in = 0|
    var input;
        input = In.ar(in, 1);
        Out.ar(out, input);

}).add;
)

// 在右声道播放噪声
x = Synth("help-PinkNoise", [\out, 1]);

// 读取输入并在左声道播放
Synth.after(x, "help-In", [\out, 0, \in, 1]);

从控制总线读取：

(
SynthDef("help-InKr", { |out = 0, in = 0|
    Out.ar(out,
        SinOsc.ar(In.kr(in, 1), 0, 0.1)
    )
}).add;
SynthDef("help-lfo", { |out = 0|
    Out.kr(out, LFNoise1.kr(0.3, 200, 800))
}).add;
)


b = Bus.control(s, 1);
b.set(800);

Synth("help-InKr", [\in, b.index]);
b.set(400);
b.set(300);
Synth("help-lfo", [\out, b.index]);

在节点顺序中稍后从 synth 读取控制数据：

(
SynthDef("help-Infreq", { |bus|
    Out.ar(0, FSinOsc.ar(In.kr(bus), 0, 0.5));
}).add;

SynthDef("help-Outfreq", { |freq = 400, bus|
    Out.kr(bus, SinOsc.kr(1, 0, freq/40, freq));
}).add;

b = Bus.control(s, 1);
)

// 将第一个控制 Synth 添加到默认服务器的尾部；此时还没有音频
x = Synth.tail(s, "help-Outfreq", [\bus, b.index]);

// 在它之前添加发声的 Synth；它从上一个周期接收 x 的数据
y = Synth.before(x, "help-Infreq", [\bus, b.index]);

// 在 y 之前添加另一个控制 Synth，位于服务器的头部
// 现在它会在 y 接收之前覆盖 x 的周期旧数据
z = Synth.head(s, "help-Outfreq", [\bus, b.index, \freq, 800]);

// 获取另一个 bus
c = Bus.control(s, 1);

// 现在 y 接收 x 的数据，即使 z 仍然存在
y.set(\bus, c.index); x.set(\bus, c.index);    // 警告！声音会变响！

x.free; y.free; z.free;
