PbindProxy

增量事件模式参考

Pattern : AbstractFunction : Object

另请参阅：Pbindef、Pdef

说明

保留一个 Pbind 的引用，其中单个键可以被替换。当旧流结束并设置新流时，它继续播放，并按节拍调度这些更改。

类方法

PbindProxy.new( ... pairs, ... kwargs)

使用给定的 patternpairs 返回 PbindProxy 的新实例。与 Pbindef 不同，它没有内部名称。

a = PbindProxy(\note, Pseq([0, 7, 9], inf), \dur, 0.2).play;
a.set(\note, Pseq([0, 6, 10]));
a.stop;

它也支持关键字参数语法：

a = PbindProxy(note: Pseq([0, 7, 9]), dur: 0.2).play;
a.stop;

实例方法

.source

返回 Pbind 的包装器

.set( ... args)

设置给定的 patternpairs。

.at(key)

返回该键处的模式。这可用于单独设置量化值，因此不同的基本模式可以按不同方式量化。

x.at(\freq).quant = 2;

.quant

.quant = val

设置所有基本模式的 quant，或返回源模式的 quant 值。

示例

(
    SynthDef(\Pdefhelp, { |out, freq, sustain = 1, amp = 1, pan|
        var env, u = 1;
        env = EnvGen.ar(Env.perc(0.03, sustain), 1, doneAction: Done.freeSelf);
        5.do { var d; d = exprand(0.01, 1); u = SinOsc.ar(d * 300, u, rrand(0.1, 1.2) * d, 1) };
        Out.ar(out, Pan2.ar(SinOsc.ar(u + 1 * freq, 0, amp * env), pan));
    }).add;
)
s.boot;


x = PbindProxy.new;
x.set(\instrument, \Pdefhelp);

x.play;

x.set(\degree, Pseq([0, 2, 5b, 1b], inf));
x.set(\dur, 0.1);
x.set(\degree, Pseq([1b, 5, 3, 1b, 6, 2, 5, 0, 3, 0, 2], inf));
x.set(\legato, Prand([1.0, 2.4, 0.2], inf), \mtranspose, -3);
x.set(\mtranspose, nil); // 移除键

x.set(\degree, Pseq([1, 2, 3, 4, 5, 6], 1));
x.play;

x.set(\degree, Pseq([1, 2, 3, 4, 5, 6], 3), \dur, 0.02);
x.play;

x.set(\degree, Pseq([1, 2, 3, 4, 5, 6], 3), \dur, 0.1);
x.set(\degree, Pseq([1b, 5, 3, 1b, 6, 2, 5, 0, 3, 0, 2], inf));
x.play;
