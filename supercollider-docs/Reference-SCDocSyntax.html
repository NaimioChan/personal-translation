SCDoc 语法

SCDoc 标记语言语法

另请参阅：Writing Help、SCDoc、SCDocHTMLRenderer

Introduction

本文档规定了 SCDoc 标记语言的语法和 Grammar。SCDoc Markup 在 SuperCollider 中主要用于帮助文件。它是一种具有特定于 SuperCollider 需求的语义层次的语法。

注意： 关于编写帮助文档的指南可在 Writing Help 中找到。

Specification

文档分为头部部分和主体部分。头部仅包含头部标签，这些标签不允许出现在文档主体中。

SCDoc 文档由标签和文本组成。

  • 标签由以 ::（双冒号）结尾的单个单词组成。
  • 未标记的文本变为普通散文。
  • 段落由一个或多个空行分隔。
  • 标签不区分大小写：TITLE::、Title:: 和 title:: 的解析结果相同。
  • 某些标签将同一行上的剩余文本作为其参数
  • 某些标签会包含其后的文本，直到单个结束标签（双冒号 ::）。
  • 有些包围标签可以嵌套，而另一些是模态的，会忽略任何标签直到遇到结束标签。

头部标签

头部标签将其定义行中剩余文本作为参数。它们不需要结束标签。

TITLE:: 名称

文档的标题。对于类参考文档，它必须与类名相同。

title:: SCDoc
CATEGORIES:: 列表

以逗号分隔的文档类别列表。主要由 Browse 页面使用。

类别可以是分层的，其中层级用 > 表示。

categories:: External Control>OSC, Scheduling>Clocks
RELATED:: 链接

以逗号分隔的相关文档列表。

related:: Classes/SCDoc, Reference/SCDocSyntax
SUMMARY:: 文本

本文档的简短摘要。

summary:: SCDoc markup language syntax
REDIRECT:: 名称

对于类重定向系统，指定保存实现类的实例变量的名称。示例：

redirect:: implClass
CLASS:: 名称

已弃用，请改用 TITLE。

节标签

文档可以划分为节和子节。节的主体由其节标签之后直到下一个同级或更高级别节标签之前的所有内容组成。

各节具有与节名相同的链接锚点。

注意： 方法标签也会创建此类锚点。方法名前面会加上 *（类方法）或 -（实例方法）。

层级中同一级别的结构化标签可能在功能上等价，但在渲染或查询目的上被区别对待。例如 examples:: 等价于 section::，但意味着特定的格式，或专门标识示例部分以用于定制用途，例如为具有给定父类的类连接所有示例。

结构标签可以有子元素，例如列表中的各项或章节中的小节和正文。

级别 1（最高）：

SECTION:: 名称

一个命名区块。名称应为纯文本，不能包含任何标签。

section:: Introduction
DESCRIPTION:: CLASSMETHODS:: INSTANCEMETHODS:: EXAMPLES::

这些标签开始类参考的标准章节。CLASSMETHODS 和 INSTANCEMETHODS 具有特殊含义，因为它们指定了所记录的方法是类方法还是实例方法。

级别 2：

SUBSECTION:: 名称

一个命名子节。名称应为纯文本，不能包含任何标签。示例：

subsection:: Some more info

级别 3：

SUBSUBSECTION:: 名称

命名的子子节。名称应为纯文本，且不能包含任何标签。示例：

subsubsection:: Some more detailed info

方法标签

这些是第 3 级子节：

METHOD:: 方法名 [argstring]

为一个或多个方法编写文档，方法名以逗号分隔的列表给出。

注意： 如果多个方法作为一组进行文档化，则对于已有参数，这些方法必须具有相同的参数名签名。例如，将以下方法分组是可以的：foo (a, b) bar (a, b, c) zoo (a) 但以下不行：foo (a, x) bar (a, b, c) zoo (y)

方法标签之后应跟方法的简短描述，以及可选的参数和返回值描述。参见下方方法内允许的标签一节。

SCDoc 将 getter 和 setter 方法视为单个属性的读/写接口。这意味着你不应为 setter 编写尾随下划线。相反，应将其记录为不带下划线的单个属性，就像只有一个 getter 一样，并描述该可设置/获取的属性。

METHOD 标签通常用在 CLASSMETHODS 和 INSTANCEMETHODS 内部，但也可以在这些区段之外使用。在这种情况下，它记录的是不绑定到特定类的通用接口，此时参数和默认值应在可选的 argstring 中给出

对于真实方法，不允许使用 argstring，而是会自动填入参数名和默认值。

PRIVATE:: 方法名

此标签的行为类似于一个 section，但没有 section 主体。它把一个或多个方法标记为私有，使其不会出现在自动生成的 Undocumented Methods 小节中。它期望一个以逗号分隔的方法名列表。

COPYMETHOD:: 类名 方法名

此标签的行为类似于一个 section，但没有 section 主体。从类参考中复制一段方法文档，并将其插入此处，就如同该方法是在本文档中记录的一样。方法名必须以 * 为前缀表示类方法，以 - 为前缀表示实例方法。

copymethod:: SinOsc *ar

在方法部分中，允许使用以下可选标签，按下面给出的顺序排列。这些标签是第 4 级子章节。

ARGUMENT:: [argname]

每个参数对应一项。参数部分的正文应包含对给定参数的描述。argname 是可选的，若未给出则会自动填充。若给出，则必须与该位置上参数的真实名称一致。

如果方法有 varargs，则 varargs 的参数名（如果给出）应以三个点和空格（"... "）为前缀

RETURNS::

本节应包含对返回值的描述，尤其是类型。

DISCUSSION::

这个可选部分可以包含与该方法的有关的更详细的讨论和代码示例。

method:: ar, kr
This is a nice method, try it out!
argument:: freq
The frequency of this thing as a floating point value.
argument:: amp
The amplitude, be careful. Goes to 11.
returns::
An UGen.

模态标签

这些标签包围一段文本，并以单个 ::（双冒号）结束标签结尾。所包围的文本不能包含任何其他标签。

STRONG::

以粗体字体渲染文本。

EMPHASIS::

以强调字体（通常为斜体）渲染文本。

SOFT::

以柔和色调渲染文本。

LINK::

创建指向另一个文档的链接。文本应为文档键，即相对于 Help 文件夹的路径且不带扩展名，例如 Classes/SinOsc 或 Reference/SCDocSyntax

可选地，路径后面可以跟 #anchor 以跳转到文档中的特定位置，并跟 #label 以指定链接的另一个标签。

所有类型的节都会自动创建一个与节同名的锚点。方法也会创建一个锚点，其中方法名对于类方法以 * 为前缀，对于实例方法以 - 为前缀。

路径可以为空，用于链接到当前文档内部的锚点；锚点也可以为空，仅指定链接标签。

See section link::#Introduction:: in this document.
Take a look at link::Classes/SCDoc#*indexAllDocuments::
Try link::Search#scdoc#Searching for SCDoc::,
or perhaps link::Classes/SinOsc##go make some music::

URL 会自动变成链接，但如果想使用另一个链接标签，也可以用此标签显式创建。

ANCHOR::

在文档中的此位置手动创建锚点。

IMAGE::

插入图像，文本应为图像的相对路径。

image::foo.png::

可选地可以给出图像标题：

image::foo.png#Figure 1::

并且，图像可以点击并链接到另一个页面：

image::foo.png#click this image#Classes/SinOsc::

如果你想要链接但没有标题，只需将标题留空。

MATH::

将 LaTeX 代码转换为行内公式。例如

math::\frac{\pi}{2}::

变为嵌入在一行文本中的 π/2。

以下标签（CODE、TELETYPE 和 MATH）可以写成两种形式：内联或块级。内联形式的结束标签位于同一行，并且需要将应作为文本一部分的任何双冒号用反斜杠（\）转义。块级形式的开始标签和结束标签各自独占一行，并且可以接受多行文本。在块级形式中，只有单独占一行的结束标签才有效，文本内部的任何结束标签都不应转义（除非它位于单行上）。

code:: inline form ::

code::
block form :: <- needs no escaping
can span multiple lines
::
CODE::

渲染语法着色的 SuperCollider 代码。

TELETYPE::

渲染等宽文本。

MATH::

以显示样式渲染 LaTeX 代码。例如

math::
\int_0^{2\pi}\sin(x)~dx = 0
::

becomes∫₀^2π sin(x) dx = 0

它通过一个块与文本分隔。具体细节请查看所使用的渲染引擎 kaTeX，网址为 https://katex.org

列表与表格

列表项、表格行和定义术语使用 ##（双井号）表示。表格单元格和定义描述使用 ||（双竖线）表示。列表和表格可以嵌套，并以结束标签结束。

TABLE::

创建表。示例：

table::
    ## a 1 || a 2 || a 3
    ## b 1 || b 2 || b 3
    ## c 1 || c 2 || c 3
::

Renders:

a 1

a 2

a 3

b 1

b 2

b 3

c 1

c 2

c 3

DEFINITIONLIST::

定义列表项由一个或多个以 ## 为前缀的术语组成，后跟以 || 为前缀的描述。示例：

definitionlist::
     ## foo
     ## bar
     || Common dummy-variable names.
     ## SuperCollider
     || A very nice computer software.
::
LIST::

创建一个简单的项目符号列表。项目以 ## 为前缀

NUMBEREDLIST::

创建编号列表。各项以 ## 为前缀

TREE::

创建一个树结构。通常与更多 TREE 标签嵌套使用。项目以 ## 为前缀

注释与警告

这些标签内部可以包含其他标签，并以结束标签结尾。

NOTE::

创建一个包含重要内容的 NOTE 框。

注意： 像这样

WARNING::

创建一个包含非常重要内容的 WARNING 框。

警告： 像这样

FOOTNOTE::

创建一条脚注，它将在文档末尾渲染。在 FOOTNOTE 标签所在的位置，将渲染脚注编号，并带有一个指向该脚注的链接。示例：

Hello I'm a geek footnote::
According to http://en.wikipedia.org/wiki/Geek the word geek is a slang term, with different
meanings ranging from "a computer expert or enthusiast" to "a carnival performer who performs
sensationally morbid or disgusting acts"
::

结果是这样的：Hello I'm a geek1

其他标签

KEYWORD:: 关键字

为此文档指定一个或多个可搜索的关键字。将在此标签的位置创建一个以 kw_ 为前缀的关键字锚点。

CLASSTREE:: 类名

渲染从给定类开始的子类类树。

Grammar

以下是语法的精确规范：

start             ::= document
document          ::= START_FULL dochead optsections
                    | START_PARTIAL sections
                    | START_METADATA dochead optsections
dochead           ::= { headline } headline
headline          ::= ( headtag words2 | "CATEGORIES::" commalist | "RELATED::"
                      commalist ) eol
headtag           ::= "CLASS::"
                    | "TITLE::"
                    | "SUMMARY::"
                    | "REDIRECT::"
sectiontag        ::= "CLASSMETHODS::"
                    | "INSTANCEMETHODS::"
                    | "DESCRIPTION::"
                    | "EXAMPLES::"
optsections       ::= [ sections ]
sections          ::= sections section
                    | section
                    | subsections
section           ::= ( "SECTION::" words2 eol | sectiontag ) optsubsections
optsubsections    ::= [ subsections ]
subsections       ::= subsections subsection
                    | subsection
                    | subsubsections
subsection        ::= "SUBSECTION::" words2 eol optsubsubsections
optsubsubsections ::= [ subsubsections ]
subsubsections    ::= subsubsections subsubsection
                    | subsubsection
                    | body
subsubsection     ::= "SUBSUBSECTION::" words2 eol optbody
                    | "METHOD::" methnames optMETHODARGS eol methodbody
                    | "COPYMETHOD::" words eol
                    | "PRIVATE::" commalist eol
optMETHODARGS     ::= [ METHODARGS ]
methnames         ::= { METHODNAME COMMA } METHODNAME
methodbody        ::= optbody optargs optreturns optdiscussion
optbody           ::= [ body ]
optargs           ::= [ args ]
args              ::= { arg } arg
arg               ::= "ARGUMENT::" ( words eol optbody | eol body )
optreturns        ::= [ "RETURNS::" body ]
optdiscussion     ::= [ "DISCUSSION::" body ]
body              ::= blockA
                    | blockB
blockA            ::= [ blockB | blockA ] bodyelem
blockB            ::= [ blockA ] prose
bodyelem          ::= rangetag body "::"
                    | listtag listbody "::"
                    | "TABLE::" tablebody "::"
                    | "DEFINITIONLIST::" deflistbody "::"
                    | blocktag wordsnl "::"
                    | "CLASSTREE::" words eol
                    | "KEYWORD::" commalist eol
                    | EMPTYLINES
                    | "IMAGE::" words2 "::"
prose             ::= { proseelem } proseelem
proseelem         ::= anyword
                    | URL
                    | inlinetag words "::"
                    | "FOOTNOTE::" body "::"
                    | NEWLINE
inlinetag         ::= "LINK::"
                    | "STRONG::"
                    | "SOFT::"
                    | "EMPHASIS::"
                    | "CODE::"
                    | "TELETYPE::"
                    | "MATH::"
                    | "ANCHOR::"
blocktag          ::= CODEBLOCK
                    | TELETYPEBLOCK
                    | MATHBLOCK
listtag           ::= "LIST::"
                    | "TREE::"
                    | "NUMBEREDLIST::"
rangetag          ::= "WARNING::"
                    | "NOTE::"
listbody          ::= { "##" body } "##" body
tablerow          ::= "##" tablecells
tablebody         ::= { tablerow } tablerow
tablecells        ::= { optbody "||" } optbody
defterms          ::= { "##" body } "##" body
deflistrow        ::= defterms "||" optbody
deflistbody       ::= { deflistrow } deflistrow
anywordurl        ::= anyword
                    | URL
anyword           ::= TEXT
                    | COMMA
words             ::= { anyword } anyword
words2            ::= { anywordurl } anywordurl
eol               ::= NEWLINE
                    | EMPTYLINES
anywordnl         ::= anyword
                    | eol
wordsnl           ::= { anywordnl } anywordnl
nocommawords      ::= nocommawords TEXT
                    | nocommawords URL
                    | TEXT
                    | URL
commalist         ::= { nocommawords COMMA } nocommawords

[1] - 根据 http://en.wikipedia.org/wiki/Geek 的说法，geek 一词是俚语，含义各异，从“计算机专家或爱好者”到“表演骇人或恶心节目的狂欢节表演者”不等
