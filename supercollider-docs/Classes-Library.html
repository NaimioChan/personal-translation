Library

将对象保存在中心位置

LibraryBase : MultiLevelIdentityDictionary : Collection : Object

另请参见：Archive、LibraryBase

说明

Library 是一个全局的 MultiLevelIdentityDictionary。Library 可用于存储希望全局访问的数据。它是使用类变量的一种替代方案。它是存储菜单、注释和常用可复用函数的好地方。
