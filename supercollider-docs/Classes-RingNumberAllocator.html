RingNumberAllocator

在指定范围内的循环数字分配器

Object

另请参见：ContiguousBlockAllocator、PowerOfTwoAllocator、StackNumberAllocator

说明

连续循环遍历数字范围，一旦到达范围末端便从头重新开始。

类方法

RingNumberAllocator.new(lo, hi)

创建一个新实例，带有 lo 和 hi 值。

参数：

lo

初始值

hi

maximum

实例方法

.alloc

分配下一个编号。达到 hi 值后返回 lo。

返回值：

（在此处描述返回值）

.init

将分配器重置为其初始状态。

示例

a = RingNumberAllocator.new(3, 5)
7.do {a.alloc.post } // 3453453
a.init
a.alloc // 3
