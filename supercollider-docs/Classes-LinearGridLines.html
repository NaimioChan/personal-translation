LinearGridLines

计算适合线性间隔网格线的数值，用于绘图或其他 UI 元素。

参见：GridLines、AbstractGridLines、ExponentialGridLines、DrawGrid、ControlSpec、Plotter、plot

说明

LinearGridLines 是一个策略对象，用于为绘制网格线和标签寻找合适的间隔。其值跨越由对应的 ControlSpec 所定义的范围。LinearGridLines 的大部分功能继承自其父类 AbstractGridLines。这些实例方法由 DrawGrid 使用（而 DrawGrid 又由 Plotter 使用），由它负责绘制线条和标签。

LinearGridLines 通常不会直接实例化，而是由 GridLines 工厂类或 ControlSpec: -grid 方法实例化，这些方法会针对给定的 spec 返回相应的 AbstractGridLines 子类。

(
// LinearGridLines
var linGrid = ControlSpec(0, 100, \lin, units: "Time").grid;
// ExponentialGridLines
var expGrid = \freq.asSpec.grid;

DrawGrid.test(linGrid, expGrid);
)

类方法

.new

参数：

spec

一个定义数值范围、warp 和 step 的 ControlSpec。

返回值：

此类的实例。

注意： AbstractGridLines 不应直接实例化。应使用 GridLines 工厂类或 ControlSpec: -grid 方法来返回合适的 AbstractGridLines 子类。

实例方法

.spec

获取/设置定义数值范围、warp 和步进的 ControlSpec。

返回值：

一个 ControlSpec。

.asGrid

返回此对象。

讨论：

nil.asGrid 返回一个 BlankGridLines（AbstractGridLines 的子类），它不绘制任何线条。因此，如果 nil 被传给 DrawGrid 的 grid 参数，则对应轴上不会绘制任何线条。

.niceNum

将一个值舍入到处于相同数量级内的逻辑“漂亮数字”。详情见下文讨论。

参数：

val

你希望变得更美观的值。

round

一个布尔值。粗略地说，舍入允许返回的数字高于或低于输入 val（类似于 round 操作），而当为 false 时，返回的数字倾向于高于 val（类似于 ceil）。

返回值：

该友好数字。

讨论：

此方法用于支持确定网格线值的内部计算，不过它也可能对其他应用有用。

观察舍入行为：

(
var g = GridLines([0, 10000].asSpec);
"in val / rounded / not rounded".postln;
10.collect{ 10000.rand }.sort.do({ |x|
    postf("% / % / %\n", x, g.niceNum(x, true), g.niceNum(x, false))
})
)

该实现基于：A. S. Glassner, Ed., Graphics Gems. San Diego: Morgan Kaufmann, 1990。

.looseRange

返回将包含 min 和 max 的逻辑最小值和最大值，内部使用 -niceNum 确定。

参数：

min

要包含在返回范围中的最小值。

max

要包含在返回范围中的最大值。

ntick

在 [min, max] 范围内你希望的行数（“刻度”），默认值：5。

返回值：

一个 Array，包含你的 min 和 max 所对应范围的下界和上界，即 [rangeMin, rangeMax]。

.getParams

专供 DrawGrid 使用。返回一个 Dictionary，其键为：'lines'，即应在其中绘制线条的值的数组；以及 'labels'，即每条线的 2 元素数组 [value, "formatted label"] 组成的数组。

注意，返回的最高值和最低值不一定包含你的 valueMin 和 valueMax，而是表示 DrawGrid 将绘制网格线的值（端帽线随后在数据/网格边界处绘制）。

参数：

valueMin

要绘制的数据的最小值。返回的最低网格线值可能高于此值。

valueMax

要绘制的数据的最大值。返回的最高网格线值可能低于此值。

pixelMin

网格范围的下界，以像素为单位。当基于 tickSpacing 确定网格值（若 numTicks 为 nil）时，用于计算可用网格空间的大小。

pixelMax

网格范围的上界，以像素为单位。当基于 tickSpacing 确定网格值（若 numTicks 为 nil）时，用于计算可用网格空间的大小。

numTicks

你希望在图上看到的刻度数量的显式指定值（不过结果只是近似值）。如果你希望根据 pixelMin、pixelMax 和 tickSpacing 自动确定刻度数量，请设为 nil。

tickSpacing

刻度之间的最小距离（以像素为单位）。此值仅在 numTicks 为 nil 时使用。

返回值：

一个 Dictionary。

.formatLabel

将数值格式化为文本显示，舍入到所需精度。

参数：

val

要舍入并转换为文本标签的值。

numDecimalPlaces

返回的 String 中要表示的小数位数。

返回值：

一个 String。
