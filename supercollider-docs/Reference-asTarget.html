asTarget

转换为有效的 Node Target

另请参阅：Node

asTarget

下面列出的类实现了方法 asTarget。该方法在 Node 类（Group 和 Synth）中被广泛使用，用于将非 Node 对象转换为合适的目标。这使得 nil 和 Server 的实例可以用作目标。在编写内部创建节点的类时，这可能很有用，但在大多数情况下，正常使用中几乎不需要调用 asTarget。

有关实现 asTarget 的类的更新列表，请参见 Methods: asTarget 中的 asTarget

Node: -asTarget

返回 Node 本身的实例。Node 的子类（Synth 和 Group）是有效目标，无需转换。

Server: -asTarget

返回一个 Group 对象，表示此 Server 实例的 Default Group。请注意，该对象可能与其他表示默认组的对象不完全相同，但会是等价的。

s = Server.default;
g = s.asTarget;     // s 的默认组
h = s.defaultGroup; // 再次
g == h;             // true
g === h;            // false
Nil: -asTarget

返回一个 Group 对象，表示当前默认服务器的默认组。

s = Server.default;
g = nil.asTarget;
g == s.defaultGroup; // true
Integer: -asTarget

返回一个 Group 对象，表示当前默认 Server 上的一个组节点，以该 Integer 作为其节点 ID 编号。

注意： 尽管这在某些情况下很方便，但它不会在默认服务器上创建相应的节点，也不会检查以确保该节点存在。此外，它不会直接访问服务器的 NodeIDAllocator，因此节点 ID 可能会重复。由于这些原因，使用此方法时应格外小心。当处理非默认 Server 时，Group-basicNew 更安全也更简单，否则需要设置 server 实例变量以确保正确的定位。

/////// 展示问题

s = Server.default;
s.boot;
g = s.nextNodeID.asTarget;
x = Synth.head(g, "default");   // 但服务器上不存在 g
s.sendMsg(*g.addToHeadMsg);     // 现在它被发送到默认服务器，在默认组中
x = Synth.head(g, "default");   // 现在这样可行
x.free; g.free;

// 如果不使用默认 Server，Integer-asTarget 可能会出现问题

Server.default = Server.local;
Server.default.boot;            // 退出默认服务器
i = Server.internal; i.boot;
g = i.nextNodeID.asTarget;
i.sendMsg(*g.addToHeadMsg);     // 似乎可行，但是……
x = Synth.head(g, "default");   // 糟糕，这发送到了默认服务器，所以找不到 Group
g.server == Server.default;     // true，所以这就是问题所在
g.server = i;
x = Synth.head(g, "default");   // 现在到正确的位置
x.free; g.free;
/////// 一个更实用的示例

s = Server.default;
s.boot;
s.sendMsg(\g_new, x = s.nextNodeID);
// ...

// 现在，如果由于某种原因我们需要使用 Node 对象
y = Synth.head(x.asTarget, "default");

// 这比 Group.basicNew(s, x); 更简单，前提是你使用的是默认服务器：
z = Synth.head(Group.basicNew(s, x), "default");

y.free; z.free; x.asTarget.free;
