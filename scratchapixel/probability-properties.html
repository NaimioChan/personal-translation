概率的性质

阅读时间：9 分钟。

互斥事件与完备事件

一般来说，学概率论时你会花不少时间学习与集合有关的东西（更一般地说是集合论）。如第一章所解释的，样本空间就是一个集合的例子。与集合相关的定理和性质有一大串，比如两个集合的并集或交集是什么，等等，但我们不在这里学它们（因为它们对我们不那么重要，而且我们也得承认它们相当无趣）。不过互斥事件这个概念是个例外，你需要了解它。如果两个集合 A 与 B 没有公共元素，就说它们是互斥的或不相交的（两个说法意思相同）。例如 \(A = \{1, 2, 3\}\) 和 \(B = \{4, 5, 6\}\) 就是两个互斥或不相交的集合。用到事件的概念上，我们说两个事件互斥（或不相交），是指它们不可能同时发生。注意不要把这个概念与独立事件的概念混淆（见下文）。

另一个重要概念解释起来略为简单些，那就是完备事件的概念。如果一组事件（比如骰子的点数）中至少有一个必定发生，就说这组事件是联合完备的，或称完备的。

当你开始把互斥事件与完备事件这两个概念组合在一起时，事情就稍微复杂了（一堆拗口的数学表达）。例如，我们知道 1、2、3、4、5、6 是掷骰子的可能结果。因此在这个情形下，我们可以说该集合中的事件是完备的，因为掷骰子时我们一定能得到其中一个数字（而且只能是这些数字）。但如果你考虑由结果 1 和 6 构成的集合，这些事件是互斥的（因为它们不可能同时发生），但并不完备（因为你可能得到别的数字，比如 2、3、4 或 5，因此你无法保证必定得到 1 或 6）。掷硬币则是产生既互斥又完备的事件的实验例子：两个可能结果中（你要定义随机过程至少需要两个结果，只有一个那就是确定性的），你一定能得到其中之一（因此它们是完备的），而如果你得到「正面」，你就不可能得到「反面」（因此它们是互斥的）。

概率的性质

如果你记得我们在第一章给概率下的定义：事件 A 发生的概率 Pr(A)，其中 A 是实验样本空间的可能结果之一，那么 Pr(A)（A 会发生的概率）要成立，需要满足三条公理：

  • 公理 1：首先对每个事件 A，\(Pr(A) \ge 0\)，

  • 公理 2：如果某个事件必定发生，那么该事件的概率为 1。

  • 公理 3：第三条公理涉及概率的可加性，我们在第 1 章已经谈过。它说的是：如果两个事件互斥（上面我们解释了什么是互斥事件），那么其中一个或另一个发生的概率是它们概率之和。正式地说，任何可数的互斥事件序列 \(E_1, E_2, ...\) 都满足：$$Pr(E_1 \cup E_2 \cup \;...) = \sum_{i=1}^\infty Pr(E_i).$$ 在集合论中，用来表示并集的 \(\cup\) 符号可以读作「或」。例如两个集合 A 与 B 的并集（写作 \(A \cup B\)）是那些在 A 或在 B 或同时在 A 和 B 中的点构成的集合。我们在第一章已经给过这条公理应用的一个例子。

本章余下部分我们假定所处理的实验都有有限样本空间，换句话说，我们只考虑可能结果数目有限的实验（它们的样本空间 S 含有限个元素 \(s_1, s_2, ..., s_n\)）。如果你现在假定概率 \(p_i\) 与样本空间 S 中的结果 \(s_i\) 相关联（其中 \(i = 1, 2, ..., n\)），那么这些概率 \(p_1, p_2, ..., p_n\) 必须满足下列条件：

\(p_i \ge 0\)，对 \(i = 1, ..., n\)

以及

\(\sum_{i=1}^n p_i = 1\)。

记得第 15 课（《着色的数学》）中讲过 \(\sum\) 符号是求和的意思。换句话说，一个实验中每个可能事件所关联的所有概率之和总是 1（六面骰子每个点数所关联的概率之和，即 6 个 1/6，为 1）。

从这些公理可以推出几条更有用的性质。如果你考虑每个结果出现可能性都相同的实验（每个结果的概率是 \(1 \over n\)，\(n\) 是可能结果的数目），那么若该实验样本空间中的事件 A 恰好包含 \(m\) 个结果，则 \(Pr(A) = {m \over n}\)（换句话说，在简单样本空间 S 中，事件 A 的概率是 A 中结果数目与 S 中结果总数之比）。如果你考虑掷骰子得到奇数的概率，这里 m=3、n=6，那么 Pr(奇数)=3/6。还有几个推论：如果事件集合 A 是事件集合 B 的子集（数学中记作 \(A \subseteq B\)），那么 \(Pr(A) \le P(B)\)。这称为单调性。最后，事件 E 发生的概率只能大于等于零、小于等于一：\(0 \le Pr(E) \le 1\)。这称为数值界限性质。如果一个事件从不发生，其概率为 0；如果它总是发生，其概率为 1。

还有最后一个对我们这些关心 3D 渲染的人很重要的定理。它叫作乘法法则。要理解蒙特卡罗方法并不需要知道它，但既然这门课程是泛泛谈概率的地方，而且我们后面在这些教程中会用到这个定理（当我们学习一种叫俄罗斯轮盘赌的技术时），所以我们在这里介绍它。要理解乘法法则，你需要考虑一个实验，比如我们把一枚硬币掷两次。想象你记下第一次和第二次掷出的是「正面」还是「反面」。现在的问题是：「得到 HH 的概率是多少？」（其中 H 表示正面，T 表示反面），换句话说，我们连续得到两个正面的概率是多少？下面这张图（叫作概率树）也许能帮你对这个问题答案有个直觉：

第一次掷出后得到「正面」的机会是 \(1 \over 2\)。因为这些事件互斥，第二次掷出得到「正面」的机会仍然是 50%，然而连续两次得到正面的合成概率，是第一次得到「正面」的概率乘以第二次得到正面的概率，即 \(1 \over 4\)。看看上面那棵概率树，也许更容易理解。每次掷出得到「正面」或「反面」的概率都相同，但得到某个特定「正」「反」序列的概率，是该序列中各结果概率相乘的结果。换句话说，若想求比如序列 HHT 的概率，就得把得到 H 的概率乘以再次得到 H 的概率、再乘以得到 T 的概率，即 \( {1 \over 2 } * {1\over 2} * {1 \over 2} = {1 \over 8} \)。不过这只有在序列中各事件彼此独立时才成立（见下文）。对这个定理感兴趣的读者可以查一下条件概率。

独立事件

掷一枚硬币时，如我们所知，得到正面或反面的概率是 \(1\over 2\)，但如果你再掷第二次，得到正面或反面的概率仍然是 \(1\over 2\)。换句话说，第一次掷出并没有改变第二次掷出的结果，或者换个说法：第二次掷出得到正面或反面的机会，与我们第一次是否得到「反面」或「正面」完全无关。当然，这与你掷多少次硬币无关。如果你连续得到 5 次正面（虽然不太可能，但至少从概率角度看仍然可能），到第六次，你得到「正面」或「反面」的机会仍然是五五开，而这就是你所说的不相交或互斥事件。事件彼此独立——或者说，这也许是对独立事件更正式的定义——如果知道某个事件 B 已经发生并不改变 A 的概率，那么就说 A 与 B 独立。当事件独立时，由上面介绍的乘法法则可推出 \(Pr(A \cap B) = Pr(A)Pr(B)\)。集合论中 \(\scriptsize \cap\) 符号表示交集。这个表达式可以读作：得到 A 和 B 的概率等于 A 与 B 各自概率的乘积。
