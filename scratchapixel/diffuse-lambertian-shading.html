漫反射与朗伯着色

阅读时间：22 分钟。

漫反射或朗伯着色

在 CG 中模拟漫反射物体很容易。但要弄清它是怎么工作的，我们得先了解光与表面相互作用的方式。严格来说，要把这个题目彻底弄懂，应该先学辐射度量学。为了让这节入门课保持简单直观，我们就跳过这一步。把概念简化一下：在 CG 中给一个点着色时，我们假定这个点代表一块非常小的表面，我们称之为微分面积。别太在意「微分」这个词，把注意力放在「面积」上。我们不讨论没有物理意义的理论上的点，而是考虑该点周围一小块面积，在 CG 里一般记作 \(dA\)。此外，我们考虑的是落在 \(P\) 周围这一小块面积表面上的光的量。落在 \(P\) 处的光不能被简化成一条光线，因为我们关心的不是一个孤立的点，而是该点周围的小区域 \(dA\)。落在这个区域上的光包含在一个垂直于 \(P\) 的小体积内，如下图所示中左边的插图。

换句话说，包含在这个体积内、截面与 \(dA\) 相同的全部光能，都落在 \(dA\) 上。如果像上图左图那样，有恒定的光能通量穿过这个体积，那么可以认为任意时刻都有恒定数量的光能打到 \(dA\) 的表面。换个说法：想象任意时刻都有 1000 个光子打到 \(dA\) 的表面。这 1000 个光子会与物体表面发生作用：一部分被吸收，一部分几乎同时被反射。过了很短一段时间，又有 1000 个新光子打到 \(dA\) 的表面。如果光子通量恒定，这个过程就会不断重复。由于垂直于 \(dA\) 的光锥截面与 \(dA\) 相同，\(dA\) 每隔一小段时间就会被 1000 个光子轰击一次（在 CG 中我们常把这小段时间记作 \(dt\)，这个概念与 \(dA\) 类似，只是作用在时间上）。当这个光锥相对于 \(P\) 处的法线倾斜时，会出现一个有趣的现象。如上面第二、第三幅插图所示，随着光束与 \(P\) 处法线之间的夹角增大，光束与物体表面的截面会变得比 \(dA\) 更大。换种说法：原本打到 \(dA\) 的那 1000 个光子，当光束与法线成一定夹角时，只有其中一部分到达 \(dA\)。这个比例（\(dA\) 接收到的光子数占光束中光子总数的比例）随着夹角增大而变小。当光束垂直于物体表面时，完全没有光子打到 \(dA\)。

总结一下：

  • 当光束垂直于 \(dA\) 时，小光锥内 100% 的光子（该光锥的截面与 \(dA\) 相同）都会打到 \(dA\)。

  • 当光束与着色点的法线成一定夹角时，光束与表面的截面就变得比 \(dA\) 更大。这意味着光子或光能被分布在比 \(dA\) 更大的区域上。既然我们只关心落在 \(dA\) 所覆盖区域上的光能量，也可以说：光束与法线的夹角越大，到达 \(dA\) 的光子越少。夹角越大，光子越少。因此，随着光束与法线之间的夹角增大，\(dA\) 接收到的能量越来越少。

  • 极端情况下，当光束垂直于 \(P\) 处的法线时，光子完全不会落到 \(dA\) 上。这种特殊情形下，\(dA\) 完全接收不到任何光能。

从这些观察出发，就比较容易理解：当光束垂直于表面，换句话说，当表面法线 \(N\) 与光线方向 \(L\) 平行时，面元 \(dA\) 接收到的光能最多。然而，当光束以一定角度照射表面时，\(dA\) 接收到的光能比光束垂直于表面时要少，这意味着表面本身向环境中反射的光也会更少。由此自然可以推出：表面会变暗。如前所述，随着 \(N\) 与 \(L\) 之间的夹角增大，打到 \(dA\) 上的光子越来越少。实际效果就是：两个向量之间的夹角越大，表面越暗。最终，当 \(N\) 与 \(L\) 垂直时，\(dA\) 完全接收不到光，因此呈黑色（既然接收不到光，也就不会反射任何光）。更一般地说，亮度与 \(dA\) 除以 \(dL\) 的比值成正比。由于 \(dL\) 即光束的斜截面，会随着两个向量之间夹角的增大而变大，这个比值随夹角增大而减小。

这条原理是 CG 中最基本、最广为人知的现象之一，名字叫朗伯余弦定律。表面接收到的光的量，与表面法线 \(N\) 和光线方向 \(L\) 之间的夹角直接成正比。这个夹角在数学上可以定义为：

$$\cos\theta = N \cdot L$$

定律名字里的「余弦」就是这么来的。夹角 \(\theta\)（希腊字母 theta）的余弦，定义为向量 \(N\) 与 \(L\) 的点积。如果这门课里只能记住一件事，那大概就应该是这条基本定律。当然，表面反射多少光、因而看起来多亮，直接取决于它接收多少光。于是我们可以这样写：漫反射表面的最终颜色（「漫反射」在这里的含义，我们马上就会定义）与两个向量之间夹角的余弦成正比：

$$ \begin{array}{l} \text{Diffuse Surface Color} & \propto & \text{Incident Light Energy} \cdot \cos\theta \\ & \propto & \text{Incident Light Energy} \cdot N \cdot L \\ \end{array} $$

这里的符号 \(\propto\) 表示「正比于」。不过这只是问题的一个方面。现在至少知道怎么计算到达漫反射表面某一点的光的量了，但要补全整幅图景、得出可用的公式，还需要知道漫反射表面把这些光中的多少反射到环境中，尤其是沿观察方向（眼睛的方向）。首先，当光能打到 \(P\) 处的表面时，一部分被物体吸收，一部分被反射。如第一章所述，这由表面的 反照率 参数决定。反照率定义的是反射光与入射光之比：

$$\text{albedo} = \dfrac{\text{reflected light}}{\text{incident light}}.$$

在计算机图形学中，反照率常用希腊字母 \(\rho\)（rho）表示。把这几块拼起来：我们有入射光的量，它正比于表面法线与光线方向之间的夹角；也有表面反射光的量，它正比于表面反照率。把这两个部分合在一起，可以说漫反射表面反射的光量，等于它接收的光量乘以反照率（即入射光中被表面反射、也就是未被吸收的那部分比例）：

$$\text{Diffuse Surface Color} = \text{albedo} \cdot \text{Incident Light Energy} \cdot N \cdot L.$$

在已知入射光能、表面法线、光线方向和表面反照率的情况下，这几乎就是计算漫反射表面某点颜色的完整公式了。只差一项就能把公式补齐。

如第一章所述，漫反射表面有一个独特性质：它把打到表面的光，向入射点上方所有方向等量地反射出去。想象一束光打到物体表面的某一点，光能就从这个入射点向外的方向半球上重新分布，如图 3 所示。从实用角度看，这意味着光束的能量（我们知道它被表面法线与光线方向夹角的余弦所衰减）被重新分布到半球的表面上。反过来看这个问题：如果把这个半球表面上分布的全部能量收集起来，它应该等于入射光能，当然要减去被表面吸收的那部分光。重新分布出去的光与入射到表面的光一样多，只少了被表面吸收的部分。在数学上，把这个半球表面上的光能收集起来，可以用积分写出：

$$\text{Amount of Reflected Light(P)} = \color{green}{\int_\Omega} \color{red}{\rho_d \cdot \text{Light Energy} \cdot \cos\theta}\color{green}{\;d\omega}.$$

积分符号的意思是：我们要把散布在半球表面上的全部光能，以某种方式加总起来（可以想象成在数分布在该半球表面上的光子数）。这个公式里半球的概念由 \(\Omega\) 这一项表示。读这个公式时，你可以说：「收集（\(\int\) 这一项）一束入射光经 \(P\) 处的表面反射后的光能（也就是例如光子数），收集范围是半球（这里由 \(\Omega\) 这一项定义），该半球绕入射点处的表面法线 \(N\) 定向。」我们知道，反射的能量本身等于表面反照率乘以入射光能，再乘以表面法线与光线方向夹角的余弦。把这两个概念合起来，就得到左边那个积分项（公式中绿色的部分），以及我们要收集的东西，即积分号右边红色的那一项。

如果你对积分的概念不熟悉，建议先读一读 着色数学 这门课。

这门课不会讲太多积分的内容，也不会解释 \(d\omega\) 这一项是什么意思。不过你应该知道：把「某个值」在某个物体的表面（这里是半球面）上收集起来，可以看成把表面切成许多小块，在这些小块的表面上测量我们关心的量，再把结果加起来。这样做是因为要测量的量在物体表面上可能会变化。比如物体只是一块平面时，平面上一个小块的面积可以直接用平方米、英寸或你想用的任何长度单位来量，我们称之为微分面积。这个概念本章前面已经介绍过，微分面积一般记作 \(dA\)。但到了球面或半球面，我们不用平方米，而用球面度。球面度是立体角的单位，立体角是用角度而非长度来衡量球面上的一块区域的量。CG 中立体角最常用的符号是 \(\omega\)。因此 \(d\omega\) 这一项指的就是微分立体角的概念，说得更通俗些，就是球面上的一小块，只是用立体角来表示。上面那个积分的目的是：把关注的表面（这里是半球面）切成很小的块（即该半球面上的 \(d\omega\)，因为它们位于半球面上，数学上用球面度来度量），再把这些小块——也就是各个微分立体角——上测得的量加起来，从而测出某个值（本例中用红色标出的那个值）。

关于积分，以及如何用解析方法或 Monte Carlo 积分之类的技术求解，请参阅 着色数学 这门课。

好了，希望你同意这一点：表面反射的光量不可能大于真正到达表面的光量减去被吸收的光量。这合乎逻辑吧？换种说法：如果用上面的公式来量表面反射的能量，它应当小于或等于入射光能：

$$ \text{Total Amount of Reflected Light(P)} = \color{green}{\int_\Omega} \color{red}{\rho_d \cdot L_i \cdot \cos\theta}\color{green}{\;d\omega} \le L_i . $$

其中 \(L_i\) 表示入射光能。对我们来说幸运的是，这个特定情形下积分的结果可以用解析方法算出来。简单说，我们知道这个积分的结果是什么。再说一次，关于积分如何求解，请参阅《着色数学》这门课。这里可以用微积分第一基本定理。这个定理的思想是：如果已知某个函数 \(f\) 的原函数 \(F\)，就能算出 \(f\) 在某个闭区间上积分的结果。通常写成：

$$\int_a^b f(x)dx = F(b) - F(a).$$

我们这个积分的问题在于它是用立体角（\(d\omega\) 这一项）表示的，而立体角不是个好用的单位。为简化起见，可以把 \(d\omega\) 这一项换成 \(\sin\theta d\theta d\phi\)，其中角度 \(\theta\)（希腊字母 theta）定义在区间 [0, \(\pi/2\)] 上，角度 \(\phi\)（希腊字母 phi）定义在区间 [0, \(2\pi\)] 上。这个思路见图 5。换句话说，我们不再用球面度，而改用弧度也就是角度，处理起来更方便。不过现在要对两个量 \(\theta\) 与 \(\phi\) 积分，也就是说需要一个二重积分而不是一个积分：

把立体角换算成球坐标下的角度 \(\theta\) 和 \(\phi\) 时，为什么会用到 \(\sin(\theta)\)？

它来自这样一个需要：随着 \(\theta\) 变化，球面上区域的「宽度」也在变化，必须把这考虑进去。这是球面几何中的一个基本概念，尤其是在用积分描述球面上的面积时。

球坐标（\(\theta\) 与 \(\phi\)）在单位球（半径 = 1）上表示三维空间中的点。在这个系统中：

  • \(\theta\)（theta）是极角，从 z 轴正方向量起。

  • \(\phi\)（phi）是方位角，在 xy 平面内从 x 轴正方向量起。

处理球面这类表面上的积分时，我们用立体角表示面积。球坐标下的立体角 \(d\omega\) 与单位球上的面积相关。把球面上的一个小面积（比如一块面积微元）投影到 \(\theta\) 与 \(\phi\) 的平面上时，由于球面的曲率，这块面积在球面上的实际大小并不是一个简单的矩形。随着 \(\theta\) 变化，尤其是远离赤道（\(\theta = \frac{\pi}{2}\)）时，纬度带的「宽度」会减小。

  • 在两极（\(\theta = 0\) 或 \(\theta = \pi\)），这些带退化成点，没有宽度。

  • 在赤道（\(\theta = \frac{\pi}{2}\)），这些带的宽度最大。

\(\sin(\theta)\) 这个因子就是用来计入这种宽度变化的。它本质上是对球面面积元的「水平」（即方位）分量做缩放，该分量正比于 \(\sin(\theta)\)。

球坐标下球面（表面积）的微分面积元为 \(\sin(\theta) d\theta d\phi\)。于是函数在球面上的积分可写成：

$$ \int \int f(\theta, \phi) \sin(\theta) \, d\theta \, d\phi $$

这个积分把函数 \(f\) 在球面上加总，并借助 \(\sin(\theta)\) 正确地计入了不同纬度处面积大小的变化。使用 \(\sin(\theta)\) 对于准确反映球面的几何现实是必不可少的。它保证积分中表示的面积元正确体现了球的几何形状：靠近两极的面积比靠近赤道的面积小。当把积分从用立体角表示换算成用更熟悉的角度量 \(\theta\) 与 \(\phi\) 表示时，这一几何修正是关键。

这个二重积分等于单位球面积的数学证明：

我们来算一下。求球体总表面积的积分是：

$$ A = \int_{0}^{2\pi} \int_{0}^{\pi} \sin(\theta) \, d\theta \, d\phi $$

  • 对 \(\theta\) 积分：

    $$ \int_{0}^{\pi} \sin(\theta) \, d\theta = -\cos(\theta) \bigg|_{0}^{\pi} = -\cos(\pi) + \cos(0) = 2 $$

  • 对 \(\phi\) 积分：

    $$ \int_{0}^{2\pi} d\phi = 2\pi $$

把这两个结果合并：

$$ A = 2 \times 2\pi = 4\pi $$

这个结果 \(4\pi\) 正是单位球的表面积公式，说明在面积元中使用 \(\sin(\theta)\) 的积分计算确实得到了正确的总面积。

$$ {\int_{\phi=0}^{2\pi}}{ \int_{\theta=0}^{\pi/2}} \rho_d \cdot L_i \cdot \cos\theta \cdot \sin\theta \; {d\phi} \; {d\theta} \le L_i. $$

积分里被积的量，就是公式末尾带字母 \(d\) 的那些量。本例中是 \(\phi\) 与 \(\theta\)。换句话说，常数 \(\rho_d\) 与 \(L_i\) 不受影响，可以提到积分号外面：

$$ \rho_d \cdot L_i {\int_{\phi=0}^{2\pi}}{ \int_{\theta=0}^{\pi/2}} \cos\theta \cdot \sin\theta \; {d\phi} \; {d\theta} \le L_i. $$

还要注意，\(\le\) 号的两边都有 \(L_i\) 这一项。把不等式两边同除以 \(L_i\)，就得到：

$$ \rho_d \cdot \dfrac{L_i}{L_i} {\int_{\phi=0}^{2\pi}}{ \int_{\theta=0}^{\pi/2}} \cos\theta \cdot \sin\theta \; {d\phi} \; {d\theta} = \rho_d {\int_{\phi=0}^{2\pi}}{ \int_{\theta=0}^{\pi/2}} \cos\theta \cdot \sin\theta \; {d\phi} \; {d\theta} \le 1. $$

另外：

$$\int_a^b dx = b - a.$$

因此：

$$\int_0^{2\pi} d\phi = 2\pi.$$

我们可以把第一个积分（对 \(\phi\) 的积分）换成 \(2\pi\)：

$$\rho_d \cdot 2 \pi {\int_{\theta=0}^{\pi/2}} \cos\theta \cdot \sin\theta \; {d\theta} \le 1.$$

最后可以用微积分第一基本定理来解最后一个积分。\(\cos x \sin x\) 的原函数是：

$$-\dfrac{1}{2}\cos^2(x).$$

万一你没弄明白这个原函数是怎么求出来的，下面是推导步骤。我们从原函数出发，证明它的导数的确是 \(\cos(x) \sin(x)\)：

  • 起始表达式：

    • 考虑函数 \(-\frac{1}{2} \cos^2(x)\)。

  • 定义内层函数：

    • 令 \(u = \cos(x)\)。这样设定后，我们重新审视表达式：\(-\frac{1}{2} u^2\)。

  • 应用链式法则：

    • 为了求 \(-\frac{1}{2} u^2\) 对 \(x\) 的导数，我们用链式法则。链式法则规定：对复合函数求导时，先对外层函数求导、把内层函数当作常数，再乘以内层函数对 \(x\) 的导数。

  • 链式法则的实际运用：

    • \(-\frac{1}{2} u^2\) 对 \(u\) 求导得到 \(-u\)。

    • 在 \(u = \cos(x)\) 的前提下，\(u = \cos(x)\) 对 \(x\) 的导数是 \(-\sin(x)\)。

  • 合并结果：

    • 于是导数变为 \(-u \times (-\sin(x)) = \cos(x) \sin(x)\)。

  • 最后一步：

    • 代回原表达式，并把这些步骤串起来，我们得到：

    $$\frac{d}{dx}\left(-\frac{1}{2} \cos^2(x)\right) = \cos(x) \sin(x).$$

    • 这证实 \(-\frac{1}{2} \cos^2(x)\) 的导数确实是 \(\cos(x) \sin(x)\)，也就验证了 \(-\frac{1}{2} \cos^2(x)\) 是正确的原函数。

因此：

$$ \int_0^{\pi/2} \cos\theta \cdot \sin\theta \; {d\theta} = \left [ -\dfrac{1}{2}\cos^2(x) \right ]_0^{\pi/2} = -\dfrac{1}{2}\cos^2(\pi/2) + \dfrac{1}{2}\cos^2(0) = 0 + \dfrac{1}{2} = \dfrac{1}{2}. $$

最后得到结果：

$$\rho_d \cdot 2 \pi \cdot \dfrac{1}{2} = \rho_d \cdot \pi \le 1.$$

\(\rho_d\) 这一项，也就是表面反照率，可以取 [0,1] 区间内的任意值。假设某个表面的反照率取 0.5，那上面的不等式显然就不成立了：\(\frac{1}{2} \cdot \pi\) 并不小于 1。可见上面得到的公式并非对反照率所有可能取值都成立。要让这个不等式成立，唯一的办法是把反照率本身除以 \(\pi\)：

$$\dfrac{\rho_d}{\pi} \cdot \pi \le 1.$$

这样就成立了。所以漫反射表面反射的光量实际上是：

$$\text{Diffuse Surface Color} = \dfrac{\rho_d}{\pi} \cdot L_i \cdot \cos \theta.$$

因为把这个公式在半球上积分：

$$\text{Total Amount of Reflected Light(P)} = {\int_\Omega} {\dfrac{\rho_d}{\pi} \cdot L_i \cdot \cos\theta}{\;d\omega} \le L_i .$$

你就会发现，用这个公式，漫反射表面反射的能量不会多于它接收的能量：

$${\rho_d}\le 1.$$

可以把反照率除以 \(\pi\) 看成一种对积分结果做归一化的方法。

公式有了，来实践一下。这次需要给场景加一盏灯。为简单起见，先从一盏平行光开始，而且只有一盏。场景中有多盏灯时该怎么办、以及球形光源，我们会在下一章讲。我们会修改上一课里开发的光线追踪器的源码。首先，场景中每个物体现在都有一个反照率参数，你可以把它看成物体的颜色：


class Object 
{ 
    Object(const Matrix44f &o2w, const Vec3f &c = 0.18) : objectToWorld(o2w), worldToObject(o2w.inverse()), albedo(c) 
    ... 
    Vec3f albedo; 
    ... 
};

为什么默认颜色是 0.18？我们把 反照率 的默认值设为 0.18，是因为现实世界中的物体平均会反射掉所接收光的大约 18%。这是一个平均值。换句话说，如果你去查各种水果、沥青、雪、树叶、草等物体反射多少光，再把这些值取平均，得到的结果接近 18%。关于这个题目，更多信息见 深入 BRDF、线性与曝光 这门课。

当光线打到场景中的物体时，我们先算出交点处的表面法线，再用上面给出的公式算出与相机光线对应的像素颜色：


Vec3f castRay( 
    const Vec3f &orig, const Vec3f &dir, 
    const std::vector&ltstd::unique_ptr&ltObject>> &objects, 
    const std::unique_ptr&ltDistantLight> &light, 
    the Options &options) 
{ 
    Vec3f hitColor = options.backgroundColor; 
    float tnear = kInfinity; 
    Vec2f uv; 
    uint32_t index = 0; 
    Object *hitObject = nullptr; 
    if (trace(orig, dir, objects, tnear, index, uv, &hitObject)) { 
        Vec3f hitPoint = orig + dir * tnear; 
        Vec3f hitNormal; 
        Vec2f hitTexCoordinates; 
        hitObject-&gtgetSurfaceProperties(hitPoint, dir, index, uv, hitNormal, hitTexCoordinates); 
        Vec3f L = -light-&gtdir 
        // 计算被单个平行光源照亮的漫反射
        // 表面的颜色。
        hitColor = hitObject-&gtalbedo / M_PI * light-&gtintensity * light-&gtcolor * std::max(0.f, hitNormal.dotProduct(L)); 
    } 
 
    return hitColor; 
}

这只是公式的直接应用。反照率除以 \(\pi\)，保证表面反射的光不会多于它接收的光。然后结果乘以光强，再乘以光的颜色（这样得到交点处入射的总光能量），并按交点处表面法线与光线方向夹角的余弦衰减。

注意，如果光源与表面法线位于垂直于表面法线的平面的同一侧，那么表面法线与光线方向的点积为正。反之，如果光源在表面「背后」，点积为负。当然，光源在技术意义上位于表面背后时，本来就不该再照亮这个表面；但更重要的是，我们不希望在计算表面颜色时引入负值。因此我们用 C++ 的 std::max() 函数对点积结果做钳制（第 20 行）。
