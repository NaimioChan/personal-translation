抽样分布

阅读时间：34 分钟。

这一章请仔细读。它讲的是理解蒙特卡罗方法最重要的那些概念。由于这一章要读的内容已经很多，本章给出的公式中，大量数学证明会放到下一章。

抽样分布：来自统计学的统计量

我们无法计算一个无限总体的总体均值（这样的总体可以想象成无限多次掷硬币的结果。当然这个概念只是理论上的，这样的总体只存在于假设中）。即使总体是有限但非常大，计算均值也可能变成一件不切实际的任务。面对这两种情况中的任何一种，我们能做的替代方案是从总体中抽取样本（其中每个样本都可以看作一个随机变量），把这些抽到的随机变量之和除以样本数，得到我们所说的样本均值 \(\bar X\)。这个数给出的是总体均值 \(\mu\) 的一个估计（不是近似）。这两个概念我们已经在上一章介绍过。

在统计学里，当某个总体的某种特征可以用这个总体中所有元素或个体算出来时，我们说得到的值是总体的一个参数。比如总体均值就是一个总体参数，用来定义某个量的平均值。参数是固定的值。另一方面，当我们用样本去估计某个总体参数时，我们说由样本得到的值是统计量。参数常用希腊字母表示（如 \(\sigma\)），统计量通常用罗马字母表示（如 \(S\)）。注意，由于可以从同一个总体中抽取不止一个样本，这个统计量的值很可能因样本而异。

我们计算均值、方差等量的方式，取决于我们用的是总体中的全部元素，还是只用总体中的样本。下面两张表有助于比较这两种情况的差别：

总体（参数）
\(\bar x \approx \mu \)
参数是一个值，通常未知（因此必须估计），用来表示总体的某种特征。例如总体均值就是一个参数，常用来表示某个量的平均值。
\(N\) 是总体的总大小（比如一个国家的总人口）。
均值
\(\mu = \dfrac{\sum_{i=1}^N {x_i}}{N}\)
方差
\(\sigma^2 = \dfrac{\sum_{i=1}^N {(x_i - \mu)^2}}{N} = \dfrac{\sum_{i=1}^N x_i}{N} - \mu^2\)
样本（统计量）
\(\bar x \approx \mu \)
统计量是由一份数据样本计算出来的量。它用来给出关于对应总体中未知值的信息。例如样本中数据的平均，用来给出关于抽取该样本的那个总体来说的平均值的信息。
\(n\) 是样本的大小（比如掷硬币的次数）。
均值
\(\bar X = \dfrac{\sum_{i=1}^n x_i }{n}\)
方差
\(S_n^2 = \dfrac{\sum_{i=1}^n (x_i - \bar X)^2 }{n} = \dfrac{\sum_{i=1}^n x_i}{n} - \bar X^2\)

注意统计量的方差记作 \(S_n^2\)（下标 n 表示从总体中抽取的元素个数），以便与总体方差 \(\sigma^2\) 区分。方差的第二种写法很有用，因为从编程的角度看，你可以在从总体中抽取元素的同时计算方差（而不必等到所有样本都抽完）。既然我们已经确立了这两种情况的区别及它们之间的关系（统计量是对总体参数的估计），下面就来看一个实际的例子。为了让演示更容易，我们写了一个 C++ 程序（见下面源代码），它生成一个总体，其中元素的取值由 0 到 20 之间的整数定义（这类似于用标了数字的卡片做实验）。为了生成这个总体，我们为 [0,20] 区间内的每个取值任意取一个 1 到 50 之间的数。这个数代表总体中具有该取值（0、1、2……直到 20）的元素个数。总体的大小就是这些数之和。这个总体的参数（总体大小、总体均值与方差）汇总在下一张表里：

总体大小总体均值总体方差
572 8.970280 35.476387

程序的其余部分会对这个总体采样 1000 次，其中样本大小（为计算样本均值与样本方差而从总体中抽取的元素个数）会在 2 到 20 之间变化；这有助于我们看清采样技术在样本数少和样本数多时表现差别有多大。我们随机选一个样本大小 n，然后从总体中抽取 n 个样本，每次抽取时先随机挑出总体中的一个个体（1 到总体大小之间的任意随机数）。

我们求出这个个体所持取值的过程有点特别。我们从个体索引中逐个减去持有特定取值的个体数（先从持值为 0 的那一组开始，然后是 1，等等），一旦个体索引小于 0 就跳出这个循环。


int item_index = pick_item_distr(rng), k; 
for (k = 0; k <= MAX_NUM; ++k) { 
    item_index -= population[k]; 
    if (item_index < 0) break; 
}

跳出该循环时，代码里 k 的值就是被选中元素所持的取值。这个技巧之所以有效，是因为被抽中元素的索引是随机选取的（也就是说，选到 1 那一组里某个元素的可能性，与选到 2、3……或 20 各组里某个元素的可能性相同）。

随着元素被从总体中抽出，我们更新用于计算样本均值与样本方差的变量。这个过程结束时，我们得到（一开始）1000 个样本以及它们对应的样本均值与方差。把这些结果画出来，有助于我们对从总体中抽样的过程得出一些有意思的观察。注意图中（图 1）样本大小小的画成红色，样本大小大的画成蓝色（样本大小介于 2 与 20 之间时，颜色在红蓝之间插值）。图中的绿点标出的是总体参数（均值与方差）相重合的位置。任何靠近这一点的样本，都可以认为给出了总体均值与方差的良好估计。样本离这一点越远（无论往哪个方向），估计就越差。

如果你还是不太理解为什么图 1 里样本（或者说统计量）四处散落，想想右边那个简单情形：我们画了比如 9 个人的体重。如果我们要测总体体重的均值，会得到位于那条线中间某处的某个值（在对应图里标为总体均值）。现在设想从中抽样时，我们抽到的正是右边被红圈圈出的三个个体。如你所见，由这三个个体算出的样本均值与总体均值相差很大。再设想样本取的是被绿圈圈出的那三个个体。对这几个样本求平均，反而得到对总体均值相当好的估计。样本的集合以及它们「随机」分布的方式，代表总体中元素所有可能组合的一个子集。样本均值有多分散，取决于一些因素（我们很快就讲到），比如样本大小以及总体分布本身。

下面是用来生成图 1 中数据的程序源代码。


#include &ltrandom> 
#include &ltcstdlib> 
#include &ltcstdio> 
 
static const int MAX_NUM = 20;   //总体中元素都编了号（取值在 0 到 20 之间） 
static const int MAX_FREQ = 50;  //持有某个特定数值的元素个数在 1 到 50 之间 
 
int main(int argc, char **argv) 
{ 
    int minSampples = atoi(argv[1]);  //最小样本大小 
    int maxSampples = atoi(argv[2]);  //最大样本大小 
    std::mt19937 rng; 
    int population[MAX_NUM + 1]; 
    int popSize = 0; 
    float popMean = 0; 
    float popVar = 0; 
    static const int numSamples = 1000; 
 
    rng.seed(17); 
 
    // 创建总体
    std::uniform_int_distribution&ltuint32_t> distr(1,MAX_FREQ); 
 
    for (int i = 0; i <= MAX_NUM; ++i) { 
        population[i] = distr(rng); 
        popSize += population[i]; 
        popMean += population[i] * i;  //概率 * x_i 
        popVar += population[i] * i * i;  //概率 * x_i^2 
    } 
 
    popMean /= popSize; 
    popVar /= popSize; 
    popVar -= popMean * popMean; 
    fprintf(stderr, "size %d mean %f var %f\n", popSize, popMean, popVar); 
    std::uniform_int_distribution&ltuint32_t> n_samples_distr(minSampples, maxSampples); 
    std::uniform_int_distribution&ltuint32_t> pick_item_distr(0, popSize - 1); 
 
    float expectedValueMean = 0, varianceMean = 0; 
    // 现在我们有了数据和统计量，可以对它采样了
    for (int i = 0; i < numSamples; ++i) { 
        int n = n_samples_distr(rng);  //样本大小 
        float sample_mean = 0, sample_variance = 0; 
        // 从总体中抽取样本并计算统计量
        for (int j = 0; j < n; ++j) { 
            int item_index = pick_item_distr(rng), k; 
            for (k = 0; k <= MAX_NUM; ++k) { 
                item_index -= population[k]; 
                if (item_index < 0) break; 
 
            } 
            // k 是我们从总体中取到的数值， 
            // 它是 [0:20] 之间某个数的结果
            sample_mean += k; 
            sample_variance += k * k; 
        } 
        sample_mean /= n; 
        sample_variance /= n; 
        sample_variance -= sample_mean * sample_mean; 
 
        float c1[3] = { 1, 0, 0 }; 
        float c2[3] = { 0, 0, 1 }; 
        float t = (n - minSampples) / (float)(maxSampples - minSampples); 
        float r = c1[0] * (1 - t) + c2[0] * t; 
        float g = c1[1] * (1 - t) + c2[1] * t; 
        float b = c1[2] * (1 - t) + c2[2] * t; 
        printf("sample mean: %f sample variance: %f col: %f %f %f;\n", sample_mean, sample_variance, r, g, b); 
    } 
 
    return 0; 
}

从这张图里我们能得出什么观察？首先注意，这张图可以沿横轴（x）与纵轴（y）来读。任何靠近样本均值线（那条青色竖线）的样本，都可以认为给出了总体均值的良好估计。任何靠近总体方差线（那条青色横线）的样本，则给出总体方差的良好估计。不过，真正「好」的样本是同时靠近这两条线的样本。我们在图 1 里用一个黄色形状示意了这一点，它标出绿点周围的一簇样本，这些样本可以算作好样本，因为它们与这两个参数都足够接近（如果你对这个话题感兴趣，可以读一读置信区间）。还要注意，这一簇里大多数样本是蓝色的，但并非全部都是（仍有一小部分是红色或偏红的样本）。这告诉我们，样本越大，我们越有可能得到收敛到总体参数的估计。不过注意，我们说的是「更有可能」。我们没有说样本越大估计就越好。这正好抓住了统计学与「近似」概念之间那种差别（虽然微妙，也带点哲学意味）。在统计学里，总存在一种可能（哪怕非常小）：某个样本给出的值恰好等于总体参数。无论多么不可能，这种机会在样本大小任意大（或任意小）时都存在。然而，一个非常小的样本比一个样本大得多的样本更有可能给出偏差很大的估计，尽管样本估计更有可能收敛到总体参数。

注 1：确实，根据大数定律（我们在第 2 章介绍过），随着 n 趋于无穷，样本平均值依概率收敛、并且「几乎」必然收敛到期望值 \(\mu\)。

注意我们在前面的定义里用了「几乎」。我们无法确定它会收敛，但可以说它收敛的概率随样本增大而升高。这一切都是概率问题。图 2 显示样本的「质量」随样本大小增大而发生的变化。样本仍分布在总体均值与方差周围，但样本的簇缩小了，这确实说明估计的平均质量比图 1 里更好。换句话说，簇随 n 增大而变小（表明估计的整体质量提升），或者换个说法：随着 \(n\) 增大，统计量越来越集中到某个值附近。由此我们可以问两个问题？那个值是什么，以及随着 \(n\) 趋于无穷这些统计量会怎样？但我们在介绍大数定律时已经给出了这些问题的答案。那个值就是总体均值本身，而样本均值在 \(n\) 趋于无穷时趋近这个总体均值。记住讲期望值那一章里的这个定义：

$$ \begin{array}{l} \lim_{n \rightarrow \infty} \text{ Pr }(|\bar X - \mu| < \epsilon) = 1 \\ \bar X \rightarrow \mu. \end{array} $$

如图 3 所示，我们的程序生成的总体具有任意分布。这个总体并不服从任何特定的概率分布，尤其不服从正态分布。我们为什么这样选择，很快就会明白。因为这个分布是离散且有限的，这个总体当然有明确的均值与方差，我们上面已经算过了。现在我们要做的是从这个总体中取一个大小为 \(n\) 的样本，计算它的样本均值，并把这一实验重复 1000 次。样本均值会舍入到最接近的整数值（这样它就取 0 到 20 之间的某个整数）。过程结束时，我们统计均值为 0、1、2……直到 20 的样本各有多少个。图 4 显示了结果。非常值得注意的是，如你所见，样本的分布服从正态分布。我们这里看的不是卡片的分布，而是样本的分布。务必把这个区别看清楚。它是统计量的分布。还要注意，这并不是一个完美的正态分布（你现在能理解我们在上一章为什么对此说得那么具体了），因为显然，结果与完美的正态分布（红色曲线）之间是有差别的。总之，尽管总体的分布是任意的，样本或统计量的分布却不是（但它在分布上收敛到正态分布。这个想法我们后面还会回到）。

一位读者的提问：你凭什么说这个抽样分布不是完美的正态分布？还有，你是怎么得到那条拟合你数据的曲线的（图 4 中那条红色曲线）？我们知道正态分布由一条数学公式以及两个参数（均值与标准差）定义（见前一章）。从计算的角度说，是可以测出我们抽样分布的偏度与峰度的（但本版课程没有展示怎么做）。只要这两个参数中任何一个不为零，我们就可以确定我们的抽样分布不是完美的正态分布（这两个术语的解释见前一章）。至于第二个问题，是可以算出样本的期望值及其标准差的（下面会讲怎么做），再由这些数画出一条像图 4 里那样的曲线。记住这条曲线本身没什么意义。你关心的是样本以及它们的抽样分布。你可以把这条曲线理解为展示了抽样分布的整体集中趋势。

我们已经反复说过很多次：样本均值与样本方差本身就是随机变量（每个样本的值很可能与其他样本不同），因此像任何其他随机变量一样，我们可以研究它们的概率分布。换句话说，我们不是去研究比如某个国家（总体）里所有成年人的身高（这一属性）是如何分布的，而是从这个总体中抽样来估计总体的平均身高，再看这些样本彼此之间的分布是怎样的。在统计学里，样本（或统计量）的分布称为抽样分布。与总体分布的情形类似，抽样分布也可以用模型（即概率分布）来定义。它定义的是：对于一个给定总体以及给定大小的样本，所有可能的样本是如何分布的。

注 2：某个统计量的抽样分布，就是该统计量在取自大小为 n 的随机样本时、作为随机变量来看的分布。换句话说，均值的抽样分布就是样本均值的分布。

记住，统计量本身就是某些随机变量的函数，因此它自己也是一个随机变量。与所有其他随机变量一样，它因此也有一个分布。这个分布就是我们所说的统计量 \(\bar X\) 的抽样分布。统计量可能取哪些值、以及取这些值中各值的可能性有多大，都由该统计量的概率分布定义。

从这些定义可以得出一个重要结论：如果你知道某个统计量 \(\bar X\) 的抽样分布，那么在观测数据之前，你就能知道 \(\bar X\) 取某些值的概率或可能性有多大。

下一个概念是我们目前所用技巧的延伸。还记得第 1 章里我们学过的计算期望值的方法吗？对于离散随机变量（连续随机变量的概念相同，但用离散随机变量描述更容易），我们知道期望值或均值不过就是每个结果按其概率加权后的和。

注 3：正如总体可以用均值等参数来描述，抽样分布也可以。换句话说，我们可以把用于计算随机变量均值的那套方法，同样用到样本或统计量上。用在样本上时，所得的值叫作均值分布的期望值，可以定义为：

$\mu_{\bar X} = E(\bar X) = \sum_{i=1}^n p_i \bar X_i,$

其中 \(p_i\) 是与样本均值 \(\bar X_i\) 关联的概率，而这些概率本身是按抽样分布的规律分布的。当样本以相同概率抽出时（即均匀分布），概率就是 \(1 \over n\)，这里的 \(n\) 表示样本或统计量的个数（不是样本大小）。

由于超出本课程范围的原因，\(\mu_{\bar X} \) 不能视为与均值是同一个东西（因为当样本大小趋于无穷时这个值无定义），不过它可以被解读或看作类似的东西。这个均值分布的期望值在某种意义上可以看作有限个样本均值的加权平均。不是平均，而是加权平均，权重是每个可能结果的频率（或概率）：

$$E(\bar X) = \sum_{i=1}^n w_i \bar X_i.$$

这与前面的公式相同，只是我们把 \(p_i\) 换成了 \(w_i\)；不过在这个语境下，这两项是同义的。

可以证明，均值分布的期望值 \(\mu_{\bar X} \) 等于总体均值 \(\mu\)：\(\mu_{\bar X} = \mu\)。这个等式的证明可以在本章末尾找到（见样本均值的性质）。不过眼下我们只需说：在统计学里，当某个统计量（如 \(\mu_{\bar X}\)）的期望值等于某个总体参数时，这个统计量本身被称为该参数的无偏估计量。例如，我们可以说 \(\bar X\) 是 \(\mu\) 的无偏估计量。这个重要概念我们同样会在下一章详细回顾。我们还会在讲蒙特卡罗的那一章里说明，蒙特卡罗就是一个（无偏）估计量。

如果现在增加样本大小（即增大 \(n\)），样本就更有可能给出对总体均值的更好估计（这个结果我们已在图 2 中示意过）。并非所有样本都靠近均值，但一般来说样本越大（\(n\)），样本越靠近均值。样本分布的形状和上一种情况一样是正态分布，但如果你把图 3 与图 4 的图形对比，可以看到第二个分布比第一个更紧。随着 \(n\) 增大，你就越接近于用总体中所有元素来估计均值，所以从逻辑上说，样本均值平均而言更有可能靠近总体均值（或者换个说法：样本均值偏离总体均值的机会更低）。这个实验展示的东西与我们已在图 1 和图 2 中看到的类似（再核对一下注 1），那就是样本越大，我们在概率上就越有可能收敛到真正的均值（即总体均值）。我们可以很容易通过观察均值分布的期望值 \(\mu_{\bar X}\)（以及与之关联的标准差 \(\sigma_{\bar X}\)）随样本增大而变化的方式来实验验证这一点。我们应当预期样本均值的期望 \(\mu_{\bar X}\) 收敛到总体均值 \(\mu\)，并且正态分布（以其标准差衡量）随样本增大而不断变紧。下面是我们为计算这两个变量所做的代码改动，它们分别命名为 expectedValueDistrMeans（相当于 \(\mu_{\bar X}\)）与 varianceDistrMeans（相当于 \(\sigma_{\bar X}\)）。这个版本的代码里每个样本的样本大小相同（第 6 行），我们还提高了从总体中采样的总次数（第 4 行）以改善估计的稳健性（我们从 1000 提到 1000 个统计量或样本）：


int main(int argc, char **argv)
{
    ...
    static const int numSamples = 10000;
    ...
    float expectedValueDistrMeans = 0, varianceDistrMeans = 0;
    for (int i = 0; i < numSamples; ++i) {
        int n = atoi(argv[1]); // 固定样本大小
        float sample_mean = 0, sample_variance = 0;
        for (int j = 0; j < n; ++j) {
            ...
        }
        sample_mean /= n;
        sample_variance /= n;
        sample_variance -= sample_mean * sample_mean;
        meansCount[(int)(sample_mean)]++;
        
        expectedValueDistrMeans += sample_mean;
        varianceDistrMeans += sample_mean * sample_mean;
    }
    expectedValueDistrMeans /= numSamples;
    varianceDistrMeans /= numSamples;
    varianceDistrMeans -= expectedValueDistrMeans * expectedValueDistrMeans;
    fprintf(stderr, "Expected Value of the Mean %f Standard Deviation %f\n", expectedValueDistrMeans, sqrt(varianceDistrMeans));

    return 0;

首先，你从一个总体出发。然后你从这个总体中随机抽取元素。在这张图里，每次实验我们做 3 次观测，也就是从总体中抽 3 个个体。因为这些是随机变量，但也是实验的可能结果，我们用小写 \(x\) 来标记它们。如果现在对这 3 个抽到的个体取加权平均，就得到我们所说的统计量或样本，其大小为 \(n = 3\)。为计算这个样本的值，我们用的是期望值（或均值）的公式。每个样本本身是一个随机变量，但由于现在它们代表总体中某 n 个个体的均值，我们用大写字母 \(X\) 来标记它们。我们可以把这一实验重复 \(N\) 次，得到一串样本：\(X_1, X_2, ... X_N\)。这一批样本就是我们所说的抽样分布。由于样本是随机的，我们也可以用计算总体中个体均值的同一方法来计算它们的均值。这就是我们所说的均值分布的期望值（或均值），记作 \(\mu_{\bar X}\)。一旦有了这个值，我们就可以算出均值分布的方差 \(\sigma_{\bar X}\)。

首先，数据似乎证实了理论：随着样本大小增大，我们所有样本的均值（\(\mu_{\bar X}\)）趋近总体均值（即 8.970280）。此外，均值分布的标准差 \(\sigma_{\bar X}\) 如预期那样减小（你可以把它想象成正态分布的曲线变得更窄）。因此如前面所述，随着 \(n\) 趋于无穷，抽样分布变成一个均值为 \(\mu\)（总体均值）、标准差为 0 的完美正态分布：\(N(\mu, 0)\)。我们说随机变量序列 \(X_1, ... X_n\) 在分布上收敛到正态分布。

试着把依分布收敛这个概念与我们在讲期望值那一章谈过的依概率收敛联系起来。

这一点很重要，因为数学家喜欢有证明：最终样本均值 \(\mu_{\bar X}\) 与总体均值 \(\mu\) 是相同的，因此这个方法成立（这是从理论角度说的，因为显然在实践中，无限大的样本是不可能的）。换句话说，我们可以写（并且也用实验验证了这个结果）：

$$\mu_{\bar X} = E[\bar X] = \mu.$$

如果你对数学没那么在意，只想弄明白这对你（以及渲染领域）意味着什么，那么可以就把它理解为「你不断采样（即 \(n\) 增大）时，你的估计就越来越好」。最终你有了足够多的样本，你的估计与你试图估计的值非常接近，理论上当样本无限多时两者甚至相同。这就是它「意味着」的全部。

现在来谈一件在统计学里当然很重要、但在渲染里更重要的事（终于有点对我们有用的了）。如果你再看一遍那张表，可能已经注意到：N=2 与 N=16 时均值分布的期望值之差（8.9608 - 8.9289 = 0.0319）比 N=32 与 N=16384 时期望值之差（8.9703 - 8.9658 = 0.0045）更大。换句话说，从 32 个样本增加到 16384 个样本，估计只好了一点点（准确地说，是 0.0319/0.0045 分之一），相比从 2 个样本增加到 16 个样本而言！

当你不断增大样本大小 \(n\) 时（这个关系我们会在本章末尾证明），均值分布的方差按下面的公式减小：

$\sigma_{\bar X} = {\dfrac{\sigma}{\sqrt{n}}}.$

其中 \(\sigma\) 是总体的标准差，\(n\) 是样本大小。换句话说，均值分布的标准差（你可以把它理解为总体均值估计中的误差，事实上在统计学里，均值分布的标准差 \(\sigma_{\bar X}\) 叫作标准误）随样本数（\(\sqrt{n}\)）减小的速率是非线性的（平方根运算是一个非线性算子）。如果你愿意用大 O 记号，我们可以说收敛速率是 \(O(\sqrt{n})\)（你可以读作「算法的性能与 n 的平方根成正比」）。注意方差 \(\sigma_{\bar X}^2\)（在统计学里也叫均方误差（MSE））则随 \(n\) 线性变化，因为方差是标准差的平方。

这个关系带来的结果是：要把估计的误差减半，需要四倍的样本。

等讲到蒙特卡罗方法那一章，我们会回到这个观察。

下面这串结果有助于更好地理解「要把估计的误差减半，需要四倍的样本」。设想总体的标准差一开始是 1，你从样本大小 4 开始，于是你的标准误是 \(error = 1/\sqrt{4} = 0.5\)。现在如果你想把这个误差减小 2 倍，就需要 4 倍的样本，也就是 16 个样本。验算一下：\(error = 1/\sqrt{16}=0.25\)，正确。如果再想把这个误差减半一次，就需要 4 乘 16 个样本，即 64 个样本：\(error = 1/\sqrt{64}=0.125\)。注意处理时间随样本大小线性增长，所以样本数变成四倍，处理时间也变成四倍（假设样本数与处理时间之间是线性关系，这是个合理的假设）。这应该开始让你有直觉：为什么蒙特卡罗方法很快就会变得昂贵。你可以在图 5 中看到这个收敛速率的图示。不过从实践角度看，这意味着：哪怕只想把估计质量稍微提高一点，代价也会很快变得高得难以承受；但另一方面，这个方法只需相对较少的样本就能给出相当不错的估计。这个关系的证明会放在下一章，不过我们现在就可以用实验来检验它。我们修改了程序，让它输出由样本算出的标准误以及由公式 \(\sigma \over \sqrt{n}\) 算出的标准误，然后用不同的样本大小运行程序。

所有这些工作引向数学中所谓的中心极限定理（或称 CLT，它被认为是统计学乃至数学中最重要的概念之一，大部分抽样理论都建立在它之上）。

中心极限定理指出，均值抽样分布的均值 \(\mu_{\bar X}\) 等于总体的均值 \(\mu\)，而均值分布的标准误 \(\sigma_{\bar X}\) 等于总体的标准差 \(\sigma\) 除以 \(n\) 的平方根。此外，均值的抽样分布会趋近正态分布 \(N(\mu, {{\sigma}/{\sqrt{n}}})\)。这些关系可以归纳如下：

$$ \begin{array}{l} \mu_{\bar X} = \mu \\ \sigma_{\bar X} = \dfrac{\sigma}{\sqrt{n}}. \end{array} $$

再说一次，这个定理的强大之处在于：即使我们对总体的分布一无所知，只要有足够多的样本（并假设这些样本是独立同分布的），样本均值的分布总会趋近正态分布。

给好奇的读者：你可能会在统计学的文献里遇到「渐近分布」这个术语。这是个进阶话题，我们会放到另一门课里去讲，不过这里可以给个简短的回答：它指的是当 n 趋于无穷时，某个抽样分布所收敛到的那个函数。就样本均值而言，我们说过当 n 趋于无穷时，抽样分布在分布上收敛到均值为 \(\mu\)、标准差为 \(\sigma^2\) 除以 n 的平方根的正态分布：\(\mathcal{N}(\mu, \sigma / \sqrt{n})\)。因此这个正态分布被称为 \(X_n\) 的渐近分布。事实上，把 \(\bar X\) 减去 \(\mu\)、除以方差 \(\sigma\)，再整体乘以 \(\sqrt{n}\)，它甚至就变成了标准正态分布。我们可以说 \(\sqrt{n}(\bar X - \mu) / \sigma\) 在分布上收敛到标准正态分布 \(\mathcal{N}(0, 1)\)。

样本均值的性质

下面我们来回顾样本均值的性质：

$$\bar X = \dfrac{1}{n} (X_1 + ... + X_n),$$

尤其是给出样本均值的均值与方差的证明。首先回顾样本均值的期望值——如前所述，它等于总体均值（式 1）。

$$E[\bar X_n] = \dfrac{1}{n} \sum_{i=1}^n E[X_i] = \dfrac{1}{n} \cdot { n \mu } = \mu.$$

样本均值的期望值，无非就是构成该样本均值的所有随机变量的期望值的平均。要理解这个证明，你需要回到期望值的第一条与第二条性质（可以在这一章找到：

$$ \begin{array}{l} E[aX+b] = aE[X] + b\\E[X_1 + ... + X_n] = E[X_1] + ... + E[X_n]. \end{array} $$

由于样本均值等于：\(\bar X = \dfrac{1}{n} (X_1 + ... + X_n)\)，我们可以写成：

$$ \begin{array}{l} E[\bar X]&=&E[\dfrac{1}{n}(X_1 + ... + X_n)]\\ &=&\dfrac{1}{n}E[X_1 + ... + X_n]\\ &=&\dfrac{1}{n} \sum_{i=1}^N E[X_i]. \end{array} $$

我们还知道，按定义随机变量的期望值就是总体均值，因此可以把等式中的 \(E[X_i]\) 换成 \(\mu\)。证明的结尾是平凡的。你有 n 个 \(E[X]\) 之和，即 n 倍的总体均值。两个 n 约掉，剩下 \(\mu\)（式 1）。接下来看样本均值的方差（式 2）：

$$ \begin{array}{l} E[\bar X]&=&E[\dfrac{1}{n}(X_1 + ... + X_n)]\\ &=&\dfrac{1}{n}E[X_1 + ... + X_n]\\ &=&\dfrac{1}{n} \sum_{i=1}^N E[X_i]. \end{array} $$

这个证明需要用到方差的第二条与第三条性质（可以在这一章找到：

$$ \begin{array}{l} Var(aX + b) = a^2Var(X)\\Var(X_1+...+X_n) = Var(X_1) + ... + Var(X_n). \end{array} $$

有了这两条性质，推导很简单：

$$ \begin{array}{l} Var(\bar X)&=&Var(\dfrac{1}{n}(X_1 + ... X_n))\\ &=&\dfrac{1}{n^2 } Var(X_1 + ... X_n)\\ &=&\dfrac{1}{n^2 } \sum_{i=1}^n Var(X_i). \end{array} $$

最后，你只需把 \(Var(X)\) 换成 \(\sigma^2\)。与样本均值的均值一样，我们有 n 个，两个 n 约掉，剩下 \(\sigma^2 / n\)。最后我们可以写出，等于方差平方根的标准差为 \(\sigma / \sqrt{n}\)。注意这条性质很有意思，因为它在本质上说明样本均值的方差低于总体分布本身的方差，这也就意味着样本均值 \(\boldsymbol{ \bar X }\) 比单次观测的值 \(\boldsymbol{X_i}\) 更有可能靠近 \(\boldsymbol{ \mu }\)。

用一个实验可视化二项分布：豆子机

我们用这段精彩的视频（YouTube 上原版完整视频的链接）来结束本章，它展示的是所谓豆子机（bean machine）的模拟。豆子机（又称 quincunx 或高尔顿板）由 Francis Galton 爵士发明，用来演示中心极限定理（特别是说明正态分布是对二项分布的近似）。想法是让一颗小球沿着一块面板的正面滚下，面板上布满了等间距钉子构成的网格。球往下滚的过程中撞到钉子就向左或向右弹（随机地、相互独立地），最后落到板底一格宽的格子里。随着时间推移，各格中球堆起的高度就近似一条钟形曲线。播放视频，就能亲眼看到这个相当神奇的现象。这个实验让我们对中心极限定理有所领悟。样本均值的行为就像沿面板正面向下弹跳的球：有时弹向左，有时弹向右，但平均而言它落在中间附近，结果就是钟形。
