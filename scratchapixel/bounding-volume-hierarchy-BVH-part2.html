包围体层次结构：BVH（第 2 部分）

阅读时间：20 分钟。

论文的其余部分，重点在于改进他们的技术：把上一章介绍的包围体按层次组织起来。这项技术叫作包围体层次结构，也就是 BVH。与其他可能的加速结构相比，它通常能给出很好的结果。基于这一原理的变体有很多。本章我们来看 Kay 和 Kajiya 所使用并描述的方法。把包围体归并成更大的包围体、再把这些更大的包围体继续归并，这个想法非常简单，也很容易理解。图 2 中，我们展示了一组物体及其各自的包围体（为简单起见这里用盒子）。把这些包围盒合并起来（通常按邻近程度），就得到代表物体组的更大包围体。很容易看出：如果一条光线不与任何这些更大的组相交，我们就可以跳过对组内所包包围体的测试，从而一次排除许多物体。这显然能省下大量渲染时间。

原理非常简单，但要想高效，物体和包围体必须按邻近程度分组。如果不按邻近程度分组会有什么问题，图 3 作了说明。两只红色茶壶的包围盒被归到了一组，尽管它们彼此离得很远。在图 3 中，光线与这两个包围体都相交，于是有四只茶壶需要做与光线的求交测试。而在图 1 中，这些茶壶里只有两只（D 和 E）需要测试相交。

为了按邻近程度对物体分组，Kay 和 Kajiya 建议把它们插入一个空间划分数据结构。这种结构把空间划分成子区域，物体通常按位置被插入这些子区域。这一过程在图 3 中演示。如果我们创建一个包住场景中所有物体的盒子，就可以把这个盒子划分成八个等大的子盒（图 4 和图 5 中，这一过程以二维方式演示）。然后场景中的每个物体都可以按它们加入场景的顺序，插入与它重叠的子盒里。于是我们可以假定，某个子体素中包含的所有物体彼此都相当接近（至少比位于其他子盒中的物体更接近）。

如图 4 所示，一个物体可能同时与多个子盒或单元重叠。这种情况下，Kay 和 Kajiya 随意地把物体插入其中一个重叠的单元。我们选择插入物体包围盒质心所在的那个单元（质心在图中用每只茶壶中心的小点表示）。论文中提出了两种空间数据结构：中位数切分与八叉树。前者与你可能听说过的 k-d tree 空间划分数据结构有些关联。本课程不介绍这些结构。后者，也就是八叉树，将用于我们对 Kay 和 Kajiya 论文的实现。如前所述，它把一个立方体划分成八个单元，这些单元再继续划分，依此类推。递归过程在所有物体都插入八叉树之后停止，或者在达到用户定义的最大深度时停止。

构建层次结构

八叉树数据结构在另一门课程中有详细介绍。不过简而言之，创建和插入物体的过程如下。首先我们计算场景中所有物体的包围体，在此过程中把算出的这些包围体合并，得到场景的整体包围体。从这个整体包围体可以确定八叉树的尺寸（一个位于整体包围体中心的立方体，其边长取该包围体沿 x、y、z 轴范围中的最大值）。这个立方体代表八叉树的顶层节点，也就是它的根。随后插入物体时，我们以自顶向下的方式遍历这棵树。如果要插入物体的节点是叶节点，且该叶节点尚未包含任何物体，我们就把物体插入这个节点。如果该节点已经包含物体（并且尚未达到用户定义的最大深度），就把当前节点划分成八个单元，把节点原有的物体和新物体都插入它们各自重叠的单元（注意物体可能与不止一个单元重叠）。

这个过程一直重复，直到所有物体都插入八叉树。第二步，这次以自底向上的方式遍历八叉树。我们从叶节点开始，计算它们所含物体的整体包围盒（一个叶节点可以有一个或多个物体）。叶节点之上的那个节点，其整体包围盒则由它的子节点的包围体合并得到。这个过程一直重复到根节点（此时它应当与我们先前算出的整个场景范围一致）。这两个过程结束后，我们得到场景的一种表示：包围体层次结构，其中的包围体按邻近程度分组（某个节点叶节点中包含的物体被归到一起，等等）。注意，八叉树在这里其实并没有被当作加速结构使用（不要把这项技术与用作加速结构的八叉树混淆——我们以后会专门写一门课讲那种技术）。八叉树对光线求交测试其实没有真正的好处，它只是用来计算并构建这套包围体层次结构。 ## 与层次结构求交

BVH 的求交相当简单。我们从根节点开始，测试光线是否与该节点的包围体相交。一般来说，如果某个节点的包围体被光线相交，我们就往树下一层，测试与该节点各个子节点包围体的相交。如果该节点是叶节点，就测试光线是否与它包含的任一物体相交。这个做法实现起来很简单，但还可以进一步优化。当我们测试光线与某节点各子节点包围体的相交时，假定不止一个这类单元的包围体被相交，我们应当先探查相交距离最小的那个子节点，因为可见物体最可能就包含在这些单元里。图 6 说明了这个想法（我们把光线与某单元包围体的相交，用光线与单元边界的交点处的一个点来表示。请记住现实中我们是与单元的包围体相交，图中用球体表示，而不是与单元本身相交）。如你所见，光线与根节点（黑色）相交，于是要测试根节点的子节点（红色）。这些单元按它们被创建的顺序测试：0、1、2、3。光线与单元 0 和单元 1 的包围体相交，因此接下来测试这两个节点的子节点。问题在于，尽管与单元 1 的包围体的相交距离（\(t_1\)）小于与单元 0 的包围体的相交距离（\(t_0\)），单元 0 的子节点却会先于单元 1 的子节点被测试。先测单元 1 的子节点会更高效，因为这样能更早找到与茶壶 A 的相交。Kay 和 Kajiya 建议使用一个列表：把被光线穿透的节点子节点插入其中，并按相交距离排序（从小到大）。然后我们从这个列表中取出第一个节点，测试它的子节点。如果其中某些子节点被光线相交，它们自己也会被插入列表。它们会插到列表中已有元素的前面，因为它们的相交距离必然小于已插入的任何节点的相交距离。

在编程中，这类列表叫作优先队列。它们像普通队列，只是每个元素都带一个「优先级」。在优先队列中，优先级高的元素先被取出；如果两个元素优先级相同，则按它们在队列中的顺序取出。在我们的具体情形里，用与包围体的相交距离来定义队列中各包围体的优先级：相交距离最小的包围体就是队列中优先级最高的元素。在 C++ 中我们可以使用 priority_queue 类，它属于 C++ 标准库 STL（更多细节见源代码一节）。

按这个过程，我们就能确保总是先测试层次结构中离光线起点最近的节点。如果这些节点都不包含可见物体，我们就继续测试离光线起点更远的节点，如此反复，直到列表为空。


while (priority_queue is not empty) {

还有最后一个细节需要注意。看图 7 你会发现，我们不能用与包围体的相交距离来确定哪些包围体包含可见物体。尽管到 B 的包围体的距离 \(t_{VB}\) 小于到 C 的包围体的距离 \(t_{VC}\)，光线最终相交的物体却是 C 而不是 B。我们只能确定一点：当与已相交物体的距离小于与列表中下一个节点包围体的相交距离时，就可以停止层次结构的遍历。如图 7 所示，优先列表中的节点顺序应当是 VB、VC、VA（因为 \(t_{VB}\) < \(t_{VC}\) < \(t_{VA}\)）。当我们与 VB（B 的包围体）所包含的物体求交时，得到物体 B 的相交距离 \(t_B\)。但 \(t_B\) 并不小于 \(t_{VC}\)，因此我们还要测试与物体 C 的相交，结果发现 \(t_C\) 小于 \(t_B\)，于是 C 取代 B 成为潜在的相交物体。但由于 \(t_C\) 小于 \(t_{VA}\)，我们既不需要测试与 A 的相交，也不需要测试列表中 VA 之后可能存在的任何节点。因此我们可以停止层次遍历，返回 B 作为可见物体。如果在光线追踪器里用上所有这些技术，我们现在得到如下结果：

源代码

完整源代码在本课程的最后一章。

BVH 类变得更复杂了。我们给这个类加了一个 OctreeNode 和一个 Octree 类。想了解八叉树的读者可以参阅后面几节，那里有专门讲这个主题的课程。八叉树节点持有八个指向其他八叉树节点的指针，也就是它的子节点。构造函数把场景范围作为输入参数（第 38 行）。这个范围用来计算并设置根节点的尺寸与位置（它的质心，第 40-49 行）。新物体（更准确地说是它们的包围体，但请记住 Extents 类持有指向被包围物体的指针）从根节点开始插入（第 52-53 行）。如果当前节点是空的叶节点（还没有物体插入过这个叶节点），我们就把物体插入这个叶节点并返回。如果节点是叶节点，已包含一个或多个物体，但我们已经达到八叉树的最大深度，那么我们仍然把物体插入这个节点（第 73 行）。而如果还没达到最大深度，我们就把该节点标记为「内部」，并把节点原先持有的物体和新物体一起重新插入八叉树（第 77-82 行）。如果节点不是叶节点，我们检查物体应当插入该节点的哪个子节点（第 86-93 行）。如果该子节点还不存在就创建它（第 97-98 行），最后把物体插入这个子节点（第 99 行）。构建包围体层次结构的函数很简单。我们从根开始，沿树往下直到叶节点。这个节点的包围体由它持有指针的所有物体的包围体合并得到。然后我们在往回走的过程中，用其子节点的包围体合并得到当前节点的包围体（第 130 行）。


class BVH : public AccelerationStructure
{
    static const uint8_t kNumPlaneSetNormals = 7;
    static const Vec3f planeSetNormals[kNumPlaneSetNormals];
    struct Extents
    {
        Extents()
        {
            for (uint8_t i = 0; i < kNumPlaneSetNormals; ++i)
                d[i][0] = kInfinity, d[i][1] = -kInfinity;
        }
        void extendBy(const Extents &extents)
        {
            for (uint8_t i = 0; i < kNumPlaneSetNormals; ++i) {
                if (extents.d[i][0] < d[i][0]) d[i][0] = extents.d[i][0];
                if (extents.d[i][1] > d[i][1]) d[i][1] = extents.d[i][1];
            }
        }
        bool intersect(
            const float *precomputedNumerator, const float *precomputeDenominator, 
            float &tNear, float &tFar, uint8_t &planeIndex);
        float d[kNumPlaneSetNormals][2]; // 每一组平面法线对应的 d 值
        const Object *object; // 该包围体所包含的指针（供八叉树使用）
    };
    Extents *extents;
    struct OctreeNode
    {
        OctreeNode *child[8];
        std::vector&ltconst Extents *> data;
        Extents extents;
        bool isLeaf;
        uint8_t depth; // 仅用于调试
        OctreeNode() : isLeaf(true) { memset(child, 0x0, sizeof(OctreeNode *) * 8); }
        ~OctreeNode() { for (uint8_t i = 0; i < 8; ++i) if (child[i] != NULL) delete child[i]; }
    };
    struct Octree
    {
        Octree(const Extents &extents) : root(NULL)
        {
            float xdiff = extents.d[0][1] - extents.d[0][0];
            float ydiff = extents.d[1][1] - extents.d[1][0];
            float zdiff = extents.d[2][1] - extents.d[2][0];
            float dim = std::max(xdiff, std::max(ydiff, zdiff));
            Vec3f centroid(
                (extents.d[0][0] + extents.d[0][1]),
                (extents.d[1][0] + extents.d[1][1]),
                (extents.d[2][0] + extents.d[2][1]));
            bounds[0] = (Vec3f(centroid) - Vec3f(dim)) * 0.5f;
            bounds[1] = (Vec3f(centroid) + Vec3f(dim)) * 0.5f;
            root = new OctreeNode;
        }
        void insert(const Extents *extents)
        { insert(root, extents, bounds[0], bounds[1], 0); }
        void build()
        { build(root, bounds[0], bounds[1]); }
        ~Octree() { delete root; }
        struct QueueElement
        {
            const OctreeNode *node; // 树中由该节点持有的八叉树节点
            float t; // 用作键值
            QueueElement(const OctreeNode *n, float thit) : node(n), t(thit) {}
            // 比较符用 > 而不是 <，这样 priority_queue 的行为就像最小堆
            friend bool operator < (const QueueElement &a, const QueueElement &b) { return a.t > b.t; }
        };
        Vec3f bounds[2];
        OctreeNode *root;
    private:
        void insert(
            OctreeNode *node, const Extents *extents, 
            Vec3f boundMin, Vec3f boundMax, int depth)
        {
            if (node-&gtisLeaf) {
                if (node-&gtdata.size() == 0 || depth == 16) {
                    node-&gtdata.push_back(extents);
                }
                else {
                    node-&gtisLeaf = false;
                    while (node-&gtdata.size()) {
                        insert(node, node-&gtdata.back(), boundMin, boundMax, depth);
                        node-&gtdata.pop_back();
                    }
                    insert(node, extents, boundMin, boundMax, depth);
                }
            } else {
                // 把包围体插入正确的八叉树单元
                Vec3f extentsCentroid = (
                    Vec3f(extents-&gtd[0][0], extents-&gtd[1][0], extents-&gtd[2][0]) +
                    Vec3f(extents-&gtd[0][1], extents-&gtd[1][1], extents-&gtd[2][1])) * 0.5;
                Vec3f nodeCentroid = (boundMax + boundMin) * 0.5f;
                uint8_t childIndex = 0;
                if (extentsCentroid[0] > nodeCentroid[0]) childIndex += 4;
                if (extentsCentroid[1] > nodeCentroid[1]) childIndex += 2;
                if (extentsCentroid[2] > nodeCentroid[2]) childIndex += 1;
                Vec3f childBoundMin, childBoundMax;
                Vec3f boundCentroid = (boundMin + boundMax) * 0.5;
                computeChildBound(childIndex, boundCentroid, boundMin, boundMax, childBoundMin, childBoundMax);
                if (node-&gtchild[childIndex] == NULL)
                      node-&gtchild[childIndex] = new OctreeNode, node-&gtchild[childIndex]-&gtdepth = depth;
                insert(node-&gtchild[childIndex], extents, childBoundMin, childBoundMax, depth + 1);
            }
        }
        void computeChildBound(
            const uint8_t &i, const Vec3f &boundCentroid,
            const Vec3f &boundMin, const Vec3f &boundMax,
            Vec3f &pMin, Vec3f &pMax) const
        {
            pMin[0] = (i & 4) ? boundCentroid[0] : boundMin[0];
            pMax[0] = (i & 4) ? boundMax[0] : boundCentroid[0];
            pMin[1] = (i & 2) ? boundCentroid[1] : boundMin[1];
            pMax[1] = (i & 2) ? boundMax[1] : boundCentroid[1];
            pMin[2] = (i & 1) ? boundCentroid[2] : boundMin[2];
            pMax[2] = (i & 1) ? boundMax[2] : boundCentroid[2];    
        }
        // 自底向上构建
        void build(OctreeNode *node, const Vec3f &boundMin, const Vec3f &boundMax)
        {
            if (node-&gtisLeaf) {
                // 计算叶节点的包围体
                for (uint32_t i = 0; i < node-&gtdata.size(); ++i) {
                    node-&gtextents.extendBy(*node-&gtdata[i]);
                }
            }
            else {
                for (uint8_t i = 0; i < 8; ++i)
                    if (node-&gtchild[i]) {
                        Vec3f childBoundMin, childBoundMax;
                        Vec3f boundCentroid = (boundMin + boundMax) * 0.5;
                        computeChildBound(i, boundCentroid, boundMin, boundMax, childBoundMin, childBoundMax);
                        build(node-&gtchild[i], childBoundMin, childBoundMax);
                        node-&gtextents.extendBy(node-&gtchild[i]-&gtextents);
                    }
                }
            }
        }
    };
    Octree *octree;
public:
    BVH(const RenderContext *rcx);
    const Object* intersect(const Ray&ltfloat> &ray, IsectData &isectData) const;
    ~BVH();
};

在 BVH 类的 intersect 方法里（第 37 行），我们首先测试光线是否与整个场景的包围体（八叉树根节点的范围）相交。如果相交，就用这个节点以及光线起点到其包围体的相交距离初始化一个 priority_queue 列表。我们重载了 operator <（上面第 63 行），让它表现得像最小堆（默认行为是最大堆，键值最大的元素优先级最高，而我们想要的正好相反）。其余代码与上面给出的伪代码类似。我们取出列表顶部的第一个节点（同时把它从列表中移除，第 72-73 行）。如果这个节点是叶节点，就测试光线是否与节点包含的任一物体相交，并记录最小的相交距离（第 79 行）。如果它是内部节点，就测试光线是否与该节点各子节点的包围体相交，一旦相交就把子节点加入列表（用相交距离作为键来设定元素在列表中的优先级，第 93 行）。这个过程反复进行直到列表为空，但也可以提前停止：只要列表中第一个节点的相交距离大于到已相交物体的距离（第 71 行）。


BVH::BVH(const RenderContext *rcx) : AccelerationStructure(rcx), extents(NULL), octree(NULL) 
{ 
    Extents sceneExtents; 
    extents = new Extents[rcx-&gtobjects.size()]; 
    for (uint32_t i = 0; i < rcx-&gtobjects.size(); ++i) { 
        for (uint8_t j = 0; j < kNumPlaneSetNormals; ++j) { 
            rcx-&gtobjects[i]-&gtcomputeBounds(planeSetNormals[j], extents[i].d[j][0], extents[i].d[j][1]); 
        } 
        extents[i].object = rcx-&gtobjects[i]; 
        sceneExtents.extendBy(extents[i]); 
    } 
    // 创建层次结构                                                                                                                                                                                     
    octree = new Octree(sceneExtents); 
    for (uint32_t i = 0; i < rcx-&gtobjects.size(); ++i) { 
        octree-&gtinsert(extents + i); 
    } 
    octree-&gtbuild(); 
} 
 
inline bool BVH::Extents::intersect( 
    const float *precomputedNumerator, const float *precomputeDenominator, 
    float &tNear, float &tFar, uint8_t &planeIndex) 
{ 
    __sync_fetch_and_add(&numRayVolumeTests, 1); 
    for (uint8_t i = 0; i < kNumPlaneSetNormals; ++i) { 
        float tn = (d[i][0] - precomputedNumerator[i]) / precomputeDenominator[i]; 
        float tf = (d[i][1] - precomputedNumerator[i]) / precomputeDenominator[i]; 
        if (precomputeDenominator[i] < 0) std::swap(tn, tf); 
        if (tn > tNear) tNear = tn, planeIndex = i; 
        if (tf < tFar) tFar = tf;

    } 

    return true; 
}

正常情况下，我们插入 BVH 的应当是三角形而不是网格。为了尽快完成基础部分，我们会在本课程将来的版本里说明怎么做到这一点。不过下一章我们会演示如何把三角形插入网格加速结构。作为练习，你可以仿照网格的实现，试着修改本课程中 BVH 的代码，让它支持三角形的插入。

接下来是什么？

Kay 和 Kajiya 的技术在茶壶场景上效果很好。总体而言 BVH 方法表现良好，有时在生产渲染器中被选作所支持的加速结构（通常与另一种结构配合使用，原因会在下一章末尾变得清楚）。思路是把这些模型以某种方式拆成更小的片段，插入简单三维网格的体素里。我们会在下一章说明，对网格做光线追踪既简单又快。
