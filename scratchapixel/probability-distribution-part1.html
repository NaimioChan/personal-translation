阅读时间：11 分钟。

概率分布

概率分布这个概念非常重要（并在重要性采样方法中起核心作用）。我们之所以在本章而不是更晚介绍它，是因为你应当给这个概念与随机变量的概念同等的重视，实际上应当把它们看作一个整体的两部分（或者至少是相互关联的）。回想上一章我们如何提到随机变量是某种把结果映射到实数值的函数，同时也提到概率如何与这些结果相关联。对一枚骰子或一枚硬币来说，各个结果出现的可能性相同（结果可以是 1 到 6 之间的任何数字，或者是正面或反面），因此我们在这个情形下已经说明：与每个结果相关联的概率是 \(1\over n\)，其中 \(n\) 是可能结果的总数（骰子是 6，硬币是 2）。既然每个结果都有一个关联概率（你可以把它看作一组「结果—对应概率」的配对），我们就可以把这些概率值与可能的结果值画成图。在统计学中，这就是我们所说的概率分布。后面我们会给出更正式的定义，不过先研究几个例子。

例 1

这些概率分布相当无趣，因为实验中每个可能结果的概率都一样。不过当实验各结果有不同概率时，概率分布看起来就有意思多了。我们来研究一个这样的分布例子。回想上一章描述的那个实验：我们有 10 张卡片，其中 3 张标着数字 0，5 张标着数字 1，2 张标着数字 2。如果你把这些卡片放进盒子里、摇一摇盒子等等，你会（希望如此）同意盒子里每张卡片被随机抽到的可能性相同。如果我们把样本看作 \(S = \{0, 0, 0, 1, 1, 1, 1, 1, 2, 2\}\)（这个集合里顺序无关，数字完全可以用另一种顺序排列），那么这个集合中每个结果都有关联概率 \(1\over 10\)。在概率论中，当我们考虑得到这个结果或那个结果的概率时，得到这两个结果中任一个的概率是它们概率之和（我们会在下一章研究概率的性质）。这称为加法法则。换句话说，如果你想知道掷一枚骰子时得到 2 或 5 的概率，这个概率就是得到 2 的概率（我们知道是 \(1\over 6\)）加上得到 5 的概率（同样是 \(1\over 6\)），即 \(2 \over 6\)。用到我们的卡片例子上，得到标着 0 的卡片的概率，是集合中标着 0 的每张卡片概率之和；得到标着 1 的卡片的概率，是集合中标着 1 的每张卡片概率之和，依此类推。如果我们把样本空间归约为基本事件的空间，就得到 \(S = \{0, 1, 2\}\)，而得到 0、1 或 2 的概率分别是 \(3 \over 10\)、\(5 \over 10\) 和 \(2\over 10\)。现在把这些概率作为结果的函数画出来，就得到下面这张更有意思的图：

注意，与其他函数相反，这里每个「结果—概率」配对对应的点并不相连，因为在这些特定情形下我们处理的是离散随机变量。对连续随机变量而言，概率分布函数表示为一条曲线（这个话题在下一门课程里再细说）。希望借助这个例子，你开始明白这个函数的含义了。它定义或描述了概率在一个实验的样本空间上的分布。作用在离散随机变量上时，这个函数叫作概率质量函数（或 pmf）。最后给出概率分布更正式的定义。

在概率论与统计学中，概率分布给随机实验每种可能结果的可测子集指派一个概率。这个分布可以是离散的，也可以是连续的。离散分布可以用它的概率（分布）函数来刻画，该函数指明随机变量取各个不同可能值的概率。

在进入下一个例子之前，注意所有概率之和等于 1。我们确实会在下一章说明这是概率的一条性质。概率永远不会大于 1，而一个实验的各概率之和为 1。

例 2

在概率论中，当某个随机过程只有两个结果时（比如「正面」或「反面」、「成功」或「失败」），我们就称之为伯努利（或二项）试验。在硬币实验中，这两个结果以相同概率出现（\(\scriptsize p = {1 \over 2 }\)），但在更一般的情形下，我们说它们以概率 p 和 1 - p 出现（概率之和为 1）。但比如说，如果我把硬币掷 6 次，得到 4 次正面的概率是多少？注意这个实验（掷 6 次并数正面次数）的可能结果现在可以是 0、1、2、3、4、5 或 6。首先，如果你现在考虑一个实验：从伯努利试验的概率分布中抽取 \(n\) 个随机样本，其中每个样本可以取值 0 或 1，那么这 \ (N\) 个样本之和可以写成：

$$S = \sum_{i=1}^N x_i$$

假设我们想求 \(S = n\) 的概率，其中 \(n \leq N\)，也就是 \(N\) 个样本中有 \(n\) 个取值为 1、而 \(N- n \) 个样本取值为 0 的概率。在数学中，这个离散（因为 \(n\) 取离散值）概率分布叫作二项分布，可以用下面的方程解析地计算：

$$Pr(S = n) = C_n^N p^k(1-p)^{(N-n)}$$

其中 n = 0, 1, 2, ..., N，而：

$$C_n^N = {{N!}\over{n!(N-n)!}}.$$

表达式 \(x!\) 叫作 x 的阶乘。它等于所有小于或等于 x 的正整数的乘积。例如：\(\scriptsize 5! = 5 * 4 * 3 * 2  * 1 = 120\)。项 \(C_n^N\) 统计的是 \(N\) 个样本中有 \(n\) 个取值为 1 的方式数。在公平硬币的情形下，概率 p 等于 \(1\over 2\)。在我们的例子里，我们把硬币掷 6 次，因此 n=6，而 k 可以取 0 到 6 之间的任何值。例如，若令 k=3，二项分布会给出我们掷 6 次硬币得到 3 次正面的概率。我们可以写一个小 C++ 程序来计算 k 取 0 到 6 之间每个值时对应的所有概率：


#include &ltrandom> 
#include &ltcstdlib> 
#include &ltcstdio> 
#include &ltiostream> 
 
inline uint64_t fact(uint64_t x) { 
  return (x <= 1 ? 1 : x * fact(x - 1)); 
} 
 
int main(int argc, char **argv) 
{ 
    uint64_t N = atoi(argv[1]); 
    uint64_t Nfac = fact(N); 
    for (uint64_t n = 0; n <= N; ++n) { 
        uint64_t CnN = Nfac / (fact(n) * fact(N-n)); 
        double prob = CnN * powf(0.5, n) * powf(1 - 0.5, N - n); 
        std::cout << n << " " << prob << std::endl; 
    } 
 
    return 0; 
}

我们把结果画成图 1 中的曲线。得到的数字可以看作得到某个随机变量的频率。例如第一列给出掷 6 次后得到 0 次正面的频率（该概率为 0.015625）。第二列给出掷 6 次后得到 1 次正面的概率（0.093750），等等。另一种看法是：有 1.5% 的时候你会得到 0 次正面，9.3% 的时候你会得到 1 次正面，23% 的时候你会有 2 次正面，31% 的时候你会得到 3 次正面，等等。

我们研究这个例子的原因，是要说明在例 1 中我们很容易手工算出随机分布的概率分布（因为实验足够简单），但对一些更复杂或更典型的情形，这个概率分布可以用数学方程计算（方程的参数就是实验的参数，比如何时要掷多少次硬币、伯努利试验中取得「成功」的概率是多少，等等）。而正如任何其他数学方程一样，改变这些参数确实会改变概率分布的「形状」。看看下面这三张图，它们都是用二项分布方程、取不同参数 \(N\) 值画出来的：

这里的概率数值并不那么重要。你读不清那些数字也没关系，我们只希望你理解：随着方程参数改变，分布的整体形状会变。仅看这些分布本身我们还能说更多（例如它们关于中心值对称，当 N 分别设为 6、12、20 时中心值是 3、6、10 等等），不过这些观察先放一边，把重点留在：有些概率分布可以用数学方程定义，而改变这些方程参数的取值就能改变它们的形状。我们举了二项分布的例子，那么用方程还能定义多少种分布呢？有不少，但关于这一点大概最值得说的是：自然界中有些概率分布非常常见，而其中最常见、最有用的之一叫作正态分布或高斯分布。正态分布与二项分布非常相似，只不过二项分布适用于离散随机变量，正态分布适用于连续随机变量。本章我们不给出正态分布的方程，因为它用到两个我们尚未介绍的参数——均值和标准差（想看方程请参见概率分布：第 2 部分）。不过这些概念会在下一章解释。现在我们先展示正态分布长什么样：

另一个我们已经借骰子和硬币的例子接触过的基本概率分布叫作离散均匀分布（它的连续对应物叫连续均匀分布）。这个分布适用于每个可能结果出现可能性都相同的任何实验，且这 \(n\) 个结果每一个的概率都是 \(1\over n\)。若样本空间中指派给每个结果 \(s_1, s_2, ..., s_n\) 的概率是 \(1\over n\)，则该样本空间称为简单样本空间。计算机图形学中另一个常见的概率分布是泊松分布，不过现在不用太在意它。等讲到采样的课程时我们还会再遇到这个名字。概率分布的一览表可以在这里找到。
