计算贝塞尔曲面的法线

阅读时间：7 分钟。

我们已经学了几种构造贝塞尔曲面片的技术，但还剩一个问题：得给这个曲面片着色。生成点的位置这件事我们已经会做，着色用得上，但还需要法线。怎么在网格每个顶点的位置上生成法线？我们可以用与 TriangleMesh 类里 getSurfaceProperties 方法类似的技术，轻松算出一个面法线：对一个面构成的两条边做叉积。但这项技术只能给出面法线。


// 面法线
const Vec3f &v0 = P[k]; 
const Vec3f &v1 = P[k+1]; 
const Vec3f &v2 = P[k+3]; 
faceNormal = (v1 - v0).crossProduct(v2 - v0);

我们要的是顶点法线，即构成网格的每个点处、垂直于贝塞尔曲面的法线。所幸网格是由方程算出来的，所以我们同样可以用数学在贝塞尔曲面片的任意一点上算出准确的法线。要做的是在关注点（它在曲面片上的坐标由 \(u\) 和 \(v\) 给出）上算出两条切线，一条沿 \(u\) 方向，一条沿 \(v\) 方向。把这两条切线做叉积，就得到我们要的法线。现在的问题是，这两条切线怎么算？如前面所提示的，可以把这个问题用数学语言表达出来。数学上，由函数算出的曲线切线，可以定义为该函数对某个参数的导数，例如：

$$\dfrac{\partial}{\partial x}f(x),$$

就表示函数 \(f(x)\) 对参数 \(x\) 的导数。对计算贝塞尔曲面片上点的公式，我们也可以照做。例如可以算该函数（或方程）对参数 \(u\) 或 \(v\) 的导数：

$$\dfrac{\partial}{\partial u}B(u,v), \dfrac{\partial}{\partial v}B(u,v).$$

第一个公式给出沿 \(u\) 方向的切线，第二个给出沿 \(v\) 方向的切线。现在我们知道函数 \(B(u,v)\) 本身可以写成：

$$B(u,v) = \sum_i\sum_j b_i(u) b_j(v) p_{ij}.$$

其中 \(b_i(u)\) 与 \(b_j(v)\) 是伯恩斯坦多项式，\(p_{ij}\) 是控制点。我们也知道伯恩斯坦多项式怎么算：

$$ \begin{array}{l} k_1(t) = (1 - t)^3\\ k_2(t) = 3t(1 - t)^2\\ k_3(t) = t^23(1 - t)\\ k_4(t) = t^3 \end{array} $$

所以只需算出这些函数的导数，它们是：

$$ \begin{array}{l} k'_1(t) = -3(1-t)^2\\ k'_2(t) = 3(1-t)^2-6t(1-t)\\ k'_3(t) = 6t(1-t)-3t^2\\ k'_4(t) = 3t^2 \end{array} $$

像 \((x^2+3)^3\) 这样的复合函数的导数，可以用所谓的链式法则来算。

$$\dfrac{d}{dx}y = \dfrac{d}{du}y \dfrac{d}{dx}u.$$

你需要：

  • 认出 \(u\)（总是先挑最内层的表达式，通常是括号内或根号下的那部分）

  • 然后用 \(u\) 把 \(y\) 重新表达出来

  • 接着把 \(y\) 对 \(u\) 求导，再把所有东西用 \(x\) 重新表达

  • 下一步是求出 \(\dfrac{d}{dx}u\)

  • 再把 \(\dfrac{d}{du}y\) 与 \(\dfrac{d}{dx}u\) 相乘。

在我们的例子里，令 \(u = x^2 + 3\)，于是 \(y = u^3\)。可以看到 \(u\) 是 \(x\) 的函数，\(y\) 是 \(u\) 的函数。用链式法则，首先要求出 \(\dfrac{d}{du}y\) 与 \(\dfrac{d}{dx}u\)。

$$\dfrac{d}{du}y = 3u^2 = 3(x^2 + 3)^2,$$

以及：

$$\dfrac{d}{dx}u = 2x.$$

于是：

$$\dfrac{d}{dx}y=\dfrac{d}{du}y \dfrac{d}{dx}u=3(x^2 + 3)^2(2x)=6x(x^2+3).$$

照这几步走，很容易求出我们那些公式的导数。

如果把公式 \(B(u,v) = \sum_i\sum_j b_i(u) b_j(v) p_{ij}\) 对 \(u\) 求导，就得到（这会给出参数对 \((u,v)\) 时曲面片上沿 \(u\) 方向的切线）：

$$ \begin{array}{l} \dfrac{\partial}{\partial u}B(u,v) =&-3(1-u)^2 \sum_j b_j(v) p_{0j}\\ &3(1-u)^2-6u(1-u) \sum_j b_j(v) p_{1j}\\ &6u(1-u)-3u^2 \sum_j b_j(v) p_{1j}\\ &3u^2 \sum_j b_j(v) p_{3j} \end{array} $$

这里的做法是算出沿 \(u\) 方向的一条贝塞尔曲线，然后有了这条曲线之后，用 \(k'_1(u)\)、\(k'_2(u)\)、\(k'_3(u)\) 与 \(k'_4(u)\) 沿它求导。要求沿 \(v\) 方向的切线也可以照做：

$$ \begin{array}{l} \dfrac{\partial}{\partial v}B(u,v) =&-3(1-v)^2 \sum_i b_i(u) p_{i0}\\ &3(1-v)^2-6v(1-v) \sum_i b_i(u) p_{i1}\\ &6v(1-v)-3v^2 \sum_i b_i(u) p_{i2}\\ &3v^2 \sum_i b_i(u) p_{i3} \end{array} $$

大功告成！剩下要做的，就是计算这两个公式，得到参数坐标 \((u,v)\) 处的两条切线，再把这两条切线做叉积，得到该点处的法线。这项技术的实现在下面。我们有两个函数：dUBezier 算沿 \(u\) 方向的切线，dVBezier 算沿 \(v\) 方向的另一条切线。结果令人意外。从旁边的图可以看到，结果不仅非常光滑，而且曲面片边界处的过渡完全看不出来。数学又一次表现出色，给出了完美的结果，连曲面片的边缘和角上也是如此。


Vec3f dUBezier(const Vec3f *controlPoints, const float &u, const float &v) 
{ 
   Vec3f P[4]; 
   Vec3f vCurve[4]; 
   for (int i = 0; i < 4; ++i) { 
       P[0] = controlPoints[i]; 
       P[1] = controlPoints[4 + i]; 
       P[2] = controlPoints[8 + i]; 
       P[3] = controlPoints[12 + i]; 
       vCurve[i] = evalBezierCurve(P, v); 
   } 
 
   return -3 * (1 - u) * (1 - u) * vCurve[0] + 
       (3 * (1 - u) * (1 - u) - 6 * u * (1 - u)) * vCurve[1] + 
       (6 * u * (1 - u) - 3 * u * u) * vCurve[2] + 
       3 * u * u * vCurve[3]; 
} 
 
Vec3f dVBezier(const Vec3f *controlPoints, const float &u, const float &v) 
{ 
   Vec3f uCurve[4]; 
   for (int i = 0; i < 4; ++i) { 
       uCurve[i] = evalBezierCurve(controlPoints + 4 * i, u); 
   } 
 
   return -3 * (1 - v) * (1 - v) * uCurve[0] + 
       (3 * (1 - v) * (1 - v) - 6 * v * (1 - v)) * uCurve[1] + 
       (6 * v * (1 - v) - 3 * v * v) * uCurve[2] + 
       3 * v * v * uCurve[3]; 
}
