面光源：数学基础

阅读时间：56 分钟。

请先阅读：一句提醒

面光源的实现比点光源、太阳光和聚光灯都复杂。对没有经历过计算机图形学早期阶段的人来说，它们今天也许显得无处不在，但事情并非一直如此。与主要基于阴影贴图的其他方法相比，光线追踪能对面光源的贡献给出更「精确」的评估。但反过来，光线追踪天生就慢。正如 Kajiya 曾说过的：不是光线追踪慢，是计算机慢。自 Kajiya 那个年代以来算力已大幅进步，光线追踪依然计算密集，但如今的机器能在合理时间内完成这项任务，这也促成了它近年来在生产中的广泛采用。

然而，尽管如今最好的计算机性能让基于光线追踪的渲染得以普及，评估面光源对三维场景照明的贡献所涉及的数学，也比点光源或聚光灯的数学更复杂。因此，为了给你一个它如何工作的概览，我们需要覆盖多得多的材料。从这里开始涉及的概念，可能需要很长、有时很复杂的解释；而本课只是入门课，所以我们面临一个很有挑战的练习：既要给出足够的信息，又不能过长、过于技术化，也不能只是重复那些已把这些概念讲透的课程。我们先在此致歉，但正如我所说，这是一件难做的事，而且 Scratchapixel 的课程经常互相重叠。我们的学习方法一般是：即使某项技术本身有专门的课程，也会在本课的语境里再解释一遍。事情就是这样。理想情况下，每门课都应尽可能独立于其他课程运作。所以，请记住这一点，在读下面几章时尽量保持投入。

说实话，我们认为本课是这个主题上现有的最好的资料之一，尤其是对不太熟悉本课所讲数学概念的读者而言。我们照惯例尽量用简单的词、清晰的例子来讲，并把推导拆成尽可能多的步骤。所以，尽管这看起来要费很大力气，我真心认为这份辛苦值得，尤其考虑到你很难在别处找到解释和图示都这么到位的内容。「一切伟大的成就都需要时间。」

为什么面光源才是理想之选？

由于简单、计算成本相对较低（与光线追踪的面光源相比，甚至与本身就有严重局限的阴影贴图技术相比），定点光源在生产中仍被广泛使用，尤其是在电子游戏里。但它们在概念上天生带有缺陷，无法准确再现真实世界的光照场景。我们来梳理这些局限，以便更好地理解为什么只要有可能就该用面光源。

如前所述，定点光源的内在缺陷在于没有尺寸，这会引出一系列问题。两个主要问题是：

  • 定点光源的反射在物理上不真实：我们之所以「看见」物体，是因为光从被其他光源照亮的物体上反射过来（间接光照），或者直接从光源反射过来（直接光照）。场景中的物体有尺寸，所以模拟它们在其他表面上的反射一般很直接。但间接的镜面反射或漫反射，只有在计算机足够强大、能在合理时间内（从几分钟到几小时不等）处理时，才变得可行。关于这些技术的更多细节，尤其是漫反射，见课程 全局光照与路径追踪。但光源如果没有尺寸，它又怎么能反射到表面上呢？

    在旁边的图中，你可以看到三盏面光源在一个平面上的反射，反射的大小与光源在场景中作为三维物体（本例中是一个简单的圆盘）的尺寸成正比。图的左侧所用的是点光源。虽然该光源的反射在平面上可见，但这个反射的大小与物理现实不符。这盏光源的镜面反射之所以可见，原因见课程 着色器与 BRDF 简介。于是，虽然我们看到了反射，它却缺乏物理真实感，大小也无法控制，当目标是要生成模拟现实的图像时，这就成了难题。

  • 定点光源按设计不会产生软阴影：下面的视频演示了面光源的尺寸如何影响光被一个遮挡球体投射到地面上的半影大小。光源越小，阴影越锐利；反之，光源越大，阴影越柔和。由于定点光源没有物理尺寸，它们从设计上就是产生完全锐利阴影的，这在真实感渲染中往往并不理想。

如前所述，先驱研究者很早就（1970 年代末、1980 年代初）为用光线追踪模拟面光源打下了数学基础。但当时的计算机还不够强大，无法在合理时间内完成这些计算。直到 2000 年代末、2010 年代初，计算机变得足够强大，光线追踪面光源才开始在生产中可行地使用，而不再昂贵到无法承受。这一点尤其成立，因为在 GPU 上跑光线追踪变得容易了（大约 2016 年 Nvidia 和 AMD 推出基于 RTX 的 GPU），而在这项创新之前，光线追踪只限于 CPU（用 GPU 做光线追踪的尝试大约可追溯到 2000 年代中期）。

本章余下的部分将用来介绍理解「如何用光线追踪模拟面光源」所需的数学概念；如前所述，这条路既比其他技术（尤其是阴影贴图技术或辐射度方法）更直接，也不受那些技术固有局限的困扰。但世上没有理想的东西，当然，我们会看到光线追踪的面光源也有它自己的缺点！

蒙特卡洛积分概念的快速友好入门

我们把自己设想成一个正被面光源照亮的点。想象你就是这个点，如图 1 所示。顺着你的法线看，你是正朝上看的，你看到的基本上是一个部分挡住面光源表面的球体。从这个视角看，不难猜到面光源发出的光只有一部分会照到你，因为一部分光被球体挡住了

你的任务是度量「光源整个表面上发出的光，有多少被球体挡住了？」球体有一些漂亮的几何性质，所以你可能会想，可以利用它们来算出「发出的光」与「被挡住的光」之比，但那太简单了。不，你的任务是设计一种方法，无论挡住面光源的是什么形状都管用——形状可以是另一个平面、一个球体，甚至是一只兔子，或者如果导演决定了，一匹独角兽也行。哪天我得跟你讲讲那些著名电影导演的故事：他们曾在影片上映前几天，要求把一套 CG 布景铺满粉色的风车——真事！那么，为什么不能是独角兽呢？可这到底要怎么做？

想象一张 512x512 像素的白色图像，正中央有一个半径 128 像素的黑色圆盘。这个设置代表从我们的点 \(x\) 看过去的面光源，中心那个深色圆盘则代表从 \(x\) 看过去挡光的球体。为了解决这个问题，我们采用一种受辐射度启发的做法：把图像沿每个维度一分为二来细分。第一次迭代就得到四个象限。我们继续细分这些象限，直到达到最大细分层级，或者某个象限完全落在球体内或球体外。若一个象限同时含有白色和黑色像素，就认为它与球体重叠。最后，我们把完全由白色像素填满的象限（排除与球体重叠或落在球体内的那些）中的像素数加起来，再除以图像的总像素数，就得到光源未被遮挡的比例。

在看图 2 的结果之前，先注意：用数学我们是可以非常精确地算出「未被球体遮挡的那部分光」所占的比例的。既然知道圆盘半径，我们就知道球体覆盖的像素总数恰好是 \(\pi \times r^2\) 或 \(\pi \times 128^2 = 51,471.85\)。把这个数除以图像的总像素数，就得到 \(\frac{\pi \times 128^2}{512^2} = \pi \times \frac{1}{16} = 0.1963\)。也就是说，19.63% 的面光源被球体遮挡，这意味着有 80.37% 的面光源对 \(x\) 可见。这就是解析地算出这个数的方法。我们把这个数（80.37%）称为我们的期望值。

现在来看看结果。正如你在图 2 的动画中看到的，随着细分次数增加，比例会趋近 80.37%。所以这个方法是有效的，也能看出：把四叉树细分得更细，估计就能更准。注意，虽然我们一直用球体作遮挡物，这个技术换任何形状都能用。很好。

我们刚用的方法受一个叫 辐射度 的研究领域的启发。因为 1980 和 1990 年代光线追踪太慢、没法用于生产，人们开始寻找别的方式来模拟面光源、间接漫反射与镜面反射这类东西。辐射度方法的核心思想是把着色点之上的空间「细化」成越来越小的曲面片。这个过程有助于识别出各块独立的光，再把这些块当作「积木」来计算光能如何从一块曲面片传递到场景中的其他曲面片。

辐射度方法与更一般的有限元方法（FEM）相关。FEM 是一种数值技术，用于求偏微分方程边值问题的近似解。它把一个大问题——比如热传导或弹性变形这类物理现象——细分成更小、更简单的部分，称为有限元，再通过综合的过程重建出解。这个方法在工程与物理科学中至今流行，但在计算机图形学里，它的应用仅限于模拟漫反射的相互反射。按设计，它若不费很大周折，就无法有效模拟镜面反射的相互反射。这主要是它失宠的原因，让位给了光线追踪——只要有足够的算力，光线追踪在这类效果的模拟上表现出色。

专论这个主题的两本经典著作如今已进入公有领域，可以下载 PDF：

  • 《Radiosity and Realistic Image Synthesis》（1993），Michael F. Cohen 与 John R. Wallace 著。

  • 《Radiosity, A Programmer's Perspective》（1994），Ian Ashdown 著。

记住，我们在这里想确定的是：光源的面积中有多少对 \(x\) 可见。从数学上讲，这可以表述成一个积分问题。这类问题要把数值在一个空间或表面上（比如面光源的表面）求和或 积分——这个空间或表面称为积分域——从而得出一个整体的度量，比如可见性、面积或面光源的强度。此前我们用受辐射度启发的空间细分方法处理过它。而现在，我们要换一种方法，叫蒙特卡洛积分。

我不打算深入这些方法背后的数学细节，因为网站上有一系列课程把这个主题讲得很透（例如见 蒙特卡洛方法的数学基础 与 蒙特卡洛方法实践）。既然它们对理解光线追踪面光源的实现必不可少，我们就得把那些课程里已经探讨过的不少内容再走一遍。为重复致歉；不过好在一点：我们在这门课里引入这些概念的方式，某种程度上比那两门专讲蒙特卡洛方法的课友好得多，而且它们当然也很有互补性。我们先从一个非常简单、非正式但很实际的例子开始，再由此把概念形式化。

这种基于概率（后面再详述）的蒙特卡洛积分方法，其思路是对面光源的表面采样。要测你所在国家成年人口的平均身高，去量每个成年人的身高再除以成年人总数，大概不现实。你不如从全国成年人口里随机抽几千人，量这些被选中的人的身高，再用这些身高之和除以样本量求平均。这不会给你成年人口的精确平均身高，但从统计上讲能给出一个合理的近似。选前民调用的就是这个思路。同样地，我们可以把这种方法用到面光源上。想象往光源表面随机撒豆子——这就像从全国成年人口里随机挑人——再数有多少豆子落在圆盘内、多少落在圆盘外（圆盘代表从点 \(x\) 看过去可能遮挡光源的物体）。数学上这很直接：在我们那张 512x512 图像的表面上生成随机点，检查每个点在球内还是球外，在球外就给计数器加一。生成完所有想要的点后，用落在圆盘外的豆子总数除以豆子总数。下面这段 Python 代码做的就是这件事：


import numpy as np
import matplotlib.pyplot as plt

def draw_disk(image, center, radius):
    for x in range(image.shape[0]):
        for y in range(image.shape[1]):
            if (x - center[0])**2 + (y - center[1])**2 <= radius**2:
                image[x, y] = 0  # Black for inside the disk

def is_inside_disk(center, radius, point):
    return (point[0] - center[0]) ** 2 + (point[1] - center[1]) ** 2 <= radius ** 2

# Initialize parameters
width, height = 512, 512
radius = 128
center = (width // 2, height // 2)
num_points = 128

# Create a white image
image = np.ones((width, height)) * 255

# Draw a black disk
draw_disk(image, center, radius)

# Monte Carlo simulation to estimate the area outside the disk
outside_count = 0
points = np.random.randint(0, high=width, size=(num_points, 2))

# Set up the plot
fig, ax = plt.subplots()
ax.imshow(image, cmap='gray', origin='upper')

# Check each point and adjust markersize
for point in points:
    inside = is_inside_disk(center, radius, point)
    if not inside:
        outside_count += 1
    color = 'ro' if inside else 'go'
    ax.plot(point[1], point[0], color, markersize=3)  # Smaller point size

# Calculate percentage of points outside the disk
percentage_outside = (outside_count / num_points) * 100

# Display the result
ax.set_title(f"Monte Carlo Estimation of Area Outside Disk: {percentage_outside:.2f}%")
ax.set_xticks([])
ax.set_yticks([])

plt.show()

图 3 展示了点数递增时的结果，具体是：128、256、512、1024 和 2048。可以看到，与基于辐射度的方法类似，用的点或样本越多，估计就越好——更准确地说，逼近期望结果的概率提高了，这个我们后面再谈。这个结果真让人意外。只要随机撒豆子，数一数有多少豆子没落在被遮挡的区域内，我们就能估计出可见性积分。这个方法简单得不可思议，却有效。

注意最后一张图用了 2048 个样本，结果（81%）超过了期望值（80.37%）。用蒙特卡洛方法，结果有时会低于、有时会高于期望结果。估计值与期望值之间的差称为方差。因为估计结果取决于我们（随机地）挑选的样本，改变随机数生成器的种子，在样本数相同的情况下可能得到完全不同的结果，有的高于、有的低于、有的恰好等于期望值。具体落在三者中的哪一种无法预测，因为它取决于一个随机过程：样本的挑选。估计是高于还是低于期望值并不关键。关键在于随着样本数增加，得到接近期望值的结果的概率也随之增加（如果我们用不断增加的样本数继续模拟，就会观察到这一点）。关于这个方法的详细解释见课程 蒙特卡洛方法。简而言之，2048 个样本的方差很可能比 16 个样本小。样本数越多，我们对「估计逼近期望值」的信心就越大。

希望这个例子已经让你对蒙特卡洛方法是什么、怎么工作有了直觉——在积分域（光源表面）上按随机样本对给定函数（面光源的可见性）求值，再把这些样本的结果按所选样本总数求平均。

我们把难度再提高一档。

渲染方程与半球采样 vs 面采样

要进一步探讨面光源，我们需要退一步，看看在计算机图形学中我们是如何模拟光源效果的。这会引出渲染中最重要的公式之一，称为渲染方程。眼下我们先给出一个只限纯漫反射表面的简化版本。虽然有一门完整的课程专门讲渲染方程这个进阶主题，但在这里我们不能回避这个关键概念，因为要深入面光源实现的种种挑战，正需要它。

这个方程的原理并不太复杂。想象你是一个点。你下方是一个不透明表面，所以照亮你的光不可能来自下方。它只能来自上方，而你所在的平面把空间一分为二，来自上方的光必然被限制在以你所在点法线为中心的一个半球方向范围内。这个概念相当直白，如图 XX 所示，图中你可以看到沿 \(x\) 处法线朝向的半球。这里照亮 \(x\) 的光来自我们加到这个简单场景里的两盏面光源。

顺便注意，当你站在户外时，照亮你的光不仅来自太阳，也来自你周围所有其他物体，包括天空。

你可能已经猜到，我们想对来自这一半球方向的光量做「积分」（即「收集」的同义词）。这构成一个积分问题，因为尽管半球纯属虚构，它仍是一个表面——至少你会同意，它不是由离散元素构成的。现在，在计算机图形学（以及物理学）中，当我们对一组方向（此处即半球）积分时，会用到立体角的概念（它与我们上一章已经讨论过的微分面积概念相对应——正如立体角这个概念当时也已引入）。如果你愿意，可以把立体角想成单位球面（在本例中是半球面）上的一块面积。它的单位是 球面度。球面的面积是 \(4\pi r^2\)，考虑到这里处理的是单位球面（嗯，是半球而不是整球），我们的半球有 \(2\pi\) 球面度。

换个说法，或者如果你愿意，可以借助下面这张图来想象：它展示了从 \(x\) 看过去场景的 180 度鱼眼视图。这基本上就是 \(x\) 「会看到的」景象，而所有到达 \(x\) 的光都来自由「它看到的」那些方向。我们要做的就是「扫过」这个视野并收集光。但由于它是连续空间，我们必须借助积分才能在数学上表达这个过程。

渲染方程——也许是计算机图形学中最著名的公式之一——替我们完成这件事。它对从半球方向范围内到达 \(x\) 的光量做积分。对半球上考虑的每个方向，这个光量都要乘以表面 BRDF 和 Lambert 余弦定律。被积函数——即被积分的那个函数——是从半球内每个可能方向到达 \(x\) 的光量（即下式中的 \(Li\) 项）。它可以这样定义：

$$L(x) = \textcolor{blue}{\frac{R(x)}{\pi}} \int_{H^2} \textcolor{orange}{Li(x, \omega) \cos(\theta)} d\omega$$

其中：

  • \(L(x)\) 是 \(x\) 的辐射亮度（颜色），

  • \(Li(x, \omega)\) 是从方向 \(\omega\) 朝 \(x\) 入射的光，

  • \(\theta\) 是 \(x\) 处表面法线与光线方向之间的夹角，

  • \(\cos(\theta)\) 如前所述，是 Lambert 余弦定律的应用（因入射角而使向外的辐照度——即入射光量——减弱的因子）。

你可以把 \(\textcolor{orange}{Li(x, \omega) \cos(\theta)}\) 项看作方程的照明部分。我特意在里面留了四项，好让你格外留意它们：

  • \(\textcolor{blue}{\frac{R(x)}{\pi}}\) 在技术上代表 BRDF。本课只处理理想的漫反射表面，而 \(\frac{R(x)}{\pi}\) 描述的正是漫反射表面的 BRDF。这里 \(R(x)\) 表示表面反照率（有时也记为 \(\rho\)，即希腊字母 rho）——如果你愿意，可以把它想成表面颜色。分母中的 \(\pi\) 起归一化因子的作用（详见讲 BRDF 的课程）。按惯例这一项会出现在积分号右侧，但由于它在此语境下是常数，可以移到积分号外、放到左边。

  • \(H^2\) 表示积分域，此处即半球。希腊字母 \(\Omega\)（大写希腊字母 omega）有时也用来表示它。

  • \(d\omega\) 是我们所说的微分立体角。数学上，我们称之为变量 \(\omega\) 的微分（在此例中），它表明积分变量是 \(\omega\)。

  • \(\omega\) 本身也需要考虑，它是所考察的入射光的反方向。

下图试图表现积分中这样一个「方向」如何被可视化。你可以把它想成一个从 \(x\) 出发、沿入射光方向 \(\omega\) 定向的小锥体。再注意，这个锥体在单位半球表面上会形成一个小帽，它正对应我们在讲 BRDF 的课程中讨论过的微分面积概念。

渲染方程通过在一个半球方向范围内对到达 \(x\) 的光量积分来求解。被积函数——即被积分的那个函数——是从半球内每个可能方向到达 \(x\) 的光量。我们用蒙特卡洛积分来求解，这和我们上面处理「可见光面比例」问题的做法完全相同。我们会在积分域（即半球表面）上采样：随机挑选若干方向，沿这些方向发射光线，检查它们是否与发光物体（比如面光源）相交（本课只限于直接光照，所以只考虑会发光的几何体）。把每条光线返回的颜色相加（若光线没打到任何光源就是 0，若打到光源就是光源的颜色，即它发射的辐射亮度），再按样本总数求平均。下图展示了地面某一点上的过程，我们向半球上方发射了 64 条光线。具体怎么做会在下一章详述，所以现在不必太在意实现细节。先把概念抓住就好。概念化不难。挑随机方向，你能做到；把这些光线与上方的光源求交，到这会儿你也该会了。

如果仔细看上图，会注意到在射出的 64 条光线中，只有 2 条与面光源表面相交，这个比例相当低。这应该暗示了这种方法的问题所在——噪声。我们需要大量光线，才能既保证检测到面光源，又有足够多的样本与它表面相交，从而正确计入它对 \(x\) 处照明的贡献。

说明一下，问题出在光线数量偏少。真正打到面光源的光线数，可能从图像的一个像素到下一个像素变化很大。比如某个像素有 2 次命中，下一个有 5 次，再下一个甚至可能是 0 次。为什么不呢？这种波动意味着每个像素对该像素可见的那一点照明的近似都大不相同，于是图像出现噪声。问题不只是方差大（近似值与期望值之间的差距），还在于这个方差从像素到像素剧烈变化。要减小方差，唯一的办法是增加样本数。

下面是半球采样方法的伪代码，用来近似渲染方程的结果：


uint32_t num_samples = 64;
Vec3f L = 0;
for (uint32_t n = 0; n < num_samples; ++n) {
    // 随机挑一个方向
    Vec3f rand_dir = ...;
    if (Intersect(x, rand_dir, scene, &isect_info)) {
        if (isect_info.mesh-&gtemission_ != 0)
			// 目前把 emission_ 设为 1（见下方注释）
            L += 1 / M_PI * isect_info.mesh-&gtemission_ * max(0, rand_dir.Dot(isect_info.N)) / pdf; 
    }
}
L /= num_samples;

注意 1/M_PI 这一项，它对应漫反射 BRDF。分子里的 1 代表 \( R(x) \)，即表面反照率。本例中我们的地面被设为纯白——这种反照率在现实中并不存在，但对本演示来说没有问题。再说一次，现在不必担心这些随机方向是怎么生成的。我们只需说：在所有可能的方向中，每个方向被选中的机会均等。也不用担心除以 pdf 变量这一步，后面再讲。所以你可以看到，本例中我们射出 64 条光线，方向全都落在沿 \(x\) 处法线的半球方向范围内。如果光线与发光网格（面光源？）相交，我们就把它按漫反射 BRDF 和 Lambert 余弦定律加权的贡献累加进去（即表面法线与光线方向的点积——其中光线方向就是我们随机选出的样本方向）。

简而言之，我们对半球「采样」，有点像做一次民意调查，看看这些随机选出的方向上来了多少光；借助蒙特卡洛积分的魔力，把结果求平均，就得到积分的近似——假如我们能解析地求解它（或者能像大自然那样以光速解决这个问题），那才会是精确结果。

如前所述，这种方法的问题在于只有少数样本可能打到面光源，这很麻烦，因为会在图像里产生可观的噪声。我们可以增加光线数，但数越多渲染越慢。那么，如果能保持样本数不变而降低噪声呢？

把问题反过来看就能做到这一点。我们不去采样半球，转而采样面光源的表面。我们不再沿法线方向的半球内生成随机方向，而是在面光源表面生成样本，如下图所示（方法是选取均匀分布在光源表面上的随机位置，然后把每个采样点与 \(x\) 连起来，为每个样本确定一个光线方向。注意这些 \(\omega\) 光线样本向量是从 \(x\) 指向光源上的采样位置，与光实际传播的顺序相反——光是从光源走向 \(x\)）。

现在，只要我们把数学稍作调整，这样做是完全可以的，因为我们需要找到光源表面与该表面如何用立体角表达之间的一个换算关系——或者说对应关系。你可以把面光源投影到半球上再在半球上采样，但这个问题并不好直接求解，因为一个多边形投影到球面上会变成球面多边形，而球面多边形我们没有直接的表示方式（如下图所示）。

那我们改怎么办？你可以把面光源上的每个样本看成光源表面上的一个微分面积 \(dA\)。我们要做的是设法把这个微分面积 \(dA\) 「换算」成微分立体角 \(d\omega\)。幸运的是，两者的关系确实存在，而且相当简单：

$$dw = \frac{\cos(\theta')}{|x - x'|^2} dA$$

  • 其中 \(\theta'\)（或 \(\cos^{-1}(-\omega \cdot N')\)）是光源法线 \(N'\) 与样本光线方向 \(\omega\) 之间的夹角

  • \(x'\) 是面光源表面上的样本

  • \(x\) 是着色点

  • \(|x - x'|\) 是 \(x\) 到 \(x'\) 的距离

  • \(\omega\)，即向量 \(\vec{x' - x}\)，是样本光线方向

注意分母中的距离平方对应平方反比定律，我们在上一章介绍过它。这条物理定律的由来是：光从光源发出后按球状扩散。这里我们认为面光源在 \(x'\) 处既沿径向又各向同性地发光——也就是在每个方向上均匀发光。因此，如上一章所述，光扩散所覆盖的表面积随距光源距离的平方增长。

我们的渲染方程现在变成：

$$L(x) = \frac{R(x)}{\pi} \int_{A} L_{e} vis(x, x') \cos(\theta) \frac{\cos(\theta')}{|x - x'|^2} dA$$

\(vis(x,x')\) 这一项表示两点之间是否互相可见。注意我们现在是对光源表面的面积积分，而不是对半球方向积分。哇！干得好。技术上，要把它写成代码，我们还需要（再一次）讨论概率密度函数（PDF），但这个马上就到。现在，请相信下面这段伪代码是能工作的：


uint32_t num_samples = 64;
Vec3f L = 0;
for (uint32_t n = 0; n < num_samples; ++n) {
    // 在光源表面上随机挑一个方向
    Vec3f wi;
	float pdf;
	float t_max;
	Vec3f Le = light-&gtSample(x, r1, r2, &wi, &pdf, &t_max); 
	if (!Occluded(x, wi, t_max, scene)) // 不要在 t_max 之外寻找交点
		L += 1 / M_PI * Le * max(0, wi.Dot(isect_info.N) * max(0, -wi.Dot(light-&gtnormal)) / (t_max * t_max * pdf)); 
}
L /= num_samples;

注意上面的代码里，我们不再把光源当成带自发光属性的几何体，而是使用派生自 Light 类的光源。这就是为什么在大多数生产级渲染器里，面光源在图像中不可见——默认它们不被当作几何体处理。稍后细说。因此，我们直接从光源取它发射的能量（Le），并使用光源法线——等我们深入实现细节，你会发现取得它非常容易。t_max 如前所述保存了从 \(x\) 到采样位置 \(x'\) 的距离。面光源表面上的采样位置由两个定义在 [0:1] 范围内的随机数算出，即上面伪代码中的 r1 和 r2。这一点很快也会讲到。下图展示了用这种思路能得到什么样的图像。关于这个概率密度函数（pdf）的进一步解释稍后给出。

在比较半球采样与面采样这两种方法之前，我想指出：正如你在下图看到的，这两种方法（至少目前）产出的结果不一样。

不妙，但这是故意的。代表半球采样方法的那张图用的面光源发射值是 (1,1,1)——本质上就是 1。而在使用面采样方法的图里，光源面积是 5.11E+7 平方米（或者说平方单位），功率是 1.34E+8，因此它的辐射出射度（W/m^2）是 2.62541 W/m^2。如果我们在半球采样方法里用这个值代替 1，两张图就完全吻合了。


uint32_t num_samples = 64;
Vec3f L = 0;
for (uint32_t n = 0; n < num_samples; ++n) {
    // 随机挑一个方向
    Vec3f rand_dir = ...;
    if (Intersect(x, rand_dir, scene, &isect_info)) {
        if (isect_info.mesh-&gtemission_ != 0)
			// 把 emission_ 设为 2.62541
            L += 1 / M_PI * isect_info.mesh-&gtemission_ * max(0, rand_dir.Dot(isect_info.N)) / pdf; 
    }
}
L /= num_samples;

在半球采样中，你考虑的是每平方米有多少光能沿某个特定方向从表面射出、回到关注点 \(x\)。本质上，半球方法利用统计采样，把光源的辐射度量属性（单位面积的能量）转换成一种可以对立体角积分的形式。这个方法把基于面积的度量（光源表面积）变成基于角度的度量（立体角）。因此，使用半球采样方法时要留意给几何体用正确的「发射」值（辐射出射度），你可以像上面那样由面光源的功率和面积算出它。反过来说，如果你的目标是让两种方法产出可比的结果，也可以根据已知的辐射出射度和面积反算光源的功率。

好。现在两种方法产出相同的结果了。可我们为什么要费这么大劲？看下面这张图你就会发现，在样本数相同的情况下，面采样方法生成的图像噪声比半球采样的对应结果少得多——我是说，少得非常明显。所以，在三维渲染里模拟面光源，我们当然用面采样方法。

概率密度函数（PDF）、概率分布与蒙特卡洛估计量简介

在继续之前，有必要澄清一个与蒙特卡洛估计技术相关的关键概念。这一点尤其重要，因为本课重点并不是蒙特卡洛方法，而你可能还没读过那两门专门讲它的课程。我们需要理解的关键概念是概率密度函数（pdf），我们在光照的 Sample() 方法里已经碰到过它。

我们用几个例子来建立直觉：概率密度函数是什么，以及它在蒙特卡洛积分的语境里解决什么问题。先想一个情形：你用面采样方法给一个尺寸 1x1 单位（也就是面积为 1 单位）的光源采样。假设你决定用 16 个样本，于是在光源表面生成 16 个样本，再用上面给出的代码算出每个样本的光线方向。很好。但现在，假设你想采样一个 2x2 单位的面光源，面积是最初那个光源的 4 倍。你同不同意，光源更大，它的贡献也应该更显著？别把它想成最初的光源变大了，而要想成四个最初的光源挤在一起组成了一个更大的光源。这样一来，我们的能量就是最初光源的 4 倍了！对吧？

然而，如果你套用我们提供的那个采样光源的代码（面采样方法），会发现代码里没有任何东西考虑光源的尺寸。于是，对这两个光源采样实际上会得到相同的结果，除非你为每次计算调整 pdf（概率密度函数）的值。这个调整能保证采样更大的光源时，结果也按比例变大。设想 pdf 对 1x1 的光源是 1，对 2x2 的光源是 0.25。那么对更大的光源（2x2）来说，结果会是初始采样的 4 倍，因为我们会把光源贡献的结果除以 0.25。看来思路对了！


uint32_t num_samples = 64;
Vec3f L = 0;
for (uint32_t n = 0; n < num_samples; ++n) {
    // 随机挑一个方向
    Vec3f rand_dir = ...;
    if (Intersect(x, rand_dir, scene, &isect_info)) {
        if (isect_info.mesh-&gtemission_ != 0)
            L += 1 / M_PI * isect_info.mesh-&gtemission_ * max(0, rand_dir.Dot(isect_info.N)) / pdf; 
    }
}
L /= num_samples;

某种程度上，PDF 就是我们用来体现「光源尺寸与它发出的能量之间关系」的调整变量。光源越大，PDF 越小，于是蒙特卡洛近似的结果就越大。在均匀采样的情况下，PDF 是 \(1/\text{Area}\)。我们会给出更多关于 PDF 的一般背景，并更精确地解释为什么在这个语境下这个 PDF（\(1/\text{Area}\)）是有效的。

在统计学里，你可能想知道一颗骰子掷出数字 5 的概率。骰子有六个面，只有六种可能结果。假设骰子没被做手脚，掷骰子时每个数字被掷出的概率相等，这个概率是 \(1/6\)。注意，就骰子而言，因为结果数量有限（6 个），我们说这些概率是离散的。那么，面光源表面上一个点被选中的概率是多少？这里的问题很不一样，因为我们不再处理离散结果，而是处理连续域（面光源表面代表一段连续的结果范围）。你可以选光源 x 轴上的任意值、z 轴上的任意值。

这里关键在于密度这个词。在连续域（我们说的是二维表面，即面光源表面，但也可能是一维的线比如一根弦，或者三维的体积）中，\(p(x)\)——其中 \(p\) 是概率密度函数——给出的不是该点发生的概率，而是概率在该点附近分布的稠密程度的度量。和任何概率一样，所有概率之和必须为 1。PDF 也是如此，但由于它是函数，我们需要把求和（比如把 \(1/6\) 加六次，即掷出骰子任一面的概率）换成积分，于是：\(\int p(x) = 1.\)，其中 \(p(x)\) 就是我们的概率密度函数（它是一个函数，和数学里任何函数一样标准）。PDF 在整个表面上的积分度量的是从表面上任意位置抽到一个样本的总概率，逻辑上它必须是 100%（即概率为 1），因为抽出的每个样本必定来自那个表面的某处。当表面发射均匀，即表面每一部分发光（在蒙特卡洛模拟语境下即被采样）的可能性相同时，PDF 必须反映这种均匀性。如果表面面积为 \(A\)，那么把 PDF 设为 \(\frac{1}{A}\) 就能保证概率密度均匀铺满整个表面。这样设定 PDF 可保证在表面上的积分之和为一：

$$ \int_{\text{Surface}} \frac{1}{A} \, dA = \frac{1}{A} \times A = 1 $$

把均匀发光或均匀采样的表面的 PDF 定义为 \(\frac{1}{\text{Area}}\)，这套数学框架就能保证选中该面积中任一部分的概率正确反映它相对于整块面积的占比。这对准确、无偏的蒙特卡洛模拟至关重要——采样域的每一部分（比如光源表面）被选中的概率必须按它的面积成比例加权。

这就引出蒙特卡洛估计量的公式——这个术语你要记住，凡讲到蒙特卡洛方法的教科书里都会出现：

$$\textcolor{blue}{\int f(x) \, dx} \approx \textcolor{green}{\frac{1}{N} \sum_{i=1}^N \frac{f(x_i)}{p(x_i)}}, \textcolor{red}{\quad x_i \sim p}$$

这个公式说明，右边的蒙特卡洛估计量给出了 函数 \(f(x)\) 的积分 的近似。它包含这些内容：

  • 蒙特卡洛估计量由若干项求和后取平均构成：函数 \(f(x)\) 在按采样分布 \(p\) 抽出的各个样本位置 \(x_i\) 上求值，再除以 \(x_i\) 处的概率密度函数。

  • \(x_i \sim p\) 这一项表示样本 \(x_i\) 是从某个概率分布 \(p\)（可以是均匀或非均匀的）中抽出。

还要注意符号 \(\approx\) 表示近似。蒙特卡洛估计量给出的是 \(\int f(x) \, dx\) 的近似。

幸好在本次课程里我们只处理均匀分布的样本。我说「幸好」，是因为理解非均匀分布背后的数学并不算太复杂，但确实需要仔细解释。读完之后若想深入这个主题，请参阅 重要性采样 这门课。本课的关键要点是：大多数先进的基于光线追踪的渲染引擎都在某种程度上大量依赖蒙特卡洛估计量。随着课程推进，我们会了解到更多细节，但仅蒙特卡洛估计量本身，就是构成这些系统（即便不是全部，也是大多数）的基本积木。

把它应用到我们处理立体角时的渲染方程上（半球采样方法），得到：

$$L(x) \approx \frac{R(x)}{\pi} \sum_{i=1}^{N} \frac{L_i(x, \omega_i) \cos(\theta_i)}{p(\omega_i)}$$

而如果我们采样面光源（面采样方法），可以写成：

$$L(x) \approx \textcolor{blue}{\frac{R(x)}{\pi}} \sum_{i=1}^{N} \frac{\text{vis}(x,x') L_e(x') \cos(\theta) \cos(\theta')}{p(x')r^2}$$

其中：

  • \(\theta\) 表示光线方向 \(\omega\) 与 \(x\) 处表面法线之间的夹角。

  • \(\theta'\) 是 \(x'\) 处光源法线与光线方向之间的夹角。

  • \(x\) 是物体表面上的着色点。

  • \(x'\) 是光源表面上的一个样本（从概率分布 \(p(x)\) 中抽出）。

  • \(p(x)\) 是我们的概率分布函数（在均匀分布样本的情况下应为 \(1/\text{Area}\)）。

  • \(r\) 是 \(x\) 到 \(x'\) 的距离。

  • \(\text{vis}(x,x')\) 是一个函数：两点互相可见时返回 1，否则返回 0。

我们把漫反射表面的 BRDF 从求和中省略了，因为它是常数。

在进入下一章、给你这套技术针对各种典型面光源形状的实际实现之前，先拆解一下在实践中该如何应用上面的公式，可能有用。如这个公式所示：

$$\int f(x) \, dx \approx \frac{1}{N} \sum_{i=1}^N \frac{f(x_i)}{p(x_i)}, \quad x_i \sim p$$

它分为两部分：

  • 第一部分 \(\frac{1}{N} \sum_{i=1}^N \frac{f(x_i)}{p(x_i)}\)，是蒙特卡洛估计量。

  • 第二部分 \(x_i \sim p\)，是你用代码实现这个算法时的起点。技术上，它涉及按概率分布 \(p\) 抽取一个随机变量 \(x_i\)。

目前我们只处理均匀分布，所以 PDF 是常数（1/Area），这点前面已经提过好几次。但并不总是这样。举个例子，想象一盏矩形面光源，贴着一张圆盘的纹理，中心极亮、边缘渐隐。直觉上，在纹理最亮处生成更多样本是合理的，因为那里是光源对场景照明在能量上贡献最大的地方。这种做法会比均匀采样更有效，因为均匀采样把贡献高的区域和贡献低的区域同等对待。

下图（图 17）对比了均匀与非均匀采样策略。左边，矩形面光源的表面用均匀分布采样。注意很多样本落在光源较暗的区域，尽管这些样本对总体光贡献极小，因为大部分光能集中在光源中部。右边，样本按一种给了光源中能量更多区域更大权重的概率分布抽出，因此更偏向中心而非边缘。需要注意，左图中每个样本的 PDF 是常数且等于 1/Area。右图中每个样本各有自己的 PDF 值，样本最集中处值较高、样本稀疏处值较低，反映了蒙特卡洛估计量求和中不均匀的分布。

用这种思路，我们会从一个概率分布函数抽样本，它在面光源中心生成的样本比边缘多。由于样本分布不均匀，我们就需要相应地调整 PDF 值：中心的样本因更集中，PDF 比边缘的高。直觉上这说得通：如果光最亮处（因为贴了纹理）生成样本的概率更高，PDF 当然会更大。但记住，PDF 在 MC 估计量的分母上。于是分母越大，除法结果越小。换句话说，更可能被生成的样本——通常来自纹理较亮的区域——由于 PDF 值更高，对整体近似的贡献反而更小。反过来，来自纹理较暗区域、不太可能被生成的样本，由于 PDF 值较低，贡献更大。这看起来反直觉，其实是一种策略性平衡：既然来自高概率（亮）区域的样本更多，除以 PDF 就有效地把贡献在光源表面上拉平了。这种做法保证了由纹理各处光强不同所决定的样本不均匀分布，不会扭曲整体的光照估计。通过在蒙特卡洛估计量的分母里使用 PDF，我们精确地补偿了这种样本分布不均，从而更准确地表现光源对场景的实际影响。

这个概念是蒙特卡洛方法用法中的根本。它保证了：当我们从不一定均匀的概率分布中挑选样本时，近似不会因这种非均匀的样本分布而偏向那些更可能被抽中的样本，从而产生偏斜或偏差。使用非均匀 PDF 还有一个相当大的好处：能在积分域中优先选到那些对近似贡献更大的区域，而不是贡献较小的区域，从而有效地降低方差（对我们来说就是减少噪声）。

但这暂时不是重点。我们深入这番解释，主要是为了理解实现蒙特卡洛方法最初的几步——其中涉及按特定概率分布函数生成样本。通过这些例子，希望你已对这种运作方式建立了直觉。别担心，下一章我们会用代码看几个实际例子。

所以，总结一下，这就是你该怎样读这个公式并在实践中实现它：

$$\int f(x) \, dx \approx \textcolor{green}{\frac{1}{N} \sum_{i=1}^N \frac{f(x_i)}{p(x_i)}}, \textcolor{red}{\quad x_i \sim p}$$

  • 按 PDF 生成样本：如果面光源贴的纹理中间有一块亮斑，我们希望纹理值高的地方生成更多样本，因为那些正是对光照贡献近似贡献最大的光源区域（这是一种降方差技术，本课后面以及专门讲采样技术的后续课程里会更多地讲到。这个方法还有个叫法：重要性采样）。这就是「按给定 PDF 或给定分布抽样本」的意思。不过目前我们用的是均匀分布，如前面对矩形光源所学，它是 \(1/\text{Area}\)。有些教科书把这一步称为采样过程（有时记为 \(Sp\)）。我们会在下一章探讨这类方法——它们封装了生成这些样本、使其分布与所选 PDF 相匹配的逻辑。

  • 把抽到的样本用于你的蒙特卡洛估计量：一旦从 PDF 抽出样本并（由 PDF 本身）确定了这些样本的概率（我们的 \(x'\)），我们就可以用这些样本对函数 \(L_e(x')\) 求值，把 \(L_e(x')\) 除以 \(p(x')\)（即 \(x'\) 的概率），再把结果加进求和。所有样本处理完后，这个总和除以样本数。

虽然就本课而言这只是个细节，而且在专讲蒙特卡洛方法的课程里有解释，但要注意 \(\frac{f(x)}{p(x)}\) 本身被视为一个「随机」值。为什么？因为样本 \(x\) 是随机选的，所以在某个随机位置上对函数求值的结果本身也是随机的。只有这类随机数的平均，才在概率意义上趋于期望值。技术上这写作：

$$E[Xi] = \int_{\Omega} f(x) d\mu(x).$$

所以期望值本身就是：假如你能算出这个积分，就会得到的结果。当我们做不到时（积分无法解析求解），就退回使用蒙特卡洛方法。如前所述，对单个样本求值——教科书里记为 \(X\)（大写 X 字母），或用 \(Xf\) 表示它是对函数 \(f\) 求值的结果——会给我们另一个「随机」结果：

$$Xf(x) = \dfrac{f(x)}{p(x)}$$

有意义的是若干个这样的随机样本的均值，因为这个平均值会收敛到期望值，从而给我们一个估计：

$$\bar{Xf}(\{x_i\}_{i=1}^N) = \frac{1}{N} \sum_{i=1}^N Xf(x_i)$$

这里的 \( \bar{X} \) 指随机样本的均值，即估计量。蒙特卡洛的核心思想是：当样本数趋于无穷时，估计量与期望值一致，可以写作：

$$\lim_{n \to \infty} \bar{Xf}(\{x_i\}_{i=1}^N) = \int_{\Omega} f(x) d\mu(x).$$

如果你对第一个公式里的 \(\mu\) 项好奇，请参阅 重要性采样 这门课。

回到我们最初的例子，光源尺寸是 1x1，所以 PDF（目前是常数，因为我们只讲了均匀分布）是 1。当光源尺寸是 2x2 时，PDF 变成 \(1/4\)。实际上，把这些样本位置上的 \(L_e\) 除以 0.25，就意味着这盏光源的贡献是 1x1 光源的四倍。

这与我们一直用于面采样方法的代码相符，其中 pdf 实际上被设为 \(1/\text{Area}\)。虽然代码里没有展示面积如何计算，但我们会在下一章给出完整的源码。


uint32_t num_samples = 64;
Vec3f L = 0;
for (uint32_t n = 0; n < num_samples; ++n) {
    Vec3f wi;
    float pdf;
    float t_max;
    Vec3f Le = light-&gtSample(x, r1, r2, &wi, &pdf, &t_max); 
    if (!Occluded(x, wi, t_max, scene)) // 不要在 t_max 之外寻找交点
        L += 1 / M_PI * Le * max(0, wi.Dot(isect_info.N) * max(0, -wi.Dot(light-&gtnormal)) / (t_max * t_max * pdf)); 
}
L /= num_samples;

上面的伪代码中，t_max 对应 \(r\)，pdf 对应 \(p(x)\)。注意，当 \(\omega_i\) 从 \(x\) 变到 \(x'\) 时，我们需要把 -wi.Dot(light->normal) 里光源样本与光源法线的点积取反。

注意这只是这些概念的入门，后面还有很多。我们再次强烈建议你读那两门专讲蒙特卡洛方法的课程，以及 重要性采样——后续很多课程都会引用它们。希望这篇入门能给你刚好够用的信息，让你看懂它们在用光线追踪采样面光源时的用法，并对它们如何以及为何有效形成直觉，而不必深入更多细节或形式化背景。

采样策略

在结束本章之前（我是不是已经提过好几次了？），我想强调一个与这些样本生成有关的重要方面。到目前为止，虽然我们还没看代码、因而不知道这些样本是如何生成的，我们展示的例子中样本都是随机分布的。但正如你在生成的图像中（尤其是图 17 左图）看到的，这种「朴素」做法可能产生样本成簇的现象。样本生成的随机性，使得是否会出现簇——也就是彼此靠近的一堆样本——无法预测。这种成簇很成问题，因为它导致光源同一区域样本过多，而其他区域采样不足。

我想在这里强调的是：生成这些样本的方法有比这好得多的选择——远不止我们在本章提到的那个重要性采样方法。文献中有相当大一部分专门设计能生成最佳采样图案的算法，它们避免形成这类簇，同时保持固有的随机性——而随机性对蒙特卡洛方法能工作至关重要。

这个话题大到足以撑起好几门专门的课程，所以我们现在不再深入，但我想让你知道有这回事。如果你特别感兴趣，可以看我们关于 采样策略 和 重要性采样 的课程。
