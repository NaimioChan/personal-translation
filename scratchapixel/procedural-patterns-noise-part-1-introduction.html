简介

阅读时间：17 分钟。

对物理学家来说，任何随时间 t 变化的量 V 中那些不可预测的变化，都称为噪声。（《分形图像的科学》，Richard F. Voss）

本课以非常简单（近乎朴素）的形式解释噪声的概念。你会了解噪声是什么、它有哪些性质、以及能用它做什么。噪声并不是一个复杂的概念，但它有很多微妙之处。要用对，就需要理解它如何运作、如何生成。为了能做出一些图像并试验各种参数，我们会实现一个称为值噪声的噪声函数的简单（但功能完整）版本。读本课时请记住，我们会略过许多技术，它们太复杂，无法在这里讲透。这只是一篇对噪声及其若干应用的简短简介。本站有很多课程，可以单独学习本课提到的每个主题（走样、纹理生成、复杂噪声函数、地形云与水面生成），以及一些进阶编程技巧，比如位运算、哈希等）。

历史背景

噪声诞生于 80 年代中期，是作为用图像为物体做纹理的替代方案而出现的。我们可以把图像映射到物体上，给外观增加视觉复杂度。在 CG 中这称为纹理映射。但在 80 年代中期，计算机内存极少，用于纹理的图像很难装进 RAM。CG 工作室里的人开始寻找替代方案。用纯色渲染出的物体看起来太干净了。他们需要某种东西，通过在物体表面调制其视觉属性（颜色、光泽度）来打破这种干净的外表。在编程中，需要生成随机数时我们通常用随机数生成器。然而，用一个 RNG（随机数生成器）给 3D 物体的外观增加变化并不足够。我们在自然界能观察到的随机图案通常是平滑的。真实物体表面上的两个点彼此靠近时看起来往往一样。但同一物体表面上相距很远的两点可能差别极大。换句话说，局部变化是渐进的，而全局变化可以很大。RNG 没有这个性质。每次调用它，返回的数彼此无关（不相关）。因此调用这个函数很可能产生两个差别极大的数。这就不适合为空间上相邻的两个点在视觉外观上引入细微变化。举个例子：我们来观察一张天然岩石的图像（图 1 左），假设我们的任务是做出一张复现该物体外观的 CG 图像。你不能用纹理（最直接的方案就是拿这张图贴到一个平面上）。我们有一个平面，不加纹理时看起来完全是平的（均匀的颜色）。这个例子有意思的地方在于，我们能观察到岩石图案由三种主要颜色构成：绿、粉、灰。这些颜色在岩石表面上大致等量分布。这个问题最直接的解法，比如是用 Photoshop 打开这张图，把三种平均色各取一个，用在一个程序里，用它过程式地生成一个与参考图大致相似的图案。下面的代码就是这么做的。不过目前我们能为逐像素制造变化所做的一切，就是用 C 的 drand48() 函数，它返回 [0:1] 范围内的随机值。


void GenerateRandPattern() 
{ 
    unsigned imageWidth, imageHeight; 
    imageWidth = imageHeight = 512; 
    static const unsigned kNumColors = 3; 
    Color3f rockColors[ kNumColors ] = { 
        { 0.4078, 0.4078, 0.3764 }, 
        { 0.7606, 0.6274, 0.6313 }, 
        { 0.8980, 0.9372, 0.9725 } }; 
    std::ofstream ofs( "./rockpattern.ppm" ); 
    ofs << "P6\n" << imageWidth << " " << imageHeight << "\n255\n"; 
    for ( int j = 0; j < imageWidth; ++j ) 
    { 
        for ( int i = 0; i < imageHeight; ++i ) 
        { 
            unsigned colorIndex = std::min( unsigned( drand48 () * kNumColors ), kNumColors - 1 ); 
            ofs << uchar( rockColors[ colorIndex ][ 0 ] * 255 ) << 
                   uchar( rockColors[ colorIndex ][ 1 ] * 255 ) << 
                   uchar( rockColors[ colorIndex ][ 2 ] * 255 ); 
        } 
    } 
    ofs.close(); 
}

如图 1 中间所示，这个程序的结果并不令人信服（其实这个图案有个名字，叫白噪声。白噪声是什么我们后面再解释，目前只需记住它看起来就像图 1 中间那样）。我们用 RNG 为过程式生成的纹理的每个像素挑一种颜色，造成像素之间的巨大变化。为了改善结果，我们从纹理中复制了一小块区域（10x10 像素），把它缩放（放大）到原图的尺寸（256x256 像素）。放大这一部分画面会让像素变模糊，但为了让结果更平滑，我们又在 Photoshop 里加了一层高斯模糊。我们还没有很好地匹配参考图，但如你所见，得到的图像（图 1 右）已经比原来那张（中间）好。局部上有小的变化（像素之间颜色的微小变化），而全局上有更大的变化（三种输入颜色的混合）。

这个实验的结论是：要生成平滑的随机图案，我们需要用 RNG 在一个固定位置的网格上（我们称之为晶格；在例子里这个网格对应输入 10x10 图像的像素位置）赋随机值，再用类似高斯模糊的方式（一个平滑函数）去模糊这些值。下一章会展示如何实现。但目前你只需记住：噪声（在计算机图形学的语境下）是一个函数，它对网格（我们常称为晶格）上生成的随机值做模糊。

我们刚才描述的过程类似于双线性插值（见插值一课）。在下面的例子（图 2）中，我们建了一个 10x10 的二维网格，在网格每个顶点上放一个随机数，然后用线性插值渲染出更大的图像。

如你所见，结果的质量不太好。我们在插值一课中指出，双线性插值是插值数据最直接可行的技术，而要提高结果质量（如果需要的话），可以使用更高阶的插值函数（用来插值数据的函数）。下一章我们会写一个噪声函数，其效果优于这种对二维网格数据的简单线性插值。

Ken Perlin 在 1983 年写出了最流行的噪声实现（大概也是同类中最早的），当时他正参与 1982 年版电影《创》（© Walt Disney Pictures）。如果你去他的网站（或者在你常用的搜索引擎里搜 Ken Perlin），很容易找到那一页：Ken Perlin 亲自讲述他的噪声图案的来历。1997 年，Ken Perlin 因对该片的贡献获得美国电影艺术与科学学院颁发的技术成就奖。他在 1984 年的 Siggraph 上介绍了自己的工作，并在 1985 年发表了论文《An Image Synthesiser》，这篇论文在纹理合成领域具有开创性。如果你有兴趣了解噪声函数的基础（及其发展史），强烈建议读一读这篇论文。Perlin 噪声在噪声第二课中有讲解。

过程式纹理的世界

噪声的发展引出了计算机图形学中一个新的研究方向。噪声可以看作一种基本积木，由它可以生成许多有趣的过程式纹理（也叫实体纹理，见纹理一课）。在过程式纹理的世界里，可以生成许多类型的纹理，它们并不总是想模仿自然图案。写一个生成砖墙类图案的程序很简单。有些图案可以是有规律的、不规则的，或随机的（非确定性的）。

除了规则图案（它们只遵循几何规则，形状完美）之外，其他所有图案都可以用噪声来引入不规则性，或为过程式生成的纹理带来表面的随机性。Ken Perlin 提出他的噪声函数版本之后，CG 界许多人开始用它来建模复杂的材质与物体，比如地形、云，或让水面动起来。噪声并不限于改变物体的外观。它还可以用于过程式建模，对物体表面做置换（用于生成地形），或控制体积的密度（云建模）。通过逐帧偏移噪声的输入，我们还能用它做过程式动画。直到 90 年代中期，这都是给水面做动画最受青睐的方法（Jerry Tessendorf 在 90 年代后期提出了更实用的方法。见海洋波浪动画一课）。

本课最后一章给出了一些简单实体纹理（分形）的例子。纹理合成一课会提供这个主题的更多信息。

噪声的主要优缺点

如我们在简介中所说，噪声的优点是紧凑。与纹理映射相比它不占多少内存，实现一个噪声函数也不算很复杂（噪声函数需要存储的数据很少）。从这个非常基本的函数出发，还能造出各种各样的纹理（我们会在本课最后一章给出一些例子）。最后，用噪声给物体加纹理不需要对表面做任何参数化，而纹理映射通常需要（我们需要纹理坐标）。

另一方面，它们通常比纹理映射慢。噪声函数需要执行不少数学运算（即便都很简单，数量也不少），而纹理映射只需要访问已载入内存的纹理（图像文件）的像素。

理想噪声的性质

我们可以把所有理想噪声应该具备的性质列出来，但并非每种噪声实现都能全部满足（而且版本相当多）。

噪声是伪随机的，这大概是它的主要性质。它看起来随机，却是确定性的。给定相同的输入，它总是返回相同的值。如果你要为一部电影渲染图像好几次，你希望噪声图案保持一致、可预测。或者比如你把这个噪声图案贴到一个平面上，你希望该图案逐帧保持不变（即使相机移动或平面被变换。图案跟着平面走。我们说这个函数是不变的：它在变换下不改变）。

无论输入值的维度是多少，噪声函数总是返回一个浮点数。点的维度反映在噪声的名字里。一维、二维和三维噪声函数分别以一维、二维和三维点作为输入参数。甚至还有四维噪声，它取一个三维点作为输入参数，另加一个浮点值，用来让噪声图案随时间变化（时变实体纹理）。本课给出一维和二维噪声的例子。三维和四维噪声的例子在噪声第二课中展示。用数学语言说，噪声函数是从 Rn 到 R 的映射（n 是传给噪声函数的值所在维度）。它以一个坐标为实数的 n 维点作为输入，返回一个浮点数。一维噪声用于给物体做动画，二维和三维噪声用于给物体做纹理。三维噪声有助于调制体积的密度。

噪声是带限的。记住噪声主要是一个函数，你可以把它看成一个信号（把函数画出来，得到的曲线就是你的信号）。在信号处理中，可以把信号从空间域转换到频率域。这个操作的结果能让你看到信号的不同频率。如果你不明白从空间转到频率空间是什么意思，不必太担心（这在这里属于题外话，你可以去看傅里叶变换一课）。你只需记住：噪声函数可能由多个频率组成（低频对应大尺度的变化，高频对应小尺度的变化）。但其中有一个频率压过其他所有频率。而这一个频率既决定了你噪声函数的视觉外观，也决定了它在频率空间中的特征。为什么要在意噪声函数的频率？当噪声在画面中很小时（想象一个离相机很远的、用噪声做纹理的物体），它又变回白噪声，这正是我们在行话里称为走样现象的成因。图 4 对此做了说明。

在这张图的背景里，相邻像素取的是随机值。这不仅不好看、不真实，而且如果你渲染一串图像，这一区域像素的值会逐帧剧烈变化（图 4）。走样与采样这个主题有关，这是计算机图形学中一个非常庞大且关键的主题。如果你想弄清是什么造成了这个不想要的效果，我们建议读一读采样一课。

我们提到过，噪声用一个平滑函数去模糊在晶格点上生成的随机值。数学中的函数有各种性质。本课语境下有两个特别值得关注：连续性与可微性。解释它们是什么在这里属于题外话，但通过一个简单的例子，你会直观地理解它们的含义。导数是与曲线轮廓相切的一条线，如图 5 所示。然而，如果函数不连续，就不可能计算这个导数（函数也可能连续，但并非处处可微，如图 5 右侧所示）。由于我们后面会解释的原因，有些地方需要计算噪声函数的导数，因此最好选一个光滑、连续且可微的函数。Ken Perlin 最初的噪声实现用的函数并不连续，几年后他提出了另一个函数来修正这个问题。

我们可以在噪声曲线的任何地方求出切线。如果这条曲线上有某个地方求不出切线，或切线在此突然改变，那就造成了我们所说的不连续。

最后，当你看着贴到物体上的噪声时，理想情况下你不应该看到噪声图案的重复。如前所述，噪声只能在一个预先设定大小的网格上计算。上面的例子里我们选的是 10x10 的网格。如果要在该网格边界之外计算噪声，我们该怎么办？噪声就像一块瓦；要用特定尺寸的瓦铺满更大的区域，就得把许多块瓦并排放置。但这样做有两个明显的问题。在瓦的边界处，噪声图案会不连续。

// 图 6 此处并排插入多张噪声瓦片重复的图，然后是周期性的但仍重复。

理想情况下，你希望瓦与瓦之间过渡不可见，从而覆盖无限大的区域而永远看不到接缝。在 CG 中，当一张二维纹理无缝时，说它在两个方向（x 和 y）上都是周期性的。也有人说可平铺，但这个说法容易混淆。任何纹理都可平铺。但它未必无缝。你的噪声函数应该设计成图案是周期性的。此外，由于你用了许多图案相同的瓦，你可能会看出该图案的重复。这个问题的解法在本课这个阶段较难解释。你现在需要知道的是：噪声函数生成的图案没有大尺度特征（所有特征尺寸大致相同，记住我们说过函数是带限的）。如果你拉远，看不到大尺度特征的重复，因为函数里没有这些特征。至于构成噪声的其他较小特征，等你拉得足够远时，它们已经小到看不见了。让图案不可见的诀窍（确实是个诀窍）是把它做得足够大（让晶格点的网格足够大），这样当你覆盖整个屏幕时，这些特征在画面中已经小到看不见。我们会在下一章演示这个效果。
