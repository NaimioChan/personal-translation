简单的图案示例

阅读时间：19 分钟。

我们以一些用噪声函数生成的图案示例来结束本课。Ken Perlin 最初开发他的噪声函数时，提出了几个简单的算法，以这个函数为积木来生成有趣的实体纹理。其中一些函数（比如湍流）至今仍被广泛使用。他在 1985 年 Siggraph 上发表的一篇题为《An Image Synthesiser》的开创性论文中描述了这些图案中的大部分以及另外一些。这篇论文在网上很容易找到，我们强烈建议你读一读。

如前面所说，我们这个版本的噪声函数并不能造出最好看的噪声（目前我们的噪声相当块状）。本课的目标不是开发好看的噪声，而是理解这门技术如何运作以及函数的性质。要看更好看的噪声函数版本（称为梯度噪声，即 Ken Perlin 在 1985 年提出的原始技术），请看噪声第二课。不过，这不妨碍我们给你看几个例子，尤其是二维噪声，可以用它造出更复杂的图案。我们建议改动代码里的参数，以理解它们对结果的影响。下面每一章你都会看到算法描述、得到的图案，以及生成相应图像所用的代码。

一维噪声示例

我们要描述的最早的例子之一在所有维度上都行得通。不过我们先从一维讲，稍后再给二维噪声的例子。这门技术在三维噪声上的例子见第二课。总之，其思路是把若干噪声的贡献加起来（在 CG 文献里每一层常称为倍频程，但尽可能避免这个说法）。我们可以以连贯的方式改变这些不同噪声层（或倍频程）的参数——例如改变它们的频率与幅度。换句话说，我们可以在逐层的频率变化与幅度变化之间建立联系。

  • 我们从一个基础频率与单位幅度（1）出发，用这些值算出噪声的第一层。

  • 然后加上第二层噪声，但把这一层的频率乘以 2、幅度乘以 0.5（等同于把幅度除以 2）。

  • 第三层，我们把频率乘以 4、幅度除以 4。第 4 层与第 5 层的频率与幅度分别乘以 8 和 16、除以 8 和 16。

如果你还没看出关系：每一层的频率是上一层的两倍，幅度是上一层的一半。这样造出一系列噪声再把它们相加，就得到图 1（下图）的结果。如你所见，这条曲线的轮廓比单一噪声丰富得多。视觉上它看起来像山脉的轮廓（你可以把倍频程或层的概念理解为给地形叠加更小频率的细节——既然山的高度远大于构成风景细节的岩石高度，那么随着噪声层频率升高而降低其幅度就显得合理了）。我们提这一点并非偶然。后面用这门技术的二维版本时会说明，我们可以用这个结果去置换网格，造出像山的东西。记住本课第一章讲过的：噪声可以模拟许多自然形状，比如山或海浪。这就是一个例子。

在进一步谈术语之前，先说一句：这个例子里某一层的频率与幅度由二的幂决定。把我们刚描述的想法形式化成伪代码，可以写成：


float noiseSum = 0; 
static const unsigned numLayers = 5;  //倍频程 
#if 0 
for (unsigned i = 0; i < numLayers; ++i) { 
    // 改变频率与幅度
    noiseSum += noise(P * pow(2, i)) / pow(2, i); 
} 
#else 
// 或者这样写
float amplitude = 1; 
float frequency = 1; 
for (unsigned i = 0; i < numLayers; ++i) { 
    // 改变频率与幅度
    noiseSum += noise(P * frequency) * amplitude; 
    amplitude *= 0.5;  //1, 0.5, 0.25, 0.0625, ... 
    frequency *= 2;  //1, 2, 4, 8 ... 
} 
#endif

造这个图案要用多少层？这里有个技术上的答案，我们只简单看一下。当输入值的频率变高时，噪声函数的结果很可能又变成白噪声（见本课第一章关于噪声性质的部分），这是我们要避免的。你可以想加多少层就加多少层，直到输入值的频率把噪声函数的结果变成白噪声为止。这就引出另一个问题：我们知道这什么时候发生吗？理论上知道，我们可以算出这何时发生。这由走样的规则决定，那是个复杂而庞大的主题。关于此的解释见走样与过滤一课（基础部分），噪声第二课里有对噪声过滤的基础介绍。

理论如此。实践上（当我们用这门技术做电影时），我们很少用超过 3 层或 5 层（有时到 7 层）。原因有几个。首先，计算噪声代价高。所以你用的层数越多，计算时间越长。另一个主要原因是，当我们加到超过 5 层或 7 层之后，这些层对结果的贡献可能已不明显，因为到那个阶段它们的幅度已经很小。如果更多层既不带来明显差别、计算又依然昂贵（除非你把噪声图案放大来看），那我们该用超过 5 层吗？

理想情况下，你要在理论与实践之间找折中。完美的代码会在发现下一层输入值的频率会导致白噪声时自动停止叠加（关于在变成白噪声之前截断层数的函数示例，见走样一课）。自动系统仍可能导致层数非常多，代价可能很高。让用户用输入参数控制所使用的最多层数，默认设为 3、5 或 7。

术语

现在说些术语。把频率与幅度相互关联的噪声层相加，这门技术可以叫分形和。用这门技术制造分形曲线（或曲面）并不限于计算机图形学。它看起来很像一条表示股市在某段时期内走势的曲线。Benoit Mandelbrot 研究过这些曲线及其数学表示，他是一位以研究分形图案（尤其应用于金融）而闻名的数学家。这里我们只限于介绍几个技术名词。不过对这个主题感兴趣的读者可以读分形一课（这本身就是一个相当庞大而迷人的题目）。现实世界中的许多东西——风景、海景、云、植物，乃至股市的走势等——都具有分形的性质。

当分形噪声相继各层的幅度与其频率成反比时，用来描述该结果的术语是粉红噪声。把它写成公式，可以写作：


float pinkNoise = 0; 
static const unsigned numlayer = 5; 
float rateOfChange = 2.0f; 
for (unsigned i = 0; i < numLayers; ++i) 
{ 
    // 改变频率与幅度
    pinkNoise += noise(P * pow(rateOfChange, i)) / pow(rateOfChange, i); 
}

更具体地说，相继各层之间频率与幅度的变化几乎构成了所得噪声曲线的签名。它定义了该曲线的频谱性质。我们用谱密度这个术语来描述所得噪声由哪些频率（层）组成。而这些层各自都有一个特定的幅度，我们称之为功率谱。幅度与频率可以相互关联，比如粉红噪声那样，也可以不关联。你也可能让相继各层之间的频率变化存在某种关系。这些观察对在计算机图形学中制造许多图案至关重要，我们建议你在读其他讲图案生成的课程之前先把它理解透。

我们可以把一系列频率相关的基​​本噪声相加，从而造出一个复杂的噪声函数（分形和）。一层的频率与它的幅度也是相关联的。既然能这样做，反过来也许同样可行：即我们可以拿一个看似分形的信号，把它分解成更具体的噪声函数，从而找出相邻两层之间的频率比（该信号由哪些不同频率组成，这些频率之间如果存在关系又是什么关系），以及每一层的频率-幅度比。这样做就能确定该信号的频谱性质。这一观察对开发特别是模拟海面的算法至关重要。假定我们知道自然界某些图案的谱密度，那么我们就能用计算机重建它们，得到相似的图案（这个过程与声学中的频谱建模合成概念完全一致）。这个很妙的观察至少从 80 年代中期起就在 CG 中被广泛使用。

名称里的 noise（粉红噪声）有误导性，因为它指的是一组频率与幅度相互关联的噪声函数之和。倍频程一词有时也被（误）用来代替「层」这个词。层比倍频程更通用，后者在音乐里也用。一个倍频程是频率的加倍或减半。如果它在程序（或文献）中被使用，那就意味着分形和计算中每个相继层的频率是前一层的两倍。也就是说，我们公式里的变化率一项会取值 2。如果相继各层之间的频率比不等于 2，这个词就不准确，应该改用「层」。当我们把逐层频率加倍、且这些层的幅度与其频率成反比时，就得到一种特殊类型的粉红噪声，称为布朗噪声（以数学家 Robert Brown 命名）。


float brownianNoise = 0; 
const unsigned numlayer = 5; 
float rateOfChange = 2.0f; 
for (unsigned i = 0; i < numLayers; ++i) 
{ 
    // 改变频率与幅度
    brownianNoise += noise(P * pow(rateOfChange, i)) / pow(rateOfChange, i); 
}

在计算机图形学中，你常会发现分形函数被称为 fBm（即分数布朗运动）。CG 界从数学领域借用了这些术语的大部分，主要作为一种便利的标签，用来以通常更简化、更直白的形式称呼使用这些技术的函数。在 fBm 函数的通用形式里，一层的幅度不必与其频率成反比。你可以用两个值来控制频率与幅度如何逐层变化。间隙度一词用来控制频率逐层变化的速率。间隙度在分形中有特定含义（更多信息见分形一课）。幅度逐层的变化率没有官方术语；在下面的 fBm 函数伪代码里，我们称之为 gain：


float fBm(Vec3f P, float lacunarity = 2, float gain = 0.5, int numLayers = 5) 
{ 
    float noiseSum = 0; 
    Vec3f Pnoise = P; 
    float amplitude = 1; 
    for (unsigned i = 0; i < numLayers; ++i) 
    { 
        // 改变频率与幅度
        noiseSum += noise(Pnoise) * amplitude; 
        Pnoise *= lacunarity; 
        amplitude *= gain; 
    } 
 
    return noiseSum; 
}

一维噪声的这些基本概念建立之后，我们看看把同样的技术用在二维噪声上会发生什么。

二维噪声示例

为了让程序更好用，我们先写一个简单的通用函数，它遍历图像的所有像素并由此算出一个二维位置。像素颜色根据该点的噪声函数设定。这个函数是个模板，以一个噪声函数作为参数。我们就在这个噪声函数里实现计算各种图案的代码（完整例子请下载源码）。


template&ltNoiseFunc N> 
void createNoiseImage(const char *filename) 
{ 
    unsigned imageWidth = 512, imageHeight = 512; 
    float invImageWidth = 1. f / imageWidth; 
    float invImageHeight = 1.f / imageHeight; 
    float noiseFrequency = 5; 
    float *imageBuffer = new float[imageWidth * imageHeight]; 
    float *currPixel = imageBuffer; 
    for (unsigned j = 0; j < imageHeight; ++j) { 
        for (unsigned i = 0; i < imageWidth; ++i) { 
            Vec2f P(i * invImageWidth, j * imvImageHeight) * noiseFrequency; 
            *currPixel = (*N)(P); 
            currPixel++; 
        } 
    } 
    saveImage(filename, imageBuffer, imageWidth, imageHeight); 
    delete [] imageBuffer; 
}

第一个例子很简单。为了演示程序的用法并测试我们的噪声函数，我们先输出一张简单的噪声图像。

分形和

第二个例子演示我们已在一维情形讲过的分形和。我们累加五层噪声的贡献。在每个相继层之间，我们把上一层点的频率乘以二，把上一层的幅度除以二。

下面是得到的图像以及计算这个结果的代码（代码已经稍作优化。我们本可以用 pow(2, k) 函数来改变噪声函数的频率与幅度。但这个函数相对较慢，我们可以用对频率（2）与幅度（0.5）参数的递归相乘来替代它：


unsigned numLayers = 5; 
float maxNoiseVal = 0; 
for (unsigned j = 0; j < imageHeight; ++j) { 
    for (unsigned i = 0; i < imageWidth; ++i) { 
        Vec2f pNoise = Vec2f(i, j) * frequency; 
        float amplitude = 1; 
        for (unsigned l = 0; l < numLayers; ++l) { 
            noiseMap[j * imageWidth + i] += noise.eval(pNoise) * 2; 
            pNoise *= 2; 
            amplitude *= 0.5; 
        } 
        if (noiseMap[j * imageWidth + i] > maxNoiseVal) maxNoiseVal = noiseMap[j * imageWidth + i]; 
    } 
}

注意，由于我们叠加了若干层噪声，结果可能大于 1，这在把该值转成像素颜色时会成问题。我们可以在转成像素颜色时对值做钳制。不过更好的做法是归一化这些噪声值：把数组里所有值除以算出的最大值。为此，我们在计算噪声图中所有条目的过程中把最大值存进 maxNoiseVal 变量。等所有值都算完后，再把它们统统除以 maxNoiseVal（第 12 行）。

如前所述，分形和能造出可信的地形以及许多其他自然图案（海景、风景等）。我们可以很容易地造一张二维纹理来置换网格（图 3）。更多细节见纹理合成、地形生成以及海面建模几课。

在代码里，你可以试着改变频率与幅度乘数做实验，把你的分形噪声函数变成我们前面描述过的更通用的 fBm 函数。

改变间隙度与 gain 的值可以实现许多不同的外观，如图 4 所示。


ValueNoise noise; 
float frequency = 0.02f; 
float frequencyMult = 1.8;  //间隙度 
float amplitudeMult = 0.35; 
unsigned numLayers = 5; 
float maxNoiseVal = 0; 
for (unsigned j = 0; j < imageHeight; ++j) { 
    for (unsigned i = 0; i < imageWidth; ++i) { 
        Vec2f pNoise = Vec2f(i, j) * frequency; 
        float amplitude = 1; 
        for (unsigned l = 0; l < numLayers; ++l) { 
            noiseMap[j * imageWidth + i] += noise.eval(pNoise) * amplitude; 
            pNoise *= frequencyMult; 
            amplitude *= amplitudeMult; 
        } 
        if (noiseMap[j * imageWidth + i] > maxNoiseVal) maxNoiseVal = noiseMap[j * imageWidth + i]; 
    } 
} 
for (unsigned i = 0; i < imageWidth * imageHeight; ++i) noiseMap[i] /= maxNoiseVal;

湍流

湍流是建立在与分形和相同原理上的函数。不过，我们不是每一层都直接用噪声函数，而是用有符号噪声的绝对值。我们先把噪声的结果转成有符号噪声，再对这个结果取绝对值。如下图所示，处理后的噪声函数形成一个由凸起构成的轮廓。凡是曲线为负的地方（黑线），我们就沿 x 轴把这些区域的曲线镜像过来。红线曲线就是结果。用二维噪声配合这门技术，可以产生适合模拟火焰、烟或云的图案。


ValueNoise noise; 
float frequency = 0.02f; 
float frequencyMult = 1.8; 
float amplitudeMult = 0.35; 
unsigned numLayers = 5; 
float maxNoiseVal = 0; 
for (unsigned j = 0; j < imageHeight; ++j) { 
    for (unsigned i = 0; i < imageWidth; ++i) { 
        Vec2f pNoise = Vec2f(i, j) * frequency; 
        float amplitude = 1; 
        for (unsigned l = 0; l < numLayers; ++l) { 
            noiseMap[j * imageWidth + i] += std::fabs(2 * noise.eval(pNoise) - 1) * amplitude; 
            pNoise *= frequencyMult; 
            amplitude *= amplitudeMult; 
        } 
        if (noiseMap[j * imageWidth + i] > maxNoiseVal) maxNoiseVal = noiseMap[j * imageWidth + i]; 
    } 
} 
for (unsigned i = 0; i < imageWidth * imageHeight; ++i) noiseMap[i] /= maxNoiseVal;

大理石纹理

大理石纹理可以通过用噪声函数或分形和调制正弦图案的相位来制造。这里的思路不是直接用噪声函数生成图案，而是扰动我们用来生成图案的那个函数。在本例中，我们用一个分形和来改变或偏移正弦函数的相位。这个思路能给任何周期函数或规则函数引入随机性。我们的例子很简单，只画出一张黑白大理石纹理。不过，如果在混合中引入一些颜色，也许能造出更真实的图案。纹理合成一课含有更进阶的例子。


float frequency = 0.02f; 
float frequencyMult = 1.8; 
float amplitudeMult = 0.35; 
unsigned numLayers = 5; 
 
Vec2f pNoise = Vec2f(i, j) * frequency; 
float amplitude = 1; 
float noiseValue = 0; 
// 计算一些分形噪声
for (unsigned l = 0; l < numLayers; ++l) { 
    noiseValue += noise.eval(pNoise) * amplitude; 
    pNoise *= frequencyMult; 
    amplitude *= amplitudeMult; 
} 
noiseMap[j * imageWidth + i] = (sin((i + noiseValue * 100) * 2 * M_PI / 200.f) + 1) / 2.f;

木材纹理

与大理石纹理一样，木材也靠一个简单的技巧。思路是把噪声函数乘以一个大于 1 的值。我们把这个乘法的结果叫 \(g\)（历史上它被称为 \(g\)，取自木材纹理的指代）。纹理是通过从 \(g\) 中减去它的整数部分得到的。把一个正的浮点数转成整数，得到的整数必然小于或等于 \(g\)。因此，这个减法的结果在 [0:1) 范围内（不含 1）。图 6 说明了这个过程。在这个例子里，我们把噪声函数乘以 4。蓝线表示 \(g\) 的值，红线表示从 \(g\) 中减去其整数部分的结果。把噪声函数乘以大于 4 的值，红线会出现更多断裂。在二维中，这些断裂标出较亮与较暗颜色区域之间的边界（见下图）。


float g = noise.eval(Vec2f(i, j) * frequency) * 10; 
noiseMap[j * imageWidth + i] = g - (int)g;
