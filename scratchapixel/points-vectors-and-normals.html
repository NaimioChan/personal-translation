点、向量与法线

阅读时间：15 分钟。

几何是数学的一个分支，研究形状、大小、图形之间的相对位置以及空间的性质。

为什么这门课重要，你会学到什么

本课内容相当全面，对很多人来说可能是个挑战，尤其如果你是图形学新手。不过也有好消息，下面是值得深入这门课的理由：

1）计算机图形学的起点：许多教科书建议从几何的理论部分学起，我们却不这么看。先从「面向初学者的 3D 渲染」这一部分入手，把脚伸进计算机图形学的世界。这样你能更互动地接触材料，也能看到这些理论在生成有趣图像时的应用。简而言之，我们建议先去探索、先去创作，然后再回头补底层的几何。这种做法能避开一个坑：被理论压住，却看不到它的实际用途。

2）来自一线制作老手的指引：本课的深度与清晰度来自作者，他们带来了多年的一线制作经验。本内容之所以与众不同，一个关键原因是它关注行业惯例和实操细节，而这些常被传统教学资料一带而过，其中包括矩阵记法的细节和笛卡尔坐标系的表示方式。我们的贡献者在专业场合里摸爬滚打过图形学的复杂之处，也体会过在没有指导的情况下把这些基础概念拼凑起来的困难。他们的经历——在职业压力中自学的一路——促成了本课这种全面的写法。我们希望替你省掉孤立地学这些关键概念时伴随的困惑与挫败。通过分享源自大量经验的洞见，我们为你在图形学的迷宫里指出一条更清楚的路，让你受益于只有一线老手才有的、来之不易的知识。

3）掌握必要技能：学完本课，你将掌握渲染、着色和图形学编程所需的大部分工具与概念，包括对向量、点、法线、矩阵的透彻理解，以及如何用三角函数操作这些元素。矩阵行列式、四元数、绕任意轴旋转等方法因复杂度较高，留到专门的课程里讲，但你依然能拿到 CG 编程所需的约 80% 的几何知识。后续课程会深入矩阵行列式和四元数，进一步拓宽你的理解。

完成本课，你就在通往计算机图形学的路上迈过了一个重要里程碑，也有了应对更复杂主题与项目的扎实基础。

几何基础

在计算机图形学领域，理解点、向量、矩阵和法线，就像写字要认识字母一样基础。因此，大多数图形学教材都从线性代数和几何讲起。但一上来就啃复杂的数学概念，对急着想了解图像如何生成的人来说会很吓人。如果一想到要碰数学或者「矩阵」这个概念，你就对学图形学编程打起了退堂鼓，那先别急着放弃。

「3D 渲染基础」这一段，我们安排的课程并不预设你有线性代数背景，而是有意选择一种不那么传统的 CG 编程教学方式。这样你能尽早做点实际又有趣的事，比如写一个只需要很少数学和一些编程知识的基础光线追踪器。动手搭建渲染器是学数学的一种生动又令人满足的方式，各种概念用上去的效果能立刻以画面反馈给你（比如你渲染出的图像）。不过必须明白：点、向量和矩阵在生成图形学图像中起关键作用，后面的课程会大量依赖它们。

本课旨在揭开这些元素的面纱，讲清它们的功能，并介绍操作它们的方法。本课还会说明 CG 研究者多年来在解决问题和写代码时采用的各种线性代数惯例。熟悉这些惯例很有必要，因为文献和网上资料常常略过它们。在看别人的代码或方法之前，先确认他们用的是哪套惯例，这一点至关重要。

对数学倾向很强的读者，这里插一句：你可能会觉得本课收进了一些并非严格属于线性代数的概念，这有些不寻常。我们的目标是扩大课程范围，把图形学中常用的基础数学技巧都涵盖进来，哪怕它们与向量、矩阵只有间接关系。比如从严格的数学角度看，点并不属于线性代数（线性代数只研究向量）。但我们仍然要讲点，因为它在图形学中太常见，而且操作它用的是类似的数学手段。如果你还没弄清点与向量的区别，别担心——这一章会详细展开。

什么是线性代数？向量入门

线性代数是数学中一个关键领域，研究向量及其操作。你可能会问：「向量到底是什么，它在计算机图形学（CG）里为什么重要？」简单说，向量可以看作一串或一组数，长度可变，数学家常称之为元组（tuple）。描述向量的大小时，我们用「n 元组」这个说法，其中「n」表示向量的元素个数。例如一个含六个元素的向量，用数学记号写作：

$$V = (a, b, c, d, e, f),$$

其中 a、b、c、d、e、f 各自是实数（比如 1、3、4.56、-11、-13.08、0 等等）。

把这些数组织成一个向量，是为了表达某个在问题语境中有意义的值或概念。在 CG 领域，向量作用关键，因为它可以表示空间中的位置或方向。此外，向量可以接受变换——一组强大而简洁的运算，用来改变它们的值。这些变换称为线性变换，是 CG 中修改向量属性的基本工具。后续讨论中我们会更深入地讲变换，但先要明白它在图形学中应用与理论上的关键地位。

点与向量

在计算机图形学领域，点与向量这两个概念都起基础作用，各自在三维空间中有不同用途。

一个点本质上是三维空间中的一个具体位置。它标记一个精确的地点，不指示任何方向或大小。这就像在地图上指出一个位置，你关心的是这个地点本身，而不是从别处过来的方向或距离。

相反，向量在同一三维空间中同时表示方向与大小（或长度）。向量可以想象成从一处指向另一处的箭头，表示从起点（原点）到终点的行进方向，以及这两点之间的距离。三维点与向量都用前面介绍的元组记法表示：

$$V = (x, y, z),$$

其中 \(x\)、\(y\) 和 \(z\) 是实数，定义该向量在空间中的方向与大小。

要注意，向量与点的解释在不同科学领域差别很大。比如数学家和物理学家往往对这两个概念持更一般化的看法，在他们的语境里，向量可以包含任意多甚至无穷多个元素，远远超出图形学常用的三维范围。

本章末尾会提到齐次点的概念。对于某些数学运算，比如矩阵乘法，在点的记法里引入第四个元素会很方便，由此得到齐次坐标：

$$P_H=(x, y, z, w).$$

齐次点为图形学中的某些变换与运算提供了便利。它乍看可能复杂，随着课程推进，它的用处会越来越清楚。这里提到它，是为了让你在文献里遇到时不至于困惑，后面会深入讨论。

变换速览

下面看看平移和旋转这类线性变换如何作用于计算机图形学（CG）中的点与向量，从而简化它们在三维空间中的操作。

平移是一项基本操作，把点移到空间中的其他位置。平移一个点，指的是把它从一处挪到另一处，不改变朝向或大小。这个操作就像把物体拿起来放到别处。但平移不能以同样方式作用于向量，因为向量的本质在于方向与大小，而不在起点位置。所以，在不改变方向和长度的前提下移动一个向量，它仍是同一个向量，无论放在空间哪里。

对向量来说，旋转是更相关的变换。旋转一个向量会改变它的方向，同时保持起点和大小不变。这个操作就像让一个箭头绕空间中某点转动：箭头指向新方向，但长度和起点保持不变。

这些概念的简单表示如下：

  • 点的变换：\(P \rightarrow \text{Translate} \rightarrow P_T\)

  • 向量的变换：\(V \rightarrow \text{Rotate} \rightarrow V_T\)

下标 \(T\) 表示原有点或向量「变换后」的版本。

还有一个方面我们没谈：向量的大小或长度在 CG 中意味着什么。向量的长度很关键，因为它决定了沿给定方向延伸多远。当向量长度恰为 1 时，称它已被归一化，方向不变，大小被缩放到单位长度。归一化在 CG 中是常见要求，用于简化计算、保证不同运算之间的一致性。不过在有些情形下保留向量原始长度更有用，比如当这个向量表示两点之间的具体距离时（例如从点 \(A\) 到点 \(B\)），它同时给出方向与两点间的间隔量。

归一化向量有时并不好处理，做错就会引入错误。因此始终要注意：根据用途判断这个向量该不该归一化。每次使用向量时问一句它是否已归一化，能帮你避开常见的坑，让你的 CG 运算得到预期结果。

法线

在计算机图形学与几何中，法线这个概念对于定义曲面在某点处的朝向至关重要。曲面上一点 \(P\) 处的表面法线，本质上是一个垂直于该点切平面的向量。也就是说，它直指离开曲面的方向，表明曲面在三维空间中的朝向。

法线在着色过程中不可或缺。着色这项技术根据场景中的光源来决定表面明暗与颜色。借助法线理解曲面的朝向，图形学算法就能准确模拟光照对物体各部位的作用，为渲染出的场景增添真实感与深度。

要注意，法线虽然和向量一样有方向与大小，但在变换处理上不同于向量。这种区别来自：法线与光影的交互方式取决于它相对于光源的朝向，而不只是它在空间中的位置。因此，变换法线时需要特殊考虑，才能在物体被移动或改动之后，仍保持其表面正确的光照效果。

法线如何变换，将在专门讲法线变换的章节里进一步探讨。眼下，理解法线是垂直于曲面的向量、以及它在着色中的作用，就为图形学中光照与渲染的更进阶主题打下了基础。

从理论到 C++

在 C++ 代码里，用一个 Vec3 类同时表示点、向量和法线，是处理这些不同但相关的几何实体的简洁做法。这种统一表示与 OpenEXR 等口碑良好的库的做法一致，兼顾效率与代码简洁。用一个类而不是为点、向量、法线各设一个类，是一个设计取舍：以更低的代码复杂度换取语义出错的可能。


template&lttypename T> 
class Vec3 
{ 
public: 
    // 初始化向量的 3 种最基本方式
    Vec3() : x(T(0)), y(T(0)), z(T(0)) {} 
    Vec3(const T &xx) : x(xx), y(xx), z(xx) {} 
    Vec3(T xx, T yy, T zz) : x(xx), y(yy), z(zz) {} 
    T x, y, z; 
}; 
 
typedef Vec3&ltfloat> Vec3f; 
 
Vec3&ltfloat> a; 
Vec3f b;

你描述的 Vec3 模板类可以方便地用不同数据类型（如 float、int、double）实例化，从而适应图形应用中对各种精度的需求。这个类的结构允许用默认值 0 或分别为每个轴指定值来初始化一个三维实体，为不同用例提供灵活性。

下面简要拆解这个类的结构及其含义：

  • 模板参数 ：这种设计让类可以用任意数值类型实例化，因此可以按应用的精度需要，把 Vec3 与 float、int、double 等一起使用。

  • 构造函数：类中提供三个构造函数，实现多种初始化方式：

    • 默认构造函数把各分量初始化为 0，适合创建零向量。

    • 单值构造函数把各分量初始化为同一个值，适合创建各方向取值相同的向量。

    • 三值构造函数允许分别指定每个分量，灵活性最高。

  • 公有成员 x、y、z：直接访问向量（或点、或法线）的分量简化了代码的操作与阅读，但需要小心处理，以便在不同语境中清楚区分这些实体的用法。

用单个 Vec3 类表示点、向量和法线可以简化代码库，但也要求使用时有纪律。具体来说，做变换时必须记住点（空间中的位置）、向量（方向与大小）与法线（垂直于曲面的朝向）在语义上的差别，才能保证计算正确。例如平移这类变换会影响点，却不会以同样方式影响向量或法线；而旋转可能影响向量和法线，却不影响点。

采用这种做法意味着某些运算——尤其是变换——可能需要专门的处理或额外的函数，才能正确判断 Vec3 实例在给定语境中扮演的角色。这一设计决定凸显了清晰文档的重要性，也说明最好有辅助函数或方法来封装「按预期语义正确变换这些实体」的复杂性。

小结

这一章为计算机图形学（CG）的关键概念打下基础，着重讲了向量、点及其在三维空间中变换的数学与实践层面。以下是所涵盖要点的简明小结：

  • CG 中的向量被定义为在三维空间中表达方向的实体，用三个数值表示。这一定义比数学中更宽泛的向量观（可存在于任意维度）收窄了范围。

  • 点被理解为三维空间中的具体位置，同样用三个数表示。点与向量的这一区别在 CG 中是根本性的，它影响二者在建模与变换中的用法。

  • 齐次点是点概念的扩展，用四个数而不是三个数表示。它是一种特殊情形，便于某些数学运算，比如涉及透视投影的变换，后面会更详细地探讨。

  • 本课引入了线性变换的概念，作为修改点与向量的手段。这些变换包括平移（用于点）和旋转（用于向量）等操作。线性变换的原理在于，它保持被修改实体的线性与几何性质，比如直线与平面。

  • 向量的归一化被强调为一种把向量长度调整为 1、同时保持方向的过程。向量的原始长度在某些算法中可能很关键，因为它代表两点之间的距离。

本章还提示了理解点与向量如何处于某个坐标系之中的重要性——坐标系是一个框架，用于精确定义和操作空间中的点与向量。坐标系充当参照或原点，对解释那些在二维和三维语境中定义点与向量的三个数至关重要。
