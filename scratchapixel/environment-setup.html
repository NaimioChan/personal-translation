一切准备就绪！

阅读时间：3 分钟。

本课仍在编写中（2024 年 2 月），目前正在完善。

Scratchapixel 的教学方式——提供自包含、易于编译的程序——是有好处的，但许多刚接触计算机图形学和编程的人可能并不知道怎么编译、运行这些程序。我们想在这里把这件事说清楚。

我们会用什么编程语言？

我们所有的示例程序都用 C++ 编写。Swift、Objective-C、Rust、Go、C# 这些语言虽然也流行，但 C++ 仍是图形应用中最常用的语言。一旦上手，它就会成为一件非凡的工具。

Scratchapixel 并不是学 C++ 的平台，而且书籍和网络上现成的资源非常充足，所以这里不展开讲。我们建议你在网上搜搜推荐，找到适合自己需要的资源（如果有的话，最好用你的母语资料）。我们非常赞成你去买一本书——对，就是那种有印刷书页、能塞进包里随身带的厚实物件。

Windows、macOS 与 Linux

我们的示例绝大多数（即便不是全部）是在 Windows 系统上测试的。不过，我们编译程序的方式在 macOS 和 Linux 上同样可用。我们不用 Microsoft Visual Studio 这类工具来写代码和编译，而是用一个简单的文本编辑器。编译方面，我们使用终端（Windows 上用 GitBash；终端本来就是 Linux 和 macOS 环境的一部分）以及 gcc 或 clang（我们更偏爱后者）这样的跨平台编译器。

硬件

任何一台电脑都够用。你不需要 GPU，有 CPU 就行。如果预算紧张，可以考虑树莓派，不过你仍然需要屏幕、键盘、鼠标等外设。

软件

Windows

  • 在你的电脑上安装 Git，以获得 GitBash 终端。

  • 安装 Microsoft Visual Studio。Community 版本免费。虽然我们不会直接用它，但 MS Visual Studio 带有编译所需的 C/C++ 头文件与库。安装时务必勾选 C/C++ 相关选项。

  • 挑一个你喜欢的文本编辑器。我们推荐 Notepad++。

  • 我们建议下载 clang++ 作为你的编译器。

MacOS

  • 安装 Xcode，它包含 clang++。MacOS 基于 Unix，终端是系统自带的。

Linux

如果你用的是 Linux，多半已经装好了编译器，也知道怎么用终端。

测试你的工作环境

  • 打开一个终端。

  • 进入你想写代码的目录：

    
cd c:/Users/Romeo/Desktop/dev

  • 用你选好的文本编辑器新建一个名为 test.cc 的文件，内容如下：

    
#include &ltiostream>

int main() {
    std::cerr << "Hello world!" << std::endl;
    return 0;
}

  • 编译这个程序：

    
clang++ -o test.exe test.cc

  • 用 ./test.exe 运行程序。
