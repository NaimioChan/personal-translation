三维密度场的体积渲染

阅读时间：26 分钟。

到目前为止，我们只学了如何渲染均匀的体积物体。也就是散射系数与吸收系数在空间中处处不变的物体。这没问题，但有点无聊，自然界里的东西也不长这样。如果你看蒸汽火车冒出的烟云，这些体积是非均匀的。有些部分比其他部分更不透明。那么我们怎么渲染非均匀的体积物体呢？

在现实世界里，我们会说吸收系数或散射系数随空间变化。吸收系数越高，体积越不透明。而散射与吸收可以彼此独立地随空间变化。不过我们一般选择更实用的做法：对一个给定的体积物体，散射系数与吸收系数都取常数值，改用密度参数来调制体积在空间中的外观。想象密度参数（编程里不过是个 float 或 double 这样的实数）随空间变化。那我们就可以这么做：

$$ \sigma_s' = \sigma_s * density(p)\\ \sigma_t = (\sigma_s + \sigma_a) * density(p)$$

其中 \(\sigma_s'\) 就是被随空间变化的密度参数调制后的散射系数。Beer 定律中使用的消光系数 \(\sigma_t\)（即吸收系数与散射系数之和），同样也被随空间变化的密度参数调制。而 \(density(p)\) 是一种函数，返回空间点 p 处的密度。这样做，我们就能渲染出上图那样火山烟羽的体积物体图像。

现在的问题是，这个密度场怎么生成？可以用两种技术：

1. 过程式：你可以用 3D 纹理，比如 Perlin 噪声函数，以过程式的方式生成随空间变化的密度场。

2. 模拟：你可以用流体模拟程序，模拟流体（比如烟）的运动，同样能生成随空间变化的密度场。

本章我们用第一种做法。下一章我们学习如何渲染流体模拟的结果。

用噪声函数生成密度场

本课中我们将用 Perlin 噪声函数以过程式方式生成 3D 密度场。如果你不熟悉过程式噪声生成这个概念，我们建议你读下面两门课：值噪声与过程式图案（第 1 部分）以及Perlin 噪声（第 2 部分）。

什么是过程式噪声函数（这里指 Perlin 噪声函数）？它是一个函数（取「函数」在编程上的意义），通过 3D 空间以过程式方式生成噪声图案。我们可以用这个图案生成数值随空间变化的密度场。噪声函数以一个点为参数，返回该点处 3D 噪声纹理的值（一个 float 或 double 之类的实数）。该值被限定在 [-1,1] 范围内。密度可以是 0（没有体积）也可以是正值，所以我们需要对噪声函数的取值做截断或重映射，才能得到正的密度值。下面这段代码把取值从 [-1,1] 重映射到 [0,1]：


float density = (noise(pSample) + 1) * 0.5;

其中 pSample 是我们步进穿过体积时、沿相机光线的采样点位置。

噪声函数方面，我们将使用 Ken Perlin 本人提供的改进版 Perlin 噪声实现（链接）。同样，如果你感兴趣，可以在专门讲 Perlin 噪声（第 2 部分）的那门课里学到这段代码如何以及为何能工作。但在本课中，我们假定你熟悉这个函数。如果不熟，也不必太担心。你只需知道：把你想求值的 3D 空间点的位置传给这个函数，它就会为该点返回一个 [-1,1] 范围内的值。下面把代码列出来供参考（完整实现见源代码部分提供的文件）：


int p[512]; // 排列表（见源代码）
 
double fade(double t) { return t * t * t * (t * (t * 6 - 15) + 10); }
double lerp(double t, double a, double b) { return a + t * (b - a); }
double grad(int hash, double x, double y, double z)
{
    int h = hash & 15;
    double u = h&lt8 ? x : y,
           v = h&lt4 ? y : h==12||h==14 ? x : z;
    return ((h&1) == 0 ? u : -u) + ((h&2) == 0 ? v : -v);
}
 
double noise(double x, double y, double z)
{
    int X = (int)floor(x) & 255,
        Y = (int)floor(y) & 255,
        Z = (int)floor(z) & 255;
    x -= floor(x);
    y -= floor(y);
    z -= floor(z);
    double u = fade(x),
           v = fade(y),
           w = fade(z);
    int A = p[X  ]+Y, AA = p[A]+Z, AB = p[A+1]+Z,
        B = p[X+1]+Y, BA = p[B]+Z, BB = p[B+1]+Z;
 
    return lerp(w, lerp(v, lerp(u, grad(p[AA  ], x  , y  , z   ),
                                   grad(p[BA  ], x-1, y  , z   )),
                           lerp(u, grad(p[AB  ], x  , y-1, z   ),
                                   grad(p[BB  ], x-1, y-1, z   ))),
                   lerp(v, lerp(u, grad(p[AA+1], x  , y  , z-1 ),
                                   grad(p[BA+1], x-1, y  , z-1 )),
                           lerp(u, grad(p[AB+1], x  , y-1, z-1 ),
                                   grad(p[BB+1], x-1, y-1, z-1 ))));
}

非均匀参与介质的内散射

但愿看了图 4，你就能体会到问题在哪。对均匀体积物体，处理光线时我们要做的只是求出采样点沿光照方向到物体边界的距离。然后用这个距离（记作 Dl）和体积的消光系数（sigma_t = sigma_a + sigma_s）套 Beer 定律，算出光穿过体积到达采样点之后还剩多少（有多少被透射）。简单：


Color lighRayContrib = exp(-Dl * sigma_t * density) * lightColor;

非均匀体积的问题在于，这个做法不再成立，因为密度沿光线也在变化，这在图 4 里看得出来。注意：我们并不是在解第 2 章用正向光线步进解过的那个问题。我们迄今用光线步进，是为了估计沿相机光线的内散射项，仅此而已。但光线步进技术在这里又会派上用场：既用来估计内散射项，也用来估计相机光线与光线穿过非均匀参与介质时的透射率。问题不同（估计内散射 vs 估计光线的透射率），技术相同（本例中是正向光线步进，它是随机采样方法的一种形式）。我们需要把光线切成一系列线段，估计每一段的透射率，假定在该线段长度内（即步长所定义的小体积元素内）体积元素的密度是均匀的，然后随着沿光线推进，把总透射值乘以该采样点的透射率。写成伪代码，可以这样实现：


// 计算非均匀介质中的光线透射率
float transmission = 1;
float stepSize = Dl / numSteps;
for (n = 0; n < numSteps; ++n) {
    float t = stepSize * (n + 0.5);
    float sampleAtt = exp(-density(evalDensity(t) * stepSize * sigma_t);
    transmission *= samplAtt;
}

这两段代码做的事是一样的。有一个小小的数学技巧我们可以利用，只是到如今才讲（因为现在正是讲它的好时机）。就是这个：

$$e^a * e^b = e^{a + b}.$$

如果你看代码，可以看到透射值本质上是一串相互相乘的指数。若把光线步进循环（第 2 段代码）展开，会得到类似这样的东西：


// dx = stepSize，noise(x) 的取值在 [0,1] 范围内
float t0 = dx * (0.5); // n = 0
float t1 = dx * (1 + 0.5); // n = 1
float t2 = dx * (2 + 0.5); // n = 2
...
float transmission = exp(-dx * sigma_t * noise(t0)) *  
                     exp(-dx * sigma_t * noise(t1)) * 
                     exp(-dx * sigma_t * noise(t2)) * 
                     ...;

若用我们刚学到的指数性质重写这段代码，就得到：


float tau = noise(t0) + noise(t1) + noise(t2) + ...;
float transmission = exp(-tau * sigma_t * dx);

换句话说，沿光线步进时（跟处理相机光线时一模一样），我们只需把沿光线各采样点处的密度值累加起来，再用这个和去调用一次指数函数，就得到光线的衰减/透射值（这确实省了点时间）。这个概念如下图所示。

技术上讲，相机光线的透射值也可以这么算，但注意下面给出的代码里，我们在沿相机光线推进时用透射值去衰减 Li 项。随着穿过体积推进，我们需要光线透射的中间值，这就是为什么我们不像计算光线透射那样、只把密度累加进一个变量、最后再算最终的透射值。


float transmission = 1; // 设置相机光线的透射率（完全透射）
vec3 result = 0; // 相机光线的辐射亮度（从体积传播到眼睛的光能量）
for (n = 0; n < numSteps; ++n) {
    float t = t0 + stepSize * (n + 0.5);
    vec3 samplePos = ray.orig + t * ray.dir;
    float sampleDensity = evalDensity(samplePos);
    // 需要这个中间结果来衰减 Li 项（见下文）
    transmission *= exp(-sampleDensity * sigma_t * stepSize);
    // 内散射（Li(x)）
    if (density > 0 && hit_object-&gtintersect(...) {

        for (nl = 0;  nl < numStepsLight; ++nl) {

            tau += evalDensity(samplePosLight);

        float lightRayAtt = exp(-tau * sigma_t * stepSize);
        result += lightColor * lightRayAtt * sigma_s * ... * transmission;
    }
}

「tau」这个名字不是随便取的。文献里你常会看到它被用来表示一个叫光学深度的量。这个量常用两个希腊字母表示：tau（\(\tau\)）或 rho（\(\rho\)）。本章我们不给光学深度下正式定义，因为此刻那样可能会让人困惑。但我们在体积渲染：总结、公式/理论那一章里给了。

实用（且可运行）的实现

我们来对程序做必要的调整，演示这在实践中如何运作。记住算法现在是这样工作的：

1. 沿相机光线做光线步进。在相机光线上的每个采样点处，估计采样位置的密度，以计算采样点透射率并估计内散射贡献。

2. 沿光线做光线步进：以前我们只沿相机光线步进，现在还得沿光线步进。对均匀体积物体，我们只需沿相机光线步进以估计内散射项。而对非均匀体积，我们要沿相机光线步进来估计内散射项（这点不变），但现在还要沿光线求密度项。而且我们需要沿光线步进，以便也沿这些光线对密度函数求值。

换句话说，现在相机光线与光线都得步进，并在这些光线的每个采样点处对一个密度函数求值。目前是 Perlin 噪声函数。这是大量的运算，你会看到把球体作为非均匀介质来渲染会明显比均匀版本慢。


// [comment]
// 该函数现在由 integrate 函数调用，用来求
// 采样位置 p 处非均匀体积球体的密度。它返回该 3D 位置处 Perlin 噪声
// 函数的值，并重映射到 [0,1] 范围。
// [/comment]
float eval_density(const vec3& p)
{ 
    float freq = 1;
    return (1 + noise(p.x * freq, p.y * freq, p.z * freq)) * 0.5;
}

vec3 integrate(
    const vec3& ray_orig, 
    const vec3& ray_dir, 
    const std::vector<std::unique_ptr<Sphere>>& spheres)
{
    ...

    const float step_size = 0.1;
    float sigma_a = 0.5; // 吸收系数
    float sigma_s = 0.5; // 散射系数
    float sigma_t = sigma_a + sigma_s; // 消光系数
    float g = 0; // Henyey-Greenstein 非对称因子
    uint8_t d = 2; // 俄罗斯轮盘赌的「概率」

    int ns = std::ceil((isect.t1 - isect.t0) / step_size);
    float stride = (isect.t1 - isect.t0) / ns;

    vec3 light_dir{ -0.315798, 0.719361, 0.618702 };
    vec3 light_color{ 20, 20, 20 };

    float transparency = 1; // 透射率初始化为 1（完全透明）
    vec3 result{ 0 }; // 体积球体颜色初始化为 0

    // 主光线步进循环（正向，从 t0 步进到 t1）
    for (int n = 0; n < ns; ++n) {
        // 抖动采样位置
        float t = isect.t0 + stride * (n + distribution(generator));
        vec3 sample_pos = ray_orig + t * ray_dir;

        // [comment]
        // 求采样位置的密度（随空间变化的密度）
        // [/comment] float eval_density(const vec3& p)
        &ltspan style="color: red; font-weight: bold; background-color: rgba(255,0,0,0.1); border: 1px none rgba(255,0,0,0.3);"&gtfloat density = eval_density(sample_pos);</span>
        float sample_attenuation = exp(-step_size * density * sigma_t);
        transparency *= sample_attenuation;

        // 内散射。
        IsectData isect_light_ray;
        if (density > 0 && 
            hit_sphere-&gtintersect(sample_pos, light_dir, isect_light_ray) && 
            isect_light_ray.inside) {
            size_t num_steps_light = std::ceil(isect_light_ray.t1 / step_size);
            float stide_light = isect_light_ray.t1 / num_steps_light;
            float tau = 0;
            // [comment]
            // 沿光线做光线步进。把密度值累加进 tau 变量。
            // [/comment] float eval_density(const vec3& p)
            for (size_t nl = 0; nl < num_steps_light; ++nl) {
                float t_light = stide_light * (nl + 0.5);
                vec3 light_sample_pos = sample_pos + light_dir * t_light;
                &ltspan style="color: red; font-weight: bold; background-color: rgba(255,0,0,0.1); border: 1px none rgba(255,0,0,0.3);"&gttau += eval_density(light_sample_pos);</span>
            }
            float light_ray_att = exp(-tau * stide_light * sigma_t);
            result += light_color *       // 光的颜色
                      light_ray_att *     // 光线的透射值
                      phaseHG(-ray_orig, light_dir, g) * // 相位函数
                      sigma_s *           // 散射系数
                      transparency *      // 光线当前的透射值
                      stride *            // 黎曼和里的 dx
                      density;            // 采样位置处的体积密度
        }

        // 俄罗斯轮盘赌
        if (transparency < 1e-3) {
            if (distribution(generator) > 1.f / d)
                break;
            else
                transparency *= d;
        }
    }

    // 组合背景色与体积球体的颜色
    return background_color * transparency + result;
}

在这个实现里，相机光线与光线用的步长相同。这不必要。为了提速，你可以用更大的步长来估计光线的透射值。另外，既然我们用了过程式纹理，可能会遇到一些滤波问题。如果你对噪声函数采样的频率太低，可能会漏掉过程式纹理的一些细节，最终出现走样问题。这同样是滤波问题，我们这里不深入，但要知道步长、噪声频率与图像分辨率在某种意义上是相互关联的（从采样的角度看）。

你可能会惊讶程序输出（右图）看起来还不太像云。不过，正如噪声图案图像（左图）所示，构成噪声图案的「块」默认相当平滑，所以体积看起来也平滑。把过程式噪声做成云的样子这门手艺，需要用各种方式调整噪声函数的结果，才能得到视觉上更有意思的效果（我们后面会展示）。

虽然不起眼，但这正是 1997 年电影《超时空接触》片头那段壮观体积效果所用的技术。那些图像用 Pixar 的渲染器渲染，由 Sony Picture Imageworks 制作。那个片头在当时是一项巨大的技术工程。如前所述，他们用的技术与本课提供的一样。区别在于他们用了一些几何体（而不是基础球体）来定义体积物体的形状，并用一些分形图案给星云加上云状的质感。前一种技术我们会在本课最后一章（生产中的体积渲染）提到。至于云状质感，现在看看我们能做些什么……

摆弄密度函数（做出更有意思的外观与动画）

写一个光线步进器是一回事，做出云状的过程式纹理是另一回事。前者是一门科学，后者更关乎艺术：用一系列数学工具去塑造过程式纹理，花大量时间调参数，直到最终得到你满意的结果。我们这里的目标不是做出令人惊叹的图像，而是给你一些工具或砖块：第一帮你理解事情如何运作，第二让你最终能自己重新组合成更复杂的系统，做出「哇」的图像——如果你想的话。不过这交给你了……但如果你做出了什么酷东西，跟我们分享！

下面介绍几个技巧，可以用来做出更有意思的云状「球体」。这只是其中一小部分工具的挑选。

Smoothstep

smoothstep 函数你应该不陌生，我们已经在好几处用过它，包括噪声函数里。它在两个值之间制造「平滑」过渡。下面是该函数的一种实现：


float smoothstep(float lo, float hi, float x)
{
    float t = std::clamp((x - lo) / (hi - lo), 0.f, 1.f);
    return t * t * (3.0 - (2.0 * t));
}

我们可以用这个函数在球体边界附近制造衰减。为此，我们对 eval_density 函数做些改动，把球心与半径作为参数传进去。这样就能算出采样位置到球心的归一化距离，并用这个值来调整球体的密度，大致如此：


float eval_density(const vec3& sample_pos, const vec3& sphere_center, const float& sphere_radius)
{
    vec3 vp = sample_pos - sphere_center;
    float dist = std::min(1.f, vp.length() / sphere_radius);
    float falloff = smoothstep(0.8, 1, dist); // 距离从 0.1 到 1 时，从 0 平滑过渡到 1
    return (1 - falloff);
}

这个技巧同样有助于在体积到达球体边界之前把它淡出。我们用 smoothstep 函数控制衰减从离边缘或侧面多远的地方开始（以及最终结束，但对衰减效果来说，结束值应保持在 1）。

fBm

fBm（在旧日好时光里也叫 plasma 或「混沌」纹理）代表分形布朗运动（Fractal Brownian Motion）。在计算机图形学领域，它的含义与数学里不同。我们考虑的是它对我们图形工程师和艺术家意味着什么。它是一种分形图案，由若干层过程式噪声相加而成，各层的频率与振幅不同。你可以在过程式生成部分的课程里找到关于这种图案的一些信息。

一个典型 fBm 过程式纹理的代码可以这样构造：


float eval_density(const vec3& p, ...)
    vec3 vp = p - sphere_center;
    ...
    // 构建 fBm 分形图案
    float frequency = 1;
    vp *= frequency; // 必要时缩放初始点值
    size_t numOctaves = 5; // 层数
    float lacunarity = 2.f; // 相邻频率之间的间隔
    float H = 0.4; // 分形增量参数
    float value = 0; // fBm 的结果（用作我们的密度）
    for (size_t i = 0; i < numOctaves; ++i) {
        value += noise(vp) * powf(lacunarity, -H * i);
        vp *= lacunarity;
    }

    // 把负值截掉
    return std::max(0.f, value) * (1 - falloff);
}

构建一个 fBm 图案只需两行代码（对各层循环）。在这个基础版本上可以做出很多变化，比如取噪声函数的绝对值（这种图案叫 turbulence）等等。想进一步了解这个话题（以及如何正确地对这种图案做滤波），同样请参看过程式生成部分。

Bias

Bias 会移动中心值（0.5）所在的位置，而保持 0 和 1 不变。


float eval_density(...) 
{
    float bias = 0.2;
    float exponent = (bias - 1.0) / (-bias - 1.0)
    // 假定 exponent > 0

用图元的局部坐标系旋转噪声图案

还有一种技术在旧日好时光里用得很多（在流体模拟因算力提升而变得主流之前），用来让体积图元（球体、立方体等）内部的噪声图案动起来。我们传给密度函数的采样位置是在世界空间里定义的，但我们可以把这个点定义在一个附着于球体的参考系里。换句话说，把采样点从世界空间变换到物体空间。要在球体参考系里定义采样点，我们只需：


vec3 sample_object_space = sample_pos - center;

更通用的做法是用矩阵变换球体图元，然后用物体到世界矩阵的逆矩阵把采样点从世界空间变换到球体局部参考系。不过为了简单，我们的示例程序没有使用矩阵。但你可以用 Scratchapixel 上提供的信息自己轻松做到这一点。

这个技巧之所以有用，原因如下：如果我们移动球体，在球体局部参考系里定义的点的坐标不会变。这就可以用来确保噪声图案无论球体如何变换都粘在球体上。有点像你用手指搓动的玻璃弹珠里的纹理。我们为说明这个想法所选的例子（虽然跟我们刚才讲的稍有不同，但概念与结果一样）：我们会在物体空间里绕图元球体的 y 轴旋转这个点（更好的做法是用物体到世界矩阵旋转球体，再用世界到物体矩阵把采样点从世界空间变换到物体空间，但我们这里太懒了，于是改为在物体空间里旋转这个点）。结果是，我们能看到分形图案也跟着旋转，又有点像我们在看一颗转动的玻璃弹珠。用这种方法还可以施加更复杂的变形（线性或非线性）。


float eval_density(const vec3& p, const vec3& center, const float& radius)
{ 
    // 把点从世界空间变换到物体空间
    vec3 vp = p - center;
    vec3 vp_xform;

    // 在物体空间中旋转采样点（frame 是从 1 到 120 的全局变量）
    float theta = (frame - 1) / 120.f * 2 * M_PI;
    vp_xform.x =  cos(theta) * vp.x + sin(theta) * vp.z;
    vp_xform.y = vp.y;
    vp_xform.z = -sin(theta) * vp.x + cos(theta) * vp.z;

    float dist = std::min(1.f, vp.length() / radius);
    float falloff = smoothstep(0.8, 1, dist);
    float freq = 0.5;
    size_t octaves = 5;
    float lacunarity = 2;
    float H = 0.4;
    vp_xform *= freq;
    float fbmResult = 0;
    float offset = 0.75;
    for (size_t k = 0; k < octaves; k++) {
        fbmResult += noise(vp_xform.x , vp_xform.y, vp_xform.z) * pow(lacunarity, -H * k);
        vp_xform *= lacunarity;
    }

    return std::max(0.f, fbmResult) * (1 - falloff);
}

注意现在我们能清楚地看到分形图案的 3D 结构了。
