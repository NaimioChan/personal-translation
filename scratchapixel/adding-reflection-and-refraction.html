添加反射与折射

阅读时间：6 分钟。

光线追踪的另一个关键优势，是它能自然而然地模拟反射与折射这类精细的光学效果。要准确渲染玻璃或镜面这类材质，这些能力至关重要。Turner Whitted 在 1979 年的里程碑论文《An Improved Illumination Model for Shaded Display》中，率先把 Appel 的基础光线追踪算法扩展到了这类高级渲染技术。Whitted 的创新在于把算法扩展出去，让它承担处理反射与折射效果所需的计算。

反射与折射是基本的光学现象。详细探讨会放在后面的课程里，但为了做模拟，先理解它们的基本原理是有好处的。设想一个既有反射性质又有折射性质的玻璃球。只要知道入射光线射到球面上时的方向，我们就能算出这条光线接下来怎么走。反射光线与折射光线的方向，都由接触点处的表面法线以及入射光线的来向决定。此外，算折射方向还需要知道材质的折射率。折射可以想象成光线在折射率不同的介质之间穿行时路径发生的弯折。

同样要认识到，像玻璃球这样的材质同时具备反射与折射两种性质。难点在于：在某个具体的表面点上，该怎么把这两种效果混合起来？是不是简单地 50% 反射加 50% 折射就行？实际情况更复杂。混合比例受入射角影响，也与表面法线、材质折射率等因素有关。这里 Fresnel 方程起了关键作用，它给出了确定反射与折射适当配比所需的公式。

总结一下，Whitted 算法的运行方式如下：从观察者发出一条主光线，找出它与场景中物体最近的那个交点。一旦遇到非漫反射或透明的物体，就需要额外计算。对于玻璃球这样的物体，确定其表面颜色要分别算出反射颜色与折射颜色，再按 Fresnel 方程把它们适当混合。这三步——算反射、算折射、套用 Fresnel 方程——让复杂光学现象的真实感渲染成为可能。

要真实感地渲染玻璃这类同时具有反射与折射的材质，光线追踪算法要加入几个关键步骤：

  • 计算反射：第一步是确定光从物体上反射出去的方向。这项计算需要两份关键信息：交点处的表面法线，以及主光线的入射方向。反射方向确定之后，就向场景中发出这样一条新光线。举例来说，如果这条反射光线射到一个红球，我们就用既定的算法，朝光源发出一条阴影光线，评估到达球上该点的光量。得到的颜色（若处于阴影中则变黑）再按光源强度调整，然后计入最终反射回玻璃球表面的颜色。

  • 计算折射：接下来模拟折射效果，也就是光穿过玻璃球时的弯折，这条光线称为透射光线。要准确计算光线进入和离开玻璃时的新方向，需要交点处的法线、主光线的方向，以及材质的折射率。折射光线离开球体时，由于介质改变，会再次发生折射，路径也随之改变。透过折射率不同的材质观看时看到的视觉畸变，正是这种弯折造成的。如果这条折射光线随后打到一个绿色球上，就计算该点的局部光照（同样用阴影光线），得到的颜色取决于该点是在阴影里还是在光里，再把它计入玻璃球表面的视觉效果。

  • 套用 Fresnel 方程：最后一步是用 Fresnel 方程算出反射光与折射光各占多少，它们共同决定玻璃球上该关注点的颜色。这个方程需要材质的折射率、主光线与交点法线之间的夹角，输出反射与折射的混合系数。

下面给出的伪代码，说明了如何把反射颜色与折射颜色合成起来，确定玻璃球在交点处的外观：


// 计算反射颜色
color reflectionColor = computeReflectionColor(); 

// 计算折射颜色
color refractionColor = computeRefractionColor(); 

float Kr; // 反射混合值
float Kt; // 折射混合值

// 用 Fresnel 方程计算混合值
fresnel(refractiveIndex, normalHit, primaryRayDirection, &Kr, &Kt);

// 按 Fresnel 方程混合反射色与折射色。注意 Kt = 1 - Kr
glassBallColorAtHit = Kr * reflectionColor + Kt * refractionColor;

光既不能被创生也不能被消灭，这条原则是入射光中反射部分（Kr）与折射部分（Kt）之间关系的根基。这种光的守恒意味着：没有被反射的那部分光必然是折射了，因此反射光与折射光之和等于总的入射光。Fresnel 方程优雅地表达了这一概念，它给出的 Kr 与 Kt 只要算得正确，相加应当为 1。这一关系带来一处计算上的简化：只要知道 Kr 或 Kt 中的一个，用 1 减去它就能确定另一个。

这个算法的美妙之处还在于它的递归性质。递归很强，但也带来复杂性。举例来说，如果最初那个玻璃球场景里的反射光线打到红球、折射光线打到绿球，而这两个球也都是玻璃做的，那么在这些新交点上，计算反射与折射颜色的过程又要重复一遍。这种递归性质使得同时含多个反射面与折射面的场景能被细致地渲染出来。但它也带来挑战，特别是在相机处在一个内壁反光的盒子里这类情形中，光线理论上可以无限次弹射。为控制这一点，我们给递归深度设一个任意上限，光线到达预定深度就停止计算。这个限制保证渲染过程能够结束，得到的是场景的一个近似表示，而不是陷进无穷无尽的计算里。这样做可能会牺牲绝对的准确性，但在细节与计算可行性之间取得了平衡，确保渲染能在实际可接受的时间内出结果。
