蒙特卡罗方法快速入门

阅读时间：23 分钟。

最初我们并不想让这门课程这么长，也不想塞进这么多关于概率与统计的内容，但现实是：如果你想要理解蒙特卡罗方法，就必须在概率与统计理论上走完一大段路。

本章我们会试着让你对蒙特卡罗方法有个感觉：它们是什么、如何工作、为什么这样、用来做什么。这篇快速入门是写给没有时间、也没有兴趣再深入的读者的。但如果你真想学会这些方法是什么，你可能需要把余下的各章全部读完。

这门课程更像是对蒙特卡罗方法所依托的数学工具的介绍。这些方法本身会在下一门课程（《实践中的蒙特卡罗方法》）中讲解。

关于蒙特卡罗的一段前言

像你在 CG 文献里经常见到的许多其他术语一样，蒙特卡罗在不少门外汉眼里像个魔咒。而与计算机图形学里某些数学工具（比如球谐函数，它们多少有些复杂，至少相比蒙特卡罗近似是这样）不同，蒙特卡罗方法本身的原理相对简单（甚至可以说容易）。这很好，因为这种方法处理各类复杂问题极其顺手。蒙特卡罗积分或蒙特卡罗近似（两个说法都能用，不过说积分通常更好）大概是种老方法（该方法最早的文献记载可见于数学家 Comte de Buffon 18 世纪初的一些著作），但直到 20 世纪 40 年代中期的某个时候才得到现在这个朗朗上口的名字。蒙特卡罗是摩纳哥公国一个以赌场闻名的区。正如我们将在本课程中说明的，蒙特卡罗方法与统计学领域关系密切，而统计学本身对判断你在碰运气的游戏中赢或输的机会非常有用，比如轮盘赌、任何涉及掷骰子、抽牌之类的事情，它们都可以看作随机过程。因此这个名字相当贴切，它抓住了这个方法的神韵。这个方法本身曾由一些著名数学家协助发展与形式化（Fermi、Ulam、von Neumann、Metropolis 等人），在研制原子弹的研究中至关重要（它被用来研究裂变材料中中子输运的概率行为），而它在现代科学中的流行与计算机有很大关系（von Neumann 本人就造过几台最早的计算机）。不用计算机，蒙特卡罗积分十分繁琐，因为它需要海量计算，而这正是计算机擅长的。既然我们回顾了一些历史、交代了这个方法名字的由来，接下来就解释蒙特卡罗是什么。不过很遗憾，正如前面简要提到的，蒙特卡罗方法的数学含义建立在统计与概率论中许多重要概念之上。我们得先梳理这些概念（并把它们介绍给你），然后才能看蒙特卡罗方法本身。

蒙特卡罗方法快速入门

什么是蒙特卡罗？MC 方法背后的概念既简单又稳健。但正如我们很快就会看到的，它可能需要极其庞大的计算量，这也是它的流行与计算技术的出现同步的原因。生活中有太多东西难以精确求值，尤其当涉及非常大的数目时。例如，要数清一个 1 公斤的罐子里可能装了多少颗软心豆，虽然并非不可能，但可能要花很长时间。你可以一颗一颗手工数，但这可能要花很久（而且也不是什么最令人愉快的工作）。计算一个国家成年人口的平均身高，需要量出构成该人口的每个人的身高，把数字加起来，再除以被测人数的总数。同样，这也是一件可能要花很长时间的事。我们可以改为从该人口中抽取一个样本，计算它的平均身高。它不太可能给出整个人口的精确平均身高，不过这种技术给出的结果通常是对那个数字的一个不错的近似。我们用精度换取了速度。民意调查（也称统计）就建立在这条原理上，而我们对它都有直觉上的熟悉。有趣的是，近似值和整个人口的精确平均值有时会恰好相同。这纯属偶然。多数情况下两个数字会不同。不过我们可能想问一个问题：差多少？事实上，随着样本规模增大，这个近似会收敛到那个精确数字。换句话说，近似值与实际结果之间的误差随样本规模增大而变小。直觉上这个概念容易把握，不过我们会在下一章看到，（从数学角度看）它应当用另一种方式表述或解释。要说明的是，为公平起见，构成样本的元素必须以相等的概率随机选取。

注意人的身高是一个随机数。它实际上可以是任何值，这正是随机事物的本性。因此，当你对一个总体采样——随机挑出该总体中的元素、测量它们的身高来近似平均身高——每一次测量都是一个随机数（因为你样本中的每个人身高很可能不同）。有趣的是，随机数之和仍是另一个随机数。如果你无法预测加总中各个数字是多少，又怎能预测它们之和的结果呢？所以和的结果是一个随机数，而构成和的那些数字是随机的。

对数学家来说，一个总体的身高会被称为随机变量，因为构成这个总体的人的身高随机变化。我们通常用大写字母表示随机变量，常用字母 X。

在统计学中，构成那个总体的元素（如前所述是随机的）用小写字母表示，一般也是 \(x\)。例如，如果我们写 \(x_2\)，这表示样本集合中第二个人的身高（它是随机的）。所有这些 \(x\) 也可以看作随机变量 X 的可能取值。如果我们把这个随机变量（总体身高）叫作 X，就可以用下面这个伪数学公式表达「从样本近似成年人口平均身高」的概念：

$$Approximation(Average(X)) = { 1 \over N} \sum_{n=1}^N x_n.$$

你可以这样读它：随机变量 X（某个国家成年人口的身高）的平均值的近似，等于从该总体中随机选出的 N 个成年人（样本）的身高之和（\(\Sigma\) 符号），除以数目 N（样本规模）。本质上，这就是我们所说的蒙特卡罗近似。它的做法是：要近似大量事物某个属性的值，就从这些事物中随机挑出 N 个，取该属性的平均值。你也可以说，蒙特卡罗近似是一种用样本近似事物的方法。我们将在后面几章学到，需要近似的这些东西在数学上叫作期望（稍后详述）。如前所述，某个国家成年人口的身高可以看作随机变量 X。但要注意，它的平均值（例如把构成该人口的每个人身高取平均得到，其中每个数字也都是随机数）是唯一的（为避免与通常用字母 N 表示的样本规模混淆，我们用 M 表示整个总体的规模）：

$$Average(X) = { 1 \over M\ } (x_1 + x_2 + ... x_M),$$

其中 \(x_1, x_2, ... x_M\) 如前所述对应构成整个总体的每个人的身高（如果我们举例的话）。在统计学中，随机变量 X 的平均值叫作期望，写作 E(X)。

总结一下，蒙特卡罗近似（MC 方法之一）是一种用样本近似随机变量期望的技术。它可以用下面的公式在数学上定义：

$$E(X) \approx { 1 \over N } \sum_{n = 1}^N x_n.$$

数学符号 \(\approx\) 表示这个符号右侧的公式只给出随机变量 X 的期望 E(X) 的一个「近似」。注意，从某种意义上说，它不过是随机值（那些 \(x_n\)）的平均。

如果你只想知道蒙特卡罗这个神秘术语背后藏着什么，那么这就是你需要的全部。不过为了让这篇快速入门完整，我们来说明一下这个方法为什么有用。正如前面提到的，计算 E(X) 有时是难以处理的。意思是，你无法精确计算 E(X)，至少无法用高效的方式。当 E(X) 的计算涉及非常大的「总体」时尤其如此，比如计算一个国家成年人口的平均身高那种情况。此时 MC 近似提供了一种非常简单快捷的方式，至少能近似这个期望。它不会给你精确值，但可能已经足够接近，而代价只是精确计算 E(X)（如果可能的话）所需成本的一小部分。

蒙特卡罗、有偏与无偏光线追踪

作为这篇快速入门的结尾，我们知道你们中很多人听过蒙特卡罗光线追踪这个说法，也听过有偏与无偏光线追踪，很可能正是来看这一页，想找到这些术语到底什么意思的解释。那我们快速讲一下，尽管我们仍然建议你读完本课程余下部分以及后面几门课程，以获得深入的答案。

想象你要用一台数码相机拍张照片。如果你把图像表面划分成规则网格（我们的像素），注意每个像素都可以看作一小块连续表面，场景中物体反射的光就落在这块面上。这些光最终会被转换成单一颜色（这个过程我们稍后再说），然而如果你透过其中任何一个像素去看，可能会发现它看到的不止一个物体，或者它所看到的物体表面的颜色在像素面积上是变化的。我们在图 1 中示出了这个想法。理想情况下，我们要做的是计算从这块表面、在像素面积范围内反射出的光量。这是典型的难处理问题，意思是没有任何方法能让你对穿过该像素的光量在像素表面上做积分。虽然我们可以把这个想法写成数学式子，但这样的方程没有解：

$$L_{pixel} = \int_{pixel area} L(x_p) dA,$$

这里 L 表示辐射亮度（如讲辐射度量学的课程中所述）。这个方程可以读作「到达一个像素的能量（方程左边 L 这一项，也就是最终为该像素保存的颜色）可以按入射辐射亮度（打到该像素上的光）在像素面积上的积分来计算」。正如我们刚说的，这个问题没有解析解，因此我们需要改用数值近似。

同样，这里的原理非常简单。它通过在像素面积上若干位置对像素表面采样，来近似这个积分的结果。换句话说，与蒙特卡罗近似的情形一样，我们会用「随机采样」来求这个积分（并得到它的近似）。我们只需在像素面积上选几个随机样本位置，把它们的颜色平均。现在的问题是怎么求出这些样本的颜色。当然是用光线追踪！光线照常从眼睛位置出发，但会穿过散布在像素面积上的每一个随机样本位置（图 2）。样本的颜色就是光线与场景中物体交点处的颜色。用数学写出来就是：

$$L_{pixel} \approx {1 \over N } \sum_{n=1}^N L(x_n),$$

其中 \(L(x_n)\) 表示样本颜色。和往常一样，这只是近似（所以有 \(\approx\) 符号）。这个方法叫蒙特卡罗积分（虽然与蒙特卡罗近似方法相似，但在这里是用来求一个积分的近似）。你会在下一门课程中找到蒙特卡罗积分方法的正式定义。这里只是对这个概念的不正式、快速的介绍。

如果你还没完全理解这个问题，那就设想我们正透过看的那个像素，其表面被一个 16x16 的颜色网格覆满（如图 3 所示）。问题似乎更简单了，因为我们只有 256 种不同的颜色，所以事实上在这种情况下求像素颜色是可行的：我们只需把所有这些颜色加起来，再把结果除以 256。但如果网格无限大，这个解法就行不通。想求这个问题的近似，我们只需比如在图像上 8 个不同位置采样（这里的 8 只是个例子。它代表样本规模 N，其值可以任取），读取这些位置上网格的颜色，把这 8 个颜色加起来再除以 8。这个想法见图 3。

从图 3 可以看到，得到的近似接近平均颜色，但能看出差别。这就是蒙特卡罗方法的陷阱：它们只给我们近似值。这个方法的另一个陷阱是，每次重新计算近似，你都会得到不同的结果。这源于方法的随机性（每次计算近似时，8 个样本的位置都在变）。例如，下图是一块同样的颜色网格用 8 个样本做 16 次近似的结果。

好消息是，你可以增加样本数来减小这个误差。坏消息是，要把误差减半，你需要两倍的样本。这就是蒙特卡罗方法被认为慢的原因。更准确的说法是，它们的收敛速率（随样本数增加而收敛到正确结果的速度）相当低。这将在本课程和下一门课程中详细研究。下面这一系列图像是另外一组 16 次近似，分别用了 8、16、32、64、128 和 256 个样本。

如预期那样，随着样本数增加，相邻两次近似之间的差别变小了。你在渲染中看到的这种差异就是你熟知的噪声（假设你用的是光线追踪器）。它由实际解应当是什么与你得到的近似之间的差异造成。技术上正确的名字是方差（概率与统计和方差的研究关系极深）。样本数较少时你通常会得到更多噪声，或者换个说法：增加样本数可以减小噪声（或方差）。但要注意，你从一次近似到另一次近似得到的变动量（假设样本数相同）也取决于网格各颜色之间差异有多大。在下面的例子里，我们可以看到这个网格各颜色之间的颜色与亮度差异比上一个例子大得多。上一个例子里 256 个样本时，相邻近似之间的差别几乎看不出来，而这个网格用同样多的样本，差别就明显可见了。

什么时候会出现这种情况？当你透过一个像素看到很多物体，或者只看到一个或少数几个表面细节繁复的物体。不过一般来说，你要避免「透过一个像素看到的东西视觉复杂度很高」的情形，因为细节越多，你需要越多样本才能降低噪声。这个想法也与走样的概念以及重要性采样的概念有关。下面是我们用来生成这些结果的代码：


#include &ltfstream> 
#include &ltcstdlib> 
#include &ltcstdio> 
 
int main(int argc, char **argv) 
{ 
	std::ifstream ifs; 
	ifs.open("./tex.pbm"); 
	std::string header; 
	uint32_t w, h, l; 
	ifs >> header; 
	ifs >> w >> h >> l; 
	ifs.ignore(); 
	unsigned char *pixels = new unsigned char[w * h * 3]; 
	ifs.read((char*)pixels, w * h * 3); 
	// 采样
	int nsamples = 8; 
	srand48(13); 
	float avgr = 0, avgg = 0, avgb = 0; 
	float sumr = 0, sumg = 0, sumb = 0; 
	for (int n = 0; n < nsamples; ++ n) { 
		float x = drand48() * w; 
		float y = drand48() * h; 
		int i = ((int)(y) * w + (int)(x)) * 3; 
		sumr += pixels[i]; 
		sumg += pixels[i + 1]; 
		sumb += pixels[i + 2]; 
	} 
	sumr /= nsamples; 
	sumg /= nsamples; 
	sumb /= nsamples; 
	for (int y = 0; y < h; ++y) { 
		for (int x = 0; x < w; ++x) { 
			int i = (y * w + x) * 3; 
			avgr += pixels[i]; 
			avgg += pixels[i + 1]; 
			avgb += pixels[i + 2]; 
		} 
	} 
	avgr /= w * h; 
	avgg /= w * h; 
	avgb /= w * h; 
	printf("Average %0.2f %0.2f %0.2f, Approximation %0.2f %0.2f %0.2f\n", avgr, avgg, avgb, sumr, sumg, sumb); 
	delete [] pixels; 
	return 0; 
}

因为我们用光线追踪来求这次蒙特卡罗积分的样本，所以这个方法叫蒙特卡罗光线追踪（也叫随机光线追踪——stochastic 一词是随机的同义词）。

有三篇奠基性论文提出了这个方法：The Rendering Equation（Kajiya 1986）、Stochastic Sampling in Computer Graphics（Cook 1986）和 Distributed Ray-Tracing（Robert L. Cook、Thomas Porter、Loren Carpenter 1984）。

现在来说有偏与无偏这两个术语。在统计学中，我们据以计算 E(X) 近似值的那条规则叫估计量。方程：

$$Approximation(E(X)) = { 1 \over N } \sum_{n=1}^N x_n,$$

就是一个估计量的例子（其实它是一个被称为蒙特卡罗估计量的东西的简化版本，我们叫它基本估计量。你可以在下一门课程中找到蒙特卡罗估计量的完整方程与完整定义）。如果一个估计量的结果随样本规模 N 增大而趋近期望，就说它是无偏的。我们可以证明这个近似在 N 趋于无穷时收敛到实际结果（参见采样分布一章）。另一种表述是：近似值与期望值之间的差在 N 趋于无穷时收敛到 0，可以写成：

$$Approximation(E(X)) - E(X) = 0 \text { as N approaches } \infty.$$

蒙特卡罗估计量就是这种情况。总结一下：蒙特卡罗估计量是无偏的。但当估计量的结果与期望之间的差不为 0 时（N 趋于无穷时），这个估计量就说是有偏的。不过这并不意味着该估计量在 N 趋于无穷时不收敛到某个值（当它们收敛时，就说它们是一致的），只是这个值不同于期望。乍看之下，无偏估计量似乎比有偏估计量更好。的确，我们为什么需要、或者为什么要用结果不同于期望的估计量呢？因为其中一些估计量有很有意思的性质。例如，如果偏差足够小，而估计量又比无偏估计量收敛得更快，这就可以算是一个有意思的性质。对同样的样本数 N，这些有偏估计量的结果也可能比无偏估计量的结果方差更小。换句话说，如果你用有偏估计量计算若干次近似，相比用无偏估计量（在样本数相同的情况下），你可能会看到相邻两次近似之间的变动更小。这同样可能是一种有意思的品质。总结一下，你可以用有偏的、也可以无偏的蒙特卡罗光线追踪器。在样本量相同的情况下，有偏 MC 光线追踪器很可能比无偏 MC 光线追踪器噪声更少（或者更快），不过使用有偏估计量会让你相对「真实」结果引入一些小的误差（偏差）。一般来说这个偏差很小（否则这个估计量就没什么用了），而且如果你不知道它在那里，就察觉不到。

我们可以把蒙特卡罗光线追踪的概念再推进一步。如《着色简介》课程中所述，要计算主光线（或相机光线）与物体表面的交点 P 处的颜色，需要在以该点法线为中心的方向半球上，对到达 P 的光量做积分。如果你还没猜到，这是又一个积分，粗略地可以写成：

$$L_P = \int_\Omega L_\Omega.$$

记住，在讲着色的课程中 \(\Omega\) 表示半球。不过和往常一样，这涉及在连续区域上对某个量做积分，而它没有解析解。因此这里同样可以使用蒙特卡罗积分方法。这个想法是：在半球面上生成随机样本来「采样」这个半球，并从 P 向场景中穿过这些样本发射光线，从而得到到达 P 的光量的近似（图 4）。换句话说，我们从可见点 P 发出随机光线，把结果平均。

$$L_P \approx { 1 \over N } \sum_{n=1}^N L_n.$$

这又是蒙特卡罗光线追踪器典型的工作方式。注意，当我们从 P 向场景发出一条光线以查明来自那个方向的光有多少时，如果这条光线与另一个物体相交，我们就用同样的方法近似这个物体返回的光量。这个过程是递归的。由于我们追踪光线的路径，这个算法有时也叫路径追踪。你可以看图 5 的示意。

这个想法也可以用下面的伪代码表示。


Vec3f monteCarloIntegration(P, N) 
{ 
    Vec3f lightAtP = 0; 
    int nsamples = 8; 
    for (int n = 0; n < nsamples; ++n) { 
        Ray sampleRay = sampleRayAboveHemisphere(P, N); 
        Vec3f Phit; 
        Vec3f Nhit; 
        if (traceRay(sampleRay, Phit, Nhit)) { 
            lightAtP += monteCarloIntegration(Phit, Nhit); 
        } 
    } 
    lightAtP /= nsamples; 
 
     return lightAtP; 
}

显然，这一切只是对蒙特卡罗光线追踪非常快速、也非常粗略（可以说）的介绍。要获得更准确、更完整的信息，我们强烈建议你读完本课程余下部分以及下一门课程。

不过作为结论，可以说蒙特卡罗方法是依靠随机采样来近似结果的数值技术，尤其是积分的结果。这些积分有时可以用其他技术求解（如果你感兴趣，可以搜一下 Las Vegas 算法的例子），不过我们会在后面几门课程中说明，相比其他解法它们具有一些性质，使其更有用（尤其是在求解我们在计算机图形学中必须处理的那类积分时）。

蒙特卡罗在渲染领域居于核心地位。它与许多非常重要的其他主题相连，比如采样、重要性采样和光传输算法，也被用在许多其他重要的渲染技术中（尤其是在着色中）。
