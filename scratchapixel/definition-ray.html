光线的定义

阅读时间：10 分钟。

前置知识

从这一课往后，我们要学的大多数技术都会用到几何课程里讲过的点、向量、矩阵、相机与三角学。我们还会大量复用计算 3D 点的像素坐标课程里学到的内容，那门课讲的是顶点与向量可以被变换到哪些不同的坐标系。你还应当熟悉3D 观察：针孔相机模型课程中讨论的概念。开始读本课之前，请务必先把这些基础打好。

本课讲什么？

在光线追踪的入门课程中，我们已经简略提到过光线追踪如何用来解决可见性问题。回顾一下：在 3D 渲染的语境下，可见表面判定是这样一个过程——确定场景几何体的哪些部分透过相机是可见的。我们可以用光线追踪来计算可见性（这个过程上一课已经解释过）：为图像中的每个像素投射一条光线，寻找这条光线相交的最近物体（如果有的话）。再回顾一下，光线追踪是一种计算光线与表面之间交点的技术。用光线追踪计算可见性，也叫光线投射。

给定欧几里得空间中的一组障碍物，若连接空间中两点的线段不与任何障碍物相交，则这两点被称为互相可见——维基百科上对 [visibility](http://en.wikipedia.org/wiki/Visibility_(geometry)) 的定义。

用光线追踪解决可见性来生成图像，需要对图像中所有像素循环：为每个像素生成一条光线，把这条光线投射进场景，寻找这条光线与场景中任何表面的可能交点。这些光线叫作主光线（也叫相机光线或眼睛光线），因为它们是第一批投射进场景的光线（次级光线用来计算阴影、反射、折射等）。要判断光线是否与某个表面相交，我们需要对场景中的每个物体做一次与该光线的相交测试。一条光线可能命中不止一个表面。可见表面就是交点距离最近的表面。这里的距离，指的是从光线原点到交点的距离（对主光线来说，原点就是相机的位置）。


for (int j = 0; j < height; ++j) { 
    for (int i = 0; i < width; ++i) { 
        // 生成主光线（这正是本课的主题）
        ... 
        float tnear = INFINITY;  //最近的交点，初始设为 INFINITY 
        for (int k = 0; k < numObjects; ++k) { 
             float t = INFINITY;  //与当前物体的交点（如果有） 
             if objects[k]-&gtintersect(pimaryRay, tnear) && t < tnear) { 
                 tnear = t; 
                 framebuffer= objects[k].color; 
            } 
        } 
    } 
}

本课将把光线的概念形式化，更重要的是讲清主光线是如何生成以模拟针孔相机的。一旦理解了主光线如何生成，下一步就是学习几种计算光线与几何体交点的技术。这就是用光线追踪生成 3D 物体图像的最低要求。

关于光线追踪与透视投影的说明：针孔相机模型是在 CG 中最容易模拟的。与光栅化一样，这也是我们要用于光线追踪的模型。用这个模型形成图像。记住，针孔相机所描述的 3D 到 2D 映射是透视投影。

本章我们会学习一些关于光线的有用内容。下一章我们将研究主光线是如何计算的。

定义光线

正如上一课所述，

光线追踪是一种用来计算点之间可见性的技术。它就是一种基于光线概念的技术，而光线在数学上（以及在计算机程序中）可以定义为一个点（光线在空间中的原点）和一个方向。于是光线追踪背后的想法，就是寻找数学解，计算这条光线与各类几何体的交点：三角形、二次曲面（我们在后续某一课中会讲）、NURBs 等。光线追踪的全部内容就是这些。

本课（更具体地说，本章）要解释的部分是光线的概念，以及我们如何在理论上和编程中定义它。定义一条光线只需要两个变量：一个点和一个向量。这个点（在程序里我们就简单地把它定义为一个 vec3f 代表光线的原点，向量则代表它的方向。记住，方向一般应当归一化。


// 定义一条光线的最低要求是一个位置和一个方向
Vec3f orig;  //光线原点 
Vec3f dir;  //光线方向（已归一化）

这个点与这个方向结合起来，代表的就是一条半直线。数学上，这条半直线上的任意一点可以定义为：

$$P = orig + t * dir.$$

其中 \(t\) 是从原点到半直线上该点的距离。这个变量可以为负也可以为正。如果 \(t\) 为负，光线上的该点就在光线原点的后方；如果 \(t\) 为正，点 P 就在光线原点的「前方」。实践中，使用光线追踪时，我们一般只关心光线与位于原点前方的表面的交点。这意味着只有当 \(t\) 为正时，我们才认为光线与表面之间的交点是有效的。


// 定义光线的原点与方向
Vec3f orig = ...; 
Vec3f dir = ...; 
float t = INFINITY; 
// 这条光线与该物体相交吗？若找到交点，intersect() 返回 true
if (object.intersect(orig, dir, t) && t > 0) { 
    // 这是一个有效交点，命中点位于光线原点的前方
    ... 
}

从数学角度看，上面的公式叫作参数方程。这条半直线由一个方程描述，而该方程是参数变量 \(t\)（或称参数）的函数。

光线与几何体的求交程序总是以参数 \(t\) 的形式返回交点（如果找到了交点）。换句话说，如果找到了交点，求交程序会计算从光线原点到该交点的距离，并把这一信息返回给你。据此，你可以用上面介绍的光线参数方程轻松算出交点在 3D 空间中的位置（即命中点）。


// 定义光线的原点与方向
Vec3f orig = ...; 
Vec3f dir = ...; 
float t = INFINITY;  //到物体的交点距离（如果有）。初始设为一个很大的数 
// 这条光线与该物体相交吗？若找到交点，intersect() 返回 true
if (object.intersect(orig, dir, t) && t > 0) { 
    // 这是一个有效交点，命中点位于光线原点的前方，用 t 算出命中点
    Vec3f hitPoint = orig + dir * t; 
}

光线就是这些。从编程角度看，光线也可以定义为一个 C++ 类：


class Ray 
{ 
public: 
    Ray(), orig(0), dir(0,0,-1) {} 
    Ray(const Vec3f &o, const Vec3f &d) : orig(o), dir(d) {} 
    // 等等
    ... 
    Vec3f orig; 
    Vec3f dir; 
};

有些程序员喜欢给这个类再加几个成员变量，比如 \(t_{min}\) 和 \(t_{max}\) 距离。它们为 \(t\) 定义了一个有效取值范围。换句话说，如果求交程序返回的 \(t\) 不落在 [\(t_{min}\), \(t_{max}\)] 这个范围内，那就视为没有交点（即使 \(t\) 大于 0）。


class Ray 
{ 
public: 
    Ray(), orig(0), dir(0,0,-1), tMin(0.1), tMax(1000) {} 
    Ray(const Vec3f &o, const Vec3f &d) : orig(o), dir(d), tMin(0.1), tMax(1000) {} 
    // 等等
    ... 
    Vec3f orig; 
    Vec3f dir; 
    float tMin, tMax; 
}; 
 
Ray ray; 
// 设置光线的方向与原点
ray.orig = ...; 
ray.dir = ...; 
float t = INFINITY; 
if (object.intersect(ray, t) && t >= ray.tMin && t <= r.tMax) { 
     // 有效交点
     ... 
}

你想给 Ray 类加多少参数都行。用不用 Ray 类也由你决定。这完全取决于个人偏好与需求。程序里怎样表示这份数据没有定规。有些程序员喜欢往 Ray 类里加信息，比如到最近可见表面的距离 \(t\)（在求交程序找到交点时设置）、指向命中物体的指针等。另一些程序员则更喜欢把这些信息与光线变量分开，存进一个叫 Intersection 之类的结构体或类里。同样，除了至少要有光线原点和光线方向，其余一切都可以按你喜欢的方式来做（而且都是可选的）。

不过编程时有一点可能有用：按类型给光线打上标记，比如主光线、阴影光线、反射光线、折射光线等。它可以用来做统计（比如你想知道渲染某个场景投射了多少条阴影光线），也可以在代码里根据光线类型调用不同的函数。这也是常见做法。

光线有什么用？

光线几乎到处都能用。它们被用来解决可见性问题、收集物体颜色的信息、计算阴影等。本课要学的这种光线叫作相机光线，也叫主光线。

对画面中的每个像素，我们都需要构造一条相机光线，把它投射进场景。如果光线与物体相交，我们就计算这些交点处物体的颜色，并把这些颜色赋给对应的像素。简而言之，这就是用光线追踪生成一张 CG 图像的过程。我们可以区分主光线（第一批投射进场景、以相机原点为原点的光线）与次级光线（阴影、漫反射、镜面反射、透射等光线），后者用于着色。次级光线在光线的交点处从主光线派生出来。这些次级光线的方向取决于它们的类型：阴影（朝光源方向投射一条光线）、反射（朝反射方向投射一条光线）、折射（朝折射方向投射一条光线，可用 Snell 定律计算）等。
