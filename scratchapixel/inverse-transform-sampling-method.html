逆变换采样法

阅读时间：24 分钟。

这一章更像是对逆采样法的一般性介绍。与计算机图形学直接相关的例子会在后面几门课里给出（特别是《实践中的蒙特卡罗方法》《采样入门》以及《重要性采样入门》）。

逆变换采样法

如上一段所述，CDF 可以用来回答这样一个问题：「连续随机变量 X 取小于等于某个数的任意值的概率是多少，其中这个数位于该随机变量所有可能取值范围的某处。」回答这类问题在计算机图形学里有用吗？答案是有用，但只是间接有用。

我们用一个不需要任何渲染与着色知识就能理解的例子。设想你想开发一个列车运行模拟器。你关心的是模拟某一列车从 A 点开往 B 点。查看这趟车的真实运行数据时，你注意到从 A 到 B 所需的时间可以是 25 到 35 分钟之间的任意值，平均 30 分钟。如果你把 25 到 35 之间的时间等分，统计每个时间区间内到达的列车数（除以列车总数），你可能会发现得到的曲线与我们本章前面用过的标准正态分布函数非常像（当然这不一定，我们只是又用了这个函数，因为已经熟悉它了）。换句话说，这条曲线的样子类似于上一章图 2 或图 4 中那样的曲线（分别用红色和黑色），或者下图。这张图里我们把时间分成 1 分钟一格，如果把格分得更小，你会得到更接近黑色曲线（真正的函数/PDF）的图。

这意味着什么，或者换个说法，你该怎样理解这条曲线？很简单，它只说明：比如列车在计划到站时间的 1 到 2 分钟内到达的可能性，比在 3、4 或 5 分钟内到达的可能性更大。理解这一点很重要。用概率来表述：列车在计划时间 1 到 2 分钟内到达的概率，高于它在 3、4 或 5 分钟内到达的概率。

顺便注意，列车实际到达时间与平均时间之间的时间差，可以看作一个连续随机变量，其取值范围在下界 -5（列车不可能早到 5 分钟以上）与 5（列车不可能晚到 5 分钟以上）之间，我们可以写成：

$$ -5' <= X <= +5'.$$

记住，在概率论里这叫作随机变量的样本空间。现在我们手上有这些数据了，来试着做一个逼真的列车模拟。如果你对概率和 CDF 了解不多，只想模拟「列车一般不会准点到」这个事实，你可以给列车速度加一点小的随机偏移，让它要么早到、要么晚到（不过有时它也可能恰好准点，随机过程的本性就是如此）。从编程角度看，你可以简单地取一个 25 到 35 之间的随机数，再由这个值算出列车速度（假设你知道 A 到 B 的距离，且列车匀速行驶）。你的虚拟列车于是就会带着与计划到站时间之间的某个时间差到达。程序大致如下（这个程序只部分正确，因为我们应该按分、秒等来换算时间，但为简单起见我们忽略了这个细节）：


#include &ltcstdlib> 
#include &ltcstdio> 
int main(int argc, char ** argv) 
{ 
    srand48(13);  //初始化均匀随机变量 
    int numSims = 10; 
    const float dist = 10;  //10 公里或英里 
    for (int i = 0; i < numSims; ++i) { 
        float time = 25 + drand48() * 10;  //25 到 35 分钟之间的任意时间 
        float speed = 60 * dist / time;  //公里/英里每小时 
        printf("Train travel at speed: %f\n", speed); 
    } 
    return 0; 
}

对不熟悉 C++ 的读者：drand48() 是一个返回 0 到 1 之间随机实数的函数。我们暂且假设不知道这个函数是怎样分布这些随机数的，换句话说，我们不知道 drand48() 以多大的概率生成这些随机数。不过这个程序对真实世界的模拟很差。它也许会让你产生随机的错觉，但并没有准确模拟真实的运行数据。为什么？模拟产生的每一列车，都在计划到站时间的某个时间差内到达。这就是我们的随机变量 X。我们把这个时间差记作 \(\Delta t\)。现在把时间区间 [-5,5] 分成规则的小区间或箱（下面代码中是 100 个）。模拟产生的每一列车，我们都把 \(\Delta t\) 映射到对应的箱并把该箱的值加一（模拟结束时所有箱都归一化，即除以列车总数）。这就能告诉我们随机变量 X（由 \(\Delta t\) 表示）在程序里是如何分布的。下面是新代码：


#include &ltcstdlib> 
#include &ltcstdio> 
#include &ltcstring> 
 
int main(int argc, char ** argv) 
{ 
   srand48(13); 
   int numSims = 1000000; 
   int numBins = 100; 
   int bins[numBins]; 
   memset(bins, 0x0, sizeof(int) * numBins);  //把所有箱清零 
   const float dist = 10;  //10 公里 
   for (int i = 0; i < numSims; ++i) { 
       float diff = (2 * drand48() -1) * 5;  //-5 到 5 之间的随机变量 
       int whichBin = (int)(numBins * (diff / 5 + 1) * 0.5); 
       bins[whichBin]++; 
       float time = 30 + diff; 
       float speed = 60 * dist / time; 
   } 
   float sum = 0; 
   for (int i = 0; i < numBins; ++i) { 
       float r = bins[i] / (float)numSims; 
       printf("%f %f\n", 5 * (2 * (i /(float)(numBins)) -1), r); 
       sum += r; 
   } 
   fprintf(stderr, "sum %f\n", sum); 
   return 0; 
}

现在我们得到的是相对于平均时间的时间差落在某一区间内的列车数（除以列车总数）。在概率论里，这就是我们的概率分布函数（因为这些都是概率，如果你把它们全加起来，应该得到 1，运行上面的程序就能验证）。换句话说，这个结果给出了列车早到 5、4、3、2、1 分钟，准点，或晚到 1、2、3、4、5 分钟的概率。之前用真实运行数据做这个练习时（见上图），我们发现这条曲线（或图）具有标准正态分布函数的形状。如果我们的模拟做对了（也就是产生的数据与真实世界数据相似，这是任何模拟的终极目标），它按理应该有相同的概率分布。我们把数据画出来看看这张图（第 23 行的结果）：

令人失望！曲线是平的，不是钟形曲线。这个概率分布是均匀的，这在预料之中，因为在 C/C++ 里 drand48() 是已知的均匀分布随机数生成器（取 0 到 1 之间任何值的概率相同），而不是我们需要的正态分布。

那么，我们的程序要做到什么才算一个好的模拟器？要模拟真实世界的数据，程序使用的随机数生成器就应该生成与我们试图模拟的随机过程具有相同概率分布函数（即 PDF）的随机数。这看起来理所当然。换句话说，如果在真实世界里，列车到达时间与计划到站时间的时间差服从标准正态分布函数，而你又把这个时间差看作一个（连续）随机变量（这就是我们试图模拟的随机过程），那么程序里用的随机变量也应该如此。可我们该怎么做？

这个想法是渲染的基础，我们会在后面几门课（采样）里看到。

从编程角度看，假设我们只能用这个 drand48() 函数，而我们知道它服从均匀概率分布（不过在 C++11 这个最新的 C++ 标准里，你现在可以找到具有各种概率分布函数的随机数生成器，包括正态分布；但为了这个练习我们不用那些）。如果你还记得我们讲 CDF 时说的，这个函数从 0 到 1，且单调递增。既然我们只能以相同概率生成 0 到 1 之间的数，那么我们可以做的，就是用 drand48() 取一个数，把它看作 CDF 的结果。如果你看图 1（它示意了这个想法），应该很清楚：抽到构成这一列的任何一个小方块的概率是相等的。每个方块被选中的概率相等，每个方块上任何位置被选中的概率也相等。因此，用一个均匀分布的随机变量在 0 到 1 之间沿 Y 轴任取一点是合理的。如果我们说 \( r\) 就是 drand48() 的结果（在文献里，均匀分布的随机数常用希腊字母 epsilon \(\epsilon \) 表示），我们可以写成：

$$CDF(x) = r \text{ where } \{r: 0 \leq t \leq 1\}.$$

这个想法是把均匀分布随机数生成器的结果，看作对某个 x 值（我们并不知道是哪个）的 CDF 结果。但为什么这样看问题有意思？因为，如果我们能以某种方式把 CDF 反过来，也就是说找到这样一个函数：

$InvCDF(r) = x,$

我们就有了一个办法，可以只靠抽取 0 到 1 之间均匀分布的随机数（用 drand48() 之类的函数很容易做到），就按我们想要的任何 PDF 抽取随机数（因为 CDF 直接由 PDF 导出）。这本质上就是逆变换采样法的原理。

来看看在我们的例子里它是怎么起作用的。图 2 中我们画出了标准正态分布函数的 CDF（这个 PDF 定义了我们的列车在计划到站时间前后某个时间差内到达的概率）。我们知道，CDF 会收敛到 1。我们可以把这张图的 Y 轴理解为均匀分布随机数生成器的结果。现在，如果我们把这张图反过来（所得图形见图 2 下部），就得到另一张图，其中 X 轴从 0 变到 1（原先上图的 Y），Y 轴从 -5 变到 5（原先上图的 X）。我们把 CDF 反过来了。若随后在 0 到 1 之间为 X 随机取一个值（比如用 drand48()），我们读出该函数（蓝色）在这个 X 值上的结果时，得到的就是某个随机值（沿 Y 轴的值），代表列车实际到达时间与计划到站时间之间的时间差。再说一次，由于 X 值是随机的，Y 值也是随机的：

$$InvCDF(drand48()) = y,$$

其中 \( y\) 是从具有目标 PDF 的「随机数生成器」中抽出的随机数。这正是我们列车模拟想要的东西。

花点时间看看这张图，试着看看 X 取不同值时会发生什么。你可以看到，正态分布 CDF 的反函数在 X 很小时（0 到 0.05 之间）以及 X 接近 1 时（0.95 到 1 之间）变化很小。但既然 X 的取值是随机且均匀的，这就意味着这个函数更可能返回 -2/-1.5 与 1.5/2 之间的值，而不是 [-5,-2] 或 [2,5] 之间的值。这正是我们要的，因为只要看一眼 PDF 就知道，列车在 1 或 2 分钟的时间差内到达的可能性，比 3、4 或 5 分钟更大（见图 4 中标注「该范围内的时间更有可能被选中」的那个箭头）。

总结一下，要用具有给定 PDF 的随机变量为列车模拟取一个随机值，我们需要：

  • 我们想模拟的随机变量 X 的 PDF（列车例子里是标准正态分布函数，但也可以是其他任意 PDF）。

  • 由这个 PDF 构造一个 CDF（比如用黎曼和）。

  • 把这个 CDF 反过来（下面会讲怎么做）。

  • 抽取一个均匀分布的「辅助」随机数 \(\epsilon\)。

  • 对这个 \(\epsilon\) 值，从反 CDF 中得到 \( y\)：

    $$InvCDF(\epsilon) = y.$$

  • 得到的结果值 \( y\) 就是一个取自具有目标 PDF 的随机变量 X 的随机数。

那么下一个问题是：我们怎么求出 CDF 的反函数？如果你的 CDF 是一个函数（比如标准正态分布函数），在某些情况下该函数的反函数也可能有解析形式。但我们不想只限于反函数存在的那些情形，因为实际中我们可能面对任意 PDF。因此我们需要一个通用的解法。恰好，通过离散化 PDF，我们可以很容易地算出其对应 CDF 的一个「离散化」版本，比如用黎曼和法、按上一章讲的那样把样本累加起来。写成代码就是：


// 标准正态分布函数
float pdf(const float &x) 
{ return 1 / sqrtf(2 * M_PI) * exp(-x * x * 0.5); } 
 
int main(int argc, char ** argv) 
{ 
    int nbins = 32; 
    float minBound = -5, maxBound = 5; 
    float cdf[nsamples + 1], dx = (maxBound - minBound) / nbins, sum = 0; 
    cdf[0] = 0.f; 
    for (int n = 1; n < nbins; ++n) { 
        float x = minBound + (maxBound - minBound) * (n / (float)(nbins)); 
        float pdf_x = pdf(x) * dx; 
        cdf[n] = cdf[n - 1] + pdf_x; 
        sum += pdf_x; 
    } 
    cdf[nbins] = 1; 
    printf("sum %f\n", sum); 
    for (int n = 0; n < nsamples + 1; ++n) { 
        printf("%f %f\n", minBound + (maxBound - minBound) * (n / (float)(nbins)), cdf[n]); 
    } 
    ... 
    return 0; 
}

这样（在代码里）构造 CDF 时，要注意第一个和最后一个样本应当分别是 0 和 1，还要注意中间其他样本怎么处理。注意，尽管我们离散化了 PDF 来构造 CDF，CDF 本身仍然是连续函数。我们把程序打印的结果画出来（CDF 在 -5 到 5 上的值，这是我们为 PDF（标准正态分布函数）选定的边界）：

下一步是生成一个均匀分布的随机数 r，这可以用 drand48() 之类的函数做到。然后我们用一个叫 lower_bound 的 C/C++ 函数，它返回一个数值数组（这里是构成 CDF 的那些 float）中第一个值小于给定值（r）的元素。下图示意了这个函数的工作方式（r = 0.491）。我们之所以能用这个函数，是因为 CDF 是单调递增的分段线性函数（换句话说，序列中每个样本的值都大于或等于数组中它前面那个样本）。

把返回指针的地址减去数组首个元素的地址，就得到数组首个元素与该元素的偏移量，而这个元素的值小于 r。写成代码就是：


#include &ltalgorithm> 
int main(int argc, char ** argv) 
{ 
    ... 
    srand48(13); 
    float r = drand48(); 
    float *ptr = std::lower_bound(cdf, cdf + nbins + 1, r); 
    int off = (int)(ptr - cdf - 1); 
    printf("r %f offset %d\n", r, off); 
    printf("%f %f\n", cdf[off], cdf[off + 1]);  //r 落在这个界之间 
    ... 
    return 0; 
}

现在我们知道了夹住 r 的那两个值（它们在数组中的索引，当然还有通过索引很容易取到的值）。如下图所示，这两个样本之间的连线，以及下界样本（n=15）与 r 之间的连线，可以看作两个相似三角形的斜边。我们从几何那门课知道，相似三角形对应边长度之比相等。换句话说，我们可以写成：

$${ DE \over AB } = { DF \over AC }.$$

然后我们把 r 重映射到 0 到 1 之间（这个值我们称为 t，它相当于下图中的 DE），使得：

$$t = DE = {(r - \text{ lower bound }) \over (\text{ upper bound } - \text{lower bound})},$$

这样 AB 就等于 1。DF 是我们要求的距离。它是我们问题的部分解。我们还知道 AC，它就是 CDF 的上界（例中为 5）减去下界（例中为 -5）再除以样本总数。

最后我们可以解出 DF：

$$ \begin{array}{l} dx = \dfrac{(max - min )}{nsamples }\\ \dfrac{DE}{AB } = \dfrac{DF}{AC} = \dfrac{t}{1} = \dfrac{DF}{dx}\\ DF = t * dx \end{array} $$

最后，我们可以求出 x：

$$x = min + n_{lower} * dx + DF = min + (n_{lower} + t) * dx.$$

这不是最优雅的做法，但最字面。更好的思路是把 CDF 的范围看作 [0,1]，最后把得到的 x 重映射到 [min, max]。也就是说：

$$ \begin{array}{l} dx = \dfrac{1}{samples}\\ x = (n_{lower} + t)* dx\\ x = min + (max - min) * x. \end{array} $$

照例给出代码版本：


int main(int argc, char ** argv)
{
    ...
    float t = (r - cdf[off]) / (cdf[off + 1] - cdf[off]);
    printf("t %f\n", t);
    float x = (off + t) / (float)(nbins);
    x = minBound + (maxBound - minBound) * x;
    printf("x %f\n", x);
    ...
    return 0;
}

对于 r（或 y）= 0.491，我们得到 x = -0.178。如你所见，即便不去显式地求 CDF 的反函数，我们也有办法对任意给定的 y 值求出 x。现在把这个方法用到列车模拟上。我们要做的就是从 PDF 算出 CDF（第 28-35 行）。然后每当我们想模拟一列新的列车，就调用一个函数（第 11-19 行），在其中以均匀分布取一个 [0,1] 范围内的随机数（第 13 行），并用刚才描述的逆采样法算出一个具有目标 PDF 的随机数（第 14-18 行）。照例，为了检验模拟的准确性，我们会统计落在计划到站时间前后若干时间区间内的列车数。如果模拟做对了，我们应该得到一条钟形曲线，类似于正态分布函数的那样。来检查一下。


#include &ltcstdlib> 
#include &ltcstdio> 
#include &ltcstring> 
#include &ltcmath> 
#include &ltalgorithm> 
 
// 标准正态分布函数
float pdf(const float &x) 
{ return 1 / sqrtf(2 * M_PI) * exp(-x * x * 0.5); } 
 
float sample(float *cdf, const uint32_t &nbins, const float &minBound, const float &maxBound) 
{ 
    float r = drand48(); 
    float *ptr = std::lower_bound(cdf, cdf + nbins + 1, r); 
    int off = std::max(0, (int)(ptr - cdf - 1)); 
    float t = (r - cdf[off]) / (cdf[off + 1] - cdf[off]); 
    float x = (off + t) / (float)(nbins); 
    return minBound + (maxBound - minBound) * x; 
} 
 
int main(int argc, char ** argv) 
{ 
     srand48(13);  //给随机数生成器播种 
     // 创建 CDF
     int nbins = 32; 
     float minBound = -5, maxBound = 5; 
     float cdf[nbins + 1], dx = (maxBound - minBound) / nbins, sum = 0; 
     cdf[0] = 0.f; 
     for (int n = 1; n < nbins; ++n) { 
         float x = minBound + (maxBound - minBound) * (n / (float)(nbins)); 
         float pdf_x = pdf(x) * dx; 
         cdf[n] = cdf[n - 1] + pdf_x; 
         sum += pdf_x; 
     } 
     cdf[nbins] = 1; 
 
    // 我们的模拟
    int numSims = 100000; 
    int numBins = 100;  //用来收集模拟数据 
    int bins[numBins];  //用来收集模拟数据 
    memset(bins, 0x0, sizeof(int) * numBins);  //把所有箱清零 
    const float dist = 10;  //10 公里 
    for (int i = 0; i < numSims; ++i) { 
	   float diff = sample(cdf, nbins, minBound, maxBound);  //-5 到 5 之间的随机变量 
	   int whichBin = (int)(numBins * (diff - minBound) / (maxBound - minBound)); 
	   bins[whichBin]++; 
	   float time = 30 + diff; 
        float speed = 60 * dist / time; 
    } 
    sum = 0; 
    for (int i = 0; i < numBins; ++i) { 
        float r = bins[i] / (float)numSims; 
        printf("%f %f\n", 5 * (2 * (i /(float)(numBins)) -1), r); 
        sum += r; 
    } 
    fprintf(stderr, "sum %f\n", sum); 
    return 0; 
}

这正是我们期望看到的。得到的曲线就像一条正态分布函数。

小结

由于这个方法对任何对有着色和渲染感兴趣的人都如此重要，我们把这一章里你应当记住的东西总结一下。首先，再复述一遍我们试图解决的问题。我们的目标是模拟一个具有给定概率密度函数（PDF）的随机过程。这个 PDF 可以是任意的，尤其是当我们试图模拟一个已经采集到数据的真实世界现象时。理解任意 PDF 这个概念很重要。有些函数比如正态分布可以用作 PDF。常见概率分布一览可以在 Wikipedia 上找到。但并非每个真实世界现象的随机行为都能塞进这些函数中的一个，这种情况下我们就说这个 PDF 是任意的。无论任意与否，PDF 的性质总是一样的。样本空间内所有取值的 pdf 之和等于 1，它表示该随机变量取某个给定值的相对可能性（如上一章所述）。

我们需要的是能够抽取具有相同概率函数的随机变量。换句话说，如果真实列车在计划到站时间前后 1 分钟内到达的可能性比 2、3、4、5 分钟更大（这就是 PDF），那么当我们抽取随机数来模拟列车的实际到达时间时，这些数中靠近 1 的就要比靠近 2、3、4、5 的更多。这就是我们说「按给定 PDF 抽取随机数」的意思。

逆变换法就是可以达到这个目标的一种技术。它对任意 PDF 都成立，换句话说，PDF 不必是已知的解析函数（比如正态分布函数）才能用。只要我们有这个 PDF 的数据，就可以用这个方法。它的做法是抽取一个均匀分布的随机数。我们把这个随机数记作 \(\epsilon\)。如果我们假设这个数就是 CDF 的结果，那么只要我们能以某种方式把 CDF 反过来，就可以写成：

$$ InvCDF(\epsilon) = x,$$

其中 \( x\) 是从目标概率分布（列车到达时间与计划到站时间之间某个时间差的可能性）中抽出的随机数。本章我们已经说明，不一定非要对函数求逆。在代码里，我们可以直接从 CDF 得到结果。

逆变换法在计算机图形学里是基础性的，尤其是在渲染、光线追踪、采样、重要性采样以及蒙特卡罗方法中。

常见 PDF 的 CDF

有意思的是，计算机图形学中一些非常有用的函数，其 CDF 可以解析地求出。本版课程里我们要看的唯一一个函数是指数分布（下一课会用到它）。你可能猜到了，指数分布是一种基于指数函数的 PDF。它有这样的形式：

$$PDF = \lambda e^{-\lambda x }.$$

变量 \(\lambda\)（希腊字母 lambda）叫作分布的率（rate）。下面你可以看到这个函数在 \(\lambda\) 取不同值时的几个图形。注意这个 PDF 只在 x 大于 0 时有意义。

这个 PDF 非常常见。例如，放射性物质的衰变就服从指数规律。如果我们想计算一个服从指数分布的随机变量 X 大于某个值 t 的概率，可以从 t 到无穷对 PDF 积分来求这个概率：

$$ P(X > t) = \int_{t}^{\infty} \lambda e^{-\lambda x}dx = \left[ -\frac{\lambda}{\lambda} e^{-\lambda x}\right]_t^{\infty} = -e^{-\lambda \infty} - - e^{-\lambda t} = e^{-\lambda t}. $$

$$ \int e^{-ax}dx\\ u = -ax \\ du = -adx \\ dx = -\frac{du}{a}. $$

然后换元：

$$ \int e^{u}({-\frac{du}{a}}) \\ -\frac{1}{a} \int e^u du. $$

代入 \(\int e^u du = e^u + C\)，最终得到：

$$ -\frac{1}{a} e^{-ax} + constant. $$

如果你不记得怎样用微积分第二基本定理对函数积分，请看《着色的数学》那一章。记住指数函数的原函数就是指数函数本身（确实是个相当非凡的函数），且 \( e^{-\infty} = 0\)。现在，在大多数情况下（至少在 CG 里），我们更关心的是随机变量 X 小于 t 的概率。我们可以写成：

$$P(X < t) = 1 - \lambda e^{-\lambda x}.$$

而这本质上就是指数分布的 CDF。把这个函数反过来很简单：

$$ \begin{array}{l} y = 1 - \lambda e^{-\lambda x}\\ e^{-\lambda x} = 1 - y\\ -\lambda x = \ln(1 - y)\\ x = \dfrac{-\ln(1 - y)}{\lambda}. \end{array} $$

记住指数函数 \( e^x\) 的反函数是自然对数 \(\ln(x)\)。这个等式里的变量 y 就是我们均匀分布的随机变量 \(\epsilon\)，而由于该变量是均匀分布的，从概率角度看 \(1 - \epsilon\) 与 \(\epsilon\) 是类似的。于是我们反过来的 CDF 简化为：

$$x = \dfrac{-\ln(1 - \epsilon )}{\lambda} = \dfrac{-\ln(\epsilon )}{\lambda}, \text{ where } 0 \le \epsilon \le 1.$$

这是一个非常重要的结果。任何服从指数分布的随机变量都可以用这个函数采样。你要做的只是取一个均匀分布的随机数，对这个数取自然对数，再把结果除以分布的率 \(\lambda\)（它应当是已知的）。
