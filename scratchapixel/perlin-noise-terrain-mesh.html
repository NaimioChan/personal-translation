用 Perlin 噪声创建地形网格

阅读时间：7 分钟。

本章我们会学一种有趣的技巧：用 2D Perlin 噪声位移网格的顶点，从而生成地形。正如讲噪声的第一课提到的，噪声函数是一个关键的「过程式纹理」基元，可以用它构造更复杂的过程式纹理，比如分形图案或湍流图案。我们会先展示一个用简单噪声函数生成地形的例子（下图），接着再展示分形图案的例子。

这项技巧能帮我们更好地理解计算 Perlin 噪声函数导数的重要性，那正是下一章的主题。

这项技巧背后的想法很直接，与我们所说的置换贴图类似。如果你从上方俯视网格，会看到把噪声图像叠加到网格上时，二者完美吻合：每个网格顶点都对应噪声图像里的一个像素。如你所知，我们可以在某种归一化设备坐标中定义像素坐标（此时像素坐标落在 [0,1] 范围内）。网格顶点也可以这样做：这些坐标在术语上叫作纹理坐标。我们来看看创建这个网格要用的代码：


PolyMesh* createPolyMeshPlane( 
    uint32_t width = 1, 
    uint32_t height = 1, 
    uint32_t subdivisionWidth = 40, 
    uint32_t subdivisionHeight = 40) 
{ 
    PolyMesh *poly = new PolyMesh; 
    poly-&gtnumVertices = (subdivision with + 1) * (subdivisionHeight + 1); 
    poly-&gtvertices = new Vec3f[poly-&gtnumVertices]; 
    poly-&gtst = new Vec2f[poly-&gtnumVertices]; 
    float invSubdivisionWidth = 1.f / subdivisionWidth; 
    float invSubdivisionHeight = 1.f / subdivisionHeight; 
    for (uint32_t j = 0; j <= subdivisionHeight; ++j) { 
        for (uint32_t i = 0; i <= subdivisionWidth; ++i) { 
            poly-&gtvertices[j * (subdivisionWidth + 1) + i] = Vec3f(width * (i * invSubdivisionWidth - 0.5), 0, height * (j * invSubdivisionHeight - 0.5)); 
            poly-&gtst[j * (subdivisionWidth + 1) + i] = Vec2f(i * invSubdivisionWidth, j * invSubdivisionHeight); 
        } 
    } 
 
    poly-&gtnumFaces = subdivisionWidth * subdivisionHeight; 
    poly-&gtfaceArray = new uint32_t[poly-&gtnumFaces]; 
    for (uint32_t i = 0; i < poly-&gtnumFaces ++i) 
        poly-&gtfaceArray[i] = 4; 
 
    poly-&gtverticesArray = new uint32_t[4 * poly-&gtnumFaces]; 
    for (uint32_t j = 0, k = 0; j < subdivisionHeight; ++j) { 
        for (uint32_t i = 0; i < subdivisionWidth; ++i) { 
            poly-&gtverticesArray[k] = j * (subdivisionWidth + 1) + i; 
            poly-&gtverticesArray[k + 1] = j * (subdivisionWidth + 1) + i + 1; 
            poly-&gtverticesArray[k + 2] = (j + 1) * (subdivisionWidth + 1) + i + 1; 
            poly-&gtverticesArray[k + 3] = (j + 1) * (subdivisionWidth + 1) + i; 
            k += 4; 
        } 
    } 
 
    return poly; 
}

顶点的纹理坐标在第 16 行计算。这也是一个坐标落在 [0,1] 范围内的空间。网格左上角的顶点纹理坐标是 [0,0]，而右下角的顶点纹理坐标是 [1,1]。这样，用顶点的纹理坐标去查噪声图像就很方便了。

在这个例子里，我们把 2D 噪声函数的值烘焙进一张图像，再从那张图像里读取噪声值（上一章展示过怎么做）。实践中我们更可能直接求 2D 噪声函数的值。当一张图像被用来置换物体的顶点时，我们说这张图像是一张高度图（或置换贴图）。

在高度图的情况下，我们通常用像素颜色的明度（比如亮度）来控制置换的幅度。一般来说，像素越亮，置换越大，当然，如果你愿意，完全可以用另一种方式把像素值映射到置换量。这都取决于你想造出的效果。你需要记住的是：你用一张图像以某种方式控制物体顶点沿法线被置换或移动的量（法线是垂直于网格表面的方向。对于躺在 xz 平面上的平面来说，网格法线处处都是 (0,1,0)）。


for (unsigned j = 0; j < imageHeight; ++j) { 
    for (unsigned i = 0; i < imageWidth; ++i) { 
        // Perlin 噪声的范围是 [-1:1]
        float perlinNoise = PerlinNoise::evalAtPoint(Vec3f(i, j, 0) * (1 / 128.f)); 
        noiseMap[j * imageWidth + i] = (perlinNoise + 1) * 0.5; 
    } 
} 
 
// 置换
for (uint32_t i = 0; i < poly-&gtnumVertices ++i) { 
    Vec2f st = poly-&gtst[i]; 
    uint32_t x = std::min(static_cast&ltuint32_t>(st.x * imageWidth), imageWidth - 1); 
    uint32_t y = std::min(static_cast&ltuint32_t>(st.y * imageHeight), imageHeight - 1); 
    poly-&gtvertices[i].y = 2 * noiseMap[y * imageWidth + x] - 1; 
}

要记住，Perlin 噪声的值落在 [-1,1] 范围内。但当我们把这些值存进图像缓冲时，把它们重映射到了 [0,1] 范围（第 5 行）。不过后面置换顶点时，这些值又被映回 [-1,1] 范围（第 15 行），因为这样网格才能沿 y 轴保持以原点为中心。我们会把顶点向上推（值大于 0 时）或向下推（值小于 0 时），而如果值为 0，顶点的 y 坐标就保持 0。

如果你渲染这个网格，并把噪声图像作为纹理贴在上面，应该会得到与本章第一张图类似的结果。注意噪声图像中白亮的部分对应网格上的凸起，而图像中的暗部对应凹陷或谷地（也注意置换量与像素值成正比）。

正如本章开头提到的，你可以用更有趣的过程式图案来置换网格顶点，比如分形图案——它可以构造成若干噪声层的加权和。看上一课讲噪声的内容，学习如何以噪声函数为积木生成分形图案。下面是生成那张用于置换网格的分形图像的代码：


uint32_t numLayers = 5; 
float maxVal = 0; 
for (uint32_t j = 0; j < imageHeight; ++j) { 
    for (uint32_t i = 0; i < imageWidth; ++i) { 
        float fractal = 0; 
        float amplitude = 1; 
        Vec3f pt = Vec3f(i, j, 0) * (1 / 128.f); 
        for (uint32_t k = 0; k < numLayers; ++k) { 
            fractal += (1 + PerlinNoise::evalAtPoint(pt)) * 0.5 * amplitude; 
            pt *= 2; 
            amplitude *= 0.5; 
        } 
        if (fractal > maxVal) maxVal = fractal; 
        noiseMap[j * imageWidth + i] = fractal; 
    } 
} 
 
for (uint32_t i = 0; i < imageWidth * imageHeight; ++i) 
    noiseMap[i] /= maxVal;

分形图像通常比单层噪声含有更高频的细节。因此，要在置换中看到这些细节，你大概得提高网格本身的密度。下面是用分形图像置换后的网格渲染结果。
