光线与平面、光线与圆盘求交

阅读时间：4 分钟。

光线与平面求交

本章我们来看如何计算光线与平面、光线与圆盘的交点。从几何课程中我们知道，两个相互垂直的向量的点积（或标量积）总等于 0：

$$A \cdot B = 0$$

当向量 \(A\) 与 \(B\) 垂直时，这一点成立。一个平面由一个点 \(p_0\) 和一条法线 \(n\) 刻画，前者表示它到世界原点的距离，后者确定平面的朝向。对平面上任意一点 \(p\)，用 \(p\) 减去 \(p_0\) 就能得到平面上的一个向量。由于这个结果向量落在平面内，它与平面的法线垂直。利用两个垂直向量点积为 0 这一性质，得到（公式 1）：

$$(p - p_0) \cdot n = 0$$

同样，光线用参数形式描述（公式 2）：

$$l_0 + l * t = p$$

这里 \(l_0\) 表示光线的原点，\(l\) 表示光线的方向。这意味着我们可以用光线的原点、方向以及标量 \(t\) 来确定光线上的任意位置，后者是一个正实数，表示从光线原点到目标点的参数距离。如果光线与平面相交，它们就在交点处共有一个点 \(p\)。把公式 2 代入公式 1 得到：

$$(l_0 + l * t - p_0) \cdot n = 0 $$

我们的目标是求出 \(t\) 的值，以便用光线的参数方程算出交点的位置。解出 \(t\)，得到：

$$ t = -{\dfrac{(l_0-p_0)\cdot n}{l \cdot n}} = {\dfrac{(p_0 - l_0) \cdot n}{l \cdot n}} $$

值得注意的是，如果平面与光线平行（即 \(l \cdot n\) 趋近于 0），它们要么完全重合，给出无穷多解，要么根本不相交。在实际的 C++ 实现中，当分母小于一个很小的阈值时，我们通常返回 false（表示不相交）。


bool intersectPlane(const Vec3f &n, const Vec3f &p0, const Vec3f &l0, const Vec3f &l, float &t)
{
    // 假定所有向量都已归一化
    float denom = dotProduct(n, l);
    if (denom > 1e-6) {
        Vec3f p0l0 = p0 - l0;
        t = dotProduct(p0l0, n) / denom; 
        return (t >= 0);
    }

    return false;
}

光线与圆盘求交

确定光线与圆盘交点的过程很直接。通常一个圆盘由它的位置（圆盘中心）、一条法线和一个半径定义。第一步是检查光线是否与圆盘所在的平面相交。这一步的光线与平面求交，可以直接用我们为光线与平面求交测试写的代码。如果与平面有交点，下一步就是算出交点，并量出该点到圆盘中心的距离。若这个距离小于或等于圆盘半径，光线就与圆盘相交。作为优化，可以不去直接算距离，而是把距离的平方与圆盘半径的平方比较。这个平方距离可以用向量 \(v\)（见代码）与自身的点积得到。计算实际距离需要对这一点积开平方。不过为了效率，我们可以把点积结果直接与半径的平方（通常预先算好）比较，从而避开代价不小的开平方运算。


bool intersectDisk(const Vec3f &n, const Vec3f &p0, const float &radius, const Vec3f &l0, const Vec3f &l)
{
    float t = 0;
    if (intersectPlane(n, p0, l0, l, t)) {
        Vec3f p = l0 + l * t; // 计算交点
        Vec3f v = p - p0; // 从圆盘中心指向交点的向量
        float d2 = dotProduct(v, v); // 圆盘中心到交点的距离平方
        // return (sqrtf(d2) <= radius); // 直接比较距离（效率较低）
        // 优化后的做法（使用预先算好的半径平方）：
        return d2 <= radius * radius; // 比较距离平方（效率更高）
    }

    return false;
}
