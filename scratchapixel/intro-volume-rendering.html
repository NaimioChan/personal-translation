体积渲染简介

阅读时间：22 分钟。

前言：本课的结构与方法

这门课大约写于 2022 年。这虽然不算很久（写这段更新说明的时候是 2024 年 8 月），但我是在离开网站多年（超过 8 年）之后、有点匆忙地写下这门课的。

这门课之所以重要，是因为我开始做 Scratchapixel 时就对自己承诺：只要体积渲染那门课还没写，这个项目就不算完成，至少第一阶段不算。这是我职业生涯中投入相当多精力的一个主题，所以它在某种意义上对我很重要。这门课的初版还算可以，但随着时间推移我意识到它还能更好，最终我会继续打磨它。

此外，本课侧重于用一种称为光线步进的技术来实现体积渲染。这个方法未必算过时，但在现代生产级渲染软件里并不那么常用，那些软件更偏好一种称为 delta 追踪的方法。不过，在很长一段时间里，光线步进方法曾是这些软件渲染体积时事实上的标准，所以拿它作为起点来学习一点也不丢人。我认为读者从这里开始是可以的，因为它更简单，也更容易理解那些更高级方法所依托的必要数学基础。

概括一下：

  • 本课一直在持续改进中。

  • 本课聚焦光线步进技术，但后面还会有一门课去研究更现代的方法，比如 delta 追踪方法。

体积渲染（严格来说，用参与介质这个词比用「体积」更好）是一个几乎和硬表面渲染一样庞大、一样复杂的主题。它有自己的方程组，而这些方程实际上几乎是描述光与硬物质相互作用的方程的一种推广。对不太习惯这种复杂数学表述的读者来说，它们可能是难以招架的。

秉承我们在 Scratchapixel 上讲东西的方式，面对教体积渲染这个挑战，我们选择了「自下而上」的路线。换个说法，就是实践的路线。我们不从方程出发一头扎进去，而是先写代码渲染一个简单的体积球体，并在过程中以我们希望足够直观的方式解释各个环节。到最后，再把到目前为止学到的一切汇总并形式化。

体积渲染会有好几门课（这是个庞大的主题）。在这门入门课里，我们研究体积渲染与光线步进的基础。接下来的课程会讲渲染体积的其他可行方法、应用于参与介质的全局光照、多重散射，以及用来存储体积数据的格式（例如 OpenVDB）等等。

如果你对体积渲染感兴趣，可能还想看看 模拟天空的颜色 这门课。天空就是一种体积。

引言

本课头两章的目标，是学会如何渲染一个球形的体积，它被单一光源照亮、置于纯色背景之上。这能帮我们对「体积是什么」建立初步的直观理解，并引出我们用来渲染它们的算法——光线步进。

在这一章里，我们只渲染一个密度均匀的普通体积。由外部物体或体积内部投射的阴影，以及如何渲染密度变化的体积，我们都先不管。这些会在后面几章研究。

我们不去提供大量关于体积是什么、以及渲染体积所用方程的详细背景，而是直接进入实现，再从那里推导出对体积渲染更正式的理解。

内部透射率、吸收、粒子密度与 Beer 定律

光被物体反射或由光源发出后到达我们的眼睛，在穿过充满粒子的空间体积时很可能会被吸收。体积里的粒子越多，体积就越不透明。从这一简单观察出发，我们可以建立一些与体积渲染相关的基本概念：吸收、透射，以及体积的不透明度与它所含粒子密度之间的关系。眼下我们先假定体积中粒子密度是均匀的。

当光穿过体积射向我们的眼睛时（我们看到的物体图像就是这样形成的），其中一部分会被体积吸收。这个现象称为吸收。眼下我们关心的是从背景透射穿过体积的光量。我们说的是内部透射率（光在穿过体积时被体积吸收的量）。内部透射率可以看作一个从 0（体积挡住所有光）到 1（真空中所有光都透过）的值。

透射穿过该体积的光量由 Beer-Lambert 定律（简称 Beer 定律）支配。在 Beer-Lambert 定律中，密度的概念用吸收系数（以及散射系数，本章后面会介绍）来表达。本质上是「体积越密，吸收系数越高」；而如你直觉可以猜到，随着吸收系数增大，体积变得更不透明。Beer-Lambert 定律的公式是：

$$ T = \exp(-\text{distance} \times \sigma_a) = e^{-\text{distance} \times \sigma_a} $$

该定律指出，光穿过体积的内部透射率 \(T\) 与体积的吸收系数 \(\sigma_a\)（希腊字母 sigma）和光穿过材质所走的距离（即路径长度）的乘积之间，存在指数关系。

这些系数的单位是距离的倒数或长度的倒数，例如 \(cm^{-1}\) 或 \(m^{-1}\)（这只是尺度的问题）。这一点很重要，因为它有助于直觉地把握这些系数承载的是什么信息。你可以把吸收系数（以及后面会介绍的散射系数）看作某个随机事件在任意给定点／距离上发生的概率或可能性（例如光子被吸收或被散射）。

人们说吸收系数和散射系数表达的是一个概率密度（如果你想深入查这个主题的话）。既然是概率，它就不该超过 1；不过这取决于所用的度量单位。例如，用毫米为单位时，某种介质可能得到 0.2。但换成厘米和米来表示，这个值就分别变成 2 和 20。所以实践中并没有什么东西阻止你使用大于 1 的值。

系数与平均自由程之间的关系。

吸收系数和散射系数的单位是长度的倒数，这一点很重要，因为如果你取系数的倒数（1 除以吸收系数或散射系数），会得到一个距离。这个距离叫作平均自由程，代表随机事件发生的平均距离：

$$ \text{mean free path} = \frac{1}{\sigma_s} $$

这个值在模拟参与介质中的多重散射时起着重要作用。想更多了解这些非常酷的主题，请看讲次表面散射和高级体积渲染的课程。

吸收系数或距离越大，\( T \) 就越小。Beer-Lambert 定律的公式返回 0-1 范围内的数。如果距离或吸收系数为 0，公式返回 1。对非常大的距离或密度，\( T \) 趋近于 0。距离固定时，\( T \) 随吸收系数增大而减小。吸收系数固定时，\( T \) 随距离增大而减小。光在体积中走得越远，被吸收得越多。体积中粒子越多，被吸收的光越多。很简单。你可以在图 1 中看到这个效果。

Beer 与宝石。

只吸收的介质是透明的（而不是半透明的），但会使透过它看到的图像变暗（例如啤酒、葡萄酒、宝石、有色玻璃）。

在均匀背景上渲染一个体积

从这里入手很容易。想象我们有一块体积板，厚度和密度已知，比如分别是 10 和 0.1。那么，如果背景颜色（比如我们看到的一堵墙反射的光）是 \((xr, xg, xb)\)，我们透过体积看到的背景颜色有多少，就是：


vec3 background_color {xr, xg, xb};
float sigma_a = 0.1; // 吸收系数
float distance = 10;
float T = exp(-distance * sigma_a);
vec3 background_color_through_volume = T * background_color;

不能再简单了。

散射

注意，到目前为止我们一直假定体积是黑的。换句话说，我们只是把体积板所在处的背景颜色变暗。但体积不必是黑的。和实心物体一样，体积也会反射（更准确地说，散射）光。这就是为什么晴天你看一朵云时，几乎能像看实心物体那样看出云的形状。体积也可以发光（想想烛焰），这一点我们为了完整性才提一下，本章会忽略发射。

那么假定我们这块体积板有一定的颜色，比如 \((xr, xg, xb)\)。我们先不管这颜色从何而来，本章后面会解释。就姑且说，这个体积因为它像实心物体那样「反射」照亮它的光而呈现出某种颜色（并非真的反射，但现在先沿用实心物体那种「反射」的概念）。那么代码就变成：


vec3 background_color {xr, xg, xb}; 
float sigma_a = 0.1; 
float distance = 10; 
float T = exp(-distance * sigma_a); 
vec3 volume_color {yr, yg, yb}; 
vec3 background_color_through_volume = T * background_color + (1 - T) * volume_color;

可以把它想成 Photoshop 里把两张图（A+B）混合的过程，比如用 alpha 混合。假设你要把图像 B 叠到 A 上面，A 是背景图（我们那面蓝色的墙），B 是一个带透明度通道的红色圆盘的图像。把这两张图合成的公式是：

$$ C = (1 - B.\text{transparency}) * A + B.\text{transparency} * B $$

这里，透明度是 \(1 -\) 透射率（也叫不透明度），B 是我们体积物体的颜色（被体积「反射」、朝我们眼睛／相机传播的光）。等我们讨论光线步进算法时会再回到这一点；现在先记住它。

渲染我们的第一个体积球体

渲染第一张 3D 图像所需的一切已经齐了。我们用到目前为止学到的东西，渲染一个假定内部充满粒子的球体。假定球体是在某个背景之上渲染的。原理非常简单。我们首先检查相机光线与球体是否相交。如果没有交点，就直接返回背景颜色。如果有交点，就计算光线进入和离开球体表面的位置。由此可以算出光线在球体中穿过的距离，再应用 Beer 定律计算有多少光透过球体。眼下我们假定球体「反射」（散射）的光是均匀的。光照稍后再看。

实现细节。

严格来说，要得到两点之间的距离，我们并不需要算出光线进入和离开球体的位置。只要用 tmax 减去 tmin 即可（即光线与球体相交处沿相机光线的参数距离）。在下面的例子里我们把这两个点算出来，是为了强调我们这里关心的是这两点之间的距离。


class Sphere : public Object 
{ 
public: 
    bool intersect(vec3 ray_origin, vec3 ray_direction, float &t0, float &t1) const {
        // 计算光线与球体的交点
    }
    float sigma_a{ 0.1 }; 
    vec3 scatter{ 0.8, 0.1, 0.5 }; 
    vec3 center{ 0, 0, -4 }; 
    float radius{ 1 }; 
}; 
 
vec3 traceScene(vec3 ray_origin, vec3 ray_direction, const Sphere *sphere) 
{ 
    float t0, t1; 
    vec3 background_color { 0.572, 0.772, 0.921 }; 
    if (sphere-&gtintersect(ray_origin, ray_direction, t0, t1)) { 
        vec3 p1 = ray_origin + ray_direction * t0; 
        vec3 p2 = ray_origin + ray_direction * t1; 
        float distance = (p2 - p1).length();  // 不过你也可以直接写 t1 - t0 
        float transmission = exp(-distance * sphere-&gtsigma_a); 
        return background_color * transmission + sphere-&gtscatter * (1 - transmission); 
    } 
    else {
        return background_color; 
    }
} 
 
void renderImage() 
{ 
    Sphere *sphere = new Sphere; 
    for (each row in the image) {
        for (each column in the image) {
            vec3 ray_dir = computeRay(col, row); 
            vec3 pixel_color = traceScene(ray_origin, ray_dir, sphere); 
            image_buffer[...] = pixel_color;  // 把像素颜色存入图像缓冲区 
        }
    }
    saveImage(image_buffer); 
    //...
}

很合乎逻辑，随着密度增大，透射率趋近于 0，也就是说体积球体的颜色压过了背景颜色。

在上面那些图里可以看到，体积在球体中心附近变得更不透明，那里光线穿过球体的距离最长。你还能看到，随着密度增大（sigma_a 增大），球体整体变得更不透明。成了！你刚刚渲染出了自己的第一个体积球体，成为体积渲染专家的路已经走了一半。

加上光！入射散射

到现在我们有了一个漂亮的体积球体图像，可光照呢？如果把光照到一个体积物体上，可以看到更直接暴露在光下的那部分体积比处于阴影中的部分更亮。体积和实心物体一样会被光照亮。我们怎么把它考虑进来？

原理很简单。想象光源发出的光在体积中穿行时的遭遇。在体积中穿行时，它的强度会因吸收而衰减。不出意外，光在体积中走过一段距离后还剩多少能量，由 Beer 定律决定。换句话说，如果知道光在体积中走过的距离，它在该距离处的强度就是：


float light_intensity = 10; // 只是个数字，可以取任意值 
float T = exp(-distance_travelled_by_light * volume-&gtabsorption_coefficient); 
float light_intensity_attenuation = T * light_intensity;

如我们上面刚学到的，光能量在穿过体积时按 Beer 定律减少。这说得通。但还有别的事在发生：光沿着它被发出的方向传播，在这条路径上，一部分被吸收，但也有一部分被散射到与初始发出方向不同的方向上。如果那个方向正对着视线方向的反方向，那么这些光就会打到你的眼睛或相机传感器的表面。这和光从实心物体表面反射的过程非常相似，但有几处有意思的细微差别。

由于云不是实心物体，光打到粒子上可能发生两种情况：

  • 它可能被吸收。

  • 它可能被散射。说到体积时我们不说反射，更愿意说散射。光被散射了。

如果光在体积里没有打到粒子，它当然会沿同一方向继续传播。光被吸收与被散射的概率对比，眼下我们先不关心。此刻你需要留意的一点是：如果光被散射到与视线方向相反的方向上，那么光源发出的这部分光最终会打到你的眼睛，尽管它一开始（被光源发出时）并不是沿那个方向传播的。这个效应叫作入射散射。入射散射指的是穿过体积的光因一次散射事件而被重新导向眼睛。

这个效应在图 4 中作了图示。散射事件是光子与构成介质／体积的粒子或原子相互作用的结果。原子不是把光子吸收掉，而是把光子朝与其入射方向不同的方向「吐」出来（如果体积由水或烟这类分子构成），或者在烟中含有极小的固体颗粒（如灰尘、烟灰、海盐等）时从这些微粒上反射。我们会在后面几章进一步了解这个现象。

看图 4 时注意，到达眼睛的光（沿图中画成蓝色的那条特定的眼睛／相机光线）是两部分光之和：来自背景（我们那个蓝色背景）的光，以及来自光源、因入射散射而被散射向眼睛的光（黄色光线）。

一个体积的外观，也就是你从某个给定视点看到的那个体积，因此是若干种被吸收的光的组合：可能是沿穿过它的视线直接可见的背景的光，也可能是场景中各个光源发出的、从所有可能方向照亮这朵云的光。要生成一朵云的真实感图像，我们就需要考虑这两个效应。吸收我们已经看过了，现在需要考虑如何处理入射散射效应。

目标是设法找到一种办法，度量由于入射散射效应而被散射向眼睛（沿相机光线）的光。但问题在于：沿视线被散射的光可能发生在 \( t_0 \) 与 \( t_1 \) 之间的任何位置，这两个点界定了沿相机光线（更准确地说，是沿相机光线方向的反向）朝眼睛传播的光处于球体边界内的范围。这并不是一个光粒子落在 \( t_0 \) 与 \( t_1 \) 所定线段上特定位置的离散过程。不是的，这是一个光沿该线段被连续吸收和散射的现象。那么我们如何度量沿一段给定距离的连续光能流入？

在看这个问题的解法之前，我们先约定一些记号。我们定义 \( L_i(x, \omega) \) 为一个函数，它以辐射亮度给出有多少光被散射向眼睛的方向（用希腊字母 \(\omega\)，即 omega，表示），其中 \( x \) 定义了线段 \( t_0 \) 到 \( t_1 \) 上的任意一点（如果你不熟悉辐射度量单位，请查看讲渲染方程的课程）。

在物理学中，当需要表示某种能量在某段距离或某个体积上的流入时，我们用积分来表达这个度量。换句话说，我们这里想要的是把函数 \( L_i(x, \omega) \) 在 \( t_0 \) 到 \( t_1 \) 的范围上积分，得到的数基本上就是我们要找的东西。如果你对积分的概念不太熟悉，可以把它读作「把沿方向 \(\omega\) 的光线、在参数距离 \( t_0 \) 到 \( t_1 \) 之间被散射的所有光能收集起来」。如果这些量是离散的，我们直接把它们相加就行；但当函数是连续的（比如 \( L_i \)）时，我们就用积分来表达这个想法。实践中，这个积分写成：

$$\int_{x=t_0}^{t_1} Li(x, \omega) dx$$

我们不再重讲一门积分的课。如果你不熟悉积分的概念以及最常用的求值方法，请看 着色的数学 那门课。但这里提醒自己一下：积分度量的是被积函数曲线下方的面积。对于 \( y=f(x) \) 这种函数，它定义的是曲线而不是曲面，若是曲面那度量的就是体积了。

问题在于，我们需要求值的那个积分没有解析解。对球形这类形状简单的体积、以及简单的光照情形，也许会有解析解，但既然我们要的是一个适用于任意体积形状（包括本课后面会看到的非均匀体积）、以及任意光照情形的解，走这条路没有意义。那该怎么办？我们就采用实验物理与实践物理、以及计算机图形学里大多数时候的做法（至少就为电影或电子游戏做图像而言，世界的命运并不取决于我们的计算）：用一种称为黎曼和法的技术来近似这个积分。

黎曼和背后的想法很简单。我们可以把曲线下方的面积拆成面积已知的更简单的形状，比如矩形（图 7）。然后我们以已知宽度的固定间隔（\( dx \)）沿曲线对 \( L_i(x, \omega) \) 采样，所得矩形的面积就可以算成 \( L_i(x, \omega) \) 乘以 \( dx \)（其中 \( x \) 位于区间的中点）。把所有矩形的面积加起来，就得到曲线下面积的一个近似（如图 7 所示）。成了！如前所述，结果并不精确等于曲线下的面积，只是一个近似，看图 7 应该就能看明白。而你大概也能直观理解：矩形的宽度越小（\( dx \) 越小），我们越接近曲线下的真实面积（但处理时间也越长）。

具体到我们的体积渲染问题，实践中怎么做？这个我们下一章再看。但你可能已经猜到了，作为预告：它本质上归结为把相机光线位于球体边界内的那一段划分成长度为 \( dx \) 的更小段。对每个小段，我们计算函数 \( L_i(x, \omega) \)。这包括（图 5）：

  • 从位于小段中点的 \( x \) 向光源方向射一条光线，看它从哪里离开体积物体。这能告诉我们光从光源出发、穿过体积到达 \( x \) 所走过的距离。

  • 有了这个距离，我们就可以应用 Beer 定律，知道光在体积中走过这段距离后还剩多少能量。

然后我们把 \( L_i(x, \omega) \) 乘以 \( dx \)，并累加每个小段的贡献。就这样。

不过，机敏的读者会意识到有一个问题我们没回答。事实上，应该指出两点观察：

  • 喂，抱歉，可是现在我们已经知道有多少光从光源到达采样位置 \( x \) 了。这没问题。但这并没有告诉我们这些光最终有多大比例被入射散射到方向 \( \omega \) 上。说得好。你确实还没看到 \( L_i(x, \omega) \) 到底做什么的完整图景。换句话说，我们看了 \( L_i(x) \) 那部分，但还没用上 \( \omega \) 这个变量，如你所猜，它在这个比例的计算中起作用。

  • 其次，沿 \( \omega \) 被散射的光，在从 \( x \) 到 \( t_0 \) 的途中不也在被吸收吗？换句话说，假定 \( x \) 位于体积内（它确实在），它在离开体积、到达我眼睛之前，仍需要在体积里走一段距离。所以我猜在这段体积内走过的距离上，这些光也被吸收了。没错！

好吧，如果你能直觉地想到这两点观察，那你很棒，我们也值得夸一夸。这意味着你可以进入下一章了，我们会在那里处理它们。
