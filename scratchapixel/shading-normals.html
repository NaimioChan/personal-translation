法线、顶点法线与朝向比

阅读时间：11 分钟。

现在我们已经梳理了影响物体外观的参数（有多亮、什么颜色等等），可以开始学习一些基本的着色技术了。

法线

法线在着色中起核心作用。众所周知，物体朝向光源时会显得更亮。物体表面的朝向，在决定它反射多少光、从而决定其表观亮度上至关重要。物体表面上任一点 \(P\) 处的这个朝向，可以用法线 \(N\) 表示，法线在 \(P\) 处垂直于表面，如图 1 所示。注意图 1 中，随着光方向与法线之间的夹角增大，球的亮度如何下降。这种亮度下降是常见的观察，但很少有人理解其原因。我们稍后会解释这一现象。现在我们只需记住：

  • 「法线」一词（用大写字母 \(N\) 表示）指的是垂直于物体表面上 \(P\) 处表面切线的向量。换句话说，要找到 \(P\) 处的法线，我们需要在 \(P\) 处画一条与表面相切的线，然后取垂直于这条切线的向量（注意在 3D 中这会是一个切平面）。

  • 物体表面某一点的亮度取决于法线的方向，法线定义了该点处物体表面相对于光的朝向。换个说法：物体表面上任一点处的亮度，取决于该点法线与光方向之间的夹角。

现在的问题是，我们怎么计算这条法线？解的复杂程度会因所渲染几何体的类型而有很大差别。球面的法线通常很容易求出。如果已知球面上一点的位置与球心，该点处的法线可以通过用球心减去该点位置算出：


Vec3f N = P - sphereCenter;
也可以用基于微分几何的更复杂技术来计算球面上某点的法线，但本节不会研究这些技术。

如果物体是三角网格，那么每个三角形定义一个平面，垂直于该平面的向量就是落在这个三角形表面上的任一点的法线。垂直于三角形平面的向量可以很方便地用该三角形两条边的叉积得到。请记住 \(v1 \times v2 = -v2 \times v1\)。因此，边的选择会影响法线的方向。如果你按逆时针顺序声明三角形的顶点，那么可以用下面的代码：


Vec3f N = (v1-v0).crossProduct(v2-v0);

如果三角形位于 xz 平面内，那么得到的法线应该是 \((0,1,0)\) 而不是图 2 中所示的 \((0,-1,0)\)。

以这种方式算出的法线，我们称之为面法线（因为对于整个面来说法线都一样，与在该面或该三角形上选哪个点无关）。三角网格的法线也可以定义在三角形的顶点上，那里称为顶点法线。顶点法线用于一种叫作平滑着色的技术，本章末尾会讲到。眼下我们只关注面法线。

在你的程序里，如何以及何时计算即将被着色的那一点处的表面法线，并不重要。关键在于当你准备给该点着色时，这个信息已经就绪。在本节少数几个执行了基本着色的程序里，我们在每个几何体类中都实现了一个特殊方法 getSurfaceProperties()。在这个方法里，我们计算交点处的法线（如果使用光线追踪），以及其他变量，比如纹理坐标，后者本课后面会讨论。下面是球体和三角网格两种几何体类型中这些方法实现的样子：


class Sphere : public Object 
{ 
    ... 
public: 
    ... 
    void getSurfaceProperties( 
        const Vec3f &hitPoint, 
        const Vec3f &viewDirection, 
        const uint32_t &triIndex, 
        const Vec2f &uv, 
        Vec3f &hitNormal, 
        Vec2f &hitTextureCoordinates) const 
    { 
        hitNormal = hitPoint - center; 
        hitNormal.normalize(); 
        ... 
    } 
    ... 
}; 
 
class TriangleMesh : public Object 
{ 
    ... 
public: 
    void getSurfaceProperties( 
        const Vec3f &hitPoint, 
        const Vec3f &viewDirection, 
        const uint32_t &triIndex, 
        const Vec2f &uv, 
        Vec3f &hitNormal, 
        Vec2f &hitTextureCoordinates) const 
    { 
        const Vec3f &v0 = P[trisIndex[triIndex * 3]]; 
        const Vec3f &v1 = P[trisIndex[triIndex * 3 + 1]]; 
        const Vec3f &v2 = P[trisIndex[triIndex * 3 + 2]]; 
        hitNormal = (v1 - v0).crossProduct(v2 - v0); 
        hitNormal.normalize(); 
        ... 
    } 
    ... 
};

一个简单的着色效果：朝向比

现在我们知道了如何计算物体表面某一点的法线，也就有了足够的信息来做一个简单的着色效果，叫作朝向比。这项技术要计算待着色点处的法线与视线方向的点积。确定视线方向很直接。在光线追踪中，它就是与表面在 \(P\) 处相交的那条光线的方向的反向。如果你不用光线追踪，视线方向也可以通过从表面上的点 \(P\) 向眼睛 \(E\) 画一条线来确定：


Vec3f V = (E - P).normalize(); // 或者用 -ray.dir，如果你使用光线追踪

记住，两个向量的点积在它们平行且同向时返回 1，在它们垂直时返回 0。如果两个向量指向相反方向，点积为负。由于我们把结果当作颜色使用，不关心负值，所以需要把结果钳制到零：


float facingRatio = std::max(0.0f, N.dotProduct(V));

当法线与向量 \(V\) 指向同一方向时，点积返回 1。如果两个向量垂直，结果为 0。用这个简单的技术着色一个位于画面中心的球，球心会呈现白色，越靠近边缘越暗，如下图所示。


Vec3f castRay( 
    const Vec3f &orig, const Vec3f &dir, 
    const std::vector&ltstd::unique_ptr&ltObject>> &objects, 
    const Options &options) 
{ 
    Vec3f hitColor = options.backgroundColor; 
    float tnear = kInfinity; 
    Vec2f uv; 
    uint32_t index = 0; 
    Object *hitObject = nullptr; 
    if (trace(orig, dir, objects, tnear, index, uv, &hitObject)) { 
        Vec3f hitPoint = orig + dir * tnear;  // 着色点 
        Vec3f hitNormal; 
        Vec2f hitTexCoordinates; 
        // 计算待着色点处的法线
        hitObject-&gtgetSurfaceProperties(hitPoint, dir, index, uv, hitNormal, hitTexCoordinates); 
        hitColor = std::max(0.f, hitNormal.dotProduct(-dir));  // 朝向比 
    } 
 
    return hitColor; 
}

恭喜！你刚刚学会了第一堂着色技术。现在我们来探索一种更真实的着色方法，用它模拟光对漫反射物体的影响。不过在深入这个方法之前，我们需要先介绍并理解光的概念。

平直着色与平滑着色、顶点法线

三角网格的局限在于，除非三角形非常小，否则它们无法完美表示光滑曲面。把朝向比技术用于多边形网格时，你需要计算光线所交三角形的法线，并以这个面法线与视线方向的点积来计算朝向比。这种做法会让物体呈现出刻面感，如下图所示。这种着色方法因而被称为平直着色。

如前所述，三角形的法线可以通过计算向量的叉积求得，例如 \(v0v1\) 与 \(v0v2\)，其中 \(v0\)、\(v1\)、\(v2\) 表示三角形的顶点。为解决刻面感问题，Henri Gouraud 在 1971 年提出了一种方法，现在称为平滑着色或Gouraud 着色。这项技术旨在让多边形网格表面上的着色连续，这样尽管网格由平面（多边形或三角形）构成，却能模拟出一个连续的物体。为此，Gouraud 引入了顶点法线的概念。我们不再为每个面计算或存储一条法线，而是在网格的每个顶点上存一条法线。这些法线与网格所逼近的底层光滑曲面保持一致。着色三角形表面上的某一点时，用交点重心坐标对三角形各顶点处的顶点法线做线性插值，算出一条「假光滑」法线。

用三角形的重心坐标插值任意图元变量——包括颜色、纹理坐标或法线——的技术，在前面几课中已经讲过。如果你还不熟悉这种方法，我们建议阅读「光栅化：实践实现」课程的 光栅化阶段 一章。

上图说明了这项技术。定义在三角形顶点上的顶点法线，垂直于三角网格所逼近的底层光滑曲面。有时三角网格并非直接由光滑曲面导出，此时顶点法线必须即时计算。在没有光滑曲面可依据时，计算顶点法线有多种技术，本课不会探讨。请改用 Maya 或 Blender 这类软件来处理；比如在 Maya 中，你可以选中多边形网格，在 Normals 菜单里选择「Soften Edge」选项。

从实践与技术角度看，每个三角形都有自己的一套三条顶点法线，也就是说，一个三角网格的顶点法线总数等于三角形数量乘以三。在某些情况下，两个或多个三角形共享的顶点上的顶点法线是相同的（指向同一方向），但通过给它们赋不同朝向，可以实现不同的效果（例如模拟表面上的硬边）。

下面是计算三角形表面上任一点插值法线的源代码，假定你已经有了该三角形的顶点法线、该点的重心坐标以及三角形索引：


void getSurfaceProperties( 
    const Vec3f &hitPoint, 
    const Vec3f &viewDirection, 
    const uint32_t &triIndex, 
    const Vec2f &uv, 
    Vec3f &hitNormal, 
    Vec2f &hitTextureCoordinates) const 
{ 
    const Vec3f &v0 = P[trisIndex[triIndex * 3]]; 
    const Vec3f &v1 = P[trisIndex[triIndex * 3 + 1]]; 
    const Vec3f &v2 = P[trisIndex[triIndex * 3 + 2]]; 
    hitNormal = (v1 - v0).crossProduct(v2 - v0);  // 面法线

    // 用 Gouraud 技术计算「光滑」法线（插值顶点法线）
    const Vec3f &n0 = N[trisIndex[triIndex * 3]]; 
    const Vec3f &n1 = N[trisIndex[triIndex * 3 + 1]]; 
    const Vec3f &n2 = N[trisIndex[triIndex * 3 + 2]]; 
    hitNormal = (1 - uv.x - uv.y) * n0 + uv.x * n1 + uv.y * n2; 
    hitNormal.normalize();  // 为保险起见归一化，尽管 N 本身已经归一化

    // 纹理坐标
    const Vec2f &st0 = texCoordinates[trisIndex[triIndex * 3]]; 
    const Vec2f &st1 = texCoordinates[trisIndex[triIndex * 3 + 1]]; 
    const Vec2f &st2 = texCoordinates[trisIndex[triIndex * 3 + 2]]; 
    hitTextureCoordinates = (1 - uv.x - uv.y) * st0 + uv.x * st1 + uv.y * st2; 
}

尽管这项技术能产生光滑表面的观感，你仍能注意到多边形球体带刻面的轮廓，如下图所示。这项技术改善了三角网格的外观，但并未彻底解决其刻面感问题。最终的解决方案是使用细分曲面（后面某一节会讨论），或者在把光滑曲面转换成三角网格时增加所用三角形的数量。
