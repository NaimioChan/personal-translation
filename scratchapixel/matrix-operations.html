矩阵运算

阅读时间：2 分钟。

转置

矩阵的转置记作 \(M^T\)，是把矩阵 \(M\) 沿主对角线（从左上到右下）翻转得到的，效果就是把 \(M\) 的各行变成 \(M^T\) 的各列，反之亦然。转置操作在代码里可以这样实现：


Matrix44 transpose() const {
    Matrix44 transpMat;
    for (uint8_t i = 0; i < 4; ++i) {
        for (uint8_t j = 0; j < 4; ++j) {
            transpMat[i][j] = m[j][i];
        }
    }
    return transpMat;
}

这段代码演示了行列互换的做法，由于该操作不是原地进行的，需要用一个新矩阵来存放转置后的值。转置在行主序与列主序两种矩阵约定之间转换时特别有用——不同的 3D 应用用的约定并不相同。

求逆

矩阵求逆这个概念在线性代数中起着关键作用，在 3D 图形学中尤其如此。如果点 A 乘以矩阵 \(M\) 被变换成点 B，那么把 B 乘以 \(M^{-1}\)（即 \(M\) 的逆），就能把 B 还原成 A。用数学写出来是 \(MM^{-1} = I\)，其中 \(I\) 是单位矩阵。矩阵与其逆相乘，结果就是单位矩阵。

在 矩阵如何工作 一节中讨论过正交矩阵，指出它的逆可以直接通过转置得到。正交矩阵的定义是：它的各行与各列都是正交的单位向量。这一性质对 3D 图形学中变换法线这类过程至关重要。

矩阵求逆对于在坐标系之间变换点或向量这类操作至关重要。例如在 3D 渲染中，通常要把光线的方向与起点变换到物体空间去做求交测试。如果发生了相交，要把交点转回世界空间，就需要变换矩阵的逆。

矩阵求逆 一课详述了如何计算矩阵的逆。要写出哪怕一个最基本的渲染器，理解和运用矩阵求逆都是不可或缺的，那里也会给出实用的代码示例来帮助理解。
