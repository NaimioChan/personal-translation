三线性插值

阅读时间：6 分钟。

三线性插值是双线性插值技术的直接延伸。它可以看作两个双线性插值的线性插值：一个针对格子的前表面，一个针对后表面。要算出 e 和 f，我们用上一章讲的技术做两次双线性插值。要算出 g，我们沿 z 轴（用 tz，也就是采样点 g 的 z 坐标）对 e 和 f 做线性插值。

三线性插值的优缺点和它的二维版本一样。它快、容易实现，但结果不够平滑。不过在体积渲染或流体模拟中，需要在三维网格里做极大量的查找，它仍然是个很好的选择。

下面是网格上三线性插值的一个简单例子。注意，和双线性插值一样，结果可以用一系列操作算出来（第 43 到 45 行），也可以写成格子 8 个角点的加权和（第 47 到 55 行）。


template&lttypename T> 
class Grid 
{ 
public: 
    unsigned nvoxels;  //体素数量（立方体） 
    unsigned nx, ny, nz;  //顶点数量 
    Vec3&ltT> *data; 
    Grid(unsigned nv = 10) : nvoxels(nv), data(NULL) 
    { 
        nx = ny = nz = nvoxels + 1; 
        data = new Vec3&ltt>[nx * ny * nz]; 
        for (int z = 0; z < nz + 1; ++z) { 
            for (int y = 0; y < ny + 1; ++y) { 
                for (int x = 0; x < nx + 1; ++x) { 
                    data[IX(x, y, z)] = Vec3&ltt>(drand48(), drand48(), drand48()); 
                } 
            } 
        } 
    } 
    ~Grid() { if (data) delete [] data; } 
    unsigned IX(unsigned x, unsigned y, unsigned z) 
    { 
        if (!(x < nx)) x -= 1; if (!(y < ny)) y -= 1; if (!(z < nz)) z -= 1; 
        return x * nx * ny + y * nx + z; 
    } 
    Vec3&ltT> interpolate(const Vec3&ltT>& location) 
    { 
        T gx, gy, gz, tx, ty, tz; 
        unsigned gxi, gyi, gzi; 
        // 把点的坐标重映射到网格坐标
        gx = location.x * nvoxels; gxi = int(gx); tx = gx - gxi; 
        gy = location.y * nvoxels; gyi = int(gy); ty = gy - gyi; 
        gz = location.z * nvoxels; gzi = int(gz); tz = gz - gzi; 
        const Vec3&ltT> & c000 = data[IX(gei, gyi, gzi)]; 
        const Vec3&ltT> & c100 = data[IX(gxi + 1, gyi, gzi)]; 
        const Vec3&ltT> & c010 = data[IX(gxi, gyi + 1, gzi)]; 
        const Vec3&ltT> & c110 = data[IX(gxi + 1, gyi + 1, gzi)]; 
        const Vec3&ltT> & c001 = data[IX(gxi, gyi, gzi + 1)]; 
        const Vec3&ltT> & c101 = data[IX(gxi + 1, gyi, gzi + 1)]; 
        const Vec3&ltT> & c011 = data[IX(gxi, gyi + 1, gzi + 1)]; 
        const Vec3&ltT> & c111 = data[IX(gxi + 1, gyi + 1, gzi + 1)]; 
#if 1 
        Vec3&ltT> e = bilinear&ltVec3&ltT> >(tx, ty, c000, c100, c010, c110); 
        Vec3&ltT> f = bilinear&ltVec3&ltT> >(tx, ty, c001, c101, c011, c111); 
        return e * ( 1 - tz) + f * tz; 
#else 
        return 
            (T(1) - tx) * (T(1) - ty) * (T(1) - tz) * c000 + 
            tx * (T(1) - ty) * (T(1) - tz) * c100 + 
            (T(1) - tx) * ty * (T(1) - tz) * c010 + 
            tx * ty * (T(1) - tz) * c110 + 
            (T(1) - tx) * (T(1) - ty) * tz * c001 + 
            tx * (T(1) - ty) * tz * c101 + 
            (T(1) - tx) * ty * tz * c011 + 
            tx * ty * tz * c111; 
#endif 
    } 
}; 
 
template&lttypename T> 
void testTrilinearInterpolation() 
{ 
    Grid&ltT> grid; 
    for (unsigned i = 0; i < 1000; ++i) { 
        // 生成一个随机位置
        Vec3&ltT> result = grid.interpolate(Vec3&ltt>(drand48(), drand48(), drand48())); 
    } 
}

实现细节（2024 年更新）

这门课最初写完之后，我们为修 bug 对代码做了些改动（2024 年）。检查代码的输出不像二维图像插值那样简单直接。原因是三维网格主要用来存储和渲染体积物体，要正确测试插值，得有一个能处理体积的渲染器。

这门课最初写的时候，体积渲染那门课还没有。现在情况不同了。我们推荐看看体积渲染这门课，那里有三维线性插值的一个可能用法。

同时，代码也做了改进：为输出/升采样网格的每个切片输出一帧。把输出的图像逐张过一遍，就能实际看到插值的结果。感谢 @kristopolous 提出这个建议，并修改代码实现了这个想法。

下面是该程序输出结果的可视化。初始三维网格 scr_grid3d 的分辨率是 8x8x8，程序要把这个网格升采样成 target_grid3d，大小为 128x128x128。程序遍历升采样网格（target_grid3d）的每个顶点，用低分辨率网格的数据做三线性插值来设定它们各自的值。实现这门技术时，有几点需要小心：

  • 顶点数等于网格在任一维度上构成该维度的格子数加 1（在代码示例中，网格三个轴的维度相同）。
