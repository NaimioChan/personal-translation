随机变量函数的期望值：无意识统计学家定律

阅读时间：7 分钟。

这一章我们要讲一个对蒙特卡罗方法非常重要的概念。在讲期望值的那一章里，我们解释过如何计算离散随机变量 X 的期望值。X 的期望值就是每个结果乘以其概率后求和（如上一章所述，概率由概率质量函数即 PMF 给出）。它可以看作一个加权平均：

$$E[X] = \sum_{i=0}^{N-1} X_i pmf(X_i),$$

其中 N 表示随机变量 X 可能取的结果数，PMF 是概率质量函数。它给出结果 \(X_i\) 出现的概率。如前几章所提示的，计算这个期望值在某种程度上类似于计算一个悬挂物的质心。

把这个概念推广到连续随机变量，我们得到：

$$E[X] = \int_{-\infty}^{\infty} X pdf(X).$$

这是一个重要的结果。现在，设想你有一个 x 的函数 f：f(x)。再设想这个函数定义在 x 值的某个区间上。我们把这个区间记作 [a,b]。现在我们设想变量 X 也定义在区间 [a,b] 上。换句话说，你每次从 X 中取一个数，都会得到 [a,b] 区间内的某个值。这里的想法是把 X 当作函数 f 的参数。也就是说，f 是随机变量 X 的函数，可以写成：f(X)。

举个实际的例子，设想我们有一个随机变量 X，它返回 1 到 6 之间均匀分布的整数。均匀分布的意思是每个结果的概率都是 1/6。现在我们设想有一个这样的函数：

$$F(X) = (X - 3)^2.$$

如果我们从 X 中取一个随机数，它返回 2，那么在 X = 2 时 \(F(X) = (X - 3)^2\)，得到 \(F(2) = (2 - 3)^2 = 1\)。

要特别注意的是：如果 X 是随机变量，那么 F(X) 也是随机变量。如果我们无法预测 X 的结果，那显然也无法预测 F(X) 的结果。两者都是随机变量，不过还要注意，我们可以把 F(X) 看作对 X 做变换的一个函数。换句话说，F(X) 是 X 的一个变换版本。不要以为 F(X) 会和 X 有相同的概率分布函数。也就是说，X 的映射或变换会引出另一个概率分布函数。记住这两个要点：

  • 如果 X 是随机变量，那么 X 的任何函数 F(X) 也是随机的。

  • X 与 F(X) 各有自己唯一的概率分布（当然，除非 F(X) = X）。

还要注意，即使我们事先知道 X 的概率分布，若想知道 F(X) 的概率，你仍然需要去计算它（后面我们会讲怎么做）。

回到我们的例子。我们知道，对于可能结果为 {1, 2, 3, 4, 5, 6} 的均匀分布随机变量，每个结果的概率都是 1/6。如果函数 F(X) 定义为 \((X - 3)^2\)，我们来算一下 F(X) 的概率分布。对 X 的每个结果，我们都要算出 F(X) 的结果。其中有些结果会有相同的值，于是它们的概率会叠加。根据乘法法则，某个结果的概率等于该结果在集合中出现的次数除以可能结果的总数（在我们的实验里是 6）。我们来算：

$$ \begin{array}{l} X = 1, \; F(1) = (1-3)^2 = 4,\\ X = 2, \; F(2) = (2-3)^2 = 1,\\ X = 3,\;F(3) = (3-3)^2 = 0,\\ X = 4,\;F(4) = (4-3)^2 = 1,\\ X = 5,\;F(5) = (5-3)^2 = 4,\\ X = 6,\;F(6) = (6-3)^2 = 9. \end{array} $$

从上面的表可以看到，对 X 的每个结果计算 F(X)，得到一个零、两个一、两个四和一个九。F(X) 的某个结果 Y 的概率，等于所有使 F(X) = Y 的 X 的概率之和。于是得到：

$$ \begin{array}{l} Pr(F(0)) &=& \dfrac{1}{6}\\ Pr(F(1)) &=& \dfrac{1}{6} + \dfrac{1}{6} &=& \dfrac{2}{6}\\ Pr(F(4)) &=& \dfrac{1}{6} + \dfrac{1}{6} &=& \dfrac{2}{6}\\ Pr(F(9)) &=& \dfrac{1}{6}. \end{array} $$

现在，如果我们想计算 F(X) 的期望值，可以走两条路。如果知道 F(X) 的概率分布，我们可以写（方法 1）：

$$ \begin{split} E[F(X)]&=&0 \times Pr(F(X) = 0) + 1 \times Pr(F(X) = 1) +\\ &&4 \times Pr(F(X) = 4) + 9 \times Pr(F(X) = 9),\\ &=&0 * \dfrac{1}{6} + 1 * \dfrac{2}{6} + 4 * \dfrac{2}{6} + 9 * \dfrac {1}{6},\\ &=&3.167. \end{split} $$

在数学上，如果记 Y 为随机变量 F(X)、\(P_Y\) 为 Y 的概率分布，我们得到：

$$E[F(X)] = E[Y] = \sum Y_i P_Y(Y_i).$$

其中求和遍历 Y 的所有可能取值（例中是 4 个：{0,1,4,9}）。

或者，如果你不知道 F(X) 的概率分布，你仍然可以用已知的 X 的概率分布来计算 E[Y]（方法 2）：

$$ \begin{split} E[F(X)] & = &(1-3)^2\times Pr(X = 1) + (2-3)^2\times Pr(X = 2) +\\ && (3-3)^2\times Pr(X = 3)+ (4-3)^2\times Pr(X = 4) +\\ && (5-3)^2\times Pr(X = 5) + (6-3)^2\times Pr(X = 6)\\ &=&4 * \dfrac{1}{6} + 1 * \dfrac{1}{6} + 0 * \dfrac{1}{6} + 1 * \dfrac{1}{6} + 4 * \dfrac{1}{6} + 4 * \dfrac{1}{6}\\ &=&3.167. \end{split} $$

数学上我们会把这个结果写成：

$$E[F(X)] = F[Y] = \sum F(X_i) P_X(X_i).$$

其中求和遍历 X 的所有可能取值（例中是 6 个：{0,1,2,3,4,5,6}）。

这是一个重要结果，因为在实践中你未必知道 F(X) 的概率分布。当然你可以把它算出来，但那是额外的一步，用第二种方法就能省掉。数学上，这个结果可以写成：

$$E[F(X)] = \sum F(X) P_X(X),$$

对离散随机变量而言，以及：

$$E[F(X)] = \int F(X) P_X(X) \:dX,$$

对连续随机变量而言。这些公式非常关键，在蒙特卡罗方法中起着本质性的作用。在数学里，它们有时被称为无意识统计学家定律。我们不太确定为什么这么叫，但常见的解释是：事实上大多数人并没有意识到，当他们计算随机变量函数的期望值之类的东西时，用的并不是第一种解法（即用 F(X) 的概率分布）去算 E[F(X)]，而是第二种解法（即用 X 的概率分布）：

当统计学家以为自己在算 \(E[Y] = \sum Y_i P_Y(Y_i)\) 时，他/她实际经常在算的是 \(E[F(X)] = \sum X_i P_X(Y_i)\)。结果虽然相同，但前者需要 F(X) 的概率分布，后者不需要。

记住这个方法的妙处在于：只要你知道 X 的概率分布，就不必知道 F(X) 的概率分布也能算出它的期望值。

这个结果就是蒙特卡罗积分的基础。
