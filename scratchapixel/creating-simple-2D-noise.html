创建一个简单的二维噪声

阅读时间：15 分钟。

上一章我们已经讲清了制造噪声所用的大部分技术。从今往后，创建更高维的噪声应该是容易得多的事，因为它们都基于相同的概念与技术。往下学之前，务必先掌握并真正理解上一章讲的内容。如果还有不清楚的，重读一遍，或者有问题就给我们发邮件。

记住所有噪声函数都返回一个浮点数，但它的输入可以是一个浮点数、一个二维点或一个三维点。噪声函数的名称与输入值的维度有关。二维噪声就是取二维点作为输入的噪声函数。三维噪声取三维点，我们在本课第一章甚至提到过四维噪声，其中第四维实际上代表时间（它将基于三维点产生噪声图案，但随时间变化）。

如果你读过插值一课（如果还没读，我们建议现在就读），你可能已经知道二维噪声怎么运作。对于二维情形，我们把随机值分布在规则二维网格的顶点位置上（图 1）。二维版本的噪声函数将取一个二维点作为输入。我们把这个点叫 P。与一维版本类似，我们需要找出该点在网格上的位置。同一维情形一样，我们的二维网格有一个预先设定的分辨率（网格是正方形，所以沿 x 轴与 y 轴的分辨率相同）。为了便于说明，假定是 4（一个二的幂）。如果点落在网格边界之外（P 的坐标小于 0 或大于 4），我们同样用取模的方法把 P 的位置重映射到网格上。我们对 P 的 x 与 y 坐标做取模运算。这就给出该点在网格上的新坐标（把这个新点叫 Pnoise）。

如图 2 与图 3 所示，这个点被某个单元格的四个顶点包围。我们会用插值一课里描述的相同技术，通过对单元格角点的值做线性插值来求出该点的值。为此，我们先计算 tx 与 ty，它们相当于一维噪声中的 t。

用 tx，我们现在可以把左侧两个角点的值与右侧两个角点的值做插值。这会得到两个值 nx0 与 nx1，它们分别对应 c01/c10（nx0）与 c01/c11（nx1）沿 x 轴的线性插值。现在我们得到了单元格下边缘与上边缘、并与 Pnoise 的 x 坐标垂直对齐的两个插值结果，接着用 ty 对它们做线性插值。沿 y 轴这次插值的结果，就是 P 的最终噪声值。

下面是我们简单二维值噪声的代码。网格每边大小为 256。注意，同一维噪声一样，可以更换 t 的重映射函数。在这个版本里我们选了 Smoothstep 函数。不过你也可以试着不用该函数（直接使用 tx 与 ty）、改用 Cosine 平滑函数，或你知道的任何其他平滑函数来做实验。


#include &ltcstdio> 
#include &ltrandom> 
#include &ltfunctional> 
#include &ltiostream> 
#include &ltfstream> 
#include &ltcmath> 
 
template&lttypename T> 
class Vec2 
{ 
public: 
    Vec2() : x(T(0)), y(T(0)) {} 
    Vec2(T xx, T yy) : x(xx), y(yy) {} 
    Vec2 operator * (const T &r) const { return Vec2(x * r, y * r); } 
    T x, y; 
}; 
 
typedef Vec2&ltfloat> Vec2f; 
 
template&lttypename T = float> 
inline T lerp(const T &lo, const T &hi, const T &t) 
{ return lo * (1 - t) + hi * t; } 
 
inline 
float smoothstep(const float &t) { return t * t * (3 - 2 * t); } 
 
class ValueNoise 
{ 
public: 
    ValueNoise(unsigned seed = 2016) 
    { 
        std::mt19937 gen(seed); 
        std::uniform_real_distribution&ltfloat> distrFloat; 
        auto randFloat = std::bind(distrFloat, gen); 
 
        // 创建随机值数组
        for (unsigned k = 0; k < kMaxTableSize * kMaxTableSize; ++k) { 
            r[k] = randFloat(); 
        } 
    } 
 
    float eval(Vec2f &p) const 
    { 
        int xi = std::floor(p.x); 
        int yi = std::floor(p.y); 
 
        float tx = p.x - xi; 
        float ty = p.y - yi; 
 
        int rx0 = xi & kMaxTableSizeMask; 
        int rx1 = (rx0 + 1) & kMaxTableSizeMask; 
        int ry0 = yi & kMaxTableSizeMask; 
        int ry1 = (ry0 + 1) & kMaxTableSizeMask; 
 
        // 用排列表取得单元格角点处的随机值
        const float & c00 = r[ry0 * kMaxVerticesMask + rx0]; 
        const float & c10 = r[ry0 * kMaxVerticesMask + rx1]; 
        const float & c01 = r[ry1 * kMaxVerticesMask + rx0]; 
        const float & c11 = r[ry1 * kMaxVerticesMask + rx1]; 
 
        // 用 Smoothstep 函数重映射 tx 与 ty 
        float sx = smoothstep(tx); 
        float sy = smoothstep(ty); 
 
        // 沿 x 轴对值做线性插值
        float nx0 = lerp(c00, c10, sx); 
        float nx1 = lerp(c01, c11, sx); 
 
        // 沿 y 轴对 nx0/nx1 做线性插值
        return lerp(nx0, nx1, sy); 
    } 
 
    static const unsigned kMaxTableSize = 256; 
    static const unsigned kMaxTableSizeMask = kMaxTableSize - 1; 
    float r[kMaxTableSize * kMaxTableSize]; 
}; 
 
int main(int argc, char **argv) 
{ 
    unsigned imageWidth = 512; 
    unsigned imageHeight = 512; 
    float *noiseMap = new float[imageWidth * imageHeight]; 
 
    // 生成值噪声
    ValueNoise noise; 
    float frequency = 0.05f; 
    for (unsigned j = 0; j < imageHeight; ++j) { 
        for (unsigned i = 0; i < imageWidth; ++i) { 
            // 生成 [0:1] 范围内的浮点数
            noiseMap[j * imageWidth + i] = noise.eval(Vec2f(i, j) * frequency); 
        } 
    } 
 
    // 把噪声图输出为 PPM
    std::ofstream ofs; 
    ofs.open("./noise.ppm", std::ios::out | std::ios::binary); 
    ofs << "P6\n" << imageWidth << " " << imageHeight << "\n255\n"; 
    for (unsigned k = 0; k < imageWidth * imageHeight; ++k) { 
        unsigned char n = static_cast&ltunsigned char="">(noiseMap[k] * 255); 
        ofs << n << n << n; 
    } 
    ofs.close(); 
 
    delete[] noiseMap; 
 
    return 0; 
}

注意结果大概不如我们希望的好。得到的噪声相当块状。专业应用里的噪声产生的结果平滑得多。记住本课的目标是教你噪声函数所依据的基本概念。要改善结果需要更精细的技术，但若不能先写出一个简单的函数，学习它们会很吃力。现在不要太在意噪声函数的结果，先努力弄懂它如何运作、学习并理解它的性质。你仍然可以拿这段代码玩出些有趣的效果/图像，下一章就会看到。下一课（第二部分）会教你做出更好看的噪声。

三维噪声与更高维

本课会给出一个一维与二维噪声的例子。三维与四维噪声的代码我们会在下一课讲噪声时提供。不过，如果你读过插值一课并理解了本章讲的概念，你可以很容易地把代码扩展成三维噪声。你要做的只是沿 x 轴对随机值做插值（得到 4 个值），再把这个插值结果沿 y 轴做插值（得到 2 个值）。剩下两个值，你需要沿第三维（z 轴）插值才能得到最终结果（噪声第二课含有一个三维噪声的例子）。

现在我们当前的代码有个问题。我们在第一章提到过，噪声是一个紧凑的函数，不占多少内存。但在二维情形下，我们已经分配了一个 256x256 的随机值数组。如果三维版本也用同样的技术，我们就得分配一个 256x256x256 的浮点数组，对一个本应占用极少内存的函数来说，这已经开始是相当可观的一块内存了。Ken Perlin 用简单而优雅的方案解决了这个问题：排列表。下面我们就来讲。

引入排列的概念

假定我们希望噪声函数保持内存高效，那么无论处理一维、二维还是三维版本，我们都限制自己只用一个 256 个随机值的数组来计算噪声。要应对这个限制，我们必须确保噪声函数的任何输入值（一个浮点数、一个二维或三维点）都能映射到这个随机值数组中唯一的一个值。如你已知，我们噪声函数的每个输入点坐标都会被转成一个整数。而这个整数用来查随机值数组。Ken Perlin 把 0 到 255 这些数存进另一个 256 个整数的数组，并随机两两交换，把这个数组的条目打乱（置换）。Perlin 把这个数组的大小扩展到 512，把下标 0 到 255 的值复制到下标 256 到 511。换句话说，把数组的前半段复制到后半段。


std::mt19937 gen(seed); 
std::uniform_real_distribution&ltfloat> distrFloat; 
auto randFloat = std::bind(distrFloat, gen); 
 
// 创建随机值数组并初始化排列表
for (unsigned k = 0; k < kMaxTableSize; ++k) { 
    r[k] = randFloat(); 
    permutationTable[k] = k; 
} 
 
// 打乱排列表中的值
std::uniform_int_distribution&ltunsigned> distrUInt; 
auto randUInt = std::bind(distrUInt, gen); 
for (unsigned k = 0; k < kMaxTableSize; ++k) { 
    unsigned i = randUInt() & kMaxTableSizeMask; 
    std::swap(permutationTable[k], permutationTable[i]); 
    permutationTable[k + kMaxTableSize] = permutationTable[k]; 
}

我们不再直接查随机值数组，而是先用整数位置去查这个排列表。我们知道，输入点的整数值必然是 255 的倍数。假定这个数是 201。用这个值去查排列表，会返回表中下标位置 201 处存储的值。这次查表得到一个 0-255 范围内的整数，现在我们就可以把它当作随机值数组的下标。

你可能想知道为什么排列表的大小是函数周期的两倍（大小是 512 而不是 256）。如果处理的是二维噪声，我们首先用输入点 x 坐标的整数值去查排列表（如前所述）。这会返回一个 [0:255] 范围内的整数值。我们把这个查表结果加到输入点 y 坐标的整数值上，再把这两个数之和用作排列表的下标。由于第一次查排列的结果在 [0:255] 范围内，而该点 y 坐标的整数值也在 [0:255] 范围内，这意味着排列表可能的下标值范围是 [0:511]。因此排列表的大小是 512。下面这段代码也许能帮你理清：


int xi = std::floor(p.x); 
int yi = std::floor(p.y); 
 
float tx = p.x - xi; 
float ty = p.y - yi; 
 
int rx0 = xi & kMaxTableSizeMask; 
int rx1 = (rx0 + 1) & kMaxTableSizeMask; 
int ry0 = yi & kMaxTableSizeMask; 
int ry1 = (ry0 + 1) & kMaxTableSizeMask; 
 
// 用排列表取得单元格角点处的随机值
const float & c00 = r[permutationTable[permutationTable[rx0] + ry0]]; 
const float & c10 = r[permutationTable[permutationTable[rx1] + ry0]]; 
const float & c01 = r[permutationTable[permutationTable[rx0] + ry1]]; 
const float & c11 = r[permutationTable[permutationTable[rx1] + ry1]];

这个技术很巧妙，因为随着你给噪声函数增加维度，它依然管用。它提供了一种把任何输入点映射到随机值数组中唯一位置的方法。我们做的只是把输入点的坐标当作排列表的下标。在编程中，我们把这种技术称为哈希表或哈希函数。这类技术在当时相当流行（现在也是，只是年轻开发者不太熟悉了）。它们有助于把某个特定的键（例如一个点的位置）映射到存在内存块中的某些数据，使查表过程高效（关于哈希函数的更多内容，见编程技巧一课）。
