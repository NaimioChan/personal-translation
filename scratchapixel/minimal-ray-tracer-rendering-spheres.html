一个极简光线追踪器：渲染球体

本章详细讲解本课程附带的程序源码。这个程序是一个基础但可用的工具，能准确渲染一个只含球体的场景。下面是程序的主要特性列表：

  • 支持相机变换，也就是说我们可以从任意视点渲染场景。这一能力用到了我们在上一课生成相机光线中学到的东西。

  • 正确的几何可见性。如果一条光线与不止一个球体相交，显示的是交点距离最近的那个球体。

  • 找到交点后，会算出球面上交点处的法线与纹理坐标，并用它们给球体着色。

首先要解决的一个难题，是让程序支持不同的几何类型。比如在这个版本里，我们只想渲染球体。可如果下一个版本想渲染多边形网格呢？这个问题有几种解法，在 C++ 中通常借助类继承机制来解决。一般做法是先定义一个基类，给出程序里几何体的通用定义。然后我们可以按需要添加任意多个虚函数（派生类在 C++ 中可以覆盖虚函数），并为每个派生自基类的类定制这些方法。例如：


class Object

    virtual ~Object() {} // 虚析构函数
    Object() {} // 构造函数
};

class Sphere : public Object

public:

{

    if (mySphere.intersect(orig, dir, t)) {

    }
}

在上面的伪代码中，类 Object 是纯虚的，这意味着派生自 Object 的类必须实现 intersect() 方法。这个方法就是放置光线与该类所代表几何类型专用求交代码的地方，比如本课程第二章讲过的光线与球体求交代码。


class Sphere : public Object
{
public:
    ...
    bool intersect(const Vec3f &orig, const Vec3f &dir, float &t) const override
    {
        float t0, t1; // 若光线相交，t 的解
#if 0
        // 几何解法
        Vec3f L = center - orig;
        float tca = L.dotProduct(dir);
        if (tca < 0) return false;
        float d2 = L.dotProduct(L) - tca * tca;
        if (d2 > radius * radius) return false;
        float thc = sqrt(radius * radius - d2);
        t0 = tca - thc;
        t1 = tca + thc;
#else
        // 解析解法
        Vec3f L = orig - center;
        float a = dir.dotProduct(dir);
        float b = 2 * dir.dotProduct(L);
        float c = L.dotProduct(L) - radius * radius;
        if (!solveQuadratic(a, b, c, t0, t1)) return false;
#endif
        if (t0 > t1) std::swap(t0, t1);

        if (t0 < 0) {
            t0 = t1; // 若 t0 为负，改用 t1
            if (t0 < 0) return false; // t0 和 t1 都为负
        }

        t = t0;

        return true;
    }
    ...
};

为了简单起见，这个程序里没有引入 Ray 类。这样做是为了说明：仅仅为了把两个变量归拢在一起而建一个类，未必站得住脚。因此我们在 intersect() 方法里直接使用光线的原点与方向。

球体如何定义已经确定了，现在可以创建一个布满大量球体的场景，它们的位置和半径在三维空间中随机生成。这些球体被加入一个物体列表。这个列表可以容纳任何 Object 类型的物体，而借助 C++ 的继承机制，派生自 Object 的任何类的实例也都能放进去（注意，纯虚的 Object 类是无法创建实例的）。在我们的场景里，这些实例就是 Sphere 类的对象。


int main(int argc, char **argv)
{
    // 创建场景（添加物体与光源）
    std::vector&ltstd::unique_ptr&ltObject>> objects;

    // 生成一个由随机球体组成的场景
    uint32_t numSpheres = 32;
    gen.seed(0);
    for (uint32_t i = 0; i < numSpheres; ++i) {
        Vec3f randPos((0.5 - dis(gen)) * 10, (0.5 - dis(gen)) * 10, (0.5 + dis(gen)) * 10);
        float randRadius = (0.5 + dis(gen)) * 0.5;
        objects.push_back(std::make_unique&ltSphere>(randPos, randRadius));
    }

    // 设置选项
    Options options;
    options.width = 640;
    options.height = 480;
    options.fov = 51.52;
    options.cameraToWorld = Matrix44f(0.945519, 0, -0.325569, 0, -0.179534, 0.834209, -0.521403, 0, 0.271593, 0.551447, 0.78876, 0, 4.208271, 8.374532, 17.932925, 1);

    // 最后渲染
    render(options, objects);

    return 0;
}

此外，我们在程序的 main() 函数里配置图像宽高之类的选项，然后把物体列表与选项传给 render() 函数。通常 render() 函数会遍历图像的所有像素，构造主光线。相机到世界矩阵用来变换光线的原点与方向。


void render(
    const Options &options,
    const std::vector&ltstd::unique_ptr&ltObject>> &objects)
{
    ...
    float scale = std::tan(deg2rad(options.fov * 0.5));
    float imageAspectRatio = options.width / static_cast&ltfloat>(options.height);
    Vec3f orig;
    options.cameraToWorld.multVecMatrix(Vec3f(0), orig);
    for (uint32_t j = 0; j < options.height; ++j) {
        for (uint32_t i = 0; i < options.width; ++i) {
#ifdef MAYA_STYLE
            float x = (2 * (i + 0.5) / static_cast&ltfloat>(options.width) - 1) * scale;
            float y = (1 - 2 * (j + 0.5) / static_cast&ltfloat>(options.height)) * scale * 1 / imageAspectRatio;
#else
            float x = (2 * (i + 0.5) / static_cast&ltfloat>(options.width) - 1) * imageAspectRatio * scale;
            float y = (1 - 2 * (j + 0.5) / static_cast&ltfloat>(options.height)) * scale;
#endif
            Vec3f dir;
            options.cameraToWorld.multDirMatrix(Vec3f(x, y, -1), dir);
            dir.Normalize();
            *(pix++) = castRay(orig, dir, objects);
        }
    }

    // 把结果保存为 PPM 图像（在 Windows 下编译请保留这些标志）
    ...
}

关于 MAYA_STYLE 那处 if-else：当图像不是正方形时，需要按图像宽高比调整屏幕窗口。数学上这种调整有两种做法。第一种，把屏幕窗口的宽度（x 轴）乘以图像宽高比。例如图像分辨率为 640x480 时，宽高比是 1.33，于是屏幕窗口在 x 方向宽 1.33 个单位、在 y 方向高 1 个单位（这里假定视场角不影响屏幕窗口的尺寸）。另一种做法是让屏幕窗口沿 x 轴保持 1 个单位的宽度，而在 y 轴上按图像宽高比的倒数进行缩放，如下图所示。

两种做法在数学上都会改变透过相机看到的物体取景，但同样有效。Maya 采用第二种做法。因此，如果你希望光线追踪器的输出与 Maya 的渲染结果对齐，就需要按图像宽高比的倒数调整光线方向的 y 分量。否则，你可以保持光线的 y 坐标不变，而把 x 坐标乘以宽高比：


#ifdef MAYA_STYLE 
float x = (2 * (i + 0.5) / (float)options.width - 1) * scale; 
float y = (1 - 2 * (j + 0.5) / (float)options.height) * scale / imageAspectRatio; 
#else 
float x = (2 * (i + 0.5) / (float)options.width - 1) * imageAspectRatio * scale; 
float y = (1 - 2 * (j + 0.5) / (float)options.height) * scale; 
#endif

在编译命令里加上 -DMAYA_STYLE 选项即可启用第一种情形。

光线的原点、方向以及物体列表被传给 castRay() 函数。我们没有在这个函数里遍历场景的所有物体，而是交给 trace() 函数。trace() 函数接收物体列表以及光线的原点与方向，遍历场景中的物体，调用每个物体的 intersect() 方法。因此，如果物体是球体，就会触发 Sphere 类的 intersect() 方法。对于 TriangulatedMesh（待实现），则会调用 TriangulateMesh 类的 intersect() 方法。这个函数在光线与物体相交时返回真，否则返回假。找到交点后，作为 intersect() 方法输入参数的 \(t\) 会被更新为光线原点到交点之间的距离。trace() 函数对于维护最近交点距离至关重要，因为一条光线可能与多个物体相交。变量 tNear 初始被设为一个大得多的数，一旦发现更近的交点就更新（如下面的伪代码所示）。


bool trace(
    const Vec3f &orig, const Vec3f &dir, 
    const std::vector&ltstd::unique_ptr&ltObject>> &objects, 
    float &tNear, const Object *&hitObject)
{
    tNear = kInfinity;
    auto iter = objects.begin();
    for (; iter != objects.end(); ++iter) {
        float t = kInfinity;
        if ((*iter)-&gtintersect(orig, dir, t) && t < tNear) {
            hitObject = iter-&gtget();
            tNear = t;
        }
    }

    return (hitObject != nullptr);
}

关于 std::unique_ptr：unique_ptr 是一种智能指针，通过指针持有对象的独占所有权，并在 unique_ptr 离开作用域时释放该对象。用 unique_ptr 管理动态分配的几何体，可以让程序员不必手动释放内存，智能指针在离开作用域时会自动处理。

如果 castRay() 函数里 trace() 返回真，就表示光线与 hitObject 变量所指的物体相交。我们同时得到了到该物体的交点距离 t。有了这些信息，就能算出交点（下面第 9 行），并对相交物体调用 getSurfaceData() 方法，取得交点处表面的法线与纹理坐标（下面第 12 行）。随后用法线与纹理坐标对该点着色。把光线的方向取反，再与法线做点积，就能算出所谓的朝向比。当法线与光线方向一致时，这个比值趋近于 1；当两者垂直或方向相反时，它趋近于 0 或降到 0 以下。最后，用纹理坐标计算一个棋盘图案。交点处的颜色由物体颜色（创建时随机赋予）、朝向比结果和图案混合而成：


Vec3f castRay(
    const Vec3f &orig, const Vec3f &dir,
    const std::vector&ltstd::unique_ptr&ltObject>> &objects)
{
    Vec3f hitColor = 0;
    const Object *hitObject = nullptr; // 指向被击中物体的指针。
    float t; // 光线原点到命中点的交点距离。
    if (trace(orig, dir, objects, t, hitObject)) {
        Vec3f Phit = orig + dir * t;
        Vec3f Nhit;
        Vec2f tex;
        hitObject-&gtgetSurfaceData(Phit, Nhit, tex);
        // 用法线与纹理坐标给命中点着色。
        // 法线用来算一个简单的朝向比，纹理坐标
        // 用来算一个基本的棋盘图案。
        float scale = 4;
        float pattern = (fmodf(tex.x * scale, 1) > 0.5) ^ (fmodf(tex.y * scale, 1) > 0.5);
        hitColor = std::max(0.f, Nhit.dotProduct(-dir)) * mix(hitObject-&gtcolor, hitObject-&gtcolor * 0.8, pattern);
    }

    return hitColor;
}
