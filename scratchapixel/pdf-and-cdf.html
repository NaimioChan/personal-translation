概率密度函数（PDF）与累积分布函数（CDF）

阅读时间：12 分钟。

PDF（概率密度函数）与 CDF（累积分布函数）这两个概念在计算机图形学里非常重要。正因为太重要，不应该把它们埋在一门讲蒙特卡罗方法的长课里，但后面的章节要用到，所以必须在这里先介绍。如果你认真对待渲染与着色（从编程的角度），这一章建议仔细读。我们很可能会经常回来引用这一页，甚至在其他课程里重新介绍这些概念，让它们更显眼一些。

概率分布函数，即 PDF

前面几章我们已经介绍过概率分布的概念。简而言之，概率分布为一次随机实验的每个可能结果分配一个概率。我们也提过，随机变量可以是离散的，也可以是连续的。掷骰子得到的数字是离散随机变量的一例，伦敦的降雨量则是连续随机变量的一例（任意时刻降下的水量当然可以测量，但这个数可以落在某个范围内的任何位置；而骰子只能取固定的值，1、2、3、4、5 或 6）。

在第 3 章（我们介绍概率分布概念的那一章）里，我们提到过称为二项分布的函数，它可以用来计算 n 次独立的「是/否」实验中成功次数的概率（比如「掷 6 次硬币，得到 3 次正面的概率」）。当一个函数定义的是离散概率分布（就像我们刚给的例子），我们称这个函数为概率质量函数（或 pmf）。现在我们来看连续的情形。某个特定族群的成年人身高是一个连续随机变量，它一般或多或少服从正态分布。它之所以是连续变量，是因为身高不像骰子的点数那样被离散化。正态分布或高斯分布的概念是在第 8 章介绍的。它是由两个参数（均值与标准差）定义的一个函数。当一个像正态分布这样的函数定义的是连续概率分布（比如身高在一个成年人总体中的分布方式），这个函数就叫作概率密度函数（或 pdf）。换句话说，pdf 用于连续随机变量，pmf 用于离散随机变量。在计算机图形学里，我们几乎总是跟 pdf 打交道。总结一下：

  • 概率质量函数（pmf）是离散随机变量的概率分布。

  • 概率分布函数（pdf）是连续随机变量的概率分布。

PDF 可以用来计算随机变量落在某个区间内的概率：

$Pr( a \le X \le b) = \int_a^b pdf(x)\:dx.$

从这个表达式可以看出，一个 PDF 在其整个定义域上的积分必须总为 1。

在数学记号里，X ~ D 表示随机变量 X 具有概率分布 D。

累积分布函数，即 CDF

在整个概率论领域里，说到用于计算机图形学的蒙特卡罗方法，累积分布函数（CDF）大概是最重要、最有用的概念之一。为什么？CG 图像的渲染涉及大量积分，除了用一种叫作逆采样法的方法之外，其他手段都很难高效地求值，而这种方法正是建立在 CDF 之上的（逆采样法我们会在本章后面学习）。PDF 与 CDF 这两个概念都是计算机图形学渲染领域的核心。建议你好好学它们，这应该不难，因为它们是非常简单（却强大）的工具。

在下面的例子（图 2）中，我们画出了标准正态分布函数的曲线。这个函数只是正态（或称高斯）分布函数的一个特例，其中参数 \(\mu\) 与 \(\theta\)（它的均值与标准差）分别等于 0 和 1。这个函数我们在这门课前面某一章介绍过。这里选哪个函数并不重要。任何其他概率密度函数都可以用。不过记住，PDF（以及 PMF）最主要也最重要的性质之一是概率之和必须等于 1。如果 g(x) 就是这样一个函数（换句话说是一个 PDF），那么：

$$\int_{-\infty}^{\infty} g(x) dx = 1.$$

在这个例子里，g(x) 表示本章开头解释的那种连续随机变量的 PDF；不过请记住，当随机变量是离散的时候这一点同样成立（把每个可能结果的概率加起来，你会得到 1）。顺带一提，正态分布的性质之一就是它的积分为 1（这很好，因为我们要用这个函数当 PDF 就需要这一点）。

在讲着色那门课［链接］里，我们学过积分，也学过如何用黎曼和技术数值地求积分。这个想法是：在积分区域内按固定间隔对函数取值，把每个值乘以两个间隔之间的距离，再把它们加起来。相邻间隔之间的距离越小，近似就越准确。我们也在图 2 里示意了这个想法（此例中 dx=1）

尽管积分区间从负无穷到正无穷，但由于函数在 [-5,5] 之外非常接近零，只考虑这个范围内的值是可以接受的。为了把演示保持简单，我们也只在该范围内按 10 个固定间隔对正态分布函数取值。实践中你大概会想用更多样本，以得到更准确的近似。下面是我们这个 PDF 在这 10 个样本上的结果（第一行：样本索引，第二行：x 值，第三行：标准正态分布函数 g(x) 的结果）：

12345678910
-4.5 -3.5 -2.5 -1.5 -0.5 0.5 1.5 2.5 3.5 4.5
0.000 0.000 0.017 0.129 0.352 0.352 0.129 0.017 0.000 0.000

这张表里第三行的数字我们舍入到小数点后三位，但如果你运行下面的程序，可以得到精确值。把每个数乘以样本之间的距离（此例中 dx=1）再相加，如预期那样得到 1（并非所有 PDF 都会精确给出 1。标准正态分布函数的特别之处在于，无论取多少个样本，加起来总和都是 1。只取少量样本时，用黎曼和法对 PDF 积分只能得到接近 1 的值，但如前面所述，随着样本数增加，和应该越来越接近 1。换句话说，随着样本数趋于无穷，所有 PDF 的样本和都会收敛到 1）。你可以编译运行下面这个程序来核对这个结果：


#include &ltcstdio> 
#include &ltcstdlib> 
#include &ltcmath> 
int main(int argc, char **argv) 
{ 
    int numIter = 10; 
    float minBound = -5, maxBound = 5; 
    float cdf = 0, dx = (maxBound - minBound) / (float) numIter; 
    for (int i = 0; i < numIter; ++i) { 
        float x = minBound + (maxBound - minBound) * (i + 0.5) / (float)numIter; 
        float g_x = 1 / sqrtf(2 * M_PI) * exp(-(x * x) / 2); 
        printf("%f %f\n", x, g_x); 
        cdf += g_x * dx;  //把当前样本加到此前所有样本上 
        printf("CDF at %f: %f\n", x, cdf); 
    } 
    printf("Sum: %f\n", cdf);  //最终的和应该为 1 
    return 0; 
}

计算 CDF 本身很简单，只要把当前样本的贡献加到此前已经算好的所有样本之和上（我们程序的第 13 行）。记住，我们用这个技巧去计算一个 PDF 的 CDF，而按定义 CDF 是连续函数。因此，尽管我们的方法得到的是一串离散样本，CDF 本身仍是连续函数。只取少量样本时，我们得到的只是那个 CDF 应有的样子的一种相当粗糙的表达（就像图 2 里你能看到，那些矩形只是给出了标准正态分布函数 CDF 的一个很粗略的形状），不过当然，用的样本越多，就越接近它实际的「真实」形状。下面的图示意了这一点，你可以看到用 10 个样本（红色）和 30 个样本（绿色）近似出的函数 CDF，与真实 CDF（蓝色）的对比。如你所见，样本越多，我们越接近真实的 CDF。

那么真正的问题来了。CDF 有什么用？在概率论里，它们可以用来计算诸如「随机变量 X 出现前 N 个可能结果中任何一个的概率是多少」这样的问题。举个例子。我们知道骰子有 6 个可能结果，可能是 1、2、3、4、5 或 6。我们也知道每个结果的概率都是 1/6。那么，如果我们想知道掷这颗骰子得到小于等于 4 的数的概率，我们要做的就是掷出 1、2、3、4 的概率之和。用数学写出来就是：

$$\Pr(X <= 4) = \Pr(1) + \Pr(2) + \Pr(3) + \Pr(4) = \dfrac{1}{6} + \dfrac{1}{6} + \dfrac{1}{6} + \dfrac{1}{6} = \dfrac{4}{6}.$$

我们把前 N 个给定可能结果的概率加了起来（例中 N 等于 4）。如果我们把 Pr(X <=1)、Pr(X <= 2)……直到 Pr(X <= 6) 的这些求和结果画出来，就得到图 4 中的图，你可以猜到，它就是我们这个随机变量的概率函数（红色）的 CDF（绿色）。用离散随机变量（我们掷骰子的例子）来解释 CDF 的用途更容易，不过请记住，这个想法对离散和连续概率函数都适用。例如，如果我们说标准正态分布是某个连续随机变量 X 的 PDF，那么现在我们知道如何用它的 CDF 来回答这样的问题：X 取小于等于 0 的任意值的概率是多少？

$$\Pr(X <= 0)\;?$$

答案就是这个随机变量 X 取小于等于 0 的任意值的所有概率之和。我们同时也知道，PDF 就是「描述」这些「连续」结果概率的函数。因此我们要做的，就是把这个概率从比如 -5 累加到 0（原因前面解释过：我们选 -5 是因为对任何小于 -5 的值，PDF 都非常接近 0）。要做到这一点，我们可以用比如前面描述过的黎曼和法。如果你看图 3 里的蓝色曲线（它就是标准正态分布函数真实的 CDF），可以看到在 x = 0 处 CDF 等于 0.5。因此这个问题的答案就是 0.5。

$$\Pr(X <= 0) = CDF(0) = 0.5.$$

这就是 CDF 用途的一个例子，但它们对我们（也就是对计算机生成图形感兴趣的人）最有用的地方，是在一种叫作逆变换采样法的技术里的用法，我们接下来就讲。

注意 CDF（总是）是单调递增函数（这意味着 PDF 总是非负的）。不过它并非严格单调。可能存在保持常值的区间。另外从数学角度看，一个 PDF 可以看作其 CDF 的导数：

$$pdf(x) = { d \over {dx} } cdf(x).$$
