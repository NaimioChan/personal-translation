创建一个简单的一维噪声

阅读时间：26 分钟。

噪声是一个函数，对给定的输入 x 返回 [0:1] 范围内的浮点数（x 可以是浮点数、二维、三维或四维点，但本章我们只看一维情形。我们的输入位置也可以为正或为负，范围从 0 延伸到正无穷或负无穷）。我们本可以用随机数生成器来产生这些浮点数，但第一章已解释过，它每次被调用时返回的值彼此差别极大。这造成一种称为白噪声的图案，不适合纹理生成（白噪声图案不平滑，而自然界大多数图案是平滑的）。

所以，我们改为在等间隔的位置上生成一系列随机点（用 drand48()）。如果你做的是二维，我们在规则网格（晶格）的顶点上生成这些随机值；如果你做一维，这个网格可以看作一把尺子。为简单起见，我们假定该网格的顶点或尺子上的刻度位于 x 轴与 y 轴上坐标为整数的位置（0、1、2、3 等）。这些随机数只在这些位置上生成一次（在噪声函数初始化时）。

继续我们的一维例子，可以看到我们手上只剩下一串定义在尺子整数位置上的点或值。例如函数在 x = 0 处的结果是 0.36，在 x = 1 处的结果是 0.68，等等。但当 x 不是整数时，这个函数给出什么结果？要计算 x 轴上任意一点的值，我们需要找出该输入值在 x 轴上最近的两个整数位置（最小与最大），并使用与这两个位置关联的随机值。比如 x 等于 0.5，围绕 x 的两个整数点是 0 和 1。这两个点关联的随机值是 0.36 和 0.68。x = 0.5 时函数的结果，就是点 1 处定义的值 0.36 与点 2 处定义的值 0.68 的混合。我们可以用一种称为线性插值的简单插值技术来计算这个数。线性插值是一个简单的函数，对特定值 \(t\) 返回 \(a\) 与 \(b\) 的混合，其中 t 在 [0:1] 范围内：

在我们的噪声函数中，我们把 \(a\) 与 \(b\) 替换为定义在 x 周围整数位置上的随机值（如果 x = 1.2，就是 x = 1 与 x = 2 的随机值），并由 x 计算 \(t\)：从 x 本身减去为 x 找到的最小整数值即可（t = 1.2 - 1 = 0.2）。


int xMin = (int)x; 
float t = x - xMin;

下面是用线性插值计算值的代码。在多数着色语言里，这个函数叫 lerp（当然是指线性插值）：


template&lttypename T = float> 
inline T lerp(const T &lo, const T &hi, const T &t) 
{ return lo * (1 - t) + hi * t; }

这个 mix 函数在 CG 程序员那里通常称为 Lerp（线性插值）函数。如果你在某个渲染器的源码里或某本书里看到 Lerp 函数，应该知道它和这里用的 mix 函数是同一个东西。

用线性插值计算 [0:1] 范围内任意 x 的值，相当于从点 1 到点 2 画一条线。如果我们对 [1:2]、[2:3] 等区间内的所有点重复这个过程，就得到图 4 中的曲线。你现在也许明白了我们为什么把这类噪声称为值噪声（噪声可以用几种不同方式制造）。思路就是在尺子（一维）或网格（二维）上等间隔地生成一些值，然后做线性插值。

现在我们已经具备了写一个简单噪声函数所需的全部零件。初始化函数时，我们生成一系列随机值，存进一个浮点数组（图 4 底部方框里的数字）。如代码所示，数组长度很容易改。这一点后面很重要，但为了让演示简单，我们只生成 10 个值（从原点 0 到 9）。数组中数字的下标对应它在尺子上的位置。数组第一个数对应 x = 0，第二个对应 x = 1，依此类推。要为 x 计算噪声值，我们先算出 x 的整数边界（x 的最小与最大整数值）。然后可以把这两个整数值当作存放随机数的数组的下标位置。我们取到的两个数 \(a\) 与 \(b\)，就是这两个下标位置上存储的随机值。我们还需要用上面描述的技术从 x 求出 \(t\)（从 x 减去 x 的最小整数）。最后一步是调用 mix 函数，用 \(t\) 对 \(a\) 与 \(b\) 做线性插值。这样就得到了噪声函数在 x 处的结果。


class ValueNoise1D 
{ 
public: 
    ValueNoise1D( unsigned seed = 2011 ) 
    { 
        srand48(seed); 
        for (unsigned i = 0; i < kMaxVertices; ++i) { 
            r[i] = drand48(); 
        } 
    } 
 
    // 求噪声函数在位置 x 处的值
    float eval(const float &x) 
    { 
        int xMin = (int)x; 
        assert(xMin <= kMaxVertices - 1); 
        float t = x - xMin; 
 
        return lerp(r[xMin], r[xMin + 1], t); 
    } 
 
    static const unsigned kMaxVertices = 10; 
    float r[kMaxVertices]; 
}; 
 
int main(int argc, char **argv) 
{ 
    ValueNoise1D valueNoise1D; 
 
    static const int numSteps = 200; 
 
    for (int i = 0; i < numSteps; ++i) { 
        float x = i / float(numSteps - 1) * 10; 
        std::cout << "Noise at " << x << ": " << valueNoise1D.eval(x) << std::endl; 
    } 
 
    return 0; 
}

我们在 x 轴上从 x = 0 开始的每个整数位置只定义了 10 个随机值，所以只能为 [0:10] 范围内的 x 计算值。为什么是 [0:10] 而不是 [0:9]？当 x 在 [9:10] 范围内时，我们会用下标 9 和 0 处的随机值来算噪声值。如图 6 所示，这样做的话，曲线的开头和结尾是相同的。换句话说，x = 0 与 x = 10 时的噪声相同（在我们的例子里都是 0.36）。我们把这条曲线复制一份，移到现有曲线的左边或右边。现有曲线（曲线 1）定义在 [0:10] 范围，新的副本（曲线 2）定义在 [10:20] 范围。

你可以看到曲线相接处（x = 10）没有不连续。为什么？因为曲线 1 末端的噪声值与曲线 2 开头的噪声值相同。这是因为当 x 在 [9:10] 范围内时，我们对 x = 9 与 x = 0 的随机值做插值。由于相继的曲线副本之间没有不连续，我们可以复制任意多次，把噪声函数延伸到无穷。x 的取值不再限于 [0:10]。它可以取从 0 到无穷（或负无穷。噪声函数也应该能处理负值）之间的任何正值或负值。

在代码里怎么做到？我们知道当 x 在 [0:9] 范围内时如何计算噪声值。但当 x 大于 9 时（x 为负的情形同理），比如 9.35，我们希望如前所述对 x = 9 与 x = 0 处的随机位置做插值。如果取 x 的最小与最大整数，我们得到 9 和 10。但我们不想用 10，而想用 0。这里需要的是取模运算符。取模运算符给出一个数除以另一个数的余数（在我们的情形里是 x 除以 10 的余数）。算一下就知道，9 除以 10 的余数是 9，10 除以 10 的余数是 0。换句话说，对 x = 9.35 的最小与最大整数值使用取模运算符，得到 9 和 0，正是我们想要的。而且你试一下就会发现，对任何大于 10 或小于 0 的 x，用这个运算符总能返回正确的整数边界（负值需要特别小心，但原理相同）。

用这个技术，我们沿 x 轴移动时可以反复循环经过噪声函数（类似于复制原曲线）。我们在第一节提到过，噪声函数是周期性的。在这个例子里函数周期是 10（在原点两侧对负值和正值 x 每 10 个单位重复一次）。下面我们用取模运算符（C++ 里的 %）。不过后面我们会看到如何简化并提高效率（注意下面这段代码对小于 0 的 x 不适用。这个限制会在本代码片段的最后一个版本里去掉）：


class ValueNoise1D 
{ 
public: 
    ValueNoise1D(unsigned seed = 2011) 
    { 
        srand48(seed); 
        for (unsigned i = 0; i < kMaxVertices; ++i) { 
            r[i] = drand48(); 
        } 
    } 
 
    // 求噪声函数在位置 x 处的值
    float eval(const float &x) 
    { 
        int xi = (int)x; 
        int xMin = xi % (int)kMaxVertices; 
        float t = x - xi; 
        int xMax = (xMin == kMaxVertices - 1) ? 0 : xMin + 1; 
 
        return lerp(r[xMin], r[xMax], t); 
    } 
    static const unsigned kMaxVertices = 10; 
    float r[kMaxVertices]; 
}; 
 
int main(int argc, char **argv) 
{ 
    ValueNoise1D valueNoise1D; 
 
    static const int numSteps = 200; 
 
    for (int i = 0; i < numSteps; ++i) { 
        float x = i / float(numSteps - 1) * 10; 
        std::cout << "Noise at " << x << ": " << valueNoise1D.eval( x ) << std::endl; 
    } 
 
    return 0; 
}

这个结果本身没问题（技术上它做对了），只是它看起来像锯齿状的曲线，不太自然。如果你看自然界的随机图案，比如海面（波浪）的轮廓，它们通常没有这种锯齿状轮廓。它们的轮廓是平滑的（圆润的）。要改变这条曲线的外观，我们可以用另一个轮廓平滑的函数（产生「S」形曲线的函数）重新映射输入 \(t\) 值。常用来重映射 t 的两个 S 曲线函数是余弦与 smoothstep 函数。必须理解：插值随机值的代码没有变。我们在把 \(t\) 的值用于 mix 函数之前先对它重新映射。再强调一次，我们不是用「S」曲线函数替换 mix 函数。我们用一个平滑函数重新映射 \(t\)，然后用这个重新映射后的 \(t\) 值对 \(a\) 与 \(b\) 做线性插值。伪代码如下：


float smoothNoise(const float &a, const float &b, const float &t) 
{ 
    assert(t >= 0 && t <= 1);      //t 应在 [0:1] 范围内 
    float tRemap = smoothFunc(t);  //重映射 t 输入值 
    return lerp(a, b, tRemap);     //用新的 t 返回 a-b 的插值 
}

余弦

我们先画出 [0:2Pi] 范围内的余弦函数（绕单位圆一整圈）。你对这条曲线的轮廓肯定很熟悉（图 7 左图）。如你所见，曲线在 x 处于 [0:Pi/2] 时从 1 到 0，在 [Pi/2:Pi] 时从 0 到 -1，在 [Pi:3/2Pi)] 时从 -1 到 0，最后（最后一个象限）在 [3/2Pi:2Pi] 时从 0 到 1。曲线上函数从 1 变化到 -1 的那一段（x 在 [0:Pi] 区间时）可以用来插值两个值。因为 \(t\) 在 [0:1] 区间内，我们在用它之前先重映射：乘以 Pi 即可（记住我们希望 x 在 [0:Pi] 区间内）。不过我们想要重映射函数的结果从 0 到 1，而余弦函数在 x 处于 [0:Pi] 范围时是从 1 到 -1。诀窍是写成 1 - cos(t * Pi)，这样得到的值从 0（1-cos(0)=0）到 2（1-cos(1 * Pi)=1--1=2）。把这个结果除以 2（或乘以 0.5），重映射函数最终返回 [0:1] 范围内的值（图 7 右图）。补完代码：我们用余弦函数重映射后的 t 值，通过 mix 函数对 r1 与 r2 插值。以下是我们将使用的代码：


float cosineRemap(const float &a, const float &b, const float &t) 
{ 
    assert(t >= 0 && t <= 1); 
    float tRemapCosine = (1 - cos(t * M_PI)) * 0.5; 
    return lerp(a, b, tRemapCosine); 
}

用这段代码，曲线的轮廓不变（因为我们还是在相同位置插值相同的预定义值），但相邻两个值之间的过渡平滑得多（图 8）。

Smoothstep

smoothstep 函数在噪声函数的实现中被广泛使用（Ken Perlin 写的、广为人知的噪声实现即 Perlin 噪声里就用了它）。关于这个函数本身没什么好说的，除了它在我们关心的 [0:1] 范围内的轮廓恰好是我们想要的样子。下面是该函数的公式与图像（图 9 右图。注意 Cosine 重映射公式（(1-cos(t*M_PI))*0.5）的轮廓几乎相同）。

把 smoothstep 函数写成代码时要小心，因为 \(t\) 需要求 2 次与 3 次幂。可以用下面这种实现稍作优化：


float smoothstepRemap(const float &a, const float &b, const float &t) 
{ 
    float tRemapSmoothstep = t * t * (3 - 2 * t); 
    return Mix(a, b, tRemapSmoothstep); 
}

一个简单的一维噪声函数

本节我们会快速演示几种改变噪声函数结果的方式。首先看看我们的函数长什么样。我们仍然用 10 个随机数生成噪声图案（同图 10）。这意味着函数在 x 轴上将从 0 变化到 10（对 [9:10] 范围内的值，我们使用晶格 9 和 0）。之后它会以 10 个单位为周期重复。我们之前提到过，噪声函数是周期函数（图 5 说明了这一想法）。在实际应用中，这么短的周期是不能令人满意的。噪声函数的最终版本会处理长得多的周期（256；我们会解释为什么用这个数）。我们还得把代码写成能处理 x 为负值的情况。我们用取模运算符在噪声函数中循环，但 x 为负时这就不管用了，使事情比本应更复杂（也更慢）。在代码的最终版本里，你会学到如何更优雅地处理这种情况。最后注意，噪声结果在 y 轴上仍然在 [0:1] 范围内变化。

缩放

只要缩放输入值 x 或乘函数本身的结果，就能很容易地改变函数的形状。第一种操作会改变函数的周期性。把 x 乘以大于 1 的值会提高函数的周期性（你改变了噪声函数的频率）。简言之，你会把曲线压缩（让它看起来更短）。下一章用二维噪声的例子会看得更明显。如果把 x 乘以小于 1 的值，曲线会沿 x 轴拉伸，看起来更长（图 11）。这个操作对控制噪声图案的频率很有用。


float frequency = 0.5; 
float freqNoise = valueNoise1D.eval(x * frequency);

第二个最基本的操作是乘噪声函数的结果，这会改变它的幅度。如果你用一维噪声给曲线做动画，效果可能太强。把幅度调小可以减弱它（图 12）。


float amplitude = 0.5; 
float ampNoise = valueNoise1D.eval(x) * amplitude;

偏移

你也可以给噪声函数的输入加上某个值。这会把曲线向左移（如果给 x 加正数）或向右移（如果给 x 加负数）。这种通过给 x 加偏移来移动噪声函数结果的技术，对让函数随时间动起来很有用（每帧增大偏移值）。


float offset = frameNumber; 
float offNoise = valueNoise1D.eval(x + offset);

有符号噪声

噪声函数通常返回 [0:1] 范围内的值。但并非必须如此。这取决于实现方式。例如，你可以给整数晶格点赋 [-1:1] 范围内的随机数，使噪声函数返回同一范围内的值。不过如我们所说，惯例通常返回 [0:1] 范围内的值，而把这个值重映射到 [-1:1] 范围很容易。得到的噪声有时称为有符号噪声。下面是代码，以及我们的噪声函数结果被重映射到 [-1:1] 范围后的图像（图 21）。当你用噪声给物体做过程式动画、或想改变某个参数时，这又会很有用。想象你有一个物体，它在 y 轴上的位置是 3，用有符号噪声来调制该物体沿该轴的位置；你可能希望物体在 0-6 范围内变化。这种情况下，把有符号噪声函数乘以 3，使它变化在 [-3:3] 范围内，再加上 3，物体就会沿 y 轴在 [0:6] 范围内变化。


float signedNoise = 2 * valueNoise1D.eval(x) - 1;

一个完整的一维噪声函数

只用 10 个随机数会导致周期极短。这意味着如果我们在很大的 x 范围上使用它（比如从 0 到 100），函数会重复很多次（十次）。从视觉上看，你很有可能看出这个图案，这会让结果显得不太自然。我们在第一章提到过，噪声的性质之一是它不应该看起来是周期性的。为达到这一点，我们会作弊，把噪声函数的周期做得非常大。

在上一章（讲噪声性质的那一段）我们提到，当你拉得足够远时，噪声会变得很小，重复几乎看不出来。这其实更像是个掩护手段。看图 15 下方那条曲线，我们画的是从 0 到 256（一个周期）的噪声函数。如你所见，如果我们把这条曲线复制到左右两边，再拉得更远，把三条曲线并排看，你大概分辨不出这条线是由同一曲线的三个副本组成的。诀窍在于给噪声周期找一个足够大的尺寸，使得拉远后无法辨认图案，同时又足够小，让随机值数组保持在合理的大小（内存占用低）。256 或 512 都是能达到这一效果的好数值。

现代大多数噪声函数实现使用 256 个点（或 512）的晶格网格。256 这个值并非随意选的。为什么是 256 而不是 255 或 257？因为这个数是二的幂（2^8）。处理这类数时，我们可以用位运算符（&）替代取模运算符 %。过去程序员偏爱算术运算而非 % 运算符，因为后者更慢。现代处理器/编译器处理得很好，所以除了在 x 为负时能让事情更简单之外，并没有特别必要改用 & 运算符。

你能解释为什么 & 更好，以及它是怎么工作的吗？

在 C/C++ 中，-10 % 256 与 -10 & MASK（MASK = 255）并不相同。一个返回 -10，另一个返回 246，而 246 才是 x = -10 时我们想在噪声函数里用的值（如果噪声周期是 256，随机值数组的第一个元素（下标 0）对应 x = -256。如果 x = -10，下标位置就是 246）。即使理论上编译器在取模对象是二的幂时会优化代码，它对 x 为负的情况也不管用，而 & 管用。

它的工作原理更微妙，我们建议你读位运算一课以获得深入解释。不过，如果你已经熟悉这个主题，下面这段代码应该能帮你找到答案：


#include &ltbitset> 
using namespace std; 
#define MASK 256 - 1 
int a = -10; 
int b = a & MASK; 
bitset&lt16> ab(a); 
bitset&lt16> bb(b); 
bitset&lt16> mb(MASK); 
cout << ab << "=" << a << "\n" << mb << "=" << MASK << "\n" << bb << "=" << b << "\n"; 
1111111111110110=-10 
0000000011111111=255 
0000000011110110=246

注意第 18 行，我们处理了 x 为负时将 x 向下取整到最小整数的情况（int(-1.2) 是 -1，而我们想要 -2。所以如果右边括号内的布尔测试为真，它就会给结果加 -1：-1 + -1 = -2）。如果你好奇、想验证函数是周期性的，可以写下面的代码：


template&ltInterpolationFunc F> 
class ValueNoise1D 
{ 
public: 
    ValueNoise1D(unsigned seed = 2016) 
    { 
        srand48(seed); 
        for (unsigned i = 0; i < kMaxVertices; ++i) { 
            r[i] = drand48(); 
        } 
    } 
 
    // 求噪声函数在位置 x 处的值
    float eval(const float &x) 
    { 
        // 向下取整
        int xi = (int)x - (x < 0 && x != (int)x); 
        float t = x - xi; 
        // 用 & 取模
        int xMin = xi & kMaxVerticesMask; 
        int xMax = (xMin + 1) & kMaxVerticesMask; 
 
        return (*F)(r[xMin], r[xMax], t); 
    } 
    static const unsigned kMaxVertices = 256; 
    static const unsigned kMaxVerticesMask = kMaxVertices - 1; 
    float r[ kMaxVertices ]; 
}; 
 
int main(int argc, char **argv) 
{ 
    ValueNoise1D&ltsmoothstep> valueNoise1D; 
 
    static const int numSteps = 200; 
 
    for (int i = 0; i < numSteps; ++i) { 
        // x 从 -10 变化到 10
        float x = (2 * (i / float(numSteps - 1)) - 1) * 10; 
        std::cout << "Noise at " << x << ": " << valueNoise1D.eval(x) << std::endl; 
    } 
 
    return 0; 
}

如你所见，用周期的倍数（256）作为 x 调用噪声函数，总是返回相同的值（数组中下标 0 处存储的随机值）。你也可以写下面的代码，这是检查函数周期性的另一种方式：

最后一件非常重要的事

噪声函数的实现依赖于创建一个随机值数组，其中每个随机值都被认为位于尺子上的整数位置。这是一个非常重要的观察，后面做噪声函数滤波时会极其有用。本课第一章我们提到，当噪声图案太小时，它又变成白噪声，产生称为走样的视觉瑕疵。当噪声频率过高时，可以通过对噪声函数滤波来消除走样。问题是怎么算「过高」。这个问题的答案恰恰与尺子上各个预定义随机值之间的距离有关：相邻两个随机数相隔 1 个单位。你必须记住噪声函数的这个性质（关于噪声滤波的一章见噪声第二课）。
