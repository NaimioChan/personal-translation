理解黑体辐射，为 CG 模拟得到真实的颜色与光照

阅读时间：11 分钟。

黑体的光谱

本课简要介绍如何计算黑体的光谱。它用到若干与光谱渲染、颜色转换和色彩空间有关的技术。由于这些题目本身的复杂度，它们在别的课程里有详细展开。这里假定读者已经扎实掌握了这些技术，本课不再解释。

黑体是这样一类物体：它们几乎能吸收全部入射辐射，并把这份能量以光的形式重新发射出去。这个定义做了简化，算不上严谨的科学表述，但有助说明火焰、白炽金属乃至灯泡这类现象。这些物体发光来自一个辐射过程。该过程的细节超出本课范围（我们在这里不深入物理），热力学方面的专家欢迎补充。这类物体的一个关键特征是：它们发射的光谱取决于自身的温度。光谱这个概念，简单说，就是用波长来表示颜色。

当黑体的温度升到约 1000K（开尔文）时，它呈深红色。温度继续升高，颜色在 4500K 左右转为偏黄，接近 6500K 时趋于白色，在 8000 至 9000K 之间转为淡蓝。值得注意的是，几乎所有液体和固体物体在温度达到约 800K 时就开始发光。虽然低于这个阈值物体也会发光，但发出的光太弱，看不出来。

光色之谜

我们常遇到灯泡里灯丝被加热到发出辐射、其中一部分落在可见光谱内的情况。发出光的颜色与灯丝温度直接相关，因此在玻璃泡透明或为白色的前提下，灯泡的颜色会从橙到蓝变化。这一现象正是摄影中色温概念的基础：色温指拍摄对象时使用某种光源所得到的色彩效果。例如烛光的温度在 1000 至 2000K 之间，因此呈暖光。典型的白炽灯工作温度约 2500K，发出的光同样偏暖。相比之下，太阳表面温度约 6500K，因此阳光呈白光。

温度在 2500-3500K 左右的物体发出的光被认为是暖光，特征是红／橙色调；而 6500K 左右的光源发出的光则被认为是冷光，带蓝／白色调。有一点很有意思：白炽灯的峰值发射波长约 1160 nm，实际上落在光谱的红外部分，人眼看不见。这部分红外辐射对这类灯具散发的热量贡献很大，而且是超出它们所发出的可见光之外的。

普朗克定律

给定波长与温度下的功率谱密度（本质上是物体有多亮）可以用普朗克定律算出来：

$$\begin{array}{ll} I(\lambda,T)=\frac{2hc^2}{\lambda^5}\frac{1}{e^{\frac{hc}{\lambda kT}}-1} \end{array}$$

其中 \(h\) 是普朗克常数（xx），\(c\) 是光速（xx m/s），\(k\) 是玻尔兹曼常数（xx），\(\lambda\) 是波长，\(T\) 是黑体的温度。要算某个温度下黑体的颜色，需要从 380 nm 到 780 nm 求普朗克公式的值（这一段覆盖可见光谱）。然后我们用颜色匹配函数把得到的黑体光谱转成 XYZ 三刺激值，最后把 XYZ 颜色转成 RGB（光谱与颜色转换在基础部分的《颜色》一课中有讲）。

我们的示例程序会对 1000K 到 10000K 这一范围内的温度逐个计算颜色。如果 XYZ 颜色没有正确缩放，某些 RGB 颜色可能超过 1。把结果存成位图图像之前，必须小心先把颜色缩下来。另一种做法是使用浮点图像格式（PFM、OpenEXR、Radiance HDR）。有些 RGB 颜色还可能是负值。虽然可以通过调整这些颜色的位置让它们落进所选色彩空间的色域内，但在我们的例子里，为简单起见，直接把负值截断。

const double wavelengthMin = 380;
const double wavelengthMax = 780;
const double wavelengthStep = 5;
const unsigned numSteps = (wavelengthMax - wavelengthMin) / wavelengthStep + 1;
 
inline double computePlanck(
    const double &T,        // 温度（开尔文）
    const double λ)   // 波长（米）
{
    static const double h = 6.62606896e-34; // 普朗克常数
    static const double c = 2.99792458e+8; // 光速
    static const double k = 1.38064880e-23; // 玻尔兹曼常数
    static const double arg1 = 2 * M_PI * h * c * c;
    static const double arg2 = ( h * c ) / k;
    return (arg1 * pow(lambda, -5.0)) / (exp(arg2 / (lambda * T)) - 1.0);
}
 
template&lttypename T>
class Color3
{
public:    
    Color3() : r(0), g(0), b(0) {}
    Color3( T rr, T gg, T bb) : r(rr), g(gg), b(bb) {}
    T r, g, b;
};
 
typedef Color3&ltdouble> Color3d;
 
// 把 XYZ 三刺激值转成 RGB
Color3d XYZ2RGB(const double &X, const double &Y, const double &Z)
{
    // 把 XYZ 转成 sRGB
    return Color3d(
        X *  3.2406 + Y * -1.5372 + Z * -0.4986,
        X * -0.9689 + Y *  1.8758 + Z *  0.0415,
        X *  0.0557 + Y * -0.2040 + Z *  1.0570 );
}
 
Color3d computeBlackbody(const double &temperature, double &power)
{
    power = 0;
    double X = 0, Y = 0, Z = 0;
    for (unsigned k = 0; k < numSteps; k++ ) {
        // 换算成纳米
        double lambda = (wavelengthMin + k * wavelengthStep) * 1e-9;
        double I = computePlanck(temperature, lambda);
        power += I * wavelengthStep;
        X += I * colorMatchingFunc[k][0];
        Y += I * colorMatchingFunc[k][1];
        Z += I * colorMatchingFunc[k][2];
    }
    power /= double( numSteps );
    
    // 归一化结果
    double nor = 1 / std::max( X, std::max( Y, Z ) );
    
    X *= nor, Y *= nor, Z *= nor;
    
    return XYZ2RGB(X, Y, Z);
}
 
void computeBlackbodyRamp()
{
    unsigned rampWidth = 512, rampHeight = 50;
    unsigned tempMin = 1000;
    unsigned tempMax = 10000;
    Color3d result[ rampWidth ];
    double power, temperature;
    for (unsigned i = 0; i < rampWidth; ++i) {
        temperature = tempMin + (tempMax - tempMin) * i / double(rampWidth - 1);
        result[ i ] = computeBlackbody(temperature, power );
    }
    // 把 double 型 rgb 转成无符号字节
    unsigned numBytes = 3 * rampWidth;
    unsigned char lines[ numBytes ];
    unsigned r, g, b;
    double scale = 1 / 2.6; // 任意选一个除数，让值保持在 1 以下
    for (unsigned i = 0, k = 0; i < rampWidth; ++i, k += 3) {
        r = (unsigned char)(std::max( 0., std::min( 1., result[i].r * scale ) ) * 255 + 0.5);
        g = (unsigned char)(std::max( 0., std::min( 1., result[i].g * scale ) ) * 255 + 0.5);
        b = (unsigned char)(std::max( 0., std::min( 1., result[i].b * scale ) ) * 255 + 0.5);
        lines[ k ] = r, lines[ k + 1 ] = g, lines[ k + 2 ] = b;
    }
    // 把结果存成 PPM 文件
    std::ofstream ofs("./blackbodyramp.ppm");
    ofs << "P6\n" << rampWidth << " " << rampHeight << "\n255\n";
    for (unsigned j = 0; j < rampHeight; ++j) {
        ofs.write((char*)lines, numBytes);
    }
    ofs.close();
}

斯特藩-玻尔兹曼定律

我们已经学会了怎样把黑体的温度转换成颜色。在渲染中，确定这个黑体发射了多少能量同样有用。有几种方法可以用。用普朗克辐射公式算出的光谱里，每个值代表黑体在某个特定波长上发射的能量。要求总发射能量，把这些值加起来就行。这个过程是数值积分的经典例子：我们算出的光谱曲线（剖面）下方的面积，对应黑体辐射的总功率（参见《着色的数学》一课）。把光谱里的每个值乘以 \( \Delta\lambda \)（波长间隔，这里是 5），求和，再除以间隔的总数（81）。注意这个积分结果只算进了可见光谱范围（380-780 nm）内的辐射功率，很可能只占整个光谱总发射功率的一小部分。这个结果就是辐射功率（也叫辐射通量或辐射功率），单位是瓦特（每单位时间？待确认）。

黑体辐射的能量也可以用斯特藩-玻尔兹曼定律解析地算出来。定律说的是：黑体辐射体每单位面积每秒辐射的能量（焦耳每秒每平方米，也就是瓦特每平方米）与绝对温度（以开尔文计）的四次方成正比，公式为：

$$\sigma T^4$$

其中常数 \(\sigma\) 称为斯特藩-玻尔兹曼常数，其值为

$$\sigma = 5.670374419 \times 10^{-8} \, \text{W} \cdot \text{m}^{-2} \cdot \text{K}^{-4}.$$

普朗克轨迹

在色度图上，把黑体随温度升高所发出颜色连接起来形成的曲线，称为普朗克轨迹。

你既可以用普朗克定律算出这条曲线，也可以用下面代码片段里的公式做快速近似：


Color3d computePlanckLocus(const double &T)
{
    double x_c, y_c;
    double arg1 = 1e9 / (T * T * T), arg2 = 1e6 / (T * T), arg3 = 1e3 / T;
    if (T >= 1667 && T <= 4000) {
        x_c = -0.2661239 * arg1 - 0.2343580 * arg2 + 0.8776956 * arg3 + 0.179910;
    } else if (T > 4000 && T <= 25000) {
        x_c = -3.0258469 * arg1 + 2.1070379 * arg2 + 0.2226347 * arg3 + 0.240390;
    }
    double x_c3 = x_c * x_c * x_c, x_c2 = x_c * x_c;
    if (T >= 1667 && T <= 2222) {
        y_c = -1.1063814 * x_c3 - 1.34811020 * x_c2 + 2.18555832 * x_c - 0.20219683;
    } else if (T > 2222 && T <= 4000) {
        y_c = -0.9549476 * x_c3 - 1.37418593 * x_c2 + 2.09137015 * x_c - 0.16748867;
    } else if (T > 4000 && T <= 25000) {
        y_c = +3.0817580 * x_c3 - 5.87338670 * x_c2 + 3.75112997 * x_c - 0.37001483;
    }
    double X = x_c / y_c;
    double Y = 1;
    double Z = (1 - x_c - y_c) / y_c;
    return XYZ2RGB(X, Y, Z);
}
