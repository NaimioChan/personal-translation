点与向量上的数学运算

阅读时间：12 分钟。

我们已经讲清了笛卡尔坐标系的原理，包括这些系统中点与向量的坐标之间的关系，现在来探讨一些作用于点与向量的主要运算。这些运算是任何三维应用或渲染引擎功能的基础。

C++ 中的向量类

开始之前，我们先搭好 C++ 里 Vector 类的结构：


template&lttypename T>
class Vec3
{
public:
    // 初始化向量的三种主要方式
    Vec3() : x(T(0)), y(T(0)), z(T(0)) {}
    Vec3(const T &xx) : x(xx), y(xx), z(xx) {}
    Vec3(T xx, T yy, T zz) : x(xx), y(yy), z(zz) {}
    T x, y, z;
};

向量长度

前面提到过，向量可以想象成从一点出发、到另一点结束的箭头。它不仅表示从点 A 到 B 的方向，也用来度量这两点之间的距离。这个度量由向量的长度得出，可用下面的公式计算：

$$||V|| = \sqrt{V.x * V.x + V.y * V.y + V.z * V.z}$$

用数学语言说，双竖线（||V||）表示向量的长度。向量的这个属性也叫范数或大小（图 1）。


template&lttypename T> 
class Vec3 
{ 
public: 
    ... 
    // 长度可以是类的方法……
    T length() 
    { 
        return sqrt(x * x + y * y + z * z); 
    } 
    ... 
}; 
 
// ……也可以在类外的函数里计算长度
template&lttypename T> 
T length(const Vec3&ltT> &v) 
{ return sqrt(v.x * v.x + v.y * v.y + v.z * v.z); }

三维笛卡尔坐标系的各根轴由单位向量表示。

归一化向量

由于文化影响不同，「normalize」这个词可以拼成带 's' 或带 'z' 两种形式。不过在编程中，方法或函数的命名通常以美式拼写为准，所以代码里用带 'z' 的 normalize。

按行业惯例、这里拼作带 'z' 的形式，归一化向量是长度为 1 的向量（如图 1 中的向量 B），也叫单位向量。归一化一个向量的过程是：先算出它的长度，再把向量的每个坐标除以这个长度。公式如下：

$$ \hat{V} = \frac{V}{|| V ||}$$

C++ 实现可以在效率上做得更好。具体来说，只有当向量长度大于零时才做归一化，以避免除以零。一项优化是先算出向量长度的倒数，再把每个坐标乘以这个倒数值，而不是逐个除以长度。这种做法更可取，因为乘法运算一般比除法便宜，而在渲染中归一化是高频操作，这点差别会显著影响性能。有些编译器可能会自动做这层优化，但显式地写出来能缩短渲染时间。


template&lttypename T>
class Vec3
{
public:
    ...
    // 向量归一化方法
    Vec3&ltT>& normalize()
    {
        T len = length();
        if (len > 0) {
            T invLen = 1 / len;
            x *= invLen, y *= invLen, z *= invLen;
        }

        return *this;
    }
    ...
};

// 向量归一化的工具函数
template&lttypename T>
void normalize(Vec3&ltT> &v)
{
    T len2 = v.x * v.x + v.y * v.y + v.z * v.z;
    if (len2 > 0) {
        T invLen = 1 / sqrt(len2);
        v.x *= invLen, v.y *= invLen, v.z *= invLen;
    }
}

数学中的范数指给向量赋予长度、大小或距离的函数，比如这里讲的欧几里得范数。

点积

点积，也叫标量积，涉及两个向量 A 与 B，概念上是一个向量在另一个向量上的投影，结果是一个标量。这个运算记作 \(A \cdot B\)，有时也记作 \(\langle A, B \rangle\)，做法是把两个向量对应位置的元素相乘再求和。对三维向量，运算为：

$$A \cdot B = A.x * B.x + A.y * B.y + A.z * B.z$$

这个过程与计算向量长度的方法相似：两个相同向量（A=B）点积的平方根就是该向量的长度。可以写成：

$$||V||^2=V \cdot V$$

归一化方法就用到了这条原理：


template&lttypename T>
class Vec3
{
public:
    ...
    T dot(const Vec3&ltT> &v) const
    {
        return x * v.x + y * v.y + z * v.z;
    }

    Vec3&ltT>& normalize()
    {
        T len2 = dot(*this);
        if (len2 > 0) {
            T invLen = 1 / sqrt(len2);
            x *= invLen, y *= invLen, z *= invLen;
        }

        return *this;
    }
    ...
};

template&lttypename T>
T dot(const Vec3&ltT> &a, const Vec3&ltT> &b)
{
    return a.x * b.x + a.y * b.y + a.z * b.z;
}

点积在三维应用中很关键，因为它给出两个向量夹角的余弦，如图 2 所示。这个运算有多种用途，比如求两向量夹角，或做正交性检测——点积为零就意味着两个向量垂直。

  • 若 B 是单位向量，运算 \(A \cdot B\) 得到 \(||A||\cos(\theta)\)，表示 A 在 B 方向上的投影大小，方向相反时带负号。这称为 A 在 B 上的标量投影。

  • 若 A 和 B 都不是单位向量，表达式可以调整为 \(A \cdot \frac{B}{||B||}\)，其中 \(B / ||B||\) 就是 B 除以自身长度后得到的单位向量。

  • 当两个向量都已归一化，对它们的点积取反余弦（\(\cos^{-1}\)）就得到两者之间的夹角 \(\theta\)：\(\theta = \cos^{-1}\left(\frac{A \cdot B}{||A||\:||B||}\right)\) 或 \(\theta=\cos^{-1}(\hat{A} \cdot \hat{B})\)，其中 \(\cos^{-1}\) 表示反余弦函数，在编程语言里通常写作 acos()。

点积在三维几何中作用关键，用途多样，比如正交性检测。两个向量正交（垂直）时点积为 0；指向相反时点积为 -1；方向相同时为 1。这个运算被广泛用于求两向量的夹角，或求一个向量与坐标系某根轴的夹角，也有助于把向量坐标转换为球坐标，详见三角函数那一讲。

叉积

叉积是一种向量运算，与产生标量的点积不同。和点积不一样，叉积的结果是一个向量。这个运算的独特之处在于，结果向量垂直于原来两个向量所定义的平面。叉积记作：

$$C = A \times B$$

计算叉积使用如下公式：

$$ \begin{array}{l} C_X = A_Y \times B_Z - A_Z \times B_Y\\ C_Y = A_Z \times B_X - A_X \times B_Z\\ C_Z = A_X \times B_Y - A_Y \times B_X \end{array} $$

叉积 \(A \times B\) 得到向量 C，它与 A 和 B 都正交。这两个向量定义了一个平面，而 C 垂直于该平面。A 与 B 本身不必互相垂直，但当它们垂直且为单位长度时，就与 C 一起构成一个笛卡尔坐标系。这个概念在构建坐标系时很有用，创建局部坐标系那一章有进一步探讨。


template&lttypename T> 
class Vec3 
{ 
public: 
    ... 
    // 叉积的类方法
    Vec3&ltT> cross(const Vec3&ltT> &v) const 
    { 
        return Vec3&ltT>( 
            y * v.z - z * v.y, 
            z * v.x - x * v.z, 
            x * v.y - y * v.x); 
    } 
    ... 
}; 
 
// 叉积的工具函数
template&lttypename T> 
Vec3&ltT> cross(const Vec3&ltT> &a, const Vec3&ltT> &b) 
{ 
    return Vec3&ltT>( 
        a.y * b.z - a.z * b.y, 
        a.z * b.x - a.x * b.z, 
        a.x * b.y - a.y * b.x); 
}

记住叉积公式有个好用的窍门：计算某个分量时，就用公式里没有明确出现的那些坐标字母，比如问一句「为什么是 z？」，来记住计算 \(C_X\) 涉及哪些分量。更根本的是，理解叉积的结果是垂直于原来两个向量的向量，就能合乎逻辑地把这个公式重新推出来。用矩阵表示可以让这个运算更直观：

$$ \begin{pmatrix} a_x\\a_y\\a_z \end{pmatrix} \times \begin{pmatrix} b_x\\b_y\\b_z \end{pmatrix} = \begin{pmatrix} a_yb_z - a_zb_y\\ a_zb_x - a_xb_z\\ a_xb_y - a_yb_x \end{pmatrix} $$

这种表示说明，要计算结果向量的任一分量（比如 x 分量），用的是 A 与 B 中另外两个分量（y 与 z）。

必须认识到，叉积中向量的顺序会显著影响结果。例如 \(A \times B\) 与 \(B \times A\) 的结果不同：

$$A \times B = (1,0,0) \times (0,1,0) = (0,0,1),$$

而

$$B \times A = (0,1,0) \times (1,0,0) = (0,0,-1).$$

叉积被描述为反交换的，意思是交换两个向量的位置会使结果反号：若 \(A \times B = C\)，则 \(B \times A = -C\)。这一性质凸显了向量顺序在决定结果向量方向上的重要性。当两个向量定义了一个坐标系的初始两根轴时，由它们叉积得到的第三个向量指向哪边，取决于该坐标系的手性——这个概念前面讨论过。

尽管两个向量做叉积得到的结果是唯一且一致的——比如 \(A = (1, 0, 0)\) 与 \(B = (0, 1, 0)\) 永远得到 \(C = (0, 0, 1)\)——但对结果向量方向的解读取决于坐标系的手性。这个区别很关键，因为虽然计算结果不变，结果向量画出来朝向哪边，取决于坐标系是右手系还是左手系。

判断结果向量指向哪边，有个实用的手势窍门。在右手坐标系中，把食指对齐向量 A（比如曲面上的切线）、中指对齐向量 B（比如确定法线朝向时的副切线），拇指就指向向量 C（比如法线）的方向。同样两个向量改用左手，拇指所指的方向就反过来。必须认识到，这个方法处理的是向量方向的表示，而不改变计算结果本身。

在数学中，叉积的输出被称为伪向量。向量参与叉积的顺序很关键，尤其是在由某点处的切线与副切线计算表面法线时。这个顺序决定了算出的法线是朝内（内向法线）还是朝外（外向法线）。创建朝向矩阵那一章对此有进一步探讨，那里详述了叉积中向量顺序对表面朝向的影响。

向量/点的加法与减法

在向量数学中，加法和减法这类运算相当直接。向量与标量或另一个向量相乘得到一个新向量。向量之间可以相加、相减，等等。值得一提的是，有些三维 API 会把点、法线和向量区分开，因为它们在技术上有差别。比如法线的变换方式就与点和向量不同。两个点相减得到向量，而一个向量加上另一个向量或一个点则得到点。

尽管有这些区别，实践表明，为法线、向量、点各维护一个独立的 C++ 类所带来的额外复杂度未必值得。遵循行业标准 OpenEXR 的先例，我们用一个统一的模板类 Vec3 来封装法线、向量和点，在编码层面不作区分。这种做法要求在少数例外情形下小心处理：某些变量语义不同，却都声明为通用的 Vec3 类型，需要区别对待。下面是演示常见操作的 C++ 代码，体现了用单一类处理各种向量相关操作的便利：


template&lttypename T> 
class Vec3 
{ 
public: 
    ... 
    // 重载加法运算符以实现向量相加
    Vec3&ltT> operator + (const Vec3&ltT> &v) const 
    { return Vec3&ltT>(x + v.x, y + v.y, z + v.z); } 
    // 重载减法运算符以实现向量相减
    Vec3&ltT> operator - (const Vec3&ltT> &v) const 
    { return Vec3&ltT>(x - v.x, y - v.y, z - v.z); } 
    // 重载乘法运算符以实现与标量相乘
    Vec3&ltT> operator * (const T &r) const 
    { return Vec3&ltT>(x * r, y * r, z * r); } 
    ... 
};
