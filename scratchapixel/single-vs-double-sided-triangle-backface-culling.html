单面与双面三角形以及背面剔除

阅读时间：6 分钟。

单面与双面三角形

我们在讲光栅化的课程里已经讨论过背面剔除这个说法，这里再回顾一下。想象你要写一个计算光线与三角形求交的函数。我们用一个右手坐标系搭建场景，三角形的顶点按逆时针顺序定义。三角形放在距光线原点五个单位远处，光线原点位于世界坐标系的原点 \((0, 0, 0)\)。光线沿 z 轴负方向。我们已经知道怎么计算三角形法线：按这种构造，如果三角形的所有顶点都落在 x-y 平面或与其平行的平面内，法线就与 z 轴正方向一致。记住，法线的朝向取决于坐标系的左右手性以及三角形顶点的定义顺序（也叫绕序）。如图 1 所示，光线方向与三角形法线面对面。

法线朝外的那个图元表面定义为外表面，相反的一侧则称为内表面。改变坐标系的左右手性或顶点的顺序，会翻转法线方向，实际上就是把内表面和外表面互换。这种表面朝向会影响表面的可见性与着色。着色不是我们眼下关注的重点，先来看可见性的问题。

在 CG 场景里，外表面朝向相机的图元称为正面朝向。反过来，图元的外表面背对相机时，则称为背面朝向。渲染程序通常允许在渲染过程的可见性阶段丢弃所有背面朝向的图元，只让外表面朝向相机（正面朝向）的图元可见。比如 OpenGL 就提供了这类控制。这类图元称为单面图元（只有外表面朝向观看者时才可见）。要让一个图元无论表面朝向还是背向相机都可见，可以把它声明为双面。有些渲染程序不提供把图元指定为单面或双面的选项，而是要么一律丢弃所有背面朝向的图元（使它们在最终画面中不可见），要么默认把它们全设为双面。RenderMan 规范允许你逐个图元指定某个物体应按单面还是双面处理（使用 RiSide 调用）。此外，RenderMan 规范还提供了选项来定义场景坐标系的左右手性（用 RiOrientation 过程），以及按需相对于坐标系手性反转图元表面朝向（用 RiReverseOrientation 调用）。

Vulkan、Metal、DirectX 这类实时 API 也提供了控制能力：既可以指定定义三角形的顶点按逆时针还是顺时针顺序给出，也可以控制是否丢弃背面朝向的三角形。这项配置通常在定义图形管线的图元装配状态时完成。


// Using Vulkan API
rasterization_state.polygonMode = VK_POLYGON_MODE_FILL;
rasterization_state.cullMode = VK_CULL_MODE_BACK_BIT ;
rasterization_state.frontFace = VK_FRONT_FACE_COUNTER_CLOCKWISE;

背面剔除（如果你喜欢，也可以简单叫「移除」）这个说法是指：法线背对视线的物体不会被画到屏幕上。启用背面剔除后，法线不朝向视线的多边形、三角形、曲面等等都不会被渲染。最终图像里只有法线朝向相机的几何体才可见。

在 z 缓冲风格的渲染器里，这项技术可能大幅减少需要渲染的面数，从而显著提升渲染速度、降低内存占用。举例来说，理论上多边形球体有 50% 的面可以被剔除。

在光线追踪里，这个特性的好处没那么大，因为一般来说我们希望场景里所有几何体都能投射阴影，不管物体表面相对于光线方向的朝向如何。不过背面剔除对主光线仍然有用。如果一个多边形的表面法线与视线向量的夹角超过 90 度（如图所示），就可以把它排除在求交测试之外。只要在法线与视线方向之间做一次简单的点积测试，就足以判断这个面是否该被剔除。

当然，如果物体声明为双面，我们就不剔除这个面。此外，对透明物体来说，剔除背面朝向的表面可能并不可取。

综合起来

开发渲染程序时，务必让它能应付所有可能出现的情形。让用户可以选择坐标系的左右手性、按需反转表面朝向、并指定图元是单面还是双面，这些都会显著影响一帧画面里看得见什么，即便几何体完全相同。

举例来说，坐标系手性的选择会影响法线的方向，而法线是由三角形的顶点 \(v_0, v_1, v_2\) 定义的。在右手坐标系里，法线（由三角形顶点算出）指向你（背向屏幕，假定 x 轴指向右侧）。在这种情形下，光线与三角形求交函数会返回 false，只要启用了背面剔除，即便光线确实与三角形相交。反过来，换成左手坐标系就会反转法线朝向（法线将背向你，沿你的视线方向），求交测试就能成功。第一种情形下三角形不可见，第二种情形下它可见——尽管是同一个三角形。

下面是单面/双面特性的实现。在函数开头，计算三角形法线与光线方向的点积。如果点积为负，两个向量方向相反，说明这是正面朝向的表面。如果点积为正，两个向量方向相同，说明我们看到的是表面的内侧（或背面），也就是背面朝向。如果图元声明为单面，这种情形下它就不该可见，函数应返回 false。


bool intersectTriangle(point v0, ..., const bool &isSingleSided)
{
    Vec3f v0v1 = v1 - v0;
    Vec3f v0v2 = v2 - v0;
    Vec3f N = crossProduct(v0v1, v0v2);
    normalize(N);
    ...
    // 实现单面/双面特性
    if (dotProduct(dir, N) > 0 && isSingleSided)
        return false; // 该表面背面朝向
    ...
    return true;
}
