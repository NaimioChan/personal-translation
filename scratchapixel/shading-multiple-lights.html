多光源

阅读时间：4 分钟。

线性的光照响应

想象你要用不同的灯去拍一个物体，比如图 1 里的玩具。假设一开始所有灯都关着。你打开第一盏灯，拍一张；关掉它，再对每一盏灯重复这个过程。最后把所有灯都打开，再拍一张。现在把每盏灯单独打开时拍的照片全部相加，再和所有灯同时打开时拍的那张比较——得到的这两个图像看起来应该是一样的。

$$ \text{Image}_{\text{light1}} + \text{Image}_{\text{light2}} + \text{Image}_{\text{light3}} + ... = \text{Image}_{\text{all lights}}. $$

换句话说，每盏灯的贡献是按线性方式叠加的。这个观察很重要，原因有两点。第一，如果你想生成照片级真实的图像，渲染器就必须遵循同一条原则。对美术人员来说这也重要：他们要从各个单独图层重新合成 CG 渲染结果，而每个图层代表场景中某一盏灯单独的贡献。如果在把某个图层与其他图层相加之前，先用曲线以非线性方式改变它的亮度（比如加个伽马），从物理角度看就会得到错误的结果。更重要的是从编程角度看，这条原则只是说：在渲染器里，把每盏灯的贡献加起来就行。换句话说，到达某一点的总光量，就是各盏灯对该点贡献的光量的线性之和。

用数学语言来说，对漫反射表面，这个概念可以写成下面的公式：

$$S_P = \sum_{N=0}^{N=(nlights-1)}\dfrac{\rho_d}{\pi} * Li_N * \cos (N.L_N).$$

其中 \(S_P\) 表示着色点。数学中符号 \(\sum\) 的意思是「求和」。换句话说，对场景中每一盏灯（总共有 \(nights\) 盏），我们把公式里的 \(Li_N\) 和 \(L_N\) 两项换成当前这盏灯的光强与方向，算出漫反射公式。这等同于：

$$S_P = \dfrac{\rho_d}{\pi} * (Li_0 * \cos (N.L_0) + Li_1 * \cos (N.L_1) + ... + Li_{N-1} * \cos (N.L_{N-1})) .$$

从编程角度看，处理多于一盏光源非常简单。首先，可以把所有灯放进一个列表，把这个列表传给 castRay() 函数——着色就在那里完成。然后遍历所有灯，把它们的贡献累加到该着色点的光照上。要记住，光的贡献会被 \(P\) 的法线与光线方向之间夹角的余弦所衰减。这一项对每盏灯都不同，因此需要逐灯计算。同样，每盏灯也都要投一条阴影光线。最终代码大致如下：


int main(int argc, char **argv) 
{ 
    ... 
 
    // 加载几何体      
    std::vector&ltstd::unique_ptr&ltLight>> lights; 
 
    Matrix44f l2w1; 
    l2w1[3][0] = 2; 
    l2w1[3][1] = 4; 
 
    lights.push_back(std::unique_ptr&ltLight>(new PointLight(l2w1, Vec3f(1, 0.6, 0.6), 500))); 
 
    Matrix44f l2w2; 
    l2w2[3][0] = -1; 
    l2w2[3][1] = 4; 
    l2w2[3][2] = -1; 
 
    lights.push_back(std::unique_ptr&ltLight>(new PointLight(l2w2, Vec3f(0.6, 0.6, 1), 500))); 
 
    // 最后渲染       
    render(options, objects, lights); 
 
    ... 
} 
 
Vec3f castRay( 
    const Vec3f &orig, const Vec3f &dir, 
    const std::vector&ltstd::unique_ptr&ltObject>> &objects, 
    const std::vector&ltstd::unique_ptr&ltLight>> &lights, 
    const Options &options) 
{ 
    Vec3f hitColor = 0; 
    IsectInfo isect; 
    if (trace(orig, dir, objects, isect)) { 
        Vec3f hitPoint = orig + dir * isect.tNear; 
        Vec3f hitNormal; 
        Vec2f hitTexCoordinates; 
        isect.hitObject-&gtgetSurfaceProperties(hitPoint, dir, isect.index, isect.uv, hitNormal, hitTexCoordinates); 
        for (uint32_t i = 0; i < lights.size(); ++i) { 
            Vec3f lightDir, lightIntensity; 
            IsectInfo isectShad; 
            lights[i]-&gtgetShadingInfo(hitPoint, lightDir, lightIntensity, isectShad.tNear); 
            bool vis = !trace(hitPoint + hitNormal * options.bias, -lightDir, objects, isectShad, kShadowRay); 
            // 累加光的贡献                 
            hitColor += vis * isect.hitObject-&gtalbedo * lightIntensity * std::max(0.f, hitNormal.dotProduct(-lightDir)); 
        } 
    } 
    else { 
        hitColor = options.backgroundColor; 
    } 
 
    return hitColor; 
}
