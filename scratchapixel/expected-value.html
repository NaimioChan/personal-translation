阅读时间：25 分钟。

期望值

平均值或算术平均的概念很简单。比如你有一群人，想测量这群人的平均身高，就把这群里每个人的身高加起来，再把结果除以人数。同样，如果你想计算任何其他平均值，比如一组 \(n\) 个实值的平均，你只需把所有值加起来，再把这个和除以 \(n\)。下面这 3 个数字 {0, 1, 2} 的平均值是 (0+1+ 2)/3=1。很简单。

回到我们 10 张卡片的例子，我们知道这个实验的样本空间（至少如果我们只考虑基本事件）是 \(S = \{0,1,2\}\)。如果你不知道盒子里卡片的分布，你可能会想说这个实验的平均值就是可能结果值之和除以结果数目。在我们的例子里就是 (0+1+2)/3=1。但这个答案是错的。为什么？因为盒子里有些数字出现得比其他数字更频繁，因而它们在均值的计算中「分量」更重，确实倾向于把均值拉向它们的值。举个例子。设想你有 4 张卡片，分别标着 0、1、2 和 2。现在因为这个分布里数字 2 出现了两次，这 4 个数字的均值会被推向数字 2：(0+1+2+2)/4=1.25。再看看如果分布是这样会怎样：0, 0, 1, 2。这 4 个数字的均值是：(0+0+1+2)/4=0.75。因为数字 0 出现得比其他数字多，均值现在被推向 0。盒中卡片数字的最终均值，是每个数字乘以它的权重之和。那么这些权重究竟怎么得到？它们可以通过把具有某个数字的卡片数除以盒中卡片总数算出来，而如果你还没猜到，这些正是各结果的概率。用我们 4 张卡片的例子很容易验证：

$$ \begin{array}{l} mean &=& \dfrac{(0+1+2+2)}{4} \\ &=&0 * \dfrac{1}{4} + 1 * \dfrac{1}{4} + 2 * \dfrac{1}{4} + 2 * \dfrac{1}{4} \\ &=&0 * \dfrac{1}{4} + 1 * \dfrac{1}{4} + 2 * \dfrac{2}{4}.\\ \end{array} $$ $$S = \{0,1,2\}, \; p = \{ \dfrac{1}{4}, \dfrac{1}{4}, \dfrac{2}{4}\}.$$

总之，卡片总体均值的正确答案可以通过把样本空间中每个数字乘以它的概率算出来：0*2/10+1*5/0+2*3/10=1.1。不过在统计学中，为了把第一种方法（标准算术平均：把所有数字加起来除以卡片总数）与第二种方法（用概率得到同一个值）区分开，第二种方法的结果叫作期望值。

再次注意，均值和期望值相等，但均值是数字的简单平均、不加任何权重，而期望值是按概率加权求和。我们可以写成：

$EV = \sum_{i=1}^N p_i x_i.$

其中 EV 表示期望值，\(p_i\) 是与结果 \(x_i\) 相关联的概率。

计算这个数字非常像计算重心或支点，如果你喜欢的话可以想象一个悬挂装置。如果一些物体用绳子挂在一条坚实的横杆上且均匀分布，那么这个整体的支点并不在横杆的中点（如下图所示），而是在悬挂装置达到平衡的地方，也就是横杆上左边重量与右边重量相等的那一点（下图右侧。注意支点如何稍稍向右移动了）。总体参数的均值可以看作同一回事，其中挂在横杆上的物体是实验的可能结果，物体的重量是与这些结果相关联的概率。

现在把这个概念形式化。总体参数的均值用希腊字母 \({\mu}\)（读作「mu」）表示。在卡片的例子里，你可以用两种方式计算这个值。你可以把全部卡片上所有数字加起来，再除以卡片总数；或者如果你知道卡片的概率分布（假定我们确实有这个信息），就可以用上面描述的方法：把每个结果乘以它的概率再求和。我们把这两个解法写出来，验证它们给出相同结果：

$$ \begin{array}{l} \mu &=&\dfrac{(0+0+1+1+1+1+1+2+2+2)}{10}=1.1,\\ EV&=&0 * 0.2 + 1 * 0.5 + 2 * 0.3=1.1. \end{array} $$

作为一个实际例子，我们来计算掷骰子的期望值。我们知道有 6 个可能结果 1、2、3、4、5、6，且每个结果的概率都是 \(1 \over 6\)，因此：

$$EV = \dfrac{1}{6} (1+2+3+4+5+6) = 3.5.$$

我们之所以温和地引入这个想法——当实验的结果与概率已知时，它的期望值（等于总体均值）可以通过把结果值乘以各自概率再求和算出（希望我们通过几个例子已经让你相信这确实成立）——是为了帮你对接下来要谈的内容建立更好的直觉，那部分或许稍微更抽象一些。正如我们刚提到的，到目前为止用过的几个例子里，实验的概率分布和结果都是已知的。但这大概是例外而非常态，尤其是在统计学领域工作时。举例来说：如果你事先知道一场选举中每位候选人（可能结果）得到的票数（概率），那么当然，统计研究（民意调查）就没有本质意义了。在绝大多数情况下，这些变量是未知的（有时结果是已知的，比如选举的情形，但并非必须如此）。这就引出一个问题：那我们该怎么办？

如果你在心里回答「我们用采样」，那你的方向是对的。但我们更愿意从随机变量的角度来解释这个想法。如果你需要测量某个属性或总体参数，却对该总体一无所知，也不知道所关心参数的可能取值范围，你就只剩一个选择：走上街头去问！或者如果你更懂点技术，可以用电话簿随机挑选全国各地的电话号码（当然，你选择号码的方式必须真正「随机」，换句话说必须公平无偏）。你拨打这些号码，如果在线上有人接，且假定这个人符合你的选择标准（他或她是住在巴哈马的成年人，不是小孩也不是游客），那就问这个人的身高。恭喜，你把自己变成了一个随机变量。那就假定，作为进行这项统计研究的人，你就是那个试图测量总体参数的随机变量，在我们的例子里就是住在巴哈马的成年人口的身高。为什么说你是随机的？因为每次你打电话获取一个人的身高时，你取的是不同的值，比如第一次 168 厘米，第二次 175，第三次 167，等等。你一直在变。然而作为随机变量，你的任务是测量住在巴哈马的成年人口的平均身高，所以当你收集数据并据这些数据算出一个平均身高时，有趣的事情就开始发生了。一开始你取前两个观测值的平均（168 和 175 除以 2 = 171.5），接着三次电话后，取前三个观测值的均值（168、175 和 167 除以 3 = 170），等等，你随着收集新观测值一直这么做。这个过程有趣的地方在于，每个中间结果都是随机的（这很正常，因为每个观测值都是随机数）。例如前两个观测值的均值是 171.5，前三个观测值的均值是 170，等等，因此每次我们加入一个新的观测值、用迄今收集到的所有观测值计算随机变量的均值时，均值的值都会变。但你最终会观察到，到某个时候你的观测值会多到再加一个观测值对均值的计算影响越来越小。另一种看法是：随着样本规模增大，随机变量的均值收敛到一个唯一值，而如果你还没猜到，这个值就是期望值（如果你还没猜到，我们很快会解释）。这通常很容易从直觉上理解。如果你有一千个人，身高都在比如 165 到 175 厘米之间（到目前为止平均身高是 170 厘米），那么出现一个身高与你样本中多数人差别很大的个体，不太可能对该样本的总体平均身高产生很大影响。你可以把这看作一个稀释过程。往一升纯水里加一滴牛奶，不太可能让水看上去浑浊。

对于你可能觉得显而易见的事情，这段解释很长，但我们刚描述的东西，在论证统计学与蒙特卡罗方法从数学角度看为何成立时起着重要作用。我们举一个实际例子。拿一个简单的实验比如掷骰子，在反复重复实验的过程中计算结果的均值。我们可以用一个小 C++ 程序来模拟，每次加入新观测值时打印出随机变量的均值（这个程序里我们用均匀分布的随机数生成器来抽取 1 到 6 之间的随机数，但现在不用担心这一点。我们只假定这个过程与手工掷骰子相同）。因为程序不能永远跑下去，我们在 1000 次试验后停止：


#include &ltrandom> 
#include &ltcstdlib> 
#include &ltcstdio> 
 
int main(int argc, char **argv) 
{ 
    std::mt19937 rng; 
    rng.seed(2013); 
    std::uniform_int_distribution&ltuint32_t> die(1,6); 
    int sum = 0; 
    for (int n = 1; n <= 1000; N++) {  //试验次数 = n         
        int rnd = die(rng);  //随机变量 X 的结果               
        sum += rnd;  //更新和     
        printf("%d %f\n", n, float(sum) / n);  //打印样本均值          
    } 
 
    return 0; 
}

如果你把这个程序的结果画出来（把均值相对于用于计算它的试验次数作图），可以看到随着试验次数增加，这个值的平均收敛到 3.5（我们知道这就是六面骰子的期望值）。

因为统计学里一切都有名字（也有确切含义），由一个随机变量 \(X\) 产生的一组观测值的均值叫作样本均值（记住，一组观测值叫作样本或统计量）。样本均值一般记作 \({\bar X}\)，你可以读作「X bar」，数学上可以写成：

$$\bar X_n = \dfrac{1}{n} (X_1 + X_2 + ... + X_n).$$

其中 \(X_1, X_2\)、…… 是一列随机变量，它们具有独立同分布（或称 i.i.d）的性质。

问：「样本均值定义里的那些 X 对应的是观测值。在随机变量的简介里，你提到过为了把观测值与用大写字母表示的随机变量区分开，观测值应当用小写字母？」这确实常常是混淆的来源。我们选择这种记号，是因为教科书里一般就是这么写的，而这背后有个原因，目前还没到解释的时候。不过我们可以这样说：随机变量是从样本空间到 \(\mathbb{R}\) 的函数。\(\mathbb{R}\) 表示数学中我们所说的实数空间。因此，用数学行话说，我们说随机变量（它们是函数）可以逐点代数运算。不过这没那么重要。如果你把随机变量理解为某个结果 \(\omega\) 的函数（其中 \(\omega\) 可以是样本空间 S 中的任何结果），把观测值理解为这个函数的结果，那么你可以写成像 \(x = X(\omega)\) 这样。而与其写 \(\bar X = {1 \over n } (x_1+x_2+...+x_n)\)，你也可以写 \(\bar X = {1 \over n} (X_1(\omega)+X_2(\omega) + ... + X_n(\omega)\)。换个说法，你可以把这些 \(X_1, X_2\)、…… 看作随机变量 \(X\) 的实例。

为了解释 i.i.d 是什么意思，我们举个例子。考虑不公平硬币的情形（即得到反面或正面的概率不相同。我们也可以说这是一枚灌了铅的硬币）。设想这枚硬币以概率 \(2/3\) 落在正面，以概率 \(1/3\) 落在反面。如果我们把硬币掷两次，第一次掷出的结果不会改变第二次的结果。因此这些结果是独立的（我们在第 3 章已经解释过这个概念）。还要注意，硬币第一次被掷时，得到正面或反面的概率分别是 \(2/3\) 和 \(1/3\)。也要注意，硬币第二次被掷时，实际得到正面或反面的概率仍然是 \(2/3\) 和 \(1/3\)。换句话说，第一次掷后你得到正面或反面的概率并没有改变。使这些结果同分布的，是随着实验一次次重复，每个可能结果所关联概率的一致性。总之，尽管硬币是灌了铅的，得到的随机变量序列仍是 i.i.d 的。简言之，i.i.d 随机变量彼此独立，且具有相同的概率分布。

总结一下，我们的 C++ 程序表明，随着样本规模增大，样本均值收敛到期望值：

$\bar X_n \approx EV.$

其中符号 \(\approx\) 表示「近似」（但在我们的语境里，更好的做法是养成改用「估计」这个词的习惯，我们很快就会解释为什么）。「随着样本规模增大，样本均值在数值上和概率上都收敛到期望值」这个想法，表述在概率论的一个定理中，该定理叫作大数定律（或 LLN）。解释这个定理有几种可能的思路；其中一种是：当试验次数变得很大时，实验中每个结果的相对频率趋向于该结果的概率。如果我们掷一枚骰子 6000 次，其中大约 1000 次应当是 1（可能不正好是 1000，但如果不是，也应该非常接近），大约 1000 次应当是 2，等等。

有趣的是，注意试验次数越多，恰好得到「试验次数除以 6」那么多结果的概率反而越小（假设试验次数是 6 的倍数）。你也可以用一个更简单的实验来看这个问题。如果你把一枚硬币掷 10 次，得到 5 次正面的概率是多少？这可以用二项分布解析地算出来：

$$ \left( \begin{array}{cr} 10 \\ 5 \end{array} \right) \left( { 1 \over 2 }\right)^5 \left(1 - {1\over 2}\right)^5 = 0.2461. $$

但如果你现在考虑 100 次试验，这个概率就变成：

$$ \left( \begin{array}{cr} 100 \\ 50 \end{array} \right) \left( { 1 \over 2 }\right)^{50} \left(1 - {1\over 2}\right)^{50} = 0.0796. $$

如你所见，试验次数越多，恰好得到 N/2 次正面（其中 N 是试验次数）的概率越小。在试图理解大数定律的概念时，这是一个重要的区分：大数定律保证的是正面的比例随着 \(n\) 增大而趋近 1/2，然而如前所述，有趣的是恰好得到 N/2 次正面的概率反而变小。你可以从数学上证明这一点。比如我们来计算 100 次试验中得到 40 到 60 之间任何次数正面的概率（这不过是恰好得到 40、41、……60 次正面的概率之和）：

$$ Pr(40 \leq X \leq 60) = \sum_{i=40}^{60} \left( \begin{array}{cr} 100 \\ i \end{array} \right) \left( \dfrac{1}{2} \right)^i \left( 1 - \dfrac{1}{2} \right)^{100 -i} = 0.9648. $$

然而，如果我们计算 10 次试验中得到 [4,6] 区间内任何次数正面的概率，就得到：

$$ Pr(4 \leq X \leq 6) = \sum_{i=4}^{6} \left( \begin{array}{cr} 10 \\ i \end{array} \right) \left( \dfrac{1}{2} \right)^i \left( 1 - \dfrac{1}{2} \right)^{10 -i} = 0.6563. $$

随着试验次数增加，得到接近 1/2 的概率会增大。

如你所见，每个数字对应的试验次数除以试验总数，趋近于每个结果的概率。在骰子的例子里，我们知道概率是 \(1/6\)，但如你所见，当我们不知道那个概率是多少时，可以改用采样方法来估计它。而这确实管用！解释这个定理的另一种说法是：它保证随机变量的平均值有稳定的长期结果。换句话说，随着我们不断增加试验次数，定理告诉我们，离散随机变量的平均值趋向于一个极限，这个极限就是该随机变量的期望值（详情见上面的灰色框）：

$$\bar X_n \xrightarrow{p} E[X] = \mu \text{ as } n \rightarrow \infty.$$

右箭头上方的上标 p 表示「依概率收敛」。你也可以把这条性质定义为：

$$ \begin{array}{l} \lim_{n \rightarrow \infty} \text{ Pr }(|\bar X_n - \mu| < \epsilon) = 1. \end{array} $$

用文字说，它的意思是：样本均值与总体均值之差小于一个非常非常小的值（这里用希腊符号 epsilon \(\epsilon\) 表示）的概率，在 \(n\) 趋于无穷时为 1。我们一般称之为依概率收敛。总之，你应当记住：一个随机样本的样本均值 \({ \bar X }\) 总是依概率收敛到抽出该随机样本的那个总体的总体均值 \({\mu}\)。

随机变量的期望值意味着什么，常常没被说得很清楚。比如当你写 \(E[X_1]\)，其中 \(X_1\) 是一个随机变量时，它所指的其实很简单。当然，单独的 \(X_1\) 可能取任何值，但它的期望值 \(E[X_1]\) 是固定的。而这个固定值对所有随机变量 \(X_1, X_2, ... X_n\) 都相同：\(E[X_1] = E[X_2]=...=E[X_n]\)。你可以把这看作它们共有的一条性质，之所以如此，是因为这些随机变量共享同一个概率分布，因而必然具有相同的期望值。而按定义，随机变量的这个期望值也等于总体均值（再参见本章开头）。然后注意：

$E[X_1]=E[X_2]=...=E[X_n]=\mu.$

它们相等，但要记住它们的计算方式不同：均值是数字的简单平均，而随机变量的期望值是把各结果按概率加权求和（因此期望值取决于各结果的概率分布）。在维基百科关于大数定律的条目中，用符号 \(\mu\) 代替了 \(E[X]\)，这让人困惑，因为理想情况下最好把总体均值与随机变量期望值这两个概念分开，即使它们的值相等。

重要：概率与统计学中有许多你需要了解的概念，但我们认为这个概念是理解其他一切的关键。务必在心里弄清楚：按定义，随机变量 \(X\) 的期望值等于总体均值。它在后面几章中会被大量使用。

到这里，也许该稍微退一步，把我们学到的东西总结一下（并给出期望值更正式的定义）。首先，希望我们如今已经讲得相当清楚：\(X\) 的期望值只取决于 \(X\) 的分布。这一点希望上面已经充分解释。因此两个具有相同分布的随机变量有相同的期望值。如果你对巴哈马的人口采样，而你的朋友同时做同样的事，你们是两个不同的变量，但你们会得出该人口身高的同一个期望值。期望值还有几个同义词：它也叫均值或期望。不过要避免用「均值」这个词，因为它容易与总体均值混淆。一般来说，你可以把随机变量 \(E[X]\) 的期望值理解为其分布的一个概括。如果把概率分布想象成在一条直线上分布着具有某种重量（结果的概率）的物体（各结果），那么期望值可以看作质心。最后当然，如果我们知道随机变量的分布，就可以直接计算期望值（而不必用样本、依赖大数定律）：

$$E[X] = \sum_{i=1} p_i x_i \rightarrow = \sum_{\omega \in S} X(\omega) p(\omega).$$

其中 \(p(\omega)\) 是某个返回结果 \(\omega\) 概率的函数。正如多次提到的，期望值就是各结果 \(x_i\) 按各自概率 \(p_i\) 加权之和。最后，总体均值与期望值相等：\(\mu = E[X]\)。

期望值的性质

期望值有一些性质，它们很重要，尤其是用来证明我们接下来要介绍的一些技术。

性质 1：首先，如果你考虑 \(Y = aX + b\)（随机变量 Y 等于随机变量 X 乘以某个因子再加上一个常数），那么：

$$E[Y] = aE[X] + b.$$

这从直觉上并不难理解。比如你考虑一个实验，骰子上的数字都乘以 10，那么这个随机变量的期望值是 35（10 乘以 3.5，也就是普通六面骰子的期望值）。不过如果你要证明，可以写：

$$ \begin{array}{l} E[aX] &=& \sum_i a x_i P(X = x_i) \\ &=&a \sum_i x_i P(X = x_i)\\ &=&aE[X]. \end{array} $$

如果 \(X = c\)，其中 \(x\) 是常数（换句话说，取值为 \(c\) 的概率是 1），那么 \(E[X] = c\)。这里同样不难理解。如果一枚骰子所有面上的数字都相同，那么它的期望值就是这个数字。

性质 2：随机变量之和的期望值，等于构成该和的各个随机变量期望值之和（和的期望等于期望之和）：

$$E[X_1 + ... X_n] = E[X_1] + ... + E[X_n].$$

如果我们掷一枚硬币，令 X 在硬币正面朝上时取 1、反面朝上时取 0。然后我们再掷一枚骰子，令 Y 表示朝上的面。X 与 Y 同时发生（可以写成 X + Y）的概率是多少？在第 3 章（关于概率的性质）中我们解释过，这个问题的答案是 X 与 Y 各自发生概率的乘积，这称为乘法法则。换句话说，得到 X = 1（其中 X 定义为掷出正面时为 1，否则为 0）与 Y = 2（其中 Y 是掷骰子的结果）的联合概率等于各自结果发生概率的乘积，即：

$$Pr(X = 1, Y = 2) = {1 \over 2} \times {1 \over 6} = {1 \over 12}.$$

在概率论中，我们可以把两个随机变量的组合表示为第三个随机变量 Z = (X,Y)，其中 Z 叫作联合随机变量，它的结果是形如 \((x, y)\) 的有序对，在我们这个例子里 \(0 \le x \le 1\) 且 \(1 \le y \le 6\)。换句话说，我们可以说得到正面和 2 的概率，或者说得到结果 3（由正面和 2 得到）的概率，是得到正面的概率乘以得到 2 的概率，可以写成：Pr(X = 1, Y = 2)。有了这个工具，我们可以写（记住期望值就是实验所有结果乘以各自概率之和）：

$$ \begin{array}{l} E[X + Y] &=&\sum_i \sum_j (x_i + y_j) Pr(X = x_i, Y = y_i) \\ & = & \sum_i \sum_j x_i Pr(X = x_i, Y = y_i) + \sum_i \sum_j y_j Pr(X = x_i, Y = y_i) \\ & = & \sum_i x_i Pr(X = x_i) + \sum_j y_j Pr(Y = y_j) \\ &=&E[X] + E[Y].\end{array} $$

记住对给定实验而言各概率之和为 1，这就是为什么我们可以写（Y 的概率之和为 1，因此可以把这个求和从方程中去掉）：

$$\sum_j Pr(X = x_i, Y = y_j) = Pr(X = x_i),$$

以及（X 的概率之和为 1，因此可以把这个求和从方程中去掉：

$$\sum_i Pr(X = x_i, Y = y_j) = Pr(Y = y_j).$$

如果你还有疑虑，可以自己用硬币/骰子的例子算算结果。我们知道硬币与骰子实验各自的期望值是 0.5 和 3.5，因此和应当是 4。我们来验证（如旁图所示我们有 12 个可能结果，概率为 \(1\over 12\)）：

$$ \begin{array}{l} E[X + Y] &=& (0+1)\dfrac{1}{12} + (0+2)\dfrac{1}{12} + (0+3)\dfrac{1}{12} + \\ && (0+4)\dfrac{1}{12} + (0+5)\dfrac{1}{12} + (0+6) \dfrac{1}{12} + \\ && (1+1)\dfrac{1}{12} + (1+2) \dfrac{1}{12} + (1+3) \dfrac{1}{12} + \\ && (1+4) \dfrac{1}{12} + (1+5) \dfrac{1}{12} + (1+6) \dfrac{1}{12} \\ &=& (1 + 2 + 3 + 4 + 5 + 6) \dfrac{1}{12} + (2 + 3 + 4 + 5 + 6 + 7) \dfrac{1}{12} \\ &=& \dfrac{21}{12} + \dfrac{ 27}{12} = 4 = 0.5 + 3.5. \end{array} $$

对独立随机变量之积也有类似的定理，但我们不会用到它，目前可以忽略。还有一些别的性质，但渲染中不用。

术语小结

在课程的这个地方，重要的是你要清楚区分：

  • 样本均值 \(\bar X\)（我们的估计）。

  • 总体均值 \(\mu\)（我们试图估计的总体参数的精确均值）。

  • 期望值 \(EV\) 或 \(E[X]\)（它也是我们试图估计的总体的精确均值，不过是把实验结果按概率加权求和算出来的）。

阅读其他统计学文献（包括维基百科上的条目）时要非常小心，因为并非所有资料都使用相同的约定。期望值与「均值」一词是同义的。不过，均值不能与总体均值混淆。此外，尽管一般认为总体均值用符号 \(\mu\) 表示，这个符号有时也被用来表示均值或期望值（而不是 E[X] 或 EV）。这个局面我们无能为力。至少在本课程中，我们尽量保持记号的一致。
