阅读时间：29 分钟。

反射、折射（透射）与菲涅尔

反射与折射在现实世界中非常常见，每天都看得到。玻璃或水是两种很常见的材质，两者兼有这两种性质：光能穿过它们——这个现象我们称为透射——同时它们也能反射光。本章要回答的重要问题是：我们怎么知道有多少光被透射、有多少光被反射？要回答这个问题，就需要了解菲涅尔效应。另一些材质是不透明的，完全不能透射光，但能很好地反射光，比如金属。

本章我们将学习如何模拟反射、折射（透射），以及菲涅尔效应——对玻璃、水这类透明材质，它决定有多少光被反射、有多少光被透射。

反射

先从反射说起，它几乎是光与物质相互作用中最简单的形式。反射是光子（如果你不熟悉光子这个概念，也可以理解为一束入射光）打到玻璃、水或铝板这类反射性表面时发生的事。光子遇到的情况和网球打到地板上非常相似：它会沿一个方向弹回，这个方向关于撞击点处的表面法线与入射方向对称，如图 1 所示。换句话说，如果入射方向与表面法线的夹角记作 \(\theta_i\)，反射方向与表面法线的夹角记作 \(\theta_r\)，那么 \(\theta_i = \theta_r\)。很简单！这叫作反射定律。

已知入射方向和表面法线时，计算反射方向非常简单。如图 2 所示，向量 I 和 R 可以用向量 A 和 B 表示：

$$ \begin{array}{l} I &=& A + B,\\ R &=& A - B. \end{array} $$

向量 \(B\) 很容易算，它就是向量 \(I\) 或 \(R\) 在向量 \(N\) 上的投影。如讲 几何 的课程所述，这可以用下面的公式计算：

$$B = \cos(\theta) * N.$$

\(\cos(\theta)\) 这一项当然等于：\(N.I\)。它是 \(N\) 与 \(I\) 的点积。

现在可以把 \(B\) 代回这两个公式：

$$ \begin{array}{l} I &=& A + \cos(\theta) * N,\\ R &=& A - \cos(\theta) * N. \end{array} $$

第一个公式可以改写成：

$$A = I - \cos(\theta) * N.$$

用这个结果，第二个公式可以写成：

$$ \begin{array}{l} R &=& I - \cos(\theta) * N - \cos(\theta) * N,\\ R &=& I - 2\cos(\theta) N,\\ R &=& I - 2(N \cdot I)N. \end{array} $$

只有当反射光线的方向与视线方向一致时，我们才能看到光线的反射。在图 3 中可以看到三条入射方向不同、颜色也不同的光线的反射。虽然这些光束在表面上的同一点相交，观察者却只能看到中间那条（橙色）光线的反射。如果你固定视线方向，把中间那条入射光线的方向哪怕只改一点点，观察者就看不到那条光线的反射了。要重新看到这条光线的反射，观察者就得移动位置，让自己的视线方向与橙色反射光线的方向对齐。如果入射方向固定而观察者移动，那么当视线方向依次与红、橙、绿三条反射光线的方向对齐时，观察者就会依次看到物体表面上的红点、橙点和绿点。这和我们观察波浪起伏的水面上太阳的倒影很相似：当浪面相对观察者的角度恰好合适时，我们能看到太阳的倒影，但由于浪形变化很快，这个倒影会迅速出现又迅速消失（闪烁效应）。

发出这些光线的场景物体，其反射像会随视线方向变化，正因如此我们说反射是与视角相关的。如果你看着镜子里一个静止物体的像并改变方向，会发现这个物体的像变了。当我们从不同角度看一个物体时，觉得这很自然；但当我们相对于映出同一物体的镜子改变位置时，也许会觉得没那么自然，尽管原因本质上相同：我们看到的是物体的不同部分。相对地，我们说漫反射是与视角无关的，因为它不随视角变化，详见讲 朗伯材质 的那一章。

在光线追踪器里模拟反射非常简单。如果主光线打到的物体是类镜面表面，我们就用入射视线方向（主光线方向）和交点处的表面法线算出反射方向，然后递归调用 castRay() 函数（函数调用自身），把反射光线的颜色赋给主光线的颜色。反射光线可以称为反射光线，有时也叫镜面光线（「镜面」一词的含义我们会在下一章更详细地解释）。注意，这项技术只能产生完全清晰的反射。要了解如何产生模糊或光泽反射，请参阅下一章或本节第二门讲着色的课程。在我们的例子里，平面在不反射球体时反射的是背景色，因此平面和背景图像在视觉上无法区分。为此我们把反射的亮度削减一点（本例为 20%——第 24 行）。这并不算错，因为类镜面表面通常本来也不会反射 100% 的入射光。本章后面要讲的菲涅尔效应也会影响表面反射多少光。


Vec3f reflect(const Vec3f &I, const Vec3f &N) 
{ 
    return I - 2 * dotProduct(I, N) * N; 
} 
 
Vec3f castRay( 
    const Vec3f &orig, const Vec3f &dir, 
    const std::vector&ltstd::unique_ptr&ltObject>> &objects, 
    const std::vector&ltstd::unique_ptr&ltLight>> &lights, 
    const Options &options, 
    const uint32_t & depth = 0) 
{ 
    if (depth > options.maxDepth) return options.backgroundColor; 
    ... 
    if (trace(orig, dir, objects, isect)) { 
        ... 
        switch (isect.hitObject-&gttype) { 
            case kDiffuse: 
            ... 
            case kReflection: 
            { 
                Vec3f R = reflect(dir, hitNormal); 
                hitColor += 0.8 * castRay(hitPoint + hitNormal * options.bias, R, objects, lights, options, depth + 1); 
                break; 
            } 
            ... 
        } 
    } 
    ... 
 
    return hitColor; 
}

注意这个过程可能是递归的。完全可能出现这种情况：一条光线与反射表面相交，我们由此投出另一条反射光线，它又与另一个反射表面相交，如此下去。换句话说，只要光线没有相交到非镜面的物体、也没有完全不相交任何东西（此时我们返回背景色），这个过程就会不断投出反射光线。如果一条光线一直只在反射表面之间反射、从不反射别的东西，我们就会陷入某种无限递归。为防止这种情况，我们一般会对递归次数设一个上限。反射光线在表面上被反射的次数叫作光线深度。从主光线投出一条反射光线时，我们说这条光线的深度为 1。经过两次反射后，光线深度为 2，依此类推。每次递归调用 castRay() 函数，光线深度就加一。在函数开头（第 14 行），我们检查光线深度是否超过允许的最大光线深度。若是，就停止继续执行函数，直接返回背景色（就像光线没有与任何物体相交一样）。当然，引入这个上限意味着生成的图像会偏离现实。不过对大多数场景而言，深度用到远大于 4 或 5 一般也看不出什么视觉差别。只有在渲染非常复杂的透明表面（比如水花）时，才需要把深度用得远大于 5，才能做出接近实物的图像。但希望这类情况一般很少见。要记住，给递归深度设上限的另一个原因还在于光线追踪开销很大：递归越深，渲染一帧所需时间越长。设置最大递归深度始终是图像质量与渲染时间之间的权衡。

注意反射（以及我们从此以后要研究的许多其他着色效果）都能用光线追踪算法完美模拟。记住，光线追踪本质上是计算两点之间可见性的技术。在这个具体情形里，我们计算的是从投出光线的那个点到光线沿其方向（本例中是反射方向）遇到的第一个表面之间的可见性。这正是为什么在模拟反射这类效果时，光线追踪比光栅化更好。

折射

本课只讨论清澈透明物体的情形。许多透明物体会让穿过介质的光发生衰减。本课忽略介质造成的光衰减与吸收效应。关于这个效应，你可以在讲着色的进阶课程里找到资料。

光线从一种「透明」介质进入另一种时，会改变方向。这个现象如图 7 所示。可以看到，图中这条光线在两种介质的分界处（可以是空气—玻璃、空气—水、玻璃—水等）发生了弯折。光线的新方向取决于两个因素：光线的入射角，以及新介质的折射率（也称为折射指数，有时写作 ior）。玻璃和水的折射率分别约为 1.5 和 1.3。在入射角固定的情况下，弯折的程度取决于折射率（如下图所示）。

光在真空中传播时，我们都知道它以光速传播，这个速度常用常数 \(c\) 表示。但当它穿过另一种介质时，速度会降低。若把光在这种介质中的速度记作 \(v\)，那么折射率就是 \(c\) 与 \(v\) 之比：

$$\eta= \dfrac{c}{v}.$$

折射率一般用字母 \(\eta\)（希腊字母 eta）表示。光在水中的速度比在玻璃中快，但比在空气中慢（空气的折射率非常接近 1，在 CG 中我们几乎总是把空气当作真空处理）。折射、也就是光线的弯折，解释了为什么透过玻璃或水这类透明物体看到的物体会显得变形。它能制造出一些相当奇特的效果，比如图 8 中「断笔」的错觉。透过玻璃球看物体时，透过球看到的物体的像会颠倒，如图 9 所示。这些都是折射造成的效果（属于光学效应的范畴）。解释折射现象超出了本课的范围。眼下我们只专注于可以用来计算折射光线方向的公式。

折射由斯涅尔定律描述：对给定的一对介质，入射角 \(\theta_1\) 的正弦与折射角 \(\theta_1\) 的正弦之比，等于两种介质折射率之比的倒数（图 7）：

$$\dfrac{\sin\theta_1}{\sin\theta_2} = \dfrac{\eta_2}{\eta_1}.$$

可以看到，这个公式真的很简单。我们已知 \(\theta_1\)，它就是入射光线方向与表面法线的点积，也知道两个折射率。但它在 3D 空间中是怎么起作用的？看图 10，可以看到入射光线、反射光线和透射光线都位于同一个平面内，这个平面叫作入射面（该平面内包含入射光线和表面法线）。换句话说，我们可以在入射面内做几何构造。看图 11。首先可以看到，我们要构造的透射光线向量 \(T\) 是向量 \(A\) 与 \(B\) 之和：

$$T = A + B.$$

\(A\) 与 \(B\) 可以用下面两个公式轻松算出：

$$ \begin{array}{l} A = M\sin(\theta_2),\\ B = -N\cos(\theta_2). \end{array} $$

\(N\) 我们知道了，那向量 \(M\) 呢？这个向量同样可以通过构造轻松得到。可以看到 \(M\) 可以这样算：

$$M = \dfrac{(I + C)}{\sin(\theta_1)}.$$

公式的第一部分很简单。\(I + C\) 这一项给出一个垂直于 \(N\) 的向量，或者换个说法，一个与表面相切的向量。不过这个向量还没有归一化。要归一化，只需把它除以 \(\sin(\theta_1\)。可以看到 \(I + C\) 的长度正好等于 \(\sin(\theta_1)\)。如果未归一化向量的长度为 0.7，把它除以 0.7，除后长度就是 1，向量就归一化了。我们有 \(M\) 和 \(N\)。向量 \(C\) 照例就等于：

$$C = \cos(\theta_1)N.$$

把这些元素合在一起，就得到：

$$ \begin{array}{l} T = A + B,\\ T = M\sin(\theta_2) - N\cos(\theta_2),\\ T = \dfrac{(I + C)\sin(\theta_2)}{\sin(\theta_1)} - N\cos(\theta_2),\\ T = \dfrac{(I + \cos(\theta_1)N)\sin(\theta_2)}{\sin(\theta_1)} - N\cos(\theta_2). \end{array} $$

我们知道（斯涅尔定律）：

$$\dfrac{\sin(\theta_2)}{\sin(\theta_1)} = \dfrac{\eta_1}{\eta_2}.$$

因此：

$$T = \dfrac{\eta_1}{\eta_2}(I + \cos(\theta_1)N) - N\cos(\theta_2).$$

我们还知道：

$$\cos^2(\theta) + \sin^2(\theta) = 1 \rightarrow \cos(\theta) = \sqrt{1 - \sin^2(\theta)}.$$

而由于：

$$\sin(\theta_2) = \dfrac{\eta_1}{\eta_2} \sin(\theta_1).$$

最终得到：

$$T = \dfrac{\eta_1}{\eta_2}(I + \cos(\theta_1)N) - N\sqrt{1 - \left( \dfrac{\eta_1}{\eta_2} \right) ^2 \sin^2(\theta_1)}.$$

若写作：

$$ \begin{array}{l} \eta = \dfrac{\eta_1}{\eta_2},\\ c_1 = \cos(\theta_1) = N \cdot I,\\ c_2 = \sqrt{1 - \left( \dfrac{n_1}{n_2} \right) ^2 \sin^2(\theta_1)} \rightarrow \sqrt{1 - \left( \dfrac{n_1}{n_2} \right) ^2 (1 - \cos^2(\theta_1))} \end{array} $$

则：

$$ \begin{array}{l} T = \eta(I + c_1 N) - N c_2,\\ T = \eta I + (\eta c_1 - c_2) N. \end{array} $$

也许你该花点时间体会一下自然（以及数学）之美。光遵循如此简单的数学几何规律，而引发折射现象的物理效应却相当复杂，这实在令人惊叹。恭喜，你现在能算出折射光线的方向了。在实际实现这个公式时，有几处细节需要注意。首先，某些情况下光线会从外侧打到表面，比如光线进入一片水域时。但当光线离开那片水域时，法线会指向水面的另一侧。这种情形下，要让公式成立，我们得把法线方向反过来。判断入射光线是从外侧还是内侧打到表面，只需检查法线与入射光线方向点积的符号（如图 12 所示）。要记住 \(\cos(\theta_1\) 的结果也必须为正。如果它为负（即入射光线从外侧打到表面），就需要把点积的符号反过来。最后要记住，\(\eta_1\) 与 \(\eta_2\) 分别是第一、第二种介质的折射率。如果光线离开第二种介质进入第一种，就需要把两种介质折射率的顺序对调，再算 \(\eta\)。


Vec3f refract(const Vec3f &I, const Vec3f &N, const float &ior)
{
    Vec3f Nrefr = N;
    float NdotI = Nrefr.dotProduct(I);
    float etai = 1, etat = ior; // etai 是光线在进入第二种介质之前所处介质的折射率                                              
    if (NdotI < 0) {
        // 我们在表面外侧，希望 cos(theta) 为正                         
        NdotI = -NdotI;
    }
    else {
        // 我们在表面内侧，cos(theta) 已为正，但需要反转法线方向                                 
        Nrefr = -N;
        // 对调两个折射率             
        std::swap(etai, etat);
    }
    float eta = etai / etat; // n_1 / n_2
    ...
}

在这段代码里，ior 是光线刚打到或即将离开的那个实体对象（玻璃、水等）的材质的折射率。如前所述，空气的折射率接近 1，因此在 CG 中我们一般忽略它，把空气当作真空处理。

还有一个细节需要考虑。当入射角大于某个称为临界角的值时，入射到表面上的光会 100% 被反射。换句话说，入射角大于临界角时，完全没有折射。不过这只会发生在光线从一种介质进入折射率更低的另一种介质时，比如水—空气、钻石—水或玻璃—水的情形。这个现象叫作全内反射。

如果需要，可以算出这个角度；不过在计算折射方向时，有个更简单的办法判断它何时发生：当 \(c_2\) 这一项的平方根号内的值为负时（此时平方根是负数，也就是虚数），就发生了全内反射：


Vec3f refract(const Vec3f &I, const Vec3f &N, const float &ior)
{
    Vec3f Nrefr = N;
    ...
    float k = 1 - eta * eta * (1 - cosi * cosi);
    if (k < 0)
        // 全内反射。这种情况下没有折射                                  
        return 0;
    else
        eta * I + (eta * NdotI - sqrtf(k)) * Nrefr ;
}

还有另一种办法可以算出或判断入射光何时被反射而不是被折射：算出折射角的正弦。如果 \(\sin\theta_2\) 大于 1，就是全内反射的情形。注意这个值可以用斯涅尔定律轻松算出：


float sint = etai / etat * sqrtf(std::max(0.f, 1 - cosi * cosi));

最后是折射函数的完整实现：


Vec3f refract(const Vec3f &I, const Vec3f &N, const float &ior)
{
    float cosi = clamp(-1, 1, dotProduct(I, N));
    float etai = 1, etat = ior;
    Vec3f n = N;
    if (cosi < 0) { cosi = -cosi; } else { std::swap(etai, etat); n= -N; }
    float eta = etai / etat;
    float k = 1 - eta * eta * (1 - cosi * cosi);
    return k < 0 ? 0 : eta * I + (eta * cosi - sqrtf(k)) * n;
}

右边是一张玻璃球的渲染图。与图 9 中真实玻璃球的例子一样，可以看到球体内背景几何体的像被颠倒了。如果你顺着折射光线穿过球体的路径走一遍，就会明白原因。不过这张图的问题在于它并不完全真实。玻璃球以及几乎其他所有透明表面（水、钻石、水晶等）既透射光也反射光，既折射也反射。问题是我们怎么知道它们透射多少光、又反射多少光？这个比例由菲涅尔方程给出，我们接下来就学。

菲涅尔

正如上文所述，玻璃或水这类透明物体既折射也反射。它们反射多少光、透射多少光，取决于入射角。入射角减小时，透射光的量增加。而根据能量守恒原理，反射光的量加上折射光的量必然等于入射光总量，因此可以推出：入射角增大时反射光增加，当角度接近 90 度时可达到 100%。严格来说，玻璃球的边缘是 100% 反射的；而在它的中心处，球面只反射约 6% 的入射光。

反射光与折射光的比例，可以用所谓的菲涅尔方程算出。解释这些方程的来源以及如何推导，远远超出本课愿意提供的讲解深度。光由两列相互垂直的波组成，我们称之为平行偏振光与垂直偏振光。不了解这个细节也不必担心。只需知道：我们要用两个不同的方程（每种波各一个）分别算出这两列波的反射光比例，再取平均作为结果。这两个菲涅尔方程是：

$$ \begin{array}{l} F_{R\parallel} = \left( \dfrac{\eta_2 \cos\theta_1 - \eta_1 \cos \theta_2}{\eta_2 \cos\theta_1 + \eta_1 \cos \theta_2} \right)^2,\\ F_{R\perp} = \left( \dfrac{\eta_1 \cos\theta_2 - \eta_2 \cos \theta_1}{\eta_1 \cos\theta_2 + \eta_2 \cos \theta_1} \right)^2. \end{array} $$

取两者的平均，就得到实际的反射光比例：

$$F_R = \dfrac{1}{2}(F_{R\parallel} + F_{R\perp}).$$

\(\eta_1\)、\(\eta_2\) 是两种介质的折射率，\(\cos\theta_1\) 与 \(\cos\theta_2\) 分别是入射角与折射角。如前所述，由能量守恒，折射光的比例可以直接算作：

$$F_T = 1 - F_R.$$

要记住，如果光从一种介质进入折射率更低的另一种介质，可能会发生全内反射。玻璃或水这类材质就会这样，因此需要把这种情况考虑进去。做法与反射时相同：算出折射角的正弦，也就是 \(\theta_2\)。如果 \(\sin\theta_2\) 大于 1，就是全反射的情形。这种情形下不必计算菲涅尔公式，直接把 \(F_R\) 设为 1 即可。照例，如果你发现入射光线位于折射率较大的物体内部，就需要把两个折射率对调。这同样可以通过检查表面法线与入射光线方向夹角的余弦符号（即 \(\cos\theta_1\) 的符号）来判断。下面是菲涅尔公式的一种实现：


void fresnel(const Vec3f &I, const Vec3f &N, const float &ior, float &kr)
{
    float cosi = clamp(-1, 1, dotProduct(I, N));
    float etai = 1, etat = ior;
    if (cosi > 0) { std::swap(etai, etat); }
    // 用斯涅尔定律计算 sini         
    float sint = etai / etat * sqrtf(std::max(0.f, 1 - cosi * cosi));
    // 全内反射                 
    if (sint >= 1) {
        kr = 1;
    }
    else {
        float cost = sqrtf(std::max(0.f, 1 - sint * sint));
        cosi = fabsf(cosi);
        float Rs = ((etat * cosi) - (etai * cost)) / ((etat * cosi) + (etai * cost));
        float Rp = ((etai * cosi) - (etat * cost)) / ((etai * cosi) + (etat * cost));
        kr = (Rs * Rs + Rp * Rp) / 2;
    }
    // 由能量守恒，透射率由下式给出：                                                
    // kt = 1 - kr;
}

菲涅尔效应在自然界很容易观察到。看本章开头那张有远山和近处卵石的湖面照片，可以看到反射似乎随距离增强。还要注意，远处反射很强，而近处我们透过水看得比远处更清楚。这是菲涅尔造成的。如图 16 所示，入射角随距离增大，而我们已知反射与透射的比例随入射角增大而增大。于是很自然地，望向远处时水面反射的光更多。而如果几乎垂直地俯视水面，比如站在离岸几米处，入射角很小，大部分光被透射，于是我们透过水看得比望向远处时更清楚。你在非常多的物体上都能轻易观察到这个效果：玻璃幕墙的建筑立面、边缘反射更强的玻璃球，等等。

实现

现在把学到的都用上，试着复现那支插在玻璃杯水中的笔的图像。这个练习里，我们只用一个简单圆柱体来建模水体。为保持简单，我们没有建装水的玻璃杯模型，这留作练习。场景用一盏平行光渲染。为简单起见，水体不投射阴影。透明物体的阴影投射会在另一门课里讲。笔用平面着色模型渲染，场景其余部分用平滑着色（顶点法线插值）。首先，把这个体模型声明为既反射又折射的表面。我们还给物体类加了一个 ior 成员变量，用来保存物体的折射率：


TriangleMesh *mesh3 = loadPolyMeshFromFile("./cylinder.geo", Matrix44f::kIdentity);
if (mesh3 != nullptr) {
    mesh3-&gttype = kReflectionAndRefraction;
    mesh3-&gtior = 1.3;
    objects.push_back(std::unique_ptr&ltObject>(mesh3));
}

在 castRay 函数里，我们只给材质 switch 增加了一个分支。如果表面是透明的，我们先按菲涅尔公式算出反射光的比例。注意，作为一个小优化，只有当反射光比例小于 1（即不是全内反射）时，我们才计算透射光。然后算出反射光线与折射光线（第 22、27 行），并沿反射与折射方向各投一条光线，得到反射光和透射光。注意我们又得给光线起点加一点偏移，以避免讲阴影的那几章里已经描述过的痤疮现象。对反射，要把点推到入射光线打到表面的同一侧；对折射，要把点往内侧推（图 17）。

在光线追踪里，我们沿法线方向推光线起点来处理痤疮，这是解决该问题非常朴素的做法。针对这个问题的研究已经有人做过，可以在网上找到。理想的做法是让偏移能自动算出，而不是整个场景固定一个值、或按物体分别固定。

最后，用菲涅尔公式的结果把两者混合起来（第 32 行）。


switch (isect.hitObject-&gttype) {
    case kDiffuse:
    {
        ...
        break;
    }
    case kReflection:
    {
        ...
        break;
    }
    case kReflectionAndRefraction:
    {
        Vec3f refractionColor = 0;
        // 计算菲涅尔     
        float kr;
        fresnel(dir, hitNormal, isect.hitObject-&gtior, kr);
        bool outside = dir.dotProduct(hitNormal) < 0;
        Vec3f bias = options.bias * hitNormal;
        // 如果不是全内反射的情形，计算折射                                   
        if (kr < 1) {
            Vec3f refractionDirection = refract(dir, hitNormal, isect.hitObject-&gtior).normalize();
            Vec3f refractionRayOrig = outside ? hitPoint - bias : hitPoint + bias;
            refractionColor = castRay(refractionRayOrig, refractionDirection, objects, lights, options, depth + 1);
        }
    
        Vec3f reflectionDirection = reflect(dir, hitNormal).normalize();
        Vec3f reflectionRayOrig = outside ? hitPoint + bias : hitPoint - bias;
        Vec3f reflectionColor = castRay(reflectionRayOrig, reflectionDirection, objects, lights, options, depth + 1);
        
        // 混合两者   
        hitColor += reflectionColor * kr + refractionColor * (1 - kr);
        break;
    }
    default:
        break;
}

注意，我们得到的结果与用商业渲染器（这里是 Mental Ray）渲染同一场景的结果非常相似。两张图的差别来自：参考图里最大深度设为 10，而右图（我们的渲染）里最大深度上限设为 4。把上限设为 10，就会得到同样的图像：

关于反射你还应该知道的另一件事：导体与电介质。

这一章已经很长了，我们介绍了着色中的许多基本概念。也就是说，我们讲了：

  • 反射，

  • 折射，

  • 菲涅尔，

  • 以及光线、场景与偏移——后者是用光线追踪计算或模拟这些效果带来的副产品。

关于这些不同的效果还有很多可说的。比如反射是一种波长效应：不同波长的光在同一材质中的折射方式并不相同。这些细节我们以后再学。不过在结束本章之前，你也许想知道一件事：金属物体也反射光。事实上，在计算机图形学中，我们喜欢把材质分成两大类：电介质材质与导体材质。你可能已经猜到，导体就是金属。金属也反射光，而且在掠射角下反射得更多。不过用来表示金属反射光比例的菲涅尔方程，与我们本课学过的、用来模拟电介质材质菲涅尔效应的那个不同。电介质本质上是不导电的材料，也就是电绝缘体。这一类里包括玻璃、塑料以及水——纯水确实是电绝缘体。记住导体和电介质这两个名字，它们在着色和计算机图形学里用得非常多。
