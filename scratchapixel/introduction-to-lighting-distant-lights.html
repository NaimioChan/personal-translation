平行光源

阅读时间：9 分钟。

平行光，又名太阳

模拟平行光非常简单，所以这一章很短。事实上，它是最简单、最基本的一种光源（大概也是你为了让程序跑起来最先实现的那类光源）。

但什么是平行光？说实话，自然界里并不存在真正的平行光。它是一种发出光线彼此平行的光源。在真实世界里，大多数光源（如果不是全部的话，但既然我没在宇宙的其他地方旅行过，我不敢百分之百肯定）都有某种物理形状，光从该形状发出，因此光一般是沿径向发射的。比如我们的太阳，它是一团火球。嗯，在古希腊神话里人们是这么看的。对现代科学家来说，它大概比这复杂。

但关键在于，太阳可以被建模为一个向所有方向发光的球。问题在于我们的星球——地球——离太阳太远，以至于从太阳打到地球上的光被限制在一个非常窄的方向锥内。窄到在宇宙尺度上，在那个锥内传播的光束可以被认为（几乎）彼此平行。这基本上就是计算机图形学世界里的平行光想要达成的事：模拟太阳光对地球的影响。再说一次，把太阳当作球形光源来模拟可能更准确（本课后面会讨论）。不过，在面光源因算力提升而普及之前，我们并不费这个劲。既然光线被认为是彼此平行的，我们需要的只是一个方向。继续用太阳作类比：你可以把它想成你用一根手指指向太阳、告诉别人它在天空哪个位置时，那根手指所指的方向。

注意有些建筑软件提出用物理正确的方式算出太阳在天空中的位置。你输入年、月、日、时，系统就以宇宙级的精度算出太阳在天空中的位置。它能做到这一点，是因为根据日期与一天中的时刻预测太阳相对地球位置的公式，已经被人类知晓好几个世纪了。我们至今还预测不了的，是那天的天气）。

所以你看，模拟一盏平行光所需的全部东西，就是一个方向。


class SunLight : class Light {
public:
	Vec3&ltfloat> direction_{0,1,0}; // 天顶
	Vec3&ltfloat> light_color_{1};
}

平行光的实现

从实现角度看，你要做的就是沿光源方向射出一条阴影光线，判断你正在着色的那个点是否处在沿该方向上某个物体的阴影里。如果你愿意，可以把这条光线射到无穷远，这里的无穷远是在浮点值的语境下说的，也就是 float（或 double，如果你决定用 double 的话）能容纳的最大数。


// 原点、方向、tmin 与 tmax
Ray shadow_ray(x, light-&gtdirection_, 0, std::numeric_limits&ltfloat>::max());
if (!occlusion(scene, shadow_ray)) {
    L += albedo / M_PI * light-&gtlight_color_ * std::max(0.f, std::cosf(N, light-&gtdirection_));
}

如上面代码所示，我们向场景中投射一条阴影光线。如果没有遮挡（occlusion 返回 false），我们就可以把这盏光源对着色点整体亮度的贡献累加进去。如果你对光照累加与光照循环的概念不熟，请回看本课上一章。就这样！这种光源真的就只有这些内容。

美术层面的考量

从美术或风格的角度看，用不用太阳光是有区别的。

  • 会聚的阴影与发散的阴影：确实，从接下来两张图可以看到，因为使用平行光时光线是彼此平行的，这类光源投出的阴影形状，与球形光源（不管是点光源还是聚光灯）产生的阴影形状非常不同。人类非常习惯于看到太阳投下的阴影，所以如果你想做一张表现户外阳光场景的图，建议用平行光。与用聚光灯之类去模拟这个效果相比，它生成的阴影形状会让你的大脑觉得更熟悉。Pixar、DreamWorks 这样的工作室在为场景打光、以及为以最可信的方式模拟某类效果而选择正确光源类型时，非常注意这类细节（即使最终画面的观感仍然是风格化的）。从视觉角度看，阴影对组织画面贡献很大，并且带有特殊的含义，可以从情绪层面强调故事里正在发生的事。它们构成了电影与叙事中所使用的一套视觉语法。

  • 没有衰减：并不是说太阳不受平方反比定律的约束、逃过了所有物理定律。更准确地说，是地球的大小相对于太阳的距离，使得光在人类尺度距离上的衰减可以忽略。换句话说，如果你测量你站在地面上接收到的阳光，与沿太阳方向 10 米甚至 1000 米外接收到的光量相比，除非你有极其精密的仪器，否则光能的差别大概是测不出来的。所以，至少在做电影和电子游戏的图像时，这件事我们可以忽略。这对画面的观感有深远影响，因为这意味着与点光源、聚光灯等其他光源类型相比，太阳光没有任何衰减。

  • 色温：每盏光源都有色温，但我们一般不会按温度来设置光源颜色。美术师或使用 3D 软件的人只会调光源颜色，以得到想要的效果。不过，如果你想模拟太阳光，应该记得太阳光的温度大约是 5900 开尔文。光温与颜色如何关联，可以看讲黑体的那门课。从美术角度看，这意味着太阳光带一点偏红的色调。下面几张图展示了纯白光色（左）与按温度推导出的太阳光色（中）的差别。当然，真实世界里的太阳光感觉没那么红，但那也是因为天空的颜色（偏蓝）补偿了那种橙红色，使它看起来更中性。这也是户外场景里阴影会显得偏蓝的原因，在下面那张《玩具总动员》的图里就能看到。他们用灯光复现了这个效果。

Pixar 大量运用这类视觉线索，多年来发表过好几篇文章，解释他们如何用灯光在电影里传达各种情绪。我希望哪天有时间把这些老文章重新翻出来，让它们再见天日。它们讲的规则是永恒的，只可惜这些文档已经被埋进互联网档案馆里了（图片由 Pixar 提供，出自 1995 年上映的《玩具总动员》）。

平行光在现代渲染中的意义

另外还有一个旁注：你可能会想，随着基于物理的渲染器与超级计算机的出现，使用平行光还有意义吗？为什么不干脆用非常小的球形或圆盘形面光源？这是个好问题。事实上，许多渲染器（比如 Arnold）在平行光上提供了一个参数，让你可以把阴影光线分布在一个很小的角度范围内（角度值可以自己设，方便你试不同的值）。确实，严格说来太阳不是三维空间中的一个点。从地球这个星球的角度看，它仍然被感知为一个很小的圆盘，其张角 \(\theta\) 约为 0.5 度。你只要用地球与太阳之间的距离和太阳的直径，就能很容易地算出这个角度。所以，与其摆一盏半径极大、离场景极远（从而从场景视角看起来很小、投射的光线基本平行）的球形或圆盘形面光源——这可行，但有可能引入与浮点精度相关的错误——更好的做法一般是把阴影光线分布在一个约略大于 0.5 度的小方向锥内。这能帮你打破典型平行光产生的极锐利阴影。观察户外场景，你会发现所有阴影的边缘都带点柔和。

我们不会在这里给出锥角功能的实现，但 球形面光源：使用锥体采样 这一章提供了实现它所需的解释与源代码。你要做的只是在一个开口角比如 0.5 度的方向锥内采样，而这么做的全部信息都在那一章里。

话虽如此，我们这组讲平行光的章节就到此结束了。是时候进入面光源的世界了。
