标准坐标系

谈到顶点变换管线时，用来描述顶点被变换到哪些坐标系的术语存在一些差异，尤其在两个最常见的渲染 API——OpenGL 与 RenderMan 接口——之间（本课使用的坐标系定义遵循这一接口的定义）。如果你熟悉 OpenGL 渲染管线，也许会以为我们在上一章里有些术语用错了。首先必须记住：本课讲的不是 OpenGL，也不是基于 z 缓冲的渲染器所用的经典顶点变换管线，而是光线追踪器如何生成主光线（相机光线）。生成这些光线的过程，与基于光栅化的渲染器把点投影到图像平面上的过程正好相反。其次要注意，用来定义点被变换到其中的空间的那些坐标系，其含义并不取决于我们用光线追踪器还是光栅化器，更多是一个约定问题。一般来说，世界空间、相机空间、物体空间与光栅空间在所有渲染 API 中定义相同，但裁剪坐标（这个概念更偏 OpenGL 专有）、NDC 与屏幕空间的定义则可能因系统而异。为了更清楚地帮你区分至少两件事——本课为构造主光线所描述的体系，与 OpenGL 顶点变换管线（我们在上一课描述过）——我们将在本章里把两者再简述一遍并做比较。希望这个练习能消除阅读本课时可能在图形 API 专家脑中留下的任何困惑。

在光线追踪中，我们从一个像素位置出发，把它变换成图像平面上的一个点，再据此构造光线方向。这个过程涉及把原本以像素坐标（即光栅空间）表示的「点坐标」变换到 NDC 空间，再变换到屏幕空间（我们已在前面几章描述过这个过程）。光栅到 NDC 的转换把原始像素坐标重映射到 [0,1] 范围。NDC 到屏幕空间的转换把值从 [0,1] 重映射到 [-1,1]（图像为正方形时），若图像宽度大于高度，则 x 轴上为 [-宽高比, 宽高比]、y 轴上为 [-1,1]。这些坐标随后按相机视场角的正切除以二进行缩放。总结一下：我们从光栅走到 NDC，再走到屏幕空间。

光栅化的过程不同。它的目标是取 3D 空间中的一个点，把它投影到图像平面上，再把得到的坐标转换成像素坐标。我们从一个 3D 空间中的点出发，需要设法把它投影到图像上，这一步一般使用透视（或正交）投影矩阵。首先，点从 3D 的世界空间转换到相机空间。此时点的坐标是相对相机的坐标系定义的。进入相机空间后，点再用例如透视投影矩阵投影到图像平面上。在 OpenGL 顶点变换管线的这个阶段，点据说带有裁剪坐标。这些点还没有除以其 z 坐标，但 OpenGL 已经可以测试它们是否可见。如果它们通过了这个可见性或裁剪测试，就再从齐次坐标转换成笛卡尔坐标（这个过程叫作 z 除或透视除法）。这些点据说带有归一化设备坐标，或说位于 NDC 空间。注意在这个空间里，OpenGL 中点的坐标处于 [-1,1] 范围。而在 RenderMan 接口中，NDC 空间定义的是坐标处于 [0,1] 范围的点。最后，NDC 空间中的点被转换成光栅坐标或窗口坐标，也就是点最终的像素坐标。

我们在下表中总结了这两套体系的各个步骤及其对应的坐标系：

由像素坐标计算光线方向OpenGL/Metal/Vulkan/DirectX（顶点变换管线）
像素的位置（像素坐标）。光栅空间。点的坐标定义在世界空间中。
把点从像素坐标或光栅空间变换到 NDC 空间。点坐标被重映射到 [0:1] 范围。把点从世界空间变换到相机空间。
把点的坐标从 NDC 重映射到屏幕空间。点在屏幕空间中的坐标沿 x 轴在 [-宽高比, 宽高比] 之间变化，沿 y 轴在 [-1, 1] 之间变化。用投影矩阵把点投影到近裁剪面（图像平面）上。

坐标空间名称说明
物体空间3D 模型在最终被变换之前所处的空间。你在 3D 建模应用里建一个物体时，模型一般以原点为中心。不过，你可能需要把这个物体（包括旋转、平移与缩放）移动到渲染场景中的另一个位置。物体空间指的就是物体被变换到场景中这个最终位置之前的位置。
世界空间顶点坐标相对世界笛卡尔坐标系表示。这是物体被变换到场景中最终位置之后的顶点坐标。
相机空间物体是世界空间中的顶点，经变换后相对相机的笛卡尔坐标系表示（相机处于默认位置时，世界与相机的笛卡尔坐标系是对齐的）。
屏幕空间在 RenderMan 规范中，这个空间指相机图像平面上某点的坐标。在 OpenGL 中，它指以像素坐标表示的投影点位置（该坐标系的原点是画面的左上角）。
NDC 空间归一化设备坐标（Normalized Device Coordinates）——在 RenderMan 规范中，以这个空间表示的点，其 x 与 y 坐标处于 [0, 1] 范围内（与光栅空间相同，只不过不是 x 轴上 [0:宽度]、y 轴上 [0:高度]，而是两个坐标都从 0 到 1）。在 OpenGL 中，以这些坐标表示的点，其 x 与 y 坐标沿 x 轴处于 [-宽高比, 宽高比] 范围，沿 y 轴处于 [-1, 1] 范围（假设图像的宽度大于其高度）。
光栅空间在 RenderMan 规范中，它指以像素坐标表示的某点的位置（等同于 OpenGL 中的屏幕空间或窗口坐标）。在这个空间里，1 个单位对应 1 个像素（参见 NDC 空间）。
裁剪坐标投影点在 z 除之前的坐标（仅 OpenGL）。
窗口坐标以像素坐标表示的投影点坐标（仅 OpenGL）。类似于 RenderMan 中的光栅空间。

总之，我们已经说明所描述的这两套体系做的并不是同一件事，不应混淆。前面几章描述的体系，是把以像素坐标定义的点转换成图像平面上的点，用来计算光线方向。第二套体系，即 OpenGL 顶点变换管线，是把 3D 场景中的点投影到图像平面上，再把这些投影点转换成像素坐标。

一点提醒

屏幕空间、NDC 空间这类有标准名称的坐标系，在 OpenGL 顶点变换管线与 RenderMan 接口中都会出现，但在各自的渲染 API 里用途与定义都不同。如果你熟悉 OpenGL 渲染管线，我们建议你读下一章，那里我们解释这两种渲染接口之间的差异。
