着色的数学

阅读时间：29 分钟。

在开始学习着色之前，你首先至少得熟悉几个基础数学概念（主要是几何与微积分）。没有这些工具，着色就无从谈起。本章会以更直观而非更形式化的方式来介绍这些概念。我们希望你对这些概念熟悉到能继续读后面讲着色的课程。我们建议你把本章当作自学微积分和几何的起点。

球坐标

我们已经知道，点与向量（在三维空间中）可以用三个坐标来定义，这些坐标称为笛卡尔坐标（因为它们是相对一个笛卡尔坐标系定义的）。你也可以用球坐标来定义点和向量。在这个坐标系里，点或方向的位置以及向量的长度由两个角度（记作 \(\theta\) 和 \(\phi\)，即希腊字母 theta 和 phi）和一个径向距离（\(r\)）确定。角 \(\theta\) 称为极角，从某个固定的天顶方向量起。用来量这个极角的天顶方向是 y 轴（见图 1）。

注意，有些资料改用 z 轴作为笛卡尔坐标系的竖直轴。不过这种做法越来越少见，当然与着色相关的论文例外——按传统，那里的 z 轴一直当作上向量用（关于球坐标与笛卡尔坐标的互相转换，见下面的说明）。

球坐标有什么用？主要在于它能把向量的定义从三个笛卡尔坐标减到两个坐标（\(\theta\) 和 \(\phi\)）。此外，计算机图形学里向量常常用来定义球面上的位置，这种情况下角度比笛卡尔坐标更好用。例如，你需要让一个向量沿水平或竖直方向旋转时，只要把其中一个角加一个小步长即可。注意 \(\theta\) 的变化范围是 \(0\) 到 \(\pi\) 弧度（半圈），而 \(\phi\) 的变化范围是 \(0\) 到 \(2\pi\) 弧度（一整圈）。


for (int i = 0; i < numSteps; ++i) {
    float theta = i / float(numSteps - 1) * M_PI; 
        for (int j = 0; j < numSteps; ++j) { 
        float phi = j / float(numSteps - 1 ) * 2 * M_PI; 
        // 用角度 theta 和 phi（单位为弧度）做点什么……
    }
}

在着色的语境下，如你所料，球面和半球起着重要作用，用球坐标会很方便。例如，BRDF 是入射光方向（L）与出射观察方向（V）的函数。我们可以用球坐标而不是笛卡尔坐标来定义这些向量，从而把 BRDF 从六个变量（两次三个坐标）的函数缩减为只有四个变量（两次两个角度）的函数。从球坐标转到笛卡尔坐标可以用下面的公式（假定 y 轴是上向量。如果你用的坐标系是 z 轴为上向量，着色里经常如此，那就把下面公式里的 y 和 z 坐标对调）：

$$ \begin{array}{l} x = r\:\sin(\theta)\:\cos(\phi)\\ y = r\:\cos(\theta)\\ z = r\:\sin(\theta)\:\sin(\phi) \end{array} $$

同样，用下面的公式可以轻松地从笛卡尔坐标转到球坐标（这里同样别忘了：如果你用的坐标系以 z 轴为上向量，就把 y 和 z 坐标对调）：

$$ \begin{array}{l} r = \sqrt{x^2+y^2+z^2}\\\ \theta = \cos^{-1}( \dfrac{y}{r} )\\\ \phi= \tan^{-1}( \dfrac{z}{x} ) \end{array} $$

关于球坐标的更多内容，见几何这门课。不过要注意，本课用的是 y 轴作为上向量，不是 z 轴。这些公式可以用下面的 C++ 代码实现。记住，如果向量已归一化，它的长度为 1，那么 \(r\) 就等于 1。这种情况下当然不需要用 r 去除 z。还要注意，用三角函数由 x、y、z 反算时，得到的向量是归一化的。最后，向量归一化之后，向量 y 坐标的值就是角 \(\theta\) 的余弦：


// 假定所有角度单位为弧度
float theta = deg2rad(theta_deg); 
float phi = deg2rad(phi_deg);
float x = sin(theta) * cos(phi);
float y = cos(theta); 
// 若 z 轴为上，则对调 y 和 z
float z = sin(theta) * sin(phi);
// 此处 r = 1，因为 xyz 是由三角函数算出的
float r = sqrtf(x * x + y * y + z * z);
float theta = acos(y / r);
// 若 z 轴为上，则用 z
float phi = atan2(z, x); 
// 若 z 轴为上，则用 y 替代 z
float costTeta = y;

我们还可以用一个简单技巧由笛卡尔坐标算出 theta。因为 \(r = \sqrt{x^2 + y^2 + z^2}\)，我们可以写成 \(r^2 = x^2 + y^2 + z^2\)。整理各项得到 \(y^2 = r^2 - x^2 - z^2\)；y 是角 theta 的余弦，所以 \(\cos(\theta) = \sqrt{r^2 - x^2 - z^2}\)，而向量归一化时 \(r^2\) 等于 1，于是最终得到 \(\cos(\theta) = \sqrt{1 - x^2 - z^2}\)。

微分与积分

除了三角学和几何，着色领域另外两件最重要的工具是积分与微分。它们属于一门叫作微积分的数学：「微积分是研究变化的数学，正如几何是研究形状的数学、代数是研究运算及其在解方程中应用的数学」。只要了解几个基本点，这两个概念就极其简单（而且它们之间的联系我们马上会讲）。

先从微分说起。在计算机图形学里，我们常常要处理函数。度量到达表面上某一点的光量可以看成一个函数，可以写成 \({Light_{incoming}} = f(x)\)，其中 \(x\) 表示表面上的一个点。这个式子告诉我们：从物体表面到达某一点的光量，是该点在三维空间中位置的函数（图 3）。还有更简单的例子，比如运动小球的位置是时间的函数，可以写成 \(p = f(t)\)。很多时候我们想知道这个函数在 \(x\) 附近如何变化，记作 \(f(x + \Delta x)\)。在数学记号中，符号 \(\Delta x\)（希腊大写字母 delta）一般表示两点之间极小的差（这两个点是函数自变量的输入值）。我们在图 4 中说明了这个概念。如果把函数 \(f(x)\) 在两个位置 \(x\) 和 \(x + \Delta x\) 上的结果画出来，就可以在这两点之间画一条割线。当 \(\Delta x\) 趋近于零时，我们可以看到（图 4）穿过这两点的直线越来越精确地逼近 \(x\) 处的切线。切线就是割线在 \(\Delta x\) 趋近于零时的极限。这条直线的斜率等于函数 \(f\) 在 \(x\) 处的导数，可以按 \(dy\)（即 \(f(x + \Delta x)\) 与 \(f(x)\) 之差）除以 \(\Delta x\) 来算：

$$m = { \dfrac{ f(x + \Delta x) - f(x) } { (x + \Delta x) - x } } = { \dfrac{f(x + \Delta x) - f(x)} {\Delta x} }$$

函数之差除以点之差，称为差商。值 \(m\)——我们现在知道它是函数在 \(x\) 处的斜率——也叫变化率。形式上，函数 f 在 x 处的导数是差商在 \(\Delta x\) 趋近于零时的极限：

$$f'(x) = \lim_{x \to 0} { \dfrac{f(x + \Delta x) - f(x) } {\Delta x}}$$

如果这个极限存在，我们就说 \(f\) 在 \(x\) 处可微。表示函数导数可以用好几种记号。最常见（也最现代）的做法是在函数名上加一撇，如 \(f'(x)\)。这称为拉格朗日记号。你也可以用莱布尼茨记号，把导数记作 \({{d\over dx}f(x)}\) 或 \({{{df}\over dx}(x)}\)（其中 \({d \over dx}\) 称为导数算子，应当读作「函数 f 对 x 的导数」）。这些是计算机图形学里最常用的记号。

相当多的函数都有现成规则可以用来求导。例如常数的导数为零，形如 \(f(x) = x^n\)（其中 \(n\) 为任意有理指数）的函数导数为 \(f'(x) = n x ^{n-1}\)。这称为幂法则，在计算机图形学里非常常用。不过，用解析方法求函数导数并不总是可行。好在遇到这种情况时，函数的极限一般可以用数值近似高效地算出来。例如，你可以取两个彼此接近的 \(x\) 值各算一次函数，再用两个结果之差近似这个极限。计算机图形学里很多函数都是离散化的。要算离散化函数在任意 \(x\) 处的微分（假定函数是一维的），需要取 x 处的采样与 x + 1 处函数值之差（这里的 x 是离散采样位置）。得到的数学表达式称为有限差分。注意，如果把有限差分的结果除以 \(\Delta x\)，就得到差商。如果有函数 \(f\)，那么当 \(F' = f\) 时，\(F\) 就是 \(f\) 的原函数。举个具体例子：如果你有函数 \(x^2 + 1\)，那么这个函数的导数（用幂法则）是 \(2x\)（记住常数的导数为零，因为它不随 x 变化）。而 \(2x\) 的原函数是 \(x^2\)。不过常数在求导时会消失，所以最一般的情况下，任何函数的原函数都应当包含一个常数。正确的答案（至少是最一般的答案）是：\(x^2 + c\)，其中 \(c\) 表示一个常数。总结一下，如果：

  • \(f\) 是 \(F\) 的导数，那么，

  • \(F\) 是 \(f\) 的原函数

如果用一个函数 \(p = f(t)\) 给出运动物体随时间变化的位置（或距离），那么这个函数的导数 \({dp \over dt}\) 给出速度（位置随时间的变化），而速度的原函数给出位置随时间的变化（即原函数 \(p = f(t)\)）。记住，速度乘以时间得到位置。我们在图 6 中说明了这个想法：上图是位置随时间变化的函数（\(F\)），下图是这个函数的速度（\(F'\) 或 \(f\)）。我们选的函数（\(2x^2\)）使得它的导数（速度）可以用幂法则轻松算出（\(4x\)）。注意，由于这个例子里速度（\(4x\)）是线性函数（一次多项式函数），图像是一条直线。记住这个例子，讲积分时我们还会用到。

现在我们来看看积分。积分和原函数其实是一回事。因为直接说「某函数的原函数」有时不太方便，我们改用某种记号。我们前面一直在用的函数 \(2x\)，它的原函数可以按下面的约定来写：

$$\int 2x dx = x^2 + c$$

上面这个表达式称为 2x 的不定积分，也就是 2x 的原函数的另一种说法。你马上就会明白我们为什么在这里用「不定」这个词。目前最需要记住的是：这个拉长的 S 符号表示积分，而积分不是别的，就是函数的原函数（记住，导数给出的是任意一点处切线的斜率）。

就不定积分而言，给定函数 \(f\) 的积分、函数 \(F\) 的导数，以及 \(F\)，是同一回事：

\(F = \int f(x)dx\)。

这称为微积分第一基本定理。

回到我们那个例子：函数 \(F(t)\) 给出物体随时间变化的距离。现在设想我们需要用速度（记住，速度是 \(F(t)\) 的导数）算出时刻 \(a\) 与时刻 \(b\) 之间的位置差。举例来说，取 \(a\) 等于零、\(b\) 等于五秒。换句话说，我们想知道物体五秒后走了多远。显然，用原函数 \(F(t)\) 来算这个值很容易，只需写成：

$$\begin{array}{l} d &=& F(b) - F(a) = F(5) - F(0) = 2*5^2-20^2=50\end{array}$$

但这里假设我们只有速度（导数），要据此算出物体在五秒内走过的距离。既然速度乘以时间得到距离，我们可以假定：取时刻 \(t = 1\) 的速度，那么到该时刻为止物体走过的距离就等于时刻 \(t =1 \) 的速度乘以 1（速度乘时间）。接着要算物体从时刻 \(t=1\) 到时刻 \(t = 2\) 走过的距离。这个距离同样可以用物体在时刻 \(t=2\) 的速度乘以 1 来估计，这个 1 就是物体从 \(t=1\) 走到 \(t= 2\) 所花的时间。在数学记号里，我们一般把这个时间步长记作 \(dt\)。如果对剩下的三秒重复这个过程（直到抵达 \(t = 5\)），那么每个时间片段都有一个值，表示物体从时刻 \(t\) 到时刻 \(t + dt\) 走过的距离。把这五个时间步长内物体走过的距离加起来，就得到物体从时刻 \(t=0\) 到时刻 \(t = 5\) 总共走过距离的一个「近似值」（为什么说是近似，我们马上解释）（见图 7）。若用 \(2x^2\) 的导数即 \(4x\) 来做，得到：

$$ \begin{array}{l} d &=& f(1) * dt + f(2) * dt + f(3) * dt + f(4) * dt + f(5) * dt\\ &=& v(1) * 1 + v(2) * 1 + v(3) * 1 + v(4) * 1 + v(5) * 1\\ &=& 4*1*1 + 4*2*1 + 4*3*1 + 4*4*1 + 4*5*1 = 60 \end{array} $$

如你所见，我们用原函数 \(^2\) 算出的值与用导数 \(4x\) 算出的值并不相同。前面说过，用导数的那个方法得到的是近似值，我们很快就会解释原因，也会说明如何减小误差。

小结一下目前学到的内容。我们学到：要计算某个原函数 \(F(x)\) 在由上下限 \(a\)、\(b\) 确定的区间上的变化量 \(X\)，可以用下面的公式：

$$X = F(b) - F(a)$$

我们还学会了如何用 \(f(x)\)（即 \(F(x)\) 的导数）来计算 \(X\) 的近似值。做法是在 \(a\) 与 \(b\) 之间按等间隔 \(dx\) 对 \(f(x)\) 求值，把这些值乘以 \(dx\)，再把结果加总：

$$X_{approx} = f(x_0) * dx + f(x_0 + dx) * dx + f(x1 + dx) * dt + ... + f(x_{n-1} + dt) * dt$$

这个求和可以用下面的数学约定写成更紧凑的形式：

$$X_{approx} = \sum_{n=1}^N f(x) dx$$

其中符号 \(\sum\) 表示「求和」（希腊大写字母 sigma）。在数学里，这种写法称为黎曼和（以德国数学家 Bernhard Riemann 命名）。注意在黎曼和中：

$$dx = {(b - a) \over N}$$

其中 N 同样是在计算 \(X\) 的近似值时所用的子区间数量。在黎曼和中，\(dx\) 通常是等间隔的，但不必如此。

现在设想我们有一个类似图 6 下图那样的速度函数。在这张图上，由于我们已经算出物体在一个时间步长 \(dt\) 内走过的距离为 \(v(t)\) 乘以 \(dt\)，可以把这个距离在图上表示成一个小矩形（有时也叫一个分块），这个矩形的宽和高分别是 \(dt\) 和 \(v(t)\)（图 8）。既然要计算物体从 t=0 到 t=5 总共走过距离的近似值，我们把物体在从 t=0 到 t=5 等间隔取得的各个小时间步长 \(dt\) 内走过的距离加起来，而其中每一个距离都能在图上表示成一个矩形，那么算出的总距离也可以看作这些矩形面积之和，这里矩形面积按 \(v(t)\) 乘以 \(dt\) 计算。我们前面用的公式：

$$\sum_{n=1}^N f(x) dx,$$

于是就可以看作速度曲线下方矩形面积之和。而这些矩形面积之和，也可以看作曲线从 \(a\) 到 \(b\) 下方面积的一个「近似」。你也能明白为什么这个矩形面积之和只是曲线下真实面积的一个近似。图 9 中我们把矩形位于曲线上方的那部分标成了红色，以便更清楚地显示它们如何高估了与其重叠的那段曲线下的真实面积。这就解释了为什么用导数法求出的 d 的近似值（60）大于用原函数法算出的精确值（50）。前面我们还说过要演示如何减小这个误差。如果你还没想出来怎么做，试着想象取更小的 \(dt\) 步长会怎样。这样用来近似曲线下面积的矩形数量会增加，但正如你从图 10 中应该能看到的，矩形落在曲线范围之外的那部分也变小了（图 9 与图 10 两种近似的误差差别在图 10 中标成了红色），因此我们得到更精确的近似（但它仍然是近似，只是更好一些）。如果我们能不断减小 \(dx\)，误差当然会越来越小。现在的问题是：当 \(dx\) 趋近于零时，这个近似会变成什么？如果你还没猜到：当 \(dx\) 趋近于零时，矩形数量变得无穷多，（理论上）我们就得到了点 \(a\) 与点 \(b\) 之间曲线下面积的精确值。而这本质上正是积分。换句话说：

$$X = \lim_{dx \to 0} \sum_{n=1}^N f(x)dx= \int_a^b f(x)dx$$。

当 \(dx\) 趋近于零时，曲线下矩形面积之和等于函数 f(x) 的定积分（这里说「定」是因为积分是在 \(a\) 与 \(b\) 之间计算的），它同样类似于该函数所定义曲线在点 \(a\) 与点 \(b\) 之间的面积（图 11）。换句话说，你可以把积分看成不是别的，就是一个求和：\(a\) 与 \(b\) 之间任意一点处的高度，乘以矩形的底 \(dx\) 之和。这就是定积分。在计算机程序里，我们通常给 \(dx\) 取一个很小的值，如前所述，值越小误差越小（但计算积分也越耗时）。例如下面这个 C++ 程序，你可以用它分别以原函数（\(2x^2\)）和用积分法以导数函数（\(4x\)）来计算两个给定时刻之间距离的变化：


#include &ltcstdlib> 
#include &ltcstdio> 
 
float F(float x) { return 2 * x * x; } 
float f(float x) { return 4 * x; } 
 
int main(int argc, char **argv) 
{ 
	float a = atof(argv[1]); 
	float b = atof(argv[2]); 
	int N = atoi(argv[3]); 
	float exact = F(b) - F(a); 
 
	// 用黎曼和计算近似值 
	float dt = (b - a) / N, time = dt, sum = 0; 
	for (int i = 1; i <= N; ++i) { 
		float delta_d = f(time) * dt; 
		sum += delta_d; 
		time += dt; 
	} 
	printf("Result, exact %f, approximation %f, diff %f\n", exact, sum, sum - exact); 
 
	return 0; 
}

可以用下面的命令编译并运行这个程序：


c++ -o derivative derivative.cpp -O3 
./derivative 0 5 100

前两个参数是积分的边界（积分区间 [a,b]），第三个参数是黎曼和里用来求这个积分的矩形数量。如果你多运行几次，就会看到随着分块数量增加，误差在减小。用数学形式表达，本例中程序参数对应的值会是下面这些式子：

$$\int_0^5 4x dx \approx \sum_{n=1}^N 4x dx,$$

其中：

$$0 \leq x \leq 5 \rightarrow \sum_{n=1}^{N=100} 4 * { (n * (5 - 0)) \over 100 } * {(5 - 0) \over 100}$$

上面这个程序算的就是这个。关于积分，最需要记住的一点是：我们能用积分函数的原函数算出积分的结果。回想一下，我们用下面的公式计算了某个原函数 \(F(x)\) 在区间 \([a,b]\) 上的变化量：\(X = F(b) - F(a)\)。我们用积分形式、借函数导数算同一个值：\(\int_a^b f(x)dx\)，因此可以写出下面的等式：

$$\int_a^b f(x) dx = F(b) - F(a)$$

其中 f(x) 是 F(x) 的导数，F(x) 是 f(x) 的原函数。这是一个极其重要的关系，在微积分里称为微积分第二基本定理。在数学中，表达式 \(F(b) - F(a)\) 通常用下面的记号来定义：

$$\left[ F(x) \right]_a^b \rightarrow F(b) - F(a)$$

举个例子，设想你要用微积分第二基本定理计算 \(4x\) 在区间 \([0,5]\) 上的积分。这种做法通常只有在你容易找到被积函数的原函数时才可行。在这个简单例子里，我们知道 \(4x\) 的原函数是 \(2x^2\)，因此可以写成：

$$\int_{a=0}^{b=5} 4xdx = \left[ 2x^2 \right]_{a=0}^{b=5} = 2 * 5^2 - 2 * 0^2 = 50$$

这门技术在计算机图形学里很常用，因为尤其在着色中，我们不断需要计算积分，特别是涉及三角函数的积分。这些导数（及其逆运算）在网上很容易查到，所以我们不在这里列出。举个例子（后面几章我们会用到余弦函数的积分），设想你要在区间 \([0:\pi]\) 上对余弦函数积分：

$$\int_0^{\pi} cos(x) dx$$

余弦函数的原函数是正弦函数，因此用微积分第二基本定理可以写成：

$$\int_0^{\pi} = \left[ sin(x) \right]_0^{\pi} = sin(\pi) - sin(0) = 0 - 0 = 0$$

这个结果是意料之中的：如果你在范围 \([0,\pi]\) 内画出余弦函数的图像，并把这个积分看作该区间内曲线下的带符号面积，那么如图 12 所示，这个面积为零（区间 \([0,\pi/2]\) 里的「正」面积被区间 \([\pi/2:\pi]\) 里的「负」面积抵消了）。

到目前为止我们只处理了一维定义的函数（\(f(x)\) 只取一个变量 \(x\)），但微分和积分也可以用于二维和三维函数。例如在二维情形，我们可能想对函数 \(x = f(x, y)\) 积分，其中 \(x\) 和 \(y\) 是这个函数的两个变量。画出来时，这样的函数给出一个曲面（图 13）。现在写出这个函数的积分：

$$\int_{ax}^{bx} \int_{ay}^{by} f(x,y)dxdy$$

和一维情形类似，我们需要把这个曲面限制在沿 x 轴和沿 y 轴的一些区间内，这些区间定义了我们所说的积分域（进行积分时 x 和 y 的取值范围）。同样和一维情形类似，我们会把曲面「划分」成许多小分块，但由于处理的是曲面而不是曲线，这些分块定义在 xy 平面上，尺寸分别是 \(dx\) 和 \(dy\)。函数 \(f(z,y)\) 返回一个高度 \(z\)，它乘以 \(dx\) 和 \(dy\) 就得到曲面下方一个细长立方体的体积。把所有这些立方体的体积加起来，就得到曲面下体积的一个近似（如图 13 所示）。一维和二维情形下的黎曼和道理相同。

$$V_{approx} = \sum_{i=1}^M \sum_{j=1}^N f(x_i, y_j)dA_{ij}$$

解释二维积分时最常用的例子，是计算一个水箱里水的体积：我们唯一知道的是水面相对于箱底的高度（z），它是 xy 平面上位置的函数（我们假定水面不平，否则当然就没多大意思了）（在计算机图形学里，你可以把它叫作高度场）。这就是图 13 所展示的情形。

总之，一维函数 \(f(x)\) 的积分可以看作曲线下的面积，而二维函数 \(f(x,y)\) 的积分可以理解为曲面下的体积。下面顺带谈谈三维的情形。

我们已经反复说过很多次：一维函数在给定区间（积分域）上的积分，与这个区间内曲线下的面积「类似」。说「计算积分就等于计算曲线下面积」的问题在于：别把这种解释当成积分唯一且字面上的解释。实际上，你应当始终结合积分所用问题的语境来理解积分的含义。例如，在讲着色的某门课里我们展示了：光线追踪是一种手段，可以用它计算某个辐射度量——辐射亮度——在一个像素面积上的值。在这个具体例子里，因为我们处理的是二维函数（辐射亮度是像素表面上某点位置的函数），这个问题可以写成二重积分（一个对 x、一个对 y）。这个积分的结果并不是字面意义上的函数下「体积」（这里的函数就是我们要度量的辐射亮度），而在这个语境下更确切地说是辐射亮度的面密度（换句话说，是每平方单位的辐射亮度，这里的单位指以米、厘米、英尺、英寸等度量的距离）。设想你要测量一个平面上的叶子密度（即每平方米的叶子数）。假定叶子分布不均匀，要测这个平面上任意局部位置的叶子密度，你需要定义一块面积（积分域），并把这块面积划分成等间距的小块（\(dx\) 和 \(dy\)）。假设每个小块的宽和高都是 1（于是每块面积为一平方米）。那么数出任意一块里包含的叶子数量，你就得到了这块的叶子面密度（图 14）。但你也可以把这个度量写成在这块面积上的积分：

$$Leaf_{density} = \int_{A} f(x)dA$$

函数 \(f(x)\) 会返回在面积为 \(A\) 的小块 \(P\) 中、位于 \(x\) 附近的小面积元素 \(dA\) 内任意一点 \(x\) 处的叶子数（比如每平方米多少片叶子）。

既然我们提出积分也可以看作表示一种面密度，理解三维积分就容易多了。就像前面那个例子——只能用返回水面上任意一点高度、且该高度是二维平面内位置函数的函数，来算水箱里有多少水——现在设想你要计算一种非均匀材料的密度（即单位体积的质量）。所谓非均匀，是指密度在物体的不同区域之间有变化。注意密度本身可以定义为三维空间中点的函数，如 \(\rho = f(x,y,z)\)（密度通常用希腊字母 rho 表示，\(\rho\)）。积分域就是我们要测量物体密度的那个区域（图 15 中的立方体）。我们假定密度随空间变化，但可以假定在物体的极小区域内密度是均匀的。于是，与处理曲线和曲面时所用的技术类似，我们会用黎曼和的方式在积分域上对密度函数积分：把需要计算密度的物体体积划分成尺寸为 \(dx\)、\(dy\)、\(dz\) 的小三维分块。在这些位置上求密度值，乘以分块的体积（\(dx * dy * dz\)），再把结果加总：

$$\rho_{approx}=\sum_{i=1}^M \sum_{j=1}^N \sum_{k=1}^O f(x_i, y_j, z_k) dV_{ijk}$$

图 15 中 N=M=0=10。和往常一样，当 \(dx\)、\(dy\)、\(dz\) 趋近于零时，可以把黎曼和写成三重积分：

$$\rho = \int_{ax}^{bx} \int_{ay}^{by} \int_{az}^{bz} f(x,y,z)dxdydz$$

同样，这里的积分最好理解为所积分函数面密度的一种体现。在我们的例子里，某个体积内物体的密度是由每一维上的一些区间（我们的积分域）确定的。

积分并不限于三维。维度想有多少就有多少，而且我们很快会看到，渲染中的许多公式其实涉及超过三维的多重积分（这些维度不一定对应空间位置或方向，也可以是时间之类）。我们会在第 2 卷的课程（渲染方程）里介绍这些公式。

结语：揭开渲染数学的面纱

本章介绍的这些数学工具几乎用在每一个与渲染相关的算法里，积分尤其如此。在本章里，我们希望已经把它们的来龙去脉、运作方式与原理讲得简单直观。如果你不知道微分和积分是什么，你几乎（真的）不可能理解计算机图形学算法的理论和实际实现。不过，如果你肯花力气读完本课，现在你对这些技术应当有了更好的理解，并且应该会同意：它们一点也不难。
