例 1：在二维中模拟散景效果

阅读时间：12 分钟。

引言：散景效果

散景效果（bokeh effect）是一种视觉伪影，但它是令人愉悦的那种，常被认为极大提升了照片的审美品质。人们其实可以利用这种效果，做出下面这几个例子里那种惊艳或有趣的图像。本课我们会展示如何只用二维技术来模拟这个效果。如果你不知道什么是散景，它就表现为下面这些照片焦外区域里看得到的那些弥散圆。简单回顾一下：相机的镜头把场景中物体反射的光聚焦到图像平面上。然而只有处在某个距离范围内的点才会在图像中清晰成像。其余所有点（太近或太远的）的光会散布到一块可能大于一个像素的区域上，从而形成这些圆形。场景中每一个在图像里失焦的点都会这样被模糊；不过由于对比的缘故，场景中的亮点——比如光源——形成的弥散圆会明显比暗点产生的更易看见。

本课不会太详细地讲散景效果的成因。另有一课会专门讲这个有趣的话题，以及一般意义上的镜头像差模拟（在渲染基础部分你也能找到关于景深与模糊的有用信息）。现在只需说明：实际上这些圆并不总是圆的。使用带叶片的孔径光阑时，失焦的点会被模糊成光圈叶片构成的多边形形状（右边的图里能看到这些叶片）。这个效果在左上角那张照片里清晰可见。叶片是圆的时候形成圆形，叶片是直边的时候就形成多边形。现在我们来看一种在二维中模拟这个效果的方法。

在二维中模拟散景效果

对这个效果的一种粗略解释是：场景中物体反射的光会向各个方向反射（当然这只对漫反射物体成立）。其中一部分光会穿过相机光圈，在胶片平面上形成一个弥散圆（或者按上面所说，取决于叶片形状，形成多边形）。要把这些光线重新聚焦到图像平面上的同一点，你需要一个镜头。不过先别跑题。当一个点在图像平面上出现在好几处时，就形成了弥散圆。这个效果怎么用二维方式模拟呢？想象一张全黑图像正中间有一个白色像素。把这张图像向每个方向各平移一个像素并累加结果，我们就能让这一个像素在图像里出现在好几处。图 2 展示了这个过程。你要做的就是把这个像素涂抹到它的邻居上。这段动画里，原图只向各方向平移了一个像素，但这只是为了简化演示；没有任何东西阻止你用大于一个像素的平移量来造出更大的模糊。注意，当我们把原图的一份拷贝朝某个方向平移并累加结果时，也可以降低这份拷贝的不透明度，从而造出柔和的模糊。一般规律是，你可以让拷贝的不透明度取决于所施加的平移量，这样白点离它原来的位置越远，亮度就越淡。在图像处理中，平移图像的一份拷贝并累加结果，与给图像施加模糊滤镜时所做的很相似。不过我们这个例子里造出模糊的原理并不是通常采用的做法，这一点会在讲图像滤镜的课程里解释。最后，如果你愿意，也不必局限于把图像拷贝朝每个方向平移。你可以在预先定义的一组方向内，按某个固定的像素量平移图像并累加它的拷贝，从而给这份模糊一个有趣的形状。图 3 给出了几个例子，模糊分别呈菱形（即钻石形）和三角形。

我们用一些代码来试着模拟它。我们需要两张分辨率相同的图像。第一张当作「遮罩」，是一张灰度图，定义模糊图形的形状与强度。第二张可以是我们想施加模糊的任意彩色图像。原理很简单。我们遍历遮罩图像的每个像素，把该循环中当前的像素记为 P(i,j)，其中 P(i,j) 是这个像素的亮度（一个灰度值），(i,j) 是它的坐标。每次迭代，我们累加输入彩色图像的一份拷贝，把它平移 (i,j) 个像素，再乘以遮罩像素值。这个算法的动态演示见图 4。在这个例子里，结果图像 I2 就是 16 张图像按某些灰度值加权后的和。不过要注意，作为一项优化，遮罩中的黑像素可以跳过（如果明知结果会是黑的，就没必要去算图像与某个颜色的乘积）。因此本质上，在这个例子里我们只累加了 4 份图像拷贝（遮罩中亮度大于 0 的像素个数：c11、c12、c21 和 c22）。累加这些图像也会让最终图像中像素的亮度大幅增加。设想图像全白、遮罩里也只有白像素的情形，那最终图像 I2 里每个像素的亮度就会是 16。在显示或存盘之前，最好把这些值归一化。一个简单的做法是把遮罩中所有像素的亮度加起来，再用最终图像除以这个数。

最后我们把这些想法落成实际代码。我们先读两张分辨率相同的图像。和 Dan 原帖里一样，我们用 Marcie 的图像作为彩色图，遮罩则用一张在画面左下角有一个小的白色六边形（6 边）多边形遮罩的图像。用这两张图得到的效果不太明显，不过别担心，稍后我们会换几张图让它更明显。我们还需要创建第三张图像，用来累加结果。然后遍历遮罩图像的每个像素。如果遮罩中的像素 P(i,j) 不是黑色，我们就把彩色图像平移 (i,j)，把这份拷贝乘以遮罩像素值，再把结果加到第三张图像上。这个过程结束后，我们归一化像素值，把结果存成 PPM 文件。平移图像我们会用上一章介绍的 'circshift' 方法（记住，图像边界之外的像素会绕回来）。这个算法的代码如下：


Image I = readPPM("./marcie.ppm"); 
Image J = readPPM("./hexagon.ppm"); 
int w = J.w, h = J.h; 
Image K(w, h); 
float total = 0; 
// 遍历每个像素
for (int j = 0; j < h; ++j) { 
    for (int i = 0; i < w; ++i) { 
        // 若遮罩中的该像素不是黑色
        if (J(i, j) != Image::kBlack) { 
            // 累加彩色图像平移后的拷贝，按遮罩值加权 
            K += J(i, j) * Image::circshift(I, std::pair&ltint, int="">(i, j)); 
            total += J(i, j);  //累加遮罩亮度值用于归一化 
        } 
    } 
} 
 
K /= total;  //归一化 
savePPM(K, "./out.ppm");

花点时间看看这段代码，找出用来操作图像与颜色的各个运算符。我们用运算符 () 按坐标访问像素。写这类方法时，总是按引用返回值以避免拷贝：


Rgb& operator () (const unsigned &x, const unsigned int &y) const 
{ 
    assert(x < w && y < h); 
    return pixels[y * w + x]; 
}

我们用运算符 != 把一个颜色与另一个颜色比较，不等号右边用的是预定义颜色（避免每次都新建一个 Rgb 实例，原因上一章已经解释过）：


bool operator != (const Rgb &c) const { return c.r != r && c.g != g && c.b != b;

我们还用了复合赋值运算符 += 和 /=。第 13 行的 total += J(i, j) 挺有意思：它计算一个像素的亮度，并把结果加到一个 float 上。它的实现可以在 Rgb 结构里找到：


friend float& operator += (float &f, const Rgb rob) 
{ 
    f += (rgb.r + rgb.g + rgb.b) / 3.f; 
    return f; 
}

我刚刚做了什么？

除了写出并运行你第一个图像处理程序之外，你做的事叫作卷积。图像滤波和卷积是一回事。这项技术很快会在二维那一课里完整讲解。简而言之，卷积是图像乘法的一种形式，但它不是把两张图像逐像素相乘，而是把第一张图像的每个像素与第二张图像的所有像素相乘。这需要四层嵌套循环：


for (n = 0; i < imageHeight; ++m) { 
    for (m = 0; m < imageWidth; ++m) { 
        for (int j = 0; j < maskImageHeight; ++j) { 
            for (int i = 0; i < maskImageWidth; ++i) { 
                ... 
            } 
        } 
    } 
}

这类算法的处理时间为 \(O(N^4)\)（假设遮罩与图像分辨率相同），你大概也能猜到，它可能非常昂贵。幸运的是，在我们的例子里遮罩图像大部分像素是黑的，这大大加快了计算。然而当遮罩变大时（如后面几个例子），很快就会明显看出算法很慢（而且本课我们只用了分辨率相当低的图像）。加速图像卷积的一种办法是在频率空间中执行这个运算。

自己动手做！

原例中遮罩的尺寸和图像本身都让散景效果不太明显。我们换几张图像玩玩，看看能得到什么（这是这个练习的创造性部分）。正如本课开头提到的，散景效果在小面积的背景高光附近更明显，比如镜面反射和光源。遗憾的是，PPM 文件能存的亮度值范围不足以模拟这类高光。但我们可以作弊。转成 float 之后，把任何数值大于某个阈值（本例为 0.5）的像素乘以某个任意值（本例为 3），让它们更亮。这有助于在输入图像里造出一些高光。下面这些图展示了通过改变遮罩形状能得到的一些视觉上有趣的结果（这些图像随源码一起提供，你可以自己跑这些例子，最终试试你自己的形状）。

别笑话我们选的某些形状。有些相机制造商在设计镜头时，就是为了造出这些特定形状的散景。你也可以自己做出这些形状（正如维基百科上关于散景的条目所指出的：「近来，摄影师们利用散景的形状，用纸板做出心形、星形等他们希望的散景形状的简单遮罩，套在镜头上」）。空心圆盘形或甜甜圈形的散景（右上）可以用折反射镜头造出来。把我们的程序生成的图像（那棵圣诞树）与另一些照片比一比（顶部那张图就是折反射镜头产生的散景）。
