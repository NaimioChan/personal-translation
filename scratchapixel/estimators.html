估计量

阅读时间：14 分钟。

在最终去看蒙特卡罗方法本身（下一课）之前，我们需要引入估计量这个重要概念。不过先让我们快速复习一下到目前为止学过的东西。

快速回顾

前几章我们引入了总体参数的概念。我们可以用简单的平均来计算任何总体参数的均值。这个均值记作 \(\mu\)。然而，当由于实际原因无法测量这个均值时，我们可以借助抽样来估计它。思路是做一系列观测，这些观测取一串随机变量的形式，记作 \(X_i\)，再对它们的值求平均。这就是所谓的样本均值：

$$\bar X = \dfrac{\sum_{i=1}^n X_i}{n}.$$

总体的方差与样本均值的方差都可以用下面的公式计算：

$$\sigma^2 = { {\sum_{i=1}^N {(x_i - \mu)^2}}\over N} = {{\sum_{i=1}^N x_i}\over N} - \mu^2,$$

以及

$$S_n^2 = { {\sum_{i=1}^n (x_i - \bar X)^2 } \over n} = {{\sum_{i=1}^n x_i}\over n} - \bar X^2.$$

分别对应两者。本章我们还会再谈到样本均值的方差。由于样本均值本身就是一个随机变量（它是随机变量的平均，因此本身也是随机的），我们可以用计算样本均值的同一方法来度量它的均值与方差。样本均值的均值就是所有样本均值的简单平均。至于样本均值的方差，我们在上一章发现并证明了它与总体方差通过下面的等式相联系：

$$\bar \sigma_n^2 = { \sigma^2 \over n }.$$

其中 \(\sigma^2 \) 是总体方差，\(n\) 是样本大小。上一章我们还说明，根据大数定律，样本均值 \(\bar X \) 依概率、并且几乎必然趋近总体均值 \(\mu\)：

$$\bar X \xrightarrow{p} \mu \quad \text{ for } n \rightarrow \infty.$$

右箭头上方的上标 \(p\) 表示「依概率收敛」。

最后，我们还学到了关于样本均值本身分布的一些东西。我们知道统计量的分布称为抽样分布，它的期望值（样本均值分布的期望值）就是总体参数的均值 \(\mu\)，并且 \(\bar X\) 在分布上收敛到正态分布（均值为 \(\mu\)、方差为 \(\sigma^2 / n\)）。我们还知道它的收敛速率与 \(1 / \sqrt{n}\) 成正比。归纳起来我们有：

  • 总体均值 \(\color{\red}{\mu}\) 与方差 \(\color{\red}{\sigma^2}\)。

  • 样本均值 \(\color{\red}{\bar X_n}\) 及其方差 \(\color{\red}{S_n}\)。

  • 均值分布的期望值 \(\color{\red}{\mu_{\bar X}}\) 与均值分布的方差 \(\color{\red}{ \sigma_{\bar X}^2 }\)。

估计值与估计量

估计量的概念很简单，在某种意义上只是样本均值概念的一种推广。显然，在统计学里，说到估计量时用的术语与我们此前用的不同。总体的一个参数现在用希腊字母 \(\theta\)（theta）而不是 \(\mu\) 来表示。照例，我们的目标是用某种统计方法去估计 \(\theta \) 的值，而它是未知的（比如 \(\theta\) 可以是居住在巴哈马的成年人总体的身高）。前一章之前的做法是对总体抽样并对结果求平均，以此估计这个值。结果叫作样本均值，可以写成：

$$\bar X = \color{red}{\dfrac{1}{n}} (\color{green}{X_1} \color{red}{+} ... \color{red}{+} \color{\green}{X_n}) = {\sum_{i=1}^n \dfrac{X_i}{n}}.$$

其中 \(n\) 是样本大小，\(X_i\) 是随机变量，或者如果你愿意，也可以说是一些可观测数据。这里需要注意的是，样本均值不过是某种函数（求和再平均），作用于一组可观测数据。换句话说，如果你看上面样本均值的等式，绿色那些项是可观测数据，而红色那些项与数学算子则对这些数据做运算，产生一个结果，即对总体参数 \(\theta \) 的一个估计。所有这些项与算子构成一个函数，数据是它的自变量。我们可以把这一想法形式化地写成：

$$\delta(x_1, ... x_n),$$

其中希腊字母 \(\delta\)（小写 delta）表示一个（实值）函数，它以一组可观测数据 \(x_1, ... x_n\) 为自变量。

这个函数 \(\delta\) 就是我们所说的参数 \(\theta\) 的估计量，而 \(\delta(x_1, ..., x_n)\) 的结果叫作 \(\theta\) 的估计值。

样本均值只是这类估计量的一个例子，但我们在后面的课程里会学到还存在其他估计量。重要的是要意识到，估计量是数据的函数，因此：

由于估计量 \(\delta(X1, . . . , Xn)\) 是随机变量 \(X1, . . . , Xn\) 的函数，所以估计量本身也是随机变量（顺带说一句，这就是我们所说的统计量），

这一点我们在本课里重复过很多次，但现在我们已经把它形式化了。试着看清估计量与估计值的区别（虽然很微妙）：估计值是一个具体的值 \(\delta(x_1,...,x_n)\)，我们可以用可观测值 \(x_1, ..., x_n\) 把它确定下来。估计量是随机向量 \(X\) 的函数 \(\delta(X)\)，而再说一次，估计值只是一个具体的值 \(\delta(x)\)。

在讲期望值的那一章里，我们提到随机变量可以逐点代数运算。这很重要，因为它说明了估计量本身可以被视为随机变量这一点是成立的。若干随机变量相加的结果仍然是随机变量。这也说明，用作估计量的函数类型没有限制；如前面所说，不同的估计量会在后面的课程里研究。一个估计量（相对其他估计量）的「吸引力」取决于它的性质，比如它的均方误差（RSE，上一章我们简要谈过）、它的一致性以及它的渐近分布。上一章我们简要涉及了这些概念。我们会在将来专门讲估计量的一课里详细回顾它们（这个题目在渲染里足够重要，值得单独一课）。还有一个重要性质我们尚未谈到，那就是无偏性；现在我们来看这个概念。

无偏估计量与有偏估计量

有偏与无偏的概念在渲染里很重要。如果你对计算机图形学和渲染感兴趣，很可能见过一些文章或帖子，作者在里面谈到有偏或无偏路径追踪。这是什么意思，论坛上也常有人问。这个术语与渲染领域无关，而属于统计学领域。「无偏路径追踪」这个说法是为了指称渲染中某一类基于「无偏统计方法」的算法而造出来的。我们先来解释它是什么意思，然后为了好玩，再回到渲染领域，看看 Wikipedia 给出的无偏渲染的定义，并向你展示：现在，用本课给你的全部信息，你能看懂这个定义里的每一个字。

这个概念相当简单。本章前面我们引入了估计量 \(\delta(X)\) 的概念。样本均值是估计量的一种形式，但从一般意义上说，估计量是一个作用于可观测数据、并返回总体参数值 \(\theta\) 的估计的函数（本章我们将用 \(\theta\) 表示我们想估计的未知参数）。在讲期望值的那一章里，我们说明过当样本大小趋于无穷时，样本均值依概率收敛到总体均值：

$$\bar X_n \xrightarrow{p} \theta \quad \text{ for } n \rightarrow \infty.$$

我们也可以用样本均值的期望值来表达这个关系：

$$E[\bar X_n] - \theta = 0.$$

但既然我们计算样本均值的方法本身就是一个估计量，我们可以把 \(\bar X_n\) 换成 \(\delta(X)\)：

$$E[\delta_{unbiased}(X)] - \theta = 0.$$

这是一个重要结果。它说明估计量的期望值与总体参数之差为 0。但即便在估计量是随机变量简单平均这一特定情形下这成立，你也完全可以设计出一个具有某些有趣性质、但期望值不同于参数 \(\theta\) 的估计量。换句话说，这样的估计量会产生下面的结果：

$$E[\delta_{biased}(X)] - \theta \neq 0.$$

估计量的期望值与参数之间的差，就是我们所说的偏差（bias）。换句话说，我们可以把上面的关系写成：

$$E[\delta_{biases}(X)] - \theta = \text{ bias }.$$

当然你已经猜到了，如果偏差为 0，我们就说这个估计量是无偏的；而从逻辑上说，当这一点不成立时（偏差不为 0），我们就说这个估计量是有偏估计量。

为了说得完全周全，我们应当在这个定义里补上一句：要成为无偏估计量，估计量必须对 \(\theta\) 可能取的任何值都无偏。来自均值为 \({ \theta }\) 的未知正态分布的一个样本 \({ \bar X_n } \)，是 \({ \theta}\) 的无偏估计量，因为对 \({ -\infty < \theta < \infty }\) 有 \({ E[\bar X_n] = \theta } \)。

你可能会问，一个估计量的期望值与我们试图估计的参数不同，这难道不是个大问题吗（换句话说，你可能会觉得这个结果是错的）？在一般情况下，这确实可以看作一种不理想的行为；但设想一个收敛速率远好于其他估计量的估计量。即使它的期望值相对 \(\theta\) 的真实值略有偏差，但已经足够接近、可以被视为有效的估计，那么你能比其他估计量「更快」得到可接受的估计这一点（即便它有偏），也可能非常有利（想象一个速度比视觉准确度或保真度更重要的系统）。你在什么程度上认为用这个「有偏」估计量得到的结果、相对于用「无偏」估计量得到的结果是可接受的，完全由你自己判断。记住，计算机图形学的主要目标之一是用尽可能少的样本生成高质量的抗锯齿图像（我们很快就会看到这是什么意思）。因此，收敛速率快的估计量往往比其他估计量更受青睐，即使它们产生有偏的结果。

估计量的性质

估计量的无偏性（或有偏性）是我们已经谈过的一个性质。

方差是另一个性质：它与估计量的收敛速率有关（随着样本大小增加，你多快能到达真实均值）。对无偏估计量而言，这个方差用 \(E[(\bar X_n - \theta)^2]\) 度量（你也可以写成 \(E[(\delta(X) - \theta)^2]\)），如上一章简要提到的，它也称作估计量的均方误差（或 M.S.E.）。一般规律是：估计量的方差越小越好（它收敛到结果越快）。

一致性是本章要回顾的最后一个性质。你会经常看到这个术语。如果一个估计量随着样本大小 \(n\) 增大，它靠近总体参数 \(\theta\) 的概率也随之增大，我们就说这个估计量是一致的。由大数定律我们知道，随着 \(n \rightarrow \infty\) 增大，样本均值 \(\bar X\) 依概率收敛到 \(\theta \)，因此在这个情形下一致性是成立的。

作为一般规律，好的估计量既无偏、又有最低的方差或 M.S.E.。不过有偏估计量的方差常常低于无偏估计量（我们在研究各种估计量时会看到）。

作为最后的练习，花点时间读一读下面 Wikipedia 关于无偏渲染器的定义。令你大为满意的是，你应该会相当惊讶地发现，这个定义所涉及的每一个想法现在对你都完全说得通了。我们在其中插入了解说：

在计算机图形学中，无偏渲染指的是一种不会在辐射亮度近似中引入任何系统误差或偏差的渲染技术。

你知道渲染器的目标是计算一个叫作辐射亮度的量。我们在《着色入门》那门课里详细谈过辐射亮度。这一行所指的方法，就是我们用来（通过采样）求这个辐射亮度的估计量；如果这个估计量是无偏的，那么我们就可以说我们的渲染器也是无偏的。

因此，它常被用来生成其他渲染技术所比对的参考图。

因为估计量是无偏的，我们知道只要样本足够大，它最终会收敛到真实的辐射亮度。因此无偏渲染器产生的图像可以用作参考图（比如用来与有偏渲染器产生的图像比较）。

从数学上说，无论观测多少次，无偏估计量的期望值总是总体均值。［……］

前几章我们证明了，当 \(n \rightarrow \infty\) 时样本均值 \(\bar X_n\) 越来越接近参数 \(\theta\)。

方差与标准差分别随数据点数而减小，这意味着要把误差的标准差减半，需要四倍的数据点。

上一章我们解释过，均值分布的方差或 M.S.E \(\sigma_{\bar X}^2 \) 等于总体方差除以样本大小 \(n\)。由于标准差只是方差的平方根，我们也说明过要把标准差（你可以把它看作误差的一种度量）减半，需要四倍的样本。

这使得无偏渲染技术对实时或交互速率的应用不那么有吸引力。

我们还解释过，无偏估计量一般比有偏估计量更受青睐；不过有偏估计量可以更快地收敛到 \(\theta\)，这使它们比无偏估计量更有吸引力，尤其是在速度优先于准确度时（或者准确度并不关键时）。

反过来，一个无偏渲染器产出的、看起来平滑无噪声的图像，在概率上是正确的。有偏的渲染方法未必就是错的，只要估计量是一致的，它仍然可以收敛到正确答案。不过它确实会引入一定的偏差误差。

在评价一个估计量时，有偏这个性质不如一致这个性质重要。收敛很重要，无论估计是否有偏（假设样本数足够大，产生的图像方差极小，我们至少知道无偏图像与有偏图像之间的差别只来自偏差，而不是有偏估计量引入的其他误差）。换句话说，偏差一般可以接受，但误差不行。要看这些概念在实践中怎么用，请查阅题为《光传输入门》的那一课。
