图层种子

简介

可以将 Layer Seed 连接到某个属性，以便该属性的父图层向其输出连接传递唯一值。

像复制器这样的图层可以自动为其 Input Shapes “播种”随机数，但对于单个图层则并非如此，例如需要 3 个随机行为才能生成 3 个随机数。与其管理多个图层，不如将一个 Layer Seed 连接到单个随机行为的 Seed 属性，从而为其连接的每个图层生成不同的随机数。

界面

Offset：偏移数值以生成新的种子。

示例：

  1. 创建一个文本图形。
  2. 单击文本图形的 Generator随机日期。
  3. 选中 Text Shape，然后按两次 Cmd/Ctrl + D 创建两个副本。
  4. 在视口中将它们分开。
  5. 右键单击 Random Date 字符串生成器的 Seed 属性 > Add Utility > Layer Seed。

Random Date 会向每个 Text Shape 传递不同的种子，从而渲染出唯一的日期。

示例：

  1. 创建一个椭圆。
  2. 创建一个颜色数组。
  3. 在 Color Array 上，点击 + Add 按钮 3 次以添加 3 个索引。
  4. 为每个索引设置一种独特的颜色。
  5. 连接 colorArray.id→ellipse.fillColor
  6. 取消勾选 Auto Index。
  7. 右键单击 Color Array 的 Index 属性 > Add Utility > Layer Seed。
  8. 右键单击 Color Array 的 Index 属性 > Add Expression...
  9. 输入 %4。
  10. 选中 Ellipse，多次按 Cmd/Ctrl + D 创建多个椭圆副本。
  11. 在视口中将椭圆分开。

每个 Ellipse 都会从 Color Array 中获得随机的 Fill Color。

%4 属性表达式（模 4）会将 Layer Seed 的值转换为 0 到 3 之间的值，以匹配 Color Array 中 id 的数量。
