数值生成器

简介

生成数字，并可设置精度、填充和分隔符。

界面

Number：设置要生成的数值。

Precision：设置显示的小数位数。

Padding：设置小数点前至少显示的位数。

Thousands Separator：设置用于分隔千位的符号。（例如 1,000 中的 ,）。

Decimal Separator：设置用于分隔数字整数部分与小数部分的符号。（例如 12.75 中的 .）。

Multiplier：输出Number乘以该值的结果。也可以为其设置关键帧，从而为Number制作动画。
