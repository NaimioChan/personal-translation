调度组

简介

以程序化方式在时间上定位子图层。

Scheduling Group 提供了一种将一组图层分组，并以程序化方式影响其时间偏移的方法。在下面的示例中，一个错开行为连接到了 Child Offset 属性。第一个到最后一个图层的时间偏移分别由 Stagger 的 Minimum 和 Maximum 值设置。通过调整 Stagger 的 Maximum 属性，可以在时间上移动图层。

如果向调度组添加或移除图层，Stagger 会自动更新它们的时间偏移。

当图层被拖出 Scheduling Group 时，它们会保留已应用的时间偏移。

层级：

当组或图层层级包含在调度组中时，只有父级会受到影响。所有子级都会继承父级的偏移，但自身不会被偏移。

也可以对图层进行“排序”。在此示例中，延长一个图层的片段会“波及”调度组中的其他图层。

界面

Child Offset：为调度组中的每个图层添加时间偏移。

Sequencing：勾选后，图层将依次排列。

Overlap：为排序后的图层添加重叠（或使用负值添加间隙）。

Schedule from End：勾选后，调度将从合成末尾开始。

Start Frame：当 Schedule From End 未勾选时，设置调度开始的帧。默认情况下，此属性连接到合成的 Frame Range。

End Frame：当 Schedule From End 勾选时，设置调度开始的帧。默认情况下，此属性连接到合成的 Frame Range。

Ordering Policy：

  • Layer Order：根据图层顺序排列偏移。
  • Alphabetical：根据图层的显示名称按字母顺序排列偏移。这不会改变实际的图层顺序。

Flip Order：反转图层的调度顺序。勾选后，图层将按从下到上的顺序排列。

Shapes Only：勾选后，除图形外的所有图层类型都将被排除在调度之外。

示例：

  1. 创建 3 个 Basic Shapes。
  2. 在选中全部 3 个图形的情况下，点击工具架中的 Schedule selected Layers 按钮。
  3. 调整所创建的错开行为的 Minimum 和 Maximum 属性。

信息：

图层片段的左侧或右侧（取决于 Show Names 设置）会出现一个小图标，表示该图层属于某个 Scheduling Group。

提示：

用于自定义调度组内图形行为的控件可在图形的Advanced 标签页下找到。
