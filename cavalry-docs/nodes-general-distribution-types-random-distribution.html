随机分布

简介

将点分布到随机位置。

界面

Shape：设置用于在其中分布点的图形。

Size：设置 Shape 的尺寸。

Count：设置点的数量。

Seed：设置随机种子。

Use Probability：基于 Probability 值放置点。

Probability：值越高，返回“true”的可能性越大。例如，将 材质采样器 或 图像采样器 以灰度图像或渐变连接到此属性，意味着点更可能散布在较亮的区域。

Threshold：设置裁剪值 [low, high]。沿用上例，Threshold 为 L = 0 和 H = 1 意味着会使用暗色与亮色值的完整范围。任何超出此阈值的 Probability 值都会被跳过。

Relax：勾选后，点会尝试彼此远离。

Relax Distance：设置点尝试彼此远离的距离。

Max Iterations：设置松弛算法的运行次数。数值越高越精确，但速度越慢。

Keep Shape：勾选后，位于 Size 参数范围之外的任何点都会被剔除。
