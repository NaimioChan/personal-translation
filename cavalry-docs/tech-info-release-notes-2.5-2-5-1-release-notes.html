2.5.1 发行说明

发布日期：2025 年 10 月 7 日

增强

  • 仅 macOS
  • 渲染为 PNG 和 ProRes 时新增 Bit Depth 选项：
    • PNG：16-bit。
    • 仅 macOSProRes：10-bit 和 12-bit。

重要错误修复

  • 在 macOS 上双击或将 .cv 文件拖到 Applications/ 中的 Cavalry 图标或程序坞上，不再导致崩溃。
  • 从 Windows 工作站访问远程服务器的 UNC 路径相关问题已解决。
  • 球面化滤镜的 Back Visibility 现在已生效。
