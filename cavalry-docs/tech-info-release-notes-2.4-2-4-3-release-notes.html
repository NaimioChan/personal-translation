2.4.3 发行说明

发布日期：2025年6月16日

增强

  • 支持自定义标签页的窗口（例如 场景窗口、控制中心）现在可以溢出。标签页有最大宽度，如果标签页无法全部容纳在可用空间内，则可以滚动标签页。
  • Proportional Constraint 选项已添加到 Background Blur、Fast Blur 和 投影 滤镜的 Blur 属性。

重要缺陷修复

  • 已解决影响 资源窗口 中已保存文件重新排序的问题。
  • 断开 噪波、振荡器 或 扭曲滤镜 等图层上的 Time 属性后，在复制该图层或其所在合成时，不再重新连接（终于！）。
  • 连接到 控制中心 的属性的 UI affordance 现在会显示在 Control Centre 的所有标签页中。
  • 来自 Cavalry UI 之外的色板和颜色现在也受 Color Picker（吸管）支持。
