等值线图形

简介

将图像、Shader 或图形图层转换为轮廓。

界面

Common Attributes +

Mode：决定轮廓是由图像资源、Shader 还是图形图层生成：

  • Image：使用图像资源作为轮廓的来源。
  • Shape Layer：使用图形（以及Shader）作为轮廓的来源。
  • Shader：使用Shader（不含图形）作为轮廓的来源。

信息：

Image 和 Shader 模式比 Shape Layer 模式性能更好，尤其是在使用滤镜时。如果性能有问题，可以考虑将 Input Shape 渲染为图像序列，并将该序列用于 Image 模式。

Input Shape：当 Mode 设为 Shape Layer 时，连接一个图形。

Input Image：当 Mode 设为 Image 时，连接一个图像资源。可以直接从资源窗口、通过 资源数组，或通过 从智能文件夹获取资源 工具连接。

Time：当 Mode 设为 Image 时，设置要采样的视频或图像序列的帧号。默认情况下，它连接至合成的时间。请注意，当连接了 Input Shape 或 Input Shader，且它们包含随时间变化的属性时，应使用它们各自的 Time 属性。

Input Shader：当 Mode 设为 Shader 时，连接一个Shader。

Size：当 Mode 设为 Shader 时，定义采样区域的世界空间尺寸。

Looping：当 Mode 设为 Image 且勾选 Looping 时，所有视频或图像序列资源都会循环。

Source Channel：选择要采样的输入颜色分量：Alpha、Luma（默认）、Red、Green 或 Blue。

  • Alpha：使用输入的 Alpha 通道。
  • Luma：使用输入的亮度通道。
  • Red：使用输入颜色通道的红色分量。
  • Green：使用输入颜色通道的绿色分量。
  • Blue：使用输入颜色通道的蓝色分量。

Invert Source：启用后，输入的亮度值会在采样前被反转。

Use Threshold Graph：启用后，可使用 Threshold Graph 来重新映射输入的采样值。

Threshold Graph：当勾选 Use Threshold Graph 时，绘制一条曲线以重新映射输入的采样值。这可用于压缩/拉伸亮度值的变化，从而在这些区域生成更多或更少的轮廓。

Extraction Mode：决定从采样输入中提取的几何体类型：

  • Isolines：输出开放或闭合的轮廓线。
  • Filled Regions：为各层级之间的每个条带输出闭合图形，包括孔洞。
  • Cell Boundaries：输出每个条带的外轮廓，即填充区域之间的分界线。

Contour Levels：设置创建的轮廓数量（在亮度值范围内均匀分布）。

Grid Size：设置采样网格的大小。数值越小，结果越精确/细化，但可能影响性能。

Clean Up Path：启用后，输出轮廓中彼此非常接近的点会被移除。

Simplify：启用后，处于 Simplify Tolerance 范围内的点会被移除。

Simplify Tolerance：设置移除某个点可能给轮廓带来的最大偏差（以场单元格为单位）。容差越高，性能越好，但会产生更棱角分明、低多边形感的观感。

Output Béziers：启用后，输出轮廓会重采样为贝塞尔曲线。

Filter Path Size：启用后，小于 Path Size 的路径会被移除。路径的“大小”按包围盒的最长维度（宽度/高度）计算。

Path Size：当勾选 Filter Path Size 时，任何“大小”小于该值的轮廓都会被移除。

Field Smoothing：设置追踪前对采样场施加的模糊量。这可用于柔化噪点，从而生成更平滑的轮廓。

Path Smoothing：设置对追踪出的轮廓施加的平滑量，通过圆化“marching-grid”的阶梯来实现。

Group By Level：启用后，所有轮廓会归入一个网格。取消勾选可让每个轮廓各生成一个子网格，以便行为可以单独处理每一个。

Sort Mode：当取消勾选 Group by Level 时，决定提取出的子网格的排列顺序。当勾选 Group by Contour Level 时，子网格始终按 Contour Level 顺序堆叠：

  • Contour Order：默认顺序，不作任何重排。
  • Area：按各个轮廓的面积从小到大排列。
  • Brightness：按亮度排列轮廓。
  • X：按轮廓在 X 轴上的位置排列。
  • Y：按轮廓在 Y 轴上的位置排列。
  • Random：随机排列轮廓。使用 Random Seed 重新排序。
  • Shader Value：按经过 Invert Source 和 Threshold Graph 处理后输入的通道值排列轮廓。

Reverse Sort：启用后，子网格的排列顺序会被反转。

Random Seed：当 Sort Mode 设为 Random 时，设置随机种子值以重新排列轮廓。
