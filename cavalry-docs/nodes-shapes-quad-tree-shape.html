四叉树图形

简介

Quad Tree 使用点分布，根据点的密度将一个正方形细分为更小的正方形。

界面

Common Attributes +

Source Distribution：选择一个分布类型。

Size：设置源正方形的尺寸 [x,y]。

Max. Iterations：尝试细分正方形的最大次数。

示例：

  1. 创建一个 Quad Tree Shape。
  2. 将 Source Distribution 设为 Random。
  3. 将 Count 减小到 5。
  4. 创建一个图形。
  5. 为它设置不同的颜色（使用属性编辑器中的 Fill 标签页）。
  6. 选中该图形，按住 Option/Alt 并点击复制器 图标，该图标位于工具架中。
  7. 将 Duplicator 上的分布类型设为 Sub Mesh。
  8. 将 Quad Tree 连接到 Duplicator 的 Sub Mesh 分布的 Input Shape。
  9. 调整 Quad Tree 上的 Seed 以调整细分。
