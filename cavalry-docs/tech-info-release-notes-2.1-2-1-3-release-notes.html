2.1.3 版本说明

发布日期：2024年7月16日

2.1 版本说明→

文件版本升级：

在 Cavalry 2.1.2 或更早版本中创建的场景，在 Cavalry 2.1.3 中打开时会被转换。文件会被复制到一个新的场景中，需要保存——打开时你会注意到旧场景命名为 <yourSceneName> [Converted].cv。任何在 2.1.3 及之后版本保存的场景将无法完全兼容 Cavalry 的任何先前版本。

新功能

工具

  • 新增 应用文本材质。它扩展了Apply Text Fill（现已弃用），使 Fills、Strokes、Shaders 和 Filters 也能受到影响。使用 Apply Text Fill 的旧场景将继续可用，但我们建议尽可能替换该图层。

效果

  • 新增 色阶滤镜：重新映射图层的黑场和白场级别。
  • SkSL 着色器 的编辑器已改进，现在属于 Starter 功能。Create > Demo Scenes > Custom Shaders and Filters 中也新增了若干示例。

常规

  • ProRes 现在支持导出 Linear PCM audio。
  • Render Manager 的 Audio Only 格式现在支持导出为 .wav 和 .aiff。
  • JavaScript Console 已从消息栏分离，成为JavaScript 编辑器 内的独立嵌入式面板。
  • 新增可独立停靠的JavaScript 控制台 窗口。
  • 现在可以通过 View 菜单决定Rulers 的数值显示方式。

增强

  • 现在可以在属性编辑器中右键单击属性标签并选择 Rename... 来重命名任何属性。
  • 现在可以在首选项中设置 Autosave Limit。
  • 文本图形 的 String 属性界面已更新，以容纳更大的输入区域并改进 String Generators 的连接。
  • 资源窗口 中新增了 Color Labels。
  • 使用正则表达式 已改进：
    • 粘贴 Regex 时现在会去除换行符。
    • Regex 新增了语法高亮。
    • Regex 现在支持捕获组。
  • 当在资源窗口 中选中项目时，Composition > Pre-Compose 菜单项现在会变暗。
  • Style/Material Behaviour（Apply Font Size 等）的界面现在会根据Mode 显示/隐藏属性。
  • 现在可以使用快捷键 Cmd/Ctrl + / 在JavaScript 编辑器 和JavaScript 图层 中注释/取消注释选中的代码行。
  • 颜色窗口 的最小宽度已略微减小。请注意，需要取消停靠 Add Layers 窗口，才能将 Color Window 设为最小宽度。
  • View 菜单中新增 Show Viewport Tool Help 项。Tool Settings 窗口中的按钮也已重命名。
  • 现在可以通过颜色窗口 中展开菜单的 Set Gradient from Palette 选项，设置 多点渐变着色器 的色标。选择一个 Multi-Point Gradient Shader 图层，然后运行该命令。创建的色标将根据合成分辨率随机定位。
  • API getSelection 现在包含 sortByHierarchyOrder 参数。

重要错误修复

  • Background Blur 滤镜现在能在 Pre-Comp 中正确渲染。
  • 导入 sRGB 色彩空间之外的图像可能导致图像在应用中显示不正确。现在导入时会正确转换。
  • 从 Shelf 向层级中添加摄像机后使用Camera 工具，不再会创建多个摄像机。
  • 已解决导出/导入 .cvc 文件的各种问题。请注意，2.1.3 之前导出的 .cvc 文件可能仍存在问题。
  • 在吸附到播放头或播放范围时，Clip Ends 的定位早了一帧。
  • 使用 Option/Alt 替换包含预合成覆盖 的合成时，现在能正确更新。
  • 重命名 Array 或 Dynamic Attributes 时，当前名称会再次在对话框中预选。
  • 修复了删除连接到JavaScript 工具 的凸包 时触发的崩溃。
  • 修复了在序列 的 Skip Indices 字段中设置某些范围时触发的崩溃。
  • 在 Style/Material Behaviours 中使用 Specific Indices 时，特殊字符未被作为单词包含。例如，如果字符串包含 43%，则只会影响 43。
  • 包含 整数值 bézier 曲线的动画曲线现在能在曲线编辑器 中正确绘制。
  • 随机分布 的 Ellipse 模式再次正常工作。
  • 修复了Attribute Expressions 可能创建无大小限制的缓存，导致较长渲染期间内存攀升的问题。
