捏合

简介

在衰减范围内捏合与拉扯图形，方式是移动 空对象。

界面

通用属性 +

Active：启用/停用变形器。在最初放置 Bind Area 和 Pinch Point 的衰减时很有用。

Bind Area：Pinch 生效的区域。默认情况下，创建 Pinch Deformer 时会添加一个名为 Pinch Binder 的衰减并连接到该属性。落在该衰减内的图形点会受到影响，范围之外的点则被忽略。

Pinch Point：默认情况下，创建 Pinch Deformer 时会创建一个名为 Pinch Mover 的空对象并连接到该属性。之后可以重新定位该 Null，以“捏合”它正在变形的图形。

示例：

  1. 创建一个椭圆
  2. 将 Radius 设为 W = 300，H = 300。
  3. 取消勾选 Bézier。
  4. 使用 Deformer 属性上的 + 图标，从列表中选择 Pinch。
  5. 移动 Pinch Binder 衰减，使其中心位于椭圆的边缘上。
  6. 移动 Pinch Mover 空对象。

椭圆位于衰减内的部分会被变形。可以试着增大 Pinch Binder 衰减的尺寸，或调整其 Falloff Graph。
