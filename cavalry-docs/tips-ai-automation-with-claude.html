使用 Claude 进行 AI 自动化

简介

通过向 AI 助手给出自然语言指令，你可以在 Cavalry 中自动化重复性任务。

Cavalry 使用 Model Context Protocol（MCP）——一种让 AI 助手直接与应用通信的开放标准——来接收来自你的助手的指令并执行文档上的任务。

Cavalry 的 MCP 服务器在你的设备本地运行，并连接到受支持的 AI 助手。

MCP 能做什么

用你自己的话描述一项任务，AI 助手就会通过 MCP 执行它，无需手动操作、编写脚本，也无需深入了解 Cavalry 的界面。

典型用途包括批量处理、文件准备、图层整理、本地化，以及制作可复用的自定义工具/脚本。

要求

开始之前，请确认已安装以下内容：

  • Claude。
  • Cavalry 2.8 或更高版本。

Claude 需要 macOS Big Sur 11 或更高版本。

将 MCP 服务器连接到你的 AI 助手。

配置 Cavalry

  1. 打开 首选项 窗口。
  2. 勾选窗口底部的 Enable MCP Server。

确认连接

  1. 确保 Cavalry 和 Claude 都在运行。
  2. 在 Claude 中，进入 File > New Conversation 并输入以下提示词：“你能看到 Cavalry MCP 服务器吗？”

注意：

Cavalry 和 Claude 必须同时运行才能相互通信。

向 AI 助手发出提示

启用 MCP 服务器后，以下是几种值得一试的强大用法。

示例 1：执行批量操作

将合成中的所有图形连接到另一个图层。要求 AI 助手连接所有图形，以确保外观一致。例如：“添加一个 Value Layer，并将它连接到当前合成中所有 Rectangle 的 Corner Radius。”

示例 2：自动重命名图层

随着场景变复杂，保持场景树井然有序。AI 助手可以识别每个图层包含的内容并为你重命名。例如：“重命名我的 Cavalry 合成中的图层。”

示例 3：创建自定义工具

构建适合你工作流程的可复用工具。描述你想要创建的工具，并说明它应该有 UI。你可以将 AI 助手生成的内容保存到 Scripts 文件夹中，以便日后复用。例如：“为 Cavalry 创建一个可复用的丝网印刷插件，带有半色调、墨量密度和对位控制。”

常见问题

支持哪些 AI 助手？

目前支持 Claude。

为什么 Claude 无法连接到 Cavalry？

请确认 Cavalry 2.8 或更高版本已打开并正在运行。重启 Claude 和 Cavalry。

为什么 Claude 拒绝我的请求或出现意外行为？

并非所有任务都能一次成功。请重新表述你的请求，或让 Claude 再试一次。我们会持续开发和扩展对 MCP 的支持。

MCP 会消耗我的每月 AI 额度吗？

将 MCP 与 Cavalry 一起使用不会消耗你的每月 AI 额度。Claude 的使用量由你的 Claude 套餐决定。

我所在的地区可以使用 MCP 吗？

这取决于你所在地区是否支持 Claude——请参见 Claude 支持的国家和地区列表。不过，MCP 目前不向中国客户提供。

为什么安装后 Cavalry 连接器没有出现在 Claude 中？

请将 Claude 更新到最新版本，然后从 Claude 的目录中重新安装该连接器。
