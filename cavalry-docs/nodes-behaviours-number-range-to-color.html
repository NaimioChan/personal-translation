数值范围转颜色

简介

基于渐变将数值重映射为颜色。

界面

Source Minimum：范围内的最小值。

Source Maximum：范围内的最大值。

Value：连接一组数值（例如来自 电子表格 工具的值）。

Gradient：Source Minimum 值会被重映射为渐变最左侧设置的颜色值，Source Maximum 值会被重映射为渐变最右侧设置的颜色值。

Clamp：勾选后，输出永远不会高于或低于 Maximum 或 Minimum 值。

信息：

该图层也用作 电子表格 工具中各选项的基础。Value 属性不会出现在 Spreadsheet 的属性编辑器界面中，因为它由图层自身的数据驱动。

示例：

  1. 创建 2 个图形（shape1 和 shape2）。
  2. 创建一个 Number Range to Color。
  3. 设置：
  4. Source Minimum = -100
  5. Source Maximum = 100
  6. 连接 shape1.position.y→numberRangeToColor.value
  7. 连接 numberRangetoColor.id→shape2.fillColor
  8. 在视口中上下移动 Shape1。

当 Shape1 在 Y 轴上到达 100 的位置时，Shape2 的 Fill Color 会被设为白色（渐变的极右端）。当它向下移动到 Y 轴 -100 的位置时，Shape2 的 Fill Color 会趋向黑色（渐变的极左端）。若勾选了 Clamp，则当 Shape1 超过 100，Shape2 将保持白色。

反转数值：

无论 Minimum 和 Maximum 中输入什么值，较小的值始终会被用作 Minimum，较大的值始终会被用作 Maximum。例如，当 Minimum 属性中输入的值实际上大于 Maximum 属性时，这些值会在该图层的计算过程中被反转。
