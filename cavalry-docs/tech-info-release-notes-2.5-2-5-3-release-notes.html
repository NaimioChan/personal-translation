2.5.3 发行说明

发布日期：2025 年 11 月 13 日

功能

  • 上传到 ：渲染管理器的 Upload 标签页现在包含 Canva 区块，可用于自动上传。使用账户中新增的 Linked Accounts 区块，即可将 Cavalry 关联到你的 Canva 账户。

脚本

API

  • hasAttributeDefinitionOverrides()
  • clearAttributeDefinitionOverrides()
  • getAttributeDefinitionOverride()
  • setAttributeDefinitionOverride()

增强

  • OpenType Stylistic Sets 现在通过复选框启用，而不再使用单选按钮，因此它们不再是互斥的。
  • 在文本工具中三击可选择整行。
  • 图形新增 Plus Darker 混合模式。

重要错误修复

  • 一处导致 Starters 无法导入图像序列的回归问题已解决。
  • 向数组添加多个索引现在快得多。
  • 一个长期存在的问题已解决：某些字体家族中的字重无法正确加载。
  • 影响空换行增大Font Size 的问题已解决。
  • 修复了在特定情形下将 子网格 的 Level Mode 设为 All 时可能触发的崩溃。
  • 修复了影响JavaScript 图层动态索引重新排序的问题。
  • 修复了叠加模糊滤镜可能导致出现环绕的问题。
  • 影响Containers 与关闭上下文菜单的问题已解决。
  • 受衰减影响的复制器中辉光滤镜的问题已解决。

说明

  • Plus 混合模式已重命名为 Plus Lighter（旧版场景会自动更新）。
