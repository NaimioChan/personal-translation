应用文本材质

简介

Apply Text Material 可用作文本图形上的 Material Behaviour，以程序化方式为字符、行、单词或部分字符串设置材质。例如，将最后一个单词的颜色设为蓝色，或每当字符串中出现 Cavalry 一词时将其设为绿色。

界面

Behaviour

Mode：选择用于选取范围的模式：

  • Regex：设置Regular Expression 以确定字符串中哪些部分会被选中。属性编辑器界面顶部提供了若干预设。
  • Specific Indices：手动输入索引，以确定选中哪些行/单词/字符。
  • All：当通过另一个行为使用 范围衰减 时使用此设置。参见下方示例。

Index Mode：当 Mode 设为 Specific Indices 时，选择受影响的层级：

  • Line：填充由 Specific Indices 定义的字符串中的每一行。
  • Word：填充由 Specific Indices 定义的字符串中的每个单词。
  • Character：填充由 Specific Indices 定义的字符串中的每个字符。

Specific Indices：当 Mode 设为 Specific Indices 时，设置要选中的索引。列表中的值应以逗号 , 分隔，范围应以冒号 : 分隔。例如 0,1:3,8 将选中索引 0、1、2、3 和 8。你也可以输入 first 或 last 来以程序化方式选中这些索引。注意空格字符也算作一个索引。

Regex：输入Regular Expression。更多信息请参见使用正则表达式。

Capture Group Indices：当正则表达式包含捕获组时，确定返回哪些组。列表中的值应以逗号 , 分隔，范围应以冒号 : 分隔。更多信息请参见使用正则表达式。

Overwrite Blend Mode：勾选后，可为选中范围设置Blend Mode。

Blend Mode：设置混合模式。

Filters：已连接的滤镜列表。使用

Fill

参见通用属性（Fill 标签页）。

移除 Fill：

要移除已有的 Fill，必须先覆盖它。为此，启用 Fill 并将 Alpha 设为 0。

Stroke

参见通用属性（Stroke 标签页）。

移除 Stroke：

要移除已有的 Stroke，必须先覆盖它。为此，启用 Stroke 并将 Alpha 设为 0。

与 Falloff 配合使用：

  1. 创建一个文本图形。
  2. 使用 Material Behaviours 属性上的 + 按钮，添加一个 Apply Text Material。
  3. 将 Apply Text Material 的 Mode 设为 All。
  4. 转到 Apply Text Material 的 Fill 标签页，右键点击 Color 属性 > Add Behaviour > Color Blend。
  5. 转到 颜色混合 的 Falloff 标签页，右键 > Add Falloff > Range Falloff。

现在可以使用 Range Falloff，从 Color Blend 的渐变两端为每个字符设置颜色。
