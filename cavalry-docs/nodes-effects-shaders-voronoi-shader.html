Voronoi 着色器

简介

Voronoi 图是一种镶嵌图案，可在自然界中见到，例如细胞或长颈鹿的皮毛，常用于建筑、艺术和计算机科学。

它的生成方式是在平面上散布若干点，并将平面细分为若干单元，每个单元包围距离对应点最近的区域。

界面

Settings

通用属性 +

Offset：偏移图案的位置。

Scale：增大/减小图案的尺寸。

Rotation：更改图案的角度。

Time：此属性会自动连接到合成的帧编号，在播放时使图案不断演化。如果需要静态的 voronoi 图案，请移除该连接，或将其替换为帧行为，以增大/减小 voronoi 演化的速度。

Loop Length：设置 Distortion Amount 循环一次所需的帧数。数值越小，voronoi 的演化速度越快（反之亦然）。

Distortion Amount：voronoi 图案最初由均匀的点阵生成。此属性可将这些点沿随机方向移动，从而生成不那么均匀的图案。

Seed：改变 Distortion Amount 的方向，以生成不同的图案。

Style：定义单元的显示效果：

  • Flat：用 Cell Color 填充单元。
  • Greyscale：用随机的灰度色（从黑到白）填充每个单元。注意该范围经过钳制，最暗的单元永远不会是 100% 黑色。因此可以将 Edge Color 设为黑色，这样在使用渐变映射滤镜为单元重新着色时，边缘便能被单独分离出来。参见下方提示。
  • Euclidean：用以每个网格点为中心的径向渐变填充单元。
  • Manhattan：用以每个网格点为中心的四边形状渐变填充单元。

渐变映射：

要为每个单元设置不同的颜色，请将 Style 设为 Greyscale，然后为图形添加一个渐变映射滤镜。这样可以重新映射 voronoi 的灰度值（由暗到亮）为彩色。最暗的单元在设计上不会被设为纯黑，因此，如果将 Edge Color 设为黑色（#000000），就可以使用渐变映射滤镜渐变上 position 0 - 0.02（最左侧）的区域来单独分离并影响 voronoi 边缘的颜色。

Equidistant Edges：当 Style 设为 Euclidean 时，渐变会沿垂直于边缘的线绘制，形成“金字塔”外观。

Greyscale Seed：随机更改 Greyscale 风格所设置的灰度颜色。

Cell Color：设置 Style 设为 Flat 时用于填充单元的颜色。

Type：选择图案的生成方式：

  • Normal：创建一种图案，它还可以在单元之间的边缘处生成间隙。
  • Hierarchical：创建一种图案，并可选择将单元进一步细分为更小的单元。当 Style 设为 Flat 时，每个 Level 的单元颜色可在 Hierarchical Colors 标签页中设置。

Edge Width：当 Style 设为 Normal 时，增大/减小边缘之间间隙的宽度。

Edge Feather：当 Style 设为 Normal 时，增大/减小边缘的柔和度。此属性有 0 的软下限，但可以通过手动输入负值将其设为负数。

Roundness：当 Style 设为 Normal 时，增大/减小各边缘相接处的圆角，以获得更柔和、更圆润的外观。

Edge Color：当 Style 设为 Normal 时，设置边缘之间间隙的颜色。

Levels：当 Style 设为 Hierarchical 时，设置单元可被细分的次数。例如，值为 2 时，会先细分部分单元一次，然后再细分其中部分单元一次。最顶层/第一层为 0。

Levels Amount：当 Style 设为 Hierarchical 时，递归地增大/减小单元被细分的概率。

Hierarchical Colors

当 Style 设为 Flat 且 Mode 设为 Hierarchical 时，可以设置每个 Level 的单元颜色。

Level 0 Color：设置级别 0 所有单元的颜色。

Level 1 Color：设置级别 1 所有单元的颜色。

Level 2 Color：设置级别 2 所有单元的颜色。

Level 3 Color：设置级别 3 所有单元的颜色。

Level 4 Color：设置级别 4 所有单元的颜色。
