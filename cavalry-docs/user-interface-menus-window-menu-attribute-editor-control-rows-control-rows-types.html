控制行：类型

简介

图层属性编辑器 UI 中可出现多种类型的控制行。

类型

数值

  • int：整数是不带小数点的数字，如 4。示例：复制器 上的 Count。
  • double：带小数位的数字，如 4.153。示例：图形上的 Rotation。
  • int2：一组两个整数，如 1920, 1080。示例：合成设置中的 Resolution。
  • double2：一组两个双精度数，如 103.453, 487.543。示例：复制器 上的 Shape Position。
  • double3：一组三个双精度数，如 103.453, 487.54, 2.5。示例：2.5D 图形的 Position。

颜色

包含 R、G、B、A 及十六进制值的属性。注意：十六进制值不能设置动画。

单击颜色色板会弹出颜色选择器，其中包含吸管工具。

颜色名称

可以将当前 Library Palette 和任何 Project Palettes 的名称输入到十六进制字段中，这些标签会解析为对应的十六进制值。

例如，若加载了默认的 “Cavalry” 调色板，输入 gre 就会出现自动补全列表，其中包含 “Green” 色板。通过单击或方向键选择 “Green” 并按 Return，对应的十六进制值 #4ffd7a 将被输入到字段中。

随时按 Escape 可取消输入。

滑块

如果属性设置了硬性的最小值和最大值，则使用滑块。例如 Opacity 的值只能在 0 到 100 之间，无法设置到该范围之外。

字符串

字符串可包含字母数字字符和符号。

字符串行还包含一个 + 图标，这是连接 字符串生成器 的快捷方式。

图表

请参见 Common Attributes。

输入列表

输入列表是可包含多个连接的行。可通过将图层拖到该行、建立连接，或单击控件右侧的 + 图标来添加并连接一个新图层，从而建立输入连接。这会弹出可连接图层的兼容列表。

会显示一个数字以表示连接数量，单击连接图标会弹出连接列表。可通过拖动列表中的项对该列表重新排序，并可使用右侧的 x 图标移除连接。

要移除所有输入，请右键单击输入列表所在行的任意位置，然后选择 Disconnect All Inputs。

移除多个输入：

移除连接时按住 Cmd/Ctrl，可防止弹出窗口关闭。在断开多个图层时这很有用。

生成器

生成器是一种特殊的下拉菜单。它们与下拉菜单的不同之处在于，它们实际表示一组图层，选择后这些图层会连接到父图层。

可以在其他节点上重复使用生成器内的选项。为此，请右键单击生成器并选择 Reveal Generator 选项。这会将生成器提升到场景窗口，之后可将其连接到其他生成器。例如两个 Duplicator 可以共用同一个 Distribution。注意：生成器一旦被“公开”，就无法再从场景窗口中隐藏。

复选框

复选框（又称 bool）是具有两种状态的属性。勾选时输出 1，未勾选时输出 0。
