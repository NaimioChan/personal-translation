橡皮管肢体

简介

一个简单的双骨骼 IK 系统，适用于弯曲或笔直的肢体。

界面

Start Controller：一个图形（默认为 空对象 ），可用于控制图形的顶部。

End Controller：一个图形（默认为 空对象），可用于控制图形的底部

Joint Position：确定关节位置在图形上的百分比。

Length：肢体的长度。

Taper Graph：沿图形长度创建锥形渐变（仅几何体）。参见 通用属性。

Flip：翻转关节以向另一侧弯曲。

Stretch：当控制器之间的距离大于原始图形时，拉伸图形以匹配该距离。

Curvature：设置关节的贝塞尔手柄长度。0% 为线性关节，100% 将手柄长度设为最大。

Rotation：使用命令创建 Rubber Hose 时，旋转会自动连接到 End Rotation 空对象。

Offset -

Divisions：

任何图形/线条都需要设置 Divisions，变形才能生效。

示例：

  1. 创建一个 基本线条
  2. 将 Divisions 设为 50
  3. 选中线条，从菜单中选择 Animation > Attach Rubber Hose Limb。
