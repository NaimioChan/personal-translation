曲线滤镜

简介

使用可编辑曲线校正图层的 RGB、alpha 以及色相/饱和度分量。

界面

Color Component：选择要沿可编辑图表重映射的颜色属性。前五项影响通道值，后五项基于另一项调整某一颜色属性：

  • RGB：影响红、绿、蓝通道。
  • Red：影响红色通道。
  • Green：影响绿色通道。
  • Blue：影响蓝色通道。
  • Alpha：影响 alpha/透明度通道。
  • Hue vs Hue：两个轴都表示色相。用于将特定色相范围移向另一色相，例如在不使用色轮的情况下微调橙色肤色。
  • Hue vs Saturation：横轴表示色相；曲线控制该色相处的饱和度。用于压低或提升特定颜色范围（如绿色）的饱和度，同时不影响其他颜色。
  • Hue vs Luminance：按色相选择，并改变亮度。
  • Luminance vs Saturation：横轴表示亮度（色调）；曲线控制该亮度处的饱和度。用于提升或降低特定色调范围的饱和度，例如在不影响中间调饱和度的情况下对压暗的阴影或过曝的高光去饱和。
  • Saturation vs Saturation：横轴表示像素现有的饱和度；曲线控制其最终饱和度。用于抑制已经过饱和的颜色或提升暗淡的颜色，而无需整体统一偏移饱和度。

数值曲线：

对于 RGB、Red、Green、Blue 和 Alpha 分量，图表的横轴是输入值，纵轴是输出值。位于线以下的数值会变暗，位于线以上的会变亮。

曲线后方绘制了滤镜输入的直方图。在 RGB 通道上，它会显示全部三个通道以及亮度，以便在图像数值被重映射之前预览它们。

颜色曲线：

后五条曲线的命名中，第一个词是选择像素所依据的分量，第二个词是发生变化的分量。第一个词和第二个词分别由横轴和纵轴表示。

编辑曲线

添加点

要添加点，可以：

  • 在曲线上单击，以沿曲线添加一个点。
  • 在任意位置双击，即可在该位置精确添加一个点。曲线会重新绘制以容纳新点。

移动点

单击并拖动点可移动单个点。要将多个点一起移动，可以：

  • 按住 Cmd/Ctrl 并单击多个点以选择多个点，然后点击并拖动任一已选点。
  • 在空白处点击并拖动以框选多个点，然后点击并拖动任一已选点。

设置插值

按住 Option/Alt 并单击一个点，可在以下插值之间循环切换：

  • Smooth（默认，永不过冲）。
  • Bézier（手动控制柄）。
  • Linear。

删除点

要删除一个或多个点，先选中它们，然后按 Delete 或 Backspace

重置曲线

使用 Reset 按钮清除当前曲线。按住 Option/Alt 可重置所有曲线。

目标调整

点击 eyedropper 按钮，然后在视口中点击图形。当前曲线上会在光标所在数值处放置一个点。向上或向下拖动可在该处弯折曲线。按 Escape 或再次点击该按钮可取消。

波形

波形按钮会在曲线下方加载 RGB 分量图，按水平位置绘制，每个颜色通道显示为一条带。
