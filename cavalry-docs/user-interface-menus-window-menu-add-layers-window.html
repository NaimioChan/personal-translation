添加图层窗口

简介

Add Layers 窗口是查找并添加 Cavalry 中可用图层的地方。

添加图层

要向场景中添加图层，你可以：

  1. 双击某个图层。
  2. 将图层从 Add Layers 窗口拖放到场景窗口。
  3. 使用 ⬆︎/⬇︎ 键选择图层，然后按 Return 添加所选图层。

顶部的搜索栏可用于筛选结果，也可以使用标签页按图层类型筛选结果。

信息：

使用 Cmd/Ctrl + ⬅︎/⮕ 切换标签页。

也可以通过场景窗口顶部的 + 按钮添加图层。

信息：

使用 Cmd/Ctrl + .（句点）作为快捷键，调出 Add Layers 弹出窗口。
