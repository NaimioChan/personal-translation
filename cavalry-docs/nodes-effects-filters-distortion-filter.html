扭曲滤镜

简介

通过采样着色器来扭曲图形。

界面

Settings

通用属性 +

Amplitude：决定扭曲的强度。

Sample Mode：决定如何采样 Input Shader。参见通用属性。

Invert：反转 Input Shader 的数值——0-1 的数值会反转为 1-0。

Direction Mode：设置扭曲类型：

  • Lens：将像素坐标推向或推离中心。大于 0.5 的值会远离中心，小于 0.5 的值会朝向中心。
  • Directional：沿 Direction Angle 指定的方向推动像素坐标。大于 0.5 的值会沿 Direction Angle 移动，小于 0.5 的值会向相反方向移动，例如 Direction Angle - 180。
  • Warp：将像素值重映射为方向，并沿该方向推动像素坐标。0-1 的值会重映射为 0˚-360˚ 的角度。

Curve Interpolation：决定如何重映射 Distortion Shader 的数值（仅在 Direction Mode 设为 Lens 时生效）：

  • Sine Wave：使用正弦波（s 曲线）重映射。这会生成更平滑的扭曲。
  • Linear：使用线性重映射。

Distortion Offset：增大/减小扭曲。注意：当 Direction Mode 设为 Warp 时不适用。

Automatic Padding：根据扭曲结果自动调整图形的边界框。注意：仅在 Direction Mode 设为 Directional 或 Warp 时适用。

Padding：手动调整图形的边界框，以显示/裁切扭曲结果。

Direction Angle：为 Directional 方向模式设置角度。

Use Single Direction：当 Direction Mode 设为 Directional 时，沿单一方向推动像素。所有大于 0 的值都会沿 Direction Angle 移动。

Shader

Show Preview：在视口中显示 Input Shader 的预览。

Preview Opacity：增大/减小 Input Shader 预览的不透明度。

Input Shader：选择一个着色器来驱动扭曲。
