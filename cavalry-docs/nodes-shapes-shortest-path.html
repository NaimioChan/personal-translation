最短路径

简介

通过点的分布在起点和终点位置之间寻找最短路径来生成路径。

该算法通过以下方式计算最短路径：

  1. 从 Input Path 上的给定位置开始。
  2. 在 Distribution 中搜索相邻点。默认情况下使用最近的 10 个点，也可以基于 Search Distance 搜索。
  3. 选择最接近终点位置的相邻点并移动到该点。
  4. 循环执行步骤 2 和 3，直到路径到达终点位置。

界面

Common Attributes +

Input Shape：连接一个图形，以从中生成起点和终点位置。

Count：设置要生成的路径数量。

Start Travel：设置 Shortest Path 起点在 Input Shape 上的位置。如果 Count 大于 1，可连接一个行为来为每条路径改变位置。

End Travel：设置 Shortest Path 终点在 Input Shape 上的位置。如果 Count 大于 1，可连接一个行为来为每条路径改变位置。

Use Search Radius：默认使用最近的 10 个点来计算最短路径——勾选 Use Search Radius 后，可以使用 Search Radius 获得更精细的控制。

Search Radius：设置搜索的最大半径，以找到最短路径应前往的“下一个点”。

Use Levels：勾选后，确定使用 Input Shape 的哪个层级来生成起点/终点位置。

Level Mode：选择要影响网格层级中的哪个（些）层级。

  • Custom...：手动设置 Custom Level。
  • Text (Lines)：与 Text Shape 一起使用时，将影响每个行。
  • Text (Words)：与 Text Shape 一起使用时，将影响每个单词。
  • Text (Characters)：与 Text Shape 一起使用时，将影响每个字符。

子网格：

如果将字符串为 TEXT 的 文本图形 用作 Input Shape，则可用 Level Mode 来确定起点/终点位置的生成范围。例如，若设为 Text (Characters)，起点和终点都必须位于每个单独的字母上（T、E、X 或 T）；而若设为 Text (Words)，起点和终点可以在整个单词的任意位置生成。例如，起点可以位于第一个 T 上，终点可以位于 X 上的某处。

Custom Level：设置自定义层级。

Points Distribution：选择一个分布来创建供 Shortest Path 算法搜索的点。

绘制调试信息：

Shortest Path 支持视口设置中的 Draw Debug Information 选项，可用于预览 Points Distribution 中的点。

示例：

  1. 创建一个 Ellipse。
  2. 将其 Radius 设为 200,200。
  3. 创建一个 Shortest Path。
  4. 连接 ellipse.id→shortestPath.inputShape
  5. 将 Shortest Path 的 Count 设为 20。
  6. 右键点击 Start Travel 属性并选择 Add Behaviour > Random。
  7. 将 Random 的 Maximum 设为 1。
  8. 更改 Shortest Path 上 Random Distribution 的 Seed 值。

遮罩分布：

可以使用 遮罩分布 确保只有图形内部的点会被考虑用于 Shortest Path。
