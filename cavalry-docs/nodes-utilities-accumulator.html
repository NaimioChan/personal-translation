累加器

简介

创建图形的“堆叠”或自定义布局。

当连接到复制器或子网格变形器时，Accumulator 会为每个正在计算的网格加上 Value 中的数值。

界面

Value - 设置要累积的值，或连接一个行为。

Padding - 在每个图形之间添加间隙。

Offset - 在输出上加上或减去一个值。

示例：

  1. 创建一个矩形。
  2. 单击 Deformers 属性并选择对齐。
  3. 将 Align 的 X 属性设为 1。
  4. 选中矩形后，单击工具架中的复制器图标，将其添加到复制器。
  5. 将复制器的 Distribution 设为 Point。
  6. 在属性编辑器中，右键单击矩形的 Size 属性并选择 Add Behaviour > Random。
  7. 将随机行为的 Minimum 设为 50，Maximum 设为 150。
  8. 取消勾选随机行为的 Use Layer as Seed 属性。
  9. 创建一个 Accumulator。
  10. 连接 accumulator.id→duplicator.shapePosition.x
  11. 连接 rectangle.size.w→accumulator.value

这些矩形会并排排列，并尊重彼此的宽度。尝试增加复制器上的 Count，或更改随机行为上的 Seed。
