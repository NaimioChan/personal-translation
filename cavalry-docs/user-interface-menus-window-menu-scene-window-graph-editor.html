曲线编辑器

简介

曲线编辑器可用于编辑关键帧及其产生的动画曲线。动画曲线是绘制在关键帧之间的线，表示关键帧值变化的速度，也称为“插值”。通过操纵关键帧的手柄，可以使用缓动创造更自然的运动。

同时也支持预览程序化动画曲线。例如，如果将噪声行为连接到图形的 position.x，产生的动画曲线就可以显示在曲线编辑器中。

界面

调整动画曲线

要将关键帧及其动画曲线载入曲线编辑器，可以任选以下方式：

  • 在场景树中选择一个或多个图层——这将载入所有已设置动画的属性。
  • 在场景树中选择一个或多个属性——这将载入所有选中的已设置动画的属性。
  • 在时间编辑器中选择一个或多个关键帧——切换到 Graph Editor 时，这将载入与所选关键帧关联的所有属性。

已设置动画的属性载入曲线编辑器后，选择关键帧即可进行调整。

  • 将关键帧上/下移动可增大/减小其值。
  • 将关键帧左/右移动可在时间上向后/向前移动它们。

信息：

要显示贝塞尔手柄，请选择一个或多个关键帧或一条动画曲线。

可以通过操纵关键帧的贝塞尔手柄来调整动画曲线。关键帧有 3 种基本插值（或状态）：

  • Linear：产生的动画曲线为直线，表示两个关键帧之间均匀的变化速率。
  • Bézier：产生的动画曲线为曲线，表示两个关键帧之间平滑的变化速率。贝塞尔关键帧可用于让值缓入缓出。
  • Step：产生的动画曲线为 L 形，表示关键帧之间值不发生变化。也称为“保持”关键帧，当播放头到达每个关键帧时，值会突然跳变。

要更改关键帧的插值，可以任选以下方式：

  • 选择一个或多个关键帧 > 右键单击 > Key Interpolation，然后选择一个选项。
  • 选择一条或多条动画曲线 > 右键单击 > Curve Interpolation，然后选择一个选项（这将转换该动画曲线上的所有关键帧）。

Bézier 关键帧在曲线编辑器中显示手柄。移动手柄将改变动画曲线。有关如何操作手柄，请参见下面的快捷键。

双击以编辑：

双击关键帧会弹出窗口，其中的选项可用于就地设置关键帧的属性。

  • Value：设置该关键帧的属性值。
  • Interpolation：设置该关键帧的插值。
  • Magic Easing：为Magic Easing 选择一个选项。
  • Bézier Handle Positions：设置该关键帧贝塞尔手柄的位置。通过 Use Absolute Bezier Positions 首选项，这些位置可以是绝对值或相对值。
  • Angle Locking：当关键帧的 Interpolation 设为 Bézier 时，勾选后，改变一个手柄的角度会由另一个手柄镜像。
  • Weight Locking：当关键帧的 Interpolation 设为 Bézier 时，勾选后，调整一个手柄的长度会按比例影响另一个手柄的长度。

循环

要为动画曲线设置循环，请选择一条或多条曲线并右键单击以调出上下文菜单。可选择：

  • Loop Settings...：打开 Loop Settings 会显示以下选项：
    • Mode：见下文。
    • Limit Loops：勾选后，指定动画曲线应循环的次数（在初始动画曲线之外）。
    • Filter Last Keyframes：勾选后，可将循环限制为指定数量的关键帧。例如，值为 2 时会播放完整的动画曲线，然后只循环最后 2 个关键帧。请注意，动画曲线必须至少包含 3 个关键帧。
  • Loop After：循环将在最后一个关键帧之后发生：
    • None：不循环。
    • Looping：以第一个关键帧的值开始循环。
    • Looping with Offset：以最后一个关键帧的值开始循环。
    • Oscillate：在第一个和最后一个关键帧之间往返。
  • Loop Before：循环将在第一个关键帧之前发生：
    • None：不循环。
    • Looping：以第一个关键帧的值开始循环。
    • Looping with Offset：以最后一个关键帧的值开始循环。
    • Oscillate：在第一个和最后一个关键帧之间往返。

也可以使用窗口底部工具栏中的按钮。

按住 Option/Alt 并双击动画曲线也会打开 Loop Settings... 窗口。

程序化动画曲线

当图形的动画由另一个图层驱动时，其继承的动画曲线也可以在曲线编辑器中预览。例如，如果将噪声行为连接到图形的 Position，在 Graph Editor 中选择该图形就会预览其动画曲线。

动画偏移也是如此。

工具

关键帧图层

参见关键帧图层。

关键帧值

Frame：在选中一个或多个关键帧的情况下，设置该关键帧的帧号。

Value：在选中一个或多个关键帧的情况下，设置该关键帧的值。

变换工具

变换工具可用于移动和缩放选中的关键帧。启用该工具后，所选关键帧周围会出现绿色区域。Click + drag：

  • 绿色区域的中部可移动所选内容。
  • 绿色区域的边缘可水平或垂直缩放关键帧。
  • 绿色区域的角可同时水平和垂直缩放关键帧。

从边缘缩放时按住 Option/Alt，可从绿色区域中心缩放关键帧。

网格吸附

勾选后，关键帧将吸附到定义的增量。使用复选框启用并设置网格的大小。

残影

启用后，对关键帧或手柄进行调整时，会绘制一条淡线，显示动画曲线原来的位置。

绘制通道名称

启用后，属性名称将显示在曲线编辑器左侧。

节奏标记

添加参考线以标示秒或音频节拍。切换按钮可启用/禁用它们，或使用箭头打开包含以下选项的展开窗口：

Mode：选择一种模式：

  • Seconds：在每一秒添加节奏标记。
  • Beats per Minute：基于 BPM 添加节奏标记。

Divisions：当 Mode 设为 Seconds 时，确定在每秒之间添加多少个子步。

Beats per Minute：当 Mode 设为 Beats per Minute 时，为音轨设置 BPM。灰色参考线代表节拍，蓝色参考线标示小节。

Offset：当 Mode 设为 Beats per Minute 时，在时间上向前或向后移动标记。

Beats per Bar：当 Mode 设为 Beats per Minute 时，设置每个小节的节拍数。

循环

参见上文。

缓冲区

通过保存缓冲区，可以保存动画曲线并在之后恢复。这在尝试动画的时序和缓动时很有用。

  • Snapshot Buffer Curve：将选中的动画曲线保存到缓冲区。
  • Swap Buffer Curve：如果已为选中的动画曲线保存了缓冲区，则在保存的缓冲区与这些曲线的任何最近更改之间切换。

插值

设置关键帧之间动画曲线的插值：

  • Linear：相邻关键帧之间的直线。
  • Bézier：在关键帧之间绘制贝塞尔曲线，可使用手柄手动调整每条曲线的形状。
  • Stepped：动画曲线将保持一个关键帧的值，然后跳变到下一个关键帧的值。
  • Stepped Next：动画曲线将立即跳变到下一个关键帧的值，并保持该值直到下一个关键帧。
  • Auto-Bézier：相邻之间的切线平滑，并在峰值和谷值处自动变平，因此曲线永远不会超出关键帧值。
  • Plateau：与 Auto-Bézier 相同，但第一个和最后一个关键帧被强制展平。这是最严格的不过冲变体——保证曲线上的最大值和最小值恰好位于关键帧处。
  • Spline (allows overshoot)：Auto-Bézier 的更平滑版本，不进行展平，意味着曲线可以过冲关键帧值以保持连续性。这允许曲线略微高于或低于两个相邻关键帧的值，在需要最大平滑度时很有用。
  • Clamped (allows overshoot)：与 Spline 类似，但当关键帧的值接近其相邻关键帧时，切线会变平为线性。这对于防止近似相等的保持关键帧之间出现“脚滑”很有用。

贝塞尔

连接或断开贝塞尔手柄。

对齐

将从多个属性选择的动画曲线或关键帧彼此对齐，或对齐到播放头。当左/右对齐时，所有选中的动画曲线/关键帧将对齐到最左/最右的关键帧。当居中对齐动画曲线/关键帧时，它们将对齐到所有选中的动画曲线/关键帧的平均位置。

按住 Option/Alt 可对齐到播放头（当前时间）。
