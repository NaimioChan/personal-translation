动态渲染

简介

动态渲染可用于在渲染时生成不同的值，从而为同一个合成创建大量变体。

  • 为某些抽象的程序化美术作品/动画创建变体。
  • 自动化原本耗时且易出错的工作流程。
  • 为片尾画面设置版本管理。
  • A/B 测试。
  • 输出个性化广告。
  • 以及更多……

动态渲染的选项位于渲染管理器中。

设置动态渲染

动态渲染由两个主要部分组成：

  • Dynamic Index：位于渲染管理器顶部栏中的属性，每次渲染完成后其输出值递增 1。
  • Render Range：位于 Render Queue Item（RQI）的 Dynamic 标签页下的属性。此处设置的值决定 Cavalry 渲染该 RQI 的次数（注意：必须勾选 Dynamic Render）。

如果将 Render Range 设为 0,2，Cavalry 将渲染该 Render Queue Item 3 次。第一次渲染时，Dynamic Index 输出 0，第二次渲染输出 1，第三次则输出 2。这个简单的概念可用于为每次输出创建变化。

在下面的简单示例中，Polygon 的边数由一个已连接到 Dynamic Index 的值数组 驱动。将 Dynamic Index 拖拽连接到 颜色数组 的 Array Index 后，Polygon 的 Fill Colour 和 Sides 都会在渲染时发生变化。

可以使用 Dynamic Index Offset 预览结果。

  • 值为 0 时输出 Color Array 上的第一个索引（绿色）。
  • 值为 1 时输出第二个（黄色）。
  • 值为 2 时输出第三个（粉色）。

要输出全部三种变体，将 Dynamic 标签页下的 Render Range 设为 0,2。渲染过程中，Cavalry 会依次遍历 Dynamic Index 的 0、1 和 2，并为每个值输出一个单独的文件。

下面的示例使用了相同的技术，但通过一个包含队伍名称和十六进制值的 电子表格 节点来驱动 文本图形 和彩色背景图形。Logo 的设置为：将两个 SVG Assets 添加到 资源数组，然后连接到 SVG Shape。

想象一下，当你的客户想要把高度改成 40px 时，这对全部 32 支 NFL 球队来说能节省多少时间！你只需修改一次，然后点击 Render，剩下的繁重工作交给 Cavalry 来完成。

文件名

默认情况下，使用 动态渲染 时，文件会写入与 Dynamic Index 对应的单独目录（0、1、2……），以防止文件互相覆盖。另一种方式是，将 <Dynamic> 渲染令牌添加到 Render Manager 中的 File Name。该令牌会把 Dynamic Index 的编号添加到 File Name 中，这意味着文件会直接写入指定的 Path。

你可以取消勾选 Render Manager 的 Dynamic 标签页中的 Ensure Unique File Names 来覆盖此行为。取消勾选后，需要由你自己确保文件不会互相覆盖。

通过将 字符串 连接到 File Name 属性，可以创建唯一且动态的文件名。例如，将 电子表格 数据连接到 String，就可以在渲染时使用电子表格每一行的内容来生成每次输出的文件名。只要每一行的数据都是唯一的，每个文件名就会是唯一的。通过 Formatted String 的 String Generator 还可以进一步扩展此功能，它可以将多个字符串串联起来。

渲染令牌（例如 <Composition>）也可以在 String 中使用。请注意，只有在 Render Queue Item 中查看时，渲染令牌才会以青色样式显示（表示有效）。
