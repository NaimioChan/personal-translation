空对象

简介

空对象可绘制（在视口中可见），但不可渲染（不会出现在任何输出中）。它们最常用于绑定，但在许多其他场景中也经常使用。

界面

通用属性 +

Shape：设置空对象的类型。

  • Cross：将空对象设为十字准星。
  • Circle：将空对象设为圆形。
  • Square：将空对象设为矩形。

Custom Color：默认情况下，空对象使用其标签颜色；勾选 Custom Color 后，空对象将使用 Color 属性设置的颜色。

Color：为空对象设置自定义颜色。

Limit Position：启用后，空对象的位置会被限制在 Minimum Position 与 Maximum Position 值之间。

Minimum Position：设置一个值以限制空对象的最小位置 [x,y]。

Maximum Position：设置一个值以限制空对象的最大位置 [x,y]。

Draw Position Limits：在视口中显示位置限制。

Limit Rotation：启用后，空对象的旋转会被限制在 Minimum Rotation 与 Maximum Rotation 值之间。

Minimum Rotation：设置一个值以限制空对象的最小旋转。

Maximum Rotation：设置一个值以限制空对象的最大旋转。

Limit Scale：启用后，空对象的缩放会被限制在 Minimum 与 Maximum Scale 控件之间。

Minimum Scale：设置一个值以限制空对象的最小缩放 [x,y]。

Maximum Scale：设置一个值以限制空对象的最大缩放 [x,y]。

信息：

快捷键 Shift + Cmd/Ctrl + = 可创建一个 Null。
