帧

简介

使用并操控时间以驱动其他属性。

界面

Common Attributes +

Value：为 Time 设置一个乘数。最终输出为 Value × Time × Strength + Offset

Interpolation Mode：决定输出值的计算方式：

  • Frame：输出当前的 frame × Value
  • Seconds：每秒递增该值（取决于合成的 Frame Rate）。

Cycle Length：当 Interpolation Mode 设为 Seconds 时，设置增加“value”需要多少秒。

Graph：当 Interpolation Mode 设为 Seconds 时，调整该值在一秒内的插值。参见 图表属性。

Offset：设置一个加到输出值上的值。也用作保持值（× StrengthStart Frame。

Start Frame：设置 Time 开始递增的帧。此帧之前，输出为 Offset × Strength

Time：来自时间轴的当前帧。默认为合成的时间。

示例：

  1. 创建一个 Basic Line。
  2. 将其 Pivot.X 设为 100。
  3. 右键单击 Basic Line 的 Rotation 属性，选择 Add Behaviour > Frame。
  4. 设置 Frame 行为的：
    • Interpolation Mode 为 Seconds。
    • 打开 Graph，将左侧点的 Position 设为 0.95。
    • 将 Value 设为 -6（时钟的秒针每秒旋转 6°）。
  5. 按播放。

这将创建一只滴答作响的时钟的秒针。
