矩形

简介

作为 基本图形 的一部分创建 Rectangle 基础图形。

界面

Size - 设置矩形的尺寸 [w, h]。

Radius Mode - 确定是在全局设置圆角半径，还是逐个角设置：

  • All - Corner Radius 设置将设定所有角的半径。
  • Individual - 通过 Top 和 Bottom Radii 分别设置每个角。

Corner Radius - 设置矩形各角的半径。

Top Radii - 设置顶部各角的半径 [l, r]。

Bottom Radii - 设置底部各角的半径 [l, r]。

Chamfer - 对矩形的角进行切角。

Edge Divisions - 设置 [w, h] 的分段数

Vectorize - 将各角从贝塞尔（默认）转换为多边形。

Corner Divisions - 设置矢量化曲线的分段数。
