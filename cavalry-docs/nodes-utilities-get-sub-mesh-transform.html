获取子网格变换

简介

获取子网格中任意图形的变换（位置、旋转、缩放）。例如，将另一个图形的位置连接到复制器或Forge Dynamics 图形 的 pointId 4，或文本图形中的第三个字符。

有关子网格的更多信息，请参阅子网格。

界面

Input Shape：连接一个子网格图形（例如复制器、文本图形等）。

Use Bounding Box：勾选后，使用子网格包围盒的中心，而不是子网格的变换。当使用文本图形作为 Input Shape 时，这很有用，因为文本图形中的单词或行不提供变换信息。

Level Mode：选择要影响子网格的哪个（些）层级。

  • Custom...：手动设置 Custom Level Range。
  • Text (Lines)：与文本图形配合使用，将影响每个行。
  • Text (Words)：与文本图形配合使用，将影响每个单词。
  • Text (Characters)：与文本图形配合使用，将影响每个字符。

Sub-Mesh Index：设置要作为目标的子网格图形的 Id。

Position：一个只读属性，可用于连接到另一个图形的 Position 属性。

Rotation：一个只读属性，可用于连接到另一个图形的 Rotation 属性。

Scale：一个只读属性，可用于连接到另一个图形的 Scale 属性。
