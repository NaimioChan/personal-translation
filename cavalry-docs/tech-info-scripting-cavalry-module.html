Cavalry 模块

简介

此模块提供对 Path 类的访问、用于创建 noise 和 random 数字的函数，以及一系列让颜色处理更简便的工具，还有 clamp、norm、map 和 dist 等大量数学函数。以下方法可用于 JavaScript 工具 和 JavaScript 编辑器。此模块中的所有内容都位于 cavalry 命名空间中，因此方法需要加上 cavalry. 前缀，例如 var distance = cavalry.dist(0,0,100,200);

给出的示例用于 JavaScript 编辑器（运行示例所需的设置较少）。

JavaScript 变形器还可以访问 def 模块，该模块提供访问和修改被变形几何体的方法。

成员函数

Path 类

Cavalry 模块包含一个 Path 类，可用于构建路径，随后在屏幕上绘制。Path 本身包含若干方法。

其中一些方法使用 'param' 或 'parameter' 一词。这是一个 0 到 1 之间的数字，表示沿曲线控制笼从 0（起点）到 1（终点）的进度。控制笼由曲线的控制点构成，勾勒出曲线的基本形状。请注意，'param' 值为 0.5 并不一定代表曲线一半长度处的位置。这是因为受曲线控制点及其最终形状的影响，param 值与曲线长度之间的关系并非线性。要将长度值转换为 param 值，请使用 paramAtLength。

复制图形：

在 视口 中右键单击一个图形并选择 Copy as JavaScript，会将图形的信息以 JavaScript 代码形式复制到剪贴板。

绘制路径：

var path = new cavalry.Path();


path.moveTo(0.,0.);


path.lineTo(0.,-100.);

path.addRect(-300,-300,-200,-250);


path.addEllipse(250, -300, 100,60);


// this path can then be returned if on the JavaScript layer


// or used to create an Editable Shape like so

moveTo(x:number, y:number)

开始一个新的轮廓。

lineTo(x:number, y:number)

绘制一条到 x,y 的直线。

cubicTo(cp1X:number, cp1Y:number, cp2X:number, cp2Y:number, endX:number, endY:number)

使用两个控制点和一个端点绘制三次贝塞尔曲线。

quadTo(cp1X:number, cp1Y:number, endX:number, endY:number)

向路径添加一条二次贝塞尔曲线。

arcTo(cp1X:number, cp1Y:number, cp2X:number, cp2Y:number, radius:number)

使用两个控制点和一个半径绘制弧线。

conicTo(cp1X:number, cp1Y:number, endX:number, endY:number, weight:number)

向路径添加一条圆锥曲线。其中 weight：

  • = 1：曲线为二次贝塞尔曲线（权重为 1 的圆锥曲线在数学上等同于二次曲线）。
  • < 1：曲线近似椭圆。权重越小，曲线越倾向于圆形，权重更小时曲线也更尖锐。
  • > 0：曲线开始类似双曲线。随着权重增加，曲线开口更大。
  • = 0（或非常小的值）：可能产生退化情况，或视觉上与直线或极尖锐曲线相比没有太大变化的曲线。

pathData() → object

此函数返回一个字典数组，提供一种便捷方式来迭代和修改现有路径，而不必创建新的 Path 类。每个字典包含动词 type 变量（例如 moveTo 或 lineTo），以及与该动词相关的任何 'point' 对象。

根据动词类型，字典包含不同的对象：

  • moveTo：包含一个 point 对象（含 x 和 y 变量）。
  • lineTo：包含一个 point 对象（含 x 和 y 变量）。
  • quadTo：包含一个表示控制点的 cp1 对象（含 x 和 y 变量），以及一个 point 对象（含 x 和 y 变量）。该 point 是 quadTo 动词的端点。
  • cubicTo：包含表示第一和第二个控制点的 cp1 和 cp2 对象（均含 x 和 y 变量），以及一个 point 对象（含 x 和 y 变量）。该 point 是 cubicTo 动词的端点。
  • close：不包含任何点。

resample(edgeLength:number)

基于所需的 'edgeLength' 采样点来重建路径。

/*


1. Create a Text Shape.


2. Click the + button on the Text Shape's 'Deformers' attribute and choose 'JavaScript Deformer'.


3. Paste the below into the JavaScript expression.


*/





var depth = 3;


var frequency = 5;


var multiplier = n0;





var meshes = def.getMeshesAtDepth(depth);





for (var mesh of meshes) {


    var path = mesh.getPathAtIndex(0);


    path.resample(5);





    var pd = path.pathData();


    for (var idx = 0; idx < pd.length; idx++) {


        if (idx % frequency == 0) {


            let line = new cavalry.Line(0,0,pd[idx].point.x, pd[idx].point.y);


            line.setLength(line.length()+multiplier);


            pd[idx].point = line.end();


        }


    }


    path.setPathData(pd);


    mesh.setPathAtIndex(0, path);


}

1. Create 2 Nulls, an Ellipse and a JavaScript Shape.


2. Right click the JavaScript Shape's n0 attribute and choose 'Delete Selected Attribute'.


3. Use the + button to add 2 x Double2 and 1 x Layer attributes.


4. Connect each of the Null's positions to the Double2 attributes.


5. Connect the Ellipse to the Layer attribute.


6. Copy and paste the below into the JavaScript Shape's Expression.


7. Move the Nulls outside the Ellipse.

function getPath() {


    var intersectionPath = n2.path;





    var path = new cavalry.Path()


    var line = new cavalry.Line(n0.x, n0.y, n1.x, n1.y);





    var intersections = intersectionPath.lineIntersections(line);





    for (let pt of intersections) {


       path.addEllipse(pt.x,pt.y,20,20);


    }


    return path;


}

measureText(string:string, fontFamily:string, fontStyle:string, fontSize:int) → {width:number, height:number, x:number, y:number, centreX:number, centreY:number}

返回一个表示某段文本边界框的对象，无需实际创建文本图形。

  • width：文本的宽度
  • height：文本的高度
  • x：文本的左边缘
  • y：文本的上边缘
  • centreX：左右边缘的平均值
  • centreY：上下边缘的平均值
var measure = cavalry.measureText("Some text to measure", "Lato", "Regular", 72);


console.log(JSON.stringify(measure));

fontMetrics(fontFamily:string, fontStyle:string, fontSize:int) → {top:number, ascent:number, descent:number, bottom:number, leading:int, averageCharacterWidth:number, maxCharacterWidth:number, xMin:number, xMax:number, xHeight:number, capHeight:number}

返回一个包含给定字体信息的对象。所得度量值会按字体大小缩放。

  • top：任一字形边界框在原点之上的最大范围，通常为负值；在可变字体中已弃用
  • ascent：基线上方需保留的距离，通常为负值
  • descent：基线下方需保留的距离，通常为正值
  • bottom：任一字形边界框在原点之下的最大范围，通常为正值；在可变字体中已弃用
  • leading：行间需增加的距离，通常为正值或零
  • averageCharacterWidth：平均字符宽度，未知时为零
  • maxCharacterWidth：最大字符宽度，未知时为零
  • xMin：任一字形边界框在原点左侧的最大范围，通常为负值；在可变字体中已弃用
  • xMax：任一字形边界框在原点右侧的最大范围，通常为正值；在可变字体中已弃用
  • xHeight：小写字母 'x' 的高度，未知时为零，通常为负值
  • capHeight：大写字母的高度，未知时为零，通常为负值
var metrics = cavalry.fontMetrics("Lato", "Regular", 72);


console.log(JSON.stringify(metrics));

工具

versionLessThan(version:string) → bool

如果当前使用的 Cavalry 版本低于指定版本，则返回 true。这有助于在脚本中为依赖 Cavalry 版本的功能提供支持。

// This will return true in Cavalry 1.3.1, and false in Cavalry 1.5.0


console.log(cavalry.versionLessThan("1.4.0"));

SEMVER：

Cavalry 的版本号采用语义化版本。

MAJOR.MINOR.PATCH（例如 1.5.0）用于正式版本。

MAJOR.MINOR.PATCH.PRE-RELEASE-TYPE.NUMBER（例如 2.0.0-beta.1）用于预发布构建。
