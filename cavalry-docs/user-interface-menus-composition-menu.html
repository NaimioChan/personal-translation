合成菜单

New Composition：向场景添加一个新的合成。

New Composition from Preset：向场景添加一个新的合成并应用预设。此命令也可以通过右键单击资源窗口页脚中的合成图标来运行。

Composition Settings...：调整合成相关属性，包括 Resolution、Start/End Frame、FPS 和运动模糊。请参阅合成设置。

Pre-Compose：创建一个新的合成，将选中的图层添加到其中，并把新合成放入当前合成内。新合成将继承当前合成的 Resolution、Frame Range 和 Frame Rate。

Pre-Compose based on Selection Bounds：创建一个新的合成，将选中的图层添加到其中，并把新合成放入当前合成内。新合成将根据所选图形的边界框继承其 Resolution，并在当前合成中调整位置，使这些图形保持原位。

Close Composition：关闭当前合成。注意：这需要场景窗口中打开多个合成。

Close Other Compositions：关闭除当前活动合成之外的所有其他已打开的合成。

Set Composition to Playback Range：将合成的起始帧和结束帧设置为播放范围。

Set Playback Range to [Selection/Composition]：此菜单项取决于当前选择：

  • Selection：将 Playback Range 设为所有选中图层中最早和最晚的帧。
  • Composition：如果未选择任何内容，则将 Playback Range 设为合成的起始帧和结束帧。

Set Playback Start to Current Frame：将合成的播放范围起点设置为当前帧。

Set Playback End to Current Frame：将合成的播放范围终点设置为当前帧。

Go to Playback Start：将播放头移动到合成的 Playback Range 起点。

Go to Playback End：将播放头移动到合成的 Playback Range 起点。

Go to Composition Start：将播放头移动到合成的 Frame Range 起点。

Go to Composition End：将播放头移动到合成的 Frame Range 终点。

Go to Previous Time Marker：将播放头移动到左侧最近的时间标记位置。

Got to Next Time Marker：将播放头移动到右侧最近的时间标记位置。

Move Forward：将播放头向前移动 1 帧。

Jump Forward：将播放头向前移动首选项窗口中 Nudge Step 值所定义的帧数。

Move Backward：将播放头向后移动 1 帧。

Jump Backward：将播放头向后移动首选项窗口中 Nudge Step 值所定义的帧数。

Solo Selection in Viewport/Clear Viewport Soloing：此菜单项取决于当前选择：

  • Solo Selection in Viewport：将选中的图层添加到 Quicklist，并将模式设为 Filter Viewport。请参阅标签。
  • Clear Viewport Soloing：在未选择任何内容时，此命令会取消选择 Quicklist，以移除所有视口过滤。请参阅标签。

Clear Quicklist：从 Quicklist 中移除所有图层。

Enable Time Remapping：在场景窗口中选中合成后，运行此命令会添加一个 Time Remapping 属性，并在合成的第一帧和最后一帧上放置关键帧。第一个关键帧的值设为 0%，最后一个设为 100%。它们表示合成时长上的百分比。之后可以编辑这些关键帧，以提高或降低合成的原始播放速度。例如，将最后一个关键帧重新定位到合成长度的一半处（比如将其拖向第一个关键帧），会使播放速度加倍。

循环合成：

当一个合成被放置在另一个合成内（也称为 Pre-Comp）时，可以使用 Time Remapping 来循环其动画。操作如下：

  1. 在场景窗口中选择要循环的合成。
  2. 转到 Composition > Enable Time Remapping。
  3. 选择 Time Remapping 动画曲线（可以在场景树中选择该属性，也可以在时间编辑器或曲线编辑器中选择 keybar（连接关键帧的线））。
  4. 右键单击 > Loop After > Looping。
  5. 根据需要，在时间编辑器中延长 Pre-Comp 的片段。

Toggle Background Alpha：将当前合成的 Background Alpha 设为 0 或 255。
