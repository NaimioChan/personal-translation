图形菜单

Make Editable：将原始图形（例如椭圆）转换为几何体。

Make Editable Copy：复制原始图形（例如椭圆）并转换为几何体。

Bake Selected Shape：制作图形的一个副本，并将任何变形烘焙到其中。

Separate：将所有闭合路径转换为独立的图形。

Separate to Editable：将所有闭合路径转换为独立的图形，并转换为可编辑图形。

Merge：将多个图形合并为一个图形。注意：这不是布尔运算。

Merge to Editable：将多个图形合并为一个可编辑图形。注意：这不是布尔运算。

Centre Pivot：将轴心移动到图形边界框的中心。

Centre Pivot (Centroid)：将轴心移动到图形的质心。这也可用于寻找图形的视觉中心。

Freeze Transform：将选中图形的当前变换设为零。

Reset Transform：将变换（位置、旋转、缩放、倾斜和轴心）重置为默认值。

Add Background to Selected：为每个选中的图形创建一个连接到矩形的边界框，并将每个选中的图形添加到每个边界框的 Input Shapes 属性中。

Swap Fill/Stroke：交换图形填充与描边的状态和颜色。例如，如果一个图形有红色填充且没有描边，运行此命令后将得到一个没有填充、描边为红色的图形。注意，这不适用于着色器。

Close Contour：闭合开放的轮廓。

Open Contour：打开闭合的轮廓。

Join Contours：将同一路径上不同轮廓的两个端点连接起来，形成一个轮廓。

Split Path at Selection：根据选中的点（最多 2 个）拆分路径。

  • 开放路径：
    • 选中一个点后，在该点处将路径拆分为两个开放轮廓。
  • 闭合路径：
    • 选中一个点后，在该点处打开路径。
    • 选中两个点后，在这两个点之间将路径拆分为两个闭合轮廓。

Reverse Contour(s)：反转轮廓的方向。

Set First Point：将选中的点设为 Point Index 0。

Join Bézier Handle：如果贝塞尔手柄被解除锁定/断开，将其与相对的手柄连接，使移动其中一个时另一个也随之移动。

Break Bézier Handle：如果贝塞尔手柄被锁定/连接到相对的手柄，则断开它，使两者可以独立移动。

Convert to Corner Point：将贝塞尔点转换为角点。

Convert to Bézier Point：将角点转换为贝塞尔点。

Delete Selected Points：移除所有选中的点。

Delete Selected Points and Split Path：移除所有选中的点及其关联的边。

Boolean (Union)：将选中的图形合并在一起。

Boolean (Subtract)：从第一个选中的图形中移除其余选中的图形。

Boolean (Intersection)：移除第一个选中图形之外的所有内容，只保留重叠区域。

Boolean (Exclude)：只显示不重叠的区域（与相交相反）。

提示：

布尔运算会根据所选图形的结果创建一个新的可编辑图形。第一个图形会受到随后添加到选择中的任何图形的影响。
