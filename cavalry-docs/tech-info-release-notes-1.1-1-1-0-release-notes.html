1.1 版本说明

新功能

  • Lottie 导出：可在 File 菜单或 Render Queue Item 的 Formats 标签页中找到。
  • 布局图形：水平、垂直和网格布局。要开始使用，选择一些图形，在视口中右键单击并选择“Embed in Layout”选项之一。
  • Bake Animation：支持烘焙非关键帧动画。可在Animation 菜单下找到。
  • Skew：现在可以倾斜图形，作为其 Transform 的一部分。
  • 可见性序列：该行为可用于连接到复制器的 Shape Visibility，以便按顺序显示/隐藏副本。
  • Capsule Primitive：Tools 窗口中提供的新基础图形。
  • **String Length** 工具：统计字符串中的字符数量，并将其作为数字输出。
  • Composition Preferences：现在可以通过 Preferences 窗口中的新标签页设置默认分辨率、帧率和合成范围。
  • Control Centre 窗口：将属性编辑器中的任意属性提升到此窗口，为场景中的重要控制项创建一个通用的访问位置。你可以通过在属性编辑器中右键单击属性并选择 Add to Control Centre 或 Remove from Control Centre 来添加和移除属性。
  • Apply Layout Deformer 可以让你获取现有的一组网格（例如由复制器创建的对象），并将它们按布局排列。
  • PSD Import（拼合）。
  • 新增了 Tip Window！你可以从 Help 菜单或消息栏中的胶囊按钮打开它。你可以在 首选项 窗口中关闭该胶囊按钮。
  • 新增 矩形图案 图形。你可以用它在一行或一个环形中创建矩形的虚线图案。适合用于为 FUI 创建控件、条形码、饼图和堆叠条形图。
  • 获取名称 工具可以获取图层的名称，然后你可以将其传递到其他对象中，例如 Text 图形。
  • 现在你可以将图片粘贴到 Cavalry 中。如果你设置了项目，图片将保存到你的资源文件夹中；否则，如果你的场景已保存，图片将保存到该位置。如果没有保存场景，图片将被放置在桌面上。
  • 按 U 键可在场景窗口中单独显示选中的图层及其动画。
  • 打乱分布：可用于重新排列来自任何其他分布的点。
  • Render notifications。可在 首选项 中设置。

图形编辑

  • Join Contours：当路径中包含多个开放轮廓时，选中任意两个端点，即可使用 Shape > Join Contours 命令将两者连接起来。
  • Open Contour：对闭合轮廓执行 Shape > Open Contour 命令，将在“第一个点”处将其打开。注意：目前需要至少选中一个点。
  • Set First Point：执行 Shape > Set First Point 会将最后选中的点设为 Point Index: 0。该命令也可在 Edit Shape 工具的右键上下文菜单中使用。
  • Enable/ Disable Bezier Weight Locking：现在可以在加权与不加权的贝塞尔控制柄之间切换（目前仅可从 Edit Shape 的右键上下文菜单中使用）。
  • Point Snapping：视口中的新吸附选项。启用后，你可以吸附到路径上的其他点（任何选中的图形都可用于点吸附）。
  • Onion Skinning：可编辑图形现在具有 Onion Skinning 属性（默认开启）。在视口中启用 Onion Skinning 后，你可以预览任何路径动画的前/后帧。使用视口按钮中的设置可自定义其外观。
  • Points Transform Tool：现在可以使用 Edit Shape 工具变换选中的点。目前可通过视口顶部工具选项中的复选框启用。注意：旋转和缩放对路径动画不起作用。
  • Delete point and edges：删除路径上的点时按住 alt，可在删除点处拆分路径。这会打开闭合路径。
  • Pencil Tool improvements：铅笔工具现在绘制的路径更优化（更干净）。
  • Pen tool 现在支持角度吸附、吸附到正在编辑的图形上的点，以及 Snapping 弹出面板中的其他设置。
  • 使用 Pen/Pencil 绘制时，现在会添加到任何选中的 Editable Shape 中。
  • 现在可以在可编辑图形之间复制/粘贴路径。
  • Shapes 菜单中的 Make Editable Primitives 复选框。
  • Make Editable（Cmd/Ctrl + E）现在会删除原始图形。
  • Make Editable copy（Shift + Cmd/Ctrl + E）会保留旧行为，即同时保留原始图形。
  • Make Editable 现在会尝试保留材质。目前不支持着色器。
  • Separate to Editable 已添加到 **Shape 菜单。**

Edit Shape 工具

  • Edit Shape 工具已完全重写，现在支持编辑非常密集的路径。
  • Edit Shape 工具的界面已更新。控制柄现在为圆形，角点为方形，贝塞尔点为圆形。
  • 现在可以使用 Edit Shape 工具同时编辑多个图形。
  • 在 Edit Shape 工具中悬停到点上时会显示工具提示，显示该点的索引。
  • 在 Edit Shape 工具中，轮廓中的第一个点现在会以黄色高亮显示。
  • 双击某个点将选中该轮廓中的所有点。
  • 按住 Shift 双击某个点将选中该路径中的所有点。
  • 不可编辑图形的点在 Edit Shape 工具中有了新的外观。
  • 现在可以使用套索工具选择图形点（按住 alt 并拖动以绘制选择区域）。
  • Edit Shape 工具现在具有上下文菜单（此处将添加更多命令）。
  • 按住 x 并在视口中单击贝塞尔控制柄，会删除（归零）该控制柄。

文本工具

  • **逐字符调整。**现在可以按字符更改字体、样式、大小和字距，只需选中你需要的字符并进行调整。
  • Select tool：选中 Text 图形时，按 enter/return 可切换到文本工具。
  • 文本工具
    • 在编辑模式下，单击框外可切换到 Select 工具
    • 在编辑模式下，Option/Alt + 单击框外可创建新的 Text 图形
    • 有选区时，按 escape 可清除选区。
    • 没有选区时，按 escape 可切换到 Select 工具
    • 支持输入法编辑器。
  • 文本工具中用于导航文本的以下平台快捷键现在可用：
    • 导航/选择到行首/行尾
    • 导航/选择到下一行/上一行
    • 导航/选择到下一个/上一个单词
    • 导航/选择到文档开头/结尾
    • 导航/选择到段落开头/结尾（仅 macOS）

常规增强/重要修复

  • 图层图标有了颜色！
  • Transform 工具现在可配合多个选中图层使用。视口上方的工具设置中有两种模式。Group 会将选区作为一个整体进行变换（边界框很快也会旋转！）。Individual 会围绕每个图形各自的轴心点进行变换。
  • 属性控件的无限拖动，因此拖动属性时不再受显示器边缘的限制。
  • 现在可以重命名数组属性。右键单击并从上下文菜单中选择 Rename。
  • 数组属性（例如 Color 数组上的属性）可通过新的 Reorder 上下文菜单重新排序（在索引上右键单击）。
  • Spreadsheet Lookup 现在支持同一列中的混合数据类型。
  • 现在有菜单项和快捷键可将合成 Alpha 设为 0。Windows 上为 Alt-Ctrl-b，macOS 上为 Alt-Command-b。
  • 已有切换吸附的快捷键（Cmd/Ctrl + U）。
  • **Milliseconds **已添加到 Local Time 工具中。
  • Make Editable 已添加到视口上下文菜单中。
  • 现在可以在时间编辑器中右键单击图层的可见性条并选择“Always Visible”，这会完全禁用该图层的可见性条，意味着它将始终可见。例如，这意味着如果你增加合成长度，就不需要管理此项目的可见性条。
  • **全选 **和 反转选择现在可用于点选择。
  • Project Settings 的快捷键现在为 Option/Alt + P。
  • 现在可以双击时间编辑器中的图层，在属性编辑器中加载其界面。
  • 3D Matrix Deformer 现在可作用于子网格，以这种方式工作时，它会按 position.z 值在视口中重新排列网格。
  • Sweep Gradient 现在具有旋转属性。
  • 现在可以按住 Option/Alt 键，将资源窗口中的合成拖动到场景窗口中的合成上以替换它。
  • 对图层分组时，组的可见性条现在会与组内容匹配。
  • 现在可以通过右键单击资源的属性行来替换文件资源。
  • Alt + [ 和 alt + ] 现在会截断图层的可见性条。
  • 拖动图层的端点现在会影响所有选中的图层。
  • Ellipse 图形中添加了 Semicircle 选项。
  • 资源窗口中新增了从 Compositions in Group 执行 right click > Create Array 的选项。
  • 智能资源重新链接：如果你有多个缺失的资源，在找到一个后，我们会搜索该文件夹中的其他缺失资源，并在找到时重新链接它们。
  • 现在可以在曲线编辑器中复制关键帧。
  • 现在可以在曲线编辑器中复制/粘贴贝塞尔控制柄。
  • 视口上下文菜单中有 Add Background to Selected 菜单项。
  • 现在可以在 Render Queue Item 中选择“Current Frame”作为选项。
  • 现在可以渲染单个渲染项（右键单击 Render Queue Item 标题）。
  • 在视口中按 Cmd/Ctrl + 滚动可切换为平移。
  • Transform 工具现在可配合多个选中图层使用。

Beta 版中的新内容

  • Noise Shader -
  • 在 Cavalry 中处理音频的体验应有所改善。现在可以在视口控制栏的新设置中选择正在播放的音轨，并静音音频。
  • Segment Path 变形器。将路径拆分为多个部分，这可以与 Sub-Mesh Deformer 结合使用，制作多色虚线图案。
  • 子网格边界框。为子网格添加背景。例如，句子中的一个单词，或一行文本。
  • SkSL 着色器：此着色器上的属性现在可以是 float、float2、half4（颜色）。使用 + 按钮添加新属性，并右键单击生成的属性以重命名；这些属性在 SkSL 代码中作为 uniform（同名）可用。

已知问题

Lottie 导出不支持复制器或 Layout Shape 内项目上的渐变着色器。
