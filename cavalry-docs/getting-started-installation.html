安装

简介

如何安装 Cavalry。

macOS 和 Windows 安装程序可从 cavalry.studio 下载。

旧版安装程序：

如有需要，可在此下载旧版安装程序。

安装

macOS

双击 .dmg 文件，然后将 Cavalry 图标拖到 Applications 图标上。

默认情况下，Cavalry 会安装到：Macintosh HD/Applications/。

注意：

macOS 安装程序是 Universal Binary，因此同时支持 Intel 和 Apple silicon 芯片。安装程序会根据你的处理器自动安装正确的版本。

Windows

运行 .msi 文件并按照提示操作。

默认情况下，Cavalry 会安装到：C:\Program Files\Cavalry。

在 Windows 上可以使用 msiexec 执行无人值守安装。以管理员身份启动 Command Prompt，然后运行以下命令（将 Cavalry_XXXX.msi 替换为安装程序的文件名）：

> msiexec /i "C:\Path\To\Cavalry_XXXX.msi" /quiet /norestart

信息：

要以管理员身份运行 Command Prompt，请右键点击 Command Prompt 并选择“Run as Administrator”。

卸载

macOS

只需从 /Applications/ 文件夹中删除 Cavalry.app 即可。以下文件夹也可以手动删除：

  • ~/Library/Application Support/Cavalry
  • ~/Library/Preferences/Cavalry

Windows

使用 Add/Remove Programs。
