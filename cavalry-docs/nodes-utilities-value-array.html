值数组

简介

创建一个数值列表，可通过索引将其分配给其他图层。

界面

Mode：设置输出哪个（些）值：

  • Index：输出数组中的所有索引。
  • Minimum：输出数组中所有值里的最小值。
  • Maximum：输出数组中所有值里的最大值。
  • Average：输出数组中所有值的平均值。
  • Accumulate：输出数组中所有值的总和。

Auto Index：勾选后，该图层将自动输出所有索引。

Array Index：选择数组中的索引。

Reverse：反转索引的输出顺序。例如，若有 3 个索引 0,1,2，其顺序将反转为 2,1,0。

Count：输出数组中索引的数量。

Add

0: Value：数组中的第一个索引。

示例：

从基本图形（Polygon）开始，并将其放入复制器。

  1. 创建 3 个索引（Add 按钮），并为每个索引分别设置 3、5、8。
  2. 连接 valueArray.id→basicShape.sides
  3. 将一个随机节点连接到 Value Array 的 Array Index。
  4. 将 Random 上的 Min and Max 设为 0 和 2

每个副本都会随机成为 3 边、5 边或 8 边的多边形。

另请参见颜色数组。
