基本图形

简介

创建矩形、椭圆或多边形等原始图形。原始图形包含 Width、Height、Radius 等程序化属性。

界面

通用属性 +

Primitive Type：选择要创建的原始图形类型：

  • 弧形
  • 箭头
  • 胶囊
  • 齿轮
  • 椭圆
  • 多边形
  • 矩形
  • 圆环
  • 星形
  • 超椭圆
  • 超级图形

可编辑图形：

使用工具栏中的工具创建图形时，可使用 Shape > Create Editable Primitives 选项来创建包含可编辑点的可编辑图形，而不是程序化原始图形。启用该设置后，原始图形工具的图标中也会显示一个小 E。
