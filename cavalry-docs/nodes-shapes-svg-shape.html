SVG

简介

从 .svg 文件创建图形。

界面

Common Attributes +

File：从资源窗口中拖入 .svg 文件。

SVG Materials：取消勾选此属性可忽略 SVG 的材质。在 Fill 标签页下启用 **Fill ** 以替换填充颜色。

SVG Strokes：取消勾选此属性可忽略 SVG 的描边。在 Fill 标签页下启用 Stroke 以替换描边颜色。
