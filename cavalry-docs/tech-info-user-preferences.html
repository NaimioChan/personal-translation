用户首选项

如果首选项出现问题，你可以放心删除 Cavalry 目录中包含的文件。

建议先临时重命名 Cavalry 目录或文件（例如 preferences_temp.json）以保留备份。在问题被定位/解决后，可以选择恢复或删除这些重命名后的文件。

危险：

  • 在删除/重置任何这些文件之前，请确保 Cavalry 已关闭。
  • 删除这些文件后，启动时会重新创建默认文件。
  • 你将丢失这些文件此前保存的任何首选项。

应用程序和工作区首选项文件保存在：

  • macOS：~/Library/Preferences/Cavalry/
  • Windows：C:\Users\<USER>\AppData\Local\Cavalry\

信息：

AppData 和 ~/Library 是隐藏文件夹。要找到它们：

  • Windows：在 Explorer 的 View options 中勾选“Hidden Items”。
  • macOS：在 Finder 中，打开 Go 菜单时按住 Option/Alt 即可显示 Library。
