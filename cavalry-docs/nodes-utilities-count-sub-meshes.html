统计子网格

简介

统计图形在指定层级内的子网格数量。有关子网格和层级的更多信息，请参见子网格。这主要用于统计文字在文本框内换行后产生的行数。

界面

Input Shape：连接要统计的子网格（Text/Duplicator/SVG 等）。

Level Mode：选择要影响子网格中的哪个层级。

  • Custom...：手动设置Custom Level。
  • Text (Lines)：与文本图形配合使用，将影响每一行。
  • Text (Words)：与文本图形配合使用，将影响每个单词。
  • Text (Characters)：与文本图形配合使用，将影响每个字符。

Custom Level：设置要影响的子网格层级结构中的层级。

Count：用于预览统计结果的输出。

示例：

  1. 使用文本工具在视口中绘制一个文本框，以创建一个文本图形。
  2. 输入足够长的String，使其开始在文本框内换行。
  3. 创建一个Count Sub-Meshes工具。
  4. 连接 textShape.id→countSubMeshes.inputShape
  5. 使用文本工具调整文本图形文本框的宽度。

随着文字重新换行，Count Sub-Meshes 的Count会更新为对应的行数。

连字：

连字是使用不同字形以避免 i 的点、f 的弧线等特征相互碰撞的字母组合。例如在 Cavalry 的默认字体（Lato）中，fi 和 fl 会连接成单个字形。由于连字被视为一个网格，Count Sub-Meshes 工具会将这类连字计为一个字符。
