Alpha 材质覆盖

简介

Material Overrides 允许编辑复杂/深层网格结构（如 SVG 或文本）内部的材质。这可通过子网格行为的 Fill 或 Stroke 标签页实现。

通过向子网格添加 Alpha Material Override，可以在原始 alpha 与覆盖所设置的 alpha 之间混合。随后可以向子网格添加衰减来控制效果。

界面

通用属性 +

Alpha：设置 alpha 值。

示例：

  1. 将 SVG 导入资源窗口。
  2. 将其拖入视口，并从选项中选择 Asset Layer，以创建SVG 图形。
  3. 将子网格连接到 SVG Shape 的 Deformer 属性。
  4. 在子网格上，切换到属性编辑器中的 Fill 标签页。
  5. 使用 + 按钮向 Fill Overrides 属性添加一个 Alpha Material Override。
  6. 将 Alpha 设为 0。
  7. 在 Alpha Material Override 上，打开 Falloff 标签页，右键点击以添加一个衰减。
  8. 在 SVG Shape 上移动该衰减。

当衰减经过 SVG 的各个部分时，这些部分会变为透明。
