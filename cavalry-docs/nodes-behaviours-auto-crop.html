自动裁剪

简介

根据图形的边界框裁剪图形。

界面

通用属性 +

Mask Shape：确定遮罩的形状：

  • Rectangle：使用矩形遮罩。
  • Ellipse：使用椭圆形遮罩。

Align X：设置裁剪在图形边界框上开始的水平位置，范围为 -1（左边缘）到 +1（右边缘）。

Align Y：设置裁剪在图形边界框上开始的垂直位置，范围为 -1（上边缘）到 +1（下边缘）。

Progress Mode：

  • Percentage：将裁剪的大小设置为整体宽度的百分比。
  • Size：以像素为单位设置裁剪的大小。

Percentage：当 Progress Mode 设为 Percentage 时，按图形宽度/高度的百分比增加或减少裁剪量。

Size：当 Progress Mode 设为 Size 时，以像素为单位增加或减少裁剪量。

示例：

  1. 创建一个文本图形。
  2. 在属性编辑器中，点击 Deformers 行上的 +，然后从列表中选择 Auto-Crop。
  3. 将 Align X 设为 -1。
  4. 为 Percentage W 设置关键帧：
    • Frame 0 = 100
    • Frame 25 = 0
  5. 按下 Play。

文本将在 25 帧内从左到右显现出来。由于裁剪的宽度是根据文本的宽度自动设置的，如果文本的 String 发生变化，它会自动更新。

图像着色器：

将 Auto-Crop 与连接到图像着色器的图形一起使用时，应将图像着色器的 Scale Mode 设为 None，以避免对图像进行任何重新缩放或平铺。
