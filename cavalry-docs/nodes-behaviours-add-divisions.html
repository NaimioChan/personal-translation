添加分段

简介

在图形的边缘上添加分段，以获得更平滑和/或更精细的变形。

界面

通用属性 +

Mode：确定图形边缘的分段方式。

  • Number of Divisions：设置要在现有点之间添加的分段数量。
  • Edge Length：为点之间生成的边缘设置特定长度。这可以使点的分布更均匀。

Divisions：当 Mode 设为 Number of Divisions 时，设置细分数量。例如，值为 5 会将一条边细分为 6 条边（沿该边创建 5 个新顶点）。

Max. Length：当 Mode 设为 Number of Divisions 时，如果某条边的长度小于此值，则不会对其进行细分。例如，一个 100x100 的矩形，Divisions 设为 2、Max Length 设为 51，结果只会进行一次细分，因为第一次细分后生成的边长小于 51px。

Edge Length：当 Mode 设为 Edge Length 时，设置生成边缘的长度。

Keep Original Points：当 Mode 设为 Edge Length 时，确定是否保留图形中的原始点。取消勾选可使点的分布更均匀，但在某些情况下对原始图形的呈现会不够准确。
