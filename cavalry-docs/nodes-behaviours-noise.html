噪波

简介

生成噪波图案，用于变形图形或生成数值。

界面

Common Attributes +

Strength Fade to Zero：勾选后，Strength（包括衰减）会在 0 与结果之间进行插值。未勾选时，它会在 Minimum 和 Maximum 值之间进行插值。

Use Normals：勾选后，变形将基于图形的法线。未勾选时，点会从图形中心进行缩放。此属性仅在 Noise 行为用作变形器时才相关。

Noise Type：设置要生成的噪波类型：

通用噪波属性

所有 Noise Types 都包含以下属性：

  • Minimum：设置最小输出值。

  • Maximum：设置最大输出值。

  • Offset：为输出值加上/减去一个值。

  • Frequency：设置噪波的大小/缩放。当数值趋近 0 时，图案的细节会变少。

  • Separate Channels：勾选后，会为 x、y 通道传入不同的值。

  • Seed：设置随机种子。改变此值会生成新的噪波图案。

  • Use Layer as Seed：勾选后，Noise 行为所连接的每个图层都会使用不同的 Seed。另请参阅 图层种子。

  • Stagger：设置一个值，以在时间上偏移每个噪波采样。与复制器（或任何子网格）一起使用时，会为每个 Id 传入不同的 Time 值。

  • Looping：勾选后，噪波图案会按 Loop Length 循环。请注意，这会影响 Time Scale。

  • Loop Length：设置循环所跨越的帧数。

  • Time：此属性会自动连接到合成的 Time。如果需要静态噪波，请断开连接。

  • Time Scale：设置一个乘数，用于提高/降低噪波演变的速度。

  • Noise Position：设置噪波图案的位置。

  • Noise Rotation：设置噪波图案的旋转。

  • Noise Scale：设置噪波图案的缩放。

  • Use Position Context：勾选后，Noise 行为会获取上下文，并在与子网格（复制器、文本、SVG 等）配合使用时，根据每个子网格的位置为每个 Id 传入唯一的值。取消勾选则意味着子网格的位置会被忽略。

  • Use Index Context：勾选后，Noise 行为会获取上下文。在与子网格（复制器、文本、SVG 等）配合使用时，可用它来控制每个 Id 受到的影响。取消勾选此属性会导致所有图层无论 Id 如何都会收到相同的值。

  • Octaves：设置组合在一起的噪波层数。较高的值会增加更精细的细节和复杂度，但会增加计算时间。

  • Lacunarity：为每个八度的频率设置乘数。较高的值会让每个后续八度添加更细密、更紧凑的细节。需要 Octaves 至少为 2。

  • Gain：为每个八度的振幅设置乘数。较低的值会让较高的八度贡献更少，从而得到更平滑的噪波；较高的值则会让细节更明显。需要 Octaves 至少为 2。

  • Curl Noise：勾选后，生成无散度（旋转、流体般）的运动，而不是标准的随机噪波。

  • Curl Amount：设置 Curl Noise 效果的强度，决定它对运动或位移的影响程度。
