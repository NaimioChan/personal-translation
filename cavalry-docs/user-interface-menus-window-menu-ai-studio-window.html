AI Studio 窗口

简介

使用专为工作流打造的 AI 工具和功能，为你的工作流提供补充。

高级功能：

需要订阅 Canva 高级方案 Canva AI 与 Cavalry。

工具

背景移除

使用 AI 移除视频背景，只保留主体，使其位于透明背景之上。

时长：

视频素材的时长上限为 10 秒。当视频素材超过此限制时，会出现一个黄色警告图标。

Video：选择要移除背景的视频素材。

Model：选择执行背景移除的 AI 模型。

Remove Background：点击按钮开始背景移除流程。

Results：见结果。

  • Playback：使用播放功能预览生成的视频。
  • Background：使用下拉菜单选择背景样式，以便查看生成的 Alpha 通道。
  • Loupe：启用后，将鼠标悬停在预览上时会显示光标所在区域的放大窗口。

Add to Composition：在 Results 区域选择一个缩略图，然后点击此按钮，将生成的视频添加到资源窗口和当前合成。

生成矢量

使用提示词生成矢量图稿。

Model：选择用于生成矢量图稿的 AI 模型。

Prompt Window：输入提示词，说明要生成的矢量图稿类型。

Prompt Guide Options：使用下拉选项为提示词补充更多上下文。

Generate：点击按钮开始生成流程。

Results：见结果。

Add to Composition：在 Results 区域选择一个缩略图，然后点击此按钮，将生成的图稿添加到资源窗口和当前合成。

图像转图层

将图像转换为多个独立图层，并连同 摄像机 一起放置在 2.5D 空间中。图像转图层是一种生成式分离：原图中不可见的被遮挡区域由模型合理填充，而非还原，因此分离出的图层可能无法精确重建隐藏内容。

Image：选择要移除背景的视频素材。

Model：选择用于生成图层的 AI 模型。

Nearest Distance：定义用于放置距相机最近图层的 Position Z 值。

Furthest Distance：定义用于放置距相机最远图层的 Position Z 值。

Generate：点击按钮开始该流程。

Results：见结果。

Add to Composition：在 Results 区域选择一个缩略图，然后点击此按钮，将生成的图稿添加到资源窗口和当前合成。

结果

此区域会填充已完成任务的缩略图。点击缩略图会加载更大的预览。缩略图会根据当前启用的功能进行筛选，但勾选 Show All 会显示所有功能的全部结果。

要清除缩略图，右键点击某个缩略图并选择 Remove。随后会出现一个模态对话框，其中提供同时移除缩略图和该任务所生成资源的选项。

生成的资源：

如果设置了 Project，生成的资源会保存到 Assets 文件夹；如果未设置 Project，则保存到已保存场景所在的同一位置。如果场景尚未保存，资源会保存到桌面。生成资源时，文件的路径会输出到消息栏。

AI Pass

如果在 Cavalry 会话进行期间购买 AI Pass，则需要重启 Cavalry 才能更新额度。
