沿向量推动

简介

沿向量变形图形。

界面

通用属性 +

Use Normals：勾选后，变形将基于图形的法线。取消勾选时，点会从图形的中部变形。

Direction：手动设置变形所沿的向量。

Reverse Direction：反转 Direction。

示例：

  1. 创建一个椭圆。
  2. 将其 Radius 设为 200,200。
  3. 取消勾选 Bézier。
  4. 点击椭圆 Deformers 属性上的 + 按钮，选择 Push Along Vector。
  5. 在 Push Along Vector 上：
    1. 将 Strength 设为 1000%。
    2. 勾选 Use Normals。
  6. 打开 Push Along Vector 的 Falloff 标签页，然后在 Falloffs 输入框中右键 > Add Falloff > Falloff。
  7. 沿椭圆边缘移动衰减。
