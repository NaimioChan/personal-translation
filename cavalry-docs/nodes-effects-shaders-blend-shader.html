混合着色器

简介

将多个着色器组合在一起，输出单个着色器。

界面

通用属性 +

Shaders：已连接着色器的列表。右键单击 > Add Shader、拖放现有着色器，或建立连接来添加着色器。

使用齿轮图标调整每个图层的设置：

  • Shader：所连接的着色器。
  • Invert：反转着色器的值。
  • Sample Mode：确定 Input Shader 的采样方式：
    • RGB：使用组合的 RGB 值。
    • Luma (Gamma Corrected)：使用经 gamma 校正的亮度值。
    • Saturation：使用饱和度值。
    • Lightness (Value)：使用明度值（RGB 通道的平均值）。
    • Red Channel：采样红色通道中的值。
    • Blue Channel：采样蓝色通道中的值。
    • Green Channel：采样绿色通道中的值。
