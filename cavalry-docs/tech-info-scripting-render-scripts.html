渲染脚本

简介

Cavalry 可以执行脚本：

  • 用于设置渲染队列项。
  • 在渲染队列项执行每次渲染之前。
  • 在渲染队列项执行每次渲染之后。

以下 API 都位于 render 命名空间中。它们仅在渲染队列项中可用。脚本可在渲染管理器中渲染队列项的 Scripts 标签页里添加到相应编辑器。

动态渲染：

使用动态渲染时，可通过 api.getDynamicIndex() 成员访问 Dynamic Index。

任何 JavaScript 执行都会阻塞后续渲染，直到脚本运行完毕。这是有意设计，以便在开始下一次渲染前，完成下载/替换资源或通过某种方式修改场景等过程。

图像序列：

脚本在整个序列渲染之前和之后执行，而不是在每张单独图像渲染前后执行。

类型

渲染设置脚本

添加一个在任何渲染设置开始之前运行的脚本，因此可用于影响渲染队列项本身。

渲染前脚本

添加一个可用于操作场景并为其渲染做准备的脚本。

渲染后脚本

添加一个在渲染队列项完成后运行的脚本。

信息：

脚本可以使用 JavaScript API 执行诸如修改属性、从网络获取新信息，或替换并重新加载资源等任务。

成员函数

composition → string

返回渲染队列项中每个合成的 layerId。可作为渲染前与渲染后脚本的一部分使用。

console.log(render.composition);

path → string

返回渲染的文件路径——任何动态令牌/路径都会完全解析。可作为渲染后脚本的一部分使用。

console.log(render.path);

renderQueueItem → string

返回 renderQueueItemId，以便对其做出更改。可作为渲染设置脚本的一部分使用。

console.log(render.renderQueueItem);
