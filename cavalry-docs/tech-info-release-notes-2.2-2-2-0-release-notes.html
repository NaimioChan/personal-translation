2.2 版本说明

发布日期：2024 年 11 月 5 日

新功能

图形

  • 文本图形 支持 OpenType。
  • Strokes 新增 Gradient 颜色模式。请注意目前支持仅限于颜色（暂无抖动、插值、对齐等选项）。
  • 现在可以为路径添加多个 Stroke。参见图形 Stroke 标签底部的 Multi Stroke 属性。

行为

  • Knot Behaviour：在轮廓线与自身相交处为路径添加间隙。
  • Stitches Behaviour：用缝线效果填充闭合路径。

工具

  • 描边复制器。
  • 应用 OpenType 样式行为。

衰减

  • 衰减 新增两种图形类型：
    • Sweep：创建类似“雷达”的效果（与 Sweep Gradient 类似）。
    • Shape：使用自定义图形作为衰减。
  • 新增 范围衰减。

常规

  • Transform tool 已添加到 曲线编辑器。
  • Proportional Easing：在 时间编辑器 和 曲线编辑器 中使用 Transform tool 时，缩放关键帧也会缩放任何贝塞尔手柄。
  • Maintain Proportional Easing：在 时间编辑器 和 曲线编辑器 中移动关键帧时，关键帧周围的贝塞尔手柄会被调整以保持相似的缓动。可在 首选项 中选择关闭此功能。
  • 新增“Quick Mask”模式：双击 Pen、Pencil 或任意基本图形工具后，工具栏图标会变为黄色，表示该工具处于“Quick Mask”模式。在此模式下绘制会创建一个新图形，并作为所选图形的 Clipping Mask。

JavaScript API

API

  • isAttrDefault()
  • saveViewportContentsAsImage()
  • cancelRender()

Cavalry

  • applyMatrix()
  • rgbaToHex()

Script UIs

  • setTransparentForMouseEvents()

增强

  • 许多 Filters 已优化，速度至少提升 2 倍；当滤镜连接到 Duplicator 内的图形时，速度提升更为显著。图像着色器 在 macOS 上某些测试场景中的播放速度提升了约 40 倍。
  • 可在 场景窗口 中重新排序合成标签页。
  • 工具栏 中的基本图形工具现在会在 工具设置 中勾选 Create Editable Primitives 时显示一个小的 E 图标。
  • Forge Dynamics 图形 现在支持 Body 的 Scale。
  • 在 资源窗口 中悬停合成和大多数资源时，现在会显示预览。
  • 在 属性编辑器 中悬停图像、视频（第一帧）、.csv、Google Sheets 和文本资源输入时，现在会显示预览。
  • Wave Deformer 现在可以适应轮廓长度，从而产生更均匀的变形。
  • Layout Based on Size at Frame：与 Layout Group 一起使用的动画图形的边界框现在可以设定在特定帧上。此选项位于图形的 Advanced 标签中。
  • 文本图形 现在可以设置为避免在 Text Box 内换行，从而避免最后一行出现单个单词（孤字）。
  • 噪波 行为现在支持 Noise Rotation 和 Noise Scale。
  • 应用字体大小 现在支持衰减。
  • Style 和 Material Behaviours 现在包含 All 模式，可在配合行为与 范围衰减 时使用。
  • 新增 Create > Demo Scenes > Text > Variable Font 示例，展示上述功能。
  • 新增 Create > Demo Scenes > JavaScript > Random Dash Pattern 示例。
  • 组件 的 Show Layer Groups 模式现在改为 Compact Layout。结合 Cavalry 2.1.3 引入的属性重命名功能，这为界面提供了更简化的选项。
  • JavaScript 窗口/面板和属性表达式中使用的字体已更新为 Fira Code。
  • Sign In 窗口中新增连接状态检查。
  • Attribute Expressions 现在可以添加到复选框属性。
  • 当硬盘空间不足 50MB 时现在会触发提醒，以降低保存文件失败的风险。
  • 延长开放路径 新增 Path Curvature 选项。
  • Beat Markers 现在为 Pacing Markers，并包含在每秒添加标记的选项。
  • 首选项 窗口新增 Maintain Proportional Easing 和 Use Absolute Bézier Positions 选项。
  • 导入图像序列以及 图像智能文件夹 现在支持大写文件扩展名（JPG、PNG...）。
  • 点击 Frame/Timecode Display 中的 F 或 T 前缀现在可在帧和时间码之间切换。
  • Viewport Quality 和 Render Quality 模式已更新，以改善抗锯齿。
  • 文本图形 新增 Justify 对齐选项。
  • 文本图形 新增 Paragraph Spacing 选项。
  • 从智能文件夹获取资源 现在有 Count 属性。
  • 当 View > Draw Outside Composition Boundary 激活时，复杂图形现在会被转换为边界框以提升性能。
  • 网格浏览器 中新增 Verb Count。这在配合 混合图形 行为时很有用。
  • 文本图形 现在支持 Text Paths 的循环。
  • Bend 和 挤压与拉伸 新增 High Quality 选项。
  • 路径偏移 现在支持开放路径。
  • 将 资源窗口 中的现有合成拖到 Create a Composition 按钮上，现在会创建一个父合成，并从现有合成继承其 Resolution、Frame Rate 和 Frame Range。
  • 修剪带锥度的 Stroke 现在会将该 stroke 遮罩掉。

重要错误修复

  • 在 JavaScript 编辑器 中使用 Run Script 按钮时按住 Option/Alt 的功能已恢复。
  • 禁用音频播放后，循环播放时现在仍保持禁用。
  • Sound Behaviour 的 Frequency Bands 现在最小设为 2，以避免在 Windows 上崩溃。
  • 辉光滤镜 不再产生“块状”结果。
  • Text Background 现在将单个换行视为段落，与新的 Paragraph Spacing 功能一致。此前使用双换行的行为被视为错误，因此未提供向后兼容：任何旧文件都需要更新。
  • Forge Bodies/Shaders/Falloffs 等中的 Input List 界面现在在从列表中移除项时会正确更新列表项 Id。此前这会引起因上下文而异的多种问题。
  • Hidden Guides 不再能被双击。
  • Scene Tree 中 Animate Path 按钮的样式已恢复。
  • 现在禁止在为图层建立父子关系时按住 Cmd/Ctrl。
  • Attribute Editor 中上下文菜单的变暗效果已恢复。
  • JavaScript 编辑器 中的自动补全现在区分大小写。
  • 修复了 时间轴计数器 包含在 Pre-Comp 中时其触发的动画受影响的问题。
  • 当 Stroke 的 Dash Pattern 为小数值且未定义间隙时，自动生成的间隙不再舍入为最接近的整数。
  • 修复了某些西里尔字形作为图层标签时无法正确渲染并导致崩溃的问题。
  • 混合图形 现在在 Delta 模式下行为正确。
  • 数学 工具现在可以连接到枚举（下拉菜单）。
  • 值、值2 和 值3 的 Time Offset 现在恢复工作。
  • Noise Behaviour 的 Context > Filter Position 选项（位于上下文菜单中）现在会在会话之间保留其状态。
  • 现在可以使用 Motion JPEG 编解码器渲染为 QuickTime。
  • 导出的 ProRes 4444 或 4444 XQ 文件若包含 alpha 但第一帧完全不透明，现在可导入 Adobe After Effects/Premiere Pro。
  • 时间轴计数器 的 Convolution Graph 现在方向正确。请注意旧场景不会自动更新。要更新文件，可以新建一个 Timeline Counter 替换现有的，或运行 api.set(layerId, {"legacyGraph": false});（将 layerId 替换为 Timeline Counter 的 layerId），然后水平翻转 Convolution Graph。
  • 具有非整数帧率的合成现在会正确地向 Frame/Timecode Display 和 Timecode String Generator 报告时间码。
  • 修复了父子关系与继承变换相关的回归问题。子级现在在建立/解除父子关系时会“留在原位”（Skew 的已知问题仍然存在）。
  • 修复了可能导致 Distribution 属性的关键帧被锁定的问题。
  • （仅 macOS）改进了将 ProRes 渲染导入其他应用时非整数帧率的报告方式。请注意某些应用会对帧率进行舍入，因此可能需要重新解释素材。
  • 用作 Clipping Mask 的隐藏 Merge Shape 现在在打开已保存的场景时行为正常。
  • 现在不再会意外地对 Assets Window 中所选的 Group 或 Comp 应用变换。
  • 修复了以更高分辨率渲染为 MP4 时的崩溃，并已在此处说明渲染为 MP4 的限制。
  • isAttrReadOnly 在使用 getAttributeDefinition() 时现在会正确返回。
  • 只读属性不再显示 Control with Null 选项。
  • setUserData 现在能正确地保存对象。
  • setVerticalToolbar() 现在能正确渲染。
  • 修复了在 场景树 中搜索时子图层不会返回的回归问题。
  • 修复了在 Viewport 中通过 衰减 与带锥度 stroke 的 拖尾 交互时崩溃的问题。
  • 修复了 Windows 上 Scripts 目录中源已丢失的目录联接可能导致 Cavalry 启动时崩溃的情况。
  • Text Path 上的 文本图形 现在会在尖角处正确定位字符。

备注

  • NFT.Storage 不再支持上传到其 NFT.Storage Classic 产品，因此对于新安装的 Cavalry，该上传预设已从 上传预设管理器 中移除。可从 Preferences 目录中安全删除 uploadPresets.json 文件，以便为现有安装更新此项，但请注意这也会影响对 Web3.Storage 预设所做的任何更改。
  • Cavalry 的渲染器在此次更新中经历了重大升级，因此使用 Shader 和/或 Filter 的场景在 Cavalry 2.2 中渲染时，与之前版本相比可能会有细微的视觉差异。
  • 混合子网格位置 的 Falloffs 标签因不受支持已被移除。我们希望在未来版本中恢复此功能。
