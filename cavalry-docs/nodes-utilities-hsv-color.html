HSV 颜色

简介

使用色相、饱和度和明度创建颜色。

界面

Input Color：设置起始颜色。当设为黑色（默认值）时，该属性会被忽略；但对于其他任何颜色，都可以使用 Hue、Saturation 和 Value 属性来调整 Input Color。见下方示例。请注意，Saturation 和 Value 会叠加到 Input Color 上。

Hue：通过绕色轮旋转来选择不同的颜色色相。

Saturation：增加/降低颜色的饱和度。

Value：增加/降低颜色的明度（或亮度）。

Output Color：结果颜色的预览。

示例：

  1. 创建一个图形。
  2. 创建一个 HSV Color。
  3. 连接 hsvColor.id→shape.fillColor
  4. 调整 HSV Color 上的设置。

示例：

  1. 创建一个图形。
  2. 在图形的 Fill 标签页中，右键单击 Shaders 属性输入框，然后选择 Add Shader > Gradient Shader。
  3. 创建一个 HSV Color。
  4. 将 Input Color 设为 R = 255、G = 36、B = 224。
  5. 将 Hue 设为 90。
  6. 在渐变上，选择第一个色标。
  7. 连接 hsvColor.inputColor→gradient.0.color
  8. 在渐变上，选择第二个色标。
  9. 连接 hsvColor.outputColor→gradient.1.color
  10. 点击 HSV Color 的 Input Color 色板，并沿色轮移动该控件。
