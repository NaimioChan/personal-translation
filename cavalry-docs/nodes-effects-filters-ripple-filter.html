波纹滤镜

简介

使用线性、同心或螺旋波形扭曲图形的材质。可用它创建水波、冲击波或向外辐射的脉冲扭曲。

提示：

为 Phase 设置动画，使波浪沿其 Direction 传播。

界面

通用属性 +

Sampling Quality：控制图像的采样/插值方式。这些选项按从上到下可视为由低到高质量，在处理文字等精细细节时很有用。

  • Nearest Neighbour：使用最近的像素，不做混合。
  • Bilinear：在相邻像素之间混合，以获得更平滑的结果。适合一般的图像缩放，但可能引入柔化/模糊。
  • Catmull–Rom：一种高质量重采样方法，结果更锐利，并能保留精细细节。
  • Mitchell：均衡的高质量滤镜。

Mode：确定要创建的波纹类型：

  • Linear：创建沿线传播的波纹。
  • Concentric：创建从中心点向外辐射、形成同心圆的波纹。
  • Spiral：创建从中心点螺旋向外的波纹。

Centre：当 Mode 设为 Concentric 或 Spiral 时，设置波纹的原点，其中 (0, 0) 为图形的中心。

Decay：设置波纹的 Amplitude 随距离衰减的速度。值越大，波纹越集中在 Centre 附近。

Decay Length：当 Mode 设为 Concentric 或 Spiral 时，设置一个参考距离，在此距离上，一个单位的 Decay 会使 Amplitude 降低约 63%。

Direction：当 Mode 设为 Linear 时，以度为单位设置波传播的方向。

Displacement：当 Mode 设为 Linear 时，选择像素是垂直于波方向推移（经典波浪），还是沿波方向推移（压缩/拉伸）。

  • Perpendicular：垂直于 Direction 推移波纹。
  • Parallel：平行于 Direction 推移波纹。

Amplitude：以像素为单位设置沿波方向的最大位移。

Wavelength：以像素为单位设置相邻波峰之间的距离。

Phase：以度为单位设置波的相位偏移。为它设置动画，可让波纹远离或朝向 Centre 传播。

Waveform：选择波形的形状：

  • Sine：
  • Triangle：
  • Square：

Arms：当 Mode 设为 Spiral 时，设置螺旋的臂数。
