素材图形

简介

将图像/视频从资源窗口或文件系统拖入场景窗口或视口时，会创建一个 Footage Shape。它与基本图形 的不同之处在于，它会继承用于创建它的素材的尺寸。

界面

Common Attributes +

Shrink：减小/增大 Footage Shape 的边界。

Size：一个只读属性，输出所连接 Image Shader 中 File 资源的分辨率。

小心：

创建 Footage Shape 的唯一方式是将图像从资源窗口或文件系统拖入场景窗口或视口。它无法通过添加图层窗口创建。
