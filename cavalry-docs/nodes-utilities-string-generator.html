字符串生成器

简介

以程序化方式生成字符串，例如日期与时间、哈希、数字和时间码。

界面

Generator：选择生成器的类型：

  • Block
  • Formatted Date and Time
  • Formatted String
  • Hash
  • Hexadecimal
  • Random Date
  • Random Number
  • 时间码生成器
  • Value

Prefix：设置出现在数字之前的字符。

Suffix：设置出现在数字之后的字符。

String Manipulators：连接一个 String Manipulator。

示例：

  1. 创建一个 Text Shape
  2. 点击 String 属性上的 + 按钮，选择 String Generator。
  3. 将 Generator 设置为 Random Date。
  4. 选中该 Text Shape，点击 工具架 中的 复制器 图标。

每个复制出的 Text Shape 都会被赋予一个随机生成的日期。
