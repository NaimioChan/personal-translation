应用布局

实验性功能：

这是一项实验性功能。要启用它，请在首选项中勾选 Enable Experimental Features。

简介

Apply Layout 行为可用于在子网格中堆叠图形。

界面

Layout：选择图形的布局方式：

  • Grid：参见网格布局。
  • Horizontal Layout：参见水平布局。
  • Vertical Layout：参见垂直布局。

Size：设置 Layout Shape 的尺寸。默认情况下，它连接到合成的 Resolution 属性。要手动设置该值，请移除此连接。

Level：手动设置 Level 值。有关层级的更多信息，请参见子网格。

Vertical Alignment：让布局对齐到顶部或底部。

Horizontal Alignment：让布局对齐到左侧或右侧。

Column Span：使用网格布局时，可用该属性跨越多列。

Row Span：使用网格布局时，可用该属性跨越多行。

示例：

  1. 创建一个椭圆。
  2. 选中Ellipse，点击复制器图标（位于工具架中）。
  3. 在属性编辑器中，将 Distribution Type 设为 Point。
  4. 点击Duplicator 上 Deformer 属性旁的 +。
  5. 从列表中选择 Apply Layout。
  6. 右键点击椭圆的 Radius 属性，选择 “Add Behaviour > 随机”。
  7. 将 Random 的 Minimum 设为 50，Maximum 设为 200。
  8. 拖动 Random 行为上的 Seed 属性。
