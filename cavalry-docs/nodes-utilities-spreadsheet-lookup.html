电子表格查找

简介

根据相关的文本字符串（键）在电子表格数据中查找值。除其他用途外，这在创建 design systems 时很有用，其中许多图层共享相同的属性。例如，在下表中，键 corner-radius 会返回 值 10。

Key Value
corner-radius 10

使用查找的好处在于，可以出于整理目的移动行，而不会丢失与该值的链接。

界面

File：连接一个 .csv 或 Google Sheet 资源。

Excel Sheet：从 .xlsx 资源中选择一个工作表（标签页）。

Lookup Column：选择数据中用于搜索键的列。

Lookup Key：指定要在 Lookup Column 中查找的键（文本）。

Value Column：选择要与 Lookup Key 匹配的列。

示例：

  1. 创建一个 Rectangle。
  2. 在 资源窗口 中右键单击并选择 Import Google Sheet...
  3. 粘贴此链接：https://docs.google.com/spreadsheets/d/1DB4Yv0W_sT1nIlKiQFUBeQyXZoz88tdQt8YvLzXYwbU/edit?usp=sharing
  4. 创建一个 Spreadsheet Lookup。
  5. 将 Google Sheet 从 资源窗口 拖到 Spreadsheet Lookup 上的 File 属性。
  6. 为 Lookup Column 选择 Key 列。
  7. 为 Value Column 选择 Value 列。
  8. 在 Lookup Key 中输入 corner-radius。
  9. 连接 spreadsheetLookup.id→rectangle.cornerRadius

信息：

电子表格数据中的任何更改都需要通过在 Asset Window 中右键单击该电子表格资源并选择 Reload 来更新。
