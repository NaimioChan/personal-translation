闪光

简介

沿垂直或水平轴收窄图形。

界面

Common Attributes +

Direction：设置图形变形的轴向：

  • Vertical：沿 Y 轴变形。
  • Horizontal：沿 X 轴变形。

Amount：增大/减小效果强度。注意：边缘需要存在分段。

Start Stretch：垂直于轴向缩放图形顶部的点。

End Stretch：垂直于轴向缩放图形底部的点。

Graph：使用 Graph 调整效果曲线。参见 Common Attributes。
