描边

简介

Stroke Utility 可以连接到多个图形，以控制它们的描边颜色。这样一来，许多图形就能共用同一种颜色，只需在一个图层上操作即可完成更新。

信息：

图形连接到 Stroke Utility 后，所有已连接图形的颜色都可以从其中任一图形或通过 Stroke Utility 本身来更改。

界面

Color：使用 Hex 或 RGB 值设置图形的颜色（只有 RGB 值可以制作动画）。点击色板可使用 HSV 设置颜色。

自动补全 Hex：

当十六进制代码包含重复的字符或数字序列时，会被自动补全。例如，输入 AB 后按回车，会得到 #ABABAB。

Shaders：已连接的着色器列表。

Alpha：整个着色器网络的不透明度/alpha 的总控制。

Width：设置描边的宽度。

Cap Style：设置开放路径上端点（描边两端）的外观。

  • Flat：在端点处截断的平直端点。
  • Round：以端点为圆心的半圆端点。
  • Projecting：平直端点，向外超出端点半个 Width 的距离。

锥形描边：

请注意，勾选 Tapered Width 时不支持 Projecting 端点。此时 Cap Style 将回退为 Round。

Join Style：设置接合处的外观。

  • Mitre：锐角转角。
  • Round：圆角转角。
  • Bevel：斜切/倒角转角。

Mitre Limit：设置锐角转角改为斜切绘制的临界值。

Dash Pattern：输入以逗号分隔的数字序列（实线、间隔、实线、间隔……）。

Dash Offset：沿路径偏移 Dash Pattern。

Align：沿路径对齐描边。

  • Centre：沿路径中心对齐描边。
  • Inner：沿路径内侧对齐描边。
  • Outer：沿路径外侧对齐描边。

小心：

开放路径仅支持 Centre 对齐。当单个路径中出现多个轮廓时，任何开放轮廓都会被设为 Centre，无论 Align 设置如何。

信息：

如果 Align 设为 Inner 或 Outer 并启用了 Trim，则闭合路径的 Cap Style 将设为 Flat，无论其设置如何。当一个图形中存在多个轮廓时，任何开放路径都会遵循 Cap Style 设置。

Trim：启用后，以下控件可用。

Start：设置描边在图形上开始的百分比位置。

End：设置描边在图形上结束的百分比位置。

Travel：让描边沿图形移动。

Reverse Path：反转描边的方向。

Tapered Width：勾选后，描边沿轮廓从起点到终点呈锥形变化。

Start Width：描边 Width 在轮廓第一个点处的乘数。

End Width：描边 Width 在轮廓最后一个点处的乘数。

Double Taper：勾选后，Taper 的 Width 会在轮廓上由 Taper From 属性确定的位置设为 100%。此时可以将 Start Width 和 End Width 设为 0%，从而创建一种从零开始、增至完整宽度、再减回零的锥形效果。

Cap Centres：偏移 Round 端点的中心。

Taper From：勾选 Double Taper 后，设置轮廓上 Width 设为 100% 的位置。

Middle Length：设置 Taper From 位置两侧 Width 为 100% 的描边长度。

示例：

  1. 创建 2 个图形。
  2. 创建一个 Stroke Utility。
  3. 在场景窗口中选择这两个图形。
  4. 在场景窗口中，按住 Option/Alt，连接 stroke.id→shape.stroke（Option/Alt 会同时为两个选中的图形建立连接）。
  5. 调整 Stroke Utility 的 Color。

两个图形的描边颜色都会更新。
