行为混合器

简介

组合并控制多个行为的效果。

界面

Add

每个索引包含以下属性：

  • Input Behaviour：连接一个行为。
  • Enabled：启用或禁用该行为的效果。
  • Strength：确定该行为的强度。
  • Blend Mode：为该索引选择混合模式。每个索引会影响其下方索引的结果：
    • Normal (Add)：输出数值。
    • Min.：所有数值将降低到最低值。
    • Max.：所有数值将提升到最高值。
    • Minus：减去数值。
    • Multiply：乘以数值，使数值减小。
    • Screen：乘以数值的反相，使数值增大。
    • Overlay：高值将提升，低值将降低。

注意：

Behaviour Mixer 不支持变形器。
