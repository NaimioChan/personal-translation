路径分布

简介

沿一条或多条路径分布点。

界面

Count Mode：

  • Per Shape - 沿整个图形分布点。例如，如果将 Duplicator 用作 Input Shape，Count 中的值将均匀分布在整个图形上。
  • Per Sub-Mesh - 沿每个子网格分布点。例如，如果将 Duplicator 用作 Input Shape，Count 中的值将均匀分布在每个子网格上，最终得到共[Count] x [the Count of the Input Shape] 个图形。
  • Per Contour - 沿每个轮廓分布点。例如，如果用 Pencil 创建的包含多条线（轮廓）的路径作为 Input Shape，Count 中的值将均匀分布在每个轮廓上。

Count - 按 [Count Mode] 设置复制点的数量。

Input Shape - 添加要沿其分布点的图形。

Travel - 沿 Input Shape 长度的一定比例移动点。

Length - 设置将使用的路径长度（1 = 全长）。

Use Rotation - 使复制出的图形沿路径的法线对齐。

Flip - 反转路径的方向。

Exclude End - 勾选后，开放路径的末端将被忽略。这相当于将 Count 加 1 但移除最后一个点。

Offset - 围绕路径偏移点。
