Cavalry 播放器

简介

技术预览：

潜在用途包括现场播放、展览、现场视觉等。

直接在 Cavalry Player 中播放 .cv 文件。

启动 Cavalry Player

macOS

任选其一：

双击 /Applications/Cavalry.app/Contents/Applications/CavalryPlayer

或者；

  1. 打开 Terminal（Applications/Utilities/Terminal）。
  2. 输入 cd /Applications/Cavalry.app/Contents/Applications/。
  3. 按 Return。
  4. 输入 ./CavalryPlayer。
  5. 按 Return。随后会弹出一个 Finder 窗口。
  6. 浏览并选择场景文件。
  7. 点击 Open。

Windows

任选其一：

双击 C:\Program Files\Cavalry\CavalryPlayer

或者；

  1. 打开 Command Prompt。
  2. 输入 cd C:\Program Files\Cavalry\。
  3. 按 Return。
  4. 输入 .\CavalryPlayer。
  5. 按 Return。随后会弹出一个 File Explorer 窗口。
  6. 浏览并选择场景文件。
  7. 点击 Open。
