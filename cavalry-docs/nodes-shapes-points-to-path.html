点转路径

简介

使用分布中的点创建路径。

界面

Common Attributes +

Point Source：参见Distribution Types。

Close：闭合路径。

Bézier：勾选后，点之间将创建贝塞尔路径。

示例：

  1. 创建一个 Points to Path。
  2. 将 Point Source 设为 Array。
  3. 创建 3 个 Nulls。
  4. 连接 null1.position→pointsToPath.array.0
  5. 连接 null2.position→pointsToPath.array.1
  6. 连接 null3.position→pointsToPath.array.2
  7. 移动或为这些 Null 设置动画。
