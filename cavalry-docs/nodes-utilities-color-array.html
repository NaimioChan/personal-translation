颜色数组

简介

创建一个颜色列表，可通过索引将其分配给其他图形。

界面

Auto Index：勾选后，节点会自动输出所有索引。

Index：选择数组中的索引。

Reverse：反转索引的输出顺序。例如，有 3 个索引 0,1,2 时，它们的顺序将反转为 2,1,0。

Count：输出数组中索引的数量。

Add

0: Color：数组中的第一个索引。

示例：

先准备一个简单的基本图形，并将它放入复制器中。

  1. 点击 Add
  2. 连接 colorArray.id→basicShape.color
  3. 连接一个随机行为。
  4. 将 Minimum 设为 0，Maximum 设为 2。
  5. 连接 random.id→colorArray.index

每个副本都会被赋予一个随机颜色。

另请参见 值数组。

双击设置 Index：

双击索引所在的行，即可将 Index 设为该值。
