场景窗口

简介

场景窗口是 Cavalry 的核心。它由几个其他区域组成：

  • 用于浏览时间的时间轴。
  • 用于整理图层与层级的场景树。
  • 用于重新调整图层与动画时间的时间编辑器。
  • 用于调整动画曲线的曲线编辑器。

管理合成

可以同时打开多个合成。它们由场景窗口顶部的标签页表示。

打开合成

要打开合成，可以：

  • 在资源窗口中双击一个合成。
  • 在合成嵌套于另一个合成时，点击 Open 按钮。参见预合成。

关闭合成

要关闭合成，可以：

  • 从菜单中选择 Composition > Close Composition 来关闭当前合成。
  • 点击合成标签页上出现的 x。
  • 右键点击合成标签页，然后从以下选项中选择：
    • Close：关闭选中的合成。
    • Close Others：关闭除选中合成之外的所有合成。
    • Close Tabs to the Left：关闭位于选中合成左侧的所有合成。
    • Close Tabs to the Right：关闭位于选中合成右侧的所有合成。
