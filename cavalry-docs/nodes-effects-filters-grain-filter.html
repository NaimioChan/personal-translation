颗粒滤镜

简介

添加细腻的颗粒，以模拟胶片的视觉效果。

界面

通用属性 +

Grain Type：决定颗粒是彩色的还是黑白的：

  • Color：为每个颜色通道分别设置颗粒值。
  • Monochrome：在所有颜色通道上创建均匀的颗粒。

Grain Amount：当 Grain Type 设为 Monochrome 时，决定对图像施加多少颗粒。数值越高，噪点纹理越明显。

Size：当 Grain Type 设为 Monochrome 时，决定颗粒的大小。数值越大，噪点越粗糙。

Red Amount：当 Grain Type 设为 Color 时，设置红色通道中的颗粒量。用于针对单个颜色控制噪点。

Green Amount：当 Grain Type 设为 Color 时，设置绿色通道中的颗粒量。用于针对单个颜色控制噪点。

Blue Amount：当 Grain Type 设为 Color 时，设置蓝色通道中的颗粒量。用于针对单个颜色控制噪点。

Red Size：当 Grain Type 设为 Color 时，设置红色通道中的颗粒大小。用于按通道改变颗粒大小。

Green Size：当 Grain Type 设为 Color 时，设置绿色通道中的颗粒大小。用于按通道改变颗粒大小。

Blue Size：当 Grain Type 设为 Color 时，设置蓝色通道中的颗粒大小。用于按通道改变颗粒大小。

Log Grain：控制生成颗粒时使用的色彩空间。“Log”空间会产生更接近胶片的颗粒特征。

Texture：决定原始图像对颗粒分布的影响程度。数值越高，颗粒越会跟随图像的结构。

Sharpen：在添加噪点之前锐化图像。数值越高，边缘和细节越清晰。

Sharpen Edges Only：勾选后，锐化仅应用于明暗对比强烈的图像区域。

Highlight：设置图像高光中出现的颗粒量。数值越低，明亮区域的颗粒越少。

Midtone：设置图像中间调中出现的颗粒量。控制中等亮度范围内的颗粒。

Shadow：设置图像阴影中出现的颗粒量。数值越高，暗部区域的颗粒越多。

Time：默认情况下，此属性连接到合成的 Time。移除此连接可防止颗粒在播放过程中发生变化。
