JavaScript 编辑器

简介

JavaScript Editor 可用于编写 JavaScript 脚本，并在 Cavalry 中运行这些脚本，以创建、连接图层并影响图层。有关如何编写脚本的更多信息，请参阅Scripting 部分。

小心：

脚本会跨会话保存（关闭并重新打开 Cavalry 后它们仍然存在），但需要注意的是，JavaScript Editor 并不是编辑文件系统中文件的方式。可以从文件系统导入文件，但对脚本所做的任何编辑都不会保存回原始文件。

Stallion：

使用 Visual Studio Code 的用户还应该看看 Stallion，这是一个将脚本发送到 Cavalry 的扩展，随 Cavalry 的 Typescript 定义一同提供。

界面

按钮

Run Script：运行当前标签页中的脚本。若只运行所选文本，请在点击此按钮时按住 Option/Alt。

Clear Script：清空当前标签页。

Load...：从文件系统导入脚本。导入时会弹出一个对话框，询问是将脚本加载到新标签页，还是替换当前标签页。

Save As...：将当前标签页保存到文件系统。

Save Encrypted...：将当前标签页以加密格式保存到文件系统。

标签页

  • 使用 + 按钮添加新标签页。
  • 要重命名标签页，右键点击某个标签页并选择 Rename...。
  • 要关闭/移除标签页，右键点击某个标签页并选择 Delete，或点击 x 按钮。

查找

信息：

按 Cmd/Ctrl + F 可将光标/插入符放入搜索字段。

Search field：输入要在脚本中定位的字符串。

Previous：高亮显示与搜索字符串匹配的上一个结果。

Next：高亮显示与搜索字符串匹配的下一个结果。

Replace：勾选后会出现新的一行，其中包含将搜索字符串替换为新字符串的选项。

Replace field：输入用于替换搜索字符串的字符串。

Replace：将当前搜索字符串替换为替换字符串。

Replace All：将搜索字符串的所有实例替换为替换字符串。

编辑器

在此处输入 JavaScript 代码。输入时，新行会自动缩进。

代码注释：

要注释掉代码行，请选择某行或某几行的任意部分，然后使用 Cmd/Ctrl + / 快捷键。每行都会添加注释（//），从而禁用该代码。要对已注释掉的代码取消注释，请使用相同的热键。

自动补全

输入例如 api.、cavalry. 或 ui. 时，会出现自动补全窗口。使用 ⬆︎/⬇︎ 键选择一个选项，然后按 Return 从结果列表中选择所需的成员函数。也可以使用光标双击某个结果。

输入 {、[ 或 " 时，会自动创建匹配的闭合字符。如果删除这样一对匹配字符中的第一个，两个都会被删除。

格式化

要整理脚本的缩进，可以：

  • 使用 Shift + Option/Alt + F；或
  • 右键点击 > Format All。

如果选中了脚本的一部分，则只会格式化该部分，上下文菜单项也会变为 Format Selection。

控制台面板

当点击 Run Script... 时，所有日志都会在此处输出，并根据其状态进行颜色编码。注意，如果JavaScript 控制台已作为工作区的一部分停靠，则此面板会隐藏。

代码片段面板

Snippet Panel 可用于保存代码段以供重复使用。

创建代码片段

要创建代码片段，请在编辑器中选择一段代码并将其拖入 Snippet Panel。

插入代码片段

要将代码片段插入脚本，请将光标置于脚本中的某一行上，然后从代码片段面板中把代码片段拖放到脚本面板中。

导入代码片段

要导入代码片段，可以：

  • 点击 Import... 从文件系统导入有效的 .json 代码片段文件。
  • 将文件系统中有效的 .json 代码片段文件拖放到 Snippet Panel。

重命名代码片段

要重命名代码片段，可以：

  • 双击代码片段的行。
  • 选择一个代码片段并按 Return。
  • 点击 Rename。
  • 右键点击代码片段的行并选择 Rename。

重新排序代码片段

要重新排序代码片段，请在列表中向上/向下拖动它。

删除代码片段

要删除代码片段，可以：

  • 选择代码片段所在行并按 Delete 按钮。
  • 点击 Delete。
  • 右键点击代码片段的行并选择 Delete。

导出代码片段

要导出代码片段，可以：

  • 点击 Export...。
  • 右键点击代码片段的行并选择 Export...。

提示：

可以从支持拖放选中文本块的应用程序（如 TextEdit 或 Sublime Text）直接将文本拖放到 Snippet Panel 中。

运行代码片段

如果代码片段包含可执行代码，可以通过以下任一方式运行：

  • 点击 Run Snippet。
  • 右键点击代码片段的行并选择 Run Snippet。

信息：

代码片段会保存为一个 JSON 字典。

{


    "resourceType": "cavalry.snippets",


    "semVer": "1.0",


    "snippets": [


        {


            "contents": "api.primitive(\"rectangle\");",


            "name": "Example Snippet"


        }


    ]


}

包含 Snippets Panel 中所列代码片段的 snippets.json 文件位于：

  • macOS：~/Library/Application Support/Cavalry/
  • Windows：C:\Users\<USER>\AppData\Roaming\Cavalry\
