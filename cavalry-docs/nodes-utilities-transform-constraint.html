变换约束

简介

将一个图形约束到另一个图形。

界面

Target：要约束到的图形。

Offset：在图形的原始位置上叠加/减去一个值。

Rest Position：当 Position Strength 设为 0 时，图形将返回的位置。

Rest Offset：在 Rest Position 上叠加/减去一个值。

Rest Rotation：当 Rotation Strength 设为 0 时，图形将返回的旋转角度。

Rotated Offset：在 Rest Rotation 上叠加/减去一个值。

Position Strength：Out Position 的乘数。调整此值可决定图形在 0, 0 与 Target 变换之间的向量上的位置。

Out Position [read only]：显示约束输出的 [x, y] 值。Id 连接会将 x 和 y 位置合并，而此属性可让你将各自独立的 [x, y] 属性连接到其他图层。

Rotation Strength：Out Rotation 的乘数。

Out Rotation：将此属性连接到另一个图形的旋转属性。

示例：

用一个图形拿起另一个图形：

快捷方式：

  1. 按照下文（详细方式）的步骤 1-6 操作。
  2. 移动到第 50 帧。
  3. 选择该约束。
  4. 依次进入 Animation > Constraints > Transform Constraint Tools > Pick Up.
  5. 移动到第 150 帧。
  6. 依次进入 Animation > Constraints > Transform Constraint Tools > Drop

现在 Hand 应在第 50 帧“拿起”Ball，然后在第 75 帧再次“放下”它。

详细方式：

  1. 创建 2 个图形
  2. 将其中一个命名为“Hand”，另一个命名为“Ball”。
  3. 创建一个 Transform Constraint。
  4. 连接 constraint.outPosition→ball.position
  5. 将 Hand 作为 Target 连接到 Constraint 上。
  6. 为 Hand 设置 2 个 position.x 关键帧（fr0 = -200，fr200 = 200），使其水平运动。
  7. 将约束上的 Position Strength 的 X 和 Y 都设为 0。
  8. 在第 50 帧，复制 Hand 的 Position X 值，并粘贴到约束的 Rest Position X 中。
  9. 为 Rest Position X 设置关键帧。
  10. 后退一帧。
  11. 以值 0 为 Position Strength X 设置关键帧。
  12. 前进一帧。
  13. 以值 100 为 Position Strength X 设置关键帧。
  14. 跳到第一帧。
  15. 点击播放。

在第 50 帧，Hand 应“拿起”Ball。

  1. 移动到第 74 帧。
  2. 为 Position Strength X 设置关键帧（值应为 100）。
  3. 移动到第 75 帧。
  4. 复制 Hand 的 Position X 值，并粘贴到约束的 Rest Position X 中。
  5. 为 Rest Position X 设置关键帧。
  6. 以值 0 为 Position Strength X 设置关键帧。
  7. 跳到第一帧。
  8. 点击播放。

现在 Hand 应在第 50 帧“拿起”Ball，然后在第 75 帧再次“放下”它。
