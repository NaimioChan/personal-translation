时间轴计数器

简介

使用时间标记或节奏标记随时间累积或触发一个数值。

界面

Count：Read only 当前输出的预览。

Count Target：选择要计数的标记类型：

  • Time Markers：经过时间标记时触发。
  • Beats per Minute：经过设为 Beats per Minute 的节奏标记时触发。
  • Seconds：经过设为 Seconds 的节奏标记时触发。

Time：当前时间。默认连接到合成的 Time 属性。

Count Mode：选择经过标记时应发生的情况：

  • Accumulate：播放头每次经过时间标记或节奏标记时，将 Count 加 1。
  • Trigger：播放头位于时间标记或节奏标记上时，将 Count 设为 1；否则设为 0。

Convolution Size：增加命中标记时数值变化所经历的持续时间。

Convolution Offset：相对于标记，将卷积发生的时间向前或向后移动。

Convolution Graph：在其 Size（持续时间）范围内塑造或缓动卷积。

Filter Marker Color：使用时间标记时，仅对特定颜色的时间标记计数。

Marker Color：选择要筛选的颜色。

示例：

  1. 创建一个图形。
  2. 创建一个 Timeline Counter。
  3. 向时间轴添加若干个时间标记。
  4. 连接 timelineCounter.id→shape.position.y
  5. 为图形的 Position Y 属性添加值为 *50 的属性表达式。
  6. 点击播放。

播放头每次经过一个 Time Marker，图形就会向上移动 50px。
