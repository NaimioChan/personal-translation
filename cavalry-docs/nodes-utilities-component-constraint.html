组件约束

简介

将图形约束到另一个图形的点或边。

界面

Constraint Type：选择要使用的约束类型。

  • Edge Constraint：将图形约束到Target的一条边上。
    • Position Strength：Out Position 的乘数。调整该值可决定图形在 0, 0 与Target的变换之间的向量上的位置。
    • Out Position：将该属性连接到另一个图形的 Position。
    • Rotation Strength：Out Rotation 的乘数。
    • Out Rotation：将该属性连接到另一个图形的 Rotation。
    • Target：连接要约束到的图形。
    • Index：选择要约束到的边 ID。
    • Edge Bias：沿边的长度移动图形。
    • Normal Bias：沿边的法线移动图形。
    • Offset：偏移图形的 Position。
  • Point Constraint：将图形约束到Target的一个点上。
    • Position Strength：Out Position 的乘数。调整该值可决定图形在 0, 0 与Target的变换之间的向量上的位置。
    • Out Position：将该属性连接到另一个图形的 Position。
    • Rotation Strength：Out Rotation 的乘数。
    • Out Rotation：将该属性连接到另一个图形的 Rotation。
    • Target：连接要约束到的图形。
    • Index：选择要约束到的点 ID。
    • Normal Bias：沿点的法线移动图形。
    • Offset：偏移图形的 Position。
