应用字符间距

简介

Apply Character Spacing 可作为文本图形上的样式行为使用，以创建程序化的字距对。这避免了针对每种情况手动设置的需要，非常适合字符串可能发生变化的情况（例如在自动化工作流中）。

界面

添加

Match String - 输入要影响的字符。

Character Spacing - 为匹配的字符串设置字符间距。

示例：

  1. 创建一个文本图形
  2. 在属性编辑器中，单击 Style Behaviour 属性。
  3. 选择 Apply Character Spacing。
  4. 在属性编辑器中拖动 Apply Character Spacing 的 Character Spacing 属性。

注意 Cavalry 中 v 与 a 之间的间距会更新，而其他字符保持不变。将 Match String 中的字符串改为 ly，即可只影响这些字母，或使用 添加新索引
