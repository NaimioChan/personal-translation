视口

简介

视口是渲染合成中的图形并使其可见的地方，从而可以对它们进行可视化合成。

使用工具来选择、变换、编辑和绘制图形，以及编辑受支持的滤镜和着色器。

在视口中使用选择工具悬停在图形上时，会显示图形的名称，并根据图形的复杂程度高亮显示其路径或包围盒，以指示单击时将选中的内容。这种“预选择高亮”的细节级别是自动确定的：

  • Full：对于复杂度较低的图形，所有路径/轮廓都会高亮显示。
  • Medium：当图形复杂度中等时，会为各个子网格绘制包围盒。文本图形有特殊处理：随着字符数量增加，会为每个单词绘制包围盒。
  • Low：对于复杂的图形，只绘制一个包围盒。

显示图层名称：

使用选择工具悬停时显示图层名称是可选的，可通过 View > Show Layer Names on Hover 设置。

选中图形后，会绘制包围盒，并在右上角显示带有图层名称的标签。关于选择组及其子级，请参见组。

信息：

视口的画布（合成之外的区域）颜色可通过首选项窗口中的 Viewport Canvas Color 设置。

多视口

要打开额外的视口，请使用 Window > Add Viewport 菜单项。

当场景中有多个合成时，任何次级视口的页脚中都会出现一个下拉菜单，可用于选择和预览特定的合成。该下拉菜单还包含“活动”合成的选项——即场景窗口中当前打开的标签页。

当场景中有多个合成时，次级视口不会显示播放控件。

播放仅对“活动”合成提供支持，但拖动播放头，或使用热键、播放控件逐帧步进，可以预览非活动合成的动画。非活动合成的当前帧也会在播放停止时更新。

使用多个视口时，任何设置为“活动”合成的视口都会在窗口周围显示紫色边框。

设置

缩放

设置视口的缩放比例。可以使用下拉菜单选择数值，也可以直接输入数值。

快捷键：

  • 在未选择任何内容时，按 F 可将视口缩放设为最佳适配。
  • 在选中图形时，按 F 可将视口缩放设为所选内容的最佳适配。
  • 使用 Cmd/Ctrl + +/- 可将视口缩放逐级放大一倍/缩小一半。

摄像机

当场景中存在多个摄像机时，使用下拉菜单为每个视口选择摄像机视图。

播放

  • Go to the first frame：将播放头移动到播放范围的第一帧。
  • Go to the previous frame：将播放头向后移动一帧。
  • Playback：开始播放。再次点击可停止播放。
  • Go to the next frame：将播放头向前移动一帧。
  • Go to the last frame：将播放头移动到播放范围的最后一帧。

Playback Mode：决定播放过程中播放头到达 Playback End 时会发生什么：

  • Loop Playback：当播放头到达 Playback End 帧时，回到 Playback Start 帧并继续播放。
  • Playback Once：当播放头到达 Playback End 帧时，停止播放。

标签过滤

该图标会变为绿色，表示Quicklist 标签已激活，并正在影响视口中显示的内容。

颜色管理

启用/禁用颜色管理。

选项：

  • 参见颜色管理。

音频播放

全局启用/禁用音频播放。

选项：

  • Play Audio：启用/禁用音频播放。
  • Audio Device：选择用于播放音频的音频设备。
  • Output Channels：选择要输出音频的通道。在 macOS 上可以根据系统设置自动设置。
  • Playback Volume：增大/减小播放时音频的音量。注意，这不会影响导出音频的音量。

音频设备名称：

名称中包含 Unicode 字符的音频设备可能会导致无法向该设备播放音频。这些字符无法在列表中正确显示——请通过操作系统重命名设备以替换或移除它们。

吸附

将图形吸附到网格、其他图形、合成等。

选项：

  • Enable Snapping：启用/禁用吸附。
  • Snapping Threshold：设置距网格多远（以屏幕像素为单位）以内会进行吸附。
  • Grid：启用/禁用网格吸附。
  • Ruler Guide：启用/禁用吸附到参考线。
  • Composition：启用/禁用吸附到合成中心。
  • Bounding Box：启用/禁用吸附到包围盒。
  • Point：启用/禁用吸附到图形的点。
  • Pixel：启用/禁用吸附到 Pixel Grid。像素网格可通过网格设置和视图菜单启用/禁用。

网格

在视口中显示网格线。注意，点击图标只会启用/禁用 2D 网格。

网格偏好：

2D Grid 按“每个合成”保存，而 3D 和 Pixel Grid 则作为偏好设置保存，这意味着即使启用了 2D 网格，也不代表下次创建或加载新合成时它仍会保持启用（除非该合成已保存为启用 2D 网格的状态）。

2D

Show 2D Grid：显示/隐藏 2D 网格。

Copy/Paste Grid：使用这些按钮可将网格从一个合成复制/粘贴到另一个合成。

Grid Type：确定 2D 网格的类型：

  • Regular：带有细分和原点的网格。
  • Swiss：带有间距选项的简单网格。

Origin：当 Grid Type 设为 Regular 时，确定网格原点的放置位置。

  • Centre：将网格原点放在合成中心。
  • Top Left：将网格原点放在合成左上角减去 Margin 的位置。
  • Bottom Left：将网格原点放在合成左下角减去 Margin 的位置。
  • Top Right：将网格原点放在合成右上角减去 Margin 的位置。
  • Bottom Left：将网格原点放在合成右下角减去 Margin 的位置。

Rotation：旋转网格。注意，当 Grid Type 设为 Regular 时，Origin 也必须设为 Centre。

Margins：设置从合成边界开始或裁切网格的距离。

Size Mode：当 Grid Type 设为 Regular 时，选择单元格大小的确定方式：

  • Size Of Cell：以像素为单位设置主网格单元格的尺寸。
  • Number of Divisions：将合成的宽度/高度减去任何边距后，除以此数值来创建主单元格。

Cell Size：以像素为单位设置主 2D 网格线之间的间隙大小。

Subdivision Count：当 Grid Type 设为 Regular 时，确定每个主单元格内创建多少个次单元格。

Gutter：当 Grid Type 设为 Swiss 时，以像素为单位设置单元格之间的间距大小。

Major Line Color：设置 2D 网格主单元格的颜色/透明度。

Minor Line Color：设置 2D 网格次（细分）单元格的颜色/透明度。

3D

Show 3D Grid：显示/隐藏 3D 网格。

Grid Color：设置 3D 网格的颜色/透明度。

Grid Size：以像素为单位设置 3D 网格的总大小。

Grid Step：以像素为单位设置 3D 网格线之间的间隙大小。

Pixel

Show Pixel Grid：显示/隐藏像素网格。像素网格只会在特定的缩放级别下出现，具体取决于当前合成的分辨率。

在播放时更新界面

勾选后，界面会在播放期间更新。这包括场景窗口中的播放头、声音行为上的均衡器以及属性编辑器中的属性等元素。注意，这有时可能会对性能产生不利影响。

信息：

注意，必须禁用播放缓存，才能启用在播放时更新界面。

播放缓存

启用/禁用播放缓存。注意，如果Show Drawables 设为 Except during Playback，则播放被缓存后，可绘制对象（衰减、空对象等）会被隐藏。将其设为 Always 可保持它们可见。

小心：

播放缓存针对整个合成，因此对合成所做的任何更改（时间更改除外）都会清除整个缓存。

显示合成边界

勾选后，会围绕合成边界绘制边框。

选项：

  • Boundary Color：设置合成边界的颜色。

运动路径

勾选后，会在视口中绘制表示所选动画图形方向和速度的路径。参见运动路径。

选项：

  • Show Frames：勾选后，会绘制圆点来表示图形在每一帧上的位置。
  • Show Seconds：勾选后，会沿路径绘制条形来表示一秒。每个条形代表一秒的第一帧。
  • Show Keyframes：勾选后，会绘制较大的圆点来表示图形的位置关键帧。
  • Show Path：勾选后，会在表示每一帧的点之间绘制线条。
  • Show Direction：勾选后，会绘制人字形箭头来指示方向。
  • Path Duration：以秒为单位设置运动路径的可见长度。注意，该值是路径的总时长，因此值为 6 时，当前帧前后各会显示 3 秒。

洋葱皮

在视口中绘制洋葱皮图层。

选项：

  • Onion Skinning：启用/禁用洋葱皮。
  • Pre Color：设置当前帧之前图形的颜色。
  • Pre Frames：设置在当前帧之前绘制多少帧。
  • Post Color：设置当前帧之后图形的颜色。
  • Post Frames：设置在当前帧之后绘制多少帧。
  • Outline Only：不填充每个图形。

剪贴蒙版概览

在视口中绘制剪贴蒙版。

选项：

  • Show Clipping Masks：勾选后，连接到所选图形的蒙版会在视口中以轮廓形式绘制。
  • Fill：勾选后，每当选中连接了蒙版的图形时，视口中都会出现绿色叠加层。

透明样式

设置视口的透明样式。

选项：

  • Use Checkerboard：勾选后，有透明度的区域会显示棋盘格。注意——所有合成都有合成背景。如果 Alpha 设为 255，勾选此设置不会有任何效果（因为没有透明度）。

视口设置

选项：

  • Viewport Quality：设置视口渲染哪些功能。可用于在需要时提高播放速度。注意——此设置不会影响最终渲染。请使用渲染管理器中的对应功能。
    • Full：使用抗锯齿的完整质量。
    • No Anti-aliasing：在视口中关闭抗锯齿。
    • No Anti-aliasing, Shaders or Filters：移除抗锯齿、所有滤镜和着色器以及任何图像过滤（参见图像着色器）。
  • Anti-aliasing：确定 Viewport Quality 设为 Full 时使用的抗锯齿类型：
    • Auto (Recommended)：自动为每个图层选择最合适的抗锯齿方法。
    • Standard：对所有图层使用分析抗锯齿。这能为大多数作品提供出色的质量，并且是典型场景中最快的选项。某些高级功能可能渲染得较慢。
    • Enhanced (MSAA)：对所有图层使用多重采样抗锯齿。这可以在某些作品上产生更干净的边缘，并改善网格、粒子和渐变描边等特定功能的性能。
  • Color Space：当在首选项中启用颜色管理时，默认情况下，RGB 像素值会从工作色彩空间转换为计算机显示器的色彩空间。可以启用其他色彩空间，以预览合成在其他设备上的显示效果。
  • Layer Tools：勾选后，某些图层会显示紫色界面元素，可用于直接在视口中调整其设置。必须选中受支持的图层才会显示这些工具。注意，当图形是另一个图形的父级时，图层工具不可用。
  • Draw Debug Information：在视口中绘制（不可渲染的）诊断信息。这对于可视化复制器中的点 ID 很有用。
  • Show FPS in Playback：在视口底部显示播放期间视口运行的每秒帧数。
  • Viewport Tool Help：勾选后，每个工具的有用提示会叠加显示在视口左下角。
  • Show Drawables：控制可绘制对象（衰减/空对象/摄像机辅助线）的显示
    • Always：始终显示可绘制对象。
    • Except during Playback：除播放期间外显示可绘制对象。
    • Never：从不显示可绘制对象。
  • Shape Depth Debug：可用于诊断某些图形在子网格中的深度。对于 SVG 作品等很有用。

小心：

Debug Information 目前仅支持 pointId，且不会在播放时显示。

上下文菜单

在视口中右键点击图形或空白区域，会弹出一个包含各种选项的菜单：

  • Select：选择光标下的图形。当多个图形重叠时，从菜单项中选择所需的图形。
  • Select Hierarchy：当某个图形是另一个图层的子级时，使用菜单项选择层级中位于其上方的图层。
  • Get Info：显示光标下图形的信息。点击菜单项会将其值复制到剪贴板。
  • Zoom to Fit：缩放视口，使合成适配其中。
  • Zoom：设置视口的缩放级别。
  • Save Snapshot：将视口当前状态的快照保存到某个槽位。
  • Remove Snapshot：从槽位中移除快照。
  • Clear All Snapshots：移除所有槽位中的快照。
  • Copy Layer Id：将图层的 Id 复制到剪贴板，以便用于脚本
  • Copy as SVG：将所选图形以 SVG 数据形式复制到剪贴板。
  • Copy as JavaScript：将所选图形的信息以 JavaScript 代码形式复制到剪贴板。参见Cavalry 模块。
  • Make Editable：将基础形状转换为可编辑图形。
  • Add Background to Selected：通过创建矩形和包围盒工具，为所选图形创建背景。
  • Layout：将所选图形添加到布局中。
  • Bring to Front：将所选图形移到其父级层级的顶部。
  • Bring Forward：将所选图形在其父级层级中上移一层。
  • Send Backward：将所选图形在其父级层级中下移一层。
  • Send to Back：将所选图形移到其父级层级的底部。
  • Add to Duplicator：将所选图形添加到复制器中。
  • Group Selected：将所选图形添加到组中
  • Lock Selected：锁定所选图形，以防意外选中。注意，锁定行为取决于首选项。
  • Show in Attribute Editor：在属性编辑器中载入或显示所选图形。
  • Show in Scene Window：在场景窗口中载入或显示所选图形。
