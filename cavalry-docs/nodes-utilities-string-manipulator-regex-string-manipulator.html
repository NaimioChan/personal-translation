正则表达式字符串操纵器

简介

正则表达式（简称 regex）是用于指定搜索模式的字符序列。正则表达式的一个常见用途是匹配字符串或字符串中的部分内容，以便对结果进行后续处理。例如，默认表达式 a+ 会返回输入字符串中出现的所有字母 a。因此字符串 Cavalry 会输出 aa，因为单词 Cavalry 中有两个 a。

使用正则表达式→

界面

Regex：输入一个正则表达式。字符串操纵器将返回该表达式的结果。更多信息请参见使用正则表达式。

Capture Group Indices：当正则表达式包含捕获组时，确定返回哪些组。列表使用逗号 , 分隔，范围使用冒号 : 分隔。更多信息请参见使用正则表达式。

示例

字符串 正则表达式 描述 结果
Hello World. \s 移除空格 HelloWorld.
As Capably as Cavalry. C.....y 以 C 开头、以 y 结尾的 7 个字母的单词 CapablyCavalry
Is it Colour or Color? Colou?r Colour 或 Color ColourColor
3 is the magic number. \d 任意数字 3
