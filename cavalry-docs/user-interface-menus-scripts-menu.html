脚本菜单

脚本菜单可用于加载带界面的脚本，或直接运行保存在 Scripts 目录中的脚本。该目录位于：

  • macOS：~/Library/Application Support/Cavalry/Scripts
  • Windows：C:\Users\<USERNAME>\AppData\Roaming\Cavalry\Scripts

带用户界面（UI）的脚本可以像其他任何可停靠窗口一样停靠，并作为工作区的一部分保存。

有关编写脚本的更多信息，请参阅脚本：入门；有关如何为脚本安装和创建用户界面，请参阅脚本界面。

界面

Show Scripts Folder：在文件系统中打开存储脚本的目录。保存在此位置的任何脚本都会出现在 Scripts 菜单项下。更多信息请参阅脚本界面。
