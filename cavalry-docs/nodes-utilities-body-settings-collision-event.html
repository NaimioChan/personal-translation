Body 设置碰撞事件

简介

在 Forge Dynamics 模拟中，当动态 Body 与其他 Body 发生碰撞时更新其设置。

界面

Kill on Collision：如果 Body 发生碰撞，则将其从模拟中移除。

Set Sensor：勾选后，将图形设为传感器。

Sensor：勾选后，图形可以触发碰撞事件，但不会触发碰撞。

Set Friction：勾选后，在图形碰撞时设置其 Friction。

Friction：设置图形碰撞时要应用的 Friction 值。

Set Bounce：勾选后，在图形碰撞时设置其 Bounce。

Bounce：设置图形碰撞时要应用的 Bounce 值。

Set Density：勾选后，在图形碰撞时设置其 Density。

Density：设置图形碰撞时要应用的 Density 值。

Set Gravity Scale：勾选后，在图形碰撞时设置其 Gravity Scale。

Gravity Scale：设置图形碰撞时要应用的 Gravity Scale 值。

Use Collision Index：勾选后，每次碰撞都会使其索引加 1。例如，这可以与连接到 Friction 的 Value Array 配合使用——每当图形发生碰撞时，其 Friction 值就会变为数组中的下一个值。

Specific Collisions：勾选后，使用 Collision Numbers 属性定义要使用哪些碰撞。

Collision Numbers：输入一个值，以指定用哪些碰撞来触发该事件。0 是第一次碰撞，使用逗号分隔的值可包含多次碰撞。例如，输入 0,2 将包含第一次和第三次碰撞。

Fade Changes：勾选后，图形将恢复到其原始设置。

Fade Time：定义图形恢复到其原始设置所需的时长（秒）。
