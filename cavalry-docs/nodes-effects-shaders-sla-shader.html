SLA 着色器

简介

创建新颖的噪波效果。

致谢：

SLA Shader 由 David Farmer 授权提供，以纪念 Mark Coleran 的一生。

界面

通用属性 +

Noise Type：选择噪波类型：

Octaves：计算噪波函数所用的倍频数。数值越高，噪波图案中的细节越多。

Scale：增大/减小噪波的缩放。

Offset：在 x/y 上偏移噪波的位置。

Color A：设置一种颜色，供噪波与 Color B 插值。

Color B：设置一种颜色，供噪波与 Color A 插值。

Invert：反转 RGB 颜色。注意这是后期处理，因此并不会“翻转”Color A 和 Color B——alpha 不受影响。

Gamma：设置应用于输入值的伽马校正，大于/小于 1 的值会使图层变暗/变亮。

Displacement：增大此值可生成更动荡的噪波。

Time：此属性会自动连接到合成的帧编号。断开连接即可得到静态噪波。

Time Scale：增大/减小噪波的速度。
