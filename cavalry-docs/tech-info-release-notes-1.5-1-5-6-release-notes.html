1.5.6 版本说明

发布日期：2023年5月10日

1.5 版本说明→

新功能

  • API 新增 getCavalryVersion()。
  • API 新增 getSystemInfo()。
  • API 新增 toNativeFilePath()。

增强

在复制器中使用时，Ray Shape 现在支持碰撞。

重要错误修复

  • 一个长期存在的 macOS 错误——单次撤销可能撤销多个步骤——现在终于被复现，并且我们希望它就此成为历史。这是一个非常难以捉摸的问题，但我们认为它与在时间编辑器中右键单击、然后在不关闭右键菜单的情况下在视口中左键单击有关——这会破坏撤销队列。我们可能尚未找到该问题的所有情形，如果它再次出现，请告诉我们。
  • 修复了删除通过工具架创建的 Forge Dynamics Shape 时导致的崩溃。
  • Sub-Mesh Behaviour 上的 Replace Fill/Stroke 复选框此前失效。
  • 新的 Swap Fill/Stroke 命令此前对 Editable Shapes 无效。
  • 从网站（如 heroicons.com）复制的 SVG 代码，现在粘贴到 Cavalry 中可以正确渲染。
