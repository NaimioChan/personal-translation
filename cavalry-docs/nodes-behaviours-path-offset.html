路径偏移

简介

收缩或扩展路径。

界面

Closed Paths Mode：决定路径偏移的方向：

  • Single Sided：正的 Offset 值会向外偏移路径。
  • Double Sided：同时向内和向外偏移路径。

Open Paths Cap Style：设置开放路径上端点（描边的两端）的外观：

  • Flat：终止于端点的平头端。
  • Round：以端点为圆心的半圆端。
  • Projecting：超出端点半个描边 Width 的平头端。
  • Joined：延长端点，使它们连接路径的两端。

Offset：设置路径偏移的量。

Rounded：为所有外部角点添加圆角。

示例：

  1. 使用钢笔工具绘制一个闭合图形。
  2. 在属性编辑器中，点击 Deformers 属性的 + 图标并选择 Path Offset。
  3. 右键点击 Path Offset 的 Offset 属性，选择 Add Behaviour > Stagger。
  4. 将 Stagger 的 Maximum 设为 100。
  5. 选中该图形，点击复制器图标，该图标位于工具架中。
  6. 将复制器的 Distribution 设为Point。

每个复制出的路径都会变大。可以试着增大复制器的 Count 和/或调整 Stagger 的Graph。

信息：

Path Offset 不支持在同一路径中混合闭合与开放轮廓。路径会作为整体偏移，这在处理文本时能产生更可预测的结果。不过，可以将同一个 Path Offset 连接到多个图形。
