属性编辑器

简介

属性编辑器是核心窗口之一，可加载场景中每个图层的 UI，以便操作属性、设置关键帧和建立连接。

每个图层的属性编辑器 UI 都包含一组独特的属性，这些属性位于 Control Rows 内。

控制行类型→ 控制行交互→

设置关键帧：

属性只有在作为可动画属性时才会出现在场景窗口中，这意味着必须在属性编辑器中为该属性设置关键帧，它才会出现。有关如何设置关键帧，请参见 控件行 - 交互。

可同时加载多个 UI，从而提供全局视图并支持多项操作。

窗口界面

搜索栏

按属性筛选图层 UI。例如：

  1. 选择 4 个图形。
  2. 单击 Show Selected 按钮。
  3. 在搜索栏中输入 “position”。
  4. 拖动 position.x。

每个图形的 position.x 都将被设为相同的值。

UI 数量

指示当前已加载的 UI 数量相对于最大数量。达到最大值时，下一个加载的 UI 将移除堆栈底部的 UI。最大值可通过 Max Attribute Editor UIs 偏好设置 设置。

Live Mode

启用 Live Mode 后，在场景窗口中选择一个图层将清空属性编辑器，并加载所选图层的 UI。

Show Selected

单击此按钮可清空属性编辑器，并加载所选图层的 UI。

Clear All

从属性编辑器中移除所有图层 UI。

图层 UI

依赖关系图

当图层具有输入/输出连接时，将出现此按钮。单击它会加载 依赖关系图 的不可编辑弹出式版本，以供预览。

连接图标

当图层具有输入/输出连接时，此处将显示连接图标。

用户预设

请参见 User Presets。

固定

通过将图层固定到属性编辑器，可使图层保持常驻。将标题栏中的固定图标 设为其绿色状态 ，以防止该 UI 被移除（例如在 Live Mode 下，或在场景窗口中按住 Option/Alt 双击图层时）。

关闭

要将图层的 UI 从属性编辑器中移除，请单击标题栏左上角的 x 图标。

使用图层

图层创建时，其 UI 会出现在属性编辑器中。还有几种方法可将图层 UI 加载到属性编辑器。

  1. 从 场景窗口 将图层拖入属性编辑器。
  2. 在场景窗口中双击某个图层。
  3. 开启属性编辑器中的 Live Mode。开启 Live Mode 后，在场景窗口中选择一个图层将清空属性编辑器，并加载所选图层的 UI。

信息：

在场景窗口中按住 Option/Alt 双击图层，可清空属性编辑器，使新 UI 成为窗口中唯一的 UI。

要了解如何与属性交互，请参见 Control Rows。

高级

在属性编辑器中右键单击图层的标题栏，根据图层类型的不同，以下部分或全部选项将可用。

Copy Layer Id：将图层的 Id 复制到剪贴板。在使用 JavaScript APIs 编写脚本时，这会很有用。

Reset all Attributes：将除 渐变 和 图表 部件之外的所有属性重置为默认值。这不会移除任何连接或关键帧。

Delete all Animation：删除该图层上的所有关键帧。

Advanced

  • Wireframe：勾选后，图形将在视口中以线框显示。

Context

  • Filter Time Offset：从该计算中移除所有 Time Offset Contexts。
  • Filter Index：从该计算中移除所有 Index Contexts。这与 Use Incoming Index 不同，因为它会在该图层上游的整个计算链中禁用 Context（此处为 Index）的使用。
  • Filter Position：从该计算中移除所有 Position Contexts。
