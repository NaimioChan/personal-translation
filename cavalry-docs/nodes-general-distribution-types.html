简介

分布可用于多种其他图层，包括复制器和连接图形。它们提供了一种分布点的方式，这些点随后可用于定位图形。

类型

阵列：通过为每个索引指定位置来分布点。

圆形：以径向图案分布点。

自定义：使用 JavaScript 分布点。

Fibonacci：以斐波那契螺旋图案分布点。

网格：在网格中分布点。

交点：在路径相交处分布点。

线性：在水平或垂直线上分布点。

遮罩：分布点并移除落在另一个图形之外的点。

数学：使用数学表达式分布点。

粒子：将点分布到粒子图形上。

路径：沿路径分布点。

点：在 0,0 处分布点。

随机：将点分布到随机位置。

玫瑰：以玫瑰图案分布点。https://en.wikipedia.org/wiki/Rose_(mathematics

图形边缘：将点分布到另一个图形的边缘上。

图形点：将点分布到另一个图形的点/顶点上。

排序：通过重新排序另一个分布的 Id 来分布点。

打乱：通过重新排列另一个分布的 Id 来分布点。

子网格：将点分布到子网格的位置上。

变换：将点分布到某个图层的位置上。

体素化：通过将另一个图形体素化来分布点。
