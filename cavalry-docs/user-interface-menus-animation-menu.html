动画菜单

Set Transform Keyframes：设置变换关键帧：

  • Position：在当前帧为所有选中图层设置 position.x 和 position.y 关键帧。
  • Rotation：在当前帧为所有选中图层设置 rotation 关键帧。
  • Scale：在当前帧为所有选中图层设置 scale.x 和 scale.y 关键帧。
  • All：在当前帧为所有变换设置关键帧。

Magic Easing：为选中的关键帧添加Magic Easing。

Constraints：向合成添加约束：

  • Transform Constraint：添加一个变换约束。
  • Transform Constraint Tools >
    • Pick Up：在使用变换约束时，自动设置拿起图形所需的关键帧。请参阅变换约束页面上的示例。
    • Drop：在使用变换约束时，自动设置放下图形所需的关键帧。请参阅变换约束页面上的示例。
  • Point Constraint：添加一个设为 Point Constraint 的组件约束。
  • Edge Constraint：添加一个设为 Edge Constraint 的组件约束。
  • Composition Constraint：添加一个合成约束。

Add Null：向当前合成添加一个空对象。

Create Rubber Hose Limb：向当前合成添加一个橡皮管肢体。

Attach Rubber Hose Limb：将橡皮管肢体附加到选中的图形。

Add Animation Control：向当前合成添加一个动画控制。

Add Rig Control (Joystick)：向当前合成添加一个绑定控制。

Add Look At：向当前合成添加一个注视约束。

Add Time Marker：在播放头处添加一个时间标记。

Animate Along Path：运行与沿路径为图形制作动画相关的命令：

  • Move along Path：使用前两个选中的图形，将让第一个沿第二个移动。例如，先选择一个图形，再选择一个路径，然后运行此命令。将创建一个路径查找器，连接到该图形的 Position 和 Rotation，并将该路径作为其 Input Path 添加。
  • Deform along Path：使用前两个选中的图形，将让第一个沿第二个变形。例如，先选择一个图形，再选择一个路径，然后运行此命令。将创建一个路径查找器，作为变形器连接到该图形，并将该路径作为其 Input Path 添加。

Nudge Backward：在时间上将图层/关键帧向后推移。

Nudge Forward：在时间上将图层/关键帧向前推移。

Go to Next Keyframe：将播放头移动到下一个关键帧。关键帧可以按当前选择进行过滤。

Go to Previous Keyframe：将播放头移动到上一个关键帧。关键帧可以按当前选择进行过滤。

Move Layer Start to Current Frame：偏移整个片段，使其从播放头处开始。

Move Layer End to Current Frame：偏移整个片段，使其在播放头处结束。

Set Layer In Point to Current Frame：裁剪片段，使其从播放头处开始。

Set Layer Out Point to Current Frame：裁剪片段，使其在播放头处结束。

Bake Animation：对动画曲线进行采样，并根据首选项窗口中 Bake Animation 部分的所选设置重新绘制它。这些设置可用于减少或增加使用该命令时创建的关键帧数量。此命令还可用于将行为或 Magic Easing 生成的过程化动画转换为关键帧动画。

Reverse Animation：反转选中属性/关键帧的动画曲线。在场景窗口中选择属性或关键帧，然后点击按钮。

Delete Animation：移除选中属性中的所有关键帧。选择一个图层可移除所有属性上的全部动画。

Align Keyframes：将选中的关键帧相互对齐。其工作方式与对齐图形相同。想象在每个属性上每组选中的关键帧周围画一个矩形，然后将这些矩形相互对齐。

  • Align Left：将关键帧对齐到最靠近时间轴起点（左侧）的关键帧。
  • Align Centre：居中对齐关键帧。
  • Align Right：将关键帧对齐到最靠近时间轴终点（右侧）的关键帧。
