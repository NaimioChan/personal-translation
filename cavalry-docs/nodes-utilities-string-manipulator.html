简介

字符串操纵器可用于以程序化方式编辑字符串。

界面

Manipulator：选择操纵器的类型：

  • 更改字符串大小写：更改字符串的大小写。
  • 连接字符串：拼接字符串。
  • 正则：使用正则表达式匹配字符串或字符串的某些部分，以便对结果进行后续处理。
  • 替换字符串：查找字符串中的某些部分并将其替换为另一个字符串。
  • 调整字符串长度：更改字符串的长度。
  • 打乱字符串：打乱字符串的顺序。
  • 子字符串：裁掉字符串的起始/结束部分。
  • 过渡字符串：从一个字符串过渡到另一个字符串。
  • Unicode 偏移：按 Unicode 码位偏移字符串中的字符。

信息：

字符串操纵器可以叠加使用，以影响同一个字符串。单击文本图形 String Manipulators 属性上的黄色输入连接图标，然后将它们拖动到彼此上方/下方，即可重新排序。
