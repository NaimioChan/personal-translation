场景树

简介

场景树位于场景窗口内时间编辑器/曲线编辑器的左侧，由父/子图层与动画属性的双重层级构成。图层可以互相设为父级，用于动画目的和/或整理合成。

场景树的构成

锁定图层

场景树的最左侧有几列开关。最左边的一列包含每个图层的锁定开关。点击每一行的这个区域会显示一个锁图标，它会禁止在视口中选中图形、衰减和 Null 等“可绘制”图层。当需要确保在选择/移动其他图形时不会意外移动某个图形时，这会很有用。锁定图层还会阻止重命名任何类型的图层。

参见 Locking Layers Prevents Selection in the Scene Window 首选项，自定义锁定图层如何影响场景窗口中的选择。

隐藏/禁用图层

第二列包含一个带有眼睛或对勾图标的开关。对于图形、衰减和 Null 等“可绘制”图层，这里会显示眼睛图标，点击该行可以在视口中隐藏或绘制该图层之间切换。对于任何不可绘制的图层，则会显示对勾图标。切换它会启用/禁用该行为/工具/效果（即停止其计算）。

作为另一个图形子级的图形会继承父图形的可见性，因此当父级不可见时，界面中会将该子图形的眼睛图标变暗（当其设置为可见时）。

信息：

隐藏的图形不会被渲染，但当它们连接到其他图层时（例如作为复制器或描边的 Input Shape），仍会被计算。

为图形可见性设置关键帧：

每个图形在属性编辑器的 Advanced 标签页下也都有 Hidden 属性。它同样可以设置关键帧或连接，以随时间隐藏/显示图形。

2.5D

当合成中包含相机时，启用此开关的图形将被置于 2.5D 环境中。

音频播放

Sound 行为图层包含一个用于启用/禁用音频播放的开关。这也会影响音频是否被导出。

为音频播放设置关键帧：

Play Audio 属性位于Sound 行为 的 Advanced 标签页下，可在属性编辑器中为音频播放设置关键帧。

设置标签颜色

使用彩色方块为每个图层设置标签颜色。点击方块会打开一个预定义颜色列表，可用于以视觉方式对图层进行分类整理。

图层颜色也会被时间编辑器和曲线编辑器继承。

标签

点击标签图标可快速分配标签。如果场景中尚不存在这些标签，它们会被创建。

层级

层级是相关图层的集合，以树状排列。父图层会在其下方显示子图层，名称和图标略微向右缩进。层级可以有很多层深。例如，一个子级可以是孙级的父级，依此类推。

创建层级

要让 Layer1 成为 Layer2 的子级，点击并拖拽 Layer1，将其移动到 Layer2 上方。Layer2 周围会出现一个框，表示它将成为 Layer1 的父级。松开鼠标后，Layer1 会位于 Layer2 下方并向右缩进，表示它现在是 Layer2 的子级。

将一个图形拖到另一个图形上时，按住 Shift 会重置子级的变换，使其“吸附”到父级的位置、旋转和缩放。

或者，点击 Layer1 将其选中，然后按住 Cmd/Ctrl 点击 Layer2 将其加入选择，再按 Cmd/Ctrl + P，Layer2 就会成为 Layer1 的父级。如果选中的图层超过两个，则最后选中的图层会成为其他图层的父级。

父图层的图标左侧会出现一个箭头展开图标。它可用于展开或折叠层级，这有助于简化场景树的显示。请注意，折叠层级并不会隐藏图层，它纯粹是整理工具。

对于图形、衰减和 Null 等“可绘制”图层，子图层还会继承父图层的变换。例如，移动父级时，子级会随之移动。

提示：

如果在视口中选中了处于折叠层级中的图层，其父级的展开图标会变为绿色，该行右侧也会出现一条绿色竖线，以便在场景树中更容易找到它。

使用 Edit > Show in Scene Window 命令（Cmd/Ctrl + L）可将场景树滚动到该图层，并展开包含它的任何层级。

从层级中移除图层

要取消图层的父级关系，将其从父级层级中拖到场景树的空白区域，或拖到不同层级的两图层之间，然后松开鼠标。

重新排列层级

图层可以在层级中上移/下移或移入/移出。只需点击并拖拽一个或多个图层在图层列表中上下移动。其他图层之间会出现一条白线，指示该图层将位于列表中的位置。松开鼠标后，图层会在列表中重新定位。注意白线的水平位置。根据图层之间的间隙表示的是展开层级中的最后一个子图层，还是折叠层级下方的位置，线条会相应缩进。

显示/隐藏动画属性

带有动画属性的图层会在层级箭头图标右侧显示一个小圆点。点击该圆点会隐藏该图层的所有动画属性。这有助于专注于整理和场景层级。

提示：

要快速同时显示和隐藏多个图层的动画，可以先选中它们，然后使用快捷键 Cmd/Ctrl + Shift + H 切换 Show/Hide Animation 状态。此选项也可以在编辑菜单中找到。

命名图层

要在 Cavalry 中重命名图层，只需在场景树中选中该行并按 Return 键。这会使名称变为可编辑状态。完成后，再次按 Return 或点击框外以提交名称更改。按 Escape 会停止编辑过程，且不提交新名称。

可以同时重命名多个图层。点击一个图层将其选中，然后按住 Shift 点击另一个图层，将其以及两者之间的所有图层加入选择。按 Return 会将最后选中的图层切换到编辑模式，输入的任何内容都会应用到其他所有选中的图层，并附带后缀（Name 1、Name 2、Name 3……）。

搜索

场景窗口顶部、主图层层级上方有一个搜索栏。要搜索，只需点击该框并开始输入。图层随后会按名称筛选。

也可以通过将图层拖入搜索字段来填充搜索内容。

搜索子图层：

请注意，搜索因作为其他图层的子级而被隐藏的图层时，至少需要输入 3 个字符。这是为了缩小搜索范围，并减少层级被意外强制展开的可能。

编组图层

要对一个图层或一组选中图层进行编组，只需选中图层，然后按 Cmd/Ctrl + G。选中的图层随后会作为新组的子级。

选择图层

点击图层的行内任意位置即可选中图层。使用 Cmd/Ctrl + 点击可在现有选择中添加或移除图层。选择第二个图层时按住 Shift 会选中两者之间的所有内容。

双击图层

操作 结果
双击图层 将该图层的界面加载到属性编辑器。
Option/Alt + 双击图层 先清空属性编辑器，再加载该图层的界面。
Option/Alt + Cmd/Ctrl + 双击合成图层 打开该合成。等同于点击合成图层行上的 Open 按钮。

动画偏移

可以建立连接，在现有任何关键帧动画之上叠加额外的动画。例如，可以为某些线性动画添加Noise 行为，让运动感觉更自然。从图层拾取连接时，任何带有关键帧动画的图层的行上都会出现一个额外的输入。将连接放到该输入上即可创建 Animation Offset。

在曲线编辑器中预览带有已连接 Animation Offset 的图层时，原始动画曲线会以虚影形式显示。

界面

顶部栏

Search：根据搜索结果筛选场景窗口的内容。

Add Layers：访问添加图层窗口的弹出版本，以便向合成添加图层。使用 Cmd/Ctrl + . 快捷键。

Motion Blur：为合成启用运动模糊。

Presets：保存和/或应用合成的预设。

Composition Settings：打开合成设置窗口。

Frame/Timecode display：通过输入数值或拖动控件来设置播放头当前所在的帧。点击 F 或 T 前缀，或按住 Option/Alt 点击输入框，可在帧或时间码显示之间切换。

底部栏

Tags：打开/关闭标签抽屉。

Animation Layer Filter：筛选场景树，仅显示选中的图层及其动画属性。可以使用以下快捷键：

快捷键 结果
U 筛选任何选中的图层，并且如果某些动画属性被隐藏，则会显示它们。如果没有选中任何内容，则筛选整个场景。
Option/Alt + U 筛选任何选中的图层，包括任何带有动画属性的子级，并且如果某些动画属性被隐藏，则会显示它们。
Shift + Option/Alt + U 筛选任何选中的图层，包括所有子级，并且如果某些动画属性被隐藏，则会显示它们。

Time Editor/Graph Editor switch：用于在时间编辑器和曲线编辑器之间切换。
