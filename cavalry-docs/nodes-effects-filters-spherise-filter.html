球面化滤镜

简介

将输入的图形映射到一个可以旋转的球体上。

Aspect Ratio：

为获得最佳效果，被滤镜处理的图形尺寸应具有 2:1 的长宽比。

界面

设置

通用属性 +

Sampling Quality：控制图像的采样/插值方式。这些选项从上到下可视为由低到高质量，在处理文字等精细细节时很有用。

  • Nearest Neighbour：使用最近的像素，不进行混合。
  • Bilinear：在邻近像素之间混合以获得更平滑的结果。适合一般的图像缩放，但可能引入柔和/模糊。
  • Catmull–Rom：一种高质量的重采样方法，可产生更锐利的结果并保留精细细节。
  • Mitchell：均衡的高质量滤镜处理。

Centre：设置球体的位置。

Radius：以图形尺寸的百分比设置球体的半径。

Visibility：在使用包含透明度的图像时，决定球体的哪些面可见：

  • Both：同时显示球体的正面和背面。
  • Front：仅显示球体的正面。
  • Back：仅显示球体的背面。

Rotation：以角度为单位，围绕 X、Y 或 Z 轴旋转球体。

光照

Enable Lighting：为球体表面启用漫反射光照。

Light Position：设置光源的 3D 位置。

Light Intensity：设置光源的亮度。

Light Color：设置光源的颜色。

Ambient Strength：设置环境光的强度（基础照明）。

Ambient Color：设置环境光的颜色。

Specular Strength：设置高光的强度。

Specular Color：设置高光的颜色。

Shininess：设置高光的大小和锐度。数值越高，高光越小、越锐利。

Use as Bump Map：勾选后，图形的材质将被用作凹凸贴图，以增加表面细节光照。

Bump Map Strength：增强/减弱凹凸贴图对表面光照的影响。

Enable Self Shadowing：勾选后，球体背面会添加阴影。

Shadow Intensity：决定阴影区域的暗度。

Shadow Softness：决定阴影由暗到亮过渡的柔和程度。

Back Exposure：设置球体背面/内部表面的亮度。
