挤出

简介

挤出图形以呈现深度感。例如，将椭圆连接到 Extrude 会创建圆柱形图形。

界面

Common Attributes +

Input Shapes：连接要挤出的图形。参见Input List。

Extrude Distance：设置挤出的距离。

Extrude Angle：设置挤出的角度。

Level Mode：这些预设会为你设置 Level 值。有关更多信息，参见子网格。

  • Custom...：手动设置 Custom Level。
  • Text (Lines)：将 Level 值设为 1。
  • Text (Words)：将 Level 值设为 2。
  • Text (Characters)：将 Level 值设为 3。
  • All：影响所有子网格，与 Level 无关。

Custom Level：手动设置 Level 值。

Combine Meshes：启用后，为构成整体图形而绘制的各个网格会合并为单个网格。为 Extrude 添加 Stroke 时，这会使 Stroke 仅保留在外侧边缘。这也可用于消除网格之间有时可见的细缝。

Cap End：启用后，会在挤出的末端添加封盖。这可用于消除网格之间有时可见的细缝。

Back-face Culling：启用后，挤出中不可见的部分不会被绘制。

示例：

  1. 创建一个 Extrude。
  2. 创建一个 Polygon。
  3. 连接 polygon.id→extrude.inputShapes
