1.5.5 版本说明

发布日期：2023年4月26日

1.5 版本说明→

新功能

常规

  • 新增 Edit > Add to Group 菜单项。
  • 新增 Shape > Swap Fill/Stroke 菜单项。

脚本

  • API 新增 disconnectInput()。
  • API 新增 disconnectOutputs()。
  • 新增 onLicenceUpdated 应用程序回调。

增强

常规

  • Text Backgrounds 现在支持 Specific Indices 输入中的 last 标记。
  • Text Backgrounds 现在支持 Specific Indices 的负值，以选择最后、倒数第二、倒数第三等段落/行/词/字符。
  • 现在支持同时启用/禁用所选图层上的 Fill/Stroke。注意：在选择其他图层之前，请确保已打开 Fill/Stroke 标签页（单击该标签页会更改选择）。
  • 来自其他合成的属性连接现在会被如此标注。
  • 现在重新支持通过在时间编辑器中选择图层来删除它们。
  • 通过 right click > Add Behaviour 工作流向属性添加 Random、Oscillator 或 Stagger 行为时，Cavalry 在某些情况下会尝试提供更多帮助。例如：
    • 向默认 Ellipse 的 radius.x 添加 Random 会将 Random 的 Maximum 设为 100（即 Ellipse 的宽度）。
    • 向默认 Ellipse 的 radius.x 添加 Oscillator 会将 Oscillator 的 Minimum 设为 -100，Maximum 设为 100。
    • 向具有 4 种颜色的 Color Array 的 Index 添加 Random 会将 Random 的 Maximum 设为 4。

脚本

  • api.create() 的 name 参数现在是可选的。

重要错误修复

常规

  • 新增了进一步的安全检查，以解决打开特定场景时发生的崩溃。
  • 动画控制 重新支持不从第 0 帧开始的动画曲线。
  • 已解决使用 Specific Indices 的文本背景的多个问题。
  • 改进了与复制器中渐变相关的性能下降问题。
  • 当预合成中包含带有 Shape Time Offset 的图层时，对预合成进行时间重映射会产生不必要的时间偏移。此问题已解决。
  • 修复了在添加关键帧后撤销创建 Ellipse 或 Rectangle 时的崩溃（需要相当特定的步骤）。

脚本

  • 路径动画关键帧此前未被识别为已选中。此问题已修复。

说明

Apple 公证流程的一些变动，导致我们无意中将最低系统要求提高到了 macOS 12。本次发布已按预期恢复为 macOS 10.14。
