Cavalry 团队版

旧版：

本页仅适用于 Cavalry 2.6.1 及更早版本。现已无法创建新的团队，但对已有团队的支持仍在继续。

简介

通过统一计费和批量许可证管理，在整个组织中部署 Cavalry。

多个个人许可证可以组合为一个团队，让组织能够将多个许可证合并到一张发票下。被分配许可证的任何用户都将拥有与 Professional 许可证相同的功能。

团队层级

团队由具有以下角色的用户组成：

  • Owner：团队的所有者。
  • Admin：添加和分配许可证。
  • Member：Admin/Owner 可以将许可证分配给团队成员。
权限 Owner Admin Member
创建团队 ✔️
管理 Stripe 客户门户¹ ✔️
删除团队² ✔️ ✔️
分配/移除 Admin 角色 ✔️ ✔️
添加/移除成员 ✔️ ✔️
添加/移除许可证 ✔️ ✔️
分配许可证 ✔️ ✔️
被分配许可证 ✔️ ✔️ ✔️

¹ Stripe 客户门户包括查看发票、更新付款方式、账单地址和税号，或取消订阅。

² 可通过将许可证数量设置为 0，或在 Stripe 客户门户中取消订阅来删除团队。参见常见问题。

入门流程

要创建新团队：

  1. 访问 welcome.scenegroup.co。
  2. 输入团队 Owner 的电子邮件。
  3. 输入名称并设置密码。
  4. 这将触发验证步骤。输入通过电子邮件发送的验证码以确认你的身份。
  5. 输入团队名称，并可选择添加域名。
  6. 输入付款详细信息以备未来付款之用。此步骤不会产生任何费用。
  7. 确认所需的许可证数量。此时将从你的卡中扣款。
  8. 可选择向团队邀请成员并分配许可证。这会向成员发送电子邮件，若他们尚未拥有账户，则会为其完成注册。点击 Add Myself 为 Owner 分配许可证。或者，此步骤也可通过团队门户完成。

欧盟 VAT 编号：

注册了“共同体内部交易”的欧盟客户应输入有效的增值税/税务信息，其中包括国家代码（例如 GB123456789）。任何税款均按“反向征收”方式处理（从你的发票中移除）。

该信息可通过个人资料部分在团队门户中进行追溯更新。

团队门户

团队门户可供具有 Owner 或 Admin 角色的用户访问，可用于管理团队。

活跃用户：

绿色的个人资料图标表示该用户当前已登录。

团队

团队当前状态的概览，以及以下操作能力：

添加/移除用户

点击“Add Users”按钮邀请新用户加入团队。受邀用户将收到一封包含邀请的电子邮件。兑换后，他们将出现在团队门户的用户列表中。

如果在邀请用户时勾选了“Assign available Licences”，那么在邀请被兑换时若有可用许可证，就会为用户分配一个。

添加/移除许可证

点击窗口顶部的“Add Licences”按钮，以管理团队可用的许可证数量。打开此窗口时，Qty 列中的值代表当前的许可证数量。

添加许可证

要添加更多许可证，请增加 Qty 列中的值。随着该值增加，付款信息会随之更新。额外许可证按按比例方式收费，也就是说费用基于从现在到续订日期之间剩余时间的百分比计算。

移除许可证

要减少团队许可证池中的可用许可证数量，请减少 Qty 列中的值。此阶段不会产生费用或退款。现有许可证将保持激活，直到续订日期，届时可用许可证数量将减少。如果其中某些许可证已分配给用户，则激活日期最早的成员将失去对 Pro 功能的访问权限（谁晚谁出局）。

分配许可证

要为某个用户分配许可证，可以：

  • 点击该用户行上的“Assign licence”按钮。
  • 使用该行右侧的 ... 图标并选择 Assign Licence。

如果有未使用的许可证，就会分配给该用户。如果没有可用许可证，则会出现内嵌结账界面。完成结账后，新许可证即被分配。

取消分配许可证

要取消分配许可证，请使用该行右侧的 ... 图标并选择 Unassign Licence。这会将许可证退回可用许可证池。

许可证类型状态：

Licence type 列表示分配给成员的许可证类型：

  • Team：从团队的许可证池中分配的 Team 许可证。
  • BYOL：成员拥有在团队许可证池之外分配的许可证（Bring Your Own Licence，自带许可证）。
  • -：成员拥有 Starter 许可证，或没有分配许可证。简而言之，他们无法访问 Professional 功能。

分配 Admin 角色（仅 Owner）。

要为某个用户分配Admin权限，Owner 可使用该行右侧的 ... 图标并选择 Assign Admin Role。

预览邀请

点击 Members 列表上方的 ⓘ 图标，可预览所有未兑换邀请的列表。请注意，邀请会在 30 天后过期，并在此后不久从列表中移除。随时可以发送新的邀请；如果同一成员存在多个邀请，其任意一个有效邀请均可兑换。

账单

查看当前订阅的详细信息，包括续订日期、许可证数量和未来费用。

使用指向 Stripe 客户门户的链接管理账单信息，包括付款方式、账单地址和税务，并访问发票。

个人资料

团队资料

点击“Edit Team profile”按钮更新团队名称或团队域名。

你的个人资料

要更新与你个人用户相关的信息，请使用“Manage User profile”按钮链接到你的账户。

常见问题

有按月付款选项吗？

没有，年度订阅是唯一选项。

有最低订购量吗？

创建团队至少需要订购 1 个许可证。

我可以添加其他电子邮件地址来接收发票吗？

目前无法通过团队门户实现，但 Admin 用户可通过电子邮件提出申请。请在申请中提供团队的相关信息。

如果在订阅期中间添加新许可证会怎样？

额外许可证按比例收费，也就是说如果年度订阅已过一半，则只收取年度订阅剩余 6 个月的费用。这能让整个团队的续订日期保持同步。续订日期到来时，该许可证将按全价收取下一年的费用。

如果在订阅期中间取消许可证会怎样？

该许可证将在续订日期被移除。在此之前它保持激活，此后不再收费。不提供退款。

如果所有许可证都被取消会怎样？

所有许可证将在续订日期到期，团队将被移除。如果你在续订日期前改变主意，请通过团队门户添加 1 个或多个许可证。

如何删除团队？

要么在团队门户中将许可证数量减至 0，要么通过团队门户的账单部分在 Stripe 客户门户中点击 Cancel Subscription 按钮。团队和所有许可证将保持激活，直到续订日期，届时团队将被移除。如果你在续订日期前改变主意，请通过团队门户添加 1 个或多个许可证，和/或在 Stripe 客户门户中点击 Renew Subscription 按钮。

你们提供采购订单/发票服务吗？

使用团队门户需要刷卡付款，但如果需要发票，请联系我们。

你们接受其他货币付款吗？

目前使用团队门户需要以 GBP 刷卡付款，但如果你想讨论以 EUR 或 USD 付款，请联系我们。

如何转移团队的所有权？

无法直接通过团队门户完成，请使用 Owner 的电子邮件地址联系我们，并提供新 Owner 的相关信息。

如何解决未通过 3D Secure 验证的付款？

当付款未通过 3D Secure 验证时，团队 Owner 将收到一封说明如何解决该问题的电子邮件。Admin 用户应联系 Owner。

说明

一些示例场景及其结果：

场景 1

  • 为订阅添加 4 个许可证，并分配给团队成员。
  • 之后通过团队门户将许可证数量减少到 3。

结果：全部 4 个许可证保持激活，但在续订日期，激活日期最早的成员将失去对 Pro 功能的访问权限（谁晚谁出局）。使用团队门户的团队部分进行任何更改。

场景 2

  • 一个大项目结束，因此通过团队门户将许可证数量从 10 减至 0。
  • 后来有新项目到来，预计会持续到续订日期之后，因此将许可证数量增加到 5。

结果：在续订日期，可用许可证数量将从 10 减少到 5，并据此收费。任何已分配的许可证将从激活日期最早的成员处移除（谁晚谁出局）。使用团队门户的团队部分进行任何更改。

场景 3

  • 通过团队门户将许可证数量从 5 减至 3。
  • 之后将许可证数量增加到 6。

结果：新增的许可证按比例金额收费，可用许可证数量将从 5 增加到 6。在续订日期，将按 6 个许可证收费。
