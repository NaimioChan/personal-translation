命令搜索

简介

快速搜索并执行 Cavalry 命令，包括创建图形、打开窗口、运行菜单项和打开脚本。

界面

在应用程序的任意位置输入 /（斜杠）即可调出该窗口。搜索命令并按 Return 即可执行。

最近执行的三条命令会出现在搜索栏上方，便于快速访问。

快速操作

通过从列表中选择“Quick Action”，可以执行某些操作。选择 Quick Action 后，Command Search 窗口会滑动到针对当前选择的、与所选操作相关的选项列表。

在应用程序的任意位置输入 Option/Alt + /（斜杠）即可调出按快速操作筛选的窗口。

Keyframe…

显示所选图层所有可设置关键帧的属性。选择某一行，会在当前帧为与该行关联的属性创建关键帧。

也可以为例如 position.x 添加关键帧：

  • 选择一个图形。
  • 输入 Option/Alt + /。
  • 开始输入“Position”。
  • 使用 ⬆︎/⬇︎ 方向键选择 Position 行。
  • 输入 Option/Alt + X

设置 RGB 关键帧时使用 XYZ。例如，选中 material.materialColor 行后，输入 Option/Alt + X 可为 material.materialColor.r 设置关键帧。

当属性包含 4 个通道（例如红、绿、蓝、Alpha）时，使用 W 设置第四个通道。

Presets…

显示所选图层所有可用的预设。选择某一行会应用相应的预设。
