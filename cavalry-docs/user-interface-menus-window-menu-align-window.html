对齐窗口

简介

对齐和分布图形的边界框，或对齐路径的点。

界面

此窗口会根据启用的是选择还是编辑图形工具而显示不同内容。

选择工具

要将图形与其他所选图形对齐或分布，只需选中多个图形，然后从下方的选项中选择。

按住 Option/Alt 键点击下方选项，可将图形对齐或分布到合成。

编辑图形工具

要将点与其他所选点对齐，只需选中多个点，然后从下方的选项中选择。

按住 Option/Alt 键点击下方选项，可将点对齐到合成。

按住 Shift 键点击下方选项，还会对齐点的 handles。

信息：

如果仅选中一个图形，对齐选项将默认基于合成。

选项

对齐

  • Left Align：水平对齐所有所选图形/点的左边缘。
  • Centre Align：水平对齐所有所选图形/点的中心。
  • Right Align：水平对齐所有所选图形/点的右边缘。
  • Top Align：垂直对齐所有所选图形/点的上边缘。
  • Middle Align：垂直对齐所有所选图形/点的中心。
  • Bottom Align：垂直对齐所有所选图形/点的下边缘。

分布

  • Horizontal Distribution：水平分布所有所选图形。
  • Vertical Distribution：垂直分布所有所选图形。
  • Even Distribution：均匀分布所有所选图形（水平和垂直方向）。

小心：

distribution 选项仅支持在使用 Select 工具时影响图形。

信息：

  • 图形的分布范围位于第一个和最后一个所选图形之间。
  • 基于选择分布图形时，至少需要三个图形。如果仅选中两个图形，则会基于合成应用 Horizontal 或 Vertical Distribution（相当于按住 Option/Alt）。
