2.0.2 版本说明

发布日期：2024年2月8日

2.0 版本说明→

新功能

  • 新增 最短路径图形。

增强

  • 资源窗口中的文件资源现在会添加标签，以显示该资源被使用的次数。
  • 资源窗口中的资源新增 “Reveal in Scene Window” 选项。
  • 自动裁剪现在支持椭圆形遮罩。
  • 渲染为 WebM（VP8/VP9）新增比特率选项。

重要错误修复

  • 修复了导致使用 api.WebClient() 的脚本无法在同一会话中启动两次的问题。这尤其影响了 Scenery 上传脚本。
