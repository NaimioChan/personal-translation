JavaScript 图层

简介

JavaScript 可用于多种图层，包括 JavaScript 工具、JavaScript 图形、JavaScript 变形器、JavaScript 发射器、JavaScript 修改器 和 JavaScript 发射器，以在 Cavalry 中设置多种属性类型。

可从表达式写入的主要数据类型有：

名称 attrType 描述
Double double 带小数位的数字。例如 4.153。
Double2 double2 由两个 double 组成的集合。例如 Position 103.453, 487.543。
Double3 double3 由三个 double 组成的集合。例如 Position（2.5D）103.453, 487.543, 50.730。
Int int 整数是不含小数点的数字。例如 4。
Int2 int2 由两个整数组成的集合。例如 Composition Resolution 1920, 1080。
Bool bool 具有两种状态的复选框：1 或 0（开/关）。
String string 可包含字母数字字符和符号。
Color color 包含 R、G、B 和 A 值的属性。
Point Data pointData 由 Distributions 生成的点。参见使用点数据。
Asset assetId 接受 .json、.txt 或 .csv 资源。参见使用资源。
Layer layerId 接受任意图层。参见使用图层数据。

这意味着在 Cavalry 中，支持 JavaScript 的图层可以连接到上述任意数据类型。

连接两个不兼容的数据类型（例如表达式返回 int，但 JavaScript 连接到了 string）会触发自动转换数据类型的尝试，但强烈建议正确匹配输出类型，以便更好地控制浮点精度等因素。

上述所有类型也可作为输入使用，并可在脚本中通过属性名引用。要将其他属性添加为变量，请点击界面底部的 + 按钮并选择相应的数据类型。随后即可从另一个数据类型匹配的属性建立输入连接。默认情况下，变量名是字母 n 后跟数字，例如 n0、n1。不过，右键点击该属性并选择 Rename 即可重命名。

变量名称：

变量名称区分大小写，且不得包含空格。

JavaScript 会导入一个 上下文模块，其中包含若干可与 复制器 配合使用的有用成员。

  • ctx.index：Duplicator 的 Index。
  • ctx.count：Duplicator 的 Count。
  • ctx.positionX/ ctx.positionY：Duplicator 点的位置。
  • ctx.layerId：请求 JavaScript 图层进行计算的图层 id。
  • ctx.attributeId：请求 JavaScript 图层进行计算的属性 id。

有关使用这些值的示例，请参见 Create > Demo Scenes > JavaScript > Position to Color 预设。

复杂数据类型（color、int2、double2）是遵循以下模式的简单 JavaScript 对象：

let color = {

    r: 200,

    g: 100,

    b: 50,

    a: 255

};



let someDouble2 = {

    x: 200.4,

    y: 55.6

};

为简便起见，输入值可以被修改或返回。

使用此图层编写 JavaScript 表达式的主要规则是它必须返回一个值。例如，以下表达式调用了一个返回值的函数：

function toCelsius(fahrenheit) {

    return (5/9) * (fahrenheit-32);

}



toCelsius(n0);

全局变量：

在全局层级设置变量时，请使用 var 而不是 let/const。由于 JavaScript 图层每帧都会运行，全局使用 let/const 会失败，因为表达式第二次运行时变量已经存在，无法重新赋值。

使用资源

JavaScript 可以利用 JSON/Text/CSV 资源（CSV 资源包括 Google Sheets 和 Microsoft Excel）。要将这些资源类型之一用于 JavaScript 图层，请点击 + 按钮并选择 Add Text/JSON/CSV Asset。这会创建一个新的属性，可接受受支持的资源作为输入。

  • Text 资源将作为字符串加载。
  • JSON 资源将作为 JSON 对象字面量加载。
  • CSV 资源将作为 JSON 对象字面量加载。
    • 顶层对象属性将与列名一致。
    • 每一列包含：
      • rows：行数据数组（数字或字符串）。
      • min：该列中的最小数值（如果该列为数值型）。
      • max：该列中的最大数值（如果该列为数值型）。
// Print out all the column names of a CSV connected to Attribute 'n1'.

var columns = Object.keys(n1);

for (var columnName of columns) {

    console.log(columnName);

}
// Return the maximum value in a column titled 'Cavalry' from a CSV/Google Sheet connected to Attribute 'n1'.

n1.Cavalry.max;

// If the column title contains spaces. e.g. 'Cavalry Users'.

n1["Cavalry Users"].min;
// Return the total of all the values in a column titled 'Cavalry Users' from a CSV/Google Sheet connected to Attribute 'n1'.

function setSum() {

    let total = 0;

    for (let row of n1["Cavalry Users"].rows) {

        total += Number(row)

    }

    return total;

}



setSum();
// Given a JSON asset connected to Attribute 'n1', output the value for the "title" key.

// Connect the JavaScript Utility to a Text Shape's String.

/* Contents of example.json

{

    "data": {

        "title": "My Title",

        "body": "This is some body text."

    }

}

*/

n1.data.title

使用点数据

  1. 创建一个 JavaScript 变形器。
  2. 点击其属性编辑器界面底部的 + 按钮，选择“Add Point Data”以添加一个新的动态属性。
  3. 创建一个 复制器。
  4. 右键点击 Distribution 属性并选择 Reveal Generator。
  5. 删除 Duplicator（保留 Grid Distribution）。
  6. 连接 gridDistribution.id→javaScriptDeformer.n1
  7. 将 JavaScript 输入中的代码替换为以下任一项：
    • console.log(n1.points[0].position.x); 或；
    • console.log(n1.points.length);
  8. 创建一个图形。
  9. 连接 javaScriptDeformer.id→shape.deformers

将播放头步进到下一帧，即可把值打印到 JavaScript 控制台。第一个示例将输出第一个 pointId 的 position.x（更改 [0] 中的值可返回其他 pointId），而第二个示例将返回 Distribution 中的点数（默认 3x3 网格为 9）。

使用图层数据

所连接图层的类型决定哪些对象可用：

  • Drawable（例如 Null、Falloff）：将提供一个 layer 对象，包含以下 2D 世界空间变换变量：
    • position（例如 n1.layer.position、n1.layer.position.x）
    • rotation（例如 n1.layer.rotation、n1.layer.rotation.z）
    • scale（例如 n1.layer.scale、n1.layer.scale.x）
  • Shape（例如 Rectangle、Duplicator）：将提供一个 mesh 属性（例如 n1.mesh），表示局部空间中的网格层级结构。mesh 属性是 Mesh class（来自 Cavalry 模块）的实例。

使用 Layer 动态输入时，可用 hasInput 判断是否已连接图层。例如，这可以避免尝试读取不存在的网格数据。

// Assuming 'n1' is a Layer dynamic input.

console.log(n1.hasInput);

// Returns true if a Layer is connected 'n1'.

2D 与 2.5D 旋转：

JavaScript 不区分 2D 和 2.5D 图层，因此对于 2D 图层请使用 rotation.z。

// Closest Point on Path example.

// Paste this into the JavaScript Editor and then hit 'Run Script'.



// Create a Null and two Shapes

const nullId = api.create("null", "Move Me!!");

const ellipse1Id = api.primitive("ellipse", "Ellipse");

const ellipse2Id = api.primitive("ellipse", "Path");

api.setFill(ellipse2Id, false);

api.setStroke(ellipse2Id, true);

api.set(ellipse2Id, {"generator.radius": [350,350]});



// Create a JavaScript Utility.

const jsUtil = api.create("javaScript");

// Add the dynamic attributes and the expression.

api.addDynamic(jsUtil, "array", "layerId");

api.addDynamic(jsUtil, "array", "layerId");

const expression = 'function getPoint() {\n\xa0\xa0\xa0\xa0let toPt = n2.layer.position;\n\xa0\xa0\xa0\xa0let closestPoint = n1.path.findClosestPoint(toPt.x, toPt.y);\n\xa0\xa0\xa0\xa0return closestPoint.position;\n};\ngetPoint();'

api.set(jsUtil, {"expression": expression});



// Make the connections.

api.connect(ellipse2Id, "id", jsUtil, "array.1");

api.connect(nullId, "id", jsUtil, "array.2");

api.connect(jsUtil, "id", ellipse1Id, "position");

依赖输出的计算

JavaScript 图层是 Cavalry 中唯一能确切知道是哪个图层和哪个属性触发了计算的地方。可以利用这一信息，根据正在计算的是哪个连接来输出不同的值。使用 ctx.layerId 和 ctx.attributeId 属性即可访问该信息。

// In this example we assume a JSON Asset is connected to the JavaScript layer's n1 Attribute.

function getText() {

    if (ctx.layerId == "textShape#1") {

        // If textShape#1 is asking JavaScript for a value, return a given JSON value

        return n1["colors"]["Green"];

    } else if (ctx.layerId == "textShape#2") {

        // If textShape#2 is asking JavaScript for a value, return a different JSON value

        return n1["colors"]["Yellow"];

    }

    return "None";

}



getText();

表达式中的错误将打印到 JavaScript 控制台。

小心：

通过 Cmd/Ctrl + Return 运行表达式时，必须建立输出连接，表达式才会运行。
