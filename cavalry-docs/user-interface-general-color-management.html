色彩管理

注意：

色彩管理是“选择性启用”的功能，目前被视为技术预览。

简介

色彩管理确保设计在不同设备和导出格式下看起来一致。Cavalry 采用管线式流程，色彩会流经各个不同的阶段。

色彩管理可通过首选项启用，或通过项目设置针对单个项目覆盖设置。也可以通过Viewport Settings启用/禁用。

“禁用”实际意味着什么：

禁用色彩管理时，Cavalry 仍会执行色彩运算，只是对Working Space和视口的Display Color Space都使用 sRGB。这等同于启用色彩管理、将 Working Color Space 设为 sRGB，并将视口的 Display Color Space 设为 sRGB，也就是说，即使禁用了色彩管理，色彩依然可预测。

工作色彩空间

Working Color Space 决定所有内部渲染运算（混合、抗锯齿、渐变和合成）所使用的色彩空间。

色彩管理不会影响以下内容：

  • 色彩始终以 sRGB 输入或拾取。
  • 色彩始终以 sRGB 随场景（.cv）一起存储。
  • 平面的纯色最终外观不受影响。

视口显示色彩空间

视口的 Display Color Space 控制合成在屏幕上的显示方式。这是一种预览变换，会把工作色彩空间转换为目标显示配置文件。

色轮外观

视口的 Display Color Space 会有意影响色轮的外观，以便在拾取颜色时显示目标显示设备可用的色彩范围。

渲染

以下格式在渲染时会自动嵌入工作色彩空间。这能确保导出结果在其他应用程序中正确显示：

  • PNG
  • JPEG
  • WebP
  • Quicktime
  • WebM
  • MP4

资源

所有图像/视频资源和渲染结果都会进行色彩管理，但 GIF、SVG 和 Lottie 除外，无论工作空间是什么，它们都会转换为 sRGB。

这一设置会根据资源的色彩配置文件自动确定，但可以在资源窗口中右键点击某个资源并选择 Color Settings... 来覆盖。这会打开一个新窗口，其中包含以下选项：

Interpret As：选择一个色彩配置文件，以覆盖检测到的色彩配置文件。

使用场景：

  • 素材没有嵌入色彩配置文件时。
  • 嵌入的色彩配置文件不正确时。
  • 素材是在其他色彩空间中拍摄、需要重新解释时。

Linearise：保留色域，将传递函数替换为线性（gamma 1.0）。

Preserve RGB：勾选后，色彩管理会被绕过，原始 RGB 值不经转换直接传递。

使用场景：

  • 其他图层（如图像采样器）需要从资源中采样亮度值时。

常见问题

为什么色彩以 sRGB 存储？

这是目前的限制，未来计划支持更广的色域范围。

GIF/Lottie 导出效果不同，为什么？

无论工作色彩空间是什么，这些网络格式始终会转换为 sRGB。

Gamma 2.4 与 Rec.709

  • Rec.709 是摄像机编码标准。
  • Gamma 2.4 (BT.1886) 是广播监视器的显示标准。

当内容被标记为 Rec.709 时，Cavalry 使用 Gamma 2.4 进行显示。这可以通过资源的 Color Settings... 覆盖。
