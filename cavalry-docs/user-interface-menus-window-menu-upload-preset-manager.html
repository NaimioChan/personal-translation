上传预设管理器

简介

创建和编辑预设，随后可在渲染管理器的 Advanced 标签页中选择这些预设，以便在渲染过程中上传图像/视频。

界面

Preset：选择一个现有预设进行编辑。点击 + 图标创建新预设，或点击垃圾桶图标删除当前选中的预设。

Preset Name：为预设命名。该名称将显示在渲染管理器的 Upload Preset 下拉属性中。

URL：输入基础 URL。

Path：输入该 URL 的端点。

Automatic MIME Types：自动检测并设置内容类型。

Authentication Type：选择身份验证方式：

  • Basic：手动添加身份验证 Header。
  • Bearer：身份验证需要 Bearer Token 或 API 密钥。选择此选项后，在下方添加 Token。
  • None：不需要身份验证 Header。

Token：输入密码/令牌/密钥。

Headers：以键值对形式输入所需的标头信息。使用 + 按钮添加更多标头。

提示：

添加预设后，必须关闭并重新打开渲染管理器，新的 Upload Preset 才会出现。

信息：

web3.storage 已预先配置，仅允许编辑 Token。

小心：

目前无法从列表中删除 Headers，但空标头会被忽略，因此不会造成影响。
