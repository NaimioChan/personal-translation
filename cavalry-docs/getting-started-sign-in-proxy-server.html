代理服务器

简介

Cavalry 可以设置为通过代理服务器向许可服务器发送 https 请求。这在企业网络中通常是必需的。

设置

要进行设置，只需在 Sign In 窗口中展开 Web Proxy 下拉区域并输入你的信息。

Enable：启用/禁用服务器。

Address：IP 和端口号。例如 https://192.168.1.2:1234

Username：输入你的用户名（可选）。

Password：输入你的密码（可选）。

信息：

注意：如需稍后修改这些设置，请前往 Help > Sign Out 打开登录窗口。

旧版设置

危险：

以下为旧版方法。它仍然有效，但将被弃用。上述登录窗口是首选方案。

  • 创建一个名为 web_proxy.json 的文本文件，其中包含以下代码（将 url 和端口号替换为适合你网络的设置）：
{

  "address": "http://192.168.1.2:1234"

}
  • 将此文件放入：
    • macOS - ~/Library/Preferences/Cavalry/
    • Windows - C:\Users\<USER>\AppData\Local\Cavalry\
  • 重启 Cavalry
  • 登录。

信息：

AppData 和 ~/Library 是隐藏文件夹。要找到它们：

  • Windows - 在 Explorer 的 View options 中勾选“Hidden Items”。
  • macOS - 在 Finder 中，打开 Go 菜单时按住 Option/Alt，Library 便会显示出来。

如有需要，可以在文件中添加更多字段。

{

  "address": "http://192.168.1.2:1234",

  "enabled": true,

  "username": "yourUsername",

  "password": "yourPassword"

}
  • address → string：（必填）输入代理 IP。
  • enabled → bool：（可选）输入 true/false 以启用/禁用代理。
  • username → string：（可选）为需要身份验证的代理输入用户名。
  • password → string：（可选）为需要身份验证的代理输入密码。
