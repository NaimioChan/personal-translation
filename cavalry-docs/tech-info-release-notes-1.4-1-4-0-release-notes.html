1.4 版本说明

Release date: 17th Oct 2022

文件版本升级：

在 Cavalry 1.3.1 或更早版本中创建的场景，在 Cavalry 1.4 中打开时会被转换。文件会被复制为一个需要保存的新场景——打开时你会注意到旧场景被命名为 <yourSceneName> [Converted].cv。在 1.4 及更高版本中保存的任何场景将不兼容旧版 Cavalry。

CPU 渲染器：

由于滤镜和着色器存在性能问题，我们在 Cavalry 1.4 中移除了 CPU 后端。

新功能

图形

  • 挤出：为图形添加 2D 挤出。
  • 连接图形：新增自动贝塞尔模式，用于在点之间绘制平滑曲线。
  • 沿路径的文本：沿路径定位文本。它与 Pathfinder 的区别在于它不是变形器。
  • Scale to Fit Text Box：文本图形上的新功能。它会缩放字号，以便让大量文本保持在文本框内。
  • 图形新增 Freeze Calculations 属性。可在 Advanced 选项卡下找到，用于“暂停”计算以优化合成。

工具

  • 调度组：以程序化方式在时间上定位图层。
  • 时间轴计数器：使用时间或节拍标记来随时间累积或触发数值。
  • 累加器：创建图形的“堆叠”或自定义布局。

效果

  • 像素排序滤镜：按亮度等各种属性对图层的像素进行排序，从而重排像素。
  • 狭缝扫描滤镜：创建动画飞越效果。
  • 扫描线滤镜：模拟 CRT 显示器。
  • 刮擦滤镜：从一条线拉伸像素以创建涂抹效果。
  • 边缘检测滤镜：将图像中颜色的边界转换为线条。
  • 锐化滤镜：增加边缘像素之间的对比度，使画面看起来更锐利。
  • 暗角滤镜：模拟通过某些类型镜头观看图像时的光线衰减特性。
  • 色调分离滤镜：通过将图形的颜色变化减少为纯色调或纯色，营造低色深效果。
  • HSV 调整滤镜：调整图形的色相、饱和度和明度。
  • 内阴影滤镜：为图形添加内阴影以模拟深度。

渐变：渐变着色器已重写，现在具备多项新功能：

  • 新增 Stop Interpolations：以更多样的方式混合 Color Stop。
  • 新增 Jitter 属性：在 Color Stop 之间添加噪波。
  • 新增 Wrap UVs 选项：当位置 0 或 1 处没有 Color Stop 时环绕渐变。
  • 新增 Shape Gradient：沿半径（由中心向外）创建的多边形渐变。

渐变着色器和刮擦滤镜现在还包含新的图层工具，可在视口中与属性交互。

常规

  • 快捷键管理器：将自定义快捷键映射到命令。
  • 上传预设管理器：创建和编辑预设，以便在渲染时将文件上传到在线位置。
  • 按 / 启动命令搜索，以搜索并运行任何基于菜单的命令。
  • 时间重映射：为合成重新映射时间。参见合成菜单。

场景窗口

时间编辑器已完全重写。值得注意的改进包括：

  • 交互速度快了很多。
  • 现在可以按住 Option/Alt 点击并拖动关键帧来复制它们。
  • 现在可以将关键帧/片段端点吸附到其他关键帧/片段端点/时间标记。
  • 现在会标示设置为循环的动画曲线。
  • 在触控板上双指捏合缩放。
  • 新增时间标记。
  • 新增节拍标记。
  • 自定义魔法缓动表达式：通过时间编辑器或曲线编辑器中的上下文菜单，为魔法缓动设置自定义表达式。
  • 当图层在时间编辑器中位于“屏幕外”时，该行左侧或右侧会出现新的 < 或 > 指示器。点击它们会平移视图，重新框选该图层。
  • 已知缺失的功能（来自 1.3.1）：
    • 拖动关键帧栏的各个区段。
    • 用于设置片段起点/终点的上下文菜单选项。
    • 变换工具不再包含波纹编辑功能。

渲染管理器

  • 新的 Advanced 选项卡中新增了 Upload 选项。
  • 新增 Metadata：随任意输出一起导出元数据。

资源窗口

  • 图像智能文件夹：导入整个目录的图像资源（静帧、影片和图像序列），然后通过“键”引用它们，无需逐个导入和引用。
  • 音频智能文件夹 [beta]：导入整个目录的音频资源（.wav、.aiff），然后通过“键”引用它们，无需逐个导入和引用。

脚本

现在可以使用 JavaScript 编辑器中的 Save Encrypted... 按钮保存加密脚本。加密后源码将被混淆，但脚本仍可通过 Scripts 菜单读取。可用此技术分发闭源脚本。JavaScript 编辑器也已改进，换行时会自动缩进，并会自动补全括号。

新增 API

  • 用于按相对量移动选中可编辑点的 movePoint API。
  • 用于将选中可编辑点移动到指定位置的 setPointPosition API。
  • hasStroke、hasFill 和 getCurrentGeneratorType API。
  • preCompose、createCompReference 和 getCompFromReference API。
  • 所有 UI 控件新增 setFixedHeight(int) 和 setFixedWidth(int)
  • ui.Label() 新增 setBackgroundColor(string)、setFontSize(int) 和 setTextColor(string)
  • ui.VLayout() 新增 addSeparator(string)
  • ui.ColorPicker()，提供一个可从屏幕拾取颜色的吸管按钮。
  • ui.ColorWheel()，提供用于脚本的基础色轮 UI。
  • ui.Slider()
  • api 模块新增 getArrayCount(layerId:string, attrId:string)，用于返回数组属性中子项的数量。
  • api 模块新增 resetAttribute(layerId:string, attrId:string) 和 resetLayerAttributes(layerId:string)。
  • api 模块中的 getAppAssetsPath() 方法，用于返回 App 资源的位置。这对于访问 Cavalry 的图标等以在脚本中使用很有用。
  • api 模块新增 createTimeMarker(time:int) removeTimeMarker(markerId) getTimeMarkers()。
  • NumericField 新增 onValueChanged() 回调函数
  • api.runDetachedProcess(...)，将在独立线程中运行进程（例如上传或 ffmpeg 压缩）。
  • api.makeFolder(...)，将在文件系统上创建文件夹。
  • 用于 ImageButton UI 的 setState() 函数。
  • api.getPlatform() API。将返回 macOS 或 Windows。

破坏性变更：

  • getSelectedAttributes() 现在返回一个包含独立 layerIds 和 attrIds 的对象。

增强

常规

  • 自动保存现在仅在内容发生变化时保存。
  • 改进了 Lottie 导出中路径方向的处理方式。
  • 视口上下文菜单（右键）新增 Copy as JavaScript 选项。这会复制图形的绘制指令，之后可在 JavaScript 中使用以重建该图形。
  • 现在可以通过将色板拖放到视口上来设置 Composition Background 颜色。将色板拖放到图形上仍会设置该图形的颜色。
  • 动画菜单中已添加 Reverse Animation、Delete Animation 和 Align Keyframes（因此可在快捷键管理器中为它们设置快捷键）。
  • Reverse Animation 现在可用于关键帧选择。
  • 所有图形的 Advanced 选项卡下新增 Draw on top of Parent 复选框。用于反转绘制顺序和层级的默认行为。注意，取消勾选时，子级不会继承父级的 Opacity。

用户界面

  • 新增 Darker UI，以改善对比度。
  • 在 Windows 上，打开偏好设置窗口的菜单项已从 Window 菜单移至 Edit 菜单。在 macOS 上仍保留在 Cavalry 菜单中。
  • 工具架新增项：
    • 沿路径的文本
    • 挤出
    • 将选中项添加到调度组和 Sequence。
    • 将选中项添加到调度组和 Stagger。
  • 现在加载包含大量资源的场景时会显示进度条。
  • UI 优化：当开启 Update the UI During Playback 时，UI 对播放的影响应会降低。
  • Quick Add Window 搜索改进。匹配算法已大幅改进。
  • 使用新的 Minimise Cache 按钮，可从偏好设置窗口快速清除图像缓存。
  • 将图像序列导入资源窗口现在应该是即时的。
  • 新增从列表属性（例如复制器的 Input Shapes 属性）中 Disconnect All Inputs 的选项。

图层

  • 改进了相交分布，以处理贝塞尔曲线与贝塞尔曲线的相交。
  • JavaScript 编辑器现在支持多行注释。
  • 合成现在可以设置为循环。
  • 新增 Composition Length 属性——可与时间标记结合使用，以设置动态时间轴。
  • 声音行为 [beta]：
    • 新增 Maximum dB 属性：输出音频资源的峰值。
    • 新增 File Length 属性：输出音频资源的时长。
  • 图像采样器新增 Offset 属性。
  • 3D 矩阵 现在具有对齐选项。
  • 包围盒工具现在支持多个 Input Shapes。
  • 来自智能文件夹的资源：现在可以通过 Specific Index 或 Auto-Index 引用资源。

说明

  • 导入视频格式（MP4、HEVC、WebM、APNG 和 GIF 文件）现在快了 5 倍。这方面仍有更多工作要做。

循环：

我们对图做了一些更改，以更好地处理循环（例如创建连接/层级，其中子级可以影响其父级，而父级又影响其子级……）。我们注意到在某些情况下，1.3.1（及更早版本）中允许的连接现在不再被允许，因此这可能会破坏一些旧场景。没有简单的方法来“撤销”这一点，因为很难预测所有场景，不过它应该只会影响少数人；如果你怀疑这可能影响到了你的某些场景，请告诉我们，以帮助我们改进对这类场景的处理。

旧版场景与图像智能文件夹：

打开在 1.3.1 或更早版本中保存的文件时，如果某个 Image Smart Folder 缺失（例如已不在文件系统中的原始位置），场景会打开，但该 Image Smart Folder 不会出现在资源窗口中。很遗憾，没有自动恢复的方法，但按照以下步骤可以恢复场景：

  1. 将 Image Smart Folder 重新导入资源窗口。
  2. 将来自智能文件夹的资源工具加载到属性编辑器。
  3. 将 Image Smart Folder 从 Assets Window 拖入 Asset From Smart Folder Utility 的 Smart Folder Asset 属性。

如果难以找到缺失的文件夹，可以在场景文件中找到原始文件路径。用文本编辑器打开 .cv 文件，在文件顶部你会看到类似以下的条目：

{

    "data": {

        "filePath": "@assets/Cans"

    },

    "nodeId": "asset#10",

    "type": "file"

},

filePath 条目显示该文件夹的名称及其在文件上次保存时的位置。

如果在 1.4 中保存的场景里存在缺失的 Image Smart Folder，它们会被标记出来，并可按预期重新链接。

值得注意的问题修复

  • Windows 用户名中的 Unicode 字符（如 é、â、ö）曾导致无法登录。现已修复。
