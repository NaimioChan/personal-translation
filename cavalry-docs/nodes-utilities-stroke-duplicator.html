描边复制器

简介

Stroke Duplicator 可用于创建复杂的描边组合。

界面

Stroke Count：设置要添加的描边数量。

参见通用属性（Stroke 标签页）

示例：

  1. 使用钢笔工具绘制一条路径。
  2. 在 Stroke 标签页上，点击 Multi Stroke 属性上的 + 按钮，然后选择 Stroke Duplicator。
  3. 将 Stroke Count 设为 3。
  4. 右键点击 Color 属性 > Add Array > Color Array。
  5. 在 Color Array 上，使用 Add
  6. 回到 Stroke Duplicator，右键点击 Width 属性 > Add Behaviour > Stagger。
  7. 将 Stagger 的 Minimum 设为 30，Maximum 设为 100。
  8. 打开 Stagger 的 Graph，并使用右下角的按钮翻转图表。
