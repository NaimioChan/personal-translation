系统要求

操作系统

macOS

macOS 12.0（Monterey）及更高版本。

macOS 支持：

Cavalry 1.5.6 是最后一个支持 macOS 10.14 及更高版本的版本。

Cavalry 1.1.1 是最后一个支持 macOS 10.13 及更高版本的版本。

请参阅旧版安装程序下载旧版本。请注意，旧版本不提供技术支持。

Windows

Windows 10 及更高版本。

硬件

CPU

macOS

Intel 或 ARM（Apple Silicon）。

Windows

Intel 或 AMD。

Windows ARM CPU：

搭载 ARM CPU 的 Windows 机器将使用 Windows 的 Prism 模拟器，性能可能会受到影响。

GPU

兼容 OpenGL 4.1 Core Profile 的显卡。

Intel

架构必须为 Gen. 12 Alder Lake 或更高。

https://downloadcenter.intel.com/product/80939/Graphics-Drivers

NVIDIA

https://www.nvidia.com/Download/index.aspx

AMD

https://www.amd.com/en/support

Windows：

界面部分区域渲染不正确，通常说明存在显卡问题。

请确保所有显卡驱动均为最新版本。

Windows 笔记本电脑可能安装了多个显卡。在这种情况下，Cavalry 会尝试自动选择“高性能”显卡。也可以通过 Settings > System > Display > Graphics 明确设置：找到 Cavalry，或点击 Browse（位于 Custom Options for Apps 下）添加 Cavalry，然后将其设为 High performance。

内存

最低需要 512 MB 内存。

网络

登录 Cavalry 需要网络连接。

系统诊断

打开 Help > System Diagnostics 窗口可查看系统的相关信息。在排查问题时，这些信息可用于支持工单。
