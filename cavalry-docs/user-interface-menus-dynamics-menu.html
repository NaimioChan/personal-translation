动力学菜单

Make Dynamic：创建一个Forge Dynamics 图形，并将选中的图形连接到它。

Active Forge Solver：选择要受影响的解算器（Forge Dynamics 图形）。

Add Field：向 Active Solver 添加一个场。

Add Collision Event：向 Active Solver 添加一个碰撞事件。

Cache Solver：为 Active Solver 生成缓存文件。
