半径

简介

生成一个可包围多个图形的圆的半径。

信息：

请注意，Radius Utility 输出的是数值，并不会生成图形。将输出连接到图形（例如 Ellipse），即可在视口中看到结果。

界面

Input Shapes：连接一个或多个图形，以生成围绕它们的半径。

Centre Mode：确定半径中心的计算来源：

  • Custom Centre：手动为半径中心设置位置。
  • Shapes' Centre：半径中心位于输入图形的中心。
  • Smallest Circle：通过计算能够包围输入图形的最小圆来确定半径中心的位置。

Centre：当 Centre Mode 设为 Custom Centre 时，为半径中心设置位置。

Expand：为 Radius 和 Inner Radius 添加偏移。正值会增大 Radius 并减小 Inner Radius。

Centre Position：半径中心的输出。

Radius：半径的输出。

Inner Radius：可绘制在输入图形内部的圆的半径输出。

示例：

  1. 创建 3 个图形。
  2. 将它们彼此分开。
  3. 创建一个 Radius Utility。
  4. 将这 3 个图形连接到 Radius Utility 的 Input Shapes 属性。
  5. 创建一个 Ellipse。
  6. 禁用 Ellipse 的 Fill 并启用 Stroke。
  7. 连接 radius.centrePosition→ellipse.position
  8. 连接 radius.radius→ellipse.radius
  9. 在视口中移动输入图形。

随着图形的移动，Ellipse 会增大/缩小。
