矩形图案

简介

Rectangle Pattern Shape 可用于创建堆叠条形图和饼图。输入值会被归一化以适合其宽度或角度。

界面

Shape

Common Attributes +

Pattern Mode：设置图案的分布方式：

  • Line：沿一条线分布矩形。
    • Use Fixed Size：勾选后，条形将缩放以适合 Size。
    • Orientation：设置线条的方向：
      • Horizontal：条形沿 X 轴排列。
      • Vertical：条形沿 Y 轴排列。
    • Size：为图形设置固定尺寸。
    • Gap Type：设置间隙样式：
      • Alternating：每个间隙由 Bar Size 设定。在此模式下，Count 包含矩形和间隙。
      • Fixed Width：每个间隙由 Fixed Gap Width 设定。在此模式下，间隙是在 Count 之外额外添加的。
    • Fixed Gap Width：为每个间隙设置固定宽度。
    • Alignment：将图形对齐到其左边缘（0）与右边缘（1）之间的位置。
  • Ring：沿环形分布矩形。
    • Outer Radius：设置环的外半径。
    • Inner Radius：设置环的内半径。
    • Start Angle：设置起始角度。
    • End Angle：设置结束角度。
    • Gap Type：设置间隙样式：
      • Alternating：每个间隙由 Bar Size 设定。在此模式下，Count 包含矩形和间隙。
      • Fixed Angle：每个间隙由 **Fixed Gap Angle. ** 设定。在此模式下，间隙是在 Count 之外额外添加的。
    • Fixed Gap Angle：为每个间隙设置固定角度。

Count：设置矩形和间隙的总数。

Dynamic Bar Size：连接一个行为来设置矩形的大小。数值会被归一化以适合 Size。

信息：

请注意，“间隙”实际上是一个空矩形，因此例如将Random Behaviour 连接到 Dynamic Bar Size 会创建大小随机的矩形和间隙。

Advanced

Common Attributes +

Use Index Context：勾选后，Rectangle Pattern Shape 将拉取上下文。这可用于控制 Id 的分配方式，从而单独影响每个矩形——例如，将一个 颜色数组 经由 子网格 添加到 Rectangle Pattern Shape 的 Fill Color。

示例：

  1. 创建一个 Rectangle Pattern Shape。
  2. 将 Gap Type 设为 Fixed Width。
  3. 将 Count 设为 5。
  4. 创建一个 值数组。
  5. 向 Value Array 再添加 4 个索引（共 5 个），并为每个索引设置不同的值。
  6. 连接 valueArray.id→rectanglePatternShape.dynamicBarSize

Value Array 中的值会被归一化以适合 Rectangle Pattern Shape 的宽度。试着将 Pattern Mode 改为 Ring。

可以使用 子网格 为 Rectangle Pattern Shape 的每个部分添加颜色：

  1. 点击 Rectangle Pattern Shape 的 Deformers 属性旁的 +。
  2. 从列表中选择 子网格。
  3. 在 Sub-Mesh 的 Fill 标签页中，勾选 Replace Fill。
  4. 右键点击 Sub-Mesh 的 Color 属性，选择 Add Array > Color Array。
  5. 向 颜色数组 再添加 4 个索引（共 5 个），并为每个索引设置不同的颜色。
