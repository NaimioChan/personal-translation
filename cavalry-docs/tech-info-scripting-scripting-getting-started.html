脚本入门

简介

Cavalry 中的 JavaScript 可以访问场景中的图层和数据，因此可以编写脚本来执行自定义工作流程。这包括创建图层、设置属性、建立连接以及更多内容。

最简单的入门方式是查看 Create > Demo Scenes > JavaScript 菜单中的示例。

下面是一个示例脚本，它会创建一个文本图形并为其制作动画。将此脚本复制粘贴到JavaScript 编辑器的标签页中，然后点击 Run Script 按钮即可运行。

// Get the height of the composition (we're going to drop the text from the top)

var height = api.get(api.getActiveComp(), "resolution.y");

// The time difference between the first and last letters dropping

var timeOffset = 20;



// Make a text shape

var textShapeId = api.create("textShape", "Bouncy Text");

// Set some attributes on the text layer

// The attributes are set via a dictionary of (key, value) pairs

// This means many attributes can be set at once.

api.set(textShapeId, {"horizontalAlignment": 1,

                      "fontSize": 120,

                      "font.style": "Black",

                      "verticalAlignment": 1,

                      "material.materialColor": "#ff24e0",

                      "autoWidth": true,

                      "autoHeight": true});



// Get the bounding box of the text layer

var bbox = api.getBoundingBox(textShapeId, true);

// How far to we need to move the text shape to get it 'offscreen'

var distToEdge = bbox.y * -1 + height * .5;



// Get the start frame of the text shape (this could just be 0, but we're getting the in frame just to show off)

var startFrame = api.getInFrame(textShapeId);

// Set the end frame

var endFrame = startFrame+40;



// Create a Sub-Mesh layer which will power the 'per character' animation.

var subMeshId = api.create("subMesh", "Bounce In Animator");

// Set some keyframes, and set magic easing

api.keyframe(subMeshId, startFrame, {"shapePosition.y": distToEdge});

api.keyframe(subMeshId, endFrame, {"shapePosition.y": 0});

api.magicEasing(subMeshId, "shapePosition.y", startFrame, "BounceOut");

// Connect the Sub-Mesh to the Text layer's Deformers Attribute

api.connect(subMeshId, "id", textShapeId, "deformers");

// Parent the Sub-Mesh to the Text.

api.parent(subMeshId, textShapeId);



// Create a Stagger - this will be used to create the time offset

var staggerId = api.create("stagger", "Bounce In Stagger");

// Set the minimum/ maximum attributes on the Stagger

api.set(staggerId, {"minimum": -timeOffset, "maximum": 0});

// Flip the Graph on the Stagger so that the first letter bounces in first (by default the last letter would go first).

api.flipGraph(staggerId, "graph", "vertical");

// Connect the Stagger to the Sub-Mesh

api.connect(staggerId, "id", subMeshId, "shapeTimeOffset");

// Parent the Stagger to the Text

api.parent(staggerId, textShapeId);

// Start playback

api.play();

安装 UI 脚本

要安装UI 脚本，请前往 Help > Show Scripts Folder，然后将脚本文件拖入该文件夹。允许使用嵌套文件夹，它们会显示为子菜单。保存到该文件夹的脚本会立即出现在 Window > Scripts 菜单中，无需重启 Cavalry。

Cavalry 场景

每个 Cavalry 场景都由若干图层树组成。其中有一个资源树，包含场景中的所有资源图层；除此之外，Cavalry 中的每个合成都有自己的图层树。可以用 JavaScript 遍历这些树，从而访问 Cavalry 中（几乎）每个图层。每棵树都可以由任意数量、任意层级的图层组成。

访问图层与属性

要访问合成中的图层和属性，需要用到它们的 LayerId 和/或 AttributeId。

图层 Id

要获取 layerId（编写脚本时可用于访问图层），请在属性编辑器、场景窗口或视口中右键点击该图层，然后从上下文菜单中选择 Copy Layer Id。

图层类型

layerType 是 layerId 的一部分，因此可以按上述方式获取。layerType 是 layerId 中位于 # 之前的部分。例如，如果 layerId 是 basicShape#1，那么 layerType 就是 basicShape。

属性 Id

要获取 attrId（编写脚本时可用于访问属性），请在属性编辑器中右键点击某个属性，然后从上下文菜单中选择 Copy Scripting Path。例如：

  1. 创建一个基础图形。
  2. 在属性编辑器中，右键点击 Position 属性。
  3. 从上下文菜单中选择 Copy Scripting Path。

这会将 position 复制到剪贴板，随后即可在脚本中作为参数使用：

api.get("basicShape#1", "position");

模块

JavaScript 可用于多个位置，Cavalry 提供了 4 个模块，用于访问场景中的数据。此外还提供了许多便捷方法，让处理这些数据更加容易。请注意，Cavalry 提供的 JavaScript 模块并非在所有位置都可用。

API 模块

  • 仅在JavaScript 编辑器中可用。
  • 它提供对场景和文件系统的编辑访问权限。
  • 该模块的前缀是 api。

上下文模块

  • 可在JavaScript 图层中使用。
  • 它提供与计算JavaScript 工具输出相关的方法。
  • 该模块的前缀是 ctx。

Cavalry 模块

  • 可在JavaScript 图层和JavaScript 编辑器中使用。
  • 它提供实用方法和类，用于处理和创建可供其他地方使用的数据。
  • 该模块的前缀是 cavalry。

变形器模块

  • 仅对JavaScript 变形器可用。
  • 该模块的前缀是 def。

日志

使用 console.<method>() 将消息写入 Cavalry 的JavaScript 控制台。下面的方法可用于打印特定上下文的消息，这些消息带有不同颜色的强调色，便于快速识别。

console.log("This is a test."); // Typically used in testing (green).

console.info("Confirming this happened as expected."); // Confirm when something expected has happened (green).

console.warn("Just to let you know..."); // Warn a user when they've done something unexpected (yellow).

console.error("Something went wrong."); // Flag when something has gone wrong (red).

console.debug("I am a developer."); // Print a message to Terminal/Cmd Prompt.

术语表

许多成员函数可以将参数作为输入，并且/或者会返回不同类型的值：

  • int：整数是不带小数点的数字。例如 4。
  • number：带小数位的数字。例如 4.153。
  • string：字符串可以包含字母数字字符和符号，应使用双引号包裹。例如
  • "string"。
  • bool：布尔值可以是 true 或 false。
  • array：数组是项目的列表。例如 ["one", "two", "three"] 或 [1, 2, 3]。
  • object：对象是属性的集合（一个名称（或键）和一个值）。例如 {width:10, height:10}。
