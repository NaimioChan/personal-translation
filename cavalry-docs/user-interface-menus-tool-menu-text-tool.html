文本工具

简介

在视口中创建和编辑文本。

文本工具可用于创建容器，并直接在视口中输入文本。

界面

  • 在视口中单击可创建文本图形，其 Text Box 会自动设置为适合文本。
  • 在视口中单击 + 拖拽可创建用于输入文本的区域。文本会在 Text Box 内自动换行。

上述使用哪种方法创建文本图形，将决定 Text Box Size 是自动设置还是由用户定义。可以在属性编辑器中勾选/取消勾选 Text Box Size 属性上的 Auto 复选框来更改。

  • 使用角和边上的手柄调整 Text Box 的大小。这需要取消勾选 Text Box Size 属性上的 Auto。
  • 使用Transform 控件（左上角）移动文本。
  • 使用 Resize Text 控件（右下角）增加/减小 Font Size。
