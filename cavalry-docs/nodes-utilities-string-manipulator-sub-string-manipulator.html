子字符串操纵器

简介

Sub-String Manipulator 可用于输出指定范围的字符。范围的设置方式与 Cavalry 中所有数组的工作方式相同。例如，文本字符串 Cavalry 有 7 个字母，因此表示为 0 到 6 之间的范围。

0 1 2 3 4 5 6
C a v a l r y

界面

Start Position：设置第一个字符的索引。

End Position：设置最后一个字符的索引。

Exclude End：勾选后，End Position 的索引将从范围中移除。例如，Start Position 和 End Position 均为 0 时会保留 1 个字符可见（Id0 位于 0,0 范围内）。勾选 Exclude End 会将其移除。

提示：

要从字符串 Cavalry 中输出 ava，请将 Start Position 设为 1，End Position 设为 3。
