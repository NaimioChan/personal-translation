JavaScript 图形

简介

JavaScript Shape 是一种可通过 JavaScript 表达式定义的图形。

有关如何在所有 JavaScript 图层中使用 JavaScript 的更多信息，参见JavaScript 图层。

参见 JavaScript Layers→

信息：

参见 Create > Demo Scenes > JavaScript > Heart Path 以查看示例。

界面

Shape

Common Attributes

JavaScript

输入用于创建图形的 JavaScript 表达式。可以在脚本中使用 Path Class 来定义网格。

信息：

也可以将 JavaScript 工具 连接到 自定义图形 的 Input Shape，以创建等效于 JavaScript Shape 的效果。

复制图形：

在视口中右键单击图形，并选择 Copy as JavaScript，即可将该图形的信息以 JavaScript 代码形式复制到剪贴板。
