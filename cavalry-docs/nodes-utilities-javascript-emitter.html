JavaScript 发射器

实验性功能：

这是一个实验性功能。要启用它，请在首选项中勾选 Enable Experimental Features。

简介

使用 JavaScript 创建自定义的粒子发射器。

关于如何在所有 JavaScript 图层中使用 JavaScript 的更多信息，请参阅JavaScript 图层。

查看 JavaScript 图层→

全局变量

time：帧编号。

fps：合成的 Frame Rate。

lifespan：粒子的 Lifespan。

particles：粒子数组。

可以像其他任何JavaScript 图层一样保存或加载数据对象。

界面

通用属性 +

Custom Color：视口中会绘制一个 Emitter 的表示——勾选 Custom Color 后，将使用 Color 中设置的值来绘制。取消勾选时，则使用 Label Color（即场景窗口中该行所使用的颜色）。

Color：为 Emitter 的视口绘制设置 Custom Color。

Time：此属性连接到合成的 Time，用于在每一帧驱动粒子。如有需要，可以将该连接替换为关键帧或其他行为。

FPS：此属性连接到合成的 Frame Rate。可以移除该连接并手动输入。

Expression Window：在此处输入 JavaScript 表达式。

提示：

  1. 创建一个粒子图形。
  2. 在属性编辑器中，点击 Emitters 属性上的 + 按钮并选择 JavaScript Emitter。
  3. 点击 Play。
// The default JavaScript Emitter expression.

// Emit for one second every other second while rotating.

var seconds = Math.floor(time / fps);

if (seconds % 2 == 0) {

    for (let i = 0; i < 5; i++) {

        var particle = {};

        particle.position = {'x': 0, 'y': 0};

        particle.speed = 10;

        particle.angle = (time*10)+cavalry.random(-15, 15, time, i);



        particles.push(particle);

    }

}
