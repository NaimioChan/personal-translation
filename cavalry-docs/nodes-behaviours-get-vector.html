获取向量

简介

Get Vector 可与复制器上的点配合使用，返回某个点与目标之间的方向。

界面

Common Attributes +

Target：连接一个图形以从中获取向量。

Normalize：返回的值被归一化为 0 到 1 之间。

示例：

  1. 创建一个图形。
  2. 将其连接到复制器。
  3. 将 值2 连接到复制器上的 Shape Position。
  4. 向 Value2 行为添加一个衰减。
  5. 创建一个 获取向量 行为。
  6. 取消勾选 Normalize。
  7. 连接 getVector.id→value2.value
  8. 连接 falloff.id→getVector.target
