视图菜单

Show Rulers：在视口中显示/隐藏标尺。

Show Guides：在视口中显示/隐藏参考线。

Ruler Options：决定标尺数值的显示方式：

  • Origin in Centre：以合成中心为 0,0。
  • Origin In Bottom Left：以合成左下角为 0,0。
  • Use Pixels：以像素为单位显示数值。
  • Use Percentage：以合成宽度/高度的百分比显示数值。

Show 2D Grid：在视口中显示/隐藏 2D 网格。

Show Pixel Grid：在视口中显示/隐藏像素网格。像素网格只会在特定缩放级别下出现，具体取决于当前合成的大小。

Show Composition Boundary：显示/隐藏合成边界。启用后，合成边界周围会绘制一条白色边框。

Show Layer Names on Hover：显示/隐藏预选高亮时的图层名称。

Show Viewport Tool Help：显示/隐藏视口帮助浮层。也可以使用 Viewport Settings 窗口中的复选框。

Show Layer Tools：显示/隐藏图层工具。某些图层会显示紫色界面元素，可直接在视口中调整其设置。必须选中受支持的图层，这些工具才会出现。请注意，当某个图形是另一个图形的父级时，图层工具不可用。也可以使用 Viewport Settings 窗口中的复选框。

Viewport Quality：设置视口渲染哪些功能。可在需要时用它提高播放速度。注意：此设置不影响最终渲染，最终渲染应在渲染管理器中通过 Render Quality 设置。请注意，此设置在会话之间或打开新场景时会恢复为 High。

  • Highest（仅 macOS）：使用多重采样抗锯齿（MSAA）。
  • High：使用标准抗锯齿的完整质量。
  • Low：移除 Anti-aliasing 和任何 Image Filtering（参见 图像着色器）。
  • Lowest：与 Low 相同，但同时移除所有 Filters 和 Shaders。

Draw Outside Composition Boundary：启用/禁用合成边界之外的图形显示。

Draw Debug Information：在视口中为选中的图形显示有用的信息。

Snapping：启用/禁用视口吸附。

Show Snapshot：选择在视口中显示哪个已保存的快照。可使用 Option/Alt + SnapShotNumber 作为快捷键。

Save Snapshot：将视口当前状态的快照保存到一个槽位。

Remove Snapshot：从槽位中移除快照。将快照保存到某个槽位也会覆盖该槽位中已有的快照。

Clear All Snapshots：移除所有槽位中的快照。

Zoom In：逐步放大视口。

Zoom Out：逐步缩小视口。

Zoom：设置视口的缩放级别。

Enter Full Screen：让应用程序进入全屏模式。
