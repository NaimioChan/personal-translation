从智能文件夹获取资源

简介

Asset from Smart Folder 可用于引用智能文件夹中包含的资源（图像、视频、音频等）。参见图像智能文件夹或音频智能文件夹。

界面

Mode：选择引用资源的方式：

  • Path：通过资源的文件名/文件路径引用资源。
  • Auto Index：通过资源的 index 引用资源。这在复制器中使用智能文件夹时很有用。智能文件夹按字母顺序排列，因此将模式设为 Auto Index 会按相同顺序输出资源。
  • Specific Index：设置智能文件夹中要输出的特定索引。可以设置一个值，也可以连接一个行为，为每个上下文传递不同的索引。

Smart Folder Asset：将资源窗口中的 Image Smart Folder 或 Audio Smart Folder 连接到此属性。

Path：输入文件名，或连接包含智能文件夹内资源文件名的电子表格或数组。

Index：设置一个特定索引，或连接一个行为。

Count：只读属性，返回图像智能文件夹或音频智能文件夹中找到的资源数量。注意，智能文件夹最大深度限制为 5 层目录。

Out Path：只读属性，可用于输出资源的 Path。当 Mode 设为 Specific Index 时，可将其连接到渲染队列项的 File Name。

操作路径：

可以通过将 Out Path 连接到字符串，然后使用Replace String 来编辑文件路径。例如：

要移除 .png 文件扩展名：

  • 将 Replace 设为 .png。
  • 将 With 留空。

要将 / 替换为 -：

  • 将 Replace 设为 /。
  • 将 With 设为 -。

随后可以将该 String 连接到文本图形作为“标签”，或连接到渲染队列项的 File Name，以便在任何渲染中引用该图像的名称。

文件路径：

在资源窗口中右键点击智能文件夹并选择 View File Paths...，即可预览资源的索引。

示例：

  1. 导入一个包含 apple.png、orange.png 和 banana.png 文件的智能文件夹。
  2. 将该智能文件夹从资源窗口拖入属性编辑器或视口。
  3. 创建一个字符串数组。
  4. 再添加两个索引：使用 Add 按钮，并在每个索引中填入 apple.png、orange.png 和 banana.png。
  5. 将 String Array 连接到 Asset from Smart Folder 的 Path 属性。
  6. 取消勾选 String Array 上的 Auto Index，并在 Index 中输入 1。

图像应从苹果变为橙子。

尝试将 String Array 换成电子表格，并将渲染管理器的 Dynamic Index 连接到其 Index。
