延长开放路径

简介

沿切线或指定角度延伸开放路径的两端。

界面

Mode：决定延伸长度的单位：

  • Pixels：按特定像素数延伸路径长度。
  • Percentage of Length：按原始长度的百分比延伸路径长度。

Extend Start：以 px/% 为单位指定路径起点的延伸长度。

Extend End：以 px/% 为单位指定路径终点的延伸长度。

Angle Mode：决定延伸端点的方向

  • Path Tangent：路径沿起点/终点的切线延伸。
  • Path Curvature：通过描绘一个代表路径端点曲率的圆来延伸路径。
  • Arc：通过生成圆弧来延伸路径。
  • Custom...：沿自定义角度延伸路径。

Arc Radius：当 Angle Mode 设为 Arc 时，设置绘制圆弧所沿圆的半径。

Arc Sweep Angle：当 Angle Mode 设为 Arc 时，设置“该圆”的绘制量

Arc Direction：决定圆弧圆心位于路径切线的哪一侧：

  • Normal：圆弧沿路径法线放置。
  • Inverted：圆弧放置在路径法线的另一侧。

Opposite Direction for End：终点的圆弧与“Arc Direction”所指定的方向相反。

Start Angle：当 Angle Mode 设为 Custom 时，设置一个角度以沿该角度延伸路径的起点。

End Angle：当 Angle Mode 设为 Custom 时，设置一个角度以沿该角度延伸路径的终点。

示例：

  1. 使用钢笔或铅笔工具绘制一条开放路径。
  2. 双击图形的图层，将其界面加载到属性编辑器中。
  3. 单击图形 Deformers 属性旁的 + 按钮。
  4. 从列表中选择 Extend Open Paths。
  5. 增大 Extend Open Paths 的 Start 和 End 值。
