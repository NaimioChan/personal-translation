切割路径

简介

将图形切成多个切片。

界面

Count：设置将图形切成多少个切片。

Angle：设置切片的角度。

Offset：沿 Angle 方向为切片添加位置偏移。可连接行为（例如 Random）以分别影响每个切片。

Spread：垂直于 Angle 方向为切片添加位置偏移。可连接行为（例如 Random）以分别影响每个切片。

Flatten Shape：勾选后，当复制器或文本图形之类的子网格被“切分”时，子网格会被扁平化为单个网格。

扁平化的图形：

请注意，勾选 Flatten Shape 后：

  • 图形会被“作为一个整体”处理，也就是说切片基于图层整体的边界框，而不是各个子网格。这可能会影响生成切片的位置。
  • 任何输入的材质都会被移除。之后可以为图形添加子网格行为，用于为每个切片应用单独的材质。例如，在 Chop Path 之后将 Sub-Mesh 作为 Deformer 添加到 Duplicator，然后向子网格的 Fill Color 添加一个颜色数组，为每个切片指定颜色。
