控制中心

简介

Control Centre 是一处用于将场景中最重要的属性提升出来以便快速轻松访问的地方。这对绑定或与同事、客户共享场景特别有用。

要将属性添加到 Control Centre，请在属性编辑器中右键点击某个属性，然后选择 Add to Control Centre。

要从 Control Centre 中移除属性，请右键点击 Control Centre 或属性编辑器中的某个属性，然后选择 Remove from Control Centre。

界面提示：

向 Control Centre 添加属性时，属性编辑器的对应行会添加一个小蓝点。

界面

Add Group

Options：使用 菜单。

  • Auto-Group by Source Layer：为每个图层创建组，并将属性放置在其父图层的组下。
  • Expand all Groups：展开所有组。
  • Collapse all Groups：折叠所有组。
  • Clear Composition：使用此菜单项移除特定合成中的所有属性。
  • Clear Control Centre：从 Control Centre 中移除所有属性。

Search：使用搜索栏在 Control Centre 窗口中筛选特定属性和组。点击 x 图标可清除搜索。

Filter：打开合成列表，可用于显示/隐藏对应的属性。

组

使用 菜单。

  • Rename：重命名该组。
  • Ungroup：移除该组，但保留所有子属性。
  • Delete Group：从 Control Centre 中移除该组及其所有子属性。

重新排序

属性和组可以通过在堆栈中上下拖放单个行来重新排序。拖动属性/组时，其他属性/组行会在视觉上“拆分”，形成可拖入属性/组的间隙。

启用重新排序：

当筛选或搜索处于启用状态时，无法重新排序。清除搜索栏并确保勾选了 (Select all) 筛选选项，即可启用重新排序。

技巧

隔离单个属性

无法将多输入行中的单个输入提升出来，例如图形 Position 属性中的 position.x。要绕过此限制，可以创建一个 值，将 value.id→shape.position.x，然后把 value 属性添加到 Control Centre。

复选框

任何复选框属性行都可以添加到 Control Centre，但在某些场景中可能需要自定义复选框。例如，明/暗模式切换。图层界面中的任何复选框都是输出 0 或 1 的布尔值，因此通过将复选框连接到另一个属性，即可用这些值来触发变化。例如，将 动画控制 图层的 Active 属性连接到 颜色数组 的 Index，就可以用 Active 复选框在 Color Array 的索引 0 和 1 之间切换。

也可以使用 If/Else 工具创建自定义布尔值。

滑块

任何滑块属性行都可以添加到 Control Centre，也可以使用 Edit Limits... 功能创建自定义滑块。当模板需要某个不应超出特定范围的值时，这很有用。Step 也可用于例如将 double 属性（带小数的属性）转换为 integer（整数）。

下拉菜单

参见 自定义下拉菜单。

命名

属性名称可以自定义：在属性编辑器或 Control Centre 中右键点击属性所在行，然后选择 Rename...。
