工具架

简介

工具架位于默认工作区顶部，包含用于设置快捷操作的快捷按钮，可用来加速常见的工作流程。

按钮

演示场景

选择一个场景添加到当前合成中作为示例，供启发或学习之用。并非所有示例都设置为动画，但在选择菜单项时按住 Cmd/Ctrl 会自动开始播放。这些内容也可以通过创建菜单访问。

复制器

创建一个复制器，并将所选图形添加到其 Input Shapes 属性中。

挤出

创建一个挤出图形，并将所选图形添加到其 Input Shapes 属性中。

Forge Dynamics

创建一个 Forge Dynamics 图形，并将所选图形添加到其 Bodies 属性中。

粒子

创建一个粒子图形图形和一个粒子发射器。

自动动画

为合成添加自动动画行为，并将其连接到所选图形的 Deformers 属性。

对齐

为合成添加对齐行为，并将其连接到所选图形的 Deformers 属性。

绑定控制

为合成添加绑定控制。

动画控制

为合成添加动画控制。

Rubber Hose

创建一个默认的 橡皮管肢体。如果选中了图形，Rubber Hose 将连接到其 Deformers 属性。

赛璐珞动画

创建一个赛璐珞动画图形并启用铅笔工具（除非钢笔工具已处于激活状态）。

文字沿路径

在选中一个文字图形和一个图形的情况下，点击 Text along a Path 按钮会将 Path 连接到文字图形的 Text Path 属性，使文字沿路径排列。它还会将文字图形的 Path Travel 连接到合成的 Time，这意味着文字会在播放时沿路径移动。移除该连接即可自定义动画。

调度组 - 顺序

将所选图形添加到调度组，并勾选 Sequence 属性。

调度组 - 错开

将所选图形添加到调度组，添加一个错开行为并将其连接到调度组的 Child Offset。

布局组 - 水平

将所选图形添加到布局组，并将其 Direction 属性设置为 Horizontal。

布局组 - 垂直

将所选图形添加到布局组，并将其 Direction 属性设置为 Vertical。

布局组 - 网格

将所选图形添加到网格布局行，并将其嵌套在网格布局组内。

摄像机

为合成添加摄像机。
