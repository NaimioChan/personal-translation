文件菜单

New Scene：创建一个新的空场景。

Open...：打开之前创建的场景。

Open Recent：打开最近打开的五个场景中的任意一个。

Restore Autosave：打开之前自动保存的文件。需要将 Autosave 偏好设置设为 Autosave。

Save：保存场景。

Save As...：将当前场景保存到新位置或使用新文件名。

Increment and Save：在当前场景文件所在位置创建一个新的场景文件，将文件名的后缀数字加一，然后打开新创建的场景。更多细节见下方信息框。

文件格式：

Cavalry 的原生文件格式是 .cv。文件默认以紧凑的 JSON 格式保存，可通过首选项窗口调整相关选项。

Import Assets...：打开 Finder/资源管理器的导入对话框。

Import Reference...：将另一个 .cv 文件作为引用导入。

Import Scene...：导入另一个 .cv 或 .cvc 文件。

Import Google Sheet...：打开 Import Google Sheet 窗口。参见 Google Sheets。

Import Image Smart Folder...：打开 Finder/资源管理器导入对话框，并选择一个包含图像资源的文件夹。参见 图像智能文件夹

Import Audio Smart Folder...：打开 Finder/资源管理器导入对话框，并选择一个包含音频资源的文件夹。参见 音频智能文件夹

Export Selected...：将选中的（以及与之连接的）图层导出为 .cvc 文件。

Export Lottie...：将场景导出为 Lottie（.json）文件。

评估 Lottie：

使用 Starter 许可证时，File > Export Lottie 菜单项会显示为 Export Lottie... (Demo Mode)。此时可以导出第一个选中的图层到 Lottie，因此可用于评估特定图层的文件大小和兼容性。

Export as Project...：将场景或选中的合成连同所有连接的资源导出到一个新的项目目录。这可用于归档和/或与客户或同事共享项目。

  • Mode：选择要导出到新项目的合成：
    • All Compositions：导出场景中的所有合成。
    • Selected Compositions：导出所有选中的合成。
  • Include Fonts：勾选后，导入到资源窗口的所有字体会被复制到新项目的 /Assets 目录。⚠️ 请确保字体具备正确的共享许可。
  • Include Palettes：勾选后，如果设置了项目，/Palettes 目录（默认为 /Assets/Palettes）中找到的所有 .pal 文件都会保存到新项目中。

Project Settings：打开 项目设置 窗口。

Set Project：从最近五个项目中选择任意一个。

Show Project Folder：在文件系统中打开项目的根目录。

Render Manager：打开渲染管理器。

Render Current Frame...：将当前帧渲染为 .png 文件。

Render Current Frame to SVG...：将当前帧导出为 .svg 文件。

Reduce Scene：从场景中移除所有未使用的合成和资源。

Increment and Save：

如果文件已保存，且其文件名包含有效的“计数器”，那么执行 Increment and Save 时会直接进行，不会中断。

如果当前场景尚未保存，或其文件名不包含“计数器”，执行 Increment and Save 会触发“Save As...”对话框。输入包含有效“计数器”的文件名后，之后再次使用该命令时会直接进行，不会中断。

如果场景已保存，但其文件名不包含“计数器”，“Save As...”对话框会建议一个（例如 file.cv > file 2.cv），此时可以添加任意自定义的“计数器”。

“计数器”是一个分隔符后跟一个数字。有效的分隔符有空格、句点（句号）、下划线和连字符。有效文件名的示例如下：

原始名称 新名称
file-001.cv file-002.cv
my-file-3.cv my-file-4.cv
my file 1.cv my file 2.cv
my file1 5.cv my file1 6.cv
myfile.7.cv myfile.8.cv
myfile_004.cv myfile_005.cv

如果递增后的文件会覆盖已有文件，则会显示警告对话框。
