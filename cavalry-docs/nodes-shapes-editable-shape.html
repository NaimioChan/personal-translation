可编辑图形

简介

Editable Shape 是一种非程序化的图形，可以使用 Pen 或 Pencil 工具创建，也可以通过 Shapes > Make Editable 命令（Cmd/Ctrl + E）转换任何程序化图形来创建。还可以在工具栏中勾选顶部的工具选项 Make Editable Primitives 来创建。

路径动画：

你可以使用关键帧和Edit Shape 工具为 Editable Shape 的顶点设置动画。这也称为路径动画。

  1. 使用 Pen 工具绘制一个图形（这会创建一个 Editable Shape）。
  2. 在属性编辑器中，单击 Path 属性上的关键帧图标。
  3. 将时间轴移动到另一帧。
  4. 使用 Edit Shape 工具，在视口中移动图形的任意点。

场景窗口中将创建两个关键帧，拖动时间轴时图形会播放动画。对图形点的任何后续更改都会创建新的关键帧（或更新现有的关键帧）。

界面

Common Attributes +

Path - 创建关键帧后，你对图形顶点所做的任何更改都会创建新的关键帧，顶点将在各关键帧之间变换到对应的位置。

路径动画：

使用场景树中 Editable Shape 所在行的 Animate Path 按钮，可以设置一个初始的 Path 关键帧。如有需要，也可以用同一按钮移除任何关键帧。

Fill Rule - 决定当一个 Editable Shape 中存在多个 Contour 时如何创建孔洞：

  • Even Odd - 与另一个 Contour 相交的任何 Contour 都会创建孔洞。
  • Winding - 要创建孔洞，相交的 Contour 必须与另一个 Contour 的绘制方向相反。

Onion Skinning - 勾选后，当前帧之前或之后的帧会在视口中预览。请确保同时启用了洋葱皮视口选项。
