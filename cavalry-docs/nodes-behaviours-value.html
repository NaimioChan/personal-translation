值

简介

一个简单的行为，可以存储和操控一维数值。

界面

Common Attributes +

Value：设置一个基础值，其输出为“Value × Strength + Offset”。

Offset：在应用 Strength 之后为 Value 加上一个值。与衰减配合使用时，可用于设置一个“基础”值。

Time Offset：设置用于偏移动画曲线的时间帧数。例如，如果一个图形的 Position.X 连接到 Value 的 Value，那么当 Value 的 Id（输出）连接到另一个图形的 Position.X 时，就可以用 Time Offset 延迟该图形的动画。负值表示时间向后。
