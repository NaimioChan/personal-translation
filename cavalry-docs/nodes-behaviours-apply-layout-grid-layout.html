网格布局

简介

Grid Layout 可与应用布局行为一起使用。

布局：

请注意，此类布局仅供子网格使用。要为布局添加图形，请参见布局。

界面

Columns：设置一列中的单元格数量。

Rows：设置一行中的单元格数量。

Horizontal Padding：为布局的左侧和右侧添加内边距。

Vertical Padding：为布局的顶部和底部添加内边距。

Cell Margins：为每个单元格添加内边距。

Direction：确定图形在网格中的排列流向：

  • Flow Columns：图形将按从左到右（然后从上到下）排列。
  • Flow Rows：图形将按从上到下（然后从左到右）排列。

Reverse Layout Order：反转 Layout Items 的排列顺序。

Shuffle：随机化图形的排列顺序。

Seed：为 Shuffle 设置种子值。

Scale to Fit：缩放每个图形以适配其单元格。

Scale Multiplier：使用 Scale to Fit 时，增加或减小每个图形的缩放。

Keep Aspect Ratio：使用 Scale to Fit 时，保持图形的宽高比。
