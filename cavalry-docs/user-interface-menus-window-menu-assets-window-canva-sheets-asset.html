Canva 表格资源

简介

Canva 表格资源可用作电子表格工具的输入。从 Canva 表格导入数据意味着任何人都可以在任何地点的浏览器中编辑数据，并在 Cavalry 中即时更新。

权限：

使用敏感或私有数据时，可通过邀请特定用户，或通过表格的 Share 选项设置 Access level 来限制访问。

Canva 表格 URL

复制 Canva 表格 URL 的方式有以下两种：

  • 在表格的 Share 选项中，点击 Copy link。
  • 如果在浏览器中使用 Canva，可直接从浏览器标签页的地址栏/多功能框中复制 URL。

导入

导入表格：

  1. 执行以下任一操作：
    • 在资源窗口中右键单击，然后选择 Import Canva Sheet...
    • 使用 File > Import Canva Sheet... 菜单项。
  2. 在对话框中输入表格的 url。
  3. 点击 OK。

Canva Sheet Asset将出现在资源窗口中。

引用页面

如果表格包含多个页面/标签页，导入表格时会弹出第二个对话框，询问要导入哪个页面。

连接数据

将此资源从资源窗口拖入视口或场景窗口，会创建一个电子表格工具，并将该资源连接到其 File 属性。

或者，手动创建一个电子表格工具，然后将 Canva Sheet Asset 从资源窗口拖到其 File 属性上。

选项

右键单击 Canva Sheet 资源会提供以下选项：

  • Spreadsheet Settings：定义 Cavalry 如何解读数据（CSV Asset 也有相同的设置）：
    • Delimiter：设置用于分隔数据中各个单元格的符号。注意：对于 Canva 表格资源，此项必须设为 ,（逗号）。.csv 数据可能使用其他分隔符。
    • Quote：设置用于界定数据中字符串的符号。
    • Decimal Separator：设置用于分隔数字整数部分与小数部分的符号。（例如 12.75 中的 .）
    • Factorize：在电子表格上使用 Factorize 属性时必须勾选此项。注意：对数据进行因子化可能会影响性能。
  • Rename：重命名该 Canva 表格资源。
  • Reload：重新加载 Canva 表格数据。Canva 表格发生更改后都需要执行此操作。
  • Replace Canva Sheet：将当前 Canva 表格的链接替换为另一个表格。
  • Open Canva Sheet in Browser：在 Web 浏览器中打开链接的 Canva 表格。
  • Delete：从场景中移除该 Canva 表格资源。

混合数据类型：

如果列中的单元格混合了多种数据类型（字符串/数值/颜色等），可能需要在表格中指定格式，以便“正确”解读单元格内容。例如，下表中的第一个单元格是数值，因此该列会被按数值读取，但第二个单元格不是有效数值，因此不会被 Cavalry 读取。

列
28
11/345

在此示例中，需要先选中该列，然后从顶部工具栏的 Number format 下拉菜单中选择“Text”选项，将这些单元格设为“文本”。这样在由电子表格工具读取时，它们会被解读为字符串。请注意，这意味着第一个单元格中的数字 28 不再被作为数值读取。
