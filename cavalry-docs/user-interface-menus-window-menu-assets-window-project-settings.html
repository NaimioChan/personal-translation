项目设置

简介

项目设置通过使用相对于项目的相对文件路径，在场景、资源和渲染结果（以及更多内容）之间建立关联。

设置项目后，会在文件系统的指定位置创建一个 Project Description。Project Description 只是一个 .json 文件，用于指定指向其他目录的默认文件路径。其结果是，例如在资源窗口中双击导入资源时，Finder（macOS）或资源管理器（Windows）会在项目指定的目录中打开。

当多人处理同一场景或共享同一批资源时，设置项目也很有帮助。这意味着可以建立一套工作流程来让团队保持有序——渲染结果放在这里，场景放在这里，资源可以在那里找到，等等。设置项目后，指向图像、音频、字体等的所有文件路径都会变为相对路径，因此在与工作室之外的客户/同事/自由从业者共享项目时，所有指向已导入资源的链接都能保持有效。

信息：

设置项目后，点击底部栏中朝右的箭头图标，或转到 File > Show Project Folder，即可在 Finder/资源管理器中显示包含 Project Description 的目录。

界面

创建新项目

创建新项目：

  1. 执行以下任一操作：
    1. 转到 File > Project Settings。
    2. 点击资源窗口左下角的文件夹图标。
  2. 点击 Project Settings 窗口右下角的 Create... 按钮。
  3. 在文件系统中选择一个目录作为项目的根文件夹。
  4. 为项目命名（默认使用第 3 步中所选文件夹的名称）。

或者，从资源窗口左下角的下拉菜单中选择 Create...，然后执行上面的第 3 步和第 4 步。

自定义项目

Project Settings 窗口中已预先填好各目录的默认位置。如有需要，可以编辑这些位置以创建自定义路径。

小心：

在 Project Settings 窗口中更改现有目录的名称，也会更改文件系统中对应目录的名称。例如，如果资源路径原本是 @project/Assets 并改为 @project/Images，则文件系统中的 Assets 目录会被重命名为 Images。

Name：项目的名称。该名称会用于资源窗口左下角的下拉菜单中。

小心：

更改项目 Name 不会改变文件系统中实际目录的名称。

Scenes：保存场景或打开场景的默认位置。

Renders：保存渲染结果的默认位置。

Assets：导入资源的默认位置。

  • Palettes：保存在此处的 .pal 文件会作为 Library Palettes 出现在颜色窗口中。参见：调色板。

Autosave：存储自动保存文件的默认位置。

默认情况下，此时会在项目目录中创建名为 Assets（以及 Palettes）、Renders、Scenes 和 Autosave 的目录，以及一个名为 projectDescription.json 的文件。

执行 File > Open... 时，Finder/资源管理器会打开项目目录中的 Scenes 目录。File > Save 也是如此。在资源窗口中双击时，Finder/资源管理器会打开 Assets 目录。渲染管理器中的 Path 会预先填入“@project/Renders”，这意味着渲染时文件会写入该目录。

编辑现有项目

要编辑项目，请再次打开 Project Settings 窗口并编辑路径。或者，参见下方的自定义设置。

切换项目

最近使用的项目会出现在资源窗口左下角的下拉菜单中。选择某个项目即会设置该项目。

也可以从资源窗口左下角的下拉菜单中选择 Load...，然后定位到包含 projectDescription.json 文件的目录，来设置现有项目。

打开现有项目中的场景时，也会切换到该项目。参见 path-to-project。

清除项目

移除项目设置的方式有：

  • 从资源窗口左下角的下拉菜单中选择 Clear Settings；或
  • 转到 File > Project Settings，然后点击 Project Path 行右侧的 x。

未设置项目时，指向资源、渲染结果等的所有路径都会变为绝对路径。

path-to-project

设置项目后，会在保存的每个场景文件旁创建一个名为 path-to-project 的文件。这是一个简单的文件，用于从 .cv 文件所在位置指向 projectDescription.json 文件。

以下是默认项目中的 path-to-project 文件示例：

📁 Project

  ┠ 📁 Assets

  ┠ 📁 Autosave

  ┠ projectDescription.json

  ┠ 📁 Renders

  ┠ 📁 Scenes

    ┠ yourSceneFile.cv

    ┠ path-to-project

存在 path-to-project 文件意味着，打开 yourSceneFile.cv 文件时，Cavalry 会自动切换到其上级项目。

在文本编辑器中打开时，path-to-project 可能只显示为 ..，这只表示向上一级，即 projectDescription.json 文件所在的位置。可以根据自定义工作流程的需要编辑此文件。例如，向上两级然后进入名为 MyFolder 的目录，应写作 ../../MyFolder。

如果已设置项目，保存新场景时，path-to-project 文件会自动包含相对于该项目的正确路径。

Cavalry Player：

使用 Cavalry 播放器 时，包含资源（图像、svg、音频等）的场景需要 path-to-project 文件。通过 Cavalry CLI 渲染时它也很有用。

自定义设置

projectDescription.json 文件也可以在文本编辑器中手动编辑，但在编辑前请确保它当前未被使用。

// projectDescription.json

{

    "description": {

        "assets": "@project/Assets",

        "autoSave": "@project/Autosave",

        "name": "Cavalry",

        "palettes": "@project/Assets/Palettes",

        "renders": "@project/Renders",

        "scenes": "@project/Scenes"

    }

}

色彩管理

Enable Color Management：勾选后，场景（包括大多数图像/视频资源和渲染结果）都会进行色彩管理。通过为场景设置工作色彩空间，合成及其他色彩运算会使用统一的色彩空间，从而更容易控制颜色的外观。

所有图像/视频资源和渲染结果都会进行色彩管理，但 GIF、SVG 和 Lottie 除外，无论工作色彩空间是什么，它们都会转换为 sRGB。任何渲染结果都会自动采用场景的工作色彩空间。

Working Color Space：选择一个色彩空间。

Compositing Bit Depth：决定每个像素存储的色彩信息量。更高的位深度会带来更多颜色和更平滑的渐变：

  • 8-bit：每个通道 256 种颜色。
  • 16-bit：每个通道 65,536 种颜色。
