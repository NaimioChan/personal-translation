工作区

简介

Cavalry 的默认工作区由各种窗口组成，但也可以为特定场景的任务设置并保存自定义窗口布局。当在绘制/绑定/动画等任务之间切换焦点时，这很有用，可以只显示每项特定任务所需的界面元素。

保存工作区

要保存工作区：

  1. 按你偏好的布局排列各个窗口。
  2. Window > Save Workspace...
  3. 为工作区命名并保存。

刚刚保存的工作区现在会出现在 Window > Workspaces > <yourSavedWorkspace> 下

整理工作区：

工作区可以通过将它们保存到文件夹/目录中来整理。加载工作区时，每个文件夹会显示为一个“类别”。例如，/Workspaces/Animation/Character.json 会在菜单中显示为 Workspaces > Animation > Character。

加载工作区

要加载工作区：

  1. Window > Workspaces > 选择一个已保存的工作区。

窗口会根据所选工作区重新排列。

更新工作区

工作区不会自动保存——可以把它们看作一种“预设”。如果需要更新现有工作区，只需按照保存工作区的步骤操作，并用相同名称覆盖现有工作区即可。

常规

工作区保存在：

  • macOS：~/Library/Preferences/Cavalry/Workspaces/
  • Windows：C:\Users\<USER>\AppData\Local\Cavalry\Workspaces\

退出 Cavalry 时，当前布局会被保存，并在下次启动 Cavalry 时使用。这就是活动工作区，保存在：

  • macOS：~/Library/Preferences/Cavalry/workspace.json
  • Windows：C:\Users\<USER>\AppData\Local\Cavalry\workspace.json

信息：

AppData 和 ~/Library 是隐藏文件夹。要找到它们：

  • Windows：在 Explorer 的 View options 中勾选“Hidden Items”。
  • macOS：在 Finder 中，打开 Go 菜单时按住 Option/Alt，Library 便会显示出来。

macOS Ventura：

由于 macOS Ventura 中存在一个影响窗口拖动的已知 Bug，重新定位窗口时通常会显示的预览已被暂时禁用。这纯粹是视觉问题，不影响功能。我们已将该问题告知 Apple，并希望尽快解决。
