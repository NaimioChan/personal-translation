2.0 版本说明

发布日期：2024年1月10日

文件版本升级：

在 Cavalry 1.5.6 或更早版本中创建的场景，在 Cavalry 2.0 中打开时会被转换。文件会被复制到一个新的场景中，需要保存——打开时你会注意到旧场景命名为 <yourSceneName> [Converted].cv。任何在 2.0 及之后版本保存的场景将无法完全兼容 Cavalry 的任何先前版本。

macOS 版本要求提升：

2.0 版本对 macOS 的最低要求已提升至 macOS 11。

Cavalry 2.0 有哪些新内容？

包括：

  • 摄像机：创建 2.5D 环境，为合成增加深度。
  • 预合成覆盖：覆盖合成中包含的属性，以创建模板。
  • 组件图形：收集图层并提升属性，以创建简化的自定义容器。
  • 后台渲染：交付渲染任务，以便继续并行工作。
  • 锥形描边：沿路径渐变描边的宽度。
  • 大幅的性能提升。
  • 全新的粒子系统现已作为实验性功能提供。
  • 以及更多……

新功能

常规

功能

  • 预合成覆盖 ：提升图层的属性，使其可以从预合成自身访问和覆盖，从而为同一预合成的多个版本添加变化。
  • 轨道遮罩：使用 Alpha 遮罩来遮罩图形。
  • 图形新增 Transform Only 运动模糊选项。
  • 粒子分布，用于将图形定位到粒子上。
  • 动画偏移：在现有任何关键帧动画之上叠加额外动画。
  • 文件菜单中新增 Increment and Save。
  • 颜色窗口中新增 Palette Generator。

UI/UX

  • JavaScript 编辑器的升级 ：
    • 查找和替换文本。
    • 自动缩进。
    • 插入匹配括号和双引号的辅助功能。
    • Snippet Editor。
  • 运动路径：在视口中预览图形的位置和速度。
  • 首选项窗口中新增 Locking Layers Prevents Selection in the Scene Window 选项。
  • 在视口中悬停于图形上时，现在会显示 Pre-Selection Highlighting。显示的细节程度会随所悬停图形的复杂度自适应。例如，不再高亮段落中的每个字符，而是仅显示单词或整个文本图形的边界框。
  • 视图菜单现在包含 Show Layer Names on Hover 选项。
  • 选中的图形现在会在视口中显示标签。

渲染

  • Background Rendering ：交付渲染任务，以便继续并行工作。
  • 新增 Sprite Sheet 渲染格式。
  • WebP 图像格式现在可以作为资源导入，并作为 File Format 导出。
  • Alpha Add 混合模式，有助于修复相邻边缘之间的接缝。
  • 可在渲染时重新调整合成的时间。请参阅渲染管理器页面的 Compositions 标签页。

图形编辑

  • 图形菜单中新增 Split Path at Selection 命令。
  • 对齐窗口中新增 Point Alignment。

图形

  • 组件图形 ：组件是包含其他图层集合的图层。这些图层的属性可以提升到组件，从而创建简化的自定义用户界面。
  • Tapered Stroke：沿路径创建锥形描边。请参阅通用属性（Stroke 标签页）。
  • 分段路径 ：它取代了现已移除的 Trim Path 工具（实验性功能）。
  • 合并：从两个包含开放路径的图形创建一个包含闭合路径的图形。
  • 超级图形已添加到 Basic Shape。
  • EXPERIMENTAL 粒子系统，包含图形、发射器和修改器。

行为

  • 自动动画：仅用少量关键帧即可为图形添加多种动画。
  • 自动裁剪行为：根据边界框裁剪图形。
  • 波浪变形器：沿开放和闭合路径创建循环波浪变形。
  • 切割路径 ：将图形切割成若干片段。
  • 行进变形器 ：重新定位路径中所有轮廓的起点。
  • Value3 行为。
  • Value3 混合。

工具

  • 摄像机 ：为合成添加摄像机，以创建 2.5D 环境。
  • 半径工具 ：生成可包围多个图形的圆的半径。
  • Value3 数组。
  • 新增了多个工具图层，用于配合粒子图形使用：
    • EXPERIMENTAL Emitters：定义粒子的出现位置以及添加到合成中的数量：
      • 分布发射器。
      • JavaScript 发射器。
      • 粒子发射器。
    • EXPERIMENTAL Modifiers：可用于更改粒子属性的场。
      • 数据修改器。
      • 流场修改器。
      • 力修改器。
      • 目标修改器。
      • 图像修改器。
      • JavaScript 修改器。
      • 磁力修改器。
      • 路径修改器。
      • 速度修改器。
      • 湍流修改器。
      • 可视化修改器。
      • 漩涡修改器。

效果

  • 背景模糊滤镜 ：模糊图形中位于另一图形内部的区域。
  • 棋盘着色器：为图形添加棋盘图案。

脚本

Cavalry 模块

  • degreesToRadians()
  • radiansToDegrees()
  • boundingBox() 现在会输出 centre、top、bottom、left 和 right 变量。
  • Cavalry 模块的 Path Class 新增以下方法：
    • empty()：返回路径是否为空。
    • pointCount()：返回路径中的点数。
    • contains()：返回由 x,y 指定的点是否位于路径内部（仅对闭合路径有效）。
    • pathData()：返回表示路径的动词和点数组。
    • length()：返回路径的长度。
    • pointAtParam()：返回一个包含 x,y 变量的点对象，对应路径上给定参数处的位置。
    • tangentAtParam()：返回一个包含 x,y 变量的点对象，对应路径上给定参数处的切线。
    • angleAtParam()：返回以度为单位的角度，表示路径上给定参数处的切线。
    • paramAtLength()：给定长度，返回该长度值对应的参数值。
    • findClosestPoint()：查找路径上最近的点。
    • offset()：扩大或缩小闭合路径。
    • trim()：通过从起点/终点裁剪来缩短路径的长度。
    • resample()：根据所需的“edgeLength”采样点来重建路径。
    • lineIntersections：返回路径与直线相交处的点数组。
    • pathIntersections：返回此路径与给定路径相交处的点数组。
    • relax：使路径中的点彼此远离。
    • smooth：通过对点位置取平均值来平滑点。
    • scatter：通过飞镖投掷法在路径内部散布点。点默认会被松弛。
  • 新增 Line Class，包含若干新方法。
  • 新增 Mesh Class，包含若干新方法。
  • 新增 Material Class，包含若干新方法。
  • 新增 Matrix Class，包含若干新方法。

增强

常规

  • 帧行为新增了 'Seconds' 插值。
  • Beta Features 已重命名为 Experimental Features，以避免 beta 版本（例如 Cavalry 2.0 beta 7）与功能之间的混淆。
  • 资源窗口现在支持排序。
  • 组在视口中的选择/交互已改进：
    • 单击并拖动组内的任意图形现在会移动整个组。
    • 双击图形会深入到该层级。
    • 按住 S 可选择组的子级。
    • 右键单击组内的图形，可选择该层级中的父级。
  • EXPERIMENTAL 轨迹现在可以自动继承粒子图形的颜色。
  • 当图形用作复制器的 Input Shape 时，现在会遵循图形的 Opacity。
  • 网格浏览器已焕然一新，并包含缩略图预览。
  • 场景窗口中的 Notes 功能现在具有黄色背景色，以提高对比度。
  • 通过 Composition > Pre-Compose 菜单（或场景窗口中的上下文菜单）创建预合成时，新的预合成会继承父合成的 FPS。
  • 网格分布新增 Flow Rows/Columns 属性。
  • 细分提供了一个选项，可改善开放路径端部生成的曲线。
  • 首选项中新增一项，用于确定锁定的图层是否也在场景窗口中锁定。
  • 对可编辑图形使用添加分割行为时，现在会在视口中显示点。
  • 如果可编辑图形正在被变形，现在会同时绘制原始路径和变形后的路径。
  • 带括号的图像序列（例如 filename (1).png、filename (2).png、filename (3).png ...）现在可以导入资源窗口。
  • 合成设置窗口中新增 Blur Align 选项。
  • 投影滤镜新增了改进的默认值。
  • 渲染管理器中新增一个选项，用于决定是否在 SVG 文件中包含合成背景。
  • 场景预设已重命名为演示场景（它们从来就不是真正的“预设”！）。
  • 使用自动动画功能，为演示场景新增了若干文本转场。
  • 演示场景中新增了若干 JavaScript 示例。
  • Bevel 现在以更可预测的方式处理开放路径上的倒数第二个点。
  • 检测到缺失字体时，消息栏现在会显示警告。
  • 将 SVG 图形作为可编辑图形导入时，现在会遵循层级。
  • 重采样路径新增 Corner Angle 属性，有助于保留角点。
  • 按住 Option/Alt 并在视口中拖动预合成，现在会创建该预合成的第二个引用（例如仍链接到现有合成），而不是创建新的合成副本。
  • 获取子网格变换新增 Use Bounding Box 属性，以支持文本图形的单词和行。
  • 现在可以禁用属性表达式。
  • 使用关键帧图层时，会出现一个新的附加控件，用于反映所有图层的组合值。

UI/UX

  • 现在可以通过将连接拖放到视口中的图形上来建立连接。
  • 文本图形的字体菜单现在会使用字体本身渲染列表。不受支持的字体将回退到默认字体。
  • 属性编辑器现在包含：
    • “粘性标题”。
    • 动画滚动。
    • 标题栏新增颜色分隔线。
    • 用于更好地对常用属性分组的分隔线。
    • 改进了生成器（例如复制器的分布）的缩进。
    • 数组的界面改进。
    • 根据“模式”显示/隐藏属性（参见自动动画）。
    • 新增“内联帮助”消息。
  • 程序化动画曲线现在会在曲线编辑器中预览。
  • 现在可以通过在场景窗口中双击关键帧，直接访问 Magic Easing 设置。
  • 在曲线编辑器中双击关键帧时弹出的窗口现在包含更多选项，包括 Magic Easing、interpolation 和 bezier handle lengths。
  • 曲线编辑器中控制柄的“约束”已改进。此前，移动贝塞尔控制柄时施加的约束（例如将控制柄移过其他关键帧）过于激进，可能导致“双击动画曲线以添加新关键帧”功能在某些情况下产生不准确的曲线。图形属性曲线（例如衰减）也做了类似改进。
  • 最近添加的图层现在会作为“快速添加”快捷方式，出现在图形变形器和滤镜属性的属性编辑器中。
  • 新增热键，可通过单击颜色窗口中的色块来设置图形的填充/描边颜色。
  • 合成菜单中新增用于关闭当前合成或其他合成的命令。
  • Enable Time Remapping 命令现在可从场景树和时间编辑器的上下文菜单中使用。
  • 现在可以约束多个属性的比例。例如，如果矩形的 Width = 100、Height = 200，在约束启用时将 Width 设为 200 也会把 Height 设为 400。
  • Shift + F 热键现在会在曲线编辑器中适配帧范围，与时间编辑器一致。
  • 改进了在曲线编辑器中删除关键帧时对动画曲线的保留。
  • 改进了在图形属性（例如衰减）中添加点时对曲线图形的保留。
  • 输入部分有效的十六进制颜色代码现在会自动补全（例如输入 AB 会得到 #ABABAB）。
  • 资源窗口的上下文菜单中新增了图标。
  • 改进了编辑数值/字符串/标签时的高亮对比度。
  • 双击预合成现在会将其界面加载到属性编辑器中——这与场景窗口中任何其他图层的工作方式一致。单击 Open 按钮，或按住 Option/Alt + Cmd/Ctrl 双击场景窗口中合成图层的行，将会打开该合成（使其成为活动合成）。
  • 现在右键单击属性编辑器中的某一行时，可以使用 Control with Null 选项。它会创建一个空对象，并将其 Position 连接到该行的属性。
  • 现在右键单击视口时会出现 Get Info 选项，提供光标下图形的信息。单击菜单项会将其值复制到剪贴板。

性能

  • Cavalry 2.0 进行了大量优化。速度提升取决于场景，但平均而言，你可以预期播放速度提升约 200%。在复杂场景中性能提升最为明显，我们观察到最高约 600% 的速度提升。简单场景的播放性能至少应提升 10%。
  • 打开大型场景现在快得多。在我们的测试中，2000 个图层的场景加载时间现在快约 22 倍。
  • 选择大量图层现在快约 100 倍。

重要错误修复

  • 路径分布的 Per Contour 中的 Count 已恢复正常工作。
  • 路径偏移现在能再次正确处理孔洞。
  • 当选择工具设置为 'Individual' 时，按住 Option/Alt 并拖动以复制图形，不再导致双重变换。
  • MP4 和 WebM 影片现在通过图像缓存加载，这意味着加载时占用的 RAM 大幅减少。
  • 修复了在曲线编辑器中双击创建新关键帧时的错误。
  • 将默认连接到合成的图层（例如合成约束连接到 Resolution）复制到其他合成时，这些图层现在会连接到新合成的属性。
  • 修复了通过场景窗口弹出菜单从动画控制建立连接时的错误。
  • 使用自定义时间格式且以 / 或 : 作为分隔符的渲染令牌（例如 <%X>）现在改用 -。
  • 使用视口缓存时，视口装饰（例如 FPS）不再绘制。
  • “New Beta Available” 提示条应仅在实际存在比当前已安装版本更新的 beta 时出现。
  • 使用混合模式的图形不再与合成的棋盘格混合。
  • 电子表格的 Row Count 输入连接现在可以从其连接的属性访问。
  • 快速模糊滤镜不再裁剪 Y 轴。
  • 修复了间隔器会导致布局组失效的问题。
  • Forge Dynamics 模拟的缓存已修复。
  • Reverse Animation 命令重新恢复正常。
  • 居中和右对齐文本的字符间距现在按预期工作。
  • 为时间上有偏移的预合成添加时间重映射时，关键帧现在会正确放置在预合成的开始/结束处。
  • 修复了在图像智能文件夹根目录中发现图像序列时导致的崩溃。
  • 修复了 macOS 保存对话框中的一个问题：在打开未保存场景的情况下退出 Cavalry 后按 Return，未遵循默认（保存）选项。
