布尔

简介

Boolean 可用于从其他图形中移除或向其添加图形。它与裁剪遮罩的区别在于，它实际编辑的是几何体，而不仅仅是在视口中将其移除，因此描边等功能会按照生成的网格更新。

界面

Common Attributes +

Clipping Shapes：连接用于与主图形进行布尔运算的图形。

Mode：

  • Union：添加到图形中。
  • Subtract：移除图形的一部分。
  • Intersect：移除图形外部的所有内容，只保留重叠区域。
  • Exclude：仅显示不重叠的区域（与 Intersect 相反）。

信息：

布尔运算是叠加的，因此每次运算都会作用于其上方运算的结果。

示例：

  1. 使用矩形工具绘制 2 个相互重叠的矩形。
  2. 在属性编辑器中，点击 Rectangle1 上 Deformers 属性旁的 + 图标。
  3. 从列表中选择 Boolean。
  4. 双击 Boolean 将其载入属性编辑器。
  5. 连接 rectangle2.id→boolean.clippingShapes
  6. 在场景窗口中将 Rectangle2 的可见性设置为关闭（点击“眼睛”图标）。
  7. 将 Mode 设置为 Subtract。

现在 Rectangle2 已从 Rectangle1 中移除。
