合成设置

简介

合成设置窗口可用于设置合成的分辨率、帧范围和其他属性。可以通过 Composition > Composition Settings... 菜单项（Cmd/Ctrl + K），或通过 场景窗口打开。

界面

Resolution：以像素为单位设置合成的宽度和高度。使用上方的下拉菜单选择一些常用预设。

Frame Range：设置合成的起始和结束帧编号。

Playback Range：设置播放时使用的起始和结束帧编号。也可以使用时间编辑器顶部的端点（带绿色端头的条）来设置此值。

Time：一个只读属性，输出当前帧。它不接受输入，但可以连接到其他属性，不过在这里帧 通常是更好的选择。

Frame Rate：设置合成播放时的 FPS（每秒帧数）。

Background Color：使用十六进制或 RGB 值设置合成的背景颜色。点击色板可设置 HSV 值。

提示：

将色板从颜色窗口拖到视口的空白部分，即可设置 Background Color。

信息：

通过场景窗口内的上下文菜单（右键点击）创建的合成，其 Background Color Alpha 被设为 0。

Playback Step：每隔 n 帧播放。例如，值为 2 时会每隔一帧播放，同时保持 Frame Rate 不变。

Motion Blur：为合成启用/禁用运动模糊。

Shutter Angle：设置快门角度。默认值 180° 会带来“电影感”。即 Frame Rate 的 50%。

Motion Blur Centre：影响模糊位于当前帧之前还是之后。默认值 0 会使其以该帧为中心（运动模糊在运动方向上前后均匀）。

Blur Align：调整运动模糊采样点相对于 Motion Blur Centre 的位置。这对于控制动画开始/结束时的运动模糊程度很有用。例如，如果图形在上一帧是静止的，将 Blur Align 设为 -100 将不会产生运动模糊。

Motion Blur Samples：决定运动模糊的采样次数。数值越高，模糊越平滑，但也会带来性能开销。

Keyframe Layer：当前活动的关键帧图层。

Referenceable：勾选后，当场景作为引用导入时，该合成会出现在资源窗口中。

信息：

也可以将合成从资源窗口拖入属性编辑器来访问这些设置。
