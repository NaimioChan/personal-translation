区域范围

简介

将一系列输入值解释为一个区域，然后将其重映射为尺寸。

这适用于创建比例图表，即用数值来确定 Ellipse 的 Radius 或 Rectangle 的 Sides。例如，如果要表示人口，直接把数值连接到复制器中椭圆的半径，会产生与数据不成比例的视觉呈现。

在下图中，直接连接输入值（上图）时，Radius 为 100 的椭圆面积远大于 Radius 为 20 的椭圆面积的 5x，但在经过 Area to Dimensions 工具处理之后（下图），它们的比例是正确的——输入值为 20 的椭圆在视觉上是输入值为 100 的椭圆面积的 1/5。

界面

Value：输入或连接一组数值。

Maximum Value：为 Value 设置最大值——通常是所连接数值中的最高值。

Maximum Dimensions：Maximum Value 被重映射到的值。

Clamp：勾选后，输出将永远不会超过 Maximum Dimensions。

示例：

  1. 创建一个Ellipse（Option/Alt + 点击椭圆工具）
  2. 创建一个值数组。
  3. 使用 Add 按钮添加一个 Value Array。
  4. 为每个索引设置值：
    1. 0:Value = 34
    2. 1:Value = 20
    3. 2:Value = 100
  5. 选中Ellipse，点击复制器图标（位于工具架中）。
  6. 将复制器的 Distribution Type 设为 Linear。
  7. 将复制器的 Size 设为 500。
  8. 创建一个 Area Range。
  9. 连接 valueArray.id→areaRange.value
  10. 连接 areaRange.id→ellipse.radius
  11. 将 Area Range 的 Maximum Value 设为 100。
