应用 OpenType

简介

Apply OpenType 可用作 Style Behaviour，以程序化方式动态启用文本图形中使用的 OpenType 特性。

界面

Mode：选择用于选取范围的模式：

  • Regex：设置Regular Expression 以确定字符串中哪些部分会被选中。属性编辑器界面顶部提供了若干预设。
  • Specific Indices：手动输入索引，以确定选中哪些行/单词/字符。
  • All：当与行为配合使用 Apply Typeface 时使用此设置。参见 Create > Demo Scenes > Text > Variable Font。

Index Mode：当 Mode 设为 Specific Indices 时，选择受影响的层级：

  • Line：填充由 Specific Indices 定义的字符串中的每一行。
  • Word：填充由 Specific Indices 定义的字符串中的每个单词。
  • Character：填充由 Specific Indices 定义的字符串中的每个字符。

Specific Indices：当 Mode 设为 Specific Indices 时，设置要选中的索引。列表中的值应以逗号 , 分隔，范围应以冒号 : 分隔。例如 0,1:3,8 将选中索引 0、1、2、3 和 8。你也可以输入 first 或 last 来以程序化方式选中这些索引。注意空格字符也算作一个索引。

Regex：输入Regular Expression。更多信息请参见使用正则表达式。

Capture Group Indices：当正则表达式包含捕获组时，确定返回哪些组。列表中的值应以逗号 , 分隔，范围应以冒号 : 分隔。更多信息请参见使用正则表达式。

Add

Font Feature：从列表中选择一个 OpenType 特性。注意，该列表不会根据字体进行筛选，因此请确保所用字体支持该特性。

Enabled：勾选后，启用该 OpenType 特性。

示例：

  1. 创建一个文本图形。
  2. 将 Font 设为 Inter。
  3. 输入字符串 I heard the store is open from 1st June to 3rd July.。
  4. 点击 Style Behaviours 属性右侧的 +。
  5. 从列表中选择 Apply OpenType。
  6. 在场景窗口中双击 Apply OpenType 图层，将其界面加载到属性编辑器中。
  7. 将 Mode 设为 Regex。
  8. 在 Regex 控件中输入字符串 (\d+)(st|nd|rd|th)。
  9. 在 Capture Group Indices 控件中输入 2。
  10. 从 Font Feature 列表中选择“Superscript”。

只有当 st 或 rd 出现在数字之后时，这些字符才会被设为 Supertype。
