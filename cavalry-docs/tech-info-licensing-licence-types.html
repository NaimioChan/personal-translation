Cavalry 许可证类型

旧版：

本页仅适用于 Cavalry 2.6.1 及更早版本。

旧版用户

旧版

Cavalry 通过网站提供 3 种类型的许可证：

  • Starter：无需付款或提供信用卡信息即可使用。
  • Professional：付费版本，以年度订阅形式提供，包含额外功能。
  • Team：为团队购买和管理许可证。

有关 Team 和 Education 许可证的信息，请参阅网站。

Enterprise 许可证提供通过 CLI 进行的无界面渲染。

Starter

Starter 许可证面向学习或评估，但也可用于商业用途。它没有有效期，因此你想用多久都可以，除少数例外之外功能齐全：

  • 渲染和导出限制为 1920 x 1080px。你可以在任意尺寸的合成中工作，但任何输出都会被调整为最大不超过上述两个尺寸之一。
  • 某些功能不可用（见下文）。

Professional

Professional 许可证将渲染分辨率提升至最高 15360 × 8640px，并包含对以下功能的访问权限：

Try Pro：

大多数 Professional 功能都可以通过界面顶部的 Try Pro 按钮进行评估。以 Starter 许可证登录时，加载 Try Pro 示例会启用 Restricted Mode，从而阻止保存或渲染。移除 Professional 功能，或以 Professional 许可证登录，即可停用 Restricted Mode。

以 Professional 许可证登录时，该按钮显示为 Pro Features，因为这些场景可作为演示场景使用。

2.5D

  • 摄像机：使用摄像机创建 2.5D 环境。
  • Camera Guides：变换 摄像机 的“视图框”来驱动其动画。

自动化

  • 动态渲染：轻松自动化渲染合成的多个版本。
  • Google Sheet Asset：导入数据以通过 Google Sheets 驱动动画。
  • 图像智能文件夹：导入包含图像、视频或图像序列资源的文件夹，之后可通过外部数据引用这些资源。
  • 音频智能文件夹：导入包含音频资源的文件夹，之后可通过外部数据引用这些资源。

图形

  • 网格图形：通过向网格添加顶点来使图像/图形变形。
  • 调度组：以程序化方式在时间上排布子图层。
  • Layout Groups：将图形堆叠为布局。
  • 挤出：挤出图形以营造深度感。
  • 时间轴计数器：使用时间标记或节奏标记来随时间累积或触发数值。
  • 累加器：创建图形或自定义布局的“堆栈”。
  • 组件：收集图层并提升属性，以创建简化的自定义容器。
  • 切割路径：将图形切成若干切片。
  • 分段路径：将路径分割为更小的区段以创建子网格。
  • 最短路径：通过点分布找到起点与终点之间的最短路径来生成路径。
  • 等值线图形：将图像或图形图层转换为轮廓线。
  • Rectangle Pattern Shape：创建堆叠条形图和饼图。

行为

  • 弯曲变形器：让图形围绕圆周弯曲，从而使其变形。
  • Squash and Stretch Deformer：挤压和拉伸图形，并提供添加鼓胀效果和保持图形面积的选项。
  • Knot Deformer：在轮廓自相交处的路径上添加间隙。
  • 轮廓转子网格：将图形内的路径轮廓转换为子网格。

用户界面

  • 快捷键管理器：自定义执行命令所用的快捷键。
  • 控制中心：提升合成中最重要的属性以便快速访问 —— 非常适合用于绑定，以及与同事或客户共享复杂场景。
  • Multiple Viewports：启动多个视口窗口以预览多个合成。
  • 依赖关系图：以示意图形式查看并操作合成内的连接关系。

渲染

  • Audio Export：渲染为 .mp4、.webm 和 .mov 时包含音频，或仅将音频渲染为 .acc。
  • Lottie 导出：将动画导出为适合网页的 Lottie（.json）格式。
  • Background Rendering：将渲染任务交由后台执行，以便同时继续工作。

工作流

  • 跟踪工具：跟踪视频素材中的平面。
  • 引用：将其他 Cavalry 场景文件作为资源导入，以实现团队协作。
  • 预合成覆盖：覆盖合成中包含的属性以创建模板。
  • Export as Project：将场景或选定的合成及其连接的资源导出到新的 Project 目录。

模拟

  • Forge Dynamics：功能完备的刚体动力学系统。

    • Forge Dynamics 图形：Forge Dynamics 系统的“核心”。
    • 碰撞事件
      • Body 设置碰撞事件：在图形碰撞时更改其密度/摩擦/弹性等。
      • 颜色碰撞事件：在图形碰撞时更改其颜色。
      • 冲量碰撞事件：在图形碰撞时为其添加额外的力。
      • 粘性碰撞事件：在图形碰撞时将它们粘在一起。
      • 可见性碰撞事件：在图形碰撞时影响其可见性。
    • 约束
      • 桥接约束：将图形连接在一起。
      • 距离约束：将图形约束到其原始位置。
      • 固定约束：将图形固定在其位置上。
    • 场
      • 吸引场：将图形拉向目标或推离目标。
      • 方向场：创建有方向的力来推动图形。
      • 拖拽场：对图形的位置速度和旋转速度施加反向作用力。

  • 值求解器 + 值2求解器：存储之前帧的数值，以便对其进行累积和/或衰减。

JavaScript

  • Scripting APIs：使用 JavaScript 访问场景中的图层和数据，从而编写执行自定义工作流的脚本。
  • JavaScript 工具：使用 JavaScript 表达式驱动其他图层。
  • JavaScript 图形：通过 JavaScript 表达式创建图形。
  • JavaScript 变形器：通过 JavaScript 表达式创建变形器。
  • JavaScript 编辑器：编写可访问 Scripting APIs 的 JavaScript 脚本，以创建、连接和影响图层。注意 —— 虽然 JavaScript Editor 在 Starter 许可证中可用，但只有 Professional 许可证才能运行脚本。
  • Setup/Pre/Post-Render Scripts。

滤镜与着色器

  • 狭缝扫描滤镜：创建动画式的穿梭飞行效果。
  • 像素排序滤镜：按照亮度等各种属性对图层的像素进行排序，从而重新排列像素。
  • 刮擦滤镜：从一条线上拉伸像素，形成涂抹效果。
  • 扫描线滤镜：模拟 CRT 显示器的效果。
  • 背景模糊滤镜：对位于另一图形内部的图形区域进行模糊。
  • Voronoi 着色器：通过计算点阵之间的距离生成细胞状图案。
  • 辉光滤镜：为图形添加辉光效果，并可控制 RGB 通道。
  • 亮度模糊滤镜：根据另一图层的亮度值对一个图层进行模糊。
  • 色度键滤镜：使用高级遮罩控制从图像中移除绿/蓝/红幕。
  • 球面化滤镜：将输入的图形映射到可旋转的球体上。

通用

  • 移动变形器：重新定位路径中所有轮廓的起始点。
  • Radius Utility：生成一个可包围多个图形的圆的半径。
  • 描边复制器：为图形添加复杂的描边组合。

实验性功能

所有 实验性功能 —— 请确保在 首选项 中勾选 Show Experimental Features，以便访问这些功能。

  • 粒子：模拟烟雾、雨或灰尘等复杂的基于物理的效果。
    • 粒子图形：粒子系统的“核心”。
    • 发射器：定义粒子出现的位置，以及向合成中添加多少粒子：
      • 分布发射器
      • JavaScript 发射器
      • 粒子发射器
    • 修改器：可用于改变和影响粒子属性的场。
      • 数据修改器
      • 流场修改器
      • 力修改器
      • 目标修改器
      • 图像修改器
      • JavaScript 修改器
      • 磁性修改器
      • 路径修改器
      • 速度修改器
      • 湍流修改器
      • 视觉修改器
      • 旋涡修改器

兼容性

Starter 和 Professional 用户可以共享文件，但当文件包含 Professional 功能时，Starter 用户将被切换到 Restricted Mode，从而阻止保存或渲染。其标志是应用程序标题栏中出现“Restricted”字样，并叠加显示在视口中。

Enterprise

Enterprise 许可证包含 Professional 许可证中的全部内容，并额外提供以下功能：

  • CLI：命令行界面让你无需启动 Cavalry 本身即可执行各种任务。部分功能在 Starter 和 Professional 版本中可用，但 render 和 list 命令以及 --prompt 参数是 Enterprise 独有功能。

有关你所持许可证的信息可在 关于窗口 中找到。

  • Email：当前登录的用户。
  • Licence Class：正在使用的许可证类型：
    • Starter：你已使用免费许可证登录。
    • Professional：你已使用 Professional 许可证登录。
  • Licence Status：许可证的状态：
    • Active：许可证处于激活状态。
    • Offline：离线时，你会看到距离需要重新验证还有多少天的提示。
    • Suspended：表示付款出现问题，并提示你还有多少天可以解决该问题。请访问 account.scenegroup.co 解决问题，或联系 support@cavalry.studio。
    • Expired：你的许可证已失效。你需要通过 cavalry.scenegroup.co 注册另一个 Starter 或 Professional 许可证。

管理订阅

登录你的 账户，并使用 Manage Subscription 按钮更改付款详细信息或取消订阅。
