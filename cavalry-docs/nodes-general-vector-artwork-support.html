矢量图稿支持

简介

Cavalry 支持导入和导出 SVG 图稿，这意味着可以从 Affinity、Figma 和 Adobe Illustrator 等其他矢量软件复制/粘贴 SVG 代码。

导入

除了将 SVG 作为资源导入外，将 .svg 文件拖拽或粘贴到视口时也可以导入并转换。

从资源窗口或文件系统将 SVG 文件拖拽到视口，或通过剪贴板粘贴 SVG 数据，都会弹出一个包含两个选项的对话框：

  • Asset Layer：创建一个 SVG 图层，并将 .svg 资源连接到 File 属性。
  • Separate Layers：将 .svg 资源拆分为独立图层，把每个图层转换为可编辑图形，并设置匹配的 Fill 和 Stroke。

信息：

从资源窗口或文件系统将 SVG 资源拖拽到视口或场景树时按住 Option/Alt，可跳过该弹窗并执行 Separate Layers。

复制和粘贴 SVG 数据

可以从 Adobe Illustrator、Affinity 和 Figma 等其他矢量软件复制/粘贴 SVG 代码。

应用程序 操作说明
Adobe Illustrator Edit > Copy（Cmd/Ctrl + C）
Figma 右键点击路径并选择 Copy/Paste as > Copy as SVG。
Affinity Edit > Copy（Cmd/Ctrl + C）。请确保在 Settings > General > Miscellaneous 中勾选了 Copy Items as SVG

导出

Cavalry 合成可以通过渲染管理器或 File > Render Current Frame to SVG... 菜单项渲染为 SVG。

Cavalry 图形也可以复制到剪贴板。要以 SVG 形式将图形复制到剪贴板，请在视口中选择一个或多个图形，然后 右键点击 > Copy as SVG。

支持的功能

功能 导入 导出 说明
Opacity ✔️ ✔️ 图形的 Opacity 和/或 Fill Alpha 将决定导出时 SVG 的 fill-opacity。
Gradient ✔️
Clipping Masks ✔️
Text ✔️ 缺失的字体会回退到默认字体。
Blend Modes
Stroke Alignment 仅支持 Centre 对齐。

小心：

对 SVG 的支持可能参差不齐，因为它并非功能完备的格式。例如，SVG 格式原生不支持 Inner 或 Outer Stroke，因此不同软件会用不同方式绕过这一问题。所以在应用程序之间交换文件时，效果可能无法 100% 一致。
