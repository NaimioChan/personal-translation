1.5.0 版本说明

发布日期：2023年1月12日

文件版本升级：

最初在 Cavalry 1.4 或更早版本中创建的场景，在 Cavalry 1.5 中打开时会被转换。文件会被复制到一个新的场景中，需要保存——打开时你会注意到旧场景命名为 <yourSceneName> [Converted].cv。任何在 1.5 及之后版本保存的场景将无法兼容 Cavalry 的先前版本。

新功能

图形

全新的基于层级的 布局系统，取代现已弃用的 布局图形（beta）：

  • 布局组：以水平或垂直布局排列图形。
  • 网格布局行：将图形排列成一行，以便在 Grid Layout Group 中使用。
  • 网格布局组：将 Grid Layout Rows 排列成列以创建网格。

工具

  • Count Sub-Meshes Utility：统计图形在给定层级内的子网格数量。

滤镜

  • 伽马校正滤镜：应用伽马曲线来调整图像的感知亮度或暗度。

脚本

常规

  • 新增 info、warn、error 和 debug console 方法。

API 模块

  • exec
  • getKeyframeIdsForAttribute
  • getSelectedKeyframeIds
  • serialise
  • deserialise
  • setPreferenceObject
  • hasPreferenceObject
  • getPreferenceObject
  • setUserData
  • hasUserDataKey
  • getUserDataKey
  • getLayerFromUUID
  • addToControlCentre
  • removeFromControlCentre

Script UI

  • setOpenLocation：设置单击文件夹图标时 Finder/Explorer 打开的路径。
  • 新增 Callbacks：
    • onAssetAdded
    • onAssetRemoved
    • onLayerAdded
    • onLayerRemoved
    • onJSError
    • onAttributeSelectionChanged
    • onPointSelectionChanged
    • onKeySelectionChanged

增强

  • 抖动滤镜：该滤镜已改进，现在有更多 Modes/Patterns。
  • 半调滤镜：Halftone Filter 已被替换。任何在 1.4 中创建并使用 Halftone Filter 的场景，加载时会使用旧版滤镜——我们建议将其替换为新版本，但请注意各项设置的功能并不完全对等。
  • 单击场景树的标题栏现在会取消选择所有图层。
  • 布局选项已添加到工具架。
  • Cavalry .cv 文件现在以紧凑格式保存，以减小文件体积。在 VSCode/Sublime/等中，或通过 JSONLint.com 这类网站，将紧凑文件转换为 pretty-print，即可重新排版为之前的“人类可读”形式。
  • 在时间编辑器中双击关键帧时按住 Option/Alt，现在会将播放头移动到该关键帧所在的帧。

重要错误修复

  • 非 GUI 的加密脚本现在可以按预期加载。
  • 在 Windows 上导入特定的 Google Sheets 工作表现在重新按预期工作。
  • 重命名包含在控制中心中的图层，现在会按预期更新。
  • 微移片段（-/=）现在重新正常。
  • 已解决与关键帧图层相关的若干问题。
  • 右键单击 > Add Background to Selected 现在重新正常。
  • 已修复在缩放视图时时间编辑器中第 0 帧会卡住的问题。
  • 已修复使用 Animation Layer Filter 时，父级上的关键帧导致场景窗口中出现垂直错位的问题。
  • 在时间编辑器中使用 Option/Alt 键复制并替换路径动画关键帧时，现在会遵循缓动。
  • 已修复当 Stagger 用作 Time Offset 且子网格数量少于 Stagger 范围时，子网格会一起移动的问题。
  • 作为对 Freeze Calculations 功能相关问题的一项修复，场景现在打开时会定位到播放范围的第一帧，而不是场景保存时所在的那一帧。
  • 已修复无法编辑 Distortion Filter 中着色器关键帧的问题。
