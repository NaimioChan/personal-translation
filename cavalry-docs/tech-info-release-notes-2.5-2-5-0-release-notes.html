2.5 发行说明

发布日期：2025 年 10 月 1 日

文件版本升级：

在 Cavalry 2.4.3 或更早版本中创建的场景，在 Cavalry 2.5 中打开时可能会被转换。如果被转换，文件会被复制到一个需要保存的新场景中——打开时你会看到旧场景被命名为 <yourSceneName> [Converted].cv。在 2.5 及之后版本中保存的任何场景可能无法完全兼容旧版 Cavalry。

新功能

  • 引用：将其他场景文件作为“Assets”导入，然后像“Pre-Comp”一样使用，让多位艺术家可以协作完成更大的项目。
  • 跟踪工具：跟踪视频素材中的平坦表面（平面）。
  • Export as Project：将场景或选中的合成连同任何连接的资源导出到新的项目目录。
  • WebM 导出现在支持 AV1。
  • 包含音频的视频文件现在会同时导入视频轨道和音频轨道。

增强

  • 布局组现在包含 Wrapping 选项和新的 Spacing Mode。
  • 在 macOS 上导入 ProRes 文件现在使用硬件加速。
  • MP4 Export 现在在 macOS 上使用硬件编码，以提升导出质量和速度。
  • 预合成覆盖（也与引用相关）：
    • 现在可以自定义预合成覆盖 在 Pre-Comps 中的排列顺序。
    • 默认情况下，Override 的标签由 layerNiceName.attrNiceName 定义，但当属性被重命名后，现在只显示 attrNiceName。
    • 全新的紧凑界面设计。
    • 新增 Reset Value to Origin 命令。
  • 支持拖放重新排序的 Arrays/Compounds。
  • 组件：
    • 当任意子图层被隐藏时（即 Component 处于非编辑模式），现在会显示所有已添加动画的属性。
    • 由于已支持重新排序，'spacious/compact' 界面选项已移除。
  • 文本图形新增 'All Caps' 样式选项。
  • SkSL Filter 和 Shader 现在包含Export to Plugin 窗口。
  • Box 和 Circle 箭头新增 Constrain proportions 界面。
  • 预设现在支持从菜单、工具架以及通过拖放添加图层。例如，将图像拖入视口时，Image Shader 的 Scale Mode 可以设为 Fit Cover。
  • 场景窗口和JavaScript 编辑器的“分隔条”位置现在会跨会话保存。
  • 导入资源时按住 Shift 现在会打开 Finder/资源管理器，并定位到项目设置中定义的 Scenes 目录——在处理引用时很有用。
  • 新增右键选项，可在场景窗口中关闭合成。
  • 界面顶部显示的当前场景路径预览，在设置项目后将显示相对路径。
  • 第三方插件现在支持多通道 Shaders/Filters。
  • Cmd/Ctrl + F 现在会在支持搜索的窗口中激活搜索。
  • Option/Alt + T 现在在时间编辑器和曲线编辑器之间切换。
  • 快捷键管理器已改进：
    • 新增 'All Shortcuts' 标签页。
    • 所有标签页均支持筛选/搜索，包括按快捷键搜索。
    • 改进的 'error' 提示。
    • 窗口现在可以停靠。
    • 如果快捷键属于“子菜单”中的菜单项，现在会包含其子菜单名称。例如 'Align Left' 现在为 'Align Keyframes > Align Left'。
    • 现在可以为第三方脚本分配快捷键。
    • 改进命令排序。
  • 命令搜索现在包含 Quick Actions。
  • 使用任何“创建并连接”工作流时，按住 Cmd/Ctrl 现在会加载新图层的属性编辑器界面。这些工作流包括：
    • 右键 > Add Behaviour/Utility 等。
    • 该
    • 该 Add
    • 该 Add
  • 调整字符串长度字符串操纵器现在支持 Word、Line 和 Paragraph。
  • 合成现在包含 Preserve Frame Rate 属性。
  • 第三方插件作者现在可以指定插件所需的 Cavalry 版本，并在版本不匹配时阻止加载。
  • 新增 Edit Limits... 功能，可用于自定义属性的硬/软限制。对于需要特定自定义数值范围的组件和预合成覆盖，这很有用。
  • JavaScript 编辑器中新增 Format 命令。

重要错误修复

  • 渲染队列项 File Name 的连接图标已恢复。
  • 在图形的 Mask 标签页中添加 Feather 不再受视口缩放影响。
  • 与属性表达式和图形 2.5d Position/Rotation 属性相关的界面问题已解决。
  • 曲线编辑器的 Transform tool 现在能处理非整数关键帧值。
  • 对组多次运行 Shape > Centre Pivot 命令现在符合预期。
  • 修复了一处回归问题：right click > Replace... 图像资源会破坏所有已连接的 Image Shader。
  • 为 Clipping Masks 添加 Feather 可能导致原图形偏移的问题已解决。
  • 修复了 2.5D 变换的单个属性表达式失效的边界情况。
  • 描边工具、Inner Alignment 与 Composition Boundary 相关的问题已解决。
  • 与 Live Mode 以及加载范围衰减相关的崩溃已解决。
  • 导致组件中的动画属性可能丢失的问题已解决。
  • 使用 Dynamic Rendering 时暴露的内存泄漏已解决。
  • 改进了 Pan icon 可能卡住的若干情形。
  • 通过场景窗口列表替换输入连接时会“全部替换”的问题已解决。
  • 与默认 'Compact' JSON Format 偏好设置相关的问题已解决，该设置曾导致使用 LucidLink 的客户保存时间过长。
  • 布尔 缺失的裁切选项已恢复。
  • 若干“双重变换”问题已解决。例如，现在支持移动包含文本图形以及作为其文本路径的图形的群组。
  • 删除数组索引后再撤销可能触发的崩溃已修复。
  • 通过 Option/Alt + 单击将单个关键帧（作为唯一关键帧时）转换为贝塞尔曲线时崩溃的问题已解决。
  • 运算2 现在支持连接到 int2 属性（例如 Background Shape 的 Shrink 属性）。
  • 多行列表（Shaders/Falloffs）中重新排序的撤销现在可用。
  • 向 Forge Dynamics Shape 的 Bodies 列表添加图形的撤销现在可用。
  • 向 Multi-Row 列表（Shaders/Falloffs）添加内容的撤销现在可用。
  • 脚本：
    • 破坏性变更：alwaysShowVerticalScrollBar() 与 alwaysShowHorizontalScrollBar()。
    • 破坏性变更：movePoint 的 localSpace 参数不再反转。
    • "url" MIME 类型不再错误地将文件导入为资源。
    • 使用 api.deleteAnimation() 移除包含 Magic Easing 的动画时崩溃的问题已解决。
    • onSelectionChanged 回调与资源相关的回归问题已解决。
    • 重新加载 .xlsx 资源现在可用。

说明

  • Blur Filter 已重命名为快速模糊滤镜，以便与新的 Gaussian 及其他模糊滤镜区分。
  • Layer Tools 和 Viewport Tool Help 的设置已从工具设置窗口移至视口设置。
