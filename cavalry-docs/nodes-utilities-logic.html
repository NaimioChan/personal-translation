逻辑

简介

对布尔（开/关）值执行简单的逻辑运算（AND、OR、XOR）。

界面

First：设置用于运算的第一个布尔值。使用输入连接时，小于 0.5 的值被视为 false，大于或等于 0.5 的值被视为 true。

Operation：确定逻辑运算：

  • AND (both)：当 First 和 Second 均为 true 时，Result 为 true。
  • OR (one or both)：当 First 和/或 Second 为 true 时，Result 为 true。
  • XOR (one but not both)：当 First 或 Second 之一为 true 时，Result 为 true；但两者均为 true 时则不是。

Second：设置用于运算的第二个布尔值。使用输入连接时，小于 0.5 的值被视为 false，大于或等于 0.5 的值被视为 true。

Result：输出的只读预览。结果为 true 时，Logic Utility 会输出值 1；结果为 false 时则输出值 0。

示例：

  1. 创建一个椭圆。
  2. 创建两个Comparison 工具。
  3. 将两者的 Second 都设为 0。
  4. 连接 ellipse.position.x→comparison1.first
  5. 连接 ellipse.position.y→comparison2.first
  6. 创建一个 Logic Utility。
  7. 连接 comparison1.id→logic.first
  8. 连接 comparison2.id→logic.second
  9. 创建一个颜色数组。
  10. 使用 AddColor Array 并设置一种不同的颜色。
  11. 连接 logic.id→colorArray.index
  12. 连接 colorArray.id→ellipse.fill.color

使用 Select 工具在视口中移动椭圆。当椭圆位于视口的左下象限时，它会改变颜色，因为：

  • 它在 X 和 Y 方向的位置都小于 0，这意味着两个 Comparison 都返回 true。
  • 这意味着 Logic 也返回 true。
  • 从而将 Color Array 的 Index 设为 1。
