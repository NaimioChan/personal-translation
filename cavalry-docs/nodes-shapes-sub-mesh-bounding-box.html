子网格边界框

实验性功能：

这是一个实验性功能。要启用它，请在偏好设置中勾选 Enable Experimental Features。

简介

使用子网格（Duplicator、Text、SVG 等）的边界框创建矩形。有关子网格的更多信息，请参见 子网格。

界面

Common Attributes +

Input Shape：连接任何包含子网格的其他图形。

Level：设置要影响的子网格层级。

Expand：增加或减小生成的边界框尺寸。

Fixed Size：默认情况下，每个边界框的大小由各个子网格（例如文本字符串中的每个字符）的大小决定。取消勾选 Auto（Width/Height）复选框，即可将边界框设为固定的宽度和高度。

Specific Indices：输入每个子网格的特定 id，以便围绕它创建边界框。输入以逗号分隔的值（例如 0, 4, 7），或使用冒号创建范围（例如 1:4），也可以两者组合使用（例如 2, 3:5）。

Sequences Keep Gaps：勾选后，Specific Indices 属性中的范围（例如 0:3）将被转换为序列（例如 0,1,2,3）。这可以用来统一带有上伸部/下伸部的字母（例如 h 和 y）各自边界框的高度。请注意，此功能仅适用于一行——不支持多行文本/子网格。

信息：

请记住 Id 从 0 开始，因此字符串中的第一个单词是 id0。

示例：

  1. 创建一个 Sub-Mesh Bounding Box 图形。
  2. 将其 Fill Color 设为绿色。
  3. 创建一个 文本图形。
  4. 在 Text 属性中输入 Sub-Mesh Bounding Box。
  5. 连接 textShape.id→subMeshBoundingBox.inputShape
  6. 将 Level 设为 2（单词是 Text Shape 中子网格的第 2 层级）。
  7. 在 Specific Indices 属性中输入 0,2。

绿色框将绘制在 Sub-Mesh 和 Box 这两个单词周围。

跨换行符的 Specific Indices：

在向 Specific Indices 输入范围时请注意，如果该范围包含跨换行的字符或单词，生成的边界框将涵盖所有这些字符或单词。在下图中，尽管两个示例使用了相同的索引，但请注意范围 0:3 创建的边界框涵盖了 Enter indices across a，而 0,1,2,3 则为每个单独的单词创建了一个边界框。
