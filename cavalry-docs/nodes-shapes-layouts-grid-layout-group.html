网格布局组

简介

网格布局组可用于将网格布局行组织成列，从而创建网格。

布局简介→

虽然布局组也可以使用Wrap功能创建网格，但网格布局组适用于每一行都需要特定数量项的情况。

快速开始：

  1. 创建 3 个图形。
  2. 选中全部 3 个图形，在视口中右键单击并选择Layout > Embed selected in Grid Layout。

这会创建如下层级结构：

Grid Layout Group

  ┠ Grid Layout Row

    ┠ Shape1

    ┠ Shape2

    ┠ Shape3

行：

网格布局组需要以网格布局行作为子级。也可以将图形直接添加到网格布局组，但如果没有网格布局行，它就只是一个更复杂的垂直布局。

网格布局组的列由放置在网格布局行中的项所定义。各行中的项数不必相同，因此一个包含 10 项的网格布局行可以与一个包含 3 项的网格布局行一起嵌套在网格布局组中。间隔器可用于在行中创建空白布局项，以构建列宽均匀的网格。

任何放置在网格布局组内但不在网格布局行中的图形，都会被当作横跨所有列的全宽布局项。

界面

通用属性 +

Draw Extents：勾选后，将在视口中绘制Minimum和Maximum Size的示意。

Minimum Size：确定布局位于另一个布局内时所占据的最小宽度和高度。

Maximum Size：确定图形在布局内可填充的最大宽度和高度。一旦布局组内图形的总宽度/高度超过这些值，图形就会开始重叠。默认情况下，Maximum Size连接到合成的Resolution，移除该连接即可设置自定义值。

信息：

如果Maximum Size设置为小于Minimum Size的值，Maximum Size会在内部被钳制为Minimum Size的值（反之亦然）。这不会反映在属性编辑器中，但在勾选Draw Extents的视口中可以看到。

Margins：设置布局边缘（上、下、左、右）周围的空间。

Spacing：设置每个布局项之间显示的空间。

Ordering Policy：确定网格布局行在网格布局组内的排列顺序：

  • Layer Order：根据网格布局行在网格布局组内的顺序排列它们。层级顶部的图形被视为第一个布局项。
  • Alphabetical：根据Layer Name按字母顺序排列网格布局行。
  • Shuffle：随机排列网格布局行。

Flip Order：反转Ordering Policy。

Shuffle Seed：当Ordering Policy设置为Shuffle时设置随机种子。
