凸包

简介

创建一个包住其他图形的图形。

界面

Common Attributes +

Input Shapes - 连接图形，以便在其周围绘制 Convex Hull。

High Quality - 启用后，生成的图形将支持包含贝塞尔和/或二次曲线的 Input Shapes。

示例：

  1. 创建 2 个 Polygon。
  2. 为它们都添加一些位置关键帧。
  3. 创建一个 Convex Hull。
  4. 将这 2 个多边形连接到 Input Shapes 属性。
  5. 按播放。
