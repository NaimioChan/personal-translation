1.5.1 版本说明

发布日期：2023年2月2日

1.5 版本说明→

新功能

图形

  • Guide Layers：将图形设置为在视口中可见，但在文件渲染和/或预合成中不可见。

滤镜

  • 镜像滤镜：沿中心线翻转图形以创建镜像。

脚本

API 模块

  • delete 已重命名为 deleteLayer。⚠️ 这是一项破坏性变更。
  • deserialise 已更新为接受 json 字符串，而不是文件路径。⚠️ 这是一项破坏性变更。
  • importScene：导入 .cv 或 .cvc 文件。
  • runProcess 已更新。⚠️ 这是一项破坏性变更——如果旧脚本使用了其返回值，将会报错。
  • hasAttribute：检查图层上是否存在某个属性。
  • Proxy Server：通过 Web Client 连接时使用代理。
    • 新增 setProxy
    • 新增 setProxyBasicAuthentication
    • 新增 setProxyBearerAuthentication
  • exists 已重命名为 layerExists——exists 为向后兼容而保留，但不再出现在自动补全中。
  • writeToFile 新增了 'overwrite' 参数。
  • 新增 invertSelection：反转当前选择。
  • importGoogleSheet 现在会对无效的 Sheet/SpreadsheetIds 返回错误。
  • 新增 addGuide、deleteGuide、clearGuides 和 getGuides API，用于处理标尺参考线。

Cavalry 模块

  • 新增 Path.arcTo()：根据两个点和半径绘制圆弧。
  • 新增 Path.back()：设置路径中的最后一个点。
  • rgbToHex 和 rgbToHSV 现在新增了 scaled 参数，用于确定 RGB 值是按 0..1 还是 0..255 输入。

UI 模块

  • 新增 Draw 控件：通过 Cavalry Path 绘制自定义图形。
  • 新增 ScrollView 控件：控制脚本窗口中滚动条的位置。
  • 新增 Container 控件：用这些控件为布局提供带圆角的背景颜色。
  • add 现在可以一次接受多个参数（例如 layout.add(first, second, third)）
  • 为 LineEdit 和 FilePath 新增了 onValueCommitted 和 onValueChanged 回调函数。
  • 为 LineEdit 和 MultiLineEdit 新增 setTextColor。
  • 新增 ui.setFixedSize：为窗口设置固定尺寸。
  • 新增 ui.setMinimumWidth：为窗口设置最小宽度。
  • 新增 ui.setMinimumHeight：为窗口设置最小高度。
  • 新增 ui.setMaximumWidth：为窗口设置最大宽度。
  • 新增 ui.setMaximumHeight：为窗口设置最大高度。
  • 新增 ui.setFixedWidth：为窗口设置固定宽度。
  • 新增 ui.setFixedHeight：为窗口设置固定高度。
  • 新增 ui.setToolbar：让窗口表现得像工具栏。
  • 新增 ui.setVerticalToolbar：将水平（默认）工具栏窗口设置为垂直工具栏。
  • 为 HLayout、VLayout 和 DropDown 新增 clear()。
  • 新增 previousPage：PageView 上的一个函数，返回上一次访问的页面。
  • 为 VLayout 和 HLayout 新增 itemCount()：返回布局中控件的数量。
  • 为 DropDown 新增 insertSeparator。
  • ui.resize 已被移除，因为它不是可停靠窗口的有效操作。⚠️ 这是一项破坏性变更。

Context 模块

  • niceName：获取从 JavaScript 工具请求数值的图层的易读名称。

增强

  • 下拉菜单现在支持自动预览，这意味着在确认选择之前，结果会交互式地反映在视口中。
  • 文本图形 现在在 Advanced 标签下新增了 Font Scale 属性。它可用于将一个 Text Shape 中由 Shrink to Fit Text Box 应用的缩放传递给另一个 Text Shape。
  • 在视口中，Shift 现在也可以用于从选择中添加或移除对象。
  • 当工具架宽度缩小时，Shelf 图标现在可以溢出显示。

重要错误修复

  • 凸包 重新恢复正常。
  • 已恢复在时间编辑器中用 Shift + 选择关键帧的功能。
