布局图形

已弃用的功能：

这是一项已弃用的功能。替代功能请参见布局。

简介

将图形添加到布局图形后，这些图形会依次排列（垂直、水平或网格状）。布局图形的尺寸随后由其中图形的总尺寸决定。因此，当你为布局图形中的某个图形制作动画时，其他图形会随之移动。

界面

通用属性 +

Layout：选择图形的排列方式：

  • Grid Layout：参见网格布局。
  • Horizontal Layout：参见水平布局。
  • Vertical Layout：参见垂直布局。

Size：设置布局图形的尺寸。默认情况下，此属性连接到合成的 Resolution 属性。要手动设置此值，请删除该连接。

Add Spacer：间隔器可用于在布局中创建间隙或空白单元格。

Layout Items：将图形拖放到此区域，或连接到此区域。Layout Items 列表中还有更多选项，具体取决于所选的 Layout 模式：

  • - 切换图形是否出现在布局中。
  • Settings：
    • Grid Layout
      • Column Span：设置图形将跨越的列数。设为 2 表示图形将放置在一个宽 2 列的单元格中。
      • Row Span：设置图形将跨越的行数。设为 2 表示图形将放置在一个高 2 行的单元格中。
      • Fixed Position：为图形设置一个固定的单元格。
      • Position：为图形设置要放置的单元格。例如，值为 2, 2 会将图形放在第二行第二列。
    • Horizontal Layout
      • Baseline：将图形放置在基线上。这对齐文本和图形很有用。
      • Vertical Alignment：设置图形在其单元格内的垂直对齐。
    • Vertical Layout
      • Horizontal Alignment：设置图形在其单元格内的水平对齐。
  • - 从 Layout Items 中移除该图形。
