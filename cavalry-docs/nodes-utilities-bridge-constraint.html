桥接约束

简介

在 Forge Dynamics 模拟中将图形连接在一起，形成链条或桥接结构。

界面

Stretch：决定约束的拉伸程度。较高的值会产生更具弹性的效果。

Frequency (Hz)：较高的值会让弹簧弹跳更明显。

Damping Ratio：较高的值会让弹簧更快静止。

Breakable：启用后，约束可被其他力打断。

Breaking Mode：设置约束断裂的条件：

  • Force：当力高于 Breaking Force 时，约束断裂。
  • Distance：当约束超出其 Stretch Limit 时断裂。
  • Time：当高于 Breaking Force 的力持续超过 Breaking Duration 的连续帧数时，约束断裂。

Breaking Force：设置使约束断裂所需的力的大小。

Stretch Limit：设置约束在断裂前可被拉伸的 Rest Length 倍数。例如，如果 Rest Length 为 100、Stretch Limit 为 2，则约束会在拉伸到 100 \times 2 = 200 时断裂。

Breaking Duration：设置约束在受力高于 Breaking Force 后需持续的连续帧数才会断裂。

Stress Threshold：以 Breaking Force 的百分比设置一个阈值，约束在该阈值范围内会断裂。

Add

固定

  • Mode：
    • Off：禁用约束。
    • Pin：固定指定索引的位置。
    • Transform：将指定索引的位置固定到一个变换。
  • Pinned Index：设置要固定的索引。使用子网格（例如 Duplicator）作为 Body 时，可以使用字符串 first 或 last 动态设置第一个和最后一个 Id。或者，在此处输入数值将固定对应的 Id。
  • Transform：连接一个图形以设置固定点的位置和旋转值。
  • Limit Rotation：限制约束的旋转。
  • Rotational Limits：设置上限（U）和下限（L）角度，以钳制约束的旋转。
