Web API

简介

Cavalry 提供了一种与 Web 上的 API 端点交互的方式：创建一个 WebClient 对象，并调用它的方法进行 get、post 或 put。这些 API 调用是阻塞的，也就是说它们必须成功完成后，脚本才能继续执行下一部分。

除了 WebClient，Cavalry 还提供了一个简单的 WebServer。你可以调用 /get 获取你在服务器上设置的任意响应；如果你喜欢冒险，也可以使用 /post。为了方便使用 /post，WebServer 可以轮询新数据，并在检测到数据投递时触发回调函数。

快速上手

尝试以下示例来了解 Web API。

简单的 get 请求。

// Make a new WebClient


var client = new api.WebClient("https://www.boredapi.com");


// Send the Get Request (this returns a random activity to do if you're bored).


client.get("/api/activity");


// Check it succeeded


if (client.status() == 200) {


    let obj = JSON.parse(client.body());


    // Safety check, and print the activity


    if ('activity' in obj) {


        console.log("Random activity: "+obj.activity);


    }


}

获取并保存 SVG 文件。

// Update Uri and path


var client = new api.WebClient("https://cavalry.studio");


client.get("/path/to/logo.svg");


if (client.status() == 200) {


    api.writeToFile("/path/to/cavLogo.svg", client.body());


}

WebClient

小心：

使用 WebClient 时，构造函数只能包含基础 URL（例如 https://www.boredapi.com）。传入路由（例如 https://www.boredapi.com/api/activity）会导致错误，此时 WebClient.status() 会返回 -1。

setBasicAuthentication(username:string, password:string)

为后续所有请求设置基本身份验证。

setDigestAuthentication(username:string, password:string)

为后续所有请求设置摘要身份验证。

setTokenAuthentication(token:string)

为后续所有请求设置基于令牌的身份验证。

addHeader(key:string, value:string)

为后续请求添加请求头。API 密钥、应用密钥、内容类型等都可以通过这种方式添加。

getHeaders() → object

var client = new api.WebClient("https://www.boredapi.com");


client.get("/api/activity");


if (client.status() == 200) {


    let headers = client.getHeaders();


    for (const [key, value] of Object.entries(headers)) {


      console.log(`${key}: ${value}`);


    }


}

status() → int

返回请求的状态。例如 200 表示 OK。

body() → string

返回的响应体。它通常采用 JSON 形式，如果不确定，可以用 getHeaders() 检查 Content-Type 头。

get(path:string)

执行 get 请求。完成后，status() 以及（如果成功）body() 即可使用。

post(path:string, content:string, contentType:string)

执行 post 请求。完成后，status() 以及（如果成功）body() 即可使用。

put(path:string, content:string, contentType:string)

执行 put 请求。完成后，status() 以及（如果成功）body() 即可使用。

postFromFile(path:string, filePath:string, contentType:string)

用于直接提交文件的辅助方法。上传二进制文件（如图片或影片）时尤其需要此方法。执行 post 请求。完成后，status() 以及（如果成功）body() 即可使用。

putFromFile(path:string, filePath:string, contentType:string)

用于直接提交文件的辅助方法。上传二进制文件（如图片或影片）时尤其需要此方法。执行 put 请求。完成后，status() 以及（如果成功）body() 即可使用。

writeBodyToBinaryFile(path:string)

如果使用 get 获取的是二进制数据（即图片或影片），则不能将其传给通常的 api.writeToFile() 调用。你必须改用此函数将 body 数据写入文件（例如之后你可以将其作为资源导入 Cavalry）。

setProxy(hostAddress:string, port:number)

输入代理服务器的 IP 和端口号。

setProxyBasicAuthentication(username:string, password:string)

输入用于向代理服务器验证的用户名和密码。

setProxyBearerAuthentication(password:string)

输入使用 bearer token 的代理服务器的密码。

WebServer

一个实现 Cavalry 服务器的 UI 脚本完整示例。请将其保存到 Cavalry 的 Scripts 文件夹（Help > Scripts），然后通过 Window > Scripts 菜单加载。

var server = new api.WebServer();





var button = new ui.Button("Start Server");





button.onClick = function () {


    if (!server.isRunning()) {


        server.listen("localhost", 1234);


        button.setText("Stop Server");


    } else {


        server.stop();


        button.setText("Start Server");


    }


}





function Callbacks() {


    this.onPost = function () {


        console.log("Queue length: "+server.postCount());


        processButton.setEnabled(true);


    }


}





var processButton = new ui.Button("Process Posts");


processButton.setEnabled(false);





processButton.onClick = function () {


    while(server.postCount()) {


        let obj = server.getNextPost();


        console.log("Process: "+obj.result);


    }


    processButton.setEnabled(false);


}





var callbackObj = new Callbacks();


server.addCallbackObject(callbackObj);





ui.add(button);


ui.add(processButton);


ui.show();

脚本运行后，在 JavaScript 编辑器中运行以下代码，/post 的文本应会打印到控制台。

var client = new api.WebClient("http://localhost:1234");


client.post("/post", "Cavalry Needs You!", "text/plain");


client.post("/post", "Join the Cavalry!", "text/plain");

listen(host:string, port:int)

让服务器在指定的端口号上监听主机地址（例如 localhost）。

stop()

停止服务器，轮询也会一并停止。

setResultForGet(resultText:string)

设置 /get 请求的结果，目前仅支持 text/plain。

getNextPost() → object

由于在你来得及处理之前可能会发生许多 /post 事件，Cavalry 会为你将它们排队。此函数会获取下一个（最早）的 post，并将其从队列中弹出，这意味着一旦获取，你就无法再从服务器访问它。该对象包含一个 result 字符串和一个 headers 数组，每个 header 都是一个带有 name 和 value 的对象。请注意，/post 事件仅支持非二进制数据。

getNewestPost() → object

与上述方法类似，只是它不会获取最早的未处理 /post，而是跳到最新的一个并将其从队列中弹出。

postCount() → int

返回未处理的 /post 事件数量。使用 getNextPost() 或 getNewestPost() 函数处理这些 post。

clearPosts()

清除所有未处理的 /post 事件。使用 getNextPost() 或 getNewestPost() 函数处理这些 post。

addCallbackObject(callbackObj:object)

设置一个 Callback 对象（与 UI 回调对象非常相似）。这是一个实现了 onPost 函数的 JavaScript 对象。设置 Callback 对象后，服务器将开始轮询新信息，默认每 3 秒轮询一次。

var server = new api.WebServer();


function Callbacks() {


    this.onPost = function () {


        console.log("Check result: " + server.getNewestPost().result);


    }


}





var callbackObj = new Callbacks();


server.addCallbackObject(callbackObj);

setHighFrequency()

在设置 Callback 对象之后调用此方法，会将轮询频率改为每秒一次。

setRealtime()

在设置 Callback 对象之后调用此方法，会将轮询频率改为每秒 60 次。这对于与 midi 控制器等设备进行实时通信很有用。
