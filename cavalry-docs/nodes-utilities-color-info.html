颜色信息

简介

获取指定颜色的色相、饱和度或明度。

界面

Mode：选择要输出的颜色属性：

  • Hue：输出 Color 的色相（0-360）。
  • Saturation：输出 **Color **的饱和度（0-1）。
  • Value：输出 Color 的明度（0-1）。

Color：设置颜色。

Result：只读值，用于预览输出。

示例：

  1. 创建一个 Color Info。
  2. 将 Mode 设为 Hue。
  3. 创建一个图形。
  4. 连接 colorInfo.id→shape.position.x
  5. 点击 Color Info 上的颜色色块以弹出颜色选择器。
  6. 点击并拖动外圈中的白色圆环以调整色相。

图形将沿 X 轴在 0 到 360 之间移动。
