2.1 版本说明

发布日期：2024 年 5 月 15 日

文件版本提升：

在 Cavalry 2.0.3 中创建的场景在 Cavalry 2.1.0 中打开时会被转换。文件会被复制到一个新的场景中，需要另行保存——打开时你会注意到旧场景被命名为 <yourSceneName> [Converted].cv。在 2.1.0 及之后版本中保存的任何场景将无法完全兼容 Cavalry 的任何先前版本。

Cavalry 2.1 有哪些新内容？

📣 制造点动静吧！！ 📣

Cavalry 2.1 的主题是音频，包括音频导出、多轨音频播放以及对 Sound Behaviour 的重大改进。

新功能

常规

  • 颜色窗口 中新增 Label Palettes 标签页，可用于为图层、关键帧和时间标记设置自定义标签颜色。
  • 新增 音频监视器 窗口。
  • 音频智能文件夹 现在是一项 功能。
  • 拥有 Starter 许可的用户现在可以将首个选中图层导出为 Lottie，以评估该功能。
  • 新增 Try Pro 窗口。可从 工具架 中的按钮打开，旨在提供使用专业版功能的简单示例。请注意 Starter 用户会被切换到“受限模式”，该模式禁止保存和渲染——删除 Pro 图层即可恢复保存和渲染。

音频导入

支持的音频文件类型列表已扩展，包括：

  • .mp3 音频文件。
  • .aac 音频文件。
  • .caf（即 Apple Loops）音频文件。

支持的音频文件类型完整列表见此处。

音频导出

音频现在可以导出为以下格式：

  • 新增 Audio Only 格式（.aac）。
  • MP4（h264）。
  • QuickTime（Motion JPEG、Uncompressed 422、ProRes 422、ProRes 422 HQ、ProRes 422 LT、ProRes 422 Proxy、ProRes 4444、ProRes 4444 XQ）。
  • WebM（VP8、VP9）。

音频播放

更多用于处理音频播放的控制项：

  • 支持多轨音频播放。
  • Sound Behaviour 现在有 in/out 点（即 Clips）。
  • 场景树 中新增一个开关，可独立于 Sound Behaviour 的输出启用/禁用音频播放。
  • Viewport 音频设置弹窗中新增 Playback Volume 控制。

内嵌音频：

请注意，不支持视频资源中包含的音频。

CLI

  • CLI 中已添加对音频导出的支持。

行为

  • Sound Behaviour 现在是一项 Starter 功能，并包含以下改进：
    • Frequency Scale：选择用于采样音频文件频率的模型。
    • Frequency Range Hz：自定义采样文件时的频率范围。
    • Band Weighting Graph：控制各频段对输出值的贡献。
    • Active Bands（Output）：在 Equaliser 中所选活动频段的数量。
    • Volume Adjustment：为音轨音量制作动画。
    • Pan：将音频偏向左/右声道。
    • Play Audio：通过动画控制音频播放的开/关。

脚本

API 中新增了以下功能：

API

  • editComponent()。
  • getSuperTypes()。
  • setCavalryPreference。
  • getCavalryPreference。
  • setGradientFromColors。
  • setGradientInterpolation。
  • connect 成员函数现在可以选择覆盖现有连接。
  • getGenerators()

Cavalry

  • conicTo()。
  • normalAtParam。
  • quadTo。
  • convertConicsToQuads。

Script UIs

  • onMouseEnter。
  • onMouseLeave。
  • setBackgroundColor()。
  • onCavalryPreferenceChanged 回调。
  • Container 新增 close() 方法。

增强

  • 加载视频资源在许多情况下现在快得多。
  • 摄像机工具 现在包含“Dolly”快捷键。
  • 时间编辑器 现在在框选超出当前视图的关键帧/剪辑时会自动滚动。
  • Import Google Sheet... 对话框的视觉效果已改进。
  • 加载 Google Sheet Assets 现在多线程进行，意味着多个资源会并发加载，并且在从 Google API 调用数据时不再阻塞交互。
  • 在 Assets Window 中复制合成时，Guides 现在也会被复制。
  • 时间轴 现在当 Frame Indicator 处于时间码模式时会显示时间码标尺。
  • 动态渲染：Number of Renders 属性现在为 Dynamic Range，意味着可以按 RQI 设置范围，并且（通过脚本）可以渲染任意一组序列。
  • 加载场景时现在会通过模态窗口提示任何缺失字体。
  • 缺失字体现在会在 Attribute Editor 中被标记。
  • 现在可以在 渲染管理器 中删除所有选中的渲染队列项。
  • 现在可以从 资源窗口 中删除当前活动合成。请注意，如果将成为新活动合成的合成位于层级之中，它会被移到根层级（这需要改进！）。
  • 未激活的行为现在输出 0 或其输入值（目前尚未覆盖所有行为）。
  • 颜色窗口 中新增 Circular 生成器类型。
  • 值数组 现在可以输出其所有值的总和。
  • 支持具有水平滚动的鼠标。
  • 时间编辑器 现在支持使用触控板进行自由滚动。
  • 组 现在有选项用于决定其中的图形如何与彼此以及 Group 外的其他图形视觉组合。
  • 现在可以将 字符串 连接到颜色，反之亦然。
  • 四角定位 图形新增“Bind Selected Shape”按钮。
  • 边界框 工具新增“Create and Connect Rectangle”按钮。
  • Create > Demo Scenes > Audio 中新增音频示例。

重要错误修复

  • 使用中键平移 时间编辑器 不再破坏与 场景树 的垂直对齐。
  • <frame> Render Token 现在恢复工作。
  • View > Draw Outside Composition Boundary 现在恢复工作。
  • 手动将图形作为 Bodies 连接到 Forge Dynamics 图形 后，打开其设置（齿轮图标）时现在会显示正确的界面。请注意，通过 场景树 中的弹出菜单建立连接时仍会出现此错误。
  • 空 Sub-String String Manipulator 导致的崩溃现已解决。
  • 使用带 Transition from End 的 Transition String Manipulator 导致的崩溃现已解决。
  • 修复了在编辑模式下右键单击 文本图形 某些区域时崩溃的问题。
  • length() API 成员函数现在按预期工作。
  • 素材图形 现在能正确读取 图像智能文件夹 中图像的尺寸。
  • 时间编辑器 在撤销 Pre-Compose Selection 操作后不再出现垂直错位。
  • 使用受支持的鼠标进行水平滚动时的方向已统一。

备注

  • Quick Add 窗口现在称为 Add Layers 窗口，并已纳入默认工作区。
  • Audio Smart Folders 和 Image Smart Folders 现在最多限制为 5 层子目录。
  • 组 新增的混合与不透明度模式在某些边缘情况下可能改变部分旧场景的外观。如果遇到这种情况，请尝试从默认的 Individual Layers 模式切换到 Artboard。

API 变更

  • Time Marker 的 Color 属性已更新为 Draw Color Id。脚本路径也已从 drawColor 改为 drawColorId，现在接受 number。使用该路径的任何脚本都应更新，以兼容 Cavalry 2.1 及以上版本。参见 createTimeMarker 示例。
