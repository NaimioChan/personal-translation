创建菜单

Quick Add...：打开添加图层窗口。

Create Editable Primitives：通过工具创建 Primitives（例如椭圆）时，将其转换为几何体。

Primitives：创建一个原始图形（椭圆、矩形、多边形……）

Background：向当前合成添加一个背景图形。

Shapes：选择要添加到当前合成的图形。

Behaviours：选择要添加到当前合成的行为。

Effects：选择要添加到当前合成的效果。

Utilities：选择要添加到当前合成的工具。

Layout：将当前选择添加到布局。

Text Animation Presets：选择一个文本图形图层，然后选择一个预设来为它应用动画。

Demo Scenes：选择一个场景作为示例添加到当前合成，以获取灵感或学习。并非所有示例都设置了动画，但在选择菜单项时按住 Cmd/Ctrl 会自动开始播放。
