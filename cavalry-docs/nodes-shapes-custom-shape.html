自定义图形

简介

Custom Shape 是一种图形，它会继承另一个图形或图形组的网格与材质。它可用于创建其他网格的“实例”。

界面

Common Attributes +

Bake Transform - 勾选后，Input Shape 的变换将应用到 Custom Shape 的输出上，这意味着如果 Input Shape 被缩放，Custom Shape 的输出也会相应变化。这也可以作为一种在缩放时保持 Stroke Width 的方法。

Input Shape - 连接一个图形或图形组，以据此生成 Custom Shape 的网格。

示例：

  1. 使用 Pen 工具绘制一个 Editable Shape。
  2. 创建一个 Custom Shape。
  3. 连接 editableShape.id→customShape.inputShape
  4. 将 Custom Shape 的 Scale X 设为 -1
  5. 使用 Edit Shape 工具移动 Editable Shape 上的点。

现在，Custom Shape 已成为 Editable Shape 的镜像。
