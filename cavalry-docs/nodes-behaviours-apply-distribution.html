应用分布

实验性功能：

这是一项实验性功能。要启用它，请在偏好设置中勾选 Enable Experimental Features。

简介

Apply Distribution 可用于分布子网格。例如，将文本图形的字符按放射状图案分布。

界面

Distribution：参见分布类型。

Level Mode：这些预设会设置 Level 值：

  • Custom...：手动设置 Level 属性。
  • Text (Lines)：将 Level 值设为 1。
  • Text (Words)：将 Level 值设为 2。
  • Text (Characters)：将 Level 值设为 3。

Custom Level：手动设置 Level 值。有关层级的更多信息，请参见子网格。

示例：

  1. 按住 Option/Alt 并点击工具栏中的 Text 工具，创建一个默认文本图形。
  2. 在属性编辑器中，点击文本图形 Deformers 属性上的 + 按钮。
  3. 从列表中选择 Apply Distribution。
  4. 将 Apply Distribution 的 Distribution 设为 Circle。
  5. 将 Count 设为 7（以匹配字符串中的字符数）。
