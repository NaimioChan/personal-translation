窗口菜单

简介

窗口菜单包含用于启动和排列窗口的选项和命令。

选项

Workspaces：选择一个工作区来布置窗口。

Save Workspace...：将当前布局保存为一个工作区。

Reset to Default Workspace：将布局重置为默认工作区。

Add Layers：参见添加图层窗口。

Align Window：参见对齐窗口。

Animation Utilities：参见动画工具。

Assets Window：参见资源窗口。

Attribute Editor：参见属性编辑器。

Audio Monitor：参见音频监视器。

Color Window：参见颜色窗口。

Control Centre：参见控制中心。

Dependency Graph：参见流程图。

Glyph Browser：参见字形浏览器。

Graph Editor：参见曲线编辑器。

JavaScript Console：参见JavaScript 控制台。

JavaScript Editor：参见JavaScript 编辑器。

Mesh Explorer：参见网格浏览器。

Message Bar：参见消息栏。

Scene Statistics：参见场景统计。

Scene Window (Time Editor)：参见场景窗口。

Shelf：参见工具架。

Tag Window：参见标签窗口。

Tool Settings：参见工具设置。

Toolbar：参见工具栏。

Upload Preset Manager：参见上传预设管理器。

SHortcut Manager：参见快捷键管理器。

Command Search：参见命令搜索。

Command Search (Quick Actions only)：参见命令搜索。

Add Viewport：打开一个额外的视口。

Focus Mode：在当前工作区与仅由视口和工具栏组成的简化工作区之间切换窗口布局。
