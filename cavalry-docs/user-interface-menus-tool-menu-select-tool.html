选择工具

简介

选择工具可用于选择、移动、旋转和缩放图形。

交互

选择

要选择图形，只需单击其中一个。要选择多个图形，可以：

  • 单击并拖拽光标以创建框选，或；
  • 使用 Cmd/Ctrl + 单击，将更多图形添加到选择中。

移动

要移动图形，只需在视口中单击并拖拽。

旋转

要旋转图形，在选中图形的情况下，将光标移到边界框外侧的角上。光标会变为弧形箭头。单击并拖拽即可旋转。

拖拽时按住 Shift 将启用吸附。请参阅下文的工具设置。

缩放

要缩放图形，在选中图形的情况下，将光标移到边界框的角上。光标会变为双向箭头。单击并拖拽即可缩放。

拖拽时按住 Shift 会将缩放约束到两个轴。

轴心

使用轴心工具可在视口中调整图形的轴心。

工具设置

有关此工具可用的特定于上下文的选项，请参阅工具设置。
