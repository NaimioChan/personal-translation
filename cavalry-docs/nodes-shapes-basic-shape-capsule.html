胶囊

简介

作为 基本图形 的一部分创建 Capsule 基础图形。

界面

Radius - 设置 Capsule 起点（S）与终点（E）的半径。

Mode：

  • Length - Capsule 依据从 Start Point 到 End Point 的长度绘制。在此模式下，Start Point 由 Capsule Shape 的 Position 决定。
  • Start/End - Capsule 在起点与终点的位置之间绘制。

Length - 设置 Capsule 的长度。

Start - 设置 Capsule 起点中心的位置。

End - 设置 Capsule 终点中心的位置。

Trim Ends - 沿 Capsule 的长度偏移起点/终点位置。

Bézier - 勾选后，起点和终点由贝塞尔点创建。

Edge Divisions - 设置点之间的分段数。这对于创建更平滑的变形尤其有用。

提示：

如果在 视口 中启用了 Viewport Snapping，则可以通过图层工具沿 Capsule 的长度吸附其起点/终点。此功能仅对处于 Start/End 模式的 Capsule 有效。
