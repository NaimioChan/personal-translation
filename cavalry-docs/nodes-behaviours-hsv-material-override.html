HSV 材质覆盖

简介

Material Overrides 允许你编辑复杂/深层网格结构（如 SVG 或文本）内部的材质。这可通过 子网格 行为的 Fill 或 Stroke 标签页实现。

通过向子网格添加 HSV Material Override，可以在原始色相、饱和度和颜色与 Override 所设置的值之间混合。随后可向 Sub-Mesh 添加衰减来控制该效果。

界面

Common Attributes +

Hue：设置色相值。

Saturation：设置饱和度值。

Value：设置值。

示例：

  1. 将 SVG 导入资源窗口。
  2. 将其拖入视口，并从选项中选择 Asset Layer 以创建 SVG Shape。
  3. 将 子网格 连接到 SVG Shape 的 Deformer 属性。
  4. 在 Sub-Mesh 上，切换到属性编辑器中的 Fill 标签页。
  5. 使用 + 按钮向 Fill Overrides 属性添加 HSV Material Override。
  6. 调整 Hue、Saturation 和 Value 值。
  7. 在 HSV Material Override 上，打开 Falloff 标签页并右键单击以添加衰减。
  8. 在 SVG Shape 上移动衰减。

当衰减在 SVG 各部分上移动时，它们会改变颜色。
