资源数组

简介

创建一个资源列表，可通过索引将其分配给其他图形。

界面

Auto Index：勾选后，该图层将自动输出所有索引。

Index：要从 Assets 列表中使用的索引。

Reverse：反转索引的输出顺序。例如，若有 3 个索引 0,1,2，其顺序将反转为 2,1,0。

Count：输出数组中索引的数量。

Add

0: Asset：数组中的第一个索引。将资源或资源文件（.svg/ .csv/ .png 等）连接或拖入此属性。

示例：

  1. 将 2 个 .png 文件从 Finder/资源管理器拖入资源窗口。
  2. 右键点击导入时创建的、包含这些 .png 文件的组，选择 Create Array from Group。这会创建一个包含 2 个索引的 Asset Array，每个索引都连接一个 .png 文件。
  3. 创建一个矩形。
  4. 打开 Fill 标签页。
  5. 右键点击 Shaders 属性，选择 Add Shader > 图像着色器。
  6. 将 Asset Array 连接到 Image Shader 上的 Image 插槽。
  7. 在场景窗口中选择 Rectangle，然后点击工具架中的复制器图标。

这会创建一个由 9 个矩形组成的网格，每个矩形的图像交替变化。如果你想随机化这一顺序，可以添加一个 Minimum 为 0、Maximum 为 1 的Random Behaviour，并将其连接到 Asset Array 的 Index。

信息：

有关此图层如何发挥作用的示例，请参见动态渲染部分。

双击设置 Index：

双击某个索引所在的行，会将 Index 设为该值。
