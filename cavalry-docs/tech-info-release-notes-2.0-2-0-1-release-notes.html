2.0.1 版本说明

发布日期：2024年1月31日

2.0 版本说明→

文件版本升级：

在 Cavalry 2.0.0 中创建的场景，在 Cavalry 2.0.1 中打开时会被转换。文件会被复制到一个新的场景中，需要保存——打开时你会注意到旧场景命名为 <yourSceneName> [Converted].cv。任何在 2.0.1 及之后版本保存的场景将无法完全兼容 Cavalry 的任何先前版本。

macOS 版本要求提升：

2.0.1 版本对 macOS 的最低要求已提升至 11.0（Big Sur）。

新功能

脚本

API 模块

  • getControlCentreAttributes()
  • bringForward()
  • bringToFront()
  • moveBackward()
  • moveToBack()

Cavalry 模块

  • mergeOverlaps()

小心：

在全局级别为JavaScript 图层设置变量时，任何使用 let 或 const 的旧文件现在都会被转换为 var。

增强

  • JavaScript 图层的速度提升了约 3 倍。
  • 细分现在有 Smooth Angle 属性。
  • 子网格新增 Index Mode。
  • 为预合成覆盖和组件新增了“在预合成/原始图层中显示”按钮。
  • 轮廓图形新增 Preserve Materials 属性。
  • 颜色窗口中的 Palette Generator 现在可以使用 LCh Color Model（也称为 HCL）生成颜色。

重要错误修复

  • 修复了打开包含相互连接的 JavaScript 图层的场景时发生的崩溃。
  • 修复了 Cavalry 模块中 quadTo 的 'cp1' 对象导致的崩溃。
  • 修复了通过场景窗口连接到数组中现有索引时，实际却添加了新索引的错误。
  • 修复了通过场景窗口连接到数组/列表中现有索引以替换原有连接时，实际却添加了新索引/条目的错误。
  • 修复了在添加部分演示场景后按撤销时发生的崩溃。
  • 修复了打开/导入某些包含多个合成和资源组合的场景时导致崩溃的问题。
  • 从数学图层到复选框的连接（例如 math.id→ifElse.condition
  • 从旋转到某些图层类型的连接（例如 shape.rotation→valueArray.array.0
