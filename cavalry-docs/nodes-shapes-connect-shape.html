连接图形

简介

连接点的分布，以创建错综复杂的线条图案。

Connect Shape 用直线或曲线连接由分布生成的点。

界面

Shape

Common Attributes +

Mode - 设置连接的连接模式。

  • Within Range - 当点落在 Search Distance 范围内时创建连接。
  • Nearest - 将 Source 点连接到距其最近的 Target 点。
  • Point Index - 将 Source 的点索引连接到 Target。

Time Offset - 在此属性上连接一个行为（例如 Stagger），以偏移连接线上已有的任何动画（例如 Stroke trim）。

Search Distance - 当点进入此范围内时，它们将连接（取决于其他设置）。

Connection Limit - 设置可建立的最大连接数。

Per Point Connection Limit - 设置每个点可建立的最大连接数。

Skip Points - 每隔 nth 个点忽略一个点。

Skip Offset - 按此值偏移跳过。

Line Type - 设置连接所用的线条类型：

  • Linear - 用直线创建连接。
  • Auto Bézier - 用曲线创建连接。

Auto Bézier Mode：

  • Smooth - 设置相等的贝塞尔手柄，在连接的两端形成肩部形状。
  • Shoulder Target - 设置贝塞尔手柄，在连接的目标端形成肩部形状。
  • Shoulder Source - 设置贝塞尔手柄，在连接的源端形成肩部形状。
  • Projection Vectors - 将贝塞尔控制点朝目标投影。若未指定 Projection Vector Target，则使用 0,0。

Control Point Bias - 调整贝塞尔曲线的形状。

Projection Vector Target - 连接一个图形作为目标，用于 Auto Bézier Mode 设为 Projection Vectors 时。

Source

Source Distribution - 设置分布类型以确定源点的位置。

Ignore Target Distribution - 勾选后，Source 点将相互连接，而不再寻找 Target。

Target

Target Distribution - 设置分布类型以确定目标点的位置。

提示：

将 Source/Target Distribution 设为 Sub-Mesh，并连接一个复制器 作为 Input Shape，即可绘制分布的点。
