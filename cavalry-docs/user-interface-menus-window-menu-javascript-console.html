JavaScript 控制台

简介

JavaScript Console 可用于调试 JavaScript 脚本。有关如何编写脚本的更多信息，请参阅Scripting 部分。

它也可以作为JavaScript 编辑器中的嵌入面板使用。如果 JavaScript Console 已作为工作区的一部分停靠，则此面板会隐藏。

界面

Clear logs（按钮）：使用此按钮可清除控制台中所有先前的日志。

Console：所有日志都会在此处输出，并根据其状态进行颜色编码：

  • 绿色 = 成功
  • 黄色 = 警告
  • 红色 = 错误

注意：

JavaScript Console 是可编辑的，这意味着可以添加笔记，其内容也可以复制到剪贴板。
