图像采样器

简介

Image Sampler 会采样 Input Asset 的数值（明暗），然后输出 0 到 1 之间的值（黑色 = 0，白色 = 1）。支持图像、图像序列和视频。

Material Sampler：

出于性能考虑，Image Sampler 不支持滤镜和着色器。它读取的是原始图像数据，因此任何调整（色阶、色相等）都需要在原始资源上完成，并在资源窗口中重新加载。如需更高的灵活性，可以查看 材质采样器，但代价是性能。

界面

Position：设置 Image Sampler 的位置。0,0 位于合成的中心。

Rotation：设置 Image Sampler 的旋转角度（以度为单位）。

Scale：设置 Image Sampler 的缩放。

Skew：沿 X 轴或 Y 轴倾斜或错切 Image Sampler。

Pivot：定义 Image Sampler 的轴心点。在为旋转和缩放制作动画时很有用。

Opacity：设置 Image Sampler 的预览不透明度。注意：Image Sampler 不会包含在渲染中。

Enabled：取消勾选时，Image Sampler 将输出数值 1（结果与没有 Image Sampler 时相同）。切换场景窗口中的可见性图标（眼睛）只会隐藏 Image Sampler，而此属性会影响其输出。

Strength：确定 Image Sampler 输出的强度。

Invert Value：勾选后，图像的输出将被反转，低值输出 1，高值输出 0（例如白色 = 0，黑色 = 1）。

Image Asset：连接一个图像资源。可以直接从资源窗口连接，也可以通过资源数组或智能文件夹资源连接。支持静帧图像、图像序列和视频。

Tiling：确定在 Image Asset 边界处的处理方式。

  • Clamp：使用 Image Asset 边缘的值。
  • Repeat：重复/循环 Image Asset。
  • Decal：裁切出 Image Asset。

Looping：当使用图像序列或影片作为 Image Asset 时，循环播放该序列/影片。

Offset：为输出加上/减去一个值。

Channel：选择要采样的颜色通道：

  • RGB：采样所有 RGB 通道。
  • Red：采样红色通道。
  • Green：采样绿色通道。
  • Blue：采样蓝色通道。
  • Alpha：采样 Alpha 通道。
  • Luminance：采样图像的亮度

Time：连接到合成的 Time，用于驱动视频或图像序列的帧编号。

示例：

  1. 将图像导入资源窗口。
  2. 创建一个 Image Sampler。
  3. 将图像从资源窗口拖入 Image Sampler 的 Image Asset。
  4. 创建一个矩形。
  5. 选中 Rectangle，点击工具架中的复制器项。
  6. 连接 imageSampler.id→duplicator.shapeScale

图形将根据图像的亮度进行缩放。注意：将 Image Sampler 的 Opacity 设为 0，即可在视口中隐藏它。
