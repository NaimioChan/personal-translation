2.4 发行说明

发布日期：2025年5月7日

新功能

常规

  • 新增 依赖关系图 窗口，提供合成内部连接关系的交互式示意图或映射。Starter 用户可预览，但不能创建或编辑。它取代了 Flow Graph。
  • 新增 网格图形，通过添加顶点创建网格来变形图像/图形。
  • 新增 网格工具，用于配合 网格图形 使用。
  • Third-party plugins：开发者现在可以创建并分发原生滤镜和着色器。
  • Excel（.xlsx）文件导入，包括在 Spreadsheet Utility 和 电子表格查找 中选择工作表/标签页的选项。

行为

  • 振荡器 已升级。新功能包括：
    • 用作变形器时支持无缝循环。
    • 新增 Seconds 和 Minutes (BPM) 时间模式。
    • 可创建自定义 Wave Type。

旧场景将使用“旧版”Oscillator 以保持向后兼容。可以手动替换，但请注意功能并不完全对等，因此可能需要调整部分设置。

效果

着色器

  • 新增 SLA 着色器。特别感谢 David Farmer 贡献其 SLA 噪声着色器，以纪念 Mark Coleran。

滤镜

  • SkSL 滤镜。使用 SkSL（“Skia Shading Language”）编写自定义滤镜。

工具

  • 摄像机引导：使用引导线驱动 Camera 的动画。
  • 应用字体样式 样式行为。动态设置 Underline、Strikethrough、Subscript 和 Superscript 等文字样式功能。
  • 秒转帧：将秒转换为帧。

脚本

  • isThirdPartyLayer
  • areAttributeValuesEqual
  • getParentComp
  • reorderArrayAttr
  • resyncPathKeyframes
  • getLayerVersion
  • compareVersions
  • isDirectory
  • isFile
  • getAbsolutePath
  • getRelativePath
  • listDirectory
  • listDirectoryRecursive
  • unZip
  • magicEasing 现在支持值为 "None" 或 "Custom" 的 easingName，并包含可选的 expression 参数。
  • 返回十六进制颜色值的 API 现在统一采用 #6437ff 这样的格式，即小写并以 # 为前缀。
  • ⚠️ 返回包含 alpha 的十六进制颜色值的 API 现在将 alpha 值放在末尾。例如 #[ff24e0]+[32] 而非 #[32]+[ff24e0]

增强

  • Encrypted Scripts 现在可由 Starter 许可通过 脚本菜单 运行。
  • 颜色窗口 有多项更新，包括：
    • 更新 UI，增加用于不同调色板类型的标签页。
    • 可重新排序的 List view，包含色板名称。见下方说明。
    • 将颜色粘贴到色板的命令。
    • 在列表视图中指定到 Fill/Stroke（无需快捷键）。
    • 从选区添加色板的命令。
    • 选择带有颜色的图层的命令。
    • 从 Scene Palette 中删除未使用的色板。
  • 渐变 组件有多项更新，包括：
    • 新的全宽 UI。
    • 可预览 Jitter 和 Interpolation。
    • Reverse Gradient 命令。
    • 渐变复制/粘贴命令。
  • Viewport 的 2D Grid 已更新：
    • 新增“Swiss”网格类型。
    • Regular 网格现在可指定原点（例如左上角）。
    • 现在支持创建非均匀网格。
    • 2D 网格现在按合成保存。
    • 网格可复制和粘贴。
  • 文本图形 现在包含 Style 属性，可用于为文本应用 Underline、Strikethrough、Subscript 和 Superscript 样式。
  • Camera Views：额外的 视口 现在可以从不同 摄像机 中选择视图。
  • getAttributeDefinition 现在包含 default 键。
  • 打乱字符串操纵器 已更新，提供更多打乱字符串的方法。
  • 自动裁剪 行为新增 Size 进度模式。
  • 描边支持基于百分比的 Dash Patterns。
  • 将色板从 Color Palette 拖动/放入 Viewport 中图形上的逻辑已改进。
  • Show Composition Boundary Viewport 选项现在可设置为自定义颜色。
  • 当 Viewport 启用 Playback Caching 时，Update the Viewport in Playback 按钮现在会变暗。
  • 从 窗口菜单 打开窗口时，现在会记住窗口大小。
  • 现在可以从 JavaScript 编辑器 中执行“Run Snippet”。
  • 文本图形 现在会继承其设置。例如，如果上一次操作 Text Shape 时将 Font 设为 Arial、Font Size 设为 100，那么接下来创建的 Text Shape 也会沿用这些设置。
  • 现在可以静音某个输入连接。
  • 复制器 新增 Skip Invisible Duplicates 属性（Advanced 标签页）
  • 现在可以复制/粘贴 Graph Widget。
  • Assets from Smart Folder 工具在 Specific Index 模式下现在会输出文件名。
  • 曲线编辑器 的 Transform tool 现在支持顶部、底部和角部控制点。
  • 噪波着色器 新增 Cycles 属性。
  • 噪波着色器 新增 Gamma 属性。
  • 图像着色器 的 Scale Mode 属性新增 Fit Cover 选项。
  • 图像着色器 新增 Missing Frames 选项。
  • 场景树 新增右键菜单 Reveal Composition in Assets Window 选项。
  • UI 标签页支持悬停激活。例如，将图层从 Scene Window 拖到已停靠的 依赖关系图 上。
  • JavaScript Window 的 Snippet 面板现在支持新的可重新排序列表。
  • 当描边的 Color Mode 设为 Gradient 时，渐变停止点现在支持 Alpha。
  • 混合子网格位置 行为现在可处理子网格（Text/SVG）。请注意，此更新需要新的图层，旧场景仍可正常工作，但我们建议尽可能替换该图层。
  • 指向“未使用”Generator 的连接不再列在 UI 中。
  • 改进了对处于“Restricted Mode”的 Starter 许可的警告。

重要缺陷修复

  • 已解决从 Forge Dynamics 固定约束 移除 Pin 时的多个问题。
  • Composition Boundary 现在仅在合成外部绘制。
  • rgbaToHex() 现在按预期支持 alpha。
  • 图层的 nice names 现在可以匹配其 layerId。
  • 值2求解器 现在可以直接连接到例如图形的 Position。
  • 文本图形 再次支持 Justify 对齐选项。
  • 现在可以从 Merge Shape 中移除材质（Fill/Stroke）。
  • 如果未设置 Project，启动时不再显示用于在 Assets Window 中显示 Project 的按钮。
  • 影响关键帧或动画曲线插值设置的“操作顺序”问题现已解决。
  • 将多个图像导入 资源窗口 时，现在会添加到选定的文件夹（如果已选中），而不再添加到新文件夹。
  • 删除已设置动画的数组索引不再导致 Time Editor 错位。
  • 从数组中移除索引后执行撤销不再触发崩溃（此处可能仍有隐患）。
  • 修复了一个回归问题：复制图层层级可能导致 Time Editor 与 Scene Tree 错位。
  • Pre-Comp 的 Blend Mode 现在受支持。这也与另一个问题相关：将 Pre-Comp 的不透明度从 100% 改为 99% 可能导致外观大幅变化。
  • 当着色器连接到描边时，图形的 Fill Alpha 不再影响其 Stroke Alpha。
  • 右键单击图层进行重命名时，现在会正确取消选择之前选中的图层。
  • 现在可以正常复制和/或复制粘贴 摄像机。
  • 打开包含位于 Project 内缺失资源的场景时，如果未设置 Project，现在会正确报告为缺失。
  • 未选中任何点时运行 Shape > Split Path at Selection 不再触发崩溃。
  • 撤销为描边添加着色器的操作时，Viewport 现在会正确更新。
  • 删除 JavaScript 图形 导致的崩溃已解决。
  • 在选中动画通道时删除图层导致的崩溃已解决。
  • 导致旧版文件中已保存属性出现问题的缺陷已解决。该问题与 Noise 行为上的“Use Layer as Seed”有关。
  • 钢笔工具 现在在使用 摄像机 时能正确绘制。
  • 在 Attribute Editor 中切换用于显示/隐藏相关属性的下拉菜单时，不再偶尔无法显示正确的属性。
  • F 适配现在（再次）可用于 曲线编辑器 中选中的关键帧。
  • 在 曲线编辑器 中删除关键帧不再将动画曲线从视图中清除。
  • Demo Scenes > JavavScript > Truchet Tiles 示例已更新。
  • 图像序列中的缺失帧不再影响其整体时长。

说明

  • Mesh Array 已重命名为 图形数组，以免与新的 网格图形 功能混淆。
  • hamburger 图标已替换为展开（...）图标。该图标用于 Color Window 和 Text Shape（可变字体）。
  • 为了让 Cavalry 自带调色板中的默认色板名称显示出来，需要重新生成它们。操作如下：
    1. 关闭 Cavalry。
    2. 将 Palettes 文件夹重命名为 Palettes-old。
    3. 打开 Cavalry。
    4. 手动将 Palettes-old 文件夹中的自定义调色板移动到将要（重新）生成的 Palettes 文件夹中
    5. 完成后即可删除 Palettes-old 文件夹。
