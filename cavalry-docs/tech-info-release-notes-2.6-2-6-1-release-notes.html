2.6.1 发行说明

发布日期：2026 年 3 月 5 日

功能

脚本

API

  • setKeyframeVelocity()
  • clearKeyframeVelocity()

重要错误修复

  • Text Backgrounds 现在在调整 Line Spacing 时能与父级文本图形正确对齐。这也会影响文本样式（删除线、下划线等）。
  • SkSL 滤镜 的 + 按钮已恢复。
  • SLA 着色器 的一处回归问题已解决。
  • 某些旧版场景中会额外要求一个本不需要的变形器的问题已解决。
  • 对复制器的输入图形使用滤镜时导致裁切的问题已解决。
  • 缩放包含滤镜的 自定义图形 中群组的子级时，不再导致裁切。
  • 在 Pre-Comp 中缩放连接到滤镜的图形时，滤镜的视觉结果现在与父级合成中一致。
  • 在依赖关系图中框选连线两次后，移动图层时不再破坏界面。
  • 排序分布 无法为其 Target 接受变换的回归问题已解决。
  • 当 Pre-Comps 中没有摄像机时，其中的 2.5d 图层在父级合成中可能顺序翻转的问题已修复。
  • Forge Dynamics 模拟中仅对 rotation.z 有动画的 Kinematic Bodies 现在会被正确处理。
  • 在 素材图形 上使用 [ 快捷键现在会正确遵循关联的音频。
  • 通过脚本为 SLA 着色器 添加动态属性时崩溃的问题已解决。
  • 添加 细分 会阻止此前变形器动画的缓存问题已解决。
  • 对 Pre-Comp Override 使用 Reveal the Origin Layer 命令时可能导致属性编辑器界面无法移除的问题已解决。
  • 影响带有 offset pivots 的 可编辑图形 在视口中选择的问题已解决。
  • 序列工具预览的一处外观问题已解决。
  • 导致阿拉伯语（从右到左）文本的最后一个字符被重复渲染的回归问题已解决。
