2.7 发行说明

发布日期：2026年4月16日

Cavalry 现已加入 Canva！：

Cavalry 于 2026 年 2 月加入了 的团队。作为其“让全世界都能设计”使命的一部分，Cavalry 中付费的“Professional”功能现已免费！

旧版用户仍可继续使用其 Scene Group 账户访问最高至 Cavalry 2.6.1 的版本。

使用 Canva 登录：

登录 Cavalry 现在需要 Canva 账户。

增强

  • Image Smart Folders 现在可以设置为忽略图像序列。使用资源窗口中出现的齿轮图标。
  • 新增 Help > Getting Started Guides 入门引导流程。
  • 移动整个图层片段时按住 Shift 现在会启用吸附。

重要缺陷修复

  • Style Behaviours 不再需要外部更改才能更新。
  • 当 路径偏移 用于复制器的输入图形时，更改现在会立即更新。
  • Pre-Comp 中的 四点变形 现在可按预期产生动画。
  • 如果图形的轴心位于另一个图形之上，轴心工具 现在会保持当前选择。
  • 当启用 Transform Only 运动模糊，或添加了 Filter 且合成中存在 摄像机 时，2d 图形现在能正确渲染。
  • 编辑图形工具 与 Transform tool 配合使用时，现在能正确处理非连续的点。
  • 重新排序 字符串数组 中某个多行索引时，不再触发崩溃。
  • 范围衰减 现在能正确处理 99.5 到 100 之间的 End 值。
  • 重新排序 字符串数组 的索引（其中某个索引设为多行）时，不再触发崩溃。
  • 已解决一个过度优化问题：连接了 Bevel Deformer 的图形更新无法即时生效。
  • 已解决一个问题：旋转后的 渐变着色器 无法为 Editable Shapes 正确渲染。
  • 已解决影响 衰减（Shape Type 设为 Shape）的内存问题。

说明

  • CLI 在 Cavalry 2.7 中不可用，因此如果你正在使用该功能，请继续使用当前版本。我们正努力在后续版本中恢复该功能。
