图像智能文件夹

简介

Image Smart Folder 可用于导入包含图像、视频或图像序列资源的文件夹，之后可通过外部数据或连接引用这些资源。

导入 Image Smart Folder：

  1. 在 资源窗口 中右键单击，然后选择 Import Image Smart Folder...
  2. 浏览到文件系统中的一个目录，然后单击 OK。

文件夹导入后，可与 Asset from Smart Folder Utility 配合使用。将 Image Smart Folder 从 资源窗口 拖入 场景窗口 或 视口 将创建并连接一个 Asset from Smart Folder Utility 和一个 素材图形：将 Asset from Smart Folder 的 Path 更新为图像相对于 Image Smart Folder 的位置，即可引用该图像。例如 path/to/image.jpg。

图像序列：

导入包含图像序列的文件夹时，每个序列都必须位于各自独立的文件夹中。

注意，任何以数字结尾的文件都可能被读取为图像序列，因此若需要使用名称相似的独立文件，请确保它们命名唯一，例如 image_one、image_two，而不是 image_1、image_2 等，或者将它们放在各自的文件夹中。

若要忽略图像序列，请单击 Image Smart Folder 资源行上的齿轮图标，并取消勾选 'Detect Sequences'。

示例：

  1. 导入一个包含 apple.png、orange.png 和 banana.png 文件的 Smart Folder。
  2. 将该 Smart Folder 从 资源窗口 拖入属性编辑器或视口。
  3. 创建一个 字符串数组。
  4. 使用 Add 按钮再添加两个索引，并在每个索引中分别填入 apple.png、orange.png 和 banana.png。
  5. 连接 stringArray.id→assetfromSmartFolder.path
  6. 取消勾选 Asset Array 上的 Auto Index，并在 Index 中输入 1。

图像应从苹果变为橙子。

尝试将 String Array 换成 电子表格，并将 渲染管理器 的 Dynamic Index 连接到它的 Index。

智能文件夹深度：

出于性能考虑，Smart Folder 的最大深度为 5 个目录。在下面的示例中，Level5 目录中的图像可以访问，而 Level6 目录中的图像则不能。

📁 Root

  ┠ 📁 Level1

  ┠ image.jpg

    ┠ 📁 Level2

    ┠ image.jpg

      ┠ 📁 Level3

      ┠ image.jpg

        ┠ 📁 Level4

        ┠ image.jpg

          ┠ 📁 Level5

          ┠ image.jpg

            ┠ 📁 Level6

            ┠ image.jpg
