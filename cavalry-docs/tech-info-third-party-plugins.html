第三方插件

简介

编写自定义着色器、滤镜和 JavaScript 图层，它们可以作为原生图层加载到 Cavalry 中。

创建产品：

Cavalry 会递归搜索“Third Party”目录，因此插件可以打包在任意目录中，但建议将每个“产品”发布在单个文件夹中，其中包含一个 strings/definition.json 文件。

一个产品可以是单个着色器，也可以是包含 10 个着色器的合集。请据此打包和分发每个产品。

安装

要安装第三方图层，请将插件的文件夹或该文件夹的 .zip 拖拽到 Cavalry 窗口的任意位置。

如果文件夹中的文件有效，会出现一个确认对话框。

这会将包含着色器/滤镜文件的文件夹添加到：

  • macOS：~/Library/Application Support/Cavalry/Third-Party/Plugins
  • Windows：C:\Users\<USER>\AppData\Roaming\Cavalry\Third-Party\Plugins

随后该图层即可在 Cavalry 中使用。

信息：

AppData 和 ~/Library 是隐藏文件夹。要找到它们：

  • Windows：在 Explorer 的 View options 中勾选“Hidden Items”。
  • macOS：在 Finder 中，打开 Go 菜单时按住 Option/Alt 即可显示 Library。

插件结构

第三方图层由多个文件组成。

📁 Layer


  ┠ definitions.json


  ┠ layer.sksl


  ┠ layerIcon.png


  ┠ layerIcon@2x.png


  ┠ setup.js


  ┠ strings.json


  ┠ welcome.js


  ┠ versioning.js

图层 SkSL 文件

该文件包含定义图层的 SkSL 代码。可以使用 Cavalry 的 API 模块中的 encryptFile 对这些文件进行加密。加密后的图层应使用扩展名 .skslc。

Definitions JSON 文件

该文件包含用于创建图层属性的信息，以及 UI 顺序、图标名称和其他有用信息。同一个文件中可以包含多个图层的定义。请参阅下方的示例。

作者

definitions.json 和 strings.json 文件都必须包含“author”键，作为图层创建者（例如公司名称）的标识符，该标识符在插件注册过程中内部使用。此标识符不得包含任何空格或句点（句号）字符，最好使用 camelCase 书写。

"author": "sceneGroup",

superTypes：

第三方图层的 superTypes 包括：

图层类型 SuperType 用途
Filter thirdPartyFilter 创建自定义滤镜。
Shader thirdPartyShader 创建自定义着色器。
JavaScript Utility thirdPartyJavaScript 生成值（数字、颜色、字符串）。
JavaScript Shape thirdPartyJavaScriptShape 创建自定义图形。
JavaScript Deformer thirdPartyJavaScriptDeformer 修改现有图形。

JavaScript 设置脚本

此可选脚本可用于在创建图层时执行额外的设置。例如，可以根据需要创建额外的图层和连接。运行此脚本时，会提供一个名为“setup”的模块，其中包含变量“layerId”。可以使用它访问正在创建的图层的 id。

节点字符串

strings.json 文件可用于包含：

  • Nice names：可以指定 niceName，以覆盖 definitions.json 中属性的名称。未指定 niceName 时，名为 camelCase 的属性会在 UI 中自动转换为 Camel Case。
  • Tooltips：添加悬停在属性上时显示的信息。

此文件必须包含 author 键。

不支持的功能：

请注意，目前尚不支持翻译。

图标

添加图标是可选的，但强烈建议这么做。默认图标的名称应通过 Definition Schema 设置。

图标类型 尺寸 后缀 示例名称
图层 18x18px layerIcon.png
图层（高分辨率屏幕） 36x36px @2x layerIcon@2x.png
属性编辑器 16x16px _ae layerIcon_ae.png
属性编辑器（高分辨率屏幕） 32x32px _ae@2x layerIcon_ae@2x.png

属性编辑器图标不常使用，但在某些情况下可能需要，例如 扭曲滤镜 的 Input Shader 下拉列表。

欢迎

可以包含一个可选的 welcome.js 文件，用于引导/欢迎新用户。使用 Script UI 创建一个“启动画面”，它会在安装成功后显示。

install.fromUpdate 可用于在更新插件时创建条件判断。

const process = install.fromUpdate ? `updated` : `installed`;


const label = new ui.Label(`You have ${process} the plugin.`);

版本管理

如果插件的文件夹中存在 versioning.js，则在打开任何包含该插件图层的场景时都会运行它。这可为拥有含旧版插件场景的用户提供向后兼容性。

versioning.js 可以通过插件模块访问两个成员变量：

  • layerId 例如 plugin.layerId
  • saveData 例如 plugin.saveData：saveData 是该图层在 .cv 文件中的数据副本，可用于访问属性数据。

编写图层

在 Definition 中添加属性时，这些值会自动作为 uniform 在图层中可用。请注意，并非所有属性类型都受支持。

添加以下代码行：

uniform float2 resolution;

……将其添加到着色器顶部，会让 Cavalry 将该 uniform 设置为正在渲染的图形尺寸。

支持子着色器，可以通过 setup 脚本创建，然后像 SkSL Shaders 那样在代码中采样。

子着色器应连接到着色器的 childShaders 属性（此属性会自动添加）。

支持多通道滤镜。

缺失插件

打开包含缺失插件的场景时，Cavalry 会创建该场景的副本。该副本会从场景中移除缺失的插件，因为目前用户无法通过 UI 修复此问题。

同时会出现警告对话框。要解决此问题，用户应安装缺失的插件，然后重新打开原始场景文件。
