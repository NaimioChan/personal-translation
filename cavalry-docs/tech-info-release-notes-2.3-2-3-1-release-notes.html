2.3.1 发行说明

发布日期：2025年1月8日

文件版本升级：

在 Cavalry 2.3 或更早版本中创建的场景，在 Cavalry 2.3.1 中打开时会被转换。文件会被复制为一个需要保存的新场景——打开时你会注意到旧场景被命名为 <yourSceneName> [Converted].cv。在 2.3.1 及之后版本中保存的任何场景都不会完全兼容 Cavalry 的以往版本。

新功能

脚本

API Module

  • getFileModifiedDate
  • getFileSize
  • loadSmartFolderAsset
  • encryptFile

Script UIs

  • setPopoverPreferredSide()
  • setAcceptsDrops()

常规

  • 编写第三方插件的技术预览。

增强

  • 声音 现在包含 Linear 频率刻度和 A-Weighting 属性。
  • 新增 Pressing Return in an Attribute Field 首选项，用于确定在字段内按下 Return 键时的行为。
  • 图像着色器 的 Tiling X/Y 现在默认设为 Clamp。
  • 预设：
    • 现在可为所有兼容的选中图层设置。
    • 为 Render Queue Item 保存预设时，现在可以选择是否包含 File Name 和 Path。
    • 现在可以通过右键单击 Scene Window 中的图层来应用预设。
  • 资源预览的改进意味着包含数百个图像资源的场景现在性能更好。
  • 现在可以复制 Assets Window 中分组的 Group Id。
  • 可以使用预设从 合成菜单 创建合成。
  • 透明合成背景的棋盘格已改进。

重要缺陷修复

  • 修复了 Forge Dynamics 的一个回归问题：Constraints 和 Collision Events 属性被替换成了 Auxiliary。
  • Mono 48000 Hz .mp3 文件导入时不再触发崩溃。
  • 已移除使用 api.createTimeMarker() 时的无害警告。
  • 修复了着色器缓存可能导致输出视频出现故障的问题。

说明

  • onAppStateChange 回调已弃用，并替换为 onAppStateChanged 以保持一致性。
