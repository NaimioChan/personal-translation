图像转图形

简介

通过对图像采样来创建图形。

界面

Common Attributes +

Image：连接图像资源。可以直接从资源窗口连接，也可以经由 资源数组 或 从智能文件夹获取资源 连接。

Mode：决定输出的图形类型：

  • Rectangles：输出矩形。
  • Circles：输出圆形。

Iterations：设置图像被采样的次数。数值越高，生成的图形越多，还原度越高。

Filter：这些设置可以提升视口和渲染中的图像质量，尤其是在调整图像大小时。

  • None (Fastest)：当速度最重要时使用。调整图像大小时不会执行重采样，这是质量最低的设置。
  • Bilinear：执行基础重采样。质量较低，但速度非常快。
  • Mipmaps：Mipmap 是通过双线性插值预先生成的、经过优化的低分辨率图像版本。缩小图像时，它们可用于获得最佳质量与性能。
  • Bicubic：这是最慢的方法，但在放大图像时能产生最佳质量。
