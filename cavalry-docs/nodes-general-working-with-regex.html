使用正则表达式

简介

正则表达式（简称 Regex）可用于 Cavalry 中的多种位置，包括正则表达式字符串操纵器、应用字体大小 等 Material/Style 行为，以及 JavaScript 图层。

正则表达式是用于指定搜索模式的字符序列。正则表达式的一个常见用途是匹配字符串或字符串中的部分内容，以便对结果进行后续处理。例如，表达式 a+ 会返回输入字符串中出现的所有字母 a。因此输入字符串 Cavalry 会返回 aa，因为它包含两个 a。

像 Regex101 这样的在线平台是学习和测试正则表达式的绝佳资源。

Regex 方言：

JavaScript 图层使用 ECMAScript 正则表达式。

文本和 Style 行为（应用字体、应用字体大小 等）使用 ICU 正则表达式，它支持用于不区分大小写匹配等选项的内联标志。

示例

与正则表达式字符串操纵器配合使用

正则表达式字符串操纵器只返回正则表达式的结果。

字符串 正则表达式 描述 结果
Hello World. \s 移除空格 HelloWorld.
As Capably as Cavalry. C.....y 以 C 开头、以 y 结尾的 7 个字母的单词 CapablyCavalry
Is it Colour or Color? Colou?r Colour 或 Color ColourColor
3 is the magic number. \d 任意数字 3

与 Style/Material 行为配合使用

Style 行为（应用字体、应用字体大小，以及 应用文本材质 等 Material 行为）会使用正则表达式的结果来影响字体、外观或字符间距。

字符串 图层 正则表达式 描述 结果
How are you today? 应用字体 \b(today)\b 返回单词“today”。 How are you today?
Animate in Cavalry 应用文本材质 \b(Cavalry)\b 返回单词“Cavalry” 单词 Cavalry 将用 Fill 着色

捕获组

捕获组是一种存储和提取被匹配字符串中特定部分的方式。将正则表达式的部分内容用括号包裹即可创建组，随后通过在 Capture Group Indices 属性中输入组的 Id 来筛选它们。

例如，对于字符串 hello@cavalry.studio，可以使用以下正则表达式分离名称、域名和顶级域名：\b(\w+)@(\w+)\.(\w+)\b。

这将保存捕获组，其索引如下：

索引 内容
1 hello
2 cavalry
3 studio

随后，通过在 Capture Group Indices 属性中输入组的 Id 即可使用这些捕获组。例如，在选择了粗体字体的 应用字体 中输入 2，结果会是：hello@scenegroup.co。另外，将 Capture Group Indices 设为 1,3，结果会是：hello@scenegroup.co。

输入值 0 或将 Capture Group Indices 属性留空，将返回完整匹配项。

内联标志

内联标志通过放置在表达式开头来改变正则引擎匹配模式的方式。所有 Style 和 Material 行为都支持这些标志。

标志 名称 描述 示例
(?i) 不区分大小写 不区分大小写进行匹配 (?i)hello 匹配 “Hello”、“HELLO”、“hello”
(?m) 多行 ^ 和 $ 在行边界处匹配，而不只是在字符串开头/结尾 (?m)^Line 匹配任意行首的 “Line”
(?s) Dot All . 除其他字符外也匹配换行符 (?s)a.b 匹配 “a”、换行、“b”
(?x) 注释 允许在模式中使用空白和注释以提高可读性 适用于复杂模式

标志可以组合使用：(?im) 同时启用不区分大小写和多行模式。

示例

字符串 正则表达式 结果
Typography is important. Good typography matters. (?i)(\btypography\b) Typography is important. Good typography matters.
