颜色窗口

简介

创建和管理 Library、Project、Label 和 Scene 调色板。

界面

要设置颜色，可以：

  • 移动色轮界面中的白色圆环。
  • 使用 Eye Dropper 图标拾取应用内的任意颜色。

生成的色块随后可以拖放到属性编辑器中的属性、视口中的图形，或下方的调色板窗口中。

也可以通过手动输入 Hex、RGB 或 HSV 数值来设置颜色：

  • Hex：输入十六进制颜色代码（例如 #4ffd7a）。
  • RGB：输入 RGB（红、绿、蓝）颜色（例如 79,253,122）。
  • HSV：输入 HSV（色相、饱和度、明度）颜色（例如 134, 68, 99）。

自动补全 Hex：

当十六进制代码包含重复的字符或数字序列时，会自动补全。例如，输入 AB 后按 Return，将得到 #ABABAB。

色板

使用顶部的子标签页加载不同类型的调色板。

使用右侧的图标在网格和列表布局之间切换视图。

添加色板

要添加色板，可以：

  • 将上方 Color Widget 中的色板拖放到调色板中。
  • 选中一个或多个图形，然后选择 Add Colors from Selection 选项。

在将色板从 Color Widget 拖入调色板时按住 Option/Alt，可以添加重复的颜色。

复制色板

要复制现有色板，请在网格视图中按住 Option/Alt 并拖动色板。

应用色板

要设置属性的颜色，可以：

  • 将色板的颜色块直接拖到视口中的某个 Shape 上，以设置其 Fill Color。
  • 在网格视图中，选中一个或多个图形时：
    • 单击色板可设置所选图形的 Fill 颜色（需要勾选 Fill）。
    • Option/Alt + 单击色板可启用所选图形的 Fill 并设置其颜色。
    • Shift + 单击色板可启用所选图形的 Stroke 并设置其颜色。
  • 使用列表视图中色板所在行上的按钮。请注意，如果尚未启用 Fill 或 Stroke，这些按钮会启用相应属性。
  • 将色板的颜色块拖到属性编辑器中的 Color 属性上。
  • 在属性编辑器中选中某个图层的 Color 属性后，单击色板的颜色块。

重命名色板

要重命名色板，请在列表视图中执行以下任一操作：

  • 双击一行。
  • 选中一行并按 Return。
  • 右键单击一行并选择 Rename。
  • 单击该行的省略号 选择 Rename。

调整色板顺序

在列表视图中，拖放色板所在的行即可调整色板顺序。

删除调色板

要删除调色板，请使用“选项”菜单中的 Delete Palette 菜单项，或者从“选项”中选择 Reveal in Finder/Explorer，然后在文件系统中删除 .pal 文件。

选项菜单

单击省略号

  • New Palette...：创建一个新的空白调色板。
  • Import...：导入现有调色板。Cavalry 支持导入 .pal、.ase（Adobe® Swatch Exchange）和 .theme 文件类型。
  • Save As...：保存调色板的一个版本。
  • Rename Palette...：重命名调色板。
  • Reveal in Finder/Explorer...：在文件系统中显示调色板所在位置。
  • Set Gradient from Palette：为选中的渐变属性设置色标，该属性位于属性编辑器中。通过选中图层本身，也可以用这种方式设置 多点渐变着色器，所创建的色标会根据合成分辨率随机定位。
  • Create Array from Palette：创建一个预先填充调色板中颜色的 颜色数组。
  • Clear Palette：从调色板中移除所有色板。
  • Delete Palette：移除调色板。请注意，这会从文件系统中删除调色板，且无法撤销。

网格视图

网格视图以网格布局将色板显示为单独的颜色块。

右键单击色板可显示以下选项：

  • Clear Palette：从调色板中移除所有色板。
  • Copy Hex Color Value：将色板的十六进制颜色值复制到剪贴板。
  • Paste Color：粘贴十六进制颜色或从 Color 属性复制的颜色。
  • Delete：从调色板中移除色板。

列表视图

列表视图会显示色板名称，并允许在调色板中对色板重新排序和重命名。

选项

使用省略号

  • Rename：重命名色板。
  • Set W3C Name：将色板重命名为使用 W3C 名称。

调色板

Library

Library 调色板是色板的集合，可用于为图形和其他图层指定颜色。

通过从顶部的下拉菜单中选择一个已保存的调色板来加载它。

Project

Project 调色板与 Library 调色板相同，只是它们保存在相对于项目的位置。默认情况下，该目录为 @project/Assets/Palettes/。保存在当前项目目录内的任何调色板都会显示在这里。

Scene

场景调色板中的色板可用于在图层之间创建共享连接。它们也会随场景一起保存。

场景调色板中的色板可用于连接多个颜色相同的图层。对色板的任何更改也会更新所有已连接的图层，也就是说只需在一个位置更改颜色。

连接场景色板

Grid View

  • 在网格视图中，将鼠标悬停在色板上，使用出现的连接锚点创建到任何具有 Color 属性的图层的连接。
  • 在列表视图中，使用色板颜色块左侧的连接锚点创建到任何具有 Color 属性的图层的连接。
选项

使用省略号

将 Library Palette 的色板拖入 Scene Palette 窗口，即可创建场景调色板色板。

  • Add Colors from Selection：根据所选图形的 Fill Color 创建色板。
  • Add Colors from Selection and Connect：根据所选图形的 Fill Color 创建色板，并将场景色板连接到每个所选图形。
  • Load from Library：将 Library 调色板中的色板添加到场景调色板。

Labels

Label 调色板可用于为图层、关键帧和时间标记着色，以便于组织管理。当前调色板可以“热切换”，也就是说可以随时为场景应用新的颜色主题。

如果在打开已保存的场景时正在使用其他调色板，则会加载随该场景保存的调色板。如果打开场景时使用的调色板在本地不存在，则会使用 Default 调色板。

设置图层的标签颜色

可以通过以下任一方式设置图层的标签颜色：

  • 在列表视图中，单击该行上的标签图标。在 Label 调色板中单击某个色板，会为所有选中的图层和/或关键帧设置标签颜色。

右键单击色板的颜色块/行，或者在列表视图中使用省略号

  • Select Layers with Color：选中活动合成中所有使用所选标签颜色的图层。

使用省略号

  • Reset Layers to Default Colors：将所有图层标签重置为默认颜色。可以通过编辑 .pal 文件中的 types 键来自定义默认值。

可以通过在 Default 调色板的空白处右键单击，并选择“Restore Default Palette”来恢复 Default 调色板。

界面底部的指示器会显示当前选中了多少个图层或关键帧，并在单击色板时更新。

Generator

基于当前主色生成调色板。

Color：选择生成调色板所使用的颜色模型：

  • RGB：使用 RGB 颜色模型生成颜色。
  • LAB：使用 LCh 颜色模型（也称 HCL）生成颜色。

Type：选择要生成的调色板类型：

  • Monochromatic：生成主色的不同深浅色调。
  • Analogous：生成色轮上相邻的颜色。
  • Complementary：生成位于色轮上与主色相对一侧的颜色。
  • Split Complementary：生成主色以及主色补色两侧相邻的两种颜色。
  • Triadic：生成在色轮上均匀分布的三种颜色。
  • Square：生成在色轮上均匀分布的四色。
  • Rectangular (Tetradic)：在色轮上生成与主色等距的 2 种颜色，以及它们的补色。
  • Circular：生成在色轮上均匀分布的颜色。
  • Golden Ratio：使用黄金比例创建调色板。这种调色板类型会避免颜色重复，相邻颜色始终不同。

Make Harmonic：勾选后，视觉上非常相似的颜色会被轻微调整，使它们更易区分。

Number of Colors：指定调色板包含的颜色数量。除 Split Complementary（6）、Triadic（6）和 Golden Ratio（20）外，Number of Colors 可设置为 2 到 8 之间的值。

Preview：调色板的预览。

Generate：单击以选择一个选项：

  • 保存调色板，以便在 Library Palette 中使用。
  • Set Gradient from Palette：在选中 渐变着色器 的渐变属性时，使用该调色板设置色标。
  • Create Color Array from Palette：使用该调色板创建 颜色数组。

信息：

Library、Project 和 Label 调色板也可以手动创建。有关调色板的格式和位置信息，请参见调色板页面。
