运动路径

简介

绘制并编辑表示所选动画图形方向和速度的路径。

运动路径可在视口设置中启用/禁用，最多会为 10 个所选图形显示。

外观

运动路径的信息密度可在视口设置中确定，选项包括显示帧、秒、关键帧以及路径及其方向。路径的长度也可以设置为表示一段时间。

最多可以同时显示 10 个所选图形。

交互

可以直接在视口中与运动路径交互。这与曲线编辑器中的交互方式以及编辑图形工具非常相似。

关键帧

移动关键帧

关键帧由菱形表示。

要在视口中移动关键帧，请在选择工具处于活动状态时：

  • 点击并拖动关键帧到新位置。

添加关键帧

要向运动路径添加新的关键帧，请在选择工具处于活动状态时：

  • 在视口中选中一个图形，按住 S 键并点击运动路径上的某一帧。

按住 S 期间，会显示新关键帧创建位置的预览。只要该帧上尚未存在关键帧，就会在该整数帧上创建新的关键帧。

删除关键帧

要从运动路径删除关键帧，请在选择工具处于活动状态时：

  • 选中一个关键帧并按 Delete 键。

插值

关键帧的控制柄决定图形在其父关键帧两侧的加速/减速。对于贝塞尔关键帧，控制柄显示为线条末端的小圆圈。注意，线性关键帧没有可见的控制柄。

要转换控制柄，请在选择工具处于活动状态时：

  • 按住 Option/Alt 并点击关键帧，可在贝塞尔/线性插值之间切换。
  • 按住 Option/Alt 并点击拖动关键帧，可在贝塞尔/线性插值之间切换并且编辑控制柄。

贝塞尔控制柄可以是联合的或断开的。联合控制柄也会移动与其相对的控制柄，而断开的控制柄则不会。

要设置控制柄的联合/断开状态：

  • 按住 Option/Alt 并点击拖动控制柄，可在联合和断开状态之间切换。
  • 按住 Option/Alt 并点击拖动控制柄，可在联合和断开状态之间切换并且移动它。

速度编辑

速度编辑是一种在保持运动路径形状的同时增大/减小图形速度的方法。

要编辑图形的速度，请在选择工具处于活动状态时：

  • 要编辑运动路径的速度，请拖动沿路径出现的小黄色箭头。
  • 要编辑运动路径的影响，请拖动远离路径出现的小黄色箭头（沿路径的法线方向）。
  • 按住 Option/Alt 会将更改镜像到关键帧的另一侧（如果存在）。

请确保在 Motion Path 视口设置中启用 Frames，以便可视化速度变化。

速度预设

可以通过视口将缓动预设应用到关键帧。点击运动路径上两个可见关键帧之间的部分，会弹出一个菜单：

内置速度预设

默认情况下，会以列表形式显示内置预设。点击其中一个，会将相应的速度预设应用到该段运动路径两侧的每个关键帧。与速度编辑一样，应用缓动时会保持运动路径的原始形状。

自定义速度预设

要保存自定义速度预设，请从列表中选择 Create Custom Preset...，然后在窗口中输入所需的值：

  • Preset Name：为速度预设输入名称。
  • Speed In：设置 0 到 2 之间的值，以确定图形从第一个关键帧开始时的速度，其中 0 表示非常慢的开始，2 表示非常快的开始。0 可以看作是曲线编辑器中水平控制柄的等价物。
  • Influence In：为第一个关键帧的控制柄设置 0 到 1 之间的长度，其中 0 表示零长度，1 表示最大长度。
  • Speed Out：设置 0 到 2 之间的值，以确定图形进入最后一个关键帧时的速度，其中 0 表示非常慢的结束，2 表示非常快的结束。0 可以看作是曲线编辑器中水平控制柄的等价物。
  • Influence Out：为最后一个关键帧的控制柄设置 0 到 1 之间的长度，其中 0 表示零长度，1 表示最大长度。

保存自定义预设后，点击运动路径时，它会出现在 Custom Presets 菜单项下。

管理自定义速度预设

保存一个或多个自定义速度预设后，可以对它们进行编辑和/或导出。要编辑自定义速度预设，请从列表中选择 Manage Custom Presets...，会弹出一个包含以下选项的窗口：

列表

使用每一行右侧的 ... 按钮来：

  • Rename：重命名速度预设。双击某一行也可以重命名。
  • Edit...：编辑速度预设。窗口中的选项与上文完全相同。点击 Save 提交更改。
  • Export...：将速度预设保存到文件系统。
  • Delete：移除速度预设。
按钮
  • Import：导入速度预设。
  • Export All...：将列表中的所有自定义速度预设导出到一个 .json 文件。参见设置默认速度预设。

设置默认速度预设

通过将Export All... 导出的 .json 文件保存到...

  • macOS：~/Library/Preferences/Cavalry/VelocityPresets/
  • Windows：C:\Users\<USER>\AppData\Local\Cavalry\VelocityPresets\

...其中包含的速度预设可用于通过首选项窗口中的 Default Velocity Presets 偏好设置填充菜单。

设置完成后，点击运动路径上两个可见关键帧之间的部分时，菜单顶部会填入该文件中包含的速度预设，并将“内置”预设降级到子菜单中。

当项目具有预定义的运动语言时，这有助于确保动画师团队之间的一致性。
