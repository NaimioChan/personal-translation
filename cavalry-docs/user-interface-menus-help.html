帮助菜单

About：打开关于窗口，其中包含当前 Cavalry 版本、电子邮件和许可证类型的信息。在 macOS 上，该窗口位于 Cavalry 菜单下。

Getting Started Guides：启动带有一系列入门提示的新手引导流程。

Documentation：查看文档。

Video Tutorials：在 Cavalry 的 YouTube 频道观看教程。

System Diagnostics：启动一个窗口以查看系统诊断信息。在排查问题时，这有助于在支持工单中分享。

Send Anonymised Analytics：允许 Cavalry 发送匿名分析数据，以帮助我们了解它的使用情况。

Send Anonymised Crash Reports：发生崩溃时，Cavalry 会向 sentry.io 发送匿名报告，帮助我们为后续版本的 Cavalry 解决问题。

Show Preferences Folder：在文件系统中打开存储首选项的目录。

Show Scripts Folder：在文件系统中打开存储脚本的目录。保存在此位置的任何脚本都会出现在 Scripts 菜单项下。更多信息请参阅脚本界面。

Show Plugins Folder：在文件系统中打开存储插件的目录。更多信息请参阅第三方插件。

Show Logs Folder：在文件系统中打开存储日志的目录。当被要求在支持工单中发送日志时，这会很有用。

View Account...：在浏览器中打开你的 Canva 账户。

Sign Out...：退出你的用户账户，这将打开 Sign In 窗口。
