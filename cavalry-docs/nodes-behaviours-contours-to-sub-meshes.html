轮廓转子网格

简介

将图形内的路径轮廓转换为子网格，以便可以单独操作每个轮廓。

此图层会转换图形的底层网格结构，在它之后添加其他支持子网格的行为之前，不会对图形产生可见影响。

界面

Keep Holes：勾选后，轮廓内的轮廓会被视为孔洞并“分组”。请注意，轮廓必须完全位于另一个轮廓之内，才能被可靠地视为孔洞。

示例：

  1. 使用钢笔工具绘制若干闭合轮廓。绘制过程中不要取消选择图形，以确保所有轮廓都绘制在同一个图形内。
  2. 点击可编辑图形 Deformers 属性的 + 按钮，选择 Contours to Sub-Meshes。
  3. 点击可编辑图形 Deformers 属性的 + 按钮，选择 Sub-Mesh。
  4. 进入子网格的 Fill 选项卡，勾选 Replace Fill。
  5. 右键点击子网格的 Color 属性 > Add Array > Color Array。
  6. 点击 Color Array 的 + Add 按钮两次，为数组再添加两个索引并设置一些颜色。

第一步中绘制的每个轮廓都会被应用 Color Array 中的一个颜色。
