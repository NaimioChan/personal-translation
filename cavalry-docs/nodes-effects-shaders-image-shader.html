图像着色器

简介

用于图像、图像序列和视频的着色器。

界面

通用属性 +

File：连接图像、图像序列或视频资源。可以直接从资源窗口连接，也可以通过资源数组或从智能文件夹获取资源连接。

Filter：这些设置可以提升视口和渲染中的图像质量，尤其是在调整图像大小时：

  • None (Fastest)：调整图像大小时不会进行任何重采样——这是质量最低的设置。
  • Bilinear：执行基本的重采样。质量较低，但速度非常快。
  • Mipmaps：Mipmap 是通过双线性插值预先计算、优化过的低分辨率图像版本。在缩小图像时，使用它们可以获得最佳的质量与性能。
  • Bicubic：这是最慢的方法，但在放大图像时可获得最佳质量。

Scale Mode：设置 File 如何适配图形的边界框：

  • None：不缩放。
  • Fit Contain：使 File 适配图形的边界框，确保整张图像始终可见。
  • Fit Width：使 File 的宽度适配图形边界框的宽度。
  • Fit Height：使 File 的高度适配图形边界框的高度。
  • Fit Cover：使 File 适配图形边界框的宽度或高度，从而在保持宽高比的同时填满图形。

Tiling：确定 File 边界处的处理方式：

  • Clamp：使用图像的首尾值。
  • Repeat：重复/循环图像。
  • Mirror：镜像/往复图像。
  • Decal：裁切图像。

Scale：增大/减小 File 的缩放。

Offset：偏移 File 的位置。

Rotation：旋转 File。

Looping：勾选后，图像序列、视频或 gif 将设置为无限循环。

Use Footage FPS：勾选后，将使用 File 的帧率，而不考虑父级合成的帧率。

FPS：设置图像序列的播放帧率。默认情况下，此控件连接到合成的帧率，但可以通过移除连接来手动设置。

Time：与合成 Time 的连接，用于驱动视频或图像序列的帧编号。

Missing Frames：确定图像序列中缺失帧的显示方式：

  • Noise：显示噪波图案。
  • Nearest Frame：显示最近的“已找到”帧。例如：
源 显示
image-00 image-00
missing image-00
missing image-03
image-03 image-03
image-04 image-04
  • Black：显示黑色帧。

Sequence Length：只读属性，以帧为单位返回 File 的时长。静态图像将输出 1。

Size：只读属性，返回 File 的分辨率。
