2.5.4 发行说明

发布日期：2025 年 12 月 1 日

重要错误修复

  • File > Import Asset... > Any Still 在存在图像序列时不再导入图像序列。
  • .mp4 和 .gif 在播放时不再卡顿。
  • 翻转图表属性现在会在两个轴上正确翻转图形。
  • 可能导致副显示器受影响的 DPI 问题已解决，该问题会在断开显示器、从睡眠中唤醒和/或将 Cavalry 在显示器之间移动时出现。
