工具栏

默认工作区中位于视口左侧的垂直窗口，包含视口的工具。

基础形状工具（Rectangle、Ellipse 等）的图标会根据其他设置而呈现略有不同的外观。

Create Editable Primitives

启用 Create Editable Primitives 后，工具栏中每个基础形状工具的图标上都会加上一个小小的 E。

此设置可从图形菜单或任意基础形状工具的设置中访问。

Quick Mask

双击 Pen、Pencil 或任意基础形状工具，其工具栏图标会变为黄色，表示该工具处于“Quick Mask”模式。在该模式下绘制会创建一个新图形，该图形将作为所选图形的剪贴蒙版。
