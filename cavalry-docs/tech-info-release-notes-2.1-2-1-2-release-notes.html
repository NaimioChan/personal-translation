2.1.2 版本说明

发布日期：2024年6月11日

2.1 版本说明→

文件版本升级：

在 Cavalry 2.1.1 或更早版本中创建的场景，在 Cavalry 2.1.2 中打开时会被转换。文件会被复制到一个新的场景中，需要保存——打开时你会注意到旧场景命名为 <yourSceneName> [Converted].cv。任何在 2.1.2 及之后版本保存的场景将无法完全兼容 Cavalry 的任何先前版本。

新功能

图形

提取子网格：通过从另一个图形中提取特定子网格来创建图形。

增强

  • 按住 Q 并在应用中任意位置拖动，现在也支持时间码。
  • 时间编辑器和曲线编辑器的右键菜单中新增 Select Attribute Keyframes。在场景树中选择一个属性，或点击属性的关键帧条，然后在时间编辑器中右键单击即可显示该选项。
  • 打开场景时通知缺失字体的模态窗口，现在只会列出每种字体一次，而不是为使用缺失字体的每个图层分别列出。
  • Create > Demo Scenes 中的示例现在会添加到新合成中，而不是活动合成。
  • 扭曲滤镜 新增了 Blend Mode 和 Opacity 属性。
  • 展平图形图层 新增 Maintain Transforms 属性。

重要错误修复

  • 修复了 辉光滤镜 在非居中对齐的Text Shapes以及轴心偏移的冻结图形上渲染不正确的问题。
  • 修复了导入 .cvc 可能触发崩溃的特定问题。
  • 修复了 时间轴计数器 的一处回归问题：Filter Marker Color 被忽略，且 Marker Color 界面未正确更新。
  • 修复了在从睡眠模式唤醒的第二显示屏上运行 Cavalry 时偶发崩溃的问题。
  • Create > Demo Scenes > JavaScript > Closest Point 示例现在重新可用——这是 API 的问题。
  • 修复了 挤出 同时使用 Combine Meshes 和 移动变形器 时的崩溃。
