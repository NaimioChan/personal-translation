拖尾

简介

根据其他图形的运动生成拖尾（线条）。

实验性功能：

这是一项实验性功能。要启用它，请在偏好设置中勾选 Enable Experimental Features。

界面

Shape

通用属性 +

Input Shapes：连接一个或多个图形以生成拖尾。

Limit Length：勾选后，拖尾的长度将限制为最大 Length 值。

Length：设置拖尾的最大长度。注意：当 Limit Length 未勾选时，此项不可用。

Start Frame：设置拖尾开始出现的第一帧。

Path Type：选择曲线类型：

  • Béziers：拖尾将创建为贝塞尔曲线。
  • Lines：拖尾将创建为多边形折线。

Time Offset：偏移添加到拖尾上的任何动画的时间。例如，如果将一个振荡器连接到描边的 Width，则可以将一个交错连接到 Time Offset，以偏移每条拖尾的动画。

Stroke

通用属性 +

Use Particle Color：勾选后，拖尾会从用作 Input Shape 的粒子图形继承颜色。

Advanced

通用属性 +

Use Index Context：勾选后，拖尾会获取上下文。这可用于控制 Id 的分配方式，从而单独影响每条拖尾——例如，向拖尾图形的 Stroke Color 添加一个颜色数组。

示例：

  1. 创建一个图形。
  2. 选中该图形，点击复制器图标（位于工具架中）。
  3. 在属性编辑器中，右键点击复制器的 Shape Position 属性，然后选择 Add Behaviour > Noise。
  4. 打开 Noise 的属性编辑器界面。
  5. 将 Strength 增大到例如 500。
  6. 创建一个拖尾图形。
  7. 连接 duplicator.id→trails.inputShapes
  8. 隐藏复制器。
  9. 按下播放。
