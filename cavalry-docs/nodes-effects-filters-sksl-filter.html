SkSL 滤镜

简介

使用 SkSL（“Skia Shading Language”）编写自定义滤镜。

SkSL（“Skia Shading Language”）是 GLSL 的一个变体，被用作 Skia 的内部着色语言。经过一些小的修改，来自 https://www.shadertoy.com/ 等网站的 GLSL 代码即可转换后在 Cavalry 中使用。

有关 GLSL 与 SkSL 之间差异的更多细节，请参阅 Skia 文档。

整数 Uniform：

SkSL 滤镜不接受整数 uniform，请改用浮点数。

界面

Blend Mode：参见混合模式。

Filter Code：在此处编写/粘贴/编辑 SkSL 代码。

Padding：当滤镜产生的像素超出原始图形的边界时，可用此项扩展边界。

Inputs：点击 + 按钮选择一种 uniform 类型并添加一个。右键点击某个属性并选择 Rename... 可重命名 uniform。之后该名称即可在 Filter Code 中作为变量使用。

导出为插件

点击 Export to Plugin... 会打开一个导出窗口，可用于将图层导出为插件。

Author：设置用于填充 definitions.json 中 "author" 键的字符串。此字段会在会话之间保留。

Plugin Name：设置用于填充 strings.json 中 "niceName" 键的字符串

Encrypt：勾选后，导出的文件将被加密。

Export...：点击 Export 选择文件的导出位置。Author 和 Plugin Name 字段为必填项。

注意：

请注意，可能需要对导出的文件进行一些调整。例如，可能需要添加图标、工具提示等。

内置 Uniform

可以将内置 Uniform 添加到 Filter Code：

必需

  • layer：对此着色器对象调用 eval(float2) 以采样图形。uniform shader layer; 必须包含在滤镜代码的开头。

可选

  • resolution：正在渲染的图形尺寸，可用于制作随内容缩放的滤镜。参见 Create > Demo Scenes > Custom Shaders and Filters > Emboss Filter 中的示例。

示例：

参见 Create > Demo Scenes > Custom Shaders and Filters > 中的以下示例：

  • Emboss Filter
  • Green Screen Filter
  • Scatter Filter

示例：

  1. 创建一个 Rectangle。
  2. 创建一个 SkSL 滤镜。
  3. 将以下内容粘贴到 Filter Code 中：
uniform shader layer;



half random(half2 co) {

    return fract(sin(dot(co, half2(12.9898, 78.233))) * 43758.5453);

}



half2 randomOffset(half2 p) {

    half angle = random(p) * 6.283185;

    half radius = random(p + half2(1.0, 1.0)) * n0;

    return half2(cos(angle) * radius, sin(angle) * radius);

}



half4 main(float2 p) {

    half2 baseOffset = randomOffset(p);

    return layer.eval(p + baseOffset);

}
  1. 连接 skslFilter.id→rectangle.filters
  2. 增大 SkSL 滤镜的 n0 和 Padding 属性。

这将创建一个散布效果
