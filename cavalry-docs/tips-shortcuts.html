快捷键

简介

一份并不详尽的快捷键（又称热键）列表。可以使用 快捷键管理器 自定义大多数快捷键/热键。

快捷键

应用程序全局快捷键：

快捷键 描述
Cmd/Ctrl + .（句点/句号） 打开 Quick Add 窗口
Option/Alt + P 打开 项目设置 窗口
Cmd/Ctrl + Z 撤销
Cmd/Ctrl + Shift + Z 重做
B 设置播放起始帧
N 设置播放结束帧
V 选择工具
T 文本工具
A 编辑图形工具
Shift + T 设置位置关键帧。
Cmd/Ctrl + Option/Alt + ⮕ 移动到下一个关键帧
Cmd/Ctrl + Option/Alt + ⬅︎ 移动到上一个关键帧
;（分号） 播放/停止
Space 播放/停止
Q 通过左右拖拽擦洗帧
Cmd/Ctrl + P 建立父子关系
Cmd/Ctrl + Shift + P 取消父子关系
Escape 取消渲染
Cmd/Ctrl + Option/Alt + U 将所选内容加载到属性编辑器
= 将关键帧向前移动 1 帧
- 将关键帧向后移动 1 帧
+ 将关键帧向前移动 5 帧
_（下划线） 将关键帧向后移动 5 帧

逐帧步进

步进的帧数由 合成设置 中的 Playback Step 设置控制。默认为 1。使用 Shift 修饰键会将此数值乘以 5。

快捷键 描述
Cmd/Ctrl + ⮕ 向前移动 1 帧。
Cmd/Ctrl + ⬅︎ 向后移动 1 帧
Cmd/Ctrl + Shift + ⮕ 向前移动 5 帧
Cmd/Ctrl + Shift + ⬅︎ 向后移动 5 帧

时间编辑器

快捷键 描述
Return 或 F2 重命名图层。
[ 将可见性条范围的起点设为当前帧。
] 将可见性条范围的终点设为当前帧。
Option/Alt + [ 将可见性条起点裁剪到当前帧。
Option/Alt + ] 将可见性条终点裁剪到当前帧。
