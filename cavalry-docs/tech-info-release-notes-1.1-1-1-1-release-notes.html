1.1.1 版本说明

概要

这是一个补丁版本，用于解决在 Cavalry 1.1 中发现/引入的问题。

新增元素/功能

可见性序列 新增 Always On 和 Always Off 属性。

常规增强/重要修复

  • 修复了资源窗口中的一个问题：在整理资源时，Groups 会意外打开/关闭。
  • 提高了使用滤镜时的播放速度。
  • 在 macOS 上使用新的默认 Use Native Encoder 选项时，Export to Quicktime 会忽略第一帧。
  • 调整资源大小时的光栅图像质量现在有所改善。请参阅图像着色器上新的 Filter 属性。
  • 直接从文件系统将视频素材拖入视口时会失败。
  • 3D 矩阵 的 Level Mode 现在支持衰减。
