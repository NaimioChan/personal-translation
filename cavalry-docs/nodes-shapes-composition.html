合成

简介

用于合成图层的舞台。

要创建 Composition，可以：

  • 点击 资源窗口。
  • 在 资源窗口 中拖动一个资源，并将其放到 上。
  • 通过 Composition > New Composition 菜单。

要打开 Composition，请在 资源窗口 中双击一个 Composition。

预设：

使用预设为新 Composition 设置自定义默认值（分辨率、帧率等）。

可以同时打开多个 Composition，但只能将其中一个设为活动 Composition。使用场景窗口顶部出现的选项卡在已打开的 Composition 之间切换。

界面

要加载 Composition 的界面，请将其从 资源窗口 拖入属性编辑器。

Common Attributes +

Composition 设置：

使用这些属性可以为 Composition 设置动画或影响其外观。要调整 Resolution 或 Frame Rate 等设置，请参见合成设置。

Pre-Comp

作为图层用在另一个 Composition 中的 Composition 也称为 Pre-Comp。可以将多个 Pre-Comp 添加到另一个 Composition，以此创建只有一个“真相来源”的副本——对原始 Composition 所做的任何更改都会传播到它的所有 Pre-Comp。

创建 Pre-Comp

要创建 Pre-Comp，可以：

  • 从 资源窗口 中将一个 Composition 拖入视口或场景树中的另一个 Composition。
  • 在现有 Composition 中选择多个图层，然后：
    • 右键单击 > Pre-Compose Selection。
    • 使用 Composition > Pre-Compose 菜单。

要了解把 Composition 用作可编辑“模板”的方法，请参见 预合成覆盖。

如果 Composition 中已存在某个 Pre-Comp，可以将其引用替换为 资源窗口 中的另一个 Composition。为此，可以：

  • 按住 Option/Alt，从 资源窗口 拖动一个 Composition，并将其放到 场景窗口中该 Pre-Comp 所在的行上；或
  • 在 场景窗口中选择多个 Pre-Comp，然后按住 Option/Alt，从 资源窗口 拖动一个 Composition 并将其放入场景窗口。

将 Pre-Comp 从场景树拖入属性编辑器将显示以下属性：

Artboard - 勾选后，Pre-Comp 的子图层不会被其边界遮罩，其 Background 也不会被渲染。

Preserve Frame Rate - 勾选后，Pre-Comp 将保持其帧率。例如，当一个 12fps 的 Composition 作为 Pre-Comp 位于 24fps 的 Composition 中时，勾选 Preserve FPS 可确保 Pre-Comp 以 12fps 播放。取消勾选时，Cavalry 会重新插值 Pre-Comp 的帧率，以匹配其父级的 24fps 帧率。

将 Pre-Comp 设为活动 Composition：

点击 Open 按钮，或按住 Option/Alt + Cmd/Ctrl 并双击场景窗口中某个 Composition 图层的行，都将打开该 Composition（使其成为活动 Composition）。

注意：

创建新 Composition 的唯一方式是通过 资源窗口 或菜单。无法通过 添加图层窗口 创建。
