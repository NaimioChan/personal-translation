网格工具

简介

通过添加控制顶点来创建网格，这些顶点可用于变形栅格图形（图像）和/或其他着色器。

支持：

网格工具仅支持与网格图形配合使用。

界面

添加顶点

选中网格图形后，按住 Option/Alt 并单击该图形。

继续保持按住 Option/Alt 并单击，可创建更多顶点及连接边。

编辑顶点

顶点有两个位置：Bind 和 Offset。更多信息请参阅网格图形（Mesh 选项卡）。

按住 Option/Alt 并单击拖拽顶点，可移动其 Bind Position。

单击并拖拽顶点可移动其 Offset Position。同时会出现一个“幽灵”顶点，指示其 Bind Position。

按住 Option/Alt 时，顶点将在视口中返回其 Bind Position。这相当于取消勾选网格图形的 Mesh 复选框。

创建边

网格内三角形的方向可通过以下方式自定义：

  1. 按住 Shift。
  2. 单击一个顶点。
  3. 拖拽到另一个顶点并释放鼠标。

这对于优化最终的变形效果很有用。例如，当添加了 4 个独立顶点构成一个矩形时，该矩形会沿对角线拆分为两个三角形。按上述步骤操作，即可让拆分线连接另外两个顶点。

选项

在视口中右键单击顶点，然后从以下选项中选择：

  • Control with Null(s)：创建 Null 并将其连接到选中的顶点。
  • Set Keyframe：为选中的顶点设置 Offset Position 关键帧。
  • Delete Vertex：删除选中的顶点。

热键

快捷键 说明
Option/Alt 添加顶点。
Shift 绘制/连接边。
S + 单击 + 拖拽 增加/减小软选择大小。

工具设置

有关此工具可用的特定于上下文的选项，请参阅工具设置。

示例：

  1. 将图像导入到资源窗口。
  2. 右键单击图像，选择 Add to Composition as Mesh。
  3. 启用网格工具。
  4. 单击网格图形以确保其被选中。
  5. 按住 Option/Alt 并单击网格图形的中心以创建顶点。
  6. 释放 Option/Alt，然后单击并拖拽该顶点。
