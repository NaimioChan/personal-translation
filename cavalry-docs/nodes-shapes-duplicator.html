复制器

简介

Duplicator 可用于复制和分布图形，以创建网格、圆形及其他图案。

界面

Shape

Common Attributes +

Input Shapes - 连接要复制的图形。参见 Input List。

Distribution - 决定副本的布局。参见 Distribution Types。

Shape Position - 按每个副本单独设置位置。

Shape Rotation - 按每个副本单独设置旋转。

Shape Scale - 按每个副本单独设置缩放。

Shape Visibility - 按每个副本单独设置可见性。

Shape Opacity - 按每个副本单独设置不透明度。

Auto Id - 自动循环使用 Input Shapes 列表中的所有 Id。

Shape Id - 设置要分布的 Input Shape(s) 的 Id。0 是第一个 Id。

Shape Time Offset - 按每个图形单独偏移副本的动画曲线。提示：连接一个 Stagger 行为。

提示：

将 Stagger 行为与 Shape Time Offset 一起使用时，可以使用负的 Minimum 值来确保动画从第 0 帧开始。例如，将 Minimum 设为 -50，即可在 50 帧内偏移动画。

Advanced

Common Attributes +

Use Index Context - 勾选后，Duplicator 将读取上下文。当 Duplicator 作为另一个 Duplicator 的 Input Shape 时，可用于控制 Id 的分配方式。

Index Context - 将此输出连接到另一个图层，将按相应的“上游深度”输出每个副本的索引。更多信息请参见上下文。

Skip Invisible Duplicates - 勾选后，被 Shape Visibility 隐藏的任何副本的网格也会被移除。这还会影响 Duplicator 的边界框，可用于优化较重的场景。

Input Shape - 变换：

为避免图形作为 Duplicator 的一部分时未出现在预期位置所可能造成的困惑，Input Shape 的变换信息会被忽略。“变换信息”包括任何图形的 Position、Rotation、Scale、Skew 和 Pivot 属性。

当 Position 为 100,100 的图形作为 Duplicator 的 Input Shape 连接时，该位置将被忽略并重置为 0,0。结果是每个副本都位于各个分布点的同一位置，而不是按其 100,100 的位置偏移。这样设计是为了避免意外添加偏移可能带来的困惑。

这仅适用于父级图形，图形的任何子级的变换信息都会被保留。可以利用层级结构来覆盖内置的功能。在下面的示例中，Group 作为 Duplicator 的 Input Shape 连接，而 Shape 是 Group 的子级。在这种情况下，Shape 的 Position 100,100 会被传递，从而使每个副本相对于 Duplicator 的点偏移该数值。Group 仍位于 0,0，但 Shape 在 Group 中的位置会被保留。

  • Group - 变换被忽略。
    • Shape - 变换被保留。

此技巧还可用于将任何变换动画传递给 Duplicator。通过将一个有动画的图形添加到 Group，再将该 Group 添加到 Duplicator，Group 将被定位在一个点上，而 Shape 随后会在 Group 内移动。
