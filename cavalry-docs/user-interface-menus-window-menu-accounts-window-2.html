账户窗口

旧版：

本页仅适用于 Cavalry 2.6.1 及更早版本。

账户窗口可用于查看并管理 Cavalry 账户以及任何已连接的账户。

个人资料

点击个人资料图标将打开当前已登录的 Cavalry 账户。

将光标悬停在图标上，会显示当前已登录的电子邮箱账户及其许可类别和状态。

已连接账户

可以将其他平台（例如 Canva）连接到你的 Cavalry 账户。连接处于活动状态时，该图标的状态会由灰色变为绿色。

点击图标将根据连接状态显示菜单：

未连接：

  • Link [platform] Account...：打开 Cavalry 账户，并按步骤连接某个平台。

已连接：

  • Go to [platform]...：打开该平台的网站。

退出登录：

要使用其他邮箱登录，请转到 Help > Sign Out... 退出登录，随后会打开登录窗口。
