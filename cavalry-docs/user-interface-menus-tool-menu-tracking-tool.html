跟踪工具

简介

跟踪视频素材中的平面，并使用边角定位图形在其上叠加图形/动画。

这适用于屏幕替换等任务。

跟踪完全自动化，素材可以正向或反向跟踪，这意味着可以从任意帧开始。

信息：

包含跟踪标记、且遮挡尽可能少且短暂的平面能获得最佳效果。当默认的‘Balanced’模式无法得到良好的跟踪结果时，像‘Edge Snap’和‘Robust’这样的预设可能有助于跟踪低质量素材。

界面

参见工具设置。

工作流程

  1. 将一些素材导入到资源窗口。
  2. 将视频/图像序列资源从资源窗口拖入视口。
  3. 前往 Tool > Tracking 启用该工具。
  4. 在场景窗口中选择素材图形。
  5. 在要跟踪的设备/广告牌的每个角上放置 4 个跟踪标记。单击并拖拽即可放置，所有标记放置完成后仍可重新调整它们的位置。
  6. 点击工具设置窗口中的‘Track’。
  7. 创建一个矩形，并为其添加棋盘格着色器。
  8. 选中矩形后，点击工具设置窗口中的‘Apply’，并选择相关的跟踪数据（其名称将基于素材图形）。

这将创建一个边角定位图形并将其连接到矩形，同时把跟踪数据分配给该边角定位图形的各个空对象。
