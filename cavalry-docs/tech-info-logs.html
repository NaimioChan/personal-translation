日志

Cavalry 会在结束会话时（例如关闭 Cavalry）保存日志。这些日志在尝试调试问题时有时会很有用。

完整的会话日志位于：

  • macOS：~/Library/Application Support/Cavalry/logs
  • Windows：C:\Users\<USER>\AppData\Roaming\Cavalry\logs

信息：

AppData 和 ~/Library 是隐藏文件夹。要找到它们：

  • Windows：在 Explorer 的 View options 中勾选“Hidden Items”。
  • macOS：在 Finder 中，打开 Go 菜单时按住 Option/Alt 即可显示 Library。
