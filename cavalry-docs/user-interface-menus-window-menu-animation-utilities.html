动画工具

简介

一组实用的工具命令。

界面

Bake Animation：此命令会提取所有所选动画曲线，并根据所选的精度设置（Low、Medium 或 High）尝试简化它们。设置越高，形状越精确，但会生成更多关键帧。

Snap Selected to Current Frame：将所有所选关键帧吸附到当前帧。

Reverse Animation：反转所选属性/关键帧的动画曲线。在场景窗口中选择属性或关键帧，然后点击按钮。

Reset Transform Attributes：重置一个或多个图形的 Position、Rotation、Scale 和 Pivot 属性。选择一个或多个图形，然后点击按钮。

Crop Animation to Selected Keys：删除所有未选中的关键帧。选择若干关键帧并点击按钮。此命令只会影响包含所选关键帧的属性。

Delete Animation for Element：删除所选 Element 的全部动画。

Nudge Value：增加/减少所选关键帧的值。设置一个 +/- 数值并点击 Go!

Nudge Frame：增加/减少所选关键帧的帧数。设置一个 +/- 数值并点击 Go!
