2.6 发行说明

发布日期：2026年2月4日

新功能

常规

  • Editable Motion Paths：在视口中操纵运动路径。
  • 为场景启用 Color Management。见色彩管理。
  • 轴心工具：新增的操纵器和可编辑运动路径意味着需要一个新工具来编辑轴心。注意，这取代了此前使用选择工具时的工作流程。
  • Manipulator：为选择工具新增的类 3D 视口操纵器。它与新的 Lattice 和 晶格控制器 配合使用，也可以选择为图形图层启用。
  • 文件 > Reduce Scene：从场景中移除所有未使用的合成和资源。
  • 新增 Systems Diagnostics 窗口，可通过帮助菜单打开。它可用于帮助调试问题，并在排查故障时在支持工单中分享有用信息。

图形

  • Rectangle Pattern Shape：该图层已从实验性功能转为正式功能。见增强。

行为

  • Lattice：使用灵活的控制点网格变形图形。
  • 四点变形：使用带贝塞尔手柄的四角变形来变形图形。
  • 路径松弛：使路径点彼此远离。
  • 路径平均：通过对路径点的位置取平均值来平滑路径。
  • 网格求解器：连接变形器，以创建绘画机器或差分生长之类的迭代效果。

工具

  • 晶格控制器：操纵多个晶格点的位置、旋转和缩放。
  • Forge Dynamics：
    • 浮力场：创建流体容器，动态刚体将根据其密度在其中漂浮或下沉。
    • 路径场：为动力学刚体施加路径跟随力。
    • 旋涡场：施加螺旋力，使动力学刚体绕中心点旋转。
  • Block String Generator：创建文本块，并可选择使用行为来填充段落、行、单词和字符。
  • Unicode 偏移字符串操纵器：按 Unicode 码点偏移字符串中的字符。

效果

  • 边缘扭曲滤镜：使用着色器扭曲图形的边缘。

脚本

API

  • isReferenced()
  • getActiveTool() + 回调

Cavalry

  • setChildMeshAtIndex()

Deformer

  • getRootMesh()
  • setRootMesh()
  • getFalloffAtPoint()
  • meshDepth

Script UIs

  • 新增 onAttrConnected 和 onAttrDisconnected 应用回调。
  • 新增 onToolChanged 回调。
  • 新增 List 控件。

增强

  • 性能改进：一些复杂场景的播放速度现在最高提升 5 倍。
  • 滤镜新增 Matte 标签页，允许使用其他图形作为滤镜效果的遮罩。
  • 将一个图形拖到另一个图形上时，按住 Shift 会重置子级的变换，使其“吸附”到父级的位置、旋转和缩放。
  • 视口中的运动路径选项已移至专用按钮。
  • 绳结 行为新增 Geometric 模式，可用于模拟。
  • 自动动画 新增 Align Animation 选项，扩展了原先的 Offset by In Frame。
  • 在动画开始/结束处添加关键帧时，生成的贝塞尔手柄已得到改进。
  • ui.Modal() 现在可在普通 UI 脚本之外使用。
  • Filter 蒙版新增 Apply Mode。
  • 正则表达式支持内联标志。
  • ui.ColorPalette() 现在会为带 alpha 的十六进制颜色渲染棋盘格。
  • 16 位视口。可通过偏好设置设置。
  • 图像着色器 新增 Rotation 属性。
  • Gradient along a Path 现在支持锥形描边。
  • Inner Shadow 滤镜新增 Spread 属性。
  • 子网格 现在可以通过将轴心对齐到子网格的边界框来定位轴心。
  • Playback Caching 改进：
    • 如果可用内存过低，缓存会中止。
    • 缓存现在会在时间轴中以紫色条表示。
    • 拖动时间轴时会使用缓存。
    • 内存占用减少约 85%。
  • 表示 Array 索引的数字背景界面现在会动态调整大小，以适配最高索引的位数。它现在还支持 UI Font Size = Large 偏好设置。
  • Cavalry 的 JavaScript 引擎已升级至 V8 12.4，新增对 ECMAScript 2024 特性的支持，包括 Array.fromAsync、Set 方法（union、intersection、difference）以及迭代器辅助方法。
  • 依赖关系图：
    • Backdrops：创建一个容器，以在视觉上对多个图层进行分组并一起移动。
    • Wire Styles：设置图层端口之间连接线的样式。
    • Mini-Map：显示/隐藏窗口的迷你地图，可用于在图中导航。
    • Bookmarks：保存当前图视图。
    • 显示/隐藏网格：显示/隐藏背景网格。
  • Forge Dynamics：
    • 可破坏约束新增多种模式。
    • 固定约束 新增 Tension 和 Damping。
    • 新增 Complex Polygon 碰撞形状类型，带来凹形支持。
    • 新增 Soft Body 碰撞形状类型。
    • Collision Groups：通过输入逗号分隔的字符串（例如 text, rocks）来分配碰撞组，以筛选场对各个刚体的影响，或刚体与其他刚体的交互方式。
  • 细分 新增 Threshold 属性。
  • 倒角 新增 Radius Mode 和 Minimum/Maximum Angle 属性。
  • Color Names：现在可以将当前库调色板和任意项目调色板的名称输入十六进制字段，让这些标签解析为对应的十六进制值。
  • Rectangle Pattern Shape 新增 Orientation 属性。注意，Bar Size 也已更名为 Dynamic Bar Size。
  • Bulge 和 Spherise 滤镜新增 Sampling Quality。
  • 对视口渲染和滤镜的整体改进。
  • 延长开放路径 新增 Arc 角度模式。
  • Graph 属性新增自定义预设。
  • 渐变着色器、多点渐变着色器 和 渐变映射滤镜 新增 Oklab 和 LCH 插值。
  • 在 macOS 上导入 MP4 文件现在使用硬件加速。

重要缺陷修复

  • 一个 macOS 问题（终于！）已解决：双击 .cv 文件会打开 Cavalry，但不会加载场景。
  • 在场景树中使用 +/- 热键微调 Footage Shape（带音频的视频）或 Sound 行为时，现在会同时影响帧偏移和片段。
  • 已解决导致富文本编辑无法随场景保存的问题。
  • 已解决一个回归问题：经过对齐的图形的 拖尾 位置受到影响。
  • 已解决影响通过场景树替换列表中第一个变形器的问题。
  • 已解决多个回调未触发的问题。
  • 导出到 Lottie 时，多个资源现在会按预期复制到 images/ 目录。
  • Cmd/Ctrl + F 现在会适配曲线编辑器中所有可见的动画曲线。
  • 延长开放路径 在 Angle Mode 设为 Path Curvature 时现在能正确工作。
  • 当 Angle Mode 设为 Arc 时，禁用 延长开放路径 的起始/结束现在能正确工作。
  • 修复了视口剪切蒙版预览绘制位置错误的问题。
  • 使用正则表达式处理西里尔字符时导致的崩溃已解决。
  • 现在可以导入同时也被已导入的引用使用的资源。
  • 取消勾选 挤出 的 Combine Meshes 相关崩溃已解决。
  • 已解决 摄像机引导 视口绘制的问题。
  • 应用文本材质 现在恢复正常工作。
  • 将 路径引导 连接到图形的位置属性时不再导致崩溃。
  • 为一个图形添加 4 个 Inner Shadow 滤镜不再导致该图形消失。
  • 使用 Option/Alt + 拖动来复制渐变的色标时不再触发崩溃。
  • 在 Live Mode 激活时使用 Add Layers 弹出窗口，不再出现“幽灵”窗口。
  • 已解决 展平图形图层 在特定情况下隐藏材质的问题。
  • 已解决一个回归问题：当首尾关键帧值相同时，曲线编辑器无法预览循环动画曲线。
  • Reveal Composition in Assets Window 现在会在相关合成位于某个父级资源组中时打开该资源组。
  • 已解决与“特定索引”以及将 Text Backgrounds 与 Style Behaviours 混用相关的多个问题。
  • 导入场景或引用时不再包含 Render Queue Items。这些项此前会在场景窗口中显示为“孤立”图层。
  • 更新 Spreadsheet Utility 的 Excel Sheet 时，Row Count 和 Column Count 现在也会更新。
  • 当连接了 Field 时，Forge Dynamics 不再在播放期间向终端输出调试信息。
  • 从 Add Layers 弹窗（Cmd/Ctrl + .）拖放图层的功能已恢复。
  • 重命名标签被省略（...）的图层现在可按预期工作。
  • Array 图层的属性编辑器界面不再在光标跨窗口移动时改变其垂直位置。
  • ColorPalette 填充 UI 宽度的方式已改进。

说明

  • Create Editable Primitives 菜单项已从图形菜单移至创建菜单。
  • Forge Dynamics：对包含子网格的图形（例如文本）的“尺寸”计算有误，导致其 Density 不正确。此问题已修正，但被视作缺陷，因此未添加向后兼容。旧场景可能需要调整 Density 值。
  • 合成设置中已移除 Linear Gamma 选项，着色器中已移除 Color Filter 选项。如果此前使用了这些选项，那么在偏好设置中启用 Color Management 并将 Working Color Space 设为 Linear sRGB，即可与旧设置保持一致。着色器会自动遵循工作色彩空间。

Web Player

  • Web Player（beta）已更新，以支持 Cavalry 2.6。
