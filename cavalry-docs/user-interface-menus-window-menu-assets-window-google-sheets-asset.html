Google 表格资源

简介

Google 表格资源可用作电子表格工具的输入。从 Google 表格导入数据意味着任何人都可以在任何地点的浏览器中编辑数据，并在 Cavalry 中即时更新。

Google 表格 URL

复制 Google 表格 URL 的方式有以下两种：

  • 直接从浏览器标签页的地址栏/多功能框复制到剪贴板。
  • 使用 Share 选项中的 Copy Link 按钮复制到剪贴板。注意，如果电子表格中包含多个工作表/标签页，此方法只会复制主工作表的 URL。默认情况下，该工作表的 URL 以 gid=0 结尾，但如果该工作表已被删除，则会使用最近创建的工作表。如有疑问，请改为从浏览器标签页的地址栏/多功能框复制 URL。

引用工作表

要引用特定的工作表/标签页，请在该工作表/标签页打开或处于活动状态时，从浏览器地址栏/多功能框复制 url。

权限：

通过 Share 按钮提供的 Link Sharing 选项必须设为 Anyone with the link。Role 可设为任意可用选项。

目前尚无法访问权限受限的表格。

导入

导入表格：

  1. 执行以下任一操作：
    • 在资源窗口中右键单击，然后选择 Import Google Sheet...
    • 使用 File > Import Google Sheet... 菜单项。
  2. 在对话框中输入表格的 url。
  3. 点击 OK。

Google Sheet Asset将出现在资源窗口中。

连接数据

将此资源从资源窗口拖入视口或场景窗口，会创建一个电子表格工具，并将该资源连接到其 File 属性。

或者，手动创建一个电子表格工具，然后将 Google Sheet Asset 从资源窗口拖到其 File 属性上。

选项

右键单击 Google Sheet 资源会提供以下选项：

  • Spreadsheet Settings：定义 Cavalry 如何解读数据（CSV Asset 也有相同的设置）：
    • Delimiter：设置用于分隔数据中各个单元格的符号。注意：对于 Google 表格资源，此项必须设为 ,（逗号）。.csv 数据可能使用其他分隔符。
    • Quote：设置用于界定数据中字符串的符号。
    • Decimal Separator：设置用于分隔数字整数部分与小数部分的符号。（例如 12.75 中的 .）
    • Factorize：在电子表格上使用 Factorize 属性时必须勾选此项。注意：对数据进行因子化可能会影响性能。
  • Rename：重命名该 Google 表格资源。
  • Reload：重新加载 Google 表格数据。Google 表格发生更改后都需要执行此操作。
  • Replace Google Sheet：将当前 Google 表格的链接替换为另一个表格。
  • Open Google Sheet in Browser：在 Web 浏览器中打开链接的 Google 表格。
  • Delete：从场景中移除该 Google 表格资源。

混合数据类型：

如果列中的单元格混合了多种数据类型（字符串/数值/颜色等），可能需要在表格中指定格式，以便“正确”解读单元格内容。例如，下表中的第一个单元格是数值，因此该列会被按数值读取，但第二个单元格不是有效数值，因此不会被 Cavalry 读取。

列
28
11/345

在此示例中，需要使用 Google 表格中的 Format > Number > Plain Text 菜单项，将这些单元格设为“纯文本”。这样在由电子表格工具读取时，它们会被解读为字符串。请注意，这意味着第一个单元格中的数字 28 不再被作为数值读取。
