路径引导

简介

沿路径移动或变形闭合图形。

界面

通用属性 +

Behaviour

Travel：按 Input Shape 长度的百分比移动图形。

Loop：勾选后，图形会回到路径起点并继续动画。取消勾选时，图形会沿第一个/最后一个点的方向继续运动。

Reverse Input Path：反转输入路径的方向。

Input Shape：连接一个图形，以便沿它定位/变形图形。

Deformer

Taper Graph：沿 Input Shape 的长度创建锥形渐变。

Path Offset：让图形偏离 Input Shape。

Flip：沿 x 轴翻转图形。这对文本尤其有用。

Value

Rotation Offset：为 Rotation 添加偏移。

Rotation（只读）：输出沿 Input Shape 法线的旋转。可将此值连接到另一个图形的 Rotation 属性。

示例（变形器）：

  1. 创建一个矩形。
  2. 将矩形 Width（W）的 Edge Divisions 设为 20。
  3. 点击矩形上 Deformers 旁的 + 图标并添加 Pathfinder。
  4. 使用钢笔工具绘制一条路径。
  5. 连接 path.id→pathfinder.inputShape

示例（沿路径动画）：

  1. 创建一个椭圆。
  2. 使用钢笔工具绘制一条路径。
  3. 创建一个 Pathfinder。
  4. 连接 path.id→pathfinder.inputShape
  5. 连接 pathfinder.id→ellipse.position

信息：

在添加 Pathfinder 以将图形变形到 Input Path 的内侧或外侧之前，可以先使用对齐行为将图形固定在其上/下/左/右边缘。
