对比色

简介

输出与输入颜色形成对比的颜色。

UI 设计中的一项常见工作是为文字或图标挑选与背景色对比足够强烈、清晰易读的颜色。Contrasting Color Utility 可用于自动化这一过程，并确保符合最新的WCAG 无障碍标准。

界面

Mode：设置用于检验Input Color与Primary Color对比度的对比率：

  • Most Contrasting：输出与Input Color对比最强烈的颜色（Primary 或 Secondary）。
  • Least Contrasting：输出与Input Color对比最弱的颜色（Primary 或 Secondary）。
  • 3:1：必须遵循的最低级别。也称为 A 级（基本合规）。
  • 4.5:1：对大多数用户而言既可用又可访问。也称为 AA 级（可接受合规）。
  • 7:1：无障碍的最高标准级别。也称为 AAA 级（最佳合规）。
  • Custom：设置自定义的Custom Ratio。

Custom Ratio：设置自定义比率 [value]:1。

Input Color：设置要与Primary Color进行检验的颜色。通常，这是文字或图标的颜色。

Primary Color：设置要与Input Color进行检验的颜色。如果通过对比率检验，则输出该颜色。

Secondary Color：设置当Primary Color未通过对比率检验时输出的替代颜色。

示例：

  1. 创建一个矩形。
  2. 创建一个椭圆：
    • 将Radius设为70。
    • 禁用Fill。
    • 启用Stroke。
  3. 将矩形和椭圆Group。
  4. 选中该组，在工具架中点击复制器图标。
  5. 将复制器的网格Size（Width 和 Height）设为 500。
  6. 创建一个颜色数组。
  7. 使用 Add
  8. 连接 colorArray.id→rectangle.fill.color
  9. 创建一个Contrasting Color Utility。
  10. 连接 colorArray.id→contrastingColor.inputColor
  11. 连接 contrastingColor.id→ellipse.stroke.color

位于颜色较浅的矩形上的椭圆，其Stroke颜色应设为Primary Color，反之亦然。

信息：

最佳实践是选择彼此形成对比的Primary和Secondary颜色，从而确保当其中一个不通过时，另一个更有可能具备足够的对比度而清晰可读。
