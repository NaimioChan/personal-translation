2.0.3 版本说明

发布日期：2024年2月22日

2.0 版本说明→

文件版本升级：

在 Cavalry 2.0.2 中创建的场景，在 Cavalry 2.0.3 中打开时会被转换。文件会被复制到一个新的场景中，需要保存——打开时你会注意到旧场景命名为 <yourSceneName> [Converted].cv。任何在 2.0.3 及之后版本保存的场景将无法完全兼容 Cavalry 的任何先前版本。

新功能

行为

  • 新增 弯曲变形器。
  • 新增 挤压与拉伸。它取代了旧的 Squetech Deformer（旧场景仍可正常使用）。

工具

  • 填充 和 描边 现在是正式的工具体。此前一直可以对它们使用“Reveal Generator”，而这一改动意味着现在可以通过将这些工具连接到图形来更轻松地共享材质（包括着色器）。

脚本

  • setStep 已添加到 NumericField。
  • getInOutKeyframeIds
  • timecodeToFrames
  • framesToTimecode
  • hexToRgba
  • hsvToRgba

信息：

我们发现 API 中的颜色处理有些混乱。hexToRgb 和 hsvToRgb 返回的数值范围是 0…1，但 Cavalry 期望的是 0..255。现在已隐藏这两个函数，改用 hexToRgba 和 hsvToRgba，但旧脚本不受影响，因为这些函数仍然存在。

增强

  • 跨上下文预选高亮。在视口中悬停某个图形时，它在场景窗口中的行也会高亮（反之亦然）。
  • 界面中显示的小数位数现已减少。浮点值（可包含小数的数值）现在会隐藏第一位小数之后的所有末尾零。例如，1.00 或 2.130 将分别显示为 1.0 或 2.13。
  • 切换合成时，属性编辑器中各 UI 的展开/折叠状态现在会被记住。
  • WebM 导出现在支持 Alpha。
  • Text Shapes 现在会根据其 String 自动重命名。仅当你没有为该图层明确设置易读名称时才会发生。
  • 边界框 工具现在可以在指定的帧上计算数值。
  • 改进了 工具设置 窗口中各设置之间的视觉间距。
  • 添加分段 现在有 Edge Length 模式。
  • 现在可以通过按住 Option/Alt 单击，将场景窗口中的帧指示器切换为时间码。
  • Connection Hints：选择某个图层时，场景窗口中与之连接的其他图层的连接图标会以轮廓提示。

重要错误修复

  • 将图形用作 文本图形 的 Track Matte 现在可以正常工作。
  • Align Deformer 在 Pre-Comp 中使用时重新恢复正常。
  • 撤销通过场景窗口将着色器连接到图形的操作现在可以正常工作。
