数值范围

简介

Number Range 可用于重映射某个范围内的数值。例如，若一组输入值的范围是 0-100，可以用 Number Range 将这些值放大，输出 0-400 的范围。

界面

Source Minimum：输入范围内的最小值。

Source Maximum：输入范围内的最大值。

Value：连接一组数值（例如来自 Spreadsheet 的数据）

Minimum：Source Minimum 要重映射到的值。

Maximum：Source Maximum 要重映射到的值。

Graph：参见图表属性

Clamp：勾选后，当输入值高于或低于 Maximum 或 Minimum 时，输出会被钳制在这些值上。取消勾选时，输出值会循环。

Offset：为输出加上或减去一个值。

Spreadsheet：

该图层也用作 电子表格 工具中各选项的基础。Value 属性不会出现在 Spreadsheet 的属性编辑器界面中，因为它由连接到 Spreadsheet 的数据驱动。

示例：

  1. 创建 2 个图形（Shape1 和 Shape2）。
  2. 创建一个 Number Range。
  3. 设置：
    • Source Minimum = -100
    • Source Maximum = 100
    • Minimum = -400
    • Maximum = 400
  4. 连接 shape1.position.y→numberRange.value
  5. 连接 numberRange.id→shape2.position.y
  6. 在视口中上下移动 Shape1。

当 Shape1 在 Y 轴上到达 100 的位置时，Shape2 会移动到 400 的位置。若勾选了 Clamp，则当 Shape1 超过 100 后，Shape2 将保持在 400。

反转数值：

无论 Minimum 和 Maximum 中输入什么值，较小的值始终会被用作 Minimum，较大的值始终会被用作 Maximum。例如，当 Minimum 属性中输入的值实际上大于 Maximum 属性时，这些值会在该图层的计算过程中被反转。Source Minimum 和 Source Maximum 也是如此。
