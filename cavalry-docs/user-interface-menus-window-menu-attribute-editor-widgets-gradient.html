渐变

简介

渐变部件会出现在多个图层上，包括 渐变着色器、渐变映射滤镜、索引转颜色 和 颜色混合。

界面

渐变模式

大多数包含渐变部件的图层也会包含 Gradient Mode 属性：

Gradient Mode：选择渐变的插值方式：

  • RGB Interpolation：在颜色之间沿穿过色轮的直线进行插值。
  • Oklab Interpolation：使用 Oklab 插值，在颜色之间沿穿过色轮的直线进行插值。
  • HSV Interpolation (Short Path)：使用色相（H）、饱和度（S）和明度（V），在颜色之间沿色轮的最短路径进行插值。
  • HSV Interpolation (Long Path)：使用色相（H）、饱和度（S）和明度（V），在颜色之间沿色轮的最长路径进行插值。
  • LCH Interpolation (Short Path)：在颜色之间沿色轮的最短路径进行插值。LCH 插值通过在感知均匀的色彩空间中插值明度（L）、色度（C）和色相（H）来混合颜色。
  • LCH Interpolation (Long Path)：在颜色之间沿色轮的最长路径进行插值。LCH 插值通过在感知均匀的色彩空间中插值明度（L）、色度（C）和色相（H）来混合颜色。

渐变

要创建新的 Color Stop，请将光标定位在渐变上并单击。

要调整 Color Stop 的属性，请选中一个 Color Stop，然后调整渐变下方的属性：

  • Position：沿渐变设置所选 Color Stop 的位置（0-1）。
  • Jitter：根据强度为插值曲线添加噪波。Jitter 将添加在所选 Stop 与其右侧下一个 Stop 之间。注意：此属性仅在 渐变着色器 和 渐变映射滤镜 上可用
  • Color：设置所选 Color Stop 的颜色。也可以双击 Color Stop 弹出颜色窗口，并在其中调整颜色。

按住 Option/Alt 单击并拖动 Color Stop 可复制它。

按住 Cmd/Ctrl 可选择多个 Color Stop。

可将颜色窗口中的色板拖放到渐变行的任意位置。所选 Color Stop 的 Color 将被更新。

信息：

Color Stop 的 Position 和 Color 属性可设置动画或建立连接。

选项

右键单击渐变可弹出以下选项：

  • Copy Gradient：将 Color Stop 复制到剪贴板。
  • Paste Gradient：将已复制到剪贴板的 Color Stop 粘贴到某个渐变属性。
  • Adjust Colors (HSV)：对渐变中的所有 Color Stop 执行 HSV 颜色调整。
  • Distribute Stops：将渐变宽度上的所有 Color Stop 均匀分布。
  • Subdivide Gradient：在任意现有 Color Stop 之间的一半位置添加新的 Color Stop。
  • Reverse Stop Positions：翻转渐变的 Color Stop。注意这不会影响 Jitter 或 Interpolation 设置。
  • Shuffle Stop Positions：随机交换 Color Stop 的位置。
  • Shift Stops Left：将每个 Color Stop 移到其左侧下一个 Color Stop 的位置。最左侧的 Color Stop 将绕到渐变最右侧的 Color Stop。
  • Shift Stops Right：将每个 Color Stop 移到其右侧下一个 Color Stop 的位置。最右侧的 Color Stop 将绕到渐变最左侧的 Color Stop。
  • Select All：选择所有 Color Stop。
  • Invert Selection：取消选择已选的 Color Stop，并选择未选的 Color Stop。
  • Select Same Color：选择所有与所选 Color Stop 颜色相同的 Color Stop。
  • Set Interpolation：设置所选 Color Stop 的颜色向下一 Color Stop 颜色混合的插值方式：
    • Linear：应用线性（直线）曲线。
    • Stepped：应用阶梯曲线。
    • Smooth：应用平滑曲线。
    • Crush：应用两端平缓、中间陡峭的曲线。
    • Smooth Blend：应用平滑曲线。
    • Contrast：应用两端陡峭、中间平缓的曲线。
  • Save Gradient to Palette：在 颜色窗口 中创建一个新的库调色板，其中每个 Color Stop 用于创建一个色板。
