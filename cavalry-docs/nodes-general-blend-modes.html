混合模式

简介

混合模式可用于将图形和效果相加，从而组合出有趣的风格。

Mode Description
Replace 替换目标
Normal 不混合
Plus Lighter 颜色相加
Screen 将像素的反相相乘，再反转结果；使目标变亮
Overlay 根据目标进行相乘或滤色
Darken 取源与目标中较暗者
Lighten 取源与目标中较亮者
Color Dodge 提亮目标以反映源
Color Burn 压暗目标以反映源
Hard Light 根据源进行相乘或滤色
Soft Light 根据源提亮或压暗
Difference 以较高对比度从较亮者中减去较暗者
Exclusion 以较低对比度从较亮者中减去较暗者
Multiply 将源与目标相乘，使图像变暗
Plus Darker 将源的颜色分量取反后相加，再反转结果
Hue 源的色相配合目标的饱和度和明度
Saturation 源的饱和度配合目标的色相和明度
Color 源的色相和饱和度配合目标的明度
Luminosity 源的明度配合目标的色相和饱和度
Alpha Add 合并两个相邻抗锯齿边缘的 alpha

相邻边缘：

当图形完全边缘对齐时，抗锯齿会在这些边缘之间产生接缝。尝试使用 Alpha Add 创建无缝连接。注意这仅在 Background's Alpha = 0 时受支持。要移除合成的背景，请前往 Composition > Toggle Background Alpha。
