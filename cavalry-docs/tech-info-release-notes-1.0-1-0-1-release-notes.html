1.0.1 版本说明

发布于 2020 年 8 月 26 日

概要

此版本主要用于解决部分 Windows 用户在编辑颜色和/或使用外部平板设备时遇到的问题。它还包含其他各种小改进和增强。

新增元素/功能

正式版

  • 视口中的时间码预览。可通过 首选项 窗口启用/禁用。

Beta

信息：

实验性功能可在 Preferences Window 中开启。

  • Magic Easing：在关键帧之间应用数学插值。注意：我们遵循即将推出的 Web Animation 标准，这对 After Effects 用户来说可能不太熟悉。更多信息请参阅此处。
  • Bake Keyframe Animation 命令。

常规增强/重要修复

  • 所有 String 属性现在都有一个 +，你可以从中轻松添加 字符串生成器。
  • 现在可以通过 alt + double click + drag 使用触控笔缩放视口和时间编辑器。
  • 现在可以将渐变保存到库调色板。右键单击渐变控件，并选择“Save to Palette”。
  • 现在可以将渐变加载到库调色板。首先选择一个 Gradient 属性，然后使用库调色板菜单并选择“Set Gradient from Palette”。
  • 弧形 和 超椭圆 基础图形现在默认使用贝塞尔曲线绘制。
  • 移动父图形的动画现在也会移动其所有子项的动画。
  • 消息栏现在具有队列。以前，如果两条消息发送到消息栏的速度过快，其中一条会丢失。现在你可以单击消息栏查看队列中的所有消息。
  • 消息栏现在还提供消息弹出面板，单击消息栏左侧的按钮可打开过往消息列表。
  • 如果某个 Render Queue Item 会覆盖现有文件，渲染管理器现在会弹出警告对话框。
