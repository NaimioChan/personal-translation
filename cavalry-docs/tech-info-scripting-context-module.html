上下文模块

简介

以下方法仅对 JavaScript 工具、JavaScript 图形、JavaScript 变形器、JavaScript 发射器 和 JavaScript 修改器 可用。此模块中的所有内容都在 ctx 命名空间中，因此方法需要以 ctx. 为前缀，例如 var index = ctx.index;

成员函数

index → int

当前点的索引。在使用复制器（或其他生成索引的图层，如 连接图形 或 拖尾）时可用。

count → int

点的总数。在使用复制器（或其他生成索引的图层，如 连接图形 或 拖尾）时可用。

positionX → number

当前点的 X 位置。在使用复制器（或其他生成索引的图层，如 连接图形 或 拖尾）时可用。

positionY → number

当前点的 Y 位置。在使用复制器（或其他生成索引的图层，如 连接图形 或 拖尾）时可用。

attributeId → string

正在计算的属性的 Id。

layerId → string

正在计算的图层的 Id。

saveObject(name:string, objectLiteralToSave:object)

保存一个对象以供之后使用。此功能的常见用法是创建求解器——例如，某个脚本需要知道上一个值。

要保存的值必须是一个对象。

如果要保存路径以供之后使用，请在保存/加载时使用 path.toObject()/ path.fromObject(obj) 方法。

// Simple example


ctx.saveObject("test", {"someKey": 10});





// A path example


// Create a path


var path = new cavalry.Path();


path.moveTo(0.,0.);


path.lineTo(0.,-100.);


path.lineTo(300.,-100.);


// Save it


ctx.saveObject("path", path.toObject());


// Safety check that there is a saved value


if (ctx.hasObject("path")) {


    // Load the object


    let previous = ctx.loadObject("path");


    // set the path from the object


    path.fromObject(previous);


}

loadObject(name:string) → object

加载已保存的对象。

ctx.saveObject("test", {"someKey": 10});


var textObj = ctx.loadObject("test");


console.log(textObj["someKey"])

hasObject(name:string) → bool

如果名为 name 的对象已保存且可加载，则返回 true。

ctx.saveObject("test", {"someKey": 10});


if (ctx.hasObject("test")) {


    /// do something


}

niceName() → string

获取请求 JavaScript Utility 返回值的图层的显示名称。

console.log(ctx.niceName);

transformationMatrix() → matrix

返回上游的局部二维变换矩阵，如果不存在则返回 null。

/*


1. Create a Shape.


2. On the Shape's Deformers attribute, click the + button and choose JavaScript Deformer.


3. Copy the below in the JavaScript Deformer's Expression.


*/





var tm = ctx.transformationMatrix();


console.log(tm.position().x);

globalTransformationMatrix() → matrix

返回上游的全局二维变换矩阵，如果不存在则返回 null。

/*


1. Create a Shape.


2. On the Shape's Deformers attribute, click the + button and choose JavaScript Deformer.


3. Copy the below into the JavaScript Deformer's Expression.


4. Group the Shape.


*/





var tm = ctx.globalTransformationMatrix();


console.log(tm.position().x);
