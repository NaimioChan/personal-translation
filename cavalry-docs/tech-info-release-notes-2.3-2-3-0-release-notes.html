2.3 发行说明

发布日期：2024年12月11日

文件版本升级：

在 Cavalry 2.2.1 或更早版本中创建的场景，在 Cavalry 2.3 中打开时会被转换。文件会被复制为一个需要保存的新场景——打开时你会注意到旧场景被命名为 <yourSceneName> [Converted].cv。在 2.3 及之后版本中保存的任何场景都不会完全兼容 Cavalry 的以往版本。

新功能

常规

  • 预设：为图层、合成 和 Render Queue Items 保存并应用预设配置。
  • Multi-Viewports：打开多个 Viewport 以预览不同的合成。
  • 渲染管理器 重新支持 GIF export。

图形

  • 等值线图形：将图像或图形转换为轮廓。

行为

  • 轮廓转子网格：将图形内的路径轮廓转换为子网格。

工具

  • 图层种子：为各个输出连接生成唯一值。

脚本

API Module

  • hasCustomAttributeName
  • hasAttributeExpression
  • getAttributeExpression
  • addAssetToComp

Script UIs

  • onAssetUpdated 回调。
  • onAssetAsyncLoadFinished 回调。
  • onAppStateChange 回调。
  • modal 的新 showConfirmation 函数。

增强

  • Attribute Editor Previews：某些图层现在会在其 Attribute Editor UI 顶部显示预览，以帮助直观呈现其效果。
  • 电子表格 工具的 Column Count。
  • Copy as SVG 已添加到 编辑菜单。
  • 文本图形 的 Background Shape 新增圆角选项。
  • 现在可以在 首选项 中设置 Viewport 画布的颜色。
  • 合成现在会在 资源窗口 中显示 FPS 和 Resolution 标签。
  • 首选项 窗口已添加滚动条。
  • SkSL 着色器 现在：
    • 支持采样其他着色器。已新增示例场景 Create > Demo Scenes > Custom Shaders and Filters > Sample Image Shader。
    • 拥有新的（不那么迷幻的！）默认值。
    • 包含 resolution 内置 uniform。
  • Cavalry 2.2 发布宣传中的“hello”动画已添加到 Create > Demo Scenes > Illustration > Gradient along a Path。
  • Scene Tree 中的图层现在会添加 Pro 标签，以帮助 Starter 用户清理包含专业版功能的合成，从而关闭 Restricted Mode。
  • 复制 合成 现在也会复制已添加到 控制中心 的属性。
  • 右键单击 资源窗口 中的 Create a Composition 按钮，可为新合成应用预设。
  • 当 组件 处于非编辑模式时，选中它不再预览其中包含的图形。
  • api.create() 现在包含可选的 allowDefaultPreset 参数。
  • 已将 attrId、isArray、isCompound 和 isDynamic 键添加到 getAttributeDefinition
  • JavaScript 控制台（窗口和面板）现在可编辑，这意味着可以添加笔记，其内容也可以复制到剪贴板。
  • 路径引导 的变形精度已改进，尤其是对闭合图形。

重要缺陷修复

  • 当 图像着色器 的 Scale Mode 设为 Fit 时，图像现在会与图形中心对齐。请注意，之前对齐到顶部/左侧的旧场景不会自动更新。要更新文件，可以创建新的 Image Shader 替换现有的，或在 JavaScript Editor 中运行 api.set(layerId, {"legacyGraph": false});（将 layerId 替换为 Image Shader 的 layerId）。
  • 修复了连接到图形的 对齐 可能导致其 图像着色器 “滑动”的问题。请注意，如果 Image Shader 的 Scale Mode 设为 Fit Vertically 或 Fit Horizontally，仍会出现该问题。
  • 在窗口之间拖动合成时，不再显示合成预览。
  • Pen 工具的“下一点预览”绘制已恢复。
  • 索引转颜色 的 Gradient Mode 现在恢复可用。
  • 为 Label 使用 setText() 时，现在会忽略 Markdown 样式。纯文本和 markdown 文本仍继续支持 HTML 标签（例如 <b>Bold</b>）。
  • 关闭 Sign In 窗口时，确认对话框现已修复。
  • 已解决列表输入（例如 Forge Bodies）中的 id 可能变得不连续的多个问题。
  • 已移除向 数学分布 添加索引后撤销时出现的无害错误。
  • 当没有选中关键帧时，曲线编辑器 页脚中的数值现在会正确清除。
  • 已解决 调制 默认 Divisor 值的问题。

说明

  • 基本图形 的 Shape Type 属性已重命名为 Primitive Type。
  • Composition 标签页已从 首选项 窗口移除，因为这些选项现在可以通过新的预设功能应用。
  • Cavalry 2.2 中更广泛的升级暴露出 RGB 分离滤镜 的 Blend Modes 一个此前未被发现的问题。在某些情况下，这可能导致在 Cavalry 2.1 或更早版本中创建的场景出现视觉变化。2.3 中又做了进一步的小修复，但该问题不会被“逆转”，因此打开旧场景时可能需要手动调整。
