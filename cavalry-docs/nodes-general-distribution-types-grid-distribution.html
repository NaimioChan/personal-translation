网格分布

简介

以网格形式分布点。

界面

Count - 设置点的数量 [x,y]。

Size - 根据 Size Mode 设置点分布所覆盖的距离。

Pattern Offset - 设置一个值来偏移每隔一行/列。[x,y]。

Size Mode - 决定 Size 属性的用法：

  • Fit - 在 Size 值的范围内分布点。
  • Step - Size 值决定每个点之间的间距。

Direction - 决定点按行还是按列排序。

  • Flow Columns - 点从左到右、再从下到上排序。
  • Flow Rows - 点从下到上、再从左到右排序。

信息：

默认情况下，点从左下到右上排序。使用负的 Size 值可改为从上到下或从右到左排序图形。
