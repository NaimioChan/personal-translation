格式化字符串生成器

简介

通过组合输入字符串数组来构建自定义字符串。

界面

Formatted String：输入一个字符串。使用 {<indexNumber>} 引用某个索引。默认情况下，这是一个单行输入框，但输入软回车（Shift + Return）会将界面转换为多行输入框。

Add

0:String：数组中的第一个索引。

格式化字符串

数组中的每个字符串都可以通过在花括号中包裹其索引，在Formatted String中被引用。生成的输出字符串会将 {0} 替换为0:String中输入的内容。

示例：

  1. 创建一个字符串生成器。
  2. 将Generator设为Formatted String。
  3. 在Formatted String中输入 Here's to the {0} ones.。
  4. 在0:String中输入 crazy。
  5. 创建一个文本图形。
  6. 连接 stringGenerator.id→textShape.string

Formatted String中的 {0} 已被替换为 crazy，因此文本图形会输出“Here's to the crazy ones.”。

数值

Formatted String Generator仅接受字符串作为输入，但可以使用数值生成器将数值转换为字符串。例如，要将矩形的Width添加到Formatted String Generator，可以先将其连接到数值生成器，然后再将数值生成器连接到Formatted String Generator的某个索引。

动态文件名

Formatted String Generator也是生成动态文件名的好方法。与动态渲染结合使用时尤其有用。只需将Formatted String Generator连接到渲染管理器中Render Queue Item的File Name——每当Dynamic Index递增时，就会生成一个新的文件名。

Formatted String Generator可用于组合各种输入，包括来自电子表格工具的数据、渲染令牌以及合成中的数值，从而创建量身定制的唯一文件名。

如果已通过电子表格工具连接外部数据，或将数组的Index连接到渲染管理器的Dynamic Index，则每次渲染都会获得由Formatted String Generator生成的唯一文件名。

示例：

  1. 将包含以下数据的 .csv 或 Google Sheet 资源导入资源窗口：
Colour Hex
Red #ff0000
Green #00ff00
Blue #0000ff
  1. 将资源拖入视口以创建一个电子表格工具。
  2. 将电子表格的Column Title设为Colour。
  3. 勾选Fixed Row。
  4. 将渲染管理器的Dynamic Index连接到电子表格的Row Index。
  5. 创建一个字符串生成器。
  6. 将Generator设为Formatted String。
  7. 在Formatted String中输入 Colour-{0}。
  8. 连接 spreadsheet.id→stringGenerator.array.0（0:String属性）。
  9. 将String Generator连接到Render Queue Item的File Name。

进行动态渲染时，每个文件将命名为 Colour-Red、Colour-Green、Colour-Blue。

渲染令牌：

请注意，渲染令牌不会继承用于确认其在Formatted String Generator中有效的样式，因此请确保拼写和格式正确。连接到 Render Queue Item 的File Name后就会显示该样式，因此可以用它来确认令牌是否已正确输入。

信息：

不带索引的条目（空花括号）会根据其在字符串中的位置进行编号。例如，包含 {} {} {} 的字符串等同于 {0} {1} {2}。当同一字符串中同时存在带索引和不带索引的条目时也是如此。例如，{2} {} {1} {} 会被解释为 {2} {0} {1} {1}。
