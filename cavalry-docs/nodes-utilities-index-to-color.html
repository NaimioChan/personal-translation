索引转颜色

简介

将渐变映射到每个索引，以设置子网格（复制器、文本等）中图形的颜色。

界面

Utility

Value：沿渐变输出的位置（0 = 最左，1 = 最右）。

Gradient Mode：为 Gradient 选择一种插值方式。参见渐变。

Gradient：设置颜色值。参见渐变。

Reverse：反转/倒置渐变。

Advanced

Use Index Context：勾选后，Index to Color 将拉取上下文。与子网格（复制器、文本、SVG 等）配合使用时，这可用于控制 Id 的分配方式。

示例：

  1. 创建一个基本图形。
  2. 选中该图形，点击工具架中的复制器图标。
  3. 创建一个 Index to Color。
  4. 连接 index.ToColor.id > basicShape.fill.color

每个副本都会沿渐变依次着色。

示例：

  1. 创建一个基本图形。
  2. 选中该图形，点击工具架中的复制器图标。
  3. 创建一个 Index to Color。
  4. 连接 index.ToColor.id > basicShape.fill.color
  5. 在 Index to Color 的 Advanced 标签下取消勾选 Use Incoming Index。
  6. 右键单击 Index to Color 的 Value > Add Behaviour > Random。
  7. 将 Random 的 Maximum 设为 1。

每个副本都会沿渐变获得一种随机颜色。
