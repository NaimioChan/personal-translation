Cavalry CLI

旧版：

当前 Cavalry 2.7 或更高版本不提供 CLI。

概述

Cavalry CLI（Command Line Interface，命令行界面）可用于执行各种任务，包括无需启动 Cavalry 界面即可进行渲染。某些功能仅在 Enterprise 许可证下可用。

开始使用

运行 CLI 的方法如下（假设 Cavalry 安装在默认位置）：

macOS

  • 打开 Terminal（Applications/Utilities/Terminal）。
  • 输入以下命令以切换目录（cd）。 
    cd /Applications/Cavalry.app/Contents/Applications/CavalryCLI.app/Contents/MacOS/
  • 按 Return，然后输入： 
    ./cavalry-cli [your command here]

Windows

  • 打开 Command Prompt。
  • 输入以下命令以切换目录（cd）。 
    cd C:\Program Files\Cavalry
  • 按 Return，然后输入： 
    .\cavalry-cli [your command here]

输入 ./cavalry-cli -h（macOS）或 .\cavalry-cli -h（Windows）后按 Return，会输出以下帮助信息：

Command Line Interface

Usage: Cavalry CLI [OPTIONS] [SUBCOMMAND]



  -h,--help                   Print this help message and exit

  --prompt                    Enter continuous command-line mode in which JavaScript commands can be executed.



Subcommands:

  render                      Render a scene. This requires an Enterprise licence.

  version                     Version information

  auth                        Authenticate (Password may be piped or entered when prompted)

  proxy                       Set proxy settings

  list                        List additional information. This requires an Enterprise licence.

随后就可以使用这些标志来构建命令。

例如，下面的命令会将文件 sceneName.cv 的第 0-50 帧渲染为名为 outputFileName 的 animated png，并保存到 Desktop。

macOS

./cavalry-cli render ~/Desktop/sceneName.cv -n outputFilename -d ~/Desktop/ -s 0 -e 50 --format apng

Windows

.\cavalry-cli render C:\Users\Username\Desktop\sceneName.cv -n outputfilename -d C:\Users\Username\Desktop\ -s 0 -e 50 --format apng

项目设置：

如果场景文件保存时设置了 Project，且未定义 -d（directory），则输出会保存到 项目设置 中定义的 Renders 目录。

资源替换：

在渲染时可以使用 --assetSwap 将某个资源（图片、音频、csv、svg 等）替换为另一个资源。参数应成对输入：

  • 资源 ID
  • 新的路径或 URL

例如 --assetSwap asset#2 ~/Desktop/cavalry.jpg。

要找到资源 ID，可以在 资源窗口 中右键点击某个资源，然后选择 Copy Asset Id。

渲染令牌

要在命令中使用渲染令牌生成 File Name（-n），请用单引号或双引号将它们括起来。例如以下两种写法都可以正常工作：

-n '<Composition>_Name'

-n "Name_<Resolution>"

version

要查看当前安装的 Cavalry 版本，请运行 version 命令。

输入 ./cavalry-cli version -h（macOS）或 .\cavalry-cli version -h（Windows），会输出以下帮助信息。

Version information

Usage: Cavalry CLI version [OPTIONS]



  -h,--help                   Print this help message and exit

macOS

./cavalry-cli version

Windows

.\cavalry-cli version

会返回已安装的 Cavalry 版本。

[11:30:29.657 info    ] App Version: 0.15

auth

使用 CLI 进行渲染需要先通过身份验证。

输入 ./cavalry-cli auth -h（macOS）或 .\cavalry-cli auth -h（Windows）后按 Return，会输出以下帮助信息：

Authenticate (Password may be piped or entered when prompted)

Usage: Cavalry CLI auth [OPTIONS] email



  email TEXT REQUIRED         Email Address



  -h,--help                   Print this help message and exit

  --sslCertificatePath TEXT   Specify the path to a CA (Certificate Authority) certificate (e.g a cacert.pem file)
./cavalry-cli auth name@email.com

按 Return 后会要求输入密码。

也可以通过管道传入密码：

echo "yourPassword" | sudo ./cavalry-cli auth name@email.com

Docker：

Docker 实例可能需要 CA（Certificate Authority）证书以进行 SSL 服务器验证。使用 --sslCertificatePath 指定证书的路径。

proxy

可以使用 proxy 命令输入/更新代理服务器设置。输入 ./cavalry-cli proxy -h（macOS）或 .\cavalry-cli proxy -h（Windows）后按 Return，会输出以下帮助信息：

Set proxy settings

[At least 1 of the following options are required]

Usage: Cavalry CLI proxy [OPTIONS]



  -h,--help                   Print this help message and exit

  --address TEXT Excludes: --reset

                              Server Address

  --username TEXT Needs: --address Excludes: --reset

                              Username (Password may be piped or entered when prompted)

  --reset Excludes: --address --username

list

企业版功能：

此功能仅在 Enterprise 许可证下可用。详情请联系我们。

可以列出场景的附加信息，例如 Composition 和 Render Queue item 的 ID。这些 ID 可以作为标志添加到 render 命令中。输入 ./cavalry-cli list -h（macOS）或 .\cavalry-cli list -h（Windows）后按 Return，会输出以下帮助信息：

List additional information

Usage: Cavalry CLI list [OPTIONS] [scene]



  scene TEXT                  The full path to the scene file.



  -h,--help                   Print this help message and exit

  --compositions Needs: scene List all compositions

  --render-items Needs: scene List all render items

例如，下面的命令会输出该场景中所有 Composition 的信息。

macOS

./cavalry-cli list ~/Desktop/sceneName.cv --compositions

Windows

.\cavalry-cli list C:\Users\Username\Desktop\sceneName.cv --compositions

按 Return 将返回场景中 Composition 的列表及其 ID。

[11:17:43.468 info    ] Relinked asset: asset#2

[11:17:43.471 info    ] Composition ID                Composition Name

[11:17:43.471 info    ] compNode#1                    Composition 1

[11:17:43.471 info    ]

[11:17:43.471 debug   ] Saving preferences

随后可以在 render 命令中使用 --composition 标志并配合 Composition ID。例如，要渲染 Composition 1，请在 render 命令中添加 --composition compNode#1。

--prompt

企业版功能：

此功能仅在 Enterprise 许可证下可用。详情请联系我们。

通过 --prompt 参数，CLI 可以与 JavaScript API 结合使用。这样就可以在没有 UI 的情况下与 Cavalry 交互。

要以交互式 JavaScript 模式启动 CLI：

macOS

  • 打开 Terminal（Applications/Utilities/Terminal）。
  • 输入以下命令以切换目录（cd）。 
    cd /Applications/Cavalry.app/Contents/Applications/CavalryCLI.app/Contents/MacOS/
  • 按 Return，然后输入： 
    ./cavalry-cli --prompt
  • 按 Return。

Windows

  • 打开 Command Prompt。
  • 输入以下命令以切换目录（cd）。 
    cd C:\Program Files\Cavalry
  • 按 Return，然后输入： 
    .\cavalry-cli --prompt
  • 按 Return。

现在可以输入 JavaScript 命令了。例如：

// Print 'hello' to the console.

console.log("hello");



// Open a Cavalry Scene.

api.openScene("/Path/To/file.cv", true);



// Set an attribute within the open Scene.

api.set("basicShape#1", {"material.materialColor": "#6437ff"});



// Render all RQIs.

api.renderAll();

也可以使用 | 符号来“管道”连接命令，从而运行多条命令。例如：

api.set("basicShape#1", {"material.materialColor": "#6437ff"}) | api.renderAll()

管道命令中的分号：

请注意，在管道连接多条命令时，使用分号（;）终止行可能会产生错误。例如：

这样会出错（第一条命令后带有分号）：

api.set("basicShape#1", {"material.materialColor": "#6437ff"}); | api.renderAll();

但这样可以正常工作：

api.set("basicShape#1", {"material.materialColor": "#6437ff"}) | api.renderAll();

错误代码

信息：

要获取返回值，应从一个进程中运行 CLI（例如从 Cavalry 中的 JavaScript）。或者，如果直接在 Terminal 或 Command Prompt 中运行 CLI，可以使用以下命令获取最后执行命令的返回值：

  • Terminal：echo $?
  • Command Prompt：echo %ERRORLEVEL%
返回值 错误
0 成功。
200 登录失败。可能是许可证服务器无法访问。详见控制台。
201 登录失败，密码字段为空。
202 许可证无效。请使用 --auth 命令登录以继续。
203 许可证无效。此功能需要 Enterprise 许可证。
204 无法加载场景文件。
205 Render Queue Item 不存在。
206 验证许可证出错。无法将许可证文件保存到磁盘。

术语表

INT：整数，即不带小数点的数字。例如 4

INT x 2：用于定义范围的一组两个整数。例如 4 8（4[space]8）

FLOAT：带小数位的数字。例如 23.5

TEXT：可以包含字母、数字、特殊字符、连字符或井号的文本字符串。例如 sceneName-01
