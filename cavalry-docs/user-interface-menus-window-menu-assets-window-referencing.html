引用

简介

将其他 Cavalry 场景文件（.cv）导入为“资源”，然后将其用作“预合成”。这样可将项目拆分为更小的场景，再在主场景中组合，从而让多位美术师协作完成一个项目。

Reference 不过是一个导入到 资源窗口 的 Cavalry 场景文件（.cv），就像图像或视频资源一样。之后可将 Reference 导入多个其他场景文件，因此对原始 Reference 所做的任何更改都会反映在这些父文件中。

界面

  • Artboard：勾选后，Reference Composition 的 合成边界 将被忽略，这意味着例如 Reference Composition 内的图形动画到其合成边界之外时仍保持可见。Composition Background 也会被忽略。

工作流程

导入

在 资源窗口 中双击，然后选择一个 .cv 文件，以将另一个 Cavalry 场景导入为 Reference。这会将场景文件导入为资源，并显示其中包含的所有合成。请注意，必须在 合成设置 中勾选 Referenceable，合成才会作为 Reference 的子项出现。

从 /Scenes 导入：

设置 Project 后，导入资源将默认使用为 Assets 设置的目录。由于用作 Reference 的 .cv 文件可能已保存到为 Scenes 设置的目录中，导入资源时按住 Shift 将改为默认使用该目录。

覆盖

任何已设置为 Pre-Comp Override 的属性，都会出现在已导入另一场景中某个合成的 Reference Composition 的 Overrides 标签页下。之后可通过 Pre-Comp 的 Overrides 标签页访问这些属性，为每个 Pre-Comp 增加变化。

打开已导入的 Reference

在 资源窗口 中右键单击 Reference 的父级，然后选择 Open Reference File... 以打开该 Reference 的 .cv 文件。

示例：

创建一个“reference”场景：

  1. 创建一个图形。
  2. 右键单击 Fill > Color，然后选择 Add Pre-Comp Override。
  3. 在 资源窗口 中右键单击该合成，选择 Rename 并将其重命名为“Reference”。
  4. File > Save（reference.cv）

创建一个“main”场景：

  1. File > New Scene。
  2. File > Import Assets...。
  3. 选择在第 5 步保存的 reference.cv 文件，然后单击 Open。
  4. 将“Reference”合成拖入场景窗口。
  5. 在场景窗口中双击“Reference”合成，将其加载到 属性编辑器。
  6. 在 Shape 标签页下勾选 Artboard。
  7. 在场景窗口中选择 Reference 合成，并按 Cmd/Ctrl + D 复制它。
  8. 在视口中移动它。
  9. 双击任意一个 Pre-Composition，并打开 Overrides 标签页。
  10. 更改 Fill Color。
  11. File > Save（main.cv）。

编辑“reference”场景：

  1. 右键单击 reference 资源的父级，然后选择 Open Reference File...。
  2. 选择图形的 Stroke 标签页并启用 Stroke。
  3. File > Save。

重新加载“main”场景：

  1. File > Open Recent > 选择在第 14 步保存的 main.cv 文件。

两个 Pre-Composition 都已更新，包含对 Reference 中图形 Stroke 所做的更改。

项目设置

虽然并非必需，但在使用引用时建议使用 项目设置，以确保文件路径相对于其他资源。

可绘制项：

Nulls 和 Falloffs 包含在 Reference 文件中时不会显示或渲染。可将设置为 辅助图层 的图形（见 Advanced 标签页）作为替代方案，用于需要可见但不参与渲染的“辅助对象”进行定位/对位。
