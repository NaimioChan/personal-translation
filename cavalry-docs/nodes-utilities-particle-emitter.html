粒子发射器

实验性功能：

这是一项实验性功能。要启用它，请在偏好设置中勾选 Enable Experimental Features。

简介

从点、图形或路径发射粒子。

界面

Transform

通用属性 +

Custom Color：视口中会绘制一个表示发射器的图形——勾选 Custom Color 时，将使用 Color 中设置的值绘制；取消勾选时，则使用 Label Color（即场景窗口中该行所用的颜色）。

Color：为发射器在视口中的绘制设置自定义颜色。

Emitter

Emitter Shape：选择要从中发射的图形：

  • Point：从点发射粒子。
  • Circle：从圆形内部发射粒子。
  • Square：从方形内部发射粒子。
  • Input Shape：从图形内部发射粒子。
  • Input Shape Perimeter：从图形的路径发射粒子。

Input Shape：连接要从中发射粒子的图形。

Size：设置 Circle 或 Square Emitter Shape 的宽度和高度。

Use Single Position：取消勾选时，粒子会按“每个粒子”从输入图形内部或沿其路径的随机位置发射。勾选后，位置按“每帧”设置，因此当 20 个粒子在 1 帧内发射时，每个粒子都会从相同的位置发射。这可用于创建爆炸类的效果。

Maximum Particles：发射的粒子最大数量。

Emitter Type：确定粒子是按时间还是按距离发射：

  • Time：在每一帧（或子帧）发射粒子。
  • Distance：每当发射器的位置发生变化时发射粒子。

Particles per Pixel：当 Emitter Type 设为 Distance 时，设置发射器每移动一个像素将发射多少个粒子。

Rate：当 Emitter Type 设为 Time 时，设置每秒发射的粒子数量。

Duration：定义发射粒子的时间段。

Interval：定义发射器在开始下一个发射周期前暂停的时间（以秒为单位）。Duration 为 2、Interval 为 1 时，会产生持续发射 2 秒、然后暂停 1 秒、再重复该周期的粒子“爆发”。

Probability：使用发射周期时，设置粒子在 Duration 时间内发射的概率。这可用于让每次爆发的感觉不那么均匀。

Direction Type：确定粒子的发射方向：

  • Angle：沿 Initial Direction 设置的角度发射粒子。
  • Inwards：沿指向 Emitter Shape 路径内侧的法线发射粒子。
  • Outwards：沿指向 Emitter Shape 路径外侧的法线发射粒子。

Initial Direction：设置粒子发射所沿的角度。可以连接行为（例如随机）来按“每个粒子”设置角度。

Initial Speed：设置粒子发射时赋予它们的速度。可以连接行为（例如随机）来按“每个粒子”设置速度。

Perimeter Margin：当 Emitter Shape 设为 Input Shape Perimeter 时，扩展用于发射的路径宽度。例如，可用于从椭圆图形创建一圈粒子。

Use Path Normals：当 Emitter Shape 设为 Input Shape Perimeter 时，沿 Input Shape 的法线发射粒子。

Normal Angle：当 Emitter Shape 设为 Input Shape Perimeter 时，相对于路径法线偏移粒子的发射方向。

Use Emitter Velocity：

Emitter Velocity Strength：

Override Lifespan：勾选后，Lifespan 中的值将覆盖粒子图形的 Lifespan。当多个发射器连接到一个粒子图形时，这会很有用。

Lifespan：使用此值覆盖粒子图形的 Lifespan。

Time：此属性连接到合成的 Time，以在每一帧为粒子制作动画。如有需要，可将该连接替换为关键帧或其他行为。

Seed：设置用于在 Emitter Shape 内定位粒子的随机种子。
