图表属性

图表属性出现在多个图层上，包括 交错、衰减 和 数值范围。它可用于塑造图层的效果。

例如，在 衰减 上使用类似下图的曲线，会使其所连接行为的“Strength”在经过图形时从“开启”平滑过渡到“关闭”（然后再次过渡回来）。

调整图表与在 曲线编辑器 中处理动画曲线非常相似。

  • 单击并拖动一个点以移动它。
  • 按住 Option/Alt 单击一个点，可在直线与贝塞尔插值之间切换。
  • 单击并拖动以移动手柄。
  • 在窗口中的任意位置双击可添加新点。
  • 选择后按 Delete 可移除点。

窗口右侧有几个预设曲线。单击其中一个，即可将曲线设为图标所表示的形状。

可使用窗口右下角的按钮将图表水平方向和/或垂直方向翻转。

可使用窗口右下角的按钮复制和/或粘贴图表。也可以右键单击图表属性来执行此操作。

可通过选中一个点，并使用底部的 P（位置）和 V（数值）输入框，手动输入图表上点的值。

使用输入框右侧的按钮开启 Grid Snapping。

要为点或手柄设置动画或建立连接，请选中一个点或手柄，然后为其设置关键帧，或在 P（位置）或 V（数值）输入框上拖出/拖入连接。

信息：

要建立连接，你需要让窗口保持常驻。只需单击左上角的小“展开”图标，或抓住标题栏将面板“撕”下来。
