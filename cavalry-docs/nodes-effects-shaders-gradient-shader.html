渐变着色器

简介

在颜色之间进行插值，创建平滑的颜色过渡。

界面

通用属性 +

Screen Space：勾选后，渐变会以屏幕空间绘制。其结果是图形会在静态渐变上移动。取消勾选时，渐变会“贴合”到图形上。

Reverse：勾选后，将渐变的方向从“从左到右”反转为“从右到左”。

Premultiply：勾选后，透明像素的计算会采用预乘。当色标具有不同的 Alpha 时，这有助于避免出现深色边缘。

Tiling：确定渐变边界处的处理方式：

  • Clamp：使用渐变的首尾值。
  • Repeat：重复/循环渐变。
  • Mirror：镜像/往复渐变。
  • Decal：裁切渐变。

Gradient Mode：确定用于在色标之间进行插值的色彩空间。参见渐变。

Mode：选择渐变类型：

  • Conical：两点式锥形渐变。

    • Gradient：设置渐变的色标。
    • Start Radius：设置渐变起始处色标的半径。
    • End Radius：设置渐变结束处色标的半径。
    • Start Centre：定位渐变起始处的中心。
    • Wrap UVs：勾选后，最后一个色标将与第一个色标进行插值（反之亦然），这意味着渐变会环绕。注意：如果第一个和最后一个色标都位于 0 或 1 处，勾选此属性不会有可见效果。

  • Linear：线性渐变。

    • Gradient：设置渐变的色标。
    • Scale：缩放渐变。
    • Rotation：旋转渐变。
    • Gradient Scales with Rotation：勾选后，渐变会沿旋转轴缩放以适配图形。
    • Offset：偏移渐变的位置。
    • Wrap UVs：勾选后，最后一个色标将与第一个色标进行插值（反之亦然），这意味着渐变会环绕。注意：如果第一个和最后一个色标都位于 0 或 1 处，勾选此属性不会有可见效果。

  • Radial：沿半径（由中心向外）创建的渐变。

    • Gradient：设置渐变的色标。
    • Scale：缩放渐变。
    • Radius Mode：
      • Fixed Radius：为渐变设置固定半径。
      • Bounding Box：让渐变随图形缩放。
    • Size Ratio：Bounding Box 的乘数。
    • Radius：为渐变设置 Fixed Radius。
    • Offset：偏移渐变的位置 [x,y]。
    • Wrap UVs：勾选后，最后一个色标将与第一个色标进行插值（反之亦然），这意味着渐变会环绕。注意：如果第一个和最后一个色标都位于 0 或 1 处，勾选此属性不会有可见效果。

  • Shape：沿半径（由中心向外）创建的多边形渐变。

    • Gradient：设置渐变的色标。
    • Scale：缩放渐变。
    • Radius Mode：
      • Fixed Radius：为渐变设置固定半径。
      • Bounding Box：让渐变随图形缩放。
    • Size Ratio：Bounding Box 的乘数。
    • Radius：为渐变设置 Fixed Radius。
    • Offset：偏移渐变的位置 [x,y]。
    • Shape Sides：设置渐变图形的边数。
    • Wrap UVs：勾选后，最后一个色标将与第一个色标进行插值（反之亦然），这意味着渐变会环绕。注意：如果第一个和最后一个色标都位于 0 或 1 处，勾选此属性不会有可见效果。

  • Sweep：围绕圆周行进的渐变。

    • Gradient：设置渐变的色标。
    • Rotation：为渐变设置旋转。
    • Start Angle：设置渐变的起始角度。
    • End Angle：设置渐变的结束角度。
    • Offset：偏移渐变的起始/结束角度。
    • Wrap UVs：勾选后，最后一个色标将与第一个色标进行插值（反之亦然），这意味着渐变会环绕。注意：如果第一个和最后一个色标都位于 0 或 1 处，勾选此属性不会有可见效果。

图层工具

色标可以在视口中使用选择工具进行操作。当在场景窗口中选中 Gradient Shader 时，渐变会显示在视口中。

  • 调整渐变的 Size Ratio/ Rotation（Radial 和 Shape）：单击并拖动渐变两端带紫色描边的白点。按住 Cmd/Ctrl + 单击并拖动可仅影响 Rotation。
  • 更新色标的位置：沿紫色线单击并拖动色标。
  • 增大/减小色标的插值：按住 Shift 并向左/向右拖动。
  • 增大/减小色标的抖动：按住 Cmd/Ctrl 并向左/向右拖动。
  • 复制色标：按住 Option/Alt 并拖动。
  • 删除色标：选中一个色标并按 Delete 键。
  • 更改色标的颜色：双击色标并在弹出的颜色编辑器中调整该色标的颜色，或者从颜色窗口拖动色板并将其放到色标上。

提示：

渐变使用图形的边界框来定位颜色。在某些情况下，这可能需要一些处理。例如，如果在椭圆的 Stroke 上使用 Sweep Gradient，更改 Stroke 的 Trim 会改变其边界框，进而改变渐变的位置。

要解决此问题，可以尝试将渐变应用到椭圆的 Fill，然后使用弧形图形作为裁剪蒙版。在这种设置下，椭圆的边界框不会改变，因此渐变会保持在固定位置。
