渲染令牌

简介

渲染令牌可以添加到渲染管理器中的 File Name 或 Path 属性，用于自动生成渲染的文件名。

要添加 渲染令牌，只需在 File Name 或 Path 输入框中右键点击，然后从下拉菜单中选择一个。每个令牌都会出现在尖括号之间，例如 <Token>，并高亮显示。你也可以手动输入令牌。如果不小心输入了无效令牌，它会以红色高亮显示，并且不会被使用。

渲染令牌

令牌 描述
<Composition> 合成的名称。
<Scene> 场景的名称（例如 sceneName.cv）。
<Project> 当前项目的名称。必须在项目设置中设置项目，此令牌才会生效。
<Frame> 帧编号。
<Resolution> 合成的分辨率。
<FPS> 合成的 FPS（每秒帧数）。
<Format> 格式（.png、.jpg、.mov 等）。
<Dynamic> 为每次动态渲染输出 Dynamic Index。

信息：

<Token> 会替代而不是叠加任何自动生成的值（如帧编号或 dynamic index）。例如：

  • File Name 为 Composition、Padding 设为 3 时，输出为 Composition.000.png
  • File Name 为 Composition.<Frame>、Padding 设为 3 时，同样输出 Composition.000.png，而不是 Composition.000.000.png。

日期与时间令牌

令牌 描述
<D> 星期（名称）。例如，如果当前是星期一，令牌将输出 Monday。
<d> 星期（简称）。例如，如果当前是星期一，令牌将输出 Mon。
<DD> 月中的日期（数字）。例如，如果当前日期是 8 月 11 日，令牌将输出 11。
<M> 月份（名称）。例如，如果当前日期是 8 月 11 日，令牌将返回 August。
<m> 月份（简称）。例如，如果当前日期是 8 月 11 日，令牌将返回 Aug。
<MM> 月份（数字）。例如，如果当前日期是 8 月 11 日，令牌将输出 8。
<YYYY> 年份（YYYY）。例如，如果当前年份是 2024，令牌将输出 2024。
<YY> 年份（YY）。例如，如果当前年份是 2024，令牌将输出 24。
<T> 时间（HH:MM）。例如，如果当前时间是下午 5:15，令牌将输出 17:15。
<TZ> 时区。例如，如果在英国曼彻斯特，令牌将输出 GMT。

信息：

渲染令牌可以串联使用。例如，如果当前日期是 2020 年 8 月 11 日，令牌 <d>-<DD>-<m> 将输出 Tue-11-August。

自定义时间格式

也可以创建自定义时间格式，例如 <%Y>、<%H%M> 或 <%B-%Y>。

令牌 描述
<%Y> 以十进制数字写入年份，例如 2017。
<%y> 以十进制数字写入年份的后 2 位（范围 [00..99]）。
<%b> 写入缩写的月份名称，例如 Oct。
<%B> 写入完整的月份名称，例如 October。
<%m> 以十进制数字写入月份（范围 [01..12]）。
<%V> 写入 ISO 8601 周数（范围 [01..53]）。在 ISO 8601 中，每周从星期一开始。
<%j> 以十进制数字写入一年中的第几天（范围 [001..366]）。
<%d> 以十进制数字写入月中的日期（范围 [01..31]）。
<%a> 写入缩写的星期名称，例如 Fri。
<%A> 写入完整的星期名称，例如 Friday。
<%u> 以十进制数字写入星期，其中星期一为 1（ISO 8601 格式）。
<%H> 以十进制数字写入小时，24 小时制（范围 [00-23]）。
<%I> 以十进制数字写入小时，12 小时制（范围 [01..12]）。
<%M> 以十进制数字写入分钟（范围 [00..59]）。
<%S> 以十进制数字写入秒（范围 [00..60]）。
<%c> 写入标准日期和时间字符串，例如 Sun Oct 17 04-41-13 2010。
<%X> 写入本地化的时间表示，例如 18-40-20 或 6-40-20 PM。
<%D> 等同于 <%m>-<%d>-<%y>。
<%F> 等同于 <%Y>-<%m>-<%d>（ISO 8601 日期格式）。
<%r> 写入本地化的 12 小时制时间。
<%R> 等同于 <%H>-<%M>。
<%T> 等同于 <%H>-<%M>-<%S>（ISO 8601 时间格式）。
<%p> 写入本地化的 a.m. 或 p.m.。
<%z> 以 ISO 8601 格式写入与 UTC 的偏移（例如 -0430）。
<%Z> 写入与时区设置相关的时区名称或缩写，例如 BST。

环境变量

环境变量也可以用作 渲染令牌。使用语法 <Env:VARIABLENAME>。例如：

  • macOS：将 <Env:HOME> 添加到 Path 后，文件会写入 Macintosh HD/Users/<YourUser>。
  • Windows：将 <Env:USERPROFILE> 添加到 Path 后，文件会写入 C:\Users\<YourUser>。

要查看正在使用的环境变量：

  • macOS：在 Terminal 中输入 printenv。
  • Windows：在 Command Prompt 中输入 set。

提示：

格式化字符串生成器 可用于将令牌与其他属性值/字符串拼接，从而生成动态文件名。

令牌可以手动输入（例如 <Resolution>），但只有通过将 String Generator 连接到 Render Queue Item 的 File Name，把它们传递给渲染管理器后，它们才会显示为高亮。
