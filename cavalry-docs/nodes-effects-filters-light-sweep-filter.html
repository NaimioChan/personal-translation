光线扫过滤镜

简介

模拟一个光源在图层上方移动。

界面

Sweep Intensity：设置光的亮度。

Direction：以度为单位设置扫过图层的角度。

Shape：为扫光选择形状。

Centre：设置光线扫过的中心点。

Cone Width：设置光束的宽度。

Centre Percentage：设置锥形宽度中保持完全照亮的百分比。

Use Falloff：当 Shape 设为 Line 时，限制光线扫过在 Y 轴上距 Centre 的距离。

Falloff Distance：设置光线经过 Centre 后衰减的距离。

Edge Intensity：设置光线扫过边缘处附加辉光的强度。

Edge Thickness：当 Edge Intensity 大于 0 时，设置光线扫过边缘的厚度。

Light Color：设置光的颜色。
