1.3.1 发行说明

这是一个补丁版本，用于修复图像从时间轴中消失的问题，同时还包含一些其他改进。1.3 主要版本的发行说明见下方：

1.3 发行说明→

新功能

  • Snapshots - 将视口当前状态的快照保存到内存中。相关选项位于 View 菜单中。

增强

  • 将 SVG 添加到视口/场景窗口时按住 Option/Alt，现在会跳过模态选项并分离图层。
  • 合成设置 窗口现在更加紧凑。
  • 圆形分布 现在可以选择在其弧线末端添加一个点。
