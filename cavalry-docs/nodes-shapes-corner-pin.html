四角定位

简介

Corner Pin 会变形图形，可用于营造 3D 透视的错觉。

界面

Common Attributes +

Bind - 勾选后，图形将根据 Null 的位置发生变形。取消勾选后，可以调整其 Size。

Size - 设置 Corner Pin 图形的尺寸。可用作参考

Top Left - 连接一个变换（默认为 Null）。

Top Left Offset - 偏移所连接的变换。

Top Right - 连接一个变换（默认为 Null）。

Top Right Offset - 偏移所连接的变换。

Bottom Left - 连接一个变换（默认为 Null）。

Bottom Left Offset - 偏移所连接的变换。

Bottom Right - 连接一个变换（默认为 Null）。

Bottom Right Offset - 偏移所连接的变换。

Bind Selected Shape（按钮） - 将每个角点移动到第一个所选图形的边界框，并将其绑定到 Corner Pin。

示例：

  1. 创建第二个 Composition（Composition 2）。
  2. 在 资源窗口 中双击 Composition 2，将其加载到场景窗口。
  3. 通过合成设置 将其 Resolution 设为 600 x 800px。
  4. 向 Composition 2 添加一些图形（作为画面内容）。
  5. 在 资源窗口 中双击 Composition 1，将其加载到场景窗口。
  6. 创建一个 Corner Pin。
  7. 取消勾选 Bind。
  8. 将 Width 和 Height 设为 600 和 800。
  9. 将各个 Null 移动到 Corner Pin 图形的各个角（可借助 Bounding Box Viewport Snapping）。
  10. 勾选 Bind。
  11. 从 Assets Window 中将 Composition 2 拖入场景窗口，并将其放到 Corner Pin（图形本身，而非组）上，使其成为该图形的子级。
  12. 使用 Select 工具移动 Null。

注意：

可以在 scenery.io 上查看一些示例场景。
