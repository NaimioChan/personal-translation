更改字符串大小写操纵器

简介

更改文本字符串的大小写。

界面

Mode：设置模式：

  • Lower Case：将所有字符转换为 lower case。
  • Upper Case：将所有字符转换为 UPPER CASE。
  • Proper Case：将所有字符转换为 Proper Case。Proper Case 会将每个单词的首字母大写。参见下方的 Word Exclusion List。
  • Sentence Case：将所有字符转换为 Sentence case。Sentence Case 会查找通常表示句子结束的标点（ . ! ? ），并将下一个单词的首字母大写。如果希望换行后的首字母也大写，请使用 New Line as Sentence Delimiter 选项。

Word Exclusion List：使用 Proper Case 模式时，可以添加以逗号分隔的字符串（单词）来排除。例如，如果源字符串为 this is a string，则向 Word Exclusion List 添加 is,a 后，is 和 a 这两个词将不会被大写，结果为 This is a String。通过这种方式排除单词，你可以创建自定义的 Title Case。

小心：

Word Exclusion List 区分大小写。在上面的示例中，如果源字符串为 this iS a string，则结果为 This IS a string，因为 iS 与列表中输入的 is 不匹配。

New Line as Sentence Delimiter：勾选后，当 Mode 设为 Sentence Case 时，换行后的第一个字母将大写。
