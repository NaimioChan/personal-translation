声音

简介

播放音频并驱动变形或数值。

处理音频

将音频文件直接从 资源窗口 拖入 场景窗口 或 视口，将创建一个 Sound Behaviour 并连接该音频文件。

要在播放时听到音频，必须在 视口 底部的设置中启用 Audio Playback。

在 Pre-Comps 中编辑音频：

为包含 Sound Behaviour 的 Pre-Comp 设置入点/出点不会影响音频输出——音频必须在其父合成中被裁剪。

界面

Behaviour

通用属性 +

File：从 资源窗口 拖入一个音频文件。

Mode：

  • Spectral：输出各独立的频段。
  • Level：仅输出单个 RMS/Peak 响度——开销更低，忽略频率内容）。

Frequency Scale：选择对音频文件频率进行采样的模型：

  • Logarithmic：对应音乐八度的结构，每个八度代表频率翻倍，类似于音阶的组织方式。
  • Mel：对应人类感知音高差异的非线性方式，适用于语音。
  • Bark：对应人类感知声音的方式，纳入了听觉掩蔽和带宽的概念。
  • Linear：频率区间按线性划分（不做重映射）。

Frequency Range Hz：自定义采样文件时的频率范围。

Equaliser：预览声音文件并隔离频段。使用光标可移除/添加要排除/包含的频段。右侧的按钮可用于启用或停用所有频段。

Frequency Bands：设置要采样的频段数量。

Channel：选择要输出的音频通道：

  • Mono：将立体声通道合并为一个通道输出。
  • Left：输出左声道。
  • Right：输出右声道。

Level Type：当 Mode 设为 Level 时，确定如何输出音轨的峰值电平：

  • RMS：输出在短暂时间段内计算出的最响瞬间。
  • Peak：输出音频信号中最响的瞬间。

Volume Clipping：低于此阈值的数值将被忽略（在均衡器中以红线表示）。

Band Weighting Graph：使用曲线图控制各频段对输出值的贡献，曲线上的位置 P（0..1）代表 Frequency Range Hz（L..H）。值 V 为 0 会移除该频率的贡献，值为 1 会使其贡献加倍。默认值 0.5 将保持数值不变。

A-Weighting：勾选后，将应用 A-weighting，以计入人耳感知的相对响度。

Auto-Normalise：将音轨峰值的输出重映射到 0..1。

Start at Zero：平移输出，使音轨的最低 dB 移至 0 dB，而不像 Auto-Normalise 那样压缩范围。

Value Offset：为输入加上/减去一个值。

Frame Offset：在时间轴上偏移音频播放。

Sub Steps：可用于“平滑”声音信号。值为 0 时，Cavalry 在每个帧编号处对音频文件采样。添加子步后，Cavalry 会采样得更频繁。例如，值为 1 时会在第 0.5、1 和 1.5 帧采样，并取这些值的平均值。

Smoothing Frames：通过增加用于生成采样的帧数来平滑声音信号。例如，值为 2 时将采样当前帧和前一帧，并取这些值的平均值。

性能：

使用 Sub Steps 和 Smoothing Frames 时，预计会有 (smoothingFrames+1)*subSteps 的性能损耗

例如，Smoothing Frames = 2 且 Sub Steps = 4 会对该图层产生 (2 + 1) * 4 = 12x 的时间损耗。

dB Range（输出）：输出连接到 File 属性的素材中的最小和最大 dB 值。

File Length（输出）：连接到 File 属性的素材的时长（以帧为单位）。

Active Bands（输出）：在 Equaliser 中选中的活动频段数量。

Volume Adjustment：增大/减小音轨的音量。注意这是播放控制，不会影响图层输出的强度。

Pan：将音频偏向左（负值）或右（正值）立体声通道。注意这是播放控制，不会影响图层输出的强度。

信息：

注意无法对 Volume Adjustment 或 Pan 属性建立连接。此处所需的任何调整都应使用关键帧驱动。

参见 通用属性。

Advanced

Use Index Context：勾选后，上下文 可传递给其他图层。例如，可用于将每个频段映射到 复制器 中的各个图形。

Play Audio：勾选后，音频将可听见。这相当于在场景树中打开扬声器图标。

示例：

  1. 导入一个音频素材。
  2. 将素材拖入 场景窗口 或 视口 以创建 Sound 行为。
  3. 创建一个图形。
  4. 连接 sound.id→shape.position.y
  5. 增大 Sound 行为的 Strength（取决于音频素材）。
  6. 播放

音频将驱动图形的垂直运动。

信息：

Sound Behaviour 以 dB（分贝）输出，其数值可能因音频素材而异。

合并音频轨道：

使用 行为混合器 合并多个 Sound 行为的输出。

信息：

小心：

使用 Sub Steps 和 Smoothing Frames 时，预计会有 (smoothingFrames+1)*subSteps 的性能损耗

例如，Smoothing Frames = 2 且 Sub Steps = 4 会对该节点产生 (2 + 1) * 4 = 12x 的时间损耗。

旧版：

在 Cavalry 2.8 之前的版本中创建的场景将继续使用旧版 Sound 行为（其图标上有一个黄点标记）。当前版本与旧版 Sound 行为之间无法保证一致性，因此升级场景应手动处理。
