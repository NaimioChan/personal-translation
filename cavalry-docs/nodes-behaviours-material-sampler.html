材质采样器

简介

Material Sampler 会采样一个 Input Shape，然后根据图形的明暗值（亮度/暗度）输出 0-1 之间的值（例如黑色 = 0，白色 = 1）。或者，如果连接到支持颜色的属性（例如 Fill Color），则改为输出颜色。

它可以与着色器结合使用，以控制其他图形的属性，与复制器一起使用时尤为有用。

性能：

Material Sampler 存在一些已知的性能问题，尤其是在采样大量点时（例如复制器）。在处理较多数量的点时，请考虑使用图像采样器。

界面

Common Attributes +

Value：一个乘数。

Input Path：连接一个带有材质的图形，作为采样来源。

Graph：使用曲线图来重新映射输出值。

Offset：为输出值加上/减去一个值。

示例：

  1. 将一张图像导入资源窗口。
  2. 将图像拖入场景窗口（这会创建一个素材图形）。
  3. 创建一个 Material Sampler。
  4. 连接 footageShape.id→materialSampler.inputShape
  5. 创建一个矩形。
  6. 在选中该 Rectangle 的情况下，单击工具架中的 Duplicator 项。
  7. 连接 materialSampler.id→duplicator.shapeScale

图形将根据图像进行缩放。

小心：

Material Sampler 目前不支持 SkSL Shaders，其中包括噪波着色器。

小心：

在 Pre-Comp 中使用时，Material Sampler 目前不支持帧变化。请尽可能改用组而不是合成作为变通方法。
