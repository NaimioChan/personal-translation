依赖关系图

简介

Dependency Graph 是一个窗口，提供合成内部连接关系的交互式示意图或地图。

图层的构成

在 Dependency Graph 中查看时，图层表示为包含属性列表的区块。每个属性的输入和输出连接由“端口”表示，输入在左侧，输出在右侧。

节点会根据类型（int、string、double 等）进行颜色编码。

标题行

标题行包含图层的图标，并从图层的 Label Color 继承其颜色。

点击输出端口会从 Id（输出）连接创建一个连接。

当把连接拖放到此行的输入端口上时，会出现一个菜单，列出可连接的可用属性。

界面

标题栏

Grid Snapping：启用后，图层在重新定位时会吸附到网格。

Show Grid：显示/隐藏背景网格。

Mini-Map：显示/隐藏窗口的 Mini-Map，可用于在图面中导航。

Wire Style：设置图层端口之间连接线的样式：

  • Bézier：在端口之间绘制贝塞尔曲线。
  • Straight：在端口之间绘制直线。
  • Orthogonal：在端口之间绘制肘形连接。

Search：在图面中搜索图层。如果找到图层，视图会更新以将其框选显示。

Bookmarks：保存图面的当前视图。选项：

  • Save Bookmark...：将当前视图位置保存为书签。保存书签后，它会出现在列表中，可用于将视图重置到该书签。
  • Manage Bookmarks...：打开一个弹出窗口，其中列出已保存的书签，可重命名或删除。

Clear Selected：点击以从布局中清除所有所选图层。

Clear all：点击以从布局中清除所有图层。

创建图层

要在 Dependency Graph 中创建图层：

  • 定位光标。
  • 按 Tab 键。
  • 在弹出窗口中滚动或搜索图层。
  • 双击某个图层即可创建。

图层会出现在靠近光标位置的地方。

加载图层

只需将图层从场景树拖放到 Dependency Graph，即可映射其连接。被拖入的图层被视为“根”图层，所有上游图层也会一并添加。

向 Dependency Graph 添加图层时，该图层及相关图层会在网格布局中定位和整理。

双击图层，或在启用 Live Mode 时单击，可将其界面加载到属性编辑器。

要删除图层，选中它并按 Delete 键。注意，这会真正从场景中删除该图层。要仅从布局中移除图层，请使用界面右上角的 Clear Selected 按钮。

连接

创建连接

要在 Dependency Graph 中创建连接，可以：

  • 点击一个图层的输出端口，然后点击另一个图层的输入端口。
  • 在一个图层的输出端口上按住并拖动，然后在另一个图层的输入端口上松开鼠标。

如果图层的属性尚未暴露，右键点击输出 Id 端口会打开可用属性列表。

注意，点击输入的 Id 行时，会出现该图层的属性列表，从列表中选择一个属性即可建立连接。

覆盖现有连接

如果某个属性上已存在连接，尝试向同一属性建立不同的连接会替换现有连接。

删除连接

要删除连接，可以：

  • 选中它，然后按 Delete 键；或
  • 右键点击并选择 Disconnect。

属性表达式

右键点击连接可添加Attribute Expression 或编辑已有的表达式。如果存在属性表达式，连接线上会出现 π 符号。

布局

点击并拖动图层，可在布局中重新定位它。

滚动可放大/缩小视图。

按 F 可使当前图面适配窗口。

布局会随场景一起保存。

背景板

创建一个容器，用于在视觉上对多个图层分组并一起移动。

创建背景板

要创建背景板：

  1. 选择一个或多个图层。
  2. 右键点击并选择 Create Backdrop from Selection。

编辑背景板

  • Rename：要重命名背景板并添加可选描述，可以：
    • 双击背景板内部。
    • 右键点击背景板并选择 Edit Backdrop...。
  • Resize：拖动背景板的边缘或角可调整其大小。
  • Color：右键点击背景板并选择 Set Color，从Label Palette 中选择颜色。

删除背景板

要删除背景板：

  • 右键点击背景板并选择 Delete Backdrop。

不支持的功能：

以下连接目前不会在 Dependency Graph 中显示：

  • 指向自身的连接，例如 position.x→position.y
  • 来自 Composition Settings 的连接，例如 composition.time→noiseBehaviour.time
  • 来自 Render Manager 的连接，例如 renderManager.dynamicIndex→colorArray.index
  • 来自 Scene Palette 的连接。
