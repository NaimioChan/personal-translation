噪波着色器

简介

从 Perlin、Value 或 Cellular 噪波创建连贯的噪波效果。

界面

通用属性 +

Noise Type：选择噪波类型：

  • Perlin Noise
  • Simplex Noise
  • Cellular Noise

Scale：增大/减小噪波的缩放 [x,y]。

Offset：在 x 和 y 方向上偏移噪波的位置。

Minimum：设置噪波的最小值（0 = 黑色）。

Maximum：设置噪波的最大值（1 = 白色）。

Gamma：设置 gamma 校正，其中大于/小于 1 的值会使图层变暗/变亮。

Time：此属性自动连接到合成的帧编号。断开连接即可获得静态噪波。

Time Scale：增大/减小噪波的速度。

Frequency：增大/减小噪波的频率。

Amplitude：乘以 Minimum 和 Maximum 的值。

Cycles：将噪波压缩为平滑重复的图案。将 Octaves 设为 1 通常会产生更可预测的结果。可以使用 Minimum 和/或 Gamma 来增加对比度。

Octaves：计算噪波函数所使用的倍频程数。每个倍频程的频率大约翻倍，即大小为上一个的一半，但可以通过 Lacunarity 控件进行更改。

Lacunarity：较高的值会产生更多或更大的“间隙”。

信息：

Lacunarity 源自拉丁语 lacuna，意为“间隙”或“湖泊”。😉
