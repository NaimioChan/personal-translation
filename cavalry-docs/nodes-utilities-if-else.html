条件判断

简介

根据条件是否成立，在两个结果之间切换。

界面

Condition：一个布尔值，对任何 ≥ 0.5 的值输出 True，对任何 < 0.5 的值输出 False。

True：连接一个图层，当 Condition 为 True 时将其输出。

False：连接一个图层，当 Condition 为 False 时将其输出。

示例：

  1. 创建一个椭圆。
  2. 创建 2 个Scene Palette 颜色（蓝色和绿色）。
  3. 创建一个 If Else 工具。
  4. 将绿色色板连接到 True。
  5. 将蓝色色板连接到 False。
  6. 连接 ellipse.scale.x→ifElse.condition
  7. 连接 ifElse.id→ellipse.fillColor

当缩放值在 0.5 上下变化时，其颜色会在绿色和蓝色之间切换。
