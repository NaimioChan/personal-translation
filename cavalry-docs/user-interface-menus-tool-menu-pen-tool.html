钢笔工具

简介

在视口中绘制可编辑图形。

界面

  • 单击以创建角点。
  • 单击并拖拽以创建贝塞尔点。

信息：

绘制过程中会显示预览路径。

当路径即将闭合时，现有节点上方会出现一个圆圈。

工具设置

有关此工具可用的特定于上下文的选项，请参阅工具设置。

快捷键

快捷键 说明
Cmd/Ctrl + / 清除选中的路径。
S、Escape 或 Return 确认路径并取消选择图形。
G 确认一个轮廓，然后开始绘制另一个。
Shift 绘制时吸附到轴向。
Option/Alt 绘制时在贝塞尔点之后创建直线。
Cmd/Ctrl 禁用吸附（如果已启用）
