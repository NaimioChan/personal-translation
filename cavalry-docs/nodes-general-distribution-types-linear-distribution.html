线性分布

简介

在水平或垂直直线上分布点。

界面

Count - 设置点的数量。

Size - 根据 Size Mode 设置点分布所覆盖的距离。

Direction：

  • Horizontal - 水平分布点。
  • Vertical - 垂直分布点。

Size Mode：

  • Fit - 在 Size 值的范围内分布点。
  • Step - Size 值决定每个点之间的间距。
