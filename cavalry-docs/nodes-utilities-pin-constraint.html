固定约束

简介

在 Forge Dynamics 模拟中将图形固定在其原始位置，同时允许其旋转。图形还可以由 motor 驱动，因此可用于齿轮、轮子或曲轴等概念。

界面

Horizontal Alignment：将约束的位置对齐到 Body 的左边缘（-1）或右边缘（1）。

Vertical Alignment：将约束的位置对齐到 Body 的顶部（1）或底部（-1）边缘。

Motor：勾选后，被固定的图形会获得旋转力。

Motor Speed：设置被固定图形旋转的速度。

Maximum Torque：设置 Motor 的扭矩或力。值越高，被固定的图形越能对抗密度更大的图形。

Limit Rotation：勾选后，约束的旋转永远不会超过或低于 Rotational Limits。

Rotational Limits：设置上限（U）和下限（L）角度，以钳制约束的旋转。

Tension：当该值大于 0 时，约束会以类似弹簧的方式尝试回到其原始角度，值越高弹簧越强。当该值设为 0 时，约束将自由旋转。

Damping Ratio：增加/减小约束旋转“弹簧”的阻尼，其中 0 = 弹跳振荡，1 = 平滑返回且无弹跳。

Breakable：启用后，约束可被其他力打断。

Breaking Mode：设置约束断裂的条件：

  • Force：当力超过 Breaking Force 时，约束将断裂。
  • Distance：当约束移动超出其 Stretch Limit 时，将断裂。
  • Time：当超过 Breaking Force 的力连续保持的帧数超过 Breaking Duration 时，约束将断裂。

Breaking Force：设置使约束断裂所需的力的大小。

Stretch Limit：设置约束在断裂前可被移动的 Rest Length 倍数。例如，如果 Rest Length 为 100，Stretch Limit 为 2，则约束在拉伸至 100 \times 2 = 200 时断裂。

Breaking Duration：设置约束在断裂前必须处于超过 Breaking Force 的力作用下的连续帧数。

Stress Threshold：以 Breaking Force 的百分比设置一个阈值，约束在该阈值范围内将断裂。

示例：

  1. 创建一个 Rectangle。
  2. 将 Width 设为 600，Height 设为 30。
  3. 创建一个 Ellipse。
  4. 将 Ellipse 的 Position 设为 100,400。
  5. 选中两个图形，然后点击工具架中的 Forge 图标。
  6. 在 Forge Dynamics 的 Bodies 标签页下，点击 Rectangle 的齿轮图标。
  7. 点击窗口底部附近 Constraints 属性旁的 +，然后选择 Pin Constraint。
  8. 按播放

Ellipse 会下落并撞到 Rectangle，使其原地旋转。
