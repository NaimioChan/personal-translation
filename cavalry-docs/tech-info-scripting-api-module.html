API 模块

简介

以下 API 全部位于 api 命名空间中。它们仅在JavaScript 编辑器中可用，在JavaScript 图层中编写表达式时则不可用。

此命名空间中的所有命令都必须以 api. 为前缀，例如 api.create("null", "My Null");

该 API 可以与 Web 通信（参见 Web API），并执行 shell 命令。参见下方的 runProcess。

提示：

处理图层和属性时，了解它们的 layerId 和 attrId 很重要。

要查找 layerId：

  1. 在视口、场景窗口或属性编辑器中该图层的标题栏上右键点击该图层。
  2. 选择 Copy Layer Id。

这会将图层的 Id 复制到剪贴板。

要查找 attrId：

  1. 在属性编辑器中右键点击某个属性。
  2. 从上下文菜单中选择 Copy Scripting Path。
  3. 在列表中选择并点击一个选项。

这会将属性的 Id 复制到剪贴板。

这些 Id 随后就可以在脚本中使用。在下面的示例中，basicShape#1 是 layerId，position.x 是 attrId。

api.get("basicShape#1", "position.x");

getAttributeDefinition(layerId:string, attrId:string) → object

返回一个对象，包含某个属性的详细信息。

console.log(definition.type);

返回的对象包含以下键：

  • attrId // 属性的 Id
  • type // 例如 double、string、int2
  • prefix // 界面中使用的前缀
  • placeholder // 字符串属性的占位符（例如 Stroke 的 Dash Pattern 包含 Dash, Gap (e.g. “4, 2“)）
  • isAttrReadOnly // 属性为只读时为 true
  • allowsAspectRatioLocking // 属性的比例可以被约束
  • numericInfo // 一个对象，其中任意子键都可以为 null
    • hardMin // 允许的最小值
    • hardMax // 允许的最大值
    • softMin // 在界面中拖动可设置的最小值
    • softMax // 在界面中拖动可设置的最大值
    • step // 拖动时数值增大/减小的增量
    • isBound // 检查 hardMin 和 hardMax 是否存在，即该属性是一个滑块
  • multiline // 属性为多行字符串时为 true
  • enumValues // 下拉属性的有效索引
  • children // 子属性定义（例如 position 属性有三个子项：x、y 和 z）。
  • isArray // 属性为数组时为 true
  • isCompound // 属性为复合属性时为 true（例如 Graph 属性中的一个点）
  • isDynamic // 该属性为动态属性时为 true（例如 JavaScript 图层中包含 uniforms 的数组）
  • default // 返回该属性的默认值。注意列表/复合属性没有默认值。

setGenerator(layerId:string, attrId:string, type:string)

Cavalry 中的某些图层包含 Generator，它们是用于扩展图层功能的独立功能块。例如 Basic Shape 图层有一个 Generator 来决定它创建的图形（如 Ellipse、Rectangle...）。可以使用此函数设置 Generator。

// Create an Ellipse and set it up


var ellipseId = api.primitive("ellipse", "Ellipse");


api.set(ellipseId, {"generator.radius.x": 10, "generator.radius.y": 10, "hidden": true});


// Create a Duplicator


var duplicatorId = api.create("duplicator", "Duplicator");


// Connect the Ellipse to the Duplicator


api.connect(ellipseId, "id", duplicatorId, "shapes");


// Change the Distribution on the Duplicator to a Custom Distribution


api.setGenerator(duplicatorId, "generator", "circleDistribution");


// Set the Distribution count


api.set(duplicatorId, {"generator.count": 10});

modifyKeyframeTangent(layerId:string, data:object)

修改关键帧切线。传入的对象必须包含 frame 键。除非指定了某一侧手柄且该手柄未被权重和角度锁定，否则入、出两侧手柄都会受影响。

  • inHandle // 一个可选布尔值，用于指定要影响的 inHandle。
  • outHandle // 一个可选布尔值，用于指定要影响的 outHandle。
  • angleLocked // 布尔值，表示关键帧切线是否角度锁定（可选）。
  • weightLocked // 布尔值，表示关键帧切线是否权重锁定（可选）。
  • angle // 为关键帧切线设置新角度，0 为水平（可选）。
  • weight // 为关键帧切线设置新权重（可选）。
  • xValue // 贝塞尔手柄 X 位置（帧）的绝对值。
  • yValue // 贝塞尔手柄 Y 位置（值）的绝对值。

设置水平关键帧的示例：

    api.keyframe(ellipseId, keyTime, {"position.x":value});


    keyTime+=40;


}





// Get the keyframe times


var times = api.getKeyframeTimes(ellipseId,"position.x")


for (let frame of times) {


    // Modify the tangents, giving them all a weight of 20 and an angle of 0 (flat)


    api.modifyKeyframeTangent(ellipseId, {"position.x":{"angle":0, "frame": frame, "weight":20}});


}

getEditablePath(layerId:string, worldSpace:bool) → [object]

此函数返回一个 Editable Path 对象，可对其编辑后再设置回任意 Editable Shape 图层。

Editable Paths 与普通路径（如 Cavalry 模块 中的路径）并不相同。worldSpace 参数可用于决定路径点坐标返回在局部空间——不考虑可编辑图形的位置、旋转与缩放——还是应用了这些变换的世界空间。Editable Path 的点具有入手柄和出手柄，与在视口中编辑的点相同。它们还有权重与角度锁定设置。普通路径使用 moveTo、lineTo 和 cubicTo 构建。在 Editable Path 中，可以向 Contour 的 points 数组添加额外的点。

结构如下：

[


  {


    "points": [


      {


        "position": {


          "x": 0.0,


          "y": 0.0


        },


        "outHandle": {


          "x": 0.0,


          "y": 0.0,


          "selected": bool


        },


        "inHandle": {


          "x": 0.0,


          "y": 0.0,


          "selected": bool


        },


        "weightLocked": bool,


        "angleLocked": bool,


        "selected": bool


      }


    ],


    "isClosed": bool


  }


]

inHandle 和 outHandle 对象是可选的（缺失时会创建线性点）。标记为 bool 的值需为 true 或 false。

var multiplier = 1.5;


var primId = api.primitive("ellipse", "Ellipse");


var editableId = api.makeEditable(primId, false);





var path = api.getEditablePath(editableId, false);


for (let contour of path) {


    for (let point of contour.points) {


        point.inHandle.x *= multiplier;


        point.outHandle.x *= multiplier;


        point.inHandle.y *= multiplier;


        point.outHandle.y *= multiplier;


    }


}


api.setEditablePath(editableId, true, path);

setEditablePath(layerId:string, worldSpace:bool, pathObject:object)

这会在可编辑图形上设置可编辑路径（不支持图元）。有关可编辑路径结构的详细信息，请参阅 getEditablePath。worldSpace 参数将决定路径点坐标设置于局部空间——不考虑可编辑图形的位置、旋转与缩放——还是应用了这些变换的世界空间。如果以世界空间访问可编辑路径，也应将其以世界空间设置。

调色板

Cavalry 有两种相关但不同的调色板：

  • Scene Palette 是位于当前场景内部的 colorArray 图层。把材质连接到其中的色样后，更改一个色样就会更新下游的每个图层。改动可撤销，并随 .cv 文件保存。
  • 文件调色板是用户库调色板文件夹或当前项目调色板文件夹中的 .pal、.ase 或 .theme 文件。它们可跨场景保留；改动会直接写入磁盘，且不可撤销。

下面的函数涵盖这两者。Scene Palette 辅助函数（getScenePalette、addSceneSwatch、removeSceneSwatch）作用于场景级节点。其余函数读写磁盘上的 .pal 文件；其 scope 参数为 "library" 或 "project"，在可选时默认同时搜索两个层级——先搜索库。

返回 Scene Palette 的 layerId。Scene Palette 是一个 colorArray 图层，保存着场景内共享的色样。配合 addSceneSwatch 和 removeSceneSwatch 管理色样，再用 api.connect 把 <paletteId>.array.<index> 连接到材质的 materialColor，即可用一个色样驱动多个图形。

console.log(api.getNiceName(paletteId));

向 Scene Palette 添加一个色样并返回其数组索引。color 是 Cavalry 能解析的任意字符串（例如 "#ff2266"、"red"）。可选的 name 是色样标签；省略时会根据最接近的命名颜色生成名称。

// Drive a Shape's fill from the swatch.

插件

这些函数用于自动化安装和编写第三方插件（以包含 definitions.json 和 strings.json 的文件夹形式提供的自定义图层、滤镜和着色器）。它们会把文件放到 getThirdPartyPluginsFolder 下。

警告：

插件安装会改动用户的整个环境，而不只是当前场景。在脚本中调用 installPlugin 或 writePluginFile 前，请务必先与用户确认。

installPlugin(sourcePath:string) → object

把插件文件夹或 .zip 安装到用户的第三方插件文件夹，并将其定义与字符串注册到当前会话中。返回的对象包含：

  • ok（bool）——安装是否成功。
  • installedPath（string）——目标文件夹。
  • registeredTypes（string 数组）——新注册的 nodeType。
  • wasUpdate（bool）——若匹配到并更新了已有定义则为 true。
  • requiresRestart（bool）——改变架构的更新只有在 Cavalry 重启后才生效，因为场景中已存在的实例依赖先前的属性布局。仅源码改动（.sksl、.js）会在下次创建实例时生效。
  • error（string）——当 ok 为 false 时的说明。
var result = api.installPlugin("/path/to/MyPlugin");

    console.log("Installed " + result.registeredTypes.length + " Layer types at " + result.installedPath);


    if (result.requiresRestart) {


        console.log("Restart Cavalry for schema changes to take effect.");


    }


} else {


    console.log("Install failed: " + result.error);


}

Timer(callback:object)

定时器可用于 UI 脚本，在轮询 Web API 时很有用。定时器触发时会调用定时器对象上的 onTimeout() 函数。实现此函数，即可让定时器在触发时执行逻辑。

函数：

  • start() // 启动定时器。
  • stop() // 停止定时器。
  • isActive() // 返回定时器当前是否正在运行。
  • setInterval(interval:int) // 设置定时器的时长（以毫秒为单位）。
  • setRepeating(repeat:bool) // 设置定时器是否重复（默认为 true）。
  • onTimeout() // 在定时器对象上实现此回调函数，定时器到期时它会被调用。
// Define a callback class to be used by the timer


function Callbacks() {


    // This callback will be called whenever the timer times out


    this.onTimeout = function () {


        console.log("Timer Expired");


    }


}





// Create the callback class


var callbackObj = new Callbacks();





// Make the timer and feed it the callback object


var timer = new api.Timer(callbackObj);
