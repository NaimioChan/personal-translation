2.4.1 发行说明

发布日期：2025年5月13日

重要缺陷修复

  • Viewport Quality = Balanced 性能自 Cavalry 2.3.2 起出现回退。此修复应使所有模式下的 Viewport 渲染都略微加快。
  • 图像转图形 现在在 Windows 上恢复可用。
  • 在 Windows 上，如果 @project/Assets/Palettes/ 目录为空，点击 颜色窗口 中的 Project 调色板标签页不再触发崩溃。
  • 已恢复对 .ase 导入的支持。
  • 在 依赖关系图 中连接到“generator”（例如 Fill Color）时，UI 现在会正确更新。
  • 从 依赖关系图 删除某些图层时不再触发崩溃。
  • 背景模糊滤镜 再次支持 Blur Shape 的世界变换。
  • 已恢复 .psd 资源支持。
  • 交错 行为不再向控制台输出（无害的）警告。
  • ui.Modal 不再对两个按钮/选项都返回 false。
