图形数组

简介

创建一个图形列表（图形/合成/组），可通过索引将它们指定给其他图层。

界面

Auto Index：自动输出数组中的所有索引。

Index：手动输出数组中的一个索引（取消勾选 Auto Index 后可启用）。

Reverse：反转索引的输出顺序。例如，有 3 个索引 0,1,2 时，它们的顺序会反转为 2,1,0。

Count：输出数组中的索引数量。

Add

0: Shape：数组中的第一个索引。把图形、合成或组拖入此属性。

示例：

  1. 创建 3 个不同的图形。
  2. 创建一个 Shape Array。
  3. 点击 Add
  4. 将每个 Shape 连接到 Shape Array 上的对应索引。
  5. 创建一个 自定义图形。
  6. 连接 shapeArray.id→customShape.inputShape
  7. 选中该 Custom Shape，点击 工具架 中的 复制器 图标。

双击设置 Index：

双击某个索引所在的行，就会把 Index 设为该值。
