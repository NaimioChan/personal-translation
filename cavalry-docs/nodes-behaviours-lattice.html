晶格变形器

简介

使用灵活的控制点网格来变形图形。

界面

Common Attributes +

Grid Count：设置晶格网格的控制点数量。

Triangulate：勾选后，所连接的图形也会被三角化，以支持纹理变形。

Deformers：连接一个行为，以对晶格点进行“逐点”操控。

Controllers：连接一个晶格控制器，可用于操控多个晶格点的位置、旋转和缩放。

按钮

  • Reset Lattice：将所有晶格点恢复到其原始网格位置。
  • Keyframe Selection：为选中的晶格点添加关键帧。
  • Add Controller to Selection：添加一个晶格控制器，可用于平移当前选中的晶格点。

图层工具

在选中 Lattice 图层并激活选择工具的情况下，视口中会显示一个图层工具。

要选择晶格点，可以：

  • 单击选择。
  • 按住 Cmd/Ctrl 并单击各个点，将其加入选择。
  • 框选多个点。
  • 按住 Option/Alt 并围绕点位绘制圈选，以选择它们。

选中多个点时，会出现一个可用于移动它们的操纵器。

视口吸附

Lattice 的图层工具遵循视口吸附。在选中多个点并使用操纵器时，将使用最后选中的点进行吸附。也可以单击选择中的某个特定点并拖动它，以使用该点进行吸附。
