边缘扭曲滤镜

简介

使用着色器扭曲图形的边缘。

界面

通用属性 +

Filter

Border：扭曲宽度，单位为像素。

Amplitude：像素可位移的最大值。

Edge Sharpness：控制扭曲融入图形的方式。

Direction：

  • Both：将像素推向图形的内外两侧。
  • Outward：仅将像素推向图形外侧。
  • Inward：仅将像素推向图形内侧。

Shader

Show Preview：在视口中沿图形的边缘预览 Input Shader。

Preview Opacity：设置预览的不透明度。

Input Shader：选择用于扭曲的着色器。
