JavaScript 工具

简介

JavaScript Utility 可用于设置属性、创建自定义模拟、分布等。

关于如何在所有 JavaScript 图层中使用 JavaScript 的更多信息，请参阅JavaScript 图层。

查看 JavaScript 图层→

界面

Expression Window：在此处输入 JavaScript 表达式。

+ Button：添加一个新变量。

n0：一个默认的（双精度）变量。

示例：

用 JavaScript 制作一个字符串数组。

  1. 创建一个文本图形。
  2. 选中 Text Shape，点击工具架中的 Duplicator 图标。
  3. 创建一个 JavaScript Utility。
  4. 将以下内容复制并粘贴到表达式窗口中。
var animation = [

  "2d",

  "3d",

  "Cel"

];

animation[ctx.index]
  1. 连接 javaScript.id > text.string

复制器中的前三个文本图形将分别显示 2d、3d 和 Cel。

为了循环使用数组中的每个索引，将最后一行改为 animation[ctx.index % animation.length]

可以通过在字符串中添加 \n 来换行。例如 2d\nrules 将输出：

2d

rules
