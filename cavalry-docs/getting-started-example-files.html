示例文件

简介

下载精选的示例场景文件，开始在 Cavalry 中创作。以下所有示例均可通过 Scenery 下载，这是一个涵盖 Cavalry 各方面的社区。

示例

文本、睡眠、重复

这里使用一个文本图形和一个设为 Transition 的字符串操纵器。拖动 Percentage 时，文本图形上的字符串会过渡到操纵器 Final Text 中输入的字符串。字符串数组用于通过复制器创建多行文本。将组用作复制器的 Input Shape 后，彩色背景也会被复制，并调整以适配文本的宽度。

低频率

一个线条图形连接到一个复制器。然后使用一个振荡器作为线条上的变形器（勾选 Use Normals）。接着将一个交错连接到振荡器的 Frequency，以偏移每条线。查看这个教程，了解如何在一分钟内完成搭建。

Concentrick

将一个圆形用作复制器的 Input Shape，并将其 Distribution 设为 Point。然后使用交错行为对每个复制圆形的 Radius 进行交错。接着将一个振荡器连接到复制器的 Shape Position。拖动振荡器上的 Stagger 值即可改变效果。

Mazin

一个基本线条（旋转 45º）位于组之下（因为复制器会忽略顶层图形的变换）。然后将该组添加到复制器中。接着使用一个值为 0 和 90 的值数组，以及一个值行为（带有衰减）连接到它的 Array Index。衰减在这两个值之间起到开关作用。还有一个JS Math 节点用于在线条的 Length 与网格分布的 Size 属性之间建立关系。这其实并非必需，但意味着当线条长度改变时，分布尺寸也会更新。😎

Joy Rig

这是我们的绑定控制和关键帧图层功能演示。最好查看这些链接，了解它们如何组合在一起。😉

Ring Ting

使用复制器将圆点排列成一个环。路径分布的 Input Path（一个圆形）随后被噪波行为变形。然后使用衰减确定 Noise 的强度。

互锁

一个弧形通过点分布复制，并使用值数组指定它们的旋转角度，使它们彼此相对放置。该复制器随后进入第二个复制器，形成一个简单图案，再通过 Shape Rotation 属性为其制作动画。动画曲线在曲线编辑器中设为 Loop with Offset。

聚焦

圆形带有一个渐变着色器（设为 Conical），并使用 Overlay 混合模式。它还带有一个模糊滤镜，其 Amount 连接了一个振荡器。试着调整振荡器上的 Stagger 属性来改变偏移值。

视错觉艺术

小心你的 👀！圆形被另一个圆形（遮罩）遮罩。然后 Mask 的 Position.x 连接到一个交错行为。接着使用一个振荡器为交错行为的 Maximum 属性制作动画。一个复制器创建水平布局，另一个则将它们垂直堆叠。然后使用一个连接到垂直复制器 Shape Rotation 的调制，创建 (0,180) 的图案，使各行交替翻转。

按钮

一个使用 Cavalry 制作界面元素草图的示例。一个值2 连接到投影滤镜的 Offset。该 Value 2 添加了一个衰减。衰减范围内的对象会接收该 Value，范围外的则不会（注意我们添加了 2 的 Offset，以确保始终有一些阴影）。将衰减依次移过每个图形，就能营造出按钮被按下的错觉。

看

矩形通过一个帧经由另一个帧进行旋转。随后使用路径分布沿一个矩形（路径）进行复制。注意矩形上勾选了 Vectorise 并设置了一些 Edge Divisions。这会将圆角从贝塞尔曲线转换为“线段”，以改善噪波产生的变形效果。

昼与夜

这个示例更接近于一个“绑定”。空对象通过一些值和值2 行为连接到各个图层。它们被用作乘数，分别控制遮罩（月亮）的 Position、线条（太阳）的 Length、复制器（星星）的 Count 以及 Color（天空）。左右移动空对象，场景就会从夜晚过渡到白天。注意空对象的 position.y 通过 Limit Position 属性被“锁定”。灵感来自这篇文章。

四叉树

通过子网格分布和四叉树图形进行复制，以定位和缩放其他合成。这个示例还展示了如何通过噪波和随机行为改变 3 个输入图形来创造复杂性。

数据

将一个矩形和文本图形编组（Items），然后添加到一个复制器，其分布设为线性分布。接着导入一个Google Sheet，并连接到 3 个独立的电子表格工具。然后在每个电子表格上分别为 Label、Value 和 Color 设置 Column Title（即所链接 Google Sheet 第一行中的名称）。每个电子表格分别链接到条形图的 Height 和 Color，以及标签的 Text。注意 Value 电子表格使用数值范围进行了重新映射，以将数据中相对较大的数值转换为适合合成的值。一个对齐行为连接到条形图的 Deformer 属性，使其底部保持在原位。
