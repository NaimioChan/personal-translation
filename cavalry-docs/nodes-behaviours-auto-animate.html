自动动画

简介

只需少量关键帧，就能为图形添加各种动画。

界面

Animation

Progress Mode：选择模式。

  • Single Progress Control：使用一个 Progress 属性控制所有选项的动画。
  • Precise Progress Controls：使用各自的 Progress 属性分别控制每个选项的动画。

Progress：使用关键帧控制动画的速度和样式。达到 100% 时，图形的动画完成。默认会为 0% 和 100% 添加关键帧，并对第一个关键帧应用Magic Easing。

Position Mode：选择位置动画的类型。

  • None：无位置动画。
  • Slide from Composition Edges：图形会被定位为从合成边缘之外开始动画。
  • Drift：基于 Drift Angle and Distance，从图形的原始位置开始动画。
  • Zoom：让图形朝向或远离视口进行动画。

Direction：选择从合成边缘滑入的方向：

  • Left：从合成左边缘之外移入动画。
  • Right：从合成右边缘之外移入动画。
  • Top：从合成上边缘之外移入动画。
  • Bottom：从合成下边缘之外移入动画。

Drift Angle and Distance：为 Drift 设置角度和距离。

Zoom Distance：为 Zoom 设置距离。使用负值可让图形从远离视口的位置开始。

Alternate Direction：当 Position Mode 设为 Drift 且勾选 Use Levels 时，子网格（如文本图形或复制器）中交替的路径会从相反方向进行动画。

Rotation Mode：选择旋转动画的类型。

  • Spin：让子网格围绕其中心旋转 180°。
  • Swing from Left：让子网格以其左边缘为轴旋转 90°。
  • Swing from Right：让子网格以其右边缘为轴旋转 90°。
  • Swing from Top：让子网格以其上边缘为轴旋转 90°。
  • Swing from Bottom：让子网格以其下边缘为轴旋转 90°。
  • Swing from Centre (horizontal)：让子网格围绕其水平中心旋转 90°。
  • Swing from Centre (vertical)：让子网格围绕其垂直中心旋转 90°。

Reverse Rotation Angle：反转子网格的旋转方向。

Zoom：设置产生 2.5D 效果的虚拟相机的缩放。

Scale Mode：选择缩放动画的类型。

  • None：不缩放。
  • Scale Up：将子网格从 0 缩放到 1。
  • Scale Down：将子网格从 1 缩放到 0。

Scale From：设置缩放的起始位置。

  • Path Pivot Point：从子网格的轴心点缩放。
  • Path Centre：从子网格的中心缩放。
  • Layer Pivot：从子网格所属图层的轴心点缩放。

Opacity Mode：选择不透明度动画的类型。

  • None：不淡入淡出。
  • Fade Up：将不透明度从 0 动画到 100。
  • Fade Down：将不透明度从 100 动画到 0。

Visibility Mode：选择可见性动画的类型。

  • None：不制作可见性动画。
  • Appear：子网格从不可见开始，然后出现。
  • Disappear：子网格从可见开始，然后消失。

Use Levels：勾选后，子网格可被独立影响。使用 Timing 标签页中的选项调整动画。

Level Mode：选择要影响网格的哪些层级。

  • Custom...：手动设置 Custom Level Range。
  • Text (Lines)：与文本图形一起使用时，这将影响每一行。
  • Text (Words)：与文本图形一起使用时，这将影响每一个单词。
  • Text (Characters)：与文本图形一起使用时，这将影响每一个字符。

信息：

Level Mode 提供了若干旨在简化文本处理工作的设置。例如，Text (Words) 模式会将内部的 Custom Level Range 值设为 2, 2。这些设置会影响文本图形中的任何单词，同样的设置对 SVG 图形也可能有效。

Custom Level：设置要影响的网格层级结构中的层级。

Timing

Time Offset：勾选后，每个子网格会依据 Time Offset 在时间上交错。要自定义该效果，请取消勾选，并将例如随机行为连接到 Time Offset。

Animation Time Offset：以“每个子网格”为单位偏移动画曲线。使用负值可确保第一个子网格与 0% Progress 关键帧在同一帧开始动画。

Timing Mode：选择决定子网格动画顺序的模式。

  • Normal：动画顺序为从第一个到最后一个。
  • Random：动画顺序为随机。
  • Middle Out：动画从中间开始，向外推进。

Random Seed：勾选且 Timing Mode 为 Random 时，打乱每个子网格的动画顺序。

Reverse：勾选后，反转每个子网格的动画顺序。

Group by Parent：勾选后，动画按父级网格分组。例如，与文本一起使用且 Levels 设为 Character 时，效果是按单词对动画分组（单词是字符的父级）。这会使字符动画按每个单词分组。

Parent Timing Mode：选择决定父级网格动画顺序的模式。

  • Normal：动画顺序为从第一个到最后一个。
  • Random：动画顺序为随机。
  • Middle Out：动画从中间开始，向外推进。

Random Seed：勾选且 Parent Timing Mode 为 Random 时，打乱每个父级网格的动画顺序。

Reverse Parent Order：勾选后，反转每个父级网格的动画顺序。

Align Animation：将自动动画的动画对齐到每个所连接图层的入点或出点，这意味着同一个自动动画可用于多个图层，即使它们在时间上处于不同位置。

  • None：无偏移。
  • Start at In Frame：让动画在入帧开始。可以把所有关键帧看作一个块，其中第一个关键帧与图形片段的入点左对齐。
  • Finish at Out Frame：让动画在出帧结束。可以把所有关键帧看作一个块，其中最后一个关键帧与图形片段的出点右对齐。

示例：

  1. 创建一个文本图形。
  2. 点击工具架中的 Auto-Animate 按钮。
  3. 按下播放。

请注意，使用工具架向子网格（例如文本图形）添加自动动画时，Use Levels 属性会自动勾选。
