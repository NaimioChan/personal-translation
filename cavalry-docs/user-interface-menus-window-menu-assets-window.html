资源窗口

简介

Assets Window是添加和组织外部资源与合成的地方。

导入资源的方式有以下几种：

  • File > Import Asset...
  • 在资源窗口中双击。
  • 在窗口的空白处右键单击，然后从以下选项中选择：
    • Import Assets...：从文件系统导入任何受支持的文件类型。
    • Import Reference...：将另一个 .cv 文件作为引用导入。
    • Import Scene...：导入 Cavalry 场景（.cv 或 .cvc）。导入 .cv 会导入整个场景（包括其中的所有资源）并将其添加到一个组中。导入 .cvc 文件则会将文件内容添加到当前合成中。
    • Import Canva Sheet...：导入Canva 表格资源。
    • Import Google Sheet...：导入Google 表格资源。
    • Import Image Smart Folder...：导入图像智能文件夹。
    • Import Audio Smart Folder...：导入音频智能文件夹。
  • 将受支持的资源从文件系统拖入窗口中。

将受支持的资源从文件系统拖入视口，也会把这些资源添加到资源窗口中。以这种方式导入图像或视频时，还会创建一个素材图形并将其连接到该资源。

支持的文件类型：

  • Audio
    • .aac
    • .aif
    • .aiff
    • .caf
    • .mp3
    • .wav

包含音频的视频：

当视频包含音频时，音频轨道会作为视频的子级导入到资源窗口。这意味着如有需要，视频和/或音频轨道可以单独使用。将与音频配套的视频添加到合成时，会创建一个层级结构，其中素材图形作为图像着色器和声音行为的父级，这意味着如有需要，音频可以相对视频进行偏移。

  • Font
    • .otc
    • .otf
    • .ttf
  • Image/Image Sequence
    • .af（Affinity）：参见Affinity 资源。
    • .bmp
    • .exr（仅单通道）
    • .ico
    • .jpg
    • .png
    • .psd（仅拼合图像）
    • .webp
  • Movie
    • .apng（动画 png 通常使用 .png 文件扩展名。将其改为 .apng 才会被识别为影片。）
    • .gif
    • .mov
    • .mp4
    • .webm
  • Scene
    • .cv：将 .cv 文件作为引用导入。
  • Spreadsheet
    • .csv
    • Canva 表格：参见Canva 表格资源。
    • Google 表格：参见Google 表格资源。
    • .xslx
  • SVG
    • .svg
  • Text
    • .txt
    • .json

视频格式支持以下编解码器：

  • VP8、VP9、AV1。
  • H.263、H.264、H.265（HVEC）。
  • MPEG-4。
  • ProRes（422、422 HQ、422 LT、422 Proxy、4444、4444 XQ）、Motion JPEG、Uncompressed 422。

最大分辨率：

图像资源支持的最大分辨率为 15360 × 8640px。

界面

顶部栏

Search Bar：使用搜索栏筛选显示的项目。

Sort Order：决定项目的排序方式：

  • None：可通过拖放在层级中手动组织项目。从 None 切换到 Name/Type 再切回 None 时，该顺序会被保存并恢复。
  • Name：项目按其名称以升序字母顺序（A-Z、0-9）排列。
  • Type：项目按其资源类型分组。注意分组依据是“类型”（Audio、Audio Smart Folder、Composition、Font、Group、Image、Image Sequence、Image Smart Folder、Movie、Spreadsheet、SVG、Text），而不是“文件扩展名”。

信息：

当 Sort Order 设为 Name 或 Type 时，无法手动重新排序（拖放），但仍可通过选中项目并使用 Cmd/Ctrl + G 快捷键来编组项目。

主窗口

项目以层级形式显示，包含用于表示其“资源类型”的图标、名称和自定义标签（取决于资源类型）。出于组织管理目的，还可以从当前的标签调色板中为项目指定颜色。

重命名项目：

  1. 选中一个项目。
  2. 按下 Return。
  3. 输入新名称。
  4. 再次按下 Return，或取消选中该项目以提交更改。

预览：

将光标悬停在某一行上可加载资源或合成的预览。支持的资源类型有 image、movie（显示第一帧）、CSV/Google Sheets、Text/JSON 和 SVG。

底部栏

项目设置。

Cmd/Ctrl + G 快捷键，创建一个包含所选项目的新文件夹。

向场景添加合成。右键单击可使用预设创建新合成。将图像资源拖到该按钮上，会创建一个新的父合成，其 Resolution 设为该图像的分辨率。将合成或视频资源拖到该按钮上，会创建一个父合成，并从该合成/视频继承其 Resolution、Frame Rate 和 Frame Range。
