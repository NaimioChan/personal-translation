色度键滤镜

简介

使用高级遮罩控制从视频/图像中移除绿幕/蓝幕。

界面

通用属性 +

View：选择在视口中渲染的内容：

  • Final Result：带透明度的合成结果。
  • Source：未经处理的原始图像。
  • Alpha：以灰度显示的透明度通道。
  • Status：诊断视图，其中红色 = 透明，绿色 = 不透明，黄色 = 边缘。

Screen Color：要变为透明的颜色（通常是绿色或蓝色背景）。使用取色器从图像中选择颜色。纯黑色将不会产生抠像。

Screen Gain：控制颜色被抠除的程度。较高的值会移除更多背景。

Screen Balance：调整颜色饱和度的测量方式。0.0 = 使用其他通道的最大值，0.5 = 使用平均值（绿幕），1.0 = 使用最小值（蓝幕）。

Shadow Tolerance：确定屏幕颜色的变体可以暗多少仍被纳入遮罩。这有助于移除投射在背景上的阴影。

Shadow Softness：控制阴影内外区域之间的过渡。较高的值会产生更平滑的过渡。

Alpha Bias：调整偏置，以减少前景/主体的透明度。使用取色器从图像中选择颜色。

Use Alpha Bias for Despill：勾选后，Alpha Bias 颜色将用于影响去溢色计算。

Despill Bias：移除遮罩边缘的溢色。选取头发或肤色的颜色通常能获得最佳效果。

Despill Strength：控制去溢色的整体强度。较低的值用于细微的去溢色，较高的值用于强力移除。

Pre-Blur：在抠像前模糊输入图像，以减少噪点/颗粒。这不会影响输出。

Detail Recovery：恢复可能被错误抠除的精细细节，如发丝。使用边缘检测和颜色分析来识别应保持不透明的区域，其中 0 = 不恢复，1 = 最大恢复。

Edge Softness：控制遮罩边缘的柔和程度，其中 0 = 硬边，1 = 非常柔和的边缘，以帮助在不透明与透明像素之间创建更平滑的过渡。

Clip Black：设置透明截止值。低于该值的遮罩值将变为完全透明。请谨慎使用以避免硬边。

Clip White：设置不透明截止值。高于该值的遮罩值将变为完全不透明。请谨慎使用以避免硬边。

Clip Rollback：通过恢复部分边缘细节来柔化裁切效果。较高的值会恢复更多原始遮罩。

Screen Dilate：扩展或收缩遮罩边缘。请谨慎使用，过度侵蚀会产生糟糕的遮罩。

Screen Softness：模糊遮罩边缘，以获得更平滑的合成。这仅影响边缘，不影响实心区域。建议使用较小的值。

Despot Black：移除不透明区域中孤立的透明斑点，以清理前景/主体内可能出现的小孔洞。

Despot White：移除透明区域中孤立的不透明斑点，以清理背景内可能出现的小孔洞。

Screen Replace：确定使用“Despill”进行高级颜色校正时，前景/主体中颜色的替换方式。

Replace Color：设置用于替换前景/主体中任何溢色的颜色。设为前景/主体的主要颜色（如肤色或织物色）可获得最佳效果。

Shadow Gain：调整遮罩暗部的对比度。较高的值使阴影更不透明。

Midtones Gain：调整遮罩中间调的对比度。较高的值改善边缘清晰度。

Highlights Gain：调整遮罩亮部的对比度。较高的值使高光更不透明。
