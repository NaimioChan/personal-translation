获取名称

简介

获取图层的“显示名称”，并以字符串形式输出。

界面

Input：连接要“获取”名称的图层。

示例：

  1. 创建一个基本图形。
  2. 将其重命名为 My Layer。
  3. 创建一个 Get Name。
  4. 连接 basicShape.id→getName.input
  5. 创建一个文本图形。
  6. 连接 getName.id→textShape.text

文本图形将在视口中显示 My Layer。
