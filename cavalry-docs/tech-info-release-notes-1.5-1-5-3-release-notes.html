1.5.3 版本说明

发布日期：2023年3月30日

1.5 版本说明→

新功能

常规

  • Edit menu 现在包含 Duplicate and Split 选项。

行为

  • 颜色混合 现在有新的 HSV interpolation 选项。

工具

  • Comparison Utility：对数值执行简单的比较运算。
  • Logic Utility：对布尔值执行简单的逻辑运算（AND、OR、XOR）。
  • Contrasting Color Utility：输出与输入颜色形成对比的颜色。
  • 索引转颜色 现在有新的 HSV interpolation 选项。

效果

  • 渐变映射滤镜：根据输入的亮度生成渐变。
  • Voronoi 着色器：通过计算点阵之间的距离生成细胞图案。
  • 渐变着色器 现在有新的 HSV interpolation 选项。

脚本

API 模块

  • convertSVGToLayers()：将 SVG 文件转换为图层，无需先将该 SVG 导入为资源。
  • getFileNameFromPath() 现在有一个可选的文件扩展名参数。
  • sceneHasUnsavedChanges()：如果上次保存以来场景有任何改动，则返回 true。
  • saveScene 和 saveSceneAs 现在都会返回结果以确认成功/失败。
  • deleteFilePath：从文件系统中删除文件。

增强

  • Move/Jump 和 Go to Keyframe 已添加到 Shortcut Manager。
  • 按住 alt/opt 并单击属性编辑器中的展开箭头，现在会打开/关闭所有图层（这实际上是 2018 年某个极早期 beta 版本遗留的回归问题！）。
  • 将图层拖入 Tag Drawer 中的空白区域会创建一个新标签，并将拖入的图层分配给它。该标签以第一个选中的图层命名。

重要错误修复

  • 通过双击方式在曲线编辑器中添加新关键帧时，动画曲线现在能更好地保留。
  • 设置 绑定控制 时的数值现在会在属性编辑器和场景窗口中正确更新。
  • 改进了文本 Material/Style Behaviours 的 Regex 搜索。
  • Web API：post 现在支持添加请求头。
  • Web API：post 不再返回“以 null 结尾的字符串”。
  • 已解决使用 Animation Layer Filter 隔离图层时，场景树与时间编辑器之间的一些垂直错位。

说明

  • 图形转着色器 因兼容性问题已从界面中隐藏。旧场景不受影响。
