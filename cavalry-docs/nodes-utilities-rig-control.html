绑定控制

简介

一个 2D 控制器（也可称为摇杆），可用于基于姿势的绑定。

关键帧图层：

Rig Control 使用专用的关键帧图层为各姿势设置关键帧，这样设置姿势时不会影响主时间轴。

界面

Active：切换 Control 模式。

Control：此界面取决于 Active 状态：

  • Active unchecked：这是搭建绑定的模式。摇杆上的五个圆点代表搭建绑定所需的五个关键帧。点击每个圆点会将时间轴移动到相应的帧：
    • Centre（中立姿势）：第 0 帧
    • Left：第 1 帧
    • Right：第 2 帧
    • Top：第 3 帧
    • Bottom：第 4 帧
  • Active checked：这是为绑定设置动画的模式。移动圆点会在 Inactive mode 中设置的各姿势之间过渡。

示例：

  1. 创建一个 基本图形 和一个 Rig Control。
  2. 连接 rigControl.id→basicShape.position
  3. 将自动创建一个新的关键帧图层，并在第 0-4 帧为你设置 5 个关键帧。
  4. 在 Basic Shape 上为 Position [x,y] 设置以下关键帧：
  5. 第 0 帧 = 0, 0
  6. 第 1 帧 = -50, 0
  7. 第 2 帧 = 50, 0
  8. 第 3 帧 = 0, 50
  9. 第 4 帧 = 0, -50
  10. 在 Rig Control 上勾选 Active。
  11. 移动 Control 上的圆点。
  12. 要为绑定设置动画，请将关键帧图层设为 Default，并使用 x、y 控件设置关键帧。

参见示例文件中的演示场景。
