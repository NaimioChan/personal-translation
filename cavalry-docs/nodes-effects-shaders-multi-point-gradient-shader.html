多点渐变着色器

简介

通过为多个点设置位置、颜色和影响，创建复杂的渐变。

界面

通用属性 +

Premultiply：勾选后，透明像素的计算会采用预乘。

Gradient Mode：为 Gradient 选择一种插值方式。参见渐变。

+ Add（按钮）：向渐变添加一个新点。

每个点包含以下属性：

  • Color：为该点设置颜色。
  • Position：为该点设置位置。
  • Influence：确定该点的影响强度。
  • Jitter：根据强度为插值曲线添加噪波。抖动将添加在所选色标与其右侧的下一个色标之间。

从调色板创建色标：

Multi-Point Gradient Shader 的色标可以通过颜色窗口中展开菜单里的 Set Gradient from Palette 选项来设置。选中一个 Multi-Point Gradient Shader 图层，然后运行该命令。创建的色标将根据合成的分辨率随机定位。

图层工具

各个点可以在视口中使用选择工具进行操作。当在场景窗口中选中 Multi-Point Gradient Shader 时，视口中会出现小的紫色圆点。

  • 移动点：单击并拖动一个紫色圆点。
  • 复制点：按住 Option/Alt + 单击并拖动一个紫色圆点。
  • 增大/减小点的影响：按住 Shift + 单击并拖动一个紫色圆点。
  • 删除点：选中一个紫色圆点并按 Delete 键。
  • 更改点的颜色：双击一个紫色圆点并在弹出的颜色编辑器中调整该点的颜色，或者从颜色窗口拖动色板并将其放到紫色圆点上。

提示：

按 Escape 关闭 Color Editor 窗口，以保持选中状态。

信息：

如果同一个 Multi-Point Gradient Shader 连接到了多个图形/输出，则使用第一个连接来定位视口中的紫色圆点。可以点击场景窗口或属性编辑器中 Multi-Point Gradient Shader 的紫色输出连接图标，并选择所出现列表中的最底层，以确认这一点。

小心：

如果 Multi-Point Gradient Shader 连接到混合着色器，则 Layer Tool 不可用。
