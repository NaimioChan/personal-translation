2.4.2 发行说明

发布日期：2025年6月10日

新功能

脚本

API

  • isProLayerType()
  • isRestrictedLicence()

增强

  • 新增 UI affordance，用于指示某属性已添加到 控制中心。
  • 从智能文件夹获取资源 在其 Mode 设为 Auto Index 时现在会循环。
  • Attribute Editor 中输入列表（例如 Duplicator 的 Input Shapes）的重新排序已改进。连接弹出框也已更新，但这纯粹是外观调整。
  • 在 Time Editor、Attribute Editor 和/或 Dependency Graph 中进行选择时，现在可以用方向键在 Viewport 中移动图形（Scene Tree 中原本已支持）。
  • api.modifyKeyframeTangent 现在包含新的 xValue 和 yValue 键

重要缺陷修复

  • Integer 和 boolean 关键帧在 曲线编辑器 中移动时现在会吸附到整数值。
  • 从 资源窗口 删除合成时，如果“下一个活动合成”位于某个文件夹中，它不再被从该文件夹中移除。
  • 属性编辑器 现在会筛选图形 Fill 或 Stroke 标签页内的属性。
  • 撤销对 Scene Palette 色板颜色的更改后，色板现在会正确更新。
  • 已解决 Color Window 和调色板不更新的多个问题。
  • Edit > Duplicate (Options) 对话框不再破坏按钮布局。
  • cavalry.hexToRgba() 现在期望以 Hex+A 格式接收十六进制输入
  • ui.colorChip() 和 ui.setBackgroundColor() 现在期望以 Hex+A 格式接收十六进制输入。
  • ui.getColorWithAlpha() 现在返回 Hex+A
  • 在 welcome.js 中为插件使用 ui.scriptLocation() 时，现在返回插件所在的父文件夹。
  • 导致 Demo Scenes > JavaScript > Line Chart 示例无法运行的 mesh.childMeshCount() 和 mesh.getChildMeshAtIndex 问题已解决。
  • 修复了将 Random Behaviour 的 Minimum 和 Maximum 设为相同值时未输出该值的问题。
  • 如果首/尾关键帧的手柄使得生成的动画曲线高于/低于关键帧，现在在 曲线编辑器 中设为 Loop > Loop with Offset 时动画曲线会正确绘制。
  • 改进了 脚本界面 中 MIME types 的使用。
  • 拖动/放入 Scene palette 色板（在 List 视图中）不再触发崩溃。
  • Color Picker（吸管）现在恢复可用。请注意色板未进行颜色管理，因此目前仍不支持。
  • 重命名多个选中的图层现在恢复可用。

说明

  • File paths 已在 macOS 和 Windows 上统一，在 UI 中使用 /（斜杠）作为分隔符。Windows 上可以使用 \（反斜杠），但它们会解析为 /。例如，在 File Name 中输入 \my\path\file，在 RQIs 路径预览中会显示为 /my/path/file.png。这也包括 JavaScript APIs 返回的任何路径。
