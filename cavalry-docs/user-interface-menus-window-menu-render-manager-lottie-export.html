Lottie 导出

简介

Lottie 是一个开源的动画文件格式，最初由 Airbnb 团队创建。由于 Lottie 基于矢量，文件可以非常轻量、可缩放，并能在移动端和 Web 上原生渲染。

Cavalry 通过文件菜单或渲染管理器原生支持 Lottie 导出。更多选项也可在属性编辑器的Advanced 标签页中找到。

界面

导出为 Lottie 非常简单。只需使用 File > Export Lottie... 菜单项。也可以通过渲染管理器导出为 Lottie，因此可与动态渲染等其他原生功能配合使用。

有关如何精细控制图形导出为 Lottie 的更多选项，可在图形的属性编辑器界面的Advanced 标签页中找到。

导出文件时，Cavalry 允许你在导出文件中添加作者信息。可通过偏好设置窗口中的 Lottie Author 选项添加。

预览

包括 LottieFiles 在内的多种平台都可用于预览动画。只需访问 https://lottiefiles.com/preview，将导出的 .json Lottie 文件拖入浏览器窗口即可。你还可以在这里分享动画的链接。

优化

虽然 Lottie 格式在不断扩展，但它并不像 Cavalry 那样功能完整，因此可导出的内容存在一些限制。不过，在功能对等性不足的地方，Cavalry 会尝试智能地烘焙图形动画，从而提供广泛的可能性。

一般来说，Lottie 文件非常小，但需要的烘焙越少，导出的文件就越小。如果文件大小对你非常重要，下面的列表包含完全不需要任何烘焙的功能（假设没有变形器连接到该图形），因此会得到最小的文件：

  • Position
  • Rotation
  • Fill > Alpha
  • Stroke > Alpha
  • Stroke > Width
  • Stroke > Trim Start
  • Stroke > Trim End
  • Stroke > Trim Travel
  • Path Animation
  • Star > Point Count
  • Star > Radius
  • Star > Inner Radius

以下功能均受支持，但已知在导出为 Lottie 时会生成相对较大的文件：

  • 变形器。
  • 路径上的Magic Easing。
  • 为任何 Primitive 属性制作动画（星形 除外）。例如 齿轮 上的 Tooth Depth。
  • 绑定控制 和 动画控制（与 Path Animation 一起使用时）。
  • 复制器。

优化技巧：

  • 如果导出的文件很大，但场景中没有任何动画，你可能需要在图形属性编辑器界面的 Advanced 标签页中，将 Lottie Baking 设置从 Automatic 改为 Still。
  • 如果你的 Lottie 导出缺少了一些你期望看到的动画，请尝试图形属性编辑器界面 Advanced 标签页中的 Animated 或 Nuclear Lottie Baking 选项。

提示

功能 属性 备注
Fill Alpha 这是 Alpha 属性，而不是 Fill Color 的 alpha。
Stroke Alpha 这是 Alpha 属性，而不是 Stroke Color 的 alpha。
Stroke Trim End LottieFiles 播放器不处理 Trim Start > Trim End 的情况。
Parenting 父级会渲染在前面，因此你可能发现组或空对象是更好的选择。
Masks 使用带遮罩的动画时，使用 Path Animation 为图形或遮罩（或两者）制作动画。不支持对 Group（或 Parent）进行遮罩。
Pre-Comps Background 确保预合成的 Background Alpha 设为 0。

使用图像

可以将图像资源导出到 Lottie。LottieFiles 支持预览一个压缩文件，其中包含 .json 以及一个装有图像资源的 images 文件夹。

  1. 导入一张图像。
  2. 将图像拖入视口，以创建素材图形和图像着色器，并连接该图像。
  3. 导出为 Lottie。这会输出一个 .json 文件和一个包含该图像的 images 文件夹。
  4. 将 .json 文件和 images 文件夹一起压缩。
  5. 将 .zip 上传到 LottieFiles。

小心：

目前尚不支持图像序列，也无法将图像直接嵌入 .json 文件——只能引用 images 目录中的图像资源。

不支持的功能

以下 Cavalry 功能无法通过 Lottie 导出：

功能 备注
所有 Filters Blurs、Levels、TriTone 等。
噪声着色器
SkSL 着色器
颜色着色器
图形到着色器
Sweep 或 Conical 渐变 Lottie 格式不支持这些。
Fill/Stroke > Color > Alpha 改用 Fill/Stroke Alpha。
Stroke > Dash Pattern
Transform > Skew
图形不透明度 改用 Fill/Stroke Alpha。
Linear Gradient > Gradient Scales with Rotation
文字 文字会导出为图形，而不是可编辑的文字
设为循环的动画曲线
轨道遮罩 改用裁剪蒙版

提示：

如果你遵循了上述准则，但 Lottie 文件仍不能按预期工作，请在 Discord 上联系我们。
