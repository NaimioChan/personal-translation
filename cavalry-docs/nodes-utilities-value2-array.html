Value2 数组

简介

创建一个二维数值列表，可通过索引将其分配给其他图层。

界面

Auto Index：勾选后，该图层将自动输出所有索引。

Array Index：选择数组中的索引。

Reverse：反转索引的输出顺序。例如，若有 3 个索引 0,1,2，其顺序将反转为 2,1,0。

Count：输出数组中索引的数量。

Add

0: Value：数组中的第一个索引。设置二维数值。

示例：

  1. 创建一个 Value2 Array。
  2. 点击 Add
  3. 为每个索引设置 X, Y 值：1920, 1080 和 720, 720。
  4. 打开合成设置，然后点击并拖动其标题栏，使窗口保持常驻。
  5. 连接 value2Array.id→composition1.resolution
  6. 取消勾选 Value2 Array 上的 Auto Index。
  7. 将 Array Index 设为 1。

当 Array Index 在 0 和 1 之间切换时，Composition Resolution 将在 1920 x 1080px 与 720 x 720px 之间变化。

双击设置 Index：

双击某个索引所在的行，会将 Index 设为该值。
