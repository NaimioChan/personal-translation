1.5.4 版本说明

发布日期：2023年4月12日

1.5 版本说明→

重要错误修复

  • 已解决一个幻影 Blend Mode 导致视口绘制异常的问题。
  • Layout Groups 和 Scheduling Groups 中原本失效的复选框已重新启用。
  • 修复了一个性能错误，该错误曾导致某些场景速度下降多达 10 倍。
  • 为带有位置关键帧的图形设置父级，不再导致图形位置跳变。
  • 已解决设置变换关键帧时的崩溃，以及一个阻止从属性编辑器右键菜单设置关键帧的错误。
