1.0.2 发行说明

发布于 2020 年 10 月 20 日

概述

本次发布主要旨在提升稳定性并修复用户报告的缺陷。它还包含相当数量的改进与增强。

新增元素/功能

正式版

  • 渲染令牌：添加标记以自动生成你的 File Name。
  • 现在单个 Render Queue Item 可用于渲染多个合成。
  • Centre Pivot (Centroid) 是 Shape 菜单中新增的选项。
  • 标尺与参考线：在新的 View 菜单中开启。

测试版

小心：

实验性功能可在偏好设置窗口中开启。

  • 噪波着色器：一个新的 SkSL 着色器。

常规增强/重要修复

  • 对 Skia 的更新导致部分 SkSL 着色器的编写方式发生变化。
  • SkSL 着色器现已在 Cavalry 播放器 中得到支持。
  • Change Text Case Manipulator 已更新，加入了 Exclusion List，并新增了 Proper Case。
  • 在播放时**更新 UI** 现在带来的性能开销要小得多。该偏好项已从偏好设置窗口移至视口。

信息：

请注意，UI update during playback 优化与 macOS 10.13 不兼容。

  • 对齐窗口的改进。你现在可以对齐到合成，快捷键为 alt。
  • 绑定控制 在与 路径动画相关的方面有所改进。
  • JS Math 上新增了一个计算结果字段。
  • JS Math 的 Expression 字段现在会高亮数组变量（n0、n1、n2 等）。
  • Math Distribution 现在支持语法与数组变量高亮。
  • 将文本粘贴到 Cavalry 中现在会创建一个 文本图形，并将内容设置为剪贴板中的内容。
  • 路径引导 的 Value 标签页中新增了 Rotation 输出。
  • Z + 双击图形会缩放以适合屏幕。该图形无需被选中。
  • 使用 Wacom 笔缩放（适用于未将滚动分配给按键的情况）时，可以按住 z，然后在视口/ 曲线编辑器或时间编辑器中点击拖动。
  • Magic Easing 现在会在曲线编辑器中预览。
  • Magic Easing 现在也可以在时间编辑器中，通过右键点击两个关键帧之间的关键帧条并从菜单中选择 Magic Easing 选项来指定。这是对右键点击关键帧的方式的补充。
  • 现在允许使用 / 表示文件夹/目录，可在渲染项的 File Name 字段中使用。
  • 现在可以渲染为 .webm，支持 VP8 和 VP9 编解码器。
  • 项目设置 已得到改进。
  • 渲染管理器 的快捷键现在是 Cmd/Ctrl + B（因为 Show/Hide Rulers 占用了 Cmd/Ctrl = R）
  • macOS 触控板用户现在可以使用捏合缩放和智能缩放（双指双击）。智能缩放会“将全部内容纳入视图”。这适用于视口、曲线编辑器和图表属性。
  • Home/End 键现在会带你到 Playback Start/ End。按住 Cmd/Ctrl + Home/End 则同样作用于 Composition Start/End。

信息：

在某些 macOS 键盘上，Home/End 键可能显示为斜向箭头。在笔记本电脑键盘上也可以使用 fn + left/right arrow。

  • Sub-Mesh 现在会生成 Length Context，这意味着例如你可以根据长度给导入的 SVG 上的所有线条着色。
  • 改进了复制或重复图层的命名方式。
  • 色板现在会指示 Alpha。

小心：

我们已暂时从视口后端选项中移除 Metal。这是由于与 macOS 10.13 的兼容性问题。

由于此问题，我们将需要在未来的版本中停止支持 macOS 10.13。
