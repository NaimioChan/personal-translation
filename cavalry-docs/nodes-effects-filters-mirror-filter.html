镜像滤镜

简介

沿中心线翻转图形以创建倒影。

界面

通用属性 +

Tiling：决定图像边界处的处理方式。

  • Decal：不环绕图像。
  • Repeat：重复图像。

Offset：设置镜像中心线的位置。

Rotation：设置镜像朝向的角度。

Padding：增大/减小结果的边界。

信息：

镜像默认使用 Persist Opacity 混合模式。这会移除镜像中心线反射侧上的原始图形。

图层工具

某些属性可以在视口中使用选择工具进行操作。在场景窗口中选中 Mirror Filter 时，视口中会出现紫色界面。

  • 要 Offset 镜像的中心线，单击并拖动紫色线条中心的白色圆点。
  • 要设置镜像中心线的 Rotation，单击并拖动偏离紫色线条中心的白色圆点。

信息：

如果同一个 Mirror Filter 连接到多个图形/输出，则使用第一个连接来确定紫色界面在视口中的位置。可以通过在场景窗口或属性编辑器中点击 Mirror Filter 的紫色输出连接图标，并选择弹出列表中最底层的图层来确认这一点。

信息：

请注意，如果将 Mirror Filter 添加到子网格行为，视口工具将不会出现。
