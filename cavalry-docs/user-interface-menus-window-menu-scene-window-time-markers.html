时间标记

简介

时间标记可用于参照时间轴上重要的时刻。它们还可以连接到关键帧和片段端点，这意味着可以将它们链接起来。

界面

要添加时间标记，可以任选以下方式：

  • 在时间轴中右键单击并选择 Add Time Marker；或
  • 定位播放头并使用热键 Cmd/Ctrl + * 或 Shift + Cmd/Ctrl + 8。

要选择时间标记，请单击其中一个，或按住 Option/Alt 框选多个时间标记。

要移动时间标记，请单击并拖动它。

要移动多个时间标记，请框选多个时间标记，然后单击并拖动所选时间标记中的任意一个。

双击时间标记可打开其设置：

  • Label：输入时间标记的描述。如果输入了标签，它将根据 Timeline Draw 或 Pre-Composition Draw 设置（见下文）显示。
  • Color：从当前标签色板中为时间标记选择一种颜色。
  • Locked：勾选后，将无法移动时间标记。
  • Use Relative Placement：勾选后，时间标记将相对于合成的时长来定位。
  • Absolute Time：为时间标记设置帧号。
  • Relative Time：设置一个 0 到 1 之间的值，其中 0 = 合成的起点，1 = 合成的终点。
  • Display Color Region：勾选后，时间/曲线编辑器中的某个区域会高亮显示。
  • Color Region：设置时间标记前后要显示颜色区域的帧数。
  • Timeline Draw：选择时间标记的标签在时间轴中的显示方式：
    • Show Label on Rollover：仅当光标悬停在时间标记上时显示标签。
    • Always show Label：始终显示标签。
  • Pre-Composition Draw：选择当其父合成在另一个合成中使用时，时间标记的标签如何显示：
    • Show Label on Rollover：仅当光标悬停在时间标记上时显示标签。
    • Always show Label：始终显示标签。

连接

通过以下任一方式将时间标记连接到关键帧或片段的端点：

  • 悬停在时间标记上并使用 Connection Anchor。
  • 双击时间标记打开其设置，并使用顶部的 Connection Anchor。

连接后，移动时间标记也会移动关键帧或片段端点。

要同时连接到多个关键帧，请选择多个关键帧，然后从时间标记拖出一条连接线到其中一个选中的关键帧。

要移除连接：选择一个片段（图层）或关键帧，然后 右键单击 > Time Markers > Disconnect [option]

通过选中一个（或多个）时间标记并按删除键可删除时间标记。在时间轴任意位置右键单击并选择“Delete All Markers”可清空时间轴。

快捷键

快捷键 命令
< 将播放头移动到上一个时间标记。
> 将播放头移动到下一个时间标记。
1, 2, 3...9 将播放头移动到第一、第二、第三……个时间标记。

信息：

Absolute 时间标记将始终吸附到精确的帧。Relative 时间标记则不会。
