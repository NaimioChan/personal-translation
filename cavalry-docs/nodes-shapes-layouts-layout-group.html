布局组

简介

布局组可用于按水平或垂直方向排列图形。

布局简介→

快速开始：

  1. 创建 3 个图形。
  2. 选中全部 3 个图形，在视口中右键单击并选择Layout > Embed selected in Horizontal Layout。

尝试增大某个图形的宽度/半径。

界面

通用属性 +

信息：

所有图形在其Advanced选项卡下还有更多Layout Alignment选项，可用于进一步调整其在单元格内的对齐。

Direction：选择布局的方向：

  • Horizontal：将图形并排堆叠。
  • Vertical：将图形上下堆叠。

Wrap Mode：确定当布局组内图形的总宽度/高度超过其尺寸时会发生什么：

  • No Wrap：图形保持在一行/列中。
  • Wrap：图形换行到下一行/列。
  • Wrap Reverse：图形换行到上一行/列。

嵌套换行：

请注意，嵌套的布局组目前不支持换行。

Draw Extents：勾选后，将在视口中绘制Minimum和Maximum Size的示意。

Minimum Size：确定布局位于另一个布局内时所占据的最小宽度和高度。

Maximum Size：确定图形在布局内可填充的最大宽度和高度。一旦布局组内图形的总宽度/高度超过这些值，图形就会开始重叠。默认情况下，Maximum Size连接到合成的Resolution，移除该连接即可设置自定义值。

信息：

如果Maximum Size设置为小于Minimum Size的值，Maximum Size会在内部被钳制为Minimum Size的值（反之亦然）。这不会反映在属性编辑器中，但在勾选Draw Extents的视口中可以看到。

Margins：设置布局边缘（上、下、左、右）周围的空间。

Spacing：设置每个布局项之间显示的空间。

Spacing Mode：确定各项在可用空间内的分布方式：

  • Manual Spacers：请参阅间隔器。
  • Flex Start：将各项对齐到布局的左侧或顶部。
  • Flex End：将各项对齐到布局的右侧或底部。
  • Centre：将所有项对齐到布局的中心。
  • Space Between：分布各项，使各项之间的间隙相等。
  • Space Around：分布各项，使每一项周围都有相等的空间或边距。
  • Space Evenly：分布各项，使各项之间的间隙相等，包括布局的边缘。

Line Spacing：当Wrap Mode设置为Wrap或Wrap Reverse时，设置行/列之间的距离。

Align Content：当Wrap Mode设置为Wrap或Wrap Reverse时，确定行/列的交叉轴对齐方式。例如，如果Direction设置为Horizontal，Align Content将影响各项的垂直对齐：

  • Flex Start：将各项对齐到布局的左侧或顶部。
  • Flex End：将各项对齐到布局的右侧或底部。
  • Centre：将所有项对齐到布局的中心。
  • Space Between：分布各项，使各项之间的间隙相等。
  • Space Around：分布各项，使每一项周围都有相等的空间或边距。
  • Space Evenly：分布各项，使各项之间的间隙相等，包括布局的边缘。

Ordering Policy：确定布局组内图形的排列顺序：

  • Layer Order：根据图形在组内的顺序，从左到右/从上到下排列图形。层级顶部的图形被视为第一个布局项。
  • Alphabetical：根据图形的Layer Name按字母顺序排列。
  • Shuffle：随机排列图形。

Flip Order：反转Ordering Policy。

Shuffle Seed：当Ordering Policy设置为Shuffle时设置随机种子。

提示：

将图形的Hidden属性连接到其Exclude from Layout属性（Advanced 选项卡），这样当它在视口中被隐藏时，布局也会相应更新。
