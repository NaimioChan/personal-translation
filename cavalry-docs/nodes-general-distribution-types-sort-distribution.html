排序分布

简介

通过重新排列另一个分布的 Id 来分布点。

界面

Input Distribution：设置或连接要影响其 Id 的 Distribution。

Mode：从以下选项中选择：

  • Horizontal：从左到右排序 Id。例如，Id0 会被设为最左侧的点。
  • Vertical：从下到上排序 Id。例如，最低的点会被设为 Id0。
  • Distance from Centroid：从 Input Distribution 的质心开始排序 Id。例如，离质心最近的点会被设为 Id0。
  • Target：基于另一个图形的位置排序 Id。例如，离 Target 最近的点会被设为 Id0。

Target：连接一个图形作为 Target。

Reverse：根据 Mode 反转结果。
