电子表格

简介

从 Google Sheet、.csv 或 .xlsx 文件中读取数据。

界面

File：从 资源窗口 中拖入 Google Sheet、.csv 或 .xlsx 资源。

Excel Sheet：从 .xlsx 资源中选择一个工作表（标签页）。

Column Title：从电子表格中选择一列。电子表格的第一行被保留，用于填充此列表。

信息：

Spreadsheet 工具一次只能输出单列的数据。若要使用同一资源中的多列，请为每一列输出创建一个 Spreadsheet 工具。

Factorize：勾选后，可将文本列转换为数值。例如，一列包含文本 Summer, Spring, Summer, Summer 的数据可以转换为数值列表 1, 0, 1, 1。结果列表按字母顺序排列。

小心：

使用 Factorize 时，出于性能考虑，资源本身也必须被“因子化”。在 资源窗口 中右键单击该资源，勾选 Factorize。

Remapping：相对于数据中的最小值和最大值对数值进行重映射。例如，如果你想制作柱状图，需要让值为 1 的数据由一个高度为 300px 的矩形来表现，就可以这样设置。

  • None：禁用重映射。
  • Area Range：参见 区域范围。
  • Number Range：参见 数值范围。
  • Number Range to Color：参见 数值范围转颜色。

信息：

如果数据中的最小值为 0、最大值为 10，并使用一个简单的黑白渐变，那么值为 0 时输出黑色，值为 10 时输出白色，值为 5 时会被重映射为 50% 灰。

Fixed Row：勾选后，它将输出 Row Index 中指定的行内容（不包括标题行）。这对于动态渲染很有用。

Row Index：指定要输出的行。值为 0 时输出电子表格的第 1 行（第 0 行保留给 Column Title）。

Row Offset：为 Row Index 加上或减去一个值。

Use Every Nth Row：只对第一行以及之后每第 Nth 行进行采样，其中 N = 该值。

Row Count：一个只读属性，输出所选列中的行数。

Column Count：一个只读属性，输出数据中的列数。请注意，计数从第一列开始，到包含数据的最后一列结束。例如，如果通过 Google Sheet 导入下方数据，将返回 Column Count 为 7（A-G 列）：

A B C D E F G H I
1 1 1

请注意，.csv 文件的情况可能有所不同，因为空列仍可被定义。例如，在 ColumnA,ColumnB,,,,, 中，'ColumnB' 之后的逗号所定义的列也会被计入 Column Count。

Interpolate：勾选后，数据可以在各列之间混合。这要求 Column Title 被设置为动画，可以通过将 Value Behaviour 连接到 Column Title，并为 Value 的 Value 属性设置关键帧来实现。注意：值为 0 代表第一列。

Output Mode：设置图层的输出：

  • Data：输出原始数据。
  • Sort Order (Ascending)：输出该列数据从最小值到最大值的排序序号。
  • Sort Order (Descending)：输出该列数据从最大值到最小值的排序序号。

Sort Order：

Sort Order 会获取一列中的值并输出它们的排序序号。例如，如果名为 Data 的列包含下方数据，且 Output Mode 设置为 Sort Order (Ascending)，Spreadsheet 将按 Sort Order 输出这些值。

Data Sort Order
56 3
3 0
17 1
40 2

如果 Output Mode 设置为 Sort Order (Descending)，Sort Order 则相反。这对于排行榜之类的用途很有用。

Data Sort Order
56 0
3 3
17 2
40 1

随后可使用该输出来设置 复制器 的 Shape Position Y，从而在 Linear Distribution 中将柱状图最大的柱子放在顶部、最小的放在底部。然后可以使用 Remapping 将 Sort Order 转换为有意义的位置值。例如，将 0, 1, 2 的 Sort Order 转换为 0, 50, 100 的值。

示例：

  1. 创建一个 文本图形、一个 复制器 和一个 Spreadsheet 工具。
  2. 创建一个 .csv 文件，其中包含一行名为 'Name' 的标题，下方列出若干姓名。
Name,

Ringo,

John,

George,

Paul
  1. 将 .csv 文件导入 资源窗口。
  2. 将 .csv 拖入 Spreadsheet 工具的 File 属性。
  3. 在 Spreadsheet 工具上将 Column Title 设置为 'Name'。
  4. 连接 textShape.id→duplicator.inputShapes
  5. 将 Duplicator 的 Distribution 设置为 Linear。
  6. 将 Duplicator 的 Direction 设置为 Vertical。
  7. 将 Duplicator 的 Count 设置为 4。
  8. 连接 spreadsheet.id→textShape.string

来自该 .csv 的前 4 个名字（不包括标题）将会出现。若要多于或少于 4 个名字，只需调整 Duplicator 上的 Count Y。

示例：

  1. 创建一个包含下方数据的 Google Sheet、.csv 或 .xlsx：
Label Value Color
Twitter 235 #00acee
Instagram 1135 #c13584
YouTube 101 #ff0000
Vimeo 2301 #1ab7ea
TikTok 764 #69c9d0
  1. 如果使用 Google Sheet，请确保 Link Sharing 设置为 Anyone with the link。
  2. 通过 资源窗口 导入该 Google Sheet、.csv 或 .xlsx。
  3. 将该资源拖入 视口（这会创建一个 Spreadsheet Utility 并连接该资源）。
  4. 在该 Spreadsheet Utility 上，将 Column Title 设置为 Value。
  5. 创建一个 Rectangle。
  6. 连接 spreadsheet.id→rectangle.size.height
  7. 选中该 Rectangle，点击 工具架 中的 复制器 图标。
  8. 将 Distribution 设置为 Linear。
  9. 将 Count 设置为 5。

此时你应该得到了 5 个矩形，每个矩形的高度由数据中 Value 列的对应行决定。为了将矩形固定在一个“地面”上，你可以使用 对齐 行为。

  1. 创建一个 对齐。
  2. 连接 align.id→rectangle.deformers
  3. 在该 Align 行为上，将 Y 设置为 1。

如果数据中包含过小/过大的值，你可能需要把这些值重映射为更适合你合成结果的值。

  1. 在 Spreadsheet 工具上，将 Remapping 设置为 数值范围。
  2. 将 Source Minimum 设置为 0。
  3. 将 Source Maximum 设置为 2500。这两个值大致涵盖了数据的范围。
  4. 将 Minimum 设置为 0。
  5. 将 Maximum 设置为 500。

数据中值为 0 的数据现在会输出为 0，而值为 2500 的数据会输出为 500。在此示例中，我们实际上是将所有值除以 2500/500 = 5，因此值为 1000 的数据会被重映射为 200。

信息：

包含货币符号（如 £ € $）的字段会被识别为数值。例如，£123.45 在连接到数值属性时会被解释为 123.45。

如果值带有 k、M 或 B 后缀，则结果会分别乘以一千、一百万或十亿。例如，1.5k 在连接到数值属性时会被转换为 1500。
