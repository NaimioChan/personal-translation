垂直布局

简介

Vertical Layout 可与应用布局行为一起使用。

布局：

请注意，此类布局仅供子网格使用。要为布局添加图形，请参见布局。

界面

Horizontal Padding：为布局的左侧和右侧添加内边距。

Vertical Padding：为布局的顶部和底部添加内边距。

Auto Spacing：在布局的宽度上均匀分布单元格。

Spacing：为每个单元格之间添加间距。

Reverse Layout Order：反转 Layout Items 的排列顺序。

Invert Layout Direction：默认情况下，布局从顶部开始向下排列。勾选此项后，布局将从底部开始向上排列。

Shuffle：随机化图形的排列顺序。

Seed：为 Shuffle 设置种子值。
