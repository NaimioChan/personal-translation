分布发射器

实验性功能：

这是一个实验性功能。要启用，请在偏好设置中勾选Enable Experimental Features。

简介

粒子从分布发射。

界面

Transform

Common Attributes +

Custom Color：视口中会绘制发射器的表示。勾选Custom Color 时，将使用Color中设置的值绘制；取消勾选时，使用Label Color（即场景窗口中使用的颜色）。

Color：为发射器在视口中的绘制设置Custom Color。

Time：该属性连接到合成的Time，以便逐帧为粒子设置动画。如有需要，可将该连接替换为关键帧或其他行为。

Emitter

Initial Velocity：设置粒子发射时赋予的速度。可连接行为（例如随机）以按“每个粒子”设置速度。

Maximum Particles：发射的粒子最大数量。

Emission Mode：

  • Once：
  • Every Frame：
  • Rate per Second：

Rate：当Emission Mode设为Rate per Second时，设置每秒发射的粒子数量。

Seed：设置用于在Emitter Shape内定位粒子的随机种子。

Override Lifespan：勾选后，Lifespan中的值将覆盖粒子图形的Lifespan。当多个发射器连接到同一粒子图形时，这很有用。

Lifespan：使用该值覆盖粒子图形的Lifespan。

Distribution：选择要发射的分布类型。
