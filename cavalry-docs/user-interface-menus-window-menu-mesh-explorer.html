网格浏览器

简介

网格浏览器可用于查看图形内部的网格结构和层级。

选中单个图形即可将其信息载入网格浏览器。出于性能考虑，无法同时载入多个图形，也无法浏览子网格数量超过 200 的图形。

界面

Lock：除点击 Refresh 外，阻止窗口更新。

Refresh：图形载入窗口后，其信息并非“实时”。在对图形做出任何更改后，使用此按钮更新当前选择。

左侧的小数字表示每个网格所处的“层级”。在使用子网格行为或其他可访问子网格的图层时，这一信息很有用。

每个网格都会显示预览。若某一项为“父级”，则会显示一个文件夹图标。例如，Text 图形由 Line、Word 和 Character 等多个层级构成。

标签提供更多信息，如 Id、Point Counts 以及是否包含 Material。

Point Counts：

请注意，点数可能与视口中看到的内容并不完全一致。例如，一个视觉上由 3 个角点构成的闭合三角形，网格浏览器会报告 Point Count 为 4。这是因为在后台，闭合三角形的路径起点和终点处实际上包含了位置重合的点。

1. 0,10

2. 10,10

3. -10,10

4. 0,10

更多信息请参见路径。
