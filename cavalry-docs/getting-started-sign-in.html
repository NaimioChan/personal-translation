登录

登录

信息：

首次使用 Cavalry 需要网络连接。

Cavalry 首次启动时会显示登录窗口。点击 Sign in with Canva，然后按照提示登录。如果你还没有 Canva 账户，系统会引导你创建一个。

如有需要，网络通信可以通过代理服务器发送。

退出登录

前往 Help > Sign Out... 退出 Cavalry 登录，并打开登录窗口。

疑难解答

如果在登录 Cavalry 时遇到任何问题，请检查以下各项：

  • 确认你的机器满足最低系统要求。
  • 确认你的网络连接正常，可以访问互联网。
  • 确认你的网络上没有运行防火墙或代理服务器。这在企业环境中更为常见。如果有，请参阅代理服务器。
  • 如果使用 VPN，请确保其配置允许该连接。
  • 确认你的机器上没有由你或你的雇主设置的安全系统，可能会阻止与许可服务器通信或阻止将凭据写入文件系统。如果是后者，你在尝试登录时可能会看到以下消息——如遇此情况，请联系你的 IT 部门解除限制。
    • macOS Unable to save credentials to disk. Please check you have permission to write to the Keychain.
    • Windows Unable to save licence to disk. Please check you have permission to write to the AppData folder.

Token 交换失败

如果你在登录 Cavalry 时收到错误“Sign in failed: Token exchange failed”，通常说明防火墙或代理阻止了应用程序连接互联网。

要解决此问题，请将以下 URL 添加到防火墙/代理白名单。

  • https://www.canva.com/
  • https://canva.com/
  • https://api.canva.com/

删除凭据

如果以上步骤都无法解决问题，可能是许可证已损坏。要删除所有身份验证信息，请按以下步骤操作：

Windows

  1. 关闭 Cavalry。
  2. 前往：C:\Users\<USER>\AppData\Roaming\Cavalry\pdata（AppData 是隐藏文件夹，因此请在资源管理器的“View options”中勾选“Hidden Items”）。
  3. 删除该文件夹的全部内容（cavalry-auth、cavalry-last-email、cavalry-licence、cavalry-web-proxy）。
  4. 打开 Cavalry。
  5. 登录。

macOS

  1. 关闭 Cavalry。
  2. 打开 Applications/Utilities/Keychain Access。
  3. 搜索“app.cavalry”。
  4. 删除找到的钥匙串（应该有 4 个）。
  5. 打开 Cavalry。
  6. 登录。

如果其中任何文件缺失，可能说明有其他进程阻止了 Cavalry 写入你的文件系统。

联系支持：

如果问题仍然存在，请使用你账户关联的邮箱地址发送邮件至支持团队，并附上以下信息：

  • 请告知你之前是否曾成功登录过。如果是，是否在同一台机器上？
  • 登录失败时消息栏（和/或 Windows 上的 Cmd Prompt）中显示的任何错误消息。
  • 打开 Help > System Diagnostics，点击 Copy to Clipboard，然后将剪贴板内容粘贴到邮件中。
