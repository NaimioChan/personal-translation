JavaScript 变形器

简介

JavaScript Deformer 可用于以有趣而新颖的方式操控图形的点。

有关如何在所有 JavaScript 图层中使用 JavaScript 的更多信息，请参见 JavaScript 图层。

参见 JavaScript 图层→

此变形器与 JavaScript 图形 和 JavaScript 工具 类似，只是它可用一些额外的语法，从而能够访问图形的几何体。它可以访问整个 上下文模块，这意味着可以保存和加载数据以在帧之间使用。

有关此图层专属的成员函数，请参见 变形器模块。

界面

JavaScript Expression：在此处输入 JavaScript 代码。

示例：

  1. 创建一个 Basic Line。
  2. 创建一个 JavaScript Deformer。
  3. 将默认的 JavaScript Expression 替换为：
var points = def.getPoints();

var bbox = def.getBoundingBox();

var maxX = bbox.x+bbox.width;

var frequency = 10;

var amplitude = 50;



for (let pt of points) {

    let normX = cavalry.norm(pt.x, bbox.x, maxX);

    pt.y += Math.sin((normX+n0*.1)*frequency)*amplitude;

}



def.setPoints(points);
  1. 连接 javaScriptDeformer.id→basicLine.deformers

这会将线条变形为波浪。尝试将第 4 行的 let frequency = 10; 替换为 let frequency = n0;，并使用底部的 n0 属性来改变变形器的频率。
