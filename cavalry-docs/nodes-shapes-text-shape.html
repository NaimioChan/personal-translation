文本图形

简介

创建并格式化文本。

提示：

也可以在视口中使用文本工具创建文本图形。选中文本工具后，单击并拖动即可绘制一个文本框。如果按住 Option/Alt 单击文本工具，或在选中文本工具的情况下在视口中单击一次，创建的文本图形会勾选 Auto Width 和 Auto Height。这样文本框会适应文本，而不是让文本适应文本框。

样式继承：

创建文本图形时，它的一些设置会继承自上一次与另一个文本图形的交互。例如，如果上一次与文本图形的交互将Font 设为 Arial、Font Size 设为 100，那么接下来创建的文本图形也会沿用这些设置。这会影响以下属性：

  • Font
  • Font Style
  • Font Size
  • Alignment
  • Vertical Alignment
  • Character Spacing
  • Word Spacing
  • Line Spacing
  • Paragraph Spacing

也可以使用预设功能设置一个“默认”文本图形。如果某个预设被设为 Set as Default Settings，该预设会覆盖上述设置。

这不适用于通过脚本创建的文本，也不适用于从剪贴板粘贴的文本。

界面

通用属性 +

Shape

String：在此处输入文本、数字或符号。

生成器：从列表中生成字符串生成器。

OpenType：OpenType 功能。如果当前字符串（或选区）不包含可能受某个选项影响的字形组合，该选项会变暗。OpenType 可应用于整个字符串，也可通过选区应用，并与富文本功能结合使用。请注意，如果 String 属性带有输入连接，则不支持 OpenType。这种情况下，请改用应用 OpenType 样式行为。

重置OpenType 样式，使文本恢复默认。

字形：打开字形浏览器。双击字形可将其添加到 String。请注意，如果 String 属性带有输入连接，则不支持添加字形。这种情况下，请打开字形浏览器 并直接向输入中添加字形。

Font：选择字体和字重。

收藏字体：

可以将字体标记为收藏以便快速访问。打开字体选择器后，将光标悬停在某个字体上，该字体名称右侧会显示一个心形图标，点击即可将该字体设为收藏。收藏的字体将显示在列表顶部。

字体选择器左侧的心形图标可用于筛选列表，仅显示收藏的字体。

可变字体：

如果选择了可变字体，Font 属性右侧会显示一个小展开图标（三个点）。点击该图标会打开一个弹出窗口，以便访问字体的各轴。拖动弹出窗口的标题栏可将其分离，以便与各轴建立连接。

Typeface：连接一个字体。这样可以将不同的文本图形连接到同一种字体。

Font Size：设置字体大小。

Style：为文本应用下划线、删除线、下标、上标和/或全大写样式。使用齿轮图标设置选项：

  • Line Style：指定下划线和删除线如何渲染单词之间的空格字符：
    • Through：穿过空格创建连续的线。
    • Gaps：在存在空格的位置在线条上创建间隙。
  • Decorator Shape：为文本图形添加样式时，会创建一个新的“装饰”图形。

Alignment：将文本水平对齐到左侧、居中、右侧或两端对齐。两端对齐的文本会增加单词之间的间距，使文本同时对齐左右边距，但段落的最后一行除外，它保持左对齐。

Justify All Lines：当 Alignment 设为 Justify 时，勾选此选项还会对包含手动换行的行进行两端对齐。

Vertical Alignment：将文本垂直对齐到顶部、居中、底部或基线。

Character Spacing：设置字符之间的距离。

Word Spacing：设置单词之间距离的偏移。

Line Spacing：设置行之间距离的偏移。

Paragraph Spacing：设置段落之间距离的偏移。段落由换行定义。

Text Box Size：设置文本环绕区域的尺寸。

  • Auto Width：勾选后，文本框的宽度会适应文本宽度。
  • Auto Height：勾选后，文本框的高度会适应文本高度。

Shrink to Fit Text Box：勾选后，当字符串溢出文本框时，Font Size 会自动缩小。注意：这要求 Text Box Size 属性下的 Auto 未勾选。应用于文本的缩放系数可通过 Advanced 标签页中的 Font Scale 属性查看。

Allow Word Breaks：取消勾选并勾选 Shrink to Fit Text Box 时，单词不会跨行换行。这对自动化模板很有用，可防止长单词折行时被拆分到多行，从而超出文本框。此时文本会进行适当的缩放。

连字符：

带连字符的单词（例如 Sub-Mesh）会被视为独立的单词，除非其中包含 NON-BREAKING HYPHEN 字符（U+2011）。

Avoid Orphans：勾选后，确保文本框内的换行文本不会在最后一行留下孤立的单个单词。

Force Monospacing：点击复选框可移除非等宽字体的所有字距调整（在需要动画化文本字符串但保持每个字符位置时很有用）。使用 Monospace Multiplier 可增加或减少等宽字符之间的间距。

String Manipulators：添加一个字符串操纵器。

Style Behaviours：添加一个样式行为。样式行为可用于对文本字符串进行程序化处理。示例请参见应用字号工具。

Material Behaviours：添加一个材质行为。材质行为可用于对文本字符串进行程序化处理。示例请参见应用文本材质工具。

Formatting Inputs：向文本图形中注入 String/Text。这样可设置包含不同样式、颜色或大小的文本。然后可以在花括号中通过索引引用任何已连接的 Text 或 String。例如，一个文本字符串为 Cavalry {0} 的文本图形，会注入连接到 Formatting Inputs 索引 0 的另一个文本图形中的文本。

示例：

Formatting Inputs

  1. 创建一个文本图形（Text Shape 1）。
  2. 使用 Formatting Inputs 属性行上的 + 图标，添加第二个文本图形（Text Shape 2）。
  3. 将 Text Shape 2 的 Font Weight 设为 Bold。
  4. 在 Fill 标签页上，将 Text Shape 2 的 Color 设为蓝色。
  5. 将 Text Shape 2 的 Text 输入改为 rules。
  6. 在 Text Shape 1 上，在 Cavalry 和 {0} 之间插入一个空格字符。

现在 Text Shape 1 会显示“Cavalry rules”（其中 rules 为蓝色）。

Text Path：连接一个图形，使文本图形沿其排列。

路径与对齐：

当文本沿路径排列时，其 Alignment 会根据路径的起点/中心/终点设置。文本将根据 Alignment 按以下方式定位：

  • Left：其左边缘（第一个字符）位于路径的第一个点。
  • Centre：其中心位于路径的中点。
  • Right：其右边缘（最后一个字符）位于路径的最后一个点（对于闭合路径，该点与第一个点相同）。

Path Loop：勾选后，文本图形会沿路径循环。

Path Travel：沿路径移动文本图形。

Path Push：沿路径的法线移动文本图形。

沿路径排列文本：

使用 Shape > Reverse Contour(s) 命令或反转路径行为，可将文本定位到路径的另一侧。

Background

Background Shape：添加一个自定义图形用作背景。注意：这是一个输出连接。若要重新连接，请将文本图形的 Background Shape 属性连接到自定义图形的 Input Shape 属性。

Mode：设置 Background Shape 所依据的层级：

  • Document：创建一个涵盖整个字符串的图形。
  • Paragraph：为字符串中的每个段落创建一个图形。注意：段落由空行（例如两个换行）定义。
  • Line：为字符串中的每一行创建一个图形。
  • Word：为字符串中的每个单词创建一个图形。
  • Character：为字符串中的每个字符创建一个图形。

Specific Indices：手动输入索引，以确定选择哪些段落/行/单词/字符。输入以逗号分隔的值（例如 0, 4, 7），或使用冒号创建范围（例如 1:4），也可以将两者组合（例如 2, 3:5）。输入字符串 first 或 last 会以程序方式选择这些索引。也可以使用负值从字符串末尾向前选择索引，例如 -1 = 最后一个，-2 = 倒数第二个，-3 = 倒数第三个，依此类推。

Padding：增加/减少自定义图形围绕文本图形的内边距。

Ascender Adjustment：偏移自定义图形在字体上伸部（例如 t、d、l）上方的垂直内边距。

Descender Adjustment：偏移自定义图形在字体下伸部（例如 g、y、j）下方的垂直内边距。

Corner Radius Mode：确定是全局设置圆角半径，还是逐个角设置：

  • All：Corner Radius 设置将应用到所有圆角。
  • Individual：通过 Top 和 Bottom Radii 分别设置每个角。

Corner Radius：设置矩形圆角的半径。

Top Radii：设置顶部圆角的半径 [l, r]。

Bottom Radii：设置底部圆角的半径 [l, r]。

Chamfer：对矩形的角进行倒角。

Advanced

Font Scale：当勾选 Shrink to Fit Text Box 时，输出应用于文本的缩放系数。

Automatic Naming：勾选后，文本图形的“友好名称”会继承自其 String，除非已在场景窗口中通过重命名手动设置。

逐字符动画：

参见子网格，按字符/单词/行对文本制作动画。

执行顺序：

当组合使用多种文本功能时，它们会按以下顺序影响输出：

  1. Text input（包括字符串生成器和字符串操纵器）
  2. Style Behaviours（应用字符间距、应用字号、应用字体）
  3. Standard Materials（Fill、Stroke）
  4. Material Behaviours（应用文本材质）
  5. Formatted Inputs

命名文本图形图层：

默认情况下，文本图形的“友好名称”会继承自其 String，除非已在场景窗口中通过重命名手动设置。取消勾选 Advanced 标签页中的 Automatic Naming 即可禁用此行为。
