JS 数学

简介

使用 JavaScript 对数值执行数学运算。

界面

Expression：用于输入数学运算/JavaScript 表达式的区域。

Result：一个只读属性，用于预览 Expression 的结果。

Add：使用此按钮可以向界面添加更多索引。

0: Number：数组中的第一个索引。

信息：

要在表达式中引用某一行，请使用语法 n[index number]。例如，要引用标记为 0: Number 的索引，请使用语法 n0。

任何包含 n 后跟 value 的字符串都会被着色，以便在表达式中直观地识别它们。

示例：

将两个属性的值相加。

  1. 创建 3 个图形。
  2. 创建一个 Jsmath 工具。
  3. 连接 basicShape1.position.x→jsmath.number0
  4. 连接 basicShape2.position.x→jsmath.number1
  5. 在 Expression 输入框中输入 n0 + n1。
  6. 连接 jsmath.id→basicShape3.position.x

示例：

以 \sqrt{Shape2} 的值在 X 轴上移动 Shape1

  1. 创建 2 个图形。
  2. 创建一个 Jsmath 工具。
  3. 连接 basicShape1.position.x→jsmath.number0
  4. 在 Expression 输入框中输入 Math.sqrt(n0)。
  5. 连接 jsmath.id→basicShape2.position.x

信息：

有关 JavaScript 语法，请参见 https://htmlcheatsheet.com/js/。

信息：

要从数组中移除索引，请选中一行或多行，右键单击并选择 Delete Selected Attribute(s)。

右键单击某个索引行并选择 Rename 可为索引重命名。

右键单击某个索引行并选择 Reorder 可重新排列索引。

If 语句：

使用 Jsmath 图层可以编写 If Statements。例如……

if (n0 > n1) {1} else {0} 或等价的单行条件表达式 n0 > n1 ? 1 : 0

……其含义是“如果 n0 大于 n1，则输出 1。否则输出 0”。
