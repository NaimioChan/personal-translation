网格图形

简介

通过添加控制顶点来创建网格，以对图像或着色器进行变形。

界面

Shape

通用属性 +

Size：设置图形的尺寸。

Mesh

Mesh：勾选后，图形会转换为网格，因此可以通过添加顶点来进行变形。请参阅网格工具。

Top Left Offset：设置图形左上角的位置偏移。

Top Right Offset：设置图形右上角的位置偏移。

Bottom Left Offset：设置图形左下角的位置偏移。

Bottom Right Offset：设置图形右下角的位置偏移。

Vertices：打开一个弹出窗口，其中包含网格顶点列表：

  • 添加网格工具。
  • 每个索引包含对应顶点的位置信息：
    • Bind Position：设置顶点的起始位置。
    • Offset Position：设置用于将顶点位置从其Bind Position偏移的值。

使用x从列表中移除顶点。

Controllers：添加衰减，可用于影响成组的顶点。

Controllers：

虽然可以通过在 Controllers 列表中右键单击来将衰减添加为控制器，但以下方式可能更可取：

  1. 手动创建一个衰减。
  2. 将其定位到要影响的顶点上。
  3. 将其连接到Controllers输入。

如果控制器已绑定到顶点：

  1. 单击 Controllers 列表中的活动图标以禁用该衰减。
  2. 移动衰减。
  3. 单击Rebind。
  4. 单击 Controllers 列表中的活动图标以启用该衰减。

图像资源：

在资源窗口中右键单击图像资源，并选择Add to Composition as Mesh，即可快速将图像添加到网格图形。

也可以将图像从资源窗口拖到网格图形Fill选项卡的Shaders输入上。此时会出现一个对话框，询问是否应将网格图形调整为适配图像资源的分辨率。

示例：

  1. 将图像导入资源窗口。
  2. 右键单击该图像并选择Add to Composition as Mesh。
  3. 启用网格工具。
  4. 单击网格图形以确保其被选中。
  5. 按住Option/Alt并在网格图形的中心单击以创建顶点。
  6. 松开Option/Alt并单击拖动该顶点。

可以通过右键单击顶点并选择Set Keyframe，或通过Vertices弹出窗口，来设置Offset Position关键帧。
