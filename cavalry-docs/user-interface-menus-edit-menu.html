编辑菜单

Undo：在撤销队列中后退一步。

Redo：在撤销队列中前进一步。

Cut：将选中的图层复制到剪贴板，并从合成中移除。

Copy：将选中的图层复制到剪贴板。

Copy as SVG：将选中的图形以 SVG 代码形式复制到剪贴板。

Paste：将剪贴板内容粘贴到当前合成中。

Delete：删除选中的图层。

Group：将选中的图层添加到一个新的组中。

Group and Flatten：将选中的图层编组，并展平任何现有的层级关系。

Un-Group：取消编组所有选中的组。

Add to Group：将选中的图层添加到已有的组中。

Connect to Frame Range：创建并连接相对时间标记，将其定位在合成的起始和结束处，并连接到图形剪辑的两端，这样当合成的 Frame Range 变化时，它们始终在视口中可见。

Show/ Hide Selected：切换场景窗口中任意图层的可见性。

Show/Hide Channels：切换场景窗口中选中图层任意动画通道的可见性

Duplicate：复制选中的图层，并保留所有输入连接。

Duplicate (Options)...：打开一个模态窗口，其中包含以下选项：

  • All Inputs：复制选中的图层，以及所有作为输入连接的图层。
  • Keep Connections：复制选中的图层并保留所有输入连接（与上面的 Duplicate 相同）。

Duplicate and Split：复制一个图层，并将原图层的末端和新图层的起始端裁剪到当前帧。

Arrange

  • Bring to Front：将选中的图形移到场景树中其所在层级的最上层。
  • Bring Forward：将选中的图形在场景树中上移一层。
  • Send Backward：将选中的图形在场景树中下移一层。
  • Send to Back：将选中的图形移到场景树中其所在层级的最下层。

Select All：选中当前合成中的所有图层。

Invert Selection：取消选中已选中的图形，并选中所有未选中的图形。

Clear Selection：取消所有选中。也可以点击场景树的标题栏来清除选择。

Select by Label Color：选中所有具有相同 Label Color 的图层。

Select by Type：选中所有相同类型的图层。

Select by Tag：选中所有分配到某个标签的图层。

Show in Attribute Editor：显示或载入选中图形的属性编辑器界面。

Show in Scene Window：在场景窗口中显示或载入选中的图形。

Preferences...：打开偏好设置窗口以自定义部分功能。请注意，在 macOS 上该菜单项位于 Cavalry 菜单下。

Emoji Symbols：[仅 macOS] 标准的操作系统菜单项，会打开一个提供 emoji 符号访问的窗口。请注意，大多数 emoji 符号是位图，而只有基于矢量的 emoji 才能在 Cavalry 中正常工作。遗憾的是，无法筛选位图与 emoji，因此使用 emoji 时需要一些试错。
