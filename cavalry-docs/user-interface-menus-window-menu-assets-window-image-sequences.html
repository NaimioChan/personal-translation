图像序列

简介

导入按序号命名的图像文件。图像序列是一组文件名以连续数字结尾的图像文件。

使用

导入图像序列：

  • 在资源窗口中双击。
  • 在文件系统中定位到一个图像序列。
  • 双击其中一张图像，或选中一张图像后点击“打开”。

将图像序列添加到合成：

  • 将导入的资源从资源窗口拖入场景窗口。

这会创建图像着色器并将其连接到素材图形。

有效的图像序列形式为 <string><numbers>.<extension>。以下示例（并非全部）均有效：

  • filename_001.png、filename_002.png、filename_003.png ...
  • filename.1.png、filename.2.png、filename.3.png ...
  • filename-001.png、filename-002.png、filename-003.png ...
  • filename01.png、filename02.png、filename03.png ...
  • filename (1).png、filename (2).png、filename (3).png ...

信息：

默认情况下，Cavalry 会检测是否存在图像序列并自动导入。你可以在文件浏览器底部选择“Any Still”筛选器来阻止这一行为。

信息：

图像序列的加载速度可能更快，因此可以替代视频资源来优化场景。
