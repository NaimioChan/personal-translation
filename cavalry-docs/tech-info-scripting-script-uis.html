脚本界面

简介

可以为脚本构建用户界面（UI），使其更易于使用或与他人分享。脚本可以在JavaScript 编辑器中测试，然后保存到文件系统，这意味着它们可以作为窗口打开，从而被停靠并作为工作区的一部分保存。

要让脚本出现在脚本菜单中，应将其以 .js 或 .jsc 扩展名保存到：

  • macOS：~/Library/Application Support/Cavalry/Scripts
  • Windows：C:\Users\<USERNAME>\AppData\Roaming\Cavalry\Scripts

加密：

.jsc 是一种加密的 JavaScript 格式。可以使用 JavaScript 编辑器中的 Save Encrypted... 按钮将脚本保存为该格式。脚本一旦转换为此格式，就只能由 Cavalry 读取，最终用户无法看到源码。请记住保留一份未加密的脚本副本，因为此操作是单向的。

位置：

AppData 和 ~/Library 是隐藏文件夹。要找到它们：

  • Windows：在 Explorer 的 View options 中勾选 Hidden Items。
  • macOS：在 Finder 中按住 option 打开 Go 菜单，就会看到 Library。

快速导航到该文件夹的一种方法是使用 Help 或 Scripts > Show Scripts Folder 命令。保存到该位置的脚本随后会出现在 Scripts 菜单下。

脚本可以在 Scripts 文件夹内按文件夹组织。这些文件夹会在 Scripts 菜单下以嵌套层级显示。

提示：

脚本采用“热加载”，因此更新脚本无需重启应用。只需关闭并重新打开脚本窗口即可。向 Scripts 文件夹添加新脚本也是如此，下次打开 Scripts 菜单时它们就会出现。

资源

如果脚本包含资源（例如图像），应将这些资源放在以 _assets 为后缀的文件夹中。任何以 _assets 结尾的目录在浏览 Scripts 菜单时都会被隐藏。

例如：

可以使用 ui.scriptLocation 属性访问脚本所在位置，该属性会返回脚本的父文件夹。在为脚本界面添加图像或其他资源时，可以用它来构建相对路径。

例如：

// Create a button and set an image


var buttonTop = new ui.Button("Top");


buttonTop.setImage(ui.scriptLocation + "/scriptName_assets/icon.png");

测试资源：

从JavaScript 编辑器运行脚本时，只能通过绝对文件路径引用资源。要使用 ui.scriptLocation，脚本必须保存到 Scripts 文件夹，并从脚本菜单中运行。

快速开始

此示例将创建一个简单的窗口，包含一个标题和一个按钮，点击按钮会打印场景中选中项的数量。

// Set the window title


ui.setTitle("Print Selection Script");





// Create a button


var button1 = new ui.Button("Print Selected Layers");


// Set a callback function, this will be run when the button is clicked


button1.onClick = function () {


  let sel = api.getSelection();


  if (sel.length > 0) {


    console.log("Number of selected layers: " + sel.length);


  } else {


    console.log("There are no selected layers");


  }


};


// Create the layout, the button will be in the middle of the window


ui.addStretch();


ui.add(button1);


ui.addStretch();


// Show the window


ui.show();

registerDragDropMimeType(mimeType:string)

UI 窗口支持拖放功能。Container 控件也可用于在同一 UI 窗口内创建多个不同（非连续）的拖放区域，这意味着事件只会在 Container 内触发，而不是整个 UI 窗口。UI 窗口必须至少注册一个可接受的 MIME type。要注册多个 MIME 类型，请每行添加一个。

有效的 MIME type 值包括：

  • layerIds // 接受一个或多个图层。返回 {"layerIds":[layerId:string]}
  • assetIds // 接受来自资源窗口的一个或多个资源。返回 {"assetIds":[assetId:string]}
  • url // 接受文件或网页 URL。返回 {"text":URL:string,"url":URL:string}
  • color // 接受颜色色板。返回 {"colorHexA":hexA:string,"colorHex":hex:string}
  • text // 接受一个字符串。返回 {"text":text:string}

回调

  • onDragEnter // 当拖拽事件进入 UI 窗口/Container 时触发
  • onDragLeave // 当拖拽事件离开 UI 窗口/Container 时触发
  • onDrop // 当放置事件发生时触发
  • onContextMenuAboutToShow // 清空并重新填充 UI 上下文菜单
  • onResize // 当窗口尺寸改变时触发
// Drag and drop example


var label = new ui.Label("Drag and drop a layer in here");


var layout = new ui.HLayout();


layout.addStretch();


layout.add(label);


layout.addStretch();





var container = new ui.Container();


container.setBackgroundColor("#1755a6");


container.setRadius(3, 3, 3, 3);


container.setLayout(layout);





// This step is essential, register at least one MIME type that the Window should accept.


ui.registerDragDropMimeType("layerIds");





ui.onDragEnter = function () {


  console.log("Drag Enter");


  container.setBorder("#e62163", "2");


};


ui.onDragLeave = function () {


  console.log("Drag Leave");


  container.setBorder();


};


ui.onDrop = function (dropInfo) {


  container.setBorder();


  label.setText("You dropped: " + api.getNiceName(dropInfo["layerIds"][0]));


};





ui.setMargins(6, 6, 6, 6);


ui.add(container);


ui.show();
// Return the current size of the window


ui.onResize = function () {


  console.debug(`New size: ${ui.size().width} x ${ui.size().height}`);


};


ui.show();

ColorPalette

一个可同时显示多种颜色的控件，适合用于创建处理颜色工作流的脚本。这是一个反馈型控件，用户无法直接与之交互。setColors 函数不会苛求十六进制颜色字符串中的 # 前缀（若缺少井号，会自动添加）。

函数

  • ColorPalette()
  • getColors() → [string]
  • setColors(hex:[string]) // 设置调色板控件要使用的颜色。

    assetAsyncLabel.setText("Import of " + layerId + " complete.");


  };


  // The callback will be called when Cavalry switches to/from the active application. The possible states are 'active' or 'inactive'.


  this.onAppStateChanged = function (state) {


    stateLabel.setText("Cavalry is currently: " + state);


  };





  this.onAttrConnected = function (fromAttr, toAttr) {


    console.log("Connected: " + fromAttr + " → " + toAttr);


  };





  this.onAttrDisconnected = function (fromAttr, toAttr) {


    console.log("Disconnected: " + fromAttr + " → " + toAttr);


  };





  this.onToolChanged = function(toolName) {


        console.debug("Tool changed to: " + toolName);


  };





}

计时器

计时器可用于 UI 脚本，适合轮询 Web API。计时器触发时会调用 Timer 对象上的 onTimeout() 函数。实现此函数，以便计时器在触发时执行逻辑。更多信息请参阅 Timer。

小心：

计时器不应用于检测场景变化，请改用 应用回调。

注意：

  • 每个脚本都有自己的 JavaScript 沙盒，因此不会污染全局命名空间。
  • 在 JavaScript 编辑器中测试 UI Script 时，一次只能加载一个 UI Script 窗口。
