辉光滤镜

简介

为图形添加辉光效果，并可对各个 RGB 通道进行精细控制。

界面

Blend Mode：决定滤镜与图形的混合方式。参见混合模式。

Mode：决定颜色通道受影响的方式：

  • Simple Controls：设置同时影响所有颜色通道。
  • Individual Channel Controls：分别影响每个颜色通道。

Glow Radius：设置辉光从图形向外延伸的距离。

Intensity：增大/减小辉光的强度。

Red Glow Radius：设置红色通道的辉光从图形向外延伸的距离。

Green Glow Radius：设置绿色通道的辉光从图形向外延伸的距离。

Blue Glow Radius：设置蓝色通道的辉光从图形向外延伸的距离。

Intensity RGB：增大/减小红/绿/蓝通道辉光的强度。

Glow Tint：设置一种颜色，与输入的辉光值相乘。

Source Gamma：设置阈值，通过反向伽马调整来调整辉光输入的亮度值。减小该值可将辉光限制在源图像的较亮区域。将 Draw Mode 设为 Glow Input 可预览调整后的输入。

Source White Point：调整辉光输入的白点。值为 0.5 时，所有大于 0.5 的亮度值都会被设为白色。

Draw Mode：设置绘制模式：

  • Result：输出生成的辉光。
  • Glow Input：显示对源图像进行 Gamma 和 White Point 调整后的预览。
