自定义下拉菜单

简介

创建自定义下拉菜单，可从固定的自定义选项中选择，以设置颜色、对齐和文字等属性。该图层主要用于配合控制中心使用。

界面

Selection：下拉菜单界面。通过向下方列表添加新的行来填充下拉菜单的内容。

Add

0: Row：数组中的第一个索引。

  • Enabled：勾选后，该索引将包含在下拉菜单中。
  • Name：输入下拉菜单中该选项的标签。
  • Value：连接一个属性或图层

快速开始：

  1. 创建一个图形。
  2. 创建 3 个颜色着色器。
  3. 将每个 Color Shader 的Color属性分别设为红、蓝、绿。
  4. 创建一个Custom Dropdown。
  5. 通过点击 Add 创建 2 个新行
  6. 将每一行的Name设为 Red、Blue、Green。
  7. 为每个 Color Shader 连接 colorShader.color→customDropdown.rows.value
  8. 连接 customDropdown.id→shape.fillColor

使用 Custom Dropdown 的Selection行上已创建的下拉菜单来更改图形的颜色。

数组

下拉菜单属性（默认称为Selection）输出整数值，因此可用于驱动数组的Index。

示例：

  1. 创建一个图形。
  2. 创建一个颜色数组。
  3. 点击 Add
  4. 连接 colorArray.id→shape.fillColor
  5. 创建一个Custom Dropdown。
  6. 通过点击 Add 创建一个新行
  7. 将每个下拉菜单条目的Name设为与数组中对应的颜色相匹配。
  8. 连接 customDropdown.index→colorArray.arrayIndex（index 默认标记为Selection）。

使用 Custom Dropdown 的Selection行上已创建的下拉菜单来更改图形的颜色。
