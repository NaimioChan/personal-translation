通用属性（行为）

简介

许多行为共享这些属性。

界面

Behaviour

Strength：确定行为的强度。

信息：

许多（但并非全部）行为都包含下面的图表部件。

Graph：点击图标可弹出图表部件。它可用于塑造行为的效果。参见图表属性。

Falloffs

用于添加和设置衰减的列表。

要添加衰减，可以右键点击 Falloffs 行并选择 **Add Falloffs > Falloff **，或连接一个现有的衰减。

可见性图标（眼睛）：启用/禁用该衰减。

Layer Mode：设置每个衰减的图层模式。每个衰减会影响其下方图层的结果：

  • Normal (Add)：输出数值。
  • Min.：所有数值都会降低到最低值。
  • Max.：所有数值都会提升到最高值。
  • Minus：减去数值。
  • Multiply：乘以数值，使数值减小。
  • Screen：乘以数值的反值，使数值增大。
  • Overlay：高值会增大，低值会减小。

只需拖放即可重新排列该列表。

信息：

每个图层都会叠加到其下方图层的结果上，因此图层顺序非常重要。例如，在有 3 个衰减的情况下：

  • 第一个（最底部）衰减必须设为 Normal (Add)，否则没有可供其加减的数值。
  • 第二个衰减会作用于最底部的衰减。例如，若设为 Minus，它会减去最底部衰减设置的数值。
  • 第三个衰减会作用于其下方衰减的结果。

在下面的示例中，我们将 3 个衰减连接到了一个颜色混合。

颜色混合将数值 0 映射为粉色（其渐变左侧的颜色），将数值 1 映射为绿色（其渐变右侧的颜色）。

  • Falloff 1 是一个圆形，其 Layer Mode 设为 Normal (Add)。
  • Falloff 2 是一个较小的圆形，但其 Layer Mode 设为 Minus。
  • Falloff 3 是一个矩形，其 Layer Mode 设为 Multiply。
  • Falloff 1 只是从其中心向边缘传递从 1 到 0 的数值，颜色混合会将其从绿色（1）转换为粉色（0）。
  • Falloff 2 将其数值从 Falloff 1 的数值中减去。在中心处，两个衰减的值都是 1，因此 1 - 1 = 0
  • Falloff 3 用其数值乘以 Falloff 2 的结果。矩形内部该衰减传递的值为 1，外部为 0（我们使用图表创建了一个硬衰减）。Anything \times 0 = 0
