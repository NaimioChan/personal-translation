预合成覆盖

简介

作为图层用在另一个 Composition 中的 Composition 也称为 Pre-Comp。可以将多个 Pre-Comp 添加到另一个 Composition，以此创建只有一个“真相来源”的副本——对原始 Composition 所做的任何更改都会传播到它的所有 Pre-Comp。

Pre-Comp Overrides 可用于提升图层的属性，使其可以从 Pre-Comp 本身访问和覆盖。这样便可以为同一个 Pre-Comp 的多个版本添加变化。

引用→

支持的属性：

Pre-Comp Override 可以添加到任何可设置关键帧的属性上，下拉菜单除外。

快速开始：

  1. 在 Assets Window 中，将默认的 Composition 重命名为“Pre-Comp”。
  2. 打开合成设置，将 Resolution 设为 500,500。
  3. 创建一个 文本图形。
  4. 将 Text 的 Alignment 设为 Centre。
  5. 在属性编辑器中，右键单击 String 属性并选择 Add Pre-Comp Override。
  6. 创建第二个 Composition，并将其命名为“Main”。
  7. 在 Main Composition 处于活动状态时，从 资源窗口 中将 Pre-Comp 拖入场景窗口。
  8. 在场景窗口中复制 Pre-Comp（以创建一个名为 Pre-Comp 1 的图层）。
  9. 将它们分开，以便在视口中同时看到两者。
  10. 从 场景窗口双击 Pre-Comp 1 或将其拖入属性编辑器。
  11. 打开 Overrides 选项卡。
  12. 在 String 属性中输入“Override”。
  13. 双击任一 Pre-Comp 以加载其父级 Composition。
  14. 更改 Text Shape 的 Font。
  15. 加载 Main Composition。

两个 Pre-Comp 的 Font 都已更新，但字符串保留了各自的覆盖值。

界面

添加/移除覆盖

要添加 Pre-Comp Override：

  1. 选择一个或多个属性。
  2. 右键单击任一所选属性的行。
  3. 选择 Add Pre-Comp Override。

要移除 Pre-Comp Override：

  1. 选择一个或多个带有覆盖的属性。
  2. 右键单击该属性的行。
  3. 选择 Remove Pre-Comp Override。

如果某个属性已应用 Pre-Comp Override，该控件的行上会出现一个紫色圆点以示区别。

设置覆盖

在场景窗口中双击 Pre-Comp 将其加载到属性编辑器，然后在 Overrides 选项卡中右键单击某个属性的行并选择 Override，即可看到以下选项：

  • Reveal the Origin Layer - 打开原始 Composition，并将该属性所属的父级图层加载到属性编辑器。
  • Remove this Pre-Comp Override - 移除该 Pre-Comp Override。这等同于按照上文的步骤移除 Pre-Comp Override。
  • Reset Value to Origin - 将该属性的值重置为原始 Composition 中设置的值。

信息：

请注意，当 Composition 作为引用导入时，Reveal the Origin Layer 和 Remove this Pre-Comp Override 不可用。

重新排序覆盖

如果某个 Composition 包含带有 Pre-Comp Override 的图层，其所在行会在 资源窗口 中显示一个齿轮图标。单击该齿轮将显示所有带有 Pre-Comp Override 的属性列表。随后可以拖动这些属性，以自定义它们在 Pre-Comp 属性编辑器界面的 Overrides 选项卡中出现的顺序。

命名覆盖

默认情况下，Pre-Comp Override 的标签显示为 layerNiceName.attrNiceName。例如，如果名为 MyLayer 的图层的 Position 属性被设为 Pre-Comp Override，那么它将在 Pre-Comp 的 Overrides 选项卡中显示为 MyLayer.Position。

如需自定义名称，可以在属性编辑器中右键单击属性的标签并选择 Rename... 来重命名属性。这种情况下，标签将仅显示为 attrNiceName。例如，如果名为 MyLayer 的图层的 Position 属性被重命名为“My Custom Label”并设为 Pre-Comp Override，那么它将在 Pre-Comp 的 Overrides 选项卡中显示为 My Custom Label。
