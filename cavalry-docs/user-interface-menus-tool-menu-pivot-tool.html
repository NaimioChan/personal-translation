轴心工具

简介

在视口中移动图形的轴心点。

轴心是图形旋转或缩放所围绕的位置。轴心工具可用于在不改变图形视觉位置的情况下操作轴心，反之亦然。

界面

要在不移动图形视觉位置的情况下定位轴心，可以：

  • 单击并拖拽轴心。
  • 单击 9 个网格点之一，将轴心设为该点的位置。

要在不移动轴心视觉位置的情况下定位图形，可以：

  • Option/Alt + 单击并拖拽轴心。
  • Option/Alt + 单击 9 个网格点之一，将轴心移动到该位置。

可以使用快捷键 1-9 吸附到网格点，其中 1 是左下角，9 是右上角。

吸附

轴心工具支持视口吸附选项。按住 Shift 也会启用轴向吸附。

如果启用了视口吸附，按住 Cmd/Ctrl 会将其禁用。
