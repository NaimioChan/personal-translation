值2

简介

一个简单的行为，可以存储和操控二维数值。

界面

Common Attributes +

Value：设置二维数值。

Offset：从 Value 中增加/减去一个值。

Time Offset：设置用于偏移动画曲线的值。例如，如果一个 2D 图形的 Position 连接到 Value2 的 Value，那么当 Value2 的 Id（输出）连接到另一个图形的 Position 时，就可以用 Time Offset 延迟该图形的动画。负值表示时间向后。

信息：

Value2 上的 Id（输出）连接是一个向量，因此可以用来连接到相同数据类型的属性，例如 2D 位置。
