分段路径

简介

将路径分割为更小的片段以创建子网格。

界面

Common Attributes +

Input Shapes：连接要分割为片段的图形。

Mode：决定路径的分段方式：

  • Number of Cuts：Input Shapes 将被均匀分割为 [Count] 份。
  • Automatic Cuts：Input Shapes 将在其点处自动分割。

Count：设置从 Input Shapes 创建多少个片段。

Extension Mode：

  • Start：从片段的起点延伸修剪路径。
  • End：从片段的终点延伸修剪路径。
  • Both：同时从片段的起点和终点延伸修剪路径。

Extend：设置片段延伸的量。

示例：

  1. 使用Pencil 工具绘制一条开放路径。
  2. 创建一个 Segment Path。
  3. 连接 path.id→segmentPath.inputShapes
  4. 在 Segment Path 上，点击 Deformers 属性上的 +，然后从列表中选择 子网格。
  5. 在 Sub-Mesh 上，打开 Stroke 标签页并启用 Replace Stroke。
  6. 右键点击 Stroke Color 属性并选择 Add Array > Color Array。
  7. 向 颜色数组 再添加三个索引，并为每个索引设置不同的颜色。

原始路径应被分割为四种不同的颜色。
