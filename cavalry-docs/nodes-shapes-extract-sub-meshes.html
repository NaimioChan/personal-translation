提取子网格

简介

通过从另一个图形中提取特定的子网格来创建图形。所有材质和动画也会一并复制到生成的 Extract Sub-Meshes 图形中。

这可用于：

  • 提取 Duplicator 的不同部分，并将它们放入布局组中。
  • 提取 Duplicator 的一部分，以便使用 应用分布 重新分布特定的 Id。
  • 提取 Pre-Comp 中包含的图形。

界面

Common Attributes +

Input Shape - 连接一个图形，以从中提取子网格。参见 Input List。

Indices - 要提取的图形的索引。可以在网格浏览器中查看 Id，也可以使用视口中的 Draw Debug Information 选项查看。

Level Mode - 提取子网格的层级。

Ignore Empty Sub-Meshes - 提取网格时，忽略任何为空的 Id。

示例：

  1. 创建一个 Ellipse。
  2. 在选中 Ellipse 的情况下，单击工具架中的 复制器 图标。
  3. 创建一个 Extract Sub-Meshes。
  4. 连接 duplicator.id→extractSubMeshes.inputShape
  5. 隐藏 Duplicator。

由于这些是默认指定的索引，因此仅提取 Duplicator 的第一个和最后一个索引。试着将 Indices 中的 first,last 替换为 0:3 或 3, 6, 8。

Material：

材质会从 Input Shape 复制而来，但可以通过在属性编辑器的相应选项卡中勾选 Fill 或 Stroke 来替换。
