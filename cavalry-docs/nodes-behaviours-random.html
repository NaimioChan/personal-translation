随机

简介

生成随机数。

界面

通用属性 +

Strength Fade to Zero：勾选后，Strength（包括 衰减）将在 0 和结果之间插值。取消勾选时，将在 Minimum 和 Maximum 值之间插值。

Use Normals：勾选后，变形将基于图形的法线。取消勾选时，点会从图形中心缩放。仅在作为变形器使用时相关。

Minimum：设置要生成的最小数。

Maximum：设置要生成的最大数。

Seed：设置随机种子。

Use Layer as Seed：勾选后，Random 行为连接的每个图层都会使用不同的 Seed。另见 图层种子。

Offset：为输出加上/减去一个值。

Separate Channels：为 x 和 y 生成不同的随机值。

Use Bias Graph：勾选后，可使用 Bias Graph 设置随机数的概率。

Bias Graph：参见 通用属性。
