输入图形：变换

简介

包括复制器在内的多项功能会忽略作为 Input Shape 连接的父图形的变换信息。这是有意为之，以避免可能出现的偏移混乱。

详情

为避免图形作为复制器的一部分时未出现在预期位置而造成困惑，Input Shape 的变换信息会被忽略。“变换信息”包括任何图形的 Position、Rotation、Scale、Skew 和 Pivot 属性。

当 Position 为 100,100 的图形作为复制器的 Input Shape 连接时，该位置会被忽略并重置为 0,0。结果是每个副本都位于各自分布点的位置，而不会因其 100,100 的位置而偏移。这样设计是为了避免因意外添加偏移而造成的任何困惑。

这仅适用于父图形，图形任何子级的变换信息都会被保留。可以利用这种层级关系来覆盖内置功能。在下例中，Group 作为复制器的 Input Shape 连接，而 Shape 是 Group 的子级。在这种情况下，图形的 Position 100,100 会被传递过去，从而使每个副本相对复制器的点偏移该数值。Group 保持在 0,0，但图形在 Group 内的位置会被保留。

  • Group（忽略变换）
    • Shape（保留变换）

此技巧也可用于将任何变换动画传递给复制器。将带动画的图形添加到 Group，再将该 Group 添加到复制器，Group 会被定位到一个点上，而图形随后会在 Group 内移动。
