着色器数组

简介

创建一个着色器列表，可通过索引将它们指定给其他图层。

界面

Auto Index：自动输出数组中的所有索引。

Index：手动输出数组中的一个索引（取消勾选 Auto Index 后可启用）。

Reverse：反转索引的输出顺序。例如，有 3 个索引 0,1,2 时，它们的顺序会反转为 2,1,0。

Count：输出数组中的索引数量。

Add

0: Shader：数组中的第一个索引。为每个索引连接一个着色器。

示例：

  1. 创建一个 Ellipse。
  2. 选中该 Ellipse。
  3. 点击 工具架 中的 复制器 图标。
  4. 创建 3 个 Gradient Shaders。
  5. 创建一个 Shader Array。
  6. 使用 AddShader Array。
  7. 将各个 Gradient Shaders 连接到 Shader Array 的对应索引。
  8. 将 Shader Array 连接到 Shape 上的 Shaders 属性（位于 Fill 标签页下）。

双击设置 Index：

双击某个索引所在的行，就会把 Index 设为该值。
