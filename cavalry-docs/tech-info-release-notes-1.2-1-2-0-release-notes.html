1.2 发布说明

版本升级：

说明：1.2 版本将 macOS 的最低系统要求提升至 10.14。

新功能

Forge Dynamics

  • 💥 Forge Dynamics：刚体动力学现已登陆 Cavalry。要开始使用，请先选中一个图形，在工具架中点击 Forge 图标（F）并按下播放，或尝试 Create 菜单下新增的 Presets 之一。
    • 新增 吸引场：将图形拉向或推离目标。
    • 新增 方向场：创建方向力，推动图形沿其移动。
    • 新增 拖拽场：对图形的位置速度和旋转速度施加反向力。
    • 新增 桥接约束：将图形链接在一起。
    • 新增 距离约束：将图形约束在其原始位置。
    • 新增 固定约束：将图形固定在其位置。
    • 新增 Body 设置碰撞事件：在图形碰撞时更改其 Density/ Friction/ Bounce 等参数。
    • 新增 颜色碰撞事件：在图形碰撞时更改其颜色。
    • 新增 冲量碰撞事件：在图形碰撞时为其添加额外的力。
    • 新增 粘性碰撞事件：在图形碰撞时将它们粘在一起。
    • 新增 可见性碰撞事件：在图形碰撞时影响其可见性。
    • 新增 Dynamics 菜单，简化模拟的设置与编辑。

授权

新的授权模式。免费版现在更加自由！更多信息见 此处。

Apple Silicon (M1)

  • 💥 Apple Silicon Build：使用 Apple Silicon 机型的用户现在可以炫耀自己拥有运行 Cavalry 最快的机器。初步测试显示，相比 Intel i9 处理器，性能提升最高可达 3 倍。

文本

  • 新增 Apply Text Fill 工具（在 Cavalry 2.1.3 中已被 应用文本材质 工具取代）。这是一个可用于 Text Shape 的材质行为，允许你为特定的字符、单词或行设置颜色。试试属性编辑器界面顶部栏中新增的预设图标。
  • 新增 应用字符间距 工具。用它来创建程序化的字偶间距对或字符间距调整。
  • 新增 Formatted Date String Generator。

绘制

  • 新增 Direct Bezier Manipulation，已加入 Edit Shape 工具，现在你可以拖动路径边缘来轻松微调曲线。
  • Pencil 工具新增 Stabiliser，帮助你绘制更平滑的曲线。用这种方式画画极其放松！可通过 Pencil 的 Tool Settings 启用。
  • Reverse Path Deformer：以程序化方式快速反转任意图形上的路径。

滤镜

  • 滤镜 现在可用于合成。（说明：目前尚不包括 Blur、Mask Blur 或 Drop Shadow）
  • 新增 色差滤镜：为着色器添加色差效果。
  • 新增 半调滤镜：为图形/着色器添加半调效果。
  • 新增 像素化滤镜：对 Shaders 进行像素化，提供正方形、三角形和六边形图案选项。
  • 新增 RGB 分离滤镜：分离图形/着色器的 RGB 颜色通道。
  • 新增 抖动滤镜

常规

  • 工作区！你可以保存并加载自己的窗口布局。
  • Focus mode：使用 Cmd/Ctrl + Tab 在当前工作区与仅由视口和工具栏组成的精简布局之间切换。
  • Notes：在场景窗口中右键点击图层，选择列表中靠上的 Notes...，即可为图层添加备注。添加备注后，悬停在图层上时便会显示，也可通过该行上的按钮访问。备注支持 markdown。
  • 在 Edit 菜单中新增了 Arrange 菜单，包含 Bring Forward/ Send Backward 等命令。
  • 新增 排序分布，可根据多种设置重新排列点。
  • Animation 菜单中新增 Move Along Path 菜单项。
  • 颜色窗口新增 HSV
  • Spreadsheet Settings：现在可以设置自定义分隔符、小数分隔符和引号字符。
  • 新增 Viewport Quality 设置。
  • 渲染管理器中新增 Render Quality 设置。
  • 渲染管理器新增 .mp4 格式。
  • 新增 Ray Shape。
  • 文件菜单中新增更多 Recent File 快捷方式。

常规改进/ 重要修复

  • 现在你可以在视口中看到（并选中）合成边界之外的图形。😊（对组的支持仍在开发中）
  • 对 ProRes 导出进行了多项改进，尤其是 4444 和 4444XQ + alpha 通道方面：
    • 在 Windows（以及 macOS）上的 Adobe 产品中，Alpha 现在应能被正确解析。
    • 在 Resolve 中，0% 的 alpha 现在会被采样为绝对的 0。
    • 修复了 Alpha 颜色问题。
  • 序列 工具新增 Travel、Reverse 和 Offset。
  • 是否在范围内 工具新增 Invert。
  • 资源窗口右键菜单中新增 Duplicate Composition。
  • 自动保存文件新增 Year-Month-Day-Weekday 日期格式。
  • Sound Behaviour 现在与音频播放一样处于 beta 标记之后。现在未启用实验性功能时也无法导入音频。实验性功能可在首选项窗口中启用。
  • 工具架与 Tool Settings 窗口现已分离。
  • 🇬🇧 与 🇺🇸 拼写。我们在应用/文档中有点身份认同危机。😊 对不住美国的朋友们，不过我们目前选择暂时以母语拼写统一。Color 尚待处理，未来我们计划通过本地化让所有人都满意。
  • 混合子网格位置 现在会遵循全局位置。
  • 将资源导入资源窗口时，现在会将资源添加到所选的层级中。
  • 现在你可以 Toggle Composition Background Alpha，以便更好地处理 alpha。
  • 对 胶囊 基础图形进行了多项改进：
    • 现在可以 Trim Ends。
    • Capsule 现在有新的 Start/ End 模式。
    • 现在可以在视口中操控 Capsule 的端点。
  • 💥 Layer Tools：现在可以在视口中编辑 Ellipses 的 Radius，以及 Rectangle 的 Width、Height 和 Corner Radius。后续还会有更多！
  • 现在你可以在图形之间共享描边和填充。右键点击 Fill 或 Stroke 复选框，选择 'Reveal' 选项。这会在场景窗口中显示一个新的图层，随后你可以将它连接到多个图形。
  • Pathfinder 现在有 Rotation Offset。
  • Quad Tree 现在会对齐到像素网格，以防四边形之间出现不需要的间隙。
  • 电子表格数据现在支持逗号作为分隔符。说明：逗号仍不支持作为小数分隔符。
  • 现在可以在渲染管理器的 File Name 和 Path 属性中使用环境变量。
  • 与渲染管理器中 Dynamic Index 的连接现在会显示出来。
  • 修复了复制器上 Shape Visibility 的问题。
  • 修复了 四叉树图形 之间出现间隙的问题。
  • Animation 菜单中新增 Set Transform Keyframes 选项，可为选中的图层设置 Position、Rotation 和 Scale 关键帧。
  • 修复了 SVG 错误传递 corner radius 值的问题。
  • 在 Edit Shape 工具中拆分路径时，Shift + S + 点击现在会创建角点（S + 点击创建贝塞尔点）。
  • 改进了与 LottieFiles iOS 播放器的兼容性（还有更多工作要做）。
