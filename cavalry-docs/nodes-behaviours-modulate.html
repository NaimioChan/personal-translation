调制

简介

使用取模函数输出重复的数字序列。

界面

Common Attributes +

Mode：

  • Remainder：基于 Divisor 值创建序列。
  • Pass/Fail：根据余数是否为 0（通过）来创建序列。
  • Custom Pattern：创建自定义序列。

Divisor：设为 n 会创建从 0:n-1 的数字序列。例如值为 3 时会创建序列 0,1,2,0,1,2,0……（见下文）。

Index Offset：偏移图案的顺序。例如图案为 0, 1, 2, 0, 1, 2……时，Index Offset 为 1 会得到 1, 2, 0, 1, 2, 0……

Offset：偏移起始值。例如图案为 0, 1, 2, 0, 1, 2……时，Offset 为 2 会得到 2, 3, 4, 2, 3, 4……

Pass Value：当余数为 0 时，输出此值。

Fail Value：当余数不为 0 时，输出此值。

Custom Pattern：输入以逗号分隔的值图案。

示例（Remainder）：

  1. 创建 3 个基本图形（圆形、矩形、多边形）。
  2. 在选中全部 3 个图形的情况下，单击复制器图标（位于工具架中）。
  3. 在复制器上将 Count 设为 x = 5、y = 5。
  4. 创建一个 Modulate。
  5. 将 Divisor 设为 3。
  6. 连接 modulate.id→duplicator.shapeId

当 Divisor 为 3 时，Modulate 会输出 0, 1, 2, 0, 1, 2, 0……因此复制器会输出 圆形、矩形、多边形、圆形、矩形、多边形、圆形……（取决于它们被添加的顺序）。

示例（Pass/Fail）：

  1. 创建一个基本图形。
  2. 在选中该图形的情况下，单击复制器图标（位于工具架中）。
  3. 在复制器上将 Distribution 设为 Linear。
  4. 将 Count 设为 9，Size 设为 900.
  5. 创建一个颜色数组。
  6. 添加第二个索引并设置不同的颜色。
  7. 连接 colorArray.id→basicShape.FillColor
  8. 创建一个 Modulate 行为。
  9. 将 Mode 设为 Pass/Fail。
  10. 将 Divisor 设为 3。
  11. 连接 modulate.id→colorArray.index

得到的序列是 0,1,1,0,1,1,0……（计算过程见下文）。如果 Pass Value = 0 且 Fail Value = 1，那么对应的就是 通过、失败、失败、通过、失败、失败、通过……如果颜色数组上的颜色为红色和绿色，最终得到的颜色序列便是 红、绿、绿、红、绿、绿、红、绿……

信息：

Remainder 和 Pass/ Fail 模式使用模运算。

这里我们用 Divisor 为 3 来除一个数字。观察当这个数字每次加一时，余数值会发生什么变化。

  • 0 \div 3 = 00
  • 1 \div 3 = 01
  • 2 \div 3 = 02
  • 3 \div 3 = 10
  • 4 \div 3 = 11
  • 5 \div 3 = 12
  • 6 \div 3 = 20
  • ...

余数从 0 开始，每次递增 1，直到该数字达到 Divisor 减一为止。之后序列便会重复。因此，要创建序列 0,1,2,3,0,1,2,3,……需要 Divisor 为 4。
