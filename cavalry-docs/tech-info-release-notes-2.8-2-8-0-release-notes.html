2.8 发行说明

发布日期：2026年9月30日

新功能

常规

  • MCP：通过向 AI 助手给出自然语言指令，自动化 Cavalry 中的重复性任务。
  • Spreadsheet Utility 现在支持 Canva Sheets。
  • AI Studio 窗口：借助 AI 的强大能力，辅助完成视频背景移除、生成矢量以及将图像拆分为图层。
  • 支持 Affinity（.af）文件资源。

图形

  • 融合球图形：将多个图形组合成一个有机的团块。

工具

  • 自定义下拉菜单：创建自定义下拉菜单，可从一组固定定义的自定义选项中设置颜色、对齐方式和文本等属性。

效果

  • 光照滤镜：为图形添加接触阴影和点光源，以创建长阴影。
  • 扭转滤镜：绕中心点旋转图形的材质。
  • 波纹滤镜：使用线性、同心或螺旋波纹图案扭曲图形的材质。
  • 曲线滤镜：通过可编辑的曲线，对图层的 RGB、alpha 和色相/饱和度分量进行色彩校正。

脚本

API

  • getMagicEasing
  • loadCanvaSheet
  • replaceCanvaSheet
  • getCanvaSheetAssetURL
  • isCanvaSheetAsset
  • controlCentreSetLayout

Cavalry

  • getMaterialAtIndex

Script UIs

  • SegmentedControl

增强

  • 为图形新增 Posterize Time 属性（Advanced 标签页）。
  • Sound 行为已重写，并包含一些问题修复和改进。注意，旧版场景将继续使用旧版 Sound 行为。
  • SVG 导入现在支持：
    • 渐变（线性、径向和扫描）。
    • 不透明度。
    • 文本。
    • 剪切蒙版。
  • 控制中心支持重新排序和分组。
  • 现在可以为 Font 输入设置收藏夹。
  • 提升了视频播放的性能。
  • 提升了音频播放的性能。
  • 视口的 Audio Settings 选项中新增了 Output Channels 选项。
  • 曲线编辑器有多项更新，包括：
    • 当曲线编辑器处于空状态时，窗口会显示关于如何加载关键帧/动画曲线的说明。
    • 吸附设置中新增了 Snap to Keyframes 和 Snap to Whole Numbers 选项。
    • 现在可以使用套索选择关键帧。按住 Option/Alt 并在窗口空白处点击 + 拖动。
    • Looping > Loop Before/After 菜单项新增了 Continue 模式。
    • 新增 Loop Settings...，其中包含 Limit Loops 和 Filter Last Keyframes。
    • Option/Alt + 双击动画曲线会打开新的 Loop Settings... 弹出窗口。
    • 插值选项中新增 Auto-Bézier、Stepped Next、Plateau、Spline 和 Clamped 模式。
    • 底部栏已更新，加入了更多插值选项。
    • 将鼠标悬停在关键帧上时，会显示包含其对应值的工具提示。
    • 底部栏新增了缓冲选项。
    • 现在可以选择贝塞尔手柄并按 Delete 键，将其长度设为 0（即移除它）。注意，这是在按住 X 键点击手柄之外新增的方式。
    • 右键菜单中新增了 Reverse Animation 命令。
  • 时间编辑器有多项更新，包括：
    • 当播放头移出视图边界时，时间轴现在会平移以跟随播放头。
    • 右键菜单中新增了 Reverse Animation 命令。
    • 动画曲线和关键帧现在可以对齐到播放头。选择一个或多个动画曲线并使用对齐工具（对关键帧需按住 Option/Alt），即可将动画对齐到当前时间。
    • 子图层可见性片段中超出父级时长的部分现在会变暗显示。这体现了它继承父级可见性的事实，因此当父级不可见时它也会被隐藏。
  • 现在可以拖动 Playhead 界面的竖线部分。在距该线 5px 以内点击并拖动即可移动它。如果某个关键帧或图层也处于同一范围内，则该关键帧或图层将优先被选中。
  • 变形 已重写。旧版场景文件将继续使用之前的版本，因此可以/应该手动升级。
  • Tapered Strokes 现在可以通过图表和Stroke Width 工具来定义。
  • 文本图形 现在包含 Justify All Lines 选项，以支持手动换行。
  • 渲染管理器改进：
    • Render Queue Items 现在可以通过拖放来重新排序。
    • 新增用于删除、展开和折叠所有 Render Queue Items 的选项。
    • 新增每个 Render Queue Item 各自的进度条。
    • 展开/折叠/删除等操作现在会作用于所有选中的 Render Queue Items。
  • 连接弹窗的行采用了新的“胶囊”样式界面。
  • 首次从脚本菜单运行脚本时，现在会执行恶意代码检查。
  • 等值线图形 已扩展，以支持着色器并改进平滑效果。
  • Windows 现在支持多重采样抗锯齿（MSAA）。这也带来了一些通过视口设置处理该功能的方式上的变化。
  • .gif 导出有多项更新，包括改进的颜色表生成和抖动选项。
  • 在视口中编辑运动路径的 Velocity Curve 的功能已改进。
  • Text Shape 的 String 输入现在支持对齐，并且可以调整大小。

重要缺陷修复

  • 通过连接弹窗快速连续删除多个变形器/滤镜时，不再触发崩溃。
  • SkSL 滤镜 支持遮罩。
  • 如果未设置 Project，颜色窗口中的 Project 调色板现在会被禁用。
  • 修复了与边界框面积小于 65536 px^2 的开放路径相关的问题，该问题在 Viewport Quality 设为 High 时出现。
  • 橡皮管肢体 的旋转反转问题已修正。注意，如果此前通过属性表达式（*-1）来规避该问题，则应将这些表达式移除。
  • 在 JavaScript 中编写的包含 3 个条目的数组，现在能正确将值传递给 值3。
  • 复制包含已静音属性的合成时，不再导致崩溃。
  • 更改合成的 Frame Range 时，时间编辑器的缩放不再被重置。
  • 将 Shader 的 Scale 设为 0 时，不再隐藏其他所有 Shader。
  • 关闭并重新打开渐变的色标弹出窗口时，色标的 alpha 值现在会保留。
  • 已解决一个过度优化问题：连接了 展平图形图层 的图形更新无法即时生效。
  • Pre-Comp 中现在支持带动画的 晶格变形器。
  • 在 关键帧图层 窗口中双击 Default 图层时，该图层会按预期高亮为绿色。
  • Composition Boundary 的视口设置窗口现在具有正确的标题。
  • 曲线编辑器现在会沿贝塞尔曲线正确表示整数属性。
  • 影响 .mp4 导出的色彩空间缺陷已解决。这是一个非常特殊的情况：RGB→YUV 使用 BT.601 矩阵进行转换，但流却被标记为 BT.709。此前有多份关于 .mp4 出现色彩偏移的报告，我们希望这能解决其中部分/许多情况。
  • 当 Kinematic Hybrid 刚体的动画结束时，现在会以更自然的方式转入 Forge Dynamics 模拟。
  • 已解决对某些颜色启用 Color Management 时出现的明显色彩偏移。
  • 已解决一个问题：图层名称过长可能导致连接弹窗中的断开连接界面被遮挡。
  • 导入的字体资源现在会在资源窗口中正确标记为“使用中”。
  • 已解决一个问题：使用 Option/Alt 键创建多个连接时，图形的 Fill 标签页中会出现“幽灵”图层。
  • 当图形作为剪切蒙版连接到 组 时，Feather 现在可按预期工作。
  • Change String Case 字符串操作器现在能正确处理非句点字符（例如 U+2019 RIGHT SINGLE QUOTATION MARK）。
  • 当通过 Formatted String 字符串生成器引入硬换行时，Style Behaviours 现在能正确遵循 'last' 标记。
  • 已解决勾选 Avoid Orphans 时导致富文本样式发生变化的问题。
  • 已修复 ui.Draw 中的崩溃。
  • ui.List 项目不再“拉伸”以填满其容器。
  • 已解决一个问题：在 Windows 上，非常长（30 分钟以上）的 ProRes 渲染会失败。
  • 已解决一个问题：包含 alpha 通道、但第一帧没有 alpha的 ProRes 4444 文件无法导入 After Effects。

说明

  • CLI 在 Cavalry 2.8.0 中不可用，因此如果你正在使用该功能，请继续使用当前版本。我们正努力在后续版本中恢复该功能。

已知问题

如果购买了 AI Pass，需要重启 Cavalry 才能被检测到。
