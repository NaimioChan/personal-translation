HSV 调整滤镜

简介

调整图形的色相、饱和度和明度。

界面

通用属性 +

Hue：围绕色轮偏移图形的色相。

Saturation：增大/减小图形的饱和度。

Legacy Saturation：勾选后，图形的饱和度会乘以 Saturation 属性，以获得更强烈的效果。

Value：设置图形的明度。

HSL：勾选后，色相、饱和度和明度会被转换为色相、饱和度和亮度。此时上方的 Value 属性改为设置亮度值。
