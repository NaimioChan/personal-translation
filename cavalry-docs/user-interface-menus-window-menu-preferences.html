首选项

简介

设置用于 Cavalry 工作方式的自定义首选项。

信息：

该窗口在 Windows 上位于编辑菜单下，在 macOS 上位于 Cavalry 菜单下。

首选项

Show Experimental Features：勾选后，带有“experimental”标记的功能将可用。

保存

JSON format：设置文件的保存格式：

  • Pretty：缩进设为 4 个空格。这是最“便于人阅读”的格式，但生成的文件体积最大。
  • Compact：缩进设为 1 个空格，并且文件会被进一步“压缩”。这种格式“便于人阅读”，但生成的文件比 Pretty 更小。
  • One Line：整个文件保存为单行。这种格式不易“便于人阅读”，但生成的文件体积最小。

Pretty Print：

以 Compact 或 One Line 保存的文件仍可以使用 VSCode/Sublime 等编辑器中的 pretty-print 功能，或通过 JSONLint.com 之类的网站转换为 Pretty 格式。

Autosave：

  • Off：不自动保存。
  • Reminders：在通知栏中显示提醒。
  • Autosave：根据 Autosave Interval 保存文件。只有在自上次保存以来发生过更改时，才会创建自动保存文件。

Autosave Interval：设置自动保存的时间间隔（分钟）。

Autosave Folders：将自动保存文件分入按日期的目录：

  • Off：不保存到目录中。
  • Weekday-Day-Month-Year：例如 Thu-26-03-2023
  • Weekday-Month-Day-Year：例如 Thu-03-26-2023
  • Year-Month-Day-Weekday：例如 2023-03-26-Thu

Autosave Limit：设置可创建的自动保存文件的最大数量。达到上限后，每当创建新文件时，最旧的自动保存文件都会被删除。如果使用了 Autosave Folders，则该上限按天计算。

信息：

如果你设置了项目，则所有自动保存都会保存到项目设置中所设的目录。如果没有设置项目，则文件会保存到场景文件所在位置的自动保存目录中。

界面

UI Font Size：设置用户界面的字体大小。

  • Default：设置默认字体大小。
  • Large：设置大号字体大小。

Infinite Scrubbing：勾选后，在控件中拖动数值时不受显示器边界的限制。拖动数值时也会隐藏光标。

信息：

使用数位板/笔时此首选项会被忽略。如果光标真的发生环绕，它会与笔在带显示屏的数位板上所处的屏幕位置不一致。

Show Tips button in Message Bar：显示/隐藏消息栏中的 Tips and Tricks 按钮。

Show Feedback button in Message Bar：显示/隐藏消息栏中的 Feedback 按钮。

Max Attribute Editor UIs：设置可载入属性编辑器的界面数量上限。达到该上限后，添加任何新界面都会移除最后一个（最下方的）界面。注意：该上限不包含任何固定的界面。

Large Previews in the Attribute Editor：设置包含预览的图层（Noise、Random、Sequence 等）的预览高度。

Arrow Keys Control Hierarchy：勾选后，使用方向键将导航场景树中的层级。取消勾选后，方向键将在视口中微调所选图层，此时按住 Option/Alt 可导航层级。

Locking Layers Prevents Selection in the Scene Window：勾选后，在场景窗口中锁定图层将阻止选择该图层。注意，这也会导致单击锁定图层时 Live Mode 无法工作。

Preview Compositions in the Assets Window：勾选后，在资源窗口中悬停合成时将显示预览。

Viewport Canvas Color：设置视口画布（合成之外的区域）的颜色。

Pressing Return in an Attribute Field：决定在字段中按 Return 键时会发生什么：

  • Selects All：提交输入并选中字段内容，以便继续编辑。
  • Clears Focus：提交输入并将焦点从字段移开，以便使用快捷键/热键。

功能

Add new Layers to selected Tags：如果选中了一个或几个标签，则创建的任何新图层都会在创建时添加到该标签中。

Remember Graph Editor Curve Framing：勾选后，曲线编辑器会记住你上次处理某条动画曲线时的取景/缩放级别。

Maintain Proportional Easing：勾选后，在时间编辑器或曲线编辑器中移动关键帧时，也会缩放所有贝塞尔手柄，以保持缓动效果。

Use Absolute Bézier Positions：勾选后，在曲线编辑器中双击关键帧时，贝塞尔手柄位置的 Value 和 Frame 值将以绝对位置显示。取消勾选后，这些值将相对于关键帧显示。

Full Screen Focus Mode：勾选后，进入焦点模式时 Cavalry 将切换到全屏模式。

Nudge Step：设置按住 Shift 并使用 Animation > Nudge Backwards/Forwards 热键（-/=）时，关键帧或剪辑移动的帧数。

Default Velocity Presets：使用下拉菜单设置用于默认速度预设，可配合运动路径使用。

视口/渲染

Show Viewport Timecode：显示/隐藏视口中的时间码。

  • Never：从不在视口中显示时间码。
  • During Playback：仅在播放期间在视口中显示时间码。
  • Always：始终在视口中显示时间码。

Render Notifications：渲染完成时发送操作系统通知。

  • None：不发送通知。
  • End of Render Queue Item：每个渲染队列项目完成时发送通知。
  • End of Render Queue：整个渲染队列完成时发送通知。

色彩管理

Enable Color Management：勾选后，场景（包括大多数图像/视频资源和渲染结果）将进行色彩管理。通过为场景设置工作色彩空间，合成和其他色彩操作将使用统一的色彩空间，从而更易于控制颜色的外观。

所有图像/视频资源和渲染都会进行色彩管理，但 GIF、SVG 和 Lottie 例外，它们无论工作空间如何都会转换为 sRGB。任何渲染都会自动被赋予场景的工作色彩空间。

Bit Depth：

由于 Cavalry 尚未支持 16bit，预计会出现一些轻微的色彩偏差（最高约 1%）。

Working Color Space：选择一个色彩空间。

Display Color Space：

视口的色彩空间以及界面的某些部分可通过视口设置进行设置。

Compositing Bit Depth：确定每像素存储的颜色信息量。更高的位深度会带来更多颜色和更平滑的渐变：

  • 8-bit：每通道 256 种颜色。
  • 16-bit：每通道 65,536 种颜色。

导出

Lottie Author：你在此处输入的文本将被添加到任何 Lottie 导出的 .json 文件中。

烘焙动画

Bake Animation 命令会采样动画曲线，并根据所选设置重新绘制该曲线。它也可用于将行为或 Magic Easing 驱动的程序化动画转换为关键帧动画。这些设置可用于减少或增加使用该命令时创建的关键帧数量。

Collinear Tolerance：在采样动画曲线时，Bake Animation 命令会判断关键帧是否落在动画曲线的该角度范围内，若落在范围内则不创建关键帧。例如，将该值设为 1 会移除所有偏离动画曲线 +/- 1° 范围内的关键帧。值越高，创建的关键帧越少，结果更干净但不够精确。

Bake Accuracy：设置越高，结果越精确，但会创建更多关键帧。

性能

Image Cache Size (MB)：设置保存在内存中的图像缓存上限。

Video Cache Size (MB)：设置保存在内存中的视频缓存上限。

MCP 服务器

Enable MCP Server：勾选后，将允许与 MCP（Model Context Protocol）服务器通信。参见使用 Claude 进行 AI 自动化

MCP Server Port：设置 MCP 通信所用的端口。

信息：

上述设置可通过首选项手动编辑。
