编辑图形工具

简介

编辑图形工具可用于选择并操作可编辑图形上的点。

要创建可编辑图形，可以在使用矩形、椭圆、多边形或星形工具时勾选 Make Editable Primitives 选项，或使用图形菜单中的 Make Editable 命令（Cmd/Ctrl + E）。钢笔、铅笔和直线工具在默认情况下都会创建可编辑图形。

选择

要选择一个或多个点，先单击图形，然后可以：

  • 单击一个点。
  • 单击 + 拖拽以框选多个点（预选高亮即将推出）。
  • Option/Alt + 单击 + 拖拽以套索选择多个点。
  • 按住 Cmd/Ctrl + 单击，将点添加到选择中。
  • 双击一个点，选择同一轮廓上的所有点。
  • Shift + 双击一个点，选择图形上的所有点（当一个图形中包含多个轮廓时）。

单击图形外的任意位置将取消选择所有点。

移动

要移动一个点，只需单击 + 拖拽该点，或先选中该点，然后使用方向键以 1px 为增量微调，按住 Shift 时以 5px 为增量。

信息：

微调点时按住 Option/Alt，会从在图形的局部空间中移动点切换为在世界空间中移动。例如，微调一个旋转了 90° 的可编辑图形的点时，默认按 ⬆︎ 方向键会将点向左移动（沿其局部变换的方向）。按住 Option/Alt 则会让点改为向上移动。

编辑

点可以是角点或贝塞尔点。

要将一个或多个点从角点转换为贝塞尔点，请使用 Shape > Convert to Bézier Point 命令。要将一个或多个点从贝塞尔点转换为角点，请使用 Shape > Convert to Corner Point 命令。

更快捷的方法是直接 Option/Alt + 单击一个或多个点，在贝塞尔点与角点之间切换（例如角点会变为贝塞尔点，反之亦然）。

从角点转换为贝塞尔点时，还可以通过 Option/Alt + 单击 + 拖拽来控制贝塞尔手柄的长度。这会将角点转换为贝塞尔点，并拖出手柄，直到释放鼠标。

存在贝塞尔点的地方会出现贝塞尔手柄。手柄可以有两种状态：

  • 锁定：移动一个手柄时，相对的手柄也会向相反方向移动。
  • 解锁：每个手柄都可以独立于另一个移动。

Shape 菜单下的 Lock/Unlock bézier Handle 命令可用于将点转换为任一状态。

另一种按点逐个操作的快捷方式是 Option/Alt + 拖拽手柄。如果贝塞尔手柄处于锁定状态，Option/Alt + 拖拽手柄的一侧会将其解锁。反之，如果贝塞尔手柄处于解锁状态，Option/Alt + 拖拽手柄的一侧会将其锁定。

信息：

在一定范围内，任何贝塞尔手柄都会自动显示。无需先单击点再抓取手柄，可以直接选中它。为了更好地直观呈现其他手柄如何决定路径的形状，当选中手柄或点时，来自前一个/后一个点的入向手柄也会显示出来。

通过将路径的一端拖到另一端上，可以闭合开放路径。当光标接近某个点时，视口中会出现一个小圆圈，表示路径将被闭合。可在工具设置中调整 Close Distance 选项以改变该阈值。

工具设置

有关此工具可用的特定于上下文的选项，请参阅工具设置。

快捷键

快捷键 说明
⬆︎⬇︎⬅︎⮕ 键 以 1px 为增量在局部空间中移动选中项。
Option/Alt + ⬆︎⬇︎⬅︎⮕ 键 以 1px 为增量在世界空间中移动选中项。
Shift + ⬆︎⬇︎⬅︎⮕ 键 以 5px 为增量在局部空间中移动选中项。
Option/Alt + Shift + ⬆︎⬇︎⬅︎⮕ 键 以 5px 为增量在世界空间中移动选中项。
Option/Alt + 单击 将贝塞尔点转换为角点（或反之）。
Option/Alt + 拖拽（点） 将角点转换为贝塞尔点并设置手柄长度。
Option/Alt + 拖拽（手柄） 移动并解锁处于锁定状态的贝塞尔手柄（或反之）。
X + 单击 删除贝塞尔手柄。
Option/Alt + Delete 移除选中的点以及与之相连的两条边。
H 切换变换工具。
S + 单击 拆分路径（贝塞尔）。
S + 双击 拆分路径（角点）。
Shift 贝塞尔角度吸附。
Cmd/Ctrl 关闭吸附。
