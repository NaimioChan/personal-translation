实验性功能：

这是一项实验性功能。要启用，请在偏好设置中勾选 Enable Experimental Features。

简介

此图层可用于提取速度数据。例如，复制器 默认会添加速度数据。你可以使用此上下文，根据速度改变对象的颜色等。

界面

Strength：输出的倍数。

Offset：对输出加上或减去一个值。

示例：

  1. 创建一个 多边形。
  2. 将 Polygon 添加到一个 复制器 中。
  3. 为 Duplicator 的 Shape Position 添加 噪波。
  4. 创建一个 Velocity Magnitude Context。
  5. 连接 speedContext.id→polygon.fillColor.r

随着 Duplicator 中的图形在屏幕上移动，它们的颜色会根据行进速度而变化。提高 Velocity Magnitude Context 上的 Strength 可增强该效果。
