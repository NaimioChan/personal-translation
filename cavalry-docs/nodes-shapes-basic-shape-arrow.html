箭头

简介

创建作为基本图形一部分的箭头原始图形。

界面

Body Length：设置主体的长度。

Body Width：设置主体的宽度。

First End：选择第一个端点的形状。

  • Arrow End
    • End Length：从主体末端到端点尖端的长度。
    • End Width：该值是 Body Width 的偏移量。
    • Barb Length：移动箭头端点的倒刺。正值朝向箭头中部。
  • Barbed End
    • End Length：从主体末端到端点尖端的长度。
    • Barb Width：设置倒刺末端距主体的垂直距离。该值是 Body Width 的偏移量。
    • Barb Position：移动箭头端点的倒刺。负值朝向箭头中部。
  • Box End
    • Size：设置方框的宽度和高度。
    • Hole：勾选后，将在方框内部创建一个孔洞。
    • Hole Size：设置孔洞的宽度和高度。
  • Chevron End
    • End Length：从主体末端到端点尖端的长度。
    • Chevron Width：设置人字形末端距主体的垂直距离。该值是 Body Width 的偏移量。
    • Chevron Length：该值会加到 End Length 上，可用于加粗人字形。
    • Chevron Position：移动箭头端点的倒刺。负值朝向箭头中部。
  • Circle End -
    • Size：设置圆的宽度和高度。
    • Hole：勾选后，将在圆内部创建一个孔洞。
    • Hole Size：设置孔洞的宽度和高度。

Second End：选择第二个端点的形状。

  • 与上述 First End 相同。
