边界框约束

简介

将图形约束到其他图形的边界框。

界面

Input Shape：连接要采样其边界框的图形。

Width：值为 0 时，固定到 Input Shape 边界框的左侧；值为 100 时，固定到右侧。

Height：值为 0 时，固定到 Input Shape 边界框的底部；值为 100 时，固定到顶部。

Offset：为输出加上或减去 [x, y] 值。

Out Position [只读]：显示该图层输出的 [x, y] 值。Id 连接会同时包含 x 和 y 位置，而该属性允许你将单独的 [x, y] 属性连接到其他图层。

示例：

  1. 创建 2 个图形。
  2. 创建一个 Bounding Box Constraint。
  3. 连接 shape1.id→boundingBoxConstraint.inputShape
  4. 连接 boundingBoxConstraint.id→shape2.position
  5. 将 Bounding Box Constraint 的 Width 设为 0。

Shape 2 将被约束到 Shape 1 边界框的左边缘。
