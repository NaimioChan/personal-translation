测量文本

简介

一种无需在视口中渲染即可输出字符串边界框的优化方法。由于不需要在视口中渲染文本图形，在搭建需要获知文本图形宽度/高度的绑定装置时，这种方法速度更快。

界面

String：输入要测量的字符串。

+：添加一个字符串生成器。

Font：选择字体和字重。

Typeface：连接一个 Typeface。参见 字体。

Font Size：设置字体大小。

Out Text Size：输出所得文本的尺寸。这表示文本在一行内的尺寸，并忽略 Text Box Size。

Text Box Size：设置文本在文本框内绘制时的换行区域尺寸。更改此项会影响 Out Font Scale，但不会影响 Out Text Size。

Allow Word Breaks：取消勾选时，单词不会被拆分到多行，而是保持完整，并相应缩小文本以适配。

Out Font Scale：输出为使文本适配 Text Box Size 而应用的缩放系数。文本图形的 Shrink to Fit Text Box 功能会在后台启用。
