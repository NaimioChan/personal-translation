调色板

简介

调色板以人类可读的 .json 文件形式保存，既可以通过颜色窗口在应用内创建，也可以在文本编辑器中手动创建。

调色板可在颜色窗口的 Swatches 标签页中使用。

格式

一个包含 4 个色板的示例调色板（.pal）文件：

{

    "colors": [

        {

            "color": "#c8c8c8",

            "swatchName": "Grey",

            "uid": 0

        },

        {

            "color": "#ffffff",

            "swatchName": "White",

            "uid": 1

        },

        {

            "color": "#000000",

            "swatchName": "Black",

            "uid": 2

        },

        {

            "color": "#4ffd7a",

            "swatchName": "Green",

            "types": [

                "shader",

                "filter"

            ],

            "uid": 3

        }

    ],

    "designer": "Scene Group",

    "fileType": ".pal",

    "name": "Cavalry",

    "version": 1.0,

    "website": "https://cavalry.studio/"

}

键

  • colors（必填）：颜色数组。
    • color（必填）：设置色板的十六进制颜色值。
    • swatchName（必填）：设置色板名称。目前 Library Palettes 界面并未使用该名称，因此如有需要可以留空（例如 "swatchName": ""），但建议为 Label Palettes 设置。
    • uid：色板的 Id。Label Palettes 在切换调色板时会使用它来为图层/关键帧/时间标记重新分配颜色。
    • types：一组 superTypes，用于从 Label Palettes 为图层指定默认的标签颜色。
  • designer：作者名称。
  • fileType：指定文件扩展名。
  • name（推荐）：为调色板命名。该名称会显示在 Library Palettes 和 Label Palettes 的下拉菜单中。
  • version：设置版本号，以便将来保持兼容。
  • website：添加 designer 的 URL。

存储调色板

Library 调色板

默认的 Library Palettes 以 .pal 文件保存在：

macOS：~/Library/Application Support/Cavalry/Palettes

Windows：C:\Users\USERNAME\AppData\Roaming\Cavalry\Palettes

只需在上述 Palettes 目录内创建新目录，即可创建更多调色板库。例如，在 Palettes 目录内添加一个名为 Scene Group 的目录，就会创建一个名为 Scene Group 的新 Library，可通过颜色窗口中的 Options menu 访问和加载。

小心：

仅支持 Palettes 目录下一级的目录，并且目录必须至少包含一个调色板才会出现在颜色窗口的选项中。

Library Palettes 也可以在使用项目设置时作为项目的一部分保存。默认情况下，该目录为 @project/Assets/Palettes/。

Label 调色板

默认的 Label Palettes 以 .pal 文件保存在：

macOS：~/Library/Application Support/Cavalry/LabelPalettes

Windows：C:\Users\USERNAME\AppData\Roaming\Cavalry\LabelPalettes
