时间轴

简介

时间轴是时间编辑器或曲线编辑器上方的区域，包含播放头，也容纳时间标记。

设置当前帧

  • 点击并拖拽青色的播放头，可在时间轴中拖动浏览。
  • 点击时间轴中的任意位置，可将播放头移动到该帧。

播放范围

点击并拖拽青色的端点，设置 Playback Range 的起始帧和结束帧。点击并拖拽起点与终点之间的条，可移动整个 Playback Range。

时间标记

时间标记可用于引用时间轴上的重要时刻，并对关键帧和剪辑终点进行分组。在时间轴中右键点击即可添加一个。

快捷键

快捷键 命令
B 设置播放范围的起点。
N 设置播放范围的终点。
Cmd/Ctrl + ⬅︎/⮕ 在时间上向后/向前微调 1 帧。
Shift + Cmd/Ctrl + ⬅︎/⮕ 在时间上向后/向前微调 5 帧。
Shift + 拖拽播放头 吸附到每 10 帧（0、10、20 等）或吸附到时间标记
Option/Alt + Cmd/Ctrl + ⬅︎/⮕ 将播放头定位到下一个关键帧。选中图层、属性或关键帧会筛选结果。

提示：

Hold q + drag 可在任意窗口中拖动浏览时间轴。

在时间编辑器中，可以使用 Option/Alt + Cmd/Ctrl + 拖拽，用光标拖动播放头。

提示：

在视口设置中启用 Update the UI during playback，即可在播放时看到播放头动画。
