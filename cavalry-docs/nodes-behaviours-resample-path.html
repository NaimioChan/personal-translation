重采样路径

简介

移除重叠的轮廓和/或简化路径。

界面

Merge Overlaps：勾选后，任何重叠的轮廓都将根据 Mode 被移除或合并。

Mode：选择重采样的类型：

  • Union：在轮廓重叠处将它们合并在一起。
  • Simplify：移除轮廓中彼此重叠的部分。

Simplify：减少路径上的点数。

Simplify Threshold：设置一个距离，在此距离内的点将被移除。值越大，路径越简单。

Resample as Béziers：将简化后的点转换为贝塞尔点。

Corner Angle：任何以大于此值的角度相接的角点都不受重采样影响，将保留为角点。
