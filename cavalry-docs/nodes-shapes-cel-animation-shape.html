赛璐珞动画图形

简介

Cel Animation Shape 可用于创建逐帧动画。与通过创建关键帧来为图形制作动画不同，这里的每一帧都是一个新图形。

界面

Common Attributes +

Path - 每个关键帧代表一个新帧。对于不含关键帧的帧，将绘制上一个关键帧中包含的图形。

Fill Rule - 确定当一个 Editable Shape 中存在多条 Contour 时如何创建孔洞：

  • Even Odd - 任何与另一条 Contour 相交的 Contour 都会创建孔洞。
  • Winding - 要创建孔洞，相交的 Contour 必须与另一条 Contour 的绘制方向相反。

Onion Skinning - 勾选后，当前帧之前或之后的帧会在视口中预览。请确保 Viewport 选项中的 Onion Skinning 也已启用。

Frame tools：

  • Keyframe - 添加一个包含上一个关键帧内容的关键帧。
  • Copy to Next - 复制当前帧的内容，将时间轴前移一帧并将其粘贴到该帧中。
  • Clear Key - 创建一个空白关键帧，或清除现有关键帧的内容。

示例：

  1. 在 工具架 中单击 Cel Animation Shape 图标。
  2. 使用 Pencil 工具（自动选中）在视口中绘制。
  3. 向前移动一帧（Cmd/Ctrl + ⮕`）。
  4. 再次绘制。
  5. 重复步骤 3-4！

在 Cel Animation Shape 中创建新帧时，会为该帧创建一个新图形：路径并未被动画化。可以将某一帧复制到另一帧，然后移动其上的点，但每一帧都是一次新的“绘制”，并且可以包含完全独特的画面，包括多条路径。

如果某一帧留空，则它被视为“保持帧”，将绘制上一个包含图形信息的帧。若要添加空白帧，则必须创建一个空关键帧：参见上文的 Clear Key。
