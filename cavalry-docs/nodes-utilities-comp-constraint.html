合成约束

简介

将图形约束到合成。

界面

Width：设置从合成中心起的百分比，用于沿合成宽度对齐图形。

Height：设置从合成中心起的百分比，用于沿合成高度对齐图形。

Offset：为宽度和高度设置加上或减去一个值（px）。

示例：

  1. 创建一个文本图形。
  2. 创建一个 Comp Constraint 工具。
  3. 连接 compConstraint.id→textShape.position
  4. 将 Width 设为 0%。
  5. 将 Offset X 设为 50。

当分辨率设置（宽度）改变时，文本图形将保持在距合成左边缘 50px 的位置。

与动态渲染结合使用，可以输出同一合成的多种尺寸。在下面的示例中，合成的 Width 和 Height 连接到几个 值数组，然后将渲染管理器中的 Dynamic Index 连接到 Value Array 的 Array Index。同样的方法也用于设置文本图形的 Size。
