轮廓

简介

使用另一个图形的路径创建几何描边。轮廓图形与描边类似，但它不是渲染效果，而是实际创建几何体。这意味着它可以被变形，也可以用作其他图形的剪切蒙版。

界面

通用属性 +

Input Shapes：连接图形，以围绕其创建轮廓。

Width：设置轮廓的宽度。

Offset：设置轮廓相对于 Input Shapes 绘制的距离。

Cap Style：选择开放路径端点的形状：

  • Flat：将端点设为平头。
  • Projecting：将端点设为延伸。
  • Round：将端点设为圆头。

Join Style：选择路径“拐角”的形状：

  • Mitre：将拐角设为斜接。
  • Bevel：将拐角设为斜角。
  • Round：将拐角设为圆角。

Mitre Limit：设置斜接拐角的长度限制。当边之间的角度非常尖锐时，这有助于防止出现过长的斜接。

Dash Pattern：输入以逗号分隔的数字序列（实线、间隔、实线、间隔……）。

Dash Offset：沿路径偏移Dash Pattern。

Align：沿路径对齐描边。

  • Centre：沿路径中心对齐描边。
  • Inner：沿路径内侧对齐描边。
  • Outer：沿路径外侧对齐描边。

小心：

开放路径仅支持Centre对齐。当单个路径中出现多个轮廓时，无论 Align 设置如何，任何开放轮廓都会被设为Centre。

Trim：启用后，以下控件可用。

Start：设置轮廓在输入路径上开始处的百分比。

End：设置轮廓在输入路径上结束处的百分比。

Travel：使轮廓沿输入图形移动。

Reverse Path：反转轮廓沿输入路径行进的方向。

Clean Up：轮廓在某些情况下会产生不需要的几何体。虽然通常可以安全地忽略，但勾选 Clean Up 会移除任何可能导致最终网格出现问题的几何体。注意：使用此功能会影响性能。

Preserve Materials：勾选后，Input Shapes 的 Fill 或 Stroke Color 将应用到轮廓上。如果同时存在 Fill 和 Stroke，则使用 Stroke Color。

信息：

轮廓不是描边。虽然可以将其当作描边使用，但它实际上是一个图形，因此可以像任何其他图形一样使用（例如可以被变形，或用作分布路径等）。
