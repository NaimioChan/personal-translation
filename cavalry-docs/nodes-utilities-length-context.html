长度上下文

简介

Length Context 可以读取一条或多条路径的长度，并将值传递出去以影响任何其他属性。

界面

Remapping：重映射输入值。

  • None：不重映射数值。
  • Area Range：参见区域范围。
  • Number Range：参见数值范围。
  • Number Range to Color：参见数值范围转颜色。

示例：

  1. 按照拖尾页面中的示例用法创建一些拖尾。
  2. 为 trails.length 添加随机行为。
  3. 将随机行为的 Minimum 设为 10，Maximum 设为 200。
  4. 创建一个 Length Context。
  5. 设置：
    1. Source Minimum 为 0
    2. Source Maximum 为 200
    3. Minimum 为 1
    4. Maximum 为 40
  6. 连接 lengthContext.id→trails.strokeMaterial.width*
  7. 点击 Play。

随着 Trails 长度增长，其 Stroke Width 也会增加（长度为 0 时为 1px，长度为 200 时为 40px）。

可以对 Color（相应调整重映射值）或连接图形尝试类似的操作。
