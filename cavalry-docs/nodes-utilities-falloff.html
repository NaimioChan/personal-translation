衰减

简介

衰减可用于限定大多数行为和场的作用强度。默认情况下，衰减在中心输出值 1，并在边缘衰减到 0。该值用作与其连接的行为Strength 的乘数，并可通过曲线控制数值衰减的速度。

界面

Common Attributes +

Strength：Falloff Graph属性的乘数。

Shape Type：

  • Circle：按径向对Falloff Graph采样。
  • Rectangle：按 x 和 y 对Falloff Graph采样。
  • Linear：按 1 个维度对Falloff Graph采样。
  • Sweep：以类似扫描渐变的方式对Falloff Graph采样。使用衰减的Rotation可创建类似雷达的效果。
  • Shape：使用自定义图形对Falloff Graph采样。

Size：当Shape Type设为Circle、Rectangle或Linear时，设置衰减的大小。

Repetitions：当Shape Type设为Sweep时，设置扫描在Angles内重复的次数。

Angles：当Shape Type设为Sweep时，设置衰减的起始和结束角度。

Input Shapes：当Shape Type设为Shape时，连接要用作衰减的图形。

Path Mode：当Shape Type设为Shape时，确定图形的采样方式：

  • Filled Path：Input Shapes' 内的任何“点”都被视为处于完整强度。
  • Path Edges：使用距Input Shapes' 边缘的距离来计算衰减的强度。

Distance：当Shape Type设为Shape时，设置Falloff Graph 在距Input Shapes 多大范围内采样。距离为 0 表示只有图形内部的点会被视为“开启”。

Falloff Graph：参见图表属性。

Probability：衰减的值用于生成 1 或 0（真或假）。例如，衰减值为0.5 时，得到1 的几率为50%。

Seed：更改该值将影响Probability。

Custom Color：勾选后，衰减将使用Color中设置的值。取消勾选时，使用Label Color（场景窗口中使用的颜色）。

Color：设置衰减的颜色。

Enabled：取消勾选后，衰减将输出值 1（结果与没有衰减时相同）。

信息：

在场景窗口中选中衰减，并在右键上下文菜单中选择Enable/Disable Falloff(s)，也可以Enable/Disable 衰减。

提示：

参见Common Attributes（Falloff 选项卡），了解如何将Layer Modes 与行为配合使用。
