标尺与参考线

简介

标尺与参考线可用于精确对齐作品。

标尺

标尺出现在视口的顶部和左侧，可用于测量合成的像素或百分比数值，并显示光标的位置。

显示/隐藏标尺

要显示/隐藏标尺，请选择 View > Show Rulers，或使用快捷键 Cmd/Ctrl + R。

标尺选项

通过 View > Ruler Options 菜单确定标尺数值的显示方式：

  • Origin in Centre：数值以合成中心为 0,0。
  • Origin In Bottom Left：数值以合成左下角为 0,0。
  • Use Pixels：以像素显示数值。
  • Use Percentage：以合成宽度/高度的百分比显示数值。

参考线

参考线是可以放置在视口中的水平与垂直的不可渲染线条，用于定位图形。

创建参考线

要创建参考线，请将光标悬停在标尺上，然后 click + drag 到视口中。拖动时会出现一条细红线，以及一个指示其 X 或 Y 位置的数字。松开鼠标即可放置参考线。

移动参考线

要移动参考线，可以：

  • 将光标悬停在参考线上，click + drag，然后松开以重新定位参考线；或
  • 将光标悬停在参考线上，double click，然后在弹出输入框中输入新值。

最近像素：

创建或重新定位参考线时，它们始终会吸附到最近的像素。虽然可以手动输入小数值，但当标尺处于 Use Pixels 模式时，这些值会四舍五入到最接近的整数；而在 Use Percentage 模式下，则会被重新定位到最近的像素。注意，在 Use Percentage 模式下，最近的像素不太可能是整数值。

移除参考线

要移除参考线，请 click + drag 将其拖回标尺上，然后松开鼠标。

显示/隐藏参考线

使用 View > Show Guides 菜单选项或 Cmd/Ctrl + ; 来显示/隐藏参考线。

吸附：

通过在视口吸附选项中启用 Ruler Guide 吸附，可以吸附到参考线。
