图层

图层类型

Cavalry 的构建模块分为 4 类：

图形

图形是可以在视口中绘制的多边形对象。每个图形都有变换，因此可以制作动画。图形也可以受行为影响。

行为

行为可用于为数值制作动画或使图形变形。

工具

工具是提供基础功能的构建模块，可用于创建自定义方案。

效果

效果包括着色器和基于图像的滤镜。

创建图层

有几种创建图层的方法：

  • 打开添加图层窗口，双击一个图层，或将其拖入视口、属性编辑器或场景窗口。
  • 使用场景窗口顶部的 + 按钮。
  • 使用创建菜单。
  • 使用工具架中的某个快捷方式。
  • 通过工具栏。

提示：

快速打开 Add Layers 窗口的方法是按下 Cmd/Ctrl + .。
