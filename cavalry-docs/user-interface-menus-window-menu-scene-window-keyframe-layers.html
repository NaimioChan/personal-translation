关键帧图层

简介

关键帧图层使得在关键帧/动画曲线之间混合成为可能。当需要在奔跑和行走等动画状态之间切换时，这非常有用。关键帧图层可以在这些状态之间过渡，而无需复制/粘贴大段的动画。

界面

Active：启用/禁用该图层。

Strength：确定该图层的强度。

Mode：设置该图层的值与其下方图层混合的方式：

  • Normal：图层上的关键帧为叠加方式。
  • Overwrite：图层上的关键帧将覆盖其他图层。

双击图层的标题行可将其设为当前图层。控件将反映当前图层的值，任何更改都会应用到该图层。

当向任何非 Default Keyframe Layers 添加关键帧时，场景树中会出现一个额外的只读控件。它将显示所有关键帧图层的合成值。

使用垃圾桶图标可移除关键帧图层。

提示：

要将 Strength 动画曲线载入曲线编辑器，请打开 Keyframe Layer Editor 并选择要调整的图层。

示例：

  1. 打开 keyframeLayers.cv（下方的示例文件👇）并载入 Start Composition。
  2. 在场景窗口底部，单击 Keyframe Layer Editor 按钮
  3. 单击窗口右下角的 + 按钮，创建新的关键帧图层。
  4. 双击新的关键帧图层以切换到它。
  5. 在 armUpper.rotation 上设置关键帧：
    • fr0 = -50
    • fr20 = 50
    • fr40 = -50
  6. 在 armLower.rotation 上设置关键帧：
    • fr6 = 0
    • fr26 = 40
    • fr46 = 0
  7. 切换到曲线编辑器以调整动画曲线。
  8. 将时间轴移动到第 100 帧。
  9. 回到 Keyframe Layer Editor，将 Strength 设为 0 并设置一个关键帧。
  10. 将时间轴移动到第 150 帧。
  11. 将 Strength 设为 100。
  12. 按下播放。

手臂的摆动高度应在第 100 帧到 150 帧之间增加。
