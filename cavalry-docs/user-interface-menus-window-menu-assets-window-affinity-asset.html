Affinity 资源

简介

将 Affinity 的分层 .af 文件导入 Cavalry。

工作流程

将 .af 文件从资源窗口或文件系统拖入视口，会弹出一个包含两个选项的对话框：

  • Asset Layer：创建一个素材图形和图像着色器，并将 .af 资源连接到 File 属性。
  • Separate Layers：为 Affinity 文件中的每个独立图层分别创建一个素材图形和图像着色器，并将 .af 资源连接到其 File 属性。

说明

  • 从 Affinity 导入 Cavalry 时，矢量图形会被转换为光栅（图像）。
  • 如果资源已作为“独立图层”添加到合成后，又在 Affinity 中增删了图层，那么重新加载该资源时，这些图层不会在合成中同步增删。这种情况下，应将 .af 资源重新导入合成。
