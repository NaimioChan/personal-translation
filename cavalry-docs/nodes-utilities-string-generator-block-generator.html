块生成器

简介

创建文本块，并可选地使用行为来填充段落、行、单词和字符。

这可以用于许多场景，包括配合象形文字字体以及生成 FUI 文本。

界面

Paragraphs：要生成的段落数量。

Lines：每段的行数。

Words：每行的单词数量。

Characters：每个单词的字符数量。

Mode：为生成器选择一种模式：

  • Unicode Code Point：输入用于定义字体码点的值。
  • String：输入一个字符串。

Code Point：当 Mode 设置为 Unicode Code Point 时，输入一个值以定义字符的码点。例如，“!” 的码点是 33，它是大多数西文字体的第一个码点。

String：当 Mode 设置为 String 时，输入该字符串。

Word Delimiter：输入一个字符串，使其出现在单词之间。

Line Delimiter：输入一个字符串，使其出现在行之间。

示例：

  1. 创建 文本图形。
  2. 点击 GeneratorBlock。
  3. 设置：
    1. Words 为 3。
    2. Characters 为 1。
    3. Mode 为 String。
  4. 右键单击 String 属性，选择 Add Array > String Array。
  5. 点击 Add 字符串数组 以添加两个新索引。
  6. 在两个新索引中输入 Y 和 Z。
  7. 在 Block String Generator 的 Word Delimiter 属性中输入一个 ,（逗号）。

这会创建字符串 X,Y,Z。试着将 字符串数组 替换为 值数组（通过 Value String Generator）。这会创建类似 1,2,3 的字符串，随后可以将其连接到接受逗号分隔字符串的属性，例如 应用字体大小 的 Indices 属性。

示例：

  1. 创建 文本图形。
  2. 点击 GeneratorBlock。
  3. 右键单击 Characters 属性，选择 Add Behaviour > Random。
  4. 将 Random 的 Minimum 设置为 2，Maximum 设置为 6。
  5. 将 Block String Generator 的 Words 属性设置为 5。
  6. 右键单击 Block String Generator 的 Code Point 属性，选择 Add Behaviour > Random。
  7. 将此处 Random 的 Minimum 设置为 8678，Maximum 设置为 8681。
  8. 在 Block String Generator 的 Word Delimiter 属性中输入若干个 space 字符。

这会创建类似 ⇦⇨ ⇧⇦⇧⇩⇧ ⇩⇨⇩ ⇦⇨ ⇨⇧⇦⇧ ⇦⇨⇨⇧⇨ 的字符串。试着更改两个 随机 行为中任意一个的 Seed。
