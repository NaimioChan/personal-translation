动画控制

简介

将属性的动画曲线（例如从第一个关键帧到最后一个关键帧）重映射为一个百分比。

Animation Control 可以被看作是一种水平“缩放”动画曲线的方式。例如，如果某个属性有多个关键帧，总共跨越 100 帧，那么将一个 Animation Control 连接到该属性，并为其设置关键帧...

  • Amount = 0（第 0 帧）
  • Amount = 100（第 50 帧）

...这样就会使相同的动画在一半的时间内完成，也就是速度加倍。这等同于在时间编辑器中使用变换工具来缩放关键帧。

动画曲线：

动画曲线在曲线编辑器中最容易观察。它就是连接关键帧的那条线，从第一个关键帧开始，到最后一个关键帧结束。在时间编辑器中，它由连接各关键帧的彩色线表示。

使用 Animation Control 意味着一个属性可以被绑定，以触发另一个属性的动画。例如，通过将一个图形的 position.y 属性连接到 Animation Control 的 Amount 属性，当该图形向上移动时，就可以用它来驱动另一个图形的动画曲线。

界面

Active - 勾选后，Animation Control 处于激活状态。

Amount - 一个 0 到 100 之间的值，其中 0 = 第一个关键帧，100 = 最后一个关键帧。

示例：

  1. 在基础图形的 Position X 通道上创建 4 个关键帧。
  2. 连接 animationControl.id > basicShape.position.x。
  3. 拖动 Animation Control 图层上的 Amount。

当你将 Amount 从 0 移动到 100 时，基础图形将在其第一个和最后一个（第 4 个）关键帧之间播放动画。

小心：

无法在连接到激活状态的 Animation Control 的属性上编辑关键帧。取消勾选 Active 即可允许编辑。
