齿轮

简介

作为 基本图形 的一部分创建 Cogwheel（又称 Cog 或 Gear）基础图形。

界面

Teeth - 设置齿或齿轮的数量。

Pitch Radius - 设置从中心到每个齿中点的半径。

Hole Radius - 设置孔的半径。

Tooth Depth - 设置每个齿的总高度。

Tooth Width - 设置每个齿在中点处的宽度。

Tooth Taper - 设置每个齿的内侧与外侧锥度角。

Midpoint Position - 设置每个齿的中点位置，其中 0 为齿根，1 为齿尖。

齿轮示例

要创建齿轮系统，需要遵循以下基本准则：

  • 每个 Cogwheel 的 Module 必须一致。模数是一个比值，可简单表示为：Module = 2 * Pitch Radius / Number Of Teeth
  • 齿的形状/大小必须相同。
  • 每个 Cogwheel 的 Pitch Circle 必须相互“接触”。

在下面的示例中：

  • Medium Cogwheel 的 Pitch Radius 为 200，12 Teeth。
  • Small Cogwheel 的 Pitch Radius 为 100，6 Teeth。
  • Large Cogwheel 的 Pitch Radius 为 400，24 Teeth。

200 / 12、100 / 6 和 400 / 24 均等于 16.66，因此每个 Cogwheel 具有相同的 Module。

旋转的数学计算也相当简单。如果：

  • r1 = Medium Cogwheel 的旋转
  • t1 = Medium Cogwheel 的齿数
  • r2 = Small Cogwheel 的旋转
  • t2 = Small Cogwheel 的齿数

r2 = r1 * t1 / t2

对于 Medium > Small 的情况，则为：

r2 = r1 * 12/6

可以使用 JS 数学 Utility 来搭建此方程。

  1. 创建一个 JS 数学 Utility。
  2. 添加表达式 -n0 * n1/n2
  3. 添加 3 个索引。
  4. 连接 Medium.rotation→jsmath.index0
  5. 连接 Medium.teeth→jsmath.index1
  6. 连接 Small.teeth→jsmath.index2
  7. 连接 jsmath.id→Small.rotation

随着 Medium Cogwheel 旋转，Small Cogwheel 将以正确的速度旋转，从而彼此啮合。为了正确定位它们，请在 X 轴上将它们分开 300（即它们 Pitch Radius 值之和）。
