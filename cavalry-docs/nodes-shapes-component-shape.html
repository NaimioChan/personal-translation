组件

简介

Component 是一种图层，其中包含其他图层的集合。这些图层的属性可被提升到 Component 上，以便创建自定义的用户界面。

通过将其他图层设为 Component 的子级，Component 可以隐藏这些图层，从而创建简化的用户界面。参见编辑 Component。

支持的属性：

任何可创建连接的属性都可以在 Component 中使用。

快速开始：

  1. 创建一个 Component。
  2. 创建一个 Rectangle。
  3. 在属性编辑器中，从 Rectangle 的 Size 属性拖出一条连接，放到 Control 选项卡中 Component 界面顶部的紫色区域。
  4. 在场景窗口中将 Rectangle 设为 Component 的子级。
  5. 在属性编辑器中，右键单击 Size 属性并选择 Rename。
  6. 为该属性设置自定义标签。
  7. 在属性编辑器中，右键单击 Component 的标题栏。
  8. 选择 Component 并取消勾选 Edit Component。
  9. 在属性编辑器中，右键单击 Component 的标题栏。
  10. 选择 Component 并勾选 Compact Layout。

Component 的界面将得到简化，Rectangle 也会从图层堆栈中隐藏。

界面

Edit Component

Component 有两种模式，可通过在属性编辑器中右键单击图层的标题栏，并从 Component 菜单中选择相应选项来访问。

  • 勾选 - 可以将其他图层的属性添加到 Component。作为 Component 子级的任何图层都会在场景窗口中显示。
  • 取消勾选 - 作为 Component 子级的任何图层都会在场景窗口中隐藏，并且无法添加或移除其他图层的属性。

为 Component 添加属性

要为 Component 添加属性，请在属性编辑器中从图层的属性拖出一条连接，放到 Control 选项卡中 Component 界面顶部的紫色区域。

从 Component 移除属性

要从 Component 移除属性，可以：

  • 在 Component 的 Control 选项卡中右键单击该属性，并选择 Remove from Component。
  • 使用源属性上的连接图标。

自定义标签：

右键单击属性并选择“Rename”即可自定义属性标签。
