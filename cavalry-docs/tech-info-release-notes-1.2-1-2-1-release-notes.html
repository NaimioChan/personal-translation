1.2.1 发布说明

新功能

  • 新增 Intersections Distribution，你可以将点放置在图形彼此相交的位置。
  • 新增 四角定位：通过将角点钉到 Null 上，对合成/图像/图形进行变形。
  • CLI：使用新的 --swapAsset 命令在渲染时替换资源。
  • 文本图形 新增 Background 标签页，可用于为文本添加背景。它使用文本的基线来定位，因此更适合用于字符串中可能包含或不包含上伸部/下伸部的文本（例如，边界框的高度会随文本边界框的高度变化而变化）。
  • 电子表格 现在有新的 Interpolate 属性，意味着你可以在数据列之间进行混合。此外还有 Sort Order 模式，会为每一行输出排名。这对数据可视化很有用。
  • 文本新增 应用字体 样式行为，允许你基于搜索（正则）动态设置字体。

改进

  • Color Window：在 Palettes 菜单中可预览超过 5 种颜色。
  • Render Manager：
    • 新增 Delete All 渲染队列项按钮。
    • Dynamic 标签页中新增 Ensure Unique File Names 选项。取消勾选后，Cavalry 在使用渲染标记时将不会把文件添加到文件夹中，也不会在文件名后附加“索引”。
    • 改进了文件路径中非法字符的提示。
    • 改进了渲染到锁定（只读）位置时的警告。
  • 新增 1350x1080（4:5）分辨率预设。
  • 改进了场景窗口中 SubUI 上属性名称的显示。例如，Color Alpha 在 Fill 和 Stroke 上显示相同，现在则会分别显示为 Fill Color Alpha 和 Stroke Color Alpha。
  • 使用 Focus Mode 时现在会保存窗口状态。
  • 改进了创建新图层时的自动编号。
  • 属性编辑器搜索栏支持 Auto-complete，并会自动切换标签页。
  • Mask Feather 已内置到图形中（Mask Blur 滤镜现已移除）。
  • Value String Generator 新增 Decimal Separator。
  • 时间编辑器中的放大和缩小图标现在改为了按钮。
  • F2 现在可在场景窗口和资源窗口中触发重命名。
  • 现在可以通过属性编辑器图层标题行中的 Advanced > Context 右键菜单过滤掉 Position Context。
  • 改进了撤销功能，尤其是针对文本。
  • 电子表格数据支持 X11 颜色。说明：名称中包含数字的颜色（如 blue1）不受支持。

新的实验性功能：

  • 新增 JavaScript：可直接在 Cavalry 中编写 JavaScript 表达式。看看 Create > Presets > JavaScript 菜单中新增的预设。
  • 新增 Filters：
    • Black and White：将图形/着色器转换为黑白。
    • Brightness and Contrast：调整图形/着色器的亮度和对比度。
    • Scan Lines：创建 CRT 电视效果。
    • Shift Channels：
    • Glow：为图形添加辉光。
    • Threshold：将比阈值更暗/更亮的所有像素转换为黑/白。

已知问题

  • Aliasing 功能已被暂时移除。
  • 部分滤镜存在已知的画质问题。我们正在修复。
