组

简介

收集图层以便组织它们和/或创建共同的变换。

Group 可用于执行多种任务，包括：

  • 同时变换多个图形。
  • 组织合成中的图层。
  • 将图形的变换传递到复制器（Duplicator 按设计会忽略 Input Shape 的变换，但通过将正在动画的对象编组，然后将 Group 作为 Input Shape 添加，副本也会随之动画）。

界面

Common Attributes +

  • Blending and Opacity Mode：决定 Group 内的图形在视觉上如何相互组合：
    • Artboard：Group 的 Blend Mode 只影响 Group 内的图形，而 Opacity 会将这些图形作为一个整体影响。
    • Individual Shapes：Group 的 Blend Mode 也会影响 Group 外的图形。Opacity 会单独影响每个图形。

合成中一旦存在 Group，就可以将图层拖入以添加到 Group，或拖出以从中移除。

信息：

使用 Cmd/Ctrl + G 快捷键可将选中的图层编组。使用 Shift + Cmd/Ctrl + G 取消编组。

在视口中操作 Group

  • 使用选择工具，单击并拖动 Group 中的任意图形，即可变换 Group 的全部内容。
  • 通过以下方式深入选择 Group 层级中的图形：
    • 双击 Group 中的某个图形。
    • 在视口中右键单击 Group 中的某个图形，并选择 Select Hierarchy。该图形层级中的父级列表将可供选择。
    • S + 单击 Group 中的某个图形，可直接选中它，无论其处于哪个层级。
  • 选中 Group 时，视口中会出现一个标注有该 Group 图层名称的包围盒。注意，这不适用于父级为非 Group 图层（例如图形）的情况。
  • 属于层级一部分的非可绘制对象（例如行为）会被忽略。

信息：

单击即可选中与所选图形处于同一层级的其他图形。
