布局

简介

布局提供了一种让图形彼此“紧贴”来堆叠图形的方式。这意味着，如果堆叠中某个图形的边界框发生变化，其他图形会移动，以容纳该图形所需的新空间。

这对于创建需要响应尺寸变化的动态布局很有用，同时也是一项有趣的、富有艺术性的功能。

创建布局

只需将图形添加到任意一种布局组类型中，即可创建布局：

  • 布局组：以水平或垂直方向排列图形，并可选择换行到多行/多列。
  • 网格布局组：将网格布局行排列成列。
  • 网格布局行：将图形排列成行，以便在网格布局组中使用。

快速开始：

  1. 创建 3 个图形。
  2. 选中全部 3 个图形，在视口中右键单击并选择Layout > Embed selected in Horizontal Layout。

创建简单的水平布局：

  1. 创建 2 个图形。
  2. 创建一个布局组。
  3. 在场景窗口中选中这两个图形。
  4. 将这两个图形单击并拖到布局组上。
  5. 松开鼠标。

这两个图形将在水平布局中并排排列。如果更改任一图形的Width（Size W），布局会相应更新。

布局组可以像其他任何图层一样通过Add Layers窗口创建，也可以使用场景窗口或视口中的上下文菜单创建。只需选中多个图形，右键单击并选择Layout > Embed selected in [Horizontal/Vertical/Grid] Layout。

要将图形从布局组中移除，只需将其拖出布局组。

层级

布局组是层级结构，图形按图层堆栈从上到下组织。任何布局组的子级都会参与排列，但比子级更深的图形（例如孙级等）会被忽略。

通过在其他布局组中嵌套布局组，可以创建更复杂的布局。

Exclude from Layout：

布局组中的图形可以通过在属性编辑器的Advanced选项卡下勾选Exclude from Layout，将其排除在布局之外。请参阅通用属性。

变换

将图形添加到布局组后，其变换（位置/旋转/缩放）仍可调整，这意味着可以在布局组内为图形制作动画。请注意，布局读取的是图形的边界框，并忽略“顶层”变换。因此，即使图形可能被旋转，由于图形的边界框未发生变化，布局本身也不会改变。

Reset Position：

当图形添加到布局组时，其Position会被重置为0,0。虽然图形不必位于 0,0，但如果图形被意外移动，布局可能会显得错乱。

从布局组中移除图形时，图形的变换会被保留。

边界框

图形的世界空间边界框用于计算其在布局中占据的空间。由于顶层变换会被忽略，图形必须作为另一个图形的子级，变换才会影响布局的边界框计算。

在下面的示例中，由于黄色矩形是一个组（下方）的子级，它的旋转会改变该组的边界框，进而影响布局组中其他图形的布局。

信息：

尽管子级以下的图形（例如孙级等）会被布局本身忽略，但作为层级结构的一部分，它们会参与其父级的边界框计算，从而可能影响布局。

间隔器

间隔器可用于填充布局中的任何可用空间，从而用于均匀分配间距或将单元格对齐到布局的左/右/上/下侧。

在下面的示例中，请注意间隔器如何填充布局中的可用空间，从而迫使其他单元格相应地调整对齐。

要向布局中添加间隔器，只需通过Add Layers窗口创建一个，然后将其拖入布局组。

布局组的Spacing Mode必须设置为Manual Spacers，间隔器才会参与布局计算。在其他任何Spacing Mode下，除非将其设置为“Fixed Size”，否则间隔器会被忽略。

对齐

图形的单元格内对齐可以通过其Advanced选项卡下的Vertical/Horizontal Layout Alignment选项设置。请参阅通用属性（Advanced 选项卡）。

请注意，文本图形的Alignment和Vertical Alignment会被这些设置覆盖。

说明

  • 使用基线对齐的文本图形会与布局底部对齐。这意味着任何下伸部分都会位于其“单元格”之外。
  • 布局组具备组的特性，因此子级会继承添加到其中的任何变换、滤镜或变形器。
  • 通过Add Layers窗口或上下文菜单创建任何布局组类型时，它们会在场景窗口中被锁定。这是为了防止在视口中与其他图形交互时，对组内图形添加任何非预期的变换。
