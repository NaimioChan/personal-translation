1.3 发行说明

新功能

JavaScript

  • 新增 JavaScript API：JavaScript 可用于多个不同位置，Cavalry 提供 3 个模块，让你访问场景中的数据：
    • 上下文模块：可在 JavaScript 工具 中使用。
    • Cavalry 模块：可在 JavaScript 工具 和 JavaScript 编辑器 中使用。
    • API 模块：可在 JavaScript 编辑器 中使用
    • 脚本界面：构建带有用户界面（UI）的脚本，使其更易于交互或与他人分享。
    • Web API：与网络上的 API 端点交互。
    • Pre and Post Render Scripts：在每个由 Render Queue Item 执行的渲染之前或之后运行脚本。
  • 新增 JavaScript 编辑器：通过脚本访问新的 API！
  • 新增 JavaScript 变形器：使用 JavaScript API 编写你自己的变形器。
  • 新增 JavaScript 图形：使用 JavaScript API 定义你自己的图形。

效果

  • 新增 多点渐变着色器：通过为多个点设置位置、颜色和影响来创建复杂的渐变。
  • 新增 混合着色器：将多个着色器组合在一起，输出单个着色器。
  • 新增 扭曲滤镜：通过采样着色器来扭曲图形。

其他

  • 新增 图像采样器 工具：它是（可能很慢的）材质采样器 的替代方案。虽然它快得多（快很多很多），但有一个缺点——它只支持图像/序列/视频，因此无法与着色器（Gradient/ Noise 等）一起使用。这里的变通方法是预先渲染所有材质，再将它们作为资源导回。
  • 新增 获取子网格变换 工具：用它获取任意 Sub-Mesh 的子网格变换（位置、旋转、缩放）。例如，将图形的位置连接到 Duplicator 或 Forge Dynamics Shape 的 pointId4。
  • 新增 区域范围 行为：将区域映射到宽度和高度，以产生成比例的区域。
  • 新增 Text Asset：将 .txt 或 .json 文件导入场景。配合新的 从资源获取字符串 工具使用，以输出文本文件的内容。
  • 新增 从资源获取字符串 工具，用于输出 Text Asset 的内容。
  • Beat Markers：为时间编辑器和 曲线编辑器添加参考线，用于指示音频节拍。
  • 为 Add Layers 窗口添加了内联帮助。
  • 圆形分布 新增 Travel 属性。
  • 场景窗口中的 Tabs！现在可以同时打开多个合成进行工作。
  • 控制中心：
    • 来自多个合成的属性无论当前激活的是哪个合成都可以访问。
    • 属性通过标签页进行组织。
    • 新增了 Clear All 按钮。
  • 新增 Attribute Expressions：为带有输入连接的属性添加内联数学表达式。
  • Create 菜单中新的 Animation Presets 可以应用到场景中已有的图层。目前可用的预设主要针对带有子网格的图形（Text、SVG、合并图形、Duplicator 等）。

增强

  • Figma 和 Adobe Illustrator 在导出 SVG 时不会为描边宽度为 1 的图形指定描边宽度（只指定颜色）。对于指定了颜色但未指定描边宽度的情况，Cavalry 现在会正确地将其解释为描边宽度 1。
  • 字符串 和 字符串数组 工具现在可以转换为多行文本字段。添加换行（Shift + Enter）会将字段转换为多行。
  • 时间编辑器的右键上下文菜单中新增了关键帧插值选项。
  • 改进了 Image Sequence Assets 的加载时间和内存占用。下一站是视频！
  • 电子表格 的 Output Mode 新增 Sort Order (Descending) 选项。
  • 复制/粘贴图层不再追加 [Copy]，而是按 1 递增（取决于同名中已有的最大数字）。
  • 噪波着色器 已脱离 Beta。
  • Simple Value Solver 和 Simple Value 2 Solver 已重命名为 值求解器 和 值2求解器，并脱离 beta，因为它们现在可以选择写入缓存文件，从而可与运动模糊一起使用。
  • 渲染管理器 中新增 Respect Viewport Filtering 属性。任何通过 Tags 在视口中隐藏的图层都不会被渲染。
  • 现在可以在国际键盘上使用 Alt + 8/9 或 Alt + 5/6（取决于键盘）输入方括号 []。
  • 在 Create > Demo Scenes > JavaScript 中新增了多个可供尝试的 JavaScript 预设。
  • 属性编辑器上下文菜单中新增 Add Utility 菜单。
  • 优化了场景窗口中音频波形的性能。
  • 赛璐珞动画图形 现在支持循环。注意：这仅适用于新创建的 Cel Animation Shape。
