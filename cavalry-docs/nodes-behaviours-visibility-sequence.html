可见性序列

简介

Visibility Sequence 行为可用于影响子网格（如复制器或文本）的可见性。可通过设置范围来决定每个子网格的可见性。任何超出该范围的子网格，其可见性都将被设为关闭。

例如，当将一个 Visibility Sequence 连接到 Count 为 10 的复制器时，Start 值设为 10% 会将复制器中第一个子网格的可见性设为关闭（10 的 10% 是 1，因此第一个子网格落在范围之外）。

界面

Start - 设置一个百分比，以标记范围的起点。

End - 设置一个百分比，以标记范围的终点。

Travel - 每次以一个子网格为单位递增地偏移范围。

Always On - 输入以逗号分隔的 Id 列表，使其始终保持可见。也可使用冒号来设置范围 - 1,3,5:8

Always Off - 输入以逗号分隔的 Id 列表，使其始终保持不可见。也可使用冒号来设置范围 - 1,3,5:8

Invert - 反转结果范围，使范围之外的任何内容都被设为开启。

示例：

  1. 按住 Option/Alt 并单击椭圆工具以创建一个椭圆。
  2. 选中椭圆后，在工具架中单击复制器图标。
  3. 将 Distribution 设为 Linear。
  4. 将 Count 设为 10。
  5. 将 Size 设为 1000。
  6. 右键单击 Shape Visibility 属性。
  7. 选择 Add Behaviour > Visibility Sequence。
  8. 将 Visibility Sequence 载入属性编辑器。
  9. 将 Start 设为 50%。

复制器的前 5 个子网格将被隐藏。
