2.1.1 版本说明

发布日期：2024 年 5 月 30 日

2.1 版本说明→

新功能

行为

  • 新增 延长开放路径 行为：沿切线或自定义角度延伸开放路径的端点。

效果

  • 辉光滤镜 已更新，现在是一项 功能。请注意它并非完全向后兼容，旧场景中可能需要调整。

脚本

API

  • setDynamicIndexOffset
  • getCurrentGenerator

增强

  • 噪波 行为的噪声类型新增 Seed 属性。
  • View > Show Snapshots > All（Option/Alt + 5）的质量已改进。
  • Copy Keyframes/Animated Attribute 现在出现在 时间编辑器 和 曲线编辑器 的上下文菜单中。
  • Animation > Animate Along Path > Move Along Path 命令现在在选中 空对象 或 衰减 以及路径时可以正常工作。此前尽管选择有效，该命令也会报错。

重要错误修复

  • 修复了导出为 MP4 时的 YUV 色彩配置转换问题。
  • 现在可以连接到 渲染管理器 中 Dynamic 标签下的新 Render Range 属性。请注意，对于在早期版本中保存且包含指向先前 Number of Renders 属性的连接的那些场景，转换后的 renderRange.e 连接会添加一个值为 -1 的 属性表达式。这是因为例如 10 次渲染现在表示为 0..9。我们知道存在输入连接图标不显示的问题：可以使用右键菜单移除连接。
  • Windows：时间编辑器 中用于交互的 Option/Alt + 滚动和 Shift + 滚动快捷键已恢复。
  • 在 时间编辑器 中拖动关键帧条不再导致闪烁。
  • 场景树 中用于视觉连接动画属性的虚线现在再次与“显示动画”开关正确对齐。
  • 修复了通过上下文菜单移除连接至子属性时失败的问题。
  • 修复了在 Library、Label 和 Scene Palettes 中复制色板时崩溃的问题。
  • 修复了 Google Sheets 资源偶尔加载失败的问题。
  • 对在 Pre-Comp 中被遮罩的图形使用 Align Behaviour 现在可正常工作。

备注

我们了解到一种情况：此前删除的合成（及其图层）可能会保留在 .cv 文件中。这不会造成危害，但意味着这些图层会作为标签出现在 scenery.io 上。这些隐藏的合成现在会在打开场景时出现，以便清理。与此同时，我们仍在寻找根本原因，因此如果这影响到了你的某个场景，欢迎告知我们。
