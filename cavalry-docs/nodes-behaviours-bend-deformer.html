弯曲变形器

简介

围绕圆周弯曲图形来使其变形。

界面

通用属性 +

Bend Angle：以度为单位设置弯曲角度。360° 会将矩形弯曲成一个圆环。

Direction：确定沿哪条轴放置变形圆：

  • Horizontal：让变形圆沿 X 轴对齐。
  • Vertical：让变形圆沿 Y 轴对齐。

Horizontal Pin：当 Direction 设为 Horizontal 时，相对于图形的边界框对齐变形圆。

  • Centre：从图形边界框的中心弯曲。
  • Left：从图形边界框的左边缘弯曲。
  • Right：从图形边界框的右边缘弯曲。

Vertical Pin：当 Direction 设为 Vertical 时，相对于图形的边界框对齐变形圆。

  • Middle：从图形边界框的中部弯曲。
  • Top：从图形边界框的顶部弯曲。
  • Bottom：从图形边界框的底部弯曲。

High Quality：增加点采样，以获得更高质量的输出。

Use Levels：勾选后，子网格可被独立影响。

Level Mode：选择要影响网格的哪些层级。

  • Custom...：手动设置 Custom Level。
  • Text (Lines)：与文本图形一起使用时，这将影响每一行。
  • Text (Words)：与文本图形一起使用时，这将影响每一个单词。
  • Text (Characters)：与文本图形一起使用时，这将影响每一个字符。

Custom Level：设置要影响的网格层级结构中的层级。

示例：

  1. 创建一个Rectangle。
  2. 将其 Width 设为 800。
  3. 点击矩形 Deformers 属性上的 + 按钮，然后选择 Bend。
  4. 调整 Bend Angle，以增加或减小应用于矩形的弯曲程度。

多个图形：

默认情况下，Bend 会基于各图形自身的边界框对其进行变形。要将多个图形作为一个整体变形，可以使用 Custom Shape 或 Pre-Comp。

Custom Shape

  1. 将多个图形添加到群组中。
  2. 创建一个自定义图形。
  3. 连接 group.id→customShape.inputShape
  4. 为 Custom Shape 添加一个 Bend Deformer。
  5. 确保 Bend Deformer 的 Use Level 属性未勾选。

Pre-Comp

  1. 添加多个图形。
  2. 选中这些图形，然后转到 Composition > Pre-Compose。
  3. 为新的 Pre-Comp 添加一个 Bend Deformer。
  4. 确保 Bend Deformer 的 Use Level 属性未勾选。

请注意，Pre-Comp 的分辨率必须包含足够的内边距以容纳弯曲后的结果，否则图形可能会被 Pre-Comp 的边界裁剪。
