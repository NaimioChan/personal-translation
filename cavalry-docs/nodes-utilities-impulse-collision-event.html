冲量碰撞事件

简介

当图形在 Forge Dynamics 模拟中发生碰撞时，为其施加额外的力。

界面

Use Bounce Direction：勾选后，冲量将沿图形因碰撞而运动的方向施加。

Bounce Factor：Bounce Direction 的乘数。

Direction：以向量形式设置施加冲量的方向。例如 1, 0 = 向右，0, 1 = 向上。使用更大的值可施加更强的冲量。

Rotational Power：增加/减小冲量所施加的旋转力。负值会添加顺时针方向的旋转冲量。
