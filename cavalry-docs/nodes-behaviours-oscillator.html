振荡器

简介

使用三角波图案变形图形并影响数值。

界面

通用属性 +

Behaviour

Strength Fade to Zero：勾选后，Strength（包括衰减）会在 0 与结果之间插值。取消勾选时，它会在 Minimum 和 Maximum 值之间插值。

Type：选择波的类型：

  • Sine：创建正弦波。
  • Cosine：创建余弦波。
  • Tangent：创建正切波。

Wave Style：选择波的形状：

  • Normal：平滑的曲线波形。
  • Square：方波。
  • Triangle：三角波。
  • Sawtooth：锯齿波。
  • Custom...：使用 Graph 创建自定义波形。

Graph：当 Wave Style 设为 Custom... 时，使用该曲线图绘制自定义波形。参见通用属性。

Minimum：设置波的最小高度。

Maximum：设置波的最大高度。

Value Offset：偏移最小/最大值。

Stagger：设置一个值，与复制器一起使用时，可让各个副本的运动在时间上交错。

Separate Channels：为 x 和 y 生成不同的值。

Time Mode：决定 Frequency 属性与时间的关系（一个周期是波的两个峰值之间的距离）：

  • Seconds：Frequency 值表示每秒的周期数。若 Frequency 设为 1 且 Time Scale 设为 1，正弦波将每秒上下运动一次。
  • Minutes (BPM)：Frequency 值表示每分钟的周期数。若 Frequency 设为 60 且 Time Scale 设为 1，正弦波将每秒上下运动一次。

Frequency：根据 Time Mode 设置完整波形周期的时长。

Time：自动连接到合成的时间。

Time Offset：设置一个值来偏移动画/时间（以秒为单位）。

Time Scale：设置时间的倍数。

Deformer

Use Normals：勾选后，变形将基于图形的法线。取消勾选时，点会从图形的中部缩放。

Number of Waves：设置沿路径或绕路径创建的完整波的数量。

循环：

通过 Time Mode、Frequency 和 Time Scale 属性，可以让振荡器每隔 x 秒循环一次。若需要在特定的帧数周期内循环，可以使用数学工具在 FPS 与时间之间建立关系。例如：

  1. 创建一个图形。
  2. 右键点击 Position 属性 > Add Behaviour > Oscillator > Y。
  3. 将 Oscillator 的 Minimum 设为 -100，Maximum 设为 100。
  4. 创建一个数学工具。
  5. 打开合成设置，将 Frame Rate 连接到 Math 的 First 属性。
  6. 在 Math 的 Second 属性中输入一个值，表示一次循环应经历的帧数。
  7. 将 Math 的 Operation 设为 Divide。
  8. 连接 math.id→oscillator.frequency

若合成的 Frame Rate 发生变化，振荡器仍会按 Math 的 Second 属性中输入的帧数继续循环。

也可以改用属性表达式代替 Math：将合成的 Frame Rate 连接到振荡器的 Frequency，然后添加 /32 的属性表达式，其中 32 是振荡器循环所依据的帧数。

圆周运动：

使用两个振荡器（Sine 或 Cosine）制作圆周运动时，应给其中一个振荡器加上 0.25 的 Time Offset。

信息：

将振荡器连接到例如图形上的 position.x 时，使用 Time Scale 来加快振荡速度。

旧版振荡器

旧版振荡器：

Oscillator 在 Cavalry 2.4 中进行了更新。旧版场景（在 Cavalry 2.4 之前创建的场景）会继续使用旧的 Oscillator，但可以手动更新为使用当前的 Oscillator。操作方法：

  1. 保存一个新版本的场景。
  2. 创建一个新的 Oscillator。
  3. 将新 Oscillator 的设置与旧版 Oscillator 的设置保持一致。
  4. 将旧版 Oscillator 的所有现有连接替换为新 Oscillator 中的对应连接。

需要微调各项设置才能尽量接近原始场景，尤其是：

  • Time Scale：为了匹配旧版 Oscillator 的速度，很可能需要将其从原始值调小。
  • Frequency：现在它取决于新的 Time Mode，因此需要相应调整。
  • Frequency：若该 Oscillator 被用作变形器，请注意现在应使用 Deformer 标签页下新增的 Number of Waves 属性来控制变形产生的波的数量。例如，若旧版 Oscillator 作为变形器使用且 Frequency 为 10，与之近似的等效设置是 Frequency 为 1、Number of Waves 为 10 的 Oscillator。
