描边宽度工具

简介

描边宽度工具可用于在视口中调整图形的锥形描边。

交互

启用描边宽度工具并选中图形后，拖拽视口中出现的小白点。

增加宽度

要增加描边的宽度，将圆点沿图形的法线方向移离路径。

移动宽度的位置

要改变宽度的位置，将圆点沿路径移动。

Width Profile：

通过描边宽度工具设置的宽度，也可以在图形 Stroke 选项卡下的 Width Profile 图表中调整。

工具设置

Limit Stroke Width：勾选后，视口工具将无法增加/减小描边的 Width 值。

Lock Point Order：勾选后，描边宽度工具创建的每个点都无法越过其相邻点。

Snap to Points：勾选后，沿路径长度移动宽度时，其位置会吸附到路径的点上。

Reset Profile：移除所有宽度，并将 Width Profile 图表设为一条水平直线。

Snap Widths：

将宽度移离/移向路径（以增加/减小其宽度）时按住 Shift，可吸附到其他宽度。
