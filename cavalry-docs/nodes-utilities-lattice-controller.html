晶格控制器

简介

操纵多个晶格点的位置、旋转和缩放。

界面

Strength：增加/减小控制器对晶格点的影响。可用于在点的原始位置与控制器所施加的偏移之间进行混合。

Pivot Offset：将控制器从其原始位置偏移。

Position：在 X 轴和 Y 轴上偏移晶格点。

Rotation：围绕控制器的中心旋转晶格点。

Scale：从控制器的中心缩放晶格点。

小心：

手动将晶格控制器连接到晶格时，请确保在建立连接前已选中一些晶格点。推荐使用晶格的 Add Controller to Selection 按钮完成此操作。

示例：

  1. 创建一个矩形。
  2. 将 Edge Divisions 设为 1,1。
  3. 点击 晶格。
  4. 选中 Lattice 并激活选择工具，框选矩形右上象限的晶格点。
  5. 点击 Lattice 界面底部的 Add Controller to Selection。
  6. 使用选择工具移动/旋转/缩放控制器。
