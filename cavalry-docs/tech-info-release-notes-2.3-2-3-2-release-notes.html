2.3.2 版本说明

发布日期：2025 年 1 月 28 日

增强

  • Show Scripts Folder 命令现在可以从 Scripts 菜单中使用。
  • 资源窗口 底部页脚新增了用于 File > Show Project Folder 命令的内联按钮。
  • Starter 用户现在可以复原 视口，从 Windows 菜单进行，而无需使用“Reset to Default Workspace”。
  • CLI 现在支持在使用 Docker 实例时指定 CA 证书路径。

重要错误修复

  • Windows 现在会自动选择'High performance' GPU。这修复了 Viewport 和 Time Editor 可能显示为白色的问题。Windows 笔记本电脑此前可能一直自动选择 'low power' GPU，因此用户也可能体验到性能提升。请注意，如果显卡不受支持，此问题仍可能出现。
  • 修复了使用 VP9 Codec 渲染 WebM 时崩溃的问题。
  • 修复了 Text 与错位的变音符号（重音符号）相关的回归问题。
  • Use Layer as Seed 属性（Noise 和 Random Behaviour）不再在Pre-Comps 之间产生不同结果。
  • 当焦点位于 String 属性的字段中时，按下 Cmd/Ctrl + D 不再触发崩溃。
  • 包含位于丢失的 NAS 驱动器上的Assets的场景不再触发崩溃。
  • 复制标签（label）中包含特定非拉丁字符的图层所引发的崩溃已解决。
  • 由 百叶窗滤镜 产生的 SkSL 错误不再出现。
  • ui.onClose 现在可正常工作。
  • Live Mode 与 扭曲滤镜 一起使用时的崩溃已解决。

备注

  • Context Index 工具已重命名为 索引上下文，以与 Duplicator 的 Index Context 属性保持一致。这是外观层面的更改，因此不会影响旧场景。
