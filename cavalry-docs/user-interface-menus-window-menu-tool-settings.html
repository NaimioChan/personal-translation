工具设置

简介

工具设置窗口包含与当前所用工具相关的上下文选项。它位于默认工作区的左上角。

视口工具帮助：

在视口设置中启用 Viewport Tool Help 后，每个工具的快捷键/热键提示可以覆盖显示在视口中。

图层工具：

请注意，许多图层都有专属的图层工具。选中某些图层时，会显示紫色的界面元素，可用于直接在视口中调整其设置。要显示这些工具，必须在视口设置中启用 Layer Tools。

注意，当某个图形是另一个图形的父级时，图层工具不可用。

工具

选择

Snap Angle：设置按住 Shift 键旋转图形时的吸附角度。

Manipulator：勾选后，在选择图形以及某些其他元素（如 Lattice 点）时，视口中会绘制一个“类 3D”的操纵器。

  • Transform：单击并拖拽操纵器中心即可自由移动所选内容，或使用红色和绿色箭头进行轴向吸附。
  • Rotation：单击并拖拽操纵器周围的圆环即可旋转所选内容。
  • Scale：单击并拖拽红色和绿色方块，沿 X 或 Y 轴缩放所选内容。按住 Shift 可同时影响两个轴。
  • World/Local Transform：点击操纵器左上角的黑色菱形，可在世界空间和局部空间之间切换。

Transform mode：在多选时决定变换工具是将所选内容作为一个组还是作为各个图形分别处理：

  • Group：将所有所选图形一起旋转/缩放。
  • Individual：从各图层各自的轴心点分别旋转/缩放所有所选图形。

Corner Radius：

按住 Option/Alt 可为 Rectangle 调整各个角的圆角半径。

编辑图形

Snap Angle：设置按住 Shift 键旋转图形时的吸附角度。

Tooltips：勾选后，将光标悬停在图形的点上时，视口中会显示信息。

Transform Tool：勾选后，所选的点可以作为一个组进行旋转或缩放。

信息：

启用 Transform 工具后，任何贝塞尔手柄都会被隐藏，并且无法将角点转换为贝塞尔点、分割路径或使用“贝塞尔塑形”（bézier moulding）功能。

Close Distance：设置一个距离，所选的点被放到另一个点附近时，若在该距离内便会与之合并。注意：该值与视口缩放无关。当光标位于距第一个点的该距离内时，视口中会显示这一距离。

Curve Ghosting：勾选后，编辑点时会出现路径的“幽灵”作为参考。

钢笔

Snap Angle：设置按住 Shift 键旋转图形时的吸附角度。

Stroke Width：设置描边的宽度。

Cap Style：设置开放路径的端点（描边两端）的外观。

  • Flat：平直端点，在终点处终止。
  • Round：半圆形端点，终点位于其中心。
  • Projecting：平直端点，向外延伸超出终点半个宽度。

Close Distance：如果图形的最后一个点在距起点该值范围内绘制，则会创建闭合路径。注意：该值与视口缩放无关。当光标位于距第一个点的该距离内时，视口中会显示这一距离。

铅笔

Stroke Width：设置描边的宽度。

Cap Style：设置开放路径的端点（描边两端）的外观。

  • Flat：平直端点，在终点处终止。
  • Round：半圆形端点，终点位于其中心。
  • Projecting：平直端点，向外延伸超出终点半个宽度。

Accuracy：决定最终图形与光标移动轨迹的接近程度。设置越高，图形越精确，但会创建更多的点。

Stabiliser：勾选后，路径在绘制过程中会被“稳定化”。这有助于用更少的点绘制更平滑的曲线。

Stability Radius：决定稳定程度。值越高，曲线越长、越平滑。

Close Distance：如果图形的最后一个点在距起点该值范围内绘制，则会创建闭合路径。闭合路径时，Close Distance 范围内的内容会被重新采样，以便创建平滑的连接。这意味着路径的起点也会被更新。注意：该值与视口缩放无关。当光标位于距第一个点的该距离内时，视口中会显示这一距离。

摄像机

线条

Stroke Width：设置描边的宽度。

Cap Style：设置开放路径的端点（描边两端）的外观。

  • Flat：平直端点，在终点处终止。
  • Round：半圆形端点，终点位于其中心。
  • Projecting：平直端点，向外延伸超出终点半个宽度。

文字

无设置。

网格

Soft Selection：勾选后，可以在光标一定范围内选择网格顶点。选择强度会随着远离中心而衰减。

Soft Selection Size：设置 Soft Selection 的半径。

跟踪

Preset：选择最适合该素材的跟踪预设：

  • Edge Snap：智能地“吸附”到屏幕的边界，而不是跟踪屏幕内部的点。
    • 优势：
      • 跟踪速度非常快，尤其适用于长镜头。
      • 屏幕与背景之间有清晰分明、高对比度的边缘时。
      • 屏幕上的内容均匀、模糊、带有某种动画，或缺乏可跟踪的特征时。
      • 当某个物体（如手或道具）短暂地从屏幕前方经过时。该跟踪器更擅长在屏幕被遮挡后“重新找回”屏幕。
    • 劣势：
      • 需要定义明确的屏幕边界。如果边缘模糊、对比度低或与背景融为一体，可能会失败。
  • Balanced：在大多数常见跟踪情形下兼顾速度与精度。其工作方式是跟踪屏幕内部密集的特征点云。
    • 优势：
      • 适用于大多数跟踪任务。
      • 屏幕上有丰富纹理或独特视觉细节（例如跟踪标记）时。
      • 摄像机运动平滑至中等偏快时。
    • 劣势：
      • 如果屏幕的大部分被遮挡（例如被手或其他物体挡住），可能会丢失跟踪。
      • 对于纹理极少、有运动模糊或有大面积反光的屏幕可能较吃力。
  • Robust：该跟踪器专为应对中断而设计。其工作方式是记住屏幕特征的一个“关键帧”，并尝试在当前帧中重新找到它们。这使其速度较慢，但更具韧性。
    • 优势：
      • 当某个物体（如手或道具）短暂地从屏幕前方经过时。该跟踪器更擅长在屏幕被遮挡后“重新找回”屏幕。
      • 跟踪因快速运动或运动模糊而出现偏移时。
    • 劣势：
      • 比 Balanced 预设更慢。
      • 如果遮挡物过大或持续时间过长，仍可能失败。

Supervised：勾选后，如果质量下降过多，跟踪会停止，以便在继续跟踪之前手动重新定位标记。仅在 Balanced 和 Robust 预设下可用。

Show Grid：勾选后，视口中会绘制被跟踪平面的预览。

Track Backwards：放置跟踪标记后，点击此按钮可分析素材，并沿时间向后移动来创建跟踪数据。

Track Forwards：放置跟踪标记后，点击此按钮可分析素材，并沿时间向前移动来创建跟踪数据。

Create a Keyframe：通过为标记设置关键帧来覆盖任何自动跟踪数据，从而完善跟踪数据。这对于修正可能偏离过远的个别帧，或管理分段之间需要留出间隔的跟踪很有用。关键帧由时间轴正下方的一个绿色帧表示。

Apply：选择图形并选择相关数据，以创建一个边角定位图形并连接到所选图形，同时将跟踪数据分配到边角定位的各个 Null 上。

Clear：移除所有跟踪数据。

基础形状

以下工具会显示以下设置：

  • Rectangle
  • Ellipse
  • Polygon
  • Star
  • Arc
  • Super Ellipse
  • Cogwheel
  • Arrow
  • Capsule

Create Editable Primitives：勾选后，创建任何基础形状时都会创建一个可编辑图形。

Toolbar：

勾选 Create Editable Primitives 后，工具栏中每个基础形状工具的图标上都会加上一个小小的 E。

Tool Help：勾选后，提示信息会覆盖显示在视口的左下角。

Draw in 2.5D：勾选后，图层在创建时会启用 2.5D，这意味着在摄像机激活时可以在 2.5D 中绘制图形。
