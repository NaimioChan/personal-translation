预设

简介

预设可用于保存和应用预先配置的设置，并可为图层、合成和渲染队列项目设定默认值。

使用预设

预设可以通过图层属性编辑器界面的标题行、场景树的标题栏或渲染队列项目的标题行进行设置或访问。

快速开始：

如何使用预设设置默认合成：

  1. 打开合成设置窗口并定义你的合成设置（Resolution、FPS、Background Color 等）。
  2. 点击 Preset Save Preset...。
  3. 为预设命名。
  4. 点击 Preset Manage Presets...'
  5. 右键点击预设所在行，选择“Set as Default Settings”。

此后每次创建新合成时，它都会从该预设继承设置。

保存预设

要保存预设：

  1. 更改图层的属性值/设置。
  2. 点击 Preset
  3. 选择 Save Preset...。
  4. 输入“Preset Name”。
  5. 点击 Save。

保存选项

这些选项会因类型而异：

  • Reset Layer：勾选后，保存的预设在应用到图层时，还会重置任何非默认属性。
  • Include Primitive Type（仅基本图形）：勾选后，如果此预设之后应用到基本图形，它还会设置 Primitive Type。保持未勾选可创建仅影响通用属性的预设。
  • Include Transforms（仅图形图层）：勾选后，变换设置（Position/Rotation/Scale/Pivot）会包含在预设中。
  • Include Path（仅可编辑图形图层）：勾选后，路径也会包含在预设中。
  • Availability（仅图形图层）：决定保存的预设之后可以应用到所有图形图层，还是仅限正在保存的特定图形类型：
    • This Shape Type：该预设仅在正在保存的特定图形类型上可用。
    • All Shapes：该预设在所有图形图层上可用。当制作影响 Fill、Stroke 等通用属性的预设时，这很有用。
  • Include File Name and Path（仅渲染队列项目）：勾选后，File Name 和 Path 也会包含在预设中。未勾选时请注意：如果勾选了 Reset Layer，应用预设时 File Name 和 Path 会被清除。取消勾选 Reset Layer 可保留现有的 File Name 和 Path。

应用预设

要应用预设：

  1. 打开图层的属性编辑器界面。
  2. 点击 Preset
  3. 从列表中选择预设。

管理预设

要重命名、删除预设或将其设为默认：

  1. 点击 Preset
  2. 选择 Manage Presets...。这会打开 Manage Presets 弹出窗口。

选项

重命名预设

要重命名某个预设，可以：

  • 选中预设所在行，然后按 Return。
  • 双击预设所在行。
  • 点击预设行上的“...”图标，然后选择“Rename”。
  • 右键点击预设所在行，然后选择“Rename”。
移除预设

要移除某个预设，可以：

  • 点击预设行上的“...”图标，然后选择“Delete”。
  • 右键点击预设所在行，然后选择“Delete”。

会出现确认对话框：删除预设时按住 Option/Alt 可跳过该对话框。

设置默认预设

预设可用于覆盖默认设置。例如，创建基本图形时，可以将其设置为宽 400 的蓝色矩形。

要将预设用作图层的默认设置，可以：

  • 点击预设行上的“...”图标，然后选择“Set as Default Settings”。
  • 右键点击预设所在行，然后选择“Set as Default Settings”。

默认预设会标有绿色图标。

要移除图层的自定义默认设置，可以：

  • 点击已设为默认的预设行上的“...”图标，然后选择“Remove as Default Settings”。
  • 右键点击已设为默认的预设所在行，然后选择“Remove as Default Settings”。

共享预设

预设会保存到 Preferences 文件夹内 Presets 目录下的 presets.json 中。

向 Presets 目录添加其他有效的 .json 文件后，这些文件包含的预设会在应用或删除预设时可用。如果 .json 无效（存在语法错误），其中的预设将不会被加载。

说明

连接不会随预设一起保存。这包括添加到渲染队列项目的合成。

具有系统默认值的属性不会随预设保存。

使用工具拖出基本图形和/或文本时不支持预设，但按住 Option/Alt 点击工具创建“默认”图形时支持预设。
