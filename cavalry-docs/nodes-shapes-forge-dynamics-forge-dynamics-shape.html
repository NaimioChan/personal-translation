Forge Dynamics 图形

简介

Forge Dynamics 是一个 2D 物理引擎，基于由 Erin Catto 打造的出色 Box2D 构建。

界面

Shape

Common Attributes +

Start Frame：设置模拟开始的帧。

Gravity：设置重力的强度。

Ground Mode：决定模拟应如何响应合成边界。

  • Off：忽略合成边缘。
  • Composition Bottom：与合成的底部碰撞。
  • Composition Edges：与合成的所有边缘碰撞。

Ground Friction：设置一个值，以决定摩擦力对与合成边缘碰撞的影响程度。摩擦值越高，图形失去速度的速度越快。

Velocity Iterations：校正施加在图形上的力的强度。值越高，结果越准确。

Position Iterations：碰撞期间校正图形位置以减少重叠的强度。值越高，结果越准确。

Fields：向模拟中添加Field。

Collision Events：向模拟中添加Collision Event。也可以通过 Body 选项卡下的设置为每个 Body 单独添加 Collision Event。

信息：

添加到 Body 的任何 Collision Event 都会覆盖添加到 Forge Dynamics Shape 的 Collision Event。

Bodies

Bodies：连接要纳入模拟的图形。可以通过场景窗口将图形拖入此属性、使用 right click > Add Body > select Shape，或通过连接锚点来添加图形。

Bodies 列表包含启用/禁用、设置特定参数或将它们从模拟中移除的选项。

单个 Body 的设置

你可以通过 Bodies 列表中的齿轮图标访问“单个 Body”的设置：

  • Input Shape：用作 Body 的图形。
  • Friction：设置一个值以决定摩擦力。Friction 值越高，图形失去速度的速度越快。
  • Bounce：设置一个值以决定图形的弹性。Bounce 值越高，图形弹得越高/越远。
  • Density：设置一个值以决定图形的密度。Density 值越高，图形看起来越重，移动它需要更大的力。
  • Gravity Scale：增大/减小 Shape 选项卡下的 Gravity 属性对图形的影响。值为 -1 会反转图形的 Gravity 设置，值为 2 则会将其加倍。
  • Body Type：
    • Dynamic：Body 会根据为模拟设置的属性移动。
    • Still：Body 会保持在原位，虽然会参与碰撞，但其位置或旋转不会受到影响。
    • Kinematic：Body 的位置和旋转将由 Input Shape 上的任何关键帧动画决定。
    • Kinematic Hybrid：Body 的位置和旋转将由 Input Shape 上的任何关键帧动画决定，直到最后一个关键帧时，它将加入模拟。

Kinematic Shapes：

Kinematic Shapes 仅支持关键帧动画。不支持通过行为进行的程序化动画。

  • Constrain Hybrids：此设置会为混合 Body 附加一个弹簧，使其在动画结束时弹动至停止。
  • Hybrid Frequency：设置弹簧的频率，单位为 Hz。
  • Hybrid Damping：设置弹簧恢复静止的速度。值越高，次级运动越少。
  • Sensor：Sensor 是一种可以触发碰撞事件、但不会触发碰撞的图形。
  • Collision Shape Type：设置用于碰撞的形状。这些形状会自动以“最佳猜测”方式设定，但也可以手动设置。更简单的形状有助于提升复杂场景的性能，但会降低模拟的准确度。在视口设置中启用 Draw Debug Information 后选中 Forge Dynamics Shape，即可在视口中显示 Collision Shape（请确保图层未锁定）。
    • Box：使用图形的包围盒。
    • Circle：使用“最贴合”图形的圆。
    • Simple Polygon：使用“最贴合”图形的多边形。最多可使用 12 条边的多边形。如果无法用 12 边形来近似 Body，则会改用方盒。
    • Complex Polygon：将图形分割为更小的 fixture（子 Body）来创建碰撞形状，以支持凹图形。
    • Chain：此设置用于开放轮廓/路径。这是单侧碰撞，如何正确设置取决于轮廓的绘制方式。作为参考：使用编辑图形工具选中轮廓时，轮廓上指示方向的小箭头所在的一侧即为会发生碰撞的一侧。
    • Chain (Reversed)：此设置用于开放轮廓/路径。当 Chain 对某个轮廓不起作用时，很可能该轮廓是“反的”，因而被排除在碰撞之外。遇到这种情况可尝试此设置。
    • Soft Body：使用此设置模拟可变形对象。

信息：

Chain Collision Shape Type 适用于开放路径。由于开放路径没有体积，无法施加力，因此无论其 Body Type 为何，它们始终保持静止。封闭路径虽然可以设为 Chain，但也遵循相同的原理。

  • Max Fixtures Per Body：当 Collision Shape Type 设为 Complex Polygon 时，设置要创建的“fixture/子 Body”的最大数量。
  • Stiffness：当 Collision Shape Type 设为 Soft Body 时，设置弹簧频率，单位为 Hz（每秒振动次数）。值越高，软体越硬。
  • Damping：当 Collision Shape Type 设为 Soft Body 时，设置阻尼比率，以控制振荡衰减的快慢。
  • Pressure：当 Collision Shape Type 设为 Soft Body 时，设置用于保持体积的内部压力。值越高，粒子会被向外推以维持 Body 的形状。
  • Shape Matching：当 Collision Shape Type 设为 Soft Body 时，设置一种影响力，将 Soft Body 的粒子移回其原始位置，从而在碰撞使图形变形后帮助保持形状的一致性。
  • Particle Radius：当 Collision Shape Type 设为 Soft Body 时，设置用于模拟软体的粒子大小。值越小细节越精细、粒子越多，但也越难控制。
  • Max Stretch：当 Collision Shape Type 设为 Soft Body 时，将弹簧连接允许的最大拉伸设为静止长度的倍数。值越低，在冲击下越能保持形状，但灵活性可能较差。值为 2 意味着弹簧可以拉伸到静止长度的两倍。
  • Live Forever：启用后，Body 始终包含在模拟中。
  • Lifespan：设置一个时长（以秒为单位），超过后 Body 将从模拟中移除。
  • Starts Asleep：启用后，Body 在另一个图形与之碰撞前将处于休眠状态。
  • Allows Sleep：启用后，Body 在进入休眠时被允许睡眠。这有助于提升性能。
  • Starting Velocity：设置 Body 首次出现时施加给它的速度。
  • Starting Rotational Velocity：设置 Body 首次出现时施加给它的旋转速度。
  • Position Damping：设置 Body 位置的阻尼。值越高，位置衰减得越快。
  • Rotation Damping：设置 Body 旋转的阻尼。值越高，旋转减速得越快。
  • Use Maximum Velocity：启用后，所有 Body 的速度都会被限制在 Maximum Velocity。
  • Maximum Velocity：设置 Body 可达到的最大速度。
  • Use Maximum Rotational Velocity：启用后，所有 Body 的旋转速度都会被限制在 Maximum Rotational Velocity。
  • Maximum Rotational Velocity：设置 Body 可达到的最大旋转速度。
  • Collision Groups：通过输入以逗号分隔的字符串（例如 text, rocks）来分配碰撞组。这些组可用于筛选 Field 对单个 Body 的影响，或 Body 与其他 Body 的交互方式。
  • Collides With：输入以逗号分隔的字符串（例如 text, rocks），以指定某个 Body 要与之碰撞的 Collision Group。特殊标记 none 可用于让某个 Body 不参与任何碰撞。
  • Level Mode：选择要影响子网格的哪些层级。有关更多信息，参见子网格。
    • Custom...：手动设置 Custom Level。
    • Text (Lines)：与 Text Shape 一起使用时，将影响每一行。
    • Text (Words)：与 Text Shape 一起使用时，将影响每一个词。
    • Text (Characters)：与 Text Shape 一起使用时，将影响每一个字符。
    • All：影响所有子网格，与层级无关。
  • Custom Level：手动设置自定义层级。
  • Constraints：添加约束。
  • Collision Events：添加Collision Event。

全局设置

Use Maximum Velocity：启用后，所有 Body 的速度都会被限制在 Maximum Velocity。

Maximum Velocity：设置 Body 可达到的最大速度。

Use Maximum Rotational Velocity：启用后，所有 Body 的旋转速度都会被限制在 Maximum Rotational Velocity。

Maximum Rotational Velocity：设置 Body 可达到的最大旋转速度。

Initial State

Initial Position Strength：设置将 Body 吸引回起始位置的力。为此属性设置关键帧，可以在模拟进行到一半时将 Body 拉回起始位置。

Initial Rotation Strength：设置将 Body 吸引回其起始旋转的力。为此属性设置关键帧，可以在模拟进行到一半时将 Body 拉回起始旋转。

Starting Velocity：设置所有 Body 首次出现时施加给它们的速度。

Starting Rotational Velocity：设置所有 Body 首次出现时施加给它们的旋转速度。

Advanced

World Scale：当模拟中存在非常大或非常小的图形时，用它来调整世界缩放，以提升模拟质量。

Time Step：设置模拟每秒步进（计算）的次数。值越高，模拟质量越高，但可能影响性能。

Cache Solver（按钮）：缓存 Forge Dynamics 模拟。Cavalry 会播放播放范围，以便将缓存文件保存到磁盘。保存缓存后，此按钮会变为 Update Cache 按钮。该操作会覆盖正在使用的任何现有缓存。

Remove Cache（按钮）：移除已保存的缓存文件。这不会从文件系统中删除 .sdcache 文件。

Use File Cache：启用后，模拟可以保存到 .sdcache 文件中。这对于较重的模拟实现更快的播放，或通过 Cache Offset 重新计时很有用。它也是运动模糊所必需的。

Cache File Path：设置缓存文件的保存位置。该位置在首次缓存求解器时确定，也可以使用文件夹图标打开 Finder/资源管理器窗口并导航到现有的 .sdcache 文件。

Cache Offset：设置缓存的时间偏移。

循环：

你可以利用缓存“倒回”模拟，并在需要时创建循环。操作方法：

  1. 缓存模拟。
  2. 在模拟结束后紧接着为 Cache Offset 设置一个关键帧。
  3. 例如，如果该关键帧设置在第 100 帧，则将播放头移到第 200 帧（即再向前 100 帧），然后添加一个值为 -200 的关键帧。

通过在第 200 帧设置值为 -200 的关键帧，你实际上是要求缓存显示第 200 + -200 帧，即 = 0。也就是说，缓存回到了第 0 帧（起点）。

下表说明了 Cache Offset 如何创建回到第 0 帧的循环。

帧 Cache Offset 值 等效值
0 0 0
100 0 100
200 -200 0

不支持的功能：

无法在模拟期间更新图形的几何体。例如：

  • 为 Scale 设置动画。
  • 为原始图形的属性设置动画（例如 Rectangle 的 Width 或 Ellipse 的 Radius）。
  • 为顶点设置动画（即路径动画）。
  • 使用变形器。
  • 为 凸包 或 连接图形 之类的图形设置动画。
