1.5.2 版本说明

发布日期：2023年2月22日

1.5 版本说明→

新功能

  • Setup Render Script：添加一个脚本，可在Render Queue Item 开始之前对其产生影响。
  • 场景树中的Composition Reference 名称。如果 Composition References（Pre-Comps）的图层名称与资源窗口中原始合成的名称一致，那么重命名该合成时，场景树中的 Composition Reference（Pre-Comp）也会一起重命名。

工具

  • 测量文本 工具：一种经过优化的方法，无需在视口中渲染即可输出字符串的边界框。

脚本

API 模块

  • 新增修饰键支持：
    • isAltHeld()
    • isShiftHeld()
    • isControlHeld()
    • isMetaHeld()
  • replaceGoogleSheet()：用另一个 Google Sheet 资源替换现有的 Google Sheet 资源。
  • setSelectedKeyframeIds()：设置关键帧选择。
  • getAttributeFromKeyframeId()：获取给定关键帧的属性路径。
  • getGuides() 已弃用，替换为 getGuideInfo()。
  • presentOpenFile()：打开并过滤一个对话框窗口以加载文件。
  • presentSaveFile()：打开一个对话框窗口以保存文件。

Cavalry 模块

  • boundingBox()：返回路径的边界框。
  • 字体度量：
    • fontExists()：如果 Cavalry 可以使用某字体，则返回 true。
    • getFontFamilies()：返回 Cavalry 可用的所有字体族的列表。
    • getFontStyles()：返回给定字体族所有可用样式的列表。
    • measureText()：返回表示某段文本边界框的对象，无需实际创建文本图形。

UI 模块

  • FlowLayout：一种新布局，其内容可根据布局的尺寸重新排列。
  • getUUID()：返回控件的唯一标识符。
  • 为 Draw 和 Container 控件新增鼠标事件回调：
    • onMousePress()
    • onMouseRelease()
    • onMouseDoubleClick()
    • onMouseMove(position)
  • Draw 和 Container 新增了 useHoverEvents() 函数。
  • 为 Windows 和 Containers 新增拖放功能。参见 registerDragDropMimeType() 以及以下回调函数：
    • onDragEnter()
    • onDragLeave()
    • onDrop()
  • runFileScript()：在其他 UI 脚本中运行 UI 脚本。
  • 新增 onClose 回调。
  • 新增右键菜单功能：
    • addMenuItem()：在 Window 或 Container 中添加右键菜单。
    • addSubMenu()：在右键菜单中添加子菜单。
    • showContextMenu()：在鼠标位置显示 Container 或 Window 中的右键菜单。
    • showContextMenuOnRightClick()：右键单击时自动在鼠标位置显示右键菜单。仅在 ui 模块中可用。
    • clearContextMenu()：清除右键菜单项。可用于更新右键菜单项。
  • Container 新增 setBorder()。

渲染模块

  • renderQueueItem：渲染时返回 renderQueueItemId。

增强

  • 字符串数组 现在新增了输出最长或最短字符串的选项。
  • 值数组 现在新增了输出最小值、最大值或平均值的选项。
  • 所有 Array 现在都有 Count 属性。
  • 通过在属性编辑器中右键单击建立连接时创建的图层，现在不再是所连接图层的子级。这是为了在通过复制图层来优化场景时，尽量避免输入被重复。
  • HSV 颜色 现在包含 Input Color。

重要错误修复

  • 我们移除了 Stroke 的 Dash Pattern 自动补全，它此前一直在引发问题。
  • 已解决因 1.5.1 中移除 Silhouette Blend Mode 而导致的视口问题。
  • Points to Path 在取消勾选 Bézier 时现在可以正确闭合。
  • 现在可以通过 JavaScript API 删除合成。
