粒子图形

实验性功能：

这是一个实验性功能。要启用它，请在偏好设置中勾选 Enable Experimental Features。

简介

技术预览：

⚠️ 请注意，这是一个技术预览。场景可能无法与未来版本的 Cavalry 100% 兼容。

功能可能会发生变化，因此当前文档非常简略。如有任何疑问，请到 Discord 上提问。

粒子系统由多个图层组成：

  • Particle Shape：承载其他功能的“核心”。
  • Emitters：定义粒子出现的位置以及添加到合成中的粒子数量：
    • 分布发射器
    • JavaScript 发射器
    • 粒子发射器
  • Modifiers：可用于改变粒子属性的场。
    • 数据修改器
    • 流场修改器
    • 力修改器
    • 目标修改器
    • 图像修改器
    • JavaScript 修改器
    • 磁性修改器
    • 路径修改器
    • 速度修改器
    • 湍流修改器
    • 视觉修改器
    • 旋涡修改器

快速上手的方法是点击工具架中的 Particle Shape 图标，然后按 play。这会在合成中添加一个 Particle Shape 和一个与之连接的 粒子发射器。

粒子分布：

粒子分布 可用于将几何体附加到每个粒子上，或者例如将 Particle Shape 用作 连接图形（或任何使用分布的图层）的输入。

Time：此属性连接到合成的 Time，用于在每帧为粒子设置动画。如有需要，可将该连接替换为关键帧或其他行为。

Lifespan：设置

Emitters：将 Emitters 连接到此属性，以定义粒子的生成位置。

Modifiers：修改器可用于操控粒子的运动和属性。它们可以“堆叠”，每个修改器都在其下方的修改器之上叠加。

Turbulence：为粒子添加噪波运动。

Gravity：设置使粒子加速的力的大小和方向。

Drag Force：设置与粒子相对运动方向相反的力的大小。

Mass：粒子的质量决定了施加力时的加速度。质量越大的粒子加速越慢。

Number of Particles：（只读）当前正在发射的粒子数量。

将粒子作为网格：

Particle Shape 在某些方面与其他图形不同，以便高效处理大量粒子。例如，它不包含 Fill 或 Stroke 标签页，视觉外观可以通过 Visual 标签页或使用 视觉修改器 来调整。它也不会输出路径，这意味着它无法被变形、无法与 组件约束 之类的图层配合使用，也无法渲染为 SVG。

若要以此方式使用 Particle Shape，可以将 粒子分布 与确实会输出路径的 复制器 一起使用。
