打乱字符串操纵器

简介

重新排列文本字符串中的字符。

界面

Mode：确定字符串中被打乱的部分：

  • All：打乱整个字符串。
  • Regex：打乱与正则表达式匹配的字符串。

Regex：当 Mode 设为 Regex 时，输入一个正则表达式。字符串操纵器将返回该表达式的结果。更多信息请参见使用正则表达式。

Capture Group Indices：当 Mode 设为 Regex，且正则表达式包含捕获组时，确定返回哪些组。列表使用逗号 , 分隔，范围使用冒号 : 分隔。更多信息请参见使用正则表达式。

Grouping：确定字符串中受 Percentage 值影响的部分：

  • Word：Percentage 值为 50 时，每个单词的一半会被打乱
  • Line：Percentage 值为 50 时，每一行的一半会被打乱。注意，行由“换行”定义，而非文本框内的自动换行。
  • Paragraph：Percentage 值为 50 时，每个段落的一半会被打乱。
  • Document：Percentage 值为 50 时，整个文档的一半会被打乱。

Percentage：将被打乱的字符串百分比。

Time Offset：以“每组”为基础偏移任何动画。例如，连接 交错 这样的行为，可创建逐词打乱的效果。

Direction Mode：确定组的打乱方式：

  • Start：从字符串开头打乱。Percentage 为 50 时，单词/行/段落/文档的前半部分会被打乱。
  • End：从字符串末尾打乱。Percentage 为 50 时，单词/行/段落/文档的后半部分会被打乱。
  • Random：随机打乱每个组的字符串。

Shuffle Type：确定打乱方法：

  • Unicode Offset：按 Unicode 码点偏移字母。例如，偏移量为 1 时，a 字符会被打乱为 b。此模式适用于非拉丁字符。
  • Random Alphanumeric：使用字母数字字符进行打乱。
  • Custom String：仅使用 Custom String 属性中输入的字符，从原始字符串进行打乱。

Unicode Offset：当 Shuffle Type 设为 Unicode Offset 时要偏移的码点数量

Keep Punctuation：勾选后，如果 Shuffle Type 设为 Unicode Offset，Space 字符和/或任何标点符号（.,- 等）将不会被打乱。

Random Seed：更改用于随机化打乱的种子。

Custom String：当 Shuffle Type 设为 Custom String 时，改用此处输入的字符串中的字符。
