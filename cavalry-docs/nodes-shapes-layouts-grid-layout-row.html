网格布局行

简介

网格布局行可用于将图形排列成一行，以便在网格布局组中使用。

布局简介→

放置在网格布局行下的每一项，都会根据父级网格布局组下传的尺寸约束放入相应的列中。

行不受其他行影响。一个包含 10 项的网格布局行可以与一个包含 3 项的网格布局行一起嵌套在网格布局组中。间隔器可用于在行中创建空白布局项，以构建列宽均匀的网格。

网格布局行：

网格布局行只有与网格布局组配合使用时才有意义。单独使用时，它没有任何作用。

对齐

图形的单元格内对齐可以通过其Advanced选项卡下的Vertical/Horizontal Layout Alignment选项设置。请参阅通用属性（Advanced 选项卡）。

请注意，文本图形的Alignment和Vertical Alignment会被这些设置覆盖。

界面

通用属性 +

Minimum Column Width：设置行中每一列的最小宽度。连接值数组可为每一列设置单独的值。

Ordering Policy：确定图形在网格布局行内的排列顺序：

  • Layer Order：根据图形在网格布局行内的顺序排列。层级顶部的图形被视为第一个布局项。
  • Alphabetical：根据Layer Name按字母顺序排列图形。
  • Shuffle：随机排列图形。

Flip Order：反转Ordering Policy。

Shuffle Seed：当Ordering Policy设置为Shuffle时设置随机种子。
