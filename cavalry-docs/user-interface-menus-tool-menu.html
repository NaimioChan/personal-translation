工具菜单

简介

工具可用于在视口中交互或创建图层。

工具设置

每个工具都有自己的设置，可在工具设置窗口中找到。绘制图形时，既可以绘制原始图形，也可以绘制可编辑图形。原始图形是具有 Radius、Size 等属性的图形，而可编辑图形由可移动的点或顶点组成。

启用 Create Editable Primitives 可创建可编辑图形。可编辑图形可使用编辑图形工具进行编辑。

快捷键

绘制图形时，可以使用以下快捷键执行各种操作：

  • 按住 Shift 可约束比例。
  • 按住 Option/Alt 可从光标起始位置向外绘制图形。
  • 选中工具后，在视口中单击一次将创建一个以光标为中心的默认图形。

你也可以 Option/Alt + 单击工具栏中的图标来创建默认图形。
