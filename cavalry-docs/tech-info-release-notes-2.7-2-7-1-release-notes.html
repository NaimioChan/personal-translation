2.7.1 发行说明

发布日期：2026年4月29日

重要缺陷修复

  • 已解决一个过度优化问题：连接了 Boolean Deformer 的图形更新无法即时生效。
  • 已解决一个问题：在 Pre-Comp 中，输入图形带动画的 Boolean Deformer 结果不一致。
  • 修复了在 Windows 上，无互联网连接或防火墙阻止许可调用时启动 Cavalry 导致崩溃的问题。
  • 改进了与旧版身份验证凭据的冲突，该冲突曾导致部分用户使用 Canva 登录时出现问题。
  • 已解决影响 Scenery.io 脚本的问题。
  • 新增了多项回退机制，以尽量改善部分用户遇到的“白色视口”问题；同时，当 GPU 不满足最低要求时，会给出更好的提示。
  • 上下文模块 现在支持第三方插件。

说明

  • CLI 在 Cavalry 2.7.1 中不可用，因此如果你正在使用该功能，请继续使用当前版本。我们正努力在后续版本中恢复该功能。
