交换颜色覆盖

简介

材质覆盖允许你编辑复杂/深层网格结构（如 SVG 或文本）内部的材质。这可以通过子网格行为的 Fill 或 Stroke 标签页实现。

Swap Color Override 让你可以取出子网格（例如 SVG、Text Shape 或 Duplicator）中的某一种特定颜色，并将其替换为另一种颜色。

界面

Common Attributes +

Old Color：设置要替换掉的颜色。

New Color：设置用于替换 Old Color 的颜色。

示例：

  1. 将 SVG 导入资源窗口。
  2. 将其拖入视口，创建一个SVG Shape。
  3. 将Sub Mesh连接到 SVG Shape 的 Deformer 属性。
  4. 在 Sub Mesh 上，切换到属性编辑器中的 Fill 标签页。
  5. 使用 + 按钮，为 Fill Overrides 属性添加一个 Swap Color。
  6. 为 Old Color 设置一个与 SVG 中相符的颜色值。
  7. 为 New Color 设置要将 Old Color 替换成的颜色值。
