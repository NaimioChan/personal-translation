通用属性（图形）

简介

Cavalry 中的大多数图形都包含下方列出的通用属性。

界面

Shape

Position：设置图形的位置。0,0 位于合成的中心。

Rotation：设置图形的旋转角度（单位为度）。

Scale：设置图形的缩放。

Skew：沿 X 轴或 Y 轴倾斜或错切图形。

Pivot：定义图形的轴心点。在为旋转和缩放制作动画时很有用。

Opacity：设置图形的不透明度。

Blend Mode：设置混合模式。

Deformers：已连接的变形器列表。使用 + 按钮创建并连接一个行为，或拖放一个现有行为以将其连接。

Filters：已连接的滤镜列表。使用 + 按钮创建并连接一个滤镜，或拖放一个现有滤镜以将其连接。

Motion Blur：启用/禁用运动模糊：

  • None：无运动模糊。
  • Full：启用Full 运动模糊。还需为合成启用 Motion Blur：点击场景树顶部的图标，或在合成设置窗口中勾选 Motion Blur。
  • Transform Only (Fast)：启用Transform Only 运动模糊。

Fill

Fill：启用/禁用填充。也可以通过 Option/Alt + 单击选项卡中的图标来设置。

Color：使用 Hex 或 RGB 值设置图形的颜色（仅 RGB 值可制作动画）。单击颜色色块可使用 HSV 设置颜色。

自动补全 Hex：

当十六进制代码包含重复的字符或数字序列时，它们会被自动补全。例如，输入 AB 然后按 Return，将得到 #ABABAB。

Shaders：已连接的着色器列表。

Alpha：整个着色器网络的不透明度/alpha 的主控。

Stroke

Stroke：启用/禁用描边。也可以通过 Option/Alt + 单击选项卡中的图标来设置。

Color Mode：确定颜色如何应用于描边：

  • Single Color：使用单一颜色。
  • Gradient：沿描边应用渐变。

Color：当 Color Mode 设为 Single Color 时，使用 Hex 或 RGB 值设置图形的颜色（仅 RGB 值可制作动画）。单击颜色色块可使用 HSV 设置颜色。

自动补全 Hex：

当十六进制代码包含重复的字符或数字序列时，它们会被自动补全。例如，输入 AB 然后按 Enter，将得到 #ABABAB。

Shaders：当 Color Mode 设为 Single Color 时，将着色器连接到此列表。

Gradient Mode：当 Color Mode 设为 Gradient 时，为 Gradient 选择一种插值方式。参见渐变。

Gradient：当 Color Mode 设为 Gradient 时，设置该渐变的颜色。

Alpha：整个着色器网络的不透明度/ alpha 的主控。

Width：设置描边的宽度。

Cap Style：设置开放路径上端点（描边两端）的外观：

  • Flat：在端点处终止的平整末端。
  • Round：以端点为圆心的半圆形末端。
  • Projecting：超出端点、延伸描边 Width 一半长度的平整末端。

锥形描边：

请注意，勾选 Tapered Width 时不支持 Projecting 端点。此时 Cap Style 将回退为 Round。

Join Style：设置接合处的外观：

  • Mitre：尖锐的拐角。
  • Round：圆角。
  • Bevel：斜切/倒角。

Mitre Limit：设置尖锐拐角被绘制为斜切的限制值。

Dash Pattern Mode：确定 Dash Pattern 值的使用方式：

  • Pixels：Dash Pattern 值以像素为长度单位使用。
  • Percentage：Dash Pattern 值以路径长度的百分比使用。

Dash Pattern：输入以逗号分隔的数字序列，例如 dash, gap。如果只使用一个值，该值将同时用于虚线和间隔。例如 10 与 10,10 相同。

Dash Offset：沿路径偏移 Dash Pattern。

Align：沿路径对齐描边：

  • Centre：沿路径中心对齐描边。
  • Inner：沿路径内侧对齐描边。
  • Outer：沿路径外侧对齐描边。

小心：

开放路径仅支持 Centre 对齐。当单个路径中出现多个轮廓时，无论 Align 设置如何，所有开放轮廓都将设为 Centre。

信息：

如果 Align 设为 Inner 或 Outer 并启用了 Trim，则闭合路径的 Cap Style 将设为 Flat，无论其设置如何。当一个图形中存在多个轮廓时，任何开放路径都会遵循 Cap Style 设置。

Trim：启用后，下列控件可用。

Gradient Trim Mode：当 Color Mode 设为 Gradient 且勾选 Trim 时，确定调整描边 Trim 时渐变的处理方式。

  • Compress：修剪后将渐变适配到路径长度。
  • Crop：让渐变保持固定于路径全长，因此修剪会遮住其中一部分。

Start：设置描边沿图形开始的百分比位置。

End：设置描边沿图形结束的百分比位置。

Travel：让描边沿图形移动。

Reverse Path：反转描边的方向。

Tapered Width：勾选后，描边可沿轮廓长度呈锥形变化。也可以使用描边宽度工具设置。

Width Graph：勾选 Tapered Width 后，使用图表定义描边的锥形变化。该图表也可在视口中使用描边宽度工具设置。

Multi Stroke：添加其他描边或描边复制器。

Masks

Feather：为图形添加模糊边缘。

Clipping Masks：连接用作剪切蒙版的图形。剪切蒙版是一种几何蒙版，因此使用图形的轮廓而不是其颜色信息。

列表界面选项：

  • Visibility：启用/禁用剪切蒙版。
  • Boolean options：
    • Union：合并图形。
    • Subtract：剪切图形。
    • Intersect：剪切图形之外的所有内容。

Clipping Mode：设置剪切蒙版的抗锯齿质量：

  • Best：高质量抗锯齿。
  • Normal：默认抗锯齿。
  • Fast：无抗锯齿。

Feather Clipping Masks：勾选后，Feather 值也会应用到连接到该图形的所有剪切蒙版。

信息：

将图形作为剪切蒙版连接时，其可见性将设为隐藏。

信息：

使用合成作为蒙版时，请确保该合成的背景 Alpha 设为 0，这样合成边界才不会包含在蒙版中。

Track Mattes：连接用作轨道遮罩的图形。轨道遮罩是基于图像的蒙版。

列表界面选项：

  • Visibility：启用/禁用轨道遮罩。

Track Matte Mode：选择一个选项来定义轨道遮罩的透明度：

  • Alpha：当 alpha 通道的像素值为 100% 时不透明。
  • Alpha Inverted：当 alpha 通道的像素值为 0% 时不透明。

小心：

无法将带有轨道遮罩的图形用作另一个图形的轨道遮罩。

Advanced

2.5D：勾选后，如果合成中添加了摄像机，图形将以 2.5D 方式绘制。

Lottie 导出：

  • Export if Visible：如果图形的可见性设为开启，则导出该图形。
  • Always Export：无论图形的可见性设为开启还是关闭，都导出该图形。
  • Never Export：无论图形的可见性设为开启还是关闭，都不导出该图形。

Lottie 烘焙：

  • Automatic：根据场景中的连接自动计算图形是否需要烘焙。
  • Animated Mesh：逐帧烘焙图形信息。材质将为静态，不支持点数变化。
  • Animated Mesh & Materials：逐帧烘焙每个图形及其任何材质。
  • Nuclear：这是“核弹式烘焙”选项，旨在绕过 Lottie 的不足。
  • Still：图形将导出为不含动画的静帧。

Wireframe：在视口中将图形显示为线框。该选项也可通过在场景树中右键单击图形来设置。勾选后，图形将不会被渲染。

Hidden：勾选后，图形将从视口中隐藏。这相当于将场景树中的眼睛图标切换为关闭。

Draw On Top Of Parent：勾选（默认）后，如果该图形是另一个图形的子级，它将绘制在父级前方。例如，当角色的眼睛是头部的子级时，这很有用。取消勾选可阻止此行为。请注意，如果图形启用了 2.5D，此属性将被忽略。

Freeze Calculations：勾选后，任何连接到该图形的输入都将暂停。这可用于优化那些连接到图形的连接已不再更新的合成。例如，将此属性从关闭关键帧为开启，将阻止对图形的任何进一步输入计算，转而使用最后已知的值。以这种方式减少不必要的计算，可以让较重的合成播放得更快。

Freeze Calculations：

  • 勾选 Freeze Calculations 会阻断任何输入/下游连接。任何输出/上游连接仍将继续计算，但由于整体需要处理的计算更少，它们也会更快。
  • 由于 Cavalry 中的任何计算最终都只为渲染图形所需，因此 Freeze Calculations 只影响图形。
  • 变换（位置、旋转、缩放等）对性能的影响非常小，因此冻结图形不会阻止其变换。
  • Freeze Calculations 具有层级性。这意味着如果父级被冻结，任何子图形也会被冻结。
  • 在合成引用（又称 Pre-Comp）中的图形上使用 Freeze Calculations 不受支持。

在下图中，假设 Freeze Calculations 已从第 24 帧的关闭关键帧为第 25 帧的开启。在第 25 帧，复制器将停止计算由噪波驱动的椭圆的半径。即使噪波在第 25 帧已停止变化，Cavalry 仍会继续“监听”任何变化，因此尽管图形本身没有变化，播放仍可能受到影响。勾选 Freeze Calculations 后，任何“监听”都会暂停，性能将大幅提升。

Vertical Layout Alignment：当图形属于布局组时，设置其单元格内的垂直对齐方式：

  • Ignore：遵循图形自身的对齐方式（不设置任何自定义对齐）。
  • Top：将图形对齐到其单元格的顶部。
  • Middle：将图形对齐到其单元格的中部。
  • Bottom：将图形对齐到其单元格的底部。

Horizontal Layout Alignment：当图形属于布局组时，设置其单元格内的水平对齐方式：

  • Ignore：遵循图形自身的对齐方式（不设置任何自定义对齐）。
  • Leading：将图形对齐到其单元格的左侧。
  • Centre：将图形对齐到其单元格的中部。
  • Trailing：将图形对齐到其单元格的右侧。

Exclude From Layout：勾选后，如果图形属于布局组，将阻止其参与布局的计算。这对于调试布局很有用。如需要，也可以将 Exclude From Layout 连接到 Hidden 属性，使该图形同时从视口中隐藏。

Layout Based on Size at Frame：勾选后，属于布局组的图形的边界框可基于其在特定帧上的大小来设置。

Layout Frame：勾选 Layout Based on Size at Frame 后，设置用于确定属于布局组的图形边界框的帧。这有助于隔离动画图形可能对布局组造成的影响。

Scheduling Group Mode：确定图形在属于调度组时的行为：

  • Use：该图层被调度组使用。
  • Ignore：该图层被调度组排除。
  • Use Children：该图层被排除，但其子级会被使用。

Guide Layer：确定图形在渲染到文件时，或当其父合成为另一个合成中的图层（Pre-Comp）时是否可见：

  • Off：不将图形设为参考图层。
  • On (Visible in Pre-Compositions)：当图形是 Pre-Comp 的一部分时会可见，但在渲染到文件时不会出现。
  • On (Invisible in Pre-Compositions)：当图形是 Pre-Comp 的一部分时不会可见，并且在渲染到文件时也不会出现。

Posterize Time：勾选后，图形的动画将按所选的 Frame Rate 更新，可用于创建与合成实际帧率无关的阶梯/频闪效果。注意：使用时运动模糊可能产生不可预测的结果。

Frame Rate：勾选 Posterize Time 后，设置用于“抽帧”图形动画的帧率。请注意，仅当该值低于合成帧率时才会生效。

Offset：勾选 Posterize Time 后，按该值移动图形的保持边界。具有相同 Frame Rate 的两个图形可以通过调整此值在不同的帧上交错动画。
