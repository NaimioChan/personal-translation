3D 矩阵

简介

为图形和子网格应用 3D 变换。

界面

通用属性 +

Position：设置 X 和 Y 位置。

Position Z：设置 Z 位置。

Rotation：设置 X 和 Y 旋转。

Rotation Z：设置 Z 旋转。

Align X：围绕 X 轴旋转时，将轴心点对齐到图形的边界框。值为 -1 会将轴心定位到左边缘，值为 1 会将其定位到右边缘。

Align Y：围绕 Y 轴旋转时，将轴心点对齐到图形的边界框。值为 -1 会将轴心定位到底部边缘，值为 1 会将其定位到顶部边缘。

Use Levels：影响图形层级结构中的不同层级。请参见下面的示例和子网格页面以了解更多信息。

Level Mode：这些预设会设置 Level 值：

  • Custom...：手动设置 Custom Level。
  • Text (Lines)：将 Level 值设为 1。
  • Text (Words)：将 Level 值设为 2。
  • Text (Characters)：将 Level 值设为 3。

Custom Level：手动设置 Level 值。

示例：

  1. 创建一个图形。
  2. 在属性编辑器中，点击 Deformers 属性上的 + 按钮。
  3. 选择 3D Matrix。
  4. 在场景窗口中双击 3D Matrix，将其加载到属性编辑器中。
  5. 拖动 Rotation X 属性。

图形将围绕其 X 轴旋转，呈现出三维物体的外观。

示例：深度排序

  1. 创建一个矩形。
  2. 启用矩形的 Stroke。
  3. 选中矩形，点击复制器图标（位于工具架中）。
  4. 设置复制器的：
    1. Distribution 为 10。
    2. Size 为 600。
  5. 点击复制器 Deformers 属性上的 + 按钮，并从列表中选择 3D Matrix。
  6. 右键点击 3D Matrix 的 Position Z 属性 > Add Behaviour > Value。
  7. 将 Value 的 Value 设为 -100。
  8. 在 Value 的 Falloffs 标签页中，右键点击 Falloffs 输入 > Add Falloffs > Falloff。
  9. 在 3D Matrix 上，勾选 Use Levels。
  10. 左右移动衰减。

当衰减经过每个矩形时，该矩形会移动到其他矩形的前面。
