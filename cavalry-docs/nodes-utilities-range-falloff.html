范围衰减

简介

Range Falloff 与 衰减类似，都可用于限定大多数行为的强度，但它不使用图形，而是使用范围。

界面

Common Attributes +

Strength：Falloff Graph 属性的乘数。

Mode：确定如何选择范围内的索引：

  • Specific Indices：手动输入索引，以确定选中哪些行/词/字符。
  • Percentage：索引将按占总范围的百分比来计算。
  • Transition：创建依次“扫过”索引的效果。

Indices：当 Mode 设为 Specific Indices 时，设置要选择的索引。列表中的值应以逗号 , 分隔，范围应以冒号 : 分隔。例如，0,1:3,8 将选择索引 0、1、2、3 和 8。你还可以输入 first 或 last，以程序化方式选择这些索引。请注意，处理文本时，空格字符也会被视作索引。

Start：当 Mode 设为 Percentage 时，设置起始百分比的值。

End：当 Mode 设为 Percentage 时，设置结束百分比的值。

Offset：当 Mode 设为 Offset 或 Percentage 时，设置要从索引中添加/减去的值。可用于让 Range Falloff 的效果移动/循环。

Transition Size：当 Mode 设为 Transition 时，设置过渡窗口内的索引数量。

Completion：当 Mode 设为 Transition 时，设置过渡完成的程度。

Use Graph：当 Mode 设为 Percentage 时，勾选此项可使用 Falloff Graph 衰减数值。

Falloff Graph：参见 图表属性。图表的 X 轴表示范围内的索引总数。

示例：

  1. 创建一个 椭圆。
  2. 创建一个 值 行为。
  3. 设置：
    1. Value 为 20。
    2. Offset 为 20。
  4. 连接 value.id→ellipse.radius
  5. 选中 Ellipse，然后点击复制器按钮（位于工具架中）。
  6. 在 Value 的 Falloff 标签页中，右键单击 > Add Falloff > Range Falloff。
  7. 将 Range Falloff 的 Mode 设为 Percentage。
  8. 调整 Start/End 值。
