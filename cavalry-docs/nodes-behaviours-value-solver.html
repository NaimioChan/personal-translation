值求解器

简介

存储之前帧的值，以便随时间累积和/或淡出。

界面

Solver

Mode - 设置 Solver 的模式：

  • Accumulate - 在每一帧上加上 Value。
  • Highest - 如果当前帧的值高于 Value，则保留该值。
  • Lowest - 如果当前帧的值低于 Value，则保留该值。
  • Velocity - 将图形的速度乘以 Value。参见下方示例。

Value - 设置在每一帧上添加到 Solver 的值。

Fade Mode - 决定值是保持持久还是淡出回到初始值。

  • Off - 不淡出值。
  • Multiply by Value - 在每一帧上，根据 Fade Value 对值进行相乘。

Fade Value - 当 Solver 处于“关闭”状态（例如在衰减之外）时，值回到其初始值的速度。该值越低，淡出越快。

Offset - 在输出上加上/减去一个值。

Start Frame - 设置启动 Solver 的第一帧。默认情况下，它连接到合成的 Frame Range（Start）属性——移除该连接即可设置自定义值。

Time - 默认连接到合成的 Time 属性。

Advanced

Use Cache - 勾选后，模拟可以保存到 .sdcache 文件。这对于较重模拟的更快播放，或通过 Cache Offset 进行时间重映射会很有用。它也是运动模糊所必需的。

Cache File Path - 设置缓存文件的保存位置。该位置在首次缓存 Solver 时确定，也可使用文件夹图标打开访达/资源管理器窗口并导航到已有的 .sdcache 文件。

Cache Offset - 为缓存设置时间偏移。

示例：

  1. 创建一个 Value Solver。
  2. 将其 Offset 设为 2，并将 Fade Mode 设为 Multiply by Value。
  3. 在属性编辑器中右键单击 Value Solver 的 Value 属性，并添加一个Value 行为。
  4. 将 Value 行为上的 Value 设为 0.5。
  5. 为 Value 行为添加一个衰减。
  6. 创建一个多边形。
  7. 连接 valueSolver.id→polygon.sides
  8. 选中多边形，然后在工具架中单击复制器图标。
  9. 将播放头向前移动，使其不在第 0 帧。
  10. 在视口中移动衰减。

当衰减在多边形上移动时，它们的边数会增加，然后回到 2。由于不存在 2 边的多边形，图形会消失。将 Value Solver 上的 Offset 设为 3，则图形在衰减之外时会变成三角形（3 边多边形）。

在上面的示例中，颜色也受到了影响。要做到这一点，只需：

  1. 再创建一个Value 行为。
  2. 连接 valueSolver.id→value.value
  3. 连接 value.id→polygon.materialColor.r
  4. 调高 Value 上的 Strength 属性。

在此示例中，Value 只是被用作乘数，用来设置一个在 0-255 范围内有可见效果的值（红色通道）。

示例 - Velocity：

  1. 创建一个椭圆。
  2. 在属性编辑器中，右键单击 Position 属性并选择 Add Behaviour > Noise。
  3. 将噪波的 Minimum 和 Maximum 设为 -100、100。
  4. 创建一个 Value Solver。
  5. 将 Value Solver 的 Mode 设为 Velocity。
  6. 将 Value Solver 的 Value 设为 0.1。
  7. 将 Value Solver 的 Offset 设为 1。
  8. 连接 valueSolver.id→ellipse.scale.x
  9. 连接 ellipse.scale.x→ellipse.scale.y
  10. 播放。

随着椭圆速度的增加，其缩放也会增加。
