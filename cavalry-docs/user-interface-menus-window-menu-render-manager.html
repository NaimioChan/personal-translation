渲染管理器

简介

渲染管理器是将场景输出为文件的地方。该窗口由两部分组成：标题栏和渲染队列。顶部的标题栏包含一些用于提交渲染的简单控件，底部的渲染队列则是你拖入合成以创建渲染队列项的地方。

提示：

  • 将合成添加到渲染队列会创建渲染队列项。可以通过窗口顶部的 + Current Composition 按钮，或从资源窗口将合成拖入渲染队列来完成。
  • 渲染队列项会随场景一起保存。
  • 任何未勾选的渲染队列项都不会渲染。

界面

标题栏

+ Current Composition：将当前活动的合成添加到渲染队列。

Progress Bar：指示整个渲染队列的完成程度。

Render All：开始渲染渲染队列中所有启用的渲染队列项（RQI）。

  • 展开所有渲染队列项
  • 折叠所有渲染队列项
  • 删除所有渲染队列项

Background Rendering：勾选后，渲染会被发送到一个单独的进程。系统会保存场景文件的临时副本，以便在渲染进行时继续在 Cavalry 中工作。资源（视频除外）会保存到内存中，因此对这些资源的更改不会影响最终渲染。后台渲染期间不应移动或更新视频资源。

启动后台渲染后，渲染状态每 5 秒会显示在消息栏中，并在渲染完成时显示一条确认消息。

Dynamic Index：此值可以传递给任何其他属性，并按“每次渲染”迭代。例如，如果你在 Dynamic 标签页下将 Render Range 设为 3，则该属性会在第一次渲染时传递 0，第二次为 1，第三次为 2。参见动态渲染。

Dynamic Index Offset：偏移 Dynamic Index，可用于预览渲染。

渲染队列项

Header

Expand/collapse：展开或折叠渲染队列项。

Enable/disable：勾选后，渲染队列项会包含在渲染队列中。

Name：渲染队列项File Name的预览。

Tag：渲染队列项File Format的可视化标识。

Presets：保存、应用或删除预设。

默认文件格式：

如果某个预设已被设为“Set as Default Settings”，则创建新的 RQI 时会使用该预设定义的File Format。否则将使用上次使用的File Format。

Delete：删除渲染队列项。按住 Option/Alt 可跳过确认对话框直接删除。

Output

File Name：设置输出文件名。

信息：

如果你在File Name中包含斜杠 /（macOS）或反斜杠 \（Windows），系统会在文件系统上创建一个新目录（如果不存在）。例如，MyFolder/Composition1 会将文件名为 Composition1 的文件输出到 MyFolder 目录中。

Frame Range Mode：选择帧范围模式：

  • Composition Start/End：输出完整的合成长度。
  • Playback Start/End：输出播放范围内的帧。
  • Current Frame：输出当前帧。
  • Custom...：设置自定义帧范围。

Frame Range：设置 Custom 帧范围。

Use Composition Playback Step：勾选后，将遵循合成的 Playback Step。取消勾选时，将使用默认的 Playback Step 值 1（每一帧）。

Padding：设置帧编号的补零位数（例如 3 会输出 image.001.png）。

Path：设置保存输出的目录。

Resolution Scale：分辨率的乘数。

Render Quality：设置渲染哪些视口特性。这有助于加快测试渲染：

  • Full：使用抗锯齿的完整质量。
  • No Anti-aliasing：关闭抗锯齿。
  • No Anti-aliasing, Shaders or Filters：移除抗锯齿、所有滤镜和着色器以及任何图像过滤（参见图像着色器）。
  • Anti-aliasing：确定当Render Quality设为 Full 时使用的抗锯齿类型：
    • Auto (Recommended)：为每个图层自动选择最合适的抗锯齿方法。
    • Standard：对所有图层使用解析抗锯齿。这能为大多数作品提供出色的质量，也是典型场景中最快的选项。某些高级功能可能渲染较慢。
    • Enhanced (MSAA)：对所有图层使用多重采样抗锯齿。这可以在某些作品上产生更干净的边缘，并提升网格、粒子和渐变描边等特定功能的性能。

Respect Viewport Filtering：勾选后，任何通过标签在视口中隐藏的图层都不会被渲染。这也包括通过 Composition > Solo Selection in Viewport 命令进行的独显，该命令同样使用标签系统。

Format

File Format：选择要输出的文件格式。请注意，除非设置了默认预设，否则File Format将基于最后添加的 RQI 设定。

  • APNG：输出动画 png。
    • Looping：勾选后，APNG 将自动循环。
  • Audio Only：输出仅含音频的 .aac 文件。
    • Container：选择要输出的文件格式：
      • AAC：输出 MPEG-4 AAC 编码的 .aac 音频文件。
      • AIFF：输出无损 Linear PCM 编码的 .aiff 音频文件。
      • Wav：输出无损 Linear PCM .wav 音频文件。
    • Audio Quality：选择音频的比特率。比特率越高，音质越好，但文件可能更大。
    • Audio Sample Rate：选择导出音频的采样率。
  • GIF：输出 .gif 文件。
    • Quality：设置图像的位深度。值越高，结果越接近原始设计，但文件越大。
    • Palette：确定颜色表的生成方式：
      • Whole Animation：在动画时长内采样约 12 帧来创建颜色表。
      • First Frame：仅采样第一帧来创建颜色表。这比 Whole Animation 更快，但不会包含动画后续可能出现的颜色。
    • Dithering：确定要使用的抖动类型，以在使用有限调色板的图像中营造更高色深的错觉，从而得到更小的文件。
      • None：禁用抖动。
      • Ordered：处理通常很快，在动画中保持图案稳定，并形成整齐的交叉线外观。
      • Diffusion：通常能生成平滑、自然的渐变并保留精细细节，但速度较慢，在运动中可能出现闪烁。
    • Alpha：勾选后，透明度低于 Alpha Threshold 的像素将作为完全透明的像素导出。
    • Alpha Threshold：alpha 值低于此值的像素将被视为透明。
  • JPEG：输出 .jpg 图像序列。
    • Quality：设置质量。值越低，文件越小，但会牺牲图像质量。
  • Lottie：输出 .json Lottie 文件。
  • MP4：输出 .mp4 视频文件。
    • Quality：设置输出文件的质量。比特率越低，文件越小。
    • Custom Bitrate：设置自定义比特率。Bitrate 必须设为 Custom...。
    • Export Audio：勾选后，合成中的任何音频都会被导出。
    • Audio Quality：选择音频的比特率。比特率越高，音质越好，但文件可能更大。
    • Audio Sample Rate：选择导出音频的采样率。
  • PNG：输出 .png 图像序列。
    • Bit Depth：设置每个像素颜色信息所用的位数。更高的位深度支持更多颜色：
      • 8-bit：在文件大小与视觉保真度之间取得平衡。
      • 16-bit：产生更平滑的颜色过渡、更少的色带，并保留更多颜色信息。
    • Compression：设置压缩（0 为不压缩）。
    • PNG Filter：
      • None -
      • Fast -
      • Best -
  • QuickTime：输出 QuickTime 影片。
    • Codec：选择编解码器：
      • Motion JPEG
      • Uncompressed 422
      • ProRes
    • ProRes Codec
      • ProRes 422 HQ
      • ProRes 422
      • ProRes 422 LT
      • ProRes 422 Proxy
      • ProRes 4444 (supports alpha)
      • ProRes 4444 XQ (supports alpha)
    • Bit Depth：设置每个像素颜色信息所用的位数。更高的位深度支持更多颜色：
      • 8-bit：在文件大小与视觉保真度之间取得平衡。
      • Up to 12-bit：产生更平滑的颜色过渡、更少的色带，并保留更多颜色信息。
    • Jpeg Quality：设置 Motion JPEG 编解码器的质量。值越低，文件越小，但会牺牲图像质量。
    • Export Audio：勾选后，合成中的任何音频都会被导出。
    • Audio Format：选择要导出的音频格式：
      • AAC：导出 AAC 音频。
      • Linear PCM：导出 Linear PCM（16 位小端、未压缩）。
    • Audio Quality：选择 AAC 音频的比特率。比特率越高，音质越好，但文件可能更大。
    • Audio Sample Rate：选择导出音频的采样率。
  • SVG：输出 .svg。这会输出一系列 SVG，而不是一个动画 SVG。
    • Include Background：勾选后，合成背景会作为图形包含在 SVG 中。
  • Sprite Sheet：将合成的每一帧输出到单张平铺的拼版图中。
    • Compression：设置压缩（0 为不压缩）。
    • PNG Filter：
      • None -
      • Fast -
      • Best -
    • Maximum Size：设置生成精灵图的最大尺寸。最终图像尺寸为合成分辨率乘以网格的行/列数，再加上Sheet Margin和Cell Gaps。如果所有帧超出 Maximum Size，则单元格/瓦片会被缩小以适应。
    • Sheet Margin：设置图版边缘与单元格/瓦片之间的边距。
    • Cell Gap：为每个单元格/瓦片添加内边距。可用于防止单元格/瓦片相互渗色。
    • JSON Metadata：勾选后，会输出每个瓦片大小和位置的 JSON 字典。可在游戏引擎中用于引用正确的单元格。
  • WebM：输出 .webm 视频文件。注意：目前不支持 alpha。
    • Codec：选择编解码器：
      • VP8
      • VP9
      • AV1
    • Quality Mode：确定设置文件大小/质量的方法。
      • Bitrate：设置比特率。
      • Quality：设置文件大小与质量之间的平衡。
    • Bitrate Presets：当Quality Mode设为 Bitrate 时，设置输出文件的比特率。比特率越低，文件越小。
    • Custom Bitrate：当Quality Mode设为 Bitrate 时，设置自定义比特率。Bitrate Presets必须设为 Custom...。
    • Quality：当Quality Mode设为 Quality 时，设置文件大小与质量之间的平衡，0 为文件最小但质量最差，100 为质量最好但文件最大。
    • Export Audio：勾选后，合成中的任何音频都会被导出。
    • Audio Quality：选择音频的比特率。比特率越高，音质越好，但文件可能更大。
    • Audio Sample Rate：选择导出音频的采样率。
  • WebP：输出 .webp 图像文件。
    • Quality：设置质量。值越低，文件越小，但会牺牲图像质量。

Dynamic

Dynamic Render：勾选以启用动态渲染。

Render Range：设置一个包含首尾的范围值，以确定对序列迭代多少次。例如，范围 0..5 会产生 6 次渲染（0,1,2,3,4,5）。

Ensure Unique File Names：为每次动态渲染设置唯一的 File Name/Path，以防在同一次渲染会话中互相覆盖。勾选后，每次动态渲染会被放入一个文件夹，其文件名会附加Dynamic Index作为后缀。注意：如果File Name包含 <Dynamic> 渲染标记，渲染不会放入单独的文件夹。取消勾选则意味着必须手动管理文件名，例如通过与 File Name 相连的 Formatted String String Generator。

Compositions

Compositions：从资源窗口拖放合成。

信息：

Compositions 标签页可用于渲染多个共享相同 Output/Format/Dynamic Render 设置的合成。

齿轮：点击齿轮图标会打开一个弹出窗口，其中包含在渲染时重新调整合成时间的选项：

  • Retime Render：勾选后，渲染会重新调整为New Composition Length。
  • New Composition Length：输入时间码（MINUTE:SECOND:FRAME）来设置渲染时长。例如，一个 25fps、时长 100 帧（4 秒）的合成，可通过输入 00:06:00 重新调整为 6 秒。

重新调整时间：

  • 虽然可以缩短合成长度，但最佳做法是用此功能来延长时长。这样可以降低重要帧（例如弹跳球触地的瞬间）被移除的风险。
  • 延长合成时，需要理解：虽然动画曲线可以在渲染时被拉伸，但发生在整数帧上的逐帧动画（例如图像序列/视频）会产生重复帧。
  • 当动画发生在 1 帧内时，请确保动画曲线的插值设为 Stepped，以防止结果在重新调整时间时被拉伸。

Scripts

Setup Render Script：添加一个在任何渲染设置开始之前运行的脚本，因此可用于影响渲染队列项本身。

Pre-Render Script：添加一个在渲染队列项开始之前运行的脚本。

Post-Render Script：添加一个在渲染队列项完成后运行的脚本。

更多信息请参见渲染脚本和脚本编写。

Upload

Canva

  • Upload to Canva：勾选后，渲染会上传到用于登录 Cavalry 的 Canva 账户。

使用 取消上传。此图标会更新为 ，即你 Canva 账户的 Projects 部分。注意，完成的上传出现在 Canva 中之前可能会有轻微延迟。

链接到 Canva：

渲染会出现在你 Canva 账户的 Projects 部分。

支持的格式/文件大小列表请参见此处。

旧版账户（Cavalry 2.6.1 及更早版本）：要上传到 Canva，必须通过访问 Account 页面并导航到 Linked Accounts 部分来创建与你 Cavalry 账户的链接。点击 Manage Links 开始此过程。

Presets

Upload：勾选后，渲染会上传到 Upload Preset 中定义的在线位置。

Upload Preset：选择一个用于发送上传的预设。使用上传预设管理器创建和编辑上传位置。

取消渲染：

取消渲染也会取消队列中的所有上传，但任何“进行中”的上传会继续。

Metadata

Enable Metadata：勾选后，元数据文件会随渲染一起导出。

Format：选择元数据使用的格式：

  • JSON：将元数据导出为 JSON 字典。
  • Simple Traits JSON：导出按 traits 文件用途排版的元数据。会自动包含一个以文件名为值的 'image' 键。
  • NFT Traits JSON：导出符合 ERC-1155 的元数据，供 NFT.Storage 等网站使用。

添加

  • Key：值的标识名称。使用点（.）可将键分组到 JSON 内它们自己的字典中。例如，attributes.colour 会把键 colour 放入名为 attributes 的字典中。
  • Value：连接图层的属性以用作值。通常，该属性会作为动态渲染的一部分设置，以便在每次渲染时更新。

Id 连接：

目前无法将图层的 Id（或输出）连接直接连到键值对的 Value 中。变通方法是经由另一个图层。例如，创建一个 随机 和一个 值 行为，然后将 Random.Id 连接到 Value.Value，再将 Value.Value 连接到元数据的 Value。

信息：

元数据文件会按每个渲染的视频、静帧或图像序列自动创建。

{


    "Key": "Value"


}
{


    "image": "Simple Traits Image",


    "properties": [


        {


            "trait_type": "first",


            "value": "Cavalry"


        }


    ]


}
{


    "image": "NFT Traits Image",


    "properties": {


        "rich_property": [


            0,


            1,


            3,


            4


        ],


        "simple_property": "Cavalry"


    }


}

提示：

可以用键值对生成字典。在 Key 中输入 Dictionary，并将 [1,2,3,4] 的 字符串 连接到 Value，会得到：

{


    "Dictionary": [


        1,


        2,


        3,


        4


    ]


}

字符串必须用引号（""）包裹。例如，值为 ["string",2,3,4] 会得到：

{


    "Dictionary": [


        "string",


        2,


        3,


        4


    ]


}
