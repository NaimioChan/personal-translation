音频智能文件夹

简介

Audio Smart Folder 可用于导入包含音频资源的文件夹，随后可通过外部数据或连接引用这些资源。

受支持的音频格式列表请参见资源窗口。

导入 Audio Smart Folder：

  1. 在资源窗口中右键单击，然后选择 Import Audio Smart Folder...
  2. 在文件系统中定位到包含音频文件的目录，然后点击 OK。

导入文件夹后，可将其与从智能文件夹获取资源工具配合使用。将 Audio Smart Folder 从资源窗口拖入场景窗口或视口，会创建并连接一个从智能文件夹获取资源工具和素材图形——将 Asset from Smart Folder 的 Path 更新为音频轨道相对于 Audio Smart Folder 的位置，即可引用该轨道。例如 path/to/track.wav。

示例：

  1. 导入一个包含 beep.wav、bloop.wav 和 whoosh.wav 文件的 Audio Smart Folder。
  2. 将该 Audio Smart Folder 从资源窗口拖入属性编辑器或视口。这会创建一个从智能文件夹获取资源工具和声音行为。
  3. 创建一个字符串数组。
  4. 使用 Add 按钮添加两个索引，并分别填入 beep.wav、bloop.wav 和 whoosh.wav。
  5. 将 String Array 连接到从智能文件夹获取资源的 Path 属性。
  6. 取消勾选 Asset Array 上的 Auto Index，并在 Index 中输入 1。

播放时，bloop.wav 会发声。

试着将 String Array 换成电子表格，并把渲染管理器的 Dynamic Index 连接到其 Index。

智能文件夹深度：

出于性能考虑，智能文件夹的最大深度限制为 5 层目录。在下例中，Level5 目录中的轨道可以访问，而 Level6 目录中的轨道则无法访问。

📁 Root

  ┠ 📁 Level1

  ┠ track.wav

    ┠ 📁 Level2

    ┠ track.wav

      ┠ 📁 Level3

      ┠ track.wav

        ┠ 📁 Level4

        ┠ track.wav

          ┠ 📁 Level5

          ┠ track.wav

            ┠ 📁 Level6

            ┠ track.wav
