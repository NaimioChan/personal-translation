颜色材质覆盖

简介

Material Overrides 可用于编辑 SVG 或文本等复杂/深层网格结构内部的材质。这可以通过子网格行为的 Fill 或 Stroke 选项卡实现。

为子网格添加 Color Material Override 后，就可以在原始颜色与 Override 设置的值之间进行混合。之后可以为子网格添加衰减来控制该效果。

界面

Common Attributes +

Color：使用十六进制或 rgb 值设置颜色（注意：只有 rgb 值才能被动画）。

示例：

  1. 将 SVG 导入资源窗口。
  2. 将其拖入视口，并从选项中选择 Asset Layer，创建一个SVG 图形。
  3. 将子网格连接到 SVG Shape 的 Deformer 属性。
  4. 在子网格上，切换到属性编辑器中的 Fill 选项卡。
  5. 使用 + 按钮向 Fill Overrides 属性添加一个 Color Material Override。
  6. 设置一个 Color。
  7. 在 Color Material Override 上打开 Falloff 选项卡，右键添加一个衰减。
  8. 将衰减移到 SVG Shape 上方。

当衰减在 SVG 上移动时，图形的颜色将变为步骤 6 中设置的颜色。
