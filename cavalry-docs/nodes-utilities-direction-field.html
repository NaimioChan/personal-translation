方向场

简介

Direction Field 会在Forge Dynamics模拟中创建方向力，推动图形沿其方向移动。这可用于模拟风等自然元素。

界面

Common Attributes +

Custom Color：默认情况下，场会使用其标签颜色；勾选Custom Color 后，将使用Color属性设置的颜色。

Draw Color：为场在视口中的显示设置自定义颜色。

Strength：设置场的强度。

Direction：以向量设置场的方向。例如 1, 0 = 右，0, 1 = 上。使用Strength属性作为乘数。

Rotational Force：对 Body 施加旋转力，使其在移动时旋转。

Affects Groups：输入以逗号分隔的字符串（例如 text, rocks），以指定/筛选受场影响的特定Collision Groups。可通过 Forge Dynamics 的Per Body Settings为 Body 添加 Collision Groups。

Falloffs：连接一个衰减，以限定场在合成中的生效位置。
