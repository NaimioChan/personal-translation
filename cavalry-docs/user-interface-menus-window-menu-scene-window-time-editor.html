时间编辑器

简介

调整图层的片段和动画曲线。

界面

片段

当光标悬停在片段末端时，该末端会高亮。单击并拖动图形片段任意一端，即可调整在视口中显示的帧。当播放头位于片段范围内时，图形将可见。对于行为，片段表示其被启用的时间段。

片段对工具、滤镜或着色器没有效果。这些图层会显示为箭头形片段。在视口中绘制的工具（如衰减和空对象）以及声音行为是此规则的例外。它们的行为与图形相同。

设置起点/终点

按住 Option/Alt 悬停在端点上，可以同时调整多个图层的起点/终点。任何共享相同入点/出点的图层，其端点都会高亮，并在单击拖动时一起移动。当一个图层的入点与另一个图层的出点位于同一帧时，也是如此。

单击并拖动入点与出点之间的条带即可移动整个片段。

快捷键

快捷键 说明
[ 将所选片段的入点移动到当前帧。
] 将所选片段的出点移动到当前帧。
Option/Alt + [ 将所选片段的入点裁剪到当前帧。
Option/Alt + ] 将所选片段的出点裁剪到当前帧。

拆分/合并片段

对于受支持的片段，右键单击图层并选择 Clips > ... 可以使用更多选项：

  • Split Clip：在当前帧拆分片段。这会把片段分成两个，意味着图层可以在视口中多次打开/关闭。
  • Merge Clip：当片段已被拆分时，将片段重新合并为单个片段。
  • Add Clip to Start：如果片段的起点设置在 0 帧之后，则添加一段从 0 帧开始并在现有片段起点结束的部分。
  • Add Clip to End：如果片段的终点设置在最后一帧之前，则添加一段从现有片段终点开始并在合成最后一帧结束的部分。

显示名称

在时间编辑器中任意位置右键单击，并在 Show Names 项下选择一个选项，即可在片段上显示图层名称。

  • None：不显示图层名称。
  • Left：将图层名称对齐到片段的左边缘显示。
  • Right：将图层名称对齐到片段的右边缘显示。

关键帧

创建关键帧

设置关键帧：在属性编辑器中设置首个关键帧后，你可以在 Time Editor 中继续设置更多关键帧。为此，可以任选以下方式：

  • 移动播放头并拖动属性的值。
  • 移动播放头并单击属性控件中的关键帧图标。
  • 选择一个关键帧或关键条，然后右键单击 > Add Keyframe。

编辑关键帧

要编辑关键帧，可以任选以下方式：

  • 将播放头移动到与现有关键帧相同的帧，然后拖动或编辑该属性的值。
  • 双击关键帧，然后通过弹出控件拖动或编辑该属性的值。双击时按住 Option/Alt 还会将播放头移动到该关键帧。

移动关键帧

要移动关键帧，只需单击并拖动。

要移动选中的多个关键帧，可以 Cmd/Ctrl + 单击或框选多个关键帧，然后拖动移动。你也可以选择和移动来自多个属性和/或图层的关键帧。

删除关键帧

要删除一个或多个关键帧，可以任选以下方式：

  • 选择一个或多个关键帧，然后按 Delete 键。
  • 选择一个或多个关键帧，然后右键单击 > Delete Keyframe(s)。

复制关键帧

要复制关键帧，请选中一个关键帧，选择 Edit > Copy Keyframe（Cmd/Ctrl + C），然后移动播放头并选择 Edit > Paste（Cmd/Ctrl + V）。对同一属性上的多个关键帧也可以执行相同操作。

你还可以将关键帧数据从一个图层复制到另一个图层。如果要复制的关键帧数据所属的属性已存在于目标图层上，这些关键帧将添加到该属性中；如果该属性不存在，则会连同关键帧数据一起添加。

再制关键帧

要再制关键帧，请选中它们，然后 Option/Alt + 单击并拖动所选内容中的任意一个关键帧。松开鼠标后即会创建关键帧的副本。此操作可跨多个属性执行。

为关键帧着色

要更改关键帧的颜色，请选择一个或多个关键帧，然后右键单击 > Set Color > 选择颜色。这对于突出动画中的关键时刻很有用。

复制缓动

将关键帧的缓动复制到其他关键帧可以通过右键菜单完成。

  • 在同一属性上选择一个或多个关键帧。
  • 右键单击并选择 > Copy Easing。
  • 选择一些不同的关键帧。
  • 粘贴（Cmd/Ctrl + V）

当选择不匹配时——例如复制 3 个关键帧并粘贴到 2 个关键帧上——Cavalry 会将 Keyframe1 复制到 Keyframe1、Keyframe2 复制到 Keyframe2，并忽略 Keyframe3。

关键条

关键条是连接关键帧对的线，可用于移动整条动画曲线，而无需选择一系列关键帧。

当关键条位于两个值不同的关键帧之间时，显示为实线。如果关键条连接的两个关键帧值相同，则显示为虚线。这样设计有助于识别图层保持静止或未发生变化的区域。

移动关键条

要移动整条关键条，只需单击并拖动它。

选择

在 Time Editor 中框选时，适用以下选择逻辑。

  • 如果选择区域内存在关键帧，则只选择关键帧。
  • 如果选择区域内没有关键帧，则选择关键条。

框选时按住 Option/Alt 可过滤掉所有关键帧和关键条，确保只选择片段。

工具

关键帧图层

Keyframe Layer：参见关键帧图层。

对齐

将选中的关键帧彼此对齐。其工作方式与对齐图形相同。可以想象为每个属性上每组选中的关键帧都围绕一个矩形边界，然后将这些矩形彼此对齐。

  • Left：将关键帧对齐到最靠近时间轴起点（左侧）的关键帧。
  • Centre：居中对齐关键帧。
  • Right：将关键帧对齐到最靠近时间轴终点（右侧）的关键帧。

变换工具

变换工具可用于移动和缩放选中的关键帧。启用该工具后，所选关键帧周围会出现绿色区域。单击并拖动绿色区域中部可移动所选内容，单击并拖动绿色区域任一端可缩放关键帧。

吸附设置

将关键帧和片段端点吸附到其他关键帧、片段和时间标记。

选项：

  • Enable Snapping：启用/禁用吸附。
  • Snapping Threshold：设置发生吸附的距离（以屏幕像素为单位）。
  • Keyframes：启用/禁用吸附到关键帧。
  • Clips：启用/禁用吸附到片段端点。
  • Time Markers：启用/禁用吸附到时间标记。

将播放头移动到关键帧：

使用 Option/Alt + Cmd/Ctrl + ⬅︎/⮕ 方向键热键，可将播放头定位到下一个关键帧。关键帧也可以通过选择图层、属性或关键帧选择来过滤。例如，如果选中了 position.x 属性，其他属性上的关键帧将被忽略。

节奏标记

在 Time Editor 中添加参考线，以标示秒或音频节拍。切换按钮可启用/禁用它们，或使用箭头打开包含以下选项的展开窗口：

Mode：选择一种模式：

  • Seconds：在每一秒添加节奏标记。
  • Beats per Minute：基于 BPM 添加节奏标记。

Divisions：当 Mode 设为 Seconds 时，确定在每秒之间添加多少个子步。

Beats per Minute：当 Mode 设为 Beats per Minute 时，为音轨设置 BPM。灰色参考线代表节拍，蓝色参考线标示小节。

Offset：当 Mode 设为 Beats per Minute 时，在时间上向前或向后移动标记。

Beats per Bar：当 Mode 设为 Beats per Minute 时，设置每个小节的节拍数。

缩放

拖动滑块可放大/缩小窗口，或单击滑块两端的放大镜图标。也可以使用以下键盘快捷键：

快捷键 命令 鼠标 触控板 数位板
Option/Alt + 滚动 缩放。 ✓ ✓
Shift + 滚动 左右平移。 ✓ ✓
双指捏合 缩放。 ✓
Option/Alt + 双击 + 拖动 缩放。 ✓
F 将缩放设置为适合播放范围 ✓ ✓ ✓
Shift + F 将缩放设置为适合帧范围 ✓ ✓ ✓

魔法缓动

在关键帧之间应用数学插值。

  1. 选择一个或多个关键帧。
  2. 右键单击 > Magic Easing。
  3. 选择一个选项。

通过从选项中选择 Edit Custom Expression...，可以为魔法缓动添加自定义表达式。一些示例：

1 - pow(1 - x, 5)
x * x * x * x * x
-(cos(PI * x) - 1) / 2
var c1 := 1.70158;


var c2 := c1 * 1.525;





x < 0.5


  ? (pow(2 * x, 2) * ((c2 + 1) * 2 * x - c2)) / 2


  : (pow(2 * x - 2, 2) * ((c2 + 1) * (x * 2 - 2) + c2) + 2) / 2;

提示：

你可以使用动画菜单中的 Bake Keyframe Animation 命令，将动画烘焙为关键帧。

信息：

注意：Cavalry 遵循即将发布的 Web Animation 缓动标准，这对 After Effects 用户来说可能不太熟悉。这不是官方页面，但可以在此处看到一些不错的示例。W3C 候选推荐标准可在此处查看。
