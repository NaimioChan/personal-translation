摄像机引导

简介

Camera Guide 表示摄像机的“取景框”，可用于驱动其动画。它们可绘制（在视口中可见）但不可渲染，因此不会出现在任何输出中。

当摄像机的 Type 设为 Guide 时，最顶层的可见 Camera Guide 将用于控制摄像机视图中的可见内容。

可以将多个 Camera Guide 添加到摄像机，并在时间编辑器中排序，以创建“多机位”剪辑。

信息：

注意，向摄像机添加 Camera Guide 时，摄像机会被禁用。这是为了防止出现循环嵌套：摄像机正透过驱动其变换的 Camera Guide 观看。设置好 Camera Guide 后，可以重新启用摄像机以查看生成的动画。

界面

Position：设置 Camera Guide 的位置。0,0 位于合成的中心。

Rotation：设置 Camera Guide 的旋转（以度为单位）。

Scale：设置 Camera Guide 的缩放。

Skew：沿 X 或 Y 轴倾斜或错切 Camera Guide。

Pivot：为 Camera Guide 定义轴心点。在为旋转和缩放制作动画时很有用。

Opacity：设置 Camera Guide 的不透明度。

Custom Color：默认情况下，Camera Guide 会使用其标签颜色，但勾选后可以通过 Color 属性指定 Camera Guide 的颜色。

Color：为 Camera Guide 设置自定义颜色。

示例：

  1. 创建一个矩形。
  2. 在场景树中为矩形启用 2.5D。
  3. 创建一个摄像机。
  4. 将 Type 设为 Guide。
  5. 使用 Input Guides 属性上的 + 按钮添加并连接一个新的 Camera Guide。
  6. 为 Camera Guide 的 Position/Rotation 等添加一些动画。
  7. 在场景树中重新启用摄像机。
  8. 点击播放。

播放：

Camera Guide 与 Null 或 Falloff 一样属于“可绘制对象”。在视口设置中将 Show Drawables 设为 Always，即可在播放时看到它们。
