可见性碰撞事件

简介

在 Forge Dynamics 模拟中，当图形发生碰撞时影响其可见性或不透明度。

界面

Mode：

  • Visibility：碰撞时隐藏图形。注意，这不会使图形退出碰撞。
  • Opacity：设置图形碰撞时的不透明度。

Visibility：如果物体的可见性初始为关闭状态，勾选此属性将在其首次碰撞后将物体的可见性设为开启。

Opacity：设置图形碰撞时应用的不透明度。

Specific Collisions：勾选后，使用 Collision Numbers 属性定义使用哪些碰撞。

Collision Numbers：输入一个值以指定用于触发事件的碰撞。0 表示第一次碰撞，使用逗号分隔的值可包含多个碰撞。例如，输入 0,2 将包含第一次和第三次碰撞。

Fade Changes：勾选后，图形将恢复到其原始设置。

Fade Time：定义图形恢复到原始设置所需的时间（秒）。

Use Collision Index：勾选后，每次碰撞都会使其索引加 1。例如，这可以与连接到 Opacity 的 Value Array 配合使用：图形每次碰撞时，其不透明度将变为数组中的下一个值。
