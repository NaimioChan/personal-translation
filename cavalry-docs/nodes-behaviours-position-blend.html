位置混合

简介

在两个位置之间混合（lerp）。

界面

通用属性 +

First (origin)：输入图形原点的位置 [x,y]。

Second：输入图形目标位置 [x,y]（例如当衰减覆盖其原点时，图形将移动到的位置）。

示例：

  1. 创建一个图形。
  2. 创建一个 Position Blend。
  3. 连接 positionBlend.id→shape.position
  4. 将 Second 设为 50, 50。
  5. 右键点击 Falloff 属性并选择 Add Falloff。
  6. 移动该衰减。

当衰减经过 First 中设置的位置时，图形会朝 Second 中设置的位置移动。
