半调滤镜

简介

半调是一种复制技术，通过大小不断变化的网点来模拟连续色调的图像，从而产生类似渐变的效果。

界面

Settings

通用属性 +

Pattern：设置半调的样式：

  • Classic：简单的网点。
  • Ink：会互相“渗开”的网点。
  • Strokes：宽度递增/递减的线条。
  • Quads：方形/菱形。

Size：增大/减小图案的尺寸。

Offset：为滤镜的位置增加/减去一个值。

Rotation：旋转该效果。

Sample Mode：决定如何采样颜色值。

  • Luma (Gamma Corrected)：输出经伽马校正的 RGB 值的加权和。
  • Brightness：输出 RGB 值的平均值。

Red Multiplier：增大/减小图案红色通道中的值（当 Use CMYK 未勾选时）。

Green Multiplier：增大/减小图案绿色通道中的值（当 Use CMYK 未勾选时）。

Blue Multiplier：增大/减小图案蓝色通道中的值（当 Use CMYK 未勾选时）。

Contrast：增大/减小对比度，以影响图案尺寸在图形上变化的渐变程度。

Threshold：增大/减小用于确定图案尺寸的阈值。值为 1（默认值）时，网点会在白色区域填满整个圆形，而在黑色区域则填充背景。

Softness：设置图案边缘的柔和程度。

Use CMYK：勾选后，使用青色、品红、黄色和黑色网点来表现图像中的颜色。这只是对 CMYK 颜色的一种表现，而非真正的色彩空间转换。

CMYK：

CMYK 即青色、品红、黄色和黑色（Key），是印刷中使用的颜色，印刷时利用纸张的白色来表现较亮的区域。因此，较亮的图像部分会使用较小的网点来表现，这与 RGB 模式下（当 Use CMYK 未勾选时）计算半调的方式相反。

Black Gamma：

Colors

Foreground Color：在 RGB 模式下（当 Use CMYK 未勾选时），为圆形选择颜色。

Background Color：选择背景颜色。

Cyan：设置用于青色通道的颜色。

Cyan Transform：偏移青色图案的位置和旋转。

Magenta：设置用于品红通道的颜色。

Magenta Transform：偏移品红图案的位置和旋转。

Yellow：设置用于黄色通道的颜色。

Yellow Transform：偏移黄色图案的位置和旋转。

Black：设置用于黑色（Key）通道的颜色。

Black Transform：偏移黑色（Key）图案的位置和旋转。

旧版场景：

在 Cavalry 1.5 之前的版本中创建、使用了 Halftone Filter 的场景，打开时会使用该滤镜的旧版。建议尽可能将该滤镜替换为新版本。请注意，两者并非 100% 完全一致，因此可能无法完美匹配。
