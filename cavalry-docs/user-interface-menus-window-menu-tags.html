标签窗口

实验性功能：

这是一项实验性功能。要启用，请在首选项中勾选 Enable Experimental Features。

简介

标签可以分配给图层，以便快速进行选择，或筛选场景窗口和/或视口。标签也可以嵌套，以获得更强的控制力和清晰度。

界面

Mode：选择标签后的结果。

  • Select：选择所有分配了所选标签的图层。
  • Filter Scene Window：在场景窗口中仅显示分配了所选标签的图层。
  • Filter Viewport：在视口中仅显示分配了所选标签的图层。
  • Filter Both：在场景窗口和视口中均仅显示分配了所选标签的图层。

Clear Tag Selection（按钮）：取消选择所有已选标签。

Add Tag（按钮）：添加新标签。

窗口

标签窗口包含 3 种标签：

  • Quicklist：快速列表可以看作是一个临时标签。其状态不会随场景保存。
  • System Tags：根据 Label Color 和 Type 自动分配的标签。
  • User Tags：用户创建的自定义标签。

管理标签

添加/移除标签

可通过以下任一方式添加标签：

  • 点击标签窗口顶部的 + 按钮，然后输入标签名称并按 Return/Enter。
  • 在场景窗口中按 Cmd/Ctrl + Shift + T 调出 Add Tag 窗口。输入标签名称并按 Return。如果勾选了 Assign Tag to Selection，任何选中的图层也会被分配该新标签。

信息：

Assign Tag to Selection 的一个快捷方式是在按 Return/Enter 时按住 Option/Alt。无论复选框是否勾选，这都会将该标签分配给任何选中的图层。

可通过以下任一方式移除标签：

  • 选择标签并按 Delete 键。
  • 右键点击标签，从上下文菜单中选择 Delete Tag。

删除标签也会将其从所有图层上取消分配。

分配/取消分配标签

可通过以下任一方式分配标签：

  • 从场景窗口中把一个或多个图层拖放到标签上。
  • 在添加标签时勾选 Assign Tag to Selection 选项。
  • 点击场景窗口中的 tag/label 图标，然后输入标签名称并按 Return/Enter。

可通过以下任一方式取消分配标签：

  • 在场景窗口中右键点击某个图层，从上下文菜单中选择 Remove Tag。
  • 在标签窗口中右键点击某个标签，然后选择 Clear Tag。注意：这会从所有图层上移除该标签。

激活标签

只需在标签窗口中选择一个标签即可激活它。你可以使用 Cmd/Ctrl 或 Shift 来选择或取消选择多个标签。

信息：

在把图层拖到标签上以分配时按住 Option/Alt，松开鼠标后该标签也会被激活。

重命名标签

要重命名标签，只需选中一个标签并按 Return/ Enter。

快速列表

快速列表可以看作是一个临时标签。它可用于快速独奏一组图层。其内容仅在当前会话中保存，不会随场景保存。

通过右键点击标签窗口中的任意位置，并在上下文菜单中选择 Convert Quicklist to Tag 选项，可以将快速列表转换为标签。

嵌套标签

标签之间的关系可以在创建时通过嵌套来建立。为此，在标签之间输入 /（正斜杠）。例如 Character/Body 会创建两个标签 Character 和 Body，其中 Body 是 Character 的子级。选择 Character 会选中所有同时分配了 Character and Body 标签的图层，而选择 Body 则只会选中分配了 Body 的图层。

提示：

在设置 Character 时，可以创建如下的层级结构：

  • Character
    • Head
      • Hair
      • Ears
      • Eyes
      • Nose
      • Mouth
    • Body
      • Arms
        • Hands
      • Legs
        • Feet

选择 Head 便会显示整个头部，包括头发、耳朵、眼睛、鼻子和嘴巴。可按需尽可能细分。

如果标签已存在，可以通过输入 <yourExistingTag>/<yourNewTag> 为其添加子级。
