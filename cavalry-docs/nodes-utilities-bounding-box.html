边界框

简介

Bounding Box 工具可用于提取一个或多个图形的边界框。除其他用途外，它还可以为文本创建动态背景。

界面

Input Shapes：连接一个或多个图形，以采样其边界框。

Expand：增大/减小所得边界框的大小 [x,y]。

Position：输出 Input Shapes 中心的位置。

Size：输出 Input Shapes 的 [width, height]。

Sample at Frame：勾选后，边界框将在特定时间点计算。这可以与动画的 Input Shapes 配合使用，以便在其动画之前、期间或之后的任意时刻输出边界框计算结果。

Sample Frame：勾选 Sample at Frame 后，设置计算 Input Shapes 边界框所依据的帧。

Create and Connect Rectangle（按钮）：创建一个矩形，并将边界框连接到其 Position 和 Size 属性。注意，如果没有连接 Input Shapes，这会创建一个宽度和高度为零的矩形。

示例：

  1. 创建一个基本图形（矩形）。
  2. 创建一个文本图形和一个 Bounding Box。
  3. 连接 textShape.id→boundingBox.inputShapes
  4. 连接 boundingBox.position→basicShape.position
  5. 连接 boundingBox.size→basicShape.size

文本后方将出现一个矩形，当文本发生任何变化时该矩形会随之更新。

注意：确保矩形在场景窗口中位于文本后方，并且文本和矩形设置为不同的颜色。
