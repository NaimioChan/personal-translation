第六部分：仿真与数值算法

现实世界的计算问题有各种各样的需求。有些计算天然是串行的，例如文字处理这类日常办公任务；另一些则展现出大量数据并行性，例如计算机图形、物理仿真与图像处理。大多数应用需要串行与数据并行计算的混合，现代计算机系统正朝着支持这些需求的方向演进。GPU 的广泛可得与相对低廉的价格，使其特别适合承担现代计算中的数据并行需求。本书这一部分聚焦于若干在 GPU 上表现良好的数据并行计算示例。

生物信息学以及计算生物学与化学是科学计算中快速增长的领域。第 43 章「用于蛋白质结构预测的 GPU 计算」由 Armstrong Atlantic State University 的 Paulius Micikevicius 撰写，给出了蛋白质结构研究中一个简单却重要问题的 GPU 实现。该算法高度数据并行，基于著名的 Floyd-Warshall 全对最短路径算法。

线性方程组在许多类型的问题中都很常见。第 44 章「求解线性方程组的 GPU 框架」由 Technische Universität München 的 Jens Krüger 与 Rüdiger Westermann 撰写，展示了如何在 GPU 上高效表示各种矩阵与向量类型。他们的框架提供基本操作，可用于构建更复杂的线性方程组求解器。作为一个例子，他们用该框架构建了用于二维波动方程仿真的共轭梯度求解器。

并行计算中另一个增长的领域是计算金融。投资公司目前使用大型处理器集群处理海量数据，用于股票期权与信用衍生品的定价等目的。在第 45 章「GPU 上的期权定价」中，Craig Kolb 与 Matt Pharr（均属 NVIDIA）描述了两种广泛使用的期权定价算法的高效 GPU 实现。

排序是计算机科学中的基础算法。GPU 排序的实现很重要，因为当用 GPU 承担计算系统的其他部分时，即便 CPU 的排序快于基于 GPU 的排序，把数据留在 GPU 上、避免来回传输到 CPU 也更高效。在第 46 章「改进的 GPU 排序」中，Peter Kipfer 与 Rüdiger Westermann（均属 Technische Universität München）改进了 GPU 排序的现有技术水平，展示了如何尽可能调动更多 GPU 资源来解决该问题。其成果是许多应用所需的有用且关键的组件。

流体流动仿真在许多行业中都很重要，从汽车与航空航天工程到医学。过去几年，GPU 流体仿真一直是热门话题，因为基于物理的仿真天然是数据并行问题，很适合 GPU 架构。第 47 章「复杂边界下的流动仿真」由 Siemens Corporate Research 的 Wei Li 与 Stony Brook University 的 Zhe Fan、Xiaoming Wei 和 Arie Kaufman 撰写，描述了用 Lattice-Boltzman 技术在 GPU 上做流体仿真，该技术对流体「包」在晶格单元之间的传递建模。他们还描述了一种模拟绕任意动态障碍物流动的新技术。

电子成像彻底改变了医生诊断与治疗病人的方式。医学图像处理是一个不断发展的领域，涉及大量并行计算。医学成像（以及任何其他类型的信号处理）中使用的一项关键算法工具是快速傅里叶变换（FFT）。第 48 章「用 FFT 做医学图像重建」由 Siemens Medical Solutions USA 的 Thilaka Sumanaweera 与 Donald Liu 撰写，给出了 FFT 在 GPU 上的高效实现，其中包括若干有见地的优化。Sumanaweera 与 Liu 还描述了如何用 FFT 在 GPU 上重建 MRI 与超声图像。

本书这一部分表明，GPU 是求解各种数据并行问题的强大计算平台。这里收录的章节只是样本：许多其他类型的计算也已在 GPU 上实现，我期待将来能看到种类更丰富、性能更好的实现。要跟进这个激动人心领域的最新进展，请访问 www.GPGPU.org。
