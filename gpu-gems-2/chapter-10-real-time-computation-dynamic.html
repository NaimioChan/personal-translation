第 10 章　动态辐照度环境贴图的实时计算

Gary King
NVIDIA Corporation

环境贴图是一种流行的基于图像的渲染技术，用来表示空间不变的[1]球面函数。本章介绍一种完全由 GPU 加速的方法，用 DirectX Pixel Shader 3.0 和浮点纹理生成一类在图形上特别有意思的环境贴图——辐照度环境贴图。该技术让应用能快速近似动态环境中复杂的全局光照效果（例如动态光源与动态物体产生的辐射度）。为简明起见，本章假定读者熟悉环境贴图，尤其是立方体贴图（Voorhies 与 Foran 1994）和双抛物面贴图（Heidrich 与 Seidel 1998）。

10.1 辐照度环境贴图

设想一个含 k 个平行光的场景，方向为 d 1..dk，强度为 i 1..ik,，照亮一个法线为 n、颜色为 c 的漫反射表面。按标准的 OpenGL 与 DirectX 光照公式，所得像素强度 B 计算如下：

公式 10-1　漫反射

在此语境下，含 k 个纹素的环境贴图可以看作存储 k 个平行光强度的一种简单方式，光线方向由纹素位置隐含给出。这为存储任意复杂的光照环境提供了高效机制；不过计算 B 的代价随环境贴图纹素数量成正比增长。我们想要的是一种能预计算漫反射的机制，使逐像素渲染代价与光源/纹素数量无关。

看公式 10-1，我们注意到几点：第一，所有法线方向为 n 的表面都会得到相同的求和值。第二，求和只依赖场景中的光源与表面法线。这意味着我们可以离线地、每张环境贴图只做一次，算出任意法线 n 的求和值，并把结果存进第二张环境贴图，以表面法线索引。这第二张环境贴图称为漫反射辐照度环境贴图（或简称漫反射环境贴图），它让我们只需一次纹理查找，就能用任意复杂的光照环境照亮物体。（这也包括由照片生成的自然光照环境，由 Miller 与 Hoffman [1984] 首创，经 Paul Debevec [1998] 推广，并在图 10-1 中演示。）生成漫反射环境贴图的简单伪代码[2]见代码清单 10-1。图 10-2b 给出了一个漫反射环境贴图的示例。

示例 10-1　漫反射卷积伪代码

diffuseConvolution(outputEnvironmentMap, inputEnvironmentMap)
{
  for_all{T0 : outputEnvironmentMap} sum = 0 N = envMap_direction(T0)
  for_all{T1 : inputEnvironmentMap} L = envMap_direction(T1) I =
      inputEnvironmentMap[T1] sum += max(0, dot(L, N)) *I T0 =
          sum return outputEnvironmentMap
}

这一概念可以简单地扩展，以处理常见的对称镜面反射函数，例如 Phong 反射模型。我们不去建以表面法线索引的辐照度环境贴图，而是建一张以视线反射向量 R 索引的；并且对每个输入纹素不去计算 max(0, dot(L, N))，而是计算 pow(max(0, dot(R, L)), s)。这类贴图称为镜面反射辐照度环境贴图。

10.2 球谐卷积

虽然用辐照度环境贴图渲染极其高效（漫反射只需一次查找，漫反射加镜面反射两次），但按代码清单 10-1 的算法生成它们并不高效。对 M 个输入纹素和 N 个输出纹素，生成一张辐照度贴图是 O(MN) 的运算。更具体地说，若想从边长 64 纹素的输入立方体贴图，生成边长仅 32 纹素的漫反射立方体贴图，代价是 32x32x6x64x64x6 ≈ 1.51 亿次运算。即使 CPU 速度接近 4 GHz，用这种暴力算法也无法实时生成辐照度环境贴图。

在 SIGGRAPH 2001 上提出了一种技术，把计算辐照度环境贴图的代价从 O(MN) 降到 O(MK)，其中 N>>K（Ramamoorthi 与 Hanrahan 2001b）。关键的洞见是：漫反射辐照度贴图随表面法线的变化极其缓慢，因此可以利用环境贴图的频域表示来更高效地生成和存储。要把球面函数（例如环境贴图）转换为其频域表示，我们使用实球谐变换[3]：

对球谐函数的详细讨论超出本章范围，但参考文献一节列出了若干深入讲解球谐函数（及其其他应用）的优秀文章。要用球谐函数计算辐照度贴图，我们只需知道几条基本性质：

  • 任一频带 l 有 2l + 1 个系数 m，取值从 - l..l。因此 l 阶投影共有 (l + 1)2 个系数。
  • 基函数是线性且正交归一的。
  • 在空域中卷积两个函数，等价于在频域中把它们相乘。

最后这条性质（信号处理中称为卷积定理）极其有力，也正是我们能借助球谐函数高效生成辐照度贴图的原因：给定要卷积的两个函数（例如兰伯特 BRDF 与采样得到的光照环境），我们可以把每个函数分别投影为 l 阶球谐表示，再把所得的 (l + 1)2 个系数相乘并求和，从而算出卷积结果。这比暴力卷积更高效，因为对漫反射光照（以及低指数的镜面反射）， 系数（公式 10-3）随 l 增大迅速趋近 0，所以用很少几项就能得到对真实漫反射卷积非常精确的近似。事实上，Ramamoorthi 与 Hanrahan（2001a）证明，漫反射光照只需 l = 2（9 个系数），镜面反射光照 l = 就足够（其中 s 是 Phong 指数）。这使示例卷积的运行时复杂度降到每个函数仅 9 x 64 x 64 x 6 ≈ 22.1 万次运算（合计 44.2 万次，其中一次用于光照环境，一次用于反射函数），而暴力技术需要 1.51 亿次运算。

我们还可以进一步改善球谐卷积的性能，办法是注意到反射函数对每个函数（兰伯特、Phong 等）而言系数是常量。因此每个函数的系数可以预先算一次（在预处理步骤中），供所有卷积复用。这一优化把示例卷积的运行时复杂度降到仅 22.1 万次运算。

剩下的唯一细节是：我们的漫反射环境贴图现在以球谐表示存储。要把它转换回空域表示，[5] 我们用逆球谐变换生成一张新的环境贴图（波浪号表示重建出的函数是个近似）：

公式 10-4　逆球谐变换

应用这个公式很直接：对输出环境贴图中的每个纹素，把球谐基函数乘以系数即可。这是 O(KN) 的过程，因此生成辐照度环境贴图的总运行时复杂度为 O(KN + KM)。

10.3 映射到 GPU

有了 Pixel Shader 3.0 和浮点纹理（GeForce 6 系列 GPU 支持的特性），把球谐卷积映射到 GPU 就变成简单的两遍操作[6]：一遍把光照环境变换为球谐表示，另一遍把它与反射函数卷积并变换回空域。

10.3.1 从空域到频域

要把光照环境变换为球谐表示，需要写一个计算公式 10-3 的着色器。这个公式有一些可以利用的性质，使写着色器成为非常直接的过程：

  • 输出是 (l + 1)2 个三分量浮点数（红、绿、蓝各一）。
  • 输入是 N 个三分量浮点数、N 个标量 d 值，以及 N 个标量 值。
  • 对任意环境贴图 L 中的任意输入纹素 i， (i)d(i) 都是一个标量常量。

最后一点是关键：它意味着我们可以离线地为每个 (l, m) 对生成一张纹理。然后可以用 (l + 1)2 个渲染遍把它映射到 GPU 上，每遍遍历输入环境贴图中的全部 N 个纹素，各乘以相应查找表中的对应纹素，生成一个三分量球谐系数。把各查找表拼成瓦片，并把所有 (l + 1)2 个三分量系数作为输出纹理中不同的像素一次渲染出来，就能把遍数减到一遍。借助 Pixel Shader 3.0 的 VPOS 输入寄存器，我们可以轻松地把输出像素位置映射到查找表的某个瓦片，使每个输出像素都能把输入环境贴图投影到相应的球谐基函数上（并按 d 缩放）。这在代码清单 10-2 的 HLSL 伪代码中给出，并在图 10-3 中演示。

示例 10-2　球谐投影伪代码

float2 map_to_tile_and_offset(tile, offsetTexCoord){
    return (tile / numTiles) +
           (offsetTexCoord / (numTiles * numSamples))} float3
    SH_Projection(inputEnvironmentMap, dωYlm, currentLlm
                  : VPOS)
    : COLOR
{
  sum = 0 for_all{T0 : inputEnvironmentMap} T1 =
      map_to_tile_and_offset(currentLlm, T0) weighted_SHbasis =
          dωYlm[T1] radiance_Sample = inputEnvironmentMap[T0] sum +=
      radiance_Sample * weighted_SHbasis return sum
}

注意，为简单起见，你可能想为环境贴图的每个面各用一张查找表。随附的演示以双抛物面环境贴图作为输入，因此生成了两张权重查找表。

10.3.2 卷积与变换回来

如 10.2 节所述，频域中的卷积算子就是把 10.3.1 节生成的 系数与目标反射函数的一组预计算系数（为清楚起见，我们称之为 系数）相乘，然后对输出环境贴图中的每个纹素求公式 10-4 的值。这与我们对公式 10-3 所用的过程非常相似，也能利用瓦片化在单遍着色器中完成。由于 对任意给定的 (l, m) 对和纹素位置都是标量常量，我们可以预先算出 (l + 1)2 张存储这些值的环境贴图。若所需输出环境贴图是立方体贴图，我们可以改而预先算出六张权重纹理（立方体贴图每个面一张），在每个面内把 (l, m) 系数拼成瓦片，再通过依次把各面设为活动渲染目标、绑定相应权重纹理、执行像素着色器来生成最终的立方体贴图。

用于做卷积加逆变换的像素着色器与 10.3.1 节所用的非常相似；不过我们不再对 K 个输出值执行 N 元循环，而是对 M 个输出值执行 K 元循环。伪代码见代码清单 10-3。

示例 10-3　卷积与求值伪代码

float3 SH_Evaluation(Llm, AlmYlm, thetaPhi : VPOS) : COLOR
{
  sum = 0
  for_all{T0 : Llm} T1 = map_to_tile_and_offset(T0, thetaPhi) weighted_BRDF =
      AlmYlm[T1] light_environment = inputEnvironmentMap[T0] sum +=
      light_environment * weighted_BRDF return sum
}

如脚注 5 所述，Ramamoorthi 与 Hanrahan（2001b）展示了做漫反射卷积的另一种方法：由前九个 项构成一个 4 x 4 矩阵，用它来变换法线向量。当逐顶点光照已经足够时，这种做法可能比本章所述更高效；不过由于卷积后的立方体贴图分辨率通常远低于屏幕分辨率，在需要逐像素光照时，或在多边形数量高的场景中，本章所述的做法具有明显的性能优势。

10.4 后续工作

至此我们展示了如何用 GPU 加速一项传统上属于离线的过程。由于该操作在现代 GPU 上只需几毫秒，借助渲染到纹理的功能生成输入环境贴图，应用实际上可以为动态环境生成漫反射与镜面反射立方体贴图。随附的演示在 GeForce 6800 GT 上生成辐照度贴图超过 300 帧每秒。平坦的环境光照明可以换成随太阳划过天空而变化、或因小房间里扔进照明弹而变化的立方体贴图查找。

用辐照度环境贴图做场景光照的一个缺陷是：正确的阴影极其困难，甚至不可能。离线渲染器用来弥补这一点的一种技术是计算一个全局阴影项（称为环境光遮蔽），用它来衰减来自环境贴图的照明（Landis 2002）。对静态物体，环境光遮蔽值可以预先算好并存储；但对动态物体则不行。在本书第 14 章「动态环境光遮蔽与间接光照」中，Mike Bunnell 给出了一种高效近似环境光遮蔽值的方法，使同样的技术也能用于动态角色。

此外，球谐函数还有一些本章未探讨的宝贵性质。例如，两组球谐系数之间的分量线性插值，等价于空域表示的线性插值。两组系数的分量相加，等价于空域表示的相加。这两条性质（配合卷积定理）提供了一套强有力的基元，可用来近似众多复杂的全局光照效果。这一概念在 Nijasure 2003 中有详细描述。

10.5 结论

渲染动态、复杂的光照环境，是交互式应用在追求视觉真实感时必须迈出的重要一步。本章演示了离线渲染中用到的一种方法——辐照度贴图——如何能在现代 GPU 上高效实现。通过巧妙运用并扩展这里介绍的技术，实时应用不再需要在复杂的静态光照与简单的动态光照之间做选择；两者兼得。
