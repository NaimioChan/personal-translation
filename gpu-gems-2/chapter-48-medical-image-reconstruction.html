第 48 章　用 FFT 进行医学图像重建

Thilaka Sumanaweera
Siemens Medical Solutions USA

Donald Liu
Siemens Medical Solutions USA

在多种医学成像方式中，快速傅里叶变换（FFT）被用于从采集到的原始数据重建图像。本章介绍一种在 GPU 上实现 FFT、用于磁共振成像（MRI）和超声成像图像重建的方案。我们的实现自动在顶点处理器、光栅化器和片元处理器之间平衡负载；它还采用了若干其他新技术，以在 NVIDIA Quadro NV4x 系列 GPU 上获得高性能。

48.1 背景

此前已有在 GPU 上实现 FFT 的工作（Ansari 2003、Spitzer 2003、Moreland and Angel 2003）。而本章介绍的改进通过大量优化从 GPU 上获得更高性能。在计算机断层扫描（CT）、MRI 和超声扫描等医学成像设备中，从采集的原始数据重建图像使用专用硬件或 CPU。得益于庞大的消费级 PC 市场带来的经济效应，GPU 有可能以更低的成本在医学图像重建中提供比 CPU 更好的性能。

我们回顾傅里叶变换与经典的 Cooley-Tukey FFT 算法，并给出该算法在 GPU 上的一种实现。然后介绍我们为获得更高性能而采用的几种具体做法。我们还简要回顾 MRI 与超声成像的图像形成物理原理，并给出在基于 NVIDIA Quadro FX NV40 的 GPU 上用 FFT 重建电影 MRI 与超声样本图像所得的结果。

为简便起见，考虑一个八采样的离散数字信号：x(0), . . ., x(7)。图 48-1 给出了计算 DFT 的 FFT 算法（即所谓的按时间抽取蝶形算法）的流程图。

图的左侧，第 1 阶段中，输入采样先经过一个输入置乱阶段。若 n 是采样的索引，该采样被送到输入置乱器的第 k 个输出，其中

k = BIT_REVERSE(n)

例如，采样索引 3（即二进制 011）被送到输出索引（二进制 110），也就是 6。输入置乱器的每隔一个输出随后乘以 ，其值为 1，所有输出送入第 2 阶段。第 2 阶段的输入再被置乱、乘以权重并求和，产生第 2 阶段的输出。第 2 阶段的每个输出由两个输入线性组合而成。这一过程在第 3 阶段和第 4 阶段重复。输入信号的傅里叶变换在第 4 阶段的输出处得到。

更一般地，若有 N 个输入采样，就会有 log2 N + 1 个阶段，需要 N log2 N 次复数乘法与加法。上述算法也可用于做二维、三维和 N 维 FFT。例如考虑一幅图像，也就是一个二维数组。用公式 4，我们可以先对所有列做一维 FFT，再对所有行做一次一维 FFT，得到二维 FFT。

48.4 GPU 上的实现

FFT 可以实现为多趟算法。参考图 48-1 可以看到，每个阶段都可以实现为片元程序的一趟。还要注意，我们可以把第 1 阶段的输入置乱和第 2 阶段的置乱合并为一个阶段（因为 为 1），这是相对 Ansari 2003 和 Spitzer 2003 的一处改进。我们的实现使用了以下 OpenGL 扩展：

  • WGL_ARB_pbuffer：我们使用单个 pbuffer，配多个绘制缓冲，同时作为每个阶段的输入和输出。另一种做法是为每个阶段用一个 pbuffer 作输入、另一个作输出。我们选择前一种，因为它稍快一些：用两个 pbuffer 会涉及切换渲染上下文，如 Ansari 2003 那样。
  • WGL_ARB_render_texture：每个阶段的输出写入二维纹理，作为下一阶段的输入。
  • NV_float_buffer, NV_texture_rectangle：用于创建浮点 pbuffer，并在每个阶段输入输出 IEEE 32 位浮点数。FFT 运算的是复数。此外，在 MRI 和超声成像等应用中，使用 32 位浮点数以获得良好的数值稳定性很重要。由于内存带宽的限制，在基于 Quadro FX NV40 的 GPU 上，四次查找 32 位浮点标量比一次查找 32 位浮点四元向量更快。因此使用 GL_FLOAT_R32_NV 纹理内部格式比用 GL_FLOAT_RGBA32_NV 格式更有利。
  • ATI_texture_float：对某些不需要高精度的纹理查找（见后文讨论），可以用 GL_LUMINANCE_ALPHA_FLOAT16_ATI 纹理内部格式把两个 16 位浮点数打包进一个 32 位内存位置。
  • ATI_draw_buffers：许多现代 GPU 最多支持四个渲染目标。此外，在 Quadro FX NV4x 系列 GPU 上，使用立体模式可以创建一个带八个绘制缓冲的 pbuffer：GL_FRONT_LEFT, GL_BACK_LEFT、GL_FRONT_RIGHT、GL_BACK_RIGHT、GL_AUX0、GL_AUX1、GL_AUX2 和 GL_AUX3。利用这两点，我们可以把两个复数输出到四个渲染目标，从而并行计算两个 FFT，再把那四个渲染目标作为下一阶段的输入——无需像使用两个独立 pbuffer 时那样切换上下文。
  • ARB_fragment_program：权重 可以在片元程序内用一条 SCS 指令算出，如 48.4.2 节所述。

应用首先创建一个 GL_FLOAT_R32_NV 浮点立体 pbuffer。注意必须在控制面板中启用立体模式才能生效。该 pbuffer 带有八个 32 位标量绘制缓冲：

  • GL_FRONT_LEFT
  • GL_BACK_LEFT
  • GL_FRONT_RIGHT
  • GL_BACK_RIGHT
  • GL_AUX0
  • GL_AUX1
  • GL_AUX2
  • GL_AUX3

第一趟中，GL_FRONT_LEFT、GL_BACK_LEFT、GL_FRONT_RIGHT 和 GL_BACK_RIGHT 是源绘制缓冲，GL_AUX0、GL_AUX1、GL_AUX2 和 GL_AUX3 是目标绘制缓冲。GL_FRONT_LEFT 与 GL_AUX0 存放第一个 FFT 的实部，GL_BACK_LEFT 与 GL_AUX1 存放第一个 FFT 的虚部。GL_FRONT_RIGHT 与 GL_AUX2 存放第二个 FFT 的实部，GL_BACK_RIGHT 与 GL_AUX3 存放第二个 FFT 的虚部。在后续各趟中，源与目标绘制缓冲互换，过程继续。所有阶段完成后，目标绘制缓冲中留下的就是两个输入二维数据数组的 FFT。随后应用显示其中一个数据数组的 FFT 幅值。

我们采用两种做法：(1) 主要给片元处理器加载；(2) 给顶点处理器、光栅化器和片元处理器都加载。我们介绍两种做法的优点与局限，并讨论如何结合两者，在 Quadro NV40 GPU 上取得最佳性能。

48.4.1 做法 1：主要给片元处理器加载

这种做法中，对算法的每个阶段，应用绘制一系列平行于 pbuffer、覆盖整个二维数据数组的四边形。应用还创建一系列一维纹理，称为蝶形查找表，每个阶段用于置乱输入数据和查找 。置乱索引自然是整数。使用 pbuffer 时可能的最大索引是 2048，即基于 NV40 的 Quadro FX 上能创建的最大纹理尺寸。这意味着我们可以用 16 位精度存放这些索引。由于要查找两个索引，我们可以用 GL_LUMINANCE_ALPHA_FLOAT16_ATI 内部格式的纹理，把两个 16 位索引打包进一个 32 位内存位置。这样一次纹理查找就能同时得到两个置乱索引。至于权重 ，我们用两张独立的 GL_FLOAT_R32_NV 纹理分别存放其实部和虚部。

数据数组的每个采样都执行一次片元程序。这种做法中片元处理器是瓶颈。顶点处理器和光栅化器大部分时间闲着，因为每个阶段只绘制一个四边形。代码清单 48-1 给出了这种情况下的 Cg 片元程序。

示例 48-1. FFT 单阶段的 Cg 片元程序（做法 1）

void FragmentProgram(in float4 TexCoordRect
                     : TEXCOORD0, out float4 sColor0
                     : COLOR0, out float4 sColor1
                     : COLOR1, out float4 sColor2
                     : COLOR2, out float4 sColor3
                     : COLOR3, uniform samplerRECT Real1,
                       uniform samplerRECT Imag1, uniform samplerRECT Real2,
                       uniform samplerRECT Imag2,
                       uniform samplerRECT ButterflyLookupI,
                       uniform samplerRECT ButterflyLookupWR,
                       uniform samplerRECT ButterflyLookupWI)
{
  float4 i = texRECT(ButterflyLookupI, TexCoordRect.xy);
  // 读入置乱
  // 坐标
  float4 WR = texRECT(ButterflyLookupWR, TexCoordRect.xy);
  // 读入权重
  float4 WI = texRECT(ButterflyLookupWI, //
                      TexCoordRect.xy);
  float2 Res;
  float2 r1 = float2(i.x, TexCoordRect.y);
  float2 r2 = float2(i.w, TexCoordRect.y);
  float4 InputX1 = texRECT(Real1, r1);
  float4 InputY1 = texRECT(Imag1, r1);
  float4 InputX2 = texRECT(Real1, r2);
  float4 InputY2 = texRECT(Imag1, r2);
  Res.x = WR.x * InputX2.x - WI.x * InputY2.x;
  Res.y = WI.x * InputX2.x + WR.x * InputY2.x;
  sColor0.x = InputX1.x + Res.x;
  // 输出数据数组 1
  sColor1.x = InputY1.x + Res.y;
  //
  float4 InputX1_ = texRECT(Real2, r1);
  float4 InputY1_ = texRECT(Imag2, r1);
  float4 InputX2_ = texRECT(Real2, r2);
  float4 InputY2_ = texRECT(Imag2, r2);
  Res.x = WR.x * InputX2_.x - WI.x * InputY2_.x;
  Res.y = WI.x * InputX2_.x + WR.x * InputY2_.x;
  sColor2.x = InputX1_.x + Res.x;
  // 输出数据数组 2
  sColor3.x = InputY1_.x + Res.y;
  //
}

该程序的输入是数据采样的纹理坐标 TexCoordRect，输出是渲染目标 sColor0 到 sColor3。uniform 变量（Real1、Imag1）是第一个二维数据数组的实部与虚部，（Real2、Imag2）是第二个二维数据数组的实部与虚部。uniform 变量 ButterflyLookupI 存放置乱坐标。uniform 变量 ButterflyLookupWR 与 ButterflyLookupWI 存放权重的实部与虚部。

代码清单 48-1 的第 1 至 3 行读入用于置乱输入数据采样的坐标 i，以及用于组合两个输入的权重的实部与虚部（WR 与 WI）。变量 r1 与 r2 存放用于查找数据值的坐标 InputX1、InputY1、InputX2 和 InputY2。第 13、14 行计算第一个二维数据数组的输出值，第 21、22 行计算第二个二维数据数组的输出值。

如前所述，这种做法中顶点处理器和光栅化器大部分时间闲着。如果把更多计算负载移到顶点处理器和光栅化器上，某些情况下性能可能提高。第二种做法正是这么做的。

48.4.2 做法 2：给顶点处理器、光栅化器和片元处理器都加载

图 48-2 给出了图 48-1 的另一种表示。每个圆对应某一趟中的一个片元。方括号中给出片元程序使用的两个置乱索引。图中还给出了片元程序使用的权重 。对每个阶段，片元被分组聚成连续的块，图中用蓝色和绿色表示。可以看出，对每个块而言，置乱索引和权重的角度变量 2k/N 都是线性变化的。这意味着，与其绘制一个覆盖整个二维数据数组的大四边形，我们可以为每个块绘制一系列较小的四边形，让顶点处理器插值置乱索引和角度变量，从而把一部分负载从片元处理器移到顶点处理器和光栅化器上。代码清单 48-2 给出了做法 2 的 Cg 片元程序。

示例 48-2. FFT 单阶段的 Cg 片元程序（做法 2）

void FragmentProgram(in float4 TexCoordRect0
                     : TEXCOORD0, in float4 TexCoordRect1
                     : TEXCOORD1, out float4 sColor0
                     : COLOR0, out float4 sColor1
                     : COLOR1, out float4 sColor2
                     : COLOR2, out float4 sColor3
                     : COLOR3, uniform samplerRECT Real1,
                       uniform samplerRECT Imag1, uniform samplerRECT Real2,
                       uniform samplerRECT Imag2)
{
  float4 WR;
  float4 WI;
  float4 i0 = float4(TexCoordRect0.z, 0.0, 0.0, 0.0); // 置乱
  // 坐标
  float4 i1 = float4(TexCoordRect0.w, 0.0, 0.0, 0.0); //
  sincos(TexCoordRect1.x, WI.x, WR.x);
  // 计算
  // 权重
  float2 Res;
  float2 r1 = float2(i0.x, TexCoordRect.y);
  float2 r2 = float2(i1.x, TexCoordRect.y);
  float4 InputX1 = texRECT(Real1, r1);
  float4 InputY1 = texRECT(Imag1, r1);
  float4 InputX2 = texRECT(Real1, r2);
  float4 InputY2 = texRECT(Imag1, r2);
  Res.x = WR.x * InputX2.x - WI.x * InputY2.x;
  Res.y = WI.x * InputX2.x + WR.x * InputY2.x;
  sColor0.x = InputX1.x + Res.x;
  // 输出数据数组 1
  sColor1.x = InputY1.x + Res.y;
  //
  float4 InputX1_ = texRECT(Real2, r1);
  float4 InputY1_ = texRECT(Imag2, r1);
  float4 InputX2_ = texRECT(Real2, r2);
  float4 InputY2_ = texRECT(Imag2, r2);
  Res.x = WR.x * InputX2_.x - WI.x * InputY2_.x;
  Res.y = WI.x * InputX2_.x + WR.x * InputY2_.x;
  sColor2.x = InputX1_.x + Res.x;
  // 输出数据数组 2
  sColor3.x = InputY1_.x + Res.y;
  //
}

注意与代码清单 48-1 相比，这里不再有蝶形查找纹理的 uniform 变量。该程序的输入是数据采样的纹理坐标 TexCoordRect0 与 TexCoordRect1。TexCoordRect0.z 与 TexCoordRect0.w 的值存放置乱坐标，TexCoordRect1.x 的值存放角度变量，全部由光栅化器插值得到。还要注意程序体第 5 行中，权重 WR 与 WI 是通过调用 sincos 指令算出的。

48.4.3 负载均衡

还应注意，做法 2 到后期阶段时需要绘制的四边形数量只有寥寥几个，而早期阶段需要绘制的四边形数量相当多。例如第 1 阶段，每个片元都要绘制一个四边形。这意味着早期阶段顶点处理器和光栅化器可能成为瓶颈，导致性能比做法 1 还差。

不过，可以早期阶段用做法 1、后期阶段用做法 2，从而获得比单用做法 1 或做法 2 都更好的总体性能。随书软件通过尝试所有可能的切换点并挑选性能最好的那个，自动选择切换点。

48.5 医学成像中的 FFT

FFT 是医学成像中使用极多的数学工具。CT、MRI 和超声成像等多种医学成像方式，都依靠 FFT 从采集到的原始数据生成人体解剖结构的图像。这里我们更详细地看看 MRI 与超声成像。CT、MRI 与超声成像基础知识的出色深入综述，见 Bushberg et al. 2001。

48.5.1 磁共振成像

本节非常简要地回顾 MRI 图像形成的物理原理。更完整的 MRI 入门可参阅 Liang and Lauterbur 2000。人体内质子（即氢（1H）原子）的密度可以用 MRI 成像。人体主要由水构成，携带大量质子。质子的行为由量子力学原理支配。不过，我们可以借助经典力学的原理，更直观地解释用 MRI 形成图像的过程。

48.5.3 超声成像

传统超声成像在图像形成中并不使用 FFT，而是采用时域延迟求和的波束形成方法。波束形成是指向物体发射并接收超声脉冲以形成图像的过程。传统超声波束形成的入门介绍见 Wright 1997。本节介绍一种用 FFT 形成图像的新方法，称为脉冲平面波成像（PPI，Liu 2002），其优点是可达到比传统超声成像高一个数量级的帧率。

图 48-5a 显示一个超声换能器，其中含有由 N 个压电元件组成的阵列。每个压电元件都连接到一条含发射器的通道，能发射频率约 1 至 20 MHz 的超声脉冲，如图 48-5b 所示。换能器（带一层耦合剂）贴在人体上，用于对人体解剖结构成像。在传统波束形成中，超声束从换能器的一端扫到另一端射入体内，逐行采集图像，做法与雷达成像相同。

在 PPI 方法中，所有元件同时被脉冲激励，产生一个沿 z 轴取向的单一平面波前，照亮整个待扫描视野。脉冲发出后，压电元件立即切换到通道中的一组接收电路。阵列中每个元件接收到的信号送入接收放大器，再送入通道中的模数转换器。为简单起见，假设该阵列为连续函数。图 48-5c 显示信号 s(x, t)，它由 x ∊ [-A/2, + A/2] 范围内的所有元件在 t ∊ [0, T max] 期间记录得到。设某点的超声散射系数为 (x, z)。我们的目标是利用 s(x, t) 重建该散射系数。正如书中光盘上的附录所示，散射系数的二维傅里叶变换为：

48.6 结论

我们给出了二维 FFT 在基于 NV40 的 Quadro FX GPU 上的优化实现，以及它在 MRI 与超声成像图像重建中的应用。我们还提出了一种新的超声波束形成方法，更适合在 GPU 上实现。在我们测试的所有情形下，GPU 做二维 FFT 的性能都优于 2.5 GHz Pentium 4 CPU。在某些情形下，GPU 的性能接近 CPU 的两倍。

用 GPU 代替 CPU 做医学图像重建，除了性能上的优势，还有其他好处。在医学成像设备中，CPU 可能正忙于控制数据采集硬件这类时间关键的任务。此时用 GPU 做图像重建更为有利，可以让 CPU 专注做数据采集。此外，与 CPU 不同，GPU 不受操作系统中断的干扰，行为更可预测。未来几年 GPU 性能的提升速度预计会超过 CPU，这会使 GPU 作为医学图像重建首选处理器的吸引力进一步增强。
