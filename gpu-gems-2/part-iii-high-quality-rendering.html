第三部分：高质量渲染

每个交互式应用的作者都要面对一个必须平衡的尺度：交付高质量的图像，但要以交互速度交付。虽然摩尔定律和 GPU 架构师的聪明才智每一代设备都给图形程序员更多原始马力，人们也不断发明新技术，从今天手上的芯片里榨出最多东西。

「高质量」是个滑溜的词，它的定义可以年复一年地突变，去年的创新技术在下一代看来就已经平淡无奇。如果不被实时性约束，我们能用 GPU 的算力做出什么样的图像？马力从不过时——今天慢的算法终将成为明天快的算法。即使在今天的实时应用里，新的 GPU 已经能交付仅仅一两年前还无法企及的图像质量。

在第 20 章「快速三阶纹理滤波」中，苏黎世联邦理工学院的 Christian Sigg 与 VRVis 研究中心的 Markus Hadwiger 攻克了所有 GPU 加速成像的一个基本难题：图像滤波。他们利用 GPU 已有的线性滤波，为复杂滤波提供了一种以 GPU 为中心的高效解法。他们的方法还能给出有效的导数，应用不限于简单的二维滤波，可扩展到体绘制与隐式曲面重建。

NVIDIA 的 Dan Wexler 与 Eric Enderton——NVIDIA GPU 加速电影级渲染器 Gelato 的两位作者——同样面对二维图像滤波与三维成像。在第 21 章「高质量抗锯齿光栅化」中，他们描述了滤波大型分块图像的方法。他们在 Gelato 中所用的方法很适合在分成大量瓦片、且分辨率可能远高于单次 GPU 遍渲染能力的场合做高度复杂的渲染。

在第 22 章「快速预滤波线段」，Eric Chan 与 Frédo Durand（麻省理工学院）给出了一种加速方法，用来改善一个无处不在、许多用户不会留意的图形实体：简单线段。Chan 与 Durand 用 CPU 预滤波的卷积来画线，使得能在 GPU 中从查找表纹理平滑地画线，速度达到交互级。高质量画线对游戏、CAD 和医学成像都有用，不只用于二维绘图，也用于渲染电话线和电力线这类出了名难处理的细长三维物体。

细如发丝的图元在第 23 章「Nalu 演示中的毛发动画与渲染」中再次登场，作者是 NVIDIA 的 Hubert Nguyen 与 William Donnelly。他们描述了为「Nalu」做动画与 GPU 渲染所用的突破性方法；这个实时演示对光照与阴影技术的创新运用，足以挑战电影和电视中一些最好的非实时角色渲染的观感。

渲染三维图像并不是 GPU 在电影制作中的唯一应用。在第 24 章「用查找表加速颜色变换」，Jeremy Selan（Sony Pictures Imageworks）描述了如何用 GPU 实时对二维图像（来自三维渲染或实拍素材）做复杂的颜色处理，以用于合成和在各种输出介质上实时预览。

与此类似，Apple Computer 的 Pete Warden 在第 25 章「Apple Motion 中的 GPU 图像处理」中描述了一个面对许多相同挑战的程序，它在专业和业余视频用户的桌面上提供了强大的实时解法。Warden 在异构、富媒体环境中使用 GPU 的经验，或许有助于引领对整个计算机使用体验做图形密集型的重新思考。

NVIDIA 的 Simon Green 重新审视并扩展了 GPU Gems 中的一个主题，在第 26 章「实现改进的 Perlin 噪声」中揭示了他的方法。这个对 GPU 友好的算法在二维和三维成像中都有应用，质量也高于目前游戏程序员中流行的简单纹理噪声。

discreet 的 Justin Novosad 在第 27 章「高级高质量滤波」中对图像滤波又提出了另一种视角。他先给出图像重建一般问题的概览，然后补充了关于图像去模糊的创新想法，甚至包括如何减轻实拍的运动模糊。

最后，Climax Entertainment 的 Iain Cantlay 在第 28 章「mipmap 层级测量」中把高质量问题带给开明的游戏程序员，提供了帮助程序员管理图像质量、内存占用与渲染速度之间复杂平衡的想法与工具——不只是针对单张静态图像，也包括这些因素在活跃的游戏内环境中如何动态地起作用。

今天的受众——无论是游戏玩家、电影观众还是计算机用户——都要求越来越丰富、高质量的影像，这一趋势至少从 1800 年代中期起就在加速。对每个 GPU 程序员来说，跟上这些即将成为标准的方法都是有利的，以确保今天和明天在所有媒介上都能获得最好的体验。

Kevin Bjorke, NVIDIA
