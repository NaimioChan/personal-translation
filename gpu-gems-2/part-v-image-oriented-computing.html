第五部分：面向图像的计算

可编程的顶点着色器与片元着色器已被证明是 OpenGL 与 Direct3D 渲染管线的强大补充。除了在传统图形应用中的预期用途，这种可编程性还催生了全新的基于 GPU 的图像创建与分析算法类别。本书这一部分聚焦这类面向图像的 GPGPU 技术。

硬件辅助的纹理映射是现代图形管线的关键部分。GPU 上的纹理映射通常要求用纹理坐标对物体参数化，这对某些类型的模型可能很困难。八叉树纹理提供了纹理映射的常规好处，却不需要使用纹理坐标。在第 37 章「GPU 上的八叉树纹理」Sylvain Lefebvre、Samuel Hornus 以及 GRAVIR/IMAG–INRIA 的 Fabrice Neyret 撰写的这一章中，作者展示了如何在 GPU 上实现八叉树纹理，并在两个交互式应用中演示了它们的用法。

GPU 生成的图像通常只考虑光源的直接光照，忽略物体之间的漫反射与光泽反射。东京大学的 Toshiya Hachisuka 在第 38 章「用光栅化实现高质量全局光照渲染」中描述了如何利用 GPU 的高性能光栅化能力实现全局光照渲染系统。通过用光栅化一次向同一方向投射大量光线，可以高效地纳入各种非局部光照效果。

接下来，第 39 章「用渐进细化辐射度实现全局光照」由北卡罗来纳大学教堂山分校的 Greg Coombe 与 NVIDIA 的 Mark Harris 撰写，介绍了另一种基于 GPU 的全局光照渲染器。通过颠倒渐进细化辐射度中「发射者」与「接收者」的常规角色，他们得以用 GPU 高效地生成考虑大量场景元素之间漫反射互反射的图像。

计算机视觉常被称为计算机图形的逆过程：图形从模型生成图像，视觉则相反。多伦多大学的 James Fung 在第 40 章「GPU 上的计算机视觉」中把传统图形管线整个倒转过来。James 展示了如何利用一块或多块 GPU 构成低成本、高性能计算机视觉系统的骨干，以交互帧率运行复杂的视觉算法。

渲染格式不被图形硬件直接支持的数据图像，是 GPGPU 应用中的常见问题。在第 41 章「延迟过滤：从难以处理的数据格式渲染」中，犹他大学的 Joe Kniss、加州大学戴维斯分校的 Aaron Lefohn 和 Nathaniel Fout 演示了如何用两遍渲染方法驯服这些「难以处理」的数据格式，该方法利用了 GPU 原生的纹理能力。

在这一部分的最后一章，即第 42 章「保守光栅化」中，隆德大学的 Jon Hasselgren、Tomas Akenine-Möller 和 Lennart Ohlsson 为 GPGPU 工具箱做出了宝贵贡献。他们展示了应用如何控制何时以及如何为部分覆盖的像素生成片元，这在离散化域上运行 GPGPU 计算时极为有用。这一能力让应用可以对哪些像素被光栅化做出保守假设，从而使从碰撞检测到遮挡剔除的各类应用得到更准确的基于 GPU 的算法。

就其本质而言，随着能力不断演进，GPU 将继续在面向图像的计算上表现出色。这一部分介绍的技术广泛展示了今天能做到什么，也为明天的前沿应用提供了可用的基础。我相信你会发现它们和我一样有用、一样发人深省。

Craig Kolb, NVIDIA
