第 11 章　近似双向纹理函数

Jan Kautz
Massachusetts Institute of Technology

本章介绍一种便于采集与渲染逼真材质（如布、羊毛、皮革）的技术。这些材质用以往的技术很难渲染，那些技术大多依赖简单的纹理贴图。我们的目标是采集上少费力、渲染上少花算力，却仍能得到逼真的外观。

我们的方法基于 Kautz 等人（2004）的近期工作，源于一个观察：在某些情况下，材质只需很少几张图像即可采集，所得结果与完整的双向纹理函数（即 BTF，我们会在第一节给出完整定义）相当。用这个近似的 BTF 渲染，相当于求值一个简单的着色模型，再在三维纹理中做一次查找。用图形硬件很容易渲染，能达到实时帧率。对多种材质都取得了有说服力的结果。

11.1 引言

计算机图形学长期追求的目标之一是生成照片级的图像。为此，逼真的材质属性必不可少。捕捉材质细微的空间变化与介观结构尤其重要，因为它们传达了关于材质的大量信息。图 11-1 比较了只用一张漫反射纹理贴图渲染的一块布，与用我们的方法渲染的结果，后者保留了空间变化与自阴影。这一比较显示了材质介观结构有多重要，也说明对许多材质来说，简单的纹理映射甚至凹凸贴图都不足以逼真地渲染。

遗憾的是，采集这类材质属性相当繁琐费时（Dana 等 1999，Lensch 等 2001，Matusik 等 2002）。原因是材质属性由四维的双向反射分布函数（BRDF）确定，它依赖局部光照方向与观察方向；Phong 模型就是 BRDF 的一个例子。若要捕捉表面上的空间变化，这个函数（也就是前面提到的双向纹理函数 [Dana 等 1999]）就变成六维的。显然，采集这样一个高维函数需要取大量样本，导致采集时间（以及存储需求）很大，这也是 BTF 测量数据不易获得的原因。

采集这全部数据的好处是，BTF 能生成非常逼真的材质渲染，因为它不仅捕捉表面上每个点的局部反射属性，还捕捉所有非局部效应，例如材质内部的自阴影、遮蔽与相互反射，如图 11-1 所示。

我们不去采集完整 BTF 再用它渲染，而是说明只采集 BTF 的若干切片就够了。这使得采集装置简单（可以手工完成），渲染方法更简单，在几年前的老 GPU 上也能实时运行。美术也能轻松调整采集到的材质，例如通过调整几个参数让它更亮或更不亮。为此我们假设采集的材质块是各向同性的（即外观不依赖其朝向），且只含小尺度特征（即没有大尺度的自阴影与遮蔽效应）。后文会更详细地讨论为何需要这些前提。

11.2 采集

采集与预处理步骤非常简单，因此采集流程很快。

11.2.1 装置与采集

装置如图 11-2 上方所示。相机正交地对准要采集的材质。假设材质是平的，所以最好把材质块放在平坦表面上。然后用平行光源（远处的点光源也可以）在不同入射仰角上照射表面。光源只沿一条弧线移动，也就是说它不绕表面法线旋转。光源沿弧线移动时，材质会显现出细微的自阴影效果，这对许多材质来说非常有特征性。

光源仰角大致以 10 度为步长分隔；也就是说，每种材质采集十张图像。如 11.4 节所示，对实时渲染而言低动态范围图像就够用；不过也可以采集高动态范围图像。

在图 11-2 中可以看到几种不同光源角度下采集的图像。所有图像都是手工采集的，但即便如此，采集一种材质也只需几分钟，相比其他方法（Dana 等 1999，Matusik 等 2002，Sattler 等 2003）是很大的优势。

11.3 渲染

如前所述，用我们的数据渲染相当简单。先做高层次描述，再深入细节。

设想用普通光照模型（例如 Phong 模型）和点光源为一个片元着色。这种情况下，我们用当前视线与光照方向以及一组参数（漫反射度、镜面反射度等）对光照模型求值，算出反射光的量。这个值让我们大致知道该像素应当多亮。既然算出了亮度，就可以用我们的图像栈把它着色得更好。我们在图像栈中选出平均亮度与像素相同的图像，再从该图像中查找相应的纹素，用这个值替代。这样就引入了图像栈中捕捉到的自阴影等细节，使渲染逼真得多。

11.3.2 实时渲染

用图形硬件做实时渲染的算法很直接。我们把着色贴图作为三维（体积）纹理载入图形硬件。在顶点着色器中计算 r( o , i )（针对单个点光源）。顶点着色器的结果是一组纹理坐标 (s, t, r/a max)，随后用它到着色贴图中查找。片元着色器完成与光源强度的相乘。执行这一操作的顶点着色器与片元着色器见代码清单 11-1。

较新的图形硬件支持片元着色器中的依赖纹理查找。有了这一特性，就可以逐片元计算 BRDF（乘以余弦），再对着色贴图做依赖纹理查找，从而避免使用顶点着色器时可能出现的欠采样瑕疵。

示例 11-1　渲染所需的顶点着色器与像素着色器

这个例子中我们使用了增强的 Phong 着色模型。

// 顶点着色器
void btfv(float4 position
          : POSITION, float3 normal
          : NORMAL, float3 tex
          : TEXCOORD0, out float4 HPOS
          : POSITION, out float3 TEX
          : TEXCOORD0, out float4 COL0
          : TEXCOORD1, uniform float4x4 mvp, uniform float3 lightpos,
            uniform float3 eye, uniform float lightintensity, uniform float Ka,
            uniform float Kd, uniform float Ks, uniform float N)
{
  // 计算光照方向
  float3 L = lightpos - (float3)position;
  L = normalize(L);
  // 计算反射方向
  float3 R = (2.0f * dot(eye, normal) * normal - eye);
  // 光照（增强的、物理正确的 Phong 模型）
  const float pi = 3.14159265;
  float costh = dot(normal, L);
  float specular = pow(dot(R, L), N);
  float intensity = Kd / pi + Ks * (N + 2.0) * specular / (2.0 * pi);
  intensity *= costh; // * cos(th)
  // 检查边界
  if (diffuse < 0.0 || intensity < 0.0)
    intensity = 0.0;
  if (intensity > 1.0)
    intensity = 1.0;
  // 加上环境光
  intensity += Ka;
  // 设置用于在体积中查找的坐标
  TEX.z = intensity;
  // 根据光照，假设 a_max 为 1
  TEX.xy = tex.xy;
  // 从应用程序拷贝 2D 部分
  // 为片元着色器设置用于缩放的光源强度
  COL0.rgb = lightintensity;
  // 变换位置
  HPOS = mul(mvp, position);
}
// 片元着色器
float3 btfp(float3 tc
            : TEXCOORD0, float3 color
            : TEXCOORD1, uniform sampler3D material
            : TEXUNIT0)
    : COLOR
{
  float3 r = (float3)tex3D(material, tc).xyz; // 在体积中查找
  return r * color;
  // 按强度缩放
}

下面展示若干用采集材质完成的渲染。所有材质都用十个不同光源位置采集。图像先裁剪到 1024x1024，再降采样到 512x512。为兼容通常要求 2 的幂纹理尺寸的图形硬件，线性化时把这十张图像重采样为八张。每组图像的线性化约需 5 秒。所有渲染中我们都用了 Phong 模型。

在图 11-4 中可以看到用我们的实时实现做出的几种渲染。所示材质有牛仔裤（Stanford 兔子与裤子）、绒面革（Stanford 兔子）、皮革（猫）、压制木（头）、蜡（头）、尼龙（裤子）、布（一块布）和羊毛（一块针织布）。

图 11-5 是一张羊毛毛衣的渲染。左图用完整 BTF 完成（6,500 张图像，用主成分分析压缩到 16 个分量）。右图用我们的技术完成。差别主要体现在掠射角处，那里遮蔽效应变得重要，而我们的技术无法重现。这也造成轻微的颜色差异（不过部分颜色差异也来自压缩）。考虑到羊毛是违反我们初始假设的材质之一（它有大尺度结构且各向异性），我们的方法表现相当不错。

11.4.1 讨论

为什么只针对固定视角、采集几个入射照明方向的图像就够？如前所述，我们只采集材质表面结构引起的光照变化，为此我们的方法足够。实际的 BRDF 由美术提供。

我们认为这项技术效果这么好，是因为人眼预期材质会有某种变化。从结果看，这种变化被我们的技术捕捉到了，给出了对真实材质的良好印象。

一般来说，带小尺度变化的材质效果最好，例如所示的布、绒面革、牛仔裤等。具有空间变化反射属性（例如不同的镜面反射度等）的材质也能采集得不错，从图 11-4 中的蜡烛蜡和压制木可以看出。

不过对某些材质，这项技术效果较差。例如采集高镜面反射材质就有问题，主要因为我们用点光源近似平行光源。我们的方法假设材质具有细尺度结构。这是因为本技术只建模随入射角的变化，不建模随方位角的变化。因此较大结构产生的阴影无法很好地捕捉或表示，因为它们总是出现在同一方向。此外，材质被假设为各向同性。

即使对违反这些假设的材质，我们的技术仍可能适合做快速预览，因为它远好于常规纹理映射，如图 11-1 所示。

11.5 结论

我们提出了一种只需少量图像就能采集与渲染复杂空间变化材质的方法。这种经验方法并不捕捉真实 BRDF，只捕捉细表面结构引起的光照变化；BRDF 可以之后再调整。用该技术做实时渲染很容易实现。
