第 20 章　快速三阶纹理滤波

Christian Sigg
ETH Zurich

当前的可编程图形硬件使我们能在片元着色器中实现通用卷积滤波，以做高质量纹理滤波，例如三次滤波（Bjorke 2004）。然而这些做法通常伴随着几个缺点：需要做大量纹理查询，尤其还有无法用 mipmap 对查询做抗锯齿。本章针对一维、二维和三维中三次 B 样条核及其一阶、二阶导数的滤波来处理这些问题。

高阶滤波的主要性能瓶颈是需要大量输入纹理采样，这些采样通常通过对输入纹理反复做最近邻采样来获得。为减少输入采样数，我们基于线性纹理取数来做三次滤波，这大幅减少了纹理访问次数，在二维和三维滤波中尤其明显。具体来说，我们用仅仅八次三线性纹理取数就能求出一个有 64 个求和项的三变量三次滤波。

在片元着色器中做自定义滤波的做法依赖于知道输入纹理的分辨率，这通常使得无法正确滤波带 mipmap 的纹理。我们描述一种把高阶滤波方案适配到带 mipmap 纹理的通用做法。

除数值重建之外，往往还需要高质量的导数重建，例如在体绘制中。我们把基本滤波方法扩展到连续一阶与二阶导数的重建。这些滤波器的一个强大应用是用三变量三次 B 样条即时计算隐式曲面曲率，这种做法已被用于离线高质量体绘制，包括非真实感风格（Kindlmann 等 2003）。

20.1 高阶滤波

OpenGL 与 Direct3D 都提供两种纹理滤波：最近邻采样和线性滤波，分别对应零阶与一阶滤波方案。所有 GPU 都原生支持这两种。不过高阶滤波模式往往带来更好的图像质量。此外，要计算纹理数据的连续导数，也必须用高阶方案。

我们展示如何在当前可编程图形硬件上实现高效的三阶纹理滤波。下面的讨论主要考虑一维情形，但它可以直接推广到更高维度。

注意，三次 B 样条滤波是标准最近邻采样和线性滤波的自然扩展，后两者分别是零次与一次 B 样条滤波。滤波的阶数与滤波后数据的平滑程度直接相关。当我们想计算导数时，数据的平滑尤其重要。在体绘制中，着色需要用到导数，因此常见的做法是把预计算好的梯度与数据一起存储。这虽然给出了一阶导数的连续近似，却要多用四倍的纹理内存，而体绘制应用中的纹理内存常常是受限的。此外，由于存储开销巨大，这种做法对二阶导数变得不切实际。相比之下，即时做三次 B 样条滤波可以给出连续的一阶与二阶导数，而且没有任何存储开销。

示例 20-1. 一维纹理的三次 B 样条滤波

float4 bspline_1d_fp(float coord_source
                     : TEXCOORD0, uniform sampler1D tex_source,
                       // 源纹理
                       uniform sampler1D tex_hg,
                       // 滤波偏移与权重
                       uniform float e_x,
                       // 源纹素尺寸
                       uniform float size_source
                     // 源纹理尺寸
                     )
    : COLOR
{
  // 计算滤波纹理坐标，其中 [0,1] 对应单个纹素
  // （也可以改在顶点程序里做）
  float coord_hg = coord_source * size_source – 0.5f;
  // 从滤波纹理中取偏移与权重
  float3 hg_x = tex1D(tex_hg, coord_hg).xyz;
  // 确定线性采样坐标
  float coord_source1 = coord_source + hg_x.x * e_x;
  float coord_source0 = coord_source - hg_x.y * e_x;
  // 取两个线性插值后的输入
  float4 tex_source0 = tex1D(tex_source, coord_source0);
  float4 tex_source1 = tex1D(tex_source, coord_source1);
  // 对线性采样加权
  tex_source0 = lerp(tex_source0, tex_source1, tex_hg_x.z);
  return tex_source0;
}

如前所述，函数 gi (x) 与 hi (x) 存在一张查找纹理中（代码清单中名为 tex_hg），以减少片元程序中的运算量。实践中 128 个采样的 16 位纹理就足够了。注意这些函数在输入纹理的采样位置上是周期的。因此我们对纹理坐标施加一个线性变换，并对查找纹理使用 GL_REPEAT 的纹理环绕参数。为清楚起见，代码清单 20-1 把这个线性变换写进了片元程序。不过通常我们会用在顶点着色器中算出的单独纹理坐标。

从查找纹理取出偏移与权重之后，我们为从源颜色纹理做的两次线性纹理取数计算纹理坐标。注意我们需要用纹理分辨率的倒数来缩放偏移，这个倒数值存在一个常量寄存器着色器参数里。

程序的其余部分执行两次颜色取数，并计算它们的加权和。注意 B 样条满足单位分解 wi (x) = 1，两个权重同样满足 g 0(x) + g 1(x) = 1。因此这种情况下我们不必在 g 0(x) 之外再存一份 g 1(x)，最终加权仍是只用一条 lerp() 指令完成的凸组合。

对于具有 256 个纹素的一维源纹理，代码清单 20-1 的片元着色器参数应按如下方式初始化：

e_x = float(1 / 256.0f);
size_source = float(256.0f);

参数 e_x 对应单个源纹素在纹理坐标中的大小，它的作用是把从滤波纹理取到的偏移缩放到源纹理的分辨率。参数 size_source 只存储源纹理的大小，用来由源纹理坐标计算滤波纹理坐标，使整张滤波纹理对应源纹理的一个纹素。

现在把这个三次滤波方法扩展到更高维度，由于张量积 B 样条的可分离性，这一步很直接。实际上我们的优化在更高维度上效果更好。借助双线性或三线性纹理查找，我们可以把 4 项或 8 项求和合并成一次加权凸组合。因此，一个含 64 项的三维三次滤波只需八次三线性纹理取数就能求值。

示例 20-2. 双三次 B 样条滤波

float4 bspline_2d_fp(float2 coord_source
                     : TEXCOORD0, uniform sampler2D tex_source,
                       // 源纹理
                       uniform sampler1D tex_hg,
                       // 滤波偏移与权重
                       uniform float2 e_x,
                       // x 方向的纹素尺寸
                       uniform float2 e_y,
                       // y 方向的纹素尺寸
                       uniform float2 size_source
                     // 源纹理尺寸
                     )
    : COLOR
{
  // 计算滤波纹理坐标，其中 [0,1] 对应单个纹素
  // （也可以改在顶点程序里做）
  float2 coord_hg = coord_source * size_source - float2(0.5f, 0.5f);
  // 从滤波纹理中取偏移与权重
  float3 hg_x = tex1D(tex_hg, coord_hg.x).xyz;
  float3 hg_y = tex1D(tex_hg, coord_hg.y).xyz;
  // 确定线性采样坐标
  float2 coord_source10 = coord_source + hg_x.x * e_x;
  float2 coord_source00 = coord_source - hg_x.y * e_x;
  float2 coord_source11 = coord_source10 + hg_y.x * e_y;
  float2 coord_source01 = coord_source00 + hg_y.x * e_y;
  coord_source10 = coord_source10 - hg_y.y * e_y;
  coord_source00 = coord_source00 - hg_y.y * e_y;
  // 取四个线性插值后的输入
  float4 tex_source00 = tex2D(tex_source, coord_source00);
  float4 tex_source10 = tex2D(tex_source, coord_source10);
  float4 tex_source01 = tex2D(tex_source, coord_source01);
  float4 tex_source11 = tex2D(tex_source, coord_source11);
  // 沿 y 方向加权
  tex_source00 = lerp(tex_source00, tex_source01, hg_y.z);
  tex_source10 = lerp(tex_source10, tex_source11, hg_y.z);
  // 沿 x 方向加权
  tex_source00 = lerp(tex_source00, tex_source10, hg_x.z);
  return tex_src00;
}

对于具有 256 x 128 个纹素的二维源纹理，代码清单 20-2 的片元着色器参数应按如下方式初始化：

e_x = float2(1 / 256.0f, 0.0f);
e_y = float2(0.0f, 1 / 128.0f);
size_source = float2(256.0f, 128.0f);

源纹素大小以这种特定方式存放在 e_x 和 e_y 参数中，使我们能用最少的指令算出全部四个源样本的坐标，因为这样可以避免对四个样本都在 x 轴上施加偏移，如代码清单 20-2 所示。在三维情况下，同样的做法可以用 14 条乘加指令算出全部八个源坐标。

三维滤波是代码清单 20-2 的直接扩展。

20.3 mipmap

对于带 mipmap 的纹理，我们遇到的问题是：与输入纹理分辨率相对应的纹理坐标偏移与缩放操作，无法像代码清单 20-1 和 20-2 那样用片元着色器的 uniform 常量完成。纹理一旦带 mipmap，合适的纹理分辨率就随片元而变（GL_*_MIPMAP_NEAREST 滤波），甚至是在两个相邻纹理分辨率之间做线性插值（GL_*_MIPMAP_LINEAR 滤波）。

本章只详细讨论 GL_*_MIPMAP_NEAREST 滤波的情形。不过 GL_*_MIPMAP_LINEAR 滤波也能用稍加扩展的方法处理：对两个有贡献的 mipmap 层级都做双三次滤波，再在片元着色器里于两者之间线性插值。

对我们的滤波方法而言，需要知道给定片元实际使用的 mipmap 层级及相应纹理分辨率，才能得到正确的偏移（e_x, e_y, e_z）与缩放因子（size_source）。然而在当前架构上，片元着色器里无法查询 mipmap 层级。因此我们采用一个变通办法，把 mipmap 信息存进我们称为 meta-mipmap 的东西。meta-mipmap 是一张额外的 mipmap，它在每一层级的所有纹素中存储相同的信息，例如该层级的分辨率。类似的做法可用于在片元着色器中模拟导数指令（Pharr 2004）。

meta-mipmap 用一张浮点 RGB 纹理，如下所示：

// 给定 mipmap_level 的每个纹素对应的 RGB 元 mipmap 信息
metatexel = float3(1 / level_width, 1 / level_height, mipmap_level);

下面的代码片段说明，代码清单 20-1 和 20-2 中的 size_source 以及 e_x、e_y 缩放与偏移（那里它们是 uniform 参数）如何被替换为按片元正确适配硬件当前片元实际所用 mipmap 层级的版本：

// 取元 mipmap 信息
float3 meta = tex2D(tex_meta, coord_source).xyz;
// 由偏移算出缩放，这样就不必存储它们
float2 size_source = float2(1.0f / meta.x, 1.0f / meta.y);
// 滤波纹理坐标
// 其中 [0,1] 对应源纹理的单个纹素
// （已经无法在顶点程序中完成）
float2 coord_hg = coord_source * size_source - 0.5f;
// 调整邻近采样的偏移
e_x *= meta.x;
e_y *= meta.y;

现在 e_x 和 e_y 初始化为单位向量，而不再预先乘以纹理尺寸：

e_x = float2(1.0f, 0.0f);
e_y = float2(0.0f, 1.0f);

对 GL_*_MIPMAP_NEAREST 滤波，我们不需要 meta-mipmap 的第三个分量（meta.z），它存放 mipmap 层级本身。但要实现 GL_*_MIPMAP_LINEAR 滤波，还需要两个有贡献的 mipmap 层级之间的插值权重。这个权重可以由经硬件插值的 meta-mipmap 第三分量取 frac(meta.z) 得到。

使用 meta-mipmap 时一个重要考量是它的纹理内存占用，直接使用的话可能相当高。理论上，应用程序使用的每种纹理尺寸与宽高比都需要一张对应的 meta-mipmap，才能取得相应的 mipmap 信息。不过这一内存开销可以大幅降低。

首先，我们只用一张 meta-mipmap，它与应用中使用的最高纹理分辨率相匹配（称为 meta_baselevel_size）。为了在任意分辨率下都取得正确的 mipmap 信息，我们通过把 GL_TEXTURE_BASE_LEVEL 纹理参数设为当前纹理的分辨率（称为 target_size），在运行时裁掉 meta-mipmap 的高分辨率层级：

glTexParameter(GL_TEXTURE_2D, GL_TEXTURE_BASE_LEVEL,
               log2(meta_baselevel_size / target_size));

其次，如果片元着色器 profile 支持用 ddx() 和 ddy() 函数取得纹理坐标对屏幕坐标的偏导数，那么高度为 1 的 meta-mipmap 确实可以用于所有宽高比与尺寸。这两个函数，加上接受用户给定导数的 tex2D() 变体，使我们即使不知道实际 mipmap 层级，也能在 mipmap 层级选择上模拟出所有宽高比。

随后用修改过的导数从 meta-mipmap 取纹理：

// 取出并修改导数
// 需要 uniform float2 meta_adjust；见下文
float2 meta_ddx = ddx(coord_source) * meta_adjust;
float2 meta_ddy = ddy(coord_source) * meta_adjust;
// 用修改后的导数采样元 mipmap
float3 meta = tex2D(tex_meta, coord_src, meta_ddx, meta_ddy).xyz;

必须设置 uniform 参数 meta_adjust，以便把 meta-mipmap 的实际宽高比适配到目标纹理的宽高比，其中 cur_base_size 是 meta-mipmap 当前 GL_TEXTURE_BASE_LEVEL 的实际大小：

meta_adjust = float2(target_size_x / cur_base_size, target_size_y);

由于我们提供的修改后导数最终决定硬件使用的 mipmap 层级，我们实际上模拟出了 meta-mipmap 的另一种宽高比，而不需要相应的存储。

总之，meta-mipmap 的纹理内存占用可以降到单张一维纹理，其长度为应用所用（任一轴上）的最高纹理分辨率。这张单一 meta-mipmap 随后就能用于过滤任意应用纹理：只要相应设置 meta-mipmap 的 GL_TEXTURE_BASE_LEVEL 与 meta_adjust uniform 片元着色器参数。图 20-3 展示了用更高阶纹理滤波处理二维纹理后的质量提升。

但对 H 的对角元素来说，滤波器核自身的导数必须求两次。图 20-1c 画出了三次 B 样条的二阶导数，它是分段线性函数。与这个滤波器的卷积和非常容易求值。代码清单 20-4 展示了用三个线性插值的输入样本怎么做。这种情况下由于滤波器形状简单，不需要滤波纹理。三个输入样本直接按单位间隔取数，用向量 (1, -2, 1) 加权。

示例 20-4. 一维纹理的二阶导数三次 B 样条滤波

float4 bspline_dd_1d_fp(float coord_source
                        : TEXCOORD0, uniform sampler1D tex_source,
                          // 源纹理
                          uniform float e_x,
                        // 源纹素尺寸
                        )
    : COLOR
{
  // 确定额外的线性采样坐标
  float coord_source1 = coord_source + e_x;
  float coord_source0 = coord_source - e_x;
  // 取三个线性插值后的输入
  float4 tex_source0 = tex1D(tex_source, coord_source0);
  float4 tex_sourcex = tex1D(tex_source, coord_source);
  float4 tex_source1 = tex1D(tex_source, coord_source1);
  // 对线性采样加权
  tex_source0 = tex_source0 - 2 * tex_sourcex + tex_source1;
  return tex_source0;
}

高质量一阶与二阶导数信息的一个很有用的应用，是由存放在三维纹理中的体数据计算隐式曲面曲率。这里的隐式曲面曲率指等值面的曲率，它很容易在图形硬件上渲染（Westermann and Ertl 1998）。

隐式曲率信息可以直接由梯度 g 和黑塞矩阵 H 算出（Kindlmann et al. 2003），用三维三次 B 样条滤波能得到高质量结果。所需的九个分量（g 三个，H 六个，因对称性）每一个都要做一次单独的三维三次卷积滤波，传统上这极其昂贵。而用本章所述的快速滤波方案，在当前 GPU 上实际上可以实时完成。图 20-5 的图像是随书 CD 中的等值面体渲染演示程序实时生成的。

20.5 结论

本章给出了一种高效的三阶纹理滤波方法，输入纹理取数次数大幅减少。基于「一次线性纹理取数与最近邻纹理取数一样快、或者慢不了多少」这一假设，我们把三次 B 样条这类三阶滤波器核的滤波优化成建立在少量线性纹理取数之上。一个三次输出样本需要 2 个而不是 4 个输入样本，一个双三次输出样本可以由 4 个而不是 16 个输入样本算出，三维三次滤波可以用 8 次而不是 64 次输入纹理取数完成。事实上，相应的片元程序更接近「手写」的线性插值，而不像三次滤波。

这一方法的另一个优点是与滤波器核相关的所有计算都已预先算好，存在小的一维查找纹理里。这样实际的片元着色器就可以与所用的滤波器核无关（Hadwiger et al. 2001）。例如，我们给出的值与一阶导数重建片元着色器，可以原样用于宽度合适的高斯滤波器。

建立在（硬件）线性输入样本之上的一个缺点是，要得到高质量结果可能需要输入纹理有更高精度。在当前 GPU 上，8 位纹理的线性插值也以类似的精度执行，这对三维三次滤波不够用，因为一次三线性插值样本包含了 8 个输入样本的贡献。我们的实现用了 16 位纹理，为底层的线性插值提供了足够精度。当前世代的许多 GPU 还支持浮点纹理滤波，精度会更高。

另一方面，我们把滤波器用于函数（或导数）重建，这在 OpenGL 术语中称为放大滤波。为了让高阶滤波器也能用于纹理缩小，我们说明了如何把它们扩展到带 mipmap 的纹理。这里引入的一个重要组成部分，是降低所需额外纹理信息（我们称为 meta-mipmap）的内存占用。

最后，我们说明了如何用本方法高质量重建一阶与二阶偏导数，这对体渲染或渲染有符号距离场表示的隐式曲面等场合尤其有用。用这一方法，曲率这类微分表面属性也能实时高质量地计算出来。
