Immune 标记

Immune Flag 关闭
节点 Immune Flag 开启
网络 Immune Flag 开启

每个非组件节点都有一个 Immune 二态 Flag，也称为 Clone Immune Flag。如果 Clone 中某个节点的 Immune 标记为 On，它就不受对主克隆中等价节点所做更改的影响。你可以用 Immune 标记自定义操作符的参数，或添加克隆主组件中不存在的额外操作符和额外数据。 bi-state 非组件上的 Immune 标记是二态标记。

  • Off
  • On - 此节点被设为免疫。

例如，克隆中的 Table DAT 常被设为免疫，以使每个克隆中的表格互不相同。

保持免疫的内容：参数、连到节点输入的连线，以及（如果节点是面板）它的所有 Panel Values，例如 state、u 和 v。Table DAT 的数据以及 Locked 节点的数据也保持免疫。

警告：如果你在 Clone 中新增节点并将该新节点的 Immune 标记设为 On，你可能还需要把它输出所连接的节点的 Immune 标记也设为 On，因为连线信息保存在节点的输入上。

组件上的 Immune

每个组件节点都有一个 Immune 三态 Flag，也称为 Clone Immune Flag。

组件上的 Immune 标记是三态标记。

  • Off
  • On - 此节点被设为免疫。
  • On Including Children - 此节点被设为免疫，并且（如果节点是 Component）组件内的所有节点（递归地）都免疫。

如果节点位于 Clone 组件内且其 Immune 标记为 On，它就不受对主克隆中等价节点所做更改的影响。

因此，使用 On Including Children 可以使整个 Components 免疫，此时组件网络内的所有节点也都免疫。

该三态标记显示在磁贴上，也显示在网络编辑器的列表模式中（按 shift+t 切换模式）。

保存 .toe 或 .tox 文件时，所有克隆节点都不会保存到 .toe 中，免疫节点除外。克隆中的免疫节点会被保存，因为它们并未在主克隆中定义。除此之外，克隆中的节点预期不会保存到文件中。


更多信息请参阅 Clone。

另请参阅 Flag。

通过 Python 设置 Immune

请参阅 OP_Class 中的 cloneImmune。

对于组件，请参阅 COMP_Class 中的 componentCloneImmune。当 componentCloneImmune 为 True 时，克隆内的所有内容都免疫。当 componentCloneImmune 为 False 时，它使用 OP_Class 的 cloneImmune 成员来判断是否只有组件本身免疫（其参数等，但不含组件内部的网络）。
