书签对话框

说明

Bookmarks 对话框可让你添加、编辑和删除 Bookmarks。书签保存在 network 位置 /local/bookmarks。

书签

书签在对话框中列出，书签名称在左列，书签的路径在右列。

当列表中的书签超过 20 个时，使用右侧的滚动条浏览。

可抓住对话框的标题栏在屏幕上拖动对话框。要关闭对话框，点击右上角的 x 按钮。

添加书签

对话框顶部的文本字段用于添加书签。在左侧的名称字段中输入书签名称，然后在右侧的字段中输入书签的网络路径。点击 Add 按钮添加书签，它会显示在下方列表中。

书签也可直接从 Bookmark Menu 添加。

编辑书签

要编辑书签的名称或路径，直接点击该字段并进行修改。按下 Enter 或点击其他字段后，名称或路径即会更新。

选项菜单

右键点击任意书签即可打开选项菜单。

加载书签

要加载书签，右键点击它打开选项菜单并选择 Load Bookmark。书签也可直接从 Bookmark Menu 加载。

删除书签

要删除书签，右键点击它打开选项菜单并选择 Delete。
