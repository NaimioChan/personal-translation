Line Metrics POP

摘要

可以为 Line Strips 添加指标属性。它们可以创建为点属性或顶点属性。

这能提供关于点及其所处上下文的有用信息。对每个点，你可以获取指向下一个点和上一个点的方向、回到 line strip 起点的距离，或它所在的 line strip 编号……这些对 Math POP 或 Lookup POP 很有用。

Line Metrics POP 的一个便利之处，是为重合点（同一位置上连续的两个或多个点）这类棘手情况给出良好取值，尤其是方向向量。这正是 Continuous Direction 参数的作用。它会配合 Direction to Next、Direction to Previous 使用，并让 Tangent 向量保持对齐，从而得到良好结果。

Info CHOP 通道

Line Metrics POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
