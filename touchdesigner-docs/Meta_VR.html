Meta VR

Oculus Rift 与 Meta Quest

TouchDesigner 通过 Oculus Rift TOP 和 Oculus Rift CHOP 支持 Meta 的多款 VR 头显，包括 Meta Quest 和 Oculus Rift。

TouchDesigner 中的 Meta VR 支持

TouchDesigner 通过 Oculus Rift TOP 和 Oculus Rift CHOP 内置支持 Meta 头显。两个操作符都有 Device 参数，以支持在同一台机器上连接多个设备。

Requirements

  • VR hardware
  • 设置头显设备：Setup Headset

Ways to interface with Meta headsets in TouchDesigner

  • Oculus Rift CHOP - 输出若干组通道，例如朝向、左右眼摄像机位置、加速度以及左右眼投影矩阵。
  • Oculus Rift TOP - 把左右眼图像输出到头显设备。

入门

上面的演示列表是开发 Meta 头显内容的好起点。

对于 Oculus 设备，首先要确保头显配置为使用「Extend Desktop to the HMD」显示模式。可以在 Oculus Configuration Utility 的 Tools->Rift Display Mode 菜单中选择。OpenGL 应用程序目前尚不支持直接 HMD 渲染。当 Oculus 在操作系统中作为额外显示器出现后，你需要确保其方向正确。默认显示为「Portrait」，但我们的测试表明正确方向是「Landscape (Flipped)」。使用 Oculus Configuration Utility 中的「Show Demo Scene」按钮测试并确认显示设置正确。一旦 Oculus 在「Extend Desktop Mode」下能正确显示演示场景，它在 TouchDesigner 中通常也能正常工作。

对于 Meta Quest 设备，请启用 PC Link。可以在 Quest 头显中前往 Settings -> Link -> Link 开关来完成。你可以通过物理 Link 线缆或使用本地 Wi-Fi 网络的 Air Link 把 Quest 设备连接到 PC。如果 PC 已连接到你的头显，你应该能在 Settings -> Link -> Launch -> Available PCs 下看到该 PC。启用 PC Link 并且有 PC 连接到头显后，启动 Link。

刷新率问题

大多数桌面显示器以 60hz 运行，但 Meta 头显可能根据型号以不同的刷新率运行。例如 Oculus Rift S 以 80hz 运行，Oculus Rift DV1 以 90hz 运行。如果有 TouchDesigner 窗口在 60hz 显示器上重绘，Windows 可能不会向 Oculus 提供 80/90hz 数据。如有可能，把所有显示器都设为 90hz 运行。但许多显示器并不支持。让你的窗口进入 perform 模式并确保「Redraw」参数关闭可以避免此问题。此外，应禁用 perform Window COMP 中的 V-Sync Mode。

Oculus Rift CHOP

Oculus Rift CHOP 提供两组主要数据。一是每只眼睛的摄像机渲染位置，以变换矩阵形式表示为 16 个 CHOP 通道。另一组数据是每只眼睛的投影矩阵，同样为 16 个 CHOP 通道。这两个矩阵可以直接用在 Camera COMP 中，通过 Pre-XForm 和 Projection Matrix 的 CHOP/DAT Matrix 参数使用。
