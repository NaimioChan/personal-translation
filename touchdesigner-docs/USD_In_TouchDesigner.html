TouchDesigner 中的 USD

Summary

USD 代表 Universal Scene Description（通用场景描述），是一套用于定义、合成和读取层级场景描述的制作流程。它由 Pixar 开发，是其 3D 图形管线的核心。它提供模型和镜头的场景描述，供 Pixar 所有渲染应用系统以及其他第三方应用使用。

USD 便于多位艺术家或内容创作者协作处理同一场景和资产。这意味着他们可以制作自己的组装、打包、编辑资产和数据，或定义 variant set，以获得可切换的离散场景树备选方案。

有关 USD 特性和 API 的详细说明，请参阅 https://graphics.pixar.com/usd/docs/

TouchDesigner 目前只读取 USD 文件，不写入 USD 文件。

另请参阅 USD COMP、USD。


Importing USD File

在 TouchDesigner 中，USD COMP 节点用于导入 USD 文件。文件加载到 TouchDesigner 后，会创建节点的层级树。节点类型取决于导入的 USD 文件中有什么，但至少应能看到 Geometry COMP/Null COMP 来表示变换操作符（即 USD 文件中的 Xforms 图元类型）或 Scope 图元，以及用于几何图元的 Import Select SOP 节点。其他常见节点类型包括用于动画变换的 Camera COMP 和 Import Select CHOP，或用于表示 PointInstancer（稍后说明）、用于 uv 纹理资产的 Import Select TOP，以及 MAT 节点。

默认情况下，TouchDesigner 中的节点层级与 USD 文件的图元层级基本相同，但在某些情况下会为更好的兼容性在路径中添加额外节点，或移动某些特殊节点。这类情况的一个例子是：为任何自带动画变换的几何类型图元（如 mesh）添加 Geometry COMP，而在 USD 文件中它们并未定义为变换图元。这有助于用户在时间变化时观察变换变化。

Supported Geometries

TouchDesigner 支持的 USD 几何图元 schema 包括 meshes、geomsubsets、points、basis curves（目前支持 Bezier 曲线，对于 B-Splines、Hermite 等其他曲线类型，插值按线性曲线处理）、NURBS Curves 和 NURBS surfaces。每个图元都在各自独立的 ImportSelect SOP 中表示，并通过其在原始 USD 文件中的独特内部层级路径来识别（即 SdfPath）。不过，在每个 Import Select SOP 中，也可以仅通过点击路径菜单来选择另一个图元，并用所选图元替换当前图元。对于包含大量几何图元的大型 USD 文件，建议记录哪些已替换为原始图元。


USD-TouchDesigner Attribute Conversions

USD 中的属性是图元的一种属性类型，具有标准类型之一（https://graphics.pixar.com/usd/docs/api/_usd__page__datatypes.html），可以有默认值和统一值，或在每个时间采样处有不同值。TouchDesigner 支持大多数标准属性类型。Primvars（图元变量）是专用于几何图元的特殊属性，其值在图元表面上可以有不同的插值类型。USD 中的 Primvars 在 TouchDesigner 中被视为自定义属性，其插值类型将转换为 TouchDesigner 的标准类型（即 Point、Vertex 和 Primitive）。


Materials and Shading

USD 中的材质是一个容器图元，包含渲染器用的 Shading 节点。每个几何都指定对某个材质图元的绑定。几何可能被拆分为多个几何，其中每个几何是一个 UsdGeomSubset，这种情况下每个子集表达自己独立的材质绑定。每个子集都有一个名为「familyName」的属性，此值必须为「materialBind」，否则绑定材质将被忽略。

材质还可以有不同的变体（variant-set），每个变体可以有不同的参数值或着色器网络。每个材质可以引用另一个资产，这种情况下就像把材质及其网络复制到该资产。

每个材质有三种「终端」输出：surface、displacement 和 volume。材质图元可以有任意数量的这些输出，每个输出指向材质网络内的某个着色器节点。目前我们支持「surface」输出类型，它直接应用于几何表面。

在 TouchDesigner 中，材质类型是 PBR MAT 或 Phong MAT 节点，而法线贴图、uv 纹理等资产文件会作为 Import Select TOP 节点加载，与 MAT 节点处于同一层级。MAT 节点的位置对应其在 USD 文件中的路径，也就是说，如果材质定义在根层级的 Scope 图元内，材质就应在该位置找到。出于性能考虑，如果某个 mesh 图元没有 xform 父级，我们会为该 mesh 图元添加一个额外的 Geometry COMP，并将绑定的 MAT 引用到其新的 COMP 父级。

材质着色器网络在内部处理，也就是说每个着色器节点的输出会传递给下一个节点，结果反映到单个 MAT 节点上，因此你可能找不到着色器对应的特定节点。 TouchDesigner 中的 UsdGeomSubset 没有新的 SOP 类型，由于每次只能将一个 MAT 节点应用于一个几何，我们将父 mesh 拆分为多个 Import Select SOP 节点。如果这些新 SOP 节点具有不同的材质绑定，则无法通过 Merge Geometry 参数合并在一起。这同样适用于 USD 网络内的所有 SOP：如果两个 SOP 节点各自的材质绑定不同，则不可合并。


Other Supported USD Features

在 TouchDesigner 中，USD 的 PointIntancer 表示为 Instancing 参数设为 ON 的 Geometry COMP。USD 中的 PointInstancer 是多个原型的向量化实例化，原型可以是 USD stage 中的图元或子树。它设计用于扩展到数十亿个实例，并可基于整数 id 对实例进行遮罩/修剪。换句话说，每个 PointInstancer 可以从一个图元表示任意数量的实例（原型），每个整数 id 都是逐实例索引（protoIndex）关系，用于标识该实例必须渲染哪个几何。如果已创作，PointInstacer 的变换操作符和朝向向量会显示为 Import Select CHOP 中的独立轨道，轨道上的每个点显示逐实例的变换（平移、旋转和缩放）与朝向值。该 CHOP 节点在 Geometry COMP 中被引用。如果已创作速度，它会影响每个实例位置的插值。角速度同理，会影响实例的朝向。

USD 的 Relationship 是一个命名空间指针，可指向（表达对）场景图中的一个或多个图元、属性和关系。

TouchDesigner 支持 USD 文件的 SubLayering 和覆盖特性。USD 最强大的特性之一也许是 Composition Arcs 操作符，它允许将多个层组装在一起，并将它们作为列表编辑层关联，可按强度顺序（从最强到最弱）解析，以避免多位艺术家同时处理同一文件时的冲突，每个人可以有自己的层 https://graphics.pixar.com/usd/docs/USD-Glossary.html#USDGlossary-LayerStack。Sublayering 是一种用于创建层的 LayerStack 的合成弧。另一种合成弧是 Variant-Sets，它允许在各种图元或属性之间切换。变体可以包含图元子树，基本上可以有任何场景描述。

在分层之后，次重要的合成机制是 Reference。它允许外部场景描述层被实例化到另一个场景描述中，而无需复制被引用场景的内容。这在某些方面类似于指针，或 C++ 中的头文件包含，也包括其递归特性。

Instancing 是 USD 的另一项特性，它使一个对象在 stage 内可以有许多实例共享同一表示。此特性有助于改善内存和速度方面的性能。为了利用这一性能提升，在 TouchDesigner 中，对于每个「master」图元的所有几何实例，只使用其中一个实例的路径，所有其他实例复用同一几何，同时保留各自的变换。


Merging

Merging 特性是提升 USD COMP 性能的一种方式，有助于减少网络层级中的节点数量。通过开启合并特性，我们合并可合并的 SOP 和 Geometry COMP，使每个节点可以与其兼容的操作符合并。我们将 TouchDesigner USD 网络中的节点分为可合并和不可合并。可合并的 SOP 取决于它们是动画还是静态、是否具有 PointInstancer 类型的父级、是否具有相同的绑定材质，或是否具有相同的父级。动画 SOP 彼此合并，静态 SOP 同理。具有 PointInstancer 类型父级的 SOP 不可合并。如果两个 SOP 的父级不同，它们也不能合并。合并还有另一个属性或参数叫合并层级。合并层级定义了理想情况下我们希望节点距离 USD 网络根节点多远进行合并。我们说「理想情况下」，是因为某些节点被标记为不可合并，因此它们的子树可能无法达到所期望的指定层级。合并从网络底部开始，但 USD 创建后，每个节点都有一个从 1 开始的层级编号，1 是根节点，每个节点的子级层级值递增 1。注意层级中同一节点的所有子级具有相同的层级编号，并且该值与其父级同级节点的子级相同。

Geometry 或 Null COMP 的合并本质上就是将其 xform 标签页中的变换值相乘。不可合并的 Geometry COMPs 是那些具有动画变换的。其他不可合并的节点是表示动画 COMP 的 Import Select CHOP 节点，以及用于 PointInstancer 类型的 Import Select CHOPs。


Glossary

SdfPath：为命名空间层级中的每个对象在 USD 文件内分配唯一路径。

xform：是 USD 变换的简写，是一种 UsdGeomXformable schema。此 Xformable 本质上是一组有序的 UsdAttribute 类型变换操作，共同构成一个变换图元。

PointInstancer：USD 中的 PointInstancer 图元是多个原型的向量化实例化，原型可以是 USD stage 中的图元或子树。它设计用于扩展到数十亿个实例，并可基于整数 id 对实例进行遮罩/修剪。换句话说，每个 PointInstancer 可以从一个图元表示任意数量的实例（原型），每个整数 id 都是逐实例索引（protoIndex）关系，用于标识该实例必须渲染哪个几何。如果已创作，PointInstacer 的变换操作符和朝向向量会显示为 Import Select CHOP 中的独立轨道，轨道上的每个点显示其逐实例的变换（平移、旋转和缩放）与朝向值。

Prototype：是文件中任何被 PointInstancer 以任意数量实例化使用的几何。作为原型使用的动画几何在经 PointInstancer 实例化后仍保持动画。此外，原型可以包含另一个 PointInstancer。

Protoindex：是逐实例指向原型的整数 ID 关系，用于指定必须渲染哪个实例。

Layer：是 USD 文件内的基本内容容器。它可以包含 1 个或多个 PrimSpec。层通常对应单个文件（或 usdz 归档内的一个文件）。

Sub-layering:

Attribute：是具有标准类型之一（https://graphics.pixar.com/usd/docs/api/_usd__page__datatypes.html）的图元的一种属性类型，可以有默认值和统一值，或在每个时间采样处有不同值。

Opinion：如果有变体集要覆盖当前的合成弧，必须有办法排除哪些定义将被忽略、哪些保留下来。通常在一层内，本地意见强于 Variant 集或继承的意见。

Stage：stage 是 USD 对场景图的抽象，源自一个根 USD 文件及其合成时引用的/分层的所有文件。stage 始终呈现支持它的场景描述经过合成后的视图。
