ThreadManager 扩展

Thread Manager 的扩展。

TDTask

一个要创建并传给 ThreadManager 任务队列的任务。 TDTask 应始终使用 ThreadManagerExt.EnqueueTask 方法入队到 Manager。

参数：

  • target (Callable)：在线程中调用的主方法。执行时会把 args 和 kwargs 传给此方法。
  • SuccessHook（Callable，可选）：目标方法完成后在主线程中调用的方法。默认为 None。
  • ExceptHook（Callable，可选）：执行目标方法期间发生异常时在主线程中调用的方法。默认为 None。
  • RefreshHook（Callable，可选）：目标方法执行期间每帧在主线程中调用的方法。默认为 None。
  • args（tuple，可选）：要传给目标方法的参数元组。默认为 ()。
  • kwargs（dict，可选）：要传给目标方法的关键字参数字典。默认为 None。

成员

Manager → ext.ThreadManagerExt :

此 TDTask 从中入队的 ThreadManager 扩展。

SuccessHook → Callable :

目标方法完成后在主线程中调用的方法。默认为 None。

ExceptHook → Callable :

执行目标方法期间发生异常时在主线程中调用的方法。默认为 None。

RefreshHook → Callable :

目标方法执行期间每帧在主线程中调用的方法。默认为 None。

State → ext.ThreadManagerExt.TDTaskStates :

TDTask 当前的 TDTaskState。默认为 TDTaskStates.STANDBY。

RanBy → int :

取用此 TDTask 执行的 TDThread 的 ID。默认为 None。

StateLock → threading.Lock :

用于安全访问 TDTask 成员的线程锁。

设计为可在线程上下文中安全使用的辅助方法。返回取用此 TDTask 执行的 TDThread 的 ID。

TDTask.SetRanBySafe(ranBy: int)→ None:

设计为可在线程上下文中安全使用的辅助方法。设置取用此 TDTask 执行的 TDThread 的当前 ID。

TDThread

带有一些 TD 专属附加功能的线程。

继承自 threading.Thread 类。

参数：

  • target (Callable)：在线程中调用的主方法。执行时会把 args 和 kwargs 传给此方法。
  • SuccessHook（Callable，可选）：目标方法完成后在主线程中调用的方法。默认为 None。
  • ExceptHook（Callable，可选）：执行目标方法期间发生异常时在主线程中调用的方法。默认为 None。
  • RefreshHook（Callable，可选）：目标方法执行期间每帧在主线程中调用的方法。默认为 None。
  • task（TDTask，可选）：入队以立即运行或独立运行时传入的 TDTask。默认为 None。
  • InPool（bool，可选）：一个布尔值，用于把 TDThread 创建为工作线程，成为线程池的一部分。默认为 False。
  • InfoQueue（queue，可选）：用于在此线程与主线程之间交换数据的队列。默认为 None。

成员

TDTask → ext.ThreadManagerExt.TDTask :

TDThread 初始化时被分配的任务。通常发生在对 ThreadManagerExt 使用 EnqueueTask 且 force 设为 true（且所有工作线程都忙）或 standalone 设为 true 时。

RefreshHook → Callable :

目标方法执行期间每帧在主线程中调用的方法。默认为 None。

Manager → ext.ThreadManagerExt :

此 TDThread 从中入队的 ThreadManager 扩展。

State → ext.ThreadManagerExt.TDThreadStates :

TDThread 当前的 TDThreadState。默认为 TDThreadStates.STANDBY。

InfoQueue → queue :

用于在此线程与主线程之间交换数据的队列。默认为 None。

Progress → float :

由线程方法使用 SetProgressSafe 设置、并由主线程使用 GetProgressSafe 读取的值。

InPool → bool :

一个布尔值，用于把 TDThread 创建为工作线程，成为线程池的一部分。默认为 False。

StateLock → threading.Lock :

用于安全访问 TDThread 成员的线程锁。

用于控制工作循环的线程事件。

ThreadManagerExt

Thread Manager COMP 的扩展。大多数用户只需要创建 TDTasks 并用 ThreadManagerExt.EnqueueTask 将它们入队。

成员

Logger → Logger COMP :

对本地 TouchDesigner Logger 的引用。不应在线程内使用。

ManagerCondition → threading.Condition :

实现条件变量的类。条件变量允许一个或多个线程等待，直到被另一个线程通知。如果给出了 lock 参数且不为 None，它必须是 Lock 或 RLock 对象，并用作底层锁。否则会创建一个新的 RLock 对象用作底层锁。

MaxNumberOfThreads → int :

当前硬件上逻辑线程的理论上限。等于 os.cpu_count()。它被用作线程池的钳制上限，但并非硬性限制，仍可手动创建线程，可以用 self.ownerComp.par.Stategyonmaxthreadsreached 设置备用策略。

MaxNumberOfWorkers → int :

组成线程池的最大工作线程数。

SafeLogger → logging.Logger :

对本地 TouchDesigner Logger 的 Python 日志对象的引用。可在线程方法中安全使用。

Shutdown → bool :

用于通知工作线程退出工作循环并关闭。只应通过 StateLock 或某个辅助方法来设置。

StateLock → threading.Lock :

用于安全访问 ThreadManagerExt 成员的线程锁。

Subscribers → List[COMP] (Read Only):

注册到此 Broadcaster 的 Subscriber 列表。

Tasks → List[TDTask] :

当前注册在 Thread Manager 上、等待在线程池中被取用的任务列表。

Threads → List[TDThread] :

当前注册在 Thread Manager 上的 TDThread 列表。其中包括工作线程。

ThreadsCount → int :

当前正在运行并在 ThreadManager 上注册的线程数。

Workers → List[TDThread] :

属于工作线程池的 TDThread 列表。

WorkersCount → int :

当前正在运行并在此 ThreadManager 上注册的工作线程数。

方法

ThreadManagerExt.EnqueueTask(task: ThreadManagerExt.TDTask, force: bool = False, standalone: bool = False)→ ThreadManagerExt.TDThread:

把一个 TDTask 添加到任务队列，之后由线程池中可用的 TDThread 取用。之所以提升 EnqueueTask，是因为用户可以在 ThreadManager 上下文之外创建任务，之后再入队交给线程池处理。

参数：

  • task（TDTask）：要添加到任务队列或（用于强制或独立模式时）传给 TDThread 的 TDTask。
  • force（bool）：强制任务立即运行，无论是作为线程池的一部分，还是在独立的 TDThread 中。默认为 False。
  • standalone（bool）：强制任务在独立的 TDThread 中立即运行。默认为 False。优先于 `force` 参数。

ThreadManagerExt.GetTaskById(taskId: str)→ ThreadManagerExt.TDTask:

根据给定的任务 ID 取得匹配的现有 TDTask，没有则返回 None。之所以提升此方法，是因为从其他组件访问它很有用。

参数：

  • taskId（str）：要从 TDTasks 列表中获取的 taskId。

ThreadManagerExt.GetThreadById(threadId: str)→ TDThread:

根据给定的线程 ID 取得匹配的现有 TDThread，找不到则返回 None。之所以提升此方法，是因为从其他组件访问它很有用。

参数：

  • threadId（str）：要从 TDThreads 列表中获取的 threadId。

ThreadManagerExt.PostProcess(ThreadManagerExt.TDThread)→ None:

在线程执行完线程方法且 TDThread.State == self.TDThreadStates.FINISHING 或 FAILED 时调用。独立线程执行和在工作循环内的工作线程执行都会调用它。

参数：

  • tdThread（TDThread）：执行完其线程方法的 TDThread。

ThreadManagerExt.Done(ThreadManagerExt.TDThread)→ None:

当后处理完成（Success 或 Except 钩子已被调用）且线程状态设为 TDThreadStates.DONE 时，调用此方法来清理和/或重置 TDThread。

参数：

  • finishingThread（TDThread）：已达到 Done 并应进行清理和/或重置的 TDThread。

ThreadManagerExt.RemoveNumberOfWorkers(toRemove: int):

移除给定数量的额外工作线程。

参数：

  • toAdd（int）：要移除的工作线程数量。

ThreadManagerExt.Subscribe(externalComp: str, messageTypes: List[str])→ bool:

此方法用于把外部组件添加为此 broadcaster COMP 的 Subscriber。它由 Subscriber 调用，把自己加入此 Broadcaster 的 Subscriber 列表。当某个组件注册为 Subscriber 后，broadcaster 收到的任何消息类型，只要是该 Subscriber 注册过的消息类型，都会被路由给该 Subscriber。

参数：

  • externalComp（str）：正在此 signaling client 上注册为 Subscriber 的 COMP 的路径。
  • messageTypes（List[str]）：Subscriber 注册的消息类型列表。当 signaling client 收到匹配的消息类型时，会把它路由给该 Subscriber。

返回：

  • bool：订阅请求是否成功。如果该 Subscriber 已经注册过则返回 False。

ThreadManagerExt.TerminateThread(thread: ThreadManagerExt.TDThread)→ None:

终止并清理给定的 TDThread。此方法保持提升，让用户能自由地手动终止线程。理想情况下，线程应因线程方法执行完毕或抛出异常而终止。如果被终止的线程属于线程池，之后会被重新创建。把成员 Shutdown 属性设为 True 会强制工作线程关闭。

参数：

  • thread（TDThread）：要手动终止的 TDThread。

ThreadManagerExt.ValidateMessageTypes(messageTypes: List[str])→ bool:

订阅时，验证传入的所有列表都是有效的 str。

参数：

  • messageTypes（List of str）：要验证的字符串列表。
