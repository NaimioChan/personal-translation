查看器激活

节点的 Viewer Active 状态让你可以交互操作Node Viewer。

通常单击/拖动节点会移动它。当节点的查看器是三个字母的图标时，单击拖动总是会移动节点。单击节点左上角的标记以开启查看器。这会让查看器可见，但它还没有激活。然后

  • 单击节点右下角的 +。
  • shortcut 键 “a” 会设置/取消所有选中节点（黄色边框的节点）的 Viewer Active 标记。
  • 按住 Alt+a 时，所有节点查看器会临时处于 Viewer Active 状态。
  • 可以在网络编辑器中使用右键菜单，将查看器设置为始终处于Viewers Always Active状态。
  • 所有节点在右下角都有自己的Viewer Active Flag。设置 Viewer Active 标记可使节点查看器处于始终可操作的状态。

查看器激活时的光标是 ^。Viewers Always Active 状态会保存在.toe中。

左：带 3 字母图标的节点。中：带查看器的节点（节点左上角标记）。右：查看器已激活的节点（右下角标记）。


查看器激活时，你只会看到查看器及其下方的名称。你可以操作、旋转、平移、缩放并操控节点查看器中的内容。控制面板可以完整操作。

提示：视图激活时，你仍可单击底部的名称栏拖动节点，在网络中四处移动。也可以右键单击名称栏，调出节点的右键菜单。

在Network Editor中按住 Alt，会为所有节点临时开启 Viewer Active；按 Alt-a 可保持该状态。再次按 Alt-a 会关闭所有节点的 Viewer Active，但自身 Viewer Active 标记已开启的节点除外。

不在 Viewer Active 状态时，节点查看器区域被禁用，行为与节点其余部分相同。这样你可以单击任意位置来选中并移动节点，或右键单击任意位置打开节点菜单。

注意：在节点查看器中移动内容不会影响其变换或参数。Exception：Camera COMP
