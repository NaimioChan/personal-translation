Mipmap 多级纹理

概述

纹理所有 mipmap 层级的示例

Mipmapping 是一种纹理技术，用于减少把大纹理映射到屏幕空间中的小区域时产生的伪影。产生这些伪影的原因是：由于绘制的像素很少，纹理中只有一小部分像素被用于为几何着色。该伪影通常表现为纹理在屏幕上移动时闪烁或有噪点。

例如：假设我们有一张 512x512 的图像，它被映射到一个只占屏幕 50x50 像素的多边形上。为该四边形贴图时，GPU 会在多个位置采样纹理。但由于它只有 50x50 像素要绘制，最终只会采样图像中 10-20% 的像素。如果对象在屏幕上移动，某一帧采样的那 10-20% 像素可能与下一帧采样的 10-20% 相差很大，使图像看起来闪烁或有噪点。

要看到这种伪影，请打开文件 noisemipmap.toe。确保节点查看器已开启，然后在网络中放大和缩小。左侧的 Noise TOP 没有使用 mipmap，右侧的则使用了。注意左侧的在网络中缩小时会闪烁，而右侧的显示出良好的视觉连续性。你还会注意到，只有当节点查看器占用的像素数小于纹理尺寸时才会出现闪烁。这里纹理宽 256x256 像素，所以以大于该尺寸查看它们时，看起来是一样的。

技术原理

Mipmapping 通过创建纹理的预缩小版本来实现。mipmap 层级是原始纹理在某个分辨率下的单个缩小版本。会创建多个 mipmap 层级，每一层都是上一层的一半大小。例如 256x256 的纹理会具有 128x128、64x64、32x32、16x16、8x8、4x4、2x2 和 1x1 的 mipmap 层级。每个 mipmap 层级都由上一层缩小而成。所以 128x128 层由原始 256x256 纹理缩小而来，同样 8x8 层由 16x16 层缩小而来。缩小时使用 2x2 的盒式滤波，在创建新 mipmap 层级时对源纹理的像素颜色取平均。

渲染时，GPU 会根据渲染几何占用的像素数，自动选择最合适的 2 个 mipmap 层级进行采样。例如渲染的几何占用 90x90 像素，则会使用 128x128 和 64x64 两个 mipmap 层级。GPU 在贴图时会在这两个层级之间混合，这就是我们在网络中缩小时看不到视觉不连续的原因。

在材质（MAT）中使用 mipmap

任何采样纹理的 MAT 都会自动使用 mipmapping。你可以点击每个贴图旁的 +，选择 Mipmap Linear 过滤以外的选项，从而在 MAT 中关闭 mipmapping。

在纹理（TOP）中使用 Mipmap

所有 TOPs 都可以按 mipmap 采样其输入。这有助于减少图像位置或缩放动画时的闪烁伪影，尤其是在使用包含大量细小细节的图像时。

Mipmap Pixels 选项位于所有 TOP 的 Common 页上的 Input Smoothness 和 Viewer Smoothness 菜单中。另请参阅 TOP Generator Common Page 和 TOP Filter Common Page。

GPU 内存开销

TOP 的 mipmap 会使该 TOP 多占用 33% 的 GPU 内存。你可以通过中键点击某个 TOP 并查看 Mipmaps: Yes，来判断它是否已创建 mipmap。
