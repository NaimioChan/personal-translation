Peer 类

Peer 描述在 oscinDAT、tcpipDAT、udpinDAT、udtinDAT 中的回调函数里发起某条消息的那条网络连接。

成员

owner → OP (Read Only):

此对象所属的 OP。

port → int (Read Only):

与该 peer 关联的网络端口。

address → str (Read Only):

与该 peer 关联的网络地址。

hostname → str (Read Only):

与该 peer 关联的网络主机名。

方法

close()→ bool:

关闭 peer 连接。成功则返回 True。例如在实现 HTML 服务器协议时，关闭 peer 会很有用。

sendBytes(*messages)→ int:

通过此连接发送一串字节。不会追加任何终止符。注意：消息不会按 OSC 格式化。

消息可以是字符串、字节数组或单个单字节数值的任意组合。 要序列化非字节值（例如浮点数或整数），有若干 Python 模块可完成此工作，例如 pickle 或 struct。 返回已发送的字节数。 

n.sendBytes( 'TYPE', 23, 255, 12, 0x34, b'\x01\x00\x02\x00\x03\x00\x00\x00')

sendOSC(address, *values, asBundle=False, useNonStandardTypes=True, use64BitPrecision=False)→ int:

通过此连接发送一条 OSC 格式的消息。可传入多组 address/valueLists 参数。此方法会自动决定把所传值转换为哪种 OSC 类型。

返回已发送的字节数。

  • address - 用于标记此消息的 OSC 地址。
  • values - 要在此消息中发送的值的列表。
  • asBundle - （关键字参数，可选）为 true 时，所有消息都在单个 bundle 中发送。
  • useNonStandardTypes - （关键字参数，可选）为 True 时，可以使用非标准 OSC 类型发送值。例如 True 和 False 会作为布尔类型 T 和 F 发送，而不是值为 1 和 0 的 int。Available in 099.2018.21730 or later.
  • use64BitPrecision - （关键字参数，可选）为 True 时，整数和浮点值将作为 64 位值发送。需要 useNonStandardTypes 也为 True。Available in 099.2018.21730 or later.
vals = [1, b'abc', 'apple', [6,7,8], True, None, float("infinity")]
n.sendOSC('/abc', vals)
整数
如果 useNonStandardTypes=True，则为 32 位或 64 位整数，取决于该整数当前值的大小。
如果 useNonStandardTypes=False，则当数值能放入 32 位整数时为 32 位整数，过大时抛出异常。
如果 use64BitPrecision=True，则始终为 64 位整数。
浮点数
如果 use64BitPrecision=True，则始终为 64 位浮点数。
如果 use64BitPrecision=False，则始终为 32 位浮点数。
值为 Infinity 的浮点数
如果 useNonStandardTypes=True，则为 OSC Infinitum 类型。
如果 useNonStandardTypes=False，则始终为 32 位浮点数。
布尔值
如果 useNonStandardTypes=True，则为布尔 T 或 F 类型。
如果 useNonStandardTypes=False，则为值为 1 或 0 的 32 位整数。
None
如果 useNonStandardTypes=True，则为 OSC nil 类型。
如果 useNonStandardTypes=False，则为值为 0 的 32 位整数。
字符串
任何情况下都是 OSC 字符串。
bytes 或 bytearray 对象
一个 OSC blob。务必把 bytes/bytearray 对象放进列表，而不是直接传给 sendOSC。如果不放在列表中直接传给 sendOSC，它会被当作单个整数值的列表处理，而不会作为 blob 发送。

send(*messages, terminator='')→ int:

通过此连接发送一串字符串。注意：消息不会按 OSC 格式化。

  • messsage - 要通过网络连接发送的一个或多个字符串。
  • terminator - （关键字参数，可选）指定消息如何终止。如果没有指定要追加的终止符，会自动在消息后追加一个空字符。要发送不带终止符的消息，请使用 terminator=''。

返回已发送的字节数。 

n.send('Hello', 'World',  terminator='\r\n') # 发送两个以 Windows 换行结尾的字符串。
