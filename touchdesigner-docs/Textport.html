Textport

Textport 是用于手动输入命令和脚本的对话框。输出到文本端口的内容包括脚本错误，以及 python 代码中 print() 和 debug() 调用产生的消息。你也可以在文本端口中编辑 DAT。

Dialogs → Textport 会打开主文本端口，但你也可以按 F4 以浮动窗口打开 Textport。F4 在 Perform Mode 中也可用。

你可以输入 python 表达式并让它求值，简单到 2+3，它会在下一行打印 5。

提示：如果你打错了一行并按了 Enter，想修改它可以按上方向键调出之前输入的行，用方向键/退格/删除键修改，然后按 Enter 重新执行。

如果你在写类似 op('/project1/geo1').par.tx 的表达式，可以更轻松地输入 op('，然后把节点拖到文本端口（这会把其路径加入字符串），再输入 ').par.tx 并按 Enter：效果相同。

提示：可以同时在文本端口中编辑多个 DAT。右键点击某个 DAT 并选择 Edit Contents in Textport...。这会在文本端口中打开一个新标签页，你可以在其中编辑或查看代码。

注意，某些启动和系统错误会输出到 Dialogs → Console。

把 Pane Type 菜单设为 Textport and DATs，即可把文本端口放入 panes 中。

TouchDesigner 中有两种脚本语言：Python 和已过时的 Tscript。对于 Tscript，所有命令都在 Tscript Commands 和 Tscript Expressions 中描述，其脚本语法见 Tscript。textport 是一个 Tscript 命令，可用于操作该对话框的内容。

你可以把 Python 的 stdout 和 stderr 重定向到任意 DAT。然后可以用 OP Viewer TOP 或 COMP 把该 DAT 转换为纹理，并整合到你的 UI 中。

文本端口对话框

可以从 Dialogs 菜单或使用 Alt+Shift+T 快捷键打开文本端口。文本端口也可以作为 Pane 打开。

输入 Python 脚本最简单的方法是通过 textport。 文本端口与 TouchDesigner 中的所有脚本一样，允许用 Python 或 Tscript 指定脚本。

打开文本端口后，先确认它已设为 Python 语言。 这由文本端口左上角的小开关按钮控制。

设为 Py 时，所有输入都按 Python 解释。 设为 T 时，按 tscript 解释。

此外，每种语言的文本端口提示符和文本颜色都不同，便于识别文本端口处于哪种状态：

Text DAT 的内容也可以直接在文本端口中编辑。把 Text DAT 拖到 Textport 上会给出以下选项：

  • Run DAT - 把「将该 DAT 作为脚本执行」的命令粘贴到 Textport 中。此选项仅在主 Textport 标签页中可用。
  • Open DAT - 在 Textport 的新标签页中打开该 DAT 的内容。可以点击对话框顶部附近的标签头在标签页之间切换。
  • Paste Text - 像其他 OP 一样粘贴该 DAT 的路径名。

此外，界面上任何位置选中的文本都可以拖到 Textport 上。

Shortcut: Textport History

在文本端口中任意位置右键点击，可调出最近命令的历史。按上方向键可向后翻阅命令历史，按下方向键可向前翻阅命令历史。

Textport Search

文本端口顶部的搜索字段可用于在文本端口的可滚动文本中查找字符串。

Textport History

在文本端口中处理 DAT 时，Textport 头部右侧会提供已查看 DAT 的历史。

在文本端口中工作的技巧

  • 按住 shift 点击文本端口中的文本，会选中光标与鼠标位置之间的文本，而不是只移动光标。

Textport 中的 Python

在文本端口中，输入 help 可得到可用命令列表，输入 help(object) 可查看任意 python 对象，例如 help(op('/project1').par.x)。

print() 命令的脚本错误和消息也会输出到该对话框。

主文本端口还会接收所有在 DATs 中运行的脚本的错误消息和 print() 命令。

不过启动和系统错误会输出到 Dialogs -> Console。

只需把任意 OP 拖到 Textport 上，就能省去输入 OP 路径名的麻烦。用鼠标左键把 OP 拖到 Textport 即可。


作为简单测试，在文本端口中输入以下内容：

help(op)

这会输出 td Module 中与该 op() 方法相关的所有帮助信息。

td Module 是包含所有 TouchDesigner 相关类和对象的主模块。应用启动时默认导入。
另一项有用的东西是 TDU Class。该对象包含一些在编写脚本时有用的 TouchDesigner 专用实用函数，可通过 tdu 对象自动获取。

文本端口中的 TScript

在文本端口中，输入 help 可得到可用命令列表，输入 exhelp 可得到可用表达式函数列表。也可以从 Help 菜单选择 Commands and Expressions 来访问 Tscript 命令和表达式。

echo 命令的脚本错误和消息也会输出到该对话框。

主文本端口还会接收所有在 DATs 中运行的脚本的错误消息和 echo 命令。

不过启动和系统错误会输出到 Dialogs -> Console。

只需把任意 OP 拖到 Textport 上，就能省去输入 OP 路径名的麻烦。用鼠标左键把 OP 拖到 Textport 即可。

textport 命令（仅 Tscript）

textport 命令用于操作 Textport 对话框。使用 textport 的优点之一是可以加载 DAT，而无需通过 Network 窗格导航到它们。例如，要在浮动 Textport 中加载一个 DAT，可以使用以下代码： 

 textport -l /datpath/datname

这在调试脚本或 monitoring network performance 时特别有用。
