Movin3D

MOVIN 是一家 3D 动作 AI 公司，开发实时的无标记动作捕捉解决方案。其旗舰产品 MOVIN TRACIN 是一款便携式 LiDAR 设备，无需标记、动捕服或专用影棚即可捕捉全身动作数据。MOVIN TRACIN 由设备端 AI 驱动，融合 LiDAR 点云与视觉数据，以传统光学系统成本的一小部分提供可用于制作的动作捕捉。

MOVIN TRACIN 通过配套桌面应用 MOVIN Studio（Windows）使用 OSC 将动作数据实时流式传输到 TouchDesigner。这让 TouchDesigner 用户可以用实时人体动作驱动实时视觉、灯光和声音——非常适合现场演出、互动装置和沉浸式体验。

MOVIN TRACIN 可在任何光照条件下工作，包括完全黑暗的环境，并且能抵抗 LED 墙、音频设备和广播设备产生的电磁干扰。

完整产品详情请见 MOVIN TRACIN 和 movin3d.com。

动作捕捉流式传输（OSC In CHOP）

MOVIN Studio 通过 OSC 流式传输骨骼关节旋转，TouchDesigner 可通过 OSC In CHOP 原生接收。通道名称编码了每个关节的路径和参数，因此将 Export Method 设为 Channel Name is Path:Parameter 的 Null CHOP 可以直接驱动角色绑定。

设置

1. Add an OSC In CHOP

在 TouchDesigner 项目中，从 CHOP 标签页添加一个 OSC In CHOP。将 Network Port 设为 11237（MOVIN Studio 用于 TouchDesigner 流式传输的默认端口）。

2. Add a Null CHOP

添加一个 Null CHOP 并将 OSC In CHOP 连接到它。在 Null CHOP 的 Common 页中，将 Export Method 设为 Channel Name is Path:Parameter。

3. Import the same character in both MOVIN Studio and TouchDesigner

将 FBX 角色文件导入 TouchDesigner 项目。然后将 same FBX 文件导入 MOVIN Studio。有关将角色导入 MOVIN Studio 的详情，请参见 MOVIN 文档中的 Import Custom Character。

重要： 在 TouchDesigner 中设置的 Node Name 必须与 MOVIN Studio 中配置的 Character Name 匹配。如果名称不匹配，实时流式传输将无法正常工作。

4. Configure and start streaming in MOVIN Studio

在 MOVIN Studio 中，打开 Streaming 标签页，选择 TouchDesigner 作为流式传输平台。确认端口号与 OSC In CHOP 中配置的一致（默认为 11237）。如果 TouchDesigner 运行在同一台机器上，将 Host 设为 127.0.0.1；如果通过网络流式传输，则设为 TouchDesigner 所在机器的 IP 地址。点击 Start Streaming。

5. Enable Export on the Null CHOP

回到 TouchDesigner，点击 Null CHOP 右下角的绿色圆形图标，启用 Export 标记。你应该会看到灰色虚线将 Null CHOP 与角色的关节连接起来，表示动作数据正在实时应用。

OSC 通道格式

MOVIN Studio 每帧为每个关节发送一条 OSC 消息。通道名称遵循以下模式：

/<CharacterName>/<JointName>:<Parameter>

例如，如果角色名为 myCharacter、关节为 Hips，通道将包含如下旋转值：

/myCharacter/Hips:rx
/myCharacter/Hips:ry
/myCharacter/Hips:rz

Null CHOP 的 Channel Name is Path:Parameter 导出方法使用此命名约定，将传入通道自动映射到 TouchDesigner 中角色层级上对应的关节变换参数。

点云流式传输（OSC In DAT + Python）

除骨骼数据外，MOVIN TRACIN 还可以将原始 LiDAR 点云数据流式传输到 TouchDesigner。由于点云数据更复杂（XYZ 位置数组及可选强度值），此工作流使用带 Python 回调的 OSC In DAT 将传入数据解析为可渲染的几何。

设置

1. Add an OSC In DAT

添加一个 OSC In DAT，将其 Network Port 设为 MOVIN Studio 中为点云输出配置的端口（请查看 MOVIN Studio 流式传输设置以确认正确端口——它与动作捕捉骨骼端口是分开的）。

2. Create a callback DAT

创建一个 Text DAT，并将其引用为 OSC In DAT 上的 Callbacks DAT。回调脚本解析传入的点云消息，并将其写入几何操作符可以使用的格式。

以下是一个示例回调，它接收点云数据并存储起来，供 Script SOP 或 Geometry COMP 使用：

# 用于 MOVIN 点云数据的 OSC In DAT 回调示例
# 将此 Text DAT 指定为 OSC In DAT 上的 Callbacks DAT

def onReceiveOSC(dat, rowIndex, message, bytes, timeStamp, address, args, peer):
    """
    Called for each incoming OSC message.
    
    The point cloud data arrives as OSC messages containing 
    arrays of float values representing XYZ positions.
    Parse these and store them for use in a Script SOP or
    other geometry pipeline.
    """

    # 用于点云地址模式的过滤
    if '/pointcloud' in address:
        # args 以扁平的浮点列表包含点云数据
        # 组织为 [x0, y0, z0, x1, y1, z1, ...]
        points = []
        for i in range(0, len(args) - 2, 3):
            x = args[i]
            y = args[i + 1]
            z = args[i + 2]
            points.append((x, y, z))
        
        # 存储点，供 Script SOP 或其他操作符访问
        op('pointcloud_storage').store('points', points)
        op('pointcloud_storage').store('num_points', len(points))
    
    return

3. Visualize with a Script SOP

使用 Script SOP（或 Script POP）读取存储的点并创建几何：

# 用于可视化 MOVIN 点云的 Script SOP 示例
# 将此放入 Script SOP 的回调中

def onCook(scriptSOP):
    scriptSOP.clear()
    
    points = op('pointcloud_storage').fetch('points', [])
    
    for pt in points:
        p = scriptSOP.appendPoint()
        p.x = pt[0]
        p.y = pt[1]
        p.z = pt[2]
    
    return

或者，可以将点云送入 Geometry COMP，并使用带点精灵材质的 Render TOP 进行渲染，实现实时可视化。

注意： 如需同时使用动作捕捉和点云流式传输的完整可运行示例，请下载下方 Sample Project 小节中链接的示例项目。

疑难解答

  • No data arriving in the OSC In CHOP — 确认 OSC In CHOP 中的端口号与 MOVIN Studio 中配置的端口一致。检查 Windows 防火墙是否阻止了连接。如果跨机器流式传输，请确保两者在同一网络上，并将 MOVIN Studio 中的 Host IP 设为 TouchDesigner 机器的 IP 地址。
  • Character does not move — 确保 Null CHOP 上启用了 Export 标记（绿色圆圈）。确认 TouchDesigner 中角色的 Node Name 与 MOVIN Studio 中的 Character Name 完全一致。
  • Skeleton appears distorted or broken — 确保 MOVIN Studio 和 TouchDesigner 中加载的是同一个 FBX 角色文件。文件不同或骨骼层级不匹配会导致重定向错误。
  • Point cloud data not appearing — 确认 OSC In DAT 设置为点云流式传输的正确端口（与动作捕捉端口分开）。检查回调 DAT 是否已正确引用，以及回调中的地址模式是否与 MOVIN Studio 发送的一致。
