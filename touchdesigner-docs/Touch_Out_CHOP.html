Touch Out CHOP

摘要

Touch Out CHOP 可用于在两个 TouchDesigner 进程之间建立高速连接。数据通过 TCP/IP 发送。Touch Out CHOP（服务器）把数据发送给 Touch In CHOP（客户端）。Touch Out CHOP 类似 Pipe Out CHOP，但针对 TouchDesigner 与 TouchDesigner 之间的通信做了高度优化。与其他软件或设备对接，见 Pipe Out CHOP。

要从另一台「服务器」计算机接收网络数据（例如从远程运行的 TouchDesigner Touch Out CHOP），必须在发送数据之前先在服务器与 Touch In CHOP 之间建立连接。你必须提供 Server Address 和 Port，以指明从哪个地址和端口把传入数据接收到通道。服务器应在此 CHOP 使用的端口上监听连接。多个 Touch In CHOP（客户端）可以从单个 Touch Out CHOP（服务器）接收数据。

NOTE for Windows OS - If experiencing connection issues make sure Windows Firewall is disabled.

参数 - Touch Out 页

Protocol protocol - 选择用哪种网络协议传输数据。不同协议的连接方式和地址参数的用法不同。详情参见 Network Protocols 文章。
  • Streaming (TCP/IP) streaming -
  • Messaging (UDP) msging -
  • Multi-Cast Messaging (UDP) multicastmsging -
Address address - 要使用的地址，并非所有协议都要求在发送端指定地址。
Network Port port - 要使用的网络端口。
Active active - 为 Off 时不发送数据。
Max Queue Size maxsize - 限制等待发送的事件数量。连接太慢时可防止溢出。
Max Queue Size Unit maxsizeunit - 为 Max Queue Size 参数选择 Samples、Frames 或 Seconds 作为单位。
Cook Every Frame cookalways - 指定无论其下方的 CHOP 是否在计算，该 CHOP 都应每帧计算。
Resend Names resendnames - 重新发送所有通道名。通常不需要用此参数，只是以备万一。
Use Synced Ports syncports - 如果需要，此参数让你通过单个全局管道发送数据。当多路数据流必须帧同步发送时，这可能很重要。详情参见 Touch In/Out Synced Ports。
  • Off off - 为每个分配的端口号使用独立端口。
  • On on - 对所有使用此 Transfer Port Type 的 Touch Out CHOP 使用单个全局管道。该全局管道内部使用端口 10500 一次性发送所有全局端口类型的数据。接收端仍用 Network Port 参数决定哪个 Touch In CHOP 获得数据。注意由于只用一个端口（10500），一台机器上只能有一个进程提供 Synced Port 数据。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Touch Out CHOP 的额外信息可通过 Info CHOP 访问。

Touch Out CHOP 的特定 Info 通道

  • connected -
  • num_clients -
  • queue_size -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
