COMP Panel 参数页

参数 - Panel 页

Panel 参数页控制面板属性，如显示开/关、启用开/关、面板帮助，以及与光标的交互。

Display display - 指定面板是显示还是隐藏。更改此参数可能会带来一些布局处理开销。对于叠加层等简单情况，调整 opacity 参数性能更好。
Enable enable - 允许你禁止对此面板的一切交互。
Help DAT helpdat - 允许指定一个 Text DAT 的路径，其内容将作为控件面板的悬停弹出帮助显示。
Cursor cursor - - 更改光标位于面板上时显示的光标。
  • Normal Select pointer -
  • Link Select linkselect -
  • Text Select ibeam -
  • Precision Select cross -
  • Busy busy -
  • Activate activate -
  • Invisible invisible -
Multi-Touch multitouch - - 启用后，此面板会以类似处理鼠标点击的方式处理它收到的第一次触摸，并更新 u、v、state 等。触摸事件必须从该面板发起。后续触摸会被忽略。如果此面板通过 Multi Touch In DAT 处理多点触控事件，可能需要禁用 Built-in Multi-Touch，以免干扰脚本处理。
  • Use Parent's Multi-Touch Settings mtouchparent - 使用父级的多点触控设置。在根组件中此项默认为启用。
  • Use Built-in Multi-Touch mtouchyes - 启用将第一次触摸用作鼠标。
  • Do Not Use Built-in Multi-Touch mtouchno - 禁用将第一次触摸用作鼠标。
Constrain Cursor constraincursor - 将光标限制在此面板内，进入后保持在其中。
Click Through clickthrough - 启用后，此 Panel Component 会忽略所有鼠标点击。
Use Mouse Wheel mousewheel - 开启后，捕获在面板上使用鼠标滚轮时的事件。
Mouse UV Buttons uvbuttons - - 允许指定哪些鼠标按钮更新 uv Panel Values。
  • Left uvbuttonsleft -
  • Middle uvbuttonsmiddle -
  • Right uvbuttonsright -
Relative UV mouserel - 启用后，uv Panel Values 会反映鼠标的相对移动。
Drag Edges to Resize resize - - 四个复选框可用于通过抓取相应的边缘或角来调整面板大小：Resize Left、Right、Bottom、Top。
  • L resizel -
  • R resizer -
  • B resizeb -
  • T resizet -
W Range resizew - - 限制左右（宽度）调整范围。
  • resizewmin -
  • resizewmax -
H Range resizeh - - 限制上下（高度）调整范围。
  • resizehmin -
  • resizehmax -
Drag to Reposition reposition - - 允许通过鼠标拖拽来重新定位面板或窗口。
  • Off off -
  • Window window -
  • Component component -
Component repocomp - 通过在 Reposition 参数中选择 Component 选项启用。指定要通过鼠标重新定位的面板组件的路径。
X Range repositionx - - 通过在 Reposition 参数中选择 Component 选项启用。设置面板组件水平重新定位的最大范围。
  • repositionxmin -
  • repositionxmax -
Y Range repositiony - - 通过在 Reposition 参数中选择 Component 选项启用。设置面板组件垂直重新定位的最大范围。
  • repositionymin -
  • repositionymax -
Anchor Drag anchordrag - - 当 Drag To Reposition 参数设为 Component，且面板的 Horizontal Mode 和/或 Vertical Mode 设为 Anchors 时，此菜单决定拖拽重新定位操作是更改 Anchor 值还是 Offset 值。
  • Anchors anchors - 拖拽重新定位操作会更改 Anchor 参数值
  • Offsets offsets - 拖拽重新定位操作会更改 Offset 参数值
Scroll Overlay scrolloverlay - - 控制面板是否受滚动条位置影响。这样可以创建不受面板滚动条影响的叠加面板。
  • Off off - 滚动条正常影响面板。
  • Ignore ignore - 滚动条移动时面板不移动。面板深度通常由 Depth Layer 参数决定。
  • Ignore and Draw Over ignoreover - 滚动条移动时面板不移动。面板绘制在滚动条和同级面板之上。
