ScriptPOP 类


此类继承自 POP class。 它引用一个特定的 Script POP。


它可以从 GeometryStagingData 对象构建 POP 几何。

另请参阅：POP Class、GeometryStagingData Class

方法

appendCustomPage(name)→ Page:

添加一页新的自定义参数。详情参见 Page Class。

示例： 

page = scriptOp.appendCustomPage('Custom1')
page.appendFloat('X1')

buildGeometry(geometryStagingData, forceCopy=False)→ bool:

分配属性内存和图元内存，并把暂存数据上传到 GPU。默认情况下暂存数据会被清除。

  • geometryStagingData - 定义要创建的几何的暂存信息。
  • forceCopy - （关键字，可选）若设为 True，函数会复制几何暂存数据而不清除它。

clear()→ None:

清除已构建的几何。

createGeometryStagingData()→ GeometryStagingData:

创建一个 GeometryStagingData 对象，用于保存中间几何定义。这是一个静态方法。

destroyCustomPars()→ int:

移除 Script POP 的所有自定义参数。返回被销毁的参数个数。

sortCustomPages(*pages)→ None:

重新排序自定义参数页。

  • pages - 按新顺序排列的任意数量页面名称

示例： 

scriptOp.sortCustomPages('Definition','Controls')
