Phaser POP

摘要

Phaser POP 的工作方式与 Phaser CHOP 类似。它对 POP 的某个属性做错开的（时间偏移的）动画插值。Phaser 输出一个新的属性 Phaser。每个点在一个周期内把 Phaser 从 0 动画到 1，但各点的值在不同时刻从 0 升起、到达 1。

输出属性范围 Phase 可用于混合或驱动下游其他属性的动画。如果 Phase Attribute Scope 是多分量的，则 Phase 也是多分量的。

Fraction 参数默认被钳制在 0 到 1 之间。Extend Input 菜单让你用小于 0 和大于 1 的数值控制 Fraction，产生不同效果。当 Fraction 超过 1 时：

  • Clamp - 默认且当前的行为 - 数值保持不变。
  • Cycle - Phaser 回到 0 状态，让输入时间在 0-1 之间循环
  • Mirror - Phaser 完全反向，让输入时间在 0-1 之间来回折返
  • Mirror Slope - 输入时间超过 1 后，第一个采样开始最先下降
  • Add - Phaser 输出的值在输入时间超过 1 后继续增大

Info CHOP 通道

Phaser POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
