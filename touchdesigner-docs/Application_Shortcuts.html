应用快捷键

有两种类型的 Shortcuts：

  • Panel Shortcuts，你为任何自定义构建的面板创建的，以及
  • Application Shortcuts（此处介绍），这些内置于 TouchDesigner 的创作界面中。

最重要的 Application Shortcuts（如 Designer Mode 中所述）有：

  • 空格键停止和启动时间轴。
  • 右方向键向前步进一帧。
  • 左方向键向后步进一帧。

（在 Panel Shortcuts 中按键不同。）

Application Shortcuts 在一个具有 3 列的 DAT 表格中定义：

  • 第 1 列：标签
  • 第 2 列：按键
  • 第 3 列：可选命令

覆盖快捷键

可以将可选的快捷键覆盖表添加到位于以下位置的文本文件中： app.preferencesFolder/TouchShortcuts.txt 如果该文件不存在，则当前未定义任何快捷键覆盖。

该文本文件的格式必须包含相同的 3 列，并在第一列中包含要替换的 Application Shortcut 的相同标签。 对于以 general 开头的 Application Shortcuts，不得修改第三列。

若只想在特定的 toe 文件中覆盖，且仅在 Perform Mode 下，可以锁定位于 /local/shortcuts 的 DAT，并按需编辑条目。

要完全禁用一个快捷键，保留该快捷键，只需将其对应的命令清空即可。
