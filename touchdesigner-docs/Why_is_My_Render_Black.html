渲染为何全黑

常常你的Render TOP全黑，而你本以为那里会显示东西。以下是一些可以尝试的方法，用来找出为何看不到预期内容。

  • 检查是否有东西正在渲染：前往 Edit -> Preferences 的 TOPs 页，将 Viewer Background 设为显示 Checker Board 作为背景（而非 Black）。
    • 然后在 Render TOP 中，如果你看到全是棋盘格，则那里确实没有渲染任何东西。如果是黑色，则有东西在渲染，但没有被照亮。
    • 添加一个灯光，并确保它位于几何体前方。
    • 将对象的材质改为带有 Emit 颜色或 Ambient 颜色。或将 Material 改为默认白色的Constant MAT。
  • 也许几何体在摄像机视野之外。将 Render TOP 的 Render Mode 参数改为 Cube Map。这样可以查看各个方向。如果在 Cube Map 渲染中也看不到东西……
  • 接下来要看摄像机的 Near 和 Far 裁剪平面。在你的Camera COMP中，Near 和 Far 参数是否设为了包围 3D 几何体的合理值？对于摄像机距离超过 1000 的大场景，几何体可能位于近/远裁剪平面之外。
  • 接下来该检查渲染的是什么了……
  • 检查 Render TOP 的 Geometry 参数。它应有一个能匹配所有预期渲染对象的模式。为确保全部捕获，可在 Geometry 参数中填入 “*”。如果仍然什么都看不到……
    • 检查你渲染的是否为 Geometry 组件。在预期可见的 Geometry 组件上，确保其 Render 标记已开启（紫色）。
    • 这还不够。Geometry 组件还有一个 Render 参数。确保 Render 参数已开启。
    • 这仍然不够。对于每个Geometry COMP，在组件内部，确保你预期渲染的网络中所有 SOP 在节点底部都开启了 Render 标记。
    • 如果你都做了却仍看不到东西，请检查你预期看到的 SOP：
      • 中键单击以查看该 SOP 的信息。包围盒是否如你所预期？
        • 检查是否存在点颜色或顶点颜色，尤其是确保 alpha 没有设为 0，或整体为黑色。
        • 查看 SOP 中数值的一种方法是把该 SOP 连接到 “SOP to DAT” 操作符，查看不同的列。有时为 0 的法线会导致黑色结果。
      • 如果仍然什么都看不到，请在网络中放一个 Sphere SOP 并开启其 Render 标记（以及 Display 标记，以便在摄像机查看器中看到它）。
  • 灯光要产生效果，灯光上的 display 标记必须开启。
  • 确保对象材质的 Alpha 参数设置不为 0。
  • 确保带纹理贴图的材质中，纹理的 alpha 不为 0。可用白色的 Constant TOP 替换你的纹理。
  • 灯光/摄像机不能嵌套在Base COMPs中，因为 base 会把它们排除在Geometry Viewer之外。
  • 也可能是因为几何体查看器的网络路径所处层级看不到所有灯光。
  • 你可能想用默认的 Camera COMP 替换 Render TOP 正在使用的摄像机。
  • 可以试试新建一个空的 Render TOP，然后加入你预期看到的对象/摄像机。也试试创建默认的 GeometryCOMP、默认的 Light COMP。
  • 其他方面……Back-Face Culling、Render TOP 上的 Blend Modes（虽然可能性不大）
