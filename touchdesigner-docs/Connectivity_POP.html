Connectivity POP

摘要

Connectivity POP 用于用一组新的图元重新连接输入的点，类似于 Grid POP 或 Torus POP 对其点集所做的。它适用于任何 POP，尤其是那些组织为多 Dimensions 的 POP，即具有行、列、切片和任意数量维度的 POP。

与 Grid POP 一样，你可以在任意维度上用 line strip 连接点，或在任意两个维度上用三角形或四边形网格连接点，也可以把它们留作点图元或不用图元。

它通常负责处理传入 POP 的点排布，并提供更多种 line strip 连接方式，例如点的锯齿形或螺旋形连接。

另请参阅 Torus POP、Dimension POP、Dimension、Grid POP、Plane POP

参数 - Connectivity 页

Connectivity surftype - - 确定用于连接点的图元。
  • None none -
  • Point Primitives points -
  • Lines lines -
  • Line Strips linestrips -
  • Line Strip per Plane linestripperplane -
  • Zig Zag per Plane zigzagperplane -
  • Spiral per Plane spiralperplane -
  • Triangles triangles -
  • Alternating Triangles alttriangles -
  • Quadrilaterals quads -
(First) Dimension Index firstdim - 选择维度索引。对于需要两个维度的模式，选择第一个维度索引。
Second Dimension Index seconddim - 第二个维度的维度索引。
(First) Dimension Closed firstdimclosed - 在第一个维度上启用环绕。
Second Dimension Closed seconddimclosed - 在第二个维度上启用环绕。
Reorder Points by Prim/Vertex Order reorderpoints - 按图元或顶点引用顺序重排点。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Info CHOP 通道

Connectivity POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
