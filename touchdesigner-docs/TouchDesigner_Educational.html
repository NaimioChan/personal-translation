TouchDesigner 教育版

TouchDesigner Educational and Commercial

TouchDesigner Educational 与 Commercial 的功能集完全相同，只是预期用途不同。


Educational

面向学生和学校，non-commercial and educational uses only 提供。（准确地说，「你不会因使用 TouchDesigner 的工作而获得金钱或报酬」）

学生和学校管理者必须注册 Educational 许可证，并经 Derivative 批准后才能购买该许可证。Register Here

  • 普通 Educational 许可证每份 300 美元。可与 Key Manager Dialog 或 License Dongle 一起使用（不含）。
  • Floating Cloud Commercial 许可证每份 450 美元
  • 在 STORE 中购买 TouchDesigner Educational。
  • Volume Discounts 可用于 TouchDesigner Educational。

关于在教育机构中设置 TouchDesigner 的更多信息，另请参阅 Educational Setup。

Commercial

Commercial（或 Pro）许可证是 required for any project or work done with TouchDesigner that you receive money or compensation for。

示例包括：a）你在做有报酬的项目；b）你用 TouchDesigner 推广自己的作品以创造收入；c）你或团队使用多台计算机制作大型商业项目的各部分。在所有这些情况下，这些项目所用的所有计算机都需要 Commercial 许可证。

  • 普通 Commercial 许可证每份 600 美元。可与 Key Manager Dialog 或 License Dongle 一起使用（不含）。
  • Floating Cloud Commercial 许可证每份 900 美元
  • 在 STORE 中购买 TouchDesigner Commercial。

解锁的功能

  • 以硬件支持的任意分辨率进行图像分辨率与合成
  • 实时创建 H.264/H.265 影片（需要 Nvidia GPU）
  • 使用 Video Stream Out TOP 通过 RTSP、RTMP 或 SRT 流式传输纹理（需要 Nvidia GPU）
  • 最多 2 个以 1920x1080 运行的 Notch 操作符（需要 Notch 许可证）
  • LIDAR 扫描仪 Ouster TOP
  • 激光扫描仪 Leuze ROD4 CHOP
  • 所有 Shared Memory 操作符
  • 向 DirectX 应用发送 send 和 receive 纹理
  • 在其他应用中使用 TouchEngine
  • 可选择在启动时隐藏 TouchDesigner 启动画面
  • Commercial 许可证对应一台计算机的一个商业密钥
  • 密钥可以在计算机之间移动
  • 不包含任何直接支持，仅提供 forum 支持

另请参阅 TouchDesigner Pro
