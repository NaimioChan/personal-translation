Cooking 标记

Cooking 标记仅适用于组件。当 Cooking 标记开启时，它会禁用 component 内部网络的计算。它也称为 Cook 标记或 Cooking Off 标记。

不计算时，内部节点不会改变，其输出数据保持不变，数据占用的 CPU 和 GPU 内存也不变。唯一的区别是关闭计算后没有节点会计算，耗时为 0 毫秒。当你重新加载包含设置了 Cooking Off 标记的 COMP 的 .toe 或 .tox 文件时，其中节点的输出为空且未定义。

示例： 

op('/project1').allowCooking = True

如果组件关闭了计算，从外部脚本设置参数、表格值、重新连接组件内部节点的连线通常仍然有效，但不建议这样做。

另请参阅 Flag。
