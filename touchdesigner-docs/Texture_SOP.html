Texture SOP

摘要

Texture SOP 为源几何赋予纹理 U、V 和 W 坐标，供纹理映射和凹凸映射使用。它会生成多层纹理坐标。

textureSOP_Class

修正接缝与展开几何

注意： 以下讨论仅适用于面和外壳图元。

如果某种纹理类型需要修正接缝，且纹理应用到顶点，则在计算纹理坐标之前会先展开环绕的图元。展开环绕图元会把它变成开放图元，其新顶点使用它们从中唯一化出来的那些相同的点。因此展开不会改变点数，也不会让后续出现裂缝。无需使用 Primitive SOP 显式展开。

接缝修正是在计算纹理坐标之后进行的。无论纹理应用到顶点还是点都需要它，并且它是在 u、v 或两者上进行的。

以下纹理类型需要修正接缝：

  • Cylindrical - 在 u 上修正接缝。
  • Polar - 在 u 和 v 上修正接缝。
  • Row/col - 在 u 和 v 上修正接缝。
  • Spline types：Uniform、Chord Length 和 Average - 在 u 和 v 上修正接缝。

注意： 当投影类型为 Cylindrical 或 Polar 时，闭合网格、Bzier & NURBS 曲面会被打开。至少会添加一行/一列顶点（NURBS 可能更多）。这是为了防止接缝处纹理坐标插值不佳。

参数 - 页

Primitive Group group - 如果有输入的图元组，在此字段中指定组名会使此 SOP 只作用于指定的组。对点组或顶点组无效。接受模式匹配，如 Pattern Matching 所述。

参数 - Texture 页

Texture Layer texlayer - 如果几何上应用了多个纹理层，此参数决定此 Texture SOP 会影响哪一层 UV 坐标。
Texture Type type - Face、Uniform Spline 和 Arc-Length Spline 纹理化方法既接受多边形，也接受样条曲线。

使用基于样条的方法之一时，在 Group 字段中指定粘贴层级会把纹理坐标的计算传播到它的所有节点。投影方法在粘贴曲面之间通常比任何样条方法都能得到更平滑的纹理连续性。有时用 Basis SOP 确保粘贴的部分按弦长参数化会有帮助。

  • Orthographic texture - 从 Projection Axis 直接投影。
  • XYZ Position xyzposition - 顶点的 XYZ 位置会被复制到 UVW 值中。
  • Equirectangular Inside (Spherical Polar) equirectangularin - 应用坐标，以正确地把等距柱状（equirectangular）纹理贴图应用到物体内部。例如适用于天空盒。
  • Equirectangular Outside (Spherical Polar) equirectangularout - 应用坐标，以正确地把等距柱状纹理贴图应用到物体外部。
  • Cylindrical cylin - 沿 Projection Axis 方向进行柱状包裹。
  • Row & Columns rowcol - 用于以网格方式构建的几何（Grid、Sphere、Tube、Skin 和 Sweep）。U 坐标沿行排列，V 坐标沿列排列。这适合为汽车挡泥板之类无法从任一轴投影的弯曲网格贴图。
  • Face face - 把纹理的副本映射到每个面上。在 Texture SOP 中使用此功能之前，应先用 Facet SOP 使点唯一化。贴图会沿每个面的法线以图形方式投影到该面，因此每个面的纹理朝向都正确。但是，贴图不会缩放以适应每个多边形，也不会因每个多边形的形状而变形。如果几何在物体空间中尺寸变化，纹理不会「粘」在几何上。它最适合为岩石块和砖块之类的物体贴图，因为纹理在多边形之间的边缘处很可能对不上。
  • Modify Source modify - 如果源几何已有纹理 UV 坐标，则保留它们。不过你可以用 Scale 和 Offset 对它们进行偏移和缩放。
  • Uniform Spline suniform - 此投影类型仅作用于 NURBS 和 Bzier 曲面。它在 U 和 V 上均匀采样每个曲面的域空间（即基），并把这些 (u,v) 值作为纹理坐标赋给曲面点或顶点。为确保相邻曲面的纹理空间之间连续，可在 Texture SOP 之前插入 Basis SOP，并打开 Concatenate 以合并 U 和/或 V 方向的样条基。
  • Average Spline saverage - 把 degree 个连续节点的平均值存入纹理属性。这些平均值称为 Greville points。此方法和 Uniform Spline 推荐用于粘贴曲面。
  • Arc Length Spline sarclen - 此方法类似 Uniform Spline 方法，因为它在计算纹理坐标时依赖底层的样条基。两种方法生成的纹理坐标范围相同，以最小和最大节点值为界。两种样条方法的区别在于相邻纹理坐标之间的间距。uniform 方法均匀采样参数空间。Arc-Length Spline 方法则依据曲面弧长来选择纹理坐标。

由于 Uniform Spline 方法严重依赖曲面的参数结构，在曲面参数化不均匀时，生成的纹理会趋向于挤压和拉伸。Arc-Length Spline 方法把纹理空间直接关联到曲面的世界空间，同时确保生成的纹理空间的尺寸和原点与底层域一致，从而减轻这一影响。

  • Edge Length edgelength - 适用于外壳 + 面（NURBs/Bezier/Polygon）。
  • Perspective From Camera persp - 赋予纹理坐标，使物体的世界空间能精确贴合摄像机的投影来贴图。如果任何点位于近裁剪面之后或超出远裁剪面，则赋予纹理坐标 0, 0, 0。注意：除非在 Camera COMP 中使用 Custom Projection 矩阵，否则投影的宽高比按 1:1 假设。你可能需要缩放 UV 以匹配渲染的宽高比。
  • Equidistant Azimuth (Fish Eye 180) equiazimuth - 应用使用 180 度鱼眼贴图的坐标。
  • Equidistant Azimuth (Fish Eye 360) equiazimuth360 - 应用使用 360 度鱼眼贴图的坐标。
Projection Axis axis - 投影所沿的轴，或来自样条的投影方法。X、Y 或 Z 轴。

  • Y Axis y -
  • Z Axis z -
Camera Name camera - 在选择 Perspective From Camera 纹理类型时使用。此菜单用于选择从哪个灯光或摄像机投影透视坐标。
Apply to coord - 选择把纹理坐标应用到 Natural Location、点纹理还是顶点纹理。

选择 Natural location 时，使用 Polar、Cylindrical、Rows and Columns 和 Face 纹理类型会把 UV 应用到顶点上。当你选择 Natural 时，Orthographic、Uniform Spline、Average Spline 和 Arc Length Spline 始终生成点 UV。

在创建新的纹理层时，如果第 0 层已存在顶点 uv，Natural Location 也会创建顶点 uv。

如果图元在两个方向上都是开放的，例如网格或曲面（两端不相接），那么顶点 UV 的优势就不适用，因为单一曲面上没有需要担心的匹配接缝。

使用顶点 UV 时，闭合接缝处会得到唯一的点；而点 UV 在接缝处是共享的，默认根据曲面的闭合方向给 U 或 V 赋 0 值。如果想让闭合曲面变为开放，只需在链路中插入 Carve SOP，并在曲面闭合的方向上放置一个 carve。

Info CHOP 通道

可以通过 Info CHOP 访问 Texture SOP 的额外信息。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
