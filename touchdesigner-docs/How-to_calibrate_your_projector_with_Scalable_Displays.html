用 Scalable Displays 校准投影仪

概述

TouchDesigner 包含 Scalable Display TOP，它让你读入从 Scalable Display Manager 软件获取的校准数据

要求

  • 一台计算机，称为校准机，运行 Scalable Display Manager 软件，且不是输出机。它可以是任何运行 Microsoft Windows XP 或更新版本、配有支持 OpenGL 显卡的计算机。
  • 一台 Logitech C920 摄像头、Canon Rebel 系列或千兆以太网相机
  • 数量不限的计算机，称为客户端机，运行 Scalable Display Client 软件并连接投影仪
  • 一份来自 Scalable 的许可证，与你的具体需求相匹配。有关许可的信息，请联系 Scalable。

Scalable Display Manager

Scalable Display Manager 软件让你创建「Scalable Mesh Files」，以处理跨数量不限的计算机和投影仪的变形与融合。 生成的文件可供 Scalable Display TOP 使用，以对 TouchDesigner 的图形输出进行变形与融合。

Scalable Display Client

Scalable Display Client 软件需要安装在所有用于最终输出的机器上，并在校准过程中使用。

校准流程

在校准机上，首先确认 Scalable Display Manager 已安装、已获许可，并连接了一台能拍到整个投影仪输出区域的相机。

在客户端机上，确认 Scalable Display Client 软件已安装。断开客户端机上不用于输出的所有显示器，并确认所有已连接的投影仪以相同分辨率运行。

在校准机上启动 Scalable Display Manager 软件，按照步骤校准投影仪。

Step 7 - Finish

校准成功后，Scalable Display Manager 会将校准数据分发到所有已连接的客户端。

在客户端上，校准文件保存在 Scalable Display Client 的安装文件夹中，通常类似 C:/Program Files/Scalable Display/DEI/LocalCalibration/

该文件夹将包含若干文件，名称为：

  • ScalableData
  • ScalableData.ol
  • ScalableData.ol.AlphaPrecursors
  • ScalableData.pol
  • ScalableDataOrthogrpahic
  • ScalableDataOrthographic.ol
  • ScalableDataOrthographic.ol.AlphaPrecursors
  • ScalableDataOrthographic.pol
  • InputBoundaryMask-blend.bmp

Step 8 - Setup TouchDesigner

在 TouchDesigner 中，按客户端机上连接的投影仪数量，将相同数量的 Scalable Display TOP 连接到你的输出图像。选择 ScalableData 或 ScalableDataOrthographic 文件。 这些文件带有「_x」后缀，其中 x 是输出的编号，因此请将文件与你的 Scalable Display TOP 对应。 要匹配投影仪的输出分辨率，将 Scalable Display TOP 的 Output Resolution 参数设为「Custom Resolution」，并在 Resolution 参数中输入投影仪的输出分辨率。同时将 Output Aspect 参数改为「Resolution」。

A Support Case Note for using Orthographic Calibration Files

案例 - 投影厅是 3 面墙加 1 个地面投影。TOP 内容网络将每个投影仪图像放在各自的 TOP 通路中，4 条 TOP 通路分别对应每台投影仪的分辨率。所有投影仪分辨率相同。使用正交校准文件时，需要将 4 个单独的 TOP 图像按左墙、中墙、右墙、地面的顺序水平堆叠进一个 Layout TOP。因此 layoutTOP 的输出分辨率是投影仪分辨率横向 ×4。这个水平堆叠 4 倍的 layoutTOP 输出给每个 scalable TOP，而每个 scalable TOP 都设为单台投影仪的分辨率。每个 scalable TOP 加载各自的正交校准文件。

对于透视校准文件则不需要这种堆叠，每个单独图像可以直接送入各自的 ScalableTOP。
