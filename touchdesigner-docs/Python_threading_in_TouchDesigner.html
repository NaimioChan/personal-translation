TouchDesigner 中的 Python 线程

使用线程很有挑战性，而在 TouchDesigner 中使用线程则更为困难。

需要克服的主要障碍是 TouchDesigner 主线程必须持续运行，该主线程负责运行用户界面，时间轴的前进和帧的生成都依赖它。

阻塞主线程会导致丢帧，更糟的是可能让 TouchDesigner 挂起或崩溃。

一条通用经验法则是，避免从其他线程访问 TouchDesigner 主线程上的对象，无论是读取还是写入。

有一些方法可以在次级线程中使用 Python 自带的线程库，从而可以使用 while 循环和其他阻塞方法。这通常涉及一个 Execute DAT，它每帧检查线程状态并将对象出队。

从 TouchDesigner 2023.31500+ 起，TouchDesigner 包含 Thread Manager。

Thread Manager 为 Python 开发者简化了 TouchDesigner 中的线程和任务处理。 高级用户可以使用 op.TDResources.ThreadManager 直接访问 Thread Manager COMP。另外，想要更简单的基于组件方式的用户，可以查看 Palette 的 ThreadManager 文件夹中提供的 Thread Manager Client。它是一个简单的面向回调的组件，封装了 Thread Manager。

此外，还有各种调试工具可用，例如具有高级日志功能的 Threads Monitor COMP。Thread Manager 设置可以在 Threads Monitor COMP 中调整。
