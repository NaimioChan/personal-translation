非茗的翻译文档库

术语表

.toe
TOuch Environment 文件，TouchDesigner 用来保存整个项目的文件类型。
.tox
TouchDesigner Component 文件，用于保存 TouchDesigner 项目中某个 Component 的文件类型。
3D 纹理
2D 纹理数组或 3D 像素网格。
绝对时间
absTime
绝对时间从 TouchDesigner 进程启动时开始从 0 计数，并且始终递增。如果 UI 顶部的 Power 0/1 按钮为 Off，或根时间轴暂停，它也会暂停。
Adaptive Homing
在 Geometry COMP 或任意 POP 的 Node Viewer 中，Adaptive Homing 选项会让正在显示的 3D 几何始终保持可见，即使几何改变了形状、大小和动画位置。
Adaptive Homing
在 Geometry COMP 或 POP 的 Node Viewer 中，Adaptive Homing 选项会让正在显示的 3D 几何保持可见。
注释
注释
注释在 Network Editor 中显示为包含用户编写的文本和图形的彩色矩形。它基于 Annotate COMP，让你可以用注释和节点分组等有用信息来记录你的网络。
数组属性
数组属性是带有多个 elements、类型为所选 Attribute Data Type 的 Attribute，例如由 12 个整数构成的属性。
属性
属性构成 POPs 的数值数据块。每个 POP 有三块数据：包含 P 点 Position 属性的 Point List、Primitive List 和 Vertex List，每一块都由任意数量的属性构成。
背景
背景是 Network 后面可见的节点查看器网格，通过开启 Display Flags 以及网络中的 RMB -> Display... Backdrop OPs 来设置。
绑定
绑定是一种 Parameter Mode，把两个或多个参数的值系在一起，改变其中任一已绑定参数的值都会改变所有参数。实际值只存储在一个地方。
书签
网络 Pane 顶部的一个下拉列表，包含用于跳转的 Network Paths。
旁路
Bypass 标记
设置了 Bypass 标记的操作符不做任何事：进入其第一个输入的所有数据都会不受影响地出现在输出端。
回调
有些操作符附带一个 DAT docked，其中包含一些 python 函数。这些函数称为 "callbacks"（回调），会在操作符中某些内容改变时被调用。
通道
CHOP 输出一个或多个通道，通道就是一串数字（Samples），表示运动、音频等。通道在 TouchDesigner 网络中的 CHOP 之间传递。通道可以 Exported 到 Parameters。
CHOP
通道操作符
一种 Operator Family，作用于 Channels（一串数字（Samples）），用于动画、音频、数学、模拟、逻辑、UI 构建，以及从设备与协议流入/流出的数据。
克隆
克隆让多个组件与主组件的内容保持一致。设置了 Clone 参数的 Component 会被强制包含与其主组件相同的节点、连线和参数。克隆不会像 Replicator COMP 那样创建新组件。
组件
COMP
包含自身 Network 的 Operator Family。共有十六种 3D Object Component 和十种 2D Panel Component 类型。另请参阅 Network Path。
连接器
每个 Node 左右两侧的缺口，让你可以把一个 Operator 的输出 Wire 到同一 Operator Family 中另一个的输入。3D Object Components 和 Panel Components 上下两端的缺口，把 Hierarchy 中每个子 Family 的组件连在一起。
容器
Container 组件类型是一种 Panel Component，可容纳、布局并显示任意数量的其他 Panel Component。
计算
重新计算 Operators 的输出数据。操作符会在以下情况计算：(1) 其输入改变，(2) 其 Parameters 改变，(3) 某些情况下时间轴向前移动，或 (4) 对该节点运行 Scripting 命令。当操作符是 Panel Component 时，用户与它交互时也会计算。操作符计算时，通常会使其输出端连接的操作符重新计算。TouchDesigner 绘制屏幕时，会重新计算所有 Dependencies，即所有 Networks 中必要的操作符，它们共同构成一帧的总「计算时间」。
DAT
数据操作符
一种操作文本字符串的 Operator Family：多行文本或表格。多行文本通常是 python Script 或 GLSL 着色器，但也可以是任意多行文本。Tables 是若干行与列的单元格，每个单元格包含一个文本字符串。
依赖
是 TouchDesigner 中的 Procedural 机制：当某份数据改变时，会自动使其他操作符和表达式重新 Cook。
依赖
可依赖
适用于 python 对象、参数、节点。
Designer Mode
你在 Designer Mode 中编辑网络。参见 Perform Mode。
对话框
任何不是 Pane 或 Viewer 的浮动窗口。
维度
维度是 POP 的元数据，描述点列表的结构，点可以按行和列排列（即大小为 nrows 和 ncolumns 的两个维度）。
Display 标记
Geometry 组件和 SOP 操作符上的蓝色 flag 决定该操作符中包含的几何是否在节点查看器和几何查看器窗格中可见。参见 Render Flag。
停靠
已停靠
任何 node 都可以停靠到另一个节点。这有助于整理网络，因为停靠在一起的两个节点在停靠父级于网络编辑器中移动时会一起移动。已停靠的节点可以折叠为停靠父级下的小图标，减少网络杂乱。
事件
事件是由各种条件产生的单时刻发生的事——来自用户造成的输入动作、来自外部设备与软件，也来自 TouchDesigner 内部状态。多种操作符类型会响应事件，并为用户提供编写响应事件 python 代码的位置。
导出
导出是把 CHOP 通道连接到操作符的参数。每个执行导出的 CHOP 的输出是一个或多个通道，仅在 CHOP Viewer 开启时有效。通道的当前值可以导出到任意操作符的参数，覆盖该参数的值。参见 Parameter。
表达式
包含数据（字符串、浮点数、列表、布尔值等）和运算符（+ * ＜ 等）的文本字符串，由节点的语言（python 或 Tscript）求值，并返回字符串、浮点列表或布尔值等。表达式用于参数、DATs 和脚本中。
扩展条件
扩展区域
在 CHOP 中，Extend Conditions 决定当你尝试获取超出通道起止范围的通道值——即在其扩展区域中——时会得到什么数字。
扩展
任何组件都可以用自己的 Python 类来扩展，这些类包含 python 函数和数据。
文件元数据
读写不同类型的文件元数据。
Filter
在 TouchDesigner 中，需要 1 个或多个输入的操作符称为 Filters，例如 Math CHOP。参见 Generator。
逐采样过滤
CHOP 的一个强大特性，可随时间过滤，例如 Lag CHOP 和 Filter CHOP，其中每个采样充当自己的过滤器。
标记
表示操作符某些状态的指示（Bypass 标记、Render 标记、Lock 标记、Viewer Active 标记）。
Folder
在 TouchDesigner 中，Folder 始终指 Windows 或 macOS 操作系统中包含文件和其他文件夹的目录/文件夹系统。它不指 TouchDesigner 内部的操作符。参见 Network Path。
帧
「Frame」这个术语是用于计时的度量，(1) 在 Timeline 中，(2) 作为 CHOP 中的时间单位，(3) 作为读入 TOPs 和从 TOP 写出的影片文件中的时间单位。Frame Rate 是每秒帧数（FPS）。
帧率
FPS
TouchDesigner 的 Timeline 运行时的每秒 Frames 数。用 project.cookRate 设置。
生成器
在 TouchDesigner 中，不需要连接任何输入的操作符称为 Generators，例如 Pattern CHOP。参见 Filter。
几何
保存在 POP 中并由 Geometry COMP 传递用于渲染的 3D 数据。
几何电子表格
目前，使用 SOP to DAT 查看 SOP 点/多边形的 XYZ 及其他属性。以前是一种 Pane 类型。
几何查看器
用于交互式查看和操控 3D 场景或对象的 3D 视口。几何查看器可在 Panes（任意窗格中按 alt+3）或所有 Geometry Object 组件的 Node Viewers 中找到。
Global OP Shortcut
组件的名称，可从项目中的任意节点访问，可在组件的 Global Operator Shortcut 参数中声明。
GPU
图形处理器。这是显卡/芯片上高速的多核处理器，接收来自 CPU 的几何、图像和数据，并生成图像和处理后的数据。
组
POP 和 SOP 中的组是点或图元的命名子集。可用 Group POP 或 Group SOP 创建。POP 和 SOP 中的许多操作（使用 Group 参数）可以限制为只影响所选组中的点或图元，而不影响其他。
层级
层级把组件与其他组件关联起来。TouchDesigner 中有两组层级：3D Object 组件和 2D Panel 组件。层级让一个组件可以相对另一个组件定位。每组都可以通过网络中节点底部/顶部之间的连线连接，或把一个组件放在另一个组件内部。
免疫
每个节点都有一个 Immune Flag，当它开启且节点位于 Clone 内部时，节点不受克隆主级任何改变的影响，因此你可以在克隆中存储额外数据，或让某个节点被克隆过程忽略。
索引与 ID
索引是点在点列表中的位置，不是属性。ID 通常是用于粒子的属性，没有顺序、值唯一，并且可以复用。
输入块
接受无限输入的 POP 每个输入有一个 seq 参数块。一个输入可以是一组 OP 模式。
实例
(1) Geometry Component 可以多次实例化并渲染其 SOP 几何：对 CHOP 的每个采样、DAT 表格的每一行、TOP 的每个像素或 SOP 的每个点各一次，(2) 实例是一种没有自己数据、只引用某个 OP（或有输入）并使用其数据的 OP。这包括 Null OP、Switch OP，以及某些情况下的 Select OP。
内部操作符
内部操作符（iOP）为常用操作符提供简单的快捷方式，可从该组件内任意位置访问。
内部参数
内部参数（iPar）像组件中的局部变量。它们为你可在组件内创建、并从该组件任意位置访问的参数集合提供简单的快捷方式。
互操作性
互操作
TouchDesigner 通过原生 Operators 和 Palette 组件与之对接的设备、协议和软件工具。
快捷键
快捷键有两种：TouchDesigner 创作界面内置的 Application Shortcuts，以及你为任意自定义面板创建的 Panel Shortcuts。
关键帧
在 Animation component 中，每个关键帧指定通道在特定时间（或帧）的值。关键帧包含值、斜率和加速度，以及插值类型。通道的关键帧用于插值并确定该通道所有采样的值。
布局
(1) TouchDesigner 窗口由顶部的菜单栏、底部的 Timeline，以及中间可选的某种 Layout 组成。一个 Layout 由一个或多个 Pane 构成，每个 Pane 可以包含 Network Editor、Viewer、Panel 等。参见 Pane 和 Bookmark。(2) 网络中的节点通过 RMB 菜单中的 Layout 命令排列。
线段带
POP 中一种具有 1 个或多个相连点的图元。
链接
引用
Link 或 Reference 是节点之间的虚线，表示节点之间流动的其他数据。例如 CHOP Exports、参数中的节点 Paths，以及参数中引用 CHOP 通道、DAT 表格和其他节点的 expressions。与此相对的是在同一 Operator Family 中连接节点的 Wire。
Lock 标记
操作符被锁定时不会 cook，其输出数据保持冻结，即使把 TouchDesigner 会话保存为 .toe 文件并重新启动也是如此。
宏
F1 到 F12 键运行宏。F1 宏让你进入 Perform Mode。在面板上按 F9 或 F10 会弹出你所指面板元素的网络。宏用旧版 Tscript 编写。
把点属性映射到参数
在某些 POP 的某些参数上，可以通过参数对话框中的 Map 页把其某个 Attributes 映射到参数，从而为 POP 的每个点设置不同的参数值。
MAT
材质
MAT 或材质是一种 Operator Family，把 Shader 应用到 SOP 或 3D Geometry Object 上，以渲染带光照的纹理表面。
菜单栏
位于 Designer Mode 界面顶部、包含菜单、链接、状态消息和其他控件的栏。
多点触控
多点触控
TouchDesigner 中支持多指或控制点输入的显示设备。
网络
每个组件都包含一个由操作符组成的网络，用于创建和修改数据。操作符之间由连线连接，连线定义操作符计算其输入并生成输出后数据流向何处。
网络编辑器
一种窗格类型，可在其中创建和编辑操作符网络。
节点
承载 Operator 的通用事物，包含 Flags（display、bypass、lock、render、immune）以及其在网络中的位置/大小。无论你说「放置一个 Operator」还是「放置一个 Node」，做的都是同一件事。
节点查看器
Network Editor 窗格中每个操作符上都有查看器。点击 Viewer Flag 即可开启此查看器。
法线
共享点、共享点上的法线、唯一点、重新计算。
对象
3D 对象
对象空间
用于定义和渲染 3D 场景的 Component 类型中的子 Family。Geometry Component 是一种包含要渲染的 3D 形状的 Object。Camera COMP 和 Light COMP 是其他 Object 类型。另外，"Objects" 也指 Python 对象。
OP 创建菜单
用于选择并创建新操作符的菜单。在 Network Editor 中按 Tab 键或双击背景，或点击操作符输出连接器上的 MMB 或 RMB，或点击 Pane Bar 中的 + 号，即可打开该菜单。
OP
操作符
任意一种程序化数据操作符。OP 在 TouchDesigner 中承担所有工作。它们「计算」并把数据输出到其他 OP，最终生成新的图像、数据和音频。参见 Node。
操作符族
族
操作符族包括 TOPs、CHOPs、POPs（Point Operators）、MATs（Materials）、DATs（数据操作符）、SOPs 和 Components（Panel Gadgets and Objects）。
Palette
TouchDesigner 中的内置面板，包含可拖放到 TouchDesigner 网络中的组件和媒体库。
窗格
TouchDesigner 布局中的工作区域，包括 Network Editor 以及另外 7 种用于不同任务的窗格类型。TouchDesigner 界面可以由单个窗格组成，也可以拆分为多个窗格。
窗格类型
共有 8 种窗格类型；Network、Panel、Textport、Geometry Viewer、TOP Viewer、CHOP Viewer、Parameters、用于 CHOP 通道的 Graph Editor，或 Geometry Spreadsheet。
Panel Component
用于创建自定义交互式 2D 控制 panels 的 Components 子 Family（Container、Widget、Text COMP Slider、Button 等）。
面板值
面板组件的内部状态就是 Panel Values，可通过 Panel CHOP、OP.panel Python 表达式或 Panel Execute DAT 访问。
面板
控制面板
在 TouchDesigner 中构建的自定义交互式控制面板。面板用 Panel Components 创建。
参数
TouchDesigner 中每个操作符都有一组控制参数，可以是整数或浮点数、菜单、二值开关、文本字符串或操作符 paths，它们决定操作符的输出。
参数对话框
显示某个操作符参数的浮动对话框、窗格类型，或 Network Editor 中的对话框。
参数表达式
参数表达式是位于参数表达式字段中的 python 表达式。
参数模式
每个参数可以处于四种模式之一：Constant Mode、Expression Mode、Export Mode 或 Bind（Binding）Mode。
参数引用
可以在任意两个参数之间建立参数引用：在一个参数中放入引用另一个参数的表达式。这会在两个参数之间创建 Link，使得一个改变时另一个自动改变（在其他软件中称为 "constraint"）。
参数大小
在参数对话框中，例如把 Parameter Size 设为 3，会得到 3 列参数，分别控制 X、Y、Z。
参数值
Parameter Value 指常量、表达式、导出、绑定引用和 Parameter Mode，它们共同决定「求值后」的参数值。
父级
父子关系有两种。「父组件」是节点所在的组件。这个比喻还延伸到祖父级、曾祖父级等。根 / 是所有节点的最终父级。另请参阅 3D Parenting 和面板 Parenting。
父级快捷方式
Parent Shortcut 是组件上的一个参数，其中包含一个名称，你可以在组件内部任意位置用 parent.Name 语法引用该组件，例如用 parent.Effect.width 获取面板宽度。
ParGroup
参数组
ParGroup 是一组相关参数，可以整体设置和获取，而不必逐个处理其中参数，例如 ParGroup t 是 tx ty tz。
Path
网络路径
操作符在 TouchDesigner 环境中的位置，例如 /geo1/circle1，即名为 geo1 的组件中名为 circle1 的节点。路径 / 称为 Root。此路径显示在每个 Pane 的顶部，表明你当前位于哪个 Component 的网络中。如果要指文件系统中的文件夹、目录、磁盘文件或 http: 地址，请参见 Folder。
模式展开
模式展开接受一个短字符串，并将其展开以生成由各个元素组成的长字符串。
模式匹配
使用通配符和方括号匹配名称。在 "Select" 类型的参数中很有用，可选择多个操作符、路径、通道等。
模式替换
与模式匹配配合使用，把匹配字符串的全部或部分替换为新数据。用于 Rename CHOP 等位置。
Perform 模式
Perform Mode 是用于现场演出的优化模式，只渲染一个指定的 Window COMP，即一个包含视频输出和（可选）控制界面的窗口。在 Perform Mode 中，网络编辑窗口不会打开——你在 Designer Mode 中编辑网络。用 F1 和 Esc 切换。
性能监视器
TouchDesigner 内置的工具，用于分析并显示 TouchDesigner 在生成输出图像、音频和数据时正在做什么。
管道
把数据从一个 TouchDesigner 进程移到另一个进程的方式。图像通过 Touch Out / In TOP 传递，通道通过 Touch Out / In CHOP 和 Pipe Out / In CHOP 传递。数据通过 TCP/IP 或 UDP 传输。
Playbar
Playbar 是 Timeline 的旧称。参见 Timeline。
点
每个 POP 和 SOP 都有一个点列表。每个点有 XYZ 3D 位置值以及其他可选属性。每个多边形 Primitive 由顶点列表定义，即点编号的列表。
多边形
多边形是一种 Primitive，由 3D 中一组 Vertices 构成，这些点隐含地连在一起形成多边形状。
POP
点操作符
POP（Point Operators）是一种 Operator Family，处理 3D 几何或任意通用数值数据的数组，运行在 GPU 加速的显卡或芯片上，可渲染为图像，或传递给 DMX 灯光、LED 阵列、激光或其他外部系统等设备。
弹出帮助
帮助消息会在以下情况出现：(1) 把光标移到 TouchDesigner 用户界面上，(2) 点击每个操作符 Parameters 页角上的 ? 帮助按钮，(3) 按住 Alt 键并把光标移到 Parameter Dialog 中的参数名上，(4) 对参数表达式中选中的文本求值。
图元
POPs 中的一种表面类型，包括三角形、四边形、线段带和点图元。Bezier、Cardinal 等曲线通过带曲线专用属性的线段带实现。Points 和图元是 Geometry Detail 的一部分，而 Geometry Detail 又是 POP 的一部分。（旧版基于 CPU 的 SOPs 包括 NURBS 和 Bezier 曲线与面片，以及球体、管和 metaball 图元。）
隐私
TouchDesigner 组件（.tox 文件）或项目（.toe 文件）的保密性，是对网络的保护，使其可以被使用但不可见、不可编辑。
程序化
程序化指根据实时输入和 TouchDesigner 的当前状态自动生成输出。它是 TouchDesigner 的连锁反应机制：当某份数据改变时，会自动使其他「dependent」操作符和表达式重新 Cook 并重新生成输出。
投影映射
一种技术或工作流程，可在往往不规则的形状和表面上显示内容。
脉冲
「脉冲」一个参数，就是向它发送信号，来源可以是 (1) exported CHOP 通道，(2) python 命令，或 (3) 鼠标点击，从而立即触发新动作。通过 python 脉冲是调用脉冲型参数上的 .pulse() 函数，例如 Speed CHOP 中的 Reset 参数。来自 CHOP 的脉冲通常是导出通道中 0 到 1 再到 0 的信号。
四边形重投影
Quad Reprojection 可为以任意朝向悬挂的平板电视和 LED 面板渲染像素级精确、透视正确的图像。
引用
节点之间的灰色虚线是 Reference（或 Link）。Reference 可以是 (1) Parameter Reference，即 OP 中作为另一个操作符名称或路径的参数，(2) Node Reference，即参数或 DAT 脚本中包含另一个操作符名称或路径的表达式，(3) DAT Cell Reference，或 (4) CHOP Channel Reference。
引用
链接
一种 Link。节点之间的灰色虚线是 Reference 或 Link，表示一个操作符正从任意 Operator Family 中的另一个操作符获取数据。
Render 标记
COMP 和 SOP 节点上的紫色标记，决定该节点是否会在 Render TOP 或 Render Pass TOP 中渲染。该操作符还必须列在 Render / Render Pass TOP 的 'Geometry' 参数中。
渲染
渲染是用 Render TOP 创建 3D 图像。渲染在更广义上也包括（用 TOP）合成以生成输出图像。
复制器
为组件创建副本，表格每一行一个，或使用 Number of Replicants 参数——它是操作符的「for 循环」。与 Clone 不同，它会自动创建主组件的副本。
分辨率
图像以像素计的宽度和高度。大多数 TOP（如 Movie File In TOP）可以设置图像分辨率。图像宽高比（考虑非方形像素）见 Aspect Ratio。
RMB 菜单
在 TouchDesigner 不同部位点击鼠标右键时出现的菜单。（有时需要按住 Ctrl。）
根
TouchDesigner 是组件的层级结构。「root」是层级中最顶层的网络。root 的 Network Path 或 Path 就是 /。典型路径是 /project1/moviein1。
采样率
采样
CHOP 的每秒采样数。网络中的每个 CHOP 都有一个采样率。相比之下，整个时间轴有一个 Frame Rate，即每秒 cook 和显示的帧数，通常是你显示器的刷新频率，默认 60。
范围
大多数 CHOP 中的一个参数，用于限制该 CHOP 的哪些通道会受影响。通常 CHOP 的所有通道都会受该操作符影响。TOP 有类似的特性 Channel Mask。
脚本
位于 Text DAT 中的一组命令，在特定条件下被触发运行。TouchDesigner 中有两种脚本语言：Python 和最初的 Tscript。脚本和单行命令也可以在 Textport 中运行。
顺序参数
序列块
顺序参数是可以由用户多次复制以创建多个实体的参数块（Sequential Blocks）。
着色器
在 GPU 上运行、从多边形和纹理创建渲染图像的 OpenGL（2022 年前）或 Vulkan（2022 年起）代码。着色器用 Text DATs 编写，并由 GLSL Material 或 GLSL TOP 引用。着色器最多由三部分组成：Vertex Shader、Pixel Shader 和 Compute Shader。
快捷方式
操作符快捷方式是返回操作符（有时是参数）的 Python 对象。其中包括用于在组件内部访问该组件的 Parent Shortcuts，以及可从 TouchDesigner 任意位置访问某个唯一组件的 Global OP Shortcuts。
片段
OP Snippets 是 700 多个 TouchDesigner 操作符的实时示例集合。你可以通过 Help 菜单、右键点击网络中的操作符，或右键点击 OP Create 对话框中的项目来访问片段。
SOP
表面操作符
一种 Operator Family，可读取、创建和修改 3D 点、多边形、线、粒子、曲面、球体和 metaball。粒子和点云现在主要用 TOP 在 GPU 上完成。
状态栏
TouchDesigner 窗口顶部的文本行，在特定事件成功或失败时显示来自 TouchDesigner 的消息。
存储
Storage 是每个操作符中的 python 字典，用户可在其中存储和取出额外数据。
Swizzle
.
Synth
Synth 是 TouchDesigner 所创作作品的旧称。一个 Synth 由 TouchDesigner 创建的 .toe 文件，以及在 TouchPlayer 中或（在 Perform Mode 中）TouchDesigner 中运行作品所需的所有相关媒体文件组成。
Table DAT
DATs（Data Operators）的一种形式，结构为文本字符串的行与列。
标签
每个操作符可以有一组作为其「标签」的文本字符串。你可以在 TouchDesigner 中设置并搜索它们。
切线
.
Textport
可手动输入命令和脚本的对话框。输出到 textport 的内容包括脚本错误，以及 python 代码中 print() 和 debug() 调用产生的消息。你也可以在 textport 中编辑 DAT。
时间切片
时间切片
时间切片是从上一个计算帧到当前计算帧的时间。在 CHOP 中，它是一组短通道，包含 CHOP 通道在上一个与当前计算帧之间的采样。
时间轴
TouchDesigner 底部的面板，控制 TouchDesigner 项目的当前全局循环 Time，或仅控制某个组件的。
TOP
纹理操作符
一种 Operator Family，可创建、合成和修改图像，并从文件与网络读取/写入图像和影片。TOP 运行在显卡的 GPU 上。
拓扑
POP 拓扑
POP 拓扑是构成 POP 的几何实体之间的关系，指 POP 的 Primitives、每个图元的 Vertx / Vertices，以及顶点所引用的 Points 列表。
Tscript
在 Python 之前，TouchDesigner 原有的内置命令脚本语言。
tuplet
tuplet 是出现在参数对话框同一行上的一组参数。tuplet 占据一个参数 page。
Unicode
TouchDesigner 完全支持 Unicode 文本。Unicode 可以输入到参数、DAT、Python 脚本等。Unicode 编码的文本文件可以载入 DAT。文件路径可以包含任何对文件路径合法的 unicode 字符。
顶点
顶点
一串顶点在 SOP 中构成一个 Polygon。每个顶点是指向 Point List 的整数索引，每个 Point 保存 XYZ 位置以及法线、纹理坐标等属性。
VFS
虚拟文件系统
让你可以把文件嵌入到 .tox 或 .toe 文件中。像 Movie File In TOP 这样读取普通文件的操作符，也可以用 vfs: 语法读取嵌入的 VFS 文件。
Viewer
节点的查看器可以是 (1) 节点内部（即 Node Viewer），(2) 浮动窗口（在节点上 RMB->View...），或 (3) 以图形显示操作符结果的 Pane。
Viewer Active
节点的一种状态，此时你可以操作其查看器中的内容（任意节点右下角的 +），例如在节点查看器中操作面板的控件，或操作 Geometry 组件查看器中的 3D 数据。关闭 Viewer Active 后，即使查看器可见，你也可以通过点击/拖动节点来选择、移动和删除它们。
Viewer 标记
每个节点都有一个 Viewer 标记，用于开启/关闭该节点在 Node Viewer 中的查看器。
Widgets
Widgets 是位于 Palette 中的一组多样化的组件，用于构建用户界面。
窗口
TouchDesigner 中的 Window 是 Microsoft Windows 或 macOS 中的窗口，其中包含 (1) 存在于 Designer Mode 中的 TouchDesigner 编辑界面，或 (2) Window Component 内部用户创建的 Panel。用户创建的窗口可以跨 Multiple Monitors 无边框，也可以是带边框的浮动窗口或弹出窗口。
连线
网络中一个节点的输出到另一个节点输入的连接。相对的概念参见 Link。
WYSIWID
TouchDesigner 是 WYSIWID——What You See Is What It's Doing（所见即其所作）。所有节点都可以有数据的交互式查看器。
