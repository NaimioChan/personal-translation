Event CHOP

摘要

Event CHOP 管理由 MIDI 键盘之类的设备触发的重叠事件的产生与存续。它可以看作一个为 MIDI 键盘设计的简单粒子系统。

Event CHOP 为输入通道中的每个由关到开的事件生成一个采样，这些输入通常来自 MIDI In CHOP、MIDI In Map CHOP、Keyboard In CHOP，或发送给 Event CHOP 的 python 事件。该采样存在的时间为事件的 attack+decay+sustain+release 时长。

注意：参见 Help->OP Snippets 中的示例

Event CHOP 可用于跟随带 MIDI 力度的复音音乐键盘，并能为每个事件生成一个对象、多边形或几何实例。它保证该对象、多边形或实例在经历 attack-decay-sustain-release 阶段后、直到事件结束之前一直存在。Event CHOP 通常经由其他操作符接入 Geometry 组件的 Instance 参数。

Event CHOP 最多输出 8 个通道，每个处于活动状态的由关到开事件生成一个采样。采样在 attack-decay-sustain-release 结束前保持活动，到那一刻采样即消失（类似粒子死亡）。

观察 Event CHOP 的通道图形即可了解它在做什么。它可以送入 Limit SOP 或 Channel SOP，为每个事件放置几何。你可以通过 Event CHOP 的通道把事件信息发送给 SOP，这些通道会被转换为几何通道，如 tx、ty、scale、texture v（给出影片时间偏移）、alpha、r、g 和 b 颜色。

在 MIDI 键盘上可以同时触发许多事件；并且，像粒子一样，你可能希望下次按下同一个键时再启动新的对象，让它们各自继续存在。

Event CHOP 正是为此设计的。每次按下任意键它都会创建一个采样，该采样按其时长存活。这个 CHOP 很轻量——只创建最少数量的通道和采样，即使面对 88 键 MIDI 键盘和频繁敲击也是如此。

其中有通道表示 age、按键时的 note number 和 MIDI velocity，还有一个标记表示该键此后是否已松开。

每个事件都有唯一 ID，保存在 id 通道中，例如可用于为每个音符生成随机的 XY 位移。

影片索引由 state 通道设定，它从 0 升到 1，然后在 1 到 2 之间持续循环，直到音符进入 release 状态，此时从 2 到 3。因此做鸟的循环动画时，0 到 1 状态用于起跳阶段，1 到 2 用于飞行中的扇翅阶段，2 到 3 用于落地阶段。

Event CHOP 的第 1 个输入用于事件触发。

第 2 个输入用于重置触发。

第 3 个输入是可选的，可用于为每个事件采样数值。

另请参阅：Timer CHOP、Count CHOP、Speed CHOP、Trigger CHOP

参数 - Channels 页

Event CHOP 输出七个通道，用于定义事件的属性。

ID id - 事件的序号，从 0 开始，每个事件递增 1。
Index index - 导致该事件的输入 CHOP 的通道索引。
Active active - 当输入大于 0 时该通道变为 1，即输入通道变为「On」时。
Input input - 输入通道在输入变为开（事件诞生）时的值。通常就是音符力度值。如果把 Midi In CHOP 接入 Event CHOP，并把 Midi In 的选项设为输出力度，力度就会进入该通道，并保留到事件结束。
Time time - 从事件开始算起的时间，单位为秒。
ADSR adsr - 按 Attack、Decay、Sustain、Release 得到的值。它使用 ADSR 页上的参数来调节速度和数值，扩展参数包括：Attack Time、Attack Level、Decay Time、Sustain Time、Sustain Min、Sustain Max、Release Time、Release Level。
State state - 这适合用于播放影片。把影片分为 4 段，对应 (0=attack, 1=decay, 2=sustain, 3=release) 各阶段。state 通道输出的是小数值，因此可以看到它爬过所有过渡，包括多个 sustain 段。例如 0...1...2...2...2...2...3...4。如果影片长 8 秒，就把 state 通道乘以 2，作为影片的时间索引传入。

在 attack 阶段从 0 到 1，在 sustain 阶段重复地从 1 到 2，在 release 阶段从 2 到 3。适合用于给影片做索引。

Reset Condition resetcondition - - 决定使用第 2 个输入 Reset Trigger 时的重置行为。仅当 CHOP 的第 2 个输入接有输入时该参数才有效。
  • Off to On offtoon -
  • While On on -
  • On to Off ontooff -
  • While Off off -
Reset reset - 设为「On」时会重置 CHOP，清除所有事件。
Reset Pulse resetpulse - 在被点击的那一帧立即重置 CHOP 并清除所有事件。
Callbacks DAT callbacks - 指向一个 DAT 的路径，其中包含每个事件的 onCreate() 和 onDestroy() 回调。

参数 - ADSR 页

Attack Time attacktime - 影响 adsr 和 state 通道。上升到 attack 最大电平所需的时间。
Attack Time Unit attacktunit - 选择该参数使用的单位：Samples、Frames 或 Seconds。
Attack Level attacklevel - 影响 adsr 通道。attack 的峰值电平。
Decay Time decaytime - 影响 adsr 通道和 state 通道。从峰值到 sustain 电平所需的时间。
Decay Time Unit decaytunit - 选择该参数使用的单位：Samples、Frames 或 Seconds。
Sustain Time sustaintime - 影响 adsr 通道。
Sustain Time Unit sustaintunit - 选择该参数使用的单位：Samples、Frames 或 Seconds。
Sustain Min sustainmin - 影响 adsr 通道。sustain 时间开始时的电平。
Sustain Max sustainmax - 影响 adsr 通道。sustain 时间结束时的电平。
Release Time releasetime - 影响 adsr 和 state 通道。
Release Time Unit releasetunit - 选择该参数使用的单位：Samples、Frames 或 Seconds。
Release Level releaselevel - 影响 adsr 通道。生命周期结束时的电平。
Speed speed - 影响事件的速度，可拉长或缩短事件的寿命。
Global Speed globalspeed -

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Event CHOP 的附加信息可通过 Info CHOP 获取。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
