Timer CHOP

摘要

Timer CHOP 是用于运行定时流程的引擎。它输出计时分数、计数器、脉冲和计时器状态等通道，并在各种计时事件发生时调用 python 函数（回调）。

使用 Timer CHOP 的示例包括触发多个定时提示、运行播放列表、时间轴、状态机，以及驱动 3D 场景中预制的动画组件。大量示例见 Help -> Operator Snippets。

你把计时器设为若干秒（或不限）、帧或采样，并通过 Start 参数或第二个输入 CHOP 触发其启动。Timer CHOP 在计数过程中以秒、帧、采样、分数和开关状态输出，其中包括一个完成时会开启的 done 通道。当它到达某些状态（如循环结束）或完成时，会调用各种 python 回调，让你自定义其行为。

Timer CHOP 由事件触发（通过脉冲其参数或驱动它的两个输入）。它接收事件、计算时间、改变状态。通过其 python 回调函数，你可以向其他节点发送事件、设置参数、读写 DAT、CHOP 和 storage 中的值、重启自身或触发其他节点。因此它可以作为状态机运行。

它有播放/暂停，以及用于减慢或加快计时器的速度控制。

它也可以无限循环，然后可以被通知立即结束或在当前循环结束时结束。

Recommended：OP Snippets for Timer CHOP。通道说明见 Initialize Start。

Multiple Timer segments - 一个 Timer CHOP 内部也可以有多个计时器。附加一个 Table DAT，即可每行定义一个计时器（段）。在 Serial Timers 模式下，一个时间段之后接另一个时间段。在 Parallel Timers 模式下，所有计时器并行运行，各自有自己的开始时间和长度，以及各自的一组输出通道。

Timer CHOP 可以以确定性的方式 Locked to Timeline，也可以在 Sequential Mode 下更自由地运行。与时间轴独立运行时，你可以向前跳转、跳出循环、暂停、goTo() 计时器中的精确位置或时间码，并动态调整速度。

给 Timer CHOP 附加一个 Info DAT 即可查看时间码，或使用 .timecode 成员。可以为每个段在 Info DAT 中放置自定义文本字符串，也可以创建自定义的动画通道。

要让整个 Timer CHOP 在最后一段之后循环，把 On Done 菜单设为 Re-Start。

Tip: What happens when you press Start - 初始化时计时器为 0，例如 timer_frames = 0。按下 Start 的那一帧，默认情况下 running 通道从 0 变为 1，所有 timer_ 计数器通道前进 1 帧。若希望计时器保持 0 直到下一帧，把 Run Value 参数设为 Zero。当 running 变为 1 时，从黑场或其他媒体切到影片可见的第一帧，这种设置很有用。

Chaining Timers - 多个 Timer CHOP 可以串联起来，这样一个结束时下一个可以开始。它们只需一起初始化，即把一个 Timer CHOP 的 ready_pulse 通道导出到下一个 Timer CHOP 的 Initialize 参数。然后就可以按顺序运行：把一个 Timer CHOP 的 done_pulse 通道输出接到下一个 Timer CHOP 的 Start 输入（或导出到其 Start 参数）。启动第一个 Timer CHOP 即可启动整条计时器链。用一些 Timer CHOP 循环等待输入或响应，或加入逻辑决定下一个启动哪个 CHOP，就可以实现状态机。

回调

这些回调会在计时器推进过程中的不同时刻被调用。

脉冲 Initialize 参数时会调用 onInitialize()。你可以在这里准备启动前的任何设置。Initialize 结束时，计时器进入「ready」状态。

脉冲 Start 参数的那一帧会调用 onStart()。计时器随后进入「running」状态。

没有 Delay 或 Play 关闭时，计时器运行的每一帧都会调用 onTimerActive()。

如果通过 Cycle 参数把计时器设为循环，就会调用 onCycleStart()。

在一个循环或段结束之前，可以根据 Cycle End Alert 参数调用 onCycleEndAlert() 回调，以便为下一个循环、段或 Timer CHOP 做准备。

如果计时器由 Segments DAT 驱动（相当于把多个计时器合为一体），就会调用 onSegmentEnter() 和 onSegmentExit()。这些回调中的参数 segment 实际上是一个对象，含有有用的成员，包括段表格中的任何自定义列：在 onSegmentEnter() 中写入代码 print(help(segment))

计时器到达完成状态时会调用 onDone()。

在 onInitialize() 中使用 .masterSeconds，即可在指定时间初始化。

参数 - Segments 页

你可以在一个 Timer CHOP 中指定多个计时器。「段」相当于一个计时器，有自己的长度、延迟时间、要重复的循环次数及其他条件。

Segments DAT segdat - 一个 Table DAT，每个计时器（段）占一行。列标题可以是 delay 或 begin、length、cycle、cyclelimit、maxcycles 和 cycleendalert，它们会覆盖对应的参数。（这些是对应参数的内部名称。）begin 比较特殊，它替代 delay，表示从 Start 起计时器开始计数的时间，无论 CHOP 设为 Serial Timers 还是 Parallel Timers（见 Segment Method）。

Segments DAT 也可以包含任意数量的自定义列。见下面的 Columns to Custom Channels 和 Columns to Info DAT。

Segment Method segmethod - 若 Segment Method 为 Serial Timers，各计时器将依次连续播放。若 Segment Method 为 Parallel Timers，各计时器可以同时播放，并为每个计时器输出一组通道。

  • Parallel Timers parallel -
Segment Units segunits - 对于列 delay、begin、length 和 cycleendalert，用此菜单指定是秒、帧还是采样。
  • Samples samples -
  • Frames frames -

Lingo

  • Segment – 每一段相当于一个计时器，带有延迟时间、长度、要重复的循环次数及其他条件。
  • Begin – 在 Parallel Timers 中，Start 之后经过多少秒（或帧、采样），各计时器才从零开始计数。
  • Done – 所有计时器计数完毕后进入的状态，无论它们是 Parallel 还是 Serial、是否分段。
  • End – Cycle End 是每个循环的结束，Segment End 是段的结束。
  • Cumulative Time – Start 时为零，受速度影响的计数，在计时器活动时增长（延迟期间不增长）。
  • Running Time – Start 时为零，自调用 Start 起的实际时间，无论延迟、速度、循环或提前点击 Go To Segment End 如何。到达 Done 时停止计数。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
