VST

Steinberg VST®（Virtual Studio Technology）是一种专有音频插件标准，运行于 Microsoft Windows 和 Apple macOS，由 Steinberg Media Technologies 开发。

TouchDesigner 通过 Audio VST CHOP 支持 VST3 插件。TouchDesigner 的实现使用 JUCE 框架来处理 VST3 插件。

VST 标准使数百名第三方软件程序员能够创建并销售虚拟乐器文件，这些文件可在 Windows 和 macOS 计算机上的流行数字音频工作站（DAW）和音频应用中运行，包括 Steinberg Cubase、Ableton Live、Logic Pro、Native Instruments、Bitwig 和 Audacity。

可以在 TouchDesigner 中使用 Audio VST CHOP 来使用 VST3 插件。VST2 plugins are not supported。关于哪些 VST 插件与 TouchDesigner 配合良好的讨论，请参阅 VST Plugin Testing

TouchDesigner 中的 VST3 插件以 CHOP 输出多通道音频，并可选择接受多通道音频作为输入（VST Effects 与 VST Instruments）。CHOP 可以按任意采样率运行，采样率由此情况下的 Audio VST CHOP 的输入采样率决定。

还可以通过 Audio VST CHOP 上的 python 函数，用 MIDI 消息控制这些插件。VST 插件的用户界面可以显示在浮动窗口中并操作。

每个插件的内置参数可以作为 TouchDesigner 操作符参数暴露出来，并填充 Plugin 页。当操作 UI 时这些参数会变化，反之亦然。这些参数可以被 Exported，或使用 Binding 绑定到其他参数，或用表达式驱动。

调色板组件库（Palette）中的 Palette:vstHost 是搭建 VST 环境的好框架。

音频由插件内部处理，精度高达 64 位。CHOP 输出和输入为 32 位浮点数。

VST 插件与主 TouchDesigner 进程在同一 CPU 上与其他 CHOP 一起在线运行。在节点上单击鼠标中键可查看计算时间。它们不在单独的进程中运行。不过，为了分担处理或确保低中断、无延迟，你可以使用 Engine Component 在单独进程中运行任何 TouchDesigner 操作符网络，包括音频。你可以将控制数据、音频、图像和数据流传输到 Engine COMP，用任意操作符处理，然后直接用 Audio Device Out CHOP 驱动音频输出。或者也可以将音频流回主进程。

VST® 是 Steinberg Media Technologies GmbH 的商标，在欧洲和其他国家注册。

See also Audio VST CHOP, VST Plugin Testing Community Post, Palette:vstHost, VST Virtual Studio Technology
