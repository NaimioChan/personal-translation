Annotate COMP

摘要

Annotate 在网络编辑器中显示为彩色矩形，内含用户编写的文本和图形。它基于 Annotate COMP，可让你用注释和节点分组等有用信息为网络做文档记录。

Annotate COMP 有三种内置形式：Comments, Network Boxes, and Annotates，它们都可以轻松创建：

  • Comments 是简单的、只有文本的便利贴。可以通过网络右键菜单或快捷键 Shift-C 创建。
  • Network Boxes 将节点组合在一起，以便标注/拖动。可以通过网络右键菜单或快捷键 Shift-B 创建。
  • Annotates（Default Setup）具备上述所有功能，并集成了强大的节点查看功能。可以通过网络右键菜单、快捷键 Shift-A、在网络中按住 Alt 并左键拖动，或在 OP Create Dialog 的 COMP 操作符族中选择 Annotate 来创建。

Default Setup

Annotate COMP 的默认设置是一个功能齐全的注释、网络框和节点查看器，设计为灵活的网络组织和文档工具。以下功能由内部节点和扩展构建，并非 Annotate COMP 本身固有的组成部分。

框右上角的 lock icon 用于锁定和解锁 Annotate 中的文本编辑。在锁定的 Annotate 中，无法编辑文本，点击主体区域会穿透到下方的网络。Annotate 还带有 RMB menu，可快速访问许多功能。它始终可以通过标题栏访问，在 Annotate 解锁时也可以通过主体访问。

你可以拖动边缘来 size Annotate，拖动标题栏来 move 它们。在 Comment 模式下没有标题栏，可以拖动文本主体来移动 Annotate。当 Enclose OPs 功能开启时，拖动 Annotate 会将它覆盖的 drag all enclosed nodes（包括其他 Annotate）一起拖动。若要拖动 Annotate 而不拖动其内容，可以在拖动时按住 Alt。

Annotate 具有强大的内置 Operator Viewer features，包括定位和交互，可通过 Parameters - OP Viewer Page 控制。基本的 text features 参见 Parameters - Text Page。更深入的 text editing and color features（包括限制文本宽度、换行等）参见 Parameters - Settings Page。

Annotate 会 layered in the network，使较小的框位于较大的框前面，但你可以通过 Depth Layer 参数获得更多控制。Annotate 默认位于网格后面，但你可以把它们放在网格前面，甚至放在节点图块之上。例如，将带透明度的图像放入 Viewer OP，把 Back Color Alpha 设为 0，然后将 Layer Zone 设为 Above Nodes。

由于 Annotate 中禁用了 Enter 快捷键和缩放进入，要 get inside an Annotate，请使用以下方法之一：

  1. 框选一个 Annotate，然后在网络上右键单击并选择「Jump Down」。
  2. 通过网络窗格顶部的路径栏找到该 Annotate。
  3. 框选一个 Annotate，在 Parameter Dialog 上右键单击「i」图标，然后从节点菜单中选择 Enter Annotation。

你可以使用 Annotate COMP 的 Mode 参数或右键菜单中的 Mode 菜单，在三种内置 Annotate 模式之间切换。 Annotate COMP 的 .utility 标记控制 Annotation 操作符是否包含在 OP 搜索等中。这个标记可以通过下面描述的 Utility 参数轻松访问。

参数 - Annotate 页

Operator Viewer opviewer - 在 Annotate 区域中显示其视图的操作符。它定义了整个 Annotate 的外观，不要与 OP Viewer 页中的 OP 参数混淆，后者是 Annotate _内部_ 的集成查看器。
Enable Interaction enable - 为 False 时，禁用 all 与 Annotate 的交互，并将所有点击穿透到下方的网络。
Enclose Operators encloseops - 为 True 时，移动 Annotate 时其区域内的其他操作符也会随之移动。
Utility utility - 设置这是否为一个 Utility node。它控制该操作符能否在搜索等中被找到。
Include in Order includeinorder - 将此 Annotate 纳入此网络中 annotateCOMP 的 Order。
Order order - 此 annotateCOMP 的 Order 编号
Layer Zone layerzone - - 此 annotateCOMP 相对网络中其他项目的分层位置。
  • Below Grid belowgrid - 位于所有内容之后，包括网格。
  • Between Grid and Nodes betweengridnodes - 位于节点之后，但在网格之前
  • Above Nodes abovenodes - 位于所有内容之上，包括网格和节点。
Depth Layer layer - 最后兜底的分层索引。同一区域内的 AnnotateCOMP 总是会尝试将其包围的较小 annotateCOMP 显示在上层。

Name ext0name - 可选，用于搜索的名称，代替实例类名。

参数 - Common 页

Common 参数页设置组件的 node viewer 和 clone 关系。

Parent Shortcut parentshortcut - 指定一个名称，可在组件内任意位置用作该组件的路径。参见 Parent Shortcut。
Global OP Shortcut opshortcut - 指定一个名称，可在任何位置用作该组件的路径。参见 Global OP Shortcut。
Internal OP iop - 内部操作符的序列标题。
Shortcut iop0shortcut - 指定一个名称，可在组件内任意位置用作下方「Internal OP」的路径。参见 Internal Operators。
OP iop0op - 此组件内 Internal OP 的路径。参见 Internal Operators。
Operator Viewer opviewer - 当上方的 Node View 参数设为 Operator Viewer 时，选择使用哪个操作符的节点查看器。
Enable Cloning enablecloning - 控制该 OP 是否应持续克隆。关闭此项会使此节点停止克隆其「Clone Master」。
Enable Cloning Pulse enablecloningpulse - 立即克隆内容。
Clone Master clone - 用作 Master Clone 的组件路径。
Load on Demand loadondemand - 仅在需要时将组件加载到内存。适用于项目中并非总是使用的组件。
Enable External .tox enableexternaltox - 开启时（默认），.toe 启动时会加载外部 .tox 文件，COMP 的内容将与该外部 .tox 一致。如有需要，可以关闭此项，以避免启动时从引用的外部 .tox 加载（COMP 的内容改为从 .toe 文件加载）。如果你希望某个 COMP 引用外部 .tox，但不总是从它加载，除非你特意按下 Re-Init Network 参数按钮，这会很有用。
Enable External .tox Pulse enableexternaltoxpulse - 此按钮会从外部 .tox 文件重新加载（若存在）。
External .tox Path externaltox - 磁盘上 .tox 文件的路径，该文件会在 .toe 启动时作为组件内容的来源。这让组件可以包含能独立更新的网络。若找不到 .tox 文件，则会加载 .toe 文件保存时的内容。
Reload Custom Parameters reloadcustom - 启用此复选框后，重新加载 .tox 时会重新加载组件 Custom Parameters 的值。这仅影响组件上的顶层参数；组件内节点上的所有参数始终随 .tox 重新加载。
Reload Built-In Parameters reloadbuiltin - 启用此复选框后，重新加载 .tox 时会重新加载组件内置参数的值。这仅影响组件上的顶层参数；组件内节点上的所有参数始终随 .tox 重新加载。
Save Backup of External savebackup - 启用此复选框后，由 External .tox 参数指定的组件的备份副本会保存在 .toe 文件中。若找不到 External .tox，将使用此备份副本。出现这种情况可能是因为 .tox 被重命名、删除，或 .toe 文件在另一台缺少组件媒体的电脑上运行。
Sub-Component to Load subcompname - 从外部 .tox 文件加载时，此选项允许你深入 .tox 取出一个 COMP，并将其作为顶层 COMP，忽略文件中的其他所有内容（该 COMP 的内容除外）。例如，若名为 project1.tox 的 .tox 文件包含 project1/geo1，将 geo1 设为 Sub-Component to Load，就会加载 geo1 来替代当前 COMP。若此参数为空，则按常规使用文件中的顶层 COMP 加载 .tox 文件。
Relative File Path Behavior relpath - - 设置此 COMP 内的子文件路径是相对于 .toe 本身还是 .tox，或从父级继承。
  • Use Parent's Behavior inherit - 从父级继承设置。
  • Relative to Project File (.toe) project - 当指定为相对路径时，该路径将相对于 .toe 文件。
  • Relative to External COMP File (.tox) externaltox - 当指定为相对路径时，该路径将相对于 .tox 文件。未指定外部 COMP 文件，或 Enable External .tox 未开启时，此项没有影响。

Info CHOP 通道

Annotate COMP 的额外信息可以通过 Info CHOP 访问。

COMP 通用信息通道

  • num_children - 此组件中的子级数量。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
