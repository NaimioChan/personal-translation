渲染

概述

渲染是用 Render TOP 创建 3D 图像。渲染也泛指包含（使用 TOP 的）合成以生成输出图像的过程。

TouchDesigner 中的渲染（或称「光栅化」）通过 GLSL 完成，包含以下特性：

  • GLSL 像素着色器、顶点着色器和几何着色器
  • 可编程 GLSL 顶点着色器中的变形
  • GLSL 像素着色器中的实时材质
  • 高级材质选项；凹凸、置换、反射、透明、暗部发射
  • 3D 场景的实时渲染，包括多通道渲染能力
  • 高级渲染技术；抗锯齿、软边锥形灯、轮廓光、雾、alpha 混合
  • 3D 纹理和 2D 纹理数组
  • 实时深度阴影
  • 多层纹理
  • 与 TOP 合成引擎集成的材质和着色器系统
  • 集成的粒子系统，支持精灵渲染
  • SSAO

在 TouchDesigner 中，渲染通过 Render TOP 和 Render Pass TOP 实现。要渲染对象，需要做几件事。

  • 创建一个 Camera COMP，并将其指定给 Render TOP 的 Camera 参数。
  • 指定要渲染的 Geometry COMP
  • 确保为要渲染的每个 SOP 和 COMP 开启 Render Flag。
  • 创建并指定 Light COMP
  • 将材质（MATs）指定给 Geometry COMP。（如果未列出任何材质，将指定默认材质）。

什么是 Render Pass TOP，为什么要使用它？

Render TOP 使用离屏缓冲进行渲染。渲染完成后，它将颜色输出复制到纹理，该纹理可用于后续渲染，或作为任何 TOP 的输入。

如今的显卡板载两种内存：快速的 GPU 内存和较慢的 GPU 内存。实现快速渲染的关键之一，是确保离屏缓冲留在快速内存中。每个 Render TOP 都有自己的离屏缓冲，因此 Render TOP 越多，这些离屏缓冲被挤出快速内存的可能性就越大。为避免这种情况，我们创建了 Render Pass TOP。

Render Pass TOP 完成与 Render TOP 相同的所有工作，但它复用 Render TOP 创建的离屏缓冲。用 Render TOP 加 Render Pass TOP 代替两个 Render TOP 的项目，通常会明显更快，即使它们渲染的几何量相同。Render Pass TOP 可以将 Render TOP 或 Render Pass TOP 作为输入，因此可以构成任意长度的 Render Pass TOP 链（只需第一个节点是 Render TOP）。

Render Pass TOP 的一种常见用法是在上一次渲染之上叠加内容。Render 和 Render Pass TOP 共享的离屏缓冲还包含 Depth Buffer，因此在 Render Pass TOP 中渲染的对象会利用离屏缓冲附带的深度信息，在场景中被正确放置和遮挡（前提是未清除 Depth Buffer，这是 Render Pass TOP 中的一个选项）。

限制

这种行为的一个后果是，离屏缓冲的内容会被 Render Pass TOP 所做的任何操作污染。因此，如果第二个 Render Pass TOP 也试图使用 Render TOP 的输出，它将没有正确的信息作为起点。

由于这个问题，Render 和 Render Pass TOP 必须按线性方式排列。每个 Render 和 Render Pass TOP 只能有 1 个 Render Pass TOP 作为输出。尝试将两个 Render Pass TOP 连接到同一个 Render 或 Render Pass TOP 会导致错误。

使用 Render Pass TOP 中的 Render/Render Pass TOP 参数时也是如此。此参数是连接两个节点的替代方式。它不允许 Render 和 Render Pass TOP 构成非线性链，只是让节点可以位于不同的网络中。
