Folder DAT

摘要

Folder DAT 列出文件系统文件夹中找到的文件和子文件夹，并监控任何变化。

对于找到的每一项，表格中会创建一行，并可选择包含以下信息的列：

  • Name
  • Base Name
  • Extension
  • 类型
  • Size
  • Depth
  • Folder
  • Path
  • Relative Path
  • Date Created
  • Date Modified
  • Date Accessed

folderDAT_Class

参数 - Folder 页

Active active - 关闭时，DAT 输出只有标题的单行表格，在休眠时或把 DAT 发送给 Replicator COMP 时很有用。
Root Folder rootfolder - 其内容将显示在 DAT 列表中的文件系统文件夹。
Refresh refresh - 打开时，监控指定的文件系统文件夹。
Refresh Pulse refreshpulse - 脉冲按钮读取一次文件夹内容。
Asynchronous Update async - 打开时，更新在主线程之外异步进行，因此不会让 TouchDesigner 掉帧或暂停。因此，磁盘上的变化发生后，Folder DAT 可能不会在下一帧内更新其数据。
Name Format nameformat - 选择是否包含文件扩展名。
  • Include Extension extension -
  • No Extension noextension -
Date Format dateformat - 表格中显示项日期所用的格式。
  • Standard std - 标准日期格式。
  • Epoch epoch - 参考日期格式。
Type type - 要显示的内容类型。
  • Files files - 包含文件。
  • Folders folders - 包含文件夹。
  • Files and Folders filesandfolders - 同时包含文件和文件夹。
Folders folders - 用 Pattern Matching 指定包含哪些文件夹。匹配文件夹路径。分隔符为空格和逗号。要匹配空格，请把整个搜索词放在双引号中。
Names names - 用 Pattern Matching 指定包含哪些名称。分隔符为空格和逗号。要匹配空格，请把整个搜索词放在双引号中。
All Extensions allextensions - 包含所有文件扩展名。
Image Extensions imageextensions - 包含 TouchDesigner 支持的图像内容。见支持的 File Types。
Movie Extensions movieextensions - 包含 TouchDesigner 支持的影片内容。见支持的 File Types。
Audio Extensions audioextensions - 包含 TouchDesigner 支持的音频内容。见支持的 File Types。
Extensions extensions - 用 Pattern Matching 指定包含哪些扩展名。此处列出的扩展名不应包含句点。例如 *txt，而不是 *.txt。
Include Subfolders subfolders - 包含指定根文件夹下的子文件夹。
Minumum Depth mindepth - 设置 Folder DAT 应递归搜索的子文件夹最小深度。
Limit Depth limitdepth - 打开 Maximum Depth 参数以限制对子文件夹的搜索。关闭此开关将搜索所有子树。
Maximum Depth maxdepth - 设置 Folder DAT 应递归搜索的子文件夹最大深度。

参数 - Columns 页

Name namecol - 文件夹或文件的名称。对于文件，此名称包含扩展名。即 myfile.txt
Base Name basenamecol - 文件夹或文件的名称。对于文件，此名称不包含扩展名。即 myfile
Extension extensioncol - 文件的扩展名，文件夹为空白。即 txt
Type typecol - 操作系统报告的文件类型。
Size sizecol - 文件大小，单位为字节。文件夹不报告大小。
Depth depthcol - 该项距 Root Folder 有多少层文件夹。Root Folder 层级上的项深度为 0。
Folder foldercol - 文件夹的路径，或对于文件，是文件所在文件夹的路径。
Path pathcol - 文件夹或文件的完整路径。
Relative Path relpathcol - 文件夹或文件相对于 Root Folder 的相对路径。
Date Created datecreatedcol - 创建日期。
Date Modified datemodifiedcol - 最近一次修改的日期。
Date Accessed dateaccessedcol - 最近一次访问或打开的日期。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

Folder DAT 的额外信息可以通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
