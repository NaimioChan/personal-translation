MIDI In DAT

摘要

MIDI In DAT 记录从指定 MIDI 设备进入 TouchDesigner 的所有 MIDI 消息。它以表格格式输出列 - message、type、channel、index、value。

不过总体设置更简单。一旦通过 Dialogs → MIDI Device Mapper 设置好 MIDI，TouchDesigner 就可以通过指向设备 1 的 /local/maps/map1 等的 Select CHOP 接收 MIDI。

另请注意，MIDI In DAT 报告的控制器索引始终会转换为从 1 开始的 1-128 范围。

表示 MIDI 事件时间戳的列

五列以不同方式表示来自操作系统的 MIDI 事件时间戳：

  • timestamp - 来自操作系统的实际时间戳数值，以毫秒为单位
  • delta_timestamp - MIDI 事件与上一事件之间的毫秒数
  • timeslice_msec - 事件在当前 timeslice 内的时间，以毫秒计。这是根据对一帧内收到的所有事件进行均匀重采样计算得出的值，因此与 'timestamp' 不同
  • absmsec - 事件的 absolute time，以整数毫秒表示。这是根据对一帧内收到的所有事件进行均匀重采样计算得出的值，因此与 'timestamp' 不同
  • absframe - 与 absTime.frame 相同，即处理该事件时的绝对帧编号

要以 CHOP 查看 MIDI 事件信息，创建一个 MIDI In CHOP，把 Mode 设为 "Automatic High Frequency" 连到 Trail CHOP，快速移动滑块即可看到采样变化的密度。

另请参阅 MIDI Event DAT、MIDI In Map CHOP、MIDI In CHOP、MIDI Out CHOP、Tscript midi() Command、MIDI Device Mapper Dialog。

midiinDAT_Class

参数 - Connect 页

Active active - 开启时记录 MIDI 事件。
Device Table device - MIDI 设备的路径 Table DAT
Device ID id - MIDI 设备的路径 Table DAT
14 Bit Values value14 - 打开 14 位 MIDI 事件记录。两条 7 位消息会被合并并作为单个 14 位值输出，这一点与 MIDI Event DAT 不同，后者会将两条消息分别输出。

传入的 7 位消息必须遵循以下规范，才能被正确解释为 14 位：

  • 两条消息中，一条是 MSB（最高有效字节），另一条是 LSB（最低有效字节），它们的值组合起来解释 14 位的值。
  • MSB 消息必须位于控制器范围 0-31 内。
  • LSB 消息必须位于控制器范围 32-63 内。其索引应为 MSB 索引 + 32。即，如果 MSB 消息的索引为 12，则 LSB 消息的索引必须为 44。
  • 此外，索引对 98、99 和 100、101 也可以用作 MSB、LSB 对。
  • 若只收到 MSB 消息，则不会输出任何内容。若在没有 MSB 消息的情况下连续收到多条 LSB 消息，则会使用最后收到的 MSB 消息的值来计算 14 位值。
  • 在此模式下，索引范围 64-95 内的消息会被解释为 7 位并照此输出，因为 64-95 范围保留给 7 位消息。

参数 - Filter 页

Skip Sense skipsense - 开启后不记录 sense 消息。
Skip Timing skiptiming - 开启后不报告时序消息。
Filter Messages filter - 开启后会启用下方的消息过滤参数。
Message message - 按 MIDI 消息内容过滤。例如 "Control Change"
Channel channel - 按 MIDI 消息通道过滤。 通道范围为 1 到 16。
Index index - 按 MIDI 消息索引过滤。索引范围为 1 到 128。
Value value - 按 MIDI 消息值过滤。值的范围为 0 到 127。

参数 - Received Messages 页

Callbacks DAT callbacks - 每向表格添加一行（即每收到一个 MIDI 事件）就运行一次此脚本。用法见 midiinDAT_Class。
Execute from executeloc - 决定脚本的运行位置。
  • Current Node current - 脚本从当前节点位置执行（例如 'cc' 所指的位置）。
  • Callbacks DAT callbacks - 脚本从 Callbacks DAT 参数中指定的 DAT 位置执行。
  • Specified Operator op - 脚本从下方 From Operator 参数指定的操作符中执行。
From Operator fromop - 当 Execute from 设为 Specified Operator 时，其状态变化会触发 DAT 执行脚本的操作符。若 Execute From 参数设为 Specified Operator，此操作符也是脚本执行的路径起点。
Clamp Output clamp - 该 DAT 默认限制为 100 条消息，但使用 Clamp Output 可以设为任意值，包括无限制。
Maximum Lines maxlines - 限制消息数量，较旧的消息会先从列表中移除。
Clear Output clear - 删除除标题外的所有行。若要用 python 脚本清除 op("opname").par.clear.pulse()
Bytes Column bytes - 在单独的列中输出消息的原始字节。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

MIDI In DAT 的额外信息可通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
