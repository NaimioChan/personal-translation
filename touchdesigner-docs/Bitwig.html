Bitwig

Bitwig Studio

Bitwig Studio 是一款数字音频工作站（DAW）和音乐制作软件，由 Bitwig 开发。它提供线性和非线性工作流，用于声音创作、录音、现场演出和环境音频。Bitwig Studio 旨在成为声音探索和音频体验交付的完整方案。

Bitwig 与 TouchDesigner 的集成

TDBitwig 是一组 TouchDesigner 组件，用于在 Bitwig Studio 与 TouchDesigner 之间通信。TDBitwig 功能让用户通过将实时视觉与现场音频输出相结合，创作自定义视听演出。

Bitwig 的主要功能

  • 音频混音：Bitwig 拥有出色的混音总线，用于混合声音。
  • 调制系统：调制系统允许你调制任何设备、VST 插件、参数，进而通过 TDBitwig 支持 TouchDesigner 参数的双向调制。
  • 硬件控制器集成：Bitwig 支持多种音乐创作和演出控制器，使其成为通过 TDBitwig 控制 TouchDesigner 的理想方案。
  • The Grid：The Grid 是模块化声音设计环境，采用类似模拟 FM 合成和 TouchDesigner CHOP 的调制范式。
  • 采样器：包含强大的多采样编辑器。
  • 通过 Bitwig SDK 扩展：Bitwig 支持公开可用的 SDK，可用自定义 Java 代码扩展功能。

TDBitwig

借助 TDBitwig，TouchDesigner 可以控制 Bitwig Studio 的参数，例如 tempo、轨道属性、片段启动和设备参数。反过来，Bitwig Studio 也可以控制 TouchDesigner 参数，从而实现音频与视觉的紧密集成。

TDBitwig 将 Bitwig Studio 的实时音频处理能力与 TouchDesigner 的实时 3D 渲染能力相结合，可用于创作生成式、沉浸式视听演出和装置。TDBitwig 能够同时生成视听效果，让艺术家打造复杂而引人入胜的体验，将声音与视觉无缝融合。

Bitwig 支持大量用于现场演出和演出控制的 hardware controllers。TouchDesigner 可以通过 TDBitwig 与这些以音频为核心的设备连接。

TouchDesigner 是一款可视化编程工具，用于构建交互体验、可视化、生成式 2D/3D 艺术和用户界面，并被用于教育、VJ、地下室原型制作与实验。TouchDesigner 包含强大的工具，可用于处理数据和控制信号，与各种物理设备、协议和软件工具互操作和通信，并将视频/音频/数据输出到专业视频卡、DMX、LED、投影仪、屏幕、激光、机器人、互联网、网络串流、AR/XR/VR 等。阅读关于 TouchDesigner Interoperability 的内容。
