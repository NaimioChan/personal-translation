Line Resample POP

摘要

Line Resample POP 接收一组 line strip，并对每条 line strip 用四种方法之一进行重采样：每条 line strip 的分割数、点之间的指定距离、根据 line strip 在各原始点处的曲率进行点分离（By Curvature），最后是通过「Independent Variable Attribute」按 line strip 的另一个属性均匀步进来分割（Points as Keyframes）。

使用 ControlPoint 属性，可让重采样后的曲线精确通过（包含）控制点。

按曲率重采样有两个距离参数——曲率高的地方使用 Minimum Distance，曲率低（直线段）的地方使用 Maximum Distance。Min Max Bias 会使最小距离处的点更多或更少。

Line Resample POP 不会改变线的形状，与 Line Smooth POP 不同。

另请参阅 Line Divide POP、Line Smooth POP。

参数 - Resample 页

Resample Method resamplemethod - - line strip 重采样方法。
  • None none -
  • Divisions per Line Strip linestrip -
  • Distance between Points dist -
  • By Curvature curvature -
  • Points as Keyframes keyframes -
Divisions resampledivs - 分段数量。
Min Distance resamplemindist - 输出 line strip 中点与点之间的最小距离。
Max Distance resamplemaxdist - 点与点之间的最大距离
Min Max Bias resampleminmaxbias - 点生成偏向——更靠近最小距离还是更靠近最大距离。
Interpolation Method interpolation - - 用于插值的方法。
  • Linear linear -
  • Cardinal cardinal - Cardinal 插值会通过控制点，从而在更高计算开销下得到更平滑的曲线。
Control Points Attribute usectrlpoints - - 一个属性会在点中包含 0 或 1 值，以标示哪些点是控制点。
  • Control Points Attribute usectrlpoints -
  • Control Points Attribute Name ctrlpointsattr - 设置输出控制点属性时的属性范围
Independant Variable Attribute indvarattr - 用作自变量的属性。
Independant Variable Step indvarstep - 自变量的步长，通常是自变量范围的一个分数。
Max Verts per Input Line Strip lsmaxverts - 设置要分配的顶点数。它应大于实际创建的顶点数（可在信息弹窗中查看）。分配的顶点越多，占用的 GPU 内存越多。
Max Tries for Binary Search maxtries - 线性重采样时二分查找的最大迭代次数。
Remove Unused Points rmvunusedpts - 移除未被图元引用的未使用点。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Info CHOP 通道

Line Resample POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
