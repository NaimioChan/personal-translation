OSC In CHOP

摘要

OSC In CHOP 用于接收 Open Sound Control 消息。OSC In 可以接收来自遵循 Open Sound Control 规范（http://www.cnmat.berkeley.edu/OpenSoundControl/）的第三方应用程序的消息。OSC In 基于无连接系统，意味着它可以同时接受来自任意数量源的多个消息。用户必须指定 OSC In 查找传入消息所用的端口号。在 OSC In 尝试使用该端口之前，该端口上不能有任何程序在运行。TouchDesigner 中的 OSC CHOP 使用 UDP 传输协议。

另请参阅 OSC In DAT、OSC Out CHOP、iOS and OSC、Touch In CHOP。

有一些选项可以让用户调整默认的消息排队系统，以便针对其特定的网络条件和使用需求进行优化。Min/Max Target 大小指定一个范围，队列会尝试把缓冲区大小保持在该范围内（以秒计）。增大 Queue Adjust Time 会决定队列可以超出该范围多久之后才尝试纠正。

如果用户希望用 OSC In 检测消息何时到达，有一个 Pulse Mode 开关，它会在任何传入消息到达时读取其单个采样，其他时候则显示脉冲复位值。这对于在 TouchDesigner 与另一应用程序之间同步节拍很有用。

NOTE for Windows OS - If experiencing connection issues make sure Windows Firewall is disabled.

参数 - OSC In 页

Active active - 开启时，该 CHOP 接收发送到网络端口的信息。关闭时不进行更新，发送到该端口的数据会丢失。
Protocol protocol - - 要使用的网络协议。更多信息请参阅 Network Protocols 一文。
  • Messaging (UDP) msging -
  • Multi-Cast Messaging (UDP) multicastmsging -
Network Address netaddress - 使用 Multicast 时，OSC In 在此地址上监听数据包。
Network Port port - OSC In 接受数据包的端口。
Local Address localaddress - 指定接收所用的 IP 地址，当系统有多块网卡（NIC，Network Interface Card）而你想选择使用哪一块时很有用。
OSC Address Scope oscaddressscope - 要减少生成的通道，可以使用通道名称模式来包含或排除通道。例如，^*accel* 会排除来自 iPhone 或 mrmr 之类 iOS 应用的加速度计通道。可用通道名称模式的语法参见 Pattern Matching。
Use Global Rate useglobalrate - 开启时，CHOP 将按 TouchDesigner 指定的 global 采样率采样。
Default Sample Rate samplerate - 当 Use Global Rate 关闭时，此参数用于确定该 CHOP 的采样率。
Queued queued - 打开此项以启用排队，帮助避免消息丢失。使用下面的参数设置队列行为。
Queue Variance queuevariance - Queue Target 周围可接受的范围。如果队列长度在目标值与变化范围内，CHOP 就不会去调整队列长度。
Queue Variance Unit queuevarianceunit - 在此参数的 Samples、Frames 或 Seconds 单位之间选择。
Maximum Queue maxqueue - 队列满时的最大大小。如果达到最大队列长度，传入的采样将被丢弃。
Max Queue Unit maxqueueunit - 在此参数的 Samples、Frames 或 Seconds 单位之间选择。
Queue Adjust Time adjusttime - 指定多久重复/丢弃一次采样，以便更接近队列目标范围。如果值为 1、单位为秒，则它每秒会尝试重复/丢弃一个采样，以维持上面 Minimum Target 和 Maximum Target 参数中设定的队列目标。
Adjust Unit adjusttimeunit - 在此参数的 Samples、Frames 或 Seconds 单位之间选择。
Strip Prefix Segments stripsegments - 从传入地址中去掉若干前缀。例如：地址 /a/b/c/d/e 去掉 3 段后会显示为 d/e（或最终通道名 d_e）。
Reset Channels resetchannels - 设为 On 时删除所有通道，在 Reset Channels 关闭之前不会添加新通道。
Reset Channels Pulse resetchannelspulse - 立即删除所有通道。
Reset Values resetvalues - 设为 On 时将所有通道值重置为 0，在 Reset Values 关闭之前通道值不会更新。
Reset Channels Pulse resetchannelspulse - 立即将所有通道重置为 0。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

OSC In CHOP 的额外信息可以通过 Info CHOP 访问。

  • queue_advanced_total -
  • total_bumped -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
