TOP to CHOP

摘要

TOP to CHOP 把 TOP 图像中的像素转换为 CHOP 通道。每个像素的颜色分量（RGBA）放入单独的通道。根据参数选项，该节点可以为整幅图像创建一组通道，也可以为每条扫描线（行）创建单独的一组通道。

可以从图像中提取单个像素、像素行、像素列或矩形区域。因此了解源图像由多少像素组成很重要。

Exclude NaN 和 Active Mask 参数可用于跳过某些像素，使其不进入 chop 通道。

有一个可选输入，用于提供采样图像的 UV 坐标。输入 CHOP 必须包含 2 个通道，分别对应 U 和 V。第一个通道始终被视为 U。生成的通道（red、green、blue 和 alpha）长度与输入通道完全一致，每个 UV 坐标对应一个值。

如果你从 Depth TOP 抓取像素，只会得到一个通道（深度）。它会被放入 R 通道。

参数 - Image 页

TOP top - 指定要采样其图像的 TOP 操作符。
Download Type downloadtype - - 提供从 GPU 延迟下载数据的选项，速度更快且不会阻塞渲染。
  • Immediate (Slow) immediate -
  • Next frame (Fast) nextframe -
Red r - 由源图像红色像素创建的通道前缀。如果创建了多个红色通道，它们会带有与图像垂直扫描线编号一致的数字后缀，例如 r0 - r4。
Green g - 由源图像绿色像素创建的通道前缀。如果创建了多个绿色通道，它们会带有与图像扫描线编号一致的数字后缀，例如 g0 - g4。
Blue b - 由源图像蓝色像素创建的通道前缀。如果创建了多个蓝色通道，它们会带有与图像扫描线编号一致的数字后缀，例如 b0 - b4。
Alpha a - 由源图像 alpha 像素创建的通道前缀。如果创建了多个 alpha 通道，它们会带有与图像扫描线编号一致的数字后缀，例如 a0 - a4。
Output Color Space outputcolorspace - - 控制输出前把数据转换到哪个色彩空间。如果输出（文件/SDI/ST2110 等）支持元数据，还会尝试把色彩空间写入其中。某些输出形式在其元数据中只支持有限数量的色彩空间。如果输出形式不认识该色彩空间，则不会包含任何元数据。
  • sRGB srgb - sRGB 色彩空间，使用 sRGB 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • sRGB - Linear srgblinear - sRGB 色彩空间，使用线性传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.601 (NTSC) rec601ntsc - Rec.601，NTSC 原色色彩空间，使用 Rec.601 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.709 rec709 - Rec.709 色彩空间，使用 Rec.709（与 Rec.2020 相同）传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.2020 rec2020 - Rec.2020 色彩空间，使用 Rec.2020（与 Rec.709 相同）传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Rec.2020 ST2084PQ rec2020st2084pq - Rec.2020 色彩空间，使用 Perceptual Quantizer 传递函数。相对于 Reference White 被视为 HDR 色彩空间。
  • Rec.2020 HLG rec2020hlg - Rec.2020 色彩空间，使用 Hybrid Log Gamma 传递函数。相对于 Reference White 被视为 HDR 色彩空间。
  • DCI-P3 dcip3 - DCI-P3 色彩空间，D65 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 (D60) dcip3d60 - DCI-P3 "D60 sim" 色彩空间，D60 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Display-P3 (D65) displayp3d65 - Display-P3 色彩空间，D65 白点，sRGB gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Display-P3 (D65) - Linear displayp3d65linear - Display-P3 色彩空间，具有 D65 白点和线性传递函数。相对于 Reference White 被视为 HDR 色彩空间。
  • ACES2065-1 aces2065-1 - ACES 2065-1（也称为 ACES AP0）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACEScg acescg - ACEScg（也称为 ACES AP1）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACESproxy acesproxy - ACESproxy 色彩空间，具有对数传递函数。相对于 Reference White 被视为 HDR 色彩空间。
  • Passthrough passthrough - 选中后，颜色值将按原样用于运算，不作任何修改，也不尝试将其转换到 Working Color Space。
Output Reference White outputreferencewhite - - 把颜色值转换为工作色彩空间以便输出时，此参数控制它们相对于 Reference White 应如何处理。如果工作色彩空间具有相同的 Reference White，则不做调整。如果不同，颜色的 Reference White 水平（亮度）会被调整到输出色彩空间所期望的范围。例如项目设置的 SDR Reference White 为 120 nits、HDR Reference White 为 80 nits，而项目工作色彩空间为 HDR、输出色彩空间为 SDR：那么颜色 (1, 1, 1) 在 HDR 色彩空间中为 80 nits，会被转换为 (0.66, 0.66, 0.66)，在 SDR 输出色彩空间中仍为 80 nits。
  • Default For Color Space default - 根据检测到/选择的色彩空间，使用 SDR 或 HDR Reference White。
  • Standard (SDR) sdr - 将输出色彩空间的参考白值按 SDR 处理。
  • High (HDR) hdr - 将输出色彩空间的参考白值按 HDR 处理。
Output as Single Channel Set singleset - 控制是为每条扫描线创建一个通道，还是把所有扫描线追加到单个通道组中。通道组指源图像的每个颜色通道对应一个 CHOP 通道，例如 RGBA 图像对应 4 个通道。
Exclude NaNs excludenans - 启用后，任一通道值为 NaN 的像素会被跳过，不会加入 CHOP 通道。
Active Channel activechannel - 启用后，只有在所选活动通道中值为非零的像素才会加入 CHOP 通道。

参数 - Crop 页

Crop crop - 指定从图像中提取什么。
  • Pixel (U,V) pixel - 在给定的 U 和 V 值处提取单个像素。
  • Row (U) row - 在给定的 U 值处提取单行，左右由 V Start 和 V End 裁剪。
  • Column (V) col - 在给定的 V 值处提取单列，上下由 U Start 和 U End 裁剪。
  • Rows and Columns block - 提取多行多列，范围由 U/V Start/End 参数限定。
  • Full Image full - 提取整幅图像。
UV Units uvunits - 指定接下来 4 个参数的单位。这些参数可以使用局部变量 $NR 和 $NC 表示行数和列数。
  • 0 to 1 norm -
  • Pixels pixel -
U Start ustart - 在 U 方向上的采样起点。超出图像范围的值由 extend 页中的图像 extend 条件决定。
U End uend - 在 U 方向上的采样终点。
V Start vstart - 在 V 方向上的采样起点。
V End vend - 在 V 方向上的采样终点。
Interpolate interp - 决定使用输入 CHOP 进行 UV 采样时的插值方法。
  • Nearest Sample nearest -
  • Linear linear -

参数 - Channel 页

Start start - 通道的起始位置，以右侧单位菜单所设单位表示（samples、frames 或 seconds）。通道长度由每条扫描线中转换为通道的像素数决定。
Start Unit startunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
  • I samples -
  • F frames -
  • S seconds -
Sample Rate rate - 通道的采样率，单位为每秒采样数。
Extend Left left - 左侧延伸条件（范围之前/之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道起点之前的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常数值
Extend Right right - 右侧延伸条件（范围之前/之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道终点之后的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常数值
Default Value defval - 用于 Default Value extend 条件的值。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Parameter Color Space parmcolorspace - - 控制如何解释此节点上的所有颜色参数。仅在项目启用了 Working Color Space 时可用。颜色值被视为处于所选色彩空间中，并在作为节点运算的一部分使用之前转换为 Working Color Space。注意这不会改变节点自身的色彩空间，因为它始终处于 Working Color Space。

  • sRGB - Linear srgblinear - sRGB 色彩空间，使用线性传递函数。相对于 Reference White 而言视为 SDR 色彩空间。

  • Rec.2020 rec2020 - Rec.2020 色彩空间，使用 Rec.2020（与 Rec.709 相同）传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 dcip3 - DCI-P3 色彩空间，D65 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 (D60) dcip3d60 - DCI-P3 "D60 sim" 色彩空间，D60 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Display-P3 (D65) displayp3d65 - Display-P3 色彩空间，D65 白点，sRGB gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACES2065-1 aces2065-1 - ACES 2065-1（也称为 ACES AP0）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACEScg acescg - ACEScg（也称为 ACES AP1）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Passthrough passthrough - 选中后，颜色值将按原样用于运算，不作任何修改，也不尝试将其转换到 Working Color Space。
Parameter Reference White parmreferencewhite - - 在将参数颜色值转换为 Working Color Space 时，此项控制相对于 Reference White 应如何处理。如果 Working Color Space 的 Reference White 相同，则不做调整。如果不同，则此颜色的 Reference White 级别（亮度）将被调整到 Working Color Space 所期望的范围。例如，如果项目将 SDR Reference White 设为 120 nits，而 HDR Reference White 为 80 nits，那么 (1, 1, 1) 的颜色在 SDR 色彩空间中为 120 nits，将被转换为 (1.5, 1.5, 1.5)，在 HDR Working Color Space 中仍为 120 nits。

  • Use Parent Panel useparent - 将使用父级面板所选的 Reference White。如果顶层面板也选择了「Use Parent」，则将使用「UI Reference White」。
  • Standard (SDR) sdr - 会将 Parameter Color Space 的 Reference White 值按 SDR 处理。
  • High (HDR) hdr - 会将 Parameter Color Space 的 Reference White 值按 HDR 处理。
  • UI ui - 会将 Parameter Color Space 的 Reference White 值按 UI 处理。其亮度使用「UI Reference White Nits」的值。
