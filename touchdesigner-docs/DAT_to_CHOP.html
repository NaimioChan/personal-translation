DAT to CHOP

摘要

DAT to CHOP 会创建一组 CHOP 通道，其值来自 DAT。

dattoCHOP_Class

参数 - DAT to 页

DAT dat - 用于获取数值的 DAT。该 DAT 应为 table 格式。若是表格格式，请使用 Table DAT，或把 Convert DAT 设为 To Table。
Select Rows extractrows - - 该参数让你选择指定所选行的不同方式。
  • All all - 选中所有行。
  • by Name byname - 使用 Start Row Name 和 End Row Name 参数选择行。
  • by Index byindex - 使用 Start Row Index 和 End Row Index 参数选择行。
  • by Start Name, End Index bynameindex - 使用 Start Row Name 和 End Row Index 参数选择行。
  • by Start Index, End Name byindexname - 使用 Start Row Index 和 End Row Name 参数选择行。
  • by Values bynames - 通过显式指定行值来选择行。
  • by Condition byexpr - 通过针对 from 列求值的表达式来选择行。
Start Row Name rownamestart - 指定选择范围的起始行名。
Start Row Index rowindexstart - 指定选择范围的起始行索引。
End Row Name rownameend - 指定选择范围的结束行名。
End Row Index rowindexend - 指定选择范围的结束行索引。
Row Select Values rownames - 指定要选择的具体行名。可以使用模式匹配，例如 row[1-4] 会选中 row1 到 row4 的所有行。
Row Select Condition rowexpr - 指定一个要计算的表达式。如果表达式求值为真，则选中该行。

展开该参数，你会看到它处于 expression mode 中。

默认情况下，Python 表达式为 re.match('.*',me.inputCell.val) != None。' .*' 表示任意字符重复多次，因此该表达式匹配所有值。如果你只想匹配父级操作符名后面跟任意数字，可以使用 parent().name+'[0-9]*'，其中 '[0-9]*' 匹配任意数字字符串。' .*'+parent().name+'.*' 会匹配任何包含该操作符父级名称的单元格。关于如何使用 Python 正则表达式模块的更多信息，可以查看 Regular Expression Operations。

From Column fromcol - 按值选择行时，该参数选择用哪一列把单元格值与 Selected Row Values 匹配，以确定选中哪些行。
Select Cols extractcols - - 该参数让你选择指定所选列的不同方式。
  • All all - 选中所有列。
  • by Name byname - 使用 Start Col Name 和 End Col Name 参数选择列。
  • by Index byindex - 使用 Start Col Index 和 End Col Index 参数选择列。
  • by Start Name, End Index bynameindex - 使用 Start Col Name 和 End Col Index 参数选择列。
  • by Start Index, End Name byindexname - 使用 Start Col Index 和 End Col Name 参数选择列。
  • by Values bynames - 通过显式指定列值来选择列。
  • by Condition byexpr - 通过针对 from 行求值的表达式来选择行。
Start Col Name colnamestart - 指定选择范围的起始列名。
Start Col Index colindexstart - 指定选择范围的起始列索引。
End Col Name colnameend - 指定选择范围的结束列名。
End Col Index colindexend - 指定选择范围的结束列索引。
Col Select Values colnames - 指定要选择的具体列名。可以使用模式匹配，例如 colvalue[1-4] 会选中 colvalue1 到 colvalue4 的所有列。
Col Select Condition colexpr - 指定一个要计算的表达式。如果表达式求值为真，则选中该列。详情参见 Row Select Condition。
From Row fromrow - 按 Specified Names 提取列时，该参数选择用哪一行把单元格值与 Selected Col Values 匹配，以确定选中哪些列。
Output output - - 指定通道输出的形式。
  • Single Channel single - 创建一个通道，每个提取的值对应一个采样。
  • Channel per Row chanperrow - 每提取一行就创建一个单独的通道。
  • Channel per Column chanpercol - 每提取一列就创建一个单独的通道。
  • Channel per Value chanpervalue - 每提取一个值就创建一个单独的通道。
First Row is firstrow - - 指定第一行是被忽略、作为名称还是作为数值。
  • Ignored ignored -
  • Names names -
  • Values values -
First Column is firstcolumn - - 指定第一列是被忽略、作为名称还是作为数值。
  • Ignored ignored -
  • Names names -
  • Values values -

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

DAT to CHOP 的额外信息可通过 Info CHOP 查看。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
