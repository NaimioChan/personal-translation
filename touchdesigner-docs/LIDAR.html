LIDAR 激光雷达

TouchDesigner 通过特定节点类型直接支持 LIDAR（激光雷达）：

  • Ouster - Ouster 制造用于用激光扫描 3D 环境的 LIDAR 设备。
  • Orbbec - Orbbec 是一家 3D 摄像头及其他传感器的开发商和制造商，其产品可在 TouchDesigner 中使用。Orbbec Femto Mega 和 Femto Bolt 使用与已停产的 Kinect Azure 相同的传感器硬件，并支持类似功能，包括在 Kinect Azure TOP 中使用时的 3D 身体跟踪。
  • Kinect Azure 从 Microsoft Kinect Azure 摄像头或 Kinect 兼容的 Orbbec 摄像头（Femto Mega、Femto Bolt 等）采集数据。
  • SICK - 制造激光雷达传感器，主要用于工业自动化应用。
  • Hokuyo CHOP 用于与 Hokuyo 激光扫描仪通信（串口或以太网接口）：Hokuyo Products
  • Leuze ROD4 CHOP
  • 通用的 2D Blob Track TOP

也可以使用其他厂商的 LIDAR 设备，通过 python 或其他 API 接入。

  • 来自 SLAMTEC 的 RPLiDAR S2E - ToF LiDAR 360° Laser Range Scanner（30m，以太网 UDP，IP65）
