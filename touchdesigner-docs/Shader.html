着色器

TouchDesigner 中的着色器是在 GPU 上运行的 OpenGL（2022 之前）或 Vulkan（2022 起）GLSL 代码，用于从多边形、纹理、CHOP 通道和参数生成渲染图像。

着色器要么内嵌在 Materials 中，要么放在 Text DATs 中并引用到 GLSL Material 或 GLSL TOP。

着色器最多由三部分组成：Vertex Shader、Pixel Shader 和 Compute Shader。（Geometry Shader 现已过时。）

TouchDesigner 中的所有着色器都是 GLSL 着色器。

最常用的材质是 Phong MAT 或 PBR MAT，它们包含众多光照和表面渲染选项。Phong MAT 和 PBR MAT 可以输出表示材质所用功能的特定 GLSL 着色器代码，这是编写你自己的着色器或改编其他着色器的良好起点。

GLSL TOP 使用 GLSL 着色器生成 2D 图像。

另请参阅 Write a GLSL Material。
