TouchEngine

TouchEngine 允许其他软件包加载 .tox 文件中的 TouchDesigner 组件、对其进行处理，并来回传递数据。

TouchEngine 是 Engine COMP 以及 Unreal Engine plugin 背后的核心技术。

TouchEngine API

SDK（包括文档和 Windows 示例项目）可在此处获取：

https://github.com/TouchDesigner/TouchEngine-Windows

macOS 版本：

https://github.com/TouchDesigner/TouchEngine-macOS

许可

在你的软件包中使用 TouchEngine 无需许可费或版税。它可以免费包含在任何软件包中，功能由最终用户在机器上安装付费的 TouchDesigner 或 TouchPlayer 许可证后启用（Educational, Commercial, 或 Pro，详见 Licensing）。此外，系统上必须安装 TouchDesigner 或 TouchPlayer 才能使用 TouchEngine。

在 TouchDesigner 中，Engine COMP 可与任何许可证配合使用，包括 Non-Commercial licenses。

实现

Derivative

Engine COMP - Engine COMP 是 TouchDesigner 中的原生组件，可将 .tox 组件文件加载到项目中，但在独立的 TouchEngine 进程上运行它们。

Unreal Engine Plugin - TouchEngine For UE Plugin 让 Unreal Engine 用户和开发者能够加载 TouchDesigner .tox 文件、处理它们，并在 Unreal Engine 内来回传递数据。

第三方

TouchPy - TouchPy 是一套用于在 Python 中操作 TouchDesigner 组件的高性能工具集。通过利用 Vulkan、CUDA 和 TouchEngine，TouchPy 为集成开辟了新途径，尤其是与 PyTorch 和 Nvidia Warp 等库的集成。TouchPy 支持 GPU 到 GPU（零拷贝）数据传输，简化了独立 Python 应用与 TouchDesigner 之间的数据交换。

SMODE - SMODE 是一套集成的图形合成平台和媒体服务器。SMODE V10 引入 TouchEngine 支持，允许你在 SMODE 中将 .tox 组件作为 2D 图层对象运行。参见文档 here。

VDMX - VIDVOX 的 VDMX 是面向 macOS 的可完全自定义、硬件加速的图层式视频平台。VDMX6 引入 TouchEngine 支持，将 TouchDesigner 的能力与 VDMX6 界面的灵活性结合起来。

FFGLTouchEngine - 一个 FFGL 插件，可将 TouchDesigner 组件（.tox 文件）加载到 Resolume 之类的程序中。

Screenberry - 一个模块化、功能强大的多平台媒体服务器。Read our blog 关于 Front Pictures 对 TouchEngine API 的集成。

Hippotizer - Green Hippo 媒体服务器现已支持 TouchEngine！Read about it here。

LightAct - LightAct 软件和媒体服务器现已支持 TouchEngine。Read about it here。

Pixera - Pixera 软件和媒体服务器现已支持 TouchEngine。在这篇分为两部分的系列文章中了解详情：Part 1、Part 2，以及这篇 Troubleshooting Guide 中的更多内容。
