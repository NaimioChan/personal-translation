RealSense

RealSense 是 Intel 的跟踪设备。TouchDesigner 使用 RealSense TOP 和 RealSense CHOP 从 Intel RealSense 设备获取多个数据流。

RealSense TOP 使用 Intel librealsense API，它为所有相机型号提供跨平台支持。RealSense CHOP 使用 Cubemos RealSense Skeleton Tracking API 提供骨骼跟踪数据。注意： RealSense CHOP 现已弃用，因为 Cubemos 不再提供骨骼跟踪 SDK 的许可证。

注意： librealsense SDK v2.50.0 看起来不会为 Apple Silicon 更新，因此不是添加到这些版本中的选项。

注意： RealSense 相机应使用 USB 3 连接。USB 2 支持仅限于较小的分辨率。

RealSense TOP

RealSense TOP 节点以多种形式输出颜色、深度和 IR 数据。

RealSense TOP 可以捕获多种数据流：

  1. Color，即来自 RealSense 相机彩色传感器的视频。
  2. Depth，对每个像素深度的计算。0 表示该像素距相机 0 米，1 表示该像素距相机为最大距离或更远。
  3. Raw Depth，直接取自 RealSense 相机 SDK 的值。同样，0 表示距相机 1 米，1 表示最大范围或更远。
  4. Visualized Depth，来自 RealSense SDK 的灰度图像，可帮助你可视化深度，但不能用于实际确定像素与相机之间的精确距离。
  5. Depth To Color UV Map，来自 32 位浮点 RG 纹理（注意，没有蓝色）的 UV 值，用于将深度图像重映射以与彩色图像对齐。你可以使用 Remap TOP 节点对齐图像以使其匹配。
  6. Color To Depth UV Map，来自 32 位浮点 RG 纹理（注意，没有蓝色）的 UV 值，用于将彩色图像重映射以与深度图像对齐。你可以使用 Remap TOP 节点对齐两者。
  7. Infrared，来自 RealSense 相机红外传感器的原始视频。
  8. Point cloud，字面意义上 3D 空间中的点云（X、Y、Z 坐标），或由 RealSense 相机扫描器创建的数据点。
  9. Point Cloud Color UVs，可用于从 Color 图像流获取每个点的颜色。
  10. Segmented Color (with Alpha)，输出相机前方检测到的人的遮罩彩色图像。
  11. IMU/SLAM Tracking 对于 T265 型号，可以使用 Info CHOP 获取相机在空间中的位置数据。

  • F200
  • R200
  • ZR300
  • SR300
  • D405
  • D415
  • D435
  • D435i
  • D455
  • D455f
  • D456
  • D555

RealSense CHOP

DEPRECATED: Cubemos 不再提供骨骼跟踪功能的许可证。

RealSense CHOP 通过参数引用一个 RealSense TOP。RealSense CHOP 在 Windows 上支持骨骼跟踪。

Skeleton Tracking: 使用所引用 RealSense TOP 的相机执行 skeleton tracking。必须在 RealSense TOP 上启用 Skeleton Tracking。

RealSense CHOP 通过 Cubemos RealSense Skeleton Tracking API 支持骨骼跟踪。该 API 在 TouchDesigner 中使用需要许可证。可在此处 here 购买完整许可证；也提供试用许可证。安装 SDK 是设置许可证文件的必要步骤。安装 SDK 后，可用 Cubemos/SkeletonTracking/scripts 目录中的 post_installation.bat 脚本设置许可证。骨骼跟踪还需要一个模型文件（.cubemos），其中两个随 Cubemos Skeleton Tracking SDK 打包，位于 Cubemos/SkeletonTracking/models/skeleton-tracking 文件夹中。

安装所需软件

相机固件

RealSense TOP *不*需要安装驱动程序，但要求设备上安装了正确的固件。你可以从此处安装 RealSense SDK 来完成： https://github.com/IntelRealSense/librealsense/releases 然后使用 Camera Viewer 工具将固件更新到推荐版本。

固件下载可在此处获取： https://dev.intelrealsense.com/docs/firmware-releases

2025.30000 系列使用 SDK 版本 2.56.5。https://github.com/IntelRealSense/librealsense/releases/tag/v2.56.5
