OP Execute DAT

摘要

OP Execute DAT 在 operator 的状态发生变化时运行脚本。

OP Execute DAT 创建时带有默认的 python 方法占位符。对于参数中每一个被监视的条件，DAT 中都有一个 matching python method。当参数中打开某个条件时，每次该条件得到满足，对应的 python 方法就会执行。

opexecuteDAT_Class

参数 - OP Execute 页

Active active - 开启时，DAT 会对所引用的 OP 作出响应。
Execute from executeloc - - （仅 Tscript）决定脚本运行的位置。
  • Current Node current - （仅 Tscript）脚本从当前节点位置执行。
  • This Node here - 脚本从 DAT 的父级执行。DAT 从父级执行是为了便于访问 DAT 的同级：过去 DAT 脚本是从 DAT 内部执行的。
  • Specified Operator op - 脚本从下方 From Operator 参数指定的操作符中执行。
From Operator fromop - 当 Execute From 参数设为 Specified Operator 时，脚本将从该路径执行。
Monitor OPs op - 指定监视哪些操作符来触发脚本。
Pre Cook precook - 在操作符计算之前触发 onPreCook() 方法。
Post Cook postcook - 在操作符计算之后触发 onPostCook() 方法。
Destroy opdelete - 操作符被删除时触发 onDestroy() 方法。
Flag Change flagchange - 操作符的某个 Flags 状态改变时触发 onFlagChange() 方法。这包括 OP_Class 的 Common Flags 列表中的所有标记，以及 COMP_Class、SOP_Class、CHOP_Class 中列出的所有可在 python 中访问的标记。
Wire Change wirechange - 操作符的输入被重新连接（连接、断开、交换）时触发 onWireChange() 方法。
Name Change namechange - 操作符名称改变时触发 onNameChange() 方法。
Path Change pathchange - 操作符路径改变时触发 onPathChange() 方法。
UI Change uichange - 操作符在网络编辑器中调整大小或移动时触发 onUIChange() 方法。
Number Children Change numchildrenchange - 操作符的子级数量发生变化时触发 onNumChildrenChange() 方法。仅适用于 Component 类型的操作符。
Child Rename childrename - 操作符的某个子级被重命名时触发 onChildRename() 方法。
Current Child Change currentchildchange - 操作符的某个子级在网络中被设为当前时触发 onCurrentChildChange() 方法。仅适用于 Component 类型的操作符。
Extension Change extensionchange - 操作符的扩展发生变化时触发 onExtensionChange() 方法。
Edit.. edit - 点击后打开文本编辑器，以编辑 DAT 中的文本。

参数 - File 页

File file - 要加载的文件的文件系统路径和名称。接受 .txt 和 .dat 文件。
Sync to File syncfile - 开启时，在项目启动时将文件从磁盘加载到 DAT 中。必须指定文件名。开启该选项会立即从磁盘加载文件。如果文件不存在，则在 DAT 第一次更新时创建它。系统会监视该文件，对文件的任何改动都会更新 DAT，而对 DAT 的任何改动都会立即写入文件。如果文件被移除，DAT 将保留其当前内容。
Load on Start loadonstart - 开启时，项目启动时从磁盘重新加载文件到 DAT 中。
Load File loadonstartpulse - 立即重新加载文件。
Write on Toe Save write - 开启时，保存项目时将 DAT 的内容写入磁盘文件。
Write File writepulse - 立即将文件写入磁盘。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

  • Input 0: -

Info CHOP 通道

OP Execute DAT 的额外信息可以通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
