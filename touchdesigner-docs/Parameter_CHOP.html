Parameter CHOP

摘要

Parameter CHOP 从所有 OP 类型获取参数值，包括自定义参数。

（它取代了 Fetch CHOP。）

也可以使用 Par Class 的 node.par.Customname 表达式或 Parameter Execute DAT 从参数获取。

从其他 CHOP 的输出获取通道，请参阅 Select CHOP。

parameterCHOP_Class

参数 - Source 页

Operators ops - 这些操作符决定从哪里获取通道。指定一个或多个操作符名称或路径。示例：wave1、slider*、constant[1-9] constant[10-19:2]、../base1。或使用菜单选择操作符。
Fetch fetch - 选择获取 Parameters 还是 Sequences。
  • Parameters partypes - 设为 Parameters 时，使用 ParGroups 和 Parameters 参数进行选择。
  • Sequences sequencetypes - 设为 Sequences 时，使用 Sequences 参数选择要查看的序列。然后使用 ParGroups 和 Parameters 参数在所选序列内进行选择。
Sequences sequences - 要从 OP 获取的序列名称列表（可包含通配符）。供 Parameters 和 ParGroups 参数在所选的序列内进行选择。一个或多个序列，或使用 * 表示所有序列。也可以使用 ^ 指定「NOT」选择。或使用菜单选择序列。请参阅 Pattern Matching。仅当 Fetch 菜单选项设为 Sequences 时启用。

如果所选序列的块数量多于一个，通道将变为多重采样，每个索引代表块索引。如果选择了多个块长度不同的序列，则块长度较短的序列将应用 HOLD 模式。

ParGroups pargroups - 要从 OP 获取的 pargroup 名称列表（可包含通配符）。一个或多个 pargroup，或使用 * 表示所有 pargroup。也可以使用 ^ 指定「NOT」选择。或使用菜单选择 pargroup。请参阅 Pattern Matching。
Parameter parameter - 要从 OP 获取的参数名称列表（可包含通配符）。一个或多个参数，或使用 * 表示所有参数。也可以使用 ^ 指定「NOT」选择。或使用菜单选择参数。请参阅 Pattern Matching。
Custom custom - 输出操作符的自定义参数。
Built-In builtin - 输出操作符的内置参数。
Name Format nameformat - 通道可以按适合多重导出的方式命名。请参阅 CHOP_Export。

Rename from renamefrom - 请参阅 Pattern Matching。
Rename to renameto - 请参阅 Pattern Replacement。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
