VFSFile 类

VFSFile 类描述 Virtual File System 中包含的虚拟文件。
要在任何操作符的文件参数中访问虚拟文件，请使用下文 virtualPath 成员中描述的虚拟路径。

成员

name → str :

获取或设置文件的名称。此名称可以包含斜杠，但不应包含前导斜杠。

size → int (Read Only):

获取文件数据的大小。

date → "datetime.datetime" (Read Only):

以 datetime Python 对象的形式获取文件的修改日期。

virtualPath → str (Read Only):

获取文件的虚拟路径。返回一个 String，用于在 Movie File In TOP 等操作符中从 VFS 获取文件数据。格式为 vfs:<path to owner>:<filename>。

originalFilePath → str (Read Only):

获取磁盘上的原始文件路径。如果 VFSFile 是从 bytearray 而非磁盘文件创建的，则此值为空。

owner → OP (Read Only):

获取 OP 所有者。

byteArray → bytearray :

获取或设置文件数据为 bytearray。

方法

destroy()→ None:

销毁此对象引用的 VFS 中的文件。

export(folder)→ str:

将文件导出到磁盘上指定的文件夹并返回位置。

  • folder - 要导出文件到的磁盘文件夹。
