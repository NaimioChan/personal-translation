TCP/IP DAT

摘要

TCP/IP DAT 用于在两台处于远程位置的电脑之间通过 TCP/IP 连接发送和接收信息。它捕获所有消息，不做任何排队或缓冲，并允许你向它发送任意消息。

使用 tcpipDAT_Class 发送消息。使用附加到 TCP/IP DAT 的回调 DAT 处理接收到的消息。参见 Network Protocols。

例如，这个 DAT 可用于拦截从 Pipe Out CHOP 发送的所有原始信息。Pipe In CHOP 和 Pipe Out CHOP 也通过 TCP/IP 连接通信，不过它们使用特定的语法。

另请参阅 Peer Class、UDP In DAT、UDP Out DAT。

关于 Tscript，参见 Tscript send 命令。

NOTE for Windows OS - If experiencing connection issues make sure Windows Firewall is disabled.

参数 - Connect 页

Active active - 此复选框启用连接。
Connection Mode mode - 指定此操作符是以 client 还是 server 身份通信。
  • This Operator is Client client -
  • This Operator is Server server -
Network Address address - 如果此节点以客户端身份通信，这里应是服务器的 IP 地址。
Port port - 要监听或连接的网络端口，取决于该节点是服务器还是客户端。
Shared Connection shared - 使用与其他使用相同网络协议的联网 DAT 相同的连接。
Row/Callback Format format - 决定接收到的数据如何解析到表格中。
  • One Per Byte perbyte - 每收到一个字节就向表格添加一行。
  • One Per Line perline - 每收到一行就向表格添加一行。行尾由 \n、\r 或空字符（\0）分隔。
    Note: In this format messages will not be logged until one of those characters are received.
  • One For All Received Data all - 每收到一条消息就向表格添加一行。由于 TCP/IP 是基于流的协议，「消息」的结束是任意的。它只是从套接字最后一次读取操作的内容。如果你要读取自定义消息格式，通常需要在 Python 中把从套接字多次读取的内容拼成一条完整消息。
Local Address localaddress - 指定服务器模式下要监听的 IP 地址，当系统有多块网卡（NIC）且你想选择使用哪一块时很有用。留空时，TCP/IP DAT 将监听所有接口。

参数 - Received Data 页

Callbacks DAT callbacks - Callbacks DAT 会为收到的每条消息执行一次。
Execute from executeloc - 决定脚本的运行位置。
  • Current Node current - 脚本从当前节点位置执行。
  • Callbacks DAT callbacks - 脚本从 Script DAT 参数中指定的 DAT 所在位置执行。
  • Specified Operator op - 脚本从下方 Component 参数指定的组件执行。
From Operator fromop - 当 Execute from 设为 On Panel Change 时，其状态变化会触发该 DAT 执行脚本的组件。如果 Execute from 参数设为 Specified Component，该组件也是脚本执行时的所在路径。
Clamp Output clamp - 该 DAT 默认限制为 100 条消息，但使用 Clamp Output 可以设为任意值，包括无限制。
Maximum Lines maxlines - 限制消息数量，较旧的消息会先从列表中移除。
Clear Output clear - 删除除标题外的所有行。要用脚本命令清空，示例如下：opparm -c /serial1 clear
Bytes Column bytes - 在单独的列中输出消息的原始字节。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

TCP/IP DAT 的额外信息可通过 Info CHOP 访问。

TCP/IP DAT 的特定信息通道

  • connections -
  • messages_pending -

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
