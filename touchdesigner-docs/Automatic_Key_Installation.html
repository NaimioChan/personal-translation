自动安装密钥

为便于将 TouchDesigner 部署到多台计算机，可以使用 Key Manager Dialog 自动安装密钥，而无需手动安装。Note: this method only works if no keys are currently enabled on the machine。这在向学校的实验室机器或为大型项目组装的机器批量部署许可证时很有用。多机许可证的其他选项包括：
Floating Licenses Using a Dongle
Floating Cloud Licenses

设置

具体做法是，先：

  • 在目标计算机的桌面上创建一个名为 TDAutoKey.txt 的文件
  • 运行 TouchDesigner

与常规的许可证安装流程一样，an active Internet Connection is necessary。

TDAutoKey.txt 文件需要包含一些必需信息，例如用户名和密码；此外还有一些可选选项，可根据需要指定。.txt 文件的格式为 

 setting = value

macOS

  • 在 macOS 上安装时必须是管理员，并且在安装密钥后需要以管理员身份启动一次 TouchDesigner。此后，任何用户都可以使用 TouchDesigner。

必需信息

前两项信息是包含所要安装密钥的 Derivative 账户的用户名/密码 

 username = <DerivativeAccountUsername>
 password = <DerivativeAccountPassword>

接下来需要指定要安装的密钥类型： 

 product = <ProductName>

有效值：

  • TouchDesigner
  • TouchPlayer
 license = <LinceseType>

有效值：

  • Commercial
  • Pro
  • Educational
  • Non-Commercial

可选设置

由于 099 具有更新日期，默认会选择更新日期最靠后的许可证。也可以通过以下设置改为选择更新日期最近的许可证： 

 updateDate = closest

如果未设置，则其行为等同于将该选项设置为： 

 updateDate = farthest

要控制密钥安装成功后是否弹出对话框，请使用此设置。如果未指定，默认为 'true' 

 notifySuccess = <TrueOrFalse>

要控制发生任何错误时是否弹出对话框，请使用此设置。如果未指定，默认为 'true' 

 notifyFailure = <TrueOrFalse>

要在密钥安装成功后自动删除 TDAutoKey.txt，请使用此设置。如果未指定，默认为 'false' 

 deleteAfterSuccess = <TrueOrFalse>


示例 TDAutoKey.txt 文件位于 File:TDAutoKey.txt。应修改 username 和 password 字段，使其与所用账户一致。
