Perform DAT

摘要

Perform DAT 以 Table DAT 格式记录各种性能时间。这些基准与 Performance Monitor 报告的内容类似。

performDAT_Class

参数 - Perform 页

Active active - - 打开/关闭日志记录。Active 为 On 时，DAT 会持续记录。
  • Active active -
  • Active Pulse activepulse -
Trigger Mode triggermode - - 提供两个选项，决定何时触发日志刷新。
  • When Frame Length Exceeds Threshold threshold - 用下面的 Trigger Threshold 参数设置刷新日志前等待的最大帧时间。
  • When a Frame is Dropped droppedframe - 一旦发生丢帧就立即刷新日志。
Trigger Threshold triggerthreshold - 帧必须超过这个时间（毫秒），DAT 才会记录并输出该帧的耗时。例如，想查看某帧计算超过 33 毫秒时会发生什么，就把此参数设为 33。
Cook Time logcook - 记录操作符的计算时间。
Export Time logexport - 记录导出 CHOP 通道所花的时间。
Viewport Draw Time logviewport - 记录绘制 3D 几何和 SOP 查看器的时间。
Movie Time logmovie - 记录从影片文件读取视频和音频所花的时间。
Draw Channels Time logdrawchannels - 记录在 CHOP 查看器中绘制通道的时间。
Object View Time logobjectview - 记录在 3D 查看器中绘制对象的时间。
Custom Panel Time logcustompanel - 记录用 Panel Components 构建的自定义面板所花的时间。
MIDI Time logmidi - 记录 MIDI 上所花的时间。
Graphics Time loggraphics - 记录各种图形系统调用，例如等待显卡的时间、对图形驱动的调用、把 TOP 数据转换为 CHOP 等。
Frame Length logframelength - 记录总帧时间（毫秒，ms）。
Misc logmisc - 记录不属于其他类别的杂项时间。
Script logscript - 记录运行脚本所花的时间。
Render logrender - 记录 Render 或 Renderpass TOP 所花的时间。
Callbacks DAT callbacks - Callbacks DAT 的路径。新建的 Perform DAT 会自带一个停靠的 Callbacks DAT。
Clear clear - 清除 DAT 的内容。
Active Pulse activepulse - 使用 resetpulse 按钮抓取单帧快照。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

Perform DAT 的额外信息可通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
