参数 - Pre-Xform 页

Pre-Xform 参数页会以与将另一个 Object 作为此节点的父级相连相同的方式，对对象组件应用变换。该变换应用在 Xform 页参数的左侧。用矩阵数学的说法，若采用「右乘」（列向量）约定，公式为 preXForm * xform * Position。

Apply Pre-Transform pxform - 启用此页上的变换。
Transform Order pxord - 更多信息请参阅 Xform 页的文档。
  • Scale Rotate Translate srt -
  • Scale Translate Rotate str -
  • Rotate Scale Translate rst -
  • Rotate Translate Scale rts -
  • Translate Scale Rotate tsr -
  • Translate Rotate Scale trs -
Rotate Order prord - 更多信息请参阅 Xform 页的文档。
  • Rx Ry Rz xyz -
  • Rx Rz Ry xzy -
  • Ry Rx Rz yxz -
  • Ry Rz Rx yzx -
  • Rz Rx Ry zxy -
  • Rz Ry Rx zyx -
Translate pt - 更多信息请参阅 Xform 页的文档。
  • X ptx -
  • Y pty -
  • Z ptz -
Rotate pr - 更多信息请参阅 Xform 页的文档。
  • X prx -
  • Y pry -
  • Z prz -
Scale ps - 更多信息请参阅 Xform 页的文档。
  • X psx -
  • Y psy -
  • Z psz -
Pivot pp - 更多信息请参阅 Xform 页的文档。
  • X ppx -
  • Y ppy -
  • Z ppz -
Uniform Scale pscale - 更多信息请参阅 Xform 页的文档。
Reset Transform preset - 此按钮会重置此页的变换，使其没有 translate／rotate／scale。
Commit to Main Transform pcommit - 此按钮会将此页的变换复制到主 Xform 页，并重置此页的变换。
Xform Matrix/CHOP/DAT xformmatrixop - 此参数可直接用 4x4 矩阵进行变换。有关直接指定矩阵的方法，请参阅 Matrix Parameters 页。该变换会应用在常规 Pre-Transform 变换之后，即按 XformMatrix * PreXForm * Position 的顺序应用。
