密钥管理器对话框

说明

Key Manager 让你创建、安装和禁用 TouchDesigner 的密钥。如果 TouchDesigner 启动时找不到有效密钥，Key Manager 对话框会自动打开。

在 TouchDesigner 已运行时，可以从 Dialogs 菜单打开 Key Manager，或使用 <alt+k> 快捷键。

创建密钥

本节介绍在计算机可连接互联网时为 TouchDesigner 创建并安装密钥。如果计算机没有网络连接，请参见下方的 Offline 一节。

  1. 在 Key Manager Dialog 顶部选择 Create 选项。
  2. 使用你的 Derivative 账户用户名和密码登录。点击 Sign In 按钮。
  3. 在接下来的对话框中，会显示你账户中所有可用的许可证。选择要用来创建密钥的许可证，然后点击 Create Key 按钮。灰显的许可证需要 updated 后才能与已安装的版本配合使用。

密钥将被创建并安装，然后就可以使用了。

离线 - 创建密钥

ONLY Use this method if your computer is offline. To disable the key in the future you will need an internet connection.

本节介绍在计算机无法连接互联网时创建并安装密钥。

如果 TouchDesigner 所在计算机无法连接互联网，可以在另一台联网设备上为其创建密钥。

1. 在需要创建密钥的计算机上，记下 Key Manager 对话框底部附近的 Machine Name 和 System Code。

2. 前往 MY ACCOUNT 并登录。前往 MY LICENSES。


3. 找到你想用来创建新密钥的许可证。该许可证不能正在另一台计算机上使用（如果正在使用，请参见「禁用密钥」）。


4. 点击该许可证以展开其 Details。点击 Create Key 按钮继续。

5. 在弹出对话框中，输入显示在 Key Manager 对话框底部的计算机信息。准备好后点击 Generate，密钥就会被创建。


6. 复制密钥并粘贴到 Key Manager 对话框的 Install 区域。点击 Install Key 按钮，就可以使用了！

禁用并转移密钥


密钥必须处于 Disabled 状态，才能转移到另一台机器，或在 update 许可时创建新密钥。

禁用密钥时计算机必须连接到互联网。需要此连接，以便在你的 Derivative 账户中禁用该密钥，从而允许你为另一台计算机创建新密钥。

  1. 在 Dialogs 菜单下打开 Key Manager Dialog。
  2. 在 Key Manager Dialog 顶部选择 Disable 选项。
  3. 下面的列表显示当前有效的密钥。点击要禁用的密钥以选中它。
  4. 点击 Disable Key 按钮。如果该密钥已在你的账户中（在 Derivative 服务器上）和本地成功禁用，它会从列表中移除，现在可以在另一台计算机上使用了。

对话框的 Help 部分回答了一些常见问题。

系统代码

疑难解答

如果在运行 TouchDesigner 时出现 Key 或 License Retrieval Error，请参阅 Troubleshooting 中的 Problems after installation with licensing or keying。

现有密钥停止工作最常见的原因是机器的系统代码发生了变化。TouchDesigner license keys are system code specific，系统代码用于创建密钥，如果系统代码变了，密钥就无法工作。你可以在 Key Manager 对话框底部查看当前的系统代码。登录 MY ACCOUNT 并在 MY LICENSES 中查看许可证，可以检查创建密钥时使用的系统代码。

系统代码常常在更换核心硬件（CPU / 主板）或更改操作系统（例如重装或更换版本）后发生变化。

系统代码由计算机硬件和已安装操作系统的各种细节生成，其中任何细节改变都会导致完全不同的系统代码。

在装有有效 TouchDesigner 密钥的机器上进行这类更改之前，我们建议先用 Key Manager Dialog 禁用现有密钥。
