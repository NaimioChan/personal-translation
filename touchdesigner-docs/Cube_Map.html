立方体贴图

Cube Map 是一种用 3 个纹理坐标采样的纹理。它由 6 张 2D 纹理组成，分别映射到单位立方体的一个「面」上（+X、-X、+Y、-Y、+Z、-Z）。3 个纹理坐标被当作从立方体中心某点出发的向量，向量命中立方体某个面上的哪一点，就采样该处的纹素。因此，根据向量指向的方向会选中立方体的某个面，再由该面决定返回其 2D 纹理上的哪个纹素。

可以使用 Cube Map TOP 创建 Cube Map。

Cube map 可用于许多高级光照技术，以及 Phong MAT 中的反射。

此示例文件展示了用 Cube Map TOP 作为 Phong MAT 的 Environment Map 来模拟反射。File:Cubemap.tox

ATI 提供了一个免费的处理 CubeMap 的工具：CubeMapGen。
