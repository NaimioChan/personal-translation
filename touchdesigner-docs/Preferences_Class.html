Preferences 类

Preferences 类描述一组可配置的偏好设置，它们在会话之间保留。可通过 ui.preferences 对象或 Preferences Dialog 访问。

成员

defaults → dict (Read Only):

一个包含各偏好设置及其默认值的字典。

方法

save()→ None:

将偏好设置值保存到磁盘。若未保存，下次启动应用程序时对偏好设置的更改将会丢失。

resetToDefaults()→ None:

将所有偏好设置重置为默认值。

load()→ None:

从磁盘恢复偏好设置值。

特殊函数

len(Preferences)→ int:

返回偏好设置的总数。 

a = len(ui.preferences)

[<preference name>]→ value:

根据偏好设置名称键获取或设置特定的偏好设置。 

v = ui.preferences['dats.autoindent']
ui.preferences['dats.autoindent'] = 0

Iterator→ str:

遍历每个偏好设置名称。 

for p in ui.preferences:
	print(p) # 打印所有首选项的名称
