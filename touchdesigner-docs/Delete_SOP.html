Delete SOP

摘要

Delete SOP 会按组指定或按几何选取来删除输入几何，几何选取使用三种选项之一：按实体编号、按包围体、按实体（图元/点）法线。你可以选择删除选中的几何还是未选中的几何。

deleteSOP_Class

参数 - Number 页

允许按编号选择要分组的实体。勾选后，会显示与此选择选项相关的选项。

Use Number usenumber - 勾选 Number 按钮下的 Enable 按钮后，选择选项会变为可用，可用于选择实体。可用字段列于下方。
Operation groupop - 勾选 Number Enable 按钮后，此选项按定义的模式（Pattern）或范围（Range）对实体分组。
  • Delete by Pattern pattern - 在下面的 Pattern 字段中选择模式。
  • Delete by Range range - 使用下面的 Start/End 和 Select_of_ 字段选择范围。
  • Delete by Expression filter - 使用下面的 Filter Expression 字段选择范围。
Pattern pattern - 当 Operation 设为 Group by Pattern 时激活。在此字段中输入要选取的图元范围。所需语法为 "S.P"，其中 S 是父曲面的索引，P 是该曲面上的轮廓索引。列表中可以将图元与轮廓混用。混合组会自动排序。

For example;
0.4 2 4 2.5 3.7 选取三个轮廓和两个图元
0-100:2 从 0 到 100 每隔一个数字选取
0-10:2,3 每三个中选取两个
0.0-6 在 primitive 0 上选取六个轮廓
0.* 选取 primitive 0 上的所有轮廓
!4 选取除第四个之外的每个图元或点
9-0 选取前十个（若启用 ordered 标记则反向）
!0.* 选取除 primitive 0 上的轮廓之外的所有轮廓
* 选取所有图元或点，不选轮廓

参见 [Scripting Guide] 中的 Pattern Matching

参数 - Normal 页

此选项用于基于实体法线的角度选取实体。勾选后，会显示与此选择选项相关的选项。

Use Normal usenormal - 勾选 Normal 按钮下的 Enable 按钮后，选择选项会变为可用，可用于选择实体。可用字段列于下方。

主轴以及相对定义轴的扩散角共同定义了一个角度范围。如果任何实体法线落在该范围内，则相关实体被选中。

For example；例如你想在 XZ 轴上的多边形山地地形中选取非常陡峭的多边形。可将 Direction 设为 0, 1, 0，将扩散角设为约 75。这样会选取法线从平躺到较缓的所有多边形。你就把所有从平躺到与轴成 75 度角的多边形都分到了一组。剩下的是 76 度或更大的所有多边形。

Direction dir - 0, 1, 0 的默认值会生成一个沿 Y 轴正向上的法线向量，它垂直于 XZ 平面，该平面即成为主轴。1, 0, 0 使法线指向 X 正方向，得到一个垂直于 YZ 平面的法线轴。可以通过输入数值（1, 1, 0 得到 45 度的平面）或使用方向向量手柄交互地调整平面的角度。应使用 0 到 1 之间的值。
  • X dirx -
  • Y diry -
  • Z dirz -
Spread Angle angle - 此字段中输入的值会生成相对主轴的偏移角。可以把它想象成一个圆锥，圆锥底面的半径由 Spread Angle 决定，圆锥的轴由 Direction 轴决定。在视口中查看图元法线，可以看到凡法线角度落在该圆锥所定义角度范围内的图元都会被选中并分组。
Backface from camera - 此菜单用于选择一个对象。通常会选择摄像机对象。从指定对象观看时背面朝向的图元会被分组或选取。
Delete Unused Groups removegrp - 如果某个组的条目数为 0，且启用了此参数，则这些组会被移除。如果要保留空组，请禁用此参数。
Delete Geometry, Keep Points keeppoints - 删除几何但保留点。

Info CHOP 通道

Delete SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
