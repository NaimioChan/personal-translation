ST2110 Device CHOP

摘要

注意

License: 仅在 TouchDesigner Pro 中可用。

此节点用于配置 ST2110 设备的 IP 设置，例如 DHCP 设置、IP 配置和 PTP 设置。目前该节点没有输出任何通道，但有一些 Info CHOP 通道提供诊断信息。

另请参阅 ST2110 In TOP、ST2110 Out TOP。

st2110deviceCHOP_Class

参数 - ST2110 Device 页

Active active - 控制此节点是否主动配置该设备的设置。
Driver driver - - 选择使用哪个设备驱动来搜索设备并与之通信。
  • Blackmagic blackmagic - 使用 Blackmagic 驱动。
  • Deltacast deltacast - 使用 Deltacast 驱动。 NOTE: This driver is deprecated and support for Deltacast IP cards will be removed in future versions.
  • AJA aja - 使用 AJA 驱动。
Device device - 选择要配置的设备。
Use DHCP usedhcp - 选择是否使用 DHCP 配置设备主端口的 IP 地址。
IP Address ipaddress - 若 DHCP 已禁用，手动设置 IP 地址。
Subnet subnet - 若 DHCP 已禁用，手动设置子网。
Gateway gateway - 若 DHCP 已禁用，手动设置网关。
PTP Profile ptpprofile - - 选择要使用的 PTP 配置文件，适用于支持选择的设备。
  • Off off -
  • ST2059-2 st2059-2 -
  • AES67 aes67 -
PTP Address ptpaddress - 手动设置 PTP grandmaster 的地址。
PTP Domain ptpdomain - 手动设置 PTP 域。
IGMP Version igmpversion - - 选择用于组播加入/离开及其他 IGMP 操作的 IGMP 版本。
  • Version 2 vesion2 -
  • Version 3 version3 -
  • Version 2 and 3 version2and3 -

参数 - SPS 页

Enable SPS enablesps - 启用设备上的 SPS 端口。
Use DHCP spsusedhcp - 选择是否使用 DHCP 配置设备上 SPS 端口的 IP 地址。
SPS IP Address spsipaddress - 若 DHCP 已禁用，手动设置 IP 地址。
SPS Subnet spssubnet - 若 DHCP 已禁用，手动设置子网。
SPS Gateway spsgateway - 若 DHCP 已禁用，手动设置网关。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

ST2110 Device CHOP 的额外信息可通过 Info CHOP 获取。

特定于 ST2110 Device CHOP 的 Info 通道

  • packets_received - 主端口上接收的数据包数量；若设备不支持此查询，则为 -1。
  • packet_errors - 主端口上发生的数据包错误数量；若设备不支持此查询，则为 -1。
  • multicast_groups_joined - 主端口加入组播组的次数；若设备不支持此查询，则为 -1。
  • multicast_sources_added - 主端口添加组播源的次数；若设备不支持此查询，则为 -1。
  • multicast_changes - 主端口上发生的组播变更操作次数；若设备不支持此查询，则为 -1。
  • ptp_locked - 若主端口上的 PTP 已锁定到 PTP grandmaster 则为 1，若 PTP 未锁定则为 0，若设备不支持此查询则为 -1。
  • sps_packets_received - SPS 端口上接收的数据包数量；若设备不支持此查询，则为 -1。
  • sps_packet_errors - SPS 端口上发生的数据包错误数量；若设备不支持此查询，则为 -1。
  • sps_multicast_groups_joined - SPS 端口加入组播组的次数；若设备不支持此查询，则为 -1。
  • sps_multicast_sources_added - SPS 端口添加组播源的次数；若设备不支持此查询，则为 -1。
  • sps_multicast_changes - SPS 端口上发生的组播变更操作次数；若设备不支持此查询，则为 -1。
  • sps_ptp_locked - 若 SPS 端口上的 PTP 已锁定到 PTP grandmaster 则为 1，若 PTP 未锁定则为 0，若设备不支持此查询则为 -1。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
