OpenCV

OpenCV（Open Source Computer Vision）是一个编程函数库，主要面向实时计算机视觉，最初由 Intel 的一个研究中心开发，现已开源。

TouchDesigner 预装了 OpenCV 4.8.0（包含贡献模块），以及与 TouchDesigner 的 Python 3.11.1 对接的 numpy，使 TouchDesigner 可以直接访问 OpenCV 函数。

OpenCV 用于 Script TOP、Blob Track TOP 和 camSchnappr。

将纹理转换为 numpyArray

通过调用 myTop.numpyArray() 方法，每个 TOP 都可以直接转换为 NumPy 数组（另见：TOP Class#Methods）

NumPy 数组是 openCV 保存数据的默认数据结构。一般而言，NumPy 可以理解为一个供 Python 使用的库，用于支持大型多维数组和矩阵，以及大量用于操作这些数组的高层函数。（对比：NumPy）

示例：为纹理应用颜色映射表

以下示例是一个 Script TOP 的内容。OpenCV 函数 cv2.applyColorMap() 接受单色图像以及对预定义颜色映射表的引用，其作用本质上与 TouchDesigner 中的 Lookup TOP 相同。更多信息见：ColorMaps in OpenCV

def onCook(scriptOp):
	# 以延迟一帧的方式获取 scriptTOP 的输入
    # 以获得更快的运行速度（对比 TopTo CHOP）
	input = scriptOp.inputs[0].numpyArray(delayed=True)

	# 图像是否已就绪？
    # 第一帧会是 None，因为我们是晚一帧取数据。
	if not input is None: 
		# 提取红色通道并转换为 uint8
		sChan = cv2.extractChannel(input,0)*255
		sChan = sChan.astype('uint8')

		# 为红色通道应用色图
		output = cv2.applyColorMap(sChan, cv2.COLORMAP_TWILIGHT_SHIFTED)
        # 把 numpyarray 输出到 Script TOP
		scriptOp.copyNumpyArray(output)
	return

示例：在纹理中查找特征

以下示例是一个 Script CHOP 的内容。首先指定 Script CHOP 的参数。

每次计算 Script CHOP 时，Top 自定义参数中指定的操作符都会被读入 numPy 数组，然后传给名为 goodFeaturesToTrack 的 openCV 函数。

注意： 所引用的 TOP 应为单色图像。可以使用 Monochrome TOP 把彩色纹理转换为灰度。这样做，并使用 Luminance 函数作为转换方式，就不必在脚本中执行此步骤（许多 openCV 函数期望输入灰度图像）。

所得的输出可用于 Instancing 设置中。

# me - 此 DAT
# scriptOp - 正在 cook 的 OP

# 在 OP 中按下 'Setup Parameters' 可调用此函数重新创建参数。
def onSetupParameters(scriptOp):
	# 创建自定义页
	page = scriptOp.appendCustomPage('Good Features')

	# 创建一个自定义 TOP 引用参数
	topPar = page.appendTOP('Top', label='TOP (monochrome)')

	# 创建一个自定义参数，用于指定要检测的特征数量
	p = page.appendInt('Features', label='Number of Features')
	p[0].default = 25
	p[0].normMin = 1
	p[0].normMax = 250

	# 创建一个自定义参数，用于指定最低质量级别
	# 低于该级别时，检测到的特征会被拒绝
	p = page.appendFloat('Quality', label='Minimum Quality Level')
	p[0].default = 0.01
	p[0].normMin = 0.001
	p[0].normMax = 1

	# 创建一个自定义参数，用于指定最小距离
	# 即检测到的特征之间的距离
	p = page.appendInt('Distance', label='Minimum Distance')
	p[0].default = 10
	p[0].normMin = 1
	p[0].normMax = 1200
	return

import numpy as np
import cv2

def onCook(scriptOp):
	scriptOp.clear()
	
	# 读取参数以确定要检测的特征数量
	topRef = scriptOp.par.Top.eval()
	features = scriptOp.par.Features
	quality = scriptOp.par.Quality
	distance = scriptOp.par.Distance
	
	# 默认值
	xVals = []
	yVals = []
	corners = []
	
	if topRef:
		# 以 numpyArray 方式读取 top
		img = topRef.numpyArray()
		
		# 由于从灰度 TOP 读取，除红色通道外全部丢弃
		# 这样也就可以跳过本来用于把彩色图转换为灰度的 cv2.cvtColor 函数
		img = img[:,:,:1]
		
		# 运行 OpenCV 的 goodFeaturesToTrack 函数
		# https://docs.opencv.org/3.0-beta/doc/py_tutorials/py_feature2d/py_shi_tomasi/py_shi_tomasi.html
		corners = cv2.goodFeaturesToTrack(img,features,quality,distance)
		
		# 对数组切片，把 x 和 y 位置分到 2 个变量中
		xVals = corners[:,:,0:1]
		yVals = corners[:,:,1:2]
	
	# 为 scriptOp 设置 2 个通道
	# 并把长度设为检测到的特征数量
	scriptOp.rate = me.time.rate
	scriptOp.numSamples = len(corners)
	tx = scriptOp.appendChan('tx')
	ty = scriptOp.appendChan('ty')
	
	# 为通道赋值
	tx.vals = xVals
	ty.vals = yVals
	return

示例：在 OpenCV 中添加元素

需要注意的一点是，OpenCV 的坐标系原点在左上角，而 TouchDesigner 以左下角为基准。因此，在 openCV 中向纹理叠加线条、文字或其他图形元素时，需要先翻转源纹理，处理后再翻回来。

以下示例会从 Script TOP 的输入读取纹理并添加一些文字：

# me - 此 DAT
# scriptOp - 正在 cook 的 OP

# 在 OP 中按下 'Setup Parameters' 可调用此函数重新创建参数。
def onSetupParameters(scriptOp):
	return

# 每当推入自定义 pulse 参数时调用
def onPulse(par):
	return

import cv2
def onCook(scriptOp):
	# 获取 scriptOp 的输入纹理
	inputTex = scriptOp.inputs[0].numpyArray(delayed=False)

	# 在向图像添加内容之前，需要先翻转它，因为 OpenCV 的坐标系
	# 起点在左上，而 TouchDesigner 起点在左下
	# flip() 的第二个参数是围绕哪个轴翻转
	inputTex = cv2.flip(inputTex, 0)

	# 现在来添加一些文本
	outputTex = cv2.putText(inputTex, 'Derivative', (100,400), cv2.FONT_HERSHEY_PLAIN, 10, (255, 0, 255), 2, cv2.LINE_AA)
	
	# 把纹理翻回来，以回到 TouchDesigner 坐标空间
	outputTex = cv2.flip(outputTex, 0)
	
	# 把最终纹理写入 scriptOp
	scriptOp.copyNumpyArray(outputTex)
	return
