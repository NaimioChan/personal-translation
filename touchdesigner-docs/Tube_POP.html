Tube POP

摘要

Tube POP 以圆柱或管状创建行和列的点。这些点可以通过 Connectivity 菜单使用各种图元连接。

管的底部和顶部各有半径参数，加上高度参数，可实现锥形管。

Connectivity 菜单让你输出三角形、交替三角形、四边形、线、线带、点图元，或不输出任何图元（None，只有点）。

你指定行数和列数。列指圆周方向的分段，行指沿侧面的分段。

在 Connectivity 菜单中，你可以沿 Rows、Columns 或两者合并的方向创建线和线带。

管绕某一轴（默认为 Y）对称，但可以使用 Rotate 和 Translate 参数对管进行后旋转和后平移。

Anchor 会将管的左侧、中心或右侧对齐到 X=0、Y=0 或 Z=0。

Details 页允许通过指定任意起始/结束角度的弧来创建部分圆柱。

End Caps 开关会添加三角形或四边形来填充端盖，使管成为封闭体积，这仍会保留 Dimension，因为没有添加或移除点，只是添加了图元。

Dimension：当管被传递到其他 POP 时，无法确定指定了多少行和列。然而 Tube POP（以及其他生成器 POP）会将其 Dimensions 作为元数据输出到所有连接到它的 POP，表明其在点列表中的点组织方式。管的维度为 numCols numRows，可被 _Dim[] 等内置属性或 GLSL 代码使用。

你可以输出点法线或顶点法线（生成 N 属性），也可以输出点纹理坐标或顶点纹理坐标（Tex 属性）。

Tube POP 接受一个输入，这将使初始管具有与输入边界框相同的边界框。然后打开 Modify Bounds 可进一步变换管。

另请参阅 Grid POP、Sphere POP、Torus POP、Revolve POP、Dimension

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
