Intel 处理器与 TouchDesigner

在考虑构建由 TouchDesigner 驱动的媒体服务器时，首先要考虑的是需要什么显卡和外设，以支持满足服务器用途所需的一系列功能。做出这些选择后，才可以选择 CPU。CPU 的选择又会通过 CPU 插槽类型以及内存和 PCI 插槽配置来限制主板的选择。

另请参阅 TouchDesigner Video Server Specification Guide。

用于 TouchDesigner 的 Intel 产品线

TouchDesigner 可运行在任何 Intel Core 或 Xeon 处理器上。这两类处理器有非常广泛的代次和型号。本文介绍 CPU 基础知识，以便更容易地为 TouchDesigner 选择处理器。

  • 整个 Xeon 处理器系列 - https://ark.intel.com/content/www/us/en/ark.html#@PanelLabel595

CPU 时钟速度 - GHz

TouchDesigner 主应用运行在单个线程上。这意味着对于单个 TouchDesigner 实例，只有一个核心会依次计算每个操作。要以 60 FPS 运行，你的 TD 应用必须能在 1/60 秒即 16.666 ms 内计算完所有操作。如果你的 TD 应用有受 CPU 限制的高处理需求，在 CPU 产品、代次等其他条件相同的情况下，提供更多处理能力的唯一方法就是更高的时钟速度。

因此，在其他条件相同的情况下，理想的 CPU 是满足你所有需求、且单核速度尽可能高的型号。单核速度以 Gigahertz 或 GHz 表示。

核心数量

除其他方面外，负责从磁盘流式读取影片文件和图像序列的 TouchDesigner Movie File In TOP 操作符是多线程的。这意味着每个正在解码的影片都可以独立于 TouchDesigner 主线程并行访问 CPU 资源。操作系统会自动管理线程到 CPU 核心的分配。在计算给定视频服务器用例所需的 CPU 型号和数量时，有很多因素会起作用。

如果媒体服务器要用 Movie File In TOP 解码多路 H.264 流，那么 CPU 拥有多个核心就很重要。此外，Windows 可以并行运行多个独立的 TouchDesigner 或 TouchEngine 进程，因此拥有合适数量的核心来支持所需的线程数非常重要……

PCI Express 通道

在配置 PC 并为 TouchDesigner 驱动的系统选择合适 CPU 时，理解 PCI-e 通道的基本功能和命名至关重要。PCIe 通道是扩展设备（如硬盘和显卡）与 CPU 之间的数据传输通路。单条通道具有以字节/秒计量的特定带宽。数据沿通路传输的频率决定传输速率。 一条 PCIe 3.0 通道的带宽为 1GB/s。主板上的 PCIe 端口通常是 x1、x4、8x 或 x16，会按所表示的倍数增加端口带宽。

给定的 CPU 只支持最多一定数量的 PCIe 通道。给定的 PCIe 扩展卡需要特定数量的通道，进而需要支持所需带宽的特定 PCIe 插槽。因此，在决定 CPU 和主板之前，我们必须先考虑支持显卡和任何其他扩展板所需的 PCIe 通道数。

截至 2018 年第四季度，唯一需要关注的 PCI Express 版本是 PCI Express 3.0。整个 Intel Core 和 Xeon 芯片系列都只支持 3.0。这意味着在查看 CPU、显卡、视频和硬盘控制器扩展板的规格时，「通道数」通常指的是 PCI Express 3.0 通道数。

系统对比：8 通道 vs 16 通道 - PCI 通道总是很重要吗？

2019 年 10 月，我们与墨西哥城的 Cocolabs 合作开展了一项案例研究。我们有机会比较 2 种系统配置的性能。这两个系统被命名为 Coco1 和 Coco2。

Coco1 系统使用具有 48 条 PCI 通道的 Xeon 处理器。Coco2 使用仅提供 16 条 PCI 通道的 i7。此外，Coco1 的主板内置双 10G 网卡，并配备更快的 NVMe Samsung SSD。Coco2 更便宜。

两个系统都使用相同的双 Quadro P4000 显卡。每块 P4000 Quadro 卡可使用 16 条 PCI 通道。由于 Coco2 的 CPU 只有 16 条通道，使用两块卡会迫使 PCI 通道以 8x 模式运行，实际上使通过 PCI 总线向显卡推送和读取数据的总带宽减半。

考虑到这些差异，比较这 3 种系统配置的合成性能基准会很有意思。注意 Coco2-1 和 Coco2-2 是相同配置的系统，但 Coco2-1 的单块 GPU 以 x16 运行，Coco2-2 的单块 GPU 以 x8 运行。

Intel Core

Intel Core 系列处理器是搭建 TouchDesigner 开发机最广泛使用的处理器。 它们是最通用的芯片，适合游戏、计算机图形设计、编程，并非常适合视听系统。

Core 代次

在 Intel Core 产品线中存在代次的概念。Core 处理器已存在多年，因此经历了许多代次和微架构。所有代次的 Core 处理器都能与 TouchDesigner 良好配合。后续代次会带来一系列影响 TouchDesigner 性能的改动。新一代产品中可能包含大量功能调整和架构修改。

超线程

超线程是一种在两个独立线程之间更高效地共享单个核心的 CPU 周期调度技术。 超线程已存在多年，因此过去 10 年 TouchDesigner 的大部分使用都是在支持超线程的 CPU 上完成的。Intel 推出了一系列不支持超线程的现代第 9 代处理器，因此值得注意这一差异。

由于 TouchDesigner 运行在单个线程上，在不支持超线程的 CPU 上，TouchDesigner 主应用不会受到性能损失。查看处理器规格时，如果线程数是核心数的 2 倍，则该处理器支持超线程。如果核心数与线程数相同，则不支持。

Turbo Boost

Turbo Boost 是一项在运行 TouchDesigner 这类高负载应用时自动提高处理器运行频率的功能。但该功能只能在有限时间内以更高频率爆发，因此基础时钟和睿频频率都是重要的考虑因素。Turbo boost 让 CPU 核心在无负载时以更节能、更低的温度运行。运行 TouchDesigner 时，Intel 处理器通常会提升到其支持的最高时钟频率。

基础时钟是指定 CPU 保证的基础速度。运行温度和散热会影响特定配置的持续运行频率。

CPU-z 可以监视每个核心的运行频率。 在此免费下载……

https://www.cpuid.com/softwares/cpu-z.html

查看处理器规格时，如果处理器有 Base Frequency 和 Max Turbo Frequency，则支持 Turbo Boost。如果只有 Base Frequency，则不支持。

内存

CPU 和主板通常决定必须使用什么内存。一般建议购买 CPU 支持的最快内存。

组装台式机时，除显卡（GPU）外，CPU 通常是第一项选择。选定 CPU 后，你可以参考本文的主板部分。选定主板后，你可以参考主板规格或主板的合格供应商列表（QVL）来选择合适的内存。

Intel 集成显卡

许多 Intel CPU 自带集成 GPU。这些 GPU 通常可与 TouchDesigner 配合使用，但性能远低于 Nvidia GPU，可能不适合要求高的 TouchDesigner 视频服务器应用。不过它们很可能可以播放简单的视频流并执行其他简单任务，因此嵌入式 Intel GPU 适合轻量级用例。

主板主 IO 背板上的内置 HDMI 端口由 Intel GPU 驱动。如果你现在或将来有兴趣使用这些端口，选择时要仔细查看主板规格。HDMI 1.4 仅支持 4K @ 30hz，而 HDMI 2.0 支持 4K @ 60Hz 及更高。DisplayPort 通常支持 4K @ 60Hz。

Core 系列

Core-i3

Core i3 处理器是 Core 系列中的入门线，在过去十年的大部分时间里只支持 2 个核心。不过随着第 8 代和第 9 代的发布，现在已有 4 核型号。这些处理器价格低廉，并配备了相当不错的时钟速度。 这些高性价比处理器确实适合低功耗、小尺寸的基础视频服务器/信息亭类应用。

注意 i3 系列不支持超线程或 Turbo Boost。这意味着这些 CPU 被锁定在单一运行频率，你必须拥有足够的核心来运行 TouchDesigner 以及操作系统和其他任务。 对于注重性价比的应用，仍建议至少提供 4 个核心，尤其是在有任何视频解码的情况下。

此外，PCI Express 通道数最多为 16，因此你只能使用一块高性能 GPU 或少数几块 8x PCI 板卡。

例如，i3-8350K 处理器支持 4 个核心，运行频率为 4Ghz。该 CPU 很可能带来不错的 TouchDesigner 性能，并有足够核心来管理视频解码或次级音频处理等其他并行线程。其价格远低于 200 美元，因此值得一看。

Core-i5

对于 TouchDesigner 系统装机者来说，i5 确实让位于顶级的 i7 系列。不过最近几代 i5 被赋予了极具吸引力的核心数和更高的时钟速度。较新一代的 i5 往往具有与上一代同类 i7 相当的性能。 现在我们已进入第 9 代，有大量非常强劲的 i5 处理器可用于构建基于 TouchDesigner 的服务器。

如果视频服务器应用定义明确，例如 6 核且无超线程的 CPU 就能满足所需的视频解码和其他要求，那么第 8 代 Intel® Core™ i5-8600K 将是不错的选择，价格远低于 300 美元。

大多数 i5 处理器支持 Turbo Boost，而大多数不支持超线程。与 i3 一样，PCI Express 通道数上限为 16 条。

第 8 代及以后的 i5 处理器对于广泛的视频服务器应用来说非常够用。这一类别的主要限制因素是核心数，以及大多数处理器缺少超线程。如果仅 6 个核心就足够，这里可以省下一些钱。

Core-i7

i7 CPU 一直是大多数 TouchDesigner 应用的标准选择。 大多数 i7 处理器支持超线程、Turbo Boost 和超频。第 9 代 i7 的最高时钟速度已越过 4Ghz 大关，缓存也更大，但在某些情况下也失去了超线程。

i7 处理器无疑是 TouchDesigner 工作站的理想处理器，也适合大多数不需要大量 PCI Express 通道的视频服务用例。

整个 i7（非 X 系列）处理器系列的芯片上 PCI express 通道最多为 16 条。

一般来说，同一代的 i7 以及现在的 i9 会支持最高的时钟速度和最多的核心数。你要支付溢价才能获得当今可用的最高性能 - 这体现在 i7 和 i9 系列上。与 i3 不同，i5、i7 和 i9 通常支持超频。

Core-i9

从架构上没有什么能明确区分 i9 与其前代 i7。两者都基于相同的 Skylake 微架构。i9 系列会获得更高的核心数，而 i7 系列可能最多到 i7-7820x 的 8 核。此外，i9 在某些情况下最终会多出几条 PCI Express 通道，并且肯定有更高的时钟速度。不过目前第 9 代 i7 处理器有不再支持超线程的趋势，因此查看规格时这也是需要留意的另一个特性。

Core-X

These processors are great for general purpose TouchDesigner applications.

X 系列处理器实际上横跨 i5、i7 和 i9 系列。每一代都有一些 X 系列处理器配备通常使其在性能上处于市场顶端的特性。在 ark.intel.com 上，核心数最多、时钟速度最高、具备更大缓存等高级特性的 Core CPU 可以在 Core X 系列部分找到。如果你按产品代码查找处理器，也可能发现它们不在通用分类中。

这些准专业级处理器专为 TouchDesigner 这类高要求应用设计，因此拥有更多核心、更高时钟速度、更大内存缓存，某些情况下还有多得多的 PCIe 通道。

所有 X 系列处理器都没有片上 Intel GPU，这对任何用显卡搭建 TouchDesigner 服务器的人来说都无所谓。 这些处理器始终支持超线程和 Turbo Boost。

对于构建单 CPU 高需求、高分辨率 TouchDesigner 服务器的人，应该在这里寻找顶级、最先进的 CPU。 该类别中任何满足性能要求且在预算内的处理器都会有良好表现。

Intel Xeon

Xeon 处理器是为服务器和高性能工作站设计的。在过去 10 年里，Xeon 处理器平台被 TouchDesigner 系统装机者广泛使用，以提供最多的核心数和最多的 PCI 通道，用于需要系统长期 24 小时运行（常以年计）的场景。

Xeon 处理器还设计为每块主板可使用多个处理器。所有 Core 处理器每块主板只支持单个 CPU。从 TouchDesigner 服务器的角度看，在 Xeon 与例如最高时钟速度相当的顶级 Core X 处理器之间做选择时，核心总数是最重要的因素。如果某个用例需要的 CPU 核心数超过单个 Core CPU 物理上所能提供的，可能就只能选择 Xeon。

过去一年，随着 Core i9 X 处理器产品线，单 CPU 核心数已从 2017 年最多仅 8 个核心飙升至多达 18 个物理核心。 这对需要高时钟速度和最多核心数的 TouchDesigner 服务器来说是一个游戏规则的改变，因此重新比较 Xeon 与 Core 变得愈发有意义。

在做直接对比之前，我们先看看 Xeon 系列相对 Core X 系列有哪些特性。

多处理器支持

Xeon 的一大优势是每块主板支持多个 CPU。（E3 系列等部分型号除外 - 请查看各自规格以确认）

更高的 PCI Express 通道数

Xeon 处理器通常支持更多 PCI-Express 通道，以支持硬件 RAID 控制器、视频 IO 卡和其他扩展板等设备。

支持 ECC 内存

纠错码内存（ECC 内存）可自动检测并即时修复单比特错误，使工作站应用可靠运行、免受数据损坏。对于高要求、任务关键的 TouchDesigner 媒体服务器场景，ECC 内存是一项重要特性。

不支持超频

许多 i5 和大多数 i7 处理器设计为可超频。 Xeon 则不能。

L3 缓存

CPU 缓存将最近取回的数据保存在内存中，以备再次需要。对于许多数据搜索用例，这可以大幅提升性能。大多数 TouchDesigner 应用从极大的三级缓存中获益很少，不过这种额外缓存是 Xeon 在高要求应用中能比 i7 快得多的原因之一。

耐久性 - 运行时间

Xeon 处理器经过认证，可日复一日地承受更重、更密集的负载。对于严肃的工作站用户，这意味着相比 i7 同类产品有更好的寿命。如果 TouchDesigner 服务器用例要求系统在常开状态下运行 5 年以上，那么仅凭这一点就值得考虑 Xeon CPU。

超线程

大多数（即使不是全部）Xeon CPU 都支持超线程。 不过所有 Core-X 系列处理器也都支持。

Xeon 系列与型号编号

截至 2018 年第四季度，Intel 有一套重新命名的 Scalable 系列 Xeon 处理器。筛选合适的 Xeon 处理器的最佳方法是使用 ARK 网页并按「Max Turbo Frequency」列排序。 一旦筛选出时钟速度最高的 CPU，就可以反推找到合适的核心数等。

Core 与 Xeon 对比

希望现在在 Core 与 Xeon 之间做选择更加直接了。如果你能从 Core X 系列的单颗 CPU 获得足够的 PCI 通道，那大概是最佳方案。如果你需要的通道数超过任何单颗 Core 处理器所能提供的，你就只能选择 Xeon 双 CPU（或更多）配置。而如果你担心崩溃，就需要 ECC 内存，因此也就需要 Xeon。
