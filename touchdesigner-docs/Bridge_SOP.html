Bridge SOP

摘要

The Bridge SOP 适用于蒙皮修剪曲面、孔洞，以及在手臂与身体、分支或管道交叉处创建高度可控的接合。

The Bridge SOP 与 Skin SOP 类似，但对生成曲面的控制强得多。给定一组轮廓（即曲面上的曲线）和/或空间面，Bridge SOP 会构建具有指定切线和曲率特征的 NURBS 蒙皮。生成曲面的精度高度依赖于所需横截面的数量和轮廓提取的质量。高精度会生成非常密集的曲面，并可能带有许多多重节点。

一般来说，曲线阶数越高，Bridge SOP 能提供的拟合越好。不过通常最好坚持使用三次（4 阶）曲线，因为软件针对三次曲线做了优化。

由于 Bridge SOP 既能连接一组空间曲线，也能连接修剪曲线，因此它的用法很像 Skin SOP 和/或 Fillet SOP。不过，桥接修剪曲面的开销大于桥接雕刻曲面。

在 Project SOP 之后，通常需要 Trim、Bridge 或 Profile SOP。

  • 使用 Trim SOP 在投影曲面上切孔
  • 使用 Bridge SOP 将轮廓曲线蒙皮到另一条轮廓曲线。
  • 使用 Profile SOP 提取曲面上的曲线，或重新映射其位置。

注意： 要为生成的蒙皮做纹理映射，请使用 Orthographic 投影，而不是基于 Spline 的投影。这样可获得更好的跨曲面连续性。

参数 - 页

Group group - Group 编辑字段允许输入要桥接的轮廓和/或面的轮廓组。如果有规则的几何曲线或曲面，此项为可选；但要让 Bridge 处理轮廓曲线，必须在此处输入内容。例如 *.0 会桥接所有输入图元的第 0（第一）个轮廓。

注意： 如果希望 Bridge SOP 桥接曲面上的曲线，请务必指定曲面上的曲线；否则它会尝试桥接自由漂浮的曲线。

Bridge bridge - - 允许桥接 N 个图元的子组或图元的模式。
  • All Primitives all -
  • Groups of N Primitives group -
  • Skip Every Nth Primitive skip -
N inc - 决定此 SOP 要桥接的图元模式。
Order order - 设置轮廓提取和蒙皮操作的样条阶数。

参数 - Surface Properties 页

Min X-Sections isodivs - 生成蒙皮中最少的横截面数量。如果创建高密度曲面，TouchDesigner 的细节级别可能会使曲面显示得不如实际平滑。可以通过调整视口的视口显示选项（例如 viewdisplay -l 1.5 SOPmain.persp1）来提高细节级别。

Production Tip: 如果在生成平滑曲面时创建了极其复杂的曲面，可以追加 Refine SOP 并使用其 Unrefine 选项，在不损害曲面外观的前提下去除部分复杂度。在 Refine SOP 中，将 First U 参数设为 0，并在 Unrefine 选项的参数中，将 U 值设为接近 Bridge SOP 中所创建曲面的阶数。

Use frenet - - 指定用于计算方向的法线类型：
  • The Frenet Frame of the Face frenet - 面的 Frenet Frame。此选项使用曲线上的局部坐标系来计算方向。
  • The Normal of the Face normal - 面的法线。
Circular Arc Fillet circular - 让 TouchDesigner 尝试生成圆形圆角，而不是自由形式圆角。只使用切线缩放的正负号；在构建圆形圆角时会忽略缩放大小。

圆角半径会自动计算，并根据导轨（曲线和/或轮廓）之间的间距及其切线进行调整。

Rotate Tangents rotatet - - 缩放和旋转参数包含三个字段。旋转字段（度）对切线施加进一步的旋转，而缩放参数则进一步缩放切线。
  • rotatet1 - 应用于输入中的第一个面。
  • rotatet2 - 应用于所有中间的面。
  • rotatet3 - 应用于输入中的最后一个面。
Scale Tangents scalet - - 缩放和旋转参数包含三个字段。旋转字段（度）对切线施加进一步的旋转，而缩放参数则进一步缩放切线。
  • scalet1 - 应用于输入中的第一个面。
  • scalet2 - 应用于所有中间的面。
  • scalet3 - 应用于输入中的最后一个面。
Use Curvature curvature - 同时也考虑曲率。
Scale Curvatures scalec - - 对曲率进一步缩放。

注意： 如果生成的蒙皮隆起过大，可以禁用 Preserve Tangent 和 Preserve Curvature Magnitude 参数，并手动微调 Tangent Scales 和 Curvature Scales，从而在曲面之间获得平滑过渡。一般来说，除非想使生成的曲面变形，否则应避免调整切线的旋转。

如果桥接的一侧隆起而另一侧没有，请尝试增大桥接中的 Min. Number of Cross sections。

参数 - Profile Extraction 页

此页的参数与 Fit 和 Project SOP 中的类似。

Divisions per Span sdivs - 每个跨度中计算的二维点数量。
Tolerance tolerance - 二维拟合算法的精度。
Preserve Sharp Corners csharp - 启用或禁用急转弯的拟合。如果生成的蒙皮出现裂缝，Preserve Sharp Corners 通常是较好的解决方案；但它可能会增加额外的节点，在某些情况下会造成不希望的「波纹」。

如果禁用此选项，生成的等参线会更少，曲面可能无法完全贴合轮廓曲线的轮廓，除非轮廓曲线是使用 Preserve Sharp Corners 选项构建的。

示例

  1. 放置一个 Circle SOP。Primitive Type: NURBS；Radius = 0.2, 0.2
  2. 放置一个 Grid SOP。Primitive Type: NURBS。
  3. 将 Circle 和 Grid SOP 都接入一个 Project SOP。将其设为显示 SOP。你会看到网格上投影出的圆——这就是我们的修剪曲线。
  4. 追加一个 Trim SOP 并将其设为显示 SOP。为视口开启 Gouraud 着色——现在可以看到网格表面被修剪出的孔洞。
  5. 追加一个 Copy SOP。Number of Copies: 2；Translation Z: 1.0；Rotation X: 30。将其设为显示 SOP。现在有了两个带修剪孔洞的网格。
  6. 追加一个 Bridge SOP，并将其设为显示 SOP。Scale Tangents: 0, 0, 0；Use Curvature: On；Preserve Curvature Magnitudes: Off；Scale Curvatures: 3, 3, 3。什么都没有发生。为什么？
  7. 需要指定要蒙皮哪些轮廓曲线。在视口选项中开启 Profile Numbers（点击视口右下角的 M，并启用该图标）。可以看到两条修剪曲线的轮廓编号为 0.0 和 1.0——即第 0 个图元的第 0 个轮廓和第 1 个图元的第 0 个轮廓）。编号奇怪是因为图元编号从 0 开始而不是 1。
  8. 在 Bridge SOP 的 Group 字段中输入：.0——这表示在蒙皮中包含所有（* 通配符）图元的第 0（第一）条曲线。现在可以看到两条修剪曲线之间生成的桥接。蒙皮向外隆起。
  9. 可以通过调整 Scale Curvatures 和 Tangent Magnitudes 来控制隆起。将 Scale Curvatures 设为：-3, -3, -3。现在我们有了一个向内隆起、连接两个孔洞的管道。

  10. 试着移动孔洞的位置和大小（修改 Circle SOP 中的 Translation 和 Radius）。Bridge SOP 会动态更新连接两个曲面的几何。将 Scale Curvature 设为：0, 0, 0 可在两个孔洞之间生成一条直通连接。

操作符输入

  • Input 0: -

Info CHOP 通道

Bridge SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
