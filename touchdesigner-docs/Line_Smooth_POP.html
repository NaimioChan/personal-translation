Line Smooth POP

摘要

Line Smooth POP 通过混合 line strip 上相邻点的位置来平滑 line strip。

它基于两种可选方法进行混合：在 Smooth by Edge Distance 方法中，你给定一个距离，它会在两个方向上沿边缘找到该距离内的点，并用 Gaussian 权重或 Box 权重进行混合。使用 Gaussian 权重时，离计算点越远的点权重越低。使用 Box 权重时，沿相邻边找到的、在指定距离内的所有点在计算最终点位置时权重相同。

在第二种 Smooth by Point Steps 方法中，你给定每个方向上要包含的相邻点数量。在这种方法中，离给定点较远的点也可能被纳入平滑计算。

在 End Points Fixed 选项中，它确保每条 line strip 的原始端点不会移动。

在 Pre-Divide 阶段，它可选择通过细分添加更多点，类似于 Line Divide POP 添加新点的方式，并且可以根据相邻点的曲率添加点。

Per-point mapping of parameters - Line Smooth POP 有一个 Map 页，可让每个点在 Edge Distance 和 Point Step Filter Size 参数上获得不同的值。在此机制中，输入中的单独属性包含用于覆盖（或加到 / 乘以）参数值的数值。参见 Mapping POP Attributes to Parameters。

另请参阅 Line Divide POP、Line Resample POP
