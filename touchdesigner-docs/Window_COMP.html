Window COMP

摘要

Window 组件允许你创建并维护一个独立的浮动或固定窗口，用于显示任意 Panel 或任意 Node Viewer 的内容。

最常见的情况是在默认的 TouchDesigner 项目中设置 Window COMP /perform。/perform 是 Perform Mode 的默认窗口。在 Window 组件的 Parameter 对话框中，你可以调整其设置，例如分辨率、居中方式，以及窗口显示在哪台显示器上。

然后按 F1 进入 Perform Mode，独立操作和显示该面板。

在窗口上按 Esc 可关闭该窗口并返回 Designer Mode。

你可以创建更多 Window 组件，将它们指向面板或其他操作符（如 TOP），调整其参数，然后脉冲 Open as Separate Window 参数查看效果。

使用 Dialog-> Window Placement Dialog，它控制启动时显示哪些 window COMP。项目中的所有 Window COMP 都会列在那里，你可以逐个测试。

窗口可以适配单台显示器，也可以横跨多台显示器。

将 Info CHOP 连接到 Window 组件 —— 它会显示窗口的当前位置和大小，以及窗口是否确实处于打开状态。

另请参阅 Window、Multiple Monitors。

参数 - Window 页

Window Operator winop - 指定窗口要显示的操作符。
Title title - 指定窗口的标题。
Justisy and Offset to... justifyoffsetto - - 下面所有定位参数都相对于你在此处指定的位置。窗口可以超出指定的「区域」，该区域仅用作定位参考。Note for macOS：使用 'Bounds of all Monitors' 时，必须在 System Preferences > Desktop & Dock > Mission Control 中关闭 'Displays have separate Spaces' 开关，详见 Multiple_Monitors#macOS。
  • Primary Display primarydisplay - 主显示器，在 Windows 控制面板中有时称为 main display，在 NVIDIA 控制面板中称为 primary display。
  • Specify Display specifydisplay - 将位置定义为下方 'Display' 参数中指定的显示器。
  • Bounds of All Displays alldisplays - 将位置定义为包含所有显示器。使用此选项时会忽略任务栏。
Ignore Taskbar ignoretaskbar - 该选项为 'On' 时忽略 Windows 任务栏。关闭时会考虑任务栏，因此位置和尺寸不会将其覆盖。
Display display - 当 Area 设为 Single Monitor 时，指定显示器索引。
Justify Horizontal justifyh - - 使窗口相对于显示器或所有显示器边界水平对齐。
  • Left left - 对齐窗口，使其左边缘与指定区域的左边缘重合。
  • Center center - 对齐窗口，使其水平中心与指定区域的水平中心重合。
  • Right right - 对齐窗口，使其右边缘与指定区域的右边缘重合。
  • Mouse mouse - 对齐窗口，使其打开时在鼠标指针处水平居中。
Justify Vertical justifyv - - 使窗口相对于显示器或所有显示器边界垂直对齐。
  • Top top - 对齐窗口，使其上边缘与指定区域的上边缘重合。
  • Center center - 对齐窗口，使其垂直中心与指定区域的垂直中心重合。
  • Bottom bottom - 对齐窗口，使其下边缘与指定区域的下边缘重合。
  • Mouse mouse - 对齐窗口，使其打开时在鼠标指针处垂直居中。
Offset winoffset - - 对齐后应用于窗口的水平偏移。
  • X winoffsetx - 对齐后应用于窗口的水平偏移。
  • Y winoffsety - 对齐后应用于窗口的垂直偏移。
Shift to Single Display single - - 此菜单提供移动打开窗口的选项。你可以将其移到单台显示器，或移到窗口打开时鼠标指针所在的显示器。
  • Off off -
  • Keep on Single Display singledisplay -
  • Keep on Display with Cursor cursordisplay -
DPI Scaling dpiscaling - - 用于管理高 DPI 显示器上 DPI 缩放的选项。要查看显示器的 DPI 缩放设置，可以使用 Monitors DAT 并参考 dpi_scale 列。
  • Native native - 使用显示器原生像素的完整分辨率，无论操作系统对该显示器的显示缩放设置如何。即 Display Scale = 1.0。此时一个 'Panel Unit' 等于一个像素。
  • Use DPI Scale usedpiscale - 使用操作系统对该显示器的显示缩放设置所确定的分辨率。例如，一台 3840x2160 的显示器若显示缩放设为 2.0，则可用分辨率为 1920x1080 个 panel unit。在 Windows 系统上，这相当于 200% 的 Display Scaling 设置。
Opening Size size - - 决定窗口尺寸的确定方式。
  • Automatic from Panel COMP/TOP automatic - 根据所指定 COMP/TOP 的尺寸自动确定大小。
  • Fill Location fill - 填满上方 Justify and Offset To... 参数中指定的位置。
  • Custom custom - 使用下方的 Width 和 Height 参数指定自定义尺寸。
  • Single Display Exclusive exclusive -
Width winw - 当 Opening Size 参数设为 Custom 时窗口的宽度。
Height winh - 当 Opening Size 参数设为 Custom 时窗口的高度。
Update Settings from Window update - 窗口打开后你可以重新定位并调整其大小。点击此按钮会读取窗口当前的设置并应用到上方的参数。
Borders borders - 控制窗口是否包含边框和标题栏。
Include Borders in Size bordersinsize - 为 'On' 时，边框计入窗口尺寸。
Always on Top alwaysontop - 控制窗口是否始终位于其他浮动窗口之上。
Cursor Visible cursorvisible - - 控制鼠标指针位于此窗口上时是否保持可见。
  • Never nocursor - 鼠标指针在该窗口上始终不可见。
  • When Moving cursoronmove - 鼠标指针仅在移动时以及停止移动后的短时间内可见。
  • Always alwaysvisible - 鼠标指针位于窗口上时始终可见。
Constrain Cursor constraincursor - - 控制鼠标指针可操作的区域。
  • Off off - 指针可移动到任意显示器的任意区域。
  • Window window - 指针被限制在此窗口的边界内。
  • Display display - 指针被限制在特定显示器内。
Cursor Display cursordisplay - 当指针被限制在特定显示器时，指定显示器索引。
Allow Viewer Interaction interact - 启用与 Window Operator 参数中指定的操作符的交互。
Allow Minimize allowminimize - 允许窗口在任务栏（macOS 中为程序坞）中最小化。
Window Pixel Format windowpixelformat - - 控制所创建窗口的像素格式。这同时影响位深（8、10、16 位）以及窗口根据内容所使用的色彩空间。此设置仅在存在生效的工作 Color Space 时起作用。
  • SDR 8-Bit fixed sdr8fixed - 内容呈现到窗口时，会从工作 Color Space 转换为 8 位定点 SDR（sRGB）。
  • SDR 10-Bit fixed sdr10fixed - 内容呈现到窗口时，会从工作 Color Space 转换为 10 位定点 SDR（sRGB）。
  • HDR 10-Bit fixed hdr10fixed - 内容呈现到窗口时，会从工作 Color Space 转换为 10 位定点 HDR 色彩空间。随后操作系统会转换该色彩空间，以便根据操作系统/驱动/显示器设置正确显示。使用此模式时应在显示器设置中启用 HDR，以避免窗口打开时闪烁。
  • HDR 16-Bit float hdr16float - 内容呈现到窗口时，会从工作 Color Space 转换为 16 位浮点 HDR 色彩空间。随后操作系统会转换该色彩空间，以便根据操作系统/驱动/显示器设置正确显示。使用此模式时应在显示器设置中启用 HDR，以避免窗口打开时闪烁。注意，尽管交给操作系统的是 16 位浮点内容，但这并不意味着会向显示器发送 16 位数据。它很可能将数据转换为显示器可接受的另一种格式。使用此模式可确保尽可能多地将信息交给操作系统进行最终的色彩空间转换。
V-Sync Mode vsyncmode - - 控制窗口在 V-Sync 方面的更新方式。启用表示与显示器刷新同步更新，可避免撕裂和丢帧。禁用表示可在刷新期间的任意时刻更新，可能导致撕裂或丢帧。在 60Hz 显示器上播放 30fps 文件等情况下应使用 FPS is Half Monitor Rate。这使每次更新正好显示 2 个刷新周期，从而保持运动平滑。
  • Disabled disabled - 关闭垂直同步。
  • Enabled enabled - 开启垂直同步。
  • FPS is Half Monitor Rate halfmonitorrate - 这使你可以在 60Hz 显示器上以 30FPS 运行项目，同时确保每幅图像正好显示 2 个刷新周期。没有此选项时，图像可能显示 1 或 3 个刷新周期，使内容看起来在卡顿。目前此功能在 2022.20000+ 系列版本中不可用，但我们希望在 Vulkan 支持该功能后恢复它。
  • FPS is Half Display Rate halfdisplayrate -
Draw Window drawwindow - 禁用时窗口完全不更新其内容。适用于不做渲染的进程，例如音频或网络进程，或使用 VR 设备时。
Hardware Frame-Lock hwframelock - 在 Window COMP 中使用此功能已弃用。强烈建议改用 Direct Display Out TOPs 实现 Frame-Lock。此功能通过 Nvidia Quadro Sync 同步卡提供多 GPU 帧锁定同步。更多信息请参见 Syncing Multiple Computers 和 Hardware Frame Lock。

参数 - Open/Close 页

Open as Perform Window performance - 在 Perform Mode 中打开此 Window COMP。任何 Window COMP 都可通过 Window Placement Dialog 设为默认 Perform Window（用 F1 快捷键打开）。此按钮可让你在 Perform Mode 中打开此 Window COMP，而无需更改当前选为「默认」Perform Window 的对象。
Open as Separate Window winopen - 将此 Window COMP 作为独立的浮动窗口打开，而不是作为 Perform Window。适用于对话框、弹出窗口或测试等场景，但不应将其用于把最终渲染内容输出到显示设备。此时应改为使用单个大型 Perform Window，而不是多个独立窗口。
Close winclose - 关闭窗口（如果已打开）。
Set as Perform Window setperform - 将 Window Placement 对话框中的 Perform Window 设置永久更改为该窗口。
Window Placement Dialog opendialog - 打开 Window Placement 对话框的快捷方式。
Include in Placement Dialog includedialog - 为 'On' 时，此 Window COMP 会显示在 Window Placement 对话框中。
Prevent Display Sleep blocksleep - 为 'On' 时，无论系统的电源和睡眠设置如何，显示器都不会休眠。
Close on Escape Key closeescape - 为 'On' 时，在此窗口上按 Esc 键会将其关闭。提示：无论此参数开启还是关闭，Shift-Escape 始终会将其关闭。

参数 - Extensions 页

Extensions 参数页设置组件的 Python 扩展。更多信息请参阅 extensions。

Re-Init Extensions reinitextensions - 重新编译所有扩展对象。通常只有在扩展对象被引用且其定义已更改时，扩展对象才会被编译。
Init Extensions On Start initextonstart - 在 TouchDesigner 启动时自动执行 Re-Init
Extension ext - 用于在此组件上创建扩展的信息序列
Object ext0object - 可附加到组件的类实例数量。
Name ext0name - 可选，用于搜索的名称，代替实例类名。
Promote ext0promote - 控制扩展是直接在组件层级可见，还是必须通过 .ext 成员访问。示例：n.Somefunction 与 n.ext.Somefunction

参数 - Common 页

Common 参数页设置组件的 node viewer 和 clone 关系。

Parent Shortcut parentshortcut - 指定一个名称，可在组件内任意位置用作该组件的路径。参见 Parent Shortcut。
Global OP Shortcut opshortcut - 指定一个名称，可在任何位置用作该组件的路径。参见 Global OP Shortcut。
Internal OP iop - 内部操作符的序列标题。
Shortcut iop0shortcut - 指定一个名称，可在组件内任意位置用作下方「Internal OP」的路径。参见 Internal Operators。
OP iop0op - 此组件内 Internal OP 的路径。参见 Internal Operators。
Operator Viewer opviewer - 当上方的 Node View 参数设为 Operator Viewer 时，选择使用哪个操作符的节点查看器。
Enable Cloning enablecloning - 控制该 OP 是否应持续克隆。关闭此项会使此节点停止克隆其「Clone Master」。
Enable Cloning Pulse enablecloningpulse - 立即克隆内容。
Clone Master clone - 用作 Master Clone 的组件路径。
Load on Demand loadondemand - 仅在需要时将组件加载到内存。适用于项目中并非总是使用的组件。
Enable External .tox enableexternaltox - 开启时（默认），.toe 启动时会加载外部 .tox 文件，COMP 的内容将与该外部 .tox 一致。如有需要，可以关闭此项，以避免启动时从引用的外部 .tox 加载（COMP 的内容改为从 .toe 文件加载）。如果你希望某个 COMP 引用外部 .tox，但不总是从它加载，除非你特意按下 Re-Init Network 参数按钮，这会很有用。
Enable External .tox Pulse enableexternaltoxpulse - 此按钮会从外部 .tox 文件重新加载（若存在）。
External .tox Path externaltox - 磁盘上 .tox 文件的路径，该文件会在 .toe 启动时作为组件内容的来源。这让组件可以包含能独立更新的网络。若找不到 .tox 文件，则会加载 .toe 文件保存时的内容。
Reload Custom Parameters reloadcustom - 启用此复选框后，重新加载 .tox 时会重新加载组件 Custom Parameters 的值。这仅影响组件上的顶层参数；组件内节点上的所有参数始终随 .tox 重新加载。
Reload Built-In Parameters reloadbuiltin - 启用此复选框后，重新加载 .tox 时会重新加载组件内置参数的值。这仅影响组件上的顶层参数；组件内节点上的所有参数始终随 .tox 重新加载。
Save Backup of External savebackup - 启用此复选框后，由 External .tox 参数指定的组件的备份副本会保存在 .toe 文件中。若找不到 External .tox，将使用此备份副本。出现这种情况可能是因为 .tox 被重命名、删除，或 .toe 文件在另一台缺少组件媒体的电脑上运行。
Sub-Component to Load subcompname - 从外部 .tox 文件加载时，此选项允许你深入 .tox 取出一个 COMP，并将其作为顶层 COMP，忽略文件中的其他所有内容（该 COMP 的内容除外）。例如，若名为 project1.tox 的 .tox 文件包含 project1/geo1，将 geo1 设为 Sub-Component to Load，就会加载 geo1 来替代当前 COMP。若此参数为空，则按常规使用文件中的顶层 COMP 加载 .tox 文件。
Relative File Path Behavior relpath - - 设置此 COMP 内的子文件路径是相对于 .toe 本身还是 .tox，或从父级继承。
  • Use Parent's Behavior inherit - 从父级继承设置。
  • Relative to Project File (.toe) project - 当指定为相对路径时，该路径将相对于 .toe 文件。
  • Relative to External COMP File (.tox) externaltox - 当指定为相对路径时，该路径将相对于 .tox 文件。未指定外部 COMP 文件，或 Enable External .tox 未开启时，此项没有影响。

  • winh -
  • winopen -

COMP 通用信息通道

  • num_children - 此组件中的子级数量。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
