Points 类

Points 类描述由一个 SOP 拥有的 point objects 集合。

成员

owner → OP (Read Only):

此对象所属的 OP。

方法

没有该操作符专属的方法。

特殊函数

len(Points)→ int:

返回点的总数。

a = len(op('box1').points)

[index]→ td.Point:

按整数索引获取特定的点。

n = op('box1').points[0]

Iterator→ td.Point:

遍历每个点。

for m in op('box1').points:
	# 对 m（一个 Point）做些什么
