从 Arduino 发送数据

首先安装 Arduino 以及任何必要的串口驱动。

这是一个示例文件：Media:Arduino sample.tox

以下简单 sketch 将每秒输出一些值： 

 void setup()
 {
   // 以 9600 bps 打开串口：
   Serial.begin(9600);
 }
 void loop()
 {
   delay(1000);
    
   int  i = 1234;
   Serial.print(i, DEC);
   Serial.print('\n');
  
   float f = 321.7;
   Serial.print(f);
   Serial.print('\n');
 }

要在 TouchDesigner 中接收这些消息，请放置一个 Serial DAT。 默认情况下，所有参数都应与上述 sketch 兼容，你应能看到这两个值每秒到达 DAT。

更具体地说，确保通信参数设置为与 Arduino 相同的波特率。 默认设置为 9600,8,N,2，但如有需要可以提高波特率。 另外，确保 Table Format 设置为 One Row Per Line。

上述 sketch 在每个值之后输出单个换行字符「\n」。遗憾的是，在这种情况下执行 println() 命令不会生效，因为它同时输出回车和换行，而这两者在 Serial In DAT 中 会被解释为空行。

要随时查看实际接收到的字节值，请打开 Received Messages 参数下的 Value Column 参数

在使用 Arduino 通过共享的串口连接上传新 sketch 时，务必在 Serial DAT 中将 Active 参数 off。

上传 sketch 后，将 Active 参数重新 on。

或者，对于二进制通信，sketch 中的 print 语句可以输出单个字节： 

 char a = 123;
 Serial.print(a, BYTE);

在这种情况下，Serial In DAT 的 Table Format 应设置为 One Row Per Byte。

确保在 DAT 中打开「Value Column」以显示它们的数值。

除上述日志外，还可以为每个接收到的条目调用一个 python 脚本。

在 Arduino 上接收数据

最后，要向 Arduino 输出字符，请使用 Serial DAT's 的发送方法。

字节可以通过同一个 Serial DAT 发送。

在 Arduino 上使用命令 Serial.available() 和 Serial.read() 来访问这些字节。

以下链接展示了这些命令在 Arduino Sketch 中的用法：

[4]

接收多字节消息时，要记住数据流没有明确定义的起始或结束字节。 因此一种常见方法是：将所有字节追加到字符缓冲区，直到收到换行符。收到换行符后，即可从字符缓冲区中解析出所需元素。 

 //
 // 解析由三个十进制值加一个回车组成的传入消息
 // 例如  "12 34 56\n"
 // 在 TouchDesigner 中：     op('serial1').send("12 34 56", terminator="\n")
 //
 char buffer[16];   // 预期的最大长度
 int len = 0;
 void setup()
 {
   Serial.begin(9600); 
 }
 void loop()
 {
     if (Serial.available() > 0) 
     {
         int incomingByte = Serial.read();
         buffer[len++] = incomingByte;
         //
         // 检查是否溢出
         //
         if (len >= 16)
         {
             // 溢出，重置
             len = 0;
         }
         //
         // 检查换行（消息结束）
         //
         if (incomingByte == '\n')
         {
             int red, green, blue;
             int n = sscanf(buffer, "%d %d %d", &red, &green, &blue);
             if (n == 3)
             {
                 // 收到有效消息，在此使用这些值..
             }
             else
             {
                  // 解析错误，丢弃
             }
             len = 0; // 重置缓冲区计数器
         }
     }
 }
