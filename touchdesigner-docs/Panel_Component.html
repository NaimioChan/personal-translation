Panel 组件

摘要

Panel 组件是 Components 的子 Family，用于创建自定义的可交互 2D 控制面板和用户界面（也称为 Panels）。它们位于 OP Create 对话框中 Components 的第二列。

示例见 Help > OP Snippets

面板组件包括：

Container COMP - 可容纳任意数量的其他按钮、滑块、字段、容器等

Widget COMP - 一个 Container COMP，具有额外功能以支持 Widgets 库。

Text COMP - 用于输入文本字符串并在面板中渲染文本。

Slider COMP - X、Y 和 XY 方向的简单滑块，输出 1 或 2 个通道

Button COMP - 简单的开关按钮，包括 toggle、momentary 以及一组单选按钮

List COMP - 可让你用 Python 创建和定义列表

OP Viewer COMP - 由任何操作符的查看器创建面板

Parameter COMP - 由任何操作符的参数创建面板

Select COMP - 从其他任意位置选择一个 Panel 组件

Table COMP - 一种简洁且优化的方式，用于创建用户界面控件网格

面板中的面板

在 2D 控制面板中，Panel 组件以两种可能的方式显示在另一个面板（Parenting）内：

  • 把面板放置在另一个 Panel 组件（通常是 Container 组件）内。
  • 通过在同一网络中把节点连接到另一个节点，如 3D Parenting 中那样。
