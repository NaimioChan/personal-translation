预填充

Pre-Filling 是少数 OP 中使用的功能，如 Cache TOP、Cache SOP 和 Texture 3D TOP。它用于一次性填满某个 OP 的全部内容，而该 OP 通常每次计算只填充其中一部分。例如 Cache TOP 通常每帧只缓存 1 张图像。通过预填充，你可以在加载时就缓存它的所有图像。

预填充的做法是以 Frame = 1、Frame = 2 等依次计算节点的输入，直到达到填满该 OP 所需的计算次数。要为每个缓存项生成不同信息，使用表达式 me.time.frame 来驱动你的节点。例如，在 Movie File In TOP 中用 me.time.frame - 1 作为索引（设为 Play Mode: Specify Index），把 Movie File In TOP 中的 N 张图像缓存到 Cache TOP 中。
