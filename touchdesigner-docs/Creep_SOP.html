Creep SOP

摘要

Creep SOP 可以沿 Path Input（input1）几何的表面变形并动画 Source Input（input0）几何。

creepSOP_Class

参数 - 页

Reset reset - 根据下方 Reset Method 参数重置 creep 状态。
Reset Method resetmethod - - 对 Source Input 进行平移、旋转和缩放，以完成下面列出的给定选项。
  • Fill path fillpath - 计算出一组值，把输入几何拉伸或收缩到 Path Input 几何的整个长度和宽度。这些值会填入 SOP 底部的九个变换字段。
  • Keep proportions keepproportions - 与上述类似，但初值经过设置以尽量减少对象几何的变形。

注意

下面三个变换字段设置输入几何沿 Path 的行（U）和列（V）方向的平移。creep 平移为 0.5, -0.5, 1 时，源位于路径中央，距离路径一个单位。 对于缩放，尺寸为 0.2 0.3 的源将占据 Path 上 20% 的列和 30% 的行。

Translate t - - 在 Path Input 表面上平移 Source Input creep 几何。
  • X tx - 沿 Path Input 的 U 参数平移 Source Input
  • Y ty - 沿 Path Input 的 V 参数平移 Source Input
  • Z tz - 沿 Path Input 的 W 参数平移 Source Input（高于/低于 Path 的高度）
Rotate r - - 在 Path Input 表面上旋转 Source Input creep 几何。
  • X rx - 沿 Path Input 的 U 参数旋转 Source Input
  • Y ry - 沿 Path Input 的 V 参数旋转 Source Input
  • Z rz - 沿 Path Input 的 W 参数旋转 Source Input
Scale s - - 在 Path Input 表面上缩放 Source Input creep 几何。
  • X sx -
  • Y sy -
  • Z sz -

Info CHOP 通道

Creep SOP 的附加信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
