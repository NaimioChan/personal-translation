Convert POP

摘要

Convert POP 是一个通用工具，它保留输入的点，但以各种方式把这些点重新连接为图元。这包括与 line strip 之间的相互转换、打开/关闭 line strip、把 quad 转换为 triangle、剥离所有图元，以及从点创建 Point Primitive。

它还可以把 POP “展平”为有序形式：先让所有图元的点互不相同，然后遍历每个图元，按各图元顶点的顺序排列点，从而对所有点重新排序（菜单项 Unique Points and Reorder to Prim/Vertex Order）。点列表中的第一个点是第一个图元的第一个顶点，点列表中的最后一个点是最后一个图元的最后一个顶点。

另请参阅 Primitive POP。

参数 - Convert 页

Convert convert - - 决定要对图元或点执行的转换操作。
  • None none -
  • Keep Points, Delete Primitives deleteprims -
  • Points to Point Primitives topointprims -
  • Line Strips to Lines linestripstolines -
  • Triangle, Quads and Lines to Line Strips tolinestrips -
  • Quads to Triangles quadstotriangles -
  • Close Line Strips closelinestrips -
  • Open Line Strips openlinestrips -
  • Reverse Vertex Order of Each Primitive reversevertorder -
  • Unique and Reorder Points by Prim/Vertex Order uniquereorderpoints -
  • Copy Topology Back to CPU (Slow) cpureadback -

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Info CHOP 通道

Convert POP 的附加信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
