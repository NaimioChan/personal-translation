Torus POP

摘要

Torus POP 创建封闭管状的点行与点列。这些点可以用 Connectivity 菜单以多种图元连接。

圆环与圆环的横截面各有一个半径参数。

Connectivity 菜单让你输出三角形、交错三角形、四边形、线、line strip、点图元，或不输出图元（None，仅点）。

你指定行数和列数。Columns 指围绕圆环的分段，Rows 指围绕横截面圆的分段。

在 Connectivity 菜单中，可以沿 Rows、Columns 或两者合并的方向创建线和 line strip。

圆环围绕某个轴（默认为 Y）对称，但可以用 Rotate 和 Translate 参数对圆环做后旋转和后平移。

Anchor 会把圆环的左、中或右侧对齐到 X=0、Y=0 或 Z=0。

Details 页让你通过指定圆环的一段圆弧（任意起止角度）来制作部分圆环。

End Caps 开关会添加三角形或四边形填充端盖，使圆环成为封闭体，同时仍保留 Dimension，因为没有增删点，只增加了图元。

Dimension：圆环传给其他 POP 时，无法确知指定了多少行和列。但 Torus POP（及其他生成器 POP）会把其 Dimensions 作为元数据输出给所有与它相连的 POP，指明点在点列表中的组织方式。圆环的尺寸为 numCols numRows，可供 _Dim[] 等内置属性或 GLSL 代码使用。

你可以输出点法线或顶点法线（生成 N 属性），也可以输出点纹理坐标或顶点纹理坐标（Tex 属性）。

Torus POP 接受一个输入，使起始管状体的包围盒与输入的包围盒相同。然后开启 Modify Bounds 可以进一步变换圆环。

另请参阅 Tube POP、Sphere POP、Grid POP、Field POP、Point Generator POP、Revolve POP、Dimension

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
