Run 类

Run 类描述一个延迟执行的脚本实例。更多信息请参阅 Run Command Examples。 它们可以从 runs 对象访问。可以使用以下方法执行带延迟的脚本：

DAT.run()
Cell.run()
td.run()

成员

active → bool :

获取或设置此脚本在到达目标帧后是否执行。

group → str :

获取或设置与此脚本关联的组标签。

isCell → bool (Read Only):

当来源是来自 Cell.run() 调用的 cell 时返回 true。

isDAT → bool (Read Only):

当来源是来自 DAT.run() 调用的 DAT 时返回 true。

isString → bool (Read Only):

当来源是来自 td 模块 run() 调用的字符串时返回 true

path → OP (Read Only):

此脚本执行所在的 operator 位置。

remainingFrames → int :

获取或设置执行前剩余的帧数。

remainingMilliseconds → int :

获取或设置执行前剩余的毫秒数。

source → DAT | Cell | str (Read Only):

run 的来源。它可以是 DAT、cell 或字符串。

方法

kill()→ None:

在执行前终止此 run，并将其从位于 td Module 的全局 runs 列表中移除。
