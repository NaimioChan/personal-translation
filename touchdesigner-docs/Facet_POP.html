Facet POP

摘要

Facet POP 执行操作，使点可在多个图元之间共享，或创建新点使点不被共享。

Unique Points 会创建新点，使每个图元的每个顶点都不与其他任何顶点共享点。（例外：按定义，闭合线带上的第一个顶点和最后一个顶点指向同一个点）

Consolidate Points 有可能减少点的数量，它把指定距离容差内的点合并为一个点。之后多个顶点可以引用同一个点，即「共享」一个点。

Cusp Polygon 会检查多边形之间的所有边，若某条边相邻的两个面在指定角度容差内未对齐，就把该边上的点变为独立点。

可以在 Facet POP 之后接一个 Normal POP 来计算点法线或顶点法线，从而让表面呈现分面外观或平滑外观。

参数 - Facet 页

Group group - 如果存在输入组，在此字段中指定组名将使该 POP 仅作用于指定的组。
Operation operation - - 选择要执行的操作。
  • No Operation none -
  • Unique Points unique -
  • Cusp Polygons cusp -
  • Consolidate Points conspoints -
Angle angle - 面之间的夹角阈值，超过该角度时共享边的顶点不再共享点。
Distance dist - 设置合并点时点之间的最大距离。
Max Tries maxtries - 尝试合并点时的最大迭代次数，用于处理目标点已被合并的情况。
Remove Degenerate removedegenerate - 移除相邻顶点引用同一点的图元。
Remove Unused Points removeunusedpoints - 移除未被图元引用的多余点。
Technique technique - - 点合并技术。
  • Brute Force bruteforce -
  • Shared Memory sharedmemory -
  • Spatial Grid spatialgrid -
  • Spatial Grid Per Voxel spatialgridpervoxel -
Voxels Grid Resolution gridres - 定义通过 Spatial Grid Per Voxel 方法合并点时使用的体素网格分辨率。
Specify Bounding Box specifybbox - 启用在使用 spatial grid per voxel 方法合并点时指定边界框。
Bounding Box bbox - 在使用 Spatial Grid 方法合并点并指定边界框时，用作边界框的 SOP。
Compute Point Normals computenormals - 是否在后续操作中计算点法线。
Copy Topology Info Back to CPU cpureadback - 启用后，将 GPU 上保存的点数和拓扑信息复制到 CPU。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Info CHOP 通道

Facet POP 的附加信息可通过 Info CHOP 获取。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
