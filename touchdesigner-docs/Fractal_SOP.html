Fractal SOP

摘要

Fractal SOP 让你把输入几何分割成锯齿状、像山脉一样的分区。它会沿指定的法线向量（Direction 的 xyz 字段）或输入几何的顶点法线，创建看似随机的偏移和细分。这非常适合创建地形和景观。

fractalSOP_Class

参数 - 页

Group group - 如果存在输入组，在此字段中指定组名将使该 SOP 仅作用于指定的组。接受模式匹配，说明见 Pattern Matching。
Divisions divs - 输入几何的细分次数。1 - 3 范围内的值适合起步。更高的值会导致几何过多，应谨慎使用。
Smoothness smooth - 平滑度值缩放偏移量。范围通常在 0 到 1 之间，小数值比大数值产生更大的偏移。Smoothness 和 Scale 效果相似，但有细微差别。Smoothness 在 SOP 的每次迭代中计算。而迭代次数又由 Divisions 数量决定。相比之下，Scale 是对偏移幅度的全局缩放，不考虑偏移产生时所处的阶段。在 Divisions 大于 1 的前提下，使用较低的 smoothness 值（产生较大偏移）配合较小的 scale 值，会比相反做法——高粗糙度值（小偏移）配合较大的 scale 值——得到略显更随机的结果。
Scale scale - 分形细分的全局设置。见上文关于 Smoothness 与 Scale 的讨论。
Seed seed - 用于分形化的随机种子。指定不同的整数值会得到不同的形状。
Fixed Boundary fixed - 启用后，此选项阻止 Fractal 对边缘（边界）施加任何偏移，这样你就可以例如对一个平面做分形化，同时仍能把平面的边缘连接到盒子的侧面。实现方式是先细化所有断点之间的表面，然后再进行分形化。
Use Vertex Normals vtxnms - 不使用下面的 Direction 字段，而是把任意给定点的分形化方向设为输入顶点法线的方向。当使用球体或其他圆润对象作为输入时，这可能更可取，因为偏移会从球体中心发出，而不是都朝同一方向。
Direction dir - 分形化的方向。默认值 0, 0, 1 使分形偏移指向 Z 方向。可被 Use Vertex Normals 覆盖。

Info CHOP 通道

Fractal SOP 的额外信息可以通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
