Sprite SOP

摘要

Sprite SOP 在 XYZ CHOP 参数所引用 CHOP 定义的点位置处创建几何（quad sprites）。

spriteSOP_Class

参数 - 页

XYZ CHOP xyzchop - 需要一个 3 通道的 CHOP 来指定要生成的四边形的 X、Y、Z 位置。每个采样创建 1 个四边形。创建的四边以每个采样定义的点为中心。
Camera camera - 几何将始终朝向此处指定的 Camera COMP。
Width CHOP widthchop - 可以指定一个 1 通道的 CHOP 来设置该采样处四边形的宽度。
Color CHOP colorchop - 可以指定一个 3 通道的 CHOP 来设置该采样处四边形的 R、G、B 颜色值。
Alpha CHOP alphachop - 可以指定一个 1 通道的 CHOP 来设置该采样处四边形的 alpha。
Perspective Width perspectivewidth - 创建的几何宽度。仅当 Use Constant Width 小于 1.0 时此参数才有效。
Use Constant Width constantwidth - 在 Perspective Width 与 Constant Width 之间混合。Use Constant Width = 0 时，宽度只由 Perspective Width 决定；Use Constant Width = 1 时，宽度只由下方的 Constant Width 参数决定。
Constant Width Near constantwidthnear - 位于 Constant Width Falloff Start 处或更近的四边形所用宽度。
Constant Width Far constantwitdhfar - 位于 Constant Width Falloff End 处或更远的四边形所用宽度。
Constant Width Falloff Start falloffstart - 在此位置或更近处，几何使用 Constant Width Near 参数作为宽度。
Constant Width Falloff End falloffend - 在此位置或更远处，几何使用 Constant Width Far 参数作为宽度。

注意：在 Falloff Start 与 Falloff End 之间，宽度按两值之间的半余弦衰减确定。

Info CHOP 通道

Sprite SOP 的额外信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
