CallbacksExt 扩展

Python 回调系统

CallbackExt 扩展为自定义组件提供 Python 回调功能。所有回调都会收到一个参数，其中包含 info dictionary。回调可以定义在 Callback DAT 参数指定的 DAT 中。要将所有回调报告到 textport，请开启 Print Callbacks 开关参数。Callback DAT 和 Print Callbacks 参数通常位于 Callbacks 参数页，但其位置可以自定义。

信息字典总是包含「ownerComp」键。它还会有保存回调名的「callbackName」键。有时会包含描述回调的「about」键，如果期望返回值，则始终应包含此键。通常，回调在其关联的内部方法之后调用，以便覆盖该方法的原有行为。

TouchDesigner 的 Python 回调系统使用 CallbacksExt Extension。

向组件添加 CallbackExt

向组件添加 CallbackExt 的标准做法是使用 palette:callbacksHelper 组件。

方法

DoCallback(callbackName, callbackInfo=None, callbackOrDat=None) → callbackInfo | None

如果存在，则调用 ownerComp.par.Callbackdat 中指定名称的回调，并返回 callbackInfo，回调的返回值放在 callbackInfo['returnValue'] 中。
如果找到用户回调，则返回 callbackInfo，回调的返回值位于 callbackInfo['returnValue'] 中。如果未找到回调，则返回 None。
如果 ownerComp 有一个名为 Printcallbacks 的参数，且该参数为 True，则会把回调调试信息打印到 textport。
DoCallbacks 是你使用 CallbacksExt 实现回调系统时的主要函数。
  • callbackName - 要调用的回调名称
  • callbackInfo - (Optional) 一个将作为唯一参数传给回调的对象。默认是一个带有 ownerComp 和 callbackName 键的字典。该对象可以是任意类型。如果传入的是字典且不含 "ownerComp" 或 "callbackName" 键，这些键会被自动添加。。
  • callbackOrDat - (Optional) 用于接收回调的 DAT 或函数。如果这是 DAT，则从该 DAT 中指定名称的回调调用；如果是函数，则直接调用该函数。如果为 None（默认），则从 ownercomp 的 callbackDAT 参数所设置的 callback DAT 调用回调。

EditCallbackDAT()

在默认编辑器中编辑 Callback DAT

SetAssignedCallback(callbackName, callback, details=None)

注意： 这是专家功能，不供一般使用。
指定回调会把回调系统设置为调用指定的 python 方法，而不是搜索 callback DAT。设置后，调用 DoCallback(callbackName) 时默认会调用该 callback。
  • callbackName - 要调用的回调名称
  • callback - 回调，或 None 表示移除已指定的回调
  • details - Optional 调用回调时通过 infoDict 的 ['details'] 键传入的额外信息。

PassCallbacksTo(passTarget)

注意： 这是专家功能，不供一般使用。
为在 callback DAT 中找不到的回调设置一个目标 DAT 或函数。这样可以设置在 callback DAT 中找不到回调时的备用行为。
  • passTarget - 一个 DAT 或函数

PassOnCallback(info)

注意： 这是专家功能，不供一般使用。
把此回调传给 PassTarget。它意在从回调内部调用，以便有意将其传递下去。使用 PassCallbacksTo 设置 PassTarget。
  • info - 回调的 info 对象
