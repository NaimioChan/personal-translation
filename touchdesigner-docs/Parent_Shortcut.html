父级快捷名

父级快捷方式允许在其任何子级操作符中用 parent.Name 表示法引用任意组件，无论子级位于组件内部多深的位置。

注意：关于项目中其他位置组件的全局快捷方式，请参阅 Global OP Shortcut。

在组件内部使用父级快捷方式的优势是：

  • 你无需知道主组件向上有多少级父级。要到达主组件，不必写 parent(3)，而是写 parent.Name。
  • 这样组件就变得非常便于移植，可以复制/粘贴或移动到任意网络中。

要指定快捷方式，请在组件的 Parent Shortcut 参数中输入名称，例如 Effect。要引用该快捷方式，请使用 parent.Name，其中 Name 是组件快捷方式参数中输入的值，此处为 parent.Effect。
由于 parent.Name 的所有使用都会指向父级快捷方式而不再使用绝对路径，将组件移到另一个网络不会破坏组件中的任何表达式。

注意，默认情况下组件 /project1 的 Parent Shortcut 参数设为 Project。因此在其内部任何位置，parent.Project 都会指向此顶层操作符。

Example: 一个面板位于 /project1/fireEffect。与其使用 parent().par.w 或 parent(2).par.w 等来访问其宽度（取决于表达式所在位置），不如将该面板的 Parent Shortcut 设为 Effect。这样在组件内部任何位置，parent.Effect 都会指向 /project1/fireEffect，而 parent.Effect.par.w 就是该面板的宽度参数。

如果将 fireEffect 组件移到完全不同的位置：/project3/controlpanel/effects/fireEffect，那么任何包含 parent.Effect 的内部表达式都会方便地指向 /project3/controlpanel/effects/fireEffect。

如果主组件的所有 clones 都具有相同的父级快捷方式，在任何克隆中使用该名称都会指向各克隆自身的位置，使克隆中的路径更简单、克隆更便于移植。

（Parent Shortcut 以前称为 Path Variable 或 Internal Shortcut。）

精确用法和细节请参阅 OP Class#Members。
