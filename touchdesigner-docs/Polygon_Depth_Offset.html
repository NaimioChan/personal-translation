多边形深度偏移

Polygon Depth Offset 是处理 Z-Fighting 的一种方式。Polygon Depth Offset 会把多边形的深度值推离摄像机若干个单位。这一过程与摄像机无关，因此比手动平移多边形容易得多（因为某个方向上的平移在某个摄像机视角下有效，换一个视角就无效了）。

偏移的值为 polygonOffsetFactor * deltaZ + minValue * polygonOffsetUnits，其中 deltaZ 是相对于多边形屏幕面积的深度变化量，minValue 是在给定实现下保证能产生可分辨偏移的最小值。本质上，polygonOffsetUnits 是对偏移的常量改变，polygonOffsetFactor 是随表面相对观察者倾斜程度而变的改变。
