SOP 属性

This page applies to attributes of SOPs. 关于 POP 属性，请参阅 Attribute。

Attributes 包含有关实体的信息，例如其颜色、速度、法线等。 属性可以附加到 Points、Vertex (Vertices)、Primitives 或整个几何上。

点和顶点属性会跨图元插值，因此比图元属性提供更高的局部灵活性（例如 Color）。顶点属性用于处理以下情况：共享的点在图元边界处需要不同的属性值，例如极坐标纹理贴图的接缝。图元颜色通常比点颜色占用更少内存，点颜色又比顶点颜色占用更少。

常用属性

法线

请参阅 Normals。法线是与特定几何实体相关联的方向向量，通常与该实体垂直。曲面上某一点处的法线是与该点处曲面垂直的向量，由该点处的切向量叉积计算得出。

颜色

由 RGBA 指定的表面颜色与 alpha。取值范围为 0 到 1。alpha 分量 Cd(3) 控制给定元素的透明度，其中 1 为完全不透明，0 为完全透明。

纹理坐标（Tex）

项目通过 XYZ 值在空间中定位。为了区分纹理坐标空间与 XYZ 空间，会用 U 和 V（有时还有 W）来替代 X、Y 和 Z。 ​ 要把纹理贴图（图像）放到几何上，必须为几何指定纹理坐标。纹理贴图位于它自己的 (U, V) 纹理坐标空间中。指派给几何后，(U, V) 坐标决定图像如何映射到几何上：U,V 为 0,0 时使用纹理图像的左下角，1,1 时使用右上角。纹理空间不应与样条的参数空间混淆。 ​ Sphere SOP 和 Grid SOP 这类生成器 SOP 已经为每个点指派了 UV。可使用 Texture SOP、Point SOP，或用 SOP to DAT 搭配 DAT to SOP 来添加或修改这些属性。 ​ 可以用下面的方式来理解纹理坐标：纹理贴图有它自己的坐标空间。如果纹理是一块带网格图案的桌布，那么桌布上 3, 4 位置的颜色，即使桌布被包裹在不规则形状的物体上，仍然位于 3, 4 位置。可以说 3, 4 位置的颜色处于桌布的坐标空间中。 ​ TIP：使用 Point SOP，可以交换位置与纹理坐标。 这样就能对「纹理空间」进行建模。再用一个 Point SOP 即可把位置与纹理交换回原来的位置。

属性优先级顺序

属性的优先级顺序从高到低为：

  1. 顶点属性
  2. 点属性
  3. 图元属性
  4. 细节属性

优先级更高的属性会覆盖优先级更低的同名属性。（只有 Bone Group SOP 拥有来自外部导入骨架的细节属性。）

属性的数据类型

共有三种不同的属性数据类型。它们在内部的处理方式略有不同。

Vector Data This data type represents a 3D vector in space. When any transforms occur on the detail, this attribute will also be transformed. Examples of a vector attribute are normals (N) or velocity (v).
Floating Point Data This data type represents an array of floating point values. The values are not transformed when the geometry gets transformed. Some examples of this type of attribute are diffuse colors (Cd), and texture co-ordinates (uv).
Indexed String Data This attribute consists of an ordered list of character strings. The attribute stored with the element is an integer representing the offset into the array of strings. A value outside the bounds of the array is considered to be "not assigned". An example of this is the material attribute.
