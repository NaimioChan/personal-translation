Neighbor POP

摘要

Neighbor POP 使用 P 属性，为输入的每个点查找离它最近的点。它把最近点的索引放入数组属性 Nebr。你需要指定邻居的最大数量，并选择 Max Neighbors Distance 来确定查找邻居的距离范围。

属性 Nebr 的大小等于 Max Neighbors 参数。如果找到的数量少于该值，它会用特殊数值 4294967295 作为邻居索引的值。属性 NumNebrs 保存每个点找到的邻居数量。

你可以输出到所找到邻居的平均距离，并可选地包含该点的位置。也可以输出反距离加权平均值，此时最近的点对平均值的影响最大。

除了输出邻居的索引，你还可以输出邻居的任意属性集合（注意，这可能产生大量数据）。

Neighbor POP 的另一种形式接收第二个输入，将第一个输入的每个点与第二个输入的点进行比较。

邻居由点之间的距离确定，但通过 Neighbors Type 菜单，也可以由沿连接相邻点的图元边的连通性来确定（目前仅一步）。例如，在一条线带或四边形中彼此相邻的两个点互为邻居。

（ Distribution - Default, Unique, Closest, Random ）

内部使用无界空间哈希算法，并将点放入 Num Hash Buckets 中的某一个。

参数 - Neighbor 页

Neighbors Type nebrtype - - 检查邻居时，选择使用边连通性，还是仅使用到邻居点的距离。
  • By Distance distance -
  • Connected connected -
Max Neighbors Distance maxdistance - 指定一个距离，低于该距离的点被视为当前点的邻居。
Distribution distribution - - 确定返回哪种邻居集合。（'Default' 和 'Unique' 按顺序遍历相邻单元直到达到最大邻居数，'Unique' 保证不重复，'Closest' 按距离排序返回最近的邻居，'Random' 返回所有邻居中更均匀的随机采样）
  • Default default - 最快的模式。按顺序遍历相邻单元，从后到前、从下到上、从左到右，达到最大邻居数时停止。在少数情况下，当源点的相邻单元具有相同哈希时，可能产生重复。
  • Unique unique - 与 Default 模式类似，但会检查重复，并生成唯一的邻居列表。
  • Closest closest - 最慢的模式。检查所有邻居并按距离排序，返回最近的至多最大数量的邻居。
  • Random random - 无偏的邻居列表：检查所有邻居，并随机选取以达到最大数量。
Num Hash Buckets numhashbuckets - 根据点的位置将其分入的桶数量。一个不错的经验法则是取接近点数量的值。
Output Hash Attrib outputhash - 是否输出包含 Spatial Hash 值的属性，这对调试和优化性能很有用。
Output nebroutput - - 是在数组属性中输出各个邻居及其属性，还是输出它们的平均值或距离加权平均值。
  • Neighbors nebr -
  • Average avg -
  • Inverse Distance Weighted Average weightedavg -
Max Neighbors maxneighbors - 指定最大邻居数。这决定了所有存储邻居信息的属性的数组大小。
Neighbors nebrs - - 启用邻居属性的添加。
  • Neighbors nebrs -
  • Neighbor Attr Name nebrattrname - 包含邻居点索引的属性的名称。
Num Neighbors numnebrs - - 启用邻居数量属性的添加。
  • Num Neighbors numnebrs -
  • Num Neighbors Attr Name numnbrsattrname - 邻居数量对应的属性名称。
Add Distance Attribute dodist - - 是否输出包含到查询点距离的属性。
  • Add Distance Attribute dodist -
  • Distance Attribute Name distattrname - 指定存储距离值的属性的范围。
Max Neighbors for Average maxnebrsavg - 指定对邻居属性求平均时考虑的最大邻居数。
Include Query Point incquerypt - 开启后，当输出为平均值时，计算平均值会包含查询点本身。
Add Prefix addprefix - 输出邻居属性时是否添加 Nebr 前缀。
Cast Integers to Floats castintstofloats - 对邻居属性值求平均时，是否将整数属性转换为浮点数。
Neighbor Point Attributes nebrptattrs - - 为第一个输入中的每个点创建大小为最大邻居数的数组属性，其中存放其邻居属性。
