Retina 与高 DPI 分辨率

概述

现在所有新款 Mac 机型都配备 Retina 显示屏。这种高 dpi 显示屏也开始流行于 Razor、Dell、Lenovo、MSI 等厂商的高端 Windows 笔记本电脑。从 2022.20000 系列版本开始，TouchDesigner 完全支持高 DPI 显示屏。UI 会遵循操作系统中的「scaling」设置，但会使用全部像素来渲染 UI，以获得清晰的观看体验。如果 TouchDesigner 的 UI 不符合你的需求，可以按以下说明调整 UI 缩放：

在 Windows 中调整 UI 缩放

TouchDesigner 界面的字体大小可以通过 Windows 显示设置调整。

1) 在桌面的空白处右键单击并选择 Display Settings，打开 Display Settings。也可以从 Windows 控制面板中打开 Display Settings。

2) 在此对话框中，注意「Change the size of text, apps, and other items:」这一设置。

3) 增大此设置会增大字体大小。例如，可以试试 150% 或 200%。

4) Windows 会要求你注销并重新登录，设置才能完全生效。
