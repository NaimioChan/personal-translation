Clip DAT

摘要

注意

License: 仅在 TouchDesigner Pro 中可用。

Clip DAT 包含由 Clip CHOP 和 Clip Blender CHOP 操纵的运动片段的信息。 Clip DAT 可保存任意命令或脚本文本，并可根据 Execute 参数页上的设置触发（这正是 Clip DAT 与 Text DAT 的不同之处）。Clip DAT 的脚本会在指定片段通过 Clip Blender CHOP 播放时触发。

clipDAT_Class

参数 - Text 页

Edit.. edit - 单击此按钮会打开文本编辑器，用于添加/编辑/删除 DAT 中的文本。
File file - 要加载的文件路径和名称。接受 .txt 和 .dat 文件。文件可从磁盘或网络读取。指定 URL 时使用 http://。
Reload File reload - 设为 1 时，把文件重新加载到 DAT 中。

参数 - Execute 页

Execute from executeloc - 决定脚本的运行位置。
  • Current Node current - 脚本从当前节点位置执行。
  • This Node here - 脚本从 Text DAT 自身执行。
  • Specified Component comp - 脚本从下面 Component 参数指定的组件执行。
Clip clip - 指向一个 Clip CHOP，在 Clip Blender CHOP 中运行时它会触发该脚本。
Component component - 当 Execute From 参数设为 Specified Component 时，脚本执行所用的路径。
Execute on Frame (First) framefirst - 当该片段的指定索引在 clipblender 中第一次被播放时，执行一次脚本。即使该片段在 clipblender 中循环，脚本也只执行一次。
Execute on Frame (Loop) frameloop - 每当该片段的指定索引在 clipblender 中被播放时执行脚本。当片段循环时，每次循环都会运行脚本。
Execute on Exit exit - 当 clipblender 退出指定片段时执行脚本。
Print State printstate - 把调试信息打印到 textport。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

Clip DAT 的额外信息可通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
