时间切片

Time Slicing 是 TouchDesigner 的一项功能，即使整体帧率下降、时间轴跳帧，也能保持 CHOP 通道平滑。Time Slicing 让整体动画更平滑、更准确，并在帧率下降时帮助避免音频爆音。

一个 Time Slice 是从上次计算帧到当前计算帧的时间。（参见 Absolute Time。）在 CHOPs 中，它是包含 CHOP 通道在上次计算帧和当前计算帧之间采样的那组短通道。

如果全局帧率为每秒 60 帧，时间切片就是 1/60 秒的倍数。例如，如果 TouchDesigner 跳过了一帧，时间切片就是 2 个采样，即 2/60 秒。

你可以通过创建一个 Perform CHOP 并把它送到 Trail CHOP，把 Perform 设为 Cook 和 Time Slice Step 通道，即 cook 和 timeslice_step，来查看时间切片的大小。

参见 OP Snippets 中的 Time Slice CHOP。

许多 CHOP，例如 Filter CHOP，会计算一个采样的时间切片，以确保即使 TouchDesigner 进程跳帧，曲线也平滑、脉冲也准确。相反，Constant CHOP 不是时间切片的——它始终只有一个采样长。

Time Slice 是每个 CHOP 上的 Common 页参数，在大多数 CHOP 上会自动设置/取消设置。

Example：如果当前帧是 77，而先前显示的帧是 73，那么时间切片长 4 帧（第 74 到 77 帧）。这意味着 TouchDesigner 向前跳了 4 帧以跟上实时时钟。假设时间轴帧率为每秒 60 帧，如果该 CHOP 包含默认每秒 44100 采样的音频，则包含音频的 CHOP 中会有 44100*4/60 = 2940 个采样。

可以通过任何 CHOP 节点上的 MMB 信息弹窗检查该 CHOP 是否为时间切片。

注意：时间切片的最大长度通过 Edit → Preferences → CHOPs 中的首选项设置。目前为 200 毫秒。参见 Audio Device Out CHOP 中的音频提示。

这些短通道的计算速度远快于完整的动画范围通道，并且占用更少内存。这种速度和内存效率的提升对交互式 3D、木偶操控和音频处理极为重要。

Time Slicing Tutorial

CHOP 通常会在较长的起始-结束帧范围上计算通道。这对不需要每帧重新生成或重新计算的预动画通道和关键帧通道是很好的方法。

但是，如果由于用户输入（例如使用 Mouse、Keyboard 或 MIDI CHOP）或其他实时数据输入而确实需要每帧求值通道，且我们只关心最近几帧的值，那么计算整个范围的通道就是多余的。只计算所需的那部分通道更高效。这部分称为「时间切片」（Time Slice）。

查看 CHOP 的信息时，会报告它的帧范围以及是否为时间切片。

另请参阅 Absolute Time、Time Slice CHOP 的 OP Snippets、Timeline、Hog CHOP 以及 Tscript:timeslice 命令。

要对 CHOP 进行时间切片，请在 Common 页上设置它的标记。试试 Noise CHOP，观察 Time Slice 打开和关闭时的效果。

把一个 Constant CHOP 送到 Filter CHOP，向前播放并调整 Constant CHOP 滑块，观察时间切片 CHOP 的结果。

使用 Time Slicing 时，即使 TouchDesigner 跟不上 timeline 的采样率（默认为每秒 60 帧），采样也不会丢失或未被处理。所有帧都会被处理，只是每次以 1、2 或更多帧为一批。这能让 TouchDesigner 得到更准确的曲线和时序。

Time Slicing 尤其能降低高采样率 CHOP（例如音频网络中的那些）的内存需求，并且让你在网络中调整音频参数时几乎立即看到结果。由于即使一小段音频剪辑也可能占用超过 1MB 存储，只存储和处理其中所需的那部分能显著降低内存需求，尤其是在大型 CHOP 网络中。

时间切片的 CHOP 不会保留超出所需的通道历史，并且每帧都会重新计算。这使它们非常适合实时应用。即便如此，它们也可以用来「表演」并录制一段动画，而不是用关键帧制作。

Time Slicing 的工作方式

每当 Timeline 向前移动时，时间切片的 CHOP 就会计算。时间轴向前跳跃的时长就是当前时间切片的大小。时间切片与时间轴同步，使其第一个采样紧接在上一个时间切片的最后一个采样之后，最后一个采样位于当前帧。如果时间轴正在向前播放，生成的时间切片永远不会重叠，也不会有间隙。在一次计算中，所有时间切片的 CHOP 都会有相同的时间切片区间。

当 CHOP 网络需要计算时，会计算时间切片区间，并把单个时间切片传过网络。由于当前帧始终包含在该切片内，切片可以很容易地导出到任何参数。

界面

CHOP Parameter Dialog - Time Slice 开关位于所有 CHOP 参数对话框的 Common 页中。对于不支持时间切片的 CHOP，以及某些始终以时间切片模式运行的 CHOP，此开关会变灰。

Edit -> Preferences -> CHOPs Dialog - 可以使用此对话框更改 Time Slice 首选项。也可以从 Textport 使用 timeslice 命令更改。

始终进行时间切片的 CHOP

大多数 CHOP 不需要时间切片能力；它们处理时间切片输入的方式与处理普通通道数据相同。时间切片 CHOP 和非时间切片 CHOP 可以在同一个 CHOP 网络中混用。Time Slice 选项是为那些会读取或修改通道中当前采样之外其他采样的操作、或维护内部状态的操作的 CHOP 提供的。

一般来说，如果要创建时间切片的 CHOP 网络，所有支持时间切片能力的 CHOP 都应打开其 Time Slice 标记（位于 Common 页）。

偶尔进行时间切片的 CHOP

以下 CHOP 在特定条件下会输出时间切片，但不被视为时间切片 CHOP。这些 CHOP 的 Common 页中的 Time Slice 按钮会变灰。

Trim CHOP - Trim CHOP 可以从任何输入 CHOP 中裁出当前时间切片。把 Unit Values 菜单改为 Current Time Slice 即可选择此功能。

Record CHOP - 此 CHOP 可用于在动画范围上录制时间切片 CHOP 的输出。它也可以从只输出单帧的 CHOP（例如 Mouse 或 Keyboard CHOP）中插值出时间切片。使用 Record Input 参数可以在整个时间切片上采样输入，或只在当前帧采样。使用 Record Output 参数可以选择输出范围。

Null CHOP 可以停止过度计算

参见 Null CHOP Cook Type → Selective 选项。

Time Slice 选项

可以使用 Edit -> Preferences -> CHOPs 对话框更改 Time Slice 首选项。

Maximum Time Slice Size (ms) - 此选项让你以毫秒为单位限制时间切片的最大长度。默认最大值为 200ms。如果你只需要几帧历史、而时间轴正以较大间隔跳跃，这会很有用。如果时间切片大于此最大长度，它会从当前帧向后裁剪（导致此切片与上一个切片之间出现间隙）。切片始终结束于当前帧。

Time Slicing 的用途

实时木偶操控与控制

Time Slicing 加快动画对用户输入的响应。它为你提供多种可叠加到输入上的效果，例如滞后、弹簧和过滤。否则在实时输入上很难实现这些效果。

动画表演

有时用输入设备「表演」动画比用关键帧或 CHOP 制作要容易得多。可以用 Record CHOP 录下输入并锁定。之后可以用 CHOP 处理这些数据，或在需要时再次表演。

实时音频处理

时间切片音频处理相比普通音频处理的性能提升相当显著。使用 Time Slicing，可以处理实时音频输入并用数据控制动画。也可以反过来——用动画的功能控制音频输出。没有 Time Slicing，很难搭建网络实时完成这些操作。

普通音频处理

Time Slicing 让你能更高效地清理音频文件或为其添加效果。你可以打开所有支持时间切片的 CHOP，在播放音频的同时操作它，获得实时结果。当你对新的音频满意后，关闭时间切片的 CHOP，并为整个范围生成最终音频剪辑。这样可以更快地反复调整参数以达到期望效果。
