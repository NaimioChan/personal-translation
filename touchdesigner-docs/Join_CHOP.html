Join CHOP

摘要

Join CHOP 接收其所有输入，把一个 CHOP 接在另一个之后。它假定它们都有相同的通道。

第一个 CHOP 的结尾段与第二个 CHOP 的开头段重叠，其余输入 CHOP 依此类推。第二个输入会被平移，以与第一个的结尾对齐。

混合让你能把通道拼接在一起：一边逐渐淡出一个 CHOP，一边淡入下一个 CHOP，或者在相邻 CHOP 的通道之间插入插值曲线。

Quaternion Blend 使用最短旋转弧把旋转三元组（rx ry rz）混合在一起。旋转三元组由「quaternion」属性识别，这些属性在 Attribute CHOP 中设置。

Translation Blending 通过从上一通道的最终速度缓慢过渡到下一通道的初始速度，把平移通道混合在一起。下一通道可能会被上下平移。如果不希望这样，请改用 cubic 混合（在 Shape 菜单中）。Translation Blending 作用于表示平移或位置的通道三元组（*tx *ty *tz）。

参数 - Blend 页

Method blendmethod - - 用于生成无缝序列的混合方法：
  • Preserve Length pre - 各 CHOP 的总长度保持不变。
  • Overlap Sequences ovl - 让当前 CHOP 与之前的 CHOP 重叠。更适合音频。
  • Insert Blend Region ins - 在各 CHOP 之间插入一个区域进行混合。
Shape blendfunc - - 要使用的混合插值形状。参见 Cycle CHOP 中的 Shape。
  • Linear lin -
  • Ease in ei -
  • Ease out eo -
  • Ease in Ease out cos -
  • Cubic cub -
  • Add add -
  • Hold Previous holdprev -
First Input Specifies Blend Regions blendbyinput - 勾选后，第一个输入可以是多通道输入，为 Join CHOP 的其余输入指定混合区域。input0 的通道 1 用于在 input1 与 input2 之间混合，通道 2 在 input2 与 input3 之间，依此类推。如果指定的通道不够，最后一个通道会被重复使用。
Region blendregion - 混合区域的大小。
Blend Region Unit blendregionunit -
Bias blendbias - 混合时偏向哪一段：前一段（-1）、后一段（+1）或都不偏（0）。
Match by match - - 按索引或按名称匹配各输入之间的通道。
  • Channel Number index -
  • Channel Name name -

参数 - Scope 页

Step step - 设为 1 时，下一段会被上下平移，使其从上一段结束的位置开始。
Step Scope stepscope - 使用 Step 的通道名称。
Blend Scope blendscope - 应当混合的通道名称。其他通道不会被混合。
Translate X Blend transscopex - 将进行 translation 混合的通道名称。每个字符串字段包含其组成通道的列表，例如 *tx、*ty 和 *tz。
Translate Y Blend transscopey - 将进行 translation 混合的通道名称。每个字符串字段包含其组成通道的列表，例如 *tx、*ty 和 *tz。
Translate Z Blend transscopez - 将进行 translation 混合的通道名称。每个字符串字段包含其组成通道的列表，例如 *tx、*ty 和 *tz。

参数 - Rotate 页

Quaternion Blend quatrot - 对旋转通道使用四元数混合。
Shortest Path Rotation Blending shortrot - 启用时进行补偿。
Rotation Scope rotscope - 在 Shortest Path Rotation Blending 开启时可用。
Cycle Length cyclelen - 在 Shortest Path Rotation Blending 开启时可用。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Join CHOP 的附加信息可以通过 Info CHOP 获取。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
