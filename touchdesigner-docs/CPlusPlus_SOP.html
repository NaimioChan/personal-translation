CPlusPlus SOP

摘要

CPlusPlus SOP 让你可以用 C++ 编写自己的插件，从而制作自定义 SOP 操作符。

有关如何制作与此 SOP 配合使用的 .dll 的详细信息，请参阅 Write a CPlusPlus Plugin 和 C++ category 中的其他文章。

C++ 代码可以按 GPU 或 CPU 加载来编写。为这两种选项开发 C++ 代码的难易程度相当接近。不过，在 C++ 代码中设置「directToGPU」标记后，只有其中一种模式会被识别为有效模式。这两种模式各有专用类，因此要注意，将「directToGPU」标记设为「true」或「false」需要在 execute() 或 executeVBO() 中调用不同的类和函数。

在 CPU 模式下，几何数据可以逐个添加，也可以一次性添加。此外，在 CPU 模式下，CPlusPlus SOP 还可以使用已连线的 SOP 输入，以及 SOP to DAT、SOP to CHOP 或 SOP 输出 OP。另外，DAT、CHOP 和 TOP 的「非连线」输入操作符可以作为自定义参数使用。此时必须先在 C++ 代码中处理这些自定义参数，才能接受来自其他操作符的输入。

GPU direct 模式与 CPU 模式类似，但不能使用任何下游的输出 SOP，也不能被 SOP to DAT 或 SOP to CHOP 操作符访问。在 GPU direct 模式下，数据会立即加入 VBO 缓冲区，通过更快的更新提升性能，但顶点数量和面数组索引必须在填充缓冲区之前确定。

Windows 下作为 Visual Studio 项目的 CPlusPlus SOP 示例可在 C:/Program Files/Derivative/TouchDesigner/Samples/CPlusPlus/SimpleShapesSOP 或你的自定义 TouchDesigner 安装文件夹中找到。（注意：在 macOS 上位于此处：TouchDesigner.app/Contents/Resources/tfs/Samples/CPlusPlus/SimpleShapesSOP）

Custom Parameters - 自定义参数可由 C++ SOP 的 .dll 自动创建。可以在 SimpleShapes.cpp 的 setupParameters() 函数中删除、编辑或追加此自定义参数页。已定义的自定义参数可根据其是否适用于特定任务来启用或禁用。

Geometry Data - C++ SOP 代码中的几何可以由任意算法定义，甚至可以从外部文件导入。可用的几何是三角网格和粒子系统。注意，如果原始几何中有超过 3 个顶点的多边形，必须在加入三角形列表之前将其转换为具有已知且有效顶点索引的三角形。

要导出到 TouchDesigner 的几何数据可以包含点坐标、法线和纹理坐标、RGBA 颜色、网格和/或粒子系统的三角形信息，以及具有任意名称、float 或 integer 类型、最多 4 个分量的自定义属性（即 Cd0、Cd1、Cd2、Cd3）。

cplusplusSOP_Class

参数 - Load 页

Plugin Path plugin - 要加载的插件的路径。
Re-Init Class reinit - 此参数开启时，会删除插件创建的类实例，并创建一个新实例。
Re-Init Class reinitpulse - 立即重新初始化该类。
Unload Plugin unloadplugin - 此参数大于 1 时，会删除插件创建的类实例并卸载插件。如果多个 SOP 加载了同一插件，它们都需要卸载才能释放该文件。

操作符输入

  • Input 0: -

Info CHOP 通道

CPlusPlus SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
