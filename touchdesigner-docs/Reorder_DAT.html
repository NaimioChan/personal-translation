Reorder DAT

摘要

Reorder DAT 允许你重新排列输入表格的行和列。你还可以使用 In Specified Order 选项来获得行和列的重复副本。

reorderDAT_Class

参数 - Reorder 页

Reorder reorder - - 此参数允许你重排行或列。
  • Rows row -
  • Columns col -
Method method - - 指定如何重排表格。
  • Reverse reverse - 反转行或列的顺序。
  • Replace by Names replacenames - 将输入表格中 From 指定的行或列复制到 To 指定的行或列。行或列以名称指定。
  • Replace by Indices replaceindices - 将输入表格中 From 指定的行或列复制到 To 指定的行或列。行或列以编号指定。
  • Swap by Names swapnames - 将 From 指定的行或列与 To 指定的行或列交换。行或列以名称指定。交换是累积的。
  • Swap by Indices swapindices - 将 From 指定的行或列与 To 指定的行或列交换。行或列以编号指定。交换是累积的。
  • In Specified Order by Name specifyname - 按名称以指定顺序复制行或列。未列出的任何行或列将按输入顺序追加。你可以多次指定同一行或列，以获得它的多个副本。
  • In Specified Order by Index specifyindex - 按索引以指定顺序复制行或列。未列出的任何行或列将按输入顺序追加。你可以多次指定同一行或列，以获得它的多个副本。
Before before - 要从中复制或交换的行或列。
After after - 要复制或交换到的行或列。
Order order - 要复制的输入行和列的顺序。
Delete Unspecified delete - 仅在 Method 为「In Specified Order by Name」或「In Specified Order by Index」时可用。它会删除未在 Order 参数中列出的任何行/列。

  • Node node - DAT 使用它自己的脚本语言。

Custom Extension customext - 指定自定义扩展名。

  • Input 0: -

Info CHOP 通道

可通过 Info CHOP 访问 Reorder DAT 的额外信息。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
