XML DAT

摘要

XML DAT 可用于解析任意 XML 以及 SGML/HTML 格式的数据。格式化后，可以输出文本中选定的部分以供进一步处理。

使用 XML DAT 解析的一种方法是：用 Text DAT 或 Web DAT 读取 XML，再传给默认的 XML DAT。然后开始细化选择，把匹配全部的模式（即「*」）改为能减少输出元素的字符串。

XML 与 HTML 背景

XML 和 HTML 数据由元素构成树状结构。每个元素可以是带标签的，也可以包含任意文本。元素可以嵌套。带标签的元素以开始部分开头，通常以结束部分终止。

示例： 

 <greeting a="1" b="2" c="3"> Hello there. </greeting>

上例中有两个元素。第一个是名为 greeting 的 tag 元素，带有属性 a, b 和 c。第二个元素是 text 元素，内容为「Hello there.」

XML DAT 的工作方式

XML DAT 首先解析其输入，创建一个内部的元素树。

然后用 Element Scope 参数过滤掉不需要的元素。剩下的元素用于生成输出。输出的格式由 Format 参数决定。随后可以用 Output 参数进一步限制每个选定作用域元素所显示的信息。

每个解析出的元素包含若干详细信息：

Label - 每个元素会被赋予一个任意标签，如 n0、n1、n2 等。所有元素都是保留元素「root」的子级。

Type - 元素主要分为「tag」或「text」类型，tag 类型还可细分为「doctype」、「declaration」、「comment」或「entity」。

Text - 元素的文本指元素的标签属性，或任意文本内容。在上例中，第一个元素类型为「tag」，文本为「greeting」。第二个元素类型为「text」，文本为「Hello there.」。

Level - 描述元素的嵌套深度。例如唯一的根元素层级始终为 0。

Parent - 每个元素有一个父级。根元素没有父级。

Children - 每个元素可以有任意数量的子级元素。

Attributes - 每个带标签的元素可以有任意数量的属性。每个属性由名称和值组成。在上例中，greeting 标签包含 3 个属性（名称分别为 a、b 和 c，值分别为 1、2 和 3）。

参数 - Format 页

Parse SGML/HTML sgml - 启用后，输入应为 SGML/HTML 格式，包括表单数据。禁用时，则假定为 XML 格式。
Merge merge - - Merge 和 label 可用于合并两个数据输入。第二个输入必须是 XML 格式，而不能是 SGML/HTML。这两个参数控制第二个输入合并的位置和方式。
  • Before Element before - 第二个输入合并到指定元素标签之前。
  • After Element after - 第二个输入合并到指定元素标签之后。
  • Inside Element inside - 第二个输入作为指定元素标签的子级合并。
  • Replace Element replace - 第二个输入替换指定元素标签。
Label mlabel - 指定进行合并的元素。

参数 - Element Scope 页

这部分参数控制选择哪些元素作为输出。默认选择所有元素。

Label label - 元素标签必须匹配此参数。
Type type - 元素类型必须匹配此参数。
Text text - 元素文本必须匹配此参数。
Name name - 如果元素包含属性，则至少有一个属性的名称必须匹配此参数。
Value value - 如果元素包含属性，则至少有一个属性的值必须匹配此参数。
Parent Label plabel - 元素的父级标签必须匹配此参数。
Parent Type ptype - 元素的父级类型必须匹配此参数。
Parent Text ptext - 元素的父级文本必须匹配此参数。
Parent Name pname - 元素的父级必须有一个属性，其名称匹配此参数。
Parent Value pvalue - 元素的父级必须有一个属性，其值匹配此参数。

参数 - Output 页

选定要输出的元素后，还可以进一步细化其输出。

Name Attributes oaname - 只输出名称匹配此参数的属性。
Value Attributes oavalue - 只输出值匹配此参数的属性。
Children Labels oclabel - 只输出标签匹配此参数的子级。
Show show - - 控制所选元素的呈现方式。
  • Summary Table sumtable -
  • Summary Tree sumtree - 此输出选择与摘要表类似，但它输出的是树状结构的缩进 ascii 表示。在挑选合适的参数时，可用它快速定位感兴趣的区域。
  • XML xml - 输出所选元素的符合 XML 规范的树结构，随后可以再送入另一个 XML DAT 进行进一步处理。
  • Attributes per Row attribs - 输出所选元素所有属性的表格。每个元素的属性各占一行。
  • Attributes per Column attribscol - 输出所选元素所有属性的表格。每个元素输出为一行，每列表示一个属性。
  • Children children - 输出所选元素所有子级的表格。
  • Text text - 输出所有「text」类型元素的全部文本内容。
Label Prefix lprefix - 决定在输出表格、属性或子级时是否给元素标签加前缀。

Info CHOP 通道

XML DAT 的额外信息可通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
