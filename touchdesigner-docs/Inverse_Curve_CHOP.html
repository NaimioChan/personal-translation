Inverse Curve CHOP

摘要

Inverse Curve CHOP 使用曲线对象为 bone objects 计算反向运动学模拟。

Inverse Curve CHOP 会拉伸并摆放一组骨骼，使其跟随由另一组 objects（guide）定义的曲线。

用 Bone Start / Bone End 指定链中的第一根和最后一根骨骼。

在 Guide Components 字段中按顺序、以空格分隔列出 Guide 来指定它们。此参数也接受模式和通配符。示例：null[1-5] null17 null4。你也可以把该组中的骨骼一并指定。

该 CHOP 随后会为每根骨骼生成一组 rotate 和骨骼长度通道。此外，该 CHOP 还会为链中的第一根骨骼输出 3 个 translate 通道。它也会自动建立导出链接，所以你只需为该 CHOP 打开 export 标记。

该 CHOP 求解这个系统的方式，是在所提供的 Guide 对象之间创建一条 guide 曲线。用 Interpolation 和 Order 参数定义它使用哪种曲线。默认情况下，曲线的控制顶点是对象的质心。曲线还会通过采用每个 guide 对象的方向而获得朝向。骨骼的 X 轴与该朝向对齐。

你可以用 Inverse Curve SOP 查看这条曲线。只需给它 Inverse Curve CHOP 的名字，它就会提取几何用于查看 / 调试。它实际上会包含 3 条曲线（原始 guide，以及在 +X 和 +Y 方向位移的 guide）。这些曲线可以用 Skin SOP 蒙皮以获得更好的反馈，等等。

如有需要，可以用 span 参数裁掉 guide 曲线的开头和结尾。例如 Span 0.3 0.7 会把骨骼铺在曲线中间 40% 的部分。

在极少数情况下，用户设置的曲线所有 X 轴（扭转）都指向曲线的同一方向，这时会用 Up Vector 参数来打破这种平局（可以这么说）。不过，这种曲线设置在开始时很可能就是退化的，应当通过把所有对象扭转 90 度来避免。

参数 - Inverse Curve 页

Guide Components guide - 描述该曲线的一组对象。
Bone Start bonestart - 要放置的链中第一根骨骼。
Bone End boneend - 要放置的链中最后一根骨骼。
Span span - -
  • span1 - 要对齐的 guide 曲线起始比例。
  • span2 - 要对齐的 guide 曲线结束比例。
Interpolation interpolation - - 用 guide 组件创建的 guide 曲线类型。
  • Polygonal Curve polygon - 创建一个多边形，每个 guide 组件处有一个顶点。
  • Bezier Curve bezier - 创建一条 Bezier 曲线，每个 guide 组件处有一个控制点。
  • NURBS Curve nurbs - 创建一条 NURBs 曲线，每个 guide 组件处有一个控制点。
Order order - 使用 NURBs 或 Bezier 插值时的曲线阶数。
Up Vector upvector - - 用此参数控制骨骼扭转。
  • X upvectorx - up 向量的 X 分量。
  • Y upvectory - up 向量的 Y 分量。
  • Z upvectorz - up 向量的 Z 分量。
Map Exports mapexports - 把计算出的变换值直接导出到骨骼链参数上。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

操作符输入

  • Input 0: -

Info CHOP 通道

Inverse Curve CHOP 的附加信息可以通过 Info CHOP 获取。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
