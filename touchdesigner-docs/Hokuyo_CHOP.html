Hokuyo CHOP

摘要

Hokuyo CHOP 用于与 Hokuyo 激光扫描仪通信（串口或以太网接口）：Hokuyo Products

Hokuyo CHOP 可用于所有串口或以太网 Hokuyo 激光扫描仪，不过我们内部测试过的只有 URG-04LX-UG01（串口）、UST-10LX（以太网）和 UST-20LX（以太网）。

它可以与 Blob Track CHOP 配合，检测其视野中的对象。参见 Blob Track 的 Snippet。

在 Windows 操作系统中，可以在设备管理器里找到计算机所有可用的串口。它们的名称以 'COM' 开头。例如：COM1、COM2、COM3 等。

Hokuyo CHOP 以米为单位输出激光扫描的测量数据，可以是极坐标或笛卡尔坐标。激光扫描在 N 度范围内逆时针进行（由设备定义，例如 URG-04LX-UG01 为 240 度，UST-10LX 为 270 度），并返回在该点激光击中第一个物体的距离。

Hokuyo 激光扫描仪有一个角分辨率，它规定一次完整扫描返回的数据点数。对于 URG-04LX-UG01，大约每 0.3515 度有一个数据点，因此在 240 度扫描中共有 682 个数据点。对于 UST-10LX，每 0.25 度有一个数据点，因此在 270 度扫描中共有 1080 个数据点。Hokuyo 激光扫描仪还有起始步和结束步，用于定义总的检测范围。

在下表中，UST-20LX 和 UST-10LX 的测量参数与 UTM-30LX 相同。UST-20LX 以太网型号的工作方式也与 UST-10LX 相同。

参数 - Connect 页

Active active - 启用与 Hokuyo 传感器的连接。
Interface interface - - 选择设备接口。
  • Serial serial - 启用串口通信，以及 Serial Port 参数。
  • Ethernet ethernet - 启用以太网通信，以及 Network Address 参数。
Serial Port port - 选择串口连接要使用的 COM 端口。弹出菜单中提供默认端口名 1 到 8，不过也可以在此字段中手动输入任何名称。
Network Address netaddress - 要连接的激光扫描仪的网络地址。UST-10LX 设备的默认地址是 192.168.0.10。
High Sensitivity highsensitivity - 此复选框启用传感器的高灵敏度模式。High Sensitivity 模式会提高激光扫描仪的检测能力，但测量误差的概率也更高。仅适用于串口设备。
Motor Speed motorspeed - 修改激光扫描仪的电机转速。在同一环境中运行多个激光扫描仪时应使用此选项。不同激光扫描仪使用不同电机转速可以避免它们之间的光干扰。仅适用于串口设备。
Start Step startstep - 指定激光扫描的第一个数据点。Start step 必须是第一个和最后一个测量点之间的数字，且必须小于或等于 end step 参数。请参考上表获取各设备的第一个/最后一个测量点。此参数默认为 0，即 UST-10LX 和其他以太网激光器的起始步。对于 URG-04LX-UG01 及类似设备，起始步必须为 44 或更大。
End Step endstep - 指定激光扫描的最后一个数据点。End step 必须是第一个和最后一个测量点之间的数字，且必须大于或等于 start step 参数。请参考上表获取各设备的第一个/最后一个测量点。此参数默认为 1080，即 UST-10LX 和其他以太网激光器的结束步。对于 URG-04LX-UG01 及类似设备，结束步必须为 725 或更小。
Output output - - 以极坐标或笛卡尔坐标输出扫描数据。
  • Polar Coordinates polarcoords - 输出在每个具体扫描角度（以度为单位）上到第一个被击中物体的距离。
  • Cartesian Coordinates cartesiancoords - 输出逆时针扫描中每个被检测物体的 x、y 坐标，以设备中心为原点。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Hokuyo CHOP 的附加信息可以通过 Info CHOP 访问。

Hokuyo CHOP 特有的信息通道

  • incoming_data_packets -
  • data_packets_per_second -
  • dropped_data_packets -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
