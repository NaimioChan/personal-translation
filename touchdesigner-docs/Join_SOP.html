Join SOP

摘要

Join SOP 把一串面或曲面连接成一个继承它们属性的单一图元。不同类型的面可以连接在一起，曲面也可以。不允许混合面与曲面类型。被连接一侧的曲面不必具有相同的行数或列数。不同阶数和参数化的样条类型都是有效输入。必要时，Join SOP 会把多边形等较简单的图元转换为 Bzier 和 NURBS。

连接不同于倒角（见 Fillet SOP）或缝合（见 Stitch SOP），因为它取 n 个图元并在可能改变图元相连端之后把它们转换成一个。倒角会在每对输入之间创建一个新图元，且从不影响原始形状。缝合会改变原始形状，但不改变结果图元的数量。

参数 - 页

Group group - 如果存在输入组，在此字段中指定组名将使该 SOP 仅作用于指定的组。接受模式匹配，说明见 Pattern Matching。
Blend blend - 决定图元的连接方式。blended 的面或曲面通常会把要连接的端部重新定位，并把它们分别转换为单个公共点、行或列。降低容差（见下文的 Tolerance）可以减少或消除改变量。不进行 blend 时，原始形状不受影响，而是用一条弧状倒角连接选定的端部。无论哪种情况，结果都是一个图元。
Tolerance tolerance - 容差的含义随连接类型而变。容差低时，blended 图元的形状改变更小。如果容差小于 1，会在最后一点与倒数第二点（或行、列）之间插入新的点、节点、行或列。容差越低，插入位置越靠近被拉拢的端部，受影响的区域也越小。容差为零时，blended 输入完全不变：面由一条直线连接，曲面由一个近乎平坦的线性面片连接。

容差也会影响在非 blended 图元之间构建的倒角的大小和圆滑度。容差为零会产生短而平的倒角；容差为一会生成尖锐、不自交的倒角。

Bias bias - 只影响 blended 图元，方式是在两个原始端部之间线性改变公共点、行或列的位置。偏置为零时，公共部分会与第二个图元的端部重合，而第一个图元的端部会被一直拉伸到那里。偏置为一时，公共部分会与第一个图元的端部重合，第二个图元会被拉伸。

混合容差为 0 时，偏置不起作用。

Multiplicity knotmult - 影响在混合点插入的节点数量，从而允许平滑或尖锐的连接。Multiplicity 开启时，连接会是尖锐的。Blend 未开启时，开启 multiplicity 会通过强制插入重节点来影响倒角的形状和紧度。

multiplicity 开启时，倒角通常表现更好。不过这也意味着生成的面或曲面在连接点处存在不连续，可能不太适合在该区域做点建模。

Multiplicity 对多边形和网格没有影响。

Connect Closest Ends proximity - Join SOP 把第一个图元的尾端与下一个图元的头端相连，依此类推；除非开启此开关，此时会改为选择最近的端部。对于曲面，此选项会按下文 Direction 参数所指定的 U 或 V 方向进行邻近测试。
Direction dir - - 此菜单决定连接操作的参数化方向，可以是 U 或 V，仅在输入为曲面时有意义。U 方向与列相关；V 方向指行。例如，在 U 方向连接两个曲面，会生成一个比任一输入列数更多的曲面。行数也可能更多，但仅当两个输入的行数不同或 V 基不同时。
  • in U ujoin -
  • in V vjoin -
Join joinop - - 可以选择按组连接 n 个图元，或以循环方式每隔 n 个图元连接一次。

For Example；假设有六个图元，编号 0 - 5，且 N = 2。那么，

  1. Groups 会生成 0-1 2-3 4-5
  2. Skipping 会生成 0-2-6 和 1-3-5。
  • All Primitives all -
  • Groups of N Primitives group -
  • Skip Every Nth Primitive skip -
N inc - 决定要分组或跳过的图元数量。N2。
Wrap Last to First loop - 启用后，它会把第一个图元的开头与最后一个图元的结尾相连，从而形成一个单一的封闭面或外壳。如果输入中只有一个开放的图元，它会被闭合。Primitive SOP 提供了更直接的图元闭合方式，但几乎没有形状控制。
Keep Primitives prim - 如果未勾选此按钮，输入图元在连接后会被删除。如果勾选，则会保留。

Info CHOP 通道

Join SOP 的附加信息可以通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
