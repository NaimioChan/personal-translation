Filter CHOP

摘要

Filter CHOP 会平滑或锐化输入通道。它通过将每个采样与其邻近采样范围内的采样组合，来设定该采样的新值。每种滤镜类型对邻近采样使用各自的权重系数。Filter Width 决定使用多少个邻近采样。

默认的 Gaussian 滤镜能很好地平滑数据，通常 Filter Width 在 .3 秒左右。当输入是阶跃变化到新值时，Box Filter 很有意思：数值会线性插值到新值。

在 Filter CHOP 之后接一个 Trail CHOP，把滤波后和滤波前的信号连到它的输入端，会很有用。

若你想传入一个或多个多采样通道，并希望把每个采样当作独立的滤镜来滤波，请打开 Filter per Sample 参数。

若想要类似但更突然的效果，参见 Lag CHOP。

Filter CHOP 既能滤波运动也能滤波声音，但滤波声音更适合用其他 CHOP（参见 Audio Filter CHOP、Band EQ CHOP 和 Parametric EQ CHOP）。

One Euro Filter 说明

当人与 TouchDeigner 处于交互循环中并希望快速响应时，One Euro Filter 特别有用：它对数值的大幅变化响应迅速，同时能平滑输入中的抖动：

  • Cutoff Frequency：若慢速抖动是个问题，则减小它。
  • Slope Cutoff Frequency：避免抖动引起的高导数突变。（研究论文的实现将此值固定为 1Hz）
  • Speed Coefficient：若高速滞后是个问题，则增大它。

1 € filter（「one Euro filter」）是一种简单算法，用于对含噪信号进行滤波，以获得高精度和高响应性。它使用一阶低通滤波器，并带有自适应截止频率：低速时，较低的截止频率通过减少抖动来稳定信号；而随着速度提高，截止频率会增大以减少滞后。该算法易于实现、占用资源极少，且只有两个易于理解的参数，便于调节。与其他滤波器相比，在相同的抖动抑制量下，1 € filter 的滞后更小。（researchgate.net）

以下是调节 One Euro 滤波器的步骤： 首先将 Speed Coefficient 设为 0，Cutoff Frequency 设为一个合理的中间值，例如 1 Hz。然后让身体部位保持静止或以极低速度移动，同时调整 Slope Cutoff Frequency 以消除抖动，并在这些慢速动作中保持可接受的滞后（减小 Slope Cutoff Frequency 会减少抖动但增加滞后，Slope Cutoff Frequency 必须 > 0）。接下来，让身体部位朝不同方向快速移动，同时增大 Speed Coefficient，重点是最小化滞后。先找到合适的数量级来调节 Speed Coefficient，这取决于你所处理的数据种类及其单位：不妨从 0.001 或 0.0001 这样的值开始。你可以先将 Speed Coefficient 反复乘以或除以 10，直到在快速移动时察觉延迟有变化。注意 Speed Coefficient 与 Speed Coefficient 这两个参数有明确的概念关系：若高速滞后是个问题，增大 Speed Coefficient。若慢速抖动是个问题，减小 Slope Cutoff Frequency。

参考：Casiez, G., Roussel, N. and Vogel, D. (2012). 1€ Filter: A Simple Speed-based Low-pass Filter for Noisy Input in Interactive Systems

参数 - Filter 页

Type type - 共有七种滤镜：
  • Gaussian gauss - 此滤镜具有高斯（正态或「钟形」）曲线形状，可平滑通道。它起低通滤波器的作用。滤镜越宽，截止频率越低，数据越平滑。
  • Left Half Gaussian halfgauss - 这会在通道上产生滞后。若输入通道表示随时间变化的数值，此滤镜只使用当前采样之前的采样。对于时间数据，这更符合实际，因为你无法预知未来。（也许某天可以。）它具有半钟形。
  • Box box - 此滤镜为箱形，即它使用的每个邻近采样具有相同权重系数。它可能在输出通道中产生不想要的台阶，因为当窗口滑过采样时，滤镜两端采样的影响不会淡出。它对数据进行低通滤波，类似 Gaussian 滤镜。
注意：使用 Gaussian 或 Box 过滤时，通道会延迟半个滤波器大小（即 Filter Size 为 30 个采样时，输出会延迟 15 个采样）。要消除此延迟，可使用 Left Half Gaussian 或 Left Half Box 过滤器。应用 Sharpen 或 Edge Detect 过滤器总会使输出延迟半个滤波器大小。应用 Despike 过滤器会使输出延迟整个滤波器大小。
  • Left Half Box halfbox - 此滤镜在数据上产生滞后，只使用之前的采样，其他方面与箱形滤镜相同。
  • Edge Detect edge - 此滤镜检测「边缘」，即输入通道中的急剧变化。它起高通滤波器的作用。随着滤镜宽度增大，会加入更多低频。
  • Sharpen sharpen - 此滤镜锐化所有高频。它是边缘检测结果与原始数据之和。
  • De-spike despike - 此滤镜移除「尖峰」（比预期采样值高出或低出 `Spike Tolerance' 以上的采样）。滤镜宽度可以让你消除持续数个采样的尖峰。宽滤镜会移除宽尖峰（持续数个采样的尖峰），小滤镜只会移除窄尖峰（长度为一两个采样）。
  • Ramp Preserve ramp - 此滤镜尝试输出一个按 'Ramp Rate' 参数速率递增的斜坡。输入到 Filter CHOP 的通道应以该速率递增，其中可能有些误差/噪声。Ramp Preserve 会忽略输入通道，除非输入值与当前斜坡值之差大于 'Ramp Tolerance' 参数。当差值大于容差时，斜坡会重置，从当前输入值开始。
  • One Euro oneeuro - 此滤镜适合在保持高精度和响应性的同时滤波含噪信号。
Effect effect - 滤镜影响通道的程度（0 - 无影响，1 - 最大影响）。
Filter Width width - 计算当前采样时使用的周围采样量。以 Units 表示。
Filter Width Unit widthunit - 选择使用 Samples、Frames 还是 Seconds 作为此参数的单位。
Spike Tolerance spike - 对于 De-spike 滤镜类型，这是采样与其邻近采样可以相差而不被视为尖峰的量。
Ramp Tolerance ramptolerance - 使用 Ramp Preserve 滤镜时，若输入值偏离当前输出斜坡值达到此量，斜坡会重置为新的输入值。否则 Ramp Preserve 会按指定的 'Ramp Rate' 继续攀升。
Ramp Rate ramprate - 使用 Ramp Preserve 滤镜时，这是 CHOP 输出通道递增的速率。只有当输入通道值偏离期望输出值达到 'Ramp Tolerance' 的量时，CHOP 才会改为输出输入通道值。
Number of Passes passes - 滤镜应用于通道的次数。
Filter per Sample filterpersample - 将滤镜应用于通道的每个采样，而不是跨越整个通道。适用于多采样通道。
Cutoff Frequency (Hz) cutoff - 若慢速抖动是个问题，则减小它。
Speed Coefficient speedcoeff - 若高速滞后是个问题，则增大它。
Slope Cutoff Frequency (Hz) slopecutoff - 避免抖动引起的高导数突变。
Reset reset - 开启时重置（旁路）滤镜效果。
Reset Pulse resetpulse - 立即重置滤镜效果。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。
