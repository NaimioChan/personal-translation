Audio Dynamics CHOP

摘要

Audio Dynamics CHOP 用于控制音频信号的动态范围。动态范围指的是音频在一段时间内的响与轻程度。该操作符包含两种动态控制：压缩和限制。 建议将此 CHOP link 到一个 Info CHOP，以便获得一些视觉反馈：正在应用的压缩或限制量将显示在 Info CHOP 中。

Compressor 压缩器的目标是在信号超过某个阈值时降低其振幅，同时引入很少或没有谐波失真。所需的阈值由用户设置，应用的压缩量由压缩比决定。当输入信号高于和低于阈值时，attack 和 release 参数决定压缩应用和释放的速度。

Limiter 限制器的作用是确保信号处于某个动态范围内，同时尽可能少地引入谐波失真。与压缩器不同，其目标不是应用平滑或音乐化的动态控制，而是将信号保持在「安全」范围内，以兼容下游的任何 CHOPS（例如 Audio Device Out）。这意味着 Limiter 具有更突然（瞬时）的 attack 值，用户无法调整。

Input 2：Side Chain Channels - 传入的其他音频通道可用于确定应用到第一个输入的音频通道的增益。

注意：这是一篇关于以程序化方式 mixing audio for games 的有用文章。

参见 Audio Filter CHOP、Audio Para EQ CHOP、Audio Band EQ CHOP、Audio Spectrum CHOP 另请参见：Envelope CHOP。

参数 - Pre 页

Input Gain (dB) inputgain - 此参数控制通道在到达压缩器之前的音量。如果要压缩的信号不在有用的动态范围内，可用此参数来修正。

参数 - Compressor 页

Enable Compressor enablecompressor - 开启或关闭压缩器。
Compression Type compressiontype - 决定使用哪种压缩方法。
  • Automatic Gain Control compagc - 这种压缩适合在一段较长时间内振幅不断变化的音频段落。要应用这种压缩，将阈值设为接近你希望听到的最大音量的值。应用较大的压缩比（约 1.0），并将 attack 和 release 设为较高的值。当音频段落越过阈值时，压缩会缓慢应用；如果设置得当，信号将被压缩到恒定的范围。将 attack 和 release 设得太低会导致输出音量变化过快，而设得太高则可能导致压缩应用得太慢。
  • Musical Dynamics compmus - 如果一段人声或乐器演奏的振幅在变化，需要被带入统一的动态范围，可以尝试应用这种压缩。除非想要浓重的压缩声音，否则最好轻量使用此效果。将阈值设入你想要压缩的音量范围，并应用较低的压缩比。尝试不同的 attack 和 release 值，直到获得良好的动态平衡。
Channel Linking chanlinkingcomp - 当各个通道进入 CHOP 时，它们可以按相同的量压缩，也可以单独压缩。如果按相同量压缩，将评估所有通道的最高峰值，并用此值确定压缩量。

如果单独压缩，每个通道将被评估并按不同的量压缩。

  • Compress Equally compequally -
  • Compress Individually compindividually -
Threshold (dB) thresholdcompressor - 此参数设置信号必须超过才会应用压缩的阈值。它使用分贝刻度，其中「0 分贝」被视为可能的最响信号*，「-60 分贝」则几乎听不见。这里假定输入信号已归一化到「-1 到 +1」的范围。
Ratio ratiocompressor - 比值是应用到信号的压缩量，相对于信号超出阈值的程度而言。「0」的比值不应用任何压缩。「1」的值会使信号振幅被压到阈值。大于「1」的值会使信号在越过阈值时变得更轻。
Knee kneecompressor - knee 定义了当信号接近或越过阈值时，CHOP 如何过渡到压缩。knee 为「0」（硬拐点）时，可把压缩器视为应用平坦的压缩响应，其中：

compression_gain(db) = amount_that_signal_has_crossed_threshold(dB) * compression_ratio 这类压缩并不总是理想的，因为它可能对声音的动态产生强烈影响。增大 knee 参数会使进入压缩的过渡变得平滑。 参见下方的 Knee 图。

Attack (msec=10**val) attackcompressor - attack 控制当信号越过阈值时压缩器响应的速度。增大 attack 参数会使压缩器以更慢、更平滑的速率应用压缩。参数增得太多会导致压缩应用得太慢。
Release (msec=10**val) releasecompressor - release 控制当信号降到较低电平或完全低于阈值时压缩器响应的速度。与 attack 一样，较高的值会减慢响应，但值太高则会太慢。
Output Gain (dB) gaincompressor - 应用压缩后，信号可以用 Gain 降低到较低的音量水平。为了补回失去的音量，可以增大此参数。

参数 - Limiter 页

Enable Limiter enablelimiter - 开启或关闭限制器。
Channel Linking chanlinkinglim - 与压缩器相同。
  • Limit Equally compequally -
  • Limit Individually compindividually -
Threshold (dB) thresholdlimiter - 这是信号必须超过才会应用限制的阈值。通常此值应保持为「0」分贝。与压缩器一样，「0」分贝的值被视为可能的最响信号。

从数字音频的角度来看，在「+1 <-> -1」之间变化的信号电平处于「0」分贝的音量水平，因为数字系统无法表示大于「+1 <-> -1」的任何值。超过的值在送往输出设备时只会被削波。限制器可以让你在超出此范围时避免音频被削波，并应用一种平滑得多、几乎听不见的快速压缩。 降低阈值会使输出被钳制到更低的水平。

Release (msec=10**val) releaselimiter - 虽然限制器的 attack 总是很快，但 release 仍可由用户设置。它决定限制器退出限制状态所需的时间。增大 release 有助于平滑限制器的效果。值太高可能导致限制器释放得太慢。例如，在一次过响的音调爆发之后，限制器的增益可能被推到极端值。这个极端值需要很长时间才能完全释放。

在 frequency 这类参数中放入带有通道索引 me.channelIndex 的表达式，即可让每个通道各不相同。

Knee kneelimiter - 与压缩器类似，此参数控制当信号变响时 CHOP 如何过渡到限制。较大的 knee 意味着更平滑的过渡。参见上方的 Knee 图。

设为「0」时，信号超过阈值之前不会应用任何限制。增大 knee 参数时，会在信号超过阈值之前应用一些限制，以整体上平滑限制的效果。

参数 - Post 页

Dry / Wet Mix drywet - 当此参数从 1（Wet）向 0（Dry）减小时，会移除滤波器的效果。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

  • limiter_multiplier - 限制器降低响度的量。不以 dB 表示——线性

  • limiter_db

  • limiter_release_msec

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
