硬件帧锁定

什么是 Hardware Frame-Lock？

Hardware Frame Lock 用于让 GPU 与连接到它的显示器或投影仪同步。这样就可以在多个显示器或投影仪之间、以及在多块显卡之间保持帧精确的同步。当内容跨越多个输出，或使用多个 GPU 和/或多台带多个 GPU 的计算机时，通常需要这种同步。当显示器或投影仪需要同步到外部时基源时也可以使用它。

Hardware Frame Lock 由两部分组成。

Genlock

Genlock 确保所有显示器的刷新间隔在同一时刻发生（彼此同相）。同步信号可以由同步组中的某块 Quadro 内部产生，也可以由插入 Quadro Sync 卡的外部 House-Sync 信号提供。没有 Genlock 时，各显示器可能在不同间隔刷新，导致部分显示器在其他显示器之前开始更新内容，从而出现视觉撕裂。Genlock 通过在 Nvidia 控制面板中设置 Quadro Sync 获得。无论 TouchDesigner 项目如何设置，它都能工作（只要 V-Sync 开启），并且不需要 Pro 许可证。 也可以用命令行 QSync Utility 来设置。

Hardware Frame-Lock

Hardware Frame-Lock 在 Window COMP 中通过「Hardware Frame-Lock」参数启用。此功能也使用 Quadro Sync 卡，并确保所有显示器只有在全部准备好更新时才更新。这可以避免某个进程出现卡顿、还没准备好输出新帧，而其他进程却照常更新，导致最终画面同时显示两帧不同内容的情况。发生卡顿时，所有进程都会停顿并等待落后的进程。此模式由于所需的额外开销，也会降低整体渲染性能，因此只应在绝对必要时使用。很多内容在多个显示器上展示都不需要 Frame Lock，看起来也很好。

Frame Lock 的限制

新的 Direct Display Out TOP 是使用 Frame Lock 更稳健的方式，因为它避免了 Window COMP 所需的与 Windows 桌面合成器的任何交互。这是在 2025.30000 及之后版本中使用 Frame Lock 的推荐方式。 Frame Lock 不是容错机制。如果一台机器开始丢帧，那么所有机器都需要丢帧。对于表现不佳的机器，没有「追赶」机制。 因此，让 Sync Out CHOP 和 Sync In CHOPs 具有很高的超时值很重要。后面会详细说明。

Direct Display Out TOP

Direct Display Out TOP 允许直接对接 GPU 的 DisplayPort 输出，而不与 Windows 桌面合成器交互。这使 Frame Lock 的工作流程稳健得多。

Window COMP

总体而言，Frame Lock 无法稳健应对窗口位置变化、模式变化（进入 Perform 再回到 editor）。使用 Frame Lock 时，应让应用程序直接以 Perform 模式启动，窗口定位为全屏无边框，并位于正确显示器上的正确位置。

诊断 Frame Lock

Nvidia 有几个关于 Frame Lock 行为的选项，可以使用 configureDriver.exe 进行配置。下载 configureDriver.exe 工具：https://www.nvidia.com/en-us/drivers/driver-utility/

然后选择「Enable the SwapGroupPresentIndicator for OpenGL and Vulkan」来开启此功能。

另请参阅 Sync In CHOP 和 Syncing Multiple Computers。

Nvidia Quadro Sync

Nvidia Quadro Sync 硬件方案需要使用特定的 Quadro 显卡以及相应的 Quadro Sync 卡来实现同步。每台需要同步的计算机都需要自己的同步卡，通过带状线缆连接到显卡。

要求

Quadro Sync

  • NVIDIA Quadro Sync 卡
  • NVIDIA Quadro/RTX 专业显卡。

单系统上的多个 GPU

这是最简单的设置，可以同步单台计算机上多个 GPU 和显示器的输出。

为同步设置系统时，有一些限制需要考虑：

  • 所有连接的显示器必须使用相同的 EDID。最简单的方法是确保它们是相同的类型、制造商和型号。
  • 在 TouchDesigner 中使用多个 GPU 时，请使用 GPU Affinity 以获得最佳性能。这需要为每个 GPU 使用单独的进程文件。

1) 确保显卡与同步卡之间的所有连接和供电都已正确设置。

2) 确保 Nvidia 控制面板中的 Vertical Sync 设置为「On」或「Use the 3D application setting」。

3) 要启用 Frame Lock，打开 Nvidia 控制面板的 Synchronize Displays 部分。

  1. 把 The timing server is... 的选项设为 On this System。
  2. 在 Select displays to lock to the server: 部分勾选所有所需显示器的复选框。

4) 在你的 TouchDesigner .toe 文件中，确认以下内容：

  • 如果在单台 PC 上使用多个 GPU，请确保为每个 GPU 上运行的每个 .toe 文件正确设置 GPU Affinity。
  • 启动进程时让 Direct Display Out TOP 不处于激活状态。
  • 在 Direct Display Out TOP 中打开 Hardware Frame-Lock 参数。
  • 在服务器和客户端机器上使用 Sync Out CHOP 和 Sync In CHOP。
  • 使用从 Sync Out CHOP 进入 Sync In CHOP 的一个通道来打开所有输出上的 Direct Display Out TOP。这是必需的，以便各进程中的交换完全同步发生。在此过程中，服务器和客户端各自 CHOP 中的 Timeouts 应设为 5 秒。这确保所有输出都能打开并在任何进程开始推进之前准备就绪。
  • 播放开始后，可以把 Server 上的 Timeout 调低一些，比如 1 秒，以便在出现问题时仍能与之交互。不过在客户端上应保持较高值，因为它们永远不应超时。
