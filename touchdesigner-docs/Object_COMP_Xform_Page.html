Object COMP Xform 参数页

参数 - Xform 页

Xform 参数页控制对象组件在世界空间中的变换。

Transform Order xord - 附加到此参数的菜单允许你指定组件各项变化发生的顺序。改变 Transform 顺序会改变物体的去处，就像先走一个街区再向东转，与先向东转再走一个街区，到达的地方不同。用矩阵数学的说法，如果我们采用「向量右乘」（列向量）约定，Scale、Rotate、Translate 的变换顺序会写成 translate * rotate * scale * vectorOrPosition。

Rotate Order rord - 点击此选项时出现的旋转矩阵让你可以设置组件旋转的变换顺序。与上面的 transform 顺序一样，改变组件旋转发生的顺序会改变组件的最终位置。

Translate / Rotation / Scale t[xyz] r[xyz] s[xyz] - 这三个字段分别让你指定沿三个轴中任一轴的移动量；绕三个轴中任一轴旋转的角度（度）；以及沿三个轴的非等比缩放。除了直接在这些字段中输入数值，你也可以在 Viewport 中用 Select & Transform 状态操作组件来修改数值。

Pivot p[xyz] - Pivot 点编辑字段让你定义组件缩放和旋转所围绕的点。改变组件的 pivot 点会产生不同结果，具体取决于对组件执行的变换。

例如，在缩放操作中，如果组件的 pivot 点位于 -1, -1, 0，而你想把组件缩放为 0.5（将其尺寸减小 50%），组件会朝 pivot 点方向缩放，看起来会向左下滑动。

在上面的示例中，对具有不同轴心点的组件执行旋转会产生非常不同的结果。

Uniform Scale scale - 此字段让你沿三个轴等比改变组件的尺寸。

注意： 一般不建议对摄像机的通道进行缩放。不过，如果你决定这么做，涉及缩放时渲染输出会尽可能与 Viewport 保持一致。

Constrain To constrain - 允许把对象的位置约束到在此参数中指定路径的任何其他对象。

Look At lookat - 通过命名你希望组件注视（Look At）或指向的组件，可让你为组件定向。一旦指定该组件进行注视，它就会持续朝向那个组件，即使你移动它。例如，如果你想让摄像机跟随另一个组件的运动，这会很有用。Look At 参数使该组件指向另一组件的原点。

提示： 要为摄像机指定一个场景中不显示的兴趣中心，请创建一个 Null 组件并关闭其显示标记。然后把 Camera 的父级设为新建的 Null 组件，并用 Look At 参数让摄像机注视该组件。你可以用 Select 状态移动 Null 组件来引导摄像机的视线。如果你希望同时看到摄像机和 Null 组件，请打开 Null 组件的显示标记，并在额外的 Viewport 中使用 Select 状态，方法是点击 TouchDesigner 窗口右上角的某个图标。

Look At Up Vector lookup - 指定 Look At 时，可以为 lookat 指定一个 up 向量。如果不使用 up 向量，当 lookat 组件穿过目标组件的 Y 轴时，可能会得到很差的动画效果。

  • Don't Use Up Vector - 如果 look at 组件不会穿过目标组件的 Y 轴，请使用此选项。
  • Use Up Vector - 这会精确规定执行注视的组件的旋转。指定的 Up Vector 不应与 look at 方向平行。参见下文 Up Vector。
  • Use Quaternions - 四元数是 3D 旋转的一种数学表示。此方法会找出在球面上从一点移动到另一点的最有效方式。

Path SOP pathsop - 指定作为组件要沿其移动的路径的 SOP。例如，你可以指定一个为摄像机提供样条路径的 SOP。

制作提示：沿路径平滑运动 - 让组件沿动画路径运动很简单。不过，使用 NURBS 曲线作为路径时，你可能会注意到组件沿路径行进时会意外加速和减速。这通常是因为 CV 的间距不均匀。这种情况下，使用 Resample SOP 重新分布 CV，使其沿曲线均匀分布。但要注意——如果路径曲线是动态的，使用 Resample SOP 可能会很慢。

另一种方法是在路径曲线上附加 Basis SOP 并将其改为 Uniform Curve。这样组件会沿曲线匀速运动，也就不需要 Resample SOP 及其生成的多余点。

Roll roll - 使用角度控件，你可以指定组件沿路径动画时的旋转。

Position pos - 此参数让你指定组件沿路径的位置。可输入的数值范围从 0 到 1，其中 0 等于路径的起点，1 等于路径的终点。值滑块允许高达 10，以便沿路径进行多次「循环」。

Orient Along Path pathorient - 如果选择此选项，组件将沿路径定向。组件的正 Z 轴将指向路径前进方向。

Up Vector up - 为组件定向时，Up Vector 用于确定正 Y 轴指向何处。

Auto-Bank Factor bank - Auto-Bank Factor 根据组件当前位置处路径的曲率使其翻滚。要关闭自动倾斜，请把 bank scale 设为 0。
