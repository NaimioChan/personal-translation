ST2110 Out TOP

摘要

注意

License: 仅在 TouchDesigner Pro 中可用。

支持 Blackmagic 和 AJA 的 ST2110 设备。Note: Support for Deltacast IP devices will be removed in future builds.

要获取为输出 essence 生成的 SDP，请使用 Info DAT 并选择要获取的 SDP。

另请参阅 ST2110 In TOP、ST2110 Device CHOP。

Audio Buffer Length audiobufferlength - 音频缓冲队列保持多长。这有助于在视频生成出现卡顿时避免音频爆音。

Audio Source Port audiosourceport - 音频 essence 发送所用的本地网络端口号。有些设备会自动选择该端口。
Audio Destination Port audiodestport - 音频 essence 应发送到的目标网络端口号。
Audio Payload Id audiopayloadid - 为音频 essence 的 RTP 数据包指派的 Payload Id 编号。音频通常为 97。

参数 - SPS 页

SPS 即 Seamless Protection Switching，部分采集卡支持该功能。它为同一份数据提供第二条并行路径作为备份，以防主路径失效。

Enable SPS enablesps - 控制 SPS 流是否处于活动状态。
SPS Video Destination IP spsvideodestip - 视频 SPS essence 应发送到的组播 IP 地址。
SPS Video Source Port spsvideosourceport - 视频 SPS essence 发送所用的本地网络端口号。有些设备会自动选择该端口。
SPS Video Destination Port spsvideodestport - 视频 SPS essence 应发送到的目标网络端口号。
SPS Video Payload Id spsvideopayloadid - 为 SPS 视频 essence 的 RTP 数据包指派的 Payload Id 编号。视频通常为 96。
SPS Audio Dest IP spsaudiodestip - 音频 SPS essence 应发送到的组播 IP 地址。
SPS Audio Source Port spsaudiosourceport - 音频 SPS essence 发送所用的本地网络端口号。有些设备会自动选择该端口。
SPS Audio Destination Port spsaudiodestport - 音频 SPS essence 应发送到的目标网络端口号。
SPS Audio Payload Id spsaudiopayloadid - 为音频 SPS essence 的 RTP 数据包指派的 Payload Id 编号。音频通常为 97。

参数 - Color 页

Color Space colorspace - - 在通过网络线缆发送数据之前，从工作色彩空间转换到此色彩空间。在可能的情况下，该色彩空间信息也会包含在输出信号中。

  • Rec.601 (NTSC) rec601ntsc -
  • Rec.709 rec709 -

  • DCI-P3 dcip3 -

  • Display P3 (D65) displayp3d65 -
  • ACES2065-1 aces2065-1 -
  • ACEScg acescg -
  • ACESproxy acesproxy -
  • Passthrough passthrough -
Output Reference White outputreferencewhite - - 为输出而从 Working Color Space 转换颜色值时，此参数控制应如何相对于 Reference White 处理这些值。如果 Working Color Space 的 Reference White 相同，则不做调整。如果不同，则会把颜色的 Reference White 水平（亮度）调整到 Output Color Space 期望的范围。例如，若工程设定的 SDR Reference White 为 120 nits、HDR Reference White 为 80 nits，且工程 Working Color Space 为 HDR 而 Output Color Space 为 SDR：那么值为 (1, 1, 1) 的颜色（在 HDR 色彩空间中为 80 nits）将被转换为 (0.66, 0.66, 0.66)，在 SDR Output Color Space 中仍是 80 nits。
  • Default For Color Space default - 根据检测到/选择的色彩空间，使用 SDR 或 HDR Reference White。
  • Standard (SDR) sdr - 将输出色彩空间的参考白值按 SDR 处理。
  • High (HDR) hdr - 将输出色彩空间的参考白值按 HDR 处理。
  • UI ui -
Output Color Space outputcolorspace - - 控制输出前把数据转换到哪个色彩空间。如果输出（文件/SDI/ST2110 等）支持元数据，还会尝试把色彩空间写入其中。某些输出形式在其元数据中只支持有限数量的色彩空间。如果输出形式不认识该色彩空间，则不会包含任何元数据。
  • sRGB srgb - sRGB 色彩空间，使用 sRGB 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • sRGB - Linear srgblinear - sRGB 色彩空间，使用线性传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.601 (NTSC) rec601ntsc - Rec.601，NTSC 原色色彩空间，使用 Rec.601 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.709 rec709 - Rec.709 色彩空间，使用 Rec.709（与 Rec.2020 相同）传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.2020 rec2020 - Rec.2020 色彩空间，使用 Rec.2020（与 Rec.709 相同）传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Rec.2020 ST2084PQ rec2020st2084pq - Rec.2020 色彩空间，使用 Perceptual Quantizer 传递函数。相对于 Reference White 被视为 HDR 色彩空间。
  • Rec.2020 HLG rec2020hlg - Rec.2020 色彩空间，使用 Hybrid Log Gamma 传递函数。相对于 Reference White 被视为 HDR 色彩空间。
  • DCI-P3 dcip3 - DCI-P3 色彩空间，D65 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 (D60) dcip3d60 - DCI-P3 "D60 sim" 色彩空间，D60 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Display-P3 (D65) displayp3d65 - Display-P3 色彩空间，D65 白点，sRGB gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Display-P3 (D65) - Linear displayp3d65linear - Display-P3 色彩空间，具有 D65 白点和线性传递函数。相对于 Reference White 被视为 HDR 色彩空间。
  • ACES2065-1 aces2065-1 - ACES 2065-1（也称为 ACES AP0）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACEScg acescg - ACEScg（也称为 ACES AP1）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACESproxy acesproxy - ACESproxy 色彩空间，具有对数传递函数。相对于 Reference White 被视为 HDR 色彩空间。
  • Passthrough passthrough - 选中后，颜色值将按原样用于运算，不作任何修改，也不尝试将其转换到 Working Color Space。

参数 - Common 页

Output Resolution outputresolution - - 快速更改 TOP 数据的分辨率。
  • Use Input useinput - 使用输入的分辨率。
  • Eighth eighth - 将输入的分辨率乘以该数值。
  • Quarter quarter - 将输入的分辨率乘以该数值。
  • Half half - 将输入的分辨率乘以该数值。
  • 2X 2x - 将输入的分辨率乘以该数值。
  • 4X 4x - 将输入的分辨率乘以该数值。
  • 8X 8x - 将输入的分辨率乘以该数值。
  • Fit Resolution fit - 使宽度和高度适应下面给定的分辨率，同时保持宽高比。
  • Limit Resolution limit - 宽度和高度被限制为下面给定的分辨率。如果其中一个维度超过给定的分辨率，则宽度和高度将被缩小，以在保持宽高比的同时适应给定限制。
  • Custom Resolution custom - 启用下面的 Resolution 参数，可直接控制宽度和高度。
Resolution resolution - - 仅当 Resolution 参数设为 Custom Resolution 时启用。某些生成器（如 Constant 和 Ramp）不使用输入，仅使用此字段确定其大小。右侧的下拉菜单提供一些常用分辨率。
  • W resolutionw -
  • H resolutionh -
Resolution Menu resmenu - 包含一些常用分辨率的下拉菜单。
Use Global Res Multiplier resmult - 使用 Edit>Preferences>TOPs 中的 Global Resolution Multiplier。这会将所有 TOP 的分辨率乘以设定的数值。在硬件规格不同的计算机上工作时这很方便。如果项目是在显存充足的工作站上设计的，而使用仅有 64MB VRAM 的笔记本电脑的用户可以将 Global Resolution Multiplier 设为一半或四分之一，以便以可接受的速度运行。勾选此复选框后，此 TOP 会受全局乘数影响。
Output Aspect outputaspect - - 设置图像宽高比，使任何纹理都能以任何尺寸查看。在合成宽高比不同的 TOP 时要注意意外结果。（可以使用 xres、yres、aspectx、aspecty 定义非方形像素的图像，其中 xres/yres != aspectx/aspecty。）
  • Use Input useinput - 使用输入的宽高比。
  • Resolution resolution - 使用图像所定义分辨率的宽高比（即 512x256 为 2:1），此时每个像素为方形。
  • Custom Aspect custom - 允许你在下面的 Aspect 参数中显式定义自定义宽高比。
Aspect aspect - - 在 Output Aspect 参数设为 Custom Aspect 时使用。
  • Aspect1 aspect1 -
  • Aspect2 aspect2 -
Aspect Menu armenu - 包含一些常用宽高比的下拉菜单。
Input Smoothness inputfiltertype - - 控制对 TOP 输入图像的像素过滤。
  • Nearest Pixel nearest - 使用最近像素或精确图像表示。在任何非 Native Resolution 的缩放级别查看时，图像会显得有锯齿。
  • Interpolate Pixels linear - 在像素之间使用线性过滤。这就是让查看器中的 TOP 图像在各种缩放级别下都好看的方式，在使用除 Native Resolution 以外的任何 Fill Viewer 设置时尤其有用。
  • Mipmap Pixels mipmap - 缩放图像时使用 mipmap 过滤。这可用于减少细节丰富的运动/缩放图像中的伪影和闪烁。
Fill Viewer fillmode - - 决定 TOP 图像在查看器中的显示方式。

注意： 要理解 TOP 如何处理图像，在刚开始放置 TOP 时，你会希望将此设为 Native Resolution。这样你可以看到实际发生的情况，而没有任何查看器自动缩放。

  • Fit Best best - 拉伸或压扁图像，使图像的任何部分都不被裁剪。
  • Fit Outside outside - 拉伸或压扁图像，使图像在保持其比例的同时填满查看器。这通常会导致图像的一部分被查看器裁剪。

操作符输入

  • Input 0: -

Info CHOP 通道

ST2110 Out TOP 的额外信息可通过 Info CHOP 获取。

特定于 ST2110 Out TOP 的 Info 通道

  • connected - 若设备已连接/活动则为 1，否则为 0。
  • frames_sent - 发送出去的视频帧数。
  • frames_dropped - 输出端的丢帧数。这些是进程未能提供新数据的输出帧。如果 TouchDesigner 运行的帧率低于信号格式的帧率，该值应会增长。这意味着先前创建的帧会被再次（或更多次）发送出去。
  • frames_skipped - 这些是 TouchDesigner 已产出、但未被输出设备消费的帧。这可能是因为 PCIe 带宽（或设备）慢于数据吞吐量/帧率所需。
  • packets_dropped - 在会报告此项的设备上，为输出端丢弃的数据包数量。
  • packets_underrun - 在会报告此项的设备上，为设备需要时缺失的数据包数量。
  • frame_queue_length - 在 CPU 内存中排队等待输出的视频帧数。
  • frame_hw_queue_length - 在设备硬件中排队等待输出的视频帧数。

TOP 通用信息通道

  • resx - TOP 的水平分辨率，以像素为单位。
  • resy - TOP 的垂直分辨率，以像素为单位。
  • aspectx - TOP 的水平宽高比。
  • aspecty - TOP 的垂直宽高比。
  • depth - 如果此 TOP 包含 2D 或 3D 纹理数组，则为该 2D 或 3D 数组的深度。
  • gpu_memory_used - 此 TOP 使用的纹理内存总量。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
