Audio File Out CHOP

摘要

Audio File Out CHOP 使用多种不同的编解码器将音频流保存到文件。

目前支持 .wav、.mp3、.aiff 和 .ogg 容器格式。

另请参阅：Movie File Out TOP。

audiofileoutCHOP_Class

参数 - Audio File Out 页

File Type filetype - - 选择输出文件的文件类型（容器）。
  • WAV wav - .wav 文件类型。可使用 Codec 参数选择音频编解码器。
  • OGG ogg - .ogg 文件类型。音频编解码器为 Vorbis。Vorbis 压缩可实现无缝播放。
  • MP3 mp3 - .mp3 文件类型。音频编解码器为 MP3。MP3 压缩无法无缝播放。Vorbis（.ogg）是很好的替代方案。
  • AIFF aiff - .aiff 文件类型。音频编解码器为 Uncompressed 16-bit（PCM）。
Unique Suffix uniquesuff - 启用后，me.fileSuffix 在 file 参数中使用时将是唯一后缀。
N n - 禁用唯一后缀后，me.fileSuffix 将只包含 N 的值，而不是唯一值
File file - 设置保存输出的音频文件的路径和文件名。文件扩展名必须与 file type 参数匹配。
Codec codec - - 输出 WAV 或 AIFF 文件类型时选择压缩编解码器。使用 AIFF 时可选 Big Endian 选项，这是处理 AIFF 文件的行业标准。
  • Uncompressed 16-bit (PCM) pcm16 - 未压缩音频（Pulse Code Modulation）
  • Uncompressed 24-bit (PCM) pcm24 - 未压缩音频（Pulse Code Modulation）
  • Uncompressed 32-bit (PCM) pcm32 - 未压缩音频（Pulse Code Modulation）
Bit Rate bitrate - - 选择 MP3 文件类型的比特率。
  • 96 kb/s b96 -
  • 128 kb/s b128 -
  • 192 kb/s b192 -
  • 256 kb/s b256 -
  • 320 kb/s b320 -
Record record - 开启时，将打开音频文件并开始录制。关闭时，将关闭文件并释放读/写锁。
Pause pause - 暂停将音频录制到音频文件。
Header Source DAT headerdat - 指向一个 Table DAT 的路径，该 DAT 存储应写入输出图像或影片文件的头部元数据。头部数据以键值对写入，第一列存储键，第二列存储对应的值。有关支持的元数据，请参阅 File Metadata。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

操作符输入

  • Input 0: -

Info CHOP 通道

Audio File Out CHOP 的额外信息可通过 Info CHOP 访问。

Audio File Out CHOP 特有的 Info 通道

  • last_samples_written -
  • total_samples_written -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
