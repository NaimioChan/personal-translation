参数对话框控件

以下是参数对话框中用于操作 parameter 值的控件列表。

标签页

标签页用于将功能相似的参数组合划分到一个页中。

有时标签页会嵌套，这样在一个标签页内，各参数可以根据标签页在不同情况下应用不同设置。例如，Container 组件的 Drag 页上就有两个标签页：When Dragging this Component 和 On Dropping into this Component。
