Pulse CHOP

摘要

Pulse CHOP 在一个通道中按固定间隔生成脉冲。每个脉冲的幅度可以用 CHOP 滑块或图形上的控制柄编辑。

Pulse CHOP 在可指定长度的静态通道中给出一组脉冲。

另请参阅 LFO CHOP，可获得 Time Sliced 的无尽脉冲流；以及 Pattern CHOP，可获得一串静态脉冲。

Pulse CHOP 可用作 Copy CHOP 的触发，并可表示按固定时间间隔发生的事件。

默认情况下，脉冲长度为单个采样，但你可以增大 Pulse Width，使脉冲成为通向下一脉冲的阶梯。还可以按 Linear、Ease In Ease Out、Cubic 或其他曲线在脉冲之间插值。

脉冲可以限制在最小/最大范围内。若 Limit Type 为 Clamp，图形上会在每个脉冲的最小值和最大值处显示额外的便捷控制柄。

Pulse CHOP 生成单个通道，你可以将多个 Pulse CHOP 合并为一个多通道 CHOP。

Pulse CHOP 使用其可选的第一输入作为开始/结束参考，因此多个 Pulse CHOP 可以拉伸到同一区间。

可选的第二输入用于在特定采样位置指定脉冲。每个单采样输入通道随后会被解释为一个脉冲的位置。

为了设置最后一个采样处的值，提供了 Last Pulse at Last Sample 选项。否则，最后一个脉冲会位于最后一个采样之前。

参数 - Pulse 页

Number of Pulses number - 要生成的脉冲数量。
Interpolate interp - - 可以使用以下函数曲线在脉冲之间插值：
  • Off nointerp - 禁用插值。
  • Linear (Ramp) linear - 区间拉长时在采样之间使用线性插值。区间缩短时对新采样附近的所有采样取平均。
  • Ease in easein - 使用 easein() 函数进行混合。
  • Ease out easeout - 使用 easeout() 函数进行混合。
  • Ease in Ease out cosine - 同时使用 easein() 和 easeout() 函数。
  • Cubic cubic - 在采样之间进行三次插值，曲线比 Linear 更平滑。此方法不建议用于剧烈变化的通道。
  • Connect connect - 脉冲值不会回到 0，而是保持到下一次脉冲。
Pulse Width width - 默认情况下，脉冲长度为单个采样，但你可以增大 Pulse Width，使脉冲成为通向下一脉冲的阶梯。
Pulse Width Unit widthunit - - 选择此参数使用的单位：Samples、Frames 或 Seconds。
  • I samples -
  • F frames -
  • S seconds -
Limit Type limit - - 用此菜单启用下方的 Minimum 和 Maximum 钳制值。
  • Off nolimit - 脉冲可以是任意值，不进行钳制。
  • Clamp clamp - 将脉冲值钳制到下方指定的 Minimum 和 Maximum 值。
Minimum min - 脉冲可以限制在 Minimum 下限内。若 Limit Type 为 Clamp，图形上会在每个脉冲的最小值处显示额外的便捷控制柄。
Maximum max - 脉冲可以限制在 Maximum 上限内。若 Limit Type 为 Clamp，图形上会在每个脉冲的最大值处显示额外的便捷控制柄。
Minimum Spacing minspacing - 通过第二输入创建脉冲时，Minimum Spacing 参数会按此处指定的最小距离将脉冲彼此分开。间距单位由 Pulse Index Unit 参数控制。
Cascade when Spacing cascade - 启用脉冲之间的最小间距后，级联会按最小间距所增加的采样量来偏移脉冲。
Outside Pulses outpulse - 控制如何处理指定在操作符范围之外的脉冲位置。
Pulse Index Unit pulseunit - 控制第二输入中指定的值应按何种单位解释。
Separate Output Channels separateoutchan - 打开后，会为每个脉冲创建单独的通道。
Non-Additives nonadditives - 启用后，不会把同一采样索引上指定的脉冲幅度相加。
Last Pulse at Last Sample lastpulse - 为了设置最后一个采样处的值，提供了 Last Pulse at Last Sample 选项。否则，最后一个脉冲会位于最后一个采样之前。

参数 - Channel 页

Channel Names channelname - 可以用「chan[1-20]」这样的简单图案创建许多通道，它会生成 chan1 到 chan20 共 20 个通道。有关此项及所有 Options 的说明，请参见 Common CHOP Parameters 一节。参见 Scope and Channel Name Matching Options。
Start start - 区间起点，以 Units（秒、帧或采样）表示。
Start Unit startunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
  • I samples -
  • F frames -
  • S seconds -
End end - 区间终点，以 Units（秒、帧或采样）表示。
End Unit endunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
  • I samples -
  • F frames -
  • S seconds -
Sample Rate rate - 通道的采样率，单位为每秒采样数。默认值：me.time.rate
Extend Left left - 左侧延伸条件（范围之前/之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道起点之前的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Extend Right right - 右侧延伸条件（范围之前/之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道终点之后的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Default Value defval - 用于 Default Value extend 条件的值。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

可通过 Info CHOP 访问 Pulse CHOP 的额外信息。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
