图元组

图元组是一组相互关联的图元，被当作一个集合处理。这很重要，因为你可以对它们整体施加操作，省去对每个元素分别操作的麻烦。此外，图元组还可用于过滤掉特定操作不需要的图元。分组不是影响整个输入，而是把操作范围限制在组内的图元上。

创建图元组

在 Touch 中对图元分组，可使用 Group SOP、任何带点组输入栏的 SOP，或 SOP Editor 中的 Select 状态。 在 SOP Editor 中对图元分组：

  1. 使用 Select 状态，并在子图标中选择 Primitive Groups 图标。
  2. 用光标选择所需的图元。
  3. 点击 + 按钮调出 Parameters 对话框，然后点击 Combine Groups 页标签。
  4. 在编辑字段中输入新的组名。
  5. 点击 group <- selection 按钮。

有序组与无序组

图元组可以是有序的或无序的。在 SOP Editor 的 Select 状态下，单击鼠标键执行有序选择。拖动光标划过图元可进行批量选择。此操作会创建一个框选区域，围住若干图元。以这种方式选择的图元会生成无序组。

批量选择只有在框选区域内仅包含一个图元时，才会生成或保持有序选择。无序组按创建顺序存储图元；有序组按选择顺序存储图元。

如果想重新选择组内的图元，可以从 Select 状态调出 Parameters 对话框，在 Combine Groups 页标签下的 Group 参数弹出菜单中选择组名。然后点击 selection <- group 按钮。

删除图元时，Touch 会自动将它从所属的所有图元组中移除。
