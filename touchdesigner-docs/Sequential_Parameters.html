序列参数

基础

序列参数是参数块（Sequence Blocks），用户可多次复制它们以创建多个实体。例如，Constant CHOP 允许你通过点击参数对话框中的 + 按钮创建多个通道。Point POP 允许你创建多个点，等等。

（请参阅本页末尾的「Creating Custom Sequential Parameters」以创建你自己的序列块。）

所有参数序列都以一个带 + 和 - 按钮的序列头参数开始，后面跟着一个或多个参数「块」。下图显示了 Add SOP 的 Points 页的参数对话框。序列头的标签为「Point」，后面跟着两个序列块，每个块包含一个 Position 和一个 Weight 参数。

序列块中的参数按以下形式命名：

<sequence name><sequence index><parameter name>
  • sequence name：序列名称，同时也是序列头参数的名称
  • block index：块在序列中的索引（从 0 开始）
  • parameter name：参数的描述性名称

在下面的示例中，序列参数被展开以显示其 Python 名称。序列名称为「point」。

你可以通过多种方式添加和删除序列参数块。头部的 + 和 - 按钮分别添加和删除序列块。你也可以在参数对话框中右键点击块参数的名称，然后在 RMB 菜单中选择 Insert Block 或 Remove Block。最后，你还可以使用 Python（见下文 Python 一节）

用于参数表达式的序列辅助函数

在参数表达式中，你可以使用：

  • me.curSeq 访问当前正在计算的参数的 sequence。
  • me.curSeq.numBlocks 访问当前正在计算的参数所在序列的块数量。len(me.curSeq) 也可以。
  • me.curBlock 访问当前正在计算的参数的 sequence block。
  • 借此你可以引用该块中的任何其他参数，例如 me.curBlock.par.posz，无需指定序列名称或块编号。

在 Python 中使用序列参数

有许多工具类、成员和方法可用于在 Python 中处理序列参数。本节将概述这些功能，详细文档请参阅：Sequence Class、SequenceBlock Class、SequenceCollection Class

序列对象

Sequence objects 是在 Python 中与参数序列交互的主要接口。可通过序列中任意参数的 sequence 成员访问它们，也可通过序列名称和操作符的 seq 成员访问。

mySequence = op('/add1').par.point0posx.sequence	# 获取序列对象
sameSequence = op('/add1').seq.point				# 获取序列对象的另一种方式

每个序列都有一个唯一的 sequence name。该名称用于标识序列，并作为所有块参数名称的前缀。它也是序列头参数的名称。你可以将鼠标悬停在序列头的标签上，或查看块参数名称来找到序列名称。它还存储在序列对象的 name 成员中。

序列块

Sequence blocks 是参数序列中重复出现的参数块。可使用 Sequence 对象访问和控制序列中的块。以下示例使用上文 ADD SOP 图片中显示的 point 序列。

seq = op('/add1').seq.point				# 获取名为 "point" 的序列对象
alsoSeq = op('/add1').seq['point']		# 也可以使用方括号写法
allBlocks = seq.blocks					# 所有序列块的列表
count = len(seq)						# 序列块的数量
firstBlock = seq[0]						# 序列中的第一个块
print(firstBlock.index)					# 打印该参数块在序列中的索引。这里为 0

你也可以使用序列对象控制序列中的块数量：

seq.numBlocks = 4						# 将块的数量设为 4
seq.insertBlock(2)						# 在第 2 个位置插入一个块
seq.destroyBlock(0)						# 销毁第一个块

序列块提供了对块内参数的便捷访问，使用熟悉的 par 和 parGroup 集合类。请注意，从序列块访问参数时，使用的是基础名称（不含序列前缀），而不是完整名称。下面的示例说明了这一点，同样使用上文 Add SOP 的图片：

seq = op('/add1').seq.point				# 获取名为 "point" 的序列对象
block = seq[1]							# 序列中的第二个块

block.par.weight = 3					# 访问该块的 "weight" 参数。它的实际名称是 "point1weight"
block.par['weight'] = 4					# 也可以使用方括号写法
block.parGroup.pos = [1,1,1]			# 访问该块的 "pos" 参数组。

序列块中的参数

在序列中获取参数的三种方式。

op('add1').par.point1posx                # 法线
op('add1').seq.point[1].par.point1posx   # 按块索引
op('add1').seq.point[1].par.posx         # 最简单的方式：按块索引

有多种方式可以遍历每个块中的给定参数：

seq = op('add1').seq.point

# 打印所有 weight 参数的值

# 使用 Sequence.blocks
for block in seq.blocks:
	print(block.par.weight)
	
# 使用 Sequence[blockIndex]
for index in range(len(seq)):
	print(seq[index].par.weight.eval())
	
# 使用 Sequence.blockPars：
for weightPar in seq.blockPars.weight:
	print(weightPar.eval())

参数和 ParGroups 中的序列辅助成员

参数和 parGroups 中内置了一些用于处理序列的辅助成员：

# 参数辅助方法
par = op('/add1').par.point0weight	
print(par.sequence)						# 打印序列对象。如果该参数不在序列中则为 None

# parGroup 辅助方法
parGroup = op('/add1').parGroup.point1pos		
print(parGroup.sequence)				# 打印序列对象。如果该 parGroup 不在序列中则为 None
print(parGroup.sequenceIndex)			# 打印该 parGroup 的序列块在序列中的索引。这里为 1
print(parGroup.blockIndex)				# 打印该 parGroup 在其块中的索引。这里为 0（它是块中的第一个 par）

创建自定义序列参数

你可以使用 Component Editor 在组件上创建自定义序列参数。创建序列有两种方式：

方法一

  1. 创建一个 Sequence 参数，它会生成序列头
  2. 在 Sequence 参数下方创建所需的块参数
  3. 将 Sequence 参数的 numBlocks 改为你创建的块参数数量

方法二

  1. 创建所需的块参数
  2. 选中这些块参数
  3. 右键点击其中一个选中的参数，选择 Create Sequence

向序列添加和移除参数

有几种方式可以向序列添加或移除参数：

  • 将它们拖入或拖出序列。
  • 在参数列表中选中它们，然后在 RMB 菜单中选择 Add To Sequence 或 Remove From Sequence。
  • 更改 Sequence 头参数的 numBlocks 成员。

引用另一个块

引用序列中的另一个块时，块可能会被重排序、删除或插入，因此需要块中有某种不变的东西。例如，如果你删除了前面的块 0、1 或 2，me.curSeq[3] 会变成 me.curSeq[2]。

但如果你在块中创建一个专门名为 Blockname 的参数（数值或字符串），那么对于每个新块，其值都会自动附加一个唯一编号。例如，如果块中第一个 Blockname 被设为 A7，那么下一个块将包含设为 A8 的块名，依此类推。要在以后任何时候获取该块，可以直接按名称索引：me.curSeq['A7']，而要访问该块的某个参数，只需 me.curSeq['A7'].par.Speed，例如。

如果你将该块的原始参数设为只读，那么所有新建的 Blockname 参数也将是只读的，这更为可取，因为你不希望有人误改它。
