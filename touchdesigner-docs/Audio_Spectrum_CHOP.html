Audio Spectrum CHOP

摘要

Audio Spectrum CHOP 计算并显示输入通道的频谱。

在默认的 Visualization 模式下，该 CHOP 会强调较高频率的电平和较低频率的范围，以更易理解的方式显示频谱。

在另一种模式，即 Time to Magnitude and Phase 模式下，音频可以转换到频谱域，进行处理，然后再转换回来，得到经过滤波的音频信号。将信号转换为其频谱时，会从包含音频信号的一个通道生成两个通道。一个通道包含频率分量的幅度，另一个包含相位。这些通道的命名例如 chan1_m 和 chan1_p，其中 _m 和 _p 分别是幅度通道和相位通道的后缀。

提示：如果从默认的 8192 采样减小 FFT Size，可以缩短计算时间。此 CHOP 最快的形式是将 Output Length 参数设为 "Output Length Manually"。例如将输出缓冲区大小设为 2048 采样，FFT Size 设为 2048。每次计算时，该 CHOP 查看最新的 2028 采样（在 44.1 KHz 下相当于 50 msec，即 3 帧），这已经足够。注意该 CHOP 的默认形式会给出 22,000 个采样：从 1 Hz 到 22,050 Hz，步长为 1 Hz（设为 Frequency vs Logarithmic 缩放时），专为清晰解读而设计：采样 1000 就是 1000 Hz 处的音频电平。

提示：要找出进入 Audio Spectrum CHOP 的波的确切频率，查看该节点的 Info 弹出窗口（在节点上按 MMB）。其中写道：将 "Frequency ↔ Logarithmic Scaling" 设为 0，然后将任意采样乘以 xxxx 即可得到该采样处的频率。xxxx 取决于采样率等，并非常数。

参见 Audio Filter CHOP、Audio Para EQ CHOP、Audio Band EQ CHOP、Audio Oscillator CHOP，均设置为 White Noise。

参数 - Spectrum 页

Mode mode - - 选择要使用的模式，模式见下文。
  • Visualization visual - 以更有用的方式显示频谱，（默认情况下）提升高频的电平，并拓宽低频的水平范围。
  • Time to Magnitude and Phase timetoraw - 假定输入为信号，计算频谱。
  • Magnitude and Phase to Time rawtotime - 假定输入为频谱（类似于设置为上述选项的 Audio Spectum CHOP 所输出的频谱），重建信号。
FFT Size fftsize - - 转换为频率需要 2 的幂次采样数，例如 512、1024、2048。（FFT 即 Fast Fourier Transform。）采样越多，频谱越准确，但越不能代表最新的声音。无论大小如何，该 CHOP 都使用最新的采样。已知 44100 采样/秒的音频在时间轴帧率为 60 帧/秒时每帧为 735 采样，若该 CHOP 晚 1 帧计算且 FFT 大小为 1024，则它会重用 1024-735 = 289 个采样，这很好，因为有一点重叠。但若它晚 2 帧计算，则会漏用 446 帧，因为它已前进 735*2=1470 个采样，而只使用其中的 1024 个。
  • 64 64 -
  • 128 128 -
  • 256 256 -
  • 512 512 -
  • 1024 1024 -
  • 2048 2048 -
  • 4096 4096 -
  • 8192 8192 -
  • 16384 16384 -
Frequency <-> Logarithmic Scaling frequencylog - Logarithmic（=1）对人耳来说更直观。每个八度用相同数量的采样表示，因此低频更易读。Frequency（=0）对固定的 Hz 数显示一个采样，这是原始 FFT 给出的结果，但上层大多数采样并不有趣。你的耳朵更善于听八度范围。IMPORTANT NOTE：若 Mode 设为 Visualization 且此参数设为 0，输出数据的解读会更简单：1 sample per Hz。将 CHOP 查看器的 Units 设为 Samples（在 CHOP 图表上按 RMB），则采样 5000 处看到的电平就是 5 KHz 处的电平。
High Frequency Boost highfreqboost - 为 0 时，电平不变。大于 1 时，电平被提升，主要在高频处。High Frequency Boost 可以超过 1 过度驱动。
Output Length outputmenu - - 确定输出长度的方式。
  • Match Length To Frequency matchtofrequency -
  • Set Length Manually setmanually -
Set Output Length outlength - 输出所需的采样数。采样越少，频率分辨率越低。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

说明

就 CPU 占用而言，FFT 大小为 2048 是合理的方案。频谱有良好的清晰度，也有足够的填充来（几乎）应对两次丢帧。

Audio Spectrum CHOP 的专属信息通道

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
