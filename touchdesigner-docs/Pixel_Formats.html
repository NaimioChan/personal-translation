像素格式

像素格式（Pixel Formats）规定了 TOPs 的像素如何存储。通常 TOP 使用 8 位像素格式存储。这意味着 TOP 的每个像素在其 R、G、B 和 A 通道（红、绿、蓝、Alpha）上各有 8 位信息，合计每个像素 32 位信息。8 位精度总共只能表示 256 个不同的值。由于可取值如此之少，8 位纹理在其 R、G、B、A 通道上只能存储 0 到 1 之间的值。对大多数 TOP 与渲染操作而言，这种格式通常够用。

不过，用 8 位像素格式做某些操作时，可能出现色带（color banding）之类的瑕疵。出现这种情况时，可以使用 16 位和 32 位浮点像素格式。这些格式除了不受 [0-1] 范围限制、可以取负值和大于 1 的值之外，精度也高得多。浮点像素格式还用于高动态范围（HDR）渲染。

你可以在所有 TOP 的 Common 页上用 Pixel Format 参数选择任一 TOP 的像素格式。某些像素格式受显卡限制。例如，如今大多数显卡上，32 位像素格式除 Nearest Filtering 外无法使用任何 Texture Filtering 方法。

32 位浮点格式不支持任何类型的过滤。在该 TOP 被使用的所有地方，都会被强制为最近邻过滤。

定点与浮点

定点格式无论是 8 位还是 16 位，都只能表示 0 到 1 之间的值。精度更高的定点格式只是在 0 到 1 之间有更多可表示的值。浮点格式则能表示非常大的值和非常小的值，正负皆可。

不含全部 RGBA 通道的格式

为了节省内存和提升性能，有些格式并不包含全部红、绿、蓝和 Alpha 通道。例如有只含红色通道的格式，也有只含红、绿两个通道的格式。使用这些格式时，其他 TOP 会把缺失的红、绿、蓝通道视为 0，把缺失的 Alpha 通道视为 1。

Depth TOP 与深度纹理

Depth TOP 用一种只有它能创建的特殊像素格式生成图像。那是高精度的 24 位定点格式，其值被限制在 [0,1] 范围内。其他 TOP 可以把此 TOP 作为输入而不损失精度，但你需要把自己 TOP 的像素格式设为 32 位，才能保持更高的精度水平。其他 TOP 会把深度纹理的值视为 RGBA = (D, D, D, 1)。

支持的像素格式

  • 8-bit fixed (RGBA) - 一种 RGBA 格式，每通道 8 位，每像素共 32 位。取值范围限于 [0-1]。
  • 16-bit float (RGBA) - 一种 RGBA 格式，每通道 16 位，每像素 64 位。取值可为任意数，正负皆可。
  • 32-bit float (RGBA) - 一种 RGBA 格式，每通道 32 位，每像素 128 位。取值可为任意数，正负皆可。
  • 10-bit RGB, 2-bit Alpha, fixed (RGBA) - 一种 RGBA 格式，每通道 10 位、alpha 2 位，每像素共 32 位。取值范围限于 [0-1]。
  • 16-bit fixed (RGBA) - 一种 RGBA 格式，每通道 16 位，每像素共 64 位。取值范围限于 [0-1]。
  • 11-bit float (RGB), Positive Values Only - 一种 RGB 浮点格式，红、绿通道各 11 位，蓝通道 10 位，每像素共 32 位（因此内存占用与 8 位 RGBA 相同）。此格式的 Alpha 通道始终为 1。取值可以大于 1，但不能为负，即范围为 [0, 无限)。

(R) formats - 这些格式只包含红色（R）通道的信息。这些格式中 GB = 0，A = 1。

  • 8-bit fixed (R) - 红通道 8 位，每像素共 8 位。取值范围限于 [0-1]。
  • 16-bit fixed (R) - 红通道 16 位，每像素共 16 位。取值范围限于 [0-1]。
  • 16-bit float (R) - 红通道 16 位，每像素 16 位。取值可为任意数，正负皆可。
  • 32-bit float (R) - 红通道 32 位，每像素 32 位。取值可为任意数，正负皆可。


(RG) formats - 这些格式只包含红、绿（RG）通道的信息。这些格式中 B = 0，A = 1。

  • 8-bit fixed (RG) - 红、绿通道各 8 位，每像素共 16 位。取值范围限于 [0-1]。
  • 16-bit fixed (RG) - 红、绿通道各 16 位，每像素共 32 位。取值范围限于 [0-1]。
  • 16-bit float (RG) - 红、绿通道各 16 位，每像素 32 位。取值可为任意数，正负皆可。
  • 32-bit float (RG) - 红、绿通道各 32 位，每像素 64 位。取值可为任意数，正负皆可。


(A) formats - 这些格式只包含 alpha（A）通道的信息。这些格式中 RGB = 0。

  • 8-bit fixed (A) - 一种仅含 Alpha 的格式，每通道 8 位，每像素 8 位。取值范围限于 [0-1]。
  • 16-bit float (A) - 一种仅含 Alpha 的格式，每通道 16 位，每像素 16 位。
  • 32-bit float (A) - 一种仅含 Alpha 的格式，每通道 32 位，每像素 32 位。
