节拍对话框

Dialogs 菜单下的 Beat 对话框可让你在听音乐时通过敲击节拍来设置 TouchDesigner 项目的每分钟节拍数（BPM）。Beat CHOP 用它来确定其周期长度和「相位」（即何时回到循环的起点）。

如何设置 BPM 和相位

从 Dialogs 菜单中打开 Beat 面板。

要设置 BPM，首先开启 Listen 按钮。然后按 Tap 按钮 EVERY 4 BEATS，最好在每个小节的开头按一次。每次敲击时 BPM 都会调整。10 或 20 秒后，停止按 Tab 按钮，并关闭 Listen 按钮。它会保持最新的 BPM，直到你再次 Listen/Tap。

Beat 面板会将你的敲击平均为最接近的 BPM，因此你可以持续每 4 拍敲一次，以获得更准确的平均 BPM。

当周期与音乐漂移后，可以将斜坡循环的起点重新同步到音乐小节的起点：在 Listen 按钮关闭时，按一次 Tap 按钮。它会重新同步，且不影响 BPM。

节拍圆环上的橙色三角形可用来调整相位，以便让视觉相对于音乐提前/延后。

你可以观察节拍循环，或使用 Beat CHOP 根据每分钟节拍数生成 0 到 1 的斜坡。

注意：可以使用 python 命令设置全局每分钟节拍数： op('/local/time').tempo = 140

另请参阅：Beat CHOP。
