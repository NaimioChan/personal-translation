Trail SOP

摘要

Trail SOP 接收输入 SOP，为输入 SOP 的每个点在过去若干帧内生成轨迹，并以不同方式连接这些轨迹。它可以为任何输入几何生成轨迹，无论是平移的立方体、变形的表面还是粒子。这适用于多帧残影效果和时间建模。

当使用 Particle SOP 或 Spring SOP 作为输入时，务必将 trail increment 保持为整数值。否则轨迹将无法正常工作。

trailSOP_Class

参数 - 页

Result Type result - 如何构建轨迹几何。
  • Preserve Original preserve - 保留原始几何。
  • Connect as Mesh mesh - 将结果点连接为网格。
  • Connect as Polygons poly - 将结果点连接为多边形。
  • Compute velocity velocity - 点移动得越快，会计算出相应的速度属性。
Trail Length length - 通过设定 Trail SOP 使用的最大帧数来设置轨迹长度，即 Trail Length 为 25 时，会连接此前二十五帧的几何。
Trail Increment inc - 这会跳过指定数量的帧，以更少的点构建长度相同的轨迹。这样会通过减少轨迹中的点数来降低轨迹的分辨率。在使用 Preserve Original 时，这样做更有利于残影效果。如果将 Increment 设为 2 或更大，你会看到长度相同的轨迹，但几何的副本更少。
Cache Size cache - 在可用内存中缓存的帧数。
Evaluate Within Frame Range evalframe - 此选项指定 Trail SOP 仅在当前帧范围内（$FSTART、$FEND）求值（计算）。如果未启用此选项，SOP 可以在起始帧之前求值。
Connectivity surftype - 使用 Mesh Primitive Type 时，此选项用于选择曲面类型。
  • Rows rows - 创建水平线。
  • Columns cols - 创建垂直线。
  • Rows and Columns rowcol - Rows 和 Columns 都勾选。在线框显示下看起来像四边形，但所有多边形都是开放的（如果图元类型为 polygon）。
  • Triangles triangles - 用三角形构建网格。
  • Quadrilaterals quads - 生成由四边形构成的侧面（默认）。
  • Alternating Triangles alttriangles - 生成相对的三角形；类似于 Triangles 选项。
Close Rows close - 勾选后，会闭合输出选择中的行。
Velocity Scale velscale - 勾选 Compute Velocity 时，按特定值缩放速度。
Reset reset - 开启时，清除所有缓存的几何，将轨迹重置为与输入一致。
Reset Pulse resetpulse - 将几何重置一帧。

Info CHOP 通道

Trail SOP 的附加信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
