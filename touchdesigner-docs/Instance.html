实例

TouchDesigner 中有两种实例化：

1. Geometry Component 中的几何实例是几何对象的副本，可以独立变换。Geometry COMP 有一个 Instance 参数页用于创建实例。你可以为 CHOP 的每个采样、表格的每一行、图像的每个像素或 SOP 的每个点创建一个实例。实例的变换可以通过提供带 X、Y、Z 及其他数据的 CHOP 通道来实现。

2. 实例是一个 OP，它实际上没有自己的数据，而只是引用一个 OP（或有输入）并使用其数据。这包括 Null OP、Select OP 和 Switch OP。在此语境下，它是对另一个 OP 数据的引用。
