Projection POP

摘要

Projection POP 接受 float3 的 3D 空间属性（如 P），并输出到 float3 属性，在笛卡尔（正交）、极坐标、圆柱和透视坐标系之间转换该属性。例如，所有采用笛卡尔 X、Y、Z 格式的点都可以转换为极坐标的经度/纬度/半径格式。

From Coordinate System 菜单让你选择如何解释输入属性的 3 个数值：

  • Cartesian 将 float3 属性的 3 个数值视为通常 3D「正交」坐标空间中的 X、Y 和 Z。（在 TouchDesigner 中，X 为从左到右的水平方向，Y 为从下到上的垂直方向。Z 沿视线方向，由远及近。）
  • Spherical 将该属性的三个数值视为经度、纬度和半径，假设轴为垂直的 Y 轴。
  • Cylindrical 将该属性的 3 个数值视为纬度（绕 Y 的角度）、Y 值和半径。
  • Screen Space 是沿 Z 轴的透视形式 - 你需要指定额外的摄像机/透视信息。0,0 为左下角，1,1 为右上角。
  • Normalized Device Coordinates（NDC） - 对于视野内的点，第一个和第二个分量在 -1 到 1 之间，其中 0,0 位于中心。第三个分量在 0 到 1 之间（重新映射到 Near 和 Far 距离）。

To Coordinate System 菜单让你选择希望输出属性的 3 个数值采用何种形式。

角度可以用以下形式表示

  • Degrees，即通常图形标准中的角度（360 为一整圈），或
  • Radians（Pi 3.14157 为一整圈）
  • Cycles（值为 1 表示完整旋转 360 度）
  • Normalized - 一种 0-1 归一化形式，类似 Spherical 的经度，具有环绕特性：沿 -Z 轴看去，后方为 0，左侧为 .25，正对为 .5，右侧为 .75，后方为 1。对于纬度，数值从南极的 0 到北极的 1。有时用于在球体上映射纹理。

另请参阅 Sphere POP、Tube POP、Normalize POP 以及 Texture Map POP。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
