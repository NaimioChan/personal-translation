Feedback POP

摘要

Feedback POP 接收另一个称为「target」的 POP 在上一帧的输出，即延迟一个计算周期，并将其沿操作符链向下传回 target POP。这样就能逐帧增量修改已有的 POP 数据。

执行 Initialize 时，它会对接入的输入做快照，作为其初始状态，并保持该状态直到你点击 Start。（不点 Initialize 而直接按 Start 会立即做快照并开始。）但若 Pre-Roll 大于 0，按 Initialize 会先运行循环那么秒数，然后进入「ready」状态等待 Start。

接上一个 Info CHOP，查看其 initializing、ready、running 和 done 通道，以及一些计时器计数通道（timer_seconds ....

关闭 Play 参数会暂停循环，点击 Go To Done 会结束等待 Initialize 的反馈循环。这两个操作都会阻止链上的节点继续计算。

另请参阅 Particle POP，它是 Feedback POP 的扩展。另请参阅 Trail POP 和 Cache POP，它们以其他方式捕获、保持和操作过去的 POP 数据。

参数 - Feedback 页

Target POP targetpop - 对网络中下游某个 POP 节点的引用，其数据会在一帧之后取回。
Initialize initializepulse - 根据其输入和参数初始化 POP，它通过在接入的 Info CHOP 中打开 ready 通道表示已就绪，等待 Start 脉冲。
Start startpulse - 开始播放。
Play play - 暂停或播放反馈循环。
  • Play play -
  • Step Pulse steppulse - 仅步进一帧。
Pre-Roll preroll - 在初始化期间先运行循环这么长时间，然后才就绪。
  • Pre-Roll preroll -
  • Pre-Roll Unit prerollunit - 预热阶段的时间单位。
Go to Done donepulse - 将立即进入 done 状态。
Use Memory Limit usememlimit - 对可复制回来的 target POP 数据启用内存限制。
Input Multiplier inputmul - 将此 POP 的 GPU 内存占用限制为输入 GPU 内存占用的倍数。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Info CHOP 通道

Feedback POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
