Build a List COMP

概述

本文详细说明构建 List COMP 的细节。假定读者已了解 Python 语言。List COMP 由回调控制，这些回调位于创建时停靠到它的 DAT 中。

回调阶段

List COMP 在 Reset 参数被脉冲或加载时运行其 init 回调。这些 init 函数用于让用户分配 Table、Row、Col 或 Cell 特定的属性，这些属性决定 List 的布局和外观。四个 init 函数按以下顺序调用：

  • onInitTable(comp, attribs)
  • onInitCol(comp, col, attribs)
  • onInitRow(comp, row, attribs)
  • onInitCell(comp, row, col, attribs)

初始化完成后，以下回调函数会在特定事件上运行：

  • 鼠标在单元格上移动时调用 onRollover(comp, row, col, coords, prevRow, prevCol, prevCoords)
  • 鼠标在单元格上按下时调用 onSelect(comp, startRow, startCol, startCoords, endRow, endCol, endCoords, start, end)
  • onRadio(comp, row, col, prevRow, prevCol)
  • onFocus(comp, row, col, prevRow, prevCol)
  • onEdit(comp, row, col, val)

使用 Folder DAT 作为内容源构建简单的 List COMP

假设你想显示 Folder DAT 的内容，并能高亮鼠标经过的行。再假设点击某一行会改变该行的布局，并运行一个以行和列为参数的自定义脚本。作为要求，第一行应作为标题行，其布局与其余行不同。此示例假定 Folder DAT 宽 5 列，并与 List COMP 平行摆放。

使用 List COMP 时要注意，它的灵活性也意味着创作者需要自行管理状态。这意味着当 List COMP 运行前面提到的回调时，必须确保以适当方式保存 List 的当前状态。例如，当某行在鼠标经过时改变布局，回调必须确保在鼠标离开该行后把布局改回默认外观。将所需状态保存在 Python 列表或字典中作为 Storage 已被证明非常有用。

在 List 页的 List COMP 参数中，将 Rows 和 Columns 参数改为反映 Folder DAT 的大小，并启用 Lock First Row 参数。在 Layout 参数页中，将 Width 参数改为 900。

打开停靠的回调 Text DAT 进行编辑。 在 initRow 函数中输入以下内容以指定每行的 bgColor，然后点击 List COMP Reset 参数查看变化： 

def onInitRow(comp, row, attribs):
	# 如果是第一行，把背景设为略偏红，否则保持灰色
	if row == 0:
		bgColor = [0.4,0.2,0.2,1]
	else:
		bgColor = [0.2,0.2,0.2,1]

	# 把 bgColor 赋给该行的属性
	attribs.bgColor = bgColor

	return

现在在 initCell 函数中指定每个单元格的内容，然后点击 List COMP Reset 参数查看变化： 

def onInitCell(comp, row, col, attribs):
	# 从 Folder DAT 获取单元格内容
	cellContent = op('../folder1')[row,col].val

	# 把 Folder DAT 中的文本赋给单元格属性
	attribs.text = cellContent

	return

立刻就能看到需要适当设置列宽，这可以在 initCol 函数中完成。 此外，我们会让第一列可拉伸，这样当我们增大 List COMP 的宽度时，第一列会调整到该宽度，而其余列保持不变。给可拉伸列的初始宽度即为其最小宽度。编辑完成后点击 List COMP Reset 参数查看变化。 

def onInitCol(comp, col, attribs):
	# 在列表中指定各列的宽度
	colWidth = [150,150,250,90,90]

	# 在列表中指定哪一列可拉伸
	stretch = [1,0,0,0,0]

	# 把宽度和拉伸属性赋给列属性
	attribs.colWidth = colWidth[col]
	attribs.colStretch = stretch[col]

	return

我们可以通过 initTable 函数以通用方式为 List COMP 添加更多格式，然后点击 List COMP Reset 参数查看变化： 

def onInitTable(comp, attribs):
	# 将所有单元格的对齐方式设为中心左对齐
	attribs.textJustify = JustifyType.CENTERLEFT

	# 将所有单元格的下边框设为淡蓝色
	attribs.bottomBorderOutColor = [0.2,0.2,0.6,1]

	return

要在鼠标经过时改变行的外观，请编辑 rollover 回调函数。rollover 回调函数在鼠标于单元格上移动时被调用。因此，在改变行的布局时，此例中应比较上一行与当前 rollover 行，只在两者不同时更改 bgColor。当鼠标移出或移入 List COMP 时，row、col、prevrow 和 prevcol 参数分别为 -1。 

def onRollover(comp, row, col, coords, prevRow, prevCol, prevCoords):
	# 确保只在 row 与 prevRow 不同时才更改布局
	if row != prevRow:

		# 我们不想更改表头行，因此判断 row 是否大于 0
		# 这也处理了移出 List 时 row 返回 -1 的情况
		if row > 0:
			rowAttribs = comp.rowAttribs[row]
			rowAttribs.bgColor = [0.2,0.4,0.2,1]

		# 与之前一样，我们检查 prevRow 不是表头行，并且
		# 我们不是从 List 外部进入
		if prevRow > 0:
			rowAttribs = comp.rowAttribs[prevRow]
			rowAttribs.bgColor = [0.2,0.2,0.2,1]

	return

要在 List COMP 上实现点击时的瞬时布局变化，可以像使用 rollover 回调那样使用 select 回调。select 回调还会接收 start 和 end 参数，start 在鼠标按下时为 True，end 在鼠标抬起时为 True。由于鼠标按下时可能在 List COMP 上移动，你还会收到 start 和 end 的行/列信息。由于不知道此前选中了哪一行，我们需要将选中的行保存到存储中： 

def onSelect(comp, startRow, startCol, startCoords, endRow, endCol, endCoords, start, end):
	# 在鼠标按下时执行
	if start and startRow > 0:
		# 获取被点击行的行属性
		# 并更改 bgColor
		rowAttribs = comp.rowAttribs[startRow]
		rowAttribs.bgColor = [0.2,0.6,0.4,1]

		# 把 startRow 存入 storage，以便在鼠标松开时还原布局更改
		comp.store('prevSelect',startRow)

		# 运行脚本并把 row 和 column 作为参数传入
		op('../myScript').run(startRow, startCol)
	
	# 在鼠标松开时执行
	elif end:
		# 从 storage 获取之前选中的行
		prevSelRow = comp.fetch('prevSelect',None)

		# 如果存在之前选中的行，把其布局恢复为默认
		if prevSelRow:
			rowAttribs = comp.rowAttribs[prevSelRow]

			# 如果鼠标仍在之前选中的行上，把其布局改为 rollover 背景
			# 否则改为默认外观
			if startRow == endRow:
				bgColor = [0.2,0.4,0.2,1]
			else:
				bgColor = [0.2,0.2,0.2,1]

			# 把颜色赋给该行的 bgColor 属性
			rowAttribs.bgColor = bgColor

		# 从 storage 中移除之前选中的行
		comp.unstore('prevSelect')

	return

使用 Python 字典作为 List COMP 的内容

单元格文本内容通过 text 属性赋值，我们也可以从列表或字典等结构中获取数据。 此示例假定内容字典具有以下结构： 

myDict = {
	'header':[
		{'id':'name','label':'Name'},
		{'id':'extension','label':'Extension'},
		{'id':'type','label':'Type'},
		{'id':'size','label':'Size'}
	],
	'content':[
		{'name':'MyList.toe','extension':'toe','type':'TouchDesigner File','size':184666},
		{'name':'MyImage.jpg','extension':'jpg','type':'Image File','size':184326},
		{'name':'MyList1.toe','extension':'toe','type':'TouchDesigner File','size':184632},
		{'name':'MyList2.toe','extension':'toe','type':'TouchDesigner File','size':184536}
	]
}

header 键保存第一行的信息，而 content 键保存其余所有行的文本。 为了从 List COMP 访问该字典，我们会将此字典作为 Dependency Class 对象存储到 List COMP。 

import TDStoreTools # 见下文

myListCOMP = op('/project1/myListCOMP')
myListCOMP.store('contentDict', TDStoreTools.DependDict(myDict))

要显示与所存字典项数相同的行数，我们将 List COMPs 的 Row 参数改为： 

len(me.fetch('contentDict',{'content':[]}))+1

同样，对于列，我们会查看 header 字典的大小： 

len(me.fetch('contentDict',{'header':[]}))

fetch 方法的第二个参数是默认值，在未找到所存项时返回。

要让单元格显示正确内容，我们需要在 initCell 回调函数中取出所存字典，并根据行和列从 content 字典中取出对应条目： 

def onInitCell(comp, row, col, attribs):
	contentDict = comp.fetch('contentDict',None)
	if contentDict:
		header = contentDict['header'][col]
		if row == 0:
			attribs.text = header['Label']
		else:
			id = header['id']
			rowContent = contentDict[row-1]
			attribs.text = rowContent[id]

	return

由于使用的是 Dependable Collection 对象，我们对字典所做的每次更新也会显示在 List COMP 中 

myListCOMP = op('/project1/myListCOMP')
contentDict = myListCOMP.fetch('contentDict',None)
newItem = {'name':'someFile.toe','extension':'toe','type':'TouchDesigner File','size':932753}
contentDict['content'].append(newItem)
