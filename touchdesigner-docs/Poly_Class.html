Poly 类

Poly 描述单个 geometry polygon 的实例。它是 Prim Class 的实例。

成员

closed → bool (Read Only):

如果 poly 闭合则返回 True，否则返回 False。

方法

没有该操作符专属的方法。

Prim 类

成员

center → TDU.Position :

获取或设置此图元的重心坐标。以 TDU.Position 对象表示。

index → int (Read Only):

该图元在列表中的索引。

normal → TDU.Vector (Read Only):

此图元计算出的法线向量，以 TDU.Vector 对象表示。

owner → OP (Read Only):

此对象所属的 OP。

weight → float (Read Only):

图元关联的权重。只有某些图元（例如由 Metaball SOP 创建的图元）才能把该值从其默认值 2.0 改掉。

direction → TDU.Vector (Read Only):

从该 SOP 的质心指向此图元质心的归一化向量。

min → TDU.Position (Read Only):

此图元在各维度上的最小坐标，以 TDU.Position 对象表示。

max → TDU.Position (Read Only):

此图元在各维度上的最大坐标，以 TDU.Position 对象表示。

size → TDU.Position (Read Only):

此图元在各维度上的尺寸，以 TDU.Position 对象表示。

方法

destroy(destroyPoints=True)→ None:

销毁并移除此对象所引用的实际图元。仅当该图元属于 scriptSOP 时此操作有效。注意：调用之后，此 SOP 中其他已有的 Prim 对象可能不再有效。

  • destroyPoints -（关键字，可选）为 True 时，其 points 也会被销毁；为 false 时，它们只是被分离。该参数默认为 True。

eval(u, v)→ TDU.Position:

在给定 u、v 坐标处计算图元上的 position。u、v 应在 [0,1] 范围内。注意： 多边形和曲线会忽略 v 参数。 

center = op('box1').prim[0].eval(0.5, 0.5)

特殊函数

len(Prim)→ int:

返回顶点总数。 

a = len(op('box1').prim[0])

[index]→ td.Vertex:

按整数索引获取特定顶点 

n = op('box1').prims[5][0]

[row, col]→ td.Vertex:

按整数行值和列值从 Mesh 获取特定顶点。 

v = op('grid1').prims[2,3]

Iterator→ td.Vertex:

遍历每个顶点。 

for m in op('box1').prims[5]:
	# 对 m（一个 Vertex）做些什么
