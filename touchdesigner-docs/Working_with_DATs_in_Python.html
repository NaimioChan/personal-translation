在 Python 中使用 DAT

处理 DAT 所用方法和类的主要文档是 DAT Class 和 Cell Class 两篇文章。本文给出使用这些方法和类的示例。

入门

描述任意 Operator 的主要类类型是基类 OP Class。你需要其中一个的引用才能做任何事。有两个全局操作符对象始终可用（Textport 中除外）：

  • me 指当前正在求值或执行的操作符。例如，执行脚本时，me 指包含它的 DAT。求值表达式时，me 指包含它的操作符。
  • root 指顶层组件 /。

要获取对其他 OP 的引用（例如位于节点 'constant1' 旁边、名为 'pattern1' 的节点），最常用的函数是 op() 和 ops()，例如 op('pattern1')。

op() 返回单个 OP 对象，而 ops 返回 OP 列表（可能为空）。它们在 td Module 中描述。

这些函数从当前组件开始搜索操作符，因此相对路径和绝对路径都受支持。当前组件定义为：me 所在的 OP。

注意 OP Class 本身也包含 op() 和 ops() 方法。此时会从该 OP 开始搜索节点。

例如：me.op('..') 总是返回其自身的父级，而 op('..') 返回当前组件的父级。

如果你在节点 'constant1' 的参数中输入 Python 表达式，并希望获取对 'pattern1' 的引用，你会输入

op('pattern1')

如果在脚本中，你可以将此引用赋给变量，以便重复访问更方便。

n = op('pattern1')

此时 op() 会相对于执行该脚本的 DAT 进行搜索。

OP 还有一个 parent() 方法，可用于获取其父级 COMP。

parent()

如果你在 COMP 的参数中放入 Python 语句，并想引用该 COMP 的子级，可以使用 OP 的 op() 方法，它在参数中可用为 me。

me.op('achildnode')

提示： 要快速了解可对任意节点使用哪些成员和方法，选择该节点，在其参数对话框中点击 Python Help 图标。你会进入该节点 python 类的 wiki。在那里你可以了解能获取节点的哪些信息，以及有哪些可用方法。也可以通过右键点击节点并从菜单中选择 "Python Help..." 打开该文档。


有关本节的更多细节，请参阅 Working with OPs in Python。

在脚本中使用 DAT

要在脚本中使用 DAT，首先要用 op() 获取你感兴趣的 DAT 的引用。最好将其赋给变量，以便在脚本中多次使用，而无需每次需要时重新搜索 OP。然后你可以使用 DAT 引用上的 [] 来引用特定单元格。你可以使用标签或索引来引用单元格。例如，此脚本将单元格从一个表格复制到另一个表格。

 # 获取名为 'table1' 的 DAT 的引用
 n1 = op('table1')
 # 获取名为 'table2' 的 DAT 的引用
 n2 = op('table2') 
 
 # 现在获取我们关注的两个单元格的引用
 c1 = n1['month', 'sales']   # 获取标为 'month' 的行与标为 'sales' 的列交叉处的单元格
 c2 = n2[3,6] # 获取第 3 行和第 6 列。（注意索引从 0 开始，而不是 1）。
 
 # 把它们作为字符串拼接，并用新值更新该单元格
 total = c1 + c2
 n2[3,6] = total

常见 Python 任务

表达式

Get a cell value by index op('table1')[2,3]
Get a cell value by label op('table1')['r1', 'c1']
Get a cell value by row index, col label op('table1')[2, 'product']
Cast cell to integer and float int(op('table1')['month', 3])
float(op('table1')['speed', 4])
Get the number of table rows op('table1').numRows
Get the number of table columns op('table1').numCols
Set a cell value by indeces or labels op('table1')[3,4] = 'hello'
op('table1')[2, 'answer'] = 'hello'
op('table1')['month', 3] = 'july'
Set a cell value by label op('table1')['r1', 'c1'] = 'abc'
Copy a table to another table op('table1').copy(op('fromTable'))
Append a row to a table op('table1').appendRow(['s1','s2', num])
Append a column to a table op('table1').appendCol(['s1','s2', num])
Access current cell in an Evaluate DAT me.inputCell
Access neighboring cells in an Evaluate DAT me.inputCell.offset(1,2)
