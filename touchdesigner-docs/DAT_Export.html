DAT Export

DAT 导出会以表格格式把数字、字符串或表达式发送到任意 operator 的 parameter。

要从 DAT 导出数据，DAT 底部的绿色 Export 标记必须开启，并且该 DAT 必须是列名正确的表格格式。 列名为：

path parameter value enable

每一行代表一个要导出到另一个节点参数的值。

path 和 parameter 指定数据将导出到的操作符与参数的网络路径。

value 列包含要导出的数据。它可以是数值、字符串值或表达式。

enable 列是可选的。设为「0」时该行的导出被禁用，设为「1」时导出启用。

DAT 的绿色 Export Flag 必须开启才能启用导出。 导出建立后，DAT 与操作符之间会出现一条虚线数据 link，表示连接。

要禁用导出，只需关闭 DAT 的 export 标记。

从 CHOP 导出的相关内容，另请参阅：CHOP Export。
