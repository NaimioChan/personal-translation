高斯泼溅

这里汇集了 TouchDesigner 中 Gaussian Splat 的相关信息。

Point File In POP 读取 gaussian splat 文件，并自动把文件中的字段转换为合适的 POP 属性。请参阅 Point File In POP 的 Operator Snippets。

可接受的文件是 .gsz（原生 gaussian splat 文件格式）和带专用 gaussian splat 字段的 .ply 文件。

可渲染为 gaussian splat 的 POP 包含以下属性：

  • P - float3
  • Color - float4
  • Rotate - float4 - 四元数
  • Scale - float3
  • Sh[15] - 十五个 float3

包含上述属性的 POP 通过连接到 gsGeo COMP 来渲染（可在 Palette 的 POPs / Gaussian Splats 下找到）。

POPs / Gaussian Splats 文件夹包含以下组件：

  • gsLoader （2026 年 9 月已过时 - Point File In POP 会自动载入 .gsz 和 .ply splat 文件）

gsTransform - 接收包含 gaussian splat 属性的 POP，执行类似 Transform POP 的平移/缩放/旋转变换，但同时会相应调整 splat 属性。（Transform POP 后续会改进为自行完成此操作）

  • gsGeo - 在其输入上连接 POP 后，它包含用 Render TOP 正确渲染所需的设置和着色器。
  • gsScene - 把上述所有内容合并到一个组件中。

（gsGeo 和 gsScene 中的着色器代码相对 Gerritens 于 2024 年发布给 alpha 测试者社区的原始代码，经过了改写、改进和修正（原代码在旋转上有误）。）
