布局

TouchDesigner 窗口由顶部的菜单栏、底部的 Timeline，以及中间可任选的一种窗格 Layout 组成。一个 Layout 由一个或多个窗格组成，每个窗格可以包含 Network Editor、Viewer、Panel 等。有关窗格使用的更多信息，请参阅 Panes。

Layout Strip

可以使用 Layout Strip 保存和调用布局，它位于 TouchDesigner 窗口顶部菜单栏的正下方。

左侧是一组默认窗格布局。有 5 种可选：single、quad、vertical split、horizontal split 和 tri split。点击相应的图标即可加载该布局。

保存自定义布局

你也可以点击 add layout 按钮来保存自己的自定义布局。

例如，如果在 TouchDesigner 界面被分成 2 个垂直窗格时添加布局，那么所有这些窗格信息（包括窗格的类型和路径）都会保存到自定义布局中，并添加到 layout strip。项目的布局保存在 .toe 文件中，以便每次重新打开项目时都能访问。布局以布局组件的形式保存在 /local/layouts 中。

加载自定义布局

点击自定义 Layout 会按保存时的配置加载窗格，并加载每个窗格保存的网络路径。

重命名和删除自定义布局

右键点击某个布局会打开菜单，其中有重命名或删除所选布局的选项。
