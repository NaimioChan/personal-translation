Vertex 类

Vertex 描述对单个几何顶点的实例引用，包含在 Prim 对象中。

成员

index → int (Read Only):

顶点在其 primitive 中的位置。

owner → OP (Read Only):

此对象所属的 OP。

point → td.Point :

获取或设置该顶点引用的 point。

prim → td.Prim (Read Only):

该顶点所属的 prim。

属性

除上述成员外，所有属性也是成员。

例如，如果 Vertex 包含纹理坐标，可以通过以下方式访问：Vertex.uv

更多信息见 Attribute Class。

方法

没有该操作符专属的方法。
