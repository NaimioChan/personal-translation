Noise CHOP

摘要

Noise CHOP 生成一种永不重复的不规则波形，数值大致在 -1 到 +1 范围内。

它既能生成平滑曲线，也能生成每个采样都随机的噪声。它使用与 Noise SOP 相同的数学方法。

你可以创建多条形状不同的曲线，并可调整周期、振幅、谐波等。

可选地，可以连接一个输入。假定该输入包含 1 到 3 个通道，表示空间中点的 X、Y、Z 坐标，用于在 3D 噪声空间中任意位置采样。输入中的一个索引在输出中产生一个采样。

所有噪声函数在 Time Slicing 开或关时表现完全一致，但 Harmonic Summation 和 Brownian 例外，它们的方法无法在 Time Slice 模式下限制为 1。当 Timeline 回绕到第 1 帧时，噪声函数会继续运行而不中断。

参数 - Noise 页

Type type - - 用于生成噪声的噪声函数。可用函数包括：
  • Sparse sparse - 基于 Sparse Convolution 生成高质量的连续噪声。
  • Hermite hermite - 比 Sparse 更快，但生成的噪声质量较低。
  • Harmomic Summation harmonic - 稀疏噪声，可控制谐波的频率步进。最慢的类型。
  • Brownian brownian - 像随机飞行中的虫子一样运动。当 Num of Integrals 为 2 时，其加速度每帧都会随机变化。
  • Random random - （白噪声）每个采样都是随机的，与其他任何采样无关。与音频中的「白噪声」相同。
  • Alligator alligator - 单元噪声。
Seed seed - 任意数字，整数或非整数均可，作为随机数生成器的起点。每个数字都会产生完全不同的噪声图案，但特征相似。
Period period - 噪声周期相邻峰值之间的大致间隔。以 Units 表示。增大周期会拉长噪声图案。

周期与频率相反。如果周期为 2 秒，基础频率就是每秒 0.5 个周期，简称 0.5Hz。Hz 指的是赫兹，那位 19 世纪的电气与音频工程师，而不是开租车公司的那位。

如果 Type 设为 Random，将此值设为零会产生完全随机的噪声。否则，周期应大于零。

Period Unit periodunit - 选择此参数使用的单位：Samples、Frames、Seconds 或 Fraction。
Harmonics harmon - 叠加在基础频率之上的高频分量数量。该数值越大，噪声越崎岖（只要 roughness 不为零）。0 个谐波则只给出基础形状。

基础频率为 0.1Hz 的谐波，默认会在 0.2Hz、0.4Hz、0.8Hz 等处产生谐波（直到 Harmonics 参数指定的谐波数量）。

Harmonic Spread spread - 谐波频率提升的倍数。通常为 2。spread 为 3、基础频率为 0.1Hz 时，会在 0.3Hz、0.9Hz、2.7Hz 等处产生谐波。此参数仅对 Harmonic Summation 类型有效。
Roughness rough - 控制高频噪声的效果。roughness 为零时，基础频率以上的所有谐波都不起作用。为 1 时，所有谐波的振幅都与基础频率相同。当 roughness 介于 0 和 1 之间时，较高谐波的振幅会从基础频率起指数衰减。

默认 roughness 为 0.5。这意味着第一个谐波的振幅是基础频率的 0.5，第二个为 0.25，第三个为 0.125。谐波叠加到基础波形上形成最终形状。Harmonics 参数和 Roughness 参数都必须非零，才能看到谐波效果。

Exponent exp - 将噪声值推向 0，或推向 +1 和 -1。（它把数值提升到该指数次幂。）指数大于 1 会把通道拉向零，小于 1 则会把峰值拉向 +1 和 -1。它用于重塑通道。
Num of Integrals numint - 定义对 Brownian 噪声进行积分的次数（参见 Area CHOP 第 114 页）。数值越大，曲线越平滑、细节越少。超过 4 的数值会产生大致相同的曲线。此参数仅对 Random 噪声类型有效。
Amplitude amp - 定义噪声值的振幅（对输出值进行缩放）。
Reset reset - 仅在操作符的 Time Slice 参数开启时可用。切换此参数会重置噪声计算，并在参数释放前保持该值。
Reset Pulse resetpulse - 仅在操作符的 Time Slice 参数开启时可用。对此参数发出脉冲会重置噪声计算。

参数 - Constraints 页

Constraint constraint - - Constraint 及其参数可让噪声曲线在选定的值上开始和/或结束。也可以强制平均值。注意： 这仅在 Time Slice 关闭时有效，因为时间切片没有预定的起点/终点。
  • None none - 未设置约束。
  • Start Value start - 将噪声起始位置设为下方「Starting Value」参数中的值。
  • End Value end - 将噪声结束位置设为下方「Ending Value」参数中的值。
  • Mean Value offset - 将噪声平均位置设为下方「Mean Value」参数中的值。
  • Start/End Values endpoints - 使用下方参数分别设置噪声的起始和结束位置。
Starting Value constrstart - 起始位置的值。
Ending Value constrend - 结束位置的值。
Mean Value constrmean - 噪声平均值对应的值。
Normalize normal - 确保所有噪声曲线落在 -1 到 1 之间。在 Amplitude 参数之前应用。仅对 Random 和 Harmonic Summation 噪声类型有效，因为 Hermite 和 Sparse 噪声始终是归一化的。随机噪声的归一化在两次积分之间进行，从而产生更受控的曲线。注意： 这仅在 Time Slice 关闭时有效，因为时间切片没有预定的起点/终点。

参数 - Channel 页

Channel Names channelname - 你可以用「chan[1-20]」这样的简单模式创建多个通道，它会生成从 chan1 到 chan20 的 20 个通道。关于此参数及所有 Options 的说明，请参见 Common CHOP Parameters 一节。参见 Scope and Channel Name Matching Options。每个通道都有唯一的 seed，因此在相同参数设置下所有通道都会不同。
Start start - 区间起点，以 Units（秒、帧或采样）表示。
Start Unit startunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
End end - 区间终点，以 Units（秒、帧或采样）表示。
End Unit endunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
Sample Rate rate - 通道的采样率，单位为每秒采样数。默认值：me.time.rate
Extend Left left - 左侧延伸条件（范围之前/之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道起点之前的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Extend Right right - 右侧延伸条件（范围之前/之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道终点之后的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Default Value defval - 用于 Default Value extend 条件的值。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Noise CHOP 的额外信息可通过 Info CHOP 查看。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
