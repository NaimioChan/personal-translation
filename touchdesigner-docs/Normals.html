法线

带点法线（蓝色）和图元法线（粉色）的 Box SOP。

normal 是与特定几何实体相关联的方向矢量，通常垂直于该实体。给定点处曲面的法线是垂直于该点曲面的矢量，由该点处切矢量的叉积计算得出。

法线取的方向（向上或向下）取决于叉积的计算顺序（可以想象软木塞随螺旋旋转方向向上或向下移动）。

法线用于诸如此类的用途：作为物体随时间运动方向的基准，以及确定着色。在 Model Editor 中，你可以用点法线和图元法线进行拾取，甚至沿法线平移几何。

表面法线表示表面朝向的方向。它用于确定表面受到多少着色；朝向灯光越多，着色越亮。

法线的类型

法线分为四种：平面法线、点法线、顶点法线和表面法线。它们表示点、平面、顶点或表面曲线的朝向（方向）。如果一条曲线是平面的，且其点不与其他图元共享，则其默认的点、顶点和图元法线相同，都垂直于曲线所在平面。

启用显示法线

在 Display Options 对话框中启用 normals 选项，即可在 TouchDesigner 中激活点、顶点和图元法线显示；该对话框可通过右键单击任意 SOP 并从上下文菜单中选择 Display Parameters 打开。

注意，必须先计算点法线（例如在 Point SOP 中）。图元法线是在需要时即时计算的，且仅在开启显示时才计算。某些系统生成的图元（如 sphere 和 cylinder）没有法线。
