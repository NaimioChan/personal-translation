参数表达式

参数表达式是位于参数表达式字段中的 Python 表达式。它可以是简单的数学公式，也可以是使用 Python 的复杂表达式。参数中一些常见的 python 表达式见 Python Tips。

Python 相关帮助请参阅 Python。

提示：在表达式中单击并按 Ctrl-e，即可在文本编辑器中编辑参数中的长表达式。也可以在参数的右键菜单中选择 Edit Expression。

（可以将节点置于旧式表达式格式 Tscript。有关所有 Tscript 表达式的列表，请参阅 Tscript Expressions，或打开 textport，单击左上角的语言选项将其设为 tscript 模式，然后输入 exhelp。）
