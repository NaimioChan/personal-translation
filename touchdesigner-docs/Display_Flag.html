Display 标记

Display flags（浅蓝色）位于 TOPs、CHOPs、SOPs 和 Object 组件上。

网络背景与查看器窗格的 Display 标记

打开操作符的 Display 标记后，即可在 Viewer 窗格中查看该 OP 的数据（即分别为 TOP Viewer、SOP Viewer、CHOP Viewer 或 Geometry Viewer）。

如果 Network Editor 窗格启用了背景显示选项，那么该类型中打开了 Display 标记的 OP 将显示在编辑窗格的背景中。网络会「浮」在其上方。背景显示通过网络编辑器的右键菜单 Display > Backdrop TOPs 启用（或 Backdrop CHOPs/Backdrop Geometry）。

另请参阅 Render Flag 和 Flag。

几何与摄像机查看器的 Display 标记

3D 组件上的同一个 Display 标记用于选择在 Camera 组件以及父级查看器中查看的对象。
