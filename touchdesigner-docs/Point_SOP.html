Point SOP

摘要

Point SOP 让你直接深入几何内部，操作 Source 中点的位置、颜色、纹理坐标和法线，以及其他属性。Point SOP 还允许创建自定义点属性。它是 Primitive SOP 的补充。使用第二个输入，可以用两个 SOP 各自的表达式进行组合（见：PointSOP Class）。如果第二个输入的点数少于第一个输入，第二个输入中的点会循环使用。

例如，你可以为点着色，或翻转输入几何的法线。使用 Position X、Y 和 Z 中的表达式，可以把任意给定的输入点连同任何标准属性，按表达式定义移到新位置。

Width（width）属性影响 Line MAT 中的线宽。Scale 属性（pscale）影响粒子大小，在 Line MAT 中它影响每个点处的圆点大小。

提示：如需更大的灵活性，请使用 Script SOP。

Group group - 如果有输入组，在此字段中指定组名会让该 SOP 只作用于指定的组。接受模式匹配，详见 Pattern Matching。
Position t - 可在此输入表达式来平移给定点的 XYZ 坐标。此处要修改的属性为：me.inputPoint.x、me.inputPoint.y 和 me.inputPoint.z。

只要在 Position X 字段中输入 me.inputPoint.x，就表示每个输入点的 X 坐标原样通过，不做任何修改。

把该输入改为 me.inputPoint.x+5 表示每个输入点的 X 坐标将位移 5 个单位。这个表达式可以扩展出许多有用的效果。Y 和 Z 字段同样可以进行变换。

翻转法线

你可以输入以下内容来翻转输入几何的点法线：

(-me.inputNormal[0] -me.inputNormal[1] -me.inputNormal[2])

填入此参数设为 Add Normals 的字段。这样可行，因为它取用现有的法线

(me.inputNormal[0] me.inputNormal[1] me.inputNormal[2])

并对其取反（前面的 - ）。

Info CHOP 通道

Point SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
