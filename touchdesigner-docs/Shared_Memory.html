共享内存

共享内存可用于多个 TouchDesigner 进程之间，或 TouchDesigner 与其他第三方应用之间。

以下操作符使用共享内存，在 TouchDesigner Educational、Commercial 和 Pro 中可用。

Shared Memory Inputs

  • Shared Mem In TOP
  • Shared Mem In CHOP
  • Shared Mem In COMP

Shared Memory Outputs

  • Shared Mem Out TOP
  • Shared Mem Out CHOP
  • Shared Mem Out COMP

全局共享内存

对于某些使用共享内存的节点，例如 Shared Mem Out CHOP 和 Shared Mem Out TOP，还有第二种共享内存工作模式的选项。通常每个节点会使用给定名称创建自己的内存，数据在节点计算时更新和读取。这意味着节点可能接收到来自不同帧的数据，因为它们在帧内的计算时间不同。

但有时希望数据之间保持同步。使用全局共享内存可以实现这一点。在底层，*Out 进程会创建一个单一的大型共享内存段，所有发送数据的 *Out 节点都会将其数据放入该段。在 *In 侧，该内存每帧读取一次，并将数据分发给所有 *In 节点。这样所有 *In 节点将始终接收到来自 *Out 进程同一帧的数据。

由于使用的是全局共享内存段，一台机器上只能有一个 *Out 进程使用全局共享内存，因为它使用一个自定义名称，如果另一个进程也尝试使用全局共享内存就会冲突。
