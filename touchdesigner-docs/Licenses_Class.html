Licenses 类

Licenses 类描述所有已安装 license objects 的集合。它可以通过 licenses 对象访问，该对象位于自动导入的 td module 中。 

print(len(licenses))	# 许可证数量
print(licenses[0])		# 列表中的第一个许可证
for l in licenses:
	print(l.type)		# 打印所有已安装许可证的类型

成员

disablePro → bool :

为 True 时，应用程序将如同没有 Pro 许可证一样运行。这可用于测试与较低级别许可证的兼容性。（另请参阅：app.addNonCommercialLimit）

dongles → list (Read Only):

获取连接到系统的加密狗列表。

machine → str (Read Only):

电脑的机器名。

systemCode → str (Read Only):

唯一的电脑系统代码。

isPro → bool (Read Only):

为 True 时，应用程序正以 Pro 许可证运行。建议使用此项和 isNonCommerical，而不是 type 方法。

isNonCommercial → bool (Read Only):

为 True 时，应用程序正以 Non-Commercial 许可证运行。建议使用此项和 isPro，而不是 type 方法。

type → str (Read Only):

所有已安装许可证中级别最高的许可证类型，某些产品为 'Pro'、'Non-Commercial'、'Commercial'。另请参阅 App Class 中的 app.product。

方法

install(key)→ bool:

使用指定密钥安装 license。成功时返回 True。
