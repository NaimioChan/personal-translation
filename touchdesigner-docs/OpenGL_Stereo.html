OpenGL 立体显示

THIS FEATURE IS NO LONGER SUPPORTED AS OF THE 2022.20000 SERIES OF BUILDS

OpenGL 原生立体（也称为 Quad Buffered Stereo）是一种向 GPU 驱动提供左眼和右眼图像、并让驱动按其自身设置和 PC 配置以自身方式呈现给用户的方法。这与其它立体输出方法不同，例如以双倍宽的输出分辨率将左右图像并排放在一起，或使用两路输出，一路用于左眼、一路用于右眼。

其中一个例子是 Nvidia 的 3D Vision 系统，显示器以 120hz（每眼 60hz）输出图像，并使用诸如 these 的快门眼镜来控制每只眼睛看到的内容。

设置

要让 OpenGL Stereo 工作，你首先需要在 GPU 驱动的设置中进行设置。详细信息请参阅 GPU 厂商的文档。对于 Nvidia 的情况，你需要先使用 Nvidia 控制面板的 'Set up Stereoscopic 3D' 部分。然后确保在 'Manage 3D settings' 部分中将 'Stereo - Enable' = On。还要确保根据你使用的显示技术选择了正确的 'Stereo - Display mode'。

接下来，要让 TouchDesigner 以启用立体窗口的方式启动，请设置 Windows 环境变量 TOUCH_STEREO=1。如果设置了 TOUCH_STEREO=1 但 TouchDesigner 无法设置立体窗口，启动时会显示一个对话框。

渲染

渲染立体图像需要使用两台彼此略微偏移的摄像机，以及非对称的投影视锥。详细讨论此问题的文章位于 here.

Matrix Class 中提供了一个新的方法 projectionStereo() 来帮助实现这一点。该函数会为左眼和右眼创建投影矩阵，你可以在 Camera COMP 中将其用作 Custom Projection。除了自定义投影之外，你还需要在 X 轴上将两台摄像机分别偏移 -IPD/2.0（左眼）和 +IPD/2.0（右眼）。IPD 是瞳距，同样传给 projectionStereo() 函数，以厘米为单位。
