Write a GLSL POP

概述

这有助于你为 GLSL POP、GLSL Advanced POP、GLSL Copy POP 编写着色器，并在 GLSL_TOP 和 GLSL_MAT 中访问 POP 缓冲区

官方 GLSL 文档可在 this address. 找到。TouchDesigner 主要支持的 GLSL 版本是 4.60。

读写属性

GLSL POP 可以通过每个 POP 的 "Create Attributes" 页创建并写入新属性，或通过 "Output Attributes" 参数选择要修改的输入属性，然后分配用于写入。来自第一个输入的未修改 POP 输入属性会以引用方式传给下游 POP，不额外占用内存。参见 POP#Some_POP_Features_and_Concepts 中的 Memory Reduction via References。

每个属性都是一个 Shader Storage Buffer Object（SSBO）。

输出属性（包括新属性）未初始化，需要由着色器代码写入值，除非 "Initialize Output Attributes" 为 On（默认）；此时对现有属性会从输入值复制，新属性则用 "Create Attributes" 页的默认值填充。这是在自定义着色器运行前额外执行的一次着色器调度，如果用户确定所有输出值都会被写入，为性能应关闭它。在下游 POP 中读取未初始化的值可能导致不可预测的行为和崩溃。

"Output Access" 菜单允许将输出属性设为只写（writeonly SSBO 限定符）或读写。读写是执行原子操作所必需的。此时应先初始化输出值，可以使用开关参数，或在多通道 POP 的第一遍中完成（仅 GLSL POP）。

所有输入的输入属性都会自动可供读取。

线程数

参见 Compute_Shader 和 Compute Shader，了解线程如何按调度次数和每个工作组的线程数组织。GLSL POP 提供简化模式以及对线程数的完全控制。大多数情况下人们希望一个线程读写一个属性元素（一个点、顶点或图元）的值，这可通过不同菜单项实现，具体取决于 GLSL POP。

Uniform

在其各自页面上用参数字段声明的 uniform 会在着色器中自动声明。

POP 概述

GLSL POP

这是最简单的 GLSL POP。它允许用户一次处理一类属性：point、vertex 或 primitive 属性。

GLSL POP 中唯一而 GLSL Advanced POP 没有的功能，是使用 "Passes" 参数多次运行着色器。

所有输入属性都可读取。对于与所选类别不同的属性，访问这些属性的函数会带属性类别前缀，与 GLSL Advanced POP 类似。例如，如果处理 point 属性，名为 "Attrib" 的属性若为 point 属性可用 TDIn_Attrib() 访问，若为 vertex 属性用 TDInVert_Attrib()，若为 primitive 属性用 TDInPrim_Attrib()。详见下文。

所有输入的索引缓冲区也可读取，见下方 uint TDInputPointIndex(uint inputIndex, uint vertIndex)。

  • "Number of Threads" 模式 "Auto" 会为所选类别（point、vertex 或 primitive）的每个元素创建一个线程。
  • "Number of Elements in Other Input" 对其他输入类似 "Auto"。

如果所选类别和输入的元素数量在 GPU 上已知而 CPU 上未知（见 POP#Indirect_POPs_and_Memory_Management），会填充间接命令缓冲区，并以间接调度启动计算着色器。

  • "Manual Number of Elements" 根据 "Number of Elements" 参数创建线程。
  • "Number of Elements" from Attribute 根据指定 POP 和属性的第一个元素值创建线程。此时计算着色器以间接调度启动。

在所有这些情况下，实际线程数是将请求线程数向上取整到最近的工作组大小，uint TDNumElements() 包含请求的线程数，uint TDIndex() 包含一个 1d 索引。

使用 "Manual" 模式时，工作组大小和调度次数可在 3 个维度上指定，此时 TDNumElements() 和 TDIndex() 未定义，会导致编译错误。

示例着色器：

void main() {
	const uint id = TDIndex();
	if(id >= TDNumElements())
		return;
		
	P[id] = TDIn_P(); // 等同于 TDIn_P(0, TDIndex());
}

为使 P[id] = TDIn_P(); 无错误编译，输入中必须存在 P，并在 "Output Attributes" 中选中用于写入。

TDIn_P() 读取输入 0（第一个输入）中元素 TDIndex() 处的 P 属性，它是 TDIn_P(0, id) 的简写，因为 id 映射到 TDIndex()。

这会用 P[id] 写入输出中的元素 id。

如上所述，TDNumElements() 是请求的线程数（"Auto" 模式下且 Attribute Class 选择 "Point" 时，每个点一个线程）。实际线程数很可能更高，因为它会向上取整到工作组大小，NVIDIA 硬件设为 32，AMD 硬件设为 64。if 条件可防止着色器写出已分配 SSBO 的边界，否则可能导致不可预测的结果和崩溃。

GLSL Advanced POP

GLSL Advanced POP 允许做 GLSL POP 能做的事，并有以下差异和附加功能：

  • 可在同一着色器中读写和创建所有类别的属性（point、primitive、vertex）
  • 可写入来自多个 POP 的属性（"Extra Outputs" 页）。修改的输出可用 GLSL Select POP 选择。
  • 可修改点和图元的数量（"Output" 页）
  • 可写入索引缓冲区
  • 额外的 "Per Primitive Batch" 着色器调度模式，会在第一个输入中存在的每个图元批次上运行一次着色器。

为提高处理和渲染效率，相同类型的所有图元（Triangles、Quads、Line Strips、Lines、Point Primitives）在索引缓冲区中分组在一起。处理多种图元类型时，每种图元类型调度一次着色器可能更有利，因为此时某些变量是常量，用户知道所有图元都是同一类型，无需额外的 if() 条件。

处理图元时，GLSL Advanced POP 允许用参数或属性设置每种类型的图元数量，但使用 Topology POP 合并多个 GLSL Advanced POP 的结果（通常每个属性类别一个着色器更有利）并设置拓扑信息也很方便。

示例着色器：

void main() {
	const uint id = TDIndex();
	if(id >= TDNumElements())
		return;
		
	oTDPoint_P[id] = TDInPoint_P(); // 等同于 TDInPoint_P(0, TDIndex());
}

基础着色器读取输入 P 属性并原样写入输出。注意额外的 "Point" 前缀用于区分属性类别，因为不同属性类别中可能存在同名属性。

以下代码片段展示如何遍历一个图元的所有点：

for (int i = 0; i < TDInputNumVertsPerPrim(); i++)
{
	uint vertId = TDInputPrimVertsStartIndex() + i;
	uint pointId = TDInputPointIndex(0, vertId);
}

当输出点数量改变时，不再创建对未更改输入点属性的引用，因为现有属性缓冲区中的点数与新的点数不匹配。现有和新点属性的手动更新留给用户完成。同样，当顶点或图元数量改变时，不再创建对未更改输入顶点和图元属性的引用。

GLSL Copy POP

GLSL Copy POP 允许在每个拷贝上运行自定义 GLSL 代码。不过所有拷贝都限制为具有相同拓扑，与 Copy POP 类似。与 Copy POP 类似，还提供一个 template 输入。没有其他输入，因此其他 POP 属性需使用 "POP Buffers" 页和 TDBuffer() 函数访问，与 GLSL TOP 和 MAT 类似，见下文。

与 Copy POP 的内部工作方式类似，会调度一个计算着色器更新点、一个更新顶点、一个更新图元。

默认情况下，只有点运行自定义着色器，而顶点和图元只是将输入属性复制到所有拷贝。

不过也可以为顶点和图元提供自定义着色器。

示例点着色器：

void main() {
	const uint id = TDIndex();
	if(id >= TDNumPoints())
		return;
		
	// TDInputNumPoints()：输入几何体上的点数
	// TDInputPointIndex()、TDInputIndex()：与输入当前点 id 匹配的点 id
	// TDCopyIndex()：复制编号
	
	// TDTemplate_Attrib() 函数用于采样模板输入的属性

	// P[id] = TDIn_P() + TDTemplate_P();
	// 等同于 P[id] = TDIn_P(TDInputPointIndex()) + TDTemplate_P(TDCopyIndex());

	P[id] =  TDIn_P() + TDCopyIndex() * vec3(0.5, 0, 0);
	
	// 更新已存在的点组（如果有）
	TDUpdatePointGroups();
}

每个输出点执行一个线程，即 TDIndex() 是输出点索引。TDInputPointIndex() 指与当前输出点匹配的输入点索引。TDIn_P() 不带属性时读取 TDInputPointIndex()，因为我们假定要从输入中匹配的原始点读取。TDCopyIndex() 是当前拷贝索引。TDTemplate_P() 在未提供参数时从模板输入的拷贝索引位置读取 P。TDUpdatePointGroups() 是一个辅助函数，用于更新输入上原有的任何点组：在每个拷贝中，输入里属于某组的点将属于同一组。
