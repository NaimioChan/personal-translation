OP Find DAT

摘要

OP Find DAT 从某个组件开始遍历组件层级，查看该组件内的所有节点，并输出一个表格，每个符合用户所选条件的节点占一行。例如，条件可以是所有 Ramp TOP，或所有名称以「wave」开头的节点，或所有 Clone 参数设为「master1」的节点，或所有带有名为「emitter」的标签的 Geometry 组件。

条件可以限定为只包含某些操作符族或某些操作符类型的节点。它可以按路径匹配、按某些参数包含某些值（常量和表达式都算）、按注释、按标签，或按某个 DAT 的内容包含某些字符串来过滤。

你也可以让该 DAT 只查看从指定组件向下若干层级的范围，例如 2 层，或不限层数。

条件可以区分大小写或不区分，但区分大小写的 On 或 Off 会作用于 OP Find DAT 中的所有条件。

此外，你还可以在附加的回调 DAT 中的回调里返回 True 或 False，用更专门的条件排除某些节点。

借助 Combine Filters 菜单（Any 或 All，默认为 All），你可以对模式匹配条件做「或」或「与」运算。

它还可以接收一个可选的 DAT，其中包含操作符列表（例如另一个 OP Find DAT），用于串联过滤器。

输出列

有多种列可供选择，包括 name、id、paths、type 和 tags。（id 是操作符的一个成员，是一个该节点唯一的整数，在 TouchDesigner 进程运行期间不会改变。）

你也可以在回调 DAT 中定义列名，并通过回调 DAT 中的另一个函数填充列单元格，从而输出自定义列。例如，你可以输出一个自定义列，内容为节点的 tx 参数值。

你可以控制 OP Find DAT 何时计算。通常，只要指定层级中的任何节点发生变化，它就会计算。通过 Active Cook 菜单参数，你还可以强制它每帧计算，或完全关闭计算。你也可以点击 Active Cook 上的 Pulse 参数强制计算一次，或用 node.cookpulse.pulse() python 调用实现相同效果。

OP Find DAT 可以不接收作为起始点的组件路径，而是接收一个输入 DAT，其中包含预先生成的起始节点路径列表，并把每一输入行的结果合并到输出中。要使用此功能，输入 DAT 的第一列应包含节点「id」，这可以通过另一个开启名为「ID」的列的 OP Find DAT 生成。

例如，假设你先列出所有作为面板的组件，然后按类型或 Clone 参数分成若干组。第一个 OP Find DAT 把庞大的层级预过滤为少量节点，后续的 OP Find DAT 则在更简单的集合上运行，从而省去大量检查和计算。

参数 - Component 页

Active Cook activecook - - 决定何时计算该 DAT。
  • Off off - 这会完全阻止该操作符计算。
  • Automatic auto - 仅在结果会变化时才计算/更新内容。
  • Always always - 反复持续计算该操作符，以捕捉可能被漏掉的更新情况。
  • Incremental incremental - 这会在每帧计算，但每次计算只添加一个结果，直到所有结果都添加完毕。此时计算停止。
Cook Pulse cookpulse - 手动强制 OP Find DAT 更新。
Component component - 搜索起始组件的路径。
Include Component includecomponent - 将搜索起始的组件本身也包含在搜索中。
Include Wire Hierarchy includewired - 连接到起始组件的任何组件都包含在搜索中。
Minimum Depth mindepth - 设置 OP Find DAT 递归搜索子组件的最小深度。
Limit Max Depth limitmaxdepth - 开启 Maximum Depth 参数，以限制对子组件的搜索。关闭此开关将搜索所有子网络。
Maximum Depth maxdepth - 设置 OP Find DAT 递归搜索子组件的最大深度。
Limit Max Operators limitmaxops - 限制搜索中遍历的操作符总数。
Maximum Operators maxops - 搜索所限制的操作符数量。

参数 - Families 页

该参数页决定搜索中包含哪些操作符族。

Object COMPs objects - 在搜索中包含 Object COMP，例如 Geo COMP。
Panel COMPs panels - 在搜索中包含 Panel COMP，例如 Container COMP。
Other COMPs other - 在搜索中包含其他类型的 COMP，例如 Base COMP。
TOPs tops - 在搜索中包含 DAT 族操作符。
CHOPs chops - 在搜索中包含 CHOP 族操作符。
SOPs sops - 在搜索中包含 SOP 族操作符。
MATs mats - 在搜索中包含 MAT 族操作符。
DATs dats - 在搜索中包含 DAT 族操作符。

参数 - Filters 页

Case Sensitive casesensitive - 在下面所有模式匹配中区分大小写。
Combine Filters combinefilters - - 按 'All'、'Any' 或 'Custom' 组合下面的过滤器以得到匹配。'Custom' 允许用 'or' 和 'and' 关键字指定过滤器的子选择。
  • All all - 所有过滤器都必须匹配，操作符才会被包含在搜索结果中。（AND）
  • Any any - 任一过滤条件得到满足，操作符就会被包含在搜索结果中。（OR）
  • Custom custom -
Custom Combine customcombine - 指定在搜索中组合哪些过滤器。
Name namefilter - 使用操作符的名称，例如 'wave1'、'wave2' 等。
Type typefilter - 使用 waveCHOP 和 panelexecuteDAT 之类的名称。查看 Type 列以了解语法。
Parent Shortcut parentshortcutfilter - 仅匹配包含此处指定的 Parent Shortcut 的操作符。
OP Shortcut opshortcutfilter - 仅匹配包含此处指定的 OP Shortcut 的操作符。
Path pathfilter - 指定操作符应位于的路径。
Parent Path (relative) parentfilter - 指定操作符应位于的相对父级路径。这是该 DAT 的 parentPath 列上的一个过滤选项，可通过打开该 DAT 的 Columns 页上的 Parent Path 参数来启用。
Exclude Path (relative) excludefilter - 指定应从搜索中排除的相对路径。
Wire Path wirepathfilter -
Comment commentfilter - 仅匹配包含此处指定注释字符串的操作符。
Tags tagsfilter - 仅匹配符合此处指定标签的操作符。多个标签可以用空格分隔的列表来搜索。
DAT Text textfilter - 仅包含内容中匹配指定字符串的操作符（前提是它们属于 DAT 族）。
Par Name parnamefilter - 仅匹配具有指定参数名称的操作符。参数的名称、值和表达式必须全部匹配，才会被包含。
Par Value parvaluefilter - 仅包含匹配指定参数值的操作符。参数的名称、值和表达式必须全部匹配，才会被包含。
Par Expression parexpressionfilter - 仅包含匹配指定参数表达式字符串的操作符。参数的名称、值和表达式必须全部匹配，才会被包含。
Par Non-Default Only parnondefaultonly - 仅匹配参数为非默认值的操作符。

Name namecol - 在结果表中包含操作符的名称。
Type typecol - 在结果表中包含操作符类型。例如 rampTOP。
Parent Shortcut parentshortcutcol - 在结果表中包含操作符的 Parent Shortcut。
OP Shortcut opshortcutcol - 在结果表中包含操作符的 OP Shortcut。
Path pathcol - 在结果表中包含操作符的路径。
Relative Path relpathcol - 在结果表中包含操作符相对于搜索根的路径。
Parent Path parentpath - 包含父级路径。
Wire Path wirepathcol - 在结果表中包含操作符的连线路径。
Depth depthcol - 包含一列，显示所找到操作符相对于根路径的深度。
Cook Times cooktimescol - 包含所找到操作符的计算耗时。
Tags tagscol - 包含操作符的标签。
General Properties genprop - 在结果表中包含操作符的名称、id、isCOMP、节点位置、节点大小和 dock id。
CPU Time cputime - 在结果表中包含操作符的 CPU 计算耗时。
GPU Time gputime - 在结果表中包含操作符的 GPU 计算耗时。
CPU Memory cpumem - 在结果表中包含操作符的 CPU 内存。
GPU Memory gpumem - 在结果表中包含操作符的 GPU 内存。
Children children - 在结果表中包含该操作符的子级。

参数 - Callbacks 页

Callbacks DAT callbacks - 包含各事件回调的 DAT 路径。用法参见 opfindDAT_Class。
Convert Bool to Int convertbool - 对于布尔逻辑值，值为 '1' 或 '0'。当此参数关闭时，值为 'True" 或 'False'。
Convert None to Empty convertnone - 对于 'None' 值，该值会被转换为 Empty。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。
