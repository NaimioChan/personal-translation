Cache POP

摘要

Cache POP 每帧在输入处接收 POP 数据，并在 GPU 内存中保留最近若干帧的数据（最多 Cache Size 帧）。它输出其中任一保留帧，由 Output Index 决定，作用类似于对输入的时间延迟。此外，Cache Select POPs 和 Cache Blend POPs 可以访问 Cache POP 所保留输入的任意组合，从而实现多帧混合。

例如，如果 Cache POP 的 Step Size 为 3，它会每隔 3 帧保存一帧，使 Cache POP 覆盖的时间变为三倍。这减少了长时间缓存所需的内存量。注意，GPU 内存中保存的数据未压缩。

关闭 Active 开关参数即可冻结 Cache POP 中保存的数据集。Reset 参数开启期间，可以清空缓存并保持为零帧（输入直接送到输出）；按 Reset 脉冲可以清空缓存并立即重新开始累积缓存。（连接到 Cache POP 的 Info CHOP 会显示缓存中的帧数。）

为 Cache Index 提供的值是 0 和负整数。-2 表示第三新的缓存数据。超出范围的索引会被钳制在 -(Cache Size-1) 到 0 之间（含两端）。

也可以指定两个通道来定义权重，一个用于权重，一个用于索引。

Cache POP 提供多种为缓存图像索引编号的方式。

当 .toe 或 .tox 文件重新启动时，缓存从清空状态开始 - 不会在文件中保存任何内容。

注意，掉帧时缓存中的数据可能比不掉帧时更旧。Trail POP 虽然功能不同，但处理掉帧更优雅：它会为缺失的帧填补数据，并为每个 timeslice 打上 Age 属性标记。Cache POP 没有内置这一功能。

另请参阅 Cache Select POP、Cache Blend POP、Trail POP、Cache TOP、Texture 3D TOP。

参数 - Cache 页

Active active - - 启用后，Cache POP 会捕获输入的 POP 帧。
  • Active active -
  • Active Pulse activepulse - 点击（脉冲）后仅在一帧内有效，并向缓存添加一个快照，同时丢弃最旧的快照。
Always Cook alwayscook - 强制该操作符每帧计算。
Cache Size cachesize - 缓存中最多保留的快照数。满后，最旧的快照会被最新的替换。
Step Size step - - 写入缓存的快照之间的时间步长。
  • Step Size step -
  • Step Size Unit stepunit - 步长可以用秒或帧表示。
Output Index outputindex - - 指定要输出的 POP 索引 - 0 为当前，负值越负越久远。
  • Output Index outputindex -
  • Output Index Unit outputindexunit - 索引以秒、帧（基于时间轴每秒帧数）或原始索引表示。
Interpolate Frames interp - 开启时，如果每个快照的点数相同，所选索引可以在缓存帧之间插值。否则使用最近的缓存帧。
Reset reset - - 重置缓存并保留一个快照。
  • Reset reset -
  • Reset resetpulse - 将缓存重置为 0 个快照。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Info CHOP 通道

Cache POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
