▸什么是 Point Operator

POP（Point Operators）是 TouchDesigner 的一个新 Operator Family，用于创建和修改 3D 几何数据，运行在加速的 GPU 显卡或芯片上。

“POPs” 中的 “P” 指 “点”，但巧合的是它也涵盖其他以 P 开头的东西——图元、多边形、粒子系统、点云，以及数据可视化中任何形式的数据点。

POP 的数据都从 points with attributes 开始，而从点出发，我们可以处理粒子系统、点云、多边形、线、样条曲线，以及任何 3D 几何形状和数据点形式。

POP 由 Render TOP 渲染，也可以传给 DMX 灯光系统、LED 阵列、激光器或其他外部系统等设备。

最简单地说，POP 由点列表、顶点列表和图元列表组成。

点

每个 POP 都包含一个点列表，它由一组 Point Attribute 组成。最常见的属性是 Position（P），即点在 3D 空间中的 XYZ 位置。POP 还可能具有其他属性，如 Color（Color）（始终带红、绿、蓝和 alpha 分量）和 Normal（N），后者是一个方向矢量（含 3 个分量）。点还可以有额外的用户自定义属性，或由某些 POP 操作符自动生成的属性。

点是多边形、线、线带、样条曲线、点云、粒子系统、任何 3D 几何形状和任何形式数据点的构成单元。

图元

每个 POP 都包含一组 “图元”（primitive），同样带有一组 Primitive Attribute。图元的类型有：

  • Point（1 个点）
  • Line（2 个点）
  • Line Strip（1 个或多个点）
  • Triangle（3 个点）
  • Quad（4 个点）

图元可以有属性，例如 Color，它应用于整个图元。

顶点

每个图元都有一个顶点列表。顶点是点列表中的索引。因此一个 quad 图元有 4 个顶点，即点列表中 4 个点的索引集合。如果一个 quad 图元的顶点索引为 6、7、8、9，那么它指的是第 7、8、9 和第 10 个点。顶点也可以有属性。

POP 历史

POPs are a replacement and re-think of TouchDesigner's historically first operator family, SOPs (1989), with many new features and benefits. Like SOPs, POPs are a procedural family of operators that create and affect points, and primitives like triangles, quads and lines. POPs implements point clouds and particles, and it imports FBX, obj , Alembic files and more.

请参阅本页末尾标题为 “SOPs vs POPs” 的一节，了解两者的更深入比较。

POP 通过 Geometry Component 渲染

POP 被放入 Geometry COMP 中，以便用 Render TOP 渲染。材质（MAT）被应用到 Geometry COMP（与 SOP 一样），并使用 POP 属性。这些 Geometry COMP 会被传递给 Render TOP。

在 GPU 上运行的 3D 操作符为我们带来：

- 由于高度 GPU 并行而带来的速度。- 更少的内存：POP 在内存上经过高度优化，因为任何 POP 中只会创建发生变化的属性。

POP 实现了 CHOP 的许多功能

不必把 POP 转换为 CHOP（这会造成 GPU 到 CPU 再到 GPU 的复制）就能对 3D 数据和属性进行数学/逻辑/混合操作。把数据和过程都保持在 GPU 上，速度更快，内存占用更少。

生成器与过滤器操作符

与其他 TouchDesigner 操作符族一样，POP 包括 “generator” 操作符（创建新形状，或从文件或其他系统导入形状），以及 “filter” 操作符（修改来自其他 POP 的数据，并可能从更简单的输入生成复杂的形状和数据）。

▸POP 的一些功能与概念
  • Creating New Attributes - 有些 POP 允许只需在 Output Scope 参数中命名一个新属性，就能轻松创建新属性。TouchDesigner 会自动选择属性的大小和类型。（在 Math POP、Math Mix POP、Limit POP 以及许多其他 POP 中）
  • Math with no Coding - 若干 POP，如 Transform POP、Math POP、Math Mix POP 和 Normalize POP，无需编写代码即可提供基本操作能力。总体而言，POP 消除了大量编码需求。

设置属性类型和大小 - 在你看到 >>> 的地方，可以指定属性类型和大小。

  • Attributes Feeding Rendering - POP 与渲染结合得更好，因为属性更丰富、更可控。比如发光线条是几何与着色相结合。某些情况下，隐藏的 POP 会生成用于渲染发光或线条的多边形。
  • Compute Shaders 是 POP 内的编程语言。你可以使用 GLSL POP、GLSL Advanced POP 编写自定义 GPU 着色器，它们有大量辅助函数和预置示例。You can also write custom C++ POP operators 则让你在 CPU 侧编写代码。
  • Multi-Component Attributes - 一个属性可以是每个点一个数值，也可以有 2、3 或 4 个分量，例如 float4 Color：它有多个 “分量” Color(0)、Color(1)、Color(2) 和 Color(3)。此外，“数组” 例如是在一个属性中存放多个 float3，你可以在 Attribute POP 中创建。
  • Attribute Component Swizzling - Color(0)、Color(1)、Color(2) 和 Color(3) 可写作 Color.rgba。P(1) 可写作 P.y。
  • Single-Component menus - 在需要指定属性的单个分量时（例如用于索引），许多 POP 都使用一个单分量菜单，让你从所有 POP 属性的分量中选择一个。
  • Multi-columns of Parameters（Parameter Size 参数）：大多数 POP 提供一组适用于矢量所有分量的参数。在某些 POP 上你会看到 “Parameter Size”，它会给出 1、2、3 或 4 组参数，从而为每个分量提供一组参数。例如在 ReRange POP 上，这使你能够为位置的 X、Y 和 Z 分量分别应用不同的重映射（在 CHOP 中这需要三个 CHOP）。
  • Memory Reduction via References - 每个 POP 只为它正在修改或新建的属性分配内存。例如，如果它不修改 Position，就会使用流入该 POP 的 POP 的 Position。这节省了大量内存。提示：POP 查看器的左下角会显示该 POP 中创建/修改了哪些属性，其余属性都从上游 POP 原样传递（称为 “POP attribute references”）。

另外，节点的中键点击信息弹窗会显示属性名称，如果名称后面跟着 (r)，说明它是对另一个节点内存的引用。

Line Strips 是由多点构成的 primitives（如三角形、quad 等），可以通过大多数生成器 POP、Line POP 或 Primitive POP 创建。

    • Line Strip 也可以由任何具有 LineBreak 属性的点列表创建；在 Line Break POP 中，它按顺序接受该点列表，并根据 LineBreak 属性中的 0 或 1，或 LineStripIndex 属性中的整数，把它分割成 line strip 图元。
  • High Precision - 用户自定义属性可以是单精度或双精度浮点数，也可以是 32 位或 64 位整数。
  • GLSL POPs - 有些 POP 允许你用 GLSL 风格的计算着色器编写代码。
  • Weights - 若干 POP 会为每个点生成 0-1 的权重值，其他 POP 则用这些权重在两种状态之间混合，例如 Transform POP 可以部分地变换每个点。
  • Dimensions - Dimension - POP 中点列表的更高层次组织方式。
  • Parameters driven per-point by Attributes - Transform POP 和 Noise POP 有一些由它们的 Map page 驱动的参数。
  • Multi-POP Inputs with Sequential Blocks - 允许无限输入的那些 POP，如 Merge、Switch、Math Mix、Blend、Attribute Combine 等，共享一种新的灵活输入指定方式。你可以 (1) 像以前一样逐个接线，或者 (2) 在参数中用模式匹配指定多输入，如 “box*”。还可以 (3) 为每个输入添加一个顺序块，每个块都有一个 POP 路径参数。后者最灵活，因为每个顺序块都可以有额外参数，例如对于 Attribute Combine POP，指定要从每个输入中提取哪些属性；或者对于 Merge POP，指定要为每个输入合并哪些组。对于每个接线输入，它会自动创建一个顺序块。（你可以在每个顺序块中使用模式匹配。）如有需要，可以混合接线和非接线输入。
  • 带 Sort POP 的 Sorting 使用现代快速排序算法实现。排序可以基于任意属性的任意分量。
  • Over-Allocation Caveat of GPUs：如果某个 POP 的点、图元或顶点数在开始计算时无法确定，它就需要分配这些实体的最大数量，从而有一部分内存用不上。所以它们有时不得不超额分配。有些 POP 有参数，可以让你设置该 POP 中预期的最大数量。
  • Class Conversions - 要在 “类” Point Attribute 与 Vertex Attribute 之间、以及 Vertex Attribute 与 Primitive Attribute 之间转换，请使用 Attribute Convert POP。使用 Convert POP 在不同图元类型之间转换。
  • GPU-resident computing - 你可以把计算保持在 GPU 上，不因与 CPU 之间收发数据而破坏并行性。由于 TOP 也基于 GPU，它们之间的交互也得到优化。除绝对需要 CPU 时（例如加载文件）外，POP 全部在 GPU 上运行。
  • Line Material 底层由一个 POP 实现，并会转换为三角形集合。线条的更多方面可以通过属性按点控制。Line MAT 的更多特性通过 Line MAT 的 Attributes 页用 POP 属性控制。
▸图元
图元类型

POP 中的图元类型有：

  • Point 图元 - 在点列表中有 1 个索引
  • Line 图元 - 点列表中的两个点
  • Line Strip 图元 - 点列表中任意数量的点
  • Triangle 图元 - 三个点
  • Quad - 图元 - 四个点

提示：POP to DAT 可以把全部内容显示出来，只需把它的 Extract 菜单设为 Primitives、Points 或 Vertices

Line Strip 的开放或闭合

Line strip 可以是开放的或闭合的。在 POP 中，如果 line strip 最后一个顶点的点索引与第一个顶点的点索引相同，它就是闭合的。

没有图元的点（以及为什么单有点不渲染）

你可以有一组没有任何图元的点。（用任何 Generator POP，或使用 Primitive POP 都可以得到）

Render Instancing 只看点列表。Copy SOP 模板不在乎。许多 POP 也不在乎——它们遍历点列表中的点，修改某些东西，仅此而已。

但在 Render TOP 中，除非点带有 point 图元，否则无法渲染点本身。

生成器（Circle、Torus、Tube、Point Generator、Box、Rectangle 和 Sphere）（在适用时，Connectivity 设为 None）都能创建带对应图元的点。

Primitive POP（如 Add SOP）可以剥离图元，使你没有任何图元，除非你在 Primitives 标签页中创建它们。

POP 中图元的顺序 - 图元会按这个特定顺序重新分组：先是所有 Triangle，然后 Quad、Line Strip、Line 和 Point。
▸属性
标准保留属性

这些是固定用途的内置属性：每个点都有一个位置，称为 P 属性（实际上可以有 POP 没有 P 属性）。P 有 3 个分量，包括用于 X、Y 和 Z 维度的 P(0)、P(1) 和 P(2)。P 是 “float3” 属性类型（“矢量属性”）。

（注意，任何单个浮点数的属性，如 PointScale，称为标量属性。）

每个点还可以有其他可选属性，通过各种 POP 添加。N 用于法线，是 3 个浮点数的矢量属性（float3）。Color 是点颜色，始终有 4 个分量，分别为红、绿、蓝和 alpha。你常会看到用 Color(0) Color(1) Color(2) 只改变 RGB（或其 swizzle 形式 Color.rgb）。Tex 是点的纹理坐标，始终是 3 个浮点数的矢量属性，其中包含 3D 纹理的第三维。

你可以在 POP 中许多通用位置创建和修改颜色与纹理属性，比如在 Normalize POP、Math POP、Math Mix POP、Pattern POP、Noise POP、Random POP、Projection POP、Lookup*、Line POP 等中。

常用属性

TouchDesigner 中还常用其他属性名，你应养成使用它们的习惯，除非有理由不这样做。这些包括 Tan（切线）、Pointscale、LineWidth、Dir、Dist、Vel、Disp, Speed、Accel、Weight、Curv（曲率）、Index（通用索引）Nebr（相邻索引）、PartForce（粒子）

Particle POP 属性带有 Part 前缀。Ray POP 属性带有 Ray 前缀。

只有 1 个分量的属性——如 Weight 或 PointScale——称为 “标量属性”。

点属性、顶点属性或图元属性

点有属性，但图元和顶点也可以有属性。

Why would you put attributes on vertices instead of points？大多数情况下点属性是理想且足够的。如果 Weight 只依赖于位置 P，点属性就可以。但如果一个点被两个或多个图元的两个或多个顶点共用，你可能想为每个顶点设置不同的颜色或纹理坐标。

在哪里创建属性

你可以用 Attribute POP 创建属性，但也可以在许多 POP 中即时创建属性：在原本要给出输出属性名的位置指定一个新名称。例如：Math POP。

属性数据类型

如果是浮点数，属性可以是任意名称、任意大小。一个属性可以是

  • float（32 位）
  • double（64 位双精度浮点数）
  • integer（32 位）
  • uint（无符号 32 位整数）

带计数器的 POP，如 Ray、Line Metrics 或 Neighbor POP，会创建无符号整数属性。

属性大小可以是：

  • 标量属性 1 个分量
  • 2 个以上分量的矢量属性（例如 float2、float3 或 float4）
  • 矩阵属性 - 从 2x2 直到 4x4 的矩阵

属性限定符

有些内置或自定义属性的定义和控制更严格。一个 float4 是 4 个浮点数，但带有 “Color” 限定符的 float4 专门表示颜色。

当前的限定符有 Color、Direction 和 Quaternion。某些操作符期望接收带特定限定符的属性。在 POP 节点的中键点击信息弹窗中，属性名称旁边会显示其限定符。

你可以在 Attribute POP 中设置属性的限定符。

数组属性

另外，你可以有 Array Attributes，例如一个 5 个浮点元素的数组，表示为 MyArray[0] 到 MyArray[4]。或者一个 5 个 float4 的数组，如 ColorScheme[5]，其中某个分量可以是 ColorScheme[5](2)。

属性名称

属性名称只能包含大写和小写字母 A-Z 以及数字 0-9。属性名称将（也应）始终以字母开头。Derivative 定义的标准和常用属性以首字母大写命名，如 Weight。用户自定义属性可以以小写或大写开头，但为避免将来的冲突、并更容易被识别为用户自定义，建议以小写开头。

属性列表

你可以获得所有点属性的列表：在 python 中用 op('pop1').pointAttributes()，并在 () 中使用模式匹配。或者查看中键点击的 Info 弹窗。此外，每个 POP 节点查看器的左下角会显示添加或更改了哪些属性（见下文）。请查看 Python Members and Functions 一节。

没有 P 属性的 POP

可以在没有 P 属性的情况下创建和操作 POP——一个点可以表示任何数据，不一定是有位置的东西。或者在一条 POP 链上，P 无关紧要。例如当你想要在 3D 中显示一个没有 P 的点时，没有 P 属性的点会被赋予一个 (0, 0, 0) 的 P 值。例如，你可以用 Attribute Combine POP 剥离 P。
▸创建新的自定义属性
  • 可以用 Attribute POP 在点、顶点或图元上创建任何新属性，并用常量值初始化。
  • 但许多 POP 如 Math POP 或 Limit POP 接受一个属性输入，你可以创建任意新属性来存放结果。默认情况下，输出属性与所选的输入属性类型相同。但在你输出到某个属性的地方，可以指定新的属性名称和类型。
  • 如果 Output Attribute 名称在 italics 中，表示它会自动填充该名称的属性。
  • 像 Field POP 或 Line Metrics POP 这样的 POP 会生成带建议默认名称的新属性。
  • 还有许多专用 POP 提供更复杂的设置，如 Noise 和 Pattern。
  • 用于指定新输出属性的参数组 - 点击 >>> 图标。
    • 五个参数帮助你：(1) 把值放到同一属性的输入上，(2) 放到 POP 中已存在的另一个属性上，(3) 放到新属性上（保留名称属性和全新属性都算）。
  • 多分量参数 - 一个 float3 属性被认为有三个 “分量”，是一个矢量属性。POP 参数根据其设置，会把传入属性的 1、2、3 或 4 个分量传到输出阶段。如果是 1 个分量，它会被传递到输出属性的所有分量。否则，输出的分量数（2、3 或 4）必须与输入的分量数一致。
  • 如果输出是新属性，且并非所有分量都被填充，则使用默认值。
  • 自定义属性可以是 64 位浮点数或 32 位整数、整数和无符号整数，并可以按此方式操作。（内置属性为 32 位）
  • 自动命名 - 在 Math、Math Mix 和 Math Combine 等 POP 中，你可能会看到以斜体显示的输出属性名称，这表示它是默认将创建或修改的属性名称，因此你不必自己输入名称。
  • 输出属性是标准化的 - 输出属性块、属性选择菜单或属性分量选择，必须以字母字符开头。
  • 标准错误/警告检查 - 在某些 POP 中合并输入时，会有一个 Error/Warning 菜单让你选择要做什么。
▸选择属性的分量与 swizzling

对于由 2 个或更多数字组成的属性（“矢量” 属性），如 Position（P）或 Color，每个数字称为该属性的一个 “分量”。（是的，components 在 TouchDesigner 中还有别的含义，这里指的是 “属性的分量”。）

在选择要操作的属性或要输出的属性时，你可以选择属性的部分分量。属性 Color 等同于 Color(0) Color(1) Color(2) and Color(3) 合在一起，而你可以选择 Color(0) Color(2) 只获取并使用红、蓝分量。

如果输入属性的范围是 P(1) P(0)，它并不等同于 P(0) P(1)。因为 P(0) 和 P(1) 是 X 和 Y 值以及位置，P(1) P(0) 给出两个值，先是 Y 值再是 X。如果你随后把结果（比如在 Math CHOP 中）输出到 P(0) P(1)，你就交换了 X 和 Y 分量。这是混合和重排属性分量的强大机制。

把输入分量与输出分量对应，以及 Parameter Size 1 到 4：请见 Overview.toe /components_of_attributes。

Swizzling 与属性的分量

当你需要指定属性的一个或多个分量时，还有几种更紧凑的写法。属性现在可以使用 swizzling 形式 -

  • P.xy 等同于 P(0) P(1)，P.z 是 P(2)
  • Color.rgb 等同于 Color(0) Color(1) Color(2)，Color.a 是 alpha Color(3)。
  • MyAttr.i0123 是任意属性的通用索引形式（“.i” 表示索引）MyAttr(0) MyAttr(1) MyAttr(2) MyAttr(3)。
  • 而对于任意属性，你可以在 () 中用逗号分隔数字：

MyAttr(0, 1, 2) 或 MyAttr(0,1,2) 等同于 MyAttr(0) MyAttr(1) MyAttr(2)

你也可以重排，例如 x 和 y，使用 P.yxz 或 P(1,0,2)

（专业提示：float4 这样的属性，如 “homogenous” 位置，可以把第 4 个分量称为 .w。它们用于 4x4 矩阵乘法。）

（见 Overview.toe 中 POPExamples 里的分量 /swizzling）

▸组

组（点、顶点或图元的组）在内部用一个位标记表示，在 32 位 GPU 字中每个 POP 可以有 32 个组。组用 Group POP 创建。Group POP 还可以把组转换为属性，限制更少但占用更多内存。

许多操作符可以只影响指定组中的点、顶点或图元，而不影响其他点、顶点或图元。例如用于影响某些点的 Transform POP，或用于把其他 OP 的部分提取到其输出中的 Merge POP，都使用组。

其他 POP 可能会自动创建组。（Extrude POP、Copy POP）

另请参阅 Dimension - 它是在结构化点列表上的一种分组形式，无需手动创建组。（见 Copy POP）
▸POP 的一些通用功能

每个 POP 可能具有这些功能的某种组合：

输入选择

对于多个输入

  • 每个输入都会创建一个顺序块
  • 输入也可以是对其他 POP 的引用
  • 你可以用模式匹配在一个块中处理多个 POP
  • 对于每个输入，你可以选择要操作哪些属性或组（如 Attribute Combine、Math Mix、Merge POP）

范围

  • 选择属性的哪种类型（“类”）：作用于 Point、Vertex 或 Group 属性（菜单）
  • 用 Scope 或 Group 决定是否生效
  • 根据属性分量值决定影响
  • 可以用权重决定影响程度（以属性的任意分量作为权重）

选择属性

  • 从输入 POP 中选择你要使用的任意属性，通常通过 Input Attribute Scope 进行。
  • 选择属性的任意分量。P(0) P(1) 只给出 X 和 Y
  • 重排分量 - 输入中的 P(2) P(0) P(1) 会把 Z Y X 传给下一阶段。
  • 选择任意属性作为 Reference（如 Noise 中）

操作

  • （修改一个 1 到 4 个分量的数组）
  • 对于多分量属性（float2、float3 等），可以一组参数用于所有分量，也可以为每个分量各用一组参数。（使用 Parameter Size 参数）

一些数学

  • 基本算术和简单函数，如 Math 中、ReRange POP、Limit POP
  • 没有 Function POP - 更完整的数学函数请见 Math POP 或 Math Mix POP 中的菜单。
  • 生成函数，如 Pattern POP 中。

拓扑

后处理

  • 重新映射数值范围

▸粒子

请参阅 Particle POP，获取 Particle POP 的当前说明。

以下是把点当作粒子的一些其他通用信息。

什么是粒子？- 粒子就是一个 POP 点——最少只需要一个表示位置的 P 属性。但可以用属性来扩展它……速度、方向、速率、年龄、质量、力，甚至每点一个完整的 3x3 或 4x4 变换。

Particle POP 可选地添加这些属性，你可以在粒子反馈循环中使用它们。

注意，点不会被渲染成圆点。要使点可见，你需要创建 Point 图元。大多数生成器在 Connectivity 设为 Point Primitives 时会这样做。

可以用 Trail POP 创建点的时间历史，它会为每个点创建一条 line strip，并使用 id 属性表示粒子。（关于 /Trail 见 Overview.toe 示例）因此粒子可以可视化为多点 line strip。

另一种方式是在 Geometry COMP 中通过实例化对每个点渲染几何，而不创建新数据（这是经典的 SOP 方法）。

表示粒子的另一种方式是使用任何几何，就像用 Copy POP 创建的那样。这会在 POP 中创建新几何，可以在渲染前进一步操作/做动画。

不过使用 Copy GLSL POP，你可以在每个点上运行计算着色器代码，根据点的属性扭曲几何，从而可以随时生成，比方说，鸟群。（示例在 Examples/ 文件夹中。）

在每个点上进一步渲染内容，属于特殊渲染着色器在每点实例化的表面上渲染的范畴，如 point sprite 或 Line MAT。

粒子运动通过在时间上“积分”完成（这里的积分指力被转换为速度，速度在下一帧被转换为位置）。所以除了 Particle POP，还可以用一个 Feedback POP 来实现，其中涉及多个 POP 的循环。Roy & Tim Gerritsen 和 Peter Sistrom 的组件示例就是例证。

另一种方式是在一个 GLSL 操作符中完成整个模拟。目前 POP 中还没有多少示例代码能帮助做到这一点。

力 - 可以表示为一个 POP，通过创建或累加 POP 的 float3 PartForce 属性，用参数指定力，或使用 Force POP 累加该属性。最终力必须被加到粒子上，并转换为新的速度和位置。（待澄清：）另一种方式是一组点或图元，每个都通过其属性定义力属性。由力积分器（Particle POP）来解释这些，并把力和速度转换为下一位置。可以用带自定义参数的常规 POP 和操作符来构建这些。

▸点云

POP 中的点云具有与 TOP 中相同的功能（如果你熟悉那套工作流程的话）。

任何移除了连接关系（三角形、quad、线、linestrip）的 POP 都可以视为点云。

点云有两种形式：

  • 一组没有图元的点。
  • 一组点，带一组 “Point Primitive”，其中每个 point 图元是点列表中某个点的索引号。只有这些才能直接在渲染器中渲染。

你可以用 Point File In POP 或 File In POP 读入包含点云的文件。也可以用 Point Generator POP 生成点云。

如何写出点云文件：File Out POP

为什么在 POP 中做点云比在 TOP 中更好：

  • 不必考虑把 XYZ 位置值与 RGB 颜色通道对应起来。
  • 不必每 4 个分成一组。
  • 不需要像方形纹理那样需要 Active 通道。
  • 每个点可有无限属性。
  • 更容易收缩为子集（通过 POP 中的组，或通过 Delete POP）
  • POP 创建的组：保留的特殊组名（以 _ 开头？）
  • SOP 和点云不再分离——全都集成在 POP 中。
  • 它们只是点，与粒子是同一类东西。
在 Examples/GaussianSpats 文件夹中有一个 GaussianSplats 示例。
▸线与曲线

没有 curve 图元，但 line strip 可以包含曲线属性，和/或通过 Line POP、Line Divide POP、Line Smooth POP 和 Line Resample POP 进行线性或样条细分、平滑和重采样（这些都会细分任何 Line Strip）。

Line POP 直接在 Line POP 中细分曲线，或输出带额外属性的控制点来定义曲线形状：Weight、Tension、Interpolation Type、Bezier 入和出切线、切线连续性（3 种情况）。这些属性无论在何处生成，都可以被 Line Divide POP 使用。某些 3D 曲线可以在 Alembic In POP 等中读入 POP。

Line Smooth POP 还可以添加点和平滑线条。
▸只读内置属性

只读内置属性是方便的内部生成属性，可在 POP 参数中指定属性时使用。它们包括诸如点的整数索引号、或点在 0 到 1 之间归一化的索引这类数字，这些原本很难获得（你可以用一个 Pattern POP 和 Normalize POP 得到）。

在哪里找到只读属性：它们出现在属性名菜单的次级菜单中，例如你在 Math、Math Mix 和 Lookup POP 中看到的菜单。把鼠标悬停在属性菜单底部的展开箭头上即可选择内置属性。

它们还包括基本常量，如 pi（3.14158）。

它们最常用于 Math 和 Math Mix POP、Lookup Channel POP、Lookup Texture POP、Lookup Attribute POP，以及 Delete POP、Group POP 等中。

所有只读内置属性名称都以 _ 开头。它们都是保留名称。有些内置属性是按点、按图元或按顶点生成的，取决于你正在修改的属性类（点、顶点、图元）。

内置只读属性的行为与普通属性一样，但它们不会被输出或传给下一个 POP。

内置只读属性列表

部分列表：

  • _PointI - 整数点索引
  • _PointU（点索引归一化到 0 到 1）（第一个点为 0，最后一个点为 1）
  • _PointCy（点索引按周期归一化，从 0 到 (N-1)/N）（所以当 _PointCy 为 1 时，它是点列表中的第一个点。
  • _PrimI - 图元索引
  • _PrimU（图元索引归一化到 0 到 1）
  • _PrimCy（图元索引按周期归一化……）
  • _VertI - 处理顶点时的当前顶点编号。
  • _VertU - （顶点索引归一化到 0 到 1）
  • _VertCy - （顶点索引按周期归一化……）
  • _DimI[] - 每个点在其多维数组中都有一个位置——点所在的列/行/切片等。例如，_DimI[1] 会是点在 3D 网格中的行号。
  • _StepSeconds - 自上次网络计算以来的秒数步长（即“Time Slice”）
  • _StepFrames - 以帧为单位的步长
  • _MaxInt 和 _MaxUInt 以及 _NoNeighbor 这些是特殊数值，可在表达式中与属性值比较。
  • _ArrayI、_ArrayU、_ArrayCy - 用于遍历 Array Attribute 中的每个元素。

▸“index” 与 “id”
index

在 POP 中，“index” 是不变的，并不是属性。你会在 POP to DAT 的点列表、图元列表以及每个图元的顶点列表中看到 index。对于这些列表，Index 从 0 开始，以 1 为步长递增。

你不能写入 “index”。“Index” 也以内置属性 _PointI、_PointU 和 _PointCy 的形式出现。图元的顶点索引、POP 的图元索引也是如此，它们是不变的，不是属性。

所有 Lookup POP 也都通过内置属性以同样方式引用/使用 Index。

就像文本文件中的行号，它们标明信息相对于起点的位置。

id

“id”，例如粒子的 PartId，通常用于实体的唯一编号，它在实体存续期间一直附着于该实体，但可能以任意顺序出现，而且某个值的 id 可能不存在，即 id==7 可能在点列表中不存在。Particle POP 会在点上生成自己的 id。在构建类似的系统时，把 id 用在属性名中。
▸纹理映射

我们在 POP 中用于纹理坐标的常用属性是 Tex（以前为 uvw），它始终是 float3 矢量属性类型，其中第 3 个值在适用时用于 3D 纹理，否则不使用（设为 0）。但在把它赋给材质时（通过参数中的 >>> 图标），你可以使用任意属性名。有些材质使用多组纹理坐标，你可以随意命名，如 TexA、TexB 等……

Tex 属性可以在所有生成器 POP 上创建，也可以用 Texture Map POP 创建/调整，还能在许多提供更多控制的其他 POP 中创建，如 Normalize POP、Math、Math Mix、Projection、Noise、Pattern、Transform、Lookup* 等。

纹理坐标创建在点上或图元的顶点上，所以你必须注意它们在哪里。当存在类似球体或圆环的纹理环绕时，它们会放在顶点上，但在其他情况下（如网格）放在点上。
▸维度

Dimension 是 POP 中一个强大的概念，为点列表中的点提供某种组织方式。详见 Dimension 的 wiki 页面。摘要：

POP 的点列表内部可能有一种隐含结构。例如，Grid POP 是一个隐式按列和行排列的点列表，如果它们以三角形、quad 或 point 图元连接，这种结构可能并不明确。Grid POP 默认有两个维度（行和列），增加切片数量后有三个。当你把一个 POP 传给另一个 POP 时，你可能希望保留已知的结构信息。

Dimension 是描述 POP 中点列表结构的元数据，会在 POP 之间传递。

▸CPU/GPU 上的点数与拓扑信息、内存管理

对于某些 POP 操作：

  • 结果点数只在 GPU 上已知。结果 POP 在信息弹窗中会显示 “Point Count Info on GPU” 而不是 “Point Count Info on CPU”（例如：Facet POP 的 Cusp 和 Consolidate 操作……）
  • 结果顶点数和图元数（拓扑信息）只在 GPU 上已知。结果 POP 在信息弹窗中会显示 “Topology Info on GPU” 而不是 “Topology Info on CPU”（例如 Convert POP：打开或闭合 line strip）
  • 点数与拓扑信息都只在 GPU 上已知。这种情况下，结果 POP 在信息弹窗中会显示 “Point Count Info on GPU” 和 “Topology Info on GPU”（例如 Delete POP）

对于这些 POP 的点数和/或拓扑，分配的内存是该 POP 可能使用的最大内存。

从 GPU 下载这些 POP 的实际点数与拓扑信息（图元数和顶点数）会导致停顿。

对于下游 POP 的计算着色器，点数量信息与拓扑信息通过缓冲区传递，以避免停顿和不必要的工作：这称为计算着色器的间接调度 - 不过它比常规的计算着色器调度要稍微昂贵一些。

中键点击的信息弹窗会执行下载，并显示已使用与已分配的量。

有些操作符（POP to DAT，即 GPU POP 上的 copy topology back to CPU）以及 Python 函数支持「下一帧」异步下载，可避免停顿，但会引入 1 帧延迟。Copy topology back to CPU 会把该 POP 变回普通 POP，只在后续环节重新分配必要的内存。

Topology POP 允许你为 GPU 上带信息的 POP 手动分配内存，因此可以在不停顿的情况下回收部分未使用的内存。

Feedback POP 有一个开关，可将分配的内存限制为输入内存的倍数，以防在反馈循环内创建几何时内存占用暴涨。（已被 Topology POP 的功能取代）

对于集成 GPU，CPU 与 GPU 共享内存，因此从 GPU 下载信息不会造成停顿（尚待实现自动化）

另请参阅 POP Topology。

间接与直接 POP 信息

某些 POP 上的「Copy Topology Info Back to CPU」开关：

对于若干 POP 与操作（包括 Proximity POP），结果的点/图元/顶点数量只有在 GPU 上才知道。

在这种情况下，结果就是我们所说的「间接 POP」，因为其后的 POP 会执行计算着色器的间接调度，从 GPU 缓冲区获取拓扑。

这也意味着，对这些 POP 会按可能产生的点/图元/顶点最大数量来分配 GPU 内存。

而其后的 POP 会用这个最大数量来分配内存。

因为要知道实际的点/图元/顶点数量，就意味着从 GPU 下载数据，而这会造成停顿。

所以这个开关的作用就是：下载拓扑信息，并把该 POP 变回「直接 POP」。

它应该放在单独的 POP 中，我们未来可能会这样做。
▸POP 与 SOP

如果你已经在使用 SOP，这部分会很有用。下表列出了可替代某些 SOP 的 POP。

  • POP 在 GPU 上以高度并行的计算着色器运行。SOP 在 CPU 上运行。
  • POP 提供比 SOP 更好、更现代的工作流程：它结合了 SOP、CHOP 和 TOP 的关键特性。
  • 所有与点云相关的 TOP 都在 POP 中实现，而且更多，不再受限于映射到 4 通道图像格式。
    • 你可以从 TOP（TOP to POP）、Point File In POP 中获取点云，POP 中也有原生的点云生成器。
  • 驻留在 TOP 中的 particlesGPU 已在 POP 中重新实现。粒子系统通过 Feedback POP 和通用数据操作来实现。
  • POP 对属性的创建与操作更强大，并且可以控制属性的数据类型，包括有符号/无符号整数和双精度。
  • 「属性数组」是新增功能 - 例如，它可以是一个包含 12 个 float3 向量的数组。
  • 相比简陋且缓慢的 Point SOP，在 POP 中可以用 Math Mix POP 进行大量原始数学运算。
  • SOP 可以有多边形，边数不限，并会渲染为填充的多边形表面。POP 只用三角形和四边形来表示表面。POP 的 Line Strip 可以闭合，但不会渲染为闭合表面。
  • SOP 中的开放多边形类似 POP 中的「line strip」，但 line strip 可以闭合，不过这并不意味着 line strip 构成表面。闭合的 line strip 只是 3D 空间中的一条环绕线。
  • POP 并不直接沿用 SOP 的做法。例如，Normal POP 会创建表面法线与切线，而在 SOP 中这由 Facet SOP 完成。
  • 你可以在同一个 Render TOP 中渲染 SOP 和 POP。
  • 你可以右键点击 POP 并选择一个 Geometry COMP，以创建 POP-in-a-Geo。
  • 几何实例化的做法与 SOP/CHOP/DAT 相同，POP 属性可以用在 Instancing 页上。
  • POP 实现了样条曲线的功能（但以样条细分的 Line Strip 形式）：例如在 Line Divide POP 中的 Bezier、BSpline 和 Cardinal 样条。

POP 目前不实现以下内容：

  • 表面布尔运算
  • NURBS
  • 图元类型「Mesh」。SOP 中的网格是定义了行/列的点排布。在 POP 中替代它的是更强大的点排布概念，称为 Dimensions。

▸POP 中的新结构技术

这里汇总了你在 POP 中会看到、但在 TouchDesigner 其他部分可能（还）不会出现的东西。按由浅入深的顺序排列……

1. 多输入 POP 的输入管理，使用顺序参数块，你可以在 Math Mix POP 和 Blend POP 等操作符中看到。

    • 每个输入一个块。
    • 每个输入在顺序参数块中都有自己的一组参数。
    • 每个输入可以是一根连线，也可以通过参数引用。

2.「可调整大小的参数」 - Parameter Size 让你可以为属性的每个分量使用单独的参数。设为 3 就会得到 X、Y、Z 三列参数。

3. 你可以开启选项来改变顺序参数块中包含哪些参数。Line POP 和 Create POP 就有这个功能。

4. 参数由用户定义的顺序参数块（不是自定义参数），见于 Point POP、Line POP、Primitive POP、Curve POP。

5. Map 页 - 由属性驱动的参数 - 参数可以根据该 POP 的某个属性，在每个点上取不同的值。

6. 以及参数提示（当 Math Mix 的输出属性为空时，还有映射提示）

7. 通过 Specification 参数进行实例化（场、力等）（引用一个 POP，其点列表表示每个点一个实例）（Field POP、Force POP）

8. 禁用多值参数组中未激活的参数。

9. 顺序参数块现在更有结构、更灵活。

10. 用户现在可以在 Component Editor 中创建自己的自定义顺序参数块。

11. 自动重命名操作符名称，以反映其新类型。

12. 无标签的参数面板。页菜单全部在一行内。Geo 查看器标题。

13. 参数后缀现在统一从 0 开始。

14. 多列弹出菜单。双重下拉菜单（用于属性）。

15. 将顺序参数块折叠为单行摘要（Math Mix 和 Math Combine POP 的 Combine 页）
