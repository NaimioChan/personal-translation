WebRTC DAT

摘要

WebRTC DAT 代表任意数量的WebRTC点对点连接一端的对等端。

在 TouchDesigner 中，每个连接都由生成的 UUID 表示。该 UUID 必须传给WebrtcDAT Class连接级的 Python 方法。

WebRTC DAT 的输出是一个表格，每行一个连接，列为：id（即 UUID）、connection_state、signaling_state、ice_connection_state和ice_gathering_state。

这些列共同描述连接的状态，对调试也有用。例如，若 ice_connection_state 失败，说明本地与远端 ICE 候选地址配对以进行网络流传输时出了问题。可能是 NAT 穿越失败；若使用 STUN 服务器，这可能意味着需要 TURN 服务器（见https://en.wikipedia.org/wiki/STUN#Limitations）。

WebRTC 的视频和音频输入/输出通过Video Stream In TOP、Video Stream Out TOP、Audio Stream In CHOP和Audio Stream Out CHOP完成。

另请参阅WebRTC。

webrtcDAT_Class

参数 - Connection 页

Active active - 活动时，可以连接对等端并发送媒体/数据。停用时，所有现有连接都会关闭。
Reset reset - 重置与此 DAT 关联的对等端。等同于先停用再重新启用 active 参数。
Custom Bit Rate Limits bitratelimits - 启用时，可以指定自定义的最小/最大比特率。这些最大比特率限制以 kbps 表示，适用于与 WebRTC DAT 关联的所有轨道。
Minimum Bit Rate (kbps) minbitrate - 与 WebRTC DAT 关联的所有轨道的最小比特率。
Maximum Bit Rate (kbps) maxbitrate - 与 WebRTC DAT 关联的所有轨道的最大比特率。
Callbacks DAT callbacks - 引用一个包含 WebRTC 回调的 DAT。

参数 - ICE 页

STUN Server URL stun - STUN 服务器的 URL。有关 STUN 的更多细节，请参阅WebRTC#ICE。
TURN Username username - 访问指定 TURN 服务器的用户名。
TURN Password password - 访问指定 TURN 服务器的密码。
TURN Server turn - TURN 服务器 URL 序列。
TURN Server URL 0 turn0server - TURN 服务器的 URL。有关 TURN 的更多细节，请参阅WebRTC#ICE。
