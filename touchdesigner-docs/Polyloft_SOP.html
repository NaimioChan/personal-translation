Polyloft SOP

摘要

Polyloft SOP 通过连接（即放样/缝合）开放或闭合面的点来生成三角形网格，不添加任何新点。Polyloft 也可以用类似方式连接不相关的点组。面与点组不必具有相同的点数。

可选输入指定静止几何，通常是在某个特定面（一般为 1）上主输入的副本。这会强制点顺序在整段动画中保持不变，并防止几何变形时三角形缝合出现跳变。如果使用静止几何来做放样并指定了面组或点组，请确保它们在第二个输入中已定义。

参数 - Polyloft 页

Connect Closest Ends proximity - 从最近的两个点开始缝合，并处理任意面朝向和起始顶点。
Consolidate Points consolidate - 缝合前融合相邻点。
Distance dist - 合并的阈值距离。
Minimize minimize - 距离最小化目标：
  • 2-Point Distance point2 - 默认缝合目标。
  • 3-Point Distance point3 - 可能有助于避免相交。
U Wrap closeu - 在 U 方向闭合缝合（闭合每个横截面）。
  • Off nonewu -
  • On wu -
  • If Primitive does ifprimwu -
V Wrap closev - 连接第一个和最后一个横截面。
  • Off nonewv -
  • On wv -
  • If Primitive does ifprimwv -
Create Polygon Group creategroup - 把生成的三角形放入一个组。
Name polygroup - 当上面的参数 Create Polygon Group = On 时，在此指定组名。
Method method - 选择如何执行放样/缝合。
  • Faces faces - 通过连接一组面的控制顶点来缝合这些面。
  • Points points - 缝合多组点，每组作为一个横截面。
Group group - 要放样的面的子集。
Keep Primitives prim - 缝合后保留横截面。

参数 - Point Groups 页

缝合多组点，每组作为一个横截面。

Point Group point - 要缝合的点集序列。
Point Group point0group - 点组。

Info CHOP 通道

Polyloft SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
