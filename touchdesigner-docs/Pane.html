窗格

窗格（Pane）是 TouchDesigner 布局中的工作区域。TouchDesigner 窗口可分割为 2 个或更多窗格。有 9 种窗格类型可供选择，用于填入窗格以完成不同任务。

每个窗格顶部都有 Pane Bar。其中间是窗格的 network path。左右两侧的按钮和图标可让你选择窗格中的查看器、书签、在网络历史中跳转、分割窗格、全屏，或把一个窗格链接到另一个。

在网络路径中，点击 / 字符可通过菜单导航，或点击空白处输入网络路径，或剪切/粘贴网络路径。

TouchDesigner 创作界面 Designer Mode 可以是单个窗格，也可分割为多个窗格（也称为 Worksheet）。窗格的排列与显示方式称为窗格 layout。可使用 Layout Strip 管理布局。

分割窗格，或使用 Pane Layout 栏选择多窗格布局。

Network Editor 窗格类型是主视图，可让你把 OP 连接起来。

Panel 视图可让你查看控制面板并与之交互。

Geometry Viewer 可让你与 3D 场景和对象交互。TOP Viewer、CHOP Viewer 和 Geometry Spreadsheet 可分别用于查看 TOP、CHOP 和 SOP 中的数据，其中 Geometry Spreadsheet 还能修改数据。

Parameter 和 Textport 视图提供与同名 dialogs 相同的信息。

Browser 会在窗格中载入一个多用途树形浏览器。此浏览器可用于查看 TouchDesigner 网络、CHOP 通道、磁盘文件系统以及 Palette 库，都在同一个窗格中。

另请参阅 desk 命令和 neteditor 命令。
