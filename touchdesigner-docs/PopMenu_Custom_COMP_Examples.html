PopMenu 自定义 COMP 示例

本页包含如何设置 popMenu 自定义组件的示例。示例假定你具备 TouchDesigner 和 Python 的基础知识。

popMenu 的完整文档见：PopMenu Custom COMP。

示例 1 - 菜单参数

在本示例中，我们将探索 popMenu 参数提供的功能。更多细节见 popMenu parameters。

创建 popMenu

要创建 popMenu，从 Palette（Derivative 下的 UI 文件夹）中拖一个到你的网络里。要测试 popMenu，点击 Open 参数。你可以点击 Close 参数或按 esc 关闭菜单。注意： 菜单节点中的视图并不总能准确反映 popMenu 窗口的样子，所以测试时最好打开它来看。

列表项参数

要给 popMenu 添加列表项，只需把它们加到 Items 参数中的 Python 列表里。要禁用列表中的项，把它们加到 Disabled Items 参数中的 Python 列表里。被禁用的项必须与 Items 列表中的项完全一致。Highlighted Items 的用法与 Disabled Items 完全相同，但该项带高亮颜色且仍可用。要在某一项之后创建分隔线，把它加到 Dividers After Items 参数的 Python 列表中。

使用 Checked Items 参数在 popMenu 中创建勾选项有几种做法。如果输入一个 Python 列表，列表中的项旁边会带勾。但这种方法无法创建空的复选框。要做到这一点，请使用 Python 字典，键与列表 Items 匹配，值为 1（勾选）或 0（未勾选）。

对齐与格式参数

要调整 popMenu 相对于鼠标出现的位置，使用 Horizontal Align 和 Vertical Align 参数。Align Offset 参数让你输入对齐的像素偏移量。

还有一些基本的格式参数可用。Columns 参数可用于创建多列菜单。注意： 如果你有多于一列，Dividers After Items、Checked Items 和 SubMenus（见下面的示例）将不可用。Borders 参数打开和关闭菜单的外边框，Max Height 参数设置菜单显示滚动条的大小。

示例 2 - popMenu 网络

在本示例中，我们将搭建一个简单的网络：按钮被按下时，在其上方打开一个 popMenu。

创建 popMenu

要创建 popMenu，从 Palette（Derivative 下的 UI 文件夹）中拖一个到你的网络里。本示例中请确保它的名称为 popMenu。

PopMenu 的输入与输出

基于表来设置 popMenu 很简单，只需把表连到 popMenu 的输入上。表格的第一列将用作 popMenu 的列表项，其他列被忽略。要创建示例菜单，做一个单列 Table DAT，4 行内容为："Test"、"Demo"、"Trial"、"Example"。把表连到 popMenu。按下 Open 参数即可看到菜单。提示： 对于多列表格和带标签的输入表格，可以使用不同的 Input Table 参数设置。


要用 CHOP 获取 popMenu 的结果，把一个 Null CHOP 连到 popMenu 的 CHOP 输出上。popMenu 打开后、尚未做出选择时，selected_cell 通道的值为 -1。做出选择后，selected_cell 为所选项的索引。用同样的方法配合 Table DAT 和 popMenu 的 DAT 输出，可以获取所选 Item 的文字。在做出选择之前，表格是空的。

用 Button 打开并响应 popMenu

首先需要一个按钮。在网络中创建一个 Button COMP。把它的 Width 参数改为 100，Button Type 参数改为 Momentary。要让按钮打开 popMenu，创建一个 Panel Execute DAT，并把它的 Panel 参数设为这个新按钮。接着，在 DAT 中输入以下代码，创建新的 onMenuChoice 函数并替换默认的 onOffToOn 函数：

def onMenuChoice(info):
	debug(info)
	debug(info['item'])

def onOffToOn(panelValue: PanelValue):
	op('popMenu').Open(callback=onMenuChoice)
	return

onOffToOn 回调打开菜单，并把选择回调设为 onMenuChoice。onMenuChoice 函数打印发送给回调的所有信息，然后只打印其中最常用的部分，即所选项的字符串。有关回调的更多信息，见：popMenu Callback System。

要测试按钮菜单，为按钮打开一个浮动查看器并点击它。你会想用浮动查看器，因为节点视图会拉伸按钮，导致菜单位置不可预测。菜单打开了，但它出现在鼠标位置，而不是附着在按钮上。我们来修正一下……

把 popMenu 附加到 Button

要把 popMenu 附加到按钮上，使用菜单 Pop Menu 参数页底部的参数。首先，把 Button Comp 参数设为你的按钮。注意： 虽然该参数叫 Button Comp，因为这是它最常见的用途，但它可以是任何 panel 组件。接着，把 Horizontal Attach 参数设为 Left，把 Vertical Attach 参数设为 Top。这些定义菜单的对齐点附着在哪里。我们希望它与该操作符的左下角对齐，所以把 Vertical Align 参数设为 Bottom。

再测试一次按钮。看起来不错，只是菜单大小能匹配按钮大小会更好。进入菜单的 Width 参数，注意它含有表达式 me.OptimalWidth。那个 OptimalWidth 成员包含刚好包裹菜单文字所需的尺寸。把 Width 改成 100，与按钮的宽度一致。现在测试，结果会与本示例顶部的图像相同。

示例 3 - 用脚本创建的简单选择 popMenu

在本示例中，我们将创建一个弹出式上下文菜单，让你选择 TouchDesigner 网络中的当前节点。与前面的示例不同，我们将只用脚本创建这个菜单。

系统 popMenu

对于上下文弹出菜单，你通常希望完全用脚本创建并打开菜单。你可以用自己的 popMenu COMP，也可以使用 TouchDesigner 提供的 system popMenu。如果使用系统 popMenu，应仅用于上下文菜单和其他用后立即消失的东西，因为它也可能被 TouchDesigner 的其他功能调用。这个系统 popMenu 位于：op.TDResources.PopMenu

创建简单选择菜单

首先，在一个放有其他操作符的网络中创建一个 Text DAT。在其中输入以下文本：

def menuChoice(info):
	op(info['item']).current = True

menuItems = [child.name for child in parent().children]

op.TDResources.PopMenu.Open(
		items=menuItems,
		callback=menuChoice,
		disabledItems=[me.name],
	)

menuChoice 函数是在做出菜单选择时被调用的函数。它只是把选中的操作符设为网络中的当前节点。

menuItems 列表包含你的 textDAT 所在网络中所有节点的名称。它是用 Python 列表推导式创建的。如果你不熟悉这种语法，这里有个不错的教程：Python List Comprehension With Examples。

脚本的最后一部分打开实际的弹出菜单。它是对系统 popMenu 的 Open 方法的一次调用。你会认出大部分参数与 popMenu COMP 上的参数相对应。items 参数保存菜单的列表项，本例中我们放入上一行创建的名称列表 menuItems。callback 参数接收一个 Python 函数，在从菜单中做出选择时作为回调。本例中我们要用脚本顶部的 menuChoice 函数。disabledItems 参数对应 Disabled Items 参数，作为示例我们提供一个只有一个元素的列表，即脚本操作符的名称。 popMenu 的 Open 方法其他参数的信息，见 popMenu Methods。

要测试脚本，缩小视图直到能看到脚本网络中其他节点，然后右键点击 textDAT 并选择 Run Script。从菜单中选择一个 Operator 名称时，该 Operator 周围会出现绿框，表示它是「当前」节点。

示例 4 - 高级选择 popMenu

在本示例中，我们将扩展上一个示例，创建一个弹出式上下文菜单：它不仅能选择网络中的节点，还使用 popMenu 的高级功能显示菜单中正被悬停的节点以及当前已选中的节点。

创建高级选择 popMenu 脚本

在一个放有其他操作符的网络中创建一个 Text DAT。在其中输入以下文本：

def onMenuChoice(info):
	if info['item'] == 'Close Menu':
		info['menu'].Close()
	else:
		op(info['item']).current = True

def onRollover(info):
	for child in parent().selectedChildren:
		child.selected = False
	if info['item'] == 'Close Menu' or info['item'] is None:
		return
	op(info['item']).selected=True

menuItems = [child.name for child in parent().children]
lastChild = menuItems[-1]
menuItems.append('Close Menu')
op.TDResources.PopMenu.Open(
		items=menuItems,
		callback=onMenuChoice,
		disabledItems=[me.name],
		dividersAfterItems=[lastChild],
		checkedItems='{child.name: child.current for child in op("' \
						+ parent().path + '").children}',
		autoClose=False,
		rolloverCallback=onRollover
	)

右键点击 textDAT 并选择 Run Script 来测试代码。注意，在菜单中悬停到某个节点名称上时，该节点周围会出现黄色选择框。点击节点名称后，它成为当前节点，其名称被勾选。点击 Close Menu 可以（你猜到了）关闭菜单。

这个脚本信息量很大，我们分段来看……

选择与悬停回调
def onMenuChoice(info):
	if info['item'] == 'Close Menu':
		info['menu'].Close()
	else:
		op(info['item']).current = True

onMenuChoice 函数与上一个示例中的类似，只是增加了 Close Menu 选项。可以看到，为菜单选择定义特定操作就像写一个 if/else 语句一样简单。

def onRollover(info):
	for child in parent().selectedChildren:
		child.selected = False
	if info['item'] == 'Close Menu' or info['item'] is None:
		return
	op(info['item']).selected=True

onRollover 回调使用 Operator 的 selected 成员，在悬停菜单项时给节点加上你看到的黄框。for 循环取消选中网络中的所有节点。然后我们检查确保不是悬停在 Close Menu 项上，也不是悬停在空处。鼠标离开 popMenu 时也会调用悬停回调，所以该项可能是 None！最后，如果鼠标悬停在有效项上，就把对应 Operator 的 selected 成员设为 True。

高级选择 popMenu 的设置与勾选项表达式
menuItems = [child.name for child in parent().children]
lastChild = menuItems[-1]
menuItems.append('Close Menu')
op.TDResources.PopMenu.Open(
		items=menuItems,
		callback=onMenuChoice,
		disabledItems=[me.name],
		dividersAfterItems=[lastChild],
		checkedItems='{child.name: child.current for child in op("' \
						+ parent().path + '").children}',
		autoClose=False,
		rolloverCallback=onRollover
	)

脚本的这一部分创建实际菜单。与上一个示例一样，我们创建一个 menuItems 列表，包含脚本的所有同级节点。然后把这个列表的最后一个成员存入 lastChild，供 Open 方法使用。最后，把 "Close Menu" 追加到列表中，创建该选项。

在 Open 方法中，我们用 menuItems 作为列表项。我们用存入 dividersAfterItems 参数的 lastChild，在各选项与 Close Menu 选项之间画一条线。

checkedItems 参数包含一个表达式，它会持续更新菜单中的复选框。它使用 Python 字典推导式（可在 here 了解）创建一个以 Operator 名称为键、数据等于该 Operator 的 current 成员的字典。结果是除「当前」操作符外，每个 Operator 名称旁都创建一个空复选框，当前操作符则带勾。注意： checkedItems 参数也接受字面字典或列表，但提供表达式能让它实时更新。

此菜单的 autoClose 参数为 False，因为它要一直打开，直到选中 Close Menu。最后，我们把 rolloverCallback 参数设为上面创建的 onRollover 函数。

示例 5 - 带子菜单的颜色选择 popMenu

在本示例中，我们将创建一个带子菜单的 popMenu，用来为网络中的节点颜色选择黑色或白色。

创建颜色选择 popMenu 脚本

在一个放有其他操作符的网络中创建一个 Text DAT。在其中输入以下文本：

def onMainMenuChoice(info):
	info['menu'].OpenSubMenu(
			items=['white', 'black'],
			callback=onSubMenuChoice,
			callbackDetails=info['item'],
		)

def onSubMenuChoice(info):
	menuOp = op(info['details'])
	if info['item'] == 'white':
		menuOp.color = (1,1,1)
	elif info['item'] == 'black':
		menuOp.color = (0,0,0)

menuItems = [child.name for child in parent().children]
op.TDResources.PopMenu.Open(
		items=menuItems,
		callback=onMainMenuChoice,
		subMenuItems=menuItems,
		autoClose=True,
		allowStickySubMenus=True
	)

右键点击 textDAT 并选择 Run Script 来测试代码。悬停到某个 Operator 名称上时，会出现带 black 和 white 选项的子菜单。选择其中之一会改变该 Operator 在网络中的颜色。

在本示例中，我们启用了 popMenu 的 sticky sub-menus 功能。这让你可以点击子菜单项（这里是 Operator 名称），强制子菜单「粘住」不关闭，从而能在菜单不关闭的情况下点击子菜单选项。现在试一下。你会看到子菜单设为粘住时，Operator 名称以粗体显示。现在你可以在黑色和白色之间切换，而无需重新打开 popMenu。再次点击名称可关闭粘住状态。即使子菜单处于粘住状态，菜单失去焦点时仍会关闭。

我们分段来看这个脚本……

onMainMenuChoice 回调
def onMainMenuChoice(info):
	info['menu'].OpenSubMenu(
			items=['white', 'black'],
			callback=onSubMenuChoice,
			callbackDetails=info['item'],
		)

这是创建子菜单最重要的部分。你是在父菜单的常规选择回调中定义所有子菜单设置的。OpenSubMenu 方法与用于打开 popMenu 的 Open 方法基本相同。区别在于你是在 info['menu'] 上的选择回调内部调用它，而它保存着父 popMenu。

注意，我们按前面示例所述设置了所有项回调，并有一个独立的选择回调 onSubMenuChoice 来处理来自子菜单的选择。这里用到的另一个新功能是 details 参数。你可以用 details 把任何需要的额外信息传给选择回调。本例中我们需要知道是哪个主菜单项生成了子菜单，所以传入 info['item']。

onSubMenuChoice 回调
def subMenuChoice(info):
	menuOp = op(info['details'])
	if info['item'] == 'white':
		menuOp.color = (1,1,1)
	elif info['item'] == 'black':
		menuOp.color = (0,0,0)

onSubMenuChoice 回调相当简单。首先，我们从 onMainMenuChoice 回调收到的 info['details'] 中取出要影响的 Operator。然后对选中的 info['item'] 做简单判断，决定把操作符设成什么颜色。

颜色选择 popMenu 的设置
menuItems = [child.name for child in parent().children]
op.TDResources.PopMenu.Open(
		items=menuItems,
		callback=onMainMenuChoice,
		subMenuItems=menuItems,
		allowStickySubMenus=True
	)

这个 popMenu 的主要设置与前面的示例相似。这里唯一要注意的新东西是 allowStickySubMenus 参数。它启用粘性菜单，详见 above。

Important Note: op.TDResources 中的系统 popMenu 提供两级子菜单。如果你需要更多层级，就必须自己创建一套 popMenu。话虽如此，超过两级子菜单的菜单往往会让人困惑。
