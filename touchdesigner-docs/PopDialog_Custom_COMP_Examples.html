PopDialog 自定义 COMP 示例

本页包含如何设置 popDialog 自定义组件的示例。所有示例都假定你具备 TouchDesigner 和 Python 的基础知识。

popDialog 的完整文档见：PopDialog Custom COMP。

示例 1 - 通知弹窗对话框

在本示例中，我们将创建一个非常简单的 popDialog，向用户显示一条必须点击的通知。

创建 popDialog

要创建 popDialog，从 Palette（Derivative 下的 UI 文件夹）中拖一个到你的网络里。

设置基本参数

要创建示例弹窗，进入 Pop Dialog 自定义参数页，按下图设置参数：

  • Title：标题栏的文字。
  • Text：对话框正文。
  • Buttons：要显示的按钮数量。
  • Button Label 1：按钮 1 的文字。注意： 按钮 2 被忽略，因为 Buttons 设为 1。
  • On Esc Press Button：如果按下 Esc 键，模拟按下所选按钮。
  • On Enter Press Button：如果按下 Enter 键，模拟按下所选按钮。
  • Esc On Click Away：如果为 True，点击对话框以外的任何位置（或切换到其他应用窗口）都会模拟按下 Esc 键。

所有 popDialog 参数的详细说明见 popDialog wiki。

打开 popDialog

要测试 popDialog，点击 Open 参数。这对测试有效，但这样的对话框通常是在 Python 脚本中打开的。要打开，只需调用 popDialog 的 Open 方法。你可以在 textport 中输入以下内容来完成：

op("<path to your popDialog>").Open()

示例 2 - 选择弹窗对话框

在本示例中，我们将创建一个 popDialog，向用户提供几个按钮供选择。我们还会写一个脚本来响应这些按钮。

创建 popDialog

要创建 popDialog，从 Palette（Derivative 下的 UI 文件夹）中拖一个到你的网络里。

设置参数

要创建示例弹窗，进入 Pop Dialog 自定义参数页，按下图设置参数：

以下参数与第一个示例有明显不同：

  • Title：设为空白，只是为了看看没有标题栏时 popDialog 是什么样子。
  • Buttons：这次我们要四个按钮。
  • Button Label 1-4：这是四个可用的选项。
  • On Esc Press Button：如果按下 Esc，我们希望选中 "Cancel" 按钮。
  • On Enter Press Button：由于 Enter 没有明显的默认选项，这里也直接选 "Cancel" 按钮。

现在可以点击 Open 参数测试对话框了。看起来没问题，但还不起作用。

编写 onSelect 回调

这一步需要一个 Text TOP，放在 popDialog 旁边的网络中。创建它，并确保名称为 "text1"。然后，要编辑 popDialog 的 Callback DAT，点击 Callbacks 页上的 Edit Callbacks 参数。在 DAT 中输入以下文本：

def onSelect(info):
	"""A button has been pressed"""
	if info['button'] == "Cancel":
		return
	else:
		textTOP = info['ownerComp'].op('../text1')
		textTOP.par.alignx = info['buttonNum'] - 1

popDialog 回调使用 TouchDesigner 的 Python Callback System，它会把一个参数（info）传给所有回调，其中保存相关信息的字典。在回调顶部的 if 语句中可以看到，info['button'] 保存被按下按钮的文字。如果该按钮是 "Cancel"，我们不做任何事，直接退出回调。否则，我们查看 info['buttonNum']，它保存被按下按钮的编号。这个编号减一，对应 textTOP 的 alignx 参数，用来设置合适的对齐方式。注意，在定位 textTOP 时，我们从 popDialog 本身出发，它保存在 info['ownerComp'] 中。

保存回调 DAT，再试一次 popDialog，同时观察 text1。现在按下对话框按钮会设置文字的对齐方式！

示例 3 - 文本输入弹窗对话框

在本示例中，我们将创建一个允许用户输入文本的 popDialog。我们还会写一个脚本使用该文本。

创建 popDialog

要创建 popDialog，从 Palette（Derivative 下的 UI 文件夹）中拖一个到你的网络里。

设置参数

要创建示例弹窗，进入 Pop Dialog 自定义参数页，按下图设置参数：

以下参数有明显不同：

  • Text Entry Area：如果为 True，对话框将带一个文本输入字段。
  • Text Entry Default：文本输入字段中初始的文字。

现在可以点击 Open 参数测试对话框了。看起来没问题，但还不起作用。

编写另一个 onSelect 回调

这一步需要一个 Text TOP，放在 popDialog 旁边的网络中。你可以用示例 2 中的那个，确保名称为 "text1"。然后编辑 popDialog 的 Callback DAT，写入以下文本：

def onSelect(info):
	"""A button has been pressed"""
	if info['button'] == "Cancel":
		return
	else:
		textTOP = info['ownerComp'].op('../text1')
		textTOP.par.text = info['enteredText']

此回调与示例 2 中的类似。唯一实质区别是我们把 textTOP 的 text 参数设为 info['enteredText']。

保存回调 DAT，再试一次 popDialog，同时观察 text1。现在输入文本会设置 TOP 的内容。

示例 4 - 用脚本创建弹窗对话框

在本示例中，我们将完全用脚本创建 popDialog。

实际使用中，你很少需要操作单个 popDialog 的参数。由于 popDialog 的设计前提是同一时间屏幕上只有一个，通常直接使用 op.TDResources 中的系统 popDialog 是安全的。提示： 如果你确实使用系统对话框，务必给 Open 方法提供全部参数，或者（更好的做法）使用 OpenDefault 方法。

创建 popDialog 脚本

首先，在网络中创建一个 Text DAT。输入以下文本：

def dialogChoice(info):
	debug(info['button'])
	debug(info['details'])

op.TDResources.PopDialog.OpenDefault(
			text='This is a dialog',
			title='The title',
			buttons=['OK', 'NO'],
			callback=dialogChoice,
			details='Any python object',
			textEntry=False,
			escButton=2,
			enterButton=1,
			escOnClickAway=True)

这个脚本做两件事：先定义对话框的回调，然后打开它。dialogChoice 函数的作用与前两个示例中使用的 onSelect 回调完全相同。之后的命令打开系统 popDialog。大部分参数都很直观，例外的是 callback 参数，它接收一个在选择发生时被调用的 python 函数；以及 details 参数，它包含一个 python 对象，存放回调中可能需要的任何用户信息。注意： 如果需要多条用户信息，details 可以是列表或字典。

要打开对话框，右键点击 Text DAT 并选择 Run Script。 保存回调 DAT，再试一次 popDialog，同时观察 text1。现在输入文本会设置 TOP 的内容。
