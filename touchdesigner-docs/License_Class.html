License 类

License 类描述一个已安装许可证的实例。它们可以从 licenses 对象访问。

成员

index → int (Read Only):

许可证在列表中的索引。

isEnabled → bool (Read Only):

若许可证在本地启用（即从未被禁用）则为 True。

isRemotelyDisabled → bool (Read Only):

若许可证已被远程禁用则为 True。

key → str (Read Only):

密钥序列。

remoteDisableDate → tuple[int, int, int] (Read Only):

许可证被远程禁用的日期，表示为元组（年、月、日）。

status → int (Read Only):

数值状态码。负值表示该许可证不适用于当前应用程序。值为零表示适用。

statusMessage → str (Read Only):

状态码的说明。

systemCode → str (Read Only):

与此许可证关联的系统代码。

type → str (Read Only):

许可证类型，例如某些产品为 'Pro'、'Non-Commercial'、'Commercial'。另请参阅 App Class 中的 app.product

updateExpiryDate → tuple[int, int, int] (Read Only):

此许可证的更新到期日期，表示为元组（年、月、日）。

version → int (Read Only):

数值形式的许可证版本。
