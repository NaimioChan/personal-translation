Project SOP

摘要

Project SOP 通过将 3D 面投影到样条曲面上来创建曲面上的曲线（也称修剪曲线或轮廓曲线），很像光线在 3D 曲面上投下 2D 阴影。有两种投影方法：沿矢量投影，或将面直接映射到曲面的参数空间。

使用 Bridge SOP 将轮廓曲线蒙皮到另一条轮廓曲线。

使用 Profile SOP 提取曲面上的曲线或重新映射其位置。

如果最终得到的轮廓曲线不可见，它可能仍然存在。单击 SOP 的信息弹出窗口（使用鼠标中键）即可确认轮廓曲线是否存在。

轮廓曲线的其他操作

要删除投影曲线，请使用 Delete SOP，并输入轮廓编号（例如 1.4 返回第二个图元上的第五个轮廓（计数从 0 开始））。在 Viewport Display 选项中启用 Profile Number 图标，即可看到各轮廓的编号。

可以使用 Group SOP 对轮廓曲线分组。方法是在 Pattern 栏中键入轮廓编号。可以使用所有正则表达式。

可以使用 Primitive SOP 对轮廓施加参数化仿射变换。也可以使用 Primitive SOP 打开、闭合、反转和循环轮廓曲线。

注意： 在 Primitive SOP 中对轮廓施加变换时，只能绕 Z 轴旋转，因为投影曲线是位于曲面域内的平面曲线。因此，为轮廓提供 X 或 Y 方向的旋转没有意义。

参数 - 页

Face Group facegroup - 要投影到样条曲面上的面组。接受图案，如 Pattern Matching 中所述。
Surface Group surfgroup - 要将面投影到的曲面组。接受图案，如 Pattern Matching 中所述。
Cycle Type cycle - - 选择用于将 3D 面投影到 3D 样条曲面上的方法。
  • All on Each Surface in Sequence allseq - 若按参数化方式投影，面之间的空间关系会被保留。例如，如果文本「hello」按参数化并按顺序投影，字母会自然地并排出现在曲面上。沿矢量投影时，顺序不适用。
  • All on Each Surface Overlapping allover - 若按参数化方式投影，面之间的空间关系不会被保留，因此它们会在所选投影域区域内重叠出现。沿矢量投影时，重叠不适用。
  • One per Surface oneeach - 每个面按其在输入中或各自组中的出现顺序投影到一个曲面上。
  • Cycled cycled - 这与上面的 One Per Surface 相同，但如果还有剩余曲面，会重新从头开始使用面。

参数 - Method 页

Method method - - 在沿矢量投影或使用下方参数进行参数化投影之间选择。
  • Along Vector vector - 面沿 3D 矢量投影，其在曲面上的图像会转换为曲面上的曲线。一条空间曲线可能生成多条轮廓，取决于它相对于曲面的位置、曲面形状以及所选的投影侧。如果投影的面与曲面完全不相交，则不会生成轮廓曲线。
  • Parametrically parametric - 面的空间尺寸会直接映射到样条曲面的域上。所得投影对曲面的参数化很敏感，很可能看起来有变形。但它是两种投影类型中最快的，并且在形状规则、采用弦长参数化的曲面上通常表现良好。
Axis axis - - 特征四个角投影到基面所沿的轴。当从外部以 Vector 粘贴方式添加特征时使用。
  • X xaxis - 笛卡尔轴 X、Y 或 Z。
  • Y yaxis - 笛卡尔轴 X、Y 或 Z。
  • Z zaxis - 笛卡尔轴 X、Y 或 Z。
  • Face Normal fnorm - 投影轴沿每个面各自的法线。因此每个面可能有不同的投影方向。此选项对非平面面也很有效。
  • Minimum Distance mindist - 沿到曲面的最小距离矢量投影整个 3D 面。投影分辨率由 Divisions per Span 值给出。
  • User Defined: other - 启用正下方的 Vector 栏，用于指定矢量的 X、Y 和 Z 分量。

注意： 当选择 Minimum Distance 选项时，Side 按钮会被禁用，因为它对此投影类型没有意义。

Vector vector - - 若上方 Axis 参数中未选择任何主轴，则为投影矢量的 X、Y 和 Z 分量。
  • vector1 -
  • vector2 -
  • vector3 -
Side projside - - 选择投影到几何的哪一侧，最近还是最远。
  • Closest closest - 会把面投影到投影矢量任一方向上曲面的最近部分。例如，如果投影到管上的曲线位于管内部，会得到两条轮廓，分别在管的两侧；如果曲线位于管外部，则会投影到离它最近的一侧。
  • Farthest farthest - Closest 的反向。在上面的例子中，若曲线位于管内部，Farthest 同样会得到两个图像，但若曲线位于管外部，它会选择最远的一侧。
Divisions per Span sdivs - 在空间面上的相邻跨度之间要计算的点数。跨度是多边形上连接两个相邻 CV 的线段，或样条曲线上两个断点之间的弧。分割数越多，投影通常越精确。
Ray Tolerance rtolerance - 控制射线与曲面相交的精度。射线从 3-D 曲线的每个点沿投影矢量投射。
Fit Tolerance ftolerance - 控制 2-D 拟合精度，通常小于 0.01。
Max UV Gap (%) uvgap - 指定曲面域尺寸的百分之多少以内，允许将两条独立的轮廓合并为一条曲线。
Order order - 所得轮廓曲线的样条阶数。曲线类型（Bzier 或 NURBS）继承自空间曲线。但阶数不继承，因为样条阶数对拟合质量提供了有用的控制。如果空间面是多边形，轮廓将是 NURBS 曲线。
Preserve Sharp Corners csharp - 控制投影曲线中尖角的插值精度。当投影存在曲率剧烈变化区域时应打开。
Super Accurate Projection accurate - 使用非常精确但开销较大的代数剪枝算法来确定矢量与曲面的相交。
U from ufrom - - 指定哪个空间坐标（X、Y 或 Z）必须映射到曲面的 U 参数方向。
  • X Coordinate uvx -
  • Y Coordinate uvy -
  • Z Coordinate uvz -
V from vfrom - - 指定哪个空间坐标（X、Y 或 Z）必须映射到曲面的 V 参数方向。
  • X Coordinate uvx -
  • Y Coordinate uvy -
  • Z Coordinate uvz -
Map Profile to Range: userange - 此选项默认开启。它会使轮廓被缩放和平移，以适配下文所述的曲面域范围。若关闭此选项，轮廓坐标会不经任何变换地映射到曲面域上；因此如果轮廓的点不在目标曲面的域内，轮廓将不可见。

通常，如果投影的面此前是用 Profile SOP 并选择 Parametrically to XY 选项从同一曲面提取的，则不应将其映射到 U/V 范围。 提取与重新投影的配合，对于实现目前只有 3D 曲线才能达成的建模目标非常有用。这类任务包括编辑轮廓的点、将轮廓接合、缝合或倒角、雕刻或细化轮廓等。通过将轮廓参数化提取到 XY，Touch 会创建一个与 2D 轮廓相同的 3D 面，只是多了一个（恒定的）Z 分量。

所得 3D 曲线可以用所有可用的 3D 工具建模。最后，可以将建模后的 3D 面按参数化方式重新应用到曲面上，并确保关闭范围映射选项。

U Range urange - - 以百分比表示 U 曲面域中映射区域所占的部分。完整范围 0-1 会使轮廓映射到 U 参数方向的整个域。该范围不限于 0-1 区间。

  • vrange1 -
  • vrange2 -
Mapping Type maptype - - 选择如何重新定位和缩放现有轮廓，使其适配指定的域范围。
  • Uniform unif - Mapping 会将投影面的空间坐标转换为曲面域中的 (U,V) 点，不考虑曲面的参数化。
  • Chord Length chordlen - Mapping 会考虑曲面参数化，并尝试计算最适合模型空间与参数决定因素的投影。

若面未映射到范围，其顶点会不经任何变换地传递到轮廓。可将此技巧与 Profile SOP 中的参数化提取配合使用，以编辑由 Project 以外的 SOP 生成的轮廓的点：提取、编辑点，然后再次投影。

提示

NURBS 发际头皮面片

The: Along Vector → Axis → Minimum Distance 选项非常有用，例如在以下情形：你有一个头部的 NURBS 曲面，想通过把发际线投影到头部的曲面上来获得一个 NURBS 面片。你可以：

将 NURBS 头部设为模板。

输入 Model SOP。

在 Model Editor 中启用 Snap to Template 选项（Snap 选项）。

沿头部曲面在你想要发际线的位置绘制一条 NURBS 曲线。然后用 Project SOP 选择 Minimum Distance 选项，你就得到了一条轮廓曲线，可用它修剪头部曲面以获得该面片。

这样获得了头皮处的 NURBS 面片后，就可以把它用作头发的基底。

示例

  1. 放置一个 Circle SOP - Type: NURBS，Radius: 0.3, 0.3；然后放置一个 Tube SOP - Type: NURBS。
  2. 将它们连接到 Project SOP - Circle 接到 Input1；Tube 接到 Input2。
  3. 在 Project SOP 后追加一个 Trim SOP - 它会根据 Project SOP 提供的投影修剪曲面。必须把 Trim SOP 追加到 Project SOP 之后，才能实现这种修剪。
  4. 在 Circle 和 Tube SOP 上启用模板标记；将 Project SOP 设为显示 SOP。

Info CHOP 通道

可通过 Info CHOP 访问 Project SOP 的额外信息。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
