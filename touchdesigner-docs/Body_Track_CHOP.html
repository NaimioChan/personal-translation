Body Track CHOP

摘要

注意

OS: 此操作符仅在 Microsoft Windows 操作系统下受支持。
Hardware: 此操作符使用 Nvidia Maxine 系统的 Augmented Reality (AR) SDK，需要 20、30、40 或 50 系列 Nvidia RTX GPU。

The models for this operator are not included with TouchDesigner. To use this operator you will need to download the 0.8.7 version AR SDK for your GPU from https://www.nvidia.com/en-us/geforce/broadcasting/broadcast-sdk/resources/.

Body Track CHOP 可以 2D 或 3D 方式跟踪一个或多个人体的边界框和 34 个关键点，并可选择输出关节角度。

输入图像取自指定的 TOP，可以是任意分辨率或格式，也可以是静态图像或视频。

检测到的特征坐标以相对于输入图像左下角的 u、v 位置给出。默认情况下值域为 0 到 1，但可启用 'Aspect Correct' 参数对数值进行缩放，使其在保持原图宽高比的同时可用作 3D 坐标。

bodytrackCHOP_Class

参数 - BodyTrack 页

Active active - 启用人体跟踪功能。
Model Folder modelfolder - 用于人体检测的 AI 模型文件的位置。默认情况下这些文件位于 Config/Models 文件夹中。
TOP top - 提供用于进行人体跟踪的图像的 TOP 操作符的路径。
High Performance highperformance - 以牺牲质量为代价启用高性能。仅在 Keypoints 开启时可用。
Bounding Boxes bbox - 输出描述检测到的人体周围边界框的通道。这些通道给出人体中心的 u、v 位置以及框的宽度和高度。位置相对于输入图像的左下角。
Bounding Box Confidence bboxconfidence - 输出一个通道，描述 AI 模型在输入图像中检测到人体的确定程度。数值越大表示置信度越高。
Keypoints keypoints - 根据是否启用 Body 3D，输出人体关键点的 UV 或 XYZ 位置。
Keypoints Confidence keypointsconfidence - 输出一个通道，描述 AI 模型对每个关键点的检测确定程度。数值越大表示置信度越高。
Rotations rotations - 输出人体每个关键点的 rx、ry 和 rz 值。(0,0,0) 表示人体正对着摄像机。值域为 +/- 180 度。
Body 3D body3d - 如果启用了关键点，则为每个关键点输出 XYZ 位置而非 UV 位置。
Field of View (Horz) fov - 如果启用了 Body 3D，fov 是拍摄传入 Body Track 的图像的摄像机的视野。
Aspect Correct UVs aspectcorrectuv - 重新缩放 u、v 位置，使其具有输入图像正确的宽高比。当把 u、v 位置用作 3D 坐标而非图像位置时，这很有用。
Mirror U Positions flipskelu - 翻转 UV 的 u 坐标，使 1.0 变为 0.，0. 变为 1。
People Tracking peopletracking - 跟踪输入图像中的多个人。每个人都有一个持久 ID，可通过 Bounding Boxes 开关访问。
Max Bodies maxbodies - Maxine SDK 可跟踪的最大人数。达到新的最大跟踪目标数后，任何新目标都会被丢弃。此参数不影响 CHOP 的输出通道数。此参数没有上限；不过当前版本的 SDK 一次最多只能跟踪 8 个人。
Shadow Tracking Age shadowtrackingage - 一旦先前跟踪到的 body 不再被检测到，内部整数会被重置，并每帧递增一。shadow tracking age 是该整数的阈值，超过后该 body 会被丢弃且不再跟踪。此属性以帧数为单位，默认为 90。
Probation Age probationage - 此选项是跟踪器考察期的长度。body 达到此年龄后即被视为有效，并被分配一个 ID。这有助于减少误报，即仅在少数几帧中检测到虚假 body 的情况。此值以帧数为单位，默认为 10。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
