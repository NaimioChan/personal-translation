优化的 Python 表达式

概述

优化的 Python 表达式

从 2018.20000 系列版本开始，TouchDesigner 中内置了一个自定义的 Python 表达式执行引擎。该引擎会解析参数中的 Python 表达式。假设该表达式中使用的成员和方法都属于该引擎已知的范围，它就会在不使用 Python 引擎的情况下求值表达式。这通常使表达式的求值时间约为通过常规 Python 引擎求值时的 1/4。

此功能的目标不是用该引擎求值每一个参数表达式，而是求值最常用的表达式。你可以把鼠标停在参数名上，判断表达式是否由该引擎求值。弹出的提示中会显示 (Optimized) 或 (Unoptimized)。Perform CHOP 有一个参数用于监视已优化表达式的数量。

如果某个表达式导致错误，引擎就会停止用于该表达式，改用 Python 引擎。如果表达式被修改，或在下次加载文件时，TouchDesigner 会再次尝试用该引擎求值该参数。

缓存的 Python 表达式

除了优化的表达式之外，还有一个缓存表达式结果的新系统，可避免它们每帧重新计算。Perform CHOP 有若干参数用于监视已缓存表达式的数量。

该引擎能求值什么

Python 表达式被解析时会拆分为词元（token）。一个词元可以是常量布尔值 True，也可以是常量字符串。词元也是表达式中的方法、成员和变量名。引擎有一组它能识别的词元，如果表达式只包含这些词元，它就能求值该表达式。如果表达式中含有任何它不认识的词元，它就不会尝试求值，而会使用常规 Python 引擎。

只要表达式只包含引擎能识别的词元，表达式的大小和复杂度就没有限制。

例如，这个表达式可以由优化表达式引擎求值： 

 op(‘geo1’).par.tx + math.max(parent().par.tx + op(‘speed1’)[0], 10) / int(op('table1')['header', 5])
