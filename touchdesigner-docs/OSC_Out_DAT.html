OSC Out DAT

摘要

OSC Out DAT 用于在远程计算机之间通过 OSC 连接发送信息。使用 .sendOSC() python 方法输出 OSC 消息。

OSC bundle 让你可以在一条命令中发送一组消息，而不是作为各自独立的消息发送。当你设置 kwarg asBundle=True 时，OSC Out DAT 的 sendOSC() 函数会接受消息列表并以 bundle 形式发送。 Bundles 最初是作为性能优化而创造的，用于实时控制具有大量参数的合成器。（感谢 Jesse Gilbert）

另请参阅 OSC、OSC In DAT、OSC In CHOP、OSC Out CHOP、iOS and OSC、Network Protocols、Sync。

NOTE for Windows OS - If experiencing connection issues make sure Windows Firewall is disabled.

参数 - Connect 页

Active active - 开启时，DAT 从网络端口接收/向网络端口发送信息。关闭时不会更新。发送到该端口的数据会丢失。
Protocol protocol - - 选择要使用的网络协议。更多信息参见 Network Protocols 一文。
  • Messaging (UDP) msging -
  • Multi-Cast Messaging (UDP) multicastmsging -
  • Reliable Messaging (UDT Library) reliablemsging -
Network Address address - 使用 UDP 时目标计算机的网络地址。对于 multi-cast，这是要发送到的 multi-cast 地址。该地址是标准的 WWW 地址，例如 'foo' 或 'foo.bar.com'。你可以填 IP 地址（如 100.123.45.78）。如果填「localhost」，表示管道的另一端在同一台计算机上。
Port port - 要发送到的网络端口。
Local Address localaddress - 指定发送所用的 IP 地址，当系统有多块网卡（NIC，Network Interface Card）而你想选择使用哪一块时很有用。
Shared Connection shared - 使用与其他使用相同网络协议的联网 DAT 相同的连接。
OSC Address Scope addscope - 要减少生成的通道，可以使用通道名称模式来包含或排除通道。例如，^*accel* 会排除来自 mrmr 之类 iOS 或 iPhone 应用的加速度计通道。可用通道名称模式的语法参见 Pattern Matching。
Include Type Tag typetag - 在每条消息中包含参数列表类型标签。它包含参数类型关键字（以防解析应用需要识别参数类型）。
Split Bundle into Messages splitbundle - 开启时，bundle 中包含的每条消息各占一行。
Split Message into Columns splitmessage - 开启时，OSC 地址和参数各有独立列，否则它们包含在 message 列中。
Bundle Timestamp Column bundletimestamp - 开启时，每个 bundle 的时间戳值会包含在一列中。

参数 - Received Messages 页

Callbacks DAT callbacks - Callbacks DAT 会为收到的每条消息执行一次。
Execute from executeloc - 决定脚本的运行位置。
  • Current Node current - 脚本从当前节点位置执行。
  • Callbacks DAT callbacks - 脚本从 Callbacks DAT 参数中指定的 DAT 位置执行。
  • Specified Operator op - 脚本从下方 From Operator 参数指定的操作符中执行。
From Operator fromop - 当 Execute from 设为 Specified Operator 时，其状态变化会触发 DAT 执行脚本的操作符。若 Execute From 参数设为 Specified Operator，此操作符也是脚本执行的路径起点。
Clamp Output clamp - 该 DAT 默认限制为 100 条消息，但使用 Clamp Output 可以设为任意值，包括无限制。
Maximum Lines maxlines - 限制消息数量，较旧的消息会先从列表中移除。
Clear Output clear - 删除除标题外的所有行。若要用 python 脚本清除 op("opname").par.clear.pulse()
Bytes Column bytes - 在单独的列中输出消息的原始字节。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

OSC Out DAT 的额外信息可以通过 Info CHOP 访问。

OSC Out DAT 特有的信息通道

  • messages_pending -

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
