创建密钥

创建密钥

本节介绍在计算机可连接互联网时为 TouchDesigner 创建并安装密钥。如果计算机没有网络连接，请参见下方的 Offline 一节。

  1. 在 Key Manager Dialog 顶部选择 Create 选项。
  2. 使用你的 Derivative 账户用户名和密码登录。点击 Sign In 按钮。
  3. 在接下来的对话框中，会显示你账户中所有可用的许可证。选择要用来创建密钥的许可证，然后点击 Create Key 按钮。灰显的许可证需要 updated 后才能与已安装的版本配合使用。

密钥将被创建并安装，然后就可以使用了。

离线 - 创建密钥

ONLY Use this method if your computer is offline. To disable the key in the future you will need an internet connection.

本节介绍在计算机无法连接互联网时创建并安装密钥。

如果 TouchDesigner 所在计算机无法连接互联网，可以在另一台联网设备上为其创建密钥。

1. 在需要创建密钥的计算机上，记下 Key Manager 对话框底部附近的 Machine Name 和 System Code。

2. 前往 MY ACCOUNT 并登录。前往 MY LICENSES。


3. 找到你想用来创建新密钥的许可证。该许可证不能正在另一台计算机上使用（如果正在使用，请参见「禁用密钥」）。


4. 点击该许可证以展开其 Details。点击 Create Key 按钮继续。

5. 在弹出对话框中，输入显示在 Key Manager 对话框底部的计算机信息。准备好后点击 Generate，密钥就会被创建。


6. 复制密钥并粘贴到 Key Manager 对话框的 Install 区域。点击 Install Key 按钮，就可以使用了！
