Par 类

Par 类描述单个 Parameter 的实例。另请参阅 Custom Parameters。

成员

owner → OP (Read Only):

此对象所属的 OP。

val → Any :

仅获取或设置参数的 constant mode value。重要： 要获取参数当前实际生效的值，无论其 Parameter Mode（常量、表达式、导出或绑定）如何，请始终使用下面 below 所述的 eval() 方法。 

op('geo1').par.tx.val   # 常量值
op('geo1').par.tx.eval()   # 求值后的参数
op('geo1').par.tx.val = 5
op('geo1').par.tx = 5  # 与上面等价，写法更简洁
op('parexec1').par.op = [parent(), parent(2)] # 对于允许多个操作符的参数，可以赋一个 OP 列表

设置此成员时，参数也会被置于常量模式。见下面的 mode 成员。

要按其索引设置菜单值，请使用下面所述的 menuIndex 成员。

expr → str :

仅获取或设置未求值的表达式。要获取参数的当前值，无论其 Parameter Mode（常量、表达式、导出或绑定）如何，请使用下面所述的 eval() 方法。 

op('geo1').par.tx.expr = 'absTime.frame'  # 设置成与当前帧一致

设置此成员时，参数也会被置于表达式模式。见下面的 mode 成员。

注意： 为方便起见，表达式用双引号括起，这样你可以安全地放入包含单引号的表达式。'a' 和 "a" 在 Python 中括起字符串的效果相同。

enable → bool :

获取或设置参数的启用状态。只能设置在 Custom Parameters 上。

TouchDesigner 2023.30000+

如果参数位于含多个参数的 ParGroup 中，这只获取/设置该单个参数的启用状态。在以前的 TouchDesigner 版本中，这会获取/设置整个 ParGroup 的启用状态。

enableExpr → str :

获取或设置控制此参数启用状态的表达式。此成员由所有参数和参数组共享。 

p.enableExpr = "me.par.X.menuIndex == 5"
# 注意外层的引号，因为这是表达式而非对象。

TouchDesigner 2023.30000+

如果表达式是 lambda 函数，它会为参数组中的每个参数调用一次，以索引作为参数…… 

rgbaPar.enableExpr = "lambda parIndex: parIndex < 3" # 启用前 3 个元素
rgbaPar2.enableExpr = "lambda parIndex: parIndex >= 3" # 启用第 4 个元素

readOnly → bool :

获取或设置参数的只读状态。为 True 时，无法通过 UI 修改参数，只能用脚本。

bindExpr → str :

获取或设置一个返回可绑定对象的表达式。可用于把此参数的常量值绑定到所引用对象的值。 

p.bindExpr = "op('geo1').par.tx"

注意外面的引号，因为 bindExpr 是表达式，不是对象。

bindMaster → OP (Read Only):

此参数所绑定到的对象，可能为 None。

bindReferences → list (Read Only):

绑定到此参数的对象列表（可能为空）。

bindRange → bool :

获取或设置参数的范围绑定状态。若为 True，min、max、clampMin、clampMax、normMin、normMax、normVal 值会基于主绑定参数。只能设置在自定义参数上。

vecIndex → int (Read Only):

参数的向量索引。例如，op('geo1').par.tz 的值为 2。

name → str :

获取或设置参数的唯一名称。 

op('myOperator').par.Custompar.name = 'Translate'

只能设置在 Custom Parameters 上。

label → str :

获取或设置参数的标签。 

op('myOperator').par.Custompar.label = 'Translate'

只能设置在 Custom Parameters 上。

subLabel → str (Read Only):

返回子标签的名称。

startSection → bool :

获取或设置参数的分隔符状态。为 True 时，会在此参数与其前面的参数之间绘制可见的分隔符。只能设置在 Custom Parameters 上。

help → str (Read Only):

获取或设置自定义参数的帮助文本。要查看任何参数的帮助，按住 Alt 键把鼠标悬停在参数上。对于内置参数，可用此项获取其帮助文本。

parGroup → ParGroup (Read Only):

此参数所属的参数 ParGroup。ParGroup 是一组在参数对话框中共用一行、共享同一标签的参数，例如 Translate (x, y, z)..

min → int :

获取或设置参数的数值最小值。若 clampMin = True，参数值会被限制在该最小值。只能设置在 Custom Parameters 上。

max → int :

获取或设置参数的数值最大值。若 clampMax = True，参数值会被限制在该最大值。只能设置在 Custom Parameters 上。

clampMin → bool :

获取或设置参数的数值钳制行为。若设为 clampMin = True，参数会在下端按 min 中指定的值钳制。只能设置在 Custom Parameters 上。

clampMax → bool :

获取或设置参数的数值钳制行为。若设为 clampMax = True，参数会在上端按 max 中指定的值钳制。只能设置在 Custom Parameters 上。

normMin → int :

若参数是数值滑块，获取或设置参数的最小滑块值。只能设置在 Custom Parameters 上。

normMax → int :

若参数是数值滑块，获取或设置参数的最大滑块值。只能设置在 Custom Parameters 上。

normVal → float :

以归一化滑块位置获取或设置参数的值。只能设置在 Custom Parameters 上。

default → Any :

获取或设置参数的默认值。只能设置在 Custom Parameters 上。

defaultBindExpr → str :

获取或设置参数的默认绑定表达式。只能设置在自定义参数上。 

op('base1').par.Size.defaultBindExpr = 'me.par.tx'

defaultExpr → str :

获取或设置参数的默认表达式。只能设置在 Custom Parameters 上。 

# 该值默认取此表达式。
op('base1').par.Size.defaultExpr = 'me.time.frame'

defaultMode → ParMode :

获取或设置参数的默认求值模式。 

op('geo1').par.tx.defaultMode = ParMode.EXPRESSION

模式为以下之一：ParMode.CONSTANT、ParMode.EXPRESSION、ParMode.EXPORT 或 ParMode.BIND。

更多信息见 Parameter_Dialog#Working_with_Parameter_Modes。

order → float :

获取或设置参数在参数页上的位置。只能设置在 Custom Parameters 上。

page → td.Page :

获取或设置自定义参数所属的参数页。只能设置在 Custom Parameters 上。

sequence → Sequence | None (Read Only):

此参数所属的 Sequence。若不在序列中则为 None。

sequenceBlock → SequenceBlock | None (Read Only):

此参数所属的 SequenceBlock。若不在序列中则为 None。

password → bool :

获取或设置参数的密码模式。为 True 时所有文本都渲染为星号。只能设置在自定义的 string、int 或 float 参数上。Custom Parameters。

mode → ParMode :

获取或设置参数的求值模式。 

op('geo1').par.tx.mode = ParMode.EXPRESSION

模式为以下之一：ParMode.CONSTANT、ParMode.EXPRESSION、ParMode.EXPORT 或 ParMode.BIND。

更多信息见 Parameter_Dialog#Working_with_Parameter_Modes。

prevMode → ParMode (Read Only):

参数之前的求值模式。

menuNames → list :

获取或设置所有可能菜单选项名称的列表。对于非菜单参数，返回 None。只能设置在 Custom Parameters 上。

menuLabels → list :

获取或设置所有可能菜单选项标签的列表。对于非菜单参数，返回 None。只能设置在 Custom Parameters 上。

menuIndex → int :

按索引获取或设置菜单常量值。

menuSource → str :

获取或设置一个返回带 .menuItems、.menuNames 成员对象的表达式。例如，可用于创建条目动态跟随另一个菜单的自定义菜单。简单的菜单源包括另一个带菜单的参数，或由 tdu.TableMenu、tdu.ParMenu 创建的对象。 

p.menuSource = "op('audiodevin1').par.device"

注意外面的引号，因为 menuSource 是表达式，不是对象。

exportOP → OP (Read Only):

导出到此参数的 operator。

exportSource → Channel (Read Only):

导出到此参数的对象。例如：Cell、Channel 或 None。

collapser → bool (Read Only):

若参数是可折叠参数的父级（即可折叠组），则返回 True。

collapsable → bool (Read Only):

若参数可折叠，则返回 True。

styleCloneImmune → bool :

获取或设置参数的样式克隆免疫。为 False 时，参数定义会匹配其操作符被克隆到的任何匹配主参数。为 True 时，保持不变。

lastScriptChange → tuple (Read Only):

返回关于此参数上次被脚本修改的信息。通过 UI 更新参数时会被清除。 

python >>> op('/level1').par.invert.lastScriptChange
SetInfo(dat=type:textDAT path:/text1, function='<module>', line=1, frame=300061, timeStamp=1613150878)

菜单参数

菜单参数可以通过指定菜单的字符串值或其数字索引来获取或设置。例如，以下写法等价：

op('geo1').par.xord = 'trs'
op('geo1').par.xord = 5

另一种方式是更直接地访问菜单：

n = op('geo1')
n.par.xord.menuIndex = 5  # trs
a = n.menuNames[0]  # 返回 'srt'
b = n.menuLabels[0] # 返回 'Scale Rotate Translate'

方法

eval()→ Any:

计算参数。该值可能来自参数的常量值、表达式、导出或绑定，取决于其模式。

a = op('geo1').par.tx.eval()

对可容纳多个 OP 的 OP 参数调用 eval 时：只有 1 个结果则返回单个 OP，多于 1 个则返回 OP 列表，没有结果则返回 None。

evalNorm()→ float:

类似于 eval()，但返回归一化的滑块值。

evalExpression()→ Any:

计算参数的表达式部分（如果包含的话）。将忽略导出等。

a = op('geo1').par.tx.evalExpression()

注意：evalExpression 的结果始终是表达式的 Python 返回值，可能与 Par.eval() 略有不同。例如，在存放操作符的参数中，只要操作符存在，.eval() 总是返回操作符，即使表达式实际返回的是字符串路径。而 evalExpression 函数会返回该字符串路径。

要计算不在参数内的任意表达式字符串，请参阅 OP.evalExpression。

evalExport()→ Any:

计算参数的导出部分（如果包含的话）。将忽略表达式等。

a = op('geo1').par.tx.evalExport()

evalOPs()→ List[OP]:

将参数计算为一系列操作符。例如，对于指定操作符路径列表的自定义参数，这很有用。

a = op('base1').par.Paths.evalOPs()

evalFile()→ tdu.FileInfo:

将参数计算为文件路径。返回带有完整路径的 FileInfo 对象。

a = op('moviefilein1').par.file.evalFile()
print(a.ext)
print(a.baseName)
print(a.exists)

pulse(value=1, frames=0, seconds=0)→ None:

脉冲会将参数设为指定值，计算该操作符，然后将参数恢复为之前的值。

对于脉冲类型参数，不指定也不使用值或时间。

  • value - （可选）用于脉冲此参数的值，默认为 1。
  • frames - （可选）在将参数恢复为原始值之前经过的帧数。
  • seconds - （可选）在将参数恢复为原始值之前经过的秒数。
op('moviein1').par.reload.pulse(1) # 设置 reload 开关，然后 cook
op('glsl1').par.loadvariablenames.pulse() # 激活 pulse 参数
op('geo1').par.ty.pulse(2, frames=120) # 对 geometry 的 ty 参数 pulse 120 帧
op('text1').par.text.pulse('GO!', seconds=3) # 将 text TOP 的字符串字段 pulse 3 秒
op('noise').par.type.pulse('random', seconds=0.5) # 对 noise 的 menu 类型参数 pulse 半秒

reset()→ bool:

将参数重置为默认状态。

如果有任何改动则返回 true。

op('geo1').par.tx.reset()

copy(Par)→ None:

复制指定的 parameter。

  • Par - 要复制的参数。
op('geo1').par.tx.copy( op('geo2').par.tx )

destroy()→ None:

销毁此 Par 所引用的参数。如果该参数已被销毁，将抛出异常。只能销毁自定义参数和顺序参数。销毁顺序参数会销毁其整个块。注意：任何参数被销毁后，现有的参数对象都会失效，需要重新获取。

isSamePar(par : Par)→ bool:

如果提供的 Par 是同一操作符上的同一参数，则为 True。由于 op('container1').par.x == op('container2').par.x 比较的是值，而 op('container1').par.x is op('container1').par.x 始终为 False（因为 TouchDesigner 的内部实现），必须使用 isSamePar 来比较参数对象。同样，op('container2').par.Myfloat in op('container2').customPars 会返回不可靠的结果。

  • par - 要比较同一性的参数。

转换为值

Par 类实现了被视为数字或字符串所需的全部方法，此时即获取或设置其值。因此，在参数中或数值表达式中使用时，无需显式调用 eval() 或 set()。

例如，在参数中以下写法等价：

  • (float)me.par.tx
  • me.par.tx.eval()
  • me.par.tx

以下写法也等价：

  • me.par.tx.eval() + 1
  • me.par.tx + 1

以下同样如此：

  • me.par.tx.val = 3
  • me.par.tx = 3

注意：但是，如果不计算参数，就无法使用属于转换后对象类型的函数：

  • me.par.tx.hex() # doesn't work
  • me.par.tx.eval().hex() # works!
