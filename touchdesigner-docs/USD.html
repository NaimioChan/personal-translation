USD

OpenUSD 或简称 USD 指 Universal Scene Description，它是一套用于定义、合成和读取层级场景描述的制作流程。它由 Pixar 开发，是其 3D 图形管线的核心。USD 提供模型和镜头的场景描述，供多种第三方创作应用、渲染器、NVIDIA GPU 应用以及 Pixar 的渲染应用使用。

TouchDesigner 的 USD COMP 可加载并导入 USD 文件中大多数几何 schema，支持 crate/二进制或 ASCII 文件格式，扩展名为（.usd）、（.usda）、（.usdc）和（.usdz）。

USD 便于多位艺术家或内容创作者协作处理同一场景和资产。这意味着他们可以制作自己的组装、打包、编辑资产和数据，或定义 variant set，以获得可切换的离散场景树备选方案。

有关 USD 特性和 API 的详细说明，请参阅 https://openusd.org/docs/

示例：https://developer.apple.com/augmented-reality/quick-look/

TouchDesigner 目前使用 USD 版本 25.05.01。
