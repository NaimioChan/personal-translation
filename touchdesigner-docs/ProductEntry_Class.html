ProductEntry 类

用于与系统中单支加密狗的加密狗条目交互的类。

成员

licenseType → int (Read Only):

返回加密狗上该产品条目的许可证类型。

updateDate → tuple[int, int, int] (Read Only):

该产品条目的有效期。返回 (YYYY, MM, DD) 形式的元组。

version → str (Read Only):

该加密狗产品条目适用的 TouchDesigner 版本。

方法

没有该操作符专属的方法。
