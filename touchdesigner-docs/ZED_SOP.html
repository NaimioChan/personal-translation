ZED SOP

摘要

注意

OS: 此操作符仅在 Microsoft Windows 操作系统下受支持。

ZED SOP 使用 ZED，通过在房间或感兴趣物体周围移动来扫描并创建几何。要了解我们使用的 ZED SDK，请参阅 ZED 一文。

请参阅 ZED TOP、ZED CHOP、ZED POP 和 ZED。

zedSOP_Class

参数 - 页

ZED TOP zedtop - 配置该摄像机的主 ZED TOP 的名称。主 TOP 决定该 SOP 从哪个摄像机接收数据。
Sample sample - 启用期间，ZED 摄像机在空间中采样点。禁用后，它会根据这些点生成表面，以及任何法线或纹理属性。
Reset reset - 清除已提取的几何并重置空间映射。
Reset Pulse resetpulse - 在按钮释放时（button-up）立即触发 Reset。可通过 python 使用 pulse() 方法访问。
Preview preview - - 选择摄像机采样时预览的细节级别。
  • No Preview nopreview - 摄像机采样时不显示预览。
  • Limited Preview limited - 预览的细节级别受限。
  • Full Preview full - 预览显示所有可用点。
Maximum Memory maxmemory - 设置用于空间映射的最大内存。
Resolution resolution - 设置摄像机使用的空间映射分辨率。较小的分辨率会生成细节丰富的几何，较高的分辨率只保留几何中较大的变化。
Range range - 设置空间映射后将从摄像机中提取的物体的距离范围。较小的深度范围会使用靠近摄像机的物体，较大的深度范围会使用离摄像机较远的物体。
Normals normals - 启用后，提取的几何将带有法线。
Texture texture - 启用后会创建网格的空间映射纹理和纹理坐标。空间映射纹理可使用 ZED TOP 获取。
Filter filter - - 设置网格的过滤级别。
  • Low low - 几何中的小孔会被移除。
  • Medium medium - 几何将被平滑处理。
  • High high - 几何中的三角形数量将被减少，几何将被平滑处理。
Consolidate Points consolidatepts - 启用后，彼此靠近的多余点会被合并。

Info CHOP 通道

ZED SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
