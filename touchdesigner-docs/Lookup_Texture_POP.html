Lookup Texture POP

摘要

Lookup Texture POP 最简单的形式是：取两个属性（Lookup Attribute U 和 Lookup Attribute V），其值在 0-1 范围内，然后对每个点，把属性值作为索引查入 TOP 的像素，取出四个 RGBA 值，并把这些值放入 POP 属性。

若 U 索引为 0，则从 TOP 的第一列取值；若索引为 1，则从 TOP 的最后一列取值。若 Lookup Index Units 菜单设为 Pixel Index，则查找索引可用像素编号表示，从 0 到 imagewidth-1。

若索引超出范围，Extend Left 和 Right 菜单决定在做查找之前如何处理索引，例如将其保持在 0 或 1，或在 0 与 1 之间循环。

Output Attribute Scope 参数决定取回每个 RGBA 像素值后如何处理——你可以先把值重映射范围，再放入指定的输出属性。

可在 Lookup Attribute W 参数中包含属性分量名称，从而查找 3D 纹理 TOP。

另请参阅 Lookup Attribute POP、Lookup Channel POP、Curve POP（Lookup 页）
