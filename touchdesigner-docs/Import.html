导入

TouchDesigner 可以导入多种媒体和数据文件类型。支持的文件类型列表以及它们会被转换成的 Operators，请参阅 File Types。

你可以将文件拖放到 TouchDesigner 网络中来进行导入。

在菜单栏上，通过 File → Import File... 使用 Import File Dialog 导入

FBX .fbx 格式的几何和场景文件也通过 File → Import File... 导入，它会将 .fbx 文件转换为相应的 Object 组件和 SOP 操作符。你可以选择从原文件中导入摄像机、灯光等数据。
