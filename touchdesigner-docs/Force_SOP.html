Force SOP

摘要

Force SOP 向输入的 metaball 场添加力属性，该场被 Particle SOP 或 Spring SOP 用作吸引或排斥力场。一般来说，大于 0 的力值会使点被吸引，小于 0 会使点被排斥。

forceSOP_Class

参数 - 页

Radial Force doradial - 勾选后，根据力的数值触发朝向或远离 metaball 场中心的力。
Force radial - 勾选 Radial Force 时，控制径向力场的强度。
Directional Force doaxis - 勾选后，启用下面所有参数，以便控制特定的力属性。
Direction dir - 勾选 Directional Force 时，确定方向向量轴，并为下面的定向力激活沿方向向量的力。
  • X dirx -
  • Y diry -
  • Z dirz -
Axial Force axial - 勾选 Directional Force 时，控制沿主轴方向的力。增大此值会使粒子沿方向向量所定义的 metaball 场主轴移动。
Vortex Force vortex - 勾选 Directional Force 时，此字段控制粒子绕主轴获得的扭量。正值使粒子顺时针旋转，负值使其逆时针旋转。这是一种离心力。
Spiral Force spiral - 控制垂直于主轴（Direction 字段）的吸引/排斥力。大于 0 的值会使点被拉向主轴。小于 0 的值使粒子沿垂直于主轴的方向被推开。这是一种切向力。

提示

要查看 metaball 的影响场，请打开输入 metaball 对象的 hulls 显示。Particle SOP 和 Spring SOP 都会把这些 hull 显示为辅助几何。

调整 metaball 输入的权重，以增强或减弱 metaball 影响场内的场效应。

一般来说，最好尽量把力和力场的尺度保持在较小的范围而不是较大。这往往能让粒子运动和吸引更可控、更真实。

Info CHOP 通道

Force SOP 的额外信息可以通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
