NotchLC

NotchLC（更多信息 here）是一种高质量、GPU 加速的视频格式。它的质量高于 HapQ，但代价是更高的 GPU 占用和更大的文件体积。它还提供 10 位色彩输出。

Movie File In TOP 读取并解码 NotchLC 影片文件，而 Movie File Out TOP 将 NotchLC 编解码器编码进影片文件。

Movie File Out TOP 中的「Quality」滑块会在各种 NotchLC 质量设置之间线性混合。质量 1.0 等同于 NotchLC 的「Best」质量，0.0 等同于 NotchLC 的「Good」质量。使用以下数值即可与其他质量等级对应：

质量设置
NotchLC Quality Name Quality Parameter Value
Good 0.0
Good Very 0.285
Excellent 0.575
Optimal 0.862
Best 1.0
