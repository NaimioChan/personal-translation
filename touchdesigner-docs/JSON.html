JSON

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，便于人阅读和编写，也便于机器解析和生成。它基于 JavaScript 编程语言规范的一个子集。

在 TouchDesigner 中可以读取、写入、过滤和操作 JSON。参见 JSON DAT 和 TDJSON。
