纹理过滤

概述

GPU 渲染贴有纹理的几何时会发生纹理过滤。仅仅查看纹理时（例如在 TOP 查看器中）也会发生。纹理过滤用于在渲染分辨率与原生分辨率不同时让纹理看起来更好。要理解纹理过滤如何工作，请先确保你理解 Texture Coordinates and Texture Sampling 的工作原理。 纹理过滤主要有 3 种类型：

Nearest - Nearest 过滤只取最接近当前采样纹理坐标的那一个像素的颜色。Nearest 过滤会让图像看起来更像素化，但在追求像素级精确时很有用。

Linear - Linear 过滤也称插值，会混合 GPU 当前采样坐标最近的 4 个像素。该混合是线性混合，坐标越接近的像素权重越大。

Mipmap Linear - Mipmap linear 也称 Trilinear，是 Linear 过滤再加上在两个不同 mipmap 层级之间采样与混合。更多信息请参阅关于 Mipmapping 的文章。

在 TouchDesigner 中控制纹理过滤

根据纹理的使用位置，TouchDesigner 中有多处可以控制纹理过滤。

在 TOP 中

每个 TOP 的 Common 页上有两个与纹理过滤有关的参数。

Input Smoothness - 此参数控制执行该节点的操作时，输入到该节点的 TOP 如何被过滤。如果输入 TOP 的分辨率与当前 TOP 的分辨率相同，此参数不会起作用（因为像素会完全对应）。

Viewer Smoothness - 此参数影响在 TOP 查看器和网络背景中绘制纹理时的过滤方式。它不影响节点的实际纹理数据，只影响在 TOP 查看器中查看图像时的样子。此参数不影响使用 MAT 渲染时纹理如何被采样。MAT 有自己的参数来控制 TOP 如何被采样。

这两个参数都有两个选项：

Nearest Pixel - 这是 Nearest 过滤。
Interpolate Pixels - 这是 Linear 过滤。
Mipmap Pixels - 这会使用 Mipmap 以不同尺寸显示纹理。参见 Mipmapping。

为什么要用 Mipmap？缩小图像时，会合并一个或多个像素来得到每个新像素。缩小时，Nearest Pixel 和 Interpolate Pixel 不会考虑所有像素。TOP 以 Mipmap 方式对输入进行采样，在图像被缩小时（无论是降低图像分辨率，还是通过 Corner Pin Transform 之类的 TOP 缩小）能更好地平均像素。

在 MAT 中

在 MAT 中，每个接受 TOP 作为输入的参数旁边都有一个 + 按钮。按下此按钮会弹出一个对话框，其中包含该纹理在此 MAT 中如何使用的各种设置。

Filter Type 参数控制这一特定纹理的过滤。三个选项是：Nearest、Linear 和 Mipmap Linear。Mipmap linear 是默认值。如果该 TOP 没有生成 mipmap，MAT 会自动对此 TOP 使用 Linear 过滤。通常你只需让此设置保持 Mipmap Linear。

其他纹理采样方法

除了这些方法，Anisotropic Filtering 还可用于提升带纹理几何的视觉质量。各向异性过滤（Anisotropic Filtering）是一种考虑多边形相对摄像机朝向角度的过滤方法，依据该信息改变纹理过滤方式。更多信息请参阅 Anisotropic Filtering 文章。
