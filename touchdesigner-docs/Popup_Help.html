弹出帮助

Popup Help 是帮助信息的名称，它在以下情况出现：（1）把光标移到 TouchDesigner 用户界面上；（2）点击每个操作符 Parameters 页角落的 _? 帮助按钮；（3）按住 Alt 键同时把光标移到 Parameter 对话框中的参数名上。弹出帮助提供与上下文相关的帮助和 TouchDesigner 使用提示。

Popup Help on Expressions - 在参数中使用 python 表达式时，对表达式中任何部分选中的内容都会显示弹出帮助。例如，对于表达式 me.time.seconds*2，你可以选中高亮表达式中的 me.time.seconds 部分，me.time.seconds 的结果就会出现在弹出帮助中。
