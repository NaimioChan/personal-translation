投影映射

以下是 TouchDesigner 中投影映射的几种形式及对应解决方案。多数位于 Palette 的 Mapping 下，其他则是 TouchDesigner 中的特定操作符类型。

Kantan Mapper

Kantan Mapper 是一个投影映射与遮罩工具，你可以在投影仪的视野中定义 2D 多边形和贝塞尔轮廓，然后用选定的图像（TOP）填充每个形状。

Kantan UV Helper

Kantan UV Helper 是 Kantan Mapper 的附加工具，用于利用 Kantan 的第二个 UV Map 输出。使用该 Helper 可以减轻处理时间，因为 Kantan 本身不再参与渲染过程。

CamSchnappr

CamSchnappr - 如果你有一个实体 3D 结构以及该结构的虚拟 3D 模型，可以通过在投影图像中选择并移动 6 个引导点，把渲染的虚拟模型完全对齐地投影到该实体结构上。它支持带混合区域的多个投影仪。

Projector Blend

projectorBlend - 一个用于平滑混合 NxM 投影仪阵列的工具。

Stoner

Stoner - 交互式角点固定图像变形器，外加用于手动将图像适配到实体 3D 表面的网格变形器。

Corner Pin SOP

CornerPinSOP - 此调色板组件是用于 SOP 的暴力角点固定组件。在固定激光角点时也可能有用。

Quad Reproject

quadReproject - QuadReproject 用于 LED 屏幕（或任何像素阵列），可渲染像素完美的图像，并从相对于 LED 屏幕的任意观看位置渲染。

Vioso

Vioso 与 TouchDesigner 集成，可读取 VIOSO Calibrator 软件的校准数据。Vioso 的自动对齐技术使多投影仪全景显示、穹顶以及用于投影映射的多投影仪装置等安装的搭建更加自动化和快捷。

Scalable Dislays

Scalable Displays - Scalable Display TOP 可加载运行 Scalable Display Calibration 软件所获取的校准数据。

Sweet Spot

sweetSpot 是一种更常被称为 Trompe-l'œil 的技术，它从观察者的位置渲染场景，再重新投影到表面上。为大幅面投影、环绕环境或带跟踪的显示器装置创建的结果，从 sweet spot 的大致区域观看时，看起来会接近透视正确。若需像素完美、透视正确的结果（更适合 XR Stage 环境中的 LED 屏幕），还请查看 Camera COMP's Quad Reprojection 功能。

Kinect 校准

Kinect Calibration 组件是一个借助棋盘格将 Kinect 摄像机校准到投影仪的示例。它使用了与 camSchnappr 相同的技术，因为可以从其点云中获取 3D 坐标。

Corner Pin TOP

Corner Pin TOP - 基础角点固定。
