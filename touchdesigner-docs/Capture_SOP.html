Capture SOP

摘要

Capture SOP 用于把几何中的点加权到捕获区域。权重方案在下一节 Capture Region SOP 中说明。

权重及其对应的区域会以点属性和细节属性的形式沿 SOP 链向下传递。

Capture SOP 可以接受一个可选的第二输入，用于指定捕获过程中要使用的额外捕获区域。第二输入中的捕获区域会在 Hierarchy 参数所指定对象层级中的捕获区域之后处理。也可以只指定第二输入而完全不指定 Parent Object。

captureSOP_Class

参数 - Capture 页

Group group - 指定要对第一输入（input0）中的哪些点组进行操作。
Hierarchy rootbone - 会遍历对象层级来找到用于加权的 Capture Region。此参数指定遍历层级的顶层。
Weight from weightfrom - 使用此菜单指定权重的来源。
  • Surface surface -（默认）使用曲面来计算点的权重（对 NURBS 而言是 CV 的权重）。当 CV 可能远离曲面时，这对 NURBS 曲面非常有用。使用 Weight From Surface 时，每个 CV 根据曲面在 Capture Region 中的位置加权。具体做法是计算该 CV 在 NURBS 曲面上的「最受影响点」，再计算该位置的权重。
  • Points cv - 选择 Weight From Points 时，使用点在区域内的位置进行加权。
Capture Frame captframe - 指定进行捕获计算的帧号。每当 TouchDesigner 到达此帧，几何就会被重新捕获。常见的做法是把 Capture Frame 设为动画范围之外的帧，例如 -1。指定进行捕获计算的帧号。每当 TouchDesigner 到达此帧，几何就会被重新捕获。常见的做法是把 Capture Frame 设为动画范围之外的帧，例如 -1。

注意： 加载 .toe 文件时，所有关联的捕获区域都会在 Capture Frame 处求值。必须设置关键帧，使捕获区域在 Capture Frame 处处于正确位置，否则后续加载文件时几何的加权会出错。

Point Coloring color - 此选项根据捕获权重，用点属性按捕获区域为每个点上色。点的颜色继承自它所在的 Capture Region。例如，如果一个点同时落在蓝色捕获区域和黄色捕获区域内，该点会呈绿色（蓝色权重占优时更偏蓝，黄色权重占优时更偏黄）。此外，权重越轻，点的颜色越暗。例如在蓝色区域边缘附近，被捕获的点呈深蓝色；在中心附近则呈亮蓝色。如果某个点没有被任何区域捕获，则呈亮红色。
  • Default Source Color coldefault -
  • Color by Capture Region colregion -
Override File captfile - 捕获覆盖文件（*.ocapt）的名称。此文件在 TouchDesigner 完成点加权后加载。覆盖文件的每一行列出一个点编号、一个区域（路径和图元编号）以及一个权重。几何上的点会被修改为使用这些自定义权重。

Override File Format - 覆盖文件中的每一行必须采用以下格式：

例如： 

0 /obj/chain_bone1/cregion 0 0.0 			
0 /obj/chain_bone2/cregion 0 3.757989 			
0 /obj/chain_bone3/cregion 0 1.757989


这把点 0 加权到三个区域（实际上只有两个，因为第一条的权重为零）。请记住，Override File 是在 TouchDesigner 完成自身的捕获权重计算之后读取的，因此在本例中，如果点 0 原本被分配给区域 /obj/chain_bone4/cregion 0，这部分权重将保持不变。 一个点可以加权的区域数量没有上限。如果某个点/区域组合在文件中出现两次，则使用后一条。

例如： 

0 /obj/chain_bone1/cregion 0 1.0			
0 /obj/chain_bone1/cregion 0 2.0

这会使第一条被忽略（使用 2.0 的权重）。

weight 字段用于规定某个区域对一个点的影响相对大小。可以是任意数字。TouchDesigner 计算出的权重范围由每个 Capture Region 的 Inner/Outer Weight 参数指定（请参阅 Capture Region SOP）。 创建捕获 Override File 最简单的方法是使用 Save Override File 按钮（见下文），并从 TouchDesigner 生成的文件开始修改。

参数 - Override 页

Save File savefile - 此处指定的文件可作为「工作文件」，用于保存所有点或所选部分点的点加权。捕获覆盖文件的格式相当直观（见上文），因此如果你需要自定义覆盖，从这里开始是个好选择。
Increment Save File autoincr - 保存前会递增 Save File 名称。关闭此选项时要小心，因为不会有警告或确认对话框来阻止你覆盖 .ocapt 文件。
Save All Data to File savecaptfile - 把所有点的点加权保存到 Save File。
Save Selected Points to File savesel - 仅保存在查看器中选中的点的点加权。

Note: 你必须在 Viewport 中编辑这个 SOP，所选内容才会应用到该 SOP。

Info CHOP 通道

Capture SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
