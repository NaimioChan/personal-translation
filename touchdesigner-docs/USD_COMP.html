USD COMP

摘要

USD COMP 可加载并导入 USD 文件中大多数几何 schema，支持 crate/二进制或 ASCII 文件格式，扩展名为（.usd）、（.usda）、（.usdc）和（.usdz）。目前 USD COMP 中使用的是 USD 版本 25.05.01。你可以将 USD 文件拖放到 TouchDesigner 网络中，或通过 USD File 参数导入。另请参阅 File Types。

来自 USD 文件的资产会保存到 TDImportCache 文件夹中与 USD 文件同名的「.tdc」文件里，该文件夹创建在你的 toe 文件旁边。资产通过 Import Select OP（Import Select TOP / Import Select SOP / Import Select CHOP）从「.tdc」文件读取。重新加载 .toe 文件时，资产可以直接从「.tdc」缓存导入，无需重新导入 USD 文件。但是，如果不存在「.tdc」（例如 toe 文件换了计算机），则会重新打开 USD 文件以抓取资产，并保存新的「.tdc」。

在 USD COMP 中打开 USD 文件：

1）在「USD File」参数中指定有效的文件路径，包括带有正确 .usd 扩展名的文件名。

2）此步骤因 USD COMP 是刚创建还是需要更改参数的默认值而有所不同。如果文件是首次在网络中加载，并且接受默认参数值，则只需按「Import」按钮即可生成 USD 网络并导入资产。注意：我们建议将「Import Method」改为其他模式（工作量更少），这可显著提升性能。通常，第一页上的任何更改都需要通过脉冲 import 重新构建网络。

3) 当「Import Method」菜单设为「Reload Assets (Import Selects)」时，「Import」脉冲会重新加载内部资源（例如网格等）；当文件被移到其他位置、打开 .toe 文件时资源未被找到并正确重载，或文件已更改但没有结构性/层级变化时，这个模式特别有用。

4) 当「Import Method」菜单设为「Merge with Existing」时，「Import」按钮用于在 USD 文件发生某些改动后，把这些改动合并到当前网络中，而不必完全重建。

以下是一些示例：https://developer.apple.com/augmented-reality/quick-look/

另请参阅：USD、USD In TouchDesigner、Import Select CHOP、Import Select TOP、Import Select SOP、FBX COMP

参数 - USD 页

USD File file - USD 文件的路径。文件可以是二进制（.usd 或 .usdc）或 ASCII 格式（.usda）。
Import Method importmethod - - 决定点击下面的 'Import' 按钮时执行什么操作。
  • Full Replacement full - 完全重建 USD COMP 内部的网络，并从 USD 文件重新加载资产。
  • Merge with Existing merge - 将 USD 文件中的任何更改与 USD COMP 的现有内容合并。
  • Reload Assets (Import Selects) reload - 加载到 Import Select 操作符中的资产（几何、纹理、动画）会从 USD 文件重新加载到现有 USD COMP 的网络中。
Import imp - 按上面 'Import Method' 参数的设置导入内容的脉冲。
Use Material usematerial - 一个开关，用于指定是否为所有带有材质绑定的几何图元启用材质/着色。打开此开关后，会生成 MAT 节点，并按需生成用于纹理映射资产的 ImportSelect TOP。
Cameras cameras - 一个开关，用于指定是否为 USD COMP 创建 Camera 节点（前提是在 USD 文件中已定义）。
Generate Actor COMPs genactors - 启用后，将生成 Actor COMP 而非 Geometry COMP，作为 Import Select SOP 的父级。
Merge Geometry mergegeo - 一个开关，用于将可合并的几何 SOP 及其变换 COMP 合并到指定的合并层级。此功能可显著提升 USD COMP 网络的性能。
Merge Level mergelevel - 定义合并节点所需的合并层级。起始值为 1，即网络的根节点；子节点的值随其在树层级中的位置递增。默认情况下此参数禁用，在 Merge Geometry 开关设为 ON 后可启用。
Max Wired Children maxwiredchildren - 此值用于定义 Geometry/Null COMP 节点在同一网络层级上（注意此网络层级指同一画布网络中可见的所有节点）可以拥有多少个连线的子级。如果节点的子级多于此值，其所有子级都会被移入其内部。这用于修剪父节点的连线子节点，使网络更轻量、更整洁。默认值为 5。
Compute Normals computenormals - 一个开关，用于通过 OpenSubdiv 库从 USD 文件中指定的 subdivision schema 生成法线向量。将此开关设为 OFF 会使 SOP 改用 TouchDesigner 生成的法线（仅 CPU 模式）。
Keep Parameters keepparams - 一个开关，用于保留当前网络的参数，而非重新导入（通过 Update 参数）网络的参数。
Import POPs pops - 当为 On 时使用 Point Operators，当为 Off 时使用 Surface Operators 在 USD COMP 内加载几何。
Direct to GPU gpudirect - 一个开关，用于在使用 SOP 时（即上方的「Import POPs」为 Off）将几何直接加载到 GPU。这使渲染比 CPU 模式快得多。但是，目前仅支持 mesh 和 point 图元。如果 USD 场景包含其他图元类型（如 NURBs Patches），则每个不支持的 Import Select SOP 都会产生一个错误。
Keep Parameter Values keepparams - 一个开关，用于保留当前网络的参数，而非重新导入（通过 Update 参数）网络的参数。
Keep Connections keepconnections - 一个开关，用于保留当前网络的连接，而非重新导入（通过 Update 参数）网络的连接。
Callbacks DAT callbacks - Callbacks DAT 会在导入或更新期间执行，便于修改和定制导入的操作符及生成的网络。
Update update - 更新网络。当 USD 文件在 USD 网络导入 TouchDesigner 后被编辑时，此选项特别有用。

参数 - Xform 页

Xform 参数页控制对象组件在世界空间中的变换。

Transform Order xord - 用于指定组件各项更改的发生顺序。更改 Transform Order 会改变最终结果的位置，就像先走过一个街区再向东转，与先向东转再走过一个街区，会到达不同的地方。用矩阵数学的说法，若采用「向量右乘」（列向量）约定，Scale、Rotate、Translate 的变换顺序会写成 T * R * S * Position。
  • Scale Rotate Translate srt -
  • Scale Translate Rotate str -
  • Rotate Scale Translate rst -
  • Rotate Translate Scale rts -
  • Translate Scale Rotate tsr -
  • Translate Rotate Scale trs -
Rotate Order rord - 用于设置组件旋转的变换顺序。与上面的变换顺序一样，更改组件旋转的发生顺序会改变组件的最终位置。Rx Ry Rz 的旋转顺序会生成如下的最终旋转矩阵 R = Rz * Ry * Rx
  • Rx Ry Rz xyz - R = Rz * Ry * Rx
  • Rx Rz Ry xzy - R = Ry * Rz * Rx
  • Ry Rx Rz yxz - R = Rz * Rx * Ry
  • Ry Rz Rx yzx - R = Rx * Rz * Ry
  • Rz Rx Ry zxy - R = Ry * Rx * Rz
  • Rz Ry Rx zyx - R = Rx * Ry * Rz
Translate t - 用于指定沿三个轴中任一轴的移动量、绕三个轴中任一轴的旋转角度（单位为度），以及沿三个轴的非均匀缩放。除了直接在这些字段中输入数值，也可以在 Viewport 中用 Select & Transform 状态操作组件来修改数值。

Rotate r - 用于指定沿三个轴中任一轴的移动量、绕三个轴中任一轴的旋转角度（单位为度），以及沿三个轴的非均匀缩放。除了直接在这些字段中输入数值，也可以在 Viewport 中用 Select & Transform 状态操作组件来修改数值。

Parent Transform Source parentxformsrc - NOTE: This parameter replaces the previous 'Constrain To' parameter. 使用「Parent Transform Source」来指定该对象使用什么初始位置。可以是「Parent (Hierarchy)」、「Specify Parent Object」或「World Origin」之一。

Operator Viewer opviewer - 当上方的 Node View 参数设为 Operator Viewer 时，选择使用哪个操作符的节点查看器。
Enable Cloning enablecloning - 控制该 OP 是否应持续克隆。关闭此项会使此节点停止克隆其「Clone Master」。
Enable Cloning Pulse enablecloningpulse - 立即克隆内容。
Clone Master clone - 用作 Master Clone 的组件路径。
Load on Demand loadondemand - 仅在需要时将组件加载到内存。适用于项目中并非总是使用的组件。
Enable External .tox enableexternaltox - 开启时（默认），.toe 启动时会加载外部 .tox 文件，COMP 的内容将与该外部 .tox 一致。如有需要，可以关闭此项，以避免启动时从引用的外部 .tox 加载（COMP 的内容改为从 .toe 文件加载）。如果你希望某个 COMP 引用外部 .tox，但不总是从它加载，除非你特意按下 Re-Init Network 参数按钮，这会很有用。
Enable External .tox Pulse enableexternaltoxpulse - 此按钮会从外部 .tox 文件重新加载（若存在）。
External .tox Path externaltox - 磁盘上 .tox 文件的路径，该文件会在 .toe 启动时作为组件内容的来源。这让组件可以包含能独立更新的网络。若找不到 .tox 文件，则会加载 .toe 文件保存时的内容。
Reload Custom Parameters reloadcustom - 启用此复选框后，重新加载 .tox 时会重新加载组件 Custom Parameters 的值。这仅影响组件上的顶层参数；组件内节点上的所有参数始终随 .tox 重新加载。
Reload Built-In Parameters reloadbuiltin - 启用此复选框后，重新加载 .tox 时会重新加载组件内置参数的值。这仅影响组件上的顶层参数；组件内节点上的所有参数始终随 .tox 重新加载。
Save Backup of External savebackup - 启用此复选框后，由 External .tox 参数指定的组件的备份副本会保存在 .toe 文件中。若找不到 External .tox，将使用此备份副本。出现这种情况可能是因为 .tox 被重命名、删除，或 .toe 文件在另一台缺少组件媒体的电脑上运行。
Sub-Component to Load subcompname - 从外部 .tox 文件加载时，此选项允许你深入 .tox 取出一个 COMP，并将其作为顶层 COMP，忽略文件中的其他所有内容（该 COMP 的内容除外）。例如，若名为 project1.tox 的 .tox 文件包含 project1/geo1，将 geo1 设为 Sub-Component to Load，就会加载 geo1 来替代当前 COMP。若此参数为空，则按常规使用文件中的顶层 COMP 加载 .tox 文件。
Relative File Path Behavior relpath - - 设置此 COMP 内的子文件路径是相对于 .toe 本身还是 .tox，或从父级继承。
  • Use Parent's Behavior inherit - 从父级继承设置。
  • Relative to Project File (.toe) project - 当指定为相对路径时，该路径将相对于 .toe 文件。
  • Relative to External COMP File (.tox) externaltox - 当指定为相对路径时，该路径将相对于 .tox 文件。未指定外部 COMP 文件，或 Enable External .tox 未开启时，此项没有影响。
Parameter Color Space parmcolorspace - - 控制如何解释此节点上的所有颜色参数。仅在项目启用了 Working Color Space 时可用。颜色值被视为处于所选色彩空间中，并在作为节点运算的一部分使用之前转换为 Working Color Space。注意这不会改变节点自身的色彩空间，因为它始终处于 Working Color Space。
  • sRGB srgb - sRGB 色彩空间，使用 sRGB 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • sRGB - Linear srgblinear - sRGB 色彩空间，使用线性传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.601 (NTSC) rec601ntsc - Rec.601，NTSC 原色色彩空间，使用 Rec.601 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.709 rec709 - Rec.709 色彩空间，使用 Rec.709（与 Rec.2020 相同）传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.2020 rec2020 - Rec.2020 色彩空间，使用 Rec.2020（与 Rec.709 相同）传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 dcip3 - DCI-P3 色彩空间，D65 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 (D60) dcip3d60 - DCI-P3 "D60 sim" 色彩空间，D60 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Display-P3 (D65) displayp3d65 - Display-P3 色彩空间，D65 白点，sRGB gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACES2065-1 aces2065-1 - ACES 2065-1（也称为 ACES AP0）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACEScg acescg - ACEScg（也称为 ACES AP1）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Passthrough passthrough - 选中后，颜色值将按原样用于运算，不作任何修改，也不尝试将其转换到 Working Color Space。
Parameter Reference White parmreferencewhite - - 在将参数颜色值转换为 Working Color Space 时，此项控制相对于 Reference White 应如何处理。如果 Working Color Space 的 Reference White 相同，则不做调整。如果不同，则此颜色的 Reference White 级别（亮度）将被调整到 Working Color Space 所期望的范围。例如，如果项目将 SDR Reference White 设为 120 nits，而 HDR Reference White 为 80 nits，那么 (1, 1, 1) 的颜色在 SDR 色彩空间中为 120 nits，将被转换为 (1.5, 1.5, 1.5)，在 HDR Working Color Space 中仍为 120 nits。
  • Default For Color Space default - 将根据所选的色彩空间使用 SDR 或 HDR Reference White。
  • Use Parent Panel useparent - 将使用父级面板所选的 Reference White。如果顶层面板也选择了「Use Parent」，则将使用「UI Reference White」。
  • Standard (SDR) sdr - 会将 Parameter Color Space 的 Reference White 值按 SDR 处理。
  • High (HDR) hdr - 会将 Parameter Color Space 的 Reference White 值按 HDR 处理。
  • UI ui - 会将 Parameter Color Space 的 Reference White 值按 UI 处理。其亮度使用「UI Reference White Nits」的值。

  • errors - 该操作符的错误数量（如果有）。
