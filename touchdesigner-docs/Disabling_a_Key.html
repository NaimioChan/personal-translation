停用密钥

禁用并转移密钥


密钥必须处于 Disabled 状态，才能转移到另一台机器，或在 update 许可时创建新密钥。

禁用密钥时计算机必须连接到互联网。需要此连接，以便在你的 Derivative 账户中禁用该密钥，从而允许你为另一台计算机创建新密钥。

  1. 在 Dialogs 菜单下打开 Key Manager Dialog。
  2. 选择 Key Manager Dialog 顶部的 Disable 选项。
  3. 下面的列表显示当前有效的密钥。点击要禁用的密钥以选中它。
  4. 点击 Disable Key 按钮。如果该密钥已在你的账户中（在 Derivative 服务器上）和本地成功禁用，它会从列表中移除，现在可以在另一台计算机上使用了。
