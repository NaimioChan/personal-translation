SOP 入门视频笔记

你将创建什么

在本教程中，你首先会创建一个带噪波的球体，然后给球体添加材质，把它合成到渐变背景之上，并加上一个假阴影。

把几何、摄像机和灯光插入项目

  • 打开 TouchDesigner，点击屏幕左侧四分之一处 palette 浏览器顶部的 X。
  • 右键拖动框选网络中的现有节点，然后右键点击并选择 delete，或者按 delete 键。
  • 双击网络编辑器，OP Create Dialog 应当会出现（也可以按 <tab> 键）。在 COMP 页下按住 shift 选择 Geometry COMP、Light COMP、Camera COMP，然后切换到 TOP 页选择 Render TOP。现在你应当有 4 个节点：geo1、cam1、light1 和 render1，从前往后三个节点有虚线指向 Render TOP。这些虚线表示 Render TOP 正在为自身的 parameters 引用那些节点。

移除默认几何并换成你自己的

  • 双击 Geometry COMP，删除里面的 Torus SOP。（右键 → Delete）
  • 双击网络，再次按住 shift 放置一个 Sphere SOP，接着放一个 Noise SOP。
  • 在 Spheres 页下，把 Primitive Type 参数设为 NURBS。
  • Noise SOP 查看器下方四个圆形图标中最右边两个，用于设置这些粒子是否显示和渲染（将鼠标悬停在图标上可看到该图标代表什么的提示）。选中这两个参数，使它们高亮。
  • 用滚轮向外缩小，直到回到最初的 project1 层，或从网络编辑器顶部的 path 栏中选择 project1。

给几何添加材质

  • 双击网络，从 MAT 页选择一个 Phong MAT。把它放在 Geometry COMP 上方。
  • 选中 Phong MAT 并把它拖到 Geometry COMP 上。两者之间应当出现一条短虚线，表示材质已应用。现在你的几何在 Render TOP viewer 中也应当明显更暗、更有光泽。
  • 点击 Phong MAT，在其 parameters 下把 Diffuse 参数值分别设为 Red、Green、Blue 的 0.075、0.075 和 0.075。这应当生成非常深的灰色。
  • 把 Specular 的 R、G、B 设为 1、1 和 1，然后把 Shininess 参数设为 24。

修改 Camera COMP 和 Light COMP 的位置

  • 选中 Camera COMP，把它的 Translate Z Parameter 设为 20，而不是默认值（5）。
  • 选中 Light COMP，把 Translate 参数设为 x: -50、y: 50、z: 0。在 Render TOP viewer 中，球体现在应当更小并位于中央，光从上方照下。

添加 Ramp TOP 背景并把几何合成到其上

  • 双击网络，在 TOP 页下选择一个 Ramp TOP。
  • 在 Ramp TOPs parameters 的 Common 页下，把 Custom Resolution 设为 1280x720
  • 在 Ramp TOPs parameters 中，在 Ramp Bar 上点击两个新点，把它们放得非常靠近，位置在屏幕往上三分之一处。
  • 点击要编辑的点，然后拖动 value 滑块，为每个点设置 Value 滑块。做出一个看起来像地面的渐变，后面是墙，地面在往上三分之一处与墙相接。

  • 双击网络，选择一个 Composite TOP。把 TOP 放在 Render TOP 和 Ramp TOPs 的右侧。
  • 左键点击 Render TOPs 的输出，然后左键点击 Composite TOPs 的输入，把它连到 Composite TOP 中。
  • 把 Ramp TOP 也连到 Composite TOPs 的输入。
  • 选中 Composite TOP，在其 parameters 中把 Operand parameter 设为 Over。

用 Ramp TOP 和 Transform TOP 插入假阴影效果

  • 在 Render TOP 和第一个 Ramp TOP 之间新建一个 Ramp TOP。
  • 再次在参数的 Common 页下把 Ramp TOPs 的分辨率设为 1280x768。
  • 切回 Ramp 页，把 Type 设为 Circular，Phase 设为 0.8，Period 设为 0.4。
  • 在 Ramp Bar 的中间添加一个新点。
  • 把 3 个 Ramp Bar 的值全部设为 0，并把中间和最右侧 Ramp Bar 的 Alpha 设为 0。
  • 现在你应当有一个边缘渐隐的黑斑和棋盘格背景。如果这个斑对 viewer 来说太大，你可以把 Ramp Bar 中间的值向左拖来收缩渐变。
  • 右键点击 Ramp TOPs 的输出，按住 shift 选择 Transform TOP、Blur TOP，然后松开 shift 选择 Level TOP。
  • 选中 Transform TOP，把它的 Translate parameter 设为 x: 0、y: -0.25。
  • 选中 Scale 参数，设为 x: 0.4、y: 0.08。
  • 切换到 Blur TOP，把 Pre-Shrink 参数设为 5，Filter Size 设为 16。
  • 选中 Level TOP，在 Post 页下把 Opacity 参数设为 0.3。
  • 最后把 Level TOPs 的输出连到 Composite TOPs 的输入，你会注意到 Composite TOPs 查看器中没有变化。这是因为 Composite TOP 对其输入的叠放方式：排在后面的输入会被放在前一层之下。
  • 选中 Composite TOP，你会在参数中看到一个 Input OP 参数。点击列表中 Level TOP 旁的向上箭头图标。
  • 在 Composite TOPs viewer 中，阴影现在应当能在变形的球体下方看到。

把项目设置为在执行模式中显示

  • 右键点击 Composite TOP，从 TOP 页选择一个 Out TOP。
  • 从 network 向外缩小，直到看到 project1，或点击 Network 编辑器上方路径栏中的 /。
  • 选中 project1，在 project1 参数的 Layout 页下，把 Width 设为 1280，Height 设为 720。
  • 点击屏幕左上角、Network 编辑器上方的 ^，切换到 Perform Mode。之后可以按 Escape 键关闭 Perform Mode。
