Triangulate POP

摘要

Triangulate POP 将每个闭合线带转换为填充线带内部的一组三角形。

默认假定所有线带都是凸的。如果不确定所有线带都是凸的，请将 Mode 设为 Convex and Concave。

开放线带和其他图元类型会原样传递。它支持同时包含多种图元类型以及开放和闭合线带的输入，所有不是闭合线带的内容都会原样输出。四边形默认原样输出，但有一个选项可以对四边形进行三角化。

如果 Mode 菜单为 Convex Only，它会高度并行执行（很快）。如果为 Convex and Concave，对较长的线带可能会非常慢。需要相应设置 Max Verts per Input Line Strip，可以设置 Max iterations 来限制迭代次数（使某些闭合线带只被部分三角化）

注意：如果可以从一个点画一条线到另一个点并穿过线带，则该线带是凹的。否则就是凸线带，例如圆。

另请参阅 Polygonize POP、Trace POP

参数 - Triangulate 页

Mode mode - 设置用于对闭合线带进行三角化的模式。
  • Convex Only convex -
  • Convex and Concave (Slower) concave -
Connect Holes connectholes - 如果模式为 'Concave'，可以将孔洞线带连接到包围它的线带，以便正确地对带孔洞的形状进行三角化。目前有一些限制：所有线带都应位于 XY 平面上，孔洞线带的绕序应为顺时针，包围线带的绕序应为逆时针。Trace POP 的默认输出符合这些条件。
Hardware Ray Tracing hwraytracing - 启用 'Connect Holes' 时，算法中的相交测试是否使用硬件光线追踪。
  • Off off -
  • Fast Build (Dynamic Geometry) fastbuild -
Ray Direction raydir - 启用 'Connect Holes' 时，算法中的相交测试所使用的光线方向。大多数情况下无需更改，但在少数情况下，更改它有助于解决连接孔洞时遗漏的相交。
  • Ray Direction raydirx -
  • Ray Direction raydiry -
Max Number of Line Strips maxls - 连接孔洞时用于临时内存分配。它应大于或等于输入中的线带数量。
Number of Passes numpasses - 连接孔洞时，为确定孔洞线带连接到哪些线带而执行的遍历次数。
Max Verts per Input Line Strip lsmaxverts - 在凸和凹模式下，每个闭合输入线带的最大顶点数。这应是一个常量，更改该值会导致计算着色器重新编译。顶点数更多的闭合线带目前会从输出中移除。
Line Strips Exceeding Max Verts exceedmaxverts - 在 'Concave' 模式下，对超过最大顶点数的线带如何处理。可以将所得三角形的顶点设为 0 以便轻松移除，也可以将线带长度钳制到最大顶点数。
  • Set resulting triangle vertices to 0 zero -
  • Clamp line strip number of vertices to max vertices clamp -
Max Iterations maxiter - 在凸和凹模式下，对输入中每个闭合线带尝试三角化的最大迭代次数。如果数值太低，闭合线带只会被部分三角化。这可以防止自相交的闭合线带导致无限循环、使 TouchDesigner 冻结。
Triangulate Quads triangulatequads - 是否将四边形图元转换为三角形。
Remove Zero Area Triangles remzerotri - 如果启用，将移除没有面积的三角形（其 3 个点共线）。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Info CHOP 通道

Triangulate POP 的附加信息可通过 Info CHOP 获取。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
