Pipe In CHOP

摘要

Pipe In CHOP 让用户能把自定义设备的数据输入到 CHOP 中。它是以 TCP/IP 网络连接实现的。

连接可以来自一个用户编写的程序，它输出到 Pipe In CHOP 的端口；也可以来自另一个 TouchDesigner 进程，此时数据来自一个 Pipe Out CHOP。

发送到 Pipe In 输出的常规通道数据会变成 CHOP 通道（带浮点值的通道名，每帧一个值）。与之混合的，还可以是 TouchDesigner 脚本命令，它们在到达时被执行。

提示： 通过网络发送脚本命令和其他数据包，首选方式是 TCP/IP DAT 或 UDP In DAT。

此节点与 Touch In CHOP 不同，它依靠命令流工作，而不像 Touch In CHOP 那样只是简单的通道数据流。信息以各种命令的形式进入，这些命令记录在你安装目录下的文件中 C:/Program Files/Derivative/TouchDesigner*/touch/docs/pipe。

要从另一台「服务器」电脑接收网络数据（例如来自远程运行的 TouchDesigner Pipe Out CHOP），必须先在该服务器与 Pipe In CHOP 之间建立连接，才能发送数据。你必须提供 Server Address 和 Port，以接收传入到某个通道的数据。服务器应在此 CHOP 使用的端口上监听连接。

NOTE for Windows OS - If experiencing connection issues make sure Windows Firewall is disabled.

另请参阅 Shared Mem In CHOP。

参数 - PipeIn 页

Connection Mode mode - - 把操作设为服务器或客户端。
  • This Operator is Client client -
  • This Operator is Server server -
Server Address address - 服务器电脑的网络地址。该地址是标准的 WWW 地址，例如「foo」或「foo.bar.com」。你可以使用 IP 地址（例如 100.123.45.78），也可以填电脑的网络名。如果填「localhost」，表示管道的另一端在同一台电脑上。
Server Port port - 服务器的网络端口。
Active active - 为 On 时，该 CHOP 从管道或服务器接收信息。为 Off 时不发生更新。服务器发送的数据会丢失，但管道会保存数据，直到 Active 再次打开。若处于 Network 模式，打开此参数会发起连接，关闭则断开连接。
Queued queued - 勾选后启用网络排队。参见以下参数。
Minimum Target mintarget - 队列目标范围的下限。Pipe In CHOP 会尽量保持队列长度大于或等于此值。
Min Unit mintargetunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
Maximum Target maxtarget - 队列目标范围的上限。Pipe In CHOP 会尽量保持队列长度小于或等于此值。
Max Unit maxtargetunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
Maximum Queue maxqueue - 队列满时的最大容量。达到最大队列长度时，传入的采样会被丢弃。This also affects the maximum number of script commands that can be queued up before they start gettting dropped.
Max Queue Unit maxqueueunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
Queue Adjust Time adjusttime - 指定多久重复/丢弃一次采样，以便更接近队列目标范围。如果值 = 1 且单位 = seconds，它会尝试每秒重复/丢弃一个采样，以维持上面 Minimum Target 和 Maximum Target 参数设定的队列目标。
Adjust Unit adjusttimeunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
Reset Channels reset - 丢弃并清除所有通道和传入数据。
Allow Incoming Scripts allowscripts - 除非此参数打开，否则传入的脚本命令会被忽略。关掉它更安全。
Echo Messages to Console echo - - 把所有传入命令（不含通道数据）打印到 Console，Console 可从 Dialogs 菜单打开。测试连接的一个好办法是在传入流中放入「echo X」命令。
  • Off off -
  • Full Messages to Console on -
  • All Events to Console raw -
Callbacks DAT callbacks - 指向一个 DAT 的路径，其中包含每个收到事件的回调。用法见 pipeinCHOP_Class。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Pipe In CHOP 的额外信息可通过 Info CHOP 访问。

  • connected -

  • queue_retarded_total -
  • queue_advanced_total -
  • time_under_target -
  • time_over_target -
  • queue_bumped -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
