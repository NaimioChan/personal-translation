Resample SOP

摘要

Resample SOP 会将一个或多个图元重采样为等长段。它仅适用于多边形，因此当输入为 NURBS 或 Bzier 曲线时，会先使用 Level of Detail 参数将其转换为多边形。

resampleSOP_Class

参数 - 页

Group group - 允许你指定要重采样哪些图元或图元组。接受模式，如 Pattern Matching 中所述。
Level of Detail lod - 如果你执行此操作的几何不是由多边形构成（例如 NURBS 圆），此参数决定转换为多边形的细节程度。细节级别越高，重采样过程越精确。
Resample by Polygon Edge edge - 此开关允许按多边形的每条边进行重采样，而不是对整个多边形进行重采样。这意味着重采样时会保留角点。启用此参数后，Measure Method 将被禁用。如果指定了 Segment Length，则只细分长度超过指定长度的边。每条边会被均匀细分，使每个细分的最大长度小于或等于指定的长度。

如果选择 Maximum Segments，边的分段数不会超过指定的数量。如果关闭长度参数，则每条边会被分割为指定数量的段。

Method method - - 指定几何的分段方式。
  • Even Length Segments dist - 沿原始输入进行等长测量
  • Even X Segments x - * Even X spaced Segments
  • Even Y Segments y - 与 X 类似，但沿 Y 轴。
  • Even Z Segments z - 与 X 类似，但沿 Z 轴。
Measure measure - - 指定沿曲线样条段进行测量的方式。
  • Along Arc arc - 此测量方法将曲线本身划分为等长的段。
  • Along Chord chord - 此方法在图元上求值点之间创建等长的直线段。速度更快，但精度较低。

Maximum Segment Length dolength - 启用此选项后，它会覆盖 Arc/Chord 长度的值，允许你自行指定重采样几何中段的长度。值越小，插值越平滑。
Length length - 此参数让你指定重采样几何的 Arc/Chord 长度。
Maximum Segments dosegs - 启用后，允许你覆盖重采样几何中使用的最大段数。
Segments segs - 让你指定沿弧测量时使用的段数。

同时选择 Maximum Segment Length 和 Maximum Segments 时，生成的多边形被约束为固定长度，可能比原始输入曲线短。

仅选择 Maximum Segments 时，各段跨越原始输入曲线的完整距离。

两个选项都未选择时，输入曲线仅被转换为多边形。

Maintain Last Vertex last - 如果选中，图元的最后一个 CV 会包含在重采样后的多边形中，即使最终生成的边短于给定的段长。

示例

使用 Resample SOP 创建等长旗标：

  1. 使用 Grid SOP 创建若干条水平线：Primitive Type: Polygon；Connectivity: Rows；Size: 3, 1
  2. 追加一个 Group SOP：Group: group1；Entity: Points；Number: Enable；Pattern: 0-99:1,10
  3. 追加一个 Spring SOP：Source Group: group1；Forces/Wind: 1, 0, 0；Turbulence: 1, 0, -1
  4. 追加一个 Resample SOP，将每条线裁剪为等长：Maximum Segments On；Segments: 15
  5. 追加一个 Skin SOP，其参数可保持默认，并在 Viewport 选项中启用 Points 显示。
  6. 点击 Play 查看结果。根据需要调整视图。
  7. 在 Spring SOP 和 Skin SOP 之间来回切换显示的 SOP。注意这些线在 Spring SOP 中受力后被拉伸和变形，偏离了原始长度。经过重采样后，它们保持等长。

Info CHOP 通道

可通过 Info CHOP 访问 Resample SOP 的额外信息。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
