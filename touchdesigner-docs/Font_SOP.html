Font SOP

摘要

注意：Font SOP 已在版本 2019.14650 中弃用，请使用 Text SOP。

Font SOP 让你用 Adobe Type 1 Postscript 字体在模型中创建文本。

要安装字体，请把字体文件复制到安装路径的 $TFS/touch/fonts 目录中。重启 TouchDesigner 后即可在 Font SOP 中使用。

fontSOP_Class

参数 - 页

Primitive Type type - 从以下类型中选择。有关不同类型的信息，见 Geometry Types 一节。Bzier Curves 和 Polygons 对内存的使用最高效，因为对含直线段的字母使用多边形，对其他字母使用 Bzier 曲线。

注意： 由于一个 Open GL 错误，Bzier 字体中的洞可能着色不正确。

  • Bezier Curves and Polygons bezierpoly -
  • Beziers Only bezier -
  • Polygons Only poly -
Font file - 选择用于创建文本的字体。点击 + 按钮会弹出 File Dialog，点击菜单下拉会弹出最常用字体的菜单。
Text text - 在此输入要生成的文本。

你的文本可以包含以下特殊字符：

  • \ - 按字面取下一个字符（因此你可以在文本中使用 / 和 ` 字符）；
  • `string` - 把反引号（在 T 键上方）括起来的字符串作为表达式求值；
  • \n - 开始新的一行；
  • \xxx - 用 ascii 码指定字符（例如 \007）。

For Example: 如果你在文本字符串中放入类似 \\$F3 的内容，播放动画时你应该能看到字体的所有可能字符（把最后一帧设为 256）。

Entering Expressions as Text - 你也可以对文本使用表达式。

For Example: me.time.frame - 将显示当前帧。

op('null1')['chan1'] - 将显示 CHOP null1 中通道 chan1 的当前值。

'hello world'[int(me.time.frame)%11] - 使文本的十一个字母在前十一帧中依次出现。

Other Methods of Entering Text - 你可以使用 \xxx 十进制表示法指定字符。可用字符取决于所用的字体类型。

For Example: \065 - 将显示「a」。

你也可以用 Par Class 在 Font SOP 中设置文本。这可以从 textport、Logic CHOP 或 Expression CHOP，或任何脚本中完成。（见 Scripting 中的文章）

For Example: op('font1').par.text = 'hello world' - 将显示这些文字：hello world

Center Text Horizontally hcenter - 此复选框让你把文本沿 X = 0 水平居中。
Center Text Vertically vcenter - 此复选框让你把文本沿 Y = 0 垂直居中。
Translate t - 在 x、y 和 z 方向平移几何。
  • X tx -
  • Y ty -
  • Z tz -
Scale s - 在 X 和 Y 轴上缩放文本。
  • X sx -
  • Y sy -
Kerning kern - X 方向的字母间距。如果有多个行，则为 Y 方向的行间距。如果需要手动逐字符布置，可以在 Model 模式下完成。
  • X kernx -
  • Y kerny -
Italic Angle italic - 并不真正提供字体的斜体版本，而是把文本按指定度数剪切使其倾斜。负值使文本向左倾斜。
Level of Detail lod - Adobe 字体由 Bzier 曲线定义。如果只选多边形，Font SOP 会把它们转换为多边形。此值调整转换后多边形中的点数。
Hole Faces hole - 在多边形和 Bzier 面中生成洞。
Texture Coordinates texture - 为 Font SOP 创建的几何添加 uv 坐标。
  • Off off - 不添加 uv 坐标。
  • Orthographic ortho - 添加正交 uv 坐标。
