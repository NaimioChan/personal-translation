CHOP Execute DAT

摘要

当指定 CHOP 的通道值发生变化时，CHOP Execute DAT 会运行其脚本。你可以指定要监视的通道，并按值以各种方式变化来触发。每个发生变化的采样都会调用一次脚本，因此在渲染一帧时，每个通道可能被调用 2 次或更多次，具体取决于 TouchDesigner 向前步进了多少帧（参见 Time Slicing）。

CHOP Execute DAT 通过 default python method placeholders 创建。参数中每个受监视的条件在 DAT 中都有对应的 python 方法。当参数中开启某个条件后，每次满足该条件时都会执行对应的 python 方法。

chopexecuteDAT_Class

参数 - CHOP Execute 页

Active active - 开启时，DAT 会响应所引用的 CHOP。
Execute from executeloc - - （仅 Tscript）决定脚本运行的位置。
  • Current Node current - （仅 Tscript）脚本从当前节点位置执行。
  • This Node here - 脚本从 DAT 的父级执行。DAT 从父级执行是为了便于访问 DAT 的同级：过去 DAT 脚本是从 DAT 内部执行的。
  • Specified Operator op - 脚本从下方 Component 参数指定的组件执行。
From Operator fromop - 当 Execute From 参数设为 Specified Operator 时，脚本将从该路径执行。
CHOP chop - 其通道变化将触发 DAT 执行脚本的 CHOP。
Channel channel - 哪个通道的变化会触发。
Off to On offtoon - 当指定通道从 off 切换到 on 时执行 onOffToOn() 方法，在第一帧「on」时调用。
While On whileon - 当指定通道为 on 时执行 whileOn() 方法。每帧调用一次。
On to Off ontooff - 当指定通道从 on 切换到 off 时执行 onOnToOff() 方法，在第一帧「off」时调用。
While Off whileoff - 当指定通道为 off 时执行 whileOff() 方法。每帧调用一次。
Value Change valuechange - 当指定通道以任何方式改变值时执行 onValueChange() 方法。每帧调用一次。
While Off/On Frequency freq - - 在使用上方 While On 或 While Off 选项时启用。决定 DAT 执行 For Every Sample 还是 Once Per Frame。
  • Execute For Every Sample everysample -
  • Execute Once Per Frame onceperframe -
Edit.. edit - 点击后打开文本编辑器，以编辑 DAT 中的文本。

参数 - File 页

File file - 要加载的文件的文件系统路径和名称。接受 .txt 和 .dat 文件。
Sync to File syncfile - 开启时，在项目启动时将文件从磁盘加载到 DAT 中。必须指定文件名。开启该选项会立即从磁盘加载文件。如果文件不存在，则在 DAT 第一次更新时创建它。系统会监视该文件，对文件的任何改动都会更新 DAT，而对 DAT 的任何改动都会立即写入文件。如果文件被移除，DAT 将保留其当前内容。
Load on Start loadonstart - 开启时，项目启动时从磁盘重新加载文件到 DAT 中。
Load File loadonstartpulse - 立即重新加载文件。
Write on Toe Save write - 开启时，保存项目时将 DAT 的内容写入磁盘文件。
Write File writepulse - 立即将文件写入磁盘。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

CHOP Execute DAT 的额外信息可通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
