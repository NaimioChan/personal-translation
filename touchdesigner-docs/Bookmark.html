书签

书签可在每个窗格顶部访问。点击 Bookmark 图标会弹出 Bookmark Menu，其中包含收藏当前窗格、编辑现有书签以及加载任何现有书签的选项。收藏当前网络位置可通过菜单或在 Bookmarks Dialog 中完成。

书签

bookmark 是对 TouchDesigner 项目网络层级中某个位置的引用。通过收藏某个位置，可以快速跳转到该位置，而不必每次都上下浏览网络。项目的书签会被保存，以便每次在 TouchDesigner 中重新打开项目时都可访问。书签以 bookmark 组件的形式保存在 /local/bookmarks 中。

书签可随时通过 Bookmark Menu 调用。书签列在此菜单底部。要加载书签，点击其名称，书签的路径就会被加载到窗格中。

书签菜单

Bookmark 菜单可在每个 Pane 顶部访问。点击 Pane Bar 中的 Bookmark 图标即可打开该菜单。

书签

在 Bookmark 标题栏下方，有用于 Bookmark this Pane 和 Edit Bookmarks...（使用 Bookmarks Dialog）的按钮。收藏当前网络位置可通过点击 Bookmark this Pane 按钮完成。点击后，会打开一个对话框，显示书签将保存的路径和一个默认名称。可在此处编辑，然后按对话框中的 Done 确认。按 Cancel 退出。

点击 Edit Bookmarks... 按钮将打开 Bookmarks 对话框。

书签会列出（目前按字母顺序）。点击书签名称，该书签的路径就会加载到该窗格中。

书签可通过 Bookmarks 对话框添加、编辑和删除。从 Bookmark 菜单选择 Edit Bookmarks...，或从 Dialogs 菜单选择 Bookmarks...，或使用 Alt-b 快捷键。

书签对话框

说明

Bookmarks 对话框可让你添加、编辑和删除 Bookmarks。书签保存在 network 位置 /local/bookmarks。

书签

书签在对话框中列出，书签名称在左列，书签的路径在右列。

当列表中的书签超过 20 个时，使用右侧的滚动条浏览。

可抓住对话框的标题栏在屏幕上拖动对话框。要关闭对话框，点击右上角的 x 按钮。

添加书签

对话框顶部的文本字段用于添加书签。在左侧的名称字段中输入书签名称，然后在右侧的字段中输入书签的网络路径。点击 Add 按钮添加书签，它会显示在下方列表中。

书签也可直接从 Bookmark Menu 添加。

编辑书签

要编辑书签的名称或路径，直接点击该字段并进行修改。按下 Enter 或点击其他字段后，名称或路径即会更新。

选项菜单

右键点击任意书签即可打开选项菜单。

加载书签

要加载书签，右键点击它打开选项菜单并选择 Load Bookmark。书签也可直接从 Bookmark Menu 加载。

删除书签

要删除书签，右键点击它打开选项菜单并选择 Delete。
