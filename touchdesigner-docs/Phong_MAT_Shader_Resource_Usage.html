Phong MAT 着色器资源占用

概述

每块 GPU 在卡上都有有限的资源可供执行着色器时使用。这些资源限制会影响同一时间能使用多少灯光、骨骼及其他功能。该限制是按物体计算的。只要影响单个物体的灯光数量有限（用 Light Mask 参数控制），你就可以在场景中使用上百盏灯。

Varying

varying 是从顶点着色器传给像素着色器的值。该值按顶点计算，然后在图元上插值（用构成该图元的其他顶点的 varying 来插值）。每个顶点上设置的 uv[3] 属性之所以能正确地为图元做纹理映射，靠的就是这个机制。

如今大多数 GPU 有 32 到 40 个可用的 varying。想知道你的显卡有多少，可以查看 $SYS_GFX_GLSL_MAX_VARYINGS 变量，它是一个内置的 Variable。

通过 varying 传递的内容包括位置（灯光位置）、矢量（聚光灯方向、法线）、纹理坐标、投影映射和阴影贴图信息等。

取决于着色器中矢量运算的写法，其中一些值可能通过 Uniforms 传给像素着色器，而不是在顶点着色器中计算后再经 varying 传给像素着色器。特别是是否使用法线贴图，会极大改变着色器里的矢量运算，从而导致 varying 用量大不相同。

不使用法线贴图时的 varying 用量

- 对每盏灯（任意类型），从灯光位置到顶点位置的矢量占用 3 个 varying。
- 对每盏灯（任意类型），如果该灯有衰减，则占用 1 个 varying。
- 对每盏灯（任意类型），如果该灯有阴影贴图（且 MAT 上的阴影强度不为 0），则占用 4 个 varying。
- 对每盏灯（任意类型），如果该灯有投影映射，则占用 3 个 varying。
- 如果开启了镜面反射（镜面颜色不为 (0,0,0)），或使用了 varying alpha，则从摄像机位置到顶点位置的矢量占用 3 个 varying。
- 如果使用了边缘光、漫反射、镜面反射或 varying alpha，则法线矢量占用 3 个 varying。
- 如果使用环境贴图，环境纹理坐标占用 2 个 varying。
- 每套实际用到的纹理坐标占用 2 或 3 个 varying（采样 3D 纹理时为 3 个，否则为 2 个）。如果你用了多种贴图（例如 Color Map 和 Specular Map），但它们使用同一套纹理坐标（例如都用纹理集 0，即 uv[0-2]），那么 varying 用量就只有 2-3 个。它们在像素着色器中采样纹理时共用同样的 varying。

使用法线贴图时的 varying 用量

- 对每盏灯（任意类型），从灯光位置到顶点位置的矢量占用 3 个 varying。
- 对每盏灯（任意类型），如果该灯有衰减，则占用 1 个 varying。
- 对每盏聚光灯，聚光方向占用 3 个 varying。
- 对每盏灯（任意类型），如果该灯有阴影贴图（且 MAT 上的阴影强度不为 0），则占用 4 个 varying。
- 对每盏灯（任意类型），如果该灯有投影映射，则占用 3 个 varying。
- 如果开启了镜面反射（镜面颜色不为 (0,0,0)），或使用了 varying alpha，则从摄像机位置到顶点位置的矢量占用 3 个 varying。
- 如果使用了边缘光，则法线矢量占用 3 个 varying。其他需要法线的功能，使用的是从法线贴图得到的法线。
- 如果使用环境贴图，环境纹理坐标占用 2 个 varying。
- 每套实际用到的纹理坐标占用 2 或 3 个 varying（采样 3D 纹理时为 3 个，否则为 2 个）。如果你用了多种贴图（例如 Color Map 和 Specular Map），但它们使用同一套纹理坐标（例如都用纹理集 0，即 uv[0-2]），那么 varying 用量就只有 2-3 个。它们在像素着色器中采样纹理时共用同样的 varying。

如果每个物体需要更多灯光

如果每个物体需要的灯光数量超过 GPU 单次渲染所能处理的数量，你可以用 Render Pass TOP 以同一摄像机、不同的灯光组合重新渲染同一批几何，然后简单地用 Add TOP 把第一次和第二次渲染的结果相加。

Uniform

uniform 是在着色器整个执行过程中保持恒定的值。uniform 的例子包括漫反射、镜面反射和自发光颜色。其他 uniform 包括骨骼矩阵（做变形时）以及灯光颜色之类的灯光信息。
