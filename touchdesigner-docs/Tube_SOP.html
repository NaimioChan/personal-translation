Tube SOP

摘要

Tube SOP 沿 X、Y 或 Z 轴生成开放或封闭的管、锥体或棱锥。它输出为网格、多边形或简单的管 Primitive。

tubeSOP_Class

参数 - Tube 页

Primitive Type type - - 从以下类型中选择。有关不同类型的信息，请参阅 Geometry 类别文章。使用 instancing 时不建议使用「Primitive」图元类型。
  • Primitive prim -
  • Polygon poly -
  • Mesh mesh -
  • NURBS nurbs -
  • Bezier bezier -
Connectivity surftype - 使用 Mesh Primitive Type 时，此选项用于选择曲面类型。
  • Rows rows - 创建水平线。
  • Columns cols - 创建垂直线。
  • Rows and Columns rowcol - Rows 和 Columns 都勾选。在线框显示下看起来像四边形，但所有多边形都是开放的（如果图元类型为 polygon）。
  • Triangles triangles - 用三角形构建网格。
  • Quadrilaterals quads - 生成由四边形构成的侧面（默认）。
  • Alternating Triangles alttriangles - 生成相互对置的三角形；类似 Triangles 选项。
Orientation orient - - 管的主轴（长轴）。
  • X Axis x -
  • Y Axis y -
  • Z Axis z -
Orient Bounds orientbounds - 仅在连接了输入以设置管边界时可用。当 Orient Bounds = On 时，它会旋转几何以匹配用于边界的输入 SOP 的朝向。
Modify Bounds modifybounds - 仅在连接了输入以设置管边界时启用。将 Modify Bounds = On 可启用下方的变换参数，进一步修改边界的位置、缩放、半径和高度。
Rotate Order rord - - 设置旋转的应用顺序。
  • Rx Ry Rz xyz -
  • Rx Rz Ry xzy -
  • Ry Rx Rz yxz -
  • Ry Rz Rx yzx -
  • Rz Rx Ry zxy -
  • Rz Ry Rx zyx -
Center t - - 管中心相对于对象原点的位置。
  • X tx -
  • Y ty -
  • Z tz -
Rotate r - - 这三个字段沿 X、Y 和 Z 轴旋转管。
  • Rotate rx -
  • Rotate ry -
  • Rotate rz -
Radius rad - - 第一个字段是管顶部的半径，第二个字段表示管底部的半径。
  • rad1 -
  • rad2 -
Height height - 管的高度。
Reverse Anchors reverseanchors - 反转锚点的方向。
Anchor U anchoru - 设置 X 方向上的点，几何围绕该点定位、缩放和旋转。
Anchor V anchorv - 设置 Y 方向上的点，几何围绕该点定位、缩放和旋转。
Anchor W anchorw - 设置 Z 方向上的点，几何围绕该点定位、缩放和旋转。
Imperfect imperfect - 此选项仅适用于 Bezier 和 NURBS 类型。选中时，管状体为近似的非有理曲线，否则为精确的有理曲线。

参数 - Detail 页

Rows rows - 管中的行数。
Columns cols - 管中的列数。
U Order orderu - 如果选择了样条曲面，则按此阶数沿 U 构建。
V Order orderv - 如果选择了样条曲面，则按此阶数沿 V 构建。
End Caps cap - 如果选中，会在管的两端添加刻面端盖。
Texture Coordinates texture - 为球体添加 UV 纹理坐标。
  • Off off - 不向曲面添加 UV 坐标。
  • Row & Columns rowcol - 添加顶点 UV 坐标。
Compute Normals normals - 勾选此项为 On 会计算曲面法线。

Info CHOP 通道

可通过 Info CHOP 访问 Tube SOP 的额外信息。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
