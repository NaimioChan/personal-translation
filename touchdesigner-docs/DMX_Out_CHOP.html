DMX Out CHOP

摘要

DMX Out CHOP 把通道发送到 DMX、Art-Net、sACN、KiNET 或 FTDI 设备。DMX 的通道值为 0-255。

送入 DMX Out 的第一个通道对应第一个 DMX 地址（DMX 通道）。随着你向 DMX Out 添加通道，会按顺序访问后续 DMX 通道。例如，如果向 DMX Out 输入 12 个通道，你就会控制 DMX 通道 1 到 12。

TouchDesigner 中的 DMX 是在 ENTTEC 设备上开发的，即其 DMX USB Pro 和以太网 DMX 设备，但它应该适用于许多支持 DMX/Art-Net/sACN/KiNET 的设备和软件。

可以在一个 DAT 中提供 Routing Table，通过为每个通道添加行并指定 net、subnet 和 universe 来指定地址。

ENTTEC NOTE: - 使用 ENTTEC 的 NMU (Node Management Utility) 来配置和检查网络中发现的 ENTTEC 设备。

macOS NOTE: - ENTTEC USB Pro 可能无法自动连接，要启用它，请在 Terminal 中输入以下命令：

sudo kextunload -b com.apple.driver.AppleUSBFTDI

提示：设置和用法示例参见 OP Snippets。

提示：用 WireShark 监视你的 DMX 网络流量。


另请参阅：DMX Out POP、Art-Net、sACN、DMX In CHOP、DMX

参数 - DMX 页

Active active - 开启时连接到设备。
Interface interface - - 选择连接设备所用的接口类型。
  • Enttec Generic Serial serial - 使用操作系统的串口调用写入数据。
  • Enttec USB Pro enttecusbpro -
  • Enttec USB Pro Mk2 enttecusbpromk2 -
  • Art-Net artnet - 把接口设为 Art-Net 协议。
  • sACN sacn - 把接口设为 sACN 协议。
  • KiNET kinet - 把接口设为 KiNET 协议。
Format format - - 在 Packet Per Sample 或 Packet Per Channel 之间选择发送方式。
  • Packet Per Sample packetpersample - 每个通道充当一个 DMX 通道，即 1 个 universe 用 512 个通道。
  • Packet Per Channel packetperchan - 通道中的每个采样充当一个 DMX 通道。这样可以为一个 universe 设置一个通道，即 1 个通道带 512 个采样表示 1 个 universe。多个 universe 就添加多个通道。
Rate rate - 向设备发送数据的频率（每秒）。 
       WARNING: DMX512 devices have a maximum refresh rate of 44Hz. It is recommended that Rate <= 44 for reliable performance.

Serial Port serialport - - 当 Interface 参数设为 Generic Serial 时，该参数让你选择使用哪个串口（COM）。
  • COM3 com3 -
DMXking Port dmxkingport - - 选择要发送到的 DMXking 端口。
  • Default default -
Device device - - 从菜单中选择 DMX 设备。
  • * * -

参数 - Network 页

Net (0-127) net - 当 Interface 参数设为 Art-Net 时，此项设置 net 地址。一个 net 是 16 个连续 subnet 或 256 个连续 universe 的组。该参数的取值范围为 0-127。这not网络 IP 地址。
Subnet (0-15) subnet - 当 Interface 参数设为 Art-Net 时，此项设置 subnet 地址。一个 subnet 是 16 个连续 universe 的组。该参数的取值范围为 0-15。这not网络子网掩码。
Universe universe - 当 Interface 参数设为 Art-Net 时，此项设置 universe 地址。一个包含 512 个通道的 DMX512 帧称为一个 universe。该参数的取值范围为 0-15。
Multicast multicast - 为 sACN 启用多播。多播会根据设备的 Net、Subnet 和 Universe 自动构建 IP。这样可以指定多个 universe，一次发送到多台设备。
Network Address netaddress - 指定要使用的 IP 地址。该地址对应接收设备的地址。当该地址设为默认的 255.255.255.255 时，消息会改为广播到网络上的所有设备。在所有情况下，接收设备的 Art-Net Net、Subnet 和 Universe 仍必须与 DMX Out CHOP 中指定的相匹配。
Local Address localaddress - - 当发送机器装有多个网络适配器时，可以用该参数在此指定其 IP 地址，从而选择从哪个适配器发送数据。
  • 192.168.0.102 192.168.0.102 -
Local Port localport - 少数情况下需要指定数据发送所用的自定义端口。默认值 -1 表示使用操作系统分配的端口。
Use Custom Port customport - 启用 Network Port 参数可指定接收硬件的端口。
Network Port netport - 用于指定接收硬件的端口。按 ArtNet 规范，默认值为 6454，仅在少数情况下才应更改。
Send ArtSync sendartsync - 启用后会发送 ArtSync 数据包。ArtSync 数据包用于将多个 universe 同步在一起。其做法是先等待所有 ArtDmx 数据包发送完毕，然后发送一个 ArtSync 数据包。
ArtSync Timeout artsynctimeout - 指定 ArtSync 在发送 ArtSync 数据包之前等待所有 ArtDmx 数据包发送完成的时间，单位为毫秒。如果超时到达时它们尚未全部发送完毕，ArtSync 将终止，并且不会发送 ArtSync 数据包。此外，还会发送新一帧的 ArtDmx 数据包，并启动新的 ArtSync。
CID cid - 发送方的唯一 ID。
Source source - 用户为来源指定的名称（仅供信息参考）。
Priority priority - 发送数据的优先级，用于存在多个来源的情况。
KiNET Version kinetversion - - 设置要使用的 KiNET 协议版本。
  • DmxOut (v1) v1 -
  • PortOut (v2) v2 -
Use Custom KiNET Port customkinetport - 启用后可为 KiNET v2 接口指定自定义端口。禁用时，端口为广播端口：255。
KiNET Port kinetport - 指定 KiNET v2 接口的端口。
Routing Table routingtable - 当对 Art-Net 或 sACN 使用 Packet Per Channel 格式时可用。使用停靠的 Table DAT 将通道路由到相应的 universe。可为每个通道添加行并指定 net、subnet、universe 和 netaddress 来指定地址。net、subnet、universe 和 netaddress 列都是可选的，分别对应 DMX Out CHOP 的 Net、Subnet、Universe 和 Network Address 参数。例如，如果 Routing Table 中缺少 net 列，则改用 Net 参数。

从参数中移除 Routing Table 后，指定的地址将用于第一个通道，而所有其他通道会被分配到连续的地址。

注意： 对 sACN 来说，第一个可用的 universe 索引为 1，因为 universe 0 被系统保留供将来使用。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

操作符输入

  • Input 0: -

Info CHOP 通道

DMX Out CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
