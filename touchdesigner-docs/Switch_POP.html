Switch POP

摘要

Switch POP 让你选择其中一个输入，并原样输出该输入。所有输入的点、顶点和图元数量可以各不相同。

它用数值参数 Index 选择输入，0 表示第一个输入。如果 Index 是小数——非整数，它可以混合两个输入：如果输入的点、顶点和图元数量相同，就可以一次混合两个相邻输入。

提示：由于它只混合相邻输入（输入 N 与输入 N+1 或 N-1），要从最后一个输入混合到第一个输入，可把第一个输入再作为最后一个输入接上，并用 CHOP 让数值从 0 循环到输入数量，当 Index 达到输入数量时跳回 0。

如果 Index 超出范围，会被钳制。

要混合输入的任意组合，见 Blend POP。

Switch POP 处理多输入的架构与 Attribute Combine POP 类似。

Extend extend - 决定索引超过输入数量时的处理方式。允许负索引。

  • Length Mismatch lengthmismatchnotif -

Point Attribute Scope pointattrscope - - 要混合的点属性范围。
  • * * -

  • * * -

  • * * -

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Info CHOP 通道

Switch POP 的额外信息可通过 Info CHOP 获取。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
