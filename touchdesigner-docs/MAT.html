MAT

摘要

MAT 或材质是一种 Operator Family，把 Shader 应用于 SOP 或 3D Geometry Object，以渲染带光照的带纹理表面。

有关 MAT 相关文章的完整列表，另请参阅 Category:MATs。

Material Operators 或 MATs 用于为几何创建材质。可通过 Object Components 的 Display 页上的 Material 参数把它们应用到几何上。

Phong MAT 和 GLSL MAT 设计为使用 TOPs 和 GLSL 程序（像素和顶点着色器）作为输入，以创建更高级的着色器。

最常用的 MAT 是 Phong MAT。Phong MAT 包含大量光照选项，可让用户创建一些非常独特的效果。

Phong MAT - 对几何应用 phong 着色器。几何必须有 normals 才能使高光着色生效。几何必须有 Texture Coordinates 才能使任何应用的贴图（即 Color Map、Bump Map、Specular Map 等）生效。可使用 Deform 参数页使几何变形。Phong MAT 还为 Transparency、Rim Lights 和 Shadows 提供其他高级功能。

PBR MAT - 对几何应用 PBR 着色器。与 Environment Light COMP 配合使用。也可通过加载到 Substance TOP 的 .sbsar 文件使用 Substance Designer PBR 材质。

Line MAT - 以线和点配合不同的几何来渲染几何边缘。

Constant MAT - 此材质对几何应用恒定的纯色。没有高光着色，即着色不受摄像机和灯光位置影响。

PBR MAT - 对几何应用 PBR 着色器。与 Environment Light COMP 配合使用。也可通过加载到 Substance TOP 的 .sbsar 文件使用 Substance Designer PBR 材质。

Depth MAT - 可用于从几何获取深度信息，用于深度通道渲染。它不会渲染任何颜色。

GLSL MAT - 强大的材质操作符，对几何应用像素和顶点 GLSL 着色器。可在 GPU 上使用顶点着色器使几何变形。几何必须有 Texture Coordinates 和 normals。

Point Sprite MAT - 用于 Point Sprite 几何类型的特殊材质。Particle SOP 可创建 point sprite。
