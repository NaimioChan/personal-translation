CPlusPlus POP

摘要

CPlusPlus POP 让你可以用 C++ 编写自己的插件，从而制作自定义 POP 操作符。

有关如何制作与此节点配合使用的插件以及如何获取示例项目的详细信息，请参阅 Write a CPlusPlus Plugin、Write a CPlusPlus POP 和 C++ Category 中的其他文章。

cplusplusPOP_Class

参数 - CPlusPlus 页

Plugin Path plugin - 要加载的插件的路径。
Re-Init Class reinit - - 此参数开启时，会删除插件创建的类实例，并创建一个新实例。
  • Re-Init Class reinit - 此参数开启时，会删除插件创建的类实例，并创建一个新实例。
  • Re-Init Class reinitpulse - 立即重新初始化该类。
Unload Plugin unloadplugin - 此参数大于 1 时，会删除插件创建的类实例并卸载插件。如果多个 TOP 加载了同一插件，它们都需要卸载才能释放该文件。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Info CHOP 通道

CPlusPlus POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
