ZED CHOP

摘要

注意

OS: 此操作符仅在 Microsoft Windows 操作系统下受支持。

ZED CHOP 从 ZED 摄像机读取位置和平面跟踪信息。它还可以使用 UV 在房间中查找平面，并返回该平面的信息，例如其尺寸／朝向是相对于摄像机还是相对于房间本身。

启用 Camera Transform 参数后，我们会提供平面朝向数据以及以下内容。

Channel Name Description
camera:tx, camera:ty, camera:tz Camera translation vector
camera:rx, camera:ry, camera:rz Camera rotation vector

启用 Body Tracking 后，Body 3D 参数会为每个关节启用 tx tz tz 位置值（即 p1/body/shoulder_l:tx 是第一个被跟踪身体的左肩位置的 x 分量），Body 2D 参数会启用 u v 坐标。以下是 ZED Body Tracking 文档中列出的 18、34 和 38 关节所支持的身体关键点。

ZED CHOP 通过 Max Bodies 参数支持多人身体跟踪。前面以及下面的每个通道名都可以加上 p# 前缀，表示该通道属于哪个身体，即 p3/body/neck:tx 通道表示第三个被跟踪身体的颈部位置 x 分量。

Number of Joints Channel Names
18 neck, nose, eye_[lr], ear_[lr], shoulder_[lr], elbow_[lr], wrist_[lr], hip_[lr], knee_[lr], ankle_[lr]
34 pelvis, spine_lower, spine_upper, neck, head, nose, eye_[lr], ear_[lr], collar_[lr], shoulder_[lr], elbow_[lr], wrist_[lr], hand_[lr], hand_tip_[lr], hand_thumb_[lr], hip_[lr], knee_[lr], ankle_[lr], heel_[lr], foot_[lr],
38 pelvis, spine_lower, spine_middle, spine_upper, neck, nose, eye_[lr], ear_[lr], collar_[lr], shoulder_[lr], elbow_[lr], wrist_[lr], hand_pinky_[lr], hand_middle_[lr], hand_index_[lr], hand_thumb_[lr], hip_[lr], knee_[lr], ankle_[lr], big_toe_[lr], heel_[lr], small_toe_[lr], _[lr],

以下通道包含每个被跟踪身体的信息。

Channel Name Description
id Body ID
tracked Whether a body is being actively tracked (0 or 1)
moving Whether a body is moving (0 or 1)
vel_x, vel_y, vel_z Velocity of tracked body

Bounding Boxes 参数会启用边界框位置的通道。

启用 Body 2D 后，bbox2d:[xywh] 通道表示边界框左下角（x,y）坐标以及宽度和高度，bbox2d:[uv], bbox2d:norm[wh] 则以 UV 坐标提供。

启用 Body 3D 时，会同时提供边界框 bbox3d 和头部边界框 headbbox3d。

注意： 该 CHOP 可与 Stereolabs ZED 硬件配合使用。 更多信息以及应安装哪个 ZED SDK，请参阅 ZED 一文。

另请参阅 ZED TOP、ZED POP 和 ZED SOP。

参数 - ZED 页

Active active - 为「On」时，从 ZED 摄像机采集数据。
ZED TOP zedtop - 配置该摄像机的主 ZED TOP 的名称。主 TOP 决定该 CHOP 从哪个摄像机接收数据。
Camera Transform cameratransform - 启用变换，返回摄像机的位置和旋转。
Camera Transform resetcameratransform - 将当前摄像机位置归零，实际上把当前位置设为新的原点。
Plane Orientation planeorientation - 启用点处平面，返回与 UV 坐标对应平面的位置。
Get Plane getplane - 返回相对于摄像机初始位置的摄像机位置。将输出 tx、ty、tz 三通道表示摄像机位置，单位为米。将输出 rx、ry、rz 三通道表示朝向。
Pulse getplanepulse - 立即返回相对于摄像机初始位置的摄像机位置。
Plane Reference Frame planereferenceframe - - 控制面板坐标是相对于摄像机还是相对于世界。
  • World world - 平面位置输出相对于摄像机的初始位置。
  • Camera camera - 平面位置输出相对于摄像机之前的位置。
Plane Point U planepointu - 设置图像中用于提取平面位置的点的 U 坐标。
Plane Point V planepointv - 设置图像中用于提取平面位置的点的 V 坐标。
Plane Position planeposition - 返回平面中心的 tx、ty 和 tz 位置通道。
Plane Rotation planerotation - 返回平面的 rx、ry 和 rz 旋转通道。
Plane Normal planenormal - 返回平面的 nx、ny 和 nz 法线通道。
Plane Size planesize - 返回平面边界矩形的大小。
Body Tracking bodytracking - - 身体跟踪可跟踪视频帧中的人体骨架。每种模式使用的 AI 模型都需要针对你的 GPU 进行训练。这需要几分钟，但只要不更换 GPU，每台机器上每个模型只需训练一次。对于「Joint Mode」参数被禁用的模型，输出将为「Absolute」。
  • Off off - 禁用身体跟踪。
  • Skeleton - 18 Joints skeleton18 - 按 this article 中所述跟踪 18 关节骨架。
  • Skeleton - 34 Joints skeleton34 - 按 this article 中所述跟踪 34 关节骨架。位置和旋转相对于父级关节，如该文所述，其中 0 号关节为「root」关节。
Max Bodies maxbodies - 将被跟踪的身体数量上限。
Body 3D body3d - 启用后输出 3D 位置。如果 Joint Mode 设为「Relative」，还会包含旋转。
Joint Mode jointmode - - 控制关节值是场景中的绝对值还是彼此相对。
  • Absolute Position absolute - 每个关节在空间中的绝对 XYZ 位置，单位为米。
  • Relative, with Orientation relative - 以层级方式表示的 3D 骨架位置和旋转，各自相对于父级关节。
Body 2D body2d - 每个关节的 2D 归一化 UV 坐标，表示它们在图像中的位置。
Aspect Correct UVs aspectcorrectuv - 使用宽高比校正 UV 坐标。对于 2x1 的宽高比，归一化坐标（0.25, 0.25）将覆盖宽度的四分之一和高度的八分之一，而不是高度的四分之一。此模式在进行正交渲染或在 TOP 中使用 Fraction Aspect 单位时很有用。
Bounding Boxes boundingboxes - 启用边界框。仅当启用 Body 3D 时才会启用头部边界框。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

ZED CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
