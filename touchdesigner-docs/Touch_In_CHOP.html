Touch In CHOP

摘要

Touch In CHOP 可用于通过 CHOP 在两个 TouchDesigner 进程之间建立高速连接。

数据通过 TCP/IP 发送。Touch In CHOP（客户端）从 Touch Out CHOP（服务器）接收数据。Touch In CHOP 类似 Pipe In CHOP，但针对 TouchDesigner 与 TouchDesigner 之间的通信做了高度优化。与其他软件或设备对接，见 Pipe In CHOP 或 TCP/IP DAT。

要从另一台「服务器」计算机接收网络数据（例如从远程运行的 Touch Out CHOP），必须在发送数据之前先在服务器与 Touch In CHOP 之间建立连接。

数据以时间切片形式接收，如果发送方或接收方未按目标帧率运行，可用它来消除丢帧。见 Time Slicing 和 Time Slice CHOP。也可以按非时间切片方式运行，以接收完整的通道数据。

要分析传入消息的时序，给 Touch In CHOP 附加一个 Info CHOP。它会显示内部队列大小，以及是否在丢数据或缺数据（queue_advanced_total 和 queue_retarded_total 不应增加，queue_length 不应为零）。

NOTE for Windows OS - If experiencing connection issues, confirm Windows Firewall is disabled for TouchDesigner.

参数 - Touch In 页

Protocol protocol - 选择用哪种网络协议传输数据。不同协议的连接方式和地址参数的用法不同。详情参见 Network Protocols 文章。
  • Streaming (TCP/IP) streaming -
  • Messaging (UDP) msging -
  • Multi-Cast Messaging (UDP) multicastmsging -
Address address - 服务器计算机的计算机名或 IP 地址。可以用 IP 地址（例如 100.123.45.78），也可以直接用计算机的网络名称。若填「localhost」，表示管道的另一端在同一台计算机上。
Network Port port - 服务器的网络端口。
Active active - 开启时，CHOP 从管道或服务器接收信息。关闭时不更新。服务器发送的数据会丢失，但管道会保存数据直到再次开启 Active。若处于 Network 模式，开启此参数会建立连接，关闭则断开连接。
Queue Target queuetarget - CHOP 试图维持的目标队列长度。
Queue Target Unit queuetargetunit - 在此参数的单位中选择 Samples、Frames 或 Seconds。
Queue Variance queuevariance - Queue Target 周围可接受的范围。如果队列长度在目标值与变化范围内，CHOP 就不会去调整队列长度。
Queue Variance Unit queuevarianceunit - 在此参数的 Samples、Frames 或 Seconds 单位之间选择。
Maximum Queue maxqueue - 队列满时的最大大小。如果达到最大队列长度，传入的采样将被丢弃。
Max Queue Unit maxqueueunit - 在此参数的 Samples、Frames 或 Seconds 单位之间选择。
Queue Adjust Time adjusttime - 指定多久重复/丢弃一次采样，以便更接近队列目标范围。如果值为 1、单位为秒，则它每秒会尝试重复/丢弃一个采样，以维持上面 Minimum Target 和 Maximum Target 参数中设定的队列目标。
Adjust Unit adjusttimeunit - 在此参数的 Samples、Frames 或 Seconds 单位之间选择。
Recover Outside Range recover - 若队列大小超出目标大小范围的时间超过「adjust time」，则在开启此选项时会停止发送新数据或丢弃大量数据，直到队列大小回到最小/最大目标的中间。若关闭此选项，队列大小会改为缓慢向目标大小靠拢（通过偶尔丢帧或重复单帧）。
Use Synced Ports syncports - 如果需要，此参数让你通过单个全局管道发送数据。当多路数据流必须帧同步发送时，这可能很重要。详情参见 Touch In/Out Synced Ports。
  • Off off - 为每个分配的端口号使用独立端口。
  • On on - 对所有使用此 Transfer Port Type 的 Touch Out CHOP 使用单个全局管道。该全局管道内部使用端口 10500，一次性发送所有全局端口类型的数据。接收端仍用 Network Port 参数决定哪个 Touch In CHOP 获得数据。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
