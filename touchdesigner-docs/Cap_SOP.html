Cap SOP

摘要

Cap SOP 用于以平面或圆滑的封面封闭开放区域。网格的封盖方式是沿 U 或 V 方向延伸网格（例如 NURBS 管）。面的封盖方式是附加一个单独的面或外壳封盖。

capSOP_Class

参数 - 页

Group group - 指定要应用封盖的 Primitive Group。创建图元组的方法见 Group SOP。

参数 - U Caps 页

Preserve NURB Shape U pshapeu - 封盖 NURBS 曲面时，使用此选项可以把原始曲面在封盖处钳制，从而保留它。
First U Cap firstu - 从菜单中选择一个选项：
  • No End Cap none - 不改变图元的这一侧。
  • End Cap Faceted facet - 通过创建一个使用独立点的同类型面来封盖。
  • End Cap Shared share - 通过创建一个与原图元共享点的同类型面来封盖。
  • End Cap Rounded round - 通过创建/延伸一个包含若干同心圆形区域的网格来封盖。这样会形成子弹头或穹顶状的封盖。
  • End Cap Tangential tangent -
Divisions divsu1 - 圆滑封盖中的横截面数量。
Scale scaleu1 - 影响圆滑封盖的高度（正值和负值均可）。
Last U Cap lastu - 与 First Cap U / V 类似，但在图元另一端沿相反方向构建封盖。
  • No End Cap none -

Divisions divsu2 - 圆滑封盖中的横截面数量。
Scale scaleu2 - 影响圆滑封盖的高度（正值和负值均可）。

操作符输入

  • Input 0: -

Info CHOP 通道

Cap SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
