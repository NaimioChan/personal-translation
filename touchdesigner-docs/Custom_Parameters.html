自定义参数

自定义参数让你可以在 Parameter Dialog 的用户自定义 Parameter Pages 上创建各种 Parameters。

可以通过三种方式创建自定义参数：

  • 在 Components 上，如下所述。
  • 在 Script SOP、Script CHOP 和 Script DAT 等脚本操作符上，如下所述。
  • 在 C++ operators 上。请参阅 Write a CPlusPlus Plugin 页面。

easiest way to see and edit parameters of components的方式是通过 Component Editor Dialog：在组件节点上右键单击并选择 Customize...

另请参阅：Internal Parameters

命名约定

自定义参数与内置参数的区别在于：自定义参数的名字除首字母大写外其余为小写（例如 Divisions），而所有内置参数全为小写（例如 brightness）；并且自定义参数出现在 Parameters 对话框第二行页面之下。应遵循的标准是首字母大写、其余字母小写。如果自定义参数的首字母不是大写，创建会失败并返回错误。另外，所有参数名都不包含下划线。

示例：

  1. 用于搜索词的字符串参数：Searchterm
  2. 一个距离值：Distance

自定义参数名的字符数应保持在 12 个以下，最好是 10 个，因为如果用参数名旁的 + 图标展开参数，名字会难以辨认。

参数标签的形式为：Rotate to X Axis，其中除名词、动词、形容词、副词之间的词（如 from、if、and、to）之外，每个词都大写。

在 COMP 上创建自定义参数

QUICK START：使用任意组件或脚本操作符上的右键菜单 Customize... 对话框，创建和管理自定义参数最为方便。首先通过填写页面名称并按 Add Page 来添加新的自定义页。然后在 Pages 下选中该页，输入参数名（首字母大写、其余字符小写、不含空格，例如「Speed」）和参数类型（例如 Float），再点击 Add Par 创建参数。之后你可以修改 Parameters 对话框上显示的标签、默认值等。在组件内部，可以用本例中的 parent().par.Speed 访问该参数。

在组件上创建自定义参数分两步。第一步是创建参数，第二步是定义其行为。自定义参数会作为组件的一部分一直存在，直到被显式删除，创建它们的代码只需运行一次。

所有可用参数类型及其参数的列表见 Page Class 页面。

在内部，自定义参数是通过 python 函数创建和管理的。下面是使用 Customize 对话框的 python 等价写法。

下面的代码会在名为 Parameter Page 的组件上创建一个 pulse 类型按钮，脚本名为「Startsearch」，标签为「Click to Start Search」。这段代码可以输入到与名为 base1 的 Base COMP 处于同一网络的 Text DAT 中，如果 base1 是在根（/）层级创建的，也可以输入到 Textport 中： 

# 在名为 base1 的 Base COMP 节点上创建一个 pulse 按钮参数
baseOp = op('base1')
newPage = baseOp.appendCustomPage('Controls')

# 创建一个包含一个 pulse 参数的 tuplet
newTuplet = newPage.appendPulse('Startsearch', label='Click to Start Search')

tuplet 是一组相关参数，它们会出现在参数界面的同一行。 你可以像操作其他任何 pulse 参数一样操作上面的 Pulse 按钮： 

baseOp.par.Startsearch.pulse()


下面的代码会在名为「Car Controls」的 Parameter Page 上创建一个 float 滑块类型参数，标签为「Speed of Car」，脚本名为「Speed」。滑块的最小值为 -2，最大值为 2。该参数会被限制在最小 -10、最大 10 之间，防止输入更低或更高的值。（这些值最初是 0 和 1。） 

# 在名为 base1 的 Base COMP 节点上创建一个浮点参数
baseOp = op('base1')
newPage = baseOp.appendCustomPage('Car Controls')
newTuplet = newPage.appendFloat('Speed', label='Speed of Car', size=1)
# 获取此 tuplet 的第一个（也是唯一的）参数
p = newTuplet[0]

# 定义新建参数的属性

# normMin 成员定义滑块的最小值
p.normMin = -2

# normMax 成员定义滑块的最大值
p.normMax = 2

# default 成员定义参数的默认值
p.default = 0.1

# min 成员定义参数的绝对最小值
# clampMin 成员阻止低于 min 中设定的值
p.min = -10
p.clampMin = True

# max 成员定义参数的绝对最大值
# clampMax 成员阻止高于 max 中设定的值
p.max = 10
p.clampMax = True


你也可以通过为 int 或 float 类型参数指定 size 关键字来创建多值参数。这适用于为单个参数设置多个方面之类的场合。系统自带了一些预置的多值参数类型，为常用的数组提供了更方便的命名方案，例如 RGB、RGBA、XYZ 等。

创建这些参数的方法会返回一个 parameter instances 元组，可用于定义参数的属性。在下面的示例中，创建的参数名将使用指定的名称加上表示参数在列表中顺序的索引，即「Vector1」、「Vector2」和「Vector3」。任何参数的最大 size 为 4。这里用 for 循环遍历所有向量并快速设置它们的参数。 

# 在名为 base1 的 Base COMP 节点上创建 3 个浮点参数
baseOp = op('base1')
newPage = baseOp.appendCustomPage('Car Controls')
newTuplet = newPage.appendFloat('Vector', label='Movement Vector', size=3)

# 定义新建参数的属性
for p in newTuplet:
	# normMin 成员定义各滑块的最小值
	p.normMin = 0

	# normMax 成员定义各滑块的最大值
	p.normMax = 1

	# default 成员定义参数的默认值
	p.default = 0.1

	# min 成员定义参数的绝对最小值
	# clampMin 成员阻止低于 min 中设定的值
	p.min = 0
	p.clampMin = True

	# max 成员定义参数的绝对最大值
	# clampMax 成员阻止高于 max 中设定的值
	p.max = 10
	p.clampMax = True

关于自定义参数类型的完整概述，请参阅 Custom Parameter section of the COMP Class。

在脚本 OP 上创建自定义参数

与 COMPs 上的自定义参数类似，Script CHOP、Script SOP 或 Script DAT 等脚本 OP 允许你通过脚本 OP 的回调来定义自定义参数： 

def setupParameters(scriptOp):
	page = scriptOp.appendCustomPage('Custom')
	page.appendFloat('Valuea', label='Value A')
	page.appendFloat('Valueb', label='Value B')
	return

修改 setupParameters() 回调函数后，脉冲脚本 OP 的「Setup Parameters」参数以执行参数创建。

自定义参数名必须以大写字母开头，后面只能跟小写字母、数字或下划线。

在脚本 OP 上访问自定义参数

脚本 OP 中的参数可以通过多种方式访问。第一种是通过 onPulse() 回调访问按钮类型参数。在下例中，脚本 OP 有两个自定义 pulse 按钮。onPulse() 回调会打印被按下按钮的名称。 

# 在 OP 中按下 'Setup Parameters' 可调用此函数重新创建参数。
def setupParameters(scriptOp):
	page = scriptOp.appendCustomPage('Custom')
	page.appendPulse('Buttona')
	page.appendPulse('Buttonb')
	return

# 每当推入自定义 pulse 参数时调用
def onPulse(par):
	print(par.name)
	return

滑块的值通过用脚本名调用参数来访问。在下例中定义了两个滑块，通过在 cook() 回调中添加 print() 函数，每次计算时访问它们的值： 

# 在 OP 中按下 'Setup Parameters' 可调用此函数重新创建参数。
def setupParameters(scriptOp):
	page = scriptOp.appendCustomPage('Custom')
	page.appendFloat('Slidera')
	page.appendFloat('Sliderb')
	return

def cook(scriptOP):
	scriptOp.clear()
	print(scriptOp.par.Slidera)
	print(scriptOp.par.Sliderb)
	return

编辑自定义参数

自定义参数是 Par Class 的实例，因此可以用 Par Class Members 修改。

例如，下面的脚本用于创建 2 个 float 参数滑块，标签分别为「Value0」和「Value1」： 

# 在名为 base1 的 Base COMP 节点上创建 2 个浮点参数
baseOp = op('base1')
newPage = baseOp.appendCustomPage('Custom')
newPar = newPage.appendFloat('Valuea', label='Value A')
newPar = newPage.appendFloat('Valueb', label='Value B')


之后可以通过访问 Par Class 来编辑参数的所有属性。例如，下面的脚本把两个 float 参数滑块的标签改为「Float Slider 1」和「Float Slider 2」： 

# 编辑名为 base1 的 Base COMP 节点上 2 个浮点参数的标签
baseOp = op('base1')
baseOp.par.Valuea.label = 'Float Slider A'
baseOp.par.Valueb.label = 'Float Slider B'


同样可以用下面的脚本把赋给这些参数的脚本名改为「Floatsliderx」和「Floatslidery」： 

# 编辑名为 base1 的 Base COMP 节点上 2 个浮点参数的标签
baseOp = op('base1')
baseOp.par.Valuea.name = 'Floatsliderx'
baseOp.par.Valueb.name = 'Floatslidery'

删除自定义参数

可以通过调用参数的 destroy 方法删除自定义参数，如下： 

# 这将从 Base COMP 'base1' 中移除名为 'Speed' 的自定义参数
baseOp = op('base1')
baseOp.par.Speed.destroy()

或者从一个 Operator 中移除所有自定义参数： 

# 这将从 Base COMP 'base1' 中移除所有自定义参数
baseOp = op('base1')
baseOp.destroyCustomPars()

启用和禁用自定义参数

可以用下面的脚本把自定义参数设为启用或禁用状态： 

# 在名为 base1 的 Base COMP 节点上创建一个 pulse 按钮参数
baseOp = op('base1')
newPage = baseOp.appendCustomPage('Controls')
newPar = newPage.appendPulse('Startsearch', label='Click to start search')

# 禁用该 pulse 按钮
baseOp.par.Startsearch.enable = False

# 启用该 pulse 按钮
baseOp.par.Startsearch.enable = True

你可以用 Parameter Execute DAT 监视另一个参数，并在它变化时改变该参数的启用状态。

对自定义参数排序

可以在同一个 Parameter Page 上如下重排自定义参数： 

# 假设 Base COMP 'base1' 有 3 个自定义参数，按 'Color'、'Speed'、'Value' 的顺序显示
baseOp = op('base1')
page = baseOp.customPages[0]  # 假设在第一页
page.sort('Speed','Color','Value')

如果这些参数不在同一页上，顺序不会受到影响。

在页面之间移动参数

只需给自定义参数的 page 成员赋一个新值，就能在 Parameter Pages 之间移动它们。 被移动的参数会保留其所有属性，包括所有成员，例如 min、max 和 default 的值。 一个 tuplet 中的所有参数都显示在同一页上。 

# 在页 'Car Controls' 上创建参数
baseOp = op('base1')
p = baseOp.par.Size
p.page = 'Car Spec'  # tuplet 中的其他参数将紧随其后。

删除自定义参数页

直接调用自定义 Parameter Page 的 destroy 方法即可将其删除。 

baseOp = op('base1')
page = baseOp.customPages[0]
page.destroy()

重排自定义参数页

可以通过指定新的顺序来重排自定义 Parameter Pages： 

baseOp = op('base1')
baseOp.sortCustomPages('Car Controls', 'Car Spec')

列出自定义参数

可以用 customPars 方法返回添加到某个操作符的所有 Custom Parameters 的列表。该列表按它们在 Parameter Dialog 中出现的顺序排列： 

baseOp = op('base1')
baseOp.customPars

列出自定义参数页

可以用 customPages 方法返回添加到某个操作符的所有 Custom Parameters 页的列表。该列表按它们在 Parameter Dialog 中出现的顺序排列： 

baseOp = op('base1')
baseOp.customPages

从网络内部访问自定义参数

在包含自定义参数的组件中，在网络中右键单击并选择 Open Parent Parameters。

使用自定义参数的值

创建之后，自定义参数的用法与任何同类型内置参数相同。访问参数值（包括自定义参数）有多种方式。

第一种是在组件内部直接使用类似 parent().par.Length 的表达式。

第二种是使用 Parameter CHOP。Parameter CHOP 会按类别或名称模式，从被引用的组件中获取自定义参数和标准参数。它会为每个选中的参数创建一个 CHOP 通道。

第三种是使用 Parameter Execute DAT。该 DAT 为它所引用的参数提供 Python 回调函数。

克隆体中的自定义参数

这里指的是设置了 Clone 参数的组件克隆体上的参数，而不是这些克隆体内部的参数。

通常，自定义参数的属性（如标签、默认值、最大/最小值、菜单项）会传播到所有克隆体。可以把自定义参数的 styleCloneImmune 属性设为 True 来关闭这一特性。

参数的当前值及其 Parameter Mode do not 会传播到所有克隆体。它们与主节点的其他参数或 Flag 一样，在每个克隆体中保持独立。

参数顺序会自动传播到克隆体。页面顺序也会自动传播到克隆体。
