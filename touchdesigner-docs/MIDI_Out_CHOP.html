MIDI Out CHOP

摘要

MIDI Out CHOP 在其输入通道变化时向任何可用的 MIDI 设备发送 MIDI 事件。更灵活地，可以使用 Python midioutCHOP Class 通过现有的 MIDI Out CHOP 向 MIDI 设备发送任何类型的 MIDI 事件。在 Tscript 中，midi 命令可以输出 MIDI 事件。

MIDI 设备可以是其他软件程序（如 midisynth），也可以是连接到串口的设备。通道用于控制 MIDI 事件的发送。通道在最近的时间切片上求值（从上一个 Timeline 位置到当前位置）。

MIDI Out CHOP 根据其输入通道的任何变化发送 MIDI 事件。通道必须按适当方式命名，例如 ch3c14 和 ch7n60。

在此切片期间，每当通道值发生变化就会发送一个事件。只要 Timeline 以实时方式运行（"Realtime" 标记位于顶部菜单栏中），所有时序都会保留。

命名 CHOP 通道：通道通过名称映射到事件。音符、控制器和力度等事件后面必须跟音符/控制器编号（n65、c7）。若音符事件省略了编号，则音符编号为通道的值。其他事件会发送到整个通道，无需尾随编号（pc、pw）。通道前缀可用于标识事件应发送到哪个 MIDI 通道（即 "ch1n45" 将该 TouchDesigner 通道指定给 MIDI 通道 1 上的音符 45 消息）。进入 MIDI Out CHOP 之前，通道始终可以用 Rename CHOP 重命名。

MIDI Out CHOP 也会发送 MIDI 力度。进入 MIDI Out CHOP 的通道值会作为音符的力度发送。若 Normalize 为 "None"，通道值需为 0 到 127。若 Normalize 为 "0 to 1"，0 到 1 之间的通道值会被缩放为 MIDI 的 0 到 127。

"Cook Every Frame" 选项会让 CHOP 每帧计算，即使该 CHOP 未被显示。All Volume Off 和 All Volume On 标记是新增的，会为全部 16 个通道的 Controller 7 发出事件。MIDI 输出在单独的线程中进行，以减少对 TouchDesigner 的拖慢。现在它在 Time Slice 模式下支持音符事件和控制器事件。（尚不支持 Program Change 或 Sysex 消息）音符通道仅当输入通道从 0 或更小变为大于零的值时才会重新触发 Note On。Note Off 事件类似。通道名称决定其如何被解释。

例如，

ch3n60 - 此通道被解释为通道 3 的音符 60。当值从 0 或更小变为大于零时，会发送 Note On 事件
ch5n - 此通道将包含音符编号。 该值会被量化为整数，当整数值改变时，旧值的音符关闭，新值的音符开启。如果通道从 53 跳到 78，会为音符 53 发送 Note Off 事件，为音符 78 发送 Note On 事件。
ch14c7 - 该通道的值会发送到通道 14 的控制器 7（音量）。默认情况下，0 到 1 的值映射到 MIDI 值 0 到 127。

以下功能在 Time Slice 模式下可用：

默认情况下，通道以 "ch" 开头，后接通道编号（1-16）。对于音符，则后接 "n" 表示音符，再接音符编号的数字。对于控制器，则后接 "c" 和控制器编号。这些前缀可以修改。MIDI Out 现在会解释触后、压力、弯音轮通道，并把这些事件输出到 MIDI 流。新增了音符归一化，允许 0 到 127 和 0 到 1 的范围。MIDI Out 读取一个 bar ramp 通道以输出 MIDI 时钟事件（参数旁有通道弹出菜单用于选择通道名称）。Program change 事件通过 "pc" 通道实现。7 位和 14 位控制器事件都可以输出。你可以捕获 MIDI 流并输出到文件。

另请参阅 MIDI In DAT、MIDI Event DAT、MIDI In Map CHOP、MIDI In CHOP、midi 命令。

参数 - Dest 页

Active active - 启用或禁用 MIDI Out CHOP。
MIDI Destination destination - - MIDI 事件发送到哪里。MIDI Mapper 是默认目标。
  • Device device -
  • File file -
Device Table device - MIDI 设备的路径 Table DAT。
Device ID id - 指定要使用的设备 id。
One Based Index onebased - 使索引从 1 开始而非默认的从 0 开始。
MIDI File file - 输出 MIDI 文件的文件名。
Write MIDI File writefile - 将所有数据写入 MIDI 文件。
Channel Prefix prefix - 所有输入通道必须具有的前缀字符串，用于从通道名中提取通道号（即 "ch1note44"，通道前缀为 "ch"）。
Cook Every Frame cookalways - 强制 CHOP 每帧计算。应设为 On，因为否则 MIDI Out CHOP 只有在 CHOP 通向图形显示查看器时才会计算。你希望无论是否显示任何内容它都能计算。

  • None none -

参数 - Control 页

Controller Name controlname - 控制器通道的基础名称。
Controller Format controlformat - - 发送 7 位或 14 位控制器事件。
  • 7 bit Controllers 7bit - 发送单条 7 位控制器消息。
  • 14 bit Controllers 14bit - 将两条 7 位控制器消息配对，解释为单条 14 位消息。

请注意，指定的控制器索引必须在 0-31 范围内，因为 32-63 范围保留给要发送的相应消息对。因此在 此模式下，32-63 范围被保留且用户无法访问。此外，64-95 范围保留给 7 位消息，所以索引范围 64-95 内的任何消息都会作为单条 7 位消息发送。

Normalize controlnorm - - 将不同范围的通道值映射到 0-127。
  • None off -
  • 0 to 1 0to1 -
  • -1 to 1 -1to1 -
  • On/Off onoff -
Program Change progname - program change 通道的名称。
Bar Ramp Name barname - 时钟 tick 频率由斜坡的周期决定。斜坡必须为 0 到 1。为每个 4 拍小节提供 0 到 1 斜坡的输入通道名称。
Ticks per Bar barticks - 默认为 96 = 4 拍 * 每拍 24 tick。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

MIDI Out CHOP 的额外信息可通过 Info CHOP 访问。

MIDI Out CHOP 特定的 Info 通道

  • events_sent -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
