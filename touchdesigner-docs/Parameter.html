参数

TouchDesigner 中的每个操作符都有一组控制参数，可以是整数或浮点数、菜单、二元开关、文本字符串或操作符 paths，它们决定操作符的输出。

参数对话框通常位于网络编辑器的右上方。按 p 可以关闭和打开参数对话框。右键单击操作符并选择「Parameters...」，即可打开任意操作符的参数对话框。

TouchDesigner 中的参数只存在于 Operators（OP 或「节点」）中。参数类型包括：

  • 数字，包括整数和浮点数
  • 数字对、三元组或四元组（例如宽度和高度、XYZ 位置、RGBA 颜色）
  • 开关标记（toggle）
  • 菜单
  • 文本字符串
  • 指向 TouchDesigner 网络中其他节点的 paths
  • 启动操作（如运行脚本）的「脉冲」按钮
  • python 对象 - 任何可以用数字、True/False 值、字符串、列表和字典构造的 python 对象。该 python 对象必须是自包含的，例如不能引用其他操作符或参数。

某些情况下，多个参数在表示单个数据单元时会被归为一组。这些就是参数组，即 ParGroups。例如，颜色参数组包含红色、绿色和蓝色（有时还有 alpha）参数。严格来说，所有参数都属于某个参数组，即使它是只含一个参数的组。

请参阅 Component Editor 以创建自定义参数并了解可用的参数类型范围。有关在 Python 中操作参数的详细信息，请参阅 Par Class 和 ParGroup Class。

参数模式与求值

每个 Parameter 都可以处于四种模式之一：Constant 模式、Expression 模式、Export 模式或 Bind（Binding）模式。「evaluated parameter」是参数基于其模式、表达式、导出或绑定得到的结果值。

当 Parameter Mode 处于 Expression 模式时，参数可以由 Python 表达式驱动。

提示：光标位于参数中时按 ctrl-e/Cmd+e，会在文本编辑器中打开当前参数的表达式，便于查看和编辑较长的表达式。

通过将 Exporting 个 CHOP 通道导出到参数，参数可以由 CHOPs 驱动，此时参数进入 Export Mode。在下面的参数对话框示例中，Y-Translate 参数正通过 CHOP 通道导出被控制。这由对话框中参数显示的绿色表示（绿色代表 CHOP！）。

使用 Binding 可以将参数与其他参数和 CHOP 通道双向同步。参数将进入 Bind Mode。

重要：op('pattern1').par.phase 是 python 的 parameter object，通常会为你转换为求值后的值，例如在参数表达式中使用时。更安全的做法（尤其是在脚本中使用参数时）是使用 op('pattern1').par.phase.eval()，它始终给出最终求值结果。


参数属性

参数还有许多其他属性，其中一些取决于参数类型。完整的 Python 细节请参阅 Par Class 和 ParGroup Class。

  • name（鼠标悬停在参数上时看到的内部 python 名称）
  • label
  • 默认值
  • 最小值、最大值、下限钳制、上限钳制、下限钳制值、上限钳制值（用于整数和浮点数）
  • 菜单条目
  • enable 标记和 enable 表达式（决定你能否访问该参数 - 通常意味着在其他参数的当前状态下它不相关）
  • 只读 - 参数处于活动状态并在求值，但在关闭只读之前无法手动编辑
  • 分区分隔线 - 在界面中，前面的参数之后会出现一条线

自定义参数

自定义参数是用户创建的参数，可以添加到 Components、Custom Operators 以及脚本操作符（Script TOP / Script CHOP / Script SOP / Script DAT / Script POP）中。对于组件和脚本操作符，可以在 Component Editor 中创建/编辑/删除它们。

更多信息请参阅 Custom Parameters。
