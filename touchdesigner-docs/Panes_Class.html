Panes 类

Panes 类描述所有 pane objects 的列表。可通过 ui.panes 访问。

成员

current → td.Pane (Read Only):

当前选中的 pane。

方法

createFloating(type=None, name=None, maxWidth=1920, maxHeight=1080, monitorSpanWidth=0.9, monitorSpanHeight=0.9)→ Pane:

返回一个浮动窗格。

  • type - （关键字，可选）所创建窗格的类型。示例见 Pane。默认为 Network Editor。
  • name - （关键字，可选）窗格名称。可用此值在 ui.panes 中找到该窗格。
  • maxWidth - （关键字，可选）所创建窗口宽度的上限。以像素为单位。
  • maxHeight - （关键字，可选）所创建窗口高度的上限。以像素为单位。
  • monitorSpanWidth - （关键字，可选）以显示器宽度的比例指定窗口宽度。
  • monitorSpanHeight - （关键字，可选）以显示器高度的比例指定窗口高度。

示例 

    p = ui.panes.createFloating(type=PaneType.NETWORKEDITOR, name="Output")
    p.owner = op('/project1/base1')

特殊函数

len(Panes)→ int:

返回窗格总数。 

a = len(ui.panes)

[index]→ td.Pane:

按字符串或索引获取特定窗格。 

p = ui.panes[0]
p = ui.panes['pane1']

Iterator→ td.Pane:

遍历每个窗格。 

for n in ui.panes:
	# 对 n 做些什么
