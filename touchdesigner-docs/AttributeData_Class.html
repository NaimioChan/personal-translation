AttributeData 类

AttributeData 包含特定的几何 Attribute 值，与 Prim Class、Point Class 或 Vertex Class 相关联。属性的每个值必须是同一类型，可以是 float、string 或 integer。例如，点或顶点法线属性数据由 3 个 float 值组成。

成员

owner → OP (Read Only):

此对象所属的 OP。

val → float | int | str | tuple | TDU.Position | TDU.Vector (Read Only):

此对象中包含的一组值。取决于属性的类型，它可能返回 float、integer、string、tuple、Position 或 Vector。例如，Normal 属性数据表示为 Vector，而 Position 属性数据表示为 Position。

方法

没有该操作符专属的方法。
