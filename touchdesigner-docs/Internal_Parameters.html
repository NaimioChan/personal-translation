内部参数

Parameters 是在 TouchDesigner 中保存数据的强大方式。但如果把只在内部使用的参数放在 component 的顶层，会让组件显得杂乱。「内部参数」为你在组件内创建的参数集合提供简单快捷方式，可从该组件内任何位置访问。它们就像「持久化的局部变量」。

最简流程

最简单的方式是，在网络背景上右键并选择 Create Internal Parameters...。你取一个快捷方式 Name。（默认是 Parent Shortcut 名称（如果存在），或「Local」。）按下 Apply 后，它会在你的网络中创建一个 Base COMP（名为 iparName），你可以在其中添加一组自定义参数。当你为 Base COMP 添加参数 Parname 后，网络中的任何位置都可以用类似 ipar.Name.Parname 的表达式引用它。

（这是在父组件的 Common 页上设置的，快捷方式名称和 Base COMP 的路径分别在 Internal OP Shortcut 1 和 Internal OP 1 中。）

ipar.Name 会在父组件层级中向上搜索，直到找到具有匹配 Internal OP Shortcut 名称的组件。 从那里它找到保存该组参数的 Base COMP。

另请参阅 Internal Operators。

手动流程

进入任意组件，例如默认 TouchDesigner 的 /project1。 创建一个 Base Component，并命名为 iparEffect。

在 iparEffect 上创建一个 Float Custom Parameter 并命名为 Size。

转到 /project1 的参数，进入 Common 页。将 Internal OP Shortcut 1 设为 Effect，为你的内部快捷方式命名。

将 Internal OP 1 设为 ./iparEffect，给出新 Base 组件的路径。

现在在组件内获取和设置该 base 组件的参数就很容易了：

回到 project1 中并创建一个 Circle SOP。在其 Radius 参数中输入 ipar.Effect.Size。

更改 iparEffect 上的 Size 参数。Circle SOP 上的表达式会正确更新。

要在 python 脚本中设置 Size 参数，创建一个 Text DAT 并在其中写入：ipar.Effect.Size = 1.7

在 Text DAT 上关闭 Viewer Active，然后在节点上右键 → Run Script。iparEffect 上的 Size 参数会变为 1.7。

理由

将值作为参数保存在组件内部，相比把值保存在表格、Constant CHOP、Extensions 或 Storage 中具有优势，详见下文的优缺点。内部参数使用简单，可以减少甚至消除在扩展中编写代码的需要。而且通过在组件内创建参数，它们不会不必要地暴露到外部。 另请参阅 Internal Operators 或 iOP。

建议

给内部参数扩展取一个有意义的名字。如果它是一堆影片，把 Parent Shortcut 参数命名为 Bin，内部参数名称也用 Bin。

与任何参数一样，如果内部参数是操作符路径，你必须写成例如 op(ipar.Effect.Oppath) 或 ipar.Effect.Oppath.eval()。否则一般不需要 .eval()。

要在网络中方便地查看已求值的参数，在 Base COMP 中放一个 Parameter DAT，并在 Base COMP 的 OP Viewer 参数中填入 ./parameter1。查看器现在会显示 Parameter DAT 的参数表格。

当内部参数出现在参数表达式中时，要查看它来自哪里，选中文本 ipar.Effect 并将光标放在参数标签上。它会显示其路径。

讨论 - 在 TouchDesigner 中保存和修改数据的位置

回顾一下，TouchDesigner 中已有多种在内部保存数据的方式：

  • 位于 Table DAT 单元格和 Text DATs 中的文本字符串
  • 已有参数（在 Constant CHOP、Add SOP…… 上）
  • 组件外部的 Custom Parameters
  • 作为「locked」的 CHOP、SOP 和 TOP（且更难修改）
  • 任意操作符中的 TouchDesigner-python Storage
  • TouchDesigner-python Extension「Properties」
  • 函数和脚本中的常规 python 变量（脚本运行后不持久）
  • 保存在 Script CHOP、Script DAT 和 Script SOP 中、用于生成数据的数据
  • Dialogs → Variables，你可以在其中创建变量并通过 var('VARNAME') 在 python 中访问。它们只是字符串。这些变量不常用。
  • 内部参数

内部参数的优缺点

优点

  • 过程式（更改参数会可靠地触发下游计算）
  • 易于手工编辑
  • 提供良好的视觉反馈 - 你可以看到数值实时变化
  • 可以给它们易于理解的标签
  • 它们的值可以是依赖其他数据的 python 表达式，并以过程式方式求值。这些自定义参数可以由动画表达式驱动。
  • 可以用动画通道导出到它们
  • 对数据完整性有严格控制：它们有默认值，强加了最小和最大范围，菜单有特定值和标签
  • 可以处理多种数据类型（字符串、True/False 布尔值、整数、浮点数、菜单、操作符路径、python 列表）
  • 使用新的 Python 参数类型，参数还可以保存 python 列表或字典，其元素为简单字符串、布尔值、整数和浮点数。（与所有自定义参数一样，你在 Component Editor 中右键 → Customize Component 创建 Python 参数）
  • 持久 - 它们作为常规参数保存在 .toe 或 .tox 中
  • 开发时语法错误更少
  • 可与扩展配合使用，有时可替代扩展
  • 代码更少，要学的更少：你不需要在 DAT 中编写 python 类来定义任何东西。
  • 速度与任何地方的参数相同，至少与 DAT 单元格中的动画数值一样快。
  • 比扩展或回调中的 python 代码更快，因为它们被编译为优化的可执行格式。（将鼠标悬停在带表达式的参数上，你可能会看到「Optimized」字样，表示它已编译为执行代码。）

限制

  • 在参数中，你无法轻易表示 SOP 数据（点、多边形、图元、属性）以及复杂的 python 结构。
  • 过去无法管理一维、二维或三维数字的长列表或大型数组，不过现在有了 Python 参数类型，例如可以保存简单列表。
  • 内部参数（任何参数）比 DAT 单元格占用更多内存，但与任何自定义参数相同。
  • 操作符类参数的语法是：op(ipar.Effect.Operatorpath)。如上所述，当参数不是浮点数、整数、布尔值或字符串，而是操作符（如某个节点的路径）时，在表达式中某处使用 ipar.Effect.Operatorpath 可能解析为参数对象而非你想要的值，因此需要写成 op(ipar.Effect.Operatorpath)。Python 类型参数同理。

从组件外部访问 ipar

你可能想获取另一个组件某个 ipar 的值，或者想让组件上的某个参数使用该组件的 ipar。

由于是「内部」的，用 ipar 无法做到。但你可以使用组件的一个成员来访问它：COMP.internalParameters[Name]，其中 Name 是你想要的 ipar 名称。 COMP.internalParameters 是组件上找到的内部参数快捷方式字典。

另请参阅 Internal Operators。
