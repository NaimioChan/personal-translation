OpenVR CHOP

摘要

注意

OS: 此操作符仅在 Microsoft Windows 操作系统下受支持。

OpenVR CHOP 从 OpenVR SDK 接收位置数据、帧渲染信息和动作数据。每个 CHOP 可以以 5 种模式之一输出：Sensors、Projection Matrices、Trackers、Frame Timings、Actions 和 Skeletons。

动作

动作在 OpenVR Actions 中有更详细的说明。

以更高频率获取传感器数据

默认情况下，运行 VR 系统时，文件会被 OpenVR SDK 限制为 VR 设备的刷新率。这有助于确保良好 VR 体验所需的低延迟输出。如果在非 VR 情况下只使用控制器/Vive 追踪器进行追踪，只要项目中没有任何 OpenVR TOP，文件就可以以更高的采样率运行并采样这些设备。如果项目中任何位置存在 OpenVR TOP，那么播放就会被限制为 VR 设备的刷新率。

另请参阅 OpenVR、OpenVR TOP、OpenVR SOP、Audio Render CHOP

参数 - Setup 页

Active active - 控制此节点是否从 OpenVR 驱动查询数据。
Output output - - 控制此节点将输出哪一类数据。
  • Sensor sensor - 输出传感器朝向等数据，以及渲染分辨率等常规信息。
  • Projection Matrices projmatrices - 输出每只眼睛的投影矩阵。
  • Trackers trackers - 输出追踪器状态/变换。这既可以包括 Vive Trackers，也可以只是控制器的变换。
  • Frame Timings frametimings - 有关帧渲染的常规信息。
  • Actions actions - 系统所使用的 OpenVR Actions 定义的动作通道。
  • Skeletons skeletons - 手部骨架信息，如 here 所述。请注意，OpenVR 已不再支持 'Finger Tip Bones'。
Max Trackers maxtrackers - 此节点应输出数据的追踪器最大数量。
First Tracker firsttracker - 要输出的第一个追踪器编号。例如，若此项设为 2 且 Max Trackers 为 2，则将输出追踪器 2 和 3 的数据。
Orientation orientation - 进行 'Sensor' 输出时，控制是否输出朝向通道。默认朝向的单位是 1 单位 = 1 米。
General Info generalinfo - 进行 'Sensor' 输出时，控制是否输出常规信息通道，例如渲染分辨率和游玩区域大小。
Near near - 输出 'Projection Matrices' 时，控制构建投影矩阵所用的近裁剪面。
Far far - 输出 'Projection Matrices' 时，控制构建投影矩阵所用的远裁剪面。
Unit Scale unitscale - OpenVR 默认使用 1 单位 = 1 米的缩放。此参数允许改变缩放，以防导入的场景使用了不同的缩放。
Custom Actions customactions - 打开以允许指定自定义 OpenVR Actions manifest 文件。
Action Manifest actionmanifest - OpenVR Actions manifest 文件的路径。默认情况下，这与 Custom Actions 禁用时 OpenVR 使用的 manifest 相同。
Use Legacy Names uselegacynames - 使用来自 Action Manifest 的旧版通道命名约定。除非要加载已有的旧文件，否则应保持关闭。
Skeleton Range skeletonrange - - 控制骨架值的运动范围。
  • With Controller withcontroller - 输出考虑控制器形状的骨架。骨架看起来像是握着控制器。
  • Without Controller withoutcontroller - 输出如同控制器不存在的骨架。这允许骨架形成完全闭合的拳头。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

OpenVR CHOP 的额外信息可通过 Info CHOP 获取。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
