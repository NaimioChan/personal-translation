Panel COMP 颜色页

参数 - Color 页

Color 参数页设置面板的背景色、边框色和禁用色。

Background Color bgcolor[rgb] bgalpha - 背景的 RGBA 值。（默认：black (0,0,0,0)）

Border A bordera[rgb] borderaalpha - 边框 A 颜色的 RGBA 值。

Border B borderb[rgb] borderbalpha - 边框 B 颜色的 RGBA 值。

Left leftborder leftborderi - 最左侧 2 个像素的颜色。选项为 0（不改变）、Border A（使用 Border A 中定义的颜色）或 Border B（使用 Border B 中定义的颜色）。

Right rightborder rightborderi - 最右侧 2 个像素的颜色。选项为 0（不改变）、Border A（使用 Border A 中定义的颜色）或 Border B（使用 Border B 中定义的颜色）。

Top topborder topborderi - 最上方 2 个像素的颜色。选项为 0（不改变）、Border A（使用 Border A 中定义的颜色）或 Border B（使用 Border B 中定义的颜色）。

Bottom bottomborder bottomborderi - 最下方 2 个像素的颜色。选项为 0（不改变）、Border A（使用 Border A 中定义的颜色）或 Border B（使用 Border B 中定义的颜色）。

Multiply RGB by Alpha multrgbbyalpha - 把 RGB 通道乘以 alpha 通道。

Border on Top panelborderontop - 在所有同级面板之上绘制面板的边框。

Composite panelcomposite - 选择面板与同级面板的合成方式。各种合成方法的说明请参阅 Composite TOP。
