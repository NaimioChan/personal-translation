Superquad SOP

摘要

Superquad SOP 生成等二次曲面（isoquadric surface）。它产生类似 metaball 的球状形状，不同之处在于它不会因周围环境而改变形状。你可以改变等二次曲面的 XY Exponent，使其形状更「方」或更「星形」。此外，等二次曲面始终定义为多边形或网格类型的几何。

参数 - 页

Primitive Type type - 从以下类型中选择。关于不同类型的信息，见 Primitive 一文。取决于所选的图元类型，某些 SOP 选项可能不适用。
  • Polygon poly -
  • Mesh mesh -
Connectivity surftype - 使用 Mesh 图元类型时，此选项用于选择曲面类型。
  • Rows rows - 创建水平线。
  • Columns cols - 创建垂直线。
  • Rows and Columns rowcol - Rows 和 Columns 都勾选。在线框显示下看起来像四边形，但所有多边形都是开放的（如果图元类型为 polygon）。
  • Triangles triangles - 用三角形构建网格。
  • Quadrilaterals quads - 生成由四边形构成的侧面（默认）。
  • Alternating Triangles alttriangles - 生成相对的三角形；类似于 Triangles 选项。
Modify Bounds modifybounds - 仅当有输入连接到 Superquad SOP 以设置 superquad 的边界时可用。当 Modify Bounds = On 时，下方的 transform 参数会进一步修改边界的位置和半径。
Radius rad - 决定整体半径。
  • X radx -
  • Y rady -
  • Z radz -
Center t - superquad 中心相对对象中心的偏移。
  • X tx -
  • Y ty -
  • Z tz -
Reverse Anchors reverseanchors - 反转锚点的方向。
Anchor U anchoru - 设置 X 方向上的点，几何围绕该点定位、缩放和旋转。
Anchor V anchorv - 设置 Y 方向上的点，几何围绕该点定位、缩放和旋转。
Anchor W anchorw - 设置 Z 方向上的点，几何围绕该点定位、缩放和旋转。
Orientation orient - 决定等值面的极轴。
  • X Axis x -
  • Y Axis y -
  • Z Axis z -
Rows rows - superquad 使用的行数。
Columns cols - superquad 使用的列数。
XY Exponent expxy - XY Exponent 决定 X 和 Y 轴上的膨胀/收缩。
Z Exponent expz - Z Exponent 决定 Z 轴上的膨胀/收缩。有关指数的说明，见 Metaball SOP。
Multiple Points per Pole upole - 决定极点处的点是共享的还是各列独有的。
Cusp Polygons cusp - 使点独一无二，从而让 superquad 呈分面状。
Cusp Angle angle - 以度为单位的输入角度，用于决定顶点何时不共享，从而产生尖角。
Texture Coordinates texture - 为球体添加 UV 纹理坐标。
  • Off off - 不向曲面添加 UV 坐标。
  • Row & Columns rowcol - 添加顶点 UV 坐标。
Compute Normals normals - 在几何上创建法线。

Info CHOP 通道

Superquad SOP 的额外信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
