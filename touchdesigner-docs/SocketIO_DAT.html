SocketIO DAT

摘要

SocketIO DAT 连接到指定 URL 的 Socket.IO 服务器。

SocketIO DAT 有 4 个输入，顺序如下（example）：

  1. Additional headers，表格格式，两列，结构为名称/值对。等同于 extraHeaders 选项。
  2. Server events，表格格式，结构为单列事件名称。当服务器发出这些事件中的任何一个时，将触发 onReceiveEvent 回调。
  3. Additional query parameters，表格格式，两列，结构为名称/值对。等同于 query 选项。
  4. Authentication parameters，表格格式，两列，结构为名称/值对。典型的 socket.io 认证用法需要 token 条目。等同于 auth 选项。

SocketIO DAT 也可以向服务器发出事件。这通过 Python 的 emit 方法完成。不支持确认回调。

SocketIO DAT 使用 socket.io's C++ Client API v3.1.0 构建，可与 socket.io v3 或 v4 服务器配合使用。

SocketIO DAT 会将 socket.io 状态消息打印到 TouchDesigner 文本控制台。可通过设置环境变量 TOUCH_TEXT_CONSOLE=1 启用文本控制台（见：https://docs.derivative.ca/Variables#System_Environment_Variables）。文本控制台将在下次启动 TouchDesigner 时打开。

另请参阅：WebSocket DAT、Web Client DAT

socketioDAT_Class

参数 - Connect 页

Active active - 启用后，SocketIO DAT 会主动监听来自服务器的事件，也可以发出事件。
Reset reset - 断开连接然后重新连接。
URL url - socket.io 服务器的 URL。
Verify Certificate (TLS) verifycert - 启用 TLS（传输层安全）证书验证。
Reconnect Delay delay - 重连尝试之间的延迟（毫秒）。

参数 - Received Messages 页

Callbacks DAT callbacks - 每收到一条消息，Callbacks DAT 执行一次。
Execute from executeloc - 决定脚本的运行位置。
  • Current Node current - 脚本从当前节点位置执行。
  • Callbacks DAT callbacks - 脚本从 Callbacks DAT 参数中指定的 DAT 所在位置执行。
  • Specified Operator op - 脚本从下方 From Operator 参数指定的操作符中执行。
From Operator fromop - 当 Execute from 设为 Specified Operator 时，其状态变化将触发 DAT 执行脚本的操作符。如果 Execute from 参数设为 Specified Operator，该操作符也是脚本执行时的所在路径。
Clamp Output clamp - 该 DAT 默认限制为 100 条消息，但使用 Clamp Output 可以设为任意值，包括无限制。
Maximum Lines maxlines - 限制消息数量，较旧的消息会先从列表中移除。
Clear Output clear - 删除除标题外的所有行。若要用 python 脚本清除 op("opname").par.clear.pulse()
Bytes Column bytes - 在单独的列中输出消息的原始字节。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

操作符输入

  • Input 0: -
  • Input 1: -

Info CHOP 通道

SocketIO DAT的额外信息可通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
