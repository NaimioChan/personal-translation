Leap Motion CHOP

摘要

Leap Motion CHOP 从 Leap Motion 控制器读取手、手指、工具和手势数据。它输出手、手指和工具的位置、旋转以及 'tracking' 通道，这些通道指示这些值当前是否被检测到并在更新。目前一次只能连接 1 台 Leap Motion 设备。

要连接设备，你需要安装 Ultraleap Tracking Software。为获得最佳性能，建议使用此处提供的最新版 Gemini 驱动，Windows 版（v5.13.2 或更高）或 MacOS 版（v5.14.0 或更高）：https://developer.leapmotion.com/tracking-software-download。旧版 2 或版本 4 的 Orion 驱动也受支持。更多信息请参阅下面的 API 参数详情。

除了安装驱动，还必须告诉 TouchDesigner 在哪里找到跟踪库。安装说明因操作系统而异：

On Windows: 你可以使用 Library Folder 参数指向系统中 LeapC.dll（Orion/Gemini）或 Leap.dll（Version 2/3）文件的位置。该文件随 LeapSDK 一起安装，位置可能因版本和安装时选择的选项而异。

On MacOS: 库文件夹应指向 Ultraleap 跟踪应用的位置。默认是 '/Applications/Ultraleap Hand Tracking.app'，TouchDesigner 会自动在该应用的内容文件夹中找到库文件。

提示： 如果使用 Gemini V5，Leap Motion 只能在一个朝向下工作。默认情况下手从相机视图底部进入，不过可以在设置中改为反转方向。这是 Gemini V5 与旧版 V2/V4 API 之间的一个重要区别，后者可以在任一朝向下工作。

注意： TouchDesigner 不包含使用 Leap Motion 硬件或软件的许可。请务必向 UltraLeap website 查询你的项目可能需要的任何适用许可。

另请参阅 Leap Motion、Leap Motion TOP

参数 - Setup 页

Active active - 当为 'On' 时，从 Leap Motion 传感器捕获数据。
API api - - 选择使用 Leap Motion V2 还是 V4/V5 SDK 进行跟踪。V5 提供最快最稳定的跟踪，V2 提供一些旧版功能，如手势。
  • Version 2 Tracking default - 旧版跟踪，包含手势和工具跟踪。下载 (Windows: Orion Beta 3.2.1, MacOS: 2.3.1)
  • Orion (v4) / Gemini (v5) on - Gemini 提供最佳性能，稳定性更好，手部识别更快，可更快开始跟踪。下载 Gemini (Windows 5.13.2 or greater, MacOS 5.14 or greater) 。旧版 4 Orion 跟踪仅在 Windows 上可用。下载 Orion 4.1.0。
Library Folder libfolder - 此参数仅在 Windows 上使用，用于指向与所选 API 版本对应的库文件（.dll）的位置。该 dll 文件可在从 Ultraleap 网站下载的驱动包中的 'LeapSDK/lib/x64' 文件夹内找到。对于 V4 和 V5，文件名为 'LeapC.dll'；对于版本 2，文件名为 'Leap.dll'。

对于 Gemini V5，请先安装跟踪软件，然后把此参数设为 C:\Program Files\Ultraleap\LeapSDK\lib\x64，它会在那里找到 LeapC.dll 文件。

HMD Mode hmd - - 把设备切换到 Head Mounted Display 模式。
  • Default default -
  • On on -
  • Off off -
Debug Channels debugchannels - 如果设置，将包含以下通道：
  • connected - 若 Leap Motion 传感器已连接则为 1，否则为 0。
  • sequence_id - 与当前帧对应的唯一 id。
Status Channels statuschannels - 如果设置，将包含以下通道：
  • hands - 传感器检测到的手的数量。
  • fingers - 传感器检测到的手指数量。
  • tools - 传感器检测到的工具数量。
  • gestures - 传感器检测到的手势数量。
  • [hand / finger / tool / circle / swipe / keytap / screeptap]:tracking - 如果手、手指、工具或手势的数据正在被主动跟踪则为 1，否则为 0。
Named Hands namedhands - 这将手部通道命名为右手（r）或左手（l）。
Hands hands - 手的数量。对于每只检测到的手，将包含以下通道：
  • hand*:t[xyz] - 手相对于传感器的坐标。
  • hand*:r[xyz] - 检测到的手的旋转。
Left Hands lefthands - 使用 'Named Hands' 时，指定将跟踪多少只左手。
Right Hands righthands - 使用 'Named Hands' 时，指定将跟踪多少只右手。
Hand Velocity handvelocity - 如果设置，对于每只手，除其他通道外还会包含以下通道：
  • hand*:v[xyz] - 检测到的手的速度。
Hand Sphere handsphere - 仅在使用 API = Version 2 Tracking 时可用。它会为被跟踪的手添加以下通道：
  • hand*/sphere:t[xyz] - 检测到的手部球体的位置。
  • hand*/sphere:radius - 检测到的手部球体的半径大小。
Pinch Strength pinchstrength - 捏合定义为拇指与食指之间的距离。
  • hand*:pinch - 检测到拇指与食指之间有多少捏合。
Grab Strength grabstrength - 抓取定义为手接近握拳的程度。
  • hand*:grab - 检测到多少抓取，强度为 0 表示平手，1 表示握拳。
Named Fingers namedfingers - 此选项不会简单地为每根被跟踪的手指使用手指索引号，开启后会把手指通道命名为 thumb、index、middle、ring 和 pinky。
Fingers per Hand fingersperhand - 不使用 'Named Fingers' 时，指定每只手要跟踪多少根手指。
Finger Rotation fingerrotation - 跟踪所有手指的旋转。
  • hand*/finger*:r[xyz] - 手指的旋转。
Finger Size fingersize - 如果设置，对于每根手指，除其他通道外还会包含以下通道：
  • hand*/finger*:length - 检测到的手指长度。
  • hand*/finger*:width - 检测到的手指宽度。
Finger Extended fingerextended - 跟踪手指的伸直程度，当手指像指向一样伸直时，被视为伸展。
  • hand*/finger*:extended - 手指的伸直程度。
Finger Joints fingerjoints - 跟踪每根手指每个关节的位置。
  • hand*/finger*/joint_mcp:t[xyz] - 手指的 mcp 关节位置。
  • hand*/finger*/joint_pip:t[xyz] - 手指的 pip 关节位置。
  • hand*/finger*/joint_dip:t[xyz] - 手指的 dip 关节位置。
  • hand*/finger*/joint_tip:t[xyz] - 指尖位置。
Tools tools - 工具的数量。对于每个检测到的工具，将包含以下通道：
  • tool*:t[xyz] - 工具相对于传感器的坐标。
  • tool*:length - 检测到的工具长度。
  • tool*:width - 检测到的工具宽度。
Circle Gestures circlegestures - 画圈手势的数量。对于每个检测到的 Circle Gesture，将包含以下通道：
  • circle*:handindex - 与该手势关联的手的索引。见注释。
  • circle*:t[xyz] - Circle Gesture 中心相对于传感器的坐标。
  • circle*:radius - 手势中圆的半径。
  • circle*:progress - 手势中完成的周期数。
Swipe Gestures swipegestures - 滑动手势的数量。对于每个检测到的 Swipe Gesture，将包含以下通道：
  • swipe*:handindex - 与该手势关联的手的索引。见注释。
  • swipe*:fingerindex - 与该手势关联的手指的索引。见注释。
  • swipe*:t[xyz] - Swipe Gesture 相对于传感器的坐标。
  • swipe*:start[xyz] - Swipe Gesture 起点相对于传感器的坐标。
  • swipe*:speed - 滑动的速度。
Key Tap Gestures keytapgestures - 敲击按键手势的数量。对于每个检测到的 Key Tap Gesture，将包含以下通道：
  • keytap*:handindex - 与该手势关联的手的索引。见注释。
  • keytap*:fingerindex - 与该手势关联的手指的索引。见注释。
  • keytap*:t[xyz] - Key Tap Gesture 相对于传感器的坐标。
Screen Tap Gestures screentapgestures - 敲击屏幕手势的数量，它被识别为工具或手指快速向前敲击的动作。对于每个检测到的敲击屏幕手势，将包含以下通道：
  • screentap*:handindex - 与该手势关联的手的索引。见注释。
  • screentap*:fingerindex - 与该手势关联的手指的索引。见注释。
  • screentap*:t[xyz] - Screen Tap Gesture 相对于传感器的坐标。

NOTES: 旋转顺序为 Rx Ry Rz。所有矢量都以下列 coordinate system 给出。

对于手势，如果 handindex 为 1，则带 hand1 前缀的通道包含与该手势关联的手的数据。如果 handindex 为 -1，表示没有可用于该手势关联手的通道。fingerindex 同理。

只要 Leap Motion 传感器仍在检测，所有带索引的前缀（hand*、hand/finger* 等）的数据就会继续对应同一只手/手指/工具/手势。

如果检测到的手/手指/工具/手势数量超过指定限制，手/手指/工具/手势的限制会过滤掉 Leap Motion 传感器的数据。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Leap Motion CHOP 的额外信息可以通过 Info CHOP 访问。

Leap Motion CHOP 的特定 Info 通道

  • installed -
  • connected -
  • hmd_policy_request -
  • hmd_policy_actual -
  • sequence_id -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
