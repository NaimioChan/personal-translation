链接

Link 或 Reference 是节点之间的灰色虚线，表示一个操作符正在从另一个操作符获取数据。相比之下，着色的 Wire 把同一 Operator Family 中一个节点的输出连接到另一个节点的输入。

Reference / Link 类型包括：

  1. OP 中的参数，其值为另一个操作符的名称或路径——节点获取另一个节点数据的节点路径，如 Select TOP 和 Select CHOP 中那样。
  2. Parameters 中的 Python 表达式，或包含以下内容的 DAT 脚本：
    1. 另一个操作符的名称或路径
    2. 来自另一个参数输出的数据：op('pattern1')['chan1'][5]
    3. 另一个操作符的参数：op('pattern1').par.phase
    4. 另一个操作符的 python 成员，如 op('pattern1').numSamples
  3. CHOP Exporting，其中 CHOP 通道被发送到操作符 Parameter。
  4. DAT Export，其中 table DAT 的一行被发送到操作符 Parameter。
  5. DAT 操作符，在另一个节点发生变化时执行其内容，如 CHOP Execute DAT 中那样。

当引用出现在表达式中，如 op('base1/pattern1').par.phase，它指定从中获取值的位置。例如从 DAT 表格单元格获取 op('table1')[3,4]，或从 CHOP 的输出通道获取 op{'pattern1')['chan1']。

当引用是 OP 中的参数时，如 /project1/pattern1，源 OP 输出的数据会被传递或共享给包含该引用的 OP。例如，若是对 TOP 的引用，源图像不会被复制，而是用于生成该 OP 的输出。

在某些情况下，作为 OP 引用的参数实际上是对多个 OP 的引用——通过列出它们的路径或使用通配符来指定多个 OP 以获得多 OP 路径。参见 Pattern Matching。

具有引用参数的操作符示例：

  • Select TOP, Select CHOP, Select DAT
  • Render TOP 摄像机、灯光和几何对象的名称
  • Composite TOP
  • Join CHOP
