Alembic Out POP

摘要

Alembic Out POP 将 POP 内容写入 Alembic .abc 文件。它输出的点、顶点和图元与 POP 的结构相似但不完全相同。.abc 文件可包含多帧动画以及内置属性和自定义属性。多个 POP 可作为各自独立的对象输入到同一个 Alembic 文件中。

Alembic Out POP 的每个输入都要求恰好存在以下 POP 图元类型之一。

  • 点会写为 OPoints。
  • Triangle 和 Quad 图元会写为 OPolyMesh。
  • Line Strips 和 Lines 会写为 OCurves，曲线类型设为 Linear。

其中 OPoints、OPolyMesh 和 OCurves 是传给 Alembic SDK 的底层对象。

注意 - 每个输入 POP 必须只包含一种图元类型（即输入 POP 只能有 Triangles 或只能有 Point 图元，不能两者兼有）。

由于 Alembic 的 OCurves 在导出为 OPolyMesh 时不支持像 Triangles 和 Quads 那样的顶点索引引用，TouchDesigner 会将 Line Strip 数据转换为一组点和一份长度列表。这意味着闭合的 line strip 会以重复的起始顶点写出，以表示其闭合。（即闭合的 line strip 0,1,2,3,0 会变成开放的 line strip 0,1,2,3,4，其中 0 和 4 是同一个点）。Alembic In POP 会检测首尾点是否重复，并将其转换为闭合的 line strip。

Output of Attributes:

  • Point 图元支持写出所有 Point 属性
  • Triangle 和 Quad 图元支持写出所有 Point、Vertex 和 Primitive 属性
  • Lines 和 Line Strips 支持写出 builtin Point 和 Primitive 属性。（内置属性见下文）

Vertex List：与 TouchDesigner 相比，Alembic 对图元使用反向的绕序，这意味着写入时以及从 Alembic In POP 读取时，每个图元的顶点顺序都会翻转。

Built in Attributes：Alembic Out POP 会自动导出以下内置属性

  • Color 属性写为 Cd float4
  • N 属性写为 N float3
  • Tex 属性写为 uv float2，或在开启 Export 3D Texture Coord 时写为 uv float3

注意 - Line Strips 和 Lines 对 Point 和 Primitive 属性仅支持内置属性，不支持写入自定义属性。

对于动画点云，指定 Point Id 和 Velocity 这两个点属性会按以下方式写出这些属性。

  • Point Id 写为 .pointIds int64
  • Velocity 写为 .velocities float3

这些属性可以由 Particle POP 之类的节点创建，这类节点会生成 PartId 和 PartVel，也可以作为自定义属性创建。

Custom Attribute data types：Point、Triangle 和 Quad 图元支持以下自定义属性类型

  • uint, int, float, double
  • int2, float2, double2
  • int3, float3, double3
  • 数组属性

Output of POP groups：Alembic Out POP 忽略 POP 组。

Animated multi-frame output：当动画对象的拓扑不变时，可启用 Topology Unchanged 开关，这样拓扑只会在开头写出一次。

Outputting multiple POPs to one Alembic file：Alembic Out POP 支持将多个 POP 各自作为独立对象导出到同一个 Alembic 文件中，位于根之下。例如写出两个 POP 会得到路径为 /object1 和 /object2 的对象。

参数 - Inputs 页

Input input - 管理该 POP 输入的 Sequential 参数块起始处。
In POP input0pop - 当前序列块的输入 POP。
Object Name input0objname - Alembic 对象名称。
Ids Attribute input0idname - 包含点 id 信息的点属性名称。仅在导出 Point 图元时可用。
Velocity Attribute input0velname - 包含速度信息的点属性名称。仅在导出 Point 图元时可用。
Point Attribute Name input0ptattrname - 通过模式匹配选择要保存的自定义点属性。
Vertex Attribute Name input0vertattrname - 通过模式匹配选择要保存的自定义顶点属性。
Prim Attribute Name input0primattrname - 通过模式匹配选择要保存的自定义图元属性。

参数 - Alembic Out 页

Unique Suffix uniquesuff - - 启用后，me.fileSuffix 在 file 参数中使用时将是唯一后缀。

gg

N n - N 是 me.fileSuffix 中使用的索引。启用 unique suffix 时，N 指定计算唯一后缀/名称时的起始递增索引。
Leading Zeros Digits leadingzerosdigits - 指定文件名后缀的最少位数。如果索引数字小于该值，会在前面补零，使后缀总位数达到该值。
File file - 设置保存输出的影片文件的路径和文件名。文件名必须包含文件扩展名，例如 .obj/.exr 等。
FPS fps - 所创建 Alembic 文件的帧率。
Limit Length limitlength - 可用于在文件达到指定长度后自动停止录制。
Length length - - 停止录制文件时的长度。
  • Length length -
  • Length Unit lengthunit - 帮助不可用。
Record record - 当此参数设为 1 时，文件将处于录制状态。
Record Pulse recordpulse - 立即写出一个文件。
Pause pause - 暂停录制。
Add Frame addframe - 每点击一次按钮，就向输出添加一帧。 Pause 必须为 On 才能启用 Add Frame 参数。
Max Active Saves maxactive - 指定可同时运行的最大文件保存任务数。
Include Primitives includeprim - 可用于启用将图元数据写入文件。
Tex Coord Attribute texcoordattrib - 在写出包含纹理坐标的几何文件时，指定要使用的纹理属性名称（不必是 Tex）。
Topology Unchanged unchangedtopology - 写出时可用于指明拓扑不会变化，这意味着拓扑只会写出一次。
Samples per Second abcfps - 指定提供给 Alembic 库的时间采样率
Export 3D Texture Coord abc3dtex - 开启后，纹理会以 3D 纹理写入自定义属性，因为 Alembic 默认只支持 2D 纹理。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Info CHOP 通道

Box POP 的额外信息可通过 Info CHOP 查看。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
