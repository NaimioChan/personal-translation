窗口

TouchDesigner 中的窗口是 Microsoft Windows 或 macOS 中的一个窗口，其中包含 (1) 存在于 Designer Mode 中的 TouchDesigner 编辑界面，或 (2) Window Component 内用户创建的 Panel。用户创建的窗口可以无边框地横跨 Multiple Monitors，也可以是带边框的浮动窗口，或弹出窗口。

另请参阅 Window Placement Dialog、Window COMP、Multiple Monitors。
