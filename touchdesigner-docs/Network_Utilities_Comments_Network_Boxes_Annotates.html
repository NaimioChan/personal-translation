网络工具：注释、网络框与标注

Network Utilities 是一类特殊的 nodes，用于组织 TouchDesigner 网络。内置的 Network Utilities 有 Comments 和 Network Boxes，而 Annotates 则功能更完整、更开放。你也可以创建自定义 Network Utilities。

内置 Network Utilities

内置 Network Utilities 用于 TouchDesigner 网络中常见的注释和分组任务。它们通过右键菜单中的选项创建，通常可以像普通节点一样调整大小或移动。

注释

Comments 用于在网络中添加简单的文本说明。To create a Comment，从网络右键菜单中选择 Add Comment，或在网络上将鼠标悬停时按 Shift-C。点击 Comment 中的任意位置即可编辑文本。To move Comment：从中间任意位置拖动；to size it：拖动边缘。

Network Box

Network Box 用于对节点进行分组、标注和移动。To create a Network Box，从网络右键菜单中选择 Add Network Box，或在网络上将鼠标悬停时按 Shift-B。点击标题即可编辑文本。To move Network Box：拖动标题即可移动它，其中的所有节点会随之一同移动。To drag 框内的 without：在拖动被围住的节点时按住 Alt。To size Network Box：拖动边缘。你也可以拖动节点，使其边缘与 Network Box 的边缘重叠；框会自动扩展以容纳该节点。

标题是 Network Box 中唯一可用鼠标交互的部分。点击主体区域与直接点击网络完全相同。

Network Utility 节点详情

Network Utility 节点（或简称 Utility nodes）与其他 TouchDesigner 节点类似，但有几处重要区别：

参数

为保持简洁，选中 Utility 节点时，参数不会出现在标准窗格参数对话框中。Comment 和 Network Box 可通过右键获得简化的参数框，完整参数框则通过 Alt-右键打开。

在简化参数中，你可以修改 Comment 的文本大小，以及 Network Box 的标题大小/对齐方式。要了解完整参数框中可用的参数，请参阅 Annotate COMP。Annotate COMP 在 Annotate 页上有一个 Utility parameter，可用于开启或关闭它是否被视为 Network Utility。

在 OP Find DAT 和搜索/替换对话框中隐藏

为避免 Utility 节点干扰内省网络，除非打开 Include Utility 参数（在 Families 页上），否则它们不会出现在 OP Find DAT 中。同样，使用 Search/Replace Dialog 时，除非在 Advanced 模式中打开 Comments (Utility)，否则 Utility 节点不会出现。

对 Python 隐藏

为避免 Utility 节点干扰内省，默认情况下它们会在某些 Python 方法和成员中被隐藏：

op、ops 和 COMP.findChildren 不会返回任何 Utility 节点，除非将 includeUtility=True 作为参数传入。

除非将 includeUtility=True 作为参数传入，否则 COMP.cook(recurse=True) 不会递归进入 utility 节点。

COMP.children、COMP.currentChild 和 COMP.selectedChildren 永远不会返回 Utility 节点。

「Enter」快捷键被禁用

为防止意外进入 Network Utilities，已禁用「Enter」网络快捷键。要查看其内部网络，可以选中 Utility 节点，然后在网络上右键并选择 Jump Down。

自定义 Network Utility 节点

Network Utility 节点基于 Annotate COMP，它允许将 Panel 作为 TouchDesigner 网络的一部分显示。你可以研究 Comment、Network Box 和默认的 Annotate COMP 作为示例。你会发现 Comment 和 Network Box 只是 Annotate 的模式，可通过其 Mode 参数选择。更多细节请访问 Annotate COMP 页面。
