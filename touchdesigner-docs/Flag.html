标记

TouchDesigner 中的「Flag」指 Operator 状态的指示器（Bypass flag、Render flag、Lock flag、Viewer Active flag……）。标记不是参数，它们是操作符的二元状态。

操作符标记

操作符标记位于 Network Editor 中 Node 的左边缘和底边缘。

标记也可见于网络的「Table View」：在网络中按「T」进入/退出 Table View。它以表格形式显示节点，完整的一组标记在各列中可见。

标记不是参数，因此改变标记本身不会导致节点计算。你不能导出到标记。

有些标记是特定操作符族专有的，比如 3D Geometry 操作符的 Render flag。

所有标记都用例如 op('nodename').lock = True 来设置。

要用 Python 处理所有常见操作符标记，见 OP_Class 中的 Flags 一节，以及各操作符族的类。

所有节点上的标记

  • Viewer - 打开节点中央的数据查看器。
  • Viewer Active - 使查看器可交互，以便进一步检查节点的输出数据，或操作面板。
  • Lock - 节点输出的数据被冻结在内存中（并保存在 .toe .tox 中）
  • Bypass - 第一个输入直接传递到输出。组件上的 Bypass 会导致其内部所有节点被绕过。
  • Cooking - 在组件上，会使内部的节点不进行计算。
  • Immune - 克隆中的节点可以免疫于克隆。
  • Current - 该节点是网络中的当前节点
  • Selected - 该节点是网络中选中的节点之一。
  • Expose - 该节点可以在网络中隐藏。
  • Python - 把节点内容的语言设为 Python 的标记（默认）。仅在 Parameter Dialog 上可见。

3D Object 组件上的标记

  • Render - 如果关闭，对象不会出现在 Render TOP 或 Render Pass TOP 的任何渲染中。
  • Display - 如果关闭，对象不会出现在任何摄像机查看器中。
  • Pickable - 如果关闭，对象在 3D Geometry Viewers 或 SOP Editor 中不可选。

CHOP 上的标记

  • Export - 如果关闭，该 CHOP 不会导出任何内容。

SOP 上的标记

  • Compare - 以绿色线框显示该 SOP 的输入几何，便于比较。
  • Template - 在 3D 查看器中把该 SOP 显示为模板几何。灰色线框模板不可选也不可编辑。
