UDP In DAT

摘要

UDP In DAT 用于在两台远程计算机之间通过 UDP 连接接收信息。它会捕获所有消息，不进行任何排队或缓冲，并允许你向它发送任意消息。一旦此 DAT 收到消息，它就可以使用「send」命令回复发送方。在收到消息之前使用 send 命令不会生效，因为此时它还不知向何处发送数据。在 multicast 模式下，它不发送组播消息，而是直接向最近一条组播消息的发起者发送回复。

另请参阅 Peer Class、UDP Out DAT、Touch In DAT 和 TCP/IP DAT。

NOTE for Windows OS - If experiencing connection issues make sure Windows Firewall is disabled.

udpinDAT_Class

参数 - Connect 页

Active active - 此复选框启用连接。
Protocol protocol - - 选择要使用的协议，更多信息参见 Network Protocols 一文。
  • Messaging (UDP) msging -
  • Multi-Cast Messaging (UDP) multicastmsging -
Network Address address - 要监听的组播 IP 地址。
Port port - 要监听的网络端口。
Shared Connection shared - 使用与其他使用相同网络协议的联网 DAT 相同的连接。
Row/Callback Format format - - 确定如何解析传入的数据。
  • One Per Byte perbyte - 每收到一个字节就向表格添加一行。
  • One Per Line perline - 每收到一行就向表格添加一行。行尾由 \n、\r 或空字符（\0）分隔。
  • One Per Message permessage - 每收到一条消息就向表格添加一行。
Local Address localaddress - 指定要监听的 IP 地址，当系统有多个 NIC（网络接口卡）并且你想选择使用哪一个时很有用。留空时，UDP In DAT 会监听所有接口。

参数 - Received Data 页

Callbacks DAT callbacks - Callbacks DAT 会为每条传入的消息执行一次。用法见 udpinDAT_Class。
Execute from executeloc - 决定脚本的运行位置。
  • Current Node current - 脚本从当前节点位置执行。
  • Callbacks DAT callbacks - 脚本从 Callbacks DAT 参数中指定的 DAT 所在位置执行。
  • Specified Operator op - 脚本从下方 From Operator 参数指定的操作符中执行。
From Operator fromop - 当 Execute from 设为 Specified Operator 时，其状态变化将触发 DAT 执行脚本的操作符。如果 Execute from 参数设为 Specified Operator，该操作符也是脚本执行时的所在路径。
Clamp Output clamp - 该 DAT 默认限制为 100 条消息，但使用 Clamp Output 可以设为任意值，包括无限制。
Maximum Lines maxlines - 限制消息数量，较旧的消息会先从列表中移除。
Clear Output clear - 删除除标题外的所有行。若要用 python 脚本清除 op("opname").par.clear.pulse()
Bytes Column bytes - 在单独的列中输出消息的原始字节。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

可通过 Info CHOP 访问 UDP In DAT 的额外信息。

UDP In DAT 专属 Info 通道

  • messages_pending -

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
