面板

面板（Panel，或控制面板）是在 TouchDesigner 中构建的自定义图形用户界面控件。参见 Panel Component，它们用于创建此类用户界面。

面板的「外观」通过 Text COMPs 和 TOPs 创建。

面板的「手感」或行为由以下决定：Panel Components 的设置、面板内的 Panel Execute DAT 和 Extensions、panelCOMP Class 的 panel 成员，以及使用 Panel CHOP 把 Panel Values 转换为 CHOP 通道。

要在显示器上的浮动窗口或固定位置窗口中显示面板，请使用 Window COMP。

编辑时，可以通过以下方式查看面板：

  • 右键点击 Panel Component 并选择 View...
  • 把 Pane 类型改为 Panel
  • 如果你在 Panel 组件内工作，点击 Pane Bar 的方形图标（Open Viewer）
