Python 类与模块

以下重要 Python 类与模块列表大致按主题分组。

Python Reference 中按字母顺序列出了此 wiki 上所有 TouchDesigner Python 页面。

操作符相关类

以下类是与操作符及操作符所用对象对应的 Python 接口。各个操作符类（例如 TextTOP Class 和 RampTOP Class）未在此列出，但它们确实存在于 td module 中，指向每个类的链接可以在 here 找到，或点击其 parameter dialog 中的 Python Help 按钮。这些类位于 td module 中，因此无需导入。

  • OP Class - 一个 TouchDesigner operator。
    • Connector Class - OP 的连线连接器。这些的列表可在 OP.inputConnectors 和 OP.outputConnectors 中找到。组件还有 COMP.inputCOMPConnectors 和 COMP.outputCOMPConnectors。
    • Page Class - 一个参数页。这些的列表可在 OP.pages 中找到，在组件和脚本操作符上则可在 OP.customPages 中找到。
    • ParCollection Class（OP.par） - 保存某个 OP 的所有参数。
      • Par Class - 单个 parameter。
    • ParGroupCollection Class（OP.par） - 保存某个 OP 的所有参数组。
      • ParGroup Class - 单个参数组。
        • ParGroupPulse Class - 带 pulse 参数的单个参数组。
        • ParGroupUnit Class - 带 unit 参数的单个参数组。
    • SequenceCollection Class（OP.seq） - 保存某个 OP 的所有序列。
      • Sequence Class - 描述并控制一组顺序参数。顺序参数会在其 sequence 成员中引用这些对象之一。
        • SequenceBlock Class - 用于访问序列中特定块（一组 parGroups）的 parGroups。
    • CHOP Class - OP 的子类，定义 CHOP 操作符。
      • Channel Class - 一个 channel 对象。通过 CHOP 索引或其他 CHOP 成员（如 chan、chans 等）访问。
      • Segment Class - 描述来自 Timer CHOP 的单个分段。
    • COMP Class - OP 的子类，定义 component 操作符。
      • ObjectCOMP Class - COMP 的子类，定义 Objects，用于创建和渲染 3D 场景。
      • PanelCOMP Class - COMPS 的子类，定义 Panel Components，用于创建 2D UI 元素。
        • Panel Class - panelCOMPs 的成员，包含所有相关的 panel values。通过 panelCOMP.panel 访问。
          • PanelValue Class - 单个 panel values。可通过 panelCOMPS 的 panel 成员访问，也可在 Panel Execute DAT 的回调中访问。
        • ListAttributes Class - 用于 ListCOMP 的 list attributes 集合。
          • ListAttribute Class - 包含定义 ListCOMP 中单元格的属性。
        • Actors Class - 描述 Bullet Solver COMP 和 Nvidia Flex Solver COMP 所使用的所有 Actor COMP 的集合。用于 BulletsolverCOMP 或 flexsolverCOMP。
        • Bodies Class - 用于 ActorCOMP 的 bodies 集合。
          • Body Class - 用于 ActorCOMP 的单个刚体（物理对象）。
      • VFS Class - COMP 的虚拟文件系统
        • VFSFile Class - 虚拟文件系统中包含的虚拟文件。
    • DAT Class - OP 的子类，定义 DAT 操作符。
      • Cell Class - 定义 DAT 表格中的单个单元格。
      • Peer Class - 描述在 oscinDAT、tcpipDAT、udpinDAT、udtinDAT 中的回调函数里发起消息的网络连接。
    • MAT Class - OP 的子类，定义 MAT 操作符。
    • POP Class - OP 的子类，定义 POP 操作符。
      • Bounds Class - 包含边界数据（min、max、center、size）
      • Attributes Class - POP attributes 的集合
        • Attribute Class - 关于某个实体的信息，例如其颜色、速度、法线等。
    • SOP Class - OP 的子类，定义 SOP 操作符。
      • Attributes Class - SOP attributes 的集合
        • Attribute Class - 关于某个实体的信息，例如其颜色、速度、法线等。
          • AttributeData Class - 包含与 Prim Class、Point Class 或 Vertex Class 关联的特定几何 Attribute 值。
      • Group Class - 描述 Prim Class 或 Point Class 的分组列表。
      • Points Class - points 的集合。
        • Point Class - 单个几何 point。
          • InputPoint Class - 用于 Point SOP 参数的特殊点对象。
      • Prims Class - primitives 的集合。
        • Prim Class - 单个几何 primitive。
          • Poly Class - 定义几何 polygon 的 Prim 子类。
          • Mesh Class - 定义几何 mesh 的 Prim 子类。
          • Bezier Class - 定义一组 Bezier 曲线的 Prim 子类。
          • Vertex Class - 定义单个几何 vertex 的 Prim 成员。
    • TOP Class - 定义 TOP 操作符的 OPs 子类。
      • CUDAMemory Class - 保存对 CUDA 内存的引用。
        • CUDAMemoryShape Class - 描述 CUDA 内存段的形状。
      • TextLine Class - Text TOP 或 Text SOP 中经过格式化的一行文本。包含该行文本、位置等各种成员。

辅助类

以下辅助对象是 td module 的一部分，因此可以在任何位置访问，包括在表达式中，无需导入（例如 absTime.frame）。

  • AbsTime Class (absTime) - 关于 absolute time 的信息
  • App Class (app) - 关于 TouchDesigner 应用程序的信息，包括版本、安装文件夹等。
  • Project Class (project) - 关于当前 TouchDesigner 会话的信息
  • TDU Class (tdu) - 与 TD 对象不直接相关的 TouchDesigner 通用工具。
    • ArcBall Class (tdu.ArcBall) - 封装 3D 查看器交互的许多方面。
    • Camera Class (tdu.Camera) - 为摄像机维护 3D 位置和朝向，并提供多种方法来操控摄像机的位置和方向。
    • Color Class (tdu.Color) - 保存 4 分量颜色
    • Dependency Class (tdu.Dependency) - 用于创建 Dependable Python 数据。
    • Matrix Class (tdu.Matrix) - 保存用于变换的单个 4x4 矩阵。3D 对象的变换见 ObjectCOMP Class。
    • Position Class (tdu.Position) - 保存 3 分量位置
    • Quaternion Class (tdu.Quaternion) - 保存用于 3D 旋转的四元数对象
    • Timecode Class (tdu.Timecode) - 保存时间码值
    • Vector Class (tdu.Vector) - 保存 3 分量向量
  • Licenses Class (licenses) - 关于已安装 license 对象的信息
    • DongleList Class (licenses.dongles) - 已连接的加密狗列表
      • Dongle Class - 连接到系统的一个加密狗
    • License Class - 已安装许可证的单个实例
        • ProductEntry Class - 系统中单个已连接加密狗的条目
  • MOD Class (mod) - 访问位于 TouchDesigner DAT 中的模块
  • Monitors Class (monitors) - 访问所有已连接显示设备的信息
    • Monitor Class - 单个显示设备
  • Runs Class (runs) - 关于所有延迟 run objects 的信息
    • Run Class - 单个延迟运行对象
  • SysInfo Class (sysInfo) - 当前系统/硬件信息
  • UI Class (ui) - 关于应用程序 UI 元素的信息
    • Colors Class (ui.colors) - 应用程序颜色
    • Options Class (ui.options) - 可配置的 UI 选项
    • Panes Class (ui.panes) - 编辑器中所有已打开窗格的集合
      • Pane Class - 单个窗格对象
        • NetworkEditor Class - 显示网络编辑器的 Pane 子类
    • Preferences Class (ui.preferences) - TouchDesigner 偏好设置的集合
    • Undo Class (ui.undo) - 与撤销系统交互的工具，包括创建基于脚本的撤销步骤

标准 Python 模块

td module 还会自动导入若干有用的标准模块，可通过其命名空间在表达式中访问（例如 math.cos(math.pi)）：

  • collections - 容器数据类型
  • enum - 枚举支持
  • inspect - 检查活动对象
  • math - 数学函数
  • re - 正则表达式操作
  • sys - 操作系统相关的数据和函数
  • traceback - 栈工具
  • warnings - 警告控制

TouchDesigner 工具模块与 Python 工具

以下内容包含用于 TouchDesigner 的扩展 Python 工具。

  • TDFunctions - 用于在 TouchDesigner 中进行高级 Python 编程的各种工具。
  • TDJSON - TouchDesigner 专用的 JSON 工具。
  • TDStoreTools - 用于 TouchDesigner 的 Storage 和 Dependency 系统的工具。
  • TDResources (op.TDResources...) - 不是模块，但包含可通过 Python 访问的系统资源。它包括系统 pop-up menu、button pop-up menu、pop-up dialog 和 mouse 资源。

第三方包

The following 3rd party packages are automatically installed with TouchDesigner. 它们不在 td module 中，因此必须在脚本中显式导入才能使用。括号中的名称是实际使用的包名（例如，要使用 OpenCV，请在脚本顶部写入：import cv2）。有关添加或安装其他 Python 模块的信息，见 Importing Modules。

  • attrs (attr) - 无需样板代码的类。
  • box (box) - 支持点号访问的高级 Python 字典。
  • Certifi (certifi) - 用于在验证 TLS 主机身份时校验 SSL 证书可信度的根证书。
  • Chardet (chardet) - 通用字符编码检测器。
  • charset-normalizer (charset_normalizer) - 帮助你从未知字符集编码中读取文本的库。
  • decorator (decorator) - 定义保留签名的函数装饰器和装饰器工厂。
  • defusedxml (defusedxml) - 为 Python 标准库模块提供 XML 炸弹防护。
  • depthai (depthai) - C++ depthai-core library 的 Python 绑定。
  • idna (idna) - 支持应用程序中的国际化域名（IDNA）协议。
  • jsonpath (jsonpath_ng) - 用于访问和修改 JSON 结构的 JSONPath 工具。
  • jsonschema (jsonschema) - jsonschema 是 JSON Schema 规范在 Python 中的实现。
  • jsonschema-specifications (jsonschema_specifications) - JSON Schema 元模式和词汇表，以注册表形式提供。
  • MWParserFromHell (mwparserfromhell) - 易用且极其强大的 MediaWiki wikicode 解析器。
  • NumPy (numpy) - Python 科学计算的基础包。
  • OAuthlib (oauthlib) - 用于构建 OAuth 和 OpenID Connect 服务器的库。
  • opencv-python (cv2) - 预构建的仅 CPU 版 OpenCV Python 包（计算机视觉）。
  • packaging (packaging) - 包工具，包括版本处理、说明符、标记、依赖、标签和实用程序。用于版本字符串比较。
  • pip (pip) - pip 是 Python 的包安装器。你可以用 pip 从 Python Package Index 和其他索引安装包。
  • ply (ply) - 用于 lex 和 yacc 的解析工具。
  • pygdtf (pygdtf) - Python 的通用设备类型格式（GDTF）库。
  • pymvr (pymvr) - Python 的 My Virtual Rig（MVR）库。
  • Pygments (pygments) - 用 Python 编写的语法高亮包。
  • pyparsing (pyparsing) - 一组类库，客户端代码可用它在 Python 代码中直接构建解析语法。
  • pyrankvote (pyrankvote) - PyRankVote 是一个 Python 库，提供不同的排序选择投票系统（有时称为优先投票系统），由 Jon Tingvold 于 2019 年 6 月创建。
  • pyrfc6266 (pyrfc6266) - Python 中的 RFC6266 实现。
  • pyrsistent (pyrsistent) - Pyrsistent 是一组持久化集合（有人称之为函数式数据结构）。持久化是指它们不可变。
  • PyYAML (yaml) - YAML 解析器和生成器。
  • referencing (referencing) - JSON 引用 + Python。
  • Requests (requests) - 唯一非转基因的 Python HTTP 库，可安全供人类使用
  • Requests OAuthlib (requests_oauthlib) - 用于构建 OAuth1 和 OAuth2 客户端的易用 Python 接口
  • rpds (rpds) - 与 Rust 持久化数据结构（rpds）的 Python 绑定。
  • six (six) - Python 2 与 3 兼容性工具。
  • smartypants (smartypants) - SmartyPants 的 Python 分支。
  • tabulate (tabulate) - 在 Python 中美观地打印表格数据。
  • tzdata (tzdata) - IANA 时区数据的提供者。
  • urllib3 (urllib3) - HTTP 客户端。
  • whats-that-code (whats_that_code) - 编程语言检测库。
