全局 OP 快捷名

Global Operator Shortcuts 帮助你从 any operator 到达任何 component。 在大型系统中，你可能想访问并非当前操作符父级的组件，而是位于任意组件中的组件。因此这种情况下 Parent Shortcuts 无法使用。

示例

你有一个组件 /myProject/mediaManager，希望在任何地方都能访问它。
把它的 Global OP Shortcut 参数设为 MediaManager。
这样在任何操作符或脚本中，op.MediaManager 都等同于该组件：op('/myProject/mediaManager')。
该组件中的子级影片操作符 movie1，之后就可以在任何地方通过 op.MediaManager.op('movie1') 访问。

冲突

如果两个组件具有相同的 Global OP Shortcut，就会出错。处理方式是分别重命名它们，或按顺序命名。
例如 /myProject/Player1 和 Player2 可以用如下表达式设置它们的 shortcut 参数：'Player'+str(me.digits))。
这样得到的快捷键是 Player1 和 Player2。

关于确切用法和细节，参见 OP Class#Members。
另请参阅：Td_Module 中的 parent()、Parent Shortcut。
