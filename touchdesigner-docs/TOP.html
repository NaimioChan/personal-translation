TOP

摘要

另请参阅 Category:TOPs 以获取与 TOP 相关的完整文章列表。

Texture Operators 又称 TOPs，是提供实时、基于 GPU 的合成与图像处理的图像操作符。TOP 的所有计算都在系统 GPU 上执行。TOP 可用于准备纹理、合成流式图像和影片、构建控制面板元素、处理 32 位浮点数据，以及几乎任何其他图像任务。TOP 支持多种格式，包括用于处理高动态范围（HDR）图像的浮点图像格式。

使用 TOP 时，所有渲染与合成都发生在屏幕外。数据可以缩放到任意分辨率，只受显存容量和显卡最大分辨率的限制。

用于保存点云数据的 TOP（其中 R G B 分别存放 32 位 X Y Z 数据）可以通过在查看器上右键并选择 View as Points，以 3D 点集方式查看。

注意： TouchDesigner 非商业版限制为 1280x1280 分辨率。

TOP 标记

右下角只包含 2 个标记：TOP 的 Display Flag 和 Viewer Active Flag。打开显示标记会把该 TOP 显示为当前 Network Pane 的背景。打开多个 TOP 显示标记时，会把多个 TOP 输出以平铺序列显示为网络窗格的背景。


TOP 查看器

所有 TOP 操作符都有可交互的 Node Viewers。要与其交互，请打开该 TOP 的 Viewer Active Flag 使查看器处于活动状态。

存在 alpha 通道的图像会显示灰色棋盘格背景。可以在 Edit 菜单中打开 Preferences 来关闭它。在偏好设置中你可以选择用棋盘格或黑色作为 alpha 背景。

使用 LMB 移动图像。使用 MMB 放大和缩小图像。使用主页快捷键 "h" 重新居中图像。

点击 RMB 会打开查看器选项菜单。快捷键列在菜单每一项的旁边。

Home - 重新居中并缩放图像以适配查看器。

Display Pixel Values - 在图像上显示像素信息。要让数值正确更新，Timeline 应正在向前播放。

将显示以下内容：

  • 光标 uv 坐标
  • 光标 xy 像素坐标
  • RGB 值 0-255
  • RGB 值 0-1

Display Field Guide - 在图像上显示 24x24 的网格参考图。该参考图还会显示图像的动作安全区和字幕安全区。

Display Mode - 显示模式选项提供查看图像特定通道的功能。

可用的显示模式如下：

  • Color - 显示所有 RGB 通道。
  • Red/Green/Blue/Alpha - 分别显示 Red/Green/Blue/Alpha 通道。
  • Mono - 以单色显示图像。
  • Normalize Split - 同时显示图像中的每个通道，并归一化到 0-1。非常适合查看浮点和点云数据。

View as Points - 把 TOP 中的数据以每像素 3D 点的方式显示，假定 red = x、green = y、blue = z。适合查看点云数据。

点云数据的 3 种显示模式：1) Color 2) Normalized Split 3) View as Points
