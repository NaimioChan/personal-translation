Add SOP

摘要

Add SOP 既可以自行创建新的点和多边形，也可以用于向现有输入添加点和多边形。

如果指定了输入，此 SOP 会按下面的说明向其添加点和多边形。如果未指定输入，则按下面的说明生成新的点和多边形实体。它可以从 DAT 读取点和顶点。另见 DAT to SOP。

addSOP_Class

参数 - Points 页

Points DAT pointdat - 指向包含点数据的 Table DAT 的路径。默认情况下，可以在表格的前 4 列中使用未命名的列定义 x、y、z 和 w。

如果下面 Named Attributes 参数处于开启状态，则可以在 Points Table DAT 中使用命名列定义以下属性：

  • P(0) P(1) P(2) P(3)
  • N(0) N(1) N(2)
  • Cd(0) Cd(1) Cd(2) Cd(3)
  • uv(0) uv(1) uv(2)

任何其他列都会作为单浮点属性添加。

注意： 在 Points Table DAT 中提供 N(0) N(1) N(2) 时，请关闭 Polygon 参数页上的 Compute Normals。

Named Attributes namedattribs - 允许在上面的 Point Table DAT 中定义额外属性。
Delete Geometry, Keep Points keep - 使用此选项可移除任何未使用的点。勾选时，输入中的现有几何会被丢弃，但此 SOP 创建的多边形会保留，输入中的任何点也会保留。
Add Points addpts - 开启时，你可以使用下面的参数添加自定义位置和权重的单独点。
Point point - 要添加的点的序列
Position point0pos - - 三个输入字段分别表示该点的 X、Y 和 Z 坐标。这些值可以是常量（数字）或变量。下面是三个示例： 
0.2    0.42    1.3

0.2    op('xform1').par.tx    1.36

# 从 SOP grid1 读取第六个点（第一个点为 0）
op('grid1').points[5].x    op('grid1').points[5].y    op('grid1').points[5].z
  • Position point0posx -
  • Position point0posy -
  • Position point0posz -
Weight point0weight - 该点的样条权重。如果该点之后被用于创建样条（nurbs 或 Bezier）图元，该权重会影响图元的形状，并可能使该图元变为有理图元。多边形和 metaball 不受此权重影响。

参数 - Polygons 页

Method method - - 指定通过 Group 方式或 Pattern 方式用这些点创建多边形。
  • By Group group - 按 group 字段以及分组/跳过规则确定的数目创建多边形。
  • By Pattern pattern - 使用下面的 Polygon Table 或 Polygon 0 参数指定用于创建多边形的点。
Group group - 要连接的点子集。
Add add - - 可选地连接点的子组。
  • All Points all - 添加所有点，就像你在 Points 页中手动添加它们一样。
  • Groups of N Points group - 仅添加指定数量的点。
  • Skip Every Nth Point skip - 添加点，但每隔第 N 个点跳过。
  • Each Group Separately sep - 为 Group 参数中指定的每个组创建单独的多边形。例如，如果你有一个 Group SOP 创建了名为 group1 的组并使用 Create Boundary Groups 选项，可以将其连接到 Add SOP，并在 Group 参数中输入 group1__*。如果选择 Each Group Separately，则会为表面上的每个边界创建多边形。

Tip: The Each Group Separately option is useful when pasting surfaces. Boundary groups can be created for the boundaries of two adjacent surfaces, and then the PolyLoft SOP (using the Points option) can be used to stitch these surfaces together.

N inc - 用于添加点的增量/跳过量。
Closed closedall - 闭合生成的多边形。
Polygons Table polydat - 指向包含多边形数据的 Table DAT 的路径。接受按第一列中的点编号指定的多边形行。第二列表示多边形是闭合（1）还是开放（0）。
Polygon poly - 多边形模式的序列
Pattern poly0pattern - 通过为每个多边形指定点模式来创建固定数量的多边形。在此输入连接列表以添加多边形。它们由一个点编号列表组成，用于定义点的连接顺序。形式为：{from}-{to}[:{every}][,{of}]。

有效连接列表示例：

1 2 3 4 - 通过连接点编号 1,2,3,4 构成一个多边形。
1 3-15 16 8 - 包含 3-15 的所有点。
1-234 820-410 235-409 - 按指定顺序包含 1-820 的点。
0-15:2 - 包含 0 到 15 中每隔一个的点。
0-15:2,3 - 每 3 个点中包含 2 个（即 0, 1, 3, 4, 6, 7, 9, 10, 12, 13, 15）。
!4 - 包含除 4 以外的所有点。
!100-200 - 包含所有小于 100 和大于 200 的点。
* - 包含所有点。
9-0 - 按相反顺序包含前十个点。
!9-0 - 按相反顺序包含除前十个点之外的所有点。
Closed poly0closed - 要创建闭合多边形，请勾选 Closed 按钮。

参数 - Post 页

Remove Unused Points remove - 仅保留已连接的点，丢弃未使用的点。
Compute Normals normals - 在几何上创建法线。

用法

与点表达式结合使用时，Add SOP 可用于从另一个 SOP 中提取特定的点。例如，要从 geo1 中的 Grid SOP 提取第五个点的 X、Y 和 Z 值： 

op('geo1/grid1').points[5].x
op('geo1/grid1').points[5].y
op('geo1/grid1').points[5].z

如果指定了 Source，以此方式添加的点会追加到点列表末尾。在 SOP 节点上中键单击可得知共有多少个点。例如，如果你添加了两个点，而共有 347 个点（从 0 到 346），则你添加的是最后两个点编号：345 和 346。

操作符输入

  • Input 0: -

Info CHOP 通道

Add SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
