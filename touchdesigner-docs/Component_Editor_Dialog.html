组件编辑器对话框

说明

Component Editor 用于设置 custom components 和 Script Operators 的许多方面（例如 Script DAT），尤其是 Custom Parameters 的管理。其中还有用于管理 Extensions、Shortcuts and Tags 和 Storage 的区段

要打开 Component Editor，右键点击你要编辑的 COMP 并选择 Customize Component...

为方便起见，Component Editor 的每个主要区段都可以折叠，参数/页面列表区域的大小可以用其下方的手柄调整。

标题栏

标题栏显示并控制你正在编辑的操作符。名称可在 Component 区域中更改。当前选中的组件可在 Path 区域中更改。右上角的四个 buttons 会分别打开 floating viewer、parameter dialog、network editor 或本 help page。

你也可以从网络中将操作符拖到标题栏上来选择要编辑的操作符。

自定义参数

Custom Parameters 区段可方便地编辑组件的自定义 pages 和 parameters。

创建页面与参数

该区段最上面两行用于创建新的自定义页面和参数。要创建页面，在文本框中输入新页面名称并按 Add Page。要创建参数，在文本框中输入新参数的标签，选择参数样式，选择值的数量（如需要），然后按 Add Par。参数创建时，标签会自动转换为有效的参数名称（首字母大写，不含特殊字符）。如果你选择的参数类型可以容纳可变数量的值（float 或 int），你还可以选择 1 到 4 的 size。

使用页面列表和参数列表

该区段的中部包含组件的 custom pages 列表（左侧）和 custom parameters 列表（右侧）。参数列表显示当前选中页面中的自定义参数。参数和页面可以拖动来重新排序。参数也可以拖到不同的页面中。使用 RMB menus 和 ctrl-C/ctrl-V 进行剪切和粘贴，包括跨不同组件。双击可编辑名称，按「x」可删除。在列表中拖放可重新排序。提示： 复制参数会以人类可读的 JSON 格式把它们放到剪贴板中。你可以在任何文本编辑器中编辑它们，然后重新复制并粘贴编辑后的版本。

把参数从 Parameter Dialog 拖到 Parameter 列表中，会在你的组件中复制该参数。会出现一个菜单，其中有为新参数自动创建 Reference 或 Bind 的选项。

  • Bind New Par as Master - 在被拖动的参数上放置一个绑定表达式，指向新参数。
  • Bind New Par as Reference - 在新参数上放置一个绑定表达式，指向被拖动的参数。
  • Set Reference Expression on Source - 在被拖动的参数上放置一个表达式，指向新参数。
  • Cancel - 不创建表达式或绑定表达式。点击别处效果相同。

编辑自定义参数

在列表中选中某个自定义参数时，两个列表下方会显示编辑区域。这里可以更改该自定义参数的设置。以下设置自上而下排列，其 Python 脚本名称列在 like this 中：

  • parameter tupletName - 参数的脚本名称。多值参数（例如 RGB）会为每个值在该名称后加上后缀。
  • label label - 参数显示的标签
  • enable enable - 被禁用的参数会变灰。禁用与当前设置无关的参数
  • enable expr enableExpr 作为在其他脚本中设置启用状态的替代方法，你可以在此输入 Python 表达式。如果表达式求值为 True，参数将被启用。此表达式从自定义组件的上下文中求值。Example: me.par.Useminmax 如果同一操作符上名为 Useminmax 的参数求值为 True，则启用该参数。
  • help help - 按住 Alt 键将鼠标悬停在参数标签上时显示的弹出帮助。
  • read only readOnly - 为 True 时，参数值不可设置，但可选择/复制，并可被其他参数引用。此设置通常用于由组件内部作为输出或信息值设置的参数。用户可通过参数的右键菜单更改此设置。
  • section section - 为 True 时，在参数上方创建一个视觉分隔线。
  • style style - 参数样式（例如 Int 或 Float）和大小（如适用）。关于样式及样式专属值的信息，参见 Custom Parameters。

以上值对所有参数通用。下一区段包含某些参数类型专属的值，仅在适用时出现。标题栏包含每个子值实际的参数 name（如适用）。

  • default default - 值是指通过参数右键菜单「重置」参数时，参数将被设为的值。右侧的按钮决定默认模式（constant、expression 或 bind）。要把当前参数值或状态（包含模式数据）复制到默认值中，点击默认值区段旁的箭头。菜单中还有为整个页面或整个组件设置所有默认值的选项。
  • range min/max normMin/normMax - 参数滑块的范围。超出此范围的值仍允许在文本输入区中输入，也可通过脚本设置。
  • clamp min/max clampMin/clampMax（复选框）和 min/max（值） - 定义参数的绝对最小值和最大值。要强制执行钳制，必须勾选钳制值左侧的复选框。
  • menuNames menuNames - 菜单参数使用的值字符串列表，以空格分隔。这是菜单参数实际返回的值。含空格的值请使用引号。使用 Menu Editor 按钮可获得基于列表的界面。
  • menuLabels menuLabels - 菜单参数使用的标签字符串列表，以空格分隔。这是菜单参数在其下拉列表中显示的选项。含空格的标签请使用引号。使用 Menu Editor 按钮可获得基于列表的界面。
  • menuSource menuSource - 指向另一个菜单参数、或指向具有 menuNames 和 menuLabels 成员的 Python 对象的表达式。参数将从该来源获取其 menuNames 和 menuLabels。提示： 工具函数 parMenu（位于 TDFunctions 中）可帮助创建合适的 menuSource Python 对象。你也可以使用 tdu.TableMenu 从菜单名称和标签的表格创建合适的 menuSource 对象。

扩展代码

Extension Code 区段协助为你的自定义组件创建 Python Extensions。要创建新扩展，只需在文本框中输入名称并点击 Add。创建后，你可以用右侧的 Edit、Init 和 X 按钮编辑、重新初始化或删除该扩展。三角形按钮会展开 Advanced 功能，可用来为扩展创建自定义定义和/或名称，或打开/关闭 Promotion。使用 + 和 - 按钮添加或移除扩展槽。

提示： 在 TouchDesigner 中，惯例是把扩展名称首字母大写并加上后缀 Ext。

快捷键与标签

此区段让你设置组件的标识功能。你可以输入 Parent Shortcut、Global OP Shortcut，并添加/移除 Tags。

在此下方，你可以设置 Internal Operator 快捷键。在 Internal OP Shortcut 字段中输入快捷键名称后，可以用 Create 按钮创建操作符（如果尚不存在）。如果已存在，你可以在 Internal OP 字段中输入路径（绝对路径或相对于组件的路径）。当该字段指向有效操作符时，Edit 按钮会在 Component Editor 中打开它。使用 + 和 - 按钮添加或移除 Internal OP 快捷槽。

存储

Storage 区段让你直接访问组件的 Storage 字典。你可以看到所有键和数据。按 x 会删除已存储的键和数据。要更改数据或键，双击文本。要添加新键或刷新列表，使用底部的 Add Key 和 Refresh 按钮。

提示： 你输入的任何数据都会由 Python 求值，因此如果你想强制使用字符串类型的数据，请用引号括起来。
