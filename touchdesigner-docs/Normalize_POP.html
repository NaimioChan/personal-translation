Normalize POP

摘要

Normalize POP 可以把所有 XYZ 位置值重新缩放到 0-1 范围，并且可以对任意属性这样做。

它可以输出到任意现有或新建的属性。

它的能力远不止于此：它可以把任意位置转换为极坐标或柱坐标，即以 0-1 范围表示的纬度、经度和半径。

它可以把这些归一化值中的任意一个放入 float2、float3 或 float4 属性的任意分量。

在把数值归一化到 0 和 1 之间后，它还可以用 Bias 让数值更接近 0 或 1，可以对归一化值应用 Lookup 函数（例如应用 ease-in ease-out），然后应用 Exponent（提升或降低数值，但保持 0 和 1 不变），最后把 0-1 值 Re-range 到任意其他范围。

Normalizing into polar or cylindrical form：例如归一化极坐标半径时，它会找到离 0, 0, 0 最远的点，然后计算每个点相对于最远点的距离。这样就归一化了半径。

当把点归一化为绕 Y 轴的经度时，会给出 0 到 1 的值，其中 0 或 1 位于沿 -Z 轴的「背面」，经度值 .5 位于沿 +Z 轴的「正面」。

类似地，绕 Y 轴的纬度中，值 0 在南极（按西方文明的思维方式），值 1 在北极，值 .5 表示点位于赤道附近。

绕 Y 轴的柱面归一化也做类似处理。

See also Projection POP 和 Texture Map POP。

About feeding components to Normalize and other POPs - 如果你填入 P(1) P(0) P(2)（或 P.yxz），它会先交换前 2 个分量（x 和 y），再把结果传给下一阶段；此时如果有 Box X，它处理的将是输入的原始 y 坐标（P(1)）。
