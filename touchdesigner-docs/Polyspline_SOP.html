Polyspline SOP

摘要

Polyspline SOP 把样条曲线拟合到多边形或外壳上，并输出该样条的折线近似。你可以选择在原始点之间创建细分，或忽略原始点的位置、把形状分成等长的段。

Polyspline 可选择对输出曲线重新采样，从而控制其每一段的长度和数量。

提示： 使用此 SOP 时，在 Viewport 选项对话框中启用 Points 显示会很有用。这样你能确切看到该 SOP 产生的效果。

参数 - 页

Group group - 要使用的面的子集。接受模式匹配，详见 Pattern Matching。
Spline Type basis - 要使用的样条类型。共有七种选择：
  • Bezier bezier - 典型的 Bezier 样条。
  • Special Bezier sbezier - Bezier 的变体。
  • Special Smooth Bezier c1bezier - Bezier 的变体。
  • Degree 2 Bezier degree2 - Bezier 的变体。
  • BSpline bspline - 更柔和的曲线，不经过 Source 的原始点。
  • Cardinal cardinal - 曲线经过 Source 的原始点。
  • Linear linear - 直线段。
Close closure - 决定输出的样条是开放还是闭合。
  • Off cnone - 输出样条为开放。
  • On calways - 输出样条为闭合。
  • If polygon does cifpoly - 沿用输入面的闭合状态。也就是说，如果 Source 多边形是闭合的，就创建闭合样条；如果 Source 多边形是开放的，就创建开放样条。
Division Method divide - 通过添加额外细分来细化样条的设置。
  • Standard standard - 不对曲线重新采样。
  • Even Length Segments evenlen - 确保各段等长。
  • Even X Segments evenx - 确保各段在 X 方向上等长。
  • Even Y Segments eveny - 确保各段在 Y 方向上等长。
  • Even Z Segments evenz - 确保各段在 Z 方向上等长。
Segment Length segsize - 重新采样后曲线各段的长度。

Division Method Standard 如果选择了 Even Length Segments，则由 Segment Length 设置输出段的长度。输出段数由 Output Divisions 决定。 如果 Output Divisions 为零，则用 Segment Length 参数计算输出段数，即这个大小的段能放入整体形状多少段。 如果选择了 Even Length Segments，同时 Output Divisions 和 Segment Length 都为零，则会生成错误信息："Invalid number of divisions or segment size"。

Output Divisions polydivs - 重新采样后曲线中的段数。

如果选择了 Division Method = Standard，此参数不起作用。如果选择了 Even Length Segments，此参数设置创建的边数。各段长度由 Segment Length 决定。如果 Segment Length 为 0，则把整体形状分成该数量的段，以此决定输出段的长度。

如果 Output Divisions 参数设为零，则使用 Segment Length 参数的值来计算 Output Divisions 的数量。

Sample Divisions edgedivs - 重新采样前的样条细分数量。

如果选择了 Division Method = Standard，这就是每条边的细分数量。如果选择 Even Length Segments，它会微妙地决定段长计算的精确程度。

First CV Count first - 重复第一个控制顶点的次数，从而决定其重数。这决定复制 Source 多边形第一个顶点的次数。当 Source 由开放多边形组成时最有用的；线首端多出的顶点会迫使曲线延伸到线的起点。例如，值为 2 会迫使 Cardinal 曲线延伸到其第一个顶点，值为 3 会迫使 Bspline 从其第一个顶点开始。
Last CV Count last - 决定重复最后一个控制顶点的次数，从而决定其重数。这决定复制 Source 多边形最后一个顶点的次数。当 Source 由开放多边形组成时最有用的；线末端多出的顶点会迫使曲线延伸到线的末端。
CV Tension tension - Source 多边形的点所施加的张力。张力越大，所得形状越接近原始形状。

操作符输入

  • Input 0: -

Info CHOP 通道

Polyspline SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
