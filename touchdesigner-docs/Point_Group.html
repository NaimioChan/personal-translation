点组

点组是一组被当作集合处理的关联点。这很重要，因为你可以把它们作为一个整体施加操作，省去对每个元素逐个操作的麻烦。此外，点组可用于过滤掉特定操作不需要的点；分组把操作范围限制在组内的点上，而不是影响整个输入。

创建点组

在 Touch 中对点分组，可使用 Group SOP、任何带点组输入字段的 SOP，或 SOP Editor 中的 Select 状态。

在 SOP Editor 中对点分组：

  1. 使用 Select 状态，并在子图标中选择 Point Groups 图标。
  2. 用光标选择需要的点。
  3. 点击子图标旁的 + 按钮调出 Parameters 对话框。点击 Combine Groups 页标签。
  4. 在编辑字段中输入新的组名。
  5. 点击 group <- selection 按钮。

有序组与无序组

点组可以是有序的，也可以是无序的。在 SOP Editor 的 Select 状态中，单击鼠标执行有序选择。批量选择通过拖动光标划过点来完成，该操作会创建一个框选区域，包围若干点。以这种方式选出的点会生成无序组。

批量选择只有在框选区域内仅框住一个点时，才会生成或保持有序选择。无序组按创建顺序存储点，有序组按选择顺序存储点。

如果想重新选中组内的点，可从 Select 状态调出 Parameters 对话框，在 Combine Groups 页标签下的 Group 弹出菜单中选择组名，然后点击按钮 selection <- group。

删除某个点时，Touch 会自动把该点从它可能所属的所有点组中移除。
