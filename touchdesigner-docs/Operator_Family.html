操作符家族

内置 Operators 共有七个 Families。在这七个族中，六个是基本操作符族，一个是 Component 族，后者还可以包含操作符网络。包含组件的组件构成 TouchDesigner 的层级，并产生操作符 Paths。

  • COMPs - Components - Object Components（3D 对象）、Panel Components（2D UI 控件）以及其它组件类型。组件包含其它操作符。
  • TOPs - Texture Operators - 所有 2D 图像操作。
  • CHOPs - Channel Operators - 运动、音频、动画、控制信号。
  • POPs - Point Operators - 3D 点、图元、多边形、点云、粒子以及基于 GPU 的数据操作。
  • DATs - Data Operators - 纯文本形式的 ASCII 文本、脚本、XML，或组织为单元格表格。
  • MATs - Material Operators - 材质和着色器。
  • SOPs - Surface Operators - 旧版 3D 点、多边形和其它 3D 图元，具备一些 POP 中尚无法实现的能力。

在每个操作符族中，"generator" 操作符有 0 个输入并创建数据，而 "filter" 操作符有 1 个或多个输入并过滤数据。

每个操作符族都有独特的颜色。只有同一族（同色）的操作符才能相互 Wired。许多操作符的参数会引用其它族的操作符：Links。此外 Exporting 将数值数据从 CHOP 流向所有操作符。

TOP、CHOP、POP、SOP、DAT 和 SOP 族的 Custom Operators 可以使用 C++ 创建，从而扩展 TouchDesigner 的功能。它们会出现在 OP Create Dialog 的 'Custom' 选项卡下。
