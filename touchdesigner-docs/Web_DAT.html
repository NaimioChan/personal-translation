Web DAT

摘要

注意：Web DAT 自版本 2019.15230 起弃用，请改用Web Client DAT。

   The Web DAT fetches pages of data from a web connection. The data should be ASCII-readable. The Web DAT will automatically uncompress any gzip compressed page transfers. XML content is formatted into a readable indented structure, versus one long line normally sent by the server. An Info DAT can be used to obtain properties of the last page retrieved.

使用 Web DAT 从网站获取页面有两种主要方法：

  • Fetch
  • Submit and Fetch

Fetch 方法只是用简单的 “GET” 协议从互联网获取页面，而 Submit and Fetch 方法可用于向服务器提交表单数据。后一种方法默认使用 “POST” 协议。


两种方法都允许用 DAT 表格输入来指定获取时的选项。该表格应由名称/值对的行组成。第一列是名称，第二列是值。Fetch 方法只是把这些对拼接到指定的 URL 中，而 Update and Fetch 方法先把这些对发送到 Web 服务器，然后再获取结果页面。

例如，假设一个内容如下的表格连接到 Web DAT：

name joe
month May

如果指定的 URL 是： http://www.example.com

那么 Fetch 方法实际获取的是： http://www.example.com?name=joe&month=May

同样，Submit and Fetch 方法会先把这些对发送到指定的 Web 服务器，然后再获取页面。

注意表格中的空格和其他特殊字符会被正确编码。例如，名称或值中的每个空格都会编码为：%20

第一个输入也可以是文本数据，此时在 POST 期间数据会按原样发送到 Web 服务器，不做任何格式化或编码。如果第一个输入是文本，在 GET 操作中会被忽略。

Web DAT 的第二个输入可用于指定请求中的自定义 HTTP 请求标头。与第一个输入一样，这应是一个由标头字段名与值组成的名称/值对表格。例如

Content-Type application/json
Date Tue, 12 Nov 2013 08:12:31 GMT

每一行都会自动合并为由冒号分隔的单行文本。如果第二列为空，则第一列的内容在转为请求标头时会附加一个分号。

另请参阅XML DAT、TCP/IP DAT、WebSocket DAT。

参数 - Fetch 页

URL url - 要获取的网页的 URL 地址。
Fetch fetch - 按下此按钮时会获取数据。用此方法从互联网检索简单的单页内容。默认情况下，Web DAT 会阻塞进程，直到整个页面传输完成或发生错误。你可以使用 Asynchronous Fetch 选项进行异步下载。
Submit Method method - 目前只实现了 POST，之后会扩展 GET 等其他方式。
  • POST post -
Submit and Fetch submitfetch - 将输入 DAT 中所有名称/值对发送到服务器，然后获取 URL 参数中指定的页面。

用此方法在获取页面前向 Web 服务器发送数据。要发送的数据以名称和值对的形式提供。可以用连接到第一个输入的表格格式 DAT 指定，其中第一列表示数据名称，第二列表示数据值。Web DAT 会暂停，直到整个页面传输完成或发生错误。

Include Header in Output includeheader - 在输出中包含 HTTP 标头。
Timeout timeout - 若此值为 0，获取请求永不超时。其他值表示获取超时前的毫秒数。
Disconnect disconnect - 关闭会话。
Asynchronous Fetch asyncfetch - 开启此选项可让下载在后台进行。可以用DAT Execute DAT在数据最终到达时执行操作。
Verify Peer Certificate verifypeer - 启用 TLS（传输层安全）证书验证。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。
