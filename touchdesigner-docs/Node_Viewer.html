节点查看器

node 可以显示其图标或查看器。点击左上角的节点标记（Viewer Flag）可切换查看器或图标。

只有当节点处于 Viewer Active 模式时，查看器才可交互。


左：带 3 字母图标的节点。中：带查看器的节点（节点左上角标记）。右：查看器已激活的节点（右下角标记）。

要获得可调整大小的浮动节点查看器，右键单击节点并选择 View...

创建新节点时，节点查看器可以默认开启。要这样做，请勾选 Edit -> Preferences -> Network 中的复选框以开启 Viewer On by Default 选项。

每个操作符族都有其特定的 Viewer 风格。

注意：在节点查看器中移动内容不会影响其变换或参数。Exception：Camera COMP
