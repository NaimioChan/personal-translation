组件变量

组件 variables 创建于任意组件的本地，可在该组件中任何位置使用，且仅在该组件中可用。

它们通常与 Tscript 一起使用，但也可以与 Python 一起使用，不过在 Python 中，Extensions 中的属性更灵活。

在 Python 中，你会使用 var('VARNAME') 表达式来获取组件变量。在 Python 中设置它们比较困难，大致像 op('../../local/set_variables')['varname',1] = value 这样。

在 Tscript 中，使用 TScript：cvar 命令来创建、列出和删除组件变量。任何组件的组件变量都可以在 Variables Dialog 中查看：把你要查看的组件拖放到 Variables 对话框上，如果该组件存在本地变量，就会创建一个标签页来显示它们。

组件变量在 TouchDesigner 的网络中按层级求值。如果引用了某个组件变量而它未在本地组件中定义，那么它会在父组件中搜索该变量。这一过程会持续到找到该变量，或到达网络层级的顶端 /，即根。

组件变量的内部工作方式：组件变量存储在组件内一个名为 local 的 Base COMP 中。变量定义在 local 内一个名为 variables 的 table DAT 中。该 DAT 由名为 set_variables 的 Table DAT 提供数据，命令（TScript：cvar、rvar）正是使用该 DAT 来插入变量。这允许把其他变量的表格合并进 variables。TScript：cvar 命令可用于列出、设置或取消设置组件变量。

注意：根变量只是在层级根部 / 设置的组件变量。
