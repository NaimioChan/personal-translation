Skin SOP

摘要

Skin SOP 接受任意数量的面，并在其上构建蒙皮曲面。但如果给定两个或更多曲面，该 SOP 会构建四个蒙皮，每个对应一组边界曲线。

所有面和曲面类型都有效，只要输入仅包含面或仅包含曲面。不同类型的面可以蒙皮成一个曲面。例如，可以将三次开放 NURBS 曲线与多边形和五次闭合 Bzier 曲线一起蒙皮，即使这三个面的控制顶点数量不同。同样，此 SOP 可以蒙皮不同类型、不同行数、列数等的曲面的边界曲线。

当面类型作为输入时，输入 SOP 的数量和每个输入中的面数决定蒙皮方法。如果只有一个输入，则执行「线性蒙皮」操作，在各横截面之间运行蒙皮。结果是经典的直纹或蒙皮曲面。如果存在第二个输入，则执行「双线性蒙皮」，在第一个输入中的面（U 横截面）与第二个输入中的面（V 横截面）之间计算交叉蒙皮。结果是其名称源自各方向横截面数量的曲面：三角形、四边形或多边界曲面，以及扫掠曲面和 N 条导轨的特殊情况。在可能的情况下，横截面按等参线进行插值。

如果需要对蒙皮中的相切性有更多控制，可尝试使用 Bridge SOP。

提示： 如果蒙皮结果的顺序有问题，可尝试在 Skin SOP 之前插入一个 Sort SOP，并 Sort by Normals。

skinSOP_Class

曲面类型

Single Boundary Surface - 一个面（开放或闭合）会转换为边界与面形状完全一致的曲面。基本上，此操作为该面构建一个内部区域。曲面类型将与面的类型相似。例如，NURBS 曲线生成 NURBS 曲面。如果曲线凹度很大，结果可能不如预期令人满意。

Patch - 两个边界面定义一个直纹曲面。两个面上的箭头指示所需的参数方向，两个面必须相同，以避免曲面出现不良扭曲。可使用 Primitive SOP 或建模器来修正问题。曲面类型将类似于两个横截面中较复杂的类型。例如，如果多边形和 NURBS 曲线一起蒙皮，曲面类型将是 NURBS。该曲面始终以这两个面作为其两条边界。

Linear Ruled/Skinned Surface - 两个或更多面线性蒙皮成单个曲面。面上的箭头指示每个面所需的参数方向，所有面必须相同，以避免曲面出现不良扭曲或翻转。可使用 Primitive SOP 或建模器来修正问题。曲面类型将类似于所有横截面中最复杂的类型。例如，如果多边形、Bzier 和 NURBS 曲线一起蒙皮，曲面类型将是 NURBS。除非关闭「Preserve Shape」（见下方参数），否则曲面会穿过每个横截面。如果横截面有重复点，或彼此共享点，启用形状保持时结果可能不好看。

A Special Swept Surface - 此情形执行双线性蒙皮，需要两个输入。U 面（第一个输入）沿 V 面（第二个输入）扫掠。两个面不必在端点处接触。但如果它们的端点重合，曲面的两条边界将完全与两个面吻合。曲面类型将类似于两个面中较复杂的类型。例如，如果多边形和 Bzier 曲线一起蒙皮，曲面类型将是 Bzier。

Triangular Surface - 此情形需要两个输入进行双线性蒙皮。一个输入有两个面，另一个输入只有一个面。面的端点不必重合，但如果重合，曲面边界将完全与面形状吻合。基本上，三个面定义一个待由曲面填充的内部区域。曲面类型将类似于三个边界面中最复杂的类型。例如，如果这些面是 Bzier 和 NURBS 曲线，曲面将是 NURBS 图元。

Square Surface - 四个面定义曲面的外部边界。此情形需要两个输入进行双线性蒙皮：两条 U 边界（第一个输入）与 V 边界（第二个输入）交叉蒙皮。面的端点不必重合，但如果重合，曲面边界将完全与面形状吻合。基本上，四个面定义一个待由曲面填充的内部区域。曲面类型将类似于四个边界面中最复杂的类型。例如，如果这些面是多边形和 NURBS 曲线，曲面将是 NURBS 图元。

A Special Case of M-rails - 一个输入包含导轨，另一个输入包含横截面。横截面沿导轨扫掠形成曲面。面上的箭头指示每个面所需的参数方向，所有面必须相同，以避免曲面出现不良扭曲或翻转。可使用 Primitive SOP 或建模器来修正问题。曲面类型将类似于导轨和横截面中较复杂的类型。例如，如果这些面是多边形和 NURBS 曲线，曲面将是 NURBS 图元。

Multiple-Boundary Surface - 不要与 N 元面片混淆。此情形通过允许 U 和 V 方向有更多内部横截面，推广了四边形曲面的概念。如果没有内部横截面，此情形就退化为四边形曲面。曲面会对所有边界和内部横截面进行插值。当面相交时结果会改善。面上的箭头指示每个面所需的参数方向，所有面必须相同，以避免曲面出现不良扭曲或翻转。可使用 Primitive SOP 或建模器来修正问题。曲面类型将类似于所有面中最复杂的类型。例如，如果这些面是多边形和 NURBS 曲线，曲面将是 NURBS 图元。

参数 - 页

U Cross Sections uprims - 此字段默认为空，提供了一种指定第一个输入的面和曲面子集的方式。通过从该字段的弹出菜单中选择一个或多个图元组来指定。
V Cross Sections vprims - 此字段默认为空，提供了一种指定 V 面子集的方式。如果存在第二个输入，可供选择的图元组取自第二个输入。如果只有第一个输入，弹出菜单中列出的组属于第一个输入。这意味着只要第一个输入中同时有 U 组和 V 组，双线性蒙皮并不总是需要两个输入。
Connectivity surftype - - （结果仅对多边形和网格可见）。
  • Rows rows - 创建水平线。
  • Columns cols - 创建垂直线。
  • Rows and Columns rowcol - 行列都有。在线框显示下看起来像 Quads，但所有多边形都是开放的（若图元类型为 polygon）。可在 Model Editor 中对比。
  • Triangles triangles - 用三角形构建网格。
  • Quadrilaterals quads - 生成由四边形构成的侧面（默认）。
  • Alternating Triangles alttriangles - 生成相互对置的三角形；类似 Triangles 选项。
Preserve Shape keepshape - 此参数决定线性蒙皮（图中情形 c）的精度。启用后，它确保生成的曲面穿过每个横截面。这里的横截面可以是面或曲面边界，取决于蒙皮的类型。禁用时，Preserve Shape 生成的曲面其 CV 与横截面的 CV 重合（在它们被转换为共同类型并具有相同数量的 CV 之后）。关闭形状保持时蒙皮算法更快，但精度不足。

当横截面有许多重合的 CV 或彼此非常接近时，开启形状保持的蒙皮可能产生不符合直觉的形状。此时可尝试抖动 CV、改变 V Order（见下文），或直接禁用形状保持。

进行双线性蒙皮时，形状保持会被停用。

V Wrap closev - 此菜单（菜单：Off、On、If primitive does）设置决定曲面是否应在 V 参数方向上环绕。选项为开放（Off）、闭合（On）或从横截面继承闭合类型。进行双线性蒙皮时 V Wrap 被忽略。
  • Off nonewv -
  • On wv -
  • If Primitive does ifprimwv -
Use V Order force - 启用或禁用 V Order 参数的使用。如果标记为 OFF，蒙皮曲面在 V 方向按三次（阶数 4）构建，除非给定的开放 V 横截面少于四个，或闭合 V 横截面少于三个。例如，如果输入由两个面组成且 V Wrap 标记为 OFF，曲面在 V 方向将是线性的（阶数 2）。当所有面或曲面分别为多边形或网格时，以及进行双线性蒙皮时，V Order 标记的状态无关紧要。

这里，横截面指面或曲面边界，取决于蒙皮的类型。

V Order orderv - 当 V Order 标记启用时，指定蒙皮曲面的阶数。阶数为「n」的 NURB 曲面至少需要 n 或 n-1 个横截面才能构建，分别取决于曲面在 V 方向是开放还是闭合。同阶的 Bzier 曲面在开放时至少需要 M*(n-1) + 1 个横截面，闭合时需要 M*(n-1) 个横截面。M 是一个非负整数乘数。当所有面或曲面分别为多边形或网格时，以及构建双线性蒙皮时，V 阶数会被忽略。
Skin skinops - 可选择按 n 个图元的子组或按循环方式每隔第 n 个图元进行蒙皮。

For example；假设有六个图元，编号为 0 - 5，且 N = 2。那么，

  • Groups 会生成 0-1 2-3 4-5
  • Skipping 会生成 0-2-6 和 1-3-5。
  • All Primitives all -
  • Groups of N Primitives group -
  • Skip Every Nth Primitive skip -
N inc - 决定要分组或跳过的图元数量。N2。
Keep Primitives prim - 决定输入图元是保留（On）还是从输出中删除（Off）。
Output Polygons polys - 若设置，此标记指示程序在曲面类型为 Mesh 时将蒙皮曲面转换为多边形。

Info CHOP 通道

Skin SOP的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
