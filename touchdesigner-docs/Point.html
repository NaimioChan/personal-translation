点

(note - to be updated for POPs - currently SOP-leaning)

Python API 见 Point Class。

每个 POP 和 SOP 都有一个点列表。点是带若干可选额外属性的 XYZ 位置。point attributes 包括：

  • P - 以 3 个浮点数表示的 XYZ 三维位置。
  • Cd - 颜色（可选）标准的 4 值属性，其中 RGB 颜色为 Cd[0]、Cd[1]、Cd[2]，alpha 为 Cd[3]。（见 Point SOP）
  • uv - 纹理（可选）标准的 3 值属性，其中 UV 为 uv[0] 和 uv[1]，W 为 uv[2]。（见 Point SOP）
  • N - 法线矢量（可选）标准的 3 值属性。（见 Facet SOP 和 Point SOP）
  • T - 切线矢量（可选）标准的 4 值属性。（见 Attribute Create SOP）
  • 用户自定义属性。（见 Point SOP）

每个 Polygon 由顶点列表定义，顶点列表是一串点编号。

在 s SOP 上，用鼠标中键点击节点，可以看到点、多边形、粒子系统及其他图元、属性和包围盒的摘要。

注意：点不能被直接渲染。要渲染点，必须先 Particles。可以用 Convert SOP 把点转换为粒子，或由 Particle SOP 直接生成。另请参阅 Point Sprite MAT。
