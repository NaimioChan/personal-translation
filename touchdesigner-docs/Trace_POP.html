Trace POP

摘要

Trace POP 读取一张 TOP 图像并对其进行描边，在超过一定亮度阈值的区域周围生成线带。你可以使用 Threshold 参数控制阈值，并与由 Channel 菜单决定的像素值（默认为亮度）进行比较。

线带可以三角化为三角面，也可以保持其基本形式（最快但最不实用）作为 2 点线段。

可以使用 Resolution Multiplier 参数降低所得线带或三角网格的分辨率。

可以使用 Smooth Edge Distance 参数平滑线带，其作用类似于 Line Smooth POP 中的平滑。

Extend 菜单决定线带是沿边界继续，还是作为开放线带分开。

Winding 会使外围线带为逆时针方向，被其包围的线带为顺时针方向。

X 方向的输出为 -.5 到 .5（P(0)），但可以使用 ReRange P 参数重新映射范围。

你可能需要调整 Max Num Line Strips 参数或 Max Num Verts 参数（因为这些数值必须预先确定，以便 GPU 避免溢出）。

另请参阅 Polygonize POP、Triangulate POP、Extrude POP

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
