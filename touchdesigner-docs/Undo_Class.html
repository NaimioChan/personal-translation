Undo 类

用于启用和禁用撤销功能的类。可以在脚本中创建撤销块。回调结束时，任何悬挂的撤销块都将被终止。见页面底部的 examples。

此类作为全局 UI Class 的成员提供，可通过 ui.undo 访问。

成员

globalState → bool :

全局撤销是否启用。

redoStack → list (Read Only):

可用重做操作的名称列表。

state → bool (Read Only):

撤销是否启用。

undoStack → list (Read Only):

可用撤销操作的名称列表。

方法

startBlock(name, enable=True)→ None:

开始一个带名称的撤销块。块处于活动状态期间，对 TouchDesigner 对象的任何在编辑器中可撤销的脚本更改都会加入撤销堆栈。

  • name - 块的名称，应简要描述将被撤销的更改。
  • enable - 在罕见情况下，若想在一个存储撤销信息的块内插入一个不存储撤销信息的块，可以创建 enable 为 off 的块。示例：
# 撤销此操作只会移除 noiseTOP 和 noiseSOP。

ui.undo.startBlock("constant1 r = 0")
a = op('constant1').par.colorr = 0
ui.undo.startBlock("constant2 g = 0", enable=False)
a = op('constant2').par.colorg = 0
ui.undo.endBlock()
a = op('constant3').par.colorb = 0
ui.undo.endBlock()

clear()→ None:

清除撤销和重做堆栈。这将终止任何当前的撤销块。

addCallback(callback, info=None)→ None:

将 Python 回调添加到当前撤销块中。

回调应定义为 def yourCallbackName(isUndo, info)。isUndo 参数说明该调用是撤销还是重做（两者使用同一回调），info 参数是与传给 addCallback 相同的 Python 对象，应包含执行撤销/重做所需的任何信息。

  • callback - 用户定义的回调函数。应定义为 callback(isUndo, info)
  • info - 此参数将在回调中回传给用户

redo()→ None:

重做下一个操作。这将终止任何当前的撤销块。

undo()→ None:

撤销上一个操作。这将终止任何当前的撤销块。

endBlock()→ None:

终止一个撤销块。

撤销块示例

设置撤销块很简单，只需启动它，然后执行编辑器通常可以撤销的任何更改： 

ui.undo.startBlock("Change Title Text")
op('title').par.text = 'Making Your Own Undo System'
op('title').par.fontsize = 30
ui.undo.endBlock()

运行此脚本后，执行撤销操作会将引用的 text 和 fontsize 参数改回其先前的值。重做功能同样自动。

撤销回调

你也可以作为撤销堆栈的一部分执行 Python 动作。当你更改 TouchDesigner 编辑器不知道如何撤销的内容时（例如更改 extension 值），这很有必要。撤销回调接受 info 参数，应用于向回调提供撤销和重做信息。 

# 撤销回调必须在被 ui.undo.addCallback 引用之前定义
# 当 TouchDesigner 试图撤销它被添加到的块时会调用此回调
def undoMasterChange(isUndo, info):
	# isUndo 说明此次调用是撤销还是重做
    # info 是用户提供的任意 Python 对象
	if isUndo: # True 表示撤销
    	ext.MasterExt.data = info['prev'] # 把数据改回我们存为 "prev" 的内容
    else: # False 表示重做
        ext.MasterExt.data = info['new'] # 把数据改回我们存为 "new" 的内容

newData = 'new stuff'

# 开始该块
ui.undo.startBlock("Update Master Data")

# 保存撤销/重做信息
info = {'prev': ext.MasterExt.data, 'new': newData) 

# 接下来执行更改
ext.MasterExt.data = newData

# TouchDesigner 不知道如何撤销上述操作，因此添加回调
ui.undo.addCallback(undoMasterChange, info)

# 你可以把回调与普通可撤销项混用，所以下一行会被加入该块
op('master').par.Version += 1 

# 结束该块
ui.undo.endBlock()

注意：向撤销块添加内容的顺序可能有影响。执行 undoing 时，更改将被撤销，回调将按其在撤销块中接收的 reverse order 运行。执行 redoing 时，更改将按最初在撤销块中接收的顺序进行。
