Attribute SOP

摘要

Attribute SOP 可让你手动重命名和删除点、顶点和图元属性。

每个参数页的顶部区域用于删除特定类型的属性。

例如：Cd Alpha

Pattern Matching - 删除时会接受通用模式匹配来确定要删除哪些属性。例如：

* = 删除所有属性
Cd = 删除 Cd 属性
Cd Alpha = 删除 Cd 和 Alpha 属性
a* = 删除所有以 a 开头的属性
* ^Cd = 删除除 Cd 之外的所有属性

注意： 绝不要只删除以下属性中的某一个，而应始终将它们一起保留或删除。这是因为 TouchDesigner 的 capture/deform 系统要求这三个属性同时存在。只删除其中一部分会因它们相互依赖而导致错误： pCapt (point attribute), pCaptPath, pCaptData (detail attribute)

另请参见：Attribute Create SOP。

每个页面的下一部分用于重命名属性。在 'From Attribute' 参数中指定原始输入属性的名称，在 'To Attribute' 参数中指定想要改成的新名称。

attributeSOP_Class

参数 - Point 页

Delete Attributes ptdel - - 使用该字段指定要删除的点属性。只需输入要删除的属性列表（以空格分隔），例如输入：Cd Alpha。也可以使用右侧的下拉菜单来选择。
  • * * -
Point Rename pt - 点重命名序列
From Attribute pt0from - 指定要重命名的属性，或从右侧的下拉菜单中选择。
To Attribute pt0to - 在此输入属性的新名称。

参数 - Vertex 页

这些标签页与 Point 页相同，只是它们处理输入几何的顶点和图元属性。

Delete Attributes vertdel - - 使用该字段指定要删除的顶点属性。只需输入要删除的属性列表（以空格分隔），例如输入：uv N。也可以使用右侧的下拉菜单来选择。
  • * * -
Vertex Rename vert - 顶点重命名序列
From Attribute vert0from - 指定要重命名的属性，或从右侧的下拉菜单中选择。
To Attribute vert0to - 在此输入属性的新名称。

参数 - Primitive 页

接受所有类型的几何。

Delete Attributes primdel - - 使用该字段指定要删除的图元属性。只需输入要删除的属性列表（以空格分隔），例如输入：Cd creaseweight。也可以使用右侧的下拉菜单来选择。
  • * * -
Prim Rename prim - 图元重命名序列
From Attribute prim0from - 指定要重命名的属性，或从右侧的下拉菜单中选择。
To Attribute prim0to - 在此输入属性的新名称。

参数 - Detail 页

Delete Attributes attrdel - - 使用该字段指定要删除的 Detail 属性。只需输入要删除的属性列表（以空格分隔）。也可以使用右侧的下拉菜单来选择。
  • * * -
Detail Rename attr - Detail 重命名序列
From Attribute attr0from - 指定要重命名的属性，或从右侧的下拉菜单中选择。
To Attribute attr0to - 在此输入属性的新名称。

操作符输入

  • Input 0: -

Info CHOP 通道

Attribute SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
