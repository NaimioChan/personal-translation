Designer 模式

在 Designer Mode 中，你在 Network Editor、Animation Editor 和其他 Panes 中编辑 Network、Nodes 和 Parameters。

相比之下，Perform Mode 是你在 Designer Mode 中创建的用户界面。

Designer Mode 有自己的 Application Shortcuts，与 Perform Mode 的不同。

另请参阅 Perform Mode、Window Placement、Privacy。
