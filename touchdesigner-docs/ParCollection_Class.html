ParCollection 类

ParCollection 类可用于访问 Parameters。要访问某个参数，需要使用其内部名称，可将鼠标悬停在参数名上，查看弹出的提示来获得。另请参阅 Par Class。操作符的此实例可在 OP.par 中找到。

成员

该对象为组件中的每个参数包含一个成员。可以使用以下方式读取值：

a = op('geo1').par.tx

也可以使用以下方式修改值：

a = op('geo1').par.tx = 4
a = op('geo1').par.lookat = 'null1'

owner → OP (Read Only):

此对象所属的 OP。

方法

[name]→ Par:

使用 [] 下标和赋值运算符可以方便地访问 Parameters。

  • name - 必须是精确的字符串名称。不支持通配符。如果未找到则返回 None。
p = op('base1').par['Myfloat5']
