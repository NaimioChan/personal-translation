在 TouchDesigner 中使用共享内存

概述

TouchDesigner 中的各种 OP 都能通过共享内存发送和接收数据，这是在两个不同进程之间发送数据的快速方式。本指南将帮助你制作自己的应用，以便从 TouchDesigner 发送或接收数据。本指南给出设置和使用共享内存的基础知识。针对每种 OP 类型更具体的文章会告诉你如何读写此共享内存，以便进程之间能正确通信。

注意： 你需要 TouchDesigner Commercial 或 Pro 才能使用 Shared Memory 节点。

源文件

提供了 C++ 源代码，使此任务容易得多。你可以在 TouchDesigner 安装目录中的 Samples/SharedMem 获取源文件。

UT_SharedMem

此类的功能涵盖了管理共享内存所需的一切。如果你是发送方，需要创建共享内存，同时指定共享内存的大小。此大小需要足够大，以容纳你要写入的所有数据。数据量取决于你使用的 OP 类型。更多信息请参阅该 OP 的文章。如果你是接收方，只需指定共享内存的名称。此名称与你在共享内存 OP 中给参数起的名称一致。像这样创建共享内存以发送数据

 UT_SharedMem *shm = new UT_SharedMem(ShmString(L"mymemoryname"), myRequiredSize); // 根据 OP 计算出尺寸

或作为接收方

 UT_SharedMem *shm = new UT_SharedMem(ShmString(L"mymemoryname"));

使用以下方式检查共享内存的状态

 UT_SharedMemError err = shm->getErrorState();
 if (err != UT_SHM_ERR_NONE)
 { 
    // 发生了错误
 }


在读写内存之前，你需要锁定它。如果能够锁定内存，你就可以获取指向内存的指针并使用它。获得此指针后，用它做什么取决于你通信的 OP 类型。 最后，读写数据完成后解锁。 

 if (!shm->lock())
 {
     // 错误
 }
 else
 {
     void *data = shm->getMemory();
     
     // 在此使用数据
     
     // 完成后解锁
     shm->unlock();
 }

UT_Mutex

UT_Mutex 是一个用于锁定/解锁共享内存段、确保两个进程不会同时访问它的类。你不需要自己使用此类，但 UT_SharedMem 会用到它，所以务必在你的项目中包含并编译它。

编译问题与注意事项

Unicode

在 2018.20000 及更早的版本中，UT_SharedMem 类没有编写 Unicode 支持。如果你遇到涉及 LPCWSTR 类型或其他 Unicode 类型的错误，说明你在开启 Unicode 支持的情况下编译，但使用的是 2018.20000 及更早版本的旧源代码/头文件。转到项目属性 'General' 页，在 'Character Set' 中选择 'Not Set'。如果你需要 Unicode 支持，请使用 2019.10000 系列或更新版本的头文件。

在 2019.10000 系列版本中这一点已更改，该类已编写为符合 Unicode。
