Plane POP

摘要

Plane POP 以平面网格的形状创建成行成列的点。这些点可以用 Connectivity 菜单以各种图元连接起来。

Connectivity 菜单让你输出三角形、交替三角形、四边形、线、线带、点图元，或不输出任何图元（None，只有点）。

你指定行数和列数。默认情况下 Columns 指 X 方向的分段，Rows 指 Y 方向的分段。

在 Connectivity 菜单中，你可以沿 Rows、Columns 或两者合并的方向创建线和线带。

Orientation 菜单让你把网格放置在 YZ 平面或 ZX 平面上。

Anchor 会把网格的左、中或右侧对齐到 X=0、Y=0 或 Z=0。

随后可以用 Rotate 和 Translate 参数对平面网格做旋转和平移。

Dimension：当网格被传给其他 POP 时，无法确切知道指定了多少行多少列。不过 Plane POP（以及其他生成器 POP）会把它的 Dimensions 作为元数据输出给它连接的所有 POP，表明点在点列表中的组织方式。平面网格的维度是 numCols numRows，内置属性（例如 _Dim[]）或 GLSL 代码都可以使用它。

你可以输出点法线或顶点法线（生成 N 属性），也可以输出点纹理坐标或顶点纹理坐标（Tex 属性）。

应用 Orientation 之后，假设是 YZ，则分配纹理坐标时，第一个分量 Tex(0) 沿第一个字母的轴（YZ 方向中即 Y），Tex(1) 沿第二个字母的轴（YZ 方向中即 Z）。

Plane POP 可以接受一个输入，这会让起始网格的包围盒与输入的包围盒相同。然后打开 Modify Bounds 就能进一步变换该管状体。

另请参阅 Grid POP、Sphere POP、Torus POP、Revolve POP、Dimension

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
