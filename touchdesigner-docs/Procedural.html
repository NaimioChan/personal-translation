程序化

程序化是指根据实时输入和 TouchDesigner 的当前状态自动生成输出。Dependency 是 TouchDesigner 中的程序化机制：当某一份数据变化时，会自动引起其他操作符和表达式重新 Cook。这确保 TouchDesigner 进程中的所有数据保持一致，并使所有输出显示、UI、设备和协议实时更新。

TouchDesigner 既是「pull system」也是「push system」。拉取系统是程序化部分，数据被生成、修改并拉向输出，例如显示、音频设备、网络流和设备。推送系统基于来自用户输入、外部设备和软件以及内部生成事件的 Events。事件通常会导致参数、DAT 表格和 python 数据结构的更改，进而影响拉取发生时生成的程序化数据，通常每个时间轴帧发生一次。

自动依赖

如果某个操作符的输出数据或参数值发生变化，会使其下游的其他操作符计算。下游是指连接到变化节点输出的操作符，以及引用该变化操作符的操作符（或其参数）（通常表现为网络中的虚线）。

Python 数据依赖

由于 Python 本身没有程序化机制，TouchDesigner 中的 Dependency Objects 允许 python 数据在变化时触发下游计算。

关于如何设置 Python 依赖，请参见 Dependency_Class。要创建可递归依赖的 Python 集合，请参见 Deeply Dependable Collections。

另请参阅 Event。
