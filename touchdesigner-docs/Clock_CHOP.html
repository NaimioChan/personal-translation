Clock CHOP

摘要

Clock CHOP 生成反映年、月、周、日、时、分、秒和毫秒的通道。它还有一个月相周期通道。它以独立通道和不同单位提供日期。它以两种方式呈现时间：

  • 它生成反映年、月、周、日、时、分、秒和毫秒的 0-1 ramps。
  • 它会生成 integers that reflects the day-of month 等。在这种形式下，2004 年的 year 通道值为 4，以此类推。
  • 它会生成到特定日期的倒计时。

它带有日出/日落功能，你也可以通过向该 CHOP 输入 1-6 个通道来覆盖一年中的第几天。

参数 - Clock 页

Output output - Fractions 或 Units 会影响 Clock CHOP 输出的通道数据。Fractions 给出方便的 0-1 渐变，Units 给出整数，例如一天的小时为 0-23。例如，使用 Fractions 以及 day、hour 和 minute 通道来驱动一个挂钟。
  • Units units - 生成 integers that reflect the day-of month 等。在这种形式下，2004 年的 year 通道值为 4，以此类推。
  • Fractions fractions - 生成 0-1 ramps，反映年、月、周、日、时、分、秒和毫秒的时间。
  • Countdown countdown - 以 Countdown 模式运行。第一个输入应包含名为 year、month、day、hour、min、sec 和 msec 的通道。任何缺失的值都假定为指定年份 1 月 1 日的午夜。第二个输入完全是可选的，缺失的值取自当前时间。对于年份值，25 表示 2025，以此类推。
Hour Format hourformat - 12 hour 或 24 hour - 使 hour 通道在 12 或 24 小时之间循环。也会影响 AM/PM 通道。
  • 12 hour 12 -
  • 24 hour 24 -
Hour Adjust houradjust - 在 Clock CHOP 读取当前时间后，它会加上 Hour Adjust，以假装当前时间与实际的当前时间不同。
Start Reference startref - 对应年份 0、第 1 天、0 时 0 分的日期/时间。它可以相对于 2000 年 1 月 1 日，也可以相对于 TouchDesigner 进程启动的时间。
  • Since Jan 1 2000 jan1 -
  • Since Program Start program -
Millisecond msec - 如果 Output 为 Units，则为当前毫秒，从一秒开始的 0 递增到一秒结束的 999。如果 Output 为 Fraction，则为当前毫秒的小数部分。
Second sec - 如果 Output 为 Units，则为当前秒，整点时为 0，递增到 59。如果 Output 为 Fraction，则为当前秒的小数部分（分钟过后 45 秒给出 .75）。
Minute min - 如果 Output 为 Units，则为当前分钟，整点时为 0，递增到 59。如果 Output 为 Fraction，则为当前分钟的小数部分（分钟过后 45 秒给出 .75）。
Hour hour - 如果 Output 为 Units，则为当前小时，午夜时为 0，并受 AM/PM 影响。如果 Output 为 Fraction，则为当前小时的小数部分（小时过后 15 分钟给出 .25），并考虑当前的分钟和秒。
AM/PM ampm - 中午之前为 0，中午之后为 1。
Day of Week wday - 如果 Output 为 Units，则为实际的星期几，从星期一的 0 到星期日的 6。如果 Output 为 Fraction，则为当前时刻在一天中的小数部分，因此在下午 6:30 为 .77，并考虑小时、分钟和秒。要获取当前时间相对于周的小数部分，请使用 week 输出。
Day of Month day - 如果 Output 为 Units，则为实际的月内日期，例如 3 月 20 日为 20。如果 Output 为 Fraction，则此参数被禁用。要获取当前时间相对于月的小数部分，请使用 month 输出。
Day of Year yday - 如果 Output 为 Units，则为一年中的第几天，1 月 1 日为 0。如果为 Fraction，则此参数被禁用。要获取当前时间相对于年的小数部分，请使用 year 输出。
Week week - 一年中的周，第一周为 0，一年中最后一周为 51。
Month month - 一年中的月份，1 月为 1，12 月为 12。
Year year - 如果 Output 为 Units，则为相对于 Start Reference 的整数年份，从 0 开始，因此 2009 年默认是 9。如果 Output 为 Fraction，则为当前年份的小数部分，并考虑今天的月、日、时、分和秒。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Clock CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
