glTF

图形库传输格式或 GL 传输格式（glTF）是一种免版税的规范，用于让引擎和应用程序高效地传输和加载 3D 场景与模型。glTF 能将 3D 资源的体积以及解包和使用它们所需的运行时处理降到最低。glTF 定义了一种可扩展的发布格式，通过让 3D 内容在业界可互操作使用，简化了创作流程。

glTF 文件由 glTF In COMP 和 glTF Out COMP 处理。

glTF 导入

导入通过 glTF In COMP 完成。导入时会生成一个内部网络，其中的节点按应用到 glTF 文件的节点映射创建。glTF In COMP 一次只能导入一个场景（glTF 文件）。

关于 Blender glTF 导出的技巧（用于导入 TouchDesigner），请参阅 Blender 页面。

glTF 导出

导出通过 glTF Out COMP 完成。glTF Out COMP 会遍历输入的 COMP（引用的或内部的），并根据定义的节点映射在导出时创建 glTF 节点层级。

TouchDesigner 中的节点与术语映射

下面概述 glTF 文件中的元素如何映射到 TouchDesigner，以及反向的映射。作为起点，请参阅这篇关于 Basic Structure of glTF 的文章。

  • Scene：场景是根 COMP，导入时它是 glTF In COMP，使用 Internal Network 模式导出时它是 glTF Out COMP。
  • Node：节点由 Geometry COMP（用于一般变换节点）或 Null COMP（用于骨骼/关节节点）表示。不过，如果该节点不是骨骼/关节节点且只包含一个 Camera 或一个 Light，它会被合并为单个 Camera COMP 或 Light COMP。
  • Camera：摄像机由 Camera COMP 表示。
  • Light：灯光（参见：KHR_lights_punctual）由 Light COMP 表示。
  • Mesh：网格由 POP 表示。在导入侧它具体是 Import Select POP，但在导出侧可以是任意 POP。
  • Skin：蒙皮由 Skin Deform POP 表示。Skin Deform POP 使用该 POP（即网格）的 BonePath、BoneBindPoses、BoneIndices 和 BoneWeights 属性。
  • Morph Targets：变形目标（即 Blend Shape）由 POP 表示，但更具体地说，它是 Blend POP 的任意 > 0 的输入（即不含第一个输入）。变形目标/Blend Shape 在导入时总是通过 Import Select POP 完成，但导出时可以是任意 POP，前提是它遵循上述规则，即作为 Blend POP 的输入。
  • Animation：动画是一个 CHOP，它导出到变换或混合权重参数值。在导入侧，动画总是通过 Import Select CHOP 完成，但导出时可以是任意通用 CHOP。
  • Material：材质由 PBR MAT 表示。
  • Texture：纹理由 TOP 表示。在导入侧，纹理总是 Import Select TOP，但导出时可以是任意 TOP，前提是它被 PBR MAT 使用并引用。导入时，所有纹理/TOP 都包含在 touchTextures COMP 中。
