右键菜单

RMB Menu 或 Context Menu 是在 Operator 上点击鼠标右键时出现的菜单。

见 Mouse Click。

常用选项

  • Parameters
    • Reset to Defaults
  • Viewer
  • Edit Comment
  • Create Movie
  • Explore Media Folder
  • Change OP Type
  • Select Inputs
    • Outputs
  • Force Cook
  • Delete

COMP 专用选项

  • Open Control Panel...
    • Native Size...
    • Borderless...
    • Edit Mode...
  • Save Component
    • with Media...
  • 显示选项

TOP 专用选项

  • Save Image...

CHOP 专用选项

  • CHOP Exporter...
  • Information...
  • Save CHOP Channels...
  • Edit Keyframes...
  • Play Audio Sample

SOP 专用选项

  • Spreadsheet...
  • Save Geometry...
  • Model Geometry...
  • Display Parameters...

DAT 专用选项

  • Save Contents...
  • Edit Contents...
  • Run Script...
  • Toggle Data Format...
