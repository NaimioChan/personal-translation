根

TouchDesigner 是组件的层级结构。「Root」是层级中最顶层的网络。根目录的 Network Path 或路径就是 /。典型的路径是 /project1/moviein1。

通常你在 / 下的组件中工作，例如 /project1 中，但你可以把任意内容放在 / 中。

Root 还包含 /local，其中有 MIDI 设置、Layout、可从任何位置访问的 python 模块，以及 Variables。/local 会原样保存在 .toe 文件中，并在重新启动时从 .toe 重新载入。/local 的部分内容通过 MIDI mapper 等对话框控制，但由于 /local 中有很多是文本文件和表格，大多数内容都可以由用户手动编辑。

通常放在 Root 中的其他内容：

  • 启动脚本（使用 Execute DAT）
  • 用于管理到显示器的输出的 Window Components
  • 如果需要，用于从单一位置输出到音频设备的 Audio Device Out CHOPs。
  • 你希望项目中各部分都能访问的常用库、组件和脚本。

Root 实际上是一个 Base COMP。看看你能否找到显示其参数对话框的方法！至少有两种方式。

因此，最好将大部分工作放在 /project1 这样的组件中进行，这样组件可以通过 RMB→Save Component... 导出和分享。

在 Root 中通常有 /perform，它是一个 Window Component。它绑定到 Window Placement Dialog，是用于 Perform Mode 的默认 Window Component。

/ui 和 /sys 不会保存在 .toe 中。它们会在 TouchDesigner 启动时重新载入。你可以查看 /ui 和 /sys 内部，但修改它们没有太大用处。
