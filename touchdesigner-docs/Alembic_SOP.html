Alembic SOP

摘要

Alembic SOP 加载并播放 Alembic 文件几何序列。

几何支持的 Alembic 图元有 polymesh、curves 和 points。此外，也支持 Alembic 变换。

对于包含动画的 Alembic 文件，使用 Time 参数，并注意 Unit 菜单，可用帧、秒或任意你喜欢的单位来控制它。

一个 Alembic 归档可包含一个或多个几何体的对象路径。可以一次查看所有这些对象，也可以用 'Object Path' 参数菜单分别选择它们。

Alembic 文件 schema 中的每个对象都可以拥有标准属性或自定义属性。标准属性是法线（N）、速度（V）和纹理坐标（UV）。 多个自定义属性可以存在于一个 Alembic schema 中，名称和类型更灵活。自定义属性类型可以是以下任意一种：

  • 浮点数组
  • 整数数组
  • 浮点数的 2d 或 3d 向量
  • 含 16 个浮点元素的矩阵

Alembic 几何作用域与 TouchDesigner 属性类型之间的转换如下表所示：

Alembic Scope TouchDesigner Attribute
Varying, Vertex Point
Facevarying Vertex
Uniform, Constant Primitive

Alembic SOP 可将几何体加载到 CPU 或 GPU。 虽然使用 GPU 快得多，但有一些限制：

  • 在 GPU direct 模式下，无法在下游连接其他 SOP。
  • 在 GPU direct 模式下，当有多个对象且它们拥有不同的属性集时，每个对象缺失的属性会使用默认值。例如，如果一个几何体有法线数据而另一个没有，那么缺失法线属性的几何体其法线向量的 x、y、z 分量将分别设为 0、0、1。

参数 - 页

Alembic File file - Alembic 文件的文件路径。
Object Path objectpath - 指定要加载哪个几何对象。每个几何对象可以表示多个几何体的层级。也可以从可用对象列表中选择「All Objects」选项。该选项默认被选中。
Time time - 指定加载 Alembic 采样序列的哪一部分。时间单位菜单会将当前时间单位换算为所选单位。可用选项为 Frames、Seconds 和 Fraction。
Time Unit timeunit -
Transform xform - - 如果输入 Alembic 文件中有可用的变换数据，选择应用哪个变换。
  • None none - 不对几何应用任何变换，它们位于原点。
  • Static Local Transformation transform - 为 Object Path 中所选的几何对象应用静态局部变换。
  • Static World Transformation transform - 为 Object Path 中所选的几何对象应用静态世界变换，直至其父级变换。
  • Dynamic Transformation transform - 当 Alembic 文件包含动态或动画几何体时，变换会应用到所选几何体。此选项会为给定几何体同时执行局部和世界变换（如果可用）。
Interpolation interp - - 在 Alembic 文件的采样/关键帧之间插值。此参数仅在所选几何定义为动态且输入 Alembic 文件中有可用变换信息时有效。
  • None none - 不在各采样之间进行插值。
  • Smooth Interpolation interpT - 计算每两个采样之间的平滑插值。
Straight to GPU straightgpu - 直接将几何体加载到 GPU。此选项比默认加载到 CPU 快得多，但无法将几何输出到其他 SOP，也无法在 SOP to CHOP 或 SOP to DAT 中访问几何数据。建议在 Alembic 文件中预先烘焙好法线和 UV，因为在 TouchDesigner 中无法通过 SOP 添加它们。
Compute Normal compnml - 为输入几何体创建法线。
Unload loadfile - 将 unload 切换为「on」将卸载并关闭文件。将其设为「off」，文件将重新加载。文件卸载后，可以被其他应用程序覆盖或删除。

Info CHOP 通道

Alembic SOP 的额外信息可通过 Info CHOP 查看。

Alembic SOP 专用信息通道

  • start_time -
  • end_time -

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
