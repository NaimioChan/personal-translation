DMX Map DAT

摘要

DMX Map DAT 引用一个 DMX Out POP 或一个 DMX Fixture POP，并以表格格式输出它们的 DMX universe。DMX Map DAT 可用于可视化 DMX universe 布局，对于 DMX Out POP，它还有助于调试 DMX Fixture POP 之间的通道冲突。

dmxmapDAT_Class

参数 - DMX Map 页

Active active - 启用时，DAT 会获取最新的 DMX universe 数据。禁用时，会保持最后一个 universe 状态。
Update Value updateval - 启用时，value 列会更新为最新值。禁用时，它会保持最后一个值，除非 universe 中发生了会重新排列通道的变化。
Update Value Pulse updatevalpulse - 脉冲时，会抓取最新值的更新。
DMX Fixture/Out POP dmxpop - 要从中获取 DMX universe 数据的 DMX Fixture POP 或 DMX Out POP。
Net Filter netfilter - 按 net 值过滤表格的字符串模式。参见 Pattern Matching。
Subnet Filter subnetfilter - 按 subnet 值过滤表格的字符串模式。参见 Pattern Matching。
Universe Filter universefilter - 按 universe 值过滤表格的字符串模式。参见 Pattern Matching。
Network Address Filter netaddressfilter - 按 netaddress 值过滤表格的字符串模式。参见 Pattern Matching。
Exclude Unused Channels excludeunused - 禁用时，每个 DMX universe 的全部 512 个通道都会输出到表格。启用时，只有由 POP 设置了值的通道才会包含在输出中。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。
