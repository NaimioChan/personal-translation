Dependency 类

Dependency 对象是一种值，当依赖值发生变化时，会自动使任何引用它的表达式更新。这些对象免去了手动强制计算操作符的需要，例如引用 Extensions 或 Storage 中值的操作符。 关于可变对象（列表、字典、集合）中依赖的信息，请参见 Deeply Dependable Collections

实例化器

TDU.Dependency(val = None)→ TDU.Dependency:

创建新的依赖对象。

  • val - 存储在依赖对象中的起始值。可以是任何 Python 对象。

成员

val → Any :

与此对象关联的值。在表达式中引用此值会使操作符依赖于它的值。设置此值会使那些操作符按需重新计算。

peekVal → Any (Read Only):

返回与 .val 相同的值，但不会对该值建立依赖。

callbacks → list :

可修改的函数列表。当 Dependency 对象被修改时，会调用列表中的每个函数。每个函数调用时传入一个参数，该参数是包含以下内容的字典：

  • 'dependency' - 被修改的 Dependency。
  • 'prevVal' - 先前值（如果可用）。
  • 'callback' - 此回调函数。

ops → list (Read Only):

当前依赖于此对象的 operators 列表。

listAttributes → list (Read Only):

当前依赖于此对象的 list attributes 列表。

方法

modified()→ None:

当更改的不是值本身而是某个子组件时，需要调用此方法。例如，如果 Dependency.val 是字典，设置其中任何成员都不会通知依赖的操作符，必须调用 modified。

setVal(val, setInfo=None)→ None:

设置值，并可附带可选信息。

  • val - 要设置的新值。
  • setInfo (Keyword, Optional) - 传递给 modified 回调的可选信息。

[<index or key>]→ collection value:

Only when the dependency wraps iterable or mapped data such as a list or dictionary，可以使用 [] 访问被包装数据中的条目。

dep = TDU.Dependency({'fred': 33, 'wilma':39})
print(dep['fred']) # 打印 "33"。字典的键可直接作用于 dependency 对象。
dep2 = TDU.Dependency(["a", "d", "g"])
print(dep[2]) # 打印 "g"。列表的索引可直接作用于 dependency 对象。

用法

例如，考虑以下模块，它作为 extension 用在名为 comp1 的组件中

class MyClass:
	def __init__(self):
		self.Scale = 5

任何引用 Scale 的表达式在 Scale 被手动更改时都不会更新。例如，如果这些表达式之一位于 Constant CHOP 的 value 字段中，那么当 Scale 的值更新时它不会更新。

示例： 

# 使用非提升（non-promoted）扩展
op('comp1').ext.MyClass.Scale

# 使用提升（promoted）扩展
op('comp1').Scale

如果你需要引用动态更新，可以创建一个 Dependency。首先如下定义一个 TDU.Dependency：

class MyClass:
	def __init__(self):
		self.Scale = TDU.Dependency(5)

现在，Scale 值与引用它的操作符之间建立了计算依赖。引用该值有两种方式。第一种与我们之前引用该值的方式类似：

# 使用非提升（non-promoted）扩展
op('comp1').ext.MyClass.Scale

# 使用提升（promoted）扩展
op('comp1').Scale

另一种方法是显式调用 Scale 的 val：

# 用于非提升扩展
op('comp1').ext.MyClass.Scale.val

# 用于提升（promoted）扩展
op('comp1').Scale.val

注意通常不需要 .val，因为在大多数情况下 Dependency 对象会自动转换为其底层值。

要更新此值，必须引用该成员的 val。Dependency 值本身是一种类型，写成下面的表达式实际上会用普通整数覆盖 Dependency 的值，并移除引用中的计算依赖：

# 更新提升扩展依赖的错误方式
op('comp1').Scale = 5

你应该改为将值赋给 Dependency 的 val，如下所示：

# 更新提升扩展依赖的正确方式
op('comp1').Scale.val = 5

使用此方法会在更新 Scale 的值的同时保持 Dependency 不变。

字典、列表、集合以及其他内容可变的对象称为「可变」（mutable）对象。If the contents of a mutable object changes, a dependency wrapping it does not automatically register as being modified! 你必须使用 deeply dependable collection，或如下例所示手动调用 .modified() 函数：

op('comp1').Scale.val = [1,2,3]
op('comp1').Scale.val[1] = 15 # 仅更改内容不会更新依赖！
op('comp1').Scale.modified() # 此次调用通知 TouchDesigner 该值已更改

可以创建在依赖对象变化时被调用的 Python 回调：

op('comp1').Scale.callbacks = [print]

# 添加函数需要先取出列表、修改，然后再重新设回
def prevPrint(info):
	print(f'Previous value: {info['prevVal']})
    
callbacks = op('comp1').Scale.callbacks
callbacks.append(prevPrint)
op('comp1').Scale.callbacks = callbacks

# 移除回调的做法类似
callbacks = op('comp1').Scale.callbacks
callbacks.remove(print)
op('comp1').Scale.callbacks = callbacks
