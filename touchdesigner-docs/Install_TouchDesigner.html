安装 TouchDesigner

如何安装 TouchDesigner

下载

从 here 下载最新版本的 TouchDesigner

另外，如果你需要特定版本的 TouchDesigner，可以在 Official Downloads page 上找到存档版本。

Windows

Installer Versions for Windows

Windows 上有 2 种安装程序版本：完整安装程序和 Web 安装程序。Web 安装程序体积小得多，只包含最少的文件，并可在安装过程中或之后选择安装功能支持。我们建议使用 Web 安装程序，以获得更快的安装过程。完整安装程序包含用于 Kinect、RealSense 和 openCV 等特定设备的大型模型和库。

如果在安装过程中选择了额外的 Installer Components，Web 安装程序需要联网。

双击 TouchDesigner.xxxx.xxxxx.exe 文件，按照安装程序对话框中的说明操作。请确保以管理员账户进行安装。

macOS

双击 TouchDesigner.xxxx.xxxxx.dmg 文件，然后将 TouchDesigner 图标拖到你的 Applications 文件夹。

Please make sure you are installing from an Administrator account.

密钥设置

首次打开 TouchDesigner 时，Key Manager Dialog 会引导你完成安装许可证的过程。

如何安装 TouchPlayer

Windows

Windows 上的 TouchDesigner 安装程序包含 TouchPlayer。要安装 TouchPlayer，使用 TouchDesigner 安装程序并选择 Custom Install and TouchPlayer Options（详见下文）。点击 Install 后会出现安装 TouchPlayer 的选项。

macOS

在 macOS 上，TouchPlayer 是单独的安装程序，可从 Official Downloads page 下载。

Windows 上的安装程序选项

Custom Install and TouchPlayer options

使用此复选框，在点击「Next」后会提供更多选项，例如

  • 为此安装指定自定义标记以便识别。此名称会用于桌面图标，并作为附加标识出现在所有操作系统引用中，例如「Open With...」菜单和「Add or remove program」对话框。
  • 显示或隐藏桌面图标
  • 自定义与 TouchDesigner 的文件关联
  • TouchPlayer 选项
    • 包含 TouchPlayer 桌面图标
    • 在 Open With... 菜单中包含 TouchPlayer
    • 将 TouchPlayer 设为 .toe 文件（TouchDesigner 文件）的默认应用程序

Install Runtime for Dongle Licensing

勾选此框以包含 CodeMeter 服务的安装，使用 License Dongle 运行 TouchDesigner 需要该服务

处理 Web 安装程序的 Installer Components

使用 Windows 的 Web 安装程序时，在选择安装文件夹或设置额外选项后，会出现一个 Installer Components 选择对话框。这些文件与某些功能（或设备支持）相关，我们认定它们占安装程序文件大小的很大一部分，但大多数用户并不经常使用。

该对话框让你选择安装程序在安装过程中应下载哪些功能。标题后的体积是该功能安装后占用硬盘空间的估计值。

之前已安装的 Installer Components 会被预先选中。

在此过程中选择任何 Installer Components 都需要有效的网络连接。

所选 Installer Component 文件的下载位置

安装程序会把选中的组件文件下载到硬盘上的 %USERPROFILE%\Documents\Derivative\InstallerCache 文件夹。

在开始下载前，安装程序会检查所需文件是否已存在于该文件夹中。

删除已下载的 Installer Component 文件

安装流程的最后一个对话框有一个复选框，用于删除已下载的文件。它只会删除安装过程中下载的文件。 另外，你也可以删除 %USERPROFILE%\Documents\Derivative\InstallerCache 中的任何 *.zip 文件。

在初次安装后添加 Installer Components

要向之前安装的版本添加 Installer Components，请打开 Windows 的「Installed Apps」对话框，在要修改的 TouchDesigner 安装项右侧下拉菜单中选择「Modify」。

在打开的对话框中选择要添加的 Installer Components。

注意： 你无法删除 Installer Components。

同时安装多个版本

有时你会希望同时安装多个版本的 TouchDesigner 或 TouchPlayer。你可能需要旧版本来测试之前的项目，或者想尝试 Experimental 中的最新功能，同时保留 Official 以用于当前项目。

Windows

当安装程序检测到系统中已安装 TouchDesigner 时，会提供一些管理多个版本的选项

Install Parallel Build

此选项会在已安装的任何版本之外安装新版本，而不移除你当前的 TouchDesigner 版本。你还可以在下一页的 Custom Install and TouchPlayer options 下使用新的「custom tag」功能以便更容易识别，例如使用类似 Official、Experimental 或 ProjectName 的标记名称。

Replace currently installed build

此选项会用新版本替换你当前已安装的版本。如果你已安装多个版本，会显示一个列表，让你选择要替换的具体版本。

macOS

  • 将应用拖到任何方便的位置即可。如果它与那里已有的另一个 TouchDesigner 版本冲突，请在弹出对话框中选择「Keep Both」。为了更有条理，你可以重命名应用文件以包含版本号。
  • 右键点击任意 TouchDesigner 文件并选择「Open With」会显示计算机上所有 TouchDesigner 版本的列表，选择你要使用的那个即可。

Windows 系统上有用的安装程序命令行开关

安装程序可与多种命令行开关一起使用：

  • /SILENT、/VERYSILENT指示安装程序静默或非常静默运行。静默时，不显示向导和背景窗口，但显示安装进度窗口。非常静默时，连此安装进度窗口也不显示。其他一切照常，例如安装期间的错误消息会显示，启动提示也会（如果你未使用 DisableStartupPrompt 或「/SP-」命令行禁用它）。
  • /DIR="x:\dirname"覆盖「Select Destination Location」向导页上显示的默认目录名。必须指定完整路径名。可包含「expand:」前缀，指示安装程序展开名称中的任何常量。例如：'/DIR=expand:{autopf}\My Program'。
  • /LOG="folder\filename"让安装程序在指定目录中创建日志文件，详细记录文件安装以及安装过程中执行的 [Run] 操作。这对调试很有帮助。例如，如果你怀疑某个文件在应该被替换时没有被替换（或相反），日志文件会告诉你该文件是否真的被跳过以及原因。日志文件中的信息本质上是技术性的，因此并非为终端用户所理解而设计。它也不是为机器解析而设计的；文件格式可能随时更改，恕不另行通知。注意： 需要日志文件预期位置的完整路径。
  • /Extract会将安装中的所有相关文件解压到一个文件夹。配合 /DIR 可以指定目标文件夹。如果安装过程因某些未知原因失败，这会很有用。在解压出的文件夹结构中，TouchDesigner.exe 可执行文件位于 bin 文件夹中。
  • /Codemeter将选择在安装 TouchDesigner 的同时安装 Codemeter 运行时。
  • /Tag="My Tag"允许指定自定义标记，以便更容易识别并行安装。
  • /TDDesktopIcon=false不会在桌面放置 TouchDesigner 应用程序快捷方式。
  • /TDOpenWith=false不会将 TouchDesigner 加入受支持文件类型的「Open With...」上下文菜单。
  • /TPDesktopIcon会将 TouchPlayer 的应用程序快捷方式添加到桌面。
  • /TPOpenWith会将 TouchPlayer 加入受支持文件类型的「Open With...」上下文菜单。
  • /TPIsDefault会将 TouchPlayer 设为 .toe 文件的默认应用程序。


命令行开关的完整列表，请参阅此文章：https://jrsoftware.org/ishelp/index.php?topic=setupcmdline

Windows 操作系统上安装期间的问题

安装程序在安装期间退出或报错中止

当安装程序在安装期间退出且未给出充分理由时，以管理员权限打开 Windows 命令提示符窗口并运行：

"C:\MyFolder\TouchDesigner0xx.xxxxx.exe" /LOG="example.log"

将生成的日志文件以压缩包或链接形式发送到 Derivative Support，并附上对遇到错误的说明

注意： 如果你持续遇到安装程序的问题，可以尝试在不实际安装的情况下运行 TouchDesigner。某种程度上，安装程序只是把文件复制到磁盘并确保满足某些先决条件。所有必需文件都单独包含在安装程序中，你可以使用上述 /Extract 安装程序命令行开关尝试解压它们。

解压出的文件夹结构会包含一个 bin 文件夹，其中可以找到 TouchDesigner.exe

安装程序因对文件夹的访问权限不足而无法继续

这种情况可能发生在之前安装版本的卸载阶段。最好的解决办法是重启计算机，然后重新开始安装过程。

安装程序无法移除先前安装的 TouchDesigner 版本

在某些情况下，安装程序会因为无法卸载先前安装的 TouchDesigner 版本而退出。

Geekuninstaller（可从 here 获取）在解决安装和卸载相关问题方面效果良好。

如果错误持续存在，尝试重新安装先前安装的 TouchDesigner 版本，通过 Windows 的「Apps & features」对话框移除它，然后再次尝试安装新版本。

Windows 操作系统上安装后缺少库

为 Windows N 和 Windows KN 发行版安装缺少的库

Windows N 和 Windows KN 版本面向欧洲和韩国市场，由于反垄断法规，不包含 Windows Media Player，而运行 TouchDesigner 需要其中的部分组件。

你可以为 Windows 10 / 11 下载并安装缺少的功能 here

安装后与许可或密钥相关的问题

Windows - 许可证获取错误

在某些情况下，启动 TouchDesigner 会失败，并弹出标题为 TouchDesigner Key Retrieval Error 或 License Retrieval Error 的对话框。错误消息内容大致如下：

这可以通过重建 wmi 仓库来解决。

Please be advised though that deleting and rebuilding the repository can cause damage to the system or to installed applications.

要重建 WMI 仓库，请执行以下操作：

  1. 禁用并停止 winmgmt 服务
  2. 找到 C:\Windows\System32\wbem，并将 wbem 复制到其他位置作为备份。
  3. 重命名 C:\Windows\System32\wbem\repository 文件夹（注意：如果 winmngmt 服务仍在运行，将无法重命名该文件夹）
  4. 启用并启动 winmgmt 服务
  5. 以管理员身份打开命令提示符，运行以下命令：

cd C:\Windows\System32\wbem\ for /f %s in ('dir /b *.mof') do mofcomp %s

如果你仍有问题，请加入 support thread here。

macOS - 安装或禁用密钥时的权限错误

如果你在安装密钥时遇到 L1 Key Error（见下图），或在禁用密钥时遇到错误，请按以下说明操作。请确保你处于管理员账户。

在你的管理员账户中，打开 Terminal 并粘贴以下命令：

ls -l -d "/Library/Application Support/ca.derivative"

你应该会得到类似这样的一行返回。注意组所有者应为 admin，而不是 wheel：

drwxrwxr-x@ 10 root admin 340 17 Jan 2017 /Library/Application Support/ca.derivative

如果缺少该目录，请在 Terminal 中输入此命令：

sudo mkdir "/Library/Application Support/ca.derivative"

如果权限不匹配（第一列），请在 Terminal 中输入此命令：

sudo chmod 775 "/Library/Application Support/ca.derivative"

如果组所有者是 wheel 而不是 admin（第四列），请在 Terminal 中输入此命令：

sudo chgrp -R admin "/Library/Application Support/ca.derivative"

重启 TouchDesigner，再次尝试安装或禁用密钥。

防火墙问题

如果 Key Manager 出现连接错误，可能是防火墙阻止了对我们密钥服务器的访问。请确保防火墙允许到 www.derivative.ca 和 derivative.ca 的 443 端口 TCP 连接。

代理服务器

TouchDesigner 目前不使用你的系统可能正在使用的代理服务器配置。如果你的连接需要代理服务器，需要使用离线密钥生成方法。

卸载期间的问题

安装程序在卸载期间退出但没有报错

发生这种情况时，最佳做法是重启计算机以释放文件夹上可能存在的锁定。通常重启后剩余文件已被移除，可以开始全新安装。
