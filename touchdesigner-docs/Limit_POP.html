Limit POP

摘要

Limit POP 可对任意属性进行钳制，使其落在下限-上限范围内；也可以把超出范围的数值循环回范围内，或类似地在范围内来回折返。你可以只限制上限，或只限制下限。

如果属性是多分量的（例如 Color 有 4 个分量），默认所有分量以相同方式应用限制。但如果你把 Parameter Size 改为例如 3，那么每个颜色分量都有一组参数。于是 R、G、B 可以有不同的 Limit Type 以及不同的最小/最大范围。

其中一些功能在 Math Mix POP 和 Math Combine POP 中也可以用 min(A)、max(A)、loop()、zigzag() 和 clamp() 函数实现。

随后可以把数值全部变为正值，再把这些最终值转换为整数属性（int、unsigned int）。

提示：如果你只想处理红、蓝两个颜色分量，把 Unput Attribute Scope 设为 Color(0) Color(2) 或 Color.rb，并将 Parameter Size 设为 2 以便独立控制。

另请参阅 Quantize POP、Math Mix POP、Math Combine POP

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
