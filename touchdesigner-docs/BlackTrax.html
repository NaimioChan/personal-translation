BlackTrax

BlackTrax 是由 CAST Software 开发的基于视觉的实时跟踪系统，专长于大型演出。BlackTrax Beacon（「BTBeacons」）附着在表演者或刚性物体上，BlackTrax 系统可精确跟踪 Beacon 的位置、旋转、速度和加速度。

使用 BlackTrax 的大型演出示例包括 Cirque du Soleil 的 Toruk - The First Flight、The Weekend 的 Starboy World Tour，以及 Mattia Diomedi's "V"。

BlackTrax Beacon 的数据可用于驱动视觉输出，例如投影映射或演出灯光（如聚光灯）。在 Mattia Diomedi 的「V」（用 TouchDesigner 构建）中，BlackTrax 被用于将表演者的动作与精美的视觉效果无缝配对。Beacon 附着在 2 位表演者的手上，他们的动作影响 LED 屏幕背景和 2 台投影仪的输出。

关于「V」的更详细说明，请参阅我们的 Blog article。

另见：BlackTrax Showcase。

BlackTrax 跟踪数据可以使用 BlackTrax CHOP 引入 TouchDesigner。

工作原理

BlackTrax 可高精度跟踪多达 255 个 Tracking Point（LED）或 85 个 Beacon；每个 Beacon 最多可有 3 个 LED。在 50 英尺距离下精度为 1/4 英寸，可跟踪乒乓球，精度达 7mm。跟踪速度为每秒 100 帧，标准 BlackTrax 方案的距离为 50 英尺，升级套餐可提升至 700 英尺。

Beacon 和 LED 通过 BlackTrax 摄像机进行跟踪。这些摄像机从 Beacon 和 LED 获取位置数据（平移、旋转），随后进行处理并发送到任何第三方系统（例如 TouchDesigner）。

更多信息请参阅 BlackTrax FAQ 或 How BlackTrax Works

应用

BlackTrax 在投影映射中有多种应用。要将影像投影映射到可移动物体上，请将 BlackTrax Beacon 附着到该物体，这样无论它在投影仪 FOV 中的哪个位置，都能利用来自 beacon 的位置和旋转数据精确映射。在 TouchDesigner 中，可以通过 BlackTrax CHOP 以及 TouchDesigner 的投影映射工具之一，即 CamSchnappr 或 Kantan Mapper 来实现。

BlackTrax 是跟踪表演者的绝佳选择。通过将 Beacon 附着到表演者身上，可以高精度地跟踪他们的动作，而将这些数据用于 TouchDesigner 后，可能性无穷。如需灵感，请参阅 Mattia Diomedi's "V" 或 BlackTrax Showcase
