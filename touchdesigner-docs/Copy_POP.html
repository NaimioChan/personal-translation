Copy POP

摘要

Copy POP 使用两种方式复制其输入：(1) Number of Copies 参数指定复制数量，并对每个副本应用变换；(2) 第二个输入 Template POP，在每个模板点处放置一个副本。

对于 (1) 中的每个副本，变换是累积的，也就是说，变换会应用到前一个副本的变换上，而第一个副本不应用变换。

完成 (1) 之后，再对结果应用 (2)。

Template 页选择使用模板的哪些属性来为每个“每模板点”副本定义变换。

Template Attributes 页决定向输出添加哪些属性，以及这些属性如何由第一个输入和模板输入组合而成（相乘或相加）。

如果副本数量大于 1，第一个输入的维度会增加一维，而维度数会按第二个（模板）输入的维度增加。参见 Dimension。

另请参阅：GLSL Copy POP、POP Rotations

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
