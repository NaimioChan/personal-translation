ParGroupPulse 类

ParGroupPulse 类描述以脉冲参数结尾的 ParGroup 子类。另请参阅 Custom ParGroup。

注意： ParGroupPulse 类将在未来的 TouchDesigner 版本中弃用。建议直接访问脉冲参数，而不是通过此对象。

成员

没有该操作符专属的成员。

方法

pulse(value, frames=0, seconds=0)→ None:

脉冲会将参数设为指定值，计算该操作符，然后将参数恢复为之前的值。

对于脉冲类型参数，不指定也不使用值或时间。

  • value - （可选）用于脉冲此 parGroup 的元组，默认为 [1]。
  • frames - （可选）在将参数恢复为原始值之前经过的帧数。
  • seconds - （可选）在将参数恢复为原始值之前经过的秒数。
op('moviein1').parGroup.reload.pulse([1]) # 设置 reload 开关，然后 cook
op('glsl1').parGroup.loadvariablenames.pulse() # 激活 pulse 参数
op('geo1').parGroup.t.pulse([0,2,0], frames=120) # 对 geometry 的 transform 参数 pulse 120 帧
op('text1').parGroup.text.pulse(['GO!'], seconds=3) # 将 text TOP 的字符串字段 pulse 3 秒
op('noise').parGroup.type.pulse(['random'], seconds=0.5) # 对 noise 的 menu 类型参数 pulse 半秒
