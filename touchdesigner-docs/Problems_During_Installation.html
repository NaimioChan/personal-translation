安装过程中的问题

Windows 操作系统上安装期间的问题

安装程序在安装期间退出或报错中止

当安装程序在安装期间退出且未给出充分理由时，以管理员权限打开 Windows 命令提示符窗口并运行：

"C:\MyFolder\TouchDesigner0xx.xxxxx.exe" /LOG="example.log"

将生成的日志文件以压缩包或链接形式发送到 Derivative Support，并附上对遇到错误的说明

注意： 如果你持续遇到安装程序的问题，可以尝试在不实际安装的情况下运行 TouchDesigner。某种程度上，安装程序只是把文件复制到磁盘并确保满足某些先决条件。所有必需文件都单独包含在安装程序中，你可以使用上述 /Extract 安装程序命令行开关尝试解压它们。

解压出的文件夹结构会包含一个 bin 文件夹，其中可以找到 TouchDesigner.exe

安装程序因对文件夹的访问权限不足而无法继续

这种情况可能发生在之前安装版本的卸载阶段。最好的解决办法是重启计算机，然后重新开始安装过程。

安装程序无法移除先前安装的 TouchDesigner 版本

在某些情况下，安装程序会因为无法卸载先前安装的 TouchDesigner 版本而退出。

Geekuninstaller（可从 here 获取）在解决安装和卸载相关问题方面效果良好。

如果错误持续存在，尝试重新安装先前安装的 TouchDesigner 版本，通过 Windows 的「Apps & features」对话框移除它，然后再次尝试安装新版本。
