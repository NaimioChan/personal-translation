面板值

Panel Values 保存 Panel Components 的当前状态。面板值会根据用户与控制面板的交互而变化。

可通过 4 种方式访问面板值：

  • 在面板组件上中键点击调出其信息框，即可查看面板值。注意，字符串值以及那些 instant 的值（先设为 X 再回到 0 或空）不会显示在 Panel CHOP 上。这些值在下面标记为 string 和 instant。
  • Panel CHOP 用于查看和访问组件的所有面板值。
  • Python 中的 PanelValue Class 访问 Python 值与状态；在 TScript 中，panel() 表达式返回面板值。
  • Panel Execute DAT 会在面板值变化时运行脚本。

面板值会在以下情况改变：

  • 用户与面板交互时。
  • 使用 Python 的 click() 调用虚拟点击面板时。见 ButtonCOMP Class、SliderCOMP Class、ContainerCOMP Class
  • 在 Tscript 中使用 click 命令或 Tscript 的 controlpanel 命令时。

通用面板值

下面的列表简要说明所有面板值。某些值对某些面板类型没有效果，下面会说明。

  • select → int - 在面板上按下鼠标左键、中键或右键时为 1。
  • lselect → int - 按下鼠标左键时为 1。
  • mselect → int - 按下鼠标中键时为 1。
  • rselect → int - 按下鼠标右键时为 1。
  • reposition → int - 组件被重新定位时为 1。
  • resize → int - 组件被调整大小时为 1。
  • dragout → int - 在控件内点击、拖出控件并松开时，若在控件外松开，会从 0 变为 1。每次在控件内点击时会被设为 0。
  • ldragout → int - 与 dragout 相同，但仅在使用鼠标左键时。
  • mdragout → int - 与 dragout 相同，但仅在使用鼠标中键时。
  • rdragout → int - 与 dragout 相同，但仅在使用鼠标右键时。
  • ctrl → int - 点击面板时若按住 Ctrl 键则为 1。
  • alt → int - 点击面板时若按住 Alt 键则为 1。
  • shift → int - 点击面板时若按住 Shift 键则为 1。
  • cmd → int - 点击面板时若按住 Cmd 键则为 1（仅 OSX）。
  • u, v → float - 对应光标的 x 和 y 位置。每当在面板上按下任何鼠标按键时更新。
  • trueu, truev → float - 在所有面板中都有。默认与 u 和 v 相同。处于 Relative UV 模式时，它们的行为仍与非 Relative UV 模式时相同（不会进入相对模式）。
  • rollu, rollv → float - 在控件上滚动时给出光标的 u 和 v 位置。
  • dragrollover → int - 当可拖放的内容被拖到其上时从 0 切换到 1。面板必须允许放置，此项才会启用。
  • dragrollu, dragrollv → float - 拖动并在控件上滚动时，给出光标的 u 和 v 位置。面板必须允许放置，此项才会启用。
  • rollover → int - 当光标位于面板上且该面板是最前元素时为 1。注意：这与 inside 值不同，后者不需要位于前景。
  • inside → int - 光标位于面板上任意位置时为 1。
  • insideu, insidev → float - 在控件上滚动时给出光标的 u 和 v 位置。
  • children → int - 控件内网络中的组件数量（不包含子级的子级）。
  • display → int - 面板 display 参数的当前值。注意：此值只读。
  • enable → int - 面板已启用则为 1，否则为 0。注意：此值只读。
  • key → int - 光标位于此控件上时最近按下的键，随后是 0。'a' 键的值为 97，即其 ASCII 值。当你按下 'a'，并针对面板值 key 触发 Panel Execute 时，会得到 2 次调用，一次 .val 为 97，一次为 0。
  • focusselect → int - 若你最后一次点击发生在此面板中则为 1，否则为 0。它跟踪焦点层级，焦点由鼠标点击（左/中/右键均可）设置。若点击了某个面板，它及其父级层级中所有面板的 focusselect 值都会设为 1。若点击了另一个面板，两个面板共同祖先的 focusselect 保持不变，第一个面板及其未被共享的祖先值设为 0，新面板及未设置的祖先值设为 1。注意：此值只读，请使用 PanelCOMP 方法 setFocus 来更改面板焦点。
  • click → int - 统计间隔不超过 .6 秒的连续点击次数。
  • winopen → int - 面板作为浮动窗口打开时为 1，否则为 0。
  • wheel → int - （瞬时）使用鼠标滚轮时，发出一个正数或负数的脉冲，然后回到 0。
  • screenw, screenh → int - 更新为面板最近的窗口大小。Node Viewers 不影响此值。可在 TOP 的表达式中使用这些值，使其以特定分辨率渲染。请谨慎使用，多个查看器会相互冲突。
  • screenwm, screenhm → int - Screen Width Margin 和 Screen Height Margin 面板值会在考虑边距后给出面板的屏幕坐标。
  • drag → int - 面板当前正被拖动时为 1。
  • drop → int - 面板被放下时为 1。
  • scrollu, scrollv → float - 获取或设置面板的归一化（0-1）滚动位置。

仅 Slider 的面板值

  • stateu, statev → float - （可能已过时，请使用 u、v、trueu、truev）对应光标的 x 和 y 位置。每当在滑块面板上按下任何鼠标按键时更新。stateu/statev 与 u/v 的区别在于，前者会使用 Slider 的「Slider Page」参数（Zone、Range、Clamp 等）来确定 stateu/statev 的结果。

仅 Button 和 Table 的面板值

  • state → int - （仅按钮）对于瞬态或开关按钮，在面板上进行任何鼠标点击时，值在 on=1/off=0 之间切换。对于 Slider，当滑块类型为 'Slider U' 时该值匹配 stateu，为 'Slider V' 时匹配 statev。对 'Slider UV' 类型，state 不起作用。
  • lstate → int - （仅按钮）在面板上左键点击时，值在 on=1/off=0 之间切换。
  • mstate → int - （仅按钮）在面板上中键点击时，值在 on=1/off=0 之间切换。
  • rstate → int - （仅按钮）在面板上右键点击时，值在 on=1/off=0 之间切换。
  • picked → int - （仅按钮）picked 面板值与按住 Shift 或 Ctrl 点击按钮组件配合工作。当按住 Shift 或 Ctrl 点击多个瞬态按钮时，最后一个被点击的按钮会保持 state 面板值，而其他所有按钮的 state 面板值会设为 1。这正是 picked 面板值发挥作用之处，因为它会保持为 1，直到你点击选中单个按钮。

仅 Radio 和 Exclusive 按钮的面板值

  • radio → int - 通过任何鼠标点击选中的单选/互斥按钮的索引。索引从 0 开始，单选按钮按字母数字顺序排序。使用互斥按钮类型时，连续点击同一个按钮两次后，值 -1 表示没有选中任何按钮。
  • lradio → int - 通过左键点击选中的单选/互斥按钮的索引。
  • mradio → int - 通过中键点击选中的单选/互斥按钮的索引。
  • rradio → int - 通过右键点击选中的单选/互斥按钮的索引。
  • radioname → str - 返回 radio 变量中所选按钮的名称（字符串）。可在表达式或函数中使用。
  • lradioname → str - 返回 lradio 值中所选按钮的名称（字符串）。可在表达式或函数中使用。
  • mradioname → str - 返回 mradio 值中所选按钮的名称（字符串）。可在表达式或函数中使用。
  • rradioname → str - 返回 rradio 值中所选按钮的名称（字符串）。可在表达式或函数中使用。

仅 Field 的面板值

  • key → int - （瞬时）在键盘上按下某键时，此值被设为该键的 ASCII 码，随后立即变为 0。要监视没有 ASCII 值的按键，请使用 Keyboard In DAT。
  • invalidkey → int - （瞬时）按下无效按键时会发出脉冲。例如，在设为 numeric 的字段上按下 alphanumeric 键 'a'，此时 invalidkey 面板值会先脉冲到 97 再回到 0。
  • focus → int - 点击字段时会设置 focus。当 focus 为 1 时，若字段可编辑，就可以输入。
  • field → str - （字符串）字段当前保存的值。
  • fieldediting → str - （字符串）字段在编辑过程中的内容。

仅 Table 的面板值

单元格 ID 是数值，从第一个已定义的单元格开始为 0。

  • celloverid → int - 光标所在的单元格 ID。光标不在任何单元格上时为 -1。
  • cellfocusid → int - 当前正在编辑的单元格 ID。没有单元格正在编辑时为 -1。
  • cellselectid → int - 当前正被按下的单元格 ID。没有单元格正被按下时为 -1。
  • celllselectid → int - 当前正被鼠标左键按下的单元格 ID，否则为 -1。
  • cellmselectid → int - 当前正被鼠标中键按下的单元格 ID，否则为 -1。
  • cellrselectid → int - 当前正被鼠标右键按下的单元格 ID，否则为 -1。
  • cellradioid → int - 最后被点击的单元格 ID。松开鼠标按键后该值仍保留。
  • celldragid → int - 正被拖出的单元格 ID。
  • celldropid → int - 有内容放置其上的单元格 ID。
