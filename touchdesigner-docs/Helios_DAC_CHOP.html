Helios DAC CHOP

摘要

DEPRECATED: 请改用 Laser Device CHOP。

Helios DAC 是一款激光控制器。Helios DAC CHOP 最多接收五个通道作为输入，前 2 个通道解释为 X 和 Y（水平和垂直）位置值，接下来的 3 个通道解释为红、绿、蓝颜色值。它把数据输出到 Helios DAC。Helios DAC 设备通过 ILDA 线缆连接到激光器。之后用户就可以用 Helios DAC CHOP 控制激光器应输出的图像。Helios DAC CHOP 的应用包括显示计算机生成的形状动画或灯光秀的其他特效。

当输入的 RGB CHOP 通道全为零，或 Red Scale、Green Scale 和 Blue Scale 参数全为零时，会发生消隐（全部关闭）。

采样之间 RGB 值的大幅变化很可能在视觉上是正确的，因为激光器通常可以快速开关。

X 和 Y 的范围通常是 -1 到 +1，RGB 的范围通常是 0 到 1。

注意： Helios DAC CHOP 会监听系统上的任何设备变化，并在被触发时执行 Helios 设备重新扫描。不过，只有在所有 Helios 连接都关闭时才能触发重新扫描，也就是说所有 Helios DAC CHOP 都必须处于停用或旁路状态。若只有单个 Helios DAC CHOP 想执行 Helios 设备重新扫描，只需停用再重新激活该 CHOP。

另请参阅：EtherDream CHOP、EtherDream DAT、Laser CHOP，以及 Pattern CHOP。

参数 - Helios DAC 页

Active active - 如果关闭，Helios DAC CHOP 会停止向 Helios DAC 发送数据，并立即清空其点缓冲。可以把它等同于关闭 Helios DAC 电源。
Device device - 从此菜单中选择要控制的 Helios DAC。
Queue Time (Seconds) queuetime - 决定 Helios DAC CHOP 点缓冲的队列大小以及排空它所需的相应时间。在发送较少点时，通常把此值调小会很有用。
X Scale xscale - 允许按指定系数缩放输入的 x 值。
Y Scale yscale - 允许按指定系数缩放输入的 y 值。
Red Scale redscale - 允许按指定系数缩放输入的 r 值。
Green Scale greenscale - 允许按指定系数缩放输入的 g 值。
Blue Scale bluescale - 允许按指定系数缩放输入的 b 值。
Intensity Scale intensityscale - 允许按指定的系数缩放输入强度值（i）。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Helios DAC CHOP 的附加信息可以通过 Info CHOP 访问。

Helios DAC CHOP 特有的信息通道

  • heliosdac_queue_seconds -
  • heliosdac_points_dropped -
  • heliosdac_queue_adjusted -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
