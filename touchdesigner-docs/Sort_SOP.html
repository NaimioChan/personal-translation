Sort SOP

摘要

Sort SOP 允许你以不同方式排序点和图元。有时图元已按所需顺序排列，但点的顺序不是。可能有很多种组合。要排序顶点，请使用 Primitive SOP。

sortSOP_Class

参数 - Point 页

Point Sort ptsort - 按以下条件排序输入几何中的点：
  • No change none - 不应用排序。
  • By vertex order vtxord - 按与顶点相同的顺序排列点。
  • By x byx - 按 X 位置排序。
  • By y byy - 按 Y 位置排序。
  • By z byz - 按 Z 位置排序。
  • Reverse rev - 反转点顺序。
  • Random seed - 使用指定种子随机化点顺序，但不改变点的位置。
  • Shift shift - 按 Offset 参数指定的量移动点。
  • Proximity to Point prox - 按到指定点的邻近度排序点。
  • Along Vector vector - 沿用户定义或对象定义的向量排序点。
  • Distance to Object object - 根据到 Vector Object 参数中指定对象的距离排序点。
  • Closest Neighbour neighbour - 按次近距离重排点。较慢的 n×n 搜索。
Seed pointseed - 当 Point Sort 设为 Random 时的随机种子。
Offset pointoffset - 按 offset 行指定的量移动点顺序。
Point pointprox - 按 Proximity to Point 排序时参考的 X、Y 和 Z 坐标。

Info CHOP 通道

Sort SOP的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
