Select CHOP

摘要

Select CHOP 从任意 CHOP 网络中的其他 CHOP 选择通道并重命名。你可以从滑块、按钮等控制面板控件中选择通道。它从一个或多个 CHOP 获取通道。

它只选择你指定的通道。例如："c2 c5 c3 c3" 会得到 4 个通道，其中最后两个相同，全部按指定的顺序。

获取通道有两种方式 - 通过 CHOP 和 Channel Name 参数，或直接从连接到其输入的 CHOP 获取。使用 CHOP 和 Channel Name 参数（而非连线输入）时，所有提取与重命名选项同样适用。

选择 CHOP 与通道的方法见 Pattern Matching。

它还可以通过生成新的通道名来重命名通道。可使用的模式见 Pattern Replacement 和 Pattern Expansion。

把现有通道名改造成新名称的更多方法见 Channel Naming Patterns。

（Select CHOP 从任意 CHOP 获取通道，而 Parameter CHOP 获取任意 OP 的参数。）

另请参阅 Rename CHOP（Select CHOP 能做其中大部分事情，而且更多。）

selectCHOP_Class

参数 - Select 页

CHOP chop - 通道的源。（前提是 CHOP 没有直接连接。）
Channel Names channames - 要保留的通道名。可以使用名称模式。例如： 
 chan[1-5] *x /project1/geo1:t[xyz]

名称的顺序决定输出通道的顺序。如果某个通道被指定多次，它在输出中也会出现多次。

Rename from renamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to renameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Filter by Digits filterbydigits - 此开关启用下面两个参数，以选择名称末尾带有指定位数的通道。例如，可用它选中所有名称以数字 "1" 结尾的通道，如 tx1、ty1、tz1、rotate1 等。
Digits digits - 使用 'Filter by Digits' 时，指定要选择的通道名末尾的数字
Strip Digits stripdigits - 开启时，选中的通道名会去掉数字后输出。关闭时，选中的通道名保持不变。
Align align - - 此菜单处理多个输入 CHOP 具有不同起始或结束时间的情况。一个 CHOP 输出的所有通道共用相同的起始/结束区间，因此必须用 Align Options 处理输入：
  • Automatic auto - 若存在 Time Slice，则裁剪到当前 [Time Slice]，否则执行 Extend Min/Max。
  • Extend to Min/Max none - 找出最早的起点和最晚的终点，并使用延伸条件把所有输入延伸到该范围。（见 Extend Conditions）。
  • Stretch to Min/Max stretch - 找到最早的起点和最晚的终点，并将每个通道的起点和终点拉伸到该范围。
  • Shift to Minimum start - 找到最早的起点，并平移所有通道使其都从该索引开始。所有通道都扩展到最长通道的长度。
  • Shift to Maximum end - 找到最晚的终点，并平移所有通道使其都在该索引结束。将所有通道扩展到最长通道的长度。
  • Shift to First Interval shift1 - 将所有通道平移到第一个 CHOP 的起点，并使用第一个输入的范围对所有输入进行采样。
  • Trim to First Interval trim1 - 将所有通道裁剪到第一个 CHOP 的范围。
  • Stretch to First Interval stretch1 - 将所有通道拉伸到第一个 CHOP 的范围。
  • Trim to Smallest Interval trim - 将所有通道裁剪到最小的起始/结束区间。起点和终点值可能并非来自同一通道。
  • Stretch to Smallest Interval squash - 将所有通道拉伸到最小的起始/结束区间。起点和终点值可能并非来自同一通道。
Automatic Prefix autoprefix - 当两个通道同名时，开启此选项会把节点名（或节点的父级名等）作为前缀加到通道名上。例如，若从 /wave1/chan1 和 /wave2/chan1 中选择某个通道，关闭此选项时通道会被重命名为 chan1 和 chan2。开启后通道将被命名为 wave1:chan1 和 wave2:chan1。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

操作符输入

  • Input 0: -

Info CHOP 通道

Select CHOP 的额外信息可通过 Info CHOP 获取。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
