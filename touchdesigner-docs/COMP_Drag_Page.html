COMP 拖放页

参数 - Drag/Drop 页

请参阅 Drag-and-Drop，了解面板组件之间拖放功能的完整说明。

When Dragging This drag - - 指定此 Panel Component 是否可被拖拽。
  • Use Parent's Drag Settings dragparent - 遵循父级 Panel Component 的 Drag 设置。
  • Legacy Drag System legacy - 允许拖拽此 Panel Component。使用 Paramters Drag Script、Drop Destination Script 和 Dropped Operator 控制其行为。「Use Drag/Drop Callbacks」是更强大的新版工作流程。
  • Do Not Allow Drag dragno - 禁止拖拽此 Panel Component。
  • Use Drag/Drop Callbacks usecallbacks - 通过下方指定的自定义脚本精确指定行为。
Drag Script dragscript - 指定开始拖拽 Panel Component 时执行的脚本。请参阅 Drag and Drop 页面的 Drag Script 部分。
Drop Types droptypescript - 如果指定了拖放目标脚本，还可以添加一个 DAT 表格，列出拖放目标脚本将提供的返回类型。返回类型可以是操作符类型之一（COMP、TOP、CHOP、SOP、MAT、DAT）、channel，或受支持的文件类型。请参阅 Drag and Drop 页面的 Drop Types 部分。
Drop Destination Script dropdestscript - 指定拖拽的 Panel Component 被放下时执行的脚本。会创建一个临时网络，并将该组件（或 Dropped Component 中指定的替代操作符）复制到此网络。你可以在此网络中添加或修改操作符。请参阅 Drag and Drop 页面的 Drop Destination Script 部分。
Dropped Operator paneldragop - Dropped Component 参数是指定要放下的替代操作符最简单的方式。注意此替代操作符必须存在，否则会放下组件本身。替代项仅在放到网络或控制面板上时使用。通过拖放粘贴的文本，或通过放到桌面保存的文件，仍会使用原始项。
On Dropping Into drop - - 指定此 Panel Component 是否接受放在其上的项目。
  • Use Parent's Drop Settings dropparent - 遵循父级 Panel Component 的 Drop 设置。
  • Legacy Drop System legacy - 允许将项目放到此 Panel Component 上。使用 Paramter Drop Script 控制其行为。「Use Drag/Drop Callbacks」是更强大的新版工作流程。
  • Do Not Allow Drop dropno - 禁止将项目放到此 Panel Component 上。
  • Use Drag/Drop Callbacks usecallbacks - 通过下方指定的自定义脚本精确指定行为。
  • Fill Custom Parameter fillparm - 避免任何脚本，只需在自定义参数中填入被放下节点的路径。
Built-In Drop Options builtindrop - 通常，在节点上放下时，如果查看器未激活，会提供内置的放下选项，否则提供自定义的放下选项。关闭此选项后，两种情况都只使用自定义的放下选项。
Drop Script dropscript - 当把另一个组件或外部文件放入某个组件时，会运行该组件的 Drop Script。请参阅 Drag and Drop 页面的 Drop Scripts - Text 部分。

也可以在 drop script 字段中指定一个 Table DAT。TouchDesigner 会自动查找表格中的 2 列。第一列应指明数据类型，第二列应指明包含处理该数据类型脚本的 Text DAT。请参阅 Drag and Drop 页面的 Drop Script - Tables 部分。

Drop Parameter dropparm - 当「On Dropping Into」设为 Fill Custom Parameter 时，此参数指定要填充哪个参数。此选项与关闭「Built-In Drop Options」结合，可以快速将任何节点放到此查看器上，并用放下的路径填充自定义参数。
Drag/Drop Callbacks dragdropcallbacks - 指定哪个 DAT 保存自定义的拖放脚本。如果为空，按「Add」创建一个带默认脚本的 DAT。
