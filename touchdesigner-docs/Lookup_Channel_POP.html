Lookup Channel POP

摘要

Lookup Channel POP 最简单的形式是：取一个属性（Lookup Attribute），其值在 0-1 范围内，然后对每个点，把属性值作为索引查入 CHOP 的通道，为每个通道取一个插值后的值，并把这些值放入 POP 属性。

若索引为 0，则从 CHOP 的第一个采样取值；若索引为 1，则从 CHOP 的最后一个采样取值。若 Lookup Index Units 菜单设为 Sample Index，则查找索引可用采样编号表示，从 0 到 number_of_samples-1。

若索引超出范围，Extend Left 和 Right 菜单决定在做查找之前如何处理索引，例如将其保持在 0 或 1，或在 0 与 1 之间循环。

连续块决定取回每个通道值后如何处理——你可以先把值重映射范围，再放入指定的输出属性。

另请参阅 Lookup Texture POP、Curve POP（Lookup 页）、Lookup Attribute POP

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
