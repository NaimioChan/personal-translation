几何查看器

Geometry Viewer 让你可以在 Geometry COMP、Light COMP、Camera COMP 和所有其他 3D Node Viewers 中查看和操作 3D 对象，也可以在 Geometry Viewer Panes 中操作（在任意窗格中按 alt+3）。

通过 right-click 菜单，你可以使用线框（w）和 Display Options（d）等查看选项，例如点编号、法线、网格、坐标轴等。你还可以更改导航模式。

提示： 它有自己的光照用于查看 3D 场景，与你创建的灯光对象相互独立。要在 geometry viewer 中复制默认光照，请创建两个 Light COMP 对象。把一个平移到 (30, 30, 100) 并把其 Light Color 设为 (0.9, 0.9, 0.9)。把另一个平移到 (-100, 0, 30) 并把其 Light Color 设为 (0.3, 0.3, 0.3)。

显示选项

在查看器上点击右键打开视图选项菜单。（如果在窗格中使用 Geometry Viewer，必须处于 View 状态。）

点击右键会弹出 geo 视图选项菜单
  • Camera Navigation Modes - 更改鼠标控制摄像机移动的方式。
  • 3D SpaceMouse Navigation Modes - 更改 SpaceMouse 设备控制摄像机移动的方式。
  • Adaptive Homing - 启用自适应归位后，摄像机会自动调整以框住当前内容。用鼠标手动调整摄像机位置会临时覆盖自适应归位行为。可以通过调用下面的某个 Home 或 Frame 选项重新启用自适应归位。
  • Display Options - 打开 geometry viewer 的显示选项对话框。在这里可以打开/关闭点、法线、uv 坐标等的显示。
  • Toggle Hilite Dot Per Point - 为场景中的每个点显示一个叠加圆点（仅 POP）。
  • Display Attribute Text - 把属性数据或索引作为文本叠加显示在几何上（仅 POP）。
  • Display Attribute Vector - 把多维属性数据作为向量箭头叠加显示在几何上（仅 POP）。如果所选属性少于 3 维，缺少的维度按 0 处理。属性值会被归一化，因此幅值较小的向量会显示为较小的箭头。
  • Display Attribute Dots - 把单维属性显示为彩色圆点，并带一个与其值大小成比例的蓝色环。场景中的最小值显示为纯红圆点，最大值显示为纯蓝圆点。
  • Display Attribute Colors - 把多维属性数据显示为彩色圆点（仅 POP）。属性不会被归一化，以保留颜色值。这意味着大于 1 的属性会显示为纯白，负值会显示为黑色。
  • Home All - 把视图朝向重置为沿 z 轴向下，并确保视图包含所有几何。
  • Home Selected - 把视图朝向重置为沿 z 轴向下，并确保视图包含所有选中的几何。
  • Frame All - 移动视图以包含所有几何，不改变视图朝向。
  • Frame Selected - 移动视图以包含所有选中的几何，不改变视图朝向。
  • Frame C-Plane - 移动视图以包含构造平面，不改变视图朝向。
  • Toggle Shaded/Wireframe - 在着色和线框之间切换几何的渲染。
  • Toggle Ortho/Perspective - 在正交视图和透视视图之间切换。
  • Select Viewport -
  • Perspective Viewport - 把视口切换为透视视图。
  • Top Viewport - 把视口切换为顶视图。
  • Front Viewport - 把视口切换为正视图。
  • Right Viewport - 把视口切换为侧视图。
  • Help - 打开此帮助页面。

摄像机导航模式

geometry viewer 有 4 种摄像机导航模式，可从查看器右键菜单中选择。前 3 种模式下，摄像机的推拉（dolly）始终朝向光标位置，各模式的区别在于如何设定轴心。轴心决定摄像机在 3D 空间中环绕（旋转）的中心，也决定摄像机移动的速度，即轴心点越远，鼠标每移动一次摄像机移动得越远。最后一种模式 Camera Mode 从摄像机的视角进行移动和旋转，更接近真实摄像机（如 pan、tilt、dolly、track、crane）或 Unreal 这类游戏引擎中的移动方式。

Viewport Mode

这一标准控制方案始终以视图中心作为环绕的轴心。推拉始终朝向光标位置进出移动。

  • LMB - 绕轴心环绕
  • MMB - 使用中键拖动或滚轮推拉
  • RMB - 左右移动（track）和上下移动（crane）

Cursor Mode

如果光标停在某块几何上，几何上的那个特定点会成为新的轴心，并决定环绕的旋转中心和摄像机移动的速度，即如果把光标停在远处的几何上滚动滚轮，摄像机会快速朝该点移动；如果停在较近的几何上，移动会较慢。如果光标不在任何几何上，则以视图中心为轴心，距离与上一个轴心相同（如上文的 viewport 模式）。

  • LMB - 绕轴心环绕
  • MMB - 使用中键拖动或滚轮朝轴心移近或远离（dolly）
  • RMB - 垂直于摄像机方向左右移动（track）和上下移动（crane）

Object Mode

轴心是查看器中所有几何的中心；如果查看器支持选择，则只是选中几何的中心（参见 Geometry Pane）。如果没有几何，则使用原点 0,0,0 作为轴心。

  • LMB - 绕轴心环绕
  • MMB - 使用中键拖动或滚轮推拉
  • RMB - 左右移动（track）和上下移动（crane）

Camera Mode

控制基于摄像机的视角，轴心是摄像机的位置。这最接近真实摄像机或 Unreal 这类第一人称游戏引擎中可能的摄像机移动。

  • LMB - 上下看（tilt）或左右看（pan）
  • MMB - 在 XZ 平面中前后移动摄像机（dolly），或左右看（pan）
  • RMB - 左右移动（track）和上下移动（crane）。注意： 与上面其他模式相反，因为移动基于摄像机的视角。

Connection Problems：如果在 macOS 上使用 Spacemouse 出现问题，可在“Privacy & Security”下找到名为‘Input Monitoring’的设置，它可能会阻止某些设备的输入。值得检查一下 TouchDesigner 是否在其中。或者进行一次 OSX 更新，这可能会提示你重新验证 3Dxware 权限。

3D SpaceMouse 导航模式

geometry viewer 中的摄像机也可以用 3DConnexion SpaceMouse 控制。SpaceMouse 支持 6 轴的全 3D 移动（XYZ 平移和 XYZ 旋转），并且独立于鼠标光标工作。Geometry viewer 为 SpaceMouse 支持 3 种独立的导航模式，与常规的鼠标驱动导航模式无关。可通过在活动查看器上点击右键并从菜单中选择模式。

Object Mode

Object Mode 是默认导航模式，效果像 SpaceMouse 直接在操作查看器中的几何。例如，把 SpaceMouse 向右轻推会把几何在查看器中向右移动，把 SpaceMouse 向前倾会把几何旋转远离摄像机。注意实际上几何并未在场景中移动，而是摄像机围绕对象移动，从而让人感觉你直接移动了几何。

Camera Mode

在 Camera Mode 中，SpaceMouse 直接控制摄像机的位置和朝向，而不是对象。例如，把 SpaceMouse 向前轻推会让摄像机在场景中前进，向右扭转 SpaceMouse 会让摄像机向右转。此模式的感觉通常与 Object Mode 相反。

Target Camera Mode

此模式在某种程度上是另外两种摄像机模式的混合。扭转 SpaceMouse 会让摄像机绕几何中心旋转（环绕），而推动 SpaceMouse 会直接移动摄像机。

在节点查看器中

3D 对象类型组件和 SOP 的 Node Viewers 也是 geometry viewer。这些 geometry viewer 不包括窗格中 Geometry Viewer 的全部工具栏，但你可以在 Viewer Active 模式下通过查看器上的右键菜单访问许多查看器选项。

在窗格中

任何 Pane 都可以通过窗格类型菜单或快捷键 alt+3 设为 Geometry Viewer。

使用 Geometry Viewer 窗格

摄像机与几何拾取

  • Camera - - 选择要通过哪台摄像机查看场景。你也可以在右侧字段中手动输入所需摄像机的路径。
  • Lock Camera - - 打开此锁定按钮时，正在通过其查看的摄像机位置会锁定到查看器中的视图。因此环绕、缩放或重新定位视图时，会更新摄像机位置以与视图保持同步。
  • Save View to - - 这会把查看器中的当前视图保存到菜单中所选的摄像机。它会更新摄像机的位置，使其与当前视图同步。
  • Pick - - 此菜单可让你选择场景中的任何 Object Component。右侧字段可用于 Pattern Matching，以快速选择多个对象。

查看器状态

Geometry Viewer 的状态栏可让你切换查看器状态。点击其中一个按钮切换状态，或按住某个状态的快捷键临时切换状态。例如，在 View 状态下工作时，按住 “s” 键可以临时进入 Select & Transform 状态。按住 “s” 键时选择或变换一些几何，然后松开按键，就会回到 View 状态。

  • View - - 在 3D 空间中环绕、平移和缩放。
  • Select & Transform - - 选择和变换几何。
  • Construction Plane - - 显示并定位构造平面
  • Bones - - 创建骨骼。

查看器工具

  • Display Options - - 打开 Display Options 对话框。
  • Home Button - - 把视图归位到以下视图之一：Front、Right、Top、Y-axis 或 X-axis。
  • Camera Perspective - - 在透视摄像机与正交摄像机之间切换视图。
  • Construction Plane - - 在 Construction Plane 状态下，打开或关闭 Construction Plane 的显示。
  • Shading Options - - 在几何的线框或着色显示模式之间切换。
  • Selected Geo Info - - 显示所选几何的信息。
  • Viewport Options - - 从不同的视口布局中选择。
  • Snapshot - - 用 LMB 点击可对视口截图。用 RMB 点击可打开截图选项。
  • Background TOP - - 输入 TOP 的路径，以在视口背景中载入图像。
  • Background Scale - - 调整 Background TOP 中载入图像的缩放。
  • Snap Options - - 调整视口的吸附选项和优先级。
