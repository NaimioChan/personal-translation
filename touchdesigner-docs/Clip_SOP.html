Clip SOP

摘要

Clip SOP 用一个平面切割源几何并产生折痕。

clipSOP_Class

参数 - 页

Group group - 如果存在输入组，在此字段中指定组名会让此 SOP 只作用于指定的组。接受模式匹配，详见 Scripting Guide. 中的 Pattern Matching。
Keep clipop - 控制保留切割结果哪一部分的选项：
  • Primitives Above the Plane above - 保留切割平面以上的图元。
  • Primitives Below the Plane below - 保留切割平面以下的图元。
  • All Primitives both - 同时保留切割平面生成的上下两部分图元。会在几何中形成折痕。
Distance dist - 允许你沿 Direction 向量移动切割平面。如果 Direction（平面法线）为 0 1 0，在 Distance 字段中填入正数会把平面沿 Y 向上移动。
Direction dir - 0 1 0 的默认值产生一个沿 Y 正向上的 Normal 向量，它垂直于 XZ 平面，该平面即成为裁剪平面。1 0 0 把法线指向正 X，得到 YZ 平面上的裁剪平面。可以通过输入数值（1 1 0 得到 45 度角的平面）或使用方向向量插孔交互式地把平面置于某个角度。
  • X dirx -
  • Y diry -
  • Z dirz -
Create Groups newg - 勾选后，可以为切割平面上下的几何生成指定的组。见下面两个组选项字段。仅当 All Primitives 都保留时此选项才可用。
Above Plane above - 勾选 Create Groups 后，可以把切割平面以下的几何赋予此字段中输入的 Group 名称。
Below Plane below - 勾选 Create Groups 后，可以把切割平面以上的几何赋予此字段中输入的 Group 名称。

操作符输入

  • Input 0: -

Info CHOP 通道

Clip SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
