CHOP Channel 参数页

通道名称的创建

Channel Name - 以下类型的文本模式会生成多个通道名称：

Channel Pattern Channels Created
chan1 chan2 chan3 chan1 chan2 chan3
chan[1-3] chan1 chan2 chan3
ch[1-2]n[2-6:2] ch1n2 ch1n4 ch1n6 ch2n2 ch2n4 ch2n6
r[xyz] rx, ry rz
geo[1-2]:t[xy] geo1:tx geo1:ty geo2:tx geo2:ty
gain band[4-6] off[lr] gain band4 band5 band6 offl offr

Start-End

Start/End - 指定起止区间。默认起止为 0。这些选项中的值可以用任何 Units 表示。

采样率

Sample Rate - 通常 CHOP 采样率设为 60「每秒采样数」。这意味着 TouchDesigner 会尝试每秒计算该操作 60 次。使用低于全局采样率的采样率可能导致通道数据出现混叠（错误）。

扩展条件

Extend Conditions - 见于 Extend CHOP 以及若干生成器 CHOP，它决定当你试图采样 CHOP 起止范围之外时的取值。它可以保持值、重复通道等。

使用 chop() 函数采样通道时，索引–值可能位于 CHOP 区间之外。但仍会返回合理的值。用户可以控制 CHOP 区间之外的通道值。

可以在任何 CHOP 的弹出信息中查看扩展条件的状态。

Extend Left - CHOP 区间之前的扩展条件。包括：

  • Hold - 保持第一个或最后一个值。
  • Slope - 在通道起点之前或终点之后延续斜率。
  • Cycle - 重复循环该通道。
  • Mirror - 重复循环该通道，每隔一个循环进行镜像。
  • Default Value - 使用 Default Value 参数中指定的常量值。

Extend Right - 区间之后的扩展条件。选项与 Extend Left 相同。

Default Value - 用于 Default Value 扩展条件的值。

合法的通道名称

CHOP 通道名称可以包含以下字符：

  • 大写和小写字母
  • 数字
  • 以下字符：- _ : /

一般来说，CHOP 会将无效字符替换为下划线。
