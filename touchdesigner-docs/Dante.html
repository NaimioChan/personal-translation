Dante

Dante 是基于 IP 的专业低延迟音频行业标准之一。它允许在实现 Dante 标准的软件工具与硬件设备之间以未压缩形式串流音频。

Dante 为 Audinate 专有，有数百种支持 Dante 的第三方产品。

在 TouchDesigner 中通过安装 Dante Virtual Soundcard 获得支持，可在 32x32 @48KHz、16x16 @96KHz 和 8x8 @192KHz 下实现音频通道的低延迟传输（输入与输出）。

如何在 TouchDesigner 中使用 Dante

Dante Virtual Soundcard 是一款软件应用，其作用类似声卡，在 TouchDesigner 中显示为普通音频设备。它提供了一种廉价的方案，可在支持 Dante 的设备或普通 MacOS 与 Windows 计算机之间通过 1Gbs 有线网络串流音频。可在此处以 $29.99 购买。Dante Virtual Sound Card

安装 Dante Virtual Soundcard 后，Dante 设备会出现在 Audio Device In CHOP 中，作为一组立体声输入通道：在 Windows 上为 ASIO 或 Direct Sound 设备，在 macOS 上为 Core Audio 设备。在 ASIO 下 TouchDesigner 支持 16 位和 24 位，32 位会被降转为 24 位。

它也会作为一组立体声输出通道出现在 Audio Device Out CHOP 中。

另请参阅：NDI and Dante Networks

用 Dante 连接两台计算机

要连接两台运行 Dante Virtual SoundCard (DVS) 的计算机，必须购买 DVS 软件许可，并在每台计算机上安装 DVS。此外，同一网络上还必须存在第三个 Dante 时钟源，两台已安装 DVS 的计算机才能通信。这意味着仅有两台安装 DVS 并接入网络的计算机，还不足以构成可用的 Dante 音频网络。

通常 Dante 时钟源由硬件网络设备（如 Focusrite RedNet System）或嵌入式 Dante 接口（如 Yamaha 的 TF Series 中的接口）产生。

除硬件方案外，Audinate 还提供名为 Dante Via 的纯软件方案，可生成时钟源以激活 Dante 音频网络。

Dante 网络配置好有效的时钟源设备后，DVS 软件将被检测到，应用 Dante Controller 会提供用于在 DVS 或其他 Dante 硬件设备之间传递音频的路由界面。

注意，为保持低延迟，TouchDesigner 进程运行期间不能出现长于该延迟的掉帧，否则音频需要在单独的 TouchDesigner 进程中运行。

请参阅 Audio Device In CHOP 和 Audio Device Out CHOP。

重要说明

为确保音频性能正常、没有数字爆音，在搭建由运行不同软件的计算机组成、并且混用 ASIO 与 Windows WDM 系统音频驱动程序的网络时，请遵循以下准则。

ASIO 与 WDM 的采样率必须一致。ASIO DAW 程序和 WDM 音频程序中的所有采样率值都必须设为相同的采样率。 如果 ASIO 与 WDM 的采样率不同，则一个或多个程序的音频将听不到。 更改 WDM 采样率时：先在声卡的 Audio Driver Settings Hardware 控制面板中设置采样率，然后再更改 Windows 内 Sound>Advanced>Default Format 或 Sound>Recording 控制面板中的采样率。 注意，如果在 Windows 内的 Sound 控制面板中更改了采样率，WDM 程序可能需要关闭后再重新打开才能听到声音。 更改 ASIO 采样率时：如果更改了 DAW 的采样率，WDM 音频将不再被听到，因为采样率不再匹配。此时必须在 Windows 的 Sound>Advanced>Default Format 面板中更改 WDM 采样率，使其与 DAW 的采样率一致。

搭配 NDI 使用 Dante

在 Dante 网络上运行 NDI 会大幅增加延迟。必须强制 NDI 在与 Dante 不同的网络和 NIC 上工作。

本节介绍我们在 Dante 与 NDI 网络上进行的一些测试。由于 Dante 和 NDI 都使用 Bonjour 网络发现协议，NDI 会干扰 Dante 网络的带宽。各论坛上一直有讨论如何将网络隔离到不同的 NIC 和网段，但 Derivative 未能验证任何变通方案。

  • https://forums.newtek.com/showthread.php/154532-Required-dual-NIC-setup-having-tough-time-getting-NDI-to-only-hit-one
  • https://forums.newtek.com/showthread.php/154021-Routing-NDI-traffic-to-a-specific-NIC

在运行 2 路 3840x2160 的 NDI 串流时，Dante 延迟会出现非常严重的数字音频爆音突发。在这些情况下，Dante Controller 软件会明显显示出更大的延迟。

不使用 NDI 的 Dante。没有爆音。延迟明显更低。

硬件考虑事项

如 Dante Controller 软件所示，10G Asus 网卡默认延迟明显偏高。左侧是 ASUS，右侧是 SuperMicro Intel 10G。 NUC 连单路 NDI 3840x2160 输入都无法播放。

Dante 硬件

Focusrite Pro 提供了一系列强大的工具，让 Dante 网络的使用变得直接而简单。https://pro.focusrite.com/category/audiooverip

RedNet X2P 是一种经济可靠的方案，既能生成 Dante 网络时钟，也能在 Dante 网络上监听或发送音频。该设备支持 POE，因此可以部署在取电困难的复杂环境中。有了该设备和一台兼容的交换机，除了计算机端的发送方和接收方之外，你就拥有完整的 Dante 网络方案。在作为接收方的 TouchDesigner 计算机上，只需安装 Dante Virtual Soundcard 即可。

可能解决同一台计算机上 NDI 问题的 Dante 硬件

这种在同一台计算机上运行 Dante 音频与 NDI 发送方或接收方的变通方案尚未经过 NOT 测试，但据 Focusrite 称应该可行。使用其 RedNet PCI 卡时，与 TouchDesigner 的连接将通过 ASIO 驱动进行，因此会自动隔离，因为 PCI 卡内置的 NIC 在操作系统中不会显示为标准 NIC。它的表现更像一块声卡。这样做可以让 Dante 网络轻松分配到同一台网络交换机上的独立网段，或分配到隔离的单独网络交换机。
