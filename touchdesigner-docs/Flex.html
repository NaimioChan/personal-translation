什么是 Nvidia Flex？

Nvidia Flex 是一个基于粒子的物理模拟器。Flex 对所有对象类型使用统一的粒子表示。模拟中的所有刚体（静态形状/曲面除外）都由粒子组成，它们在模拟中的行为由物质类型决定：rigid、soft、fluid、rope、cloth。由于 Flex 模拟中的所有刚体都由粒子表示，所有物质都能无需多个求解器而无缝地一起模拟。

TouchDesigner 中的 Nvidia Flex

Nvidia Flex 模拟通过 Nvidia Flex Solver COMP 完成。Nvidia Flex Solver COMP 负责运行模拟并更新模拟中所有刚体的变换。Nvidia Flex Solver COMP 包含所有全局参数，例如粒子半径和摩擦。刚体可通过 Actor COMP 添加到 Nvidia Flex Solver COMP 的模拟中。Actor COMP 目前仅支持流体物质和静态形状。

流体通过实例化或发射创建。使用实例化时，粒子数量由输入实例的数量决定（例如 TOP 的分辨率、SOP 中的点数），其初始变换由实例输入参数计算（另见：Actor COMP）。使用发射时，最大粒子数通过参数显式设置。Actor COMP 初始为 0 个流体粒子，但流体粒子会由发射器加入模拟。创建粒子不需要 SOP。粒子碰撞边界仅由半径定义（在 Nvidia Flex Solver COMP 上），因此 Actor COMP 内的 SOP 除渲染外无关紧要。自然，与碰撞粒子半径相同的 sphere SOP 会最准确。为提高性能可以使用低多边形球体。

Nvidia Flex Solver COMP 仅在运行 Windows 操作系统的系统上工作。

注意：较新的驱动版本会破坏某些功能（例如多个碰撞体），因此建议使用 Nvidia 驱动 546.xx 版本。因此 Nvidia Flex 在较新的 Nvidia 显卡（如最低驱动为 570.xx 的 Nvidia RTX 50 系列）上也会有问题。最后支持 Flex 的 Nvidia 显卡是 Nvidia RTX 40 系列。

在 TouchDesigner 中 Flex 能做什么？

Flex 让你在 TouchDesigner 中创建逼真的流体粒子模拟。也支持流体发射。除流体外，TouchDesigner 还支持静态形状/曲面。

Flex 与 Bullet

Nvidia Flex Solver COMP 作为 Bullet Solver COMP 的替代品存在。这两个物理模拟器都使用 Actor COMP 把刚体加入模拟。

关键区别在于 Flex 是粒子模拟器，而 Bullet 是刚体模拟器。Bullet 没有粒子模拟器；它只是刚体模拟器。Flex 也支持刚体模拟，但目前 TouchDesigner 中的 Flex 仅支持流体粒子模拟。由于 Flex 利用 GPU（即 CUDA），其模拟可支持比 Bullet 多得多的刚体。

Nvidia Flex Solver COMP 是比 Bullet Solver COMP 更封闭的模拟。在用户交互和获取模拟信息方面，Bullet 是更好的选择。这主要是因为 Bullet Solver CHOP，它允许取回变换、速度等模拟信息，是 Bullet 反馈系统中的关键部分。TouchDesigner 中的 Bullet 在 Python 方面也有更好的支持（见 Body Class）。此外，Bullet 提供碰撞回调机制。

Bullet 支持冲量和连续的线性/角向力。这些力可以是全局的，也可以是局部的（针对特定 Actor COMP）。Flex 只支持力场。力场可以向外推（正强度）或向内拉（负强度），并可选从力场中心线性衰减。

Flex 内置了以平面形式提供的模拟边界。Nvidia Flex Solver COMP 上以参数形式最多提供 6 个平面。默认平面是 +Z XY 平面，即粒子被约束在平面的 +Z 一侧。

如何在 TouchDesigner 中使用 Flex

关于如何在 TouchDesigner 中使用 Flex 的完整示例，请参阅 Help → Operator Snippets 下的 Nvidia Flex Solver COMP Snippets。

另请参阅：https://docs.derivative.ca/Bullet_Dynamics#How_to_use_Bullet_in_TouchDesigner

在 TouchDesigner 中，Nvidia Flex Solver COMP 是物理模拟的主要操作符。它负责运行模拟并求解模拟中每个刚体的变换和速度。Actor COMP 表示模拟中的刚体，可使用 Force COMP 添加力场。

要创建一个简单的流体发射器模拟：

  1. 创建一个 Nvidia Flex Solver COMP
  2. 启用平面。把平面旋转为 +Y XZ 平面。为此，把平面绕 X 轴旋转 90 度。
  3. 创建一个 Actor COMP 并在 Nvidia Flex Solver COMP 上引用它，以便它被加入模拟。
  4. 这个 Actor COMP 将作为流体发射器。所以，把 Actor COMP 的运动学状态改为 dynamic。然后在 Flex 页上，把 Flex Type 改为 Fluid Emitter
  5. 选择发射变换。Fluid Emitter 变换由 Actor COMP 的变换计算（Xform 和 Pre-Xform 页）。实例化会自动启用且实例会自动创建，因此实例页上的参数将不起作用。
  6. 选择发射速度和尺寸。
  7. 选择最大发射粒子数。流体发射器会不断创建新的流体粒子直到最大值，之后开始在 Actor COMP 内回收已有的流体粒子。
  8. 使用 Nvidia Flex Solver COMP 上的「Start Sim」参数开始模拟。
