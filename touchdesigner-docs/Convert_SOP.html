Convert SOP

摘要

Convert SOP 将几何从一种几何类型转换为另一种类型。类型包括 polygon、mesh、Bezier patche、particle 和 sphere primitive。

convertSOP_Class

Notes： 并非所有几何都能转换为特定类型。例如，三角化的多边形曲面无法转换为单个 NURBS 曲面，Mesh 球体也无法转换为 primitive 球体。此外，某些转换会保留形状。例如，将 Bzier 曲线转换为 NURBS 曲线，或将多边形网格转换为 NURBS 曲面。

Circle Notes：转换为 primitive 圆可供习惯使用 polygon 圆的 action 用户使用，以便将其转换为 primitive 圆，用于 TouchDesigner 的 Skeleton、Arm 和 Limb SOP。

Trimmed Surface Notes：如果要转换的图元是曲线（NURBS 或 Bezier）且为平面，则会生成裁剪曲面，使可见部分与曲线重合。如果曲线不是平面，则转换为非裁剪曲面。裁剪方案的优点是可以得到非常干净的曲面，并完美处理凹曲线。

参数 - Level of Detail 页

这会影响 U/V/Trim Curve 字段的使用：

  • 用于 Level of Detail：U、V、Trim Curve Level of Detail

在样条中，段（span）是两个断点之间的曲线弧。每段细分数指定两个断点之间要创建多少个点。如果细分数 = 0，则两个断点之间由一段连接；如果细分数 = 1，则会创建两条边；依此类推。 与 Level of Detail 相比，Divisions 的优点是可以确切知道最终会有多少个点——这对多边形建模极其有用。

U lodu - 设为 Level of Detail 时，根据上述设置控制新生成几何中使用的点或 CV 的数量。将 NURBS 曲面以 Level of Detail 为 1 转换为多边形网格，可得到对 NURBS 曲面的较好近似；而值为 2 会生成非常密集的多边形网格。

设为 Divisions per Span 时，指定每段的细分数。

提示： 使用 primdist() 表达式，根据角色或几何与摄像机的距离来动画 Level of Detail。这样当摄像机靠近/远离时，细节会随之增加/减少。

V lodv - 设为 Level of Detail 时，根据上述设置控制新生成几何中使用的点或 CV 的数量。将 NURBS 曲面以 Level of Detail 为 1 转换为多边形网格，可得到对 NURBS 曲面的较好近似；而值为 2 会生成非常密集的多边形网格。

设为 Divisions per Span 时，指定每段的细分数。

提示： 使用 primdist() 表达式，根据角色或几何与摄像机的距离来动画 Level of Detail。这样当摄像机靠近/远离时，细节会随之增加/减少。

Trim-Curve lodtrim - 曲面的裁剪部分将使用此 Trim lod（细节级别）进行转换，而不是使用隐式的常量 “1”。

U Order orderu - 转换为 spline 类型时，指定 U 或 V 基函数的阶数 + 1。

粘贴坐标

  • From Feature Surfaces - 生成的 mesh 将具有粘贴层级的形状（即最顶层的特征决定形状）。
  • From Base Surface - 生成的 mesh 将采用最底层曲面的形状。

粘贴属性

  • From Feature Surfaces - 每个 mesh 点具有该位置处最顶层特征的属性。
  • From Base Surface - 生成的 mesh 将继承根曲面的图元属性（例如材质），点属性也将是根曲面的点属性。

通过使用基础坐标和特征属性，实际上就是把属性粘贴到曲面上。

V Order orderv - 转换为 spline 类型时，指定 U 或 V 基函数的阶数 + 1。

粘贴坐标

  • From Feature Surfaces - 生成的 mesh 将具有粘贴层级的形状（即最顶层的特征决定形状）。
  • From Base Surface - 生成的 mesh 将采用最底层曲面的形状。

  • From Feature Surfaces - 每个 mesh 点具有该位置处最顶层特征的属性。
  • From Base Surface - 生成的 mesh 将继承根曲面的图元属性（例如材质），点属性也将是根曲面的点属性。

Preserve Original new - 勾选后，原始几何将与转换后的几何一起保留。
Interpolate Through Hulls interphull - 此选项适用于多边形面和网格与 NURBS 及 Bzier 曲面和曲线之间的转换。选中时，生成的曲线保持与原多边形相同的拓扑。未选中时，多边形点用作定义新曲线或曲面的外壳。
Particle Type prtype - - 选择粒子的渲染方式。
  • Render as Lines lines - 每个粒子渲染为一条 2 点线段，长度根据粒子速度决定。如果粒子没有速度，则大小仅为单个像素。
  • Render as Point Sprites pointprites - 用于 Point Sprite MAT。每个粒子是一个始终面向摄像机的像素方块。方块大小由 Point Sprite 中的参数和 pscale 顶点/点属性决定。point sprite 还会自动生成纹理坐标（左下角为 (0,0)，右上角为 (1,1)）。

说明

面到曲面转换 - 从一组多边形转换为 mesh 时，只有在 Facet SOP 的情况下才会生成单个 mesh。

否则，每个多边形会单独转换为一个 mesh。实际上，任何单个面都可以转换为任意曲面。做法是把该面切分成三到四个相邻的区域，再由它们创建 patch。

Info CHOP 通道

Convert SOP 的附加信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
