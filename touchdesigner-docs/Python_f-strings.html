Python f-string

f-strings

Python f-strings 是 Python 中格式化字符串的强大新方式。通常它们看起来像这样：

f'This string includes {expression}'

花括号内的任何内容都会作为 Python 表达式求值。你可以在线搜索「Python f-strings」获取完整细节。This 是个不错的起点。

TouchDesigner 中的 f-strings

一些 TouchDesigner 操作符允许你以多种方式使用 f-string 格式化。示例包括参数中的 textCOMP 和 colDefine 表中的 lister。会向 f-string 提供不同的变量以供在表达式中使用。这些将在各个操作符页面中说明。

示例

  • {text}! - 生成 text 中的字符串，后接一个感叹号
  • {val + 1} - 生成 val + 1（仅当 val 是数值类型时有效）
  • ${val:.2f} - 生成 val 作为保留两位小数的浮点数，并在其前面加美元符号（仅当 val 是浮点数时有效）
  • {me.path}: {text} - 生成正在求值的操作符路径，后接一个冒号，再接 text 中的字符串

在脚本中使用 f-string 格式化

要在自定义脚本、参数和组件中使用 f-string 格式化，请使用 TDFunctions 中的工具函数 formatString。
