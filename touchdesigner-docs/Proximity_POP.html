Proximity POP

摘要

Proximity POP 将第一个输入中的点与其附近在指定近/远距离内的点连接起来。如果连接了第二个输入，它会将第二个输入的点与第一个输入中处于范围内的点连接起来。

两个参数分别设置点之间可连接的最大距离和最小距离。你可以限制每个点最多能连接多少条线。Uniform Distribution 参数会让连接点的分布更随机。

你可以确保每对点之间最多只有一条线。

当 Proximity 有两个输入时，你可以（通过 Output 菜单）输出连接线，或只输出第一个输入中处于第二个输入范围内的点图元。输出线时，可以包含图元属性 LineDir 和 LineLength。

输出点时，还可以通过选择 End Point Attributes，把匹配点的所有属性作为单独的新属性输出（EndP、EndN、EndTex 等）。

每个连接图元都是 2 个点的「线图元」，而不是线带。

另请参阅 Neighbor POP、Line Metrics POP

参数 - Proximity 页

Maximum Distance maxdist - 候选点可与当前点创建连线的最大距离。
Minimum Distance mindist - 候选点可与当前点创建连线的最小距离。
Max Lines per Point maxlinesperpoint - 指定第一个输入中每个点最多发出的线条数。
Uniform Distribution uniformdist - 允许在附近的点之间均匀分布选择，而不是默认取最先找到的几个。
Max Temp Neighbors maxtempneighbors - 内部用于存储待创建连线的候选点，之后会移除部分点以达到每个点的最大线条数。
Duplicate Lines duplines - - 决定如何处理重复的邻近连线
  • Do Nothing donothing -
  • Avoid avoid -
  • Delete delete -
Num Hash Buckets numhashbuckets - 根据点的位置将其分入的桶数量。一个不错的经验法则是取接近点数量的值。

参数 - Output 页

Output output - - 输出带属性的点还是线。
  • Lines (Shared Points) lines -
  • Point Prims points -
Line Direction linedir - - 启用添加线条方向属性。
  • Line Direction linedir -
  • Line Direction Attrib Name linedirname - 线条方向的属性名称。
Line Length linelength - - 启用添加线条长度属性。
  • Line Length linelength -
  • Line Length Attrib Name linelengthname - 线条长度的属性名称。
End Point Attributes endptattrs - 启用输出第二个输入的端点属性
Origin origin - - 设置线条的原点来自第一个输入还是第二个输入。
  • First Input Points first -
  • Second Input Points second -
Remove Unused Points remunusedpoints - 移除未被图元引用的未使用点。
Copy Topology Info Back to CPU cpureadback - 启用后，将 GPU 上保存的点数和拓扑信息复制到 CPU。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Info CHOP 通道

可通过 Info CHOP 访问 Proximity POP 的额外信息。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
