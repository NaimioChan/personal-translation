Particle SOP

摘要

Particle SOP 用于为粒子系统模拟创建和控制「粒子」的运动。粒子系统常用于模拟自然现象（如雨和雪）或效果（如烟花和火花）。在 Touch 中，输入几何的点被用作粒子的起始位置。输入的每个点都可以受到外力（重力）和风的影响。粒子可以碰撞并从另一个物体上反弹，该物体由 Collision Source 设置。它们也可以在 X、Y、Z 上设置的限位平面处反弹或消亡。

粒子的初始速度/方向来自源几何的点法线，可以通过修改法线来控制该速度，例如使用 Point SOP、Facet SOP 或 Script SOP。法线大小为 1 的点会沿法线方向以每秒 1 单位的速度发射 bear 粒子。

粒子具有普通几何没有的各种 Attributes，例如速度、生命期望和年龄。这些属性必须随每个点一起携带，才能进行模拟。

第四个输入是 Surface Attractors，它使粒子附着到表面的某些区域。每个粒子的 id 用于确定一个随机的目标图元，以及该图元上随机的 u、v。该目标位置用于修改当前速度。

参数 - 页

Source Group sourcegrp - 将粒子发射限制在指定点组中找到的点上。

参数 - State 页

Particle Type prtype - - 选择粒子的渲染方式。
  • Render as Lines lines - 每个粒子渲染为一条 2 点线段，长度根据粒子速度决定。如果粒子没有速度，则大小仅为单个像素。
  • Render as Point Sprites pointprites - 用于 Point Sprite MAT。每个粒子是一个始终面向摄像机的像素方块。方块大小由 Point Sprite 中的参数和 pscale 顶点/点属性决定。point sprite 还会自动生成纹理坐标（左下角为 (0,0)，右上角为 (1,1)）。
Behavior behave - 在从几何的点发射粒子，或使用 Particle SOP 的行为使原始几何变形之间选择。
  • Particle System psystem - 表现得像粒子系统，粒子从输入点诞生。
  • Modify Source Geometry modify - 使源输入几何变形。

提示： 也可以将几何实例化到粒子上。使用 SOP to CHOP 将粒子位置获取到 CHOP 中，并在 Geometry COMP 的 Instance 页上将任意几何定位到每个粒子位置。这是用粒子系统为大量几何副本制作动画的最高效方式。

Compute Normals normals - 在几何上创建法线。仅在 Behaviour 设为 Modify Source Geometry 时使用。
Point Reuse ptreuse - 决定当需要创建点或点消亡时，如何复用点的内部内存。
  • Reuse Points in Loop loop -
  • Reuse First Available Point unused -
  • Don't Reuse Points none -
Preroll Time timepreroll - 在达到重置时间后，跳过多少秒的模拟。例如，如果在此字段中输入 33（且重置在 Tstart），第一帧将显示 33 秒时刻的模拟。换言之，前 32 秒被跳过，33 秒时刻被移到第一帧。为了计算点的状态，前 32 秒仍必须计算，因此重置时会看到一些延迟。
Time Inc timeinc - Time Inc 参数决定 SOP 的计算频率。默认情况下，此参数设为 1/me.time.rate。这意味着 SOP 每帧计算一次。涉及复杂动力学时，SOP 可能需要更频繁地计算以提高数学精度。要在计算中获得亚帧精度，请将 Time Inc 设为小于 1/me.time.rate 的值。

For example: 将 Time Inc 设为 0.5/me.time.rate 意味着 SOP 每帧会被计算两次。

注意： 切勿将此参数设得大于 1/me.time.rate。

Max Steps maxsteps - 限制 TouchDesigner 为正确交互而回溯计算粒子位置的时间深度。如果帧率较慢，此回溯计算量可能变得很大，此参数可限制该影响。
Jitter Births jitter - 这让你可以在每个粒子诞生时抖动其位置像素。
Accurate Moves accurate - 此选项通过计算分数帧值上的轨迹，使粒子在帧之间移动得更准确。
Remove Unused Points rmunused - 移除输入几何中所有未使用的点。它作为显式选项而非自动执行，是因为这样可以省去模拟期间从内存清除点所需的时间，从而避免模拟中出现不必要的变慢。
Attractor Use attractmode - 选择 Surface Attractors 使用的吸引模式。
  • All Points all - 所有点吸引器影响所有粒子（或点）。
  • Single Point per Particle single - 启用时，每个粒子被分配单个吸引点，并且只受该点影响。分配方式是点编号对吸引点总数取模。
Reset reset - 开启时，粒子系统处于重置状态，不发射粒子。
Reset Pulse resetpulse - 立即将粒子系统重置到其起始状态。

参数 - Forces 页

External Force external - 作用于粒子的重力。阻力为零时，粒子可以加速且速度不受限制。
  • X externalx -
  • Y externaly -
  • Z externalz -
Wind wind - 作用于粒子的风力。类似于 External Force。使用 Wind（不使用其他力，例如 Turbulence）时，粒子的速度不会超过风速。

讨论 - 风与外力

External Force 的作用直接影响粒子的加速度，其大小由质量决定（F = Mass × Acceleration）。Wind 是一种额外的力，但对速度敏感。如果粒子已经以风速运动，就不应再从中获得额外的力。这意味着单独使用 Wind 时存在最大速度。

在给定恒定力的情况下，质量增加会阻碍加速。Drag 是一种与运动方向相反、对速度敏感的力，即速度越大，阻力效果越强。它可用于限制粒子速度。

  • X windx -
  • Y windy -
  • Z windz -
Turbulence turb - 各轴上湍流（混沌）力的幅度。如果有的话，请使用正值。
  • X turbx -
  • Y turby -
  • Z turbz -
Turb Period period - 周期较小意味着湍流在小范围内快速变化，而较大的值会使彼此靠近的点受到相似影响。
Seed seed - 粒子模拟的随机数种子。

参数 - Particles 页

Add Particle ID doid - 在每个粒子诞生时为其添加 ID 编号。注意： 只有在通过 reset 参数重置粒子系统或首次加载后，新属性才会出现。
Add Mass Attribute domass - 选中时，按 Mass 字段中的指定计算粒子的质量。
Mass mass - 每个粒子的相对质量。较重的粒子启动更慢，减速也更慢。
Add Drag Attribute dodrag - 选中时，按 Drag 字段中输入的值计算粒子的阻力系数。
Drag drag - 每个粒子的阻力。
Birth birth - 每秒诞生的粒子数量。粒子不会成簇释放，而是在其存在第一帧内的随机时刻诞生。出生时间在第一帧内随机设定。
Life Expect life - 每个粒子存活的时长（秒）。默认为 3 秒。你可能需要根据动画长度调整此数值。
Life Variance lifevar - 粒子生命期望的变化量（秒）。如果生命期望为 1 秒、变化量为 0 秒，每个粒子恰好存活 1 秒。如果变化量设为 0.5，则有些粒子只存活半秒，另一些存活一秒半，其余则介于两者之间。这种随机性使粒子诞生看起来更自然。
Alpha Speed alpha - 粒子运动越快，应越透明。Alpha Speed 参数默认为 0，即速度增加时不改变 alpha。典型值 0.5 会使粒子在 1 单位/秒时具有 70% 的不透明度。增大 Alpha Speed 参数会使粒子在给定速度下更透明。速度为零时，粒子始终 100% 不透明。
Surface Attraction subattract - 控制粒子被 Particle SOP 第 4 个输入表面吸引器吸引的程度。
Birth Count birthcount - 指定触发 Birth 脉冲参数时创建的粒子数量。
Birth birthpulse - 脉冲时手动创建 n 个粒子。创建的粒子数量由 Birth Count 参数控制。

+ Limit Plane limitpos - 粒子到达限位平面时会消亡或反弹。六个限位平面字段定义一个包围立方体。默认设置为 1000 单位远，非常大。请将值减小到约 1 以查看效果。
  • X limitposx -
  • Y limitposy -
  • Z limitposz -
- Limit Plane limitneg - 粒子到达限位平面时会消亡或反弹。六个限位平面字段定义一个包围立方体。默认设置为 1000 单位远，非常大。请将值减小到约 1 以查看效果。
  • X limitnegx -
  • Y limitnegy -
  • Z limitnegz -
Hit Behavior hit - 控制粒子碰到六个碰撞平面或碰撞对象时发生什么。选项有：
  • Die on Contact die - 粒子与 Collision 输入碰撞时会消失。
  • Bounce on Contact bounce - 粒子与 Collision 输入接触时会反弹。
  • Stick on Contact stick - 粒子会粘在 Collision 输入上。
Gain Tangent gaintan - 摩擦参数，可视为碰撞时的能量损失。第一个参数影响垂直于表面的能量损失（增益）：0 表示所有能量（速度）都损失，1 表示垂直于表面方向无能量损失。第二个参数是沿表面切线方向的能量增益。
Gain Normal gainnorm - 摩擦参数，可视为碰撞时的能量损失。第一个参数影响垂直于表面的能量损失（增益）：0 表示所有能量（速度）都损失，1 表示垂直于表面方向无能量损失。第二个参数是沿表面切线方向的能量增益。
  • 1 和 1 表示既不损失也不获得。
  • 0.1 和 1 会使粒子撞击表面后沿其滑落，像屋顶上的雨。
  • 1 和 0 使粒子无论以什么角度入射都垂直于表面反弹。
  • -1 和 1 使粒子沿原路弹回。
  • 增益大于 1 会产生能量增益（像弹珠机的弹力柱）。
Split splittype - 选择粒子是否分裂以及在什么条件下分裂。
  • No Splitting no - 默认设置，保持粒子不分裂。
  • Split on Contact bounce - 粒子与 Collision Source 接触时分裂。
  • Split on Death die - 粒子消亡时分裂。
Min/Max Splits split - 粒子分裂时会分裂成若干其他粒子。粒子数量在此范围内随机设定。
  • splitmin -
  • splitmax -
Split Velocity splitvel - 每个分裂出的粒子被赋予此基础速度。
  • X splitvelx -
  • Y splitvely -
  • Z splitvelz -
Velocity Variance splitvar - 这是一个加到分裂速度上的随机量。制作烟花时，变化量大而速度低。渲染雨滴飞溅时，分裂速度在 Y 方向较大，而 X 和 Z 方向的变化量使粒子在 XZ 平面内向上反弹（但方向随机）。
  • X splitvarx -
  • Y splitvary -
  • Z splitvarz -

Info CHOP 通道

可通过 Info CHOP 访问 Particle SOP 的额外信息。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
