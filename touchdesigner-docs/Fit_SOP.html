Fit SOP

摘要

Fit SOP 把样条曲线拟合到一系列点，或把样条曲面拟合到 m X n 的点网格。

任何类型的面或曲面都是有效输入。Fit SOP 只看图元的控制顶点（CV），把 CV 当作要拟合穿过的数据点。例如，如果一个三次 NURBS 曲面和一个网格具有相同的行数和列数以及相同的点，它们会产生完全相同的拟合结果，因为输入 NURBS 曲面的样条基被忽略。

Fit SOP 生成两类输出：大致沿数据点路径但不一定穿过数据点的图元；以及接触所有数据点的图元。第一类称为「approximation」（逼近），主要用于从大量数据中提取精炼、平滑的形状，很适合数据简化。第二类称为「interpolation」（插值），常用作必须经过指定目标位置的路径的平滑工具。

参数 - 页

Group group - 如果存在输入组，在此字段中指定组名将使该 SOP 仅作用于指定的组。接受模式匹配，说明见 Pattern Matching。

参数 - Fit 页

这是该 SOP 的主参数页。其用途是指定拟合类型以及输出图元的特性。

Method method - 指定两种拟合风格之一：approximation 或 interpolation。每种风格都有一组参数，可从各自的文件夹访问。更多信息见下面的 Approximation 和 Interpolation 页。
  • Approximation approx -
  • Interpolation interp -
Primitive Type type - Fit SOP 的输出是 NURBS 或 Bzier 图元。所有输入面都拟合为样条曲线，所有输入曲面都拟合为样条曲面。无论以 NURBS 还是 Bzier 图元创建，得到的形状都相同。
  • NURBS nurbs -
  • Bezier bezier -
Connectivity surftype - 使用 Mesh Primitive Type 时，此选项用于选择曲面类型。
  • Rows rows - 创建水平线。
  • Columns cols - 创建垂直线。
  • Rows and Columns rowcol - Rows 和 Columns 都勾选。在线框显示下看起来像四边形，但所有多边形都是开放的（如果图元类型为 polygon）。
  • Triangles triangles - 用三角形构建网格。
  • Quadrilaterals quads - 生成由四边形构成的侧面（默认）。
  • Alternating Triangles alttriangles - 生成相互对置的三角形；类似 Triangles 选项。
U Order orderu - 如果输入是面，这是要生成的样条曲线的阶数。如果输入是曲面，这是拟合样条曲面在 U 参数方向的阶数。
V Order orderv - 如果输入是曲面，这是拟合样条曲面在 V 参数方向的阶数。如果输入是面，V 阶数无关。

参数 - Approximation 页

Approximation 拟合主要用于从密集数据中生成精炼、平滑的形状。结果是一个图元，它逼近数据点的位置和属性，但不一定接触这些点。拟合曲线或曲面唯一穿过的点是数据集的端点。如果要求拟合图元穿过所有点，答案就是插值拟合。

Approximation 拟合能够用远少于数据点数量的控制顶点生成相当合理的形状。虽然结果不太可能与原始形状完全一致，但根据所设参数，它可以非常接近。因此，approximation 拟合常被用作数据简化工具，在数据集较大时表现最佳。

拟合图元是开放还是环绕，取决于输入的「open」属性。为获得最佳结果，输入图元应为开放。

Tolerance tol - 这是 approximation 拟合中的主要精度因素。容差越小，拟合越贴近，生成的顶点数越多。如果小容差导致拟合图元出现不希望的扭曲或变形，调整样条阶数和/或启用 Multiple Knots 标记可能有帮助。
Smoothness smooth - 在给定容差下，平滑因子允许生成的形状更圆润或更不平滑。如果此参数为零，并不意味着拟合会变尖锐。它只表示在给定容差已实现的平滑程度之外，不需要额外平滑。
U Multiple Knots multipleu - 有时数据集有必须在拟合形状中保留的急弯。此时在急剧弯曲的区域插入多个节点通常能产生正确效果。不过有时模拟出的尖锐会在转角前后立即引起不希望的扭曲。降低样条阶数和/或减小容差可能有助于减轻这种副作用。
V Multiple Knots multiplev - 有时数据集有必须在拟合形状中保留的急弯。此时在急剧弯曲的区域插入多个节点通常能产生正确效果。不过有时模拟出的尖锐会在转角前后立即引起不希望的扭曲。降低样条阶数和/或减小容差可能有助于减轻这种副作用。

参数 - Interpolation 页

Interpolation 拟合主要用于生成穿过（即插值）完整数据点集及其属性的形状。与 approximation 拟合相反，插值适合小数据集。此外，与 approximation 方法不同，它产生的结构不会比它所拟合的输入更精简。在某些情况下，它甚至生成比输入更多的 CV。因此，插值拟合应仅限用于点插值至关重要的场合，例如构建精确的动画路径。

Scope scope - Scope 确定插值方法。
  • Global global - 全局插值一次考虑整个数据集，并生成与给定数据点数量完全相同的 CV。
  • Local (Curves Only) local - 局部插值采用更几何化的方式，一次构建一段曲线或曲面，每一步只使用局部数据。局部方法生成的 CV 多于给定数据点的数量，但通常比全局方法拟合得更紧密。局部方法的计算开销也比全局方法小，并且能更好地处理尖点和局部扰动。局部插值仅适用于曲线。
  • Breakpoints breakpnt - 断点插值是全局插值的一种变体，它满足数据点位置与生成曲线的断点重合的要求。样条曲线的断点是样条基在曲线上的像。断点插值仅适用于曲线。
U Data Parameter dataparmu - - 指定数据在 U 方向上的参数化方式（如果输入是曲线，则这是唯一的方向）。数据参数化可以是 uniform、chord length 或 centripetal。
Uniform 均匀参数化使用等间距的参数值。几何非常规则时效果最好。当数据间距不均匀时，这种方法可能产生非常不直观的形状，不推荐使用。
Chord Length 弦长参数化根据相邻数据点之间的相对距离计算数据的参数化。它是最常用的方法，因为它往往能产生最准确的结果。
Centripetal 向心参数化与弦长类似，但当数据有非常尖锐的拐角时效果更好。
  • Uniform uniform -
  • Chord Length chrdlen -
  • Centripetal centrip -
V Data Parameter dataparmv - V 数据参数化与 U 数据参数化相同，但当输入是曲面时它作用于 V 方向。输入是面时不使用。
  • Uniform uniform -
  • Chord Length chrdlen -
  • Centripetal centrip -
U Wrap closeu - 此菜单决定拟合曲线是否闭合，或拟合曲面是否在 U 参数方向环绕。选项为打开（Off）、闭合（On），或继承输入图元的闭合类型。
  • Off nonewu -
  • On wu -
  • If Primitive does ifprimwu -
V Wrap closev - 此菜单决定拟合曲面是否在 V 参数方向环绕。选项为打开（Off）、闭合（On），或继承输入图元的闭合类型。输入是面时忽略 V Wrap。
  • Off nonewv -
  • On wv -
  • If Primitive does ifprimwv -
Fit Corners corners - 指定进行局部曲线插值时是否保留数据中的转角。

操作符输入

  • Input 0: -

Info CHOP 通道

Fit SOP 的额外信息可以通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
