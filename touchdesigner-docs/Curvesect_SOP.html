Curvesect SOP

摘要

Curvesect SOP 用于求两个或多个面（多边形、Bézier 和 NURBS 曲线）之间的交点或最小距离点，或求面与多边形曲面或样条曲面之间的交点或最小距离点。

curvesectSOP_Class

参数 - Curvesect 页

Face Group leftgroup - 要操作的面（NURBS、Bézier、多边形）子集。接受模式匹配，详见 Pattern Matching。
Cutter Group rightgroup - 要与之相交的面或样条曲面子集。接受模式匹配，详见 Pattern Matching。
Find All Intersections xsect - 如果面接触到切割图元，则计算交点。如果不勾选该按钮，则只会找出最小距离点。目前尚不支持求面与曲面之间的最小距离。
Tolerance tolerance - 确定交点的精度。
Method method - - 在「Cut」或「Extract」操作之间选择。
  • Cut cut -
  • Extract extract -
Left Face Pieces left - - 选择左侧面要保留的部分：
  • Keep All lkeepall - 交点生成的所有面段。
  • Keep Odd-numbered Ones lkeepodd - 奇数面段：1、3、5…
  • Keep Even-numbered Ones lkeepeven - 偶数面段：0、2、4…
  • Keep None lkeepnone - 删除整个面。
Right Face Pieces right - - 选择右侧面要保留的部分：
  • Keep All rkeepall - 交点生成的所有面段。
  • Keep Odd-numbered Ones rkeepodd - 奇数面段：1、3、5…
  • Keep Even-numbered Ones rkeepeven - 偶数面段：0、2、4…
  • Keep None rkeepnone - 删除整个面。
Affect affect - - 选择要操作的输入：
  • Left Input left - 从左侧输入的面中提取。
  • Right Input right - 从右侧输入（面或曲面）中提取。
  • Both Inputs both - 同时从左侧和右侧输入中提取。
Extract Point extractpt - 如果右侧输入是曲面，则在点提取和等参线提取之间选择；如果右侧输入是面，则只提取点。
Keep Original keeporiginal - 使用 Extract 方法时，开启此项会把原始几何保留并连接到第一个输入（input0）。

示例

圆

  1. 放置两个 NURBS Circle SOP，其中一个在 X 和 Y（不是 Z）上稍微偏移。
  2. 把它们的输出连接到 Curvesect SOP，并将其设为显示 SOP。
  3. Method 设为 Cut。对于 Left Face，选择 Keep Odd-numbered Ones。
  4. 你可以提取曲线相交处内侧（偶数）或外侧（奇数）的部分。

星形

  1. 用 Model SOP 建模一条星形的闭合 NURBS 曲线。
  2. 放置一个 NURBS Circle SOP。
  3. 把它们连接到 Curvesect SOP，并将其设为显示 SOP。
  4. 它会根据与 NURBS 圆的相交情况生成五条独立的 NURBS 曲线。
  5. 可以再接一个 Join SOP，把各条 NURBS 曲线重新连接成一条新的连续曲线。它会平滑地连接剩余的段。

沿路径爬行的行为

  1. 放置一个新的 Font SOP，然后放一个 Circle SOP。Circle SOP - Type 设为 NURBS，Radius 0.1, 0.1；Centre -3, 0.3, 0.2。Font SOP - Text 设为「Creep Along Me」。
  2. 接一个 Curvesect SOP，让 Font 和 Circle SOP 分别连接到第一个和第二个输入。把 Tolerance 改为 1.0，并启用 Extract 操作。关闭 Find All Intersections。将其设为显示 SOP。
  3. 启用 Font 和 Circle SOP 的 template 标记（按住 S 单击）。
  4. 按 Home 复位视图，并在 Viewport 选项中启用 Point 显示。
  5. 当你把 Circle 的 X 值从 -3.0 改到 3.0 时，会看到若干点沿着文本中曲线的路径爬行。用 Copy SOP 把几何复制到这些点上，就得到一种沿预定路径创建不规则「群集行为」的简单方法。这之所以有效，是因为当圆在文本中的曲线上方移动时，曲线上离圆最近的点也会随之移动。
  6. 用 Model SOP 代替 Font SOP 来建模几条 NURBS 曲线作为要跟随的路径，可以更精确地控制运动。

操作符输入

  • Input 0: -

Info CHOP 通道

Curvesect SOP 的额外信息可通过 Info CHOP 查看。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
