WrnchAI CHOP

摘要

注意

License: 仅在 TouchDesigner Pro 中可用。

Note: Wrnch has be acquired by another company and it is no longer possible to obtain a license to use it anymore. This CHOP has been removed in 2022.20000+ builds.

该 CHOP 使用 wrnchAI 引擎在任何视频流中跟踪人体动作，会输出身体、面部和手部位置的通道。可同时以低延迟跟踪多个人，且该系统兼容所有摄像机和视频输入。TouchDesigner 使用 wrnchAI Edge SDK，所有计算都在本地实时完成，利用 Nvidia GPU 和 NVIDIA CUDA® 深度神经网络库（cuDNN）。这可以提供多人的 60fps 或更高（90-120fps 等）骨骼跟踪。 

Requires a separate license from wrnchAI to run in TouchDesigner. Requires Nvidia GPU on Windows OS and TouchDesigner Pro. 
Make sure to install TouchDesigner from the Full Installer, the Lite Installer does not include wrnchAI libraries.
快速入门指南

获得 wrnchAI 许可证（购买或试用）后，你将可以访问你的 wrnchAI licenses 页和 wrnchAI Edge Releases 页。

  1. 前往你的 wrnchAI licenses page。点击「key」图标，并将 Edge License Key 复制到该 CHOP 的「wrnchAI License」参数中。
  2. 前往 wrnchAI Edge Releases page 并下载 wrnchAI Engine for Win10。文件大致如下 wrnchAI-Engine-1.17.0-GPU-Win10.zip
  3. 下载后解压 .zip 文件，找到 wrnchAI trained models folder，用于该 CHOP 的「Model Folder」参数。它应位于此处：wrnchAI-engine-GPU-1.17.0-Windows-amd64/bin/wrModels

wrnchAI CHOP 需要一些时间初始化，然后即可进行跟踪。只有在引入新的 Model Folder 时才需要初始化，每次启动项目时无需重新初始化。

wrnchaiCHOP_Class

参数 - Setup 页

wrnchAI License license - 在此加入你的 wrnchAI 账户中的 Edge License Key。需要与 wrnchAI 分开的许可证。
Model Folder modelfolder - 指定包含已训练模型的文件夹路径。详情请参阅上方的快速入门指南。
GPU Device gpu - - 用于运行 wrnchAI 的可用 GPU 菜单。选择「Default」会使用 TouchDesigner 当前运行的同一块 GPU。
  • Default default - 使用 TouchDesigner 当前分配的同一块 GPU。
TOP top - 指定要处理以进行跟踪的 TOP。
Body 3D body3d - 为 3D 空间中的身体跟踪点启用通道（tx、ty、tz）。
Body 2D body2d - 为 2D 中的身体跟踪点启用通道（u、v）。
Body 3D IK body3dik - 为 3D 空间中的身体跟踪点启用 IK 通道（tx、ty、tz、rx、ry、rz 及相关的 roll 通道）。
Face Bounds facebounds - 为面部启用位置和边界通道（u、v、width、height）。
Face face - 为所有面部跟踪点启用位置通道（u、v）。
Hands Bounds handsbounds - 为手部启用位置和边界通道（u、v、width、height）。
Hands hands - 为所有手部跟踪点启用位置通道（u、v）。
Max Players maxplayers - 设置可跟踪的最大人数。每个人／玩家会创建一组新通道，前缀为 p1、p2、p3……等。

注意：参数滑块最大为 10，但通过设置更高的 Max Player 值可以跟踪更多玩家。

Aspect Correct UVs aspectcorrectuv - 调整 u 和 v 通道的值，以考虑 TOP 的宽高比。使用非正方形输入 TOP 时，开启此项可使 u、v 位置与图像对齐。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

wrnchAI CHOP 的额外信息可通过 Info CHOP 访问。

wrnchAI CHOP 特有的 Info 通道

  • initializing -
  • running -
  • processing_fps -
  • processing_time -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
