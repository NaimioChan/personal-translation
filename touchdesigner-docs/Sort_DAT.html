Sort DAT

摘要

Sort DAT 将按行或按列对表格 DAT 数据排序。

sortDAT_Class

参数 - Sort 页

Sort sortmethod - 决定表格将如何排序。
  • Rows (Specify Column Name) colname - 使用 Name 参数下指定的列对行排序。
  • Rows (Specify Column Index) colindex - 使用 Index 参数下指定的列对行排序。
  • Rows (Preserve Input Order) colpreserve - 使用输入的当前顺序。此排序允许将 Preserve First、Unique Output 和 Reverse Output 等参数应用于原始输入。
  • Columns (Specify Row Name) rowname - 使用 Name 参数下指定的行对列排序。
  • Columns (Specify Row Index) rowindex - 使用 Index 参数下指定的行对列排序。
  • Columns (Preserve Input Order) rowpreserve - 使用输入的当前顺序。此排序允许将 Preserve First、Unique Output 和 Reverse Output 等参数应用于原始输入。
Name name - 使用 Sort Specify Row/Column Name 时，在此参数中指定名称。如果排序名称未找到匹配项，输出将不排序。
Index index - 使用 Sort Specify Row/Column Index 时，在此参数中指定索引。如果排序索引为 -1 或超出范围，输出将不排序。
Order order - 确定排序类型。
  • Alphabetical alpha - 使用字母顺序排序。数字被视为字符，按其 ASCII 值排序。
  • Alphabetical with Numbers alphanum - 使用字母数字排序。
  • Numbers nums - 使用数值排序。所有字符均视为 0，保持输入顺序。
  • Random random - 随机排序表格，使用下方 Seed 参数。
Seed seed - 当 Sort Order 设为 Random 时的随机种子。
Ignore Case ignorecase - 当 Sort Order 设为 Alphabetical 或 Alphabetical with Numbers 时忽略大小写。
Preserve First preservefirst - 不对第一行或第一列重新排序（取决于 Sort 设为 Rows 还是 Columns）。
Unique Output unique - 在排序后的行/列中移除重复的行/列条目。
  • Off off -
  • Single Row/Col single -
  • Entire Rows/Cols entire -
Reverse Output reverse - 反转排序顺序。

  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。

Custom Extension customext - 指定自定义扩展名。

Info CHOP 通道

Sort DAT的额外信息可通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
