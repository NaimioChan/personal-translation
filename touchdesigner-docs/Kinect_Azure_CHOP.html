Kinect Azure CHOP

摘要

注意

OS: 此操作符仅在 Microsoft Windows 10 April 2018 or newer 操作系统下受支持。
Hardware: Kinect Azure System Requirements

Kinect Azure CHOP 可用于从 Microsoft Kinect Azure 摄像头或 Kinect 兼容的 Orbbec 摄像头（Femto Mega、Femto Bolt 等）获取身体跟踪信息，包括关节位置与旋转，以及 IMU 传感器数据。

此 CHOP 需要一个 Kinect Azure TOP 来连接摄像头并配置摄像头设置。并非所有配置设置都支持身体跟踪，例如 Passive IR 深度模式。同一时间只能有一种硬件类型使用身体跟踪（Microsoft 或 Orbbec）。如果项目中有多种硬件类型尝试使用身体跟踪，则只有最先计算的那个节点会被启用。

使用 Max Players 参数确定希望摄像头跟踪多少个人。TOP 会自动将设备发现的身体分配到可用的玩家位置。由于用于从深度摄像头图像检测玩家骨骼的系统，身体跟踪数据可能比图像数据滞后多帧。要更紧密地同步身体与图像数据，请在控制设备的主 Kinect Azure TOP 上使用「Sync Body Tracking To Image」选项（同步会增加图像采集的滞后）。

有关所跟踪关节及其层级的示意图，请访问 Microsoft's Kinect Azure SDK。

启用「IMU Channels」参数即可获取摄像头 IMU 传感器的加速度与旋转数据。

另请参阅 Kinect Azure TOP、Kinect Azure Select TOP。

kinectazureCHOP_Class

参数 - Kinect Azure 页

Active active - 启用/禁用身体跟踪数据的采集。主 Kinect Azure TOP 也必须处于活动状态才能接收数据。
Kinect Azure TOP top - 连接到摄像头的 Kinect Azure TOP 名称。
Max Players maxplayers - 设备应跟踪的玩家骨骼数量。如果摄像头找到的骨骼不足，多余的通道将被置零。
Relative Bone Rotations relbonerotations - 包含骨骼中所有骨骼的旋转数据。旋转以度为单位，相对于该骨骼的父级绕 XYZ 轴测量。
Absolute Bone Rotations absbonerotations - 包含骨骼中所有骨骼的绝对旋转数据。旋转以度为单位，相对于世界绕 XYZ 轴测量。
Bone Lengths bonelengths - 包含每根骨骼长度的通道。骨骼长度是关节与其父关节之间的距离。关节层级示意图见 Kinect Azure SDK。
World Space Positions worldspace - 包含骨骼在世界空间中的绝对位置（单位：米）的通道。
Color Image Positions colorspace - 包含骨骼在彩色图像 UV 坐标中的位置的通道。
Depth Image Positions depthspace - 包含骨骼在深度图像 UV 坐标中的位置的通道。
Aspect Correct UVs aspectcorrectuv - 缩放图像空间位置，使其与对应摄像头的宽高比匹配。
Mirror Image V Positions flipimagev - 翻转图像空间位置的 v 坐标，使 0,0 位于左上角。这是 2020.44130 版本之前的默认行为。
Mirror U Positions flipskelu - 镜像上述 Color Image Positions 与 Depth Image Positions 的 U 坐标；当这些图像在 U 方向被翻转（像镜子一样沿 x 轴翻转）时很有用。
Bone Confidence confidence - 传感器对某个关节位置与旋转正确的置信度。可以是以下值之一：
  • 0 - 关节超出范围（离摄像头太远）
  • 1 - 传感器看不到该关节，其位置根据相邻关节推算
  • 2 - 中等置信度。传感器对关节的位置/旋转相当有把握。这是传感器目前能给出的最高置信度。
  • 3 - 高置信度。保留供将来使用。
IMU Channels imuchans - 包含来自摄像头 IMU 传感器的温度、加速度与旋转数据。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

可通过 Info CHOP 访问 Kinect Azure CHOP 的额外信息。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
