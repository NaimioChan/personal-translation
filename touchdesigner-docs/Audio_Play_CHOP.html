Audio Play CHOP

摘要

Audio Play CHOP 通过任意已连接的音频输出设备，使用 DirectSound 播放声音文件。它支持最高 48.000 kHz 的 .aif、.mp3、.mid、.wav 和 .m4a 文件，其中可包含单声道、立体声甚至最多 5.1 通道。随后可将音频通道路由到 DirectSound 使用的任意扬声器位置。见下方 Outputs 一节。

注意：使用 Audio Play CHOP 时，音频采样不会进入或经过 TouchDesigner，因此你在 CHOP 中看不到它们，也无法在 CHOP 中处理它们。Audio Play CHOP 会启动一个外部进程，打开文件并将其直接发送到计算机的音频输出。若想在 TouchDesigner 内处理音频，或将其输出到 Movie File Out TOP 或 Audio Device Out CHOP，请使用 Audio File In CHOP。

Audio Play CHOP 包含一个名为 state 的通道。任何文件正在播放时该通道为 1，否则为 0。

第一个输入（Input 0:Triggers）用于触发音频文件播放。第二个输入（Input 1: Volume）可用于控制音量，若未连接输入则使用 Volume 参数。第三个输入（Input 2: Pan）用于声像，无输入时假定为居中。使用 DAT List 参数时，输入可包含多个通道，以分别操控每个文件。多个 Audio Play CHOP 可同时输出到不同设备。

它也可以通过下方的 Trigger 参数触发，但此时若通过 DAT List 指定多个文件，触发时所有文件将同时播放。

声音文件也可以通过 play() 方法 audioplayCHOP_Class 触发。某些高级选项只能通过 audioplayCHOP_Class 使用。

文件可以从磁盘或网络读取。指定 URL 时使用 http://。

audioplayCHOP_Class

参数 - AudioPlay 页

Device device - 可用音频输出设备的菜单。选择 default 会将音频设备设为 Windows 控制面板里「声音」下「播放」中所选的设备。
Outputs outputs -
Sound File file - .aif、.mp3、.mid、.wav 或 .m4a 音频文件。文件可以是单声道或立体声。
DAT List datlist - 链接到一个 Table DAT，可用作可供选择的音频文件列表。使用 DAT List 时，CHOP 上的第一个输入（Input 0: Triggers）可包含多个通道，以分别触发列表中的文件。使用 audioplay 命令可直接指定索引。
Volume volume - 0 = 静音，1 = 满音量。使用第二个输入（Input 1: Volume）或 Python 的 .play(volume=val) 方法将覆盖此参数的值。
Mode mode - - 决定使用第一个输入触发时音频的触发方式。
  • Play While On on - 输入为 1 时播放。
  • Trigger trigger - 输入变为 1 时触发一次。
  • Loop loop - 输入变为 1 时播放并循环。
Trigger trigger - 触发音频播放。
Cook Every Frame cookalways - 强制 CHOP 每帧计算。

参数 - Output 1 页

Stereo Mode stereo - 将输出设为仅 2 个通道，前左和前右。

Outputs - 此页及接下来的 Output 2 页上的输出用于路由到音频设备的不同扬声器输出。并非所有设备都支持所有输出。对于每个扬声器输出，你可以将文件的任意通道路由到其中播放。例如，可以轻松将文件的前左通道输出到所有前左扬声器输出，或将前左通道同时输出到前、后扬声器输出。每个输出参数的值决定它播放文件中的哪个通道，见下文。

File's channel mapping for outputs

  • -1 - 此输出无音频播放
  • 0 - 将播放文件的前左通道
  • 1 - 将播放文件的前右通道
  • 2 - 将播放文件的后左通道
  • 3 - 将播放文件的后右通道
  • 4 - 将播放文件的中央通道
  • 5 - 将播放文件的重低音或低频通道

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Audio Play CHOP 的额外信息可通过 Info CHOP 访问。

Audio Play CHOP 的专属信息通道

  • device_default -
  • sample_state0 -
  • sample_time0 -
  • sample_length0 -
  • sample_channels0 -
  • queue_read_pos0 -
  • queue_write_pos0 -
  • queue_length0 -
  • sample_name0_Notify -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
