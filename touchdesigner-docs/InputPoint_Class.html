InputPoint 类

Input Point 是 Point 对象的一个特例，仅在 Point SOP's 参数中可用。

以下成员是 Input Point 独有的。其他成员及更多信息请参阅 Point Class。

成员

color → TDU.Color (Read Only):

此点的颜色。它与 Cd 属性不同，因为如果 inputPoint 本身没有颜色，它可以来自顶点。

normal → TDU.Vector (Read Only):

此点的法线。它与 N 属性不同，因为如果 inputPoint 本身没有法线，它可以来自顶点或目标点。

sopCenter → TDU.Position (Read Only):

获取 inputPoint 所属几何的重心坐标。由于内部优化，这比其他获取 SOP 几何中心的方法更快。它以 tdu.Position 表示。

方法

没有该操作符专属的方法。
