ParGroupCollection 类

ParGroupCollection 类可用于访问 ParGroups。要访问某个 parGroup，需要使用其内部名称，可将鼠标悬停在参数名上，查看弹出的提示来获得。另请参阅 ParGroup Class。操作符的此实例可在 OP.parGroup 中找到。

成员

该对象为组件中的每个 parGroup 包含一个成员。可以使用以下方式读取值：

a = op('geo1').par.t

也可以使用以下方式修改值：

a = op('geo1').parGroup.tx = (1,1,1) # transform 有 3 个值
a = op('geo1').parGroup.lookat = 'null1'

owner → OP (Read Only):

此对象所属的 OP。

方法

[name]→ Par:

使用 [] 下标和赋值运算符可以方便地访问 ParGroups。

  • name - 必须是精确的字符串名称。不支持通配符。如果未找到则返回 None。
p = op('base1').parGroup['Myfloat5']
