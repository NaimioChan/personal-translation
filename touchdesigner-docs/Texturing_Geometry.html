几何贴图

需要的纹理坐标

  • 几何需要有 uv Texture Coordinates 才能在其上应用纹理或贴图
  • 要创建纹理坐标，请设置生成器 SOP 的 Texture Coordinate 参数，或在网络下游使用 Point SOP 或 Texture SOP
  • Texture SOP 让你控制 uv 坐标如何映射到表面

把图像用作纹理贴图

  • 使用 Movie File In TOP 把图像（静态图像或影片）读入 TOP
  • 在材质的 Color Map 参数中指定 TOP 的路径（Constant MAT、PBR MAT、Phong MAT 和 Point Sprite MAT 都有 Color Map）
  • 可以把 TOP 拖放到 Color Map 参数上
  • 把 MAT 指定给 Geometry COMP（包含 SOP 几何）的 Material 参数，从而把材质应用到几何上。

使用图像和影片作为材质中 Color Map 的示例文件。
