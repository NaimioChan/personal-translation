Audio Filter CHOP

摘要

Audio Filter CHOP 会滤除低频、高频、低频与高频，或滤除中频范围。

低通滤波器去除声音中的较高频率，而高通滤波器减弱声音的低频。带通滤波器用于提取某个频率范围（例如从背景噪声中提取人声），带阻滤波器用于切除某个频率范围。

如果某个频率位于通带之外，该频率处的声音幅度将被衰减。频率越远离通带，衰减越多。

Cutoff 频率也称为「半功率」频率。处于截止频率的波将被衰减至半功率。

滤波器的 Rolloff 决定在 Cutoff 频率处下降的速度。低 rolloff 会产生平缓的滤波衰减（能听到更多频率范围之外的声音），高 rolloff 会产生陡峭的滤波衰减。

更多说明请参阅 audio filter。

你可以将 Oscillator CHOP 的白噪声输入 Audio Filter CHOP，再把结果送到 Audio Spectrum CHOP，以观察 Audio Filter CHOP 的效果。Audio Filter CHOP 内部以 4 极点滤波器实现。

把 Dry / Wet 参数移到 Dry 将还原未受影响的输入信号。

参数 - Filter 页

Filter filter - - 滤波器类型：
  • Low Pass lowpass - 低于 High Cutoff 的所有频率都通过滤波器（「通带」）。
  • High Pass highpass - 高于 Low Cutoff 的所有频率都通过。
  • Band Pass bandpass - Low 与 High Cutoff 之间的所有频率都通过。
  • Band Reject bandreject - 高于 High Cutoff 且低于 Low Cutoff 的所有频率都通过。
Cutoff Units units - - 滤波器截止频率可用 Hz（菜单设为 Frequency）或 10 的幂（菜单设为 Logarithmic）表示。它会启用下面两个 Filter Cutoff 参数之一。
  • Logarithmic logarithmic -
  • Frequency frequency -
Filter Cutoff (Hz=10**val) cutofflog - 以 10 的幂表示的滤波器截止频率，值 0 对应 1 Hz（10**0），值 1 为 10 Hz（10**1），值 2 为 100 Hz（10**2），值 3 为 1000 Hz，值 4 为 10,000 Hz，值 4.5 为 31,623 Hz。以这种形式表示时，参数范围相对于人耳听觉更有意义，因为参数增加 1 约提高 3 个八度。
Filter Cutoff (Hz) cutofffrequency - 以 Hz（每秒周数）表示的滤波器截止频率。此参数设为 1000 与上述参数设为 3 的效果完全相同。
Filter Resonance resonance - 增大 resonance 会提升截止频率附近通过频率的响度。
Roll-Off (dB per Octave) rolloff - Rolloff 决定截止频率附近电平下降的程度。此参数会使其每八度下降 12 decibels（dB），更极端时为每八度 24 分贝。12 与 24 分贝对应约 1/4 和 1/16 的电平。
Dry / Wet Mix drywet - 当此参数从 1（Wet）向 0（Dry）减小时，会移除滤波器的效果。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Cutoff 调制通道输入

第二个输入是 Cutoff Modulation Channels，它允许在 CHOP 的时间切片间隔内（通常为 1/60 秒）更改滤波器参数。这可以避免快速更改参数时出现可听见的阶梯感。

你可以送入一个名为 cutofffrequency 的通道来覆盖参数值。若想非常快地调整截止频率，可以这样做。参数只能以时间轴速率变化，通常为 1/60 秒。快速变化时，频率的阶梯感很明显。为改善这一点，可以送入一个采样率更高的 cutofffrequency 通道，例如 400，这可以在 LFO CHOP 等 CHOP 中设置。

Info CHOP 通道

Audio Filter CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
