BlackTrax CHOP

摘要

注意

License: 仅在 TouchDesigner Pro 中可用。

BlackTrax CHOP 将提供来自 BlackTrax Motion Tracking Systems 的运动跟踪数据，它是由 CAST Software 开发的基于视觉的实时跟踪系统，专长于大型演出。BlackTrax Beacon（「BTBeacons」）附着在表演者或刚性物体上，BlackTrax 系统可精确跟踪 Beacon 的位置、旋转、速度和加速度。

BlackTrax CHOP 会接收来自 BlackTrax Motion Tracking Systems 的跟踪数据。见 BlackTrax。

BlackTrax CHOP 与 BlackTrax 系统配合工作。BlackTrax 最多跟踪 85 个 BlackTrax Beacon，并将其位置、旋转、速度和加速度数据在 RTTrPM Packets 内发送到 TouchDesigner。每个 Beacon 最多可附着 3 个 LED，这些 LED 也可以在 TouchDesigner 中独立跟踪。每个 Beacon 都有一个在 BlackTrax 软件中指定的 ID，必须使用 Mapping Table 将该 Beacon ID 正确映射到 TouchDesigner 中的 CHOP 通道。如果 ID 是递增的，也可以使用「Output Format」中的「From Max Beacons」选项。

服务器设置

服务器软件应设置为以 WYSIWYG 坐标系发送数据（这应为默认设置）。旋转应以欧拉角发送，而不是四元数。TouchDesigner 应支持两种字节序设置，但最好保持其默认值。

参数 - BlackTrax 页

Active active - 开启时，CHOP 接收发送到网络端口的信息。关闭时，不进行任何更新。
Port port - 接收数据包的端口。
Protocol protocol - - 要使用的网络协议。更多信息请参阅 Network Protocols 一文。
  • Messaging (UDP) msging -
  • Multi-Cast Messaging (UDP) multicastmsging -
Network Address netaddress - 使用 Multicast 时，这是监听数据包的地址。
Sample Rate samplerate - 设置此 CHOP 的采样率。
Output Format outputformat - - 指定 CHOP 通道的格式（即添加多少个 Beacon）。「From Mapping Table」会为映射表中的每一行向 CHOP 添加一个 Beacon。「From Max Beacons」会添加「Max Beacons」参数中指定的数量。
  • From Mapping Table fromtable -
  • From Max Beacons frombeacons -
Max Beacons maxbeacons - 指定要向 CHOP 添加多少个 Beacon。与「From Max Beacons」输出格式配合使用。
Centroid centroid - 启用时，添加 Beacon 的平移和旋转通道。
Velocity velocity - 启用时，添加 Beacon 的速度通道。
Acceleration acceleration - 启用时，添加 Beacon 的加速度通道。
LEDs leds - 启用时，为 Beacon 中的每个 LED 添加位置通道。
Reset Channels reset - 开启时，清除任何已存储的 Beacon 并移除任何过期数据。
Reset Pulse resetpulse - 立即清除任何已存储的 Beacon 并移除任何过期数据。
Mapping Table mappingtable - 一个将 beacon ID 映射到 CHOP 通道（beacon0、beacon1 等）的 DAT 表格。第一行映射到 beacon0，第二行映射到 beacon1，依此类推。Beacon ID 是唯一的非负整数，在 BlackTrax 应用程序中指定。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

可通过 Info CHOP 访问 BlackTrax CHOP 的额外信息。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
