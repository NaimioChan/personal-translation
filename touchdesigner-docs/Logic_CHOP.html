Logic CHOP

摘要

Logic CHOP 首先把它所有输入 CHOP 的通道转换为二进制（0 = 关，1 = 开）通道，然后用各种逻辑运算组合这些通道。

注意： Logic CHOP 已被更方便的操作符取代，如 CHOP Execute DAT 或 Text DAT，它们会在 CHOP 通道变化时运行其脚本。

Logic CHOP 对 CHOP 通道中的采样执行逻辑运算。一个 CHOP 的通道可合并为一个通道，多个 CHOP 也可合并为一个 CHOP。

使用一个输入 CHOP 时，你可以反转每个采样的值。你也可以用一个通道的采样对其他通道的采样做逻辑运算，把 N 个通道缩减为一个。可通过应用「or」「and」等来组合。

使用两个或更多 CHOP 输入时，你可以把一个 CHOP 中的通道与所有其他 CHOP 中的通道合并，把 N 个 CHOP 缩减为 1 个。

要在通道或 CHOP 之间做数学运算（加、乘……），请使用 Math CHOP。

参数 - Logic 页

Convert Input convert - - 此菜单决定把输入转换为二进制的方法：
  • Off When Zero nonzero - 通道值为零时返回逻辑 0；
    非零值返回 1。
  • Off When Zero Or Less pos - 通道值为零或更小时返回逻辑 0；值为正时返回 1。
  • Off When Outside Bounds bound - 通道值超出下方 Bounds 参数设定的范围时返回 0。
  • On When Value Changed valchange - 通道值发生变化时返回 1。
  • On When Channel Name Changed namechange - 通道名发生变化时返回 1。

Channel Pre OP preop - - 经过 Convert Input 阶段转换后，Channel Pre OP 为每个输入采样定义一元运算：
  • Off off -
  • Invert invert - 把 0 变为 1，把 1 变为 0。
  • Toggle toggle - 输入通道每次从 0 到 1 的跳变，都会在当前状态 0 与 1 之间切换。
  • Radio Button radio - 每个输入同时只能有一个通道开启。若另一个通道开启，先前「开启」的通道会被关闭。
  • Last Two On radio2 - 这类似 Radio Button，但最多保持两个通道开启。若后接 Lag CHOP，可用于在两对姿势之间混合。
  • Rising Edge rise - 在每个通道从关变为开的位置，仅保持一个采样的开启。
  • Falling Edge fall - 在每个通道从开变为关的位置，仅保持一个采样的开启。
Combine Channels chanop - - 取第一个输入并合并其通道，然后取第二个输入并合并其通道，依此类推。
  • Off off -
  • And and -
  • Or or -
  • Exclusive Or xor -
  • Not And nand -
  • Not Or nor -
  • Equivalence eqv -
  • Lowest Index On lowest -
  • Highest Index On highest -
Combine CHOPs chopop - - Combine CHOPs 会合并每个 CHOP 的第一个通道、每个 CHOP 的第二个通道，等等。输入之间的通道可按编号或名称合并。合并（逻辑）运算有：
  • Off off -
  • And and - 所有输入都开时开启，否则关闭。
  • Or or - 至少一个输入开启时开启，否则关闭。
  • Exclusive Or xor - 一个输入开启（但不多于一个）时开启。
  • Not And nand - 所有输入都开启时关闭，否则开启。
  • Not Or nor - 至少一个输入开启时关闭，否则开启。
  • Equivalence eqv - 输入相等（全开或全关）时开启，否则关闭。
  • Lowest Index On lowest - 给出当前开启的通道中的最低索引，
    若无通道开启则为 -1。
  • Highest Index On highest - 给出当前开启的通道中的最高索引，
    若无通道开启则为 -1。

Match by match - - 输入之间的通道按 Channel Name 或 Channel Number 匹配。
  • Channel Number index -
  • Channel Name name -
Align align - - 起始帧不同的输入可以对齐。请参阅 Align Options 一节。
  • Automatic auto -

  • boundmin -

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Logic CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
