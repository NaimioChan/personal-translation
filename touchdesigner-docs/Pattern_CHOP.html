Pattern CHOP

摘要

Pattern CHOP 在通道中生成样本序列。与 Wave CHOP 不同，它的用途是生成与时间（秒或帧）无关的样本数组。

它适用于曲线生成，例如查找表、可转换为 SOP 的简单形状、生成传给 Geometry COMP 以创建实例的通道，以及其他非基于时间的曲线生成，且几乎无需在 Python 中编写表达式。

所有默认值都以样本为单位，而非秒或帧（不过与所有 CHOP 一样，它带有采样率）。没有起止，只有以样本为单位的 Length。

提示：要以样本为单位显示 CHOP 查看器，请打开 Viewer Active，并将 RMB → Units 改为 Samples。

Pattern CHOP 可选地接收一个输入 CHOP 以匹配长度和采样率，并通过 Combine Channels 菜单选择追加（Appends）或插入（Inserts）新通道、替换（Replaces）输入通道、相加（Adds）输入通道或相乘（Multiplies）输入通道。

无论 CHOP 有多少个样本长，Pattern CHOP 默认在 CHOP 的长度上显示曲线的一个周期。

Tip: Customizing each channel: Pattern CHOP 的 python 对象有一个 chanIndex 成员，因此如果 Pattern 生成三个通道，你可以在任意参数中放入类似 [1, 3, 7][me.chanIndex] 的内容来为每个通道定制其值。例如，在 Type 参数中放入表达式 ['sin', 'cos', 'ramp'][me.chanIndex] 可获得 3 种不同的曲线类型。

参数 - Pattern 页

Type wavetype - 图案一个周期的形状。
  • Constant const - (1)
  • Sine sin - （-1 到 1）
  • Cosine cos - （-1 到 1）
  • Triangle tri - （-1 到 1）
  • Ramp ramp - (0-1)
  • Ramp Samples rampsamples - （0 到 numSamples-1）
  • Square square - （-1 到 -1）
  • Pulse pulse - (0-1)
  • Random random - (0-1)
  • Random per Cycle randomcycle - 一个周期内的所有样本都具有相同的随机生成值。
  • Random Non-Repeating Integers randomnonrepint - 此波形类型与 Randomize 脉冲配合使用。在每次 Randomize 脉冲之间，各样本处的随机值不会重复。例如，在最简单的情况下通道长度为 1，每次脉冲 Randomize 后样本 1 的随机值都会与脉冲前不同。
  • Step step - （0 到 1）阶跃函数
  • Cyclic Ramp rampcyclic - （0 到 (numSamples -1) / numSamples）。与 Ramp 类型相同，但相位偏移时值不会超出范围。

Number of Cycles numcycles - 设置 Type 形状在 Length 上重复的周期数（Random 除外）。

Bias bias - 将 Triangle 类型变为锯齿波，并将 Square 类型设为可变宽度。
Seed seed - 随机类型的种子。

参数 - Channel 页

Channel Names channelname - 可以用简单的模式创建许多通道，例如 chan[1-20] 可从 chan1 到 chan20 生成 20 个通道，或 t[xyz] 可生成 tx、ty 和 tz。此参数及所有 Options 的说明见 Common CHOP Parameters 一节。请参阅 Scope and Channel Name Matching Options。
Combine Channels combine - 如果连接了输入 CHOP，则采用输入 CHOP 的长度和采样率，并且
  • Off off - 仅采用输入的长度和采样率。
  • Append append - 将新的 Pattern CHOP 通道追加到最后一个输入通道之后。
  • Insert insert - 将新通道插入到第一个输入通道之前。
  • Replace replace - 按通道名称匹配，替换输入通道。
  • Add add - 按通道名称匹配，将输入通道加到生成的通道上。
  • Multiply multiply - 按通道名称匹配，将输入通道与生成的通道相乘。
Sample Rate rate - 通道的采样率，单位为每秒采样数。
Extend Left left - 左右延伸条件（范围之前/之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道起点之前的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Extend Right right - 右侧延伸条件（范围之前/之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道终点之后的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Default Value defval - 用于 Default Value extend 条件的值。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

操作符输入

  • Input 0: -

Info CHOP 通道

可通过 Info CHOP 访问 Pattern CHOP 的额外信息。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
