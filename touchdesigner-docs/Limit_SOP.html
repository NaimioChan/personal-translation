Limit SOP

摘要

Limit SOP 根据 CHOPs 送入的采样创建几何。它会在每个采样点处创建几何。可在 Channels Page 上用 Output Type 参数创建不同类型的几何。

limitSOP_Class

参数 - Channels 页

CHOP chop - 指定哪个 CHOP Network / CHOP 包含要获取的采样数据。
Rotate Order rord - - 指定 Rotate Channel X / Y / Z 通道的应用顺序。
  • Rx Ry Rz xyz -
  • Rx Rz Ry xzy -
  • Ry Rx Rz yxz -
  • Ry Rz Rx yzx -
  • Rz Rx Ry zxy -
  • Rz Ry Rx zyx -
X Channel chanx - 用于指定点位置的通道 tx。
Y Channel chany - 用于指定点位置的通道 ty。
Z Channel chanz - 用于指定点位置的通道 tz。
Rotate Channel X chanrx - 用于指定每个点上创建的几何的旋转数据的通道。仅在 Output Type 为「Polygon at Each Point」或「Primitive Circle at Each Point」时使用。
Rotate Channel Y chanry - 用于指定每个点上创建的几何的旋转数据的通道。仅在 Output Type 为「Polygon at Each Point」或「Primitive Circle at Each Point」时使用。
Rotate Channel Z chanrz - 用于指定每个点上创建的几何的旋转数据的通道。仅在 Output Type 为「Polygon at Each Point」或「Primitive Circle at Each Point」时使用。
Radius Channel chanrad - 统一控制每个点上创建的几何的半径。Radius 通道会与 Output Page 上的 Radius 参数相乘。
Radius Channel X chanradx - 控制相应轴上半径的通道。Radius 通道会与 Output Page 上的 Radius 参数相乘。
Radius Channel Y chanrady - 控制相应轴上半径的通道。Radius 通道会与 Output Page 上的 Radius 参数相乘。
Radius Channel Z chanradz - 控制相应轴上半径的通道。Radius 通道会与 Output Page 上的 Radius 参数相乘。
Alpha Channel chanalpha - 控制点的 alpha，使你可以控制在这些点处创建的任何几何的 alpha。

注意： 如果使用 Copy SOP，请打开 Copy SOP 的 Attributes Page 中的 Use Template Point Attributes 选项，使几何能够继承点属性。

Red Channel chanr - 这些通道控制点的颜色，或在这些点处创建的任何几何的颜色。
Green Channel chang - 这些通道控制点的颜色，或在这些点处创建的任何几何的颜色。
Blue Channel chanb - 这些通道控制点的颜色，或在这些点处创建的任何几何的颜色。
Texture W texturew - 控制点的 w 纹理偏移。这最常用作帧偏移或时间偏移，以距当前帧或图像序列第 1 帧的帧数表示。

参数 - Custom 页

允许向创建的几何添加自定义属性。使用 + 按钮添加更多参数，以添加更多自定义属性。

Custom Attribute customattr - 要添加到所创建几何的自定义属性序列。
Name customattr0name - 指定自定义属性的名称，例如 pscale、age，或任何自定义名称。
Channel Zero customattr0chan0 - 选择要赋给属性 [0] 索引的通道。即 pscale[0]
Channel One customattr0chan1 - 选择要赋给属性 [1] 索引的通道。即 pscale[1]
Channel Two customattr0chan2 - 选择要赋给属性 [2] 索引的通道。即 pscale[2]
Channel Three customattr0chan3 - 选择要赋给属性 [3] 索引的通道。即 pscale[3]

参数 - Output 页

Output Type output - - Limit SOP 由其采样数据生成的几何类型。
  • Polygonal Line line - 为每个采样创建一个点，并用多边形线将它们连接起来。
  • Polygon at Each Point polys - 在每个采样点处放置一个多边形。多边形的点数由 Divisions 定义。
  • Primitive Circle at Each Point circles - 在每个采样点处放置一个图元圆。
  • Sphere at Each Point spheres - 在每个采样点处放置一个图元球。
  • Poly Sphere at Each Point polyspheres - 在每个采样点处放置一个多边形球。球的频率由 Divisions 定义。
  • Tubes tubes - 沿路径创建一根管。管的截面由 Divisions 定义。
  • Strips strips - 沿路径创建一条带。带的点数由 Divisions 定义。
Divisions divisions - 仅对以下 Output Type 有效。
  • Polygon at Each Point - 每个多边形的点数。
  • Poly Sphere at Each Point - 每个多边形球的频率。
  • Tubes - 管截面上的点数。
  • Strips - 带截面上的点数。
Radius rad - 所创建几何的半径。对「Polygonal Line」禁用。
Smooth Flip flipsmooth - 动态控制一系列点上每个几何实例的扭转，以避免沿路径定向几何时有时会出现的逐帧翻转。
Limit dolimit - - 为输出几何的位置创建边界框。下拉菜单决定超出有界区域时的行为。
  • Off off - 关闭边界区域。
  • Clamp clamp - 将位置钳制到指定值。
  • Loop loop - 让位置在边界区域之间循环。
  • Zigzag zigzag - 让位置在边界区域之间来回折返。
X Limit xlimit - - 当 Limit 激活时，用于设置边界区域边缘的参数。
  • xlimitmin -
  • xlimitmax -
Y Limit ylimit - - 当 Limit 激活时，用于设置边界区域边缘的参数。
  • ylimitmin -
  • ylimitmax -
Z Limit zlimit - - 当 Limit 激活时，用于设置边界区域边缘的参数。
  • zlimitmin -
  • zlimitmax -
Apply Texture texture - 为所创建的几何应用 u、v、w 纹理坐标。
Scale texscale - - 按特定量缩放纹理坐标。
  • texscale1 -
  • texscale2 -
Offset texoffset - - 按特定量偏移纹理坐标。
  • texoffset1 -
  • texoffset2 -
Orient to Path orient - 如果选择此选项，对象将沿路径定向。要查看路径的样子，请把 Output Type 改为「Polygonal Line」。当 Output Type 为「Polygon/Primitive Circle at Each Point」时，每个对象的正 Z 轴会沿路径指向。当 Output Type 为「Tubes/Strips」时，所创建几何的截面会沿路径指向。
Lookat Object lookat - 必须勾选 Orient to Path，Lookat Object 才会生效。这让你可以通过命名希望几何朝向（指向）的对象来定向几何。指定该对象后，即使你移动它，几何也会持续朝向它。Look At 参数会让每块几何分别指向另一个对象的原点。
Rotate Polys dorotate - - 使用 Rotate 参数（见下）旋转每个点处的几何。仅对 Output Type 为「Polygon/Primitive Circle at Each Point」时有效。
  • Off off - 不旋转多边形。Rotate 参数会变灰。
  • On on - 将 Rotate 的值均等地加到所有多边形上。
  • Cumulative cum - 将 Rotate 的值累积地加到多边形上（即随每个多边形递增）。
Rotate rotate - - Rotate Polys 参数的旋转通道 rx、ry 和 rz。
  • X rotatex -
  • Y rotatey -
  • Z rotatez -
Compute Normals normals - 为所创建的几何计算法线。

Info CHOP 通道

Limit SOP 的附加信息可以通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
