Import Select SOP

摘要

Import Select SOP 用于导入并加载 USD COMP 和 FBX COMP 中定义的几何类型图元。它基本上能加载 USD COMP 或 FBX COMP 支持的任何几何类型，例如 Mesh、Points、NURBS Curves 或 Patches、Basis Curves。每个几何代表加载文件中的一个图元，也可以是为提升性能而合并在一起的一组图元。

在 USD COMP 和 FBX COMP 中，如果 Import Select SOP 渲染的是合并后的几何，则会在该 SOP 旁创建一个 Info DAT 操作符，它表示导入文件内/来自导入文件的图元原始路径，这有助于用户查看当前 SOP 由哪些几何组成。 Import Select SOP 可以在 Playback 页中使用自己的动画控制，也可以使用其父 COMP 的设置。

导入的几何可以从 GPU 或 CPU 直接加载，取决于父 COMP 节点上的 Straight To GPU 开关是否设为 ON。

参数 - General 页

Import Parent parent - 指定用于搜索素材的导入父级（例如 USD/FBX COMP）。未指定 COMP 时，默认在其路径中的第一个导入父级中搜索。
Geo Path geometry - 导入文件中的几何路径。
Reload reload - 从导入父级重新加载素材。
Compute Tangents comptang - 一个开关，用于为此 SOP 计算切线。

参数 - Playback 页

Use Parent Animation useparentanim - 一个开关，指定是使用父 COMP 的动画控制，还是为此 SOP 使用自定义设置。
Shift Animation Start shiftanimationstart - 一个开关，用于指定是否将动画移至导入文件中指示的动画起始处。
Sample Rate Mode sampleratemode - - 一个菜单，用于在 FPS 或自定义采样率之间选择。
  • File FPS filefps - 使用导入文件中所定义的 FPS。
  • Custom custom - 由 Sample Rate 参数指定的期望值。
Sample Rate samplerate - 用于指定动画的采样率（FPS）。此参数默认禁用，在 Sample Rate 菜单中选择 Custom 选项后即可启用。
Play Mode playmode - - 用于指定播放动画方式的菜单。
  • Locked to Timeline lockedtotimeline - 该模式把动画位置锁定到时间轴。此模式下 Play、Speed、Index、Cue 和 Cue Point 参数被禁用，因为时间轴直接绑定动画位置。
  • Specify Index specifyindex - 该模式允许用户通过下面的 Index 参数指定动画中的特定索引（位置）。需要随机访问动画中任意位置时使用此模式。
  • Sequential sequential - 该模式不论时间轴位置如何都持续播放（Index 参数被禁用）。下面的 Play、Speed、Cue 和 Cue Point 参数可用，提供一定控制。默认即为此值。
Initialize initialize - 将动画重置到初始状态。
Start start - 把动画重置到初始状态并开始播放。
Cue cue - 一个开关，设为 ON 时跳转到 Cue Point 并停留在该位置。仅在 Play Mode 为 Sequential 时可用。
Cue Pulse cuepulse - 按下时动画跳转到 Cue Point 并从该点继续。
Cue Point cuepoint - 将动画中的任意索引设为要跳转到的点。
Cue Point Unit cuepointunit - - 为 Cue Point 指定单位类型。更改此项会将先前的单位转换为所选单位。
  • Frames frames -
  • Seconds seconds -
  • Fraction fraction -
  • Index indices -
Play play - 一个开关，设为 ON 时使动画播放。仅当 Play Mode 中选择了 Sequential 模式时，此参数才可用/启用。
Index index - 当 Play Mode 设为 Specify Index 时，此参数显式设置动画位置。右侧的单位菜单可让你以下列单位指定索引：Index、Frames、Seconds 和 Fraction（百分比）。
Index Unit indexunit - - 为 Index 指定单位类型。更改此项会将先前的单位转换为所选单位。
  • Frames frames -
  • Seconds seconds -
  • Fraction fraction -
  • Index indices -
Speed speed - 这是一个速度倍数，仅在 Play Mode 为 Sequential 时生效。值为 1 是默认播放速度。值为 2 是双倍速度，0.5 是半速，依此类推。
Trim trim - 启用 Trim Start 和 Trim End 参数的开关。
Trim Start tstart - 从动画开头设定入点，可裁掉动画的起始部分索引。右侧的单位菜单可按索引、帧、秒或分数（百分比）指定该位置。
Trim Start Unit tstartunit - - 为 Trim Start 指定单位类型。更改后会把之前的单位换算为所选单位。
  • Frames frames -
  • Seconds seconds -
  • Fraction fraction -
  • Index indices -
Trim End tend - 从影片结尾设定出点，可裁掉动画的结束部分索引。右侧的单位菜单可按索引、帧、秒或分数（百分比）指定该位置。
Trim End Unit tendunit - - 为 Trim End 指定单位类型。更改后会把之前的单位换算为所选单位。
  • Frames frames -
  • Seconds seconds -
  • Fraction fraction -
  • Index indices -
Extend Left textendleft - - 确定父 COMP 如何处理位于 Trim Start 位置之前的动画位置。例如，若 Trim Start 设为 1，而动画当前索引为 -10，Extend Left 菜单决定动画位置如何计算。
  • Hold hold -
  • Cycle cycle -
  • Mirror mirror -
Extend Right textendright - - 确定父 COMP 如何处理位于 Trim End 位置之后的动画位置。例如，若 Trim End 设为 20，而动画当前索引为 25，Extend Right 菜单决定动画位置如何计算。
  • Hold hold -
  • Cycle cycle -
  • Mirror mirror -

Info CHOP 通道

Import Select SOP 的额外信息可通过 Info CHOP 访问。

特定的 Import Select SOP 信息通道

  • true_start_time -
  • true_end_time -

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
