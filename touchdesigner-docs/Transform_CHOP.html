Transform CHOP

摘要

Transform CHOP 接收各种格式的变换，对其应用操作，并以各种格式输出。它可用于：

  • 更改物体的位置和朝向。
  • 转换：将一种格式转换为另一种格式。
  • 将以某种变换顺序的一组变换通道，转换为变换顺序不同的等效通道组。
  • 更改动作捕捉数据或其他待校准数据的方向、起点和缩放，以匹配其他参考坐标系。

（另请参阅 Transform XYZ CHOP，了解如何对 XYZ 位置和向量进行变换。）

存在三种变换格式：

  • 使用欧拉角进行旋转的变换。这些由带后缀的通道定义：tx ty tz, rx ry rz, sx sy sz，以及可选的变换和旋转顺序 xord and rord。
  • 使用四元数进行旋转的变换。这些由带后缀的通道定义：tx ty tz, qx qy qx qw, sx sy sz，以及可选的变换顺序 xord。
  • 4x4 或 3x3 矩阵。这些由带后缀的通道定义：m00, m10, m20, m30, m01, m11... m33。记法为 m[row][col]。矩阵应为列主序，也就是说，平移部分应位于 m03, m13, m23。可以省略第 4 行和第 4 列，改用 3x3 矩阵。与其他格式不同，此格式不能任意缺少通道。必须提供 3x3 矩阵的 9 个通道或 4x4 矩阵的 16 个通道。

前两种变换格式可以缺少通道，此时将使用默认值：平移和旋转为 0，缩放为 1，四元数为 (0,0,0,1)。

输入通道常常来自 Object CHOP 或 Parameter CHOP。例如：

  • geo1:tx geo1:ty geo1:tz geo1:rx ...
  • headtx headty headtz headrx
  • tx ty tz rx ...（从 Parameter CHOP 得到的内容）
  • cam1:m00 cam1:m10 cam1:m20 .... cam1:m33

多个变换集

上述任何一种都定义了一个变换矩阵。可以通过具有不同前缀的通道来指定多个变换“集”。使用不同格式的不同集可以全都位于同一个 CHOP 中。但在同一个集内不能混用格式。每个集都会与另一输入中的集以及“Transform”页上的变换相结合，为每个集生成最终变换。

如果没有输入连接到该 CHOP，它将输出由“Transform”页生成的变换。

如果连接了输入，输出将包含与第一个输入相同数量的采样。采样会在输入之间按 1:1 结合，即忽略输入的起止范围和采样率。如果第二个输入的采样数少于第一个，则来自第 2 个 CHOP 的超范围采样将使用该 CHOP 的 extend 条件来确定值。

如果提供了多个集，它们将按第 1 个对第 1 个、第 2 个对第 2 个的方式匹配。如果第二个输入中的集少于第一个，则会循环使用这些集。例如，第一个输入有 5 个集、第二个输入有 2 个集，则匹配为第 1 对第 1、第 2 对第 2、第 3 对第 1、第 4 对第 2、第 5 对第 1。

运算顺序

各输入会先相互结合，然后其结果再与“Transform”页上定义的变换结合。

Transform CHOP 的通道常常会被导出回物体。

transformCHOP_Class

参数 - Input 页

此页定义假定传入通道的变换顺序是什么。结合传入通道和此处的变换顺序，会为传入通道构建一个矩阵。然后将其乘以 Transform 页定义的变换矩阵并输出。

任何缺失的平移、旋转或缩放通道都将默认为零（缩放则为 1）。

参数 - Output 页

此页控制节点输出哪些信息。

Post Operation postop - 可选地在最终变换输出前对其应用最后一次操作。
  • None none - 不进行操作。
  • Invert invert - 反转变换。
  • Transpose transpose - 转置变换。仅对矩阵格式的变换有效。
  • Invert Transpose inverttranspose - 反转并转置变换。仅当输入是矩阵格式的变换时才会转置。
Output output - 指定变换的输出格式。
  • Transform (Euler) transform - 标准的 Translate、Rotate 和 Scale 通道：t[xyz]、r[xyz]、s[xyz]。除非关闭 'Include Order Channels'，否则还会包含用于变换顺序和旋转顺序的 xord 与 rord 通道。
  • Transform (Quaternion) transformquat - Translate、Quaternion（用于旋转）和 Scale 通道：t[xyz]、q[xyzw]、s[xyz]。除非关闭 'Include Order Channels'，否则还会包含用于变换顺序的 xord 通道。
  • 4x4 Matrix mat - 4x4 矩阵的 16 个通道。通道将按逐列顺序输出，即最后 4 个通道是矩阵的“平移”部分。
  • 3x3 Matrix mat3 - 3x3 矩阵的 9 个通道。包含旋转和缩放，但不含平移。
  • Position position - 变换在空间中的最终位置。不包含任何朝向信息。
Determinant determ - 输出矩阵时，启用此参数还可以输出其行列式。
Un-matched Channels unmatchedchans - 控制如何处理不符合各种变换格式命名约定的通道。
  • Warn warn - 如果发现不符合任何命名约定的变换通道，则给出警告。
  • Ignore ignore - 如果发现不符合命名约定的通道，则忽略（不给出警告）。
  • Delete delete - 删除所有不符合任何命名约定的通道。
Custom Output Orders custoutputorders - 默认情况下，输出的变换使用 Transform 页上给出的顺序。启用此项可为输出的变换使用自定义顺序。这不会改变变换本身，但通道的值很可能会变化，因为它们以不同顺序结合以获得相同的整体变换。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Transform CHOP 的附加信息可通过 Info CHOP 获取。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
