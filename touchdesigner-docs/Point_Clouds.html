点云

TouchDesigner 中的点云通过一系列操作符、渲染技术、UI 功能、文件格式和设备实现。

处理点云最有效的方式是使用 TOP：TOP 中的一个像素就是一个点，至少是一个点的一个属性，因为 TOP 每个只有 4 个通道（RGBA）。点的 XYZ 位置通常放在红、绿、蓝通道中。

读取点云文件

Point File In TOP 和 Point File Select TOP 把点云带入 TouchDesigner，支持大多数常见的点云格式以及 EXR 多通道文件，可把多通道文件转换为多个 4 通道 TOP。

一个点云文件的属性值可能超过 4 个，因此第 5 个及以后的通道要用 Point File Select TOP 获取。

关于 Point File In TOP，请参阅 OP Snippets。

在 TOP 查看器中显示点云

Normalized Split 是所有 TOP 查看器的一种显示模式，其中每个 RGBA 通道以灰度显示，并按像素中浮点数或定点数的最小-最大范围归一化，同时显示最小值和最大值。

View as Points 是 TOP 的另一种显示模式，它把图像的 RGB 通道当作 XYZ 点，在交互式 3D 查看器中显示。

操作点云：TOP

Point Transform TOP 对点云施加 3D 变换、对齐和归一化。

Math TOP、Function TOP、Limit TOP 和 Lookup TOP 已得到增强，支持把像素当作通用数值数据处理，并与 CHOP 中对应的操作符高度一致。

你可以直接用 TOP 中的点云表示，在 Render TOP 中把它们作为实例渲染出来。

Movie File Out TOP 已扩展为能创建多通道 EXR（OpenEXR）文件，并通过 DAT 注入元数据。这些文件可以用 Point File In TOP 读回。

操作点云：SOP

你可以用 SOP 生成点云，例如 Sprinkle SOP。但要把它放进 TOP，需要先经过 SOP to CHOP 再经过 CHOP to TOP，通常变成一张方形纹理。

操作点云：Palette 组件

在 TouchDesigner 的 Palette Components 中，Point Clouds 一节里有一些组件。

  • Palette:pointField - 根据与基本形状的接近程度，在 alpha 通道中生成点的「权重」。
  • Palette:pointGenerator - 生成简单的点分布
  • Palette:pointMerge - 合并多个点云。
  • Palette:pointRender - 用于彩色点的简单渲染网络。
  • Palette:pointRepack - 同样的点，但放在不同宽/高的图像中。
  • Palette:pointWeight - 用于距离/衰减计算的 GLSL 代码。

操作点云：设备

TouchDesigner 支持 Kinect Azure 生成 Z 深度图像和 XYZ+颜色 点云。

Ouster LIDAR 系统可实时生成长距离点云。
