Phaser CHOP

摘要

Phaser CHOP 做的是错开的（时间偏移的）动画插值。Phaser 输出一个带多采样的通道。每个采样在一个周期内从 0 动画到 1，但各采样值在不同时刻从 0 升起、到达 1。

例如，你可能有一组 N 个对象，想从起始位置动画到结束位置。你把 Num Samples 设为 N，Phaser CHOP 就会输出一个带 N 个采样的通道，让这些采样从 0 动画到 1，并用缓动函数插值。在 Phaser CHOP 中，从起点到终点的循环由 CHOP 的第一个输入控制，该输入应该是一个值在 0 到 1 之间的通道。

这些 0-1 的值可以与 Lookup CHOP 配合，用来为成组的通道做动画。

默认情况下，时间安排是均匀错开的。若想让它们的过渡不规律地错开，就使用第二个输入：一个 CHOP 通道里的一组值（通常是 N 个采样），取值在 0 到 1 之间。phase 值指定该对象与 CHOP 中其他对象的时间关系。phase 值为 1 对应「跑在前面」的动画对象（即它比其他对象更早开始动画）。值为 0 对应对「落后」的对象（即它最后才开始缓动/动画）。如果没有提供 phase 输入，phase 就简单地取 i/N，其中 N 是对象（即采样）总数，i 是当前采样的索引。

Phaser 中还有一个「Edge」概念，它描述这组动画对象的凝聚程度以及采样上升的快慢。值小时，对象会很快完成动画；值大时，则非常缓慢并与其他采样同步进行。

看看 David Braun 的 TouchDesigner Summit Talk，了解 Phaser CHOP 的来龙去脉。它的功能大量源自 David 在定量缓动方面的研究与开发。

参数 - Phaser 页

Edge edge - 两个状态之间相位分离的边缘。edge 越小，按相位差异分离得越锐利。如果有 Edge Input，则 Edge Parameter 不会使用。
Num Samples nsamples - 指定输出的尺寸。如果有 phase 输入，则此参数不会使用。
Output Format outputformat - - 指定输出的格式。
  • Multi-Samples samples - 一个通道中有多个采样。
  • Multi-Channel channels - 多个通道。
Extend Input extend - - 指定当 time 输入超出 0-1 范围时，如何解释该输入来计算 phaser 值。
  • Clamp clamp - time 输入被钳制在 0-1 范围。
  • Cycle cycle - phaser 让输入时间在 0-1 之间循环。
  • Mirror mirror - phaser 让输入时间在 0-1 之间来回折返（Zig-Zag）。
  • Mirror Slope mirrorslope - phaser 让输入时间在 0-1 之间来回折返，且 phaser 的斜率翻转。
  • Add add - 当 time 输入超过 1（或低于 0）时，phaser 的值持续增大（或减小）。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

操作符输入

  • Input 0: Time - 相位的时间安排。未连接时，时间默认是一条 4 秒的 LFO 斜坡。该 CHOP 应只包含一个通道；除第一个之外的所有通道都会被忽略。
  • Input 1: Phase - 连接后，Phaser CHOP 的输出会照搬 phase 输入的形态。不过，如果选择了 Mult-Channel Output Format，实际上会对输出做转置。
  • Input 2: Edge - 将使用 edge 采样，而不是 Edge 参数。

Info CHOP 通道

Phaser CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
