Write a Shared Memory TOP


在 TouchDesigner 安装目录下，Samples/SharedMem/TOP 中定义了 TOP_SharedMemHeader.h 中的头结构，需要在共享内存缓冲区的起始处填入。内存缓冲区应先放该头结构，随后是图像数据。

NOTE: The 'Shared Mem Type' parameter in the TOP must be set to 'Local' for your app to be able interface with it.

创建共享内存缓冲区

请参阅 Using Shared Memory in TouchDesigner 一文了解如何创建共享内存缓冲区。如果你是发送方，需要创建一个大小能同时容纳头结构和图像数据的缓冲区。获取头结构的大小只需用 

 sizeof(TOP_SharedMemHeader)

图像数据的大小取决于通道数、分辨率和 dataType。通常为 

 width * height * number of channels * number_of_bytes_per_channel

其中 number_of_bytes_per_channel 对于 dataType GL_UNSIGNED_BYTE 为 1，对于 GL_FLOAT 为 4。

获得指向该内存的指针后，就可以进行下一步了。

写入/读取头结构

你可以在 touch/SharedMem/TOP（位于安装 TouchDesigner 的目录下）中获取用于描述通过 Shared Mem TOP 发送数据的头文件。该文件名为 TOP_SharedMemHeader.h。

头结构是共享内存中最先出现的内容。因此你可以把从 UT_SharedMem 获得的指针转换为 TOP_SharedMemHeader。 

 TOP_SharedMemHeader *header = (TOP_SharedMemHeader*)shm->getMemory();

如果你是发送方，请填写该头结构中的所有字段。有关每个需要填写的字段的更多细节，请参阅该头文件。

If you are the sender, make sure you do this, otherwise the receiver won't know where the image is. 

 header->dataOffset = sizeof(TOP_SharedMemHeader);


头结构的大多数成员都无需解释，除了 dataFormat、dataType 和 pixelFormat。这些成员的有效值列在 TOP_SharedMemHeader.h 顶部。这些值是 OpenGL 常量，但我会给出它们的实际值（十六进制），以防你的应用完全没有使用 OpenGL。

dataFormat： 这是图像在内存中的格式。例如，如果你没有 alpha 通道，且图像数据的像素格式为 RGB，则指定 GL_RGB。

dataType： 这是图像数据的数据类型。如果以 unsigned char 存储，则使用 GL_UNSIGNED_BYTE（每通道 8 位）；如果以 float 存储，则使用 GL_FLOAT（每通道 32 位）。

pixelFormat： 这是你希望在 Shared Mem In TOP 中创建的纹理格式。pixelFormat 无需与 dataType 匹配。例如，你可以根据需要从 8 位 unsigned char 数据创建 GL_RGBA16F_ARB（16 位浮点）纹理，反之亦然。不要把这里的 RGBA 与上面的 dataFormat 混淆，RGBA 并不意味着通道顺序，只表示存在这些通道，如果需要，它们可以按 BGRA 排序。


如果你是接收方，可以按需使用头结构中的信息。

读取/写入图像

只需使用头结构中的 getImage() 调用，即可获得应读取/写入图像的位置指针： 

 unsigned char *image = (unsigned char*)header->getImage(); // 对于 8 位

或

 float *image = (float*)header->getImage(); // 对于浮点数据

现在根据格式读取/写入图像数据。
