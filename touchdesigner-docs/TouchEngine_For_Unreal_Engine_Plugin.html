虚幻引擎 TouchEngine 插件

TouchEngine For UE Plugin 基于 TouchEngine API 构建。

它让 Unreal Engine 用户和开发者能够加载 TouchDesigner .tox 文件、处理它们，并在 Unreal Engine 内来回传递数据。

注意： TouchEngine For UE Plugin 兼容 Windows 上的 only。

下载与入门

要开始使用 TouchEngine For UE Plugin，请访问我们 GitHub 仓库中托管的示例项目：

https://github.com/TouchDesigner/TouchEngine-UE-Samples

插件本身位于此处。示例仓库通过子模块引用它。

https://github.com/TouchDesigner/TouchEngine-UE

文档

示例文档和插件文档都在 GitHub 上。

应以示例仓库的文档作为主要文档。

插件文档：https://github.com/TouchDesigner/TouchEngine-UE#readme
示例文档：https://github.com/TouchDesigner/TouchEngine-UE-Samples#readme

许可

使用 TouchEngine 需要 Educational, Commercial, 或 Pro 的 TouchDesigner/TouchPlayer 许可证才能运行。此外，系统上必须安装 TouchDesigner/TouchPlayer 才能使用 TouchEngine。

问题与反馈

如果你想报告问题或提供反馈，请在各仓库的 Github Issues 中发帖。

希望贡献代码的开发者也可以在 GitHub 上提交拉取请求。
