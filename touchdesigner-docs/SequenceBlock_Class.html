SequenceBlock 类

SequenceBlock 类可用于访问序列中特定块（一组 parGroups）的 parGroups。 

block = op('/add1').seq.point[3] # 获取名为 "iop" 的序列中的第 4 个块
print([parGroup for parGroup in block]) # 打印该块中所有 parGroup

注意： 使用参数名 without 作为序列前缀。

成员

index → int (Read Only):

该块的数字索引。

owner → OP (Read Only):

此对象所属的 OP。

par → ParCollection (Read Only):

一个中间参数集合对象，可从中找到某个具体的序列参数。

名称不包含序列信息前缀。

n.seq.Info.blocks[2].par.Tx # 如果未找到则抛出异常

n.seq.Info.blocks[2].parGroup['Tx'] # 如果未找到则返回 None

parGroup → ParGroupCollection (Read Only):

一个中间参数集合对象，可从中找到某个具体的序列参数组。

名称不包含序列信息前缀。

n.seq.Info.blocks[2].par.T # 如果未找到则抛出异常

n.seq.Info.blocks[2].parGroup['T'] # 如果未找到则返回 None

name → str :

获取或设置序列块的名称参数值。它在每个块中实现为一个专门命名的参数。该名称也用于通过 Sequence[block name] 以字符串标识块。

namePar → Par | None (Read Only):

定义此块名称的参数，若不存在则为 None。

sequence → Sequence (Read Only):

该块所属的序列对象。

方法

destroy()→ None:

销毁该参数块。
