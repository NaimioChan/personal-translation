导出影片对话框

说明

该对话框可用于从 TouchDesigner 中的任何查看器导出多种容器格式和编解码器的影片。

此影片导出不以实时方式运行。渲染会花掉完整显示并写入每一帧所需的时间。这样就可以图形硬件支持的最高分辨率生成影片，同时避免这些分辨率在实时播放时可能出现的卡顿和低帧率。

按喜好设置好参数后，按下 Start 按钮即可开始导出影片。按 Stop 按钮结束录制并生成 .mov 文件。Stop 按钮是可选的，达到指定时长后录制会自动停止。生成影片后，点击 View 按钮可预览最近一次的影片文件。

参数

输入

TOP Video - 要录制的 OP 的路径。指定 TOP 时，使用 TOP 中的图像数据生成影片。指定非 TOP 的操作符时，使用该 OP 的节点查看器生成影片。

CHOP Audio - 要录制的 CHOP 音频的路径。该 CHOP 必须为 Time Sliced。

设置

Resolution - 指定导出影片的分辨率。两个参数分别是 X resolution 和 Y resolution。

Movie FPS - 导出影片的每秒帧数。

Codec - 用该菜单选择编码影片所用的视频编解码器。

Quality - 控制编码影片时的视频压缩质量。Lossless 是最高质量的设置，但只有在支持无损压缩的编解码器中才真正提供无损编码，例如 Animation (rle) 编解码器。

Channels - 选择输出颜色通道还是仅输出 alpha。有些编解码器（如 Animation (rle) 和 Tiff (tiff)）提供 RGBA，会把 RGB 和 alpha 通道编码进影片文件。

Movie Timecode - 会把影片的 SMPTE 时间码叠加到导出的影片上。

Timeline Timecode - 会把 timeline 的 SMPTE 时间码叠加到导出的影片上。

Start Frame - 影片开始录制的时间轴帧。按下「Start」按钮时，Timeline 会被设为 Start Frame，影片开始编码。

End Frame - 影片停止录制的时间轴帧。若编码过程中时间轴到达该帧，进程会自动停止录制并完成影片。

Set Duration - 影片的时长。可以按帧、秒或分钟显示。更改 Start/End Frames 时，Duration 会自动更新。若更改 Duration，End Frame 会自动更新以反映新的时长。

输出

Filename - 导出影片的文件名。点击右侧的文件夹按钮可打开 File Save 对话框。若想让文件名自动递增，可在文件名中加入 "$N"，下面的自动递增数字会被插入到文件名中。

Filename Inc - 该数字在每次导出影片后自动递增。若在上面的文件名参数中加入了 "$N"，生成影片时该数字会被加入文件名。

Start/Stop - 开始和停止影片录制。按下 Start 时，Timeline 会被设为 Start Frame，录制开始。到达 End Frame 或按下 Stop 按钮时录制结束。

View - 用默认影片播放器查看最近生成的影片。
