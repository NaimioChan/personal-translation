Noise SOP

摘要

Noise SOP 使用噪声图案位移几何点。它使用与 Noise CHOP 相同的数学方法。

noiseSOP_Class

参数 - Noise 页

Group group - 如果存在输入组，在此字段中指定组名将使该 SOP 仅作用于指定的组。接受模式匹配，说明见 Pattern Matching。
Attribute attribute - - 此菜单设置 Noise SOP 作用于几何的哪个属性。
  • Point Position pos - 噪声沿点法线的方向应用。如果未指定法线，则会计算一个法线。
  • Point Normals n - 噪声分别应用到法线的每个分量，然后对矢量重新归一化。
  • Point Diffuse Color cd - 噪声分别应用到颜色的每个分量。
  • Point Alpha alpha - 噪声应用到 alpha。
  • Point Texture UV uv - 噪声分别应用到 uv 的每个分量。
  • Point Texture W w - 噪声应用到 texture w。
Type type - - 用于生成噪声的噪声函数。可用函数包括：
  • Sparse sparse - 基于 Sparse Convolution 生成高质量的连续噪声。
  • Hermite hermite - 比 Sparse 更快，但生成的噪声质量较低。
  • Harmomic Summation harmonic - 稀疏噪声，可控制谐波的频率步进。计算耗时最长。
  • Brownian brownian - 像随机飞行中的虫子一样运动。当 Num of Integrals 为 2 时，其加速度每帧都会随机变化。
  • Random random - （白噪声）每个采样都是随机的，与其他任何采样无关。与音频中的「白噪声」相同。
  • Alligator alligator - 单元噪声。
Seed seed - 任意数字，整数或非整数均可，作为随机数生成器的起点。每个数字都会产生完全不同的噪声图案，但特征相似。
Period period - 噪声周期相邻峰值之间的大致间隔。以 Units 表示。增大周期会拉长噪声图案。

周期与频率相反。如果周期为 2 秒，基础频率就是每秒 0.5 个周期，简称 0.5Hz。Hz 指的是赫兹，那位 19 世纪的电气与音频工程师，而不是开租车公司的那位。

如果 Type 设为 Random，将此值设为零会产生完全随机的噪声。否则，周期应大于零。

Harmonics harmon - 叠加在基础频率之上的高频分量数量。该数值越大，噪声越崎岖（只要 roughness 不为零）。0 个谐波则只给出基础形状。

基础频率为 0.1Hz 的谐波，默认会在 0.2Hz、0.4Hz、0.8Hz 等处产生谐波（直到 Harmonics 参数指定的谐波数量）。

Harmonic Spread spread - 谐波频率提升的倍数。通常为 2。spread 为 3、基础频率为 0.1Hz 时，会在 0.3Hz、0.9Hz、2.7Hz 等处产生谐波。此参数仅对 Harmonic Summation 类型有效。
Roughness rough - 控制高频噪声的效果。Roughness 为零时，基础频率以上的所有谐波都不起作用。为 1 时，所有谐波的振幅都与基础频率相同。当 Roughness 介于 1 和 0 之间时，较高谐波的振幅会从基础频率起指数衰减。

默认 roughness 为 0.5。这意味着第一个谐波的振幅是基础频率的 0.5，第二个为 0.25，第三个为 0.125。谐波叠加到基础波形上形成最终形状。Harmonics 参数和 Roughness 参数都必须非零，才能看到谐波效果。

Exponent exp - 将噪声值推向 0，或推向 +1 和 -1。（它把数值提升到该指数次幂。）指数大于 1 会把通道拉向零，小于 1 则会把峰值拉向 +1 和 -1。它用于重塑通道。
Number of Integrals numint - 定义对 Brownian 噪声进行积分的次数（参见 Speed CHOP）。数值越大，曲线越平滑、细节越少。超过 4 的数值会产生大致相同的曲线。此参数仅对 Random 噪声类型有效。
Amplitude amp - 定义噪声值的振幅（对输出值进行缩放）。
Keep Computed Normals keepnormals -

参数 - Transform 页

Translate、Rotate、Scale 和 Pivot 参数让你可以在 3D 噪声空间的不同位置采样。可以想象空间中每个 XYZ 点都有不同的噪声值。通常，Noise SOP 从 (0,0,0) 出发沿 X 轴以 2/period 为步长对噪声空间采样。

改变变换，就是在平移、旋转和缩放 Noise SOP 对噪声空间采样的那条线。轻微的 Y 轴旋转就像在山中沿直线行走，一路记录海拔，然后从同一初始位置重新出发，朝略微不同的方向走。你的海拔起初相近，随后逐渐偏离。

Transform Order xord - - 附加到此参数的菜单可让你指定变换发生的顺序。改变 Transform 顺序会改变最终结果，就像先走过一个街区再向东转，与先向东转再走过一个街区，会到达不同的地方。

  • Scale Translate Rotate str -
  • Rotate Scale Translate rst -
  • Rotate Translate Scale rts -
  • Translate Scale Rotate tsr -
  • Translate Rotate Scale trs -

Info CHOP 通道

Noise SOP 的额外信息可通过 Info CHOP 查看。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
