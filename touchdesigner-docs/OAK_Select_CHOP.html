OAK Select CHOP

摘要

OAK Select CHOP 相当于 Script CHOP 与 Select CHOP，以及其他硬件专用 CHOP 的结合体。基本操作是提供一个 OAK Device CHOP 和一个流名称。在最简单的情况下，该流的数据会以命名良好的通道形式出现。例如，指示检测到的物体的 2D 坐标和标签的 ImgDetections 消息会直接显示为 CHOP 通道，无需任何手动编码。在更复杂的情况下，例如手部地标跟踪，流可能是 NNData 或 Buffer 类型，需要用户实现回调并解析数据。

参数 - OAK 页

Active active - 切换 OAK Select CHOP 是否计算。
OAK Device CHOP chop - 运行 depthai 管线的 OAK Device CHOP。
Stream stream - 要接收的流名称。
Queue Size queuesize - 出于内存效率考虑，此参数控制 TouchDesigner 在从 OAK 接收消息时复用的消息数量。参见下文「Queue Size」。
Max Items maxitems - 此参数帮助 OAK Select CHOP 输出数量一致的通道。运行图像检测管线时，检测到的项目数会逐帧变化，但我们希望 TouchDesigner 输出数量一致的通道。
Output Format outputformat - - 默认选项「Items As Separate Channels」会启用时间切片，而「Items as Separate Samples」不会。如果该流会自动填充 CHOP，那么「Items as Separate Samples」是让 CHOP 稳定输出 Max Items 个采样的有用方式。
  • Items As Separate Channels itemsaschannels -
  • Items As Separate Samples itemsassamples -
Use First Sample Only firstsample - 仅使用 OAK Select CHOP 最近收到的消息。例如，对于发送极高帧率数据的 IMU 流，打开此参数将只显示最新的采样。
Sample Rate rate - CHOP 的采样率。默认采样率为 me.time.rate。
Callbacks DAT callbacks - 指定保存回调的 DAT。
Setup Parameters setuppars - 点击该按钮会运行 setupParameters() 回调函数。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

操作符输入

Info CHOP 通道

oakselect CHOP 的额外信息可以通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。

Script CHOP 功能

OAK Select CHOP 在多个方面模仿 Script CHOP。其中有一个用于 onSetupParameters 的回调，可以在其中添加自定义参数。此外，在 onReceiveNNData、onReceiveBuffer 和 onReceiveSystemInformation 等其他回调中，也可以追加通道并写入数据。实现如下所示的自定义回调时，如果要禁用时间切片或设置输出采样数，Output Format 参数应设为「Items as Separate Samples」。

import depthai as dai
def onReceiveNNData(oakSelectOp, oakNnData: dai.NNData):
    oakSelectOp.clear()
    oakSelectOp.appendChan('foo')
    oakSelectOp.numSamples = 1  # Output Format 必须为 "Items as Separate Samples"
    oakSelectOp['foo'][0] = 42    
    return

队列大小

Queue Size 参数帮助 TouchDesigner 避免保留过多消息，同时为最少数量的消息复用内存。例如，选 2 是个不错的选择，因为 TouchDesigner 可以把 1 条消息显示给用户，同时剩下的 1 条消息可异步写入新数据。不过，如果该流是高帧率流，例如 IMU 数据，那么队列大小应至少是你在单个 TouchDesigner 帧中预期接收消息数的两倍。如果 TouchDesigner 丢掉了一个视频帧，下一次计算就需要使用正常情况下两倍的消息数，因此队列大小至少要翻倍。

最大项目数

有些消息可以描述为项目。例如，ImgDetections 可以分组为 item0 的通道、item1 的通道、item2 的通道等等。对于这类流，让 OAK Select CHOP 保持恒定数量的通道会很有帮助，无论最新消息中是否存在某个项目。

输出格式

默认的 Output Format 是「Items as Separate Channels」。例如，从 MobileNet 接收 ImgDetections 时，每个检测需要 6 个通道（「confidence」、「label」、「xmin」、「xmax」、「ymin」、「ymax」）。通道总数是 6 乘以 Max Items 内置参数。这种情况下启用了时间切片，所以采样数会随时间切片而变化。

如果你愿意放弃时间切片，可以把输出格式设为「Items as Separate Samples」。这会把最新的消息按 Max Items 个采样重排为 6 个通道。换句话说，每个 ImgDetection 项目对应一个 CHOP 采样。使用「Items as Separate Samples」的另一个原因是你正在实现 onReceiveNNData 这类回调，并且需要设置采样数（oakSelectOp.numSamples = 1）。

仅使用第一个采样

与 Shuffle CHOP 一样，Use First Sample Only 参数可以方便地让 OAK Select CHOP 只使用最近收到的消息。例如，IMU 流可能发送极高帧率的数据，打开此参数就像在「Absolute」值模式下使用 Trim CHOP 只显示最新的采样。

Info CHOP

当 OAK Select CHOP 连接到 Info CHOP 时，除了常规的计算相关通道外，还会有一些 OAK 专用的通道：

  • sequence_num：（见 depthai documentation 中的「sequenceNum」）
  • messages_received：使用 OAK Select CHOP 上所设流名称接收到的消息总数
  • fps：该流的有效每秒帧数，即 TouchDesigner 接收消息的速度。这不是该流的目标 FPS。
