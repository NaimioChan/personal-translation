ListAttributes 类

ListAttributes 类描述用于单元格、行、列或表格的一组 list attribute objects。可从 List Component 访问。

对单个 List Attributes 的访问取决于其类型：行、列或单元格：

rowAttribs = op('list1').rowAttribs		# 获取用于行的 ListAttributes 对象
print(len(rowAttribs))					# 行数
print(rowAttribs[0].bgColor)			# 行通过行号访问。
										# 这会打印第一行的背景色设置

colAttribs = op('list1').colAttribs		# 获取用于列的 ListAttributes 对象
print(len(colAttribs))					# 列数
print(colAttribs[0].bgColor)			# 列通过列号访问。
										# 这会打印第一列的背景色设置

cellAttribs = op('list1').cellAttribs	# 获取用于列的 ListAttributes 对象
print(len(cellAttribs))					# 单元格总数
print(colAttribs[0,2].bgColor)			# 单元格通过 [row, col] 访问。
										# 这会打印第一行第三列单元格的背景色设置

注意： 上述属性是 List 组件层级布局技术的设置。这意味着单元格设置会覆盖行设置，行设置会覆盖列设置，列设置会覆盖表格设置。若想知道某个单元格中的最终值，请使用 listCOMP.displayAttribs[row, col]。

成员

没有该操作符专属的成员。

方法

没有该操作符专属的方法。
