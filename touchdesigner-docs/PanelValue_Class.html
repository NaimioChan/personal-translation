PanelValue 类

PanelValue 描述对 Panel Value 的实例引用。可通过组件的 panel 成员访问，并在 Panel Execute DAT 中使用。

可用面板值的列表请参阅：Panel Value。

成员

name → str (Read Only):

面板值的名称。可能的名称列表见 Panel Value。name 是字符串。

owner → OP (Read Only):

此对象所属的 OP。

val → Any :

获取或设置面板值。

valid → bool (Read Only):

若所引用的面板值当前存在则为 True，若已被删除则为 False。

方法

没有该操作符专属的方法。

转换为值

PanelValue 类实现了所有必要的方法，可作为数字或字符串处理，在此情况下即获取或设置其值。因此在参数中或数值表达式中使用时，无需显式调用 eval() 或 set()。 例如，以下写法在参数中等价： 

(float)parent().panel.u
parent().panel.u.val
parent().panel.u

# 以下写法也等价
parent().panel.u.val + 1
parent().panel.u + 1

# 以下写法同样如此
parent().panel.u.val = 0.5
parent().panel.u = 0.5
