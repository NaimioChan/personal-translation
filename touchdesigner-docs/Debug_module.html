Debug module

debug module 提供用于 TouchDesigner 内置 debug 语句的工具。它还包含用于自定义这些语句以及构建自定义调试输出的实用功能。此模块可直接通过 tdu.debug 使用。

可以使用调色板中的 debugControl 组件，在不使用 Python 的情况下设置 debug 行为。

成员

style → types.SimpleNamespace :

一个命名空间，包含有关如何处理 debug 语句的信息。不应直接更改这些数据，而应使用下面的 setStyle 函数。

方法

debug(*args)→ None:

将所有参数和额外调试信息（默认为 DAT 和行号）打印到 texport。要更改行为，请使用 debugControl 组件或（下面的）setStyle 函数。
TIP: Use debug instead of print when debugging Python scripts in order to see object types and the source of the output.

setStyle(printStyle=None, showDAT=None, showFunction=None, showLineNo=None, timeStamp=' ', suppress=None, formatOverride=None, functionOverride=None)→ None:

设置内置 TD 调试函数的样式。以 None 传入的任何参数都会使该功能保持不变。

printStyle:
'pprint'=把非字符串参数转换为 pprint.pformat(arg, indent=4, sort_dicts=False)。让列表、字典等更易读
'pprint_sorted'=把非字符串参数转换为 pprint.pformat(arg, indent=4)。让列表、字典等更易读。字典键将按字母排序
'repr'=把非字符串参数转换为 repr(arg)
否则，把非字符串参数转换为 str(arg)
showDAT：在调试消息中显示调用 debug 的 DAT
showFunction：在调试消息中显示调用 debug 的函数
showLineNo：在调试消息中显示调用 debug 的行号
suppress：如果为 True，则抑制（不打印）任何 debug 调用
timeStamp: Python time format code.
formatOverride：覆盖 debug 打印的默认消息。可以使用 {0}、{1} 和 {2} 分别表示 DAT、函数和行号
functionOverride：覆盖内置的 TD 调试函数。项目中任何 debug 调用都会以全部参数调用此函数。设为 False 可移除覆盖。

debugs(*args)→ str:

返回调试函数将打印的字符串。要更改行为，请使用 debugControl 组件或（上面的）setStyle 函数。这是用于构建自定义调试系统的实用函数。

info(*args, stackOffset=0)→ list:

返回经调试函数处理后的所有参数和额外调试信息。要更改行为，请使用 debugControl 组件或（上面的）setStyle 函数。这是用于构建自定义调试系统的实用函数。
