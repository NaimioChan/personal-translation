属性

属性构成了 POPs 的数值数据块。每个 POP 都有三块数据：一个 Point List（其中包含 P Position 属性）、一个 Primitive List 和一个 Vertex List。这些列表各由任意数量的属性组成。每个属性都有一个名称。

Position（P）是标准的点属性，内置的可选属性包括 normals（N）、纹理坐标（Tex）、颜色（Color）等。Color 图元属性使每个图元都能拥有单独的颜色。N 顶点法线属性使每个顶点都能拥有单独的曲面法线向量。

POP 的点列表具有长度 numPoints，即所有点属性的长度，图元和顶点列表同理。

一个 point attribute 可以是 scalar point attribute，即每个点一个数值；也可以是 vector point attribute，即每个点 2、3 或 4 个数值，例如 P（X Y Z 位置）属性就是一种 float3（3 个数值）向量属性。

一个 primitive attribute 是 numPrimitives 个单标量数值或 2 值、3 值、4 值向量的列表。

一个 vertex attribute 是 numVertives 个标量数值或向量的列表，对应 POP 所有图元的总顶点数。

每个属性都是单独分配的数值列表，因此创建或删除某一个属性时不会影响其他内容。

请参阅下方的 Attribute Data Types。此外，属性可以有一个 Qualifier，例如 float4 表示 Color，float3 表示 XYZ 方向，float4 表示旋转四元数。

For attributes of SOPs see SOP Attribute as this page is focused on POPs.

属性术语

  • Built-in Attributes - 严格保留的属性，例如 P、PointScale、N 和 Tex。
  • Common Attributes - 常用但不受 TouchDesigner 严格控制的属性，例如 PartMass 和 PartVel。
  • Read-Only Attributes - 由 TouchDesigner 预先计算的属性（例如归一化的点序号 _PointU），可用于 Math POP、Math Mix、Math Combine POP 等。
  • Components of Attributes - 对于向量类属性，一个 flaot3 有 3 个「分量」，称为 P(1) 或 P.y 或 P.i2（参见 Swizzling）
  • Attribute Class - 指 POP 数据中的 Point、Primitive 和 Vertex 类。
  • Array Attribute - 一种属性类型，每个点有多个 float 或 float2 等
  • 标量属性与向量属性 - 单分量、多分量。

常用属性

法线（N）

请参阅 Normals。法线是与特定几何实体相关联的方向向量，通常与该实体垂直。曲面上某一点处的法线是与该点处曲面垂直的向量，由该点处的切向量叉积计算得出。

颜色（Color）

由 RGBA 指定的表面颜色与 alpha。取值范围为 0 到 1。alpha 分量 Color.a 控制给定元素的透明度，其中 1 为完全不透明，0 为完全透明。

纹理坐标（Tex）

各个项通过 XYZ 值在空间上定位。为了区分纹理坐标空间与 XYZ 空间，使用标签 U 和 V，有时也用 W，来代替 X、Y 和 Z。 ​ 为了把纹理贴图（图像）放置到几何上，必须为几何指定纹理坐标。纹理贴图位于它自己的 (U, V) 纹理坐标空间中。指定到几何后，(U, V) 坐标决定如何把图像映射到几何上：U、V 为 0,0 时使用纹理图像的左下角，1,1 时使用右上角。 ​ 大多数生成器 POP（例如 Sphere POP 和 Plane POP）已经为每个点或顶点指定了纹理坐标。 ​ 可以用以下方式理解纹理坐标：纹理贴图有自己的坐标空间。如果纹理是一块带网格图案的桌布，那么即使把桌布包裹在不规则形状的物体上，桌布上位置 3, 4 处的颜色仍留在位置 3, 4 处。可以说位置 3, 4 处的颜色位于桌布自己的坐标空间中。 ​

属性优先级顺序

属性的优先级顺序从高到低为：

  1. 顶点属性
  2. 点属性
  3. 图元属性

优先级较高的属性会覆盖优先级较低的同名属性。（只有 Bone Group SOP 具有来自外部导入骨架的 Detail 属性。）

点属性和顶点属性会在图元之间插值，因此比图元属性具有更高的局部灵活性（例如 Color）。顶点属性用于处理共享点在图元边界处需要不同属性值的情况，例如极坐标纹理贴图的纵向接缝。图元颜色通常比点颜色占用更少内存，点颜色又比顶点颜色占用更少。

属性数据类型

共有三种不同的属性数据类型。它们在内部的处理方式略有不同。

Vector Data This data type represents a 3D vector in space. When any transforms occur on the detail, this attribute will also be transformed. Examples of a vector attribute are normals (N) or velocity (PartVel).
Floating Point Data This data type represents an array of floating point values. The values are not transformed when the geometry gets transformed. Some examples of this type of attribute are diffuse colors (Cd), and texture co-ordinates (Tex).
