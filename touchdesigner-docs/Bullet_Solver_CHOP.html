Bullet Solver CHOP

摘要

Bullet Solver CHOP 与 Bullet Dynamics 系统配合使用。它输出 Bullet 模拟求解后的结果，可以包含整个系统（Bullet Solver COMP）或系统中单个 actor（Actor COMP）的结果。

Bullet Solver CHOP 也可以配合 Bullet Solver COMP 或 Actor COMP 上的「Feedback CHOP」参数使用。可以使用 Bullet Solver CHOP 抓取 Bullet Solver 的模拟结果，修改后再送回其来源的 Bullet Solver COMP。模拟下一步开始时的值将取决于回送的 CHOP 中的值。这允许在下一帧（时间步）开始时将任何 CHOP 数据注入模拟。

例如：让模拟中的一个 actor 在点击时跳到鼠标光标处。

Output Channels:

  • actor_id: Actor COMP 的 OP id
  • body_id: Actor COMP 内 body 的 id。如果 Actor COMP 是静态的或使用实例化（见：Actor COMP），则可以有多个 body。body id 从 0 递增到 N-1，N 是 Actor COMP 中 body 的总数。
  • active: body 是否在模拟中处于活动状态
  • colliding: body 当前是否与另一个 body 碰撞
  • colliding_actor_id 正在与之碰撞的 body 所在 Actor COMP 的 ID
  • colliding_body_id 正在与之碰撞的 body 的 ID；与 colliding_actor_id 一起可映射回模拟中的特定 body
  • total_collisions: 此 body 发生的碰撞总数
  • t[xyz]: body 在给定变换空间中的平移
  • r[xyz]: body 在给定变换空间中的旋转
  • s[xyz]: body 在给定变换空间中的缩放
  • vel_t[xyz]: body 的线速度
  • vel_r[xyz]: body 的角速度

另请参阅：Bullet Dynamics、Bullet Solver COMP、Actor COMP、Force COMP、Impulse Force COMP、Constraint COMP。

参数 - General 页

Solver or Actor COMP comp - 对 Bullet Solver COMP 或 Actor COMP 的引用。如果引用的是 Bullet Solver COMP，则 CHOP 会输出其所有 actor 的模拟结果。如果引用的是 Actor COMP，则 CHOP 只输出该 actor 的模拟结果。
Transform Space xformspace - - 输出变换值所用的空间。即变换值（平移/旋转）将相对于所选空间输出。
  • World world - 输出变换位于世界坐标系中。
  • Bullet Solver bulletsolver - 输出变换相对于 Bullet Solver COMP。
  • Actor actor - 输出变换相对于 Actor COMP。
Collision Info collisioninfo - 向 CHOP 添加 colliding、colliding_actor_id、colliding_body_id 和 total_collisions 通道。要跟踪 body 的这些值，必须在 Bullet Solver COMP 上启用「Perform Contact Test」。
Translation trans - 向 CHOP 添加 translation 通道。
Rotation rot - 向 CHOP 添加 rotation 通道。
Scale scale - 向 CHOP 添加 scale 通道。
Linear Velocity linvel - 向 CHOP 添加 linear velocity 通道。
Angular Velocity angvel - 向 CHOP 添加 angular velocity 通道。
Sample Rate rate - CHOP 的采样率。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Bullet Solver CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
