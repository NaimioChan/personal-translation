AnnotateCOMP 类

create(opType, name, initialize=True)→ OP:

在此组件内创建一个给定类型的新节点。如果提供了 name，新节点将使用该名称；如果该名称已被使用，则使用下一个编号的名称。opType 可以是具体的类型对象，例如 waveCHOP，也可以是字符串 'waveCHOP'。如果给定的是节点的实际实例 n，则可分别通过 type(n) 和 n.OPType 访问它们。

除非 initialize=False，否则会运行与该操作符关联的初始化脚本。 返回新节点。

  • opType - 要创建的操作符类型所对应的 Python OP 类型。
  • name - （可选）新操作符的名称。如果已存在同名操作符，则使用下一个编号的名称。
  • initialize - （关键字，可选）如果设为 false，则不会运行该节点的初始化脚本。大多数节点初始化时不执行任何操作，但有些会。例如 Light COMP 会在其内部初始化一个由 SOP 组成的网络。
n.create(waveCHOP)
w = n.create(boxSOP, 'box12')

对所有指定的操作符进行布局。

  • ops - 要布局的操作符。未指定时为全部
  • horizontal - （关键字，可选）如果为 True，则水平布局。
  • vertical - （关键字，可选）如果为 True，则垂直布局。
  • gridRows - （关键字，可选）如果设置，则以该行数的网格布局。

注意： 只能指定 horizontal、vertical 或 gridRows 中的一个。

将操作符复制到此组件中。如果提供了 name，新节点将使用该名称。返回新节点。

  • name - （关键字，可选）如果提供，新节点将使用此名称。如果已存在同名操作符，则使用下一个编号的名称。

findChildren(type=None, name=None, path=None, depth=None, maxDepth=None, text=None, comment=None, tags=[], allTags=False, parValue=None, parExpr=None, parName=None, onlyNonDefaults=False, includeUtility=False, key=None)→ List[OP]:

返回符合指定条件的 operators 列表。

  • type - （关键字，可选）指定 OP 的类型。例如 type=boxSOP
  • name - （关键字，可选）指定 OP 的名称。支持 Pattern Matching。例如：name='project*'
  • path - （关键字，可选）指定 OP 的路径。支持 Pattern Matching。例如：path='*/pics/*'
  • depth - （关键字，可选）指定 OP 相对于调用 OP 的相对深度。子级深度为 1，其子级深度为 2，依此类推。
  • maxDepth - （关键字，可选）指定 OP 相对于调用 OP 的最大相对深度。
  • text - （关键字，可选）指定 OP 的 DAT 内容。支持 Pattern Matching。例如：text='*import*'
  • comment - （关键字，可选）指定 OP 注释。支持 Pattern Matching。例如：comment='*todo*'
  • tags - （关键字，可选）指定要搜索的标签列表。支持 Pattern Matching。例如：tags=['*sequencer*', '*interface*']
  • allTags - （关键字，可选）为 True 时，仅包含匹配所有指定标签的 OP。
  • parValue - （关键字，可选）指定 OP 中任意参数的值。支持 Pattern Matching。例如：parValue='500'
  • parExpr - （关键字，可选）指定 OP 中任意参数的表达式。支持 Pattern Matching。例如：parExpr='*sin*'
  • parName - （关键字，可选）指定 OP 中任意参数的名称。支持 Pattern Matching。例如：parName='clone'
  • onlyNonDefaults - （关键字，可选）为 True 时，仅包含非默认参数。
  • includeUtility - （关键字，可选）如果指定，控制结果中是否包含 Utility nodes（例如 Comments）。
  • key - （关键字，可选）指定自定义搜索函数。
# 查找所有名称以 circle 开头的 OP
n.findChildren(name='circle*')

# 查找所有 wide CHOP
n.findChildren(type=CHOP, key = lambda x: x.nodeWidth > 200)

# 查找所有指定克隆的 COMP
n.findChildren(type=COMP, parName='clone', onlyNonDefaults=True)

progressiveUnload(totalFrames=None, timePerFrame=None, nodesPerFrame=None, gpuMemPerFrame=None, opsToExclude=None)→ None:

此操作在数帧的时间内释放组件的内存，以尽量减少可感知的影响。progressiveUnload() 让你可以尝试释放为此组件的子节点分配的 CPU 和 GPU 内存，卸载会分摊到多帧进行。对于每个被卸载的节点，下次该节点计算时内存会被重新分配，因此请确保没有其他东西仍在使用它，以保持其被释放。

unload() 在 Movie File In TOP 上拥有的 cacheMemory 选项在 progressiveUnload() 中不可用。因此，Movie File In TOP 的所有内存都会被释放。另见 OP 方法 unload()。

参见 COMP.progressiveUnloader 以观察和控制卸载。组件的 progressiveUnloader member 包含有关最近一次卸载操作的状态信息，并具有修改该卸载操作的方法，例如 kill()，它会终止卸载。

如果未提供任何参数，则所有内容都在单帧内卸载。

所有 PerFrame 选项都可以一起指定。当满足其中任一条件时，卸载将进入下一帧。

  • totalFrames - （关键字，可选）卸载所跨的最大帧数。不能与其他选项一起使用。
  • timePerFrame - （关键字，可选）每帧用于卸载的时间。以毫秒为单位。该帧内节点会持续被卸载，直到用于卸载的总时间等于或大于此值。因此最后一帧的卸载时间可能大于此值。
  • nodesPerFrame - （关键字，可选）每帧卸载的节点总数。
  • gpuMemPerFrame - （关键字，可选）每帧卸载的 GPU 内存。以 MB 为单位。该帧内节点会持续被卸载，直到卸载的 GPU 内存总量等于或大于此值。因此最后一帧卸载的 GPU 内存可能大于此值。
  • opsToExclude：（关键字，可选）：指定不应被卸载的 OP 列表。如果列表中指定了某个 COMP，则其内部所有 OP 也会被排除。
# 在接下来的 10 帧中逐步卸载该 COMP
n.progressiveUnload(totalFrames=10)

# 每帧卸载 5 个节点来逐步卸载该 COMP
n.progressiveUnload(nodesPerFrame=5)

# 每帧卸载该 COMP，直到卸载耗时至少达到 16ms
n.progressiveUnload(timePerFrame=16)

# 每帧卸载该 COMP，直到至少满足一个指定条件
n.progressiveUnload(gpuMemPerFrame=15, timePerFrame=16)

OP 类

成员

通用

name → str :

获取或设置操作符的名称。

base → str (Read Only):

返回名称中任何数字之前的部分。

digits → int (Read Only):

返回名称中最后一段连续数字的数值，如果找不到则返回 None。如果名称末尾没有数字，则数字可以位于名称中间。

path → str (Read Only):

操作符的完整路径。

id → int (Read Only):

操作符的唯一 id。该 id 也可以传给 op() 和 ops() 快捷方式。重新打开文件时 id 并不一致，并且当 OP 被复制/粘贴、改变 OP 类型、删除/撤销时会发生变化。不过重命名 OP 时 id 不会改变。其数据类型为整数。

op → OPShortcut (Read Only):

操作符查找器对象，用于通过路径或快捷方式访问操作符。注意： 相对于 '/' 搜索的该方法的版本也在全局 td module 中。

op(pattern1, pattern2..., includeUtility=False) → OP or None

返回路径与给定模式匹配的第一个 OP，相对于该操作符内部。如果没找到则返回 None。可以指定多个模式，它们都会加入搜索。也可以使用数字形式的 OP id。

  • pattern - 可以是遵循 Pattern Matching 规则的字符串，指定要返回哪个 OP；也可以是整数，此时必须是 OP Id。可以给出多个模式，将返回第一个匹配的 OP。
  • includeUtility (Optional) - 如果为 True，允许返回 Utility nodes。如果为 False，将忽略 Utility 操作符。
b = op('project1')
b = op('foot*', 'hand*') # 逗号分隔
b = op('foot* hand*')  # 空格分隔
b = op(154)

op.shortcut → OP

通过 Global OP Shortcut 指定的操作符。如果该操作符不存在，就会抛出异常。这些快捷方式是全局的，必须唯一。也就是说，剪切并粘贴一个已指定 Global OP Shortcut 的操作符会导致名称冲突。此时必须重命名其中一个快捷方式。此外，只有组件才能指定 Global OP Shortcuts。
  • shortcut - 对应目标操作符中指定的 Global OP Shortcut 参数。
b = op.Videoplayer

列出所有 Global OP Shortcuts：

for x in op:
	print(x)

opex → OPEXShortcut (Read Only):

操作符查找器对象，用于通过路径或快捷方式访问操作符。其工作方式类似 op() 快捷方法，但找不到节点时会抛出异常，而不是像 op() 那样返回 None。现在推荐在参数表达式中用它获取节点，因为报错信息比例如使用 op() 时常见的 NoneType has no attribute "par" 更有用。注意： 相对于 '/' 搜索的该方法的版本也在全局 td module 中。

op(pattern1, pattern2..., includeUtility=False) → OP

返回路径与给定模式匹配的第一个 OP，相对于该操作符内部。如果没找到则返回 None。可以指定多个模式，它们都会加入搜索。也可以使用数字形式的 OP id。

  • pattern - 可以是遵循 Pattern Matching 规则的字符串，指定要返回哪个 OP；也可以是整数，此时必须是 OP Id。可以给出多个模式，将返回第一个匹配的 OP。
  • includeUtility (Optional) - 如果为 True，允许返回 Utility nodes。如果为 False，将忽略 Utility 操作符。

parent → ParentShortcut (Read Only):

Parent Shortcut 对象，用于通过索引或快捷方式访问父级组件。

注意： a version of this method that searches relative to the current operator is also in the global td module.

parent(n) → OP or None

该操作符的第 n 级父级。如果不指定 n，返回父级。如果 n = 2，返回父级的父级，依此类推。如果该层级没有父级，返回 None。

  • n -（可选）n 是向上攀爬的层级数。当 n = 1 时返回该操作符的父级。
p = parent(2) # 祖父

parent.shortcut → OP

用快捷方式指定的父级组件。如果不存在父级则抛出异常。

  • shortcut - 对应目标父级中指定的 Parent Shortcut 参数。
n = parent.Videoplayer

更多示例见 Parent Shortcut。

iop → IOPShortcut (Read Only):

Internal Operator Shortcut 对象，用于访问内部快捷方式。另请参阅 Internal Operators。 注意： 相对于当前操作符搜索的该方法的版本也在全局 td Module 中。

ipar → IparShortcut (Read Only):

Internal Operator Parameter Shortcut 对象，用于访问内部快捷方式。另请参阅 Internal Parameters。 注意： 相对于当前操作符搜索的该方法的版本也在全局 td Module 中。

valid → bool (Read Only):

如果引用的操作符当前存在则为 True，如果已被删除则为 False。

supported → bool (Read Only):

在当前操作系统上受支持则为 True。

passive → bool (Read Only):

如果为 true，操作符在调用其访问方法之前不会计算。要使用操作符 n 的被动版本，请使用 passive(n)。

time → OP (Read Only):

定义该操作符时间参照的 Time Component。

ext → Ext (Read Only):

用于搜索父级 extensions 的对象。

me.ext.MyClass

获取一个 module on demand 对象，它相对于该操作符搜索 DAT 模块。

fileFolder → str (Read Only):

返回保存该节点的文件夹。

filePath → str (Read Only):

返回该节点的文件位置。

replicator → OP (Read Only):

创建该操作符的 replicatorCOMP（如果有）。

storage → dict (Read Only):

Storage 是与该操作符关联的字典。存入该字典的值是持久的，会随操作符一起保存。字典属性本身只读，但其内容不是。其内容可以用下文所述的 OP.fetch() 或 OP.store() 等方法直接操作，或用 Examine DAT 查看。

tags → set :

获取或设置一组用户定义的字符串。可以用 OP.findChildren() 和 OP Find DAT 搜索 Tags。

该集合是普通的 Python set，可以按此方式访问：

n.tags = ['effect', 'image filter']
n.tags.add('darken')

该操作符内部包含的 operators 列表。只有 component 操作符才有子级，否则返回空列表。

numChildrenRecursive → int (Read Only):

返回该操作符内部递归包含的操作符数量。只有 component 操作符才有子级。

enclosedBy → List[annotateCOMP] (Read Only):

包围此节点的 Annotate 操作符列表（可能为空）。另请参见 AnnotateCOMP.enclosedOPs。

方法

通用

注意：create()、copy() 和 copyOPs() 由父级操作符（一个组件）完成。更多信息见 COMP.create, COMP.copy and COMP.copyOPs methods。

pars(pattern)→ list[Par]:

返回与模式匹配的 parameter objects 列表（可能为空）。

  • pattern - 是遵循 Pattern Matching 规则的字符串，指定要返回哪些参数。
newlist = op('geo1').pars('t?', 'r?', 's?') # translate/rotate/scale 参数

注意：如果按名称搜索单个参数，使用下标运算符要高效得多。例如：

name = 'MyName1'
op('geo1').par[name]

parGroups(pattern)→ list[Par]:

返回与模式匹配的 parGroup objects 列表（可能为空）。

  • pattern - 是遵循 Pattern Matching 规则的字符串，指定要返回哪些参数。
debug(op('geo1').parGroups('p*'))

注意： 如果按名称搜索单个 ParGroup，使用下标运算符要高效得多。例如：

name = 'MyColor'
op('geo1').parGroup[name]

或者甚至：

op('geo1').parGroup.MyColor

ops(*patterns, includeUtility=False)→ List[OP]:

返回与该模式匹配的 OP 列表（可能为空），相对于该 OP 内部。

可以提供多个模式。也可以使用数字形式的 OP id。ops 成员严格来说是一个 Python Shortcut Object，而不是真正的方法。

  • pattern - 可以是遵循 Pattern Matching 规则的字符串，指定要返回哪些 OP；也可以是整数，此时必须是 OP Id。可以给出多个模式，将返回所有匹配的 OP。
  • includeUtility -（关键字，可选）如果指定，控制结果中是否包含实用组件（例如 Comments）。

注意： 相对于 '/' 搜索的该方法的版本也在全局 td module 中。

newlist = n.ops('arm*', 'leg*', 'leg5/foot*')

cook(force=False, recurse=False, includeUtility=False)→ None:

如有需要，计算该操作符的内容。

  • force -（关键字，可选）如果为 True，操作符将始终计算，即使在正常情况下不会计算。
  • recurse -（关键字，可选）如果为 True，该操作符的所有子级和子子级都会被计算。
  • includeUtility -（关键字，可选）如果指定，控制结果中是否包含实用组件（例如 Comments）。

copyParameters(OP, custom=True, builtin=True)→ None:

从指定的 operator 复制所有参数。两个操作符应当是同一类型。

  • OP - 要复制的操作符。
  • custom -（关键字，可选）为 True 时会复制自定义参数。
  • builtin -（关键字，可选）为 True 时会复制内置参数。
op('geo1').copyParameters( op('geo2') )

changeType(OPtype)→ OP:

把引用的操作符改为新的操作符类型。调用之后不应再引用这个 OP 对象，而应改用返回的 OP 对象。

  • OPtype - 你想把该操作符改成的那种操作符类型的 Python 类名。这不是字符串，而是全局 td module 中定义的类。
n = op('wave1').changeType(nullCHOP) # 把 'wave1' 变成 Null CHOP
n = op('text1').changeType(tcpipDAT) # 把 'text1' 操作符变成 TCPIP DAT

dependenciesTo(OP)→ list:

返回该操作符与指定操作符之间的操作符依赖路径列表（可能为空）。可能找到多条路径。

evalExpression(str)→ Any:

从该 OP 的上下文中对表达式求值。可用于从任意位置对任意代码片段求值。

  • str - 要求值的表达式。
op('wave1').evalExpression('me.digits')  # 返回 1

如果表达式已经存在于某个参数中，请改用该参数的 evalExpression() 方法。

destroy()→ None:

销毁该 OP 引用的操作符。如果该 OP 的操作符已经被销毁，将抛出异常。

var(name, search=True)→ str:

对 variable 求值。如果找不到，将返回空字符串。从变量中获得的大部分信息（Root 和 Component 变量除外）在 Python 中都可以通过其他方式访问，通常是在全局 td module 中。

  • name - 要搜索的变量名。
  • search -（关键字，可选）如果设为 True（默认值），会搜索操作符层级，直到找到与该名称匹配的变量。如果为 false，搜索将限制在该操作符内。

openMenu(x=None, y=None)→ None:

在 x, y 处打开该操作符的节点菜单。如果未指定 x 和 y，则在鼠标位置打开。

  • x -（关键字，可选）菜单的 X 坐标，以屏幕像素计。
  • y -（关键字，可选）菜单的 Y 坐标，以屏幕像素计。

relativePath(OP)→ str:

返回从该操作符到作为参数传入的 OP 的相对路径。使用表达式的版本见 OP.shortcutPath。

setInputs(listOfOPs)→ None:

把该操作符的所有输入设为指定的列表。

  • listOfOPs - 包含一个或多个 OP 的列表。列表中的项可以为 None，以断开特定输入。空列表会断开所有输入。

shortcutPath(OP, toParName=None)→ str:

返回从该操作符到作为参数传入的 OP 的表达式。使用相对路径常量的版本见 OP.relativePath。

  • toParName -（关键字，可选）返回指向该参数（而不是其操作符）的表达式。

resetPars(parNames='*', parGroupNames='*', pageNames='*', includeBuiltin=True, includeCustom=True)→ bool:

重置该操作符中指定的参数。

如果有任何改动则返回 true。

  • parNames（关键字，可选） - 按 Par 名称指定参数。
  • parGroupNames（关键字，可选） - 按 ParGroup 名称指定参数。
  • pageNames（关键字，可选） - 按参数页名称指定参数。
  • includeBuiltin（关键字，可选） - 包含内置参数。
  • includeCustom（关键字，可选） - 包含自定义参数。
op('player').resetPars(includeBuiltin=False) # 只重置自定义项

unload(cacheMemory=False)→ None:

卸载该节点的 CPU 和 GPU 资源。下次该节点计算时会重新分配内存，因此要确保没有东西仍在使用它，以保持其已释放状态。

  • cacheMemory -（关键字，可选）目前仅由 Movie File In TOP 支持。如果你要预加载到一个已经有视频的 Movie File In TOP，且视频格式/分辨率相同，可以用 cacheMemory 选项先卸载原来的影片并缓存其内存，从而避免在 preload() 发生时重新分配。如果为 True，该影片的内存（纹理、上传缓冲区）会被缓存，供之后另一个影片使用。在你要用相同编解码器和分辨率打开/关闭许多影片时很有用。

asType(opType, checkType=False)→ OP:

把该 OP 转换为给定类型，以便编辑器做代码分析。返回该 OP。

  • opType - 要把该 OP 转换成的类型。
  • checkType：（可选）如果为 True，会检查该 OP 是否为给定的 asType，若不是则抛出异常。

  • recurse - 同时获取任何子级或子子级中的错误。

clearScriptErrors(recurse=False, error='*')→ None:

  • recurse - 同时清除任何子级或子子级中的脚本错误。
  • error - 清除错误时要匹配的模式
op('/project1').clearScriptErrors(recurse=True)

closeViewer(topMost=False)→ None:

关闭该 OP 的浮动内容查看器。

  • topMost -（关键字，可选）如果为 True，则会关闭任何包含该 OP 父级的查看器窗口。
op('wave1').closeViewer()
op('wave1').closeViewer(topMost=True) # 包含 'wave1' 的所有查看器都将被关闭。

openViewer(unique=False, borders=True)→ None:

为该 OP 打开一个浮动内容查看器。

  • unique -（关键字，可选）如果为 False，该 OP 已有的查看器会被复用并置于前台。如果 unique 为 True，则每次都新建一个窗口。
  • borders -（关键字，可选）如果为 true，容纳查看器的浮动窗口会带边框。
op('geo1').openViewer(unique=True, borders=False) # 为 'geo1' 打开一个新的无边框查看器窗口

resetViewer(recurse=False)→ None:

把该 OP 的内容查看器重置为默认视图设置。

  • recurse -（关键字，可选）如果为 True，也会对所有子级和子子级执行此操作。
op('/').resetViewer(recurse=True) # 重置整个文件中所有操作符的查看器。

openParameters()→ None:

打开一个包含该操作符参数的浮动对话框。

存储

Storage 可用于在组件内部保存数据。存储的实现方式是每个节点一个 Python 字典。

如下所述，使用 n.store() 改变存储中的元素时，依赖它的表达式和操作符会自动重新计算。可用 n.fetch() 函数取出。

存储在 .toe 和 .tox 文件中保存，并在启动时恢复。

存储可以保存任何 Python 对象类型（不只是 Tscript 变量那样的字符串）。存储元素还可以有可选的启动值，单独指定。例如，可以用这些启动值来避免保存和加载某个与本次会话相关的对象，转而保存或加载像 None 这样定义明确的对象。

以程序方式查看存储内容的方法见 Examine DAT。

fetch(key, default, search=True, storeDefault=False)→ Any:

从该 OP 的存储字典中返回一个对象。如果找不到该项，且提供了默认值，则返回该默认值。

  • key - 要取出的条目的名称。
  • default -（可选）如果提供，且找不到条目，则返回传入的值/对象。
  • storeDefault -（关键字，可选）如果为 True 且找不到该键，则连默认值一并存储。
  • search -（关键字，可选）如果为 True，会递归搜索每个 OP 的父级，直到找到匹配。
v = n.fetch('sales5', 0.0)

fetchOwner(key)→ OP:

返回包含该存储键的操作符，如果找不到则返回 None。

  • key - 你要找的存储条目的键。
who = n.fetchOwner('sales5') # 查找带有名为 'sales5' 的存储条目的 OP

store(key, value)→ Any:

把键/值对加入该 OP 的存储字典，如果已存在则替换。如果该值不打算在 toe 文件中保存和加载，可以用下文所述的 storeStartupValue 方法为保存和加载指定另一个值。

  • key - 存储条目的字符串名称。用该名称通过 fetch() 取出值。
  • value - 要存储的值/对象。
n.store('sales5', 34.5) # 存储一个浮点值 34.5。
n.store('moviebank', op('/project1/movies')) # 存储一个 OP，以便稍后快速访问。

unstore(*keys)→ None:

对每个键，把它从该 OP 的存储字典中移除。也支持模式匹配。

  • keys - 定义要从存储字典中移除哪些键/值对的名称或模式。
n.unstore('sales*') # 删除此 OP 存储中所有以 'sales' 开头的条目

storeStartupValue(key, value)→ None:

把键/值对加入该 OP 的存储启动字典。文件启动时，该存储元素会取这个值。

  • key - 存储启动条目的字符串名称。
  • value - 要存储的启动值/对象。
n.storeStartupValue('sales5', 1) # 'sales5' 在文件启动时将具有值 1。

unstoreStartupValue(*keys)→ None:

对键，把它从该 OP 的存储启动字典中移除。也支持模式匹配。这不会影响已存储的值，只会影响其启动值。

  • keys - 定义要从存储启动字典中移除哪些键/值对的名称或模式。
n.unstoreStartupValue('sales*') # 删除此 OP 的 startup 存储中所有以 'sales' 开头的条目

杂项

__getstate__()→ dict:

返回一个字典，其中是关于该对象的持久化数据，适用于 pickle 和深拷贝。

__setstate__()→ dict:

读取该字典以更新关于该对象的持久化细节，适用于 unpickle 和深拷贝。
