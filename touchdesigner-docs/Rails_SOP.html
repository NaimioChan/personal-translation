Rails SOP

摘要

Rails SOP 通过在两条轨道之间拉伸横截面来生成曲面。这与 Sweep SOP 类似，但它对横截面的朝向和缩放有更多控制。第一个 SOP 输入是要被复制的横截面，通常放置在 XY 平面中。第二个输入 SOP 源是横截面沿其复制的轨道。

参数 - 页

X-Section Groups xsectgrp - 你可以在此指定一个组，以使用 Cross-section 输入中的一部分图元。接受模式，如 Pattern Matching 中所述。
Rail Groups railgrp - 你可以在此指定一个组，以使用 Rails 输入中的一部分图元。接受模式，如 Pattern Matching 中所述。
Cycle Type cycle - - 选择横截面如何沿轨道应用。
  • All Primitives at Each Point all - 将 Cross-section 输入中的所有图元放置在骨架的每个点上。
  • One Primitive at a Time each - 与上面类似，但变换应用于各个图元而非整体。
  • Cycle Primitives cycle - 这在将传入图元放置到骨架上时会循环使用它们。即：从顶点 0 处的 0 开始，顶点 1 处为图元 1，依此类推。
Sweep along Pairs of Rails pairs - 沿轨道 1 与 2、3 与 4、5 与 6 等扫掠，而不是 1 与 2、2 与 3、3 与 4 等。
Sweep along First and Last Rail firstl - 在第一条和最后一条轨道之间连接横截面。
Stretch to Rails stretch - 将横截面几何拉伸到轨道几何。
Use Vertex usevtx - 指定横截面多边形的两个顶点，分别放置在 rail1 和 rail2 上。例如，在将第一个顶点保持在 rail1、第七个顶点保持在 rail2 上时非常有用。
Connection Vertices vertex - - 横截面连接到轨道的顶点。

Scale scale - 横截面的整体缩放。
Roll roll - 横截面围绕骨架的非累积旋转。所有横截面得到相同的旋转。
Fix Flipping noflip - 用于在未使用方向向量且两条轨道恰好交叉、导致法线上下翻转时纠正翻转的选项。
Use Direction usedir - 使用 X、Y 和 Z 坐标中指定的方向向量。否则将使用几何的法线。
Direction dir - - 要使用的方向向量。

Group Name railname - 在此字段中指定输出组的名称。接受模式，如 Pattern Matching 中所述。

Info CHOP 通道

Rails SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
