参数模式

每个 Parameter 都可以处于四种模式之一：Constant 模式、Expression 模式、Export 模式或 Bind（Binding）模式。

将光标移到任意参数上并按出现的 +。它会显示新的一行，可在此快速切换参数模式：

  • 常量值（灰色方框）
  • 表达式（蓝色方框）
  • 导出（绿色方框）
  • 绑定（紫色方框）

每个参数都保存一个常量值。可选地，可以为任意参数添加 python 表达式。参数可以在两种模式下保存不同的值，并可随时在常量或表达式模式之间切换。单击蓝色方框进入 python 表达式模式，单击灰色方框返回常量值模式。

只有在已存在到该参数的 Export 时才能选择导出模式。当创建到某参数的导出时，模式会自动设为导出。建立此导出连接后，参数可以随时设为常量或表达式，并切回导出。在开发或调试时，这有助于临时断开导出连接（即切换到常量模式并测试特定值）。

Binding 以双向连接将参数链接在一起。在此模式下，通过界面或 python 脚本更改值会同时更新（两个或多个）参数的值并使它们保持同步。

详情请参阅参数对话框中的 Working with Parameter Modes。

要使用 python 更改参数模式，请参阅 Par Class 的 mode 成员。
