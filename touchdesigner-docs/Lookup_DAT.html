Lookup DAT

摘要

Lookup DAT 从查找表输出值。第一个输入是第二个输入的索引。

Lookup DAT 允许你通过行/列索引或行/列名称引用数据，从第二个输入中选择行。Lookup DAT 的优势在于，数据被选择的顺序与 Lookup Table 中的顺序无关，而由 Index Table 决定顺序，因此可以重排数据，并多次选择行/列。

lookupDAT_Class

参数 - Lookup 页

Index index - - 选择索引值的解释方式：作为列中包含的值/索引，或作为行中包含的值/索引。
  • Row Indices rowindices - 在 Lookup DAT 中选中的行以数字索引表示在 Index 输入中。
  • Col Indices colindices - 在 Lookup DAT 中选中的列以数字索引表示在 Index 输入中。
  • Row Values rowvalues - 在 Lookup DAT 中选中的行以值的形式表示在 Index 输入中。默认使用第一列来匹配索引，但可通过设置 Value Location 以及 Name 或 Index 参数来更改。
  • Col Values colvalues - 在 Lookup DAT 中选中的列以值的形式表示在 Index 输入中。默认使用第一行来匹配索引，但可通过设置 Value Location 以及 Name 或 Index 参数来更改。
Value Location valueloction - - 当 Index Parameter 中选择 'Row Values' 或 'Col Values' 时，此参数让你选择如何指定用于搜索索引值的查找行或列。
  • Name name - 查找行或列按名称指定。
  • Index index - 查找行或列按索引指定。
Value Name valuename - 指定查找行或列的名称。
Value Index valueindex - 指定查找行或列的索引。
Include Header includeheader - 包含第一行或第一列。

Info CHOP 通道

Lookup DAT 的额外信息可通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
