Cache SOP

摘要

Cache SOP 将其输入的几何收集到缓存中，以便对多个 SOP 进行更快的随机访问播放。当一串 SOP 的计算时间较长、需要更快播放时，应使用它。

缓存之后，几何可以按任意顺序访问。这对 2D 翻页书或场景渲染很有优势，因为几何仍然是完整的三维。结果是，由于内容已预先计算并存入缓存，你可以实时拖动原本卡顿的动画。

cacheSOP_Class

参数 - 页

Active active - 开启时，此节点每次计算都会缓存其输入几何的一个快照。
Pre-Fill prefill - 计算 'Cache Size' 次，以用几何填满 Cache SOP。设为 > 0 时会填充缓存。播放时设为 > 0，会立即填充。设为 > 0 并保存后，下次打开文件时缓存会预填充。当此值 > 0 时，节点的行为就像 'On' 参数为 0。若先设为 0，再设回 > 0，它会清除之前的数据并重新预填充。更多信息请参阅 Pre-Filling 一文。
Cache Size cachesize - 缓存的大小。
Step Size step - 节点在缓存下一个几何之前要计算的帧数。设为 1 时每次计算都缓存，设为 2 时每两次计算缓存一次，依此类推。
Output Index outputindex - 决定输出哪个缓存的几何。0 为最近缓存的几何。有效值在 0 到 cachesize - 1 之间。
Cache Points Only cachepoints - 为第一个缓存的几何保存单一拓扑，其余几何只保存点数据。
Blend Position blendpos - 在几何之间插值点。
Reset reset - 开启时，清除所有缓存的几何。
Reset Pulse resetpulse - 立即清除所有缓存的几何。

操作符输入

  • Input 0: -

Info CHOP 通道

Cache SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
