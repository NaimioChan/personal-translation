Constant CHOP

摘要

Constant CHOP 创建新的常量值通道。每个通道都可以命名并赋予不同的值。要创建通道，只需在 Constant 页的名称参数中输入通道名称，然后调整下方的值。

默认情况下 CHOP 区间（时间长度）为一个采样长（索引 0 处的一个采样 = 第 1 帧）。区间范围可以选择在 Channel 页中设置。

你可以像 geo[1-4][xyz] 那样使用 Pattern Expansion，在一行中生成多个通道。

不带输入的简单 Constant CHOP 是 CHOP 最常见的用法。不过，也可以通过把任意 CHOP 连接到它的输入并点击 Snapshot Input 按钮（Snap 页）来设置通道名称和值。这让你能从另一个 CHOP 取得一些通道，并在 Constant CHOP 中用滑块调整它们。

第二个输入可用于为常量值添加偏移。当第二个输入（Active）大于零时，第一个输入的任何变化都会被加到 CHOP 的输出上。这对于从 MIDI 滑块盒等外部输入设备调整 Constant CHOP 的值很有用。例如，你可以把鼠标或 MIDI 滑块盒连接到 Mouse In CHOP 或 MIDI In CHOP，并在移动鼠标或滑块时按住 Active 输入为 On，从而调高/调低 Constant CHOP 的值。

constantCHOP_Class

参数 - Constant 页

如果 Name 字段中有名称，就会创建该通道。你可以在 Name 字段中输入通道名称模式，从而用相同的值创建许多通道。例如，试着输入： 

geo[1-5:2]:s[xyz]

在第一个通道字段中输入，而不是「chan1」。参见 Pattern Expansion、Pattern Matching。

Constant const - 定义通道的名称/值对序列
Name const0name - 通道的名称。
Value const0value - 通道的值。

参数 - Snap 页

Constant CHOP 可以用 Snap 页预设其通道名称和值。我们常常想抓取一些通道（Snapshot）然后再编辑它们。

Snapshot Input snap - Constant 上可选的第一路 CHOP 输入在按下 Snapshot Input 按钮时使用。此时，当前帧 CHOP 输入处的通道名称和值会被用来初始化常量滑块的通道名称和值。

要从其他 OP 抓取通道，把一个 Parameter CHOP 连接到 Constant CHOP 并按 Snapshot Input。

你可以从脚本中模拟按下 Snapshot Input 按钮。要从脚本模拟点击 CHOP 对话框按钮，使用 Par Class pulse() 方法：

示例： 

op('constant1').par.snap.pulse()
First Channel first - First Channel 参数用于选取传入通道中较小的一组。当传入通道数量超过 Constant CHOP 能容纳的 40 个通道、必须拆到几个 CHOP 中时，这很有用。
Active Needs Current current - 如上文所述与第二个输入配合使用，适用于你想借助外部设备或来源为通道添加位移的情况。
当 Active Needs Current 为 On 时，只有当 Constant CHOP 是当前 CHOP，第二个 CHOP 输入（Active 输入）才会生效。
当 Active Needs Current 为 Off 时，只要 Active 输入开启（大于 0），Constant CHOP 就会受影响。
Channel Editor 在用 CHOP 编辑关键帧时会用到它。像 Keyboard In CHOP 中的按钮或 MIDI 键盘这样的输入设备，可以接入多个 Constant CHOP 的 Active 输入。如果此选项为 On，则只有当前 CHOP 会受影响。

Single Sample single - 将其关闭可创建长于一个采样的常量通道。
Start start - 区间的起点和终点，以 Units（秒、帧或采样）表示。这些参数以 Common 页上的 Units 表示。要把 CHOP 设为 100 个采样长，将 Units 设为 Samples，Single Frame 设为 Off，Start / End 设为 0 和 99。

End Unit endunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
  • I samples -
  • F frames -
  • S seconds -
Sample Rate rate - 通道的采样率，单位为每秒采样数。
Extend Left left - 左侧 extend 条件（范围之前）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道起点之前的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Extend Right right - 右侧 extend 条件（范围之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道终点之后的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Default Value defval - 用于 Default Value extend 条件的值。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Constant CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
