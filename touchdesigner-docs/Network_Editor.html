网络编辑器

Network Editor 是 TouchDesigner 中的一种窗格类型，用于创建和修改 Operators。Network Editor 是 TouchDesigner 的默认窗格类型，程序启动时即可见。在 Network Editor 中导航是应尽早掌握的重要技能。熟练掌握 Network Editor 后，你就能随时间更轻松地修改和更新网络。网络导航的主要工具是鼠标，不过某些操作也有菜单或键盘等价方式。每个鼠标按键都以不同方式操作 Network Editor 界面。

网络导航

节点选择

使用鼠标左键 LMB 选择节点。要框选多个节点，按住 shift 同时用 LMB 拖动，或使用 RMB。也可以按住 Ctrl 键，逐个左键单击要加入选择的节点。要移动节点，先选中它，然后按住 LMB 在网络编辑器中拖动。

在网络中平移

鼠标左键（LMB）导航网络时不改变缩放级别。在网络中的任意空白区域按住 LMB 拖动即可平移网络。可用「o」键开启或关闭网络的缩放「总览」视图。

缩放

鼠标中键 MMB 控制缩放级别，按住 MMB 向右或向左拖动可放大或缩小。要回到 Unity Zoom（缩放级别为 1），可使用 Unity Frame All 的快捷键「f」。

如果鼠标中键同时也是滚轮，向前滚动可放大，向后滚动可缩小。

也可以按住 Ctrl 并使用 MMB 框选缩放。要放大，按住 Ctrl 用 MMB 从左向右画框。要缩小，则从右向左画框。

在网络之间切换

有多种方式进出组件网络。

进入网络（进入组件内部）：

  • 双击组件即可进入其网络
  • 用滚轮放大到组件近处，继续放大即可进入其网络
  • 选中组件，然后按 <Enter> 键进入其网络
  • 选中组件，然后按 i 键进入其网络
  • 选中组件，然后按 pane 顶部的 network path 中的「双箭头」
  • 在组件上点击 RMB，然后从菜单中选择 Enter Component

在组件内部时，要向上返回一级：

  • 按 u 键
  • 用滚轮缩小
  • 在 pane 顶部的 network path 中，点击你想查看的组件名称。例如，如果路径是 /project1/scene1/geo2，而你想去 /project1，只需点击「project1」这个词。
  • 你可能会发现顶部 pane bar 中的 Back 和 Forward 按钮在进出组件时很方便。

与操作符交互

以下是在 Network Editor 中可执行的其他一些交互。

  • 用 LMB 抓住节点边缘并拖动，可调整节点大小
  • 网格吸附默认开启，可在 Preferences（Edit -> Preferences -> Network）中调整网格选项
  • 布局和显示选项位于 Network Editor 的右键菜单中
  • 点击右下角的 Viewer Active 标记，Node Viewers 即可进入 Viewer Active 模式（交互模式）。
  • 中键单击节点会打开操作符信息弹窗。
  • 操作符上的 Flags 可用于切换其状态（显示状态、渲染状态、可拾取状态等）
  • 动画的 Wires 表示操作符之间的数据流。
  • 按 shift+t 快捷键，或从右键菜单中选择，可将 Network Editor 切换为 list mode。
