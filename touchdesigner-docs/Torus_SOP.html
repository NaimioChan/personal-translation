Torus SOP

摘要

Torus SOP 生成完整或特定部分的圆环形状（如甜甜圈）。

torusSOP_Class

参数 - Torus 页

Primitive Type type - 从以下类型中选择。各类型的说明见 Geometry 分类文章。
  • Polygon poly -
  • Mesh mesh -
  • NURBS nurbs -
  • Bezier bezier -
Connectivity surftype - 使用 Mesh 图元类型时，此选项用于选择曲面类型。
  • Rows rows - 创建水平线。
  • Columns cols - 创建垂直线。
  • Rows and Columns rowcol - Rows 和 Columns 都勾选。在线框显示下看起来像四边形，但所有多边形都是开放的（如果图元类型为 polygon）。
  • Triangles triangles - 用三角形构建网格。
  • Quadrilaterals quads - 生成由四边形构成的侧面（默认）。
  • Alternating Triangles alttriangles - 生成相对的三角形；类似于 Triangles 选项。
Orientation orient - 构建圆环所沿的轴。
  • X Axis x -
  • Y Axis y -
  • Z Axis z -
Modify Bounds modifybounds - 仅当有输入连接到 Torus SOP 为圆环设定包围盒时启用。把 Modify Bounds 设为 On，即可用下面的变换参数进一步修改包围盒的位置和半径。
Radius rad - 第一个值（radx）定义圆环半径，第二个值（rady）确定内环半径。

  • X radx -
  • Y rady -
Center t - 圆环中心相对物体原点的偏移。
  • X tx -
  • Y ty -
  • Z tz -
Reverse Anchors reverseanchors - 反转锚点的方向。
Anchor U anchoru - 设置 X 方向上的点，几何围绕该点定位、缩放和旋转。
Anchor V anchorv - 设置 Y 方向上的点，几何围绕该点定位、缩放和旋转。
Anchor W anchorw - 设置 Z 方向上的点，几何围绕该点定位、缩放和旋转。
Rows rows - 行定义沿圆环的分段数。
Columns cols - 列决定沿圆环横截面的分段数。

参数 - Detail 页

Angle Offset angleoffset - 沿小半径旋转圆环。例如，若使用 4 行，把此值设为 45 可得到平的顶面和底面。
Imperfect imperfect - 此选项仅适用于 Bezier 和 NURBS 类型。选中时，管状体为近似的非有理曲线，否则为精确的有理曲线。
U Order orderu - 若选择了样条曲线，U 和 V 都按此阶数构建。
V Order orderv - 若选择了样条曲线，U 和 V 都按此阶数构建。
U Angle angleu - 圆环的起始和结束扫掠角度（若未启用 U Wrap）。
  • beginangleu -
  • endangleu -
V Angle anglev - 这些是扫掠成圆环的横截面圆的起止角度（若未启用 V Wrap）。
  • beginanglev -
  • endanglev -
U Wrap closeu - 若勾选 U Wrap，会创建 360 度横截面。
V Wrap closev - 勾选 V Wrap 会通过封闭图元沿 V 创建圆环。
U End Caps capu - 若勾选 U End Caps，当圆环小于 360 度时，会在其两端加上分面端盖。

如需更多封盖选项，关闭此参数，并附加一个 Cap SOP。

V End Caps capv - 若勾选 V End Caps，当圆环开口时，会在圆环顶部与底部之间补一个面。

如需更多封盖选项，关闭此参数，并附加一个 Cap SOP。

Texture Coordinates texture - 为 Torus SOP 创建的几何添加 uv 坐标。
  • Off off - 不添加 uv 坐标。
  • Row & Columns rowcol - 基于几何中的 Rows 和 Columns 添加 uv 坐标。
Compute Normals normals - 勾选此项为 On 会计算曲面法线。

Info CHOP 通道

Torus SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
