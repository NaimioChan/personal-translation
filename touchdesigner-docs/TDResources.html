TD 资源

TDResources 是一个包含 TouchDesigner 系统资源的组件，其中一些可在你的项目中使用。通过其 Global OP Shortcut 访问 TDResources：op.TDResources。注意： 这些资源在未来的 TouchDesigner 版本中会继续提供，但外观可能变化。例如，系统 popMenu 会一直可用，但颜色和字体可能改变。

弹出菜单

系统弹出菜单是 popMenu 的克隆，可通过 op.TDResources.PopMenu.Open(...) 使用。它常用于 RMB 选项菜单，也有 2 层子菜单可用。示例代码： 

op.TDResources.PopMenu.Open(['Go', 'Stop'], callback=debug, callbackDetails=['test'])

完整文档请参阅 Palette:popMenu 和 PopMenu Custom COMP Examples。

按钮弹出菜单

系统按钮弹出菜单同样是 popMenu 的克隆，可通过 op.TDResources.ButtonPopMenu 使用。它常用于按下按钮时弹出、并希望菜单与该按钮对齐的场景，但技术上可以让菜单与任何 Panel Component 对齐。它没有可用的子菜单。

它与上面的系统弹出菜单的区别在于：它用于附加到按钮上，且 the Buttoncomp, Horizontalattach, and Verticalattach parameters must be set before calling Open. 示例代码： 

buttonPopMenu = op.TDResources.ButtonPopMenu
buttonPopMenu.par.Buttoncomp = op('/myButtonPanel')
buttonPopMenu.par.Horizontalattach = 'Left'
buttonPopMenu.par.Verticalattach = 'Top'
buttonPopMenu.Open(['Go', 'Stop'], callback=debug, callbackDetails=['test'])

popMenu 的文档请参阅 Palette:popMenu 和 PopMenu Custom COMP Examples。

鼠标

op.TDResources.MouseCHOP 中有一个可供系统使用的 CHOP 鼠标信息。可以用它获取鼠标状态，无需自己搭建 Mouse In CHOP。使用 Select CHOP 可以查看所有通道并访问这些信息。也可以直接用代码访问： 

mouse = op.TDResources.MouseCHOP
normalizedMouseX = mouse['tx']
absoluteMouseX = mouse['abs_mouse_x']
leftButton = mouse['left_button']

WebClient

通过 op.TDResources.WebClient 提供了一个简单的 Web Client DAT 接口。你可以在 Python 中调用以下函数请求数据： op.TDResources.WebClient.Request(callback, url, method *args)

  • callback - 用于接收回复并调用的函数。它应具有以下参数：statusCode、headerDict、data、id。如果请求超时，这些都会是 None（id 除外）。
  • url - 要向其发送 HTTP 请求的 URL 字符串。
  • method - 作为字符串的 HTTP 请求方法。必须是以下之一："GET"、"POST"、"PUT"、"DELETE"、"HEAD"、"OPTIONS" 或 "PATCH"
  • *args - 其余参数会直接传给 web 客户端，所有选项可在 request 函数的文档中找到：WebclientDAT Class

FileDownloader

通过 op.TDResources.FileDownloader 提供了一个文件下载工具。你可以用它的 .Download() 方法下载文件。 除了下载到磁盘，也可以把文件直接下载到项目中，这主要用于 .tox 组件。

可通过调用以下函数初始化文件下载： 

op.TDResources.FileDownloader.Download(self, url:str = None, location:str = None, loadIntoProj:bool = False, 
				 compPath:COMP = None, discCopy:bool = False, dwnldCopy:Optional[bool] = None, 
				 renameTo:str = None, doneCallback=None, abortCallback=None, progressCallback=None, reqMethod:str = 'GET', 
				 reqData:dict = {}, reqPars:dict = {}, authType:str = None, username:str = None, 
				 password:str = None, appKey:str = None, appSecret:str = None, oauth1Token:str = None, oauth1Secret:str = None, 
				 oauth2Token:str = None, uploadFile:str = None, force:bool = False, clear:bool = True, showProgress:Optional[bool]=None)
  • url（str，可选）：下载数据的 url。默认为 None。
  • location（str，可选）：保存文件的位置。默认为 None。
  • loadIntoProj（bool，可选）：如果为 True，文件会被载入项目。默认为 False。
  • compPath（COMP，可选）：将文件载入到的 COMP。仅在 loadIntoProj 为 True 时相关。默认为 None。
  • discCopy（bool，可选）：如果为 True，文件会被复制到磁盘。仅在 loadIntoProj 为 True 时相关。默认为 False。
  • dwnldCopy（Optional[bool]，可选）：定义如何处理已存在的文件：None - 返回现有文件路径，True - 创建文件副本，False - 覆盖现有文件。默认为 None。
  • renameTo（str，可选）：下载文件的最终名称。默认为 None。
  • doneCallback（_type_，可选）：下载成功完成时调用的自定义回调函数。默认为 None。
  • abortCallback（_type_，可选）：下载被中止时调用的自定义回调函数。默认为 None。
  • progressCallback（_type_，可选）：下载有进展时调用的自定义回调函数。默认为 None。
  • reqMethod（str，可选）：用于下载的 HTTP 请求方法。默认为 'GET'。必须是以下之一："GET"、"POST"、"PUT"、"DELETE"、"HEAD"、"OPTIONS" 或 "PATCH"
  • reqData（dict，可选）：在请求体中发送的数据。默认为 {}。
  • reqPars（dict，可选）：请求的查询参数。这些参数会经过 URL 编码并附加到 URL 后。默认为 {}。
  • authType（str，可选）：认证类型的字符串，不区分大小写。默认为 None（即不认证），如果填写，必须是以下之一：basic、oauth1、oauth2。
  • username（str，可选）：basic 认证的用户名。默认为 None。
  • password（str，可选）：basic 认证的密码。默认为 None。
  • appKey（str，可选）：oauth1 认证的 application key。默认为 None。
  • appSecret（str，可选）：oauth1 认证的 application secret。默认为 None。
  • oauth1Token（str，可选）：oauth1 认证的 oauth1 token。默认为 None。
  • oauth1Secret（str，可选）：oauth1 认证的 oauth1 secret。默认为 None。
  • oauth2Token（str，可选）：oauth2 认证的 oauth2 token。默认为 None。
  • uploadFile（str，可选）：请求中要上传的文件的路径。仅在 PUT 请求方法下有效。默认为 None。
  • force（bool，可选）：强制下载并跳过队列。默认为 False。
  • clear（bool，可选）：如果希望在成功下载或中止下载后，stateDict 响应仍保留以供此函数最后一次调用，则设为 false。当外部调用不断探测此函数以返回下载状态时，这很有用。默认为 True。
  • showProgress（Optional[bool]，可选）：如果为 True，将显示进度窗口。默认为 None。
