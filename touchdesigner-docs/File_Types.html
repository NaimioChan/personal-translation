文件类型

TouchDesigner 可以导入和导出大多数常见的媒体文件格式。可以通过以下方式将文件加载到 TouchDesigner：

  • Drag-and-Drop：将文件直接拖入 TouchDesigner 并放下，即可自动创建一个操作符或组件。
  • Open With... 菜单：在 Windows 中右键点击 TouchDesigner 支持的文件，选择 Open With...->TouchDesigner 0xx，即可启动 TouchDesigner 并预先加载该文件。
  • 使用 Movie File In TOP、File In CHOP、File In POP、Audio File In CHOP、glTF In COMP 等操作符加载文件。文件可从磁盘加载，也可通过 http://file-url 从网络加载。
  • 使用操作系统 shell 命令 touchdesigner filename.ext 启动 TouchDesigner，它会预先加载你的文件。

TouchDesigner 原生文件

TouchDesigner 有三种原生文件类型：

  • .toe：TouchDesigner Environment 文件是创建工程的默认文件类型。
  • .tox：TouchDesigner Component 文件让你保存组件。.tox 文件使组件库可以复用和移植。
  • .tog：TouchDesigner Geometry 文件是其他几何类型以 TouchDesigner 原生格式导出的结果。
