Null POP

摘要

Null POP 不做任何事——它将输入原样传递到输出。它不消耗任何 CPU 或 GPU 内存。

它用作占位符。在构建 POP 链时，最佳实践是在末端放一个 Null POP，给它起个有意义的名字，然后在更下游引用该 Null POP，这样你就可以在链中插入新的 POP，而不必考虑 Null 连接在哪里。

注意，POP 通常不会为未被该 POP 改变的属性占用内存。例如，如果 Math POP 的输入有 P、Tex 和 Color 属性，而 Math POP 只影响 Color 属性，它不会复制 P 和 Tex 属性的内存——它会「指向」或从最后一次修改或创建它们的 POP 处获取 P 和 Tex。POP 上的弹出信息（中键单击）会显示哪些属性是引用（旁边带有 (r)）。

Info CHOP 通道

Null POP 的额外信息可通过 Info CHOP 查看。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
