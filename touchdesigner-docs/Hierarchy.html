层级

Hierarchy 把组件与其他组件关联起来。层级让一个组件可以相对另一个组件定位。

TouchDesigner 中有两组 Hierarchy：3D Object Components 和 2D Panel Components。每组都可以通过节点底部/顶部之间的连线（Wires）连接，或把一个组件放在另一个组件内部来建立关联。

  • 对于 3D 对象层级，意味着 3D 对象与其他 3D 对象相连，可以在 3D 中作为一个整体、或彼此相对地被移动/旋转/缩放（变换）。
  • 对于 2D 面板层级，意味着面板包含在其他面板内部，面板可以组成更大的用户界面。通过调整参数，面板可以作为一组、或彼此相对地移动和缩放。

如前所述，每组都可以用两种方式关联/连接：

  1. 通过连接节点底部/顶部之间的线（如上面的示例所示）。上面的节点是父级，下面的节点是子级。子级可以通过其变换参数相对父级进行变换。
  2. 通过把一个组件放在另一个组件内部。里面的节点是子级，包含它的节点是父级。子级可以通过其变换参数以及父级的 Layout 参数相对父级进行变换。你可以在每个网络顶部的 Pane Bar 中看到 Network Path 层级。

层级线总是连接同一组件组中的节点。

要在操作符处于同一网络的情况下创建层级：

  1. 左键点击组件的底部或顶部连接器。
  2. 把光标移到你想连接的组件的顶部/底部连接器。
  3. 再点击一次完成连接。

或者使用嵌入方式：对于面板，把一个面板放进另一个面板里。对于 3D 对象，把一个 3D 对象放进 3D 对象里。


（「Hierarchies」在文件系统之外也存在，Python 数据结构中也有，但这里不适用也未涵盖。）
