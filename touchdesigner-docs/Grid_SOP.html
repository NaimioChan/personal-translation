Grid SOP

摘要

Grid SOP 让你可以使用多边形、网格、Bzier 和 NURBS 曲面，或使用开放多边形生成多条线，来创建网格和矩形。

gridSOP_Class

参数 - 页

Primitive Type type - - 从以下类型中选择。关于不同种类的信息，参见 Geometry Types 一节。取决于所选的图元类型，部分 SOP 选项可能不适用。
  • Polygon poly -
  • Mesh mesh -
  • NURBS nurbs -
  • Bezier bezier -
Connectivity surftype - - （结果仅对多边形和网格可见）。
  • Rows rows - 创建水平线。
  • Columns cols - 创建垂直线。
  • Rows and Columns rowcol - 同时按行和列。在线框显示中看起来像四边形，但如果图元类型是多边形，所有多边形都是开放的。可在 Model Editor 中比较它们。
  • Triangles triangles - 用三角形构建网格。
  • Quadrilaterals quads - 生成由四边形构成的侧面（默认）。
  • Alternating Triangles alttriangles - 生成相互对置的三角形；类似 Triangles 选项。
Orientation orient - - 指定 Grid 建立在哪个平面上。
  • XY Plane xy -
  • YZ Plane yz -
  • ZX Plane zx -
Modify Bounds modifybounds - 仅当有输入连接到 Grid SOP 以设置网格边界时才启用。把 Modify Bounds 设为 On，即可启用下面的变换参数，进一步修改边界的位置和缩放。
Size size - - 网格的 X 和 Y 缩放。
  • X sizex -
  • Y sizey -
Center t - - 网格在 X、Y 和 Z 上的中心。
  • X tx -
  • Y ty -
  • Z tz -
Reverse Anchors reverseanchors - 反转锚点的方向。
Anchor U anchoru - 设置 X 方向上的点，几何围绕该点定位、缩放和旋转。
Anchor V anchorv - 设置 Y 方向上的点，几何围绕该点定位、缩放和旋转。
Rows rows - 行数和列数。Rows 是水平线，Columns 是垂直线。两行两列构成正方形或矩形。例如，若 Connectivity 设为 Rows，一行两列就构成一条单独的线。

对于 NURBS 和 Bzier 曲面，Rows 与 Cols 指的是曲面壳体的构造，因此 Rows 和 Cols 的数量不应小于 U 或 V 方向的 Order。

Columns cols - 行数和列数。Rows 是水平线，Columns 是垂直线。两行两列构成正方形或矩形。例如，若 Connectivity 设为 Rows，一行两列就构成一条单独的线。

对于 NURBS 和 Bzier 曲面，Rows 与 Cols 指的是曲面壳体的构造，因此 Rows 和 Cols 的数量不应小于 U 或 V 方向的 Order。

U Order orderu - U Order：U 参数方向上样条基的次数 +1。
V Order orderv - V Order：V 参数方向上样条基的次数 +1。
End Point Interpolate in U interpu - End-point interpolate in U：扩展曲面，使其在 U 方向上触及端点。
End Point Interpolate in V interpv - End-point interpolate in V：扩展曲面，使其在 V 方向上触及端点。
Texture Coordinates texture - - 为 Grid SOP 创建的几何添加 uv 坐标。
  • Off off - 不添加 uv 坐标。
  • Row & Columns rowcol - 基于几何中的 Rows 和 Columns 添加 uv 坐标。
Compute Normals normals - 勾选此项为 On 会计算曲面法线。

操作符输入

  • Input 0: -

Info CHOP 通道

Grid SOP 的附加信息可以通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
