ParGroup 类

ParGroup 类描述单个 ParGroup 的实例。

另请参阅 Custom Parameters。

成员

bindExpr → Tuple[str, ...] :

获取或设置返回要绑定对象的表达式。可用于将此参数的常量值绑定到所引用对象的值。

示例： 

p.bindExpr = ("op('geo1').par.tx", "op('geo1').par.ty", "op('geo1').par.tz")

注意外层的引号，因为 bindExpr 是表达式，不是对象。

bindMaster → tuple (Read Only):

此参数绑定到的对象，可能为 None。

bindRange → bool :

获取或设置参数的范围绑定状态。若为 True，min、max、clampMin、clampMax、normMin、normMax、normVal 值会基于主绑定参数。只能设置在自定义参数上。

bindReferences → tuple (Read Only):

绑定到此参数的对象列表（可能为空）。

clampMax → Tuple[float, ...] :

获取或设置参数的数值钳制行为。若设为 clampMax = True，参数将在 max 指定的值处钳制上端。只能在自定义参数上设置。

clampMin → Tuple[bool, ...] :

获取或设置参数的数值钳制行为。若设为 clampMin = True，参数将在 min 指定的值处钳制下端。只能在自定义参数上设置。

collapsable → bool (Read Only):

若参数可折叠，则返回 True。

collapser → bool (Read Only):

若参数是可折叠参数的父级（即可折叠组），则返回 True。

default → tuple :

获取或设置参数的默认值。只能在自定义参数上设置。

defaultExpr → Tuple[str, ...] :

获取或设置参数的默认表达式。只能在自定义参数上设置。

# 该值默认取此表达式。
op('base1').parGroup.Size.defaultExpr = ('me.time.frame', 'me.time.frame', 'me.time.frame')

defaultBindExpr → Tuple[str, ...] :

获取或设置参数的默认绑定表达式。只能在自定义参数上设置。

# 该值默认取此表达式。
op('base1').parGroup.Size.defaultBindExpr = ('me.par.tx', 'me.par.ty', 'me.par.tz')

defaultMode → Tuple[ParMode, ...] :

获取或设置参数的求值模式。

op('geo1').parGroup.t.defaultMode = (ParMode.EXPRESSION, ParMode.EXPRESSION, ParMode.EXPRESSION)

模式为以下之一：ParMode.CONSTANT、ParMode.EXPRESSION、ParMode.EXPORT 或 ParMode.BIND。

更多信息见 Parameter_Dialog#Working_with_Parameter_Modes。

enable → bool :

获取或设置参数组的启用状态。只能在 Custom Parameters 上设置。这也会设置组内所有单个参数的 enable 成员。

enableExpr → str :

获取或设置控制此参数组启用状态的表达式。该成员由所有参数和参数组共享。

p.enableExpr = "me.par.X.menuIndex == 5"
# 注意外层的引号，因为这是表达式而非对象。

TouchDesigner 2023.30000+

如果表达式是 lambda 函数，则会为参数组中的每个参数调用一次，并以索引作为参数……

rgbaPar.enableExpr = "lambda parIndex: parIndex < 3" # 启用前 3 个元素
rgbaPar2.enableExpr = "lambda parIndex: parIndex >= 3" # 启用第 4 个元素

exportOP → Tuple[OP | None, ...] (Read Only):

导出到此参数的操作符。

exportSource → Tuple[Cell | Channel | None, ...] (Read Only):

导出到此参数的对象元组。示例：Cell、Channel 或 None。

expr → Tuple[str, ...] :

仅获取或设置未求值的表达式。要获取参数的当前值（无论参数模式为常量、表达式、导出还是绑定），请使用下文所述的 eval() 方法。

op('geo1').parGroup.t.expr = ('absTime.frame', 'absTime.frame', 'absTime.frame')  
# 设置成与当前帧一致

设置此成员时，参数也会被置于表达式模式。见下面的 mode 成员。

注意： 为方便起见，表达式用双引号括起，这样你可以安全地放入包含单引号的表达式。'a' 和 "a" 在 Python 中括起字符串的效果相同。

help → str :

获取或设置自定义参数的帮助文本。要查看任意参数的帮助，按住 Alt 键并将鼠标悬停在参数上。

isDefault → bool (Read Only):

当参数的值、表达式和模式都处于默认设置时为 True。

isCustom → bool (Read Only):

自定义参数为 True。

isFloat → bool (Read Only):

浮点数值参数为 True。

isInt → bool (Read Only):

整数数值参数为 True。

isMenu → bool (Read Only):

菜单参数为 True。

isMomentary → bool (Read Only):

瞬时参数为 True。

isNumber → bool (Read Only):

数值参数为 True。

isOP → bool (Read Only):

OP 参数为 True。

isPulse → bool (Read Only):

对于脉冲参数为 True。

isPython → bool (Read Only):

Python 参数为 True。

isSequence → bool (Read Only):

序列头参数为 True。

isString → bool (Read Only):

字符串参数为 True。

isToggle → bool (Read Only):

开关参数为 True。

label → str :

获取或设置参数的标签。 

op('myOperator').parGroup.Custompar.label = 'Translate'

只能在自定义参数上设置。

max → Tuple[float, ...] :

获取或设置参数的数值最大值。若 clampMax = True，参数值将在该最大值处钳制。只能在自定义参数上设置。

menuIndex → Tuple[int, ...] :

按索引获取或设置菜单常量值的元组。

menuLabels → Tuple[list[str], ...] :

获取或设置由所有可用菜单选项标签列表组成的元组。对于非菜单参数，返回 None。只能在自定义参数上设置。

menuNames → Tuple[list[str], ...] :

获取或设置由所有可用菜单选项名称列表组成的元组。对于非菜单参数，返回 None。只能在自定义参数上设置。

menuSource → Tuple[str, ...] :

获取或设置由表达式组成的元组，这些表达式返回带有 .menuItems 和 .menuNames 成员的对象。例如，可用于创建条目动态跟随另一个菜单的自定义菜单。

min → Tuple[float, ...] :

获取或设置参数的数值最小值。若特定 Par 的 clampMin = True，参数值将在该最小值处钳制。只能在自定义参数上设置。

mode → Tuple[ParMode, ...] :

获取或设置参数的求值模式。

op('geo1').parGroup.t.mode = (ParMode.EXPRESSION, ParMode.EXPRESSION, ParMode.EXPRESSION)

模式为以下之一：ParMode.CONSTANT、ParMode.EXPRESSION、ParMode.EXPORT 或 ParMode.BIND。

更多信息见 Parameter_Dialog#Working_with_Parameter_Modes。

name → str :

获取或设置参数的唯一名称。 

op('myOperator').parGroup.Custompar.name = 'Translate'

只能在自定义参数上设置。

baseName → str :

获取或设置参数的基本名称。不包含任何序列前缀、序列索引或名称后缀。只能在自定义参数上设置。

normMax → Tuple[float, ...] :

如果参数是数值滑块，获取或设置参数的最大滑块值。只能在自定义参数上设置。

normMin → Tuple[float, ...] :

如果参数是数值滑块，获取或设置参数的最小滑块值。只能在自定义参数上设置。

normVal → Tuple[float, ...] :

以归一化滑块位置的形式获取或设置参数值。只能在自定义参数上设置。

order → int :

获取或设置参数在参数页上的位置。只能在自定义参数上设置。

owner → OP (Read Only):

此对象所属的 OP。

page → Page :

获取或设置自定义参数所属的参数页。只能在自定义参数上设置。

password → bool :

获取或设置参数的密码模式。为 True 时所有文本以星号显示。只能在自定义的 string、int 或 float 参数上设置。自定义参数。

prevMode → tuple (Read Only):

参数之前的求值模式。

readOnly → bool :

获取或设置参数的只读状态。为 True 时无法通过界面修改参数，只能通过脚本。

startSection → bool :

获取或设置参数的分隔符状态。为 True 时，在此参数与其前面的参数之间会绘制一条可见的分隔线。只能在自定义参数上设置。

style → str (Read Only):

描述自定义参数的行为和内容。示例：Float、Int、Pulse、XYZ 等。

subLabel → tuple (Read Only):

返回子标签的名称。

val → tuple :

仅获取或设置参数的常量值。要获取参数的当前值（无论参数模式为 constant、expression、export 还是 bound），请使用下文所述的 eval() 方法。

op('geo1').parGroup.t.val   # 常量值
op('geo1').parGroup.t.eval()   # 求值后的参数
op('geo1').parGroup.t.val = (1,2,3)
op('geo1').parGroup.t = (1,2,3)  # 与上面等价，写法更简洁

设置此成员时，参数也会被置于常量模式。见下面的 mode 成员。

要按索引设置菜单值，请使用下文所述的 menuIndex 成员。

valid → bool (Read Only):

如果引用的参数当前存在则为 True，已被删除则为 False。

index → int (Read Only):

参数在列表中的顺序。

sequence → Sequence | None (Read Only):

此 parGroup 所属的 Sequence。不在序列中时为 None。

sequenceBlock → SequenceBlock | None (Read Only):

此 parGroup 归属的 SequenceBlock。不在序列中时为 None。

blockIndex → int (Read Only):

parGroup 在其 SequenceBlock 中的索引。不在序列中时为 None。

sequenceIndex → int (Read Only):

parGroup 的 SequenceBlock 在其 Sequence 中的索引。不在序列中时为 None。

size → int :

获取或设置参数的向量大小。

maxSize → int (Read Only):

返回此 ParGroup 的 Par 元素最大数量。

defaultSize → int (Read Only):

返回此 ParGroup 的 Par 元素默认数量。

suffixes → list (Read Only):

返回用于命名此 ParGroup 的 Par 元素的后缀列表。

方法

copy(ParGroup)→ None:

复制指定的参数。

  • ParGroup - 要复制的参数。
op('geo1').parGroup.t.copy( op('geo2').parGroup.t )

destroy()→ None:

销毁此 ParGroup 所引用的参数。如果该参数已被销毁，将抛出异常。只能销毁自定义参数和顺序参数。销毁顺序参数会销毁其整个块。注意：任何参数被销毁后，现有的参数对象都会失效，需要重新获取。

eval()→ tuple:

计算参数组。该值可能来自参数组的常量值、表达式或导出，取决于其模式。

a = op('geo1').parGroup.t.eval()

evalExport()→ tuple:

计算参数的导出部分（如果包含的话）。将忽略表达式等。

a = op('geo1').parGroup.t.evalExport()

evalExpression()→ tuple:

计算参数的表达式部分（如果包含的话）。将忽略导出等。

a = op('geo1').parGroup.t.evalExpression()

要计算不在参数内的任意表达式字符串，请参阅 OP.evalExpression。

evalNorm()→ Tuple[float, ...]:

类似于 eval()，但返回归一化的滑块值。

evalOPs()→ Tuple[list[op], ...]:

将每个参数计算为一系列操作符。例如，对于指定操作符路径列表的自定义参数，这很有用。

a = op('base1').parGroup.Paths.evalOPs()

pars(pattern)→ list:

返回与模式匹配的参数对象列表（可能为空）。

  • pattern - 遵循模式匹配规则的字符串，指定要返回哪些参数。
# translate 参数
newlist = op('geo1').parGroup.t.pars('t?')

reset()→ bool:

将参数组重置为默认状态。

如果有任何改动则返回 true。

op('geo1').parGroup.t.reset()

isSameParGroup(parGroup : ParGroup)→ bool:

如果提供的 parGroup 是同一操作符上的同一 ParGroup，则为 True。由于 op('container1').parGroup.x == op('container2').parGroup.x 比较的是值，而 op('container1').parGroup.x is op('container1').parGroup.x 始终为 False（因为 TouchDesigner 的内部实现），必须使用 isParGroup 来比较 ParGroup 对象。同样，op('container2').par.Myfloat in op('container2').customPars 会返回不可靠的结果。

  • parGroup - 要比较同一性的 ParGroup。
