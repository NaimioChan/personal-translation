MIDI

MIDI 是乐器和接口控制器用于在设备之间发送事件数据的标准。

请参阅 MIDI Device Mapper Dialog、MIDI In DAT、MIDI Event DAT、MIDI In Map CHOP、MIDI In CHOP、MIDI Out CHOP。

要通过 Python 向 MIDI 设备发送 MIDI 事件，请把 MidioutCHOP Class 与 MIDI Out CHOP 配合使用。对于 Tscript，使用 Tscript 的 midi 命令。

MIDI 数据的类型

  • 音符事件 - MIDI 键盘输出 note on/off 事件、弯音事件和触后事件。像 Roland 808 的 MIDI 后裔这样的 MIDI 音序器设备也会自动定时输出 note on/off 事件。许多 MIDI 应用用 'C2' 或 'C3' 这样的英文音名描述这些事件，表示它们在键盘钢琴上的位置。但 TouchDesigner 只处理索引编号。例如 Note 60 在 TouchDesigner 之外可能显示为 C2 或 C3，尽管它代表完全相同的 MIDI 事件。
  • 控制器事件 - MIDI 控制器设备，如 Peavey 滑块盒。
  • MCR 盒各自输出控制器事件，这些是 0-127 的值。控制器事件可用于控制任何东西，一般并不表示 note on - note off 事件。
  • 其他事件类型 - 请参阅 MIDI In CHOP。

将 MIDI 与 CHOP 配合使用

要把 MIDI 事件引入 CHOP 通道，请使用 MIDI In CHOP，或将 MIDI Device Mapper Dialog 与 MIDI In Map CHOP 配合使用。

Using the MIDI In CHOP

  1. 创建一个 MIDI In CHOP。
  2. 在 MIDI Source 参数菜单中，选择正在接收 MIDI 事件的 MIDI 输入设备。它应显示 Serial Port 2、SoundBlaster Card、In From MIDI Yoke:1 或类似内容。
  3. 在 MIDI In CHOP 的 Control 参数页上，确保 Controller Index 覆盖所用输入设备的适当范围。
  4. 现在 TouchDesigner 已准备好接收 MIDI 事件。确保 TouchDesigner 正在正向播放。打开 MIDI In CHOP 的节点查看器，它会在已创建的 CHOP 通道中显示 MIDI 值。

Using the MIDI In Map CHOP

  1. 在 MIDI Device Mapper Dialog 中设置 MIDI 输入设备。
  2. 在 MIDI Device Mapper 中把 MIDI 输入的控制器事件映射到 Sliders 和 Buttons。
  3. 创建一个 MIDI In Map CHOP。
  4. 在 MIDI In Map CHOP 的参数中，把范围设为你在第 2 步映射的滑块和按钮。
  5. 现在 TouchDesigner 已准备好接收 MIDI 事件。确保 TouchDesigner 正在正向播放。打开 MIDI In Map CHOP 的节点查看器，它会在已创建的 CHOP 通道中显示 MIDI 值。

MIDI 事件转换到 CHOP 通道

查看 CHOP 上的中键信息菜单，你会看到正在创建哪些通道。在 CHOP 通道中，"ch1" 表示 MIDI 通道 1，c1 到 c8 是控制器 1 到 8，ch1n 是 MIDI 通道 1 的音符事件。

默认情况下，TouchDesigner 监听 MIDI 通道 1，接收 0 到 127 的所有音符事件，并接收 MIDI 通道 1 上控制器 1 和 2 的所有控制器事件。

若你在其他通道上发送数据，请在 MIDI Channel 参数中填写通道范围，如 "1-8"。1-16 会捕获所有内容。

若你使用 MIDI 控制器盒，必须知道你的盒子会产生哪些控制器编号。在 Control 页上，Controller Index 应设为该范围，或设为 1-32 以包含所有控制器。每个控制器会创建一个单独的通道。

注意：要了解有哪些 MIDI 事件进入 TouchDesigner，请打开 MIDI Device Mapper Dialog 并打开 In Events 选项卡。所有传入消息都会在 MIDI Device Mapper 的控制台区域报告。

现在你可以演奏乐器或推动滑块盒上的滑块。你应在图形中看到通道变化。

音符事件输出为单独 CHOP 通道

默认情况下，一个 MIDI 通道的所有音符事件合并在一个 CHOP 通道中。在 Note 页的 Note Output 中，选择 Separate Channels 可创建单独的通道。但除非你在 Note Scope 中缩小范围，否则会产生 127 个通道。

MIDI 通道合并为一组 CHOP 通道

此外，默认情况下，从 MIDI 通道 1 进入的事件输出的 CHOP 通道集与 MIDI 通道 2 不同。若你不关心数据来自哪个 MIDI 通道，可把 Channel Prefix 字段从 "ch" 改为 ""（空白），从而合并 MIDI Channel 参数中选定的所有 MIDI 通道。

播放时记录

Record 页上的 Record Method 控制 CHOP 通道的形成方式。默认情况下，它记录到 CHOP 当前帧处的通道中，因此需要正在播放动画才能进行记录。TouchDesigner 停止时，值仍会被记录，但会覆盖当前帧处的值。

若你不关心记录数值（听起来像在声明信仰），可把 Record Method 设为 Single Frame 或 Current Frame。

有时你可能希望通过把 Midi In CHOP 设为 Single Frame 或 Current Frame，并将其传递给 Record CHOP 来记录通道，后者对 MIDI 通道的处理有更多控制。从这里开始，你就可以即兴演奏了。

缩放、偏移与命名通道

你可能想先把各控制器通道的值从 0 到 1 的范围改为其他范围。这意味着对通道进行缩放和偏移。

若只有一条通道需要缩放/偏移，或所有通道需按相同数值缩放/偏移，直接使用 Math CHOP 的 Range 页即可。

否则，缩放/偏移一组通道的一个好方法是：用一个 Constant CHOP 保存所有这些通道的缩放值，再用另一个 Constant CHOP 保存通道的偏移（下限）。

然后可用 Math CHOP 缩放（相乘两个输入：Midi In CHOP 与包含缩放值的 Constant CHOP）。可用另一个 Math CHOP 偏移（相加两个输入：前一个 Math CHOP 与包含偏移值的 Constant CHOP）。

MIDI 通道最终会映射到通道名。可使用 Rename CHOP 映射。更好的做法是，把 Constant CHOP 的通道命名为所需的通道名。若它们是 Math CHOP 的第一个输入，结果将沿用 Constant CHOP 通道的名称。

参见 $HD/CHOPs/WeirdGuy 示例的 inputs CHOPnet，了解使用 Constant 和 Math CHOP 缩放、偏移和重命名通道的示例。

对 MIDI 数据做滞后或滤波

要实时生成滞后通道，你需要最近一秒或更久的 MIDI 数据。可使用 Trim CHOP，将 Absolute Value 范围设为 $T-1 到 $T，然后传给 Lag CHOP 并调整 Lag 参数。使用「Cook to Current Frame」选项。

参见 WeirdGuy 示例的输入 CHOPnet，了解正在记录的通道被修剪和滞后的示例。

用滑块控制混合

MIDI 滑块盒常用于实时混合其他预先动画化的内容。MIDI CHOP 可连接到 Blend CHOP 并用作权重因子。

使用 MIDI 辅助关键帧动画

这是一种从普通 TouchDesigner 通道（如对象的位置和旋转通道）编辑关键帧的技术。不必逐个通道用鼠标选择通道并编辑数值，你可以用 MIDI 滑块盒或 Puppetworks 设备这类输入设备在不同动画帧之间跳转，并用滑块轻松编辑多个通道值。

在 TouchDesigner 中开始、停止、继续播放

若向工作站提供输入的 MIDI 设备能够输出 MIDI Start、Stop 和 Continue 消息，TouchDesigner 将分别从当前起始帧开始、在当前帧停止、从当前帧继续。

滴答、拍与小节

若向工作站提供输入的 MIDI 设备能够输出时钟滴答，并可选地输出 Bar Messages，你就可以用 MIDI 让动画随音乐循环。

Midi In CHOP 的 Timer Ramp Name 参数会创建一个斜坡，在音乐拍开始时从 0 开始，在音乐拍结束时增至 1。（它使用 MIDI 定时脉冲。）

Midi In CHOP 的 Bar Ramp Name 参数会创建一个斜坡，在音乐小节开始时从 0 开始，在音乐小节结束时增至 1。（它使用由 Bar Message 定义的 MIDI sysex 代码，随后跟一个 MIDI 定时脉冲。）

MIDI 设备厂商

有许多适合 TouchDesigner 的 MIDI 设备。它们自然各有优缺点。缺点常包括设备分辨率低……MIDI 控制器通常输出 0 到 127 的整数。

任何像滑块设备这样的 MIDI 硬件都便于设置，但由于滑块无法被强制到先前的状态，它们在编辑 CHOP 中已有滑块设置时用处较小。不过 Constant CHOP 允许利用滑块的相对运动来编辑滑块数据。

通用换能器设备

[www.infusionsystems.com Infusion Systems] 制造 I-Cube，一套可按部件配置的换能器和输出设备。

键盘设备

TouchDesigner 几乎可与任何 MIDI 键盘配合使用，接收音符事件、弯音、力度和触后。TouchDesigner 也可与 MIDI 音序器配合使用。
