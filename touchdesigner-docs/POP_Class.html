POP 类

POP 描述对 POP 操作符的引用，包含点和图元。

成员

compare → bool :

获取或设置 Compare Flag。

dimension → Dimension (Read Only):

该 POP 的维度。该值独立于依赖时间的内容而更新。

maxVertsPerLineStrip → int (Read Only):

此 POP 中每条 line strip 的最大顶点数。

pointAttributes → (Read Only):

此 POP 中定义的点属性集合。

pointAttributesChanged → (Read Only):

此 POP 更改的点属性。

primAttributes → (Read Only):

此 POP 中定义的图元属性集合。

primAttributesChanged → (Read Only):

此 POP 更改的图元属性。

template → bool :

获取或设置 Template Flag。

vertAttributes → (Read Only):

此 POP 中定义的顶点属性集合。

vertAttributesChanged → (Read Only):

此 POP 更改的顶点属性。

方法

bounds(delayed=False)→ Bounds:

返回一个 object，其中包含该 POP 几何的边界、中心和尺寸。

  • delayed -（Keyword，Optional）若设为 True，下载结果将延迟到下一次调用 bounds() 时才返回，从而避免 GPU 因立即等待结果而停滞。

computeBounds(display=False, render=False, delayed=False)→ Bounds:

返回一个 object，其中包含该 POP 几何的边界、中心和尺寸。

  • display -（Keyword，Optional）若设为 True，则仅当 POP 的 display 标记已设置时才计算 Bounding Box。
  • render -（Keyword，Optional）若设为 True，则仅当 POP 的 render 标记已设置时才计算 Bounding Box。
  • delayed -（Keyword，Optional）若设为 True，下载结果将延迟到下一次调用 computeBounds() 时才返回，从而避免 GPU 因立即等待结果而停滞。

numPoints(delayed=False, max=False)→ int:

返回此 POP 中包含的点数。

  • delayed -（Keyword，Optional）若设为 True，下载结果将延迟到下一次调用 numPoints() 时才返回，从而避免 GPU 因立即等待结果而停滞。
  • max -（Keyword，Optional）若设为 True，则返回已分配的点数（点的最大数量）。此时结果总是即时返回，delayed 会被忽略。

numPrims(delayed=False, max=False, primType=None)→ int:

返回此 POP 中包含的图元数。

  • delayed -（Keyword，Optional）若设为 True，下载结果将延迟到下一次调用 numPrims() 时才返回，从而避免 GPU 因立即等待结果而停滞。
  • max -（Keyword，Optional）若设为 True，则返回已分配的图元数（图元的最大数量）。此时结果总是即时返回，delayed 会被忽略。
  • primType -（Keyword，Optional）若设为 triangles、quads、lineStrips、lines 或 pointPrims，则仅返回该图元类型的图元数量。

numVerts(delayed=False, max=False, lineStrips=False)→ int:

返回此 POP 中包含的顶点数。

  • delayed -（Keyword，Optional）若设为 True，下载结果将延迟到下一次调用 numVerts() 时才返回，从而避免 GPU 因立即等待结果而停滞。
  • max -（Keyword，Optional）若设为 True，则返回已分配的顶点数（顶点的最大数量）。此时结果总是即时返回，delayed 会被忽略。
  • lineStrips -（Keyword，Optional）若设为 true，则仅返回 line strips 的顶点数。

point(attributeName, index, delayed=False)→ float | int | tuple:

返回点属性值。

  • attributeName - 属性名称。
  • index - 点索引。
  • delayed -（Keyword，Optional）若设为 True，下载结果将延迟到下一次调用 vals() 时才返回，从而避免 GPU 因立即等待结果而停滞。

points(attributeName, startIndex=0, count=-1, delayed=False)→ list:

以列表形式返回点属性值。

  • attributeName - 属性名称。
  • startIndex -（Keyword，Optional）起始的点索引（默认 0）。
  • count -（Keyword，Optional）要下载的点数。值为 -1 时获取从起始索引开始的所有元素。
  • delayed -（Keyword，Optional）若设为 True，下载结果将延迟到下一次调用 vals() 时才返回，从而避免 GPU 因立即等待结果而停滞。

prim(attributeName, index, delayed=False)→ float | int | tuple:

返回图元属性值。

  • attributeName - 属性名称。
  • index - 图元索引。
  • delayed -（Keyword，Optional）若设为 True，下载结果将延迟到下一次调用 vals() 时才返回，从而避免 GPU 因立即等待结果而停滞。

prims(attributeName, startIndex=0, count=-1, delayed=False)→ list:

以列表形式返回图元属性值。

  • attributeName - 属性名称。
  • startIndex -（Keyword，Optional）起始的图元索引（默认 0）。
  • count -（Keyword，Optional）要下载的图元数。值为 -1 时获取从起始索引开始的所有元素。
  • delayed -（Keyword，Optional）若设为 True，下载结果将延迟到下一次调用 vals() 时才返回，从而避免 GPU 因立即等待结果而停滞。

reallocate()→ None:

强制该 POP 重新分配其 GPU 缓冲区。

save(filepath, createFolders=False)→ str:

将 POP 几何保存到文件系统。支持多种文件类型。返回保存的文件名和路径。

  • filepath -（Optional）要保存到的路径和文件名。若未指定，则使用默认文件名，文件保存在 project.folder 文件夹中。
  • createFolders -（关键字，可选）如果为 True，则创建 filepath 中尚不存在的目录。

vert(attributeName, index, delayed=False)→ float | int | tuple:

返回顶点属性值。

  • attributeName - 属性名称。
  • index - 顶点索引。
  • delayed -（Keyword，Optional）若设为 True，下载结果将延迟到下一次调用 vals() 时才返回，从而避免 GPU 因立即等待结果而停滞。

verts(attributeName, startIndex=0, count=-1, delayed=False)→ list:

以列表形式返回顶点属性值。

  • attributeName - 属性名称。
  • startIndex -（Keyword，Optional）起始的顶点索引（默认 0）。
  • count -（Keyword，Optional）要下载的顶点数。值为 -1 时获取从起始索引开始的所有元素。
  • delayed -（Keyword，Optional）若设为 True，下载结果将延迟到下一次调用 vals() 时才返回，从而避免 GPU 因立即等待结果而停滞。
