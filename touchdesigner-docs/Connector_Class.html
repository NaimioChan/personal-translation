Connector 类

Connector 类描述 operator 的输入或输出连接点。有两种连接类型：组件之间的连接，以及常规操作符之间的连接。 常规操作符之间的连接可通过 OP.inputConnectors 和 OP.outputConnectors 成员访问。它们是 Operators 左右两侧的连接器。 组件之间的连接可通过 COMP.inputCOMPConnectors 和 COMP.outputCOMPConnectors 成员访问。它们是 Component 操作符顶部和底部的连接器

成员

index → int (Read Only):

此连接器的数字索引。

isInput → bool (Read Only):

连接器为输入时为 True。

isOutput → bool (Read Only):

连接器为输出时为 True。

inOP → OP (Read Only):

返回与此连接器关联的任何输入操作符（例如 inSOP、inCHOP）。这仅适用于连接到组件的常规操作符连接。

outOP → OP (Read Only):

返回与此连接器关联的任何输出操作符（例如 outSOP、outCHOP）。这仅适用于连接到组件的常规操作符连接。

owner → OP (Read Only):

此对象所属的 OP。

connections → list (Read Only):

连接到此对象的 connector objects 列表。

description → str (Read Only):

此连接的描述。例如：'Color Image'。

方法

connect(target)→ None:

将此连接器连线到目标位置。目标可以是 operator 或另一个连接器。

当连接器为输入时，其连接会被替换为目标。 当连接器为输出时，会向目标追加一条新连接。

  • target - 你想连接到的 OP 或连接器。
# 把 noise1 连接到 lag1
op('noise1').outputConnectors[0].connect(op('lag1'))

# 把 choptotop1 连接到 displace1 的第 2 个输入
op('choptotop1').outputConnectors[0].connect(op('displace1').inputConnectors[1])

# 把 geo1 连接到 geo2，两种等价方法：
op('geo1').outputCOMPConnectors[0].connect(op('geo2'))
op('geo2').inputCOMPConnectors[0].connect(op('geo1'))

disconnect()→ None:

断开此连接器。 

op('lag1').inputConnectors[0].disconnect()
op('lag1').outputConnectors[0].disconnect()

# 断开 geo2 与 geo1 的连接，两种等价方法
op('geo1').outputCOMPConnectors[0].disconnect()
op('geo2').inputCOMPConnectors[0].disconnect()
