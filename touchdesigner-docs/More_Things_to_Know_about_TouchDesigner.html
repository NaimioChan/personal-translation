TouchDesigner 进阶须知

本文是 First Things to Know about TouchDesigner 的续篇。

36. 探索他人的组件

  • 在任何组件中，窗格左上角的方形框会调出你当前所在组件的面板（或查看器）。
  • 对会动的 CHOP 使用 Trail CHOP，可以清楚地观察它们的时间历程。
  • 把光标放在任意面板上（先点击该面板）并按 F10 或 F9 键，会在浮动窗口中进入它的源网络。

37. 输出到影片文件

TouchDesigner 允许你把任何操作符查看器的内容输出到影片文件。用 Movie File Out TOP 就足够简单，但下面的步骤是另一种方式。首先用 Timeline 开始向前播放。右键点击你想输出其查看器的操作符。在弹出的上下文菜单中选择 Export Movie，调出 Export Movie Dialog。选择影片的输出选项，例如分辨率、编解码器和文件名。点击 Start 按钮开始录制 QuickTime 影片。要结束，点击 Stop 按钮。

38. 连接 MIDI 设备

参见 MIDI Device Mapper Dialog，把 MIDI 设备映射到 MIDI 设备 ID（与 MIDI 通道不同）。

最简单的方法是创建一个 MIDI In CHOP，选择你的设备，转动一个控件，然后把该通道导出到参数或任何你需要的地方。

39. 使用多个显示器输出

参见 Multiple Monitors，你还可以使用 OP Snippets 中为 Window COMP 提供的便捷设置工具 windowCanvas。

40. 克隆是与主克隆保持同步的组件

clone 是主组件的一份副本，额外特性是：每当主组件发生变化（包括其中节点的连线和参数），它的所有克隆都会随之改变以保持一致。

任选一个组件，例如上面创建的 container1，把它的名称（container1）填入 Common 页上的 Clone 参数，然后复制/粘贴（Ctrl-C Ctrl-V，或通过网络菜单）该组件两次。让每个克隆的输入各不相同。你会看到每个克隆的输出都是独立的。

所有克隆节点以及克隆内部的节点都会变暗。另请参阅 Clone、Component。

41. 通过创建新组件简化网络

你可以选中节点，右键点击网络并选择 Collapse Selected。它会创建一个新的 Base COMP，选中的节点会被放入其中。组件的输入和输出会被创建，并连接到进入和离开的操作符上。

例如，如果你想让新组件成为 Container 组件，请右键点击 Base 组件并选择 Change OP Type。

（手动操作可以这样完成：首先在网络中创建一个 Container COMP。选中你想放入容器的节点，用 Ctrl+C 复制。选中该容器并按「Enter」或「i」，或用鼠标滚轮进入容器。进入后，用 Ctrl+V 把节点粘贴到容器中。如果你的节点原本连接着网络中的其他节点，请按需创建 In 和 Out CHOP、TOP、DAT、SOP 等，以建立到容器的输入和输出。然后退出组件，把它的输入和输出连接到相应的节点。最后删除你最初复制的节点。）

42. 组件查看器显示内部节点的输出 - 面板、多边形几何或任何 OP 的查看器

任何组件的查看器区域都可以包含多种内容：通常 Panel Components 显示其内部控件，Object 查看器包含其 3D 对象的视图，这是默认情况。但在组件查看器中，你可以放置任何其他操作符的查看器、组件的参数，或组件网络的交互视图。这一切都由组件参数 Common 页上的 Node View 菜单管理。

43. 使用 DAT 导出

你可以通过 DAT Export 从一张 DAT 表格导出到任意数量节点中的任意数量参数。表格需要 4 列：path、parameter、value 和 enable，并且需要在 DAT 中点击开启 DAT Export 标记。

44. TouchDesigner 崩溃或卡死时该怎么办

总有一天 TouchDesigner 会崩溃或卡死。如果崩溃，它可能会提示你保存 CrashAutoSave.toe 文件，你可以立即重启以回到崩溃前的工作。崩溃时它可能会问你是否要 .dmp 文件，接受并把文件发送给我们。不必费心发送 Microsoft 崩溃文件。如果卡死，在 Windows 上打开任务管理器，找到该进程，右键并保存转储，然后强制结束该进程。

如果 TouchDesigner 是无边框全屏，先尝试把光标放在窗口上按 Esc。这可能会取消或缩小窗口，让你得以保存或重启。如果你能调出任务管理器，可以在「进程」部分结束任何 TouchDesigner 进程。如果 Ctrl-Alt-Del 组合键（或 Ctrl-Shift-Esc）无法调出任务管理器，或者没有任何进程可以结束，那么你可能需要重启。
