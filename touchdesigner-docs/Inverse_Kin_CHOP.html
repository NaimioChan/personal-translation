Inverse Kin CHOP

摘要

Inverse Kin CHOP 为 Bone objects 计算反向运动学模拟。

inversekinCHOP_Class

参数 - Kinematics 页

Solver Type solvertype - - 此参数定义当 Bone 对象自身、其祖先或其子级被移动时，用于确定该对象运动的方法。
  • None none - 不对 Bone 对象应用任何运动解算。
  • Show Rest Position rest - 此求解器用于显示骨骼的静止位置。它按链中静止角度所定义的静止位置摆放骨骼。这些静止角度会用于反向运动学求解器。因此，这个求解器可以当作辅助工具，用来显示链的静止位置。
  • Show Capture Position capture - 此求解器用于显示 capture angles 参数中的旋转值。这些参数在 Skeleton SOP 执行「capture points」操作时设置，或通过 Grab Capture Angles 菜单设置。与 Show Rest Position 求解器一样，这个求解器也可以用来把链恢复到其捕捉朝向。
  • Inverse Kinematics inverse - IK 求解器会尽量摆放骨骼，使链中最后一根骨骼的末端触及被定义为 end affector 的对象的原点。链的形状由链中各骨骼的静止角度推导得出。

要调整 IK 求解器的结果，你可以调整骨骼的静止角度。注意，IK 求解器的解只有在一组给定静止角度下才保证连续。如果你给静止角度做动画，可能会得到四处跳动的链。 使用运动学时，可以通过在 Inverse Kin CHOP 上启用 export 标记，把运动学求解器给出的旋转导出到骨骼。不建议在运动学链中给骨骼对象添加旋转值，因为这些值会被运动学求解器覆盖。

  • IK with Constraints constraint -
  • Follow Curve curve - 此求解器把骨骼摆放为沿对象中的第一条曲线对齐。它适合给尾巴、脊柱之类的东西做动画。
Root Bone boneroot - 链的起始骨骼；即链从哪里开始。
End Bone boneend - 如果你指定某根骨骼为链中的最后一根骨骼，那么你就定义了一条以当前骨骼为链中第一根、以从菜单中选择的骨骼为链中最后一根的骨骼链。这条链包含两者之间的所有骨骼。
End Affector endaffector - 指定哪个对象将作为链的 end affector。
Twist Affector twistaffector - 如果你指定一个 twist affector，整条骨骼链会绕从链根到 end affector 的轴扭转，使第一根骨骼尽可能指向 twist affector。也可以指定 twist 值，它会在为 twist affector 生成的扭转之上叠加应用。
IK Twist iktwist - 运动学解允许的扭转量。
IK Dampening ikdampen - 阻尼量（在角度允许范围的极值处减慢）。
Curve Object curve - 要跟随的曲线对象。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Inverse Kin CHOP 的附加信息可以通过 Info CHOP 获取。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
