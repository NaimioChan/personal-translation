App 类

此类包含具体的应用程序详细信息，例如其版本和安装文件夹。可以通过 app 对象访问它，该对象位于自动导入的 td module 中。

注意： 另请参见 Variables 以及 Dialogs -> Variables，在那里可以通过 var('DESKTOP')、var('MYDOCUMENTS') 和 var('TOENAME') 形式的表达式获取更多内置路径和字符串。

成员

applicationsFolder → str (Read Only):

系统中安装应用程序的主要位置，例如 Windows 上的「C:/Program Files」。

architecture → str (Read Only):

编译的架构。通常为 32 或 64 位。

binFolder → str (Read Only):

包含二进制文件的安装文件夹。

build → str (Read Only):

应用程序版本号。

compileDate → Tuple[int, int, int] (Read Only):

应用程序的编译日期，表示为元组（年、月、日）。

configFolder → str (Read Only):

包含配置文件的安装文件夹。

desktopFolder → str (Read Only):

当前用户的桌面文件夹。

enableCachedParameters → bool :

获取或设置是否缓存参数值，而不总是重新求值。

enableOptimizedExprs → bool :

获取或设置是否启用 Python 表达式优化。每次 TouchDesigner 启动时默认为 True。

experimental → bool (Read Only):

如果 App 为实验版则返回 true，否则返回 false。

installFolder → str (Read Only):

主安装文件夹。

launchTime → float (Read Only):

启动并开始播放 toe 文件所需的总时间，以秒计。

logExtensionCompiles → bool :

获取或设置是否将启动和结束编译扩展的额外消息发送到 textport。如果编译失败，还会打印额外的错误堆栈。每次 TouchDesigner 启动时默认为 False。

osName → str (Read Only):

操作系统的名称。

osVersion → str (Read Only):

操作系统的版本。

power → bool :

获取或设置进程的整体计算状态。为 True 时启用计算。为 False 时停止计算。这与按下主界面上的电源按钮相同。其效果大于简单地暂停或停止播放栏。 

app.power = False # 关闭电源按钮。

preferencesFolder → str (Read Only):

首选项文件所在的文件夹。

processId → int (Read Only):

当前运行进程的 ID。

product → str (Read Only):

项目所运行的可执行程序类型。值为「TouchDesigner」、「TouchPlayer」或「TouchEngine」。

pythonExecutable → str (Read Only):

TouchDesigner 的 Python 可执行文件的路径。TouchDesigner 不直接使用此可执行文件，但可以用它在一个包含 TouchDesigner 所附带全部包和模块的环境中测试纯 Python 代码。该可执行文件也可用于运行外部 Python 脚本，而无需安装单独的 Python。

recentFiles → list :

获取或设置最近保存或加载的文件列表。

samplesFolder → str (Read Only):

包含配置文件的安装文件夹。

paletteFolder → str (Read Only):

包含调色板文件的安装文件夹。

userPaletteFolder → str (Read Only):

用户自定义调色板所在的文件夹。

version → str (Read Only):

应用程序版本号。

windowColorBits → int (Read Only):

TouchDesigner 窗口运行时的每颜色通道颜色位数。默认每个通道为 8 位，但可以通过设置环境变量 TOUCH_10_BIT_COLOR=1 提升到 10 位。仅在支持 10 位色的显示器上有效。

systemFolder → str (Read Only):

包含系统文件的安装文件夹。

tempFolder → str (Read Only):

用于临时文件的文件夹。

pyEnvHelper → TDPyEnvManagerHelper (Read Only):

返回对全局 python environment helper 的访问。

方法

addNonCommercialLimit(password=None)→ None:

将应用程序限制在非商业许可证级别运行。可以多次调用，但每次都可以通过与之一一对应的 removeNonCommercialLimit(password) 撤销。如果密码为空，该操作无法撤销。（另请参见 licenses.disablePro）成员。

  • password - (Keyword, Optional) 之后用于移除限制的密码。
app.addNonCommercialLimit(password='secret123')  # 可通过密码撤销
app.addNonCommercialLimit()  # 在会话期间永久保留。

removeNonCommercialLimit(password=None)→ bool:

移除先前添加的限制。成功时返回 True。

  • password - (Keyword) 添加限制时先前使用的密码。
app.removeNonCommercialLimit(password='secret123')

addResolutionLimit(width, height, password=None)→ None:

将所有纹理限制在指定数值内。可以多次调用，但每次都可以通过与之一一对应的 removeResolutionLimit(password) 撤销。最终的分辨率限制为所有调用中的最小值。如果密码为空，该操作无法撤销。

  • width - 最大纹理分辨率的宽度，以像素计。
  • height - 最大纹理分辨率的高度，以像素计。
  • password - (Keyword, Optional) 之后用于移除限制的密码。
app.addResolutionLimit(600, 480, password='secret123')  # 可通过密码撤销
app.addResolutionLimit(600, 480)  # 在会话期间永久保留。

removeResolutionLimit(password=None)→ bool:

移除先前添加的限制。成功时返回 True。

  • password - (Keyword) 添加限制时先前使用的密码。
app.removeResolutionLimit(password='secret123')
