Oculus Audio CHOP

摘要

注意

OS: 此操作符仅在 Microsoft Windows 操作系统下受支持。

Oculus Audio CHOP 使用 Oculus Audio SDK，取一个单声道声音通道，并为该声音创建空间化的立体声对或通道。

另请参阅：Audio Render CHOP

oculusaudioCHOP_Class

参数 - Setup 页

Active active - 启用后，将主动对音频输入进行空间化。
Head Object COMP headobject - 表示听者（即头部）变换的 COMP。必须是包含变换数据的 COMP，例如 Geometry 或 Camera COMP。
Source Object COMP sourceobject - 表示音频源变换的 COMP。必须是包含变换数据的 COMP，例如 Geometry 或 Camera COMP。
Minimum Range minrange - 音频源的最小衰减范围（以米为单位）。
Maximum Range maxrange - 音频源的最大衰减范围（以米为单位）
Diameter diameter - 音频源的虚拟直径。默认直径为 0，意味着音频源只是空间中的一个点。
Band Hint bandhint - - 如果已知音频源的内容，可设置此参数以改善整体音质。
  • None none -
  • Wide Band wide - 用于帮助掩盖频谱内容丰富的宽带音频源（如音乐、人声和噪声）的某些瑕疵。
  • Narrow Band narrow - 用于缺乏宽频谱内容的窄带音频源，例如纯音（正弦波、哨声）。
Reflections and Reverb reflectrevert - 启用后，将启用音频反射和混响。
Attenuation attenuation - - 选择音频源与听者（头部）之间的衰减计算方式。
  • None none - 声音不衰减
  • Fixed fixed - 基于固定值衰减。该固定值通过 Attenuation Scale 参数设置。
  • Inverse Square inversesequare - 基于平方倒数计算衰减。
Attenuation Scale attenuationscale - 在 Fixed Attenuation 模式下设置固定衰减值。
Box Room Mode boxroommode - 启用用于混响的盒状房间计算。
Room Size roomsize - - 设置盒状房间的尺寸。
  • X roomsizex -
  • Y roomsizey -
  • Z roomsizez -
Room Left Reflect roomleftrelfect - 盒左侧的反射级别（即有多少百分比的音频被反射回来）。
Room Right Reflect roomrightrelfect - 盒右侧的反射级别（即有多少百分比的音频被反射回来）。
Room Bottom Reflect roombottomrelfect - 盒底部的反射级别（即有多少百分比的音频被反射回来）。
Room Top Reflect roomtoprelfect - 盒顶部的反射级别（即有多少百分比的音频被反射回来）。
Room Front Reflect roomfrontrelfect - 盒前部的反射级别（即有多少百分比的音频被反射回来）。
Room Back Reflect roombackrelfect - 盒后部的反射级别（即有多少百分比的音频被反射回来）。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Oculus Audio CHOP 的额外信息可以通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
