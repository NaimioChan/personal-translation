Alembic In POP

摘要

Alembic In POP 加载并播放 Alembic 文件几何和多帧序列。

几何支持的 Alembic 图元有 polymesh、curves 和 points。此外，也支持 Alembic 变换。

Polymesh 图元在面为 3 个或 4 个顶点时分别作为三角形或四边形导入，面超过 4 个顶点时作为闭合线带导入。

对于包含动画的 Alembic 文件，使用 Play 页上的控件。按 Start 运行并循环。按 Cue，然后拖动 Cue Time 参数以拖动整个动画范围。关闭 Cue 时，可以调整 Speed 并用 Play 暂停。或者将 Play Mode 设为 Specify Index，并更改 Index 参数来控制当前动画位置，其表示为分数、秒、帧或索引（.abc 文件内部的帧编号）。

一个 Alembic 归档可能包含一个或多个几何的一个或多个对象路径。可以一次查看所有这些对象，也可以使用「Object Path」参数菜单分别选择它们。如果分别选中的对象包含重复的属性（即名称相同）但关联到不同的属性类（例如 vertex 与 point），则重复的属性将被转换为顶点属性。

Alembic 文件 schema 中的每个对象都可能拥有标准或自定义属性。标准属性有法线（N）、速度（V）和纹理坐标（Tex）。 一个 Alembic schema 中可能存在多个自定义属性，其名称和类型更灵活。

注意事项 - 大多数 Alembic 属性都受支持，但并非都能一对一转换为 POP 格式：

  • 16 位 int 属性（例如 Int16、V2s、P3s 等）会转换为 32 位 int。
  • 64 位属性（例如 Uint64、Int64、V2d 等）会转换为 double，这是 POP 目前唯一支持的 64 位属性。
  • 分量数大于 4 的属性（例如 Box3f、M33f、M44f 等）会打包为 vec4 数组。如果存在这类属性的数组，它们会首尾相接地打包在一起。例如 M44f 有 16 个分量，将作为 float4[4] 导入，而 M44f[2] 将作为 float4[8] 导入，M44f[0] 在前，M44f[1] 在后。

unsupported 属性列表：

  • String/WString
  • 8 位和 16 位浮点颜色
  • Bool
  • UChar/Char

参数 - Alembic 页

Alembic File file - Alembic 文件的文件路径。
Object Path objectpath - - 指定要加载哪个几何对象。每个几何对象可以表示多个几何的层级。也可以从可用对象列表中选择「All Objects」（即「*」）选项。默认选中此选项。
  • * * -
  • /box_object1/color1 /box_object1/color1 -
Load Type loadtype - - 选择是在本帧还是下一帧加载文件。在下一帧加载会显著减少总体计算时间。
  • Immediate (Slow) immediate - 在本帧加载 Alembic 文件，意味着当前计算将承担整个文件加载/读取/写入的开销。
  • Next Frame (Fast) nextframe - 在本帧异步开始 Alembic 文件加载，在下一次计算时完成并同步文件加载。由于 Alembic 加载可以在两次计算之间异步完成，这将大幅减少总体计算时间。
Transform xform - - 如果输入 Alembic 文件中有可用的变换数据，选择应用哪个变换。
  • None none - 不对几何应用任何变换，它们位于原点。
  • Static Local Transformation staticlocalxform - 对来自 Object Path 的所选几何对象应用静态局部变换。
  • Static World Transformation staticworldxform - 对来自 Object Path 的所选几何对象应用静态世界变换，直至其父级变换。
  • Dynamic Transformation dynamicxform - 如果 Alembic 文件包含动态或动画几何，则对所选几何应用变换。此选项对给定几何执行局部和世界变换（如果可用）。
Interpolation interp - - 在 Alembic 文件的采样/关键帧之间插值。此参数仅在所选几何定义为动态且输入 Alembic 文件中有可用变换信息时有效。
  • None none - 不在各采样之间进行插值。
  • Linear Interpolation interp - 计算每两个采样之间的平滑插值。
Unload loadfile - 将 unload 切换为「on」将卸载并关闭文件。将其设为「off」，文件将重新加载。文件卸载后，可以被其他应用程序覆盖或删除。

Info CHOP 通道

Alembic In POP 的额外信息可通过 Info CHOP 查看。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
