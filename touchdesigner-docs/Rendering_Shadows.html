渲染阴影

本文将介绍如何在 3D 场景中渲染阴影。你可以在 TouchDesigner 中加载 Media:3D_render.toe 跟着操作。完整的阴影示例见文末。

内置阴影

第 1 步 - 开启阴影

在 light1 中，进入其「Shadows」参数页，将 Shadow Type 改为「Hard, 2D Mapped」。你会看到阴影，但看起来不太对。这是因为来自灯光/摄像机的几何也在投射阴影。将「Shadow Casters」参数改为仅 geo1 而不是 *，这样只有 geo1 中的对象会投射阴影。

第 2 步 - 消除阴影伪影

在使用阴影的默认设置时，有时会出现覆盖几何的「摩尔纹」效果伪影。此例中不会出现，但如果你将灯光阴影参数中的 Polygon Offset Factor 改小，就能看到它们。如果遇到这些伪影，需要调整 polygon offset 值，直到它们消失。

第 3 步 - 阴影细节

可以通过调整阴影贴图，使其最有效地利用分辨率，来优化阴影细节。使用灯光的 Focal Length 和 Aperture 参数（或 FOV），尽量让几何填满深度贴图。

可以将 Depth TOP 指向灯光，以可视化阴影贴图的样子。 阴影贴图可能非常暗淡，暗淡到看不清几何（深度数据仍然有效，只是浮点值在图像中可能太不显眼）。增大灯光的 Near 参数，直到几何可见。对于 light1，此例中值为 2 即可。

现在调整 Focal Length 和/或 Aperture，直到几何尽可能填满深度贴图。调整这些参数时，观察 depth1 TOP 的查看器，检查阴影细节。尽量推到极限，但不要裁切阴影。完成后将 light1' 的 Near 参数恢复为之前的值。

提示：更改这些设置时，请复核动画场景。

第 4 步 - 调整其他阴影参数

在 phong1 的 Advanced 参数页上，试验 Shadow Strength 和 Shadow Color 参数。注意这只影响该材质上的阴影，投射到地面上的阴影不会随 phong1 改变。要改变这些阴影，请调整 /3D_render/stage/mat_floor 处的材质。

Media:Shadow_example.toe - 带阴影的示例文件。

自定义阴影贴图

如果需要自定义阴影贴图技术，可以在 Light COMP 的「Shadows」页中设置纹理（例如来自 Depth TOP 的纹理，但不一定是），并将「Shadow Type」设为「Custom」。如 Write a GLSL Material 一文所述，可以使用 TDShadowTexture 及相关函数访问这些阴影贴图。注意，渲染阴影贴图时，你很可能需要在 Render TOP 的「Advanced」页中开启「Polygon Depth Offset」功能。当由 Light COMP 内部渲染阴影贴图时，通常会自动隐式完成。附件是一个使用此功能的基本设置，不过它仍使用内部的阴影贴图算法，最终阴影并未做任何自定义。
