Stype In CHOP

摘要

注意

License: 仅在 TouchDesigner Pro 中可用。

Stype CHOP 读取来自 Stype（RedSpy）设备的摄像机跟踪信息，使用 Stype HF 协议。该 CHOP 输出的通道可用于控制虚拟摄像机，并通过 Stype TOP 实现镜头畸变。

Stype CHOP 导出的通道有：

connected - 1 或 0，表示该 CHOP 在过去 500ms 内是否收到有效的 Stype 消息
recording - 1 或 0，表示 Stype Kit 上的录制状态（更多信息参见 Stype 协议）
focus_distance - 1 或 0，表示焦点字段的使用方式（更多信息参见 Stype 协议）
hours, minutes, seconds, frames - 时间码，如果没有时间信息则可能为零
tx, ty, tz - 摄像机位置，可连接到 Camera COMP 的 Translate 参数
rx, ry, rz - 摄像机旋转，可连接到 Camera COMP 的 Rotate 参数
fov - 摄像机视野，可连接到 Camera COMP 的 FOV Angle 参数
padded_fov - 经 padding 参数扩展后的视野，可用于 Camera COMP 的 FOV Angle 参数
aspect - 摄像机的宽高比
focus - 摄像机对焦，从 0（最近）到 1（无限远），可用于模拟景深
zoom - 摄像机变焦，从 0（广角）到 1（长焦）
centerx, centery - 摄像机传感器的偏移，单位 mm，由 Stype TOP 用于计算镜头校正
k1, k2 - 径向镜头畸变参数，由 Stype TOP 用于计算镜头校正
pawidth, paheight - 传感器尺寸，单位 mm，由 Stype TOP 用于计算镜头校正

如需更多信息或诊断连接问题，可以连接一个 Info CHOP，查看是否有丢包或跳包。

注意： 此 CHOP 配合 Stype 硬件工作。 更多信息请参阅 Stype 一文。

另请参阅 Stype TOP。

参数 - Stype 页

Protocol protocol - - 要使用的网络协议。更多信息请参阅 Network Protocols 一文。
  • Messaging (UDP) msging -
  • Multi-Cast Messaging (UDP) multicastmsging -
  • Reliable Messaging (UDT Library) reliablemsging -
Network Address netaddress - 使用 Multicast 时，Stype 将在此地址上监听数据包。
Network Port port - Stype CHOP 接收数据包的端口。协议默认为 6301，但应设置为与当前硬件输出设置一致。
Local Address localaddress - 当发送机器配有多个网络适配器时，可在此处填写其 IP 地址，以选择由哪个适配器发送数据。
Active active - 开启时，该 CHOP 接收发送到网络端口的信息。关闭时不进行更新，发送到该端口的数据会丢失。
Padding padding - 0 到 1 之间的值，表示在给定镜头畸变需要采样正常渲染区域之外的范围时，视野需要增大的百分比。它用于计算填充后的视野，也可用于计算渲染节点的分辨率。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Stype CHOP 的额外信息可通过 Info CHOP 获取。

Stype CHOP 特定的 Info 通道

  • valid_packets -
  • unrecognized_packets -
  • corrupt_packets -
  • missing_packets -
  • dropped_packets -
  • last_packet_num -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
