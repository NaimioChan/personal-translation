Keyboard In DAT

摘要

Keyboard In DAT 在其 FIFO（先进先出）表格中列出最近的按键事件。每次按键按下和松开各占一行，包括 Shift、Ctrl 和 Alt，并区分左右。为方便起见，每次按键时都有一列指示当时是否按住了 Shift、Ctrl 和 Alt。

即使光标在 TouchDesigner 窗口之外（无论是控制面板、执行模式还是网络编辑器窗口），你也能获取按键。例外：在编辑器窗口中输入文本时。

你可以设置过滤器只监视某些按键。可以定义自定义快捷方式，并由 python callback in the attached script 处理。

keyboardinDAT_Class

参数 - Keyboard In 页

Active active - 阻止或允许将消息添加到日志。
Perform Window Only perform - 开启时，仅在执行模式下检测按键事件。
Keys keys - 允许通过过滤器的按键列表。只需把字符放进列表，用空格分隔。例如用 '1 2 g h' 表示 1、2、g 和 h 键。只有这些按键会被加入日志并生成事件。如果留空，则不做任何过滤。可接受的按键列表：Keyboard UI
Shortcuts shortcuts - 要监视的快捷方式列表。定义快捷方式请参见注释中的「Shortcuts」。
Panels panels - 可选的面板引用列表，用于检测来自这些面板的事件。只有当所列任一面板获得焦点时才会触发事件。
Left/Right Modifiers lrmodifiers - 开启时，左右修饰键（见注释）的状态会被加入表格。切换此参数的状态会重置表格内容。

Execute from executeloc - 决定脚本的运行位置。
  • Current Node current - 脚本从当前节点位置执行（例如 'cc' 所指的位置）。
  • Callbacks DAT callbacks -
  • Specified Operator op - 脚本从下方 From Operator 参数指定的操作符中执行。
From Operator fromop - 其状态变化会触发该 DAT 执行脚本的操作符，前提是 Execute 设为 Specified Operator。若 Execute From 参数设为 Specified Operator，该操作符也是脚本执行时所在的路径。
Clamp Output clamp - 该 DAT 默认限制为 100 条消息，但使用 Clamp Output 可以设为任意值，包括无限制。
Maximum Lines maxlines - 限制消息数量，较旧的消息会先从列表中移除。
Clear Output clear - 除表头外删除所有行。要用 Python 脚本清空：op("opname").par.clear.pulse()

说明

Shortcuts 由一组修饰键（见下文）和一个「触发」键定义，之间用 . 分隔。

例如，ctrl.shift.a 修饰键是 ctrl 和 shift，触发键是 a。当 ctrl 和 shift 中的一个被按下、且触发键 a 被按下时，该快捷方式会被激活。如果按下了其他任何修饰键，则不会检测到该快捷方式。

修饰键 - 以下是所有有效的修饰键：

  • lalt - 左 alt 键。
  • ralt - 右 alt 键。
  • alt - 左或右 alt 键。
  • lctrl - 左 ctrl 键。
  • rctrl - 右 ctrl 键。
  • ctrl - 左或右 ctrl 键。
  • lshift - 左 shift 键。
  • rshift - 右 shift 键。
  • shift - 左或右 shift 键。

操作符输入

  • Input 0: -

Info CHOP 通道

Keyboard In DAT 的附加信息可以通过 Info CHOP 获取。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
