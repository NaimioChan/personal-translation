顶点


顶点是 Polygon 的一部分，而 Polygon 是 SOP 中的 Primitive。多边形由一系列顶点组成，这些顶点隐式连接在一起，在 3D 中形成多边形状。

每个顶点是 Point List 中的整数索引，每个 Point 保存 XYZ 位置以及可选的 Attributes，例如法线和纹理坐标。

每个 Vertex 都是对一个 Point List 中 Point 的引用。Primitive List 中的多边形是 Geometry Detail 的一部分，而后者又是 SOP 的一部分。 另请参阅：Geometry Detail、Point、Point List、Point Class、Primitive、Prims Class、Polygon、SOP、SOP Class、SOP to DAT、Script SOP、Point Groups、Primitive Groups、Attributes。
