Attribute Convert POP

摘要

Attribute Convert POP 可让你把 POP attribute 从一个「attribute class」复制到另一个。也就是说，属性可以位于点、顶点或图元上。例如，你可以把图元属性转换到该图元的点上。某些情况下结果是有歧义的，例如某个点被多个图元或多个顶点共享时，此时 POP 会选取一个值，且不会报错。

转换时，它可以删除原始属性；当它创建的属性已存在时，它可以报错或给出警告。

请参阅 POP to DAT 以查找 POP 的所有属性。

请参阅 Attribute POP 以在同一属性类内复制或重命名属性。

注意：目前 POP 整体上还没有属性。

attributeconvertPOP_Class

参数 - Attribute Convert 页

Convert Operation convertop - - 选择转换的来源和目标属性类（Point、Vertex、Primitive）。
  • None none -
  • Point to Vertex pointtovert -
  • Vertex to Point verttopoint -
  • Point to Primitive pointtoprim -
  • Primitive to Point primtopoint -
  • Vertex to Primitive verttoprim -
  • Primitive to Vertex primtovert -
Input Attributes inputattrs - - 要转换到新属性类的输入属性。
  • * * -
New Attribute Name newattrs - 正在创建的新属性名称。
Delete Original deleteorig - 删除选中的传入属性。
Notification if Attribute Exists notificationifexists - - 当输入上已存在该属性时是否显示通知。
  • Ignore ignore -
  • 警告 warning -
  • Error error -
Override if Attribute Exists overrideifexists - 开启时，如果此 POP 创建的新属性与某个输入属性同名，则覆盖该输入属性。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

操作符输入

  • Input 0: -

Info CHOP 通道

Attribute Convert POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
