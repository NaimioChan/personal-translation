变量

变量是带有名称的值（文本字符串）。例如，一个内置变量名为 DESKTOP，当你在脚本或参数中看到 var('DESKTOP') 时，它会被替换为其字符串值，即你桌面的路径。要查看许多变量，请打开 Dialogs → Variables。请参阅 Variables Dialog。

注意：一些系统变量是 App Class 的成员。

要访问 TouchDesigner 中的任何变量，请使用 python 表达式 var('VARNAME')。请参阅 Td_Module 中的 var()。变量名区分大小写，因此 var('EAR') 与 var('ear') 是不同的变量。

变量有五类。它们的区别在于保存在何处以及谁可以更改它们：

  • System Environment Variables - 它们在启动 TouchDesigner 时来自操作系统，你无法在 TouchDesigner 内更改它们。它们可以在 Windows 控制面板中编辑：Control Panel → System → Advanced System Settings 或 Advanced → Environment Variables。
  • Built-in Variables - 它们内置于 TouchDesigner 中，例如 PI (3.14159)，你可以在任何地方使用，且无法更改。
  • Root Variables - Root 变量由用户创建，位于根（/）处，可在 TouchDesigner 中的任何地方使用。
  • Parent Shortcuts（见 Extensions） - 它们可在组件中的任何地方使用，以获取组件的路径。它们用于使组件与位置无关。
  • Component Variables - 你在组件中创建变量，它只能在该组件中的任何地方使用。现在有了 python，组件 extensions 具有 Properties，这些变量的使用已减少。
  • Operator 变量 - 它们已被 python 淘汰，操作符具有保存局部变量的特定成员。

提示：三个表达式返回关于变量的信息——它是否存在、是什么类型以及位于何处：varexists("NAME")、vartype("NAME") 和 varpath("NAME")。

Tscript only：关于 Tscript 中的对应写法，请参阅 varexists(), vartype(), varpath(), var()。TouchDesigner 对 System、Built-In、Root 和 Operator 变量的约定是全大写，例如 $TEMPERATURE。小写通常用于 Script 变量。混合大小写常用于其他变量——例如 $NumStudents。

系统环境变量

系统环境变量在每次启动 TouchDesigner 时加载，是在 TouchDesigner 外部定义的变量。

如何设置环境变量

Windows

你可以通过打开 Windows Start → Control Panel 对话框，然后打开 System → Advanced System Settings → Advanced 页并单击 Environment Variables 按钮，来添加/编辑/删除这些变量。你可以使用上方区域仅为当前用户添加环境变量，或使用下方区域为计算机上的所有用户添加。

macOS 请参阅 macOS Environment Variables。

环境变量列表

TEMP - TouchDesigner 创建一些临时文件的位置。

以下是一些你可以设置的变量，用于在 TouchDesigner 中获得不同行为：

TOUCH_WEB_LAUNCH 设置变量 TOUCH_WEB_LAUNCH，以选择 TouchDesigner 在启动浏览器时（例如用于帮助）使用不同的 Web 浏览器。例如将 TOUCH_WEB_LAUNCH 设为 "firefox.exe" 以使用 Firefox 查看帮助。（rvar TOUCH_WEB_LAUNCH firefox.exe）或在环境变量中设置。

TOUCH_EDITOR - 设置你希望与 TouchDesigner 一起使用的外部文本编辑器的路径。

TOUCH_TABLE_EDITOR - 设置为你希望与 TouchDesigner 一起使用的外部表格编辑器的路径。如果未定义，将使用文本编辑器。

TOUCH_TEXT_CONSOLE - 设为 1 以强制 TouchDesigner 文本控制台始终打开。

TOUCH_QUICK_CRASH - 禁用 TouchDesigner 崩溃时保存 CrashAutoSave.toe 和 .dmp 转储文件。确认对话框也会被抑制。

TOUCH_DISABLE_CRASH_HANDLERS - 禁用所有 TouchDesigner 崩溃警告和对话框。

TOUCH_MIDI_CHAN_OVERRIDE 设置此变量可让你强制来自两个输入端口之一的 MIDI 数据看起来是某个 MIDI 通道号。将变量设为 0 2 4 会强制 Input 2 映射到 MIDI 通道 2，Output 映射到 MIDI 通道 4。

TOUCH_NO_UPDATE_CHECK - 设为 1 以允许 TouchDesigner 在启动时不检查软件更新。

TOUCH_10_BIT_COLOR - 启用 10 位颜色支持，更多信息请参阅 10-bit Color Displays。需要带有 DisplayPort 连接器的高色深 LDC 显示器。

TOUCH_DOUBLE_DRAW - TouchDesigner 会将每个渲染帧输出两次。这在以显示器刷新率一半的速率渲染项目时很有用，因为它让 TouchDesigner 能可靠地执行帧倍增。通常帧倍增由显示器和显卡执行，在某些情况下这些帧可能被错误地倍增，导致卡顿。旧有功能。Use the parameter in the Window COMP instead of this.

内置变量

NOTE: These variables are Tscript variables and therefore deprecated.

TouchDesigner 的内置变量在启动时设置，用户无法更改或设置。你可以通过打开 Dialogs 菜单下的 Variables Dialog，并单击 Built-in 标签来查看内置变量。你也可以使用 TScript 命令 bvar 列出所有内置变量。

一些内置变量包括：


AF - TouchDesigner 内部时间轴的当前帧号。（python: absTime.frame）

AT - TouchDesigner 内部时间轴的当前时间（秒）。（python: absTime.seconds）

BPM - 本地时间轴的当前每分钟节拍数。

COOKRATE - TouchDesigner 内部时间轴的当前更新速率。（python: cookRate()）

CUR_TOUCHBUILD - 当前的 TouchDesigner 版本。

CUR_TOUCHVERSION - 当前的 TouchDesigner 版本号。

DESKTOP 和 MYDOCUMENTS - 分别为用户 Desktop 和 My Documents 目录的路径。

END - 本地时间轴的当前结束范围。

F - 本地时间轴的当前帧号。

FPS - 本地时间轴的当前每秒帧数。

GADGET_DRAGOUT - 最近将其 'dragout' Panel Value 设为 1 的 Panel Component 的 Path。

GADGET_INSIDE - 最近将其 'inside' 面板值设为 1 的面板组件的路径。

GADGET_ROLLOVER - 最近将其 'rollover' 面板值设为 1 的面板组件的路径。

GADGET_SELECT - 最近将其 'select' 面板值设为 1 的面板组件的路径。

USERPATH - $HOMEDRIVE/$HOMEPATH/Derivative/TouchDesigner077，用户 TouchDesigner 首选项文件的路径。它以前是 $HOME。

OP_ROLLOVER - 网络编辑器中光标最近滑过的节点的路径。

OP_SELECT - 网络编辑器中光标最近选中的节点的路径。

PANE_SELECT - Network Editor 中最近单击的 Pane 的名称。

PROJECT - 包含当前 .toe 文件的 Folder 的 Path。

RF - 根时间轴的当前帧号。

RT - 根时间轴的当前时间值（基于 $RF）。

RANGESTART - 本地时间轴的当前起始子范围。

RANGEEND - 本地时间轴的当前结束子范围。

SIGNATURE1 - 本地时间轴拍号的当前第一值。

SIGNATURE2 - 本地时间轴拍号的当前第二值。

START - 本地时间轴的当前起始范围。

SYS_* - 一组描述 CPU、GPU 版本、内存、驱动版本等信息的变量。

SYS_MAINMONITOR - 返回主显示器显示的索引。

SYS_XRES 和 SYS_YRES - 分别为系统当前的 X 和 Y 显示器分辨率。不过，你可以使用 Monitors DAT 获取连接到计算机的所有显示器的分辨率。Tscript：monitorw() 和 monitorh() 表达式。

T - 本地时间轴的当前时间值（基于 F）。

TFS - TouchDesigner 安装目录的路径。默认情况下为 C:/Program Files (x86)/Derivative/TouchDesigner099。

TOUCH - 已加载的 .toe 文件所在目录的路径。通过双击桌面上的 TouchDesigner 图标打开新的 TouchDesigner 会话时，TOUCH 将被设为桌面。

VARNAME - 最近更新的面板值的名称。

VAROP - 其面板值最近更新的面板组件的名称。

VAROPPATH - 其面板值最近更新的面板组件的路径。

VARVALUE - 最近更新的面板值的数值。

Root 变量

NOTE: These variables are Tscript variables and therefore deprecated.

Root 变量是在网络层级顶部（/，也称为 'root'）定义的变量。在此处设置后，这些变量可以在 .toe/.tox 文件中的任何网络、任何位置访问。你可以通过打开 Variables Dialog 并单击 Root 标签来查看 Root 变量。

一些示例：

TOENAME - 已加载的 .toe/.tox 文件的名称。

TOUCHBUILD - 上次保存 .toe/.tox 文件时使用的 TouchDesigner 版本。

TOUCHTIME - 上次保存 .toe/.tox 文件的时间。

TOUCHVERSION - 上次保存 .toe/.tox 文件时使用的 TouchDesigner 版本号。

可选变量：

TOUCH_HELP_DELAY - 设为 0 时，参数弹出提示被禁用；否则它表示弹出提示显示前的秒数。

Tscript：Root 变量也可以使用 rvar 命令列出、设置和取消设置，该命令就是旧式的 'set' 命令。

路径变量

请参阅 Parent Shortcut。

Tscript：每个组件都有一个名为 Path Variable 的参数。如果你在 Path Variable 中填入 "body"，那么在该组件内部的任何地方都可以使用 me.var('body')（python）或 $body（tscript），它会被展开为该组件的路径，例如 /project1/character1/body。这对于使组件与位置无关很有用。

组件变量

组件 variables 在任何组件中创建时都是局部于该组件的，可在该组件内任何地方使用，且仅限该组件。

它们通常与 Tscript 一起使用，但也可以与 Python 一起使用，不过在 Python 中，Extensions 中的属性更灵活。

在 Python 中，你会使用 var('VARNAME') 表达式来获取组件变量。在 Python 中设置它们比较困难，大致像 op('../../local/set_variables')['varname',1] = value 这样。

在 Tscript 中，使用 TScript：cvar 命令来创建、列出和删除组件变量。任何组件的组件变量都可以在 Variables Dialog 中查看：把你要查看的组件拖放到 Variables 对话框上，如果该组件存在本地变量，就会创建一个标签页来显示它们。

组件变量在 TouchDesigner 的网络中按层级求值。如果引用了某个组件变量而它未在本地组件中定义，那么它会在父组件中搜索该变量。这一过程会持续到找到该变量，或到达网络层级的顶端 /，即根。

组件变量的内部工作方式：组件变量存储在组件内一个名为 local 的 Base COMP 中。变量定义在 local 内一个名为 variables 的 table DAT 中。该 DAT 由名为 set_variables 的 Table DAT 提供数据，命令（TScript：cvar、rvar）正是使用该 DAT 来插入变量。这允许把其他变量的表格合并进 variables。TScript：cvar 命令可用于列出、设置或取消设置组件变量。

注意：根变量只是在层级根部 / 设置的组件变量。

Script 变量（仅 Tscript）

NOTE: These variables are Tscript variables and therefore deprecated.

Script 变量是在脚本中使用 set 命令设置的变量。它们仅在脚本执行期间存在。

Operator 变量（仅 Tscript）

NOTE: These variables are Tscript variables and therefore deprecated.

这些变量可以在操作符参数和脚本中使用。在脚本或 textport 中使用时，变量将应用于当前组件。例如，如果你将 cc 设为 /project1，那么 $ON 将返回 project1 作为名称，而 $OPN 将返回 root 作为父级名称。

$ON 和 $OPN - 分别为操作符的名称和父操作符的名称。提示： 这与表达式 opname(".") 和 opname("..") 相同。请参阅 opname()。

$OD 和 $OPD - 分别为操作符的编号和父操作符的编号。操作符编号是操作符名称末尾的任何数字字符。提示： 这与表达式 Tscript:opdigits(".")|opdigits(".") 和 Tscript:opdigits("..")|opdigits(".") 相同。请参阅 opdigits()。

$OT - 操作符类型。

$OF - 操作符族。

$PN - 参数名称。

$PX - 参数索引。

$PL - 参数标签。

$CURRENT - 当前网络中当前节点的名称。可通过网络编辑器或命令 opset -c 设置 Current 标记。如果节点不是网络，则为空字符串。与 opcurrent() 相同。

$SELECTED - 当前网络中所有被选中或「拾取」的节点的列表。可通过网络编辑器或命令 opset -p 设置 Pick 标记。如果节点不是网络，则为空字符串。与 opselect() 相同。

$COMP - 此变量会因使用它的组件不同而变化。它定义为 $TOUCH/Comp/current_component_path。例如，假设你有节点 /geo1/testcomp/file1（其中 file1 是 File In SOP），并且在 File In SOP 的 File 参数中写入 $COMP/mesh.tog，它会解析为 $TOUCH/Comp/geo1/testcomp/mesh.tog。

Operator 变量（节点专用）（仅 Tscript）

NOTE: These variables are Tscript variables and therefore deprecated.

某些 OP 类型具有只能在该节点参数中使用的变量，即节点专用的 Operator 变量。可用的变量因 OP 而异，你可以查看 OP 的帮助页来了解它支持哪些变量（如果有）。

TOP 具有 RESX 和 RESY，即输入图像分辨率。

其中一些变量在节点计算期间会变化。这些变量的值会针对每个被求值的「单元」而变化。「单元」是操作符所作用的对象，因此对 CHOP 而言，「单元」是一个采样；对 Point SOP 而言，「单元」是一个点；对 Primitive SOP 而言，每个「单元」是一个图元。例如，如果在 Point SOP 中使用变量 $TX，则对每个点，$TX 会取该点的 X 位置。
