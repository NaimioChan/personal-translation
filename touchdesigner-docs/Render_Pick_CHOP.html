Render Pick CHOP

摘要

Render Pick CHOP 对渲染结果（来自 Render TOP 或 Render Pass TOP）进行采样，并返回该拾取位置上几何的 3D 信息。采样的值可以包括位置、法线、点颜色、纹理坐标、深度和对象路径。要获取对象路径，应使用 Info DAT。

拾取位置通过渲染的 uv 坐标指定。这些 uv 坐标可以通过点击 Panel Component 来选择，也可以在 Render Pick CHOP 的 U 和 V 参数中显式设置。

除返回的几何数据外，此节点还有两个通道「picked」和「trigger」用于指示拾取状态。在搜索位置找到对象时，「picked」为 1。当既找到了对象、又满足「Picking By」条件时，「trigger」为 1。也就是说，「Panel Value」为 1，或「Select」参数为「On」。

另请参阅多样本 Render Pick DAT。

参数 - Render Pick 页

Strategy strategy - - 决定何时根据拾取交互更新值。
  • While Select select -
  • Hold First Picked holdfirst - 保存拾取到几何时首次返回的值。
  • Hold Last Picked holdlast - 保存拾取到几何时最后返回的值。它与 Continuous 策略的区别在于：如果拾取开始采样到空白区域（场景中该部分没有几何），它会保留最后拾取到的值。相反，使用 Continuous 策略时，如果拾取开始采样到空白区域，值会被清零。
  • Always always -
Clear Previous Pick on New Pick clearprev - 此参数仅在 Strategy 设为 Hold Last Picked 时启用。开启时，在空白区域开始新的拾取会清除值；关闭时，如果拾取从空白区域开始，将保留最后的值。
Response Time responsetime - - 决定值的更新时机。
  • Next Cook (Faster) nextcook - 值在当前帧捕获，在下一帧更新。结果为上一帧的数据，但计算时间快得多。
  • This Cook (Slower) thiscook - 值在当前帧捕获并更新。
Pick Radius pickradius - 控制拾取搜索区域的半径。如果在拾取中心没有找到任何东西，它会在 Pick Radius 定义的搜索区域内继续搜索几何。
Pick Radial Step pickradstep - 用于减少搜索区域内的搜索量。搜索区域会在从拾取中心向外呈「辐条」状的位置上进行采样。
Pick Circular Step pickcirstep - 用于减少搜索区域内的搜索量。搜索区域会在从拾取中心向外呈「环」状的位置上进行采样。
Render/RenderPass TOP rendertop - 指定要采样的渲染。
Use Pickable Flags usepickableflags - 开启后，只有 Pickable Flag 处于开启状态的几何才能被 Render Pick CHOP 选中。Pickable Flag 位于所有 Object 组件上。
Include Non-Pickable Objects includenonpickable - 将不可拾取的对象纳入拾取算法，使不可拾取的对象可以遮挡可拾取的对象。例如，如果场景中只有一个可拾取对象，同时存在大量额外的不可拾取几何，开启此参数后，若该可拾取对象位于不可拾取对象之后（被不可拾取对象遮挡），它将无法被选中。
Picking by pickingby - - 决定拾取位置的设置方式。
  • Panel panel - 使用 Panel 参数中所指定范围的面板组件。鼠标在该组件控制面板上的 uv 位置将成为渲染中被采样的 uv 位置。当 Panel Value 参数指定的面板值为 1 时，拾取生效。
  • Parameters parameters - 使用下方的 U、V 和 Pick 参数进行拾取。
Panel panel - 指定按面板拾取时使用哪个面板组件。
Panel Value panelvalue - 指定按面板拾取时使用哪个面板值来触发拾取。
U picku - 设置按参数拾取时的 u 坐标。
V pickv - 设置按参数拾取时的 v 坐标。
Select select - 按参数拾取时，此参数 = 1 时拾取生效。
Activate Callbacks activatecallbacks - 为每个拾取事件启用 Callback DAT。
Callbacks DAT callbacks - 包含所收到拾取事件回调的 DAT 路径。

参数 - Options 页

Fetch Position position - - 返回几何上被拾取点的位置。通道为 tx, ty, tz。
  • No no - 不返回位置值。
  • In SOP Space sopspace - 返回被拾取点在 SOP 变换空间中的位置。
  • In World Space worldspace - 返回被拾取点在世界变换空间中的位置。
  • In Camera Space cameraspace - 返回被拾取点在摄像机变换空间中的位置。
  • Relative to Object relativetoobj - 返回被拾取点相对于 Reference Object 参数所指定对象的位置。
Fetch Normal normal - - 返回几何上被拾取点的法线。通道为 nx, ny, nz。
  • No no - 不返回法线值。
  • In SOP Space sopspace - 返回被拾取点在 SOP 变换空间中的法线。
  • In World Space worldspace - 返回被拾取点在世界变换空间中的法线。
  • In Camera Space cameraspace - 返回被拾取点在摄像机变换空间中的法线。
  • Relative to Object relativetoobj - 返回被拾取点相对于 Reference Object 参数所指定对象的法线。
Reference Object referenceobj - 获取 Relative to Object 中的位置或法线时使用的对象。
Fetch Point Color color - 返回几何上被拾取点的点颜色。通道为 cr, cg, cb, ca。
Fetch Texture UV uv - 返回几何上被拾取点的纹理坐标。通道为 mapu, mapv, mapw。
Fetch Object Path path - 返回被拾取对象的路径。此结果需要 Info DAT，且其 Node Path 参数引用 Render Pick CHOP。
Fetch Depth depth - 返回几何上被拾取点的深度。该值是点位置在 Depth Buffer 近平面与远平面之间的非线性比例。通道为 depth。
Fetch Instance ID instanceid - 返回对象的 Instance ID。如果未启用实例化，此值始终为 0。通道为 instance。
Custom Attrib 1 customattrib1 - 指定从对象返回哪些自定义属性。
Custom Attrib 1 Type customattrib1type - 属性类型从此菜单中选择。
Custom Attrib 2 customattrib2 - 指定从对象返回哪些自定义属性。
Custom Attrib 2 Type customattrib2type - 属性类型从此菜单中选择。
Custom Attrib 3 customattrib3 - 指定从对象返回哪些自定义属性。
Custom Attrib 3 Type customattrib3type - 属性类型从此菜单中选择。
Custom Attrib 4 customattrib4 - 指定从对象返回哪些自定义属性。
Custom Attrib 4 Type customattrib4type - 属性类型从此菜单中选择。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

可通过 Info CHOP 访问 Render Pick CHOP 的额外信息。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
