VFS 类

VFS 类描述 COMP 的 Virtual File System。
要在任何操作符的文件参数中访问虚拟文件，请使用虚拟路径格式：vfs:<path to comp>:<filename>。
VFSFile_Class 负责文件操作符。

成员

owner → OP (Read Only):

获取 OP 所有者。

方法

[name]→ VFSFile:

可以使用 [] 语法轻松访问 VFS Files。

  • name - 必须是精确的 VFS 文件名。不支持通配符。如果未找到，将引发错误。
p = op('base1').vfs['Banana.tif']

addByteArray(byteArray, name)→ VFSFile:

从 bytearray 向组件添加嵌入式文件。返回所添加文件的 VFSFile 实例。要删除文件，请参阅 VFSFile Class 上的 destroy()。

  • byteArray - 表示文件内容的 bytearray 或 bytes 对象。
  • name - 文件在 VFS 上的名称。

addFile(filePath, overrideName=None)→ VFSFile:

从磁盘向组件添加嵌入式文件，并可选择覆盖名称。返回所添加文件的 VFSFile 实例。要删除文件，请参阅 VFSFile Class 上的 destroy()。

  • filePath - 要添加的磁盘文件路径。
  • overrideName (Keyword, Optional) - 指定时，将覆盖文件在 VFS 中的名称。

export(folder, pattern='*', overwrite=False)→ list:

将所有匹配的文件导出到磁盘上的文件夹。如果 overwrite 为 True，则磁盘上同名的现有文件将被覆盖。返回磁盘上导出文件的路径列表。

  • folder - 要导出文件到的磁盘文件夹。
  • pattern (Keyword, Optional) - 用于匹配名称的模式。
  • overwrite (Keyword, Optional) - 为 True 时，将覆盖任何同名文件。
# VFS 包含一个名为 'A/B.tif' 的文件
COMP.vfs.export('C:/tmp') # 返回 ['C:/tmp/A/B.tif']

find(pattern='*')→ list:

查找 VFS 中所有名称匹配该模式的文件。返回 VFSFile 对象的列表。

  • pattern (Keyword, Optional) - 用于匹配名称的模式。

特殊函数

len(VFS)→ int:

返回虚拟文件的总数。 

a = len(op('base1').vfs)

Iterator→ str:

遍历每个虚拟文件名。 

for f in op('base1').vfs:
	debug(f) # 打印 base1 上所有虚拟文件的信息
