Select POP

摘要

Select POP 从其单一路输入中取出各个属性，并原样输出这些属性。它常被使用，以便你单独处理某些属性，处理完后再在下游用 Attribute Combine POP 把它们合并回去。

点的数量不变。所选属性中的数据不变。拓扑也不变 - 它输出的图元和顶点与输入相同。

由于 POPs 族操作符中未在某个 POP 里被修改的属性实际上不会复制数据，也不会分配更多内存（它们只是对真正持有数据的 POP 的引用），因此选择属性再合并回去并不会让速度更快或更省内存。这更多是一种工作流程偏好，更接近 CHOPs 的工作方式。在 Select POP 节点上中键单击可查看信息弹窗，注意其消耗的 GPU 内存为 0。

除了连线输入，你还可以使用 POP 参数来引用当前或其他网络中的另一个 POP。

注意：与 Attribute Combine POP 增加点属性数量、但不改变点数不同，Merge POP 会把图元及其顶点与各输入的点列表合并，从而增加点数。例如，它把所有点的 P 属性合并在一起，形成更长的点列表。

另请参阅 Attribute Combine POP、Math Mix POP 和 math Combine POP（也可提取单个属性）、 Merge POP、Topology POP

Info CHOP 通道

Select POP 的额外信息可通过 Info CHOP 获取。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
