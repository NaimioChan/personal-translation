面板快捷键

有两类 Shortcut：内置于 TouchDesigner 创作界面的 Application Shortcuts，以及 Panel Shortcuts（此处介绍）。Panel Shortcuts 可添加到任何自定义构建的面板，以增加键盘功能。

以下是默认的 Panel Shortcuts，正如你在 Perform Mode 中或操作任何面板时会用到的：

  • 要停止时间轴，按住 Shift 并按空格键。
  • 要前进一帧，按住 Shift 并按右方向键
  • 要后退一帧，按住 Shift 并按左方向键。

设置 Panel Shortcuts

在 Designer Mode 中，Application Shortcuts 的行为是：空格键暂停，右方向键前进一帧，左方向键后退一帧。

要创建新的 Panel Shortcuts，请为每个所需的面板组件在位置 local/shortcuts 添加一个 DAT。第一列留空，第二列是字符，第三列是脚本命令。它只被面板读取，不会被工作表读取。第一列不用的原因是为了与应用快捷键表保持相同格式。 Note: the third column is currently only TScript. To use Python place your code in macro and simply reference the macro from this table instead.

示例：local/shortcuts 表： （记住第一列是空白的。）

label key command
c echo you pressed c
D echo you pressed D
b echo you pressed b
B echo you pressed B

可以使用特殊保留的标签来指定特定键盘字符： （记住第一列是空白的。）

label key command
up echo You pressed up
down echo You pressed down
left echo You pressed left
right echo You pressed right
tab echo You pressed tab
enter echo you pressed enter
esc echo you pressed escape
backspace echo you pressed backspace
space echo you pressed space bar
prtsc echo you pressed print screen
scrlk echo you pressed scroll lock
pause echo you pressed pause
insert echo you pressed insert
home echo you pressed home
pgup echo you pressed page up
del echo you pressed del
end echo you pressed end
pgdn echo you pressed page down
numlk echo you pressed num lock
F1 echo you pressed F1
F2 echo you pressed F2
F3 echo you pressed F3


也可以通过字符的 ASCII 值来指定字符： （记住第一列是空白的。）

label key command
65 echo you pressed capital A
66 echo you pressed a


你可以添加 ctrl、alt、shift 修饰键： （记住第一列是空白的。）

label key command
alt.b echo you pressed alt b
ctrl.b echo you pressed ctrl b
shift.tab echo you pressed shift tab
ctrl.alt.down echo you pressed ctrl alt down
shift.ctrl.up echo you pressed ctrl shift up

复合修饰键的顺序是任意的：alt.ctrl.shift、ctrl.alt 等。另请注意，并非所有键盘对相同的按键组合都有相同的报告。

用面板值实现快捷键

另一种方式是，每个面板还包含「key」Panel Value，它会以脉冲形式输出在其上按下按键的数值。每当按下某个键，「key」面板值会被设为该字符的 ASCII 值，然后立即回到 0。请确保你的脚本能捕获由 off 到 on 的按键值变化。

每个按键事件都会沿其面板链向上传递，直到被途中的字段组件或快捷键脚本拦截。


使用以下函数在 ASCII 值与字符之间转换： 

string  ftoc(int num)   // 浮点数转字符
num     ctof(string)    // 字符转浮点数


示例： 

ftoc(65) = "a"
ctof("a") = 65
