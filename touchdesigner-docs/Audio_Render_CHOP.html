Audio Render CHOP

摘要

注意： 在 Apple Silicon Mac 上，此操作符仅从 build 2022.33910 起可用。

Audio Render CHOP 使用 Steam Audio SDK，根据收听者和音频源的完整变换（平移、旋转、缩放）对音频进行空间渲染。Audio Render CHOP 以音频源作为输入，并按 Output Format 参数指定的格式对声音进行空间输出。Audio Render CHOP 输出的通道数取决于 Output Format。

你需要为收听者的变换指定一个 3D 组件，并为声源的变换再指定一个 3D 组件。

输出的采样率由音频源决定，音频源必须为 44100 或 48000。

可使用 Info DAT 在 Simulation 模式下填充烘焙探针的位置和半径。

参见 Help → Operator Snippets 中的 Audio Render CHOP 示例。

另请参阅 Oculus Audio CHOP。

audiorenderCHOP_Class

参数 - Audio Render 页

Active active - 打开或关闭 Audio Render。
Mode mode - - 此菜单决定使用哪种 Steam Audio 模式。
  • Simple Positional simple - 仅针对单声道声源的声音模拟。
  • Simulation simulation - 针对多个声源的声音模拟。
Output Format outputformat - - 音频的输出格式。
  • Binaural Binaural - 根据声源相对于收听者的 3D 位置进行空间化。
  • Stereo stereo - 基于左、右声道进行空间化。
  • Quadraphonic Surround quadraphonic - 基于前左、前右、后左、后右声道进行空间化。
  • 5.1 Surround fiveone - 基于前左、前右、前中、LFE、后左、后右声道进行空间化。
  • 7.1 Surround sevenone - 基于前左、前右、前中、LFE、后左、后右、侧左、侧右声道进行空间化。
  • Custom Setup custom - Custom Setup 需要使用 Mapping Table。
  • Ambisonics ambisonics - Ambisonics 是一种编码三维 360 度音频的格式。Audio Render CHOP 使用的 Ambisonics 格式为 3 阶 SN3D 格式，由 16 个编码通道（WXYZ、RSTUV、KLMNOPQ）组成，用于定义声音的球面。在 Simulation 模式下启用反射时，Ambisonics 会被禁用。
  • Direct Effect direct - 仅在 Simulation 模式下使用，基于点声源与收听者之间的直达路径模拟声音。启用反射时，Direct Effect 会被禁用。
Enable Attenuation attenuation - 根据收听者中心位置与声源之间的距离对声音进行衰减。衰减量由每个声源所选的衰减模式决定。
Ambisonics Order ambisonicsorder - 输出缓冲区的 Ambisonics 阶数。
Mapping Table mappingtable - 一个 DAT 表格，用于指定设置中的各个扬声器及其位置。该表格必须包含名为 x、y、z 的 3 列。每一行指定一个扬声器，这 3 列指定其位置。与 Custom Setup 输出格式配合使用。映射表会为每一行创建一个通道。
Listener Object COMP listenerobject - 表示收听者头部的 COMP。必须是包含变换数据的 COMP，例如 Geometry 或 Camera COMP。
Source source - 音频源的序列。
Object COMP source0object - 表示声音源的 COMP。必须是包含变换数据的 3D Object COMP，例如 Geometry COMP 或 Camera COMP。
Enable Directivity source0directivity - 打开或关闭指向性。禁用时，声音会从声源向各个方向发出（即全向）。
Dipole Weight source0dipoleweight - 在指向性图案中混入的偶极子权重。0 = 纯全向，1 = 纯偶极子，0.5 = 心形指向性图案。
Dipole Power source0dipolepower - 偶极子的锐度。值越大，声音的方向越窄。
Attenuation Mode source0attnmode - - 此菜单决定该声源使用的衰减模式。注意： 由于已知问题，启用反射时衰减模式会被禁用。若在反射开启时启用衰减，将回退到 Steam Audio 的默认衰减模型，即幂次为 1 的反距离衰减。
  • Inverse Distance inverse - 衰减量由反距离衰减函数计算。
  • Custom Curve custom - 衰减量由自定义曲线计算。
Attenuation Inverse Power source0invpower - 反距离衰减函数的幂次。例如，幂次为 2 时，衰减量为 (1/distance)^2。
Attenuation Curve CHOP source0chop - 被引用的自定义衰减曲线 CHOP 的路径。该 CHOP 必须恰好有一个通道来表示曲线。垂直轴表示衰减量，水平轴表示距离。衰减量被限制在 [0, 1] 之间。距离应始终为非负值，并假定该 CHOP 以采样为单位。

参数 - Meshes 页

Update Meshes update - 启用后，任何静态网格的更改都会自动更新到模拟中。
Update Meshes Pulse updatepulse - 脉冲触发时，若静态网格有变化，会将其更新到模拟中。
Mesh mesh - 静态网格的序列。
Mesh Objects/POPs/SOPs mesh0object - 网格使用的对象，可以是 geometry COMP、POP 或 SOP。COMP 必须包含三角形多边形形式的 SOP 或 POP 几何。根 COMP 的 display flag 关闭时仍会被采集。不过，子级 COMP 只有在其 display flag 开启时才会加入场景。
Absorption mesh0absorb - - 低、中、高频声音被吸收的比例。0 = 不吸收声音，1 = 声音被网格表面完全吸收。
  • Absorption mesh0absorb1 - 低频（0 - 800 Hz）的吸收量。
  • Absorption mesh0absorb2 - 中频（800 Hz - 8 kHz）的吸收量。
  • Absorption mesh0absorb3 - 高频（8 kHz 及以上）的吸收量。
Scattering mesh0scatter - 为反射散射声音。0 = 以与入射表面相同的角度反射（即纯镜面反射），1 = 均匀随机反射（即纯漫反射）。
Transmission mesh0trans - - 低、中、高频声音透射的比例。0 = 声音不透过，1 = 声音完全透过网格表面。
  • Transmission mesh0trans1 - 低频（0 - 800 Hz）的透射量。
  • Transmission mesh0trans2 - 中频（800 Hz - 8 kHz）的透射量。
  • Transmission mesh0trans3 - 高频（8 kHz 及以上）的透射量。

参数 - Simulation 页

Enable Air Absorption airabsorb - 为所有声源打开或关闭空气吸收。空气吸收是指声音从声源传播到收听者的过程中随距离损失的量。
Enable Occlusion occlusion - 为所有网格打开或关闭射线投射遮挡。若从收听者到声源的单条射线被遮挡，则该声源被视为被遮挡。
Number of Surfaces numsurfaces - 计算总声音透射时考虑的表面的最大数量，从距离收听者最近的表面开始计算。
Enable Reflection reflection - 为所有网格打开或关闭反射。
Diffuse Samples diffsamp - 为反射射线生成的方向数量。
Duration duration - 生成的脉冲响应的时长（秒）。
Ambisonics Order refambixord - 生成的脉冲响应的 Ambisonics 阶数。
Number of Rays numrays - 从收听者追踪的射线数量。
Number of Threads numthreads - 用于实时反射模拟的线程数。
Number of Bounces numbounces - 每条射线在表面上的反射次数。
Irradiance Min Distance irmindist - 用于计算从声源到达某一表面的声音能量的最小距离。
Reflection Bake Mode bakemode - - 此菜单决定使用的烘焙模式。在计算反射时，烘焙是一种有用的优化工具。烘焙会生成探针，这些探针均匀分布，并以固定高度放置在任何网格「地板」之上。网格「地板」用于模拟地板或地形，因此网格应水平或沿 XZ 平面放置，才会在其上方生成探针。探针的影响区域由 3D 位置和半径定义。烘焙有两种变体：静态收听者和静态声源。例如，若选择静态收听者，烘焙会假定收听者的位置保持不变。随后每个探针都会烘焙反射数据，模拟其位置与收听者之间的声音。烘焙完成后，声源可以动态移动，只要它们位于任何已烘焙探针的范围内，就会使用该探针的烘焙反射数据来计算其反射声音，从而减少计算量和模拟时间。若声源不在任何已烘焙探针的范围内，则该声源不会受任何烘焙数据影响，可能导致声音计算错误。用于反射的所有参数也会用于烘焙。以下情况不会生成探针：场景中没有几何、spawn box 不包含场景中的任何几何、生成的所有探针都位于 spawn box 之外，或所有几何都是 X-Y 或 Y-Z 平面。
  • Off off - 烘焙已关闭。关闭烘焙会停用当前所有活动的烘焙。
  • Manual manual - 烘焙已开启，但须脉冲触发 Baked Reflections 才能开始烘焙。
  • Automatic auto - 烘焙已开启，当烘焙参数发生变化时会自动开始烘焙。
Bake Reflections bake - 立即开始烘焙。完成后，反射将自动使用烘焙数据。可通过 Info CHOP 中的 bake_complete 通道监视烘焙状态。
Baked Data Variation variation - - 此菜单决定哪些对象在烘焙时位置固定。若所选静态对象的位置发生变化，必须重新烘焙，否则计算出的反射将不正确。
  • Static Listener listener - 每个烘焙探针计算反射时，声源位于探针位置，收听者位于某个固定位置。收听者的位置必须保持静止。此模式适用于模拟移动声源到静态收听者的反射。
  • Static Source source - 每个烘焙探针计算反射时，收听者位于探针位置，声源位于某个固定位置。声源的位置必须保持静止。此模式适用于模拟移动收听者到静态声源的反射。
Probes Distance probedist - 两个相邻探针之间的间距。
Y-Offset from Surface yoffset - 所有探针生成时所处的、高于几何表面的高度。
Size of Spawn Box size - - 生成探针的 spawn box 沿 X、Y、Z 轴的大小。
  • Size of Spawn Box sizex -
  • Size of Spawn Box sizey -
  • Size of Spawn Box sizez -
Origin of Spawn Box origin - - 这些 X、Y、Z 值决定 spawn box 中心的位置。
  • Origin of Spawn Box originx -
  • Origin of Spawn Box originy -
  • Origin of Spawn Box originz -
Distance from Listener lstnrdist - 为探针存储烘焙数据时距收听者的最大距离。
Save Duration savedur - 每个探针处保存的脉冲响应的时长（秒）。
Batch Size batchsize - 同时烘焙的探针数量。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Audio Render CHOP 的额外信息可通过 Info CHOP 访问。

Audio Render CHOP 的专属信息通道

  • audioposition_full_time -
  • audioposition_panbin_time -
  • distance_attenuation -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
