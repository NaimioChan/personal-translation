Curve POP

摘要

Curve POP 用于在 XY 平面（Z=0）中生成曲线，可用作 Lookup Attribute POP 的查找曲线或其他用途。它是一个「函数」：P(0) 的 X 值在各点之间均匀递增，而 P(1) 的 Y 值呈现不同的插值形状。生成的曲线也存放在属性 Curve 中，为了清晰起见，可以用它代替 P(1)。

与 S Curve CHOP 一样，它默认为 ease-in ease-out 曲线，但 Curve POP 允许添加多个分段（连续参数块），从而获得更多样的曲线。曲线可以由若干分段组成，每段由 Sequential Blocks 个参数定义，各自具有起点值、终点值和 Curve Type。

Curve Type 包括 Constant、Linear、各种 Ease 以及 Bezier。

Alpha 和 Beta 值会影响曲线：Alpha 使其更陡或更平缓，Beta 使其更偏向分段的起点或终点。选择 Bezier 时，Slope In 和 Slope Out 会影响分段端点处的斜率。

更一般地说，我们把这两个轴视为 U 和 V。曲线可以输出为纯点、linestrip，或 RGBA 颜色曲线。

由于 U 值可以从任意值开始和结束，你可以对曲线归一化，使 U 值（P(0)）位于 0 到 1 之间。

使用 Symmetric 开关可以把曲线扩展到双倍长度并使其对称。

Lookup 页可让你直接把曲线用作查找，而无需先把任何东西转换为点。这样可以保持最高精度，并避免查找曲线在两个分段之间急剧跳变时出现的插值问题。此时，你接上一个输入 POP，并希望用曲线修改其中一个或多个属性。在这种模式下，它的行为类似于 Lookup Attribute POP。

提示：如果希望特定点精确落在你的 U 关键帧值上，请确保（Number of Points - 1）能被你的 U 值整除。

另请参阅 S Curve CHOP、Line POP、Lookup Attribute POP、Pattern POP
