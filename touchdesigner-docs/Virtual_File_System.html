虚拟文件系统

概述

TouchDesigner 的虚拟文件系统（VFS）允许将图像、影片、音频、字体、其他媒体以及任意文件嵌入.tox或.toe文件中。你可以像读取文件系统中的文件一样打开并读取它们。如果.tox和.toe文件依赖图像、声音或字体文件，这会提高它们的可移植性。当然，这会让你的.tox和.toe文件按硬盘上文件的大小相应变大，但一个虚拟文件可以同时被多个操作符引用。

Tools 部分的调色板组件virtualFile让你无需脚本即可存储虚拟文件。

访问文件

内部文件可直接用vfs:前缀寻址。例如：vfs:/project1:test.jpg。此 VFS 地址可用于任何指向外部文件的参数。所有会打开文件的操作符，例如Movie File In TOP和Audio File In CHOP，都在其文件参数中支持 VFS 语法。注意： USD COMP、FBX COMP 和glTF In COMP不支持从 VFS 加载文件。

详细信息

锁定 TOP 时保存在.tox/.toe中的图像会用 LZW 压缩，而引用 VFS 中.jpeg文件的 Movie File In TOP，则完全保持 JPEG 压缩。VFS 可容纳完整的影片文件与音频文件，包括 H.264 和.mp3文件。它还可以容纳.ttf字体文件，在某些情况下还包括用于CPlusPlus TOP、CPlusPlus SOP和CPlusPlus CHOP的.dll文件。

结合Privacy选项（只能使用 TouchDesigner Pro 设置），VFS 可为内置于 TouchDesigner.tox/.toe文件中的媒体提供额外的私密性。

用法

两个 Python 类让你可完全访问 VFS 功能。

  • VFS Class - 描述 COMP 的虚拟文件系统。
  • VFSFile Class - 描述虚拟文件系统中的虚拟文件。

示例

完整细节请参阅上面的类 wiki。

Add a file from disk op('/base1').vfs.addFile('Banana.tif')
Add an image from TOP op('/base1').vfs.addByteArray(op('someTop').saveByteArray('.jpg'), 'imageName.jpg')
Delete an image op('/base1').vfs['Banana.tif'].destroy()
Save virtual file to disk op('/base1').vfs['Banana.tif'].export('diskFolderName')
Access virtual file in OP's file parameter (constant mode) vfs:/base1:Banana.tif

调色板示例

使用Palette（位于Tools下）中的virtualFile组件作为 VFS 的用户界面。这样你无需原本必需的脚本即可使用 VFS。
