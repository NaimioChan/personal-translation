AbsTime 类


该类包含关于「absolute time」的信息，即 TouchDesigner 自进程启动以来已运行的时间。可以通过 abstime 对象访问它，该对象位于自动导入的 td module 中。只有用 UI 顶部的电源开关按钮、或 td module 中的 power() 方法、或暂停根时间轴，它才会暂停。绝对时间对所有节点都相同。见 absolute time。

成员

frame → float (Read Only):

自应用程序启动以来播放的绝对总帧数。只有用电源 On/Off、power() 或暂停主时间轴才会暂停。

absTime.frame
tdu.rand(absTime.frame + .1) # 一个在所有节点间一致、每帧变化的唯一随机数

seconds → float (Read Only):

自应用程序启动以来播放的绝对总秒数。只有用电源 On/Off、power() 或暂停主时间轴才会暂停。

step → float (Read Only):

上一帧开始与当前帧开始之间经过的绝对帧数。当该值大于 1 时，系统正在丢帧。

stepSeconds → float (Read Only):

上一帧开始与当前帧开始之间经过的绝对时间。

方法

没有该操作符专属的方法。
