Hole SOP

摘要

Hole SOP 用于在被面围住的区域打孔，即使这些面不在同一平面上。它还可以从输入几何中移除已有的孔。

孔是这样生成的：查找被其他面围住的面，并创建通向内部面的桥接。它比 Extrude SOP 或 Divide SOP 的打孔功能更灵活，因为它可以处理与外部面朝向并不完全一致的内部面。如有需要，它还可以移除在输入几何中找到的已有桥接。

注意： 此 SOP 仅适用于 Polygonal 和 Bezier 几何类型。NURBS 曲面会在内部转换为 Bezier。

holeSOP_Class

参数 - 页

Group group - 如果存在输入组，在此字段中指定组名将使该 SOP 仅作用于指定的组。接受模式匹配，说明见 Pattern Matching。
Unbridge Holes unbridge - 此功能检查输入中通向孔的桥接并移除这些桥接，使内部部分独立出来。有时你需要取消面的打孔，以便用其他方式连接它们。
Distance Tolerance dist - 与外部不完全处于同一平面的内部多边形仍然可以成为孔。Distance Tolerance 值告诉 Hole SOP 潜在的孔可以距外部表面多远。超出此距离的面不会成为孔。
Angle Tolerance angle - 相对于外部面发生了旋转的内部面也可以成为孔。Angle 值设置潜在孔相对于外部的最大旋转。超出此旋转的面不会成为孔。
Snap Holes to Outlines snap - 任何旋转或平移偏离外部（或轮廓）平面的孔的顶点将被移动，使其位于轮廓平面的表面上，从而避免面扭曲。

Info CHOP 通道

Hole SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
