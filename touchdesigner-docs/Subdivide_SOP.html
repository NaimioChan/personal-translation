Subdivide SOP

摘要

Subdivide SOP 接收一个输入多边形曲面（可以只接入一个输入，也可以同时接入两个），用 Catmull-Clark 细分算法划分每个面，生成平滑的多边形曲面。它尤其适合消除多边形模型常见的棱角感——而且无需为整个对象增加大量额外几何。为了获得最佳效果，多边形应为凸多边形，且分布相对均匀。

细分曲面还允许你基于多边形控制形状创建平滑曲面。控制形状变化时，内部的平滑形状也随之变化。

折痕与裂缝

折痕

折痕控制多边形面对细分曲面的拉扯强度，很像一块磁铁把曲面吸向参考多边形。可以用 Creases 栏指定要使用的输入组，从而有选择地应用。

折痕通过控制多边形面对细分曲面的拉扯强度来起作用，像磁铁把曲面吸向参考多边形。下图展示从左到右把 Crease Weight 设为 0, 1, 2 的结果。权重增大时拉扯效果增强，形状趋近参考多边形。

折痕算法

如果有第二输入：

如果启用了 Override 按钮，第二个输入中定义的每条边，其边折痕权重都会设为 override 的值。
如果第二个输入上存在顶点属性 "creaseweight"，输入中每条匹配的边，其折痕权重都会设为所有共享边顶点属性的最大值。
如果第二个输入上存在图元属性 "creaseweight"，第二个输入中的每个多边形都会把匹配的边设为相应的权重。

如果没有第二输入：

如果指定了 override，则细分曲面的所有边都使用该 override 的值。
如果存在顶点属性 "creaseweight"，将用该属性定义曲面各边的折痕权重。
如果存在图元属性 "creaseweight"，将用该属性定义细分曲面的折痕权重。

在共享边上定义折痕权重时，使用共享边权重中的最大值。例如，如果两个多边形共享一条边并使用图元属性，则该共享边会使用折痕权重的最大值。

闭合裂缝

裂缝可以通过 Pull Cracks Closed 或 Stitch Cracks Together 闭合，因此 Surrounding Faces 参数中一次只能选其中一项。Bias 仅适用于 Pulling，选择 Stitching 时被禁用。

裂缝由未细分区域上的一条边和细分区域上的多条边形成。Surrounding Faces 菜单决定未细分区域上的那条边——更一般地说，包含该边的多边形——会怎样处理。

如果选择 No Edge Division 并把裂缝拉合，细分边上的所有点都会被拉（即移动）到未细分边上最近的点。指定 No Edge Division 时，Bias 被禁用。

如果用 Divide Edges 选项拉合裂缝，未细分的边会被切成许多段，使未细分边上的每个点现在都对应细分边上的一个新点。然后，新切分的边上的点会与细分边界上的点相连。Bias 为 1 时，这些连接点会沿细分边界放置；Bias 为 0 时会沿未细分边界放置（0 到 1 之间的值则放在两者之间的某处）。

用 Triangulate 选项拉合裂缝所做的事与 Divide Edges 完全相同，只是还会对未细分的多边形进行三角化。这是需要的，因为把未细分边界拉向弯曲的细分边界很可能产生非平面多边形，Triangulate 会把这个多边形分成更小的（平面）多边形。使用 Bias 为 1 拉合裂缝并三角化，通常能得到最好的结果。

Triangulate 选项是必要的，因为 Divide SOP 无法处理（非常）非平面的多边形。

另一方面，Stitch Cracks Together 选项会插入新的多边形（三角形）来闭合裂缝。选择 No Edge Division 时会创建许多三角形，每个三角形有一个顶点位于未细分边上的某个点。

选择 Divide Boundary Edges 时，未细分的边会被分割，因此有更多点可用于构成三角形。得到的三角形形状更规整（不会那么细长）。Triangulate 选项同样会对未细分的多边形做三角化，不过这个选项较少使用，因为缝合时该多边形应保持平面。

参数 - 页

Group subdivide - 作为要细分多边形网格的输入子集。接受模式匹配，如 Pattern Matching 所述。
Creases creases - 此栏让你指定第二输入的一个子集作为折痕。由 Creases 栏指定的第二输入元素会作为折痕使用。折痕多边形中的每条边对应多边形网格中具有相同点编号的边。点的位置无关紧要。多边形边要被视为同一条边，必须共享相同的点。仅仅在物理上靠近是不够的。

除非被覆盖，图元属性 creasesharpness 用于确定所指定折痕的锐度。

Depth iterations - 细分多少次迭代。数值越高，曲面越平滑。
Override Crease Weight Attribute overridecrease - 决定折痕锐度由图元还是顶点 creaseweight 属性决定，或由此 SOP 覆盖。
Crease Weight creaseweight - 如果折痕权重被覆盖，则使用此权重。

提示： 默认启用 Override Crease Weight Attribute。因此你可以直接设置一个适用于所有折痕的值。不过，你也可以用 Vertex 或 Primitive SOP 设置折痕属性，从而获得更多控制。

Generate Resulting Creases outputcrease - 如果有任何折痕比 Depth 更锐利，它们会保留在生成的几何中。启用此参数后，这些剩余折痕会以相应的图元属性值创建，并放入指定的组。
New Group outcreasegroup - 放置生成折痕的组名。
Close Cracks closeholes - 选择输出几何中如何处理间隙。
  • Do Not Close noclose - 不闭合裂缝。
  • Pull Cracks Closed pull - 移动细分区域边界上的点，以闭合细分过程中形成的裂缝。
  • Stitch Cracks Together stitch - 添加多边形（三角形）来闭合细分造成的裂缝。
Surrounding Faces surroundpoly - 选择拉合或缝合裂缝时如何处理裂缝两侧的多边形。
  • No Edge Division nodiv - 选择 No Edge Division 时会创建许多三角形，每个三角形有一个顶点位于未细分边上的某个点。
  • Divide Edges edges - 拉合或缝合裂缝时，通过插入新的多边形（三角形）闭合裂缝，并分割细分区域周围的边。
  • Triangulate triangulate - 与 Divide Edges 完全相同，只是还会对未细分的多边形做三角化。这是需要的，因为把未细分边界拉向弯曲的细分边界很可能产生非平面多边形，Triangulate 会把这个多边形分成更小的（平面）多边形。Bias 为 1 拉合裂缝并三角化通常能得到最好的结果。
Bias bias - 决定拉合裂缝时移动哪些点。
  • 0 表示把细分区域上的点移动到边界。
  • 1 表示把边界上的点移动到细分区域。

Info CHOP 通道

Subdivide SOP 的额外信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
