GeometryStagingData 类

此类保存定义 3D 几何所需的暂存数据，之后这些数据会传给 Script POP 进行最终构建。它支持定义图元以及点、顶点和图元属性数据。属性值可以直接追加，也可以通过从现有 POP 缓冲区复制来填充。同样，新图元可以逐个追加，也可以从另一个 POP 复制整个图元缓冲区。

从现有 POP 复制缓冲区有两种方式，取决于之后是否需要修改数据：

  • GPU 复制 - copy()、copyPrims()、copyPointAttribBuffer()、copyVertAttribBuffer() 和 copyPrimAttribBuffer() 在 GPU 端复制属性和索引缓冲区。这些操作很快，但无法从脚本修改复制后的缓冲区内容。
  • CPU 复制 - download() 在 CPU 上创建属性和索引缓冲区的副本。之后可以从脚本修改或扩展这些缓冲区。

另请参阅：POP Class、ScriptPOP Class、AttribList Class

成员

pointAttributeValues → dict (Read Only):

字典，把每个属性名映射到暂存点属性值的 AttribList。

primAttributeValues → dict (Read Only):

字典，把每个属性名映射到暂存图元属性值的 AttribList。

vertAttributeValues → dict (Read Only):

字典，把每个属性名映射到暂存顶点属性值的 AttribList。

方法

allocatePointAttribValues(numValues)→ dict:

分配多个点属性值。返回按属性名索引的 AttribList 字典。

  • numValues - 要分配的值的数量。
stagingData.createPointAttrib(name="P")
pointAttribs = stagingData.allocatePointAttribValues(10)
positions = pointAttribs["P"]
for i in range(10):
    positions[i] = (i, i, 0)

allocatePrimAttribValues(numValues)→ dict:

分配多个图元属性值。返回按属性名索引的 AttribList 字典。

  • numValues - 要分配的值的数量。

allocateVertAttribValues(numValues)→ dict:

分配多个顶点属性值。返回按属性名索引的 AttribList 字典。

  • numValues - 要分配的值的数量。

appendDimension(dimensionSize)→ None:

在元数据中添加一个维度，用于描述点列表的结构。

  • dimensionSize - 维度大小。

appendPointAttribValue(attributeName, value)→ int:

添加一个点属性元素。返回元素总数。

  • attributeName - 属性名称。
  • value - 值，或由分量、列和数组值组成的元组。

appendPointAttribValues(attributeName, values)→ int:

添加多个点属性元素。返回元素总数。

  • attributeName - 属性名称。
  • values - 要添加的值列表。列表中的元素可以是 float、int 或元组。

appendPrimAttribValue(attributeName, value)→ int:

添加一个图元属性元素。返回元素总数。

  • attributeName - 属性名称。
  • value - 值，或由分量、列和数组值组成的元组。

appendPrimAttribValues(attributeName, values)→ int:

添加多个图元属性元素。返回元素总数。

  • attributeName - 属性名称。
  • values - 要添加的值列表。列表中的元素可以是 float、int 或元组。

appendPrimLine(pointIndex0, pointIndex1)→ None:

添加一个 line 图元。

  • pointIndex0 - 点索引 0。
  • pointIndex1 - 点索引 1。

appendPrimLineStrip(pointIndices)→ None:

添加一个 line strip 图元。

  • pointIndices - 包含点索引的元组。

appendPrimLineStrips(pointIndices)→ None:

添加一个 line strip 图元。

  • pointIndices - 由点索引元组组成的列表。

appendPrimLines(pointIndices)→ None:

添加多个 line 图元。

  • pointIndices - 点索引列表。

appendPrimPoint(pointIndex)→ None:

添加一个点图元。

  • pointIndex - 点索引。

appendPrimPoints(pointIndices)→ None:

添加多个点图元。

  • pointIndices - 点索引列表。

appendPrimQuad(pointIndex0, pointIndex1, pointIndex2, pointIndex3)→ None:

  • pointIndex0 - 点索引 0。
  • pointIndex1 - 点索引 1。
  • pointIndex2 - 点索引 2。
  • pointIndex3 - 点索引 3。

appendPrimQuads(pointIndices)→ None:

appendPrimTriangles(pointIndices)→ None:

clear()→ None:

清除暂存数据。

copy(pop)→ None:

把 GPU POP 的属性值和图元索引复制到暂存 GPU 缓冲区。

  • pop - 要从其复制信息的 POP。

copyPointAttribBuffer(pop, attributeName, stagingAttributeName)→ bool:

把 POP 属性缓冲区复制到暂存数据缓冲区。

  • pop 要从其复制缓冲区的 POP。
  • attributeName - POP 的属性名称。
  • stagingAttributeName - (Keyword, Optional) 暂存属性名称。

copyPrimAttribBuffer(pop, attributeName, stagingAttributeName)→ bool:

把 POP 属性缓冲区复制到暂存数据缓冲区。

  • pop 要从其复制缓冲区的 POP。
  • attributeName - POP 的属性名称。
  • stagingAttributeName - (Keyword, Optional) 暂存属性名称。

copyPrims(pop)→ None:

复制 GPU 图元索引缓冲区。

  • pop - 要从其复制信息的 POP。

copyVertAttribBuffer(pop, attributeName, stagingAttributeName)→ bool:

把 POP 属性缓冲区复制到暂存数据缓冲区。

  • pop 要从其复制缓冲区的 POP。
  • attributeName - POP 的属性名称。
  • stagingAttributeName - (Keyword, Optional) 暂存属性名称。

download(pop, delayed=False)→ None:

复制 POP 的属性值和图元索引。

  • pop - 要从其下载信息的 POP。
  • delayed - (Keyword, Optional) 如果设为 True，下载结果会延迟返回，避免 GPU 因立即等待结果而停转。

createPointAttrib(attributeName, numComps=1, numMatRows=1, numMatCols=1, arrSize=1, type=AttribDataType.FLOAT32, qualifier=AttribQualifier.NONE)→ bool:

创建点属性。

  • attributeName - 属性名称。
  • numComps - (Keyword, Optional) 分量数量。
  • numMatRows - (Keyword, Optional) 矩阵行数。
  • numMatCols - (Keyword, Optional) 矩阵列数。
  • arrSize - (Keyword, Optional) 指定数组中允许的最大元素数量。值为 0（或不设置）表示该属性是单个非数组值。
  • type - (Keyword, Optional) 属性数据类型。
  • qualifier - (Keyword, Optional) 属性限定符。
  • defaultValue - (Keyword, Optional) 最多 4 个元素的元组，用于设置默认分量值。

createPrimAttrib(attributeName, numComps=1, numMatRows=1,, numMatCols=1, isArray=False, arrSize=1, type=AttribDataType.FLOAT32, qualifier=AttribQualifier.NONE)→ bool:

  • attributeName - 属性名称。
  • numComps - (Keyword, Optional) 分量数量。
  • numMatRows - (Keyword, Optional) 矩阵行数。
  • numMatCols - (Keyword, Optional) 矩阵列数。
  • arrSize - (Keyword, Optional) 指定数组中允许的最大元素数量。值为 0（或不设置）表示该属性是单个非数组值。
  • type - (Keyword, Optional) 属性数据类型。
  • qualifier - (Keyword, Optional) 属性限定符。
  • defaultValue - (Keyword, Optional) 最多 4 个元素的元组，用于设置默认分量值。

createVertAttrib(attributeName, numComps=1, numMatRows=1, numMatCols=1, arrSize=1, type=AttribDataType.FLOAT32, qualifier=AttribQualifier.NONE)→ bool:

  • defaultValue - (Keyword, Optional) 最多 4 个元素的元组，用于设置默认分量值。
