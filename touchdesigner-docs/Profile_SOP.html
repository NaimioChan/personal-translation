Profile SOP

摘要

Profile SOP 可用于提取和操作轮廓。

通常你需要在 Project SOP 之后使用 Trim SOP、Bridge SOP 或 Profile SOP。使用 Trim SOP 在投影曲面上挖洞。使用 Bridge SOP 将轮廓曲线蒙皮到另一条轮廓曲线。

参数 - Profile 页

Group group - 此栏允许你指定曲面上的特定曲线组，其他图元会被忽略。可以通过提供轮廓图案在该组内指定轮廓曲线（例如 *.3 指定所有样条曲面中的第四个轮廓）。
Method method - - 此菜单可将轮廓作为世界图像或参数化图像提取为独立的 3D 曲线。非参数化选项得到的曲线，其形状和空间位置与所选轮廓相同或非常接近。参数化选项会生成 XY 平面上的面，其顶点和类型与 2D 中的轮廓相同；此外，如果轮廓是样条，它将与提取出的曲线具有相同基。
  • Extract extract - 使用下方的提取参数从轮廓中提取 3D 曲线。
  • Remap remap - 使用下方的参数化参数从轮廓生成平面面。
Parametrically to X Y parametric - 若为 Fitted（未勾选此选项），轮廓将是一条空间 NURBS 曲线，其空间位置和形状与曲面上的曲线相同。它很可能不是平面的。若为 Extracted Parametrically（勾选此选项），结果会把轮廓的参数化图像提取为 3D 面，即 XY 平面上的面，其类型（多边形、Bzier、NURBS）与轮廓相同，顶点与轮廓 CV 对应。但这不能保证轮廓与提取曲线在空间上重合，更像是分析工具。

提示： 参数化提取的轮廓可以通过 Project SOP 选择 Parametric 选项且不设置 Mapping to Range，从而完全一致地重新应用到曲面上。用此方法提取轮廓、拉动其点或像编辑任何 3D 面那样编辑它，然后将其重新投影到曲面上的同一位置。

Smooth Curve smooth - 启用后，会通过提取的点拟合样条。参数化提取轮廓时此参数被禁用。禁用此参数可跳过拟合过程，该过程可能很耗性能（处理速度），而且在提取布尔运算产生的轮廓时并不必要（见 Surfsect SOP）。
Divisions per Span sdivs - 轮廓上每个跨度要计算的点数。跨度是多边形上连接两个相邻 CV 的线段，或样条曲线上两个断点之间的弧。分割数越高，轮廓通常越精确。
Tolerance tolerance - 此参数指定所提取 3D 数据拟合过程的精度，通常小于 0.01。
Order order - 所得 3D 曲线的样条阶数。曲线类型（Bzier 或 NURBS）继承自空间曲线。但阶数不继承，因为样条阶数对拟合质量提供了有用的控制。如果轮廓是多边形，空间曲线将是 NURBS 曲线。
Preserve Sharp Corners csharp - 控制轮廓曲线中尖角的插值精度。当轮廓存在曲率剧烈变化区域时应打开。
Keep Surface keepsurf - 指定提取后是否移除父级曲面。
Delete Original Profile delprof - 当 Keep Surface 参数为 On 时，选择保留还是删除原轮廓。
Mapping Type maptype - - 选择如何重新定位和缩放现有轮廓，使其适配指定的域范围。这是将不可见轮廓带入视野的好方法：把 U 和 V 参数方向的映射范围设为 0 到 1。映射到单位域之外的轮廓会变为不可见，但不会从曲面上移除。其他更改轮廓的方式可通过 Primitive SOP 获得。
  • Uniform unif - Uniform 将轮廓的空间坐标转换为曲面域中的 (U,V) 点，不考虑曲面的参数化。
  • Chord Length chordlen - Chord Length 会考虑曲面参数化，并尝试计算最适合模型空间与参数决定因素的轮廓。
U Range urange - - 以百分比表示 U 曲面域中映射区域所占的部分。完整范围 0-1 会使轮廓映射到 U 参数方向的整个域。该范围不限于 0-1 区间。

  • urange2 -
V Range vrange - - 以百分比表示 V 曲面域中映射区域所占的部分。完整范围 0-1 会使轮廓映射到 V 参数方向的整个域。该范围不限于 0-1 区间。

Info CHOP 通道

可通过 Info CHOP 访问 Profile SOP 的额外信息。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
