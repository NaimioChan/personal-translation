组件时间

Component 可以在其 local 网络（即 comppath/local/time）中拥有一个 Time COMP，以创建本地 Component Time。该 Time COMP 的参数定义此组件基于时间的属性和 Timeline 设置，例如速率、起点、终点和范围。这对于彼此独立地驱动系统的各个部分，或使用不同的速率、范围或循环设置很有用。

Component Time 会被组件的所有同级继承。在任何网络位置，Timepath 都是沿层级向根向上遍历时找到的第一个 Component Time 的路径。Timepath = / 的 Component Time 称为 Root Time。Tscript 表达式 timepath() 可用来查找任意节点或网络的 Timepath。

要在任意组件中创建 Component Time，右键点击该 COMP 并从弹出菜单中选择 Add Component Time...。一个 Time COMP 会被添加到该组件的 local/time 位置。

当在网络编辑器中查看带 Component Time 的网络时，编辑器窗格底部会显示 mini-timeline。

类似于 Component Variables
