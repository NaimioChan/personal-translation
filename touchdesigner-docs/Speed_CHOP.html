Speed CHOP

摘要

Speed CHOP 在一段时间范围内将速度（单位/秒）转换为距离（单位）。更一般地说，你给它一个速率（CHOP 输入），它输出一个累积值。例如，Speed CHOP 将旋转速率（转/秒）转换为旋转圈数。（数学爱好者会认出这是一个「积分」，即计算曲线下的面积。曲线是某时间范围内的输入通道值，输出是面积。）

如果你向 Speed CHOP 送入一个值为 1 的 Constant CHOP 通道，Speed CHOP 的输出将每秒增加 1。如果送入 -2，它将每秒减少 2；如果送入 0，输出不变。可使用 Trail CHOP 查看其结果。你可以按 Reset 参数，或向第二个输入送入一个（值大于 0 的）通道，将 Speed CHOP 重置为 0。

第一个输入包含要「积分」的通道。默认情况下，Speed CHOP 按时间切片，因此它在每次计算时不断向输出累加/累减。如果关闭其 Time Slice 参数，并向它送入一个具有固定帧范围的 CHOP（如默认的 Noise CHOP），就能看到从 0 开始的累积值。

输出的计算方式是将输入每个采样的通道值相加，除以 Speed CHOP 的 samples per second（通常为 60），从 Start 索引处的采样开始。负的输入值会减少输出，正值会增加输出。累积值放入输出通道。

当 CHOP 被重置时，其输出可通过 Reset Value 参数设为任意值。

当使用第二个输入重置输出时（第二个输入大于 0），面积被重置并保持为重置值。例如，将一个 Wave CHOP（有一半时间为负）送入第二个输入，会使输出在半个周期内被重置。

另请参阅：Lookup CHOP、Timer CHOP、Count CHOP、Event CHOP

参数 - Speed 页

Order order - 决定所用积分的阶数。如果输入是速度，一阶积分将返回位置。如果输入是加速度，二阶积分将返回位置，一阶积分将返回速度。
  • First first -
  • Second second -
  • Third third -
Speed speed - 允许在没有连接输入时生成值。一旦有输入连接到 Speed CHOP，此参数就会被禁用。
First Constant constant1 - 积分一次后加到整个结果上的常量。
Second Constant constant2 - 积分两次后加到整个结果上的常量。
Third Constant constant3 - 积分三次后加到整个结果上的常量。
Limit Type limittype - 从菜单中选择 loop、clamp 或 zigzag 等限制选项。值将保持在 Min 到小于 Max 的范围内。
  • Off off - 不限制数值。
  • Clamp clamp - 若通道值超出 Maximum/Minimum 范围，就直接截断，用 Maximum 或 Minimum 限制值替代。
  • Loop loop - 通道在区间的另一端继续。
  • Zigzag zigzag - 将数值镜像回区间内。
Minimum min - 输出通道可以具有的最小值。
Maximum max - 输出通道可以具有的最大值。
Speed per Sample speedsamples - 将速度应用于通道的每个采样，而不是整个通道。适用于处理多采样通道。
Reset Condition resetcondition - - 此菜单决定 Reset 输入如何触发通道重置。
  • Off to On offtoon - 当 Reset 输入由关变开时重置通道。
  • While On on - 当 Reset 输入为开时重置通道。通道将保持重置值，直到输入变为关。
  • On to Off ontooff - 当 Reset 输入由开变关时重置通道。
  • While Off off - 当 Reset 输入为关时重置通道。通道将保持重置值，直到输入变为开。
Reset Value resetvalue - 重置时，通道被设为该值。
Reset reset - 开启时，此开关将通道重置为 Reset Value。
  • Reset reset -
  • Reset Pulse resetpulse -
Reset on Start resetonstart - 开启时，每次重新启动 .toe 文件时 Speed CHOP 都会重置。如果 Speed CHOP 的值变得过大，当达到 CHOP 数值分辨率极限时可能会开始跳变。这对长时间运行的项目很有用，重新启动文件即可重置该值。
Reset Pulse resetpulse - 点击立即将通道重置为 Reset Value。
Reset On Start resetonstart - 开启时，每次重新启动 .toe 文件时 Speed CHOP 都会重置。如果 Speed CHOP 的值变得过大，当达到 CHOP 数值分辨率极限时可能会开始跳变。这对长时间运行的项目很有用，重新启动文件即可重置该值。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Speed CHOP的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
