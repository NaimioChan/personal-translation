Text POP

摘要

Text POP 用系统上安装的任意 TrueType 或 OpenType 字体，或磁盘上任意 TrueType/OpenType 字体文件创建几何。支持 Unicode。

Text POP 支持两种连接模式：Triangles 和 Line Strips。Triangle 模式可启用挤出。Text POP 上有 3 个图元属性。CpIndex 和 GlyphIndex 与 Text SOP 相同，是输入文本中的索引。这两个字段分开，是为了处理多个码点由单个字形表示的情况。GlyphId 表示与每个「字符」关联的唯一 id。

Line Strips 为每个多边形创建一条闭合线段。开启 Bridge Holes 后，若某个字形有孔洞，这些多边形会被桥接起来，形成单条闭合线段。

Process multiple strings transformed separately：Specification DAT 和 Specification CHOP 允许各个字符串在 3D 中各自独立定位和设置样式。规范操作符中的每一行都是一个独立的文本块，有自己的对齐方式。

Spec DAT 的每一行代表一个「文本块」。每个 Spec DAT 都包含名为 text 的列，其中的字符串会覆盖 Text 参数。

大多数列会覆盖某个 Text POP 参数，例如 text、tx 和 fontsize。下面列出的部分列名没有对应的参数。

Spec CHOP 也可以按块指定值。使用 Spec CHOP 时，其采样数必须与 Spec DAT 中第一个列标题之后的行数相同。

可被覆盖的参数有 tx、ty、tz、rx、ry、rz、sx、sy、sz、px、py、pz、tracking、trackingx、trackingy、linespacing、wordwrap、wordwrapsize、fontsize、fontsizex、fontsizey、fontcolorr、fontcolorg、fontcolorb、fontcolora、text、alignx 和 aligny。

tracking 和 fontsize 分别与 trackingx 和 fontsizex 相同。

text、alignx 和 aligny 只能通过 Table DAT 指定。

要在文本字符串格式中加入换行或制表符，请把 Text 参数切换为表达式模式，并分别使用 \n 和 \t。例如 'first\nsecond' 会把这两个词放在不同行。

Transforming text blocks：列名或通道名可以包含 tx、ty、tz 以及所有旋转和缩放通道（这些使用 Transform Order 参数）。

当 append 为 1 时，可以使用名为 append 的特殊列/通道，把一个文本块相对于前一个块的末尾定位。常规变换会被每个追加的文本块继承。

局部变换（ltx、lrz 等）可用于给块应用额外的变换，这些变换不会被追加的块继承。如果特殊列/通道 localxform 设为 'pre'，则局部变换会在世界空间中先行应用，然后再应用继承的变换。

Text POP vs Geo Text COMP vs Text COMP vs Text TOP - Text POP 创建线段轮廓和三角形，作为 3D 数据存在，可在 POP 中进一步操作。Geo Text COMP 在配合 Render TOP 渲染时直接生成像素，不转换为 POP 或 3D 轮廓形式——它们像纹理贴图一样直接渲染在 3D 场景中的四边形多边形上。Text COMP 在 2D 面板中做类似的事——字符串直接渲染到面板像素中，而 Text COMP 与其他面板 COMP 一样可交互。Text TOP 则用同样的方式把像素直接渲染成 TOP 图像。

注意：Text POP 的大部分工作在 CPU 上完成。

另请参阅：Text TOP、Text COMP、Geo Text COMP、Unicode、Triangulate POP、Extrude POP。

参数 - Text 页

Connectivity connectivity - - 决定用于连接各点的图元。
  • Triangles triangles -
  • Line Strips linestrips -
Bridge Holes bridgeholes - 为带孔洞的字形桥接内部与外部线段之间的孔洞。仅 Line Strips 可用。
Mode mode - - 控制内容取自 Text 参数，还是取自 Specification DAT/CHOP。
  • Text text -
  • Specification DAT/CHOP specdat -
Text text - 要创建为几何的文本字符串。如果需要换行或制表符，请把此参数改为表达式模式，并指定包含 \n 或 \t 的 Python 字符串来表示换行和制表符。例如 'First Line\nSecond Line'。
Specification DAT specdat - 在 Specification 模式下作为文本数据来源的 Table DAT 路径。该表格的第一行应有 2 或 3 列，标为 tx、ty、tx 和 text。其后的每一行都会在给定的 x、y 坐标处显示一行文本，坐标从左下角量起。x 和 y 以 POP 空间单位计。
Specification CHOP specchop - 在 Specification 模式下可提供数值数据的 CHOP 路径。名为 tx、ty 或 tz 的通道可用于定位 Specification DAT 中指定的文本数据。DAT 中的每一数据行都应在 CHOP 中有对应的采样。
Scale Font to BBox Height scalefonttobboxheight - 缩放字体的垂直尺寸，使其基于字体的垂直边界框。
Break Language breaklang - 语言类型提示，帮助正确格式化字形。应为 Text TOP/SOP Unicode Language Abbreviations 表中的缩写。
Reading Direction readingdirection - - 用于设置语言是从左到右阅读，还是从右到左阅读。
  • Left To Right lefttoright -
  • Right To Left righttoleft -
Word Wrap wordwrap - 勾选后，当文本占用下面 Word Wrap Size 参数设定的空间时自动换行。
Word Wrap Size wordwrapsize - 决定换行前使用的 3D 空间量。
Smart Punctuation smartpunct - 启用智能标点。例如，成对的引号会被替换为合适的弯引号，3 个句点会替换为省略号字符，两个连字符会变成破折号。
Level of Detail levelofdetail - 通过给几何添加/移除细分来控制文本形状的质量。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。
Parameter Color Space parmcolorspace - - 控制如何解释此节点上的所有颜色参数。仅在项目启用了 Working Color Space 时可用。颜色值被视为处于所选色彩空间中，并在作为节点运算的一部分使用之前转换为 Working Color Space。注意这不会改变节点自身的色彩空间，因为它始终处于 Working Color Space。
  • sRGB srgb - sRGB 色彩空间，使用 sRGB 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • sRGB - Linear srgblinear - sRGB 色彩空间，使用线性传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.601 (NTSC) rec601ntsc - Rec.601，NTSC 原色色彩空间，使用 Rec.601 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.709 rec709 - Rec.709 色彩空间，使用 Rec.709（与 Rec.2020 相同）传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.2020 rec2020 - Rec.2020 色彩空间，使用 Rec.2020（与 Rec.709 相同）传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 dcip3 - DCI-P3 色彩空间，D65 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 (D60) dcip3d60 - DCI-P3 "D60 sim" 色彩空间，D60 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Display-P3 (D65) displayp3d65 - Display-P3 色彩空间，D65 白点，sRGB gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACES2065-1 aces2065-1 - ACES 2065-1（也称为 ACES AP0）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACEScg acescg - ACEScg（也称为 ACES AP1）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Passthrough passthrough - 选中后，颜色值将按原样用于运算，不作任何修改，也不尝试将其转换到 Working Color Space。
Parameter Reference White parmreferencewhite - - 在将参数颜色值转换为 Working Color Space 时，此项控制相对于 Reference White 应如何处理。如果 Working Color Space 的 Reference White 相同，则不做调整。如果不同，则此颜色的 Reference White 级别（亮度）将被调整到 Working Color Space 所期望的范围。例如，如果项目将 SDR Reference White 设为 120 nits，而 HDR Reference White 为 80 nits，那么 (1, 1, 1) 的颜色在 SDR 色彩空间中为 120 nits，将被转换为 (1.5, 1.5, 1.5)，在 HDR Working Color Space 中仍为 120 nits。
  • Default For Color Space default - 将根据所选的色彩空间使用 SDR 或 HDR Reference White。
  • Use Parent Panel useparent - 将使用父级面板所选的 Reference White。如果顶层面板也选择了「Use Parent」，则将使用「UI Reference White」。
  • Standard (SDR) sdr - 会将 Parameter Color Space 的 Reference White 值按 SDR 处理。
  • High (HDR) hdr - 会将 Parameter Color Space 的 Reference White 值按 HDR 处理。
  • UI ui - 会将 Parameter Color Space 的 Reference White 值按 UI 处理。其亮度使用「UI Reference White Nits」的值。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
