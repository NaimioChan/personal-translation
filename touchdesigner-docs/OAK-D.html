OAK-D

来自 Luxonis 的 OAK-D 摄像机提供一系列带深度视觉和片上机器学习的高分辨率摄像机。

OAK 摄像机在设备端完成计算机视觉任务，并把处理后的图像或数据发送到 Windows 和 macOS 上的 TouchDesigner。例如，OAK 摄像机可以为实时 RGB 图像计算人体骨骼地标，并把地标和图像一起发送到 TouchDesigner。OAK 是 OpenCV AI Kit 的缩写，源自线上众筹。Luxonis 扩展了 OAK 硬件产品线，还发布了多个在 OAK 上运行的开源库，例如 DepthAI。

三种操作符类型协同实现 OAK 功能：OAK Device CHOP 是与摄像机设备交互的主要接口。OAK Select CHOP 从 OAK Device CHOP 的摄像机结果中提取通道和字典数据。OAK Select TOP 从摄像机中提取处理后的图像。每台摄像机上运行的每个 DepthAI 模型都会有一个 OAK Device CHOP，外加一个或多个 OAK Select OP。

将 TouchDesigner 与 OAK 摄像机集成的目的，是在与 TouchDesigner 环境其余部分实现新颖交互的同时，借助 OAK 硬件提供低延迟、高吞吐的性能，并把部分计算卸载到外部设备。

注意：如果你发现不涉及 TouchDesigner 的纯 Python DepthAI / OpenCV 示例比涉及的示例运行得更快，请告知 Derivative。例如，Derivative 的目标是让在 TouchDesigner 中接收的 OAK RGB 摄像机每秒帧数至少与在纯 Python 中用 DepthAI 和 OpenCV 接收的一样快。

OAK-D 是开源硬件设计。

注意：截至 2024 年夏季，支持深度模型的飞行时间（Time-of-Flight）版本摄像机正在开发中。

安装

安装 TouchDesigner 时必须选择 OAK-D。无需其他安装步骤。TouchDesigner 的安装包含 depthai Python 模块，作为 third-party package。为简化起见，请不要把 depthai 安装到任何自定义 Python 环境中，即使这些环境并未与 TouchDesigner 一起使用。

模型在首次使用时会下载一次。

用法

示例文件为 OAKExamples.toe。说明和提示在该文件内。该文件位于 C:/Program Files/Derivative/TouchDesigner.2023.xxxxx/Samples/OAK。

注意： 要使用此文件，请将其复制到常规程序位置之外的文件夹，例如你的用户文档或桌面。

默认情况下，模型会视其来源下载到 %USER%/.cache/blobconverter 或 %USER%/.cache/TDFileDownloader。

疑难解答

如果你在使用 depthai 示例时遇到问题，可以考虑按以下步骤操作，以帮助 Derivative 修复该问题。

  1. 确认所用的 depthai Python 模块来自 TouchDesigner 的 site-packages 文件夹。在 DAT 中运行此脚本
    import depthai as dai
print('depthai version:', dai.__version__)
print('depthai location:', dai.__file__)
    打印出的位置应在 TouchDesigner 的 site-packages 文件夹内，而不是自定义 Python 环境。
  2. 把问题隔离到最小案例。删除复现该问题不需要的任何 TouchDesigner 节点。
  3. 设置以下系统环境变量。将 DEPTHAI_LEVEL 设为 debug。同时将 TOUCH_TEXT_CONSOLE 设为 1。
  4. 打开有问题的 TouchDesigner 项目，然后按 alt-c 打开控制台。在观察控制台输出的同时，按能导致该问题的步骤操作。分享必要步骤的详细说明和控制台输出。

以太网供电

有些 OAK 摄像机通过 USB 连接，另一些通过以太网供电（PoE）连接。PoE 可用的距离比 USB 线缆更长，但延迟会更高。在短距离下，USB3 仍然比 PoE 更快。如果你在使用 PoE 示例时遇到问题，请尝试减少通过网络交换的信息量。例如，可以降低摄像机的 FPS、使用更小的 RGB/单色分辨率，或使用 (1,1) 以外的 ISP 缩放。

PoE 版本的入门与安装指南位于 Luxonis 网站的帮助页面：https://docs.luxonis.com/projects/hardware/en/latest/pages/guides/getting-started-with-poe/
