Insert DAT

摘要

Insert DAT 让你向现有表格插入一行或一列。

你可以添加将以空格分隔放入新单元格的字符串。如果你希望某个单元格包含空格，在 Contents 参数中把单元格内容放在引号内：cell1 'cell 2' cell3。或在参数表达式中使用列表：['cell1', 'cell 2']

如果输入 DAT 不是表格，它会被转换为表格。

参数 - Insert 页

Insert insert - - 指定要插入什么。
  • Row row - 插入一行。
  • Column col - 插入一列。
At at - - 指定插入位置。
  • Before First start - 在开头插入。
  • After Last end - 追加到末尾。
  • Index index - 在指定索引处插入。
Index index - 插入行或列的索引。使用「At」参数中的「After Last」可在表格末尾追加。
Contents contents - 每个单元格的条目以空格分隔。含空格的条目要加引号，例如 Name Species "Home Planet" 会把 Name 放入第一个单元格、Species 放入第二个、Home Planet 放入第三个。多余的条目会被忽略。

Info CHOP 通道

Insert DAT 的额外信息可通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
