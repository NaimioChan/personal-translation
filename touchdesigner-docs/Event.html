事件

Events 是 TouchDesigner 中单一时刻发生的实例，由各种条件产生——用户引起的输入操作、外部设备和软件，以及由计时器和数值越过阈值等引起的 TouchDesigner 内部状态。

各种操作符（大多是 DAT）会响应事件。每个操作符都在某个 DAT 中有 python 回调函数，使用户可以编写代码来响应事件。

TouchDesigner 是一个基于 Procedural 的拉取式系统（输出到显示器、音频设备和其他目标的操作符会计算它生成输出所需的节点）。但它同时也是一个基于响应事件的操作符的推送式系统。

事件操作符通过其 python 回调函数响应收到的事件。回调可以通过参数、表格单元格、扩展属性、storage 使其他操作符发生变化并计算。

响应事件的操作符

响应事件的操作符包括：

响应 TouchDesigner 内部变化的各组 "Execute" DAT：

  • CHOP Execute DAT
  • Parameter Execute DAT
  • DAT Execute DAT
  • Execute DAT
  • OP Execute DAT
  • OP Find DAT

响应用户界面交互的 DAT：

  • Panel Execute DAT
  • Render Pick DAT, Render Pick CHOP, Multi Touch In DAT
  • Keyboard In DAT

响应外部事件的操作符：

  • MIDI In DAT, MIDI Event DAT
  • OSC In DAT
  • Serial DAT
  • TCP/IP DAT
  • WebSocket DAT
  • Web Client DAT
  • Web Server DAT
  • UDP In DAT
  • Art-Net DAT
  • Folder DAT
  • Monitors DAT
  • MQTT Client DAT

在某些参数被脉冲时运行脚本的操作符：

  • Timer CHOP
  • Event CHOP

以及响应事件脉冲的操作符：

  • Trigger CHOP
  • Speed CHOP
  • Count CHOP
  • 众多响应 Initialize and Start 脉冲的操作符。

OP Find DAT 和 Folder DAT 等操作符具有在条件变化时被调用的回调。回调随后可以更改参数，进而使节点计算。

操作符的 Pulse 类型参数可以使用 OP.par.parname.pulse() 脉冲。自定义 Pulse 类型参数可以触发 Parameter Execute DAT 中的脉冲回调。

脚本运行的其他原因

Script 操作符（Script CHOP、Script DAT、Script TOP、Script SOP）不是事件节点——它们属于拉取系统，当 TouchDesigner 判定它依赖 TouchDesigner 中的其他数据（通道、参数、表格单元格、扩展属性、storage）时就会计算。

当事件操作符更改参数或其他数据时，目标节点随后会按照拉取系统的 cooking 规则计算。

注意：你可以通过调用 OP.cook() 强制节点计算。其数据会按照计算规则向下游传递。
