CHOP 入门视频笔记

导入图像并进行调整

  • 双击 network，按住 shift 依次选择 Movie File In TOP、Level TOP、HSV Adjust TOP，然后松开 shift 再选择 Switch TOP。现在你应当得到 4 个相互 wired 的节点。
  • 选中 Movie File In TOP，在其 Play 页参数下点击 File parameter 旁的加号图标，然后在文件浏览器中选择 butterfly6。
  • 选中 Level TOP，在 Pre 页下把 Black Level parameter 设为 0.2
  • 选中 HSV Adjust TOP，复制粘贴（Ctrl + C、Ctrl + V）该 TOP 两次。把这些新 TOP 的输出连接到 switch1 的输入。
  • 左键点击 Level TOP 的输出，然后左键点击 Switch TOP 的输入，以把 level1 wire 到 switch1 中。
  • 选中第一个 HSV Adjust TOP，在 HSV Tweak 页下把 Hue Offset 参数设为 -25。
  • 把第二个 HSV Adjust TOPs 的 Hue Offset 参数设为 50，第三个 HSV Adjust TOPs 设为 200。

设置 Switch TOP

  • Switch TOP 现在会有四个输入：未编辑的原始图像，以及三张各自带有不同色相偏移的调整后图像。你可以这样测试：点击 Switch TOP，然后向右拖动 Index 参数滑块，看颜色是否变化。Index 参数中的数字代表输入编号。例如第一个输入是色相偏移为 -25 的图像，因为最后 wired 进来的图像是没有任何色相偏移的未编辑图像。
  • 把 Switch TOPs 的 image 参数设为 4。Switch TOPs viewer 中的图像现在应当与 Level TOPs viewer 中的图像相同。
  • 打开 Switch TOP 中的 Blend Inputs 复选框。

设置 CHOPs 来驱动参数

  • 在 network 中双击 TOPs 上方，按住 shift 在 CHOPs 页下选择 LFO CHOP，然后松开 shift 再选择 Math CHOP。
  • CHOPs 是 generators 和 filters。Generators 生成数据，即随时间变化的数值，而 filters 则修改这些数据。例如看看 LFO CHOPs viewer。LFO CHOP 是一个变化的数值（正弦波），从 -1 变到 1 再变回来。频率（数值变化的速度）可以在 CHOP 的 parameters 中编辑。把 Frequency parameter 设为 0.5。同样值得注意的是，在 OP Create Dialog 中，generators 的绿色比 filters 更深。
  • 为了给蝴蝶的颜色做动画，你可以用刚创建的 CHOP channel（在 LFO CHOP 中生成，然后用 Math CHOP 处理）作为 Switch TOP 参数中的数值。问题是 LFO CHOP 中的数值只在 -1 到 1 之间，而 Switch TOP 需要的数值是 0 到 4。
  • 点击 Math CHOP，在 range 页下你会看到 From 和 To 参数。这个参数可以让你把通道值从 -1 到 1 改成 0 到 4，从而匹配 Switch TOP 的 Index parameter。把 From parameter 设为 -1 到 1，To parameter 设为 0 到 4。
  • 要把这个值导出到 TOP，先右键点击 Math CHOP 的输出，然后选择一个 Null CHOP。
  • 激活 Null CHOP 的查看器，把通道拖放到 Switch TOPs 的 Index parameter 上，直到出现一个带箭头的小加号图标再松手。在弹出的菜单中选择 Export CHOP。现在 parameter 应当变成蓝色并不断改变数值。
  • Switch TOPs viewer 中的蝴蝶现在应当会平滑地改变颜色。

把蝴蝶叠加到黑色背景上

  • 右键点击 Switch TOP，选择一个 Over TOP。
  • 双击 Switch TOP 下方的 network，添加一个 Constant TOP。
  • 左键点击 Constant TOPs 的输出，然后左键点击 Over TOPs 的第二个输入，以把 Constant TOP wire 到 Over TOP 中。
  • Over TOPs viewer 现在应当有黑色背景，蝴蝶在其中改变颜色。
  • 右键点击 Over TOPs 的输出，选择一个 Out TOP。

在手动与自动之间切换

  • 右键点击 index 参数并从菜单中选择 Remove Export，以移除到 Switch CHOP 的 index 参数的导出。
  • 右键点击 Math CHOPs 的输出，按住 shift 选择 Switch CHOP，然后松开 shift 选择 Null CHOP。
  • 双击 Math CHOP 下方，选择一个 Constant CHOP。
  • 选中 Constant CHOPs 的输出，把它 wire 到 [[Switch CHOP] 的输入中。
  • 选中你与 Switch CHOP 一起创建的 Null CHOP，像之前那样把 Null CHOP 导出到 Switch TOPs 的 index 参数。
  • 你的 Switch CHOP 现在可以在两个值之间切换：不断变化的 LFO 值，以及你可以在 Constant CHOPs parameters 中设置的 Constant 值。要在两者之间切换，把 Switch CHOPs 的 Index parameter 改为 0 或 1。

创建一个 Button COMP 来在手动与自动之间切换

  • 双击 Switch CHOP 上方的 network，按住 shift，在 COMP 页下选择 Button COMP，然后松开 shift 切换到 CHOP 页，选择 Null CHOP。
  • 右键点击 Null CHOP，同样把这个 Null CHOP 导出，但不是导出到 Switch TOP，而是导出到 Switch CHOP。
  • 从 network 向外缩小，直到看到 Project1。在 Project1 的 Layout 页下，把 Width 改为 400，Height 改为 400。
  • 在屏幕左上角、network 编辑器上方有一个小 ^ 图标。点击它进入 Perform Mode。按 Escape 键关闭 Perform Mode。按下按钮时蝴蝶会变色，再次按下按钮则停止。
