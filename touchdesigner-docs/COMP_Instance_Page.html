COMP Instance 参数页

参数 - Instance 页

Instance 参数页提供创建几何硬件实例的能力。每个实例都有一个 instance ID，可通过 uniform 值传入 MAT 着色器。instance ID 可通过 Render Pick CHOP 获取。顶点着色器中的任何代码都可以根据 instance ID 自定义实例。

实例的属性可以由任何类型 OP 的数据单独驱动。当实例数据由 TOP 提供时，TOP 的 RGBA 通道会分配给实例属性；由 CHOP 提供时，CHOP 的通道会分配给实例属性；由 SOP 提供时，SOP 的属性会分配给实例属性；使用 DAT 时，则是一列分配给实例属性。操作符数据到实例属性的映射在下方参数以及 Instance 2 和 Instance 3 参数页上设置。

Instancing instancing - 为 Geometry Component 开启实例化。
Instance Count Mode instancecountmode - 用于确定创建多少个实例的两种模式。
  • Manual manual - 使用下方的 Num Instances 参数设置实例数量。
  • Instance OP(s) Length oplength - Instance CHOP／DAT 中的 CHOP 采样数／DAT 行数决定实例数量。
Num Instances numinstances - 当 Instance Count 使用 Manual 模式时，此参数设置实例数量。
Default Instance OP instanceop - 指定用于变换实例的 CHOP 或 DAT 路径。当 Instance Count 使用 CHOP Length／DAT Num Rows 模式时，此 CHOP 或 DAT 中的采样数／行数决定实例数量。
First Row is instancefirstrow - 当使用 DAT 行作为 Instance Count 时，如何处理 table DAT 的第一行。
  • Ignored ignored - 第一行被忽略，其值不会作为实例的一部分使用。必须使用索引来选择用于实例属性的列。
  • Names names - 第一行包含列名，可用于选择要从表中使用哪些列。
  • Values values - 第一行被视为包含第一个实例的值。必须使用索引来选择用于实例属性的列。
Transform Order instxord - 控制变换操作应用到每个实例的顺序。详情请参阅 Xform 页的文档。
  • Scale Rotate Translate srt -
  • Scale Translate Rotate str -
  • Rotate Scale Translate rst -
  • Rotate Translate Scale rts -
  • Translate Scale Rotate tsr -
  • Translate Rotate Scale trs -
Rotate Order instrord - 点击此选项时出现的旋转矩阵，可用于设置组件旋转的变换顺序。与上面的变换顺序一样，更改组件旋转的发生顺序会改变组件的最终位置。
  • Rx Ry Rz xyz -
  • Rx Rz Ry xzy -
  • Ry Rx Rz yxz -
  • Ry Rz Rx yzx -
  • Rz Rx Ry zxy -
  • Rz Ry Rx zyx -
Translate OP instancetop - 选择特定操作符，为下方的 Translate 实例属性提供数据。若未指定，则可使用 Instance 参数页上「Default Instance OP」指定的操作符。
Active instanceactive - 选择用于控制哪些实例被渲染的数据通道。只有该通道值非零的实例才会被渲染；active 通道值为零的实例会被跳过。若未给此通道分配数据，则所有实例都会被渲染。使用右侧的下拉菜单可从可用选项中方便地选择。
Translate X instancetx - 选择用于平移实例的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
Translate Y instancety - 选择用于平移实例的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
Translate Z instancetz - 选择用于平移实例的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
Rotate OP instancerop - 选择特定操作符，为下方的 Rotate 实例属性提供数据。若未指定，则可使用 Instance 参数页上「Default Instance OP」指定的操作符。
Rotate X instancerx - 选择用于旋转实例的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
Rotate Y instancery - 选择用于旋转实例的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
Rotate Z instancerz - 选择用于旋转实例的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
Scale OP instancesop - 选择特定操作符，为下方的 Scale 实例属性提供数据。若未指定，则可使用 Instance 参数页上「Default Instance OP」指定的操作符。
Scale X instancesx - 选择用于缩放实例的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
Scale Y instancesy - 选择用于缩放实例的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
Scale Z instancesz - 选择用于缩放实例的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
Pivot OP instancepop - 选择特定操作符，为下方的 Pivot 实例属性提供数据。若未指定，则可使用 Instance 参数页上「Default Instance OP」指定的操作符。
Pivot X instancepx - 选择用于实例轴心点的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
Pivot Y instancepy - 选择用于实例轴心点的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
Pivot Z instancepz - 选择用于实例轴心点的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
