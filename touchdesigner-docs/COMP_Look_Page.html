COMP Look 参数页

参数 - Look 页

Color 参数页设置面板的背景色、边框色和禁用色。

Background Color bgcolor - - 背景的 RGB 值。（默认：黑色 (0,0,0)）
  • Red bgcolorr -
  • Green bgcolorg -
  • Blue bgcolorb -
Background Alpha bgalpha - 设置背景的 alpha 值。
Background TOP top - 允许指定一个 TOP 作为面板的背景。
TOP Fill topfill - - 此菜单指定 Background TOP 填充面板背景的方式。
  • Stretch off -
  • Fill Width horizontal -
  • Fill Height vertical -
  • Fill Best best -
  • Native Resolution native -
  • Fill Outside outside -
TOP Smoothness topsmoothness - - 此菜单控制 background TOP 的查看器平滑设置。在以前版本的 TouchDesigner 中，此项始终为「Mipmap Pixels」，因此旧文件会以此设置加载，而新 Panel COMP 的默认值为「Interpolate Pixels」。
  • Nearest Pixel nearest - 使用最近像素或精确图像表示。在任何非 Native Resolution 的缩放级别查看时，图像会显得有锯齿。
  • Interpolate Pixels linear - 在像素之间使用线性过滤。用于让查看器中的 TOP 图像在各种缩放级别下都好看，在使用除 Native Resolution 以外的任何 Fill Viewer 设置时尤其有用。
  • Mipmap Pixels mipmap - 缩放图像时使用 mipmap 过滤。这可以减少细节丰富的运动/缩放图像中的伪影和闪烁。当输入为 32 位浮点格式时，只使用最近邻过滤（无论选择什么）。
Border A bordera - - border A 颜色的 RGB 值。
  • Red borderar -
  • Green borderag -
  • Blue borderab -
Border A Alpha borderaalpha - border A 颜色的 Alpha 值。
Border B borderb - - border B 颜色的 RGBA 值。
  • Red borderbr -
  • Green borderbg -
  • Blue borderbb -
Border B Alpha borderbalpha - border B 颜色的 Alpha 值。
Left Border leftborder - 最左侧 2 个像素的颜色。选项为 0（不变）、Border A（使用 Border A 中定义的颜色）或 Border B（使用 Border B 中定义的颜色）。
Left Border Inside leftborderi - 与上一参数相同，但用于内侧边框。
Right Border rightborder - 最右侧 2 个像素的颜色。选项为 0（不变）、Border A（使用 Border A 中定义的颜色）或 Border B（使用 Border B 中定义的颜色）。
Right Border Inside rightborderi - 与上一参数相同，但用于内侧边框。
Bottom Border bottomborder - 最底部 2 个像素的颜色。选项为 0（不变）、Border A（使用 Border A 中定义的颜色）或 Border B（使用 Border B 中定义的颜色）。
Bottom Border Inside bottomborderi - 与上一参数相同，但用于内侧边框。
Top Border topborder - 最顶部 2 个像素的颜色。选项为 0（不变）、Border A（使用 Border A 中定义的颜色）或 Border B（使用 Border B 中定义的颜色）。
Top Border Inside topborderi - 与上一参数相同，但用于内侧边框。
Border Over Children borderover - 在所有子级面板之上绘制面板的边框。
Disable Color dodisablecolor - 启用在面板 Enable = Off 时使用下方单独的禁用颜色。
Disable Color disablecolor - - 禁用颜色的 RGB 值。（默认：黑色 (0,0,0)）
  • Red disablecolorr -
  • Green disablecolorg -
  • Blue disablecolorb -
Disable Alpha disablealpha - 设置禁用颜色的 alpha 值。
Multiply RGB by Alpha multrgb - 将 RGB 通道乘以 alpha 通道。
Composite composite - - 选择面板与其同级面板的合成方式。各种合成方法的说明见 Composite TOP。
  • Over over -
  • Under under -
  • Inside inside -
  • Outside outside -
  • Add add -
  • Subtract subtract -
  • Multiply multiply -
Opacity opacity - 允许你控制面板的透明度。
