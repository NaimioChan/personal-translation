引用

在网络中，节点之间的灰色虚线是一个 Reference（或 Link），表示一个操作符正在从另一个操作符获取数据。

Reference 由以下之一形成

  • 一个 Parameter Reference，即 OP 中作为另一个操作符名称或路径的参数，或
  • 一个 Node Reference，即包含另一个操作符名称或路径的表达式。表达式可以出现在参数中，或出现在 DAT 的 python 脚本中。
  • DAT 单元格引用
  • CHOP 通道引用

当引用位于表达式中时，例如 op('base1/pattern1').par.phase，它指定从中获取值的位置。

当引用是 OP 中的参数时，例如 /project1/pattern1，源 OP 输出的数据会被传递到包含该引用的 OP，或与之共享。例如，如果是对 TOP 的引用，源图像会被用于生成该 OP 的输出。

在某些情况下，作为 OP 引用的参数实际上是对多个 OP 的引用——指向多个 OP 的路径可通过列出它们的路径或使用通配符指定多个 OP 来获得。见 Pattern Matching。

具有引用参数的操作符示例：

  • Select TOP, Select CHOP, Select DAT
  • Render TOP 摄像机、灯光和几何对象的名称
  • Composite TOP
  • Join CHOP
