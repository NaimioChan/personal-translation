Introduction To TOPs Vid

UPDATE: 在这段视频的 13:00 处，教程演示了在 077 版中用 CHOP Exporter 把 CHOP 导出到 TOP 参数。在较新版本的 TouchDesigner 中，CHOP Exporter 已被移除。要导出 CHOP 通道，请按以下说明操作。

  1. 在 CHOP null1 上打开 Viewer Active 标记。
  2. 从 CHOP 查看器中把 chan1 通道拖放到 transform3 TOP 的第一个 Scale 参数（sx）上。
  3. 从弹出对话框中选择 Export CHOP。

关于在较新版本 TouchDesigner 中导出 CHOP 通道的更多帮助，请参阅 CHOP Export。

另请参阅 Introduction to TOPs Vid Notes。
