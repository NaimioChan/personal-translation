三维对象

Object 组件（或 3D Objects）是所有 Components 的子 Family，用于借助 Render TOP 定义并渲染 3D 场景。最常见的对象类型是 Geometry Component，其中包含由 SOPs 定义要渲染的 3D 形状，以及 Camera、Light 和 Null 组件。

共有十六种 3D Object 组件类型，位于 OP Create 菜单 Components 页的左栏：

  • Ambient Light COMP
  • Blend COMP
  • Bone COMP
  • Camera COMP
  • Camera Blend COMP - 多摄像机插值
  • Environment Light COMP - 来自场景周围球形环境的光源，参与反射
  • Geometry COMP - 容纳被渲染的 SOPs
  • Geo Text COMP - 3D 文字
  • Handle COMP
  • Light COMP
  • Null COMP - 仅用于在层级中变换 3D 对象
  • Nvidia Flow Emitter COMP - 为 Nvidia Flow TOP 发射流体
  • Shared Mem Out COMP, Shared Mem In COMP
  • FBX COMP - 从 .fbx 文件导入几何、运动、纹理
  • USD COMP - 从 .usd 和 .usdc 文件导入几何、运动、纹理

「Object Space」指相对于某个对象的几何（SOP 中的点以及其他 3D 对象），例如 SOP 中的一个点相对于摄像机的位置。为此，Object Merge SOP 和 Object CHOP 很有用。「Object Space 中的点」是以某个 3D 对象原点为参照系表示的 XYZ 位置。

Python 对象

另外，「Objects」一词也用于 TouchDesigner 中 Python 脚本的语境。
