隐私

TouchDesigner 组件（.tox 文件）或项目（.toe 文件）的保密性是对网络的保护，使其可以被使用但不可见、不可编辑。

保密功能可以限制对整个 .toe TouchDesigner Environment 文件的访问，或对单个 Component .tox 文件的访问。设置保密功能需要 TouchDesigner Pro 许可证，设置之后所有许可证类型都会遵守项目或组件的保密设置。也就是说，最终用户无需 Pro 许可证即可运行 Private 的 .toe 文件或 Private 组件。Non-Commercial/Commercial/Educational/Pro Designer/Player 均可使用 Private 的 .toe 文件，只要它未使用其许可证不支持的功能。

你可以在 Perform Mode 中启动项目而不使用保密功能（也无需 Pro 许可证），方法是通过 Dialogs → Window Placement 对话框。但没有保密功能时，在 TouchDesigner 中按 Esc 会进入 Designer Mode，那里网络可见且可编辑。

项目保密

Project Privacy 选项阻止编辑 .toe 项目文件中的网络。这将保护 .toe 文件的内容。

在 TouchDesigner 中，File -> Project Privacy...(Pro Only) 下提供了为 toe 文件添加或移除保密的选项。启动以保密方式保存的 .toe 时只会以 Perform Mode 打开，无法访问网络。要再次访问网络，请在 Perform 窗口上按 Shift+Esc 键，系统会提示输入密码。

下次进入 perform 模式时保密功能会重新激活。也就是说，每次退出演出模式后都必须重新输入密码。

进入网络后，再次使用 File -> Project Privacy...(Pro Only) 即可根据需要永久移除保密。


要隐藏嵌入文件中的图像、影片、音频及其他媒体，请使用 Virtual File System。

组件保密

组件保密阻止访问组件的内容。用户或其他操作符和脚本无法查看或访问这些内容。可以用密码或 CodeMeter 加密狗设置组件保密。

注意： 在允许用户向受保密保护的组件中加载任意组件时，这些加载的组件可以完全访问宿主受保护组件的架构和内容。

使用密码的组件保密

右键单击任意组件并选择 Privacy... 会打开对话框，提示输入密码以启用组件保密。这将阻止访问组件内容，但组件会正常运行。

在已启用保密的组件上右键 → Privacy...，对话框会提示用户输入密码以获得临时访问权。这会在本次会话剩余时间内允许访问该组件，但重新启动项目后会恢复保密。

对临时访问的组件（如上所述）右键 → Privacy...，会提供再次恢复保密的选项。这样无需重启文件即可测试组件是否已保密。此处的另一个选项是再次提供密码，以彻底移除该组件的保密。这会删除保密，组件在设置新密码之前不再保密。

使用 CodeMeter 加密狗的组件保密

组件保密也可以锁定到 CodeMeter dongles。

现在可以设置 CodeMeter 加密狗，为组件运行（计算）授权。这些加密狗不提供对内部网络的访问权，只是允许它们在任何已授权的 TouchDesigner 或 TouchPlayer 电脑上运行。如果加密狗不存在，组件将不会 cook。这为你提供了一种自定义和管理所创建组件授权的方式，同时保持内部网络私密。使用这种组件加密狗保密需要 Pro 许可证进行设置，但 Derivative 不收取额外费用。设置了加密狗保密的组件，在插入相应加密狗时，可在所有许可证类型的 TouchDesigner 和 TouchPlayer 上运行。

使用 CodeMeter 加密狗组件保密的步骤

1) 首先需要从 CodeMeter 获取 Firm Security Box（FSB）加密狗和 FirmCode。这是 CodeMeter 提供的服务/产品，由开发者与 CodeMeter 之间处理。在你与 CodeMeter 建立账户后，他们会向你发放 FSB 和 FirmCode。

2) 获得 FirmCode 后，就可以用你唯一的 FirmCode 设置加密狗，并创建任意数量的 ProductCodes。它们可用于你希望与 ProductCode 关联的不同产品、组件或功能。所有加密狗设置都由 CodeMeter License Editor 完成，它是 CodeMeter Development Kit 的一部分。

3) 现在可以创建 2 种类型的加密狗

  • Developer Dongle - 此加密狗允许访问和编辑私有组件，供组件的作者使用。要创建它，必须设置 FirmCode、ProductCode，并在该 ProductCode 上额外设置 FeatureMap = 1。设置组件的加密狗保密（也就是将其「锁定」）也需要这个开发者加密狗。
  • License Dongle - 此加密狗在插入时允许组件在 TouchDesigner 或 TouchPlayer 中运行。但它仍会阻止访问组件内容，因此网络保持私密。要创建它，只需设置 FirmCode 和 ProductCode。

4) 插入 Developer Dongle 后，可通过 python 或 Privacy 对话框（右键单击组件并选择「Privacy...」）为组件设置保密。设置此保密后，访问组件内部的唯一方式是插入具有匹配 FirmCode、ProductCode 且该 ProductCode 的 Feature Map = 1 的 Developer Dongle。运行该组件的唯一方式同样是使用匹配的 Developer Dongle，或使用具有匹配 FirmCode 和 ProductCode 的 License Dongle。

CodeMeter 加密狗可以在同一支加密狗上携带多个 FirmCode 和 ProductCode。因此可以将你自己的组件授权添加到承载 TouchDesigner 或 TouchPlayer Commercial 或 Pro 许可证的同一支加密狗上。

如需了解 Developer Dongle 的更多细节，请联系我们。

保密与许可证

私有的 .toe 或组件不会影响系统上已安装的许可证。它们可在任何许可证（包括 non-commercial）下运行，表现与该许可证下运行非私有文件相同。这意味着，如果文件使用了仅 Pro 可用的节点，这些节点只有在安装了 Pro 许可证时才能工作。如果许可证为 non-commercial，所有 TOP 仍会受分辨率限制。私有文件也可在 TouchPlayer 中运行，限制与 TouchPlayer 运行普通 .toe 文件时相同。如果私有 .toe 文件用于商业（付费）项目，仍需 Commercial 许可证。
