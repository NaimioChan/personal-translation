Filter

在 TouchDesigner 中，需要 1 个或多个输入（才能产生有意义的输出）的操作符称为 Filter，例如 Math CHOP。「输入」既指来自其他操作符的连线，也指 OP 参数中对其他操作符的引用。

Filter 是 OP Create Dialog 中颜色较浅的操作符。

参见它们的对应物 Generators。

操作符可以有由 Parameters 定义的输入，这些输入是对其他操作符的 Path 引用，可来自任何 Operator Family。
