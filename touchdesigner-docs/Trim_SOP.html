Trim SOP

摘要

Trim SOP 会剪掉样条曲面的部分区域，或撤销先前剪掉的部分。当曲面的一部分被修剪时，它实际上并未从曲面上移除，而是被设为不可见。这意味着你仍可以修改曲面上未显示的部分（例如修改其点的位置），从而影响显示出来的部分。

可以通过将开放或闭合的轮廓指定为内部或外部区域来修剪曲面。这些轮廓不必位于曲面的域（UV 空间）内，也可以相互嵌套。

开放轮廓的处理方式如下：如果轮廓的两端都在曲面内部，则将两端相连；如果轮廓的端点在曲面域之外，则将它们投影到曲面上，该部分曲面看起来会被切掉。

通常你需要在 Project SOP 之后使用 Trim SOP、Bridge SOP 或 Profile SOP。

  • 使用 Trim SOP 在投影曲面上挖一个洞。
  • 使用 Bridge SOP 将轮廓曲线蒙皮到另一条轮廓曲线。
  • 使用 Profile SOP 提取曲面上的曲线，或重映射其位置。

选择方法 - Winding Rule

用于厘清重叠修剪环的选择方法是 winding rule，它执行重叠的命令，而不是让它们相互抵消。

提示： 由于只有包含轮廓曲线的曲面才能被修剪，你总是需要在 Trim SOP 上方链接一个 Project 或 Carve SOP。

参数 - 页

Group group - 此字段允许你指定想要修剪的组。你可以从弹出菜单中选择组，或指定点与图元范围。

你可以通过提供轮廓模式来指定组内的轮廓曲线（例如 *.3 指定所有样条曲面中的第四条轮廓）。

optype - - 可用的修剪操作类型。
  • Keep Outside keepout - 修剪曲线的内部，或在曲面的显示中挖出一个洞。保留轮廓曲线外部的区域会生成一个外部修剪环，以定义要显示的曲面范围——即轮廓曲线之外的曲面。
  • Keep Inside keepin - 保留曲线内部，并移除其他所有部分的显示。
  • Keep Natural keepnatural - 根据轮廓的固有朝向进行修剪，无论其是否开放。逆时针轮廓保留其内部，产生类似 Keep Inside 的结果。顺时针轮廓丢弃其内部，类似 Keep Outside，如果不存在外部修剪环，可能需要显式指定一个。
  • Untrim untrim - 将修剪曲线转变为普通轮廓。
  • Change Altitude chgalt -
Process Profiles Individually individual - 关闭此选项时，组内的修剪环（如果未指定组，则为曲面上的所有环）会一起被视为构成一个区域。它会报告找到的第一个区域。也就是说，如果通过连接线条可以形成多个闭合环，则不保证该区域会被修剪。此外，如果环的组中存在闭合环，则仅使用该环。

如果曲面上的环无法构成闭合环，则 SOP 将尝试利用区域边界来构成区域。如果所有环与边界总共只有两个交点，它将尝试沿边界构成该环。

For example: 使用 Carve SOP 提取四条轮廓：U 方向两条，V 方向两条。将其接入 Trim SOP 并关闭此选项。这四条轮廓将定义一个要修剪的区域。注意轮廓的端点并不重合，轮廓在参数上也不连续，创建顺序也不正确。尽管如此，Trim SOP 仍能找出这个洞。

Build outer Trim-Loop Explicitly bigloop - 此选项允许你指定构建一个外部修剪环。当曲面上有多条轮廓曲线，并且要连续执行多次涉及 Keep Inside 和 Keep Outside 选项的修剪操作时，它会很有用（参见下方示例）。

提示： 第一次在曲面上挖洞时必须生成外部修剪环，但如果你只是保留该洞的内容而丢弃其余部分，则不需要。默认情况下，外部环（绕整个域边界一周）会自动为你构建。但有时你会先执行 Keep Inside，再对不在保留区域内的某个区域执行 Keep Outside，此时你可能需要该外部曲线。这正是此参数的用处。

Trimming Tolerance trimtol - 两条修剪曲线之间，或修剪曲线与面片边缘之间，距离多近才被视为相交。
Altitude altitude - 你可以指定修剪的高度。$ALTITUDE 变量是曲面的当前高度。此值标记曲面从修剪内到修剪外的过渡。

Info CHOP 通道

可通过 Info CHOP 访问 Trim SOP 的额外信息。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
