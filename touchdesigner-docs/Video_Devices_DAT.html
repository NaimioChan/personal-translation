Video Devices DAT

摘要

Video Devices DAT 提供所有检测到的视频设备的信息，包括驱动、方向（输入或输出）、标签和名称，这些信息可在 Video Device In TOP 和 Video Device Out TOP 中引用。

你也可以将其设置为显示所有可用的视频设备。

当检测到视频设备发生变化时，它会运行回调脚本，并返回与变动设备对应的名称列表。

'name' 列是设备的唯一标识符，由几个片段构成。各片段之间以 ||| 作为分隔符，例如

V1|||83514832|||0|||0|||DeckLink 8K Pro (1)

它可拆分为：

Name Version Number ||| Unique Device ID ||| Device Index ||| Device Sub Index ||| Device Label

其中：
Name Version Number - 如果此名称的格式将来发生变化，此项可让未来的版本知道如何解析它。目前它始终为 V1。
Device Unique ID - 在可能的情况下为设备获取的唯一 ID。有时是序列号，有时基于所连接的 PCIe 端口。Blackmagic 等一些厂商会为每个连接器分配不同的 ID，而 AJA 等其他厂商为整块卡分配一个 ID，多出的连接器通过 'Device Sub Index' 字段区分。
Device Index - 设备的索引，按从驱动枚举的顺序。
Device Sub Index - 在一个设备内，连接器可能通过子索引引用，该值会在此处变化。
Device Label - 设备的英文可读标签。通常通过添加额外的 (#) 和 - # 后缀来区分相同的设备，从而保持唯一。

与大多数菜单不同，菜单所设置字符串的内容不必与系统上可用的设备完全匹配。这样做是为了在项目从一台机器迁移到另一台机器时，能够回退到其他设备。 它会先尝试使用 'Device Unique ID' 和 'Device Sub Index' 同时匹配来查找设备。如果系统上没有同时匹配这两者的设备，它会接着尝试使用 'Device Label' 和 'Device Sub Index' 同时匹配。如果仍然没有匹配，最后会尝试使用 'Device Index' 和 'Device Sub Index' 同时匹配。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

Video Devices DAT 的额外信息可通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
