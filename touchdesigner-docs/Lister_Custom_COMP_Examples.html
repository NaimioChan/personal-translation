Lister 自定义 COMP 示例

本页包含如何设置 lister 自定义组件的示例。这些示例假定你具备 TouchDesigner 和 Python 的基础知识。

有关 lister 的完整文档，请参阅：Lister Custom COMP。

示例 1 - File Lister

本例中，我们仅用参数和连线创建一个非常简单的 lister。我们还会在相关操作符中使用几个简单的 Python 表达式。最终结果是一个 lister，可让你选择在 movieFileInDAT 中显示的文件。

创建 lister

要创建 lister，请从 Palette（Derivative>UI 文件夹）中拖一个到你的网络中。

创建输入 DAT

任何表格都可以作为 lister 的输入。本例中，因为要列出文件，我们使用 Folder DAT。在网络中 lister 的左侧创建一个 Folder DAT。把该 DAT 的 Root Folder 参数表达式改为 app.samplesFolder + '/Map'。现在它包含 TouchDesigner 中提供的所有示例地图的列表。把该 DAT 的输出连接到 lister 的输入。右键点击 lister 节点并选择「View...」，打开 lister 的浮动查看器。

排序与选择数据

要让此功能生效，需要更改 lister 上的几个设置。首先，打开 Input Table Has Headers 参数，让 lister 知道表格的顶行是表头。接着，打开 Clickable Header 参数，启用列排序和筛选。

现在可以通过点击列标签对行排序。注意，做这些操作时原来的 Folder DAT 不会改变。该 DAT 只用于创建初始数据。

要选择一行，点击它即可。可以使用 shift 和 ctrl 点击选择多行。若打开 Drag To Reorder Rows 参数，可通过选中并拖动来重排行。

筛选数据

要筛选 lister 的数据，可在其 Filter String 参数中输入字符串。它现在只显示在当前筛选列中包含该字符串的行。要选择筛选列，点击列标签。

使用 lister 控制 movieFileIn TOP

这一步中，你将使用 lister 创建一个非常简单的文件选择器。本例中，先关闭一些功能。在 lister 中关闭以下开关参数：Clickable Header、Multiple Row Select、Drag To Reorder Rows。同时清除你设置的任何 Filter String。lister 的数据现在会保持与原始表格相同。

在网络中创建 Movie File In TOP。把该 TOP 的 File 参数表达式改为

op('folder1')[int(op('lister').par.Selectedrows), 1] if op('lister').par.Selectedrows else ''.

这段小小的 Python 从输入表格中选出与 lister 选中行对应的单元格。选择不同的行即可看到效果。注意： 末尾的 if 子句处理未选中任何行的情况。

示例 2 - Network Lister

本例中，我们将使用 Python 回调和 Column Definition（colDefine）表格创建一个 lister。最终结果是一个 lister，可让你选择 TouchDesigner 根网络中的操作符。

创建 lister

要创建 lister，请从 Palette（Derivative>UI 文件夹）中拖一个到你的网络中。

使用 onGetRawData 回调填充 lister

点击 lister 的 Edit Callbacks 参数，打开其回调 DAT 进行编辑。onGetRawData 回调填充 lister 的行数据。它可以处理多种不同的数据，但此处我们将使用对象列表。具体来说，我们会为每一行用一个 OP 对象填充原始数据。把以下代码放入回调 DAT：

def onGetRawData(info):
	return op('/').children

这将返回根操作符子项的列表。lister 会以列表中的每一项作为一行的基础，此处即一个 TouchDesigner Operator 对象。右键点击其节点并选择「View...」，打开 lister 的浮动查看器。你会看到 autodefine columns 功能已创建一列「objects」，各行中包含每个操作符的字符串表示。下一步是手动定义我们希望在 lister 中出现的列。

编辑 Column Definition 表格

要打开 Column Definition 表格，点击 lister 的 Edit Column Definitions 参数。在此表格中，第一列包含标签，后续列包含 lister 各列的格式信息。把你的表格改成包含以下数据：

要查看这些更改的效果，在 lister 中关闭 Autodefine Columns 参数。它现在使用你刚设置的 colDefine 表格。我们来看看此表格的一些功能……

column 行包含每列的唯一名称。columnLabel 行是将在 lister 表头中显示于该列上方的字符串。Operator 列的 columnLabel 中的「*」表示使用上方的 column 名称。Select 和 Delete 中空的 columnLabels 表示没有列标签。

sourceData 和 sourceDataMode 行定义此列要放入什么数据。lister 基于 OP 对象列表，因此 Operator 列中的 name 表示 lister 将使用每个 OP 的 name 成员（一个字符串），如 sourceDataMode 设置所示。Select 和 Delete 都是 constant sourceDataMode，因此这些行将包含 sourceData 的字面内容。

有关表格中各项设置的更多细节，请参阅 colDefine table。

在 Config COMP 中创建特殊外观

Select 和 Delete 列展示了在 lister 中创建特殊外观的两种方式。注意 Select 列有一个位图按钮，Delete 列有一个颜色不同的文字按钮。试着悬停并点击这些列，以查看更多外观。

在 colDefine 表格中，这些独特的单元格外观在 cellLook 和 topPath 中设置。要查看它们引用什么，点击 lister 的 Edit Config COMP 参数打开 Config COMP。在此 COMP 中，你会找到许多可定制的 lister 功能。其中包含 colDefine 表格、callbacks DAT，以及定义单元格外观的 TOP。button、buttonRoll 和 buttonPress TOP 定义 Delete 列的按钮外观。btnImage、btnImageRoll 和 btnImagePress TOP 定义 Select 列中显示的图像。你可以按此命名约定创建任意数量的自定义单元格外观和图像。

有关通过外观 TOP 可用的各项设置的细节，请参阅 Config TOPs。

编写按钮回调

按钮的功能通过 Python 回调实现。要设置它，打开 lister 的 callbacks DAT。添加以下文本，为 Select 按钮创建点击功能：

def onClickSelect(info):
	op = info['rowData']['rowObject']
	op.current = True

名称 onClick 后接 lister 的列名，即定义了该列点击的回调。info 字典中的 'rowData' 项包含一个 Python Ordered Dict，其中为每一列提供项目，随后是 'rowObject' 项，即作为原始数据提供给 lister 的原始对象。此处 'rowObject' 包含此行的 Operator。把该操作符的 current 成员设为 True，即可在网络中选中该操作符，如同被点击一样。打开根网络并点击 lister 中的 Select 按钮即可看到此效果。由于此列 colDefine 中的 clickOnDrag 设置为开启，你可以在按住鼠标拖动时经过它，从而在拖动过程中选中不同的操作符。

对于 Delete 按钮，输入以下代码以演示另一种做法：

def onClick(info):
	if info['col'] == 2:
		info['ownerComp'].DeleteRows([info['row']])

除了 onClick<columnName> 回调外，还有一个通用的 onClick 回调，在点击任何单元格时调用。为了对 Delete 按钮使用它，必须先通过测试 info['col'] 确认它在该列中。若我们的列是 2，则使用其 DeleteRows 方法从 lister 中删除该行。如你所见，lister 本身存储在 info['ownerComp'] 中。注意，为保证示例安全，Delete 按钮被设置为从 lister 中删除该行，而不是从网络中删除该操作符。

有关可用 lister 回调的完整列表，请参阅：Custom Callbacks。

高级回调与自定义弹出帮助

要添加到 Network Lister 的最后一项功能是显示每个操作符路径的弹出帮助字符串。这需要在 onInitCell 高级回调中设置。这些回调默认关闭，因为它们被调用得更频繁，会略微降低速度，并在 Print Callbacks 参数开启时使 textport 变得杂乱。在 lister 的 Advanced 页上打开 Do Advanced Callbacks 参数以激活它们。然后在 callbacks DAT 中添加以下代码：

def onInitCellOperator(info):
	if info['row'] > 0:
		operator = info['rowData']['rowObject']
		attribs = info['attribs']
		attribs.help = operator.path

这里我们再次使用列回调技术，把 Operator 追加到 onInitCell 回调名后。回调的第一行检查行号是否大于 0，因为表头行也会收到 onInitCell 回调。若不在表头行，我们修改该单元格的 attribs.help 成员以保存操作符路径。有关可在 attribs 中设置的众多内容，请参阅：ListCOMP Class。
