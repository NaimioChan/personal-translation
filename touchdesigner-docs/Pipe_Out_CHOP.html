Pipe Out CHOP

摘要

Pipe Out CHOP 可用于通过网络连接，把数据从 TouchDesigner 传出到远程机器上运行的其他进程。如果对方进程是另一个 TouchDesigner 进程，可以用该进程中的 Pipe In CHOP 来接收数据。多个 PipeIn CHOP 可以连接到一个 PipeOut CHOP。

关于如何用 Pipe In 和 Pipe Out CHOP 连接运行在不同机器上的两个 TouchDesigner 进程，更多信息见 Pipe In CHOP。

注意： 若要在 TouchDesigner 之间传递通道数据，见 Touch In CHOP 和 Touch Out CHOP，它们提供经过优化的 Time Sliced 数据传输。

提示： 通过网络发送脚本命令和其他数据包，首选方式是 TCP/IP DAT 或 UDP Out DAT。

NOTE for Windows OS - If experiencing connection issues make sure Windows Firewall is disabled.

另请参阅 OSC Out CHOP、Shared Mem Out CHOP。

参数 - PipeOut 页

Connection Mode mode - - 把操作设为服务器或客户端。
  • This Operator is Client client -
  • This Operator is Server server -
Server Address address - 服务器电脑的计算机名或 IP 地址。该地址是标准的 WWW 地址，例如「foo」或「foo.bar.com」。你可以使用 IP 地址（例如 100.123.45.78），也可以填电脑的网络名。如果填「localhost」，表示管道的另一端在同一台电脑上。
Server Port port - 要使用的网络端口。
Active active - 为 Off 时不发送数据。
Send Input sendinput - 发送连接到 Pipe Out CHOP 输入的数据的开/关切换。
Send Current Sample Only sendsingle - 只有当 Pipe Out CHOP 未 time sliced 时此参数才可用（见参数 Common 页）。为 On 时，只发送当前帧的采样。为 Off 时，发送本帧与 TouchDesigner 上一次计算的那帧之间的所有数据。当 TouchDesigner 不是每秒计算 60 帧、出现跳帧时，差别就显现出来。如果两次屏幕绘制之间播放跳过了 3 个动画帧，On 的情况只发送一帧数据，Off 的情况发送 3 帧数据（用 TouchDesigner 的话说就是一个「Time Slice」）。
Single Sample sample - - 在单采样模式下，此参数决定发送哪个采样：第 1 帧的采样，还是当前采样。
  • Current Frame scur -
  • Frame 1 sstart -
Send All Data upload - 按下按钮时，一次性突发发送所有通道名及其数据。
Script script - 用这些参数通过管道发送一次性的 textport 命令。
Send Script sendscript - 用这些参数通过管道发送一次性的 textport 命令。
Cook Every Frame cookalways - 打开它可确保此 CHOP 每帧都被处理。通常 CHOP 不会每帧都被处理，除非它与所显示几何的某个方面直接相关。
Send Monitor Pulses pulse - 每帧发送一次脉冲（单个空字符），用于监视连接。这能保持连接活跃，并让 Pipe In CHOP 了解连接状态，从而正确报告其状态。
Echo Messages to Console echo - 把所有传出数据打印到 Console，Console 可从 Dialogs 菜单打开。更多细节参见 Pipe In CHOP 中的这一选项。
Callbacks DAT callbacks - 指向一个 DAT 的路径，其中包含每个发出事件的回调方法。用法见 pipeoutCHOP_Class。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Pipe Out CHOP 的额外信息可通过 Info CHOP 访问。

Pipe Out CHOP 专有的 Info 通道

  • connected -
  • num_connected -
  • num_cached -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
