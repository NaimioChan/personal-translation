Filter 逐采样

像 Lag CHOP 和 Filter CHOP 这样（在时间上）进行滤波的 CHOP，也可以把每个采样当作独立的滤镜。打开它们的 Filter per Sample 参数，每个采样就会像独立的滤镜一样工作。

例如，若有 20 个长度为 100 个采样、全部设为 0 的通道，送入已打开 Filter per Sample 的 Filter CHOP，然后只把输入的某个采样设为 1，则输出的该采样会在一秒内爬升到 1，而其他所有采样保持 0。每个采样都是一个独立的滤镜。

具有此功能的其他 CHOP 有 Hold CHOP、Slope CHOP、Speed CHOP 和 Spring CHOP。
