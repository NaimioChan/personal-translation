Table DAT

摘要

Table DAT 让你手动编辑或创建由行和列组成的单元格表格，每个单元格包含一个文本字符串。「表格」是 DAT 的两种形式之一（另一种是通过 Text DAT 呈现的自由格式文本行）。

Manually editing cells - 当 Table DAT 的 Viewer Active 开启时，可以右键点击第 0 行或第 0 列来添加行/列，并在其 node viewer 的任意单元格中输入文本。用 Tab 键跳到下一个单元格，用上下方向键移到相邻单元格。

Procedurally filling cells - 你可以方便地创建并填充表格的行和列。在 Fill 页，Fill Type 菜单提供 5 个选项：Manual、Set Size、Set Size and Contents、Fill by Column 和 Fill by Row。选择填充选项后，你可以用空格分隔的名称或表达式生成带特定标题的多个行/列，再用表达式填充单元格。

在表达式中可以使用 me.subRow 和 me.subCol（用于正在填充的子区段）。Cell Expression 参数上的弹出菜单会提供建议。

点击参数下方的 +，即可生成多组新的列或行。

Filling cells externally with python - 如果不使用自动填充，可以在其他地方的 python 脚本中用类似 op('table1')[2,'select'] = 'yes' 的方式把字符串放入表格单元格，也可以在 python 中用 .appendRow() 追加行。另请参阅 Script DAT 及其 Snippets。

Loading from external files - Table DAT 还可以从磁盘或网络上的逗号分隔文件 (.csv)、制表符分隔文件 (.tsv) 或 TouchDesigner DAT 文件 (.dat) 加载表格。其他文本文件 (.txt, .py, .glsl, etc) 也能加载，但会被当作制表符分隔文件处理。可以把文件拖放到网络中，或使用 File 参数。

在指定互联网上的表格时，使用 http://。

如果把 Table DAT 拖到桌面或文件夹，DAT 文本会被转换成制表符分隔的表格，写入 .txt 文件。

另请参阅 Script DAT、Text DAT。

参数 - Table 页

Edit.. edit - 单击此按钮会打开文本编辑器，用于添加/编辑/删除 DAT 中的文本。
File file - 要加载的文件在文件系统中的路径与名称。支持逗号分隔的 (.csv)、制表符分隔的 (.tsv) 或 TouchDesigner DAT 文件 (.dat)。其他文本文件格式 (.txt, .py, .glsl, etc) 会被当作制表符分隔文件处理。
Sync to File syncfile - 开启时，在项目启动时将文件从磁盘加载到 DAT 中。必须指定文件名。开启该选项会立即从磁盘加载文件。如果文件不存在，则在 DAT 第一次更新时创建它。系统会监视该文件，对文件的任何改动都会更新 DAT，而对 DAT 的任何改动都会立即写入文件。如果文件被移除，DAT 将保留其当前内容。
Default Read Encoding defaultreadencoding - - 设置预期的文件编码格式，或自动检测格式。 UTF8、UTF16-LE、UTF16-BE、CP1252
  • Auto Detect manual -
  • UTF8 utf8 -
  • UTF16-LE utf16le -
  • UTF16-BE utf16be -
  • CP1252 cp1252 -
Load on Start loadonstart - 开启时，项目启动时从磁盘重新加载文件到 DAT 中。
Write on Toe Save write - 开启时，保存项目时将 DAT 的内容写入磁盘文件。
Remove Blank Lines removeblank - 启用后，加载文件时不会把空白行转换成空行。

参数 - Fill 页

Fill Type fill - - 你可以创建并填充表格的行和列。Fill Type 菜单提供 5 个选项：Manual、Set Size、Set Size and Contents、Fill by Column 和 Fill by Row。选择填充选项后，你可以用空格分隔的名称或表达式生成带特定标题的多个行/列，再用表达式填充单元格。
  • Manual manual - 行和列将由用户手动添加。
  • Set Size setsize - 尺寸将由 Rows 和 Columns 参数设置，但不填充单元格。
  • Set Size and Contents setsizeandcontents - 尺寸将由 Rows 和 Columns 参数设置，单元格则根据 Cell Expression 填充。
  • Fill by Column fillbycol - 行数将由 Rows 参数设置，列的内容由 Names 0 和 Cell Expression 0 参数定义。
  • Fill by Row fillbyrow - 列数将由 Columns 参数设置，行的内容由 Names 0 和 Cell Expression 0 参数定义。
Rows rows - 定义表格中的行数（如适用）。
Columns cols - 定义表格中的列数（如适用）。
Cell Expression cellexpr - 当 Fill Type 为 Set Size and Contents 时，用于填充每个单元格的表达式。可包含表达式 me.subRow 和 me.subCol
Include Names includenames - 在顶部创建额外一行，或在左侧创建额外一列，用于放置列名或行名，由 Include Names 参数填充。
Fills fills - 用于 Fill by Column 和 Fill by Row 填充类型的填充信息序列
Names fills0names - 一个或多个列或行的名称，以空格分隔。如果是表达式，每个名称可以是 python 列表的一个成员，例如 ['heading1', 'heading2']。此参数是一个顺序块的起点。
Cell Expression fills0expr - 当 Fill Type 为 Fill by Row 或 Fill by Column 时，用于填充每个单元格的表达式。可包含表达式 me.subRow 和 me.subCol。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

可以通过 Info CHOP 访问 Table DAT 的额外信息。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
