Color 类

color 类保存单个 4 分量颜色（R、G、B、A）。

注意： tdu.___ 与 TDU.___ 可以互换使用。通常 TDU.___ 用于表示类，而 tdu.___ 用于实例化函数。 

v = tdu.Color() # 初始为 (0, 0, 0, 1)
v2 = tdu.Color(0, 0, 1, 1)
values = [0, 1, 0, 1]
v3 = tdu.Color(values)
green = v3[1] # 按索引访问单个元素。等同于 v3.g

实例化器

TDU.Color(*args)→ TDU.Color:

以下参数形式是有效的实例化方式：

  • tdu.Color() - 完全不透明的黑色 (0, 0, 0, 1)
  • tdu.Color(color : TDU.Color) - 复制参数中的颜色
  • tdu.Color(rgba: list) - 作为颜色的 4 个值的列表 (r, g, b, a)
  • tdu.Color(f: float) - (f, f, f, 1)
  • tdu.Color(r : float, g : float, b : float, a: float) - 把参数分别作为颜色元素

成员

r → float :

获取或设置颜色的红色分量。

g → float :

获取或设置颜色的绿色分量。

b → float :

获取或设置颜色的蓝色分量。

a → float :

获取或设置颜色的 alpha 分量。

方法

[index]→ float:

可以使用 [] 下标操作符从 Color 访问采样值。

copy()→ TDU.Color:

返回该颜色的副本作为一个新颜色。
