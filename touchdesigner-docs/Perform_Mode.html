Perform 模式

Perform Mode 是面向现场演出的优化模式，只渲染一个指定的 Window COMP，即一个包含你的视频输出和（可选的）控制界面的窗口。在 Perform Mode 下不打开网络编辑窗口——你在 Designer Mode 中编辑网络。功能键 F1 与 Esc 键在两个模式之间切换。参见 Edit -> Window Placement 和 /perform。

提示：在 Perform Mode 和 TouchPlayer 中用 Shift-Spacebar 暂停/取消暂停时间轴。

另请参阅 Window COMP、TouchPlayer。

使用执行模式

默认情况下，Window COMP /perform 已在 Edit - Window Placement 中设置为在 Perform Mode 下渲染。

Enter Perform Mode - 点击 Layout 栏左侧的 按钮，或使用 F1 功能键进入 Perform Mode。此时你只能与 Window COMP 中指定的窗口交互。

Exit Perform Mode - 把光标移到执行窗口上，按 Escape 键离开 Perform Mode，回到完整的 TouchDesigner 网络编辑界面。提示：如果 Window COMP 的「Close on Escape Key」参数是关闭的，你可能需要按 Shift-Esc。

配置选项

在 Window Placement Dialog 中，你可以查看项目里所有的 Window COMPs 并对它们进行配置。 列表中第一列叫 Perform Window，用于设置默认使用哪个 Window 组件来做 Perform Mode。它决定了在使用界面上的 Perform Mode 按钮或按 F1 时会打开哪个窗口。

打开窗口的设置（尺寸、位置、行为）全都在 Window COMP 的参数里设定。

启动选项

默认的 TouchDesigner 启动后处于 Designer Mode，你在这里编辑 network、nodes 和 parameters。

在 Window Placement Dialog 中，你可以打开「Start in Perform Mode」，强制 TouchDesigner 为此项目以 Perform Mode 启动。更改此设置后保存项目文件，重新启动时项目就会直接以 Perform Mode 打开。

当 TouchDesigner 以 Perform mode 启动时，不会占用 Designer 界面所需的额外内存。

全屏独占模式（仅 Windows）

某些 GPU 驱动（尤其是 Nvidia）有能力在执行窗口无边框且覆盖桌面 100% 时进入全屏独占模式。此外，桌面可能还需要是「单个」显示器：要么本身就是单路输出，要么通过 Nvidia Mosaic 或 AMD EyeFinity 之类的功能合并为一路组合输出。处于全屏独占模式时，输出会以更高的性能状态运行。最重要的好处是你能获得 stutter-free playback。没有全屏独占模式时，Windows Desktop Compositor 可能不会始终显示 TouchDesigner 生成的所有帧。因此即使你跑着完美的 60FPS，若不在全屏独占模式下，也可能看到卡顿/丢帧。

判断是否处于该模式的方法：如果你 alt-tab 或切换窗口，整个桌面会闪一下/闪烁，因为它切回了普通的桌面合成模式。

提示

TouchPlayer 只以 Perform Mode 运行。项目的 perform mode 设置决定它在 TouchPlayer 中如何运行。

如果项目文件设置了 Privacy 选项，你就无法退出 Perform mode 回到 Designer Mode。

你也可以用 python 进入 Perform Mode：ui.performMode = True。参见 UI_Class。

另请参阅 Designer Mode、Window Placement 和 Window COMP。
