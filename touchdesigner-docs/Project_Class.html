Project 类

Project 类描述当前会话。可通过 project 对象访问，该对象位于自动导入的 td module 中。在其中更改的成员（例如「paths」成员）会在保存项目时写入磁盘。

成员

folder → str (Read Only):

项目所在的文件夹。

name → str (Read Only):

保存项目时使用的文件名。

saveVersion → str (Read Only):

项目上次保存时的 App 版本号。

saveBuild → str (Read Only):

项目上次保存时的 App 构建号。

saveTime → str (Read Only):

项目上次保存的时间和日期。

saveOSName → str (Read Only):

项目上次保存时的 App 操作系统名称。

saveOSVersion → str (Read Only):

项目上次保存时的 App 操作系统版本。

paths → dict (Read Only):

一个字典，可用于定义 URL 语法的路径前缀，让你能轻松地将媒体移动到不同位置。该字典保存在 .toe 文件中，并从中加载。示例：运行 project.paths['movies'] = 'C:/MyMovies'，并用参数表达式引用它：movies://butterfly.jpg。要在展开路径与折叠路径之间手动转换，请使用 tdu.collapsePath() 和 tdu.expandPath，例如 tdu.expandPath('movies://butterfly.jpg') 会展开为 C:/MyMovies/butterfly.jpg。如果你已设置好路径，在 OP 的文件浏览器中选择文件时，会使用这些快捷方式创建路径，而不是完整路径。此外，为了让你在不同机器上拥有不同的媒体位置，可以把一个 JSON 文件放在 .toe 所在的同一文件夹中，它会在启动时被读取。这会把 projects.paths 中保存的任何现有位置覆盖为 .json 中指定的、针对该机器的新文件路径。只会使用 project.paths 中已存在的条目。如果 .json 包含未在 project.paths 中指定的路径名，这些条目会被忽略。它的内容大致如下：{ "project.paths": { "movies": "M:/MyMovies" } }。如果你的 .toe 文件名为 MyProject.10.toe，则该 JSON 文件必须命名为 MyProject.Settings.json。这样做的思路是，该 .json 针对各机器唯一，不提交到版本控制，也不在机器之间共享。

cookRate → float :

获取或设置每秒处理的最大帧数。通常你不需要使用此项。建议查看根组件的 FPS 来了解计算速率。单个 components 可有自己的速率，由 rate 指定。 

a = project.cookRate # 获取当前 cook 速率
project.cookRate = 30 # 把 cook 速率设为 30 FPS

注意：此项在用户界面左下角的「FPS」栏中显示和设置。

realTime → bool :

获取或设置实时计算状态。为 True 时，可能会跳过帧以维持 cookRate。为 False 时，所有帧都会按顺序处理，无论耗时多长。例如，这非常适合用 Movie File Out TOP 输出影片而不丢帧。 

a = project.realTime
project.realTime = False # 关闭实时播放。

isPrivate → bool (Read Only):

当项目网络无法直接查看时为 True。

isPrivateKey → bool (Read Only):

当私有网络可通过口令访问时为 True。

cacheParameters → bool :

缓存参数值，而不是每次都进行计算。

externalToxModifiedInProject → bool (Read Only):

当当前项目中某个外部 tox 被修改，且项目其他地方还加载了同一 tox 的其他实例时的回调。

externalToxModifiedOnDisk → bool (Read Only):

当磁盘上的某个外部 tox 文件被修改时的回调。

windowOnTop → bool :

获取或设置窗口置顶状态。

windowStartMode → WindowStartMode :

获取或设置窗口启动模式。 模式为以下之一：WindowStartMode.AUTO、WindowStartMode.FULL、WindowStartMode.LEFT、WindowStartMode.RIGHT 或 WindowStartMode.CUSTOM。

windowDraw → bool :

获取或设置窗口绘制状态。

windowStartCustomWidth → int :

获取或设置窗口启动宽度。仅在 windowStartMode 为 WindowStartMode.CUSTOM 时使用。

windowStartCustomHeight → int :

获取或设置窗口启动高度。仅在 windowStartMode 为 WindowStartMode.CUSTOM 时使用。

windowStartCustomX → int :

获取或设置窗口启动 X 位置。仅在 windowStartMode 为 WindowStartMode.CUSTOM 时使用。

windowStartCustomY → int :

获取或设置窗口启动 Y 位置。仅在 windowStartMode 为 WindowStartMode.CUSTOM 时使用。

performOnStart → bool :

获取或设置启动时进入演出的状态。

performWindowPath → OP :

获取或设置演出窗口路径。

resetAudioOnDeviceChange → bool :

获取或设置当系统添加或移除音频设备时，音频设备是否暂时重置。

sdrReferenceWhiteNits → int :

获取或设置 SDR 颜色/内容的 Reference White 亮度，单位为 nits。

hdrReferenceWhiteNits → int :

获取或设置 HDR 颜色/内容的 Reference White 亮度，单位为 nits。

editorWindowPixelFormat → WindowPixelFormat :

获取或设置编辑器窗口使用的像素格式。这不是 Window COMP 或 Perform 窗口使用的格式（后者由 Window COMP 设置）。

必须保存项目并重启 TouchDesigner，此设置才会生效。 有效值来自 WindowPixelFormat 枚举：

  • WindowPixelFormat.SDR8_FIXED
  • WindowPixelFormat.SDR10_FIXED
  • WindowPixelFormat.HDR10_FIXED
  • WindowPixelFormat.HDR16_FLOAT

workingColorSpace → WorkingColorSpace :

获取或设置此项目使用的工作色彩空间。

必须保存项目并重启 TouchDesigner，此设置才会生效。 有效值来自 WorkingColorSpace 枚举：

  • WorkingColorSpace.PASS_THROUGH
  • WorkingColorSpace.ACES_CG
  • WorkingColorSpace.SRGB_LINEAR

方法

load(path)→ None:

从磁盘加载特定的 .toe 文件。

  • path - （可选）要加载的文件路径。若未指定，则加载默认的 .toe file，如偏好设置中所指定。
project.load('test_demo.toe')

save(path, saveExternalToxs=False)→ bool:

将当前会话保存到磁盘。如果文件已保存则返回 True，否则返回 False（例如文件已存在，且提示时用户选择不覆盖）。

  • path - （可选）若未提供，则对默认/当前文件名递增后使用。当前文件为 project.folder 文件夹下的 project.name。
  • saveExternalToxs - （关键字，可选）若设为 True，会将任何引用外部 .tox 的 COMP 的内容保存到所引用的 .tox 文件中。
project.save('test_demo.toe')
project.save()

quit(force=False, crash=False)→ None:

退出项目。

  • force - （关键字，可选）若设为 True，未保存的更改将被丢弃且不提示。
  • crash - （关键字，可选）若设为 True，应用程序将意外终止。这用于系统测试。
project.quit()  # 退出项目；如果首选项对话框中启用了 'Prompt to Save on Exit'，可能会提示未保存的更改。
project.quit(force=True)  # 立即退出项目。

addPrivacy(key)→ bool:

使用给定密钥为 toe 文件添加保密。

只能为当前没有保密且使用 Pro 许可证的 toe 添加保密。

  • key - 密钥短语。应解析为非空字符串。
project.addPrivacy('secret')

removePrivacy(key)→ bool:

完全移除 toe 文件的保密。

  • key - 当前的保密密钥短语。
project.removePrivacy('secret')

accessPrivateContents(key)→ bool:

获得对私有文件的访问权。下次保存或重新打开时，文件仍将是私有的。

  • key - 当前的保密密钥短语。
project.accessPrivateContents('secret')

applyWindowSettings()→ None:

将项目的窗口启动设置应用到当前 TouchDesigner 窗口。

stack()→ str:

当前计算与参数计算栈的格式化内容。 

print(project.stack())

pythonStack()→ str:

当前 python 栈的格式化内容。 

print(project.pythonStack())
