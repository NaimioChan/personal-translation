系统要求

TouchDesigner 和 TouchPlayer 的系统要求。

基本要求

Older than hereafter specified configurations might work but some features will not be available.

Windows

Operating System

  • Microsoft Windows 10 / Windows 11

Hardware

  • 至少 4GB GPU 显存，建议 8GB 以上。
  • 建议使用最新的 Nvidia drivers、AMD drivers 或 Intel 驱动。

TouchDesigner 需要支持 Vulkan 1.1 的 GPU 和驱动。

Nvidia GPUs

  • Nvidia Geforce 1000 系列或更高。
  • Nvidia Quadro/RTX Pascal 系列或更高。
  • 需要 530.00 或更新的驱动。建议 581.00 或更高版本驱动。

AMD GPUs

  • AMD Radeon 5000 系列或更高（RDNA 架构 GPU）。

Intel GPUs 注意：并非所有功能都支持集成显卡芯片，且对整体性能的预期较低。

  • Intel 500 及更新的 GPU（不含 5000、6000 系列）。你可以在 here. 查看你的 GPU

Apple Mac

Operating System

  • Apple macOS 13（Ventura）及以上（另请参阅 macOS）

Hardware

  • Mac Pro / iMac / Mac Mini / MacBook Pro / MacBook Air 2020+
  • TouchDesigner 需要 macOS 13 或更高版本，但我们建议运行你的 Mac 支持的最新 macOS 版本。
  • 我们强烈建议为 TouchDesigner 使用 Apple Silicon 的 Mac。对于 Intel 版 Mac，TouchDesigner 需要配备独立 AMD GPU 的机型。

输入设备

  • 需要带滚轮的三键鼠标。

功能特定要求

  • Movie File In TOP - H.264 和 H.265 硬件加速解码
    • 仅限 Windows 上的 Nvidia GPU，或在 macOS 上使用硬件支持的编解码器。
  • Movie File Out TOP - H.264 和 H.265 编码
    • 在 Windows 上需要 Nvidia GPU，也可在 macOS 上使用。
  • Video Stream Out TOP - 使用 H.264 编码
    • 仅限 Windows 系统与 Nvidia GPU
  • Syphon Spout In TOP / Syphon Spout Out TOP
    • Windows 上的 Spout 需要 Nvidia 或 AMD GPU，Intel 不可用。
  • Face Track CHOP 和 Face Track SOP
    • 仅限 Windows 系统与 Nvidia RTX GPU。
    • 使用 Face Track SOP 进行网格拟合需要一个可从外部来源下载的兼容网格文件。
  • Nvidia Background TOP
    • 仅限 Windows 系统与 Nvidia RTX GPU。
  • Nvidia Denoise TOP
    • 仅限 Windows 系统与 Nvidia RTX GPU。
  • Nvidia Flex
    • 仅限 Windows 系统与 Nvidia GPU
  • Nvidia Flow TOP
    • 仅限 Windows 系统与 Nvidia GPU
  • Notch TOP - 播放 Notch 块
    • Windows 系统
  • Optical Flow TOP - 检测输入中的运动模式。
    • Windows 系统与 Nvidia 3000 或更高 GPU
  • Scalable Display TOP
    • Windows 系统
  • C++ TOP 中的 CUDA
    • 仅限 Windows 系统与 Nvidia GPU
  • DirectX In TOP 和 DirectX Out TOP
    • Windows 系统与 DirectX 9.0 及以上
  • Photoshop In TOP
    • Adobe Photoshop CS6 及以上
  • SVG TOP
    • 仅限 Windows 系统与 Nvidia GPU
  • Geometry COMP 纹理实例化
    • 仅限 Windows 系统与 Nvidia GPU
  • Window COMP Hardware Frame Lock
    • 仅限 Windows 系统与 Nvidia Quadro Sync 或 AMD S400
  • Pangolin CHOP - 通过其 Beyond 软件驱动 Pangolin 激光灯。
    • Windows 系统
  • RealSense CHOP - 使用旧版 RealSense 设备进行骨骼和面部跟踪。
    • Windows 系统
  • Kinect 2 支持
    • Windows 系统 - 8 或 10
    • 专用 USB 3.0 控制器
  • Kinect Azure TOP / Kinect Azure CHOP - 身体跟踪与 Player Index 支持
    • Windows 系统
    • 建议使用 Nvidia GPU，但现在也支持 AMD 和 Intel 显卡。基于 CPU 的选项对大多数用例来说太慢。
  • NatNet In CHOP - 从 OptiTrack 系统接收跟踪数据。
    • Windows 系统
  • Oculus Rift
    • Windows 系统
    • Oculus Rift DK2 或 CV1
  • OpenVR - HTC Vive 或其他支持 OpenVR 的头显。
    • Windows 系统
  • ZED - 访问 ZED 设备的 TOP、CHOP、POP 和 SOP。
    • Windows 系统
