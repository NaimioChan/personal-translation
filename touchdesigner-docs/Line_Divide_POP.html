Line Divide POP

摘要

Line Divide POP 可接受任意一组 line strip，并为每条 line strip 生成一条用不同插值方法细分的新 line strip。默认为线性插值，在相邻输入点之间分 4 段。

你可以选择 Interpolation Method，默认为线性插值，但也可以选择 Cardinal、BSpline、Beziers 和 Quadratic 等样条类型。使用样条类型时，它可以使用传入的属性（例如在 Line POP 中设置的属性）来指定样条特性，例如 Weight、切线（TanIn 和 TanOut）、切线约束（TanInConstraint）和/或张力。如果存在 SegMethod 属性，它还会逐点解释插值方法。

细分分两个阶段进行。第一阶段可以设置 line strip 的总分段数，或每段的分段数，按沿曲线的距离或按 line strip 的曲率来细分。它会插值所有属性。

第二阶段可以用三种方法之一进一步重采样 line strip：Divisions per Line Strip、Distance between Points 或 Points as Keyframes。

Points as Keyframes 通过把一个属性当作自变量（例如 Time 或 U）来插值，类似 y = f(x) 数学函数。（例如，如果点上有一个 Time 属性，且你的曲线表示随时间变化的值，就可以按等时间步长重采样曲线。）

注意：Maximum Number of Vertices 参数是必需的，因为 GPU 上无法预知最终会得到多少个点，而 GPU 需要预先分配足够的内存来完成工作。否则 line strip 会被截断。

待补充：区分不同的 bezier，解释 TanInConstraint。ControlPoint 属性（laser）

另请参阅 Line POP、Curve POP、Point POP、Primitive POP、Pattern POP。

参数 - Divide 页

Divisions Method divmethod - - 施加细分的方法。
  • None none -
  • Divisions per Line Strip linestrip -
  • Divisions per Segment segment -
  • Distance between Points dist -
  • Distance by Curvature curvature -
Divisions divs - 分段数量。
Min Distance mindist - 输出 line strip 中点与点之间的最小距离。
Max Distance maxdist - 细分线条，使任意两个相邻点的间距都不超过此距离 - 即点间最大距离。
Min Max Bias minmaxbias - 点创建的偏向 - 更多靠近最小距离，或更多靠近最大距离。
By Edge byedge - 按点间距离细分时，是否在每个段（边）处重新开始。
Add ControlPoint Attribute addctrlpointattr - 是否输出 ControlPoint 属性，控制点处设为 1。
Maximum Number of Vertices maxverts - 设置要分配的顶点数。它应大于实际创建的顶点数（可在信息弹窗中查看）。分配更多顶点会占用更多 GPU 内存。

Tension tension - 控制 cardinal line strip 穿过控制点时的弯曲紧致程度
