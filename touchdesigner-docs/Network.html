网络

TouchDesigner 网络

网络是一组在一个 Component 中相互连接的 Nodes，它们属于 Operators。每个组件都包含一个网络，每个网络都位于一个组件中。

网络节点通过彩色的 wires 连接，显示同一操作符族内从一个操作符到另一个操作符的数据流（例如 CHOP 到 CHOP），每个操作符都会计算其输入并生成输出。

某些网络元素可能没有直接连线。灰色虚线表示其他数据引用：

  • parameter 中的 Python 表达式引用了另一个操作符。
  • CHOP 通道 exports 到另一个操作符的参数。
  • 参数中包含指向另一个操作符的 path。

组件包含自己的网络，使用其输入节点（In OPs）生成输出（Out OPs）。

某些节点可能被 DAT 中的脚本引用，而它们之间不会绘制连接线。

通常，节点通过连线连接，数据从左向右流动。

另请参阅：Network Editor、Network Path。
