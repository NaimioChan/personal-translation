Parameter Execute DAT

摘要

Parameter Execute DAT 在任意操作符的 parameter 状态改变时运行脚本。参数触发脚本有 4 种方式：值、表达式、导出或启用状态发生变化。

Parameter Execute DAT 通过 default python method placeholders 创建。与其他执行 DAT 不同，Parameter Execute DAT 不会计算它所监视的节点，以避免递归更新带来的问题。

parameterexecuteDAT_Class

参数 - Parameter Execute 页

Active active - 开启时，DAT 会响应所引用的参数。
Execute from executeloc - - （仅 Tscript）决定脚本运行的位置。
  • Current Node current - （仅 Tscript）脚本从当前节点位置执行。
  • This Node here - 脚本从 DAT 的父级执行。DAT 从父级执行是为了便于访问 DAT 的同级：过去 DAT 脚本是从 DAT 内部执行的。
  • Specified Operator op - 脚本从下方 From Operator 参数指定的操作符中执行。
From Operator fromop - 如果 Execute From 参数设为 Specified Operator，此操作符也是脚本执行的路径。
OPs op - 指定触发参数属于哪个（些）操作符。
Parameters pars - 指定要监视以触发脚本的参数。
Value Change valuechange - 当指定的参数值以任何方式发生变化时，执行 onValueChange() 方法。每帧调用一次。
Values Changed valueschanged - onValuesChanged() 方法在帧末执行，带有所有单个参数更改的完整列表。更改是一个命名元组列表，每个元组为 (Par, 前一个值)
On Pulse onpulse - 当 pulse 类型参数被点击或通过 Par.pulse() 方法脉冲时，执行 onPulse() 方法。
Expression Change expressionchange - 当指定参数的表达式发生变化时，执行 onExpressionChange() 方法。例如，将表达式从 me.time.frame 改为 me.time.seconds 会触发脚本。
Export Change exportchange - 如果到指定参数的导出路径发生变化，执行 onExportChange() 方法。例如，如果该参数正由 /chopname/chan1 导出，而后改为由 /chopname2/chan2 导出，则会触发脚本。
Enable Change enablechange - 如果指定参数从禁用变为启用，执行 onEnableChange() 方法。
Mode Change modechange - 如果指定的 parameter's mode 在可用的常量、表达式、导出或绑定模式之间切换，执行 onModeChange() 方法。
Custom custom - 监视 Custom Parameters。
Built-In builtin - 监视内置参数。
Edit.. edit - 点击后打开文本编辑器，以编辑 DAT 中的文本。

参数 - File 页

File file - 要加载的文件的文件系统路径和名称。接受 .txt 和 .dat 文件。
Sync to File syncfile - 开启时，在项目启动时将文件从磁盘加载到 DAT 中。必须指定文件名。开启该选项会立即从磁盘加载文件。如果文件不存在，则在 DAT 第一次更新时创建它。系统会监视该文件，对文件的任何改动都会更新 DAT，而对 DAT 的任何改动都会立即写入文件。如果文件被移除，DAT 将保留其当前内容。
Load on Start loadonstart - 开启时，项目启动时从磁盘重新加载文件到 DAT 中。
Load File loadonstartpulse - 立即重新加载文件。
Write on Toe Save write - 开启时，保存项目时将 DAT 的内容写入磁盘文件。
Write File writepulse - 立即将文件写入磁盘。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

可通过 Info CHOP 访问 Parameter Execute DAT 的额外信息。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
