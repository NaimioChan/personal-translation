浮动云授权

TouchDesigner 使用 Wibu/CodeMeter's CmCloud licensing technology 提供浮动许可证。

适用于版本 2020.28110 或 2021 年起的任何版本

Floating Cloud procedure - After purchase Derivative will send you a credential .wbc file, usually issued during Derivative business hours of 10:00-18:00 EST (UTC-4) Toronto time. For inquiries about your credential file please email our licensing team.

使用场景

从全球池为本地计算机授权 - 分布式团队与远程工作

浮动云许可证为希望让团队中任何人在全球范围内都能使用许可证池的用户提供了简单的方案。同一账户上的多个许可证池可在办公室、工作室或装置等全球地点之间共享，只要有互联网连接，就能按需把许可证发放给团队成员。 这与 Dongle based floating licensing 不同，因为那种方案要求 Dongle 和本地计算机位于同一 LAN 上。

学校与大学的实验室计算机

有时实验室计算机会经常被清空和/或没有管理员权限。使用浮动云许可证可让系统管理员把凭据作为磁盘镜像的一部分安装到实验室计算机上。这种设置会在使用 TouchDesigner 时自动占用许可证，并在 TouchDesigner 关闭时归还。

关于在教育机构中设置 TouchDesigner 的更多信息，另请参阅 Educational Setup。

在云平台上运行 TouchDesigner

浮动云许可证的一个很好的使用场景，是让在云服务器上运行 TouchDesigner 和 TouchPlayer 时的授权变得简单。这些虚拟云服务器往往没有固定的系统码。这可能是因为每次启动云服务器都会新建一个实例，也可能是因为云平台的运作方式导致系统码经常变化。基于 Dongle 的方案也不可行，因为云服务器很少能访问到硬件。

工作流程

云许可证在 TouchDesigner 启动时获取许可证，在关闭时释放许可证。运行期间，TouchDesigner 每 9 分钟续订一次许可证。因此如果互联网连接中断，那么在 9 分钟的检查间隔到来时，该机器上的许可证就会停止工作。

如果机器崩溃而不是正常关闭 TouchDesigner，许可证会在 20 分钟后在云授权服务器上自动释放。

可靠性

由于云许可证需要有效的互联网连接才能工作，它们只应在非关键场景中使用，例如实验室或办公室工作，或者互联网访问本身也是关键要素的关键场景。也就是说，它们用于云系统是安全的，因为如果云系统失去互联网，无论是否使用云许可证，系统都会无法运行。

限制

单个 .wbc 凭据文件一次最多允许 100 个连接。如果需要更多许可证，我们需要把它们分散到多个 .wbc 文件中。任何正在运行且安装了 .wbc 凭据的机器都会计入此限制，即使 TouchDesigner 没有运行。

不能停机的现场演出和装置应使用软件许可证或基于 Dongle 的许可证。

转换现有许可证

任何现有许可证都可以转换为浮动云许可证，只需支付标准许可证与浮动许可证之间的差价。商店中没有对应的商品，因此你可以在商店中使用「Payment Tokens」购买等额数量，并联系 sales@derivative.ca 让我们为你转换许可证。注意，转换不会改变许可证的更新日期。

设置浮动云许可证

单个用户账户可以分配任意数量的许可证在云中浮动，并且可以使用任何类型的许可证，即 Educational - Commercial - Pro。

激活浮动云许可证

购买浮动云许可证后，Derivative 会给你发送一个凭据文件，它是一个 .wbc 文件。

NOTE: The credential files are usually issued during Derivative business hours of 10:00-18:00 EST (GMT-4) Toronto time. For any inquiries about your credential file please email our licensing team.

Install .wbc File

  1. 安装 CodeMeter Control Center。
  2. 打开 Codemeter Control Center 应用，然后把 .wbc 文件拖放到 Control Center 上进行安装。

要让计算机从云中获取许可证，需要把这个 .wbc 加载到 CodeMeter Control Center 中，并且需要有效的互联网连接。当 TouchDesigner 或 TouchPlayer 启动时，如果系统上安装了 .wbc 文件，它会尝试从云服务获取可用许可证。如果已安装的任何本地许可证级别更高（即 Pro 高于 Commercial），它们也会叠加在云许可证之上使用。如果你不想再在某台计算机上使用云许可证，只需按下面一节的说明从 CodeMeter Control 中移除凭据即可。

组织中所有将使用云许可证的用户只使用一个 .wbc 凭据文件。该文件本身不包含任何许可证。它只包含用于联系云服务器以获取许可证的凭据。如果凭据文件因任何原因泄露（例如被交给了不该有访问权限的人），Derivative 需要为你的账户签发新的凭据文件。该账户的所有用户都需要安装这个新凭据文件，因为旧文件会停止工作。

通过命令行

可以在命令行中用以下命令把凭据文件安装到系统上：

 cmu32.exe --import --file <yourFile.wbc>

从计算机移除浮动云凭据

目前从计算机移除 CmCloud 许可证需要几个步骤。我们希望 CodeMeter 能尽快发布更好的方案。在此期间，可以用以下两种方法之一移除 CmCloud 许可证。

通过命令行

进入 CodeMeter 运行时目录，通常是：C:\Program Files (x86)\CodeMeter\Runtime\bin 执行命令：

 cmu32.exe --delete-cmcloud-credentials --serial <Serial number of CmCloud license>

在 macOS 上，该命令就叫 cmu。

在 CodeMeter Control Panel UI 中启用「Remove」按钮

1. 点击 Windows 徽标键并输入：regedit
2. 在 HKEY_CURRENT_USER/SOFTWARE/WIBU-SYSTEMS/CodeMeterCC 处新建一个 DWORD(32-bit) 值，名称为「AllowCmActDelete」，并把该项的值设为 1。
3. 重启计算机。
要停用该按钮，按第 1 步操作并把「AllowCmActDelete」设为 0，或完全删除「AllowCmActDelete」项。

更新浮动云许可证

浮动云许可证的更新可以像普通许可证一样在商店中购买。注意，浮动云池中的所有许可证必须具有相同的 Update Date，即它们必须一起批量更新。如需协助更新浮动云许可证，请发请求至 licensing@derivative.ca。

释放卡在 in-use 状态的许可证

如果使用云许可证的计算机、或该计算机上的 TouchDesigner 崩溃，许可证可能在云授权服务器上仍处于「in-use」状态。要解决这个问题，只需在原本使用该许可证的计算机上重启 TouchDesigner，然后关闭 TouchDesigner。这应该会在云授权服务器上释放该许可证。如果这没有解决问题，请联系 licensing@derivative.ca。

网络端口

CmCloud 服务通信所用的端口是网络端口号 22350。

在本地共享云许可证

云许可证的典型工作流程是在每台想通过云访问许可证的机器上安装 .wbc 凭据。不过，也支持使用一台本地服务器作为安装 .wbc 的位置、其他本地机器通过该服务器获取许可证的流程，就像 Dongle 那样。更多信息见 [[1]] 注意，安装 .wbc 的服务器仍需稳定的互联网连接才能与云授权服务器通信。

安装所需的 Codemeter 软件

要使用 USB 许可证 Dongle 或浮动云许可证，系统上需要 Codemeter Runtime 软件。

注意： 请更新到 CodeMeter Runtime 7.60+

Windows CodeMeter 安装

  • 安装 TouchDesigner 时，安装程序的第一个对话框会有一个「Install Runtime for Dongle Licensing」选项，确保勾选它。继续安装。你也可以从这里下载 dongle 运行时 CodeMeter Download。建议在 CodeMeter 安装程序选项中关闭「Automatic server search」选项，以便在安装了许多 CodeMeter 机器的网络上更快启动。
