混合

混合是一种按各种比例将两个像素组合在一起的功能。混合是图像合成的基本操作，常用于制作 transparency 效果。

在混合功能中，一个像素被指定为 the source，另一个被指定为 the destination。混合使用源混合因子来决定源像素颜色以多大比例绘制到目标像素之上。目标像素也有一个混合因子，决定其自身颜色有多少比例贡献到最终的混合像素中。

混合公式为：

Final Pixel Value = (Source Blend Factor * Source Pixel Color) + (Destination Blend Factor * Destination Pixel Color)

在 TouchDesigner 中，混合是大多数 MATs 的常用参数。
