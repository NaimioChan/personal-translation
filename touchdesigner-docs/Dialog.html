对话框

TouchDesigner 有许多用于项目监控和设置的特殊对话框窗口。大多数对话框可在 Dialogs 菜单下找到。

  • Explorer
  • Textport and DATs
  • Performance Monitor
  • Window Placement
  • Palette Broswer
  • MIDI Device Mapper
  • Beat Dialog
  • Variables/Macros
  • Console
  • 错误
  • Key Manager
