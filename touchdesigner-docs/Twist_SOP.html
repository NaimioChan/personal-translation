Twist SOP

摘要

Twist SOP 执行非线性变形，如 bend、linear taper、shear、squash and stretch、taper 和 twist。每种变形都会在一个或多个轴上扭曲对象。

twistSOP_Class

参数 - 页

Group group - 如果存在输入组，在此字段中指定组名将使该 SOP 仅作用于指定的组。接受模式匹配，说明见 Pattern Matching。
Operation op - - 此菜单允许你选择一种非线性变形类型。从以下选项中选择：
  • Twist twist - 围绕 Primary Axis 旋转输入几何。
  • Bend bend - 围绕 Primary Axis 弯曲输入几何，同时保持 Secondary Axis 上的点不动。
  • Shear shear - 沿 Secondary Axis 剪切输入几何，视线沿 Primary Axis。
  • Taper taper - 沿 Secondary Axis 锥化输入几何，视线沿 Primary Axis。
  • Linear Taper ltaper - 与 Taper 选项一样锥化输入几何；但经过 Taper 操作后只有边缘保持笔直。
  • Squash & Stretch squash - 传统动画师的弹跳工具。
Primary Axis paxis - - 这些菜单允许你选择变形的主轴和次轴。所选变形将先在 Primary Axis 上发生，然后在 Secondary Axis 上发生。
  • X Axis x - 此字段允许你选择变形的原点。
  • Y Axis y - 此字段允许你选择变形的原点。
  • Z Axis z - 此字段允许你选择变形的原点。
Secondary Axis saxis - - 这些菜单允许你选择变形的主轴和次轴。所选变形将先在 Primary Axis 上发生，然后在 Secondary Axis 上发生。
  • X Axis x - 此字段允许你选择变形的原点。
  • Y Axis y - 此字段允许你选择变形的原点。
  • Z Axis z - 此字段允许你选择变形的原点。
Pivot p - - 此字段允许你选择变形的原点。
  • X px -
  • Y py -
  • Z pz -
Strength strength - 所应用效果的 Strength。Rolloff 决定所应用效果的强调程度。使用不同类型的变换时，Strength / Roll 会产生不同效果：
  • Bend - Strength 和 Roll 用于控制几何的两端（试试值 0.5）。
  • Twist - Strength 和 Roll 用于根据距离影响扭转量。
  • Shear - Strength 和 Roll 用于根据距离影响剪切量。
  • Taper - Strength 和 Roll 用于影响弯曲方向（向内还是向外）。
  • Linear Taper - 此选项下 Strength 和 Roll 没有效果。
  • Squash and Stretch - Strength 和 Roll 用于保持源几何的表观体积。

通常 Rolloff 应等于 1 - 这样效果会均匀分布（但不仅限于）几何的边界范围内。高于 1 的值会在同一范围内多次重复该效果。如果 Rolloff 等于 0，效果可能局限于变形几何中心的一小段上，Strength 看起来可能无法正常工作。

注意： 为确保看到 Twist SOP 的效果，请确认沿边缘有足够的分段。使用与对象不同的中心可以改善对对象的控制。试着把枢轴点移到正在挤压拉伸的对象的底部。

Info CHOP 通道

可通过 Info CHOP 访问 Twist SOP 的额外信息。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
