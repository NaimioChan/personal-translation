Polygonize POP

摘要

Polygonize POP 接收一个 3D 纹理形式的 TOP（见 Texture 3D TOP）作为输入，或接收一个按三维点阵排列的 POP（见 Dimension），并创建一个 3D 多边形曲面，包围超过指定阈值的像素或点。

当输入是 3D 纹理时，它使用该 3D 纹理的某个 RGBA 通道或它们的组合（Channel 菜单）与 Threshold 参数比较。当输入是 POP 时，它使用单值 float 属性（或向量属性的某个分量）与 Threshold 参数比较。

它生成一个闭合的多边形曲面，包围所有值高于阈值的点/像素。也就是说，曲面内的所有像素/点都高于阈值，而所有低于阈值的像素/点都在曲面之外。（在某个像素值高于 Threshold 而相邻点/像素的值低于阈值处，多边形会穿过该像素。）

（按三维点阵排列的输入 POP 示例：Slices 大于 1 的 Grid POP 送入 Noise POP，生成一个值介于 -1 和 1 之间的单 float Noise 属性。Polygonize POP 的 Threshold 参数会取 0 左右。）

输出的点密度可用 Resolution Multiplier 参数降低。

体积边界处的曲面由 Extend 菜单控制——边界可以闭合或开放。

使用 3D 纹理时，像素被视为立方体，输出的 P(0) 范围为 -.5 到 .5。输出可用 ReRange P 参数重新映射范围。

另请参阅 Trace POP。

参数 - Polygonize 页

TOP top - 用作待多边形化图像的 TOP。
Channel channel - 当输入为 TOP 时，要采样的颜色通道。
  • Luminance luminance -
  • Red red -
  • Green green -
  • Blue blue -
  • Alpha alpha -
  • RGB Average rgbaverage -
  • RGBA Average average -
  • RGB Maximum rgbmax -
  • RGBA Maximum max -
Resolution Multiplier resmult - 施加到输入上的分辨率乘数。
Inside inside - 值高于阈值还是低于或等于阈值的部分被视为内部。决定三角形的绕向，进而决定其法线的朝向。
  • <= (Signed Distance) lteq -
  • > (Density) gt -
Threshold threshold - 阈值，即曲面将被创建的位置。
Extend extend - 设置采样 TOP 时的 Extend 模式。
  • Hold hold -
  • Zero zero -
  • Repeat repeat -
  • Mirror mirror -
Unique Points uniquepoints - 点是在三角形之间共享，还是每个三角形独有。
ReRange P rerangep - 是否重新映射 P 的范围。
Map to Low tolow - XYZ 中新范围的低值。
  • Map to Low tolow0 -
  • Map to Low tolow1 -
  • Map to Low tolow2 -
Map to High tohigh - XYZ 中新范围的高值。
  • Map to High tohigh0 -
  • Map to High tohigh1 -
  • Map to High tohigh2 -
Normals Method nmlmethod - 如何计算三角形的法线。
  • No Normal none -
  • Field Gradient gradient -
  • From Surface surface -
Step Multiplier nmlstepmul - 当方法为 Field Gradient 时，使用相邻场值计算梯度时步长的乘数。
Texture Coordinates texture - 是否输出点 Texture Coordinates 属性（Tex）。
Fraction of Max Allocation allocfract - 这个 POP 无法预先知道需要多少 GPU 内存，但除少数情况（细节量非常大、源中相邻体素变化很多）外，它并不需要最大分配量。这样可以节省 GPU 内存。如果点或图元缺失，或信息弹窗显示已达最大数量，说明该比例过低。
Copy Topology Info Back to CPU cpureadback - 启用后，将 GPU 上保存的点数和拓扑信息复制到 CPU。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Polygonize POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
