Primitive SOP

摘要

Primitive SOP 类似 Point SOP，但它操作的是 primitive 的位置、大小、朝向、颜色、alpha，以及图元特有的属性，例如翻转图元法线。Primitive SOP 还允许你创建自定义图元属性。

还可以用此 SOP 对轮廓施加参数化仿射变换。也可以用它打开、闭合、反转和循环轮廓曲线。

注意： 对轮廓施加变换时，只能绕 Z 轴旋转，因为投影曲线是位于曲面域内的平面曲线。因此，为轮廓提供 X 或 Y 方向的旋转没有意义。

图元与轮廓的变换

Bézier 曲面是单个图元，NURBS 曲面也是如此，而多边形网格可能由数百个独立图元组成。需要小心处理以确保得到想要的结果。轮廓可以与 3D 图元一起平移、旋转和缩放。平移与缩放的 Z 分量会被忽略。X 和 Y 分量会被解释为 U 和 V 值，因为它们作用于轮廓所在的空间。

示例 - 在球体内部映射纹理

Primitive SOP 有许多用途。通常，若把纹理贴到球体上，纹理会映射到外表面，因为 U 曲面的法线默认朝外。如果想把纹理映射到球体内部，只需让球体几何通过一个 Primitive SOP，并在 Face/Hull 页 → Vertex 菜单中选择 Reverse U（即曲面法线）。

参数 - Primitive 页

Source Group group - 如果有输入组，在此栏中指定组名将使该 SOP 只作用于指定的组。可以通过提供轮廓图案在该组内指定轮廓曲线（例如 *.3 指定所有样条曲面中的第四个轮廓）。

提示： 在此同时指定图元和轮廓（例如：0 0.*），即可同时变换父级曲面和一条轮廓曲线。

Template Group templategrp - 要变换到的模板点子集。

参数 - Transform 页

Do Transformation doxform - 勾选后允许进行变换。
Rotate to Template dorot - - 可以使用 Primitive SOP 的第二个输入指定模板。设为 On 时，该模板可用于将每个图元变换到模板点的位置和朝向。这类似于 Copy SOP 的功能，区别在于变换的是图元本身，而不是生成副本。
  • Off off - 不旋转。
  • On on - 图元会像其法线为 (0,0,1) 那样旋转，目的是指向与模板法线相同的方向。
  • Match Normals match - 旋转图元，使其真实法线与模板点的法线对齐。

Lookat Object lookat - 选择图元应朝向的对象。这在对象空间中执行 lookat；如需在世界空间中 lookat，请改用对象 Transform 页中的 lookat。

提示： 要让多个精灵始终垂直于摄像机，可将它们送入 Primitive SOP，并把摄像机指定为 Lookat Object。这样精灵就会始终垂直于摄像机。

Up-Vector upvector - - 定义图元沿 X、Y 或 Z 轴的朝向。

Up Vector 决定图元相对于目标对象（在 Lookat Object 中指定）的朝向方式。默认值为 Y 方向上的 1。当 Lookat Object 非常接近和/或越过目标时，这会让对象在 Z 轴上适度旋转，效果不错。缩放 Up Vector 会使 Lookat 图元在非常接近和/或越过目标时保持更直立。Up Vector 越强，图元就越倾向于保持垂直、抵抗旋转。

Info CHOP 通道

可通过 Info CHOP 访问 Primitive SOP 的额外信息。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
