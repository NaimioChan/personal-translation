Render Simple TOP

摘要

Render Simple TOP 渲染单个 POP，带有基本的变换、灯光，以及可选的纹理贴图或材质。其他控制项包括正交/透视、对象颜色和背景 RGBA。

摄像机位于 Z 轴上。Normalize Geo 参数会平移并等比缩放 POP 几何，使其适配原点处大小为 2 的立方体。

可以以线框渲染，或用任意 MAT 替换材质。POP 的 render/display 标记会被忽略。

Render Simple 不需要功能更完整的 Render TOP 所需的 Camera COMP、Geometry COMP 或 Light COMP。

另请参阅 Render TOP

参数 - Common 页

Output Resolution outputresolution - - 快速更改 TOP 数据的分辨率。
  • Use Input useinput - 使用输入的分辨率
  • Eighth eighth - 将输入的分辨率乘以该数值。
  • Quarter quarter - 将输入的分辨率乘以该数值。
  • Half half - 将输入的分辨率乘以该数值。
  • 2X 2x - 将输入的分辨率乘以该数值。
  • 4X 4x - 将输入的分辨率乘以该数值。
  • 8X 8x - 将输入的分辨率乘以该数值。
  • Fit Resolution fit - 放大或缩小输入分辨率以适配此分辨率，同时保持宽高比不变。
  • Limit Resolution limit - 限制输入分辨率不超过此分辨率，同时保持宽高比不变。
  • Custom Resolution custom - 直接控制宽度和高度。
Resolution resolution - - 仅当 Resolution 参数设为 Custom Resolution 时启用。某些生成器（如 Constant 和 Ramp）不使用输入，仅使用此字段确定其大小。右侧的下拉菜单提供一些常用分辨率。
  • W resolutionw -
  • H resolutionh -
Resolution Menu resmenu - 包含一些常用分辨率的下拉菜单。
Use Global Res Multiplier resmult - 使用 Edit>Preferences>TOPs 中的 Global Resolution Multiplier。这会将所有 TOP 的分辨率乘以设定的数值。在硬件规格不同的计算机上工作时这很方便。如果项目是在显存充足的工作站上设计的，而使用仅有 64MB VRAM 的笔记本电脑的用户可以将 Global Resolution Multiplier 设为一半或四分之一，以便以可接受的速度运行。勾选此复选框后，此 TOP 会受全局乘数影响。
Output Aspect outputaspect - - 设置图像宽高比，使任何纹理都能以任何尺寸查看。在合成宽高比不同的 TOP 时要注意意外结果。（可以使用 xres、yres、aspectx、aspecty 定义非方形像素的图像，其中 xres/yres != aspectx/aspecty。）
  • Use Input useinput - 使用输入的宽高比。
  • Resolution resolution - 使用图像所定义分辨率的宽高比（即 512x256 为 2:1），此时每个像素为方形。
  • Custom Aspect custom - 允许你在下面的 Aspect 参数中显式定义自定义宽高比。
Aspect aspect - - 在 Output Aspect 参数设为 Custom Aspect 时使用。
  • Aspect1 aspect1 -
  • Aspect2 aspect2 -
Aspect Menu armenu - 包含一些常用宽高比的下拉菜单。
Input Smoothness inputfiltertype - - 控制对 TOP 输入图像的像素过滤。
  • Nearest Pixel nearest - 使用最近像素或精确图像表示。在任何非 Native Resolution 的缩放级别查看时，图像会显得有锯齿。
  • Interpolate Pixels linear - 在像素之间使用线性过滤。这就是让查看器中的 TOP 图像在各种缩放级别下都好看的方式，在使用除 Native Resolution 以外的任何 Fill Viewer 设置时尤其有用。
  • Mipmap Pixels mipmap - 缩放图像时使用 mipmap 过滤。这可用于减少细节丰富的运动/缩放图像中的伪影和闪烁。
Fill Viewer fillmode - - 决定 TOP 图像在查看器中的显示方式。

注意： 要理解 TOP 如何处理图像，在刚开始放置 TOP 时，你会希望将此设为 Native Resolution。这样你可以看到实际发生的情况，而没有任何查看器自动缩放。

  • Use Input useinput - 使用与其输入相同的 Fill Viewer 设置。
  • Fill fill - 拉伸图像以适应查看器边缘。
  • Fit Horizontal width - 拉伸图像以在水平方向适应查看器。
  • Fit Vertical height - 拉伸图像以在垂直方向适应查看器。
  • Fit Best best - 拉伸或压扁图像，使图像的任何部分都不被裁剪。
  • Fit Outside outside - 拉伸或压扁图像，使图像在保持其比例的同时填满查看器。这通常会导致图像的一部分被查看器裁剪。
  • Native Resolution nativeres - 在查看器中以图像的原始分辨率显示。
Viewer Smoothness filtertype - - 控制查看器中的像素过滤。
  • Nearest Pixel nearest - 使用最近像素或精确图像表示。在任何非 Native Resolution 的缩放级别查看时，图像会显得有锯齿。
  • Interpolate Pixels linear - 在像素之间使用线性过滤。用于让查看器中的 TOP 图像在各种缩放级别下都好看，在使用除 Native Resolution 以外的任何 Fill Viewer 设置时尤其有用。
  • Mipmap Pixels mipmap - 缩放图像时使用 mipmap 过滤。这可减少细节丰富的图像在移动/缩放时的伪影和闪烁。当输入为 32 位浮点格式时，只使用 nearest 过滤（无论选择什么）。
Passes npasses - 将 TOP 的操作重复指定次数。第一次之后的每一遍都会取上一遍的结果，并用上一遍的结果替换该节点的第一个输入。例外情况是使用 compute shaders 时的 GLSL TOP，此时输入始终是所连接 TOP 的图像。
Channel Mask chanmask - 允许你选择 TOP 将作用于哪些通道（R、G、B 或 A）。默认选中所有通道。
Pixel Format format - - 用于存储图像中每个通道数据的格式（即 R、G、B 和 A）。更多信息请参阅 Pixel Formats。
  • Use Input useinput - 使用输入的像素格式。
  • 8-bit fixed (RGBA) rgba8fixed - 每个通道使用 8 位整数值。
  • sRGB 8-bit fixed (RGBA) srgba8fixed - 每个通道使用 8 位整数值，并以 sRGB 色彩空间存储颜色。注意这not对像素值应用 sRGB 曲线，而只是用 sRGB 曲线存储它们。这意味着较暗的值使用更多数据，较亮的值使用更少。下游读取这些值时会转换回线性。更多信息请参阅 sRGB。
  • 16-bit float (RGBA) rgba16float - 每个颜色通道使用 16 位，每像素 64 位。
  • 32-bit float (RGBA) rgba32float - 每个颜色通道使用 32 位，每像素 128 位。
  • 10-bit RGB, 2-bit Alpha, fixed (RGBA) rgb10a2fixed - 每个颜色通道使用 10 位，alpha 使用 2 位，每像素共 32 位。
  • 16-bit fixed (RGBA) rgba16fixed - 每个颜色通道使用 16 位，每像素共 64 位。
  • 11-bit float (RGB), Positive Values Only rgba11float - 一种 RGB 浮点格式，Red 和 Green 通道有 11 位，Blue 通道有 10 位，每像素共 32 位（因此内存占用与 8 位 RGBA 相同）。此格式中的 Alpha 通道始终为 1。值可以大于 1，但不能为负。即范围为 [0, infinite)。
  • 16-bit float (RGB) rgb16float -
  • 32-bit float (RGB) rgb32float -
  • 8-bit fixed (Mono) mono8fixed - 单通道，RGB 都具有相同的值，Alpha 为 1.0。每像素 8 位。
  • 16-bit fixed (Mono) mono16fixed - 单通道，RGB 都具有相同的值，Alpha 为 1.0。每像素 16 位。
  • 16-bit float (Mono) mono16float - 单通道，RGB 都具有相同的值，Alpha 为 1.0。每像素 16 位。
  • 32-bit float (Mono) mono32float - 单通道，RGB 都具有相同的值，Alpha 为 1.0。每像素 32 位。
  • 8-bit fixed (RG) rg8fixed - 2 通道格式，R 和 G 有值，而 B 始终为 0，Alpha 为 1.0。每通道 8 位，每像素共 16 位。
  • 16-bit fixed (RG) rg16fixed - 2 通道格式，R 和 G 有值，而 B 始终为 0，Alpha 为 1.0。每通道 16 位，每像素共 32 位。
  • 16-bit float (RG) rg16float - 2 通道格式，R 和 G 有值，而 B 始终为 0，Alpha 为 1.0。每通道 16 位，每像素共 32 位。
  • 32-bit float (RG) rg32float - 2 通道格式，R 和 G 有值，而 B 始终为 0，Alpha 为 1.0。每通道 32 位，每像素共 64 位。
  • 8-bit fixed (A) a8fixed - 仅 Alpha 的格式，每通道 8 位，每像素 8 位。
  • 16-bit fixed (A) a16fixed - 仅 Alpha 的格式，每通道 16 位，每像素 16 位。
  • 16-bit float (A) a16float - 仅 Alpha 的格式，每通道 16 位，每像素 16 位。
  • 32-bit float (A) a32float - 仅 Alpha 的格式，每通道 32 位，每像素 32 位。
  • 8-bit fixed (Mono+Alpha) monoalpha8fixed - 2 通道格式，一个值用于 RGB，一个值用于 Alpha。每通道 8 位，每像素 16 位。
  • 16-bit fixed (Mono+Alpha) monoalpha16fixed - 2 通道格式，一个值用于 RGB，一个值用于 Alpha。每通道 16 位，每像素 32 位。
  • 16-bit float (Mono+Alpha) monoalpha16float - 2 通道格式，一个值用于 RGB，一个值用于 Alpha。每通道 16 位，每像素 32 位。
  • 32-bit float (Mono+Alpha) monoalpha32float - 2 通道格式，一个值用于 RGB，一个值用于 Alpha。每通道 32 位，每像素 64 位。
Parameter Color Space parmcolorspace - - 控制如何解释此节点上的所有颜色参数。仅在项目启用了 Working Color Space 时可用。颜色值被视为处于所选色彩空间中，并在作为节点运算的一部分使用之前转换为 Working Color Space。注意这不会改变节点自身的色彩空间，因为它始终处于 Working Color Space。
  • sRGB srgb - sRGB 色彩空间，使用 sRGB 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • sRGB - Linear srgblinear - sRGB 色彩空间，使用线性传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.601 (NTSC) rec601ntsc - Rec.601，NTSC 原色色彩空间，使用 Rec.601 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.709 rec709 - Rec.709 色彩空间，使用 Rec.709（与 Rec.2020 相同）传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.2020 rec2020 - Rec.2020 色彩空间，使用 Rec.2020（与 Rec.709 相同）传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 dcip3 - DCI-P3 色彩空间，D65 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 (D60) dcip3d60 - DCI-P3 "D60 sim" 色彩空间，D60 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Display-P3 (D65) displayp3d65 - Display-P3 色彩空间，D65 白点，sRGB gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACES2065-1 aces2065-1 - ACES 2065-1（也称为 ACES AP0）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACEScg acescg - ACEScg（也称为 ACES AP1）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Passthrough passthrough - 选中后，颜色值将按原样用于运算，不作任何修改，也不尝试将其转换到 Working Color Space。
Parameter Reference White parmreferencewhite - - 在将参数颜色值转换为 Working Color Space 时，此项控制相对于 Reference White 应如何处理。如果 Working Color Space 的 Reference White 相同，则不做调整。如果不同，则此颜色的 Reference White 级别（亮度）将被调整到 Working Color Space 所期望的范围。例如，如果项目将 SDR Reference White 设为 120 nits，而 HDR Reference White 为 80 nits，那么 (1, 1, 1) 的颜色在 SDR 色彩空间中为 120 nits，将被转换为 (1.5, 1.5, 1.5)，在 HDR Working Color Space 中仍为 120 nits。
  • Default For Color Space default - 将根据所选的色彩空间使用 SDR 或 HDR Reference White。
  • Use Parent Panel useparent - 将使用父级面板所选的 Reference White。如果顶层面板也选择了「Use Parent」，则将使用「UI Reference White」。
  • Standard (SDR) sdr - 会将 Parameter Color Space 的 Reference White 值按 SDR 处理。
  • High (HDR) hdr - 会将 Parameter Color Space 的 Reference White 值按 HDR 处理。
  • UI ui - 会将 Parameter Color Space 的 Reference White 值按 UI 处理。其亮度使用「UI Reference White Nits」的值。

Info CHOP 通道

可通过 Info CHOP 访问 Render Simple TOP 的额外信息。

TOP 通用信息通道

  • resx - TOP 的水平分辨率，以像素为单位。
  • resy - TOP 的垂直分辨率，以像素为单位。
  • aspectx - TOP 的水平宽高比。
  • aspecty - TOP 的垂直宽高比。
  • depth - 如果此 TOP 包含 2D 或 3D 纹理数组，则为该 2D 或 3D 数组的深度。
  • gpu_memory_used - 此 TOP 使用的纹理内存总量。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
