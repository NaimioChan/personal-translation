Component

摘要

另请参阅 Category:Components，了解与组件相关的完整文章列表。

与其他操作符族相比，Components（或 COMPs）的独特之处在于它们包含自己的网络。要在项目中新建网络，用 OP Create Menu 创建一个新组件，并从 COMP 标签页中选择。然后进入你的新组件，开始搭建网络。组件网络可以包含操作符和/或额外的子网络（额外的组件）。子网络创建了可以导航的网络层级（使用 network path），并构成 .toe/.tox 文件的整体层级结构。


COMP Class

组件类型

组件有两种特殊的子Families：Object Components 和 Panel Components，以及许多其他组件。它们在 OP Create 菜单中分四列列出。

Object 组件（用于渲染的 3D 对象）

  • Ambient Light COMP
  • Blend COMP
  • Bone COMP
  • Camera COMP
  • Camera Blend COMP
  • Environment Light COMP
  • Nvidia Flow Emitter COMP
  • Geometry COMP
  • Handle COMP
  • Light COMP
  • Null COMP
  • Shared Mem In COMP
  • Shared Mem Out COMP
  • FBX COMP
  • USD COMP

Object 组件可以通过垂直连接（使用节点顶部和底部的连接器）建立父子层级。

ObjectCOMP_Class

Panel 组件（可交互的 2D 面板）

  • Button COMP
  • Container COMP
  • Field COMP
  • List COMP
  • OP Viewer COMP
  • Parameter COMP
  • Select COMP
  • Slider COMP
  • Table COMP
  • Widget COMP

Panel 组件可以通过垂直连接（使用节点顶部和底部的连接器）建立父子层级。

PanelCOMP_Class

其他组件

  • Base COMP - Base COMP 没有面板控件，也没有对象控件。它是组件最基本的空壳，在需要新网络时可以使用。
  • Engine COMP - Engine COMP 会在单独的进程中运行 .tox 文件（组件）。
  • Time COMP - Time COMP 包含一个操作符网络，可以驱动 Timeline、驱动 Animation COMP 中的动画，或用于驱动任何自定义的基于时间的系统。
  • Animation COMP - Animation COMP 用于创建关键帧动画数据。关键帧通道存储在组件内部，可以通过在 Animation Editor 中 scope Animation COMP 来编辑。
  • Replicator COMP - Replicator COMP 会为表格的每一行创建一个节点，并随表格变化添加和删除节点（「replicant」）。
  • Window COMP - Window COMP 创建一个单独的浮动应用程序窗口。可用于 control panels，或在输出到 multiple monitors 时使用。

组件的输入与输出

如果组件的网络包含 In 和/或 Out 操作符（大多数类型：TOP、CHOP、SOP、DAT，例如 In TOP 和 Out CHOP），组件的节点左右两侧就可以有操作符输入和输出。

这些让操作符数据流入和流出组件的网络，使组件能与其它组件、操作符以及项目的其他部分共享其内部数据。在组件内添加这些 OP 会在组件左右两侧添加按字母数字排序的输入/输出，数据可以流经它们。输入在组件左侧，输出在右侧。

当光标悬停在组件的某个输出上时，会显示输出预览窗口。在输出预览上 MMB 可查看该输出的信息。在输出预览上 RMB 会弹出 OP Create 菜单。

组件标记

组件左侧有 4 个通用 Flags：Viewer Flag、Clone Immune Flag、Cooking Flag 和 Lock Flag。Object Components 还有一个 Bypass Flag，并在其右下角另有 3 个标记：Pickable Flag（橙色）、Render Flag（紫色）和 Display Flag（蓝色）。

将组件保存为文件

你可以在节点上用右键 → Save Component 把组件保存为 .tox file。这对与其他 TouchDesigner 用户和项目共享网络很方便。你在 TouchDesigner 中创建的任何常用工具或网络都是组件的合适候选。

要把图像等其他文件嵌入 .tox 文件，参见 Virtual File System (VFS)。
