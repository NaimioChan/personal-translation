Widgets Release Notes

概述

Widgets 是一组用于构建用户界面的扩展组件。目前所有 Widget 都包含在 Widget 组件中，这些组件属于 Panel 组件族。Widget 组件派生自 Container 组件，以支持通用 Widget 实现可能需要的特定功能，不过迄今尚未在其前身之外添加任何功能。

Widgets 的首次发布是当前正在开发的更大、功能更丰富系统的精简版本。该精简版本称为「Basic Widgets」。功能更丰富的系统称为「Advanced Widgets」。预计「Basic Widgets」和「Advanced Widgets」将在未来作为并行系统同时存在。

「Basic Widgets」相比「Advanced Widgets」的主要优势在于，「Basic Widgets」不附带自定义 Python 扩展代码。这让「Basic Widgets」在升级到新版 TouchDesigner 时更不易出问题，因为「Basic Widgets」是自包含组件，而「Advanced Widgets」将依赖一个外部组件，该组件包含一系列集中功能和一套使用 Python 扩展系统开发的、不断演进的功能。

「Basic Widgets」更像旧的「TUIK」系统，那只是一个独立组件文件夹。「Advanced Widgets」将支持更现代的工作流，并提供一系列配套用户界面，用于快速开发完整的 TouchDesigner 应用。

Basic Widgets 是从 Advanced Widgets 中提取出来的，因此各 Widget 的名称与核心功能应始终保持一致。由于「Advanced Widgets」尚未公开，目前无需了解更多。以下 Wiki 文章会在适当时说明更多差异，并会随更多功能推出而持续演进。

Widgets

Widgets 分为两大组：Master Widgets 和 Main Widgets。Master Widgets 是单一功能性的用户界面元素，例如标签、按钮、复选框或输入框。Master Widget 组件始终只包含一个元素。之所以称为 Master，是因为它们是克隆母版组件，构成更大、更全面的 Main 组。

Widgets 设计为只从顶层参数使用。构成 Widget 的内部网络不应修改。更新 Widget 时，对 Widget 内部的任何更改都会丢失。无需进入 Widget 内部来定制外观或提取信息。Widget 的顶层参数应提供使用该用户界面元素所需的全部工具。

在哪里找到 Widgets

Widgets 位于调色板的 Derivative > UI > Basic Widgets 下

不要进入或修改 Widget 的内部网络

Widgets 的核心设计范式之一就是系统必须可升级。先前的用户界面工具包 TUIK 不可升级。组件一旦部署到更大的系统中，就基本「失落在太空中」。如果该组件有 bug 或需要新功能，唯一的更新方式就是回到调色板找到更新后的组件，手动替换。

「Basic Widgets」和「Advanced Widgets」都支持自动升级。两者的流程略有不同，但无论哪种情况，Widget 都会被克隆，因此其内部网络会被清空，并替换为原 Widget 的克隆母版。所以更新后，对 Widget 内部的所有更改都会丢失。

如果我想给 Widget 补充缺陷、修 bug 或添加功能怎么办？

若希望更改某个 Widget，应像 TouchDesigner 中其他任何操作符一样，在论坛或 Derivative 支持处提出请求。从这个意义上说，Widgets 是一个封闭系统，就像 Wave CHOP 或 Movie TOP 也是封闭系统一样。

如果我想自己做 Widget 怎么办？

Advanced Widgets 将支持构建自定义 Widget Kit。因此你可以利用相同的底层 Widget 架构来设计自己的 Widget 套件。「Basic Widgets」中的所有 Widget 都提取自 TDWidgetKit 组件。TDWidgetKit 将是 Derivative 开发和维护的第一个用户界面套件。你将能使用同一 Advanced Widget 系统制作并维护自己的套件。

通用属性

Widgets 有一系列通用属性。这些通用特性如下所述：

  • 所有 Widget 都包含在 Widget COMP 中。
  • 所有 Widget 都有自定义参数页。
  • 所有 Widget 都有一个 Widget 页，控制 Widget 的通用功能。
  • 所有 Widget 都有控制特定 Widget 类型的自定义页。例如 Label Widget 有一个 Label 页，控制 Label 的外观。
  • 所有「Basic Widgets」都带有 TDBasicWidget 标记。
  • 查看 Common 页上的 Clone Master 参数，即可找到所有 Widget 对其原始母版 Widget 的引用。
  • 所有 Widget 都定义了一个名为 “Widget” 的 Parent Shortcut。
  • 大多数（但并非所有）Widget 都有值。
  • Widget 的值最多为四个。
  • Widget 的值位于 Values 页。
  • Widget 的值会从组件输出传出。
  • 数值型 Widget 会通过 CHOP 输出传出值。
  • 字符串型 Widget 有 DAT 输出。
  • 菜单型 Widget 有 CHOP 和 DAT 输出。

Widget 值

Widget 最多可容纳 4 个值。因此一个 Widget 可以为 TouchDesigner 支持的所有值类型提供用户界面。TouchDesigner 支持的值类型如下：

  • Float1
  • Float2
  • Float3
  • Float4
  • Int1
  • Int2
  • Int3
  • Int4
  • String
  • Boolean

Values 页

Widget 值位于 Widget 参数的第一个自定义页上。该页名为 Values。如果某个 Widget 没有 Values 页，则它没有值——例如 Label、Header 或 Footer 就没有值。

值参数

Widget 值位于 Values 页，根据维度 1 到 4，存放值的参数分别为 Value0、Value1、Value2 和 Value3。因此，一个存放 Red Green Blue Alpha 值的 RGBA Color Widget 会把 Red 存到 Value0 参数，Blue 存到 Value1 参数，Green 存到 Value2 参数，Alpha 存到 Value3 参数。

值名称

值有一个名称，即通过 Widget 的 CHOP 或 DAT 输出传出的名称。

自定义值范围和默认值

Basic Widgets 只支持通过 Customize Component 对话框更改参数值。Advanced Widgets 提供了更便捷的功能，可设置默认值、范围和钳制行为。

更新 Widgets

要更新 Basic Widgets，必须加载 basicWidgets 组件。该组件包含整套 widget，并与内置的 op.TDUpdater 组件配合工作。

basicWidgets 组件位于 Derivative > UI > BasicWidgets 调色板文件夹中。它是该文件夹中唯一的组件，名为 basicWidgets。

要更新到较新版本，只需将 basicWidgets 拖入你的文件，然后点击 “Update Deployed” 按钮。每个文件只能加载一个 basicWidgets 组件。如果已加载了另一个组件，会收到警告错误 “Multiply defined Global OP Shortcuts”。若出现此错误，找到另一个 basicWidgets 组件并删除它即可。

更新时打开 Textport 以查看进度。完成后可以删除 basicWidgets 组件。

Widget 类型

TDWidgetKit 的 Master 与 Main

Basic Widgets 提取自 Advanced Widget 系统，来自 Derivative 设计的 Widget 套件 TDWidgetKit。在 Advanced 系统中查看时，Master Widgets 与 Main Widgets 的区别会更清楚。不过这两组在 Basic Widgets 调色板文件夹中由两个子文件夹区分。

WidgetKit Masters 是包含单一 UI 元素的 Widget。这些单一元素会被克隆，并作为部件复用于 Main 组 Widget 中。例如，masterButton Widget 包含按钮子组件，该子组件用于许多 Main 按钮 widget，如 buttonMomentary、buttonToggle 和 buttonState。masterSlider Widget 子组件可在 Main 组中的 sliderHorz、sliderHorzXFade 以及所有颜色滑块 Widget 中找到。

这些母版子组件自带一组参数页，会体现在 Widget 参数上。例如，masterLabel Widget 子组件带有 Label 和 Label Align 页。masterButton Widget 子组件带有 Button 和 Button Align 参数页。buttonMomentary Widget 同时包含 masterLabel 子组件和 masterButton 子组件，因此它有 Label、Label Align、Button 和 Button Align 这些 Widget 页。

Master Widgets

Master Widgets 只包含一个 Widget 子组件。因此每个 masterWidget 只有 Values 页、适用时的 Widget 页，以及它所包含的 Widget 子组件的参数页。

窗口部件与标签

这些 Widget 没有值。它们是非常基础的标签和分区标题。

masterHeader

只是用于面板或一组 widget 顶部的标题栏。

masterFooter

只是用于面板或一组 widget 底部的页脚。

masterLabel

masterLabel widget 包含标签子组件，该子组件用于所有 Main Widgets。

masterSection

这是一个分区控件，可用于创建可折叠的 Widget 分区。

masterValueLabel

值标签是一种较小的值标签，用于有多个值的 Widget，例如 RGB 和 HSV 颜色滑块。

按钮与开关

Buttons and Toggles 通常保存布尔值或 0 或 1 的整数值。不过 masterButtonPush Widget 没有值。

masterButton

这是适用于大多数用例的标准按钮 Widget。它有一个值，并可通过设置 Button 页的 Type 参数来支持多种按钮行为。

masterButtonPush

此按钮没有值，是一个简单的瞬态按钮，通常用于 Main 部分中复合 Widget 需要按钮支持某种行为的场合。例如 fieldFileBrowser 和 fieldFolderBrowser 使用此子组件来启动操作系统浏览器。

masterRadioButton

此 Widget 有一个整数值，该整数值表示当前激活的是哪个单选按钮。使用 Button 页的 Button Labels 参数来定义标签及所需按钮数量。标签之间用空格分隔。若标签名称中含空格，请使用引号。

masterCheckbox

保存单个布尔值参数，并支持通用复选框行为。

masterRocker

保存单个布尔值参数，并支持与内置 Toggle 自定义参数类似的行为。

输入框

masterNumericField

提供一个用于存储浮点或整数值类型的单一值。在设置浮点或整数值类型时，必须使用 Field 页的 Field Type 参数，并使用组件编辑器将 Value 参数设为正确的参数类型。为避免这些问题，强烈建议使用预先设置好的 Main widget，即 float1、float2…… int1、int2 参数。Advanced Widgets 将更好地支持轻松更改值类型。

masterStringField

这是用于设置和存储 String 值的主要 Widget。

滑块

滑块是一大类 Widget，用于通过移动鼠标选择并交互式改变值。

masterSlider

masterSlider 支持 float 和 integer 值类型。在 Basic Widgets 中，必须使用组件编辑器来修改范围和 Value Type 值参数。

masterSlider2D

此 Widget 同时控制 2 个值。在 Basic Widgets 中，必须使用组件编辑器来修改滑块的范围和值类型。

masterRange

此 Widget 同时控制 2 个值，并支持 float 和 integer 值类型。在 Basic Widgets 中，必须使用组件编辑器来修改范围和 Value Type 值参数。它适合控制起始与结束或最小值与最大值这类范围。

masterKnob

此 Widget 控制单个值，并支持 float 和 integer 值类型。在 Basic Widgets 中，必须使用组件编辑器来修改范围和 Value Type 值参数。

OP 引用

masterReferenceOP

此 Widget 仍在变动中。使用风险自负。下个版本将有更新。更新会生效，但可能导致数据丢失。

项目菜单

这一类 Widget 使用 Menu 页的 Menu Names 参数定义。它们保存单个字符串值。每个名称用空格分隔。在 TouchDesigner 中，所有参数菜单都有菜单名（小写且不含空格），以及可以含空格的菜单标签。因此菜单 Widget 遵循这一要求。要定义菜单名，请使用 Menu 页的 Menu Names 参数。每个名称用空格分隔。要为可视化弹出菜单定义不同的标签名，请使用 Menu Labels 页设置不同名称。此处个别标签可以使用空格，但需用引号把字符串括起来。

masterFolderTabs

支持返回字符串的菜单 Value 参数。每个文件夹标签页都用 Menu 页的 Menu Names 参数定义，方式如上方 Item Menus 标题小节所述。

masterDropMenu

支持返回字符串的菜单 Value 参数。每个菜单项都用 Menu 页的 Menu Names 参数定义，方式如上方 Item Menus 标题小节所述。

列表

List Widgets 不保存值，因为列表的定义及其行为相当复杂。目前请参阅此处：https://www.derivative.ca/wiki099old/index.php?title=Palette:lister

推荐工作流

widget 系统正处在一套处理组件构建与 TouchDesigner 中通用创作的新范式中心。widget 系统现在才开始推出，因为一些必要的核心功能终于完成，其中最新的一项是参数绑定。这一新工作流范式将在未来一年内分阶段推出。

此次推出的第一阶段是 Basic Widgets。Basic Widgets 的推出方式遵循构建用户界面的传统流程（TUIK），即使用网络编辑器和面板组件手动组装它们。然而一旦 Advanced Widgets 开始推出，构建 TouchDesigner 面板和组件时的大量繁琐工作将被自动化，并由所见即所得的交互式面板创作界面所增强。

这一自动化工作流遵循特定的方法论，该方法论也可以手动执行。许多 TouchDesigner 开发者在构建组件时已经在不同程度上遵循这一方法论。一旦 Advanced Widgets 完全推出，该工作流与组件架构将被所有用该系统开发的组件共享。这反过来会提高用户开发组件之间的兼容性，也更便于阅读其他设计师的作品，因为所有组件都将遵循同一范式。

因此，理解这一工作流很重要，它能让人更容易阅读和理解网络，也为在 TouchDesigner 中工作和构建系统提供了清晰且经过充分检验的方法。

与 widget 工作相关的关键特性包括……

  • Parent shortcut 与 OP shortcut
  • 自定义参数
  • 组件布局改进
  • 参数绑定
  • 参数优化 - 参数缓存

添加 Material Design 图标

Widgets 支持 Unicode 图标字体以及普通字体。TouchDesigner 包含Material Design Icons字体，可用于在通常放文本的地方创建美观的图标。只要所选字体支持相应 Unicode 码，任何标签参数都能接受 Unicode 字符串。

使用 Material Design Icons

要挑选图标，请在 Material Design Icons Cheat Sheet 的图标列表中浏览。TouchDesigner 2020.40000 系列版本附带 Material Design Icons 5.3.45 版。点击这里的 cheat sheet 按钮访问对照表：https://materialdesignicons.com - 图标字体库经常更新，请确保使用与所附带版本对应的对照表。较新版本会包含旧版本中没有的图标，也可能替换某些图标。

单击每个图标缩略图旁的 HexCode，它会把十六进制字符串复制到剪贴板。复制的字符串只是一个十六进制索引号，但必须在普通字符串前加 '0x'，使其成为 Python 兼容的十六进制格式。例如，若复制的十六进制码为 'F0EF4'，则 Python 十六进制写法为 0xF0EF4。因此在 TouchDesigner 中，把该十六进制字符串码粘贴到如下格式的表达式中……

chr(0xPASTE)

或者更具体地，对于 'F0EF4' 的情况

chr(0xF0EF4)
