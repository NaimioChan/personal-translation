Spring SOP

摘要

Spring SOP 使用多边形边缘上的弹簧「力」以及附着在每个点上的质量块，对输入的几何进行变形和移动。

几何通过模拟点与边上简单物理的力进行变形。每个点被赋予一个模拟的「质量」。其图元边缘充当「弹簧」，抵抗这些力并把点拉回原始位置。当力使弹簧拉伸时，弹簧会把点拉回。不过点回到原始位置后并不会停止运动，而会因自身质量继续振荡，直到振荡消失。

作用在点上的力如下：

外力（重力）
风（类似外力）
湍流（混沌力）

drag 值越大，或质量越小，振荡消失得越快。

参数 - State 页

Preroll Time timepreroll - 到达重置时间后，要跳过多少秒的模拟。例如，如果你在此栏输入 33（重置在 $TSTART），第一帧将显示时间为 33 秒时的模拟。换句话说，前 32 秒被跳过，33 秒处的时刻被移到第一帧。前 32 秒仍然必须计算，以得出点的状态，所以重置时你会注意到一些延迟。
Time Inc timeinc - Time Inc 参数决定 SOP 的计算频率。默认情况下，该参数设为 1/$FPS，意味着 SOP 每帧计算一次。涉及复杂动力学时，SOP 可能需要更频繁的计算以提高数学精度。要在计算中获得亚帧精度，可把 Time Inc 设为小于 1/$FPS 的值。例如把 Time Inc 设为 0.5/$FPS 就表示 SOP 每帧计算两次。

注意： 切勿把此参数设得大于 1/$FPS。

Accurate Moves accurate - 此选项通过计算分数帧值下的轨迹，使节点在帧之间的运动更精确。
Attractor Use attractmode - 描述如何为每个粒子分配吸引点。
  • All Points all - 所有点吸引器影响所有粒子（或点）。
  • Single Point per Particle single - 启用时，每个粒子被分配单个吸引点，并且只受该点影响。分配方式是点编号对吸引点总数取模。
Reset reset - On 期间重置 SOP 的弹簧效果。
Reset Pulse resetpulse - 立即重置弹簧效果。

参数 - Nodes 页

Fixed Points fixed - 这是一个点组。点组中的所有点都不受这些力影响。有关如何指定点范围的说明，另见 Group SOP。
Fixed Points go to Source Positions revertfixed - 决定 Fixed Points 组中的点是否应移动到 Source 几何中对应点的位置。
Copy Groups from Source copygroups - 决定 Spring SOP 是否每帧从 Source 几何复制组。这让你可以在 Fixed Points 栏中指定一个动画组的名称，该组的内容会保持更新。
Add Mass Attribute domass - 选中时，为变形中的几何计算 Mass。
Mass mass - 每个点的 Mass。较重的点需要更长时间才动起来，也更难停下。
Add Drag Attribute dodrag - 选中时，几何按 Drag 属性变形。
Drag drag - 每个点的 Drag。
Spring Behavior springbehavior - 弹簧的行为方式：
  • Hooke's Law hooke - 弹簧按胡克定律工作。这通常比 Normalized Displacement 更稳定。
Hooke's Law：力 = 位移 弹簧常数
  • Normalize Displacement normalize - 与 Hooke's Law 类似，只是位移按弹簧的原始长度归一化。
Spring Constant springk - 弹簧常数，即弹簧的紧度。增大该值会让弹簧更紧，物体更有刚性。数值越高，弹簧可能失控振荡。出现这种情况时降低 Time Inc。
Initial Tension tension - 几何在经受弹簧操作变形之前的初始 k 常数。

  • X limitnegx -
  • Y limitnegy -
  • Z limitnegz -
Hit Behavior hit - 控制几何碰到六个碰撞平面或碰撞对象时会发生什么。选项有：
  • Bounce on Contact bounce - 几何接触 Collision 输入时会弹回。
  • Stick on Contact stick - 几何接触 Collision 输入时会粘住。
Gain Tangent gaintan - 摩擦参数，可视为碰撞时的能量损失。第一个参数影响垂直于表面的能量损失（增益）。0 表示所有能量（速度）都损失，1 表示垂直于表面方向不损失能量。第二个参数是沿表面切线方向的能量增益。
Gain Normal gainnorm - 摩擦参数，可视为碰撞时的能量损失。第一个参数影响垂直于表面的能量损失（增益）。0 表示所有能量（速度）都损失，1 表示垂直于表面方向不损失能量。第二个参数是沿表面切线方向的能量增益。

Info CHOP 通道

Spring SOP 的额外信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
