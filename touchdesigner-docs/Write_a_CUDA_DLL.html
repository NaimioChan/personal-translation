编写 CUDA DLL

概述

CUDA 是 NVIDIA 开发的一种编程语言，让开发者能够以远比仅用于图形更通用的方式利用 GPUs 的能力。关于 CUDA 的更多细节可在 CUDA Homepage 中找到。

使用 TouchDesigner 作为编写 CUDA 的工具有很多好处。它允许你使用 TouchDesigner 已有的所有工具来创建、加载、操作、保存和可视化你传入和送出 CUDA 程序的数据。例如，如果你想编写一个对音频数据做某些处理的 CUDA 程序，不必编写使用外部 API 加载音频的代码，只需将音频加载到 CHOP 中，再将数据传入 CUDA 程序。同样，不必编写自己的 OpenGL 代码来可视化 CUDA 程序的输出，可以使用 TouchDesigner 已有的工具来可视化。

如果你有兴趣编写 CUDA，一个好的起点是 CUDA SDK 中包含的 CUDA Programming Guide。

The official 2020.20000 series release of TouchDesigner currently uses version 10.0 of the CUDA toolkit, make sure you download that version, even if a newer one is available. 不同 TouchDesigner 版本支持的 CUDA 版本请参见 here。

CUDA 现已通过 CPlusPlus TOP 获得完整支持。CUDA TOP 不再受支持。更多信息参见 Category:C++ 中的文章。
