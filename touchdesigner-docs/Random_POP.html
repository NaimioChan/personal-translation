Random POP

摘要

Random POP 接受其输入，并（1）生成包含随机值的新属性，或（2）为每个点用随机值设置、相加或相乘现有属性。

随机值可应用于点、顶点或图元属性。

默认情况下，随机值在 0 到 1 之间均匀分布，但通过 Type 菜单可以控制多种其他分布。包括 Gaussian（也称为 Normal）分布（大多数点靠近范围中心）、以各自概率随机选取的两个值（Two Values）、始终长度为 1 的随机方向向量（在一定锥角内）、单位球内的随机 float3 向量，以及 Exponential（在每个轴上分别于 0 以上呈指数衰减）。

随机值可以在指定范围（Value A 和 Value B）内生成，然后可选地在两个值之间钳制。

有一个选项可以为每个输入点生成 2 个或更多点，以增加源点周围的点密度。（Extra Points per Source Point）

随机值也可以限制在特定的点、顶点或图元组中。

提示：通过使用 Projection POP，在极坐标空间中生成随机数并转换为笛卡尔坐标，你可以获得围绕某点的径向随机分布。

Per-point mapping of parameters - Random POP 有一个 Map 页，允许每个点在 Amplitude、Offset、Exponent、Period、Value A 和 B 等参数上获得不同的值。在此机制中，输入中的单独属性包含覆盖（或相加/相乘）参数值的值。见 Mapping POP Attributes to Parameters。

另请参阅 Point Generator POP、Noise POP

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
