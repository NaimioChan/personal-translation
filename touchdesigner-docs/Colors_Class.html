Colors 类

Colors 类描述应用程序的颜色。它可以从全局 ui 对象访问。

成员

没有该操作符专属的成员。

方法

resetToDefaults()→ None:

把颜色设为其默认值。

特殊函数

Colors 类是一个可迭代对象，包含一组具名颜色属性。定义了 len、下标和赋值操作符。

每个名称都可用于获取或设置对应该颜色的三个值。

len(Colors)→ int:

返回颜色选项的总数。 

a = len(ui.colors)

[<color option name>]→ triplet(r,g,b):

给定字符串键，获取或设置特定的颜色选项。 

n = ui.colors['default.bg']
ui.colors['default.bg'] = (1,0,0)

Iterator→ str:

遍历每个颜色选项名称。 

for n in ui.colors:
	print(n)
	ui.colors[n] = myColorsList[n]
