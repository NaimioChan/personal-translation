MIDI In CHOP

摘要

MIDI In CHOP 从 MIDI 设备和文件中读取 Note 事件、Controller 事件、Program Change 事件、System Exclusive 消息和时序事件。另请参阅 MIDI In Map CHOP。

MIDI In CHOP 从连接到串口的 MIDI 设备接收 MIDI 事件，读取工作站内部的 MIDI 事件（即内置软件合成器），并解析 MIDI 文件中的乐谱。支持的 MIDI 事件包括：

Note On、Note Off
Polyphonic Aftertouch
Channel Pressure
Program Change
Control Change（MIDI 控制器设备）
Pitch Wheel
Timer Events，包括拍脉冲
Bar Messages
Start、Stop、Continue
Song Position Pointer
System Exclusive Messages

在各自 MIDI 通道上到达的 MIDI 事件可以记录到各自的 CHOP 通道上。此外，任意数量的 MIDI CHOP 都可以从相同或不同的来源读取。TouchDesigner 可以配置为让 MIDI Start、Stop 或 Continue 事件控制 Timeline 和 Beat Dialog。

'Simplified Output' 选项会为收到的每种 MIDI 事件创建一个通道，因此在使用设备期间通道数量会不断增加。无需指定名称、通道和索引模式。

'Note-On Only Channels' 参数适用于只发送 Note On 事件的 MIDI 设备，它允许自动追加 Note Off 事件，从而产生单个采样的脉冲。

带时间戳的高频 MIDI 事件

到达速度快于时间轴帧率（通常为每秒 60 帧）的 MIDI 事件可以被捕获，并表示为设为每秒 1000 个采样的 CHOP 通道。

创建 MIDI In CHOP，将 Mode 设为 "Automatic High Frequency"，连接到 Trail CHOP，在查看器中打开 Dots，然后快速推动滑块，观察采样变化的密集程度。

查看 MIDI In DAT 和 MIDI Event DAT，它们捕获所有 MIDI 事件，并在表格列中以多种形式报告其时间戳。

注意：MIDI 输入的值会保存到 TouchDesigner .toe 文件中，并在文件重新加载时恢复。重新启动 .toe 时，物理控制器可能处于不同的位置，因此在移动控制器时数值会跳变。这无法避免。

另请参阅 MIDI In DAT、MIDI Event DAT、MIDI In Map CHOP、MIDI Out CHOP。

midiinCHOP_Class

参数 - Source 页

Active active - 启用或禁用 MIDI In CHOP。
Mode mode - - 设置此 CHOP 的行为模式。
  • Automatic auto - 当从所选 MIDI 设备检测到 MIDI 信号时，会自动创建通道。此前需通过打开 'Simplified' 参数来实现。
  • Automatic High Frequency autohighf - 此模式可捕获高频 MIDI 事件，即到达速度快于时间轴帧率的事件。将 CHOP 采样率设为 1000hz 这样的高值，即可在每帧捕获多个 MIDI 事件。'Resample Mode' 菜单进一步控制一帧内收到的所有 MIDI 事件如何分布到各个采样上。
  • Manual manual - 此模式可手动控制创建哪些 MIDI 通道以及捕获哪些值。此前需通过关闭 'Simplified' 参数来实现。
Resample Mode resamplemode - - 设置一帧内收到的高频 MIDI 事件如何在 CHOP 的整个长度上分布。仅在 'Automatic High Frequency' 模式下启用。
  • Evenly Spaced even - 一帧内收到的所有 MIDI 事件在 CHOP 的整个长度上均匀分布。此模式不保留帧内事件之间的时间步长。
  • Preserve Duty preserveduty - 一帧内收到的 MIDI 事件根据事件之间的时间步长近似分布。两帧之间事件的时间步长也得到更好的保留。此模式适用于快速脉冲或方波的情况。
MIDI Source source - - 从设备或文件获取 MIDI 输入。
  • Device device - MIDI 事件实时来自设备。
  • File file - MIDI 事件来自现有文件。
Device Table device - MIDI 设备的路径 Table DAT
Device ID id - 指定要使用的设备 id。
MIDI File file - 若选择 MIDI 文件作为 MIDI 来源，则用此字段指定要读取的 MIDI 文件名。文件可以从磁盘或从网络读取。指定 URL 时使用 http://。
Read Entire MIDI File entire - 若启用，则读取整个 MIDI 文件。否则由 Channel 页上的 Start 和 End 参数决定读取文件的哪一段。
Reset Channels resetchannels - 设为 On 时删除所有通道，在 Reset Channels 关闭之前不会添加新通道。
Reset Channels Pulse resetchannelspulse - 立即删除所有通道。
Reset Values resetvalues - 设为 On 时将所有通道值重置为 0，在 Reset Values 关闭之前通道值不会更新。
Reset Channels Pulse resetchannelspulse - 立即将所有通道重置为 0。
Preserve Pulses preservepulses - 开启时，快速的值变化（脉冲）会分散到连续的输出采样上。当脉冲频率接近或超过时间轴速率时使用此选项，否则它们可能相互重叠而丢失。
Note-On Only Channels noteonchan - 对于此参数中指定的通道，每收到一个 MIDI 事件后都会追加一个 Note-Off 事件。当 MIDI 通道只收到 Note-On 事件而没有后续 Note-Off 事件时，这很有用。
1 Based Index onebased - 使索引从 1 开始而非默认的从 0 开始，这意味着索引将属于 1-128 范围而非 0-127。此参数的值会影响 Note 和 Controller 索引。
MIDI Channels channel - 该 CHOP 可读取任意数量的 MIDI 通道，编号 1-16。支持范围和多项输入（即 "1 4 6"、"1-7 12"、"1-5:2"）。
如果 Channel Prefix 留空，则来自多个 MIDI 通道的输入流会合并为一组 CHOP 通道（即通道 12 上的 "note 64 on" 事件之后紧跟通道 8 上的 "note 64 off" 事件，在 note 64 CHOP 通道中会表现为单个音符）。
Channel Prefix prefix - 从多个 MIDI 通道录制时，在此参数中填入类似 "ch" 的字符串会使 MIDI 通道按 MIDI 通道拆分为各自的 CHOP 通道。否则所有 MIDI 通道会合并为一组 CHOP 通道。
Controller Format format - - 某些控制器可以配对成 14 位控制器，而不是常规的 7 位控制器（控制器索引 0-31、98 和 100）。选择 14 位 Controllers 会把一对消息解释为一个 14 位控制器。否则它们会被解释为各自独立的 7 位 Controller。
  • 7 bit Controllers 7bit - 假定 Controller 为常规的 7 位值消息。
  • 14 bit Controllers 14bit - Controller 以两条 7 位值消息的形式接收。

传入的消息必须遵循以下规范：

  • 两条消息中，一条是 MSB（最高有效字节），另一条是 LSB（最低有效字节），它们的值组合起来解释 14 位的值。
  • MSB 消息必须位于控制器范围 0-31 内。
  • LSB 消息必须位于控制器范围 32-63 内。其索引应为 MSB 索引 + 32。即，如果 MSB 消息的索引为 12，则 LSB 消息的索引必须为 44。
  • 此外，索引对 98、99 和 100、101 也可以用作 MSB、LSB 对。
  • 如果收到 0-63 范围内的单条消息，则不会输出任何内容。
  • 在此模式下，索引范围 64-95 内的消息会被解释为 7 位并照此输出，因为 64-95 范围保留给 7 位消息。

参数 - Record 页

此处的参数仅在 Source 页上的 'Simplied Output' 为 Off 时启用。

Record Method recordtype - - 确定要记录的内容。
  • Single Frame single - 仅输出音符、控制器等的当前值，不保留先前的值。它始终在第 1 帧创建 CHOP，因此只有在 MIDI 事件到来时该 CHOP 才会计算。
  • Current Frame current - 与 "Single Frame" 相同，但 CHOP 帧始终位于当前帧，因此该 CHOP 每帧都会变化，导致其他 CHOP 每帧都重新计算。
  • Current Time Slice ind - CHOP 帧始终位于当前 Time Slice。
  • Full Length timeline - 记录时间轴的整个长度。
Record record - 此参数用作按钮，用于开始和停止向 CHOP 通道录制。

参数 - Note 页

此处的参数仅在 Source 页上的 'Simplied Output' 为 Off 时启用。

Note Name notename - 在此填入 "n" 可为音符事件生成通道。它是用于记录音符的 CHOP 通道的基础名称。若留空，则忽略音符。若 Note Output 参数设为 Separate Channels，则会为 Note Scope 中的每个音符创建 CHOP 通道，形式为：notename
Note Scope notescope - 要记录的音符范围。可以记录多个范围和音符（即 "50-60"、"64 65 66 70-80"）。
Note Output notemeth - - 说明多个音符如何处理。（作为一个通道，或各自独立）。
  • One Multiplexed Channel mult - 每个 MIDI 通道使用一个 CHOP 通道来记录所有音符。音符通道中的值是当前正在演奏的音符编号（若有多个音符在演奏，则取最近的音符）。
  • Separate Channels sep - 每个音符编号都有自己的 CHOP 通道。
Velocity velocity - - 说明多个力度事件如何记录。（分到独立通道，或作为不同采样合并在一个通道中）。
  • Off veloff - 不记录力度。
  • Note Amplitude velencode - 力度记录为音符的振幅。仅在 Note Output 设为 Separate Channels 时有效。
  • Separate Channels velsep - 力度记录在独立的 CHOP 通道中。每个音符通道都会有一个对应的力度通道。
Velocity Name velname - 当 Velocity 设为 Separate Channels 时，此参数是 Velocity CHOP 通道的基础名称（可试 "v"）。若留空，则不记录力度通道。
Aftertouch Name aftername - 复音 Aftertouch CHOP 通道的基础名称。Note Scope 中的每个音符都会创建一个 aftertouch 通道。若留空，则不创建 aftertouch 通道。
Pressure Name pressname - Channel Pressure 通道的名称。若正在记录多个通道，所有关注的通道压力变化都会记录到此 CHOP 通道上。若留空，则不创建此通道。
Normalize notenorm - - 为方便起见，可以对音符值进行归一化：
  • None off - 当 Normalize 为 Off 时，7 位控制器返回 0-127 范围内的值，14 位控制器返回 0-16383 范围内的值。
  • 0 to 1 0to1 - 这些值会被归一化到 0 到 1 范围内。
Pitch Wheel Name pitchname - Pitch Wheel CHOP 通道的名称。Pitch wheel 值的范围为 -1 到 +1。若留空，则不创建此通道。在此填入 "p" 可生成一个通道。

参数 - Control 页

此处的参数仅在 Source 页上的 'Simplied Output' 为 Off 时启用。

Controller Name controlname - Control Change CHOP 通道的基础名称。通道名会追加控制器索引（0-127）。若留空，则不记录 control change。通常包含 "c"。
Controller Type controltype - - 共有 128 个不同的控制器可用。选择 By Index Only 后，可以在 Control Index 参数中指定任意数量的控制器。否则可以从此菜单的列表中选择一个控制器。某些控制器有多个实例，例如 Sound Controllers 1-10。选择有多个实例的控制器后，可以用 Control Index 参数选择所需的实例。任何无效的控制索引都会被忽略。
  • By Index Only index - 通过索引指定控制器，而不是在下方指定特定类型。
  • Bank Select n0 -
  • Modulation Wheel n1 -
  • Breath Control n2 -
  • Foot Controller n3 -
  • Portamento Time n4 -
  • Data Entry n5 -
  • Channel Volume n6 -
  • Balance n7 -
  • Pan n8 -
  • Expression Control n9 -
  • Effect Control 1-2 n10 -
  • 14 bit General Purpose 1-4 n11 -
  • Sustain on/off n12 -
  • Portamento on/off n13 -
  • Sustenuto on/off n14 -
  • Soft Pedal on/off n15 -
  • Legato Footswitch on/off n16 -
  • Hold 2 on/off n17 -
  • Sound Controller 1-10 n18 -
  • 7 bit General Purpose 5-8 n19 -
  • Portamento Control n20 -
  • Effect Depth 1-5 n21 -
  • Non-Registered Parameter n22 -
  • Registered Parameter n23 -
Controller Index controlind - 用于按编号选择控制器，或按范围选择多个控制器。在 By Index Only Controller Type 模式下，最多可选择全部 128 个控制器或其子范围（即 "1-10"、"2 34 70"、"1-32 70-80:2"）。
Normalize norm - - 为方便起见，可以对控制器值进行归一化：
  • None off - 当 Normalize 为 Off 时，7 位控制器返回 0-127 范围内的值，14 位控制器返回 0-16383 范围内的值。
  • 0 to 1 0to1 - 这些值会被归一化到 0 到 1 范围内。
  • -1 to 1 -1to1 - 这些值会被归一化到 -1 到 +1 范围内。
  • On/Off onoff - 其中有些控制器只是开/关状态。启用 Convert to On/Off 后，大于等于 64 的值会被解释为 "1"，所有小于 64 的值会被解释为 "0"。
Unwrap unwrap - 开启时，值不会在最小值和最大值之间跳变，而是被修改为连续的斜坡。例如可与旋钮控制器配合使用。
Program Change progname - Program Change CHOP 通道的名称。所有 program change 消息都会记录到此通道上。若留空，则不创建此通道。

参数 - Chan 页

这与其他生成器的 Channel 页类似。但有几处需要考虑它们对 Midi In CHOP 的影响。

Start start - 定义录制的起始位置。在 "Tie to Time Line" 模式下，起始时间之前收到的事件都会被忽略。在 "Time Line Independent" 模式下，录制将从该点开始并持续进行（不循环回来）。若从 MIDI 文件读取，Start/End 将决定读取片段的起点。

区间的起点和终点，以 Unit（秒、帧或采样）表示。这些参数以 Common 页上的 Units 表示。若要将 CHOP 设为 100 个采样的长度，请将 Units 设为 Samples、Single Frame 设为 Off，并将 Start / End 设为 0 和 99。

Start Unit startunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
  • I samples - 使用采样。
  • F frames - 使用帧。
  • S seconds - 使用秒。
End end - 定义对 MIDI 文件要读取的片段的终点。
End Unit endunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
  • I samples - 使用采样。
  • F frames - 使用帧。
  • S seconds - 使用秒。
Sample Rate rate - 定义此 CHOP 的采样率，单位为每秒采样数。若采样率过低，快速变化的输入可能被错误表示。

注意：若采样率过低，可能会漏掉 MIDI 事件。一个音符事件可能将某个采样值设为 1，而不到 1/30 秒后的下一个音符事件又会在 CHOP 通道的同一采样上将其设为 0。这样该事件就会被漏掉。可将采样率调高，例如 600，以捕获这些事件；或确保传入的开/关事件之间有最小时间间隔，这可通过 Opcode 的 MAX 实现。

Extend Left left - 左侧 extend 条件（范围之前）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道起点之前的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Extend Right right - 右侧 extend 条件（范围之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道终点之后的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Default Value defval - 用于 Default Value extend 条件的值。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

MIDI In CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
