绑定

绑定是一种 Parameter Mode，它将两个或多个参数的值关联在一起，改变其中任一已绑定参数的值都会改变全部。实际值只存储在一处，即绑定链顶端的那个值，称为 bind master。参数可以是 bind references、bind master，或两者兼是。

Table cells、Bind CHOP channels、Panel Values 和 Dependency objects 也可以与参数绑定，但只能作为 bind master，因为它们没有可设置 bind 表达式的位置。

bind chain 是由绑定连接起来的相互关联的值的树。一个 bind master 可以有多个 bind reference，其中每个也可以是其他参数的 bind master。换言之，可以把一个或多个 bind reference 绑定到一个 bind master，也可以建立一条链：参数 C 是参数 B 的 bind reference，而参数 B 是参数 A 的 bind reference。

bind reference 是位于第四个「Bind」Parameter Mode 中的参数，在参数对话框中以紫色文字显示。bind reference 的 bind expression 会解析为其 master。它只能通过其 UI、其 val 属性或其 bind master 来更改。bind reference 不使用其 constant、expression 或 export 参数模式。

bind master 位于绑定链顶端，保存当前值。Bind master parameter 可以有 export 和表达式，通常与其他参数一样工作，但其值也可以由 bind reference 间接改变。注意： 如果 bind master 参数被其 reference 改变，它将进入 Constant Parameter Mode。

Bind master table cells 可以通过更改单元格值或 bind reference 参数值来改变。Bind master channels 仅在 Bind CHOP 上可用，可以通过更改 CHOP 的通道输入或更改 bind reference 参数值来改变。

要 bind to a Text DAT' 文本正文，请参阅下文「Binding Other Object Attributes」。

使用 Bind 表达式进行设置

要设置 bind reference，请将参数的 Parameter Mode 设为 Bind，然后添加指向 bind master 的 bind expression，例如 op('lfo1').par.phase。展开该参数并在下方输入框中键入内容即可访问 bind 表达式。上方文本输入区（部分参数可用）用于更改参数的实际值，类似 constant 模式。设置到 table cells 或 bindCHOP channels 的绑定与此类似。在 bind 表达式中为对象输入表达式，例如 op('table1')[0,0] 或 op('bind1')['chan1']。

也可以用 python 设置 bind 表达式：Par.bindExpr = string

通过拖放进行设置

也可以通过拖放设置参数之间的绑定。要使用鼠标绑定参数，始终将 bind master 拖到 bind reference。从 bind master 的参数对话框中将参数名拖到 bind reference 参数的参数名或输入框中。对于多值参数，将 bind master 的名称拖到 bind reference 的名称上。完成后，在弹出的菜单中选择 Bind。

绑定自定义菜单参数

将自定义菜单参数绑定到另一个菜单参数时，通常希望复制另一个菜单中的选项。使用 menuSource 成员即可轻松实现。使用 Component Editor Dialog（或 Python），在自定义参数的 menuSource 中编写一个指向其菜单要被复制的参数的表达式。注意： 将菜单参数拖入 Component Editor 的参数区域并在弹出菜单中选择 bind 或 reference 选项时，这会自动完成。

绑定其他对象属性和特性（bind 元组）

也可以绑定到 named object attributes，例如 Text DAT 的文本。表达式格式是包含两部分的元组，称为 bind 元组，格式为：(object, attribute)，例如：(op('text1'), 'text') 或 (op('box1'), 'nodeY')。

此类绑定的一个高级特性是：它会正确使用 Python property 的 setter 函数。如果使用 Python 特性返回一个可依赖对象（例如参数或 tdu.Dependency 对象），在 bind 表达式中使用点号表示法会跳过该特性的访问器，并在参数变化时直接更改返回的对象。使用 bind 元组表示法时，绑定值变化则会使用该特性的 setter 函数。

注意： 这仅对 Dependable 的属性双向生效。如果你发现需要绑定但不可依赖的 TouchDesigner 属性，请在论坛发帖。

绑定到 None

当 bind 表达式的求值结果为 None 时，它们始终返回 None。这有助于处理某些棘手的错误状态。例如，如果你想绑定到 /geo1 的 tx 参数，但不确定 /geo1 是否存在，可以使用这个 bind 表达式：op('geo1').par.tx if op('geo1') else None。
