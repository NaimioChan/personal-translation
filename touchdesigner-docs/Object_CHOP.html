Object CHOP

摘要

Object CHOP 比较两个对象，并输出包含其原始或相对位置与朝向的通道。可输出的信息有：

  • 一个对象相对于另一个对象的位置
  • 一个对象相对于另一个对象的旋转
  • 一个对象相对于另一个对象的方位
  • 两个对象之间的单一方位角
  • 两个对象原点之间的距离
  • 两个对象之间距离的平方倒数

两个可选输入允许你把世界空间中的 X、Y、Z 点与对象或彼此进行比较。这些输入应具有三个包含 XYZ 点的通道（三个后缀为 x、y 和 z 的通道）。或者，它们也可以采用 Transform CHOP 帮助中描述的标准变换格式。这些输入会替代目标和/或参考对象。对象与点之间可以相互比较，但「Rotation」模式将始终返回零。

另请参阅 SOP to CHOP 和 Parameter CHOP。它们从 objects 和 SOPs 中获取其他信息。

参数 - Object 页

DAT Table dat - 使用一个 Table DAT 来指定要使用的目标对象和参考对象。第一列是目标对象，第二列是参考对象。不使用表头。
Target Object target - 与参考对象位置进行比较的对象。Target Object 可以表示为文本字符串。当对象名称需要可变时，这会很有用——它允许你输入可能包含表达式或变量的名称。
Reference Object reference - 作为比较原点的对象。Reference Object 可以表示为文本字符串。
Swap Target/Reference swaptargetreference - 交换上面 Target Object 和 Reference Object 参数中定义的对象。

参数 - Output 页

Compute compute - - 指定要从对象输出的信息，如下面的参数所述。除 'measurements' 外，这些都与 Transform CHOP 中描述的标准变换格式一致。
  • Transform (Euler) transform - 使用欧拉角（rx ry rz）表示旋转的变换。
  • Transform (Quaternion) transformquat - 使用四元数（qx qy qz qw）表示旋转的变换。
  • 4x4 Matrix mat - 4x4 变换矩阵。
  • 3x3 Matrix mat3 - 3x3 变换矩阵。包含缩放/旋转，但不含平移。
  • Measurements measure - 启用下面的开关以选择要测量的内容。测量给出一个对象相对于另一个对象的位置。你得到的是 Target Object 原点相对于 Reference Object 原点和旋转的 XYZ。也就是说，你得到的是假设你站在 Reference Object 的 0,0,0 位置（原点）、沿 Reference Object 的 Z 轴方向观察时，目标对象原点的 XYZ。
Position translate - 从参考对象到目标对象的位移。
Rotation rotate - 从参考对象到目标对象的朝向差异。
Scale scale - 从参考对象到目标对象的缩放差异。
Quaternion quat - 从参考对象到目标对象的四元数。
Bearing bear - 使参考对象朝向目标对象所需的旋转。
Single Bearing Angle singlebear - 表示目标对象相对于参考对象所在方位的角度。0 度为正前方，90 度为侧方，180 度为后方。
Distance distance - 两个对象之间的距离。
Inverse Square Distance invsqr - 两个对象之间距离的平方倒数，可用于对电力、音频衰减和重力建模。
Transform Order xord - - 用于 Rotation、Scale、Transform、Bearing 或 Single Bearing Angle Compute 模式的变换顺序。
  • Scale Rotate Translate srt -
  • Scale Translate Rotate str -
  • Rotate Scale Translate rst -
  • Rotate Translate Scale rts -
  • Translate Scale Rotate tsr -
  • Translate Rotate Scale trs -
Rotate Order rord - - 用于 Rotation、Scale、Transform、Bearing 或 Single Bearing Angle Compute 模式的旋转顺序。
  • Rx Ry Rz xyz -
  • Rx Rz Ry xzy -
  • Ry Rx Rz yxz -
  • Ry Rz Rx yzx -
  • Rz Rx Ry zxy -
  • Rz Ry Rx zyx -
Include Order Channels includeorderchans - 打开以包含 Transform Order 和 Rotate Order 的通道。
Bearing Reference bearingref - - Bearing 需要一个方向作为参考基准。
  • X Axis x -
  • Y Axis y -
  • Z Axis z -
  • Bearing Vector vector -
Bearing Vector bearing - - 用于方位计算的任意基准方向。
  • X bearingx -
  • Y bearingy -
  • Z bearingz -
Point Scope X tscopex - 当连接了某个可选点输入时，这决定哪些通道代表 X、Y 和 Z。
Point Scope Y tscopey - 当连接了某个可选点输入时，这决定哪些通道代表 X、Y 和 Z。
Point Scope Z tscopez - 当连接了某个可选点输入时，这决定哪些通道代表 X、Y 和 Z。
Append Attributes appendattribs - 为 Object CHOP 创建的任何旋转通道添加一个 rotate 属性。
Smooth Rotation smoothrotate - 开启时输出平滑的旋转曲线，在 0、90 等位置不会出现图形跳变。

参数 - Channel 页

Channel Names nameformat - - 设置所创建通道的命名方式。
  • Channel Name channel - 自动命名通道。For example：tx, ty, tz。
  • Target and Channel Names target - 以目标前缀命名通道。For example：如果 target = obj1，则 obj1:tx, obj1:ty, obj1:tz。
  • Reference and Channel Names reference - 以参考参数前缀命名通道。行为与上面的 Target and Channel Names 类似，但使用参考对象的名称。
Output Range outputrange - - 对象路径所需区间的开始与结束时间。
  • Current Frame currentframe - 在当前帧输出单个采样。
  • Current Time Slice timeslice - 覆盖当前 Time Slice 的采样范围。
  • Start / End startend - 使用下面 Start / End 参数定义的范围。
Cook Past Values (slow) cookpast - 如果项目跳过了一帧或多帧，这会尝试在之前的多个帧上计算其输入，以避免其计算中出现不连续。
Start start - 对象路径所需区间的开始时间。
Start Unit startunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
End end - 对象路径所需区间的结束时间。
End Unit endunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
Extend Left left - - 该 CHOP 区间之前的延伸条件。它们是：
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道起点之前的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Extend Right right - - 区间之后的延伸条件。选项与 Extend Left 相同。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道终点之后的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Default Value defval - 用于 Default Value 延伸条件的值。

注意： 创建旋转通道时，Transform CHOP 和 Object CHOP 会选择使帧间不连续最小化的值。图形看起来会连续，不会出现 180 度跳变。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Object CHOP 的额外信息可以通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
