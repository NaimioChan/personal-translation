TouchDesigner 视频服务器规格指南

建议的操作系统

建议使用 Windows 10/11 作为操作系统。

处理器

  • 更多详情请见：Intel Processors and TouchDesigner
  • Derivative 推荐 Intel 处理器。
  • 我们曾使用 AMD Ryzen 7 成功搭建用于通用桌面用途的 TouchDesigner 系统（非专业视频服务器）。这些处理器对 TD 来说性价比极高 - https://www.amd.com/en/products/cpu/amd-ryzen-7-2700x
  • 我们没有使用 AMD Threadripper CPU 的经验，但我们预计它们能很好地工作。https://www.amd.com/en/products/ryzen-threadripper
  • TouchDesigner 的主线程运行在单个核心上。请在你的 CPU 级别和价格区间内选择主频最高的型号。
  • 选择 PCIe 通道数量足以支持所指定 PCIe 扩展卡的 CPU。
  • 如果只配一颗 CPU，请选择 CORE CPU。
  • 如果配一颗以上 CPU，则必须选择 XEON。

内存

  • 查阅你的 CPU 和主板规格，选择可用的最快内存。

显卡

  • 更多详情请见：Nvidia Geforce vs Quadro
  • Derivative 推荐 Nvidia 显卡。
  • 如果直接从显卡播放大画幅视频，请使用 Quadro。
  • 如果通过 SDI 扩展卡播放视频，请使用 Quadro。
  • 如果你想找一台性价比高的个人工作站用于 TouchDesigner 开发，请使用 Geforce 显卡。

主板

  • 确保主板支持所选 CPU 的正确插槽类型。
  • 确保有足够数量、带宽正确的 PCIe 插槽来支持你的显卡。
  • 确保按主板手册将显卡安装在正确的插槽中。
  • 注意 CPU 和主板支持的 PCI 通道数量。
  • NVMe 硬盘常常会占用 PCI 通道，安装后可能影响主板的通道可用性。

硬盘

  • 更多详情请见：Storage Technology and TouchDesigner
  • Thinkmate 的这篇文章必读。https://www.thinkmate.com/inside/articles/nvme
  • Tom's Hardware 对 NVMe 技术有很好的报道。https://www.tomshardware.com/reviews/intel-750-series-ssd,4096-2.html
  • 尽可能使用主板集成的 M.2 插槽和 NVMe 硬盘来安装操作系统。
  • 尽可能使用 NVMe 技术，而不是 SATA 或 SAS。
  • 对于更大容量、更高速度的硬盘，使用 NVMe RAID 控制卡。

60FPS 下 NotchLC 对比编解码器性能统计

NotchLC 是一种利用 GPU 的高质量编解码器。虽然它比 HAPQ 需要更多的 CPU 和 GPU 资源，但其最佳压缩设置的画质高于 HAPQ，可以说与 Apple ProRes 相当甚至更好。

从 NotchLC 测试中我们能得出的最明确结论是：你很可能无法像 HAPQ 那样把高速硬盘配置跑满。我们的 HAPQ 测试得到的回放瓶颈非常接近测试平台 3500 MB/s 的上限。NotchLC 往往在硬盘带宽容量达到之前就开始掉帧，说明限制因素更多来自 CPU。

哪个更好？HAPQ 还是 HotchLC

HAPQ 和 NotchLC 都是用于回放和录制高分辨率实时内容的强大编解码器。HAPQ 是恒定比特率编解码器，无论像素内容如何都会生成相同的文件大小。其数据以 GPU 可直接读取的格式存储，因此解码消耗的 CPU 或 GPU 资源极少。HAPQ 是 8 位编解码器，压缩质量不错，但视内容而定，你会看到柔和渐变中出现色带之类的瑕疵。NotchLC 是伪 10 位编解码器，因此能保留更多颜色信息。NotchLC 的最佳设置可生成质量很高的文件，可作为中间格式，用于传统视觉特效或视频制作流程中的进一步处理和剪辑。NotchLC 的压缩随像素内容变化：内容噪点越多，压缩率越低，文件也就越大。一段标准实拍视频在 HAPQ 中不做二次压缩时，文件比 NotchLC 小约 5%。同一文件在 HAQ 中做二次压缩后，约小 15%。

从这一比较可以得出的主要结论是：两种编解码器需要相似的硬盘配置。因此按 HAPQ 的需求设计硬盘配置，NotchLC 的回放和录制在同一系统上也会非常顺畅。

如前所述，NotchLC 对 CPU 和 GPU 的要求更高，因此在硬盘配置仍有冗余的前提下，更高的主频和更多核心会提升带宽。更快的 GPU 对 NotchLC 和 HAPQ 也都是有利因素。
