停靠

停靠节点是一种减少网络杂乱的方式，把操作符作为一个小停靠图标隐藏在另一个节点上。该图标用颜色标记来表示被停靠节点的 Operator Family。任何节点都可以停靠到另一个节点上。当停靠的父节点在 Network Editor 中移动时，被停靠的节点也会随之移动。

停靠不影响节点的行为，只影响外观。

被停靠的节点通常停靠到相关节点上，以帮助组织网络，例如 Ramp TOP。新建的 Ramp TOP 会附带一个停靠的 Table DAT，用于存储 ramp 颜色信息。要查看该 Table DAT，请单击 Ramp TOP 右下角附着的 DAT-colored 停靠图标。再次单击该图标即可将被停靠的节点折叠回图标。

停靠节点

节点可以通过两种不同方式停靠：

  • - 右键单击要停靠的节点并选择 Dock to ...，然后单击要停靠到的节点。
  • - 在 python 中对 Operator class 使用 Op.dock 和 Op.docked。
