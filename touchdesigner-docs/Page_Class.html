Page 类

Page 类描述页面上所含自定义 parameters 的列表。页面通过 COMP 类在组件上创建。另请参阅指南 Custom Parameters。

创建参数的方法会返回所创建的 ParGroup。

要查看各参数的单独属性（如 default、min、max 等），请参阅 Par Class 文档。

可以像 Python 参数列表一样访问页面： 

page = op('button1').pages[0]	# 获取页对象
print(len(page))				# 页上的参数数量
debug(page[0])					# 页上的第一个参数
for p in pages:
	debug(m.description)		# 打印页上的所有参数

成员

name → bool :

获取或设置页面名称。

owner → OP (Read Only):

此对象所属的 OP。

parGroups → list (Read Only):

此页面上的 parameter groups 列表。ParGroup 是一行上的参数集合。

pars → list (Read Only):

此页面上的 parameters 列表。

index → int (Read Only):

此页面的数字索引。

isCustom → bool (Read Only):

表示此页面是否为自定义的布尔值。

方法

appendOP(name, label=None, order=None, replace=True)→ ParGroup:

创建一个节点引用类型 parameter。此参数将接受对任何操作符的引用。

返回所创建的 parameter group 对象。

  • name - 参数名称。
  • label - （关键字，可选）参数的显示标签，默认使用 name 参数。
  • order - （关键字，可选）指定参数的显示顺序，默认为最高。
  • replace - （关键字，可选）默认会用新的属性替换参数。若为 False，则参数已存在时报错。

destroy()→ None:

销毁此对象所引用的页面及其所有参数。

sort(*pars)→ None:

按指定顺序重新排列自定义参数组或参数。 

n = op('base1')
page = n.appendCustomPage('Custom1')
page.appendFloat('Value')
page.appendFloat('Speed')
page.appendFloat('Color')
page.sort('Speed','Color','Value')

resetPars()→ bool:

重置页面中的所有参数。

如果有任何改动则返回 true。

op('geo1').pages[0].resetPars() 
op('player').customPages['Setup'].resetPars()
