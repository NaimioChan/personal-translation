CUDAMemory 类

保存对 CUDA 内存的引用。此对象析构时，CUDA 内存将被释放。

成员

ptr → int (Read Only):

返回 CUDA 内存的原始内存指针地址。

size → int (Read Only):

返回 CUDA Memory 的大小，以字节计。

shape → CUDAMemoryShape (Read Only):

返回描述此 CUDA 内存的 CUDAMemoryShape Class。有关不同数据类型下通道顺序的说明，请参阅该类的帮助。

方法

没有该操作符专属的方法。
