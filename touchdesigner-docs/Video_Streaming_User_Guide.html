视频流用户指南

本指南将介绍 TouchDesigner 用户目前可用的、用于通过互联网进行音视频流传输的受支持协议和服务。

正式版中的当前协议

  • RTMP - 一种被广泛采用的协议，用于将音视频流传输到 YouTube、Twitch 等流服务。
  • RTSP - 一种开源的服务端与客户端协议，用于通过互联网收发音视频数据。
  • NDI - 一种 IP 视频协议，在各种网络视频用例中非常有用。
  • SRT - （Secure Reliable Transport）将在 Video Stream In TOP 中推出，目前在实验版中提供。

另请参阅通过虚拟摄像头实现的 Broadcasting to Social Media from TouchDesigner。

使用 RTMP 的流服务

Twitch

URL：https://www.twitch.tv/

由 Amazon 拥有并运营的服务。它大概是迄今为止最流行的直播系统。

Services

  • 免费使用
  • 集成聊天
  • 流录制与流回放（天数有限）
  • 高级（付费）访问为录制提供各种增强功能

Advantages

  • 免费版带广告/高级版无广告
  • 易于使用
  • 首次尝试的最佳场所
  • 低延迟（3-5 秒）

Disadvantages

  • 免费版含广告
  • 内容入口非常嘈杂，充斥着玩家打游戏的画面
  • 视频的录制与存档选项有限，且总是临时的
连接与设置说明
  1. 注册用户账号。按说明操作。
  2. 成为会员后，在 “Account Settings” 的 “Stream” 部分找到你的 streamkey。“Primary Stream key” 是一个可反复使用的永久密钥，应只自己保留，否则他人可以劫持你的频道。用复制按钮把字符串复制，并在 VideoStream out TOP 的 Destination URL 参数中按如下方式构造字符串……
  3. 选择一个最近或推荐的 ingest 服务器。https://stream.twitch.tv/ingests/
  {ingest server url} = rtmp://live.twitch.tv/app/
  {stream key} = live_1234567_sduhy3xJ1KJ34Eg6CjksdJLubFS7gtUY
  RTMP Destination URL = rtmp://live.twitch.tv/app/live_1234567_sduhy3xJ1KJ34Eg6CjksdJLubFS7gtUY
最高质量设置
  • 分辨率：1920x1080
  • 比特率：6000 kbps
  • 比特率模式：CBR
  • 帧率：60
  • 关键帧间隔：2 秒
  • Profile：Main
  • B 帧：2
  • 最高质量设置以尺寸/带宽换取质量，且对更广泛的观众可能兼容性较差。我们建议你尝试所有设置，找出最适合自己用例的方案。

Youtube

URL：https://youtube.com

Services

  • 视频流传输
  • 视频转码
  • 实时视频流传输
  • 实时视频录制

Advantages

  • 可能是世界上最大的视频平台。
  • 大多数观众已拥有 Youtube 账号。
  • 智能电视预装了 Youtube —— 在电视或任何其他设备上播放内容都很方便。
  • 所有视频免费存档。
  • 可立即访问你的视频。
  • 可基于播放带来的广告收入为内容变现。

Disadvantages

  • 设置比 Twitch 更复杂
连接与设置说明
  1. 注册用户账号。
  2. 用 google 搜索 YouTube live streaming
  3. 单击名为 "YouTube Live | Learn How to Start Your Stream" 的搜索链接
  4. 前往 https://youtube.com/live_dashboard。你将进入 YouTube Studio Dashboard。
  5. 找到 “Go Live” 按钮，其图标中间有一个红点。单击它。
  6. 这会带你进入一个新的流传输界面。你可以在其中选择 Webcam 或 Stream sender。在左侧控制面板中选择 “Stream”。
  7. 在此处按照设置对话框的说明设置你的流。把 Stream URL 与 “斜杠”（“/”）拼接，为 VideoStreamOut TOP 构造字符串，如下所示……
  {stream url} = rtmp://x.rtmp.youtube.com/live2
  {stream key} = asdf-56wq-6yut-9ast
  RTMP Destination URL = rtmp://x.rtmp.youtube.com/live2/asdf-56wq-6yut-9ast
      • 重要提示：成功连接到 Studio 流传输 RTMP 服务器后，预览监视器下方的连接状态会从 “no data” 变为 “Excellent（或其他）Connection”，但在浏览器中重新加载页面之前，预览可能不会播放。

https://support.google.com/youtube/answer/2853702?hl=en&ref_topic=9257892

Mux

URL：https://mux.com/

一支充满热情的视频专家团队，在为企业用例去除流传输的部分复杂性方面做得非常出色。他们为应用开发者提供面向高质量流传输的稳健平台。

Services

  • 视频转码
  • 视频存储与回放后端
  • 直播与直播录制
  • 数据指标
  • 应用开发 API

Advantages

  • 非常出色的人工支持
  • 易于使用 - 后端用户界面良好 - 极简
  • 简洁的 API，可支持应用开发
  • 他们拥有自己的网络，并针对回放质量进行了调优
  • 支持 XXXX Kbps
  • 打造你自己的流应用，避开 Twitch 或 Mixer 的嘈杂与混乱

Disadvantages

  • 延迟高于 Twitch 和 Mixer——最高可达 30 秒
  • 可能较贵。可带着你的用例联系他们，或从这里开始了解。https://mux.com/pricing
  • 目前仅支持 RTMP 和 HLS。
  • 比 Twitch 或 Mixer 复杂得多——（它是为专业开发者设计的）
  • 他们的商业模式似乎面向视频的摄取与转码，而非直播流。
  • 他们的最大帧率为 30，最大比特率为 5000。
连接与设置说明
  1. 注册用户账号。按说明操作。
  2. 进入用户账号后，使用 Settings（齿轮图标）菜单查找文档。
  3. https://docs.mux.com/docs/live-streaming
  {ingest server url} = rtmp://global-live.mux.com:5222/app
  {stream key} = 123412341234-JKHASDF98asdf9789fAoad
  RTMP Destination URL = rtmp://global-live.mux.com:5222/app/123412341234-JKHASDF98asdf9789fAoad
最高质量设置
  • 分辨率：1920x1080
  • 比特率：7000 kbps
  • 比特率模式：CBR
  • 帧率：30
  • 关键帧间隔：0 秒
  • Profile：Main
  • 预设：
  • B 帧：2

Wowza

URL：https://wowza.com/

按用量付费的流服务会根据你的带宽用量收费。http://cloud.wowza.com 提供了一套易于使用的系统，用于 RTMP 摄取和 HLS 广播。此外他们还提供可安装到 Microsoft Azure 等云服务上的流引擎，用来管理整套可定制的流服务。其设置非常技术化。

Services

  • 视频转码
  • 直播与直播录制
  • 数据指标
  • 应用开发 API

Advantages

  • 非常出色的人工支持
  • Wowza 云服务相当易用，且可配置性很强。
  • 简洁的 API，可支持应用开发
  • 他们的网络支持自定义设置以获得更高的比特率
  • 打造你自己的流应用，避开 Twitch 或 Mixer 的嘈杂与混乱
  • 测试云服务的 30 天试用 - https://www.wowza.com/wowza-streaming-cloud-free-trial
  • 运行 Wowza 引擎的 6 个月试用 - https://www.wowza.com/wowza-streaming-engine-free-trial
  • 可提供高分辨率与高比特率

Disadvantages

  • 必须成为会员才能使用
  • 定价结构不太清晰，因为它是按用量付费
  • 云服务仅支持 RTMP
  • 比 Twitch 或 Mixer 复杂得多——（它是为专业开发者设计的）
  • 对于希望把视频内容流传输给固定数量高质量客户的 TouchDesigner 用户来说，这可能是一种不错的商业模式。
连接与设置说明
  1. 注册演示用户账号。按说明操作。
