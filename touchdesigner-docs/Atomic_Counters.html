原子计数器

原子计数器是 OpenGL 中的缓冲区对象，可对其执行原子操作。它们属于一种单独的变量类型，称为 atomic_uint（原子无符号整数）。可对其应用多种原子操作，即 atomicCounterIncrement 和 atomicCounterDecrement。

更多信息及可用函数的完整列表请参阅：https://www.khronos.org/opengl/wiki/Atomic_Counter

在 TouchDesigner 中可通过 GLSL TOP 使用原子计数器。另请参见：Write a GLSL TOP。它们可用于管线任意阶段（vertex、fragment/pixel、compute）的着色器中，可用于统计各类数据，例如顶点数量、红色像素数量等。

下面是一个简单的像素着色器示例：每次（即每个像素一次）递增原子计数器，将其转换为 float，然后写入红色通道。从视觉上看，先渲染的像素会比后渲染的像素呈现更深的红色。 

 layout(binding = 0, offset = 0) uniform atomic_uint ac;
 out vec4 fragColor;
 void main()
 {
    uint c = atomicCounterIncrement(ac);
    float r = (c/255)/255.f;
    fragColor = vec4(r,0,0,1);
 }
