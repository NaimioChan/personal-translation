Scan CHOP

摘要

DEPRECATED: 请改用 Laser CHOP。

Scan CHOP 将 SOP 或 TOP 转换为适合示波器或激光的控制波形。 输出通常位于可听范围内，可通过 Audio Device Out CHOP 直接听到，也可用于驱动示波器的 X 和 Y 偏转输入，或驱动激光投影仪重建图像。 输出也可以通过 Limit SOP 可视化。

示例组件见：Op to Audio CHOP example

示例视频见：Total Internal Reflection

另请参阅：EtherDream CHOP、EtherDream DAT

scanCHOP_Class

参数 - Scan 页

Source OP source - - 选择源节点族。
  • TOP top - 通过把每个像素的位置转换为 X 和 Y 振幅值，把栅格图像转换为控制信号。
  • SOP sop - 通过把每个点的位置转换为 X 和 Y 振幅值，把几何转换为控制信号。
  • CHOP chop - 通过把每个图形转换为对应的水平与垂直偏移，把波形转换为控制信号。
Sample Rate rate - 每秒采样数，即输出采样率。
Swap Output swap - 反转 X 与 Y 通道输出。
X Scale xscale - 缩放 x 振幅。
Y Scale yscale - 缩放 y 振幅。
Rotate rotate - 以度为单位，旋转输出的 x,y 值。
Randomize Samples randomize - 以随机顺序输出所有采样。在示波器上产生模糊的混沌图像。
Output Color color - 若开启，则创建 r,g,b 通道。若开启，则创建 r,g,b 通道。
Red Scale redscale - 缩放输出的 r 通道。
Green Scale greenscale - 缩放输出的 g 通道。
Blue Scale bluescale - 缩放输出的 b 通道。
Blanking Count blankingcount - 对于 SOP 输入，为在图元之间插入的黑/关断位置数量。 对于 TOP 输入，为在完整栅格扫描之间插入的黑/关断位置数量。颜色输出必须启用。对于 SOP 输入，为在图元之间插入的黑/关断位置数量。 对于 TOP 输入，为在完整栅格扫描之间插入的黑/关断位置数量。颜色输出必须启用。

参数 - TOP 页

通过把每个像素的位置转换为 X 和 Y 振幅值，把栅格图像转换为控制信号。亮度由每个采样在示波器上「绘制」的时长控制。 由于输出带宽很低，因此提供不同的重采样与排序选项，用于减少（或增强）闪烁。

TOP top - TOP 节点的路径。
Width width - 对图像进行重采样的列数。
Height height - 对图像进行重采样的行数。
Level level - 每个像素可具有的亮度级数。
Auto Reduce limit - 自动动态减少行数与列数，使输出帧率保持

在恒定水平。

Layered layered - 按亮度顺序输出像素，否则每行按从左到右的顺序输出。
Interleave interleave - - 控制行的输出顺序，以尽量减少闪烁。
  • Sweep sweep - 各行按顺序输出，从上到下。
  • Even Odd evenodd - 各行分两遍输出，先偶数行，再奇数行。
  • Max max - 各行以完全交错的方式输出。

参数 - SOP 页

SOP 中的每个点会创建一个带帧缓冲的立体声采样，其中 SOP 顶点的 X 放在 X 通道上，Y 放在 Y 通道上。因此示波器输出不含走样线条，只有极其锐利的矢量。

SOP sop - SOP 节点的路径。
Vertex Order vertexorder - 按每个多边形顶点的顺序输出点，而不是按几何中定义点的顺序。
Limit Step Size limitstep - 把长距离的 x,y 跳变拆分为若干较小的增量跳变。
Step Size stepsize - 启用上一选项时，每次 x,y 可变化的距离。
Vertex Repeat vertexrepeat - 把每个图元的每个顶点重复多次。
Camera camera - 从此摄像机把几何投影到 2D 平面上，否则只使用几何原始的 x,y 分量。

参数 - CHOP 页

通过把每个图形转换为对应的水平与垂直偏移，把波形转换为控制信号，从而重建原始的 CHOP 波形。该 CHOP 不应是 Time Sliced，而应具有一定的长度（例如 Trail CHOP 或带动画的 Wave CHOP）。

CHOP chop - CHOP 节点的路径。
Trigger trigger - 输出图形将从其值超过此值处开始。这样可以获得稳定的「冻结」波形，类似示波器的触发扫描。
Trigger Value triggerval - 开始触发的值。
Trim trim - 限制要扫描的 CHOP 长度。
Trim Value trimval - 要扫描的 CHOP 长度。
Trim Units trimunits - 选择此参数使用的单位：Samples、Frames 或 Seconds。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
