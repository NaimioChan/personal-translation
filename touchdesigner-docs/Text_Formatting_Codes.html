文本格式代码

本页列出可在 Text COMP 或 Geo Text COMP 的文本中使用的格式化代码，用于给文本的某些部分应用颜色、下划线、删除线或下标等格式。它基于 Slug Library。

要使用格式化代码，请打开组件中的 'Enable Formatting Codes' 参数。

这些代码写在文本中，但会由组件处理，不会在最终输出中显示。代码段以花括号加井号 {# 开头，以右花括号 } 结束。代码的写法类似函数，先写名称，括号内跟参数，例如 color(r, g, b) 或 strike(true)。一个代码段中可以写多个代码，用分号 ; 分隔，例如 {#color(255,0,0);script(2)}。

在 Text COMP 中编辑时，格式化代码在编辑过程中以原始格式显示，编辑完成后才按代码处理。对于 Text COMP 中的多行文本，格式化只作用于当前段落（以换行符标记），下一段会重置为默认值。对字号或行距的更改只影响其所在行之后的自动换行行。

代码

stretch(value) - 将文本拉伸设为 value，其中 value 为浮点数。若 value 不大于零，则忽略。

track(value) - 将文本字距设为 value，单位为 em，其中 value 为浮点数。

skew(value) - 将文本倾斜设为 value，其中 value 为浮点数。正值向右倾斜，负值向左倾斜。

scale(x, y) - 将文本缩放设为 (x, y)，其中 x 和 y 为浮点数。可以省略 y 分量，此时它被设为与 x 分量相等。若 x 或 y 不大于零，则忽略。

under(value) - 将下划线装饰状态设为 value，其中 value 为 true 或 false。若字体不包含下划线信息，则忽略。

strike(value) - 将删除线装饰状态设为 value，其中 value 为 true 或 false。若字体不包含删除线信息，则忽略。

script(value) - 将基于变换的上下标状态设为 value，其中 value 为 [−3, 3] 范围内的整数。若 value 为 0，则文本缩放和文本偏移状态被设为恒等变换。若 value 为正，则上标缩放和偏移被应用 value 次。若 value 为负，则下标缩放和偏移被应用 value 次。若 value 超出范围，或字体不包含基于变换的上下标信息，则忽略。

color(red,green,blue) - 将主文本颜色设为 (red, green, blue, 255)，其中每个分量都是 [0, 255] 范围内的整数。red, green, and blue 分量以 sRGB 色彩空间指定。若任一分量超出范围，则忽略。

color(red,green,blue,alpha) - 同上，但同时设置 alpha 值。

color2(red,green,blue) - 使用与主色相同的格式设置次文本颜色 (red, green, blue, 255)。次文本颜色仅在启用渐变时使用。

color2(red,green,blue,alpha) - 同上，但同时设置 alpha 值。

grad(value) - 将渐变状态设为 value，其中 value 为 true 或 false。

reset() - 将所有格式化状态重置为初始值。
