OpenVR 动作

动作

动作是一组可以透过 SteamVR 绑定到控制器输入的值。由于不同的系统可能配有不同控制器，与其把为 VR 制作的项目中的事件绑定到特定硬件事件（A-Button、Side Trigger 等，并非所有控制器都有），不如让 StreamVR 把这些事件抽象为「动作」，例如 'select' 或 'grab'。然后使用 SteamVR 控制器绑定 UI，即可用具体控制器硬件的功能/按钮来触发/控制这些公开的事件。项目可用的动作通过其 Action Manifest 定义，这是一个 json 文件，描述了任意数量的动作及其类型（vec1、vec3、boolean、pose、skeleton）。 TouchDesigner 定义了一份默认动作列表，可通过 SteamVR Binding 工具进行绑定。这些定义位于 Samples/OpenVR/BasicActions.json。

对于 Basic，以下就是所定义的内容，并附有其默认绑定在 HTC Vive Controller 上的说明：

  • Hand Pose: 变换矩阵，绑定到控制器的变换。
  • Trigger: 布尔值，绑定到扳机是否完全按下。
  • Squeeze: 浮点值，绑定到扳机当前按下的位置。
  • Grip: 布尔值，绑定到（侧面的）握持按钮。
  • Trackpad: X/Y 值，绑定到手指在触控板上的位置。
  • Trackpad Click: 布尔值，绑定到触控板按钮。
  • Trackpad Touch: 布尔值，绑定到触控板触摸。
  • Joystick: X/Y 值，绑定在 HTC Vive Controller 上。
  • Joystick Click: 布尔值，绑定在 HTC Vive Controller 上。
  • A Button: 布尔值，绑定到 Application Menu 按钮。
  • B Button: 布尔值，绑定到 System 按钮。
  • Skeleton: 根据控制器能检测到的内容推断出的手部骨架形状

我们还提供了一份更复杂的动作清单，更贴合你能从 Valve Index 控制器获得的动作数量，位于 Samples/OpenVR/ComplexActions。可以通过打开 "Custom Actions" 并选择 ComplexActions.json 作为 Action Manifest 来改用它。

OpenVR 关于 Action Manifest 的文档可在 here. 获取。

目前，TouchDesigner 不支持多个 Action Set，并且所提供的唯一 action set 必须命名为 "/actions/default"。

除这些 JSON 值之外，我们自己也会解析 .json 文件，并提取一些其它可选信息。 在顶层，"td_app_key" 可以设为一个字符串，例如 "basic.touchdesigner.exe"。这实质上是从 SteamVR 的角度为你的运行进程命名，这样你就可以为该 action manifest 拥有特定的绑定。若未设置，你的动作绑定将绑定到 "system.generated.touchdesigner.exe"，多个项目都会使用相同的绑定。 对于每个已定义的动作，可以提供可选的 "td_chan_name"，用于指定该动作所生成通道的 CHOP 通道名前缀。未提供该条目时，将使用动作名的后缀，去掉其中的 "/actions/default/in/" 前缀。 你可能会在某些 .json 文件中看到 "td_legacy_chan_name"，但新文件不应使用该条目。 查看 Samples/OpenVR 中提供的现有 Action Manifest，作为开始制作你自己的 Action Manifest 的参考。

绑定

绑定是把控制器所支持的实际硬件事件与动作关联起来的东西。例如把动作 "open" 关联到控制器上的 "A-Button"。 TouchDesigner 为 HTC Vive 和 Valve Index 控制器提供了默认绑定，但这些绑定可以被覆盖。也可以添加各种其它设备的绑定。

要添加/编辑绑定：启动 TouchDesigner 并确保它正在使用 OpenVR。打开 "Devices" → "Controller Settings → Manage Controller Bindings"，在 "Manager Controller Bindings For:" 中应显示使用当前 action manifest 中自定义 "td_app_key" 的 TouchDesigner。将 "Active Controller Binding" 改为 "Custom"，然后选择 "Edit this binding"。这会打开 TouchDesigner 的绑定编辑页面。对于你的控制器支持的每个硬件事件，你都可以选择一个动作来与之关联。

默认绑定

创建新的 action manifest 时，你可以为其提供默认绑定。这些在 action manifest 的 "default_bindings" 部分指定。它们必须引用一个位于 action manifest 所在目录或其子目录中的绑定 .json 文件。它不能指向驱动器上的其它位置。示例默认绑定文件位于 Samples/OpenVR/bindings。请注意，这些绑定文件中的 "app_key" 条目应与 action manifest 中的 "td_app_key" 值匹配，这样它们才被认为是该 action manifest 的默认绑定。
