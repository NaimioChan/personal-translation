几何变形（蒙皮）

概述

基于变换或完整骨架来变形几何的一种常见方式称为蒙皮（Skinning）。蒙皮让每个点受若干变换影响，每个变换具有不同的权重。

属性说明

Detail 属性 pCaptPath

pCaptPath 细节属性是一个索引属性，包含用作骨骼的 COMP 的路径列表。第一个路径对应索引 0，下一个对应索引 1，依此类推。可以使用 SOP to DAT 查看此属性的值。

Detail 属性 pCaptData

此属性的条目数与 pCaptPath 相同。每个条目包含 20 个浮点数。前 16 个构成该关节绑定/静止姿势的矩阵。其余 4 个在 TouchDesigner 中未使用，是来自 Houdini 的遗留值。

Point 或 Vertex 属性

对于 SOP，此属性称为 pCapt[]。此属性包含成对的信息。每对中第一个值是影响该点的变换索引号，第二个数值是该变换的权重。属性有一个大小，表示其条目数（例如 pCapt[8]）。该大小同时包括索引和权重，因此如果 pCapt 的大小为 8，意味着每个点最多应用 4 个变换（4 个变换和 4 个权重）。

对于 POP，数据被拆分为两个属性：BoneIndices[] 和 BoneWeights[]。它们应具有相同的数组大小，该大小表示可能影响一个顶点的骨骼最大数量。

变形时，TouchDesigner 使用索引属性并通过 pCaptPath 找到正确的 COMP。给定点的所有权重之和应为 1。索引为 -1 表示该条目没有要应用的变换。属性的大小会足够大，以容纳变形该点时使用变换最多的点。

不支持的 Houdini 属性

pCaptSkelRoot - 此属性是 Houdini 中骨架根部的路径。由于 Houdini 中的路径不太可能与 TouchDesigner 中的路径匹配，我们不支持此属性。取而代之的是 Deform SOP 和 MAT 的 Deform 页中的 Skeleton Root Path 参数。

pCaptAlpha - 不支持此属性。

pCaptFrame - 不支持此属性。

在 CPU 上变形

要在 CPU 上变形，只需使用 Deform SOP。Deform SOP 使用 Point Capture 属性而非 Vertex Capture 属性。你需要在 Skeleton Root Path 参数中指定骨架的路径。

例如，要在 FBX 中于 CPU 上变形：可以将带捕获属性的 Import Select SOP 用作 Deform SOP 的输入。Deform SOP 的骨架根路径将是 FBX COMP。

在 GPU 上变形

在 GPU 上变形非常快（几乎不耗性能）。大多数 MAT 的「Deform」页都可启用变形。

使用 GLSL MAT 变形

GLSL MAT 支持自动变形代码，你只需像 Phong MAT 一样在 deform 页设置选项，并对顶点位置和法线调用 TDDeform() 来变形它们。正确的变形代码会在着色器代码发送到 GPU 时自动生成并前置到其中。

编写自己的变形代码

你可以在 GLSL 着色器中自行编写任意变形代码。虽然在 SOP 中该数据保存在名为 'pCapt' 的单个属性里，但为了易用性以及与 POP 的未来兼容，此数据会以两个属性上传到 GPU。这两个属性名为 'BoneIndices' 和 'BoneWeights'。要在 MAT 中访问自定义属性，应通过 'Attributes' 页请求它们。BoneIndices 是 'int' 类型的数组，BoneWeights 是 'float' 类型的数组。然后可以使用 TDAttrib_BoneIndices() 和 TDAttrib_BoneWeights() 访问这些属性，它们返回值的数组。

TDBoneMat() 返回的矩阵由该骨骼在该帧的世界变换与绑定姿势组成。绑定姿势不会改变，包含在 pCaptData 属性中。世界变换每帧根据骨骼的 COMP 计算。两者的相乘方式如下：WorldTransform*BindPose

// Currently you need to define this to match max number of bones per point in your geometry. This would be half the size of pCapt array size. E.g pCapt[8] would mean set this to 4.
// Future improvements are coming for this.
#define MAX_BONES_PER_POINT 4

vec4 ApplySingleBoneDeform(vec4 pos, int i, float frame)
{
	int ind = TDAttrib_BoneIndices()[i];
	if (ind >= 0.0)
	{
		float weight = TDAttrib_BoneWeights()[i];
		return (TDBoneMatrix(ind) * pos) * weight;
	}
	else
	{
		return vec4(0.0);
	}
}

vec4 CustomSkinnedDeform(vec4 pos, float frame)
{
	vec4 newp = vec4(0.0, 0.0, 0.0, 1.0);
	
	for (int i = 0; i < MAX_BONES_PER_POINT; i++)
		newp += ApplySingleBoneDeform(pos, i, frame);

	newp.w = 1.0;
	return newp;
}
