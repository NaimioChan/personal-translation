关键帧动画

关键帧动画在 Animation Editor 中创建和编辑。创建的通道与关键帧存储在 Animation COMPs 中。可以直接在参数上使用这些动画工具为参数制作动画。下文各节介绍如何使用这些工具。

从 Animation Component 开始

要开始创建关键帧动画，首先需要一个 Animation Component。Animation Component 是存储关键帧通道数据的地方。一个项目中可以创建多个 Animation COMP，Animation COMP 也可以保存出来在其他项目中使用。

Animation Editor 一次可为一个 Animation COMP 创建并打关键帧通道。要在编辑器中编辑 Animation COMP，右键单击要载入编辑器的组件，然后选择 Edit Animation...

这会打开编辑器并 scope 所选的 Animation COMP，这会在 Path 字段中确认。
