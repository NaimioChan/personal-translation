Texture Map POP

摘要

Texture Map POP 创建 Tex 属性，用于把纹理贴图应用到表面，或把程序化生成的纹理定位到表面上。

Tex 属性是一个 float3 三分量属性。它可以是点属性，也可以是顶点属性。所有生成器 POP（如 Plane POP、Grid POP、Sphere POP、Rectangle POP、Box POP 等）都会创建它，但 Tex 也可以用 Texture Map POP 创建。

有多种投影方法，各自适用于不同类型的几何和用途。

Equirectangular Inside 和 Outside 是用于顶点的球面极坐标经纬度映射，用于 VR，可以从球体内部或外部观看。

穹顶需要映射类型 Equidistant Azimuth，即鱼眼投影。投影映射使用摄像机的透视，模拟从投影仪位置「看到」的画面。

Triplanar Coordinates 是一种生成 3 组纹理坐标（3 个属性）的类型，用于把 1 张纹理映射到物体上，但它是 3 个正交投影混合到物体 3 个面上的结果。

Tex 属性并没有什么特别之处——任何属性都可以被材质使用。Normalize POP 和 Projection POP 会生成可与材质配合使用的属性，例如做正交缩放投影，或球面/柱面投影。

某些材质需要多个纹理坐标，可以用这些方法中的任意一种创建 Tex2、Tex3 等，再提供给材质。

注意：在 SOP 中，这与使用 uvw 属性作为纹理坐标的做法类似。

另请参阅 PBR MAT、Phong MAT、Normalize POP 和 Projection POP

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
