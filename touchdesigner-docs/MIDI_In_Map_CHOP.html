MIDI In Map CHOP

摘要

请先参阅 MIDI In DAT。MIDI In Map CHOP 从 MIDI Device Mapper Dialog 读取指定的通道，后者会准备从 s1、s2 等开始的滑块通道，以及从 b1、b2 等开始的按钮通道。MIDI In Map CHOP 从中选择通道。

注意：（Apr 12 09）此页面需要根据发布说明中的信息进行更新。

另一个 CHOP —— MIDI In CHOP —— 更直接地获取 MIDI 数据，但可移植性较差，因为它在 CHOP 中直接处理 MIDI 通道号、音符号和控制器号，所以要更改 MIDI 映射就必须更改 TouchDesigner 中的设置；而使用 MIDI In Map CHOP，用户只需在 Dialogs → MIDI Device Mapper 中设置映射。

另请参阅 MIDI In DAT、MIDI Event DAT、MIDI In CHOP、MIDI Out CHOP、midi 命令、MIDI Device Mapper Dialog。

参数 - MidiInMap 页

Device Table device - MIDI 设备的路径 Table DAT。
Device ID id - 指定要使用的设备 id。
Sliders sliders - 要从 MIDI Mapper 导入的滑块控制器。例如要导入前 16 个滑块、滑块 20 以及滑块 32 到 40，请输入： 
 s[1-16] s20 s[32-40]
Buttons buttons - 要从 MIDI Mapper 导入的按钮。例如要导入前 16 个按钮、按钮 20 以及按钮 32 到 40，请输入： 
 b[1-16] b20 b[32-40]
Include Velocity in Buttons bvelocity - 如果可用，在按钮输入上启用力度。

参数 - Channel 页

Sample Rate rate - 通道的采样率，单位为每秒采样数。
Extend Left left - 左侧 extend 条件（范围之前）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道起点之前的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Extend Right right - 右侧 extend 条件（范围之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道终点之后的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default -
Default Value defval - 用于 Default Value extend 条件的值。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

MIDI In Map CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
