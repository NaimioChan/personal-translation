Panel COMP 面板属性页

参数 - Panel 页

Panel 参数页控制面板属性，如显示开/关、启用开/关、面板帮助，以及与光标的交互。

Display display - 指定面板显示还是隐藏。

Enable enable - 可让你阻止与此面板的所有交互。

Help DAT helpdat - 可让你指定一个 Text DAT 的路径，其内容会作为控制面板的悬停弹出帮助显示。

Floating Viewer Aspect vieweraspect - 控制调整浮动查看器大小时（即拖动查看器边缘调整大小）宽高比是成比例还是不受约束。


Cursor cursor - 更改光标位于面板上时显示的光标。

Multi-Touch multitouch - 启用时，此面板会以类似处理鼠标点击的方式处理它收到的第一次触摸，包括更新 u、v、state 等。触摸事件必须从该面板发起。后续触摸会被忽略。如果此面板通过 Multi Touch In DAT 处理多点触控事件，你可能希望禁用 Built-in Multi-Touch，以免干扰脚本处理。

  • Use Parent's Multi-Touch Settings - 使用父级的多点触控设置。根组件中此项默认启用。
  • Use Built-in Multi-Touch - 启用把第一次触摸当作鼠标使用。
  • Do Not Use Built-in Multi-Touch - 禁用把第一次触摸当作鼠标使用。

Click Through clickthrough - 启用时，此 Panel Component 会忽略所有鼠标点击。

Use Mouse Wheel mousewheel - 开启后，在面板上滚动鼠标滚轮时会捕获事件。

Mouse UV Buttons uvbuttons[left,middle,right] - 可让你指定哪些鼠标按键更新 uv Panel Values。

Relative UV mouserel - 启用时，uv Panel Values 会反映相对的鼠标移动。


Drag Edges to Resize resize[lrbt] - 四个复选框可让你通过抓取相应的边或角来调整面板大小：Resize Left、Right、Bottom、Top。

W Range resizewmin resizewmax - 限制左右（宽度）调整范围。

H Range resizehmin resizehmax - 限制上下（高度）调整范围。

Drag to Reposition reposition - 启用用鼠标拖动来重新定位面板或窗口。

Component repocomp - 通过在 Reposition 参数中选择 Component 选项启用。指定你想用鼠标重新定位的面板组件路径。

X Range repositionx[min,max] - 通过在 Reposition 参数中选择 Component 选项启用。设置水平重新定位面板组件的最大范围。

Y Range repositiony[min,max] - 通过在 Reposition 参数中选择 Component 选项启用。设置垂直重新定位面板组件的最大范围。
