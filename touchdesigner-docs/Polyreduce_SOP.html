Polyreduce SOP

摘要

Polyreduce SOP 把高细节的多边形模型简化为多边形更少的模型。第二个输入的多边形表示特征边，它们按点编号与输入网格匹配。

减少多边形模型的方法有：

  • 缩减到原尺寸的某个百分比
  • 缩减到特定的多边形数量（误差在几个之内）
  • 根据与摄像机的距离

注意，由于它需要（并输出）三角形网格，此操作可能导致多边形数量增加。

提供了用于特征边的第二个输入。

polyreduceSOP_Class

参数 - Reduce 页

Polygons reduce - 可作为简化候选的多边形。与这些多边形共享点的其他多边形也可能受到影响。
Features creases - 哪些多边形是特征边。
Method method - 从以下方法中选择如何减少多边形数量。
  • Percentage percentage - 用百分比选择缩减级别。
  • Number number - 按多边形数量选择缩减级别。
  • Distance distance - 根据到对象的距离减少多边形。
Keep % percentage - 当 Method 设为 'Percentage' 时，指定要保留的多边形百分比。
Keep # numpolys - 当 Method 设为 'Number' 时，指定要保留的多边形数量。
Object obj - 用作参考的对象。
Dist. Threshhold distance - 在此世界距离内多边形应保持完整细节。
Minimum % minpercent - 缩减级别的下限。

参数 - Clean 页

Stiffen Border borderweight - 没有任何约束时，平面区域的边缘会被侵蚀。此参数控制一种偏差，对这种侵蚀加以惩罚。
Stiffen Features creaseweight - 对特征边被侵蚀所加的惩罚量。
Equalize Edges lengthweight - 这种偏差惩罚长边的移除。它倾向于减少高宽高比的三角形，代价是缩减不够均匀。
Prevent Mesh Inversion meshinvert - 启用时，每次缩减都会被检测是否会翻转某个三角形的法线。虽然会带来少许开销，但结果几乎总是值得的。
Pre-Triangulate triangulate - 由于只会缩减三角形多边形，此选项会自动把输入多边形三角化。
Prevent Cracking keepedges - 这会禁止移除任何位于多边形边界处的边。这样可确保与未缩减区域之间不会产生裂缝。
Use Original Points originalpoints - 折叠边时，它将使用两个原始点之一，而不是寻找最优的内部点。

Info CHOP 通道

Polyreduce SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
