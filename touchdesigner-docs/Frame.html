帧

「Frame」（帧）是一种时间度量，是秒的整数分，用于（1）Timeline 中，（2）作为 CHOP 中的时间单位，（3）作为读入 TOP 和从 TOP 写出的影片文件中的时间单位。

「Frame」在图像处理和 TOP 中也偶用来指图像中的像素阵列，但在 TouchDesigner 中我们尽量称之为「image」，以避免混淆。

时间轴上的帧

TouchDesigner 窗口底部 Timeline 上的帧条显示当前帧号。TouchDesigner 设定为特定的每秒帧数（Frame Rate - FPS），该值在时间轴中显示和设置。默认帧率为每秒 60 帧，这也是 LCD 显示器和投影仪常见的刷新率。

你也可以在 Textport 中用 project.cookRate 在 Python 中查询和设置每秒帧数。例如，project.cookRate = 60。

当前帧与 TouchDesigner 中的当前时间绑定：时间轴的第一帧是第 1 帧，即时间 0 秒；在每秒 60 帧下，第 61 帧是时间 1 秒。

TouchDesigner 会在一秒内计算（生成其输出）最多 FPS 次。如果你知道自己只想每秒计算和渲染 25 帧，就把 FPS 设为 25。（注意：建议在项目开始时就这样做，不过并非必须。）

你可以在时间轴 UI 上把全局时间轴长度设为任意帧数。如果你要创建已知长度的内容，这可能有用。不过对大多数实时项目来说，时间轴长度并不重要。当 TouchDesigner 到达最后一帧时，它会回到第 1 帧并循环播放。TouchDesigner 中的大多数内容并不关注时间轴循环，因为它们有自己的时间计数器，例如 Movie File In TOP 默认只向前播放直到到达自己的影片结尾，而所有时间滤镜都会忽略时间轴。

另一方面，你可以在设为使用 index 驱动的参数中，用 me.time.frame 或 me.time.seconds 表达式把某些内容锁定到时间轴。

在每秒帧数设为 60 时，帧步长为 1/60 秒。由于 TouchDesigner 并不总能实时渲染，当它实时向前播放时会跳帧以跟上进度，但 Time Sliced 的 CHOP 会在内部尽可能计算中间帧。

尽管可能跳帧，你可以确信实时播放 4 秒后，它已向前步进 240 帧。

CHOP 中的帧

CHOP 对帧和时间有自己的看法。CHOP 中涉及时间的参数（length-trim time）可以用三种时间单位表示：秒、采样（索引）或帧。CHOP 可以有自己的采样率，设为每秒 120 个采样，但对 CHOP 而言，一个帧步进与时间轴上的帧步进完全相同。因此当时间轴设为每秒 60 帧时，它等同于 CHOP 中的 120/60 = 2 个采样。所以 CHOP 中的 60 帧仍然是 1 秒，无论 CHOP 的采样率是多少。

TOP 和影片文件中的帧

尽管时间轴可能设为每秒 60 帧，像 QuickTime MP4 影片文件这样的输入影片对「帧」有自己的理解，通常内置设置为每秒 30 张图像。当 Movie File In TOP 读取影片时，用户可以用「index」、「frames」、「seconds」或「fraction」来引用这些图像。与 CHOP 一样，「frames」仍指时间轴帧，第 61 帧是影片中第 1 帧之后的一秒。要引用影片内置的例如 30 这个设置，需要用「index」来指定这些图像，其中索引 0 是第一张图像，索引 30 是第 31 张图像（一秒之后）。
