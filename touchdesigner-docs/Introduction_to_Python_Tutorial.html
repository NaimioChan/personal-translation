Python 入门教程

本教程是对使用 Python in TouchDesigner 的一般性介绍。它不要求你事先了解 Python，但也不讲「如何编程」。学习 Python 的通用资源见 here。有经验的程序员也能从这里的资料中很快掌握在 TouchDesigner 中工作的基础。

参数表达式中的 Python

使用 Python 最简单、最常见的地方之一就是 parameter expressions。参数表达式让你能写一行 Python 程序来设置参数的值。如果表达式的值发生变化，参数的值会自动更新。

本节将教你编写参数表达式的全部基础。TouchDesigner Python 表达式的详细示例列表，见 Python Tips 中的 Expressions 部分。

编写一个简单的 Python 表达式

首先，使用 OP Create Dialog 创建一个 Text TOP，从 TOP 族中选择 Text。如果 Parameter Dialog 没有打开，按快捷键 p 打开它。

要在「Text」参数中输入表达式，点击参数名展开它，然后按蓝色方块。此时它进入表达式模式。在输入区域中输入 

'Hello World!'

然后按 <Enter> 键。你应当会看到：

引号很重要，它让 Python 知道「Hello World!」是一个字符串（一串字母）而不是一条命令。现在我们来试试一条命令。把你的表达式替换为 

absTime.frame

现在你能看到当前帧在参数和 TOP 显示中都在变化。拆解一下这个简短的表达式，它有两个部分：absTime 是 TouchDesigner 的 absolute time 对象，. 告诉 Python 你想取它里面的信息（称为成员），而 frame 是你想从 absTime 中取得的具体内容。

这个简单的过程能让你在 TouchDesigner 中创建强大的交互。一般来说，你只需要用 Python 代码写简短的表达式，说明你想要的那份数据。TouchDesigner 的强大之处部分在于，（大多数情况下）如果这些信息发生变化，你的参数中会自动更新。

在表达式中访问操作符：me、op 和 parent

虽然 absTime 是 TouchDesigner 中独立的对象，但大多数时候你会从网络中的操作符获取信息。要使用表达式所在操作符的信息，你使用 me 对象。在 Text DAT 的「Text」参数表达式中写下 me.name。点击操作符更改它的名字，你会看到查看器中反映出变化。

下一个例子，在你的 Text TOP 旁放一个 Rectangle TOP。op 命令（op 代表「operator」）让你导航到其他操作符并获取它们的信息。在 Text TOP 的「Text」参数中，输入 op('rectangle1').type。现在你应当得到：

你可能已经猜到，文本现在显示的是 rectangle1 的操作符类型。我们再拆解一下这个表达式。op 后面的括号表示它是一个「函数」。函数是一条（通常）需要额外信息的命令，这些额外信息称为参数。这里的额外信息是 'rectangle1'，它指明你要哪个操作符。之后是熟悉的点号记法，说明你想要所命名操作符的 type。'rectangle1' 是 TouchDesigner 的 path，你会一直用到它们。你可能从文件浏览器中熟悉这种记法。在下面的例子中你会注意到，以 / 开头的路径是「绝对」路径，从项目的顶层网络（也称为 root）开始；而不以 / 开头的路径是「相对」路径，意思是路径从表达式所在的操作符开始。

Path Expression Result
op('rectangle1') operator named rectangle1 next to me
op('comp/rectangle1') operator named rectangle1 inside an operator named comp next to me
op('/project1') operator named project1 at the top network level
op('/project1/rectangle1') operator named rectangle1 inside the operator named project1, which is at the top network level
op('..') the operator I am inside, a.k.a. my "parent"
op('.') the operator containing the expression, same as me
op('./rectangle1') an operator named rectangle1 inside me

访问操作符的另一种常见方式是使用 parent。parent() 函数返回网络层级中上一级的组件。你也可以给它一个数字，这样 parent(2) 会返回网络层级中上两级的组件。

使用 parent 和 op 的操作符快捷方式

parent 对象还可以用于在层级中向上搜索指定名字的 Parent Shortcut。例如，在 Text TOP 的「Text」参数中输入这个表达式： 

parent.Project

这会返回操作符 /project1，因为在教程文件中，project1 组件带有 Parent Shortcut Project。你可以打开 /project1's 参数框，在「Common」页上查看「Parent Shortcut」参数来确认这一点。使用这种 parent.<shortcut> 语法会一直向上搜索，直到找到带该 Parent Shortcut 的操作符。

同样，op 对象可以用于在 TouchDesigner 文件中的任何位置搜索带 Global OP Shortcut 的组件。举例来说，再次打开 /project1's 参数，在「Common」页的「Global OP Shortcut」参数中输入 MyGlobal。现在你可以在 Text TOP 的「Text」参数表达式中输入 op.MyGlobal 来获取该操作符。

这里有几条重要说明。Global OP Shortcuts must be unique. 文件中同一个名字只能有一个。它们最好只用于文件中最重要、最独特的组件。Parent Shortcuts don't have to be unique and the first one found searching upward will be returned. 这些快捷方式经常被使用；强烈建议给你的自定义组件在其顶层指定一个 Parent Shortcut。

你也可以组合各种查找操作符的方式。例如 parent.Project.op('text1') 会返回 /project1 内部的 text1 操作符。

在表达式中访问参数：par

操作符上的参数可以通过 par 对象访问。先展开 rectangle1 上的「Size」参数。你会注意到有两个独立的值，「sizex」和「sizey」，它们才是真正的参数名。把「sizey」填入 expression mode 并输入 

me.par.sizex

当你改变「sizex」时，「sizey」现在会保持同步，让矩形保持正方形。现在，在你的 Text TOP 的「Text」参数中，输入这个表达式： 

op('rectangle1').par.sizex

现在改变「sizex」也会让显示的文本保持同步。回顾一下，这里的一般流程是用 me 或 op 到达你想要的操作符，然后通过 par 对象访问你想要的参数。

访问 CHOP 通道

参数表达式的另一个常见用途是访问 CHOP 通道数据。这个例子中，放一个 Beat CHOP。这次我们不用手写表达式，而是用拖放来创建它。按以下步骤操作：

  1. 按下 Beat CHOP 右下角的 + 按钮，使它的查看器激活。
  2. 选择 rectangle1 查看它的参数对话框。
  3. 把「ramp」通道拖放到「Size」参数中左侧（x）的输入框里。
  4. 从弹出菜单中选择 CHOP Reference。

现在「sizex」中会有如下表达式： 

op('beat2')['ramp']

在 Python 中，[] 方括号记法用于指定集合中的元素。这里，因为 CHOP 可以有多个通道，你通过把通道名放进方括号来指定要哪一个通道。通常你会想用名字，但你也可以按编号选择通道。把「sizex」表达式改为 op('beat2')[0]，你会看到相同的结果。注意在 Python 中，顺序列表的第一个元素总是从零开始，而不是一。

更复杂的表达式、错误与 eval

你可能已经注意到，你的 Text TOP 现在显示一堆难以辨认的数字，因为 CHOP 发送的数据变化很快，且位数很多。要解决这个问题，我们将使用 Python 的 round 函数，它接受两个参数：要舍入的数字，以及要显示的小数位数。在 Text TOP 的「Text」参数中输入以下内容： 

round(op('rectangle1').par.sizex,1)

参数变红，操作符上出现一个红色 X 标记。这就是错误的样子。别担心，错误是写脚本时无法避免的一部分。在我们修复它之前，值得看看查看错误信息的几种不同方式。一是将鼠标悬停在参数或表达式上。另一种是点击节点上的红色 X 标记。 这个具体的错误是 td.Par doesn't define __round__ method。问题在于，严格来说 op('rectangle1').par.sizex 返回的是一个参数对象，而不是 round 函数需要的实际数值。通常使用参数对象是可行的，但偶尔你会遇到这个问题，需要把参数转换成值。要做到这一点，使用 eval 函数。把你的表达式改成这样： 

round(op('rectangle1').par.sizex.eval(),1)

TouchDesigner Python 表达式的详细示例列表，见 Python Tips 中的 Expressions 部分。

Textport 中的 Python

在 TouchDesigner 中使用 Python 时，打开一个 Textport 非常有帮助。对于快速任务，你可以按 alt-t 打开一个浮动 textport，但对于像本教程这样更长时间的 Python 工作，建议打开一个 textport 窗格。操作如下：

  1. 点击 TouchDesigner 网络视图上方最右侧的向下箭头，选择「Split left/right」。
  2. 点击新窗格上方最左侧的向下三角形，选择「Textport and DATs」。

在处理 Python 时，textport 有以下实用功能：

  • 显示 Python 代码中 print 和 debug 语句的输出。
  • 显示 Python 代码的所有错误信息。
  • 让你测试简单的 Python。

做个简单测试，在 textport 中输入 print('Hello World!') 并按 <Enter>。

在 Textport 中使用 TouchDesigner 对象

从 textport 访问 TouchDesigner 对象与在参数表达式中非常相似。最常见的情况是，你会从一个操作符开始，这意味着你需要它的路径。有一个很好的技巧：

  1. 在 textport 中输入 r = op('。不要按 <Enter>。
  2. 把你的 rectangle1 操作符拖放到 textport 中。路径会自动追加到你的命令后面。
  3. 输入 ') 并按 <Enter> 完成这一行。

你现在已经把矩形操作符赋值给变量 r。输入 r 并按 <Enter>，你会看到关于该操作符的信息。这里还有几件可以顺便试试的事：

Textport Command Result
r.name the operator name
r.par.fillcolorr the value of the fill color parameter's red attribute
r.par.fillcolorr = 0 set the value of fill color red to 0
dir(r) a list of the data and functions available in the operator
help(r.resetViewer) show help for the operator's resetViewer method

你可以用这个技巧查看 TouchDesigner 对象、测试简单的 Python 代码，以及执行简单的、一次性的 Python 任务。

DAT 中的 Python

任何比表达式更复杂的 Python 代码都写在 [DAT|DATs] 里。你会在这四个主要位置找到 / 创建这类代码：

  1. Callbacks (callback DATs and execute DATs) - 响应各种 TouchDesigner 事件
  2. Script Operators - 实际上是回调 DAT 的一个子集，这类代码用于在这些特殊操作符中生成内容
  3. Extensions - 为自定义组件创建 Python 接口
  4. Standalone modules - 通用的、可复用的 Python 代码

在我们深入 DAT 中的 Python 之前，如果你还没有设置外部编辑器，不妨先设置一个。DAT 和 textport 都可以用来编辑，但外部编辑器提供更多工具，包括语法高亮、代码折叠等。相关设置请参阅 Editing DAT Text in an External Editor。

下面各节将在上文 Python in Parameter Expressions 中描述的简单示例基础上展开。

回调

回调让你能用 Python 响应 TouchDesigner 中多种不同类型的变化。有些操作符在创建时会自带回调 DAT，例如 Timer CHOP；而另一些回调 DAT 则作为独立的操作符类型存在，例如 Parameter Execute DAT。

这个例子中，在 Python in Parameter Expressions 一节里创建的操作符旁放一个 Parameter Execute DAT。要把它设置为监视 Text TOP 的「Text」参数，请按以下步骤操作：

  1. 把 Text TOP 拖到 parexec1 DAT 的「OP」参数中。它现在应当包含 Text TOP 的名字。我们前面改过这个名字，所以你的可能不一样。
  2. 要指定监视哪个参数，在 parexec1 DAT 的「Parameters」参数中输入 text。

参数设置好了，现在可以写 Python 了。右键点击 parexec1，选择「Edit Contents...」。我们希望在参数值变化时运行代码，所以先确认我们能正确收到消息。把 onValueChange 回调改成这样： 

def onValueChange(par, prev):
	debug(par)

如果你回头看 textport，会看到参数中的数字每十分之一秒出现一条调试输出。为了展示一下你可以用它做的有意思的事，现在把 onValueChange 回调（包括上面的 import 行）改为： 

import random

def onValueChange(par, prev):
	op('rectangle1').par.fillcolorr = random.random()
	op('rectangle1').par.fillcolorg = random.random()
	op('rectangle1').par.fillcolorb = random.random()

现在每次 Text TOP 的「Text」参数变化时，你都会看到矩形的方块变成随机颜色。这种效果仅靠参数表达式是无法实现的。

对不熟悉 Python 的人来说，import 语句是用来引用外部 Python 代码（称为 modules）的方式。导入模块 random 之后，你就可以使用其中恰好也叫 random 的函数。要查看 TouchDesigner 可用的模块列表，请前往 here。

print 与 debug 的区别

上面一节中有一件重要的事需要注意，就是 debug 命令。它是 TouchDesigner 的一个实用工具，作用很像 Python 的 print 语句，但会自动加上 debug 命令来自网络中的哪个位置。在 TouchDesigner 中，你经常需要把信息发送到 textport 来修复脚本中的问题。做这件事时，你应当始终使用 debug 语句，而不是 print。

Execute DAT

Execute DAT 是提供 TouchDesigner 事件回调的 DAT 操作符。例如，上面的例子就用 Parameter Execute DAT 来响应参数值的变化。以下是各种 execute DAT 及其响应的事件：

  • CHOP Execute - CHOP 通道的变化
  • DAT Execute - DAT 表格的变化。
  • OP Execute - 操作符的一般变化，例如名称、子级、连线等。
  • Panel Execute - 与 Panel Component（UI）的交互。
  • Parameter Execute - 参数值与设置的变化
  • Execute - 系统事件，例如启动、保存文件、创建操作符等。

所有这些的示例见 OP Snippets。

Script 操作符

Script 操作符是提供回调、并由回调实际生成操作符自身数据的操作符。放置这类操作符时，会自动附带一个回调 DAT。在 DAT 中，你可以编辑 onCook 回调，定义该操作符在计算时的行为。以下是 Script 操作符列表：

  • Script CHOP - 用 Python 创建 CHOP 及其通道。
  • Script DAT - 用 Python 创建 DAT 表格。
  • Script SOP - 用 Python 通过点、曲线、网格等创建 SOP。
  • Script TOP - 用 Python 创建 TOP 图像。

所有这些的示例见 OP Snippets。

扩展

Extensions 是 Python 类，让你把数据和功能构建进自定义 components。关于扩展有很多内容，下面教程只会触及表面。要更深入地了解扩展，请参阅 here。这种添加 Python 属性和函数的简单技巧，为自定义组件赋予扩展的 Python 功能，威力极大。

创建扩展

要创建默认扩展，请按以下步骤操作：

  1. 新建一个 Container COMP
  2. 在新组件上使用 RMB Menu，选择「Customize Component...」
  3. 展开「Extension Code」部分
  4. 输入名称 TutorialExt，然后按「Add」
  5. 按「Edit」查看内容

里面有很多内容我们这里不深入，但为了了解扩展是做什么的，只需注意这几行代码： 

		# 属性：
		self.a = 0 # 属性
		self.B = 1 # 提升（promoted）属性

在组件内部访问扩展

要看看扩展的实际效果，进入容器 COMP 内部。你首先会注意到里面有一个名为 TutorialExt 的 DAT。实际扩展文本就在这里，你可以通过上文所示的 Component Editor 编辑它，也可以直接修改这里的 DAT。

这个例子中，在容器内创建一个 Text TOP。把 Text TOP 的「Text」参数改为表达式模式（点击蓝色方块），然后输入以下表达式： 

ext.TutorialExt.a

这里用 ext 对象向上搜索 TutorialExt，并返回它的 a 属性。Extensions can be accessed from anywhere inside their component using the ext object. 你也可以把表达式改为 ext.TutorialExt.B 来查看那个值。扩展属性和扩展函数都可以这样使用。

在组件外部访问扩展

扩展中被提升的成员也可以从组件外部访问。Extension members are "promoted" when they start with a capital letter. 这对属性和函数都适用。

要看看实际效果，按快捷键 u 向上离开组件。在这里再创建一个 Text TOP，同样在其「Text」参数中输入表达式。这次的表达式是：op('container1').B。如你所见，扩展属性表现得就像容器 COMP 自身的成员。如果你尝试表达式 op('container1').a，就会得到错误。这是因为只有首字母大写的扩展属性和函数才会被提升到这一层。

把 DAT 当作模块

所有含 Python 代码的 DAT 都可以当作模块使用。但导入这些模块与大多数 Python 略有不同，因为它们存在于 TouchDesigner 网络中，而不是文件里。下面的例子请在 /project1 中操作。

放置一个 Text DAT，重命名为 utils。输入以下函数： 

def my_adder(x,y):
	return 10*x+y

再添加一个 Text DAT，重命名为 test。在这个 DAT 中输入以下内容： 

import utils
a = utils.my_adder(1,3)
print(a)

打开 textport，然后右键点击 test 模块的节点并选择「Run Script」来运行它。Note: if your node viewer is active on test you will have to right-click on its name bar.

你会在 textport 中看到生成的 13。my_utils DAT 已经用 import 语句被当作模块处理。

组件模块

要创建能在组件内任何位置访问的 Component Modules，你必须把它们放在该组件的特定子级中，即 local/modules。如果这条路径还不存在，你可以创建一个名为 local 的 Base COMP，并在其中再放一个名为 modules 的 Base COMP。

TouchDesigner 中的 import 语句

TouchDesigner 使用 import 语句的一个特殊版本，它按以下顺序查找模块：

  1. 当前组件
  2. 当前组件的组件模块
  3. 各级父级的组件模块，直到根组件
  4. /sys 组件的组件模块（TouchDesigner 内部模块）
  5. 常规的 Python 磁盘搜索

Note: When you attempt to import an external module, it will first look for DATs of that name in the same folder , so be sure to avoid name conflicts keeping the above search order in mind.

按需加载模块：mod 对象

import 语句虽然有用，但有两个缺点：

  • 模块名必须是单个词，因此不能使用相对 DAT 路径。
  • 它们不适合在参数表达式中使用。

为避免这些问题，请使用 Module On Demand 或 mod 对象。

在 DAT test 中，把内容替换为以下代码： 

a = mod.utils.my_adder(1,3)
print(a)

注意这里不需要 import 语句，因此这种求值方式适合单行参数表达式。

字符串路径（包括相对路径）也可以用在 mod 对象中。只需把字符串作为参数传给 mod 对象： 

a = mod('utils').my_adder(1,3)
print(a)

绝对路径和相对路径都可以使用： 

a = mod('/project1/utils').my_adder(1,3)
print(a)

以上所有写法都会得到相同的输出。

Note: mod uses the same search order described above for import.

module 成员

你也可以通过 DAT 的 module 成员把它当作模块访问。用这种方法，test 脚本会写成： 

a = op('/project1/utils').module.my_adder(1,3)
print(a)

当确切知道模块所在位置、并想避开 TouchDesigner 任何自动搜索时，这种访问方式很有用。

模块的自动重新编译

如果你在模块的根级代码中（而不是在函数或类中）访问 CHOP 通道或参数之类的 TouchDesigner 对象，那么每当该 TD 对象变化时，模块都会自动重新编译。这会导致变慢和意外的结果，所以最佳做法是把这类引用放在函数里。此外，某些边缘情况下模块会 not 自动重新编译，这会造成更多困惑。下面演示了最佳做法： 

# 不要这样做。每当 value0 变化时模块都会重新编译
value = op('constant1').par.value0

# 这样做：
def value0():
	return op('constant1').par.value0
