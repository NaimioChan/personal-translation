TouchPlayer


TouchPlayer 只能在 Perform Mode 中运行由 TouchDesigner 创建的文件。TouchPlayer 没有用于创作文件的设计界面，它只用于回放 TouchDesigner 项目。

TouchPlayer Non-Commercial 对非付费、非商业用途免费。以 Non-Commercial 形式下载和使用 TouchPlayer 无需许可证、密钥或注册。这是与不使用 TouchDesigner 的人分享作品的好方式。他们只需安装 TouchPlayer 并运行你的文件。

TouchPlayer Commercial 许可证可用于付费项目，功能集与 TouchDesigner Commercial 相同。可在 Store 中购买，每份许可证 $300。

TouchPlayer Pro 许可证可用于付费项目，功能集与 TouchDesigner Pro 相同。可在 Store 中购买，每份许可证 $800。

TouchPlayer 提供 Volume Discounts。

安装

Windows 上的 TouchPlayer 包含在 TouchDesigner 安装程序中。要安装 TouchPlayer，请使用 TouchDesigner 安装程序并选择 Custom Install and TouchPlayer Options。点击 Install 后，会出现安装 TouchPlayer 的选项。

在 macOS 上，TouchPlayer 是独立的应用程序和安装程序，可与 TouchDesigner 并排安装。

TouchDesigner 和 TouchPlayer 安装程序可在 Official Downloads page 获取。

TouchPlayer 的工作方式

  • TouchPlayer 可打开 TouchDesigner 支持的任何 file type，并且只能在 Perform Mode 中运行。
  • 对于 .toe 文件，perform 模式的设置可由 TouchDesigner 文件的作者自定义。
  • 每个 TouchPlayer Non-Commercial 窗口都会添加一个小控制面板，包含播放/暂停、全屏、Key Manager、帮助和退出控件。使用 Commercial 或 Pro 许可证时该控制面板会被隐藏，但仍可访问。
  • TouchPlayer Non-Commercial 会要求用户确认访问某些外部设备（如用于视频/音频输入的摄像头和麦克风）和系统服务，例如 web（通过 Web DAT）或网络（通过网络操作符）。Commercial 和 Pro 中不会显示这些确认对话框。
  • TouchPlayer 的系统要求与 TouchDesigner 相同。

提示：在 TouchPlayer 和 Perform Mode 中使用 Shift-Spacebar 暂停/取消暂停时间轴。

使用 TouchPlayer

在 Windows 上安装 TouchPlayer

在 Windows 上，TouchPlayer 使用与 TouchDesigner 相同的安装程序。安装 TouchDesigner 时，可以选择在桌面创建 TouchPlayer 图标、将 TouchPlayer 添加到打开方式...菜单，以及将其设为打开 .toe 文件的默认应用程序。

启动安装程序，并在出现提示时选择 Custom install and TouchPlayer options。

然后在安装程序的下一对话框中，选择你想要的 TouchPlayer（以及 TouchDesigner）选项。然后点击 Install。

启动 TouchPlayer

要启动 TouchPlayer，请将要打开的文件拖放到 TouchPlayer 桌面图标上。或者，如果安装过程中选择了该选项，你可以右键点击该文件，在 Open With... 菜单中选择 TouchPlayer。


        


你也可以通过双击 TouchPlayer 桌面图标（如果安装过程中选择了该选项）或从 Start > Programs 菜单中选择它来启动 TouchPlayer。使用后两种方式打开 TouchPlayer 时，将打开如下所示的 TouchPlayer 启动对话框。

TouchPlayer Non-Commercial 控件

These features will not appear when using a Commercial or Pro license.

将任意 compatible file 拖放到此对话框中，即可在 TouchPlayer 中打开。

TouchPlayer 主窗口的右上角会有一个小控制面板。

点击进入 www.derivative.ca

点击暂停/播放。

点击进入和退出全屏模式。

点击进入 TouchPlayer 帮助页面。

点击退出 TouchPlayer。

为 TouchPlayer 创建合适的文件

虽然 TouchPlayer 可以播放任何 .toe 或 .tox 文件，但应遵循一些准则和最佳实践。

  • 请注意，你分发的 .toe 文件也可以被拥有 TouchDesigner 的人打开和编辑。
  • 如果要保护你的 .toe 文件，必须购买 Pro 并在 .toe 上设置 Privacy 标记：之后，其他人就无法在 TouchDesigner 中打开 .toe 进行检查。
  • 如果你的 .toe 文件是在开启 Privacy 标记的 TouchDesigner Pro 副本中创建的，那么拥有 TouchDesigner 的人将无法打开或编辑该文件。
  • 媒体（图像、影片、音频、数据）可以使用 TouchDesigner 的“Virtual File System”（vfs）嵌入到私有 .toe 文件中。
  • TouchPlayer 的不同许可证使用与对应 TouchDesigner 许可证相同的功能集。许可证对比请参见 Licensing。
  • 请注意，TouchPlayer Non-Commercial 在尝试访问网络连接、Video Device In TOP 或 Audio Device In CHOP 时会打开确认对话框。使用 TouchPlayer Commercial 或 Pro 时不会打开这些确认对话框。
  • TouchPlayer 可打开所有受支持的图像和影片文件，以及 .toe 和 .tox。
  • 虽然 TouchPlayer 不支持网络编辑界面，但你可以通过脚本（即 OP.openParameters() 调用）在任何操作符上打开浮动参数窗口。参见 OP Class。你也可以用 Parameter COMP 将参数对话框嵌入自己的窗口。

使用 TouchPlayer 许可证时进行开发

在使用多个 TouchPlayer 许可证构建项目时，你常常需要到每台机器上编辑/分析运行 TouchPlayer 许可证的网络的当前状态。这可以很容易地做到：

1. 使用 TouchDesigner 可执行文件而不是 TouchPlayer 可执行文件运行应用。TouchPlayer Commercial/Pro 许可证在 TouchDesigner 内仍然有效，但网络编辑器会被禁用 2. 在机器上安装完整的 TouchDesigner 许可证，或插入 License Dongle。网络编辑器将变为可编辑状态，无需重启文件。
3. 完成后，停用 TouchDesigner 许可证或拔下 License Dongle。应用将回退为使用先前安装的 TouchPlayer 许可证。
