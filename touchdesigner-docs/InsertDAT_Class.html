InsertDAT 类


该类继承自 DAT class。 它引用一个特定的 Insert DAT。

成员

subRow → int (Read Only):

Insert DAT 表格表达式的当前行索引。

subCol → int (Read Only):

Insert DAT 表格表达式的当前列索引。

fillName → str (Read Only):

Insert DAT 表格表达式的当前表头名称。

方法

没有该操作符专属的方法。

方法

run(*args, endFrame=False, fromOP=None, asParameter=False, group=None, delayFrames=0, delayMilliSeconds=0, wallTime=False, delayRef=None)→ td.Run:

Run 把 DAT 的内容作为脚本执行，返回一个 Run 对象，可用于选择性地修改其执行。

  • args -（可选）任意数量的参数，它们会以名为 args 的本地元组提供给脚本。
  • endFrame -（关键字，可选）若设为 True，执行将延迟到当前帧结束。
  • fromOP -（关键字，可选）指定一个可选的 operator，执行将相对于它运行。
  • asParameter -（关键字，可选）使用 fromOP 时，相对于 fromOP 的某个参数运行。
  • group -（关键字，可选）可用于指定一个组标签字符串。之后可将该标签与 td.runs 对象配合使用，以修改其执行。
  • delayFrames -（关键字，可选）可用于把执行延迟指定的帧数。
  • delayMilliSeconds -（关键字，可选）可用于把执行延迟指定的毫秒数。此值会四舍五入到最近的帧。
  • wallTime -（关键字，可选）将其设为 True 后，延迟选项将基于实际经过的时间，而不是经过的帧数。
  • delayRef -（关键字，可选）指定一个可选的 operator，它由另一个 Time Component 控制。例如，若你自己的本地时间轴已暂停，可以指向另一个时间轴，以确保此脚本仍会执行。若未提供 delayRef，则使用此 DAT。
# 抓取 DAT
n = op('text1')
# 运行 DAT
n.run()
# 带一些参数运行该数据
r.run('firstArgIsString', secondArgIsVariable)

save(filepath, append=False, createFolders=False)→ str:

将 DAT 的内容保存到文件系统。返回保存到的文件路径。

  • filepath -（可选）保存文件的路径和文件名。若未指定，则会把一个默认命名的文件保存到 project.folder
  • append -（关键字，可选）若设为 True 且格式为 txt，则内容会追加到现有文件中。
  • createFolders -（关键字，可选）如果为 True，则创建 filepath 中尚不存在的目录。
name = n.save() # 以原生格式保存，使用默认名称
n.save('output.txt') # 不带通道名称的人类可读格式
n.save('C:/Desktop/myFolder/output.txt', createFolders=True)  # 提供文件路径和 createFolder 标志

write(args)→ str:

向此 DAT 追加内容。也可用于实现 DAT 打印函数。 

# 抓取 DAT
n = op('text1')
# 直接把消息追加到 DAT
n.write('Hello World')
# 使用 print 方法
print('Hello World', file=n)

detectLanguage(setLanguage=False)→ str:

返回根据所含文本尝试自动检测 DAT 中编程语言的结果。

修改内容

以下方法可用于修改 DAT 的内容。例如，当 DAT 是 Text DAT 或 Script DAT 时可以这样做，或者当 DAT 是 Locked 时也可以。

clear(keepSize=False, keepFirstRow=False, keepFirstCol=False)→ None:

移除表格中的所有行和列。

  • keepSize -（关键字，可选）若设为 True，尺寸不变，但条目会被置为空白，具体取决于下面的其他选项。
  • keepFirstRow -（关键字，可选）若设为 True，第一行单元格会保留。
  • keepFirstCol -（关键字，可选）若设为 True，第一列单元格会保留。
n.clear() # 删除所有行和列
n.clear(keepSize=True) # 将所有表格单元格设为空白
n.clear(keepFirstRow=True) # 删除所有行，但保留第一行
n.clear(keepFirstRow=True, keepFirstCol=True) # 保留第一行、第一列，并将其余单元格设为空白

copy(DAT)→ None:

从指定的 DAT 操作符复制文本或表格。

  • OP - 其内容应被复制到该 DAT 中的 DAT 操作符。

修改文本内容

当 DAT 不是表格，而是一段文本时，可以通过其 text 成员直接访问其内容。 

t = op('merge1').text
op('text2').text = 'merge1 contains:' + t

op('text3').text = "Hello there!"

修改表格中的单个单元格

使用 DAT[row, column]，其中 row, column 指定要修改哪个单元格。行和列可以是从 0 开始的整数，也可以是列名或行名的字符串（分别在行 0 或列 0 中）： 

op('table1')['Monday',1] = 'day1'

tab = op('table1')
tab[0,0] = 'corner'
tab[1,'select'] = 'yes'
tab['Monday',1] = 'day1'

修改表格内容

以下方法可用于修改包含行和列的表格类 DAT 的内容。当 DAT 是基本的 Table DAT 或 Script DAT 时可以这样做。它也可用于向 FIFO 风格的 DAT（如 Serial DAT）追加行。

appendRow(vals, nameOrIndex=None, sort=None)→ int:

在表格末尾或指定的行名/索引之后追加一行。返回新行的整数索引。

  • vals -（可选）若指定，会用给定的值填充该行。它应是一个可表示为字符串的项列表。每一项会被复制到一个 cell 中。
  • nameOrIndex -（可选）若指定，将决定新行追加的位置。若为数值，则表示该行的数字索引。若为字符串，则代表行标签。
  • sort -（关键字，可选）若指定，将决定插入后要保持排序的列。若为数值，则表示该列的数字索引。若为字符串，则代表列标签。
n.appendRow()
n.appendRow( [1,2,3], 'January' )  # 在标签为 'January' 的行之后追加值 (1,2,3)
n.appendRow( [1,2,3], 5 )  # 在第 5 行之后追加值为 (1,2,3) 的行。
n.appendRow( [1,2,3], sort='Month' )  # 追加值为 (1,2,3) 的行，并保持 'Month' 列有序。

appendRows(vals, nameOrIndex=None, sort=None)→ int:

在表格末尾或指定的行名/索引之后追加多行。返回最后追加的行的整数索引。

  • vals -（可选）若指定，会用给定的值填充这些行。它应是一个列表的列表，其中的项可表示为字符串。每一项会被复制到一个单元格中。
  • nameOrIndex -（可选）若指定，将决定新行追加的位置。若为数值，则表示该行的数字索引。若为字符串，则代表行标签。
  • sort -（关键字，可选）若指定，将决定插入后要保持排序的列。若为数值，则表示该列的数字索引。若为字符串，则代表列标签。
n.appendRows()
n.appendRows( [[1,2,3],[4,5,6,7]], 'January' )  # 在标签为 'January' 的行之后追加 2 行：第一行值为 (1,2,3)，第二行值为 (4,5,6,7)
n.appendRows( [[1,2,3]], 5 )  # 在第 5 行之后追加一行，值为 (1,2,3)。
n.appendRows( [1,2,3] )  # 追加 3 行，值分别为 1、2、3。

replaceRow(nameOrIndex, vals, entireRow=True)→ int:

替换现有行的内容。

  • nameOrIndex - 指定将被替换的行。若为数值，则表示该行的数字索引。若为字符串，则代表行标签。
  • vals -（可选）若指定，会用给定的值覆盖该行。它应是一个列表的列表，其中的项可表示为字符串。每一项会被复制到一个单元格中。
  • entireRow -（关键字，可选）若为 True，会覆盖指定行中的每个单元格。若为 False，则只覆盖该行中与 vals 项数相同数量的单元格。
n.replaceRow(0) # 将清空第 0 行中的所有单元格（即替换为空）
n.replaceRow('January', ['January', 1,2,3])  # 行 'January' 将被替换为这 4 项的列表。
n.replaceRow(2, [1,2,3], entireRow=False)  # 在第 2 行，这 3 项将替换该行中的前 3 项。

replaceCol(nameOrIndex, vals, entireCol=True)→ int:

替换现有列的内容。用法类似，参见 DAT.replaceRow。

访问表格内容

[rowNameOrIndex, colNameOrIndex]→ td.Cell:

表格中的 cells 可以用 [] 下标操作符访问。

NameOrIndex 可以是精确的字符串名称，也可以是数字索引值。Pattern Matching not 受支持。

  • rowNameOrIndex - 若为字符串，则指定行名；若为数值，则指定行索引。
  • colNameOrIndex - 若为字符串，则指定列名；若为数值，则指定列索引。
c = n[4, 'June']
c = n[3, 4]

cell(rowNameOrIndex, colNameOrIndex, caseSensitive=True, val=False)→ td.Cell | str | None:

在表格中查找单个 cell，若未找到则为 None。

  • rowNameOrIndex/colNameOrIndex - 若为字符串，则指定行/列名。若为数值，则指定行/列索引。字符串支持 Pattern Matching。
  • caseSensitive -（可选）指定是否区分大小写。
  • val -（关键字，可选）若设为 true，会返回单元格项字符串的列表，而不是 Cell Class 项的列表。
c = n.cell(5, 'June') # 返回第 5 行、'June' 列下的单元格。
c = n.cell('A*', 2) # 查找第 2 列中任意以 A 开头的行下的单元格。
c = n.cell('A*', 2, val=True) # 返回所找到单元格的 str 类型

cells(rowNameOrIndex, colNameOrIndex, caseSensitive=True, val=False)→ list:

返回与给定的行/列名称或索引匹配的 cells 列表（可能为空）。类似用法参见 DAT.cell 方法。

findCell(pattern, rows=None, cols=None, valuePattern=True, rowPattern=True, colPattern=True, caseSensitive=False, val=False)→ Cell | str | None:

返回与给定模式以及行/列名称或索引匹配的单元格；若找不到匹配项则返回 None。

  • pattern - 用于匹配单元格的模式。
  • rows（Keyword，Optional）若指定，则仅在指定的行中查找单元格。必须指定为列表。
  • cols（Keyword，Optional）若指定，则仅在指定的列中查找单元格。必须指定为列表。
  • valuePattern、rowPattern、colPattern（Keyword，Optional）若指定并设为 False，则对单元格、行或列禁用模式匹配。
  • caseSensitive（Keyword，Optional）若设为 true，则单元格匹配区分大小写。
  • val -（关键字，可选）若设为 true，会返回单元格项字符串的列表，而不是 Cell Class 项的列表。
# 给定一个表格 "table1"：
# # id # fruit      # color  #
# # 0  # Strawberry # Red    #
# # 1  # Banana     # Yellow #
# # 2  # Cucumber   # Green  #
# # 3  # Blueberry  # Blue   #
# # 4  # Clementine # Orange #
# # 5  # *Fruit     # Green  #

# t 是指向表格 DAT 的引用
t = op('/project1/table1')

# 搜索任意值为 'Red' 的单元格
# 将返回 type:Cell cell:(1, 2) owner:/project1/table1 value:Red
t.findCell('Red')

# 在 'fruit' 列中搜索值以 'blue' 开头的任意单元格
# 将返回 type:Cell cell:(4, 1) owner:/project1/table1 value:Blueberry
t.findCell('blue*',cols=['fruit'])

# 在 'fruit' 列中搜索值以 'blue' 开头的任意单元格
# 启用区分大小写搜索
# 将返回 None
t.findCell('blue*',cols=['fruit'], caseSensitive=True)

# 将返回 type:Cell cell:(0, 1) owner:/project1/table1 value:fruit
# 由于搜索模式中的 '*' 将用于模式匹配，
# 第二列的第一行被匹配
t.findCell('*Fruit')

# 将返回 type:Cell cell:(6, 1) owner:/project1/table1 value:*Fruit
# 因为搜索模式的模式匹配已禁用
# 因此 '*' 不被解释为模式，而是作为要查找的字符串
t.findCell('*Fruit', valuePattern=False)

# 搜索任意符合模式 '*Fruit' 的单元格
# 将返回所找到单元格的 str，例如 'SweetFruit'
t.findCell('*Fruit', val=True)

findCells(pattern, rows=None, cols=None, valuePattern=True, rowPattern=True, colPattern=True, val=False)→ list:

返回与给定模式以及行/列名称或索引匹配的单元格列表（可能为空）。

  • pattern - 用于匹配单元格的模式。
  • rows（Keyword，Optional）若指定，则仅在指定的行中查找单元格。
  • cols（Keyword，Optional）若指定，则仅在指定的列中查找单元格。
  • valuePattern、rowPattern、colPattern（Keyword，Optional）若指定，则覆盖单元格、行或列的模式匹配。
  • caseSensitive（Keyword，Optional）若设为 true，则单元格匹配区分大小写。
  • val -（关键字，可选）若设为 true，会返回单元格项字符串的列表，而不是 Cell Class 项的列表。

row(*nameOrIndexes, caseSensitive=True, val=False)→ List[Cell]:

返回第一行中与名称/索引匹配的 cells 列表；若未找到则返回 None。

  • nameOrIndexes - 可包含任意多个。若为字符串则指定行名称，若为数字则指定行索引。支持 Pattern Matching。
  • caseSensitive -（可选）指定是否区分大小写。
  • val -（Optional）若设为 true，则返回单元格项字符串列表，而非 Cell Class 项列表。

类似用法请参阅 DAT.col()。 

r = op('table1').row(3, caseSensitive=False)
r = op('table1').row('June')
r = op('table1').row('A*', 'B*') # 返回第一个以 A 或 B 开头的行
r = op('table1').row('June', val=True) # 返回存储在行 'June' 下的所有字符串的列表

rows(*nameOrIndexes, caseSensitive=True, val=False)→ List[List[Cell]]:

返回行列表（可能为空），其中每一行是一个单元格列表。若未给出参数，则返回表格中的所有行。

  • nameOrIndexes -（Optional）可包含任意多个。若为字符串则指定行名称，若为数字则指定行索引。支持 Pattern Matching。
  • caseSensitive -（可选）指定是否区分大小写。
  • val -（Optional）若设为 true，则返回单元格项字符串列表，而非 Cell Class 项列表。

类似用法请参阅 DAT.rows()。 

for r in op('table1').rows():
	# 对行 'r' 做些什么

for r in op('table1').rows(val=True):
    # 对行 'r' 的字符串值做些什么

col(*nameOrIndexes, caseSensitive=True, val=False)→ list:

返回第一列中与名称/索引匹配的 cells 列表；若未找到则返回 None。

  • nameOrIndexes - 可包含任意多个。若为字符串则指定列名称，若为数字则指定列索引。支持 Pattern Matching。
  • caseSensitive -（可选）指定是否区分大小写。
  • val -（Optional）若设为 true，则返回单元格项字符串列表，而非 Cell Class 项列表。
r = op('table1').col(3, caseSensitive=False)
r = op('table1').col('June')
r = op('table1').col('A*', 'B*') # 返回第一个以 A 或 B 开头的列
r = op('table1').col('June', val=True) # 返回存储在列 'June' 下的所有字符串的列表

cols(*nameOrIndexes, caseSensitive=True, val=False)→ List[List[Cell]]:

返回列列表（可能为空），其中每一列本身也是一个列表。若未给出参数，则返回表格中的所有列。

  • nameOrIndexes -（Optional）可包含任意多个。若为字符串则指定列名称，若为数字则指定列索引。支持 Pattern Matching。
  • caseSensitive -（可选）指定是否区分大小写。
  • val -（Optional）若设为 true，则返回单元格项字符串列表，而非 Cell Class 项列表。
for c in op('table1').cols():
	# 对每个列 'c' 做些什么

for c in op('table1').cols(val=True):
    # 对每个列 'c' 中的字符串值做些什么

OP 类

成员

通用

name → str :

获取或设置操作符的名称。

base → str (Read Only):

返回名称中任何数字之前的部分。

digits → int (Read Only):

返回名称中最后一段连续数字的数值，如果找不到则返回 None。如果名称末尾没有数字，则数字可以位于名称中间。

path → str (Read Only):

操作符的完整路径。

id → int (Read Only):

操作符的唯一 id。该 id 也可以传给 op() 和 ops() 快捷方式。重新打开文件时 id 并不一致，并且当 OP 被复制/粘贴、改变 OP 类型、删除/撤销时会发生变化。不过重命名 OP 时 id 不会改变。其数据类型为整数。

op → OPShortcut (Read Only):

操作符查找器对象，用于通过路径或快捷方式访问操作符。注意： 相对于 '/' 搜索的该方法的版本也在全局 td module 中。

op(pattern1, pattern2..., includeUtility=False) → OP or None

返回路径与给定模式匹配的第一个 OP，相对于该操作符内部。如果没找到则返回 None。可以指定多个模式，它们都会加入搜索。也可以使用数字形式的 OP id。

  • pattern - 可以是遵循 Pattern Matching 规则的字符串，指定要返回哪个 OP；也可以是整数，此时必须是 OP Id。可以给出多个模式，将返回第一个匹配的 OP。
  • includeUtility (Optional) - 如果为 True，允许返回 Utility nodes。如果为 False，将忽略 Utility 操作符。
b = op('project1')
b = op('foot*', 'hand*') # 逗号分隔
b = op('foot* hand*')  # 空格分隔
b = op(154)

op.shortcut → OP

通过 Global OP Shortcut 指定的操作符。如果该操作符不存在，就会抛出异常。这些快捷方式是全局的，必须唯一。也就是说，剪切并粘贴一个已指定 Global OP Shortcut 的操作符会导致名称冲突。此时必须重命名其中一个快捷方式。此外，只有组件才能指定 Global OP Shortcuts。
  • shortcut - 对应目标操作符中指定的 Global OP Shortcut 参数。
b = op.Videoplayer

列出所有 Global OP Shortcuts：

for x in op:
	print(x)

opex → OPEXShortcut (Read Only):

操作符查找器对象，用于通过路径或快捷方式访问操作符。其工作方式类似 op() 快捷方法，但找不到节点时会抛出异常，而不是像 op() 那样返回 None。现在推荐在参数表达式中用它获取节点，因为报错信息比例如使用 op() 时常见的 NoneType has no attribute "par" 更有用。注意： 相对于 '/' 搜索的该方法的版本也在全局 td module 中。

op(pattern1, pattern2..., includeUtility=False) → OP

返回路径与给定模式匹配的第一个 OP，相对于该操作符内部。如果没找到则返回 None。可以指定多个模式，它们都会加入搜索。也可以使用数字形式的 OP id。

  • pattern - 可以是遵循 Pattern Matching 规则的字符串，指定要返回哪个 OP；也可以是整数，此时必须是 OP Id。可以给出多个模式，将返回第一个匹配的 OP。
  • includeUtility (Optional) - 如果为 True，允许返回 Utility nodes。如果为 False，将忽略 Utility 操作符。

parent → ParentShortcut (Read Only):

Parent Shortcut 对象，用于通过索引或快捷方式访问父级组件。

注意： a version of this method that searches relative to the current operator is also in the global td module.

parent(n) → OP or None

该操作符的第 n 级父级。如果不指定 n，返回父级。如果 n = 2，返回父级的父级，依此类推。如果该层级没有父级，返回 None。

  • n -（可选）n 是向上攀爬的层级数。当 n = 1 时返回该操作符的父级。
p = parent(2) # 祖父

parent.shortcut → OP

用快捷方式指定的父级组件。如果不存在父级则抛出异常。

方法

通用

注意：create()、copy() 和 copyOPs() 由父级操作符（一个组件）完成。更多信息见 COMP.create, COMP.copy and COMP.copyOPs methods。

pars(pattern)→ list[Par]:

返回与模式匹配的 parameter objects 列表（可能为空）。

  • pattern - 是遵循 Pattern Matching 规则的字符串，指定要返回哪些参数。
newlist = op('geo1').pars('t?', 'r?', 's?') # translate/rotate/scale 参数

注意：如果按名称搜索单个参数，使用下标运算符要高效得多。例如：

name = 'MyName1'
op('geo1').par[name]

parGroups(pattern)→ list[Par]:

返回与模式匹配的 parGroup objects 列表（可能为空）。

  • pattern - 是遵循 Pattern Matching 规则的字符串，指定要返回哪些参数。
debug(op('geo1').parGroups('p*'))

注意： 如果按名称搜索单个 ParGroup，使用下标运算符要高效得多。例如：

name = 'MyColor'
op('geo1').parGroup[name]

或者甚至：

op('geo1').parGroup.MyColor

ops(*patterns, includeUtility=False)→ List[OP]:

返回与该模式匹配的 OP 列表（可能为空），相对于该 OP 内部。

可以提供多个模式。也可以使用数字形式的 OP id。ops 成员严格来说是一个 Python Shortcut Object，而不是真正的方法。

  • pattern - 可以是遵循 Pattern Matching 规则的字符串，指定要返回哪些 OP；也可以是整数，此时必须是 OP Id。可以给出多个模式，将返回所有匹配的 OP。
  • includeUtility -（关键字，可选）如果指定，控制结果中是否包含实用组件（例如 Comments）。

注意： 相对于 '/' 搜索的该方法的版本也在全局 td module 中。

newlist = n.ops('arm*', 'leg*', 'leg5/foot*')

cook(force=False, recurse=False, includeUtility=False)→ None:

如有需要，计算该操作符的内容。

  • force -（关键字，可选）如果为 True，操作符将始终计算，即使在正常情况下不会计算。
  • recurse -（关键字，可选）如果为 True，该操作符的所有子级和子子级都会被计算。
  • includeUtility -（关键字，可选）如果指定，控制结果中是否包含实用组件（例如 Comments）。

copyParameters(OP, custom=True, builtin=True)→ None:

从指定的 operator 复制所有参数。两个操作符应当是同一类型。

  • OP - 要复制的操作符。
  • custom -（关键字，可选）为 True 时会复制自定义参数。
  • builtin -（关键字，可选）为 True 时会复制内置参数。
op('geo1').copyParameters( op('geo2') )

changeType(OPtype)→ OP:

把引用的操作符改为新的操作符类型。调用之后不应再引用这个 OP 对象，而应改用返回的 OP 对象。

  • OPtype - 你想把该操作符改成的那种操作符类型的 Python 类名。这不是字符串，而是全局 td module 中定义的类。
n = op('wave1').changeType(nullCHOP) # 把 'wave1' 变成 Null CHOP
n = op('text1').changeType(tcpipDAT) # 把 'text1' 操作符变成 TCPIP DAT

dependenciesTo(OP)→ list:

返回该操作符与指定操作符之间的操作符依赖路径列表（可能为空）。可能找到多条路径。

evalExpression(str)→ Any:

从该 OP 的上下文中对表达式求值。可用于从任意位置对任意代码片段求值。

  • str - 要求值的表达式。
op('wave1').evalExpression('me.digits')  # 返回 1

如果表达式已经存在于某个参数中，请改用该参数的 evalExpression() 方法。

destroy()→ None:

销毁该 OP 引用的操作符。如果该 OP 的操作符已经被销毁，将抛出异常。

var(name, search=True)→ str:

对 variable 求值。如果找不到，将返回空字符串。从变量中获得的大部分信息（Root 和 Component 变量除外）在 Python 中都可以通过其他方式访问，通常是在全局 td module 中。

  • name - 要搜索的变量名。
  • search -（关键字，可选）如果设为 True（默认值），会搜索操作符层级，直到找到与该名称匹配的变量。如果为 false，搜索将限制在该操作符内。

openMenu(x=None, y=None)→ None:

在 x, y 处打开该操作符的节点菜单。如果未指定 x 和 y，则在鼠标位置打开。

  • x -（关键字，可选）菜单的 X 坐标，以屏幕像素计。
  • y -（关键字，可选）菜单的 Y 坐标，以屏幕像素计。

relativePath(OP)→ str:

返回从该操作符到作为参数传入的 OP 的相对路径。使用表达式的版本见 OP.shortcutPath。

setInputs(listOfOPs)→ None:

把该操作符的所有输入设为指定的列表。

  • listOfOPs - 包含一个或多个 OP 的列表。列表中的项可以为 None，以断开特定输入。空列表会断开所有输入。

shortcutPath(OP, toParName=None)→ str:

返回从该操作符到作为参数传入的 OP 的表达式。使用相对路径常量的版本见 OP.relativePath。

  • toParName -（关键字，可选）返回指向该参数（而不是其操作符）的表达式。

resetPars(parNames='*', parGroupNames='*', pageNames='*', includeBuiltin=True, includeCustom=True)→ bool:

重置该操作符中指定的参数。

如果有任何改动则返回 true。

  • parNames（关键字，可选） - 按 Par 名称指定参数。
  • parGroupNames（关键字，可选） - 按 ParGroup 名称指定参数。
  • pageNames（关键字，可选） - 按参数页名称指定参数。
  • includeBuiltin（关键字，可选） - 包含内置参数。
  • includeCustom（关键字，可选） - 包含自定义参数。
op('player').resetPars(includeBuiltin=False) # 只重置自定义项

unload(cacheMemory=False)→ None:

卸载该节点的 CPU 和 GPU 资源。下次该节点计算时会重新分配内存，因此要确保没有东西仍在使用它，以保持其已释放状态。

  • cacheMemory -（关键字，可选）目前仅由 Movie File In TOP 支持。如果你要预加载到一个已经有视频的 Movie File In TOP，且视频格式/分辨率相同，可以用 cacheMemory 选项先卸载原来的影片并缓存其内存，从而避免在 preload() 发生时重新分配。如果为 True，该影片的内存（纹理、上传缓冲区）会被缓存，供之后另一个影片使用。在你要用相同编解码器和分辨率打开/关闭许多影片时很有用。

asType(opType, checkType=False)→ OP:

把该 OP 转换为给定类型，以便编辑器做代码分析。返回该 OP。

  • opType - 要把该 OP 转换成的类型。
  • checkType：（可选）如果为 True，会检查该 OP 是否为给定的 asType，若不是则抛出异常。

获取与该 OP 关联的警告消息。

  • recurse - 同时获取任何子级或子子级中的警告。

scriptErrors(recurse=False)→ str:

获取与该 OP 关联的脚本错误消息。

  • recurse - 同时获取任何子级或子子级中的错误。

clearScriptErrors(recurse=False, error='*')→ None:

清除脚本执行期间产生的任何错误。这些错误可能在执行 DAT、Script Node、Replicator COMP 回调等时产生。

  • recurse - 同时清除任何子级或子子级中的脚本错误。
  • error - 清除错误时要匹配的模式
op('/project1').clearScriptErrors(recurse=True)

childrenCPUMemory()→ int:

返回该 COMP 所有子级的 CPU 内存总用量。

childrenGPUMemory()→ int:

返回该 COMP 所有子级的 GPU 内存总用量。

外观

resetNodeSize()→ None:

把节点方块尺寸重置为默认的宽度和高度。

查看器

closeViewer(topMost=False)→ None:

关闭该 OP 的浮动内容查看器。

  • topMost -（关键字，可选）如果为 True，则会关闭任何包含该 OP 父级的查看器窗口。
op('wave1').closeViewer()
op('wave1').closeViewer(topMost=True) # 包含 'wave1' 的所有查看器都将被关闭。

openViewer(unique=False, borders=True)→ None:

为该 OP 打开一个浮动内容查看器。

  • unique -（关键字，可选）如果为 False，该 OP 已有的查看器会被复用并置于前台。如果 unique 为 True，则每次都新建一个窗口。
  • borders -（关键字，可选）如果为 true，容纳查看器的浮动窗口会带边框。
op('geo1').openViewer(unique=True, borders=False) # 为 'geo1' 打开一个新的无边框查看器窗口

resetViewer(recurse=False)→ None:

把该 OP 的内容查看器重置为默认视图设置。

  • recurse -（关键字，可选）如果为 True，也会对所有子级和子子级执行此操作。
op('/').resetViewer(recurse=True) # 重置整个文件中所有操作符的查看器。

openParameters()→ None:

打开一个包含该操作符参数的浮动对话框。

存储

Storage 可用于在组件内部保存数据。存储的实现方式是每个节点一个 Python 字典。

如下所述，使用 n.store() 改变存储中的元素时，依赖它的表达式和操作符会自动重新计算。可用 n.fetch() 函数取出。

存储在 .toe 和 .tox 文件中保存，并在启动时恢复。

存储可以保存任何 Python 对象类型（不只是 Tscript 变量那样的字符串）。存储元素还可以有可选的启动值，单独指定。例如，可以用这些启动值来避免保存和加载某个与本次会话相关的对象，转而保存或加载像 None 这样定义明确的对象。

以程序方式查看存储内容的方法见 Examine DAT。

fetch(key, default, search=True, storeDefault=False)→ Any:

从该 OP 的存储字典中返回一个对象。如果找不到该项，且提供了默认值，则返回该默认值。

  • key - 要取出的条目的名称。
  • default -（可选）如果提供，且找不到条目，则返回传入的值/对象。
  • storeDefault -（关键字，可选）如果为 True 且找不到该键，则连默认值一并存储。
  • search -（关键字，可选）如果为 True，会递归搜索每个 OP 的父级，直到找到匹配。
v = n.fetch('sales5', 0.0)

fetchOwner(key)→ OP:

返回包含该存储键的操作符，如果找不到则返回 None。

  • key - 你要找的存储条目的键。
who = n.fetchOwner('sales5') # 查找带有名为 'sales5' 的存储条目的 OP

store(key, value)→ Any:

把键/值对加入该 OP 的存储字典，如果已存在则替换。如果该值不打算在 toe 文件中保存和加载，可以用下文所述的 storeStartupValue 方法为保存和加载指定另一个值。

  • key - 存储条目的字符串名称。用该名称通过 fetch() 取出值。
  • value - 要存储的值/对象。
n.store('sales5', 34.5) # 存储一个浮点值 34.5。
n.store('moviebank', op('/project1/movies')) # 存储一个 OP，以便稍后快速访问。

unstore(*keys)→ None:

对每个键，把它从该 OP 的存储字典中移除。也支持模式匹配。

  • keys - 定义要从存储字典中移除哪些键/值对的名称或模式。
n.unstore('sales*') # 删除此 OP 存储中所有以 'sales' 开头的条目

storeStartupValue(key, value)→ None:

把键/值对加入该 OP 的存储启动字典。文件启动时，该存储元素会取这个值。

  • key - 存储启动条目的字符串名称。
  • value - 要存储的启动值/对象。
n.storeStartupValue('sales5', 1) # 'sales5' 在文件启动时将具有值 1。

unstoreStartupValue(*keys)→ None:

对键，把它从该 OP 的存储启动字典中移除。也支持模式匹配。这不会影响已存储的值，只会影响其启动值。

  • keys - 定义要从存储启动字典中移除哪些键/值对的名称或模式。
n.unstoreStartupValue('sales*') # 删除此 OP 的 startup 存储中所有以 'sales' 开头的条目

杂项

__getstate__()→ dict:

返回一个字典，其中是关于该对象的持久化数据，适用于 pickle 和深拷贝。

__setstate__()→ dict:

读取该字典以更新关于该对象的持久化细节，适用于 unpickle 和深拷贝。
