Lock 标记

若节点被锁定，它将不会 cook，其数据在输入或参数变化时也不会更新。节点数据保存在被锁定的操作符中。

另请参阅 Flag。

锁定 TOP

锁定的 TOP 会把图像以未压缩图像数据的形式保存在 .toe 文件中。.toe 文件大小将增加与锁定图像数据大小相同的量。保存了锁定 TOP 的 .toe 文件可被任何人打开，图像仍保留在 TOP 中。例如，锁定的 Movie File In TOP 会把 TOP 图像保存在 .toe 文件中，因此可在任何计算机上打开，即使该 TOP 引用的文件不存在。若之后解除 Movie File In TOP 锁定，TOP 会尝试加载其 File 参数引用的文件。

锁定 SOP

锁定 SOP 可阻止其计算，从而使你对 SOP 所做的手动建模更改（只有锁定 SOP 后才能进行）得以保留，而不是按参数更新。
