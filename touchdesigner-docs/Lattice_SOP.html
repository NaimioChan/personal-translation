Lattice SOP

摘要

Lattice SOP 允许你通过操作包裹输入源几何的网格或细分盒，对输入几何创建动画变形。

通过移动少量网格来使对象变形，比试图为对象的每个点做动画要容易得多。

此 SOP 的按钮很少，看起来很简单，但理解它的工作方式很重要。第一个输入称为 Geometry to Deform，用于要变形的几何。第二个输入称为 Rest Geometry，必须是一个均匀间隔的网格，完整包裹要变形的几何。第三个输入称为 Deformed Geometry，是初始网格的一个副本，以某种方式被改动过：用动画通道移动其部分区域、在 Model Editor 中拖拽其点，或让它经过 Spring SOP 并用模拟物理定律的力使其变形。Lattice 根据 Rest Geometry 与 Deformed Geometry 之间的差异计算变形，并将其应用到输入几何上。该 SOP 的输出是输入源中几何的变形结果。如果 Deformed Geometry 被设为动画，输出也会每帧弯曲、扭转和拉伸。

latticeSOP_Class

参数 - Lattice 页

Group group - 第一个输入中要变形的点的子集。接受模式匹配，如 Pattern Matching 中所述。
Deform Type deformtype - - 选择使用规则间隔的格架还是任意点云进行变形。
  • Lattice lattice - 使用规则间隔的格架进行变形。

Rest Geometry 和 Deformed Geometry 都必须是点顺序符合指定次序的格架。这是 Box SOP 在开启 Use Divisions 时生成的顺序。细分数必须与几何一致，否则会返回错误。

  • Points points - 使用任意点云进行变形。

Rest Geometry 和 Deformed Geometry 必须具有相同的点云。注意，不在 Rest Geometry 中某点指定半径内的点不会被变形。施加到某个点上的变形量基于 Rest Geometry 到 Deformed Geometry 的位移的加权平均值。加权函数取自指定的 metaball 核，因此其行为类似于对 Rest Geometry 中的每个点施加一个磁铁 metaball。

Divisions divs - - 必须设置为与格架网格对象中的细分数一致。
  • X divsx -
  • Y divsy -
  • Z divsz -
Kernel Function kernel - - 通过指定 Kernal Function 和 Points 进行变形，可以更容易地变形任意点云，因为这使格架的拓扑更像 metaball 而不是固定格架。Kernel Function 决定使用哪种 meta 核来确定某个点的影响。有关核类型的更多信息请查看：Metaball Model Types
  • Wyvill model wyvill -
  • Elendt model elendt -
  • Blinn model blinn -
  • Links model links -
Radius radius - 点捕获区域的大小。

操作符输入

  • Input 0: - 要变形的几何。
  • Input 1: - Rest Geometry。
  • Input 2: - Deformed Geometry。

Info CHOP 通道

Lattice SOP 的额外信息可以通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
