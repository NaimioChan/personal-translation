Line MAT

摘要

Line MAT 渲染 3D 线段、点和向量。线宽和颜色可以根据到相机的距离变化，使用两种模型：1/z 衰减（z = 到相机的距离），或远近距离渐变模型，在其中设置近端和远端的宽度与颜色，并调整三个渐变控制参数。

对于线条，它渲染不同类型的端帽与铰接/接头（圆形、方形、箭头）。 光照模型为平面着色（不受场景灯光影响）。它绘制边（如同多边形边）、点以及从点出发的向量。有多种参数控制所需形状，详见参数各节。 它渲染多种图元类型：多边形、网格、NURBS、四边形等。它还处理闭合多边形/开放多边形。

你可以在每个点处渲染一个点。你可以在每个点处渲染一个使用任意属性（如 Normal（N））的向量。点或向量可以有各自的颜色和 alpha。

Line Width 是与分辨率无关的量。线宽为 1 会绘制宽度为图像宽度 1/1000 的线。与正交相机和透视相机配合使用时都是如此。

要让线的宽度及其上的点随 SOP 的每个点变化，可以在被渲染的 SOP 上添加点属性 width 来设置宽度。值为 2 会使该点处的宽度放大为其正常宽度的 2 倍。可以用 Point SOP 的 Custom 页创建新的点属性。要影响逐点宽度而不影响线宽，请使用点属性 pscale。

当你为 Ortho Width 或 Field of View 设置动画时，可能希望线宽调整得更真实。当参数「Width Affected by FOV/Ortho Width」开启时，行为会不同：对于 Ortho 相机，当 Ortho Width 降到 1 以下时绘制线宽增大（就像在放大），升到 1 以上时减小。对于 Perspective 相机，当 Field of View 降到 90 度以下时绘制线宽增大，升到 90 度以上时减小。注意，当参数「Width Affected by FOV/Ortho Width」开启时，线条仍与分辨率无关。

lineMAT_Class

参数 - Setup 页

这是一个通用设置页，用于统一控制 Lines、Points 和 Vectors 的共有特性。该页的每项更改都会影响上述三种类型。

Depth Interpolation Model depthinterpolationmodel - - Depth Interpolation Model depthmodel - 一个菜单，用于选择线元素宽度如何随其到相机的距离变化。
  • S Curve scurve - 近平面与远平面（Distance Near 和 Far）之间有界的宽度范围，使用 S Curve 使变化更具戏剧性但仍然平滑（指曲线的连续性）。曲线形状可通过 Bias、Steepness 和 Linearize 参数控制。
  • Inverse Distance inversedistance - 使用反距离加权，使最终宽度的变化在视觉上更准确。
Inverse Distance Exponent inversedistanceexponent - 当 Depth Interpolation Model 为 Inverse Distance 时，决定宽度/大小随距离减小的速度。若设为 1（默认），宽度按 1/r 的速率减小。若设为 2，则按 1/(r*r) 减小，也就是说距离 r 处宽度为 w 的线/点，在距离加倍（2r）处的宽度/大小是距离 r 处的 1/4。
Distance Near distancenear - 指定一个与相机具有特定距离的近平面。
Distance Far distancefar - 指定一个与相机具有特定距离的远平面。
Width Near widthnear - 当到相机的距离小于或等于 Distance Near 时，指定固定的宽度值。关于线宽的处理方式，见本操作符的摘要。
Width Far widthfar - 当到相机的距离等于或大于 Distance Far 时，指定固定的宽度值。注意，当 Depth Model 选择 Near-Far Range 选项时，Distance Near 与 Distance Far 之间的任意点都会基于正弦曲线计算。
Width Affected by FOV/OrthoWidth widthaffectedbyfov - 关闭时（默认），观看某一分辨率的渲染图像时，无论视野或 ortho width 如何变化，宽度为 w 的线始终是同样多的像素宽。开启该参数后，若视野或 ortho width 加倍，宽度为 w 的线的像素宽度会减半。例如在设置相机缩放动画时很有用。
Width Bias widthbias - 为宽度插值将 S Curve 的 bias 前移或后移（仅 S Curve 深度模型）。
Width Steepness widthsteepness - 控制宽度插值所用 S Curve 的陡峭程度（仅 S Curve 深度模型）。steepness 值越高，曲线宽度的变化越剧烈（斜率更高）。此外，steepness 值越低，曲线越接近线性。
Width Linearize widthlinearize - 控制宽度插值曲线的弯曲程度（仅 S Curve 深度模型）。
Color Bias colorbias - 为颜色插值将 S Curve 的 bias 前移或后移。
Color Steepness colorsteepness - 控制颜色插值所用 S Curve 的陡峭程度。
Color Linearize colorlinearize - 控制颜色插值曲线的弯曲程度。
Lift Direction liftdirection - - 如果线条画在多边形或其边上（该多边形位于另一个 Geometry COMP + 着色器中），而你需要把它抬离表面才能完全可见，此参数指定是朝相机方向还是沿线条法线（可以是多边形法线的方向）偏移线点。
  • Along Camera Z Axis alongcamerazaxis - 沿 Camera Z 轴偏移点。
  • Along Normal alongnormal - 沿点的 Normal 向量偏移点。
  • Toward Camera towardcamera -
Lift Scale liftscale - 对于画在填充多边形之上或沿其边绘制的线条，由于渲染位置相同，可能被裁掉。为了好看，需要把线朝相机或沿其法线抬离表面。该参数缩放把线抬离表面的距离，使其好看又不会分离太远。
Num Points in Circle numptsincircle - 以 Circle（Polygon）模式绘制 Points，或绘制端帽、边之间的弯头时，此参数决定用多少个点来构成一个完整圆弧以模拟圆形。数值越低，渲染越快。

深度测试

深度测试是把正在绘制的像素的深度值与 Frame-Buffer 中当前像素的深度值进行比较。被判定在 Frame-Buffer 中当前像素之前的像素会绘制在其上。被判定在当前像素之后的像素不会被绘制。深度测试让 3D 场景中的几何能遮挡其后面的几何，也能被前面的几何遮挡，与几何的绘制顺序无关。

关于深度测试的更详细描述，请参考 Depth-Test 文章。

线框

线框功能会把几何渲染为线框，使用渲染中实际使用的图元类型。这意味着 Metaballs、NURBs 和 Beziers 等曲面会变成用于渲染它们的三角形/三角形带的线框（因为这些类型的图元无法在 OpenGL 中原生渲染）。

剔除面

cull face 参数会从渲染输出中剔除面。这可以用作优化，有时也用于去除伪影。更多信息参见 Back-Face Culling。

多边形深度偏移

此功能会把多边形向外稍微推后一点点。当你渲染两个正好重叠的多边形并遇到 Z-Fighting 时，这很有用。更多信息请参考 Polygon Depth Offset。在做 shadows 时这也是一个重要功能。

Parameter Color Space parmcolorspace - - 控制如何解释此节点上的所有颜色参数。仅在项目启用了 Working Color Space 时可用。颜色值被视为处于所选色彩空间中，并在作为节点运算的一部分使用之前转换为 Working Color Space。注意这不会改变节点自身的色彩空间，因为它始终处于 Working Color Space。
  • sRGB srgb - sRGB 色彩空间，使用 sRGB 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • sRGB - Linear srgblinear - sRGB 色彩空间，使用线性传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.601 (NTSC) rec601ntsc - Rec.601，NTSC 原色色彩空间，使用 Rec.601 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.709 rec709 - Rec.709 色彩空间，使用 Rec.709（与 Rec.2020 相同）传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.2020 rec2020 - Rec.2020 色彩空间，使用 Rec.2020（与 Rec.709 相同）传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 dcip3 - DCI-P3 色彩空间，D65 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 (D60) dcip3d60 - DCI-P3 "D60 sim" 色彩空间，D60 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Display-P3 (D65) displayp3d65 - Display-P3 色彩空间，D65 白点，sRGB gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACES2065-1 aces2065-1 - ACES 2065-1（也称为 ACES AP0）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACEScg acescg - ACEScg（也称为 ACES AP1）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Passthrough passthrough - 选中后，颜色值将按原样用于运算，不作任何修改，也不尝试将其转换到 Working Color Space。
Parameter Reference White parmreferencewhite - - 在将参数颜色值转换为 Working Color Space 时，此项控制相对于 Reference White 应如何处理。如果 Working Color Space 的 Reference White 相同，则不做调整。如果不同，则此颜色的 Reference White 级别（亮度）将被调整到 Working Color Space 所期望的范围。例如，如果项目将 SDR Reference White 设为 120 nits，而 HDR Reference White 为 80 nits，那么 (1, 1, 1) 的颜色在 SDR 色彩空间中为 120 nits，将被转换为 (1.5, 1.5, 1.5)，在 HDR Working Color Space 中仍为 120 nits。
  • Default For Color Space default - 将根据所选的色彩空间使用 SDR 或 HDR Reference White。
  • Use Parent Panel useparent - 将使用父级面板所选的 Reference White。如果顶层面板也选择了「Use Parent」，则将使用「UI Reference White」。
  • Standard (SDR) sdr - 会将 Parameter Color Space 的 Reference White 值按 SDR 处理。
  • High (HDR) hdr - 会将 Parameter Color Space 的 Reference White 值按 HDR 处理。
  • UI ui - 会将 Parameter Color Space 的 Reference White 值按 UI 处理。其亮度使用「UI Reference White Nits」的值。

Common MAT 信息通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
