FBX

TouchDesigner 使用 FBX 文件格式从 Maya、3DS Max、Cinema4D、Houdini 等软件导入场景、几何和动画。

TouchDesigner 目前使用 FBX SDK 的 2020.3.7 版本。

FBX 是来自 Autodesk 的一种文件格式和一组库，用于在应用程序之间交换模型、动画和图像/纹理数据。TouchDesigner 可读写 FBX 文件，并支持其大部分功能。 另请参阅 File Types

导入 FBX

你可以把 .fbx 拖放到 TouchDesigner 网络中，或直接加载到 FBX COMP 中。也可以通过 File -> Import File... 菜单导入。

导出 FBX

在任何 SOP 上右键，从菜单中选择 'Save Geometry...'，即可把 SOP 几何保存为 .fbx 文件。
