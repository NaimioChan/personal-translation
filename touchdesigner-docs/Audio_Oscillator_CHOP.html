Audio Oscillator CHOP

摘要

Audio Oscillator CHOP 以三种方式生成声音。它重复常见波形（正弦、三角），生成白噪声（每个采样一个随机数），或重复任意时长的已备好的输入音频片段。它通常每秒输出 44100 个采样。相比之下，LFO CHOP 默认生成频率更低、采样率更低（60 采样/秒）的波，不过 Audio Oscillator 与 LFO 可以通过改变频率和采样率互换。

当它从基本波形合成音调时，Audio Oscillator CHOP 依据 Pitch Control 输入以一定速率步进波形。默认情况下，Pitch Control 为 0 给出 440 Hz 的中央 A；为 1 给出 880 Hz；为 -1 给出 220 Hz。Pitch Control 的步长为 1 时相隔 1 个八度。步长为 1/12（.08333）时相隔 1 个半音。

Audio Oscillator 大致参照 APR 2600 voltage-controlled oscillator（VCO）建模。

最多可将三个输入 CHOP 连接到 Audio Oscillator CHOP。

Pitch Control - 第一个（可选）输入影响音高。每个 Pitch Control 通道都会生成输出通道。Pitch Control 为 0 时，输出基频波形（默认在 44,100 采样/秒下为 440 Hz）。它是「对数式」的：默认情况下，Pitch Control 增加 1 使音高提高 1 个八度，增加 2 提高 2 个八度（频率的 4 倍）。

Reset Pulse - 第二个（可选）输入包含脉冲，用于让振荡器从波形或 Playback Source 的开头重新开始。输入为 0 表示「播放振荡器」。为 1 表示「停止振荡器并将其定位于波形或 Playback Source 的开头」。

Playback Source - 第三个（可选）输入用于替换波形 Type。它是一段声音片段，按 Pitch Control 修改后的速率播放，可包含任意数量的通道。每个 Pitch Control 通道都会生成这些通道。波形 Type 和 Base Frequency 参数将被禁用。

如果将任意声音片段接入 Audio Oscillator CHOP 的 Playback Source，且 Pitch Control 为任意时长的常量 0，它就只是重复 Playback Source。若将 Wave CHOP 作为其 Pitch Control 输入，则会提高和降低输入的速率/音高。

Audio Oscillator CHOP 可作为通用的运动时间扭曲器和重复器。如果把运动通道放入第三个输入，可以通过送入不同的 Pitch Control 曲线来控制时间扭曲。pitch 为 0 是正常速度，1 是双倍速度。

与 Wave CHOP 不同，这是一个迭代型 CHOP，即在音高变化时步进波形。要看到此效果，可将 LFO CHOP 接入 Audio Oscillator。与 LFO CHOP 不同，Audio Oscillator CHOP 是为音频频率设计的。

参数 - Waveform 页

Type wavetype - - 要重复的波形形状，除非被 Playback Source 覆盖：
  • Sine sin - （-1 到 1）
  • Gaussian normal - （0 到 1）
  • Triangle tri - （-1 到 1）
  • Ramp ramp - （0 到 1）
  • Square square - （-1 到 1）
  • Pulse pulse - （0 到 1）
  • White Noise whitenoise - -1 到 1 之间的随机采样
Base Frequency frequency - Pitch Control 为零时每秒的周数。
Units per Octave octave - Pitch Control 需增加多少才能使音高提高一个八度。默认值 1 表示 Pitch Control 为 1 时音高提高 1 个八度。Units per Octave 为 .08333 表示 Pitch Control 为 3 时音高提高 3 x .08333 倍（三个半音）。这适合用 MIDI 音符编号作为 pitch control。
Offset offset - 可以为 CHOP 输出的值加上偏移。
Amplitude amp - 可以对 CHOP 输出的值进行缩放。
Bias bias - Triangle、Gaussian 和 Square 波的形状控制。对三角波，它移动峰值。对方波，它改变峰的宽度。零表示无偏置。
Phase phase - 值 .5 表示 180 度的相移，即半个周期。
Smooth Pitch Changes smooth - 如果输入到 Audio Oscillator CHOP 的 Pitch Control 通道正在上升，且运行在 Touch 默认的 60 帧/秒，那么音高会保持 1/60 秒，然后再步进 1/60 秒。这是可听见的阶梯。开启此选项后，音高对每个音频采样都上升，以额外的计算开销实现完全平滑的滑音。
Reset Condition resetcondition - - 此菜单决定 Reset 输入如何触发通道重置。
  • Off to On offtoon - 当 Reset 输入由关变开时重置通道。
  • While On on - 当 Reset 输入为开时重置通道。通道将保持重置值，直到输入变为关。
  • On to Off ontooff - 当 Reset 输入由开变关时重置通道。
  • While Off off - 当 Reset 输入为关时重置通道。通道将保持重置值，直到输入变为开。
Reset reset - 此按钮在 On 时将通道重置为 0。
Reset Pulse resetpulse - 立即将通道重置为 0。

参数 - Channel 页

Sample Rate rate - 以每秒采样数设置 CHOP 的采样率。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Audio Oscillator CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
