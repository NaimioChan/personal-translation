Ray SOP

摘要

Ray SOP 用于将一个曲面投影到另一个曲面上。射线从输入几何的每个点沿其法线方向投射。这可用于在曲面上披挂衣物、用一个对象收缩包裹另一个对象，以及其他类似效果。

raySOP_Class

参数 - 页

Group group - 如果存在输入组，在此字段中指定组名将使该 SOP 仅作用于指定的组。接受模式匹配，说明见 Pattern Matching。
Method method - - 选择 Ray SOP 的投影方法。
  • Minimum Distance minimum - 点被放置在碰撞几何上最近的点处。此方法不使用点法线。用于收缩包裹或将一个图元投影到另一个图元上。
  • Project Rays project - 点沿其法线投影，直到与碰撞几何相交。
Transform Points dotrans - 如果选中，将按下文所述变换输入点。当只关心更新源点属性时，请关闭此项。
Intersect Farthest Surface lookfar - 如果选中，此选项允许用户在与最近的相交对象还是最远的相交对象之间选择。见下方示例。
Point Intersection Normal normal - - 如果选中，用所相交碰撞表面处的法线更新源几何中的每个点。如果该点未与碰撞表面相交，则使用法线 (0,0,0)。
  • Source Normal source -
  • Collision Normal collision -
  • Reflected Ray reflect -
Bounces bounces - 在生成输出位置之前，射线从碰撞表面弹射的次数。例如，如果 bounces 设为 1，则点将投影到它碰到的第一个表面上的位置。如果设为 2，射线将像被反射或弹射一样从第一个表面重新投射，然后投影到射线碰到的下一个表面。示例见第二个 Ray 片段。
Save Bounce Geometry bouncegeo - 启用后，每次投影的射线从表面弹射时都会保存投影后的几何，从而产生输入几何的多份副本。示例见第二个 Ray 片段。
Point Intersection Distance putdist - 如果选中，用与碰撞表面的距离更新每个相交的点。如果该点未与碰撞表面相交，则使用距离 0。该值放入 $DIST 点属性，可从 Point SOP 访问。
Scale scale - 值为零时输入点不受影响。值为一时点落在相交曲面上。负值和大于 1 的值同样有效。
Lift lift - 此值通过沿法线方向偏移表面输入来进一步偏移它。
Sample sample - 此值决定每个点发送的射线数量。如果大于一，其余射线会被随机扰动，并取平均。
Jitter Scale jitter - 控制额外采样射线的扰动。
Seed seed - 允许在更高采样率下使用不同的随机序列。
Create Point Group newgrp - 如果选中，将创建一个点组，包含所有成功相交的点。
Ray Hit Group hitgrp - 指定上述点组的名称。

示例

  1. 放置一个 Grid SOP，并在 TZ 上平移 2.5。开启它的 template 标记。
  2. 向 Grid 附加一个 Point SOP，并启用 Create Point Normals 选项。
  3. 放置一个 Radius 为 2,2,2 的 NURBS Sphere，并在 Z 上平移 -2.5。
  4. 在 Viewport > Display Options 中启用该选项以显示点法线。
  5. 向 Point SOP 附加一个 Ray SOP，并将 Sphere 连接到右侧输入。使其成为显示 SOP。
  6. 反复开启和关闭 Intersect Farthest Surface 按钮。

Ray SOP 会沿点法线方向移动 Grid 的点。Collision Source（右侧输入）的第一个表面将成为这些网格点的落点。启用 Intersect Farthest Surface 选项可以让这些点落在球体的另一侧。这意味着点应继续投影到碰撞源最远的表面。

Info CHOP 通道

Ray SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
