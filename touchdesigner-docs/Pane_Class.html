Pane 类

Pane 类描述 pane 界面的实例。可通过 ui.panes 对象访问。它是 NetworkEditor Class 的父类。

成员

owner → COMP :

获取或设置此窗格指向的 component。

id → int (Read Only):

唯一的数字标识符。

link → int :

获取或设置数字链接索引。

enable → bool :

获取或设置窗格上的鼠标和键盘交互。

maximize → bool :

启用或禁用窗格最大化状态。

name → str :

获取或设置窗格名称。

ratio → float :

获取或设置窗格的分割比例（如果窗格先前已分割）。

bottomLeft → Coords (Read Only):

左下角的坐标，在命名元组中以 x/y 和 u/v 两种形式表示。

topRight → Coords (Read Only):

右上角的坐标，在命名元组中以 x/y 和 u/v 两种形式表示。

open → bool (Read Only):

如果 Pane 当前已打开，则返回 True。

type → PaneType (Read Only):

窗格的枚举类型。示例：NetworkEditor。

该枚举称为 PaneType，包含：

  • PaneType.NETWORKEDITOR
  • PaneType.PANEL
  • PaneType.GEOMETRYVIEWER
  • PaneType.TOPVIEWER
  • PaneType.CHOPVIEWER
  • PaneType.ANIMATIONEDITOR
  • PaneType.PARAMETERS
  • PaneType.TEXTPORT

方法

changeType(paneType)→ td.Pane:

将窗格更改为指定类型。会返回一个表示该窗格的新 Pane 对象。调用后，当前的 Pane 实例将不再有效。

  • paneType - 要将此窗格更改为的窗格类型。
p = ui.panes[0]
p = p.changeType(PaneType.TOPVIEWER)  # 注意：必须把 p 重新赋值为新对象。

close()→ None:

关闭该窗格。

floatingCopy()→ td.Pane:

返回该窗格的浮动副本。

splitBottom()→ td.Pane:

将窗格的下部分割为新窗格。

splitLeft()→ td.Pane:

将窗格的左部分割为新窗格。

splitRight()→ td.Pane:

将窗格的右部分割为新窗格。

splitTop()→ td.Pane:

将窗格的上部分割为新窗格。

tearAway()→ bool:

将窗格分离为浮动窗口。成功则返回 True。
