COMP Instance 3 参数页

参数 - Instance 3 页

自定义属性允许为实例分配任意属性，可在 GLSL MAT 中使用。可通过 TDInstanceCustomAttrib0()、TDInstanceCustomAttrib1() 等访问。更多信息请参阅 Write a GLSL Material。这些属性在其他材质（如 PBR MAT）中会被忽略。

当你需要更多自定义属性时，可以在下方添加更多参数。不同 GPU 支持的最大自定义属性数量不同。

Custom Instance instance - 要分配给实例的任意属性序列
OP instance0customop - 选择特定操作符，为下方的实例属性提供数据。若未指定，则可使用 Instance 参数页上「Default Instance OP」指定的操作符。
X instance0customx - 选择用于此实例属性的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
Y instance0customy - 选择用于此实例属性的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
Z instance0customz - 选择用于此实例属性的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
W instance0customw - 选择用于此实例属性的数据，使用右侧的下拉菜单可从可用选项中方便地选择。
