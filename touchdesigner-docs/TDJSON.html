TDJSON

摘要

TDJSON 模块为 TouchDesigner 中的 JSON 功能提供了多种 Python 实用函数。大多数函数处理 Custom Parameters 和 Parameter Pages，但有些适合更通用的用途。下文提到「JSON object」时，指的是可 JSON 化的 Python 对象；而「JSON 文本」是这类对象的文本表示。

要使用 TDJSON，请在 Python 脚本顶部加入下面一行：

import TDJSON

现在你可以通过以下方式调用下列任何函数：

TDJSON.<function name>(...)

提示： 有关自动转换和筛选，另请参阅 JSON DAT。

See also: JSON, JSON, JSON overview

注意： 较旧版本的 TouchDesigner 需要这样导入 TDJSON：TDJSON = op.TDModules.mod.TDJSON

函数

jsonToText(jsonObject, indent='\t') → JSON text (from json.dumps)

把 JSON 对象作为 JSON 文本返回，使用制表符缩进以便阅读。
  • jsonObject - 一个可 JSON 化的 Python 对象。
  • indent - (Optional) json.dumps 的 indent 参数。默认为 '\t' 以便阅读。

设为 None 以使用 json.dumps 的默认行为。

jsonToDat(jsonObject, dat)

把 JSON 对象作为 JSON 文本写入 dat。
  • jsonObject - 一个可 JSON 化的 Python 对象。
  • dat - 将要填入 JSON 文本的 DAT（使用 jsonToText）。其他文本会被覆盖。

textToJSON(text, orderedDict=True, showErrors=False) → JSON object or None

把 JSON 文本转换为 JSON Python 对象。除非 showErrors 为 True，否则转换失败时返回 None。
  • text - 一个 JSON 文本字符串。
  • orderedDict - (Optional) 如果为 True，返回的 JSON 对象将是 OrderedDict（来自 python 核心模块 'collections'）。
  • showErrors - (Optional) 如果为 True，转换出错时抛出异常，否则出错时返回 None。

datToJSON(dat, orderedDict=True, showErrors=False) → JSON object or None

把存储在 DAT 中的 JSON 文本转换为 JSON Python 对象。除非 showErrors 为 True，否则转换失败时返回 None。
  • dat - 包含 JSON 文本字符串的 DAT。
  • orderedDict - (Optional) 如果为 True，返回的 JSON 对象将是 OrderedDict（来自 python 核心模块 'collections'）。
  • showErrors - (Optional) 如果为 True，转换出错时抛出异常，否则出错时返回 None。

serializeTDData(data, verbose=True) → JSONable data as is, TD serializable format, or repr(data)

为一份 TD 数据返回可序列化的值。统一 OP、Cell、Channel、Page、Par、ParGroup、ParMode 这些 TD 类型的序列化格式。int、float、str、bool、None 原样返回。如果列表或字典可 JSON 化，则原样返回。其他情况返回 repr(data)。
  • data - 任意对象
  • verbose - (Optional) 如果为 True，则为 TD 对象提供完整详情；否则反序列化时需要一些额外数据。

deserializeTDData(data, verboseData=None) → TD object if appropriate info is provided. Otherwise returns data argument unchanged.

如果数据是 serializeTDData 方法在 verbose=True 时返回的格式，则返回一个 TD 对象。如果没有把 verbose 设为 True，则要返回 TD 对象必须提供 additionalInfo。如果不返回 TD 对象，则原样返回数据。
  • data - 任意对象
  • verboseData - (Optional) 要为由 serializeTDData 创建的非 verbose 数据取回 TD 对象，必须提供以下列表：
  • OP：['OP']
  • ParMode：['ParMode']
  • Par：['Par', <Par owner path>]
  • ParGroup：['ParGroup', <ParGroup owner path>]
  • Page：['Page', <Page owner path>]
  • Channel：['Channel', <Channel owner path>]
  • Cell：['Cell', <Cell owner path>]

parameterToJSONPar(p, extraAttrs=None, forceAttrLists=False) → JSON object

把自定义参数、ParGroup 或 tuplet 转换为可 JSON 化的 Python 字典。注意：属于多值 tuplet 成员的参数会为整个 tuplet 创建 JSON 对象。
  • p - 参数、parGroup 或 tuplet
  • extraAttrs - (Optional) 一个列表或元组，包含通常不作为参数定义一部分存储的属性名，例如 'val' 和 'order'。也可以是字符串：'*' 表示该参数的所有属性。
  • forceAttrLists - (Optional) 如果为 True，所有属性都会存入一个长度等于 tuplet 长度的列表

pageToJSONDict(page, extraAttrs=None, forceAttrLists=False) → JSON object

把自定义参数页转换为可 JSON 化的 Python 字典。格式：{parameter name: {parameter attributes, ...}, ...}
  • page - 要转换的页。
  • extraAttrs - (Optional) 一个列表或元组，包含通常不作为参数定义一部分存储的属性名，例如 'val' 和 'order'。也可以是字符串：'*' 表示该参数的所有可序列化属性。
  • forceAttrLists - (Optional) 如果为 True，所有属性都会存入一个长度等于 tuplet 长度的列表

opToJSONOp(o, extraAttrs=None, forceAttrLists=False, includeCustomPages=True, includeBuiltInPages=False) → JSON object

把所有自定义参数页转换为可 JSON 化的 python 字典。格式：{page name: {parameter name: {parameter attributes, ...}, ...}, ...}
  • o - 要转换的 OP。
  • extraAttrs - (Optional) 一个列表或元组，包含通常不作为参数定义一部分存储的属性名，例如 'val' 和 'order'。也可以是字符串：'*' 表示该参数的所有属性。
  • forceAttrLists - (Optional) 如果为 True，所有属性都会存入一个长度等于 tuplet 长度的列表
  • includeCustomPages - (Optional) 如果为 True，则包含自定义 par 页
  • includeBuiltInPages - (Optional) 如果为 True，则包含内置页

addParameterFromJSONDict(comp, jsonDict, replace=True, setValues=True, ignoreAttrErrors=False, fixParNames=True, setBuiltIns=False) → tuple of newly created pars

按参数 JSON 对象的定义向 comp 添加一个参数。要设置值、表达式或绑定表达式，请在 JSON 中提供 'val'、'expr' 或 'bindExpr'。
  • comp - 要添加参数的 COMP。
  • jsonDict - 参数 JSON 字典。
  • replace - (Optional) 如果为 False，参数已存在时会抛出异常。
  • setValues - (Optional) 如果为 True 且 JSON 字典中未提供 "val" 项，则无论参数是否已存在，参数值都会设为默认值。
  • ignoreAttrErrors - (Optional) 如果为 True，JSON 中的无效属性不会引发异常。
  • fixParNames - (Optional) 如果为 True，强制使用正确的大小写。
  • setBuiltIns - (Optional) 如果为 True，若在 JSON 中找到内置参数，则设置其值。

addParametersFromJSONList(comp, jsonList, replace=True, setValues=True, destroyOthers=False, newAtEnd=True, fixParNames=True, setBuiltIns=False) → tuple with (newParNames, newPageNames)

按参数 JSON 字典列表中的定义向 comp 添加参数。
  • comp - 要添加参数的 COMP。
  • jsonList - par JSON 字典的列表。
  • replace - (Optional) 如果为 False，参数已存在时会抛出异常。
  • setValues - (Optional) 如果为 True 且 JSON 字典中未提供 "val" 项，则无论参数是否已存在，参数值都会设为默认值。
  • destroyOthers - (Optional) 如果为 True，不在 jsonList 中的 par 和页将被销毁
  • newAtEnd - (Optional) 如果为 True，新参数会排到页末尾。如果你在 JSON 中使用 'order' 属性，通常应设为 False
  • fixParNames - (Optional) 如果为 True，强制使用正确的大小写。
  • setBuiltIns - (Optional) 如果为 True，若在 JSON 中找到内置参数，则设置其状态。


addParametersFromJSONDict(comp, jsonDict, replace=True, setValues=True, destroyOthers=False, newAtEnd=True, fixParNames=True, setBuiltIns=False) → tuple with (newParNames, newPageNames)

按参数 JSON 字典的字典中的定义向 comp 添加参数。
  • comp - 要添加参数的 COMP。
  • jsonDict - par JSON 字典的字典。
  • replace - (Optional) 如果为 False，参数已存在时会抛出异常。
  • setValues - (Optional) 如果为 True 且 JSON 字典中未提供 "val" 项，则无论参数是否已存在，参数值都会设为默认值。
  • destroyOthers - (Optional) 如果为 True，不在 jsonDict 中的 par 和页将被销毁
  • newAtEnd - (Optional) 如果为 True，新参数会排到页末尾。如果你在 JSON 中使用 'order' 属性，通常应设为 False
  • fixParNames - (Optional) 如果为 True，强制使用正确的大小写。
  • setBuiltIns - (Optional) 如果为 True，若在 JSON 中找到内置参数，则设置其值。


addParametersFromJSONOp(comp, jsonOp, replace=True, setValues=True, destroyOthers=False, newAtEnd=True, fixParNames=True, setBuiltIns=False) → tuple with (newParNames, newPageNames)

按页 JSON 字典的字典（用法同 opToJSONOp）中的定义向 comp 添加参数。
  • comp - 要添加参数的 COMP。
  • jsonOp - 页 JSON 字典的字典。
  • replace - (Optional) 如果为 False，参数已存在时会抛出异常。
  • setValues - (Optional) 如果为 True 且 JSON 字典中未提供 "val" 项，则无论参数是否已存在，参数值都会设为默认值。
  • destroyOthers - (Optional) 如果为 True，不在 jsonOp 中的 par 和页将被销毁
  • newAtEnd - (Optional) 如果为 True，新参数会排到页末尾。如果你在 JSON 中使用 'order' 属性，通常应设为 False
  • fixParNames - (Optional) 如果为 True，强制使用正确的大小写。
  • setBuiltIns - (Optional) 如果为 True，若在 JSON 中找到内置参数，则设置其值。


destroyOtherPagesAndParameters(comp, pageNames, parNames)

销毁 comp 上所有不在 pageNames 或 parNames 中的页和参数。
  • comp - 要销毁页和参数的 COMP。
  • pageNames - 要保留的页名称的可迭代对象。
  • parNames - 要保留的 par 名称的可迭代对象。
