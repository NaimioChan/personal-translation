Monitors DAT

摘要

Monitors DAT 是一张表格，包含所有当前检测到的显示器的数据，其中有分辨率、屏幕位置、显示器名称与描述、GPU，以及一个标记表示它是否为主显示器。

你也可以把它设置为显示所有已检测显示器的整体边界。

当检测到显示器发生变化时，它会运行一个回调脚本。这些变化可以是插入显示器、拔出显示器、显示器分辨率改变或主显示器改变。

Monitor DAT 返回的 top/bottom 值使用左下角为原点的坐标，即 (0,0) 是显示器的左下角。

参数 - Monitors 页

Callbacks DAT callbacks - 表格每次变化（即显示器状态变化）时运行此脚本一次。用法参见 monitorsDAT_Class。
Bounds bounds - 开启时，表格中会额外添加一行「bounds」。其尺寸对应包含所有已检测显示器的边界框。在该行中，「primary」指的是主显示器在表格中的索引。
Monitors monitors - - 指定要报告哪些显示器的信息。
  • All all -
  • Primary primary -
  • Non-Primary nonprimary -
  • Affinity affinity -
  • None none -
Units units - - 指定数字以 Native Pixel 单位还是 DPI Scaled 单位报告。
  • Native native -
  • DPI Scaled dpiscaled -

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

Monitors DAT 的额外信息可以通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
