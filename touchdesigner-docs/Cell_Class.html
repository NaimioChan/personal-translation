Cell 类

Cell Class 描述 DAT 操作符表格中单个单元格的内容。 DAT Class 提供多种访问各个单元格的方式。 DAT 的单元格在内部始终以字符串存储，但可以按数值访问。

重要：op('table1')[1,2] 就是这个 Python 单元格对象，通常会被自动转换为单元格中的字符串。更稳妥的做法是使用 op('table1')[1,2].val，它总是给出字符串。

成员

valid → bool (Read Only):

若引用的单元格当前存在则为 True，若已被删除则为 False。

row → int (Read Only):

单元格的数字行号。

col → int (Read Only):

单元格的数字列号。

owner → OP (Read Only):

此对象所属的 OP。

val → str :

获取或设置单元格内容，它始终以字符串值存储。

方法

run(*args, endFrame=False, fromOP=None, asParameter=False, group=None, delayFrames=0, delayMilliSeconds=0, wallTime=False, delayRef=None)→ td.Run:

把单元格内容作为脚本 Run，返回一个 Run 对象，可用于选择性地修改其执行。

  • endFrame -（关键字，可选）若设为 True，执行将延迟到当前帧结束。
  • fromOP -（关键字，可选）指定一个可选的 operator，执行将相对于它运行。
  • asParameter -（关键字，可选）使用 fromOP 时，相对于 fromOP 的某个参数运行。
  • group -（关键字，可选）可用于指定一个组标签字符串。之后可将该标签与 td.runs 对象配合使用，以修改其执行。
  • delayFrames -（关键字，可选）可用于把执行延迟指定的帧数。
  • delayMilliSeconds -（关键字，可选）可用于把执行延迟指定的毫秒数。此值会四舍五入到最近的帧。
  • wallTime -（关键字，可选）将其设为 True 后，延迟选项将基于实际经过的时间，而不是经过的帧数。
  • delayRef -（关键字，可选）指定一个可选的 operator，延迟时间从中导出。若不提供，将使用单元格的拥有者。
  • arg -（可选）将提供给脚本的参数，放在名为 args 的局部元组中。

offset(r, c)→ Cell | None:

按指定量偏移到另一个单元格，或返回 None。

  • r - 相对该单元格的行数。正值向下计数，负值向上计数。
  • c - 相对该单元格的列数。正值向右计数，负值向左计数。
c = op('table1')['March', 'Sales']
d = c.offset(-1, 2)  # 单元格 C 上方一行、右侧两列

转换为值

Cell 类实现了被当作数字或字符串处理所需的全部方法，在此情况下即获取或设置其值。因此在参数或表达式中使用时，无需显式调用去获取或设置 val。 例如，在数值参数中以下写法等价： 

(float)n[1,2]
n[1,2].val
n[1,2]

对于字符串参数，同样等价： 

(str)n[1,2]
n[1,2].val
n[1,2]

类似地，对 Cell 的表达式会自动进行类型转换： 

n[1,2].val + 1 # 字符串加 1，报错
n[1,2] + 1 # 自动转换后的值加 1

在第二种情况下，会依据 Cell 的内容决定使用数值运算还是字符串运算。 例如，如果单元格 n[1,2] 的内容为「3」，则： 

n[1,2].val + n[1,2].val # 将返回 "33"，因为 .val 是字符串。

但是， 

n[1,2] + n[1,2] # 将返回 6，因为内容 "3" 是数值。

如果 n[1,2] 包含「a」这样的非数值，则 

n[1,2] + n[1,2] # 将返回 "aa"
