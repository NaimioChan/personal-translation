Attribute Combine POP

摘要

Attribute Combine POP 接收多个 POP 输入，可让你按名称或模式匹配从每个输入中选择属性，并将这些属性送到输出。

Inputs 页上有一组用于指定输入的顺序块。对于每个块，你可以将单个输入连线到节点，也可以使用其 In POP(s) 参数通过模式匹配指定一个或多个 POP。

对于每个块，可以使用 In Attributes 和模式匹配来指定想从该输入获取哪些属性。还可以指定新名称来重命名这些属性。

对于每个块，如果与之前的输入存在 name conflict，Duplicate Attributes 菜单会提供以下选择：生成一个递增的新属性名称、使用属性的首次或末次出现，或仅使用第一个输入的属性。

Point, Vertex or Primitive Attributes：第一个输入的所有属性都会送到输出。然后从 Attribute Class 菜单中选择你想从其余输出中传递到输出的属性类型（只能选一个）。例如，你可以合并所有输入中的图元属性。

Length Mismatch 参数让你选择在诸如输入 POP 点数不相同等情况下的处理方式。可以选择不提示用户（None）、在节点上放置 Warning，或在节点上放置 Error。无论如何，当长度不匹配时，对于较短的输入，你可以选择保持属性最后一个点的值、将其设为 0、设为 1，或不做任何处理。

Attribute Combine POP 中这个针对 POP 的 architecture for handling multiple inputs 也存在于许多其他 POP 中，例如 Math Combine POP、Math Mix POP、Blend POP、Merge POP 和 Switch POP。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
