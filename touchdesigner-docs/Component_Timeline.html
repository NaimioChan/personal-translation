组件时间轴

对于任何带 Component Time 的网络，其 network editor 底部会显示 Component Timeline。

该时间轴显示 Component Time 的时间码和当前播放头位置。

该控件左侧有 2 个按钮：

  • I（Run Independently）- 这会将 Component Time 切换为独立于其他 parent Component Time 运行。当 Run Independently 为 on 时，该时间轴会保持其播放状态（播放或停止），不受其他父级时间轴影响。当为 off 时，该时间轴会与层级中更高处找到的第一个时间轴保持同步。
  • S（Scope）- 点击此按钮会把该 Component Time 载入 TouchDesigner 界面底部的 Timeline。Timeline UI 会采用 Component Timeline 的颜色，以表明其 scope 已从 root 时间改变。
不同的 Timeline 颜色表示某个 Component Time 已被 scope
