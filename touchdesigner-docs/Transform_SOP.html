Transform SOP

摘要

Transform SOP 在“物体空间”或相对于 SOP 的局部空间中平移、旋转和缩放输入几何。Model Editor 和 Transform SOP 都在“物体空间”中工作，改变点的 X Y Z 位置。相比之下，在 Geometry Viewer Pane 中为物体的变换通道制作动画，会在“世界空间”中移动/缩放整个物体，不影响几何的 XYZ 点位置。

transformSOP_Class

参数 - Transform 页

Pivot p - 变换的轴心点（与 pivot 通道中的轴心点不同）。轴心点参数让你定义几何围绕哪个点缩放和旋转。修改轴心点会根据对对象所执行的变换产生不同结果。

例如，在缩放操作中，如果对象的轴心点位于 -1, -1, 0，而你想按 0.5 缩放对象（把尺寸减小 50%），对象会朝轴心点方向缩放，看起来像是向左下方滑动。

Normals Maintain Length vlength - 勾选后，向量类属性（即法线、速度）在变换后保持相同长度。也就是说，几何被缩放时，法线长度保持不变。
Look At lookat - 允许你通过指定希望物体 Look At（或指向）的物体来确定物体朝向。指定该物体后，即使你移动它，它也会持续朝向该物体。例如，如果你希望摄像机跟随另一个物体的移动，这很有用。Look At 参数会让该物体指向另一物体的原点。

提示： 要为摄像机指定一个不在场景中显示的兴趣中心，请创建一个 Null 物体并禁用其显示标记。然后将 Camera 父级设为新建的 Null 物体，并使用 Look At 参数让摄像机注视该物体。你可以通过 Select 状态移动 Null 物体来引导摄像机的注意力。如果你想同时看到摄像机和 Null 物体，请启用 Null 物体的显示标记，并通过点击 TouchDesigner 窗口右上角的某个图标，在附加的 Viewport 中使用 Select 状态。

Post Scale postscale - 在应用 Transform 页之后设置几何的缩放。

  • Reference reference - 缩放几何使其适合 Reference Input 的边界框（此 SOP 的第二输入，即 Input 1）。

Info CHOP 通道

Transform SOP 的附加信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
