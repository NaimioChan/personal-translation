Sequence 类

一个描述并控制一组 sequential parameters 的对象。通过以下方式访问

  • parameters 的 sequence 成员
  • OP.seq Sequence Collection - 某个对象的所有序列。
  • 参数表达式中的 me.curSeq
mySequence = op('/add1').par.point0weight.sequence	# 获取序列对象
alsoMySequence = op('/add1').seq.point				# 获取序列对象的另一种方式

# 序列块是一个 SequenceBlock 对象，可访问序列中的一组参数。
print(len(seq))									# 序列中序列块的数量
print(seq[0])									# 序列中的第一个序列块
for parBlock in seq:
	print([par for par in parBlock])			# 打印所有序列块
seq.numBlocks += 1							    # 添加新的序列块（等同于在界面中按 +）

# 示例 2
# 检查 constant CHOP 序列的同级参数

n = op('/project1/constant1')
p = n.par.const2name
p.sequenceBlock.par.name  # const2name
p.sequenceBlock.par.value  # const2value

# 示例 3
# 添加一个包含 float 和 int 参数的序列
base = op('/project1/base1')
page = base.appendCustomPage('Custom')
page.appendSequence('Numbers') # 添加一个序列参数。Sequence 对象会自动获得相同的名称
page.appendFloat('F')
page.appendInt('I')
base.seq.Numbers.blockSize = 2 # 把这两个参数组包含进序列

另请参阅：Sequential Parameters、SequenceBlock Class、SequenceCollection Class

成员

blockSize → int :

获取或设置序列的 blocksize，即块中 ParGroups 的数量。更改它会向序列添加 ParGroups 或从中移除 ParGroups。

blocks → list[SequenceBlock] (Read Only):

此序列中所有块的集合。块是一组可在操作符中重复的参数。见 SequenceBlock 类。

maxBlocks → int | None (Read Only):

序列中允许的最大块数；若无限制则为 None。

name → str :

获取或设置序列名称，它会影响其所有参数名。

blockName → str (Read Only):

获取块名参数的基名。默认情况下，内置序列为 'blockname'，自定义序列为 'Blockname'。

numBlocks → int :

获取或设置此序列中参数块的总数。

owner → OP (Read Only):

此对象所属的 OP。

blockPars → list (Read Only):

一个中间参数集合对象，可从中找到特定的序列参数。

返回一个列表，含每个块中的一个参数。 

n.seq.Info.blockPars.Tx
n.seq.Info.blockPars.Tx[3] # 第 4 个块中的 Par。

n.seq.Info.blockPars['Tx'] # 如果未找到则返回 None。

blockParGroups → list (Read Only):

一个中间 parGroup 集合对象，可从中找到特定的序列参数组。

返回一个列表，含每个块中的一个 parGroup。 

n.seq.Info.blockParGroups.T
n.seq.Info.blockParGroups.T[3] # 第 4 个块中的 ParGroup。

n.seq.Info.blockParGroups['T'] # 如果未找到则返回 None。

sequencePar → Par (Read Only):

定义此序列的主序列参数。

方法

[block index]→ SequenceBlock:

使用 [] 下标与赋值运算符可以方便地访问 Sequence blocks。

  • block index - 所需块的索引。

destroyBlock(block)→ None:

销毁给定位置的参数块。

  • block - 要销毁的现有块的索引。

insertBlock(block : SequenceBlock)→ SequenceBlock:

在给定位置插入一个参数块。

  • block - 要插入的新块的索引。

返回新建的块。

moveBlock(blockFrom, blockTo, num=1)→ None:

把一个或多个参数块移动到给定位置。

  • blockFrom - 要移动的新块的索引或名称。也接受 SequenceBlock 对象。
  • blockTo - 要移动到的块的索引或名称。也接受 SequenceBlock 对象。
  • num - （关键字，可选）要移动的块数。

reorderBlocks(*indexes : int)→ None:

重新排列指定的块，其余块保持原位。

  • indexes - 要重排的块的整数索引，按新的顺序排列。
n.seq.Info.reorderBlocks(1,0)
# 交换前两个块的位置

sortBlocks(key=lambda Block, baseName="", reverse=False)→ None:

根据给定的 key 函数或 baseName 参数对块排序。若两者同时提供，将抛出异常。

  • key - 一个函数，会被传给序列中的每个块，并返回可排序的值。默认情况下它会求值块的名称参数（若已定义），否则按块的第一个参数排序。
  • baseName - 若指定，则按具有此名称的参数的值排序。
  • reverse - 若为 True，则反转排序顺序。
n.seq.Info.sortBlocks(reverse=True) # 直接反转当前顺序
n.seq.Info.sortBlocks(baseName='Value') # 按每个块中 <code>Value</code> 参数的求值结果排序
n.seq.Info.sortBlocks(key=lambda block: block.par.Key) # 按每个块中 <code>Key</code> 参数的求值结果排序
n.seq.Info.sortBlocks(key=lambda block: block.par.X + block.par.Y) # 按每个块中 X 与 Y 参数之和排序
n.seq.Info.sortBlocks(key=lambda block: (block.par.X, block.par.Y)) # 先按 X 参数排序，再在其中按 Y 参数排序。
