Slug 字体库

对于 TouchDesigner 中的排版和字体渲染，Slug Font Rendering Library 是一个动态 GPU 字体渲染和布局引擎，可实现专业高质量、分辨率无关的文本。你可以按匹配行业标准排版工具所需的精度渲染字体，确保字体和文本设计能在 TouchDesigner 中被忠实重现。它支持所有 Unicode 字符，从小尺寸到超大尺寸都可完全缩放，在任何分辨率下轮廓清晰、无瑕疵。

文本生成操作符

Text COMP 使用 Slug 渲染分辨率无关的 2D 文本和图标。

Geo Text COMP 使用 Slug 在 3D 渲染中渲染文本和图标。

Text TOP 以特定分辨率渲染栅格，使用名为 'Scalable' 的 Display Method，这是 Text TOP 设为 'Automatic' 且字体大小为 16 或更大时使用的默认渲染方式。

另请参阅 Text COMP、Geo Text COMP、Text TOP
