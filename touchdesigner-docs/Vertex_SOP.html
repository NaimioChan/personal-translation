Vertex SOP

摘要

Vertex SOP 允许你以逐顶点（而非逐点）的方式编辑/创建属性。在这方面它类似于 Point SOP。它支持两个输入，默认会继承第一个输入源。如果第二个输入的图元少于第一个输入，它会循环遍历图元并匹配顶点。如果第一个输入中的图元比第二个输入中匹配的图元有更多顶点，多出的顶点会被忽略。

目前支持三种顶点属性：

  • 漫反射颜色
  • Alpha
  • 纹理坐标

属性定义后，只能出现在点或顶点上，不能同时出现在两者上。因此，如果输入几何具有漫反射颜色的点属性，该属性将自动被「提升」为顶点属性（如果在 Vertex SOP 中添加了漫反射颜色）。

该 SOP 处理每个图元的每个顶点。对于每个被处理的顶点，有变量可让你了解：

  • 正在处理的图元的顶点编号
  • 正在处理的图元中的顶点数量
  • 该顶点引用的点
  • 包含该顶点的图元
  • 点的总数
  • 图元的总数

除了顶点属性外，还有局部变量可用于查询某些点属性的值（即位置、法线——如果存在）。要访问第二个输入源的属性，请在变量后加 2。

示例

纹理偏移

你可以在一个 TOP 中放置一组图像，并在一个材质中将它们全部应用到对象的不同部位。这让你可以使用预渲染的动画片段，并让该片段在不同表面上以不同速度和时间偏移播放。

你可以通过第一个顶点/点的纹理 W 分量来调整材质帧时间（纹理坐标是 U（水平）、V（垂直）和 W（一组纹理图像之一））。纹理 (W) 值为 -1 会向时间轴后退 1 帧。这让你可以使用 Vertex SOP 或 Point SOP 同时将不同帧应用到许多多边形。

Info CHOP 通道

Vertex SOP 的额外信息可以通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
