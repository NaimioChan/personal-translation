Geo Text COMP

摘要

Geo Text COMP 在 3D 中渲染文本。它不读取或生成 SOP，而是直接用 Slug Library 渲染，并且可以用任何 MAT 材质来打光和贴图。

你可以像在 Text COMP 中那样设置字体、颜色、大小、粗体、斜体、字距和多行。但由于 Geo Text COMP 没有像 Text COMP 那样的边界、宽度或高度，我们改用布局框和 Layout Box 参数来代替。布局框有宽度和高度，默认情况下布局框的左下角位于 Geo Text COMP 的 3D 空间（“object space”）中的 0,0,0。Layout Box Anchor U 和 V 可以让你把布局框的中心放到 0,0,0，方法是把锚点设为 .5, 5。

布局框的大小虽然默认看不见，但由 Layout Box Size 参数决定。借助它，你可以在布局框内右对齐或顶端对齐文本，并裁剪到布局框。你也可以在布局框各边留出内边距。

另请参阅对应的 2D 版本 Text COMP。有关逐字符覆盖设置的方法，请参阅 Text Formatting Codes。

Render multiple strings transformed separately：Specification DAT 和 Specification CHOP 可以让各个字符串在 3D 中独立定位和设置样式。specification OP 中的每一行都是一个独立的文本块，拥有自己的布局框、对齐和裁剪。

Spec DAT 的每一行代表一个“块”或“文本块”。每个 Spec DAT 都包含一个名为 text 的列，它是覆盖 Text 参数的字符串。

大多数列会覆盖 Geo Text COMP 的某个参数，例如 text、tx 和 fontsize。下文提到的一些列名没有对应参数。

Spec CHOP 也可以按块指定值。使用 Spec CHOP 时，其采样数必须与 Spec DAT 中第一个列标题之后的行数相同。

可被覆盖的参数包括 fontsize、fontcolor、tracking 等，以及所有布局框和对齐参数。字体/粗体/斜体也支持作为列，因为它们是不同的字体。

Transforming text blocks：列名或通道名可以包含 tx、ty、tz 以及所有旋转和缩放通道（这些使用 Transform Order 参数）。

当 append 为 1 时，可以使用名为 append 的特殊列/通道，把一个文本块相对于前一个块的末尾定位。常规变换会被每个追加的文本块继承。

局部变换（ltx、lrz 等）可用于给块应用额外的变换，这些变换不会被追加的块继承。如果特殊列/通道 localxform 设为 'pre'，则局部变换会在世界空间中先行应用，然后再应用继承的变换。

注意 - Geo Text COMP 使用 blending/transparency 来创建漂浮在空间中的字形（每个字形是一个部分透明的矩形），因此要在没有包围它们的多边形的情况下正确查看，需要确保它们在它们前面的其他几何之后绘制。这通常是通过使用“Render”参数页上的 Draw Priority 参数，并让取值比其它对象的 Draw Priority 更负来实现。所有绘制优先级最高的对象先绘制，然后绘制所有具有次高相同绘制优先级的对象。如果两个对象的优先级相同，则它们的绘制顺序是任意的，可能会变化。注意：Spec DAT 中的文本应设置为后面的内容在表格中位于前面的内容之前。它会从 Spec DAT 逐行绘制。

有关更多变换选项，请参阅 OP Snippets - relative 和 append。

Geo Text COMP 类似于 Text COMP，后者是一个 2D 的 Panel。

参数 - Text 页

Mode mode - - 控制文本从何处生成：来自 'Text' 参数，或来自通过 'Specification DAT' 参数提供的 table DAT。
  • Text text - 文本将使用 'Text' 参数的内容生成。
  • Specification DAT specdat - 文本将使用 'Specification DAT' 或 'Specification CHOP' 参数中的行和通道生成。
Text text - 在 'Text' 模式下，指定要渲染的文本。
Specification DAT specdat - 在此模式下，忽略 Text 参数，数据取自 Specification DAT 参数中的 DAT 表格。DAT 的每一行是单独一行文本，可以对其应用不同的变换、对齐、颜色和自动换行设置。布局框、内边距和对齐基于各行的 tx、ty 位置而相互独立。列标题应与该列所覆盖的参数名一致。如果某行的某个列项留空，则改用参数的值。这样可以为所有行使用默认值，同时允许特定行按需使用不同设置。变换不会被覆盖，给出的任何变换都会作为预变换，在参数给出的其他变换之前应用。当前有效的列有：text, tx, ty, tz, rx, ry, rz, sx, sy, sz, px, py, pz, ltx, lty, ltz, lrx, lry, lrz, lsx, lsy, lsz, lpx, lpy, lpz, fontcolorr, fontcolorg, fontcolorb, fontalpha, alignx, aligny, alignymode, fontsize, tracking, skew, horzstretch, linespacing, wordwrap, layoutsizew, layoutsizeh, layoutanchoru, layoutanchorv, textpaddingl, textpaddingr, textpaddingb, textpaddingt, render, append, localxform。
Specification CHOP specchop - 允许使用 CHOP 数据来设置 Specification DAT 中定义的文本块的参数。CHOP 的每个采样对应 Specification DAT 中的数据行。CHOP 只能提供数值数据，例如 tx, ty, rz, fontcolorr 等。
Sort by Depth sorted - 仅在使用 Specification DAT 时可用。启用后，specification DAT 中的行会相对于当前摄像机从后向前渲染，以便正确进行 alpha 混合。注意：对大量文本块排序可能导致性能问题，因此只在常规 alpha 混合不够用时才应启用。
Formatting Codes formatcodes - 启用文本中的格式代码。例如，代码 {#color(255, 0, 0);} 会把该行之后的所有文本变为红色。所有可用代码请参阅 Text Formatting Codes。
Parse Escape Sequences escapeseq - 启用后，'\t' 序列会转换为制表符，'\r' 或 '\n' 会转换为换行。此功能仅在使用 Specification DAT 时启用。对于 Text 模式，需要转义序列时应使用 python 表达式。
Smart Punctuation smartpunct - 启用智能标点。例如，成对的引号会被替换为合适的弯引号，3 个句点会替换为省略号字符，两个连字符会变成破折号。
Word Wrap wordwrap - 如果文本行超出布局框宽度，则自动换行。
Width Affected by FOV/OrthoWidth widthaffectedbyfov - 关闭此项时，在查看某一分辨率的渲染图像时，改变视场角或正交宽度，文本的像素宽度保持不变。开启此参数（默认）时，如果把视场角或正交宽度加倍，文本的像素宽度会减半。例如在你为摄像机缩放做动画时会用到。
Face Camera facecam - 开启此项可使文本无论摄像机朝向如何都面向摄像机。
Depth Scale S-Curve depthScaleSCurve - 关闭此项时，文本大小与距摄像机的距离成反比，即基于透视的大小。开启开关后，由 S 曲线根据距摄像机的距离决定文本的缩放。
Depth Distance Near depthDistanceNear - 指定距摄像机一定距离的近平面。用于 Depth Scale S-Curve。
Depth Distance Far depthDistanceFar - 指定距摄像机一定距离的远平面。用于 Depth Scale S-Curve。
Depth Scale Near depthScaleNear - 当摄像机距离等于 'Depth Distance Near' 参数的值时，文本将按此值缩放。用于 Depth Scale S-Curve。
Depth Scale Far depthScaleFar - 当摄像机距离等于 'Depth Distance Far' 参数的值时，文本将按此值缩放。用于 Depth Scale S-Curve。
Depth Scale Bias depthScaleBias - 在近平面和远平面之间插值深度缩放系数时，把 S 曲线偏置向后或向前移动。用于 Depth Scale S-Curve。
Depth Scale Steepness depthScaleSteepness - 控制近平面和远平面之间深度缩放系数插值的 S 曲线陡度。陡度值越高，曲线宽度上的变化越剧烈（斜率越大）。此外，陡度值越低，曲线越接近线性。
Depth Scale Linearize depthScaleLinearize - 控制近平面和远平面之间深度缩放系数插值的 S 曲线弯曲程度。
Lift Towards Camera lifttowardscam - 对于可能渲染在填充多边形之上或其边缘的文本，由于渲染在同一位置，可能会被切断。为了让它看起来更好，你需要把文本朝向摄像机从表面抬起。此参数缩放文本从表面抬起的高低，使其看起来更好，又不会分离得太远。

实例纹理化

此功能允许将任意纹理应用到实例。这些纹理不需要具有相同的分辨率，也不需要合并为 3D Texture 或 2D Texture array 之类的分组格式。可以使用「Instance Textures」参数指定多个 TOP，而每个实例所应用的纹理由「Texture Index」参数中选择的通道指定。这与 3D Texture 或 2D Texture Array 不同，后者会使用 W 纹理坐标在单个纹理内选择纹理。默认情况下，此纹理会用作 PBR MAT 的「Base Color Map」纹理，以及所有其他材质（如 Phong MAT）的 Color Map。对于支持多个贴图的材质，可以在此材质的参数中选择本功能所替换的贴图。目前在 Windows 上最多可同时使用 16384 个纹理，在 macOS 上最多可同时使用 128 个纹理。这些数量还会因渲染所用的其他纹理（如其他贴图、cone light 查找贴图等）而减少。
