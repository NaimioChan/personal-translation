Pop 文件格式

.pop File Type 是一种原生 POP 文件格式，是对 POP 输出的精确无损表示。

.pop 文件会保留所有 primitive types、属性和 Groups、Dimension。

它可以用 File Out POP 创建，或右键点击 POP 节点并选择 Save Geometry。它通过 File In POP 读入 TouchDesigner。

把文件拖放到网络中可创建一个 File In POP。你可以在桌面或文件浏览器中右键点击该文件，选择 Open With...。

锁定 POP

POP 操作符可以像其他操作符一样被锁定（用节点上的 Lock Flag），从而把内容冻结在内存中。保存时它会被包含进项目 .toe 文件。它在 .toe 和 .tox 文件中的保存格式与 .pop 文件完全相同。注意——与 TOP 一样，锁定 POP 会让 .toe 文件变得非常大。
