CHOP 的用途

控制外部设备

使用 CHOP 从外部设备获取数据并向外部设备发送数据。通过 MIDI、OSC、Shared Memory 或自定义 C++ 程序（经由 Pipe In CHOP 和 Pipe Out CHOP），数据可以以多种方式进出 TouchDesigner。此类输入可用于控制 Touch 项目的任何部分，反之，Touch 也可以通过这些方法发送 CHOP 数据来控制外部设备。

实时木偶操控

你可以将鼠标、MIDI 或其他设备一次一个地附加到对象上，执行对象的运动，逐段构建角色或对象的运动。你可以用鼠标或其他设备执行这些「手势」，并将运动捕获到 chop 中。你可以立即编辑捕获的运动，通过修剪、偏移、平滑，然后与其他运动片段组合。TouchDesigner 的实时木偶操控是快速创建运动的独特方式。

动力学与特效运动

使用 CHOP 创建特殊运动效果更容易。你可以检测 3D 场景中的事件，如碰撞或方向变化，然后触发其他运动的开始。CHOP 包含许多工具，可平滑曲线、模拟物理运动，并为运动添加自然的随机变化。例如，可以组合 CHOP 来模拟物理摄像机运动，包括滞后、抖动、碰撞和摆动。

非破坏性运动编辑

你可以使用 CHOP 以不影响原始运动通道的方式编辑运动。你可以通过偏移、压缩、扩展和扭曲时间来改变运动的时间。你可以应用平滑、反转、重复、修剪和延伸运动的操作符。你可以回到任何 CHOP，更改其对最终运动的影响，并轻松试验修改后的时间。

运动合成

一组 CHOP，每个包含一个角色的运动片段，可以一个接一个地排序，并可控制运动片段之间的混合过渡。你可以从一个运动片段开始，并用另一个运动片段临时覆盖它。运动可以分层，使手势可以临时且部分地覆盖其他手势。由于可以在不破坏原始数据的情况下试验混合，你可以轻松微调分层运动。

面部动画与口型同步

面部动作可以通过一组面部表情来制作动画，这些表情由姿势和动作片段组成。面部姿势和动作片段可以由其他姿势和面部动作片段组合而成，然后重复使用。


口型同步是一项面部动画任务，使用语音音轨和一组口部姿势来为角色的嘴部制作动画。你可以导入语音轨道，将对话中的单词添加到时间轴，把口部姿势和手势拖放到时间轴上，然后调整姿势的时序。你还可以对音频进行滤波和平滑处理，以自动生成近似的口部动作。

动作捕捉编辑

你可以从动作捕捉系统导入动作捕捉片段。捕捉动作中的缺陷可以被清理。动作捕捉数据可以应用到反向或正向运动学的角色模型上，你还可以用 CHOP 进一步细化动作。一个 CHOP 保存多通道的动作。你可以轻松地将不同的动作捕捉动作附加到一个角色上或从中分离。

关键帧姿势插值

CHOP 提供了另一种在 Touch 中手动编辑关键帧的方式，不同于用户指南中记录的通道关键帧。

在 CHOP 中，你可以为角色摆姿，将角度和 IK 末端效应器快照到单个 CHOP 中，把多个姿势依次排列，然后在另一个 CHOP 中调整时序曲线以在姿势之间插值。你可以轻松编辑姿势和时序，还可以将姿势和动画复制粘贴到其他角色。

音频编辑

你可以从外部来源将音频导入 Touch，然后对声音进行修剪、滤波、重采样、同步和混合。你可以将混合后的音频附加到动画时间轴。借助时间轴拖动和轴上的文本注释，3D 动画可以与音轨同步。

音频合成与 3D 声音

音效可以从外部来源导入，但音频也可以使用内置的音频振荡器、滤波器、混响和音量控制从零开始合成。音效随后可以由 3D 场景中的任何事件或动作触发，也可以让声音持续循环。然后音频可以放置在动画的 3D 环境中的任何位置，并带有左右声像、距离衰减、闷音和 Doppler 频移等音频线索。声音可以被触发，以帮助用户理解 3D 场景中的状况，例如角色的关节限制。音频是实时生成的，或者更复杂的音频可以被「渲染」出来并与动画一起回放。

可视化表达式语言

CHOP 让数学表达式语言既可视化又可交互。你可以用 CHOP 构建等价的数学表达式，而无需使用编译器编写代码。使用 CHOP，你可以交互式地构建表达式，并立即在图表或 Viewport 中看到结果。无需输入，因此没有「语法错误」。CHOP 可进行算术运算、从其他对象获取数据等等。

大型项目的动作管理

一个动画师团队可以在中央库中维护许多动作片段。动作可以轻松地在动画师和场景之间移动。CHOP 是管理大型项目动作的便捷方式，这类项目中许多角色的片段分散在许多场景里。多名动画师可以同时处理同一个角色。通过动作合成，你可以从动作片段库构建或「合成」角色动作，然后手动修改它们。这有助于保持角色外观一致，尤其是在多位艺术家为同一角色制作动画时。
