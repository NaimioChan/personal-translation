ListAttribute 类

ListAttribute 类描述用于定义 List Component 中某个单元格或一组单元格的属性。

成员

text → str :

获取或设置内容。

textColor → tuple[float, float, float, float] :

获取或设置文字颜色。格式为元组 (r, g, b, a)。

textJustify → JustifyType :

获取或设置文字对齐方式。值为以下之一：JustifyType.TOPLEFT、JustifyType.TOPCENTER、JustifyType.TOPRIGHT、JustifyType.CENTERLEFT、JustifyType.CENTER、JustifyType.CENTERRIGHT、JustifyType.BOTTOMLEFT、JustifyType.BOTTOMCENTER、JustifyType.BOTTOMRIGHT

textOffsetX → float :

获取或设置水平文字偏移。

textOffsetY → float :

获取或设置垂直文字偏移。

wordWrap → bool :

获取或设置自动换行。

help → str :

获取或设置鼠标悬停于该单元格时的帮助字符串。

bgColor → tuple[float, float, float, float] :

获取或设置背景颜色。格式为元组 (r, g, b, a)。

fontFace → str :

获取或设置字体。例如 'verdana'。

fontFile → str :

获取或设置字体文件。也支持 VFS 内嵌文件。

fontBold → bool :

获取或设置文字是否使用粗体渲染。

fontItalic → bool :

获取或设置文字是否以斜体渲染。

fontSizeX → float :

获取或设置字体水平大小。

fontSizeY → float :

获取或设置字体垂直大小。未指定时使用 fontSizeX。

sizeInPoints → bool :

获取或设置文字大小单位。为 True 时尺寸以点为单位，为 False 时以像素为单位。

top → TOP :

获取或设置背景图像 TOP。

topFill → FillMode :

获取或设置背景 TOP 的适配方式。值：FillMode.STRETCH、FillMode.HORIZONTAL、FillMode.VERTICAL、FillMode.BEST、FillMode.NATIVE、FillMode.OUTSIDE。

topBorderInColor → tuple[float, float, float, float] :

获取或设置内侧顶部颜色。格式为元组 (r, g, b, a)。

topBorderOutColor → tuple[float, float, float, float] :

获取或设置外侧顶部颜色。格式为元组 (r, g, b, a)。

bottomBorderInColor → tuple[float, float, float, float] :

获取或设置内侧底部颜色。格式为元组 (r, g, b, a)。

bottomBorderOutColor → tuple[float, float, float, float] :

获取或设置外侧底部颜色。格式为元组 (r, g, b, a)。

leftBorderInColor → tuple[float, float, float, float] :

获取或设置内侧左侧颜色。格式为元组 (r, g, b, a)。

leftBorderOutColor → tuple[float, float, float, float] :

获取或设置外侧左侧颜色。格式为元组 (r, g, b, a)。

rightBorderInColor → tuple[float, float, float, float] :

获取或设置内侧右侧颜色。格式为元组 (r, g, b, a)。

rightBorderOutColor → tuple[float, float, float, float] :

获取或设置外侧右侧颜色。格式为元组 (r, g, b, a)。

colWidth → float :

获取或设置列宽，以像素为单位。

colStretch → bool :

获取或设置列的伸展性。为 True 时，colWidth 指定最小宽度。

rowHeight → float :

获取或设置行高，以像素为单位。

rowStretch → bool :

获取或设置行的伸展性。为 True 时，rowWidth 指定最小宽度。

rowIndent → float :

获取或设置行缩进，以像素为单位。

editable → bool :

获取或设置内容是否可编辑。为 True 时，可通过点击单元格编辑内容。

draggable → bool :

获取或设置单元格是否可拖动。

focus → bool (Read Only):

若单元格/行/列/表格当前正在被编辑，返回 True。

radio → bool (Read Only):

若鼠标最后选中的是单元格/行/列/表格，返回 true。

rollover → bool (Read Only):

若鼠标当前位于单元格/行/列/表格之上，返回 true。

select → bool (Read Only):

若鼠标当前在单元格/行/列/表格上按下，返回 true。

方法

没有该操作符专属的方法。
