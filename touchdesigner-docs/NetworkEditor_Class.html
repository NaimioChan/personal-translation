NetworkEditor 类

NetworkEditor 类描述 Network Editor 的一个实例。它们是 Pane Class 的子类，可通过 ui 对象访问。

成员

showBackdropCHOPs → bool :

启用或禁用将 CHOP 查看器作为背景显示。

showBackdropGeometry → bool :

启用或禁用将 SOP 和 Geometry object 查看器作为背景显示。

showBackdropTOPs → bool :

启用或禁用将 TOP 查看器作为背景显示。

showColorPalette → bool :

启用或禁用操作符颜色调色板选择器的显示。

showDataLinks → bool :

启用或禁用操作符数据链接。

showList → bool :

控制操作符以列表形式还是以连接节点形式显示。

showNetworkOverview → bool :

启用或禁用网络总览的显示。

showParameters → bool :

启用或禁用当前选中操作符参数的显示。

straightLinks → bool :

控制操作符连线显示为直线还是曲线。

x → float :

获取或设置网络编辑器区域的 x 坐标，其中 zoom = 1 时 1 个单位 = 1 像素。

y → float :

获取或设置网络编辑器区域的 y 坐标，其中 zoom = 1 时 1 个单位 = 1 像素。

zoom → float :

获取或设置网络编辑器区域的缩放系数，缩放系数为 1 时，每个节点按其未缩放的分辨率绘制。

方法

fitWidth(width)→ None:

将网络区域适配到指定宽度，宽度以节点单位表示。这会影响缩放系数。

  • width - 要适配到的宽度。

fitHeight(height)→ None:

将网络区域适配到指定高度，高度以节点单位表示。这会影响缩放系数。

  • height - 要适配到的高度。

home(zoom=True, op=None)→ None:

将网络中的所有操作符归位。

  • zoom - (Keyword, Optional) 为 true 时视图会相应缩放，否则节点仅重新居中。
  • op - (Keyword, Optional) 如果指定了操作符，网络的归位将以该操作符所在位置为中心。
p = ui.panes['pane1']
n = op('/project1')
p.home(op=n)
p = ui.panes[2]
p.home(zoom=True)

homeSelected(zoom=True)→ None:

将网络中所有选中的操作符归位。

  • zoom - (Keyword, Optional) 为 true 时视图会相应缩放，否则节点仅重新居中。

placeOPs(listOfOPs, inputIndex=None, outputIndex=None, delOP=None, undoName='Operators')→ None:

使用鼠标将指定的操作符放入窗格。

  • listOfOps - 要放置的操作符列表。
  • inputIndex - 如果指定，表示要连接到哪个输入索引。
  • outputIndex - 如果指定，表示要连接到哪个输出索引。
  • delOP - 如果指定，会在放置完 listOfOPs 后立即删除该操作符。
  • undoName - 描述 Undo 操作。

Pane 类

成员

owner → COMP :

获取或设置此窗格指向的 component。

id → int (Read Only):

唯一的数字标识符。

link → int :

获取或设置数字链接索引。

enable → bool :

获取或设置窗格上的鼠标和键盘交互。

maximize → bool :

启用或禁用窗格最大化状态。

name → str :

获取或设置窗格名称。

ratio → float :

获取或设置窗格的分割比例（如果窗格先前已分割）。

bottomLeft → Coords (Read Only):

左下角的坐标，在命名元组中以 x/y 和 u/v 两种形式表示。

topRight → Coords (Read Only):

右上角的坐标，在命名元组中以 x/y 和 u/v 两种形式表示。

open → bool (Read Only):

如果 Pane 当前已打开，则返回 True。

type → PaneType (Read Only):

窗格的枚举类型。示例：NetworkEditor。

该枚举称为 PaneType，包含：

  • PaneType.NETWORKEDITOR
  • PaneType.PANEL
  • PaneType.GEOMETRYVIEWER
  • PaneType.TOPVIEWER
  • PaneType.CHOPVIEWER
  • PaneType.ANIMATIONEDITOR
  • PaneType.PARAMETERS
  • PaneType.TEXTPORT

方法

changeType(paneType)→ td.Pane:

将窗格更改为指定类型。会返回一个表示该窗格的新 Pane 对象。调用后，当前的 Pane 实例将不再有效。

  • paneType - 要将此窗格更改为的窗格类型。
p = ui.panes[0]
p = p.changeType(PaneType.TOPVIEWER)  # 注意：必须把 p 重新赋值为新对象。

close()→ None:

关闭该窗格。

floatingCopy()→ td.Pane:

返回该窗格的浮动副本。

splitBottom()→ td.Pane:

将窗格的下部分割为新窗格。

splitLeft()→ td.Pane:

将窗格的左部分割为新窗格。

splitRight()→ td.Pane:

将窗格的右部分割为新窗格。

splitTop()→ td.Pane:

将窗格的上部分割为新窗格。

tearAway()→ bool:

将窗格分离为浮动窗口。成功则返回 True。
