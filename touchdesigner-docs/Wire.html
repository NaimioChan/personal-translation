连线

Wires 是连接网络中一个节点输出与其他节点输入的彩色线条。你可以把连线看作把数据从一个节点传递到另一个节点。

第二种类型的连线是 Hierarchy Wire，它连接 3D 组件和 2D 面板组件顶部/底部的连接器，并形成这些组件的父子关系。

连线总是连接同一 Family 中的节点：两个 CHOP 之间的连线将源 CHOP 的通道集合暴露给目标 CHOP。两个 TOP 之间的连线将源 TOP 的图像暴露给目标 TOP。左右方向的数据连线出现在 CHOPs、TOPs、SOPs、DATs 以及偶尔出现在 MATs 上。

创建连线：

  1. 左键点击节点的输入或输出。
  2. 将光标移到要连接的节点的输出或输入。
  3. 再点击一次完成连接。

或

  1. 左键点击节点的输入或输出，按住不放，将光标拖到要连接的节点的输出或输入。
  2. 松开左键。

当光标位于一条连接线上时，该线会以黄色高亮。在此高亮状态下，你可以在连线上：

  • MMB（点击鼠标中键）获取传入节点的信息
  • RMB 调出菜单，可以：
    • 通过 OP Create Dialog 插入一个操作符
    • 选择源节点
    • 选择目标节点
    • 断开连线

连线会显示动画虚线，用于以视觉方式反馈网络中有哪些节点正在计算。动画虚线代表节点之间的数据流动。

提示：连线可以两种模式显示：样条曲线和直线。在 Network Editor 窗格中按热键 "s"（直线）可在这两种模式之间切换。你也可以使用 Network Editor 上下文菜单中的 "Link Straight" 菜单项切换该设置。

注意：当操作符计算并生成数据时，如果它通过连线连接到另一个操作符，它实际上并不传递或复制数据到目标 —— 它只是告知目标到哪里获取其要处理的数据。
