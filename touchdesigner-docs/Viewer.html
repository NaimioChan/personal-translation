查看器

查看器的位置

TouchDesigner 操作符的查看器出现在三个位置：

  • 在节点内 - 节点内部的查看器称为Node Viewers。
  • 在浮动窗口中 - 从窗格以浮动对话框的形式打开（使用 Tear Off 或 Copy Pane），或通过节点的右键菜单选择Viewer...打开。
  • 在Panes中

注意：在节点查看器中移动内容不会影响其变换或参数。Exception：Camera COMP

查看器的样式

每个操作符族都有对应的查看器样式。

Geometry Viewer - 用于查看和操控 3D 场景或对象的 3D 视口。你可以在 3D 场景中翻转、平移和缩放。还可以在 Object Component 层级平移、旋转和缩放几何、摄像机和灯光来编辑场景。这些查看器也作为节点查看器出现在所有 3D Component 和 SOP 中。
在 Geometry COMP 和 SOP 的节点查看器中，Adaptive Homing 选项会让正在显示的 3D 几何始终保持可见，即使几何改变了形状、大小和动画位置。可以在 Edit > Preferences > Geometry : Adaptive Homing by Default 中全局关闭。
Panel Viewer - 显示 Panel Components 的视图，并允许与控制面板交互。
CHOP Viewer - 用于检查和编辑 CHOP 通道值的 2D 查看器。时间在 x 轴，值（或幅度）在 y 轴。也作为节点查看器出现在所有 CHOP 中。
TOP Viewer - 用于查看 TOP 图像的 2D 查看器。你可以在图像上平移和缩放。也作为节点查看器出现在所有 TOP 中。
SOP Editor - 类似 Geometry Viewer，但专用于编辑 SOP 几何。使用 SOP 查看器 States，你可以直接操控几何或从头建模新几何。SOP 查看器只能从 SOP 直接打开：右键点击该 SOP，并从菜单中选择 Model Geometry...。
DAT Viewer - 显示 DAT 的文本或表格数据。通过让查看器激活，可以直接编辑（在生成器 DAT 中）。注意 DAT 的默认节点语言是 python，以蓝色文本显示；如果文本是与其他 DAT 相同的紫色，则此节点的语言被设为 Tscript。
