Web Client DAT

摘要

Web Client DAT 让你可以从 TouchDesigner 向 Web 服务器发送 HTTP 请求。它支持 GET、POST、PUT、DELETE、HEAD、OPTIONS 和 PATCH 等 HTTP 方法。

Web Client DAT 支持多种身份验证类型，例如：basic、oauth1、oauth2。

Web Client DAT 支持从 Web 服务器进行流式传输。

Web Client DAT 向 Web 服务器发送 HTTP 请求，然后在 DAT 中输出响应。启用流式传输后，它可以流式接收来自 Web 服务器的数据。

启用流式传输时，应同时启用 Clamp Output as Rows。这会把 DAT 的输出变成 FIFO 表格而非原始文本。只显示最后 N 行，N 为 Maximum Lines 参数的值。这可以防止 DAT 中的文本变得过大，从而缩短计算时间。

Web Client DAT 支持发送 GET、POST、PUT、DELETE、HEAD、OPTIONS 和 PATCH 请求方法。Web Client DAT 还支持 4 种身份验证方法：Basic、Digest、OAuth1 和 OAuth2。

第一个输入是请求中要发送的额外标头。它应为一个两列的表格，按名称/值对组织。例如：

Content-Type application/json
Connection Close

第二个输入是请求中要发送的数据/参数。它可以是一个两列的表格，按名称/值对组织。也可以只是文本，此时会按原样发送。如果请求方法没有请求体（例如 GET、OPTIONS），则若输入是表格，会将其作为查询参数附加到 URL；否则会作为请求数据发送。

name joe
month May

Web Client DAT 是Web DAT的后继者。

另请参阅：Web Server DAT、SocketIO DAT、XML DAT、TCP/IP DAT、WebSocket DAT、Web DAT。

参数 - Web Client 页

Active active - 开启/关闭该操作符。
Request Method reqmethod - 选择HTTP request method。
  • GET get - GET 方法请求指定资源的一种表示形式。使用 GET 的请求应只检索数据。
  • POST post - POST 方法用于向指定资源提交一个实体，通常会导致服务器上的状态变化或副作用。
  • PUT put - PUT 方法用请求负载替换目标资源的所有当前表示形式。
  • DELETE delete - DELETE 方法删除指定的资源。
  • HEAD head - HEAD 方法请求与 GET 请求相同的响应，但不含响应体。
  • OPTIONS options - OPTIONS 方法用于描述目标资源的通信选项。
  • PATCH patch - PATCH 方法用于对资源施加部分修改。
URL url - 要发送 HTTP 请求的服务器 URL。通常，若向安全服务器发送 HTTP 请求，URL 应以 “https://” 开头。
Upload File uploadfile - 上传文件的内容会发送到服务器（如有必要会分块发送）。
Request request - 发送请求
Stop stop - 停止来自服务器的数据流。
Stream stream - 启用流式传输。只有在服务器支持流式传输时才需要启用。
Verify Certificate (SSL) verifycert - 启用 TLS（传输层安全）证书验证。
Timeout timeout - 若未从 Web 服务器收到响应，请求的超时时间（毫秒）。
Include Header in Output includeheader - 在响应输出中包含标头。

参数 - Authentication 页

Authentication Type authtype - 身份验证的类型。
  • None none - 不进行验证
  • Basic basic - Basic 验证是经 base-64 编码的用户名和密码。
  • Digest digest - Digest 验证是经 base-64 编码、并用哈希函数加密的用户名和密码。Digest 是 Basic 验证的更安全版本。
  • OAuth1 ouath1 - OAuth 的第 1 版。OAuth1 需要 App Key、App Secret、User OAuth Token 和 User OAuth Secret。这些可在接收请求的 Web 服务器账户中找到。例如，Twitter API 的这 4 个参数值可在账户资料下找到。
  • OAuth2 ouath2 - OAuth 的第 2 版。OAuth2 首先需要向 Web 服务器发送 HTTP 请求以获取 Client ID 和令牌。可以使用浏览器获取。
Username username - Basic/Digest 验证中使用的用户名。
Password pw - Basic/Digest 验证中使用的密码。
App Key appkey - 从 Web 服务器获取的 OAuth1 App Key。
App Secret appsecret - 从 Web 服务器获取的 OAuth1 App Secret。
User OAuth Token oauthtoken - 从 Web 服务器获取的 OAuth1 用户令牌。
User OAuth Secret oauthsecret - 从 Web 服务器获取的 OAuth1 用户密钥。
Client ID clientid - 从 Web 服务器获取的 OAuth2 Client ID。
Token token - 从 Web 服务器获取的 OAuth2 令牌。

参数 - Output 页

Clear Output clear - 清除 DAT 的输出。
Clamp Output as Rows clamp - 启用时，DAT 的输出为表格而非文本。行数还会被限制为 Maximum lines 参数的值。启用流式传输时也应启用此项，以确保输出不会变得过大。
Maximum Lines maxlines - 启用限制时的最大行数。
Callbacks DAT callbacks - Callbacks DAT。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
