窗口布局对话框

说明

Window Placement 对话框（Alt-w）管理窗口位置，并决定 TouchDesigner 以 Perform Mode 还是 Designer Mode 启动。

通常你按 F1 和 Esc 进入和退出 Perform Mode，它使用单个 Window Component /perform。默认的 .toe 文件包含一个位于 /perform 的 Window Component，其参数用于自定义进入 Perform Mode 时窗口的位置、外观和行为。

Dialogs -> Window Placement（Alt-w）处的 Window Placement 对话框有助于管理一个或多个 Window 组件。

在这里你会看到现有 Window 组件的列表，对每个组件你可以打开和关闭窗口、选择它作为 Perform Mode 中打开的那个、打开其 Parameter 对话框（P 按钮），或打开包含该 Window 组件的网络。

它会为整个 .toe 文件中的每个 Window 组件显示一行。它与 Window Component 的参数保持一致：你在 Window Placement 中看到和控制的内容，是你项目中所有 Window 组件中看到和控制的内容的汇总。

Main Perform 列可让你选择在 Perform Mode 中使用哪个 Window component，默认是 /perform。


你可以打开每个 Window 组件的参数对话框（P 按钮），或打开 Window 组件所在的网络（箭头），或直接打开窗口本身（Open 按钮）。

Start in Perform Mode 标记可让你选择以 Perform Mode 还是 Designer Mode 启动 TouchDesigner。

在 Start Position 和 Custom Settings 部分，Window Placement 对话框决定 Designer Mode 窗口的位置。

Window Component 使用单独的开/关脉冲按钮来打开和关闭窗口，也可以通过 Open/Close 参数 .pulse() Python 方法触发。

Window Component 还有一个脉冲参数，可在 Perform Mode 中临时打开任意 Window 组件，而不是 Window Placement 对话框中指定的那个。

Window Component 有一个参数（Redraw）用于告知窗口不绘制任何内容。当主显示器无需输出时很有用，例如使用 Oculus Rift 时，或你的系统仅通过网络操作符输出数据，或通过 Video Device Out TOP，或其他不渲染的进程（如音频处理，或驱动不使用视频输出的 LED 灯带）输出数据时。

提示：你可以用 python 进入和退出 Perform Mode：例如 ui.PerformMode = True。参见 UI_Class。

提示：在 Window Component 中放入 tag 'hide'，即可让窗口不出现在列表中。

Designer 与 Perform Mode

参见 Designer Mode 和 Perform Mode。

多显示器设置

要设置多台显示器，参见 Multiple Monitors 并使用 Window COMP。为获得最佳性能，一般建议尽可能将 UI 和所有输出图像放入一个大型容器，使用一个 Window Component。
