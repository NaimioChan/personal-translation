CHOP Common 参数页

Time Slice - 开启后强制通道为「Time Sliced」。Time Slice 是上一次计算帧与当前计算帧之间的时间。

Scope - 为确定哪些通道受影响，某些 CHOP 会使用 Common 页上的 Scope 字符串。

Scope 中可以使用模式：*（匹配所有通道，因而影响所有通道）、?（匹配单个字符。参见 Pattern Matching。

Sample Rate Match - 处理多个输入 CHOP 采样率不同的情况。当 CHOP 需要合并采样率不同的输入时，Sample Rate Match Options 提供以下选择：

  • Resample At First Input's Rate - 使用第一个输入的采样率来重采样其他输入。
  • Resample At Maximum Rate - 重采样到最高采样率。
  • Resample At Minimum Rate - 重采样到最低采样率。
  • Error if Rates Differ - 不接受冲突的采样率。

发生重采样时，曲线按 Interpolation Method Option 插值；若 Interpolate Options 不可用，则按「Linear」插值。

Export Method - 决定如何将 CHOP 通道连接到参数。更多信息请参阅 Export 一文。

  • DAT Table by Index - 使用停靠的 DAT 表格，并通过通道在 CHOP 中的索引来引用通道。
  • DAT Table by Name - 使用停靠的 DAT 表格，并通过通道在 CHOP 中的名称来引用通道。
  • Channel Name is Path:Parameter - 通道即为导出目标的完整目的地，例如 geo1/transform1:tx。

Export Root - 此路径指向根节点，所有通过 Channel Name is Path:Parameter 导出的路径都相对于它。

Export Table - 使用 DAT Table 导出方法（见上文）时用于保存导出信息的 DAT。
