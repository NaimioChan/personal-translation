CHOP 技巧

以下是几个基本的 CHOP 技巧。这部分偏向 Tscript，需要改写为 python。

在 TOP 与 CHOP 之间获取 RGBA 值

TOP to CHOP 用于将 TOP 像素中的 RGBA 值取到 CHOP 的通道中，在那里可以用 CHOP 编辑。

CHOP to TOP 可快速将像素值送回 TOP。

在 SOP 与 CHOP 之间获取 XYZ 值

SOP to CHOP 用于将 SOP 的点中的 XYZ 值取到 CHOP 的通道中，在那里可以用 CHOP 编辑。SOP 中的所有点属性都可以获取，包括用户定义的点属性。

CHOP to SOP 用于将 CHOP 通道中的值取到 SOP 的点中。CHOP to SOP 在输入处接收几何，在不改变曲面类型或多边形、网格顶点之间的连接的情况下，只修改点的值。它的运行速度比 Point SOP 快得多。

任何点属性都可以用 CHOP 通道中的值替换。

在这两种情况下，都可以用 SOP 中的点组来限制 SOP 与 CHOP 之间传输的数据。

参见 Optimize。

用 print() 函数诊断 CHOP

有时不清楚表达式形式的 CHOP 参数在计算时的值是多少。你可以把表达式放进 print() 函数，它会在求值时显示其值。语法为 print(string, expression)，其中 string 会打印在标准输出中该值的前面。

多个对象与 CHOP 网络

有时你希望一个 CHOP 网络驱动一个对象。你可能想把这一对克隆几十次，但又希望每个的行为略有不同。因此需要在每个对象和 CHOP 网络中获得一个能标识它的数字。

如果能从对象名和 CHOP 网络名中取出数字，就可以用这个数字标识该单元。但并没有显而易见的办法把这个数字放进 CHOP 或对象参数中。这里有一种办法：

表达式函数 opdigits() 会获取 OP 名称中的数字。例如，它从名为 leg23left 的 OP 中提取出 23。

这样就能为 100 个相似的角色各做一个 CHOP 网络。例如，在 CHOP 中，可以使用下列函数获取 CHOP 网络的编号： 

   opname("..") = "ch1" (a string)

   opdigits("..") = 1 (a set of digits)

   opdigits("opname") returns the numeric value of the concatenation of all the digits in a node's name. It is used when building several similar networks. For example:
   opdigits("/obj/geo7") = 7

   opdigits("..") = 7 (at the SOP level of geo1)

在 geo1 到 geo100 这 100 个对象中，可以使用表达式： 

   opdigits(".")

可以在 Noise CHOP 的 Random Seed 参数中使用此函数，这样每个 CHOP 网络都会生成不同的噪声曲线。

CHOP 在管理大型项目中的用途

你可以在一个 CHOP 网络中保存许多角色的许多动作，并通过把任意 CHOP 立即连接到角色来查看它。因此它既是动作库，也是查看器。此外，当多位动画师协作同一个项目、目标是让角色在各场景中表现相似时，动画师可以从库中挑选动作作为起点。这就像材质库能让渲染效果在各场景间保持一致。

绕过 CHOP 网络

在需要确保 CHOP 不进行计算时，避免 CHOP 网络的计算。点击 Bypass Flag，或 Lock Flag。
