教育版配置

关于教育许可证

TouchDesigner Educational 是 TouchDesigner 的一个版本，面向学生和学校，仅限非商业和教育用途。教育版包含 Commercial 的所有功能，例如无分辨率限制、Shared Memory OPs 和自定义 C++ OP。功能对比请参阅 Licensing。

可以通过填写此 form. 来申请教育许可证的访问权限。

申请教育购买

学生和学校管理员必须申请教育购买并经 Derivative 批准，这些许可证才会在网上商店中提供。

申请步骤

  1. 单击 "My Account" 创建或登录你的 derivative.ca 账户。
  2. 在以下地址填写申请表：https://derivative.ca/node/add/educational-package
  3. 教育团队将审核你的请求。（通常在 24 小时内。）
  4. 审核完成后，你会收到一封包含答复的电子邮件。

账户获批后，用户登录账户时，网上商店就会显示教育许可证。以后如需购买更多许可证，无需重新申请。获批账户将永久拥有教育购买权限。

批量折扣

教育许可证可享受批量折扣价格。了解更多请访问我们的 Volume Discount page。

许可证选项

Non-Commercial 密钥 - 无需费用

所有账户在创建时都会自动获得 10 个 Non-Commercial 密钥。欢迎学校将这些 Non-Commercial 密钥用于教学，我们也乐于增加可用数量以便搭建实验室等。只需发送电子邮件至 licensing@derivative.ca 告知所需数量，我们就会提高你账户上的可用数量。

与付费许可证相比，Non-Commercial 密钥存在功能限制，最显著的是 1280px × 1280px 的分辨率限制。完整对比表请访问我们的 Licensing 页面。

注意事项

  • 无需费用。
  • 1280 x 1280 分辨率限制。
  • 与教育许可证相比有额外的 feature limitations。
  • 一次性使用。
  • 无法像付费许可证那样被禁用并在机器之间迁移。
  • 如果 system code 发生变化，需要创建新密钥。

TouchDesigner 教育版（每许可证 $300 USD）

TouchDesigner 教育版许可证通过 TouchDesigner 中的 Key Manager 管理。许可证一次只能位于 1（一）台机器上，但可以通过 Key Manager 和你的账户登录信息按需在机器之间迁移。

注意事项

  • 功能与 Commercial 许可证相同。
  • 可通过 Key Manager 在机器之间迁移。
  • 无法远程与学生共享，也无法通过网络共享。
  • 需要通过 Key Manager 创建和禁用密钥，因此需要机器访问权限和互联网访问。

TouchDesigner 教育版 - Floating Cloud（每许可证 $450 USD）

TouchDesigner Floating Cloud 许可证通过 .wbc 文件管理，该文件安装在用户希望访问该许可证的每台机器的 Codemeter Control Center 上。与 Dongle floating license 方法不同，不需要共享网络连接。更多信息请访问我们的 Floating Cloud License 信息页。

注意事项

  • 关闭 TouchDesigner 时许可证会自动释放。
  • 可与校内和校外的学生和教师共享。
  • Derivative 可以在每学期开始时生成新的 .wbc 文件，这样之前的学生将不再拥有访问权限，而新的 .wbc 文件可以分享给新学生。

设置建议与示例

单一计算机实验室

欢迎学校在计算机实验室中使用 Non-Commercial 密钥进行教学。账户创建时自动拥有 10 个 Non-Commercial 密钥，但 Derivative 团队乐于按需增加更多。只需将用户名和所需数量通过电子邮件发送至 licensing@derivative.ca，限制就会提高。

建议课程讲师使用 TouchDesigner 教育版密钥，以便演示无分辨率限制的项目，以及 Non-Commercial 密钥不具备的其他功能。

多地点访问

如果你需要在多个网络和/或地点访问，我们提供 TouchDesigner 教育版 Floating Cloud 许可证。更多信息请访问我们的 Floating Cloud Licenses 信息页。

有时实验室计算机会经常被重装，和/或不具备管理员权限。使用浮动云许可证可以让系统管理员将凭据作为磁盘映像的一部分安装到实验室计算机上。这种设置会在使用 TouchDesigner 时自动使用许可证，并在 TouchDesigner 关闭时归还它们。

使用此方法，用户可以在学期开始时与学生共享 .wbc 凭据文件，然后由 Derivative 在学期结束时创建新的凭据文件。这是一个手动过程，只能由 Derivative 完成。学校无法在学期中途有选择地限制特定学生的访问。每次开课时都需要完全重置并安装新的凭据文件。

Considerations

  • 可远程与学生和教师共享。
  • 可在学期结束时远程重置/撤销。
  • 每个教育许可证额外 $150 USD。

如何购买

网上商店 *Recommended

我们建议在线购买，因为这是最快的交付方式。在线购买时，许可证会在结账完成时交付。通过电汇进行的购买会在收到款项后手动交付。

购买步骤

  1. 登录你的 derivative.ca 账户。
  2. 单击购物车图标。
  3. 将所需项目添加到购物车。
  4. 完成付款详情。
  5. 结账完成后，许可证会自动交付到你的账户。

(*Dongles and Floating Cloud licenses are sent separately. A member of our team will contact you within 24 hours of purchase Monday - Friday.)

电汇

如果无法使用信用卡或 PayPal 购买，我们很乐意协助你通过电汇进行手动购买。

通过电汇购买的步骤

  1. 将采购订单通过电子邮件发送至 sales@derivative.ca
  2. 将开具发票，其中包含 Derivative 的电汇银行信息。
  3. 收到款项后，订单将手动交付到你的账户，许可证可用后我们的团队成员会与你联系。
