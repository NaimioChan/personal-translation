Analyze POP

摘要

Analyze POP 分析 POP 的任意点、顶点或图元属性，并输出一个包含统计结果的点。它通常计算任意属性的平均值、最小值或最大值。

将 Analyze POP 连接到 POP to DAT（并设置其 Transpose），看看它能得出什么结果。

如果选择多个属性，或选择全部（*），它会将输入 POP 的属性名称附加到所有输出属性名上。

提示：Analyze POP 的结果是 GPU 上的单个点。之后如何使用它会影响性能。越保持在 GPU 中，速度越快。将结果拉回 CPU 并在参数中使用会较慢。你可以通过 POP to CHOP 在下一帧拿到它（更快），但当然会有延迟。或者可以完全留在 GPU 的 POP 世界里，把这个点作为输入传给其他操作符，例如 Math Mix POP。

对于具有多个分量的属性，分析是按分量进行的。例如对 P，Min(0) 是 X 的最小值，Min(1) 是 Y 的最小值。indexMin(0) 是 X 值最小的点的索引，IndexMin(1) 是 Y 值最小的点的索引。

它还可以选择输出输入属性各采样的和与幂。

如上所述，它可以输出所选输入属性中具有最大值或最小值的采样的点索引（点编号）。

也可以在执行分析之前，使用 Combine Components 菜单将向量的各分量合并为单个分量。

注意：Palette 中的 popViewer 可以显示所有属性的范围。

另请参阅：Accumulate POP、Histogram POP

Info CHOP 通道

Analyze POP 的额外信息可通过 Info CHOP 查看。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
