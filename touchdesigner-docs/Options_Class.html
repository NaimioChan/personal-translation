Options 类

Options 类描述了可配置的 UI 选项集合。可以通过 ui.options 对象访问它。

成员

没有该操作符专属的成员。

方法

resetToDefaults()→ None:

将所有选项重置为默认值。

特殊函数

len(Options)→ int:

返回选项的总数。 

a = len(ui.options)

[<option name>]→ value:

根据选项名键获取或设置特定选项。 

v = ui.options['DAT.width']
ui.options['DAT.width'] = 50

Iterator→ str:

遍历每个选项名。 

for n in ui.options:
	print(n) # 打印所有选项的名称
