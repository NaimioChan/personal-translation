ProgressiveUnloader 类

ProgressiveUnloader 类描述 COMP 的 COMP.progressiveUnload() method 的一个特定实例。此类的方法和成员用于获取正在进行的渐进式卸载操作的进度信息，或修改该操作。 

n = op('comp1')

# 检查 comp1 是否正在逐步卸载
n.progressiveUnloader.active

# 获取 comp1 开始逐步卸载以来的总帧数
n.progressiveUnloader.elapsedFrames

# 终止 comp1 的逐步卸载
n.progressiveUnloader.kill()

成员

active → bool (Read Only):

如果渐进式卸载正在进行，返回 true

remainingNodes → float (Read Only):

返回剩余待卸载的节点数。若从未对该组件调用过 progressiveUnload()，则返回 0

nodesUnloaded → float (Read Only):

返回已卸载的节点数。若从未对该组件调用过 progressiveUnload()，则返回 0

lastFrameUnloadTime → float (Read Only):

返回最新一帧的卸载时间（毫秒）。若从未对该组件调用过 progressiveUnload()，则返回 0

averageFrameUnloadTime → float (Read Only):

返回此前所有帧的平均卸载时间（毫秒）。若从未对该组件调用过 progressiveUnload()，则返回 nan

gpuMemUnloaded → float (Read Only):

返回已卸载的 gpuMemory 总量（MB）。若从未对该组件调用过 progressiveUnload()，则返回 0

elapsedFrames → float (Read Only):

返回自渐进式卸载开始以来经过的帧数。若从未对该组件调用过 progressiveUnload()，则返回 0

方法

kill()→ None:

终止渐进式卸载操作。
