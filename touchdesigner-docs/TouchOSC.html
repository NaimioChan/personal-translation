TouchOSC

TouchOSC 是面向 iOS（iPhone/iPod Touch/iPad）和 Android 的模块化 OSC 与 MIDI 控制界面。它可以通过与控制面板的交互，以 OSC 向 TouchDesigner 发送消息。可使用适用于 Windows/Mac OSX/Linux 的 TouchOSC Editor 创建自定义控制面板。

更多信息以及 App Store 和 TouchOSC Editor 的链接见此：http://hexler.net/software/touchosc

在 TouchDesigner 中使用 TouchOSC

设置 TouchOSC

首先要确保运行 TouchOSC 的设备和运行 TouchDesigner 的电脑处于同一无线网络，以便二者能够通信。

安装 TouchOSC 后，启动应用，你会看到以下界面。

打开 OSC:Disabled 菜单。进入下一页后，开启 Enabled 开关，即可看到以下界面。

在此设置界面中，输入运行 TouchDesigner 的电脑的 IP 地址。如果你不想使用默认端口号，也可以在这里修改。完成后按 Done 按钮关闭对话框。

回到 TouchOSC 的起始界面，在 Layout 菜单中选择要使用的 Layout。准备好后按 Done 按钮。

设置 TouchDesigner

打开 TouchDesigner 并创建一个 OSC In CHOP 或 OSC In DAT。将 Network Port 参数改为你在 TouchOSC 的 Port(outgoing) 设置中选择的同一端口。默认为 8000。

现在移动或调节 TouchOSC 中的任意控件，你就会在 TouchDesigner 中看到传入的值。
