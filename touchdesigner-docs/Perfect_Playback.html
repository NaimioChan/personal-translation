完美播放

概述

本文中的「图像」一词指一个窗口的完整内容，而不是单个 TOP 的内容，因为 TOP 的内容只有在被绘制到窗口时才可见。

本页的大部分信息与 Windows 操作系统相关，因为我们在 macOS 设备上运行演出的经验不多。

尽管许多演出/项目对偶发的丢帧/卡顿并无大碍，但某些类型的内容对此格外不能容忍，缓慢平滑的运动就是一个常见例子。要获得完美播放，必须满足几项要求。TouchDesigner 生成图像的速度必须足够快，能在输出设备每次刷新时都提供一幅新图像。它也不能以与输出设备不同的速率运行。对于 60Hz 的显示器，TouchDesigner 必须以 60FPS 运行且不丢任何一帧。如果你的输出设备是别的东西，例如 SDI 卡，那么 TouchDesigner 必须以与 SDI 信号相同的速率运行（例如 29.97Hz）。

这些图像需要完整显示，而不是部分更新。对于显示器输出，这通过 Vertical Sync 实现。对于 SDI 及其他输出类型，这不成问题。

对于显示器输出，操作系统必须真正把图像呈现到屏幕上，而不是悄悄丢掉它们。这通过对桌面的「独占」访问来实现。更多信息见 here。

显示器输出的完美播放

这些是连接到桌面的输出，你通过 Window COMP 把图像显示到它们上面。

快速回答

执行以下所有操作：

  • 确保你的 TouchDesigner 设置为与显示器相同的 FPS。用 Monitors DAT 来确认这一点。
  • 确保你所有显示器都以相同的刷新率运行。用 Monitors DAT 来确认这一点。
  • 如果使用影片内容，确保它以等于显示器刷新率、或能整除显示器刷新率的 FPS 制作。

使用 Window COMP 与桌面

  • 把所有活动输出合并为一个虚拟显示器，从而把所有显示器输出合并为单个显示器输出；也可以选用 splitter device 把这些输出再拆分到更多显示器上。
  • 确保 Windows 的桌面缩放设置为 100%。
  • 确保在 Window COMP 中启用了 Vertical Sync。
  • 使用 Perform Mode。
  • 在你的 Window COMP 中禁用 Borders。
  • 不要打开任何多余的 Window COMPs。你的执行窗口应是 TouchDesigner 唯一打开的窗口。
  • 确保你的 Perform Window 已获得对桌面的全屏独占访问，更多信息见 here。

OR

Direct Display Out

  • 另一种做法是改用 Direct Display Out TOP，这样使用 Window COMP 与桌面所带来的问题就都消失了。条件允许时可以考虑使用它。

显示器刷新率与项目 FPS

用 Monitors DAT 查看你的显示器实际运行的确切刷新率。Windows 的其他对话框常把刷新率四舍五入为 60 或 30，而实际速率是 59.94 或 29.97。目标是 60FPS 却在 59.94Hz 的显示器上运行时，播放中会规律性地丢帧。

在 Window COMP 的「V-Sync Mode」下有一个选项叫「FPS is Half Monitor Rate」。在 2022.20000 系列之前的版本（Vulkan 之前）中，它让你能在 60Hz 显示器上以 30FPS 运行项目，同时确保每幅图像恰好显示 2 次刷新。没有这个选项时，一幅图像可能显示 1 次或 3 次刷新，使内容看起来在抖动。目前该功能在 2022.20000+ 系列版本中不可用，但我们希望在 Vulkan 支持后重新加入。

影片内容的 FPS

如果你在播放影片内容，该内容需要以相同的速率制作，或至少以能整除显示器刷新率的速率制作（例如在 60Hz 显示器上播放 30FPS 内容）。在 60Hz 显示器上播放 29.97FPS 视频，内容中会规律性地出现重复帧，对于缓慢平滑的运动看起来就像卡顿。

以独占访问模式运行

从 Windows 8 开始，桌面上的窗口由「Desktop Window Manager (DWM)」管理。该管理器控制桌面上不同窗口的更新方式、在它们之间进行合成等。遗憾的是，即使 TouchDesigner 以所需刷新率向操作系统提供图像，DWM 仍可能最终没有把图像显示到桌面上。对于 DWM 随机丢帧，目前唯一已知的解决办法是确保应用程序对 GPU 有「独占访问」。判断 TouchDesigner 是否获得独占访问的方法是：进入执行模式时显示器上会出现全屏闪烁；或者当你点击执行窗口以外的其他窗口、使执行窗口失去焦点时，也会出现闪烁。

进入独占模式有两种方式。第一种是使用一个覆盖整个桌面的全屏无边框窗口，并确保桌面只有一个显示器。如果 GPU 上还连接着不用于输出的额外显示器（比如用于控制操作系统或运行其他应用），TouchDesigner 就无法获得对桌面的完全控制。在此模式下，你可以点击窗口外离开独占模式，再点回窗口重新进入独占模式，每次都应看到闪烁。

第二种方式是 Window COMP 中的新功能：在「Opening Size」下选择「Single Monitor Exclusive」。这使执行窗口只针对单个显示器，其他显示器仍可连接在桌面上。此模式下你也应该会看到闪烁，但如果你点击窗口外，就无法重新进入独占模式，需要退出再重新进入执行模式。

查看 Windows 的翻转/位块传输（flipping/blitting）行为，一个有用的工具是 PresentMon

弹出菜单

由于同一时间只有一个窗口能独占访问驱动，像弹出/下拉菜单这样在你的 UI 之上再开一个窗口的东西，会使执行窗口退出独占访问并造成闪烁。如果比起常规窗口可能出现的丢帧，你更不希望这种闪烁，那就需要把窗口的宽或高做得比桌面小 1 像素，以确保它不进入独占访问模式。

把多个显示器合并为单个虚拟显示器

要获得独占模式，你只能针对单个显示器。但大多数项目需要多个显示器输出，所以你会想用 Nvidia Mosaic、Nvidia Surround 或 AMD EyeFinity 把它们合并成一个虚拟显示器。更多信息参见 Multiple Monitors。

使用执行模式并避免多个窗口

确保你在使用 Perform Mode，并确保在 Window COMP 上启用了 Vertical Sync（虽然它默认就是启用的）。

同时有多个窗口在绘制时，帧率会显著下降。GPU 驱动必须让多次缓冲区交换与单个显示器同步，造成大幅变慢。因此你应把所有内容放在一个窗口里。用 Perform Panel 来做，或者打开一个大的 Window COMP 并打开它的 Perform 参数。

非显示器输出的完美播放

非显示器输出的例子包括使用 Video Device Out TOP（虽然它也可以在后台驱动一台显示器）以及 NDI Out TOP。

快速回答

  • 确保你的 TouchDesigner 设置为以输出设备目标 FPS 相同的 FPS 运行。
  • 如果使用影片内容，确保它以等于显示器刷新率、或能整除显示器刷新率的 FPS 制作。
  • 使用 Perform Mode，并禁用 Vertical Sync 或禁用「Draw Window」选项。

影片内容的 FPS

参见 Perfect_Playback#Movie_Content_FPS。

执行模式与桌面显示器同步

默认情况下，Window COMP 的设置会让执行窗口尝试与连接到你的桌面的显示器进行垂直同步。当输出到其他输出设备时，你目标的刷新率很可能与该显示器实际运行的刷新率不同。这会导致 TouchDesigner 错误地同步到显示器的刷新率，即使你的项目 FPS 已设为你所需输出对应的正确值。要避免这一点，要么在执行窗口的 Window COMP 中关闭「Vertical Sync」，要么用 Window COMP 中的「Draw Window」参数完全关闭绘制。目前在 Designer Mode 下无法避免同步，因此帧丢失/性能只应在 Perform Mode 下评估。
