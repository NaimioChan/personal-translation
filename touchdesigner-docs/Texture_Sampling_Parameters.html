Texture Sampling Parameters

在任何为材质或着色器采样 TOP 的地方都可以访问 Texture Sampling 参数。要打开这些参数，请点击参数右侧的「+」按钮。内部名称的 parameter 部分取决于这些参数与哪个贴图参数相关。例如对于 colormap 参数，extendu 会是 colormapextendu。

Extend U /parameterextendu - 设置 U 坐标/方向的扩展模式。更多信息请参阅 Texture Extend Modes。

Extend V /parameterextendv - 设置 V 坐标/方向的扩展模式。更多信息请参阅 Texture Extend Modes。

Extend W /parameterextendw - 设置 W 坐标/方向的扩展模式。仅用于 3D Texture。更多信息请参阅 Texture Extend Modes。

Filter /parameterfilter - 控制此 TOP 被使用时如何过滤。更多信息请参阅 Texture Filtering。

Anisotropic Filter /parameteranisotropy - 控制此 TOP 被采样时使用的各向异性过滤级别。这会在采样 TOP 时产生更多采样，提高纹理质量。更多信息请参阅 Anisotropic Filtering。

Texture Coord /parametercoord - 决定使用哪一组纹理坐标（哪一层纹理）。

Coord Interpolation /parametercoordinterp - 调整 Perspective Correct 与 Linear（无透视）之间的纹理坐标插值。
