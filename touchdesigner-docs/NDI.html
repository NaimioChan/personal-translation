NDI

Newtek NDI®（Network Device Interface）是由 NewTek 开发的基于网络的视频和音频分发协议（基于以太网 LAN 的视频 over IP）。NDI® 是 NewTek, Inc. 的注册商标。关于 NDI 及其优势的详细说明可在 Official NDI page. 找到。它可用于 TouchDesigner 到 TouchDesigner，也可与众多支持 NDI 的其他软件工具和硬件产品配合使用。

参见 NDI In TOP、NDI Out TOP、NDI DAT 和 NDI Performance Testing

另请参阅：H.264 over IP 的 Video Stream In TOP、Video Stream Out TOP，以及 HAP over IP 的 Touch In TOP 和 Touch Out TOP。

对于 Build 2022.20000+ 及更高版本，查看 NDI 节点上的信息弹窗（中键单击），可以看到该版本使用的 NDI SDK 版本。
Build 2021.13790-2021.17000 使用 NDI 4.6.1 版
Build 2020.24520-2021.13780 使用 NDI 4.5 版。
Build 2020.20000-2020.24510 使用 NDI 4.1 版。

网络

NDI 协议使用 mDNS 自动发现 NDI 视频源，mDNS 是一种多播服务发现协议。如果你的 NDI 源位于多播无法到达的网络上，则需要在 NDI In TOPs 参数中指定源机器的 IP。

延迟

相比 RTSP / H264，NDI 提供延迟极低的方案，代价是更高的网络带宽。

视频格式

通过 NDI 发送的视频以 YUV 4:2:2 格式发送，并经过压缩。视频还可以选择包含 Alpha 通道。视频可以是 8 位或 16 位色深。除硬件能处理的限制外，FPS 和分辨率没有限制。压缩使用 SpeedHQ codec 完成，它基于 CPU，速度非常快。NDI 会根据包括 FPS 在内的几个因素选择压缩级别。以更高 FPS 发送时会使用更高的压缩比，以确保带宽需求不会过高。

音频

通过 NDI 发送的音频，会以传给 NDI Out TOP 的音频 CHOP 的采样率和通道数发送。

元数据

NDI 可以选择随视频帧一起发送元数据。通过 NDI 发送的元数据必须格式化为 XML。对于文本输入，文本必须已经是 XML 格式；而对于表格输入，我们会使用以下格式将单元格转换为 XML：

<?xml version="1.0" ?>
<TouchDesignerFormat>
	<HeaderInfo version=1 datatype="table" numrows=2 numcolumns=2 />
	<Data>
		<Row row=0>
			<Column column=0>
				<Cell value="A" />
			</Column>
            <Column column=1>
				<Cell value="B" />
			</Column>
		</Row>
		<Row row=1>
			<Column column=0>
				<Cell value="C" />
			</Column>
            <Column column=1>
				<Cell value="D" />
			</Column>
		</Row>
	</Data>
</TouchDesignerFormat>

多播

NDI 也可以使用多播发送数据。有关如何为 NDI 启用多播的帮助，请参阅 NDI 文档。多播的控制在 TouchDesigner 之外使用 NDI Access Manager 工具完成，该工具随 Newtek NDI Tools 提供。

分组

NDI 支持源将自身标记为一个或多个命名「组」的成员。当 NDI 接收方搜索源时，可以指定它感兴趣的组，以减少列出的源数量。

应用

NDI 提供了一个实用的移动应用，可以从手机流式传输 NDI。请在应用商店中搜索 Newtek NDI。

网络性能设置

在我们的几个内部测试平台上发现，将网络控制器的 Jumbo Frames 设为最大值后，在解决千兆网卡和交换机上高分辨率丢帧方面产生了非常明显的正面性能结果。并非所有交换机都支持 Jumbo Frames。支持的一个好交换机是 Cisco SG300-12 和 Cisco SG350-12 型号。

要设置巨型帧，请打开控制面板，找到网卡属性并点击 Configure 按钮。

在网卡属性对话框中找到 Advanced 页，在属性列表中找到 Jumbo Packet，将值设为 9014 Bytes。

性能统计

1 路 4K RGB 噪声信号约为 900 Mb/s，因此单路 4K 信号就能完全占满 1Gb/s 交换机。NDI 使用变化很大的压缩，因此 Mb/s 取决于内容。测试带宽时请使用 RGB 随机噪声，以了解你的最大需求。

排查连接问题

  • 确保所有 TouchDesigner 发送方和接收方运行相同版本的 TouchDesigner。
  • 尝试停用有问题计算机的防火墙。如果这解决了问题，请在重新开启防火墙之前解决防火墙问题。

排查丢帧问题

  • 发现其他互联网应用——最明显的是 Skype——可能干扰 NDI 并导致丢帧。原因尚不清楚，但我们确实清楚地看到过这种情况——可能是冲突所致。
