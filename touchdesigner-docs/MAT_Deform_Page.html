MAT 变形页

参数 - Deform 页

关于在 TouchDesigner 中进行变形（deform）的更多信息，请参考 Deform Article。

Deform dodeform - 在此材质上启用变形。
Get Bone Data: deformdata - 指定从何处获取变形骨骼数据。
  • From a SOP sop -
  • From another MAT mat -
  • From a DeformIn MAT deformin -
SOP with Capture Data targetsop - 指定包含变形捕获属性的 SOP。
pCaptPath Attrib pcaptpath - 指定要使用的 pCaptPath 属性的名称。当你的几何经过 Bone Group SOP 处理后，属性会被拆分为 pCaptPath0、pCaptPath1 这样的名称。一次只能渲染 1 个骨骼组，因此这应与用此材质渲染的组相匹配。
pCaptData Attrib pcaptdata - 与 pCaptPath Attrib 类似。
Skeleton Root Path skelrootpath - 指定骨架根部所在 COMP 的路径。
MAT mat - 从 MAT 或 Deform In MAT 获取变形数据时，在此处指定该 MAT。
