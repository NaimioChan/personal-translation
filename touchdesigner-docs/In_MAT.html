深度测试

深度测试是把正在绘制的像素的深度值与 Frame-Buffer 中当前像素的深度值进行比较。被判定在 Frame-Buffer 中当前像素之前的像素会绘制在其上。被判定在当前像素之后的像素不会被绘制。深度测试让 3D 场景中的几何能遮挡其后面的几何，也能被前面的几何遮挡，与几何的绘制顺序无关。

关于深度测试的更详细描述，请参考 Depth-Test 文章。

Depth Test depthtest - 启用和禁用 Depth-Test。如果禁用 depth-test，深度值不会被写入 Depth-Buffer。
Depth Test Function depthfunc - 用此函数把正在绘制的像素的深度值与深度缓冲中当前的深度值比较。如果测试通过，像素会被绘制到 Frame-Buffer。如果测试失败，像素被丢弃，Frame-Buffer 不做任何更改。

  • Less Than or Equal lessorequal -
  • Equal equal -
  • Greater Than greater -
  • Greater Than or Equal greaterorequal -
  • Not Equal notequal -
  • Always always -
Write Depth Values depthwriting - 如果 Write Depth Values 打开，通过深度测试的像素会把其深度值写入 Depth-Buffer。如果此项未打开，无论绘制的像素是否通过深度测试，Depth-Buffer 都不会有任何变化。

线框

线框功能会把几何渲染为线框，使用渲染中实际使用的图元类型。这意味着 Metaballs、NURBs 和 Beziers 等曲面会变成用于渲染它们的三角形/三角形带的线框（因为这些类型的图元无法在 OpenGL 中原生渲染）。

Wire Frame wireframe - 启用和禁用线框渲染，可选择基于 OpenGL Tesselated 或基于 Topology 的线框。
  • Off off -
  • OpenGL Tesselated Wire Frame tesselated -
  • Topology Wire Frame topology -
Line Width wirewidth - 此值是线框的宽度。此值以像素为单位。

剔除面

cull face 参数会从渲染输出中剔除面。这可以用作优化，有时也用于去除伪影。更多信息参见 Back-Face Culling。

Cull Face cullface - 选择要渲染哪些面。
  • Use Render Setting userender - 使用 Render 或 Render Pass TOP 中的渲染设置。
  • Neither neither - 不剔除任何面，渲染所有内容。
  • Back Faces backfaces - 剔除背面，渲染正面。
  • Front Faces frontfaces - 剔除正面，渲染背面。
  • Both Faces bothfaces - 剔除两个面，不渲染任何内容。

多边形深度偏移

此功能会把多边形向外稍微推后一点点。当你渲染两个正好重叠的多边形并遇到 Z-Fighting 时，这很有用。更多信息请参考 Polygon Depth Offset。在做 shadows 时这也是一个重要功能。
