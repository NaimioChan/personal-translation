COMP Layout 参数页

参数 - Layout 页

Layout 参数页控制面板的大小和位置。大小和位置以「面板单位」指定。这些单位不一定对应像素。取决于显示器的 DPI 缩放设置，一个面板单位可能覆盖多于或少于一个像素。不过，如果 DPI 缩放设为 1.0，则 1 面板单位等于 1 像素。可以通过在打开面板的 Window COMP 中设置「DPI Scaling」参数，让面板始终以像素为原生尺寸。

X x - 指定水平位置，以面板单位计，相对于其父级。
Y y - 指定垂直位置，以面板单位计，相对于其父级。
Width w - 指定面板宽度，以面板单位计。
Height h - 指定面板高度，以面板单位计。
Fixed Aspect fixedaspect - - 可以轻松创建具有下方 Aspect Ratio 参数所设特定宽高比的面板。只需设置面板的宽度或高度，另一维会根据 Aspect Ratio 参数计算。
  • Off off -
  • Use Horizontal horizontal -
  • Use Vertical vertical -
Aspect Ratio aspect - 使用上面的 Fixed Aspect 参数时指定比例，比例为宽度/高度。
Depth Layer layer - 指定面板组件的绘制顺序，类似 Photoshop 中的图层。数值较高的会绘制在任何数值较低的面板之上（处于同一层级时）。如果两个面板组件的 Depth Layer 值相同，则按操作符名称排序。
Horizontal Mode hmode - - 从 3 种模式中选择一种，以决定面板的水平宽度。
  • Fixed Width fixed - 使用上面的 Width 参数以面板单位设置此面板的宽度。
  • Fill fill - 此面板的宽度将匹配（填满）父面板的宽度。
  • Anchors anchors - 此面板的宽度由下方的 Left Anchor 和 Right Anchor 参数设置，在父面板尺寸变化时保持相对于父面板的宽度。这可以实现可拉伸的面板。这些锚点参数像 uv 坐标一样归一化为 0-1，0 是父面板的左边缘，1 是父面板的右边缘。例如，Left Anchor = 0.2、Right Anchor = 0.8 会保持宽度与父面板成比例，使左边缘距左侧 20%（0.2），右边缘距右侧 20%（0.8）。
Left Anchor leftanchor - 面板左锚点相对于父级的位置。该值归一化为 0-1，0 是父级的左边缘，1 是父级的右边缘。
Left Offset leftoffset - 左锚点的偏移量，以面板单位计。
Right Anchor rightanchor - 面板右锚点相对于父级的位置。该值归一化为 0-1，0 是父级的左边缘，1 是父级的右边缘。
Right Offset rightoffset - 右锚点的偏移量，以面板单位计。
Horizontal Origin horigin - 水平设置面板原点的位置。默认原点 (0,0) 是面板的左下角。
Horizontal Fill Weight hfillweight - 当多个面板使用 Horizontal Mode = Fill 并由父级按 Left to Right 或 Right to Left 对齐时，此 fill weight 参数可用于偏向面板的填充宽度。
Vertical Mode vmode - - 从 3 种模式中选择一种，以决定面板的垂直高度。
  • Fixed Height fixed - 使用上面的 Height 参数以面板单位设置此面板的高度。
  • Fill fill - 此面板的高度将匹配（填满）父面板的高度。
  • Anchors anchors - 此面板的高度由下方的 Bottom Anchor 和 Top Anchor 参数设置，在父面板尺寸变化时保持相对于父面板的高度和比例。这可以实现可拉伸的面板。这些锚点参数像 uv 坐标一样归一化为 0-1，0 是父面板的下边缘，1 是父面板的上边缘。例如，Bottom Anchor = 0.3、Right Anchor = 0.5 会保持高度与父面板成比例，使下边缘距底部 30%（0.3），上边缘距顶部 50%（0.5）。
Bottom Anchor bottomanchor - 面板下锚点相对于父级的位置。该值归一化为 0-1，0 是父级的下边缘，1 是父级的上边缘。
Bottom Offset bottomoffset - 下锚点的偏移量，以面板单位计。
Top Anchor topanchor - 面板上锚点相对于父级的位置。该值归一化为 0-1，0 是父级的下边缘，1 是父级的上边缘。
Top Offset topoffset - 上锚点的偏移量，以面板单位计。
Vertical Origin vorigin - 垂直设置面板原点的位置。默认原点 (0,0) 是面板的左下角。
Vertical Fill Weight vfillweight - 当多个面板使用 Vertical Mode = Fill 并由父级按 Top to Bottom 或 Bottom to Top 对齐时，此 fill weight 参数可用于偏向面板的填充高度。
Parent Alignment alignallow - - 设为 Ignore 时，面板会忽略其父级的任何 Align 参数设置。
  • Allow allow - 根据父级中的设置对齐面板。
  • Ignore ignore - 不对齐面板，但遵循边距。
  • Ignore and Ignore Margins ignoremargin - 不对齐面板，且忽略边距。
Align Order alignorder - 当父级的 Align 参数设置为 None 或 Match Network Nodes 以外的值时，此参数允许你指定对齐位置。数字较小的优先。
Post Offset postoffset - - 在所有其他位置和对齐选项应用到面板之后添加偏移。
  • X postoffsetx -
  • Y postoffsety -
Size from Window sizefromwindow - 启用后，面板组件的宽度和高度通过调整其浮动查看器窗口的大小来设置。
