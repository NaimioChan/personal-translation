参数 - Children 页

Children 参数页控制面板子级的对齐、大小和位置等方面。

Align align - - 此菜单用于指定 Panel Component 内子级的布局方式。Layout Grid Rows、Layout Grid Columns 和 Match Network Nodes 选项会缩放 Panel Component 的子级以适合组件。它们使用各子级的 Align Order 来确定子级的顺序。
  • None none -
  • Left to Right horizlr -
  • Right to Left horizrl -
  • Top to Bottom verttb -
  • Bottom to Top vertbt -
  • Grid Rows gridrows -
  • Grid Columns gridcols -
  • Match Network Nodes nodes -
Spacing spacing - 通过选择 None 或 Match Network Nodes 以外的任何 Align 选项启用。它定义对齐时子级之间的间距。
Max per Line alignmax - 通过选择 None、Layout Grid Horizontal、Layout Grid Vertical 或 Match Network Nodes 以外的任何 Align 选项启用，定义一行或一列中放置的子级最大数量。
Margin margin - - 这四个字段用于指定围绕 Panel Component 的空间。边距是 Panel Component 边框与外边缘之间的空间。

边距以绝对面板单位定义，不随窗口拉伸，因此边距不会反映在节点的面板查看器中，只在父级于浮动窗口中绘制时才体现。

  • L marginl -
  • R marginr -
  • B marginb -
  • T margint -
Justify Mathod justifymethod - - 此菜单指定面板的子级是作为一个组还是各自独立地使用下方 Jusitfy Horizontal / Vertical 参数进行对齐。
  • individual individual - 将所有子级分别独立对齐。
  • Group group - 将所有子级作为一个组对齐。先将所有子级归入一个边界框，再对齐该框。
Justify Horizontal justifyh - - 此菜单指定面板的子级是否在水平方向对齐。
  • Off off -
  • Left left -
  • Center center -
  • Right right -
Justify Vertical justifyv - - 此菜单指定面板的子级是否在垂直方向对齐。
  • Off off -
  • Top top -
  • Center center -
  • Bottom bottom -
Fit fit - - 此菜单用于缩放面板的子级。它会覆盖 Justify Horizontal 和 Justify Vertical 参数。
  • Off off -
  • Fit Width horizontal -
  • Fit Height vertical -
  • Fit Best best -
Scale scale - - 允许你统一缩放面板的子级。
  • X scalex -
  • Y scaley -
Offset offset - - 允许你偏移面板的子级。此参数会被上面的 Align、Justify Horizontal 和 Justify Vertical 参数覆盖。
  • X offsetx -
  • Y offsety -
Crop crop - - 此菜单决定部分或完全位于面板组件尺寸之外的子级面板是否被裁剪。
  • Off (Use Parent) off -
  • On on -
  • Never never -
Horizontal Scrollbar phscrollbar - - 此面板上水平滚动条的设置。
  • Off off - 无滚动条。
  • On on - 始终包含滚动条。
  • Automatic auto - 仅当子级宽度大于此面板宽度时包含滚动条。
Vertical Scrollbar pvscrollbar - - 此面板上垂直滚动条的设置。
  • Off off - 无滚动条。
  • On on - 始终包含滚动条。
  • Automatic auto - 仅当子级高度大于此面板高度时包含滚动条。
Thickness scrollbarthickness - 以面板单位设置滚动条的厚度。
