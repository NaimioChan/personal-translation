Joint SOP

摘要

Joint SOP 有助于创建基于圆的骨架，其方式是在每对输入圆之间生成一系列圆。此 SOP 至少需要一对圆才能正确工作。

jointSOP_Class

参数 - 页

Group group - 如果存在输入组，在此字段中指定组名会让该 SOP 只作用于指定的组。接受模式，参见 Pattern Matching。
Divisions divs - 让你指定每对输入圆之间的圆数量。
Preserve First Input preserve1 - 保留输入到该 SOP 的第一个圆。
Preserve Last Input preserve2 - 保留最后一个输入圆。
Orient Circles orient - 这有助于创建一个在输入圆之间过渡、既不压扁也不向外弯曲的关节。为此，可能需要反转每个输入圆的法线。例如，如果两个输入圆的法线彼此背离，那么创建的关节（如果未启用此选项）看起来会绕远路连接这两个圆。此选项会重新调整关节的朝向，使连接走较短的距离。
Smooth Path smoothpath - 如果未开启，关节圆之间是线性混合的。否则，它们会沿圆中心之间的三次分段 Bzier 曲线排布。当输入多于两个圆、且关节之间必须连续时，这很有用。如果未启用此选项，插值可能比预期的更锐利。
Smooth Twist smoothtwist - 每个关节圆都会被略微旋转，使其接近某个输入圆时 X、Y 轴对齐。此开关使这些调整成为增量的、即分段的 Bzier 函数。这同样适用于多圆输入。
Align Major Axes majoraxes - 启用后，此选项会把第一个圆的最大轴与最后一个圆的最大轴对齐。禁用时，则对齐第一个和最后一个圆的 x 轴。此选项有助于尽量减少骨骼之间关节椭圆的扭转。
Minimum Twist mintwist - 开启后，添加的圆的旋转会被计算为任一方向都不超过半圈。这会形成视觉上连续的布局，适合创建骨架；但如果之后要给这些圆蒙皮，就会出问题，因为各圆的开头可能不再连续对齐。
LR Scale lrscale - - 这些参数控制平滑路径的形状，从左侧或右侧改变隐含曲线的形状。如果 Orient Circles 选项开启，scale 的正负没有影响。关于左右这两个相对术语的讨论，参见 Align SOP。

  • lrscale2 -
LR Offset lroffset - - 这些参数让你可以覆盖圆之间的距离，从而影响关节的形状。

Info CHOP 通道

Joint SOP 的附加信息可以通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
