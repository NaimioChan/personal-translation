Point 类

Point 描述对单个 geometry point 的一个实例。可通过 SOP.points 成员访问它们。

成员

index → int (Read Only):

该点在列表中的索引。

owner → OP (Read Only):

此对象所属的 OP。

P → td.AttributeData :

坐标，类型为 AttributeData。可以用 [] 运算符读取或写入各个分量。 

point.P[0] = 5
point.P = (1,0,1)

x → float :

获取或设置 x 坐标值。等同于 P[0]。

y → float :

获取或设置 y 坐标值。等同于 P[1]。

z → float :

获取或设置 z 坐标值。等同于 P[2]。

normP → tdu.Position (Read Only):

该点在 SOP 包围盒内的归一化位置。始终在 [0,1] 范围内。以 tdu.Position 对象表示。

属性

除上述成员外，所有 attributes 也都是成员。

例如，如果该 Point 含有纹理坐标，可以这样访问：Point.uv 

box = op('box1')
print(box.N[0], box.N[1], box.N[2])
print(box.uv[0], box.uv[1], box.uv[2])

更多信息见 Attribute Class。

方法

destroy()→ None:

销毁并移除该对象所指的实际点。仅当该图元属于 scriptSOP 时此操作才有效。注意：调用之后，此 SOP 中其他已有的 Point 对象可能不再有效。
