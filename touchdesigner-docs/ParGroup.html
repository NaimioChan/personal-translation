ParGroup

ParGroup（参数组）是一组相关参数，可以整体设置和获取，而不必逐个参数操作。例如，ParGroup t 是 tx ty tz。

ParGroup

ParGroup 是一组相关参数。以 ParGroup 整体来操作通常比逐个操作 parameters 更自然。

通常，parameter dialog 上同一行显示的所有参数都属于同一个 ParGroup。例如，在 Transform TOP 中，Translate 是一种 ParGroup，包含两个主要 Par 对象：tx、ty，以及一个单位 Par。

也可以有只含单个元素的 ParGroup。例如， Geometry Object 的 Uniform Scale 参数属于一个只含一个参数的 ParGroup。注意，多元素的 ParGroup 只包含数值元素。字符串只存在于大小为 1 的 ParGroup 中。

另请参阅 ParGroup Execute DAT

基本用法

以下示例假设 n 是一个 Transform TOP，其 translate 设为 1, 2。与 n.par 一样，n.parGroup 可用于访问单个 ParGroup 对象：

t = n.parGroup.t     # 把 t 设为 Translate ParGroup
t = n.parGroup["t"]  # 为方便起见，也支持按名称映射访问。仅支持精确名称，不支持通配符。

此后，Par 对象可用的大部分成员和方法对 ParGroup 对象同样可用。不过，在适用的情况下它们返回的是值元组，而非单个值。

t.expr   # 如果 translate 参数未设置表达式，则返回 (None, None)

求值

t.eval()   # 返回 (1, 2)

注意，如果 ParGroup 只包含单个元素（例如 Uniform Scale 参数），其 eval() 方法仍返回元组而非单个值：

n.parGroup.scale.eval()  # 返回 (1.0,)

大小、映射与迭代

len(t)   # 返回 2，因为该 ParGroup 包含 2 个主参数。unit 参数在这里不包含在内。

t[1].name   # 返回 'ty'，因为 t[1] 返回 Par 对象 ty。

[i.name for i in t] # 返回 ['tx', 'ty'] #仅主参数

[i.name for i in t.pars()] # 返回 ['tx', 'ty', 'unit'] #所有参数

pars 方法与 OP.pars 相同，返回此 ParGroup 中的 all 参数，无论是否为主参数。

赋值

可以为 ParGroup 赋单个值（标量）或同样大小的元组。注意，在以下示例中，元组 () 和列表 [] 可以互换。不过在某些情况下，使用列表语法歧义更少：[3] vs (3,),，因为 (3) 不是元组。

n.parGroup.t = (4, 5)    # 赋值 tx=4, ty=5
n.parGroup.t = [4,5]    # 任何大小为 2 的可迭代对象都可以

n.parGroup.t = 5             # 把 5 赋给 tx, ty
n.parGroup.t = n.parGroup.p   # 把 pivot 值赋给 translate 参数。

n.parGroup.t = (1,2,3)  # 报错，不能把 3 个元素赋给 2 个。

注意，直接赋值给参数的 val 成员时，上述写法同样有效：

n.parGroup.t.val = (1,2)

算术运算

ParGroup 可以直接用于某些算术表达式，因为运算会按元素逐一应用：

n.parGroup.t + 1  # 返回 (2.0, 3.0)
n.parGroup.t + (1,2)  # 返回 (2.0, 4.0)

不过，为确保向前兼容，最好在适用处创建 ParGroup 对象：

tdu.Vector(n.parGroup.t) + (1,2)   # 返回值为 2.0  4.0 的 Vector

类型转换

将 ParGroup 转换为 bool 总是会抛出异常，因为 ParGroup 始终是非空元组，所以通常会返回 True。这可能造成混淆：bool(n.parGroup.button) 总是返回 True，使人误以为按钮值本身为 true。

而将 ParGroup 转换为 float 或 int，仅当该 ParGroup 正好包含 1 个元素时才会成功，例如 Uniform Scale 的情况：

5 + float(n.parGroup.scale)

这也意味着，例如 op('geo1').parGroup.scale 可用于需要数值的单个参数表达式中。

此外，由于 ParGroup 的行为类似元组，全局函数 any() 和 all() 也能按预期工作：

	any(n.parTuple.t)	# tx、ty、tz 中任一非零时为 true
	all(n.parTuple.t)	# tx、ty、tz 全部非零时为 true
