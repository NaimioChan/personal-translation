Animation COMP

摘要

Animation Component 是一个特殊组件，用于创建关键帧动画通道。该组件包含一个预定义网络，使用一个 Keyframe CHOP 和若干 Table DATs 来定义动画的 CHOP 通道。

Animation Editor 是用于创建和编辑 Animation Component 动画的用户界面。

Animation Component 同时具有输入和输出 CHOP 连接器。

Animation Component Inputs

在没有连接输入时，Animation Component 的索引会在通道的时间范围内循环。 CHOP 输入可用于手动控制动画通道的索引。例如，如果通道的关键帧从第 1 帧到第 600 帧，你可以将输入连接到该组件，并送入 1 到 600 之间的数值来手动驱动动画输出（超出范围的索引将使用通道的 extend 条件）。

使用 Keyframe CHOP 的 Index Units 菜单，你可以用秒、采样或分数（0 为起点、1 为终点）来表示数值，从而驱动动画。

Animation Component Outputs

CHOP 输出可访问动画通道的当前值。可以直接连接 CHOP，也可以附加一个 Null CHOP 来将通道 exporting 到参数。当前通道值也可以通过开启 Animation Component 的 node viewer 来查看。

使用 Animation Component

在 TouchDesigner 中对任何参数、属性或数据做关键帧，都从 Animation Component 开始。你可以通过以下方式创建 Animation COMP；

  • OP Create Dialog
  • 右键单击任意 OP 的任意参数。 RMB -> Keyframe Parameter in... -> New Animation 以创建新的 Animation COMP

要打开 Animation Editor，右键单击 Animation COMP 并选择 Edit Animation...，在编辑器中打开该动画。你也可以将任意窗格改为 Animation Editor 类型，编辑器会打开并指向最后一次被 scope 的 Animation COMP。

然后你就可以创建通道并设置关键帧。有关打关键帧的说明，请参阅 Animation Editor。

参数 - Animation 页

Time Reference timeref - Animation COMP 获取时间信息的位置。当 Range 页上的 Type 参数设为 Timeline 时，用于默认的通道范围和速率。
Play Mode playmode - - 指定播放动画所使用的方式，或允许输出整条动画曲线。
  • Locked to Timeline locked - 此模式将动画位置锁定到时间轴。在时间轴中拖动或跳转会相应地改变动画位置。此模式下 Play、Speed、Cue 和 Cue Point 参数被禁用，因为时间轴直接控制动画的位置。
  • Use Input Index input - 此模式允许用户使用 Animation COMP 上的索引输入（即输入到 Animation COMP 的 CHOP 输入）指定动画中的特定位置。Input Index Unit 参数可用于更改输入通道的单位。此模式可随机访问动画中的任意位置，灵活性最高。
  • Sequential sequential - 此模式持续播放，与时间轴位置无关（Index 参数被禁用）。下方的 Reset 和 Speed 参数被启用，可提供一定控制。
  • Output Full Range outputrange - 此选项输出整个动画通道范围。这对于用 Animation COMP 创建自定义查找曲线/通道很有用。
Play play - 为 On 时动画播放，为 Off 时停止。此动画播放控制仅在 Play Mode 为 Sequential 时可用。
Speed speed - 这是一个速度倍率，仅在 Play Mode 为 Sequential 时生效。值为 1 是默认播放速度。值为 2 是双倍速，0.5 是半速，以此类推。负值会使动画倒放。
Cue cue - 设为 1 时跳转到 Cue Point。仅在 Play Mode 为 Sequential 时可用。
Cue Pulse cuepulse - 立即跳转到 Cue Point。
Cue Point cuepoint - 将动画中的任意索引设为跳转点。仅在 Play Mode 为 Sequential 时可用。
Cue Point Unit cuepointunit - 设置 Cue Point 参数时使用的单位。
Input Index Unit inputindexunit - - 当 Play Mode 设为 Use Input Index 时，使用此菜单为索引输入通道选择单位。例如，在帧或秒之间选择来设置索引。Units X 选项会让索引直接使用 Animation COMP 内 key DAT 表中的关键帧信息，忽略 attributes DAT 表中的任何自定义设置。
  • Samples samples -
  • Frames frames -
  • Seconds seconds -
  • Fraction fraction -
  • X Units xunits -
Cyclic Range cyclic - - 为循环或非循环的输入索引调整动画的范围。使用循环输入索引时，索引 0.0 和 1.0 的查找值会得到相同结果。为避免这一点，将 Cyclic Range 设为 Yes，查找就会平滑循环。
  • Automatic auto - 检查每个通道的右侧 extend 条件（假定 type 为 cycle 和 mirror 的是循环查找）。
  • Yes yes - 当索引超出动画范围时循环输出。
  • No no - 当索引超出动画范围时不循环输出。
Specify Edit Attributes specifyedit - 开启后可启用下面的 edit attributes 参数。
Edit Origin editorigin - 更改动画通道编辑的原点。这不会改变 key DAT 表中存储的数据，但会影响通道在图表中的显示和动画的播放。
Edit Rate editrate - 更改动画通道编辑的速率。这不会改变 key DAT 表中存储的数据，但会影响通道在图表中的显示和动画的播放。
Edit Animation... editanimation - 点击此按钮将在 Animation Editor 中打开此 Animation COMP。

参数 - Range 页

Type rangetype - - 设置 Animation COMP 的工作范围。
  • Timeline timeline - 使用上一个 Animation 参数页上 Time Reference 参数所指定时间轴中设置的范围。
  • Custom custom - 使用下方的 Start 和 End 参数设置自定义范围。
Start start - Custom 范围的起点，以秒、帧或采样为单位。
Start Unit startunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
End end - Custom 范围的终点，以秒、帧或采样为单位。
End Unit endunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
Trim Left tleft - - 确定通道在超过 'End' 位置后的输出。不影响 Play Mode = Output Full Range，要控制该模式的 Extend Conditions，请调整 Animation COMP 内 Keyframe CHOP 的 Extend 参数。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道起点之前的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Trim Right tright - - 确定通道在位于 'Start' 位置之前时的输出。不影响 Play Mode = Output Full Range，要控制该模式的 Extend Conditions，请调整 Animation COMP 内 Keyframe CHOP 的 Extend 参数。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道终点之后的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常量值。
Trim Default tdefault - 用于上述 Default Value trim 条件的值。

参数 - Extensions 页

Extensions 参数页设置组件的 Python 扩展。更多信息请参阅 extensions。

Re-Init Extensions reinitextensions - 重新编译所有扩展对象。通常只有在扩展对象被引用且其定义已更改时，扩展对象才会被编译。
Init Extensions On Start initextonstart - 在 TouchDesigner 启动时自动执行 Re-Init
Extension ext - 用于在此组件上创建扩展的信息序列
Object ext0object - 可附加到组件的类实例数量。
Name ext0name - 可选，用于搜索的名称，代替实例类名。
Promote ext0promote - 控制扩展是直接在组件层级可见，还是必须通过 .ext 成员访问。示例：n.Somefunction 与 n.ext.Somefunction

参数 - Common 页

Common 参数页设置组件的 node viewer 和 clone 关系。

Parent Shortcut parentshortcut - 指定一个名称，可在组件内任意位置用作该组件的路径。参见 Parent Shortcut。
Global OP Shortcut opshortcut - 指定一个名称，可在任何位置用作该组件的路径。参见 Global OP Shortcut。
Internal OP iop - 内部操作符的序列标题。
Shortcut iop0shortcut - 指定一个名称，可在组件内任意位置用作下方「Internal OP」的路径。参见 Internal Operators。
OP iop0op - 此组件内 Internal OP 的路径。参见 Internal Operators。
Operator Viewer opviewer - 当上方的 Node View 参数设为 Operator Viewer 时，选择使用哪个操作符的节点查看器。
Enable Cloning enablecloning - 控制该 OP 是否应持续克隆。关闭此项会使此节点停止克隆其「Clone Master」。
Enable Cloning Pulse enablecloningpulse - 立即克隆内容。
Clone Master clone - 用作 Master Clone 的组件路径。
Load on Demand loadondemand - 仅在需要时将组件加载到内存。适用于项目中并非总是使用的组件。
Enable External .tox enableexternaltox - 开启时（默认），.toe 启动时会加载外部 .tox 文件，COMP 的内容将与该外部 .tox 一致。如有需要，可以关闭此项，以避免启动时从引用的外部 .tox 加载（COMP 的内容改为从 .toe 文件加载）。如果你希望某个 COMP 引用外部 .tox，但不总是从它加载，除非你特意按下 Re-Init Network 参数按钮，这会很有用。
Enable External .tox Pulse enableexternaltoxpulse - 此按钮会从外部 .tox 文件重新加载（若存在）。
External .tox Path externaltox - 磁盘上 .tox 文件的路径，该文件会在 .toe 启动时作为组件内容的来源。这让组件可以包含能独立更新的网络。若找不到 .tox 文件，则会加载 .toe 文件保存时的内容。
Reload Custom Parameters reloadcustom - 启用此复选框后，重新加载 .tox 时会重新加载组件 Custom Parameters 的值。这仅影响组件上的顶层参数；组件内节点上的所有参数始终随 .tox 重新加载。
Reload Built-In Parameters reloadbuiltin - 启用此复选框后，重新加载 .tox 时会重新加载组件内置参数的值。这仅影响组件上的顶层参数；组件内节点上的所有参数始终随 .tox 重新加载。
Save Backup of External savebackup - 启用此复选框后，由 External .tox 参数指定的组件的备份副本会保存在 .toe 文件中。若找不到 External .tox，将使用此备份副本。出现这种情况可能是因为 .tox 被重命名、删除，或 .toe 文件在另一台缺少组件媒体的电脑上运行。
Sub-Component to Load subcompname - 从外部 .tox 文件加载时，此选项允许你深入 .tox 取出一个 COMP，并将其作为顶层 COMP，忽略文件中的其他所有内容（该 COMP 的内容除外）。例如，若名为 project1.tox 的 .tox 文件包含 project1/geo1，将 geo1 设为 Sub-Component to Load，就会加载 geo1 来替代当前 COMP。若此参数为空，则按常规使用文件中的顶层 COMP 加载 .tox 文件。
Relative File Path Behavior relpath - - 设置此 COMP 内的子文件路径是相对于 .toe 本身还是 .tox，或从父级继承。
  • Use Parent's Behavior inherit - 从父级继承设置。
  • Relative to Project File (.toe) project - 当指定为相对路径时，该路径将相对于 .toe 文件。
  • Relative to External COMP File (.tox) externaltox - 当指定为相对路径时，该路径将相对于 .tox 文件。未指定外部 COMP 文件，或 Enable External .tox 未开启时，此项没有影响。

操作符输入

Info CHOP 通道

Animation COMP 的额外信息可通过 Info CHOP 查看。

COMP 通用信息通道

  • num_children - 此组件中的子级数量。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
