Extrude SOP

摘要

Extrude SOP 可用于：

  • 对 Text 及其他几何进行挤出和倒角
  • 对倒角边缘做 cusp 处理以获得锐利边缘
  • 让图元变厚或变薄

默认是从输入几何的法线方向直接向后挤出 1 个单位。

它使用表面的法线来确定挤出方向。对于平面或开放多边形，法线难以确定，结果不一定总符合预期。在 Viewer 显示选项中打开 Primitive Normals 显示即可查看法线。

挤出是通过把表面从输入几何的顶点沿第二个输入（Input 1）中给定的截面曲线延伸而生成的。截面曲线的第一个顶点默认放在输入几何的顶点上，并对齐使曲线的正 Y 轴与输入几何的法线方向相反。截面的正 X 轴默认从输入几何的中心向外延伸。

若未给出截面曲线，则使用从 (0,0,0) 到 (0,1,0) 的垂直线。这会产生从输入几何法线方向直接向后 1 个单位的挤出。再举一例，使用从 (0,0,0) 到 (.1,.1,0) 的直线，会得到这样的挤出：从输入向后延伸 1 个单位，并在各个方向向外张开 .1 个单位。Thickness 和 Depth 参数可用于平移和缩放截面，而不必直接修改曲线。

注意： 截面的形状始终相对于其第一个顶点，因此整体平移截面曲线不会有效果。另外，只使用曲线的 X 和 Y 轴，即 Z 位置值被忽略。

新几何创建后，默认会计算法线。

警告： 如果取 Text SOP 的默认输出去挤出，可能会出现明显的渲染瑕疵（以及过多多边形），因为它是在挤出三角化字母的每个三角形。需要把 Text SOP 的 Output 参数改为 Closed Polygons。参见 OP Snippets。

extrudeSOP_Class

参数 - 页

Source Group sourcegrp - 若存在输入组，在此字段中指定组名会使该 SOP 只对被指定为源（source）的组生效。接受模式匹配，说明见 Pattern Matching。
X-Section Group xsectiongrp - 若存在输入组，在此字段中指定组名会使该 SOP 只对为截面（cross-section）指定的组生效。接受模式匹配，说明见 Pattern Matching。

参数 - Values 页

Fuse Points dofuse - - 使用截面时几乎总应打开。它会合并那些在倒角时否则会交叉或重叠的多边形的点。
  • No fusion off -
  • Clamp all points all -
  • Clamp minimal set min -
  • Clamp individual face on -
  • Clamp straight straight -
Front Face fronttype - - 控制挤出的正面如何构建。你可能希望设为「No Output」，因为在动画中有些面从不会被看到，若保留只会增加额外开销。
  • No Output off - 不创建任何面。
  • Output Face face - 创建面。
  • Convex Face convex - 用 Convex Polygons 创建面（若面将被变形，例如 Twist SOP、Lattice SOP，请用此选项）。
Back Face backtype - - 该值控制挤出对象的背面是否生成面。选项与上面的 Front Face 相同。
  • No Output off -
  • Output Face face -
  • Convex Face convex -
Side Mesh sidetype - - 控制截面的挤出方式。若输入的截面是 Bzier 或 NURBS 曲线，表面将用相同几何类型的面片构建。
  • No Output off - 不创建任何网格。
  • Rows rows - 创建水平线。
  • Columns cols - 创建垂直线。
  • Rows and Columns rowcol - 行列都有。在线框显示下看起来像 Quads，但所有多边形都是开放的（若图元类型为 polygon）。可在 Model Editor 中对比。
  • Triangles triangles - 用三角形构建网格。
  • Quadrilaterals quads - 生成由四边形构成的侧面（默认）。
  • Alternating triangles alttriangles - 生成相对的三角形；类似 Triangles 选项。
Initialize Extrusion initextrude - 如果你创建的截面面片与所挤出几何的尺寸不匹配，该命令会缩放并平移它，使其恰好贴合。

一开始不贴合的原因可能是曲线没有在 Model 模式下精确画在世界轴线上，和/或所画尺度与它要挤出的对象差别过大。

Thickness Translate thickxlate - 沿垂直于输入几何法线的方向平移截面轮廓。这与截面轮廓的 X 轴相关。用于文字时，通常会使文字变细（窄）或变粗（粗体）。
Thickness Scale thickscale - 沿垂直于输入几何法线的方向缩放截面轮廓。等同于在截面自身的 X 轴上缩放。该参数对默认轮廓无效，默认轮廓相当于沿 Y 轴的垂直线。允许负的缩放值。
Depth Translate depthxlate - 沿法线方向移动截面。正值会向法线方向的反方向移动。Depth 的移动与输入截面的 Y 轴相关。使用该参数会沿法线方向改变输出几何的位置。
Depth Scale depthscale - 沿源几何法线方向缩放截面。等同于在输入截面的 Y 轴上缩放，决定挤出的深度（厚度）。
Vertex vertex - 平移截面，使指定的顶点位于截面原点。
Cusp Polygonal Sides docusp - 决定侧面是平滑着色还是按分面处理，使用 Side Cusp Angle 字段中的角度值。

Cusp 处理让你指定相邻多边形之间的夹角达到多少度时，改用锐边（顶点不共享的分面边缘）显示。

Side Cusp Angle cuspangle - 勾选后，该值控制侧面开始分面的角度。默认值为 20。
Consolidate Faces to Mesh sharefaces - 选中后，挤出会在正面与侧面网格的第一行之间、以及最后一个面与侧面网格的最后一行之间共享点。
Remove Shared Sides removesharedsides - 防止生成重复的侧面。

参数 - Groups 页

Create Output Groups newg - 勾选后，Extrude SOP 会生成三个新组，分别代表属于正面、背面以及侧面倒角/挤出的图元。组的名称由下面三个选项字段决定。
Front Group frontgrp - 为正面几何创建的输出组名称。
Back Group backgrp - 为背面几何创建的输出组名称。
Side Group sidegrp - 为侧面倒角/挤出几何创建的输出组名称。

制作技巧

该 SOP 主要用于生成文字的倒角和挤出，其输入截面来自 Font SOP。任何曲线或曲线组也可以作为输入。

偏移 - 该 SOP 可用于生成两条偏移曲线，且两条曲线之间的距离保持恒定。做法是把 Side Mesh 设为 No Output，把第一个 thickness 设为零，再调整第二个以增大或减小偏移距离。

修正散乱的法线 - 如果几何中的法线指向四面八方（比如从 File In SOP 读取几何之后，或存在大量开放或非平面多边形），可以修正它们使其适合挤出。

做法是：在包含几何的 SOP 后接一个 Group SOP，启用 Normal，并把 Spread Angle 减小到小于 180。然后接一个 Primitive SOP，它应作用于 Group SOP 中创建的组。在 Face/Hull 页把 Vertex 菜单设为 Reverse。

现在几何中的法线大致都朝向同一方向，可以挤出了。要收紧容差，进一步减小 Spread Angle。

Info CHOP 通道

Extrude SOP 的附加信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
