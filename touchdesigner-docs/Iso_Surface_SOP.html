Iso Surface SOP

摘要

Iso Surface SOP 使用隐函数创建 3D 可视化，展示 12 年级 Functions and Relations 教科书中的等值面。

隐函数的定义使其 = 0。例如对于： 

x2 + y2 = r2

其隐函数是： 

f(x, y) = x2 + y2 - r2 = 0

isosurfaceSOP_Class

参数 - 页

Implicit Function func - 在此输入用于构建隐式曲面的函数。

示例 1：(me.curPos.x**2) / (4*4) - (me.curPos.y**2) / (3*3) + me.curPos.z

这个公式会创建一个双曲抛物面，也就是马鞍形。

示例 2：(me.curPos.x**2) / 0.1 + (me.curPos.y**2) / 2 + (me.curPos.z**2) / 6 - 1

这个公式会创建一个椭球。

示例

Iso Surface SOP 的作用在概念上很简单——它接受用户指定的 R3 表达式（数学术语，意思是「具有三个维度，每个维度取一个实数」），并在函数由正变负的位置生成曲面。对于默认表达式（me.curPos[0] * me.curPos[0] + me.curPos[1] * me.curPos[1] + me.curPos[2] * me.curPos[2] - 1），表达式在单位球内小于零，在球外大于零。SOP 计算时会在指定的边界体（默认 X、Y、Z 方向均为 -1 到 +1）中逐步扫描，并在表达式等于零的位置生成几何。

这看起来可能是一种定义球体的笨办法，但借助丰富的数学函数（见 Expressions 部分），在这样简单的例子之外还有很大潜力。一个简单的示例是 noise() 函数。试着输入以下表达式。

Info CHOP 通道

Iso Surface SOP 的附加信息可以通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
