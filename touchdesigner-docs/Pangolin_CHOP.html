Pangolin CHOP

摘要

注意

OS: 此操作符仅在 Microsoft Windows 操作系统下受支持。

Pangolin CHOP 与 Pangolin 的 Beyond 对接。Beyond 是一款专业的激光与多媒体演出控制应用。Beyond 运行时，Pangolin CHOP 会向其发送激光图像帧。图像帧由 POP、CHOP 或 SOP 生成。有关在 TouchDesigner 中使用激光的概述，请参阅 Lasers。

Pangolin CHOP 应可用于任何版本的 Beyond，但建议至少使用 Beyond v5.1。

TouchDesigner Non-Commercial licenses will only work with the demo version of Beyond. A TouchDesigner Commercial, Educational, or Pro license is required to interface with licensed versions of Beyond.

Using a SOP Input：输入点会按图元分组，并会使用来自顶点、点或图元的点位置及颜色属性来构建要发送给 Beyond 的点。

Using a CHOP input：输入通道按名称确定：x、y、z、r、g、b、id、zone。只有 x 和 y 通道是必需的。每个采样都会被解释为要绘制的一个点。可以使用 id 通道把点分组为不同形状。若不使用，则所有点都被视为同一形状的一部分。zone 通道可用于为每个采样覆盖 zone 参数值，从而可以更精细地控制哪个采样/点发往 Beyond 中的哪个 zone。

Using a POP input：类似 SOP，输入点会按图元分组。点位置属性（P）是必需的，点颜色属性（Color）可选。若未指定 Color，则点颜色会设为白色。此外，还可使用图元的 Zone 属性来控制哪个图元发往 Beyond 中的哪个 zone。

另请参阅：Laser CHOP、Lasers。

用法

使用 Pangolin CHOP 时必须打开 Beyond。

Pangolin CHOP 会根据 SOP 的点或 CHOP 的采样构建激光图像，并发送给 Beyond。在 Beyond 打开且 Pangolin CHOP 激活（有输入）时，激光图像可立即在 Beyond 的 zone 查看器中对应的 zone 中看到。下面是使用 Pangolin CHOP 把一个圆发送到 Beyond 的 zone 1 的示例。


参数 - Pangolin 页

Active active - 禁用时，CHOP 不再向 Beyond 发送，Beyond 中对应的图像也会被清除。
Source source - 选择源操作符。
  • SOP sop - 使用 SOP 作为源。除位置属性外，还会使用 SOP 的点颜色属性来确定输出颜色。
  • CHOP chop - 使用 CHOP 作为源。输入通道按名称确定：x、y、z、r、g、b、id。只有 x 和 y 通道是必需的。每个采样都会被解释为要绘制的一个点。可使用 id 通道把点分组为单个形状。
SOP sop - SOP 的路径。
CHOP chop - CHOP 的路径。输入 CHOP 必须有 x、y 通道来提供点位置。此外还支持 z、r、g、b 和 id 通道。id 通道用于把点分组为单个形状。默认情况下，若没有 id 通道，每个点都是独立且不相连的。
POP pop - POP 的路径。
Zone zone - 要发送到的 Beyond 中 zone 的索引。
Rate Mode ratemode - 选择计算 Beyond 中图像速率的模式。注意：这不是 CHOP 的速率。
  • Percent of Projector Sample Rate percent - 速率按默认投影仪采样率的百分比计算。用 Percent 参数指定百分比。
  • Sample Rate sample - 指定采样率。
Percent percent - 以投影仪默认采样率的百分比指定采样率。
Sample Rate rate - 指定 Beyond 中图像的采样率
Vertex Repeat repeat - 图像中每个点的重复频率（不包括消隐点）。
Vector Frame vector - 启用时，图像会作为矢量帧发送给 Beyond。矢量帧会在 Beyond 中进行额外计算，例如添加消隐点。禁用时，图像会作为点发送给 DAC，不添加任何额外内容。
Resend Image resend - 重新把图像发送给 Beyond。
Enable Laser Output enableout - 在 Beyond 中启用激光输出。效果等同于点击 Beyond 中的「Enable Laser Output」按钮。
Disable Laser Output disableout - 在 Beyond 中禁用激光输出。效果等同于点击 Beyond 中的「Disable Laser Output」按钮。
Blackout blackout - 向 Beyond 发送黑场命令。效果等同于点击 Beyond 中的「Blackout」按钮。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
