纹理坐标与纹理采样

纹理化是指把图像（TOP）应用到几何（SOP）上的操作。具体做法是，把 MAT 应用到 SOP 所在的 Geometry COMP 上，并在 MAT 中某个接受 TOP 的参数上指定该 TOP。

将纹理坐标应用到 SOP

要确定如何把 TOP 贴到 SOP 的表面上，需要使用 SOP 的纹理坐标。SOP 的纹理坐标是名为 uv 的属性。UV 由 Texture SOP 以及 Tube、Grid、Torus、Sphere 等基本体 SOP 按点或按顶点赋予。

对纹理采样

几何被渲染时，这些 uv 值会在图元表面插值，使每个像素都有不同的 uv 值来对该 TOP 采样。采样功能会依据 uv 从 TOP 中返回单一颜色。

uv 坐标插值的可视化示意。红色是 U 坐标，绿色是 V 坐标。

用给定 uv 对 TOP 采样时，GPU 必须决定返回 TOP 中的哪个像素（这些像素称为 texel）。在 TOP 中，U == 0.0 指 TOP 中最左侧 texel 的左边缘，U = 1.0 指最右侧 texel 的右边缘。类似地，V == 0.0 是 TOP 中最底部 texel 的底边。

Texel 插值

设想一个分辨率为 2x1 像素的 TOP，U = 0.5 指两个 texel 之间的边缘，而 U = 0.33 指最左侧 texel 的中心。V = 0.5 是 texel 的中心（因为它只有 1 个 texel 高）。那么此情况下如果用 uv = (0.40, 0.5) 采样该 TOP 会怎样？这个 uv 位于左侧像素偏右的部分，它返回什么颜色？GPU 如何决定取决于选择了哪种 Texture Filtering 模式。如果选择 Nearest 纹理过滤，则返回左侧的 texel，因为它是距离该 uv 最近的像素。如果选择 Linear，则返回左右两个像素的混合。混合为 70% 的左侧像素和 30% 的右侧像素，因为 0.4 距离左侧像素中心有 30% 的路程。实际中混合是在离采样点最近的 4 个 texel 之间进行的（对于 3D Texture 则是 8 个），U 和 V 都用于决定在哪 4 个 texel 之间混合。
