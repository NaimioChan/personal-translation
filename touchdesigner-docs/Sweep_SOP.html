Sweep SOP

摘要

Sweep SOP 沿 Backbone Source 图元扫掠 Cross-section 输入中的图元，生成带状和管状形状。横截面图元被放置于脊线的每个点上，并与之垂直。Backbone Source 可以有一个或多个图元；若有多个，Sweep 会沿每一个分别扫掠横截面。

脊线是一条图元曲线，可以是开放的或闭合的，但必须至少有两个点。横截面输入也可以有多个图元，并可以用多种方式分配到脊线上。默认情况下横截面图元的原点被放在脊线上的某一点，但你也可以选择横截面的某个点号来放置。多数情况下最好在 XY 平面构建横截面图元；Sweep 会自动让它们沿脊线正确定向。横截面的朝向基于脊线线段的方向和正 Z 轴。因此脊线的垂直运动会导致横截面绕脊线轴旋转。例如，如果你在 XY 平面创建横截面，可以通过在 XZ 平面构建脊线来保持其朝向（+Y 向上）。

如果脊线图元带有点颜色或纹理坐标，它们会被保留并应用到横截面图元上。

参数 - Sweep 页

X-Section Group xgrp - 在此处指定组，可以只使用 Cross-section 输入中图元的一个子集。
Path Group pathgrp - 在此处指定组，可以只使用 Backbone 输入中图元的一个子集。
Reference Group refgrp - 在此处指定组，可以只使用 Reference 输入中图元的一个子集。
Cycle Type cycle - 根据这些菜单选项决定 Cycle Type。
  • All Primitives at Each Point all - 把 Cross-section 输入中的所有图元放在 Backbone 的每个点上。
  • One Primitive at a Time each - 与上面类似，但变换应用于各个图元而非整体。
  • Cycle Primitives cycle - 在把输入图元放到脊线上时循环使用它们。即从顶点 0 处的图元 0 开始，顶点 1 处用图元 1，依此类推。
Angle Fix angle - 尝试修复扫掠时可能出现的屈曲扭曲。
Fix Flipping noflip - 通过修正翻转的法线，尝试修复扫掠时可能出现的屈曲扭曲。
Remove Coincident Points on Path skipcoin - 选中时，完全重合的点会被忽略。
Aim at Reference Points aimatref - Reference Points 与脊线配合用来控制扫掠过程中各元素的朝向。方法是在参考点与对应脊线点之间画一条线，得出一个角度向量，用以确定横截面 profile 的朝向。启用此参数以允许这种行为。

注意： 为此，你必须通过第三输入提供 Reference Points，且 Reference Points 的数量必须与 Backbone 中的点数完全相同。

Use Vertex usevtx - 使用输入横截面的顶点编号把横截面放到脊线上。
Connection Vertex vertex - 指定要连接到脊线的特定顶点。
Scale scale - 整体缩放横截面。
Twist twist - 横截面绕脊线的累积旋转。如果指定值为五，脊线第一个点处的横截面旋转五度，下一个十度，再下一个十五度，依此类推。
Roll roll - 横截面绕脊线的非累积旋转。所有横截面获得相同的旋转。

注意： Scale、Twist 和 Roll 参数现在可以直接由同名点属性控制。因此结合 Channel SOP，这些参数可以动态控制。你可以用传入的 scale 及其他属性来做锥化。

参数 - Output 页

Create Groups newg - 选择此选项会启用组的创建。每个传入的脊线都会创建一个组。这便于在 Skin SOP 中做蒙皮。
Sweep Groups sweepgrp - 在此栏指定输出组的名称。
Skin Output skin - 根据这些菜单选项决定输出。
  • Off off - 不对输出做蒙皮。
  • On on - 对输出做蒙皮。
  • On with Auto Close auto - 如果所沿的路径曲线也是闭合的，则闭合蒙皮网格。这让你能正确闭合图元。

提示： 有一种利用 Point SOP 的第二输入来加速大量点蒙皮的方法。假设你有成千上万条程序化动画的曲线想用 Sweep SOP 蒙皮——与其在动画之后再做蒙皮，不如另做一套已预蒙皮的非动画几何。然后假定点数匹配，你只需把动画点替换进已蒙皮的几何中。

这种技术比使用 Sweep SOP 的 Skin Output 选项，或在 Sweep SOP 之后接 Skin SOP 要快得多。

Fast Sweep fast - 启用一种优化的蒙皮技术，在许多情况下能把输出速度提高 2 到 4 倍，代价是精度。为了让它正确工作，输入的拓扑在多次计算之间必须保持一致，且每个横截面的顶点数必须相同。

Info CHOP 通道

Sweep SOP 的额外信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
