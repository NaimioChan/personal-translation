NumPy

NumPy 是 Python 编程语言的库，为大型多维数组和矩阵增加了支持，并提供了大量用于操作这些数组的高级数学函数。[1]

广泛使用的计算机视觉库 OpenCV 的 Python 绑定使用 NumPy 数组来存储和操作数据。由于多通道图像就是三维数组，因此索引、切片或用其他数组做遮罩，都是访问图像特定像素的非常高效的方式。NumPy 数组作为 OpenCV 中图像、提取的特征点、滤波核等的通用数据结构，大大简化了编程流程与调试。[2]

关于 NumPy 的一份不错的通用入门资料见：https://numpy.org/doc/stable/user/absolute_beginners.html

NumPy 与 TouchDesigner

TouchDesigner 允许使用 TOP、CHOP、Channel 和 Matrix 类中的方法，轻松在 TOP 和 CHOP 数据与 NumPy 数组之间转换。

NumPy 与 CHOP

例如，可以把包含所有通道和采样的 CHOP 转换为 NumPy 数组：

# 以 2D NumPy 数组返回此 CHOP 中的所有通道
# 其宽度等于通道长度（采样数）
# 高度等于通道数。
# 数据将以 32 位浮点存储。
npArray = op('someChop').numpyArray()

同样，单个 CHOP 通道也可以转换为 NumPy 数组：

# 将此通道的数据以 NumPy 数组返回
# 长度等于轨道长度。
# 数据将以 32 位浮点存储。
npArray = op('someChop')['chan1'].numpyArray()

使用 Script CHOP 时，存储在 NumPy 数组中的数据可以转换回 CHOP 通道。此时数组的形状必须为 shape(numChannels, numSamples)，且数据类型为 float32。[3]

这里的简单示例在 Script CHOP 中创建 3 个通道，每个通道 20 个采样，并把第二个通道第 11 个采样的值设为 1，其他所有值均为 0：

# 导入 NumPy 库
import numpy as np

def onCook(scriptOp):
	scriptOp.clear()

	# 指定通道数和采样数
	numChannels = 3
	numSamples = 20

	# 创建一个填充为零的 NumPy 数组
	# 数据类型必须为 float32 才能用于 CHOP
	npArray = np.zeros((numChannels, numSamples), dtype=np.float32)

	# 把第 2 个通道的第 11 个采样设为 1.234
	npArray[1][10] = 1.234

	# 把 NumPy 数组复制到 CHOP 通道中
	scriptOp.copyNumpyArray(npArray)
	return

举一个更实用的例子：假设有一个 2 通道、10 采样的 CHOP，描述 2D 空间中某些对象的 xy 位置，我们需要计算它们两两之间的欧氏距离。结果将是 10 个通道，每个通道 10 个采样。这里可以利用 NumPy 的 broadcasting 功能来简化必要的代码。

# 导入 NumPy 库
import numpy as np

def onCook(scriptOp):
	scriptOp.clear()
	inputs = scriptOp.inputs[0]
	
	# 以 NumPy 数组获取输入 CHOP
	inPos = inputs.numpyArray()
	
	# 这会得到一个 numChannels x numSamples 的数组
	# 我们需要把该数组转置为 numSamples x numChannels 的数组
	# 以便把各点位置作为成对的值获取
	# 这相当于 Shuffle CHOP 的 "Swap Channels and Samples"
	inPos = inPos.T
	
	# 使用广播机制，我们可以去掉 for 循环
	# 并计算所有点之间的距离
	# https://numpy.org/doc/stable/user/basics.broadcasting.html
	npDist = np.sqrt(((inPos[:,:,None] - inPos[:,:,None].T) ** 2).sum(1))

	# 把 NumPy 数组复制到 CHOP 中
	scriptOp.copyNumpyArray(npDist)
	return

NumPy 与 TOP

TOP 也有类似的功能。

TOP 可以简单地读取为 NumPy 数组：

# 以 Python NumPy 数组返回 TOP 图像。
# 由于 NumPy 数组以行为先索引，像素按 [h, w] 寻址。
# 目前数据始终为 32 位浮点格式。
npArray = op('someTop').numpyArray()

与 TOPTo CHOP 类似，.numpyArray() 方法有一个参数，可在下一次调用时下载数据，从而避免阻塞 GPU。

# 延迟地以 Python NumPy 数组返回 TOP 图像。
# 由于 NumPy 数组以行为先索引，像素按 [h, w] 寻址。
# 目前数据始终为 32 位浮点格式。
npArray = op('someTop').numpyArray(delayed=True)

使用 Script TOPs 时，用 .copyNumpyArray() 方法把 NumPy 数组写回为纹理。

# 把 script TOP 的输入纹理下载到 NumPy 数组中
npArray = scriptOp.inputs[0].numpyArray()

# 把 NumPy 数组复制到纹理中
scriptOp.copyNumpyArray(npArray)

在像素格式之间转换时要小心。从输入读取纹理总是会得到 32 位浮点。如果要输出为 8 位定点，需要先把数值乘以 255，再把数组数据类型改为 unit8

# 导入 NumPy 库
import numpy as np
def onCook(scriptOp):
	# 把输入 top 复制到 NumPy 数组中
	npArray = scriptOp.inputs[0].numpyArray()

	# 8bit 的取值范围是 0 到 255，因此把数组乘以 255
	npArray *= 255

	# 把数据类型改为 uint8
	npArray = npArray.astype(np.uint8)

	# 把 NumPy 数组复制到 TOP 纹理中
	scriptOp.copyNumpyArray(npArray)
	return

NumPy 与 Matrix 类

Matrix Class 还允许把 TouchDesigner 矩阵复制到 NumPy 数组中，从而可以使用 NumPy 中各种 TouchDesigner 本身没有的矩阵运算。

import numpy as np
# 创建单位矩阵
m = tdu.Matrix()

# 把矩阵转换为 NumPy 数组
npArray = m.numpyArray()

# 仅输出矩阵的对角线值
# 将输出 NumPy 数组：array([1., 1., 1., 1.], dtype=float32)
debug(npArray.diagonal())

将 NumPy 数组转换为 bytearray

把 NumPy 数组转换为 Python bytearray 可能很有用。NumPy 通过 .tobytes() 方法支持这一点。[4]

# 把 CHOP 通道加载到 NumPy 数组中
npArray = op('someCHOP')['chan1'].numpyArray()
# 把 NumPy 数组转换为 bytearray
b = npArray.tobytes()
