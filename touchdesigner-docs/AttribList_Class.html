AttribList 类

AttribList 类保存来自 POP 的属性值列表。属性值是 floats 或 ints 的 floats、ints 或 tuples。

成员

name → str (Read Only):

此列表所含属性的名称。

owner → OP (Read Only):

此属性来源的节点。

方法

没有该操作符专属的方法。

特殊函数

len(AttribList)→ int:

返回值的总数。 

a = len(op('box1').points("P", delayed=False))

[index]→ int | float | tuple:

根据整数索引获取特定的属性值。 

n = op('box1').points("P")[0]

Iterator→ int | float | tuple:

遍历每个属性值。 

for p in op('box1').points("P"):
	# 对 p（一个元组）做些什么
