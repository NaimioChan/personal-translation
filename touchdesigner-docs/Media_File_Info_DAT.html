Media File Info DAT

摘要

Media File Info DAT 封装了媒体文件的基本元数据，输出编解码器、帧率、音频采样率、分辨率等元数据信息。

可以通过指定 File 路径，或引用 Movie File In TOP 或 Audio File In CHOP，把媒体文件输入到该 DAT。

mediafileinfoDAT_Class

参数 - Media Info 页

File file - 要加载的图像或影片文件的路径与名称。图像和影片格式即 File Types 中列出的那些。可以用 http:// 指定互联网上的文件……
TOP/CHOP topchop - 引用一个 Movie File In TOP 或 Audio File In CHOP，从中读取文件信息。
Reload Pulse reloadpulse - 从 0 变为 1 时强制重新加载文件，适用于文件发生变化或最初不存在的情况。
File Open Timeout opentimeout - TouchDesigner 等待文件打开的时间（毫秒）。达到 Disk Open Timout 后，Media File Info 会停止等待并且不输出任何内容。如果下次该 DAT 计算时文件仍未打开，它会再次等待，并重复同样的过程，直到文件打开或打开失败。
Transpose transpose - 输出将从每项一行改为每项一列。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

Media File Info DAT 的额外信息可以通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
