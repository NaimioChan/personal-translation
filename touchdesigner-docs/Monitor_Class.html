Monitor 类

Monitor 类描述单个显示器实例。可以从 monitors 对象访问它们。

成员

index → int (Read Only):

该显示器在列表中的位置。

isPrimary → bool (Read Only):

如果此显示器是主显示器，则返回 true。

isAffinity → bool (Read Only):

如果此显示器连接到已选为 GPU Affinity 的 GPU，则返回 true。未使用 GPU Affinity 时始终为 True。

connectedGPUName → str (Read Only):

与此显示器 GPU 关联的名称。

connectedGPUIndex → int (Read Only):

此显示器 GPU 的索引。

width → int (Read Only):

显示器区域的宽度，以像素计。

height → int (Read Only):

显示器区域的高度，以像素计。

left → int (Read Only):

显示器区域左边缘的位置，以像素计。

right → int (Read Only):

显示器区域右边缘的位置，以像素计。

top → int (Read Only):

显示器区域上边缘的位置，以像素计。

bottom → int (Read Only):

显示器区域下边缘的位置，以像素计。

displayName → str (Read Only):

与此显示器关联的唯一显示名称。

description → str (Read Only):

显示器或其显示适配器的描述。

dpiScale → float (Read Only):

显示器当前设置的 DPI 缩放系数。

scaledWidth → int (Read Only):

显示器区域的宽度，以点计。

scaledHeight → int (Read Only):

显示器区域的高度，以点计。

scaledLeft → int (Read Only):

显示器区域左边缘的位置，以点计。

scaledRight → int (Read Only):

显示器区域右边缘的位置，以点计。

scaledTop → int (Read Only):

显示器区域上边缘的位置，以点计。

scaledBottom → int (Read Only):

显示器区域下边缘的位置，以点计。

serialNumber → str (Read Only):

与此显示器关联的序列号名称。可能为空。

refreshRate → float (Read Only):

显示器当前的刷新率。

方法

没有该操作符专属的方法。

访问显示器

有关如何访问单个显示器的示例，请参见 Monitors Class。
