TouchDesigner 必知基础

这些是帮助你熟练使用 TouchDesigner 界面的基础知识。如果边暂停边按顺序做下去，大约需要 2-3 小时。我们会涉及 TouchDesigner 的所有主要部分和概念，以及操作 UI 的全部基础。之后希望你更熟练、也更自在地自行探索 TouchDesigner。

提示：若 TouchDesigner 中某个术语的含义不清楚，可以在左侧菜单的 TouchDesigner Glossary 或 Search 中查找。

1. 启动 TouchDesigner

使用 TouchDesigner 需要一个带滚轮的三键鼠标。（若没有鼠标或中键，可以用 alt+右键点击代替中键点击。）

先双击桌面上的 TouchDesigner 图标。

启动 TouchDesigner 后，右侧是 network 编辑器，左侧是 Palette 浏览器。点击调色板右上角的 x 将其关闭，以腾出更多空间，需要时再打开。

2. 平移、缩放并使网络居中

要平移网络，在网络空白处按住鼠标左键（LMB）拖动。

要缩放网络，按住鼠标中键（MMB）左右拖动。（提醒：若没有中键，按 alt+右键点击。）

或者，前后滚动滚轮也可以缩放。

按 "h" 键使其居中（这也称为 homing）。若只想让高亮的节点居中，按 Shift-h。

在网络空白处右键点击（RMB）并松开鼠标——你会看到网络菜单。选择 'Home All'。

3. 当前节点与选中节点

点击其中一个节点。它会显示绿色边框，并成为「当前」节点。一个网络中只有一个当前节点。

左键点击另一个节点并将其拖到新位置。注意当前节点不变。

要框选多个节点，在空白处按住鼠标右键，拖过这些节点后松开。

节点周围的黄色边框表示它们被「选中」。绿色节点也被选中。

左键点击任一选中节点并拖动——所有选中节点会一起移动。

要向选中集合中加入更多节点，按住 Shift 点击或按住 Shift 框选其他节点。要取消选中某个节点，按住 Shift 点击它。

你可以对选中的节点一起操作。右键点击网络背景并选择 Delete 删除节点，然后按 Ctrl+z 撤销（macOS 上为 Command+z）。也可以通过 Edit 菜单撤销。

现在点击任一选中节点左上角（Flag）。这会在它们的 Node Viewers 与三字母图标之间切换。重新打开节点查看器。

要取消全部选中，左键点击网络背景，除绿色「当前」节点外所有节点都会取消选中。

右键点击其中一个节点——你会看到节点菜单。选择 'View' 弹出浮动窗口。点击并拖动边缘可调整大小。现在点击角落即可关闭查看器窗口。

4. TouchDesigner 操作符生成和过滤数据

要删除所有节点，按 Control-a 全选，然后按 Delete。

现在双击空的网络。出现 OP Create Dialog，其中 OP 表示「operator」，即「节点」。应选中紫色的「TOP」标签页。TOPs 是 Texture Operator，用于处理图像。点击 Movie File In，然后在网络任意处点击以放置它。

你也可以按 Tab 调出 OP Create。要取消，点击背景。

在 moviefilein1 右侧，右键点击其紫色输出连接器。在 OP Create 中点击 'Level'，然后在 moviefilein1 右侧点击以创建 level1，它会连接到 moviefilein1。你刚刚添加了一个图像「filter」（level1），它修改图像「generator」（moviefilein1）的色阶。

TouchDesigner 操作符分为 Generator 和 Filter。「Filter」需要至少一个输入，并修改传入操作符的数据。

「Generator」不需要输入——它们创建新数据，或从外部设备和程序读取数据。颜色较深的 OP 是生成器。颜色较浅的 OP 是滤镜。

点击 level1。在右上角的对话框中，移动标有 Black Level 和 Brightness 的滑块。这些是 TouchDesigner 中典型的「parameters」，我们很快会讲到。

5. 在 Network Editor 中，从每个族添加一个操作符

我们来看看其余六个操作符族。再次双击背景。

OP Create Dialog 有六个标题，即我们所说的 Operator Families。点击 'CHOP' 对应「Channel Operators」。多次按 Tab 可循环回到 CHOP。

点击 CHOP 类型「Pattern」，把 Pattern CHOP 放在网络中 TOP 上方的一行。Channel Operator 用于运动、控制信号、音频等。

再次调出 OP Create。你可以通过输入名称找到特定操作符。输入「noi」，点击 Noise，在再次点击之前，可以用滚轮缩放网络找个空位，然后点击创建 Noise CHOP。

调出 OP Create 并点击「SOP」。Surface Operator（SOPs）处理多边形、3D 线条和其他曲面。选择一个 Sphere SOP 并将节点放入网络。

按 Tab 键并选择「MAT」。Material Operator（MATs）为 3D 对象添加纹理和着色。选择一个 Phong MAT 并放置节点。

按 Tab 键并选择「DAT」。Data Operator（DATs）操作文本字符串，包括自由文本和表格中的文本。选择一个 Monitors DAT，它是一个表格，为连接到计算机的每台显示器列出一行。

按 Tab 键并选择「COMP」以添加组件。组件有四类。从左侧的 3D Objects 栏中选择一个 Geometry COMP，它将 SOP 和材质结合起来用于 3D 渲染。

再次按 Tab 键。从 Panels 栏中选择一个 Slider COMP，它是用于构建控制面板的 2D 小工具之一。

现在你的网络中已有所有操作符族的示例。

6. 用连线连接节点

（框选除两个 TOP 以外的所有内容，将它们上移让出位置。）

节点的输入位于其左侧，输出位于其右侧。可以认为数据总体从左向右流动。

现在按 Tab，输入 'mon' 创建一个名为 Monochrome 的 TOP，并将其放在 level1 右侧。

用以下四种方式之一将 level1 的输出连接到 mono1 的输入：第一种，点击 level1 的输出，不松开拖到 mono1 的输入再松开。

同一族节点之间的连接线称为 Wires。

按 Ctrl-z 撤销连线。现在点击 level1 的输出并松开，然后点击 mono1 的输入并松开。或者也可以反向连接，从 mono1 的输入连到 level1 的输出。

点击并向右拖动 Monochrome TOP，在两者之间留出空间。

要在两个已连接的节点之间插入新节点，右键点击 level1 节点的输出，选择一个 Tile TOP 并放入网络。

按 Ctrl-z 撤销。现在右键点击连线，从菜单中选择 Insert Operator。选择并放置一个 Tile TOP。

要从某个节点创建新分支，中键点击 tile1 的输出，从 Operator 菜单中选择 Edge 并放在 mono1 上方的网络中。

要移除连线，点击 edge1 的输入，然后点击网络中的空白处。

现在将 edge1 重新连接到 tile1。

另一种断开方式是在连线上右键点击，从菜单中选择 Disconnect。再次重新连接 edge1。

从另一个节点的输出拖到已有连线上的任意位置，即可替换某个节点的输入。

7. 连线、数据流与计算

可以把数据想象成沿着这些连线流动，在这里就是图像。现在观察连线在动。点击 level1，到右侧的 Parameter Dialog，操作 Brightness 滑块。连线在动意味着数据在流动：上游节点正在 cooking，把输出交给下一个节点计算，如此向下游传递。

中键点击 tile1。这会显示该 TOP 的信息。查看 Total Cooks 了解它计算了多少次，然后中键点击 moviefilein1，会看到它只需计算一次，因为它没有变化。

我们来看看上下连接器。回到 geo1 的 Geometry 组件。

在 geo1 组件上方放一个 Null 组件。像 Geometry、Camera 和 Light 这样的 3D 组件底部和顶部有连接器（把它们连起来），这使它们在 3D 层级中成为父子关系，但数据不沿这些连接器流动。

在 geo1 组件上方放一个 Container 组件。同样，像 Slider、Button 和 Container 这样的 2D 组件底部和顶部也有连接器（把它们连起来），这是将它们归组到面板中的一种方式。同样，数据不沿它们流动，数据只通过两侧的连线流动。

8. 激活查看器以检查操作符数据

（我们更仔细看看 geo1 组件）到目前为止，左键点击节点会移动它或使其成为当前节点。你无法改变查看器。中键点击显示通用信息框，右键点击显示所有节点共享的通用节点菜单。

（提醒：若没有中键，按 Alt+右键点击。）

点击 geo1 右下角的「Viewer Active」标记会移除其边框，让你更仔细地检查该操作符数据的内容。按住任意鼠标键拖动可在几何中移动，快速右键点击会弹出该操作符专用的查看选项菜单，线框切换就在那里。

对于面板，若点击 Viewer Active，就能操作该面板。

还有两种方式可以激活查看器：

  • 第一，按住 Alt+a 会让所有节点进入 Viewer Active 状态，松开即恢复。
  • 第二，光标位于背景上时，shortcut 键「a」会切换所有选中节点的 Viewer Active 标记。

即使节点的 Viewer Active 标记已打开，你仍可访问通用弹出菜单。在底部的名称栏上，中键点击可获得节点信息，右键点击可获得节点的通用菜单。

你可以随时从底部名称栏点击拖动该操作符。若只是单击名称栏，它会成为当前节点，但同时进入编辑名称的模式，直到你点击别处，所以你可能更愿意直接框选它。

（继续之前先整理一下：使网络居中，选中 Viewer Active 已打开的节点并将它们关闭。）

9. 调整操作符的参数

TouchDesigner 中每个操作符都有一组影响其输出的 Parameters。选中并查看 pattern1。Parameter Dialog 通常停靠在网络右上角。按小写 p 键可隐藏它以获得更多空间，再次按 p 可将其调回。

要在浮动窗口中查看 pattern1 的参数，右键点击 pattern1 并选择 Parameters...。

你可以同时改变多个 OP 的参数。点击 pattern1，按两次 Ctrl+c 和 Ctrl+v 创建 pattern2 和 pattern3（macOS 上为 Command+c 和 Command+v）。点击 pattern2 并将其 Type 菜单改为 Ramp。现在框选 pattern1 到 pattern3。增大 Number of Cycles 参数。松开后你会看到三个 OP 的 Cycles 参数都被设为相同的值。

要只重置一个参数，右键点击 pattern2 的 Type 参数标签，弹出参数菜单，选择 Reset Parameter。

要将操作符的所有参数重置为默认值，右键点击节点并选择 Reset all Parameters。或者在参数对话框的「i」图标上右键点击，也能调出相同的节点菜单。

10. 数值梯级帮助你改变参数值

现在用数值梯级调整参数。选择 noise1 CHOP。

在 Parameter Dialog 中，将光标放在 Period 参数的名称或数值上，按住中键。Value Ladder 会弹出，带有 .001 .01 .1 1 10 若干增量。保持中键按下，垂直移动到某个增量，比如 .01，然后向右/左移动以增大/减小参数值。用另一个增量再试一次。

点击参数对话框的 Transform 页。若参数有两个或更多数值（如 Translate 参数），当你中键点击该数字（点击第二个值）并调出梯级时，只会改变那一个值。但若你点击参数名称并操作梯级，则会修改该参数的所有值。

提示：你也可以用鼠标左键操作数值梯级，但必须稍等片刻它才会出现，所以中键点击参数名称或数值更快。

11. 操作符标记与表格模式

Operator Flags 环绕每个节点。左侧的标记对大多数操作符族通用，底部的标记则更针对某一族。

我们看看 tile1。我们已经见过左上角的 Viewer 标记和右下角的 Viewer Active。

左侧第三个标记是 Bypass，它会关闭该操作符；若有任何输入连接，它会将第一个输入直接传递到输出。

第四个标记是 Lock 标记，它冻结内存中的数据，阻止新数据流过。修改 level1 的参数，会看到它不影响 tile1 及之后。Lock 标记适合测试，但要少用，因为它会使工程文件变大。中键点击 Tile TOP 查看它占用的 GPU 内存。

我们切换到「Table Mode」。按 Shift-T。它每行显示一个节点。这在大型网络中按字母查找节点、以及查看标记设置时很有用。

右键点击第二列可调出参数。在第一列点击、Ctrl 点击或 Shift 点击可改变当前节点和选中节点。现在点击 moviefilein1。

现在再按 Shift-T 回到网络视图，看到 moviefilein1 是当前节点。现在解锁 tile1。

12. 保存你的工作

经常保存工作状态。在 File 菜单下选择 Create Project Folder。确认 Path 为桌面。将 Project Folder 改为 Learning，然后按 Create。

资源管理器或访达会显示它在桌面创建了一个名为 Learning 的文件夹，内含一批存放媒体的文件夹，以及两个相同的 TouchDesigner Environment 文件，名为 Learning.1.toe 和 Learning.toe。

下次想保存时，只需选择 File -> 'Save'，它会递增文件名。回到资源管理器或访达会看到，它在你的工程中创建了一个 Backup 文件夹，将 Learning.1.toe 移入其中，并新建了一个 Learning.toe，它是 Learning.2.toe 的副本。

要再次保存，也可以使用 Ctrl+s（macOS 上为 Command+s），可在窗口顶部确认。

退出 TouchDesigner 后，下次重新启动时，可以进入 Learning 文件夹并双击 Learning.toe，它始终是最新的文件。

或者你可以右键拖动 Learning.toe 到桌面，创建一个快捷方式，随时从这里启动。

我们把工程里的所有内容删掉。按 Ctrl-a 全选，然后按 Delete 键。

13. 将媒体导入 TouchDesigner

你可以将常见文件类型导入 TouchDesigner，包括影片、图像、音频、FBX、点云、JSON 文件等。它也能导入 TouchDesigner .tox 组件文件。参见 wiki 页面 File Types。

在顶部菜单栏的 Dialogs 下，Windows 选择 Explorer，macOS 选择 Finder。

打开你的任一媒体文件夹，从文件浏览器将一些媒体文件拖放到 Network Editor 中。（若计算机上什么都没有，可以导航到 C:\Program Files\Derivative\TouchDesigner.2022.29040\Samples\Map 之类的地方。）

你也可以从桌面取文件并拖放进来。

另一种导入文件的方式是用 OP Create 菜单创建合适的操作符，如 Movie File In TOP、Audio File In CHOP、Point File In TOP 或 FBX Component。然后将其 File 参数设为所需的媒体文件。

或者，在桌面或 Windows/macOS 的文件夹中，右键点击这些文件之一，选择 Open with...，然后选择 TouchDesigner。这会启动一个新的 TouchDesigner 会话（新进程），并将该文件作为节点载入。

最后，在 TouchDesigner 内，可以通过 (1) File -> Open 菜单或 (2) Open Recent 菜单启动工程。这会先终止当前进程，然后启动一个新进程。

注意，包含你整个工程的 .toe「TouchDesigner Environment」文件不是被导入的，而是通过 (1) 双击文件，或 (2) 右键 -> Open With... 重新启动。

14. 进入包含网络的组件

组件的独特之处在于每个组件都包含一个 Network，而每个网络都位于某个组件中。

调出 OP Create（Tab）并创建一个 Button 组件 button1。注意所有 Components 都有灰色边框。

要进入 button1，选中它并按 Enter 或「i」键。窗格顶部的路径 /project1/button1 会告诉你所处的位置。

要退出组件，按「u」向上返回。

只要组件的 Viewer Active 关闭（且不是私有的），你也可以双击组件进入。

更巧妙的方式是用鼠标滚轮放大到靠近组件，当滚轮放大到非常接近 button1 时，就会进入其内部。反方向滚动则退出。

15. 参数类型

操作符根据其输入和参数（通常还有当前时间）计算并生成输出。所以我们来看看参数的特性。

创建一个 Circle TOP 并把它换成另一种颜色，然后创建一个 Trigger CHOP，在它们下方放一个 Text Component。

以下是 7 种最常见的参数类型：

  1. 整数（text1 - Layout 页 - Width 参数）
  2. 浮点数（带小数位的数字）（Font 页 - Font Size 参数）
  3. 开关「toggles」（Italic 参数）
  4. 菜单（Font 菜单）
  5. 文本字符串（Text 页 - Text 参数）
  6. 指向另一个节点的路径参数（text1 的 Look 页 - 将 circle1 TOP 拖到 Background TOP 参数上）
  7. 告诉操作符只执行一次的脉冲（Trigger CHOP - 点击 Trigger CHOP 的脉冲参数）

每组参数可以有一个、两个、三个或四个值。例如，当参数表示颜色时，它有 3 或 4 个值：红、绿、蓝，有时还有 alpha。（text1 Look 页 - Background Color）

16. 四种「参数模式」

每个参数都可以处于四种「参数模式」之一，这决定它如何取值。点击任意参数（如 Horiz Stretch）将其展开，看看它处于哪种模式。四个方框代表四种参数模式。

  • 这处于第一种参数模式「Constant」，也是最简单的——在参数对话框中，你只需点击滑块、输入数字、从菜单手动选择——它就设定了其「常量」值。（数值为白色时）
  • 第二种参数模式是「Export Mode」，参数由来自 CHOP 的数值驱动。（以绿色表示）
  • 第三种参数模式是「Expression Mode」，可以在其中放置 Python 表达式（以青色表示）。
  • 第四种参数模式是「Binding Mode」（紫色），两个或多个参数被绑定在一起。（右键点击 circle1 并选择 Parameters）Text COMP 的 Tracking 参数为紫色，表示它绑定到了另一个参数，可以看到是 circle1 的 Border Width，它改变 Text COMP 的 Tracking 参数，而且是双向的。

我们更仔细看看导出。为此需要更多了解 CHOP、通道和采样。

17. CHOP 输出由采样构成的通道

CHOP 输出数值。Channel Operator 创建一组 1 个或多个通道，每个通道是一组数值（Sample）。我们创建一个 Constant CHOP 并移动其滑块。它有 1 个通道和 1 个采样，中键点击节点（或点击参数对话框顶部的「i」）查看 1i 即可看到，其中 i 表示采样或索引。

点击 chan1 下的 + 创建新参数，这会生成第二个通道。在「info popup」中确认。

现在创建一个 Noise CHOP。这是一个带多个采样的 Channel。要证明这点，把视图稍微放大到节点，打开 Viewer Active，右键点击图表并选择 Dot per Sample。然后中键点击并向右拖动鼠标，即可看到每个采样一个点。（注意，节点上的鼠标点击行为取决于查看器是否激活。）

在 Noise CHOP 的图表上按 'h' 使通道居中。在参数对话框中，点击 Channel 页并将 Channel Names 参数改为 chan[1-3]。现在有 3 个通道，每个 600 个采样。要验证，中键点击节点底部名称 noise1 所在的条带，查看弹出信息中的 600i，意思是 600 个采样或索引。

要把 CHOP 显示为数字，调出 OP Create，点击 DAT，创建一个「CHOP to」DAT。然后打开名为「Include Names」的参数。现在将 Noise CHOP 拖到 CHOP to DAT 节点以及名为「CHOP」的参数上，把两者连接起来。查看查看器中的表格，每个单元格是一个采样。现在试试 Constant CHOP，你可以把 Constant 拖到 CHOP to 上。

总的来说，CHOP 用于在 TouchDesigner 中表示曲线、运动、音频信号或控制信号。（参见：Channel、CHOP）。

18. 将 CHOP 通道导出到参数

Export 将一个值从 CHOP 通道发送到操作符的参数。

创建一个 LFO CHOP，将其放慢，并连接到一个新的 Math CHOP。打开 Math CHOP 右下角的 Viewer Active 标记。创建一个 Movie File In TOP，然后添加一个新的 Transform TOP。

点击 Transform TOP 以便导出到其参数。左键按住 Math CHOP 查看器中的通道，将其拖到 Parameter Dialog 的一个参数上：即 Transform TOP 的 Translate 参数第一个数字（X 值）上，然后松开鼠标。在弹出的菜单中选择 'Export CHOP' 完成导出。注意参数变为绿色，表示它处于 Export 模式。

再次选中 Math CHOP（框选它或点击底部名称栏），然后选择 Mult-Add 页并调整 Multiply 参数来改变运动范围。

你可以关闭导出：在 Math CHOP 上关闭 Viewer Active，并点击 CHOP 底部的绿点：Transform TOP 的 Translate 回到常量模式。现在再次打开导出。（更多技巧见 Export）。

19. 在参数中放置 Python 表达式

我们来看看参数中的 Python 表达式。表达式用于参数和脚本。

创建一个新的 Pattern CHOP，命名为 sine1。在 Length 参数中输入表达式 200*3。数值现在显示为 600 = 表达式已求值为 600，并且变蓝，表示它当前处于 Expression Mode。要显示更多，将光标放在参数名「Length」上，会出现一个 +，点击该区域的任意处。会出现新的一行，显示参数的 Python 名称（'length'）、四个参数模式的方框以及可选的 Python 表达式。

点击蓝色方框左侧的灰色方框。这会使其回到 Constant Mode，数值为其默认值 1000。这在确定之前尝试不同数值时很有用。再次点击 Expression Mode 方框。

在 sine1 上，在名为 Number of Cycles 的参数中输入表达式 me.digits+2。它求值为 3，即操作符名称中的数字加 2。只选中文本 me.digits，将光标放在表达式上。会弹出 1，即你所选那部分表达式的值。

要放大参数对话框以获得更多空间：将光标放在参数对话框左边缘，出现左右箭头光标时，点击并向左拖动。

若光标位于参数中时按 Ctrl-e，会在文本编辑器中打开当前参数的表达式，便于查看和编辑长表达式。或者右键点击参数并选择 Edit Expression。

查看此表了解 TouchDesigner 中最常用的 Python 表达式：Python Tips。许多示例在 Help -> Python Examples 中。另请参阅 Parameter。

20. 参数模式：Binding

参数「Binding」指让 2 个或更多参数取相同的值。要设置它，创建两个 Pattern CHOP，然后右键点击 pattern1 并选择 Parameters...，在浮动窗口中调出其参数，然后选中 pattern2 查看其参数。接着将 pattern1 上的 Number of Cycles 参数点击拖动到 pattern2 上的同一参数并选择 Bind。改变任一参数的值，你会看到另一个也随之改变。

注意，实际共享的值在 pattern1 上——展开两个 OP 上的该参数（按两个 OP 参数上的 +），会看到 pattern2 的 Bind 表达式为紫色，内容为 op('pattern1').par.numcycles，因此它继承 pattern1 上的值。所以 pattern1 的参数称为「master」，pattern2 的参数称为「reference」。你可以让多个参数绑定到 master。

21. 组件包含带输入和输出的操作符网络

「Components」是内部存放操作符网络的操作符族。我们创建一个带连线输入和输出的组件。按 Tab，选择 COMP，选择 Container 并放入网络。进入 Container（滚轮向前，或按 Enter）。在窗格顶部确认你的路径位置——应类似 /project1/container1。

按 Tab，选择 TOP，选择 Ramp 并放置。右键点击 ramp 节点的输出并选择一个 Out TOP。按 Tab，选择 CHOP，选择 In CHOP。回到组件外部（按 u 或滚轮向后），右键点击该组件的输入创建一个 LFO CHOP。这会把新的 LFO CHOP 连接到组件的输入。将其 Type 参数设为 Ramp。

再次进入组件，将 In CHOP 的通道 Export 到 Ramp TOP 的 Phase 参数。你应该看到斜坡在移动。回到组件外部。在容器的 Panel 页，在 Background TOP 参数中填入 ./out1。你应该在查看器中看到上升的斜坡。右键点击容器的输出并添加一个 Null TOP。你现在创建了一个带 CHOP 输入和 TOP 输出的自定义组件。

22. 容器承载用户界面

回到 container1 内部。将 Ramp TOP 的 Type 改为 Circular。接着创建一个 Slider COMP。在滑块的输出上添加一个 Null CHOP，并将其通道导出到 Ramp TOP 的 Period 参数。回到上一层，打开 container1 的 Viewer Active 标记并操作滑块来改变环的宽度。这就是在 TouchDesigner 中创建用户界面的基础。

23. 组件可以有自定义参数

在 container1 上关闭 Viewer Active。右键点击 container1 并从节点菜单中选择 Customize Component...。在 Par Name 字段中输入 Position。点击 Add Par。你应该在参数对话框中看到一个新的 Custom 标签页，其中有一个名为 Position 的新参数。然后在 Customize Component 中，将 Range Min 设为 -1，Range Max 保持为 1。

进入 container1，在 Ramp TOP 上点击 Position 参数名称，调出该参数的额外设置行，在 position1 行输入 parent().par.Position。这现在应能取到我们刚创建的自定义参数。回到上一层，操作 Position 自定义参数。你应该看到圆形斜坡左右移动。这就是在 TouchDesigner 中创建自定义参数的基础。

24. 路径是节点的地址

路径就像节点或操作符的地址——它描述节点在 TouchDesigner 工程中的位置。你当前所在网络的路径显示在窗格左上角的路径导航器中。你大部分时间都在 /project1 中工作。

许多操作符有一个指向其他操作符的路径参数。创建一个 Select CHOP，并在 Operator 参数中输入 /project1/pattern1。你应该能看到 pattern1 的通道。

节点都位于组件套组件的树状层级中，从 root 开始，其名为 /。点击「home」图标进入 root。点击 '/' 并选择 project1 回到你的工作网络。

看看 Select CHOP：路径开头的 / 表示它是「绝对路径」。/project1/pattern1 是绝对路径，即在 root（/）中有一个组件 project1，而在 /project1 中有一个节点 pattern1。

路径还有其他形式：

创建一个 Select TOP，在其 TOP 参数中输入 transform1。transform1 是相对路径：当你看到不带前缀的操作符名称时，它就在当前网络中。

创建一个 Info CHOP，在其 Operator 参数中输入 container1/out1。这也是相对路径——container1 是当前网络中的一个组件，out1 是 container1 中的一个节点。

你的 container1 组件用 ./out1 作为背景图像。./ 表示「在此组件内部」，所以该路径的意思是「在此组件内部有一个名为 out1 的节点」。

进入 container1，创建一个 Select DAT，在其第一个参数中输入 ../pattern1。../ 表示父网络，所以该路径的意思是：在当前组件的父级中有一个名为 pattern1 的节点。

在 Python 表达式中你常会看到 parent()，它也指父节点。要定位到层级更上方，../../ 是父级的父级。你还会看到用 Python 函数 parent() 在父节点中定位操作符的其他方式。

25. 拆分窗格并填入其他窗格类型

有时你想同时身处两个地方。TouchDesigner 窗口可以拆分为 2 个或更多 Panes。通过窗格右上角的下拉菜单拆分窗格，选择 Split Left-Right。

窗格会通过其左上角菜单填入所选的窗格类型。Network Editor 窗格类型是你目前一直在用的。「Panel」窗格类型让你与面板组件交互。Geometry Viewer 窗格类型让你与 3D 场景和对象交互。在节点上右键 -> Viewer 可在浮动窗口中获得类似视图。

用窗格之间的分隔条调整窗格大小，然后通过窗格右上角的下拉菜单关闭该窗格。你也可以点击窗格顶部的 Layout 或 Bookmark 图标来选择多窗格布局。更多内容参见 Pane。

26. 用 Render TOP 渲染 3D 场景

现在我们用 Render TOP 在 3D 中渲染一些东西。在 /project1 中创建一个 Container 组件，把它重命名为 scene 并进入其中。创建一个 Render TOP。接着创建三个组件：一个 Geometry、一个 Light 和一个 Camera。虚线表示 Render TOP 的参数已经指向这些组件。在 Render TOP 的 Camera 参数中，你会看到 cam1，意思是「从节点 cam1 获取摄像机」。在 Geometry 参数中，geo* 里的 * 意思是「获取此网络中名称以 geo 开头的所有 Geometry 组件」。

进入 geo1 Geometry 节点的参数，把圆环在 Z 方向上旋转（Rotate 的第三个字段）设为 30 度。Render TOP 会随之变化。现在点击 geo1 的 Viewer Active 标记，点击/移动圆环让它翻滚。注意渲染结果保持不变。Geometry 组件查看器中的翻滚仅用于检查。在 geo1 查看器中按 h 回到初始位置（重置翻滚）。

现在回到 /project1。把 absTime.seconds * 20 填入 Rotate 参数的第一个字段（X）。absTime.seconds 是 Python 中表示「以秒为单位的绝对时间」的写法，它是一个每秒增加 1、一直增长到退出 TouchDesigner 为止的数值。影响参数就会影响渲染。这就是你的基本渲染设置。（absTime.frame 每帧增加 1，所以速度取决于时间轴的每秒帧数）

27. 时间轴让你播放、暂停和检查

Timeline 位于 TouchDesigner 主窗口的底部。左下角的 FPS 是 TouchDesigner 每秒将前进的帧数。注意 UI 顶部的 FPS 是 TouchDesigner 在上一秒实际绘制的帧数，它会等于或小于前者。

时间轴让你可以在 TouchDesigner 中暂停（||）、播放（▶）和单步（+）时间轴。

空格键始终会停止和启动时间轴。每次步进到另一帧时，它都会重绘屏幕。

顶部的电源按钮（0|1）会关闭 TouchDesigner 进程中所有计算、时钟和通信，适合在冻结状态下检查内容。

你会看到时间轴到达最右端后会循环回到时间轴开头。但 TouchDesigner 主要依靠自由运行的时钟、由事件驱动，所以你构建的大部分内容并不跟随循环的时间轴及其帧号：例如，创建一个 Constant CHOP，把它设为 1 并连接到 Speed CHOP。它会持续增加计数，与时间轴无关。按下 Speed CHOP 的 Reset 参数时，它会重新开始。

创建一个 Movie File In TOP，在 File 参数上选择 + 并选择 Count.mov。Movie File In TOP 会按其默认的 Sequential Play Mode 持续播放，与时间轴位置无关，把 Speed 参数调低就能看出来。

不过，如果把它的 Play Mode 菜单参数设为「Locked to Timeline」，影片的帧号与时间轴就会保持同步，影片的第一帧始终出现在第 1 帧，并且你可以拖动时间轴。

但最常见的情况是用 CHOP 通道来播放影片。创建一个 Constant CHOP，把 Movie File In 的 Play Mode 菜单改为 Specify Index，并把 Constant CHOP 的通道导出到 Index 参数。然后用 Constant CHOP 值参数上的数值阶梯升高和降低影片帧号。

28. 用 Animation Editor 创建动画曲线

创建一个 Animation Component。默认情况下它输出一个没有通道的 CHOP。现在右键点击该节点并选择 Edit Animation...（或在其参数对话框中按 Edit Animation...）。

点击 Add Channels 按钮，会创建 3 个通道：tx、ty 和 tz。关键帧是通道上的圆点。点击任意关键帧并把它移到任意位置。要给任意通道添加更多关键帧，用 alt+鼠标左键点击你想要关键帧的位置。用鼠标右键框选。框选曲线（不是关键帧圆点），把 Function 菜单从 cubic() 改为 linear() 以更改插值类型。

然后观察底部的 Timeline 以及 Animation 组件查看器中通道的值。注意通道值跟随时间轴。

如果你想更精确地控制时机，可以把一个动画通道连接到 Animation 组件的输入：创建一个 Beat CHOP 并连线到 Animation COMP 的输入。把 Animation COMP 的 Play Mode 设为「Use Input Index」，把 Input Index Unit 参数菜单设为「Fraction」。

然后创建一个 Constant CHOP，把它连线到 Animation COMP 的第一个输入，并移动 Constant 的 chan1 滑块。两种情况下，0-1 的值都会控制输出动画曲线的哪一部分，从而让 Animation COMP 与时间轴解耦。你随时可以把 Play Mode 改为 Output Full Range 来输出完整长度的通道。

另一种创建预连线动画组件的方法：右键点击某个参数并选择 Keyframe Parameter in...

29. DAT 操作符处理文本

DATs 是「数据操作符」，让你在 TouchDesigner 网络中存储和处理文本。Text DAT 用于编写脚本、着色器和任意自由文本。

创建一个 Web DAT，假设你已联网，按下 Fetch 参数。这会从网站获取 HTML。

现在创建一个 Monitors DAT，它是一张由行和列单元格组成的表格，每个单元格包含文本。附着在 Monitors DAT 上的另一个 DAT 包含一些 Python 代码，在你监控的配置发生变化时运行。你会看到两者之间有一条虚线，表示它「停靠」在 Monitors DAT 上。

这算是 DAT 的一点初步体验。

30. Sweet Sixteen 操作符

TouchDesigner 中操作符类型很多，但每个操作符族中最常用、最有用的是 Sweet Sixteen。你或许可以试试其中一些。包括：

  • Sweet Sixteen CHOPs
  • Sweet Sixteen TOPs
  • Sweet Sixteen SOPs
  • Sweet Sixteen DATs

这些都在 wiki 中，可以从 UI 里的 WIKI 按钮进入。

31. 探索 Operator Snippets

进一步了解操作符的一种方法是看小示例。选择菜单 Help → Operator Snippets。这会启动另一个 TouchDesigner 窗口，里面有数百个使用各操作符族操作符的示例。这是提示的丰富资源。

32. 从 Palette 获取组件

Palette Browser 中的组件包含预先做好的网络，有些还带有自定义控制面板。你也可以把自己创建的组件存入 Palette 以便随时取用，并在项目的其他地方复用。

要显示预做 Components 的浏览器，切换 Palette 图标的关闭/开启。或者点击 Dialogs → Palette Browser。点击一个组件并把它拖到网络中。磁盘上的组件是 .tox 文件。

观看视频 A Movie Player Panel and Building UIs，这是关于面板构建基础的教程。

33. 从社区帖子获取组件

前往 www.derivative.ca，TOUCHDESIGNER 标签页，COMMUNITY POSTS 标签页，并按 Assets 筛选：[=24 Community Assets]。

34. Perform Mode 以独立且优化的方式运行你的应用

按 F1 功能键。在浮动窗口中查看 /project1 的容器面板。TouchDesigner 处于 Perform Mode 中，它运行时没有网络编辑器。然后按 Esc 回到 Designer Mode。

TouchPlayer 只会在 Perform Mode 下运行你的应用。

35. 用 Performance Monitor 提速

Dialogs → Performance Monitor 可以让你在一帧中看到哪些节点计算、按什么顺序计算、各花了多长时间。注意，Performance Monitor 只显示 CPU 上的计算，不显示 GPU。但底部一条很长的长条通常意味着 GPU 还在忙着完成一帧的渲染和 UI 显示。

中键点击任意节点，可以看该节点是否每帧都在计算，以及最近一次计算花了多长时间。

还有 Perform CHOP，你可以创建 Info CHOP 并把任意节点拖到它上面，查看更多关于发生了什么的细节。

另一个叫「probe」的工具可以让你查看 GPU 和 CPU 的计算以及内存占用。从 Palette → Tools → probe 获取 probe，并查看它的 wiki 页面：Palette:probe。

36. 快速提示与良好习惯

  • 点击参数对话框中的 bulls-eye 圆圈，可以看到哪些参数不是默认值。这对理解别人的网络非常有用。
  • 要快速获得参数的帮助，按住 Alt 并把光标移到参数上。你会得到该参数在 wiki 中的帮助信息。
  • Color Code Nodes - 光标位于网络上时按「c」调出色板。选择一些节点。点击色板中的任意颜色。这只影响节点在网络中的外观。
  • Network Overview - 光标位于网络上时按「o」，在网络左下角调出微型节点地图。你可以点击它来平移网络。
  • 要以另一种方式查看节点，光标位于网络上时按「Shift-T」，它会切换到 "table" mode，在那里你可以看到所有节点的列表。你可以通过左栏选中一个，然后再次按「Shift-T」回到网络，看到该节点在网络中被高亮显示。
  • Ctrl+f（macOS 上为 Command+f）会调出 Find bar，让你输入要找的节点名称。与你输入匹配的名称会被高亮并居中显示。用 Edit -> Search/Replace 可以生成整个项目中符合搜索条件的操作符列表，并可选择修改它们。
  • 当你 don't have a mouse 时，用快捷键 Ctrl+=、Ctrl+-、Ctrl+up、Ctrl+down、Ctrl+left、Ctrl+right（macOS 上全部加 Command+）缩放和滚动网络编辑器。
  • 在 OP Create 中，你可以用 Shift-点击选择一串节点，从而更快地 create nodes-in-a-row。在 OP Create 菜单上用 Ctrl-点击，可以在新的独立行中创建节点。
  • 要一次把多个操作符连接到一个 multi-input OP（如 Composite TOP 或 Switch CHOP），框选这些输入，然后把其中一个的输出连接到多输入操作符的输入连接器上。它们都会被连上。
  • 节点名称 case-sensitive，所以 level2 与 Level2 是不同的。
  • 「Absolute Time」的概念是一个永远向上计数、不像时间轴那样循环到 0 的时钟。用 Python 时它能给出平滑、不断变化的值：absTime.seconds、absTime.frame。试试在 Transform TOP 的 Rotate 参数中输入 absTime.seconds。
  • 在引用或导出时使用 Null operators——这样你就能在 Null 之前插入额外的操作符来修改网络，而无需改动引用或导出的位置
  • 在节点上使用 Info DAT or Info CHOP 可以查看它的一些内部状态，也许有助于排查问题。
  • 你可以在 SOP 或 Geometry 查看器的右键菜单中（Viewer Active 模式下）开启/关闭 Adaptive Homing in SOP viewers 和 Geometry 查看器。在 Preferences → Geometry 中打开这些选项然后点 Accept，就能确保你始终在视图内看到 3D 几何。
  • 通过点击新来源的输出，再点击你要替换的连线，来 replace an existing wire。
  • 在网络上用 Alt-右键拖动来设置注释框以添加 comments and annotations，或使用「a」、「b」或「c」快捷键。Comments 是更简洁的注释。
  • 首选脚本语言是 Python，不过在较早的作品中你可能会看到 Tscript，以及参数对话框中本该显示 Python 图标的位置显示 T。
  • Status Bar 位于 TouchDesigner 主窗口的右上角，提供最近操作的信息。它可能会显示消息来表示事件成功/失败，或显示提示来告诉你如何使用某个工具。要时常留意它。（python code ui.status = 'My message' 可用于在状态栏中放置一行文字。）
