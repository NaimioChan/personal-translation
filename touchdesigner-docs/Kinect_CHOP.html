Kinect CHOP

摘要

注意

OS: 此操作符仅在 Microsoft Windows 操作系统下受支持。
Hardware: 此 CHOP 仅支持 Kinect for Windows 硬件以及 Kinect 2、not Kinect for Xbox 硬件。

Kinect CHOP 从 Kinect 与 Kinect2 传感器读取位置与骨骼跟踪数据。最多可跟踪 6 个人的完整骨骼（初代 Kinect 为 2 人），此外还会跟踪摄像头视野中另外 4 个人的中心位置。使用多个 Kinect CHOP 并更改 Camera 参数即可使用多台 Kinect 设备。

它还支持面部跟踪。

要使用 Kinect 2 设备，需要从 here 安装 Kinect 2 SDK 或运行时。

要使用初代 Kinect 1，需要安装 Kinect Runtime 1.8（用于 12000 以上的版本），或 Kinect Runtime 1.7（用于 12000 以下的版本）。 多个 Kinect：Kinect 2 SDK 不允许在同一系统上同时使用多个 Kinect。无法通过 SDK 连接不同设备。Kinect 1 可以做到，Kinect 2 不行。

另请参阅 Kinect TOP、Kinect 和 Kinect1。

参数 - Kinect 页

Active active - 为 On 时，从 Kinect 传感器采集数据。
Hardware Version hwversion - 在 Kinect v1 或 Kinect v2 传感器之间选择。
  • Version 1 version1 -
  • Version 2 version2 -
Sensor sensor - 选择使用哪台 Kinect 传感器。仅在使用 Kinect v1 时可用。
Skeleton skeleton - 选择骨骼跟踪的选项。
  • Full full - 跟踪完整骨骼。
  • Seated seated - 跟踪坐姿骨骼。
  • Off off - 不跟踪骨骼。
Max Players maxplayers - 限制跟踪的玩家数量。
Interactions interactions - 启用交互，返回「grip」和「press」等交互数据。额外输出的通道以 p[1-2]/hand_l_* 和 p[1-2]/hand_r_* 为前缀。
  • 交互手的 x 和 y 值中，0.0 对应交互区域的左边缘，1.0 对应交互区域的右边缘，但值可能超出此范围。
  • 交互手的 z 值中，0.0 表示手靠近肩膀，1.0 表示手臂完全伸展，但值可能超出此范围。

注意： 交互模式要求深度分辨率为 640x480。因此，为同一传感器显示深度图像的 Kinect TOP 将输出 640x480 分辨率的图像，并且 Kinect CHOP 中会设置 Near Depth Mode 设置。

有关使用 Kinect Interaction 创建应用的指南，请下载 Kinect for Windows Human Interface Guidelines。

Relative Bone Rotations relbonerotations - 为每根骨骼返回 rx、ry、rz 相对旋转通道。旋转相对于上一个关节。
Absolute Bone Rotations absbonerotations - 为每根骨骼返回 rx、ry、rz 绝对旋转通道。
Bone Lengths bonelengths - 返回每根骨骼的长度。
Unroll Bone Values unrollbones - 以不含不连续（或环绕）的形式返回 rx、ry、rz 值，以便安全地进行混合、滤波、滞后等处理。例如，从 0 到 360 连续变化的旋转值，展开后会从 0 开始并无限增大。
World Space Positions worldspace - 返回世界空间坐标中的跟踪位置。对于每个跟踪点，将输出 tx、ty、tz 三个通道。
Color Space Positions colorspace - 返回相对于彩色摄像头的图像空间坐标中的跟踪位置。对于每个跟踪点，将输出 u、v、tz 三个通道。注意这仅在 Kinectv2 上可用。
Depth Space Positions depthspace - 返回相对于深度摄像头的图像空间坐标中的跟踪位置。对于每个跟踪点，将输出 depthu、depthv、tz 三个通道。在 Kinectv1 和 Kinectv2 上均可使用。
Face Tracking facetracking - 返回检测到的面部的面部跟踪通道。
Status Channels statuschans - 开启后将报告若干额外的状态通道。一组通道报告某个关节当前是否正在被跟踪，另一组通道报告玩家的一部分是否被裁剪到 Kinect 传感器的边界之外。额外输出的通道以 tracked 或 clipped 为后缀。
Near Depth Mode neardepthmode - 为骨骼跟踪启用 near 模式，使深度摄像头能看到距摄像头近至 40cm 的物体（而非默认的 80cm）。
Flip Skeleton U Direction flipskelu - 翻转骨骼通道的 u 轴，在使用摄像头镜像图像时很有用。
Flip Face U Direction flipfaceu - 翻转面部通道的 u 轴，在使用摄像头镜像图像时很有用。

参数 - Smoothing 页

Joint Smoothing jointsmoothing - 激活 Kinect 用于关节跟踪的平滑算法，并启用下方的平滑参数。
Smoothing smoothing - 增大平滑参数值会返回更加平滑的骨骼位置值。平滑的特性是：平滑值越大，对原始数据的响应越弱。因此，平滑度提高会导致返回的骨骼值延迟增加。值必须在 0 到 1.0 范围内。传 0 会返回原始数据。
Correction correction - 较低的值向原始数据修正得更慢，看起来更平滑；较高的值向原始数据修正得更快。值必须在 0 到 1.0 范围内。
Prediction prediction - 向未来预测的帧数。值必须大于或等于零。大于 0.5 的值在快速移动时很可能导致过冲。此效应可以通过较小的 Max Deviation Radius 值来抑制。
Jitter Radius jitterrad - 用于减少抖动的半径（单位：米）。超出此半径的抖动都会被钳制到该半径。
Max Deviation Radius maxdevrad - 滤波后的位置允许偏离原始数据的最大半径（单位：米）。与原始数据距离超过此半径的滤波值，会沿滤波值方向被钳制在此距离处。
Rotation Smoothing rotationsmoothing - 激活 Kinect 的旋转平滑算法。与上述关节平滑一样，平滑级别越高，引入的延迟越大。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

可通过 Info CHOP 访问 Kinect CHOP 的额外信息。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
