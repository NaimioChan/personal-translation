Group 类

Group 描述 Prim Class 或 Point Class 的组列表。

可以使用 Group SOP 创建 Group，或使用 ScriptSOP Class 的 createPointGroup(str) 或 createPrimGroup(str) 方法创建。

成员

default → tuple (Read Only):

与此 Group 关联的默认值。它返回组点的元组项。

name → str :

设置/获取组名称。

owner → OP (Read Only):

获取此 group 的所有者。

方法

add(item : Point | Prim | int)→ None:

向此 group 添加一个点/图元。要添加的点或图元可以用点对象、图元对象，或点/图元对象的索引指定。

discard(item : Point | Prim | int)→ None:

从此 group 移除一个点/图元。要移除的点或图元可以用点对象、图元对象，或点/图元对象的索引指定。

destroy()→ None:

销毁当前的点/图元组。
