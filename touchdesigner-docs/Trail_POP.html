Trail POP

摘要

Trail POP 捕获并保留输入在最近 N 帧或 N 个“切片”中的所有点，即输入点的时间历史。随后它可以选择创建以各种方式连接这些点的图元。

如果所有切片中输入的点数相同，则可以通过 Connectivity 菜单轻松地将点蒙皮连接，例如为每个点随时间的轨迹生成一条线带。

如果每帧的点数都在变化（例如粒子系统），仍然可以通过在点上使用 Id 属性，并确保粒子的 Id 在其整个生命周期内保持不变，来连接与时间相关的点。你可以使用 Match by Attribute 参数选择要关联的属性。

它忽略且不使用输入的连接关系（图元）。

如果所有切片中输入的点数相同，它会新增一个 Dimension，其大小为切片数。

Trail Length 可以用秒或帧表示。秒更好，因为当你将 Trail POP 移到帧率不同的其他项目时它保持不变。Trail Increment 让你可以跳过帧 - 每 M 帧捕获一个切片。

Reset 会清除并重新开始轨迹。Oldest Point First 会反转切片的顺序。

Trail POP 能优雅地处理掉帧：（可选地）为缺失的帧填充数据并创建替代切片，以及（可选地）用 Age 属性标记每个切片。这样可以得到更平滑、抗掉帧的轨迹曲线。

Info CHOP 通道

Trail POP 的附加信息可通过 Info CHOP 获取。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
