Import Select CHOP

摘要

Import Select CHOP 用于从 FBX COMP 或 USD COMP 等导入文件中指定 CHOP 通道。这些通道的主要用途之一是表示不同图元的变换变化，或导入文件中某些动态特性的状态。Import Select CHOP 可以在 Play 页中使用自己的动画控制，也可以使用其父 COMP 的设置。

另请参阅：USD COMP、FBX COMP

importselectCHOP_Class

参数 - General 页

Import Parent parent - 指定用于搜索素材的导入父级（例如 USD/FBX COMP）。未指定 COMP 时，默认在其路径中的第一个导入父级中搜索。
Take Type taketype - - 在播放动画或混合形状之间选择。
  • Blend Shapes blendshapes -
  • Animation animation -
Blend Shape blendshape - 指定此 CHOP 要播放的导入文件中的混合形状名称（如果指定了的话）。
Reload reload - 从导入父级重新加载素材。

参数 - Playback 页

Use Parent Animation useparentanim - 一个开关，指定是使用父 COMP 的动画控制，还是为此 SOP 使用自定义设置。
Animation animation - 指定此 CHOP 要播放的导入文件中的动画名称（如果指定了的话）。
Shift Animation Start shiftanimationstart - 一个开关，用于指定是否将动画移至导入文件中指示的动画起始处。
Sample Rate Mode sampleratemode - - 在 FBX 文件中嵌入的 'File FPS' 与设定 'Custom' 采样率之间选择。
  • File FPS filefps - 使用导入文件中所定义的 FPS。
  • Custom custom - 由 Sample Rate 参数指定的期望值。
Sample Rate samplerate - 当上面的「Sample Rate Mode」参数设为 'Custom' 时，设置采样率。
Play Mode playmode - - 用于指定播放动画方式的菜单。
  • Locked to Timeline lockedtotimeline - 该模式把动画位置锁定到时间轴。此模式下 Play、Speed、Index、Cue 和 Cue Point 参数被禁用，因为时间轴直接绑定动画位置。
  • Specify Index specifyindex - 该模式允许用户通过下面的 Index 参数指定动画中的特定索引（位置）。需要随机访问动画中任意位置时使用此模式。
  • Sequential sequential - 该模式不论时间轴位置如何都持续播放（Index 参数被禁用）。下面的 Play、Speed、Cue 和 Cue Point 参数可用，提供一定控制。默认即为此值。
  • Output Full Range outputfullrange -
Index index - 当 Play Mode 设为 Specify Index 时，此参数显式设置动画位置。右侧的单位菜单可让你以下列单位指定索引：Index、Frames、Seconds 和 Fraction（百分比）。
Index Unit indexunit - - 为 Index 指定单位类型。更改此项会将先前的单位转换为所选单位。
  • Frames frames -
  • Seconds seconds -
  • Fraction fraction -
  • Index indices -
Play play - 一个开关，设为 ON 时使动画播放。仅当 Play Mode 中选择了 Sequential 模式时，此参数才可用/启用。
Speed speed - 这是一个速度倍数，仅在 Play Mode 为 Sequential 时生效。值为 1 是默认播放速度。值为 2 是双倍速度，0.5 是半速，依此类推。
Trim trim - 启用 Trim Start 和 Trim End 参数的开关。
Trim Start tstart - 从动画开头设定入点，可裁掉动画的起始部分索引。右侧的单位菜单可按索引、帧、秒或分数（百分比）指定该位置。
Trim Start Unit tstartunit - - 为 Trim Start 指定单位类型。更改后会把之前的单位换算为所选单位。
  • Frames frames -
  • Seconds seconds -
  • Fraction fraction -
  • Index indices -
Trim End tend - 从影片结尾设定出点，可裁掉动画的结束部分索引。右侧的单位菜单可按索引、帧、秒或分数（百分比）指定该位置。
Trim End Unit tendunit - - 为 Trim End 指定单位类型。更改后会把之前的单位换算为所选单位。
  • Frames frames -
  • Seconds seconds -
  • Fraction fraction -
  • Index indices -
Cue cue - 一个开关，设为 ON 时跳转到 Cue Point 并停留在该位置。仅在 Play Mode 为 Sequential 时可用。
Cue Pulse cuepulse - 按下时动画跳转到 Cue Point 并从该点继续。
Cue Point cuepoint - 将动画中的任意索引设为要跳转到的点。
Cue Point Unit cuepointunit - - 为 Cue Point 指定单位类型。更改此项会将先前的单位转换为所选单位。
  • Frames frames -
  • Seconds seconds -
  • Fraction fraction -
  • Index indices -
Extend Left textendleft - - 确定父 COMP 如何处理位于 Trim Start 位置之前的动画位置。例如，若 Trim Start 设为 1，而动画当前索引为 -10，Extend Left 菜单决定动画位置如何计算。
  • Hold hold -
  • Cycle cycle -
  • Mirror mirror -
Extend Right textendright - - 确定父 COMP 如何处理位于 Trim End 位置之后的动画位置。例如，若 Trim End 设为 20，而动画当前索引为 25，Extend Right 菜单决定动画位置如何计算。
  • Hold hold -
  • Cycle cycle -
  • Mirror mirror -

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Import Select CHOP 的额外信息可通过 Info CHOP 访问。

特定的 Import Select CHOP 信息通道

  • animation_length -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
