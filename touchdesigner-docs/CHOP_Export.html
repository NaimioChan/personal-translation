CHOP 导出

CHOP 导出把 CHOP 通道中的数值发送到任意操作符的 Parameter。

在 TouchDesigner 中有多种导出 CHOP 通道的方式。

提示： 最好从 Null CHOP 导出，这样就能在网络中就地添加各种 CHOP，而无需从另一个 CHOP 重新导出。

从 DAT 导出的内容，另请参阅：DAT Export。

如何从 CHOP 导出通道

从 CHOP 查看器导出

  1. 确保要导出到的参数在界面某处可见。例如，选中该 OP 并按快捷键 p 显示其参数，或为该 OP 打开浮动的参数对话框。
  2. 若尚未开启，请为要从中导出的 CHOP 打开 Node Viewer 的 Viewer Active Flag。
  3. 将通道从查看器拖到参数上。放开时，从弹出菜单中选择 Export CHOP。注意参数会变为绿色，表示正在被导出到。

提示： 将拖动的通道在目标 OP 上短暂悬停，即可快速到达所需的参数，这会调出该 OP 的参数页。然后可以在其任一参数选项卡上悬停拖动的通道以切换到该参数选项卡，再放到所需的参数上。

使用按通道名导出

在任意 CHOP 的 Common 页的 Export Method 参数中选择 Channel Name is Path:Parameter，即可设置按通道名导出。 如果通道名能解析为文件中的 path:parameter，CHOP 通道就会自动导出。路径和参数之间使用 ':' 和/或 '/' 作为分隔符。例如，名为 geo1:tx 的通道将导出到名为 geo1 的节点、参数 tx（如果存在）。节点的搜索从 Export Root 参数所指的节点开始。通常 Export Root 保持默认，即 python 中的 'parent()'。这表示「从我的父级开始搜索」。因此在上面的例子中，CHOP 必须与 geo1 位于同一网络，导出才能生效。通道名可以包含路径，例如 container1/geo1:tx，这将搜索 container1/geo1（相对于 Export Root）的参数 tx。此功能中可以在通道名里互换使用 / 和 :，但良好的约定是：用 name1/name2 表示节点路径，随后用 : 将节点与参数名分开。

注意： 在使用 Export by Name 的 CHOP 中，所有能解析到参数的通道都会导出。用这种导出方式无法单独断开某个通道，要么全部导出，要么全不导出。要移除某个正在导出的通道，需要从输入中选中/删除/移除该通道，使其不再到达执行导出的 CHOP。

如何确认导出

从参数

被导出到的参数会以绿色高亮。点击参数名显示参数的表达式，即可看到覆盖该参数的 CHOP 通道路径。或者，右键点击参数名，弹出菜单中会显示 Jump to Export CHOP 选项。选择它会直接带你到数据所导出的 CHOP。

从 CHOP

如果回头查看通道来源的 CHOP，会注意到 Export Flag 现已开启。可以切换该标记来启用/停用此 CHOP 的导出。

也可以在 CHOP 上按住鼠标中键并查看弹出帮助信息，快速检查通道是否正在导出。通道数值右侧报告的路径就是该通道导出到的路径。这便于快速检查，但如果通道导出到多个参数，它不会显示多个路径（若还有其他参数导出路径，第一个参数的路径后面会跟 ...）。

查明通道来自何处

如果你忘了参数的覆盖通道来自何处怎么办？

只需在被覆盖的参数上按住鼠标右键。弹出菜单出现时，最后一项将是 Jump to Export CHOP /CHOP 的路径。然后你可以在网络中导航到该节点，或选择此菜单项直接跳到导出该通道的节点。

移除导出连接

停用 CHOP 的导出

  1. 要停用某个 CHOP 输出的所有导出通道，只需关闭该 CHOP 的 Export 标记。
  2. 关闭 Export 标记会停止从此 CHOP 导出的所有通道。
  3. 将 Parameter Mode 从 Export 改为 Constant 或 Expression。

移除单个导出

  1. 在导出目标的参数上右键点击并选择 Remove Export。注意：这只会移除导出 CHOP 中一个通道的导出，且在使用上文所述的 Export Method Channel Name is Path:Parameter 时无法这样做。

提示

从 Null CHOP 导出

良好的做法是始终从网络末端附加的 Null CHOP 导出通道。

原因很简单。如果你从网络中的最后一个节点导出，但后来决定还要进一步过滤数据，就必须附加新的过滤 CHOP，然后从这个新节点重做所有导出连接。若在网络末端使用 Null CHOP 作为导出的占位符，你始终可以在 Null 之前直接插入另一个节点。这样所有导出连接都保持完好。

将 Null CHOP 重命名以反映目的地也很有帮助，例如 toGearSpeed。

导出到开关和菜单

开关复选框和参数菜单也可以作为导出目标。将通道拖放到复选框或菜单上，然后从弹出菜单中选择 Export CHOP。

对于开关复选框，0 及以下的值表示「off」，大于 0 的值表示「on」。对于参数菜单，CHOP 通道值为 0 时选中第一个菜单项，为 1 时选中第二个，为 2 时选中第三个，依此类推。

在参数中使用表达式

CHOP 导出通常通过把通道拖放到参数上，从 CHOP 通道建立到参数。另外，参数也可以用表达式引用 CHOP 通道。这是更以参数为中心的做法，同一表达式可用于多个参数。在 python 中，使用类似 op('wave1')['chan1'] 的表达式获取 CHOP 通道的值。

例如，对于 CHOP /project1/stimulate/math6 和通道 vidproc_motion，可以使用以下 Python 表达式：

op('/project1/stimulate/math6')['vidproc_motion']
