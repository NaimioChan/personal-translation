深度测试

概述

深度测试（Depth-Test）是 OpenGL 判断一个对象是否位于另一个对象前方的方式，与对象的绘制顺序无关。每次绘制对象时，它都会把每个像素的深度写入所谓的深度缓冲区（Depth Buffer）。深度缓冲区保存 0 到 1 之间的值。位于摄像机近裁剪面处的对象深度值为 0。位于摄像机远裁剪面处的对象深度值为 1。 每次绘制像素时，GPU 会将传入像素的深度值与图像上该像素当前在深度缓冲区中的值进行比较。如果传入像素的深度值小于或等于当前像素的深度值，传入像素就会覆盖绘制当前像素，并把传入像素的深度值写入深度缓冲区。如果传入像素的深度值高于当前像素的深度值，则传入像素会被丢弃。空场景的所有深度值都为 1。

可以通过更改应用于几何的 Common page of the MAT 上的参数来控制深度测试的某些行为。

深度测试函数

深度测试函数在任何 MAT 的 Common 页中选择。深度测试函数控制如何将传入像素的深度值与当前像素的深度值比较。默认比较方式为「小于或等于」（如上面的示例）。这意味着如果传入像素的深度值小于或等于当前像素的值，传入像素就通过深度测试并被绘制。如果大于当前像素的深度值，则未通过深度测试，会被丢弃。

写入深度值

在 MAT 选项中，你可以选择写入或不写入深度值。不写入深度值的材质仍会参与深度测试，但无论测试通过还是失败，它都不会把自己的值写入深度缓冲区。不过它的颜色仍会被绘制。如果你有想要渲染的几何，但并不在意别的东西是否绘制在它上面，这很有用。例如某些粒子系统。如果禁用深度测试，深度值将永远不会写入深度缓冲区。

获取深度缓冲区的值

可以使用 Depth TOP 获取深度缓冲区的值。这些值最初为 24 位精度。如果你打算使用其他 TOPs 修改这些值，建议为下游的任何 TOP 使用 16 位或 32 位像素格式，以避免丢失精度。
