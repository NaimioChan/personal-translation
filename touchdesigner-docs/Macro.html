宏

macro 是一个单词，代表一段命令脚本。用户可以通过宏向脚本传递参数。宏使用旧版 Tscript 编写。

F1 到 F12 键可运行宏。F1 宏会让你进入 Perform Mode。在面板上按 F9 或 F10 会打开你所指向的面板元素的网络。

可通过 TouchDesigner 菜单栏中的 Dialogs → Macros 访问宏，对话框的说明见 Macros Dialog。

宏可以在任何组件中本地创建。放在组件的 local/macros 组件内的 Text DAT 会为该组件定义一个宏，宏的名称就是该 Text DAT 的名称。TouchDesigner 会先在当前组件中查找宏，若未找到，则在父组件中查找，如此一直到 Root。在 root 中定义的任何宏都可以在项目中的任何位置使用。

也可以使用 Tscript Macro Command 更简单地定义宏。

另请参阅 Script、DAT 和 Python。
