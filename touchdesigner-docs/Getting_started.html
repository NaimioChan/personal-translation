快速上手

这些基础知识能帮助你熟练使用 TouchDesigner 界面。如果按顺序完整走一遍，大约需要 1-2 小时。之后你将更有能力、更从容地自行探索 TouchDesigner。

本页是两个初学者视频的文字稿：

First Things to Know Part 1 - 第 1-17 节

First Things to Know Part 2 - 第 18-33 节

提示：若 TouchDesigner 中某个术语的含义不清楚，可以在左侧菜单的 TouchDesigner Glossary 或 Search 中查找。

1. 启动 TouchDesigner

使用 TouchDesigner 需要一个带滚轮的三键鼠标，或等效设备。

先双击桌面上的 TouchDesigner 图标（或从 Windows 开始菜单启动）。

2. 平移、缩放并使网络居中

首次启动 TouchDesigner 时，你会看到右侧的 network 编辑器。左侧是 Palette 浏览器。点击其右上角的 x 关闭 Palette。

要平移网络，在网络空白处按住鼠标左键（LMB）拖动。

要缩放网络，按住鼠标中键（MMB）并左右拖动。NOTE: If you don't have a middle mouse button，按 Alt+右键。

按 "h" 键使其居中（这也称为 homing）。若只想让高亮的节点居中，按 Shift-h。

在网络空白处右键点击（RMB）并松开鼠标——你会看到网络菜单。选择 'Home All'。

3. 选择并移动节点

左键点击一个节点并拖到新位置。

要框选多个节点，在空白处按住鼠标右键并把鼠标拖过这些节点。

左键点击任一已选节点并拖动——选中的节点会一起移动。

左键点击背景可取消选中节点，只留下绿色的当前节点。

右键点击其中一个节点——你会看到节点菜单。选择 'View' 弹出浮动窗口。点击并拖动边缘可调整大小。现在点击角落即可关闭查看器窗口。

4. TouchDesigner 操作符分为 Generator 或 Filter

要删除所有节点，按 Control-a，然后按 Delete。

双击空白网络。OP Create Dialog 会出现，其中 OP 意为“operator”或“node”。点击 Movie File In，然后在网络上任意位置点击以放置它。

你也可以按 Tab。要取消，点击背景。

在第一个节点的右侧，右键点击其蓝色输出连接器，从 OP Create 中点 'Level'，然后向右点击创建 level1，它会连接到 moviefilein1。你刚刚添加了一个修改图像“generator”（moviefilein1）色阶的图像“filter”（level1）。

在右上角的对话框中，移动标有 Black Level 和 Brightness 的滑块。这些是 TouchDesigner 中典型的“参数”。

5. 在 Network Editor 中添加操作符

再次双击背景。OP Create Dialog 中有六个标题，也就是我们所说的 Operator Families。点击 'CHOP' 即 'Channel Operators'。你也可以多次按 Tab，循环回到 CHOPs。

颜色较深的 OP 是 generator。Generator 创建新数据，或从外部设备和程序读取数据。颜色较浅的 OP 是 filter。Filter 修改传入操作符的数据。

点击 CHOP 类型 "Pattern" 并将其放置到网络中。

再次唤出 OP Create。你可以输入名称来查找特定操作符。输入 "noi"，点击 Noise，创建一个 Noise CHOP。

6. 六个操作符族分别处理图像、运动、3D 和文本

我们来看看这六个操作符族。你大概已经知道，Texture Operator（TOP）处理图像，Channel Operator（CHOPs）用于运动、控制信号和音频。

按 Tab 键唤出 OP Create。在右上角，确保设为 "All" 而不是 "Basic"，以看到所有操作符。

点击 SOP。Surface Operator（SOPs）处理多边形、3D 线和其他表面。选择一个 Sphere SOP。

按 Tab 键并选择 MAT。Material Operator（MATs）为 3D 对象添加纹理和着色。选择一个 Phong MAT。

按 Tab 键并选择 COMP。组件有三类。从 3D Objects 中选择一个 Geometry COMP，它会为 3D 渲染准备 SOP 和材质。

再次按 Tab 键。从 Panels 列表中选择一个 Slider COMP，它是用于构建控制面板的 2D gadget 之一。

按 Tab 键并选择 DAT。Data Operator（DATs）操作文本字符串，既有自由文本也有表格中的文本。选择一个 Monitors DAT。

如果你愿意，在初学 TouchDesigner 时可以切回 Basic。

7. 用连线连接节点

节点输入在左侧，输出在右侧。按 Tab 创建一个名为 Monochrome 的 TOP，并把它放在 level1 右侧。

用以下两种方式之一把 level1 的输出连接到 mono1 的输入：点击并拖动然后松开。或者点击松开、移动、再点击松开。

点击并向右拖动 Monochrome TOP，在两者之间留出空间。

要在两个已连接的节点之间插入新节点，右键点击 level1 节点的输出，选择一个 Tile TOP 并放置。另一种方式是右键点击连线，从菜单中选择 Insert Operator。

要从某个节点创建新分支，中键点击 level1 的输出，从 Operator 菜单中选择 Edge 并放在上方。

节点之间的连接线称为 Wires。要移除连线，点击已连接节点的输入，edge1，然后点击网络中的空白处。要重新连接 edge1，点击 edge1 的输入，然后点击 level1 的输出。

另一种方式是右键点击连线，从菜单中选择 Disconnect。再次重新连接 edge1。

8. 连线、数据流与计算

你可以把数据想象成沿这些连线流动，在这里就是图像。现在观察连线在做动画。点击 level1，前往右侧的 Parameter Dialog，操作 Brightness 滑块。当连线有动画时，表示数据正在流动：上游节点正在 cooking，并把输出发送到下一个节点。

中键点击 tile1，查看它已经计算了多少次，然后中键点击 moviefilein1，可以看到它只需要计算一次。

几何、摄像机和灯光等 3D 组件在底部和顶部有连接器和连线，它们在 3D 层级中以父子关系连接，但连线上没有数据流动。

滑块、按钮和容器等 2D 组件在底部和顶部也有连接器和连线，这是把它们在面板中组织起来的一种方式。同样，连线上没有数据流动，数据只通过侧面的连线流动。

9. 当前节点与选中节点

点击其中一个节点使其成为「当前」节点。它会显示绿色边框。

节点周围的黄色边框表示它们已被「选中」。在网络中 right-click (RMB) 并框选其他节点即可选中它们。按住 Shift 点击，或按住 Shift 框选，可以把更多节点加入已选集合。

你可以对选中的节点一起操作。右键点击网络背景并选择 Delete 删除节点，然后按 Ctrl+z 撤销（macOS 上为 Command+z）。也可以通过 Edit 菜单撤销。

现在点击任一选中节点左上角的 Flag。这会在它们的 Node Viewers 和三字母图标之间切换。再重新打开节点查看器。

要取消全部选中，点击背景，只留下当前节点。

10. 激活查看器以检查操作符数据

到目前为止，左键点击节点时，你要么移动它，要么把它设为当前节点。你只能在查看器中看到数据。中键点击显示通用信息框，右键点击显示节点菜单。

注意： 如果没有鼠标中键，请按 Alt+右键。

点击 level1 TOP 右下角的「Viewer Active」标记会去掉它的边框，让你可以更仔细地检查操作符数据的内容；对于面板，则可以操作面板。中键点击并左右移动可缩放图像，右键点击可设置查看选项菜单。

还有三种方式可以让查看器变为交互状态：

  • Alt+a 键会让所有节点查看器临时进入 Viewer Active 状态。
  • Shift+a 切换一个名为「Viewers Always Active」的全局状态，使所有网络中的所有查看器都处于激活状态。Viewers Always Active 也在右键网络菜单中。
  • shortcut 键「a」会设置/取消所有选中节点的 Viewer Active 标记。

即使节点已开启 Viewer Active，你仍然可以访问它的通用菜单。在底部的名称栏上，中键点击可获取节点信息，右键点击可获取通用节点菜单。

11. 调整操作符的参数

我们来调整参数。选中 noise1 CHOP。TouchDesigner 中的每个操作符都有一组 Parameters，你可以用它们影响其输出。通常 Parameter Dialog 是打开的，停靠在一个网络的右上角。按小写 p 键隐藏参数对话框，再按 p 把它叫回来。

若要在浮动窗口中查看 sphere1 的参数，右键点击 sphere1 并选择 Parameters...。

选中多个具有同一参数的操作符，可以一次性修改多个操作符的该参数。把 noise1 向左移动，点击 pattern1，按 Ctrl+c 和 Ctrl+v 创建 pattern2（macOS 上为 Command+c 和 Command+v）。把 pattern2 参数的 Type 菜单改为 Ramp。现在同时选中 pattern1 和 pattern2。增大 Number of Cycles 参数。松开后你会看到两个操作符的 Cycles 参数被设为相同的值。

要把参数恢复为默认值，有三种方式：右键点击 pattern1 并选择 Reset all Parameters，或者在它的参数对话框的「i」图标上右键点击 → Reset。

要只重置一个参数，右键点击 pattern2 的 Type 参数，并从菜单中选择 Reset Parameter。

12. Value Ladder 帮助你修改参数值

现在我们用 Value Ladder 来调整参数。选中 noise1 CHOP，用鼠标滚轮放大它的查看器。

在参数对话框中，左键点击 Period 参数的名称或数值，按住不放并稍等片刻。Value Ladder 会弹出若干增量，标为 .001 .01 .1 1 10。保持左键按下，垂直移动到其中一个增量，然后向右/向左移动以增大/减小参数值。

点击参数对话框的 Transform 页。如果参数有两个或更多数值，比如 Translate 参数，当你左键点击某个数值（点击第三个数值）时，只会改动那一个值。但如果你点击名称并操作梯子，则会修改该参数的所有数值。

再给一个提速小技巧：中键点击参数名称或数值，可以更快地调出 Value Ladder。

13. 进入包含网络的组件操作符

我们在组件之间进出，进入其他网络。灰色边框的节点是 Components。在我们的网络中，geo1 和 slider1 是组件。

每个组件都包含一个 Network，而每个网络都存在于某个组件之中。

要进入 slider1，选中它并按 Enter 或「i」键。要退出组件，按「u」（up）。只要组件的 Viewer Active 关闭，也可以双击组件进入。

更顺手的方式是用鼠标滚轮放大靠近组件。当滚轮放大到非常接近 slider1 时，就会进入它内部。反方向滚动即可退出。

14. 保存你的工作

经常保存工作状态。在 File 菜单下选择 Create New Project。把 Project Folder 改为 Learning，打开 Rename File，使它创建 Learning.toe，然后按 Create。它会显示在桌面上创建了一个名为 Learning 的文件夹，其中包含两个相同的文件 Learning.1.toe 和 Learning.toe，两者都是 TouchDesigner Environment 文件。

下次要保存时，只需选择 File → 'Save'，它会递增文件名并保存。也可以按 Ctrl+s 保存（macOS 上为 Command+s）。

退出 TouchDesigner 后，下次重新启动时，可以打开 Learning 文件夹并双击 Learning.toe，它总是启动编号最新的文件。

15. 把媒体导入 TouchDesigner

TouchDesigner imports 常见的图像、影片、音频和 FBX 文件类型。它也能导入 TouchDesigner .tox 组件。参见 File Types。

我们创建一个空组件。按 Tab，在 COMP 中选择 Base，并放置它。用滚轮进入 base1。

在顶部菜单栏的 Dialogs 菜单下，选择第一项（Windows 上为 Explore）。

打开某个媒体文件夹，从文件浏览器把你的一些媒体文件拖放到 Network Editor 中。

你也可以从桌面取文件并拖放进来。

另一种方式是用 Tab 菜单创建合适的操作符，然后把它们的 File 参数设为你的媒体文件。找名字中带 File In 的操作符。

还有 File → Import File ... 对话框，在那里可以看到更多支持的文件类型选项。

在 Windows 的桌面或文件夹中，右键点击这些文件中的任意一个，选择 Open with...，然后选择 TouchDesigner。这会以该文件为节点启动一个新的 TouchDesigner 会话（新进程）。

注意：.toe 文件是「TouchDesigner Environment」文件，包含整个项目。它们不会被导入，只需双击文件即可启动（或在桌面上右键 → Open With...）。

16. 拆分窗格并填入其他窗格类型

有时你想同时身处两个地方。TouchDesigner 窗口可以拆分为 2 个或更多 Panes。通过窗格右上角的下拉菜单拆分窗格，选择 Split Left-Right。

窗格通过其左上角菜单填入窗格类型。你目前一直在用的是 Network Editor 窗格类型。「Panel」窗格类型让你可以与面板组件交互。Geometry Viewer 窗格类型让你可以与 3D 场景和对象交互。在节点上右键点击 → Viewer 会在浮动窗口中给出类似的视图。

用分隔条调整其大小，并关闭该窗格。你也可以点击窗格顶部的 Layout 或 Bookmark 图标来选择多窗格布局。更多内容参见 Pane。

17. 操作符标记影响其功能和外观

Operator Flags 围绕网络中的节点。左侧的标记为所有操作符族共有，底部的标记则属于特定操作符族。

要查看完整的标记集合，在网络窗格中按 t，把鼠标移到各标题上查看标记类型，然后再按 t 返回。关于各个标记的更多细节，参见：Bypass Flag、Display Flag、Lock、Render Flag、Viewer Flag、Viewer Active 标记。

18. 参数与三种「参数模式」

在 TouchDesigner 中，所有处理和输出数据的工作都由操作符完成。每个操作符的输出受以下因素影响：它的输入、它的参数，某些情况下还有当前时间。所以我们来看看参数的特性。最常见的参数类型有：(1) 整数，(2) 浮点数（带小数位的数），(3) 开关「toggle」，(4) 菜单，(5) 文本字符串，等等（(6) 指向另一个节点的路径，(7) 告诉操作符只执行一次某动作的脉冲）。

每个参数可以有一个、两个、三个或四个值。创建一个 Circle TOP。例如，当参数是颜色时，它有 3 或 4 个值：红、绿、蓝，有时还有 alpha。

因此每个参数可以处于三种「参数模式」之一，也就是说每个参数可以用三种方式控制。第一种最简单——「Constant」——在参数对话框中你只需点击滑块、输入数字、从菜单中手动选择——它设定其「常量」值。另外两种「参数模式」非常强大：「Expression Mode」，你可以在其中放入 Python 表达式（以绿色显示）；第三种是「Export Mode」，参数由来自 CHOP 的数值驱动。你可以在三者之间切换。先来看看导出。为此我们需要更多地了解 CHOP、通道和采样。

19. CHOP 输出由采样组成的通道

CHOP 输出数值。通道操作符会创建一组 1 个或多个通道，每个通道是一组数值（Sample）。我们创建一个 Constant CHOP 并移动它的滑块。它有 1 个通道和 1 个采样，中键点击节点看到 1i 就能确认，其中 i 表示采样或索引。点击 chan1 下方并输入 chan2。现在它输出 2 个通道。

现在创建一个 Noise CHOP。这是一个带多个采样的 Channel。要证明这点，把视图稍微放大到节点，打开 Viewer Active，右键点击图表并选择 Dot per Sample。然后中键点击并向右拖动鼠标，即可看到每个采样一个点。（注意，节点上的鼠标点击行为取决于查看器是否激活。）

在 Noise CHOP 的图表上按 'h' 使通道居中。在参数对话框中，点击 Channel 页并将 Channel Names 参数改为 chan[1-3]。现在有 3 个通道，每个 600 个采样。要验证，中键点击节点底部名称 noise1 所在的条带，查看弹出信息中的 600i，意思是 600 个采样或索引。

要把 CHOP 显示为数字，调出 OP Create，点击 DAT，创建一个「CHOP to」DAT。然后打开名为「Include Names」的参数。现在将 Noise CHOP 拖到 CHOP to DAT 节点以及名为「CHOP」的参数上，把两者连接起来。查看查看器中的表格，每个单元格是一个采样。现在试试 Constant CHOP，你可以把 Constant 拖到 CHOP to 上。

总的来说，CHOP 用于在 TouchDesigner 中表示曲线、运动、音频信号或控制信号。（参见：Channel、CHOP）。

20. 把 CHOP 通道导出到参数

Export 将一个值从 CHOP 通道发送到操作符的参数。

创建一个 LFO CHOP，让它慢下来，并连接到新的 Math CHOP。把它设为 Math CHOP 的 Viewer Active。创建一个 Movie File In TOP，右键点击它的输出，再添加一个新的 Transform TOP。

（点击 Transform TOP，这样你才能向它导出。）左键点击 Math CHOP 查看器中的通道，把它拖到 Parameter Dialog 中的某个参数上（比如 Transform TOP 的 Translate X 参数）。在出现的菜单中选择 'Export CHOP' 完成导出。注意该参数变为绿色，表示该参数处于 Export 模式。

再次选中 Math CHOP（框选它或点击底部名称栏），然后选择 Mult-Add 页并调整 Multiply 参数来改变运动范围。

点击 CHOP 底部的绿点可以关闭导出，Transform TOP 的 Translate 会回到常量模式。再把导出打开。（更多技巧参见 Export）。

21. 在参数中放入 Python 表达式

我们来看看参数中的 Python 表达式。表达式用于参数和脚本。首选语言是 Python，不过在较早的作品中你会看到 Tscript。

新建一个 Pattern CHOP，命名为 sine1。在 Length 参数中输入表达式 200*3。数值现在显示为 600 = 该表达式已被求值为 600，并且它变为蓝色，表示当前处于 Expression 模式。要展开更多内容，把光标放在参数名「Length」上，会出现一个 +，在该区域任意位置点击。会出现新的一行，显示该参数的 Python 名称（'length'）、三个参数模式的复选框，以及可选的 Python 表达式。

点击蓝色方框左侧的灰色方框。这会使其回到 Constant Mode，数值为其默认值 1000。这在确定之前尝试不同数值时很有用。再次点击 Expression Mode 方框。

第三种参数模式是 Export 模式，所以如果你回到保存导出的 Transform TOP，点击 Translate，会看到 tx 处于 Export 模式（绿色），并且能看到通道来自哪里。在这里可以在 Constant、Expression 和 Export 模式之间切换。

在 sine1 上，在名为 Number of Cycles 的参数中输入表达式 me.digits+2。它求值为 3，即操作符名称中的数字加 2。只选中文本 me.digits，把光标放在表达式上。它会弹出 1，即表达式该部分的值。

要放大参数对话框以获得更多空间：将光标放在参数对话框左边缘，出现左右箭头光标时，点击并向左拖动。

如果光标位于某个参数中时按 Alt-E，会在文本编辑器中调出当前参数的表达式，便于查看和编辑长表达式。

查看这个表格，了解 TouchDesigner 中最常用的 Python 表达式：Python Tips。另请参阅 Parameter。

22. 创建一个带输入、输出和操作符网络的组件

组件是内部可以容纳操作符网络的操作符族。我们创建一个带有输入和输出操作符的组件。按 Tab，选择 COMP，选择 Container 并在网络中放置它。进入该 Container（滚轮向前，或按 Enter）。在窗格顶部确认你的路径位置。

按 Tab，选择 TOP，选择 Ramp 并放置。右键点击 ramp 节点的输出并选择一个 Out TOP。按 Tab，选择 CHOP，选择 In CHOP。回到组件外部（按 u 或滚轮向后），右键点击组件的输入来创建一个 Beat CHOP。这会把新的 Beat CHOP 连接到组件的输入。

回到组件内部，把 In CHOP 的通道 export 到 Ramp TOP 的 Phase 参数。再回到组件外部。在容器的 Panel 页中，在 Background TOP 参数里填入 ./out1。你应该会看到一条上升的斜坡。右键点击容器的输出并添加一个 Null TOP。现在你就创建了一个带 CHOP 输入和 TOP 输出的自定义组件。

（退出这个组件。）

23. 路径是节点的地址

路径就像节点或操作符的地址——它描述节点在你的 TouchDesigner 项目中的位置。创建一个 Select CHOP，在 Operator 参数中输入 /project1/pattern1。许多操作符都有一个指向其他操作符的路径参数。

所有节点都处于组件嵌套组件的树状层级中，起点是 root，其名称为 /。点击「home」图标回到 root。点击「/」并选择 project1，回到你正在工作的网络。看看 Select CHOP：

路径开头的 / 表示这是绝对路径。/project1/pattern1 是绝对路径，其中在 root（/）里有一个组件 project1，在 /project1 里有一个节点 pattern1。

路径还有其他形式：

创建一个 Select TOP，在其 TOP 参数中输入 transform1。transform1 是相对路径：当你看到不带前缀的操作符名称时，它就在当前网络中。

创建一个 Info CHOP，在其 Operator 参数中输入 container1/out1。这也是相对路径——container1 是当前网络中的一个组件，out1 是 container1 中的一个节点。

你的 container1 组件用 ./out1 作为背景图像。./ 表示「在此组件内部」，所以该路径的意思是「在此组件内部有一个名为 out1 的节点」。

进入 container1，创建一个 Select DAT，并在它的第一个参数中输入 ../chopto1。../ 表示父网络，因此该路径的意思是：在当前组件的父级中有一个名为 chopto1 的节点。

在 Python 表达式中你会经常看到 parent()，它同样指父节点。要定位到层级更上方，../../ 是父级的父级。

24. 用 Render TOP 渲染 3D 场景

现在我们用 Render TOP 渲染一些 3D 内容。创建一个 Container 组件并进入其中。创建一个 Render TOP。接着创建三个组件：一个 Geometry、一个 Light 和一个 Camera。虚线表示 Render TOP 的参数已经引用了这些组件。在 Render TOP 的 Camera 参数中，你会看到 cam1，意思是「从节点 cam1 获取摄像机」。Geometry 的 * 表示获取此网络中的所有 Geometry 组件。

打开 geo1 Geometry 节点的参数，在 Z 轴上旋转圆环（Rotate 的第三个字段）。Render TOP 会随之变化。现在点击 geo1 的 Viewer Active 标记，点击/拖动圆环使其翻滚。注意渲染保持不变。Geometry 组件查看器中的翻滚仅用于检查。在 geo1 查看器中按 h 回到原位（重置翻滚）。

这就是你的基础渲染设置。现在在 Rotate 参数的第一个字段中填入 absTime.frame。absTime.frame 是 Python 中表示「绝对帧编号」的写法，这个数字会持续增大，直到你退出 TouchDesigner。

25. 时间轴让你播放、暂停和查看

Timeline 位于 TouchDesigner 主窗口的底部。左下角的 FPS 是 TouchDesigner 每秒将推进的帧数。注意顶部的 FPS 是 TouchDesigner 在上一秒实际绘制的帧数。

时间轴让你可以在 TouchDesigner 中停止（||）、启动（>）和单步（+）时间轴。

Shift+空格 总是会停止和启动时间轴。（按住 Shift 再按空格。）每推进到另一帧，它都会重绘屏幕。

你会看到，当时间轴到达最右端时，它会循环回到时间轴的开头。但 TouchDesigner 主要是事件驱动的，配有一个自由运行的时钟，因此你搭建的大多数东西并不跟随循环的时间轴及其帧编号：例如，创建一个 Constant CHOP，把它设为 1 并连接到一个 Speed CHOP。它的计数会持续增加，与时间轴无关。按 Speed CHOP 的 Reset 参数可以让它重新开始。

创建一个 Movie File In TOP，在 File 参数上选择 + 并选择 Count.mov。Movie File In TOP 默认以 Sequential Play Mode 持续播放，与时间轴位置无关。

但如果你把它的 Play Mode 菜单参数设为「Locked to Timeline」，影片与时间轴的帧编号就会保持同步，影片的第一帧始终在第 1 帧出现，并且你可以拖拽浏览。

26. 用 Animation Editor 创建动画曲线

创建一个 Animation Component。默认情况下它输出一个没有通道的 CHOP。现在右键点击该节点并选择 Edit Animation...（或在其参数对话框中按 Edit Animation...）。

点击 Add Channels 按钮，会创建 3 个通道：tx、ty 和 tz。关键帧是通道上的圆点。点击任意关键帧并把它移到任意位置。要给任意通道添加更多关键帧，用 alt+鼠标左键点击你想要关键帧的位置。用鼠标右键框选。框选曲线（不是关键帧圆点），把 Function 菜单从 cubic() 改为 linear() 以更改插值类型。

然后观察底部的 Timeline 以及 Animation 组件查看器中通道的值。注意通道值跟随时间轴。

如果你想更精确地控制时机，可以把一个动画通道连接到 Animation 组件的输入：创建一个 Beat CHOP 并连线到 Animation COMP 的输入。把 Animation COMP 的 Play Mode 设为「Use Input Index」，把 Input Index Unit 参数菜单设为「Fraction」。

然后创建一个 Constant CHOP，把它连线到 Animation COMP 的第一个输入，并移动 Constant 的 chan1 滑块。两种情况下，0-1 的值都会控制输出动画曲线的哪一部分，从而让 Animation COMP 与时间轴解耦。你随时可以把 Play Mode 改为 Output Full Range 来输出完整长度的通道。

另一种创建预连线动画组件的方法：右键点击某个参数并选择 Keyframe Parameter in...

27. DAT 是强大的文本处理操作符

DATs 是「数据操作符」，让你可以在 TouchDesigner 网络中存储和操作文本。Text DAT 用于编写可在某些事件发生时运行的脚本。

创建一个 Web DAT，假设你已联网，按 Fetch 参数。它会获取 HTML，但 DAT 可以保存任何 ASCII 文本，比如 GLSL 着色器和脚本。

现在创建一个 Monitors DAT，它是由行和列组成的单元格表格，每个单元格包含文本。Monitors DAT 上还附有另一个 DAT，其中包含一些 Python 代码，在监视器配置变化时运行。

这算是 DAT 的一点风味。

进一步了解操作符的一种方法是看小示例。选择菜单 Help → Operator Snippets。这会启动另一个 TouchDesigner 窗口，里面有数百个使用各操作符族操作符的示例。这是提示的丰富资源。

30. 从 Palette 获取组件

Palette Browser 中的组件包含预先做好的网络，有些还带有自定义控制面板。你也可以把自己创建的组件存入 Palette 以便随时取用，并在项目的其他地方复用。

要显示预做 Components 的浏览器，切换 Palette 图标的关闭/开启。或者点击 Dialogs → Palette Browser。点击一个组件并把它拖到网络中。磁盘上的组件是 .tox 文件。

观看视频 A Movie Player Panel and Building UIs，这是关于面板构建基础的教程。

UI/gal 包含一个由 20 个预制可自定义小工具组成的库，可以复制/粘贴到你的网络中，用来制作控制面板。

31. 从 .tox 论坛获取组件

在 TouchDesigner 菜单栏上按 [ EXAMPLES ] 前往 www.derivative.ca/forum 的 .tox 组件论坛。你可以在论坛网页上点击一个 .tox，在新的 TouchDesigner 会话中启动它。你也可以把 .tox 文件下载到电脑上，然后拖放到 TouchDesigner 中。双击任何 .tox 也会在新的 TouchDesigner 进程中启动它。

32. 用 Performance Monitor 提速

Dialogs → Performance Monitor 让你可以在单帧中看到哪些节点在计算、以什么顺序计算，以及各花了多长时间。注意，Performance Monitor 只显示 CPU 上的计算，不显示 GPU。但底部出现很长的条通常意味着 GPU 仍在忙于完成一帧的渲染并显示 UI。

中键点击任意节点，可以看该节点是否每帧都在计算，以及最近一次计算花了多长时间。

还有 Perform CHOP，你可以创建 Info CHOP 并把任意节点拖到它上面，查看更多关于发生了什么的细节。

调色板里也有：Palette → Tools → probe，以及关于它的 wiki 页面：Palette:probe。

33. 快速技巧与好习惯

  • 点击参数对话框中的 bulls-eye 圆圈，可以看到哪些参数不是默认值。这对理解别人的网络非常有用。
  • Color Code Nodes - 光标位于网络上时按「c」调出色板。选择一些节点。点击色板中的任意颜色。这只影响节点在网络中的外观。
  • network overview - 把光标放在网络上，按「o」在网络左下角调出微型节点图。你可以点击它来平移网络。
  • Ctrl+f（macOS 上为 Command+f）会调出一个 Find bar，让你输入可能在找的节点名称。与你输入匹配的名称会被高亮并居中。
  • 换一种方式查看节点：把光标放在网络上，在网络中按「t」，它会切换到 "table" mode，你可以在列表中看到所有节点。你可以通过左列选择一个，再按「t」回到网络，并看到该节点在网络中被高亮。
  • 当你 don't have a mouse 时，用快捷键 Ctrl+=、Ctrl+-、Ctrl+up、Ctrl+down、Ctrl+left、Ctrl+right（macOS 上全部加 Command+）缩放和滚动网络编辑器。
  • 在 OP Create 中，用 Shift-点击可以更快地创建 nodes-in-a-row，在 OP Create 菜单上按住 Alt-点击可以在分支中创建节点。
  • 节点名称是 case-sensitive，所以 leve1 与 Level1 不同。
  • 「Absolute Time」这个概念是一个永远递增、不会像时间轴那样循环回 0 的时钟。它给出平滑且始终变化的值：absTime.frame、absTime.seconds。
  • 在引用或导出时使用 Null 操作符——这样你可以在 Null 之前插入额外操作符来修改网络，而无需改变引用或导出的位置。
  • Status Bar 位于 TouchDesigner 主窗口的右上角，提供最近操作的信息。它可能会显示消息来表示事件成功/失败，或显示提示来告诉你如何使用某个工具。要时常留意它。（python code ui.status = 'My message' 可用于在状态栏中放置一行文字。）
  • 在节点上使用 Info DAT or Info CHOP，查看它的一些内部状态，或许还能排查问题。
  • 通常的做法是使用 Shift-Spacebar to stop，但在 Designer Mode 中，你可以使用空格键。
  • 你可以在 SOP viewers 和 Geometry 查看器中打开/关闭自动回到原位。在 Preferences → Geometry 中打开这些选项然后按 Accept，这样就能确保你始终在视图中看到 3D 几何。
  • 通过点击新来源的输出，再点击你要替换的连线，来 replace an existing wire。
