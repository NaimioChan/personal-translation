TUIK

TUIK 是 TouchDesigner 中已过时的旧版 UI 套件，已被 Widgets 取代。

本文概述 TUIK（读作 \ˈtwēk\）。TUIK 代表「Touch User Interface Kit」，是一组用户界面组件。

概述

TUIK 是位于 Palette 中的一组用户界面组件，可让用户轻松构建自定义控制面板。

入门

在 Browser 中，选择 Palette 标签。如果调色板浏览器尚未显示，可从 Dialogs → Palette 中选择 Palette，或点击 TouchDesigner 窗口左侧细小的收起栏来展开它。 在 Palette 中，点击打开文件夹「TUIK」，然后打开「Windowparts」。接着从列表中选择「emptypanel」组件，并用 Drag-and-Drop 将其拖入 TouchDesigner 的 Network。

接着 Drag-and-Drop 组件「titlebar」，并通过连接顶部的连接器和底部的连接器把它连到「emptypanel」，从而建立「父级」或「层级」关系。此过程与 3D_Parenting 相同。

几乎所有 TUIK 组件都可以自定义：将鼠标悬停在容器上，然后按键盘上的 F11。对「titlebar」组件这样做，会得到一个表格，其中有一行名为「dialogname」，第二列设为「Controlpanel」。把该节点切换到 Viewer_Active 模式后修改这个值，就会改变「titlebar」中的文字。

打开「emptypanel」上的 RMB Menu，选择「Open Control Panel」→「Borderless...」，以以在浮动、无边框的窗口中打开控制面板。

要让「titlebar」组件随「emptypanel」的尺寸一起调整大小，把 Panel_COMP_Layout_Page 上的「Width」参数从常量值改为 

par(opparent(".",0)+"/panelw")

The 

opparent(".",0)

该表达式返回节点在层级中的父级路径，其中「0」可以替换为你想要向上跨越的层级数。

接着 Drag-and-Drop 另一个「emptypanel」组件，并将其按层级设父级到第一个「emptypanel」组件。把 Panel_COMP_Layout_Page 上的「Width」和「Height」参数改为 

par(opparent(".",0)+"/panelw")

以及

par(opparent(".",0)+"/panelh")-25

其中减去 25 是为了计入「titlebar」组件的高度。再把「Margin」参数改为 5，把「Align Margin」参数改为 2。这样可确保之后添加的组件彼此间隔 2 像素。最后把「Align Order」参数设为 1，以确保新的「emptypanel」对齐在「titlebar」组件下方。

在 Palette 中，现在导航到「TUIK」→「Sliders」文件夹，并把「sliderhorzvalue」Drag-and-Drop 到 TouchDesigner 的 Network 中。 将「sliderhorzvalue」按层级设父级到第二个「emptypanel」，并通过将鼠标悬停在其上、按键盘 F11 来修改定义。把「sliderhorzvalue」复制粘贴几次，你应得到类似下面的控制面板：

自定义 TUIK 组件

每个组件的根目录下都有一个 define Table DAT，用于修改组件的行为和外观。将鼠标悬停在 TUIK 小工具上并按 F11，直到在节点查看器中看到 define 表格，即可编辑它。另一种方式：进入 TUIK 小工具，选择 define Table DAT，按「a」，然后修改你想更改的那一项旁边第二列的数值。值可以是字符串、数字或表达式。

所有组件还带有 color Table DAT，可为组件的某些部分指定颜色。第一列指定 TUIK 组件的部分，第二列指定颜色。颜色可以用真实名称指定，例如 Blue，也可以设置自定义颜色： 

rgba(125,90,80,1)

其中颜色范围为 0 到 255，alpha 范围为 0 到 1。

TUIK 小工具

窗口部件

  • emptypanel - 该组件是空容器，可作为控制面板的起点。修改它的 X 和 Y 宽度参数可增大或减小面板尺寸。
  • titlebar - 该组件提供可拖动的标题栏和关闭按钮。define Table DAT 可让你指定标题栏标签。
  • menu - 该组件是下拉菜单。define Table DAT 可让你指定菜单标签。组件内部有若干 Table DAT，用于指定下拉菜单的条目，以及选择某个下拉菜单条目时执行的脚本。相关脚本位于其包含的 scripts BASE 组件中。该小工具有两个输入：一个替代 Table，用于指定菜单条目；另一个 Table 输入，用于指定哪些下拉元素被启用或禁用。
  • heading - 该组件可用作控制面板子小节的标题。define Table DAT 可让你指定标题标签。
  • viewer - 可让你把 TOP 显示为控制面板查看器。define Table DAT 可让你指定查看器组件所显示的 TOP 的来源。也可以直接把 TOP 接到查看器的 In TOP 上来显示。
  • label - 用作简单的标签。define Table DAT 可让你指定标签的标题文字。

滑块小工具

  • sliderhorz - 是水平滑块，将其当前值输出为 CHOP 通道。define Table DAT 可让你指定滑块的标签。channelname 行会更改输出通道的名称。lower_range 和 upper_range 可设置滑块的值范围。若 lower_clamp 或 upper_clamp 设为 1，滑块输出值将被限制在 lower_range 和 upper_range 指定的值范围内。format 可让你在「float」与「integer」之间选择滑块值的输出格式。type 可设为「std」或「xfade」，其中「xfade」会模拟交叉淡化滑块。把方向从「horizontal」改为「vertical」会切换滑块的滑动方向。你还需要调整滑块组件的 Width 和 Height 参数。
  • sliderhorzmulti - 与 SliderHorz 相同，但带有多个旋钮。
  • sliderhorzvalue - 与 SliderHorz 相同，但带有数值字段。
  • range - 是带 2 个旋钮、用于指定范围的水平滑块。
  • slider2d - 是二维滑块。define Table DAT 可让你指定滑块的标签。displaylabel 控制是否显示标签，labelwidth 设置标签宽度。channelname 行会更改输出通道的名称。
  • knob - 是旋转滑块，类似许多硬件界面上的电位器。define Table DAT 可让你指定旋钮的标签及其 lower_range 和 upper_range。
  • knobendless - 与 Knob 相同，但旋转不受限制，可以无限旋转。define Table DAT 可让你指定旋钮的标签及其 lower_range 和 upper_range。

按钮小工具

  • buttonmomentary - 是简单的瞬时按钮。define Table DAT 可让你指定按钮的标签，以及按钮上显示的文字「buttonlabel」。displaylabel 控制是否显示标签，labelwidth 设置标签宽度。channelname 行会更改输出通道的名称。
  • buttontoggle - 是简单的开关按钮。define Table DAT 可让你指定按钮的标签，以及按钮上显示的文字「buttonlabel」。displaylabel 控制是否显示标签，labelwidth 设置标签宽度。channelname 行会更改输出通道的名称。
  • buttonradio - 是单选按钮组。define Table DAT 可让你指定单选按钮组的标签，以及每个单选按钮各自的标签。displaylabel 控制是否显示标签，labelwidth 设置标签宽度。channelname 行会更改输出通道的名称。
  • radiogroup - 与 ButtonRadio 小工具相同，但设计不同。define Table DAT 可让你指定单选按钮组的标签，以及每个单选按钮各自的标签。displaylabel 控制是否显示标签，labelwidth 设置标签宽度。channelname 行会更改输出通道的名称。
  • button checkbox - 是复选框样式的简单开关按钮。define Table DAT 可让你指定标签，以及复选框旁显示的文字「buttonlabel」。displaylabel 控制是否显示标签，labelwidth 设置标签宽度。channelname 行会更改输出通道的名称。
  • button symbol - 与 buttonmomentary 小工具相同，但按钮面上使用符号而非文字。

数值字段小工具

  • valuefield - 是字段小工具。define Table DAT 可让你定义字段的标签及其格式。格式可为「float」、「integer」或「string」。displaylabel 控制是否显示标签，labelwidth 设置标签宽度。
  • stringfield - 与「ValueField」小工具相同，只是 define Table DAT 的 format 选项设为「string」。
  • stringfieldexec - 与「StringField」相同，但带有一个按钮，松开该按钮后可运行连接到 In DAT 的脚本。

取色器小工具

  • colorpicker - 是圆形 HSV 取色器。它以 HSV 和 RGB 格式返回所选取的值。
  • colorpickerhsv - 是矩形 HSV 取色器。它以 HSV 和 RGB 格式返回所选取的值。
  • sliderhsv - 是水平 HSV 取色器，每个值对应一个滑动旋钮。它以 HSV 格式返回所选取的值。
  • slider3hsv - 与 sliderhsv 相同，但每个颜色值都有独立的滑块。
  • sliderrgb - 是水平 RGB 取色器，每个值对应一个滑动旋钮。它以 RGB 格式返回所选取的值。
  • slider3rgb - 与 sliderrgb 相同，但每个颜色值都有独立的滑块。

列表小工具

  • dropdownlist - 是按钮列表小工具，所有可用按钮都隐藏在下拉列表中。用鼠标左键点击文本框，或点击其旁的箭头按钮，即可打开下拉列表。该小工具的第一个输入是条目列表，第二个输入是选中某个列表项后要执行的脚本。define Table DAT 可让你指定 DropdownList 的标签。displaylabel 控制是否显示标签，labelwidth 设置标签宽度。listitems 可让你指定下拉列表应有多少个按钮。
  • dropdownbtn - 是类似 dropdownlist 的小工具，但不显示所选的值，只有一个用于打开下拉列表的按钮。
  • fieldlist - 是可由用户填写的字段列表。它附带一个名为 rename 的脚本，用户可在其中指定字段更改后要执行的操作。
  • list - 是按钮列表小工具，可选择重新排列其内容。该小工具的输入是条目列表。第一个输出是重排后的列表，第二个输出是选中的按钮。调整小工具的高度可控制显示多少个按钮。define Table DAT 可让你指定 ButtonList 的标签。若 define Table DAT 中的 reorder 设为 1，则启用重排按钮。

文本字段小工具

  • textarea - 以 Text DAT 为输入并显示它，需要时添加滚动条。
  • textareafixed - 以 Text DAT 为输入，但只显示 define Table DAT 中定义的行数。
