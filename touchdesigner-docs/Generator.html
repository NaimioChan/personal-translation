Generator

在 TouchDesigner 中，不需要连接任何输入（就能产生有意义输出）的操作符称为 Generator，例如 Pattern CHOP。“输入”既指来自其他操作符的 wires，也指 OP 参数中指向其他操作符的 OP References。

Generator 是 OP Create Dialog 中颜色较深的操作符。

请参阅与它们对应的 Filters。

操作符可以拥有由 Parameters 定义的输入，这些输入是 Path 引用，可来自任何 Operator Family。
