Lookup CHOP

摘要

Lookup CHOP 从查找表输出值。第一个输入（Index Channel）是第二个输入（Lookup Table）的索引。Lookup 从查找表输出插值后的值。

Index 和 Lookup Table 都可以包含任意数量的通道。

值为 0 的索引采样映射到查找表的开头（第一个采样），值为 1 的索引采样映射到查找表的末尾（最后一个采样）。

输出 CHOP 的长度与 Index 输入相同。其通道数与 Lookup Table 输入相同，通道名也与 Lookup Table 输入相同。输出中填入从查找表提取的数据。落在两个查找表采样之间的索引会进行插值。可在查找表范围之外采样。

注意：当索引小于 0 或大于 1 时，会使用查找表的 Extend Conditions。

输出的采样率是 Index 输入的采样率。

Lookup CHOP 可用于从颜色查找表取值，其中一个索引产生红、绿、蓝通道。它也可用于滚降或衰减表，用于指定参数随距离下降的程度。

参数 - Lookup 页

Index Range index - - Index Range 把索引通道的值映射到查找表的起点和终点，默认为 0 和 1。第一个参数代表查找表的起点。当索引通道为该值时，它将索引查找表的起点。第二个参数代表查找表的终点，行为相同。
  • index1 -
  • index2 -
Cyclic Range cyclic - - 为循环或非循环输入索引调整 Lookup Table（第二个输入）的范围。使用循环输入索引（第一个输入）时，索引 0.0 和 1.0 的查找值结果相同。为避免这一点，将 Cyclic Range 设为 Yes，查找将平滑循环。
  • Automatic auto - 检查每个通道的右侧 extend 条件（假定 type 为 cycle 和 mirror 的是循环查找）。
  • Yes yes - 用于查找循环输出（振荡器、节拍驱动的输出等）。
  • No no - 用于查找单个波形（滑块映射等）。
Per Index Channel chanmatch - - 决定索引通道如何映射到查找通道表。
  • One Lookup Table Channel onetoone - 第一个索引通道匹配到完整查找表。
  • All Lookup Table Channels onetomany - 每个索引通道都与每个查找表匹配。
Match by match - - 决定在 'One Lookup Table Channel' 模式下索引通道如何与查找通道匹配。
  • Channel Number index - 索引通道按其在剪辑中的索引与查找表匹配。若查找表数量少于索引通道，查找表会循环使用。
  • Channel Name name - 索引通道按名称与查找表匹配。未匹配的索引通道保持「原样」。
Interpolate interp - 开启时，输入可在采样之间插值。关闭时使用最近的采样。
Extend Left left - - 查找输出的左延伸条件（范围之前/之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道起点之前的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常数值
Extend Right right - - 查找输出的右延伸条件（范围之前/之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道终点之后的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常数值
Default Value defval - 用于 Default Value extend 条件的值。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Lookup CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
