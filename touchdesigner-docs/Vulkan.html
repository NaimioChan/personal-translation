Vulkan

TouchDesigner 的图形 API 现在是Vulkan。macOS使用MoltenVK，这是一个可移植性项目，让 Vulkan 能运行在 Apple 的 Metal 框架之上。

为何选择 Vulkan？

TouchDesigner 转向 Vulkan，既是为了确保面向未来，也是为了降低 OpenGL 现有的驱动开销。转向 Vulkan 后，由于驱动开销更低，许多 TOP 操作的 CPU 计算时间应该会更短。此外，视频 I/O 等许多操作可以进一步线程化以提升性能。线程化能力也为将来做好了准备——届时节点的计算也能以更线程化的方式进行。

在 macOS 方面，以 Vulkan 为目标意味着我们可以使用 MoltenVK，也就是说实际的图形调用由 Metal 完成。这确保我们与 Apple 正在投入资源的 API 保持同步。唯一的缺点是 Metal 不支持几何着色器，因此在 macOS 上，所有 GPU 的几何着色器现在都完全没有了。通过在底层使用 Metal，我们终于可以在所有平台上安全地使用计算着色器，从而开始在 TouchDesigner 内的操作中更多地使用它们。这让 macOS 上开箱即用 NotchLC 编码/解码等功能成为可能。

Vulkan 将迎来许多跨厂商扩展，例如 Vulkan Video，它让我们能用单一的 API 利用所有 GPU 的视频编码/解码芯片。这将消除我们目前仅限 Nvidia 硬件编解码的限制。不过这项工作尚未完成。

我们希望在未来带来的另一项令人兴奋的功能，是直接驱动 GPU 输出，而无需它们成为桌面的一部分。这将避免桌面合成器造成的许多问题，以及演出输出与 UI 输出之间 EDID 混淆的问题。

Vulkan 对 HDR 色彩空间输出的支持也更好，这是未来可以期待的另一项功能。
