Script SOP

摘要

Script SOP 每次计算时运行 python 脚本。它可以创建、删除和修改点、图元及其顶点。它可以创建自定义属性或内置属性，例如 Cd（颜色）、uv 和 N（法线）。它可以添加多边形、贝塞尔曲线和网格等。它可以合并多个输入。默认情况下，Script SOP 创建时带有一个停靠的 DAT，其中包含三个 Python 方法：cook()、onPulse() 和 setupParameters()。每次 Script SOP 计算时会运行 cook() 方法。每当按下 Script 页上的 Setup Parameter 按钮时，会运行 setupParameters() 方法。每当推入自定义脉冲参数时，会运行 onPulse() 方法。

请参阅 Help → Python Examples 和 Help → Operator Snippets。

注意：由于 Script SOP 可以从任何地方获取数据，很难确定它在程序上依赖什么。因此每次任何 Script OP 运行时，都会列出它所依赖的操作符、参数、节点等，当它们发生变化时，Script OP 会重新计算。

参数 - Script 页

Callbacks DAT callbacks - 指定保存回调的 DAT。用法见 scriptSOP_Class。

操作符输入

  • Input 0: -

Info CHOP 通道

Script SOP 的额外信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
