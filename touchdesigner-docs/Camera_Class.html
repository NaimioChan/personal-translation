Camera 类

辅助类，用于维护摄像机的 3D 位置与朝向，并提供多种方法来操纵摄像机的位置和方向。此类用于 viewportCamera 调色板组件。

实例化器

TDU.Camera()→ TDU.Camera:

创建一个新的摄像机对象

成员

dir → tdu.Position :

以指向目标点的向量形式获取或设置摄像机的方向。向上方向视为 (0,1,0)。

pivot → tdu.Position :

获取或设置摄像机围绕或朝向旋转的空间 3D 点。

position → tdu.Position :

获取或设置摄像机所在的空间 3D 点。

方法

blendCamera(targetCamera, blendFactor)→ tdu.Camera:

返回一个使用 blendFactor 与给定摄像机混合后的摄像机。摄像机位置使用线性插值混合，旋转使用球面线性插值混合。

  • targetCamera - 作为混合目标的第二个摄像机。
  • blendfactor - 介于 0 和 1 之间的混合值。"

dolly()→ None:

使摄像机远离或靠近轴心点。

frameBounds()→ float:

设置摄像机以框住给定的边界盒。返回取景场景的宽度，可用于设置正交投影。

look()→ None:

让摄像机绕自身位置旋转。

move3D()→ None:

使用 3D 鼠标的数据移动摄像机。

pan()→ None:

在朝向轴心点的 2D 平面内平移摄像机。

setTransform()→ None:

设置摄像机视图矩阵。

track()→ None:

沿 Y 轴上下或左右移动摄像机。

transform()→ None:

获取摄像机视图矩阵。

tumble()→ None:

绕轴心点旋转摄像机。

walk()→ None:

在 ZX 平面内前后移动摄像机并绕其位置旋转。
