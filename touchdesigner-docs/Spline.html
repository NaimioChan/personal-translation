样条

TouchDesigner 允许你创建 Bézier 和 NURBS 曲线与曲面（不过在此讨论中，我们只涉及曲线）。样条曲线和多边形统称为「face」，而网格和样条曲面称为「hull」。与多边形类型不同，NURBS 和 Bézier 实体本质上是称为样条的光滑图元。不必掌握区分这两种样条类型的数学原理。但了解计算机生成曲线数学中产生的一些概念是有用的，因为它们会影响你在 TouchDesigner 中开始创作时对曲线类型的选择，也会影响你绘制曲线的方式。

线性样条

绘制曲线最直接的方式是连接一系列点。得到的曲线是线性样条，等同于多边形。这种生成曲线的方法有两个主要缺点。第一，要产生任何看起来真正弯曲的东西，你需要大量点。存储和计算所有这些点并不是对计算机资源的有效利用。第二，以这种方式创建的曲线操作起来非常笨拙，因为一旦移动一个点，就会破坏形状的光滑性。

高阶样条

解决线性连接产生的棱角问题的方法是通过一系列混合函数。混合函数（或称基函数）是在曲线控制顶点（CV）之间生成光滑连接的数学基础。样条曲线通过作用于这些点的数学混合函数，在其控制顶点之间生成光滑过渡。控制曲线的 CV 集合称为「hull」。

曲线段

TouchDesigner 中的 NURBS 和 Bézier 曲线是由若干相连曲线段组成的分段曲线。NURBS 与 Bézier 曲线的主要区别在于曲线段相接处的连续性水平。NURBS 曲线在这些接点处通常非常光滑（混合函数的阶数越高，连接越光滑）。Bézier 曲线每「阶数加一」个点就会出现一次不连续。

阶数

「阶数加一」的说法通常被称为曲线的 order（阶）。例如，三次曲线的 degree（次数）为三，因此 order 为四。

样条的 degree 由其底层混合函数的 degree 决定。TouchDesigner 支持 degree 从 1 到 10 的样条。上限是出于实用和效率的考虑而选定的。

你会发现三次样条对大多数应用来说足够光滑且表现良好。很少需要用到其他 degree。

断点、节点与样条基

曲线段汇合的点称为断点。需要强调的是，该断点在曲线本身上，而不是像构成 hull 的 CV 那样远离曲线。

断点是称为「knot」（节点）的特殊值在所谓参数空间或样条域中的映像。域就是一串升序排列的节点，它与样条 order 和样条类型一起定义样条基。

可以把曲线的域想象成从 0 到 1（或例如 -12.7 到 83.2）的线段，其大小和原点由两个端节点的值给出。

类似地，曲面由两个节点序列定义，形成一个矩形（U,V）域。节点序列必须始终按升序排列。

Relations of World Space and Domain Space

由于节点是域的构成要素，它们将曲线的域线段和曲面的域矩形划分为更小的片段，这些片段彼此之间的大小关系往往比域的总大小更重要。同样，在世界空间中，断点所界定的区域将曲线划分为曲线段，将曲面划分为面片。

根据样条类型的不同，在给定固定控制顶点集的情况下，节点之间的相对距离通常决定样条的形状。当把曲面的纹理空间与其参数空间对应起来时，域的大小和原点就有意义了。此时，如果纹理预期只覆盖整个曲面一次，曲面的域必须是单位正方形。将域映射到新的范围和原点不会影响样条图元的形状，因为节点比例保持不变。

节点在域中不必均匀分布。某一区域中的节点越多，样条段就越小，因此你对该区域的样条有更大程度的控制。如果多个节点放在同一个值上，就会产生所谓的重数（multiplicity）。并非所有样条类型都允许出现重数。

有理样条

TouchDesigner 支持两种有理样条：NURBS 和 Bézier。曲线的每个 CV 都有 X、Y 和 Z 坐标，决定其在世界空间中的位置。每个 CV 还有第四个分量，称为 W。W 分量决定 CV 的权重（另见：Point Weight (W)）。权重决定 CV 对样条曲线的「拉力」（像磁铁一样）。W 分量的值决定样条是有理还是非有理。非有理样条只有相同的权重（通常 W=1），而有理样条至少包含一个不同的权重。虽然非正权重（W 小于或等于零）在理论上说得通，但往往会产生不符合直觉的形状，并使样条脱离其凸包。出于实用考虑，TouchDesigner 只支持正权重（W > 0）。

CV 的权重越高，样条在该 CV 附近越尖锐。权重值很大时，样条几乎会穿过该 CV。同样，小于一的权重往往会使该 CV 影响区域内的样条变平。

不过，导致尖锐程度波动的并不只是权重的大小。同样重要（甚至更重要）的因素是权重之间的相对差异。相邻权重越接近，它们对给定区域的影响越小，因而样条越接近非有理。例如，如果一条样条曲线的所有权重都是一千，曲线的形状将与非有理曲线完全相同。

在 TouchDesigner 中，某些模型（如完美的 NURBS 圆）通常以有理方式构建。虽然你可以在建模器及其他地方自行创建有理模型，但我们建议谨慎使用权重，因为它们会增加模型的复杂度（可能导致系统性能下降），而且应用到相邻曲线区域时也可能失去效果。

在 TouchDesigner 支持的样条类型中，NURBS 曲线能让你对曲线的局部区域及其光滑度有更大程度的控制。

NURBS 曲线与曲面

NURBS 是 Non-Uniform Rational B-Spline（非均匀有理 B 样条）的缩写。NURBS 曲线使用一系列称为「基」的混合函数，从定义 NURBS hull 的控制顶点（CV）序列生成光滑曲线。

使用 NURBS 曲线的主要优势在于，移动一个 CV 只影响样条的局部区域，同时保持曲线的连续性，即使在断点处也是如此。这让你可以「拉扯」NURBS 曲线或曲面的 CV 来生成所需形状，而不会产生折角或不连续。

NURBS 曲线的形状受其节点之间相对距离的很大影响。节点按升序出现，并且可能重复。重复的节点称为具有重数。

在 Bézier 曲线中，所有节点都是唯一的，因此不会产生重数。Bézier 与 NURBS 节点之间的对应关系是：Bézier 节点类似于具有最大重数的 NURBS 节点。前面提到的 Bézier 不连续就发生在这些节点处。同样，NURBS 曲线在节点达到最大重数处也会出现不连续。当某节点在 NURBS 基中重复 degree 次时，即达到最大重数。NURBS 和 Bézier 曲线在不连续点处都会有一个 CV 位于曲线上。

如果重数出现在曲线的端点，则该 NURBS 曲线被视为「clamped」（钳制）。通常，NURBS 曲线两端都是钳制的，但闭合曲线通常不钳制；Bézier 曲线则始终是钳制的。

由此可知，在给定一组 CV 的情况下，NURBS 曲线的形状由节点之间的相对距离决定。通常有两种节点参数化类型：均匀和弧长。第一种中节点均匀分布。第二种中，节点之间的距离由相邻 CV 之间的距离决定。规则形状推荐使用均匀参数化，自由形状则使用弧长。第三种参数化称为「向心」，与弧长类似，最适合尖锐的曲线。

在 NURBS 曲线中创建尖锐点

有时希望沿 NURBS 曲线模拟不连续（一个尖角点）。这可以通过以下三种方式之一实现：

  1. 在 SOP Editor 中通过 Curve > Parameters 对话框，将所选 CV 的权重改为很大的值，例如 10,000。这会给该 CV 极大的「拉力」，使曲线几乎正好穿过它。
  2. 如果将三次曲线的两个相邻 CV 拖到中间某个 CV 上，它看起来就会像一个尖角点。这样做称为提高该 CV 的重数。当相邻的「degree」个 CV 重叠时，即达到最大 CV 重数。
  3. 使「degree」个节点完全相同。这样做称为提高节点的重数。你可以在 Refine SOP 中选择 Subdivision 选项来完成，也可以在 Model Editor 中选择 Refine 状态并用鼠标中键划分。
钳制与非钳制的 NURBS 曲线

clamped 曲线会经过其端点，unclamped 曲线则不会。多数情况下你使用的都是 clamped 曲线。unclamped 情况通常对闭合曲线有用。

在 TouchDesigner 中，你可以构建闭合的 NURBS 曲线，它们可以是 clamped 或 unclamped 的（见下文）。闭合的 clamped 曲线会在两个端点相接处显示出不连续。

周期曲线

闭合的 unclamped 曲线会自身环绕，被称为周期曲线，因为环绕部分的节点实际上是原始节点的循环重复。把周期 NURBS 曲线保存到文件时，周期节点不会被保存，而是在加载文件时自动生成。

NURBS 曲面

NURBS 曲面的拓扑类似于 Mesh 图元。在 NURBS 曲面中，UV 坐标矩阵的每个节点代表一个 CV，它们由行和列连接构成 NURBS 外壳。这样可以建模复杂的平滑曲面，只需移动 CV 即可改变其形状。

提示： 要创建开放的 cubic NURBS 曲面，至少需要 4 x 4 个 CV。一般而言，U Order 为 m、V Order 为 n 的开放曲面需要 m x n 个 CV。对于 order 为 m 的开放 NURBS 曲线，至少需要 m 个 CV 才能正确定义。

Bezier 曲线与曲面

Bézier 与 NURBS 类似，但它们总是经过外壳的端点（即 clamped），也可能经过中间的 CV（取决于 CV 总数和曲线的 order）。Bézier 与 NURBS 的主要区别在于，Bézier 按曲线 order 的固定间隔存在不连续（在曲线上看起来可能是一个尖点）。

在 SOP Editor 中，通过 Curve State > Parameters 对话框设置曲线的 order。

例如，如果曲线的 order 为 4，则 degree 等于 3，意味着每个曲线跨度内有四个 CV。每个跨度之间都会有一个不连续处。order 为四的曲线通常被称为「cubic」。

NURBS 曲线移动控制点时只会改变曲线的局部，而在 Bézier 曲线中，移动属于某个跨度的控制点时，该跨度整体都会受影响。

如果把曲线的 order 设为 2 这样的低值，则 Bézier 的每个跨度只在一个 CV 之间，看起来像直线。因此 order 设为 2 会得到一条看起来像多边形（由直线段组成）的曲线。这种曲线称为「linear」。

Bezier 曲面

Bézier 曲面的拓扑类似于 Mesh。在 Bézier 曲面中，UV 坐标矩阵的每个节点代表一个 CV，它们由 Bézier 外壳的行和列连接。这样可以建模复杂的平滑曲面，只需移动 CV 即可改变其形状。

注意： 开放的 Bézier 曲面只能用等于 order-1 的倍数加一的 UV 数量来构建。例如，对于 order 4 的曲线，U 或 V 的数量可以等于 4、7、10、13、16 等，因为如果 order 是 4，就取 order-1（=3）乘以跨度数再加 1，如下：4=(1*3)+1、7=(2*3)+1、10=(3*3)+1、13=(4*3)+1、16=(5*3)+1。如果 Bézier 曲面在 U 和/或 V 方向上是 wrapped 的，上面的公式就丢掉那个「+1」。

曲面上的曲线（轮廓曲线或修剪曲线）

TouchDesigner 支持曲面上的曲线（也称为 trim 曲线和 profile 曲线，简称 profiles），它们定义在父曲面的参数空间（即 domain）大小之内并受其约束。

Types of Profiles

TouchDesigner 中有三种 profile：多边形、NURBS 曲线和 Bézier 曲线。每种 profile 类型的定义与其 3D 对应类型非常相似。例如，NURBS profile 可以是开放或闭合的、clamped 或 unclamped 的、有理或非有理的，其 order 可以在 2 到 10 之间变化。profile 与 3D 面的根本区别在于，profile 是 2D 曲线，其 CV 是父曲面 domain 中的 (U, V, W) 点；3D 面的 CV 则是对象空间中的 X、Y、Z、W 四元组。对这两种面而言，W 都是有理分量（W=1 即非有理情况）。

Visual Properties

因此，profile 的可视化表示就是一条始终粘附在曲面上的曲线。我们看到的 3D 形状只是构成 profile 的 2D 几何在曲面上的映像。这意味着曲面形状改变时，曲面上的 profile 映像会随之改变；也意味着 profile 的任何部分都无法脱离曲面。

如果整个 profile 或其中一部分超出曲面 domain 的边界，它就会变得不可见，因为曲面本身在该范围之外没有定义。不可见的 profile 仍然有效，可以重新带回视野。有关操作 profile 的方法，请参阅 Profile 和 Primitive SOP。

profile 曲线的一个常见用途是修剪，即保留或移除 profile 围住的曲面部分（见 Trim SOP）。这也是 profile 曲线有时被称为 trim 曲线的原因。

Profile Numbering and Display

profile 在 TouchDesigner 中显示为虚线曲线。可以在 Display Options 对话框中点击 Accessories 页的 Profile Number 图标来显示其编号。profile 编号总是以其父曲面的图元编号为前缀。例如，「0.2」是 geo detail 中第一个图元的第三个 profile（编号从零开始）。

profile 可以与 3D 图元共存于图元组中。得到的混合组会这样指定其元素：「1 0.2 6 2.9-2.17 4.*」。
