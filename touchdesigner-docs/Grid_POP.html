Grid POP

摘要

Grid POP 在平面中创建成行成列的点，并可选地创建多个点切片，从而形成 3D 网格。可以使用 Connectivity 菜单用各种图元连接这些点。

网格尺寸由 X、Y 和 Z 指定，但可以使用 Rotate 参数把网格后旋转到任意角度，并使用 Translate 参数平移。Columns 指 X 方向的分段，Rows 指 Y 方向的分段，Slices 指 Z 方向的分段（旋转前）。

Connectivity 让你选择输出的图元及其组织方式。你可以输出三角形、四边形、线、线带、点图元，或者不输出图元（只有点）。使用 Line 开关，可以在 X、Y 和/或 Z 方向生成线和线带。使用 Plane 开关，可以在 XY、YZ 和/或 ZX 平面生成三角形和四边形。

Randomize 参数会把每个点随机化到其所在单元格内的位置，你可以把单元格想象成点周围、直到相邻单元格之前的盒子。当 Randomize 设为 1 时这尤其有用，它能保证每个单元格中恰好有一个均匀随机分布在单元格内的点，并且没有点落到别的单元格里，否则这很难保证。Random Size Fit 会把随机化后的网格放进原始未随机化网格的边界内，或者放进比原始未随机化网格大一个单元格的空间内。

Anchor 会把网格的左侧、中心或右侧对齐到 X=0。Y 和 Z 同理。

Dimension：当网格传递给其他 POP 时，无法确切知道 Grid POP 中指定了多少行、列和切片。不过网格（及其他生成器 POP）会把它的 Dimensions 输出到所有连接到它的 POP。Dimension 是了解点列表中点的组织方式的有力指标。2D 网格的 dimension 为 numCols numRows，3D 网格的 dimension 为 numCols NumRows numSlices。每个 POP 都会输出其 dimension，内置属性如 _Dim[] 可以使用它。Append Dimension 菜单让你能更多地控制输出 dimension 的形式。

你可以输出点、顶点或图元法线（N 属性），也可以输出点或顶点纹理坐标（Tex 属性）。

Grid POP 可以接收一个输入，这会使起始网格的包围盒与输入的包围盒相同。然后打开 Modify Bounds 可以进一步变换网格。

你可以打开 Unique Points，使每个图元的每个顶点都使用独立的点（不共享点）。但此时网格的 Dimension 会丢失——dimension 只是 numPoints。

另请参阅 Dimension、Sphere POP、Tube POP、Torus POP、Line POP

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
