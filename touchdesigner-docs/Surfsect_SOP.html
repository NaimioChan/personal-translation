Surfsect SOP

摘要

Surfsect SOP 对 NURBS 和 Bezier 曲面执行布尔运算，或只生成曲面相交处的 profile。单个曲面不必是实体（即在 U 和 V 方向闭合），也不必作为一组构成实体（例如你可以用球体切割网格）。

第一输入中的曲面在参数列表中记为「A」，第二输入中的曲面记为「B」。整个 A 集合与 B 集合求交，从而可以对样条曲面做真正的 csg 运算。因此，如果 A 构成实体、B 构成实体，A 与 B 之间的任何布尔运算都会产生实体。如果任一集合的拓扑是开放的，结果也同样是开放的。

修剪区域的内外判定取决于曲面法线的方向。如有必要，可以用 Primitive SOP 反转曲面的 U 或 V 方向来反转曲面法线。

surfsectSOP_Class

参数 - 页

Group A groupa - NURBS 和 Bezier 曲面的子集。接受模式匹配，如 Pattern Matching 所述。
Group B groupb - 要与 A 求交的 NURBS 和 Bezier 曲面子集。接受模式匹配，如 Pattern Matching 所述。
3D Tolerance tol3d - 相交运算的世界空间精度。
2D Tolerance tol2d - 相交运算的 domain 精度。
Marching Steps step - 追踪每个 profile 跨度的步数。

参数 - Boolean 页

启用 A 与 B 中曲面之间的布尔运算：

Operation boolop - 从以下运算中选择：Union、Intersect、A-B、B-A 或 User-defined。

如果 Operation 设为 User-defined，则以下选项可用：

  • Union union -
  • Intersect intersect -
  • A minus B aminusb -
  • B minus A bminusa -
  • User Defined: other -
Keep Inside A insidea - 保留 A 曲面的内部部分。
Keep Inside B insideb - 保留 B 曲面的内部部分。
Keep Outside A outsidea - 保留 A 曲面的外部部分。
Keep Outside B outsideb - 保留 B 曲面的外部部分。

参数 - Generate Profiles 页

只在曲面相交处创建 profile。

Target target - 为哪个曲面输出 profile：A、B 或两者。
  • A a -
  • B b -
  • A and B both -
A Profiles Group creategroupa - 把 A 的 profile 放入用户定义的组。
profilesa - 分配给 profile 组 A 的名称。
B Profiles Group creategroupb - 把 B 的 profile 放入用户定义的组。
profilesb - 分配给 profile 组 B 的名称。
Avoid Already Trimmed-Out Parts mindholes - 只对可见的曲面部分求交，并在修剪后的曲面边界处截断交线 profile。
Join Profiles Created by Multiple Surfaces join - 如果某个曲面因与两个或更多曲面相交而出现多段相邻 profile，这些 profile 会合并成一条 curve-on-surface。

Info CHOP 通道

Surfsect SOP 的额外信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
