Sprinkle POP

摘要

Sprinkle POP 在输入 POP 的表面或体积内创建点。

你根据 Method 菜单创建点。Per Primitive 方法在图元（三角形或四边形）表面创建点，它让每个图元的点分布大致恒定，与其大小无关。（目前还没有按面积恒定的表面点创建方法。）Volume 方法在闭合体积内随机创建点。（如果体积不闭合，结果会有一些近似。）

Number of Points 参数是一个近似上限值，Volume (Deterministic) 方法会产生更精确的点数（TBD）。

默认情况下，它每创建一个点，也会创建一个 Point Primitive。后者在直接渲染点时很有用，但其他用途（比如往每个点上复制）可能不需要。如果不需要图元、只想要点列表并希望节省内存，可关闭 Create Point Primitives。

在 volume 模式下它可以使用 Hardware Ray Tracing（仅用于点生成，不用于输入属性插值）。

另请参阅 Point Generator POP、Random POP

Info CHOP 通道

Sprinkle POP 的额外信息可通过 Info CHOP 获取。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
