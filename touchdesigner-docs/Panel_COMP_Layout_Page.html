Panel COMP 布局页

参数 - Layout 页

Layout 参数页控制面板的大小和位置。

X x - 指定相对于父级的水平位置，以像素为单位。

Y y - 指定相对于父级的垂直位置，以像素为单位。

Width w - 指定面板的宽度，以像素为单位。

Height h - 指定面板的高度，以像素为单位。

Fixed Aspect fixedaspect - 便于创建具有特定宽高比的面板，宽高比在下方 Aspect Ratio 参数中设置。只需设置面板的宽度或高度，另一维度会根据 Aspect Ratio 参数计算。

Aspect Ratio aspect - 使用上方 Fixed Aspect 参数时指定比例，比例为 width/height。

Depth Layer layer - 指定面板组件的绘制顺序，类似 Photoshop 中的图层。数值越高，会绘制在任何数值更低（且处于同一层级）的面板之上。若两个面板组件的 Depth Layer 值相同，则按操作符名称排序。


Horizontal Mode hmode - 从 3 种模式中选择一种，决定面板的水平宽度。

  • Fixed Width - 使用上方 Width 参数设置此面板的宽度，以像素为单位。
  • Fill - 此面板的宽度将匹配（填满）父面板的宽度。
  • Anchors - 此面板的宽度由下方的 Left Anchor 和 Right Anchor 参数设置，父面板尺寸变化时会保持相对父面板的宽度。这使面板可以拉伸。这些锚点参数像 uv 坐标一样归一化为 0-1，0 为父面板左边缘，1 为父面板右边缘。例如 Left Anchor = 0.2、Right Anchor = 0.8 会按比例保持宽度，使左边缘距离左侧 20%（0.2），右边缘距离右侧 20%（0.8）。

Left Anchor leftanchor - 面板左锚点相对父级的位置。此值归一化为 0-1，0 为父级左边缘，1 为父级右边缘。

Left Offset leftoffset - 左锚点的偏移，以像素为单位。

Right Anchor rightanchor - 面板右锚点相对父级的位置。此值归一化为 0-1，0 为父级左边缘，1 为父级右边缘。

Right Offset rightoffset - 右锚点的偏移，以像素为单位。

Horizontal origin horigin - 水平设置面板原点的位置。默认原点 (0,0) 为面板左下角。

Horizontal Fill Weight hfillweight - 当多个面板使用 Horizontal Mode = Fill，且由父级按 Left to Right 或 Right to Left 对齐时，可用此填充权重参数调整面板填充宽度的偏向。


Vertical Mode vmode - 从 3 种模式中选择一种，决定面板的垂直高度。

  • Fixed Height - 使用上方 Height 参数设置此面板的高度，以像素为单位。
  • Fill - 此面板的高度将匹配（填满）父面板的高度。
  • Anchors - 此面板的高度由下方的 Bottom Anchor 和 Top Anchor 参数设置，父面板尺寸变化时会保持相对父面板的高度。这使面板可以拉伸。这些锚点参数像 uv 坐标一样归一化为 0-1，0 为父面板下边缘，1 为父面板上边缘。例如 Bottom Anchor = 0.3、Right Anchor = 0.5 会按比例保持高度，使下边缘距离底部 30%（0.3），上边缘距离顶部 50%（0.5）。

Bottom Anchor bottomanchor - 面板下锚点相对父级的位置。此值归一化为 0-1，0 为父级下边缘，1 为父级上边缘。

Bottom Offset bottomoffset - 下锚点的偏移，以像素为单位。

Top Anchor topanchor - 面板上锚点相对父级的位置。此值归一化为 0-1，0 为父级下边缘，1 为父级上边缘。

Top Offset topoffset - 上锚点的偏移，以像素为单位。

Vertical origin vorigin - 垂直设置面板原点的位置。默认原点 (0,0) 为面板左下角。

Vertical Fill Weight vfillweight - 当多个面板使用 Vertical Mode = Fill，且由父级按 Top to Bottom 或 Bottom to Top 对齐时，可用此填充权重参数调整面板填充高度的偏向。


Parent Alignment alignallow - 设为 Ignore 时，面板会忽略父级的所有 Align 参数设置。

  • Allow - 根据父级中的设置对齐面板。
  • Ignore - 不对齐面板，但遵守边距。
  • Ignore and Margins - 不对齐面板，并忽略边距。

Align Order alignorder - 当父级的 Align 参数设为 None 或 Match Network Nodes 以外的值时，此参数可让你指定对齐位置。数字越小越靠前。

Post Offset postoffset[xy] - 在所有其他位置和对齐选项应用于面板之后，再添加一个偏移。

Size From Window stufffromwindow - 启用时，面板组件的宽度和高度通过调整其浮动查看器窗口的大小来设置。
