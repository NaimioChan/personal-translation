DAT Execute DAT

摘要

DAT Execute DAT 监视另一个 DAT 的内容，并在内容变化时运行脚本。另一个 DAT 通常是表格。

DAT Execute DAT 用 default python method placeholders 创建。对于参数中每个被监视的条件，DAT 中都有一个对应的 python 方法。当某个条件在参数中开启时，每次满足该条件都会执行对应的 python 方法。

Note for 2025.30000 and later builds - 新的 onTableChange 方法现已完成所有工作，其余 4 个旧方法（onRowChange、onColChange、onCellChange 和 onSizeChange）已弃用。 从旧版本加载的 DAT Execute DAT 不会包含新的 onTableChange 回调的更新用法注释。你可以在网络中新建一个 DAT Execute DAT，或从下面的代码片段中获取这些信息。

参数 - DAT Execute 页

Active active - 开启时，DAT 会响应所引用的 CHOP。
Execute from executeloc - - （仅 Tscript）决定脚本运行的位置。
  • Current Node current - （仅 Tscript）脚本从当前节点位置执行。
  • This Node here - 脚本从 DAT 的父级执行。DAT 从父级执行是为了便于访问 DAT 的同级：过去 DAT 脚本是从 DAT 内部执行的。
  • Specified Operator op - 脚本从下方 From Operator 参数指定的操作符中执行。
From Operator fromop - （仅 Tscript）当 Execute From 参数设为 Specified Operator 时，脚本将从该路径执行。
DAT dat - 被监视的 DAT，其内容变化时会触发脚本执行。
Table Change tablechange - 如果自上次计算以来表格有任何变化，就会调用 onTableChange() 方法。
Row Change rowchange - 已弃用，请改用 onTableChange()。对于（自上次计算以来）发生变化的每一行，都会调用一次 onRowChange() 方法。
Column Change colchange - 已弃用，请改用 onTableChange()。对于（自上次计算以来）发生变化的每一列，都会调用一次 onColChange() 方法。
Cell Change cellchange - 已弃用，请改用 onTableChange()。对于自上次计算以来发生变化的每个单元格，都会调用 onCellChange() 方法。
Size Change sizechange - 已弃用，请改用 onTableChange()。对于自上次计算以来的每次表格尺寸变化，都会调用 onSizeChange() 方法。
Execute execute - - 决定方法是在帧开始还是帧结束时执行。
  • Start of Frame start - 该方法会在帧开始时调用。如果一帧内某行变化了 4 次，该方法也会运行 4 次（例如对 Multi Touch In DAT 事件很有用）。
  • End of Frame end - 该方法每帧最多执行一次，在帧结束时执行，即使它在一帧内被触发多次。例如，如果 Monitor 设为 Row，某行在一帧内可能变化多次，但每行只会被调用一次。
Edit.. edit - 点击后打开文本编辑器，以编辑 DAT 中的文本。

参数 - File 页

File file - 要加载的文件的文件系统路径和名称。接受 .txt 和 .dat 文件。
Sync to File syncfile - 开启时，在项目启动时将文件从磁盘加载到 DAT 中。必须指定文件名。开启该选项会立即从磁盘加载文件。如果文件不存在，则在 DAT 第一次更新时创建它。系统会监视该文件，对文件的任何改动都会更新 DAT，而对 DAT 的任何改动都会立即写入文件。如果文件被移除，DAT 将保留其当前内容。
Load on Start loadonstart - 开启时，项目启动时从磁盘重新加载文件到 DAT 中。
Load File loadonstartpulse - 立即重新加载文件。
Write on Toe Save write - 开启时，保存项目时将 DAT 的内容写入磁盘文件。
Write File writepulse - 立即将文件写入磁盘。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

DAT Execute DAT 的额外信息可通过 Info CHOP 查看。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
