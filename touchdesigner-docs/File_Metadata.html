文件元数据


Movie File Out TOP 和 Audio File Out CHOP 允许用户提供一个 Table DAT，包含要写入文件的元数据键值对。类似地，Movie File In TOP、Audio File In CHOP 和 Media File Info DAT 可以读入这些元数据。以下是元数据表的有效键值列表。

文件元数据

音频文件输出格式

  • OGG：支持以 VorbisComment 存储的任意键值对
  • MP3：支持存储在其 ID3v2 标签中的元数据
  • AIFF：支持存储在其 INFO 块中的元数据
  • WAV：支持以 RIFF 格式存储的元数据

影片文件输出格式

  • VP8/VP9：在其 Tag Directory 中支持任意键值对
  • 影片格式支持以下内容
支持的标签
artist title author date
comment description genre copyright
  • OpenEXR 支持任意键值对
  • TIFF 支持 Exif 元数据
  • JPEG 支持 Exif 元数据
  • PNG 支持 Exif 元数据

Exif 元数据

  • JPEG 和 PNG 使用 libexif 生成 Exif 数据，并在录制时插入到其相应的头部。Supported tags
  • TIFF 使用 libtiff 管理其 Exif 写入。Supported tags
  • 支持多个分量的标签可以在一个条目中用逗号分隔指定各分量。即 43,39,52.44
