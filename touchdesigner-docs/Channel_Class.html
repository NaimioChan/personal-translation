Channel 类

Channel 对象描述来自 CHOP 的单个 channel。CHOP Class 提供多种访问各个通道的方式。 有关此类的更多用法示例，请参阅 Working with CHOPs in Python。

成员

valid → bool (Read Only):

若引用的通道值当前存在则为 True，若已被删除则为 False。

index → int (Read Only):

通道的数字索引。

name → str (Read Only):

通道的名称。

owner → OP (Read Only):

此对象所属的 OP。

exports → list (Read Only):

此通道当前导出到的 parameters 列表（可能为空）。

vals → list :

获取或设置 Channel 值的完整列表。只能在 Script CHOP 中用 Python 修改 Channel 值。

方法

[index]→ float:

可以用 [] 下标运算符方便地访问 Channel 的采样值。

  • index - 必须是数字采样索引。不支持通配符。

要获取通道的第三个采样（假设该通道有 3 个或更多采样）： 

n = op('pattern1')
c = n['chan1'][2] # 第三个采样
l = len(n['chan2']) # 通道中的采样总数

eval(index)→ float:

在指定的采样索引处对通道求值。若未给出索引，则使用基于当前时间的当前索引。

  • index -（可选）要求值处的采样索引。

evalFrame(frame)→ float:

在指定的帧处对通道求值。若未给出帧，则使用当前帧。

  • frame -（可选）要求值处的帧。

evalSeconds(secs)→ float:

在指定的秒数处对通道求值。若未给出时间，则使用当前时间。

  • secs -（可选）要求值处的时间，单位为秒。

numpyArray()→ numpy.ndarray:

以 NumPy 数组形式返回此通道的数据，长度等于轨道长度。

destroy()→ None:

销毁并移除此对象所指的实际 Channel。仅当该通道属于 Script CHOP 或 OSC In CHOP 时此操作才有效。 注意：调用之后，此 CHOP 中其他已有的 Channel 对象可能不再有效。

average()→ float:

返回所有通道采样的平均值。

min()→ float:

返回所有通道采样的最小值。

max()→ float:

返回所有通道采样的最大值。

copyNumpyArray(numpyArray)→ None:

把 numpyArray 的内容复制到通道的采样值中。

  • numpyArray - 要复制的 NumPy 数组。形状必须为 shape(n)，其中 n 是该 CHOP 的采样长度。数据类型必须为 float32。只能在 Script CHOP 中用 Python 修改 Channel 值。

转换为值

Channel 类实现了被当作数字处理所需的全部方法，在此情况下即对其当前值求值。因此在参数或数值表达式中使用时，无需显式调用 eval()。

例如，以下写法在通道中等价： 

(float)n['chan1']
n['chan1'].eval()

以下写法也等价，因为 + 1 会隐式地把通道转换为数字： 

n['chan1'].eval() + 1
n['chan1'] + 1
