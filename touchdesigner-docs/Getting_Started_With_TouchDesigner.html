TouchDesigner 入门

确保你的电脑符合最低 System_Requirements，并准备一个三键鼠标。

在 Windows 上，更新电脑的显卡驱动，并应用所有可用的 Windows 更新。 在 macOS 上，更新到你的 macOS 版本中可用的最新更新，即如果你用的是 macOS 26，就更新到最新的 26.x.x。

要下载 TouchDesigner，请前往 Downloads

下载的同时，create an account，以便安装后获取密钥。

Install 并启动 TouchDesigner。

许可

启动 TouchDesigner，如果没有密钥，Key Manager Dialog 会自动打开。Create a key。

TouchDesigner Non-Commercial 可以（免费）用于个人和教育用途，包括演示和学习如何使用 TouchDesigner。

Educational、Commercial 和 Pro 许可证可从 store 获取，Licensing 页面说明了功能上的差异。

从哪里开始学习 TouchDesigner

查看官方 TouchDesigner Curriculum，了解基础入门。

Learn TouchDesigner 页面会介绍 TouchDesigner 的所有学习资料，包括教程、示例和文档。

如果你有兴趣参加工作坊学习 TouchDesigner，请查看 Workshops & Events。

对于想写代码的人，Python 是 TouchDesigner 的默认脚本语言。你可以从这里开始找到所有 Python 文档和参考资料：Python Reference。
