POP to DAT

摘要

POP to DAT 通过 Extract 菜单，将 POP 的点或图元转换为点表（每行一个点）、图元表（每行一个图元）或顶点表（每行一个顶点）。

在所有情况下，它都会为每个属性分量创建一列，Attributes 参数可让你选择要包含的特定属性。

Primitives 表有一列可选项，显示图元类型 - point、line、linestrip、triangle、quad。

Transpose 开关参数可让你转置表格（交换行与列），把所有属性名放到第一列，某些情况下更易阅读。

在不影响源数据的前提下，你可以精简显示的数据，例如限制在某个点索引范围内的点、每 N 个点显示 1 个，或随机精简数据。这使大型数据集更容易检查。

你也可以选择只显示位于特定 Groups 中的点或图元。

由于 POP 数据在 GPU 上而 DAT 表格在 CPU 上，GPU 到 CPU 的传输可能造成停顿。Download Type 默认为 Next Frame (Fast)，延迟最小，但 DAT 会晚一 Time Slice 显示。否则 Download Type 为 Immediate，可能在当前帧造成数毫秒的延迟。

另请参阅 DAT to POP、POP to CHOP、POP to TOP。

参数 - POP to 页

Active active - 启用时，DAT 会抓取并转换所引用 POP 的最新几何信息。禁用时，会保留上次转换的值。
POP pop - 要转换其数据的 POP。
Download Type downloadtype - - 提供从 GPU 延迟下载数据的选项，速度更快且不会阻塞渲染。
  • Immediate (Slow) immediate -
  • Next frame (Fast) nextframe -
Extract extract - 指定转换点、图元、顶点还是细节数据。
  • Points points - 转换点数据。
  • Vertices vertices - 转换顶点数据。
  • Primitives primitives - 转换图元数据。
  • Detail detail - 转换细节数据。
  • Dimensions dimensions - 转换维度数据。
Attributes attrib - 要转换的属性。
Primitive Type primitivetype - 启用时，添加一列显示图元类型：point、line、linestrip、triangle 或 quad。
Transpose transpose - 启用时把列转换为行。行数变为列数。
Thin Out Range thinoutrange - 启用基于索引的筛选。
Thin Range Start thinrangestart - 确定基于范围筛选的起始索引。
Thin Range Length thinrangelength - 确定按索引范围筛选的元素数量。
Thin Step thinstep - 筛选每第 N 个元素。
Thin Random thinrandom - 确定被随机筛选的元素比例。
Thin Random Seed thinrandomseed - 设置被随机筛选元素的随机种子。
Group group - 如果存在输入组，在此字段中指定组名将使该 POP 仅作用于指定的组。
Invert Group invertgroup - 如果存在输入组，且在 Group 参数中指定了组，则会使 POP 仅作用于不在指定组中的元素。
Group Columns grpcol - 当设为 None 以外的值时，会为每个组添加一列，获取该元素的组名。
  • None none -
  • Group Names in one Column onecolumn -
  • Column per Group colpergrp -

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

POP to DAT 的额外信息可通过 Info CHOP 获取。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
