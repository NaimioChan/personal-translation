Write a CPlusPlus TOP

概述

Make sure you've read through Write a CPlusPlus Plugin first for general information about writing a plugin for a CPlusPlus TOP.

CPlusPlus TOP 允许你编写 C++ 代码来创建一个可输出多个纹理的 TOP。目前你可以通过填充 CPU 内存缓冲区（TOP_ExecuteMode::CPUMem）或填充 cudaArray 缓冲区（TOP_ExecuteMode::CUDA）来创建输出。

大部分文档保存在 C++ API 的头文件中。示例中也包含大量关于工作流的注释。

若要将使用 TouchDesigner 2021.10000 及更早版本头文件编译的 CPlusPlus TOP 升级到 2022.20000 及之后版本中运行，请参阅 CPlusPlus TOP Upgrades For 2022.20000 Builds

CUDA

CPlusPlus TOP 可与 CUDA 一起使用。示例参见 TouchDesigner 安装包附带的 CudaTOP 示例项目。注意 C++ 代码中发生的任何 CUDA 操作都必须在主线程上、在 OP_Context::beginCUDAOperations() 和 OP_Context::endCUDAOperations() 调用之间进行。
