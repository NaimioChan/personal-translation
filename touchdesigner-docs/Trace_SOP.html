Trace SOP

摘要

Trace SOP 读取图像文件并自动描边，在超过一定亮度阈值的区域周围生成一组面。你可以控制该阈值以及所得面的分辨率。

traceSOP_Class

参数 - Trace 页

TOP Name top - 指定要描边的 TOP 图像。
Threshold thresh - 亮度级别值用于调整图像中描边轮廓出现的位置。
Add Point Texture addtexture - 此选项允许生成点纹理坐标（UV）。当启用 Convert to Poly 选项时，偶尔会需要这样做。
Remove Borders delborder - 启用后，此选项会消除原图像边缘的多余数据，使其不被描边。当原图像存在你不想描边的“脏”边缘时，这很有用。
Compute Normals normals - 在几何上创建法线。

参数 - Filters 页

Border Width bordwidth - 移除边界应以像素为单位的宽度。
Resample Shapes doresample - 决定生成描边轮廓的细化程度（点数）。
Step Size step - 勾选 Resample Shapes 时控制描边轮廓细化程度的值。
Smooth Shapes dosmooth - 勾选此选项后，会对几何进行过滤以去除尖角。
Corner Delta corner - 勾选 Smooth Shapes 时控制拐角平滑程度的值。
Fit to Curves fitcurve - 勾选后，此处的几何会转换为二维 Bzier 曲线。平直边缘在多边形中保留。
Fitting Error error - 控制上述曲线拟合过程精度的值。为获得最佳结果，输入应保留尽可能多的点，即不要勾选 Smooth Shapes 或 Resample Shapes。
Convert to Poly convpoly - 此选项会将上述曲线转换回多边形。
Level of Detail lod - 此值控制转换回多边形的精度。
Hole Faces hole - 这会桥接输出中的所有孔洞，使其能够被正确渲染。Bzier 曲线和多边形都可以开孔，但多边形开孔有时效果更好。你可能希望在开孔前使用 Convert to Poly 选项。

Info CHOP 通道

Trace SOP 的附加信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
