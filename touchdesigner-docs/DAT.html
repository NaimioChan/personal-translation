DAT

摘要

DAT 相关文章的完整列表参见 Category:DATs。

DATa Operators（或 DATs）用于保存文本数据，例如字符串、脚本和 XML。DAT 要么包含多行文本（如脚本），要么包含由行和列单元格组成的表格，每个单元格包含一个字符串。你可以直接在 DAT Viewer 中编辑 DAT 的内容。

用 op('text1').text 访问包含普通文本的 DAT。用 op('table1')[1,2] 或按行/列名 op('table1')['rowname', 'colname'] 访问包含表格的 DAT 中的单元格。

重要：op('table1')[1,2] 是一个 python cell object，通常会为你转换成单元格中的字符串。更安全的做法是使用 op('table1')[1,2].val，它总是返回字符串。

用于脚本的 DAT

DAT 可以连接在一起，以选择、重排和求值数据与表达式，使 DAT 成为强大的 procedural scripting tool。

包含脚本的 DAT 可以由鼠标单击等事件触发，也可以由 TouchDesigner 控制面板中任何小工具的操作触发。DAT 脚本还可以由 CHOP 中的通道变化触发。

Script Example：这会创建一个点击时播放声音的按钮：创建一个 Button 组件（Tab -> COMP -> Button）。进入其内部（Enter），创建一个 Audio Play CHOP（Tab -> CHOP -> Audio Play）。
然后创建一个 Panel Execute DAT（Tab -> DAT -> Panel Execute），并把它的 Viewer Active。然后在其查看器中点击，把 offToOn() 函数改为：
def offToOn(panelValue):
     op('audioplay1').par.trigger.pulse()
     return

在节点外单击以结束文本输入。按 u 返回上层，通过 Button 页和 Button Type 参数把按钮设为 Momentary 按钮。然后把按钮设为 Viewer Active。单击按钮的查看器，它应该会发出 Notify 声音。

你也可以在 Textport 或另一个 DAT 中用「run」命令运行 Text DAT 中的脚本。

用于表格的 DAT

DAT 表格是由包含文本字符串的单元格组成的行与列。

名为 Table DAT 的 DAT 用于定义新的表格。要手动增删表格的行和列，请在 Viewer Active 开启时在表格上右键单击，然后从菜单中选择。

随后这些表格由 Select DAT、Evaluate DAT、Merge DAT、Switch DAT、Sort DAT 等来操作。

你可以用表格 DAT 导出到参数。参见 DAT Export。

DAT 表格可以用 tabcell 命令修改。

表格单元格用 tab()、tabr()、tabc() 或 tabrc() 表达式读取。参见 Help 菜单中的 Commands and Expressions。

Table Example：这会创建两个带有名字的 TOP 图像：创建一个 Table DAT（Tab -> DAT -> Table）。把它的 Viewer Active。在查看器上右键单击，选择 Add Column，然后选 Add Row，再选 Add Row，这样应该会得到 3 行 2 列的空单元格（或在参数中填入 2 和 3）。
在左上角单元格中点击并输入 name，在右上角输入 age，然后在其余单元格中填入 joe、9、jane、21。
现在创建一个 Text TOP（Tab -> TOP -> Text），在名为 Text 的参数中输入此表达式，以从表格中取回一个单元格：`tabc("table1", $OD, "name")`。你应该会在 Text TOP 查看器中看到 "joe"。复制/粘贴该 Text TOP（Ctrl-C、Ctrl-V）。新 TOP 应名为 text2，其查看器应显示 "jane"。
这个 tabc() 表达式从表格 table1（即你编辑的节点）中获取。它取自名为 name 的列。行是 $OD，这是一个可在任意节点中使用的变量，表示「operator digits」，即操作符名称末尾的数字，这里对 text1 和 text2 分别是 1 和 2。
在 TOP 的表达式中，可以把 "name" 替换为 "age"。

用于处理 Web 和 XML 数据的 DAT

Web Client DAT 通过向互联网传递 URL 并接收响应来获取 HTML 或其他数据。结果和任何 XML 数据都可以用 XML DAT 过滤，再用其他 DAT 进一步处理。

用于原始文本的 DAT

DAT 也可以用来保存原始文本，供 Text TOP 和 Text SOP 在合成和 3D 中使用。它们还可以用来在网络中留下注释，或用作面板小工具的弹出帮助消息。

编辑 DAT

开启 Viewer Active Flag 后，可以直接在 DAT 的查看器中编辑 DAT。

你也可以在 Textport 中编辑 DAT：右键单击 DAT 并选择 Edit Contents in Textport。

某些 DAT 生成器和大多数 DAT 过滤器无法编辑，因为它们的数据来自输入。与可编辑的 DAT 相比，查看器中会用更淡的文字颜色来表示这一点。如果你需要临时编辑这些 DAT 之一的内容，可以用 Lock Flag 锁定该 DAT 后再编辑。不过，DAT 解锁后这些改动会丢失，而且锁定会使它无法 cooking，因此这通常只对排查和调试有用。

默认情况下，文本类 DAT 会在左侧边距显示行号，表格类 DAT 会显示行号和列号。这些数字的显示可以在 Preferences 中控制。

在外部编辑器中编辑 DAT 文本

在任何 DAT（或任何参数）中，如果右键单击 DAT 节点并选择 Edit Contents...，就会在外部编辑器中编辑该文本。记事本是 Windows 默认的文本编辑器。

要改用其他文本编辑器（如 Notepad++、Vim、Sublime 等），需要修改 Text Editor 和 Table Editor 首选项的值。这些首选项位于 Preferences 对话框的 DATs 页。请把它们的值设为要使用的编辑器可执行文件（.exe）的安装路径。例如 C:/Program Files ..。

每个人都有自己的偏好，可以看看 Sublime Text 2。

要了解如何设置环境变量，参见 Variables。
