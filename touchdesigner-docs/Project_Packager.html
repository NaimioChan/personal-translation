项目打包器

projectPackager 是一套脚本和工作流程，用于创建仅在 Windows 上使用的安装程序，它将 TouchDesigner 项目与必要的 TouchDesigner 程序文件打包成一个可分发的安装程序。对最终用户而言，结果看起来就像是一个已安装的应用程序。

根据 Derivative 的 [EULA] 第 15 条： 当被许可方希望将 Derivative 网站上提供的安装程序与被许可方自己的资产捆绑时，Licensee must first receive consent from Derivative by contacting Derivative at licensing@derivative.ca。被许可方同意：(i) 仍对二级被许可方的作为或不作为承担全部责任和义务，包括二级被许可方对本协议的遵守，以及 (ii) 必须并且将会向 Derivative 提供所要求的、关于被许可方预期如何使用 Project Packager 和 Packaged Product（定义见下文）的信息。

通用

你可以在 TouchDesigner 安装目录的 Sample 文件夹中找到所需文件。

TouchDesigner 在文件夹结构中是「隐藏」的，在程序项、开始菜单或桌面中没有任何引用。应当注意，安装程序制作者可以选择不安装某些文件，而这些文件是功能完整的 TouchDesigner 所必需的。因此，从项目的安装文件夹中使用 TouchDesigner，与运行原版安装版本并不相同。

虽然你可以完全自定义脚本，但移除显示 Derivative 许可证的对话框违反 Derivative 的条款与条件。当最终用户安装运行 TouchDesigner 的项目时，必须明确该项目的许可证，且最终用户也同意 Derivative 的许可证及条款与条件。

此外，需要注意的是，最终用户在 TouchDesigner 中运行项目时必须安装 TouchDesigner 许可证密钥。

TouchDesigner 使用 innoSetup 构建其 Windows 操作系统安装程序。

Inno Setup 是 Jordan Russell 和 Martijn Laan 为 Windows 程序提供的 free 安装程序。它于 1997 年首次推出，如今在功能集和稳定性上可与许多商业安装程序匹敌甚至超越。[1]

前提条件

此工作流程只会为 Windows 操作系统创建安装程序。

  • innoSetup

所需文件

  • 包含在单一文件夹结构中的 a TouchDesigner project。这意味着该项目可能使用的任何资产都必须位于与 TouchDesigner 项目文件相同的根文件夹下。创建者应确保对外部媒体和文件的所有引用都是相对路径。
  • a TouchDesigner Installer file，可从 derivative 下载。仅支持以 2022.xxxxx 开头的安装程序。
  • 项目的图标文件
  • 项目的许可证文件。[2]

可以选择许多不同的许可证类型。但重要的是要确保所选许可证与 Derivative 的许可证兼容。

大于 2.1 GB 的安装程序

默认情况下，安装程序总大小不能超过 2.1 GB。这是 Innosetup 的限制，可以通过设置 InnoSetup 指令来克服 

DiskSpanning=yes

启用磁盘跨卷后，安装程序不会把所有压缩文件数据都存入 SETUP.EXE，而是拆分为多个 SETUP-*.BIN 文件（称为「切片」），与一个 SETUP.EXE 并存

每个切片的大小和要创建的切片数量分别由 [Setup] 段的 DiskSliceSize 和 SlicesPerDisk 指令的值决定。你可能还想调整的其他磁盘跨卷相关指令包括 DiskClusterSize 和 ReserveBytes。

注意，如果安装的压缩后大小超过 2,100,000,000 字节，则必须将此指令设为 yes。

要把生成的文件作为单个 .exe 分发，可以使用 7zip 以及 ResourceHacker 创建自解压归档

有关如何创建自解压归档的进一步说明，请见下文。

说明

准备工作

  1. 从此处下载 InnoSetup：https://jrsoftware.org/isdl.php
  2. 安装 InnoSetup
  3. (optional) 使用 VisualStudio 之类的 IDE 时，安装「Inno Setup」扩展可能比较方便。[3] 此外，InnoSetup 和此安装脚本都使用 Pascal 脚本（现代类 Delphi 的 Pascal）。建议安装 Pascal 扩展以便开发。[4]
  4. 从 TouchDesigner 安装目录的 Sample 文件夹复制 ProjectPackager 文件夹
  5. 确保项目包含在单一的文件夹树中。

编译安装程序

要使用的脚本名为 projectPackager.iss。默认情况下，它是一个功能完整的安装程序构建器，编译时需要若干参数：

  • ProjectName：（required）项目和安装程序将使用的名称。
  • ProjectVersion：（optional，默认：1.0.0.1）此项目的版本号。
  • ProjectPublisher：（required）发布者（你或你的公司）的名称。
  • ProjectURL：（optional，默认：None）最终用户可从中了解项目信息的 URL。
  • ProjectIcon：（optional）与此项目关联的图标文件路径。
  • ProjectLicense：（optional，默认：None）包含本项目应采用许可证的 *.rtf 文件路径。若未指定，安装过程中显示的许可证将是 unlicense。
  • ProjectFolder：（required）要打包的项目的路径。
  • ProjectFile：（required）项目主 *.toe 文件的路径。
  • StartWithPlayer：（optional，默认：0）可选择项目应以 TouchPlayer（default）还是 TouchDesigner 启动。
  • TDInstallerLocation：（required）将与此项目一起打包的 TouchDesigner 安装程序的路径。
  • TDSkipFiles：（optional，默认：None）文本文件的路径，其中列出 TouchDesigner 安装目录中不应与此项目一起打包的文件。
  • InstallerIcon：（optional，默认：一个图标）指定自定义图标的路径，该图标将作为安装程序文件的图标。
  • OutputName：（optional，默认：ProjectName）指定安装程序文件的名称。
  • CodeMeter：（optional，默认：0）若设为 true，将在安装过程结束时安装 codemeter 运行时。
  • Sign：（optional，默认：0）如果机器上安装了代码签名证书，启用此项将尝试对安装程序签名。

所有这些参数都可以通过文件夹中附带的 projectPackager.ini 文件设置。

也可以选择通过命令行设置这些参数。

使用 projectPackager.ini 文件：

在终端中导航到仓库并运行： 

>ISCC.exe projectPackager.iss

使用命令行参数：

删除 projectPackager.ini 文件，然后在终端中导航到仓库并运行： 

>ISCC.exe /dProjectName="My Project" /dProjectVersion="1.0.0.2" projectPackager.iss
  • 注意每个参数都需要以 /d 开头
  • 还应注意，.ini 文件中的条目和命令行参数可以混用。命令行参数优先于 ini 文件条目。

减小安装程序体积

安装程序编译期间的 TDSkipFiles 命令行参数会跳过某些文件，不将它们包含在最终安装程序中。请参阅示例 [skipFiles.txt]，了解哪些文件对你的项目可能并不必要。

创建自解压归档

所需的模板文件 7zSDTemplate.sfx、configTemplate.txt 和 VersionInfoTemplate.rc 位于 ProjectPackager/sfxHelpers 文件夹中。

  • 使用 7zip 创建归档：
7za.exe a ./InstallerOutput/installer.7z ./InstallerOutput/*
  • 调整 configTemplate.txt 以适配你的应用程序
  • 调整 VersionInfoTemplate.rc 以适配你的应用程序
  • 使用 ResourceHacker 编译资源文件
"ResourceHacker.exe" -open ./VersionInfo.rc -save ./VersionInfo.res -action compile -log con
  • 将生成的资源文件嵌入 7zSDTD.sfx
"ResourceHacker.exe" -open ./7zSDTemplate.sfx -save ./7zSD.sfx -res ./VersionInfo.res -action addoverwrite -mask VersionInfo,, -log con
  • 创建自解压归档
cat ./7zSD.sfx ./config.txt ./InstallerOutput/installer.7z > ./MyApplication.MyVersion.exe
  • 最后同样重要的是更改文件的权限
chmod 770 ./MyApplication.MyVersion.exe
