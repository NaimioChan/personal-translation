Text COMP

摘要

Text COMP 是一个 panel，用于显示构建用户界面所需的文本。文本可以是只读的，也可以是只读但可复制/粘贴的，或可直接在面板中完全编辑。

有 formatting 种模式，用于显示单行字符串和多行文本、浮点数和整数、密码字段等。文本来源是 Text 参数，然后格式化后在面板中显示。格式化示例包括把数字显示为货币、百分比或科学计数法，或把整数时间码值转换为小时/分钟/秒/帧。其他格式化选项包括支持 Python 语法、Custom C++ Fmt 和 Custom Python F-String 语法。

当用户在面板中点击编辑文本时，内容会以原始格式显示，编辑完成后再重新格式化。

Text COMP 支持在文本中使用 inline formatting directives，实现颜色、删除线、下划线、小型大写字母、下标、渐变等效果。例如，代码 {#color(255, 0, 0);} 会把该行之后的所有文本变为红色。

它提供 text-fitting 个选项，用于自动换行、文本放不下时缩小、左中右对齐以及语言阅读方向。只读文本可以选择是否可选中。

你可以绘制 multiple transformed/formatted strings using a "Specification DAT" table：表格每一行绘制一个字符串，每个字符串在面板中都有自己的位置和格式。列可以是 x、y、text、fontsize、fontcolorr、fontcolorg、fontcolorb、fontalpha、skew、tracking 和 horzstretch。也可以使用 Specification CHOP 提供文本属性的数值。

Spec DAT 的每一行代表一个“块”或“文本块”。每个 Spec DAT 都包含一个名为 text 的列，它是覆盖 Text 参数的字符串。

它具有 python callbacks，可对每个发生变化的字符或字符串执行，此外还有焦点变化的回调。

Resolution-independent text 会按面板尺寸所需的分辨率直接绘制到屏幕，因此在任何缩放级别下文字都清晰锐利。它基于 GPU，使用 Slug Library。

X、Y、Width 和 Height 的单位是「panel units」，而以前是实际的像素单位。Default Font Size、Text Offsets 和 Padding 以面板单位计。

Text COMP 的示例见 Operator Snippets。

参见 Text Formatting Codes

另请参阅 Geo Text COMP，了解 Text COMP 对应的 3D 渲染版本。

注意：Text COMP 是 Field COMP 的替代品，完全取代了它，并增加了许多以前没有的功能。

参数 - Text 页

Mode mode - - 控制内容取自 Text 参数，还是取自 Specification DAT/CHOP。
  • Text text -
  • Specification DAT/CHOP specdat -
Text text - 此参数是面板中所显示文本的数据来源。值可以是数字、字符串，也可以是使用 python 或 bind 表达式对外部数据源的引用。当用户在面板中编辑文本时，这些更改会保存回该值或其绑定的原始数据源。例如，可以用类似 'op('table1')[0,0]' 的 bind 表达式把面板中的文本绑定到 DAT 单元格的内容。
Specification DAT specdat - 在 Specification 模式下作为文本数据来源的 Table DAT 路径。该表格的前几行应有 3 列，分别标为 x、y 和 text。其后的每一行都会在给定的 x、y 坐标处显示一行文本，坐标从左下角量起。x 和 y 以面板单位计。
Specification CHOP specchop - 在 Specification 模式下可提供数值数据的 CHOP 路径。名为 x 和 y 的通道可用于定位 Specification DAT 中指定的文本数据。DAT 中的每一数据行都应在 CHOP 中有对应的采样。
Type type - - Type 参数控制值的解释方式，以及可用的格式化和编辑选项。
  • String string - 值被解释为单行文本。如果源文本包含多行，会被合并到一行中。此模式适用于简单标签或数据输入字段。
  • Float float - 值在格式化显示前被当作浮点数处理。编辑时只接受数字。
  • Integer integer - 值在格式化显示前被当作整数处理。编辑时只接受数字。整数模式可用于格式化时间码和其他整数。
  • Multi Line multiline - 显示跨多行的较长文本时使用此模式。行由换行符（\n）分隔，也可以设置为在面板边界处自动换行。注意：使用 '\n' 转义序列输入换行符时，请为 Text 参数使用表达式模式。参数处于常量模式时，转义序列会被忽略并当作字面量。
  • Password password - 用此模式模拟密码框，格式化后的文本会被替换为点。注意：虽然密码在面板中不可见，但它并不安全，仍会显示在 value 参数中，并可通过 python 访问。
  • Specification DAT specdat - 此模式下忽略 Text 参数，数据取自 Specification DAT 参数中给定的 DAT 表格。此模式可用于在面板内任意位置显示多个单行字符串。此模式不支持直接在面板中编辑文本。表格的前几行必须包含 3 列，分别标为 x、y 和 text。其后的每一行都会在给定的 x、y 坐标处显示一行文本。x 和 y 以面板单位计，从左下角量起。对齐参数可用于相对每个 x、y 点定位文本。
Formatting formatting - - 此参数控制源文本在面板内如何格式化和显示。可用选项会随所选模式变化。例如，Float 模式下有科学计数法或百分比选项，而 Integer 模式下有把源值当作时间码的选项。
  • Default default - 此选项在所有模式下均可用，对源值应用最少的格式化。
  • Custom (Fmt Syntax) customfmt - 文本值使用 c++ Fmt 语法格式化，其中源文本为值 0。Float 模式下，宽度也可作为值 1 使用，精度为值 2。详情见 Fmt documentation。
  • Custom (Python F-String Syntax e.g. {val} ) customfstring - 文本值使用 Python F-String 语法格式化，源文本可在变量 'val' 中获取。在这种格式中，花括号之间的任何内容都被当作 python 表达式，便于把字面文本与动态表达式混合起来。
Custom Formatting customformatting - 此参数为 Python F-String 和 C++ Fmt 等自定义模式提供格式化字符串。两种情况下，源文本定义在花括号（ {} ）内，花括号之外的文本被当作常量。
Precision precision - 在 Float 模式下用于设置小数位数。
Thousands Separator thousandsseparator - - 在 Float 和 Integer 模式下用于在千位之间添加分隔符，便于阅读大数字。例如 1,000,000
  • None none - 不添加分隔符。
  • Space space - 使用半角空格字符分隔千位，即 1 000 000
  • Comma comma - 使用逗号分隔千位 1,000,000
Framerate framerate - 设置将整数格式化为时间码时每秒的帧数。
Use Smart Punctuation smartquote - 启用智能标点。例如，成对的引号会替换为合适的曲引号，3 个句点会替换为省略号字符，两个连字符会变为破折号。
Formatting Codes formatcodes - 启用文本中的格式化指令。例如，代码 {#color(255, 0, 0);} 会把该行之后的所有文本变为红色。所有可用代码见 Text Formatting Codes。
Parse Escape Sequences escapeseq - 启用后，'\t' 序列会转换为制表符，'\r' 或 '\n' 会转换为换行。此功能仅在使用 Specification DAT 时启用。对于 Text 模式，需要转义序列时应使用 python 表达式。
Smart Punctuation smartpunct - 启用智能标点。例如，成对的引号会被替换为合适的弯引号，3 个句点会替换为省略号字符，两个连字符会变成破折号。
Word Wrap wordwrap - 启用自动换行，仅在上述 'Type' 参数设为 'Multi Line' 时可用。当单行文本超出面板边缘时，自动换行会把它拆成多行。面板宽度等于 Width 参数减去左右内边距。换行通常发生在空格、制表符或连字符处，但如果单个词比整页还长，也可以在词中间断开。
Edit Mode editmode - - 控制文本是否可以在查看器中直接编辑。
  • Locked locked - 文本为只读，无法在查看器中编辑。
  • Editable editable - 在活动查看器中点击会进入编辑模式，可直接在查看器中编辑文本。当查看器失去焦点（通过点击外部或按 Enter、Escape）时，查看器中的内容会保存回 Text 参数。若 Text 参数包含 bind 表达式，文本会保存回 bind 另一侧的成员，即另一个参数、DAT 单元格或 python 属性。
  • Select Only selectonly - 查看器中的文本可以选中并复制，但不能更改。
  • Editable (Continuous Update) editablecontinuous - 与「Editable」选项类似，但每次按键后都会把值保存回源，而不是只在查看器失去焦点后保存。
Shift-Enter for New Line shiftenter - 在多行模式下启用此选项时，按 Enter 会完成编辑并保存值，用户若要新建一行须按住 Shift 再按 Enter。
Placeholder Text placeholdertext - 当没有给定文本时，此参数是面板中所显示文本的数据来源。类似提示文本。
Placeholder Text Color placeholdercolor - - 占位符文本的默认颜色。可以用格式化代码为文本的不同部分应用其他颜色。
  • Placeholder Text Color placeholdercolorr -
  • Placeholder Text Color placeholdercolorg -
  • Placeholder Text Color placeholdercolorb -
Reading Direction readingdirection - - 用此参数控制文本是从左到右（LTR）还是从右到左（RTL）显示。使用 RTL 模式时若检测到 LTR 字符，也支持双向布局。
  • Left To Right lefttoright -
  • Right To Left righttoleft -
Focus Order fieldfocus - 包含组件路径列表的 Table DAT 路径，用于控制在编辑时用户按 TAB 或 Shift+Tab 后哪个面板获得焦点。
Drag Drop Behavior dragdropmode - - 此参数控制用户把对象拖放到活动文本窗口时会发生什么。可以使用 Drag/Drop 页上配置的通用面板拖放系统，也可以使用此处提供的某个预定义行为。使用 Append 或 Insert 等预定义行为会禁用通用拖放回调。
  • Use Panel System panel - 使用通用的面板拖放控制。更多信息见 Drag-and-Drop。
  • Insert Text textinsert - 将被拖放对象的文本内容插入到当前内容中。文本会插入到最近已知的光标位置。
  • Replace Text textreplace - 用被拖放对象的文本内容替换当前文本值。
  • Append Text textappend - 将被拖放对象的文本内容追加到当前文本值的末尾。
Callbacks DAT callbacks - 包含 python 回调函数的 Text DAT 路径，可用于响应查看器中的各种事件。

参数 - Layout 页

Layout 参数页控制面板的大小和位置。大小和位置以「面板单位」指定。这些单位不一定对应像素。取决于显示器的 DPI 缩放设置，一个面板单位可能覆盖多于或少于一个像素。不过，如果 DPI 缩放设为 1.0，则 1 面板单位等于 1 像素。可以通过在打开面板的 Window COMP 中设置「DPI Scaling」参数，让面板始终以像素为原生尺寸。

参数 - Drag/Drop 页

请参阅 Drag-and-Drop，了解面板组件之间拖放功能的完整说明。

When Dragging This drag - - 指定此 Panel Component 是否可被拖拽。
  • Use Parent's Drag Settings dragparent - 遵循父级 Panel Component 的 Drag 设置。
  • Legacy Drag System legacy - 允许拖拽此 Panel Component。使用 Paramters Drag Script、Drop Destination Script 和 Dropped Operator 控制其行为。「Use Drag/Drop Callbacks」是更强大的新版工作流程。
  • Do Not Allow Drag dragno - 禁止拖拽此 Panel Component。
  • Use Drag/Drop Callbacks usecallbacks - 通过下方指定的自定义脚本精确指定行为。
Drag Script dragscript - 指定开始拖拽 Panel Component 时执行的脚本。请参阅 Drag and Drop 页面的 Drag Script 部分。
Drop Types droptypescript - 如果指定了拖放目标脚本，还可以添加一个 DAT 表格，列出拖放目标脚本将提供的返回类型。返回类型可以是操作符类型之一（COMP、TOP、CHOP、SOP、MAT、DAT）、channel，或受支持的文件类型。请参阅 Drag and Drop 页面的 Drop Types 部分。
Drop Destination Script dropdestscript - 指定拖拽的 Panel Component 被放下时执行的脚本。会创建一个临时网络，并将该组件（或 Dropped Component 中指定的替代操作符）复制到此网络。你可以在此网络中添加或修改操作符。请参阅 Drag and Drop 页面的 Drop Destination Script 部分。
Dropped Operator paneldragop - Dropped Component 参数是指定要放下的替代操作符最简单的方式。注意此替代操作符必须存在，否则会放下组件本身。替代项仅在放到网络或控制面板上时使用。通过拖放粘贴的文本，或通过放到桌面保存的文件，仍会使用原始项。
On Dropping Into drop - - 指定此 Panel Component 是否接受放在其上的项目。
  • Use Parent's Drop Settings dropparent - 遵循父级 Panel Component 的 Drop 设置。
  • Legacy Drop System legacy - 允许将项目放到此 Panel Component 上。使用 Paramter Drop Script 控制其行为。「Use Drag/Drop Callbacks」是更强大的新版工作流程。
  • Do Not Allow Drop dropno - 禁止将项目放到此 Panel Component 上。
  • Use Drag/Drop Callbacks usecallbacks - 通过下方指定的自定义脚本精确指定行为。
  • Fill Custom Parameter fillparm - 避免任何脚本，只需在自定义参数中填入被放下节点的路径。
Built-In Drop Options builtindrop - 通常，在节点上放下时，如果查看器未激活，会提供内置的放下选项，否则提供自定义的放下选项。关闭此选项后，两种情况都只使用自定义的放下选项。
Drop Script dropscript - 当把另一个组件或外部文件放入某个组件时，会运行该组件的 Drop Script。请参阅 Drag and Drop 页面的 Drop Scripts - Text 部分。

也可以在 drop script 字段中指定一个 Table DAT。TouchDesigner 会自动查找表格中的 2 列。第一列应指明数据类型，第二列应指明包含处理该数据类型脚本的 Text DAT。请参阅 Drag and Drop 页面的 Drop Script - Tables 部分。

Drop Parameter dropparm - 当「On Dropping Into」设为 Fill Custom Parameter 时，此参数指定要填充哪个参数。此选项与关闭「Built-In Drop Options」结合，可以快速将任何节点放到此查看器上，并用放下的路径填充自定义参数。
Drag/Drop Callbacks dragdropcallbacks - 指定哪个 DAT 保存自定义的拖放脚本。如果为空，按「Add」创建一个带默认脚本的 DAT。

参数 - Common 页

Common 参数页设置组件的 node viewer 和 clone 关系。

Parent Shortcut parentshortcut - 指定一个名称，可在组件内任意位置用作该组件的路径。参见 Parent Shortcut。
Global OP Shortcut opshortcut - 指定一个名称，可在任何位置用作该组件的路径。参见 Global OP Shortcut。
Internal OP iop - 内部操作符的序列标题。
Shortcut iop0shortcut - 指定一个名称，可在组件内任意位置用作下方「Internal OP」的路径。参见 Internal Operators。
OP iop0op - 此组件内 Internal OP 的路径。参见 Internal Operators。
Node View nodeview - 决定节点查看器中显示的内容，也称为 Node Viewer。某些选项会根据组件类型而不可用（Object Component、Panel Component、Misc.）
  • Default Viewer default - 显示该组件类型的默认查看器：Object COMP 显示 3D Viewer，Panel COMP 显示 Control Panel Viewer。
  • Operator Viewer opviewer - 显示下方 Operator Viewer 参数中指定的任何操作符的节点查看器。
Operator Viewer opviewer - 当上方的 Node View 参数设为 Operator Viewer 时，选择使用哪个操作符的节点查看器。
Keep in Memory keepmemory -
Enable Cloning enablecloning - 控制该 OP 是否应持续克隆。关闭此项会使此节点停止克隆其「Clone Master」。
Enable Cloning Pulse enablecloningpulse - 立即克隆内容。
Clone Master clone - 用作 Master Clone 的组件路径。
Load on Demand loadondemand - 仅在需要时将组件加载到内存。适用于项目中并非总是使用的组件。
Enable External .tox enableexternaltox - 开启时（默认），.toe 启动时会加载外部 .tox 文件，COMP 的内容将与该外部 .tox 一致。如有需要，可以关闭此项，以避免启动时从引用的外部 .tox 加载（COMP 的内容改为从 .toe 文件加载）。如果你希望某个 COMP 引用外部 .tox，但不总是从它加载，除非你特意按下 Re-Init Network 参数按钮，这会很有用。
Enable External .tox Pulse enableexternaltoxpulse - 此按钮会从外部 .tox 文件重新加载（若存在）。
External .tox Path externaltox - 磁盘上 .tox 文件的路径，该文件会在 .toe 启动时作为组件内容的来源。这让组件可以包含能独立更新的网络。若找不到 .tox 文件，则会加载 .toe 文件保存时的内容。
Reload Custom Parameters reloadcustom - 启用此复选框后，重新加载 .tox 时会重新加载组件 Custom Parameters 的值。这仅影响组件上的顶层参数；组件内节点上的所有参数始终随 .tox 重新加载。
Reload Built-In Parameters reloadbuiltin - 启用此复选框后，重新加载 .tox 时会重新加载组件内置参数的值。这仅影响组件上的顶层参数；组件内节点上的所有参数始终随 .tox 重新加载。
Save Backup of External savebackup - 启用此复选框后，由 External .tox 参数指定的组件的备份副本会保存在 .toe 文件中。若找不到 External .tox，将使用此备份副本。出现这种情况可能是因为 .tox 被重命名、删除，或 .toe 文件在另一台缺少组件媒体的电脑上运行。
Sub-Component to Load subcompname - 从外部 .tox 文件加载时，此选项允许你深入 .tox 取出一个 COMP，并将其作为顶层 COMP，忽略文件中的其他所有内容（该 COMP 的内容除外）。例如，若名为 project1.tox 的 .tox 文件包含 project1/geo1，将 geo1 设为 Sub-Component to Load，就会加载 geo1 来替代当前 COMP。若此参数为空，则按常规使用文件中的顶层 COMP 加载 .tox 文件。
Relative File Path Behavior relpath - - 设置此 COMP 内的子文件路径是相对于 .toe 本身还是 .tox，或从父级继承。
  • Use Parent's Behavior inherit - 从父级继承设置。
  • Relative to Project File (.toe) project - 当指定为相对路径时，该路径将相对于 .toe 文件。
  • Relative to External COMP File (.tox) externaltox - 当指定为相对路径时，该路径将相对于 .tox 文件。未指定外部 COMP 文件，或 Enable External .tox 未开启时，此项没有影响。
Parameter Color Space parmcolorspace - - 控制如何解释此节点上的所有颜色参数。仅在项目启用了 Working Color Space 时可用。颜色值被视为处于所选色彩空间中，并在作为节点运算的一部分使用之前转换为 Working Color Space。注意这不会改变节点自身的色彩空间，因为它始终处于 Working Color Space。
  • sRGB srgb - sRGB 色彩空间，使用 sRGB 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • sRGB - Linear srgblinear - sRGB 色彩空间，使用线性传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.601 (NTSC) rec601ntsc - Rec.601，NTSC 原色色彩空间，使用 Rec.601 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.709 rec709 - Rec.709 色彩空间，使用 Rec.709（与 Rec.2020 相同）传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.2020 rec2020 - Rec.2020 色彩空间，使用 Rec.2020（与 Rec.709 相同）传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 dcip3 - DCI-P3 色彩空间，D65 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 (D60) dcip3d60 - DCI-P3 "D60 sim" 色彩空间，D60 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Display-P3 (D65) displayp3d65 - Display-P3 色彩空间，D65 白点，sRGB gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACES2065-1 aces2065-1 - ACES 2065-1（也称为 ACES AP0）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACEScg acescg - ACEScg（也称为 ACES AP1）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Passthrough passthrough - 选中后，颜色值将按原样用于运算，不作任何修改，也不尝试将其转换到 Working Color Space。
Parameter Reference White parmreferencewhite - - 在将参数颜色值转换为 Working Color Space 时，此项控制相对于 Reference White 应如何处理。如果 Working Color Space 的 Reference White 相同，则不做调整。如果不同，则此颜色的 Reference White 级别（亮度）将被调整到 Working Color Space 所期望的范围。例如，如果项目将 SDR Reference White 设为 120 nits，而 HDR Reference White 为 80 nits，那么 (1, 1, 1) 的颜色在 SDR 色彩空间中为 120 nits，将被转换为 (1.5, 1.5, 1.5)，在 HDR Working Color Space 中仍为 120 nits。
  • Default For Color Space default - 将根据所选的色彩空间使用 SDR 或 HDR Reference White。
  • Use Parent Panel useparent - 将使用父级面板所选的 Reference White。如果顶层面板也选择了「Use Parent」，则将使用「UI Reference White」。
  • Standard (SDR) sdr - 会将 Parameter Color Space 的 Reference White 值按 SDR 处理。
  • High (HDR) hdr - 会将 Parameter Color Space 的 Reference White 值按 HDR 处理。
  • UI ui - 会将 Parameter Color Space 的 Reference White 值按 UI 处理。其亮度使用「UI Reference White Nits」的值。
