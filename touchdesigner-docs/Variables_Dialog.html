变量对话框

说明

Variables/Macros 对话框可让你查看 Environment Variables、Built-In Variables 和 Macros。这是旧式的 Tscript 技术，此处仅为支持旧项目而保留。由于 Tscript 已弃用，如今构建项目时不建议使用。

关于环境变量、内置变量、局部 Operator 变量和 Script 变量以及其他变量类型的更多信息，请参阅 Variables article。

变量

Environment 和 Built-in 变量不可编辑，它们是只读的。

以前可以使用此对话框添加/编辑/删除 Root 变量和 Component 变量。 现在要添加/编辑/删除变量，请直接转到定义它们的位置，即 root 或你想编辑其变量的组件的 /local/variables 中的 Table DAT。
