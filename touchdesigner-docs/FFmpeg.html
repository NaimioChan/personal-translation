FFmpeg

FFmpeg 是一个用于读写多种图像、影片和音频文件的软件库。它被 Movie File In TOP 和 Movie File Out TOP 以及其他读写音频、视频的节点使用。

ffmpeg.exe 包含在 TouchDesigner 的 bin 文件夹中。TouchDesigner 的 TOPs 能完成 ffmpeg.exe 的大部分工作。做不到的部分，许多提供 ffmpeg.exe 示例的网站之一是 labnol.org

另请参阅 FFmpeg.org、FFmpeg wikipedia、File Types

FFmpeg 的使用

FFmpeg 的使用依据 LGPL 第 3 版许可授权，可在此查看 here，也可在 TouchDesigner 安装目录的 Samples/OSSLicenses 文件夹中查看。
