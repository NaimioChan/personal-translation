JSON DAT

摘要

JSON DAT 使用 JSONPath 语法转换和过滤 JSON 文本，并输出过滤结果。这样就不必编写脚本来解析和操作 JSON，并让数据流保持程序化。

它接受 JSON 文本作为输入，并把输入转换为 DAT.source 成员中的 Python 对象。

然后用 JSONPath Filter parameter 过滤 JSON，并把结果数据以 JSON 文本形式从 DAT 输出。

它还会把过滤结果放到 DAT.results（结果的 Python 列表）和 DAT.result（第一个结果）中。

你可以把 Output 菜单设为 Expression，并用 me.result['city'] 之类的表达式在 DAT.source、DAT.result 和 DAT.results 上测试表达式，它会从 DAT 输出求值后的表达式。然后你可以在别处把该表达式用作 op('json1').result['city']。DAT.expr 也是 JSON DAT 的成员，例如 op('json1').expr 会返回求值后的表达式参数。

Output tables：把 Output Format 菜单设为 Table，JSON DAT 就可以输出表格。它会尽力把 JSON Filter 的结果组织成 DAT 表格中的行和列，包括值和表头。任何无法表示为简单字符串、整数、浮点数或布尔值的单元格，都会保留为其余部分的 JSON 字符串。单元格或单元格范围可以再用 Select DAT 进一步缩减，然后传给另一个 JSON DAT，由它把 JSON 字符串转换为表格。

See also: JSONPath、OP Snippets 以及 TDJSON 函数，用于转换和操作 JSON 数据。

jsonDAT_Class

参数 - JSON 页

Filter filter - 遵循 JSONPath 语法的过滤字符串，用于过滤输入的 JSON。
Output output - - 选择 JSON DAT 的输出。
  • Filter Result filterresult - 输出把过滤器应用到 JSON 文本输入后返回的列表。
  • Expression expression - 输出自定义表达式。
Expression expression - 要输出的自定义表达式
Output Format outputformat - - 选择 DAT 输出的格式。
  • None none - 不对输出做任何格式化，实际上意味着它会是 Python 格式（即使用单引号）。
  • Indented indented - 缩进，并把单引号转换为双引号。
  • Table table - 把 JSON 输出格式化为表格。如果根结构是列表，则是一列值。如果根结构是字典，则第一行为名称表头，下一行为值。如果输出是字典列表，则名称表头下会有多行值。此时每一行代表列表中的一个字典结构，如果该字典没有列标题中某个名称的条目，则该单元格留空。
  • Double Quotes doublequotes - 把单引号转换为双引号。
Hold Last Non-Empty Results holdlast - 启用后，如果结果变为空，则保留最近一次的结果，实际上只有新的非空结果才会更新输出。

  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。

Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

操作符输入

  • Input 0: - 一个 JSON 文本输入。

Info CHOP 通道

JSON DAT 的附加信息可以通过 Info CHOP 获取。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
