Polystitch SOP

摘要

Polystitch SOP 尝试把多边形曲面缝合在一起，从而消除因以不同细节级别计算曲面而产生的裂缝。

首先，找出所有待缝合多边形的边界。如果一条边不被任何其他多边形共享，它就是边界边。边的唯一性由点编号决定，而不是由空间位置决定。然后，每条边界在每个「角」处被拆成若干片段。可以手动指定角点列表，也可以把边界方向变化达到一定量的任何点标记为角点。

最后，彼此距离在容差内的任意两段边界会被缝合在一起。做法是把高细节边上的点吸附到低细节边的点上。

polystitchSOP_Class

参数 - 页

Polygons to Stitch stitch - 要考虑缝合的多边形。
Corner Points corners - 点编号列表，这些点被视为边界边上的断点。
Max Dist to Stitch tol3d - 两条边仍能被缝合的最大间距。
Consolidate Points consolidate - 当一条边上的多个点被吸附到同一位置时，把它们合并为单个点。合并只沿边界进行，不跨边界进行。
Automatically Find Corners findcorner - 每当一条边在某个点的方向变化超过指定角度时，就把该点标记为角点。
Corner Angle angle - 边界点变化多大角度就会被视为角点。

Info CHOP 通道

Polystitch SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
