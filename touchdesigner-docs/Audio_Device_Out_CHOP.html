Audio Device Out CHOP

摘要

Audio Device Out CHOP 使用 DirectSound/CoreAudio 或 ASIO 将音频发送到任何连接的音频输出设备。 Audio Device Out CHOP 上的第二个输入可用于音量控制。

提示：如果出现音频爆音或音频中断，可能是由主 timeline 的实际帧率引起的——某些帧的计算/渲染耗时过长。参见 Time Slicing。有四种可能的补救方法：

  • 全局 CHOP Maximum Time Slice Size 可能短于最坏情况下的时间步长。其默认值为 .2 秒，在 Edit -> Preferences -> CHOPs -> Maximum Time Slice Size 中设置）。如果任何一帧的绘制时间长于 Maximum Time Slice Size 时间，音频就会爆音。
  • 之后可以将音频缓冲区大小增加（Buffer Length 参数默认为 .15 秒），最大到 Maximum Time Slice Size。
  • 优化你的网络，使帧时间在任何情况下都不超过音频缓冲区大小或最大时间切片大小。你可以用 Perform CHOP 精确监视这一点。
  • 将音频放在单独的 TouchDesigner 进程中。

参数 - Audio Device Out 页

Active active - 开启或关闭音频输出。
Driver driver - 在默认的 DirectSound/CoreAudio 或 ASIO 驱动之间选择。
  • DirectSound default - 默认的 Windows 音频驱动（又称 WDM）或 macOS CoreAudio 驱动，取决于你的操作系统。
  • ASIO asio - 低延迟驱动，通常来自硬件制造商。
Device device - 可用音频设备的菜单，用于输出。选择 default 会将音频设备设为 Windows Control Panel>Sounds and Audio Devices>Audio>Sound Playback 中所选的设备。
Error if Missing errormissing - 如果找不到指定的设备，该 CHOP 将报错。
Outputs outputs - 当 Driver 在 Windows 上设为 ASIO、在 macOS 上设为 CoreAudio 时，此参数可用于选择要使用的输出通道。
Buffer Length bufferlength - 音频缓冲区的长度，以秒为单位。音频输出会延迟此数值的时间。例如，如果 Buffer Length 为 0.25，那么声音会比此 CHOP 收到它晚 250ms = 0.25 秒播出（以保持缓冲区充满）。如果音频输出中出现噼啪声或爆音，请尝试增大此值。
Adjust Speed adjustspeed - 此值控制当输出队列变得过长或过短时修正队列的力度。较大的值能更快恢复队列大小，但会产生可听见的音高变化。
Volume volume - 0 = 静音，1 = 最大音量。
Pan pan - 0 = 左，0.5 = 居中，1 = 右。
Clamp Output clampoutput - 将输出钳制在 -1 到 1 之间，以避免削波和音频系统过载。
Cycle Channels in Output - 为 True 时，音频通道会发送到每个音频输出，使任何输出都不会静音。例如，这允许单个通道输出到两个立体声输出上。（仅限 ASIO）。
Cook Every Frame cookalways - 强制 CHOP 每帧计算。输出音频时应始终保持勾选。当 CHOP 不使用时可以关闭。

参数 - Output 1 页

在 Windows 上使用 DirectSound 时，此页以及下一个 Output 2 页上的输出用于路由到音频设备的不同扬声器输出。并非所有设备都支持所有输出。

当 Audio Device Out CHOP 有多个输入通道时，通道按顺序应用到勾选的扬声器输出。第一个输入通道输出到第一个勾选的扬声器，第二个输入通道输出到第二个勾选的扬声器，依此类推。

Stereo Mode stereo - 设置为简单的立体声左/右输出模式。
Front Left frontleft - 如果可用，启用此输出。
Front Right frontright - 如果可用，启用此输出。
Front Center frontcenter - 如果可用，启用此输出。
Low Frequency lowfrequency - 如果可用，启用此输出。
Back Left backleft - 如果可用，启用此输出。
Back Right backright - 如果可用，启用此输出。
Front Left of Center frontleftcenter - 如果可用，启用此输出。
Front Right of Center frontrightcenter - 如果可用，启用此输出。
Back Center backcenter - 如果可用，启用此输出。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Audio Device Out CHOP 的额外信息可通过 Info CHOP 访问。

Audio Device Out CHOP 专用 Info 通道

  • queue_speed - 输出缓冲区播放的速度。理想情况下不应偏离 1.0（正常速度）太多。
  • queue_read_pos - 队列缓冲区当前的读取位置。正常播放时，它应在起始和结束之间持续变化。
  • queue_write_pos - 队列缓冲区当前的写入位置。正常播放时，它应在起始和结束之间持续变化。
  • queue_length - 音频输出缓冲区的总长度，以秒为单位。
  • queue_added - 此值反映最后添加到输出缓冲区的音频片段的大小。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
