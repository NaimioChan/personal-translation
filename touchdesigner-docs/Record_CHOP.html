Record CHOP

摘要

Record CHOP 接收第一个（Position）输入传入的通道，将其转换并在内部记录，然后将存储的通道作为 CHOP 输出。可选的第二个（Active）输入用于启用和禁用录制。

录制期间，Record CHOP 只使用当前帧第一个输入的值。Type 决定输入值的转换方式。

提示：Trail CHOP 也会记录最后一个采样窗口，更强大的是，Palette 中的 gestureCapture 组件对多次捕获和通道数据平滑提供了更多控制。

如果 Record 设为 Auto Range，且 Active 输入开启、TouchDesigner 正在播放，则任何现有存储数组都会被清空，通道被记录到新的存储数组中，直到 Active 关闭。其行为类似采样器。

Mouse In CHOP 和 Keyboard In CHOP 通常分别连接到 Record CHOP 的 Position 和 Active 输入，用于录制鼠标运动的通道，通过按键启用（见 Keyboard In CHOP）。

Record Segment 适用于记录轨迹、蛇形以及其他使用运动时间历史的模型。

有关输入平滑，见 Time Slice CHOP。

参数 - Control 页

Record record - - 何时录制以及录制多少：
  • Off off - 输出保持不变。
  • On on - 正向播放时始终录制。当活动输入处于关闭状态时，输入保持其当前值。
  • Add add - 添加到（偏移）Record CHOP 中先前记录的现有通道集合。当 Active 输入处于关闭状态时，通道保持不变。
  • Auto Range auto - 基于 Active 的开/关创建区间。
Record Input sample - - 决定录制应采样时间片还是当前帧。对于音频，通常应使用 Current Time Slice，因为所有帧都会被求值。

如果将区间设为 Current Frame，它将始终计算（只查看）当前帧（不过无论如何，下游内容仍会计算）。因此它通常不应用于音频，而应用于设备输入之类，因为它会在捕获的帧之间插值。

  • Current Frame scur -
  • Current Time Slice sslice -
Interpolation interp - - 决定如何通过插值计算错过的输入采样。使用 Hold Previous Value 即保持前一值；Linear 和 Cubic 插值会创建值的数学混合，分别为线性（时间上值之间的直线）或三次（起始值与结束值之间的平滑圆滑曲线）。
  • Hold Previous Value hold -
  • Linear linear -
  • Cubic cubic -
Record Output output - - 决定 CHOP 输出的帧范围。
  • Full Range full - 帧范围从你开始录制的那一刻和那一帧起增长。当 TouchDesigner 第二次经过某一帧时，采样会被覆盖记录。按 Reset Channels 重新开始。
  • Current Frame curframe - 仅输出当前帧。
  • Current Frame at Frame 1 frame1 - 输出当前帧，但将其移至第 1 帧。如果通道值不变，可减少计算量。
  • Current Time Slice slice - 仅输出当前 Time Slice 采样。
  • Segment segment - 输出由 Record Segment 起止长度定义的滑动采样窗口。
Record Segment segment - - 数据在固定范围区间内记录，最新数据记录在区间末尾，其余采样向区间起点方向移动。这适合制作蛇形效果。
  • segment1 -
  • segment2 -
Record Segment Unit segmentunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
Reset Channels reset - 当前输出被清空，之后所有通道将以单采样长度开始。
Reset Condition resetcondition - - 当 CHOP 连接到 Record CHOP 的第 3 个输入（即 Input 2）时启用。决定用此输入触发重置所需的条件。
  • Off to On offtoon - 当输入通道从 Off 变为 On（即 0 到 1）时重置录制。
  • While On on - 当输入通道为 On（即 1）时重置录制。
  • On to Off ontooff - 当输入通道从 On 变为 Off（即 1 到 0）时重置录制。
  • While Off off - 当输入通道为 Off（即 0）时重置录制。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Record CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
