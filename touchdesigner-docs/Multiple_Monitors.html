多显示器

输出到多台显示器

多显示器也称为：第二显示器、多显示器、右侧显示器、双显示器、多屏显示。

TouchDesigner 可以将视频输出到多台投影仪、显示器和录制设备。TouchDesigner 可以运行在单台显示器上，也可以跨多台显示器运行。

大多数现代显卡至少支持 4 路输出。获得更多输出最简单的方法是使用拆分器，例如 QuadHead2Go 或 Datapath Fx4 显示器扩展设备。

笔记本电脑的多显示器能力因制造商规格而异。有时笔记本有许多输出接口，但同时可驱动的显示器数量仍有上限。请参阅你所用笔记本的规格以了解其能力。

跨显示器以获得最佳性能

在 Perform Mode 中，如果将所有面板合并成一个跨越所有显示器的画布，TouchDesigner 运行最快。可以先用 Container COMPs 轻松完成，然后将其指定给 Window Placement Dialog 中为 Perform Mode 设置的 Window COMP。不建议使用多个 Window COMP，这会导致性能不佳。

两台 1920x1080 显示器的示例 File:PerformMode Windows.toe

Windows

  • 在桌面背景上右键 → Display Settings → Multiple Displays → Extend These Displays。

将显示器合并为单个虚拟显示器可获得更佳性能

如果可能，还应使用 Nvidia Mosaic、Nvidia Surround 或 AMD EyeFinity 将显示器合并为单个虚拟显示器。

macOS

  • System Preferences → Displays → Arrangement → Mirror Displays = Off。

要在 macOS 上允许跨显示器，请确保同时设置以下项

  • System Preferences → Desktop & Dock → Mission Control → Displays have separate Spaces = Off

其他设置提示

  • Window Placement Dialog 可用于快速将 Perform 模式指定给不同的 Window COMP、调整参数、跳转到网络以及打开/关闭窗口。
  • Perform Mode 可以用 Shortcut 键 F1（开）和 Esc（关）打开和关闭。
  • Window COMP 中的 Always on Top 参数会强制 TouchDesigner 始终是最顶层的可见窗口。

另请参阅 Using Multiple Graphic Cards、Window COMP、Window Placement Dialog
