Cache Blend POP

摘要

Cache Blend POP 引用一个 Cache POP，并根据 Cache Index 参数和各顺序块的 Cache Weight 参数，输出其缓存数据集的混合结果。

混合是对每个点分别进行的，因此一个点的结果不受其他任何点影响。

这适用于对几何数据做时间模糊，以及计算某个点的斜率或速度（假设输入的点数不变）。

Cache Index 值为 0 时混合 Cache POP 当前帧的数据，为 -1 时混合其上一份缓存数据（第二新的一组），依此类推。

权重会被归一化。

另请参阅：Cache POP、Cache Select POP、Blend POP

Index Channel indexchan - 使用 CHOP 时用于缓存索引的通道名称。
Index Channel Unit indexchanunit - - 使用 CHOP 时索引通道的单位。

Weight Channel weightchan - 指定包含权重值的通道。
Interpolate Frames interp - 开启时，如果每个快照的点数相同，所选索引可以在缓存帧之间插值。否则使用最近的缓存帧。
Cache cache - 顺序参数块的开始，用于管理缓存中 POP 的权重和索引。
Cache Index cache0index - - 要选择的 Cache Index。

Cache Weight cache0weight - 该索引处缓存中 POP 使用的权重。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Info CHOP 通道

Cache Blend POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
