背面剔除

Back-Face Culling 是一种性能优化，可避免绘制被判定为背向摄像机的 polygons。 背向多边形定义为顶点绕序为顺时针的多边形。这意味着，如果你在看一个多边形（例如三角形），观察顶点 0、1 和 2 的位置，如果它们构成顺时针环路，那么你看到的就是多边形的背面。如果构成逆时针环路，那么你看到的就是正面。

注意： 如果在 Geometry Viewer 中查看几何，请务必使用 Vertex Number 而不是 Point Number 来判断多边形的哪一侧是正面。

一个容易犯的错误是认为多边形的法线决定了它的哪一侧是正面。这是不对的，法线与哪一侧是正面无关。不过，为使光照正常工作，法线位于多边形的正面上很重要（即顶点绕序为逆时针的那一面）。

可以在每个 MATs 的 Common 页面中开启 Back-Face Culling，也可以在 Render TOPs 中更全局地开启。
