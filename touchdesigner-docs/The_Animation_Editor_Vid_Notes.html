动画编辑器视频笔记

设置几何

  • 在屏幕底部的 timeline 中，把左侧的 End 和 Rend parameters 设为 400。
  • 双击 network，在 COMP 标签下按住 Ctrl 选择一个 Camera COMP、一个 Geometry COMP、一个 Light COMP 和一个 Render TOP。
  • 双击 Geometry COMP，删除里面的 Torus SOP。
  • 双击网络，从 SOP 标签中选择一个 Sphere SOP。
  • 选择 Sphere SOP，把它的 Radius 参数在 x、y 和 z 上设为 0.1。
  • 右键点击 Sphere SOP，选择一个 Transform SOP。
  • 把你刚创建的 Transform SOP 复制粘贴两次。

创建 Animation COMP 并为 CHOP channels 设置关键帧

  • 双击 network，从 COMP 标签中选择一个 Animation COMP，把它放在 SOPs 上方。
  • 右键点击 Animation COMP，选择 Edit Animation。动画编辑器应出现在屏幕下半部分。
  • 在 Animation Editor 的左侧有一个名为 Names 的参数。在这里可以输入 t[xy]，然后点击下方的 Add Channels 按钮，向时间轴添加名为 tx 和 ty 的两个新通道。输入 tx ty 也可以。
  • 目标是让球体以方形路径移动。这需要它从 x: 0 y: 0 移到 x: 1 y: 0，再移到 x: 1 y: 1，然后 y 1: x: 0，最后回到 x: 0 y: 0。
  • 点击编辑器左侧的 tx 按钮以选择该通道进行编辑。tx 通道在时间轴的开头和结尾已有 2 个 keyframes。要添加所需的额外 3 个关键帧，按住 alt 在彩色线上左击 3 次。
  • 右键拖动以在 5 个关键帧中选择第二个关键帧。
  • 图顶部有 F V S 和 A 参数。把 F（帧）设为 100，V（值）设为 1。
  • 选择第二个关键帧，把 F 设为 200，V 设为 1。
  • 选择第三个关键帧，把 F 设为 300，V 设为 0。
  • 在 F、V、S 和 A 参数的右侧有一个 Function 参数。Function 控制关键帧之间如何连接。通过右键拖动（不要拖过关键帧）在两个关键帧之间选择 wire。然后可以按住 shift 选择通道中的其他连线，把它们的 Function 设为 linear。此时动画曲线应具有直线段。
  • 在左侧选择 ty，然后重复该过程，只使用以下值。第一个关键帧应为 0 帧处的 0，第二个为 100 帧处的 0，第三个为 200 帧处的 1，第四个为 300 帧处的 1，最后第五个为 400 帧处的 0。

把通道导出到球体的 translate 参数

  • 退出动画编辑器。右键点击 Animation COMP 的输出，选择一个 Null CHOP。
  • 激活 Null CHOP 的查看器，把 tx 通道拖到第一个 Transform SOP 的 translate x 参数（tx 参数）上。把 ty 通道拖到第一个 Transform SOP 的 translate y 参数（ty 参数）上。
  • 现在球体应该以方形路径移动。

与时间轴无关的动画 COMP 与克隆

  • 双击网络，在 COMP 标签下选择一个 Animation COMP。重复此操作，得到两个空的 Animation COMP，把它们放在先前放置的初始 Animation COMP 下方。
  • 选择第一个新的空 Animation COMP，在它的 Common 标签下的参数中有一个 Clone 参数。把第一个 Animation 组件拖到此参数上，该 Animation COMP 应变暗。这表明此 COMP 是上方那个的克隆。克隆是内容与主节点相同、但可以有不同输入的 COMP。
  • 同样克隆第二个空的 Animation COMP。
  • 像第一个 Animation COMP 那样，把它们连接到两个 Null CHOP，然后把这些 Null CHOP 通道导出到第二个和第三个 Sphere SOP。

用 Beat CHOP 控制动画组件

  • 双击第二个 Animation COMP 左侧的网络，按住 shift 插入一个 Beat CHOP 和一个 Math CHOP。
  • 选择 Math CHOP，在 Range 标签下把它设为 From Range 0 到 1，To Range 0 到 400。
  • 把 Math CHOP 连接到第一个克隆的 Animation COMP 的输入。
  • 选择第一个克隆的 Animation COMP，在 Animation 标签下把 Play Mode 参数设为 Use Input Index。此 Animation COMP 现在由 Beat CHOP 的 Period 参数控制，而不是时间轴。

用 Constant CHOP 的 play 和 speed 通道控制动画组件

  • 双击第三个 Animation COMP 左侧的网络，按住 shift 插入一个 Constant CHOP 和一个 Null CHOP。
  • 选择 Constant CHOP，在 0 标签下添加两个名为 play 和 speed 的新通道。把 play 设为 1，speed 设为 0.5。
  • 激活 Null CHOP 的查看器，把 play 通道拖到第二个克隆的 Animation COMP 在 Animation 标签下的 Play 参数上。把 speed 通道导出到 Speed 参数。
  • 最后在第二个克隆的 Animation COMP 中，在 Animation 标签下把 Play Mode 参数设为 Sequential。

最后一步，TOP 合成

  • 缩小离开 Geometry 组件，或点击网络编辑器顶部路径栏中的 project1。
  • 右键点击 Render TOP 的输出，从 TOP 标签中选择一个 Over TOP。
  • 双击网络编辑器，在 Render TOP 下方放置一个 Constant TOP。
  • 把 Constant TOP 的 Color 改为黑色，在 Common 标签下把 Custom Resolution 设为 1280x720。
  • 把 Constant TOP 的输出连接到 Over TOP 的第二个输入。
  • 选择 project1，在参数窗口的 layout 标签下把 Width 参数设为 1280，Height 参数设为 720。
