Function CHOP

摘要

Function CHOP 提供比 Math CHOP 更复杂的数学函数：三角函数、对数函数和指数函数，以及音频分贝（dB）-功率-幅度的转换。

大多数函数只需要一个参数，它们作为一元操作符应用到每个输入通道。有些函数需要两个参数，这些函数需要使用第二个输入。第一个参数 X 始终是第一个输入中某个通道的值。第二个参数 Y 是第二个输入中对应通道的值。各输入的通道按名称或索引配对。

由于其中许多函数可能产生数学错误，提供了一个错误处理标签页用于错误处理和恢复。 错误可以通过用预定义值替换坏采样，或使用前一个采样的值来处理。或者，可以在出错时中止计算，以便调试网络。

分贝形式的函数类型：用于音频或其他信号强度。-10dB 表示功率的 1/10，-20dB 表示功率的 1/100。结果发现每 3dB 几乎正好是功率的两倍，所以 +12dB 是 2*2*2*2 = 16 倍功率。功率与幅度的平方成正比。所以 -20dB 表示幅度的 1/10，6dB 是幅度的两倍。

参数 - Function 页

Function func - 要对通道应用哪个数学函数。除二元函数「arctan (Input1/Input2)」和「Input1 ^ Input2」外，所有函数都是一元函数。对于幂函数，负底数会先取反以避免虚数，然后对结果取负。
  • sqrt(x) Square Root sqrt - 输入 1 的平方根。
  • abs(x) Absolute Value abs - 输入 1 的绝对值。
  • sign(x) Sign sign - 输入 1 的符号。
  • cos(x) Cosine cos - 输入 1 的余弦。
  • sin(x) Sine sin - 输入 1 的正弦。
  • tan(x) Tangent tan - 输入 1 的正切。
  • acos(x) Arccosine acos - 输入 1 的反余弦。
  • asin(x) Arcsine asin - 输入 1 的反正弦。
  • atan(x) Arctan( Input1 ) atan - 输入 1 的反正切。
  • atan2(y,x) Arctan( Input1 / Input2 ) atan2 - （输入 1 / 输入 2）的反正切。
  • cosh(x) Hyperbolic Cosine cosh - 输入 1 的双曲余弦。
  • sinh(x) Hyperbolic Sine sinh - 输入 1 的双曲正弦。
  • tanh(x) Hyperbolic Tangent tanh - 输入 1 的双曲正切。
  • log10(x) Log base 10 log - 输入 1 的以 10 为底的对数。
  • logN(x) Log base N logb - 输入 1 的以 Base Value 为底的对数。
  • ln(x) Natural Log ln - 输入 1 的自然对数。
  • pow(10,x) 10 ^ Input1 pow10 - 10 的输入 1 次幂。
  • exp(x) e ^ Input1 exp - e 的输入 1 次幂。
  • pow(x) Base ^ Input1 powe - Base value 的输入 1 次幂。如果 Base value 为负，结果为 -((-Base Value) ^ Input 1)
  • pow(x) Input1 ^ Exponent powb - Input 1 的 Exponent value 次幂。如果 Input 1 为负，结果为 -((-Input 1) ^ Exponent Value)。
  • pow(x,y) Input1 ^ Input2 pow - ((-Input 1) ^ Input 2)
  • dB to Power dbtopower - 分贝（Input 1）转幅度。
  • Power to dB powertodb - 幅度（Input 1）转分贝。
  • dB to Amplitude dbtoamp - 分贝（Input 1）转幅度。
  • Amplitude to dB amptodb - 幅度（Input 1）转分贝。
Base Value baseval - 用于「Log base N」和「Base ^ Input1」的底数值。参数名 /baseval
Exponent Value expval - 用于 'Input1 ^ Exponent' 的指数值。通道名 /expval
Angle Units angunit - 对于三角函数，角度可以用 Degrees、Radians 或 Cycles（0 到 1）来度量。

Match by match - 二元函数如何把两个输入的通道配对，按名称或按通道索引。
  • Channel Number index -

参数 - Error 页

Error Handling error - 如何修正有数学错误的采样：
  • Abort With Error Message abort - 中止计算。
  • Replace With Specified Values replace - 下面指定的值。
  • Use The Previous Value useprev - 使用上一个有效结果。
+ Infinity Value pinfval - 出现无穷大错误时使用的值。由 sinh()、cosh() 和 tan() 引起。
- Infinity Value ninfval - 出现负无穷大错误时使用的值。由 sinh() 和 tan() 引起。
Domain Error Value domval - 出现域错误时使用的值。由 asin()、acos()、log10()、logN()、ln() 和 sqrt() 引起。
Divide Error Value divval - 出现除以零错误时使用的值。由 pow(x,y) 引起。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Function CHOP 的额外信息可以通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
