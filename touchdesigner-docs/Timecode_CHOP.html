Timecode CHOP

摘要

Timecode CHOP 生成 Timecode 数据（通道、一个 .timecode Python 对象和其他 Python 成员）。它的 Mode 菜单提供多种通过参数获取、设置和生成时间码的方式，包括由时间码字符串、一组通道，或具有时间码的其他 OP（例如视频输入设备）驱动。也可以用 Python 函数设置时间码。

时间码数据既作为 CHOP 中的通道数据输出，也通过 Python 中的 .timecode member 作为 Timecode object 输出。

时间码可以遵循 SMPTE 标准（即非负、每秒帧数最高 60、24 小时循环），也可以采用更通用的格式（即任意每秒帧数、允许负时间码、100 小时循环）。

由通道驱动时，可以提供具有名为 negative、hour、minute、second 或 frame 通道的输入，它会被加到 Timecode CHOP 的输出上。

参数 - Timecode 页

SMPTE smpte - 启用后，生成的时间码将遵循 SMPTE timecode 标准，即没有负时间码，且时间码在 24 小时处循环。禁用时，格式更通用，允许负数，最大时间码为 100 小时。
Mode mode - 用于生成时间码的来源
  • Locked to Timeline lockedtotimeline - 从时间轴的时间生成时间码。
  • Specify Index specifyindex - 从单个索引值生成时间码。
  • Timecode String timecodestr - 从遵循以下格式的时间码字符串生成时间码：hh:mm:ss:ff 或 hh:mm:ss.ff
  • Hour, Minute, Second, Frame Parameters timecodepar - 从小时、分钟、秒和帧参数生成时间码。参数会从一个溢出到下一个，例如指定 120 秒会输出时间码 00:02:00:00。也允许小数值。
  • Sequential sequential - 时间码随时间顺序递增。
  • Timecode Object timecodeobj - 从 timecode object 生成时间码。
  • CHOP Channels chop - 从具有部分或全部通道 negative、hour、minute、second、frame 的 CHOP 引用生成时间码。
  • OP Reference op - 从带有时间码 Python 成员的 OP 生成时间码，例如 MoviefileinTOP_Class。
Rate rate - 时间码的 FPS。时间码的最大帧值等于 rate-1。如果提供的是分数速率，则速率会向上取整到最接近的整数，并在 Drop Frame 参数启用时计算丢帧。
Drop Frame dropframe - 指定如何计算 drop-frames。当 FPS 为分数时使用丢帧。FPS 无法每帧递增一个分数，因此 FPS 会向上取整到下一个整数，并通过添加丢帧来容纳累积误差。
  • Off off - 不会添加丢帧。
  • Automatic auto - 当速率为分数时，会向时间码添加丢帧。对于 29.97 之类的特殊速率值，使用已定义的标准方案（即每分钟加 2 帧，可被 10 整除的分钟除外）。其他情况下，使用计算累积误差的通用方案。
Index index - 用于生成时间码的索引。该值与指定的单位配合使用。
Index Unit indexunit - 索引值的单位。
  • I indices -
  • F frames -
  • S seconds -
Timecode String timecodestr - 遵循以下格式的时间码字符串：hh:mm:ss:ff 或 hh:mm:ss.ff
Frame frame - 时间码的帧部分。
Second second - 时间码的秒部分。
Minute minute - 时间码的分钟部分。允许溢出。
Hour hour - 时间码的小时部分。
Initialize init - 用于顺序模式。初始化时间码值。
Start start - 用于顺序模式。启动时间码的顺序递增。
Play play - 启用后，顺序时间码会向前步进。
Timecode Object timecodeobj - A timecode object.
CHOP chop - 一个 CHOP 引用，包含以下部分或全部通道：negative、hour、minute、second、frame。
OP op - 一个包含时间码 Python 成员的 OP 引用：例如 MoviefileinTOP_Class。
Custom Length customlength - 如果设为「By Value」，则使用 Length 参数。如果设为「By Timecode」，则使用 Length Timecode Object。如果设为「Off」，则默认长度为 SMPTE 时间码的 23:59:59:ff-1，否则为 99:59:59:ff-1。
  • Off off - 选中后，不使用自定义长度。长度默认为 SMPTE 时间码的 23:59:59:ff-1，否则为 99:59:59:ff-1。
  • By Value value - 选中后，使用 Length 参数从一个值设置自定义长度。
  • By Timecode Object timecodeobj - 选中后，使用 Length Timecode Object 参数从 timecode object 设置自定义长度。
Length length - 以采样、帧或秒指定自定义长度。
Length Units lengthunits - 自定义长度的单位。
  • I samples -
  • F frames -
  • S seconds -
Length Timecode Object lengthtimecodeobj - 以 timecode object 指定自定义长度。
Extend Left extendleft - 设置超出下界（SMPTE 时间码为 00:00:00:00，否则为 -99:59:59:ff+1）时的时间码行为。
  • Hold hold - 选中后，超出下界时时间码将保持其值：SMPTE 时间码为 00:00:00:00，否则为 -99:59:59:ff+1。
  • Cycle cycle - 选中后，超出下界时时间码将循环其值。SMPTE 时间码会循环到长度值，否则循环到 00:00:00:00。
Extend Right extendright - 设置超出长度参数定义的上界时的时间码行为。
  • Hold hold - 选中后，时间码会保持数值到长度值。
  • Cycle cycle - 选中后，时间码到达长度后会循环到 00:00:00:00。

参数 - Output 页

Negative Chan negativechan - 启用后，输出 negative 通道，时间码为负时该通道为真。使用 SMPTE 标准时始终为假。
Frame Chan framechan - 启用后，输出 frame 通道。
Second Chan secondchan - 启用后，输出 second 通道。
Minute Chan minutechan - 启用后，输出 minute 通道。
Hour Chan hourchan - 启用后，输出 hour 通道。
Total Seconds Chan totalseconds - 启用后，输出 total_seconds 通道，即换算成秒的时间码。
Total Frames Chan totalframes - 启用后，输出 total_frames 通道，即换算成帧的时间码。
Drop Frame Chan dropframechan - 启用后，输出 drop_frame 通道，时间码为丢帧时该通道为真。
FPS Chan fpschan - 启用后，输出 fps 通道。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

操作符输入

  • Input 0: - 可选的输入 CHOP，包含以下部分或全部通道：negative、hour、minute、second、frame。输入的时间码值会被加到 Timecode CHOP 的输出上。
