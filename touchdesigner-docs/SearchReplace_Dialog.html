查找替换对话框

Search/Replace Dialog 会在网络中查找并按需替换某段文本的所有出现位置。它有大量选项可缩小搜索条件，精确找到你要找的内容。

这是分析和编辑分散在项目各处的节点的绝佳工具。见下方的 "Results Area"。

替换操作可以撤销。

Search/Replace - 基础模式

设置

Path - 要在其中搜索的路径。

Search - 要搜索的文本。

Replace - 用来替换 Search 文本的文本。

Options

  • Case Sensitive - 只匹配大小写一致的文本。
  • Whole Words - 当 Search 文本只是更长单词的一部分时不匹配。任何非字母数字且非下划线的字符都视为单词分隔。
  • Regular Expressions - 在 Search 和 Replace 文本中使用 regular expressions。注意： Search/Replace Dialog 不使用通配符。请使用此功能进行非特定搜索。

Display

  • Relative Paths - 显示的路径名从指定的搜索 Path 开始。
  • OP Types - 显示一列，标出每个找到的 Operator 类型。
  • Found In - 显示一列，说明文本在 Operator 中的找到位置。

按钮

Search - 根据当前设置刷新搜索。每次更改设置后都必须这样做，才能更新结果。

Replace - 用指定的 Replace 文本替换指定的 Search 文本。此操作可按常规方式撤销。

结果区域

Click on a result - 打开结果的浮动网络查看器。

Hold mouse down on a result - 选择一个窗格来显示结果的网络。之后再次单击会在该窗格中显示结果网络。

Drag a result - 拖动结果操作符，就像从网络中拖动它一样。

Right Mouse Button on result - 打开该结果的选项菜单。

Search/Replace - 高级模式

附加设置

OP Types - 以空格分隔的 OP 类型列表，用于限定结果中显示哪些类型。若列出的类型与某个 Operator 类名完全一致，则会包含该类。否则会包含类型标签中含有该文本的所有操作符。下拉菜单中有所有可用操作符类型的选项。

Filter Script - 一个 Python 表达式，会对搜索中发现的每个 "operator" 进行测试。若表达式为 True，则包含该操作符。下拉菜单中有一些示例表达式。

Max Depth - 限制从指定 Path 开始的搜索网络深度。 0 表示只搜索 Path 中的操作符，不含其子级。1 包含操作符的子级，但不含孙级，以此类推。

Include

  • Non-Editable DATs - 包含在不可编辑的 DAT 中找到的文本。这些文本不会受 Replace 操作影响。
  • Built-in Pars/Pages - 包含内置的参数名与页名。这些名称不会受 Replace 操作影响。
  • Hidden OPs - 包含其 expose 成员为 false 的操作符，包括 TouchDesigner 系统操作符。

Search In - 这些复选框用于选择操作符的哪些区域会被搜索指定文本。

按钮

Search - 根据当前设置刷新搜索。每次更改设置后都必须这样做才能更新结果，除非 lock checkbox 已开启。开启后，任何设置变化都会刷新搜索。注意，即使锁定已开启，也必须手动刷新搜索才能反映被搜索网络的变化。

Replace Selected - 替换搜索结果中选中的项。

Replace All - 替换搜索结果中的所有项。

结果区域

Click on a result - 选中该搜索结果。可用 Ctrl-click 选中/取消选中更多结果。可用 Shift-click 选中一串连续的结果。

Hold mouse down on a result - 选择一个窗格来显示结果的网络。之后再次单击会在该窗格中显示结果网络。

Drag a result - 拖动结果操作符，就像从网络中拖动它一样。

Right Mouse Button on result - 打开该结果的选项菜单。
