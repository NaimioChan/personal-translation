Position 类

position 类保存单个三分量位置。位置是空间中的一个点，根据所计算的数据选用 position 还是 vector 很重要，因为对它们的矩阵运算会得到不同结果。当与 Matrix 相乘时，此类会隐式具有第 4 个分量（W 分量），值为 1。如果矩阵是投影矩阵，会使 W 分量变成 1 以外的值，则所有 4 个分量都会除以 W，使位置重新成为齐次的。新建 position 时可以不带参数，也可以用 3 个参数给出 x,y,z 值，或用单个参数，即一个含 3 项的可变对象，例如长度为 3 的列表，或另一个 position 或 vector。

注意： tdu.___ 与 TDU.___ 可以互换使用。通常 TDU.___ 用于表示类，而 tdu.___ 用于实例化函数。

创建 position 的示例：

p = tdu.Position() # 初始为 (0, 0, 0)
p2 = tdu.Position(1, 5, 0)
values = [0, 1, 0]
p3 = tdu.Position(values)

实例化器

TDU.Position(*args)→ TDU.Position:

创建一个新的 position 对象。以下参数形式都是有效的实例化方式：

  • tdu.Position() - (0, 0, 0)
  • tdu.Position(vector : TDU.Vector) - 复制 vector 的值
  • tdu.Position(position: TDU.Position) - 复制 position
  • tdu.Position(x : float, y : float, z : float) - (x, y, z)
  • tdu.Position(f : float) - (f, f, f)
  • tdu.Position(pos : list) - 含 3 项的列表，用于填充 position

成员

x → float :

获取或设置 position 的 X 分量。

y → float :

获取或设置 position 的 Y 分量。

z → float :

获取或设置 position 的 Z 分量。

方法

translate(x, y, z)→ None:

按指定的值平移 position。

  • x, y, z - 平移所用的值。
p.translate(5, 2, 0)

scale(x, y, z)→ None:

按指定的值缩放 position 的每个分量。

  • x, y, z - 用于缩放各分量的值。
p.scale(1, 2, 1)

copy()→ TDU.Position:

返回该 position 的一个副本，作为新的 position。

newV = v.copy()

特殊函数

TDU.Position[i]→ float:

获取或设置由 i 指定的 position 分量，i 可以是 0、1 或 2。

y = p[1]
p[1] = y + 2.0

TDU.Position * float→ TDU.Position:

按给定的 float 标量缩放 position，并返回新的 Position 作为结果。

p = p * 0.1
p = 0.1 * p

TDU.Position + float→ TDU.Position:

把给定标量加到 position 的全部 3 个分量上，并返回新的 position 作为结果。

p = p + 1.2
p = 1.2 + p

TDU.Position - float→ TDU.Position:

从 position 的全部 3 个分量中减去给定标量，并返回新的 position 作为结果。

p = p - 1.2
p = 1.2 - p

TDU.Vector + TDU.Position→ TDU.Position:

把 vector 加到 position 上，即使该 position 被此 vector 位移。返回新的 position 作为结果。

p2 = v + p1
p2 = p1 + v

TDU.Position - TDU.Vector→ TDU.Position:

从 position 中减去 vector。注意反过来不是合法操作：从 vector 中减去 position 没有意义。返回带有结果的新 position。

p2 = p1 - v

TDU.Position - TDU.Position→ TDU.Vector:

两个 position 相减，生成一个从第二个指向第一个的 vector，长度等于两个 position 之间的距离。

v = p1 - p2

TDU.Position += float→ None:

把给定标量加到 position 的全部 3 个分量上，position 将保存运算结果。

p += 0.1

TDU.Position += TDU.Vector→ None:

用给定 vector 位移 position，position 将保存运算结果。

p += v

TDU.Position -= float→ None:

从 position 的全部 3 个分量中减去给定标量，position 将保存运算结果。

p -= 0.4

TDU.Position -= TDU.Vector→ None:

用给定 vector 位移 position，position 将保存运算结果。

p -= v

TDU.Matrix * TDU.Position→ TDU.Position:

把 Position 乘以矩阵，并返回新的 position 作为结果。

p2 = m * p1

TDU.Position / float→ TDU.Position:

把 position 的每个分量除以标量，并返回新的 position 作为结果。

p2 = p1 / 2.0

TDU.Position *= TDU.Matrix→ None:

把 position 乘以矩阵，position 将保存结果。此时 position 在矩阵右侧相乘，等价于执行 Position = Matrix * Position。

p *= m

TDU.Position *= float→ None:

用给定标量缩放 position 的全部 3 个分量。position 将保存结果。

p *= 1.3

TDU.Position *= TDU.Position→ None:

把第一个 position 的 3 个分量与第二个 position 的 3 个分量逐分量相乘。

p1 *= p2

abs(TDU.Position)→ TDU.Position:

返回新的 position，其 3 个分量都是给定 position 各分量的绝对值。

p2 = abs(p1)

-TDU.Position→ TDU.Position:

返回新的 position，其 3 个分量都取负。

p2 = -p1
