TD 函数

TDFunctions 模块为 TouchDesigner 提供了多种 Python 实用函数。要使用 TDFunctions，请在 Python 脚本顶部加入下面一行： 

import TDFunctions

现在你可以通过以下方式调用下列任何函数： 

TDFunctions.<function name>(...)

注意： 较旧版本的 TouchDesigner 需要这样导入 TDFunctions：TDFunctions = op.TDModules.mod.TDFunctions

方法

clamp(value, inMin, inMax)→ float:

返回被限制在 inMin 与 inMax 之间的值。

  • value - 要限制的值。
  • inMin - 最小值。
  • inMax - 最大值。

parentLevel(parentOp, childOp)→ OP or None:

判断 parentOp 在任意深度上是否为 childOp 的父级。返回 None 或父子关系的深度。即 childOp.parent(<returnValue>) 将得到 parentOp。如果 childOp 不是 parentOp 的子级，此方法返回 None。

注意： 这种情况下 childOp.parent(<returnValue>) 会报错。

  • parentOp - 要评估的父级。
  • childOp - 要评估的子级。

sharedParent(op1, op2)→ OP or None:

返回 op1 与 op2 最近的共同父级。如果结果是 root，则返回 None。

  • op1 - 第一个操作符。
  • op2 - 第二个操作符。

getShortcutPath(fromOp, toOp, toParName=None)→ path expression:

返回从 fromOp 到 toOp 的快捷路径表达式。该表达式适用于 fromOp 上的任何 OP 参数表达式。表达式会纳入 Parent Shortcuts 和 Global OP Shortcuts。

注意： 因为创建快捷表达式有多种方式，此函数的结果始终只是最佳推测。

  • fromOp - 用于生成表达式的操作符。
  • toOp - 表达式指向的操作符。
  • toParName - （字符串）如果提供，快捷方式将指向 toOp 上的该参数。

panelParentShortcut(panel, parentShortcut)→ Panel COMP or None:

返回 panel 的第一个具有所提供 parentShortcut 的 panelParent。如果找不到带该快捷方式的 panelParent，则返回 None。

  • panel - 开始搜索的面板。
  • parentShortcut - 要查找的父级快捷方式。

parMenu(menuNames, menuLabels=None)→ menuSource object:

返回一个适用于 parameters 的 menuSource 属性的对象。也可通过 tdu.ParMenu 使用。

  • menuNames - 菜单值的字符串列表。
  • menuLabels - （可选）菜单标签的字符串列表。默认为 menuNames。

incrementStringDigits(string, min=1, suffixOnly=False)→ string:

用于迭代末尾带数字的字符串，或在没有数字时添加数字的方法。这模拟了重复操作符的自动命名。

  • string - 要添加数字的字符串。
  • min - （可选）如果字符串还没有数字，则要添加的数字。
  • suffixOnl - （可选）如果为 True，只使用字符串末尾的数字

findNetworkEdges(comp, ignoreNodes=None)→ dict or None:

用于在网络中放置节点的实用工具。返回一个字典，包含网络极端处的 'nodes' 和 'positions'。如果没有找到节点则返回 None。字典的键为 'top'、'left'、'right'、'bottom'。

  • comp - 要分析的网络。
  • ignoreNodes - （可选）分析时要忽略的节点列表。

arrangeNode(node, position='bottom', spacing=20)→ float:

根据网络中的其他节点放置一个节点。

  • node - 要移动的节点。
  • position - （可选）可以是 'bottom'、'top'、'left' 或 'right'。left、right 会与 top 节点并行放置。top、bottom 会与 left 节点并行放置。
  • spacing - （可选）与网络边缘的距离。

createProperty(classInstance, name, value=None, attributeName=None, readOnly=False, dependable=True)→ None:

使用此方法为类添加属性。

警告： 属性被添加到 instance 的类上，因此 instance 所属类的所有对象都会拥有该属性。

  • classInstance - 要为其添加属性的类的实例。通常是该类 __init__ 方法中的 'self'。
  • name - 属性的名称。必须是有效的 Python 对象名。
  • value - （可选）属性的起始值。
  • attributeName - （可选）用于存储属性值的特性名称。默认为 _<name>。
  • readOnly - （可选）如果为 True，该属性将只读。只读属性可通过 attributeName 修改。如果该属性是 dependable 的，请使用 attributeName.val。
  • dependable - （可选）如果为 True，该值将是 dependable 的。如果设为 "deep"，集合将深度 dependable。

makeDeepDependable(value)→ dependency object:

从提供的 python 对象返回一个 deeply dependable 对象。深度 dependable 的集合在其内容变化时会触发计算。

  • value - 深度 dependable 对象的值。

forceCookNonDatOps(comp)→ None:

递归强制计算 op 以及 comp 的所有子级，除非它们是 DAT

showInPane(operator, pane='Floating', inside=False)→ None:

在选定的编辑器窗格中打开操作符以供查看。窗格将聚焦于所选操作符，除非 inside 为 True，此时会尽可能显示其内部。

  • operator - 要查看的操作符。
  • pane - （可选）一个 ui.pane，或 'Floating' 表示新建浮动窗格。
  • inside - （可选）如果 inside 为 True，尝试显示 comp 的内部视图。

tScript(cmd)→ float:

运行 tscript 命令。这很慢，因为它会创建并销毁一个操作符。如果需要更快，请构建一个带有自己 tscript DAT 的优化网络。

  • cmd - 要运行的 tScript 命令。

parStringToIntList(parString)→ list of ints:

把以空格分隔的字符串转换为整数列表。

  • parString - 以空格分隔的整数列表。

listToParString(l)→ space delimited string list:

把列表转换为以空格分隔的字符串。

  • l - 一个 python 列表。

replaceOp(dest, source=None)→ None:

用 source 的精确副本替换 dest。如果 source 为 None 且 dest 是 comp，尝试使用 dest 的 clone 参数。

  • dest - 要被替换的 OP。
  • source - （可选）用于替换的 OP。如果为 None，使用 dest 的 clone 源。

setParDefaultsToCurrent(parList, setState=True, allowUndo=True)→ dict:

尝试把参数的默认设置设为参数的当前值或状态。如果应用失败，不会抛出异常。

返回：{'changed': [被更改的参数列表], 'unchanged': [未更改的参数列表], 'error': [出错的参数列表]}

  • parList - 要设置的参数列表。
  • setState - （可选）如果为 True，把默认值设为当前模式，否则把默认值设为当前常量值。Python 参数始终把此参数视为 True。默认为 True。
  • allowUndo - （可选）如果为 True，创建一个撤销步骤。

getParInfo(sourceOp, pattern='*', names=None, includeCustom=True, includeNonCustom=True)→ dict:

返回 sourceOp 的 parInfo 字典。parInfo 字典的格式为 {<parName>:(par.val, par.expr, par.mode string, par.bindExpr, par.default)...}

  • sourceOp - 要查找参数的操作符。
  • pattern - （可选）用于参数名的模式匹配字符串。
  • names - （可选）要包含的特定名称列表。None 表示包含全部。
  • includeCustom - （可选）包含自定义参数。
  • includeNonCustom - （可选）包含非自定义参数。

applyParDefaults(targetOp, parInfo, raiseExceptions=False)→ list:

尝试把 parInfo 字典中的参数默认值应用到 targetOp。忽略 pageindex 参数。如果失败，除非 raiseExceptions 为 True，否则不会抛出异常！这会设置 default、defaultExpr 和 defaultBindExpr，而不是值。

  • targetOp - 要应用值的操作符。
  • parInfo - parInfo 字典。parInfo 字典的格式为 {<parName>:(par.val, par.expr, par.mode string, par.bindExpr, par.default, par.defaultExpr, par.defaultBindExpr, par.defaultMode string)...}
  • raiseExceptions：如果为 True，任何参数应用失败时都会抛出异常

applyParInfo(targetOp, parInfo, setDefaults=False, raiseExceptions=False)→ list:

尝试把 parInfo 字典中的参数值、表达式和模式应用到 targetOp。忽略 pageindex 参数。如果应用失败，除非 raiseExceptions 为 True，否则不会抛出异常！

  • targetOp - 要应用值的操作符。
  • parInfo - parInfo 字典。parInfo 字典的格式为 {<parName>:(par.val, par.expr, par.mode string, par.bindExpr, par.default, par.defaultExpr, par.defaultBindExpr, par.defaultMode string)...}
  • setDefaults - 如果为 True，同时设置 par.default
  • raiseExceptions：如果为 True，任何参数应用失败时都会抛出异常

panelParentShortcut(panel, parentShortcut)→ COMP with provided shortcut or None:

返回 panel 的第一个具有所提供 parentShortcut 的 panelParent。如果找不到带该快捷方式的 panelParent，则返回 None。

  • panel - 从中搜索的面板。
  • parentShortuct - 要查找的快捷方式。

getMenuLabel(menuPar)→ label string:

返回 menuPar 当前所选菜单项的标签

  • menuPar - 一个菜单样式的参数

setMenuLabel(menuPar, label)→ None:

把 menuPar 的所选菜单项设为 menuLabel == label 的那一项

  • menuPar - 一个菜单样式的参数
  • label - 要把菜单项设为的标签

messageDialog(text, title)→ None:

打开一个弹出对话框（延迟一帧），只带一个 OK 按钮

  • text - 对话框的文本
  • title - 对话框的标题

bindChain(par, parsOnly=False)→ list of [par, par's bind master, ...]:

返回一个参数列表，从 par 开始，随后是其 bind master（如果存在），再随后是其 master 的 master（如果存在），依此类推。

  • par - 开始链式搜索的参数
  • parsOnly - 如果为 True，只返回链中的参数

unbindReferences(par, modeOnly=False)→ list of references that were changed:

清除参数的 bindReferences 的绑定字符串，或更改其模式

  • par - 绑定主参数（bindMaster）
  • modeOnly - 如果为 True，只把引用的模式改为 prevMode

getCustomPage(comp, name)→ Page object or None if name not found:

按名称获取自定义页对象

  • comp - 带自定义页的 comp
  • name - 页名称

changeParStyle(p, style, size=1, includeValueData=True)→ A list of newly created parameters:

更改参数的样式

  • p - 要更改的参数
  • style - 参数的样式字符串（例如 'Int'、'Float'、'Menu' 等）
  • size - 对于多值参数（例如 'Int'、'Float'），值的数量为 1-4
  • includeValueData - 如果为 True，包含所有 val、expr、bind 设置

multiMatch(patterns, inputList, caseSensitive=True, useMinus=True)→ list:

返回 inputList 中与 patterns 匹配的子集，类似于你在模式匹配参数中填写的内容。

  • patterns - 以空格分隔的模式匹配字符串列表，用于检查
  • inputList - 要检查的字符串列表
  • caseSensitive - 为 True 时区分大小写
  • useMinus - 如果为 True，允许 "-" 出现在 patterns 中某项之前，以把匹配该项的结果排除在外。如果为 False，忽略任何前面带 "-" 的模式

formatString(format, dataDict=None)→ formatted string:

使用 f-string 格式化来格式化字符串。

使用 f-string 风格的格式字符串和数据字典返回格式化后的字符串。更多信息请搜索 "Python f-strings"，或查看 here。 用法示例：formatString('{num} red balloons', {'num': 99})... 返回 '99 red balloons'

  • format（字符串）- 用于格式化的 f-string
  • dataDict（字典，可选）- 可供格式字符串使用的值字典。默认为 {}。
