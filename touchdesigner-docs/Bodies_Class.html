Bodies 类

Bodies Class 描述 Actor COMP 中所有 Bodies 的集合（Actor COMP 由 Bullet Solver COMP 和 Nvidia Flex Solver COMP 使用）。Bodies 对象通过其 Actor COMP 访问，用法与 Python 列表非常相似。 

bodies = op('bsolver1/actor1').bodies	# 获取 Bodies 对象
print(len(bodies))						# Bodies 的数量
print(bodies[0])						# 列表中的第一个 Body
for b in bodies:
	print(b)							# 打印所有 Body

成员

没有该操作符专属的成员。

方法

没有该操作符专属的方法。
