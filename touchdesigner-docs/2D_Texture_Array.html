2D 纹理数组

2D Texture Array 很像 3D Texture。它的创建方式相同（Texture 3D TOP、GLSL TOP）。2D Texture Array 与 3D Texture 的唯一区别在于它们在贴图时的用法。3D Texture 使用归一化（0-1）的 w 纹理坐标采样，支持在 w 方向使用 repeat 和 clamp 等 extend 模式，并在 w 坐标落在不同切片之间时于切片间混合。3D Texture 不支持 mipmap。

而 2D Texture Array 使用非归一化的 w 坐标采样。第一个切片为 0，第二个切片为 1，第三个切片为 2，依此类推。切片之间不做混合（1.4 会得到与 1 相同的结果）。你可以在 GLSL 着色器中自行混合两个切片。在 2D Texture Array 中，每个切片都可以有 mipmap。w 方向的 extend 模式不受支持，如果你采样的索引超出数组末尾，将返回数组的最后一个切片。

GLSL

要使用 2D Texture Array，需要启用 OpenGL 扩展，方法是在着色器开头加入这一行：

 #extension GL_EXT_texture_array : enable

采样器声明为

 uniform sampler2DArray name;

并使用以下函数采样

 texture2DArray(samplerName, vec3)
