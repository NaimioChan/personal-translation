3D 父子关系

摘要

在层级中创建 3D 对象有两种方法，它们可以混用。

父子节点连接器

Object Component 类型（Geometry、Camera、Light、Null……）可以利用网络中节点的顶部和底部连接器放入 3D「层级」中。3D 层级会影响你在 Render TOP 以及任何 3D 组件类型查看器中看到的内容。

下图中 geo1 和 geo2 都是 null1 的「子级」。geo1 的最终变换，是把 null1 的变换施加到 geo1 的变换上得到的结果。每个 3D 对象的变换都是一个 4x4 矩阵，表示它的平移、旋转和缩放，由其 Xform 和 Pre-Xform 参数页上的参数定义。

当你通过顶部和底部连接器把一个 Component 连接到另一个 Component 时，就建立了「父子」或「层级」关系。通过父级的 Transform 参数页移动父级时，子级会随之移动。

每个 Component 只能有一个父级。

把 3D 组件放入另一个 3D 组件的网络

父子关系也可以通过在另一个 Object COMP 内部放置一个 Object COMP 类型来实现。这与用顶部/底部连接器连线等效。如果一个 COMP 通过其顶部连接器连到另一个 COMP，那么那个 COMP 就是它的变换父级。如果它的顶部连接器没有连到任何东西，那么它所在的 COMP 就是它的变换父级。

例如，如果你想让场景中包含从某个特定摄像机看到的世界视图，可以把 Geometry Component 的输出连接到 Camera Component 的输入。以这种方式定义父子关系意味着，你对几何所做的任何变换也会包含该摄像机。

矩阵运算

使用右乘向量约定（列向量）时，父级的变换按如下方式施加到子级的变换上：

 parentXForm * xform

另请参阅：Geometry COMP、Camera COMP、Light COMP
