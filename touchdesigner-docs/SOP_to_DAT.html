SOP to DAT

摘要

SOP to DAT 允许你从 SOP 中提取点、顶点和图元（例如多边形）数据及属性。

数据按列输出，第一列为 index。index 指代 Point 或 Primitive 编号。 如果是单值属性，Attributes 以列名 attrib 输出；如果是多值属性，则以 attrib(0)、attrib(1)、attrib(2) 等多个列输出。

另请参阅：Geometry Detail、Point、Point List、Point Class、Primitive、Prims Class、Polygon、Vertex、SOP、SOP Class、Script SOP、Point Groups、Primitive Groups、Attributes。

参数 - SOP To 页

SOP sop - 指定要从中提取数据的 SOP。
Extract extract - - 指定提取点数据还是图元数据。
  • Points points - 获取点数据。
  • Vertices vertices - 获取顶点数据。
  • Primitives primitives - 获取图元数据。
  • Detail detail - 获取整个几何集的数据。
Group group - 要提取的点或图元组。若未指定，则提取全部数据。
Attributes attrib - 要提取的属性。

点的专有属性可包括表示位置和权重的 P 与 Pw。

图元的专有属性包括 vertices 和 close。Vertices 列出图元中的点编号，close 报告该图元是否为闭合多边形。index 列为点或图元编号，始终会输出。

Copy Vertex UV to Points uvforpts - 将顶点 UV 复制到点 UV。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

SOP to DAT 的额外信息可通过 Info CHOP 获取。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
