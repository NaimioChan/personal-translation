Delete CHOP

摘要

Delete CHOP 会删除其输入的整个通道和/或单个采样。

要删除通道，可在 Channels 页按通道名或通道编号范围指定要删除的通道。第二种方法使用值范围来选取所有采样值都在某个范围内的通道。第三种方法删除恒定值的通道。还有一个选项可选择删除还是保留匹配的通道。

要删除单个采样（即不删除任何通道），可在 Samples 页删除例如值低于 0 的采样，这会缩短 CHOP 的长度。

在具有两个或更多通道的 CHOP 中，使用一个或多个「比较」通道来确定要删除哪些采样。默认情况下使用第一个通道进行比较。删除某个索引处的采样会删除所有通道在该处的值。如果有 4 个通道 red、green、blue、alpha，并指定 alpha 作为「比较」通道，就可以删除所有 alpha 为 0 的采样。如果一个 CHOP 有 X、Y、Z 位置三个通道，就可以删除 XYZ 长度低于阈值的所有采样。

这很有用，例如在将 CHOP 发送到 Geometry 组件进行实例化之前精简数据。

参数 - Channels 页

Delete Channels delchannels - 开关，用于启用通道删除。
Delete discard - 决定是删除还是保留作用域内的通道：
  • Scoped Channels scoped - 删除作用域内的通道，其余通道输出。
  • Non-scoped Channels nonscoped - 作用域内的通道输出，其余通道删除。
Select Channels select - 如何选择通道 - By Name，或按 Numeric 索引。
  • By Channel Name byname -
  • By Channel Number bynum -
Channel Names delscope - 在此输入作用域模式，以指定要删除或提取的通道名称。具体做法是指定作用域模式，详见 Pattern Matching。
默认作用域模式 t* 会作用到平移通道：tx、ty 和 tz，或任何名称以 t 开头的其他通道。
Channel Numbers selnumbers - 要删除或提取的通道索引。- 参见下面的数字模式。
Channel Value chanvalue - 选择值范围选取的类型：
  • Off off - 不执行范围选取。
  • Channel Completely Within Range complete - 通道的所有采样都必须在指定范围内，该通道才会被选中。
  • Channel Partially Within Range partial - 通道至少有一个采样在范围内，该通道就会被选中。
  • Channel Completely Outside Range outside - 通道的所有采样都不能在范围内，该通道才会被选中。
Value Range selrange - 用于 Range Selection 的范围下限值和上限值。
  • selrange1 -
  • selrange2 -
Select Constant Valued Channels selconst - 选择所有采样值都相同的通道。这些通道名模式用于选取输入 CHOP 中已有的通道，详见 Pattern Matching。

这些通道编号模式也可用于选取输入 CHOP 中已有的通道：

  • 0 1 4 - 匹配第一个、第二个和第五个通道。
  • [0-4] - 匹配前五个通道。
  • [3-9:2] - 匹配索引 3、5、7 和 9 处的通道。

参数 - Samples 页

Delete Samples delsamples - 开关，用于启用采样删除。
Channels to Compare compchans - 如何选择用于与条件比较的通道 - 按 Name、按 Numeric 索引、使用 First Channel，或使用 Last Channel。
  • Use First Channel firstchan -
  • Use Last Channel lastchan -
  • By Channel Name byname -
  • By Channel Number bynum -
Channel Names compnames - 在此输入作用域模式，以指定要用作比较通道的通道名。具体做法是指定作用域模式，详见 Pattern Matching。
Channel Numbers compnums - 要用作比较通道的通道索引，默认值为 0，即第一个通道。- 参见上面的数字模式。
Multi-Compare Channels compmulti - 如果存在多个比较通道，这决定在按条件检查之前如何处理比较通道中的值：
  • Any Chan in Range any - 如果任一比较通道满足条件，则删除该采样。
  • All Chans in Range all - 如果所有比较通道都满足条件，则删除该采样。
  • Add add - 将所有比较通道相加，如果结果满足条件则删除该采样。
  • Subtract sub - 从第一个通道中减去其余所有比较通道，如果结果满足条件则删除该采样。
  • Multiply mul - 将所有比较通道相乘，如果结果满足条件则删除该采样。
  • Divide div - 用第一个通道除以其余所有比较通道，如果结果满足条件则删除该采样。
  • Average avg - 求所有比较通道的平均值，如果结果满足条件则删除该采样。
  • Minimum min - 求所有比较通道的最小值，如果结果满足条件则删除该采样。
  • Maximum max - 求所有比较通道的最大值，如果结果满足条件则删除该采样。
  • Length len - 将所有比较通道视为向量并求其长度，如果结果满足条件则删除该采样。
Delete Condition condition - 选择采样要比较的条件：
  • Less Than Value 1 less - 如果参与比较的采样低于 Value 1，则删除。
  • Greater Than Value 1 greater - 如果参与比较的采样高于 Value 1，则删除。
  • Equal to Value 1 equal - 如果参与比较的采样等于 Value 1，则删除。
  • Not Equal to Value 1 notequal - 如果参与比较的采样不等于 Value 1，则删除。
  • Inside Range inside - 如果参与比较的采样位于 Value 1 与 Value 2 指定的范围内，则删除。
  • Outside Range outside - 如果参与比较的采样位于 Value 1 与 Value 2 指定的范围之外，则删除。
Value 1 value1 - 为 Value 1 设置数值。
Include Value 1 inclvalue1 - 切换 Value 1 是否包含边界。
Value 2 value2 - 为 Value 2 设置数值。
Include Value 2 inclvalue2 - 切换 Value 2 是否包含边界。
Delete Compare Channels deletecomp - 决定是删除还是保留比较通道。
One Sample if All Deleted onesample - 即使所有采样都被删除，也会保留一个采样。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Delete CHOP 特有的 Info 通道

  • actual_length -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
