POP 属性映射到参数

在部分 POP 的某些参数上，可以为 POP 的每个点设置不同的参数值。有些 POP 允许通过参数对话框上的 Map 页，将其 Attributes 之一映射到某个参数。

例如，在 Transform POP 的 Map 页上，可以选择一个属性或属性的一个分量，并将该属性的值映射到某个参数，从而为每个点给出不同的值。

Combine Operation 菜单让你选择如何将属性值与你在 OP 对话框中设置的参数值组合 —— 可以将它们相加（Add）、相乘（Multiply），或忽略参数中的值而直接设为属性值（Set）。

使用 Sequential Blocks，可以将多个属性映射到多个参数。

每个块都有一个可用属性的菜单和一个可映射到的可接受参数的菜单。你也可以从任何输入获取属性（默认 _in0）

另请参阅：Transform POP、Blend POP、Noise POP、Random POP、Line Smooth POP、Force Radial POP、Time Filter POP
