绝对时间

Absolute Time 在 TouchDesigner 进程启动时从 0 开始计数，并且（与循环的时间轴不同）始终递增。如果 UI 顶部的 Power 0|1 按钮处于 Off，或根时间轴被暂停，它就会暂停。

TouchDesigner 中的绝对时间以秒和帧表示，其中第 1 帧对应秒数 = 0。如果全局帧率为 60，那么第 61 帧对应 1 秒，依此类推。全局帧率通常锁定为运行 TouchDesigner 的电脑上显示器的刷新率，但实际上可以是任何值。见 Project_Class 中的 cookRate。

对应的 Python 类是 absTime，其成员为 absTime.frame 和 absTime.seconds。见 AbsTime_Class 和 absolute time。
