POP

摘要

POP（Point Operators）是一种 Operator Family，可处理 3D 几何或任何通用的数值数据，在 GPU 加速的显卡或芯片上运行，由 Render TOP 渲染，或传递给 DMX 灯光、LED 阵列、激光等设备或其他外部系统。

The primary introductory documentation for POPs and the POPs Example files are here: Learning About POPs

在 TouchDesigner 中运行 Help -> OP Snippets，可查看 500+ 个各类 POP 的示例。

另请参阅 Category:POPs，了解与 POP 相关的完整文章列表。
