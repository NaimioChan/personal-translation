Ouster

Ouster 生产用于以激光扫描 3D 环境的 LIDAR 设备。TouchDesigner 支持与运行 2.x 和 3.x 固件的 Ouster LIDAR 传感器进行实时的点云采集和录制。Ouster 数据可以用 TouchDesigner 的程序化、基于节点的工具实时处理，也可以利用 TouchDesigner 中支持在 GPU 上处理点云数据的功能。

Ouster OS1

TouchDesigner 支持的 Ouster 功能

  • TouchDesigner 直接支持 Ouster 全系列产品。传感器必须运行 2.0 或更高版本的固件。
  • 输出为全景格式。
  • X、Y、Z、Range、Signal、Reflectivity、Near IR 和 Flags 在 GPU 上被灵活映射到 RGBA 图像通道。
  • 附加传感器数据包括 IMU（惯性测量单元的陀螺仪和加速度计）。
  • Time Sync Mode 支持同一区域内的多台设备（Internal OSC、Sync Pulse In、PTP 1588）。支持自动启动功能、窗口剔除（window rejection）模式。

TouchDesigner 中的点云功能提升数据处理能力

  • TouchDesigner 可以实时采集 Ouster 32 位浮点数据流的全部 7+ 个通道。
  • 缓冲区选择操作提供了一种简便方式，可在 GPU 上用程序化、基于节点的工具提取设备通道并对其进行处理，从而最大限度减少甚至避免编写代码。
  • 采集到的点数据可以在任何 TOP 查看器中以 3D 点云或 2D 数组的形式查看。
  • RGBA Normalized 查看器模式提供了一种在归一化亮度空间中查看通道数据的方式，便于查看和检查 32 位数据。
  • 点可以用 Line Material 渲染，并根据到摄像机的距离控制点的大小。
  • 增强的实例化引擎提供了一种把 TOP 中的点云数据直接映射到 3D 摄像机渲染中的方法。实例化器为每个属性类别接受一张不同的 32 位 RGBA 纹理。
  • TouchDesigner 可以实时把 Ouster 流录制为一系列 OpenEXR 文件存储。它可以录制无限通道的 32 位浮点数据，并可自定义头部数据以存储 IMU 等元信息。这些内容可以实时回放。

参见：Ouster TOP、Ouster Select TOP、Point File In TOP、Movie File Out TOP。
