Polypatch SOP

摘要

Polypatch SOP 从 mesh 图元或一组面（多边形、NURBS 或 Bezier 曲线）创建平滑的多边形面片。

polypatchSOP_Class

参数 - Polypatch 页

Group group - 要使用的输入子集。接受模式匹配，详见 Pattern Matching。
Basis basis - 选择样条类型：Cardinal 或 BSpline。
  • Cardinal cardinal -
  • BSpline bspline -
Connectivity connecttype - 此选项用于选择所创建曲面的点如何连接。
  • Rows rows - 创建水平线，即开放多边形。
  • Columns cols - 创建垂直线，即开放多边形。
  • Rows and Columns rowcol - 行和列都创建，全为开放多边形。
  • Triangles triangles - 用三角形构建网格。
  • Quadrilaterals quads - 默认网格连接——四边四边形。
  • Alternating Triangles alttriangles - 生成相互对置的三角形；类似 Triangles 选项。
  • Inherit from Source inheritconnect - 选择此连接选项时，输出网格将具有与输入外壳网格相同的连接关系。
U Wrap closeu - U 方向包裹的设置。
  • Off nonewu - 不在 U/V 方向包裹。
  • On wu - 在 U/V 方向包裹。
  • If Primitive does ifprimwu - 如果输入图元如此，则在 U/V 方向包裹。
V Wrap closev - V 方向包裹的设置。
  • Off nonewv - 不在 U/V 方向包裹。
  • On wv - 在 U/V 方向包裹。
  • If Primitive does ifprimwv - 如果输入图元如此，则在 U/V 方向包裹。
U Clamp (First) firstuclamp - U 方向起始端夹紧的设置。
  • Off firstuclampoff - 不在 U/V 方向夹紧首/末端。
  • On firstuclampon - 在 U/V 方向夹紧首/末端。
  • If primitive does firstuclampifprim - 如果输入图元如此，则在 U/V 方向夹紧首/末端。
U Clamp (Last) lastuclamp - U 方向末端夹紧的设置。
  • Off lastuclampoff - 不在 U/V 方向夹紧首/末端。
  • On lastuclampon - 在 U/V 方向夹紧首/末端。
  • If primitive does lastuclampifprim - 如果输入图元如此，则在 U/V 方向夹紧首/末端。
V Clamp (First) firstvclamp - V 方向起始端夹紧的设置。
  • Off firstvclampoff - 不在 U/V 方向夹紧首/末端。
  • On firstvclampon - 在 U/V 方向夹紧首/末端。
  • If primitive does firstvclampifprim - 如果输入图元如此，则在 U/V 方向夹紧首/末端。
V Clamp (Last) lastvclamp - V 方向末端夹紧的设置。
  • Off lastvclampoff - 不在 U/V 方向夹紧首/末端。
  • On lastvclampon - 在 U/V 方向夹紧首/末端。
  • If primitive does lastvclampifprim - 如果输入图元如此，则在 U/V 方向夹紧首/末端。
Output Divisions divisions - 输出曲面的细分数量。如需更平滑的曲面，使用更多细分。
  • X divisionsx -
  • Y divisionsy -
Output Polygons polys - 强制输出多边形而不是 mesh。

Info CHOP 通道

Polypatch SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
