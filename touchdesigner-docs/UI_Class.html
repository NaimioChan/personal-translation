UI 类

UI 类描述对应用程序 UI 元素的访问，这些元素位于自动导入的 td module 中。

要访问此类的成员和方法，请使用默认实例 ui。

例如：

# 打开 Midi Device Mapper 对话框
ui.openMIDIDeviceMapper()

成员

clipboard → str :

获取或设置操作系统剪贴板的文本内容。

colors → Colors (Read Only):

访问应用程序 colors。

dpiBiCubicFilter → bool :

获取或设置 TouchDesigner 窗口的全局 DPI 缩放过滤模式。True 表示双三次，False 表示线性。

masterVolume → float :

获取或设置主音频输出音量。值为 0 表示无输出，值为 1 表示全输出。

options → Options (Read Only):

访问应用程序 options。

panes → Panes (Read Only):

访问所有 panes 的集合。

performMode → bool :

获取或设置 Perform Mode。设为 True 进入 Perform 模式，设为 False 进入 Designer Mode。

preferences → Preferences (Read Only):

访问应用程序 preferences，也可通过 Preferences Dialog 访问。

redrawMainWindow → bool :

获取或设置主窗口是否应重绘。主窗口是主网络编辑器或 perform 窗口。

rolloverOp → OP | None (Read Only):

网络编辑器中当前鼠标下的操作符。

rolloverPar → Par | None (Read Only):

参数对话框中当前鼠标下的参数。

rolloverParGroup → ParGroup | None (Read Only):

参数对话框中当前鼠标下的 ParGroup。

rolloverPanel → PanelCOMP | None (Read Only):

返回当前鼠标下的面板。

rolloverPage → Page | None (Read Only):

返回参数对话框中当前鼠标下的页面。

rollover → Par | ParGroup | Page | OP | PanelCOMP | None (Read Only):

将其他 rollover 成员合并为一次检测，报告鼠标下的 TD 对象。由于存在一些重叠，优先级顺序为：Par | ParGroup | Page | OP | Panel。注意： Panel 和 OP 检测都会返回 PanelCOMP，因此要区分鼠标悬停在网络中的 PanelCOMP 操作符上还是活动的 Panel 上，你可能需要使用具体的 rolloverPanel 或 rolloverOP 方法。

lastChopChannelSelected → Channel (Read Only):

最后通过鼠标选中的 CHOP channel。

showPaletteBrowser → bool :

获取或设置调色板浏览器的显示。

status → str :

获取或设置状态消息。 

ui.status = 'Operation Complete'

undo → Undo (Read Only):

Undo 对象，提供对应用程序撤销功能的访问。

windowWidth → int (Read Only):

获取应用窗口宽度。

windowHeight → int (Read Only):

获取应用窗口高度。

windowX → int (Read Only):

获取应用窗口的 X 位置。

windowY → int (Read Only):

获取应用窗口的 Y 位置。

方法

copyOPs(listOfOPs)→ None:

将操作符列表复制到操作符剪贴板。所有操作符必须是同一组件的子级。

  • listOfOPs - 包含一个或多个要复制的 OP 的列表。
ui.copyOPs( op('geo1').selected )

pasteOPs(COMP, x=None, y=None)→ None:

将操作符剪贴板的内容复制到指定组件中。

  • COMP - 接收操作符的目标组件。
  • x - 可选，粘贴操作符的网络坐标。
  • y - 见 x
l = ui.pasteOPs( op('geo2') )

messageBox(title, message, buttons=['Ok'])→ int:

此方法将打开一个带有指定消息的消息对话框。返回所点击按钮的索引。

  • title - 指定窗口标题。
  • message - 指定对话框的内容。
  • buttons -（关键字，可选）指定要在对话框中显示的按钮标签列表。
# 基本用法
ui.messageBox('Warning', 'Have a nice day.')
# 指定选项并报告结果
a = ui.messageBox('Please select:', 'Buttons:', buttons=['a', 'b', 'c'])
ui.messageBox('Results', 'You selected item: ' + str(a))
# 按路径选取节点
ui.messageBox('Please select:', 'Nodes:', buttons=parent().children)
# 按首名称选取节点（列表推导式）
ui.messageBox('Please select:', 'Nodes:', buttons=[x.name for x in parent().children])
# 选取一个单元格
ui.messageBox('Please select:', 'Cells:', buttons=op('table1').cells('*','*'))

refresh()→ None:

立即更新并重绘所有视口、节点、UI 元素等。否则此更新会在所有脚本执行结束时每帧执行一次。例如，如果在脚本中手动更改了当前帧，调用 refresh 会使所有相关数据立即更新。 

for i in range(100):
	ui.status = str(i)
	ui.refresh()

chooseFile(load=True, start=None, fileTypes=None, title=None, asExpression=False)→ str | None:

打开用于加载或保存文件的对话框。返回所选文件名，如果对话框被取消则返回 None。

  • load -（关键字，可选）如果设为 True，对话框将是加载对话框，否则为保存对话框。
  • start -（关键字，可选）如果提供，指定初始文件夹位置和/或文件名选择。
  • fileTypes -（关键字，可选）如果提供，指定可用作过滤器的文件扩展名列表。否则「*.*」是唯一的过滤器。
  • asExpression -（关键字，可选）如果设为 true，结果以表达式形式提供，适用于 Parameter 表达式或作为 eval() 调用的输入。结果中可包含 samplesFolder 等 App Class 成员常量。
  • title（关键字，可选）如果提供，将覆盖默认窗口标题。
a = ui.chooseFile(start='python_examples.toe', fileTypes=['toe'], title='Select a toe') # 指定扩展名
a = ui.chooseFile(fileTypes=tdu.fileTypes['image'], title='Select an image') # 任意支持的图像扩展名
path = ui.chooseFile(load=False,fileTypes=['txt'],title='Save table as:')
if (path):
	op('table1').save(path)

chooseFolder(title='Select Folder', start=None, asExpression=False)→ str | None:

打开用于选择文件夹的对话框。返回所选文件夹，如果对话框被取消则返回 None。

  • title -（关键字，可选）如果提供，指定窗口标题。
  • start -（关键字，可选）如果提供，指定初始文件夹位置和/或文件名选择。
  • asExpression -（关键字，可选）如果设为 true，结果以表达式形式提供，适用于 Parameter 表达式或作为 eval() 调用的输入。结果中可包含 samplesFolder 等 App Class 成员常量。
a = ui.chooseFolder()
a = ui.chooseFolder(title='Select a folder location.')

viewFile(URL_or_path, showInFolder=False)→ None:

在默认外部应用程序中查看 URL 或文件。你可以使用 ui.viewFile() 在 Windows 资源管理器或 macOS Finder 中打开文件夹/目录。

  • URL_or_path - 要启动的 URL 或路径。
a = ui.viewFile('output.txt')
  • showInFolder - 在资源管理器或 macOS Finder 中显示为选中状态，而不是启动外部应用程序。
a = ui.viewFile('output.txt', showInFolder=True)
