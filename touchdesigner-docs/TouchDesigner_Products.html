TouchDesigner 产品

所有 TouchDesigner 使用均受 TOUCHDESIGNER USER AGREEMENT 的条款与条件约束。

产品

TouchDesigner 有 4 种可用的许可证类型。

TouchDesigner Non-Commercial

  • non-commercial 许可证，免费用于个人和教育用途。

TouchDesigner Educational

  • educational 许可证，面向学生和教育机构。功能与 Commercial 相同，但仅限非商业用途。价格 300 美元。

TouchDesigner Commercial

  • commercial 许可证，用于付费项目，价格 600 美元。

TouchDesigner Pro

  • pro 许可证，含支持，价格 2200 美元。


Non-Commercial、Commercial 和 Pro 的功能对比表见 Licensing。

TouchDesigner Non-Commercial

TouchDesigner Non-Commercial 一个免费提供、供个人和非商业使用的 TouchDesigner 版本。

  • TouchDesigner Non-Commercial 可免费用于非商业用途 ONLY。（准确地说，「你不会因使用 TouchDesigner 的工作而获得金钱或报酬」）
  • 图像分辨率限制为 1280x1280。（例外：高度为 1 或 2 像素的图像可以是任意分辨率，用于 ramp。参见下面的 Commercial。）
  • 不包含 Pro/Commercial 操作符的一部分子集（如 Shared Memory OP、DirectX OP、Leuze ROD4 CHOP 等）。
  • 密钥为一次性使用，不能在计算机之间转移。每个账户会获得 10 个密钥，用完请联系我们。
  • 不包含任何直接支持，仅提供 forum 支持。

功能对比见 Licensing。

TouchDesigner Educational and Commercial

TouchDesigner Educational 与 Commercial 的功能集完全相同，只是预期用途不同。


Educational

面向学生和学校，non-commercial and educational uses only 提供。（准确地说，「你不会因使用 TouchDesigner 的工作而获得金钱或报酬」）

学生和学校管理者必须注册 Educational 许可证，并经 Derivative 批准后才能购买该许可证。Register Here

  • 普通 Educational 许可证每份 300 美元。可与 Key Manager Dialog 或 License Dongle 一起使用（不含）。
  • Floating Cloud Commercial 许可证每份 450 美元
  • 在 STORE 中购买 TouchDesigner Educational。
  • Volume Discounts 可用于 TouchDesigner Educational。

关于在教育机构中设置 TouchDesigner 的更多信息，另请参阅 Educational Setup。

Commercial

Commercial（或 Pro）许可证是 required for any project or work done with TouchDesigner that you receive money or compensation for。

示例包括：a）你在做有报酬的项目；b）你用 TouchDesigner 推广自己的作品以创造收入；c）你或团队使用多台计算机制作大型商业项目的各部分。在所有这些情况下，这些项目所用的所有计算机都需要 Commercial 许可证。

  • 普通 Commercial 许可证每份 600 美元。可与 Key Manager Dialog 或 License Dongle 一起使用（不含）。
  • Floating Cloud Commercial 许可证每份 900 美元
  • 在 STORE 中购买 TouchDesigner Commercial。

解锁的功能

  • 以硬件支持的任意分辨率进行图像分辨率与合成
  • 实时创建 H.264/H.265 影片（需要 Nvidia GPU）
  • 使用 Video Stream Out TOP 通过 RTSP、RTMP 或 SRT 流式传输纹理（需要 Nvidia GPU）
  • 最多 2 个以 1920x1080 运行的 Notch 操作符（需要 Notch 许可证）
  • LIDAR 扫描仪 Ouster TOP
  • 激光扫描仪 Leuze ROD4 CHOP
  • 所有 Shared Memory 操作符
  • 向 DirectX 应用发送 send 和 receive 纹理
  • 在其他应用中使用 TouchEngine
  • 可选择在启动时隐藏 TouchDesigner 启动画面
  • Commercial 许可证对应一台计算机的一个商业密钥
  • 密钥可以在计算机之间移动
  • 不包含任何直接支持，仅提供 forum 支持

另请参阅 TouchDesigner Pro

TouchDesigner Pro

TouchDesigner Pro 包含 TouchDesigner 所提供的一切。

Pro Support

购买 Pro 许可证即可加入我们的 Pro Support 计划。我们的团队可以帮你满足任何编程、制作或咨询需求。用我们多年的经验让你的工作更轻松。

每份 Pro 许可证包含 6 小时 Pro Support。更大任务和额外支持可购买更多小时。计划包含的内容详见 Pro Support。

解锁的功能

  • Notch 操作符，无任何分辨率限制（需要 Notch 许可证）
  • 通过 Vioso TOP 或 Scalable Display TOP 进行第三方投影校准
  • 用于摄像机的 Stype 光学跟踪
  • 用于来自 BlackTrax Motion Tracking Systems 的跟踪数据：BlackTrax CHOP
  • 用 Sync In CHOP 和 Sync Out CHOP 同步多个进程或系统
  • 硬件帧锁定（NVIDIA Gsync / AMD S400 同步卡）
  • Privacy Options 用于私有 .toe 文件和私有组件。创建没有密码就无法访问的 .toe 项目文件或 .tox 组件文件。此外你还可以创建只能在 USB License Dongle 下运行的组件。详情见 Privacy。
  • 用于混合运动通道：Clip Blender CHOP、Clip CHOP、Clip DAT
  • 针对你所使用版本的缺陷修复
  • 软件修复/RFE 不保证，但 Pro 用户会获得优先服务。
  • Pro Support 计划，可直接接触 Derivative 的程序员和产品专家。

功能对比见 Licensing。

另请参阅 TouchDesigner Commercial 和 TouchDesigner Educational

旧版产品

077

TouchPlayer077 和 TouchDesigner077 已不再支持，但最新版本可在此获取。这些产品需要许可证。

Download TouchDesignerFTE 077 这是 TouchDesigner FTE 077 的最终版本。（FTE = Free Thinking Edition for learning）

Download TouchDesignerPro 077 这是 TouchDesigner Pro 077 的最终版本。

Download TouchPlayer 077 这是 TouchPlayer 077 的最终版本。

017

TouchPlayer017、TouchMixer017 和 TouchDesigner017 已于 2007 年停止，但仍可在此获取。这些产品不需要许可证。

Download TouchDesigner017 这是最终版 TouchDesigner 017 的未授权版本。

Download TouchMixer017 这是最终版 TouchMixer 017 的未授权版本。

Download TouchArt017。其中包含约 100 件用 TouchDesigner 017 制作的实时作品。要获得完整的 MIDI 和播放功能，请先安装此软件，再安装 TouchMixer 017。可通过 Dialogs -> Window Placement 在双显示器下运行。你甚至可以把它的视频送入 077 及更高版本的 Touch In TOP。

注意： TouchArt 内置的 017 Touch Tools 需要许可证，而该许可证已不再提供。请使用上文的无许可证 TouchDesigner 017 和 TouchMixer 017 来使用 TouchArt 作品。
