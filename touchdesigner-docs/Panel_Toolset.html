面板工具集

Panel 组件

TouchDesigner 控制面板的构建中用到 5 种 Panel 组件。它们位于 OP Create Menu 的「COMP」部分。按 <Tab> 并选择「COMP」，你会在列表顶部看到深灰色的 Panel 组件。它们是：Button、Slider、Container、Field、Select。

面板值

所有控制面板控件（即各种 Panel 组件类型）都有一组由所谓「Panel Values」表示的状态。完整的面板值列表见 Panel Value 页面。

正是用户与控件的交互 sets 了所有面板值。

面板值可在几个地方 accessed：

  • 一个 Panel CHOP，你可以把它放进任何控件，在那里还能看到该控件可能的面板值列表。把 Panel CHOP 放进 Button 组件，显示该按钮组件的查看器，观察 Panel CHOP 中面板值的变化。
  • panel() 表达式，可在其中查询某个变量的状态。
  • 在面板组件上中键点击，会显示所有面板值的名称和值。
  • Panel Execute DAT 可让你根据任何面板值的变化或状态触发脚本。把 Panel Execute DAT 放进 Button COMP，在 Panel Value 参数菜单中查看值列表。选择要用作触发脚本的面板值。

Panel CHOP

Panel CHOP 与 Panel Components 配合工作，抓取所有 Panel Values 并输出为 CHOP 通道。把这些通道导出到参数，是把自定义 UI 面板连接到项目中各操作符参数最直接的方式。

Panel CHOP 只有 3 个参数：

Component - 指定 Panel CHOP 从中取值的组件。你可以把任何面板组件拖放到此参数上。若此路径留空，则默认为 Parent 组件。

Select - 选择要输出哪些值。默认为 '*'，即「所有值」。可通过右侧的下拉菜单选择子集，或输入你关心的值的名称。也可使用 Pattern Matching 选择多个值。

Rename - 可让你重命名所选通道。

Panel 组件参数

所有 Panel 组件都有 3 个用于创建控制面板的通用参数页：Layout 页、Panel 页和 Color 页。此外，Button、Field 和 Slider 组件还各有一个同名参数页，用于存放该面板类型特有的参数。
