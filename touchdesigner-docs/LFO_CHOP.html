LFO CHOP

摘要

LFO CHOP（低频振荡器）以两种方式实时生成波形。它使用 Sine 或 Pulse 等常用波形合成曲线，或者重复一条准备好的输入曲线。

它按取决于 Frequency 参数和 Octave Control 输入的速率逐步遍历波形。要观察其行为，可在其输出上接入一个 Trail CHOP，并更改 Frequency 参数。

LFO CHOP 最多可连接三个输入 CHOP：

Octave Control - 没有这第一个（可选）输入时，频率就是 Frequency 参数。如果连接了此输入，每个单位都会使频率翻倍：Octave Control 为 1 时频率翻倍，为 2 时为 4 倍，为 -1 时为 Frequency 参数的一半，为 0 时频率不变。

Reset - 第二个（可选）输入包含开关值（小于等于 0 或大于 0），用于从波形起点重新开始振荡器的通道。重置方式取决于 Reset Condition 菜单的设置。默认情况下，当 Reset 输入从 off 变为 on 时，会重置波形并立即开始波形。如果 Reset Condition 设为「While On」，重置值将保持到 Reset 输入变为 off。重置意味着「停止振荡器，并将其定位到波形的起点」。

Source Wave - 第三个（可选）输入用于替换波形 Type。它是一个多采样 CHOP 曲线，可包含任意数量的通道，但受 Channel 页上定义的通道数限制。波形 Type 参数会被禁用。

LFO CHOP 可作为通用的运动时间扭曲与重复器。如果更改 Frequency，就可以控制时间扭曲。

与 Wave CHOP 不同，这是一个时间切片 CHOP，即它边运行边生成波形，并在 Frequency 变化时加快或减慢遍历波形 Type 的速度。与 Audio Oscillator CHOP 不同，LFO CHOP 是为非音频频率设计的。

另请参阅：Audio Oscillator CHOP、Wave CHOP、Pulse CHOP。

参数 - LFO 页

Type wavetype - 要重复的波形形状，除非被 Source Wave 覆盖：
  • Sine sin - （-1 到 1）正弦波。
  • Gaussian normal - （0 到 1）高斯（也称钟形或正态）曲线。
  • Triangle tri - （-1 到 1）上升到 1 再下降到 -1 的斜坡，可用 Bias 参数塑形。
  • Ramp ramp - （0 到 1）从 0 到 1 的斜坡。
  • Square square - （-1 到 1）阶跃上升/阶跃下降，可通过 Bias 控制使其成为矩形。
  • Pulse pulse - 一个采样输出 1，其他为 0。
Play play - 为 1 时 LFO 振荡，为 0 时停止。可理解为播放与暂停。
Frequency frequency - 振荡的每秒周期数。连接 Octave Control 输入后，它将以指数方式改变频率。
Offset offset - 可以为 CHOP 输出的值加上偏移。
Amplitude amp - 可以对 CHOP 输出的值进行缩放。
Bias bias - Triangle、Gaussian 和 Square 波的形状控制。对三角波，它移动峰值。对方波，它改变峰的宽度。零表示无偏置。
Phase phase - 值 .5 表示 180 度的相移，即半个周期。
Reset Condition resetcondition - 此菜单决定 Reset 输入如何触发通道重置。
  • Off to On offtoon - 当 Reset 输入由关变开时重置通道。
  • While On on - 当 Reset 输入为开时重置通道。通道将保持重置值，直到输入变为关。
  • On to Off ontooff - 当 Reset 输入由开变关时重置通道。
  • While Off off - 当 Reset 输入为关时重置通道。通道将保持重置值，直到输入变为开。
Reset reset - 此开关在 On 期间将通道重置为 0。
Reset Pulse resetpulse - 此按钮立即将通道重置为 0。

参数 - Channel 页

Channel Name channelname - 通道名称列表。可以使用 chan[1-10] 这样的模式来生成 10 个通道。请参阅 Pattern Expansion。

通过在 frequency 通道等参数中加入通道索引变量 $C，可使每个通道各不相同。

Sample Rate rate - CHOP 的采样率。默认采样率为每秒 60 个采样。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

可通过 Info CHOP 访问 LFO CHOP 的额外信息。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
