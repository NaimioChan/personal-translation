Logger 日志组件

在 TouchDesigner 中记录日志

Starting with 在 2023.10k branch 上公开发布的第一个版本，TouchDesigner 现在自带 Palette:logger COMP。

此外，TouchDesigner 内部还运行着两个 Logger COMP 实例。

所有日志消息都保留在项目所运行的机器上（本地），不会发送到 Derivative 拥有的服务器或第三方服务。

第一个记录器可通过 op.TDResources.TDAppLogger 供所有人访问，它是一个根记录器，默认情况下所有其他记录器都以其为父级。第二个记录器在内部供我们的系统工具记录消息。遇到异常问题时，我们可能会请你把日志文件发送给我们。

在任何地方，用户都可以依赖 op.TDResources.TDAppLogger 并调用 the methods promoted on its extension。

希望获得更定制体验的用户，可从调色板组件库拖放 Palette:logger COMP 并调整所有参数。

一个好的起点是在项目根目录设置一个新的记录器，使其基于项目。将其分解为各个较大组件的独立记录器，会是非常 Python 化的做法。

Logger COMP 是对 Python logging 库的封装。其中 loggerCOMP.Logger 成员实际上是 Python Logging Library 中的 Logger 对象。高级用户可据此扩展 Logger COMP 的功能。

使用不当的日志记录会带来性能开销。用户应 visit this page，这同样适用于 TouchDesigner。
