文件夹

TouchDesigner 中的「Folder」始终指 Windows 或 macOS 操作系统中包含文件和其他文件夹的目录/文件夹系统。

相比之下，TouchDesigner 的「Path」是 TouchDesigner 内部的组件层级。Path 是节点的位置，该节点可以是包含其他节点的组件。

文件夹和文件系统路径出现在读取文件的操作符中，例如 Folder DAT、Movie File In TOP、File In CHOP、File In DAT、Audio File In CHOP。

互联网上的文件系统文件可以在 TouchDesigner 参数中用其 URL 引用：http://www.internetplace.com/Movies/movie1.mp4，它会下载该文件并从本地临时文件读取。
