Text SOP

摘要

Text SOP 用系统上安装的任意 TrueType 或 OpenType 字体，或磁盘上任意 TrueType/OpenType 字体文件创建文本几何。支持 Unicode。

另请参阅：Text TOP、Unicode。

textSOP_Class

参数 - Text 页

Font font - 从此下拉菜单中为文本选择字体。所有字体由操作系统提供，任何加载到操作系统中的 TrueType 字体都可使用。
Font File fontfile - 指定任意 TrueType 或 OpenType 字体文件（.ttf, .otf file）用于文本。使用字体文件时，上方的 Font 菜单会被禁用。
Bold bold - 以 bold 显示文本。
Italic italic - 以 Italic 显示文本。
Font Size X fontsizex - 设置 X（水平）方向的字号。字号定义从基线到给定字体布局框顶部的距离。默认字体的大小 1 接近于没有下伸部分的大写字母的垂直高度。
Font Size Y fontsizey - 设置 Y（垂直）方向的字号。
Keep Font Ratio keepfontratio - 忽略 Font Size 中的 Y 值。把 X 和 Y 尺寸都设为 Font Size X。
Scale Font to BBox Height scalefontobboxheight - 缩放字体的垂直尺寸，使其基于字体的垂直边界框。
Output output - - 指定几何输出为 Triangles、Closed Polygons 或 Open Polygons。
  • Triangles triangles - 输出为三角化网格，适合着色渲染。
  • Closed Polygons (Filled Holes) closedpolys - 输出为一组分离的闭合轮廓，适合 Laser CHOP、Extrude SOP 等。追加一个 Hole SOP 以正确处理孔洞。
  • Open Polygons openpolys - 输出为一组分离的开放轮廓，适合 Laser CHOP 等。始终以线框渲染。
Level of Detail levelofdetail - 通过给几何添加/移除细分来控制文本形状的质量。
Language language - 语言类型提示，帮助正确格式化字形。应为 Text TOP/SOP Unicode Language Abbreviations 表中的缩写。
Reading Direction readingdirection - - 用于设置语言是从左到右阅读，还是从右到左阅读。
  • Left To Right lefttoright -
  • Right To Left righttoleft -
Kerning kerning - - 在 X 和 Y 方向字母之间添加的间距量。Kerning 是在字母之间添加任意偏移的方式。每种字体本已有默认偏移，使字母彼此紧贴。Kerning 参数在此基础上再加，并允许 Y 偏移。
  • kerning1 -
  • kerning2 -
Line Spacing linespacing - 决定文本行之间的间距。
Horizontal Align alignx - - 设置水平对齐方式。
  • In Reading Direction reading -
  • Left left - 文本左对齐。
  • Center center - 文本居中。
  • Right right - 文本右对齐。
Word Wrap wordwrap - 勾选后，当文本占用下面 Word Wrap Size 参数设定的空间时自动换行。
Word Wrap Size wordwrapsize - 决定换行前使用的 3D 空间量。
Text text - 要创建为几何的文本字符串。如果需要换行或制表符，推荐的做法是把此参数改为表达式模式，并指定包含 \n 或 \t 的 Python 字符串来表示换行和制表符。例如 'First Line\nSecond Line'。
Legacy Parsing legacyparsing - Note, it's recommended to use a Python expression in the Text parameter instead of enabling legacy parsing, as this parsing can easily run into issues with more complex strings. 启用后，若 Text 参数处于常量模式，\t 和 \n 字符序列将分别转换为制表符和换行符。否则 \t 和 \n 序列会保留为字面的 \ 加 t 以及 \ 加 n。

Info CHOP 通道

可以通过 Info CHOP 访问 Text SOP 的额外信息。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
