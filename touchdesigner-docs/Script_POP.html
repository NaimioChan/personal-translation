Script POP

摘要

Script POP 可以构建完整的 POP，既可作生成器（无输入），也可作其输入 POP 的过滤器。它可以创建点和所有图元类型。它可以创建任何数据类型的点属性、图元属性和顶点属性。它可以创建 Array Attributes，并可设置其 Dimension。

Script POP 每次计算时运行 Python 脚本。它可以在 CPU 上从 GeometryStagingData 对象构建 POP 几何，然后一次性上传到 GPU。默认情况下，Script POP 创建时带有一个停靠的 DAT，其中包含三个 Python 方法：cook()、onPulse() 和 setupParameters()。每次 Script POP 计算时会运行 cook() 方法。每当按下 Script 页上的 Setup Parameter 按钮时，会运行 setupParameters() 方法。每当推入自定义脉冲参数时，会运行 onPulse() 方法。

要构建 POP 几何，必须先调用 createGeometryStagingData() 创建 GeometryStagingData 对象。所有几何数据准备好后，调用 buildGeometry() 会分配所需资源并把暂存数据上传到 GPU，从而完成整个过程。

另请参阅：POP Class、GeometryStagingData Class、AttribList Class

另请参阅：Script SOP、Script CHOP、Script DAT、Script TOP。

这些函数包含在 docked 节点 script1_callbacks 中的默认脚本里。

Script POP Callbacks

me - this DAT

scriptOp - the OP which is cooking
"""

# 在 OP 中按下 'Setup Parameters' 来调用此函数，以重新创建

def onSetupParameters(scriptOp: scriptPOP):
	"""
	Called to setup custom parameters for the Script POP.
	"""
	page = scriptOp.appendCustomPage('Custom')
	p = page.appendFloat('Value', label='Value')
	return

def onPulse(par: Par):

	Args:
		par: The parameter that was pulsed
	"""
	return

def onCook(scriptOp: scriptPOP):
	"""
	Called when the Script POP needs to cook.

	"""
	# 创建几何暂存数据对象
	stagingData = scriptPOP.createGeometryStagingData()
	
	# 创建位置点属性
	stagingData.createPointAttrib(name="P")
	# 一次添加一个位置值
	stagingData.appendPointAttribValue("P", (0,0,0))
	# 添加多个位置值
	stagingData.appendPointAttribValues("P", [(1,1,0), (0,1,0)])

	# inputPoints = scriptOp.inputs[0].points("P", delayed=False)
	# stagingData.appendPointAttribValues("P", inputPoints)

	# 创建颜色点属性
	stagingData.createVertAttrib(name="Color", numComps=4, numMatCols=1, isArray=False, arrSize=1, type=AttribDataType.FLOAT32, qualifier=AttribQualifier.COLOR, defaultValue=(0,0,1,1))
	# 追加两个颜色属性值。缺失的值将设为默认值
	stagingData.appendVertAttribValues("Color", [(0,1,0,1),(1,0,0,1)] )

	# 用这些点索引追加一个三角形图元
	stagingData.appendPrimTriangle(0, 1, 2)
	
	# 分配暂存数据并上传到 GPU
	scriptOp.buildGeometry(stagingData)
    return

def onGetCookLevel(scriptOp: scriptPOP) -> CookLevel:
	"""
	Sets the scriptOp's cook level, the conditions necessary to cause a cook.

	Return one of the following:
		CookLevel.AUTOMATIC - inputs changed and output being used. 
							 TD default behavior.
		CookLevel.ON_CHANGE - inputs changed, output used or not.
		CookLevel.WHEN_USED - every frame when output is being used
		CookLevel.ALWAYS - every frame
	"""

	return CookLevel.AUTOMATIC

Info CHOP 通道

Script POP 的额外信息可通过 Info CHOP 获取。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
