WebSocket DAT

摘要

WebSocket DAT 接收并解析WebSocket消息。WebSockets 是 Web 服务器与客户端使用的一种快速、高效的双向通信协议。每条消息都会被解析并作为一行追加到 DAT 的表格中。该表格为 FIFO「先进先出」，行数限制由参数设定。可为每个收到的数据包运行可选脚本。也支持安全（TLS）WebSocket 服务器。 支持连接到不同的 WebSocket 站点，无需手动设置标头。

WebSocket DAT 会将状态和错误消息打印到 TouchDesigner 文本控制台。可通过设置环境变量 TOUCH_TEXT_CONSOLE=1 启用文本控制台（参见：https://docs.derivative.ca/Variables#System_Environment_Variables）。文本控制台会在下次启动 TouchDesigner 时打开。

SocketIO 支持请参阅SocketIO DAT。

另请参阅：TCP/IP DAT

示例项目：chat with WebSockets

websocketDAT_Class

参数 - Connect 页

Active active - 开启时，DAT 接收发送到该网络端口的信息。关闭时不会更新。发送到该端口的数据会丢失。
Network Address netaddress - 服务器计算机的网络地址。此地址是标准 WWW 地址，例如foo或foo.bar.com。可以填 IP 地址（例如100.123.45.78）。如果填localhost，表示连接的另一端在同一台计算机上。
Network Port port - 该 DAT 接收消息所用的端口。端口 443 表示安全连接。如果尝试使用非 443 端口建立安全连接，则 Network Address 参数上需要加 “wss://” 前缀。
Connection Timeout timeout - WebSocket DAT 等待连接服务器的毫秒数。注意：这是上限，连接可能在达到连接超时前就失败。

参数 - Received Messages 页

Callbacks DAT callbacks - 每收到一条消息，Callbacks DAT 执行一次。
Execute from executeloc - 决定脚本的运行位置。
  • Current Node current - 脚本从当前节点位置执行。
  • Callbacks DAT callbacks - 脚本从 Callbacks DAT 参数中指定的 DAT 所在位置执行。
  • Specified Operator op - 脚本从下方 From Operator 参数指定的操作符中执行。
From Operator fromop - 当 Execute from 设为 Specified Operator 时，其状态变化将触发 DAT 执行脚本的操作符。如果 Execute from 参数设为 Specified Operator，该操作符也是脚本执行时的所在路径。
Clamp Output clamp - 该 DAT 默认限制为 100 条消息，但使用 Clamp Output 可以设为任意值，包括无限制。
Maximum Lines maxlines - 限制消息数量，较旧的消息会先从列表中移除。
Clear Output clear - 删除除标题外的所有行。若要用 python 脚本清除 op("opname").par.clear.pulse()
Bytes Column bytes - 在单独的列中输出消息的原始字节。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

操作符输入

  • Input 0: -

Info CHOP 通道

WebSocket DAT 的额外信息可通过Info CHOP访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
