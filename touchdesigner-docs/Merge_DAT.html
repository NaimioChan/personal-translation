Merge DAT

摘要

Merged DAT 是一种多输入 DAT，用于把输入 DAT 的文本或表格合并在一起。

mergeDAT_Class

参数 - Merge 页

DAT dat - 指定要合并的 DAT 的路径。可以与操作符的连线输入一起使用。
How how - - 设置表格如何合并在一起。
  • Append Rows row - 把后续表格的行添加到第一个表格，以此合并表格。若使用 By Name 选项，后续表格的数据会添加到同名的列中，并且不会添加第一行。如果后续表格的列数多于输入表格，多出的列会被追加。
  • Append Columns col - 把后续表格的列添加到第一个表格，以此合并表格。若使用 By Name 选项，后续表格的数据会添加到同名的行中，并且不会添加第一列。如果后续表格的行数多于输入表格，多出的行会被追加。
  • Collapse Columns collapsecol - 把一行中的所有单元格拼接成一个单元格，以此合并表格。最终会得到一列、一行或多行。
  • Collapse Rows collapserow - 把一列中的所有单元格拼接成一个单元格，以此合并表格。最终会得到一行、一列或多列。
  • Collapse Cells collapsecells - 把所有单元格拼接在一起，以此合并表格。最终只会得到一个单元格。
  • Replace Cells by Column repcolcells - 按行名匹配，用后续表格的数据替换第一个表格中的数据。始终使用最后一个表格的数据。
  • Replace Cells by Row reprowcells - 按列名匹配，用后续表格的数据替换第一个表格中的数据。始终使用最后一个表格的数据。
例如，如果你的第一个输入表格是
 Name          Species	  Age				
 Birch	        Ferret	  6			
 Diefenbaker	Ferret	  4
另外还有两个输入表格，顺序为
 Name          Species	   Age				
 Birch	        Ferret	   5			
 Diefenbaker	Wolverine  5				

 Name          Species	  Age				
 Birch	        Ferret	   6			
 Diefenbaker	Otter	   10
你的输出表格将是
 Name          Species	  Age				
 Birch	        Ferret	   5
By Name byname - 指定是否按名称追加列和行。
Concatenate with spacer - 允许在拼接时用字符串分隔单元格数据。默认是一个空格。
Append Unmatched unmatched - 如果后续表格中有第一个表格里不存在的行或列，这些行或列会被添加到输出中。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。

  • Custom Extension customext - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

操作符输入

  • Input 0: -

Info CHOP 通道

Merge DAT 的额外信息可以通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
