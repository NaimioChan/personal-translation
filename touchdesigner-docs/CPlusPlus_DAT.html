CPlusPlus DAT

摘要

CPlusPlus DAT 让你可以用 C++ 编写自己的插件，从而制作自定义 DAT 操作符。

使用 CPlusPlus DAT，可以根据创建时指定的类型创建 Table 或 Text DAT 输出。 有关如何制作与此 DAT 配合使用的 .dll 的详细信息，请参阅 Write a CPlusPlus Plugin 和 C++ category 中的其他文章。注意，无论 DAT 节点是何种类型（即 Table 或 Text），用于搜索单元格和所赋文本的所有名称都必须编码为有效的 UTF-8。

Windows 下作为 Visual Studio 项目的 CPlusPlus DAT 示例可在 C:/Program Files/Derivative/TouchDesigner/Samples/CPlusPlus/DAT 或你的自定义 TouchDesigner 安装文件夹中找到。（注意：在 macOS 上位于此处：TouchDesigner.app/Contents/Resources/tfs/Samples/CPlusPlus/DAT

Custom Parameters - 自定义参数可由 C++ DAT 的 .dll 自动创建。可以在 CPlusPlusDATExample.cpp 的 setupParameters() 函数中删除、编辑或追加此自定义参数页。已定义的自定义参数可根据其是否适用于特定任务来启用或禁用。）

cplusplusDAT_Class

参数 - Load 页

Plugin Path plugin - 要加载的插件的路径。
Re-Init Class reinit - 此参数为 On 1 时，会删除插件创建的类实例，并创建一个新实例。
Re-Init Class reinitpulse - 立即重新初始化该类。
Unload Plugin unloadplugin - 此参数大于 1 时，会删除插件创建的类实例并卸载插件。如果多个 DAT 加载了同一插件，它们都需要卸载才能释放该文件。

  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。

  • Custom Extension customext - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。

  • Input 0: -

Info CHOP 通道

CPlusPlus DAT 的额外信息可通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
