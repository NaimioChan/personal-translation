Topology POP

摘要

Topology POP 让你更精细地控制如何组合现有点与拓扑（顶点和图元），以及它们的内存分配。

输入 POP 或另一个 POP 中任何无符号 int 属性，都可以解释为点索引列表，用来描述该 POP 的拓扑，同时手动描述图元数量（Topology Info）——当各类型图元数量在 CPU 上已知时用参数，当各类型图元数量只在 GPU 上已知时用属性中的值。 这样可以组合多个用 GLSL 和 GLSL Advanced POP 创建的缓冲区，例如用来描述几何。

另一种方式是从另一个 POP 提供 Topology 和 Topology info。 Primitives 和 Vertices 属性也可以从其他 POP 合并进来。

最后同样重要的是，对于点数与图元数在 GPU 上已知的 POP，如果用户知道实际数值更小，可以在这里更新最大值，以减少下游 POP 的内存分配。 另一种方式是，若确切数量已知，也可以手动输入并更新该 POP，让它知道其点数信息和拓扑信息现在在 CPU 上已知，从而免去一次下载的开销和停顿。（参见 Learning about POPs 中 Information known on CPU/GPU 一节）

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
