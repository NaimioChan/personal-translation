导出

在 TouchDesigner 中，「导出」指把数据从 CHOP 通道发送到参数。从 CHOPs 导出通道和/或从 DATs 导出数据，可以覆盖任何操作符的参数值。

CHOP Exporting

CHOP channel 中的值可以发送到任何 operator 的 parameter。参见 CHOP Export，它也称为 Channel Exporting。

方法如下：让该 CHOP Viewer Active。点击并把通道拖到要导出到的节点上——稍等片刻该节点会变为当前节点并打开其参数框。继续拖到想要的参数上再松开。在弹出的菜单中选择 'Export CHOP'。

可以用 CHOP 的 Export Flag 开关其导出。导出数据连接在网络中以灰色点状数据连线显示。箭头表示数据流向，并在计算时以动画提示活动状态。

你可以把一批通道（按 opnamepath:parname 命名）批量导出到一批参数，而不必逐个设置。做法是把 CHOP 在 Common 页上的 'Export Method' 参数改为 'Channel Name is Path:Parameter'。

DAT Exporting

从 DAT 导出时，数据（字符、字符串或数字）被发送到操作符的参数。参见 DAT Export。CHOP 和 DAT 导出都可以导出到数值、标记或菜单类型的参数。不过 DAT 导出还支持导出到文本字符串类型的参数，例如 Text TOP 中的文本字符串，或 Select TOP 中的路径。

导出与表达式引用之争 - 永恒的争论

自人类早期黎明以来，TouchDesigner 用户就一直在争论从 CHOP（和 DAT）导出，与在参数中用表达式引用 CHOP 通道，各自的利弊。Which one is better?

首先，大约从 2017 年起，两种方法的性能已经不相上下。参数中的表达式现在会被一次性「编译」成执行很快的伪代码，它们从 CHOP 通道取值的速度，与参数从 CHOP 导出取值一样快。

那么该怎样在两者之间做选择？其他因素是：

  • 如果 CHOP 中的通道被重排或重命名，通常会破坏导出，不过有时系统会询问是否应使用新路径。
  • 如果 CHOP 中的通道被重排，不会破坏 CHOP 通道引用。如果通道被重命名，CHOP 引用就会被破坏。
  • 用表达式可以额外做数学运算：op('null1')[0] * 2 - 1
  • 用 CHOP 导出时，只要给通道取合适的名称，就能把一批通道（opnamepath:parname）批量导出到一批参数，而不必逐个设置。参数引用做不到这一点。
  • 用表达式更容易引用其他组件中的参数（尽管这通常不是好做法），而且可以用各种 python 技巧来构建这些表达式。
  • 同样，用表达式时可以在 python 中根据某种逻辑切换引用哪个 CHOP 或通道，例如 op('lfo2' if parent().par.Faster else 'lfo1')[0]。
  • 用导出可以方便地禁用一批导出；借助执行导出的 CHOP 上附带的表格，或在参数上右键，可以逐个禁用导出。
