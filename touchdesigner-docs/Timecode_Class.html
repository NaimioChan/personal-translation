Timecode 类

Timecode 类保存一个时间码值。另请参阅 Timecode 和 Timecode CHOP。

实例化器

TDU.Timecode(str, hour=0, minute=0, second=0, frame=0, negative=False, smpte=True, length=0, cycle=False, autoDropFrame=True)→ TDU.Timecode:

创建一个新的 Timecode 对象

  • str - （可选）- 从时间码格式的字符串初始化 Timecode 对象：即 hh:mm:ss:ff 或 hh:mm:ss.ff
  • fps - （关键字，可选）用指定的 fps 初始化 Timecode 对象。如果未指定，将用本地时间的速率初始化。
  • hour - （关键字，可选）指定小时。如果提供了 String 参数，则应留空。默认为 0。
  • minute - （关键字，可选）指定分钟。如果提供了 String 参数，则应留空。默认为 0。
  • second - （关键字，可选）指定秒。如果提供了 String 参数，则应留空。默认为 0。
  • frame - （关键字，可选）指定帧。如果提供了 String 参数，则应留空。默认为 0。
  • negative - （关键字，可选）指定时间码是否为负。如果提供了 String 参数，则应留空。默认为 False。
  • smpte - （关键字，可选）指定时间码是否为 SMPTE 标准。默认为 True。如果 smpte 标记为 OFF，你可以突破标准，拥有超过 24 小时的时间、负时间，以及任意高于 SMPTE 60 上限的每秒帧数。
  • length - （关键字，可选）为时间码指定自定义长度。与 countdown 配合使用。必须大于 0。
  • cycle - （关键字，可选）指定时间码到达自定义长度后是否循环回第一个值。循环为 True，保持最后一个值（即长度）为 False。仅在设置了自定义长度时使用。
  • autoDropFrame - （关键字，可选）启用后，会为分数速率（例如 29.97）自动计算丢帧。默认为 True。
t = tdu.Timecode() # 00:00:00:00，fps=me.time.rate
t2 = tdu.Timecode('01:11:11:15', fps=30) # 01:11:11:15，fps=30
t3 = tdu.Timecode(frame=185, fps=30) # 00:00:06:05，fps=30
t4 = tdu.Timecode(hour=1, minute=2, second=3, frame=4, negative=True, fps=30) # -01:02:03:04，fps=30

成员

countdown → tdu.Timecode (Read Only):

返回长度与当前时间之差的时间码对象。如果未指定自定义长度，则使用默认值：SMPTE 为 23:59:59:ff，其他为 99:59:59:ff。

dropFrame → bool (Read Only):

时间码为丢帧时为 True，否则为 False。

fps → float :

获取或设置时间码的帧率（以每秒帧数计）。

frame → int (Read Only):

时间码的帧：0 到 fps-1

hour → int (Read Only):

时间码的小时：非 SMPTE 为 0 到 99，否则为 0 到 23。

minute → int (Read Only):

时间码的分钟：0 到 59。

second → int (Read Only):

时间码的秒：0 到 59。

negative → bool :

时间码为负时为 True，否则为 False。如果时间码遵循 SMPTE 标准，则始终为 False。

smpte → bool :

时间码为 SMPTE 标准时为 True，否则为 False。SMPTE 时间码不能为负，也不能超过 24 小时。

text → str (Read Only):

获取时间码的文本格式。

totalFrames → int (Read Only):

时间码的总帧数，由小时、分钟、秒、帧值计算得出。时间码是否为丢帧也会影响该值。

totalSeconds → float (Read Only):

时间码的总秒数，由小时、分钟、秒、帧值计算得出。时间码是否为丢帧也会影响该值。

cycle → bool :

获取或设置时间码是否循环。当时间码值达到自定义长度（即用 setLength() 指定）时循环则为 True。若为 False，时间码值将保持最后一个值（即长度）。

方法

setComponents(hour, minute, second, frame, negative=False, fps=None)→ None:

从各个时间分量设置时间码。

  • hour - 新的小时值。
  • minute - 新的分钟值。
  • second - 新的秒值。
  • frame - 新的帧值。
  • negative（关键字，可选）- 新时间码是否为负。默认为 False。
  • fps（关键字，可选）- 时间码的 FPS。如果未指定，则 FPS 不变。
  • autoDropFrame - （关键字，可选）启用后，会为分数速率（例如 29.97）自动计算丢帧。默认为 True。
n.setComponents(12, 22, 33, 45, negative=True, fps=60) -> new Timecode will be -12:22:33:45.

setString(timecodeStr, fps=None)→ None:

从格式为 [-]hh:mm:ss:ff 的字符串设置时间码。

  • timecodeStr - 格式为 [-]hh:mm:ss:ff 的字符串。
  • fps（关键字，可选）- 时间码的 FPS。如果未指定，则 FPS 不变。
n.setString('01:01:00:00', fps=60)

setTotalFrames(totalFrames, fps=None)→ None:

把时间码设为一个表示新总帧数的整数值。

  • totalFrames - 新的总帧数值。
  • fps（关键字，可选）- 时间码的 FPS。如果未指定，则 FPS 不变。
n.setTotalFrames(120, fps=60) # 新的 Timecode 将是 00:00:02:00

setLength(length)→ None:

把时间码设为自定义长度。与 countdown 配合使用很有用。

  • length - 新长度，可以是总帧数值或 Timecode 对象。必须大于 0。
n.setLength(600) # 把 60 FPS 的 Timecode 长度设为 10 秒。
