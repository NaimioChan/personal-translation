Web Server DAT

摘要

Web Server DAT 让你可以像 Web 客户端一样连接到 TouchDesigner，例如通过网页浏览器。Web Server DAT 支持 HTTP、WebSockets，以及发送/接收二进制数据，例如图像（上传/下载）。客户端请求如何处理由用户通过回调决定。

Web Server DAT 可以是安全的，也支持在webserverDAT_Class中通过 authenticateBasic 进行基本验证。目前通过 Python 方法只支持 Basic 验证（即编码后的用户名和密码）。验证信息会位于 HTTP 请求字典中键为 'Authorization' 的项下。

归根结底，安全完全由用户负责。用户需确保 HTTP 请求经过正确的身份验证，并确保存储用户名/密码的任何数据已加密或私密保存。

通过 Secure (TLS) 参数支持 HTTPS。

Web Server DAT 使用POCO v1.13.3 构建。

另请参阅：Web Client DAT

参数 - Web Server 页

Active active - 启动和停止 Web 服务器。
Restart restart - 服务器处于活动状态时，脉冲会重启它。
Port port - Web 服务器的连接端口。例如，若端口号为 9980，则可通过地址 “localhost:9980” 在本地（通过网页浏览器）连接该 Web 服务器。
Local Address localaddress - 指定要监听的 IP 地址，当系统有多张网卡（NIC）且你想选择使用哪一张时会很有用。留空时，Web Server DAT 会监听所有接口。
Callbacks DAT callbacks - 引用一个包含 Python 回调的 DAT。Web Server DAT 高度依赖 Callbacks DAT，事实上大部分功能都通过回调实现。

onHTTPRequest - 当 Web 服务器收到 HTTP 请求时触发。request 是 HTTP 标头的字典。同样，response 是响应数据的字典，例如状态和原因。可以向 response 字典添加额外的键/值对，它们会作为标头加入 HTTP 响应。必须从回调中返回 response。该响应会发回客户端。

onWebSocketOpen - 当与客户端打开 WebSocket 连接时触发。客户端地址会传给回调。

onWebSocketClose - 当 WebSocket 连接关闭时触发。客户端地址会传给回调。

onWebSocketReceiveText - 当服务器的 WebSocket 连接从客户端收到文本数据时触发。发送文本数据的客户端会传给回调。

onWebSocketReceiveBinary - 当服务器的 WebSocket 连接从客户端收到二进制数据时触发。发送二进制数据的客户端会传给回调。

onServerStart - 当服务器启动时触发。

onServerStop - 当服务器停止时触发。

参数 - Secure 页

Secure (TLS) secure - 启用后，Web 服务器会使用传输层安全（TLS）与客户端建立安全连接。因此，Web 服务器会通过 HTTPS 而非 HTTP 运行。
Private Key File Path privatekey - 服务器 TLS 证书的私钥文件路径。
Certificate File Path certificate - 服务器 TLS 证书的证书文件路径。
Certificate Password password - 上面指定证书的密码。该密码只在视觉上隐藏，仍可通过 Python 访问。为了保护并在保存项目时加密它，应将 Web Server DAT 放在私有组件中。
Secure (TLS) Verify Client - 为服务器启用双向 TLS（mTLS），要求验证/认证客户端证书才能完成 TLS 握手。
Minimum TLS Protocol minprotocol - 指定服务器接受的最低 TLS 协议。不满足最低版本要求的客户端会被拒绝。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

Web Server DAT 的额外信息可通过Info CHOP访问。

Web Server DAT 专属信息通道

  • server_running -
  • websocket_connections -

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
