Evaluate DAT

摘要

Evaluate DAT 使用字符串编辑和数学表达式更改传入 DAT 的单元格。

最简单的形式是：不连接输入 DAT，你可以在 Evaluate DAT 的 Expression 参数中放入任何 python 表达式。要每帧计算该表达式，可能需要将参数设为 Expression Parameter Mode。

连接 DAT 后，它输出的表格行数和列数与输入相同。

Scope 页可用于限制受影响的单元格行列。

  • 当 Output 菜单设为 Expressions 时，输入单元格会作为 Pythong 表达式计算。me.inputCell.val 是输入单元格的值。
  • 可选的第二个输入 DAT 是一个表达式数组，它们与输入的单元格匹配，然后被计算并输出。如果第二个 DAT 的行数少于第一个，则第二个输入最后一行的表达式会被重复使用。如果第二个 DAT 的列数少于第一个，则最后一列会被重复使用。
  • Expressions are optimized by storing a compiled internal version, which runs much faster. 尽可能使用它。如果你通过在表格中重复表达式来复用表达式，那么把将要循环使用的少数几个表达式放在单独的输入表中、与数据分开，也能提高性能。

如果第二个 DAT 只有一个单元格，就像 Expression 参数一样，它会将其表达式应用到所有输入单元格。一个只含 me.inputCell.val+1 的单元格第二 DAT 会给第一个输入的所有单元格加 1。

如果第二个 DAT 是

me.inputCell.val me.inputCell.val
me.inputCell.val math.sin(math.radians(float(me.inputCell.val)))

那么第一行和第一列保持不变，其余单元格会计算其 sin()。

除非使用 Output Table Size 参数，否则 Evaluate DAT 会保持第一个输入 DAT 的格式（表格或文本）。

另请参阅 Substitute DAT、Expression CHOP。

evaluateDAT_Class

表达式

Evaluate DAT 可用于（1）构建字符串，或（2）执行数学运算。

me.inputCell 指用于计算当前单元格的对应输入单元格。evaluateDAT_Class 有一个引用传入数据的成员列表。你可以使用 Python 获取数据，例如 op('datpath')[row,col] 访问 DAT 数据，op('choppath')['channame'][sampleindex] 访问 CHOP 数据。几个示例： 

# 在当前求值的列上，从输入表的特定行访问数据
me.inputTable['rowname',me.inputCol]

# 在输入行和列上为当前单元格的数据添加前缀
# 第一个单元格中的字符串将被格式化为 [0,0]:string
'['+str(me.inputRow)+','+str(me.inputCol)+']:'+me.inputCell

# 把当前单元格的数值数据与另一表格的数值数据相加
op('datpath")[me.inputRow,'colname'] + me.inputCell

# 把当前单元格的数值数据与另一表格的字符串数据拼接，中间加一个空格
op('datpath')[me.inputRow,'colname'] + ' ' + me.inputCell

# 把当前行号与另一表格的字符串数据拼接，中间加一个空格
op('datpath')[me.inputRow,'colname'] + ' ' + str(me.inputRow)

# 把 chop 通道中当前行索引处的采样与当前单元格拼接
me.inputCell + ':' + str(op('choppath')['channame'][me.inputRow])

有关在其他操作符中访问数据的更多示例，请参阅 Working with DATs in Python 和 Working with CHOPs in Python。

你也可以使用任何 Tscript Expressions 来获取数据，例如 `tab("tabpath",row,col)` 和 `chop("choppath")`。还提供了一系列局部变量，例如 $V 表示对应输入单元格的值，并且你可以使用其他 Tscript Variables，例如 $F 和 $SYS_XRES。

少数 Tscript 表达式 v() 和 vs() 是 Evaluate DAT 特有的，可以访问输入中的所有单元格。vs() 与 v() 不同，因为它始终输出字符串，而不是浮点数。

表达式 v(row,col) 和 vs(row,col) 可以使用局部变量 R（单元格的行）和 C（单元格的列）。

  • v($R,$C) 与 $V 相同。
  • v($C,$R) 转置单元格。
  • 你可以用 $C、$C-1、$C+1 定位相对的行/列，用 v($R,0) 定位第一列的单元格。v 会将单元格内容作为浮点数返回。vs 会将单元格内容作为字符串返回。

用于按行/列名称获取单元格的表达式有：

  • vr(rowname,colnum)
  • vc(rownum,colname)
  • vrc(rowname,colname)

以及上述表达式的字符串版本：

  • vsr(rowname,colnum)
  • vsc(rownum,colname)
  • vsrc(rowname,colname)

示例：vrc("john","august")

局部变量 NR 和 NC 给出输入表格的行数和列数。

参数 - Evaluate 页

Input Data DAT dat - 用于替代输入表格的另一种 DAT 表格。
Expressions DAT datexpr - 用于替代公式表格的另一种 DAT 表格。
Output output - 决定该 DAT 输出所使用的格式。
  • Evaluate evaluate - 将输入数据作为 python 表达式计算。Compiled。
  • Input Data data - 不经任何处理直接传递第一个输入的数据。
  • Input Expression expression - 如果没有第二个输入，则传递第一个输入。否则传递第二个输入。如果第一个输入的行数或列数多于第二个，则重复第二个输入的最后一行或最后一列以填充多出的单元格。
Expression expr - 如果未提供 Expression 输入或 DAT，则用于计算每个单元格的表达式。
Output Table Size outputsize - 如果 Output Table Size 参数为 Strings、Expressions 或 Commands，且有第二个输入，你可以选择输出表格大小为 Input DAT 或 Formula DAT。如果选择 Formula DAT 且其表格大小大于输入数据表格，则在计算剩余公式时将使用每行或每列的最后一个单元格。
  • Input 1 (Data) in1 -
  • Input 2 (Expressions) in2 -
Monitor Data Dependencies dependency - 如果 Output 参数设为 Strings 或 Expressions，该 DAT 会监视数据使用的任何节点，并检查时间依赖关系，据此计算。此开关默认打开。如果你只想让该 DAT 基于输入变化进行计算，可以关闭它以避免不必要的更新。
Convert Backslash Characters backslash - 会将 \n 之类转换为换行、\t 转换为制表符等。注意，如果输入 DAT 是表格，\n、\t 会被转换为空格。

Row Select Values rownames - 指定要选择的具体行名称。可以使用模式匹配，例如 row[1-4] 会选择所有名称为 row1 到 row4 的行。
Row Select Condition rowexpr - 指定一个将被计算的表达式。如果表达式结果为 true，则选择该行。

展开该参数，你会看到它位于 expression mode 中。

默认情况下，Python 表达式为 re.match('.*',me.inputCell.val) != None。'.*' 表示多次匹配任意字符，因此该表达式匹配所有值。如果要匹配父级操作符名称后跟任意数字，可以使用 parent().name+'[0-9]*'，其中 '[0-9]*' 匹配任何数字字符串。'.*'+parent().name+'.*' 将匹配任何包含该操作符父级名称的单元格。你可以在 Regular Expression Operations 中查看有关如何使用 Python 正则表达式模块的更多信息。

在 Tscript 中，你可以用局部变量 $V 访问单元格的值，用 $R 和 $C 访问行和列。

From Column fromcol - 按值选择行时，该参数选择用哪一列把单元格值与 Selected Row Values 匹配，以确定选中哪些行。
Select Cols extractcols - - 该参数让你选择指定所选列的不同方式。
  • All all - 选中所有列。
  • by Name byname - 使用 Start Col Name 和 End Col Name 参数选择列。
  • by Index byindex - 使用 Start Col Index 和 End Col Index 参数选择列。
  • by Start Name, End Index bynameindex - 使用 Start Col Name 和 End Col Index 参数选择列。
  • by Start Index, End Name byindexname - 使用 Start Col Index 和 End Col Name 参数选择列。
  • by Values bynames - 通过显式指定列值来选择列。
  • by Condition byexpr - 通过针对 from 行求值的表达式来选择行。

Col Select Condition colexpr - 指定一个要计算的表达式。如果表达式求值为真，则选中该列。详情参见 Row Select Condition。
From Row fromrow - 按 Specified Names 提取列时，该参数选择用哪一行把单元格值与 Selected Col Values 匹配，以确定选中哪些列。

Info CHOP 通道

可以通过 Info CHOP 查看 Evaluate DAT 的额外信息。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
