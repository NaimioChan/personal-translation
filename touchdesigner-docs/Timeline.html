时间轴

时间轴位于 TouchDesigner 界面的底部。播放控制按钮和时间轴设置控制整个 TouchDesigner 网络中对 Time Components 的播放。

每个组件都可以有自己的时间轴。

另请参阅：Frame 和 Time Slicing

Timepath - 改变时间轴的作用范围

时间轴可以显示「根」时间，或网络层级中任意 Component Time。时间轴当前显示的时间会显示在时间轴设置的 Timepath 字段中。

默认情况下，时间轴显示 TouchDesigner 的根时间（Timepath = /），它控制整个网络层级的播放。


时间轴也可以显示任意 Component Time。要把 Component Time 作用到时间轴上，请在该 component's mini-timeline 中按下「S」作用按钮。这会改变 Timepath 以反映所作用的 Component Time，并改变时间轴 UI 元素的颜色。每个不同的 Component Time 都会有独特的颜色，便于把它与组件的迷你时间轴关联起来。

要快速切回「根」时间，请点击 Timepath 字段旁的 / 按钮。根时间的颜色始终是 TouchDesigner 对话框和界面中通用的深蓝色。

播放控制

时间轴的这一部分包含时间码显示和播放控制。

时间码显示以帧或拍显示当前时间。可以用时间码显示旁的 TimeCode 或 Beats 按钮选择。在时间码显示的右侧，TouchDesigner 运行的每秒帧数显示在 fps 字段中，当前帧显示在 frame 字段中。也可以在帧字段中输入帧号以跳转到特定帧。

播放控制提供基本的播放操作。从左到右的按钮是：

  • Reset - 把播放头移到工作范围的起点
  • Pause - 暂停播放
  • Reverse Play - 反向播放
  • Play - 向前播放
  • Step Back - 后退一帧
  • Step Forward - 前进一帧

使用 Range Limit 按钮，可以把时间轴设为 Loop，或播放到 Once 后停止。

此区域最左侧的 I 按钮是 Run Independent 按钮。当时间轴中作用了 Component Time 时，可用它来开关「run independently」选项。

时间轴设置

时间轴的这一部分包含 Timepath 和时间轴设置。

Timepath 显示时间轴当前控制的 Time 组件的路径（当路径为根时（timepath = /），这称为根时间）。[/] 按钮可从任何其他路径跳回根时间。

时间轴设置会更改时间轴当前控制的 Time 组件的参数。这些设置是：

  • Start/End - 设置起始和结束帧，即总长度
  • RStart/REnd - 设置工作范围（子范围）的起始和结束帧。也会显示为时间轴中时间索引上方的彩色条。
  • FPS - 以每秒帧数设置 frame rate。
  • BPM - 每分钟拍数
  • ResetF - 重置帧
  • T Sig - 拍模式（Beats mode）下使用的拍号。
