Lens Distort TOP

摘要

Lens Distort TOP 使用 Brown-Conrady model 对图像应用或移除镜头畸变。这可用于校正物理相机拍摄的图像、为渲染结果施加畸变以用于增强现实（AR），或作为视觉效果。

Lens Distort TOP 使用的畸变算法可分为三个部分：径向畸变、切向畸变和相机矩阵。

径向畸变会根据像素到图像中心（由 Optical Center 参数定义）的距离来移动输出中的像素。径向畸变由 k1、k2 和 k3 常数控制，其中 k1 影响最大，k3 影响最小。正的 k 值会产生桶形或鱼眼效果，就像图像被包在球面上。负的 k 值会使图像向内弯曲，产生枕形或枕头效果。径向畸变的公式为： 

x_distorted = x * (1 + k1 * r^2 + k2 * r^4 + k3 * r^6)

y_distorted = y * (1 + k1 * r^2 + k2 * r^4 + k3 * r^6)

where, 
  r = distance from center

切向畸变会移动像素，就像它们位于一个相对相机倾斜的表面上，由 p1 和 p2 参数控制。p1 根据符号使图像上下倾斜，p2 使图像左右倾斜。切向畸变的公式为： 

x_distorted = x + (2 * p1 * x * y + p2 * (r^2 + 2 * x^2))

y_distorted = y + (p1 * (r^2 + 2 * y^2) + 2 * p2 * x * y)

where, 
  r = distance from center

相机矩阵由 Optical Center 和 Focal Length 参数定义，用于在施加畸变之前变换图像位置。Optical Center 值控制畸变效果的中心位置，而 Focal Length 参数则作为其他效果的缩放。相机矩阵通常表示为 3x3 矩阵： 

fx 0  cx
0  fy cy
0  0  1

相机镜头的畸变值可以使用 OpenCV calibration routines 确定，也可以通过特定相机的函数获取（见 kinectazureTOP class）。

  • 桶形或鱼眼径向畸变，k > 0

  • 枕头或枕形径向畸变，k < 0

  • 切向畸变， p1 < 0

  • 切向畸变， p2 < 0

Layout 页的参数用于控制畸变后（或去畸变后）的图像在输出画面内的排布方式。这些功能有助于保留原本可能被投影到画面外的输入图像部分、保持输入图像分辨率，或在镜头畸变参数变化时建立一致的输出画面。

例如，将 Post Transform 参数设为 Optimal 并保持 Optimal Alpha 为 1，畸变后的图像会被缩放和移动，使整幅输入图像都保留在输出画面内。再将 Layout 参数切换为 Native Resolution，输出的分辨率就会被缩放，从而不丢失输入图像的任何细节。接入一个 Info CHOP 可提供感兴趣区域（ROI）边界，用于从输出图像中裁出原始畸变图像。

注意： 此 TOP 支持 3D Textures 和 2D Texture Arrays。

参数 - LensDistort 页

Invert Distortion invert - 反向应用镜头畸变。这*大体上*可以抵消另一个参数相同、且未启用 Inverse 的 Lens Distort TOP 所施加的畸变。 镜头畸变算法没有精确的逆解，因此采用近似方法，可能无法精确匹配原图。近似质量随畸变幅度而变化。此外，近似算法不使用 k3 常数，任何在图像边界之外丢失的内容也无法重建。
K1 k1 - 第一个径向畸变常数。k 常数会把像素移向或移离图像中心。大于 0 的值产生桶形或鱼眼效果，小于 0 的值产生枕头或枕形效果。k1 的影响大于 k3。
K2 k2 - 第二个径向畸变常数。见 K1。
P1 p1 - 第一个切向畸变常数。使图像上下倾斜。
P2 p2 - 第二个切向畸变常数。使图像左右倾斜。
K3 k3 - 第三个径向畸变常数（在逆畸变中不使用）。见 K1。
Optical Center center - - 图像中应作为畸变中心的位置。根据所选的单位模式，该位置可以从左下角算起的绝对位置输入，也可以从图像中心算起的相对位置输入。单位模式还控制位置是以像素还是以归一化坐标计量。
  • Optical Center center1 -
  • Optical Center center2 -
Optical Center Units centerunit - -
  • R relative - 光学中心以归一化坐标计量，相对图像中心从 -0.5 到 -0.5。
  • A absolute - 光学中心以归一化坐标（0 到 1）计量，从图像左下角算起。
  • RP pixelrel - 光学中心以像素坐标计量，相对于图像中心。
  • AP pixelabs - 光学中心以绝对像素坐标计量，从图像左下角算起。
Focal Lengths focallength - - 相机矩阵的焦距分量，可以表示为归一化的、与分辨率无关的值，也可以表示为像素。焦距充当其他畸变参数的标量。归一化单位模式可用于使用毫米或其他物理单位的系统。通常缩写为 Fx 和 Fy。详情见 OpenCV。
  • Focal Lengths focallength1 -
  • Focal Lengths focallength2 -
Focal Length Units focallengthunit - -
  • F fraction - 焦距以分数或归一化坐标表示。
  • P pixels - 焦距以像素表示。

参数 - Layout 页

Layout layout - - 决定变换后的图像在最终输出图像空间内如何排布。该值可用于保持输入图像的原始像素分辨率，或确保最终的输出分辨率与宽高比。
  • Scale to Fit scale - 变换后的图像会被缩放，以填满输出图像的完整分辨率与宽高比。如果你需要特定的输出分辨率或宽高比，这个模式很有用。
  • Native Resolution native - 变换后的图像以保持其原始分辨率和宽高比的方式排布在输出中。这意味着如果输出分辨率小于输入分辨率，图像可能被裁切。
Extend Mode extendmode - - 决定当输出图像超出输入图像边界时使用什么值。
  • Hold hold - 输入图像外边缘的颜色会被延伸，以填充输出图像中的空隙。
  • Zero zero - 输出图像中的空隙在所有通道上都填充为零。
  • Repeat repeat - 输入图像会被平铺，以填充输出图像中的空隙。
  • Mirror mirror - 输入图像会被镜像并平铺，以填充输出图像中的空隙。
Optimal Alpha alpha - 决定在计算最佳后变换时保留多少图像。为零时，最佳变换只包含感兴趣区域。为一时，变换会包含输入图像的所有像素。该值等同于 OpenCV 的 getOptimalNewCameraMatrix 函数中使用的 'alpha' 值。
Post Transform transformmode - - 选择是否在镜头畸变之后对图像执行额外的变换。这有助于在最终画面内定位和缩放畸变后的图像，也可用于保留输入图像中会因畸变而被移出画面的部分。
  • None none - 不施加额外的变换。
  • Optimal optimal - 图像按 OpenCV 的 getOptimalNewCamera matrix 给出的最佳新相机矩阵进行变换。根据 Optimal Alpha 参数的值，该模式可用于确保输入图像没有任何部分丢失在画面之外。
  • Custom custom - 启用自定义的中心和缩放参数。使用此选项可相对于 Lens Distort 页上的相机矩阵修改输出图像。
  • New Camera Matrix newmatrix - 输入新的相机矩阵，用于在画面内定位输出图像。输入 Lens Distort 页的相机矩阵值将不再产生额外变换。输入最佳新相机矩阵值将得到与使用 Optimal 变换模式相同的结果。
New Center newcenter - - 新的光学中心位置，可在输出画面内平移变换后的图像。使用与 Optical Center 参数相同的值将不会产生畸变后偏移。使用 Optimal Center 值将得到与 Optimal 变换模式相同的结果。
  • New Center newcenter1 -
  • New Center newcenter2 -
New Center Unit newcenterunit - - 决定新的中心值如何解释。
  • R relative - 中心以归一化坐标计量，相对图像中心从 -0.5 到 -0.5。
  • A absolute - 中心以归一化坐标（0 到 1）计量，从图像左下角算起。
  • RP pixelrel - 中心以像素坐标计量，相对于图像中心。
  • AP pixelabs - 中心以绝对像素坐标计量，从图像左下角算起。
New Focal Lengths newfocallength - - 新的焦距，可相对于输出画面缩放变换后的图像。使用与 Focal Lengths 参数相同的值将不会产生畸变后缩放。使用 Optimal Focal Length 值将得到与 Optimal 变换模式相同的结果。
  • New Focal Lengths newfocallength1 -
  • New Focal Lengths newfocallength2 -
New Focal Length Units newfocallengthunit - -
  • F fraction - 焦距以分数或归一化坐标表示。
  • P pixels - 焦距以像素表示。
Center Offset centeroffset - - 在输出画面内平移畸变后的图像。
  • Center Offset centeroffset1 -
  • Center Offset centeroffset2 -
Center Offset Unit centeroffsetunit - -
  • F fraction - 偏移量以输出图像的比例计量，从 -0.5 到 0.5。
  • P pixels - 偏移量以输入图像的像素计量。
Scale scale - - 对图像执行额外的畸变后缩放。缩放相对于原始相机矩阵，因此大于 1 的值会拉伸图像，小于 1 的值会收缩图像。
  • Scale scale1 -

Cropping cropmode - - 裁切变换后的图像，使只有部分图像出现在最终输出中。除非指定了自定义分辨率，否则裁切区域将用于确定最终输出分辨率。
  • None none - 不进行裁切。
  • Region of Interest roi - 由 OpenCV 函数 getNewCameraMatrix 定义的感兴趣区域（ROI）用于裁切最终输出。ROI 会随任何后变换函数自动更新，因此在使用自定义变换时该模式仍然有效；不过，从变换后的图像中裁切 ROI 通常与不使用变换或裁切得到的结果相同。
  • Custom custom - 以像素或画面比例输入自定义裁切区域。输入所接入 Info CHOP 的 ROI 值将得到与使用 Region of Interest 裁切模式相同的结果。
Custom Region cropregion - - 按 Left、Bottom、Right、Top 的顺序定义自定义裁切区域。值可以是图像比例（0-1），也可以是输入图像尺寸的像素。输入所接入 Info CHOP 的 ROI 值将得到与使用 Region of Interest 裁切模式相同的结果。
  • Custom Region cropregionx - 裁切区域的左侧。
  • Custom Region cropregiony - 裁切区域的底边。
  • Custom Region cropregionz - 裁切区域的右侧。
  • Custom Region cropregionw - 裁切区域的顶边。
Crop Unit cropunit - - 用于解释自定义裁切区域值的单位。可以是图像的比例（0-1），也可以是输入图像尺寸的像素。
  • F fraction -
  • P pixels -
Scale Unit scaleunit - - 决定缩放值如何使用。
  • F fraction - 缩放以分数或归一化坐标表示。
  • P pixels - 缩放以像素表示。

  • errors - 该操作符的错误数量（如果有）。
