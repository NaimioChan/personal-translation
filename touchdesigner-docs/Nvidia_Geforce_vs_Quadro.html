Nvidia GeForce 与 Quadro

Nvidia 产品线与代次

对 TouchDesigner 系统搭建者来说，Nvidia 生态基本分为两个纵向产品线。第一条是名为 Geforce 的游戏 GPU 线，第二条是专业线 Quadro。Quadro 线专注于媒体制作、大幅面视频传输、CAD 和科学可视化。

对于为帧精确的专业视频应用而构建的 TouchDesigner 视频服务器，应使用 Quadro 线，因为它具有一系列专用于高分辨率多屏映射的特性，以及特定的帧同步技术。

对于大多数个人 TouchDesigner 开发系统，Geforce 线更可取，哪怕仅仅因为价格。Geforce 线始终比对应的 Quadro 便宜得多。此外，TouchDesigner 与 Geforce 线面向游戏的调校配合得非常好。

Nvidia 会发布覆盖其所有产品线的整代芯片。同一代的所有产品都使用同一款芯片，无论是 Geforce、Quadro 还是其他。各种特性在 Geforce 或 Quadro 中可能开放或不开放。此外，芯片会搭配各种内存带宽、时钟频率和其他会影响性能的专用 IP 核心。

Geforce 与 Geforce Ti 与 Titan

Geforce 线又分为几个子类别，把「常规」型号与「高级」和「超高级」型号区分开。如下文所示，每款 GPU 和显卡的配置都会影响整体性能。过去 6 年里，Nvidia 几乎让每一代后续 GPU 的整体性能翻倍。Nvidia 提供面向性价比的 GPU 板卡，如 1060、1070 和 1070 Ti，以及 1080、1080 Ti 和 Titan 版本等高级型号。

Geforce 显卡的 Ti 版本通常有更多内存和更高的性能规格，例如总核心数。Ti 代表 Titanium，据说没有技术含义，只是暗示「高级」的营销用语——与 Titan 在含义上并无关系。

Titan 版本是 Geforce 线中的「超高端」。相比编号最高的 Ti 型号，这通常意味着各项配置都稍多一些，但 Titan 型号仍缺少 Quadro 的专业特性。

值得说明的是，Nvidia 确实跳过了基于 Volta 的中端 Geforce 和 Quadro 显卡。Volta 芯片只出现在各条产品线的超高级型号中，即 Titan XV 和 Quadro GP100。

Quadro G 系列 GPU

Quadro GP100（Pascal）和 GV100（Volta）是强化版显卡，增加了用于运行计算软件、深度学习算法等功能，而这类功能目前在 TouchDesigner 中不受支持。它们缺少运行 3D 应用所需的重要特性，运行 TouchDesigner 会很差。

Tesla GPU

Tesla GPU 是为运行计算类应用和虚拟化工作站而设计的，目前与 TouchDesigner 不兼容。Tesla GPU 除标准 Nvidia GPU 的「Cuda Cores」外，还配备了 Tensor 核心。这通常会推高价格，Quadro G 系列和 Volta 代次即可见一斑。如果你有使用此技术的应用，请告知我们。

重要的 GPU 特性

各款显卡的 GPU 特性差异很大。本节单独列出最重要的指标以便比较。

浮点性能

FLOPs 代表「每秒浮点运算次数」。浮点性能是对 GPU 原始处理能力的衡量，因此一直是快速比较 GPU 的方法。 随着 Compute 核心、Tesla 核心和 RTX 核心的引入，FLOPs 总量在一般统计中获得了巨大提升。然而，许多推高数值的技术目前并未被 TouchDesigner 使用。因此，越来越难以比较单一的 GFLOP 数值，例如 Maxwell 和 Pascal 线，与拥有这些新核心类型并把统计值合并为单一数值的 Volta 和 Turing 线。

要直接比较浮点数值，请改用 FP32 和 FP64 这两项统计。总 GFLOPs 数值通常是把一系列不同核心相加得到的，因此可能产生误导。

像素填充率

每秒可渲染到屏幕的像素数量。

着色处理器（单元）

着色单元（或着色处理器）是显卡内的小型处理器，负责处理图像的不同方面。你可能也会听到着色单元被称为「流处理器」和「cuda 核心」。

纹理映射单元（TMUS）

TMU 负责把纹理映射到 3D 场景的几何上。TMU 越多，通常意味着纹理信息处理得越快。

纹理填充率

每秒可渲染到屏幕的带纹理像素数量。

渲染输出单元（ROPs）

ROP 负责渲染过程的某些最后步骤，把最终像素数据写入内存，并执行抗锯齿等改善图形外观的任务。

RAM

显卡的总显存。

内存总线位宽

更宽的总线位宽意味着每个周期可传输更多数据。这是内存性能的重要因素，因此也是显卡整体性能的重要因素。

DDR 内存版本

较新的 GDDR 内存版本带来更高传输速率等改进，从而提升性能。

输出类型 / HDMI / DisplayPort / DVI

GPU 板卡上的硬件视频接口类型。

高色深

大多数显卡只支持 8 位色深，即 RGBA 各 256 级。某些 Quadro 显卡支持 10 位色等更高位深。这通常需要现代 DisplayPort 类型的视频端口，并且必须使用正确的线缆连接到支持所需色深的设备。

通用特性

以下部分介绍自 Kepler 家族引入以来所有 Nvidia GPU 产品线共有的特性。

Nvidia NVENC

Nvidia NVENC 是一项执行视频编码的技术，可让 CPU 腾出来处理其他关键任务——例如运行 TouchDesigner。它最早随 2012 年 3 月的 Kepler 微架构引入，此后逐代演进，支持更多编码技术。

使用 Movie File Out TOP 时，选择任何 H264 或 H265/HVEC 编解码器都会使用基于 GPU 的编码器。你可以用 Windows 任务管理器检测 NVENC 编码器是否在工作。任务管理器的 Performance 页中有一个 Video Encode 引擎使用率的图表。

无论安装多少块显卡，GeForce 显卡最多支持同时编码 2 路视频流。Quadro 显卡每块卡支持多路并发流（仅受可用资源限制），具体数量取决于显卡型号、压缩质量等诸多因素。

Nvidia PureVideo

https://en.wikipedia.org/wiki/Nvidia_PureVideo

Nvidia PureVideo 是一种执行视频解码的硬件 SIP 核，不要与 NVENC 混淆。默认情况下，TouchDesigner 的视频解码基于 CPU，由 TouchDesigner 直接管理。如果编解码器支持，TouchDesigner 中的视频解码会跨多个 CPU 多线程进行。在 Movie File In TOP 的 Tune 页上开启 Hardware Decode 参数，即可启用 Nvidia PureVideo 解码。

Quadro 专属功能

本节介绍仅专业 Quadro 系列显卡才具备的功能。

更快的 GPU 到 CPU 内存传输

Quadro 提供更快的 GPU 到 GPU 内存传输，这对于任何不经过 GPU 的 DisplayPort/HDMI 输出的视频输出都很重要。如果你的系统使用 Video Device Out TOP、NDI Out TOP、Video Stream Out TOP 等其他输出，且发送的总分辨率较高，不妨考虑使用 Quadro。

来自 Nvidia 的支持

对于遇到的问题，Quadro 可获得 Nvidia 的直接支持，而 GeForce 显卡不提供此支持。如果我们报告的问题认为与 Nvidia 软件/驱动有关，而该问题仅在 GeForce 设备上复现，我们就无从获得支持。

设置配置文件

Quadro 显卡附带针对特定使用场景调校过的 GPU 驱动设置。

EDID 欺骗

有时需要将显卡硬编码到特定设备的 EDID，以确保即使图形端口断开连接，屏幕配置也保持不变。默认情况下，Windows 会立即根据连接的设备重新配置屏幕布局。驱动会根据找到的 EDID 记住上一次配置。对于永久连接的安装环境，即使屏幕断开，端口也必须硬编码。GeForce 显卡无法做到这一点，因此需要外部硬件方案才能获得相同的行为。

Mosaic

https://www.nvidia.com/en-us/design-visualization/solutions/nvidia-mosaic-technology

Windows 10 系统中存在各种画面撕裂和丢帧的现象。消除所有这些现象很困难，有点像黑魔法。更多信息参见 Perfect Playback。对于完美流畅的播放，一个可能很关键的功能是使用 Nvidia Mosaic 技术，将 Windows 桌面统一为跨越最多全部 4 个 DisplayPort 的单一桌面。因此，如果每个 DisplayPort 输出 3840x2160，整个 Windows 桌面就是 7680x4320。如果连接到 DisplayPort 的所有设备都是同一型号，并启用 Nvidia Mosaic，则有可能避免播放和同步方面的问题。

除了 Nvidia Control Panel 界面之外，Mosaic 还可以使用 Mosaic Utility 在命令行中配置。

GeForce 显卡有一个类似但功能较弱的功能叫 'Surround'，不过也可以用来达到类似的效果。

Quadro Sync

Quadro Sync

Quadro Sync Setup Guide

如果屏幕或投影机阵列由多台物理计算机或一台装有多块显卡的计算机驱动，则可以使用 Quadro Sync 扩展卡将所有显卡同步到相同的同步相位。没有这张同步卡，连接到某块显卡的屏幕相位可能与其他显卡不一致，导致显示器之间的内容出现视觉撕裂。这是否明显取决于所显示的内容。

要在 Window COMP 或 Direct Display Out TOP 中使用 Hardware Framelock，也需要 Quadro Sync。

除了 Nvidia Control Panel 界面外，也可以使用 QSync Utility 进行配置。

Quadro Sync 不要与 Nvidia G-sync 混淆，后者是一种让电子游戏画面更流畅的游戏技术。不过很多年前 Quadro Sync 曾名为 G-Sync。

不支持的 Nvidia 技术

本节介绍 TouchDesigner 不支持的 Nvidia 技术。

Quadro NVS

Quadro NVS 显卡不要与普通 Quadro 显卡混淆。它们面向需要多块大屏幕来查看股票经纪人财务数据之类内容的商业应用。这些显卡上的 GPU 不适合 TouchDesigner 这类对 GPU 要求很高的应用。

Nvidia SLI

SLI 是一种游戏技术，允许多块显卡通过拆分并分配到多个 GPU 来渲染单次光栅化。TouchDesigner 不兼容 SLI。利用多块显卡的唯一方式是使用 GPU Affinity。

同一系统中的多块显卡可以寻址每块显卡的所有输出。但渲染只会使用单个 GPU，而且该 GPU 也无法达到最优性能，因为主 GPU 需要管理与其他 GPU 输出端口的通信，存在开销。

简而言之，没有 GPU Affinity 时，TouchDesigner 只有在每台计算机使用单块显卡时才能达到最优运行。
