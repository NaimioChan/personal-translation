DongleList 类

连接到系统的 dongles 列表。系统实例可在 licenses.dongles 中找到。 

dongles = licenses.dongles		# 获取 DongleList 对象
print(len(dongles))				# Dongle 的数量
print(dongles[0])				# 列表中的第一个 Dongle
for d in dongles:
	print(d)					# 打印所有 Dongle

成员

没有该操作符专属的成员。

方法

refreshDongles()→ None:

刷新连接到系统的加密狗列表及其产品代码。

encrypt(firmCode, productCode, data)→ ByteArray:

使用已安装指定 firm code 和 product code 的 CodeMeter 加密狗对字符串或字节数组进行加密。成功时返回包含加密数据的字节数组。

  • firmCode - 要使用的 firm code。它必须存在于加密狗上。
  • productCode - 要使用的 product code。它必须存在于加密狗上。
  • data - 要加密的字符串或字节数组。大小至少为 16 字节。

decrypt(firmCode, productCode, data)→ ByteArray:

使用已安装指定 firm code 和 product code 的 CodeMeter 加密狗对字符串或字节数组进行解密。成功时返回包含解密数据的字节数组。

  • firmCode - 要使用的 firm code。它必须存在于加密狗上。
  • productCode - 要使用的 product code。它必须存在于加密狗上。
  • data - 要解密的字符串或字节数组。大小至少为 16 字节。

productCodeInstalled()→ bool:

如果提供的 product code 已安装在任何已连接的加密狗上，则返回 True。
