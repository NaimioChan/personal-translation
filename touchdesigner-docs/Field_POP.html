Field POP

摘要

Field POP 添加一个 Weight 属性，决定每个点在 3D 形状内的程度。字段是 3D 空间中的边界区域。形状包括球体（椭球体）、圆柱、平面、抛物面等，形状内（或形状某一侧）的所有点权重为 1，其他点均为 0。Field POP 常用于在点云中隔离或切出部分点。

它也可以输出 Dist 属性，即形状之外的点到表面的距离。

Transition Range 参数柔化 Weight 从 1 到 0 的过渡。它是权重从 1 变为 0 所经过的距离。Transition Align 决定从 1 到 0 的过渡从何处开始。默认情况下，球体字段在 Radius 处权重为 .5。若 Align 为 -.5，则在半径处权重已降到 0；若 align 为 .5，则半径处权重为 1，并在半径之外降到 0。其他字段形状类似。Transition Type 允许线性、缓入缓出或平滑阶梯式的 1 到 0 过渡。

Multiple fields in one Field POP：名为 Specification POP 的参数指向一个 POP，其中每个点都是一个定义独立字段的规格——每个字段一个点。规格 POP 的属性名与 Field POP 中的参数名相同，并覆盖每个字段的参数。菜单和开关以整数表示，第一个菜单项从 0 开始。你只需创建一个 Point POP，其属性按 Field POP 的参数命名，然后为每个字段添加一个点并设置其值。（属性 sizex 会覆盖 Size X（sizex）参数。）或者，你也可以用与 Field POP 参数名匹配的属性以程序方式生成点。工作流程与 Geo Text COMP 和 Text COMP 的 specification DAT 中定义多个字符串相同。

Using P as field position：虽然规则是属性名必须与 Field POP 的参数名相同，但 P（位置属性）是一个特例，因为它会覆盖 Field POP 的 tx、ty 和 tz 参数。若节点 point1 具有属性 radx 和 P，它们会覆盖 Field POP 的 radx、tx、ty 和 tz 参数。

Multiple weights raw or mixed：指定多个字段时，它们的权重会混合到 Weight 属性中（使用类似 Composite TOP 的 Screen 混合模式——合并多个字段会增大 Weight，但绝不会超过 1）。或者，每个字段的权重可以原始形式输出到多值 Weights 数组属性中。

Weight 或 Distance 属性可以与任何其他属性相加/相乘，例如 PartForce 属性，以将力限制在特定区域。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
