在 Python 中使用 CHOP

处理 CHOP 所用方法和类的主要文档是 CHOP Class 和 Channel Class 两篇文章。本文给出使用这些方法和类的示例。

入门

描述任意 Operator 的主要类类型是基类 OP Class。你需要其中一个的引用才能做任何事。有两个全局操作符对象始终可用（Textport 中除外）：

  • me 指当前正在求值或执行的操作符。例如，执行脚本时，me 指包含它的 DAT。求值表达式时，me 指包含它的操作符。
  • root 指顶层组件 /。

要获取对其他 OP 的引用（例如位于节点 'constant1' 旁边、名为 'pattern1' 的节点），最常用的函数是 op() 和 ops()，例如 op('pattern1')。

op() 返回单个 OP 对象，而 ops 返回 OP 列表（可能为空）。它们在 td Module 中描述。

这些函数从当前组件开始搜索操作符，因此相对路径和绝对路径都受支持。当前组件定义为：me 所在的 OP。

注意 OP Class 本身也包含 op() 和 ops() 方法。此时会从该 OP 开始搜索节点。

例如：me.op('..') 总是返回其自身的父级，而 op('..') 返回当前组件的父级。

如果你在节点 'constant1' 的参数中输入 Python 表达式，并希望获取对 'pattern1' 的引用，你会输入

op('pattern1')

如果在脚本中，你可以将此引用赋给变量，以便重复访问更方便。

n = op('pattern1')

此时 op() 会相对于执行该脚本的 DAT 进行搜索。

OP 还有一个 parent() 方法，可用于获取其父级 COMP。

parent()

如果你在 COMP 的参数中放入 Python 语句，并想引用该 COMP 的子级，可以使用 OP 的 op() 方法，它在参数中可用为 me。

me.op('achildnode')

提示： 要快速了解可对任意节点使用哪些成员和方法，选择该节点，在其参数对话框中点击 Python Help 图标。你会进入该节点 python 类的 wiki。在那里你可以了解能获取节点的哪些信息，以及有哪些可用方法。也可以通过右键点击节点并从菜单中选择 "Python Help..." 打开该文档。


有关本节的更多细节，请参阅 Working with OPs in Python。

在脚本中使用 CHOP

要在脚本中使用 CHOP，首先要用 op() 获取你感兴趣的 CHOP 的引用。最好将其赋给变量，这样在脚本中可多次使用，而无需每次需要时重新搜索 OP。然后你可以使用 CHOP 引用上的 [] 来引用特定通道。你可以使用通道名如 ['chan1']，或通道索引 [0] 来引用通道。例如，此脚本从某个 CHOP 获取名为 'chan1' 的通道，从另一个 CHOP 获取第一个通道，并将它们相加。

 # 获取名为 'pattern1' 的 CHOP 的引用
 n1 = op('pattern1')
 # 获取名为 'pattern2' 的 CHOP 的引用
 n2 = op('pattern2') 
 
 # 现在获取我们关注的两个通道的引用
 c1 = n1['chan1']
 c2 = n2[0]
 
 # 把它们相加。这会把当前时刻的值相加，而不是通道中的所有采样
 total = c1 + c2

要对通道中的每个采样执行操作，可以在通道上使用 [] 操作符。例如，此脚本会将通道中所有采样相加：

 # 获取名为 'pattern1' 的 CHOP 的引用
 n = op('pattern1')
 
 total = 0
 numSamps = n.numSamples
 c = n['chan1'] 
 for i in range(0, numSamps):
   total = total + c[i]

或者，你可以使用通道的 vals 成员，它是其所有值的列表：

 for v in c.vals:
   total = total + v

或者更简单，使用内置的 sum() 表达式：

  total = sum(c.vals)

你也可以使用 chan() 方法（它只是 [] 操作符的另一种形式，但带有搜索功能）或 chans() 方法来获取通道引用。chans() 允许你从 CHOP 获取通道列表。如果给 chans() 不传参数，则返回 CHOP 中所有通道的列表。

例如，这会获取一个 CHOP 的引用，然后将其所有通道相加。

 # 获取名为 'pattern1' 的 CHOP 的引用
 n = op('pattern1')
 # 将总计初始化为 0
 total = 0
 
 # 遍历 CHOP 中的每个通道
 for c in n.chans():
    # c 是 Channel 类的实例，可使用该类的所有方法/成员
    # 把通道的当前值累加到总和
    total = total + c
 print(total)

要打印 CHOP 中每个通道的名称，可以这样做：

 # 获取 'pattern1' 的引用
 n = op('pattern1')
 # 将总计初始化为 0
 total = 0
 
 # 遍历 CHOP 中的每个通道
 for c in n.chans():
    # c 是 Channel 类的实例，可使用该类的所有方法/成员
    print(c.name)

要获取 CHOP 中所有以 't' 开头的通道列表，只需这样做

 # 获取 'pattern1' 的引用
 n = op('pattern1')
 ts = n.chans('t*')

将通道转换为值

在参数中使用 CHOP

要在参数中引用 CHOP 值，首先需要获取 CHOP 的引用，然后使用 CHOP Class 对该 CHOP 做些什么，例如从其某个通道获取采样。

例如，这会从名为 'pattern1' 的 CHOP 中名为 'chan1' 的通道获取当前采样，该 CHOP 与我们正在输入参数的节点位于同一网络中

 op('pattern1')['chan1']

我们也可以这样通过通道索引引用 CHOP：

 op('pattern1')[1] # 获取该 CHOP 中的第 2 个通道

你也可以获取 CHOP 的其他信息，例如通道数量

 op('pattern1').numChans

或第 3 个通道的名称

 op('pattern1')[2].name

常见 Python 任务

表达式

Evaluate channel chan1 at the current frame op('pattern1')['chan1'].eval()
or if in parameter, simply: op('pattern1')['chan1']
Get sample 8 of channel chan1 op('pattern1')['chan1'].eval(8)
Get the number of CHOP Channels op('pattern1').numChans
Get the CHOP length op('pattern1').numSamples
Get the third sample from the first channel op('pattern1')[0][2]
Get the name of the 2nd channel op('pattern1')[1].name
Get the channel index of channel chan1 op('pattern1')['chan1'].index
