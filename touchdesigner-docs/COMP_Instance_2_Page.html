COMP Instance 2 参数页

参数 - Instance 2 页

当实例数据由 TOP 提供时，TOP 的 RGBA 通道会分配给实例属性；由 CHOP 提供时，CHOP 的通道会分配给实例属性；由 SOP 提供时，SOP 的属性会分配给实例属性；使用 DAT 时，则是一列分配给实例属性。

Rotate to Vector: Order instancerottoorder - 控制 Rotate To Vector 操作在变换方程中的应用位置。
  • Default default - Rotate to Vector 操作会在所有其他变换操作之前应用（轴心偏移除外），无论它们的操作顺序如何。例如 T * R * S * (RotToVector) * Position 、 R * S * T * (RotToVector) * Position 。
  • Pre-Rot prerot - Rotate To Vector 操作会作为 TRS 顺序的一部分，在主旋转之后应用。即 T * (RotToVector * R) * S * Position、 (RotToVector * R) * S * T * Position。
  • Post-Rot postrot - Rotate To Vector 操作会作为 TRS 顺序的一部分，在主旋转之前应用。即 T * (R * RotToVector) * S * Position、 (R * RotToVector) * S * T * Position。
Rotate to Vector: Forward Direction instancerottoforward - 确定几何原始朝向中以哪个轴为「前」。也就是说，它会把几何中朝该轴方向的部分当作正面，并旋转它，使其与 rotate to vector 方向对齐。

Instance Order instanceorder - 设置变换如何应用到实例。
  • Instance, then World Transform instanceworld - 先使用各个实例的变换，再应用世界变换（即 Xform 和 Pre-Xform 参数页）。worldXform * instanceXForm * Position
  • World Transform, then Instance worldinstance - 先使用世界变换，再应用各个实例的变换。instanceXForm * worldXForm * Position

实例纹理化

此功能允许将任意纹理应用到实例。这些纹理不需要具有相同的分辨率，也不需要合并为 3D Texture 或 2D Texture array 之类的分组格式。可以使用「Instance Textures」参数指定多个 TOP，而每个实例所应用的纹理由「Texture Index」参数中选择的通道指定。这与 3D Texture 或 2D Texture Array 不同，后者会使用 W 纹理坐标在单个纹理内选择纹理。默认情况下，此纹理会用作 PBR MAT 的「Base Color Map」纹理，以及所有其他材质（如 Phong MAT）的 Color Map。对于支持多个贴图的材质，可以在此材质的参数中选择本功能所替换的贴图。目前在 Windows 上最多可同时使用 16384 个纹理，在 macOS 上最多可同时使用 128 个纹理。这些数量还会因渲染所用的其他纹理（如其他贴图、cone light 查找贴图等）而减少。
