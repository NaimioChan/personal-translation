ReRange POP

摘要

ReRange POP 取输入的任意属性，重新映射其值的范围，然后输出到同一属性、任何其他现有属性或新属性。它对点、顶点或图元 attributes 操作。

它取指定属性的每个值，应用 From 范围 - To 范围的转换。

如果你将 Parameter Size 设为 3，而属性是像 P 这样的 float3，那么对于 P 的每个分量，你可以为每个属性分量设置单独的重新映射参数。

你指定的属性可以是任意类型，包括 float2、float3、float4、double 等。你可以让输出参数转换为整数。

创建新属性时，只需在 Output Attribute Scope 中填写新属性名称。ReRange POP 会决定它的数据类型，但你可以用 >>> 扩展参数覆盖。

对于 Input Attribute Scope，你可以指定分量的子集，例如 P(1) P(0)（等同于 P.yx swizzle 记法），其效果是重新排列 Y 和 X。

Info CHOP 通道

ReRange POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
