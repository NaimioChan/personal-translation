参数引用

可以在任意两个参数之间建立参数引用：在一个参数中放置引用另一个参数的表达式。这会在两个参数之间创建 Link，当一个变化时，另一个会自动变化。参数引用是一种 Link，在其他软件中称为「约束」（constraint）。

Source Parameter - 此参数正被另一个参数引用。

Reference Parameter - 此参数的值已链接（引用）到源参数，并包含一个表达式。

源参数值的任何变化都会改变被引用参数的值。

创建参数引用

Using right-click menus

1) 右键单击任意参数并选择 Yank Parameter。这将成为源参数。

2) 转到你希望被引用的参数，右键单击并选择 Put Yanked References


Using expressions

在参数中使用类似 op('pattern1').par.phase * 20. 的 Python 表达式。
