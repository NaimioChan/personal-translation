首选项对话框

说明

Preferences 是一个对话框，用于为各种 TouchDesigner 选项设置个人默认设置。这些首选项位于 Edit 菜单下的 Preferences... 中。这些选项会被保存，并应用于你下一次 TouchDesigner 会话。它们分为若干页。下面的图片概述了安装后的初始默认首选项。

注意： 首选项文件位于此处：

Windows C:/Users/username/AppData/Local/Derivative/TouchDesigner099/pref.txt

macOS ~/Library/Application Support/Derivative/TouchDesigner/pref.txt

常规首选项

保存时递增文件名 - 启用 On 后，.toe 文件名会带有数字后缀，每次保存文件时递增。Save As 不会如此，只有 Save 会。设为 On and Copy to Backup Folder 时，额外带编号的 .toe 文件会放在项目所在磁盘位置的名为 Backup 的文件夹中。

保存时创建链接文件名 - 创建一个不带编号递增的文件，它与最近保存的文件相同。这样可以方便地打开最近的文件。

退出时提示保存 - 如果启用了 Prompt to Save on Exit，每当你尝试关闭 TouchDesigner 时会弹出对话框。系统会提示你选择 Save & Quit、Discard & Quit 或 Cancel。选择 Save & Quit 时会遵循 Increment Filename when Saving 的值。

最小化时停止播放 - 启用后，当主 TouchDesigner 窗口最小化时动画会停止向前播放。窗口重新打开后，播放会继续。 On/Off 参数行为 - 设置参数对话框中的 On/Off 开关的工作方式。可选择点击任意位置切换状态，或特别地点击左侧为 Off、右侧为 On。

启用警告声音 - 每当触发警告对话框时会播放一段短音。

启用 Playbar 快捷键 - 关闭后将禁用 TouchDesigner 主要 Playbar 的键盘快捷键。

检查实验版 - 检查可用更新时包含实验版。

帮助标签 - 启用或禁用界面中的帮助弹出提示。

启动文件模式 - 选择 TouchDesigner 启动时使用默认项目、空项目还是自定义项目

自定义启动文件 - 如果 Startup File Mode 为 "Custom File"，则使用此文件。文件路径必须是绝对路径。

默认节点语言 - 决定新操作符以 Python Mode（默认）还是 Tscript 模式创建。

将外部 Python 添加到搜索路径 - 启用后 TouchDesigner 会自动把 python33 安装文件夹加入模块搜索路径。

Python 64-bit 模块路径 - python 模块搜索的附加搜索路径。

最后搜索外部 Python 路径 - 优先使用默认 Python 模块。决定上面提供的路径是在任何内置搜索路径之前先搜索，还是在内置路径搜索完之后最后搜索。

隐藏启动画面 - 打开后，TouchDesigner 启动时不会显示启动画面。此功能仅在 Commercial 和 Pro 版本中可用。

显示数值阶梯增量 -

数值阶梯步长 -

鼠标点击半径 - 鼠标点击覆盖的像素数。对于使用触控笔或其他难以在同一像素上双击、或存在其他精度问题的设备很有帮助。

使用 Alt+右键单击 代替中键单击 - 在没有中键的鼠标上很有用

显示启动错误 - 启动时不显示任何内容、仅显示警告，或显示所有错误。

Console 模式 - 控制使用哪种类型的控制台显示底层打印和错误消息。Alt+c 或菜单 Dialogs/Console 可打开它。

  • Default - 在 macOS 和 Windows 系统上都使用标准的 TouchDesigner 对话框。
  • Native (Windows Only) - 原生文本框（等同于设置环境变量 TOUCH_TEXT_CONSOLE=1）。可用于在主编辑器窗口打开之前查看错误。在 macOS 上行为与 'Default' 相同。
  • Disabled - 不创建任何控制台。例如在把输出捕获到 macOS Xcode 控制台时很有用。

在参数弹出帮助中显示上次脚本更改 - 打开后，如果参数被脚本更改，将鼠标悬停其上会显示有关该更改的信息。

网络首选项

以鼠标为中心缩放 - 缩放 Network Editor 中的布局区域，使鼠标光标正下方的点成为缩放中心。

按 TOP 查看器宽高比调整 TOP 节点大小 - 选中后，TOP 节点的大小会被锁定，使 OP Viewer 不会使底层 TOP 变形。

按 Control Panel 宽高比调整 Panel COMP 节点大小 - 选中后，Panel 节点的大小会被锁定，使 OP Viewer 不会使底层 Panel 变形。

鼠标滚轮导航 - 允许用户使用鼠标滚轮在 OP 层级中上下移动。

网络缩放到一定程度时向上跳转 - 设置网络缩放级别，达到该级别时 TouchDesigner 会在 OP 层级中上移一层。

滚轮缩放倍率 - 滚轮缩放功能的乘数。数值越大，用鼠标滚轮时网络缩放得越快。

中键缩放倍率 - 中键缩放的乘数。数值越大，用中键时网络缩放得越快。

平移/缩放延迟（秒）- 为网络上的平移或缩放操作增加的滞后秒数。

操作符名称最大尺寸（像素）- 放大时操作符名称在网络中显示的最大高度（像素）。

固定大小的操作符名称 - 选中后，操作符名称不会随网络放大缩小而变化，而是在所有网络变换中保持恒定大小。

默认开启节点查看器 - 默认在所有 OP 上开启 Node Viewer。

进入网络时开启节点查看器 - 首次进入网络时，开启该网络中所有 OP 的 Node Viewer。

点击选中时激活查看器 - 通过点击 OP 选中它时，开启该 OP 的 Node Viewer。

缓存节点查看器 - 记住查看器布局，以便在网络之间来回切换时更快。

显示 Network Editor 网格 - 在网络背景上显示网格。

网格亮度 - 如果网络网格可见，调整网格相对背景的亮度。

吸附到网格 - 设置节点吸附的网格大小。可设为 Off、Coarse 或 Fine。

吸附到 - 设置节点中吸附到网格的部位。可设为 Lower Left Corner 或 Node Center。

几何首选项

建立父子关系时保持位置 - 如果未勾选，对象在建立父子关系时会采用相对于父对象的位置。保持勾选则允许对象保留世界位置。

默认几何查看器模式 - 指定几何查看器是以 'Camera View' 模式启动（用于查看和浏览场景），还是以 'Select & Transform' 模式启动（用于选择并操作几何）。

几何查看器背景色 - 调整 Geometry Viewer 背景色的灰度级别。这会反映在所有 3D 查看器中，包括 Object Component 查看器、SOP 查看器和 MAT 查看器。

默认启用自适应归位 - 所有新建的 3D 查看器都会开启 Adaptive Homing。

默认显示网格 - 所有新建的 3D 查看器都会开启 Grid。

显示旋转轴心 - 开启或关闭旋转操作时轴心指示器的显示。

TOPs 首选项

查看器背景 - 在 TOP 的 Checker Board 或 Black 背景之间切换。

全局分辨率倍率 - 所有 TOP 中默认分辨率的乘数。

默认查看器填充模式 - 新建的 TOP 将使用此 'Viewer Fill Mode' 设置，它决定 TOP 图像在查看器中的显示方式。

默认查看器平滑度 - 新建的 TOP 将使用此 'Viewer Smoothness' 设置，它控制查看器中的像素过滤。

CHOPs 首选项

最大时间切片大小（帧）- 设置时间切片 CHOP 在连续屏幕更新之间处理的帧数上限。默认将时间切片限制为 6 帧）。

最小文字大小 - Time Sliced CHOP 查看器使用的最小文字大小。

最大文字大小 - Time Sliced CHOP 查看器使用的最大文字大小。

图形颜色 - 设置 CHOP 图形查看器中为通道分配颜色时使用的起始颜色。

色相步数 - 设置分配给通道的不同色相数量。分配完这么多颜色后，额外的通道会重复使用这些色相，但会应用下面的 Value Multiplier。

数值倍率 - 分配完 Hue Steps 中指定的颜色数量后，额外的通道会重复使用这些色相，但会应用此 Value Multiplier。每次颜色循环完 Hue Steps 数量的颜色后都会再次应用 Value Multiplier，此过程会重复进行。

最小数值 - 为分配的颜色设置最小值。

图形样式 - 设置向通道分配颜色的方式。

  • 按通道顺序设置颜色 - 使用通道顺序分配颜色。
  • 按通道名设置颜色 - 使用通道名分配颜色。
  • 按路径和通道名设置颜色 - 使用路径和通道名分配颜色。

图形显示 - 设置图形查看器的默认显示模式。

DATs 首选项

文件格式 - 选择文本存储所用的文件格式。可从 Windows 或 Unix 中选择。

最小文字大小 - 设置缩小时文字的最小高度（像素）。

最大文字大小 - 设置放大时文字的最大高度（像素）。

首选文字大小 - 设置首选的文字大小。如果未缩小或未放大过度，文字将默认使用此大小。

自动缩进 - 启用后，按回车换行时下一行会从相同的缩进级别开始。

显示缩进 - 使缩进字符在 DAT 中可见

显示行号 - 为带文本数据的 DAT 显示行号。

显示行编号 - 为带表格数据的 DAT 显示行编号。

显示列编号 - 为带表格数据的 DAT 显示列编号。

文本编辑器 - 指定在 DAT 中编辑文本时使用的外部编辑器。通过右键单击 DAT 并选择 Edit Contents... 启动

表格编辑器 - 指定在 DAT 中编辑表格时使用的外部编辑器。通过右键单击 DAT 并选择 Edit Contents... 启动
