PlayStation DualShock 手柄

Playstation DualShock 手柄可以作为 TouchDesigner 的输入设备使用。

PS3 DualShock 与 Sixaxis 手柄

使用 Playstation3 手柄需要：

  • 一个 PS3 DualShock3 或 Sixaxis 手柄
  • 一根 USB mini-B 线
  • PS3-Windows driver
  • PS3sixaxis.tox Component

必须在 Joystick CHOP 的 Joystick Source 参数中选择 PS3-Windows 驱动。目前不支持体感控制。

PS2 DualShock 手柄

使用 Playstation2 手柄需要：

  • 一个 PS2 Dualshock 或 Dualshock2 手柄
  • 一个 PS2-USB 手柄转接器
  • PS2dualshock.tox Component

必须在 Joystick CHOP 的 Joystick Source 参数中选择 PS2-USB 转接器。

提示： 如果 PS2 手柄是在 TouchDesigner 启动之后、或在 PS2Dualshock.tox 组件加入网络之后才连接到电脑，就必须从 Joystick Source 菜单中重新选择手柄转接器。如果你用的是另一种 PS2-USB 转接器，同样需要从 Joystick Source 菜单中重新选择。

网络解析

下图显示这些组件的网络。TouchDesigner 通过 Joystick CHOP 从手柄创建数据通道。

math1 CHOP 只是为了一致性而反转其中一个模拟摇杆。rename1 CHOP 把 Joystick CHOP 创建的所有通道重命名为更有意义的名字。如果你想更改任何控件的命名，可以在这里编辑重命名参数（模拟摇杆和方向键的通道为了清晰而较长，也可以用更短的名字）。

math2 CHOP 调整模拟摇杆和方向键的范围。它被重新映射为使中位为 0。水平方向，左为 0 到 -1，右为 0 到 1。垂直方向，下为 0 到 -1，上为 0 到 1。

加入 constant1 和 replace1 CHOP 是为了：如果启动时手柄不在，你的 CHOP 网络中仍然会有这些通道，并使用默认值。如果你在 rename1 CHOP 中重命名了通道，务必用新的通道名更新 constant1。

提示： 确保手柄上的 Analog 按钮已打开，红色 LED 应该亮着。否则模拟摇杆无法工作。
