Math CHOP

摘要

Math CHOP 对通道执行算术运算。一个 CHOP 的通道可以合并为一个通道，多个 CHOP 也可以合并为一个 CHOP。

OP 页允许你对每个采样进行前置运算，例如让所有采样变为正值，或对每个采样求平方。

使用 Combine Channels，对于多通道的输入 CHOP，可以将一个通道的采样与其他通道的采样相乘，把 N 个通道缩减为一个。你可以通过相乘、相加、求最大值等方式组合它们。

使用 Combine CHOPs，当有两个或更多 CHOP 输入时，可以将一个 CHOP 中的通道与所有其他 CHOP 中的通道相乘（或相加等），把 N 个 CHOP 缩减为 1 个。（否则多输入的通道只会被合并）

随后你可以对结果采样进行后置运算 —— 取负、开平方根等。

然后使用 Mult-Add 页，可以对每个采样的值进行偏移和缩放。

更方便的是，你也可以使用 Range 页，通过为某个输入 low-high 范围设置输出 low-high 范围来进行线性缩放。

最后，你可以将结果值舍入为整数。

提示：可以通过 Common 页上的 Scope 参数只影响输入的某些通道。

注意：若要在通道或 CHOP 之间进行逻辑运算（and、or……），请使用 Logic CHOP。

Tip: Customizing each channel:：你可以在 Post-Add 等参数中使用局部成员 chanIndex，例如 me.chanIndex*2，为每个通道给出不同的 post-add 值。chanIndex 在许多 CHOP（如 Pattern CHOP）中可用。（表达式未经过优化）

参数 - OP 页

这四个步骤按以下顺序执行：

Channel Pre OP preop - - 可以对单个通道执行一元运算。输入 Math CHOP 时对每个通道执行的一元运算菜单（如上所述）包括：
  • Off off - 不对通道做任何处理。
  • Negate negate - 取通道每个采样的负值。
  • Positive pos - 将通道的负值变为正值（绝对值）。
  • Root root - 对通道中的所有值开平方根。
  • Square square - 对通道中的所有值求平方。
  • Inverse inverse - 对通道中的所有值取倒数（1/x）。
Combine Channels chanop - - 对每个输入，在其 CHOP 的通道之间执行选定的运算。一个通道的第 N 个采样与其他通道的第 N 个采样组合：
  • Off off - 不组合通道。
  • Add add - 对所有通道求和。
  • Subtract sub - 用第一个通道减去所有通道。
  • Multiply mul - 将所有通道相乘。
  • Divide div - 用第一个通道除以其余所有通道。
  • Average avg - 取所有通道的平均值。
  • Minimum min - 取所有通道的最小值。
  • Maximum max - 取所有通道的最大值。
  • Length len - 将通道视为一个向量并计算其长度。
Combine CHOPs chopop - - 在输入 CHOP 之间执行的运算菜单，将多个 CHOP 合并为一个。
  • Off off - 不组合通道。
  • Add add - 对所有通道求和。
  • Subtract sub - 用第一个通道减去所有通道。
  • Multiply mul - 所有通道相乘。
  • Divide div - 用第一个通道除以其余所有通道。
  • Average avg - 取所有通道的平均值。
  • Minimum min - 取所有通道的最小值。
  • Maximum max - 取所有通道的最大值。
  • Length len - 将通道视为一个向量并计算其长度。
Channel Post OP postop - - 作为最后阶段，对上述运算得到的通道执行一个菜单（与 Channel Pre OP 相同）。
  • Off off -
  • Negate negate -
  • Positive pos -
  • Root root -
  • Square square -
  • Inverse inverse -
Match by match - - 按名称或索引匹配各输入之间的通道。
  • Channel Number index -
  • Channel Name name -
Align align - - 此菜单处理多个输入 CHOP 具有不同起始或结束时间的情况。一个 CHOP 输出的所有通道共用相同的起始/结束区间，因此必须用 Align Options 处理输入：
  • Automatic auto - 若存在时间切片，则会裁剪到当前 Time Slice，否则执行 Extend Min/Max。
  • Extend to Min/Max none - 找到最早的起点和最晚的终点，并使用 extend 条件将所有输入扩展到该范围。（参见 Extend Conditions）。
  • Stretch to Min/Max stretch - 找到最早的起点和最晚的终点，并将每个通道的起点和终点拉伸到该范围。
  • Shift to Minimum start - 找到最早的起点，并平移所有通道使其都从该索引开始。所有通道都扩展到最长通道的长度。
  • Shift to Maximum end - 找到最晚的终点，并平移所有通道使其都在该索引结束。将所有通道扩展到最长通道的长度。
  • Shift to First Interval shift1 - 将所有通道平移到第一个 CHOP 的起点，并使用第一个输入的范围对所有输入进行采样。
  • Trim to First Interval trim1 - 将所有通道裁剪到第一个 CHOP 的范围。
  • Stretch to First Interval stretch1 - 将所有通道拉伸到第一个 CHOP 的范围。
  • Trim to Smallest Interval trim - 将所有通道裁剪到最小的起始/结束区间。起点和终点值可能并非来自同一通道。
  • Stretch to Smallest Interval squash - 将所有通道拉伸到最小的起始/结束区间。起点和终点值可能并非来自同一通道。
Interp Pars per Sample interppars - 当输入频率高于时间轴时（例如音频）使用此选项。它可避免在调整 multiply、add 或 range 参数时输出出现爆音或杂音。
Integer integer - - 结果值可以转换为整数。
  • Off off - 不影响值。
  • Ceiling ceiling - 将值向上舍入到下一个整数。
  • Floor floor - 将值向下舍入到下一个整数。
  • Round round - 将值舍入到最接近的整数。

参数 - Mult-Add 页

接下来这三个步骤按以下顺序执行：

Pre-Add preoff - 首先，将该值加到每个通道的每个采样上。
Multiply gain - 然后乘以该值。
Post-Add postoff - 然后加上该值。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Math CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
