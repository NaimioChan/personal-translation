Wave CHOP

摘要

Wave CHOP 生成各种形状的重复波形。默认是 10 秒的 1 秒正弦波，共 600 帧。你可以调整周期（频率）、相位、形状、振幅和偏移。

Wave CHOP 在可指定时间范围的通道中生成一组波形。它已被LFO CHOP取代——后者提供无穷无尽的波形流，且Time Sliced；也被Pattern CHOP取代——后者对波形采样的成形有更多控制（且与时间无关）。Audio Oscillator CHOP也能生成持续重复的波形，但其默认设置针对更高频率的波形与更高（音频）采样率。

由于 Wave CHOP 的 Extend Conditions 设为 Repeat，波形会在 10 秒范围之外重复。

还可以对实际波形施加偏移、衰减和斜坡。

可使用Pattern Expansion在 Channel Name 参数中生成多个通道。以下是几个名称模式展开的示例：

  • tx ty tz
  • t[xyz] - 展开为tx ty tz
  • chan[1-4] - 展开为chan1 chan2 chan3 chan4
  • c[xyz][1-5:2] - 展开为cx1 cx3 cx5 cy1 cy3 cy5 cz1 cz3 cz5

另请参阅：LFO CHOP、Pattern CHOP、Audio Oscillator CHOP。

参数 - Wave 页

Type wavetype - 可选择以下波形形状：
  • Constant const - (1) 值恒定的「波形」。
  • Sine sin - （-1 到 1）正弦波。
  • Gaussian normal - （0 到 1）高斯（也称钟形或正态）曲线。
  • Triangle tri - (-1 到 1) 上升到 1 再下降到 0 的斜坡，可用 Bias 参数调整形状。
  • Ramp ramp - （0 到 1）从 0 到 1 的斜坡。
  • Square square - （-1 到 1）阶跃上升/阶跃下降，可通过 Bias 控制使其成为矩形。
  • Pulse pulse - (0 到 1) 在一个采样上产生 1，其余为 0。
  • Expression expr - 用户定义的表达式。

正弦公式为：

out = Amplitude * (Offset + sin ((Period*index - Phase)*360))
Period period - 周期是波形重复所需的秒数、帧数或采样数。它以该 CHOP 的 Units（默认 Seconds）表示，位于 Common 页。
Period Unit periodunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
Phase phase - 相位在时间上移动波形，以周期的分数表示，通常在 0 到 1 之间。
Bias bias - 可以在 -1 到 +1 范围内改变 bias，以调整某些波形类型的形状。
Offset offset - 波形值可以偏移。将 Offset 设为 1，正弦波可以始终为正。
Amplitude amp - 波形值可以缩放。
Decay Rate decay - 波形的振幅可以随时间以「指数衰减」减小。例如，若 Decay 为 0.2、Units 为秒，则振幅在 1 秒后衰减到 0.8，在 2 秒后衰减到 0.8 的 0.8（即 0.64）。
Decay Rate Unit decayunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
Ramp Slope ramp - 然后给结果加上斜率为 Ramp 的斜坡。每过一个时间单位，通道就增加 Ramp Slope 的值。例如，若 Ramp 为 1.2，则除波形形状外，通道每秒增加 1.2。
Ramp Slope Unit rampunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
Expression exprs - 若波形类型为 Expression，则用 Expression 参数输入数学表达式。可用的局部变量有：$I（Index）、$L（在周期 0 到 1 上循环的变量）、$C（循环变量，即当前索引处波形已经过的整数周期数）。

参数 - Channel 页

Channel Names channelname - 你可以用 “chan[1-20]” 这类简单模式创建多个通道，它会生成从 chan1 到 chan20 的 20 个通道。有关此项及所有 Options 的说明，请参阅 Common CHOP Parameters 一节。参见Scope and Channel Name Matching Options。
Start start - 区间起点，以 Units（秒、帧或采样）表示。
Start Unit startunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
End end - 区间终点，以 Units（秒、帧或采样）表示。
End Unit endunit - 选择此参数使用的单位：Samples、Frames 或 Seconds。
Sample Rate rate - 通道的采样率，单位为每秒采样数。
Extend Left left - 左侧延伸条件（范围之前/之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道起点之前的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常数值
Extend Right right - 右侧延伸条件（范围之前/之后）。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道终点之后的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常数值
Default Value defval - 用于 Default Value extend 条件的值。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Wave CHOP 的额外信息可通过Info CHOP访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
