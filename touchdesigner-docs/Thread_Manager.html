线程管理器

摘要

Thread Manager 是一个自定义 TouchDesigner 组件，设计用于包装 Threading library of Python 3.11.x。

Thread Manager 为 Python 开发者简化了 TouchDesigner 中的线程和任务处理。高级用户可以用 op.TDResources.ThreadManager 直接访问 Thread Manager COMP。或者，想要更简单的基于组件方式的用户，可以查看 Palette 的 ThreadManager 文件夹中提供的 Thread Manager Client。它提供了一个简单的面向回调的组件，包装了 Thread Manager。

⚠️ Keep in mind 用户在 TouchDesigner 中使用线程时需要谨慎。经验法则是，不要从另一个线程访问主 TouchDesigner 线程中的对象，例如 OP、COMP、参数。无论是写入、读取还是任何其他操作。无论你依赖 op.TDResources.ThreadManager 还是 Thread Manager Client 都是如此。

高级开发者可参阅 Thread Manager Ext page。

使用 ThreadsMonitor 可以更容易地调试线程。

在内部并且默认情况下，Thread Manager 会创建 TDThreads，即 Python 线程（依赖 threading 库），并扩展了 TouchDesigner 和 Thread Manager 特有的附加功能。默认的 TDThreads 组成一个工作线程池。TDThread 会在任务队列中查找 TDTasks。当有 TDThread 可用时，它会取出一个 TDTask 并在一个线程中执行。TDTask 是一个自定义对象，高级用户可以实例化它，并设置目标方法和附加属性，以定制 TDTask 在 TDThread 中的执行方式。

💡由于 Thread Manager 属于我们的 TDResources，建议使用 ThreadsMonitor 读取参数并与之交互。

threadManager Ext

参数 - Thread Manager 页

Running Threads Runningthreads - 当前正在运行并在 Thread Manager 上注册的线程数。
Number Of Workers Numberofworkers - 当前正在运行并在此 ThreadManager 上注册的工作线程数。
Max Number Of Workers Maxnumberofworkers - 组成线程池的最大工作线程数。不能大于 Max Number Of Threads（或 os.cpu_count()）。默认为 4。
Max Number Of Threads Maxnumberofthreads - 此硬件上逻辑线程的总数上限。工作线程池不能大于此值。其值等于 os.cpu_count()。达到此值时，额外的独立线程将按所选的备用策略处理。
Strategy on max threads reached Strategyonmaxthreadsreached - 达到最大线程数时，选择一个备用策略。
  • Queue Queue - 创建一个任务并入队以延迟执行，等有工作线程空出或当前线程数降到 os.cpu_count() 以下时执行。
  • Except Except - 抛出异常。
  • Create Create - 创建一个线程以强制立即执行。
Tasks In Queue Tasksinqueue - 当前在队列中等待工作线程池执行的 TDTask 数量。
Total tasks Totaltasks - 当前正在运行或排队中的 TDTask 总数。
Queue Max Size Queuemaxsize - TDTask 队列的最大长度。0 表示没有限制。
Terminate All Threads Terminateallthreads - 终止所有当前正在运行的 TDThread。请谨慎使用，仅用于调试。否则应在单个 TDThread 上实现事件或抛出异常。
Reset Reset - 把 ThreadManager 重置为初始化之后的初始状态。关闭所有运行中的线程并重启工作线程池。清除所有正在运行和待处理的 TDTask。
Utilities Utilities - Thread Manager COMP 附带的 Extras。
Open Logger Openlogger - 打开内部 Logger COMP 的参数对话框。
