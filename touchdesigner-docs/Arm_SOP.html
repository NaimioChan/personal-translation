Arm SOP

摘要

Arm SOP 会为手臂创建所有必要的几何，并提供平滑、不扭曲的皮肤，将手臂连接到身体。它通过与手印关联的反向运动学控制。

armSOP_Class

参数 - Arm 页

Capture Type capttype - - 可以将 Ellipses 或 Capture Regions 用作变形几何。椭圆形用于 Skeleton SOP。Capture Regions 用于 Capture SOP。
  • Ellipses ellipses -
  • Capture Regions cregions -
Arm Axis axis - - 沿 +X 或 -X 轴定位模型。
  • + X posx -
  • - X negx -
Radius bonerad - 控制圆半径的缩放。
Rotate Hand rotatehand - 此参数会旋转手和腕关节，以匹配手印对象的方向。为正确工作，末端执行器（手印）的缩放变换必须保持为 1。

注意： 如果通道设为 0，则手的旋转相对于前臂。如果通道设为 1，则手的旋转与末端执行器的方向相同。

Auto Elbow Twist autoelbow - 此参数会将肘关节的默认扭转调整到更自然的位置。
Elbow Twist elbowtwist - 指定肘关节的旋转角度。
Flip Elbow flipelbow - 此开关使用另一种肘部位置解来定位手臂。

参数 - Transforms 页

当手臂摆到触及末端效应器（手印）的位置时，肩、肘、腕关节可能产生看起来不自然的弯曲。变换字段允许手动调整每个关节的每个控制圆来修正这一点。

每个关节圆（例如 Shoulder 1）有三个变换字段（两个平移和一个缩放）。这些值会按该特定关节所施加的弯曲量进行缩放。换句话说，当手臂完全伸展时，变换没有任何效果。当手臂关节角度为 90 时，效果最大。因此，在调整这些值之前，请先把关节设为 90。

Info CHOP 通道

Arm SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
