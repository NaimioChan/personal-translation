Serial DAT

摘要

Serial DAT 用于通过外部端口进行串口通信，使用 RS-232 协议。这些端口通常是 9 针连接器，或新式机器上的 USB 端口。（使用 USB 端口需要 USB 转串口适配器和驱动。）在 Windows 操作系统中，计算机所有可用的串口都可以在设备管理器中找到：Computer –> Manage -> Devices -> Serial… -> COM ports。它们的名称以 'COM' 开头。例如：COM1、COM2、COM3。

要通过此连接发送字节，请参阅 serialDAT_Class 中的 send 方法，或在 Tscript 中使用 send 命令。

另请参阅 Arduino 和 Serial CHOP。

参数 - Connect 页

Active active - 此复选框启用串口连接。
Row/Callback Format format - 将传入数据解读为二进制或 ASCII 数据。如果格式为 Per Byte，每收到一个二进制字节就追加一行。如果格式为 Per Line，每收到一条以 null 或换行分隔的消息就追加一行。
  • One Per Byte perbyte -（原名为 'binary'）。
  • One Per Line perline -（原名为 'Ascii'）以 null/换行分隔。
  • One Per Message permessage - 完整的传入消息。
Port port - 选择串口连接使用的 COM 端口。弹出菜单中提供默认端口名 1 到 8，但也可在该字段中手动输入任何名称。
Baud Rate baudrate - 每秒传输的最大信息位数，包括「控制」位。请查看输入设备的默认波特率并相应设置。
  • 1200 1200 -
  • 2400 2400 -
  • 9600 9600 -
  • 19200 19200 -
  • 38400 38400 -
  • 57600 57600 -
  • 115200 115200 -
  • 230400 230400 -
  • 460800 460800 -
  • 921600 921600 -
  • 1382400 1382400 -
Data Bits databits - 此参数设置每次发送的数据位数。数据位是「反向」传输的。反向指的是传输顺序，即从最低有效位（LSB）到最高有效位（MSB）。要解读数据位，必须从右向左读。
  • 6 6 -
  • 7 7 -
  • 8 8 -
  • 9 9 -
Parity parity - 此参数可设为 none、even 或 odd。可选的校验位跟在数据位之后，作为一种简单的错误检查手段。校验位的工作方式是事先指定传输的校验为偶校验还是奇校验。如果校验设为奇校验，发送端会设置校验位，使数据位和校验位中 1 的总数为奇数。
  • Even even -
  • Odd odd -
  • None none -
Stop Bits stopbits - 传输数据包的最后部分是 1 或 2 个停止位。此后连接会等待下一个起始位。
  • 1 1 -
  • 2 2 -
DTR dtr - DTR（数据终端就绪）流控制。（仅 Windows）。
  • Disable disable - 打开设备时将该线路置为无效。
  • Enable enable - 打开设备时启用该线路。
  • Handshake handshake - 启用与设备的握手。
RTS rts - RTS（请求发送）流控制。（仅 Windows）。
  • Disable disable - 打开设备时将该线路置为无效。
  • Enable enable - 打开设备时启用该线路。
  • Handshake handshake - 启用 RTS 握手。
  • Toggle toggle - 仅在有待处理字节时线路为高。

参数 - Received Data 页

Callbacks DAT callbacks - Callbacks DAT 会为收到的每条消息执行一次。
Execute from executeloc - 决定脚本的运行位置。
  • Current Node current - 脚本从当前节点位置执行。
  • Callbacks DAT callbacks - 脚本从 Callbacks DAT 参数中指定的 DAT 位置执行。
  • Specified Operator op - 脚本从下方 Component 参数指定的组件执行。
From Operator fromop - 若 Execute From 参数设为 Specified Operator，则脚本将从该路径执行。
Clamp Output clamp - 该 DAT 默认限制为 100 条消息，但使用 Clamp Output 可以设为任意值，包括无限制。
Maximum Lines maxlines - 限制消息数量，较旧的消息会先从列表中移除。
Clear Output clear - 删除除标题外的所有行。要用脚本命令清空，示例如下：opparm -c /serial1 clear
Bytes Column bytes - 在单独的列中输出消息的原始字节。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
