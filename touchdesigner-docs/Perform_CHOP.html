Perform CHOP

摘要

Perform CHOP 输出许多通道，例如每秒帧数，用来描述 TouchDesigner 进程的当前状态。作为通道，它们可以被接入用户界面和计算，以实现该进程的实时自调节。

它输出上一帧绘制时的「计算时间」，这反映的是 TouchDesigner 在上一秒内计算了多少帧。cook

提示：在 Perform CHOP 之后接一个 Trail CHOP 来观察它的进展。

该通道接到 Trail CHOP 后，会显示哪些帧被计算、哪些帧被跳过，对于优化工作以达到目标帧率很有用。

Dialogs -> Variables -> Built-in 中的内置变量包含更多关于你运行中系统的有用数据。另请参阅 Variables 页面的内置变量小节。

参数 - Perform 页

这里列出 Perform CHOP 输出的各个通道。

Frames per Second fps - 上一秒内渲染的帧数。
Frame Time msec - 每帧计算所花费的时间（毫秒）。
Cook cook - 某帧被计算时等于 1，被跳过时等于 0。在 Trail CHOP 中查看这个通道通常很有用，可以看到帧何时被跳过（丢弃）。
Dropped Frames droppedframes - 上一帧与当前帧之间丢弃的帧数。
Movie Read Ahead Misses mvreadahead - 影片预读未能维持指定 Read Ahead 帧数的次数。
GPU Mem Used (MB) gpumemused - 已使用的 GPU 内存量（兆字节）。
Total GPU Mem (MB) totalgpumem - 系统上可用的 GPU 内存总量（兆字节）。
Total Active OPs activeops - 当前正在积极计算的操作符数量。
Total Deactivated OP Calls deactivatedops - 对某个 Cooking Flag 已关闭的组件发起计算的次数。
Total OPs totalops - .toe 文件中的操作符总数。
CPU Mem Used (MB) cpumemused - 已使用的 CPU 内存量（兆字节）。
Cook State cookstate - 监视哪些帧真正被计算了。把 Perform CHOP 接到 Trail CHOP 上，才能正确看到计算过与未计算的帧轨迹。（它看起来总是 1，因为查看器只显示当前帧，而不显示错过的帧。）
Cook Realtime cookrealtime - 监视 realtime 标记的状态，判断 TouchDesigner 是否以实时模式运行。
Cookrate cookrate - 项目的全局目标计算速率（每秒帧数）。这是根组件 root.time.rate 的每秒帧数，通常为 60，但由于帧计算耗时过长，实际每秒帧数可能更低。
Time Slice Step timeslicestep - TouchDesigner 在本次计算中向前推进的帧数。也就是 Time Slice 以帧计的长度。当系统完成一帧所需时间不超过 1000/root.time.rate 毫秒时（60 的速率对应 16.666 毫秒），它等于 1。
Time Slice Milliseconds timeslicemsec - 当前 Time Slice 的长度（毫秒）。
Perform Mode performmode - 监视 Perform Mode 的状态。
Perform Window Focus performfocus - 监视 Perform Window 当前是否拥有焦点。
GPU Temperature (Slow) gputemp - 监视系统 GPU 的温度，仅适用于 NVIDIA GPU。
AC Line Status aclinestatus - 指示笔记本的 AC 充电器是否已插上并工作。检测到交流电源时为 1，否则为 0。
Battery Charging batterycharging - 指示电池是否正在充电。充电中为 1，否则为 0。
Battery Life batterylife - 指示电池剩余电量，1 为满电，0 为空电。
Battery Time batterytime - 预计的电池剩余使用时间。仅在交流电源断开且电池未充电时有效。
Active Expressions activeexpressions - 项目中发现的活动 Python 表达式数量。
Optimized Expressions optimizedexpression - 已被优化的 Python 表达式数量，参见 Optimized Python Expressions。
Expressions Using Cache cachedexpressions - 已被缓存的 Python 表达式数量，参见 Optimized Python Expressions。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Perform CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
