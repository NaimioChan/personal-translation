OP Snippets

OP Snippets 是一组 1000 多个 TouchDesigner Operators 的实时示例。Snippets 可以复制/粘贴到你的项目中。

OP Snippets 示例可以通过三种方式启动：

  • 在网络中右键点击现有的 OP，如果菜单项可选，选择 Operator Snippets...
  • 在 OP Create 对话框中右键点击操作符名称，然后选择 Operator Snippets...
  • Help 菜单 - → Operator Snippets。

要查看最新的 snippets，请点击 Snippets 窗口中的 Newest 按钮。

提交 Operator Snippets 的准则

你可以把 snippet 示例发送给 Derivative。

在名为 readMe 的 Text DAT 中说明它的作用。在 Text DAT 的 Common 页上打开 Word Wrap。

提交 snippet 即表示你接受我们无偿使用它，以造福整个 TouchDesigner 社区。我们会尽力在 Snippet Author 字段中署名感谢你。

提交至 snippets@derivative.ca。

注意：感谢已经贡献过 snippet 的人。每一份贡献的 snippet 都需要 Derivative 花一些精力来筛选、润色，并确保它符合当前的最佳实践。因此它们最终的形式可能与最初不同。但我们确实感谢这些贡献以及你的所有见解。

感谢你帮助提升 TouchDesigner 社区的技能水平！
