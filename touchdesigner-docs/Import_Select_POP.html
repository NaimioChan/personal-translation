Import Select POP

摘要

Import Select POP 用于导入并加载 USD COMP 和 FBX COMP 中定义的几何类型图元。它基本上能加载 USD COMP 或 FBX COMP 支持的任何几何类型，例如 Mesh、Points、NURBS Curves 或 Patches、Basis Curves。每个几何代表加载文件中的一个图元，也可以是为提升性能而合并在一起的一组图元。对于 POP 不支持的几何图元类型，它们会被转换为三角形、四边形、线段带和点图元。

在 USD COMP 和 FBX COMP 中，如果 Import Select POP 渲染的是合并后的几何，则会在该 POP 旁创建一个 Info DAT 操作符，它表示导入文件内/来自导入文件的图元原始路径，这有助于用户查看当前 POP 由哪些几何组成。

Import Select POP 可以在 Playback 页中使用自己的动画控制，也可以使用其父 COMP 的设置。

导入的几何会直接加载到 GPU。

importselectPOP_Class

参数 - General 页

Import Parent parent - 指定用于搜索素材的导入父级（例如 USD/FBX COMP）。未指定 COMP 时，默认在其路径中的第一个导入父级中搜索。
Geo Path geometry - 导入文件中的几何路径。
Reload reload - 重新导入并加载几何。
Blend Shape blendshape - 指定此 POP 要加载的导入文件中的混合形状名称（如果指定了的话）。
Compute Tangents comptang - 是否计算切线。

Info CHOP 通道

Import Select POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
