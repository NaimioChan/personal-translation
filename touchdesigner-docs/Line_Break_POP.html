Line Break POP

摘要

Line Break POP 从其输入的点与 line strip 创建新的 line strip。

它可以使用一个属性（默认名为 LineBreak）创建一组 line strip：遍历输入的所有点，如果 LineBreak 属性为 1，就开启新的 line strip。如果 LineBreak 为 0，则继续当前线，包含当前点。

另一种方式是，它可以使用点属性 LineStripIndex（与 Line Metrics 创建的同名属性）来生成独立的 line strip。

它也可以在某点与前一点的距离超过指定距离时拆分 line strip。

它可以每 N 个点拆分一次 line strip。

它也可以简单地用其输入点创建一条 line strip。

另请参阅 Primitive POP、Convert POP
