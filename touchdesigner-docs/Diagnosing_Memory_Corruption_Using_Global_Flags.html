用全局标志诊断内存损坏

概述

少数情况下，崩溃可能是由一般的内存损坏引起的，这类问题很难通过常规 .dmp 文件追踪。追踪这类问题的一种方法是改变 Windows 分配内存的方式，使它在每个内存块周围放置只读的「保护」区段。如果 TouchDesigner 试图写到超出应有边界的位置，就会在那一刻崩溃。这样生成的 .dmp 文件信息量更大。如果没有这些只读保护页，操作系统会允许我们写入那块内存，而那块内存很可能正被代码的其他部分使用，从而破坏它。要强制操作系统创建这些保护页，需要使用 Global Flags 工具。它属于 Debugging Tools for Windows，可从此处下载： https://learn.microsoft.com/en-us/windows-hardware/drivers/debugger/debugger-download-tools 你可能会想选择 'As a standalone toolset' 工作流。

设置标记

Global Flags 工具在磁盘上的名称为 gflags.exe。安装后，搜索 Global Flags 或 gflags.exe 即可运行。需要以管理员身份运行。

  • 打开后顶部会有 4 个选项卡。选择 'Image File' 选项卡。
  • 在 'Image:' 字段中输入 'touchdesigner.exe'，然后按键盘上的 Tab 键。
  • 此时所有复选框都应为未勾选状态。
  • 勾选 'Enable page heap' 选项，然后点击 Ok
  • 现在运行你的项目。它很可能加载和运行得更慢。如果你的项目非常大，加载可能需要很长时间。
  • 使崩溃发生，并生成 .dmp 文件。
  • 将 .dmp 文件发送到 support@derivative.ca

要禁用此功能并恢复性能，按同样的步骤操作。这次按 Tab 键时，'Enable page heap' 应已处于勾选状态，此时取消勾选即可。

另请参阅 Troubleshooting in TouchDesigner。
