网络路径

每个节点都有 network path 或 path。路径是 operator 在 TouchDesigner 项目的 Hierarchy 中的位置。例如，/geo1/circle1 是名为 geo1 的组件中一个名为 circle1 的节点。路径 / 称为 Root 或 Home。Components 用于在路径中创建另一层级，就像计算机文件路径中的文件夹/目录一样。

示例：节点 text1 的路径是 /project1/container1/button2/text1。路径中直到最后一个节点之前的所有节点都是组件。也就是说，project1、container1 和 button2 都是组件。

如果路径以 / 开头，它就是「绝对路径」，指回层级的顶层根。示例：/project1/wave1。

如果要引用同一网络中的另一个节点，只需写出节点名：text1 或 button1/out1。这就是「相对路径」。

如果你在 /project1/container1/button2 中，「父节点」就是 /project1/container1。你可以用「..」形式引用 /project1/container1 中的另一个节点：../button3，其中 .. 表示「我的父级」。../button3 就是「相对路径」。

网络路径并不指向 TouchDesigner 文件在 Windows 文件系统中的位置。当前选中操作符的网络路径位于 TouchDesigner 中每个 pane 的顶部。TouchDesigner 网络的最高层级以「/」表示，称为网络的 root。

你可以用鼠标滚轮、Enter 和「i」键，或左键单击窗格顶部的网络路径，在网络层级中上下导航。点击当前路径的最低层级，会显示可选子组件的下拉列表。要向上导航，可使用滚轮、「u」键，或在路径中选择相应的「/」以转到该层级。

在哪里能找到路径

在每个 Network Editor 的顶部，你都能看到正在查看的网络所属组件的路径。

操作符通常有一个路径参数，例如 Select TOP，它可以从任意网络获取图像。

任何参数都可以包含带路径的 Python 表达式。

路径出现在 Python 脚本和 DAT 中包含的回调里，通常是 Text DAT。

你可能会看到表达式 op('wave1')['chan1']，它表示名为 wave1 的 CHOP 中一个名为 chan1 的通道。

你可能会看到表达式 op('/project1/effect/transform1').par.tx，它是 transform1 节点的 tx 参数。

OP Find DAT 输出一张路径表。

在导出中你会看到指向某个参数的路径：transform:tx 这是 Transform TOP 的 tx 参数。
