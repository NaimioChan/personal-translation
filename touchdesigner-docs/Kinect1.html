Kinect 1

本文包含 Kinect 第 1 版设备的信息，关于更新的第 2 版型号请参阅 Kinect 2 article。

在 Windows 操作系统上，可通过 Kinect TOP 和 Kinect CHOP 将 Microsoft Kinect1 用作 TouchDesigner 的输入设备。

Kinect 是 Microsoft 的运动传感器输入设备。该设备包括红外深度感应摄像头、RGB 彩色摄像头，以及用于音频采集的麦克风阵列。Microsoft Kinect SDK 提供骨骼跟踪、手部交互和语音识别等功能。

Kinect 最初于 2010 年随 Microsoft 的 Xbox360 游戏主机发布。2012 年 2 月 1 日，Microsoft 发布了 Kinect for Windows，其中包含仅适用于 Windows 操作系统新型 Kinect 硬件的 Kinect SDK。

TouchDesigner 中的 Kinect 支持

TouchDesigner 使用 Microsoft 官方的 Kinect for Windows SDK 内置支持 Kinect。因此，TouchDesigner 内置的 Kinect 操作符仅支持 Kinect for Windows 硬件。（有关 Xbox 360 Kinect 传感器的信息，请参阅下方提示）


Requirements

  • Kinect for Windows 硬件设备型号 1517（Kinect for Xbox360 型号 1414 和 1473 没有「官方支持」，见下文）
  • 安装 Kinect Runtime 1.8 或 Kinect for Windows SDK 1.8


Ways to interface with Kinect in TouchDesigner

  • 深度摄像头 - Kinect TOP
  • RGB 摄像头 - Kinect TOP
  • 红外摄像头 - Kinect TOP
  • 骨骼点跟踪 - Kinect CHOP 注意：关节朝向与骨骼层级见：Kinect Hierarchy
  • 手部交互 - Kinect CHOP
  • 麦克风阵列音频采集 - Audio Device In CHOP
  • 要控制摄像头的俯仰，请使用 Tscript kinecttilt 命令

使用 Kinect 传感器的提示

  • 务必连接 Kinect 传感器附带的 AC 电源。在 USB 供电下绿色 LED 会亮起，但除非同时连接 AC 电源，否则传感器无法正常工作。
  • Kinect V1 在 USB3.0 端口上可能不太稳定；如果连接设备时遇到问题或连接一段时间后断开，请尝试 USB2.0 端口。
  • 如果使用多个 Kinect，每台 Kinect 传感器必须连接到各自的 USB 控制器。在某些计算机上，多个 USB 端口共用同一个 USB 控制器，如果两个 Kinect 共用该控制器就会出问题。请参阅计算机的设备管理器，查看哪些端口属于哪个 USB 控制器。
  • 如果需要 USB 延长器，我们已成功将这些延长器与 Kinect 传感器和其他 USB 摄像头配合使用。25M USB Active Extenders 注意，这些延长器不能两个串联使用。
  • Xbox360 (models 1414 and 1473) 虽然未获官方支持，但通常安装 Kinect for Windows SDK 1.8 后即可使用。Kinect Runtime 1.8 无法用于 Xbox360 型号，这些型号不会被检测到，必须安装完整 SDK。
  • 如需更多支持与故障排除，请参阅 Kinect Support Community。
