File In POP

摘要

File In POP 读取文件并将其转换为 GPU 内存中的 POP。

文件格式：

  • .obj Wavefront Object 文件格式支持面（多边形）和线带（f 和 l 标签）。边数超过 3 的多边形会进行三角化。它支持纹理 UV 坐标（Texcoord）和法线。（内部使用 tinyobj）
  • .ply Stanford Triangle 格式通过 face 元素中的 vertex_indices 属性支持面（多边形）。3 边和 4 边的多边形在 POP 中会转换为三角形和四边形图元。超过 4 边的多边形会转换为闭合线带。red、green、blue、alpha 或 r、g、b、a 顶点元素将作为 POP 中的 Point Color 读取。

也支持较旧的格式，例如：

  • .tog TouchDesigner 几何文件，是其他几何类型以 TouchDesigner 原生格式导出的结果
  • .bhclassic Houdini 二进制几何格式。
  • .hclassic Houdini ASCII 几何格式。

指定网络上可访问的受支持文件时，可以使用 http:// URL 前缀。

某些文件格式 File In POP 和 Point File In POP 都能读取，区别在于 File In POP 只导入上面列出的属性和元素。以下是这两个操作符都能读取的文件列表。

  • .ply 文件格式可以包含自定义属性数据
  • .obj 文件格式

另请参阅：Point File In POP、Alembic In POP、FBX COMP、USD COMP、pop File Format

Info CHOP 通道

File In POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
