Storage

每个操作符都附带一个 Python「storage」字典。存入该字典的值是持久的，并随操作符一起保存。可以通过 OP.fetch() 或 OP.store() 等方法直接操作 storage 字典的内容。见 Storage Class。你可以用 Examine DAT 查看 storage。

storage 字典可通过 n.storage 直接访问。还有若干与 storage 相关的工具函数，可在此处找到：OP Storage。

自动计算

当 storage 中某个不可变元素发生变化时，依赖它的表达式会自动计算。关于可变元素（list、dict、set）的计算信息，见 deeply dependable collections.

在文件中保留

Storage 会随 .toe 和 .tox 文件一起保存，并在启动时加载。如果你希望启动时这些值处于初始状态，而不管保存文件时的值是什么，可以先用 storeStartupValue() 方法创建 storage 条目，而不用 store()

另见：StorageManager Class、Storage in OP_Class。
