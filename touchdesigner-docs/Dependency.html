依赖

依赖（Dependency）是 TouchDesigner 中的 Procedural 机制：当某一数据发生变化时，会自动使其他操作符和表达式重新 Cook。这确保 TouchDesigner 进程中所有数据保持一致，并使所有输出显示、UI、设备和协议实时更新。

自动依赖

如果某个操作符的输出数据或参数值发生变化，会使其下游的其他操作符计算。下游是指连接到变化节点输出的操作符，以及引用该变化操作符的操作符（或其参数）（通常表现为网络中的虚线）。

参见 Cook。

Python 数据依赖

由于 Python 本身没有程序化机制，TouchDesigner 中的 Dependency Objects 允许 python 数据在变化时触发下游计算。

关于如何设置 Python 依赖，请参见 Dependency_Class。要创建可递归依赖的 Python 集合，请参见 Deeply Dependable Collections。
