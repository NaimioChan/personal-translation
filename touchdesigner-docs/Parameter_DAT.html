Parameter DAT

摘要

Parameter DAT 输出一个表格，包含任意 OP 类型的操作符的参数名称和值，包括自定义参数。

它可以输出预求值的表达式、Parameter Mode，以及定义参数的所有属性 - 其类型、标签、范围、菜单项、限制等，最多 24 列信息。

parameterDAT_Class

参数 - Parameter 页

Operators ops - 这些操作符决定从哪里获取通道。指定一个或多个操作符名称或路径。示例：wave1、slider*、constant[1-9] constant[10-19:2]、../base1。或使用菜单选择操作符。
Parameters parameters - 要从 OP 获取的参数名称列表（可包含通配符）。一个或多个参数，或使用 * 表示所有参数。也可以使用 ^ 指定「NOT」选择。或使用菜单选择参数。请参阅 Pattern Matching。
Include Op Name includeopname - 在表格中每个参数名称前添加 OP 名称
Rename from renamefrom - 请参阅 Pattern Matching。
Rename to renameto - 请参阅 Pattern Expansion。
Custom custom - 输出操作符的自定义参数。
Built-In builtin - 输出操作符的内置参数。

参数 - Output 页

关于参数及其值的信息开关

Header header - 输出列标题。
Name name - 输出参数名称。
Value value - 输出求值后的参数值。
Eval eval - 以 python 对象形式输出求值后的参数值。
Constant constant - 输出参数的当前常量值。
Expression expression - 输出参数的当前 python 表达式。
Export export - 输出参数的导出路径。
Mode mode - 输出参数的当前模式（常量、表达式或导出）。
Style style - 输出参数的格式（例如 float 参数为 Float，菜单参数为 Menu 等）。
Tuplet Name tupletname - 输出参数所属元组的名称。例如，Geometry COMP 上的 tx 属于 t 元组。
Size size - 输出元组的大小。例如，Geometry COMP 上的 tx 元组大小为 3，因为它属于含 3 个参数的 t 元组。
Path path - 输出节点的路径。
Menu Index menuindex - 如果参数是菜单，则输出该菜单所选项目的索引。

参数 - Define 页

用于定义参数的信息开关。

Min/Max minmax - 输出参数的最小值和最大值。这些值会将参数值钳制在该范围内。如果 clampmin 为 0，则最小值不钳制，该行/列条目为 0。如果 clampmax 为 0，则最大值不钳制，该行/列条目为 1。
Clamp Min/Max clampminmax - 输出参数是否有钳制最小值或钳制最大值。如果为 true，则这些值由 min/max 列定义。
Norm Min/Max normminmax - 输出参数在界面中的最小值和最大值（即滑块的最小值和最大值）。
Default default - 输出参数的默认值
Enabled enabled - 输出参数当前是否启用
Read Only readonly - 输出参数当前是否只读
Section section - 输出参数上方是否有分区分隔线/分隔符（即线条）。
Menu Names menunames - 输出任意菜单参数的菜单名称列表。
Menu Labels menulabels - 输出任意菜单参数的菜单标签列表。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。
