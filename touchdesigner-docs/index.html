新增内容

当前正式版 Build 2025.33230 Download - Sept 01 2026 - Release Notes

要了解最新正式版的新增内容，请阅读我们的 2025 Official Announcement。往年的亮点总结在此处 2023、 2022 和 2021。

隆重推出 POPs！（Point Operators）

今年的正式版引入了 POPs，这是一个新的 Point Operator 族，通过 GPU 加速的工作流处理 3D 几何和任何通用数值数据，带来全新水平的性能。

Learning POPs - 要开始使用 POPs，请查看 Learning About POPs 页面以下载示例并阅读文档。你也可以在我们免费的 TouchDesigner Fundamentals Course 的 POPs section 中跟随我们的新系列教程。

发布说明

Official Builds 是可用于生产、经过测试且稳定的版本，适合构建和交付项目。

自 2025 年 10 月发布以来，我们一直在持续更新和改进 TouchDesigner 2025 的正式版。前往 Release Notes 查看完整更新日志以及当前已发布版本的详细信息。请经常回来查看，我们通常每隔一个月发布一个新版本，除大量改进和错误修复外，还经常添加新功能。


Experimental Builds 用于对 TouchDesigner 中的新功能和概念进行 beta 测试。可能会遇到错误和稳定性问题。我们不建议将这些版本用于生产工作。随着 TouchDesigner 2025 正式版最近的发布，目前没有实验版，但请继续关注，我们正在准备一批新功能，很快会作为实验版 beta 发布。

下载

Download Official Builds - 当前和过往正式版的完整列表。2025 TouchDesigner 包含新的 Point Operator 族！

Download Experimental Builds - 所有实验版的存档。

许可

Non-Commercial 许可证可免费用于个人、教育或评估目的。若你或你的组织通过使用 TouchDesigner 的工作获得报酬，则必须拥有 Commercial 或 Pro 许可证。若你是经认证的教育机构的学生或教职员工，还可以申请 Educational License。许可证对比见 Licensing。

Updating 到最新版本需要其 'Update Date' 晚于该版本编译日期的密钥。可在 derivative.ca 的 MY ACCOUNT 页面的 MY LICENSES 部分查看许可证的 'Update Date'。若你的许可证 'Update Date' 在你想要使用的版本编译日期之前就已过期，请从商店购买 '1 Year of Updates'，以获得另一年的最新版本。

支持

请在我们的 Support Forum 中报告所有 TouchDesigner 问题或提问。 若你拥有 TouchDesigner Pro 许可证，则有权获得 Pro Support 并可直接联系我们；否则请使用论坛获取 TouchDesigner 支持。

若你有账户、许可或购买方面的问题，请使用此处 Contact Us 找到的相应联系方式给我们发邮件。

文档

  • 使用 wiki 高级搜索页搜索 Search 文档。
  • TouchDesigner Glossary 是了解 TouchDesigner 概念和架构的入口。
  • 浏览左侧导航栏中的 Categories。
  • 在启动 TouchDesigner 时的启动页上，按 TOUCHTIPS 可在等待时获取各种使用提示。
  • Operator Help pages - TouchDesigner 的所有节点类型。另请查看下面的 OP Snippets。
  • Python 页是 TouchDesigner 中所有 Python 相关内容的主要入口。Python Reference 是 wiki 中所有 Python 页面的字母索引。Python Classes and Modules 按主题分组。另请参阅 Introduction to Python Tutorial 以学习 TouchDesigner 中 Python 脚本的基础知识。
  • TouchDesigner 界面中的 Help -> Python Examples 会带你打开一个包含 100+ 示例的 PythonExamples.toe 文件。
  • Offline Help - 预先下载离线文档包，即可在未连接互联网时访问 wiki。

示例组件、工具和示例

  • OP Snippets - 超过 1000 个可运行的示例，可通过以下方式找到：(1) Help -> Operator Snippets 菜单，(2) 在任意网络中右键点击任意操作符，或 (3) 在 OP Create 菜单中右键点击任意操作符。打开后，可浏览各种 OP 类型，或尝试按 Rand 或 Newest。
  • Palette Browser - 在菜单 Dialogs -> Palette Library 中，或默认 TouchDesigner 的左窗格中。所有 Palette 组件帮助页的列表请参阅 Category:Palette。
  • Community Assets - 我们网站社区信息流中的用户贡献组件和资产。如果你想分享资产，请登录 Derivative，并在 My Account 下创建一个 ASSET 后在此上传。
  • Olib from alphamoonbase - 一个强烈推荐、不断增长的活跃免费 TouchDesigner 组件资源。
  • ask google - 只需输入 “touchdesigner how …” 看看会得到什么 - 例如 - touchdesigner how hand track to sound
