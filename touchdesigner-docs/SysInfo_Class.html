SysInfo 类

SysInfo 类描述当前系统信息。注意： 可通过 sysinfo 对象访问，该对象位于自动导入的 td module 中。 

# 返回可用的内存量
sysinfo.ram

成员

numCPUs → int (Read Only):

系统上的 CPU/核心数量。

ram → float (Read Only):

可用的 RAM 内存量。

numMonitors → int (Read Only):

显示器数量。

xres → int (Read Only):

系统当前显示器分辨率的宽度。

yres → int (Read Only):

系统当前显示器分辨率的高度。

tfs → str (Read Only):

TFS 目录的路径。

MIDIInputs → list[str] (Read Only):

所有 MIDI 输入设备名称的列表。

MIDIOutputs → list[str] (Read Only):

所有 MIDI 输出设备名称的列表。

GPUName → str (Read Only):

所选 GPU 的名称。

GPUID → str (Read Only):

所选 GPU 的 UUID。

GPUPlatformID → str (Read Only):

所选 GPU 的操作系统标识符。

方法

没有该操作符专属的方法。
