Facet SOP

摘要

Facet SOP 可控制给定对象的分面平滑程度。它还可以合并点或表面法线。

Facet SOP 与 Divide SOP 一样，作为管线分阶段改变几何。因此 Compute Normals 出现了两次。例如，可以在把顶点（每个多边形的点）变为独立之前计算表面法线，从而得到平滑着色但点独立这一不寻常的结果，因为法线是在点仍然共享时计算的。

facetSOP_Class

参数 - 页

Group group - 如果存在输入组，在此字段中指定组名将使该 SOP 仅作用于指定的组。接受模式匹配，说明见 Pattern Matching。
Make Normals Unit Length unit - 勾选该选项会把法线长度归一化为一个单位。
Compute Normals prenml - 勾选该选项表示会计算表面法线。点在多边形之间共享的地方产生平滑着色，点不共享（独立）的地方产生分面边缘。若在此阶段计算法线，则基于输入的几何计算。
Unique Points unique - 使每个顶点都有独立的点。选择该选项后，所有顶点都会成为独立点，于是所有边都是硬边，没有平滑着色。
Consolidate cons - - Consolidate 通过把彼此靠近的许多点合并成一组较少的公共点，消除冗余。Consolidate 适合用于清理相邻多边形合并后可能出现的边。
  • No Consolidate none - 不合并。
  • Consolidate Points Slow points -
  • Consolidate Points Fast fpoints -
  • Consolidate Normals Slow normals -
  • Consolidate Normals Fast fnormals -
Distance dist - 距离小于该值的点和法线会被合并，或按 Consolidate 菜单中的设置对法线取平均。

通常这里应使用非常小的数值，例如 0.01。若值为 0.0，则点必须处于完全相同的位置（重合）才会被纳入合并/平均处理。

Remove Inline Points inline - 移除与其相邻点共线的点。
Distance inlinedist - 当上面的参数为 On 时，设置移除共线点的距离阈值。
Orient Polygons orientpolys - 调整所有多边形的方向，使其绕向一致。
Cusp Polygons cusp - 多数情况下，你希望一些多边形平滑着色，另一些则分面。通常以较小角度相接的多边形应平滑着色，以较锐角度相接的多边形边应分面。
Cusp Angle angle - Cusp 处理让你指定边开始分面的阈值角度。常用的典型值是 20。
Remove Degenerate remove - 有时（不常见）几何会出问题，存在一些悬着、没被使用的点，或存在没有意义的多边形。该选项会检查这些情况并将其移除。
Compute Normals postnml - 同样，可以在合并或 cusp 阶段之后计算法线。若设置了 Cusp 或 Consolidate 选项，应勾选此项。

操作符输入

  • Input 0: -

Info CHOP 通道

Facet SOP 的附加信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
