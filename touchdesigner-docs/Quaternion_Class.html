Quaternion 类

保存一个 Quaternion 对象，可用于以多种方式操控旋转。

注意： tdu.___ 与 TDU.___ 可以互换使用。通常 TDU.___ 用于表示类，而 tdu.___ 用于实例化函数。

可以用几种不同的方式来描述初始旋转，从而构建四元数：

# 由欧拉角构建，rx、ry、rz 以度为单位
q = tdu.Quaternion(30, 5, -5)
q = tdu.Quaternion([30, 5, -5])
# 由一个角度和一个旋转轴构建
q = tdu.Quaternion(30, tdu.Vector(0, 1, 0))
# 由两个向量构建，从第一个向量旋转到
second vector
q = tdu.Quaternion(tdu.Vector(1, 0, 0), tdu.Vector(0, 1, 0))
# 由一组 4 个四元数值构建
q = tdu.Quaternion(x, y, z, w)
q = tdu.Quaternion([x, y, z, w])
# 由矩阵构建
q = tdu.Quaternion(tdu.Matrix())
# 由四元数构建
q = tdu.Quaternion(tdu.Quaternion())

四元数可以像简单的 Python 列表那样使用：

print(q[1])		# 等同于 q.y
q[2] = 0		# 等同于 q.z

另请参阅 Transform CHOP，它以 CHOP 通道集合的形式接收、操控并输出四元数。

实例化器

TDU.Quaternion(*args)→ TDU.Quaternion:

以下参数形式是有效的实例化方式：

  • tdu.Quaternion() - (0, 0, 0, 1)
  • tdu.Quaternion(quaternion : TDU.Quaternion) - 复制参数中的四元数
  • tdu.Quaternion(rx : float, ry : float, rz : float) - 从以度为单位的 Euler 角
  • tdu.Quaternion(rot : float, axis: TDU.Vector) - 从旋转角度和旋转轴
  • tdu.Quaternion(v1 : TDU.Vector, v2: TDU.Vector) - 从 v1 旋转到 v2
  • tdu.Quaternion(x : float, y : float, z : float, w : float) - 从四元数值
  • tdu.Quaternion(xyzw : list) - 从列表中的四元数值
  • tdu.Quaternion(matrix : TDU.Matrix) - 从矩阵

成员

x → float :

获取或设置四元数的 x 分量。

y → float :

获取或设置四元数的 y 分量。

z → float :

获取或设置四元数的 z 分量。

w → float :

获取或设置四元数的 w 分量。

方法

lerp(q2, factor)→ TDU.Quaternion:

返回该四元数与另一四元数按插值因子进行线性插值的结果。

四元数参数可以是任何能推导出四元数的对象，即 (x,y,z,w)、Matrix 等。 插值因子必须在 0 到 1 之间。

q3 = q.lerp(q2, factor)

length()→ float:

返回四元数的长度。

l = q.length()

cross(q2)→ TDU.Vector:

返回该四元数与参数的叉积。

四元数参数可以是任何能推导出四元数的对象，即 (x,y,z,w)、Matrix 等。

l = q.cross(q2)

rotate(vec)→ TDU.Vector:

使用当前四元数旋转一个向量。返回新的向量。

v2 = q.rotate(v1)

slerp(q2, factor)→ TDU.Quaternion:

返回该四元数与另一四元数按插值因子进行球面插值的结果。

四元数参数可以是任何能推导出四元数的对象，即 (x,y,z,w)、Matrix 等。

q3 = q.slerp(q2, factor)

eulerAngles(order='xyz')→ tuple:

从当前四元数和旋转顺序返回以度为单位的 Euler 角元组（即 pitch 为 x、yaw 为 y、roll 为 z）。'order' 参数可设为任何有效的旋转顺序，默认为 'xyz'。

r = q.eulerAngles(order='xyz')

fromEuler(order='xyz')→ tuple:

从以度为单位的 Euler 角（3 个输入参数，即 pitch 为 x、yaw 为 y、roll 为 z）返回并设置当前四元数。'order' 参数可设为任何有效的旋转顺序，默认为 'xyz'。

r = q.fromEuler(order='xyz')

axis()→ TDU.Vector:

返回四元数的旋转轴向量。

v = q.axis()

dot(q2)→ float:

返回该四元数与参数的点积。

四元数参数可以是任何能推导出四元数的对象，即 (x,y,z,w)、Matrix 等。

l = q.dot(q2)

exp()→ TDU.Quaternion:

返回该四元数的指数，作为新的四元数。

q2 = q.exp()

copy()→ TDU.Quaternion:

创建该四元数的副本，其值彼此独立。

log()→ TDU.Quaternion:

返回当前四元数的自然对数，作为新的四元数。

l = q.log()

inverse()→ None:

原地反转该四元数。

q.inverse()

angle()→ float:

返回四元数的旋转角度（以度为单位）。

a = q.angle()

特殊函数

Quaternion *= Quaternion→ TDU.Quaternion:

将一个四元数的旋转应用到另一个四元数。

# 把 q2 的旋转应用到 q1
q1 *= q2
