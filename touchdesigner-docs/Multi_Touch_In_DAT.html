Multi Touch In DAT

摘要

Multi Touch In DAT 用于接收来自 Windows 标准多点触控 API 的消息和事件。它会捕获所有消息，每条新消息都会改变其输出的表格。当有消息加入 DAT 时，可以调用任何脚本指向该新消息。Multi Touch In DAT 可以送给 Render Pick DAT，也可以与 Panel Component 和 Web Render TOP 中的 interactTouch 方法配合使用。macOS 不支持 Multi Touch DAT。

它可以输出两种表格格式之一：(1) 原始事件，作为 FIFO（先进先出）列表；(2) ID 表，即把事件处理成更实用的每指一行表格。

原始事件格式会创建一个 FIFO 类型的 DAT（另请参见 FIFO DAT），每个多点触控事件在表格底部添加一行，同时删除顶部的一行。

注意：要用通过 Windows 事件流发送事件的多点触控屏操作面板控件，多点触控无需 DAT 即可工作。当需要在同一个面板上使用多根手指时（例如在显示 3D 渲染的容器中选取对象），才需要使用 DAT。

ID 表格式包含以下列：

  • id - 每次按下手指，id 加 1
  • sn - 每次按下手指的累计计数。
  • select - 为 1 时表示该行对应的手指处于按下状态。
  • downf - 手指按下发生时的绝对帧号。
  • upf - 手指按下结束时的绝对帧号
  • x、y - 位置，以水平和垂直方向的像素为单位。NOTE：x 和 y 的值以屏幕像素表示，而不是面板宽高像素。例如，如果面板在另一个面板、窗口或网络查看器中被缩放，面板右上角的位置会不同。最好使用 u 和 v，再按面板的 Width 和 Height 缩放。
  • u、v - 位置，在水平和垂直方向上为 0 到 1
  • downu、downv - 触摸首次发生时的位置，在水平和垂直方向上为 0 到 1（即初始按下位置）。

contactx、contacty - 接触区域的宽度。 contactu、contactv - 接触区域的高度。

    • monitor - 显示器编号，从 0 开始
  • clicktime - 与 downf 类似，以秒为单位
  • elapsedtime - 手指已按下的秒数。
  • changedtime - 自手指按下以来，最近一次 u 或 v 值变化的时间。
  • dclick - 发生了双击
  • aux - 用户通过 PanelCOMP_Class 方法 interactTouch() 提供的数据。当事件由鼠标通过 Include Mouse 选项触发时，aux 将包含所用的鼠标按键（1 为左键、2 为中键、4 为右键，可按位测试）。

你可以使用附加的回调 DAT（名为 mtouchin1_callbacks）来响应多点触控事件。这适用于不需要 Render Pick DAT 的 2D 界面。

请参见 Tools 下 Palette 中的 Palette:multiTouch 示例。

参数 - Multi Touch In 页

Active active - Active 为 On 时注册事件。
Output outputtype - 设置输出在表格中的显示方式。
  • Raw Events log - 事件按先进先出（FIFO）顺序添加到表格。
  • ID Table changes - 事件在表格中按每指一行处理。
Panel panel - 要从中捕获触摸事件的 Panel Component。
Relative IDs relativeid - 重新排列触摸 id，只统计指定面板内的触摸。
Relative Position relativepos - 相对于指定面板左下角输出位置和归一化坐标。
Occlude Panels by Hierarchy occlusion - 只有指定面板的子级才会收到多点触控事件。父级和同级面板上的触摸会被忽略。
Occlude Panels by Depth Layer occbydepth - 启用按 Panel Depth Layer 过滤多点触控事件。
Occlude Panels Above Depth occdepthlayer - Depth Layer 大于此值的面板发出的多点触控事件将被忽略。
Include Mouse mouse - 开启时，鼠标点击会添加一个触摸事件。该事件始终与第一次触摸共享 ID 1。同时使用鼠标和多点触控可能会导致意外行为。
Position Threshold posthresh - 如果手指移动距离小于此单位数，则不会添加新消息。单位由输入设备决定，不一定是其关联屏幕的分辨率。
Contact Threshold contactthresh - 某些触摸设备具有按压的宽度和高度，表示压力或手指接触面积。这是最小阈值，低于它不会识别任何事件。
Min Rows Displayed minrows - 表格中始终显示的最少行数。
Double Click (secs) doubleclickthresh - 两次点击之间被识别为「双击」的最大允许时间。

参数 - Received Messages 页

Callbacks DAT callbacks - 包含回调的 DAT 的路径。
Execute from executeloc - 决定脚本的运行位置。
  • Current Node current - 脚本从当前节点位置执行（例如 'cc' 所指的位置）。
  • Callbacks DAT callbacks - 脚本从上面指定的 Callbacks DAT 所在位置执行。
  • Specified Operator op - 脚本从下方 Component 参数指定的组件执行。
From Operator fromop - 当 Execute From 参数设为 Specified Operator 时，脚本将从该路径执行。
Clamp Output clamp - 该 DAT 默认限制为 100 条消息，但使用 Clamp Output 可以设为任意值，包括无限制。
Maximum Lines maxlines - 限制消息数量，较旧的消息会先从列表中移除。
Clear Output clear - 删除除标题外的所有行。要用脚本命令清空，示例如下：opparm -c /serial1 clear

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

Multi Touch In DAT 的额外信息可以通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
