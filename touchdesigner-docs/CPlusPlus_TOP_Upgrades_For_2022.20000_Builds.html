C++ TOP 升级（2022.20000 版）

由于改用 Vulkan，针对 2021.30000 及更早版本头文件编译的 CPlusPlus TOP 无法在 2022.20000 及之后的版本中工作。本页介绍为针对较新头文件编译代码所需做出的必要更改。

变更

  • getOutputFormat() 已被移除。你需要在 execute() 中指定输出格式：CUDA 通过 TOP_CUDAOutputInfo，CPU 流程通过 TOP_UploadInfo。这样提供了更大的灵活性。
  • 像素格式在 OP_TOPInputDownloadOptions::pixelFormat 中设置，取代了 OP_TOPInputDownloadOptions::cpuMemPixelType
  • TOP_Context 指针不再通过 execute() 传递。要访问它，它仍会在 CreateTOPInstance() 中传入，你可以在实例化时将其保存到 TOP 类中。该上下文可用于创建和操作 TOP_Buffer、执行 CUDA 操作，或配合 python 回调。
  • CPU 流程的具体事项：
    • OP_Inputs::getTOPDataInCPUMemory() 已被移除。要从输入 TOP 下载纹理，请使用 OP_TOPInput::downloadTexture()，并通过 OP_TOPInputDownloadOptions 指定下载选项。
    • OP_TOPInputDownloadType 已被移除，延迟下载帧或立即下载帧的选择必须手动完成。将下载结果 OP_TOPDownloadResult 保存为 TOP 类的成员，然后当你想阻塞线程等待结果时，对它调用 getData()。
    • TOP_OutputFormatSpecs 已被移除。请使用 TOP_Output 和 TOP_UploadInfo。TOP_UploadInfo 保存要输出的纹理格式。TOP_Output 包含通过 TOP_Context::createOutputBuffer() 创建缓冲区、通过 TOP_Output::uploadBuffer() 将纹理上传到 GPU 的方法，功能多得多。
  • 要使用 CUDA 流程：
    • 在操作符类中保存 CUDA 流对象 cudaStream_t。通过 cudaStreamCreate() 实例化，通过 cudaStreamDestroy() 销毁
    • 要访问输入数据，先填充一个 OP_CUDAAcquireInfo 对象，然后通过 OP_TOPInput::getCUDAArray() 将输入取到 OP_CUDAArrayInfo* inputArray 中。注意，在调用 beginCUDAOperations() 之前，获取到的 inputArray->cudaArray 为 nullptr，后文会详细说明。
    • 要回传 CUDA 输出，先填充一个 TOP_CUDAOutputInfo 对象，然后调用 TOP_Output::createCUDAArray() 创建 OP_CUDAArrayInfo* outputInfo，用于保存输出 cudaArray。同样，在调用 beginCUDAOperations() 之前 outputInfo->cudaArray 会一直为 null。
    • 只有在调用 TOP_Context::beginCUDAOperations() 之后才能开始 CUDA 操作。调用此方法后，相关的输入和输出 OP_CUDAArrayInfo::cudaArray 对象才会获得有效地址。操作完成后，调用 TOP_Context::endCUDAOperations()。
    • 此外，在 beginCUDAOperations() 和 endCUDAOperations() 之间无法访问你的 OP_Inputs 输入对象，因此要提前调用 OP_Inputs 方法获取数值。

要更好地理解所有这些变更，请参阅 Samples\CPlusPlus\ 中的示例
