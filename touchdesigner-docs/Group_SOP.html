Group SOP

摘要

Group SOP 按各种条件生成点组或图元组，并让你对这些组进行操作。元素可以出现在多个组中。SOP Editor 的许多地方都使用组来指定你希望某个 SOP 作用于输入几何的哪些部分。

你也可以创建有序组。为此，勾选 Ordered 按钮。

groupSOP_Class

参数 - Create 页

Use Number usenumber - 允许按编号选择实体分组。当 Enable 按钮处于激活状态时，选择选项变为可用，可用于选择实体。可用的字段列在下面。
Create Ordered ordered - 选中后，组中的元素按被选择的顺序遍历；否则按创建顺序遍历。
Operation groupop - 勾选 Number Enable 按钮后，此选项按定义的模式（Pattern）或范围（Range）对实体分组。
  • Group by Pattern grppattern - 在下面的 Pattern 字段中选择一个模式。
  • Group by Range grprange - 使用下面的 Start/End 和 Select_of_ 字段选择一个范围。
  • Group by Expression grpexpression - 使用下面的 Filter Expression 字段选择一个范围。
Pattern pattern - 当 Operation 设为 Group by Pattern 时激活。在此字段中输入要选择的图元范围。所需语法为「S.P」，其中 S 是父曲面的索引，P 是该曲面上的轮廓索引。你可以在列表中把图元与轮廓混合。混合组会自动排序。

例如：

  • 0.4 2 4 2.5 3.7 选择三个轮廓和两个图元，
  • 0-100:2 选择 0 到 100 中每隔一个的数字，
  • 0-10:2,3 每三个中选择两个，
  • 0.0-6 选择图元 0 上的六个轮廓，
  • 0.* 选择图元 0 上的所有轮廓，
  • !4 选择除第四个之外的每个图元或点，
  • 9-0 选择前十个（若打开 ordered 标记则反向），
  • !0.* 选择除图元 0 上的轮廓之外的所有轮廓，
  • * 选择所有图元或点，不含轮廓。

详情参见 Pattern Matching。

Transfer Selection to Pattern transfer - 这让你可以通过 Select 状态在 Viewport 中选择点/图元，以直观地定义点/图元的范围。点击此按钮会把所选择的点/图元以紧凑范围的形式传送到 Pattern 字段（例如 1-23 40 67-100）。这样就无需手动输入点或图元编号。

注意： 点与图元的选择可以直接转储到 Group 字段中，无需使用 Group SOP。做法是在 Viewport 中用 Select 状态选择点或图元。然后，在你想要计算的 SOP 的 Group 字段旁的弹出 N 菜单中，会显示输入 SOP 中的选择（例如「grid1's Primitive Selection」）。范围会自动紧凑化。

Start / End range - 当 Operation 设为 Group by Range 时激活。选择图元/点编号选取的起始和结束。
  • rangestart -
  • rangeend -
Select _ of _ select - - 当 Operation 设为 Group by Range 时激活。在上述 Start/End 范围内，每 m 个实体中选取第 n 个。

For Example: 输入 1 和 2 表示每 2 个实体中选择 1 个。

  • select1 -
  • select2 -
Filter Expression filter - 提供的 Filter Expression 会对每个点/图元求值。凡是为真的地方，就把该实体加入。点和图元的所有局部变量都可以使用，但只有在创建正确类型的组时才能访问。
Use Bounds usebounds - 此选项用于基于包围体选择实体：Bounding Box 或 Bounding Sphere。处于激活状态时，选择选项变为可用，可用于选择实体。可用的字段列在下面。包围体可以在视口中作为辅助几何看到。
Bounding Type boundtype - - 选择要使用的包围体类型。
  • Bounding Box usebbox - 选择盒子内的实体。
  • Bounding Sphere usebsphere - 选择球体内的实体。
  • Bounding Object (points only) usebobject - 选择对象内的点。请确保该对象由格式良好的多边形组成。如果使用不规则网格，先用 Convert SOP 转换为多边形，然后用 Divide SOP 把凸面分割到 3 边。
Size size - Bounding Box 或 Bounding Sphere 在 X、Y、Z 上的尺寸。
  • X sizex -
  • Y sizey -
  • Z sizez -
Center t - 包围体中心的 X、Y、Z 坐标。
  • X tx -
  • Y ty -
  • Z tz -
Use Normal usenormal - 此选项用于基于实体法线的角度选择实体。处于激活状态时，选择选项变为可用，可用于选择实体。可用的字段列在下面。

主轴以及相对所定义轴的展开角共同定义一个角度范围。如果任何实体法线位于此范围内，则选中相应的实体。

For Example: 如果你想在多边形山地地形的 XZ 轴上选择非常陡峭的多边形。你会把 Direction 设为 0, 1, 0，把展开角设为约 75。这会选中所有法线从平躺到相当倾斜的多边形。这样你就把所有从平躺到与轴成 75 度角的多边形分到一组，剩下的就是所有 76 度或更大的多边形。

Direction dir - - 默认值 0, 1, 0 生成一个沿 Y 轴笔直向上的法线向量，它垂直于 XZ 平面，该平面成为主轴。1, 0, 0 把法线指向正 X，得到一个垂直于 YZ 平面的法线轴。可以通过输入数值（1, 1, 0 得到 45 度角的平面）或交互式地使用方向向量插孔，把平面定位在某个角度。应使用 0 到 1 之间的值。
  • X dirx -
  • Y diry -
  • Z dirz -
Spread Angle angle - 此字段中输入的值会生成相对主轴的偏移角。可以把它想象成一个圆锥，圆锥底面的半径由 Spread Angle 决定，圆锥的轴由 Direction 轴决定。在视口中查看图元法线，可以看到凡法线角度落在该圆锥所定义角度范围内的图元都会被选中并分组。
Backface from camera - 此菜单用于选择一个对象。通常会选择摄像机对象。从指定对象观看时背面朝向的图元会被分组或选取。
Use Edges useedges - 让你按边对图元分组。
Edge Angle doangle - 启用 Edge Angle 参数。
Edge Angle edgeangle - 指定用于分组的边之间的角度。仅适用于图元组。
Edge Depth dodepth - 启用 Edge Depth 参数。
Edge Depth edgestep - 输入边的深度（仅用于点组）。
Point Number point - 输入具体的点编号（仅用于点组）。
Unshared Edges unshared - 在选择点时，此选项选择多边形网格中位于边界上的点（即不共享的点）加入组，并对它们排序。除了多边形网格，此选项还会查找 geo Hull 和开放面的边界。
Create Boundary Groups boundarygroups - 使用 Unshared Edges 参数选择点时，此选项变为可用。启用后，会创建形如 ⟨name⟩__⟨n⟩ 的新组（两个下划线），其中 ⟨name⟩ 是 Create 页中指定的 Group Name。编号 ⟨n⟩ 从零开始，随着创建更多组而递增。

这些组包含曲面上每条边界上的点。例如，如果你有一个中间带洞的网格，会创建两个新的点组——一个包含外边界的点，一个包含洞的点。这些新点组也是有序的。

参数 - Combine 页

这一页参数让你通过不同操作合并组，从而修改某个输入组中的图元或点数量。

Group = grpequal - 指定你希望编辑成员的组。这可以是某个输入组，也可以是在此 SOP 中创建的新组（由 Group 页上的 Group Name 参数指定）。

Info CHOP 通道

Group SOP 的附加信息可以通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
