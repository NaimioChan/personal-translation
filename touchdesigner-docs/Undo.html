撤销

撤销和重做操作以两种方式支持。大部分支持针对设计模式（在 TouchDesigner 中编辑网络），在 perform 模式中支持有限。

在编辑网络的设计模式下，创建或删除节点、更改节点参数等用户交互可以通过 Edit 菜单中的 Undo 或 Ctrl-Z（macOS 为 Cmd-Z）撤销。Edit 菜单中的 Redo 或 Ctrl-Y（macOS 为 Cmd-Shift-Z）将重做任何撤销。

脚本和 Textport 中的撤销

默认情况下，脚本不会创建撤销动作。要在脚本中创建撤销步骤，请使用 Undo Class。

支持的操作

  • 节点操作 - 创建、删除、放置、标记更改、连接与断开连接、重命名。
  • 通过用户交互或脚本更改节点参数。（包括通过选择节点进行多节点参数更改）
  • 复制和粘贴 - 包括复制节点和文本编辑
  • 通过 DAT 编辑器或外部编辑器进行 DAT 文本和表格编辑。
  • 关键帧动画编辑。

不支持的操作

  • 几何编辑中的撤销尚待支持。
  • 更改节点选择。
  • Text COMP 在编辑时具有多步本地撤销系统，并会为最终结果创建一个撤销步骤。
  • Field COMP 只使用本地单步撤销，不绑定到主撤销/重做队列。此组件已弃用，请改用 Text COMP。

Perform 模式

perform 模式中的撤销仅对在 Editor 中有效的项目有效。perform 模式中的大多数内容若想创建撤销步骤都需要脚本。信息见 Undo Class。
