Blob Track CHOP

摘要

Blob Track CHOP 可用于跟踪 2D 点数据中的斑块。

输入数据应有两个名为 tx 和 ty 的通道，以笛卡尔坐标描述 2D 点。参见 OP Snippets 示例。

输入扫描的良好来源是 Hokuyo CHOP（笛卡尔坐标模式）和 Leuze ROD4 CHOP。这些设备自然以设备为圆心输出径向扫描，每个点表示 (angle, distance)。以笛卡尔坐标模式输出每个扫描点，可为每个点给出 (x,y)，这正是 Blob Track CHOP 所需的格式。

但两个通道中的任何一组 (x,y) 点都会被分析。跟踪器会寻找彼此靠近的连续点，并处理一个斑块从另一个斑块后方经过的情况：在可指定的时间内，被遮挡的斑块会获得线性运动，之后才从输出的斑块集合中移除。

另请参见 Blob Track TOP

参数 - Tracker 页

Active active - 开启时，CHOP 从输入接收信息。关闭时，不进行任何处理。已有的斑块会保留。
Search Mode searchmode - - 控制如何在所有点之间搜索斑块。
  • All all - 将所有点相互比较以寻找斑块。此模式较慢，但对于在 CHOP 中点的顺序随机的数据更稳健。
  • Consecutive Points consecutive - 仅将点与 CHOP 数据中相邻采样内的点比较以寻找斑块。这快得多，但数据的设置必须使空间中彼此靠近的点在 CHOP 采样中也彼此相邻。来自 Hokuyo CHOP 和 Leuze ROD4 CHOP 等设备的数据就是这种格式。
Max Blobs maxblobs - 可跟踪的最大斑块数量。
Max Point Distance in Blob maxpointdistance - 如果输入中两个被测量的点之间的距离等于或小于此值，就视为属于同一个斑块。
Max Blob Movement maxblobmovement - 控制斑块在连续帧之间最多可移动多远仍被视为同一个「斑块」。
Area of Interest areaofinterest - - 限制跟踪斑块的区域。感兴趣区域之外的点会被忽略。
  • Off off - 无限制，在整个扫描区域跟踪斑块。
  • Rectangle rectangle - 仅在指定的矩形内跟踪斑块。
  • Circle circle - 仅在指定的圆形（或椭圆）内跟踪斑块。
Center center - - 感兴趣区域的中心。
  • Center centerx -
  • Center centery -
Size size - - 感兴趣区域的大小。
  • Size sizew -
  • Size sizeh -
Rotate rotate - 旋转感兴趣区域。
Allow Movement Outside Area allowmovementoutside - 开启时，在感兴趣区域内检测到的斑块可以移出该区域并仍被跟踪。关闭时，移出感兴趣区域的斑块将停止跟踪。

参数 - Blobs 页

Output Centroid outputcentroid - 将检测到的斑块的质心包含在输出通道中。
Output Velocity outputvelocity - 将检测到的斑块的速度包含在输出通道中。
Min Points per Blob minblobpoints - 构成一个斑块所需彼此靠近的最少点数。用于帮助过滤误检。
Blob Init Time (s) blobinittime - 斑块需要被检测到多长时间才被视为可信。用于帮助过滤误检。只有被检测到至少这么长时间的斑块才会输出。
Lost Blob Timeout (s) lostblobtimeout - 已丢失的斑块从输出中移除前的等待时间。
Blob Movement Prediction Type predicttype - - 启用预测后，上一帧的斑块会先预测新位置，再与当前帧匹配。
  • Off off - 斑块与上一帧的斑块位置进行匹配。
  • Simple Forward Predict simple - 预测使用恒定速度假设；斑块按上一帧移动的距离移动。
  • Kalman Filter Predict kalman - 预测使用 kalman filtering，以恒定速度模型将斑块从上一帧向前推进。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Blob Track CHOP 的额外信息可通过 Info CHOP 访问。

Blob Track CHOP 的特定 Info 通道

  • num_blobs -

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
