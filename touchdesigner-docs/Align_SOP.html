Align SOP

摘要

Align SOP 通过沿任意轴心点平移或旋转每个图元，将一组图元相互对齐或对齐到辅助输入。

Left and Right Primitives - 下文所说的「左」和「右」取决于上下文。如果使用了辅助输入，它始终是右侧图元，而主输入的几何体都是左侧图元。如果只使用一个输入，那么在对齐的每一对中都有一个左侧和一个右侧图元。这意味着相对于相邻图元，某个图元既可以作为左侧也可以作为右侧。

参数 - Align 页

Bias bias - 确定哪个图元保持不受影响：0 为 Left，1 为 Right。
Left UV leftuv - - 每个「left」图元的轴心位置。
  • U leftuv1 -
  • V leftuv2 -
Right UV rightuv - - 每个「right」图元的轴心位置。
  • U rightuv1 -
  • V rightuv2 -
Right UV End rightuvend - - 如果使用了辅助输入，此位置指定对齐的端点。左侧图元随后会在 Right UV 和 Right UV End 之间均匀分布。
  • U rightuvend1 -
  • V rightuvend2 -
Individual Alignment individual - 使输入的每个图元都参与对齐。未勾选时，只有第一个图元被对齐，其余都相对于它放置，从而保持左侧图元的空间布局。
Translate dotrans - 启用后，对齐时通过将左侧 UV 位置平移到右侧 UV 位置来平移图元。
Rotate dorotate - 启用后，对齐时通过将左侧 UV 切线（在左侧 UV 位置）对齐到右侧 UV 切线（在右侧 UV 位置）来旋转图元。

参数 - Transform 页

Transform Order xord - - 设置各项变换的整体 Transform Order 和 Rotation Order。变换与旋转顺序决定变换发生的先后次序。根据顺序不同，使用完全相同的数值可以得到不同结果。

Info CHOP 通道

Align SOP 的额外信息可通过 Info CHOP 查看。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
