Deform SOP

摘要

Deform SOP 接收几何以及点权重（由 Capture SOP 分配），并在 Capture Region 移动时对几何进行变形。这样你就可以在 Capture SOP 与 Deform SOP 之间以程序化方式灵活修改几何。

另请参阅 Deforming Geometry (Skinning)。

deformSOP_Class

参数 - 页

Group group - 可选，要变形的点组和/或图元组。接受模式，如 Pattern Matching 中所述。
Delete Capture Attributes delcaptatr - 点捕获属性会显著增加几何的内存占用。此选项会在变形几何之后删除点捕获属性，以便为后续 SOP 节省内存。
Delete Point Colors delcolatr - 你可能会使用 Capture SOP 中的点着色来辅助捕获过程。如果 Deform SOP 之后不再需要这些点颜色，可以打开此参数以删除它们。
Deform Normals donormal - 打开此项可在几何变形时同时变形法线。
Skeleton Root Path skelrootpath - 指定骨架根部的路径。

操作符输入

  • Input 0: -

Info CHOP 通道

Deform SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
