SACN

sACN（Streaming Architecture for Control Networks）是一种基于 UDP、运行在 IP 网络上的 DMX 协议。 与通过 XLR 线缆传输、最多支持 256 个宇宙的 DMX 不同，sACN 最多可支持 64,00 个宇宙。

sACN 可在 MultiCast 模式下运行，因此能减少瓶颈。 此外，IP 地址可以各不相同，只要它们订阅的是可访问的主机 IP 和端口。

sACN 在 Artistic License Integration sACN 页面中有更完整的说明。

sACN 在 DMX Out CHOP 和 DMX In CHOP 中受支持。
