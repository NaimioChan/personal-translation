Substitute DAT

摘要

Substitute DAT 使用模式匹配和替换字符串来修改输入 DAT 的单元格。它输出行数和列数相同的表格。

见下方示例。另外，你可以用第二输入提供一张替换字符串表，第一列是「before」字符串，第二列是「after」字符串。

See also：Python 的 .replace() [1]，这是可以应用于任何字符串的方法。你可以在 Evaluate DAT 或 Script DAT 中这样做。

参数 - Substitute 页

Before before - 要替换的搜索词。可以使用以下特殊字符：
  • * - 匹配任意数量的字符
  • ? - 匹配单个字符
  • [] - 匹配方括号内定义的任意字符

要精确匹配这些特殊字符，请在该特殊字符前加反斜杠（\）。

After after - 替换词。它会替换搜索词中匹配到的所有内容。允许使用空格。
Match match - 指定匹配位置：
  • Anywhere anywhere - 匹配字符串的任意部分。
  • Exact exact - 字符串必须与搜索词完全匹配。
  • At Start start - 把搜索词匹配到字符串开头。
  • At End end - 把搜索词匹配到字符串结尾。
Case Sensitive case - 在搜索词中区分大小写。
Expand the From String expand - 展开 From 字符串中的变量和反引号。
Expand the To String expandto - 展开 To 字符串中的变量和反引号。
First Match Only first - 只替换匹配字符串的第一个实例。

参数 - Scope 页

Exclude First Row xfirstrow - 强制忽略第一行，即使 Select Rows 设置未指定它。
Exclude First Col xfirstcol - 强制忽略第一列，即使 Select Cols 设置未指定它。
Select Rows extractrows - 此参数让你选择指定作用范围行的不同方式。
  • All all - 所有行都在范围内。
  • by Name byname - 使用 Start Row Name 和 End Row Name 参数划定行范围。
  • by Index byindex - 使用 Start Row Index 和 End Row Index 参数划定行范围。
  • by Start Name, End Index bynameindex - 使用 Start Row Name 和 End Row Index 参数划定行范围。
  • by Start Index, End Name byindexname - 使用 Start Row Index 和 End Row Name 参数划定行范围。
  • by Values bynames - 通过显式指定行值来划定行范围。
  • by Condition byexpr - 通过为 from 列求值的表达式来划定行范围。
Start Row Name rownamestart - 指定范围起始的行名。
Start Row Index rowindexstart - 指定范围起始的行索引。
End Row Name rownameend - 指定范围结束的行名。
End Row Index rowindexend - 指定范围结束的行索引。
Row Select Values rownames - 指定你真正想纳入范围的行名。可以使用模式匹配，例如 row[1-4] 会纳入名为 row1 到 row4 的所有行。
Row Select Condition rowexpr - 指定一个将被计算的表达式。如果表达式结果为 true，则选择该行。

展开该参数，你会看到它位于 expression mode 中。

默认情况下，Python 表达式为 re.match('.*',me.inputCell.val) != None。'.*' 表示多次匹配任意字符，因此该表达式匹配所有值。如果要匹配父级操作符名后跟任意数字，可以使用 parent().name+'[0-9]*'，其中 '[0-9]*' 匹配任意数字字符串。'.*'+parent().name+'.*' 会匹配包含该操作符父级名称的任意单元格。关于如何使用 Python Regular Expression 模块的其他信息，可查阅 Regular Expression Operations。

From Column fromcol - 按值选择行时，此参数选择在把单元格值与 Selected Row Values 匹配以确定作用范围行时使用哪一列。
Select Cols extractcols - 此参数让你选择指定作用范围列的不同方式。
  • All all - 所有列都在范围内。
  • by Name byname - 使用 Start Col Name 和 End Col Name 参数划定列范围。
  • by Index byindex - 使用 Start Col Index 和 End Col Index 参数划定列范围。
  • by Start Name, End Index bynameindex - 使用 Start Col Name 和 End Col Index 参数划定列范围。
  • by Start Index, End Name byindexname - 使用 Start Col Index 和 End Col Name 参数划定列范围。
  • by Values bynames - 通过显式指定列值来划定列范围。
  • by Condition byexpr - 通过为 from 行求值的表达式来划定列范围。
Start Col Name colnamestart - 指定范围起始的列名。
Start Col Index colindexstart - 指定范围起始的列索引。
End Col Name colnameend - 指定范围结束的列名。
End Col Index colindexend - 指定范围结束的列索引。
Col Select Values colnames - 指定你真正想纳入范围的列名。可以使用模式匹配，例如 colvalue[1-4] 会纳入名为 colvalue1 到 colvalue4 的所有列。
Col Select Condition colexpr - 指定一个将被求值的表达式。如果表达式结果为 true，该列就纳入范围。详见 Row Select Condition。
From Row fromrow - 按 Specified Names 划定列范围时，此参数选择在把单元格值与 Selected Col Values 匹配以确定作用范围列时使用哪一行。

Word Wrap wordwrap - - 为节点显示启用 Word Wrap。

操作符输入

  • Input 0: - 要处理的数据。
  • Input 1: - (optional) 一个 Table DAT，含 before 和 after 列，其中是用于替换第一输入内容的字符串。不必是整个单元格内容，也可以是任意部分字符串。

Info CHOP 通道

Substitute DAT 的额外信息可通过 Info CHOP 获取。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
