3D 纹理

3D Texture 是一种使用三个纹理坐标采样的纹理：u、v 和 w。三个坐标都归一化到 0-1 范围。理解 3D 纹理最简单的方式，是把它看成一组堆叠的 2D 纹理。3D 纹理的特殊之处在于，当 w 坐标位于两层之间时，会对相邻两层采样并混合。例如，如果 3D 纹理深度为 2（即 2 层，cache size 为 2），两层分别位于 w 坐标 0.25 和 0.75。若以 w 坐标 0.5 采样该纹理（或在 Texture Extend Mode 设为 repeat 时用 0.0），你会得到两层各占 50% 的混合。若以 w 值 0.3 采样，得到的主要是第 1 层，混有少量第 2 层。3D 纹理一次只会在 2 层之间混合。

注意，W 坐标 0 并不是第一个切片的坐标，而是第一个切片 50% 加最后一个切片 50%。要得到 100% 的第一个切片，需要的 W 坐标为（0.5 / NumberOfSlices）。

3D 纹理真正的威力在于它能在单次通道中混合多个层。在一次绘制中，你可以使用一个非常大的 3D 纹理（常常有 2048 层以上），如果你的几何上 w 值覆盖从 0 到 1 的整个范围，就能在单次通道中采样任意或全部层。如果改为手动采样许多 2D 纹理来实现，代价会高得多。这是因为 3D 纹理的显存排布方式让这种采样方式性能更好。

从 2025.30000+ 系列版本起，许多 TOP 现在可以把其运算应用到 3D Texture 上。该运算会应用到所有切片。

额外的 W 或 P 偏移信息

当 Texture 3D TOP 每帧采集一个新切片时（这是它的默认模式），它还会维护一个偏移，用来标明哪个切片是「最新」的。这一额外的偏移信息（在 Write a GLSL Material 文档中称为 POffset）使得某些使用 3D Texture 的地方能表现出不同的行为。理想情况下，3D Texture 中的第一个切片应当就是「最新」的切片（W 坐标接近 0）。但每帧把所有纹理层都挪动一遍代价太高。因此改为在采样 3D Texture 时，把维护的偏移加进 W 坐标。这样该坐标总是采样「最新」的切片，尽管最新切片在 3D Texture 中的位置每帧都在变。

材质（例如 Phong MAT）和 Time Machine TOP 会利用这一偏移信息。但在 Texture 3D TOP 之后处理该 3D Texture 的任何 TOP 都会导致这一信息丢失。
