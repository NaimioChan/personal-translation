用 CHOP 创作音频

简介

在 TouchDesigner 中，音频通过 CHOP 管理。CHOP 可以生成声音，也可以从外部来源把声音读入 TouchDesigner。音频可以生成、从音频文件播放、滤波、混合和录制。

在 CHOP 中获取音频的途径包括：来自文件、影片、麦克风或线路输入。这些在下一节中详细介绍。要听到 CHOP 的音频输出，请把音频发送到 Audio Device Out CHOP。

例如，Audio Oscillator CHOP 可以生成恒定频率的音频信号。Trigger CHOP 接收来自 TouchDesigner 的开关控制，并生成带延迟、起音、衰减、延音和释放过渡的音量包络，可用 Math CHOP 控制其响度并与音频 CHOP 相乘。Math CHOP 和 Audio Dynamics CHOP 充当混音器，Audio Para EQ CHOP 对音频频谱进行滤波。

音频快速上手

要快速得到音频，可以试试以下步骤：File:Audio with CHOPS ex.tox

  • 把一个默认的 LFO CHOP 连接到默认的 Audio Oscillator CHOP。
  • 把 Audio Oscillator CHOP 连接到 Audio Device Out CHOP。
  • 你应该会听到一个上升下降的音调。
  • 把 LFO CHOP 连接到一个新的 Audio Oscillator CHOP，并将该振荡器的 Base Frequency 设为 330。
  • 把两个振荡器连接到 Merge CHOP。把 Merge CHOP 连接到 Audio Device Out CHOP。你应该会在左、右声道各听到一个振荡器。

接下来用 Audio File In CHOP 作为音源，将它连接到 Audio Device Out CHOP。

加载音频

Audio File In CHOP - 在播放时从文件加载音频。这种流式方法占用内存很少，因为它只加载当时需要的音频采样，非常适合大型音频文件。创建的 CHOP 通道为 time-sliced。

Audio Movie CHOP - 从已加载到 Movie File In TOP 的影片中加载音轨。播放由 Movie File In TOP 控制。创建的 CHOP 通道为 time-sliced。

File In CHOP - 把整个音频文件加载到 CHOP 中。音频按音频文件的采样率加载到 CHOP。采样率越高，CHOP 加载音频占用的内存越多。创建的通道不是 time-sliced。完全加载到 CHOP 后，很容易在下游用其他 Filter CHOP 处理音频；拉伸、拼接、变调、音量等。在实时系统中使用大音频文件和高采样率时必须谨慎，因为这些操作的 CPU 占用非常高。

Audio Device In CHOP - 从连接到计算机的任何音频输入设备把音频流式传入 TouchDesigner。创建的 CHOP 通道为 time-sliced。

Audio Play CHOP - 直接把声音文件播放到音频输出设备。非常适合简单地触发声音。只播放单个文件，或从 DAT 列表中存储的文件中选择。也可以用 Tscript 的 audioplay 命令触发。音频不会继续沿 CHOP 网络向下传递。

擦洗控制

使用 Audio File In CHOP 时，至少可以通过 3 种方式定位或擦洗音频：

  • 必须先把 Audio File In 的 Play Mode 参数设为 Sequential。选择一个 Cue Point 并按下 Cue Pulse。
  • 必须先把 Audio File In 的 Play Mode 参数设为 Specify Index，然后使用 Index 参数。关闭 Repeat 参数，以避免不擦洗时音频发出嗡声。
  • 使用 Audio Movie CHOP 时，可以通过它所引用的 Movie File In TOP 来擦洗音频。影片播放被擦洗时，音频会随之变化。

使用 File In CHOP 时，可以通过在 File In CHOP 的帧范围内擦洗 TouchDesigner 的主 Timeline 来擦洗音频。

重复音频

使用 Audio File In CHOP 时，把 Repeat 参数设为 On。

使用 File In CHOP（它会静态加载整个音频文件）时，可以把 Extend Left 和 Extend Right 参数设为 Cycle。

Audio Play CHOPs 需要被反复触发才能重复音频。

TouchDesigner 音频输出音量

Audio Device Out CHOP 设置输出到扬声器的总电平。这会送到 Windows 的音量控制。

将音频输出到文件

可以使用 CHOP 上的 RMB 菜单输出任何 CHOP 中的音频。在菜单中选择 Save Data Channels，然后点击箭头按钮，即可看到输出文件可用的格式后缀，例如 .aif。可以用 VLC 或 QuickTime 或其他音频播放器播放文件来检查。

注意，该 CHOP 可能是 time-sliced，此时需要先把它录到 Record CHOP 或 Trail CHOP 中。

修改音频

  • Math CHOP - 增加/降低音量、混合声音、立体声转单声道，执行电平混音器的功能。
  • Audio Oscillator CHOP - 生成可听的音调与 LFO（低频振荡器）。
  • Constant CHOP - 为振荡器提供恒定音高控制。
  • LFO CHOP - 添加颤音或 LFO。
  • Noise CHOP - 生成白噪声。
  • Audio Band EQ CHOP - 图形均衡器。
  • Audio Para EQ CHOP - 滤波、回声、变调。
  • Audio Filter CHOP - 低通、高通、带通滤波。
  • Resample CHOP - 改变声音的采样率。
  • Trigger CHOP - 生成带延迟、起音、衰减、延音、释放的音量包络。
  • Timer CHOP - 把一个声音交叉溶解到另一个声音。
  • Lag CHOP - 生成滑音式的音高扫移。
  • Envelope CHOP - 跟踪声音的响度。

当你把整个文件读入 File In CHOP 来处理一段音频时：

  • Trim CHOP - 缩短音频。
  • Cycle CHOP - 使其重复。
  • Wave CHOP - 添加颤音或 LFO。
  • Shift CHOP - 重新调整声音的时间，简单回声、延迟。
  • Stretch CHOP - 让声音变慢或变快，但音高也会随之变化。
  • Copy CHOP - 用触发器沿时间轴复制声音。
  • Pulse CHOP - 为脉冲定时以作为音序器产生节奏。
  • Composite CHOP - 把一个声音叠在更长的声音上。
  • Lookup CHOP - 软限幅振幅等。

3D 音频

CHOP 可以接收来自 3D 场景的事件（通过 SOP to CHOP 或 Object CHOP 导入），并用这些事件触发声音、控制声音在 3D 空间中的位置。

3D 空间中的对象、粒子或点的位置可用于设置左右耳的分离度，也可用作混响控制，添加模拟声音远近的线索。

可以为画面外的对象生成音频，增加更多 3D 线索与真实感。
