Audio Device In CHOP

摘要

Audio Device In CHOP 使用 DirectSound/CoreAudio 或 ASIO 从任何连接的音频输入设备接收音频。它始终输出时间切片音频数据。

如果要将数据捕获到内存中，请使用 Trail CHOP 或 Record CHOP。 如果要录制到文件，请使用 Audio File Out CHOP 或 Movie File Out TOP。

只要音频设备的模数转换器能够处理恒定的非零电压，Audio Device In CHOP 就可以接收模拟控制电压（CVs）。

参数 - Audio Device In 页

Active active - 开启或关闭音频输入。
Driver driver - 在默认的 DirectSound/CoreAudio、ASIO 或原生设备支持的驱动之间选择。
  • DirectSound/CoreAudio default - 默认的 Windows 音频驱动（又称 WDM）或 macOS CoreAudio 驱动，取决于你的操作系统。
  • ASIO asio - 低延迟驱动，通常来自硬件制造商。
  • DataPath (RGBEASY) datapath - 原生支持从 DataPath 设备采集音频。
  • Blackmagic blackmagic - 原生支持从 Blackmagic Design 设备采集音频。
  • AJA aja - 原生支持从 AJA 设备采集音频。
Device device - 可用音频设备的菜单，用于从中接收输入。选择 default 会将音频设备设为 Windows Control Panel>Sounds and Audio Devices>Audio>Sound Recording 中所选的设备。
Error if Missing errormissing - 如果找不到指定的设备，该 CHOP 将报错。
Inputs inputs - 当 Driver 在 Windows 上设为 ASIO、在 macOS 上设为 CoreAudio 时，此参数可用于选择要使用的输入通道。
Format format - 当 Driver 设为 DirectSound 时，此项设置为 mono、stereo 或 multi-channel。同时决定创建的通道数：1（mono）或 2（立体声左和立体声右）；设为 multi-channel 时，则设置 Input 1 和 Input 2 参数页上启用的通道数。
  • Mono mono - 使用单个单声道通道。
  • Stereo stereo - 使用 2 个通道作为立体声左和右。
  • Multi-Channel multichannel - 使用 Input 1 和 Input 2 参数页上处于 On 状态的通道。
Rate rate - 音频输入采样率，以每秒采样数表示。
Buffer Length bufferlength - 输入缓冲区的大小，会影响延迟。缓冲区越大，引入的延迟越多。
Number of Channels numchan - 当 Driver 使用 Blackmagic 或 AJA 时，用此参数设置通道数。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Audio Device In CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
