Blob Track TOP

摘要

识别输入图像中的斑块并进行跟踪，返回 ID、位置和大小等信息。

NOTE: As of build 2025.32820 (May 06, 2026), you can now track an unlimited number of blobs with any license including the Non-Commercial version of TouchDesigner.

要获取 Blob Track TOP 的结果，请为其连接 Info DAT 或 Info CHOP。Info 会以像素为单位报告当前斑块的 ID、坐标和大小。每检测到一个新斑块，斑块 ID 就会增加。

它会将输入图像转换为单色（因为它基于单个颜色通道工作），但为了更好地准备图像，可在其前面接一个 Monochrome TOP，再接一个 Luma Level TOP，并调整 Black Level、Brightness 和 Gamma。

典型用法是将视频源（例如 Video Device In TOP）连接到 Blob Track TOP。

Tip: Reducing the resolution of the input image can greatly improve performance while still giving accurate tracking.

Blob Track TOP 使用 OpenCV 实现。

另请参见 Blob Track CHOP

用法

Blob Track TOP 有两种工作流程。

SimpleBlobDetector

SimpleBlobDetector 是 OpenCV 中的一种斑块检测算法。如果 only 的第一个输入已连接，就会自动使用此方法。SimpleBlobDetector 的优点是不需要已知背景即可检测斑块，但只返回斑块的位置和半径，这意味着所有斑块的矩形都会是正方形。SimpleBlobDetector 也可能相当慢，因此通常需要降低输入分辨率。一般来说，只有在背景未知时才应使用此方法。

Background Subtraction

如果连接了第二个输入，就会自动使用背景减法。背景减法的动态性较差，需要已知背景才能工作，但相比 SimpleBlobDetector 性能提升巨大，而且与 SimpleBlobDetector 不同，使用此方法的斑块矩形不限于正方形。背景减法会根据阈值参数从第一个和第二个输入生成二值图像，然后使用 OpenCV 查找轮廓并将其转换为矩形。

参数 - Constraints 页

Minimum Blob Size minblobsize - 斑块至少要有这么大才会被跟踪。
Maximum Blob Size maxblobsize - 大于此值的斑块不会被跟踪。
Maximum Move Distance maxmovedistance - 斑块在一帧内最多可移动多远仍被视为同一个斑块（保持相同 ID）。
Delete Nearby Blobs deletenearby - 有时（取决于跟踪方法）会产生重复的斑块。此功能可删除彼此过近的斑块。
Minimum Distance deletedist - 删除邻近斑块时，若两个斑块相距在此像素数之内，就会被删除。较小者会被删除。
Delete Area Tolerance deletenearbytol - 除了距离，还可以比较两个斑块的面积。如果此参数为 1，则忽略面积。此参数越小，只有面积差异显著（在两个被比较的斑块之间）的斑块才会被删除。
Delete Overlapping Blobs deleteoverlap - 删除相互重叠的斑块。
Delete Overlap Tolerance deleteoverlaptol - 如果此参数为 1，则只删除完全重叠的斑块。此值越小，斑块被删除所需的叠合程度越低。

参数 - Revival 页

Revive Blobs reviveblobs - 启用后，如果丢失的斑块（即相同 ID）满足以下所有参数，就会将其恢复。
Revive Time revivetime - 恢复丢失斑块的时间（秒）阈值。如果斑块丢失时间超过恢复时间，就不会被恢复，并被视为已过期。
Revive Area Difference revivearea - 新斑块与丢失斑块之间的面积差异阈值。
Revive Distance revivedistance - 新斑块与丢失斑块之间的距离阈值。
Include Lost Blobs in Table includelost - 启用后，丢失的斑块会包含在 Blob Track TOP 的 Info DAT 表格中。
Include Expired Blobs in Table includeexpired - 启用后，已过期的斑块（即没有恢复机会的斑块）会包含在 Blob Track TOP 的 Info DAT 表格中。
Expired Time expiredtime - 斑块过期后在 Info DAT 表格中保留的时间（秒）。

  • sRGB - Linear srgblinear - sRGB 色彩空间，使用线性传递函数。相对于 Reference White 而言视为 SDR 色彩空间。

  • Rec.709 rec709 - Rec.709 色彩空间，使用 Rec.709（与 Rec.2020 相同）传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.2020 rec2020 - Rec.2020 色彩空间，使用 Rec.2020（与 Rec.709 相同）传递函数。相对于 Reference White 而言视为 HDR 色彩空间。

  • ACEScg acescg - ACEScg（也称为 ACES AP1）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。

Parameter Reference White parmreferencewhite - - 在将参数颜色值转换为 Working Color Space 时，此项控制相对于 Reference White 应如何处理。如果 Working Color Space 的 Reference White 相同，则不做调整。如果不同，则此颜色的 Reference White 级别（亮度）将被调整到 Working Color Space 所期望的范围。例如，如果项目将 SDR Reference White 设为 120 nits，而 HDR Reference White 为 80 nits，那么 (1, 1, 1) 的颜色在 SDR 色彩空间中为 120 nits，将被转换为 (1.5, 1.5, 1.5)，在 HDR Working Color Space 中仍为 120 nits。

  • Use Parent Panel useparent - 将使用父级面板所选的 Reference White。如果顶层面板也选择了「Use Parent」，则将使用「UI Reference White」。
  • Standard (SDR) sdr - 会将 Parameter Color Space 的 Reference White 值按 SDR 处理。
  • High (HDR) hdr - 会将 Parameter Color Space 的 Reference White 值按 HDR 处理。
  • UI ui - 会将 Parameter Color Space 的 Reference White 值按 UI 处理。其亮度使用「UI Reference White Nits」的值。
