Unicode

TouchDesigner 完全支持 Unicode 文本。Unicode 可以输入到参数、DAT、Python 脚本等中。Unicode 编码的文本文件可以加载到 DAT 中。文件路径可以包含文件路径允许的任何 Unicode 字符。Text TOP 和 Text SOP 可以直接接受 unicode 字符。如果当前所选字体无法显示某个 Unicode 字符，将使用回退字体。

Tscript not 支持 Unicode，因此任何经过 TScript 的内容都会丢失 Unicode 字符，导致脚本执行不正确。

TouchDesigner 使用 UTF-8 保存 .txt 和其他文件格式，不过为兼容性也应能加载 UTF-16 和 UTF-32 文件。

节点名称、通道名称、参数名称和 SOP 属性仍限于基本字母数字字符集。

字节顺序标记

TouchDesigner 会在 .txt 文件开头查找 Byte Order Marks，以确定文件使用的编码。任何 UTF8/UTF16/UTF32 的 .txt 文件都必须带有此标记才能被正确解释。如果缺少 BOM，将假定文件使用 CP1252 编码，这是旧版 TouchDesigner 曾使用的编码。
