Audio Devices DAT

摘要

Audio Devices DAT 提供所有检测到的音频设备的信息，包括驱动、方向（输入或输出）、标签和名称，可在 Audio Device In CHOP 和 Audio Device Out CHOP 中引用。

你也可以将其设置为显示所有可用的音频设备。

当检测到音频设备发生变化时，它会运行一个回调脚本，并返回与发生变化的设备对应的名称列表。

audiodevicesDAT_Class

参数 - Audio Devices 页

Driver driver - 可用驱动的菜单，表格将只包含属于所选驱动的设备。
  • default (DirectSound/CoreAudio) default -
  • ASIO asio -
  • DataPath (RGBEASY) datapath -
  • Blackmagic blackmagic -
  • AJA aja -
  • Deltacast deltacast -
All Drivers alldrivers - 开启时，表格将显示来自所有可用驱动的设备。
Input Devices input - 开关，用于包含输入设备。
Output Devices output - 开关，用于包含输出设备。
Callbacks DAT callbacks - 每次表格发生变化（即设备状态变化）时运行一次此脚本。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

Info CHOP 通道

Audio Devices DAT 的额外信息可通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
