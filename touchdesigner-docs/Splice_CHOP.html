Splice CHOP

摘要

Splice CHOP 将连接到第二个输入的 CHOP 通道插入到第一个输入的通道中。你可以指定要移除采样的起始采样和长度。

然后，来自第二个输入的插入数据可以各种方式拉伸，再拼接进通道中被裁掉的位置。

你可以按通道编号或通道名称进行匹配。未匹配的通道，其空隙中的采样将按三种可选方式之一进行插值。

要从 CHOP 中提取一个采样、修改它并在原索引处替换它：将一个 Splice CHOP 连接到原始 CHOP，在所需位置设置 Start 和 Trim Length，开启 Output Trimmed Section，修改结果，然后将其作为第二个输入送入另一个 Splice CHOP，其第一个输入来自原始 CHOP，Start 设为 op('splice1').par.start，Trim Length 设为 op('splice1').par.trimlength。

Splice CHOP 也可以平滑 CHOP 的某一段：将 Start 和 Trim Length 设为该段。给它一个没有匹配通道的第二个输入。将 Insert Method 设为 Set to Trim Length，并调整 Insert Interpolate 菜单。

查看 OP Snippets 了解这些及其他技巧。

另请参阅 Delete CHOP、Trim CHOP、Select CHOP

参数 - Splice 页

Output Trimmed Section outputtrimmed - 关闭时，输出是根据下方参数拼接并裁剪后的通道。开启时，输出相反，包含通道中被裁掉的部分。
Direction direction - 指定下方 Start 和 Trim 参数的作用方向。
  • First to Last firsttolast - Start 和 Trim 以从通道开头向末尾方向的单位指定。
  • Last to First lasttofirst - Start 和 Trim 以从通道末尾向开头方向的单位指定。
Start start - Trim 和 Insert 操作开始的位置。根据上方的 Direction 参数，这将是通道中的第一个采样或最后一个采样。
Start Units startunits - 在此参数的 Samples、Frames 或 Seconds 单位之间选择。
Trim Method trimmethod - 提供设置裁剪长度的选项。
  • Use Trim Length trimlength - 使用下方 Trim Length 参数决定裁剪多少。
  • Trim to Insert Input Length insertlength - 第二个输入的长度即为要裁剪的量。
Trim Length trimlength - 被裁剪区域有多长。要仅输出被裁剪的区域，请将 Output Trimmed Section 切换为 On。
Trim Length Units trimlengthunits -
Insert Method insertmethod - 处理第二个输入如何拼接进通道。
  • None none - 不向通道插入任何内容。
  • Input Length natural - 第二个输入按完整长度拼接进来。如果 Trim 参数 = 0，则输出的总长度将是两个输入长度之和。
  • Stretch to Trim Length stretchtrim - 第二个输入被拉伸以填满被裁剪的区段。由于插入区段与被裁剪区段长度相同，输出的总长度将与第一个输入相同。
  • Trim to Insert Length insertlength - 启用 Insert Length 参数以设置插入数据的长度。见下方 Insert Length。
  • Stretch to Insert Length stretchinsert - 启用 Insert Length 参数以设置插入数据的长度，并将其拉伸以适应。
Insert Length insertlength - 根据上方的 Insert Method 用于设置插入数据的长度。当设为 Trim to Insert Length 时，若该参数值短于第二个输入，插入数据将被裁剪；若长于第二个输入，则会循环。当设为 Stretch to Insert Length 时，插入数据被拉伸以适应此参数值。
Insert Units insertunits -
Insert Interpolate insertinterp - 为被拉伸的插入通道选择插值方法。
  • None none -
  • Linear linear -
  • Cubic cubic -
Match by match - 按名称或编号匹配输入之间的通道。
  • Channel Number index -
  • Channel Name name -
Unmatched Chan Interpolate unmatchedinterp - 为使用「Match Channels」后未匹配的任何通道选择插值方法。
  • None none -
  • Linear linear -
  • Cubic cubic -

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受影响，一些 CHOP 会使用 Common 页上的 Scope 字符串。见 Pattern Matching。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。
Rename from commonrenamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to commonrenameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。

Example:

通道名称：c[1-10:2] ambient
重命名自：c* ambient
重命名至：b[1-5] amb

此示例获取通道 c1 c3 c5 c7 c9 和 ambient。

然后它们被重命名为 b1 b2 b3 b4 b5 和 amb。

重命名模式的进一步说明见 Rename CHOP。

Info CHOP 通道

Splice CHOP的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
