Attributes 类

Attributes 对象描述一组 Prim Class、Point Class 或 Vertex Class attributes，它们包含在 SOP 或 POP 中。

成员

owner → OP (Read Only):

此对象所属的 OP。

方法

[name]→ Attribute:

Attributes 可以使用 [] 下标操作符访问。

  • name - 属性的名称。
attribs = scriptOP.pointAttribs # 获取 Attributes 对象
normals = attribs['N']

create(name, default)→ Attribute:

为 SOP 创建一个新的 Attribute。

  • name - 属性的名称。
  • default - （可选）为自定义属性指定默认值。对于标准属性，默认值是隐含的。

标准属性有：N（normal）、uv（texture）、T（tangent）、v（velocity）、Cd（diffuse color）。 

# 创建一个使用隐含默认值的 Normal 属性。
n = scriptOP.pointAttribs.create('N')

# 设置第一个点的 Normal 属性的 X 分量。
scriptOp.points[0].N[0] = 0.3 

# 创建一个名为 custom1 的 Vertex 属性，默认值设为 (0.0, 0.0)
n = scriptOP.vertexAttribs.create('custom1', (0.0, 0.0) )

# 创建一个名为 custom2 的 Primitive 属性，默认值为 1
n = scriptOP.primAttribs.create('custom2', 1 )
