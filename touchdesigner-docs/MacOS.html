macOS

macOS 版本支持

NOTE: Always apply all macOS updates for the version of macOS you are on. For example, if you are on macOS 12, make sure to update to the lastest macOS 12.x.x

  • TouchDesigner 2025 版本需要 macOS 13 或更高版本。
  • TouchDesigner 2023 版本需要 macOS 10.15 或更高版本。
  • TouchDesigner 2022 版本需要 macOS 10.14 或更高版本。
  • 在 TouchDesigner 2021 及更早版本上也可以使用 macOS 10.12。参见 Previous Official Builds

macOS 上 TouchDesigner 的差异

  • 在 Windows 上通常使用 "ctrl" 修饰键的地方，macOS 大多使用 "cmd" 键。
  • 常见的 Main 菜单项和 macOS 系统级快捷键会尽可能沿用。例如，TouchDesigner Preferences... 的位置和快捷键是「macOS 风格」的。
  • 滚轮操作与 Windows 相反（默认如此），但这可以在 macOS 中通过 System Preferences → Mouse → Scroll Direction: Natural 设置。
  • 在 macOS 上，TouchPlayer 使用单独的安装程序分发。可以在 Download Official Builds 处的 macOS 下拉菜单中找到 TouchPlayer 下载。
  • 用于 USB Licensing Dongles 的 CodeMeter Runtime 在 macOS 上是单独的安装程序。在此下载 Download macOS CodeMeter，并使用 Codemeter Control Center 7.40b 版本。
  • 在 macOS 上可以用 ctrl+c 中断 Python 脚本。遇到卡死时可以试试。
  • 在 macOS 上，只需将 TouchDesigner 应用程序放到不同的文件夹，或重命名 TouchDesigner.app 文件（这样就不会覆盖现有版本），即可轻松运行多个版本的 TouchDesigner。

限制和已知问题

  • 请确保安装你的 macOS 版本内的所有系统更新。例如，若你使用的是 macOS 12，请确保更新到最新的 macOS 12.x.x。
  • 使用 CUDA 或硬件编码/解码的 Nvidia 专属功能将无法使用。这些包括：
    • Nvidia 专属 SDK，例如 Nvidia Flex 和 Nvidia Flow
    • 查看 Nvidia specific features 的完整列表
  • 材质（MAT）Common 页上的 Line Width 参数无效。

macOS Apple Silicon 版本专属

  • 以下操作符尚未移植
  • Movie File In TOP / Movie File Out TOP - Cineform 编解码器 SDK 看起来不会为 Apple Silicon 更新，因此无法加入这些版本。
  • RealSense TOP / RealSense CHOP - librealsense SDK v2.50.0 看起来不会为 Apple Silicon 更新，因此无法加入这些版本。

不支持的操作符

  • DirectX TOPs - Microsoft SDK
  • Kinect OPs / Kinect Azure OPs - Microsoft SDK
  • NatNet CHOP - 仅限 Windows 的 SDK
  • Notch TOP - 仅限 Windows 的 SDK
  • Nvidia Flex OPs - Nvidia CUDA SDK
  • Nvidia Flow OPs - Nvidia SDK
  • Oculus Rift OPs - 仅限 Windows 的 SDK
  • OpenVR OPs - 仅限 Windows 的 SDK
  • Pangolin CHOP - 仅限 Windows 的 SDK
  • RealSense CHOP - 仅限 Windows 的 SDK
  • Scalable Display TOP - 仅限 Windows 的 SDK
  • SVG TOP - Nvidia SDK
  • Video Stream Out TOP - Nvidia 硬件编码
  • ZED TOP / ZED CHOP / ZED SOP - 仅限 Windows 的 SDK

POPs 的限制

  • 不支持 Atomic Float（Normal POP 中用于计算 Normal 和 Tangent 的可能技术之一）
  • 不支持双精度属性
  • 不支持 Hardware Ray Tracing

崩溃报告

可以通过 Applications→Utilities→Console 找到崩溃报告。在 'Crash Reports' 下查找 TouchDesigner 崩溃报告

若要在 TouchDesigner 卡死时强制生成崩溃报告，请打开 Terminal

ps -A | grep TouchDesigner

这会输出卡死的 TouchDesigner 的进程 id，如下所示：

<process-id> ?? 1:09.97 /Applications/TouchDesigner.app/Contents/MacOS/TouchDesigner

运行以下命令来终止进程并强制生成崩溃报告。

kill -3 <process-id>

Spin 报告

若 TouchDesigner 冻结，卡死期间可能会生成 spin 报告，并出现在 Applications→Utilities→Console 的 Spin Reports 部分。若没有，可以打开 Applications→Utilities→Activity Monitor，选择 TouchDesigner，然后从工具栏的 "..." 项中选择 Spindump 以强制生成报告。


参见 Troubleshooting in TouchDesigner。
