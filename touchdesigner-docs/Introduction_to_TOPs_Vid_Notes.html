TOP 入门视频笔记

你将创建什么

本教程将介绍如何把一张蝴蝶图像导入、修改图像的色阶、把它放到更大的画布上，然后添加背景，并配合一些基本的合成技巧。建议观看本教程的视频版，因为其中对使用 TouchDesigner 时的一些最佳做法有更深入的讲解。

把图像导入 TouchDesigner

  • 打开 TouchDesigner，点击屏幕左侧四分之一处 palette 浏览器顶部的 X。
  • 双击 network 编辑器打开 OP Create Dialog，在 TOP 页下选择「Movie File In」来放置一个 Movie File In TOP。
  • 现在你的 network 中应当有一个新的 node。左键点击 node，在 network 编辑器右上四分之一处打开它的 parameters。如果你看不到 parameters，按 P 键开关它们。
  • 在 parameter 窗口中写着 file 的地方点击加号图标，打开文件浏览器。在打开的目录中选择 butterfly6 文件。

修改刚导入图像的色阶

  • 在 node 的右侧，右键点击 wire out 图标并选择一个 Level TOP。左键点击，把 level TOP 放到 network 中。
  • 在 level TOP 参数窗口中点击「Pre」页，设置以下值：Black Level: 0.14，Brightness: 1.5。
  • 查看器中的蝴蝶应当比 Movie File In TOP 中之前的蝴蝶亮得多、饱和度也低得多。

设置 Viewer 的分辨率

  • 双击 Movie File In TOP 下方的 network，选择一个 Constant TOP。在参数窗口的 constant 页下把 Alpha 值设为 0。在 common 页下，Custom Res parameter 右侧有一个箭头。点击该箭头会调出 Constant TOPs 分辨率。把分辨率设为 1280x720。

把蝴蝶合成到空白查看器上

  • 右键点击你创建的 Level TOP 的 wire out，放置一个 Composite TOP。
  • 左键点击 Constants 的输出，然后左键点击 Composite TOP 的输入。
  • 左键点击 node 选中 Composite TOP，然后在它的 parameters 中，于 Composite 页下把 Operand 参数设为 Over。在 Transform 页下把 Fixed Layer 设为 Input 2。现在查看器中应当有一只蝴蝶，周围有更多棋盘格空间。

设置蝴蝶的位置并添加渐变背景

  • 右键点击 composite TOPs 的输出，选择一个 Transform TOP。
  • 在 Transform TOPs parameters 中，中键点击 Translate parameter 下的 x 和 y 数字，可以左右拖动来给蝴蝶定位。你也可以手动输入数字。
  • 双击 Transform TOP 下方，放置一个 Ramp TOP。在 Ramp TOPs parameters 中，可以在 Ramp 页下用渐变条设置渐变。要更改颜色，选中你想改的颜色的矩形，然后在 Hue、Saturation 和 Value 参数下把颜色改成一浅蓝一深蓝。
  • 在 common 页下把 Ramp TOPs 分辨率改为 1280x720。
  • 右键点击 Transform TOPs 的输出，再放置一个 Composite TOP。
  • 把 Ramp TOP 连到 composite TOPs 的输入。
  • 把 Composite TOPs 的 operand 参数设为 Over。

再添加一只蝴蝶

  • 中键点击 Transform TOP，从 TOP 页下再选择一个 Transform TOP。
  • 选中新的 Transform TOP，把 Translate 参数设为 -0.2。
  • 把 Scale 的 x 和 y 参数设为 0.3 和 0.3。这样蝴蝶就能有不同的尺寸。
  • 左键点击新 Transform TOP 的输出，然后左键点击第二个 Composite TOP 的输入，把它们 wire 在一起。
  • 在第二个 Composite TOPs parameters 中写着 Input OP 的地方，点击 Transform2 旁的向上箭头，把 Transform TOP 移到 Ramp 之上。

在 Perform Mode 中查看蝴蝶

  • 右键点击第三个 Composite TOP（comp3）的输出，从 TOP 页选择一个 Out TOP。
  • 在屏幕最左上角、Network 编辑器上方有一个 ^ 图标。点击它把项目放入 Perform Mode。要退出 Perform Mode，按 Esc 键。
  • 分辨率与 Perform Mode 中的 Out TOPs 不同，因为 Perform Mode 使用的是 Project1 COMP 的宽度和高度。从 network 向外缩小，直到看到 Project1（或者点击 Network 编辑器上方路径栏中的 /，然后在弹出菜单中点击 /）
  • 选中 Project1，在其 parameters 的 Layout 页下把宽度 parameter 设为 1280，高度 parameter 设为 720
  • 点击屏幕左上角、Network Editor 上方的 ^ 图标，切换到 Perform Mode。然后可以按 Escape 键关闭 Perform Mode。

附加 - 用 transform 的 scale 参数让蝴蝶扇动翅膀

  • 双击网络，在 CHOP 页下按住 shift 依次点击：LFO、Math 和 Null。现在你应当有 3 个新节点。
  • 在 Math CHOP 的 range 参数中，把 From Range 设为 -1 到 1，To Range 设为 0.2 到 1。
  • 右键点击 null，选择 CHOP Export。此时应当出现 CHOP Export 对话框
  • 在 Chop Export 对话框保持打开并放到上方一侧的情况下，左键点击第一个 Transform TOP（transform1），然后左键点击并拖动 chan1 文本到 Transforms Scale x 参数的值上。会出现一个小箭头和加号图标，松开拖动，参数应当变蓝。如果一切正常，蝴蝶现在会随 LFO CHOP 的节奏扇动翅膀。
