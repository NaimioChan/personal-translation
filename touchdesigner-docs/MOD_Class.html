MOD 类

MOD 类提供对 Module On Demand 对象的访问，它允许将 DATs 作为模块动态导入。可以通过 mod 对象访问它，该对象位于自动导入的 td module 中。或者也可以使用常规的 python 语句：import。 import 语句的使用仅限于搜索路径中的模块，而 mod 格式允许在一行中写出完整语句，这对输入表达式更有用。另请注意，DAT 模块无法像常规的基于文件系统的 python 模块那样组织成包。

成员

没有该操作符专属的成员。

方法

没有该操作符专属的方法。

用法

在脚本中，有三种方法可将 DAT 作为模块导入。

  • import datName
    导入由名为 datName 的 DAT 定义的模块。支持所有常规导入选项（from、as 等）。若未找到 DAT，则使用常规文件系统搜索路径。
    # 导入名为 addMonth 的 DAT
import addMonths
  • m = mod.datName
    导入由名为 datName 的 DAT 定义的模块。
    m = mod.addMonths(1,2,3)
  • m = mod(pathToDat)
    与上述类似，但可以使用 DAT 的路径。
    m = mod('myMods/adders').addMonths(1,2,3)

用法对比

使用 import 的示例： 

import myUtils
a = myUtils.add(5,6)

使用 mod 的同一示例： 

a = mod.myUtils.add(5,6)

在搜索路径之外使用 mod 的示例： 

a = mod('/projects/utils/utilsA').add(5,6)

但请注意，单条 import 语句比多次相同的 mod 语句更快： 

import myUtils
a = myUtils.add(5,6)
b = myUtils.add(5,6)
c = myUtils.add(5,6)

将比以下更快执行： 

a = mod.myUtils.add(5,6)
b = mod.myUtils.add(5,6)
c = mod.myUtils.add(5,6)

不过上述代码可以这样改写得更高效，然后就会以与 import 语句相同的速度执行： 

m = mod.myUtils
a = m.add(5,6)
b = m.add(5,6)
c = m.add(5,6)

搜索路径

首先搜索当前组件。

若未找到 DAT，则搜索当前 component 的 local/modules component。

接下来依次搜索每个父级的 local/modules component。

若仍未找到 DAT，则返回 None。
