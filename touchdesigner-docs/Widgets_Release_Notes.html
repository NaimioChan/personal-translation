Widgets 发行说明

TDUI 0.26 TDKWidgets Version 0.5.6 - 2019 年 1 月 25 日

新功能

  • Create/Edit Value Par Exec 脉冲参数会添加一个 parameter execute DAT，用于编写附加到 Widget 值参数的脚本。
  • 许多 Widget 子组件页都有 “Customize Interaction” 脉冲按钮，它提供到正确子组件的 Panel Execute DAT 连接，以便更深入定制与 Widget 的交互。
  • OP Reference 参数支持拖放，并支持实际的 OP 类型 Value 参数。
  • 新的专用 widget 既支持通用的 OP 类型，也支持特定的 OP 类型：
  1. RenferenceOP
  2. RenferenceCHOP
  3. RenferenceCOMP
  4. RenferenceDAT
  5. RenferenceMAT
  6. RenferenceOBJ
  7. RenferenceSOP
  8. RenferenceTOP

错误修复与改进

    向后兼容性

    • BACKWARDS COMPABITILITY WARNING -
    • Widgets 上所有内联脚本参数都已更改，因此这些 Widget 参数上的脚本都将丢失。
    • Python 的值变化执行参数已移到 Value 页。这些参数现在称为 "On Value Change Script"、"Off To On Script" 和 "On To Off Script"。
