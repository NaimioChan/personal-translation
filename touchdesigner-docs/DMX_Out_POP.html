DMX Out POP

摘要

DMX Out POP 可发送到 DMX、Art-Net、sACN、KiNET 或 FTDI 设备。

DMX Out POP 会合并其 DMX Fixture POP 个输入中各自的 DMX universe，并发送到设备。它可以合并任意数量的 DMX Fixture POP，但如果多个 DMX Fixture POP 写入同一 DMX universe 的同一个通道值，就可能出现冲突。这种情况下会输出警告，调试此类冲突时 DMX Map DAT 是很有用的工具。

注意： 每个输入都必须是 DMX Fixture POP，无论通过连线还是通过参数的 OP 引用。

TouchDesigner 中的 DMX 是在 ENTTEC 设备上开发的，即其 DMX USB Pro 和以太网 DMX 设备，但它应该适用于许多支持 DMX/Art-Net/sACN/KiNET 的设备和软件。

可以在 DAT 中提供 Routing Table，通过为每个 DMX512 universe 添加行并指定 net、subnet 和 universe 值来指定网络地址。

提示：可以用单个 DMX Out POP 收集并服务项目中的任意数量 DMX Fixture POP，因为可以在 DMX Fixture POPs 参数中从根 /* 递归指定所有要搜索的 DMX Fixture POP 的路径。可以使用 Folder DAT 查找项目中的所有 DMX Fixture POP。

ENTTEC NOTE: - 使用 ENTTEC 的 NMU (Node Management Utility) 来配置和检查网络中发现的 ENTTEC 设备。

macOS NOTE: - ENTTEC USB Pro 可能无法自动连接，要启用它，请在 Terminal 中输入以下命令：

sudo kextunload -b com.apple.driver.AppleUSBFTDI

提示：使用 WireShark 观察 DMX 网络流量。向大量 universe 发送时（例如用于体积光照），使用单播（参见 DMX Fixture POP 的 DMXFixtureNetAddress 属性）比广播更有利，因为效率更高，也能避免网络过载。

另请参阅：Art-Net、sACN、DMX In CHOP、DMX Out CHOP、DMX

参数 - DMX 页

Active active - 启用后将主动向设备发送。
Interface interface - - 选择连接设备所用的接口类型。
  • Generic Serial serial - 使用操作系统的串口调用写入数据。
  • Enttec USB Pro enttecusbpro -
  • Enttec USB Pro Mk2 enttecusbpromk2 -
  • Art-Net artnet - 把接口设为 Art-Net 协议。
  • sACN sacn - 把接口设为 sACN 协议。
  • KiNET kinet - 把接口设为 KiNET 协议。
Rate rate - 数据发送到设备的频率（每秒）。WARNING: DMX512 devices have a maximum refresh rate of 44Hz. It is recommended that Rate <= 44 for reliable performance.

参数 - Fixtures 页

Fixture fixture - DMX Fixture POP 输入（连线或引用）的顺序参数块起始处。
Active fixture0active - 激活时，此 Fixture 会被合并并发送。
DMX Fixture POPs fixture0pop - 对一个或多个 DMX Fixture POP 的引用。如果存在对应的连线输入，此参数将被禁用。

参数 - Network 页

Multicast multicast - 为 sACN 启用多播。多播会根据设备的 Net、Subnet 和 Universe 自动构建 IP。这样可以指定多个 universe，一次发送到多台设备。
Network Address netaddress - 指定要使用的 IP 地址。此地址对应接收设备的地址。当地址设为默认值 255.255.255.255 时，消息将改为广播到网络上的所有设备。无论哪种情况，接收设备的 Net、Subnet 和 Universe 都必须与 DMX Out POP 中指定的相匹配。如果在 Routing Table 中为某个 net/subnet/universe 指定了 netaddress，则改用该地址。
Local Address localaddress - - 当发送机器装有多个网络适配器时，可以用该参数在此指定其 IP 地址，从而选择从哪个适配器发送数据。
  • 192.168.178.150 192.168.178.150 -
  • 10.2.0.2 10.2.0.2 -
Local Port localport - 少数情况下需要指定数据发送所用的自定义端口。默认值 -1 表示使用操作系统分配的端口。
Use Custom Port customport - 启用 Network Port 参数以指定接收硬件的端口。禁用时，默认端口为：Art-Net 6454，sACN 5568，KiNET 6038。
Network Port netport - 指定接收硬件的端口。
Priority priority - 数据优先级，用于存在多个来源的情况。与 sACN 和 KiNET 协议配合使用。
Send ArtSync sendartsync - 启用后会发送 ArtSync 数据包。ArtSync 数据包用于将多个 universe 同步在一起。其做法是先等待所有 ArtDmx 数据包发送完毕，然后发送一个 ArtSync 数据包。
ArtSync Timeout artsynctimeout - 指定 ArtSync 在发送 ArtSync 数据包之前等待所有 ArtDmx 数据包发送完成的时间，单位为毫秒。如果超时到达时它们尚未全部发送完毕，ArtSync 将终止，并且不会发送 ArtSync 数据包。此外，还会发送新一帧的 ArtDmx 数据包，并启动新的 ArtSync。
CID cid - 发送方的唯一 ID。
Source source - 用户为来源指定的名称（仅供信息参考）。
KiNET Version kinetversion - 选择要使用的 KiNET 协议版本。
  • DmxOut (v1) v1 -
  • PortOut (v2) v2 -
Use Custom KiNET Port customkinetport - 启用后可为 KiNET v2 接口指定自定义端口。禁用时，端口为广播端口：255。
KiNET Port kinetport - 指定 KiNET v2 接口的端口。
Routing Table routingtable - 使用 Table DAT 为特定 universe 指定 netaddress、source、cid、priority 和 kinetport 值。net、subnet、universe 列必须填入有效值。注意：DMX Fixture POP 可以用它自己的 Routing Table 覆盖 netaddress 值。

参数 - Multipliers 页

Use Multipliers usemultipliers - 启用乘数，对特定命名通道（即 DMX Fixture POP 上通过 Name 参数设置的名称）在运算后施加 [0-1] 的乘法。
Multiplier multiplier - 通道乘数的顺序参数块起始处。如果存在重复的通道名，该通道的乘数会被合并。
DMX Channels multiplier0dmxchannels - 选择 DMX 通道名（来自输入 DMX Fixture POP 上的 Name 参数）。旁边的菜单列出了所有可用的通道名。一个乘数序列块可以用空格分隔的格式引用多个通道名，例如 "Dimmer RGB"，其中 Dimmer 和 RGB 是通道名。"*" 可用于将乘数应用于每一个通道。
Multiplier Value multiplier0value - [0-1] 范围内的乘数值，应用于与 DMX Channels 中指定的关联通道名匹配的任何通道。

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

Info CHOP 通道

DMX Out POP 的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
