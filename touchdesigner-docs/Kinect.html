Kinect

本文包含 Kinect 2 设备的信息。有关初代 Kinect，请参阅 Kinect1。

最新功能请参阅 Kinect Azure TOP。

在 Windows 操作系统上，可通过 Kinect TOP 和 Kinect CHOP 将 Microsoft Kinect2 用作 TouchDesigner 的输入设备。

Kinect 是 Microsoft 的运动传感器输入设备。该设备包括红外深度感应摄像头、RGB 彩色摄像头，以及用于音频采集的麦克风阵列。Microsoft Kinect SDK 提供骨骼跟踪、手部交互和语音识别等功能。

Kinect2 最初于 2013 年随 Microsoft 的 Xbox One 游戏主机发布。2014 年，Microsoft 发布了 Kinect 2 for Windows，其中包含仅适用于 Windows 操作系统新型 Kinect 硬件的 Kinect SDK。

TouchDesigner 中的 Kinect 2 支持

TouchDesigner 使用 Microsoft 官方的 Kinect for Windows SDK 内置支持 Kinect。因此，TouchDesigner 内置的 Kinect 操作符仅支持 Kinect for Windows 硬件。


Requirements

  • Windows 8 或 10 操作系统。
  • Kinect for Windows 硬件设备。仅当从 Microsoft 购买额外的兼容转接器时，才兼容 Kinect for Xbox One 设备。
  • 安装 Kinect SDK 2.0


Ways to interface with Kinect in TouchDesigner

  • 深度摄像头 - Kinect TOP
  • RGB 摄像头 - Kinect TOP
  • 红外摄像头 - Kinect TOP
  • 骨骼点跟踪 - Kinect CHOP
  • 手部交互 - Kinect CHOP
  • 麦克风阵列音频采集 - Audio Device In CHOP

使用 Kinect 传感器的提示

  • 截至本文撰写时，Microsoft 尚未添加在同一系统上访问多个 Kinect 2 设备的支持。
  • 如需更多支持与故障排除，请参阅 Kinect Support Community。
