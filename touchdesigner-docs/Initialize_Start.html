初始化启动

Initialize Start 是 TouchDesigner 中准备并运行定时流程的一种方式。它适用于 TouchDesigner 中任何首先需要初始化的系统（即「initializing」状态），例如将文件读入内存、查询服务器、预模拟动力学或启动外部进程。初始化完成后，它进入「ready」状态。随后通过「Start」脉冲参数发出启动信号。例如，在开始演出之前，你可能希望在第一帧初始化所有生成式组件。

启动后，它进入「running」状态；完成时（计时器到达其长度且未循环，或脉冲 Go to Done）进入「done」状态。

ready 状态必须完全就绪、随时可用，这样按下 Start 时第一帧就是完全有效的，不会掉帧或延迟。

初始化通常需要不止一帧才能完成，因此通常提供了在若干帧内完成初始化的机制，而不会明显阻塞 TouchDesigner。initializing 状态可能持续数帧。

注意：惯例是，如果在已处于 running 或 done 时按下 Start，等同于先转到完成、按下 Initialize 然后再启动。也就是说，Initialize 阶段会自动先完成，然后再重新开始。

Initialize Start 基于 Timer CHOP。

使用 Initialize Start 方式的 TouchDesigner 部件示例包括：

  • Timer CHOP
  • FBX COMP
  • USD COMP
  • Bullet Solver COMP
  • Nvidia Flow TOP, Nvidia Flex TOP
  • Notch TOP
  • Animation COMP
  • 调色板组件库中的 Palette:moviePlayer COMP
  • ( 调色板组件库中的 Palette:particlesGpu COMP )
  • Engine COMP
  • Feedback POP
  • Particle POP

调色板组件库中有一个名为 initalizeStart 的组件，你可以用它把自己的任意组件转换为使用同一机制。

Initialize Start 遵循 Timer CHOP 的模型。

控制参数

  • Initialize（脉冲）- 准备所有数据，进入 initializing 状态
  • Start（脉冲）- 启动所有计时器，进入 running 状态
  • Play（开关）- 用于在播放时暂停
  • Speed（浮点）- 在运行时加快或减慢计时器或模拟时钟。
  • Cue（开关）、Cue Pulse（脉冲）、Cue Point（浮点，带菜单 % 索引、帧、秒）- 让你把系统放到/擦洗到指定时间
  • Length（浮点）- 如果行为是固定长度的，长度有时是预先确定的（如影片文件），有时由用户设置。
  • Pre-Roll（浮点）- 如果行为是过程式模拟，在初始化时可能会先运行模拟几秒以让它进入状态。
  • Initialize Time（浮点）- 对于固定长度的系统，在已实现的情况下，这会将内部时间轴初始化到中途某处。
  • Go to Done（脉冲）- 停止所有计时器，可能进入结束状态，进入 done 状态。

信息通道

这通常通过在操作符上附加一个 Info CHOP 来实现。它就是 Timer CHOP 和 initializeStart 调色板组件中的实际输出。

状态 -

  • initializing（若操作符在当前帧内即完成初始化则为 0）
  • ready （初始化完成之后、Start 按下之前）
  • running 在 Start 之后开启，直到 Done 或 Initialize 才关闭
  • done（如适用）

计数器 - 用于驱动动画、索引查找等。

  • timer_fraction（如适用）对于固定长度的设置，它是 timer_seconds / length_seconds。（对于无限长度或长度未知的设置，设为 0。）
  • timer_seconds（秒）受 Speed 和 Play 影响。如果长度已知且你进行循环，timer_seconds 会回到 0。它实际上就是计算出的索引 / (end - start) / (file_sample_rate)
  • timer_frames（可用时 - 基于时间轴每秒帧数的帧数。）
  • cumulative_seconds（秒）在你 Start 时从 0 开始计数。它会被 Speed 参数减慢和加快，被 Play 参数暂停。若有任何循环、跳转或擦洗，它会继续增加。
  • master_seconds（秒）- 在你 Start 时从 0 开始计时，会被 Speed 参数减慢和加快，并被 Play 参数暂停。这是主时钟。（如果提供了擦洗或跳转的功能，它会跳到相应时间。）
  • running_seconds（秒）- 在 Start 之后持续增加，不受更改 Speed、暂停 Play 或擦洗的影响。它基本上就是按下 Start 之后的「墙上时钟」。当你 Go to Done 时它停止。直到你再次 Initialize 或 Start 才会重置为 0。
  • playing_seconds（秒）- 在你 Start 时从 0 开始计数，类似 running_seconds，但 Play 暂停时它也会暂停。
  • 适用于长度已知的操作符的 length_seconds
  • cycles（如适用）

行为

固定长度与无限（未知）长度。无限长度的例子是粒子模拟。固定长度有两种：用户指定的长度，或由媒体决定的长度（如音频文件）。

回调

在某些情况下，例如 Timer CHOP，提供了回调，让你在事件发生时运行 python 代码，例如初始化结束时，或固定长度行为结束时。常见的有：

  • onInitialize() 在 Initialize 被脉冲时调用，之后每帧都会调用，直到你返回 0，以便实现多帧初始化。
  • onReady() 在初始化完成时调用。
  • onStart() 在按下 Start 时调用。
  • onDone() 在固定长度系统完成时以及脉冲 Go to Done 时调用。

错误和警告

在某些情况下，操作符会报告错误或警告，例如初始化失败。
