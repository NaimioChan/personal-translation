Select DAT

摘要

Select DAT 允许你从项目中任意其他位置获取 DAT，并且如果它是表格，还可以选择任意行和列的子集。

selectDAT_Class

参数 - Select 页

DAT dat - 所引用 DAT 的 path。
Include First Row firstrow - 强制选中第一行，即使 Select Rows 设置未指定它。
Include First Col firstcol - 强制选中第一列，即使 Select Cols 设置未指定它。
Select Rows extractrows - - 该参数让你选择指定所选行的不同方式。
  • All all - 选中所有行。
  • by Name byname - 使用 Start Row Name 和 End Row Name 参数选择行。
  • by Index byindex - 使用 Start Row Index 和 End Row Index 参数选择行。
  • by Start Name, End Index bynameindex - 使用 Start Row Name 和 End Row Index 参数选择行。
  • by Start Index, End Name byindexname - 使用 Start Row Index 和 End Row Name 参数选择行。
  • by Values bynames - 通过显式指定行值来选择行。
  • by Condition byexpr - 通过针对 from 列求值的表达式来选择行。
Start Row Name rownamestart - 指定选择范围的起始行名。
Start Row Index rowindexstart - 指定选择范围的起始行索引。
End Row Name rownameend - 指定选择范围的结束行名。
End Row Index rowindexend - 指定选择范围的结束行索引。
Row Select Values rownames - 指定要选择的实际行名。可以使用 TouchDesigner 的模式匹配（见 wiki 页面 Pattern Matching），例如 row[1-4] 会选中名为 row1 到 row4 的所有行。某些字符如 ' 需要在前面加 \。
Row Select Condition rowexpr - 指定一个将被计算的表达式。如果表达式结果为 true，则选择该行。

展开该参数，你会看到它位于 expression mode 中。

默认情况下，Python 表达式为 re.match('.*',me.inputCell.val) != None。 '.*' 表示匹配任意字符多次，因此该表达式匹配所有值。 如果要匹配父级的操作符名后跟任意数字，可以使用 parent().name+'[0-9]*'，其中 '[0-9]*' 匹配任意数字字符串。 '.*'+parent().name+'.*' 会匹配任何包含该操作符父级名称的单元格。 可查阅 Regular Expression Operations 了解使用 Python Regular Expression 模块的更多信息。

From Column fromcol - 按值选择行时，该参数选择用哪一列把单元格值与 Selected Row Values 匹配，以确定选中哪些行。
Select Cols extractcols - - 该参数让你选择指定所选列的不同方式。
  • All all - 选中所有列。
  • by Name byname - 使用 Start Col Name 和 End Col Name 参数选择列。
  • by Index byindex - 使用 Start Col Index 和 End Col Index 参数选择列。
  • by Start Name, End Index bynameindex - 使用 Start Col Name 和 End Col Index 参数选择列。
  • by Start Index, End Name byindexname - 使用 Start Col Index 和 End Col Name 参数选择列。
  • by Values bynames - 通过显式指定列值来选择列。
  • by Condition byexpr - 通过针对 from 行求值的表达式来选择行。
Start Col Name colnamestart - 指定选择范围的起始列名。
Start Col Index colindexstart - 指定选择范围的起始列索引。
End Col Name colnameend - 指定选择范围的结束列名。
End Col Index colindexend - 指定选择范围的结束列索引。
Col Select Values colnames - 指定要选择的实际列名。可以使用 TouchDesigner 的模式匹配（见 wiki 页面 Pattern Matching），例如 colvalue[1-4] 会选中名为 colvalue1 到 colvalue4 的所有列。 匹配某些字符如 ' 需要在前面加 \。
Col Select Condition colexpr - 指定一个要计算的表达式。如果表达式求值为真，则选中该列。详情参见 Row Select Condition。
From Row fromrow - 按 Specified Names 提取列时，该参数选择用哪一行把单元格值与 Selected Col Values 匹配，以确定选中哪些列。
Output output - 决定该 DAT 输出所使用的格式。
  • Input Data data - 不经任何处理直接传递第一个输入的数据。
  • Strings string - 把输入数据作为字符串求值，包括把任何变量值展开为完整字符串。
  • Expressions expr - 把输入数据作为表达式求值。

Custom Extension customext - 指定自定义扩展名。

操作符输入

  • Input 0: -

Info CHOP 通道

Select DAT 的额外信息可通过 Info CHOP 获取。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
