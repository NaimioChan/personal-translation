参数对话框

在网络编辑器中显示单个操作符参数的一种浮动对话框、窗格类型或对话框。

参数对话框可用于查看和操作操作符的所有 Parameters。每个操作符都有一个或多个参数页（或「标签页」），可在对话框中查看，有些标签页为各自 OP 独有，另一些则在不同 OP 类型间通用。

该对话框可在 TouchDesigner 用户界面的三个不同区域查看。在网络编辑器窗格中按 p 键即可查看参数对话框。如果对话框已可见，按该键会将其隐藏。也可以从节点的右键菜单中选择参数对话框，使其成为浮动窗口。最后，它还可以作为 Pane 类型查看。

所有参数对话框的布局相似，使用同一套控件来操作各种参数值。参数对话框显示在网络右侧。通过切换 Network 或 Pane Sticky 按钮，可以同时打开多个参数对话框。最上方的可见参数对话框即当前选中的 OP。

注意：可以使用 Parameter COMP 将参数对话框放入面板，并自定义要显示哪些页和参数。

参数页

每个标签页显示操作符的一个不同参数页。

参数

在任意参数名称/标签上 Left click 可展开参数模式（见下文小节）。在参数的可编辑字段中左键单击可输入新值。

在任意数值参数上 Middle click 可调出 Value Ladder 来调整该值。如果参数是双/三/四元参数（例如 Displace TOP 中的 Offset 或 Geometry COMP 中的 Translate），在参数名称/标签上打开数值梯会同时调整全部两/三/四个值。要单独调整某个参数，请用中键单击数值字段本身。

在任意参数上 Right click 可打开该参数的选项弹出菜单。

操作多个操作符的参数

选中多个同类型的操作符时，可以快速将所选操作符的参数值同时设为相同值。只需选中要更改的多个节点，然后更改当前节点的参数，所有已选节点也会随之更新。

选中多个操作符时，还可以设置进入单个操作符参数时首先显示哪个参数页。当你需要逐个修改许多节点的参数、并且总是要访问同一个参数页时，这能节省时间。例如，有 5 个 Text TOP，需要将每个的颜色改为不同颜色。不必每次都选择 Color 参数页，你可以选中所有操作符，然后选择当前操作符的 Color 页。此后每次单独选中其他某个 Text TOP 时，显示的参数页都已设为 Color 页，让你更快地修改颜色。

使用参数模式

每个 Parameter 都可以处于四种模式之一：Constant 模式、Expression 模式、Export 模式或 Bind 模式。参数模式让你快速切换模式，以测试新的值、表达式、导出或绑定设置。

  • Constant - 这是默认模式，按参数中输入的内容处理数字和字符串值。
  • Expression - 此模式用于使用 python 或 tscript 表达式设置参数值。
  • Export - 此模式用于通过来自 CHOP 或 DAT 的 Exporting 驱动参数。
  • Bind - 此模式用于通过对参数、表格单元格、Bind CHOP 或 Dependency Class 的 Binding 驱动参数。

要访问参数模式，用 LMB 单击参数名称/标签区域展开参数。这会打开该参数的编辑区，以及 4 个用于切换模式的开关。要关闭此区域，只需单击参数名称/标签或「-」图标。

参数展开后，你会看到参数的内部名称。该名称用于脚本编写和直接访问参数。

内部名称右侧有 4 个方形按钮用于切换模式。灰色按钮为常量模式，蓝色按钮为表达式模式，绿色按钮为导出模式（必须已存在导出到该参数的值才能切换到导出模式），紫色按钮为绑定模式。

下图显示了展开的 3 个参数：constant 模式下的 Seed 参数、expression 模式下的 Period 参数、export 模式下的 Harmonics 参数，以及绑定模式下的 Harmonic Spread 参数。


所有 4 种模式的值都保存在参数中。这样可以在同一参数中设置常量值、表达式、导出和绑定，并在 4 种模式间自由切换。如果参数中设置了表达式、导出或绑定但当前未选中该模式，模式按钮会在其左下角显示一个小方块来提示。

下图显示一个处于常量模式的参数，其中已设置好表达式、导出和绑定，随时可用。

使用参数模式的优势在于快速原型制作以及测试和调试能力。如果参数由表达式、导出或绑定驱动，你可以轻松跳到常量模式来停止表达式/导出对该参数的驱动。在常量模式下，你可以测试特定值，或在设定特定值的情况下检查系统。随时都可以将参数模式切回表达式/导出/绑定，重新接上原有的逻辑。
