Palette

Palette 是一组实用 Components 的集合，可以拖放到你的 network 上。通过界面左上角的 图标打开/关闭。

有关部分单独的 Palette 组件，请参阅 Category:Palette。

打开 Palette Browser

可以通过以下方式访问 Palette Browser：

  • 从主菜单栏选择 Dialogs -> Palette Browser。
  • 点击 Open Palette 按钮，它位于 Pane Layout 选项左侧、File 菜单下方。
  • 使用 Python UI Class 打开 ui.openPaletteBrowser()

界面

点击文件夹会立即在其下方的 Component 区域显示内容。点击某个组件时，界面底部会出现预览窗口，给出图标预览和附加信息。

将 Palette 元素载入 TouchDesigner

要从 Palette 载入文件，请在浏览器中选择该文件，然后把它 Drag-and-Drop 到任意 TouchDesigner 网络中。此外，也可以选中文件预览并拖放到网络中。

向 Palette 添加项目

  • 要向 Palette 添加组件，请把该组件拖到「My Components」文件夹区域下的子文件夹上。
  • 在 My Components 中创建新的子文件夹
    1. 右键点击 My Components 或 My Components 下的任意子文件夹。
    2. 从上下文菜单中选择「Add Folder」。
    3. 在弹出的对话框中输入新文件夹的名称。

从 Palette 移除组件或文件夹

要移除之前添加的组件或文件夹，请右键点击它并选择「Delete」。

注意： 默认 Palette 中的项目，或属于个人 Palette 初始创建内容的项目，无法通过这种方式删除。

更新 Palette

向包含 Palette 的文件夹添加文件时，这些文件不会自动载入 Palette 结构。要包含它们，请右键点击该文件夹并选择「Refresh Folder」。新组件随后会显示在 Palette 中。
