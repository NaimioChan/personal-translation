特化常量

Specialization Constants 是 Vulkan 的新特性，它允许基于整数常量值对代码重新优化，而无需完全重新编译着色器代码。它们适用于为很少变化的值设值，例如着色器中的「模式」，或通过 switch() 或 if() 语句选择的特定代码路径。过去这可能通过 #define 语句或 uniform 来实现。 着色器的特化版本会被缓存并重复使用，但会占用 GPU 资源。因此不应用于不断变化的值，而应用于仅偶尔变化、且取值范围有限的值。

要定义特化常量，需声明一个带额外 layout() 限定符的常量。

layout(constant_id = 0) const int SomeMode = 0;

然后你可以像使用其他变量一样使用 SomeMode。如果不希望它为 = 0，可以在 GLSL TOP、GLSL MAT 等的「Constants」页上赋予不同的值。 你可以声明多个特化常量，只需为每个赋予自己唯一的 constant_id 值（0、1、2 等）。
