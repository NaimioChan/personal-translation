录制带音频的影片

至少有四种方法用 TouchDesigner 录制带 FFmpeg 的影片。

实时录制

在实时录制中，你在表演的同时使用 Movie File Out TOP 创建影片。这会生成尽可能好的影片，但如果 TouchDesigner 和你的电脑跟不上录制影片的目标帧率，影片中可能出现重复帧。这是 Mixxa 所使用的方法。

Movie File Out TOP 会带音频录制，音频可来自实时生成的 Time Slice，或来自包含整段音频剪辑的静态 CHOP。

当 Movie File Out TOP 跟不上目标每秒帧数时，它会在影片文件中复制图像，使最终影片的帧数正确。

在实时录制中，时间轴无关紧要，你可以录制任意长度的影片。要获得更平滑的影片，可以降低包括创建影片文件的 Movie File Out TOP 在内的各 TOP 的分辨率。

非实时录制

如果你不是在表演，也不使用实时输入数据，并且希望录制可精确重复，请使用非实时录制。不会丢帧，且可以任何分辨率和任意复杂程度录制。

使用 File -> Export Movie 录制一系列帧。这与时间轴锁定，固定到时间轴上用户定义的帧范围。你可以使用 me.time.frame 和 me.time.seconds 等与时间轴锁定的变量。为此，我们建议将 Movie File In TOP 中的影片的 Play Mode 设为 Locked to Timeline，或使用 me.time.frame 指定 Specify Index。否则 Play Mode 设为 Sequential 时，每次制作影片录制的内容可能都不同。

你可能希望在每次录制影片时重置 Speed CHOPs 和 Count CHOPs。

黑魔法录制

黑魔法录制能从表演中获得顶级质量，但需要仔细设置，且是两遍流程。

从 TouchDesigner 音频端口输出的音频被直接送回音频输入，进入 Audio Device In CHOP 并馈送给 Record CHOP。因此，在你表演时，音频可以在 TouchDesigner 中生成、输出、在外部处理并与其他音频混合，然后再送回 Audio Device In CHOP 并在 TouchDesigner 中捕获。

不是在表演时制作影片，而是将选定的表演通道和数据捕获到 Record CHOP 中。使用 Select CHOPs 和 Switch CHOPs，你将数据重新路由通过网络，并以高分辨率、精确的帧率非实时录制影片，影片中包含捕获的音频。

由于音频路径与视频路径不同，你需要注意延迟其中之一，以确保最终影片中的音频与视频同步。你可以对捕获的通道使用 Trim CHOPs，或在实时中使用 Delay CHOPs 来实现，或在后期处理。

外部摄像机录制

这是「经典」做法。从 TouchDesigner 录制到摄像机录机，直接通过 HDMI 到摄像机，或通过扫描转换器。将音频在 TouchDesigner 内录制到 Record CHOP，然后可通过 RMB -> Save CHOP Channels 保存为 .aif 或 .wav。或者，将音频实时发送到摄像机。

Touch Out / Touch In 录制

如果一台电脑的 CPU 性能不足，可通过 Touch Out TOP 经千兆以太网将视频流发送到另一台电脑上的 TouchDesigner，后者通过 Touch In TOP 读取视频流。然后在那个系统上进行实时录制。

随着单系统多核的发展，在一台电脑上完成更多录制正变得可行。
