Optimus

采用 NVIDIA Optimus 技术的笔记本电脑在笔记本屏幕始终连接的内置 Intel GPU 之外，还有一块 NVIDIA 独立 GPU。

这种组合通常尝试使用较简单的 Intel GPU（集成在 CPU 上）以节省电量，只在需要时才切换到 Nvidia GPU。根据笔记本品牌/型号，可能有开关来设置。例如我的笔记本托盘中有厂商软件在运行，我可以在那里切换到 Hybrid（Intel）或 Discrete（Nvidia），之后需要重启。 BIOS 中通常也有设置可以选择使用哪一个。（引自 R Burns）

此外，Nvidia 控制面板中有一项设置，可以选择哪个应用程序使用哪块 GPU。

在正确配置 Nvidia 驱动的情况下，TouchDesigner 通常默认会用 Nvidia 完成所有处理，你可以通过观察任务管理器的 GPU 图表来确认。不过在大多数此类笔记本上，Monitors DAT 对内置显示屏仍会报告 Intel，因为这些显示屏直接连接到 Intel GPU。所以，即使实际「干活」的是 Nvidia GPU，它随后也要通过 Intel GPU 把最终图像送到内置显示屏，因此 Monitors DAT 对该显示屏会继续显示 Intel GPU。但实际上这不应妨碍你。
