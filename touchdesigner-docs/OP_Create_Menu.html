OP 创建菜单

OP Create Dialog 也叫 Tab 菜单，可用于创建新的 Operators，访问方式有：

  • 在网络背景上双击
  • 按 Tab 键
  • 点击 Network Editor Pane 顶部路径旁的 + 图标
  • 在 OP 输入/输出上使用 MMB 和/或 RMB
  • 在 Wire 上 RMB → Add Operator
  • 在网络空白处 RMB → Add Operator

它让你可以访问所有操作符类型，只需点击一个名称，然后在 Network Editor Pane 上的任意位置点击，即可将其放入网络。

从 COMP TOP CHOP SOP MAT DAT 这些标题中选择 Operator Family。

生成器（没有输入的类型）以较深的色调显示，过滤器则是 OP 颜色中较浅的色调。

你可以开始输入要查找的 OP 类型名称。任何与所输入字符串匹配的 OP 类型都会以白色高亮。例如，输入 midi，所有以 midi 开头的 OP 类型都会变白。

高级选项

添加多个操作符

使用 <ctrl> 键可以一次向网络中添加多个操作符。

首先打开 OP Create Dialog。然后按住 <ctrl> 键的同时选择操作符。每点击一个操作符，它就会被添加到网络。

将多个操作符连接在一起

使用 <shift> 键可以把多个操作符连接在一起并添加到网络。

首先打开 OP Create Dialog。按住 <shift> 键，从菜单中选择操作符时，它们会被连接在一起并添加到网络。当选择不同操作符族的 OP 时，会开始一个由相连操作符组成的新分支。

另请参阅 Change OP Type Dialog
