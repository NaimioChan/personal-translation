授权加密狗

常规尺寸 - 包含确认 LED
微型尺寸 - 宽度与 USB 端口相同

随身携带的 TouchDesigner

如果你想随身携带 TouchDesigner，可选配加密狗 license，获得极致的移动性与便利性。购买加密狗后，就可以把账户中的一个许可证放到安全的 USB 授权加密狗上。安装到加密狗上的密钥，会在任何插上该加密狗的电脑上自动为 TouchDesigner 授权（前提是该电脑已安装 CodeMeter Runtime）。

TouchDesigner 或 TouchPlayer 的教育、商业或 Pro 许可证都可以转移到加密狗上。

购买加密狗

  • 从 Store 购买许可证加密狗。
  • Derivative 会联系你，从你的账户中选择一个要转移到加密狗上的许可证。现有或新的许可证均可使用。
  • Derivative 会确认收货地址，通过 International Priority 寄出加密狗，并提供跟踪单号。

将许可证加载到加密狗

新加密狗发货时不带许可证，因此在等待送达期间你仍可正常使用许可证。

加密狗到货后：

  • 使用 Key Manager 禁用你想要加载到加密狗上的许可证。
  • 发邮件到 licensing@derivative.ca，并提供：
    • 加密狗 ID
    • 你希望加载的许可证 ID

我们的团队会在 24 小时内（周一至周五）向你发送激活链接。

更新已有的加密狗

如果你已应用了 updates，或有其他想对加密狗做的改动，只需将加密狗编号或许可证 ID 通过电子邮件发送到 licensing@derivative.ca，申请 Activation Link。加密狗不会「回连」服务器，需要手动激活才能让更新生效。

（办公时间为周一至周五 10:00 - 18:00 EST，预计约 24 小时内收到链接。）

使用你已有的加密狗

如果你已有 CodeMeter 加密狗，例如 Notch 或 Disguise 附带的，可以把 TouchDesigner 许可证加载到其上。加密狗的序列号必须以 2- 或 3- 开头（较旧的 1- 开头的不受支持）。应在 Derivative 商店购买「CodeMeter Setup Fee」，然后发邮件给我们把许可证加载到你的加密狗上。

安装所需的 Codemeter 软件

要使用 USB 许可证 Dongle 或浮动云许可证，系统上需要 Codemeter Runtime 软件。

注意： 请更新到 CodeMeter Runtime 7.60+

Windows CodeMeter 安装

  • 安装 TouchDesigner 时，安装程序的第一个对话框会有一个「Install Runtime for Dongle Licensing」选项，确保勾选它。继续安装。你也可以从这里下载 dongle 运行时 CodeMeter Download。建议在 CodeMeter 安装程序选项中关闭「Automatic server search」选项，以便在安装了许多 CodeMeter 机器的网络上更快启动。

macOS CodeMeter 安装

  • 从此处下载并安装 CodeMeter Control Center：

CodeMeter Download

如果软件或服务无法启动，你可能需要在系统的 Security Preferences 中启用它。

使用加密狗

  • 将加密狗插入电脑的 USB 端口。
  • TouchDesigner 现在会使用加密狗上安装的许可证类型（即 Commercial 或 Pro 等）。

注意： 如果之前已通过 Key Manager 在电脑上安装了其他密钥，TouchDesigner 会在已安装的密钥和加密狗之间选用可用的最高密钥类型。使用加密狗时，如果不再需要已安装的密钥，可以用 Key Manager 将它们全部禁用。

通过网络共享许可证

可以将多个许可证加载到一个加密狗上（也可以 Floating Cloud Licenses），然后在启动 TouchDesigner 时分发给网络中的其他电脑。 插入加密狗的 server 电脑，会在 client 电脑请求时向其提供许可证。服务器和所有客户端电脑都需要安装 CodeMeter Runtime 软件（见上文）。 注意，这与 Cloud 许可证的 not 不同，Cloud 许可证的设置方式不一样。这里只涉及在局域网内共享物理加密狗上的许可证。

限制

  • 加载到加密狗上的所有许可证必须是同一产品，即 TouchDesigner 或 TouchPlayer
  • 加载到加密狗上的所有许可证必须是同一许可证类型，即 Educational 或 Commercial 或 Pro

服务器设置

按以下步骤设置将作为许可证服务器的电脑。

  • 将许可证加密狗插入服务器电脑。
  • 打开 CodeMeter Control Center，点击面板右下角的 WebAdmin 按钮。
  • 在 Container 标签页中检查加密狗。这可以让你查看已加载到加密狗上的许可证。

  • 转到 Configuration > Server > Server Access，然后「启用」Network Sever。点击 'Apply'。

  • 转到 Configuration > Server> License Access Permissions。
    • 在 Basic Mode Configuration 下添加你希望其访问许可证服务器的客户端电脑的 IP 地址。例如 IP 地址 192.168.1.2。点击 'Apply'。

  • 在 CodeMeter Control Center 的 Process 菜单中重启 CodeMeter 服务。

客户端设置

开始之前，请确认客户端电脑能通过网络与许可证服务器电脑通信。在许多（但并非所有）网络环境中，可以通过 ping 服务器电脑的 IP 地址来确认。

  • Install CodeMeter 并打开 CodeMeter Control Center，然后点击面板右下角的 WebAdmin 按钮。
  • 转到 Configuration > Basic > Server Search List
    • 在 Server Search List 下添加许可证服务器电脑的 IP 地址。例如 IP 地址 192.168.1.15。点击 'Apply'。

  • 按以下说明重启 CodeMeter 服务。
  • On Windows 在 CodeMeter Control Center 的 Process 菜单中选择「Restart CodeMeter Service」。

  • On macOS，转到 System Settings > General > Login Items & Extensions > CodeMeter。将选项关闭以停止服务，然后重新打开以重启服务。

  • 在 WebAdmin 窗口中，点击窗口底部的 orange-arrow icon 确认与许可证服务器的连接正常。你应该能看到许可证服务器电脑的 IP 地址显示在列表中。

连接故障排除

如果在客户端机器上获取许可证遇到问题，可以查看 CodeMeter Control Panel 中的 'Events' 标签页，了解正在发生的情况。常见原因是服务器机器的防火墙阻止了连接。请确保允许 CodeMeter.exe 应用程序通过防火墙。该 .exe 通常位于 C:\Program Files (x86)\CodeMeter\Runtime\bin\CodeMeter.exe

管理工具

在许可证服务器电脑上，你可以查看加密狗上许可证的分配情况以及网络中正在使用的许可证。

  • 转到 License Monitoring > All Licenses 查看正在使用和可用的许可证摘要。

  • 转到 License Monitoring > Sessions 获取当前正在使用许可证的每台客户端电脑的列表。点击列表中的条目会显示许可证访问时间，并提供结束该客户端电脑会话的选项。

附加信息

重要注意事项

  • 加密狗仅适用于与加载到加密狗上的许可证版本相同的 TouchDesigner 版本。要为加密狗上的 TouchDesigner 版本 upgrade，请联系我们。
  • 加密狗仅适用于在加载到加密狗上的许可证的 Update Date 之前编译的版本。当你购买「1 Year of Updates」以延长许可证、获取更新的版本时，请联系我们更新加密狗。
  • 加密狗丢失或被盗时，其上的许可证 can not be recovered。你需要购买新许可证来替换丢失的那个。
  • 转移到加密狗上的许可证不再能通过 Derivative 的在线密钥管理系统使用。如果你决定不再使用加密狗，可以联系我们从加密狗上移除许可证，它会在你的 Derivative 在线账户中重新激活。

使用加密狗的优势

  • 随身携带你的 TouchDesigner 密钥，插入任何运行 TouchDesigner 的电脑即可立即获得授权。
  • 如果某台机器使用的是 Player 许可证，插入 Designer 加密狗即可启用网络编辑器，无需关闭/重启文件。拔出加密狗后，该机器会恢复为 Player 许可证。
  • 在多电脑环境或工作室中节省时间。简化换到其他电脑的流程。
  • 在没有互联网接入的情况下很有用。通过 Key Manager 创建/移动密钥需要在线连接，而在安装和现场工作中往往无法保证。使用授权加密狗就不必担心这一点。
  • 向客户交付成品系统时更方便。运行客户项目所需的 TouchDesigner 许可证可以包含在加密狗上。这让客户更容易保留许可证，也不需要自己的 Derivative 账户。此外，更换硬件时他们无需重新授权，是更好的交钥匙方案。
  • 在需要维修或更换硬件时更省事，使用加密狗无需创建新密钥。

创建 CmDust 日志文件以调试 CodeMeter 问题

Windows

  1. 插入加密狗或安装 .wbc 凭据文件。
  2. 启动 TouchDesigner，等它完全打开后再关闭 TouchDesigner。
  3. 通过「Start | All Programs | CodeMeter | Tools」菜单项打开 CmDust。
  4. 所运行程序的输出会写入文本文件 CmDust-Result.log，并保存到用户目录，启动 CmDust 时该目录会自动打开。

macOS 在 macOS 上，使用 cmu 命令行程序创建 CmDust 文件。cmu 的调用路径已存入搜索路径。要创建 CmDust 日志，请按以下步骤操作：

  1. 插入加密狗或安装 .wbc 凭据文件。
  2. 启动 TouchDesigner，等它完全打开后再关闭 TouchDesigner。
  3. 打开命令行/终端
  4. 输入以下命令 cmu --cmdust。
  5. 使用 --file 选项可以指定名称和存储位置。-->cmu --cmdust --file CmDust.log。默认情况下，文件会显示在屏幕控制台中。
