Transform POP

摘要

Transform POP 对输入所有点的位置（属性 P）和法线（属性 N）应用平移、旋转和缩放。

它可以将变换应用到任何 float3 属性，而不仅是 P，然后输出到任何现有或新的 float3 属性，默认是 P。它可以对点、顶点或图元属性应用变换。

它可以基于 0 到 1 的 Weight 属性对点应用部分变换，使几何的某些部分受影响、其他部分不被变换。Field POP 可以生成供 Transform 使用的 Weight 属性。

Per-point mapping of parameters - 使用 Map 页，每个点都可以根据将传入属性映射到 translate、scale、rotate、pivot 等参数，为变换参数获得不同的值。所以本质上每个点都可以得到完全不同的变换。参见 Mapping POP Attributes to Parameters。

还可以通过指定 Look At 组件（通常是 Null COMP 或 Geometry COMP），并选择哪个轴指向该组件的原点，来应用进一步的变换。

还可以通过 CHOP 或 DAT 提供 16 个值的变换矩阵来应用另一个变换。

应用 translate、rotate 和 scale 参数的顺序由 Transform Order 和 Rotate Order 菜单决定。

Inverse 开关参数会应用所指定变换的逆变换。（不再是 tx=2 ry=50 sz=4，而相当于 sz=.25、ry=-50、tx=-2）

Align 页上有许多选项，可将 X、Y 或 Z 坐标对齐到输入边界框的不同侧面/中心，或对齐到参考 POP 的边界框。

另请参阅 Math Mix POP、Trig POP

Transform POP 的附加信息可通过 Info CHOP 获取。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
