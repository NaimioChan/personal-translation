CHOP 查看器

CHOP 查看器是用于预览和编辑 CHOP 通道的 2D 图表。TouchDesigner 中的任意窗格都可以设为 CHOP Viewer（快捷键 alt+5）。

CHOP 查看器的路径可以设为某个 CHOP 或某个网络。必须在 CHOP 上打开 Display Flag 才能在查看器中查看通道。当设为网络时（即没有指定具体 CHOP），查看器可显示多个 CHOP 的通道。查看器可按 3 种模式分为多个图表：Graph Per Single Channel、Graph Per CHOP 或 Graph Per Channel Name。
