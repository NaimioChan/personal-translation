Skin POP

摘要

Skin POP 接受任意二维（或更高维）的数据排列（例如三条各含 20 个点的线带），并将其连接成由三角形或四边形组成的网格。

请参阅 POP Dimension。- Dimension 是所有 POP 都具有的属性，可在 POP 的弹出信息中看到。它定义点的虚拟排列，最简单的情形是点的行和列（即两个维度）（它们如何连接并不重要）。此时总点数 = 行数 * 列数。

你可能会看到维度 10 20 3，共 600 个点。如果输入有三个或更多维度，它会对前两个维度应用蒙皮，并对每个更高维度重复此操作。

你也可以手动强制它按指定的图元数量作为一组进行蒙皮，或每隔第 N 个图元作为一组图元进行蒙皮。

如果未提供通道名称，则按顺序使用其名称。

另请参阅 Extrude POP。

参数 - Skin 页

Skin skinops - 蒙皮图元的方式。
  • All Primitives all -
  • Groups of N Primitives group -
  • Skip Every Nth Primitive skip -
N inc - 按每 N 个输入图元分组蒙皮或每隔 N 个输入图元蒙皮时的 N 值。
Closed closed - 最后一个顶点连接到第一个顶点。
Output Quads outputquads - 是否输出四边形图元而不是三角形图元。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

  • Input 0: -

Info CHOP 通道

Skin POP的额外信息可通过 Info CHOP 访问。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
