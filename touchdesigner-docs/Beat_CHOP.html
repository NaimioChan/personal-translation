Beat CHOP

摘要

Beat CHOP 生成各种斜坡、脉冲和计数器，其时序与每分钟节拍数以及 Beat Dialog 产生的同步相关。

  • 可以每 1/4、1/2、1、2、4、8、32 拍生成一个斜坡。
  • 也可以生成任意其他长度的斜坡，例如每小节 12 拍（一个斜坡），以及 3.33 拍这样的小数拍长。
  • 可以生成一组通道，其中每个通道相对于前一个通道都有延迟。例如，这适用于让八个对象各自延迟一拍依次运动。
  • 还有一个计数器，记录已生成的斜坡数量。
  • Count+Ramp 类型会生成一个持续上升的斜坡，其值等于自开始以来的周期数。
  • 如果将 Play Mode 设为 Local Sequential，它不会查看时间轴的起点/终点（即时间轴循环时不会重置），因此更适合长时间的即兴演奏。

注意： 就本对话框而言，一个 bar 为 4 拍，而 period 是由 Period 参数设置的拍数。

Beat Dialog 用于手动敲击节拍来设置每分钟节拍数（BPM）。停止敲击后，Beat CHOP 会将 BPM 转换为与音乐保持同步的重复斜坡或脉冲。

可以使用 python 命令设置全局每分钟节拍数： op('/local/time').tempo = 140

相位可通过 Beat CHOP 的 Reset 参数控制。

Beat CHOP 的时序由 Reference Node 的 Component Time 定义。如果 Reference Node 参数留空，则使用 Beat CHOP 所在位置定义的时间。默认位于 /local/time。

另请参阅：Timeline CHOP、Time COMP。

参数 - Beat 页

Reference Operator op - 此节点用于指定 Beat CHOP 所引用的时间设置。时间由位于 timepath("reference_node") 的 Time COMP 定义
Use Reference Time Slice reftimeslice - 开启此复选框以使用 Reference Node 所用的 Time Slicing。
Play Mode playmode - - 指定用于回放输出的方法。
  • Locked to Timeline locked - 此模式将输出锁定到本地组件 Timeline。在本地时间中拖动或跳转会相应地更新输出。当本地时间轴循环时，输出会重置并从头开始。每次经过本地时间轴时输出都相同。
  • Locked to Global global - 此模式将输出锁定到全局节拍源。它会跟随开启了 'Update Global' 标记的那个 Beat CHOP。
  • Local Sequential local - 此模式无论时间轴位置如何都会产生连续输出。
Period period - 生成一个斜坡周期所需的拍数。 使用下拉菜单从一些常用的 Period 长度中选择。
Multiples multiples - 要创建的通道数量。
Shift Offset shiftoffset - 按此量延迟所有通道。0 = 不变，.5 表示延后一个周期的 50%。
Shift Step shiftstep - 设为 1 且 Multiples 为 5 时，每个斜坡通道比前一个通道晚 1/5 个周期。设为 .1 时，延迟为 1/50 个周期。这是让通道错开的一种方式。
Random Offset randoffset - 每个斜坡相对于理想斜坡随机时间偏移的量。
Random Seed randseed - 更改此值会生成一组不同的随机偏移。
Reset Condition resetcondition - - 此菜单决定 Reset 输入如何触发通道重置。
  • Off to On offtoon - 当 Reset 输入由关变开时重置通道。
  • While On on - 当 Reset 输入为开时重置通道。通道将保持重置值，直到输入变为关。
  • On to Off ontooff - 当 Reset 输入由开变关时重置通道。
  • While Off off - 当 Reset 输入为关时重置通道。通道将保持重置值，直到输入变为开。
Reset Bar Value resetbarvalue - 指定满足 Reset Condition 时 Beat CHOP 会跳到哪个 Bar。Beat 值由此值的小数部分得出。
Wait after Reset resetwait - 使用 While On Reset Condition 时，开启 Wait After Reset 会将通道保持在零，直到下一个小节开始，之后输出继续。关闭 Wait After Reset 时，重置条件一结束，通道就会重新开始输出。
Reset reset - 此按钮在开启时会将斜坡重置为零。当 Beat CHOP 的输入大于 0 时，斜坡也为零。
Reset Pulse resetpulse - 立即将斜坡重置为零。
Update Global updateglobal - 任何 Beat CHOP 都可以通过开启 Update Global 成为「全局节拍源」。会在 /local/master_beat 处创建一个参考 Beat CHOP（如果尚不存在），所有 Beat CHOP 都可以通过设置 'Play Mode: Locked to Global' 与之同步。该主 Beat CHOP 也需要开启 'Update Global'（如果尚未开启）。这意味着每个 toe 需要恰好一个主 Beat CHOP。需要时可以再切回 'Play Mode: Locked to Sequential'。 $MASTER_BEAT 会被设置为开启此选项的那个 Beat CHOP。

参数 - Output 页

Ramp ramp - 每个周期输出一个 0-1 斜坡。
Pulse pulse - 每个周期输出一个脉冲。
Sine sine - 每个周期输出一个正弦波。
Count count - 每个周期递增计数。
Count+Ramp countramp - 在小节被重置前持续累加的斜坡。
Bar bar - 输出当前小节。
Beat beat - 输出当前拍。
Sixteenths sixteenths - 输出当前十六分音符。
Ramp Bar rampbar - 每小节输出一个 0-1 斜坡。
Ramp Beat rampbeat - 每拍输出一个 0-1 斜坡。
BPM bpm - 输出当前 BPM。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Beat CHOP 的额外信息可通过 Info CHOP 获取。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
