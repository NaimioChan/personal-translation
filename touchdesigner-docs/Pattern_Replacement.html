模式替换

模式替换在某些 Pattern Matching 参数之后的第二个参数中进行，例如在 Rename CHOP 中。它使用 Pattern Expansion 的功能以及模式替换特有的额外语法，构建新名称来替换匹配到的名称。这些额外语法可以提取在模式匹配期间匹配到的通配符。

语法为 * 或 ?，后跟 (wildcardIndex)。其中 wildcardIndex 是整数，表示模式匹配参数中通配符的索引。例如有三个 * 通配符，就用 *(0) *(1) 和 *(2) 来引用它们。类似地，如果有 2 个 ? 通配符，就用 ?(0) 和 ?(1) 来引用它们。

例如，如果一个 CHOP 有 3 个通道，名称为

 left_side_monitor
 right_side_projector
 top_side_led

而 'Rename From' 的内容为

 *_side_*

作为其条目。你可以使用 *(0) 和 *(1) 提取第一个 * 和第二个 * 匹配到的内容。

模式替换

 *(1)_floor_*(0)

将得到通道名称

 monitor_floor_left
 projector_floor_right
 led_floor_top

模式替换发生在：

Rename CHOP, Select CHOP, File In CHOP, Parameter CHOP

另请参阅 Script CHOP，可在其中重新创建通道名称。
