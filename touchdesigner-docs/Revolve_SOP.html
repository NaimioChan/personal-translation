Revolve SOP

摘要

Revolve SOP 旋转面以创建旋转曲面。旋转的方向和原点由辅助几何表示，其形状像一条粗线，中心有一个十字。十字表示在对话框中输入的旋转原点，线条表示方向。更改这些参数中的任何一个，辅助几何都会相应变化。

如果辅助几何过于干扰，可进入 Viewport 选项对话框并点击 Guide geometry 按钮使其不再缩进，从而禁用它。此操作是全局的，也会禁用其他 SOP 的辅助几何。

revolveSOP_Class

参数 - 页

Group group - 如果有输入组，在此字段中指定组名会让该 SOP 只作用于指定的组。接受模式匹配，详见 Pattern Matching。

参数 - Revolve 页

Connectivity surftype - 使用 Mesh Primitive Type 时，此选项用于选择曲面类型。
  • Rows rows - 创建水平线。
  • Columns cols - 创建垂直线。
  • Rows and Columns rowcol - Rows 和 Columns 都勾选。在线框显示下看起来像四边形，但所有多边形都是开放的（如果图元类型为 polygon）。
  • Triangles triangles - 用三角形构建网格。
  • Quadrilaterals quads - 生成由四边形构成的侧面（默认）。
  • Alternating Triangles alttriangles - 生成相互对置的三角形；类似 Triangles 选项。
Origin origin - - 定义旋转原点的坐标。
  • X originx -
  • Y originy -
  • Z originz -
Direction dir - - 定义旋转方向的方向向量的 X、Y、Z 坐标。
  • X dirx -
  • Y diry -
  • Z dirz -
Convert Mesh to Polygons polys - 使输出网格由独立的多边形组成。
Imperfect imperfect - 仅适用于样条。如果选中，结果为近似的非有理曲线；否则为精确的有理曲线。

参数 - Detail 页

Revolve Type type - - 确定旋转的生成方式。
  • Closed closed - 一条闭合曲线。
  • Open Arc openarc - 一段开放曲线。
  • Closed Arc closedarc - 一个开口的弧，其边缘连接到中心，形似一块馅饼。
Start End Angles angle - - 旋转的起始角和结束角。旋转从起始角开始，朝结束角推进。如果 Beginning = 0 且 End = 360，则为完整旋转。大于 360 的值也有效。
  • beginangle -
  • endangle -
Divisions divs - 生成网格表面的密度。
Order order - 如果选择了样条类型，则按此阶数构建。
End Caps cap - 如果选中，会添加分面的端盖。

操作符输入

  • Input 0: -

Info CHOP 通道

可通过 Info CHOP 访问 Revolve SOP 的额外信息。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
