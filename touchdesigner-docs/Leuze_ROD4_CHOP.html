Leuze ROD4 CHOP

摘要

注意

License: 仅在 TouchDesigner Educational、TouchDesigner Commercial 和 TouchDesigner Pro 中可用。

Leuze ROD4 CHOP 通过 TCP/IP 连接到 Leuze ROD4 激光扫描仪。Blob Tracking 模式可将测得的距离转换为 blob，用作交互表面。它应能与目前可用的任何 ROD4 扫描仪配合使用。

某些型号上提供的 'object detection' 模式目前不受支持。

Leuze 可以与 Blob Track CHOP 配合使用，以检测其视野中的对象。参见 Blob Track 的 OP Snippet。

leuzerod4CHOP_Class

参数 - ROD4 页

Active active - 开启时，CHOP 从扫描仪接收信息。关闭时，网络连接断开，不再更新。
Network Address netaddress - ROD4 扫描仪的 IP 地址。
Network Port port - 扫描仪的网络端口。
ROD4 Protocol rod4porotocol - - 选择使用哪种协议。这必须与扫描仪在设备的 RODplussoft 设置工具中所设的协议一致。如果选错协议，你可能仍会得到某种数据，但数据将是随机且错误的。
  • Binary ROD4 compatible binary -
  • ROD4plus ASCII-Remote ascii -
Input Coordinate inputcoordinate - - 在使用 ROD4plus ASCII-Remote 协议时可用，指定使用极坐标还是笛卡尔坐标输入。这必须与扫描仪在设备的 RODplussoft 设置工具中所设的坐标一致。
  • Polar polar -
  • Cartesian cartesian -
Output Mode outputmode - - 为输出通道选择 Raw Data 或 Blob Tracking 模式。以下参数仅在 Blob Tracking 模式下可用。
  • Raw Data rawdata - 长度为 529 个采样的 CHOP，包含扫描仪测得的每个点的原始 X/Y 位置，单位为米。
  • Blob Tracking blobtracking - 原始数据会被分析，找出彼此靠近的点，将其转换为 blob 并分配唯一 ID。
Max Blobs maxblobs - 可跟踪的最大斑块数量。
Max Point Distance in Blob maxpointdistance - 扫描仪测得的两个点如果距离等于或小于此值，就被视为同一个 blob 的一部分。距离以米为单位。
Max Blob Movement maxblobmovement - 以米为单位。控制 blob 在连续帧之间最多可以移动多远，仍被视为同一个「blob」。
Area of Interest areaofinterest - - 限制跟踪 blob 的区域。
  • Off off - 无限制，在整个扫描区域跟踪斑块。
  • Distance Based distancebased - 仅在距扫描仪指定距离内跟踪 blob。
  • Bounding Box boundingbox - 仅在指定的边界框内跟踪 blob。
Max Distance maxdistance - 当 Area of Interest 参数设为 Distance Based 时，跟踪 blob 的最大距离。
Lower Left Corner lowerleft - - 指定当 Area of Interest 参数设为 Bounding Box 时所用边界框的左下角。
  • lowerleft1 -
  • lowerleft2 -
Upper Right Corner upperright - - 指定当 Area of Interest 参数设为 Bounding Box 时所用边界框的右上角。
  • upperright1 -
  • upperright2 -
Allow Movement Outside Area allowmovementoutside - 开启时，在感兴趣区域内检测到的斑块可以移出该区域并仍被跟踪。关闭时，移出感兴趣区域的斑块将停止跟踪。
Bounding Box Mask TOP boundingboxmask - 指定一个 TOP 作为边界框的遮罩，用于 Area of Interest 参数设为 Bounding Box 时。任何非零值的像素都被视为感兴趣区域的一部分，任何为 (0,0,0) 的像素则被视为不在感兴趣区域内。无论 TOP 的分辨率/宽高比如何，TOP 都会被拉伸以适配指定的边界框。该 TOP not应每帧计算，因为那会让 ROD4 CHOP 变得非常慢。
Rotate Incoming Coordinates rotate - 旋转所有传入坐标，其中 tx 和 ty 值围绕垂直的 z 轴旋转。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Leuze ROD4 CHOP 的附加信息可以通过 Info CHOP 获取。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
