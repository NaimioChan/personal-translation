可缩放用户界面

TouchDesigner 使用 Zoomable User Interface 或 Zooming User Interface（ZUI）在项目的网络中导航，并与 Node Viewers 交互。鼠标中键（和滚轮）控制所选界面的缩放级别。

你可以使用滚轮在缩放时进入 Components。类似地，如果向外缩放，就会上移到父级网络。此项以及其他可调整的鼠标滚轮与网络缩放交互设置位于 Edit > Preferences > Network 下。
