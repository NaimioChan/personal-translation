Audio File In CHOP

摘要

Audio File In CHOP 从磁盘上的文件或 http:// 地址读取音频。支持 .mp3、.aif、.aiff、.au 和 .wav 类型的文件。它始终输出时间切片音频数据。如果要录制数据，请使用 Record CHOP 或 Movie File Out TOP。

从影片文件读取请参见 Audio Movie CHOP。通过 OSC 接收音频流请参见 OSC In CHOP。

对于大文件，Audio File In CHOP 会从磁盘流式读取文件，因此无需将整个文件载入内存。

  • 它从磁盘和 http: 位置流式读取文件（后者会先复制到本地磁盘）——每次只在内存中保留几秒钟。
  • 支持的音频文件为 .mp3 .aif .aiff .wav 和其他 audio formats。
  • 它还可以仅播放 TouchDesigner 支持的任何影片文件中的音频，例如 .mov, .mpg .mp4。另请参见 Audio Movie CHOP，用于将影片文件的音频与其视频同步播放。
  • 音频文件可以拖放到 TouchDesigner 上、双击（如果愿意），或右键选择 Open With... TouchDesigner。

参数 - Audio File In 页

File file - 源文件的路径。
Reload reloadpulse - 立即从磁盘重新加载文件。
Play play - 设为 1 时音频会播放，设为 0 时停止。
Play Mode playmode - 指定播放音频所用的方法，共有 3 个选项。
  • Locked to Timeline locked - 此模式将播放位置锁定到时间轴。在时间轴中拖动或跳转会相应地改变乐曲位置。此模式下 Play、Reset、Speed 和 Index 参数被禁用，因为时间轴直接与播放位置绑定。
  • Specify Index specify - 此模式允许用户使用下方的 Index 参数指定乐曲中的特定位置。对音频流中任意位置进行随机访问时使用此模式。
  • Sequential sequential - 此模式持续播放，与时间轴位置无关（Index 参数被禁用）。下方的 Reset 和 Speed 参数被启用，可提供一定控制。
  • Timecode Object/CHOP/DAT timecodeop - 此模式允许用户通过引用时间码来设置影片索引，时间码可以是 CHOP、DAT 或 Timecode Class 对象。
Speed speed - 这是一个速度倍率，仅在 Play Mode 为 Sequential 时生效。值 1 为默认播放速度。值 2 为双倍速度，0.5 为半速，依此类推。此节点无法反向播放音频，因此负值效果不佳。
Cue cue - 设为 1 时跳转到 Cue Point。仅在 Play Mode 为 Sequential 时可用。
Cue Pulse cuepulse - 立即跳转到 Cue Point。
Cue Point cuepoint - 将歌曲中的任意索引设为跳转点。
Cue Point Unit cuepointunit - 设置 Cue Point 参数时使用的单位。
Index index - 当 Play Mode 设为 Specify Index 时，此参数直接设置歌曲位置。右侧的单位菜单可让你用以下单位指定索引：Index、Frames 或 Seconds。
Index Unit indexunit - Index 参数所用的单位。
Timecode Object/CHOP/DAT timecodeop - 通过引用时间码设置音频文件索引。应引用带 'hour'、'second'、'minute'、'frame' 通道的 CHOP、首格含时间码字符串的 DAT，或 Timecode Class 对象。
Repeat repeat - - 到达末尾时循环播放音频流。
  • Off off -
  • On on -
Trim trim - 启用下方的 Trim 参数。
Trim Start trimstart - 从音频开头设置一个 In 点，用于修剪音频流的起始位置。右侧的单位菜单可让你用索引、帧或秒指定此位置。
Trim Start Unit trimstartunit - Trim Start 参数所用的单位。
Trim End trimend - 从音频末尾设置一个 Out 点，用于修剪音频流的结束位置。右侧的单位菜单可让你用索引、帧或秒指定此位置。
Trim End Unit trimendunit - Trim End 参数所用的单位。
Pre-Read Length prereadlength - 为保持播放流畅而缓冲的音频量。这会略微影响内存占用，但并not会在音频中造成任何延迟。
Pre-Read Length Unit prereadlengthunit - Pre-Read Length 参数所用的单位。
Open Timeout opentimeout - TouchDesigner 等待音频文件打开的时间（毫秒）。若达到 Open Timeout 时间，Audio File In CHOP 将停止等待，并播放静音。如果下次该 CHOP 计算时文件仍未打开，它会再次等待，并重复此过程。它会一直这样做，直到文件打开或打开失败。
Mono mono - 即使文件有多个通道，也只输出单声道通道。
Volume volume - 设置文件的读入电平。值为 1 为满信号，0 为静音。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
