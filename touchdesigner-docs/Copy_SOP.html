Copy SOP

摘要

Copy SOP 可以复制其他 SOP 的几何，并对每个副本应用变换。

它还可以把几何复制到输入模板上的点。

copySOP_Class

参数 - Copy 页

指定要复制到其上的模板图元子集。接受模式匹配，说明见 Pattern Matching。

Source Group sourcegrp - 指定要复制其内容的输入图元子集。接受模式匹配，说明见 Pattern Matching。
Template Group templategrp - 指定要复制到其上的模板图元子集。接受模式匹配，说明见 Pattern Matching。
Number of Copies ncy - 设置源的副本数量。对于模板输入，它指定在每个模板点处放置的副本数量。
Primitives per Point nprims - 定义从每个点复制多少个图元。
Rotate to Normal nml - 仅在指定了模板输入时使用。如果模板是球体，而第一个输入是圆，则会在球体的每个点处放置一个圆。开启此选项后，所有圆都会重新调整朝向，以面向球体表面（默认球体的法线从中心向外辐射）。

如果模板几何上存在 up 属性，则该属性会（与法线一起）用于完整定义副本的旋转。up 属性可通过 Point SOP 创建。

Transform Cumulative cum - 每个变换都在前一个变换留下的位置上“叠加”。Copy SOP 生成新副本时，变换是累积的。

参数 - Stamp 页

TouchDesigner 中任何参数都允许 stamping。唯一要求是，被 stamp 的参数在某种程度上位于执行 stamping 的 Copy SOP 的上游。

Stamp Inputs stamp - 启用后，会为每个被复制的输入 stamp 前面的变量。
Copy copy - stamp 变量序列
Param copy0param - 每个 stamp 变量的标记。被 stamp 的参数可在 python 中通过 td Module 里的全局 fetchStamp() 方法访问，或在 tscript 中通过 param() 访问。见下方示例。
Value copy0value - 每个 stamp 变量的值。被 stamp 的参数可在 python 中通过 td Module 里的全局 fetchStamp() 方法访问，或在 tscript 中通过 param() 访问。见下方示例。

参数 - Attributes 页

此页可用于决定模板几何上的点属性如何影响源几何上的属性。模板属性可以通过四种方式修改源：

  • Set - 覆盖源属性。
  • Multiply - 与源属性相乘。
  • Add - 加到源属性上。
  • Sub - 从源属性中减去。

只需在相应字段中输入值，模板点属性就能影响源几何中的点、图元或顶点属性。

提示

可以使用 me.copyTotal python 成员来计算给定副本数量下的旋转角度。例如，如果有 28 个副本，可以把旋转设为：360/me.copyTotal —— 这样会自动得到 12.8571 度，将 28 个副本均匀分布在圆周上。

把 Particle SOP 用作 Template 对象，可以把 Copy Data 输入中定义的对象复制到每个粒子模板上。例如，可以用它把一只蜜蜂复制到每个粒子上，形成一群蜜蜂。

绕轴制作一系列副本，并对它们蒙皮，以获得类似车削的效果，类似于 Revolve SOP 得到的结果。

示例

创建 Stamped 几何

  1. 放置一个 Circle SOP，并将其类型设为 Polygon。
  2. 将 Circle 的 Divisions 设为：fetchStamp("sides",3) 方法 fetchStamp() 返回全局参数 sides 的值。如果尚未定义，则返回 3。
  3. 追加一个 Copy SOP，将 Number of Copies 设为 5；并将 Translate X 设为：2.5 。
  4. 在 Copy SOP 的 Stamp 页中开启 Stamp Inputs。将 Param 1 设为：sides 和 me.copyIndex+3
  5. 这会在第一个 stamp 副本上创建一个三角形；在下一个上创建一个正方形；在第三个上创建一个五边形，依此类推。每个副本的几何都会单独计算。

你可以一次设置多个 stamp Param，它们可以在副本输入的整个祖先链中的任何位置使用。

Info CHOP 通道

Copy SOP 的附加信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
