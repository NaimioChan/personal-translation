File In CHOP

摘要

File In CHOP 读入供 CHOP 使用的通道和音频文件。文件可从磁盘或网络读取。指定 URL 时使用 http://。

有效格式

关于 CHOP 所有有效格式的完整列表，参见 File Types 一节。可读入 CHOP 的文件类型包括：

  • .chan - 原始 ASCII 通道文件；每帧一行数字。通道自动命名。
  • .clip .bclip - TouchDesigner 原生 CHOP 剪辑文件。
  • .aiff - 音频文件。
  • .wav - 音频文件。

输出通道文件

通过选择 Save Data Channels，可以从 CHOP 上的 RMB 菜单输出相同的文件。

其他输入设备

关于 MIDI 文件（.mid 或 .midi），参见 MIDI In CHOP。

参数 - File In 页

Channel File file - 要加载的文件名。指定 URL 时使用 http://。
Name Options nameoption - 用此菜单控制已加载通道的名称。
  • Use Names In File infile - 使用文件中存储的通道名称。
  • Use New Names new - 使用 Name 参数中指定的名称。
  • Use Filename filename - 使用文件名作为已加载通道的名称。
Name name - 当 Name Options 参数设为 Use New Names 时，用于命名通道。
Rate Options rateoption - 用此菜单调整已加载通道的采样率。
  • No Change nochange - 采样率取自文件。
  • Override override - 采样率设为 Sample Rate 参数中的数值，但文件中的通道不重采样。
  • Resample resample - 按指定的 Sample Rate 重采样。取文件中的通道和采样率，重采样到所需采样率。这可避免在内存中不必要地使用超大数组。
Sample Rate rate - 每秒采样数，由 Rate Options 参数使用。
Extend Left left - 左侧延伸条件（范围之前/之后）。
  • No Change asis - 保持通道原样。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道起点之前的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常数值
Extend Right right - 右侧延伸条件（范围之前/之后）。
  • No Change asis - 保持通道原样。
  • Hold hold - 保持通道的当前值。
  • Slope slope - 延续通道终点之后的斜率。
  • Cycle cycle - 反复循环该通道。
  • Mirror mirror - 反复循环该通道，每隔一个循环镜像一次。
  • Default Value default - 使用 Default Value 参数中指定的常数值
Default Value defval - 用于 Default Value extend 条件的值。
Rename from renamefrom - 要重命名的通道模式。见 Pattern Matching。
Rename to renameto - 名称的替换模式。默认参数不会重命名通道。见 Pattern Replacement。
Value Override Pattern overridpattern - 要应用 Override Value 的通道作用域。
Override Value overridevalue - 由上面的 Value Override Pattern 参数赋予作用域内通道的值。
Refresh refresh - 当此参数设为 On 时重新加载文件。
Refresh Pulse refreshpulse - 立即从磁盘重新加载文件。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

File In CHOP 的额外信息可通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
