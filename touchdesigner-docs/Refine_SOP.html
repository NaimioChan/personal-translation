Refine SOP

摘要

Refine SOP 允许你在不改变形状的情况下增加任何 NURBS、Bzier 或曲面/多边形表面或面的 CV 数量。它也用于在给定容差内减少 CV 数量（即一种简单但快速的数据精简方法）。

细化与反细化的区别

细化和反细化都作用于面（多边形、Bzier 曲线和 NURBS 曲线）和曲面（图元网格、Bzier 曲面和 NURBS 曲面）。要反细化一个面或曲面，你需要指定参数区间（而不像细化那样只指定单个值）。这允许你在任意区间内反细化图元，无论是局部还是整体。例如，要反细化整个图元，选择 0 和 1 作为两个参数边界；[0,0.5] 只反细化图元的第一个参数半段。

区间边界由 First/Second U/V 字段给出。由于细化不需要区间，Second U/V 字段默认禁用。

Tolerance 控件仅用于反细化，不用于细化。细化不需要容差，因为它生成的曲线或曲面在数学上与原始完全一致。然而反细化可能会在给定区域平滑（或「熔化」）原始形状。简而言之，反细化是有损的；细化不是。

参数 - 页

Group group - 如果存在输入组，在此字段中指定组名将使该 SOP 仅作用于指定的组。接受模式匹配，说明见 Pattern Matching。
First U firstu - 启用或禁用 First U 控件。
First U domainu1 - 指定完成操作的起始/结束位置。选择此项，并指定 0 到 1 之间的参数化 U 位置。
Second U secondu - 启用或禁用 Second U 控件。
Second U domainu2 - 指定完成操作的起始/结束位置。选择此项，并指定 0 到 1 之间的参数化 U 位置。
U Divisions divsu - 如果进行细化或细分，此选项指定在 First U 与 Second U 之间执行的细化次数。
First V firstv - 启用或禁用 First V 控件。
First V domainv1 - 指定完成操作的起始/结束位置。选择此项，并指定 0 到 1 之间的参数化 V 位置。
Second V secondv - 启用或禁用 Second V 控件。
Second V domainv2 - 指定完成操作的起始/结束位置。选择此项，并指定 0 到 1 之间的参数化 V 位置。
V Divisions divsv - 如果进行细化或细分，此选项指定在 First V 与 Second V 之间执行的细化次数。

参数 - Refine 页

如果启用，将在上述位置细化图元。如果图元是 NURBS，则会如下所述多次插入一个节点。

NURB Count U refineu - 细化 NURBS 时，在 U / V 基的每个位置插入的节点数量。
NURB Count V refinev - 细化 NURBS 时，在 U / V 基的每个位置插入的节点数量。
Spacing space - - 指定如何沿样条/曲线测量。
  • Uniform Domain Lengths domain - 如果细化样条，则在相等的基区间处细化。
  • Uniform Arc Lengths arc - 每次细化在最大节点跨度（样条）或边长（多边形）的中心进行。

Note: Uniform Domain Lengths should be selected if the domain ranges are animating, otherwise the inserted points will be undeterminable as different maximum lengths are encountered.

参数 - Unrefine 页

如果启用，将从 First U 与 Second U、First V 与 Second V 之间的任何 NURBS 曲线或曲面、多边形或网格中移除 CV（移除点/行）。

NURB Count U unrefineu - 细化 NURBS 时，在 U / V 基的每个位置移除的节点数量。
NURB Count V unrefinev - 细化 NURBS 时，在 U / V 基的每个位置移除的节点数量。
Tolerance U tolu - 仅移除会使曲线、多边形或曲面变化超过此距离的节点。
Tolerance V tolv - 仅移除会使曲线、多边形或曲面变化超过此距离的节点。

参数 - Subdivide 页

Subdivide 对图元进行细化，使得一旦发生位移，细分就会造成急剧的不连续。本质上，对多边形和 Bzier 而言细分等同于细化，因为任何细化都会造成潜在的不连续。对于 NURBS，它等同于最大细化（即 count = 图元基阶数 - 1）。

Spacing subdivspace - - Subdivide 对图元进行细化，使得一旦发生位移，细分就会造成急剧的不连续。本质上，对多边形和 Bzier 而言细分等同于细化，因为任何细化都会造成潜在的不连续。对于 NURBS，它等同于最大细化（即 count = 图元基阶数 - 1）。
  • Uniform Domain Lengths domain - 如果细化样条，则在相等的基区间处细化。
  • Uniform Arc Lengths arc - 每次细化在最大节点跨度（样条）或边长（多边形）的中心进行。

如果域范围在动画中变化，应选择 注意： Uniform Domain Lengths，否则由于会遇到不同的最大长度，插入的点将无法确定。

Info CHOP 通道

Refine SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
