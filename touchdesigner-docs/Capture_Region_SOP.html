Capture Region SOP

摘要

Capture Region SOP 定义捕获区域（cregion），它是一种图元，可以看作改造过的管状图元（两端各带半个球的管）。管两端的半球称为「cap」。与其他图元一样，每个 Capture Region 都有图元编号，并可赋予图元属性。Capture Region 就是一个体积，用于定义几何的点捕获权重，随后对它做动画来使几何变形。

Capture Region 始终以线框显示（即使在着色模式下），以便你专注于该区域所作用的几何。

参数 - Region 页

有若干参数用于控制捕获区域的大小、形状和位置。区域的上半部分和下半部分有各自独立的控件。这样你在制作角色时可以一次编辑骨骼的一侧。

Max/Min Weight 参数用于点的权重计算。点越靠近区域边缘，其权重越小。默认情况下，沿区域中心轴的权重为 1（后文详述），区域边缘的权重为 0。你可以通过此参数修改这两个权重极值。

权重的计算方式

权重基于到区域中心线的距离。中心线的长度就是管的高度，并沿管的中心延伸。从横截面看，管身部分的距离是相对中心线垂直测量的，半球部分的距离则沿半径方向测量。下图展示了这一方案。图中的线表示区域边缘上各点的距离。

Info CHOP 通道

Capture Region SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
