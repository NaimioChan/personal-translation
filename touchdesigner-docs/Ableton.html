Ableton

Ableton Live 是 [Ableton] 出品的数字音频工作站（DAW）软件，用于创作和演出音乐与音频声景，支持大量音频设备、插件以及 Ableton Link 协议。 它既是为现场演出设计的乐器，也是用于作曲、录音、编曲、混音和母带处理的工具。

TDAbleton 是一个把 TouchDesigner 与 Ableton Live 紧密结合的工具。它提供对 Ableton set 中几乎所有内容的完整访问。

Ableton Link CHOP 从 [Ableton Link] 支持的网络中获取时序信息。
