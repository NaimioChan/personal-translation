DMX In CHOP

摘要

DMX In CHOP 从 DMX、Art-Net、sACN 或 KiNET 设备接收通道。DMX 的通道值为 0-255。请注意，输入速率受 DMX 最高 44Hz 刷新率的限制。

可以在一个 DAT 中提供 Filter Table，通过为每个通道添加行并指定 net、subnet 和 universe 来指定地址。此外，还可以用 srcaddress 和 destaddress 列过滤数据包，只有源 IP 地址和目标 IP 地址都匹配的数据包才会被接受。这些列的单元格值应为单个 IP 地址（即支持 Pattern Matching not）；如果留空，则会接受所有数据包。

当网络中存在需要滤除的 DMX 噪声时，srcaddress 列很有用；可以在 srcaddress 单元格中指定所需控制器的 IP。id 列应与 srcaddress 和 destaddress 配合使用，以提供唯一的通道后缀。

Wireshark 是排查网络问题的有用工具。在 Art-Net 的情况下，可以方便地用 artnet、dmx 或 dmx_chan 过滤数据包。

ENTTEC NOTE: - 使用 ENTTEC 的 NMU (Node Management Utility) 来配置和检查网络中发现的 ENTTEC 设备。

另请参阅：DMX Out POP、Art-Net、DMX Out CHOP、DMX

参数 - Port 页

Active active - 开启时连接到设备。
Interface interface - - 选择连接设备所用的接口类型。
  • Enttec Generic Serial serial - 使用操作系统的串口调用读取数据。
  • Enttec USB Pro enttecusbpro -
  • Enttec USB Pro Mk2 enttecusbpromk2 -
  • Art-Net artnet - 把接口设为 Art-Net 协议。
  • sACN sacn - 把接口设为 sACN 协议。
  • KiNET kinet - 把接口设为 KiNET 协议。
KiNET Version kinetversion - - 设置要使用的 KiNET 协议版本。
  • DmxOut (v1) v1 -
  • PortOut (v2) v2 -
Device device - 从菜单中选择 DMX 设备。
Serial Port serialport - 当 Interface 参数设为 Generic Serial 时，该参数让你选择使用哪个串口（COM）。
Format format - - 在 Packet Per Sample（按时间切片）、Packet Per Channel (Latest) 或 Packet Per Channel (All) 之间选择。选择 Packet Per Channel (Latest) 时，上次计算之外的消息都会被丢弃；而 Packet Per Channel (All) 会补上原本会因丢帧而被跳过的通道。
  • Packet Per Sample (Timesliced) packetpersample -
  • Packet Per Channel (Latest) packetperchan -
  • Packet Per Channel (All) packetperchanall -
Art-Net Net (0-127) net - 当 Interface 参数设为 Art-Net 时，此项设置 net 地址。一个 net 是 16 个连续 subnet 或 256 个连续 universe 的组。该参数的取值范围为 0-127。这not网络 IP 地址。
Art-Net Subnet (0-15) subnet - 当 Interface 参数设为 Art-Net 时，此项设置 subnet 地址。一个 subnet 是 16 个连续 universe 的组。该参数的取值范围为 0-15。这not网络子网掩码。
Art-Net Universe (0-15) universe - 当 Interface 参数设为 Art-Net 时，此项设置 universe 地址。一个包含 512 个通道的 DMX512 帧称为一个 universe。该参数的取值范围为 0-15。
Filter Table filterdat - 当 Art-Net 或 sACN 使用 Packet Per Channel 格式时可用。使用停靠的 Table DAT 指定从哪些 net、subnet、universe 通道接收。

注意： 对 sACN 来说，第一个可用的 universe 索引为 1，因为 universe 0 被系统保留供将来使用。

Net Name netname - 指定地址中 net 部分的通道前缀。
Subnet Name subnetname - 指定地址中 subnet 部分的通道前缀。
Universe Name universename - 指定地址中 universe 部分的通道前缀。
KiNET Port Name kinetportname - 指定地址中 KiNET 端口部分的通道前缀。
Start Codes startcodes - 使用 sACN 时可接受的起始代码列表。如果 DMX In CHOP 收到的 sACN 数据包的起始代码不在列表中，就会将其丢弃。
Multicast multicast - 为 sACN 启用多播。多播会根据设备的 Net、Subnet 和 Universe 自动构建 IP。这样 DMX In CHOP 就能在不知道发送方地址的情况下自动接收。
Queue Size queuesize - 使用 Art-Net 或 sACN 接口时，此项设置传入数据包队列的大小。可用于平滑数据，但延迟会更高。在 Packet Per Channel (All) 的情况下，该参数控制每次计算最多创建的数据包数量。
Rate rate - 把传入数据重采样到该速率。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

DMX In CHOP 的额外信息可通过 Info CHOP 查看。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
