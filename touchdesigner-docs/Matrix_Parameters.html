矩阵参数

若干节点（例如 GLSL TOP、Camera COMP、Geometry COMP）拥有接受矩阵的参数。TouchDesigner 参数中的矩阵可以用几种不同方式指定

Python tdu.Matrix

tdu.Matrix 对象可以手动构建，也可以从 ObjectCOMP Class 及其派生 COMP 的多种方法中获得。矩阵参数可以引用 Python tdu.Matrix，既可以直接引用返回矩阵的成员/方法，也可以引用已放入 Storage 中的矩阵。

E.g 

 m = tdu.Matrix()
 m.translate(5, 0, 0)
 m.rotate(0, 45, 0)
 op('someNode').store(‘xformMat’, m)

而在节点参数中你要填入： 

 op('someNode').fetch(‘xformMat’)

Table DAT

Table DAT 可用于指定矩阵，形式为 4x4 表格。平移应放在最后一列，这意味着采用在矩阵右侧相乘向量/点的惯例（与 GLSL 相同）。

CHOP

如果使用 CHOP，矩阵的 16 个元素取自该 CHOP 的前 16 个通道。每个通道只使用第一个采样。矩阵数据的排布方式是第 13、14、15 个通道包含平移。这既可以看作列主序、也可以看作行主序惯例，即按列或按行读取通道。

如果你用 DAT to CHOP 从 Table DAT 转换，需要用 Transpose DAT 让通道顺序正确。
