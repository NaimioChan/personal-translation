OAK Device CHOP

摘要

OAK Device CHOP 是与 OAK 摄像机交互的主要接口。它还实现了 Timer CHOP 的许多功能，例如计时计数器、脉冲和自定义 Python 回调。

基本用法

在启动 TouchDesigner 之前，通过 USB 或以太网供电（PoE）将 OAK 设备连接到计算机。如果在 TouchDesigner 运行期间连接设备，应脉冲 OAK Device CHOP 上的 Refresh Device List 参数。接下来，自定义 Python createPipeline 回调，并脉冲 start 参数以启动摄像机。摄像机运行时保存项目是可以的。下次打开项目时，摄像机会知道要自动启动。

分辨率与 ISP 缩放

depthai python 模块有一个用于 RGB 分辨率的枚举：dai.ColorCameraProperties.SensorResolution。该枚举目前包括 THE_1080_P、THE_1200_P、THE_4_K 以及许多其他值。这些选项未必与你的 OAK 硬件兼容。最常用的 RGB 分辨率是 1080p。你可以通过 ISP 缩放选择较低的分辨率来节省带宽。为 THE_1080_P 选择 (2, 3) 会得到 1280x720 的图像。

配置

DepthaiTestSuite.toe 项目包含若干基础组件，它们通过 OAK Device CHOP 发送消息，帮助控制 OAK 摄像机的设置。例如，oakDeviceConfig 基础组件让用户可以设置设备的 XLinkChunkSize、日志级别和红外激光设置。oakCameraControl 基础组件帮助控制 RGB 摄像机设置。oakStereoDepthConfig 基础组件帮助控制立体深度设置。摄像机运行期间也可以使用这些配置。

优化延迟与 FPS

Luxonis 有一个关于 low latency 的教程。在某些情况下，例如串流 4K 视频时，你会希望把 XLinkChunkSize 设为零。这可以通过 oakDeviceConfig 完成。

创建 depthai 管线时，可以为 ColorCamera 节点等各种节点设置 FPS 目标。一般而言，管线加载到摄像机之后 FPS 就无法更改。应选择较高的 FPS 值，但要记住，如果把这些数字推得太高，Info CHOP 显示的有效 FPS 可能会开始下降。

参数 - Stream In 页

名为 Stream In 的内置页用于帮助把 RGBA 8 位图像从 TouchDesigner 发送到 OAK 摄像机。你可以指定一个 TOP、一个流名称，以及以赫兹为单位的发送频率。如果流名称为空，则不会发送任何内容。向 OAK 发送图像时，TouchDesigner 会把输入图像转换为 BGR 格式。这很方便，因为可以在 OAK 摄像机上运行的大多数神经网络都期望输入图像为 BGR 格式。如果你需要图像是其他格式，应在 depthai 管线中使用 ImageManip 节点来更改格式。

Stream stream - 流信息参数的序列
Name stream0name - 指定可接收纹理的流名称。需要在 depthai 管线中创建一个 XLinkIn 节点来创建该流：pipeline.create(dai.node.XLinkIn)
Frequency (Hz) stream0frequency - 指定把纹理发送到 OAK 设备的频率。
TOP stream0top - 指定包含要发送到该流的纹理的 TOP 操作符。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

oakdevice CHOP 的额外信息可以通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
