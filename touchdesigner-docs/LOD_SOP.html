LOD SOP

摘要

LOD SOP 的特殊之处在于它实际上不改变任何几何。它为输入对象构建细节层级缓存。绘制哪个缓存取决于到摄像机的距离。因此，复杂对象在较远时会以较低的细节层级绘制。

第二个输入是 Rest Geometry。如果提供，将使用此几何执行（开销较大的）多边形减面，并且只使用左侧输入的点。

lodSOP_Class

参数 - 页

Step % steppercent - 每个后续细节层级包含的多边形数约为上一层级数量的这个百分比。
Dist. Threshhold distance - 这是呈现完整细节时距摄像机的距离。
Minimum % minpercent - 对象绘制时不会少于这个多边形数量。
Stiffen Border borderweight - 避免边界多边形被侵蚀的权重。
Equalize Edges lengthweight - 偏向大小均匀的多边形的权重。
Pre-Triangulate triangulate - 只有三角形才能被减面。因此此选项会先将多边形转换为三角形。
Optimize Rendering tstrips - 设置后，将生成三角形带并用于绘制。
Only Affect Polygons polysonly - 如果启用，在较低细节层级只显示模型的多边形部分。否则，所有类型的表面都会受距摄像机距离的影响。

Info CHOP 通道

可通过 Info CHOP 访问 LOD SOP 的额外信息。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
