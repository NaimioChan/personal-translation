Write a CPlusPlus CHOP

概述

Make sure you've read through Write a CPlusPlus Plugin first for general information about writing a plugin for a CPlusPlus CHOP.

CPlusPlus CHOP 允许你使用自定义代码操作 CHOP 数据，或将 CHOP 数据输入和输出到外部来源或文件格式。

输出通道

你可以使用 CHOP 的某个输入来确定输出的通道数、通道名、采样率等，也可以在代码中（在 getOutputInfo() 中）指定它们。

入门时，输出非 Time Sliced 数据要容易得多，此时你指定通道长度，每帧只填充相应数量的数据。不过 TouchDesigner 安装包附带的示例会输出一个 Time Slice 以作说明。

时间切片数据

如果你不熟悉什么是时间切片，参见 Time Slicing 文章。

如果插件输出的是时间切片数据，TouchDesigner 会告诉你需要输出多少采样。采样数取决于距 TouchDesigner 上次计算过了多久（由于跳帧），以及 Time Slice 的采样率与 CHOP 的采样率之比。例如，假设 CHOP 输出 120hz 采样率的数据，而 Timeline 以 60hz 运行。如果 TouchDesigner 跳过了上一帧的计算，Time Slice 大小将为 2 帧长。由于 CHOP 的采样率是 120hz 而时间轴是 60hz，你将被要求为每个通道提供 4 个采样数据来填充时间切片。
