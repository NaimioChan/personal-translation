表达式

TouchDesigner 中的表达式是一个文本字符串，其中包含数据（字符串、浮点数、列表、布尔值等）和运算符（+ * < 等），由 operator's language（python 或 Tscript）求值，并返回字符串、浮点数列表或布尔值等。

表达式用于 Parameters、DATs（尤其是 Evaluate DAT）、Tscript Commands 和 Scripts。

关于 Python 表达式，参见 Python。

有一个 Python 表达式执行引擎用于提升 Python 表达式的性能，详情见：Optimized Python Expressions

关于 Tscript 表达式，参见 Tscript Expressions。
