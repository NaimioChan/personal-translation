Magnet SOP

摘要

Magnet SOP 允许你使用由 metaball 场定义的「磁场」影响范围，用另一个对象影响输入几何的形变。它可以在对象内创建动画的凸起和凹陷，以及其他特效。

需要注意的是，实际的形变来自 Magnet SOP 的 Translate 参数，而不是来自 metaball。metaball 定义 Magnet SOP 的 Translate 参数的作用区域。metaball 的权重决定 Magnet SOP 中 Translate 的效力。

磁力在 metaball 场的中心最强，并在场的边缘衰减为零。

Translate t - - 这三个字段在三个轴上移动 Source 几何。metaball 的 Translates 只影响影响区域的位置。影响本身由 Magnet SOP 内部的假想磁体提供，此影响的姿态由 Magnet SOP 的 Translates 决定。

参数 - Attributes 页

Affect Position position - 允许磁体影响输入几何的位置。默认启用。
Affect Point Color color - 允许磁体影响输入几何的点颜色。

提示： 当启用 Affect Point Color 选项时，若要控制每个磁体对表面 Point Color 的贡献，请在 Magnet SOP 之前使用 Point SOP 将点颜色设为黑色（0,0,0）。随后 Magnet SOP 中的 Translate 字段会为每个点添加 rgb 颜色，其值为 2,2,2 并接近白色。

磁体的 scale 和 rotate 通道会在 3D 色彩空间中移动你。不推荐这样做。

Affect Point Normal nml - 允许磁体影响输入几何的点法线。
Affect Point Velocity velocity - 允许磁体影响输入几何的速度。

Info CHOP 通道

Magnet SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
