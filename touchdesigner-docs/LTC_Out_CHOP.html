LTC Out CHOP

摘要

LTC Out CHOP 输出「线性时间码」，即编码在音频信号中的 SMPTE 时间码数据。另请参阅 Linear Timecode。

使用 Info CHOP 确定当前正在输出哪些值。

此 CHOP 的输出可以发送到 Audio Device Out CHOP。

另请参阅：LTC In CHOP

ltcoutCHOP_Class

参数 - LTC 页

Play Mode playmode - 指定输出 LTC 的方法，有 2 个选项。
  • Sequential sequential - 此模式持续向前播放。
  • Timecode Object/CHOP/DAT timecodeop - 此模式允许用户通过引用时间码来设置 LTC 值，时间码可以是 CHOP、DAT 或 Timecode Class 对象。
Play play - 指定计数是递增还是保持不变。
Cue cue - 设为 on 期间，输出保持在下方指定的初始值。
Cue Pulse cuepulse - 触发脉冲时，输出被设为下方的初始值。
Frame frame - 起始计数的帧。
Second second - 起始计数的秒。
Minute minute - 起始计数的分。
Hour hour - 起始计数的时。
Frame Rate framerate - 信号每秒编码的完整帧消息数。通常在 24 到 30 之间。注意，虽然我们通过自定义使用 User Bits 1 字段支持 30 以上的帧率，但生成的 LTC 信号是非标准的，其他软件或设备很可能无法读取。遵循标准时，LTC 限制为 30fps。
Drop Frame Numbering dropframe - 丢帧编号将 30 fps 时间码转换为 29.97 fps 的 NTSC 标准。除 10 分钟的倍数外，每分钟的第一秒会跳过帧号 0 和 1。
High FPS Behaviour highfpsbehaviour - 当设定帧率高于 LTC 帧率时，指定帧号的计数方法。仅当设定帧率是 LTC 帧率的倍数时此菜单才可用。此菜单有 2 个选项。
  • Cycle Frames cycleframes - 此模式循环 LTC 帧计数，直到每个 FPS 周期结束
  • Duplicate Frames duplicateframes - 此模式将每个 LTC 帧计数重复多次，直到每个 FPS 周期结束
Timecode Object/CHOP/DAT timecodeop - 通过引用时间码设置 LTC 输出值。应引用带有 'hour'、'second'、'minute'、'frame' 通道的 CHOP，首格包含时间码字符串的 DAT，或 Timecode Class 对象。
Audio Rate audiorate - 输出信号的音频采样率。

参数 - User 页

LTC 中的 User Data 位保留用于在时间码信号中传输自定义用户数据。常用于卷号和日期，但也可用于任何内容。

User Data 1 user1 - 在保留给 User Data 1 的位中发送此值。
User Data 2 user2 - 在保留给 User Data 2 的位中发送此值。
User Data 3 user3 - 在保留给 User Data 3 的位中发送此值。
User Data 4 user4 - 在保留给 User Data 4 的位中发送此值。
User Data 5 user5 - 在保留给 User Data 5 的位中发送此值。
User Data 6 user6 - 在保留给 User Data 6 的位中发送此值。
User Data 7 user7 - 在保留给 User Data 7 的位中发送此值。
User Data 8 user8 - 在保留给 User Data 8 的位中发送此值。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

可通过 Info CHOP 访问 LTC Out CHOP 的额外信息。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
