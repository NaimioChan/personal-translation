Notch

Notch 是一个实时 3D 创作与渲染软件包。

Notch Block 播放

Notch Block 播放通过 Notch TOP 集成到 TouchDesigner 中，可在 TouchDesigner 项目内直接控制 Notch block。此功能在任何付费许可证下均可用，但 Commercial 和 Educational 许可证的能力有限制，详见 here。

加载 Notch block 时，会自动把所有暴露属性生成为 Notch TOP 上的自定义参数。

需要 Notch Builder Pro 许可证，才能在 TouchDesigner 中加载 block 且不带水印（参见 Notch Builder licensing）。使用 Notch Builder Pro 许可证时，Notch block 的分辨率限制为 4096x2160，超过该值的分辨率都会带水印。 若需要更高分辨率或多个 HD 输出，则需要 Notch Playback 许可证。关于 Notch Playback 的授权和分辨率支持，请参阅 Notch Playback Licensing。

还必须安装 CodeMeter User Runtime v7.60+：https://www.wibu.com/support/user/downloads-user-software.html

NotchLC 编解码器

同时也支持 NotchLC 编解码器的解码和编码。更多信息见其文章。
