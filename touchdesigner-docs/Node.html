节点

node 是 TouchDesigner 网络中 Operator 及其所有相关信息的载体。节点包含标记、输入与输出、OP 图标以及 OP Viewer 等信息。

左键单击节点边框，向内或向外拖动目标边缘，即可调整节点大小。在描述 TouchDesigner 网络时，「节点」和「操作符」几乎可以互换使用，例如「放入一个节点」或「放入一个 OP」都是对操作符在网络中放置位置的有效描述。

节点是通用称呼，操作符则是实际执行生成节点数据输出这一工作的具体实体。
