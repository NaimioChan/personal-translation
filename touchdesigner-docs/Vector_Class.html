Vector 类

vector 类保存单个 3 分量向量。向量描述空间中的方向，根据所计算的数据，适当使用向量或 Position 很重要。当与 Matrix 相乘时，此类会隐式具有第 4 个分量（W 分量）0。可以在不带任何参数的情况下创建新向量，也可以用 3 个参数给出 x、y、z 值，或用单个参数，即具有 3 个条目的变量，例如长度为 3 的列表，或位置或向量。

注意： tdu.___ 与 TDU.___ 可以互换使用。通常 TDU.___ 用于表示类，而 tdu.___ 用于实例化函数。

创建向量的示例： 

v = tdu.Vector() # 初始为 (0, 0, 0)
v2 = tdu.Vector(0, 0, -1)
values = [0, 1, 0]
v3 = tdu.Vector(values)

# 向量可以像 Python 列表一样访问
print(v3[1])	# 等同于 v3.y
v3[2] = 1		# 等同于 v3.z

实例化器

TDU.Vector(*args)→ TDU.Vector:

创建一个新的向量对象。以下参数形式都是有效的实例化方式：

  • tdu.Vector() - (0, 0, 0)
  • tdu.Vector(vector : TDU.Vector) - 复制该向量
  • tdu.Vector(position: TDU.Position) - 复制位置值
  • tdu.Vector(x : float, y : float, z : float) - (x, y, z)
  • tdu.Vector(f : float) - (f, f, f)
  • tdu.Vector(vec : list) - 包含 3 个条目的列表，用于填充向量

成员

x → float :

获取或设置向量的 X 分量。

y → float :

获取或设置向量的 Y 分量。

z → float :

获取或设置向量的 Z 分量。

方法

angle(vec)→ float:

返回当前向量与指定向量（vec）之间的角度（度）。 

d = v.angle(v2)

scale(x, y, z)→ None:

按指定值缩放向量的每个分量。

  • x, y, z - 用于缩放向量各分量的值。
v.scale(1, 2, 1)

normalize()→ None:

使此向量的长度变为 1。 

m.normalize()

length()→ float:

返回此向量的长度。 

l = m.length()

lengthSquared()→ float:

返回此向量长度的平方。 

l = v.lengthSquared()

copy()→ TDU.Vector:

返回该向量的副本作为新向量。 

newV = v.copy()

distance(vec)→ float:

返回当前向量到指定向量（vec）的距离。 

l = v.distance(v2)

lerp(vec2, t)→ TDU.Vector:

返回此向量与 vec2 的线性插值。即 vec1 * (1.0 - t) + vec2 * t，其中 vec1 是当前向量。t 的值不限于 [0, 1] 范围。 

l = v.lerp(v2, t)

slerp(vec2, t)→ TDU.Vector:

返回此向量与 vec2 的球面插值。t 的值不限于 [0, 1] 范围。 

l = v.slerp(v2, t)

dot(vec)→ float:

返回此向量与传入向量的点积。

  • vec - 用于计算点积的另一个向量
d = v.dot(otherV)

cross(vec)→ TDU.Vector:

返回此向量与传入向量的叉积。运算为 self cross vec。

  • vec - 用于计算叉积的另一个向量。
c = v.cross(otherV)

project(vec1, vec2)→ None:

将此向量投影到由 vec1 和 vec2 定义的平面上。vec1 和 vec2 都必须是归一化的。结果可能不是归一化的。

  • vec1, vec2 - 指定投影平面的向量。必须是归一化的。
v.project(v1, v2)

reflect(vec)→ None:

以指定向量（vec）为轴反射当前向量。 

v.reflect(v2)

特殊函数

TDU.Vector[i]→ float:

获取或设置由 i 指定的向量分量，其中 i 可以是 0、1 或 2。 

y = v[1]
v[1] = y * 2.0

TDU.Vector * float→ TDU.Vector:

按给定的浮点标量缩放向量，并返回新向量作为结果。 

v = v * 2.0
v = 2.0 * v

TDU.Vector + float→ TDU.Vector:

将给定标量加到向量的全部 3 个分量上，并返回新向量作为结果。 

v = v + 5.0
v = 5.0 + v

TDU.Vector - float→ TDU.Vector:

从向量的全部 3 个分量中减去给定标量，并返回新向量作为结果。 

v = v - 1.5
v = 1.5 - v

TDU.Vector + TDU.Vector→ TDU.Vector:

将两个向量相加，创建新向量。 

v3 = v1 + v2

TDU.Vector - TDU.Vector→ TDU.Vector:

将两个向量相减，创建新向量。 

v3 = v1 - v2

TDU.Vector += TDU.Vector→ TDU.Vector:

将第 2 个向量加到第 1 个向量上，第 1 个向量将包含运算结果。 

v1 += v2

TDU.Vector += float→ TDU.Vector:

将给定标量加到向量的全部 3 个分量上，向量将包含运算结果。 

v1 += 0.4

TDU.Vector -= TDU.Vector→ TDU.Vector:

从第 1 个向量中减去第 2 个向量，第 1 个向量将包含运算结果。 

v1 -= v2

tdu.Matrix * TDU.Vector→ TDU.Vector:

将向量与矩阵相乘，结果返回一个新向量。由于 Vector 只表示方向、没有位置概念，矩阵的平移部分不会应用到该向量上。 

v = M * v

TDU.Vector / float→ TDU.Vector:

将向量的每个分量除以标量，并返回新向量作为结果。 

v = v / 0.2

TDU.Vector *= tdu.Matrix→ TDU.Vector:

将向量与矩阵相乘，向量将包含结果。向量在矩阵右侧相乘。这与执行 v = M * v 相同，但更高效，因为不需要为 v 分配新向量。由于 Vector 仅表示方向，没有位置概念，矩阵的平移部分不会应用到向量上。 

v *= M

TDU.Vector *= float→ TDU.Vector:

按给定标量缩放向量的全部 3 个分量。向量将包含结果。 

v *= 1.1

TDU.Vector *= TDU.Vector→ TDU.Vector:

按第 2 个向量的分量对向量的全部 3 个分量进行逐分量缩放。向量将包含结果。 

v1 *= v2

abs(TDU.Vector)→ TDU.Vector:

返回一个新向量，其全部 3 个分量都是给定向量各分量的绝对值。 

v2 = abs(v1)

-TDU.Vector→ TDU.Vector:

返回一个新向量，其全部 3 个分量都被取反。 

v2 = -v1
