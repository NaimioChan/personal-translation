Fillet SOP

摘要

Fillet SOP 用于在两条曲线/多边形或两个曲面/网格之间创建平滑的桥接几何。

倒角会在每对输入之间创建一个新图元，从不影响原始形状。这与 Join 和 Stitch SOPs 相反。Join SOP 会转换并可能改变图元相连的端点，而缝合会改变原始形状，但不改变结果图元的数量。

关于「left」和「right」图元以及辅助输入选项的讨论，请参阅 Align SOP。

注意：倒角不考虑修剪曲线。要做到这一点，请使用 Join SOP。

参数 - 页

Group group - 要倒角的图元。若留空，则对整个输入倒角。接受模式，如 Pattern Matching 中所述。
Fillet fillet - 可以选择以循环方式对每 N 个图元的子组或每隔第 n 个图元进行倒角。

Example：假设有六个图元，编号为 0 - 5，N = 2。则：

  1. Groups 会倒角 0-1 2-3 4-5
  2. Skipping 会倒角 0-2-6 和 1-3-5。
  • All Primitives all -
  • Groups of N Primitives group -
  • Skip Every Nth Primitive skip -
N inc - 确定要分组或跳过的图元数量。
Wrap Last to First loop - 将第一个图元的起点连接到最后一个被倒角图元的终点；若只有一个图元，则在其两端之间创建倒角。
Direction dir - 此菜单决定倒角操作的参数方向，可以是 U 方向或 V 方向，仅在输入为曲面时有意义。U 方向对应列，V 方向对应行。
  • in U ujoin -
  • in V vjoin -
Fillet Type fillettype - 在此菜单中选择要使用的倒角类型。
  • Freeform freeform - 允许完整指定倒角。
  • Convex convex - 可以取反缩放值以确保凸形倒角。
  • Circular circular - 在输入的形状和朝向允许的范围内，尽量按径向圆弧构建倒角。你无需指定半径——它会自动确定，以确保输入之间平滑连接。当两个输入彼此靠近时，倒角半径会减小。切线缩放被忽略（与 Bridge SOP 中相同）；只考虑切线的符号，这样你就不必翻转任一输入的法线。
Primitive Type primtype - 在此菜单中选择倒角将创建的图元类型。
  • Input Geometry Type input - 在成对图元之间构建匹配类型的倒角。若这对图元类型不同，则使用更通用的类型（即 NURBS 优先于 Bzier，Bzier 优先于多边形）。
  • Polygon polygon - 在成对图元之间构建多边形倒角。
  • NURBS nurbs - 按指定阶数在成对图元之间构建 NURBS 倒角。
  • Bezier bezier - 按指定阶数在成对图元之间构建 Bzier 倒角。
Order order - 构建样条倒角所用的阶数。
Left UV leftuv - 每个左侧图元上开始倒角的参数点。

  • lrscale1 -

Match Input to Fillets seamless - 若选中，输入会被修改，使等参线从一个图元经倒角到另一图元看起来连续。同时，图元会被提升为相同的类型和阶数。这会尽量减少（即使不能消除）渲染中引入的伪影，代价是几何更精细。
Cut Primitives cut - 若选中，图元会在倒角开始处被修剪。

Info CHOP 通道

Fillet SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
