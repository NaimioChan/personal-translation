MAT Common 参数页

概述

MAT Common Page 允许你调整许多渲染设置。这些设置完全独立于所使用的着色器，因此可应用于任何着色器。某些 MAT 可能需要启用或禁用特定渲染功能才能正常工作，此时该 MAT 类型的相关参数会被禁用。

参数

混合

Blending 是把正在绘制的像素的颜色值与 Color-Buffer 中当前像素的颜色值相加。混合通常用于模拟 Transparency。

混合公式为：

最终像素值 = (Source Blend * Source Color) + (Dest Blend * Destination Color)

Blending（透明度）blending - 此开关启用和禁用混合。但请参阅 wiki 文章 Transparency。

Source Color srcblend - 此值乘以正写入 Color-Buffer 的像素的颜色值（也称为 Source Color）。

Destination Color destblend - 此值乘以 Color-Buffer 中当前像素的颜色值（也称为 Destination Color）。

Separate Alpha Function separatealphafunc - 此开关为 alpha 值启用和禁用单独的混合选项。

Source Alpha srcblend - 此值乘以正写入 Color-Buffer 的像素的 alpha 值（也称为 Source Alpha）。

Destination Alpha destblend - 此值乘以 Color-Buffer 中当前像素的 alpha 值（也称为 Destination Alpha）。

深度测试

深度测试是把正在绘制的像素的深度值与 Frame-Buffer 中当前像素的深度值进行比较。被判定在 Frame-Buffer 中当前像素之前的像素会绘制在其上。被判定在当前像素之后的像素不会被绘制。深度测试让 3D 场景中的几何能遮挡其后面的几何，也能被前面的几何遮挡，与几何的绘制顺序无关。

有关深度测试的更详细说明，请参阅 Depth-Test 文章。

Depth Test depthtest - 启用和禁用深度测试。若禁用深度测试，深度值不会写入 Depth-Buffer。

Depth Test Function depthfunc - 正在绘制的像素的深度值会用此函数与 depth-buffer 中当前的深度值比较。若测试通过，像素被绘制到 Frame-Buffer。若测试失败，像素被丢弃，Frame-Buffer 不做任何更改。

Write Depth Values depthwriting - 若 Write Depth Values 开启，通过深度测试的像素会将其深度值写入 Depth-Buffer。若未开启，则不论绘制的像素是否通过深度测试，Depth-Buffer 都不会有任何更改。

Alpha 测试

Alpha 测试让你根据像素的 alpha 值选择绘制或不绘制该像素。

Discard Pixels Based On Alpha alphatest - 启用或禁用像素 alpha 测试。

Keep Pixels with Alpha alphatest - 此菜单与下方 Alpha Threshold 参数配合，根据像素的 alpha 值决定保留哪些像素。

Alpha Threshold alphathreshold - 像素的 alpha 会与此值比较，以决定是否应绘制该像素。alpha 大于 Alpha Threshold 的像素将被绘制。alpha 小于或等于 Alpha Threshold 的像素不会被绘制。

线框

线框功能会把几何渲染为线框，使用渲染中实际使用的图元类型。这意味着 Metaballs、NURBs 和 Beziers 等曲面会变成用于渲染它们的三角形/三角形带的线框（因为这些类型的图元无法在 OpenGL 中原生渲染）。

Wire Frame wireframe - 启用和禁用线框渲染，可选择 OpenGL 细分或基于拓扑的线框。

Line Width wirewidth - 此值为线的宽度。该值以像素为单位。

剔除面

cull face 参数会从渲染输出中剔除面。这可以用作优化，有时也用于去除伪影。更多信息参见 Back-Face Culling。

Cull Face cullface - 选择要渲染哪些面。

  • Use Render Setting - 使用 Render 或 Render Pass TOP 中的渲染设置。
  • Neither - 不剔除任何面，全部渲染。
  • Back Faces - 剔除背面，渲染正面。
  • Front Faces - 剔除正面，渲染背面。
  • Both Faces - 剔除双面，不渲染任何内容。

多边形深度偏移

此功能把多边形向后推入空间一小段。当你渲染两个直接重叠的多边形并出现 Z-Fighting 时很有用。更多信息请参阅 Polygon Depth Offset。在做 shadows 时这也是重要功能。

Polygon Depth Offset polygonoffset - 开启多边形偏移功能。

Offset Factor polygonoffsetfactor - 给 Z 值添加一个偏移，偏移量取决于表面相对观察者的倾斜程度。

Offset Units polygonoffsetunits - 给 Z 值添加一个恒定偏移。
