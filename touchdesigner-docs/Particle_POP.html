Particle POP

摘要

Particle POP 用于为粒子系统模拟创建和控制「粒子」的运动。粒子就是一个带有特殊属性的 POP 点，这些属性由 Particle POP 创建，或由用户在反馈式循环中手动添加/修改，因此易于自定义。POP 完全在 GPU 上运行，能够处理数百万以上的点。初始位置来自输入的 P 属性，参数可让你定义质量、阻力的初始状态，Map 页则可让你从输入属性获取这些状态。

粒子在创建时带有初始位置（P）和速度（PartVel）以及质量（PartMass）。(1) 位置来自输入 POP 的 P 属性，(2) 速度、质量等来自 Particle POP 的参数，(3) Map 页可让你从某些输入属性获取这些初始状态。粒子可以按恒定发射率发射，也可以根据输入属性发射。根据输入属性发射时，Particle POP 会检查每个输入点的发射属性，并在该位置每帧发射相应数量的粒子（发射值会转换为整数）。除非在 Jitter Birth Position 参数上设置了值，否则这些粒子都会从完全相同的位置生成。

Map 页允许通过读取来自属性的逐点值来覆盖某些粒子参数。这包括质量（Initial Mass 参数创建 PartMass 属性）、生命期望和生命变化（PartLifeSpan）、初始阻力和速度阻尼（PartDrag）以及初始速度（PartVel）。

任何新属性都会从目标 POP 反馈回来。

粒子系统是开放且高度可定制的。它基于反馈循环：Particle POP 的输出被送往标准 POP 节点以及 Force Radial POP 节点（后者添加力、约束点、将状态改为消亡等），最终在反馈链末端到达一个 Null POP。Particle POP 使用该 Null POP 获取系统下一帧的状态（由 Target Feedback Loop POP 参数指定）。Particle POP 会查找 PartForce 和 PartVel 属性来计算当前帧的位置。

Particle POP 基于 Feedback POP 的功能和行为。它使用基于 Timer CHOP 的 TouchDesigner「Initialize / Start」标准来初始化、开始、结束、暂停、调节速度和预卷粒子系统。它共用若干相同参数，如果为 Particle POP 附加 Info CHOP，你会看到与 Timer CHOP 相同的状态通道和计时器通道。

初始化时可以将模拟预卷若干秒，这样按下 Start 时模拟已经进行中，不会还在添加最初的粒子。

当粒子从输入 POP 的某个点诞生时，可以使用 Attributes 页将属性从输入点转移到该粒子并重命名。你也可以用初始值创建新属性。topic：这些属性在此后的每个循环周期都会被修改。

粒子旋转：当粒子被渲染或用 3D 几何逐点实例化时，可以通过旋转属性（矩阵、四元数或欧拉角）控制其旋转。请参阅 POP Rotations。

属性

粒子具有普通几何没有的各种属性。这些属性必须随每个点一起携带，才能进行模拟。这些属性列于下方

粒子属性
Attribute Name Type Description
PartId uint A unique id for the particle
P vec3 The particle’s position
PartVel vec3 The particle’s velocity in Units per second
PartAge float The particle’s age (in seconds)
PartLifeSpan float The particle’s lifespan (in seconds)
PartForce vec3 The cumulative forces applied to the particle
PartMass float Particle’s mass
PartDrag float The drag factor applied to the particle causing it to decelerate.
PartDeath uint Indicates if a particle should be removed from the simulation (optional attribute)

「Time Integration」是物理模拟功能：对每个 time slice，将所有粒子的力累加（到 PartForce 属性）并转换为速度（PartVel），再转换为位置（P）。通常在启用 Time Integration 的模拟中，位置会根据施加的力（F）、质量（m）、速度（V）、位置（P）和时间增量（dt）更新。关闭 Time Integration 时，这项工作留给用户完成。

Particle POP 所做的「积分」运算如下：

Vt+1=Vt+Fm⋅ ⋅ dt{\displaystyle V_{t+1}=V_{t}+{\frac {F}{m}}\cdot dt}

Pt+1=Pt+Vt+1⋅ ⋅ dt{\displaystyle P_{t+1}=P_{t}+V_{t+1}\cdot dt}

PartDrag 属性（D）用于计算作用在粒子上、方向与其运动（V）相反的力（FD{\displaystyle F_{D}}）。

FD=D⋅ ⋅ V2{\displaystyle F_{D}=D\cdot V^{2}}

Velocity Damping 参数使用阻尼因子（VD{\displaystyle V_{D}}）随时间衰减速度（V）。

Vt+1=Vt+1⋅ ⋅ (1− − VD)⇒ ⇒ VD∈ ∈ [0,1]{\displaystyle V_{t+1}=V_{t+1}\cdot (1-V_{D})\Rightarrow V_{D}\in [0,1]}

粒子可以携带额外属性。这些属性可以从输入 POP 复制，也可以带初始值创建。

扩展粒子模拟

默认情况下，粒子模拟非常基础。粒子位置根据 PartVel 速度属性和 PartForce 力属性更新。

达到寿命的粒子会从模拟中移除。

要在模拟中注入力并影响粒子速度，例如，必须扩展粒子系统。

必须在 Target Particles Update POP 参数中引用网络中下游的一个 POP 节点，通常是 Null POP。此引用会形成反馈循环，在下一帧将更新了属性的粒子重新注入 Particle POP 模拟。借助这一机制，可以扩展模拟以控制粒子受力、空间限制、碰撞等。

当下游节点负责计算和设置粒子速度与位置时，可以禁用 Time Integration 参数。此时 Particle POP 不会使用 PartForce、PartDrag 和 PartVel 属性来更新粒子位置。

这种扩展机制有一些限制。重新注入 Particle POP 的粒子数量必须相同。重新注入的点必须携带粒子的保留属性。另一个限制是，点不能在下游被添加或移除后再重新注入。The Particle POP is responsible for creating and removing particles，但可以通过输入发射属性控制出生，并通过可选的 PartDeath 属性控制消亡。启用 Use Death Attribute 参数时，PartDeath 属性值为 1 或更大的粒子将在下一帧从模拟中移除。
