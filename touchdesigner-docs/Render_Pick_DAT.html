Render Pick DAT

摘要

Render Pick DAT 可以获取任意 3D 渲染中任意像素处 3D 表面的信息，从而可以在 3D 渲染场景上实现多点触控。它对渲染结果（来自 Render TOP 或 Render Pass TOP）进行采样，并返回指定拾取位置上几何的 3D 信息。

它接收一个至少包含三列的 DAT：select、u 和 v。通常会将 Multi Touch In DAT 连接到 Render Pick DAT，其中 Multi Touch In DAT 指向正在显示 Render TOP 输出的容器。


你可以同时从多个摄像机拾取。你可以指定 camera，使拾取从 Render TOP 中列出的第一个摄像机之外的视角进行。该列的值可以是指向 Camera COMP 的路径（相对于 Render Pick DAT，或绝对路径），也可以是整数索引（从 0 开始）。如果是索引，则当 Render TOP 中列出了多个摄像机，或在「Custom Pick Camera(s)」参数中列出了摄像机时，它会选择要使用的摄像机。这适用于各种 Multi-Camera Rendering 设置，以及 VR 等场景：此时拾取不是来自眼睛摄像机的视角，而是来自手部控制器。

拾取位置是 u,v（水平、垂直）坐标，放在你连接到 Render Pick DAT 输入的表格中。输入表格的每一行代表一个要采样的拾取点，第一行除外，它包含列标题 select、u 和 v（以及你想要的任何其他未使用列）。select、u 和 v 列就是从 Panel CHOP 得到的内容。无论渲染的宽高比如何，u 和 v 的值都从左到右、从下到上为 0 到 1。

当 Strategy 为 Always 时，该 u,v 位置始终被采样，结果显示在 Render Pick DAT 输出的对应行中。

输出表格将显示被拾取几何的路径、其位置（可选参考坐标系）、表面法线（不含凹凸贴图）、到摄像机的距离、纹理 UV 坐标、颜色、alpha 和实例 id。它可以正确拾取顶点发生变形的表面。

参数 - Render Pick 页

Strategy strategy - - 决定何时根据拾取交互更新值。
  • While Select select - 在被选择/拾取时持续更新值。
  • Hold First Picked holdfirst - 保存拾取到几何时首次返回的值。
  • Hold Last Picked holdlast - 保存拾取到几何时最后返回的值。它与 Continuous 策略的区别在于：如果拾取开始采样到空白区域（场景中该部分没有几何），它会保留最后拾取到的值。相反，使用 Continuous 策略时，如果拾取开始采样到空白区域，值会被清零。
  • Always always - 在所拾取的位置持续更新值。
Clear Previous Pick on New Pick clearprev - 此参数仅在 Strategy 设为 Hold Last Picked 时启用。开启时，在空白区域开始新的拾取会清除值；关闭时，如果拾取从空白区域开始，将保留最后的值。
Response Time responsetime - - 决定值的更新时机。
  • Next Cook (Faster) nextcook - 值在当前帧捕获，在下一帧更新。结果为上一帧的数据，但计算时间快得多。
  • This Cook (Slower) thiscook - 值在当前帧捕获并更新。
Pick Radius pickradius - 控制拾取搜索区域的半径。如果在拾取中心没有找到任何东西，它会在 Pick Radius 定义的搜索区域内继续搜索几何。
Pick Radial Step pickradstep - 用于减少搜索区域内的搜索量。搜索区域会在从拾取中心向外呈「辐条」状的位置上进行采样。
Pick Circular Step pickcirstep - 用于减少搜索区域内的搜索量。搜索区域会在从拾取中心向外呈「环」状的位置上进行采样。
Render/RenderPass TOP rendertop - 指定在哪个场景上拾取，以及从哪个摄像机拾取。默认使用 Render TOP 中列出的第一个摄像机进行拾取。可以通过「Custom Pick Camera(s)」参数指定另一个摄像机，也可以使用 camera 输入列选择多个不同的摄像机。
Custom Pick Camera(s) custompickcameras - 在此指定一个或多个 Camera COMP，即可从自定义摄像机的视口进行拾取。如果此参数为空，则使用 Render TOP 中的摄像机。要从多个不同摄像机的视角拾取，必须在输入 DAT 中指定 camera 列。
Allow Multi-Camera Rendering allowmulticamera - Multi-Camera Rendering 是同时渲染多个通道的更快方式，因此对于同时进行大量拾取可以提升速度。不过，对于在 088 中制作的某些较旧的 GLSL MATs，此功能可能无法正常工作，因此此参数允许在必要时强制关闭这项速度优化。但通常应保持开启。
Use Pickable Flags usepickableflags - 开启后，只有 Pickable Flag 处于开启状态的几何才能被 Render Pick DAT 选中。Pickable Flag 位于所有 Object 组件上。
Include Non-Pickable Objects includenonpickable - 将不可拾取的对象纳入拾取算法，使不可拾取的对象可以遮挡可拾取的对象。例如，如果场景中只有一个可拾取对象，同时存在大量额外的不可拾取几何，开启此参数后，若该可拾取对象位于不可拾取对象之后（被不可拾取对象遮挡），它将无法被选中。
Merge Input DAT mergeinputdat - 将输入表格追加到 Render Pick DAT 的列中。
Activate Callbacks activatecallbacks - 为每个拾取事件启用 Callback DAT。
Callbacks DAT callbacks - 包含所收到拾取事件回调的 DAT 路径。

参数 - Options 页

Fetch Position position - - 返回几何上被拾取点的位置。列为 tx, ty, tz。
  • No no - 不返回位置值。
  • In SOP Space sopspace - 返回被拾取点在 SOP 变换空间中的位置。
  • In World Space worldspace - 返回被拾取点在世界变换空间中的位置。
  • In Camera Space cameraspace - 返回被拾取点在摄像机变换空间中的位置。
  • Relative to Object relativetoobj - 返回被拾取点相对于 Reference Object 参数所指定对象的位置。
Fetch Normal normal - - 返回几何上被拾取点的法线。列为 nx, ny, nz。
  • No no - 不返回法线值。
  • In SOP Space sopspace - 返回被拾取点在 SOP 变换空间中的法线。
  • In World Space worldspace - 返回被拾取点在世界变换空间中的法线。
  • In Camera Space cameraspace - 返回被拾取点在摄像机变换空间中的法线。
  • Relative to Object relativetoobj - 返回被拾取点相对于 Reference Object 参数所指定对象的法线。
Reference Object referenceobj - 获取 Relative to Object 中的位置或法线时使用的对象。
Fetch Point Color color - 返回几何上被拾取点的点颜色。列为 cr, cg, cb, ca。
Fetch Texture UV uv - 返回几何上被拾取点的纹理坐标。列为 mapu, mapv, mapw。
Fetch Depth depth - 返回几何上被拾取点的深度。该值是点位置在 Depth Buffer 近平面与远平面之间的非线性比例。列为 depth。
Fetch Instance ID instanceid - 返回对象的 Instance ID。如果未启用实例化，此值始终为 0。列为 instance。
Custom Attrib 1 customattrib1 - 指定从对象返回哪些自定义属性。
Custom Attrib 1 Type customattrib1type - 属性类型从此菜单中选择。
Custom Attrib 2 customattrib2 - 指定从对象返回哪些自定义属性。
Custom Attrib 2 Type customattrib2type - 属性类型从此菜单中选择。
Custom Attrib 3 customattrib3 - 指定从对象返回哪些自定义属性。
Custom Attrib 3 Type customattrib3type - 属性类型从此菜单中选择。
Custom Attrib 4 customattrib4 - 指定从对象返回哪些自定义属性。
Custom Attrib 4 Type customattrib4type - 属性类型从此菜单中选择。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

操作符输入

  • Input 0: -

Info CHOP 通道

可通过 Info CHOP 访问 Render Pick DAT 的额外信息。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
