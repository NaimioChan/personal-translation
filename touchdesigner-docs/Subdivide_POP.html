Subdivide POP

摘要

Subdivide POP 对曲面进行细分和平滑。目前它对三角形使用 Loop 方法 [1]。它把每个四边形分成两个三角形，然后对每个三角形沿各边中点切分，细分成 4 个三角形。已有和新生成的点会与邻点混合，以产生更平滑的曲面。

增大 Depth 会进行多次递归，分为多个 pass，每个 pass 的结果在下一个 pass 中进一步细分。

把 Crease Weight 参数增大到接近 1 会更多地恢复原始形状，因此这是单纯细分面的合适方法，比如配合 Box POP 使用时。

subdividePOP_Class

参数 - Subdivide 页

Depth iterations - 设置细分的迭代次数。数值越高，曲面越平滑。
Crease Weight creaseweight - 决定几何中的锐边应保留多少
Simple Coefficients simplecoeffs - 在平滑插值点时启用简单的系数计算。
Copy Topology Info Back to CPU cpureadback - 启用后，将 GPU 上保存的点数和拓扑信息复制到 CPU。

参数 - Common 页

Bypass bypass - 把第一个输入原样传递到输出。
Free Extra GPU Memory freeextragpumem - 释放输出内存增减时累积占用的内存。
Delete Input Attributes delinputattrs - 只输出你在该 POP 中指定的属性——有助于把属性隔离到单独的分支。

操作符输入

  • Input 0: -

Info CHOP 通道

Subdivide POP 的额外信息可通过 Info CHOP 获取。

通用 POP Info 通道

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
