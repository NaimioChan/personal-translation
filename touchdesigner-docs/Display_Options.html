显示选项

有 3 种方式打开 Geometry Viewer 的显示选项。

  • 按 "p" 快捷键（如果在窗格中使用 Geometry Viewer，必须处于 View 状态）。
  • 在查看器上右键单击并选择 Display Options（如果在窗格中使用 Geometry Viewer，必须处于 View 状态）。
  • 单击 Geometry Viewer 工具栏中的 "+" Display Options 按钮。

Guides & Markers

此页用于控制 SOP 几何中点、顶点或图元叠加层的显示。对于 POP，右键菜单 view options menu 中提供更完整的属性叠加列表。

原点和网格的渲染也可以在此页中打开或关闭。

Misc

Display Options 对话框的 Misc 页
  • Aspect Ratio - 启用此选项可将查看器的宽高比强制为指定比例，而不是使用节点的尺寸。
  • Scale Attribute Overlays - 控制所有属性叠加层的大小，例如文本、向量、点等。1 为默认大小，小于 1 更小，大于 1 更大。
  • Scale in Screen Space - 控制叠加层是相对于屏幕还是相对于世界缩放。在屏幕空间中，叠加层相对于节点查看器保持恒定大小；在世界空间中，叠加层相对于几何保持固定大小，并随着放大缩小而变大变小。
  • Thin Attribute Range - 启用此选项可减少显示叠加层的点、顶点或图元的数量。只有索引落在给定范围内的那些才会被绘制。
  • Thin Attribute Percentage - 按占总数的百分比减少绘制叠加层的点、顶点或图元的数量。为 0 时不进行抽稀，全部显示。为 1 时全部移除，不会绘制任何内容。
