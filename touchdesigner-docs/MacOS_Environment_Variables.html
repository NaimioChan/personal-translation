macOS 环境变量

针对当前登录会话

要在本次登录期间向系统添加环境变量，请打开 Terminal 并输入以下内容： 

launchctl setenv ENV_VAR value

该变量将在你下次启动 TouchDesigner 时生效。 要移除该变量，请在 Terminal 中输入： 

launchctl unsetenv ENV_VAR

针对每次登录会话

要让环境变量在每次登录会话中都生效，请在用户资源库目录 ~/Library/LaunchAgents 中创建一个名为 ca.derivative.environment.plist 的文件。若 LaunchAgents 目录不存在，你可能需要先创建它。将以下内容粘贴到该文件中，并按你的环境变量进行更新： 

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <!--to set value: launchctl setenv TOUCH_ENV_VAR value-->
  <!--to unset value: launchctl unsetenv TOUCH_ENV_VAR-->
  <key>Label</key>
  <string>ca.derivative.environment</string>
  <key>ProgramArguments</key>
  <array>
    <string>sh</string>
    <string>-c</string>
    <string>
launchctl setenv ENV_VAR_1 value1;
launchctl setenv ENV_VAR_2 value2;
    </string>
  </array>
  <key>RunAtLoad</key>
  <true/>
</dict>
</plist>

这些变量会在每次登录会话开始时加载。系统自动重新打开的应用程序中可能无法使用它们。若要在本次登录的剩余时间内停止加载这些变量，你需要卸载该文件，并在 Terminal 中取消设置该文件中的环境变量 

launchctl unload ~/Library/LaunchAgents/ca.derivative.environment.plist
launchctl unsetenv ENV_VAR_1
launchctl unsetenv ENV_VAR_2

你可以运行以下命令再次重新加载环境变量。 

launchctl load ~/Library/LaunchAgents/ca.derivative.environment.plist

若不再希望定义某些环境变量，可以将它们从 plist 文件中删除，或删除该 plist 文件。重启系统，或在 Terminal 中卸载 plist 文件并取消设置这些变量，以在本次会话的剩余时间内生效。
