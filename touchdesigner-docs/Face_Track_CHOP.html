Face Track CHOP

摘要

注意

OS: 该操作符仅在 Microsoft Windows 操作系统下受支持。
Hardware: 该操作符使用 Nvidia Maxine 系统的增强现实（AR）SDK，需要 20、30、40 或 50 系列 Nvidia RTX 显卡才能运行。

The models for this operator are not included with TouchDesigner. To use this operator you will need to download the 0.8.7 version AR SDK for your GPU from https://www.nvidia.com/en-us/geforce/broadcasting/broadcast-sdk/resources/.

Face Track CHOP 可检测图像中的人脸和面部特征点，以及人脸相对于摄像机的朝向。使用兼容的三维可变形人脸模型（3DMM）和 Face Track SOP，它还可用于把三维网格拟合到检测到的人脸并为其制作动画。

输入图像来自所提供的 TOP，可以是任意分辨率或格式，既可以是静态图像也可以是视频。若图像中有多张人脸，CHOP 会尝试跟踪检测到的最大一张。

检测到的特征坐标以相对于输入图像左下角的 u、v 位置给出。默认情况下值域为 0 到 1，但可启用 'Aspect Correct' 参数对数值进行缩放，使其在保持原图宽高比的同时可用作 3D 坐标。

提示：参见 OP Snippets 中 Face Track CHOP/SOP 的几个示例。

要让点的三维渲染与原始输入图像对齐，把 Camera COMP 的 'Projection' 设为 'Orthographic'，把 'Ortho Origin' 参数设为 'Bottom-Left'，把 'Ortho Width' 设为 1，同时在 Face Track CHOP 上启用 'Aspect Correct'。

要使用网格拟合功能，需要 Nvidia「nvf」格式的兼容人脸网格文件。我们推荐使用现在已包含在 TouchDesigner 安装目录 Config/Models 文件夹中的 face_model2.nvf 文件。注意： 为旧版 TouchDesigner 生成的网格文件将不再可用。

参数 - FaceTrack 页

Active active - 启用人脸跟踪功能。
Model Folder modelfolder - 用于人脸检测的 AI 模型文件位置。默认情况下这些文件位于 Config/Models 文件夹中。
Mesh File meshfile - 用于网格拟合的 Nvidia 'nvf' 格式三维可变形网格文件。可用时，拟合后的网格可通过 Face Track SOP 访问。
TOP top - 提供用于人脸跟踪图像的 TOP 操作符路径。
Bounding Boxes bbox - 输出描述检测到的人脸边界框的通道。这些通道给出人脸中心的 u、v 位置以及框的宽度和高度。位置相对于输入图像的左下角。
Bounding Box Confidence bboxconfidence - 输出一个通道，描述 AI 模型在输入图像中检测到人脸的确定程度。数值越高表示置信度越高。
Rotations rotations - 输出 rx、ry 和 rz 值，表示人脸在图像中的朝向。(0,0,0) 表示人脸正对摄像机。当被摄者转头离开摄像机时，数值范围为 +/- 180 度。
Number of Landmarks landmarks - -
  • None none - 要输出的面部特征点数量。点从 1 开始编号，始终代表脸上固定的特征，如下巴、眉毛、鼻子等。位置以相对于输入图像左下角的 u、v 坐标给出。
  • 68 (Multi-PIE Mark-ups) num68 - AI 研究中使用的标准面部特征点集合。See Reference Diagram.
  • 126 num126 - 扩展的特征点集合。
Landmark Confidence landmarkconfidence - 为每个特征点添加置信度值。数值越高表示该特征越可能准确。
Mesh Transform meshtransform - 启用后，为拟合的人脸网格输出平移、旋转和缩放通道。此功能需要有效的三维可变形人脸网格文件（见上文说明）。这些通道的值可用于变换所接 Face Track SOP 生成的网格，使其与输入图像对齐。默认情况下拟合网格会被预先变换以与图像对齐，但若在 SOP 中禁用 'Pre-Transform'，则可以改用这些值，以获得更多控制并提高速度。
Aspect Correct UVs aspectcorrectuv - 重新缩放 u、v 位置，使其具有输入图像正确的宽高比。当把 u、v 位置用作三维坐标而非图像位置时很有用。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Face Track CHOP 的附加信息可通过 Info CHOP 获取。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
