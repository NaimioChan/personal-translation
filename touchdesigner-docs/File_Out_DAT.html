File Out DAT

摘要

File Out DAT 让你将 DAT 内容写出到 .dat 文件或 .txt 文件。.dat 文件是 TouchDesigner 的 File Types 之一，用于存放 Table DAT 的数组。

当 File Out DAT 有 0 个输入时，可以通过 send 命令触发发送文本。

若 'Append' 关闭，每次都会写入新文件；若 'Append' 开启，则向文件追加，且文件句柄保持打开。

fileoutDAT_Class

参数 - File Out 页

File file - 要写入的文件系统路径和文件名。
N n - 在文件名（File 参数中）使用 me.par.n（或 Tscript 中的 $N）配合此处的 N 参数，可实现文件名递增。N 参数必须每次手动递增。导出一个每次要保存新文件时递增的 Count CHOP 是简便做法。
Write File write - 点击此按钮写入文件一次。
Append (txt Only) append - 将文本追加到文件中，而不是完全覆盖文件内容。

Info CHOP 通道

File Out DAT 的额外信息可通过 Info CHOP 访问。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
