Circle SOP

摘要

Circle SOP 创建开放或闭合的圆弧、圆和椭圆。

如果对两个非有理 NURBS 圆（即其 X 和 Y 半径不相等）做蒙皮，可能会生成比预期更多的等参线。这是因为非有理 NURBS 圆按弦长参数化其节点，而 Skin SOP 在蒙皮前必须统一两个圆之间的节点总数。

解决办法是使用 Refine SOP，再对得到的蒙皮做 unrefine；更好的做法是——在 unrefine 之前，从同一个圆出发，先用 Primitive 或 Transform SOP 变形第二份副本，然后再蒙皮。

  • Closed Arc closedarc - 一个 Open Arc，并以连向圆心的边连接，形如一块扇形。
  • Sliced Arc slicedarc - 与 Closed Arc 相同，但把每个点都连接到圆心。与 Closed Arc 相同，但把每个点都连接到圆心。

Info CHOP 通道

Circle SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
