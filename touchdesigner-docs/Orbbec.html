Orbbec

Orbbec 是一家 3D 相机及其它传感器的开发商和制造商，其产品可在 TouchDesigner 中使用。Orbbec 生产依赖不同 3D 技术的 multiple product lines，例如立体视觉、结构光或飞行时间（TOF），用于生成深度图和点云。视型号不同，这些相机可以使用 USB 或以太网（包括 POE），并在 Windows 和/或 OSX 上受支持。在 coordination with Microsoft 中，Orbbec 还生产多款相机，它们包含与 Kinect Azure 相同的硬件传感器，并兼容 Microsoft 的人体追踪系统。

Orbbec TOP / Orbbec Select TOP

Orbbec TOP 和 Orbbec Select TOP 可用于从包括 Femto、Gemini 和 Astra 产品线在内的各种 Orbbec 相机流式传输视频数据（颜色、深度和点云）。这些 TOP 使用 Orbbec SDK，兼容相机的完整列表可在 here 找到。有些型号通过 USB 连接，其它型号通过 PoE 以太网连接。

在 TouchDesigner 中，Orbbec TOP 用于连接并配置相机，可输出一路视频流。要获取更多视频流，可以把 Orbbec Select TOP 链接到主 Orbbec TOP。在支持的设备上，还可以连接 Info CHOP 来获取 IMU 数据。

Kinect Azure TOP / Kinect Azure CHOP / Kinect Azure Select TOP

兼容的相机（包括 Femto Mega 和 Femto Bolt）与 Microsoft Kinect Azure 共用内部硬件，可以直接由 Kinect Azure TOP 和 Kinect Azure Select TOP 替代原厂 Microsoft 设备使用。把 Kinect Azure TOP 上的 'Hardware' 参数切换为 'Orbbec' 即可使用这些相机。通过把 Kinect Azure 节点与 Orbbec 相机配合使用，你可以利用 Microsoft 的人体追踪库并获取骨架玩家索引数据。Notes: Kinect Azure 节点不自动支持 Femto Mega 的以太网连接；不过，你可以通过在 toe 文件旁放置一个配置文件来启用此功能。更多信息请参见 Orbbec docs。另请注意，在同一项目中使用 Orbbec TOP 和 Kinect Azure TOP 可能导致不稳定。如果你只使用深度或彩色相机图像，建议直接使用 Orbbec TOP。

使用建议

不建议在同一项目中同时使用 Kinect 节点和原生 Orbbec 节点。如果你需要使用骨架追踪（玩家索引或 Kinect Azure CHOP），就应只使用 Kinect Azure 节点来访问 Orbbec 相机。如果不需要骨架追踪，请使用原生 Orbbec 节点。

Derivative 测试过的设备

Femto Mega，固件 1.2.7

  • 操作系统：Windows 11、macOS M4 Sequoia 15.6
  • Windows 上支持的操作符：Orbbec TOP、Orbbec Select TOP、Kinect Azure TOP、Kinect Azure Select TOP、Kinect Azure CHOP
  • macOS 上支持的操作符：Orbbec TOP、Orbbec Select TOP

Femto Bolt，固件 1.0.9（仅支持 Windows）

  • 操作系统：Windows 11
  • Windows 上支持的操作符：Orbbec TOP、Orbbec Select TOP、Kinect Azure TOP、Kinect Azure Select TOP、Kinect Azure CHOP

Gemini 2，固件 1.4.76

  • 操作系统：Windows 11、macOS M4 Sequoia 15.6
  • Windows 和 macOS 上支持的操作符：Orbbec TOP、Orbbec Select TOP

Astra 2，固件 2.8.20

  • 操作系统：Windows 11、macOS M4 Sequoia 15.6
  • Windows 和 macOS 上支持的操作符：Orbbec TOP、Orbbec Select TOP
