TDStoreTools

摘要

TDStoreTools 模块提供重要的 StorageManager 实用类，用于 TouchDesigner 的 Storage 系统。它还包含深度 dependable 集合 DependDict、DependList 和 DependSet。

要使用 TDStoreTools，请在 Python 脚本顶部加入下面一行：

import TDStoreTools

或者更常见的是，如果你只打算使用 StorageManager，请在脚本顶部使用这一行：

from TDStoreTools import StorageManager

StorageManager 类

For a primer on StorageManager usage, see: StorageManager Class

StorageManager 是一个 Python 实用类，旨在让 Storage 在 Python Extensions 中易于使用。它还有许多用于创建 Python 属性和 dependable 集合的实用功能。

StorageManager 派生自 collections 容器中的 Python MutableMapping 类。这意味着它的行为非常像 Python 字典，可以用 data = storageManager[<key>] 格式访问其中的项。

构造函数

class StorageManager(extension, ownerComp, storedItems=None, restoreAllDefaults=False, sync=True, locked=True) → StorageManager instance

创建一个新的 StorageManager 实例。 StorageManager 会把数据存储在 ownerComp.storage[<extension class name>] 中。注意： 这意味着如果某个 Component 有两个类名相同的扩展，它们会共享同一个存储字典！
  • extension - 要与此 StorageManager 关联的扩展。
  • ownerComp - 要与此 StorageManager 关联的 Component。
  • storedItems - 存储项定义字典的列表。
  • restoreAllDefaults - 把所有存储项设为默认值。
  • sync - 如果为 True，清除不再定义的旧项，并对新项设置默认值。

方法

restoreAllDefaults()

把所有存储项恢复为 init 期间定义的默认值。

restoreDefault(storageItem)

把 storageItem 恢复为 init 期间定义的默认值 。
  • storageItem - 要恢复为默认值的存储项名称。

成员

extension The extension that this StorageManager is associated with.
ownerComp The Component that this StorageManager is associated with.

深度 dependable 集合

在使用 Python 扩展时，你常常会希望把数据存储在 Dependency objects 中，以便引用该数据的表达式在数据变化时更新。对于 Python 集合（list、dict、set）这会变得更棘手，因为它们是 mutable objects。

集合的内容变化时，对象本身并不会变化。这意味着即使该集合被包裹在依赖对象中，改变集合内容也不会让引用它的表达式更新。这正是 deeply dependable collections 的用武之处。这些特殊集合即使只有内容变化也会触发更新。此外，它们是递归工作的，因此在其中创建的集合也会是深度 dependable 的。

Accessing deeply dependable collections works just like accessing their standard Python counterparts, and returned values will have all dependency wrappers stripped away so they can be used normally. They also have all the usual methods and members of their core Python counterparts. The functions and members in the sections below are in addition to those available in the standard Python objects.

注意： 深度 dependable 集合的运行速度会比非 dependable 的对应集合稍慢。 Gotcha: 注意，如果单个深度 dependable 集合同时存在于多个其他深度 dependable 集合中，可能会出现问题。这种情况很少需要，但在非常复杂的数据中可能遇到。

DependDict 类

DependDict 是 python dict 类的深度 dependable 版本。

方法

getRaw(self, key=None)

获取整个 DependDict，或从中获取移除所有依赖后的某个值。
  • key - 要返回的值的键。如果为 None，则返回整个字典。

getDependency(self, key)

从 DependDict 中获取保留依赖的某个值。
  • key - 要返回的值的键。

setItem(key, item, raw=False)

设置字典中的一项。
  • key - 其值将被设为 item 的键
  • item - 该项
  • raw - 如果为 True，且 item 是集合，该集合将 not 被做成深度可依赖的集合。

DependList 类

DependList 是 python list 类的深度 dependable 版本。

方法

getRaw(self, index=None)

获取整个 DependList，或从中获取移除所有依赖后的某个值。
  • index - 要返回的值的索引。如果为 None，则返回整个列表。

getDependency(self, index)

从 DependList 中获取保留依赖的某个值。
  • index - 要返回的值的索引。

setItem(index, item, raw=False)

设置列表中的一项。
  • index - 要设置的项的索引
  • item - 该项
  • raw - 如果为 True，且 item 是集合，该集合将 not 被做成深度可依赖的集合。

append(item, raw=False)

在列表末尾添加一项。
  • item - 新项
  • raw - 如果为 True，且 item 是集合，该集合将 not 被做成深度可依赖的集合。

insert(index, item, raw=False)

把一项插入列表。
  • index - 新项将插入到的索引
  • item - 新项
  • raw - 如果为 True，且 item 是集合，该集合将 not 被做成深度可依赖的集合。

getDependableSlice(self, start=None, stop=None, step=None)

从列表中获取保留依赖的项切片。这是必要的，因为切片写法会返回移除依赖后的项。
  • start - 切片的起始索引
  • stop - 切片的结束索引
  • step - 切片的步长
