Attribute 类

Attribute 描述与 Prim Class、Point Class 或 Vertex Class 相关联的一般几何属性。每个 Prim、Point 或 Vertex 的具体值由 AttributeData Class 描述。SOP 和 POP 的属性列表由 Attributes Class 描述。

成员

owner → OP (Read Only):

此对象所属的 OP。

name → str (Read Only):

此属性的名称。

size → int (Read Only):

与此属性关联的值的数量。例如，法线属性的大小为 3。

type → float | int | str | tuple | TDU.Position | TDU.Vector (Read Only):

与此属性关联的类型：float、integer、string、tuple、Position 或 Vector。

default → float | int | str | tuple | TDU.Position | TDU.Vector (Read Only):

与此属性关联的默认值。取决于属性类型，可能返回 float、integer、string、tuple、Position 或 Vector。

isArray → bool (Read Only):

若属性是数组则为 True。

arraySize → int (Read Only):

对于数组属性为数组大小，否则为 0。

numMatCols → int (Read Only):

对于矩阵属性为列数，否则为 0。

numMatRows → int (Read Only):

对于矩阵属性为行数，否则为 0。

方法

destroy()→ None:

销毁此对象引用的属性。 

n = scriptOP.pointAttribs['N'].destroy()

vals(delayed=False)→ list:

对 POP 以列表形式返回属性值。

  • delayed -（Keyword，Optional）若设为 True，下载结果将延迟到下一次调用 vals() 时才返回，从而避免 GPU 因立即等待结果而停滞。

访问属性

有关如何访问单个属性的示例，请参阅 Attributes。
