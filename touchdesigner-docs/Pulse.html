脉冲

「脉冲」一个参数，就是向它发送信号，来源可以是 (1) exported CHOP 通道 (2) python 命令，或 (3) 鼠标单击，从而立即触发新的动作。

有些参数本身就是 Pulse 类型，例如 Speed CHOP 中的 Reset Pulse。你可以在 Component Editor 中创建自定义的 Pulse 类型参数。

通过 python 脉冲是调用 pulse 类型参数上的 .pulse() 函数，例如 op('speed1').par.resetpulse.pulse()

提示：在 TouchDesigner 中对定时对象使用 Pulse 参数的好处是它们会立即生效 - Speed CHOP 的 Reset 脉冲以及 Movie File In TOP 上的 Cue 脉冲等，通常都有一个 on-off 开关加一个 Pulse 参数。对于 on-off 开关，在它开启期间（哪怕只有 1 帧），状态会冻结在已提示/已重置的状态。更好的做法是用 op('speed1').par.resetpulse.pulse() 之类的东西去脉冲 Pulse 参数，它会在被脉冲的那一帧开始累加计数。

来自 CHOP 的脉冲通常是导出到 Pulse 类型参数的通道中一个 0 到 1 再到 0 的信号。

也可以使用参数中从 0 到 1 再到 0 的表达式来脉冲 Pulse 类型参数。
