Lookup Attribute POP

摘要

Lookup Attribute POP 最简单的形式是：取第一个输入的某个属性（Lookup Index Attribute(s)），其值在 0-1 范围内，然后对第一个输入的每个点，把该值作为索引查入第二个输入的属性（查找曲线的 Value Attributes）。它把这些查得的值输出到新的或已有的属性（Output Attribute Scope）中。

例如，查找曲线（第二个输入）可以是 Curve POP 的输出。

若索引为 0，则从查找曲线的第一个点取值；若索引为 1，则从查找曲线的最后一个采样取值。另外，若 Lookup Index Units 菜单设为 Point Index，则查找索引以查找曲线的点编号表示，从 0 到 number_of_points-1。

若索引超出范围，Extend Left 和 Right 菜单决定在做查找之前如何处理索引，例如将其保持在 0 或 1，或在 0 与 1 之间循环。

连续块让你可以查找并输出多个属性。在每个块中，你可以先把值重映射范围，再放入指定的输出属性。

启用插值时，值使用线性插值混合。该操作符还支持对变换矩阵和四元数进行插值。

另请参阅 Lookup Texture POP、Lookup Channel POP、Curve POP（Lookup 页）。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。

  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
