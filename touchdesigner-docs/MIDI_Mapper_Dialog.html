MIDI 映射器对话框

说明

MIDI Device Mapper 对话框可用于设置 TouchDesigner 的 MIDI 设备、MIDI 输入和输出信号以及 MIDI 时序。

在此对话框中创建好 Device Mapping 后，在该设备映射所在行的任意位置按住并拖放到网络中，即可创建一个已准备好所有映射通道的 CHOP。


另请参阅 MIDI In DAT、MIDI Event DAT、MIDI In Map CHOP、MIDI In CHOP、MIDI Out CHOP、midi 命令。

Device Mapping

此表格为 TouchDesigner 创建 MIDI 设备映射。它会创建一个唯一的 Device ID，将 MIDI 输入和输出设备与一个 MIDI 设备映射关联起来。随后 MIDI operators（如 MIDI In CHOP、MIDI Out CHOP 和 MIDI In DAT）就可以使用此 Device ID。

创建新的 Device ID

MIDI 设备映射在 TouchDesigner 中由唯一的 ID 标识。此 ID 用于 MIDI 操作符的 Device ID 参数。该 ID 将指定一个输入和/或输出设备，以及供 MIDI 操作符用来创建数据通道的设备映射。

要添加新的设备映射，请点击 Add Device Mapping 按钮。这会在上方的 Device Mapping 列表中添加一行。ID 和 Channel（Ch）会被赋予默认值。点击 In Device、Out Device 和 MIDI Map 字段可打开可用选项列表。

删除 Device Mapping

右键点击要删除的设备映射，然后从菜单中选择 Delete。

In/Out Device 菜单

点击 In Device 或 Out Device 列会打开相应设备的菜单。该菜单会列出 TouchDesigner 找到的所有已连接到系统的设备。有些设备如果在 TouchDesigner 已打开时才连接，可能不会被列出。若发生这种情况，请保存 .toe 文件并重新启动 TouchDesigner。

MIDI Map 菜单

TouchDesigner System Maps

点击 Devices 标签页会显示 TouchDesigner 附带的默认 MIDI 映射。将鼠标移到右侧列表上可预览映射，点击设备即可选中。右侧会显示设备图像及其 MIDI 映射列表（即 channel s1 = b0 18 -- controller）。


User Maps

你也可以创建自定义的 User MIDI 映射。它们存储在 /local/midi/userdevices 中。要创建新的用户 MIDI 映射，请点击设备列表底部的 Add Device。一个新的默认模板映射会添加到列表中并存储在 /local/midi/userdevices 中。你可以使用 Name 字段重命名此 User Map。

现在进入在 /local/midi/userdevices/newname 处添加的映射组件内部。编辑图像（可选）。更重要的是编辑名为 sliders 和 buttons 的两个表格。目前没有自动学习功能。

提示：对于 buttons 表中的 MIDI 按钮，第一列是 On 消息，第二列是 Off 消息。若第二列与第一列相同，则该按钮表现为开关。若第二列为空，则按下按钮会生成一个短脉冲，因此它会自动关闭，无需 Off 消息。

MIDI Console

MIDI Console 显示 TouchDesigner 传入和传出的 MIDI 消息。
