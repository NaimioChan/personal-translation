Face Track SOP

摘要

注意

OS: 该操作符仅在 Microsoft Windows 操作系统下受支持。
Hardware: 该操作符使用 Nvidia Maxine 系统的增强现实（AR）SDK，需要 20、30、40 和 50 系列 Nvidia RTX 显卡才能运行。

The models for this node must be separately downloaded via the AR SDK for your GPU from https://www.nvidia.com/en-us/geforce/broadcasting/broadcast-sdk/resources/.

Face Track SOP 提供对 Face Track CHOP 生成的拟合人脸网格的访问。它既可以直接上传到 GPU 渲染，也可以传给其他 SOP 进一步修改。默认情况下，网格会被预先变换以与输入图像中的源人脸对齐（x、y 位置等于图像的 u、v 位置）。不过也可以禁用预变换，此时拟合网格会以原始尺度位于原点。仍可使用 Face Track CHOP 的 tx、ty、rx 等通道把网格与图像对齐。

注意： 要使用此功能，需要为 Face Track CHOP 的 'Mesh File' 参数提供 Nvidia 'nvf' 格式的兼容三维可变形人脸网格文件。该文件不随 TouchDesigner 提供，但 Face Track CHOP 页上给出了创建说明。

facetrackSOP_Class

参数 - Face Track 页

Face Track CHOP chop - 生成网格的 Face Track CHOP 的路径。
Direct to GPU directtogpu - 激活时，网格会直接传输到 GPU。这种方式快得多，但无法再由其他 SOP 进一步变换。
Pre-Transform Mesh pretransform - 拟合网格会被变换以与用于生成它的输入图像对齐。禁用时，网格会以原始尺度位于原点。
Compute Normals normals - 启用后自动为人脸网格生成平滑的顶点法线。

Info CHOP 通道

Face Track SOP 的附加信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
