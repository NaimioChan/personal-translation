TouchDesigner 术语表

学会说 TouchDesigner 的语言

.toe：TOuch Environment 文件，TouchDesigner 用来保存整个项目的文件类型。

.tox：TouchDesigner 组件文件，用于保存 TouchDesigner 项目中某个 Component 的文件类型。

3D Texture：2D 纹理数组或 3D 像素网格。

Absolute Time 或 absTime：绝对时间在 TouchDesigner 进程启动时从 0 开始计数，并持续增加。若 UI 顶部的 Power 0/1 按钮处于 Off，或根时间轴被暂停，它就会暂停。

Adaptive Homing：在 Geometry COMP 或任何 POP 的 Node Viewer 中，Adaptive Homing 选项会持续把正在显示的 3D 几何保持在视野内，即使几何改变形状、大小和动画位置。

Adaptive Homing：在 Geometry COMP 或 POP 的 Node Viewer 中，Adaptive Homing 选项会持续把正在显示的 3D 几何保持在视野内。

Annotate 或 Annotation：Annotate 在网络编辑器中显示为带用户文字和图形的彩色矩形。它基于 Annotate COMP，让你用注释、节点分组等有用信息为网络做文档。

Array Attribute：数组属性是一种 Attribute，含有多个所选 Attribute Data Type 的 elements，例如由 12 个整数构成的属性。

Attribute：属性构成 POPs 的数值数据块。每个 POP 有三块数据：包含 P 点 Position 属性的 Point List、Primitive List 和 Vertex List，每一块都由任意数量的属性组成。

Backdrop：Backdrop 是 Network 后方可见的节点查看器网格，通过开启 Display Flags 以及网络 RMB -> Display... Backdrop OPs 来设置。

Binding：绑定是一种 Parameter Mode，把两个或多个参数的值关联在一起，修改其中任何一个绑定参数的值都会改变全部。实际值只存储在一处。

Bookmarks：网络 Pane 顶部的一个下拉列表，包含跳转到 Network Paths 的功能。

Bypass 或 Bypass Flag：设置了 Bypass 标记的操作符不起作用：进入其第一个输入的所有数据都原样出现在输出。

Callback：有些操作符附带一个 DAT docked，其中包含一些 python 函数。这些函数称为「回调」，当操作符中某些内容变化时被调用。

Channel：一个 CHOP 输出一个或多个通道，通道就是一系列数字（Samples），表示运动、音频等。通道在 TouchDesigner 网络的 CHOP 之间传递。通道可以 Exported 到 Parameters。

CHOP 或 Channel Operator：一种 Operator Family，作用于 Channels（一系列数字（Samples）），用于动画、音频、数学、模拟、逻辑、UI 构建，以及与设备和协议之间流式传输的数据。

Clone：克隆让多个组件与主组件的内容保持一致。设置了 Clone 参数的 Component 会被强制包含与主组件相同的节点、连线和参数。克隆不会像 Replicator COMP 那样创建新组件。

Component 或 COMP：一种包含自己 Network 的 Operator Family。有十六种 3D Object Component 和十种 2D Panel Component 类型。另请参阅 Network Path。

Connector：每个 Node 左右两侧的缺口，让你把一个 Operator 的输出 Wire 到同 Operator Family 的另一个的输入。3D Object Components 和 Panel Components 上下两侧的缺口，用于在 Hierarchy 中连接各子 Family 的组件。

Container：Container 组件类型是一种 Panel Component，用于容纳、布局和显示任意数量的其他 Panel 组件。

Cook：重新计算 Operators 的输出数据。操作符在以下情况计算：（1）其输入变化，（2）其 Parameters 变化，（3）某些情况下时间轴向前推进，或（4）对节点运行 Scripting 命令。当操作符是 Panel Component 时，用户与它交互也会计算。操作符计算时，通常会导致连接到其输出的操作符重新计算。TouchDesigner 绘制屏幕时会重新计算所有 Dependencies——所有 Networks 中必要的操作符，共同构成一帧的总「计算时间」。

DAT 或 Data Operator：一种 Operator Family，用于处理文本字符串：多行文本或表格。多行文本常常是 python Script 或 GLSL 着色器，但也可以是任何多行文本。Tables 是单元格的行与列，每个单元格包含一个文本字符串。

Dependency：这是 TouchDesigner 中的 Procedural 机制：当某份数据变化时，会自动导致其他操作符和表达式重新 Cook。

Dependency 或 Dependable：适用于 python 对象、参数、节点。

Designer Mode：你在 Designer Mode 中编辑网络。见 Perform Mode。

Dialog：任何不是 Pane 或 Viewer 的浮动窗口。

Dimension：Dimension 是 POP 的元数据，描述点列表的结构，点列表可以按行和列排列（即大小为 nrows 和 ncolumns 的两个维度）。

Display Flag：Geometry 组件和 SOP 操作符上的蓝色 flag 决定该操作符所含的几何是否在节点查看器和几何查看器窗格中可见。见 Render Flag。

Docking 或 Docked：任何 node 都可以停靠到另一个节点。这有助于整理网络，因为停靠在一起的两个节点在父节点于网络编辑器中移动时会一起移动。停靠的节点可以折叠为父节点下方的小图标，减少网络杂乱。

Event：事件是单刻发生的，由多种条件产生——用户引起的输入动作、外部设备和软件，以及 TouchDesigner 的内部状态。许多操作符类型响应事件，并为用户提供编写 python 代码响应事件的地方。

Export：导出是把 CHOP 通道连接到操作符的参数。每个导出 CHOP 的输出是一个或多个通道，仅在 CHOP Viewer 开启时有效。通道的当前值可以导出到任何操作符的参数，覆盖该参数的值。见 Parameter。

Expression：包含数据（字符串、浮点数、列表、布尔值等）和运算符（+ * 等）的文本字符串，由节点的语言（python 或 Tscript）求值，返回字符串、浮点列表或布尔值等。表达式用于参数、DATs 和脚本中。

Extend Conditions 或 Extend Region：在 CHOP 中，Extend Conditions 决定当你试图获取超出起止范围的通道值（即在其 Extend Regions 中）时会得到什么数字。

Extensions：任何组件都可以用其自己的 Python 类来扩展，类中包含 python 函数和数据。

File Metadata：读写不同类型的文件元数据。

Filter：需要 1 个或多个输入的操作符在 TouchDesigner 中称为 Filter，如 Math CHOP。见 Generator。

Filter per Sample：CHOP 的一项强大功能，随时间进行滤波，如 Lag CHOP 和 Filter CHOP，其中每个采样充当自己的滤波器。

Flag：操作符某些状态的指示器（Bypass flag、Render flag、Lock flag、Viewer Active flag）。

Folder：TouchDesigner 中的 Folder 始终指 Windows 或 macOS 操作系统的目录/文件夹系统，其中包含文件和其他文件夹。它不指 TouchDesigner 内的操作符。见 Network Path。

Frame：「Frame」是时间度量，用于（1）Timeline，（2）作为 CHOP 中的时间单位，（3）作为读入 TOPs 并从 TOP 写出的影片文件中的时间单位。Frame Rate 是每秒帧数（FPS）。

Frame Rate 或 FPS：TouchDesigner 的 Timeline 运行时的每秒 Frames 数。用 project.cookRate 设置。

Generator：不需要连接任何输入的操作符在 TouchDesigner 中称为 Generator，如 Pattern CHOP。见 Filter。

Geometry：POP 中持有、并由 Geometry COMP 传递用于渲染的 3D 数据。

Geometry Spreadsheet：目前用 SOP to DAT 查看 SOP 点/多边形的 XYZ 及其他属性。以前是一种 Pane 类型。

Geometry Viewer：用于交互查看和操控 3D 场景或对象的 3D 视口。几何查看器可在 Panes（任意窗格中按 alt+3）或所有 Geometry Object 组件的 Node Viewers 中找到。

Global OP Shortcut：一种可从项目中任意节点访问的组件名称，可在组件的 Global Operator Shortcut 参数中声明。

GPU：图形处理器。这是图形卡/芯片中高速的多核处理器，从 CPU 接收几何、图像和数据并生成图像与处理后的数据。

Group：POP 和 SOP 中的 Group 是点或图元的命名子集。用 Group POP 或 Group SOP 创建。POP 和 SOP 中的许多操作（通过 Group 参数）可以限制为只影响所选组中的点或图元，不影响其他。

Hierarchy：层级把组件与其他组件关联起来。TouchDesigner 中有两组层级：3D Object 组件和 2D Panel 组件。层级让一个组件可以相对另一个定位。每组都可以通过网络中节点底部/顶部之间的连线连接，或把一个组件放在另一个里面。

Immune：每个节点都有一个 Immune Flag，开启且节点位于 Clone 内时，它不受克隆主控的任何改动影响，因此可以在克隆中存放额外数据，或让节点被克隆过程忽略。

Index and ID：Index 是点在点列表中的位置，不是属性。ID 常作为粒子用的属性，没有顺序、值唯一、可重复使用。

Input Block：接受无限输入的操作符，每个输入有一个 seq 参数块。一个输入可以是 OP 的 pattern。

Instance：（1）Geometry Component 可以多次实例化和渲染其 SOP 几何：CHOP 的每个采样、DAT 表格的每一行、TOP 的每个像素或 SOP 的每个点各一次；（2）实例是不实际拥有自己数据的操作符，它只是引用某个操作符（或有输入）并使用其数据。这包括 Null OP、Switch OP，以及某些情况下的 Select OP。

Internal Operators：内部操作符（iOP）为常用操作符提供简单的快捷方式，可从该组件内任意位置访问。

Internal Parameters：内部参数（iPar）的作用类似组件内的局部变量。它们为你创建的参数集合提供简单的快捷方式，可从该组件内任意位置访问。

Interoperability 或 Interops：TouchDesigner 通过原生 Operators 和 Palette 组件对接的设备、协议和软件工具。

Keyboard Shortcuts：键盘快捷键有两类：内置于 TouchDesigner 创作界面的 Application Shortcuts，以及你为任何自定义面板创建的 Panel Shortcuts。

Keyframe：在 Animation component 中，每个关键帧指定通道在特定时间（或帧）的值。关键帧保存一个值、斜率和加速度，以及一种插值类型。通道的关键帧用于插值并确定该通道所有采样的值。

Layout：（1）TouchDesigner 窗口由顶部菜单栏、底部 Timeline，以及中间可选的一种 Layout 组成。Layout 由一个或多个 Pane 组成，每个 Pane 可以包含 Network Editor、Viewer、Panel 等。见 Pane 和 Bookmark。（2）网络中的节点可用 RMB 菜单中的 Layout 命令排列。

Line Strip：POP 中具有 1 个或多个相连点的图元。

Link 或 Reference：Link 或 Reference 是节点之间的虚线，表示节点间流动的其他数据。例如 CHOP Exports、参数中的节点 Paths，以及参数中引用 CHOP 通道、DAT 表格和其他节点的 expressions。相对的是 Wire，它连接同一 Operator Family 中的节点。

Lock Flag：操作符被锁定时不会 cook，其输出数据保持冻结，即使 TouchDesigner 会话保存为 .toe 文件并重启。

Macro：F1 到 F12 键运行宏。F1 宏让你进入 Perform Mode。在面板上按 F9 或 F10 会打开你所指面板元素的网络。宏用旧版 Tscript 编写。

Map Point Attributes to Parameters：在某些 POP 的某些参数上，可以通过参数对话框中的 Map 页把 POP 的某个 Attributes 映射到参数，从而为 POP 的每个点设置不同的参数值。

MAT 或 Material：MAT 或材质是一种 Operator Family，把 Shader 应用到 SOP 或 3D Geometry Object 上，以渲染带光照的带纹理表面。

Menu Bar：Designer Mode 界面顶部的栏，包含菜单、链接、状态消息和其他控件。

MultiTouch 或 Multi-Touch：TouchDesigner 中支持多指或控制点输入的显示设备。

Network：每个组件都包含一个操作符网络，用于创建和修改数据。操作符通过连线连接，连线定义操作符计算其输入并生成输出后数据的流向。

Network Editor：一种窗格类型，可以创建和编辑操作符网络。

Node：承载 Operator 的通用事物，包含 Flags（display、bypass、lock、render、immune）及其在网络中的位置/大小。无论你说「放一个 Operator」还是「放一个 Node」，做的都是同一件事。

Node Viewer：在 Network Editor 窗格中每个操作符上都能找到的查看器。点击 Viewer Flag 可开启此查看器。

Normal：共享点、共享点上的法线、唯一点、重新计算。

Object 或 3D Object 或 Object Space：用于定义和渲染 3D 场景的 Component 类型子 Family。Geometry Component 是包含待渲染 3D 形状的 Object。Camera COMP 和 Light COMP 是其他 Object 类型。另外，「Objects」也指 Python 对象。

OP Create Menu：用于选择并创建新操作符的菜单。可在 Network Editor 中按 Tab 键或双击背景打开，也可以点击操作符输出连接器上的 MMB 或 RMB，或点击 Pane Bar 中的 + 符号。

OP 或 Operator：任何程序化数据操作符。OP 承担 TouchDesigner 中的所有工作。它们「计算」并把数据输出给其他 OP，最终生成新的图像、数据和音频。见 Node。

Operator Family 或 Family：操作符族有 TOPs、CHOPs、POPs（Point Operators）、MATs（Materials）、DATs（数据操作符）、SOPs 和 Components（Panel Gadgets and Objects）。

Palette：TouchDesigner 中的内置面板，包含可拖放到 TouchDesigner 网络中的组件和媒体库。

Pane：TouchDesigner 布局中的一个工作区域，包含 Network Editor 以及另外 7 种用于不同任务的窗格类型。TouchDesigner 界面可以由单个窗格组成，也可以分成多个窗格。

Pane Type：共有 8 种窗格类型：Network、Panel、Textport、Geometry Viewer、TOP Viewer、CHOP Viewer、Parameters、CHOP 通道的 Graph Editor，或 Geometry Spreadsheet。

Panel Component：Components 的子 Family，用于创建自定义交互式 2D 控件 panels（Container、Widget、Text COMP Slider、Button 等）。

Panel Value：面板组件的内部状态是 Panel Values，可通过 Panel CHOP、OP.panel Python 表达式或 Panel Execute DAT 访问。

Panel 或 Control Panel：在 TouchDesigner 内构建的自定义交互控制面板。面板用 Panel Components 创建。

Parameter：TouchDesigner 中每个操作符都有一组控制参数，可以是整数或浮点数、菜单、二值开关、文本字符串或操作符 paths，它们决定操作符的输出。

Parameter Dialog：显示某个操作符参数的浮动对话框、窗格类型，或 Network Editor 中的对话框。

Parameter Expression：参数表达式是写在参数表达式栏中的 python 表达式。

Parameter Mode：每个参数可以处于四种模式之一：Constant Mode、Expression Mode、Export Mode 或 Bind（Binding）Mode。

Parameter Reference：可以在任意两个参数之间建立参数引用，方法是在一个参数中写入引用另一个参数的表达式。这样会在两个参数之间建立 Link，一个变化时另一个会自动变化（在其他软件中称为「约束」）。

Parameter Size：在参数对话框中，把 Parameter Size 设为 3 会给出 3 列参数，例如分别控制 X、Y 和 Z。

Parameter Value：Parameter Value 指常量、表达式、导出、绑定引用和 Parameter Mode，它们共同决定参数的「求值」结果。

Parent：父子关系有两种。「父组件」是节点所在的组件。这个比喻也延伸到祖父、曾祖父等。根 / 是所有节点的最终父级。另请参阅 3D Parenting 和面板 Parenting。

Parent Shortcut：Parent Shortcut 是组件上的一个参数，其中包含一个名称，你可以在组件内任意位置用语法 parent.Name 引用该组件，例如用 parent.Effect.width 获取面板宽度。

ParGroup 或 Parameter Group：ParGroup 是一组相关参数，可以整体设置和获取，而不必逐个参数，比如 ParGroup t 是 tx ty tz。

Path 或 Network Path：操作符在 TouchDesigner 环境中的位置，例如 /geo1/circle1，即名为 geo1 的组件中名为 circle1 的节点。路径 / 称为 Root。该路径显示在每个 Pane 的顶部，表明你当前在哪个组件的网络中。若要指文件系统文件夹、目录、磁盘文件或 http: 地址，见 Folder。

Pattern Expansion：Pattern Expansion 接受一个短字符串并展开它，生成由各个元素组成的长字符串。

Pattern Matching：使用通配符和方括号匹配名称。在「Select」类参数中很有用，可选择多个操作符、路径、通道等。

Pattern Replacement：与 Pattern Matching 配合使用，用新数据替换匹配字符串的全部或部分。用于 Rename CHOP 等位置。

Perform Mode：Perform Mode 是为现场演出优化的模式，只渲染一个指定的 Window COMP，即一个包含视频输出和（可选）控制界面的窗口。在 Perform Mode 中不打开网络编辑窗口——你在 Designer Mode 中编辑网络。用 F1 和 Esc 切换。

Performance Monitor：TouchDesigner 内置的工具，在生成输出图像、音频和数据时分析和显示 TouchDesigner 正在做什么。

Pipe：把数据从一个 TouchDesigner 进程移到另一个进程的方式。图像通过 Touch Out / In TOP 传输，通道通过 Touch Out / In CHOP 和 Pipe Out / In CHOP 传输。数据通过 TCP/IP 或 UDP 传输。

Playbar：Playbar 是 Timeline 的旧称。见 Timeline。

Point：每个 POP 和 SOP 都有一个点列表。每个点有 XYZ 3D 位置值以及其他可选属性。每个多边形 Primitive 由顶点列表定义，即点编号的列表。

Polygon：多边形是一种 Primitive，由 3D 中的一组 Vertices 隐式连接成多边形状。

POP 或 Point Operators：POP（Point Operators）是一种 Operator Family，处理 3D 几何或任何通用数值数据的数组，运行在 GPU 加速的图形卡或芯片上，可渲染为图像，或传给 DMX 灯光、LED 阵列、激光等设备或其他外部系统。

Popup Help：帮助消息出现在以下情况：（1）光标移到 TouchDesigner 用户界面的元素上时，（2）点击每个操作符 Parameters 页角落的 ? 帮助按钮时，（3）按住 Alt 键并把光标移到 Parameter Dialogs 中的参数名上时，（4）对参数表达式中的选中文本求值时。

Primitive：POPs 中的一种表面类型，包括三角形、四边形、line strip 和点图元。Bezier、Cardinal 等曲线以带曲线专用属性的 line strip 实现。Points 和图元属于 Geometry Detail，而后者是 POP 的一部分。（旧版基于 CPU 的 SOPs 包括 NURBS 和 Bezier 曲线与面片，以及球体、管体和 metaball 图元。）

Privacy：TouchDesigner 组件（.tox 文件）或项目（.toe 文件）的私密性，是对网络的保护，使其可以被使用但不能被查看或编辑。

Procedural：程序化是指根据实时输入和 TouchDesigner 当前状态自动生成输出。它是 TouchDesigner 的连锁反应机制：若某份数据变化，会自动导致其他「dependent」操作符和表达式重新 Cook 并重新生成输出。

Projection Mapping：一种技术或工作流，用于在通常不规则的形状和表面上显示内容。

Pulse：对参数「脉冲」是指向它发送一个信号，来自（1）一个 exported CHOP 通道，或（2）一条 python 命令，或（3）一次鼠标点击，从而立即触发新动作。通过 python 脉冲是调用脉冲型参数（如 Speed CHOP 中的 Reset 参数）上的 .pulse() 函数。来自 CHOP 的脉冲通常是导出通道中 0 到 1 再到 0 的信号。

Quad Reprojection：Quad Reprojection 为任意朝向悬挂的平板电视和 LED 面板渲染像素精确、透视正确的图像。

Reference：节点之间的灰色虚线是 Reference（或 Link）。Reference 是（1）一个 Parameter Reference，即 OP 中作为另一操作符名称或路径的参数；（2）一个 Node Reference，即参数或 DAT 脚本中包含另一操作符名称或路径的表达式；（3）DAT Cell Reference；或（4）CHOP Channel Reference。

Reference 或 Link：一个 Link。节点之间的灰色虚线是 Reference 或 Link，表示一个操作符正从任意 Operator Family 的另一个操作符获取数据。

Render Flag：COMP 和 SOP 节点上的紫色标记，决定该节点是否会在 Render TOP 或 Render Pass TOP 中被渲染。该操作符还必须列在 Render / Render Pass TOP 的「Geometry」参数中。

Rendering：渲染是用 Render TOP 创建 3D 图像。渲染也泛指包括（用 TOP 进行的）合成以生成输出图像。

Replicator：为组件的每一行表格创建副本，或使用 Number of Replicants 参数——它是操作符的「for 循环」。与 Clone 不同，它会自动创建主组件的副本。

Resolution：图像以像素为单位的宽度和高度。大多数 TOP（如 Movie File In TOP）可以设置图像分辨率。图像的宽高比见 Aspect Ratio，其中考虑了非方形像素。

RMB Menu：在 TouchDesigner 不同部位点击鼠标右键时出现的菜单。（有时需要按住 Ctrl。）

Root：TouchDesigner 是组件的层级结构。「root」是层级中最顶层的网络。根的 Network Path 或 Path 就是 /。典型路径是 /project1/moviein1。

Sample Rate 或 Sample：一个 CHOP 的每秒采样数。网络中的每个 CHOP 都有采样率。相对地，整体时间轴有一个 Frame Rate，即每秒 cook 和显示的帧数，通常是显示器的刷新频率，默认 60。

Scope：大多数 CHOP 中的一个参数，用于限制该 CHOP 的哪些通道会受影响。通常 CHOP 的所有通道都会受操作符影响。TOP 有 Channel Mask，是类似的功能。

Script：位于 Text DAT 中的一组命令，在特定条件下被触发运行。TouchDesigner 中有两种脚本语言：Python 和最初的 Tscript。脚本和单行命令也可以在 Textport 中运行。

Sequential Parameters 或 Sequence Blocks：Sequential Parameters 是参数块（Sequential Blocks），用户可以多次复制它们以创建多个实体。

Shader：在 GPU 上运行、从多边形和纹理生成渲染图像的 OpenGL（2022 年前）或 Vulkan（2022 年起）代码。着色器用 Text DATs 编写，由 GLSL Material 或 GLSL TOP 引用。着色器最多由三部分组成：Vertex Shader、Pixel Shader 和 Compute Shader。

Shortcut：操作符快捷方式是返回操作符（有时是参数）的 Python 对象。其中包括用于在该组件内部访问该组件的 Parent Shortcuts，以及可从 TouchDesigner 任意位置访问某个唯一组件的 Global OP Shortcuts。

Snippets：OP Snippets 是 700 多个 TouchDesigner 操作符实时示例的集合。你可以通过 Help 菜单、右键点击网络中的操作符，或右键点击 OP Create 对话框中的条目来访问这些片段。

SOP 或 Surface Operator：一种 Operator Family，用于读取、创建和修改 3D 点、多边形、线、粒子、曲面、球体和 metaball。粒子和点云现在主要用 TOP 在 GPU 上完成。

Status Bar：TouchDesigner 窗口顶部的一行文字，在某些事件成功或失败时显示 TouchDesigner 的消息。

Storage：Storage 是每个操作符中的 python 字典，用户可以在其中存放和取出额外数据。

Swizzle: .

Synth：Synths 是 TouchDesigner 所创作作品的旧称。一个 Synth 由 TouchDesigner 创建的 .toe 文件，以及运行作品所需的全部相关媒体文件组成，这些文件用于在 TouchPlayer 中运行，或在 Perform Mode 中的 TouchDesigner 中运行。

Table DAT：一种 DATs（Data Operators），结构为文本字符串的行与列。

Tag：每个操作符可以有一组文本字符串作为其「标签」。你可以在 TouchDesigner 中设置并搜索它们。

Tangent: .

Textport：可以手动输入命令和脚本的对话框。输出到 textport 的内容包括脚本错误，以及 python 代码中 print() 和 debug() 调用的消息。你也可以在 textport 中编辑 DAT。

Time Slice 或 Time Slicing：时间切片是从上一次计算帧到当前计算帧的时间。在 CHOP 中，它是包含上一次到当前计算帧之间 CHOP 通道采样的一组短通道。

Timeline：TouchDesigner 底部的面板，控制当前 TouchDesigner 项目的全局循环 Time，或仅控制某个组件。

TOP 或 Texture Operator：一种 Operator Family，用于创建、合成和修改图像，以及在文件与网络之间读写图像和影片。TOP 在图形卡的 GPU 上运行。

Topology 或 POP Topology：POP Topology 是构成 POP 的几何实体之间的关系，涉及 POP 的 Primitives、每个图元的 Vertx / Vertices，以及顶点所引用的 Points 列表。

Tscript：TouchDesigner 在 Python 之前原有的内置 Command 脚本语言。

Tuplet：tuplet 是出现在参数对话框中同一行的一组参数。tuplet 占用参数的一个 page。

Unicode：TouchDesigner 完全支持 Unicode 文本。Unicode 可以输入到参数、DAT、Python 脚本等中。Unicode 编码的文本文件可以加载到 DAT。文件路径可以包含任何对文件路径合法的 unicode 字符。

Vertex 或 Vertices：一串顶点在 SOP 中构成一个 Polygon。每个顶点是指向 Point List 的整数索引，每个 Point 保存 XYZ 位置以及法线、纹理坐标等属性。

VFS 或 Virtual File System：让你把文件嵌入 .tox 或 .toe 文件中。像 Movie File In TOP 这样读取普通文件的操作符，也可以用 vfs: 语法读取嵌入的 VFS 文件。

Viewer：节点的查看器可以是（1）节点的内部（Node Viewer），（2）一个浮动窗口（在节点上 RMB->View...），或（3）一个以图形方式显示操作符结果的 Pane。

Viewer Active：节点的一种状态，此时你可以操作其查看器中的内容（任意节点右下角的 +），比如在节点查看器中操作面板的控件，或操作 Geometry 组件查看器中的 3D 数据。Viewer Active 关闭时，即使查看器可见，你也可以通过点击/拖动节点来选择、移动和删除它们。

Viewer flag：每个节点都有一个查看器标记，用于在 Node Viewer 中开启或关闭该节点的查看器。

Widgets：Widgets 是位于 Palette 中的一组多样化的组件，专为构建用户界面而设计。

Window：TouchDesigner 中的 Window 是 Microsoft Windows 或 macOS 中的一个窗口，其中包含（1）存在于 Designer Mode 中的 TouchDesigner 编辑界面，或（2）Window Component 中用户创建的 Panel。用户创建的窗口可以跨 Multiple Monitors 无边框显示，也可以是带边框的浮动窗口，或弹出窗口。

Wire：把一个节点的输出连接到网络中另一节点的输入。相对地，见 Link。

WYSIWID：TouchDesigner 是 WYSIWID——What You See Is What It's Doing（所见即所做）。所有节点都可以有交互式数据查看器。
