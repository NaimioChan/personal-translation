Sprinkle SOP

摘要

Sprinkle SOP 用于向 SOP 的表面或体积添加 points。你可以根据 Method 菜单在表面上或闭合体积内创建点。Surface 方法使点的分布按单位表面积恒定，而 Per-Primitive 则给每个图元（通常是三角形）一个固定数量，与其大小无关。

第二个输入用于在变形表面上散布点时。你通常不希望点的分布在变形过程中跳动，因此把变形后的表面作为第二输入，未变形的表面作为第一输入。Sprinkle SOP 会先在未变形表面上分布点，再把它们放到变形表面上对应的位置。

参数 - Sprinkle 页

Seed seed - 任意数字，整数或非整数，用作随机数生成器的起始值。每个数字给出完全不同的点位置。
Method method - 描述点的位置。
  • Surface surface - 点沿几何的整个表面均匀分布。也就是说，较小的多边形平均得到的点比大多边形少，等等。
  • Per Primitive perprim - 点均匀分布在每个图元之间。也就是说，每个多边形得到相同数量的点。
  • Bounding Box boundingbox - 点在几何的包围盒体积内分布。这比 volume 方法更快，但精度较低。
  • Approximate Volume approxvol - 点在体积的近似范围内均匀分布。靠近表面的区域可能得到较少的点。
  • Volume volume - 点在几何的整个体积内均匀分布。
Number of Points numpoints - 创建的点总数。
Consolidate consolidate - 移除点，直到剩余点之间至少相隔最小距离。
Distance to Nearest Point neardist - 使用 Consolidate 选项时的最小距离。

Info CHOP 通道

Sprinkle SOP 的额外信息可通过 Info CHOP 获取。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
