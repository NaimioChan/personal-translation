Laser CHOP

摘要

Laser CHOP 生成可驱动激光投影仪的通道。它使用 POP、SOP 或 CHOP 的点与线，并以指定采样率输出通道，通常为每秒 10,000 到 96,000 个采样。Laser CHOP 可对激光投影仪反射镜的运动进行最佳控制，并增强颜色控制。特别是，它能更好地控制线条保持笔直、端点不被截断或过度绘制，并消除拖尾，这些都可以通过一组参数调整。

将 CHOP 通道发送到 Laser CHOP 时，CHOP 需要 x 和 y 通道，每个采样都会被解释为要绘制的点。要绘制多个形状，还需指定名为 id 的通道来标识每个形状。id = 0 的点属于第一个形状，id = 1 的点构成第二个形状。所有其他通道都会被解释为颜色通道，并对其应用消隐。这样就可以驱动不只启用了 RGB 二极管的激光器。

通过 ILDA Protocol 控制激光时，Laser CHOP 输出的通道可以发送到 Laser Device CHOP；使用 LaserAnimation Sollinger 的 AVB 设备时，则发送到 Audio Device Out CHOP，此时音频通过 Audio Device Out CHOP 输出到低延迟、支持 AVB 的音频设备，例如 MOTU、RME、LaserAnimation Sollinger 或 Apple macOS 的产品。

LaserAnimation Sollinger's AVB2ILDA devices 让你可以使用面向专业领域的功能。请参阅 Lasers。

此 CHOP 是在 LaserAnimation Sollinger 的帮助下开发的，他们指导我们制定规格并实现必要的参数，尤其是在消隐时序设置方面。Laser Animation Sollinger 也维护自己收费的 TouchDesigner 激光工具套装，其中包括基础 Laser CHOP 的扩展，增加了一些功能：LA.laserchop。

BACKWARD COMPATIBILITY (2025.30000): Laser CHOP 在 2025.30000 中经过全面改版，包含相对旧版本的许多更改与新增。某些更改（如移除 Start Point Hold Time 和 Input Rate）在将旧文件载入 2025.30000 或更新版本时可能导致输出差异。Input Rate 参数以前用于定义激光点生成期间的采样率，但现在始终以 192000 执行，然后再重采样到 Output Rate。这可能需要对 Step Size 或 Blanking Step Size 等参数进行调整，才能达到与旧版本相同的效果。

拐角点

Laser CHOP 将输入点分为拐角点或引导点。在 2025.30000 系列版本之前，所有点都被视为拐角点。

默认情况下所有输入点都是拐角点。要将点设为拐角点或引导点，对 SOP/POP 输入使用名为 LasCorner 的布尔属性，或对 CHOP 输入使用 lascorner 通道。LasCorner = 1 表示它是拐角点。

引导点只是帮助激光沿路径或曲线移动的点，它们所属的两段线之间不会出现线方向的突变。引导点只输出一次，从不重复。在沿曲线步进时，引导点还可用于点插值。

拐角点实质上定义了激光上单条线带的起点/终点。颜色插值与点位置步进在拐角点之间进行，引导点用于加权。当激光方向发生突变（例如直角或锐角）时也应使用拐角点，以便添加适当的保持点来提高图像的锐利度。

拐角点会按其角度和拐角保持参数重复。此外，为了对每个点进行额外控制，可以通过 SOP/POP 输入中的特殊属性或 CHOP 输入中的通道，使用拐角保持查找系数与保持增量：

  • LasCornerHoldAdd（SOP 或 POP）或 lascornerholdadd（CHOP）
  • LasCornerHoldLookupFactor（SOP 或 POP）或 lascornerholdlookupfactor（CHOP）

拐角保持重复次数按以下方式计算，其中 H 是由角度/参数计算出的保持值：

NumRepeatPoints = HoldAdd + HoldLookupFactor * H

消隐

消隐是激光投影仪在显示动画时快速开启/关闭激光的能力。例如显示多个形状时，激光需要消隐能力来略过形状之间的空白处。形状之间会自动消隐，但消隐点的数量由 Color 页上的一组消隐延迟参数以及 Scanning 页上的 Blanking Step Size 参数控制。

由于激光的反射镜由电机驱动，发送给激光的位置数据很可能超前于反射镜的实际位置 —— 反射镜必须追上数据。而颜色数据是实时的，因此效果可能表现为激光关闭颜色的位置出现可见拖尾。调整消隐参数有助于防止这种情况。

参数 - Laser 页

Active active - 禁用时，CHOP 会将所有通道置零。
Source OP source - 选择激光图像的源操作符类型。
  • SOP sop - 使用 SOP 作为激光图像的源。除位置属性外，SOP 的点颜色属性用于确定输出的颜色。
  • CHOP chop - 使用 CHOP 作为激光图像的源。CHOP 需要 x 和 y 通道，每个采样都会被解释为要绘制的点。要绘制多个形状，还需指定名为 id 的通道来标识每个形状。id = 0 的点属于第一个形状，id = 1 的点构成第二个形状。所有其他通道都会被解释为颜色通道，并对其应用消隐。这样就可以驱动不只启用了 RGB 二极管的激光器。
  • POP pop - 使用 POP 作为激光图像的源。除位置属性外，POP 的颜色属性用于确定输出的颜色。
SOP sop - SOP 的路径。SOP 的位置与颜色属性（以及 LasCorner 等其他杂项属性）将用于生成激光点。
CHOP chop - CHOP 的路径。输入 CHOP 必须有点位置的 x、y 通道。此外还支持 z、r、g、b 和 id 通道。id 通道用于将点归组为单个形状。默认情况下，当没有 id 通道时，每个点都是独立、不相连的。对于接受 r、g、b 以外颜色的激光投影仪，可以添加额外且任意命名的颜色通道。额外通道包括：「lascorner」、「lascornerholdadd」和「lascornerholdlookupfactor」。
POP pop - POP 的路径。POP 的位置与颜色属性（以及 LasCorner 等其他杂项属性）将用于生成激光点。
Output Sample Rate outputrate - Laser CHOP 的采样率，也是它输出到激光的采样率。在默认每秒 48000 个采样、60fps 帧率下，Laser CHOP 每帧可输出 800 个位置与颜色值。
Swap Output swap - 交换输出的 x 与 y 轴。
X Scale xscale - 控制输出的水平缩放。
Y Scale yscale - 控制输出的垂直缩放。
Rotate rotate - 控制输出的旋转。
Camera camera - 指定用于从摄像机视角绘制 SOP 的 Camera COMP 路径。
Update Method updatemethod - 控制 Laser CHOP 如何从其源拉取数据。

大多数情况下你会希望保持默认设置「When All Points Drawn」。

有一种特定用法需要「Every Frame」更新方式。背景是 Laser CHOP 可能必须在多帧内绘制输入值。例如，给定一个含 200 个采样值的源，在以某个采样率应用所有消隐与步长设置后，激光可能需要超过一帧来绘制完整图像。效果会表现为激光图像闪烁。使用默认设置时，激光在完成绘制之前所有值后才会从输入获取一组新采样。使用「Every Frame」更新方式时，激光会在每帧之后获取剩余采样的更新值。

  • When All Points Drawn alldrawn - 一旦上一帧的所有点绘制完成，Laser CHOP 就会读取源数据。
  • Every Frame everyframe - 无论上一帧是否绘制完成，Laser CHOP 都会每帧更新输入。
Frame Start Pulse startpulse - 启用后，会在激光帧开头插入一个所有颜色均为 -1 的采样。
Debug Channel debugchan - 启用后，将包含一个额外的点状态通道：
  • -1：帧起始脉冲
  • 0：颜色
  • 1：拐角保持点
  • 2：起始点保持时间
  • 3：前置消隐开启
  • 4：后置消隐开启
  • 5：消隐
  • 6：前置消隐关闭
  • 7：后置消隐关闭
Corner Attribute Name cornerattr - 对于 SOP 和 POP 输入，可选择更改用于指定某点是否为拐角点的点属性名称。默认是 LasCorner。
Corner Hold Add Attribute Name cornerholdaddattr - 对于 SOP 和 POP 输入，可选择更改用于为拐角保持时间加上一个常量值的点属性名称。默认是 LasCornerHoldAdd。
Corner Hold Factor Attribute Name cornerholdfactorattr - 对于 SOP 和 POP 输入，可选择更改用于对拐角点保持应用查找系数的点属性名称。默认是 LasCornerHoldLookupFactor。

参数 - Scanning 页

Step Size stepsize - 输出颜色时 x、y 每次可改变的距离。
Blanking Step Size bstepsize - 不输出颜色（消隐）时 x、y 每次可改变的距离。
Minimum Corner Hold mincornerhold - 点的拐角保持的最小值。点的拐角保持值根据该点处角度的陡峭程度，在最小到最大拐角保持之间线性计算。该角度由以下三个点计算：前一个点、该点本身和后一个点。例如：当该点处角度为 180 度时，该点的拐角保持为最小值。
Maximum Corner Hold maxcornerhold - 点的拐角保持的最大值。详情见 Minimum corner Hold。当该点处角度为 0 度时，拐角保持为最大值。如果最大值低于最小值，最大值会向上钳制。
Corner Hold Lookup CHOP cornerholdchop - 引用一个 CHOP，用作在最小到最大保持之间插值时的自定义查找曲线。默认情况下（即未指定 CHOP 时）为线性插值。
Closed Shape Overlap closedoverlap - 对于闭合形状，起始/结束重叠的点数（以毫秒指定），以利用颜色插值并获得更均匀的形状。

参数 - Color 页

这些参数让你控制激光颜色通道的生成方式。尤其要注意消隐设置，需要根据激光投影仪的能力进行调整。

Red Scale redscale - 设置红色通道的强度。
Green Scale greenscale - 设置绿色通道的强度。
Blue Scale bluescale - 设置蓝色通道的强度。
Pre Blanking On Delay preblankon - 设置激光在关闭颜色输出前应在某位置等待的时间，单位 ms。
Post Blanking On Delay postblankon - 设置激光在关闭颜色输出后应在某位置等待的时间，单位 ms。
Pre Blanking Off Delay preblankoff - 设置激光在开启颜色输出前应在某位置等待的时间，单位 ms。
Post Blanking Off Delay postblankoff - 设置激光在开启颜色输出后应在某位置等待的时间，单位 ms。
Start-Point Hold Time starthold - 设置激光在新数据帧的第一个点处继续之前应等待的时间，单位 ms。
Color Delay colordelay - 设置输出中各颜色通道的延迟，单位为 ms。
Interpolate Colors interpcolors - 启用后，在点之间对颜色进行插值。
Brightness Curve Lookup CHOP brightnesscurvechop - 引用一个 CHOP，用作闭合形状软边混合的自定义查找。

参数 - Common 页

Time Slice timeslice - 开启后强制通道为「Time Sliced」。Time Slice 是上一个计算帧与当前计算帧之间的时间。
Scope scope - 为了确定哪些通道受到影响，一些 CHOP 在 Common 页上使用 Scope 字符串。
Sample Rate Match srselect - - 处理多个输入 CHOP 采样率不同的情况。发生重采样时，曲线按 Interpolation Method 选项进行插值；若没有可用的 Interpolate 选项，则按「Linear」插值。
  • Resample At First Input's Rate first - 使用第一个输入的速率重采样其他输入。
  • Resample At Maximum Rate max - 重采样到最高采样率。
  • Resample At Minimum Rate min - 重采样到最低采样率。
  • Error If Rates Differ err - 不接受互相冲突的采样率。
Export Method exportmethod - - 这决定如何把 CHOP 通道连接到参数。更多信息请参阅 Export 文章。
  • DAT Table by Index datindex - 使用停靠的 DAT 表格，并通过通道在该 CHOP 中的索引来引用通道。
  • DAT Table by Name datname - 使用停靠的 DAT 表格，并通过通道的名称来引用通道。
  • Channel Name is Path:Parameter autoname - 通道即完整的导出目标位置，例如 geo1/transform1:tx。
Export Root autoexportroot - 该路径指向根节点，通过 Channel Name is Path:Parameter 导出的所有路径都相对于它。
Export Table exporttable - 使用 DAT Table Export Methods 时用来存放导出信息的 DAT（见上文）。

Info CHOP 通道

Laser CHOP 的额外信息可以通过 Info CHOP 访问。

通用 CHOP Info 通道

  • start - CHOP 区间的起始，以采样计。
  • length - CHOP 中的采样数。
  • sample_rate - 通道的采样率，单位为帧每秒。
  • num_channels - CHOP 中的通道数。
  • time_slice - 如果 CHOP 启用了 Time Slice 则为 1，否则为 0。
  • export_sernum - 导出连接被更新的次数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
