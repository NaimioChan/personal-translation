DMX

DMX Out POP、DMX Fixture POP、DMX Out CHOP 和 DMX In CHOP 支持 DMX 及其衍生协议。

sACN（Streaming Architecture for Control Networks）是一种通过 UDP 在 IP 网络上传输的 DMX 协议。

Art-Net 是 DMX512-A 协议在 UDP 上的实现。

也支持 FTDI（串口 DMX）。FTDI 驱动版本 2.12.16

KiNET 是 Philips Color Kinetics 灯具用来接收 DMX 的网络协议。它与 ArtNET 和 sACN 非常相似。
