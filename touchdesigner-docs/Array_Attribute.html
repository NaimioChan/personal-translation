数组属性


Array Attribute 是一种 Attribute，包含多个所选 Attribute Data Type 的 elements。例如，一个数组属性可以由每个点的 12 个整数元素组成。这使 POP 能够保存更复杂的数据，并以最小的开销在 GPU 上进行大量计算。

与任何属性一样，每个数组属性都有一个 Data Type，它可以是（32 位）float、integer、unsigned integer（uint）、double（双精度 float）、矩阵或四元数，也可以是 1、2、3 或 4 分量的「向量」，如 float2、float3、float4。例如，一个数组属性可以是 12 个 float4 向量：float4[12]。

How to create array attributes -

  • Attribute POP - 在 Create 页的 New Attribute 下，为它指定一个名称（示例：MonthlyTempC）、一个 Type（float）、一个 Size（1 - 每个数组元素将是单个 float）。打开 Array 开关并指定元素数量（例如 12）。在弹出提示和节点查看器中会显示为 MonthlyTempC[12] - 12 个浮点数，默认值为 0。
  • Math Combine POP - 在其 New 页上，以同样的方式创建带常量值的数组属性。
  • DAT to POP - 对于来自 DAT 的数据，它可以根据列标题中的名称创建数组属性，例如 MyArray[0] MyArray[1] MyArray[2] 表示一个 float 数组，并会把名称相似的列收集到一个数组属性中。
  • CHOP to POP - 它可以根据 CHOP 通道的命名创建数组属性。例如通道名 Abc_0_ 和 Abc_1_ 会创建一个名为 Abc 的数组属性，包含 2 个 float 元素。将 Convert with Channels Selection 设为 Autoconvert Precise Names。
  • Combine 页上的 Math Mix POP 和 Math Combine POP 可以从其他数组属性创建数组属性。
  • GLSL POP（GLSL POP、GLSL Advanced POP、GLSL Copy POP）可以创建类似于 Attribute POP 的新数组属性。

How to set values in Array Attributes -

  • 从 Lookup Channel POP 或 Random POP 填入值。
  • 在 Math Mix 的每个 Combine 块中一次手动创建一到四个元素：Operation 为 A，A 为任意数值，输出为 MonthlyTempC[0]，然后是 MonthlyTempC[1]，依此类推。（每个块可以对 A 做 4 个值。）
  • Math Mix 和 Math Combine POP 中的内置属性 _ArrayI 和 _ArrayU 会在数组属性的各元素中给出递增的值。
  • 在 GLSL POP（GLSL POP、GLSL Advanced POP、GLSL Copy POP）中用自定义代码设置值

How to do math on Array Attributes - Math Mix 和 Math Combine POP 在其 Combine 页上，只要在 A、B 或 C 字段中指定了数组属性，就会自动应用「数组循环」。所需的 [:] 表示该运算会在每个数组元素上执行，大致遵循 Python 语法。若某个数组属性有 N 个元素，顺序块将重复 N 次。它对每次循环应用相同的参数，使用所指定数组的第 N 个元素，并把结果放入该块输出属性中现有或新建的 N 尺寸数组的第 N 个元素。目前不支持用 [x:y]（范围为 x 到 y）在某个范围内执行该运算。

例如，要把每月温度从摄氏度转换为华氏度，在一个顺序块中，让数学 Operation 为 A * B + C，在 A 中填入 MonthTempC[:]，在 B 中填入 1.8，在 C 中填入 32，并在输出中填入一个新名称 MonthTempF[:]。这会对 MonthTempC 的每个元素把摄氏温度转换为华氏温度（度数 * 1.8 + 32），结果放入一个名为 MonthTempF、含 12 个元素的新数组属性中。

如果 POP 的每个点代表一个城市，而 MonthTempC 包含 12 个月份各自的平均温度，那么它就在一个顺序块中为所有城市的所有月份做温度转换。

POPs supporting array attributes - 可对数组属性进行操作的 POP 列在下面。

  • Math Combine POP 和 Math Mix POP - 在 Combine 页上会遍历数组元素。
  • Math Combine POP - 在 New Attributes 页上可以创建数组属性。在 Pre 和 Post 页上，数学运算可以作用于数组属性。
  • Lookup Channel POP、Lookup Texture POP、Lookup Attribute POP - 支持遍历数组元素。
  • Math POP、ReRange POP、Limit POP、Quantize POP Normalize POP - 支持遍历数组元素。
  • Noise POP - 遍历数组元素，在与数组输入属性组合时，或在把数组属性用于 Noise Lookup Attribute 时——它对每个数组元素使用相同的种子。
  • Random POP - 仅在与数组输入属性组合时遍历数组元素。如果没有输入属性数组，它也不允许输出到新的数组属性。它对每个数组元素使用不同的种子。

Combining the elements of an array down to one element（非数组）- Math Combine POP 和 Math Mix POP 上的 Operation 菜单包含用于组合每个点的数组元素的函数。这些函数是 arrayavg()、arrayadd()、arraymult()、arraymin()、arraymax() 和 arraylength()，把数组的元素组合成一个。

如果你不想组合所有元素，而只想组合前 N 个元素，可以用第二个整数属性按以下语法 [:ArraySizeAttrName] 指定每个点的元素数量。例如，在处理来自 Neighbor POP 的数组属性时，你会使用 [:NumNebr]。

Built-In Read-Only Attributes for Arrays - POP 属性名菜单中有一些适用于数组的内置只读属性。它们是：_ArrayI（元素在数组中的索引）、_ArrayU（在 0 到 1 之间归一化），以及 _ArrayCy（从 0 归一化到接近 1，使其成为循环）。

记法 - float4 数组属性、int3 数组属性。数据类型 / 数组 / 属性
