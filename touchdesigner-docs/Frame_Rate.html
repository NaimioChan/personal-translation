帧率

帧率是 TouchDesigner 的 Timeline 运行所用的每秒帧数（FPS）。

项目的全局帧率通过 Project Class 的 project.cookRate 成员设置。

所有非音频 CHOPs 的采样率默认都设为此帧率。

每个组件都可以有自己的帧率和起止范围。见 Time COMP。

帧率存储在时间轴的 Time COMP 中名为 Rate 的参数里。可以通过时间轴 UI、直接通过组件的 Rate 参数，或通过 timeCOMP Class 的 rate 成员来设置。

注意，Movie File In TOP 读取的影片文件可能有自己的「frame rate」或「frames per second」，但在 TouchDesigner 中我们称之为影片的「images per second」或「sample rate」，以避免混淆。

参见 Optimize。
