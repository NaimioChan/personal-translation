操作符快捷名

在 TouchDesigner 中有三种为操作符提供快捷名称的方式：

Parent Shortcuts 从该组件内部访问更高层级的组件。

Global OP Shortcuts 从 TouchDesigner 中的任何位置访问某个唯一组件。

Internal Operator Shortcuts 和相关的 Internal Parameter Shortcuts 让组件内部的操作符可以方便地访问同一组件内的其它操作符。

这些不应与 Keyboard Shortcuts 混淆。

Python 快捷对象

有许多 Python 对象为 TouchDesigner 中的各种操作符快捷方式提供支持。它们可以通过 Td Module 在全局命名空间中访问，也可以作为 OP Class 的成员相对于操作符访问。详细用法说明请参阅那些链接。以下是这些对象本身的简要说明：

Shortcut - 所有其它快捷类的父对象。

  • OPShortcut - 最常用的快捷方式，通过 op 访问。根据提供的路径（参数）或 Global OP Shortcut（成员）返回一个操作符（若未找到路径则返回 None）。
  • OPEXShortcut - 工作方式与 OPShortcut 相同，但在未找到操作符路径时会抛出异常。通过 opex 访问。
  • OPsShortcut - 工作方式与 OPShortcut 类似，但接受多个模式（包括通配符）作为参数，并返回匹配的操作符列表。
  • ParentShortcut - 允许访问操作符的层级父级。根据提供的层级数（参数）或 Parent Shortcut 名称（成员）返回一个操作符。
  • IOPShortcut - 允许访问在组件参数中定义的 Internal Operators。返回一个操作符。
  • IparShortcut - 允许访问在组件参数中定义的 Internal Parameters。返回一个参数。这基本上与 IOPShortcut 相同，但返回操作符的 par 成员而不是操作符本身。
