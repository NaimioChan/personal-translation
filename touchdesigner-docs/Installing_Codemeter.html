安装 CodeMeter

安装所需的 Codemeter 软件

要使用 USB 许可证 Dongle 或浮动云许可证，系统上需要 Codemeter Runtime 软件。

注意： 请更新到 CodeMeter Runtime 7.60+

Windows CodeMeter 安装

  • 安装 TouchDesigner 时，安装程序的第一个对话框会有一个「Install Runtime for Dongle Licensing」选项，确保勾选它。继续安装。你也可以从这里下载 dongle 运行时 CodeMeter Download。建议在 CodeMeter 安装程序选项中关闭「Automatic server search」选项，以便在安装了许多 CodeMeter 机器的网络上更快启动。

macOS CodeMeter 安装

  • 从此处下载并安装 CodeMeter Control Center：

CodeMeter Download

如果软件或服务无法启动，你可能需要在系统的 Security Preferences 中启用它。
