Python 拖放实验性迁移

在 TouchDesigner 2020.40k 中，发布了新的 Python 拖放系统。在实验性开发过程中，回调系统以不向后兼容的方式发生了变化。

This is a guide to moving from the Python Drag/Drop system previous to 2020.46450 experimental release.

变化在于回调参数

所有回调参数现在都采用 (comp, info) 形式。comp 参数未变，但 info 参数现在是一个字典，包含之前提供的所有参数。这让我们可以保持参数不变，同时随着系统变得更完善，仍能向这些回调添加有用信息。

迁移步骤

从最初的实验性系统迁移相当简单。只需更改函数的参数，然后从中取出信息。

1) 更改参数

只需将函数定义中的参数文本替换为 (comp, info)。例如：

def onDropGetResults(comp, info):

.

2) 从 info 字典中取出信息

每个回调都不一样。总体流程是把字典中的信息放入各自的变量，就像它们作为参数传入一样。加入以下几行 before any other code 就能让你旧的回调重新工作：

  • onHoverStartGetAccept
dragItems = info['dragItems']
  • onHoverEnd
dragItems = info['dragItems']
  • onDropGetResults
dragItems = info['dragItems']
  • onDragStartGetItems
无需代码。
  • onDragEnd
accepted = info['accepted']
dropResults = info['dropResults']
dragItems = info['dragItems']
