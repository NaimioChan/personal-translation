Execute DAT

摘要

Execute DAT 可用于编辑脚本，并按条件运行它们。它可以在每一帧的开始或结束时执行，也可以在 TouchDesigner 进程的开始或结束时执行。

Execute DAT 用 default python method placeholders 创建。参数中每个被监视的条件，在 DAT 中都有一个对应的 python 方法。在参数中打开某个条件后，每次满足该条件时都会执行对应的 python 方法。

文本也可以通过节点的输入传入 Text DAT，但该文本不可编辑。文本可以在 DAT 中通过 Node Viewer 或外部文本编辑器创建。

另请参阅 OP Execute DAT。

executeDAT_Class

参数 - Execute 页

Active active - 开启时，DAT 会响应下面选定的事件。
Execute from executeloc - - （仅 Tscript）决定脚本运行的位置。
  • Current Node current - （仅 Tscript）脚本从当前节点位置执行。
  • This Node here - 脚本从 DAT 的父级执行。DAT 从父级执行是为了便于访问 DAT 的同级：过去 DAT 脚本是从 DAT 内部执行的。
  • Specified Operator op - 脚本从下方 From Operator 参数指定的操作符中执行。
From Operator fromop - 若 Execute From 参数设为 Specified Operator，该组件也是脚本执行时所在的路径。
Start start - onStart() 方法在 TouchDesigner 启动时执行。该方法在 TouchEngine 中永远不会被调用，因为组件是在 TouchEngine 启动之后才加载的。
Create create - create() 方法在节点被创建时执行。可以在启动时触发，也可以通过从磁盘加载组件、复制粘贴，或任何其他创建节点的方式触发。
Exit exit - onExit() 方法在 TouchDesigner 进程退出时执行。
Frame Start framestart - onFrameStart() 方法在每一帧开始时执行。
Frame End frameend - onFrameEnd() 方法在每一帧结束时执行。
Play State Change playstatechange - onPlayStateChange() 方法在每次播放状态改变时执行，即在时间轴上使用暂停或播放时。
Device Change devicechange - onDeviceChange() 方法在每次有设备连接到计算机或从计算机断开时执行。例如插入 MIDI 设备、摄像机、游戏手柄等。

注意： 当多个 Execute DAT 都使用 Start 和 Create 函数时，它们按 DAT 名称的字母数字顺序依次触发。

Edit.. edit - 点击后会打开文本编辑器，用于编辑 DAT 中的文本。

提示： 要把 python 的所有「标准输出」导向一个 Text DAT，可在 start() 方法中写入：sys.stdout = op('text1')

要安全地做到这一点并恢复标准输出：

prev = sys.stdout
sys.stdout = op('text1')
sys.stdout = prev

参数 - File 页

File file - 要加载的文件的文件系统路径和名称。接受 .txt 和 .dat 文件。
Sync to File syncfile - 开启时，在项目启动时将文件从磁盘加载到 DAT 中。必须指定文件名。开启该选项会立即从磁盘加载文件。如果文件不存在，则在 DAT 第一次更新时创建它。系统会监视该文件，对文件的任何改动都会更新 DAT，而对 DAT 的任何改动都会立即写入文件。如果文件被移除，DAT 将保留其当前内容。
Load on Start loadonstart - 开启时，项目启动时从磁盘重新加载文件到 DAT 中。
Load File loadonstartpulse - 立即重新加载文件。
Write on Toe Save write - 开启时，保存项目时将 DAT 的内容写入磁盘文件。
Write File writepulse - 立即将文件写入磁盘。

参数 - Common 页

Language language - - 选择 DAT 如何决定使用哪种脚本语言。
  • Input input - DAT 使用输入的脚本语言。
  • Node node - DAT 使用它自己的脚本语言。
Edit/View Extension extension - - 选择此 DAT 应向外部编辑器公开的文件扩展名。
  • dat dat - 各种常见的文件扩展名。
  • From Language language - 从 DAT 的脚本语言中选取扩展名。
  • Custom Extension custom - 指定自定义扩展名。
Custom Extension customext - 指定自定义扩展名。
Word Wrap wordwrap - - 为节点显示启用 Word Wrap。
  • Input input - DAT 使用输入的设置。
  • On on - 开启 Word Wrap。
  • Off off - 关闭 Word Wrap。

  • Input 0: -

Info CHOP 通道

Execute DAT 的附加信息可通过 Info CHOP 获取。

常见 DAT 信息通道

  • num_rows - 此 DAT 中的行数。
  • num_cols - 此 DAT 中的列数。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
