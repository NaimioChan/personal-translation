动画编辑器

说明

Animation Editor 可让你创建和编辑存储在 Animation COMPs 中的关键帧动画。

要打开 Animation Editor，右键单击 Animation COMP 并选择 Edit Animation...，在编辑器中打开该动画。你也可以将任意窗格改为 Animation Editor 类型，编辑器会打开并指向最后一次被 scope 的 Animation COMP。

编辑器会显示被 scope 的 Animation COMP 内的通道（被 scope 的 Animationm COMP 显示在 Path 字段中）。要编辑其他 Animation COMP，可右键单击该 COMP 并选择 Edit Animation... 来更改此路径。

点击 Add Channel 按钮创建通道并开始制作动画。与通道和关键帧交互的技巧请参阅下文的 Working With Channels 和 Working With Keys 小节。编辑器可让你创建和删除通道，以及添加、编辑或删除关键帧。

界面

关键帧动画的设置

关键帧动画在 Animation Editor 中创建和编辑。创建的通道和关键帧存储在 Animation COMPs 中。可以使用这些动画工具直接在参数上制作动画。下文各节介绍如何使用这些工具。

从 Animation Component 开始

要开始创建关键帧动画，首先需要一个 Animation Component。Animation Component 是存储关键帧通道数据的地方。一个项目中可以创建多个 Animation COMP，Animation COMP 也可以保存出来在其他项目中使用。

Animation Editor 一次可让你为一个 Animation COMP 创建通道并打关键帧。要在编辑器中编辑某个 Animation COMP，右键单击要加载到编辑器中的组件并选择 Edit Animation...

这会打开编辑器并 scope 所选的 Animation COMP，这会在 Path 字段中确认。

处理通道

添加通道

添加通道时，通道会被创建并存储在 Path 字段引用的 Animation COMP 中。要创建通道，将通道名称添加到 Names 字段，然后点击 Add Channels。通道将被创建并加入通道列表。可以通过在 Names 字段中指定多个通道名（显式指定或使用 pattern matching），然后点击 Add Channels，一次创建多个通道。

查看通道

编辑器左侧的通道列表显示被 scope 的 Animation COMP 的所有通道。只有在列表中选中的通道才会显示在右侧的查看器中。点击任意通道即可选中。使用 <Shift>+单击可选择多个相邻通道。使用 <Ctrl>+单击可将任意通道加入或移出所选集合。

将通道设为模板

在 channel editor 中可将通道置于模板模式，使其可见但不可编辑。要将通道设为模板，开启通道名称右侧的粉色 template 标记。模板通道在编辑器中以虚线显示。

删除通道

要删除通道，点击通道列表中该通道右侧的「X」按钮。

通道设置

通道设置可让你为通道设置 Extend Conditions。extend 条件定义通道在其起止范围之外的值。选择要更改设置的通道，然后使用 Extend Left 和 Extend Right 菜单设置该通道的 extend 条件。Default Value 字段在通道的 extend 条件设为 Default Value 时使用。

处理关键帧

所有通道创建时都带有起始和结束关键帧，用于定义通道的长度。

要向通道添加关键帧，使用 Alt+LMB。这会在光标处的通道上添加单个关键帧。

要向多个通道在特定时间添加关键帧，先选中所有要添加关键帧的通道（框选所需的段），然后使用 Alt+MMB。

要在特定时间为所有通道添加关键帧，使用 Alt+RMB。

要删除关键帧，选中关键帧后按 Delete 按钮。

选择关键帧

按住 Shift 时，点击的关键帧与此前及此后已选关键帧或段之间的所有关键帧和段都会被选中（即范围选择）。

按住 Ctrl 点击关键帧可以将该关键帧加入或移出选择。

ALT+MMB 现在可以给选中的通道段打关键帧，ALT+RMB 可以给所有通道打关键帧。

移动和编辑关键帧

要移动关键帧，用 LMB 拖动它。可以选中多个关键帧后用 LMB 拖动来移动它们。

要将移动限制为仅值或仅时间（即单一轴），按住 Shift 并用 LMB 拖动。

可以用 LMB 操作切线手柄来调整切线。要打断切线连续性（连接与断开切线），选中切线后按 <t> 键。
