TDU 类

TDU 类是一个通用工具类，包含所有不专门针对 TouchDesigner 数据结构的杂项实用函数和成员。要访问此类的成员和方法，请使用默认实例 tdu。

成员

fileTypes → dict (Read Only):

按类别整理的所有受支持文件类型的字典。 

# Movie File In TOP 接受的各种文件类型示例
tdu.fileTypes['movie']
tdu.fileTypes['image']

# 其他文件类型
tdu.fileTypes['audio']

注意：可接受的文件类型既有大写也有小写，因此如果 suffix 是后缀字符串，你需要用 suffix.lower() 强制其转为小写： 

for suffix.lower() in tdu.fileTypes['movie']:
	print(suffix)

Position 定义类。

Vector 定义类。

Quaternion 定义类。

Color → TDU.Color (Read Only):

Color 定义类。

Dependency → TDU.Dependency (Read Only):

Dependency 定义类。

FileInfo → TDU.FileInfo (Read Only):

FileInfo 对象接收一个文件路径，并有几个实用属性来提供额外信息。它派生自 str，因此可以像 Python 字符串一样使用，但可以用 isinstance(tdu.FileInfo) 把它与普通字符串区分开。

实用属性包括：

  • path：文件路径字符串
  • ext：包含 "." 及其之后的字符串
  • fileType：TD 文件类型（来自 tdu.fileTypes）
  • absPath：filepath 的绝对路径
  • dir：filepath 所在的目录
  • exists：是否存在于文件系统中
  • isDir：是否为文件系统中的目录
  • isFile：是否为文件系统中的文件
  • baseName：路径中最后一个元素的名称

MenuObject → TDU.MenuObject (Read Only):

带 menuNames 和 menuLabels 字段的命名元组。一般用于 Par.menuSource。使用 tdu.ParMenu 和 tdu.TableMenu 可以方便地创建它们。 

tdu.MenuObject(['name1', 'name2'], ['Label One', 'Label Two'])

方法

rand(seed)→ float:

给定输入种子值，返回区间 [0.0, 1.0) 内的随机值。也就是说，它永远不会返回 1.0，但可能返回 0.0。对于给定的种子，它总是返回相同的随机数。种子不必是数字。如果种子不是数字，会解析为其字符串表示以产生唯一值。例如对于 OP，其字符串表示是一个固定路径。因此可以为每个 OP 生成唯一的随机值，且在每次重新加载 TouchDesigner 时对该 OP 保持不变。 

tdu.rand(me) # 根据路径返回一个特定的随机数
tdu.rand(5) # 返回一个特定的随机数
tdu.rand(absTime.frame) # 每帧返回不同的数值

clamp(inputVal, min, max)→ float | int:

返回在最小值与最大值之间被限制的输入值。参数可以是任何可比较的类型（float、int、str 等）。

remap(inputVal, fromMin, fromMax, toMin, toMax)→ float:

返回从第一个区间重映射到第二个区间的输入值。 

tdu.remap(0.5, 0, 1,  -180, 180)  # 把滑块值重映射到角度范围

base(str)→ str:

返回字符串中任何数字之前的前导部分。如果存在斜杠，搜索从最后一个斜杠之后开始。

  • str - 要从中提取基础名称的字符串。
tdu.base('arm123') # 返回 'arm'
tdu.base('arm123/leg456') # 返回 'leg'

注意此方法对任何字符串都可用，但针对特定操作符时，使用其本地的 base 成员更高效： 

n = op('arm123/leg456')
b = n.base # 返回 'leg'

digits(str)→ int | None:

返回字符串中最后一组连续数字的数值，如果找不到则返回 None。如果存在斜杠，搜索从最后一个斜杠之后开始。数字不一定需要在字符串末尾。 

tdu.digits('arm123') # 返回 123
tdu.digits('arm123/leg456') # 返回 456
tdu.digits('arm123/leg') # 返回 None，只在最后一个 / 之后进行搜索
tdu.digits('arm123/456leg') # 返回 456

注意此方法对任何字符串都可用，但针对特定操作符时，使用其本地的 digits 成员更高效： 

n = op('arm123/leg456')
d = n.digits # 返回 456

validName(str)→ str:

返回适合作为操作符名称的字符串版本。非法字符会转换为下划线。

斜杠会转换为下划线。要保留正斜杠，请改用 validPath()。 

tdu.validName('a#bc def') # 返回 'a_bc_def'

validPath(str)→ str:

返回适合作为操作符路径（含斜杠）的字符串版本。非法字符会转换为下划线。 

tdu.validPath('/a#bc d/ef') # 返回 '/a_bc_d/ef'

expand(pattern)→ list:

按 Pattern Expansion 的规则返回展开后的项目列表。 

tdu.expand('A[1-3] B[xyz]') # 返回 ['A1', 'A2', 'A3', 'Bx', 'By', 'Bz']

expandPath(path)→ str:

使用 project.paths、当前文件夹和其他相关信息展开文件路径。 

tdu.expandPath('movies:/test.bmp') # 在 project.paths 中查找 'movies' 项。

collapsePath(path, asExpression=False)→ str:

使用 project.paths、当前文件夹和其他相关信息折叠文件路径。 

tdu.collapsePath('C:/downloads/test.bmp') # 在 project.paths 中查找与路径匹配的任意项，并从前缀中去掉当前文件夹。
  • path - 要缩短的路径。
  • asExpression - （关键字，可选）如果为 True，结果可用作表达式，包括 App Class 成员和带引号的字符串。

split(string, eval=False)→ list:

从以空格分隔的字符串返回列表，允许使用引号定界符。

  • string - 任何 Python 对象，因为它会按 str(string) 求值。参数也可以。
  • eval - （关键字，可选）如果为 True，转换任何有效的 Python 字面结构：字符串、数字、元组、列表、字典、布尔值和 None。
split('1 2.3 None fred "one \'2\'" "[1,2]"') # 产出 ['1', '2.3', 'None', 'fred', "one '2'", '[1, 2]']
split('1 2.3 None fred "one \'2\'" "[1,2]"', True) # 产出 [1, 2.3, None, 'fred', "one '2'", [1, 2]]

match(pattern, inputList, caseSensitive=True)→ list:

返回 inputList 的子集，其中每个元素都匹配该模式。支持通配符。 

tdu.match('foo*', ['foo', 'bar']) # 返回 ['foo']
tdu.match('ba?', ['foo', 'bar']) # 返回 ['bar']

forceCrash()→ None:

为调试和崩溃恢复目的强制触发崩溃

tryExcept(func1 : Callable, func2val : Any)→ Any:

求值第一个函数（func1）。如果抛出异常，则返回第二个参数。第二个参数可以是要调用的函数，也可以是最终结果。注意： 如果第二个参数是函数，只有当第一个函数失败时才会调用它。

  • func1：将被「尝试」的函数
  • func2val：一个值（func1 失败时返回）或一个函数（func1 失败时返回其结果）

这是一个单行的 try/except 函数，可在参数表达式中用于处理简单错误。提示： 用 try/except 隐藏错误时务必小心，因为它可能让你代码/网络中的真实问题变得不可见。 

    tdu.tryExcept(lambda: 1/me.par.w, 0.0) # 第二个参数就是 0.0
    tdu.tryExcept(lambda: 1/me.par.w, me.GetDefaultValue)   # 好：me.GetDefaultValue 直到需要时才被调用。
    tdu.tryExcept(lambda: 1/me.par.w, me.GetDefaultValue()) # >> 不正确 <<。总会调用第二个函数，即使并不需要。

ParMenu(menuNames, menuLabels=None)→ TDU.MenuObject:

此方法使用字符串列表创建一个对象，用于作为 parameter 菜单源。

  • menuNames - 菜单值的字符串列表。
  • menuLabels - （可选）菜单标签的字符串列表。默认为 menuNames。

TableMenu(table, nameCol=0, labelCol=None, includeFirstRow=False)→ TDU.MenuObject:

基于 DAT 表格创建参数菜单源对象。

此方法使用表格创建一个对象，用于作为 parameter 菜单源。

  • table - 用于获取菜单信息的 DAT 表格
  • nameCol - （关键字，可选）用于 menuNames 的列名或列号。默认为 0。
  • labelCol - （关键字，可选）用于 menuLabels 的列名或列号。默认为 None，表示使用名称作为标签。
  • includeFirstRow - （关键字，可选）如果为 True，把表格第一行也包含在菜单条目中。默认为 False。

通常在 Component Editor 的 menuSource 字段中这样使用 

    tdu.TableMenu(op('table1')) # 把 table1 的第一列用作菜单名称和标签列表
    tdu.TableMenu(op('table2'), nameCol='names', labelCol='labels') # 从 table2 中，把标为 'names' 的列用作菜单名称，把标为 'labels' 的列用作菜单名称
    tdu.TableMenu(op('table3'), labelCol=1, includeFirstRow=True) # 从 table3 中，把第一列用作菜单名称，第二列用作菜单标签。把这些列表包含表中第一行

isPointCloudFile(path)→ bool:

检查输入文件是否为点云文件。对于 .exr，会检查通道头。如果找到以 X,Y,Z 或 x,y,z 结尾的通道，或该文件是用 Movie File Out TOP 并设置 "Save as Point Cloud" 保存的，则返回 true。

对于所有其他类型，只检查文件扩展名。

  • path - 输入文件的路径。

parSummary(OPType)→ dict:

返回描述所提供 OP 类的内置参数的字典。

  • OPType - 要描述的 OP 类型。
tdu.parSummary(mathCHOP) # 适用于 td.OP 类型或字符串，而非实际的运算符实例。
