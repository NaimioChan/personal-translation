Python 回调系统

CallbackExt 扩展为自定义组件提供 Python 回调功能。所有回调都会收到一个参数，其中包含 info dictionary。回调可以定义在 Callback DAT 参数指定的 DAT 中。要将所有回调报告到 textport，请开启 Print Callbacks 开关参数。Callback DAT 和 Print Callbacks 参数通常位于 Callbacks 参数页，但其位置可以自定义。

信息字典总是包含「ownerComp」键。它还会有保存回调名的「callbackName」键。有时会包含描述回调的「about」键，如果期望返回值，则始终应包含此键。通常，回调在其关联的内部方法之后调用，以便覆盖该方法的原有行为。

TouchDesigner 的 Python 回调系统使用 CallbacksExt Extension。
