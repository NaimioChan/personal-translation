Video Device Out TOP

摘要

Video Device Out TOP 使用设备的原生驱动库将视频路由到输出设备。

目前支持的设备：

  • Blackmagic Design 设备。
  • Bluefish444 设备。
  • AJA 设备。
  • Deltacast 设备。

另请参阅 Video Device In TOP。

videodeviceoutTOP_Class

Signal Format signalformat - 输出的信号格式。这包括分辨率和帧率，以及帧是逐行还是隔行。请注意，使用隔行格式时，速率指的是每秒场数。
Output Pixel Format outputpixelformat - 尽可能设置输出的像素格式（取决于使用的设备类型）。根据设备和设置的要求，数据可能会转换为 YUV 色彩空间。
  • 8-bit RGB fixed8 - 8 位颜色数据，无 alpha 通道。
  • 8-bit + 8-bit Key (Alpha) fixed8key8 - 8 位颜色数据和 8 位 alpha。这通常意味着 SDI 电缆，其中一根电缆传输颜色数据，一根电缆传输 alpha 数据。
  • 10-bit RGB fixed10 - 10 位颜色数据，无 alpha。
  • 12-bit fixed12 -
Output Color Format outputcolorformat - 为支持的设备设置发出数据的颜色格式。YUV 4:2:2 或 RGB 4:4:4
  • yuv422 - YUV 4:2:2。这是通过 SDI 线传输数据最常用的颜色格式。它比 RGB 4:4:4 需要更低的带宽，但会导致一些信息损失。
  • rgb444 - RGB 4:4:4。这需要更多带宽，但不会有 YUV 4:2:2 那样的信息损失。

Manual Field Control manualfield - 输出隔行视频时，如果你使用的源视频也是隔行的，很可能需要确保奇/偶场保持同步，否则视频会看起来卡顿。你可以使用 Movie File In TOP 或 Video Device In TOP 上 Info CHOP 中的 'odd_field' 值，来判断当前帧是奇数场还是偶数场。通常奇数场是第一帧，因此你可以在 First Field 参数中使用此值，告诉 Video Device Out TOP 当前帧是第一个场。在下一帧，你会将此值设为 0（'odd_frame' 也会变为 0），告诉 Video Device Out TOP 当前帧是第 2 帧，此时你有一个完整的帧可以输出。应在 Video Device In 或 Movie File In TOP 上启用去隔行，以便场逐次送入网络。
First Field firstfield - 在输出隔行视频时，告诉 Video Device Out TOP 当前作为其输入提供的帧是最终输出图像中的第一个场还是第二个场。更多信息请参阅 Manual Field Control 的说明。
Timecode Object/CHOP/DAT timecodeop - 将时间码嵌入输出。可以引用具有 'hour'、'second'、'minute'、'frame' 通道的 CHOP、第一个单元格中包含时间码字符串的 DAT，或 Timecode Class 对象。
Transfer Mode transfermode - 控制图像数据如何在 GPU 与输出卡之间传输。
  • Automatic automatic - 为计算机上安装的组件选择最佳传输模式。可能时会选择 'Pinned'，因为其性能最佳。
  • Default default - 传输分 3 个阶段进行。GPU 到 CPU 内存。CPU 内存到驱动内存。驱动内存到输出卡。
  • Pinned pinned - 传输分 2 个阶段进行。GPU 到驱动内存。驱动内存到输出卡。
Sync Outputs syncoutputs - This feature requires a Pro license. 在 Deltacast FLEX 系列卡和 Blackmagic Design 卡上受支持。Blackmagic 需要连接参考输入。这会使多个独立的输出节点彼此保持同步。否则每个输出将有自己的输出队列长度，可能与其他节点相差 1 或 2 帧。大多数 Blackmagic 卡还需要连接 Genlock 源，此功能才能正常工作。
Sync Group Index syncgroupindex - 对于不同的卡组，可以通过为同一组中的多张卡指定相同的索引，将它们组合到不同的同步组中。
Reset Stats resetstats - 一个脉冲，用于重置所附加 Info CHOP 中的统计数据。

参数 - Color 页

Output Color Space colorspace - 控制数据在输出前转换为哪种色彩空间。如果输出（SDI/ST2110/HDMI 等）支持 HDR 元数据且下方的 HDR Metadata 开关已打开，它还会尝试将色彩空间包含在其中。某些输出形式在其元数据中只支持有限数量的色彩空间。例如 SDI 仅支持 Rec.601、709 和 2020 色域，搭配 Rec.709、HLG 和 PQ 转换。如果输出格式不认识该色彩空间，则不会包含元数据，或包含默认元数据。
  • sRGB srgb - sRGB 色彩空间，使用 sRGB 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • sRGB - Linear srgblinear - sRGB 色彩空间，使用线性传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.601 (NTSC) rec601ntsc - Rec.601，NTSC 原色色彩空间，使用 Rec.601 传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.709 rec709 - Rec.709 色彩空间，使用 Rec.709（与 Rec.2020 相同）传递函数。相对于 Reference White 而言视为 SDR 色彩空间。
  • Rec.2020 rec2020 - Rec.2020 色彩空间，使用 Rec.2020（与 Rec.709 相同）传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Rec.2020 ST2084PQ rec2020st2084pq - Rec.2020 色彩空间，使用 Perceptual Quantizer 传递函数。相对于 Reference White 被视为 HDR 色彩空间。
  • Rec.2020 HLG rec2020hlg - Rec.2020 色彩空间，使用 Hybrid Log Gamma 传递函数。相对于 Reference White 被视为 HDR 色彩空间。
  • DCI-P3 dcip3 - DCI-P3 色彩空间，D65 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • DCI-P3 (D60) dcip3d60 - DCI-P3 "D60 sim" 色彩空间，D60 白点，2.6 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Display-P3 (D65) displayp3d65 - Display-P3 色彩空间，D65 白点，sRGB gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • Display-P3 (D65) - Linear displayp3d65linear - Display-P3 色彩空间，具有 D65 白点和线性传递函数。相对于 Reference White 被视为 HDR 色彩空间。
  • ACES2065-1 aces2065-1 - ACES 2065-1（也称为 ACES AP0）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACEScg acescg - ACEScg（也称为 ACES AP1）色彩空间，线性 gamma 传递函数。相对于 Reference White 而言视为 HDR 色彩空间。
  • ACESproxy acesproxy - ACESproxy 色彩空间，具有对数传递函数。相对于 Reference White 被视为 HDR 色彩空间。
  • Passthrough passthrough - 选中后，颜色值将按原样用于运算，不作任何修改，也不尝试将其转换到 Working Color Space。
Output Reference White outputreferencewhite - - 把颜色值转换为工作色彩空间以便输出时，此参数控制它们相对于 Reference White 应如何处理。如果工作色彩空间具有相同的 Reference White，则不做调整。如果不同，颜色的 Reference White 水平（亮度）会被调整到输出色彩空间所期望的范围。例如项目设置的 SDR Reference White 为 120 nits、HDR Reference White 为 80 nits，而项目工作色彩空间为 HDR、输出色彩空间为 SDR：那么颜色 (1, 1, 1) 在 HDR 色彩空间中为 80 nits，会被转换为 (0.66, 0.66, 0.66)，在 SDR 输出色彩空间中仍为 80 nits。
  • Default For Color Space default - 根据检测到/选择的色彩空间，使用 SDR 或 HDR Reference White。
  • Standard (SDR) sdr - 将输出色彩空间的参考白值按 SDR 处理。
  • High (HDR) hdr - 将输出色彩空间的参考白值按 HDR 处理。

  • Quarter quarter - 将输入的分辨率乘以该数值。
  • Half half - 将输入的分辨率乘以该数值。
  • 2X 2x - 将输入的分辨率乘以该数值。
  • 4X 4x - 将输入的分辨率乘以该数值。
  • 8X 8x - 将输入的分辨率乘以该数值。

Info CHOP 通道

Video Device Out TOP 的额外信息可以通过 Info CHOP 访问。

Video Device Out TOP 特定的 Info 通道

  • connected - 若设备已连接/活动则为 1，否则为 0。
  • play_speed - 音频数据的播放速度。以正常速度播放时为 1，若需要调整队列大小以达到目标大小，该值会略快或略慢。
  • dropped_frames - 输出端丢帧的数量。这些是输出端未能为其提供新数据的帧。如果 TD 的运行帧率低于信号格式的帧率，该值应会不断增加。
  • skipped_frames - 这些是 TD 已生成、但未被输出端消费的帧。原因可能是 PCIe 带宽（或设备）的运行速度低于数据吞吐量/帧率所需。
  • late_frames - 这些是及时送达采集卡、但最终比预期更晚显示的帧。通常仅在 Blackmagic 设备上跟踪。
  • frame_queue_length - 在软件中排队等待输出的视频帧数量。
  • frame_hw_queue_length - 在设备硬件中排队等待输出的视频帧数。
  • audio_sw_buffer_length - 软件中音频缓冲区的长度（秒）。
  • audio_hw_buffer_length - 设备硬件中音频缓冲区的长度（秒）。
  • genlocked - 若已知采集卡与某路输入锁相（genlock），则为 1；若未锁相，则为 0；若未知，则为 -1。
  • last_dma_copy_time - 上一次从驱动内存拷贝到设备所花费的时间（毫秒）。若此设备类型不测量该值，则为 -1。

TOP 通用信息通道

  • resx - TOP 的水平分辨率，以像素为单位。
  • resy - TOP 的垂直分辨率，以像素为单位。
  • aspectx - TOP 的水平宽高比。
  • aspecty - TOP 的垂直宽高比。
  • depth - 如果此 TOP 包含 2D 或 3D 纹理数组，则为该 2D 或 3D 数组的深度。
  • gpu_memory_used - 此 TOP 使用的纹理内存总量。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
