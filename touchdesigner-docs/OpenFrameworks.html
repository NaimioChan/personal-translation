openFrameworks

The previous TouchDesigner 2021.10000 series of builds of TouchDesigner, which still used OpenGL, has an infrastructure to process and render openFrameworks projects within the TouchDesigner process via a CPlusPlus TOP. openframeworks is not compatiblity currently with the 2022.20000+ builds, due to the changeover to Vulkan as our rendering API.

TouchDesigner 的 openFrameworks 示例项目已升级到 64 位 openFrameworks v0.9.8，包含四个 C++ TOP 示例。

Download Examples here:
File:OpenFrameworksExamples.zip

设置

1) Download openFrameworks 并将其解压到你的工作目录。

2) 将 TouchDesigner 安装文件夹中的以下文件夹： 

   C:/Program Files/Derivative/TouchDesigner/Samples/CPlusPlus/OpenGLTOP

复制到解压后的 openFrameworks 文件夹中的以下目录： 

   apps/myApps

将该文件夹重命名为你项目的名称。

注意：这并非严格必需，但它会方便很多，因为 openFrameworks 包含一个属性表，其中列出了相对于 openFrameworks 文件夹根目录的所有 "Additional Include Directories"。否则所有包含目录都必须手动添加。

3) 从你刚复制过来的文件夹中打开 Visual Studio 解决方案（.sln）。你必须使用 Visual Studio 2012 或更高版本才能编译 openFrameworks。

4) 在 Visual Studio 中，于 "Solution Explorer" 里右键单击该解决方案，然后单击 "Add → Existing Project"。

5) 找到解压 openFrameworks 的文件夹并选择： 

   libs/openFrameworksCompiled/project/vs/openframeworksLib.vcproj

6) 右键单击 CPlusPlusTOPExample 项目并单击 "Project Dependencies"。在 Dependencies 页中勾选 openframeworksLib 旁的复选框。单击 OK。

7) 右键单击 CPlusPlusTOPExample 项目并单击 References。单击 "Add New Reference" 并勾选 openframeworksLib 旁的复选框。单击 OK。

8) 右键单击 CPlusPlusTOPExample 项目并单击 Properties。找到 "Configuration Properties → General"，将 "Output Directory" 设置为 $(SolutionDir)\bin

9) 单击 "View → Property Manager"（或 "View → Other Windows → Property Manager"）。展开 CPlusPlus TOP 项目。对每个 debug 文件夹，右键单击并单击 "Add Existing Property Sheet"。找到解压 openFrameworks 的文件夹并选择： 

   libs/openFrameworksCompiled/project/vs/openFrameworksDebug.props

10) 对 release 文件夹做同样的操作，只是改为选择： 

   libs/openFrameworksCompiled/project/vs/openFrameworksRelease.props

11) 回到 "Solution Explorer" 并打开 TOP_CPlusPlusBase.h。删除以下行： 

#include <windows.h>
#include <cstdio>

并将它们替换为： 

#include "ofMain.h"

12) 在 CPlusPlusTOPExample.h 中，添加 

#include "ofAppNoWindow.h"

并添加成员 

ofAppNoWindow myWindow;
ofGLProgrammableRenderer *renderer;

到该 TOP 的类体中。

13) 在 CPlusPlusTOPExample.cpp 中： 将以下行添加到构造函数 CPlusPlusTOPExample::CPlusPlusTOPExample 中： 

renderer = new ofGLProgrammableRenderer(&myWindow);
ofSetDataPathRoot(path_to_dir);

由于运行的应用是 TouchDesigner，openFrameworks 默认会在已安装的 TouchDesigner 的 bin 中查找 /data。 如果你有任何着色器/图像要加载，则需要 ofSetDataPathRootpath_to_dir); 来为 openFrameworks 提供 bin/data 目录的路径。
注意：path_to_dir 必须使用正斜杠，并且可以是绝对路径，或相对于 TouchDesigner 可执行文件的相对路径。
示例：ofSetDataPathRoot("../../../../of_v0.9.3_vs_release/apps/myApps/CPlusPlusTOPExample/bin/data/")

14) 创建一个只被调用一次的 CPlusPlusTOPExample::setup 函数： 

void CPlusPlusTOPExample::setup() 
{
    glewInit();
    renderer->setup(3, 2);<br>
    // 加载任意着色器、图像等
}

除了 glewInit(); 和 renderer->setup(3, 2);，这里也是你应加载任何着色器或图像的地方。

15) 在 CPlusPlusTOPExample::execute 顶部查询任何自定义参数。

16) 查询分辨率的宽度和高度： 

 int width = outputFormat->width;
 int height = outputFormat->height;

然后用 C++TOP 的宽度和高度设置窗口： 

 ofSetupOpenGL(&myWindow, width, height, OF_WINDOW);

17) 用以下内容包住 CPlusPlusTOPExample::execute 的其余部分：

context->beginGLCommands();<br>
// ... 其余代码<br>
context->endGLCommands();

18) 添加被上下文包裹的 CPlusPlusTOPExample::setup 调用

19) 对于 openFrameworks 中的任何渲染，都需要用以下内容包裹： 

renderer->startRender();
renderer->setupScreen();<br>
// 任何着色器/图像绑定、绘制等。<br>
renderer->finishRender();

步骤 15-19 之后的 CPlusPlusTOPExample::execute 示例 

void CPlusPlusTOPExample::execute(const TOP_OutputFormatSpecs* outputFormat, OP_Inputs* inputs, TOP_Context *context) 
{
    // 查询自定义参数 <br>
    int width = outputFormat->width;
    int height = outputFormat->height;<br>
    ofSetupOpenGL(&myWindow, width, height, OF_WINDOW);<br>
    context->beginGLCommands();<br>
    if(!isSetup)
    {
      setup();
    }<br>
    renderer->startRender();
    renderer->setupScreen();<br>
    // 任何着色器/图像绑定、绘制等。<br>
    renderer->finishRender();<br>
    context->endGLCommands();
}

19) 构建项目。使用 CPlusPlus TOP 所需的所有 DLL 都位于解压 openFrameworks 的文件夹中的以下目录： 

   apps/myApps/<project-name>/bin

由于存在依赖关系，所有 DLL 必须保留在同一目录中，这一点很重要。如果其它所需的 DLL 位于同一目录，TouchDesigner 会自动加载它们。

将 openFrameworks 代码转换为在 TouchDesigner 中运行

使用上述步骤创建 ofAppNoWindow 会导致许多 openFrameworks 函数失效，而 ofGetCurrentRenderer()（它查询窗口的渲染器）正是罪魁祸首。
渲染器持有许多有用的渲染功能，但 ofAppNoWindow 的 ofNoopRenderer 缺少关键功能。因此 ofGetCurrentRenderer() 返回的渲染器不可用，会导致崩溃或什么也不做。
要在 TouchDesigner 中使用 openFrameworks 进行渲染，必须绕过 ofGetCurrentRenderer()，也就是说任何调用 ofGetCurrentRenderer() 的函数都不能使用。这正是步骤 12-13 中创建 ofGLProgrammableRenderer 对象的原因。
要转换任何调用 ofGetCurrentRenderer() 的 openFrameworks 函数，请查看源码，了解它如何使用渲染器，然后使用已创建的 ofGLProgrammableRenderer 对象将该功能移入你的 CPlusPlusTOPExample。
openFrameworks 是开源的，因此你需要查看源代码，弄清具体哪些函数需要修改。所有绘制、绑定和变换都需要修改。

绑定着色器的示例：

shader.begin();

变为

renderer->bind(shader);

使用输入 TOP

以下代码是一个如何将输入 TOP 与 openFrameworks 一起使用的示例： 

void
CPlusPlusTOPExample::execute(const TOP_OutputFormatSpecs* outputFormat,
 				const TOP_InputArrays* arrays,
 				void* reserved)
{
    // ...
    // 使用第一个输入 TOP（这里假设它存在，但实际中可能不存在）
    const TOP_TOPInput *topInput = &arrays->TOPInputs[0];
    ofTexture texture;
    texture.setUseExternalTextureID(topInput->textureIndex);
    texture.texData.width = topInput->width;
    texture.texData.height = topInput->height;
    texture.texData.tex_w = topInput->width;
 	
    texture.texData.tex_h = topInput->height;
    texture.texData.textureTarget = topInput->textureType;
    // ...
}
