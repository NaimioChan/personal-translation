Noise POP

摘要

Noise POP 用一个噪声场影响每个点，可以把该噪声场理解为 3D 空间中平滑、随机起伏的值。

默认情况下，Noise POP 会根据点在噪声空间中的位置，沿 X、Y、Z 方向移动每个点的 P 属性。把 Grid POP 输入 Noise POP 即可可视化该场。打开开关参数 Compute Point Normals 可看到正确的着色。

Type 菜单可让你在 2-4 维的 Simplex、Perlin 之间选择。Simplex 的场外观最不呈网格状。Period 决定每个维度上两个峰值之间的大致距离（如果将 Harmonics 设为 0）。

Harmonics 通过向场中叠加另一个半周期的噪声场来增加细节，并按「谐波」数量递归进行。Harmonic Spread 是一个谐波周期与下一个谐波周期的比值。此外，整个噪声场可通过 Transform 页平移、旋转或缩放。

噪声场的值在 X、Y、Z 上平均为 0。Amplitude 和 Exponent 参数会影响结果值的大小，Offset 则加到结果噪声值上。

Output attributes - 在 Output 页上，你可以将原始噪声值输出到属性，默认名称为 Noise。由于 Noise 页上的 Noise Size 菜单参数默认为 Scalar，Noise 属性是单个标量浮点数。

如果 Noise Size 菜单参数设为 Vector，Noise 属性就是 3 分量浮点数；若 Parameter Size 设为 4，则为 4 分量。

在 Output 页上，你还可以输出若干由噪声场派生的数学函数，例如 Gradient 和 Curl。

Gradient 是标量噪声在每个点周围沿 X、Y、Z 的变化率（又称「一阶导数」），是一个名为 NoiseGradient 的 float3

Curl 表示斜率在每个点周围扭转的程度。3D Curl 是名为 NoiseCurl 的 float3。2D Curl 是名为 NoiseCurl2 的 float2

如果 Combine Operation 为 Add（默认）或 Multiply，则 float3 噪声始终应用于 P，即使噪声设为标量。使用 Combine Attribute Scope，噪声可应用于任意标量或矢量属性（1 到 4 个分量），并输出到任意新建或现有的属性。

使用 Combine Entity，你可以改为将 NoiseCurl 与任意属性组合。

当 Noise Size 设为 Vector 时，将 Parameters Size 改为 2、3 或 4，即可按 X Y Z W 各维度分别控制 Amplitude、Exponent 和 Offset 参数。

要为噪声制作动画，可在 Transform 页的任意 Translate 或 Translate 4D 参数中填入类似 absTime.seconds 的表达式。

Per-point mapping of parameters - Noise POP 有一个 Map 页，可让每个点在 Amplitude、Offset、Exponent、Period、Harmonic Spread 和 Harmonic Gain 参数上取得不同的值。在此机制中，输入中一个单独的属性包含用于覆盖（或加上/乘以）参数值的值。参见 Mapping POP Attributes to Parameters。

另请参阅 Random POP。
