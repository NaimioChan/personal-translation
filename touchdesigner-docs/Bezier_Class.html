Bezier 类

Bezier 描述单个几何 Bezier 图元的一个实例（包含一组相连的 Bezier 曲线）。它是 Prim Class 的一个实例。 可以从 Model SOP 或 Script SOP 创建。 每条曲线由一组线段描述，其中每个线段是一个 vertices 列表。每个线段的首尾顶点是锚点位置，而相邻顶点描述切线手柄。

下面的成员和方法允许在建模场景中修改 Bezier，但也可以通过直接操纵其顶点来修改 Bezier。详见 Prim Class。

成员

anchors → list (Read Only):

返回锚点 vertices 的列表。

basis → list (Read Only):

以浮点值列表的形式返回 bezier 基。

closed → bool :

获取或设置曲线是闭合还是开放。

order → float (Read Only):

返回 bezier 阶。阶等于次数加一。

segments → list (Read Only):

返回线段列表，其中每个线段是一个 vertices 列表。

tangents → list (Read Only):

以 vertex 对的列表形式返回切线。

方法

insertAnchor(u)→ Vertex:

在给定位置（u 从 0..1）插入锚点，并返回锚点顶点。

updateAnchor(anchorIndex, targetPosition, tangents=True)→ tdu.Position:

将锚点顶点修改为新的 position。如果 tangents 为 True，也会修改相邻的切线顶点。返回结果位置。

appendAnchor(targetPosition, preserveShape=True)→ Vertex:

追加一组顶点，在曲线上创建新的线段，并以 targetPosition 结尾。

返回最终的锚点顶点。

  • preserveShape -（Keyword，Optional）指定新的切线是否与上一段对齐。

updateTangent(tangentIndex, targetPosition, rotate=True, scale=True, rotateLock=True, scaleLock=True)→ tdu.Position:

将顶点 vertex 修改为新的 position，并约束旋转或缩放。Locked 控制匹配的切线。返回结果位置。

deleteAnchor(anchorIndex)→ None:

删除该锚点及其相邻的切线。
