Boolean SOP

摘要

Boolean SOP 接收两个封闭的多边形集 A 和 B。将这些 Source 设为包含你要操作的 3D 形状的 SOP。输入几何有两个重要要求：

  • 形状必须完全封闭。两端开口的管状体不是可接受的输入。你可以用端盖封闭 Tube 的末端。没有输出背面多边形的挤出文字也不可接受（即使输出了背面，也可能因第二个要求而不可接受）。
  • 所有多边形必须是凸的且共面。对于 Extrude SOP，你必须为正面和背面选择 Output Convex Faces。这样它才能作为 Boolean 的可用输入。Divide SOP 也为非 Extrude SOP 创建的几何提供了凸化功能。

Boolean 的其他注意事项如下：

  • 点颜色和纹理 UV 坐标不会被正确插值。
  • 某些情况下多边形可能被反转，使所有法线都朝外。多边形反转通常不会造成太大问题（如有必要，可用 Primitive SOP → Face/Hull 页 → Vertex → Reverse 将其反转）。
  • 当 Boolean SOP 报怨输入未封闭时，可用 Facet SOP 准备输入。此时请同时使用 Consolidate Points 和 Orient Polygons 选项。

此 SOP 相当直观可视；你可以在屏幕上试验不同的组合以查看效果。

注意： Boolean SOP 处理多边形几何类型。对于 nurbs 和 Bezier 曲面的布尔类操作——参见 Surfsect SOP。

参数 - 页

Operation booleanop  - - 下面某些操作会产生辅助几何，以便对正在执行的操作结果提供视觉反馈。该几何的外观与上下文相关——如果你执行相交操作或任一边缘操作，辅助几何将是两个输入；如果你执行 A 减 B，辅助几何将是 B；如果是 B 减 A，则是 A。如果执行并集，则不会有辅助几何。

如果辅助几何过于干扰，可进入 Viewport 选项对话框并点击 Guide geometry 按钮使其不再缩进，从而禁用它。此操作是全局的，也会禁用其他 SOP 的辅助几何。

Boolean SOP 会自动调整多边形朝向，使其朝向一致。某些情况下这可能不够，因为 Boolean 会在相交切割处产生一些非共享边。如果着色仍不够好，最好在 Boolean 之后接一个 Facet SOP。在其中依次使用 Consolidate Points、Orient Polygons，最后 Cusp。

如果多边形形状非常奇怪，你可以先用 Divide SOP 对其中一个或两个输入进行三角化。

  • Union union - 两个输入的几何会合并，内部多边形被移除。结果是封闭形状。这对于连接管道或摄像机将在其中穿行的其他形状，或相交形状必须透明的情况非常有用。形状相交处的点不会被合并。
  • Intersect intersect - 结果几何是两个输入形状重叠或相交处的封闭形状。公共区域之外的几何被丢弃。
  • A minus B aminusb - 结果是一个封闭形状，其中 B 的几何被切除或从 A 的几何中减去。
  • B minus A bminusa - 所有操作与前三项相同，但结果形状是 B 部分，从中切除了 A 部分。
  • A Edge aedge - 在两个部分相接的边缘处产生封闭面。面可能是扭曲的（非平面）。点的顺序不可预测；如果要在该面上建立连接，请附加一个启用 Order Points 选项的 Polygon SOP 来整理。
  • B Edge bedge - 在两个部分相接的边缘处产生封闭面。面可能是扭曲的（非平面）。点的顺序不可预测；如果要在该面上建立连接，请附加一个启用 Order Points 选项的 Polygon SOP 来整理。
Accurate Attributes Interpolation accattrib - 若选中，所有输入会被凸化为三角形，否则凸化为四边形。
Create Groups creategroup - 若选中，会创建一个包含第一个输入所有面的组，以及另一个包含第二个输入所有面的组。
Group A groupa - 当 Create Groups = On 时，指定 Group A 的名称。
Group B groupb - 当 Create Groups = On 时，指定 Group B 的名称。

用法

  • 从另一个 3D 形状中切出一个 3D 形状。
  • 将一个 3D 形状与另一个 3D 形状连接，移除内部多边形。
  • 在两个 3D 形状相交处创建 3D 形状。
  • 在 3D 形状相交处创建孔洞或平面。
  • 为上述任一效果制作动画。

Info CHOP 通道

Boolean SOP 的额外信息可通过 Info CHOP 访问。

SOP 通用信息通道

  • num_points - 此 SOP 中的点数。
  • num_prims - 此 SOP 中的图元数。
  • num_particles - 此 SOP 中的粒子数。
  • last_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的几何数据所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。
  • last_meta_vbo_update_time - 在另一个线程中根据 SOP 的 CPU 数据更新 GPU 上的元表面几何数据（如 metaball 或 nurbs）所花的时间。由于它属于另一个线程，此时间不计入通常的帧时间。

通用操作符 Info 通道

  • total_cooks - 自进程启动以来该操作符的计算次数。
  • cook_time - 上一次计算的耗时，单位为毫秒。
  • cook_frame - 该操作符上一次计算时的帧号，相对于组件时间轴。
  • cook_abs_frame - 该操作符上一次计算时的帧号，相对于绝对时间。
  • cook_start_time - 该操作符在其计算的那一帧中开始计算的时刻，单位为毫秒。
  • cook_end_time - 该操作符在其计算的那一帧中结束计算的时刻，单位为毫秒。
  • cooked_this_frame - 如果操作符在本帧进行了计算则为 1。
  • warnings - 该操作符的警告数量（如果有）。
  • errors - 该操作符的错误数量（如果有）。
